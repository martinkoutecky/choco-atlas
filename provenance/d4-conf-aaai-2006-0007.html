Result

The exact optimization problem is solvable in time polynomial in \(m,\tau,L\). This includes computing the exact optimum and an optimal rational vector.

The proof uses the explicitly given linear program and polynomial-time exact rational linear programming. It does not require expanding the support into individual voters.

1. Computing the majority weights exactly

Write each input mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive integers encoded in binary. Define

\(Q=\prod_{t\in T}q_t,\qquad h_t=p_t(Q/q_t).\)

Then \(\mu_t=h_t/Q\). Since the masses sum to one,

\(\sum_{t\in T}h_t=Q.\)

The binary length of \(Q\) is \(O(L)\): indeed, \(\log_2 Q=\sum_t\log_2q_t\), and the denominator encodings are part of the input. Consequently, every \(h_t\) also has \(O(L)\) bits.

For distinct candidates \(a,b\), define the integer

\(W_{ab}=\sum_{t:a\succ_t b}h_t-\sum_{t:b\succ_t a}h_t.\)

Thus \(w_\mu(a,b)=W_{ab}/Q\), and \(|W_{ab}|\le Q\). In particular, every majority weight has \(O(L)\) bits, and its sign can be determined exactly.

Constructing position arrays for the rankings permits each comparison \(a\succ_t b\) to be answered directly. Computing all margins then requires \(O(\tau m^2)\) additions or subtractions of integers with \(O(L)\) bits. Including the common-denominator computations, a conservative bound using elementary integer arithmetic is

\(O\bigl((\tau m^2+\tau)L^2\bigr)\)

bit operations.

Set \(c_{ab}=W_{ab}\) when \(W_{ab}>0\), and \(c_{ab}=0\) otherwise. The required objective is exactly

\(\displaystyle \frac1Q\sum_{a\ne b}c_{ab}x_{ab}.\)

Because \(Q>0\), minimizing the integer-coefficient objective \(\sum_{a\ne b}c_{ab}x_{ab}\) gives precisely the same optimal vectors.

2. The linear program has polynomial encoding length

If \(m=1\), the optimum is \(0\), and the empty vector is optimal. Hence assume \(m\ge2\).

There are \(n=m(m-1)\) variables. An explicit constraint list consists of:

  • \(2n\) inequalities imposing \(0\le x_{ab}\le1\);
  • \(\binom m2\) pair equalities, each expressible as two inequalities;
  • \(m(m-1)(m-2)\) ordered-triple inequalities.

Thus there are \(O(m^3)\) inequalities. Every constraint coefficient and right-hand side belongs to \(\{-1,0,1\}\). The objective coefficients have \(O(L)\) bits by Section 1.

Even using a dense matrix representation, the total linear-program encoding length \(B\) therefore satisfies

\(B=O(m^5+m^2L).\)

The feasible set is nonempty: assigning \(x_{ab}=1/2\) for every ordered pair satisfies every pair equality, and each triangle sum equals \(3/2\). It is closed and contained in \([0,1]^n\), hence compact. The linear objective therefore attains a finite minimum.

3. Exact rational optimization and running time

We apply the standard exact rational linear-programming theorem:

A linear program with binary-encoded rational data can be solved in time polynomial in its encoding length. If its feasible set is nonempty and its minimum is finite, an optimal rational solution can be computed.

This is the bit-complexity theorem for linear programming, rather than merely an approximation guarantee. Integer-data feasibility and its reduction to exact optimization through primal-dual feasibility are described in [MIT’s lecture on the ellipsoid method](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

All hypotheses have been checked: our coefficients are integers of polynomial encoding length, the feasible set is nonempty, and the objective attains a finite minimum.

Apply this theorem to the objective \(\sum_{a\ne b}c_{ab}x_{ab}\), obtaining an optimal rational vector \(x^*\). Return \(x^*\) and the exact rational number

\(\displaystyle v^*=\frac1Q\sum_{a\ne b}c_{ab}x^*_{ab}.\)

For some fixed polynomial \(P\), the total running time is bounded by

\(O\bigl((\tau m^2+\tau)L^2\bigr)+P(m^5+m^2L),\)

including polynomial-time exact evaluation of the returned objective. This is polynomial in \(m,\tau,L\).

4. A direct bound on exact output size

There is also a particularly simple bound showing that an exact optimal vector need not have a large representation.

A linear objective on a nonempty compact polytope has an optimal vertex. At such a vertex, choose \(n\) linearly independent tight constraint rows, obtaining \(Ax=b\). Here \(A\) is an invertible integer matrix, and each row has at most three nonzero entries, all equal to \(1\) or \(-1\). Hadamard’s determinant inequality gives

\(1\le|\det A|\le3^{n/2}.\)

By Cramer’s rule, all coordinates have a common denominator \(D=|\det A|\). Since each coordinate lies in \([0,1]\), they can be written as \(x_{ab}=k_{ab}/D\), with integers \(0\le k_{ab}\le D\). Each coordinate consequently needs only \(O(n)\) bits, so the whole vector needs \(O(n^2)=O(m^4)\) bits.

Its objective value has the representation

\(\displaystyle \frac{\sum_{a\ne b}c_{ab}k_{ab}}{QD}.\)

The numerator is at most \(nQD\). Hence the exact value needs \(O(L+m^2)\) bits. Exact output therefore presents no exponential-size obstruction.

5. Relation to the cited relaxation

The pair-and-triangle formulation appears as Linear Program 3 in [Conitzer, Davenport, and Kalagnanam](https://www.cs.cmu.edu/~conitzer/kemenyAAAI06.pdf), where its polynomial size and equality of optimum with the cycle relaxation are established.

For the present complexity question, that equality is unnecessary: the given formulation itself already provides the polynomial-size rational linear program. The support encoding is handled directly by the majority-weight calculation above.
