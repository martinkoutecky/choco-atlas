The continuous mirror question, as graded

Given a Boolean domain \(\{0,1\}^n\), a distribution \((\Psi_i,\mu_i)_{i=1}^{\tau}\) over RPF preference types, two partial alternatives \(\alpha,\beta\in\{0,1,?\}^n\), and a rational threshold \(q\in[0,1]\), is \(\sum_{i=1}^{\tau}\mu_i\,\mathbf{1}[\exists\,\widehat{\alpha}\in\mathrm{Comp}(\alpha),\,\widehat{\beta}\in\mathrm{Comp}(\beta):\widehat{\alpha}\succ_{\Psi_i}\widehat{\beta}]\ge q\)? Each type’s possible-dominance test uses its own completion witnesses.

Packaged proof task (what the prover saw — nothing else)

Let \(m=n\ge 1\) be the number of Boolean attributes. An RPF type is an explicitly encoded finite list \(\Psi_i=(\varphi_{i,1},\ldots,\varphi_{i,k_i})\), with \(k_i\ge 1\), of arbitrary propositional formulas over these attributes.
For \(x\in\{0,1\}^n\), define \(r_i(x)=\min\{j:x\models\varphi_{i,j}\}\), taking \(r_i(x)=\infty\) if none is satisfied; define \(x\succ_{\Psi_i}y\) exactly when \(r_i(x)<r_i(y)\). Equal ranks remain tied.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_i\) a binary rational, with \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types.
For \(\gamma\in\{0,1,?\}^n\), let \(\mathrm{Comp}(\gamma)\) consist of all Boolean assignments agreeing with its specified coordinates, without additional feasibility constraints.
Given this society, partial alternatives \(\alpha,\beta\), and a binary rational \(q\in[0,1]\), decide whether \(\sum_{i=1}^{\tau}\mu_i\mathbf{1}[\exists x\in\mathrm{Comp}(\alpha),\ y\in\mathrm{Comp}(\beta):x\succ_{\Psi_i}y]\ge q\). Each type has its own completion witnesses.
State running times in \(m,\tau,L\), where \(L\) is the total input bit length, including all formulas, masses, partial alternatives, and the threshold.

Is this mass-threshold possible-dominance problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

Single-agent possible dominance under RPF preferences is \(\mathrm{NP}\)-complete, while comparing two complete alternatives is in \(\mathrm{P}\). [Source](https://journals.flvc.org/FLAIRS/article/view/135556).
No published complexity classification for this exact distribution problem was located in the literature search.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: all listed masses are positive binary rationals summing to one.
  • Specified RPF types as nonempty, explicitly encoded lists of unrestricted propositional formulas, with unsatisfied alternatives ranked at infinity and equal ranks tied.
  • Specified completions as unrestricted Boolean assignments agreeing with known coordinates.
  • Used m=n for the number of Boolean attributes and L for total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

The problem is \(\mathrm{NP}\)-complete under polynomial-time many-one reductions. Hardness holds even with \(\tau=2\), equal masses, fixed threshold \(q=1/2\), a complete alternative \(\beta\), and at most two formulas per type.

The proof below is self-contained and does not require the single-agent complexity result from the cited [study of partial alternatives](https://journals.flvc.org/FLAIRS/article/view/135556).

1. Membership in \(\mathrm{NP}\)

For each type, write
\[ E_i \iff \exists x\in\mathrm{Comp}(\alpha),\ y\in\mathrm{Comp}(\beta): r_i(x)<r_i(y). \]

A certificate specifies a subset \(S\subseteq\{1,\ldots,\tau\}\) and, for every \(i\in S\), two assignments \(x_i,y_i\in\{0,1\}^m\). The verifier checks:

  • \(x_i\in\mathrm{Comp}(\alpha)\) and \(y_i\in\mathrm{Comp}(\beta)\).
  • \(r_i(x_i)<r_i(y_i)\), by evaluating the explicitly listed formulas.
  • \(\sum_{i\in S}\mu_i\ge q\), using exact rational arithmetic.

The certificate uses \(O(\tau m+\tau)\) bits.

Soundness. Every accepted witness proves \(E_i\) for its selected type. Since all masses are positive,
\[ \sum_{i=1}^{\tau}\mu_i\mathbf 1[E_i] \ge \sum_{i\in S}\mu_i \ge q. \]

Completeness. If the instance is a yes-instance, select all types satisfying \(E_i\) and provide one witnessing pair for each. Their total mass reaches \(q\). For \(q=0\), the empty subset suffices.

For the running time, checking completion consistency costs \(O(\tau m)\), and evaluating every selected formula on both witnesses costs \(O(L)\). To sum the masses exactly, one may maintain a common denominator given by the product of their input denominators. Its bit length is \(O(L)\). Because every partial sum lies in \([0,1]\), its numerator also has \(O(L)\) bits. With schoolbook integer arithmetic, summation and threshold comparison therefore take \(O(\tau L^2)\) bit operations.

Thus verification takes
\[ O(\tau m+L+\tau L^2), \]
which is polynomial in the input length.

2. Hardness with two equally weighted types

Reduce from propositional satisfiability, which is \(\mathrm{NP}\)-complete.

Let \(F\) be a propositional formula over variables \(u_1,\ldots,u_v\). Introduce a fresh Boolean attribute \(z\), so \(m=v+1\), and define
\[ \alpha=(?,\ldots,?,1), \qquad \beta=(0,\ldots,0,0). \]
Thus \(\alpha\) leaves the variables of \(F\) unspecified and fixes \(z=1\); \(\beta\) is complete and fixes \(z=0\).

Construct the two types
\[ \Psi_1=(z\land F), \qquad \Psi_2=(z\land F,\neg z), \]
with
\[ \mu_1=\mu_2=\frac12, \qquad q=\frac12. \]
This is a valid society with two positive masses summing to one.

For the unique completion \(y=\beta\), the first formula is false because \(z=0\). Consequently,
\[ r_1(y)=\infty, \qquad r_2(y)=2. \]

For any \(x\in\mathrm{Comp}(\alpha)\), we have \(z=1\), so \(\neg z\) is false. Hence, for both types,
\[ r_i(x)= \begin{cases} 1,&\text{if the assignment to }u_1,\ldots,u_v\text{ satisfies }F,\\ \infty,&\text{otherwise}. \end{cases} \]

It follows that:

  • If \(F\) is satisfiable, a satisfying assignment extends to an \(x\in\mathrm{Comp}(\alpha)\) with rank \(1\) for both types. Since \(1<\infty\) and \(1<2\), both types admit possible dominance. The counted mass is \(1\).
  • If \(F\) is unsatisfiable, every completion of \(\alpha\) has rank \(\infty\) for both types. For the first type, the ranks are tied; for the second, \(\infty<2\) is false. The counted mass is \(0\).

Therefore,
\[ F\text{ is satisfiable} \iff \sum_{i=1}^{2}\mu_i\mathbf 1[E_i]\ge\frac12. \]

The construction has polynomial size and takes polynomial time. This proves \(\mathrm{NP}\)-hardness under the stated restrictions. Together with Section 1, it proves \(\mathrm{NP}\)-completeness.

3. Deterministic running-time bounds

A deterministic exponential-time algorithm need not enumerate all pairs of completions.

Represent rank \(\infty\) for type \(i\) by the integer \(k_i+1\), which preserves every rank comparison. Define
\[ a_i=\min_{x\in\mathrm{Comp}(\alpha)}r_i(x), \qquad b_i=\max_{y\in\mathrm{Comp}(\beta)}r_i(y). \]
Both completion sets are finite and nonempty. Therefore their extrema are attained, and
\[ E_i\iff a_i<b_i. \]

Indeed, any witnessing pair gives \(a_i\le r_i(x)<r_i(y)\le b_i\). Conversely, assignments attaining \(a_i\) and \(b_i\) witness dominance whenever \(a_i<b_i\).

For each type, enumerate all \(2^m\) assignments, check compatibility with the partial alternatives, evaluate its rank, and update these extrema. Summing across types gives the conservative bound
\[ O\!\left(2^m(L+\tau m)+\tau L^2\right) \]
bit operations, including exact mass comparison.

If both alternatives are complete, only their two assignments need evaluation, giving
\[ O(L+\tau m+\tau L^2). \]
Also, \(q=0\) always gives a yes-instance.

Thus the unrestricted problem is \(\mathrm{NP}\)-hard—and, more precisely, \(\mathrm{NP}\)-complete. It is polynomial-time solvable exactly if \(\mathrm{P}=\mathrm{NP}\).
