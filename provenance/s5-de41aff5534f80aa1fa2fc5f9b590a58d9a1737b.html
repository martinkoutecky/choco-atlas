The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), and strict rankings \(\succ_t\) over partner types and a singleton option \(\bot\), does there exist a mass matching \(p_{tu}=p_{ut}\geq 0\), \(s_t\geq 0\), with \(s_t+\sum_{u\in T}p_{tu}=\mu_t\), that has no positive-mass weakly blocking coalition? For a nonempty support \(S\subseteq T\), let \(w_t(S)\) be the least-preferred type in \(S\) under \(\succ_t\), and let \(q_{t,u}=p_{tu}\), \(q_{t,\bot}=s_t\). A support \(S\) blocks when every \(t\in S\) has positive mass \(A_{t,S}=\sum_{v:\,w_t(S)\succeq_t v}q_{t,v}\) of weakly improving participants and some \(t\in S\) has positive mass \(B_{t,S}=\sum_{v:\,w_t(S)\succ_t v}q_{t,v}\) of strict improvers; the question is whether a feasible matching avoiding every such support exists.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(m=|T|=\tau\) is the number of partner types, and \(L\) is the total input bit length; running times are measured in \(m,\tau,L\), not in the number of possible rankings.
Each type has a strict total ranking \(\succ_t\) of \(T\cup\{\bot\}\), where \(\bot\) means remaining alone; types ranked below \(\bot\) are unacceptable. Each type represents an atomless population.
A mass matching has real entries \(p_{tu}=p_{ut}\geq0\) and \(s_t\geq0\), satisfying \(s_t+\sum_{u\in T}p_{tu}=\mu_t\). The diagonal \(p_{tt}\) counts participating mass paired with distinct individuals of the same type, so the mass of such pairs is \(p_{tt}/2\). Set \(q_{t,u}=p_{tu}\) and \(q_{t,\bot}=s_t\).
Coalitions are evaluated by their least-preferred other member's type, with no size tie-break; remaining alone is evaluated as \(\bot\). For a coalition with positive mass of every type in a nonempty support \(S\subseteq T\), set \(w_t(S)=\min_{\succ_t}S\); even when \(t\in S\), other individuals of type \(t\) remain represented.
Define \(A_{t,S}=\sum_{v\in T\cup\{\bot\}:\,w_t(S)\succeq_t v}q_{t,v}\) and \(B_{t,S}=\sum_{v\in T\cup\{\bot\}:\,w_t(S)\succ_t v}q_{t,v}\). A support weakly blocks exactly when \(A_{t,S}>0\) for every \(t\in S\) and \(B_{t,S}>0\) for some \(t\in S\); participating masses may be arbitrarily small and need not be equal across types.
Deviations into singletons are also allowed: a matching is stable only if \(\sum_{u\in T:\,\bot\succ_t u}p_{tu}=0\) for every \(t\), and no support weakly blocks.

Is deciding whether a stable mass matching exists solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite individuals with strict rankings, strict-core existence under least-preferred-other-member evaluation is decidable in polynomial time by a modified stable-roommates algorithm; emptiness is characterized by an empty preference list arising during its second phase ([Cechlárová–Romero-Medina](https://doi.org/10.1007/s001820000053)).
Ordinally stable fractional roommate matchings always exist, but that notion excludes only pairs with positive strictly improving mass on both sides, rather than the weakly blocking coalitions defined here ([Chen–Roy–Sorge](https://www.ijcai.org/proceedings/2021/0013.pdf)). No result settling the exact mass problem above was identified.

Modeling choices made when packaging the task

  • Restored deviations into singletons, omitted from the graded support test, by requiring zero mass assigned below the singleton option.
  • Interpreted each positive-mass type as an atomless population: within-type pairing involves distinct individuals, and the diagonal records participating mass rather than pair mass.
  • Retained a participating individual's own type in a positive-mass coalition support because other individuals of that type remain after excluding that individual.
  • Allowed arbitrary positive participating masses without equal-mass requirements across coalition types, as in the graded blocking criterion.
  • Allowed real matching entries; only the input masses are required to be binary rationals.
  • Defined the otherwise absent parameter m as the number of partner types, equal to the support size in this model.

Conclusion

The problem is polynomial-time solvable: every instance admits a stable mass matching.

This follows from the explicit premise that \(w_t(S)\) includes type \(t\) whenever \(t\in S\). The simple self-pairing witness works for every input size. More generally, we can characterize all stable mass matchings.

1. Every blocking support yields a blocking one-type support

Fix a feasible mass matching. For every support \(S\) and every \(t\in S\), the definition of the least-preferred type gives
\(t\succeq_t w_t(S)\).

Consequently, if \(w_t(S)\succ_t v\), transitivity implies \(t\succ_t v\). Since all allocation entries are nonnegative, this proves
\(B_{t,S}\leq B_{t,\{t\}}\).

Suppose \(S\) weakly blocks. By definition, there is some \(t\in S\) with \(B_{t,S}>0\). Hence \(B_{t,\{t\}}>0\). Moreover,
\(A_{t,\{t\}}\geq B_{t,\{t\}}>0\),
so the support \(\{t\}\) weakly blocks.

Conversely, a blocking one-type support is itself a blocking support. Therefore:

Lemma. No support weakly blocks if and only if \(B_{t,\{t\}}=0\) for every \(t\in T\).

Here, the support \(\{t\}\) describes a coalition of positive mass consisting entirely of type \(t\). It is distinct from a deviation into remaining alone.

2. Exact characterization of stability

Define \(h_t\) to be the better of \(t\) and \(\bot\) under \(\succ_t\).

Proposition. A feasible mass matching is stable if and only if, for every \(t\in T\) and every \(v\in T\cup\{\bot\}\),
\(h_t\succ_t v\Longrightarrow q_{t,v}=0\).

Proof. First suppose the matching is stable. The lemma gives
\(B_{t,\{t\}}=\sum_{v:\,t\succ_t v}q_{t,v}=0\).
Nonnegativity therefore forces every allocation strictly below \(t\) to vanish.

The singleton-deviation condition likewise forces every allocation strictly below \(\bot\) to vanish: these outcomes are partner types, so their allocation entries are precisely the entries appearing in the stipulated condition.

An outcome lies strictly below \(h_t\) exactly when it lies strictly below at least one of \(t\) and \(\bot\). Thus every allocation below \(h_t\) vanishes.

For the converse, suppose every allocation below \(h_t\) vanishes. Since \(h_t\succeq_t\bot\), all allocations to unacceptable partner types vanish, satisfying the singleton-deviation condition. Since \(h_t\succeq_t t\), all allocations strictly below \(t\) vanish. Hence \(B_{t,\{t\}}=0\) for every type, and the lemma excludes every weakly blocking support. This proves stability. ∎

In particular, the stable matchings form the polytope given by the original feasibility constraints together with these coordinate-zero constraints.

3. Construction and running time

Set \(p_{tu}=0\) whenever \(t\ne u\). For each type \(t\), choose its allocation as follows:

  • If \(t\succ_t\bot\), set \(p_{tt}=\mu_t\) and \(s_t=0\).
  • If \(\bot\succ_t t\), set \(p_{tt}=0\) and \(s_t=\mu_t\).

Strictness of the ranking ensures that exactly one case applies.

The entries are nonnegative and symmetric, and each row satisfies
\(s_t+\sum_{u\in T}p_{tu}=\mu_t\).
The permitted diagonal convention makes the self-pairing allocation feasible in the atomless population.

Every type receives only \(h_t\), so the proposition proves that this matching is stable.

The construction requires only locating \(t\) and \(\bot\) in each ranking and copying the input masses. Reading the input and writing a dense matching takes \(O(L+m^2)\) bit operations under the explicit-list encoding. All nonzero output entries are input masses, so their encoding lengths introduce no growth.

4. Scope of the conclusion

The decisive premise is the stipulated inclusion of a type’s own type in \(w_t(S)\), including mixed supports. It makes any coalition’s strict improvement imply a strict improvement through a one-type support. Thus there is no remaining difficult existence case within the stated model.
