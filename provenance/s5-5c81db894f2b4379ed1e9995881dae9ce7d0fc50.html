The continuous mirror question, as graded

Given a finite type set \(T\) of complete participant types, rational masses \(\mu_t\), nonatomic valuation oracles \(v_t\), and one unit cake for each repeated local division, determine the minimum worst-case number of type-level marking/value queries needed to output connected pieces and an assignment that is exactly envy-free in every local division, and decide whether a finite guarantee exists; in particular, characterize \(T=\{A,B,C\}\) with \(\mu_A=\mu_B=\mu_C=1/3\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of its \(\tau\) positive-mass types, with binary rational masses \(\mu_t>0\) summing to \(1\); \(\tau\) is the support size, not the number of possible types. Let \(L\) be the binary input length and \(m\ge2\) the number of participants per local division. Each type has an unknown nonnegative nonatomic probability measure \(v_t\) on \([0,1]\), positive on every nondegenerate interval; all participants of that type share this measure.
A solution is a finite list of local divisions with positive rational weights \(p_d\) summing to \(1\). Division \(d\) has a type tuple \((t_{d,1},\ldots,t_{d,m})\), allowing repeated types, and partitions a fresh unit cake into \(m\) connected intervals, assigned bijectively to its participants. The protocol chooses the tuples and weights, subject to \(\sum_d p_d\lvert\{j:t_{d,j}=t\}\rvert=m\mu_t\) for every \(t\).
Writing \(I_{d,j}\) for participant \(j\)'s assigned interval, require \(v_{t_{d,j}}(I_{d,j})\ge v_{t_{d,j}}(I_{d,k})\) for every \(d,j,k\); ties are allowed, and the entire cake must be allocated in each division.
Initially \(0\) and \(1\) are marked. A marking query chooses \(t\) and \(\alpha\in[0,1]\), returning the unique \(x\) with \(v_t([0,x])=\alpha\); a value query chooses \(t\) and an existing mark \(x\), returning \(v_t([0,x])\). Each query costs one; answers are exact, queries are adaptive, information is shared across divisions, and every output cut must be an existing mark. Protocols are deterministic and access valuations only through these oracles.
Target. Does this mass-based problem admit a protocol terminating after finitely many queries on every admissible valuation profile, or is such a guarantee impossible? What is its minimum worst-case total query count as a function of \(m,\tau,L,\mu\), particularly for \(m=3\), \(T=\{A,B,C\}\), and \(\mu_A=\mu_B=\mu_C=1/3\)? State any running-time bounds in the same parameters, treating exact real oracle operations separately from binary computation.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem admits a deterministic, always-terminating protocol. Its exact minimum worst-case total query count is \(\tau(m-1)\), independently of the positive masses and their binary encoding length.

In particular, for \(m=3\), \(T=\{A,B,C\}\), and \(\mu_A=\mu_B=\mu_C=1/3\), the minimum is exactly \(6\) queries.

Homogeneous local groups make existence straightforward. The substantive point is that their query count remains optimal even when protocols may choose mixed groups adaptively and share information across every division.

Upper bound: \(\tau(m-1)\) queries

For each \(t\in T\), create one division \(d_t\) whose \(m\) participants all have type \(t\), and give this division weight \(p_{d_t}=\mu_t\).

Ask type \(t\) the \(m-1\) marking queries with targets \(k/m\), for \(k=1,\ldots,m-1\). Denote their answers by \(x_{t,k}\), and put \(x_{t,0}=0\) and \(x_{t,m}=1\).

Nonatomicity makes the cumulative distribution continuous, and positivity on every nondegenerate interval makes it strictly increasing. Consequently, the marks occur in increasing order, and each interval \([x_{t,k-1},x_{t,k}]\) has type-\(t\) value exactly \(1/m\). Assign these intervals bijectively to the participants. Every participant is indifferent among all pieces, so every division is envy-free.

The weights are positive rationals and sum to \(1\). For each type \(t\), its weighted number of appearances is \(m p_{d_t}=m\mu_t\), as required.

Thus the protocol uses exactly \(\tau(m-1)\) marking queries and no value queries.

Lower bound: every type needs \(m-1\) queries

Let \(P\) be any correct deterministic protocol that terminates on every admissible profile. Run it on the uniform profile, where \(v_t([a,b])=b-a\) for every type \(t\).

We prove that, on this single profile, \(P\) must address at least \(m-1\) queries to each type.

Every output division uses the same grid

In any output division, let the piece lengths be \(\ell_1,\ldots,\ell_m\). Every participant has uniform valuation. Envy-freeness therefore says that each participant’s assigned length is at least every other piece length.

Because every piece is assigned, all lengths must be equal. Their sum is \(1\), so each equals \(1/m\). Hence every division has precisely the interior cut set \(G=\{k/m:1\leq k\leq m-1\}\).

Moreover, each type appears in some output division: its required weighted number of appearances is \(m\mu_t>0\).

A query constrains one cumulative value of its addressed type

Fix a type \(t\). Let \(S_t\) contain \(0,1\) and:

  • every point returned by a marking query addressed to \(t\);
  • every point evaluated by a value query addressed to \(t\).

On the uniform profile, each such query specifies the cumulative value of type \(t\) at one point. In particular, a marking query with target \(\alpha\) returns \(x=\alpha\) and imposes the constraint \(v_t([0,x])=\alpha\).

Suppose \(P\) asks fewer than \(m-1\) queries to \(t\). Then some \(x_0=k/m\in G\) does not belong to \(S_t\). This remains possible even when \(x_0\) is an existing mark produced by another type.

Perturbing the unqueried boundary preserves the entire transcript

Since \(S_t\) is finite and excludes \(x_0\), choose \(\delta>0\) such that \(\delta<1/m\) and \([x_0-\delta,x_0+\delta]\) contains no point of \(S_t\).

Define \(h(x)=\max\{0,1-|x-x_0|/\delta\}\). Replace only type \(t\)’s cumulative distribution by \(F_t^*(x)=x+\varepsilon h(x)\), where \(0<|\varepsilon|<\delta\). Leave every other type uniform.

This defines an admissible measure. Indeed, \(F_t^*(0)=0\), \(F_t^*(1)=1\), and its piecewise constant density is \(1+\varepsilon/\delta\), \(1-\varepsilon/\delta\), or \(1\). All three are strictly positive. The resulting measure is therefore nonatomic and positive on every nondegenerate interval.

At every point of \(S_t\), the cumulative value remains unchanged. Thus every value-query answer remains unchanged. Every marking-query answer addressed to \(t\) also remains unchanged: its original answer still has the specified cumulative value, and strict monotonicity guarantees uniqueness.

Inductively, determinism implies that every subsequent query and answer is identical to the original run. The protocol consequently terminates with exactly the same output.

That output has envy

Write \(J_j=[(j-1)/m,j/m]\). The perturbation changes only two grid-piece values:

\(v_t^*(J_k)=1/m+\varepsilon\), and \(v_t^*(J_{k+1})=1/m-\varepsilon\).

Every other grid piece retains value \(1/m\).

Choose a participant of type \(t\) in any output division, and let its assigned piece be \(J_r\).

  • If \(r=k\), choose \(\varepsilon<0\). It strictly prefers \(J_{k+1}\).
  • If \(r=k+1\), choose \(\varepsilon>0\). It strictly prefers \(J_k\).
  • If \(r\notin\{k,k+1\}\), choose \(\varepsilon>0\). It strictly prefers \(J_k\).

In every case the unchanged output violates envy-freeness on an admissible profile with the same oracle transcript. This contradicts correctness.

Therefore every type receives at least \(m-1\) queries on the uniform profile. Summing over the \(\tau\) positive-mass types proves the lower bound \(\tau(m-1)\). Together with the construction, this establishes the exact optimum.

Why the fixed-group impossibility does not apply

[Stromquist’s theorem](https://www.cs.umd.edu/~gasarch/TOPICS/cake/lbenvyfree.pdf) concerns a fixed group of participants and rules out an always-terminating protocol for arbitrary valuations when there are at least three participants.

Here the protocol chooses the groups. The mass constraints allow it to place all copies of each type in a homogeneous division with weight \(\mu_t\). Such a division requires only that type’s equal-value quantiles. Thus the present finite protocol does not contradict the fixed-group theorem.

Running time and representation

The optimal construction uses \(\tau(m-1)\) oracle calls and produces \(\tau\) divisions containing \(\tau m\) participant entries in total.

Represent types by their indices in the input support and output cuts by references to existing marks. Then:

  • Exact real operations: \(\tau(m-1)\) marking calls, with returned marks stored as opaque handles. No comparisons or arithmetic on returned reals are needed.
  • Binary computation: \(O(L+\tau m\log(2+\tau m))\) bit operations suffice to read and copy the masses, generate the rational targets \(k/m\), and write the explicit tuples and mark references.

For the binary bound, rational targets may be represented directly by numerator and denominator without requiring reduction. The output weights are copied from the input, so their bit lengths do not increase.

These bounds are polynomial in \(m,\tau,L\). If \(m\) is encoded in binary, they need not be polynomial in \(L\) alone; the prescribed explicit output already lists \(m\) participants per division. Arbitrary oracle-returned real coordinates are handled separately from finite binary computation.
