The continuous mirror question, as graded

Given a finite binary attribute set \(V\) and finite-support rational distributions \(\mu,\nu\) over irreducible CP-theory preference sets on \(V\), compute the exact value \(D_d(\mu,\nu)=\sum_{A,B}\mu_A\nu_B d(A,B)\).

Packaged proof task (what the prover saw — nothing else)

Let \(V\) contain \(m\geq1\) binary attributes, with outcomes in \(\{0,1\}^{V}\). A type is an explicitly listed finite set of statements \(\rho:Z=z\succ Z=1-z\,[\Omega]\), where \(z\in\{0,1\}\), \(\rho\) assigns values to a set \(C\), and \(C,\Omega,\{Z\}\) are pairwise disjoint; empty conditions and importance sets are allowed.
Such a statement directly relates outcomes \(o,o'\) when \(o_Z=z\), \(o'_Z=1-z\), both satisfy \(\rho\), and they agree outside \(\Omega\cup\{Z\}\); values on \(\Omega\) are unrestricted. Write \(R_A\) for the union of these relations for type \(A\). Types are promised consistent, meaning \(R_A\) is acyclic, and irreducible: no sequence of deletions of statements, condition literals, or importance-set entries gives a different representation with the same \(R_A\).
Define \(S(A)\) as the set of tuples \((Z,z,\Gamma,\eta)\) obtained from statements in \(A\) by choosing every \(\Gamma\subseteq\Omega\) and every complete assignment \(\eta\) on \(V\setminus(\{Z\}\cup\Gamma)\) extending \(\rho\). Identical tuples are deduplicated. Set \(d(A,B)=\sum_{(Z,z,\Gamma,\eta)\in S(A)\triangle S(B)}2^{|\Gamma|}\); this definition uses normalized statements, without transitive closure.
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. The input consists of two such probability distributions \(\mu,\nu\), each with masses summing to \(1\), with support sizes \(\tau_\mu,\tau_\nu\). Let \(L\) be the total bit length of the compact statement lists and masses; normalized sets are not supplied.
Determine the exact rational value \(D_d(\mu,\nu)=\sum_{A\in\operatorname{supp}(\mu)}\sum_{B\in\operatorname{supp}(\nu)}\mu_A\nu_B d(A,B)\).

Is exact computation of \(D_d(\mu,\nu)\) polynomial-time in \(m,\tau_\mu,\tau_\nu,L\), or is it NP-hard under polynomial-time Turing reductions?

For individual types, the standard-normalization distance equals the context-uniform normalization formula, whose evaluation is polynomial in the expanded normalized representation; that representation can be exponentially larger than compact input. Result

Exact computation of \(D_d(\mu,\nu)\) is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions, even when \(\tau_\mu=\tau_\nu=1\), both masses equal \(1\), and every statement has an empty condition.

The proof uses the normalized-set definition in the question directly.

1. Encoding a graph by promised types

Let \(G=(U,E)\) be a finite simple undirected graph with \(n=|U|\geq 1\). Introduce one binary attribute for each vertex and one additional attribute \(Z\), so \(V=U\cup\{Z\}\).

For each edge \(e=\{u,v\}\), define \(\Omega_e=U\setminus e\). Construct the types

\[ A_G=\left\{\,Z=1\succ Z=0\,[\Omega_e]:e\in E\,\right\}, \qquad B_G=\left\{\,Z=1\succ Z=0\,[U]\,\right\}. \]

All conditions are empty. If \(E\) is empty, \(A_G\) is the empty type, which the stated definition permits. The lists have polynomial bit length: there are \(|E|+1\) statements, each listing at most \(n\) importance entries.

Consistency. Every related pair in either type has \(Z=1\) in its first outcome and \(Z=0\) in its second. Consequently, two relation edges cannot be composed, and both relations are acyclic.

Irreducibility of \(A_G\). Suppose \(E\neq\varnothing\). Fix \(e\in E\), and consider outcomes \(o,o'\) defined by

\[ o_Z=1,\qquad o'_Z=0,\qquad o_X=0,\qquad o'_X= \begin{cases} 1&\text{if }X\in\Omega_e,\\ 0&\text{if }X\notin\Omega_e. \end{cases} \]

The statement indexed by \(e\) relates this pair. A statement indexed by another edge \(f\) relates it precisely when \(\Omega_e\subseteq\Omega_f\): all attributes on which the outcomes differ, other than \(Z\), must belong to \(\Omega_f\).

Every importance set has cardinality \(n-2\). Thus \(\Omega_e\subseteq\Omega_f\) implies \(\Omega_e=\Omega_f\), hence \(e=f\). This pair is therefore supplied uniquely by the statement indexed by \(e\).

Deleting that statement, or deleting any entry from its importance set, removes this pair. There are no condition literals to delete. Every allowed deletion only shrinks the represented relation, so subsequent deletions cannot restore a lost pair. Hence no nonempty sequence of deletions preserves \(R_{A_G}\). The empty type is irreducible vacuously.

Irreducibility of \(B_G\). The analogous pair differing on every attribute of \(U\), as well as on \(Z\), is removed by deleting its sole statement or any importance entry. Again, later deletions cannot restore it.

Thus every constructed type satisfies both promises.

2. The distance counts independent sets

Write \(I(G)\) for the number of independent vertex subsets of \(G\), including the empty set. We prove

\[ d(A_G,B_G)=2^n I(G). \]

The normalized set \(S(B_G)\) consists of every tuple \((Z,1,\Gamma,\eta)\), where \(\Gamma\subseteq U\) and \(\eta\) is an arbitrary complete assignment on \(U\setminus\Gamma\).

For any such tuple, the empty conditions in \(A_G\) give

\[ \begin{aligned} (Z,1,\Gamma,\eta)\in S(A_G) &\iff \text{there exists }e\in E\text{ with }\Gamma\subseteq U\setminus e\\ &\iff \text{there exists }e\in E\text{ with }e\subseteq U\setminus\Gamma. \end{aligned} \]

Therefore, membership in \(S(A_G)\) is independent of \(\eta\). Also, \(S(A_G)\subseteq S(B_G)\), and a tuple belongs to \(S(B_G)\setminus S(A_G)\) precisely when \(U\setminus\Gamma\) is independent in \(G\).

For each fixed \(\Gamma\), there are \(2^{n-|\Gamma|}\) assignments \(\eta\). Each tuple has weight \(2^{|\Gamma|}\), so their total contribution, whenever \(U\setminus\Gamma\) is independent, is

\[ 2^{n-|\Gamma|}\,2^{|\Gamma|}=2^n. \]

Complementation is a bijection between such sets \(\Gamma\) and independent subsets of \(U\). Summing proves the identity. This argument counts deduplicated tuples: overlapping generating statements do not introduce multiplicities.

Now take the singleton distributions \(\mu=\delta_{A_G}\) and \(\nu=\delta_{B_G}\), each with mass \(1\). An exact expectation oracle yields

\[ I(G)=\frac{D_d(\delta_{A_G},\delta_{B_G})}{2^n}. \]

Hence independent-set counting reduces to the requested computation by one valid oracle query.

3. A polynomial-time Turing reduction from Independent Set

For completeness, we show directly why access to these counts decides an \(\mathrm{NP}\)-hard problem.

Let \(i_k(G)\) denote the number of independent subsets of \(G\) of cardinality \(k\), and define its independence polynomial

\[ P_G(x)=\sum_{k=0}^{n}i_k(G)x^k. \]

For a positive integer \(t\), construct a graph \(G^{(t)}\) as follows. Replace each vertex \(u\) by a clique \(K_u\) containing \(t\) vertices. For each original edge \(\{u,v\}\), add all edges between \(K_u\) and \(K_v\).

An independent set of \(G^{(t)}\) contains at most one vertex from each clique. The original vertices whose cliques it meets form an independent set of \(G\). Conversely, for each independent set of \(G\) of size \(k\), independently choosing one vertex from each corresponding clique gives exactly \(t^k\) independent sets of \(G^{(t)}\). Therefore,

\[ I(G^{(t)})=\sum_{k=0}^{n}i_k(G)t^k=P_G(t). \]

For each \(t\in\{1,\ldots,n+1\}\), apply the preceding construction to \(G^{(t)}\). It has \(nt\) vertices, and the exact oracle answer \(d_t\) satisfies

\[ P_G(t)=\frac{d_t}{2^{nt}}. \]

These \(n+1\) values determine the polynomial of degree at most \(n\). Explicitly,

\[ P_G(x)= \sum_{t=1}^{n+1} \frac{d_t}{2^{nt}} \prod_{\substack{1\leq s\leq n+1\\s\neq t}} \frac{x-s}{t-s}. \]

All oracle queries and subsequent computations have polynomial size:

  • Each queried graph has at most \(n(n+1)\) vertices, so its compact type lists have polynomial bit length.
  • Since \(I(G^{(t)})\leq 2^{nt}\), the oracle answer satisfies \(d_t\leq 2^{2nt}\), and thus has polynomial bit length.
  • Each interpolation denominator has absolute value \((t-1)!(n+1-t)!\). The numerator polynomials also have coefficients of polynomial bit length. Standard exact rational polynomial arithmetic therefore performs the interpolation in polynomial time.

After recovering the coefficients, an instance \((G,k)\) of Independent Set is answered affirmatively exactly when some coefficient \(i_j(G)\) with \(j\geq k\) is positive.

The required hardness of Independent Set follows from the usual reduction from \(\mathrm{3SAT}\). Given a formula with \(q\) nonempty clauses, create one vertex for every literal occurrence, connect all occurrences within each clause, and connect occurrences carrying complementary literals. An independent set has size at most \(q\). A satisfying assignment supplies an independent set of size \(q\) by selecting one true occurrence from every clause. Conversely, an independent set of size \(q\) selects one occurrence from every clause without selecting complementary literals; those selections extend to a satisfying assignment. The graph has polynomial size. Here we use the standard \(\mathrm{NP}\)-completeness of satisfiability with at most three literals per clause. [Karp, *Reducibility Among Combinatorial Problems*](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf)

Consequently, the interpolation procedure gives a polynomial-time Turing reduction from an \(\mathrm{NP}\)-hard decision problem to exact computation of \(D_d\).

4. Consequence for compact input

The hardness holds with singleton supports, so averaging over society types is already hard in this restricted case. A polynomial-time exact algorithm in \(m,\tau_\mu,\tau_\nu,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

This result is compatible with polynomial evaluation in an expanded normalized representation: the cited paper explicitly allows that representation to be exponentially larger than the compact input. [Qi, Rauer, and Basu, *Distance Between CP-theory Preferences*](https://www.ijcai.org/proceedings/2026/0446.pdf)
