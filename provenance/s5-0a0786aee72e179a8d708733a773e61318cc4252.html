The continuous mirror question, as graded

Given a network, a finite set of user types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), a nonnegative per-capita edge-capacity vector \(b\), and for each type \(t\) a finite set \(A_t\) of feasible integral packet-flow bundles including zero flow, with capped utility \(U_t\), determine whether \(b\) is weakly enforceable by common nonnegative edge prices. Equivalently, find \(\lambda\ge 0\) and masses \(z_{ta}\ge 0\) such that \(\sum_{a\in A_t}z_{ta}=\mu_t\), \(y=\sum_{t\in T}\sum_{a\in A_t}z_{ta}a\le b\), \(\lambda_e(b_e-y_e)=0\) for each edge \(e\), and \(z_{ta}>0\) only when \(a\in\arg\max_{a'\in A_t}\{U_t(\operatorname{val}(a'))-\lambda^{\top}a'\}\).

Packaged proof task (what the prover saw — nothing else)

Given a directed network \(G=(V,E)\) with \(m=|E|\geq1\), let \(b\in\mathbb Q_{\geq0}^{m}\) be per-capita edge capacities.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has distinct terminals \(s_t,r_t\), an explicitly listed finite set \(A_t\subseteq\mathbb Z_{\geq0}^{m}\) containing zero, and utility \(U_t(q)=\alpha_t\min\{q,d_t\}\), where \(\alpha_t\in\mathbb Q_{\geq0}\) and \(d_t\in\mathbb Q_{>0}\).
Every listed bundle satisfies flow conservation outside its terminals and has nonnegative value \(\operatorname{val}_t(a)=\sum_{e\in\delta^+(s_t)}a_e-\sum_{e\in\delta^-(s_t)}a_e\). Bundles are individual packet flows; capacity constraints apply to aggregate mass consumption.
Call \(b\) weakly enforceable if there exist common prices \(\lambda\in\mathbb R_{\geq0}^{m}\) and allocations \(z_{ta}\in\mathbb R_{\geq0}\) satisfying \(\sum_{a\in A_t}z_{ta}=\mu_t\), \(y=\sum_t\sum_{a\in A_t}z_{ta}a\leq b\), and \(\lambda_e(b_e-y_e)=0\) for every edge.
Require also \(z_{ta}>0\Rightarrow a\in\arg\max_{a'\in A_t}\{U_t(\operatorname{val}_t(a'))-\lambda^{\top}a'\}\); mass may split freely among tied maximizers.
Let \(K=\sum_t|A_t|\) and let \(L\) be the total binary input length. State running times in \(m,\tau,|V|,K,L\).

Is deciding whether \(b\) is weakly enforceable solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For discrete users, welfare maximization is \(\mathrm{NP}\)-hard even with two terminal pairs and identical capped linear utilities; the resulting anchor establishes conditional failure of universal weak enforceability, rather than hardness of deciding enforceability. [Harks](https://arxiv.org/abs/1907.01976v3).
For unrestricted fractional edge flows with concave bandwidth utilities, every nonnegative capacity vector is weakly enforceable; this allows fractional individual flows rather than mass allocations over specified integral bundles. [Harks–Schwarz](https://www.fim.uni-passau.de/fileadmin/dokumente/fakultaeten/fim/lehrstuhl/harks/21m1400924.pdf).

  • Specify capped utility as nondecreasing capped linear utility with binary rational nonnegative slope and positive cap, allowing type-specific parameters as in the graded question.
  • Specify a directed network, distinct terminals, conservation outside the terminals, and nonnegative net flow value.

Result

The problem is polynomial-time solvable. In fact, every valid instance is weakly enforceable. This follows from linear programming duality: freely splitting type masses makes welfare linear in the allocation variables, even though every individual bundle remains integral.

The proof below also gives a polynomial-time algorithm for constructing allocations and common prices.

1. The welfare linear program

For each listed bundle, define its rational utility coefficient
\(u_{ta}:=\alpha_t\min\{\operatorname{val}_t(a),d_t\}\).

Consider the linear program

\( \displaystyle \text{maximize }\sum_t\sum_{a\in A_t}u_{ta}z_{ta} \)

subject to

\( \displaystyle \sum_{a\in A_t}z_{ta}=\mu_t\quad\text{for every }t, \qquad \sum_t\sum_{a\in A_t}a_ez_{ta}\leq b_e\quad\text{for every }e, \qquad z_{ta}\geq0. \)

This objective is the total utility of the allocated mass: mass \(z_{ta}\) receives bundle \(a\), whose utility is the fixed number \(u_{ta}\).

The program is feasible because \(0\in A_t\) for every type: assign \(z_{t0}=\mu_t\) and all other allocation variables zero. Its aggregate consumption is zero, which respects \(b\geq0\).

Furthermore, every feasible allocation satisfies \(0\leq z_{ta}\leq\mu_t\). Thus the feasible set is a nonempty compact polytope, and the linear objective attains a finite maximum.

2. The dual and existence of optimal prices

Associate a nonnegative variable \(\lambda_e\) with each capacity inequality and a free variable \(\eta_t\) with each mass equality. The dual is

\( \displaystyle \text{minimize }\lambda^\top b+\sum_t\mu_t\eta_t \)

subject to

\( \displaystyle \eta_t+\lambda^\top a\geq u_{ta} \quad\text{for every }t,\ a\in A_t, \qquad \lambda\geq0, \qquad \eta\in\mathbb R^\tau. \)

To check the signs and constraints, the primal Lagrangian is

\( \displaystyle \lambda^\top b+\sum_t\mu_t\eta_t+ \sum_t\sum_{a\in A_t} z_{ta}\bigl(u_{ta}-\lambda^\top a-\eta_t\bigr). \)

Its supremum over \(z\geq0\) is finite exactly when every coefficient in parentheses is nonpositive, giving the displayed dual.

The dual is feasible: take \(\lambda=0\) and \(\eta_t=\max_{a\in A_t}u_{ta}\). By finite-dimensional linear programming strong duality, a feasible primal with finite optimal value has an attained dual optimum of the same value. All hypotheses have been verified here. Consequently, there exist optimal solutions \(z^*\) and \((\lambda^*,\eta^*)\) with equal objective values.

This application requires no strict feasibility assumption, so it also covers capacities with zero coordinates.

3. Optimal solutions satisfy every enforceability condition

Write

\( \displaystyle y^*:=\sum_t\sum_{a\in A_t}z^*_{ta}a. \)

Using the mass equalities, the primal-dual objective gap can be written exactly as

\( \displaystyle \lambda^{*\top}b+\sum_t\mu_t\eta_t^* -\sum_t\sum_{a\in A_t}u_{ta}z^*_{ta} = \sum_e\lambda_e^*(b_e-y_e^*) + \sum_t\sum_{a\in A_t} z^*_{ta}\bigl(\eta_t^*+\lambda^{*\top}a-u_{ta}\bigr). \)

Every summand on the right is nonnegative by primal and dual feasibility. The gap is zero by optimality, so every summand is zero. In particular,

\( \lambda_e^*(b_e-y_e^*)=0 \quad\text{for every }e. \)

Also, if \(z^*_{ta}>0\), then

\( u_{ta}-\lambda^{*\top}a=\eta_t^*. \)

For every alternative \(a'\in A_t\), dual feasibility gives

\( u_{ta'}-\lambda^{*\top}a'\leq\eta_t^*. \)

Therefore every positively allocated bundle maximizes the type’s utility minus its payment:

\( \displaystyle z^*_{ta}>0 \ \Longrightarrow\ a\in\arg\max_{a'\in A_t} \{U_t(\operatorname{val}_t(a'))-\lambda^{*\top}a'\}. \)

Primal feasibility supplies the remaining mass and capacity conditions. Hence \((z^*,\lambda^*)\) witnesses weak enforceability.

4. Running time

The primal has \(K\) variables, \(m\) capacity inequalities, and \(\tau\) mass equalities, besides nonnegativity constraints. The dual has \(m+\tau\) variables and \(K\) bundle inequalities.

Computing the bundle values and utility coefficients uses \(O(mK)\) arithmetic operations after reading the network. Their binary encoding lengths are polynomial in \(L+\log(m+1)\): they require only sums of listed integers, rational comparisons, and rational products.

Standard exact algorithms for rational linear programming therefore construct rational optimal allocations and prices, of polynomial binary length, in

\( (m+\tau+|V|+K+L)^{O(1)} \)

bit operations. Only the listed support types and bundles are involved.

For decision alone, every promised valid instance can immediately be answered “yes”: \(O(1)\) time without reading the input, or \(O(L)\) time if the entire encoding is read.

5. Why the discrete hardness anchor does not apply

The distinction is unrestricted splitting of each type’s mass. Here the feasible allocation set is already the linear-programming model, and duality directly supplies prices supporting its optimum. The integrality of each listed bundle imposes no integrality restriction on \(z_{ta}\). This is consistent with the duality and convexification framework in [Harks](https://arxiv.org/abs/1907.01976v3).

For indivisible users, selecting one bundle per user instead introduces discrete constraints; the preceding proof no longer applies. The conditional failure of universal enforceability in that setting is discussed in Proposition 7.9 of [Harks–Schwarz](https://www.fim.uni-passau.de/fileadmin/dokumente/fakultaeten/fim/lehrstuhl/harks/21m1400924.pdf). Our argument establishes universal weak enforceability directly for the specified mass-allocation model.
