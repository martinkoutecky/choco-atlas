The anchor (named result in the paper)

Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given a finite school set \(S\), rational mass capacities \(q_s\), a finite set of preference types \(T\), and rational masses \(\mu_t\) summing to \(1\), where each type ranks \(S\cup\{\emptyset\}\), find \(x_{t,s}\ge 0\) respecting acceptability, \(\sum_s x_{t,s}\le \mu_t\), and \(\sum_t x_{t,s}\le q_s\), maximizing \(M(x)=\sum_{t,s}x_{t,s}\); among maximizers, return one with no feasible positive-mass reassignment that weakly improves every unit and strictly improves a positive mass.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. There are \(m=|S|\) schools with nonnegative binary-rational capacities \(q_s\); each type has a strict ranking \(\succ_t\) of \(A=S\cup\{\emptyset\}\), where \(\emptyset\) means unassigned. Let \(L\) be the total input bit length.
An allocation is a nonnegative matrix \(x\) satisfying \(x_{t,s}=0\) unless \(s\succ_t\emptyset\), \(\sum_{s\in S}x_{t,s}\leq\mu_t\), and \(\sum_{t\in T}x_{t,s}\leq q_s\). Set \(x_{t,\emptyset}=\mu_t-\sum_{s\in S}x_{t,s}\) and \(M(x)=\sum_{t\in T,s\in S}x_{t,s}\).
A Pareto improvement of \(x\) is a feasible allocation \(y\) together with nonnegative transferred masses \(z_{t,a,b}\), for \(a,b\in A\), satisfying \(\sum_b z_{t,a,b}=x_{t,a}\), \(\sum_a z_{t,a,b}=y_{t,b}\), and \(z_{t,a,b}=0\) unless \(b=a\) or \(b\succ_t a\), with \(\sum_{t,a,b:\,b\succ_t a}z_{t,a,b}>0\). Transfers may split mass and may involve unassigned units. An allocation is Pareto efficient if it admits no such improvement.
The computational problem is to return a rational allocation maximizing \(M(x)\) that is Pareto efficient among all feasible allocations.

Is this continuous allocation problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

Discrete: efficient assignment-maximizing mechanisms return maximum-cardinality individually rational, Pareto-efficient matchings ([Afacan–Bó–Turhan](https://arxiv.org/pdf/2012.01011)); maximum-cardinality Pareto-efficient house allocation also has a polynomial-time algorithm ([Abraham et al.](https://www.cs.cmu.edu/~dabraham/papers/acmm04.pdf)).

Result

The problem is solvable in polynomial time in \(m,\tau,L\). In fact, a Pareto-efficient allocation attains the maximum assigned mass achievable by any feasible allocation.

The algorithm uses two rational linear programs: first maximize assigned mass, then maximize a strictly preference-increasing linear score on the face of mass maximizers.

1. Pareto improvements cannot decrease assigned mass

Let \(x\) be feasible, and let \(y,z\) satisfy the transfer conditions for a Pareto improvement.

If \(s\in S\) is unacceptable to type \(t\), then \(x_{t,s}=0\). Nonnegativity and the row-sum condition therefore imply \(z_{t,s,b}=0\) for every \(b\in A\).

If \(s\) is acceptable, then \(s\succ_t\emptyset\), so a transfer from \(s\) to \(\emptyset\) is forbidden. Consequently,

\(\displaystyle z_{t,s,\emptyset}=0\qquad(t\in T,\ s\in S).\)

Using the transfer marginals and separating transfers according to whether their source and destination are schools gives

\(\displaystyle M(y)-M(x)=\sum_{t\in T,\ s\in S}z_{t,\emptyset,s}-\sum_{t\in T,\ s\in S}z_{t,s,\emptyset}=\sum_{t\in T,\ s\in S}z_{t,\emptyset,s}\geq 0.\)

Thus every Pareto improvement weakly increases assigned mass. In particular, any Pareto improvement of a maximum-mass allocation must itself have maximum mass.

2. A linear score strictly increases under every Pareto improvement

For each type \(t\), let \(r_t(a)\in\{1,\ldots,m+1\}\) denote the position of \(a\) in its ranking, with position \(1\) best. Define

\(\displaystyle u_t(a)=r_t(\emptyset)-r_t(a).\)

Then \(u_t(\emptyset)=0\), and \(b\succ_t a\) implies \(u_t(b)-u_t(a)\geq 1\).

For a feasible allocation, define

\(\displaystyle U(x)=\sum_{t\in T,\ a\in A}u_t(a)x_{t,a}=\sum_{t\in T,\ s\in S}u_t(s)x_{t,s}.\)

These scores are auxiliary coefficients constructed from the rankings; no cardinal-utility assumption is needed.

For any Pareto improvement \(y,z\), the marginal conditions yield

\(\displaystyle U(y)-U(x)=\sum_{t\in T,\ a,b\in A}z_{t,a,b}\bigl(u_t(b)-u_t(a)\bigr).\)

Every summand with positive transferred mass is nonnegative. Every strict transfer has score difference at least \(1\). Therefore,

\(\displaystyle U(y)-U(x)\geq\sum_{t,a,b:\,b\succ_t a}z_{t,a,b}>0.\)

This argument allows arbitrary splitting of mass and includes transfers from the unassigned option.

3. Algorithm and correctness

Let \(E=\{(t,s)\in T\times S:s\succ_t\emptyset\}\). Use variables \(x_{t,s}\) only for pairs in \(E\), and set all other school entries to zero.

Let \(P\) be the polytope defined by

\(\displaystyle x_{t,s}\geq 0,\qquad \sum_{s:(t,s)\in E}x_{t,s}\leq\mu_t,\qquad \sum_{t:(t,s)\in E}x_{t,s}\leq q_s.\)

It is nonempty because the zero allocation is feasible. It is bounded because every variable satisfies \(x_{t,s}\leq\mu_t\).

Perform the following optimizations:

  • Compute \(\displaystyle M^\star=\max_{x\in P}M(x)\).
  • Return a rational optimizer \(x^\star\) of \(\displaystyle \max\{U(x):x\in P,\ M(x)=M^\star\}\).

Both maxima exist: the first feasible set is compact, and the second is a nonempty closed subset of it.

To prove global Pareto efficiency, suppose \(y,z\) were a Pareto improvement of \(x^\star\). Section 1 implies \(M(y)\geq M^\star\). Since \(y\in P\), the definition of \(M^\star\) also implies \(M(y)\leq M^\star\). Hence \(M(y)=M^\star\), so \(y\) is feasible for the second optimization.

But Section 2 implies \(U(y)>U(x^\star)\), contradicting optimality in that optimization. Therefore \(x^\star\) is Pareto efficient among all feasible allocations.

Since \(M(x^\star)=M^\star\), it also maximizes assigned mass among Pareto-efficient allocations.

4. Encoding and running time

The first linear program has at most \(\tau m\) variables and \(\tau+m\) row and capacity inequalities, in addition to nonnegativity. Its coefficients are integers of constant bit length, and its right-hand sides are input rationals.

Exact rational linear programming is polynomial-time solvable in the encoded program size and returns an optimal rational solution of polynomial bit length. The hypotheses apply here because the program is rational, nonempty, and bounded. Consequently, \(M^\star\) can be computed exactly and has polynomial bit length.

The second program adds one equality with right-hand side \(M^\star\). Its objective coefficients \(u_t(s)\) on acceptable pairs are integers between \(1\) and \(m\), requiring \(O(\log(m+1))\) bits each. It is again rational, nonempty, bounded, and of polynomial encoded size. Its rational optimizer therefore has polynomial output length and can be computed in polynomial time.

Finally, compute \(x^\star_{t,\emptyset}=\mu_t-\sum_s x^\star_{t,s}\). This requires only polynomial-time rational arithmetic.

The construction operates directly on the \(\tau\) listed types; it does not expand rational masses into individual agents.
