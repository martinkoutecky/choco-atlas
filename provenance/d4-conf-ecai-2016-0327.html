The continuous mirror question, as graded

Given a finite set of consistent clause sets \(\Phi_t\), each with positive binary-rational mass \(\mu_t\) and \(\sum_t \mu_t=1\), compute a set of clauses \(\Gamma\subseteq\bigcup_t\Phi_t\) maximizing \(\sum_{\delta\in\Gamma}\sum_{t:\delta\in\Phi_t}\mu_t\), subject to \(\Gamma\cup\Phi_t\) being satisfiable for every type \(t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq 1\) distinct types, each an explicitly listed finite satisfiable set \(\Phi_t\) of Boolean clauses, with positive binary-rational mass \(\mu_t\) and \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Logically equivalent clauses are identified; clause sets have no multiplicities. Put \(U=\bigcup_{t=1}^{\tau}\Phi_t\), \(m=|U|\), and let \(L\) be the total input bit length, including clauses and masses.
A consensus is a set \(\Gamma\subseteq U\) such that \(\Gamma\cup\Phi_t\) is satisfiable for every \(t\); the satisfying assignment may differ between types. Empty clause sets and the empty consensus are allowed.
Compute any consensus maximizing \(W(\Gamma)=\sum_{\delta\in\Gamma}\sum_{t:\delta\in\Phi_t}\mu_t\). State running times in \(m\), \(\tau\), and \(L\).

Is computing an optimal consensus for this mass-weighted problem possible in polynomial time, or is it \(\mathrm{NP}\)-hard?

For finite agent profiles, a maximum-cardinality consensus can be computed using one call to Partial Max-SAT on a polynomial-size instance ([source](https://doi.org/10.3233/978-1-61499-672-9-795)).
Discrete consensus extraction also has Weighted Partial Max-SAT formulations for several preference criteria ([source](https://www.ijcai.org/Proceedings/16/Papers/159.pdf)); these are not a complexity classification of the stated mass-weighted problem. No classification of this exact continuous formulation was located.

Modeling choices made when packaging the task

  • Specified Boolean clauses and ordinary propositional satisfiability, as required by the anchor's domain.
  • Identified logically equivalent clauses and excluded multiplicities within clause sets, following the discrete convention.
  • Allowed empty type clause sets and the empty consensus, since the discrete definition permits them.
  • Made explicit that each type's compatibility test may use a different satisfying assignment.
  • Defined m as the number of distinct available clauses and L as the total explicit input bit length; any maximizing consensus may be returned.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

Computing an optimal consensus is \(\mathrm{NP}\)-hard, even when \(\tau=2\), both masses equal \(\frac12\), and every clause has at most two literals. The associated threshold decision problem is \(\mathrm{NP}\)-complete. Thus a polynomial-time algorithm exists only if \(\mathrm{P}=\mathrm{NP}\).

For \(\tau=1\), the unique optimum is \(U=\Phi_1\), which can be returned in \(O(L)\) time. The hardness begins already at support size two.

1. A reduction from Independent Set

We use the classical \(\mathrm{NP}\)-completeness of Independent Set. This also follows from the \(\mathrm{NP}\)-completeness of Vertex Cover: a vertex set \(I\) is independent exactly when its complement is a vertex cover. See [Karp’s original NP-completeness results](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

Let \(G=(V,E)\) be an explicitly represented finite simple graph with \(n=|V|\geq1\). Introduce one Boolean variable \(x_v\) for each vertex \(v\). Construct two types:

\(\displaystyle \Phi_1=\{x_v:v\in V\},\qquad \Phi_2=\{\neg x_u\lor\neg x_v:\{u,v\}\in E\},\qquad \mu_1=\mu_2=\frac12.\)

This is a valid society:

  • \(\Phi_1\) is satisfied by assigning every variable true.
  • \(\Phi_2\) is satisfied by assigning every variable false.
  • The two types are distinct because \(\Phi_1\) is nonempty and contains positive unit clauses, whereas \(\Phi_2\) contains only negative clauses of length two.
  • Since the graph is simple, the edge clauses are pairwise logically distinct. None is logically equivalent to a positive unit clause.

Consequently, \(m=n+|E|\). Using vertex labels of \(O(\log(n+1))\) bits, the construction has output length \(O((n+|E|)\log(n+1))\) and takes polynomial time.

Feasible consensuses correspond exactly to independent sets

First, no consensus can contain an edge clause \(\neg x_u\lor\neg x_v\). Indeed, \(\Phi_1\) forces both \(x_u\) and \(x_v\) true, so adding that clause makes the union unsatisfiable.

Every consensus therefore has the form

\(\displaystyle \Gamma_I=\{x_v:v\in I\}\)

for some \(I\subseteq V\).

If \(I\) contains both endpoints of an edge \(\{u,v\}\), then \(\Gamma_I\cup\Phi_2\) contains \(x_u\), \(x_v\), and \(\neg x_u\lor\neg x_v\). Hence it is unsatisfiable.

Conversely, suppose \(I\) is independent. Assign \(x_v\) true exactly for vertices in \(I\). Every unit in \(\Gamma_I\) is satisfied, and every edge clause in \(\Phi_2\) is satisfied because no edge has both endpoints in \(I\). Thus \(\Gamma_I\cup\Phi_2\) is satisfiable. Also, the all-true assignment satisfies \(\Gamma_I\cup\Phi_1\).

We have proved

\(\displaystyle \Gamma_I\text{ is a consensus}\quad\Longleftrightarrow\quad I\text{ is independent in }G.\)

The objective preserves the optimization problem

Each positive unit clause belongs only to \(\Phi_1\), so its weight is \(\frac12\). Therefore

\(\displaystyle W(\Gamma_I)=\frac{|I|}{2},\qquad \max_{\Gamma\text{ consensus}}W(\Gamma)=\frac{\alpha(G)}2,\)

where \(\alpha(G)\) is the maximum independent-set size.

Any optimal consensus consequently gives a maximum independent set by reading its selected unit clauses. Likewise, \(G\) has an independent set of size at least \(k\) exactly when the constructed society has a consensus of weight at least \(\frac{k}{2}\).

This proves the claimed hardness. In particular, bounding \(\tau\) alone cannot yield a polynomial-time algorithm unless \(\mathrm{P}=\mathrm{NP}\).

2. The threshold decision problem is in NP

Consider the decision problem asking whether some consensus has weight at least a supplied binary-rational threshold \(B\).

Let \(n\) denote the number of variables occurring in the input; then \(n\leq L\). A certificate consists of a subset \(\Gamma\subseteq U\) and, for each type \(t\), an assignment satisfying \(\Gamma\cup\Phi_t\). Its length is \(O(m+\tau n)\), polynomial in the input length. Evaluating all these clause sets takes polynomial time.

Exact weight comparisons also take polynomial time. Write the input masses as \(\mu_t=p_t/q_t\), and define

\(\displaystyle Q=\prod_{t=1}^{\tau}q_t,\qquad a_t=p_t\frac{Q}{q_t},\qquad b_\delta=\sum_{t:\delta\in\Phi_t}a_t.\)

The bit length of \(Q\) is \(O(L)\), because the denominator encodings are included in \(L\). Since the masses sum to one,

\(\displaystyle \sum_t a_t=Q,\qquad 1\leq b_\delta\leq Q,\qquad W(\Gamma)=\frac{\sum_{\delta\in\Gamma}b_\delta}{Q}.\)

The score numerator has \(O(L+\log(m+1))\) bits. Comparing it with \(B\) by cross multiplication therefore takes polynomial time in \(L\) and the encoding length of \(B\).

Together with the reduction above, this establishes \(\mathrm{NP}\)-completeness of the threshold problem, already on the stated two-type restriction.

3. One polynomial-size Weighted Partial Max-SAT instance

The binary masses permit a direct formulation without expanding a type into agents.

Introduce a selector \(s_\delta\) for each \(\delta\in U\). For every type \(t\), make a separate copy of the original variables. Write \(\delta^{(t)}\) for the corresponding renamed clause.

Use the following hard clauses:

\(\displaystyle \{\delta^{(t)}:\delta\in\Phi_t,\ 1\leq t\leq\tau\} \;\cup\; \{\neg s_\delta\lor\delta^{(t)}:\delta\in U,\ 1\leq t\leq\tau\}. \)

For each \(\delta\in U\), add the soft unit clause \(s_\delta\) with integer weight \(b_\delta\) defined above.

For a chosen selector set \(\Gamma=\{\delta:s_\delta\text{ is true}\}\), the hard clauses require the variables in copy \(t\) to satisfy precisely \(\Phi_t\) together with every selected clause. Because the variable copies are disjoint, the hard clauses admit such assignments exactly when \(\Gamma\) is a consensus. Their soft score is \(QW(\Gamma)\). Hence an optimal Max-SAT assignment yields an optimal consensus.

There are at most \(2\tau m\) hard clauses, \(m\) soft clauses, and \(m+\tau n\) variables. The hard-clause literal count is \(O(\tau L)\); the soft weights use \(O(mL)\) bits. With binary variable identifiers, the complete encoding has size

\(\displaystyle N=O\!\left(\tau L\log(2+\tau L)+mL\right).\)

Construction takes \(\operatorname{poly}(m,\tau,L)\) time, followed by one Weighted Partial Max-SAT call and \(O(m)\) extraction time. This polynomial-size formulation is consistent with the hardness result; it does not make the optimization polynomial-time solvable.

4. An exact algorithm exponential in the number of clauses

An unconditional running-time bound is

\(\displaystyle O\!\left(2^m(\tau+1)L^3\right).\)

Here is a construction establishing that bound, including when clauses contain many variables.

Represent subsets of \(U\) by \(m\)-bit masks. Enumerate the variables as \(x_1,\ldots,x_n\). Let \(P_i\) be the clauses containing \(x_i\), and \(N_i\) the clauses containing \(\neg x_i\). Define

\(\displaystyle R_0=\{\varnothing\},\qquad R_i=\{M\cup P_i:M\in R_{i-1}\}\cup \{M\cup N_i:M\in R_{i-1}\}. \)

By induction, \(R_i\) consists exactly of the sets of clauses having a true literal among the first \(i\) assigned variables. Thus \(R_n\) consists exactly of the clause-satisfaction masks attainable by full assignments. Each table has at most \(2^m\) entries.

For each type \(t\), initialize a Boolean table

\(\displaystyle f_t(M)=1\quad\Longleftrightarrow\quad M\in R_n\text{ and }\Phi_t\subseteq M.\)

Compute its downward closure,

\(\displaystyle F_t(S)=\bigvee_{M\supseteq S}f_t(M).\)

This takes \(O(m2^m)\) table updates: for each clause position \(j\), and every mask \(S\) omitting \(j\), replace the entry at \(S\) by its disjunction with the entry at \(S\cup\{j\}\). Induction over the processed positions proves the displayed closure formula.

Now \(F_t(S)=1\) exactly when some assignment satisfies both \(S\) and \(\Phi_t\). Therefore \(S\) is a consensus exactly when every \(F_t(S)\) equals one. Scan these masks and return one maximizing \(\sum_{\delta\in S}b_\delta\).

The mask construction, closures, and exact score comparisons obey the stated conservative bit-operation bound, using \(m,n\leq L\). Thus the problem is tractable for bounded \(m\), while remaining \(\mathrm{NP}\)-hard for fixed \(\tau=2\).
