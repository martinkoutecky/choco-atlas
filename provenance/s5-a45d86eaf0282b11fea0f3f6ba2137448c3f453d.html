The continuous mirror question, as graded

Given a finite type set \(T\), distribution \(\mu\), path length \(m\), binary valuations \(v_t:[m]\to\{0,1\}\), rational \(0\le\beta\le1\), and type-level \((4,3)\)-sparsity, decide whether there are nonnegative interval-assignment masses \(\lambda_{t,I}\) satisfying \(\sum_I\lambda_{t,I}=\mu_t\), \(\sum_{t,I:j\in I}\lambda_{t,I}=\beta\) for every \(j\in[m]\), and \(\sum_{t,I}\lambda_{t,I}\sum_{j\in I}v_t(j)=m\beta\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). The parameter \(\tau\) is the support size, not the number of possible types.
The input also contains a positive integer \(m\), explicit binary additive valuations \(v_t:[m]\to\{0,1\}\), and a binary rational \(\beta\in[0,1]\). Items occupy the path positions \([m]\). Each type values at most four items, and each item is valued by at least one and at most three support types.
Let \(\mathcal I=\{\varnothing\}\cup\{\{a,a+1,\ldots,b\}:1\le a\le b\le m\}\). A mass \(\lambda_{t,I}\) represents members of type \(t\) receiving the single interval \(I\); type mass may split among intervals, and no order of types is prescribed.
Feasibility means the existence of real masses \(\lambda_{t,I}\ge0\) satisfying \(\sum_{I\in\mathcal I}\lambda_{t,I}=\mu_t\) for every \(t\), \(\sum_{t\in T}\sum_{I\in\mathcal I:j\in I}\lambda_{t,I}=\beta\) for every \(j\in[m]\), and \(\sum_{t\in T}\sum_{I\in\mathcal I}\lambda_{t,I}\sum_{j\in I}v_t(j)=m\beta\). These mass constraints define feasibility without any additional joint allocation requirement.
Is this feasibility problem solvable in polynomial time, or is it NP-hard? State running times in \(m\), \(\tau\), and the total input bit length \(L\), including the encoding of \(\beta\).
For finite agents with binary additive valuations, deciding whether a partition into single intervals assigns every item to an agent who values it is NP-complete even under \((4,3)\)-sparsity, with empty bundles allowed ([source](https://arxiv.org/html/2401.04318v2)). No result settling the exact mass formulation above was located in the literature search.

  • Normalized the distribution to total mass one and retained only positive-mass support types.
  • Included the empty interval because the discrete allocation model permits agents to receive no items.
  • Interpreted type-level (4,3)-sparsity as at most four positively valued items per type and at most three positively valuing support types per item.
  • Carried over the assumption that every item is positively valued by some type, and required positive path length and nonempty support.

Result

The stated feasibility problem is solvable in polynomial time. Its running time is \((m+\tau+L)^{O(1)}\) bit operations, including the encoding length of \(\beta\). Under the given sparsity assumptions, this is also \((\tau+L)^{O(1)}\).

We use exactly the specified mass constraints, including permission to split type mass and the absence of any additional joint allocation requirement.

1. The welfare equality excludes unvalued items

For any masses satisfying the item constraints, summing those constraints gives

\(\displaystyle \sum_{t\in T}\sum_{I\in\mathcal I}\lambda_{t,I}|I|=m\beta.\)

Subtracting the required welfare equality yields

\(\displaystyle \sum_{t\in T}\sum_{I\in\mathcal I}\lambda_{t,I}\left(|I|-\sum_{j\in I}v_t(j)\right)=0.\)

Because valuations are binary,

\(\displaystyle |I|-\sum_{j\in I}v_t(j)=\sum_{j\in I}(1-v_t(j))\ge 0.\)

Every summand is therefore nonnegative. Consequently, if \(\lambda_{t,I}>0\), every item of \(I\) must be valued by type \(t\).

Define the admissible nonempty intervals of type \(t\) by

\(\displaystyle \mathcal G_t=\{I\in\mathcal I\setminus\{\varnothing\}:v_t(j)=1\text{ for every }j\in I\}.\)

Thus every feasible solution uses only intervals in \(\mathcal G_t\) and the empty interval.

2. At most ten nonempty intervals per type

Let the maximal consecutive runs of items valued by type \(t\) have lengths \(r_1,\ldots,r_k\). An admissible interval is precisely a nonempty subinterval of one such run. Hence

\(\displaystyle |\mathcal G_t|=\sum_{i=1}^{k}\frac{r_i(r_i+1)}2.\)

The type sparsity assumption gives \(\sum_i r_i\le 4\). For nonnegative integers \(a,b\),

\(\displaystyle \frac{(a+b)(a+b+1)}2-\frac{a(a+1)}2-\frac{b(b+1)}2=ab\ge 0.\)

Repeatedly applying this inequality shows that

\(\displaystyle |\mathcal G_t|\le \frac{4\cdot5}{2}=10.\)

This also covers types valuing no items, for which \(\mathcal G_t\) is empty.

3. An equivalent rational linear program

Introduce a nonnegative variable \(x_{t,I}\) for each \(I\in\mathcal G_t\), and a nonnegative auxiliary variable \(z\). Consider these constraints:

\(\displaystyle \sum_{I\in\mathcal G_t}x_{t,I}\le\mu_t\qquad(t\in T),\)

\(\displaystyle \sum_{t\in T}\sum_{\substack{I\in\mathcal G_t\\j\in I}}x_{t,I}-z=0\qquad(j\in[m]),\)

\(\displaystyle z=\beta.\)

The auxiliary variable records \(\beta\) only once in the right-hand side.

Original feasibility implies LP feasibility. By Section 1, every original feasible solution has zero mass on inadmissible nonempty intervals. Set \(x_{t,I}=\lambda_{t,I}\) on admissible intervals and \(z=\beta\). The type inequalities follow because the omitted empty-interval masses are nonnegative. The item equations hold unchanged.

LP feasibility implies original feasibility. Given a feasible LP solution, set

\(\displaystyle \lambda_{t,I}=x_{t,I}\quad(I\in\mathcal G_t),\qquad \lambda_{t,\varnothing}=\mu_t-\sum_{I\in\mathcal G_t}x_{t,I},\)

and set every remaining interval mass to zero. These masses are nonnegative and satisfy the type and item equalities. Moreover, every used nonempty interval satisfies \(\sum_{j\in I}v_t(j)=|I|\). Therefore,

\(\displaystyle \sum_{t,I}\lambda_{t,I}\sum_{j\in I}v_t(j)=\sum_{t,I}\lambda_{t,I}|I|=\sum_{j=1}^{m}\beta=m\beta.\)

This proves equivalence in both directions. In particular, when \(\beta=0\), assigning all type mass to the empty interval is feasible.

4. Encoding size and running time

The LP has at most \(10\tau+1\) variables and \(m+\tau+1\) constraints before nonnegativity constraints. Every matrix coefficient belongs to \(\{-1,0,1\}\). Its right-hand side contains each \(\mu_t\) once, \(\beta\) once, and otherwise zeros.

Consequently, a standard dense binary encoding of the LP has length

\(\displaystyle B=O\!\left((m+\tau+1)(\tau+1)+L\right).\)

Scanning the explicit valuations examines \(m\tau\) binary entries; after this scan, enumerating the admissible intervals requires at most ten intervals per type. Constructing the encoded LP takes polynomial time in the displayed bound.

We apply the standard theorem that feasibility of an explicitly encoded rational linear program can be decided exactly in time polynomial in its binary encoding length. This theorem applies to systems with equalities and to feasible regions of lower dimension; no full-dimensionality assumption is needed. See the [MIT notes on polynomial-time LP feasibility](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

All hypotheses hold here: the system is explicit, finite, linear, and rational. Thus the total running time is

\(\displaystyle \left((m+\tau+1)(\tau+1)+L\right)^{O(1)}=(m+\tau+L)^{O(1)}\)

bit operations. This depends on the bit length of \(\beta\), rather than its denominator’s numerical magnitude.

Finally, every item is valued by at least one type, so

\(\displaystyle m\le\sum_{t\in T}|\{j:v_t(j)=1\}|\le4\tau.\)

The running-time bound therefore simplifies to \((\tau+L)^{O(1)}\) on the promised instances.

5. Relation to finite-agent hardness

The cited [finite-agent result](https://arxiv.org/html/2401.04318v2) concerns partitions into one interval per agent. Such indivisible choices are absent from the present formulation: each type may distribute its mass among multiple intervals, and feasibility consists exactly of the displayed linear constraints.

Indeed, polynomial-time solvability here does not require sparsity. Without it, retaining all \(\tau\left(1+m(m+1)/2\right)\) interval variables still gives an explicitly encoded rational LP of polynomial size. Sparsity supplies the sharper bound of ten nonempty interval variables per type.
