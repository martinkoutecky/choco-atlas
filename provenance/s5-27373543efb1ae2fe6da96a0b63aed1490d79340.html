The continuous mirror question, as graded

Given a finite set of recipient–donor pair types and nondirected-donor types with rational masses \(\mu_t\), type-level compatibility relations, and rational arc scores, determine the lexicographically optimal mass assignment to feasible cycles of size at most \(3\) and chains of length at most \(4\). For each type \(t\), require \(\sum_P a_{tP}x_P\leq\mu_t\), where \(x_P\geq0\) is the mass assigned to pattern \(P\) and \(a_{tP}\) counts its uses of type \(t\); optimize the paper’s five objectives over these pattern masses, and classify the complexity in \(\tau\) and input bit length \(L\) for fixed exchange-length bounds.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: disjoint lists \(R\) of recipient–donor pair types and \(N\) of nondirected-donor types, each with positive binary-rational mass \(\mu_t\). Let \(\tau=|R|+|N|\), \(m=|R|\), and \(L\) be the total input bit length; masses need not sum to one.
The input specifies a directed compatibility relation from \(R\cup N\) to \(R\), with one rational score per compatible ordered type pair. Compatibility between distinct occurrences of the same type is permitted when specified. Add an unlimited-capacity sink \(S\) and a zero-score arc from every donor or pair occurrence to \(S\).
A feasible pattern \(P\) is a directed cycle of two or three pair occurrences, or a chain \(n\to r_1\to\cdots\to r_k\to S\), where \(n\in N\) and \(0\leq k\leq3\). Occurrences represent distinct participants, but types may repeat. Chain length is \(k+1\), including the final sink arc; direct chains \(n\to S\) are allowed.
Let \(a_{tP}\) count occurrences of type \(t\) in \(P\). Assign real masses \(x_P\geq0\), subject to \(\sum_P a_{tP}x_P\leq\mu_t\) for every type; unused mass is permitted.
Let \(\ell(P)\) be the cycle size or chain length, \(b(P)\) the number of compatible directed arcs between distinct nonsink occurrences of \(P\) that are not selected pattern arcs, and \(s(P)\) the sum of selected arc scores. Cross arcs are counted per ordered occurrence pair, including backward arcs in chains.
Lexicographically maximize \(\bigl(\sum_P\ell(P)x_P,-\sum_{P\text{ chain}:\ell(P)=4}x_P,-\sum_{P:\ell(P)=3}x_P,\sum_P b(P)x_P,\sum_P s(P)x_P\bigr)\). Sink donations count as transplants. Any assignment attaining the optimal vector is acceptable.

Is computing this exact lexicographically optimal mass assignment in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\) for the fixed exchange-length bounds, or is it \(\mathrm{NP}\)-hard?

For finite participants, an exact diving algorithm correctly optimizes these five objectives, without a polynomial-time guarantee ([Delorme et al.](https://doi.org/10.1287/opre.2022.2374)); maximizing transplant count with cycles of size at most three is already NP-hard ([Abraham–Blum–Sandholm](https://www.cs.cmu.edu/~avrim/Papers/ec150abraham.pdf)).
No result settling this exact mass problem was located in the literature search.

Result

The exact mass problem is polynomial-time solvable. For the fixed exchange-length bounds, a lexicographically optimal rational mass assignment can be computed in time polynomial in \(m,\tau,L\).

The proof uses a polynomial-size rational linear program and five successive exact optimizations. It permits repeated types and counts cross arcs between occurrence slots exactly as specified.

1. Enumerating all patterns

Write \(n=|N|=\tau-m\). An occurrence slot represents a distinct participant, even when several slots have the same type.

For cycles, enumerate every ordered tuple in \(R^2\) and \(R^3\). Retain a tuple precisely when every selected cycle arc is compatible, including the closing arc. Repeated types are allowed: compatibility from a type to itself is tested between distinct slots.

For chains, enumerate every tuple \((t_0,t_1,\ldots,t_k)\) with \(t_0\in N\), \(t_i\in R\) for \(i\geq1\), and \(0\leq k\leq3\). Retain it precisely when all selected nonsink arcs are compatible, and append the always-available sink arc. In particular, every tuple with \(k=0\) gives a direct chain.

Cycles differing only by cyclic rotation can be identified. Alternatively, retaining duplicate representatives is harmless: their coefficients are identical, and their assigned masses can be summed.

Thus the number \(q\) of retained representatives satisfies

\(q\leq m^2+m^3+n(1+m+m^2+m^3)=O((1+\tau)^4)\).

Every allowed pattern has a representative in this enumeration. Participant names supply no additional information: compatibility, scores, resource usage, and all five objective coefficients depend only on types and occurrence positions.

For each representative \(P\), compute \(a_{tP}\), \(\ell(P)\), \(b(P)\), and \(s(P)\). To compute \(b(P)\), examine every ordered pair of distinct nonsink slots. Count it precisely when its types are compatible and that particular ordered slot pair is not a selected pattern arc. This includes backward chain arcs and correctly handles repeated types.

There are at most four nonsink slots, so each compatibility calculation uses a constant number of lookups. Selected scores sum at most three input rational scores, because the sink arc has score zero. Consequently, all coefficients have bit length polynomial in \(L\), and the full enumeration and coefficient construction take polynomial time in \(m,\tau,L\).

2. The exact feasible polytope

Let \(A=(a_{tP})\), and define

\(K=\{x\in\mathbb{R}^{q}:x\geq0,\ Ax\leq\mu\}\).

This is exactly the feasible set in the question. Each pattern consumes the specified number of occurrences of each type, and the inequalities permit unused mass. There are no integrality constraints.

The polytope is nonempty, because \(x=0\) is feasible. It is also bounded. Every pattern contains at least one nonsink occurrence. Choose a type \(t\) with \(a_{tP}\geq1\). Nonnegativity and the resource inequality imply

\(a_{tP}x_P\leq\sum_Q a_{tQ}x_Q\leq\mu_t\),

and therefore \(0\leq x_P\leq\mu_t/a_{tP}\).

Since there are finitely many coordinates, \(K\) is closed and bounded, hence compact. Every linear objective therefore attains its maximum on \(K\). If \(q=0\), the empty assignment already solves the problem.

The explicit description of \(K\) has \(q\) variables, \(\tau\) resource inequalities, and nonnegativity constraints. Its total rational encoding length is polynomial in \(m,\tau,L\).

3. Exact lexicographic optimization

Define coefficient vectors by

\(c_{1P}=\ell(P)\),

\(c_{2P}=-\mathbf{1}\{P\text{ is a chain and }\ell(P)=4\}\),

\(c_{3P}=-\mathbf{1}\{\ell(P)=3\}\),

\(c_{4P}=b(P)\), and \(c_{5P}=s(P)\).

Thus the required objective vector is \((c_1^\top x,\ldots,c_5^\top x)\).

Starting with \(K_0=K\), successively compute, for \(j=1,\ldots,5\),

\(v_j=\max\{c_j^\top x:x\in K_{j-1}\}\),

and set

\(K_j=\{x\in K_{j-1}:c_j^\top x=v_j\}\).

At every stage, the maximum exists: by induction, \(K_{j-1}\) is nonempty and compact. The resulting \(K_j\) is also nonempty and compact.

Return an exact optimizer from the fifth stage. It belongs to \(K_5\), so its objective vector is \((v_1,\ldots,v_5)\).

To verify lexicographic optimality, suppose a feasible assignment \(y\) had a larger objective vector. Let \(j\) be its first differing coordinate. Then \(c_i^\top y=v_i\) for every \(i<j\), so \(y\in K_{j-1}\). But lexicographic improvement requires \(c_j^\top y>v_j\), contradicting the definition of \(v_j\).

This proves correctness without using approximate tolerances or infinitesimal weights.

4. Exactness and polynomial bit complexity

We use the standard rational linear-programming theorem: a linear program with binary-encoded rational data can be solved in time polynomial in its encoding length, including computation of an exact rational optimizer when a finite optimum is attained. This is the exact polynomial-time result established by [Khachiyan’s work on linear programming](https://www.mathnet.ru/eng/zvmmf5239).

The first program meets its hypotheses by Sections 1–2. We must also check that adding the equalities \(c_j^\top x=v_j\) does not introduce numbers of excessive bit length.

Here is a direct verification.

Every \(K_j\) is a face of \(K\). Indeed, it is obtained by successively maximizing linear functionals and retaining their maximizers. More explicitly, if \(z\in K_j\) lies strictly between two points of \(K\), then the first objective’s maximality forces both endpoints to attain \(v_1\). Applying the same argument successively forces both endpoints into \(K_j\).

Consequently, every vertex of \(K_j\) is a vertex of \(K\): a nontrivial convex decomposition in \(K\) would, by the preceding argument, also be a decomposition in \(K_j\).

Each stage’s optimal value is attained at a vertex of \(K_{j-1}\), hence at a vertex of the original polytope \(K\). We now bound the encoding length of those original vertices.

At a vertex of \(K\), there are \(q\) linearly independent tight constraints. Otherwise, a nonzero direction orthogonal to all tight constraint normals would permit sufficiently small perturbations in both directions, contradicting extremality. The vertex therefore solves an invertible rational system formed from resource constraints and coordinate nonnegativity constraints.

The entries of \(A\) are integers between \(0\) and \(3\). Let \(Q\) be the product of the input mass denominators. Its bit length is \(O(L)\). Multiplying this tight system by \(Q\) produces an integer system whose entries and right-hand sides have bit length \(O(L+1)\).

For a matrix of order \(q\) with entries of absolute value at most \(2^H\), the determinant expansion gives

\(|\det M|\leq q!\,2^{qH}\).

Applying this bound to the system matrix and the matrices arising in Cramer’s rule shows that every vertex coordinate has numerator and denominator bit length \(O(q(L+\log(q+1)))\).

Each \(v_j\) is an objective evaluated at such a vertex. Its coefficients have polynomial bit length, and it is a sum of \(q\) rational products. Thus every \(v_j\) also has polynomial bit length.

Each successive program therefore has polynomial encoding length: it adds at most four rational equalities to the original constraints. The five exact linear-programming calls, coefficient construction, and output all take polynomial time in \(m,\tau,L\).

5. Why finite-participant hardness does not transfer

The finite-participant hardness result concerns selecting disjoint exchanges, which imposes indivisibility. [Abraham–Blum–Sandholm](https://www.cs.cmu.edu/~avrim/Papers/ec150abraham.pdf) establish hardness for that selection problem. The present problem expressly permits arbitrary nonnegative real pattern masses.

For example, take one pair type \(r\), mass \(\mu_r=1\), no nondirected donors, and compatible arcs between distinct occurrences of type \(r\), with score zero. A two-cycle uses two distinct occurrence slots of type \(r\). Assigning it mass \(1/2\) consumes mass \(1\) and achieves transplant mass \(1\).

This assignment is lexicographically optimal: the resource constraint bounds the first objective by \(1\); there are no length-four chains; choosing only the two-cycle makes the third objective \(0\), its largest possible value; and the remaining objectives are zero. By contrast, a finite society containing just one participant cannot perform a cycle.

The polynomial-time conclusion therefore applies to precisely the continuous mass formulation stated in the task, including all five objectives.
