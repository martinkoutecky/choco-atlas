The continuous mirror question, as graded

Given a finite argument set \(\mathrm{Args}\), possible attack pairs \(E\), supporter types \(T\), rational masses \(\mu_t\ge 0\) summing to \(1\), and per-capita attack contributions \(q_t:E\to\mathbb{Q}_{\ge 0}\), form \(W_\mu(a,b)=\sum_{t\in T}\mu_t q_t(a,b)\). For a rational tolerance \(\alpha\) and a selected semantics among \(\alpha\)-admissible, \(\alpha\)-complete, and \(\alpha\)-stable, compute all sets \(B\subseteq\mathrm{Args}\) satisfying that semantics under the weighted semiring definitions and attack strengths \(W_\mu\).

Packaged proof task (what the prover saw — nothing else)

Let \(m=|\mathrm{Args}|\), with finite \(\mathrm{Args}\), and let \(E\subseteq\mathrm{Args}^2\) be possible attacks; self-attacks are allowed.
A society is given by its support: the list of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies an explicit function \(q_t:E\to\mathbb Q_{\ge0}\). Set \(W(a,b)=\sum_t\mu_tq_t(a,b)\) on \(E\), and \(W(a,b)=0\) elsewhere; the actual attack relation is \(R=\{(a,b):W(a,b)>0\}\).
Use the Weighted semiring \(\langle\mathbb R_{\ge0}\cup\{\infty\},\min,+,\infty,0\rangle\). Write \(W(B,C)=\sum_{b\in B,c\in C}W(b,c)\) and \(W(B,a)=W(B,\{a\})\); empty sums are \(0\).
Given \(\alpha\in\mathbb Q_{\ge0}\), a set \(B\subseteq\mathrm{Args}\) is \(\alpha\)-conflict-free when \(W(B,B)\le\alpha\). It defends \(b\) when every \(a\) with \((a,b)\in R\) satisfies \(W(B,a)>W(a,b)\).
It is \(\alpha\)-admissible when it is \(\alpha\)-conflict-free and defends every member; \(\alpha\)-complete when additionally every argument it defends belongs to it; and \(\alpha\)-stable when it is \(\alpha\)-conflict-free and \(W(B,c)>0\) for every \(c\notin B\).
The input selects one of these three semantics. Enumerate all its sets without repetition, in arbitrary order. Let \(L\) be the total binary input length and \(K\) the total output length, representing sets by \(m\)-bit incidence vectors.

For each selected semantics, is enumeration possible in time polynomial in \(m,\tau,|E|,L,K\), or is it NP-hard in the sense that such a bound would imply \(\mathrm P=\mathrm{NP}\)?

Known: a soft-constraint encoding is claimed to characterize all three weighted extension families; this is a representation result, not a polynomial-time bound ([solution equivalence](https://bista.sites.dmi.unipg.it/didattica/CSP/argumentation/ecai2010.pdf)).
Classical admissible-extension enumeration is not output-polynomial unless \(\mathrm P=\mathrm{NP}\) ([enumeration complexity](https://www.ijcai.org/Proceedings/2017/0159.pdf)); it uses a different defense condition. No classification of the exact society-input problem above was located.

Modeling choices made when packaging the task

  • Fixed the semiring to the additive Weighted semiring, matching the nonnegative contribution domain.
  • Restricted tolerance to nonnegative binary rationals and interpreted it as an upper bound on internal attack cost, rather than an exact optimum.
  • Discarded zero-mass types; masses remain normalized to one.
  • Treated zero aggregate weight as absence of an attack, since the Weighted semiring's top element represents no attack.
  • Restricted defense comparisons to actual attackers, following the later ConArg semantic definition; unattacked arguments are therefore defended vacuously.
  • Retained strict defense comparisons from the semantic definition, despite weak comparisons in the constraint encoding.
  • Allowed self-attacks and empty extensions, and counted every ordered internal attack, including self-attacks, once.
  • Measured enumeration tractability against total output length, preserving the request to compute all extensions.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

For each of admissible, complete, and stable semantics, an enumeration algorithm with total running time polynomial in \(m,\tau,|E|,L,K\) would imply \(\mathrm P=\mathrm{NP}\).

This hardness holds already when \(\tau=1\), \(\alpha=0\), and every actual attack has weight \(1\). Conversely, if \(\mathrm P=\mathrm{NP}\), all three families admit output-polynomial enumeration.

The proof uses the strict weighted defense condition stated in the question.

1. A polynomial-size SAT construction

Let \(\varphi=C_1\land\cdots\land C_r\) be a \(3\)-CNF formula over \(x_1,\ldots,x_n\), with \(n,r\geq1\). This restriction preserves NP-hardness: one can append a clause on three fresh variables without changing satisfiability.

First introduce the labels

\[ \]

\(V=\{p,g\}\cup\{x_i,\neg x_i:1\leq i\leq n\}\cup\{c_j:1\leq j\leq r\}.\)

Define the following directed edges between labels:

  • \(g\to g\) and \(p\to g\);
  • \(g\to x_i\) and \(g\to\neg x_i\), for every \(i\);
  • \(x_i\to\neg x_i\) and \(\neg x_i\to x_i\), for every \(i\);
  • \(c_j\to c_j\) and \(c_j\to p\), for every \(j\);
  • \(\ell\to c_j\) whenever the literal \(\ell\) occurs in \(C_j\).

There are no other edges. Repeated literal occurrences produce only one edge.

Replace each label \(v\) by two arguments, forming the pair \(P_v=\{v^1,v^2\}\). Replace every label edge \(u\to v\) by all four attacks from \(P_u\) to \(P_v\). Every such attack has weight \(1\).

Realize this as a society with one type: \(\tau=1\), \(\mu_1=1\), and \(q_1(e)=1\) for every \(e\in E\). Set \(\alpha=0\). Consequently, \(R=E\).

The construction has \(m=4n+2r+4\) arguments and \(|E|=O(n+r)\), and its binary input length is polynomial in the formula length.

Because weights are nonnegative and \(\alpha=0\), conflict-freeness means that no attack has both endpoints in the selected set.

2. Exact characterization of admissible sets

Write \(\overline{\ell}\) for the literal complementary to \(\ell\), and let \(D_j\) be the set of distinct literals occurring in \(C_j\).

Call a set \(S\) of literals consistent if it contains no complementary pair. Say that \(S\) hits every clause if \(S\cap D_j\neq\varnothing\) for every \(j\).

For such an \(S\), define

\(B(S)=P_p\cup\bigcup_{\ell\in S}P_\ell.\)

Claim. The admissible sets of the constructed instance are exactly

\(\{\varnothing\}\cup\{B(S):S\text{ is consistent and hits every clause}\}.\)

Proof: necessity. Let \(B\neq\varnothing\) be admissible.

Every argument in \(P_g\) or \(P_{c_j}\) has a unit self-attack. Conflict-freeness therefore excludes all these arguments from \(B\). The attacks between complementary literal pairs also prevent \(B\) from meeting both \(P_\ell\) and \(P_{\overline{\ell}}\).

Suppose \(B\) contains a literal argument \(\ell^i\). One of its attackers is \(g^1\). Since gate arguments are excluded, the only possible selected attackers of \(g^1\) are the two arguments in \(P_p\). Thus defense of \(\ell^i\) requires

\(W(B,g^1)=|B\cap P_p|>W(g^1,\ell^i)=1.\)

Hence \(P_p\subseteq B\).

Another attacker of \(\ell^i\) is \(\overline{\ell}^{\,1}\). Its only attackers are \(P_g\) and \(P_\ell\). Therefore

\(W(B,\overline{\ell}^{\,1})=|B\cap P_\ell|>1,\)

which forces \(P_\ell\subseteq B\). Every selected literal thus appears as a full pair.

There must be a selected literal. Otherwise, the nonempty set \(B\) would contain only arguments from \(P_p\). Since \(r\geq1\), the attack \(c_1^1\to p^i\) would then be undefended: \(W(B,c_1^1)=0\).

Consequently, \(B=B(S)\) for some consistent literal set \(S\). For each clause, defense of \(p^1\) against \(c_j^1\) requires

\(W(B,c_j^1)=2|S\cap D_j|>1.\)

Thus \(S\) hits every clause.

Proof: sufficiency. Conversely, suppose \(S\) is consistent and hits every clause.

The set \(B(S)\) is conflict-free: it contains no gate or clause arguments and no complementary literals.

Every attacker \(c_j^h\) of a selected argument \(p^i\) receives counterattack weight

\(W(B(S),c_j^h)=2|S\cap D_j|\geq2>1.\)

The attackers of a selected literal argument \(\ell^i\) are precisely the gate arguments and the complementary literal arguments. For each \(h\),

\(W(B(S),g^h)=2>1\quad\text{and}\quad W(B(S),\overline{\ell}^{\,h})=2>1.\)

Thus every member is defended. Finally, \(\varnothing\) is admissible vacuously. This proves the claim.

A consistent literal set hitting every clause exists exactly when \(\varphi\) is satisfiable: extend its prescribed truth values arbitrarily to the remaining variables; conversely, the true literals of a satisfying assignment hit every clause. Hence

\(\varphi\text{ is satisfiable}\iff\text{a nonempty admissible set exists}.\)

3. Complete sets coincide with admissible sets in this construction

First, \(\varnothing\) is complete. Every argument has an attacker:

  • gate and clause arguments have self-attacks;
  • literal arguments are attacked by gate arguments;
  • arguments in \(P_p\) are attacked by clause arguments.

Since \(W(\varnothing,a)=0\), the empty set defends no argument.

Now consider an admissible set \(B(S)\). We show that it defends no argument outside itself.

A useful observation is that if \(B\) is conflict-free and some \(b\in B\) attacks \(c\), then \(B\) cannot defend \(c\). Indeed,

\(W(B,b)=0<W(b,c),\)

so the required strict inequality against attacker \(b\) fails.

Every gate argument is attacked by a selected argument in \(P_p\). Every clause argument is attacked by a selected literal, because \(S\) hits every clause. The observation therefore excludes defense of gate and clause arguments.

For an unselected literal \(\ell\notin S\), the argument \(\overline{\ell}^{\,1}\) attacks both arguments in \(P_\ell\). Its only attackers are \(P_g\) and \(P_\ell\), neither of which meets \(B(S)\). Thus

\(W(B(S),\overline{\ell}^{\,1})=0,\)

and neither argument in \(P_\ell\) is defended.

These exhaust the arguments outside \(B(S)\). Therefore every admissible set in this construction is complete. Since completeness requires admissibility, the two families coincide. In particular,

\(\varphi\text{ is unsatisfiable}\implies \operatorname{Adm}=\operatorname{Comp}=\{\varnothing\},\)

whereas a satisfiable formula gives a nonempty complete set.

4. Stable existence is equivalent to satisfiability

Suppose \(B\) is stable. Conflict-freeness again excludes all gate and clause arguments and prevents selecting complementary literals.

Each clause argument \(c_j^1\) lies outside \(B\), so stability requires \(W(B,c_j^1)>0\). Its possible attackers are its own clause pair and the literal pairs occurring in \(C_j\). Clause arguments are excluded, so at least one literal occurring in \(C_j\) must be selected.

The selected literals are therefore consistent and hit every clause. They extend to a satisfying assignment.

Conversely, let a satisfying assignment be given, and let \(S\) contain exactly its true literal for each variable. The set \(B(S)\) is conflict-free. Every outside argument is attacked:

  • each gate argument receives weight \(2\) from \(P_p\);
  • each clause argument receives weight at least \(2\) from a true literal pair;
  • each unselected literal argument receives weight \(2\) from its selected complementary pair.

Thus \(B(S)\) is stable, proving

\(\varphi\text{ is satisfiable}\iff\text{a stable set exists}.\)

5. Why a total output-polynomial bound implies polynomial-time SAT

The reduction has the following behavior:

| Selected semantics | Unsatisfiable formula | Satisfiable formula |
|---|---|---|
| Admissible | Exactly \(\{\varnothing\}\) | A nonempty set exists |
| Complete | Exactly \(\{\varnothing\}\) | A nonempty set exists |
| Stable | No sets | A nonempty set exists |

Because sets are represented by \(m\)-bit vectors, the total output length on an unsatisfiable formula is \(m\) for admissible and complete semantics, and \(0\) for stable semantics.

Fix any one of the three semantics. Suppose an enumerator has total running time bounded by a polynomial \(p(m,\tau,|E|,L,K)\). We may replace \(p\) by a nondecreasing polynomial upper bound.

On the constructed instance, simulate that enumerator for

\(T=p(m,1,|E|,L,m)\)

steps. This is polynomial in the formula length. Decide satisfiability as follows:

  • If the enumerator has halted, answer satisfiable exactly when it output a nonempty set.
  • If it has not halted, answer satisfiable.

For an unsatisfiable formula, the output length is at most \(m\), so the enumerator must halt within \(T\) and output no nonempty set. The decision is therefore unsatisfiable.

For a satisfiable formula, either the enumerator has not halted, or its completed enumeration contains a nonempty set. In both cases the decision is satisfiable.

This yields a polynomial-time algorithm for \(3\)-SAT, implying \(\mathrm P=\mathrm{NP}\). Crucially, the argument requires only a total-time bound; it assumes no bound on the delay before the first output.

6. Conditional converse

For completeness, suppose \(\mathrm P=\mathrm{NP}\).

Membership of a specified set in each family is decidable in polynomial time. Compute the rational weights exactly, then check conflict-freeness and the selected defense, completeness, or stability conditions. Products and sums of the binary input rationals have polynomially bounded bit length, so these checks use polynomial time.

Given a prefix of an incidence vector, the question whether some extension of that prefix belongs to the selected family is in \(\mathrm{NP}\): guess the remaining bits and perform the membership check. Under \(\mathrm P=\mathrm{NP}\), this prefix question is polynomial-time decidable.

Traverse the binary prefix tree, pruning every prefix with no valid completion. Every feasible prefix lies on the path to an output vector. If there are \(N\) outputs, there are at most \(1+mN\) feasible prefixes, and at most twice that many prefix tests. Each vector is output once. Since \(K=mN\), the total running time is polynomial in the requested parameters. The case \(m=0\) is immediate.

Thus, for every selected semantics, output-polynomial enumeration is possible if and only if \(\mathrm P=\mathrm{NP}\).
