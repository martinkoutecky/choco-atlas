The anchor (named result in the paper)

Theorem 2 — class: algorithmic

The continuous mirror question, as graded

Given finite item types \(M\) with conflict graph \(G\), agent types \(T\) with rational mass distribution \(\mu\) and additive valuations \(v_t\), and per-capita supply \(1/r\) of each item type for \(r>\Delta(G)\), find a mass allocation \(x_{t,B}\ge0\) over integral independent bundles \(B\in\mathcal I(G)\) satisfying \(\sum_B x_{t,B}=\mu_t\) and \(\sum_{t,B\ni j}x_{t,B}=1/r\), maximizing the largest \(\alpha\) for which every used bundle satisfies \(v_t(B)\ge\alpha\operatorname{MMS}_t\). Here \(\operatorname{MMS}_t\) is defined by the analogous mass partition problem, and the algorithm should run polynomially in \(m,\tau,L,\log r\).

Packaged proof task (what the prover saw — nothing else)

Let \(M\) contain \(m\) item types, with a simple undirected conflict graph \(G\), maximum degree \(\Delta\ge1\), and a binary-encoded integer \(r>\Delta\). Each item type has per-capita supply \(1/r\).
A society is given by its support: the list of the \(\tau\) agent types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Valuations are additive, with nonnegative binary-rational item values; \(L\) is the total input bit length.
Let \(\mathcal I(G)\) contain all independent bundles, including the empty bundle; each bundle contains at most one copy of each item type. A complete mass allocation has \(x_{t,B}\ge0\), \(\sum_Bx_{t,B}=\mu_t\), and \(\sum_{t,B\ni j}x_{t,B}=1/r\) for every \(j\in M\).
Define \(\mathcal Y=\{y\ge0:\sum_By_B=1,\ \sum_{B\ni j}y_B=1/r\text{ for every }j\in M\}\) and \(\operatorname{MMS}_t=\max_{y\in\mathcal Y}\min_{B:y_B>0}v_t(B)\).
An allocation is \(\alpha\)-MMS if \(x_{t,B}>0\) implies \(v_t(B)\ge\alpha\operatorname{MMS}_t\); this condition is vacuous when \(\operatorname{MMS}_t=0\).
Set \(\beta(1)=1/2\), \(\beta(2)=3/7\), and \(\beta(\Delta)=2/(\Delta+2)\) for \(\Delta>2\).
Can a complete \(\beta(\Delta)\)-MMS mass allocation always be found in time polynomial in \(m,\tau,L,\log r\), or is attaining this guarantee NP-hard?
For discrete agents with \(n>\Delta\), complete \(\beta(\Delta)\)-MMS allocations can be found in polynomial time; for bipartite conflict graphs the guarantee improves to \(1/2\). [Source](https://link.springer.com/article/10.1007/s10458-021-09537-3)
No result settling this exact mass-allocation guarantee was located in the literature search.

  • Normalized the society to total mass one, consistent with per-capita supplies.

  • Specified nonnegative binary-rational additive item values and a simple undirected conflict graph.
  • Defined the analogous MMS partition as a unit-mass distribution over independent bundles with the same exact item marginals.
  • Allowed empty bundles and zero MMS values, as discrete partitions permit empty bundles; zero benchmarks impose no utility requirement.

Result

A complete \(\beta(\Delta)\)-MMS mass allocation can always be found in time polynomial in \(m,\tau,L,\log r\).

The proof constructs, separately for each agent type, a partition into \(r\) independent bundles whose minimum value approximates that type’s distributional MMS. Mixing these partitions according to the type masses gives the required allocation. No population expansion or MMS computation is needed.

1. The single-valuation problem

Fix one additive, nonnegative valuation \(v\), and write \(q=\operatorname{MMS}(v)\).

First, \(\mathcal Y\) is nonempty. A greedy coloring partitions \(M\) into \(k\le\Delta+1\le r\) nonempty independent sets. Give each such set probability \(1/r\), and give the empty bundle probability \(1-k/r\).

Moreover, \(q\) is attained: the minimum value in the support of any distribution belongs to the finite set \(\{v(B):B\in\mathcal I(G)\}\). Fix an attaining distribution \(y\), so every bundle in its support has value at least \(q\).

We will use \(y\) only in the proof.

Lemma 1: surviving benchmark mass

Let \(S\subseteq M\), suppose \(|S|<r\), and put \(H=M\setminus S\) and \(n=r-|S|\). There exist nonnegative weights \(z_B\), supported on independent bundles contained in \(H\), such that

\(\displaystyle \sum_B z_B=n,\qquad p_j:=\sum_{B\ni j}z_B\le1\quad(j\in H),\)

and every positively weighted bundle has value at least \(q\). Consequently,

\(\displaystyle nq\le\sum_{j\in H}p_jv(j)\le v(H).\)

Proof. Scale the benchmark distribution by \(r\). Its total mass becomes \(r\), and the mass containing each item becomes \(1\). By the union bound, bundles intersecting \(S\) have total mass at most \(|S|\). Thus bundles disjoint from \(S\) have mass \(h\ge n\).

Retain these bundles and multiply their weights by \(n/h\). Their total mass is \(n\), their item marginals are at most \(1\), and their values remain at least \(q\). Additivity and nonnegativity give the asserted inequalities. ∎

Lemma 2: an improved bound from coloring obstructions

Suppose \(2\le n\le\Delta\). Define \(F\subseteq H\) as follows:

  • If \(\Delta\ge3\), select a least-valued vertex from each connected component of \(G[H]\) isomorphic to \(K_{\Delta+1}\).
  • If \(\Delta=2\), select a least-valued vertex from each odd-cycle component of \(G[H]\).

Then \(G[H\setminus F]\) admits a polynomially computable \(\Delta\)-coloring, and

\(\displaystyle nq\le v(H\setminus F).\)

Proof. The coloring statement follows from algorithmic Brooks’ theorem. For maximum degree at most \(\Delta\ge3\), the only components preventing a \(\Delta\)-coloring are \(K_{\Delta+1}\); deleting one vertex turns each into \(K_\Delta\). For maximum degree at most \(2\), components are paths or cycles, and deleting one vertex from each odd cycle leaves a bipartite graph. Constructive Brooks coloring is available in polynomial time. [Baetz and Wood](https://arxiv.org/abs/1401.8023)

For the inequality, take \(z_B,p_j\) from Lemma 1.

If \(C\) is a \(K_{\Delta+1}\) component, each independent bundle contains at most one vertex of \(C\). Therefore

\(\displaystyle \sum_{j\in C}p_j\le\sum_Bz_B=n,\qquad \sum_{j\in C}(1-p_j)\ge\Delta+1-n\ge1.\)

If \(C\) is an odd cycle with \(2a+1\) vertices, then \(\Delta=2\) forces \(n=2\). Each independent bundle contains at most \(a\) vertices of \(C\), giving

\(\displaystyle \sum_{j\in C}p_j\le2a,\qquad \sum_{j\in C}(1-p_j)\ge1.\)

In either case, writing \(b_C=\min_{j\in C}v(j)\), nonnegativity implies

\(\displaystyle \sum_{j\in C}(1-p_j)v(j)\ge b_C.\)

The exceptional components are disjoint. Summing their inequalities yields

\(\displaystyle nq\le\sum_{j\in H}p_jv(j) =v(H)-\sum_{j\in H}(1-p_j)v(j) \le v(H)-\sum_Cb_C =v(H\setminus F). \)

∎

This lemma directly addresses the distributional benchmark; it does not assume an integral MMS partition.

2. Two elementary algorithmic tools

Lemma 3: finding one sufficiently valuable independent set

For a nonnegative weighted graph of maximum degree at most \(\Delta\), one can find an independent set \(I\) in polynomial time satisfying

\(\displaystyle v(I)\ge\frac{\operatorname{OPT}}{\lfloor\Delta/2\rfloor+1} \ge\beta(\Delta)\operatorname{OPT},\)

where \(\operatorname{OPT}\) is the maximum independent-set value.

Proof. Put \(a=\lfloor\Delta/2\rfloor+1\), so \(\Delta\le2a-1\). Start with any partition of the vertices into \(a\) classes.

Whenever a vertex has at least two neighbors in its own class, some other class contains at most one of its neighbors: otherwise its degree would be at least \(2a\). Move it to such a class. This strictly decreases the number of edges within classes, so at most \(|E(G)|\) moves occur.

At termination, each class induces a graph of maximum degree at most \(1\). Its maximum-weight independent set is found exactly by selecting every isolated vertex and a heavier endpoint of each edge.

Let these optimum class values be \(W_1,\ldots,W_a\). Any independent set of the original graph restricts to an independent set in each class, so

\(\displaystyle \operatorname{OPT}\le\sum_{i=1}^aW_i\le a\max_iW_i.\)

Return the best class solution. For \(\Delta=1\) the ratio is \(1\); for \(\Delta=2\) it is \(1/2\ge3/7\). For \(\Delta>2\), the inequality \(2a\le\Delta+2\) gives \(1/a\ge2/(\Delta+2)\). ∎

Lemma 4: bag filling within color classes

Suppose a set of items is partitioned into \(k\) independent sets, has total value \(R\), and every item has value strictly less than \(A>0\). If

\(\displaystyle R\ge\bigl(k+2(n-1)\bigr)A,\)

then one can find \(n\) pairwise disjoint independent bundles, each worth at least \(A\), in polynomial time.

Proof. Repeatedly choose a remaining color class worth at least \(A\), and take items from it until their value first reaches \(A\). The resulting bundle is independent and worth less than \(2A\).

After producing \(h\le n-1\) bundles, remaining value is at least

\(\displaystyle R-2hA\ge kA.\)

Hence at least one of the \(k\) remaining color classes has value at least \(A\), allowing the next bundle to be formed. Each item is taken at most once, so the construction is polynomial. ∎

3. Constructing a partition against the distributional MMS

Assume for now that \(r\le m\). We construct \(r\) disjoint independent bundles, each worth at least \(\beta(\Delta)q\), and then complete them to a partition of \(M\).

Maintain a set \(S\) of items already allocated as separate singleton bundles. Initially \(S=\varnothing\). At every iteration put

\(\displaystyle H=M\setminus S,\qquad n=r-|S|.\)

The case \(n=1\)

Lemma 1 supplies mass \(1\) of independent bundles in \(H\), each worth at least \(q\). Thus the maximum independent-set value in \(G[H]\) is at least \(q\).

Use Lemma 3 to construct the final bundle. Its value is at least \(\beta(\Delta)q\).

The cases \(n\ge2\)

Choose a source set \(P\) and a coloring with \(k\) classes:

| Condition | Source set \(P\) | Number \(k\) of color classes |
|---|---|---|
| \(n>\Delta\) | \(H\) | \(\Delta+1\), using greedy coloring |
| \(2\le n\le\Delta\) | \(H\setminus F\), with \(F\) from Lemma 2 | \(\Delta\) |

Set

\(\displaystyle U=\frac{v(P)}{n}.\)

Lemmas 1 and 2 prove \(q\le U\) in the respective cases.

If \(U=0\), then \(q=0\). Append \(n\) empty bundles and proceed to completion.

Otherwise, if some item \(j\in H\) satisfies

\(\displaystyle v(j)\ge\beta(\Delta)U,\)

allocate \(\{j\}\) as a singleton, add \(j\) to \(S\), and repeat. This singleton is worth at least \(\beta(\Delta)q\).

If no such item exists, every item of \(P\) is worth less than

\(\displaystyle A=\beta(\Delta)U.\)

We now apply Lemma 4 to produce all \(n\) remaining bundles. Since \(v(P)=nU\), its hypothesis is equivalent to

\(\displaystyle \beta(\Delta)\le\frac{n}{k+2(n-1)}.\)

We verify this in every case.

When \(n>\Delta\), \(k=\Delta+1\), so the right-hand side is \(n/(2n+\Delta-1)\).

  • For \(\Delta=1\), this equals \(1/2\).
  • For \(\Delta=2\), \(n\ge3\), so it is at least \(3/7\).
  • For \(\Delta\ge3\), it increases with \(n\), and hence is at least \((\Delta+1)/(3\Delta+1)\). Moreover,

\(\displaystyle \frac{\Delta+1}{3\Delta+1}-\frac{2}{\Delta+2} =\frac{\Delta(\Delta-3)}{(3\Delta+1)(\Delta+2)} \ge0. \)

When \(2\le n\le\Delta\), \(k=\Delta\), so the right-hand side is \(n/(2n+\Delta-2)\).

  • For \(\Delta=2\), it equals \(1/2\ge3/7\).
  • For \(\Delta\ge3\), it increases with \(n\), so it is at least its value at \(n=2\), namely \(2/(\Delta+2)\).
  • This case cannot occur for \(\Delta=1\).

Thus bag filling produces \(n\) bundles of value at least \(A\ge\beta(\Delta)q\).

Each singleton iteration decreases \(n\). Consequently the algorithm terminates after at most \(r-1\) singleton iterations, with exactly \(r\) disjoint independent bundles satisfying the desired value bound.

Completing the bundles

Process every unallocated item \(j\). At most \(\Delta\) of the \(r\) bundles contain a neighbor of \(j\). Since \(r>\Delta\), some bundle contains none; add \(j\) to it.

This preserves independence. Nonnegative valuations preserve every value guarantee. We obtain a complete partition

\(\displaystyle M=A_1\mathbin{\dot\cup}\cdots\mathbin{\dot\cup}A_r,\qquad v(A_i)\ge\beta(\Delta)q\quad\text{for every }i.\)

4. Combining the types

For each supported type \(t\), run the preceding algorithm with valuation \(v_t\). Let its resulting partition be \(A_{t,1},\ldots,A_{t,r}\).

Define

\(\displaystyle x_{t,B}=\frac{\mu_t}{r}\, \bigl|\{i:A_{t,i}=B\}\bigr|. \)

Then

\(\displaystyle \sum_Bx_{t,B}=\mu_t.\)

Each item belongs to exactly one bundle in each type’s partition, so

\(\displaystyle \sum_{t,B\ni j}x_{t,B} =\sum_t\frac{\mu_t}{r} =\frac1r. \)

Every positively allocated bundle for type \(t\) has value at least \(\beta(\Delta)\operatorname{MMS}_t\). Therefore this is a complete \(\beta(\Delta)\)-MMS mass allocation.

5. Binary-encoded \(r\) and bit complexity

It remains to handle \(r>m\) without listing \(r\) bundles.

For every \(y\in\mathcal Y\),

\(\displaystyle \sum_{B\ne\varnothing}y_B \le\sum_B|B|y_B =\frac mr<1. \)

Thus every feasible distribution gives positive probability to the empty bundle. Its minimum supported value is consequently \(0\), and every type has MMS \(0\).

Find a greedy coloring with nonempty classes \(C_1,\ldots,C_k\), where \(k\le\Delta+1\le m<r\). For each type, output

\(\displaystyle x_{t,C_i}=\frac{\mu_t}{r},\qquad x_{t,\varnothing}=\mu_t\left(1-\frac kr\right). \)

This is complete and satisfies the vacuous MMS conditions.

When \(r\le m\), each type’s algorithm performs at most \(m\) iterations. Coloring, the local-search procedure in Lemma 3, bag filling, and completion are polynomial operations. All thresholds use sums of input rational values, divided by integers at most \(m\), and multiplied by \(\beta(\Delta)\); their encoding lengths remain polynomial in \(L+\log m\).

The output has at most \(\tau r\le\tau m\) bundle records when \(r\le m\), and at most \(\tau(m+1)\) when \(r>m\). Its rational masses have polynomial encoding length in \(L+\log r\).

Hence the complete algorithm runs in time polynomial in \(m,\tau,L,\log r\).

6. Bipartite graphs

The mass model also preserves the stronger \(1/2\) guarantee for bipartite conflict graphs.

For every \(n\ge2\), use a two-coloring of \(G[H]\), set \(U=v(H)/n\), and use singleton threshold \(U/2\). Lemma 1 gives \(q\le U\), while Lemma 4 applies because

\(\displaystyle \frac12=\frac{n}{2+2(n-1)}.\)

When \(n=1\), the more valuable of the two color classes is worth at least \(v(H)/2\ge q/2\). Completion, mixing across types, and the binary-\(r\) argument proceed as above.

The coloring assertion correctly applies Brooks’ theorem componentwise. Thus the only obstructing components are \(K_{\Delta+1}\). Deleting one vertex from each leaves \(K_\Delta\). For \(\Delta=2\), deleting one vertex from each odd-cycle component leaves paths and even cycles, which are bipartite.

Those components are disjoint, so summing their losses justifies \(nq\le v(H\setminus F)\). This argument uses the distributional benchmark directly.

Thus there are at most \(|E(G)|\) moves. At termination, each class consists of isolated vertices and disjoint edges, so the described maximum-weight independent-set calculation is exact.

Restricting an optimum independent set to each class proves \(\operatorname{OPT}\le\sum_iW_i\le a\max_iW_i\). The comparisons with \(\beta(\Delta)\) are correct for all three degree ranges, including \(\Delta=1\).

The construction is polynomial because each item is selected at most once. Its application here always has \(A>0\); the algorithm separately handles \(U=0\).
