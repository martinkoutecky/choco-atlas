The continuous mirror question, as graded

Given a finite supported set of types \(T\), rational masses \(\mu_t\) summing to \(1\), mutually acceptable type pairs, and each type's weak ranking of acceptable partner types, compute a stable allocation maximizing matched-pair mass, or report that none exists. Let \(x_{ts}=x_{st}\geq 0\) be the mass of pairs between distinct types \(t,s\), and let \(x_{tt}\geq 0\) be the mass of same-type pairs; these consume \(x_{ts}\) units of each distinct type and \(2x_{tt}\) units of type \(t\). Set \(a_{ts}=x_{ts}\) for \(s\ne t\), \(a_{tt}=2x_{tt}\), and \(u_t=\mu_t-\sum_s a_{ts}\), requiring \(u_t\geq 0\). For each acceptable type \(s\), define \(b_t(s)=u_t+\sum_{r:\,s\succ_t r}a_{tr}\). Stability requires \(b_t(s)=0\) or \(b_s(t)=0\) for each acceptable pair of distinct types, and \(b_t(t)=0\) for each type that accepts same-type partners. Maximize \(\sum_{t<s}x_{ts}+\sum_t x_{tt}\); study the problem parameterized by tree-cut width of the graph on supported types, with an edge for every acceptable pair of distinct types.

Complexity classification

The optimization problem is \(\mathrm{NP}\)-hard, even when \(k\leq3\), no same-type pairs are acceptable, and a stable allocation is guaranteed to exist. Consequently, it is not fixed-parameter tractable with respect to \(k\), unless \(\mathrm{P}=\mathrm{NP}\).

More precisely, deciding whether a stable allocation has pair mass at least \(\tfrac12\) is \(\mathrm{NP}\)-complete, already under these restrictions. An exact general algorithm runs in \(2^m(m+\tau+L)^{O(1)}\) bit time.

The proof below permits only dyadic masses, so it applies whether “binary-rational” means dyadic rationals or arbitrary rationals encoded in binary.

1. The maximum possible objective

Write \(M(x)=\sum_{t<s}x_{ts}+\sum_t x_{tt}\). Each pair consumes twice its pair mass, including same-type pairs. Hence

\(2M(x)=\sum_t(\mu_t-u_t)=1-\sum_tu_t.\)

Thus \(M(x)\leq\tfrac12\), with equality precisely when every type is fully matched. Call such an allocation perfect.

We reduce positive binary-integer Subset Sum to the existence of a perfect stable allocation. Its input consists of positive integers \(w_1,\ldots,w_n,B\); the question is whether some \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in I}w_i=B\). We use its standard \(\mathrm{NP}\)-completeness.

2. The reduction

Types, edges, and preferences

Create two hub types \(R,S\), four types \(a_i,b_i,c_i,d_i\) for each item, and two padding types \(z,z'\).

For each item, the acceptable edges are

\(\{R,a_i\},\ \{a_i,b_i\},\ \{b_i,c_i\},\ \{c_i,d_i\},\ \{d_i,S\},\ \{a_i,c_i\}.\)

Additionally, \(\{z,z'\}\) is acceptable. There are no other acceptable pairs, including no same-type pairs.

The preferences, from best to worst, are:

| Type | Acceptable partners |
|---|---|
| \(R\) | All \(a_i\), tied |
| \(S\) | All \(d_i\), tied |
| \(a_i\) | \(b_i\succ c_i\succ R\) |
| \(b_i\) | \(a_i\sim c_i\) |
| \(c_i\) | \(b_i\succ a_i\succ d_i\) |
| \(d_i\) | \(c_i\succ S\) |
| \(z\) | \(z'\) only |
| \(z'\) | \(z\) only |

Every listed partner is strictly preferred to being unmatched. The acceptability relation is symmetric.

Positive dyadic masses

Let \(N=4\sum_iw_i+2B\), and choose a power of two \(H>N\), with \(H\leq2N\). Set

\(\mu_R=\mu_S=B/H,\)

\(\mu_{a_i}=\mu_{b_i}=\mu_{c_i}=\mu_{d_i}=w_i/H,\)

and

\(\mu_z=\mu_{z'}=(H-N)/(2H).\)

All masses are positive dyadic rationals, and their sum is

\(N/H+2(H-N)/(2H)=1.\)

The construction has \(m=6n+1\) and \(\tau=4n+4\). Its binary encoding length is \(O(n(\log H+\log n))\), polynomial in the Subset Sum input length.

3. Every perfect stable allocation encodes a subset

Suppose the constructed society admits a perfect stable allocation. For each item define scaled masses

\(p_i=Hx_{Ra_i},\qquad q_i=Hx_{a_ic_i},\qquad h_i=Hx_{d_iS}.\)

Full matching of \(a_i,b_i,c_i,d_i\), successively, gives

\(Hx_{a_ib_i}=w_i-p_i-q_i,\)

\(Hx_{b_ic_i}=p_i+q_i,\)

\(Hx_{c_id_i}=w_i-p_i-2q_i,\)

and

\(h_i=p_i+2q_i.\)

Full matching of both hubs gives \(\sum_ip_i=B\) and \(\sum_ih_i=B\). Subtracting these equalities yields

\(2\sum_iq_i=0.\)

Each \(q_i\) is nonnegative, so \(q_i=0\) for every item. Consequently,

\(Hx_{b_ic_i}=p_i,\qquad Hx_{c_id_i}=w_i-p_i,\qquad 0\leq p_i\leq w_i.\)

Now consider stability of the chord \(\{a_i,c_i\}\). The only partner strictly worse than \(c_i\) for \(a_i\) is \(R\). The only partner strictly worse than \(a_i\) for \(c_i\) is \(d_i\). Since the allocation is perfect,

\(b_{a_i}(c_i)=p_i/H,\qquad b_{c_i}(a_i)=(w_i-p_i)/H.\)

Stability requires one of these quantities to be zero. Therefore

\(p_i\in\{0,w_i\}.\)

Taking \(I=\{i:p_i=w_i\}\), the hub equation now gives

\(\sum_{i\in I}w_i=\sum_ip_i=B.\)

Thus every perfect stable allocation supplies a solution to Subset Sum. In particular, the proof excludes all fractional intermediate choices.

4. Every solution subset gives a perfect stable allocation

Conversely, suppose \(\sum_{i\in I}w_i=B\).

For each \(i\in I\), assign pair mass \(w_i/H\) to each of

\(\{R,a_i\},\quad\{b_i,c_i\},\quad\{d_i,S\}.\)

For each \(i\notin I\), assign pair mass \(w_i/H\) to each of

\(\{a_i,b_i\},\quad\{c_i,d_i\}.\)

Also assign \(x_{zz'}=\mu_z\), and set every remaining pair mass to zero.

Every gadget type and both padding types are fully matched. Each hub receives \(\sum_{i\in I}w_i/H=B/H\), so the allocation is perfect.

We check every class of acceptable edge:

  • Hub edges: Each hub is fully matched entirely within its single tie class. Thus \(b_R(a_i)=b_S(d_i)=0\) for every item.
  • Edges incident with \(b_i\): Type \(b_i\) is fully matched within its tie \(\{a_i,c_i\}\). Thus \(b_{b_i}(a_i)=b_{b_i}(c_i)=0\).
  • Edges \(\{c_i,d_i\}\): Type \(d_i\) is the worst acceptable partner of \(c_i\). Since \(c_i\) is fully matched, \(b_{c_i}(d_i)=0\).
  • Chords \(\{a_i,c_i\}\): If \(i\notin I\), all of \(a_i\) is assigned to \(b_i\), which it prefers to \(c_i\); hence \(b_{a_i}(c_i)=0\). If \(i\in I\), all of \(c_i\) is assigned to \(b_i\), which it prefers to \(a_i\); hence \(b_{c_i}(a_i)=0\).
  • Padding edge: Both endpoints are fully matched to their only acceptable partner.

These checks cover every acceptable edge. The allocation is stable.

We have therefore proved the equivalence:

A stable allocation of pair mass \(\tfrac12\) exists if and only if the Subset Sum instance is a yes-instance.

Stable allocations exist in every constructed instance

Independently of the Subset Sum answer, assign \(w_i/H\) to \(\{a_i,b_i\}\) and \(\{c_i,d_i\}\) for every item, match the padding pair fully, and leave both hubs unmatched.

The internal stability checks above still apply. The hub edges are protected by the gadget endpoints: \(a_i\) is assigned entirely to \(b_i\succ R\), and \(d_i\) entirely to \(c_i\succ S\). Hence this allocation is stable.

The reduction therefore proves hardness under the promise that stable allocations exist.

5. The graph has tree-cut width at most three

We use the standard definition: the width is the maximum adhesion and maximum number of vertices in a torso’s \(3\)-center. The \(3\)-center suppresses peripheral vertices of degree at most two while preserving bag vertices. See the [standard definition in Ganian–Korchemna](https://link.springer.com/article/10.1007/s00453-024-01241-4).

Construct a star-shaped decomposition with central bag \(\{R,S\}\). Its leaf bags are

\(A_i=\{a_i,b_i,c_i\},\qquad D_i=\{d_i\}\)

for every item, together with the padding bag \(\{z,z'\}\). These bags partition all supported types.

Adhesions. Exactly two edges leave \(A_i\): \(\{R,a_i\}\) and \(\{c_i,d_i\}\). Exactly two leave \(D_i\): \(\{c_i,d_i\}\) and \(\{d_i,S\}\). No edge leaves the padding bag. Thus every adhesion is at most two.

Central torso. Contracting leaf bags gives, for each item, a path \(R-A_i-D_i-S\). Both peripheral vertices on each path have degree two and are suppressed. The padding peripheral vertex is isolated and removed. Only the two central bag vertices remain in the \(3\)-center.

Leaf torsos. At an \(A_i\) leaf, contraction of the complement produces one peripheral vertex of degree two, attached to \(a_i\) and \(c_i\). Suppression leaves exactly the three bag vertices. At a \(D_i\) leaf, the complement likewise produces a degree-two peripheral vertex, leaving only its one bag vertex. The padding torso leaves its two bag vertices.

Thus the decomposition has width at most three, proving \(k\leq3\).

6. Exact algorithm and membership in \(\mathrm{NP}\)

For each of the \(m\) acceptable distinct edges \(\{t,s\}\), choose one endpoint whose blocking mass must vanish: impose either \(b_t(s)=0\) or \(b_s(t)=0\). For every acceptable same-type pair, additionally impose the mandatory equality \(b_t(t)=0\).

There are \(2^m\) such choices. Each choice gives a rational linear program consisting of allocation feasibility, the chosen equalities, and the objective \(M(x)\).

The equalities have a particularly simple implementation. Because all summands are nonnegative,

\(b_t(s)=0\)

is equivalent to \(u_t=0\) together with \(a_{tr}=0\) for every acceptable \(r\) satisfying \(s\succ_t r\). After consolidating repeated constraints, a branch has \(O(m+\tau)\) variables and constraints and polynomial encoding length.

Every feasible branch consists of stable allocations. Conversely, every stable allocation belongs to at least one branch, by choosing a protecting endpoint for each edge. Therefore solving all branches and retaining the largest objective gives an exact optimum, or establishes that no stable allocation exists.

Each branch is bounded: all pair masses and unmatched masses are bounded by the type capacities. Rational linear programming thus gives the running time

\(2^m(m+\tau+L)^{O(1)}\)

in bit operations.

For the decision version with a rational objective threshold, include its encoding length in \(L\). A nonempty branch satisfying the threshold has a rational vertex of polynomial encoding length. This follows from Cramer’s rule and determinant bounds: its constraint coefficients have bounded integer magnitude, and its right-hand sides have total binary length polynomial in \(L\). Such a vertex is a certificate whose feasibility, stability, and objective can be checked by exact rational arithmetic in polynomial time.

The decision problem belongs to \(\mathrm{NP}\). Together with the reduction, this proves \(\mathrm{NP}\)-completeness, including at threshold \(\tfrac12\) and \(k\leq3\).
