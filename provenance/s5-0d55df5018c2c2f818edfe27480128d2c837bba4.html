The continuous mirror question, as graded

Given finite type sets \(X,Y\), positive rational masses \(a_x,b_y\) summing to \(1\), complete strict rankings of \(Y\) for each \(x\in X\), and a rational target flow \(z\geq 0\) with row sums \(a_x\) and column sums \(b_y\), can one choose a complete strict reported ranking \(\rho_y\) of \(X\) for each \(y\in Y\) such that mass-proposing deferred acceptance produces exactly \(z\)? In mass deferred acceptance, unmatched mass proposes to its best type not yet rejected; each receiving type keeps the highest-ranked incoming mass up to its capacity and rejects the remainder. Output such reports if they exist, or determine that none exist.

Packaged proof task (what the prover saw — nothing else)

Given nonempty finite type sets \(X,Y\), each side's society is given by its support: its positive-mass types and their masses as binary rationals. Let \(\tau=|X|+|Y|\) be the total support size, not the number of possible rankings, \(m=|Y|\), and \(L\) the total input bit length; state running times in \(m,\tau,L\).
The input comprises positive masses \(a_x,b_y\) with \(\sum_x a_x=\sum_y b_y=1\), a complete strict ranking of \(Y\) for every \(x\), and a binary-rational matrix \(z\geq0\) with row sums \(a_x\) and column sums \(b_y\). A report consists of one complete strict ranking \(\rho_y\) of \(X\) for each \(y\), applying uniformly to that receiving type's entire mass; all pairs are acceptable.
Mass-proposing deferred acceptance starts with all mass unmatched. In each simultaneous round, each unmatched portion proposes to its highest-ranked receiving type that has not rejected that portion. Each receiving type pools new proposals with previously held mass, retains the highest-ranked mass up to capacity \(b_y\), and rejects the remainder. A boundary proposing type may be partially retained; only rejected portions advance, and held portions can be displaced later. Stop when all mass is held; the output records the held mass on every pair.

Is deciding whether some reports \((\rho_y)_{y\in Y}\) make mass-proposing deferred acceptance output exactly \(z\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard? In the polynomial-time case, can witnessing reports also be constructed in polynomial time?

For discrete one-to-one matching with complete strict lists, prescribed-output report construction takes \(O(n^2)\) time ([Kobayashi–Matsui](https://www.jstage.jst.go.jp/article/transinf/E92.D/2/E92.D_2_116/_pdf)).
For divisible bipartite stable allocation with both sides' rankings fixed, a polynomial-time algorithm computes the proposing side's optimal allocation ([Dean–Munshi](https://www.dcs.gla.ac.uk/research/algorithms/workshop/matchup.pdf)); this does not settle prescribed-output report construction. No result settling the exact mass report-construction problem was located.

Modeling choices made when packaging the task

  • Specified simultaneous proposal rounds to remove scheduling ambiguity.
  • Interpreted rejection as applying to a mass portion, allowing partial retention and later displacement of previously held mass.
  • Made explicit that each receiving type submits a single ranking applying uniformly to its entire mass, and that complete lists make every pair acceptable.
  • Defined m as the receiving support size, tau as the combined support size, and L as the total input bit length.

Result

The problem is solvable in polynomial time, and witnessing reports can also be constructed in polynomial time.

The criterion below uses only the proposing rankings and the locations of the positive entries of \(z\). The numerical masses matter through the promised feasibility of \(z\).

Write \(n=|X|=\tau-m\). The algorithm uses \(O(mn)\) elementary array and graph operations after reading the input. A conservative bit-complexity bound is \(O((L+m\tau)^2)\).

1. Definitions and the stability obstruction

Write \(y\succ_x v\) when proposing type \(x\) prefers \(y\) to \(v\). For each \(x\), define its worst target destination

\[ w_x=\text{the least-preferred }y\text{ with }z_{xy}>0. \]

This exists because \(a_x>0\). For each receiving type \(y\), define

\[ S_y=\{x:z_{xy}>0\},\qquad D_y=\{x:y\succ_x w_x\},\qquad B_y=S_y\cap D_y. \]

Thus \(S_y\) comprises its target holders, and \(D_y\) comprises the types having positive target mass somewhere worse than \(y\). In particular,

\[ x\in D_y \quad\Longleftrightarrow\quad \sum_{v:\,y\succ_x v}z_{xv}>0. \]

For fixed receiving reports, a feasible allocation \(v\) is stable if there are no types \(x,u\) and receiving types \(y,t\) such that \(v_{xt}>0\), \(y\succ_x t\), \(v_{uy}>0\), and \(y\) ranks \(x\) above \(u\). Such a configuration permits both sides to replace positive amounts of less-preferred mass.

Consequently, \(z\) is stable exactly when

\[ u\text{ is ranked above }x\text{ at }y \quad \text{for every }x\in D_y,\ u\in S_y\setminus\{x\}. \tag{1} \]

If two distinct types belong to \(B_y\), condition (1) requires each to rank above the other. Therefore,

\[ |B_y|\leq 1\qquad\text{for every }y \tag{2} \]

is necessary.

It is also sufficient for making \(z\) stable:

  • If \(B_y=\varnothing\), place all of \(S_y\) above all of \(D_y\).
  • If \(B_y=\{p\}\), place \(S_y\setminus\{p\}\) above \(p\), and place \(p\) above \(D_y\setminus\{p\}\).

Complete each order arbitrarily. These orders satisfy (1).

Condition (2) addresses stability alone. The next sections address whether deferred acceptance selects \(z\).

2. The deferred-acceptance property used in the proof

For allocations \(q,v\), say that \(q\) cumulatively dominates \(v\) for proposers if, for every type \(x\) and every prefix \(P\) of its preference list,

\[ \sum_{y\in P}q_{xy}\geq\sum_{y\in P}v_{xy}. \tag{3} \]

We need the following precise property of the question’s simultaneous procedure.

Lemma 1. For fixed strict receiving reports and rational masses, the procedure terminates in a stable allocation \(q\). Moreover, \(q\) cumulatively dominates every rational stable allocation under those reports.

Fixed-report termination and proposer optimality are established in [Dean–Munshi, Lemma 1](https://www.dcs.gla.ac.uk/research/algorithms/workshop/matchup.pdf). Here is a direct proof of the cumulative statement and its applicability to the specified procedure.

Proof. Fix a rational stable allocation \(v\). Choose a positive integer \(Q\) making all \(Qa_x,Qb_y,Qv_{xy}\) integral. This scaling is used only in the proof.

Replace type \(x\) by \(Qa_x\) unit residents, indexed consecutively. Every resident has \(x\)’s receiving preferences. Receiving type \(y\) becomes a hospital of integer quota \(Qb_y\). Its priority order first compares proposing types using its report, then compares residents of the same type by increasing index.

Lift \(Qv\) to a unit assignment \(M\) by assigning each type’s residents, in increasing index order, to consecutive blocks of destinations ordered from best to worst.

This unit assignment is stable. A blocking pair involving different proposing types would give a blocking configuration for \(v\). For residents of the same type, a resident assigned worse than \(y\) has a larger index than every resident of that type assigned to \(y\); hence \(y\) prefers its existing residents.

Run simultaneous resident-proposing deferred acceptance. No resident can be rejected by its hospital in \(M\). Indeed, consider the first round containing such a rejection, of resident \(i\) by hospital \(y=M(i)\). Hospital \(y\) retains its full quota of residents preferred to \(i\). Since \(M\) assigns \(i\) to \(y\), at least one retained resident \(j\) is assigned elsewhere in \(M\). Resident \(j\) prefers \(y\) to \(M(j)\): otherwise, reaching \(y\) would have required rejection by \(M(j)\) in an earlier round. Thus \(j,y\) block \(M\), a contradiction.

Each resident therefore finishes at a destination at least as good as its destination in \(M\). Counting residents assigned to each preference prefix gives (3).

The unit procedure terminates because each resident proposes to each hospital at most once. Complete lists and equality of total quotas and resident counts ensure that every resident is eventually held. Its output is stable: any hospital preferred to a resident’s final destination previously rejected that resident and thereafter holds only higher-priority residents.

Finally, aggregation of the unit procedure reproduces the question’s mass procedure round by round. At a hospital, the retained amount of each proposing type depends only on its total pooled amount and the ordering of types. Every rejected unit advances to the next receiving type on its type’s list. The additional within-type priorities therefore do not affect aggregated amounts. Aggregated stability follows because a blocking configuration between different types would give a unit blocking pair. This proves the lemma. \(\square\)

The construction algorithm below never performs this potentially large unit expansion.

3. A graph criterion

Assume (2). Construct a directed graph \(G\) whose vertex set is \(Y\).

For each \(y\):

  • If \(D_y=\varnothing\), give \(y\) no outgoing arcs.
  • If \(B_y=\{p\}\), give \(y\) the single arc \(y\to w_p\), labelled \(p\).
  • If \(B_y=\varnothing\) and \(D_y\neq\varnothing\), include an arc \(y\to w_x\), labelled \(x\), for every \(x\in D_y\).

Parallel arcs may be retained. Define

\[ R=\{y:D_y=\varnothing\}. \]

Theorem. Some complete strict receiving reports make mass-proposing deferred acceptance output \(z\) if and only if:

  • \(|B_y|\leq1\) for every \(y\); and
  • every vertex of \(G\) has a directed path to \(R\), allowing a path of length zero.

4. Necessity: a cycle gives a stable improvement

Suppose reports produce \(z\). Lemma 1 implies that \(z\) is stable, so condition (2) holds.

For every \(y\) with \(D_y\neq\varnothing\), let \(h_y\) be its highest-ranked member of \(D_y\).

If \(B_y=\{p\}\), stability forces \(p\) above every other member of \(D_y\), by (1). Thus \(h_y=p\). In all cases,

\[ y\to w_{h_y} \]

is an allowed arc of \(G\).

Suppose some vertex cannot reach \(R\). Let \(U\) be the nonempty set of all such vertices. Every allowed arc from \(U\) stays in \(U\), and every vertex in \(U\) has nonempty \(D_y\). Following the selected arcs \(y\to w_{h_y}\) therefore produces a directed cycle. Write its distinct vertices as \(y_1,\ldots,y_k\), with cyclic indexing, and set \(x_i=h_{y_i}\). Then

\[ w_{x_i}=y_{i+1}, \qquad y_i\succ_{x_i}y_{i+1}. \tag{4} \]

The types \(x_i\) are distinct because their worst destinations \(y_{i+1}\) are distinct. Choose

\[ 0<\varepsilon<\min_i z_{x_i,y_{i+1}}. \]

Form \(v\) by moving \(\varepsilon\) units of each \(x_i\) from \(y_{i+1}\) to \(y_i\). Rows and columns retain their sums: each cycle receiver gains and loses exactly \(\varepsilon\).

Every original positive entry remains positive. Moreover, each affected type retains positive mass at its original worst destination, and its additional destination is better. Consequently, its worst positive destination remains \(w_x\), so the demander sets remain exactly \(D_y\).

We now check stability of \(v\). Original holders satisfy (1), because \(z\) was stable. The only possible new holder at \(y_i\) is \(h_{y_i}\), which ranks above every other member of \(D_{y_i}\). It therefore also satisfies (1). Hence \(v\) is stable under the same reports.

But (4) means each affected proposer strictly improves: its cumulative allocation increases by \(\varepsilon\) at prefixes containing \(y_i\) but not \(y_{i+1}\). Thus \(z\) does not cumulatively dominate the rational stable allocation \(v\), contradicting Lemma 1.

Every vertex must therefore reach \(R\).

5. Sufficiency and explicit reports

Suppose the two graph conditions hold. Let \(d(y)\) be the shortest directed-path distance from \(y\) to \(R\).

For each \(y\notin R\), choose a labelled arc \(y\to w_{h_y}\) satisfying

\[ d(w_{h_y})=d(y)-1. \tag{5} \]

When \(B_y=\{p\}\), necessarily \(h_y=p\).

Construct reports as follows:

  • If \(B_y=\varnothing\) and \(D_y\neq\varnothing\), list \(S_y\) first, then \(h_y\), then \(D_y\setminus\{h_y\}\), then all remaining types.
  • If \(B_y=\{p\}\), list \(S_y\setminus\{p\}\), then \(p\), then \(D_y\setminus\{p\}\), then all remaining types.
  • If \(D_y=\varnothing\), list \(S_y\) first, then all remaining types.

Within each block use any fixed order. These are complete strict rankings. They satisfy (1), making \(z\) stable, and each selected \(h_y\) is highest-ranked in \(D_y\).

Let \(q\) be their deferred-acceptance output. Lemma 1 says that \(q\) is stable and cumulatively dominates \(z\).

We establish two consequences.

Gains can occur only for target demanders

Cumulative dominance at the prefix ending at \(w_x\) implies that \(q\) assigns no \(x\)-mass below \(w_x\): that prefix already contains all \(a_x\) units in \(z\).

Dominance at the prefix strictly above \(w_x\), together with the row sum, then gives

\[ q_{x,w_x}\leq z_{x,w_x}. \]

Therefore,

\[ q_{xy}>z_{xy}\quad\Longrightarrow\quad x\in D_y. \tag{6} \]

Fixing the terminal entry fixes the entire row

Suppose

\[ q_{x,w_x}=z_{x,w_x}>0. \tag{7} \]

If \(x\)’s row differed, equal row sums would yield a destination \(y\neq w_x\) with \(q_{xy}<z_{xy}\). Necessarily \(y\succ_x w_x\).

Equal column sums at \(y\) yield some \(u\) with \(q_{uy}>z_{uy}\). By (6), \(u\in D_y\). Since \(x\in S_y\) and \(u\neq x\), stability of \(z\) forces \(y\) to rank \(x\) above \(u\).

In \(q\), type \(x\) still has positive mass at \(w_x\), which is worse than \(y\), while \(y\) holds positive \(u\)-mass. Thus \(x,y\) block \(q\), a contradiction. Consequently,

\[ q_{x,w_x}=z_{x,w_x} \quad\Longrightarrow\quad q_{xv}=z_{xv}\text{ for every }v. \tag{8} \]

Induction on distance

We prove that every column of \(q\) equals its column of \(z\).

For \(d(y)=0\), we have \(D_y=\varnothing\). By (6), no entry in column \(y\) can increase. Equal column sums therefore force equality throughout that column.

Now suppose \(d(y)>0\), and columns at smaller distance are fixed. By (5), column \(w_{h_y}\) is fixed. In particular, its positive terminal entry for \(h_y\) is fixed, so (8) fixes the entire row of \(h_y\).

If column \(y\) differed, some type \(u\) would gain there. By (6), \(u\in D_y\), and \(u\neq h_y\) because \(h_y\)’s row is fixed. The report ranks \(h_y\) above \(u\). Also, \(h_y\)’s unchanged row contains positive mass at \(w_{h_y}\), worse than \(y\). Hence \(h_y,y\) block \(q\), again a contradiction.

Column \(y\) is therefore fixed. Induction gives \(q=z\), proving sufficiency and completing the theorem.

6. Algorithm and complexity

The theorem gives the following algorithm:

  • Find \(w_x\) for every proposing type.
  • Compute \(S_y,D_y,B_y\), rejecting if any \(|B_y|>1\).
  • Build the labelled graph \(G\).
  • Search from \(R\) in the reversed graph. Reject if some vertex is unreached.
  • Use the search distances to select the labels \(h_y\), and output the reports from Section 5.

There are \(m\) graph vertices and at most \(mn\) labelled arcs. Rank tables, set construction, graph search, and report construction each require \(O(mn)\) elementary operations.

Thus the algorithm takes \(O(L+m\tau)\) word operations, including input scanning, with a conservative implementation bound of \(O((L+m\tau)^2)\) bit operations. The reports contain \(mn\) type identifiers.

No deferred-acceptance simulation, rational optimization, or unit expansion is needed. Both the decision problem and witnessing-report construction are polynomial-time solvable in \(m,\tau,L\).
