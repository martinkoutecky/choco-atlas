The continuous mirror question, as graded

Given finite types \(T\), rational masses \(\mu_t\), strict rankings over \(T\cup\{\bot\}\), and a feasible typed roommate assignment with pair masses \(x_{tr}\) and singleton masses \(s_t\), compute the exact rational mass \(B\) of type/current-partner cells with a reciprocal-preference witness. Set \(d_{z\bot}=s_z\), \(d_{zz}=2x_{zz}\), and \(d_{zv}=x_{zv}+x_{vz}\) for \(z\ne v\). Let \(P\) contain both orientations of every positive-mass pair team and \((t,\bot)\) for each positive singleton mass. Return \(B=\sum_{z,v}d_{zv}\,\mathbf 1[\exists(t,r)\in P:\ z\succ_t r\ \land\ t\succ_z v]\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; set \(m=|T|=\tau\).
Each type \(t\) has a strict total ranking \(\succ_t\) over \(T\cup\{\bot\}\), where \(\bot\) means being alone and the label \(t\) means a distinct teammate of the same type. Every pair of types is feasible.
The input includes nonnegative binary-rational pair-team masses \(x_{tr}\) and singleton masses \(s_t\). For distinct types, \(x_{tr}\) and \(x_{rt}\) are additive portions of the same unordered pair-team category, not duplicate records.
Define \(d_{z\bot}=s_z\), \(d_{zz}=2x_{zz}\), and \(d_{zv}=x_{zv}+x_{vz}\) for \(z\ne v\); feasibility requires \(\sum_{v\in T\cup\{\bot\}}d_{zv}=\mu_z\) for every \(z\).
Let \(P=\{(t,r)\in T^2:d_{tr}>0\}\cup\{(t,\bot):s_t>0\}\); thus both orientations of each positive pair-team category are included.
The required output is the exact rational \(B=\sum_{z\in T}\sum_{v\in T\cup\{\bot\}}d_{zv}\,\mathbf 1[\exists(t,r)\in P:\ z\succ_t r\ \land\ t\succ_z v]\). Each cell contributes once, regardless of its number of witnesses. Let \(L\) be the total binary input length.

Result

Exact computation of \(B\) is polynomial-time solvable. After indexing the types, the algorithm uses \(O(m^2)\) rank comparisons and arithmetic operations, with polynomial bit complexity in \(L\). This holds for every supplied feasible outcome.

1. Compressing the witness condition

Write \(U=T\cup\{\bot\}\). For each \(t\in T\), define the rank function \(\rho_t:U\to\{1,\ldots,m+1\}\), with smaller ranks indicating better alternatives. Thus
\( a\succ_t b \iff \rho_t(a)<\rho_t(b). \)

Define
\( S_t=\{r\in U:d_{tr}>0\}. \)
By the definition of \(P\), we have \((t,r)\in P\) exactly when \(r\in S_t\). Moreover, feasibility and \(\mu_t>0\) imply \(S_t\ne\varnothing\).

Let
\( w_t=\max_{r\in S_t}\rho_t(r). \)
This is the rank of the worst alternative receiving positive mass in row \(t\).

Lemma. For every \(t,z\in T\),
\( \exists r\in U:\ (t,r)\in P\ \land\ z\succ_t r \iff \rho_t(z)<w_t. \)

Proof. If such an \(r\) exists, then
\( \rho_t(z)<\rho_t(r)\le w_t. \)
Conversely, the maximum defining \(w_t\) is attained by some \(r_*\in S_t\). If \(\rho_t(z)<w_t\), then \(z\succ_t r_*\), and \((t,r_*)\in P\). This proves both directions.

For each \(z\in T\), now define
\( C_z=\{t\in T:\rho_t(z)<w_t\} \)
and
\( a_z=\min\bigl(\{\rho_z(t):t\in C_z\}\cup\{m+2\}\bigr). \)

For every \(v\in U\), the lemma gives
\( \begin{aligned} &\exists(t,r)\in P:\ z\succ_t r\ \land\ t\succ_z v\\ &\quad\iff \exists t\in C_z:\rho_z(t)<\rho_z(v)\\ &\quad\iff a_z<\rho_z(v). \end{aligned} \)

For the last equivalence, if \(C_z\) is nonempty, its minimum rank is attained. If \(C_z\) is empty, then \(a_z=m+2\), exceeding every possible \(\rho_z(v)\), so both sides are false.

Consequently, the exact target is
\( B=\sum_{z\in T}\ \sum_{\substack{v\in U\\\rho_z(v)>a_z}}d_{zv}. \)

This expression includes each cell once, regardless of how many witnesses it has.

2. Algorithm and correctness

The algorithm is:

  • Construct every rank table \(\rho_t\) and every mass \(d_{zv}\), using precisely the supplied formulas, including \(d_{zz}=2x_{zz}\) and \(d_{zv}=x_{zv}+x_{vz}\) for distinct types.
  • Scan each row to compute \(w_t\).
  • Initialize every \(a_z=m+2\). For each ordered pair \((t,z)\in T^2\), if \(\rho_t(z)<w_t\), replace \(a_z\) by \(\min(a_z,\rho_z(t))\).
  • Sum \(d_{zv}\) over exactly those cells satisfying \(\rho_z(v)>a_z\).

The equivalences proved above establish that step 4 uses exactly the indicator in the definition of \(B\). Hence the returned value is correct.

There are \(m(m+1)\) cells and \(m^2\) ordered type pairs. Each step therefore uses \(O(m^2)\) rank comparisons and arithmetic operations. Singleton outcomes and same-type teammates are included directly in these scans.

3. Exact arithmetic and bit complexity

Represent each supplied \(x_{tr}\) and \(s_t\) as a numerator divided by a positive denominator, both encoded in binary. The argument also covers dyadic binary rationals.

Let \(D\) be the product of these input denominators. Since their total encoding length is at most \(L\), the binary length of \(D\) is \(O(L)\). Every \(Dx_{tr}\) and \(Ds_t\) is an integer, computable by exact integer division and multiplication.

Construct the integer cell masses
\( \begin{aligned} A_{z\bot}&=Ds_z,\\ A_{zz}&=2Dx_{zz},\\ A_{zv}&=Dx_{zv}+Dx_{vz}\qquad(z\ne v). \end{aligned} \)
Then \(A_{zv}=Dd_{zv}\). The algorithm computes
\( N=\sum_{z\in T}\ \sum_{\substack{v\in U\\\rho_z(v)>a_z}}A_{zv} \)
and returns \(N/D\), optionally reduced by their greatest common divisor.

Nonnegativity and feasibility imply
\( \sum_{z\in T}\sum_{v\in U}d_{zv} =\sum_{z\in T}\mu_z=1. \)
Thus \(\sum_{z,v}A_{zv}=D\), and every partial sum used to construct \(N\) lies between \(0\) and \(D\). All these integers have \(O(L)\) bits. Integer multiplication, division, addition, comparison, and greatest-common-divisor computation have polynomial bit complexity. Together with the \(O(m^2)\) scans, this proves polynomial running time in \(m,\tau,L\), where \(m=\tau\).

4. Scope

The cited [discrete result, Theorem 1](https://arxiv.org/pdf/2204.04251) concerns an upper bound on agents who can gain by misreporting. The proof here independently settles exact evaluation of the specified \(B\) from supplied masses; it makes no additional claim that \(B\) equals the mass of agents who can actually benefit from strategic misreporting.
