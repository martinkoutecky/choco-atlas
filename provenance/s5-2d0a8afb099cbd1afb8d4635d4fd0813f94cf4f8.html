The proof applies the established fractional SOSP hardness theorem through an exact, approximation-preserving reformulation.

1. Exact reformulation

For a fixed feasible decision \(x\), define \(q_t=p_tx_t\) and the realized set \(R=\{t:Z_t=1/n\}\). Its membership indicators are independent, with probabilities \(q_t\).

By definition, the multilinear extension satisfies \(F_f(\mathbf{1}_S)=f(S)\) for every set \(S\). Since \(nZ=\mathbf{1}_R\), we obtain

\[ G(Z)=F_f(nZ)=f(R), \qquad \mathbb{E}[G(Z)]=F_f(q). \]

The mass constraint is equivalent to

\[ \sum_{t=1}^n\frac{p_tx_t}{n}\le\frac{k}{n} \quad\Longleftrightarrow\quad \sum_{t=1}^n q_t\le k. \]

Furthermore, \(x_t\in[0,1]\) implies \(q_t\in[0,p_t]\). Conversely, any vector satisfying these bounds is represented by \(x_t=q_t/p_t\) when \(p_t>0\), and by \(x_t=0\) when \(p_t=0\); in the latter case the bounds force \(q_t=0\).

Consequently,

\[ \mathrm{OPT} = \max\left\{ F_f(q): 0\le q_t\le p_t,\ \sum_{t=1}^n q_t\le k \right\}. \]

This is equality of both feasible objectives and optimum values. For randomized outputs, the equality holds conditional on every output and hence also after averaging over algorithmic randomness.

2. Application of the established theorem

The cited full version explicitly formulates fractional SOSP using independent inclusion probabilities \(q_t\in[0,p_t]\), with \(\sum_tq_t\le k\). Its Theorem 2.9 establishes that any constant approximation factor strictly exceeding

\[ \rho(k)= \frac{1-e^{-k/2}} {1-(k/2+1)e^{-k}} \]

implies a polynomial-time Planted Clique algorithm succeeding with high probability. The theorem allows fractional budgets. These are precisely the formulation and hardness result stipulated in the task. [Definition 2.6 and Theorem 2.9](https://arxiv.org/pdf/1507.02351)

Given a fractional SOSP instance on \(n\) elements, construct the mass instance with exactly \(n\) listed types, masses \(1/n\), budget \(k/n\), and the same probabilities and value oracle. Run the proposed mass approximation and return \(q_t=p_tx_t\).

Section 1 proves that this procedure returns a feasible fractional SOSP solution with exactly the same approximation factor. The stated theorem therefore supplies the requested Planted Clique implication.

3. Input size and small probabilities

The reduction creates exactly \(\tau=n\) support entries. Encoding \(1/n\) and \(k/n\) requires only polynomially many bits, and multiplication or division of binary-encoded rationals has polynomial bit complexity. The value oracle is reused directly, so its answers and their bit lengths are unchanged. There is no additional candidate parameter.
