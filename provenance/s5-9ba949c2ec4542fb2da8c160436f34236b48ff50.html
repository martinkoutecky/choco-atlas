The continuous mirror question, as graded

Given a finite agenda \(\mathcal A\) and a finite support \(\mathcal T\) of complete reflexive pairwise relations with positive rational masses \(\mu_R\) summing to \(1\), find an ordered partition \((X,Y)\) minimizing \(\sum_{R\in\mathcal T}\mu_R\left|\{(a,b)\in\mathcal A^2:\mathbf 1[(a,b)\in R]\ne\mathbf 1[(a,b)\in O_{X,Y}]\}\right|\), where \(O_{X,Y}\) is the DWO with \(X\) ranked above \(Y\) and ties within each block.

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal A\) be a finite agenda with \(m=|\mathcal A|\geq 1\). A society is given by its support: a list \(\mathcal T\) of \(\tau\) complete reflexive binary relations on \(\mathcal A\), each encoded explicitly and assigned a positive binary rational mass \(\mu_R\), with \(\sum_{R\in\mathcal T}\mu_R=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total binary input length. Transitivity is not required.
An admissible output is an ordered pair \((X,Y)\) of disjoint subsets with \(X\cup Y=\mathcal A\); either subset may be empty. Its dichotomous weak order is \(O_{X,Y}=(X\times X)\cup(Y\times Y)\cup(X\times Y)\).
Find any admissible output minimizing \(D(X,Y)=\sum_{R\in\mathcal T}\mu_R|R\mathbin{\triangle}O_{X,Y}|\), where the symmetric difference counts ordered pairs. No tie-breaking among minimizers is prescribed.

Is this exact minimization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For an explicitly listed finite electorate, minimizing total ordered-pair disagreement over dichotomous weak orders is polynomial-time solvable, including complete reflexive inputs ([Chen](https://arxiv.org/html/2603.22814v1)).

Result

The exact minimization problem is solvable in polynomial time in \(m,\tau,L\). It reduces to a minimum cut with nonnegative integer capacities of polynomial bit length.

[Chen’s paper](https://arxiv.org/html/2603.22814v1) establishes polynomial-time solvability for explicitly listed electorates using minimum cuts. The proof below handles binary-rational masses directly, without expanding them into voters.

1. Compute the contribution of each pair

Label the alternatives \(1,\ldots,m\). For distinct \(i,j\), define the strict-preference mass

\(a_{ij}=\sum_{\substack{R\in\mathcal T\\(i,j)\in R,\ (j,i)\notin R}}\mu_R.\)

For \(i<j\), define the indifference mass

\(t_{ij}=\sum_{\substack{R\in\mathcal T\\(i,j)\in R,\ (j,i)\in R}}\mu_R.\)

Completeness means that each input relation contains at least one of \((i,j)\) and \((j,i)\). Thus these three possibilities exhaust the support, so

\(a_{ij}+a_{ji}+t_{ij}=1,\qquad t_{ij}\geq 0.\)

Represent an admissible output by \(x\in\{0,1\}^m\), where \(x_i=1\) means \(i\in X\), and \(x_i=0\) means \(i\in Y\). Every such vector gives an admissible output, including outputs with an empty subset.

For \(i<j\), let \(E_{ij}(x_i,x_j)\) be the expected disagreement on the two ordered pairs \((i,j)\) and \((j,i)\). Its values are:

| Output labels | Pair contribution |
|---|---|
| \(x_i=x_j\) | \(a_{ij}+a_{ji}\) |
| \((x_i,x_j)=(1,0)\) | \(2a_{ji}+t_{ij}\) |
| \((x_i,x_j)=(0,1)\) | \(2a_{ij}+t_{ij}\) |

Indeed, when the alternatives are tied, the output contains both ordered pairs. A strict input disagrees on exactly one, and an indifferent input agrees on both. When \(i\in X,j\in Y\), the output contains only \((i,j)\): an opposite strict input disagrees on both ordered pairs, and an indifferent input disagrees on one. The reverse case is symmetric.

Consequently, for every assignment,

\(E_{ij}(x_i,x_j)=a_{ij}+a_{ji}+t_{ij}|x_i-x_j|+(a_{ji}-a_{ij})(x_i-x_j).\)

This identity follows by substituting the three cases in the table.

2. Separate vertex and cut terms

Define

\(C=\sum_{i<j}(a_{ij}+a_{ji}),\qquad h_i=\sum_{j\neq i}(a_{ji}-a_{ij}).\)

Reflexivity ensures that diagonal ordered pairs never contribute disagreement. Summing the preceding identity over unordered pairs therefore gives

\(D(x)=C+\sum_{i=1}^{m}h_i x_i+\sum_{i<j}t_{ij}|x_i-x_j|.\)

To verify the vertex coefficients explicitly: a pair \(i<j\) contributes \(a_{ji}-a_{ij}\) to the coefficient of \(x_i\), and its negative, \(a_{ij}-a_{ji}\), to the coefficient of \(x_j\). Collecting these contributions yields precisely \(h_i\).

The crucial property is that every coefficient \(t_{ij}\) is nonnegative. No transitivity assumption was used.

3. Construct a minimum-cut instance

Construct a directed network with source \(s\), sink \(z\), and one vertex for each alternative.

For each \(i<j\), add arcs \(i\to j\) and \(j\to i\), each of capacity \(t_{ij}\). For each alternative \(i\):

  • If \(h_i\geq 0\), add \(i\to z\) of capacity \(h_i\).
  • If \(h_i<0\), add \(s\to i\) of capacity \(-h_i\).

All capacities are nonnegative. Zero-capacity arcs may be omitted.

For an \(s\)-\(z\) cut \((S,T)\), assign \(x_i=1\) precisely when \(i\in S\). The two arcs associated with a pair contribute \(t_{ij}|x_i-x_j|\): exactly one crosses from \(S\) to \(T\) when the labels differ, and neither crosses when they agree.

The vertex arc contributes \(h_i x_i\) when \(h_i\geq 0\). When \(h_i<0\), it contributes

\((-h_i)(1-x_i)=h_i x_i-h_i.\)

Thus, writing \(K=\sum_i\max\{0,-h_i\}\), the cut capacity \(W(S,T)\) satisfies

\(W(S,T)=K+\sum_i h_i x_i+\sum_{i<j}t_{ij}|x_i-x_j|.\)

Equivalently,

\(D(x)=C-K+W(S,T).\)

Every assignment corresponds to exactly one cut with \(s\in S,z\in T\). Since \(C-K\) is independent of the assignment, a minimum cut produces a global minimizer of \(D\).

4. Exact arithmetic and polynomial complexity

Write each input mass as \(\mu_R=p_R/q_R\), with positive integers \(p_R,q_R\) encoded in binary. Set

\(Q=\prod_{R\in\mathcal T}q_R.\)

Its bit length is at most \(1+\sum_R\log_2 q_R\), hence is \(O(L)\). Compute the integer weights

\(w_R=p_R(Q/q_R).\)

They satisfy \(\sum_R w_R=Q\). Using these weights, compute \(Qa_{ij}\), \(Qt_{ij}\), and \(Qh_i\) directly as integer sums. Multiply every network capacity by \(Q\). This preserves all minimizing cuts and makes all capacities integers.

The network has \(m+2\) vertices and at most \(m(m-1)+m\) arcs. Since \(a_{ij},t_{ij}\in[0,1]\) and \(|h_i|\leq m-1\), each integer capacity has bit length \(O(L+\log(m+1))\).

Computing the pair statistics takes \(O(\tau m^2)\) integer additions after computing the weights. All integers involved have polynomial bit length. A standard exact minimum-cut algorithm, such as Edmonds–Karp via maximum flow, uses \(O(VE^2)\) augmentations and polynomial-bit arithmetic here. Its total bit complexity is therefore polynomial in \(m,\tau,L\), independent of the numerical magnitude of \(Q\).

Finally, return \(X=S\cap\mathcal A\) and \(Y=T\cap\mathcal A\). For \(m=1\), the same construction has no positive-capacity arcs, and either admissible output has zero disagreement.

Conclusion

The reduction computes an exact minimizer in polynomial time for the stated binary-rational support encoding. Empty subsets, arbitrary ties among minimizers, and nontransitive complete inputs are all covered.
