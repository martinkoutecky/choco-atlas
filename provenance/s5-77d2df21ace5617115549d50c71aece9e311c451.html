The continuous mirror question, as graded

Given finitely many voter types \(T\), rational masses \(\mu_t \ge 0\) summing to \(1\), nonnegative rational per-voter weights \(w_t\), and a quota \(q\) with \(0 < q \le V := \sum_{t \in T} \mu_t w_t\), decide whether every yea-mass vector \(x \in \prod_{t \in T}[0,\mu_t]\) with \(\sum_t w_t x_t < q\) has a winning complement, \(\sum_t w_t(\mu_t-x_t) \ge q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a nonnegative binary-rational per-voter weight \(w_t\). The binary-rational quota satisfies \(0<q\le V:=\sum_{t\in T}\mu_t w_t\).
A coalition is any real vector \(x\in\prod_{t\in T}[0,\mu_t]\); it wins exactly when \(\sum_t w_t x_t\ge q\). Its complement is \(\mu-x\). The game is strong when every losing coalition has a winning complement.
Let \(L\) be the total input bit length. There are \(m=2\) alternatives, passage and the status quo; state running times in \(m,\tau,L\).

Is deciding strongness for this continuous weighted voting problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For discrete voters with a supplied integer quota and nonnegative integer weights, deciding strongness is \(\mathrm{coNP}\)-complete ([Freixas et al.](https://arxiv.org/abs/0803.0404)).
The continuous problem is already covered by the strongness characterization for continuous threshold games in [Kurz, Measuring Voting Power in Convex Policy Spaces](https://arxiv.org/pdf/1312.5936), which yields polynomial-time recognition. Thus the requested target is already settled.

  • Specify that the quota is a binary rational, making the computational input finite.

Result

Deciding strongness is in \(\mathrm{P}\). More precisely, the game is strong if and only if
\[ 2q\le V=\sum_{t\in T}\mu_t w_t. \]
For the prescribed \(m=2\), recognition takes \(O(\tau L^2)\) bit operations using elementary integer arithmetic.

Proof of the characterization

Define the weight of a coalition \(x\) by \(W(x)=\sum_{t\in T}w_t x_t\). By the definition of the complement,
\[ W(\mu-x)=\sum_{t\in T}w_t(\mu_t-x_t)=V-W(x). \]
Moreover, \(\mu-x\) is feasible whenever \(x\) is feasible, since \(0\le x_t\le\mu_t\) implies \(0\le\mu_t-x_t\le\mu_t\).

Sufficiency. Suppose \(2q\le V\), and let \(x\) be any losing coalition. Losing means \(W(x)<q\), because equality with the quota is winning. Consequently,
\[ W(\mu-x)=V-W(x)>V-q\ge q. \]
Thus the complement of every losing coalition wins, so the game is strong. This argument includes the boundary case \(2q=V\).

Necessity. Suppose \(2q>V\). Choose \(x_t=\mu_t/2\) for every \(t\in T\). This is a feasible coalition, and its complement equals itself. Both therefore have weight
\[ W(x)=W(\mu-x)=\frac12\sum_{t\in T}\mu_t w_t=\frac V2<q. \]
A losing coalition has a losing complement, so the game is not strong.

Together, these implications prove the characterization.

Exact algorithm and bit complexity

Compute \(V\) exactly and return “strong” precisely when \(V\ge 2q\). The algorithm processes only the supplied \(\tau\) support entries.

Here is an explicit implementation that also handles arbitrary rationals encoded by binary numerators and denominators. Write \(\mu_t=a_t/b_t\), \(w_t=c_t/d_t\), and \(q=e/f\), with positive denominators. Set \(A_t=a_tc_t\) and \(B_t=b_td_t\).

Maintain the partial sum as an unreduced fraction \(N/D\), initially \(N=0\), \(D=1\). For each support entry, update simultaneously:
\[ N_{\mathrm{new}}=NB_t+A_tD,\qquad D_{\mathrm{new}}=DB_t. \]
After all entries, return “strong” if and only if \(fN\ge 2eD\). Positive denominators justify this exact integer comparison.

To bound intermediate sizes, after processing a subset \(S\) of entries the maintained integers satisfy
\[ D=\prod_{t\in S}B_t,\qquad N=\sum_{t\in S}A_t\prod_{s\in S\setminus\{t\}}B_s. \]
Each product uses input integers whose total binary length is at most \(L\), so each product has \(O(L)\) bits. Summing at most \(\tau\) products adds at most \(O(\log\tau)\) bits. Since the explicitly supplied list has \(\tau\le L\), all intermediate integers have \(O(L)\) bits.

Each update uses a constant number of integer operations, costing \(O(L^2)\) bit operations with schoolbook multiplication. There are \(\tau\) updates and one final comparison. Hence the bound is \(O(\tau L^2)\), or \(O(m+\tau L^2)\) with \(m=2\). No dependence on the number of possible types is required.

Connection to the cited characterization

The hypotheses permit normalization: \(V>0\), and every \(\mu_t>0\). Put \(y_t=x_t/\mu_t\), \(\alpha_t=\mu_tw_t/V\), and \(Q=q/V\). Then \(y\in[0,1]^\tau\), the nonnegative weights \(\alpha_t\) sum to \(1\), and \(0<Q\le1\). Winning becomes \(\sum_t\alpha_ty_t\ge Q\), while complementation becomes \(y\mapsto1-y\).

This is a continuous threshold game. Kurz’s Lemma 4.16 states that such a normalized game is strong exactly when \(Q\le1/2\), agreeing with the direct proof above. [Kurz, *Measuring Voting Power in Convex Policy Spaces*, Lemma 4.16](https://arxiv.org/pdf/1312.5936#page=13).

The midpoint coalition used in the necessity proof is always available in this continuous model; a discrete electorate need not admit such a coalition.
