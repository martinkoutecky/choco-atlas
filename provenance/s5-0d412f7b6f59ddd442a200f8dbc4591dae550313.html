The continuous mirror question, as graded

Given a finite set of seat classes G, rational type proportions μ over a finite set T of strict ranking templates, and rational per-capita supplies q_g with ∑_g q_g > 1, consider every admissible population size N for which Nμ_t and Nq_g are integers. Each type template ranks the Nq_g indivisible seat copies by a fixed class priority and within-class copy order; one tagged student has a specified ranking and a fixed finite target set of seat copies. Under the paper’s all-reporting protocol, is there an N_0 such that for every admissible N ≥ N_0 the tagged student has a well-defined reporting strategy that secures every target seat for every lottery outcome, when the other students report truthfully?

Packaged proof task (what the prover saw — nothing else)

Input consists of a nonempty set of seat classes \(G\), with \(m=|G|\), positive rational supplies \(q_g\) satisfying \(\sum_g q_g>1\), and strict ranking templates for the truthful types and one tagged student. Each template orders classes strictly and ranks copies within each class by increasing copy index, placing every copy of a preferred class above every copy of a less preferred class.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. A target set \(S\) is an explicit finite list of distinct copies \((g,j)\), with positive indices encoded in binary; write \(s=|S|\) and let \(L\) be the total input bit length.
For an admissible positive integer \(N\), all \(N\mu_t\) and \(Nq_g\) are integers, all targets exist, and \(N\sum_gq_g\ge N+1\). There are \(N\mu_t\) truthful students of each type, one additional tagged student, and copies \((g,j)\) for \(1\le j\le Nq_g\).
In each round every student simultaneously reports one remaining copy; truthful students report their highest-ranked remaining copy. Every reported copy is allocated to one of its reporters by a fair lottery and removed. Winners and losers alike continue reporting until no copies remain; students may receive multiple copies.
A tagged student's strategy is a predetermined sequence of distinct copies, reporting its next entry each round. It is well-defined if each entry remains available when reported and no copies remain after its last round, for every lottery outcome; it succeeds if every outcome gives the tagged student all of \(S\).
Is deciding whether \(\exists N_0\ \forall\text{ admissible }N\ge N_0\ \exists\text{ a well-defined successful strategy}\) solvable in polynomial time in \(m,\tau,s,L\), or is it NP-hard?
For explicitly listed finite populations and copies, guaranteed acquisition of a target set under this protocol is decidable in polynomial time in the numbers of students and copies ([Huang, Lou and Wen](https://arxiv.org/pdf/1405.6578)). No result settling the exact eventual-success problem above was located.

Modeling choices made when packaging the task

  • Normalized the positive type masses to sum to one.
  • Interpreted N as the size of the truthful population, with the tagged student additional, since no support type for the tagged student was specified.
  • Made the unspecified within-class copy order the common increasing-index order, so each ranking template has a finite explicit encoding.
  • Restricted seat classes to positive supplies; zero-supply classes contain no copies and can be omitted.
  • Represented fixed target copies by class-index pairs with binary indices, independent of N; admissibility requires their existence.
  • Carried over the finite model's requirement that the number of copies be at least the number of students.
  • Used the discrete definition of strategy: a predetermined sequence of distinct reports, completed through exhaustion, rather than a contingent strategy; strategies may differ with N.

Result

The eventual-success problem is polynomial-time solvable. In fact, it has an explicit criterion involving only the first-ranked classes of the supported truthful types and the target indices.

The cited finite-population result appears as Theorem 1 and Algorithm 1 of [Huang, Lou and Wen](https://arxiv.org/pdf/1405.6578). The proof below establishes the eventual criterion directly.

Definitions and decision criterion

Let \(A\subseteq G\) be the set of classes ranked first by at least one supported truthful type. Every admissible population contains a truthful student of each supported type: \(N\mu_t\) is a positive integer.

For each target \(x=(g,j)\) with \(g\in A\), define
\(b(x)=j-1-\left|\{(g,i)\in S:i<j\}\right|\).

Thus \(b(x)\) counts the copies of class \(g\) with smaller indices than \(x\) that are not targets. All these copies exist whenever \(x\) exists.

Let \(a\) be the number of targets whose classes belong to \(A\). Sort their values as \(b_1\leq b_2\leq\cdots\leq b_a\), breaking ties arbitrarily.

The criterion is
\(b_r\geq r\quad\text{for every }r\in\{1,\ldots,a\}\).

When \(a=0\), this condition is vacuous. We prove that it is equivalent to eventual success.

1. Remaining copies are independent of lottery outcomes

Fix a predetermined reporting sequence for the tagged student.

In each round, the copies removed are exactly the union of the reported copies. Lottery outcomes determine their recipients, but do not change this union. Moreover, every truthful student continues reporting and chooses solely from the remaining copies.

Inductively, the remaining-copy sets and truthful reports are therefore identical across all lottery outcomes.

Consequently, guaranteed acquisition of a target requires the tagged student to report it in a round in which no truthful student reports it. If a truthful student also reports that target, the fair lottery has an outcome awarding it to that student. Once removed, it cannot subsequently be acquired by the tagged student.

This also means that, along a successful strategy, no truthful report ever removes a target.

2. Necessary deadlines

Lemma. In any well-defined successful strategy for any admissible population, a target \(x=(g,j)\) with \(g\in A\) must be acquired in a round \(R_x\leq b(x)\).

Proof. Choose a truthful type whose first-ranked class is \(g\), and a student of that type.

At the start of every round through round \(R_x\), the target \(x\) remains available. Hence class \(g\) is nonempty, and this student reports its smallest-index remaining copy.

The student cannot report \(x\), because that would prevent guaranteed acquisition. Since \(x\) is available, the reported copy must therefore have index strictly smaller than \(j\). It must also lie outside \(S\), since a truthful report of any target contradicts success.

There are \(R_x\) such rounds, including the acquisition round. Their reported copies are distinct because every reported copy is removed. Thus there must be at least \(R_x\) non-target copies of class \(g\) below index \(j\). Their number is \(b(x)\), proving \(R_x\leq b(x)\). ∎

Now suppose the criterion fails at some position \(r\), so \(b_r<r\). The first \(r\) targets in the sorted list all have deadlines at most \(b_r\). By the lemma, all must be acquired within the first \(b_r\) rounds.

The tagged student reports only one copy per round, so it can acquire at most \(b_r<r\) of these targets in that time. This is impossible.

Therefore, failure of the criterion rules out success for every admissible population.

3. Sufficient supplies prevent early class exhaustion

Assume the criterion holds. Order all targets as \(x_1,\ldots,x_s\), placing the targets in classes belonging to \(A\) first, in nondecreasing order of \(b(x)\). Place the other targets afterward in any order.

For each class \(g\), let \(J_g\) be its largest target index, or \(0\) if it contains no target. Define
\(N_0=\max_{g\in G}\left\lceil \max\{2s+1,J_g\}/q_g\right\rceil\).

For every admissible \(N\geq N_0\), all targets exist and each class has at least \(2s+1\) copies.

Consider reporting \(x_r\) in round \(r\), for \(1\leq r\leq s\). We first establish that no class can empty during these rounds.

Initially, all classes are nonempty. Whenever all classes remain nonempty, every truthful student reports from its initially first-ranked class. All truthful students reporting from the same class report its smallest-index remaining copy. Thus truthful reports remove at most one copy per class per round. The tagged report removes at most one additional copy from any class.

Inductively, after \(r\leq s\) rounds, each class therefore retains at least \(2s+1-2r\geq1\) copies. This proves both the asserted non-exhaustion and the continued validity of the truthful reporting pattern.

In particular, during these rounds truthful students report only from classes in \(A\).

4. The ordered targets are acquired without competition

We prove inductively that reporting \(x_1,\ldots,x_s\) acquires every target without competition.

At the start of round \(r\), assume all targets scheduled at positions \(r,\ldots,s\) remain available.

Consider any such pending target \(y=x_\ell=(g,j)\) with \(g\in A\). Its position satisfies \(\ell\leq a\), and the criterion gives
\(b(y)=b_\ell\geq\ell\geq r\).

Originally, \(y\) has \(b(y)\) smaller-index non-target copies in its class. During the preceding \(r-1\) rounds:

  • The tagged student has reported only targets.
  • Truthful reports have removed at most one copy per round from class \(g\).

At least \(b(y)-(r-1)\geq1\) of those smaller-index non-target copies therefore remains. Consequently, \(y\) is not the smallest-index remaining copy of its class and cannot receive a truthful report in round \(r\).

A pending target whose class is outside \(A\) also receives no truthful report, by the non-exhaustion argument.

Thus no pending target receives a truthful report in this round. The tagged student reports the available copy \(x_r\), acquires it as its sole reporter, and every other pending target remains available. This completes the induction.

Hence the tagged student acquires all of \(S\) in the first \(s\) rounds for every admissible \(N\geq N_0\).

5. Completing a well-defined predetermined strategy

After the target prefix, complete the sequence by precomputing the subsequent rounds as follows: select any remaining copy, calculate all truthful reports, and remove their union with the selected copy. Repeat until the remaining set is empty.

This is a predetermined sequence because the remaining sets are independent of lottery outcomes. Every selected entry exists when reported, and entries are distinct because selected copies are immediately removed. At least one copy disappears each round, so the sequence terminates with no copies remaining.

Thus the successful prefix extends to a well-defined successful strategy. This argument also handles \(S=\varnothing\).

6. Eventual quantification and polynomial complexity

Admissible population sizes are unbounded. Indeed, let \(D\) be a common multiple of the denominators of all masses and supplies. For sufficiently large multiples \(N\) of \(D\), all integrality conditions hold, all targets exist, and
\(N(\sum_g q_g-1)\geq1\).
The last inequality is possible because \(\sum_g q_g>1\).

Therefore, the universal failure proved when the criterion fails cannot make the eventual condition vacuously true. Conversely, when the criterion holds, the explicit threshold above proves eventual success.

The decision algorithm is:

  • Compute \(A\) from the supported truthful templates.
  • Sort targets within each class by index, obtaining the number of smaller-index targets for each.
  • Compute \(b(x)\) for targets in classes belonging to \(A\).
  • Sort those values and check \(b_r\geq r\) at every position.

All operations use integers of polynomial bit length. Sorting takes polynomially many comparisons, and subtraction never requires enumerating the copies preceding a binary-encoded target index. The algorithm is therefore polynomial in \(m,\tau,s,L\).

As a concrete special case, when \(m=1\) and the target indices are \(j_1<\cdots<j_s\), we have \(b_r=j_r-r\). The exact criterion becomes \(j_r\geq2r\) for every \(r\).
