The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), a committee \(W\subseteq C\) with \(|W|=k\), and a rational distribution \((\mu_A)\) over supported approval types \(A\subseteq C\), decide whether \(W\) satisfies continuous PJR. For every \(\ell\in\{1,\ldots,k\}\) and every choice of coalition masses \(x_A\in[0,\mu_A]\), if \(\sum_A x_A\ge \ell/k\) and all types with \(x_A>0\) share at least \(\ell\) approved candidates, must their approval union contain at least \(\ell\) members of \(W\)?

For a finite, explicitly listed electorate, testing PJR is \(\mathrm{coNP}\)-complete; detecting a violation is \(\mathrm{NP}\)-complete. Its coalition threshold is \(\ell n/k\), where \(n\) is the number of voters.

Result

Detecting a continuous PJR violation is \(\mathrm{NP}\)-complete, and testing continuous PJR is \(\mathrm{coNP}\)-complete. Consequently, testing is in \(\mathrm{P}\) if and only if \(\mathrm{P}=\mathrm{NP}\).

The key observation is that a violating coalition can always be enlarged to use the full mass of every approval type in its support.

1. A finite characterization of violations

Let \(\mathcal T\) denote the listed support, so \(|\mathcal T|=\tau\). For each nonempty \(S\subseteq\mathcal T\), define

\[ M(S)=\sum_{A\in S}\mu_A,\qquad I(S)=\bigcap_{A\in S}A,\qquad U(S)=\bigcup_{A\in S}A. \]

Lemma. A continuous PJR violation exists if and only if there are a nonempty \(S\subseteq\mathcal T\) and an integer \(1\le\ell\le k\) such that

\[ M(S)\ge\frac{\ell}{k},\qquad |I(S)|\ge\ell,\qquad |W\cap U(S)|<\ell. \]

Proof. Suppose a continuous coalition \(x\) violates PJR, and set \(S=S(x)\). Because \(x_A\le\mu_A\),

\[ M(S)\ge\sum_Ax_A\ge\frac{\ell}{k}. \]

The intersection and union in the definition depend only on \(S(x)\), so the other two inequalities hold.

Conversely, given \(S\) and \(\ell\) satisfying these inequalities, take \(x_A=\mu_A\) for \(A\in S\) and \(x_A=0\) otherwise. Positivity of the supported masses gives \(S(x)=S\), and this coalition violates continuous PJR. \(\square\)

Thus real-valued coalition masses are unnecessary as certificates.

2. Membership in \(\mathrm{NP}\)

A certificate for a violation consists of a subset \(S\), encoded by \(\tau\) bits, and an integer \(\ell\), encoded using \(O(\log(k+1))\) bits. The lemma gives a verifier using set intersections, set unions, and exact rational arithmetic.

For an explicit bit-complexity bound, write \(\mu_A=p_A/q_A\) and set

\[ D=\prod_{A\in\mathcal T}q_A,\qquad b_A=p_A(D/q_A). \]

Then \(\mu_A=b_A/D\), and normalization implies \(\sum_A b_A=D\). The integers \(D\) and \(b_A\) have \(O(L)\) bits: the sum of the input denominator lengths is at most \(L\).

Using schoolbook arithmetic, computing these integers takes \(O(\tau L^2)\) bit operations. The mass inequality is verified exactly as

\[ k\sum_{A\in S}b_A\ge\ell D. \]

With approval sets represented as incidence vectors, the set operations take \(O(\tau m)\) time. Hence certificate verification takes

\[ O(\tau m+\tau L^2) \]

bit operations, including the arithmetic preprocessing. Violation detection therefore belongs to \(\mathrm{NP}\), and continuous PJR testing belongs to \(\mathrm{coNP}\).

3. Hardness by aggregating a finite electorate

We use the finite-electorate hardness theorem supplied in the question: detecting a PJR violation in an explicitly listed electorate is \(\mathrm{NP}\)-complete. This is also stated in [*Computational Complexity of Testing Proportional Justified Representation*](https://www.cse.unsw.edu.au/~haziz/pjr-test.pdf).

Consider such an instance with a nonempty electorate \(N\), \(n=|N|\), approvals \((A_i)_{i\in N}\), and committee \(W\) of size \(k\). Keep \(C\), \(k\), and \(W\). For every approval type occurring in the electorate, let

\[ n_A=|\{i\in N:A_i=A\}|,\qquad \mu_A=\frac{n_A}{n}. \]

List each occurring type once. All listed masses are positive binary rational numbers and sum to \(1\); empty approval types are retained if present. Thus the construction satisfies every input requirement, with \(\tau\le n\).

We prove that it preserves the existence of a violation.

Finite violation implies continuous violation. Suppose \(X\subseteq N\) witnesses a finite violation at level \(\ell\). For every supported type, define

\[ x_A=\frac{|\{i\in X:A_i=A\}|}{n}. \]

Then \(0\le x_A\le n_A/n=\mu_A\), and

\[ \sum_Ax_A=\frac{|X|}{n}\ge\frac{\ell}{k}. \]

The types with positive \(x_A\) are exactly the approval types occurring in \(X\). Removing repeated copies of identical approval sets changes neither their intersection nor their union. Hence the same cohesiveness and underrepresentation inequalities hold, giving a continuous violation.

Continuous violation implies finite violation. Suppose a continuous violation exists. By the lemma, choose its witnessing support \(S\) and level \(\ell\), and let

\[ X=\{i\in N:A_i\in S\}. \]

This includes every voter of each selected type. Consequently,

\[ |X|=\sum_{A\in S}n_A=nM(S)\ge\frac{\ell n}{k}. \]

Every supported type has at least one voter, so the approval types occurring in \(X\) are exactly \(S\). Therefore

\[ \bigcap_{i\in X}A_i=I(S),\qquad \bigcup_{i\in X}A_i=U(S). \]

The remaining two violation inequalities follow from the lemma. Thus \(X\) witnesses a finite PJR violation.

The transformation is polynomial-time. If the finite input has binary length \(N_{\mathrm{in}}\), forming incidence vectors and sorting ballots takes, for example,

\[ O\!\left(N_{\mathrm{in}}+nm\log(n+1)\right) \]

time. Each output mass needs \(O(\log(n+1))\) bits, and the output length is polynomial in the finite input length.

This establishes a polynomial many-one reduction from finite PJR violation detection to continuous violation detection. Combined with membership, it proves \(\mathrm{NP}\)-completeness and, by complementation, \(\mathrm{coNP}\)-completeness of testing.

4. An exact algorithm parameterized by support size

The characterization also yields a direct algorithm whose exponential dependence is on the number of supported types.

For each nonempty \(S\subseteq\mathcal T\), compute

\[ r=|W\cap U(S)|. \]

A violation with this support exists precisely when

\[ r<k,\qquad |I(S)|\ge r+1,\qquad kM(S)\ge r+1. \]

Indeed, any witnessing level must satisfy \(\ell\ge r+1\), which implies these inequalities. Conversely, these inequalities make \(\ell=r+1\) a witnessing level. Thus no enumeration over all \(k\) levels is necessary.

After the exact-arithmetic preprocessing above, enumerate all support subsets and check these conditions. A conservative running-time bound is

\[ O\!\left(2^\tau(\tau m+\tau L^2)\right). \]

The dependence on \(k\) occurs through the integer comparisons and multiplications, whose bit lengths are included in \(L\). In particular, testing is fixed-parameter tractable in \(\tau\), despite being \(\mathrm{coNP}\)-complete when \(\tau\) is unrestricted.
