The continuous mirror question, as graded

Given candidates \(C\), target \(p\), registered mass \(\mu_t\) and eligible unregistered mass \(\nu_t\) on supported ranking types \(t\), and an addition budget \(\kappa\), decide whether there are masses \(x_t\) with \(0\le x_t\le\nu_t\) and \(\sum_t x_t\le\kappa\) such that \(\sum_t(\mu_t+x_t)(s_r(t,p)-s_r(t,c))\ge0\) for every \(c\ne p\) and \(r\in\{2\text{-Approval},1\text{-Veto}\}\). Take \(\mu\), \(\nu\), and \(\kappa\) as binary rational masses on the same registered-population scale.

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m=|C|\ge2\), a target \(p\in C\), and strict complete ranking types, consider constructive control by adding divisible voter mass under the fixed rule family \(F=\{2\text{-Approval},1\text{-Veto}\}\).
A society is given by its support: the list of types with positive mass, each with its mass as a binary rational. Here use the union support \(T=\{t:\mu_t+\nu_t>0\}\), with \(\tau=|T|\); absent registered or unregistered masses are zero. The support size is not the number of possible rankings.
Registered masses \(\mu_t\), eligible unregistered masses \(\nu_t\), and the budget \(\kappa\) are nonnegative binary rationals in one common population unit; neither society is required to have total mass one. Let \(L\) be the total input bit length.
For \(r\in F\), let \(s_r(t,c)\) be the standard per-unit scoring-rule score of candidate \(c\) in ranking \(t\). Scores are summed using voter mass; all candidates attaining the maximum are winners, with no tie-breaking.
The decision problem asks whether there exist real masses \(x_t\) satisfying \(0\le x_t\le\nu_t\), \(\sum_{t\in T}x_t\le\kappa\), and \(\sum_{t\in T}(\mu_t+x_t)(s_r(t,p)-s_r(t,c))\ge0\) for every \(c\in C\setminus\{p\}\) and \(r\in F\). The same addition must succeed under both rules.

Is this continuous mass-addition decision problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For explicitly listed, unweighted, indivisible voters, constructive control by adding voters under this rule family is \(\mathrm{NP}\)-complete. [Primary source](https://www.ifaamas.org/Proceedings/aamas2014/aamas/p61.pdf)

Result

The divisible-mass decision problem is in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\). It is exactly a linear feasibility problem of polynomial encoding length.

1. Scores and registered margins

For each listed ranking \(t\), let \(\operatorname{pos}_t(c)\) denote candidate \(c\)’s position. The scoring functions are

\(s_{2\text{-Approval}}(t,c)=\mathbf{1}\{\operatorname{pos}_t(c)\le 2\}\),

\(s_{1\text{-Veto}}(t,c)=\mathbf{1}\{\operatorname{pos}_t(c)<m\}\).

These formulas also apply when \(m=2\).

For every \(r\in F\), \(c\ne p\), and \(t\in T\), define

\(d_{r,c,t}=s_r(t,p)-s_r(t,c)\in\{-1,0,1\}\),

and define the registered margin

\(a_{r,c}=\sum_{t\in T}\mu_t d_{r,c,t}\).

All positions and score differences can be computed by scanning the explicitly listed rankings, using polynomial time in \(m,\tau,L\). No enumeration of absent rankings is needed.

2. An equivalent linear feasibility problem

Introduce one real variable \(x_t\) for each \(t\in T\). Consider the system

\(0\le x_t\le\nu_t\qquad(t\in T)\),

\(\sum_{t\in T}x_t\le\kappa\),

\(-\sum_{t\in T}d_{r,c,t}x_t\le a_{r,c}\qquad(r\in F,\ c\in C\setminus\{p\})\).

There are \(\tau\) variables and \(2\tau+1+2(m-1)\) inequalities.

To verify equivalence, the first two groups impose exactly eligibility and the addition budget. For each rule and rival, the last inequality is equivalent to

\(a_{r,c}+\sum_{t\in T}d_{r,c,t}x_t =\sum_{t\in T}(\mu_t+x_t)\bigl(s_r(t,p)-s_r(t,c)\bigr)\ge0\).

Thus it holds precisely when \(p\)’s score is at least \(c\)’s score under rule \(r\). Requiring these inequalities for every rival makes \(p\) a winner, including ties. The same variables occur in both rules’ inequalities, so the addition succeeds simultaneously.

Consequently, the original instance is a yes-instance if and only if this linear system is feasible.

If \(\tau=0\), both societies are empty. Choosing no addition gives every candidate score zero under both rules, so the answer is yes. Henceforth assume \(\tau\ge1\).

3. Polynomial encoding length

We must bound numerical encoding length, since the masses can be large binary rationals.

Write every input mass and the budget as a nonnegative integer numerator divided by a positive integer denominator. Let \(D\) be the product of all these denominators, with omitted zero masses assigned denominator one. Because their encodings are part of the input,

\(\log_2 D=O(L)\).

The product \(D\) can therefore be computed by polynomial-time integer arithmetic. Set \(y_t=Dx_t\). The equivalent system becomes

\(0\le y_t\le D\nu_t\),

\(\sum_{t\in T}y_t\le D\kappa\),

\(-\sum_{t\in T}d_{r,c,t}y_t\le Da_{r,c}\).

Every right-hand side is now an integer. In particular,

\(Da_{r,c}=\sum_{t\in T}(D\mu_t)d_{r,c,t}\).

Each scaled input quantity has \(O(L)\) bits: multiplying its numerator by \(D\) increases bit length by at most \(O(L)\). Summing at most \(\tau\) signed quantities increases bit length by at most \(O(\log(\tau+1))\). Hence every right-hand side has

\(O(L+\log(\tau+1))\)

bits. Every matrix entry belongs to \(\{-1,0,1\}\).

The dense encoding of the resulting integer linear system therefore has length at most

\(O\bigl((\tau+m+1)(\tau+L+\log(\tau+1))\bigr)\),

which is polynomial in \(m,\tau,L\). Its construction also takes polynomial time.

4. Exact polynomial-time decision

Apply the polynomial-time linear programming feasibility theorem:

Given a binary-encoded rational matrix \(A\) and rational vector \(b\), feasibility of \(Az\le b\) over real vectors \(z\) can be decided in time polynomial in the total encoding length.

This is the standard consequence of Khachiyan’s theorem; the reduction to linear-inequality feasibility and its bit-complexity treatment are described in [Nemirovski’s lecture notes, Section 8.4.2](https://www2.isye.gatech.edu/~nemirovs/OPTIII_LectureNotes2020.pdf).

All hypotheses hold here: the system is explicitly listed, all coefficients are integers, and its encoding length is polynomially bounded. The theorem decides exact feasibility, including feasible regions of lower dimension; strict inequalities or a positive interior radius are not required.

By the equivalence established above, its answer is exactly the answer to the divisible-mass control problem. This proves membership in \(\mathrm{P}\).

5. Relation to indivisible-voter hardness

The cited [AAMAS paper, Theorem 6.3](https://www.ifaamas.org/Proceedings/aamas2014/aamas/p61.pdf), establishes \(\mathrm{NP}\)-completeness for indivisible voters.

In that model, aggregating unweighted voters by ranking requires each \(x_t\) to be an integer. The present problem instead permits every real value between zero and \(\nu_t\). Removing integrality produces exactly the linear system proved tractable above. Thus the indivisible-voter hardness does not establish hardness of the divisible-mass problem.

As usual, membership in \(\mathrm{P}\) means that this problem could be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).
