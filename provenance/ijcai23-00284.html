The continuous mirror question, as graded

Given rational type masses \(\mu\in\Delta_\tau\), rational per-capita supplies \(\rho\in\mathbb{Q}_{\ge0}^q\) of indivisible item classes, additive valuations \(v_\theta(g)\), and a finite bundle bound \(K\), does there exist a bundle census \(x_{\theta,b}\) satisfying type-mass and item-supply constraints such that every positive-support pair \((\theta,b)\) has a certificate census retaining some mass \(0<\varepsilon\le x_{\theta,b}\) of type \(\theta\) with bundle \(b\), while every certificate bundle \(b'\) satisfies \(v_\theta(b)\ge v_\theta(b')-v_\theta(g)\) for every positively valued item \(g\in b'\); compute such a census and certificates.

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a finite set of item classes, \(\Theta\) finite valuation types with rational masses \(\mu_\phi\), rational per-capita supplies \(\rho_g\), and nonnegative additive valuations \(v_\phi(B)=\sum_{g\in B}v_\phi(g)\). Each individual receives an integral bundle \(B\subseteq G\).
A feasible mass allocation is \(y_{\phi,B}\ge0\) satisfying \(\sum_{B\subseteq G}y_{\phi,B}=\mu_\phi\) for every \(\phi\), and \(\sum_{\phi,B:\,g\in B}y_{\phi,B}=\rho_g\) for every \(g\).
For distinguished \(\theta\), define \(\operatorname{MXS}^{\infty}_\theta\) as the minimum \(v_\theta(B)\) over feasible \(y\) and \(B\) with \(y_{\theta,B}>0\), such that, for every \(\phi,B'\) with \(y_{\phi,B'}>0\) and every \(g\in B'\) with \(v_\theta(g)>0\), \(v_\theta(B)\ge v_\theta(B'\setminus\{g\})\).

Target. Is computing \(\operatorname{MXS}^{\infty}_\theta\) from this rationally encoded input polynomial-time solvable, or NP-hard?

Known results. For finite agents and indivisible items with additive valuations, computing an agent's minimum EFX share is NP-hard, including instances with two agents having identical valuations.

Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Result

Computing \(\operatorname{MXS}^{\infty}_\theta\) is \(\mathrm{NP\text{-}hard}\), even with one valuation type and supplies restricted to \(\{1/2,1\}\). The reduction establishes weak \(\mathrm{NP\text{-}hardness}\).

Decision version

Consider the threshold problem asking whether

\(\operatorname{MXS}^{\infty}_\theta\le K\).

A polynomial-time exact algorithm for \(\operatorname{MXS}^{\infty}_\theta\) would solve this problem by comparison with \(K\). It therefore suffices to prove that the threshold problem is \(\mathrm{NP\text{-}hard}\).

Reduction from PARTITION

Let \(a_1,\ldots,a_n\) be positive integers forming an instance of \(\mathrm{PARTITION}\), and write

\(W=\sum_{i=1}^n a_i\).

Thus, the instance is positive precisely when there is \(S\subseteq\{1,\ldots,n\}\) satisfying

\(2\sum_{i\in S}a_i=W\).

Construct an allocation instance as follows.

  • There is one type, namely \(\Theta=\{\theta\}\), with mass \(\mu_\theta=1\).
  • There are ordinary items \(g_1,\ldots,g_n\) and one sentinel item \(s\).
  • The supplies are \(\rho_s=1\) and \(\rho_{g_i}=1/2\) for every \(i\).
  • The valuation is

\(v_\theta(s)=1/2\) and \(v_\theta(g_i)=2a_i\).

  • Set the threshold to

\(K=W+1/2\).

The construction has polynomial encoding length.

For a bundle \(C\), define its ordinary-item weight by

\(q(C)=\sum_{i:g_i\in C}2a_i\).

Preliminary observations

Every supported bundle contains \(s\). Indeed,

\(\sum_{C:s\in C}y_{\theta,C}=\rho_s=1\),

while

\(\sum_Cy_{\theta,C}=\mu_\theta=1\).

Consequently, nonnegativity implies \(y_{\theta,C}=0\) whenever \(s\notin C\).

Moreover, every constructed instance has at least one admissible allocation-target pair, so the minimum is well-defined. Put mass \(1/2\) on \(\{s\}\) and mass \(1/2\) on the full bundle \(G\), and choose \(G\) as the target bundle. Its value is \(2W+1/2\), which dominates every supported bundle after removal of any positively valued item.

Forward implication

Suppose the \(\mathrm{PARTITION}\) instance has a solution \(S\), so that \(2\sum_{i\in S}a_i=W\).

Define

\(C_S=\{s\}\cup\{g_i:i\in S\}\)

and

\(C_{\overline S}=\{s\}\cup\{g_i:i\notin S\}\).

Give each bundle mass \(1/2\). Then \(s\) has supply \(1\), while every ordinary item has supply \(1/2\). Hence this is feasible.

Choose \(B=C_S\). Its value is

\(v_\theta(B)=1/2+W=K\).

Both supported bundles have ordinary-item weight \(W\). Removing \(s\) from either one leaves value \(W\), which is at most \(K\). Removing an ordinary item \(g_i\) leaves value

\(1/2+W-2a_i\le K\).

Thus all required inequalities hold, and therefore

\(\operatorname{MXS}^{\infty}_\theta\le K\).

Reverse implication

Suppose there is a feasible allocation \(y\) and a supported target bundle \(B\) such that

\(x:=v_\theta(B)\le K=W+1/2\),

and all the required inequalities hold.

As shown above, every supported bundle \(C\) contains \(s\). Applying the defining inequality to \(g=s\) gives

\(q(C)=v_\theta(C\setminus\{s\})\le v_\theta(B)=x\le W+1/2\).

Since \(q(C)\) is an integer, this implies \(q(C)\le W\).

On the other hand, feasibility determines the average ordinary-item weight:

\(\sum_Cy_{\theta,C}q(C)=\sum_{i=1}^n 2a_i\sum_{C:g_i\in C}y_{\theta,C}=\sum_{i=1}^n2a_i\rho_{g_i}=W\).

The total mass is \(1\), and every supported value \(q(C)\) is at most \(W\). An average of \(W\) is therefore possible only if

\(q(C)=W\)

for every supported bundle \(C\). In particular, this holds for the target bundle \(B\).

Let \(S=\{i:g_i\in B\}\). Then

\(2\sum_{i\in S}a_i=q(B)=W\),

so \(S\) is a solution of the original \(\mathrm{PARTITION}\) instance.

Conclusion

The constructed instance satisfies

\(\operatorname{MXS}^{\infty}_\theta\le W+1/2\)

if and only if the original \(\mathrm{PARTITION}\) instance is positive. Hence the threshold problem, and therefore exact computation of \(\operatorname{MXS}^{\infty}_\theta\), is \(\mathrm{NP\text{-}hard}\).

The proof is specific to the mass-over-types formulation and does not rely on transferring finite-agent EFX-share hardness.

Verdict

The prover correctly establishes weak \(\mathrm{NP}\)-hardness by a polynomial-time reduction from \(\mathrm{PARTITION}\). The argument directly addresses the mass-over-types formulation, and no substantive gaps or false steps were found.

Step-by-step audit

  • Decision reduction. The threshold problem \(\operatorname{MXS}^{\infty}_\theta\le K\) is sufficient for proving hardness of exact computation: an exact polynomial-time algorithm could compute the value and compare it with the rational threshold \(K\). No membership claim for the decision problem is needed.
  • Construction and encoding. The instance has one type of mass \(1\), one sentinel with supply \(1\), ordinary items with supply \(1/2\), values \(v_\theta(s)=1/2\) and \(v_\theta(g_i)=2a_i\), and threshold \(K=W+1/2\). All numbers have encoding length polynomial in the binary encoding of the \(\mathrm{PARTITION}\) instance. Reduction from \(\mathrm{PARTITION}\) therefore yields weak, rather than strong, \(\mathrm{NP}\)-hardness, exactly as claimed.
  • Sentinel observation. Since the total mass of bundles containing \(s\) equals its supply \(1\), while the total allocated mass is also \(1\), nonnegativity indeed forces every positively supported bundle to contain \(s\).
  • Existence of an admissible pair. Assigning mass \(1/2\) to \(\{s\}\) and mass \(1/2\) to the full bundle is feasible. Choosing the full bundle as the target satisfies all required removal inequalities, including removal of \(s\) and of every ordinary item. Thus the optimized set is nonempty.
  • Forward implication. A partition \(S\) produces two complementary bundles, each of mass \(1/2\). Supplies are satisfied exactly. Both bundles have ordinary-item value \(W\); removing the sentinel leaves value \(W\), and removing an ordinary item leaves \(W+1/2-2a_i\). Both are at most the target value \(K=W+1/2\). Hence \(\operatorname{MXS}^{\infty}_\theta\le K\).
  • Reverse implication: pointwise bound. Applying the defining inequality to removal of the positively valued sentinel from any supported bundle \(C\) gives \(q(C)\le x\le W+1/2\). Because \(q(C)\) and \(W\) are integers, this correctly implies \(q(C)\le W\).
  • Reverse implication: averaging. Feasibility gives

\[ \sum_C y_{\theta,C}q(C)=\sum_i 2a_i\rho_{g_i}=W. \]
The masses sum to \(1\), and every supported \(q(C)\) is at most \(W\). Since there are finitely many bundles, any supported bundle with \(q(C)<W\) would make the weighted average strictly less than \(W\). Therefore every supported bundle has \(q(C)=W\).

  • Extraction of the partition. The target \(B\) is supported, so \(q(B)=W\). Taking \(S=\{i:g_i\in B\}\) yields \(2\sum_{i\in S}a_i=W\), exactly the required partition condition.
  • Conclusion. The stated equivalence is established in both directions, so exact computation is weakly \(\mathrm{NP}\)-hard even under the claimed restrictions.

No missing hypotheses, quantifier errors, edge-case failures, or unjustified theorem applications were identified.
