The continuous mirror question, as graded

Given a rooted directed graph on role types, positive rational masses μ_t summing to one, strict rankings over incoming edges, and edge costs in {0,1,∞}, find a minimum-cost popular arborescence or report that none exists. Each role chooses one incoming edge for its cohort; popularity is determined by the mass-weighted pairwise preference margin, and total cost is the mass-weighted sum of the chosen edges' costs.

Packaged proof task (what the prover saw — nothing else)

Let \(G=(T\cup\{r\},E)\) be a directed graph whose root \(r\) has no incoming edges. Each role type \(t\in T\) has a strict ranking \(\succ_t\) over its incoming edges and mass \(\mu_t>0\), with \(\sum_{t\in T}\mu_t=1\); the root has no voting mass. Edge costs satisfy \(c:E\to\{0,1,\infty\}\).
A society is given by its support: the list of the \(\tau=|T|\) types with positive mass, each mass encoded as a binary rational. Here \(\tau\) is the support size, not the number of possible types. Set \(m=|E|\), and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A feasible outcome is an arborescence rooted at \(r\) spanning all role types. Its incoming edge \(A(t)\) serves the entire cohort of type \(t\); cohorts cannot split their choices.
Define \(\Delta_\mu(A,B)=\sum_{t:A(t)\succ_t B(t)}\mu_t-\sum_{t:B(t)\succ_t A(t)}\mu_t\). An outcome \(A\) is popular if \(\Delta_\mu(A,B)\geq0\) for every feasible outcome \(B\); equal incoming edges contribute zero.
Its cost is \(C_\mu(A)=\sum_{t\in T}\mu_t c(A(t))\). Infinite-cost edges remain available in popularity comparisons. Find a popular outcome minimizing this extended-real cost, or report that no popular outcome exists; if every popular outcome has infinite cost, return one with cost \(\infty\).

Is this minimum-cost mass-weighted popular arborescence problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

With one unweighted voter per vertex, minimum-cost popular arborescence is NP-hard even with strict rankings and costs in \(\{0,1,\infty\}\), while finding any popular arborescence is polynomial-time solvable ([source](https://arxiv.org/pdf/2310.19455)).
For the related branching problem, an algorithm handles positive integer voter weights satisfying \(w(s)+w(t)>w(u)\) for all vertices and total-preorder preferences; it concerns finding a popular branching rather than the minimum-cost problem above ([source](https://arxiv.org/pdf/2110.03460)).

Modeling choices made when packaging the task

  • Specified that the root has no incoming edges and no voting mass, and that outcomes span every supported role type.
  • Made the cohort choice indivisible: each type selects one incoming edge for its entire positive mass.
  • Specified that popularity compares against every arborescence, including those containing infinite-cost edges, as required by the discrete definition.
  • Interpreted infinite costs as extended-real objective values: a popular outcome of infinite cost is distinct from nonexistence of any popular outcome.
  • Defined m as the number of edges and L as the total input bit length.

Result and the known hardness theorem

The problem is NP-hard, already when all types have equal mass. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

We use the following given result: for a directed graph with a root having no incoming edges, strict preferences at every nonroot vertex, and edge costs in \(\{0,1,\infty\}\), computing a popular spanning arborescence minimizing the sum of its edge costs is NP-hard. This is [Theorem 1.4 of Kavitha, Makino, Schlotter, and Yokoi](https://arxiv.org/pdf/2310.19455). Their Section 5 establishes hardness through a finite-budget decision problem.

Reduction to equal positive masses

Take an instance of that unweighted problem with nonroot vertex set \(V\), where \(\tau=|V|\geq 1\). Construct a mass-weighted instance by setting \(T=V\), retaining the graph, root, strict rankings, and edge costs, and assigning

\(\mu_t=1/\tau\quad\text{for every }t\in T.\)

Every mass is positive, and their sum is one. Each original vertex becomes one explicitly listed role type. The feasible arborescences are exactly the original feasible arborescences; there is no replication or splitting of cohorts.

Define the unweighted voting margin by

\(\Delta_1(A,B)=|\{t:A(t)\succ_t B(t)\}|-|\{t:B(t)\succ_t A(t)\}|.\)

For every pair of feasible arborescences, the definition of the masses gives

\(\Delta_\mu(A,B)=\Delta_1(A,B)/\tau.\)

Since \(\tau\) is positive, these two margins have the same sign. Therefore, for every feasible \(A\),

\(A\text{ is mass-weighted popular}\ \Longleftrightarrow\ A\text{ is unweighted popular}.\)

This equivalence quantifies over all feasible competitors, including those containing infinite-cost edges, because the reduction retains every edge.

Preservation of the extended-real objective

Let the original objective be \(C_1(A)=\sum_{t\in T}c(A(t))\).

If \(A\) uses only finite-cost edges, then

\(C_\mu(A)=\frac{1}{\tau}\sum_{t\in T}c(A(t))=C_1(A)/\tau.\)

If \(A\) contains an infinite-cost edge, its head has positive mass. Consequently, both \(C_1(A)\) and \(C_\mu(A)\) equal \(\infty\).

Thus the transformation preserves the ordering of all outcome costs, including infinite costs. Combined with the popularity equivalence, it preserves exactly the set of minimum-cost popular arborescences. It also preserves both exceptional cases required by the task:

  • There is no popular outcome precisely when the original instance has none.
  • Every popular outcome has infinite cost precisely when that holds in the original instance.

In particular, for any finite integer budget \(k\),

\(\exists A\text{ unweighted popular with }C_1(A)\leq k\)

holds if and only if

\(\exists A\text{ mass-weighted popular with }C_\mu(A)\leq k/\tau.\)

Hence the stipulated optimizer would also decide the NP-hard finite-budget problem.

Encoding and running time

Let \(L_0\) be the original instance’s bit length. The reduction leaves \(m\) and \(\tau\) unchanged. Encoding each mass as the binary numerator-denominator pair for \(1/\tau\) takes \(O(\log(\tau+1))\) bits. Therefore,

\(L=O(L_0+\tau\log(\tau+1)).\)

The reduction can be performed in \(O(L_0+\tau\log(\tau+1))\) bit operations, including copying the original input and writing the masses.

An algorithm polynomial in \(m,\tau,L\) would therefore solve the original NP-hard problem in polynomial time. The support representation provides no escape from this reduction: its support size is exactly the original number of nonroot vertices.

Why the branching result does not change the conclusion

The related [weighted branching result](https://arxiv.org/pdf/2110.03460) concerns finding a popular branching under additional hypotheses. It does not solve minimum-cost optimization over popular spanning arborescences. Even in the equal-mass subclass above, preserving popularity does not make optimizing cost tractable.
