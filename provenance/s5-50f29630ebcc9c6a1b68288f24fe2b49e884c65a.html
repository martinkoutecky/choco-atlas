The continuous mirror question, as graded

Given processor types \(P\) with rational masses \(\mu_t\) summing to \(1\), minimum salaries \(p_t\), and processing times \(s_{tj}\), task classes \(J\) with rational supplies \(r_j\) per unit workforce, a deadline \(d\), and a per-capita budget \(B\), do rational masses \(x_{t,a}\ge 0\) exist for configurations \(a\in\mathbb{Z}_{\ge 0}^{J}\) satisfying \(\sum_j a_js_{tj}\le d\), \(\sum_a x_{t,a}=\mu_t\) for each \(t\), \(\sum_{t,a}a_jx_{t,a}=r_j\) for each \(j\), and \(\sum_t p_t\sum_{a\ne 0}x_{t,a}\le B\)? Take processing times and deadline to be positive integers encoded in unary.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(P\) of its \(\tau\ge1\) processor types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not all possible types.
Let \(J\) contain \(m\ge1\) task classes, with positive binary rational supplies \(r_j\) per unit workforce. Type \(t\) has positive binary rational minimum project salary \(p_t\); the per-capita budget \(B\) is a positive binary rational. Processing times \(s_{tj}\) and deadline \(d\) are positive integers encoded in unary. Let \(L\) be the total input length.
Tasks are independent, indivisible, and nonpreemptive; each processor executes its assigned tasks sequentially. A configuration is \(a\in A_t:=\{a\in\mathbb Z_{\ge0}^{J}:\sum_{j\in J}a_js_{tj}\le d\}\). Configurations are specified implicitly by these inequalities.
Mass assigned a nonzero configuration pays \(p_t\) per unit mass, regardless of workload; the zero configuration represents an idle processor and costs nothing.
Continuous feasibility means existence of \(x_{t,a}\in\mathbb Q_{\ge0}\) satisfying \(\sum_{a\in A_t}x_{t,a}=\mu_t\) for every \(t\), \(\sum_{t\in P}\sum_{a\in A_t}a_jx_{t,a}=r_j\) for every \(j\), and \(\sum_{t\in P}p_t\sum_{a\in A_t\setminus\{0\}}x_{t,a}\le B\).

Is continuous feasibility in \(\mathrm P\), with running time polynomial in \(m,\tau,d,L\), or is it NP-hard?
If it is NP-hard, is it nevertheless FPT parameterized by \(\tau\), with running time \(f(\tau)\operatorname{poly}(m,d,L)\)?

For finitely many processors and individual tasks, selecting processors within a project-salary budget and assigning every task within the deadline is NP-hard, even with two processors. It is also \(\mathrm{W}[1]\)-hard parameterized by the number of processors, even with unit salaries and unary input. [Discrete scheduling hardness](https://arxiv.org/pdf/1402.2970v3)
No result settling this exact continuous feasibility problem was located in the literature search.

  • Retained finite positive processing times as requested; inability to perform a task can be represented by a processing time exceeding the deadline.

Result

Continuous feasibility is in \(\mathrm P\) under the stated encoding, with running time polynomial in \(\m,\tau,d,L\). Consequently, it is also FPT parameterized by \(\tau\).

The proof constructs a polynomial-size rational linear program whose feasible solutions correspond exactly to the configuration assignments in the question.

1. A graph representing configurations

Fix a supported type \(t\in P\). Construct a directed multigraph \(G_t\) with vertices \(\{0,1,\ldots,d\}\cup\{z_t\}\), where \(0\) is the source and \(z_t\) is the sink.

There are two kinds of arcs:

  • For each \(j\in J\) and integer \(q\) satisfying \(0\le q\le d-s_{tj}\), add a task arc from \(q\) to \(q+s_{tj}\), labeled \(j\).
  • For every \(q\in\{0,\ldots,d\}\), add a termination arc from \(q\) to \(z_t\).

Task arcs with different labels remain distinct even when their endpoints coincide. Since \(s_{tj}\ge1\), every task arc strictly increases the time coordinate. Placing \(z_t\) last gives a topological ordering, so \(G_t\) is acyclic.

For a source-to-sink path \(\pi\), let \(a_j(\pi)\) be its number of task arcs labeled \(j\). If its termination arc leaves vertex \(q\), then

\(\displaystyle \sum_{j\in J}a_j(\pi)s_{tj}=q\le d.\)

Thus \(a(\pi)\in A_t\).

Conversely, every \(a\in A_t\) has a representing path: list its tasks in any order and follow the corresponding task arcs, then terminate. Every partial processing-time sum is at most the total, which is at most \(d\), so all these arcs exist.

The path consisting solely of the termination arc from \(0\) represents the zero configuration. Every other source-to-sink path has exactly one task arc leaving \(0\).

2. The explicit linear program

For every \(t\in P\) and arc \(e\in E(G_t)\), introduce a nonnegative rational variable \(f_{t,e}\).

Write \(\delta_t^+(v)\) and \(\delta_t^-(v)\) for the outgoing and incoming arcs at \(v\). Impose flow balance at every vertex:

\(\displaystyle \sum_{e\in\delta_t^+(v)}f_{t,e} -\sum_{e\in\delta_t^-(v)}f_{t,e} =b_{t,v}, \)

where \(b_{t,0}=\mu_t\), \(b_{t,z_t}=-\mu_t\), and \(b_{t,q}=0\) for \(1\le q\le d\).

Let \(E_t^j\) denote the task arcs labeled \(j\). Impose the exact supply constraints

\(\displaystyle \sum_{t\in P}\sum_{e\in E_t^j}f_{t,e}=r_j \qquad(j\in J). \)

Finally, let \(H_t\) be the set of task arcs leaving \(0\), and impose

\(\displaystyle \sum_{t\in P}p_t\sum_{e\in H_t}f_{t,e}\le B. \)

This charges salary when a path starts its first task. The idle path is uncharged, and a nonidle path is charged exactly once, regardless of its workload.

3. Exact equivalence

Configuration assignments give feasible flows

Suppose \(x_{t,a}\in\mathbb Q_{\ge0}\) satisfy the original constraints. For each configuration \(a\in A_t\), choose a representing path \(\pi_{t,a}\). Define

\(\displaystyle f_{t,e}=\sum_{\substack{a\in A_t\\e\in\pi_{t,a}}}x_{t,a}. \)

These sums are finite: positivity of processing times implies \(a_j\le d\), so \(A_t\) is finite.

Each path contributes its weight to the source-to-sink flow. Therefore its total value is \(\sum_a x_{t,a}=\mu_t\), establishing flow balance.

For each class \(j\), the total flow on task arcs labeled \(j\) is

\(\displaystyle \sum_{t\in P}\sum_{e\in E_t^j}f_{t,e} =\sum_{t\in P}\sum_{a\in A_t}a_jx_{t,a} =r_j. \)

Each nonzero configuration’s path uses exactly one arc in \(H_t\), while the zero configuration’s path uses none. Hence

\(\displaystyle \sum_{e\in H_t}f_{t,e} =\sum_{a\in A_t\setminus\{0\}}x_{t,a}. \)

The flow budget therefore equals the original salary expenditure. All flow variables are rational and nonnegative.

Feasible rational flows give configuration assignments

Suppose the explicit LP has a rational feasible solution. Fix \(t\).

We first prove that its flow decomposes into source-to-sink paths with nonnegative rational weights. Whenever positive flow leaves the source, choose a positive-flow outgoing arc. At any subsequent nonsink vertex reached by a positive-flow arc, conservation guarantees a positive-flow outgoing arc. Acyclicity ensures that this process reaches the sink.

Subtract from the resulting path the minimum flow on its arcs. This minimum is a positive rational number. Subtraction preserves conservation at internal vertices, decreases the source-to-sink flow by that number, and makes at least one previously positive arc zero.

Repeating takes at most \(|E(G_t)|\) iterations. When no positive flow leaves the source, no positive residual arc can remain: otherwise, choose the earliest vertex in the topological ordering with positive outgoing flow. It has no positive incoming flow, contradicting conservation; it cannot be the source or sink either.

Consequently,

\(\displaystyle f_{t,e}=\sum_{\ell:e\in\pi_{t,\ell}}\lambda_{t,\ell}, \qquad \lambda_{t,\ell}\in\mathbb Q_{>0}, \qquad \sum_\ell\lambda_{t,\ell}=\mu_t. \)

For every \(a\in A_t\), set

\(\displaystyle x_{t,a}=\sum_{\ell:a(\pi_{t,\ell})=a}\lambda_{t,\ell}, \)

with an empty sum interpreted as zero. These are nonnegative rational masses, and their sum is \(\mu_t\).

Counting labeled task arcs gives

\(\displaystyle \sum_{t\in P}\sum_{a\in A_t}a_jx_{t,a} =\sum_{t\in P}\sum_{e\in E_t^j}f_{t,e} =r_j. \)

Likewise, counting the unique initial task arc of each nonidle path gives

\(\displaystyle \sum_{t\in P}p_t\sum_{a\in A_t\setminus\{0\}}x_{t,a} =\sum_{t\in P}p_t\sum_{e\in H_t}f_{t,e} \le B. \)

Thus the reconstructed assignment satisfies every original constraint. The equivalence is exact.

4. Polynomial running time and parameterization

Each graph has \(d+2\) vertices, at most \(m(d+1)\) task arcs, and \(d+1\) termination arcs. Therefore the LP has at most

\(\displaystyle N=\tau(d+1)(m+1)\)

variables. Apart from nonnegativity, it has \(\tau(d+2)+m+1\) constraints.

Its coefficients belong to \(\{0,1,-1\}\cup\{p_t:t\in P\}\), and its right-hand sides use only the supplied rational numbers and their negatives. Each coefficient therefore has bit length bounded by \(O(L+1)\). Even a dense encoding of this LP has length polynomial in \(m,\tau,d,L\), and it can be constructed within that bound.

The standard polynomial-time theorem for rational linear programming decides feasibility exactly and produces a rational feasible point when one exists. Its hypotheses apply here because the system is explicit, finite, and has rational coefficients. See [Trevisan’s linear programming notes, Sections 5.2.4–5.2.5](https://theory.stanford.edu/~trevisan/books/cs261.pdf).

Together with the equivalence proved above, this yields a running time polynomial in \(m,\tau,d,L\). Since \(d\) is unary encoded and the supported types are explicitly listed, this is also polynomial in the total input length.

In particular, for some absolute constant \(C\), the running time is bounded by \((m+\tau+d+L+1)^C\), which is at most

\(\displaystyle (\tau+1)^C(m+d+L+1)^C. \)

This has the required form \(f(\tau)\operatorname{poly}(m,d,L)\), proving FPT parameterized by \(\tau\).

5. Relation to the discrete problem

The construction preserves indivisible tasks within every configuration. It permits rational workforce mass to be distributed among configurations, exactly as the question requires. Selecting finitely many processors would impose additional integrality conditions on those configuration multiplicities.

For example, take one supported type with \(\mu_t=1\), one task class with \(s_{tj}=1\), deadline \(d=2\), salary \(p_t=1\), supply \(r_j=3/2\), and budget \(B=3/4\). The continuous assignment \(x_{t,(2)}=3/4\), \(x_{t,(0)}=1/4\) is feasible.

With two individual processors and three individual tasks, the corresponding total salary budget is \(3/2\). It permits selecting at most one processor, which can execute at most two tasks. Thus that discrete instance is infeasible. The discrete hardness statements therefore do not contradict the continuous polynomial-time result.
