The continuous mirror question, as graded

Given a fixed candidate set \(C\subseteq\mathbb{Q}^d\), committee size \(k\), realizable strict ranking types \(t\) with Euclidean witnesses, and rational masses \(\mu_t\) summing to \(1\), find a size-\(k\) committee minimizing \(L_\mu(S)=\max_{t:\mu_t>0}\min_{c\in S}\sigma_t(c)\), or decide whether \(L_\mu(S)\le q\).

Packaged proof task (what the prover saw — nothing else)

Definitions. Fix \(d\ge 2\). An input consists of a finite \(C\subseteq\mathbb{Q}^d\), \(k\), \(q\), and finitely many strict ranking types \(t\), each promised realizable by some \(x_t\in\mathbb{R}^d\) that ranks candidates by increasing Euclidean distance, with rational masses \(\mu_t>0\) summing to \(1\). Let \(\sigma_t(c)\) be \(c\)'s rank under \(t\), and \(L_\mu(S)=\max_t\min_{c\in S}\sigma_t(c)\).

Target. Is deciding whether some \(S\subseteq C\) with \(|S|=k\) has \(L_\mu(S)\le q\) NP-hard, or is it solvable in polynomial time?

Nearest known results. The discrete Euclidean minimax Chamberlin--Courant problem is NP-hard in every \(d\ge2\), and for every \(\epsilon>0\) it is NP-hard to approximate within \(|C|^{1-\epsilon}\). For the stated finite rational-mass model, the exact decision problem is already NP-hard, since a discrete instance can be represented by positive rational masses on its ranking types and the objective depends only on their support.

Complexity of the Finite Rational-Mass Problem

Result

For every fixed \(d\ge 2\), the decision problem is \(NP\)-hard. Under the natural explicit encoding of the ranking types, it is in \(NP\), and hence is \(NP\)-complete on the promised class of realizable instances.

The rational masses do not affect the objective beyond determining which ranking types have positive support.

Support-Invariance Lemma

Let \(T\) be the finite set of ranking types, and suppose \(\mu_t>0\) for every \(t\in T\). For every committee \(S\subseteq C\),

\[ L_\mu(S)=\max_{t\in T}\min_{c\in S}\sigma_t(c). \]

Thus \(L_\mu(S)\) depends only on \(T\) and the rankings \(\sigma_t\), not on the numerical values of the positive masses \(\mu_t\).

This follows immediately from the definition: the masses do not occur in the displayed maximum, and positivity ensures that every listed type remains in the support.

Polynomial Reduction

Fix \(d\ge 2\). By the stated known result, discrete Euclidean minimax Chamberlin--Courant is \(NP\)-hard in this dimension.

Consider an instance of that problem with candidate set \(C\), electorate \(V\), committee size \(k\), and threshold \(q\). Every voter \(v\in V\) induces a strict ranking \(\sigma_v\) of \(C\) by increasing Euclidean distance.

Let \(T\) be the set of distinct rankings occurring among the voters. For each \(t\in T\), define

\[ m_t=\bigl|\{v\in V:\sigma_v=\sigma_t\}\bigr| \qquad\text{and}\qquad \mu_t=\frac{m_t}{|V|}. \]

Then:

  • Each \(\mu_t\) is a positive rational number.
  • The masses sum to one, since

\[ \sum_{t\in T}\mu_t =\frac{1}{|V|}\sum_{t\in T}m_t =1. \]

  • Every type \(t\) satisfies the realizability promise: choose any voter \(v\) whose ranking is \(t\); the voter’s Euclidean position is a realization \(x_t\).
  • The construction is polynomial-time. Equal rankings can be grouped by sorting or hashing their explicit rank vectors, and every mass has encoding length \(O(\log |V|)\).

For every committee \(S\subseteq C\),

\[ \begin{aligned} L_\mu(S) &=\max_{t\in T}\min_{c\in S}\sigma_t(c)\\ &=\max_{v\in V}\min_{c\in S}\sigma_v(c). \end{aligned} \]

The second equality holds because replacing a finite multiset of values by its set of distinct values does not change its maximum. Consequently,

\[ \exists S\subseteq C,\ |S|=k,\ L_\mu(S)\le q \]

holds exactly when the original discrete Euclidean minimax Chamberlin--Courant instance has a committee of size \(k\) and objective value at most \(q\).

If the source problem is formulated with \(|S|\le k\), this causes no difficulty when \(k\le |C|\): adding candidates cannot increase any quantity \(\min_{c\in S}\sigma_t(c)\), so every committee of size at most \(k\) can be extended to one of size exactly \(k\).

Therefore the reduction is polynomial and answer-preserving, proving \(NP\)-hardness.

Membership in \(NP\)

A certificate is a committee \(S\subseteq C\) of size \(k\). Given the explicitly encoded rank functions, one computes

\[ \min_{c\in S}\sigma_t(c) \]

for every type \(t\), takes their maximum, and compares it with \(q\). This requires polynomial time, for example \(O(|T|k)\) rank lookups after the rankings have been encoded as position arrays.

Hence the promised decision problem lies in \(NP\).

Conclusion

For every fixed \(d\ge 2\), the problem is \(NP\)-hard and, with explicit rankings, \(NP\)-complete. In particular, a polynomial-time algorithm would imply \(P=NP\).
