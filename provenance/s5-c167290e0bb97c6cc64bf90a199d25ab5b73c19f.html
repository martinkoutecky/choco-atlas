The continuous mirror question, as graded

Given a finite-horizon MDP, a feasible policy set \(\Pi\), a finite support \(T\) of stakeholder reward types with binary-rational masses \(\mu_t>0\) summing to \(1\), bounded per-type rewards, an aggregation rule \(\ell\in\{1,2\}\), and \(\alpha\in(0,1)\), construct a portfolio \(\Pi'\subseteq\Pi\) such that for every \(p\le1\), some \(\pi\in\Pi'\) has \(v_\mu^{(\ell)}(\pi,p)\ge\alpha\max_{\rho\in\Pi}v_\mu^{(\ell)}(\rho,p)\). Here \(v_\mu^{(1)}(\pi,p)=\mathbb{E}[f_\mu(G(\xi),p)]\), \(v_\mu^{(2)}(\pi,p)=f_\mu(\mathbb{E}[G(\xi)],p)\), and \(f_\mu\) is the mass-weighted generalized \(p\)-mean, including its \(p=0\) and \(p=-\infty\) cases.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) reward types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
The input MDP has finite state and action sets \(S,A\), binary-rational transitions, a fixed initial state, horizon \(H\ge1\), and binary-rational rewards \(R_t:S\times A\to[b,U]\), where \(0<b\le U\) and \(\kappa=U/b\). Write \(m=|S|+|A|\) and let \(L\) be the total binary input length.
Let \(\Pi\) be a nonempty compact feasible set of randomized Markov policies \(\pi:S\times[H]\to\Delta(A)\). It is accessed through an exact oracle returning a maximizing policy and its welfare for any queried \(p\in[-\infty,1]\); exact welfare evaluation of returned policies is also available. Count oracle queries and exact real operations separately, treating logarithms, exponentials, and comparisons as unit-cost operations.
For a trajectory \(\xi=(s_h,a_h)_{h=1}^H\), put \(G_t(\xi)=\sum_{h=1}^H R_t(s_h,a_h)\). For positive \(x\), define \(f_\mu(x,p)=(\sum_{t\in T}\mu_t x_t^p)^{1/p}\) when \(p\notin\{0,-\infty\}\), \(f_\mu(x,0)=\exp(\sum_t\mu_t\ln x_t)\), and \(f_\mu(x,-\infty)=\min_{t\in T}x_t\).
Given \(\ell\in\{1,2\}\) and binary-rational \(\alpha\in(0,1)\), let \(v_\mu^{(1)}(\pi,p)=\mathbb E_{\xi\sim\pi}[f_\mu(G(\xi),p)]\) and \(v_\mu^{(2)}(\pi,p)=f_\mu(\mathbb E_{\xi\sim\pi}[G(\xi)],p)\). An \(\alpha\)-approximate portfolio is a finite \(\Pi'\subseteq\Pi\) satisfying \(\max_{\pi\in\Pi'}v_\mu^{(\ell)}(\pi,p)\ge\alpha\max_{\rho\in\Pi}v_\mu^{(\ell)}(\rho,p)\) for every \(p\in[-\infty,1]\).

Can such portfolios, for both aggregation rules, always be constructed with size \(O(1+\ln\kappa/\ln(1/\alpha))\) using polynomially many oracle queries and exact real operations in \(m,\tau,L,H,(1-\alpha)^{-1}\), or is this approximation guarantee unattainable within these resources?

For \(N\) equally weighted stakeholders, an exact-oracle algorithm is known with portfolio size \(O(\ln\kappa/\ln(1/\alpha))\) and claimed oracle complexity \(\widetilde O((\ln\kappa)^2\ln\ln N/\ln(1/\alpha))\). [Source](https://arxiv.org/html/2502.09724v2#S4.SS1)
No result settling the stated rational-mass guarantee was located in the literature search.

  • Specified a fixed initial state, positive horizon, undiscounted trajectory totals, and randomized time-dependent Markov policies.
  • Required the feasible policy set to be nonempty and compact so welfare maxima exist; retained oracle access rather than inventing a representation for arbitrary feasibility constraints.
  • Made exact welfare evaluation and the real-operation accounting model explicit because the anchor counts maximization oracles without providing a bit-complexity model.
  • Specified binary-rational transitions, rewards, bounds, and approximation factor, and defined m and L.
  • Included the negative-infinity endpoint and defined its welfare as the minimum over positive-mass support types.
  • Added an additive constant to the portfolio-size bound to cover equal rewards and other cases where the displayed discrete bound tends to zero.

Result

Yes. For either aggregation rule, the requested portfolios can always be constructed in the stated exact-oracle model. The construction below returns a portfolio of size at most

\(1+\dfrac{2\ln\kappa}{\ln(1/\alpha)}\),

using polynomially many optimization-oracle queries and exact real operations.

The [cited paper’s Theorem 4.1](https://arxiv.org/html/2502.09724v2#S4.SS1) gives the equal-weight guarantee. The proof below handles the masses directly, without expanding them into copies of stakeholders.

1. Parameters and elementary bounds

Fix either aggregation rule \(\ell\), and abbreviate

\(v(\pi,p)=v_\mu^{(\ell)}(\pi,p)\), and \(V(p)=\max_{\pi\in\Pi}v(\pi,p)\).

Define the actual reward bounds

\(r_-=\min_{t,s,a}R_t(s,a)\), \(\qquad r_+=\max_{t,s,a}R_t(s,a)\),

and put

\(B=\ln(r_+/r_-)\), \(\qquad \varepsilon=\ln(1/\alpha)\), \(\qquad W=\ln(1/\mu_{\min})\),

where \(\mu_{\min}=\min_t\mu_t\). Thus \(B\leq\ln\kappa\) and \(\varepsilon>0\).

Every trajectory-return vector, and every expected-return vector, belongs to \([Hr_-,Hr_+]^\tau\). A weighted power mean lies between the smallest and largest coordinates: for positive powers this follows by bounding the summands, for negative powers the same calculation reverses inequalities when taking the negative root, and for power zero it follows by averaging logarithms. Consequently,

\(Hr_-\leq v(\pi,p)\leq Hr_+\), \(\qquad Hr_-\leq V(p)\leq Hr_+\).

The maxima exist. Indeed, there are finitely many trajectories, whose probabilities are continuous functions of the policy coordinates. Both aggregation rules are therefore continuous in \(\pi\) for each fixed \(p\), including \(p=-\infty\). Compactness and nonemptiness of \(\Pi\) then give attainment.

If \(\tau=1\), welfare is independent of \(p\), so one oracle query at \(p=1\) gives an exact portfolio. If \(B=0\), every reward equals \(r_-\), and every policy has welfare \(Hr_-\) for every \(p\); again one query suffices.

Henceforth assume \(\tau\geq2\) and \(B>0\), so \(W>0\).

2. A uniform bound on variation with \(p\)

We first prove, for every \(x\in[Hr_-,Hr_+]^\tau\) and every finite real \(p\),

\(0\leq \dfrac{d}{dp}\ln f_\mu(x,p)\leq \dfrac{B^2}{8}\).

Set \(y_t=\ln(x_t/(Hr_-))\), so \(0\leq y_t\leq B\), and define

\(K(p)=\ln\left(\sum_t\mu_t e^{p y_t}\right)\).

Because all masses are positive, \(K\) is smooth on the real line, and \(K(0)=0\). With the probability weights

\(w_t(p)=\dfrac{\mu_t e^{p y_t}}{\sum_u\mu_u e^{p y_u}}\),

differentiation gives

\(K'(p)=\sum_t w_t(p)y_t\),

and

\(K''(p)=\sum_t w_t(p)y_t^2-\left(\sum_t w_t(p)y_t\right)^2\).

Thus \(K''(p)\) is a variance. Writing \(a=\sum_t w_t(p)y_t\), the inequality \(y_t^2\leq By_t\) gives

\(0\leq K''(p)\leq Ba-a^2\leq B^2/4\).

For \(p\neq0\), the definition of the power mean gives

\(\ln f_\mu(x,p)=\ln(Hr_-)+K(p)/p\).

Since \(K(0)=0\), the identity \(K(p)/p=\int_0^1K'(sp)\,ds\) holds for \(p\neq0\). Its continuous extension at zero equals \(K'(0)\), which is precisely the logarithm of the normalized geometric mean. Therefore, for every finite \(p\),

\(\ln f_\mu(x,p)=\ln(Hr_-)+\int_0^1K'(sp)\,ds\).

Differentiating this smooth integral yields

\(\dfrac{d}{dp}\ln f_\mu(x,p)=\int_0^1sK''(sp)\,ds\).

The variance bound proves the claim.

Put \(D=B^2/8\). Integrating the derivative bound shows that for finite \(p\leq q\),

\(f_\mu(x,p)\leq f_\mu(x,q)\leq e^{D(q-p)}f_\mu(x,p)\).

For aggregation rule \(\ell=1\), apply these inequalities to each trajectory-return vector and take expectations. For rule \(\ell=2\), apply them to the expected-return vector. In either case,

\(v(\pi,p)\leq v(\pi,q)\leq e^{D(q-p)}v(\pi,p)\).

Taking maxima over policies gives

\(V(p)\leq V(q)\leq e^{D(q-p)}V(p)\). \[\tag{1}\]

Moreover, \(v(\pi,-\infty)\leq v(\pi,p)\), because a power mean is at least the minimum coordinate. Thus monotonicity also includes the left endpoint.

3. Truncating the negative tail

For any positive vector \(x\), let \(M=\min_t x_t\). For \(q>0\), a coordinate attaining \(M\) contributes at least \(\mu_{\min}M^{-q}\) to the defining sum. Taking the negative root gives

\(M\leq f_\mu(x,-q)\leq \mu_{\min}^{-1/q}M=e^{W/q}M\).

As above, these pointwise inequalities transfer to both aggregation rules and then to their optimal values:

\(V(-\infty)\leq V(-q)\leq e^{W/q}V(-\infty)\). \[\tag{2}\]

Choose

\(Q=\dfrac{2W}{\varepsilon}\).

Query the optimization oracle at \(-\infty\), obtaining a maximizing policy \(\pi_-\), and write \(C_-=V(-\infty)\).

For every \(p\in[-\infty,-Q]\), monotonicity and (2) imply

\(v(\pi_-,p)\geq C_-\), \(\qquad V(p)\leq V(-Q)\leq e^{\varepsilon/2}C_-\).

Hence \(\pi_-\) alone approximates this entire tail within the factor \(e^{-\varepsilon/2}=\sqrt{\alpha}\).

4. Algorithm on the remaining interval

Let

\(n=\max\left\{1,\left\lceil\dfrac{2D(1+Q)}{\varepsilon}\right\rceil\right\}\),

and define the equally spaced grid

\(p_i=-Q+\dfrac{i(1+Q)}{n}\), \(\qquad i=0,\ldots,n\).

Its spacing satisfies

\(D(p_{i+1}-p_i)\leq\varepsilon/2\). \[\tag{3}\]

Initialize the portfolio with \(\pi_-\), and initialize an anchor consisting of parameter \(c=-\infty\), policy \(\pi_c=\pi_-\), and value \(C=C_-\).

Process the grid in increasing order:

  • Query the optimization oracle at \(p_i\), obtaining \(\pi_i\) and \(V_i=V(p_i)\).
  • If \(V_i>e^{\varepsilon/2}C\), add \(\pi_i\) to the portfolio and replace the anchor by \(c=p_i\), \(\pi_c=\pi_i\), \(C=V_i\).
  • Otherwise keep the current anchor.

After processing \(p_i\), the anchor always satisfies

\(c\leq p_i\), \(\qquad v(\pi_c,c)=C\), \(\qquad V(p_i)\leq e^{\varepsilon/2}C\). \[\tag{4}\]

Indeed, a replacement makes \(C=V(p_i)\); without replacement, the comparison in step 2 supplies the last inequality.

5. Approximation proof

The negative tail was proved covered in Section 3.

Now take \(p\in[p_i,p_{i+1}]\), and use the anchor immediately after processing \(p_i\). By monotonicity and (4),

\(v(\pi_c,p)\geq v(\pi_c,c)=C\).

By (1), (3), and (4),

\(V(p)\leq e^{D(p-p_i)}V(p_i)\leq e^{\varepsilon/2}V(p_i)\leq e^\varepsilon C\).

Therefore,

\(v(\pi_c,p)\geq e^{-\varepsilon}V(p)=\alpha V(p)\).

These intervals cover \([-Q,1]\). Every anchor policy is retained in the final portfolio, so the portfolio covers every \(p\in[-\infty,1]\).

This proves the approximation guarantee for either aggregation rule.

6. Portfolio size and resource bounds

Portfolio size

Every anchor replacement increases \(C\) by a factor strictly greater than \(e^{\varepsilon/2}\). If there are \(k\) replacements, then for \(k>0\),

\(k\varepsilon/2<\ln(C_{\mathrm{final}}/C_-)\leq\ln(Hr_+/(Hr_-))=B\).

Thus, including the initial policy,

\(|\Pi'|\leq1+\dfrac{2B}{\varepsilon}\leq1+\dfrac{2\ln\kappa}{\ln(1/\alpha)}\).

Repeated policies only reduce the size of the resulting set.

Oracle queries

There is one query at \(-\infty\) and \(n+1\) grid queries. Since \(D=B^2/8\) and \(Q=2W/\varepsilon\), the query count is

\(O\left(1+\dfrac{B^2}{\varepsilon}+\dfrac{WB^2}{\varepsilon^2}\right)\).

Under the usual binary encoding of rational numerators and denominators, the total input length implies

\(B\leq2L\ln2\), \(\qquad W\leq L\ln2\).

Also,

\(\varepsilon=-\ln\alpha\geq1-\alpha\).

Consequently, the number of queries is

\(O\left(1+\dfrac{L^2}{1-\alpha}+\dfrac{L^3}{(1-\alpha)^2}\right)\),

which is polynomial in the requested parameters.

Exact real operations

Computing reward extrema and the minimum mass takes \(O(\tau|S||A|)\) comparisons. Computing the parameters, generating the grid, and processing the returned optimal values requires a constant number of exact real operations per grid point. The integer \(n\) can, if necessary, be found by incrementing an integer counter and comparing against its defining real threshold, using \(O(n)\) operations.

Even charging for handling every returned policy’s \(H|S||A|\) coordinates preserves polynomial complexity in \(m,\tau,L,H,(1-\alpha)^{-1}\).

The algorithm uses no additional welfare-evaluation calls: every comparison uses a welfare value supplied by an optimization query. In particular, it never enumerates trajectories.
