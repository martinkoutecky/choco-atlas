The continuous mirror question, as graded

Given two paths with resource categories \(I\), a finite support \(T\) of bid types with rational masses \(\mu_t>0\) summing to \(1\), packages \(S_t\subseteq I\) that are unions of at most one interval from each path, prices \(p_t\), per-capita supplies \(\sigma_i\), and a revenue threshold \(R\), decide whether accepted masses \(y_t\) exist such that \(0\le y_t\le\mu_t\), \(\sum_{t:i\in S_t}y_t\le\sigma_i\) for every \(i\in I\), and \(\sum_{t\in T}p_ty_t\ge R\). Each individual receives the whole package or nothing; \(y_t\) is the accepted mass of type \(t\).

Given two nonempty vertex-disjoint paths whose resource categories form a set \(I\), let \(m=|I|\). A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.

The input also specifies nonnegative binary-rational per-capita supplies \(\sigma_i\) and a binary-rational revenue threshold \(R\). Unused resources are allowed, and there are no exclusivity constraints between bids beyond resource capacities. Let \(L\) be the total binary encoding length of the input.

For discrete bids and one unit of each item, deciding whether disjoint accepted packages reach a revenue threshold is \(\mathrm{NP}\)-complete on two disjoint paths, even with bid prices in \(\{1,2\}\). This discrete result does not classify the continuous problem stated here.

Result

The continuous revenue-threshold problem belongs to \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\). The proof applies to arbitrary explicitly listed packages; the two-path interval restriction is unnecessary.

1. An equivalent linear feasibility system

Index the resource categories by \(I=\{1,\ldots,m\}\) and the supported types by \(T=\{1,\ldots,\tau\}\). Define the incidence matrix \(A\in\{0,1\}^{m\times\tau}\) by

\(A_{it}=1\) if \(i\in S_t\), and \(A_{it}=0\) otherwise.

Introduce one real variable \(y_t\) for each supported type. Consider the following system:

  • \(-y_t\le 0\) for every \(t\in T\);
  • \(y_t\le\mu_t\) for every \(t\in T\);
  • \(\sum_{t=1}^{\tau}A_{it}y_t\le\sigma_i\) for every \(i\in I\);
  • \(-\sum_{t=1}^{\tau}p_ty_t\le -R\).

This system has \(\tau\) variables and \(k=m+2\tau+1\) inequalities.

Its feasibility is exactly the question asked. Indeed, the first two families impose the accepted-mass bounds, the third imposes precisely the resource capacities, and the last is equivalent to the revenue requirement. Thus a vector satisfies this system if and only if it is an admissible accepted-mass vector reaching the threshold.

In particular, there is no enumeration of possible types: only the \(\tau\) types in the supplied support become variables.

2. The constructed system has polynomial encoding length

The matrix \(A\) can be constructed by checking membership in the listed intervals for every resource-type pair. This takes polynomial time in \(m,\tau,L\).

All coefficients in the feasibility system are either \(0\), \(1\), \(-1\), or rational numbers already present in the input, possibly with their signs reversed. Every such coefficient therefore has encoding length at most \(O(L+1)\). A dense representation of the entire system consequently has total encoding length

\(B=O\bigl((m+2\tau+1)(\tau+1)(L+1)\bigr)\),

which is polynomial in \(m,\tau,L\).

For completeness, rational inequalities can also be converted to integer inequalities without superpolynomial growth. For each row, multiply by the product of the positive denominators occurring in that row. This preserves the inequality because the multiplier is positive. The product’s bit length is at most the sum of the denominators’ bit lengths. Hence every resulting integer coefficient has bit length \(O(B+1)\), and the entire integer system still has polynomial encoding length.

3. Exact feasibility is decidable in polynomial time

We use the following standard linear-programming theorem:

Polynomial-time linear feasibility theorem. Given an explicitly encoded finite system \(Cx\le d\) with integer coefficients, a deterministic algorithm decides whether it has a solution over the real numbers in time polynomial in its total binary encoding length.

This is the feasibility result established by [Khachiyan’s polynomial-time linear-programming algorithm](https://www.mathnet.ru/eng/dan42319). It applies to arbitrary systems, including infeasible systems and systems whose feasible sets have empty interior. Its conclusion is an exact feasibility decision.

The integer system constructed above meets every hypothesis: it is finite, explicitly represented, and has integer coefficients with polynomial total encoding length. Applying the theorem therefore decides the original problem in time polynomial in \(m,\tau,L\).

Including the revenue inequality directly in the system also handles the boundary case where attainable revenue equals \(R\). No approximation of the optimal revenue or numerical tolerance is needed.

4. Why the discrete hardness result does not transfer

The stated model allows every real mass \(y_t\) in the interval \(0\le y_t\le\mu_t\). These are precisely linear constraints.

Discrete bid acceptance instead requires a binary decision for each bid. Those integrality requirements are absent here. Accepting a fraction of a type’s population is permitted by the continuous model, while each accepted individual still receives the whole package. Consequently, the discrete hardness theorem supplies no hardness classification for this linear feasibility problem.

The requested classification is therefore polynomial-time solvable. As usual, this does not rule out being \(\mathrm{NP}\)-hard under the hypothesis \(\mathrm{P}=\mathrm{NP}\).
