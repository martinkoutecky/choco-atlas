The continuous mirror question, as graded

Require \(\sum_r x_{t,r}=\mu_t\) for every \(t\), \(\sum_{t,r} r x_{t,r}=q\), and maximize \(\min_{t,r:x_{t,r}>0} f_t(r)/w_t\).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is polynomial-time solvable. Both the exact optimal welfare and an attaining rational allocation can be computed in

\(O\!\left(m\tau\log(m\tau+1)L^2\right)\)

bit operations using standard integer arithmetic. The allocation constructed below uses at most two bundle sizes per type.

The proof directly handles the distribution over types; it does not require the finite-agent theorem in the [cited paper](https://arxiv.org/html/2604.25308v2).

1. Feasibility at a welfare threshold

Define the weighted utility values by

\(a_{t,r}=f_t(r)/w_t\).

Because \(w_t>0\), each sequence is strictly increasing:

\(0=a_{t,0}<a_{t,1}<\cdots<a_{t,m}\).

Fix a nonnegative threshold \(z\). If \(z\leq a_{t,m}\), define

\(k_t(z)=\min\{r\in\{0,\ldots,m\}:a_{t,r}\geq z\}\).

Strict monotonicity implies that the bundle sizes meeting the threshold for type \(t\) are exactly \(\{k_t(z),\ldots,m\}\).

Threshold feasibility lemma. An allocation with welfare at least \(z\) exists if and only if

\(z\leq a_{t,m}\quad\text{for every }t\in T\)

and

\(B(z):=\sum_{t\in T}\mu_t k_t(z)\leq q\).

Proof of necessity. Suppose \(\lambda(x)\geq z\). Every positive coordinate \(x_{t,r}\) then satisfies \(a_{t,r}\geq z\). Since \(\mu_t>0\) and \(\sum_r x_{t,r}=\mu_t\), some coordinate of every type is positive. Thus \(z\leq a_{t,m}\) for every type, and all its positive coordinates have \(r\geq k_t(z)\). Consequently,

\(q=\sum_{t,r}r x_{t,r}\geq\sum_t k_t(z)\sum_r x_{t,r}=\sum_t\mu_t k_t(z)=B(z)\).

Proof of sufficiency. Suppose the stated conditions hold. Write \(k_t=k_t(z)\) and \(B=B(z)\).

If \(B=m\), the inequalities \(B\leq q\leq m\) force \(q=m\). Also,

\(0=m-B=\sum_t\mu_t(m-k_t)\).

Every summand is nonnegative and every \(\mu_t\) is positive, so \(k_t=m\) for all \(t\). Set \(x_{t,m}=\mu_t\), with every other coordinate zero.

If \(B<m\), define

\(\theta=\dfrac{q-B}{m-B}\).

Since \(B\leq q\leq m\), we have \(0\leq\theta\leq1\). Define, for every type and bundle size,

\(x_{t,r}=\mu_t\bigl((1-\theta)\mathbf{1}_{\{r=k_t\}}+\theta\mathbf{1}_{\{r=m\}}\bigr)\).

Here the indicator is one when its condition holds and zero otherwise; when \(k_t=m\), the two contributions combine into \(x_{t,m}=\mu_t\).

The coordinates are nonnegative, and their sum for type \(t\) is \(\mu_t\). Their total supply is

\(\sum_{t,r}r x_{t,r}=(1-\theta)B+\theta m=B+\theta(m-B)=q\).

Every positive coordinate has bundle size \(k_t\) or \(m\), both of which meet threshold \(z\). Hence \(\lambda(x)\geq z\). This proves the lemma.

For the easy boundary regime \(0<q<1\), the optimum is zero: positive welfare would require every positive coordinate to have bundle size at least one, forcing supply at least \(\sum_t\mu_t=1\). The lemma also covers all \(q\geq1\).

2. Exact characterization of the optimum

Let

\(C=\{a_{t,r}:t\in T,\ r\in\{0,\ldots,m\}\}\).

This is a finite set of rational numbers containing zero.

For every allocation, its welfare belongs to \(C\): the set of positive coordinates is finite and nonempty, so the minimum defining welfare is attained at one of them.

Threshold zero is feasible by the lemma, since \(k_t(0)=0\) and \(B(0)=0\). Therefore the following maximum exists:

\(z^\star=\max\left\{z\in C:z\leq a_{t,m}\text{ for all }t,\ \sum_t\mu_t k_t(z)\leq q\right\}\).

Apply the lemma’s construction at \(z^\star\). It produces an allocation \(x^\star\) satisfying \(\lambda(x^\star)\geq z^\star\).

Conversely, any allocation \(x\) has \(\lambda(x)\in C\), and this value is a feasible threshold. By the definition of \(z^\star\), it follows that \(\lambda(x)\leq z^\star\).

Thus

\(\lambda(x^\star)=z^\star=\max_x\lambda(x)\).

This proves both optimality and attainment, without any continuity assumption on the welfare function.

3. Algorithm and running time

Put \(N=\tau(m+1)\). Use the following algorithm:

  • Form the \(N\) rational values \(a_{t,r}\), sort them, and remove duplicates.
  • Binary-search this sorted list for its largest feasible threshold.
  • At each tested threshold \(z\), scan each type’s utility table to find \(k_t(z)\). Reject if some type has no qualifying size; otherwise test \(\sum_t\mu_t k_t(z)\leq q\).
  • Construct the allocation at the largest feasible threshold using the formula in Section 1.

Binary search is valid because feasibility is monotone: an allocation meeting threshold \(z\) also meets every threshold \(z'\leq z\).

Sorting uses \(O(N\log(N+1))\) rational comparisons. Each feasibility test uses \(O(N)\) comparisons and arithmetic operations, and binary search makes \(O(\log(N+1))\) tests. Allocation construction and dense output require \(O(N)\) further operations. The total is therefore

\(O(N\log(N+1))\)

exact arithmetic operations.

To justify the bit complexity, all integers representing an individual ratio \(f_t(r)/w_t\) have \(O(L)\) bits. These ratios can be compared exactly by cross multiplication.

For supply calculations, write \(\mu_t=p_t/d_t\) and use the common denominator

\(D=\prod_{t\in T}d_t\).

Its bit length is at most the sum of the input denominator lengths, hence \(O(L)\). Then

\(B(z)=\dfrac{\sum_t p_t(D/d_t)k_t(z)}{D}\).

The numerator is at most \(mD\), because \(k_t(z)\leq m\) and \(\sum_t\mu_t=1\). It therefore has \(O(L+\log m)=O(L)\) bits. Comparisons with \(q\), and the rational calculations constructing \(\theta\) and \(x^\star\), likewise involve only \(O(L)\)-bit integers.

Standard integer arithmetic performs these operations in \(O(L^2)\) bit operations each. Since \(m\geq1\), the resulting bound is

\(O\!\left(m\tau\log(m\tau+1)L^2\right)\).

All output masses are exact rationals of polynomial encoding length. Finally, the explicit utility tables imply \(N=O(L)\), so this is polynomial in the total binary input length as well.
