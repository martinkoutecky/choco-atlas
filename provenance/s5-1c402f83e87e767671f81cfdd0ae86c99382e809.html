The continuous mirror question, as graded

Given a finite cost-type set \(T\subseteq[0,1]\), rational masses \(\mu_t>0\) summing to \(1\), benefit \(v\), and quota \(\alpha<v\), consider a unit-mass society with mass \(\mu_t\) of members whose cost is \(t\). Assume the distribution satisfies the discrete counterpart of the paper's monotone-hazard condition. A mechanism maps reported types to binary activity recommendations, which are enforceable; there are no transfers, success requires active mass at least \(\alpha\), and truthful reporting must satisfy interim incentive compatibility and individual rationality. Find a mechanism maximizing expected per-capita utility \(v\Pr[\mathrm{success}]-\sum_{t\in T}\mu_t t\,a(t)\), where \(a(t)\) is a type-\(t\) member's activation probability.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(T=\{t_1<\cdots<t_\tau=1\}\subseteq[0,1]\), with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Costs, benefit \(v\), quota \(\alpha\), and welfare threshold \(B\) are binary rationals, with \(0<\alpha<v<1\); \(L\) is their total input bit length.
Assume the discrete monotone-hazard condition: \(h_i=\mu_{t_i}/\sum_{j=i}^{\tau}\mu_{t_j}\) is nondecreasing in \(i\).
The society is atomless. Each member privately knows its cost and reports an element of \(T\). Mechanisms are anonymous and depend on the report profile only through its mass distribution; a unilateral report change leaves that distribution unchanged.
At each report distribution, a mechanism chooses a lottery over vectors \(x\in[0,1]^\tau\), activating fraction \(x_r\) of the members reporting \(r\), symmetrically within each report class. Each member's realized action is binary and enforceable; there are no transfers or obedience constraints.
At truthful reports, let \(P=\Pr[\sum_{t\in T}\mu_t x_t\ge\alpha]\) and \(a(r)=\mathbb E[x_r]\). A true type \(t\) reporting \(r\) has interim utility \(vP-ta(r)\), where the expectation is over mechanism randomization. Require interim incentive compatibility \(vP-ta(t)\ge vP-ta(r)\) for all \(t,r\in T\), and interim individual rationality \(vP-ta(t)\ge0\), with outside utility \(0\).
The optimization problem maximizes expected per-capita welfare \(vP-\sum_{t\in T}\mu_t t\,a(t)\).

Is deciding whether a feasible mechanism achieves welfare at least \(B\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(\tau\), \(L\), and the fixed action-domain size \(m=2\).

For finitely many independent members with costs on \([0,1]\) satisfying monotone hazard rate, a uniform lottery activating exactly the required number is welfare-optimal under interim incentive compatibility and individual rationality whenever the required fraction is below \(v\), and succeeds surely ([Battaglini–Palfrey](https://www.nber.org/papers/w30991)). Result

The decision problem is in \(\mathrm P\). In fact, the optimal welfare has an explicit formula, and an optimal mechanism succeeds surely. The monotone-hazard assumption is unnecessary for this conclusion.

Define the zero-cost mass by \(z=\mu_0\) if \(0\in T\), and by \(z=0\) otherwise. Let \(w=1-z\) be the positive-cost mass, and let \(C=\sum_{t\in T}\mu_t t\) be the mean cost. Because \(1\in T\) has positive mass, \(w>0\).

Set \(q=\max\{0,\alpha-z\}/w\). We will prove that the optimal welfare is

\(W^*=v-Cq.\)

1. Incentive compatibility forces equal activation probabilities

A unilateral report change leaves the report distribution unchanged. Consequently, the success probability \(P\) is the same under every report available to a member.

For a positive-cost type \(t\), incentive compatibility therefore gives

\(vP-ta(t)\ge vP-ta(r)\quad\Longleftrightarrow\quad a(t)\le a(r)\)

for every report \(r\in T\). Applying this inequality in both directions to any two positive-cost types shows that all positive-cost reports have a common expected activation probability, denoted by \(a\).

If \(0\in T\), positive-cost types additionally require \(a\le a(0)\). A zero-cost type is indifferent among reports, so its incentive constraints impose no further restriction.

Since the largest cost is \(1\), individual rationality requires \(a\le vP\). Conversely, this inequality ensures individual rationality for every positive-cost type, because \(ta\le a\) for \(t\le1\). Zero-cost types have utility \(vP\ge0\).

In particular, every feasible mechanism has welfare

\(W=vP-Ca.\)

2. A sharp upper bound for every feasible lottery

For a realized activation vector \(x\), define its positive-cost activation mass by

\(S(x)=\sum_{t>0}\mu_t x_t.\)

On a successful realization, total activation is at least \(\alpha\). Zero-cost members can contribute at most \(z\), so

\(S(x)\ge\max\{0,\alpha-z\}.\)

On an unsuccessful realization, \(S(x)\ge0\). Taking expectations therefore yields

\(\mathbb E[S(x)]\ge P\max\{0,\alpha-z\}.\)

By the common activation probability established above,

\(\mathbb E[S(x)]=\sum_{t>0}\mu_t a=wa.\)

Thus \(a\ge Pq\). Substituting into welfare gives

\(W=vP-Ca\le P(v-Cq).\)

Every cost lies in \([0,1]\), so \(C\le w\). Hence

\(Cq\le wq=\max\{0,\alpha-z\}\le\alpha<v.\)

It follows that \(v-Cq>0\). Using \(P\le1\), we obtain the universal bound

\(W\le v-Cq.\)

This argument applies to arbitrary lotteries over the permitted activation vectors.

3. A feasible mechanism attaining the bound

At truthful reports, choose the deterministic activation vector that activates fraction \(1\) of zero-cost reporters, if present, and fraction \(q\) of every positive-cost report class. Within each class, use the symmetric binary activation prescribed by the model. The fractions specify class activation masses; each member’s realized action remains binary.

First, \(0\le q\le\alpha<1\). Indeed, if \(z\ge\alpha\), then \(q=0\). If \(z<\alpha\), the inequality \(q\le\alpha\) follows from

\(\alpha-z\le\alpha(1-z),\)

which is equivalent to \(z(1-\alpha)\ge0\).

The mechanism succeeds surely:

  • If \(z\ge\alpha\), activating the zero-cost class supplies the quota.
  • If \(z<\alpha\), total activation is \(z+wq=\alpha\).

Therefore \(P=1\), and every positive-cost report has expected activation \(q\). Positive-cost types are indifferent among positive-cost reports and weakly prefer them to the zero-cost report, whose activation probability is \(1\). Zero-cost types are indifferent among all reports. Thus incentive compatibility holds.

For every positive-cost type, utility is

\(v-tq\ge v-q\ge v-\alpha>0.\)

A zero-cost type has utility \(v>0\). Hence individual rationality also holds.

The resulting welfare is \(v-Cq\), attaining the upper bound.

The mechanism can also be defined at every report distribution. If its zero-report mass is \(z'\), activate all zero reporters and activate fraction \(\max\{0,\alpha-z'\}/(1-z')\) of every positive report class when \(z'<1\). When \(z'=1\), activate all zero reporters and set the positive-report fractions to zero. This rule depends only on the report distribution and agrees with the optimal vector at truthful reports.

4. Exact decision algorithm and running time

The optimum is therefore

\(W^*= v-C\,\dfrac{\max\{0,\alpha-z\}}{1-z}.\)

In particular, when the support contains no zero-cost type, \(W^*=v-\alpha C\).

The decision algorithm computes \(z\), computes \(C=\sum_t\mu_t t\), evaluates this formula exactly, and accepts precisely when \(W^*\ge B\).

This requires \(\mathcal O(\tau)\) rational arithmetic operations. With total input bit length \(L\), the intermediate numerators and denominators can be kept at \(\mathcal O(L)\) bits: a common denominator can be formed by multiplying the input denominators, whose total bit length is bounded by the input length. Subsequent arithmetic uses only a constant number of additional products and differences.

Using schoolbook integer arithmetic gives the conservative bound \(\mathcal O(\tau L^2)\) bit operations. An optimal activation vector can be output within the same bound. The action-domain size remains fixed at \(m=2\); the algorithm already handles this binary-action model.

Thus the exact atomless, finite-support problem is polynomial-time solvable. The decisive property is the report-invariance of \(P\), which forces equal expected activation among positive-cost types.
