The continuous mirror question, as graded

Given alternatives \(X\), a support \(Τ\) of τ complete rankings, and positive binary-rational masses \(μ_t\) summing to \(1\), compute an exact ranking \(π\) minimizing \(∑_{t\inΤ}\mu_t\left|\left\{\{x,y\}\subseteq X: π\text{ orders }x,y\text{ oppositely to }t\right\}\right|\).

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a finite set of \(m\) alternatives. All input and output rankings are strict total orders of \(X\).
A society is given by its support \(T\): the list of its \(\tau\) distinct types with positive mass, each with its mass \(\mu_t\) as a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number \(m!\) of possible types.
Let \(L\) be the total input bit length. Compute any ranking \(\pi\) minimizing \(\sum_{t\in T}\mu_t d_K(\pi,t)\), where \(d_K\) is Kendall distance; ties between minimizing rankings require no prescribed selection. State running times in \(m,\tau,L\).

Is computing an exact minimizing ranking for this distributional Kemeny problem possible in time polynomial in \(m,\tau,L\), or is it NP-hard?

Known results: linear ordering with nonnegative costs and minimum weighted feedback arc set with positive arc weights admit polynomial-time reductions in both directions ([Ando, Sukegawa and Takagi](https://doi.org/10.15807/jorsj.65.67)). Discrete Kemeny aggregation is NP-hard even for four complete rankings ([Dwork et al.](https://www.wisdom.weizmann.ac.il/~naor/PAPERS/rank_www10.html)).
Minimizing expected Kendall distance over a distribution on rankings is already studied as a population Kemeny median, although that statistical formulation does not specify this binary-rational support input model ([Korba et al.](https://proceedings.mlr.press/v54/korba17a/korba17a.pdf)).

Modeling choices made when packaging the task

  • Interpreted complete rankings as strict total orders, matching the bijection-based discrete definition.
  • Allowed any minimizing ranking when multiple optima exist.
  • Defined L as the total input bit length.

Result

Computing an exact minimizing ranking is \(\mathrm{NP}\)-hard, even when \(\tau\leq 4\) and every mass has constant encoding length. Thus a running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The associated decision problem is \(\mathrm{NP}\)-complete. An exact algorithm runs in
\(O\!\left(\tau B^2+(\tau m^2+m^2 2^m)B\right)\) bit operations, where \(B=O(L+\log(m+1))\).

1. Reduction from four-ranking Kemeny aggregation

Write \(x\prec_\pi y\) when ranking \(\pi\) places \(x\) before \(y\). Kendall distance counts unordered pairs whose relative orders disagree.

We use the given theorem: finding a ranking minimizing
\(\sum_{i=1}^{4}d_K(\pi,r_i)\), for four complete strict rankings \(r_1,\ldots,r_4\), is \(\mathrm{NP}\)-hard; its threshold decision version is \(\mathrm{NP}\)-complete. This is stated in Appendix B, Theorem 11 of [Dwork et al.](https://www.wisdom.weizmann.ac.il/~naor/PAPERS/rank_www10.html).

Given such an instance, let \(T\) be the set of distinct rankings among \(r_1,\ldots,r_4\). For each \(t\in T\), define its multiplicity and mass by

\(\displaystyle n_t=\bigl|\{i:r_i=t\}\bigr|,\qquad \mu_t=\frac{n_t}{4}.\)

This is a valid instance of the requested input model:

  • The support contains distinct strict total orders, and \(\tau\leq 4\).
  • Every mass is positive, and \(\sum_{t\in T}\mu_t=1\).
  • Each mass belongs to \(\{1/4,1/2,3/4,1\}\), so its encoding has constant length.

For every output ranking \(\pi\),

\(\displaystyle \sum_{t\in T}\mu_t d_K(\pi,t)=\frac14\sum_{i=1}^{4}d_K(\pi,r_i).\)

Multiplication by a positive constant preserves all minimizers. Consequently, any minimizing ranking returned for the distributional instance solves the original instance; no tie-breaking rule is needed.

With alternatives labeled by \(\{1,\ldots,m\}\), comparing and merging the four rankings takes \(O(m\log(m+1))\) bit operations, and the resulting input has \(L=O(m\log(m+1))\). Hence a polynomial-time algorithm in \(m,\tau,L\) would solve the known hard problem in polynomial time.

For decision instances, a discrete threshold \(K\) becomes the rational threshold \(K/4\), since

\(\displaystyle \sum_{i=1}^{4}d_K(\pi,r_i)\leq K \quad\Longleftrightarrow\quad \sum_{t\in T}\mu_t d_K(\pi,t)\leq K/4.\)

This proves decision hardness as well.

2. Exact arithmetic and decision membership

Use the standard binary-rational encoding, writing \(\mu_t=a_t/b_t\) with positive integers \(a_t,b_t\). Define

\(\displaystyle Q=\prod_{t\in T}b_t,\qquad w_t=a_t(Q/b_t).\)

Then every \(w_t\) is a positive integer, and \(\sum_t w_t=Q\). The total bit length of the encoded denominators is at most \(L\), so \(Q\) has \(O(L)\) bits, even though its numerical value may be large.

For distinct alternatives \(x,y\), define the integer cost

\(\displaystyle C_{xy}=\sum_{\substack{t\in T\\y\prec_t x}}w_t.\)

This is the cost of placing \(x\) before \(y\). If \(\pi=(\pi_1,\ldots,\pi_m)\), then counting each unordered pair once gives

\(\displaystyle Q\sum_{t\in T}\mu_t d_K(\pi,t) =\sum_{1\leq i<j\leq m}C_{\pi_i\pi_j}.\)

Indeed, a pair placed as \(x\prec_\pi y\) contributes exactly those masses whose rankings place \(y\prec_t x\). Also, \(0\leq C_{xy}\leq Q\), and every scaled objective value is at most \(\binom m2Q\).

Therefore all these integers fit in

\(\displaystyle B=L+2\lceil\log_2(m+1)\rceil+3\)

bits. A candidate ranking can be verified and its objective compared with an encoded rational threshold using polynomially many bit operations, including the threshold’s encoding length. The decision problem belongs to \(\mathrm{NP}\), and Section 1 therefore makes it \(\mathrm{NP}\)-complete.

3. An exact algorithm and its running time

For \(m\leq 1\), the unique ranking is optimal. Otherwise, compute \(Q\), the integer weights, and the pair costs above.

For each subset \(S\subseteq X\), let \(D(S)\) be the minimum scaled pair cost of a strict ordering of \(S\). Set \(D(\varnothing)=0\), and use

\(\displaystyle D(S)=\min_{x\in S}\left(D(S\setminus\{x\})+ \sum_{y\in S\setminus\{x\}}C_{yx}\right).\)

To prove this recurrence, consider an ordering of \(S\) ending in \(x\). Its cost is the cost of its restriction to \(S\setminus\{x\}\), plus precisely the costs \(C_{yx}\) for all other elements \(y\). The former is at least \(D(S\setminus\{x\})\). Conversely, appending \(x\) to an optimal ordering of \(S\setminus\{x\}\) attains the corresponding expression. Minimizing over the possible last elements proves the recurrence.

Evaluate subsets in increasing cardinality and record an attaining last element for each subset. Backtracking from \(X\) reconstructs an optimal strict total order. Ties can be resolved arbitrarily.

Using schoolbook integer arithmetic:

  • Computing \(Q\) and the weights takes \(O(\tau B^2)\) bit operations.
  • Computing all pair costs takes \(O(\tau m^2B)\) bit operations, with input reading absorbed in these bounds.
  • Evaluating the recurrence by directly summing each transition takes \(O(m^2 2^mB)\) bit operations.

The resulting total is

\(\displaystyle O\!\left(\tau B^2+(\tau m^2+m^2 2^m)B\right), \qquad B=O(L+\log(m+1)).\)

Storage is \(O\!\left(L+(m^2+2^m)B\right)\) bits, including reconstruction choices.

Thus binary-rational masses permit exact arithmetic with polynomial bit lengths, but they do not remove the computational hardness: constant support size already suffices.
