Fix an integer \(k\geq1\). A society is given by its support: a list of \(\tau\geq1\) types with positive binary-rational masses, here \(\mu_t=1/\tau\), summing to \(1\); \(\tau\) counts supported types, not possible types.
The input also contains a finite simple undirected graph \(H=(T,F)\) on these types and an integer \(1\leq p\leq\tau\). Choose \(A\subseteq T\) with \(|A|=p\), maximizing \(f(A)=\sum_{t\in\bigcup_{a\in A}N_k[a]}\mu_t\), where \(N_k[a]=\{t\in T:\operatorname{dist}_H(a,t)\leq k\}\). Activated types count toward the objective; disconnected pairs have infinite distance. Activation selects whole types.
Let \(m=|F|\) and let \(L\) be the total binary input length; polynomial time means polynomial in \(m,\tau,L\), with \(p\) part of the input and \(k\) fixed.

What is the optimal polynomial-time multiplicative approximation ratio for this population-mass objective, assuming \(\mathrm{P}\ne\mathrm{NP}\)?

For discrete maximum \(k\)-hop domination, a \((1-1/e)\)-approximation exists, and every larger constant ratio is impossible unless \(\mathrm{P}=\mathrm{NP}\), for each fixed \(k\geq1\). [Source](https://arxiv.org/pdf/2305.19251)
The stated uniform-mass problem is exactly that problem with every objective value divided by \(\tau\), so these same bounds already settle its approximation threshold.

Result

For every fixed integer \(k\geq1\), the optimal polynomial-time constant multiplicative approximation ratio is \(1-1/e\), assuming \(\mathrm{P}\ne\mathrm{NP}\). Greedy attains this ratio; every strictly larger constant is impossible.

1. Exact equivalence with discrete domination

Define the number of covered types by
\(D(A)=\left|\bigcup_{a\in A}N_k[a]\right|\).

Because every supported type has mass \(1/\tau\), the population objective satisfies
\(f(A)=D(A)/\tau\).

The feasible sets for both objectives are exactly the subsets of \(T\) with cardinality \(p\). Consequently, if \(D^\star\) and \(f^\star\) denote their respective optimal values, then
\(f^\star=D^\star/\tau\).

Furthermore, \(D^\star\geq p\geq1\), because each activated type covers itself. Hence, for every feasible \(A\),
\(\frac{f(A)}{f^\star}=\frac{D(A)}{D^\star}\).

Thus normalization preserves every multiplicative approximation guarantee exactly. This uses the stipulated inclusion of activated types in the objective.

2. Polynomial-time approximation

Compute every closed neighborhood \(N_k[v]\) by breadth-first search, stopping at distance \(k\). Starting with \(A_0=\varnothing\), perform \(p\) iterations, each time selecting an unselected vertex that covers the largest number of currently uncovered types.

Here is a direct proof of the guarantee. Let \(O\) be an optimal set of \(p\) vertices, and write \(C_i=D(A_i)\). For an unselected vertex \(v\), define its marginal contribution by
\(\Delta_i(v)=|N_k[v]\setminus\bigcup_{a\in A_i}N_k[a]|\).

The neighborhoods of vertices in \(O\setminus A_i\) collectively cover every type covered by \(O\) that remains uncovered by \(A_i\). Therefore,
\(\sum_{v\in O\setminus A_i}\Delta_i(v)\geq D^\star-C_i\).

Indeed, the number of such remaining types is at least \(D^\star-C_i\), and the sum counts each of them at least once. There are at most \(p\) summands. Consequently, some unselected vertex has marginal contribution at least \((D^\star-C_i)/p\). When this quantity is zero, the same conclusion follows from nonnegativity of all marginals.

Greedy therefore satisfies
\(C_{i+1}\geq C_i+(D^\star-C_i)/p\),
or equivalently,
\(D^\star-C_{i+1}\leq(1-1/p)(D^\star-C_i)\).

Starting from \(C_0=0\) and iterating yields
\(C_p\geq[1-(1-1/p)^p]D^\star\).

For \(p=1\), greedy is exact. For \(p>1\), the inequality \(1-x\leq e^{-x}\) gives \((1-1/p)^p\leq e^{-1}\). Hence
\(f(A_p)\geq(1-1/e)f^\star\).

All neighborhoods can be computed in time \(O(\tau(\tau+m))\). Using explicit membership arrays, greedy takes \(O(p\tau^2)\) additional time. These bounds are polynomial in the stipulated input parameters.

3. Matching impossibility result

The cited paper’s Definition 2 uses undirected graphs, exactly \(p\) chosen vertices, and closed distance-\(k\) neighborhoods, including the chosen vertices themselves. Its Theorem 1 states that, for every fixed integer \(k\geq1\), no polynomial-time approximation with any constant factor strictly greater than \(1-1/e\) exists unless \(\mathrm{P}=\mathrm{NP}\). These are precisely the discrete objective and constraints above. [Aivasiliotis and Pagourtzis, Definition 2 and Theorem 1](https://arxiv.org/pdf/2305.19251)

To apply that theorem, take any discrete instance on \(\tau\) vertices and assign every vertex mass \(1/\tau\), retaining its graph and budget. Each rational mass has a binary numerator-denominator representation of length \(O(\log(\tau+1))\), so this transformation has polynomial size and takes polynomial time.

An algorithm achieving a constant ratio \(r>1-1/e\) for population mass would, on these transformed instances, achieve exactly the same ratio for discrete domination by Section 1. The cited theorem rules this out under \(\mathrm{P}\ne\mathrm{NP}\).

Thus the threshold is settled. Greedy’s stronger finite-budget guarantee \(1-(1-1/p)^p\) is consistent with this result: the hardness excludes a constant improvement valid uniformly over all input budgets.
