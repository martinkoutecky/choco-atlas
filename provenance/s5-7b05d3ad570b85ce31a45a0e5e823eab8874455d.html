The continuous mirror question, as graded

Given rational masses \(\mu_t\) over finitely many complete additive utility types \(t\), rational per-capita supplies \(q_j\) of \(m\) object types, and unit equal incomes, let \(v_t^\star\) be the unique type utilities in the corresponding fractional Eisenberg–Gale market, defined by maximizing \(\sum_t \mu_t\log v_t\) subject to \(v_t=\sum_j u_{tj}y_{tj}\), \(\sum_t\mu_t y_{tj}\le q_j\), and \(y_{tj}\ge0\). Decide whether there are masses \(x_{t,B}\ge0\) over integral bundles \(B\subseteq\{1,\ldots,m\}\) such that \(\sum_B x_{t,B}=\mu_t\), \(\sum_t\sum_{B:j\in B}x_{t,B}=q_j\), and \(x_{t,B}>0\) only when \(\sum_{j\in B}u_{tj}=v_t^\star\). Each person receives a whole bundle, while each type’s mass may split among bundles; define the computational version with exact representation and comparison of the benchmark utilities.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) complete additive utility vectors \(u_t\in\mathbb Q_{\ge0}^m\), with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) object types, with binary-rational per-capita supplies \(0<q_j\le1\); each person may receive at most one object of each type. Every utility vector has a positive entry, and every object type has positive utility for some supported type. Each person has income \(1\).
Define \(v^\star\) as the unique utility vector maximizing \(\sum_t\mu_t\log v_t\), subject to \(v_t=\sum_j u_{tj}y_{tj}\), \(\sum_t\mu_t y_{tj}\le q_j\), and \(y_{tj}\ge0\). These benchmark variables have no individual upper bounds.
The input consists only of \((u,\mu,q)\). Benchmark utilities are represented as exact binary-rational numerator–denominator pairs computed from the input; all comparisons use exact equality. Let \(L\) be the total input bit length.
Decide whether real masses \(x_{t,B}\ge0\), indexed by \(B\subseteq\{1,\ldots,m\}\), satisfy \(\sum_Bx_{t,B}=\mu_t\), \(\sum_t\sum_{B:j\in B}x_{t,B}=q_j\), and \(x_{t,B}>0\Rightarrow\sum_{j\in B}u_{tj}=v_t^\star\). A type may split its mass among bundles, but every recipient must attain its benchmark utility.

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite list of agents and individual objects, existence of a complete integral allocation attaining every agent’s fractional equal-income benchmark utility is strongly NP-complete; it is polynomial-time decidable for binary utilities. [Aziz](https://arxiv.org/html/1501.06627)
Linear Fisher equilibria have rational representations of polynomial bit length and can be computed exactly in polynomial time; this establishes benchmark computation, without settling the bundle-mass feasibility question. [Devanur et al.](https://ics.uci.edu/~vazirani/market.pdf)

Modeling choices made when packaging the task

  • Normalize the society to total mass one, interpreting supplies as per-capita quantities.
  • Use nonnegative rational utilities, allowing zeros, and retain the requirements that every supported type values some object positively and every object is valued positively by some supported type.
  • Use positive supplies at most one, consistent with complete allocation and the restriction to at most one object of each type per person.
  • Retain the stated uncapped Eisenberg–Gale program for the benchmark, consistent with the convex program displayed in the source.
  • Treat benchmark utilities as derived quantities, represented by exact binary rationals rather than supplied as additional input or approximated numerically.
  • Allow real bundle masses and arbitrary splitting among bundles with exactly the benchmark utility; impose no tie-breaking.

Result

The problem is \(\mathrm{NP}\)-complete. It is already \(\mathrm{NP}\)-hard when \(\tau=1\), all utilities are positive integers, and every supply is \(q_j=1/2\).

Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. Reduction from PARTITION

We use the standard \(\mathrm{NP}\)-complete problem PARTITION: given positive integers \(a_1,\ldots,a_m\), decide whether some subset \(S\subseteq\{1,\ldots,m\}\) satisfies \(\sum_{j\in S}a_j=\frac12\sum_{j=1}^m a_j\). This is also the source problem used in [Aziz, Section 3](https://arxiv.org/html/1501.06627).

Construct a society with:

  • one supported type, with mass \(\mu_1=1\);
  • utilities \(u_{1j}=a_j\);
  • supplies \(q_j=1/2\) for every \(j\).

This construction has polynomial encoding length and satisfies every input hypothesis: the mass is positive and sums to one, each supply lies in \((0,1]\), and every utility entry is positive.

Write \(A=\sum_{j=1}^m a_j\). Because there is only one type, the benchmark constraints are exactly \(0\le y_{1j}\le1/2\). Hence every feasible benchmark allocation satisfies

\(\displaystyle v_1=\sum_{j=1}^m a_jy_{1j}\le\frac A2.\)

Equality is attained by \(y_{1j}=1/2\) for every \(j\). Since \(\log v_1\) is strictly increasing for positive \(v_1\), the benchmark is therefore

\(\displaystyle v_1^\star=\frac A2.\)

We now prove both directions of the reduction.

If PARTITION is a yes-instance. Let \(S\) have utility \(A/2\), and let \(S^c\) denote its complement. Its utility is also \(A/2\). Define

\(\displaystyle x_{1,S}=x_{1,S^c}=\frac12,\)

with all other bundle masses zero. The type’s total mass is one. Every object belongs to exactly one of \(S,S^c\), so its allocated mass is \(1/2=q_j\). Both positive-mass bundles attain \(v_1^\star\). Thus the constructed society is feasible.

If the constructed society is feasible. The equality \(\sum_Bx_{1,B}=1\), together with nonnegativity and the finite number of bundles, implies that some bundle \(B\) has positive mass. The benchmark condition then gives

\(\displaystyle \sum_{j\in B}a_j=v_1^\star=\frac A2.\)

Thus \(B\) is a solution to PARTITION.

The construction is therefore a polynomial-time many-one reduction, establishing \(\mathrm{NP}\)-hardness. Crucially, splitting a type’s mass does not defeat this reduction: feasibility still requires at least one exact half-sum bundle, and its complement supplies the required balancing distribution.

2. Polynomial-size certificates for real masses

We next show membership in \(\mathrm{NP}\), including why allowing real masses causes no certificate-size problem.

First compute \(v^\star\) exactly. The given Fisher-market theorem applies to this benchmark. Indeed, set \(z_{tj}=\mu_ty_{tj}\) and \(w_t=\sum_j u_{tj}z_{tj}=\mu_tv_t\). The supply constraints become \(\sum_tz_{tj}\le q_j\), and the objective becomes

\(\displaystyle \sum_t\mu_t\log v_t=\sum_t\mu_t\log w_t-\sum_t\mu_t\log\mu_t.\)

The last term is constant. This is the linear Fisher program with buyer budgets \(\mu_t\) and supplies \(q_j\); supplies can be normalized to one by writing \(z_{tj}=q_jh_{tj}\), giving rational utility coefficients \(u_{tj}q_j\). All transformations have polynomial encoding length. Thus exact benchmark computation takes polynomial time and produces polynomial-length rationals, by [Devanur et al.](https://ics.uci.edu/~vazirani/market.pdf).

Call \((t,B)\) admissible if \(\sum_{j\in B}u_{tj}=v_t^\star\). Associate to it a column \(c_{t,B}\in\{0,1\}^{\tau+m}\): its first \(\tau\) entries indicate type \(t\), and its remaining entries indicate the objects in \(B\).

Let \(C\) contain all admissible columns and let

\(\displaystyle b=(\mu_1,\ldots,\mu_\tau,q_1,\ldots,q_m)^{\mathsf T}.\)

The required feasibility condition is exactly \(Cx=b,\ x\ge0\).

A feasible solution uses at most \(\tau+m\) columns. Choose a feasible solution with the smallest number of positive coordinates. Suppose its corresponding columns are linearly dependent. There is a nonzero dependence vector \(\alpha\) with \(C\alpha=0\); reverse its sign if necessary so that some \(\alpha_i>0\). Set

\(\displaystyle \lambda=\min_{\alpha_i>0}\frac{x_i}{\alpha_i}>0.\)

Then \(x-\lambda\alpha\) is nonnegative, still satisfies the equations, and has fewer positive coordinates: coordinates with negative \(\alpha_i\) increase, while at least one coordinate with positive \(\alpha_i\) becomes zero. This contradicts minimality. The used columns are consequently independent, so their number \(s\) is at most \(\tau+m\).

Their masses have polynomial rational encoding length. Select \(s\) rows giving a nonsingular \(s\times s\) matrix \(M\) from these independent columns. Their masses satisfy \(Mx=b_R\), where \(b_R\) consists of the selected entries of \(b\).

Let \(D\) be the product of the input denominators of all entries of \(b\). Its bit length is at most \(L\), and \(Db_R\) is integral with entries between zero and \(D\). By Cramer’s rule,

\(\displaystyle x_i=\frac{\det M_i}{D\det M},\)

where \(M_i\) replaces column \(i\) of \(M\) by \(Db_R\). Hadamard’s inequality gives

\(\displaystyle |\det M|\le s^{s/2},\qquad |\det M_i|\le D\,s^{s/2}.\)

Thus every mass has numerator and denominator bit lengths \(O(L+s\log(s+1))\).

A certificate therefore lists at most \(\tau+m\) bundles, their types, and polynomial-length rational masses. The verifier computes \(v^\star\), checks each listed bundle’s utility by exact rational arithmetic, and checks nonnegativity and all mass and supply equations. Every check takes polynomial time.

3. Conclusion

The reduction proves hardness even with one supported type and uniform supplies \(1/2\). The certificate argument proves membership in \(\mathrm{NP}\) despite the potentially exponential bundle family and the allowance of real masses. Together they establish \(\mathrm{NP}\)-completeness.
