The continuous mirror question, as graded

Given a rational instance with projects \(A\), approval types \(T\subseteq 2^A\), mass vector \(\mu\), budget \(\ell\), durations \(\delta\), deadline \(\tau\), and a known finite-support joint cost law \(\mathcal D\), decide for threshold \(\sigma\) whether a nonanticipating policy \(\Pi\) exists that is punctual, satisfies conditional \(\alpha\)-risk assessment on every observed history, and for every \(\omega\in\operatorname{supp}(\mathcal D)\) achieves \(u_\mu(B_{\Pi,\omega})\ge \sigma^{-1}\max_{B\subseteq A:c_\omega(B)\le\ell}u_\mu(B)\), where \(u_\mu(B)=\sum_{t\in T}\mu_t|t\cap B|\).

Packaged proof task (what the prover saw — nothing else)

Definitions. An instance has projects \(A\), approval types \(T\subseteq 2^A\) with rational masses \(\mu_t\), budget \(\ell\), durations \(\delta\), deadline \( au\), risk parameter \(\alpha\), and a finite-support joint law \(\mathcal D\) over cost vectors \(c_\omega\). For \(B\subseteq A\), let \(u_\mu(B)=\sum_{t\in T}\mu_t|t\cap B|\).
A nonanticipating policy chooses which projects to start from the costs revealed by projects already completed. It is punctual if every started project finishes by \( au\). At every observed history, if \(F\) is the completed projects, \(U\) the running projects, and \(S\) the projects newly started, it satisfies conditional \(\alpha\)-risk assessment if \(\Pr_{\omega\sim\mathcal D}[c_\omega(U\cup S)\le \ell-c_\omega(F)\mid\text{history}]\ge 1-\alpha\).

Target. Is the following decision problem solvable in polynomial time, or is it NP-hard: given also \(\sigma\), does there exist such a policy \(\Pi\) for which, for every \(\omega\in\operatorname{supp}(\mathcal D)\),
\(u_\mu(B_{\Pi,\omega})\ge \sigma^{-1}\max_{B\subseteq A:\,c_\omega(B)\le\ell}u_\mu(B)\)?

Nearest known results. For finite voter lists with additive approval satisfaction, any online budgeting method satisfying fixed \(\alpha\)-risk assessment has competitive ratio \(\Omega(|A|)\); this remains \(\Omega(2)\) when every cost interval has width \(1\). No result was verified for the distribution-over-types decision problem above.

Theorem

Under the standard explicit finite-support encoding of \(\mathcal D\), the decision problem is \(\mathrm{NP}\)-hard. This remains true under all of the following restrictions:

  • \(\sigma=2\) and \(\alpha=0\);
  • \(\ell=\tau=1\);
  • every project has duration \(1\);
  • there is one approval type of mass \(1\);
  • every project cost belongs to \(\{0,1\}\).

No claim of membership in \(\mathrm{NP}\) is needed for the stated target.

Reduction from Independent Set

Let \((G,k)\) be an instance of Independent Set, where \(G=(V,E)\), \(n=|V|\), and \(1\le k\le n\).

Construct a graph \(H\) as the disjoint union of:

  • \(G\);
  • a set \(I\) of \(n\) isolated vertices;
  • a clique \(Q\) on \(2k+2\) vertices.

Let \(N=|V(H)|\). Then

\[ N=n+n+(2k+2)=2(n+k+1). \]

Write \(\iota(X)\) for the maximum size of an independent set in a graph \(X\). Independence numbers add over disjoint unions. Moreover, \(\iota(I)=n\) and \(\iota(Q)=1\). Consequently,

\[ \iota(H)=\iota(G)+n+1. \]

Since \(N/2=n+k+1\), it follows that

\[ \iota(H)\ge \frac N2 \quad\Longleftrightarrow\quad \iota(G)+n+1\ge n+k+1 \quad\Longleftrightarrow\quad \iota(G)\ge k. \]

Thus it suffices to encode the existence of an independent set of size at least \(N/2\) in \(H\).

Construction of the Policy Instance

Let the projects be \(A=V(H)\). Use the single approval type \(T=\{A\}\) with mass \(\mu_A=1\). Hence, for every \(B\subseteq A\),

\[ u_\mu(B)=\mu_A|A\cap B|=|B|. \]

Set

\[ \ell=1,\qquad \tau=1,\qquad \delta_a=1\ \text{for every }a\in A, \qquad \alpha=0,\qquad \sigma=2. \]

The support of \(\mathcal D\) consists of one anchor scenario \(\omega_0\) and one scenario \(\omega_e\) for every edge \(e\in E(H)\).

In the anchor scenario, define \(c_{\omega_0}(a)=0\) for every \(a\in A\).

For an edge \(e=\{x,y\}\), define

\[ c_{\omega_e}(a)= \begin{cases} 1,&a\in\{x,y\},\\ 0,&a\notin\{x,y\}. \end{cases} \]

Give every scenario probability \(1/(|E(H)|+1)\). In particular, every support scenario has strictly positive probability.

The construction has polynomial size: \(H\) has \(O(n)\) vertices and \(O(n^2)\) edges, and the explicitly listed distribution has polynomial support and polynomial encoding length.

Lemma 1: Every Punctual Policy Chooses a Fixed Initial Set

Every started project must start at time \(0\). Indeed, if a project starts at time \(s\ge0\), its completion time is \(s+\delta_a=s+1\). Punctuality requires \(s+1\le\tau=1\), and hence \(s=0\).

No project therefore completes before all start decisions have been made. Since costs are revealed only upon completion, all scenarios induce the same observed history when projects are selected. Consequently, a deterministic nonanticipating policy chooses one fixed set \(B\subseteq A\), independent of \(\omega\).

If the policy expresses its time-\(0\) choices in several batches, these batches receive no intervening information and may equivalently be viewed as a single choice. Alternatively, at the final time-\(0\) batch, the union \(U\cup S\) is exactly the total selected set \(B\).

Lemma 2: Conditional \(0\)-Risk Assessment Is Equivalent to Independence

At the initial history, \(F=\varnothing\). Conditional \(0\)-risk assessment for the total selected set \(B\) requires

\[ \Pr_{\omega\sim\mathcal D}\bigl[c_\omega(B)\le1\bigr]\ge1. \]

Because every support scenario has positive probability, this holds exactly when \(c_\omega(B)\le1\) for every \(\omega\in\operatorname{supp}(\mathcal D)\).

For an edge \(e=\{x,y\}\),

\[ c_{\omega_e}(B)=|B\cap\{x,y\}|. \]

Thus \(c_{\omega_e}(B)\le1\) for every edge \(e\) exactly when \(B\) contains no two adjacent vertices of \(H\), namely, exactly when \(B\) is an independent set of \(H\).

Conversely, if \(B\) is independent, then every subset of \(B\) also costs at most \(1\) in every scenario. Hence the policy that starts all projects in \(B\) at time \(0\) satisfies the risk condition at every initial sub-batch. After completion, \(c_\omega(F)\le1\), so the condition with no new starts also holds under every resulting conditional distribution.

Therefore, the feasible policies are precisely the fixed independent sets of \(H\).

Lemma 3: The Competitive Guarantee Is Equivalent to \(|B|\ge N/2\)

In the anchor scenario all projects have zero cost. Therefore,

\[ \max_{C\subseteq A:\,c_{\omega_0}(C)\le1}u_\mu(C)=u_\mu(A)=N. \]

Since \(\sigma=2\), the required guarantee in \(\omega_0\) implies

\[ |B|=u_\mu(B)\ge\frac N2. \]

Conversely, in every scenario \(\omega\), every set has utility at most \(N\). Hence

\[ \max_{C\subseteq A:\,c_\omega(C)\le1}u_\mu(C)\le N. \]

Thus every set \(B\) with \(|B|\ge N/2\) satisfies

\[ u_\mu(B)=|B|\ge\frac N2 \ge \frac12\max_{C:\,c_\omega(C)\le1}u_\mu(C) \]

for every support scenario \(\omega\).

Therefore, a valid policy satisfies the competitive guarantee exactly when its independent set \(B\) has size at least \(N/2\).

Correctness of the Reduction

Combining the three lemmas, the constructed instance admits a punctual, nonanticipating, conditionally \(0\)-risk-assessed policy with competitive factor \(2\) if and only if \(H\) has an independent set of size at least \(N/2\). By the padding calculation,

\[ \iota(H)\ge\frac N2 \quad\Longleftrightarrow\quad \iota(G)\ge k. \]

This is a polynomial-time many-one reduction from Independent Set. Hence the target decision problem is \(\mathrm{NP}\)-hard, even under the stated severe restrictions.

1. Claimed result

The prover claims NP-hardness under an explicit finite-support encoding of \(\mathcal D\), even with \(\sigma=2\), \(\alpha=0\), unit budget and deadline, unit durations, one approval type, and binary costs. This directly answers the target’s complexity alternative.

2. Padding reduction

The construction of \(H\) is correct.

  • Independence numbers add across disjoint components.
  • The isolated component contributes \(n\).
  • The nonempty clique contributes \(1\).
  • Therefore \(\iota(H)=\iota(G)+n+1\).
  • The vertex count is \(N=2n+2k+2=2(n+k+1)\), so \(N/2=n+k+1\).

Consequently, \(\iota(H)\ge N/2\) holds exactly when \(\iota(G)\ge k\). The padding is polynomial in the Independent Set instance size.

The restriction \(1\le k\le n\) is harmless: instances outside this range are trivial and can be removed by routine preprocessing.

3. Policy construction and timing

With every duration equal to \(1\) and deadline \(1\), any punctual project must start at time \(0\), under the standard convention that scheduling begins at time \(0\).

Since no selected project completes before time \(1\), no cost information is revealed while the time-\(0\) selection is being made. Nonanticipation therefore forces a deterministic policy to select the same total set \(B\) in every scenario.

The discussion of multiple time-\(0\) batches is adequate: there are finitely many projects, no information arrives between batches, and the risk condition applied to the final batch concerns the union of all projects selected by that point.

4. Risk condition

At the initial history, \(\alpha=0\), \(F=\varnothing\), and \(\ell=1\), so feasibility requires \(c_\omega(B)\le1\) almost surely. Because every explicitly listed scenario has positive probability, this is equivalent to requiring the inequality in every support scenario.

For the scenario associated with \(e=\{x,y\}\),

\[ \(c_{\omega_e}(B)=|B\cap\{x,y\}|\). \]

Thus all edge-scenario inequalities hold exactly when \(B\) contains at most one endpoint of every edge, which is exactly independence in \(H\).

The converse is also checked correctly. Every partial time-\(0\) selection is a subset of an independent set and therefore has cost at most \(1\) in every scenario. After completion, the selected set also has realized cost at most \(1\), so the condition with no running or newly started projects remains valid.

5. Competitive guarantee

The utility calculation \(u_\mu(B)=|B|\) follows immediately from the single approval type \(A\) having mass \(1\).

In the anchor scenario, every project has zero cost, so the offline optimum has utility \(N\). The factor-\(2\) guarantee therefore forces \(|B|\ge N/2\).

Conversely, the offline optimum in every scenario is at most \(N\), since no subset can contain more than all \(N\) projects. Hence any \(B\) with \(|B|\ge N/2\) satisfies the factor-\(2\) inequality in every support scenario. This direction does not require the exact edge-scenario optimum.

6. Encoding size and conclusion

The constructed graph has \(O(n)\) vertices and \(O(n^2)\) edges. There is one explicitly encoded scenario per edge plus the anchor scenario, and all probabilities and numerical parameters have polynomial encoding length.

The reduction is therefore a valid polynomial-time many-one reduction from Independent Set. No membership claim is required to establish the requested NP-hardness classification.

No mathematical gaps or false steps were found. The argument implicitly uses the standard deterministic-policy and nonnegative-start-time conventions, both of which are consistent with the formulation and with the notation \(B_{\Pi,\omega}\).
