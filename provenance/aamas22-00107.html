The continuous mirror question, as graded

Given candidates \(C\), ranking types \(T=L(C)\), a rational society \(\mu^\star\in\Delta(T)\), target outcome \(X^\star\subseteq C\), a finite corpus \(\mathcal A\) of scale-free lifted axiom schemas, and a certificate bound \(k\), compute whether there exists an inclusion-minimal explanation \(A_E\) with \(|A_E|\le k\) and normative basis \(A_N\) such that every anonymous rule \(F_\infty:\Delta(T)\to2^C\setminus\{\varnothing\}\) satisfying \(A_E\) yields \(F_\infty(\mu^\star)=X^\star\), \(A_E\) consists of instances from \(A_N\), and \(A_N\) is jointly satisfiable.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set, \(m=|C|\), and \(T=L(C)\) the strict ranking types. Write \(D=\Delta(T)\cap\mathbb Q^T\). A society is given by its support: the list of its \(\tau\) positive-mass types and their binary rational masses, summing to \(1\); \(\tau\) is the support size, not \(m!\).
An anonymous rule is any function \(F_\infty:D\to 2^C\setminus\{\varnothing\}\); winning sets retain ties, and no continuity or measurability is imposed.
The input corpus \(\mathcal A\) is a finite list of universally quantified schemas \(g\Rightarrow\varphi\). Variables range over societies in \(D\) and auxiliary rational scalars; \(g\) is a Boolean combination of rational polynomial comparisons in their mass coordinates and scalars, and \(\varphi\) is a Boolean combination of atoms \(x\in F_\infty(\mu_i)\), with \(x\in C\). Polynomials are explicitly encoded sparsely, with binary coefficients and exponents and ranking-indexed coordinates. An instance substitutes concrete societies and scalars for every variable. Thus schemas depend on normalized masses, with no electorate-size parameter.
Given \(\mu^\star\in D\), \(\varnothing\ne X^\star\subseteq C\), and a binary integer \(k\ge0\), ask whether there are \(A_N\subseteq\mathcal A\) and a finite set \(A_E\) of instances of schemas in \(A_N\), with \(|A_E|\le k\), satisfying the following conditions.
Some rule satisfies every instance of every schema in \(A_N\). Every rule satisfying \(A_E\) selects exactly \(X^\star\) at \(\mu^\star\), while for each \(B\subsetneq A_E\) some rule satisfying \(B\) selects a different outcome there.
Is this bounded rational-mass justification decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), total input bit length \(L\), and \(k\).
For finite electorates, incremental instance-graph search is sound and complete assuming a sound and complete solving subroutine ([Nardi–Boixel–Endriss](https://doi.org/10.5281/zenodo.5901351)).
Related discrete justification existence is \(\Sigma_2^{\mathrm P}\)-complete with explicitly supplied instances and \(\mathrm{NEXP}\)-hard with succinct first-order axioms; these results concern different encodings, without the present bound ([Boixel–de Haan](https://ojs.aaai.org/index.php/AAAI/article/download/16656/16463)). No result settling this rational-mass schema formulation was located.

Modeling choices made when packaging the task

  • The rule's distribution domain was unspecified; use the rational simplex throughout, consistent with the required binary-rational society representation.
  • The syntax and encoding of scale-free lifted schemas were unspecified; use universally quantified, rational-polynomial guarded Boolean constraints on winner membership, with explicit sparse polynomial encodings.
  • An instance was undefined; it grounds every society and auxiliary scalar variable with rational values.
  • Restore adequacy by requiring the normative basis to be a subset of the input corpus, and require joint satisfiability over the entire rational distribution domain.
  • Restore the nonempty target-outcome condition and allow any nonempty candidate set, as in the discrete definition.
  • Interpret k as a binary-encoded bound on the number of explanation instances, without an additional bound on their encoding lengths.
  • Normalization removes electorate size; impose no regularity on rules and retain set-valued ties.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The stated decision problem is \(\mathrm{NP}\)-hard, already when

\(m=2,\qquad \tau=1,\qquad k=1.\)

This holds even when every guard uses only linear polynomial comparisons and the entire corpus is globally consistent.

Consequently, unless \(\mathrm P=\mathrm{NP}\), there is no algorithm with running time polynomial in the total input bit length \(L\), even for these fixed parameter values. More generally, there is no running-time bound \(f(m,\tau,k)L^{O(1)}\) for any computable \(f\), unless \(\mathrm P=\mathrm{NP}\).

I prove this directly for the supplied encoding. I also give a reduction without auxiliary scalars, where hardness comes from choosing a bounded collection of instances.

1. Degenerate cases and minimality

If \(m=1\), every rule necessarily returns the sole candidate. Taking \(A_N=A_E=\varnothing\) satisfies all requirements, for every \(k\).

If \(m\geq 2\) and \(k=0\), the answer is no: the only possible \(A_E\) is empty, and an unrestricted rule can select a nonempty outcome different from \(X^\star\).

The interesting case therefore has \(m\geq 2\) and \(k\geq 1\).

Minimality lemma. Suppose \(A_N\) is globally consistent and a finite set \(E\) of its instances forces the target outcome. Then some subset \(E'\subseteq E\) forces the target and satisfies the required minimality condition.

Proof. Among the subsets of \(E\) forcing the target, choose an inclusion-minimal one, \(E'\). Every proper subset \(B\subsetneq E'\) fails to force the target. By the definition of “forces,” this means that some rule satisfies \(B\) and returns a different outcome at \(\mu^\star\).

Also, a rule satisfying all schemas in \(A_N\) satisfies \(E'\), so the forcing statement is supported by a consistent collection of instances. Finally, \(|E'|\leq |E|\). ∎

Thus minimality does not obstruct a reduction that first constructs a consistent forcing set within the bound.

2. A general guard-activation construction

Fix \(C=\{a,b\}\). Let \(r\) be the ranking \(a\succ b\), and let \(\mu^\star\) assign mass \(1\) to \(r\). Set \(X^\star=\{a\}\) and \(k=1\).

Let \(H(z_1,\ldots,z_n)\) be any Boolean combination of rational polynomial comparisons. Construct a corpus consisting of the single schema

\(\bigl(\mu_r=1\ \land\ H(z_1,\ldots,z_n)\bigr)\ \Rightarrow\ \bigl(a\in F_\infty(\mu)\ \land\ \neg(b\in F_\infty(\mu))\bigr).\)

All variables are universally quantified as required. The variables \(z_i\) are auxiliary rational scalars.

Because societies have nonnegative masses summing to \(1\), the equality \(\mu_r=1\) uniquely specifies \(\mu=\mu^\star\).

Claim. The constructed justification instance is positive if and only if \(H\) has a satisfying assignment in \(\mathbb Q^n\).

Proof.

First, the entire corpus is always globally consistent: the constant rule \(F_a(\nu)=\{a\}\) satisfies the schema for every substitution.

Suppose \(H(q_1,\ldots,q_n)\) holds for rational \(q_i\). Instantiate the schema with \(\mu=\mu^\star\) and \(z_i=q_i\), and let \(A_E\) contain this single instance. Its antecedent is true, so every rule satisfying it returns exactly \(\{a\}\) at \(\mu^\star\).

Its only proper subset is empty. The constant rule \(F_b(\nu)=\{b\}\) satisfies that subset and returns a different outcome. Hence this is a valid justification with \(A_N\) equal to the corpus.

Conversely, suppose \(H\) has no rational satisfying assignment. Every instance then has a false antecedent and imposes no restriction. In particular, \(F_b\) satisfies every possible \(A_E\). No such collection can force \(\{a\}\) at \(\mu^\star\). ∎

This construction uses normalized masses throughout and introduces no electorate-size parameter.

3. Reduction from Boolean satisfiability

Let \(\Psi\) be a Boolean satisfiability instance with variables \(p_1,\ldots,p_n\). Introduce rational scalars \(z_1,\ldots,z_n\), and define

\(H_\Psi(z)=\left(\bigwedge_{i=1}^{n}(z_i=0\ \lor\ z_i=1)\right)\land\widehat{\Psi}(z),\)

where \(\widehat{\Psi}\) replaces each occurrence of \(p_i\) by the comparison \(z_i=1\), preserving all Boolean connectives.

Claim. The formula \(\Psi\) is satisfiable if and only if \(H_\Psi\) is satisfiable over \(\mathbb Q\).

Proof. A Boolean assignment defines a rational assignment by assigning \(z_i=1\) when \(p_i\) is true and \(z_i=0\) otherwise. Under this substitution, every atom and Boolean connective has the same truth value.

Conversely, the first conjunction in \(H_\Psi\) forces every \(z_i\) to belong to \(\{0,1\}\). Interpreting \(p_i\) as true exactly when \(z_i=1\) then recovers a satisfying Boolean assignment. ∎

Apply the construction of Section 2 with \(H=H_\Psi\). Its correctness gives

\(\Psi\text{ is satisfiable}\quad\Longleftrightarrow\quad\text{the constructed instance admits a justification}.\)

Every polynomial comparison used here is linear, with constants in \(\{0,1\}\). There is one schema, two candidates, a target society of support size one, and bound one. Moreover, every constructed corpus is globally consistent.

For a source formula of bit length \(N\), variable renaming and construction take polynomial time; for example, \(O(N^2)\) bit operations suffice. The output length is \(O(N\log(N+2))\) under an explicit binary-index encoding.

Since Boolean satisfiability is \(\mathrm{NP}\)-hard, this establishes the claimed hardness for the rational-mass formulation.

4. Hardness without auxiliary scalars

The preceding reduction uses scalar assignments as Boolean witnesses. The following reduction shows hardness when guards merely specify one society.

Take a Set Cover instance with nonempty universe \(U=\{1,\ldots,u\}\), sets \(S_1,\ldots,S_s\subseteq U\), and bound \(k\).

Let

\(C=\{a,b_1,\ldots,b_u\},\qquad m=u+1.\)

Choose one ranking \(r\), let \(\mu^\star\) be its unit-mass society, and set \(X^\star=\{a\}\). For each \(j\), introduce the schema

\(\mu_r=1\ \Rightarrow\ \left(a\in F_\infty(\mu)\ \land\ \bigwedge_{i\in S_j}\neg(b_i\in F_\infty(\mu))\right).\)

There are no auxiliary scalars. Every guard consists of one linear equality. Again, the constant rule returning \(\{a\}\) satisfies the entire corpus.

Claim. A bounded justification exists if and only if the Set Cover instance has a cover using at most \(k\) sets.

Proof.

Suppose \(J\subseteq\{1,\ldots,s\}\) is a cover with \(|J|\leq k\). Instantiate its schemas at \(\mu^\star\). Their consequences require \(a\) to win and exclude every \(b_i\), because \(\bigcup_{j\in J}S_j=U\). They therefore force exactly \(\{a\}\). The minimality lemma supplies a valid minimal subset within the same bound.

Conversely, suppose a valid \(A_E\) exists. Discard instances whose antecedents are false. Every remaining instance is at \(\mu^\star\), and its exclusions correspond to one of the sets \(S_j\). Let \(J\) be the collection of their schema indices. Then \(|J|\leq |A_E|\leq k\).

If \(J\) does not cover \(U\), choose an uncovered element \(i\). Define a rule returning \(\{a,b_i\}\) at \(\mu^\star\) and \(\{a\}\) elsewhere. It satisfies every selected instance: \(a\) wins, and none of those instances excludes \(b_i\). Nevertheless, its target outcome differs from \(\{a\}\), contradicting the forcing condition. Hence \(J\) is a cover. ∎

Only one ranking coordinate is referenced. Encoding that ranking takes \(O(m\log(m+2))\) bits, and the target has \(\tau=1\). The reduction has polynomial size and running time; it never enumerates the \(m!\) ranking types.

5. Running times and the scope of the conclusion

Proven bounds

The principal lower bound fixes \(m=2\), \(\tau=1\), and \(k=1\). Therefore neither small target support nor a small justification bound yields polynomial time for the unrestricted syntax, unless \(\mathrm P=\mathrm{NP}\).

For the specific Boolean-guard fragment in Section 3, exhaustive evaluation of the \(2^n\) Boolean assignments takes \(O(2^n\operatorname{poly}(L))\) time, where \(n\leq L\).

The exclusion-schema fragment in Section 4 is \(\mathrm{NP}\)-complete. Membership follows because a certificate names at most \(\min(k,s)\) schemas, and their union can be checked in polynomial time. A dynamic program over subsets of the universe decides this fragment in

\(O\!\left(L+(s+1)2^{m-1}\bigl(m+\log(s+2)\bigr)\right)\)

bit operations. Each state records the smallest number of selected sets covering that subset. Processing one set updates a state either by omitting the set or by taking its union with the state. Comparing the resulting optimum with the binary input \(k\) adds only a cost already covered by \(L\).

Finite-instance checking

A concrete finite collection of instances admits a finite propositional test. Let \(h\) be the maximum number of society variables in a schema. For at most \(k\) instances, there are at most \(q=1+kh\) distinct societies, including the target.

After evaluating the instantiated guards and identifying equal societies, enumerate the \((2^m-1)^q\) possible nonempty outcomes at those societies. Every such assignment extends to an unrestricted rule by choosing arbitrary nonempty outcomes elsewhere. Hence enumeration checks entailment exactly.

If the concrete instances have total encoding length \(W\), the entailment stage takes

\(O\!\left((2^m-1)^{1+kh}\operatorname{poly}(W+kL+m)\right).\)

Minimality needs only the \(k\) individual deletion checks: a counterexample satisfying \(A_E\setminus\{e\}\) also satisfies every subset of that collection.

This is a finite-instance verification bound. It does not check global schema consistency or bound the bit lengths of instances that must be searched.

Why no unrestricted upper bound is asserted

The guard-activation construction also applies to

\(H(z_1,\ldots,z_n)\equiv P(z_1,\ldots,z_n)=0\)

for an arbitrary sparsely encoded integer polynomial \(P\). Thus rational zero existence reduces in polynomial time to this problem, still with \(m=2\), \(\tau=1\), \(k=1\), and a globally consistent corpus.

This is Hilbert’s tenth problem over \(\mathbb Q\), whose decidability is a recognized open problem; see [Poonen’s survey](https://math.mit.edu/~poonen/papers/h10_notices.pdf). Consequently, a general terminating decision algorithm would also decide that problem.

The requested \(\mathrm{NP}\)-hardness conclusion is fully proved. No membership in \(\mathrm{NP}\), or general decision-time upper bound, is claimed.
