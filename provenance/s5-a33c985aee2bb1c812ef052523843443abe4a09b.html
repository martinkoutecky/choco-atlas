Result

The exact cohort bid optimization problem is solvable in polynomial time in \(m,\tau,L\). Its maximizing bid vector is unique and rational. The algorithm uses only exact rational arithmetic and comparisons.

The proof below includes zero valuations and zero competing bids.

1. Characterization of the optimizer

Write \(a_j=a_{t_0j}\) and \(S=\mu_{t_0}B_{t_0}>0\). Define \(J=\{j:a_j>0\}\). Since \(\sum_j a_j=1\), the set \(J\) is nonempty.

Every feasible vector with finite objective must satisfy \(z_j=0\) for \(j\notin J\). A finite-objective feasible vector exists: assign the entire budget \(S\) to any good in \(J\). Consequently, vectors with objective \(-\infty\) cannot maximize.

For \(j\in J\), define the rational threshold \(q_j=\theta_j/a_j\), and set

\(H(c)=\sum_{j\in J}\max\{ca_j-\theta_j,0\}\), for \(c\geq0\).

This function is continuous, equals zero for \(c\leq\min_{j\in J}q_j\), and tends to infinity as \(c\) tends to infinity. Moreover, it is strictly increasing on \([\min_{j\in J}q_j,\infty)\): a coordinate attaining the minimum threshold increases strictly throughout that interval. Thus there is exactly one \(c^*>\min_{j\in J}q_j\) satisfying \(H(c^*)=S\).

Define

\(z_j^*=\max\{c^*a_j-\theta_j,0\}\) for \(j\in J\), and \(z_j^*=0\) for \(j\notin J\).

This vector is feasible. We next prove that it is the unique maximizer.

2. Proof of optimality and uniqueness

Let \(h(x)=x(1-\ln x)\) for \(x>0\), with \(h(0)=0\).

For every \(y>0\) and \(x\geq0\),

\(h(x)-h(y)\leq-\ln y\,(x-y)\),

with equality exactly when \(x=y\). Indeed, the difference between the right side and the left side is

\(x\ln(x/y)-x+y\).

For \(x>0\), this equals \(y(r\ln r-r+1)\), where \(r=x/y\). The function \(r\ln r-r+1\) has derivative \(\ln r\), so its unique minimum is zero at \(r=1\). For \(x=0\), the difference is \(y>0\).

For each \(j\in J\), let \(p_j^*=\theta_j+z_j^*=\max\{\theta_j,c^*a_j\}>0\), and define \(d_j=\ln a_j-\ln p_j^*\).

If \(z_j^*>0\), then \(p_j^*=c^*a_j\), giving \(d_j=-\ln c^*\).

If \(z_j^*=0\), then \(\theta_j\geq c^*a_j>0\), giving \(d_j\leq-\ln c^*\).

Now take any finite-objective feasible vector \(z\). Coordinates outside \(J\) contribute the same constant to both objectives. Applying the inequality above to each coordinate in \(J\) yields

\(F(z)-F(z^*)\leq\sum_{j\in J}d_j(z_j-z_j^*)\).

Let \(I=\{j\in J:z_j^*=0\}\). Since both vectors spend exactly \(S\),

\(\sum_{j\in J}d_j(z_j-z_j^*)=-\ln c^*\sum_{j\in J}(z_j-z_j^*)+\sum_{j\in I}(d_j+\ln c^*)z_j=\sum_{j\in I}(d_j+\ln c^*)z_j\leq0\).

Therefore \(F(z)\leq F(z^*)\).

If \(z\neq z^*\), some coordinate in \(J\) differs. The corresponding inequality for \(h\) is strict, so \(F(z)<F(z^*)\). Hence \(z^*\) is the unique maximizer.

3. Exact algorithm

Let \(n=|J|\). Sort the positive-valuation goods as \(j_1,\ldots,j_n\) so that

\(q_{j_1}\leq q_{j_2}\leq\cdots\leq q_{j_n}\).

Ties may be ordered arbitrarily. Define prefix sums and candidates

\(A_k=\sum_{\ell=1}^k a_{j_\ell}\), \(\quad T_k=\sum_{\ell=1}^k\theta_{j_\ell}\), \(\quad c_k=(S+T_k)/A_k\).

Scan \(k=1,\ldots,n\). Stop at the first \(k\) for which either \(k=n\) or \(c_k\leq q_{j_{k+1}}\). Return \(c^*=c_k\), then compute the bid vector using the formula in Section 1.

To verify the scan, first observe that

\(c_1=q_{j_1}+S/a_{j_1}>q_{j_1}\).

If the scan continues after \(k\), then \(c_k>q_{j_{k+1}}\), and

\(c_{k+1}=\dfrac{A_kc_k+a_{j_{k+1}}q_{j_{k+1}}}{A_k+a_{j_{k+1}}}>q_{j_{k+1}}\).

Thus every tested candidate satisfies \(c_k>q_{j_k}\).

At the stopping index, the first \(k\) thresholds are strictly below \(c_k\), while all remaining thresholds are at least \(c_k\). Consequently,

\(H(c_k)=\sum_{\ell=1}^k(c_ka_{j_\ell}-\theta_{j_\ell})=c_kA_k-T_k=S\).

By uniqueness of the solution to \(H(c)=S\), the returned value is exactly \(c^*\). Equality at the stopping threshold correctly assigns zero bids to the remaining tied goods.

4. Polynomial bit complexity and the support representation

Computing \(S\) and all \(\theta_j=\sum_{t\ne t_0}\mu_t\beta_{tj}\) takes \(O(m\tau)\) rational arithmetic operations. Sorting takes \(O(m\log(m+1))\) exact rational comparisons; the prefix scan and output construction take \(O(m)\) further operations.

These are polynomial-time operations in the binary model as well. A sum of \(r\) rationals whose numerators and denominators have at most \(b\) bits has a representation with \(O(rb+\log(r+1))\) bits: use the product of their denominators as a common denominator. Multiplication or division adds the operand bit lengths, up to a constant. Applying these bounds successively to the aggregation, thresholds, prefix sums, candidate \(c_k\), and output coordinates shows that all intermediate and output bit lengths are polynomial in \(m,\tau,L\). Exact comparisons use integer cross multiplication, and fractions can be reduced using the Euclidean algorithm.

No logarithms need to be evaluated.

The cohort enters the optimization through its aggregate budget \(S\); the other types enter through the \(m\) totals \(\theta_j\). Thus no expansion into individual buyers is required. This also explains the connection to the finite-buyer best-response result in Proposition 1 of [Kolumbus, Levy and Nisan](https://arxiv.org/html/2307.04108v2): the given cohort objective has the same mathematical form. The direct proof above establishes exact polynomial-time computation for the stated support encoding.
