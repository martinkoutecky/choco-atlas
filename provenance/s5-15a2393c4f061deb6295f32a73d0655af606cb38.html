The continuous mirror question, as graded

Given a finite set of types \(T\), rational masses \(\mu_t>0\) summing to \(1\), a budget \(1\le k\le |T|\), and an affinity table \(a_{tu}\in[0,1]\) promised to arise as expected normalized Kendall–Tau similarities under a joint distribution over rankings, choose exactly \(k\) representative types \(S\subseteq T\) maximizing \(\Psi_\mu(S)=\sum_{t\in T}\mu_t\max_{s\in S}a_{ts}\). In the decision version, determine whether some \(S\) has \(\Psi_\mu(S)\ge B\), for a given rational threshold \(B\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible rankings.
The input also contains the number \(m\ge2\) of alternatives, a binary rational affinity table \(a\in[0,1]^{T\times T}\), an integer budget \(1\le k\le\tau\), and a binary rational threshold \(B\). Let \(L\) be the total input bit length.
The table is promised to satisfy \(a_{tu}=\mathbb E[1-\operatorname{KT}(R_t,R_u)/\binom{m}{2}]\) for some joint distribution of strict complete rankings \((R_t)_{t\in T}\) of the same alternatives. The joint distribution is not supplied; arbitrary dependence is allowed. In particular, \(a_{tt}=1\) and \(a_{tu}=a_{ut}\).
Representatives are exactly \(k\) distinct types \(S\subseteq T\), with value \(\Psi_\mu(S)=\sum_{t\in T}\mu_t\max_{s\in S}a_{ts}\). The maximum is taken after the expectations defining the affinities; ties have no effect on its value.

Is deciding whether some \(S\subseteq T\) with \(|S|=k\) satisfies \(\Psi_\mu(S)\ge B\) solvable in polynomial time, or is it NP-hard, on the promised inputs? State running times in \(m,\tau,L\), and \(k\).

For finite equally weighted agents, selecting \(k\) representatives to meet a threshold for the sum of maximum affinities is NP-hard for unrestricted symmetric affinity tables with unit diagonal. The published reduction does not establish the joint-ranking realizability promise. [Dhamal, Vallam, and Narahari](https://arxiv.org/pdf/1708.05690)
No exact complexity classification for the rational-mass problem with this realizability promise was located in the literature search.

Modeling choices made when packaging the task

  • Made the number of alternatives m an input parameter and required m at least two so normalized Kendall–Tau similarity is defined.
  • Required exact binary rational affinity entries and defined L as the total input bit length.
  • Specified strict complete rankings of a common alternative set, following the discrete preference domain.
  • Interpreted the realizability condition as an existential promise about one joint distribution, without supplying that distribution or imposing independence.
  • Retained integral selection of exactly k distinct support types and clarified that maximization occurs after computing expected affinities.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is \(\mathrm{NP}\)-hard on the promised inputs, already for \(m=2\), equal positive masses, and dyadic rational data. It has a polynomial-time certificate verifier on promised inputs. Thus the realizability promise does not yield a polynomial-time algorithm unless \(\mathrm{P}=\mathrm{NP}\).

The proof constructs one joint distribution realizing the entire affinity table simultaneously.

1. The graph problem underlying the reduction. A dominating set of a simple undirected graph \(G=(V,E)\) is a set \(D\subseteq V\) such that every vertex outside \(D\) has a neighbor in \(D\).

We first justify the hardness of deciding whether a graph has a dominating set of exactly \(k\) vertices, with \(1\le k\le |V|\). We use the standard \(\mathrm{NP}\)-completeness of satisfiability for conjunctive normal form formulas with at most three literals per clause, established in [Karp’s *Reducibility Among Combinatorial Problems*](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Given such a formula with \(r\ge1\) variables, construct a graph as follows:

  • For each variable \(x_i\), create a triangle with vertices labeled \(x_i,\neg x_i,z_i\).
  • For each clause, create a clause vertex and connect it to precisely the literal vertices occurring in that clause.
  • Set the budget to \(r\).

A satisfying assignment gives a dominating set of size \(r\): select the true literal vertex from each variable triangle. These vertices dominate every triangle and, because every clause contains a true literal, every clause vertex.

Conversely, suppose there is a dominating set of size at most \(r\). The closed neighborhood of \(z_i\) consists precisely of its variable triangle. Therefore the set must contain at least one vertex from each of the \(r\) disjoint triangles. It consequently contains exactly one vertex per triangle and no clause vertices. Each clause vertex must have a selected literal neighbor. Assign every selected literal to be true; variables whose selected vertex is \(z_i\) can be assigned arbitrarily. There is no conflicting assignment because only one vertex is selected from each triangle. Every clause is satisfied.

This proves the required graph hardness. The distinction between “at most \(k\)” and “exactly \(k\)” causes no difficulty: a dominating set of size less than \(k\) can be enlarged to size \(k\) whenever \(k\le |V|\).

We may additionally require the number of vertices to be a power of two. Indeed, if the original graph has \(n_0\) vertices, let \(n\) be the least power of two with \(n\ge n_0\), add \(h=n-n_0\) isolated vertices, and increase the budget from \(k_0\) to \(k=k_0+h\). Every dominating set must include all added vertices. Thus exact-budget feasibility is preserved. Since \(n<2n_0\), this padding is polynomial.

2. Construction of the society. Let \(G=(V,E)\) be the resulting graph, with \(n=|V|\) a power of two and budget \(1\le k\le n\).

Use the types \(T=V\), so that \(\tau=n\), and give each type mass

\(\displaystyle \mu_t=\frac1n.\)

Set \(m=2\). Define the affinity table by

\(\displaystyle a_{tt}=1,\qquad a_{tu}=\frac12+\frac{\mathbf 1_{\{\{t,u\}\in E\}}}{2n^2}\quad(t\ne u).\)

The threshold is

\(\displaystyle B=\frac{k}{n}+\frac{n-k}{2n}+\frac{n-k}{2n^3}.\)

All masses are positive and sum to one. Every affinity lies in \([0,1]\), and the table is symmetric with unit diagonal. Because \(n\) is a power of two, the masses, affinities, and threshold are all dyadic rationals.

3. Proof of joint-ranking realizability. On the two alternatives, let \(R^0\) and \(R^1\) denote the two opposite strict rankings. Their Kendall distance is zero when the rankings agree and one when they differ. Since \(\binom{2}{2}=1\), their normalized affinity is exactly the indicator that they agree.

We construct jointly distributed bits \((X_t)_{t\in V}\), and then set \(R_t=R^{X_t}\).

First choose a random mode \(J\) with probabilities

\(\displaystyle \Pr(J=e)=\frac1{n^2}\quad(e\in E),\qquad \Pr(J=0)=1-\frac{|E|}{n^2}.\)

These probabilities are nonnegative and sum to one: a simple graph has \(|E|\le n(n-1)/2<n^2\).

Conditional on the mode, generate the bits as follows:

  • If \(J=0\), all bits are independent fair bits.
  • If \(J=\{v,w\}\), set \(X_v=X_w\) to one shared fair bit. Generate all remaining bits independently and fairly, independently also of that shared bit.

Fix distinct vertices \(t,u\). In every mode other than \(J=\{t,u\}\), their bits are independent fair bits, so they agree with probability \(1/2\). To see the independence explicitly, either both bits are independently generated, or one is the shared endpoint bit and the other is an independent outside bit. In the mode \(J=\{t,u\}\), they agree with probability one.

Consequently,

\(\displaystyle \Pr(X_t=X_u)=\frac12+\frac{\mathbf 1_{\{\{t,u\}\in E\}}}{2n^2}=a_{tu}.\)

For \(t=u\), agreement always holds, yielding \(a_{tt}=1\). Therefore this single joint distribution realizes every entry of the constructed table, exactly as required by the promise.

The distribution is used to prove the promise; it need not be included in the output instance.

4. Exact threshold equivalence. Fix any set \(S\subseteq V\) of exactly \(k\) representatives. Define

\(\displaystyle d(S)=\bigl|\{t\in V\setminus S:\text{ some }s\in S\text{ satisfies }\{t,s\}\in E\}\bigr|.\)

For a selected type, the maximum affinity is one because its diagonal entry is available. For an unselected type with a selected neighbor, the maximum is \(1/2+1/(2n^2)\). For every other unselected type, the maximum is \(1/2\). The last statement uses \(k\ge1\), so the maximum is over a nonempty set.

It follows that

\(\displaystyle \Psi_\mu(S) =\frac{k}{n} +\frac{d(S)}{n}\left(\frac12+\frac1{2n^2}\right) +\frac{n-k-d(S)}{2n} =\frac{k}{n}+\frac{n-k}{2n}+\frac{d(S)}{2n^3}. \)

Thus

\(\displaystyle B-\Psi_\mu(S)=\frac{n-k-d(S)}{2n^3}.\)

Since \(0\le d(S)\le n-k\), the threshold is met exactly when \(d(S)=n-k\). This condition says precisely that every unselected vertex has a selected neighbor, or equivalently that \(S\) is a dominating set.

Hence the graph instance is a yes-instance if and only if the constructed promised society is a yes-instance. A set that fails to dominate misses the threshold by at least \(1/(2n^3)\); all comparisons are exact rational comparisons.

5. Encoding size and running times. The reduction outputs \(\tau=n\) types and a table containing \(n^2\) entries, each with \(O(\log n)\) bits. The masses and threshold also have \(O(\log n)\)-bit representations. Therefore its output length is \(L=O(n^2\log n)\), and the table can be constructed in \(O(n^2\log n)\) bit operations from an adjacency representation. The reduction fixes \(m=2\).

In fact, the same affinity table is realizable for every fixed \(m\ge2\): replace \(R^0,R^1\) by a ranking of the \(m\) alternatives and its complete reverse. Their Kendall distance is either zero or \(\binom m2\), so the preceding affinity calculation remains valid.

For general input data, a certificate lists \(k\) distinct type indices, using \(O(k\log\tau)\) bits. To verify it, compute each row maximum over the selected columns, multiply by the corresponding mass, sum, and compare with \(B\).

There are \(O(\tau k)\) rational comparisons and \(O(\tau)\) rational arithmetic operations. Exact summation can use unreduced fractions: each row contributes one mass and one table entry, so the total lengths of the denominator factors used are \(O(L)\). The intermediate integers therefore have \(O(L)\) bits. With schoolbook integer arithmetic, a conservative verification bound is

\(\displaystyle O\!\left(L+\tau kL^2\right).\)

Enumerating every possible representative set consequently gives an exact algorithm with running time

\(\displaystyle O\!\left(L+\binom{\tau}{k}\tau kL^2\right).\)

For fixed \(k\), this is \(O(L+k\tau^{k+1}L^2)\). In particular, \(k=1\) is polynomial-time solvable. When \(k=\tau\), the only representative set has value one, so deciding feasibility takes \(O(L)\) time.

These algorithms use the supplied affinity table directly. Their dependence on \(m\) is only through its encoding within \(L\). The polynomial verifier assumes the realizability promise and does not test it.

1. Source problem and graph reduction

The cited starting theorem is appropriate: satisfiability of Boolean conjunctive normal form formulas with at most three literals per clause is NP-complete. This is among the problems in [Karp’s cited paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Both directions of the graph reduction are valid:

  • A satisfying assignment selects exactly one literal vertex per variable triangle. These vertices dominate all triangles and every clause vertex.
  • Any dominating set of size at most \(r\) must meet every variable triangle, because the closed neighborhood of \(z_i\) is precisely that triangle. Consequently, it selects exactly one vertex per triangle and no clause vertices.
  • Every clause vertex therefore has a selected literal neighbor. The selected literals give consistent assignments, since no triangle contributes both literals. Arbitrary assignments for variables whose selected vertex is \(z_i\) do not invalidate any selected literal.

The restriction \(r\ge1\) does not affect the hardness claim; it excludes only trivial variable-free cases. Empty clauses, repeated literals, and clauses containing opposite literals do not break the stated equivalence.

The conversion from “at most” to “exactly” is correct: adding vertices to a dominating set preserves domination, and the condition \(k\le |V|\) ensures sufficient vertices are available.

The power-of-two padding is also correct. Every added isolated vertex must be selected. Removing those \(h\) vertices from a dominating set of size \(k_0+h\) leaves a dominating set of size \(k_0\) in the original graph, and the converse holds. The bound \(n<2n_0\) ensures polynomial growth, and the padded budget remains between \(1\) and \(n\).
