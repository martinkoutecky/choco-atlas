The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), fixed rational \(p>1\), a rational distribution \(\mu\) over complete rankings \(\pi\) of \(C\), and threshold \(\theta\), decide whether there is a committee \(S\subseteq C\) with \(\lvert S\rvert=k\) and \(F_{\mu,p}(S)=\sum_{\pi}\mu_\pi\left(\sum_{j=1}^{k}b_j(\pi,S)^p\right)^{1/p}\ge\theta\), where \(b_j(\pi,S)\) are the sorted Borda scores of committee members.

Packaged proof task (what the prover saw — nothing else)

Fix a rational \(p>1\). Input consists of a candidate set \(C\) with \(m\ge1\), an integer \(1\le k\le m\), a society \(\mu\), and a binary-rational threshold \(\theta\in\mathbb{Q}\).
A society is given by its support: the list of the \(\tau\) distinct types with positive mass, each with its mass as a binary rational. Types are strict complete rankings of \(C\); masses satisfy \(\sum_{\pi}\mu_{\pi}=1\). Here \(\tau\) is the support size, not the number \(m!\) of possible rankings.
For a committee \(S\subseteq C\) of size \(k\), let \(b_1(\pi,S)>\cdots>b_k(\pi,S)\) be its members' Borda scores in ranking \(\pi\), using scores from \(m-1\) down to \(0\). Define \(F_{\mu,p}(S)=\sum_{\pi\in\operatorname{supp}(\mu)}\mu_{\pi}\bigl(\sum_{j=1}^{k}b_j(\pi,S)^p\bigr)^{1/p}\).
The decision problem asks whether some such committee satisfies \(F_{\mu,p}(S)\ge\theta\), with exact comparison and equality accepted. Let \(L\) be the total binary input length; state running times in \(m,\tau,k,L\), with \(p\) fixed.

For each fixed rational \(p>1\), is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

Conclusion

For every fixed rational \(p>1\), the support-distribution decision problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions. Hence a running time polynomial in \(m,\tau,k,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

Here, a binary rational means a rational whose numerator and denominator are encoded in binary, as in the question.

Hardness premise

Use the finite-list score-threshold hardness supplied in the task, corresponding to [Faliszewski et al., Theorem 2](https://www.ijcai.org/proceedings/2017/0028.pdf).

For fixed \(p\), a source instance consists of candidates \(C\), committee size \(k\), an explicit nonempty voter list \(V=(\pi_1,\ldots,\pi_n)\), and a binary-rational threshold \(T\). Its question is whether some size-\(k\) committee \(S\) satisfies

\(\displaystyle G_{V,p}(S):=\sum_{i=1}^{n}\left(\sum_{j=1}^{k}b_j(\pi_i,S)^p\right)^{1/p}\ge T.\)

The paper’s formulation using a winning committee is equivalent: the finite, nonempty collection of size-\(k\) committees has a maximum score, and that maximum reaches \(T\) exactly when some committee does.

Reduction and correctness

Keep \(C\) and \(k\) unchanged. For each distinct ranking \(\pi\) occurring in \(V\), let \(n_\pi\) denote its multiplicity. Output precisely these rankings as the society’s support, with

\(\displaystyle \mu_\pi=\frac{n_\pi}{n},\qquad \theta=\frac{T}{n}.\)

Every listed mass is positive. Moreover,

\(\displaystyle \sum_{\pi\in\operatorname{supp}(\mu)}\mu_\pi=\frac{1}{n}\sum_{\pi\in\operatorname{supp}(\mu)}n_\pi=1.\)

Thus the output is a valid instance, with support size \(\tau\le n\).

For every size-\(k\) committee \(S\), grouping voters with identical rankings gives the exact identity

\(\displaystyle F_{\mu,p}(S)=\sum_{\pi\in\operatorname{supp}(\mu)}\frac{n_\pi}{n}\left(\sum_{j=1}^{k}b_j(\pi,S)^p\right)^{1/p}=\frac{G_{V,p}(S)}{n}.\)

Since \(n>0\),

\(\displaystyle F_{\mu,p}(S)\ge\theta\quad\Longleftrightarrow\quad G_{V,p}(S)\ge T.\)

This equivalence holds for every committee, so it also holds after existentially quantifying over committees. Equality is preserved exactly. The transformation is therefore a many-one reduction.

Encoding size, running time, and exact arithmetic

Let \(L_{\mathrm{list}}\) be the source instance’s binary length, and let \(B\) be the threshold’s encoding length. Relabel candidates by integers from \(1\) to \(m\). Each support ranking then uses \(O(m\log(m+1))\) bits.

Each mass \(n_\pi/n\) uses \(O(\log(n+1))\) bits. Writing \(T=a/d\), with \(d>0\), the new threshold is \(a/(dn)\), whose encoding uses \(O(B+\log(n+1))\) bits. Consequently, the target length satisfies

\(\displaystyle L=O\!\left(\tau m\log(m+1)+\tau\log(n+1)+B+\log(n+1)\right).\)

Because the source lists its voters explicitly, \(m,n,k\) are bounded polynomially in \(L_{\mathrm{list}}\). Grouping rankings, counting multiplicities, and constructing the rational numbers can all be performed in polynomial time; a conservative bound is \(O(L_{\mathrm{list}}^3)\) bit operations.

Thus an algorithm taking time \((m+\tau+k+L)^{O(1)}\), for fixed \(p\), would solve the source problem in polynomial time. Its stated \(\mathrm{NP}\)-hardness proves the conclusion.

The reduction never evaluates a radical or compares committee scores. It transfers exact comparisons through an algebraic identity. Accordingly, this proof establishes \(\mathrm{NP}\)-hardness without asserting membership in \(\mathrm{NP}\).
