Packaged proof task (what the prover saw — nothing else)

Let \(X\) be finite attributes with finite domains, \(n=|X|\), and \(\mathcal X=\prod_{N\in X}N\). An acyclic CP-net \(\phi\) is a DAG on \(X\) with, for every \(N\) and parent assignment \(v\), a strict total order on \(N\); write \(\operatorname{Pref}_{\phi}(N,v)\) for its top value. For a partial assignment \(u\), \(\operatorname{opt}_{\phi}(u)\) is obtained by the Forward Sweep in a topological order, retaining values fixed by \(u\).
For \(o\in\mathcal X\), \(\operatorname{code}(o,\phi)\) is the unique smallest partial assignment \(u\subseteq o\) such that \(\operatorname{opt}_{\phi}(u)=o\). Equivalently, \(\lvert\operatorname{code}(o,\phi) vert=\lvert\{N\in X:o_N e\operatorname{Pref}_{\phi}(N,o_{\operatorname{Pa}_{\phi}(N)})\} vert\).
Input: an explicitly given rational distribution \(\mu=(\mu_o)_{o\in S}\) with finite \(S\subseteq\mathcal X\), \(\sum_{o\in S}\mu_o=1\), and rational \(q\). Set \(\operatorname{NMCL}_{\mu}(\phi)= rac{1}{n}\sum_{o\in S}\mu_o\lvert\operatorname{code}(o,\phi) vert\).

Target. Is deciding whether an acyclic CP-net \(\phi\) satisfies \(\operatorname{NMCL}_{\mu}(\phi)\le q\) solvable in polynomial time, or is it NP-hard?

For a finite multiset \(D\) of outcomes, minimizing the empirical normalized mean code length over acyclic CP-nets is NP-complete. No verified result was found for the explicitly given rational-distribution formulation above.

Interpretation

Since the stated input consists only of the rational distribution \(\mu\) and threshold \(q\), the natural decision problem is:

Does there exist an acyclic CP-net \(\phi\) such that \(\operatorname{NMCL}_{\mu}(\phi)\le q\)?

Under this interpretation, the problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard.

If instead \(\phi\) is supplied as part of the input, checking the inequality is polynomial-time solvable. These are distinct problems.

NP-hardness

We reduce from the given NP-complete empirical threshold problem.

Let \(D=(o^{(1)},\ldots,o^{(m)})\) be an explicitly listed nonempty multiset of outcomes. Its empirical normalized mean code length is

\(\operatorname{NMCL}_{D}(\phi)=\frac{1}{nm}\sum_{i=1}^{m}\lvert\operatorname{code}(o^{(i)},\phi)\rvert\).

For every distinct outcome \(o\) occurring in \(D\), let \(c_o\) be its multiplicity. Define

\(S=\{o:c_o>0\}\)

and

\(\mu_o=\frac{c_o}{m}\)

for every \(o\in S\). Then every \(\mu_o\) is nonnegative and

\(\sum_{o\in S}\mu_o=\frac{1}{m}\sum_{o\in S}c_o=1\),

so \(\mu\) is a valid explicitly represented rational distribution.

For every acyclic CP-net \(\phi\),

\(\operatorname{NMCL}_{\mu}(\phi)=\frac{1}{n}\sum_{o\in S}\frac{c_o}{m}\lvert\operatorname{code}(o,\phi)\rvert=\frac{1}{nm}\sum_{i=1}^{m}\lvert\operatorname{code}(o^{(i)},\phi)\rvert=\operatorname{NMCL}_{D}(\phi)\).

Thus the objectives agree for every \(\phi\). Consequently,

\(\exists\phi\colon\operatorname{NMCL}_{D}(\phi)\le q\)

holds if and only if

\(\exists\phi\colon\operatorname{NMCL}_{\mu}(\phi)\le q\).

The transformation is polynomial-time. Multiplicities can be computed from the explicitly listed outcomes, \(\lvert S\rvert\le m\), and each rational number \(c_o/m\) has binary encoding length \(O(\log m)\). Therefore this is a polynomial many-one reduction from the empirical problem, proving \(\mathrm{NP}\)-hardness.

The fact that arbitrary rational distributions may encode exponentially large effective populations is irrelevant: the reduction uses only denominators bounded by the explicitly listed sample size \(m\).

Membership in NP

Assume the attributes, their finite nonempty domains, the outcomes in \(S\), and all rational numbers are explicitly encoded.

A polynomial-size certificate consists of:

  • A directed graph \(G\) on \(X\).
  • For every \(N\in X\) and \(o\in S\), a proposed top value \(t_{N,o}\in N\).

The verifier first checks that \(G\) is acyclic. It then checks, for every \(N\in X\) and every \(o,o'\in S\), that

\(o_{\operatorname{Pa}_G(N)}=o'_{\operatorname{Pa}_G(N)}\)

implies

\(t_{N,o}=t_{N,o'}\).

Hence \(t_{N,o}\) depends only on the observed parent assignment \(o_{\operatorname{Pa}_G(N)}\).

This certificate determines the top value for every parent assignment appearing in the support. For an unobserved parent assignment, choose an arbitrary value of \(N\) as its top value. Because \(N\) is finite and nonempty, each chosen top value can be extended to a strict total order on \(N\). Thus every accepting certificate extends to a genuine acyclic CP-net.

Conversely, every acyclic CP-net supplies such a certificate by setting

\(t_{N,o}=\operatorname{Pref}_{\phi}(N,o_{\operatorname{Pa}_\phi(N)})\).

Using the equivalence in the question, the verifier computes

\(k_o=\lvert\{N\in X:o_N\ne t_{N,o}\}\rvert\)

and accepts precisely when

\(\sum_{o\in S}\mu_ok_o\le nq\).

This comparison uses exact rational arithmetic. During repeated addition and multiplication, numerator and denominator bit lengths are bounded by the sum of the input bit lengths, so the computation is polynomial-time.

Therefore the existential rational-distribution problem belongs to \(\mathrm{NP}\). Together with the reduction, it is \(\mathrm{NP}\)-complete.

Supplied-CP-net variant

If a complete acyclic CP-net \(\phi\) is itself supplied, there is no optimization or existential quantifier. For every \(o\in S\) and \(N\in X\), one looks up

\(\operatorname{Pref}_{\phi}(N,o_{\operatorname{Pa}_\phi(N)})\),

counts the disagreements with \(o_N\), forms the rational weighted sum, and compares it with \(nq\). This takes polynomial time in the explicit input size.

Verification report

Overall assessment

The prover correctly distinguishes the two possible interpretations of the target:

  • If the question asks whether there exists an acyclic CP-net satisfying the threshold, the problem is NP-complete.
  • If a complete acyclic CP-net is supplied as input, evaluating the threshold is polynomial-time solvable.

Under the natural existential interpretation suggested by the optimization context, the NP-hardness reduction and NP-membership argument are substantively correct.

Step-by-step audit

1. Interpretation of the decision problem

The stated input contains only \(\mu\) and \(q\), not \(\phi\). Therefore interpreting the decision problem as

\[ \exists\phi\colon \operatorname{NMCL}_{\mu}(\phi)\le q \]

is reasonable. The prover also handles the alternative supplied-\(\phi\) interpretation, so the ambiguity does not invalidate the answer.

2. Construction of the rational distribution

Given the explicitly listed nonempty multiset \(D\) of size \(m\), the prover assigns weight

\[ \mu_o=\frac{c_o}{m} \]

to every distinct observed outcome \(o\), where \(c_o\) is its multiplicity.

This is valid:

  • Every weight is nonnegative.
  • The weights sum to one.
  • There are at most \(m\) support outcomes.
  • Each numerator and denominator has polynomial binary length.

Computing multiplicities and producing these rational weights is polynomial-time for an explicitly listed multiset.

3. Equality of the objectives

The displayed identity

\[ \operatorname{NMCL}_{\mu}(\phi) =\frac{1}{nm}\sum_{i=1}^{m} \lvert\operatorname{code}(o^{(i)},\phi)\rvert =\operatorname{NMCL}_{D}(\phi) \]

is correct for every acyclic CP-net \(\phi\). Repeated outcomes contribute exactly according to their multiplicities. Consequently, the threshold instances are equivalent with the same \(q\).

This establishes a valid polynomial many-one reduction from the explicitly represented empirical threshold problem.

4. NP-hardness conclusion

Assuming, as supplied in the task, that the empirical threshold problem for an explicitly listed multiset is NP-complete, the reduction proves NP-hardness of the rational-distribution formulation. The use of denominators bounded by \(m\) correctly avoids any concern about exponentially large populations represented by arbitrary rational weights.

5. Size of the NP certificate

The proposed certificate contains:

  • A directed graph on \(n\) attributes, requiring polynomial size.
  • One proposed top value \(t_{N,o}\) for each \(N\in X\) and \(o\in S\), also polynomial in the explicit input size.

Encoding only top values is sufficient because the supplied code-length characterization depends only on the top-ranked value in each relevant conditional order.

6. Consistency over parent contexts

The verifier checks that outcomes with the same assignment to \(\operatorname{Pa}_G(N)\) receive the same proposed top value. This is exactly the consistency condition needed for \(t_{N,o}\) to define a function of the observed parent context.

The pairwise check is polynomial-time, even though it may take quadratic time in \(\lvert S\rvert\).

7. Extension to a complete CP-net

For every unobserved parent assignment, the prover chooses an arbitrary top value and extends it to a strict total order. For a finite nonempty domain, any selected top value can indeed be extended to a strict total order. Conditional orders for different parent assignments are independent, so no further compatibility condition is needed.

Thus every accepting certificate corresponds to at least one genuine acyclic CP-net, even though its full conditional preference tables might be exponentially large.

Conversely, every acyclic CP-net induces such a certificate. The certificate characterization is therefore both sound and complete.

8. Threshold verification

Using the equivalence supplied in the problem, the verifier correctly computes

\[ k_o=\left\lvert\{N\in X:o_N\ne t_{N,o}\}\right\rvert \]

and tests

\[ \sum_{o\in S}\mu_ok_o\le nq. \]

This is equivalent to \(\operatorname{NMCL}_{\mu}(\phi)\le q\) when \(n>0\). Exact rational arithmetic has polynomial bit complexity here: multiplication by the integers \(k_o\), addition of explicitly represented rationals, and comparison with \(nq\) produce bit lengths polynomial in the total input length.

9. Supplied-\(\phi\) variant

If a complete acyclic CP-net is supplied explicitly, looking up each relevant top value, counting disagreements, and evaluating the weighted rational sum is polynomial in the combined explicit input size. This secondary conclusion is correct.

Issues

Minor: missing nonempty-attribute assumption

The argument, like the task’s definition of normalized mean code length, requires \(n>0\). If \(X=\varnothing\), the factor \(1/n\) is undefined. The prover should explicitly state that the complexity classification concerns instances with at least one attribute, or note that this is implicit in the problem’s definition.

This is a well-posedness clarification rather than a defect in the reduction.

Verdict

The main classification is correct: the existential rational-distribution problem is NP-complete, hence NP-hard. No major logical or computational gap was found.
