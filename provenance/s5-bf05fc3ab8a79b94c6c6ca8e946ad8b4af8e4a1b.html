The continuous mirror question, as graded

Given a finite propositional vocabulary, a consistent integrity constraint \(\Delta\), a support \(\mathcal K\) of consistent belief bases, and positive binary-rational masses \(\mu_0(K)\) summing to \(1\), define \(M_r=\arg\min_{\omega\models\Delta}\sum_{K\in\mathcal K}\mu_r(K)d_H(\omega,K)\), where \(d_H(\omega,K)=\min_{\nu\models K}d_H(\omega,\nu)\). For each type \(K\), define its sceptical update \(R_r(K)=\{\nu\models K:d_H(\nu,M_r)=\min_{\nu'\models K}d_H(\nu',M_r)\}\), where \(d_H(\nu,M_r)=\min_{\omega\in M_r}d_H(\nu,\omega)\), and set \(\mu_{r+1}(K')=\sum_{K:R_r(K)\equiv K'}\mu_r(K)\). Compute the first stationary round, the resulting distribution, and its merged model set; determine the formula-input complexity and a bound in the vocabulary size, support size \(\tau\), and mass bit length \(L\).

Let \(\Omega=\{0,1\}^m\). The input consists of a consistent propositional formula \(\Delta\) and a nonempty society given by its support: \(\tau\) consistent propositional belief bases, identified up to logical equivalence, with positive binary-rational masses summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total binary input length, including formulas and masses. Individual bases need not entail \(\Delta\).
For a nonempty model set \(S\), put \(d_H(\omega,S)=\min_{\nu\in S}d_H(\omega,\nu)\), using Hamming distance, and abbreviate \(d_H(\omega,K)=d_H(\omega,\operatorname{Mod}(K))\).
At round \(r\), let \(\mathcal K_r\) be the current support and define \(M_r=\arg\min_{\omega\models\Delta}\sum_{K\in\mathcal K_r}\mu_r(K)d_H(\omega,K)\).
Update every current type simultaneously to the base whose model set is \(R_r(K)=\arg\min_{\nu\models K}d_H(\nu,M_r)\); retain all minimizers. Coalesce logically equivalent updated bases, setting \(\mu_{r+1}(K')=\sum_{K\in\mathcal K_r:\,R_r(K)=\operatorname{Mod}(K')}\mu_r(K)\).
Stationarity means equality of distributions over logical-equivalence classes. Let \(k=\min\{r\geq0:\mu_{r+1}=\mu_r\}\). The exact computational problem returns \(k\), the support and masses of \(\mu_k\), and \(M_k\), representing output bases and \(M_k\) by propositional formulas up to logical equivalence.

Result

The exact stationary-outcome problem is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. Thus a polynomial-time algorithm in the formula-input length would imply \(\mathrm P=\mathrm{NP}\).

The following worst-case upper bounds hold:

\[ k\leq \sum_{i=1}^{\tau}\bigl(|\operatorname{Mod}(K_i)|-1\bigr) \leq \tau(2^m-1). \]

An exact algorithm runs in time

\[ O\!\left((k+1)\tau 2^m\operatorname{poly}(m,L)\right) \subseteq O\!\left(\tau^2 4^m\operatorname{poly}(m,L)\right), \]

using \(O\!\left(\tau 2^m\operatorname{poly}(m,L)\right)\) space. These are upper bounds; their tightness is not asserted.

Hardness already holds when \(\tau=1\) and \(k\in\{0,1\}\). Moreover, computing the stationary distribution remains hard on a family where every instance has \(k=1\).

1. Termination with rational masses and coalescing

Write the initial support as \(K_1,\ldots,K_\tau\), with positive masses \(w_1,\ldots,w_\tau\). Keep these initial types as persistent labels, even when some updated model sets coincide. Define

\[ S_{i,0}=\operatorname{Mod}(K_i),\qquad S_{i,r+1}=\arg\min_{\nu\in S_{i,r}}d_H(\nu,M_r). \]

Every set here is nonempty: the initial bases and \(\Delta\) are consistent, and all minimizations take place over nonempty finite sets. Also,

\[ S_{i,r+1}\subseteq S_{i,r}. \]

The labelled representation exactly reproduces the specified process. Indeed, grouping labels with identical sets gives their summed masses, and

\[ \sum_{i=1}^{\tau}w_i d_H(\omega,S_{i,r}) = \sum_{K\in\mathcal K_r}\mu_r(K)d_H(\omega,K). \]

Identical sets receive identical updates. Induction on \(r\) therefore establishes equivalence between the labelled and coalesced processes.

We must check that coalescing cannot conceal a strict change. For a distribution \(\mu\), define

\[ C(\mu)=\sum_{K\in\operatorname{supp}(\mu)} \mu(K)|\operatorname{Mod}(K)|. \]

In the labelled representation,

\[ C(\mu_r)=\sum_i w_i|S_{i,r}|. \]

If any label shrinks strictly, positivity of its mass gives \(C(\mu_{r+1})<C(\mu_r)\), so the distributions differ. Conversely, if every label is unchanged, the distributions coincide. Consequently,

\[ \mu_{r+1}=\mu_r \quad\Longleftrightarrow\quad S_{i,r+1}=S_{i,r}\text{ for every }i. \]

Now use the integer potential

\[ P_r=\sum_{i=1}^{\tau}(|S_{i,r}|-1). \]

It is nonnegative and decreases by at least one at every nonstationary round. Hence

\[ k\leq P_0 =\sum_{i=1}^{\tau}(|\operatorname{Mod}(K_i)|-1) \leq\tau(2^m-1). \]

This proves termination without expanding rational masses into repeated agents. The corresponding finite-profile shrinking argument appears in Proposition 5 of [Gauwin–Konieczny–Marquis](https://www.labri.fr/perso/ogauwin/papers/dea/JLC.pdf); the argument above directly handles the rational-mass support representation.

2. Hardness

2.1. Hardness of computing \(k\), with one type

Let \(\varphi(x_1,\ldots,x_t)\) be an arbitrary SAT instance. Introduce a fresh variable \(y\), and put

\[ Z=\bigwedge_{j=1}^{t}\neg x_j,\qquad \Delta=\neg y\land Z,\qquad K=(\neg y\land Z)\lor(y\land\varphi). \]

Use the single type \(K\) with mass \(1\). This construction has polynomial length and satisfies every consistency promise: both \(\Delta\) and \(K\) contain the all-zero valuation \(c\).

Since \(\operatorname{Mod}(\Delta)=\{c\}\), necessarily \(M_r=\{c\}\) at every round. Initially \(c\in\operatorname{Mod}(K)\), so its distance to \(M_0\) is zero. Every other valuation has positive distance. Thus the first update replaces \(K\) by the singleton model set \(\{c\}\).

If \(\varphi\) is unsatisfiable, \(K\) already has exactly this model set, giving \(k=0\). If \(\varphi\) is satisfiable, \(K\) has additional models with \(y=1\); the first update is strict, and the singleton is subsequently unchanged, giving \(k=1\). Therefore

\[ \varphi\text{ is satisfiable}\quad\Longleftrightarrow\quad k=1. \]

One call to the exact-outcome oracle decides SAT by reading \(k\), proving the claimed hardness independently of the formulas chosen to represent the output.

2.2. Hardness of the stationary distribution when \(k=1\) is guaranteed

The preceding reduction uses the stopping index. The distribution itself also encodes SAT on instances with a fixed stopping index.

Given \(\varphi(x_1,\ldots,x_t)\), introduce fresh variables \(u,v,w\). Define

\[ X=\bigwedge_{j=1}^{t}x_j, \]

\[ A=u\land v\land\neg w\land X,\qquad J=u\land v\land w\land X, \]

\[ H=u\land\neg v\land\neg w\land\varphi,\qquad K=A\lor J\lor H. \]

Let \(\Delta\) describe the all-zero valuation \(c\):

\[ \Delta=\neg u\land\neg v\land\neg w \land\bigwedge_{j=1}^{t}\neg x_j. \]

The society consists of \(A\) and \(K\), each with mass \(1/2\). Both bases are consistent, and they are logically distinct because the unique model of \(J\) belongs to \(K\) but not to \(A\).

Again \(M_r=\{c\}\) for every round. The unique models of \(A\) and \(J\) have distances \(t+2\) and \(t+3\), respectively, from \(c\). Every model of \(H\), when one exists, has distance

\[ 1+\sum_{j=1}^{t}x_j\leq t+1. \]

It follows that:

  • If \(\varphi\) is unsatisfiable, the update of \(K\) is exactly \(A\). The two types coalesce, and the stationary support has one element of mass \(1\).
  • If \(\varphi\) is satisfiable, the update of \(K\) consists of the models of \(H\) nearest to \(c\). This set is nonempty and disjoint from \(A\), since its models have \(v=0\). The stationary support has two elements, each of mass \(1/2\).

In either case, the first update is strict because it discards the model of \(J\). After that update, all retained models of each type have the same distance to the fixed singleton \(M_r=\{c\}\), so the next update changes nothing. Thus \(k=1\) in every instance, and

\[ \varphi\text{ is satisfiable} \quad\Longleftrightarrow\quad |\operatorname{supp}(\mu_k)|=2. \]

This reduction uses fixed dyadic masses and requires no logical-equivalence test on returned formulas.

3. Exact algorithm and bit complexity

3.1. Rational arithmetic

Write the input masses as \(w_i=p_i/q_i\), with positive binary-encoded integers, and set

\[ Q=\prod_{i=1}^{\tau}q_i,\qquad a_i=p_i(Q/q_i). \]

Then \(w_i=a_i/Q\) and \(\sum_i a_i=Q\). Because the denominator encodings are included in \(L\), the bit length of \(Q\) is \(O(L)\).

Consequently, merging can minimize the integer score

\[ F_r(\omega)=\sum_{i=1}^{\tau}a_i d_H(\omega,S_{i,r}) \]

instead of its rational multiple \(F_r(\omega)/Q\). Since \(0\leq F_r(\omega)\leq mQ\), scores have \(O(L+\log(m+1))\) bits.

Coalesced masses are sums of the corresponding integers \(a_i\), divided by \(Q\). Their binary lengths remain polynomial in \(L\).

3.2. Computing distances on the Hamming cube

Put \(N=2^m\). Enumerate all valuations, evaluate the input formulas, and store each labelled model set as an \(N\)-bit vector.

For any nonempty set \(S\), its entire distance table can be computed by \(m\) sweeps. Initialize \(D(\omega)=0\) on \(S\) and \(D(\omega)=\infty\) elsewhere. In sweep \(j\), for every pair \(\omega,\omega'\) differing only in coordinate \(j\), simultaneously replace their old values \(a,b\) by

\[ \min(a,b+1),\qquad \min(b,a+1). \]

After sweep \(j\), the invariant is

\[ D(\omega)= \min_{\substack{\nu\in S\\ \nu_\ell=\omega_\ell\ \text{for }\ell>j}} \sum_{\ell=1}^{j}\mathbf 1_{\nu_\ell\ne\omega_\ell}, \]

with an empty minimum interpreted as \(\infty\). The invariant holds initially for \(j=0\). For the induction step, a candidate \(\nu\) either agrees with \(\omega\) in coordinate \(j\), contributing the old value at \(\omega\), or disagrees there, contributing one plus the old value at its paired valuation.

After sweep \(m\), this is exactly \(d_H(\omega,S)\). Each sweep processes \(N/2\) pairs. Infinity can be implemented by a sentinel \(m+1\).

Thus a distance table costs \(O(mN)\) small-integer operations. Indexed tables, or sequential tables reordered by sorting, give \(N\operatorname{poly}(m,L)\) bit time.

3.3. Iteration and output

At each round:

  • Compute distance tables for the \(\tau\) labelled sets and accumulate \(F_r\).
  • Find its minimum over models of \(\Delta\), retaining every minimizing valuation to obtain \(M_r\).
  • Compute the distance table to \(M_r\).
  • For each label, retain exactly its models attaining the minimum distance to \(M_r\).
  • Test whether every labelled bit vector is unchanged.

By Section 1, the last test detects precisely the specified stationarity condition. It therefore stops at the first such round, namely \(k\), with \(M_k\) already computed.

At termination, group equal bit vectors and sum their masses. Represent each resulting model set, and \(M_k\), by a disjunction of its complete valuation minterms. These formulas are exact, and their combined number of literal occurrences is \(O((\tau+1)(m+1)N)\).

Each round costs \(\tau N\operatorname{poly}(m,L)\) bit time. Initialization, final grouping, and formula generation fit within the same total bound. Including the final stationarity test gives

\[ T=O\!\left((k+1)\tau N\operatorname{poly}(m,L)\right). \]

Since \(k+1\leq\tau N\),

\[ T=O\!\left(\tau^2 4^m\operatorname{poly}(m,L)\right). \]

4. Dependence on formula-input length

Variables absent from every input formula can be omitted. Indeed, writing \(U\) for their valuation space, every initial model set has the form \(S\times U\), and

\[ d_H((x,y),S\times U)=d_H(x,S). \]

The merging and update operations therefore preserve this product form. The trajectory and stopping index are exactly those on the variables that occur in the input.

If their number is \(v\), then \(v\leq L\), and \(m\) can be replaced by \(v\) throughout the algorithmic bounds. Since also \(\tau\leq L\), this supplies a deterministic \(2^{O(L)}\)-time upper bound under the usual binary encoding.

Thus finite termination and an exponential-time exact algorithm coexist with \(\mathrm{NP}\)-hardness. The termination bound alone does not imply polynomial-time computation.
