The continuous mirror question, as graded

Given (m) alternatives and a finite support \{(\pi_i,\mu_i)\}_{i=1}^{\tau} of complete rankings with positive binary-rational masses summing to 1, suppose every pair has a strict weighted majority comparison and the resulting tournament T_\mu has equal triangle packing and covering numbers. Compute \operatorname{TEQ}(T_\mu).

Packaged proof task (what the prover saw — nothing else)

Let \(m\geq 1\). A society is given by its support: \(\tau\) distinct strict complete rankings \(\pi_i\) of the alternatives, each with positive binary-rational mass \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
Define \(T_\mu\) by \(a\to b\) exactly when \(\sum_{i:a\succ_{\pi_i}b}\mu_i>1/2\). Every pair is promised to have a strict majority comparison.
A triangle is a directed cycle on three vertices. The triangle packing number is the maximum number of vertex-disjoint triangles; the triangle covering number is the minimum number of vertices meeting every triangle. These two integer numbers are promised equal for \(T_\mu\).
For any nonempty tournament \(T\), put \(N_T^-(v)=\{u:u\to v\}\). A nonempty set \(A\subseteq V(T)\) is \(\operatorname{TEQ}\)-retentive if \(\operatorname{TEQ}(T[N_T^-(v)])\subseteq A\) for every \(v\in A\) with \(N_T^-(v)\neq\varnothing\). Recursively, \(\operatorname{TEQ}(T)\) is the union of all inclusion-minimal retentive sets; for a singleton tournament it is that singleton.

Is computing \(\operatorname{TEQ}(T_\mu)\) on these promised inputs solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For explicitly given tournaments with equal triangle packing and covering numbers, \(\operatorname{TEQ}\) is computable in polynomial time and the minimal retentive set is unique ([Mnich, Shrestha and Yang, 2015](https://www.ijcai.org/Proceedings/15/Papers/091.pdf)). No separate result for this exact rational-mass input problem was identified in the search.

Conclusion

Computing \(\operatorname{TEQ}(T_\mu)\) on the promised inputs is polynomial-time solvable in \(m,\tau,L\). The support representation allows the entire majority tournament to be constructed using polynomially many exact integer operations. The stated theorem for explicit tournaments then applies.

1. Constructing the majority tournament exactly

Let \(V\) be the set of \(m\) alternatives. Write each input mass as \(\mu_i=p_i/q_i\), where \(p_i,q_i\) are positive integers encoded in binary. This also covers dyadic rationals under the usual explicit binary encoding.

Define
\[ D=\prod_{i=1}^{\tau}q_i, \qquad w_i=p_i(D/q_i). \]
Each \(w_i\) is an integer, and \(\mu_i=w_i/D\). The normalization premise gives
\[ \sum_{i=1}^{\tau}w_i=D. \]

The bit length of \(D\) is at most \(1+\sum_i\operatorname{bitlength}(q_i)\), hence is \(O(L)\). Moreover, positivity and normalization imply \(w_i\leq D\), so every \(w_i\) also has \(O(L)\) bits. Products, exact divisions, and multiplications needed to construct these integers therefore take polynomial time in \(\tau,L\).

For each ranking, construct a table \(\operatorname{pos}_i(a)\) giving the position of alternative \(a\). For every unordered pair \(\{a,b\}\), compute the integer
\[ S_{ab}=\sum_{\substack{1\leq i\leq\tau\\ \operatorname{pos}_i(a)<\operatorname{pos}_i(b)}}w_i. \]
Then, exactly,
\[ a\to b \quad\Longleftrightarrow\quad \sum_{i:a\succ_{\pi_i}b}\mu_i>\frac12 \quad\Longleftrightarrow\quad 2S_{ab}>D. \]

All partial sums are at most \(D\), so these calculations use integers of \(O(L)\) bits. There are \(\binom m2\) pairs, each requiring at most \(\tau\) additions. Thus constructing all majority comparisons takes polynomial time in \(m,\tau,L\).

Because every ranking is strict and complete, the total mass preferring \(b\) to \(a\) is \(1-S_{ab}/D\). The strict-majority promise excludes \(2S_{ab}=D\), so exactly one orientation is assigned to each pair. The resulting adjacency matrix is precisely \(T_\mu\), with \(O(m^2)\) entries.

2. Applying the explicit-tournament theorem

Theorem 1 of [Mnich, Shrestha and Yang (2015)](https://www.ijcai.org/Proceedings/15/Papers/091.pdf) states that, for tournaments whose triangle packing and triangle covering numbers are equal, the minimal retentive set is unique and the tournament equilibrium set is computable in polynomial time.

Its hypotheses hold here:

  • The construction above produces an explicitly represented tournament.
  • Its triangle packing and covering numbers are equal by the input promise.
  • The paper’s recursively defined tournament equilibrium set uses the same retentiveness condition and union of inclusion-minimal retentive sets as \(\operatorname{TEQ}\) in the question.

Consequently, running that algorithm on the constructed adjacency matrix returns exactly \(\operatorname{TEQ}(T_\mu)\). For \(m=1\), one may simply return the unique alternative.

3. Complexity of the composed algorithm

The first stage takes polynomial time in \(m,\tau,L\) and produces an explicit tournament of size \(O(m^2)\). The second stage takes polynomial time in that explicit size. Their composition is therefore polynomial-time.

No recognition algorithm for the packing–covering equality is needed: it is a promise. Nor is it necessary to enumerate rankings outside the given support or expand rational masses into individual voters. A separate theorem for the rational-mass representation is unnecessary because the polynomial-time construction transfers the explicit-tournament result.
