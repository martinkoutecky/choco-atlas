Result. The continuous problem is in \(\mathrm{P}\), and consequently is FPT parameterized by \(m\). It can be solved using at most \(m-1\) tests, each either an explicit rational comparison or a linear-programming feasibility test with \(\tau\) variables.

1. Majority margins and normalization

Let \(T\) be the union of the listed supports, so \(|T|=\tau\). For distinct candidates \(a,b\), define
\[ \]
\(s_t(a,b)=1\) if \(a\succ_t b\), and \(s_t(a,b)=-1\) otherwise. Define the unnormalized majority margin
\(M_{ab}(x)=d_{ab}+\sum_{t\in T}s_t(a,b)x_t\), where
\(d_{ab}=\sum_{t\in T}s_t(a,b)\mu_t\).

For the normalized society in the question, the majority margin is
\(M_{ab}(x)/(1+\sum_t x_t)\).
The denominator is positive, so \(a\) beats \(b\) exactly when \(M_{ab}(x)>0\).

Write
\(F=\{x\in\mathbb R^\tau:0\le x_t\le\nu_t\text{ for every }t,\ \sum_t x_t\le\beta\}\).
This is a nonempty bounded rational polytope: it contains \(x=0\).

2. Exact characterization of destructive success

Let \(P(c)=\{a\in C:a\triangleright c\}\) denote the agenda predecessors of \(c\). By definition, \(c\) is shortlisted exactly when
\(M_{ac}(x)\le0\) for every \(a\in P(c)\).
The weak inequality is essential because ties produce no majority arc.

For every \(x\in F\), the following equivalence holds:

\(p\) is not the winner if and only if at least one of these conditions holds:

  • There exists \(a\in P(p)\) with \(M_{ap}(x)>0\).
  • There exists \(c\) with \(p\triangleright c\) such that \(M_{ac}(x)\le0\) for every \(a\in P(c)\).

To prove the forward implication, if \(p\) is not shortlisted, some predecessor beats it, giving condition 1. Otherwise, \(p\) is shortlisted. Since the winner is the last shortlisted candidate and differs from \(p\), some candidate after \(p\) is shortlisted, giving condition 2.

Conversely, condition 1 excludes \(p\) from the shortlist. Condition 2 ensures that the last shortlisted candidate occurs after \(p\). Either condition therefore prevents \(p\) from winning. A winner always exists because the first agenda candidate is shortlisted.

3. Testing the two conditions

For each \(a\in P(p)\), let
\(V_{ap}=\sum_{t:a\succ_t p}\nu_t\).
Then
\[ \]
\(\max_{x\in F}M_{ap}(x)=d_{ap}+\min\{\beta,V_{ap}\}\).

Indeed, if \(u=\sum_{t:a\succ_t p}x_t\) and \(v=\sum_{t:p\succ_t a}x_t\), then
\(M_{ap}(x)=d_{ap}+u-v\).
Feasibility gives \(v\ge0\), \(u\le V_{ap}\), and \(u\le\beta\), proving the upper bound. It is attained by adding only types ranking \(a\) above \(p\), filling their capacities until total added mass equals \(\min\{\beta,V_{ap}\}\). Such an allocation exists by the definition of \(V_{ap}\).

Thus condition 1 is achievable for this predecessor exactly when
\(d_{ap}+\min\{\beta,V_{ap}\}>0\).
This is an exact rational comparison, so the strict majority threshold causes no numerical ambiguity.

For each candidate \(c\) after \(p\), test feasibility of the following rational linear system:

  • \(0\le x_t\le\nu_t\) for every \(t\in T\);
  • \(\sum_{t\in T}x_t\le\beta\);
  • \(d_{ac}+\sum_{t\in T}s_t(a,c)x_t\le0\) for every \(a\in P(c)\).

This system is feasible exactly when condition 2 is achievable with this choice of \(c\). All its inequalities are weak, so ordinary exact rational LP feasibility applies. Rational linear-programming feasibility is decidable in polynomial bit complexity by [Khachiyan’s theorem](https://www.mathnet.ru/eng/dan42319).

No restrictions on candidates after \(c\) are needed: if any of them is also shortlisted, the winner still occurs after \(p\).

The algorithm accepts if any predecessor comparison succeeds or any successor system is feasible; otherwise it rejects. The equivalence proved in Section 2 establishes both directions of correctness.

4. Running time and parameterization

There are \(|P(p)|\) predecessor comparisons and \(m-1-|P(p)|\) successor LPs, hence exactly \(m-1\) possible tests. Each LP has \(\tau\) variables and
\(2\tau+1+|P(c)|\le2\tau+m\) inequalities.

Here is a precise bound expressed through the chosen polynomial-time LP solver. Let \(\operatorname{LP}(n,r,B)\) denote its worst-case bit running time on systems with \(n\) variables, at most \(r\) inequalities, and encoding length at most \(B\).

To bound coefficient lengths, take a common denominator \(D\), the product of all input mass denominators. Its binary length is \(O(L)\). Substituting \(z_t=Dx_t\) gives integral right-hand sides \(D\nu_t\), \(D\beta\), and \(Dd_{ac}\), each of bit length \(O(L)\); all variable coefficients remain in \(\{-1,0,1\}\). A dense encoding of each system therefore has length
\(O((m+\tau)(\tau+L))\).

Computing ranking positions, signs, scaled margins, and predecessor comparisons takes at most \(O(m^2\tau L^2)\) bit operations using elementary integer arithmetic. The total running time is consequently
\[ \]
\(O(m^2\tau L^2)+m\,\operatorname{LP}\bigl(\tau,2\tau+m,O((m+\tau)(\tau+L))\bigr) =(m+\tau+L)^{O(1)}\).

This establishes polynomial-time solvability in the stated support representation, without enumerating omitted rankings. It also gives an FPT bound \(f(m)(\tau+L)^{O(1)}\), with polynomial \(f\).

5. Relation to the discrete problem

The [cited discrete hardness result](https://link.springer.com/article/10.1007/s10458-026-09743-x) does not transfer to continuous masses. Fixing a successor \(c\) produces a system of majority inequalities; continuous additions give linear feasibility, whereas discrete additions retain integrality restrictions.

The same algorithm also covers a last-position target: there are then no successor LPs, and the predecessor comparisons alone decide the problem.
