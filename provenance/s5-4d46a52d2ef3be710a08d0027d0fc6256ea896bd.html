The continuous mirror question, as graded

Given a measurable cake, a finite type set \(T\), binary-rational masses \(\rho_t>0\) summing to \(1\), atomless valuation oracles \(\mu_t\), and positive entitlement rates \(e_t\) with \(\sum_{t\in T}\rho_t e_t=1\), construct a measurable partition \(C=\bigsqcup_{t\in T}A_t\) such that \(\mu_t(A_t)\geq\rho_t e_t\) for every type \(t\), using the paper’s value, cut, and set-operation model.

A society is given by its support: a list of \(\tau=|T|\geq2\) types with positive binary rational masses \(p_t\), where \(\sum_t p_t=1\); \(\tau\) counts listed types, not possible types.
The cake is a common measurable space \((C,\mathcal S)\). Each valuation \(v_t\) is a nonnegative atomless probability measure on \(\mathcal S\). Positive binary rational entitlement intensities \(q_t\) satisfy \(\sum_t p_tq_t=1\). Let \(L\) be the total bit length of the masses and intensities; there is no separate goods-count parameter \(m\).
For any previously constructed measurable slice \(A\), value access returns \(v_t(A)\), and cut access, given \(\alpha\in[0,v_t(A)]\), returns any measurable \(B\subseteq A\) with \(v_t(B)=\alpha\). Initially \(C\) is available. Queries, finite set operations, exact real arithmetic, and comparisons each cost one operation; slices are represented by oracle handles and finite set expressions. Algorithms must work for every valid cut response.
Find a measurable partition \(C=\bigsqcup_{t\in T}S_t\) satisfying \(v_t(S_t)\geq p_tq_t\) for every \(t\); pieces need not be connected.

Is this search problem solvable in time polynomial in \(\tau\) and \(L\) in the specified oracle model, or is it NP-hard?

For finitely many individual agents, a last-diminisher procedure terminates for arbitrary positive entitlements, including irrational ones; no polynomial bound is asserted. [Jankó and Joó](https://arxiv.org/pdf/2109.05269).

Result

The search problem is solvable in time polynomial in \(\tau\) and \(L\) in the specified oracle model.

The construction below uses \(\mathcal O(\tau^2 L)\) oracle queries and \(\mathcal O(\tau^2 L^2)\) total operations. It works for every valid cut response.

The starting idea is the two-player “Cut Near-Halves” procedure discussed in [Cseh and Fleiner, Section 3](https://arxiv.org/html/1709.03152). We give a direct proof for the present measurable-space oracle model; no ordering of cuts or geometric structure is required.

1. Integer demands with a short common denominator

Index the listed types by \(\{1,\ldots,\tau\}\). Write their input rationals as \(p_i=a_i/b_i\) and \(q_i=c_i/e_i\), with positive integer numerators and denominators. Define

\[ D=\prod_{i=1}^{\tau}b_i e_i, \qquad d_i=a_i c_i\,\frac{D}{b_i e_i}. \]

Every \(d_i\) is a positive integer, and the normalization assumption gives

\[ \sum_{i=1}^{\tau}d_i =D\sum_{i=1}^{\tau}p_iq_i =D. \]

Thus the required entitlement is \(p_iq_i=d_i/D\).

The sum of the binary lengths of all input denominators is at most \(L\), so \(\log_2 D\leq L\). We will use these integers directly, without constructing \(D\) individual agents.

2. A two-type splitting lemma

Lemma. Let \(A\) be a previously constructed measurable slice, let \(u,w\) be two of the valuation measures, and let \(a,b\) be positive integers. There is an algorithm returning a measurable partition \(A=U\bigsqcup W\) such that

\[ u(U)\geq\frac{a}{a+b}u(A), \qquad w(W)\geq\frac{b}{a+b}w(A). \]

It uses \(\mathcal O(1+\log_2(a+b))\) queries and works for every valid cut response.

Proof. We prove correctness by induction on the integer \(H=a+b\).

First evaluate both measures on \(A\). If either value is zero, give all of \(A\) to the other type and the empty set to the type with zero value. If both values are zero, either assignment suffices. Hence assume both values are positive.

Relabel the two types, if necessary, so that \(a\leq b\), with \(u\) having demand \(a\). Put

\[ h=\left\lfloor\frac H2\right\rfloor, \qquad k=\left\lceil\frac H2\right\rceil. \]

Ask the cut oracle for any \(B\subseteq A\) satisfying

\[ u(B)=\frac hH u(A). \]

This is a valid query because its requested value lies between zero and \(u(A)\). Let \(F=A\setminus B\), so \(u(F)=k\,u(A)/H\).

Evaluate \(w(B)\). Choose a piece \(Q\) for the type with demand \(b\) as follows:

  • If \(w(B)\geq h\,w(A)/H\), take \(Q=B\) and set \(s=h\).
  • Otherwise, take \(Q=F\) and set \(s=k\). In this case additivity gives \(w(F)>k\,w(A)/H\).

In either case, writing \(R\) for the other piece, we have

\[ u(Q)=\frac sH u(A), \qquad w(Q)\geq\frac sH w(A), \qquad u(R)=\frac{H-s}{H}u(A). \]

Since \(a\leq b\), we have \(b\geq k\geq s\), so \(b-s\) is nonnegative.

If \(b-s=0\), give \(R\) to the type with demand \(a\). Its value is \(a\,u(A)/H\), because \(H-s=a\); the other type already receives at least \(b\,w(A)/H\).

If \(b-s>0\), recursively split \(R\) with integer demands \(a\) and \(b-s\), then add \(Q\) to the second type’s allocation. This recursion has smaller total demand \(H-s<H\).

By the induction hypothesis, the first type receives value at least

\[ \frac{a}{H-s}u(R) =\frac aH u(A). \]

For the second type, put \(z=w(Q)/w(A)\), so \(z\geq s/H\). Its total allocation has value at least

\[ w(A)\left[z+\frac{b-s}{H-s}(1-z)\right]. \]

The expression in brackets equals

\[ \frac bH+\frac{a}{H-s}\left(z-\frac sH\right) \geq\frac bH. \]

This proves both guarantees.

There is only one recursive call per round, and its total demand is at most \(\lceil H/2\rceil\). If \(H\leq 2^\ell\), the next total is at most \(2^{\ell-1}\). Consequently there are at most \(\lceil\log_2 H\rceil\) cutting rounds, each requiring a constant number of queries.

All pieces are obtained by cuts, complements within the current slice, and finite unions. The proof uses only the value equality promised by each cut response, so it applies to every valid response. This proves the lemma. \(\square\)

3. Adding the types one at a time

For \(1\leq r\leq\tau\), define the cumulative integer demand

\[ H_r=\sum_{i=1}^{r}d_i. \]

We construct, inductively, a measurable partition of the entire cake among the first \(r\) types satisfying

\[ v_i(P_i^{(r)})\geq\frac{d_i}{H_r} \qquad(1\leq i\leq r). \]

For \(r=1\), assign \(P_1^{(1)}=C\). The inequality holds because \(v_1(C)=1=d_1/H_1\).

Suppose such a partition has been constructed for \(r-1\). For each \(i<r\), apply the lemma to the old piece \(P_i^{(r-1)}\), using valuations \(v_i,v_r\) and integer demands \(H_{r-1},d_r\). Write the resulting partition as

\[ P_i^{(r-1)}=A_i\bigsqcup B_i, \]

where

\[ v_i(A_i)\geq\frac{H_{r-1}}{H_r}v_i(P_i^{(r-1)}), \qquad v_r(B_i)\geq\frac{d_r}{H_r}v_r(P_i^{(r-1)}). \]

Assign \(P_i^{(r)}=A_i\) for \(i<r\), and assign

\[ P_r^{(r)}=\bigcup_{i<r}B_i. \]

These pieces partition \(C\): every old piece is partitioned into two, and the old pieces were pairwise disjoint.

For each old type, the induction hypothesis gives

\[ v_i(P_i^{(r)}) \geq\frac{H_{r-1}}{H_r}\frac{d_i}{H_{r-1}} =\frac{d_i}{H_r}. \]

For the incoming type, finite additivity and the fact that the old pieces partition \(C\) give

\[ v_r(P_r^{(r)}) =\sum_{i<r}v_r(B_i) \geq\frac{d_r}{H_r}\sum_{i<r}v_r(P_i^{(r-1)}) =\frac{d_r}{H_r}. \]

This completes the induction. At \(r=\tau\), we have \(H_\tau=D\), so setting \(S_i=P_i^{(\tau)}\) yields

\[ v_i(S_i)\geq\frac{d_i}{D}=p_iq_i \]

for every listed type.

4. Operation count and representation

The number of applications of the two-type lemma is

\[ \sum_{r=2}^{\tau}(r-1)=\frac{\tau(\tau-1)}2. \]

Each application starts with total demand \(H_r\leq D\), so it uses \(\mathcal O(1+\log_2 D)\) queries. The overall query count is therefore \(\mathcal O(\tau^2 L)\).

For completeness, the integer floor and ceiling operations in the description need not be additional primitives. Precompute powers of two up to \(2^L\). For any integer \(H\leq D\), comparisons and subtractions recover its binary digits in \(\mathcal O(L)\) operations, from which \(\lfloor H/2\rfloor\) and \(\lceil H/2\rceil\) are constructed. Thus each cutting round uses \(\mathcal O(L)\) allowed arithmetic and comparison operations. Including preprocessing, the total is \(\mathcal O(\tau^2 L^2)\).

Slice representations also stay polynomial. In each cutting round, form \(F=A\setminus B\) once; the chosen piece and the residual are simply \(B,F\) in one order or the other. Accumulate allocated slices by finite unions. Even with explicit expression trees, the preceding expression for \(A\) occurs in only one of these two expressions, because \(B\) is a new oracle handle. Consequently the total expression size grows by only a constant per cutting round or union.

The construction uses exactly the listed \(\tau\) types and the specified oracle operations. It establishes polynomial-time solvability without any goods-count parameter or additional cut structure.
