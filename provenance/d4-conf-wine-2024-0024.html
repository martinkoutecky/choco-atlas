The continuous mirror question, as graded

Given rational data consisting of worker types \(T\) with masses \(\mu_t\), obligations \(a_t>0\) satisfying \(\sum_t\mu_ta_t=1\), \(q\) chore classes with per-capita supplies \(\lambda_j\), costs \(c_{tj}\in[0,1]\), and bundle bound \(B\), let \(\mathcal{B}_B=\{b\in\mathbb{Z}_{\ge0}^q:\sum_{j=1}^q b_j\le B\}\). Compute or decide the optimum \(S^*\) over \(\theta_{t,b}\ge0\) satisfying \(\sum_{b\in\mathcal{B}_B}\theta_{t,b}=\mu_t\) and \(\sum_{t\in T,b\in\mathcal{B}_B}\theta_{t,b}b_j=\lambda_j\), where \(S^*=\min_\theta\sum_{t,b}\theta_{t,b}(\sum_jb_jc_{tj}-a_tC_t)^+\) and \(C_t=\sum_j\lambda_jc_{tj}\); determine in particular whether \(S^*\le 1/3\) for every feasible instance and how complexity changes when \(q\) or \(B\) varies.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of the \(\tau\) types with positive masses \(\mu_t\), each encoded as a binary rational; \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_t\mu_t=1\).
There are \(q\geq1\) chore classes, with rational per-capita supplies \(\lambda_j\geq0\), additive unit costs \(c_{tj}\in[0,1]\), and rational obligations \(a_t>0\) satisfying \(\sum_t\mu_ta_t=1\). The bundle bound \(B\in\mathbb Z_{\geq0}\) is encoded in binary.
Set \(\mathcal B_B=\{b\in\mathbb Z_{\geq0}^q:\sum_jb_j\leq B\}\) and \(C_t=\sum_j\lambda_jc_{tj}\). Each worker receives an integer bundle; a type's mass may be split among bundles, including the empty bundle.
An allocation consists of masses \(\theta_{t,b}\geq0\) satisfying \(\sum_{b\in\mathcal B_B}\theta_{t,b}=\mu_t\) and \(\sum_{t,b}\theta_{t,b}b_j=\lambda_j\) for every class \(j\). Instances are promised feasible.
The minimum subsidy for a type-\(t\) worker receiving \(b\) is \((\sum_jb_jc_{tj}-a_tC_t)^+\), where \(x^+=\max\{x,0\}\); define \(S^*=\min_\theta\sum_{t,b}\theta_{t,b}(\sum_jb_jc_{tj}-a_tC_t)^+\).
The decision input also contains a binary rational threshold \(K\geq0\). Let \(L\) be the total input bit length and \(m=q\) the number of listed chore classes; there is no finite total item count.

Is deciding \(S^*\leq K\) in \(\mathrm P\) or \(\mathrm{NP}\)-hard, and how does the classification change when \(q\), \(B\), or both are fixed? State running times in \(m\), \(\tau\), \(L\), and \(B\).
Does \(S^*\leq1/3\) hold for every feasible instance?

Discrete: for positive normalized weights and additive chore costs bounded by one, a connected fractional bid-and-take sharing tree containing an item shared by at least three agents admits polynomial-time rounding with total subsidy at most \((n-1)/3\), where \(n\) is the number of agents. [Verified source](https://arxiv.org/html/2404.07707v1).

  • Use a feasibility promise, matching the graded question's restriction to feasible instances.

1. Classification and running times

I use the standard bit-model interpretation that the explicitly listed costs \(c_{tj}\) are also binary rationals.

The general decision problem is \(\mathrm{NP}\)-complete, already for \(\tau=1\) and \(K=0\). Fixing either \(q=m\) or \(B\) makes it polynomial-time solvable. The proposed universal bound is false: a feasible instance with \(m=B=1\) has \(S^*=3/8\).

The following are valid running-time bounds; all hidden polynomial exponents are absolute constants.

| Parameters | Classification | Running-time upper bound |
|---|---|---|
| General | \(\mathrm{NP}\)-complete | \(\bigl(\tau\binom{B+m}{m}+\tau+m+L\bigr)^{O(1)}\) |
| Fixed \(m=q\) | \(\mathrm P\) | \(2^{O(m\log(m+1))}\operatorname{poly}(\tau,m,L,\log(B+1))\) |
| Fixed \(B\) | \(\mathrm P\) | \(\bigl(\tau(m+1)^B+\tau+m+L\bigr)^{O(1)}\) |
| Both fixed | \(\mathrm P\) | \(\operatorname{poly}(\tau,L)\) |

The fixed-\(m\) bound depends logarithmically on \(B\). In contrast, the fixed-\(B\) enumeration bound has a polynomial degree depending on \(B\).

2. The configuration LP and polynomial certificates

Define
\[ \]
\(h_t=a_tC_t\) and \(f_t(b)=(c_t\cdot b-h_t)^+\).

The allocation problem is the finite rational linear program
\[ \]
\(\displaystyle \min_{\theta\geq0}\sum_{t,b}f_t(b)\theta_{t,b},\)
subject to
\[ \]
\(\displaystyle \sum_b\theta_{t,b}=\mu_t\quad(t\in T),\qquad \sum_{t,b}b_j\theta_{t,b}=\lambda_j\quad(j=1,\ldots,m).\)

There are \(\tau\binom{B+m}{m}\) variables and \(\tau+m\) equality constraints. Every variable satisfies \(0\leq\theta_{t,b}\leq\mu_t\), so feasibility implies that the feasible set is nonempty and compact. Consequently, an optimum exists.

For completeness, feasibility is equivalent to \(\sum_j\lambda_j\leq B\). Necessity follows by summing the supply equalities. For sufficiency when \(B>0\), give every type the same bundle distribution: probability \(\lambda_j/B\) on \(Be_j\), and the remaining probability on the empty bundle. Multiplying these probabilities by \(\mu_t\) gives a feasible allocation. When \(B=0\), feasibility requires every supply to vanish.

Polynomial certificates

An optimal basic feasible solution has at most \(\tau+m\) positive variables. Each selected bundle is encoded using \(O(m\log(B+1))\) bits.

The equality matrix has integer entries bounded by \(\max\{1,B\}\). For a basic solution, select an invertible square submatrix of order \(r\leq\tau+m\). Hadamard’s inequality bounds its determinant by
\[ \]
\(\displaystyle r^{r/2}\max\{1,B\}^{r}.\)

Clearing the denominators of the relevant right-hand-side entries and applying Cramer’s rule therefore gives polynomial-length rational masses. The subsidy coefficients are also computable exactly with polynomial bit length from the input and the selected bundles.

Thus a yes-certificate lists at most \(\tau+m\) bundle–mass pairs. All allocation equalities and the subsidy inequality can be checked by exact rational arithmetic in polynomial time. This proves membership in \(\mathrm{NP}\).

Enumeration

Enumerating all bundles and solving the displayed LP gives the general running time in the table. Moreover,
\[ \]
\(\displaystyle |\mathcal B_B|=\binom{B+m}{m}\leq(m+1)^B.\)

To see the inequality, encode a bundle by a length-\(B\) sequence over the \(m\) classes plus an empty-slot symbol; every bundle has such an encoding. Hence fixed \(B\) gives polynomial time, and fixing both parameters gives \(\operatorname{poly}(\tau,L)\).

3. NP-hardness with one supported type

We reduce from Partition: given positive integers \(w_1,\ldots,w_r\) with even total \(W=\sum_iw_i\), decide whether some subset sums to \(W/2\). This restriction remains \(\mathrm{NP}\)-complete: doubling every integer converts an unrestricted Partition instance into an equivalent instance with even total.

Construction

Set
\[ \]
\(\displaystyle D=rW+1,\qquad M=D^r+W.\)

Use one type with \(\mu=a=1\), and \(2r\) classes indexed by \((i,s)\), where \(i=1,\ldots,r\) and \(s\in\{0,1\}\). Set
\[ \]
\(\displaystyle B=r,\qquad K=0,\qquad \lambda_{i,0}=\lambda_{i,1}=\frac12,\)
and
\[ \]
\(\displaystyle c_{i,0}=\frac{D^i}{M},\qquad c_{i,1}=\frac{D^i+w_i}{M}.\)

All costs lie in \([0,1]\), since \(D^i+w_i\leq D^r+W=M\). The normalization conditions hold. The total supply is \(r=B\), so the instance is feasible by Section 2.

Every constructed number has polynomial encoding length: in particular, \(\log M=O(r\log D)\).

The single type’s baseline is
\[ \]
\(\displaystyle C=\sum_{i,s}\lambda_{i,s}c_{i,s} =\frac{\sum_{i=1}^rD^i+W/2}{M}.\)

Zero subsidy forces every used bundle to have cost exactly \(C\)

For every feasible allocation,
\[ \]
\(\displaystyle \sum_b\theta_b(c\cdot b)=c\cdot\lambda=C,\qquad \sum_b\theta_b=1.\)

If its total subsidy is zero, every positive-mass bundle satisfies \(c\cdot b\leq C\). Their mean is \(C\), so every such bundle must actually satisfy \(c\cdot b=C\).

Since an optimum exists, \(S^*=0\) therefore implies the existence of a bundle satisfying
\[ \]
\[\displaystyle \sum_{i=1}^r(b_{i,0}+b_{i,1})D^i+ \sum_{i=1}^rw_ib_{i,1} = \sum_{i=1}^rD^i+\frac W2. \tag{1}\]

The digit encoding forces a partition

Because the bundle has at most \(r\) chores,
\[ \]
\(\displaystyle 0\leq\sum_iw_ib_{i,1}\leq rW<D,\qquad 0\leq b_{i,0}+b_{i,1}\leq r<D.\)

Also \(W/2<D\). Thus both sides of (1) are already valid base-\(D\) expansions, with no carries. Uniqueness of that expansion gives
\[ \]
\(\displaystyle b_{i,0}+b_{i,1}=1\quad\text{for every }i,\qquad \sum_iw_ib_{i,1}=\frac W2.\)

Consequently, the indices with \(b_{i,1}=1\) form a partition.

Conversely, suppose a partition exists. Construct a bundle choosing class \((i,1)\) for indices in the partition and class \((i,0)\) otherwise. Construct a second bundle making the complementary choices. Both have \(r\) chores and cost exactly \(C\). Giving each bundle mass \(1/2\) supplies every class in amount \(1/2\) and incurs zero subsidy.

We have proved
\[ \]
\(\displaystyle S^*\leq0\quad\Longleftrightarrow\quad \text{the Partition instance is a yes-instance}.\)

This is a polynomial reduction whose outputs always satisfy the feasibility promise. Together with Section 2, it proves the general \(\mathrm{NP}\)-completeness claim.

4. Polynomial time for fixed \(q=m\)

Enumeration alone would give a dependence polynomial in the numerical value of \(B\). To obtain dependence on its binary length, use the LP dual:
\[ \]
\(\displaystyle \max_{u,v}\left(\sum_t\mu_tu_t+\sum_j\lambda_jv_j\right),\)
subject to
\[ \]
\(\displaystyle u_t+v\cdot b\leq f_t(b) \quad(t\in T,\ b\in\mathcal B_B).\)

Here \(u\in\mathbb R^\tau\) and \(v\in\mathbb R^m\) are unrestricted. Ordinary finite-dimensional LP duality identifies its optimum with \(S^*\).

Exact separation using two integer programs per type

Given rational \(u,v\), define
\[ \]
\(\displaystyle \gamma_t(v)=\min_{b\in\mathcal B_B}\bigl(f_t(b)-v\cdot b\bigr).\)

The constraints for type \(t\) hold exactly when \(u_t\leq\gamma_t(v)\). Split the minimization into the two regions defining the positive part:
\[ \]
\(\displaystyle \gamma_t^-= \min\{-v\cdot b: b\in\mathbb Z_{\geq0}^m,\ \sum_jb_j\leq B,\ c_t\cdot b\leq h_t\},\)
and
\[ \]
\(\displaystyle \gamma_t^+= \min\{(c_t-v)\cdot b-h_t: b\in\mathbb Z_{\geq0}^m,\ \sum_jb_j\leq B,\ c_t\cdot b\geq h_t\}.\)

An empty region has value \(+\infty\). These regions cover all bundles, so
\[ \]
\(\displaystyle \gamma_t(v)=\min\{\gamma_t^-,\gamma_t^+\}.\)

Each problem has \(m\) integer variables, a linear objective, rational linear constraints, and a bounded feasible region contained in \([0,B]^m\). Clearing denominators preserves polynomial encoding length.

Deterministic fixed-dimension integer optimization solves these problems in \(2^{O(m\log(m+1))}\) times a polynomial in their encoding length. One applicable result is [Hildebrand–Köppe, Theorem 1.1](https://arxiv.org/html/1006.4661): linear objectives and constraints are quasiconvex polynomials, and the bounded region here has a bound of polynomial encoding length.

If \(u_t>\gamma_t(v)\), an optimizing bundle supplies a violated dual inequality. Otherwise, all inequalities for that type hold. Processing the \(\tau\) types therefore gives an exact separation oracle.

Why the oracle gives exact optimization

The dual has dimension \(\tau+m\). Each defining inequality has coefficients consisting of a type indicator, an integer bundle with coordinates at most \(B\), and the rational value \(f_t(b)\). Their encoding lengths are uniformly polynomial in \(\tau,m,L,\log(B+1)\).

These bounds make the dual a well-described rational polyhedron. The strong separation–optimization theorem therefore applies, including to an unbounded or lower-dimensional feasible set; see [Grötschel–Lovász–Schrijver, *Rational Polyhedra*](https://link.springer.com/chapter/10.1007/978-3-642-78240-4_7).

The dual is feasible because \(u=v=0\) satisfies every inequality. Its optimum is finite: for every bundle,
\[ \]
\(\displaystyle 0\leq f_t(b)\leq c_t\cdot b\leq B,\)
so every feasible primal allocation has subsidy at most \(B\).

Exact dual optimization consequently computes \(S^*\), and comparison with the rational threshold \(K\) is exact. Combining the oracle and optimization bounds gives
\[ \]
\(\displaystyle 2^{O(m\log(m+1))} \operatorname{poly}(\tau,m,L,\log(B+1)).\)

This proves polynomial-time solvability for every fixed number of listed classes.

5. The universal \(1/3\) bound is false

Consider the following instance:
\[ \]
\(\displaystyle q=B=1,\qquad \lambda_1=1,\qquad \mu_1=\mu_2=\frac12,\)
\[ \]
\(\displaystyle a_1=\frac14,\qquad a_2=\frac74,\qquad c_{11}=1,\qquad c_{21}=\frac12.\)

The obligations normalize correctly:
\[ \]
\(\displaystyle \frac12\cdot\frac14+\frac12\cdot\frac74=1.\)

Each bundle contains either zero or one chore. The supply equality requires an average of one chore per worker. Therefore every worker must receive one chore: any positive mass receiving the empty bundle would make the average strictly smaller than one.

The baselines are \(a_1C_1=1/4\) and \(a_2C_2=7/8\). Hence the forced allocation has
\[ \]
\(\displaystyle S^*= \frac12\left(1-\frac14\right)^+ +\frac12\left(\frac12-\frac78\right)^+ =\frac38>\frac13.\)

The failure can grow linearly with the bundle bound. For any integer \(B\geq1\), keeping these types and setting \(\lambda_1=B\) forces every worker to receive \(B\) chores and gives \(S^*=3B/8\).

The cited discrete rounding theorem concerns its specified fractional sharing-tree setting. It does not provide a rounding guarantee preserving this model’s bundle cap, which prevents transferring additional chores to the type with the larger obligation. See [Wu–Zhou, Theorem 5.3](https://arxiv.org/html/2404.07707v1).
