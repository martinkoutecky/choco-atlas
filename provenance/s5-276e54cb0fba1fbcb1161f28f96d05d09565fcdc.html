The continuous mirror question, as graded

Given \(k\) firm types, \(k\) worker types, and \(k\) technique types, each with mass \(1/k\), complete preference rankings, lexicographic worker preferences with firm priority, and a function \(\beta\) satisfying Technical Specialization, compute a stable mass matching. A matching is a distribution \(\pi_{fwt}\) with each type's marginal mass \(1/k\); it is stable if no triple \((f,w,t)\) has some positive mass of each type assigned to outcomes they rank below the proposed coalition.

Packaged proof task (what the prover saw — nothing else)

Let \(F,W,T\) be disjoint sets of firm, worker, and technique types, with \(|F|=|W|=|T|=k\geq1\); every type has mass \(1/k\), so each side has total mass one.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; \(\tau\) counts listed types, not possible preference types. Here \(\tau=3k\); set \(m=k\), and let \(L\) be the total input bit length.
Input preferences are explicit strict complete rankings: firms rank \(W\times T\), workers rank \(F\times T\), and techniques rank \(F\times W\). Each worker's ranking is lexicographic in strict orders \(P_w\) on firms and \(Q_w\) on techniques, with firm priority; firms and techniques have no separability restriction.
The supplied table \(\beta:F\times W\to T\) satisfies Technical Specialization: \(\beta(f,w)\neq\beta(f',w')\) whenever \(f\neq f'\) and \(w\neq w'\), and \((w,\beta(f,w))\succeq_f(w,t)\) for every \(f,w,t\).
A mass matching is a rational array \(\pi_{fwt}\geq0\) satisfying \(\sum_{w,t}\pi_{fwt}=1/k\), \(\sum_{f,t}\pi_{fwt}=1/k\), and \(\sum_{f,w}\pi_{fwt}=1/k\) for every respective type.
A triple \((f,w,t)\) blocks if each member has positive assigned mass on partner pairs it strictly ranks below its proposed partner pair. These three portions may come from different assigned triples. A matching is stable if no triple blocks.

Is computing a stable mass matching on this promised domain solvable in time polynomial in \(m,\tau,L,k\), or is it \(\mathrm{NP}\)-hard?

Discrete: strict worker lexicographic preferences and Technical Specialization guarantee a stable matching, with unrestricted firm and technique rankings. [Lahiri](https://mpra.ub.uni-muenchen.de/8890/1/MPRA_paper_8890.pdf)
Continuous: existence is known for multisided mass matching under aligned preferences represented by a common coalition utility, a different preference domain. [Echenique–Root–Sandomirskiy](https://arxiv.org/html/2402.13378v1)

Modeling choices made when packaging the task

  • Complete rankings are strict, as in the discrete linear-order model; no tie-breaking is needed.
  • Worker preferences use a firm-independent technique order after firm priority, retaining the supplied version's worker preference restriction.
  • Firm separability is not imposed: revised and published versions remove the supplied version's accidental inclusion of that restriction in worker lexicographic preferences.
  • Technical Specialization uses the formal condition that both firm and worker differ, rather than injectivity on all distinct firm-worker pairs.
  • Masses are normalized separately on each side; the total listed support size is three times the number of types per side.
  • The output is an exact rational mass array, and blocking permits the three improving portions to originate in different assigned triples.
  • The size variable m denotes the number of types per side, and L denotes the total binary input length.

Result

Computing a stable mass matching on this promised domain is polynomial-time solvable. A stable matching supported on exactly \(k\) triples can be constructed; each supported triple receives mass \(1/k\).

The construction underlying [Lahiri’s Theorem 1](https://mpra.ub.uni-muenchen.de/8890/1/MPRA_paper_8890.pdf) applies directly. Below is a self-contained algorithm and verification, including the case where a proposed blocking triple uses a worker’s currently assigned firm.

1. Construct an auxiliary two-sided problem

For each firm \(f\), define a strict order \(R_f\) on workers by
\[ w\,R_f\,w' \quad\Longleftrightarrow\quad (w,\beta(f,w))\succ_f(w',\beta(f,w')). \]
This is a strict complete order: distinct workers give distinct partner pairs, and the firm’s input ranking is strict and complete.

Give each worker \(w\) its prescribed firm order \(P_w\). Compute a stable bijection \(\mu:F\to W\) for these two-sided preferences using firm-proposing deferred acceptance.

For completeness, the algorithm repeatedly lets an unmatched firm propose to its most preferred worker not yet approached. A worker retains its most preferred proposing firm and rejects any other.

There are at most \(k^2\) proposals. A worker who has received a proposal always retains a firm thereafter. Consequently, an unmatched firm cannot exhaust all \(k\) workers: exhaustion would imply that all \(k\) workers retain distinct firms, contradicting the existence of an unmatched firm. Thus termination yields a bijection.

Its stability follows from the rejection rule. If \(f\) prefers \(w\) to \(\mu(f)\), then \(f\) proposed to \(w\) before proposing to its final partner. Worker \(w\) rejected \(f\), immediately or subsequently, and thereafter retained only firms it preferred to \(f\). Hence
\[ w\,R_f\,\mu(f) \quad\Longrightarrow\quad \mu^{-1}(w)\,P_w\,f. \]
In particular, no firm–worker pair strictly prefers each other to their assigned partners.

2. Assign techniques and masses

Define
\[ \nu(f)=\beta(f,\mu(f)). \]
If \(f\neq f'\), bijectivity of \(\mu\) gives \(\mu(f)\neq\mu(f')\). Technical Specialization therefore gives
\[ \nu(f)\neq\nu(f'). \]
Thus \(\nu:F\to T\) is injective and, since both sets have cardinality \(k\), bijective.

Output the rational array
\[ \pi_{fwt}= \begin{cases} 1/k,& w=\mu(f)\ \text{and}\ t=\nu(f),\\ 0,&\text{otherwise}. \end{cases} \]
Each firm occurs in exactly one supported triple. Bijectivity of \(\mu\) and \(\nu\) gives the same property for every worker and technique. All required marginals are therefore \(1/k\).

3. Prove mass stability

Every type has positive assigned mass on exactly one partner pair. Accordingly, a type has positive mass on pairs strictly below a proposed pair if and only if it strictly prefers the proposed pair to its unique assigned pair.

Suppose, for contradiction, that \((f,w,t)\) blocks.

If \(w=\mu(f)\), Technical Specialization gives
\[ (w,\nu(f)) =(w,\beta(f,w)) \succeq_f(w,t). \]
The firm therefore cannot strictly improve, contradicting blocking.

Otherwise, \(w\neq\mu(f)\), so \(f\neq\mu^{-1}(w)\). The worker’s strict improvement and firm-priority lexicographic preferences imply
\[ f\,P_w\,\mu^{-1}(w). \]
The firm’s strict improvement, together with its best-technique property, implies
\[ (w,\beta(f,w)) \succeq_f(w,t) \succ_f(\mu(f),\nu(f)) =(\mu(f),\beta(f,\mu(f))). \]
By transitivity,
\[ w\,R_f\,\mu(f). \]
Thus \(f\) and \(w\) strictly prefer each other in the auxiliary two-sided problem, contradicting stability of \(\mu\).

No triple blocks. This proof requires no restriction on technique preferences.

4. Running time and encoding

Scanning the explicit rankings builds comparison tables using \(O(k^3)\) entries. The induced orders can be obtained by scanning each firm’s ranking and retaining its \(k\) designated pairs. Deferred acceptance uses at most \(k^2\) proposals.

The output has \(k^3\) entries if written densely, or \(k\) nonzero entries if written sparsely. Each nonzero value \(1/k\) has a rational encoding of \(O(\log(k+1))\) bits. Thus both construction time and output bit length are polynomial in \(L\) and \(k\), and hence polynomial in \(m,\tau,L,k\), where \(m=k\) and \(\tau=3k\).
