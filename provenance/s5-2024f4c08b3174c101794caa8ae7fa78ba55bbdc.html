Let \(C\) be a nonempty candidate set with \(m=|C|\). Types are strict complete rankings of \(C\); use Borda with the scoring convention \((m,m-1,\ldots,1)\).
A society is given by its support: a list of \(\tau\) distinct types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length.
The required output consists of the exact scores \(\mathrm{sc}_{\mu}(c)=\sum_t\mu_t s(t,c)\) for every \(c\in C\) and the set \(\operatorname{argmax}_{c\in C}\mathrm{sc}_{\mu}(c)\), including every tied maximizer.

Conclusion

The required score-and-winner computation is polynomial-time solvable in \(m,\tau,L\). Exact rational arithmetic suffices, and its intermediate integers have polynomially bounded bit length.

Exact algorithm

Write each supplied mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive binary-encoded integers. The fractions need not be reduced.

For candidate \(c\), let \(r_t(c)\in\{1,\ldots,m\}\) be its position in type \(t\), with position \(1\) best. Under the specified Borda convention,
\(s(t,c)=m+1-r_t(c)\).
Each explicit ranking therefore determines all its scores in time polynomial in its encoding length.

Construct a common denominator and integer weights:
\(D=\prod_{t=1}^{\tau}q_t\) and \(W_t=p_t(D/q_t)\).
Every division \(D/q_t\) is exact. Moreover,
\(W_t/D=\mu_t\), so the normalization hypothesis gives \(\sum_{t=1}^{\tau}W_t=D\).

For every candidate, compute the integer
\(N_c=\sum_{t=1}^{\tau}W_t\bigl(m+1-r_t(c)\bigr)\).
Then
\(\mathrm{sc}_{\mu}(c)=N_c/D\)
exactly.

Finally, compute \(M=\max_{c\in C}N_c\) and output every candidate satisfying \(N_c=M\). Because all scores have the same positive denominator, this returns precisely \(\operatorname{argmax}_{c\in C}\mathrm{sc}_{\mu}(c)\), including all ties. The maximum exists because \(C\) is finite and nonempty.

Bit complexity

The main issue is that arithmetic must be polynomial in the binary input length, rather than merely use polynomially many arithmetic operations.

Since all denominator encodings are part of the input,
\(\log_2 D=\sum_{t=1}^{\tau}\log_2 q_t\leq L\).
Thus \(D\) has at most \(L+1\) bits.

Positivity and normalization imply \(0<\mu_t\leq1\), hence \(0<W_t\leq D\). Also, every Borda score lies between \(1\) and \(m\). Therefore
\(D=\sum_tW_t\leq N_c\leq m\sum_tW_t=mD\).

Every summand and every partial sum used to compute \(N_c\) is nonnegative and at most \(mD\). Consequently, all integers used by the algorithm have at most
\(B=L+\lceil\log_2(m+1)\rceil+2\)
bits. Partial products used to construct \(D\) are also bounded by \(D\), since each \(q_t\) is a positive integer.

Schoolbook multiplication and long division on integers of at most \(B\) bits take \(O(B^2)\) bit operations. Constructing the common denominator and weights uses \(O(\tau)\) such operations; computing all score numerators uses \(O(\tau m)\) operations. Comparing the numerators takes \(O(mB)\) bit operations. Thus, apart from input parsing, the computation takes \(O(\tau mB^2)\) bit operations.

The fractions \(N_c/D\) already specify exact scores. If reduced fractions are required, compute \(g_c=\gcd(N_c,D)\) and output \((N_c/g_c)/(D/g_c)\). The Euclidean algorithm uses \(O(B)\) divisions: within every two remainder steps, the positive remainder decreases by at least a factor of two. Hence reduction costs at most \(O(B^3)\) per candidate using schoolbook arithmetic. The total bound remains polynomial, namely \(O(L+\tau mB^2+mB^3)\), with polynomial output length.

Role of the discrete anchor

This proof uses only the explicitly listed rankings and rational masses. Cancellation of encryption masks is unnecessary for this computation and provides no complexity premise for it. The polynomial-time classification follows independently from the exact algorithm and bit bounds above.
