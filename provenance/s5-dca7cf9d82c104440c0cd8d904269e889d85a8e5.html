Theorem (2) — class: algorithmic

The continuous mirror question, as graded

Given a finite type set \(U\) with support size \(\tau\), facilities \(V\), resources \(N\), type data \(w_u,b_u\), distance \(d\), and fairness parameter \(\gamma\), suppose each period \(t\) reveals a mass profile \(\nu_t\) with \(\sum_{u\in U}\nu_{t,u}=S\), drawn i.i.d. from an unknown law \(G\). A causal policy chooses \(x_{t,u}\in\mathbb{R}_{\ge 0}^{V}\) for each type in the profile, with \(\mathbf{1}^{\top}x_{t,u}\le 1\); it must satisfy \(d(u,u')\ge\gamma(w_u^\top x_{t,u}-w_{u'}^\top x_{t,u'})\) for present types and \(\sum_{t,u}\nu_{t,u}b_u^\top x_{t,u}\le TS\rho\). Is there a policy with expected regret \(O(\sqrt{T})\) against the clairvoyant fair fluid optimum for the realized profiles, and what runtime bound can be achieved in \(\tau, |V|, N\), and the input bit length?

Packaged proof task (what the prover saw — nothing else)

Given nonempty finite type and facility sets \(U,V\), let \(m=|V|\), and let \(N,T\) be positive integers. Type data are binary rationals \(w_u\in(0,1]^V\) and nonnegative integer matrices \(b_u\in\mathbb Z_{\ge0}^{V\times N}\); \(\gamma,S>0\) and \(\rho\in\mathbb Q_{>0}^N\) are binary rationals, with global capacity \(TS\rho\).
The binary-rational distance table \(d\) is symmetric, nonnegative, zero on the diagonal, satisfies the triangle inequality and \(d(u,u')\ge\|w_u-w_{u'}\|_\infty\), and satisfies \(d(u,u')\ge\underline d>0\) whenever \(b_u\ne b_{u'}\). Write \(\overline b=\max_{u,v,k}(b_u)_{vk}\) and assume \(0<\underline\rho\le\rho_k\le\overline\rho\).
Each period reveals a profile \(\nu_t\in\mathbb Q_{\ge0}^U\) of total mass \(S\), drawn independently from an arbitrary unknown common law \(G\). A society is given by its support: the list of types with positive mass, each mass encoded as a binary rational; \(\tau\) bounds these support sizes, rather than counting all possible types. Let \(L\) be the maximum bit length of the static input together with one revealed profile.
A causal policy irrevocably chooses \(x_{t,u}\in\mathbb R_{\ge0}^V\) for each present type, with \(\mathbf1^\top x_{t,u}\le1\). For every ordered pair of present types it must satisfy \(\gamma(w_u^\top x_{t,u}-w_{u'}^\top x_{t,u'})\le d(u,u')\), and its actual mass allocations must satisfy \(\sum_{t,u}\nu_{t,u}b_u^\top x_{t,u}\le TS\rho\) componentwise on every realization.
Let \(\mathrm{OPT}(\nu_{1:T})\) maximize \(\sum_{t,u}\nu_{t,u}w_u^\top x_{t,u}\) over these same constraints with all profiles known in advance. Expected regret is \(\mathbb E_{G,A}[\mathrm{OPT}(\nu_{1:T})-\sum_{t,u}\nu_{t,u}w_u^\top x_{t,u}]\). The quantities \(S,\overline b,\underline\rho,\overline\rho\) remain fixed as \(T\) grows; the regret constant must be independent of \(G\) and \(T\).

Can this continuous online allocation problem achieve \(O(\sqrt T)\) expected regret uniformly over \(G\) with polynomial computation per period in \(m,\tau,N,L,\log T\), or is attaining this guarantee NP-hard? What runtime dependence on the remaining input parameters can be achieved?

For finite batches of constant size, an online fair allocation algorithm has a stated \(O(\sqrt T)\) expected-regret bound against the offline fair fluid benchmark ([finite-batch result](https://arxiv.org/html/2606.18679v1)).
For general stochastic allocation with concave rewards, bounded resource consumption, and unknown i.i.d. requests, \(O(\sqrt T)\) regret against hindsight optimization is known; that result does not explicitly formulate the mass-profile fairness problem above ([general allocation result](https://proceedings.mlr.press/v119/balseiro20a/balseiro20a.pdf)).

Modeling choices made when packaging the task

  • Restored strictly positive weights bounded by one, nonnegative integer resource consumption, positive resource rates, and all stated distance assumptions.
  • Used positive rational total batch mass S and rational global capacity TS rho; S replaces constant discrete batch size and masses are not normalized to one.
  • Interpreted tau as a bound on the support size of a revealed society; absent types generate no allocation variables or fairness constraints.
  • Required fairness for every ordered pair of present types and interpreted x as the actual divisible mass allocation, with resource feasibility on every realization.
  • Defined the clairvoyant benchmark and regret using the mass-weighted welfare objective and exactly the policy's allocation, fairness, and resource constraints.
  • Allowed an arbitrary unknown i.i.d. law over rational profiles, defined L using the static input and a revealed profile, and required the regret bound to hold uniformly over that law.
  • Fixed the batch mass, consumption bound, and resource-rate bounds as the horizon grows, and measured polynomial runtime per period.

Result

The guarantee is achievable in polynomial time. There is a deterministic causal policy with polynomial computation per period in \(m,\tau,N,L,\log T\), satisfying fairness and capacity constraints on every realization, and achieving the following distribution-uniform bound.

Define
\(C=\max_{u,v,k}(b_u)_{vk}/\rho_k\) and \(M=\max\{1,C\}\). Then
\[ \]
For clarity, writing the bound using inline delimiters,
\(\displaystyle \mathbb E[\mathrm{OPT}-\mathrm{ALG}]\le S\left(\frac32 M\sqrt{NT}+M+2C+3\right).\)

In particular, \(C\le\overline b/\underline\rho\), so this is \(O(\sqrt T)\) with a constant independent of \(G\) and \(T\).

Runtime depends on \(\gamma,S,\overline b,\rho\), and the distance data only through their binary encoding lengths. It requires no numerical factor involving \(\gamma\), \(1/\underline d\), or \(1/\underline\rho\), and no enumeration of possible societies.

The approach is related to the dual-price method in [Balseiro, Lu, and Mirrokni](https://proceedings.mlr.press/v119/balseiro20a/balseiro20a.pdf). Their stated assumptions include finite distributional support. The proof below directly handles arbitrary laws on the rational profiles in the question, and includes the bit-complexity argument.

1. A profile is one linear allocation request

For a revealed profile \(\nu\), let \(P(\nu)=\{u:\nu_u>0\}\), and define \(p_u=\nu_u/S\). Thus \(\sum_{u\in P(\nu)}p_u=1\).

Let \(X(\nu)\) consist of the allocations satisfying all the question’s within-period constraints:

  • \(x_u\ge0\) and \(\mathbf1^\top x_u\le1\) for every \(u\in P(\nu)\);
  • \(\gamma(w_u^\top x_u-w_{u'}^\top x_{u'})\le d(u,u')\) for every ordered pair in \(P(\nu)\).

This is a nonempty compact rational polytope: it contains zero, is closed, and lies in a product of simplices. It has at most \(m\tau\) variables and \(O(m\tau+\tau^2)\) constraints.

Define normalized reward and resource consumption by
\(\displaystyle r_\nu(x)=\sum_{u\in P(\nu)}p_u w_u^\top x_u\)
and
\(\displaystyle a_{\nu,k}(x)=\sum_{u\in P(\nu)}p_u\frac{(b_u^\top x_u)_k}{\rho_k}.\)

For every \(x\in X(\nu)\),
\(0\le r_\nu(x)\le1\) and \(0\le a_{\nu,k}(x)\le C\).
Indeed, each type’s reward is at most one, and its normalized resource consumption is at most \(C\); averaging preserves these bounds.

The original capacity constraints are exactly
\(\sum_{t=1}^T a_{\nu_t,k}(x_t)\le T\) for every \(k\).
Original rewards are \(S\) times normalized rewards.

2. The policy, including finite-precision accounting

Set
\(q=\lceil\sqrt{NT}\rceil\), \(\eta=1/(Mq)\), and \(\delta=\eta/T\).

Initialize prices \(\mu_1=0\), and an upper consumption ledger \(Q_0=0\). The ledger has one coordinate per resource.

Before period \(t\), check whether
\(T-Q_{t-1,k}\ge C+1/T\) for every \(k\).

If this fails, allocate zero in this and every subsequent period. Otherwise, after observing \(\nu_t\):

  • Solve the rational linear program

\(\displaystyle x_t\in\arg\max_{x\in X(\nu_t)}\{r_{\nu_t}(x)-\mu_t^\top a_{\nu_t}(x)\}.\)
Fix a deterministic rule for selecting an optimal rational vertex.

  • Write \(a_t=a_{\nu_t}(x_t)\), and update the ledger using

\(\widehat a_{t,k}=\lceil T a_{t,k}\rceil/T\) and
\(Q_{t,k}=Q_{t-1,k}+\widehat a_{t,k}\).

  • Update each price by downward rounding:

\(\displaystyle \mu_{t+1,k}=\delta\left\lfloor\frac{\max\{0,\mu_{t,k}+\eta(a_{t,k}-1)\}}{\delta}\right\rfloor.\)

Let \(H\) be the number of periods processed before permanent stopping. Thus the active periods form the prefix \(1,\ldots,H\).

This policy uses no knowledge of \(G\).

3. Pathwise feasibility and price bounds

Feasibility

Every active allocation belongs to \(X(\nu_t)\); zero also belongs to that polytope. Hence fairness holds in every period.

Moreover,
\(a_{t,k}\le\widehat a_{t,k}\le C+1/T\).
The pre-period check therefore ensures that the updated ledger never exceeds \(T\). Since it upper-bounds actual cumulative consumption, all global resource constraints hold on every realization.

Prices remain bounded

Optimality against the feasible zero allocation gives
\(r_{\nu_t}(x_t)-\mu_t^\top a_t\ge0\).
Consequently,
\(0\le\mu_t^\top a_t\le r_{\nu_t}(x_t)\le1\).

If \(\mu_{t,k}\ge1\), then \(a_{t,k}\le1/\mu_{t,k}\le1\), so that coordinate cannot increase during the price update. If \(\mu_{t,k}<1\), its updated value is at most \(1+\eta C\). Downward rounding cannot increase it.

Induction yields
\(0\le\mu_{t,k}\le1+\eta C\le2\)
throughout the active prefix.

Stopping leaves only a bounded tail

The rounding rule implies
\(\mu_{t+1,k}\ge\mu_{t,k}+\eta(a_{t,k}-1)-\delta\).
Summing and using \(\mu_{1,k}=0\) gives
\(\displaystyle \sum_{t=1}^H a_{t,k}\le H+\frac{\mu_{H+1,k}}{\eta}+\frac{H\delta}{\eta}\le H+\frac{\mu_{H+1,k}}{\eta}+1.\)

Upward ledger rounding adds at most \(H/T\le1\), so
\(\displaystyle Q_{H,k}\le H+\frac{\mu_{H+1,k}}{\eta}+2.\)

If \(H<T\), stopping means that some coordinate satisfies
\(Q_{H,k}>T-C-1/T\).
Combining these inequalities with the price bound gives
\(\displaystyle T-H< C+\frac1T+\frac{1+\eta C}{\eta}+2\le\frac1\eta+2C+3.\)

For \(H=T\), the same upper bound is automatic. Therefore, on every realization,
\(\displaystyle T-H\le\frac1\eta+2C+3.\)

4. A dual upper bound for the hindsight optimum

For a profile \(\nu\) and nonnegative price vector \(\mu\), define
\(\displaystyle h_\nu(\mu)=\max_{x\in X(\nu)}\{r_\nu(x)-\mu^\top a_\nu(x)\}.\)

Because zero is feasible and reward is at most one,
\(0\le h_\nu(\mu)\le1\).

Define
\(\mathcal D(\mu)=\mathbb E_G[h_\nu(\mu)]+\mu^\top\mathbf1\)
and
\(d_*=\inf_{\mu\ge0}\mathcal D(\mu)\).
These definitions require no finite-support assumption. Also \(0\le d_*\le1\), by evaluating at \(\mu=0\).

For any feasible hindsight allocation and any fixed \(\mu\ge0\),
\(\displaystyle \sum_{t=1}^T r_{\nu_t}(x_t)\le\sum_{t=1}^T h_{\nu_t}(\mu)+T\mu^\top\mathbf1.\)

This follows by applying the definition of \(h_{\nu_t}\) period by period, then using the normalized capacity constraints. Taking expectations and then the infimum over \(\mu\) proves
\(\displaystyle \mathbb E[\mathrm{OPT}]/S\le Td_*.\)

Only weak duality is used here.

5. Expected reward of the policy

For active periods, put \(g_t=\mathbf1-a_t\). Exact optimization gives
\(\displaystyle r_{\nu_t}(x_t)=h_{\nu_t}(\mu_t)+\mu_t^\top\mathbf1-\mu_t^\top g_t.\)

A pathwise price inequality

Let \(z_t=\max\{0,\mu_t-\eta g_t\}\), componentwise. Projection onto the nonnegative orthant cannot increase Euclidean distance from zero, and downward rounding decreases each nonnegative coordinate. Therefore
\(\displaystyle \|\mu_{t+1}\|_2^2\le\|z_t\|_2^2\le\|\mu_t-\eta g_t\|_2^2.\)

Expanding and rearranging,
\(\displaystyle \mu_t^\top g_t\le\frac{\|\mu_t\|_2^2-\|\mu_{t+1}\|_2^2}{2\eta}+\frac\eta2\|g_t\|_2^2.\)

Since \(a_{t,k}\in[0,C]\), we have \(|g_{t,k}|\le M\). Telescoping over the active prefix, with initial price zero, yields
\(\displaystyle \sum_{t=1}^H\mu_t^\top g_t\le\frac\eta2 NM^2H\le\frac\eta2 NM^2T.\)

Thus downward rounding introduces no additional term in this particular inequality.

Using independence at active periods

Let \(I_t\) indicate whether period \(t\) is active. Both \(I_t\) and \(\mu_t\) are determined before \(\nu_t\) arrives. Independence of the profiles therefore gives
\(\displaystyle \mathbb E[I_t(h_{\nu_t}(\mu_t)+\mu_t^\top\mathbf1)]=\mathbb E[I_t\mathcal D(\mu_t)]\ge d_*\mathbb E[I_t].\)

All quantities are integrable: \(h_\nu\le1\), and prices are bounded by two. Rational profiles form a countable set, so the deterministic selection rule also presents no measurability difficulty.

Summing the reward identity and applying the pathwise inequality proves
\(\displaystyle \mathbb E[\mathrm{ALG}]/S\ge d_*\mathbb E[H]-\frac\eta2 NM^2T.\)

Together with the hindsight upper bound and \(d_*\le1\), this gives
\(\displaystyle \mathbb E[\mathrm{OPT}-\mathrm{ALG}]/S\le\frac1\eta+2C+3+\frac\eta2 NM^2T.\)

Finally, substituting \(\eta=1/(Mq)\), and using
\(\sqrt{NT}\le q\le\sqrt{NT}+1\), gives
\(\displaystyle \mathbb E[\mathrm{OPT}-\mathrm{ALG}]\le S\left(\frac32 M\sqrt{NT}+M+2C+3\right).\)

This completes the regret proof for every admissible \(G\).

6. Polynomial bit complexity and parameter dependence

The construction avoids accumulating arbitrary rational denominators across periods:

  • Every price is an integer multiple of \(\delta=1/(MqT)\), and lies in \([0,2]\). Its encoding length is polynomial in \(L,\log N,\log T\).
  • Every ledger coordinate is an integer multiple of \(1/T\), and lies in \([0,T]\). Its encoding length is \(O(\log T)\).
  • The current LP has at most \(m\tau\) variables and \(O(m\tau+\tau^2)\) constraints. Its coefficients have encoding lengths polynomial in \(m,\tau,N,L,\log T\).

The standard polynomial-time theorem for rational linear programming applies: the LP is explicitly represented, nonempty, bounded, and has a rational objective. An exact rational optimal vertex can be returned in polynomial bit complexity. Its polynomial output size also follows from the determinant bounds for basic solutions.

Consequently, forming the resource consumptions, taking the required ceilings and floors, and updating the stored state all take polynomial time. Static preprocessing, including computing \(C\), is polynomial in the explicit static input length.

The metric assumptions beyond nonnegativity of \(d\) are unnecessary for this argument. Fairness is imposed directly inside the per-profile LP. Accordingly, neither computation nor the displayed regret bound needs a numerical dependence on \(\gamma\), \(\underline d\), or the number of possible profiles.
