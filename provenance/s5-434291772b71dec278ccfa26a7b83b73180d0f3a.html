The continuous mirror question, as graded

Given \(m\) item classes, rational per-agent supplies \(q_j\in[0,1]\), three additive valuation types \(R,C,U\) each of mass \(1/3\), and exact high-multiplicity MMS benchmarks \(\sigma_R(q),\sigma_C(q)\), find a mass assignment \(x_{t,B}\ge0\) over integral bundles \(B\subseteq[m]\) maximizing \(r\), subject to \(\sum_Bx_{t,B}=1/3\), \(\sum_t\sum_{B\ni j}x_{t,B}=q_j\), \(x_{R,B}=0\) when \(v_R(B)<r\sigma_R(q)\), \(x_{C,B}=0\) when \(v_C(B)<r\sigma_C(q)\), and \(x_{U,B}=0\) when \(v_U(B)<\pi_U(q)\), where \(\pi_U(q)=\sum_jq_jv_U(j)\) and \(\sigma_t(q)=\max_{p\in\mathcal P(q)}\min_{B:p_B>0}v_t(B)\) for \(\mathcal P(q)=\{p\ge0:\sum_Bp_B=1,\sum_{B\ni j}p_B=q_j\}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here the three designated types \(R,C,U\) each have mass \(1/3\), so total mass is \(1\) and \(\tau=3\).
There are \(m\ge1\) item classes, binary rational supplies \(q_j\in[0,1]\) per unit of society mass, and additive valuations with binary rational values \(v_t(j)\ge0\). A bundle \(B\subseteq[m]\), possibly empty, contains at most one item of each class.
Define \(\mathcal P(q)=\{p\ge0:\sum_{B\subseteq[m]}p_B=1,\ \sum_{B\ni j}p_B=q_j\text{ for every }j\}\) and \(\sigma_t(q)=\max_{p\in\mathcal P(q)}\min_{B:p_B>0}v_t(B)\).
The exact values \(\sigma_R(q),\sigma_C(q)\) are supplied as binary rationals, promised correct; computing them is outside the problem. Set \(\pi_U(q)=\sum_{j=1}^m q_jv_U(j)\).
For \(r\ge0\), a feasible mass assignment has \(x_{t,B}\ge0\), \(\sum_Bx_{t,B}=1/3\) for every type, and \(\sum_t\sum_{B\ni j}x_{t,B}=q_j\) for every class.
Every positive \(x_{R,B}\) requires \(v_R(B)\ge r\sigma_R(q)\), every positive \(x_{C,B}\) requires \(v_C(B)\ge r\sigma_C(q)\), and every positive \(x_{U,B}\) requires \(v_U(B)\ge\pi_U(q)\). Equality is permitted; guarantees apply to each assigned bundle.
The optimization objective is to maximize \(r\). Its threshold decision problem additionally receives a binary rational \(r_0\ge0\) and asks whether an assignment is feasible at \(r=r_0\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is this threshold decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard, even with the exact benchmarks supplied?

For three discrete agents with additive goods valuations, an allocation giving designated \(U\) her full proportional share and \(R,C\) at least \(11/12\) of their MMS can be found in polynomial time given their MMS partitions; the universal ratio is tight. [Feige–Norkin](https://arxiv.org/pdf/2205.05363)

Result

The threshold decision problem is \(\mathrm{NP}\)-hard, even with \(\tau=3\), \(r_0=1\), and supplied exact benchmarks fixed at \(\sigma_R(q)=1\) and \(\sigma_C(q)=2\).

The proof is a polynomial-time reduction from PARTITION. Fractional assignments cannot evade the reduction because supply conservation forces certain positive-mass bundles to have exactly the partition target value.

1. Construction

We use the standard \(\mathrm{NP}\)-complete PARTITION problem: given positive binary-encoded integers \(a_1,\ldots,a_n\), decide whether some \(A\subseteq[n]\) satisfies

\(\displaystyle \sum_{i\in A}a_i=\frac12\sum_{i=1}^n a_i.\)

Its \(\mathrm{NP}\)-completeness is established in [Karp’s original paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Set \(T=\frac12\sum_{i=1}^n a_i>0\). Construct \(m=n+2\) classes: the original classes \(1,\ldots,n\), a high-value class \(h\), and an auxiliary class \(g\). Their supplies and valuations are:

| Class | Supply | \(v_R\) | \(v_C\) | \(v_U\) |
|---|---:|---:|---:|---:|
| \(i\in[n]\) | \(1/12\) | \(0\) | \(0\) | \(a_i\) |
| \(h\) | \(1/6\) | \(0\) | \(0\) | \(5T\) |
| \(g\) | \(1\) | \(1\) | \(2\) | \(0\) |

Each of \(R,C,U\) has mass \(1/3\). Supply the benchmarks \(1,2\), and set \(r_0=1\).

All supplies lie in \([0,1]\), all valuations are nonnegative binary rationals, and the three valuation types are distinct. The construction takes polynomial time and has polynomial output bit length.

2. The supplied benchmarks are exactly correct

First, \(\mathcal P(q)\) is nonempty: independently including each class with probability \(q_j\) gives a distribution with the required marginals.

For every \(p\in\mathcal P(q)\), the marginal constraint for \(g\) gives

\(\displaystyle \sum_{B\ni g}p_B=q_g=1=\sum_Bp_B.\)

Nonnegativity therefore implies that every positive-probability bundle contains \(g\). Since \(R\) values only \(g\), every such bundle has \(R\)-value exactly \(1\). Similarly, every such bundle has \(C\)-value exactly \(2\). Consequently,

\(\displaystyle \sigma_R(q)=1,\qquad \sigma_C(q)=2.\)

Thus the benchmark promise holds for every constructed instance, independently of whether its source instance admits a partition.

The proportional benchmark for \(U\) is

\(\displaystyle \pi_U(q) =\frac1{12}\sum_{i=1}^n a_i+\frac16(5T) =\frac{2T}{12}+\frac{5T}{6} =T. \)

3. A partition gives a feasible assignment

Suppose \(A\subseteq[n]\) satisfies \(\sum_{i\in A}a_i=T\). Its complement also has value \(T\).

Assign the following bundles; all unlisted assignment variables are zero:

| Type | Bundle | Assigned mass |
|---|---|---:|
| \(R\) | \(\{g\}\) | \(1/3\) |
| \(C\) | \(\{g\}\) | \(1/3\) |
| \(U\) | \(A\cup\{g\}\) | \(1/12\) |
| \(U\) | \(([n]\setminus A)\cup\{g\}\) | \(1/12\) |
| \(U\) | \(\{h,g\}\) | \(1/6\) |

Type \(U\)'s assigned mass is \(1/12+1/12+1/6=1/3\). Every original class is assigned mass \(1/12\), class \(h\) is assigned mass \(1/6\), and class \(g\) is assigned total mass \(1\).

The \(R,C\) bundles attain their required values \(1,2\). The three \(U\)-bundles have values \(T,T,5T\), respectively, and hence satisfy the guarantee \(v_U(B)\ge\pi_U(q)=T\). The assignment is feasible at \(r_0=1\).

4. Every feasible assignment yields a partition

Conversely, suppose a feasible mass assignment exists. Let

\(\displaystyle z=\sum_{B:h\notin B}x_{U,B}\)

be the mass of type \(U\) receiving bundles without \(h\).

The supply of \(h\) bounds the mass of \(U\) receiving \(h\):

\(\displaystyle \sum_{B:h\in B}x_{U,B} \le\sum_t\sum_{B:h\in B}x_{t,B} =q_h=\frac16. \)

Because \(U\)'s total mass is \(1/3\), it follows that \(z\ge1/6\).

Define the total original-class value assigned to those \(U\)-bundles without \(h\) by

\(\displaystyle W=\sum_{B:h\notin B}x_{U,B}\sum_{i\in B\cap[n]}a_i. \)

For every positive-mass bundle in this sum, \(g\) contributes zero value and \(h\) is absent. The \(U\)-guarantee therefore requires \(\sum_{i\in B\cap[n]}a_i\ge T\), giving \(W\ge Tz\).

On the other hand, nonnegativity and the original-class supply constraints give

\(\displaystyle W \le\sum_{i=1}^n a_i\sum_t\sum_{B\ni i}x_{t,B} =\sum_{i=1}^n a_iq_i =\frac{2T}{12} =\frac T6. \)

Combining these inequalities yields

\(\displaystyle \frac T6\le Tz\le W\le\frac T6.\)

Every inequality is therefore an equality. In particular, \(z=1/6>0\) and

\(\displaystyle \sum_{B:h\notin B}x_{U,B} \left(\sum_{i\in B\cap[n]}a_i-T\right) =W-Tz=0. \)

Every summand is nonnegative. Hence every positive-mass \(U\)-bundle without \(h\) has original-class value exactly \(T\). At least one such bundle exists because \(z>0\). Its original-class subset solves PARTITION.

This establishes both directions of the reduction, including soundness for arbitrary fractional assignments.

5. Certificates and running times

For a general threshold instance, retain only bundles satisfying their type’s guarantee. Feasibility is then a linear system with nonnegative variables, at most \(\tau2^m\) columns, and \(d=m+\tau\) equality constraints. Each column records one type indicator and the bundle’s class indicators, so its entries belong to \(\{0,1\}\).

Every feasible instance has a certificate using at most \(d\) positive variables. To see this, choose a feasible assignment with minimum support. If its supported columns were linearly dependent, a nonzero dependence would preserve every equality. The type-mass rows imply that its coefficients sum to zero, so it has both positive and negative coefficients. Moving along this dependence until a coordinate first becomes zero preserves nonnegativity and reduces support, a contradiction.

For the resulting linearly independent supported columns, select an invertible square subsystem. Clearing the right-hand-side denominators and applying Cramer’s rule shows that each positive weight has bit length

\(\displaystyle O\!\left(L+d\log(d+1)\right).\)

Indeed, the common denominator has bit length \(O(L)\), and Hadamard’s inequality bounds the relevant determinants by that denominator times \(d^{d/2}\).

Thus a certificate consists of at most \(m+\tau\) bundles, their types, and polynomial-size rational weights. All supplies, masses, and guarantees can be checked by exact arithmetic in \(\operatorname{poly}(m,\tau,L)\) time. Benchmark correctness remains the stipulated promise.

Enumerating all bundles and solving the resulting explicit rational linear program gives a deterministic running time of

\(\displaystyle 2^{O(m)}\operatorname{poly}(m,\tau,L).\)

The reduction proves that a running time polynomial in \(m,\tau,L\) is impossible unless \(\mathrm P=\mathrm{NP}\), already when \(\tau=3\) and both exact positive benchmarks are supplied.
