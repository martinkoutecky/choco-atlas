The continuous mirror question, as graded

Given candidates \(C\), finite ranking-type support \(T\subseteq\mathcal L(C)\) with rational masses \(\mu_t\ge0\) summing to \(1\), a despised candidate \(w\in C\), and \(k\in\mathbb N\), does there exist \(D\subseteq C\setminus\{w\}\) with \(|D|\le k\) such that \(w\) is not a Schulze winner on \(A=C\setminus D\), where \(d_{\mu,A}(a,b)=\sum_{t\in T}\mu_t(\mathbf 1[a\succ_t b]-\mathbf 1[b\succ_t a])\) and Schulze strengths are computed from these margins?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set with \(m=|C|\), let \(w\in C\), and let \(k\in\mathbb Z_{\ge0}\).
A society is given by its support: a list \(T\) of \(\tau\) distinct strict linear orders on \(C\), each with a positive binary-rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total binary input length.
For a retained set \(A\subseteq C\), restrict every ranking to \(A\) without changing its mass, and define \(d_{\mu,A}(a,b)=\sum_{t\in T}\mu_t(\mathbf1[a\succ_t b]-\mathbf1[b\succ_t a])\) for distinct \(a,b\in A\).
Use the complete directed graph on \(A\) with these signed margins as edge weights, including zero and negative weights. Define \(P_A(a,b)=\max_{p:a\leadsto b}\min_{(x,y)\in p}d_{\mu,A}(x,y)\), where the maximum ranges over simple directed paths.
A candidate \(a\in A\) is a Schulze winner exactly when \(P_A(a,b)\ge P_A(b,a)\) for every \(b\in A\setminus\{a\}\). All such candidates win; no tie-breaking is applied, and a sole candidate wins.
Is deciding whether there exists \(D\subseteq C\setminus\{w\}\) with \(|D|\le k\) such that \(w\) is not a Schulze winner on \(C\setminus D\) in \(\mathrm P\) or \(\mathrm{NP}\)-hard, with running times measured in \(m,\tau,L,k\)?
For explicit finite lists of unweighted voters with strict rankings, destructive control by deleting at most \(k\) candidates is polynomial-time solvable in the nonunique-winner model, where success means excluding the despised candidate from the winner set (Maushagen et al., 2024).

Result

The problem is in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), including when \(k\) is encoded in binary.

The proof constructs a polynomial-size unweighted election whose Schulze winner set agrees with the given society on every retained candidate set. The stated finite-voter theorem then applies.

1. Candidate deletion preserves pairwise margins

Write \(d(a,b)=d_{\mu,C}(a,b)\). For every retained set \(A\subseteq C\) and distinct \(a,b\in A\), restricting a strict ranking does not change whether it places \(a\) above \(b\). The masses also remain unchanged. Therefore,

\[ d_{\mu,A}(a,b)=d(a,b). \]

Furthermore, \(d(b,a)=-d(a,b)\). Thus every retained election uses the corresponding submatrix of one fixed antisymmetric margin matrix.

If \(m=1\), the answer is NO because \(w\) always remains the sole candidate. Henceforth suppose \(m\ge2\).

2. An order-preserving compression of the margins

Let \(h=\binom m2\), and list the distinct positive margin values as

\[ 0<s_1<s_2<\cdots<s_q. \]

Antisymmetry implies that every nonzero margin belongs to \(\{\pm s_1,\ldots,\pm s_q\}\), and \(q\le h\).

Define \(f\) on these values and zero by

\[ f(0)=0,\qquad f(s_i)=2i,\qquad f(-s_i)=-2i. \]

This function is strictly increasing on its domain and satisfies \(f(-x)=-f(x)\). Define the compressed integer margins by

\[ M(a,b)=f(d(a,b)). \]

They are antisymmetric, even integers of absolute value at most \(2q\).

Lemma. For every \(A\subseteq C\) and distinct \(a,b\in A\), let \(P_A^M(a,b)\) denote the strongest-path value using \(M\). Then

\[ P_A^M(a,b)=f(P_A(a,b)). \]

Proof. For every simple directed path \(p\), strict monotonicity gives

\[ \min_{(x,y)\in p}f(d(x,y)) = f\!\left(\min_{(x,y)\in p}d(x,y)\right). \]

There are finitely many simple paths from \(a\) to \(b\), and at least one exists because the graph is complete. Every path strength, and hence their maximum, is a margin value in the domain of \(f\). Taking the maximum over paths therefore gives

\[ \begin{aligned} P_A^M(a,b) &=\max_{p:a\leadsto b} f\!\left(\min_{(x,y)\in p}d(x,y)\right)\\ &=f\!\left(\max_{p:a\leadsto b} \min_{(x,y)\in p}d(x,y)\right) =f(P_A(a,b)). \end{aligned} \]

This proves the lemma.

Because \(f\) is strictly increasing,

\[ P_A(a,b)\ge P_A(b,a) \quad\Longleftrightarrow\quad P_A^M(a,b)\ge P_A^M(b,a). \]

Consequently, compression preserves the entire Schulze winner set on every retained set \(A\). Singleton sets also have identical winner sets by definition.

3. Realizing the compressed margins with polynomially many voters

We now construct an explicit unweighted voter list \(V\) on \(C\) whose pairwise margin matrix is exactly \(M\).

For distinct candidates \(a,b\), choose an ordering \(r_1,\ldots,r_{m-2}\) of the remaining candidates. Consider the two strict rankings

\[ a\succ b\succ r_1\succ\cdots\succ r_{m-2}, \]

\[ r_{m-2}\succ\cdots\succ r_1\succ a\succ b. \]

Together, they contribute margin \(2\) to \(a\) against \(b\) and margin zero to every other unordered pair:

  • Both rankings place \(a\) above \(b\).
  • Each remaining candidate lies below \(a,b\) in the first ranking and above them in the second.
  • Every pair of remaining candidates appears in opposite orders in the two rankings.

For each unordered pair with nonzero compressed margin, orient it as \((a,b)\) so that \(M(a,b)=2i>0\), and add \(i\) copies of this two-voter construction. Contributions add, so the resulting list has precisely the desired margins.

If all margins are zero, use any ranking and its complete reverse. Their margins cancel, yielding a nonempty voter list with the required zero matrix.

The number \(N\) of constructed voters satisfies

\[ N\le 2hq+2\le 2h^2+2=O(m^4). \]

After relabeling candidates by integers, the explicit list occupies \(O(m^5\log(m+1))\) bits.

Deleting candidates from \(V\) preserves the pairwise margins of surviving candidates, just as in Section 1. Hence, for every \(A\subseteq C\), the unweighted election obtained by restricting \(V\) to \(A\) has margin matrix \(M\) restricted to \(A\). Section 2 proves that its winner set equals that of the original society restricted to \(A\).

4. Applying the finite-voter theorem

The supplied result of Maushagen et al. states that, for explicit finite lists of unweighted strict rankings, destructive control by deleting at most a prescribed number of candidates is polynomial-time solvable in the nonunique-winner model.

Its hypotheses match the constructed election. In particular, their definition uses the complete directed margin graph and the same strongest-path winner comparison; negative edges are omitted only from illustrations. Their Theorem 4 gives the required nonunique-winner algorithm. [Maushagen et al., definitions in Section 2 and Theorem 4](https://arxiv.org/html/2405.08956v1).

Their path convention also agrees with the stipulated simple-path convention: removing a cycle from a directed walk cannot decrease its minimum edge weight, so allowing walks cannot increase the maximum beyond what simple paths attain.

Set \(k'=\min\{k,m-1\}\). For every \(D\subseteq C\setminus\{w\}\),

\[ \begin{aligned} &w\text{ is not a winner in the original society on }C\setminus D\\ &\qquad\Longleftrightarrow w\text{ is not a winner in the constructed election on }C\setminus D. \end{aligned} \]

The candidate set, protected candidate \(w\), and deletion cardinalities are unchanged. Applying the finite-voter algorithm to \((C,V,w,k')\) therefore decides exactly the requested question.

5. Bit complexity

All preprocessing uses exact arithmetic of polynomial bit length. Indeed, write each input mass as \(\mu_t=a_t/b_t\), and take

\[ B=\prod_{t\in T}b_t. \]

The bit length of \(B\) is \(O(L)\). Each margin is computed as

\[ d(a,b)=\frac{1}{B} \sum_{t\in T} a_t\frac{B}{b_t} \bigl(\mathbf1[a\succ_t b]-\mathbf1[b\succ_t a]\bigr). \]

Since the masses are positive and sum to one, the absolute value of the integer numerator is at most \(B\). Thus these numerators have \(O(L)\) bits. Computing all margins, sorting the distinct positive values, and assigning their compressed values take polynomial time in \(m,\tau,L\).

The constructed election has polynomial encoding length. If \(p\) bounds the finite-voter algorithm’s running time as a polynomial in its input length, the total running time is bounded by

\[ \operatorname{poly}(m,\tau,L) + p\!\left(O(m^5\log(m+1))\right). \]

Clipping \(k\) to \(m-1\) requires only its encoded length, already included in \(L\). No expansion proportional to the numerical denominators or to \(k\) occurs. This proves polynomial-time solvability in the requested input model.
