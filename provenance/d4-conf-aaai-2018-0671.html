The continuous mirror question, as graded

Given \(C\), \(k\), a committee \(W\subseteq C\) of size \(k\), and approval types \(A_t\subseteq C\) with positive rational masses \(\mu_t\) summing to \(1\), decide whether every \(1\le\ell\le k\) and every submass vector \(0\le\nu_t\le\mu_t\) with \(\sum_t\nu_t\ge\ell/k\) satisfies \(\left|W\cap\bigcup_{t\in Q}A_t\right|\ge\ell\) whenever \(Q=\{t:\nu_t>0\}\) has \(\left|\bigcap_{t\in Q}A_t\right|\ge\ell\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a finite candidate set with \(m=|C|\), let \(k\) be an integer with \(1\le k\le m\), and let \(W\subseteq C\) satisfy \(|W|=k\).
A society is given by its support: a list of \(\tau\) distinct approval types \(A_t\subseteq C\), possibly empty, with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible approval sets. Let \(L\) be the total input bit length; state running times in \(m,\tau,L,k\).
A submass vector has real coordinates \(0\le\nu_t\le\mu_t\), and its participating types are \(Q=\{t:\nu_t>0\}\). The committee satisfies mass-PJR if, for every integer \(1\le\ell\le k\) and every submass vector with \(\sum_t\nu_t\ge\ell/k\), the implication \(\left|\bigcap_{t\in Q}A_t\right|\ge\ell\Rightarrow\left|W\cap\bigcup_{t\in Q}A_t\right|\ge\ell\) holds.

Is detecting a violation of mass-PJR \(\mathrm{NP}\)-hard or in \(\mathrm{P}\), equivalently, is checking mass-PJR \(\mathrm{coNP}\)-hard or in \(\mathrm{P}\)?

For finite unweighted electorates, checking PJR is \(\mathrm{coNP}\)-complete; it is also FPT in the number of voters or candidates. [Verified discrete results](https://ojs.aaai.org/index.php/AAAI/article/download/11478/11337).
No result settling this exact submass formulation was located in the literature search.

  • Specified that the quantified representation level is an integer.
  • Specified real submass coordinates, allowing arbitrary fractions of each type's mass.

Mass-PJR violation detection is \(\mathrm{NP}\)-complete

Checking mass-PJR is \(\mathrm{coNP}\)-complete. The key is that any violating submass vector can be replaced by the full masses of its participating types. This permits an exact reduction from discrete PJR.

Here, rational masses are represented by numerators and denominators encoded in binary.

1. Eliminating the submass quantifier

For a nonempty set of types \(Q\subseteq\{1,\ldots,\tau\}\), define
\(\mu(Q)=\sum_{t\in Q}\mu_t\),
\(I(Q)=\bigcap_{t\in Q}A_t\), and
\(U(Q)=\bigcup_{t\in Q}A_t\).

Lemma. A committee violates mass-PJR if and only if there exist a nonempty \(Q\) and an integer \(1\le\ell\le k\) such that
\(\mu(Q)\ge\ell/k\),
\(|I(Q)|\ge\ell\), and
\(|W\cap U(Q)|<\ell\).

Proof. Suppose a submass vector \(\nu\) witnesses a violation, and let \(Q=\{t:\nu_t>0\}\). Its positive total mass makes \(Q\) nonempty. Because \(\nu_t\le\mu_t\),
\(\mu(Q)\ge\sum_t\nu_t\ge\ell/k\).
The intersection and union conditions are precisely those in the lemma.

Conversely, given such \(Q,\ell\), set \(\nu_t=\mu_t\) for \(t\in Q\) and \(\nu_t=0\) otherwise. Since every listed mass is positive, the participating types are exactly \(Q\), and all three violation conditions hold. \(\square\)

Thus arbitrary real coordinates create no additional difficulty for certificates.

2. Membership in \(\mathrm{NP}\)

A certificate consists of \(Q\), encoded by \(\tau\) bits, and \(\ell\), encoded using \(O(\log(k+1))\) bits. The verifier checks the three conditions in the lemma.

Here is an explicit polynomial bound for exact arithmetic. Write \(\mu_t=a_t/b_t\), and let \(D=\prod_{t=1}^{\tau}b_t\). Since \(L\) includes all denominator encodings, \(D\) has \(O(L)\) bits. Put
\(s_t=a_t(D/b_t)\).
Then the mass inequality is equivalent to the integer comparison
\(k\sum_{t\in Q}s_t\ge\ell D\).

Computing these integers with schoolbook arithmetic takes \(O(\tau L^2)\) bit operations. Their bit lengths are \(O(L)\): each mass is at most one, and their total is one. Using characteristic vectors for approval sets, the intersection and union checks take \(O(\tau m)\) operations. Including input reading, a conservative verification bound is
\(O(L+\tau m+\tau L^2)\).

Therefore violation detection belongs to \(\mathrm{NP}\), and mass-PJR checking belongs to \(\mathrm{coNP}\).

3. Polynomial reduction from discrete PJR

We use the established theorem that checking PJR for an explicitly listed, finite unweighted electorate and a specified size-\(k\) committee is \(\mathrm{coNP}\)-complete. Its definition uses exactly the conditions
\(|V|\ge\ell n/k\),
\(\left|\bigcap_{i\in V}B_i\right|\ge\ell\), and
\(\left|W\cap\bigcup_{i\in V}B_i\right|<\ell\)
for a violating voter group \(V\). Consequently, detecting a discrete PJR violation is \(\mathrm{NP}\)-complete. See [Aziz et al., Theorem 3](https://ojs.aaai.org/index.php/AAAI/article/download/11478/11337).

Take such an instance with voters \(\{1,\ldots,n\}\), ballots \(B_i\subseteq C\), and committee \(W\). Partition the voters according to identical ballots. Let the distinct ballots be \(A_1,\ldots,A_\tau\), and let
\(n_t=|\{i:B_i=A_t\}|\).

Construct the mass instance by retaining \(C,k,W\) and assigning
\(\mu_t=n_t/n\).

This satisfies every required input condition: the types are distinct, their masses are positive binary-encoded rationals, and
\(\sum_t\mu_t=1\).
Moreover, \(m,k\) are unchanged, \(\tau\le n\), and the output length is
\(O(\tau m+\tau\log(n+1)+m)\).
Grouping explicitly listed ballots and counting their multiplicities takes polynomial time in the source input length. No enumeration of all possible approval sets is needed.

We prove preservation of violations in both directions.

Discrete violation implies mass violation

Suppose \(V\) witnesses a discrete violation at level \(\ell\). Let
\(Q=\{t:\text{some voter in }V\text{ has ballot }A_t\}\).

Every voter in \(V\) belongs to a type in \(Q\), so
\(\mu(Q)=\sum_{t\in Q}n_t/n\ge |V|/n\ge\ell/k\).

Every type in \(Q\) occurs in \(V\), and every ballot occurring in \(V\) is a type in \(Q\). Repetition of an identical set changes neither intersection nor union. Hence
\(I(Q)=\bigcap_{i\in V}B_i\) and
\(U(Q)=\bigcup_{i\in V}B_i\).

The lemma therefore gives a mass-PJR violation.

Mass violation implies discrete violation

Suppose the constructed mass instance violates mass-PJR. By the lemma, take witnessing \(Q,\ell\). Let \(V_Q\) contain all voters whose types lie in \(Q\).

Then
\(|V_Q|=n\mu(Q)\ge\ell n/k\).

Each type has positive multiplicity, so every type in \(Q\) occurs in \(V_Q\). Again,
\(\bigcap_{i\in V_Q}B_i=I(Q)\) and
\(\bigcup_{i\in V_Q}B_i=U(Q)\).

Thus \(V_Q\) witnesses a discrete PJR violation.

This proves a polynomial many-one reduction from discrete violation detection to mass-PJR violation detection, establishing \(\mathrm{NP}\)-hardness.

4. Conclusion and an explicit search bound

Combining hardness with certificate verification, mass-PJR violation detection is \(\mathrm{NP}\)-complete, and mass-PJR checking is \(\mathrm{coNP}\)-complete.

For completeness, an exact algorithm enumerates the nonempty subsets \(Q\) of the listed support. Set
\(r=|W\cap U(Q)|\) and \(h=|I(Q)|\).
A violation exists for this \(Q\) precisely when
\(r<k\),
\(h\ge r+1\), and
\(k\mu(Q)\ge r+1\).

Indeed, any witnessing integer satisfies \(\ell\ge r+1\), so these conditions are necessary; conversely, they make \(\ell=r+1\) a witness. This avoids a separate loop over levels.

With the arithmetic bounds above, the algorithm runs in
\(O(L+2^\tau(\tau m+\tau L^2))\).
In particular, it is fixed-parameter tractable in the actual support size \(\tau\).
