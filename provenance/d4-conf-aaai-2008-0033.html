The continuous mirror question, as graded

Given \(p\) binary attributes with a supplied ordered partition \(A_1 > \cdots > A_q\), and a distribution over \(\tau\) types with positive binary-rational masses summing to \(1\), where each type specifies conditional preferences through a CP-net compatible with that partition and having a linear extension, compute the H-Schwartz winner set. At each attribute and setting of the other attributes, use weighted local majority, returning both values on an exact tie; form the induced graph as in the paper and return its Schwartz set.

Packaged proof task (what the prover saw — nothing else)

Let \(m=p\geq 1\) binary attributes have outcome space \(X=\{0,1\}^{m}\) and a supplied ordered partition \(A_1>\cdots>A_q\) into nonempty blocks.
A society is given by its support: the list of \(\tau\) types with positive binary-rational masses summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
Each type supplies a CP-net with an explicit, complete conditional preference table of strict preferences at each attribute, promised to have a linear extension. For \(x\in A_\ell\), its parents must lie in \((A_1\cup\cdots\cup A_\ell)\setminus\{x\}\); dependencies within a block may be cyclic.
For each attribute and assignment to all other attributes, apply weighted majority to the types' conditional preferences, selecting both values on an exact tie. On \(X\), draw an edge from each selected value's outcome to the outcome with the other value, holding all other attributes fixed.
The H-Schwartz winner set \(W\) is the union of the strongly connected components with no incoming edge from another component. Compute \(W\) as an explicit list; write \(a=|W|\) and \(k=\max_\ell|A_\ell|\).

Is exact enumeration of \(W\) possible in time polynomial in \(m,\tau,L,a\), or is this computation NP-hard?
If it is NP-hard, is enumeration nevertheless possible in time \(f(k)\operatorname{poly}(m,\tau,L,a)\) for some computable \(f\)?

For finite electorates of \(n\) voters, an algorithm enumerates the winners in \(O(am d(nm+t(n)m+d))\) time, where \(d=2^k\) and \(t(n\)\) is the maximum local-rule evaluation time. [Xia–Conitzer–Lang](https://www.cs.cmu.edu/~conitzer/cyclic_votingAAAI08.pdf)
Schwartz membership for a general CP-net is PSPACE-complete; this concerns an unrestricted aggregate network, without the promised representation by individually extendible voter types. [Goldsmith–Lang–Truszczyński–Wilson](https://www.lamsade.dauphine.fr/~lang/papers/gltw08.pdf)
Weighted hypercubewise aggregation has been studied with Copeland, maximin and Kemeny selection; no complexity result for the precise rational-mass Schwartz enumeration problem above was located. [Conitzer–Lang–Xia](https://www.ijcai.org/Proceedings/11/Papers/038.pdf)

Modeling choices made when packaging the task

  • Specified explicit, complete conditional preference tables with strict binary preferences; treated existence of a linear extension as an input promise.
  • Made partition compatibility explicit, allowing dependencies within a block and excluding self-parent edges.
  • Specified explicit enumeration and included the winner count in polynomial running-time bounds, following the anchor's output-sensitive formulation.
  • Interpreted the largest block-domain size as the maximum over all blocks, correcting the anchor's apparent subscript typo; for binary attributes it equals 2 raised to the largest block size.
  • Used m=p for the attribute count and L for the total encoding length.

Result

The computation is NP-hard, in an output-sensitive sense: an algorithm running in time polynomial in \(m,\tau,L,a\) would imply \(\mathrm{P}=\mathrm{NP}\).

Nevertheless, exact enumeration is possible in time
\(2^k\operatorname{poly}(m,\tau,L,a)\).
Both statements respect the promise that every supplied voter CP-net has a linear extension.

1. A majority construction using acyclic voter types

Encode a strict conditional preference by its sign: \(+1\) means that \(1\) is preferred, and \(-1\) means that \(0\) is preferred.

Fix an attribute \(v\) and a sign function \(h\) of some other attributes, supplied by an explicit table. Construct two voter types as follows:

  • Both types give \(v\) the conditional preference specified by \(h\).
  • At every other attribute, the first type unconditionally prefers \(0\), and the second unconditionally prefers \(1\).
  • Only \(v\) has parents, namely the arguments of \(h\).

With equal masses, this pair contributes twice the sign \(h\) to the unnormalized majority margin at \(v\), and zero at every other attribute.

Each constructed CP-net is acyclic: every dependency edge ends at \(v\), and its parents have no parents. To verify the linear-extension promise explicitly, order the attributes with \(v\) last, and compare outcomes lexicographically using the applicable conditional preferences. Outcomes differing at just one attribute are ordered according to that attribute’s CPT. Thus this lexicographic order extends the CP-net.

Consequently, sums of such sign functions can be implemented independently at different attributes using individually extendible voter types.

All masses can be dyadic. If the construction initially uses \(2B\) equally weighted types, choose a power of two \(N\) satisfying
\(2B\leq N<4B\).
Add \((N-2B)/2\) neutral pairs, each consisting of two separable types with opposite preferences at every attribute, and give all \(N\) types mass \(1/N\). These additions cancel everywhere.

If identical types occur, merge them and add their masses. The resulting support still has polynomial size, positive dyadic masses, and total mass \(1\).

2. SAT reduction and its exact winner set

Let \(\psi\) be a Boolean formula in conjunctive normal form with at most three literals per clause. Introduce a fresh variable \(u\), and put
\(\Phi=\psi\land u\).

Write the variables of \(\Phi\) as \(x_1,\ldots,x_s\), and its clauses as \(C_1,\ldots,C_r\). Then \(\Phi\) is satisfiable exactly when \(\psi\) is satisfiable, while the all-zero assignment never satisfies \(\Phi\).

Use the \(2s+1\) attributes
\(z,x_1,\ldots,x_s,y_1,\ldots,y_s\),
all in one supplied block. Define the desired aggregate preferred values by
\[ \begin{aligned} \operatorname{pref}(x_i)&= \begin{cases} 0,&z=0,\\ y_i,&z=1, \end{cases}\\ \operatorname{pref}(y_i)&= \begin{cases} 0,&z=0,\\ x_i,&z=1, \end{cases}\\ \operatorname{pref}(z)&= \begin{cases} 1,&\Phi(x_1,\ldots,x_s)\text{ is true},\\ 0,&\Phi(x_1,\ldots,x_s)\text{ is false}. \end{cases} \end{aligned} \]

Here and below, these displayed formulas specify conditional preferred values; they are not being supplied as a succinct aggregate CPT.

Polynomial-size realization

For each \(x_i\) and \(y_i\), use the paired construction from Section 1 with its two-parent sign function. This uses \(2s\) pairs.

For \(z\), define \(h_j(x)=+1\) when \(C_j\) is satisfied, and \(h_j(x)=-1\) otherwise. Use one pair targeting \(z\) for each \(h_j\), together with \(r-1\) pairs targeting \(z\) with constant sign \(-1\).

If \(b(x)\) clauses are unsatisfied, their total signal is
\[ \sum_{j=1}^{r}h_j(x)-(r-1) =r-2b(x)-(r-1) =1-2b(x). \]
This is positive exactly when every clause is satisfied, and is never zero.

Thus the prescribed aggregate preferences are realized without ties. Every nonconstant voter table has at most three parents and at most eight rows. There are
\(B=2s+2r-1\)
pairs before padding, and each voter has only one possibly nonconstant table. The complete support representation, including all unconditional tables and masses, therefore has polynomial bit length.

The one-block partition satisfies the parent restriction automatically. Every voter is acyclic and has a linear extension by Section 1.

Exact characterization of the winners

Let \(G\) be the graph in the question. Reverse every edge to obtain \(H\). Since all aggregate preferences are strict, an edge of \(H\) changes one attribute from its nonpreferred value to its preferred value.

Source strongly connected components of \(G\) are exactly sink strongly connected components of \(H\).

Define
\[ b=(z=0,x=0^s,y=0^s). \]
For every satisfying assignment \(\alpha\) of \(\Phi\), define
\[ c_\alpha=(z=1,x=\alpha,y=\alpha). \]

Both \(b\) and every \(c_\alpha\) have no outgoing edge in \(H\): every coordinate already has its preferred value.

We now show that every outcome reaches one of these outcomes in \(H\).

  • If \(z=0\), hold \(z\) fixed and change every nonzero \(x_i,y_i\) to \(0\). Each change follows its preferred value, so this reaches \(b\).
  • If \(z=1\) and \(\Phi(x)\) is false, changing \(z\) to \(0\) is an edge of \(H\). Then apply the preceding case.
  • If \(z=1\) and \(\Phi(x)\) is true, hold \(z,x\) fixed and change each mismatching \(y_i\) to \(x_i\). Each change is an edge of \(H\), and this reaches \(c_x\).

A sink strongly connected component cannot have a path leaving it. Since every vertex reaches one of the displayed outcomes, every sink component contains one of them. That outcome has no outgoing edge, so its strongly connected component is its singleton.

Consequently, the winner set is exactly
\[ W=\{b\}\ \cup\ \{c_\alpha:\alpha\text{ satisfies }\Phi\}, \qquad a=1+\#\{\alpha:\alpha\text{ satisfies }\Phi\}. \]

In particular, unsatisfiable instances have exactly one winner, and satisfiable instances have at least two.

3. Why this rules out output-polynomial enumeration

Merely observing that satisfiability corresponds to multiple winners would not suffice: satisfiable instances can have exponentially many winners. The bounded output on unsatisfiable instances supplies the required argument.

Suppose an exact enumeration algorithm has total running time at most
\(P(m,\tau,L,a)\)
for some fixed polynomial \(P\).

Given \(\psi\), construct the preceding instance \(I\). Its parameters \(m,\tau,L\) are polynomially bounded in the length of \(\psi\). Choose a fixed polynomial cutoff \(Q\) that dominates \(P(m,\tau,L,1)\) on all these constructed instances.

Run the enumerator for \(Q(|\psi|)\) steps.

  • If it terminates, declare \(\psi\) satisfiable exactly when its completed list contains more than one winner.
  • If it has not terminated, declare \(\psi\) satisfiable.

This procedure is correct. An unsatisfiable formula produces \(a=1\), so the algorithm must terminate within the cutoff and return only \(b\). A satisfiable formula either terminates with at least two winners or exceeds the cutoff; both branches give the correct answer.

This would decide SAT in polynomial time. Hence output-polynomial enumeration is impossible unless \(\mathrm{P}=\mathrm{NP}\).

The reduction already uses acyclic voter types with at most three parents per attribute and dyadic masses. Hardness therefore does not rely on individually inconsistent voters or large rational denominators.

4. Exact local evaluation with rational masses

Write the supplied masses as \(\mu_t=\alpha_t/\beta_t\), and let
\(D=\prod_{t=1}^{\tau}\beta_t\).
Its bit length is at most the sum of the denominator bit lengths, hence at most \(L\).

Precompute the integer weights
\(w_t=\alpha_t(D/\beta_t)\).
Because the masses sum to \(1\), these weights sum to \(D\).

For any attribute and conditioning assignment, read each type’s applicable CPT entry and compare the two integer sums
\[ \sum_{t:\,1\text{ preferred}}w_t \quad\text{and}\quad \sum_{t:\,0\text{ preferred}}w_t. \]
Their equality detects an exact tie. All integers have \(O(L)\) bits, and explicit-table lookup takes polynomial time. Thus one local aggregate-rule evaluation takes some
\(T=\operatorname{poly}(m,\tau,L)\)
bit operations, without expanding masses into voters.

5. A block decomposition lemma

The positive result follows the block method of [Xia–Conitzer–Lang](https://www.cs.cmu.edu/~conitzer/cyclic_votingAAAI08.pdf). We give the graph argument and output-size accounting explicitly.

Split the attributes into an earlier prefix \(P\) and the next block \(B\). Preferences at attributes of \(P\) are independent of \(B\).

Let \(G_P\) be the graph on prefix assignments. For any strongly connected component \(C\) of \(G_P\), define \(U_C\) on assignments to \(B\): include a block edge whenever that edge exists under some prefix assignment in \(C\).

Lemma. The strongly connected components of the joint graph lying over \(C\) are precisely
\(C\times D\),
where \(D\) ranges over the strongly connected components of \(U_C\). Such a product is a source component exactly when both \(C\) and \(D\) are source components in their respective graphs.

Proof.

Every prefix edge lifts with any fixed block assignment, since prefix preferences do not depend on the block. Hence, with the block assignment fixed, one can move between any two prefix assignments in \(C\).

Consider an edge of \(U_C\). It occurs under some prefix assignment \(c\in C\). Starting from any prefix assignment in \(C\), first move to \(c\) while holding the block fixed, and then traverse that block edge. Repeating this procedure lifts any path of \(U_C\).

Conversely, a joint path that stays over \(C\) projects, after deleting stationary steps, to a path in \(U_C\). A path beginning and ending over \(C\) cannot leave \(C\) in its prefix projection: leaving and returning would make the intervening prefix vertices strongly connected with \(C\).

Thus two joint outcomes over \(C\) are mutually reachable exactly when their block assignments are mutually reachable in \(U_C\). This proves the product characterization.

If \(C\) has an incoming prefix edge from outside \(C\), that edge lifts at every block assignment, producing an incoming edge to every product \(C\times D\). If \(D\) has an incoming edge in \(U_C\), its witnessing prefix assignment likewise produces an incoming edge to \(C\times D\).

Finally, if both components are sources, no incoming joint edge can change the prefix from outside \(C\), or change the block from outside \(D\). Hence the product is a source. \(\square\)

6. Enumeration and its parameterized bound

Start with the single empty prefix. For each successive block \(A_\ell\), retain the source strongly connected components of the graph on the processed prefix.

For every retained component \(C\):

  • Construct \(U_C\) on the \(2^{|A_\ell|}\) assignments to the next block, taking the union of its conditional edge sets over all \(c\in C\).
  • Compute the source strongly connected components \(D\) of \(U_C\).
  • Retain each product \(C\times D\) as an explicit list.

The lemma proves inductively that these are exactly the source components on the enlarged prefix. After the last block, their union is \(W\). Exact ties are handled by inserting both directed edges.

Let \(b_\ell\) be the total number of retained prefix outcomes after block \(\ell\), with \(b_0=1\). Every finite nonempty \(U_C\) has a source component. Therefore every retained prefix outcome has an extension at the next stage, giving
\[ 1=b_0\leq b_1\leq\cdots\leq b_q=a. \]

At stage \(\ell\), building all union graphs requires at most
\[ b_{\ell-1}\,|A_\ell|\,2^{|A_\ell|} \leq a k2^k \]
local evaluations. Each union graph has at most \(2^k\) vertices and \(k2^k\) edges. There are at most \(a\) retained prefix components, so their strongly connected components can also be computed within
\(2^k\operatorname{poly}(m,a)\)
bit operations.

Every intermediate explicit list contains at most \(a\) outcomes, each of length at most \(m\). Since \(q\leq m\) and local evaluation takes polynomial bit time, the total running time is
\[ 2^k\operatorname{poly}(m,\tau,L,a). \]

Thus the requested parameterized enumeration algorithm exists, with \(f(k)=2^k\).
