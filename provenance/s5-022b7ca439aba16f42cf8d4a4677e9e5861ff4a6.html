Result

The optimization problem is solvable in time polynomial in \(m,\tau,L\), with an exact rational optimal assignment as output.

We prove this directly for the distribution-over-types formulation, without expanding the masses into a finite population.

1. Exact linear programming formulation

Introduce one real variable \(a_{qk}\) for each type \(q\) and interval \(k\). Define the rational objective coefficients

\(c_{qk}:=\mu_q\sum_{t=1}^{\tau}\mu_t w_{tqk}\).

Consider the linear program minimizing

\(\displaystyle \sum_{q=1}^{\tau}\sum_{k=1}^{m}c_{qk}a_{qk}\),

subject to:

  • Nonnegativity: \(a_{qk}\geq 0\) for every \(q,k\).
  • Complete allocation: \(\displaystyle \sum_{q=1}^{\tau}\mu_q a_{qk}=\ell_k\) for every \(k\).
  • Proportionality: \(\displaystyle \sum_{q=1}^{\tau}\sum_{k=1}^{m}\mu_qw_{tqk}a_{qk}\leq 1\) for every \(t\).
  • Swap envy-freeness: \(\displaystyle \sum_{k=1}^{m}(w_{ttk}-w_{tqk})(a_{tk}-a_{qk})\leq 0\) for every ordered pair \(t\neq q\).

The fourth constraint follows by subtracting the right-hand side of the given swap inequality from its left-hand side. Constraints with \(t=q\) are identities and may be omitted. All coefficients are fixed input-dependent rationals, so every constraint is linear.

The objective is exactly the required objective, because rearranging finite sums gives

\(\displaystyle \sum_{t=1}^{\tau}\mu_tD_t(a)=\sum_{t=1}^{\tau}\sum_{q=1}^{\tau}\sum_{k=1}^{m}\mu_t\mu_qw_{tqk}a_{qk}=\sum_{q=1}^{\tau}\sum_{k=1}^{m}c_{qk}a_{qk}\).

Thus the rational feasible points of this linear program are precisely the assignments in the question, with identical objective values.

2. Feasibility and attainment

Set \(a^0_{qk}:=\ell_k\) for every \(q,k\). This is rational and nonnegative.

Complete allocation holds because

\(\displaystyle \sum_{q=1}^{\tau}\mu_q a^0_{qk}=\ell_k\sum_{q=1}^{\tau}\mu_q=\ell_k\).

By the normalization hypothesis, for every \(t\),

\(\displaystyle D_t(a^0)=\sum_{q=1}^{\tau}\mu_q\sum_{k=1}^{m}w_{tqk}\ell_k=1\).

Finally, \(a^0_{tk}-a^0_{qk}=0\), so every swap constraint holds with equality. The feasible region is therefore nonempty.

For every feasible point, nonnegativity and complete allocation imply

\(\displaystyle 0\leq \mu_q a_{qk}\leq\ell_k\).

Since \(\mu_q>0\), this gives \(0\leq a_{qk}\leq\ell_k/\mu_q\). Consequently, the feasible region is a bounded, closed polyhedron, hence a compact polytope. The linear objective attains its minimum.

3. Polynomial encoding size

There are \(n:=m\tau\) variables. After replacing each equality by two inequalities, the number of inequalities is

\(\displaystyle R=n+2m+\tau+\tau(\tau-1)\).

Both \(n\) and \(R\) are polynomial in \(m,\tau\).

Each input rational has numerator and denominator of bit length at most \(L\). A product or difference of a constant number of such rationals has bit length \(O(L)\). This covers all constraint coefficients and right-hand sides.

Each objective coefficient \(c_{qk}\) is a sum of \(\tau\) products of three input rationals. To bound its encoding size, use the product of the summands’ denominators as a common denominator. That denominator has \(O(\tau L)\) bits; the resulting numerator has \(O(\tau L+\log(\tau+1))\) bits. Reduction to lowest terms cannot increase these bounds.

Thus every coefficient has bit length at most \(B=O(\tau L+\log(\tau+1))\). Even a dense encoding of the linear program has size \(O((R+1)(n+1)B)\), which is polynomial in \(m,\tau,L\). Constructing these coefficients also takes polynomial time using exact rational arithmetic.

In particular, small masses do not require a population expansion: they remain binary rational coefficients.

4. Exact rational output and polynomial running time

We use the standard polynomial-time theorem for rational linear programming: a linear program with binary-encoded rational data can be solved in time polynomial in its encoding length, returning an exact rational optimal solution whenever a finite optimum exists. This is the bit-complexity theorem originating with [Khachiyan’s polynomial algorithms for linear programming](https://www.mathnet.ru/php/archive.phtml?jrnid=zvmmf&option_lang=eng&paperid=5239&wshow=paper).

Here its hypotheses hold: the coefficients are rational, the encoding size is polynomial, and the feasible region is nonempty and bounded.

For completeness, the required rational output also has polynomial size. A linear objective on a nonempty compact polytope has an optimal vertex. At a vertex, the active constraint normals span the variable space: otherwise, a nonzero direction orthogonal to all active normals would allow sufficiently small feasible movements in both directions, contradicting extremality. Select \(n\) linearly independent active constraints.

Clear denominators separately in these \(n\) equations. Each resulting integer entry has bit length \(S=O((n+1)B)\), since a row contains at most \(n+1\) rational entries. Cramer’s rule expresses each coordinate as a ratio of integer determinants. Hadamard’s inequality bounds each determinant’s bit length by \(O(nS+n\log(n+1))\). Therefore an optimal vertex has rational coordinates of polynomial bit length.

Applying the exact rational linear programming algorithm consequently returns an optimal rational assignment in time polynomial in \(m,\tau,L\).

5. Relation to the cited finite-agent result

The cited paper’s Algorithm 1 and Theorem 7 use a linear program for the finite-agent setting. [Externalities in Chore Division](https://arxiv.org/html/2303.12446v2). The proof above independently establishes the classification for the stated support representation: its fairness constraints and weighted objective admit an explicit linear program of polynomial encoding size.
