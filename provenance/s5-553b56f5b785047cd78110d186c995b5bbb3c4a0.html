The continuous mirror question, as graded

Given a candidate set \(E\), an explicit partition matroid \(M\) of rank \(k\), a rational distribution \(\mu\) over at most two complete rankings of \(E\), and a rational threshold \(q\), decide whether there is a ranking \(\sigma\) with \(\Top_k(\sigma)\in\mathcal B(M)\) and \(\sum_t\mu_t d_{\mathrm{KT}}(\sigma,t)\le q\).

Packaged proof task (what the prover saw — nothing else)

Let \(E\) contain \(m\ge 1\) candidates. Rankings are strict complete orders; \(d_{\mathrm{KT}}\) is the unnormalized Kendall tau distance, and \(\mathsf{Top}_k(\sigma)\) is the set of the first \(k\) candidates.
An explicit partition matroid \(M\) is specified by nonempty partition classes \(G_1,\ldots,G_g\) and integer capacities \(0\le u_i\le |G_i|\), with rank \(k=\sum_i u_i\) satisfying \(1\le k\le m\). Its bases satisfy \(|B\cap G_i|=u_i\) for every \(i\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here types are distinct rankings \(t\), \(1\le\tau\le2\), and \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible rankings.
Given this society, \(M\), and a binary rational threshold \(q\in\mathbb Q\), decide whether a ranking \(\sigma\) satisfies \(\mathsf{Top}_k(\sigma)\in\mathcal B(M)\) and \(\sum_t\mu_t d_{\mathrm{KT}}(\sigma,t)\le q\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L,k,g\).

Is this distributional decision problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For two discrete voters, deciding whether the sum of Kendall tau distances of a feasible ranking is below a given threshold is \(\mathrm{NP}\)-complete, even for partition matroids.
For one input ranking, finding a closest ranking whose prescribed prefix is a matroid base is solvable in polynomial time.

Modeling choices made when packaging the task

  • Use m for the number of candidates, reserving tau for the number of positive-mass ranking types.
  • Interpret distribution as positive binary rational masses summing to one, with duplicate rankings combined.
  • Specify the explicit matroid by ordinary partition classes and capacities, rather than generalized lower and upper quotas.
  • Require a positive prefix length k between one and the number of candidates, following the discrete prefix convention.
  • Use strict complete input and output rankings and unnormalized Kendall tau distance; allow any binary rational threshold.

Result.

The decision problem is \(\mathrm{NP}\)-complete. Hardness already holds for two distinct types with equal masses \(\mu_1=\mu_2=\tfrac12\). The case \(\tau=1\) is polynomial-time solvable.

We interpret the question as asking whether there exists a ranking satisfying both conditions. We use the two-voter hardness theorem supplied in the question.

Reduction from two discrete voters.

Consider an instance of the supplied \(\mathrm{NP}\)-complete problem, consisting of rankings \(t_1,t_2\), an explicit partition matroid \(M\), and a threshold \(Q\), with the condition
\[ d_{\mathrm{KT}}(\sigma,t_1)+d_{\mathrm{KT}}(\sigma,t_2)\le Q. \]
Here and below, this display means the same inequality written inline as \(d_{\mathrm{KT}}(\sigma,t_1)+d_{\mathrm{KT}}(\sigma,t_2)\le Q\).

Construct the distributional instance as follows:

  • Keep the candidate set and partition matroid unchanged.
  • If \(t_1\ne t_2\), give each ranking mass \(\tfrac12\).
  • If \(t_1=t_2\), use the single support type \(t_1\), with mass \(1\).
  • Set \(q=Q/2\).

In both cases the support contains distinct rankings, has size at most two, and consists entirely of positive binary rational masses summing to \(1\). For every ranking \(\sigma\),
\[ \sum_t\mu_t d_{\mathrm{KT}}(\sigma,t) =\frac{d_{\mathrm{KT}}(\sigma,t_1)+d_{\mathrm{KT}}(\sigma,t_2)}2. \]
Equivalently, \(\sum_t\mu_t d_{\mathrm{KT}}(\sigma,t)=\bigl(d_{\mathrm{KT}}(\sigma,t_1)+d_{\mathrm{KT}}(\sigma,t_2)\bigr)/2\).

Thus the source instance admits a feasible ranking satisfying its threshold exactly when the constructed instance does. Comparing the two input rankings and copying the instance are polynomial-time operations; dividing the threshold by \(2\) increases its encoding length by at most a constant.

If “below a threshold” in the supplied theorem denotes a strict inequality \(C<T\), replace it first by \(C\le \lceil T\rceil-1\). This is equivalent because the unnormalized sum \(C\) is an integer, and the conversion is polynomial-time.

This proves \(\mathrm{NP}\)-hardness for \(\tau\le2\).

To obtain hardness specifically for two distinct equally weighted types, handle source instances with \(t_1=t_2\) using the polynomial algorithm proved below, and output a fixed yes-instance or no-instance accordingly. Such fixed instances can use two candidates, a single partition class of capacity \(1\), and the two opposite rankings: their weighted cost is always \(\tfrac12\), so thresholds \(\tfrac12\) and \(0\) give a yes-instance and a no-instance. All other source instances use the construction above.

Membership in \(\mathrm{NP}\) and verification time.

A certificate is a list of the \(m\) candidates in the proposed order \(\sigma\). Verification proceeds as follows.

  • Check that the list contains every candidate exactly once.
  • Count candidates from each \(G_i\) among the first \(k\) positions, and check that the count equals \(u_i\).
  • For each support type \(t\), count unordered candidate pairs ordered differently by \(\sigma\) and \(t\). This count is \(d_{\mathrm{KT}}(\sigma,t)\), by definition.
  • Compare the resulting rational weighted sum with \(q\) using exact integer arithmetic.

For completeness, write \(\mu_t=a_t/b_t\) and \(q=c/d\), with positive denominators. Setting \(B=\prod_t b_t\), the final comparison is
\[ d\sum_t a_t d_{\mathrm{KT}}(\sigma,t)\frac{B}{b_t}\le cB. \]
That is, check \(d\sum_t a_t d_{\mathrm{KT}}(\sigma,t)(B/b_t)\le cB\). Multiplication by the positive integer \(dB\) preserves the inequality.

Each distance is at most \(\binom m2\). Since \(\tau\le2\), every integer in this comparison has bit length \(O(L+\log(m+1))\).

With candidates represented by indices, direct pair counting and elementary integer arithmetic give the conservative verification bound
\[ O\!\left((\tau m^2+m+k+g)\log(m+1)+(L+\log(m+1))^2\right). \]
In inline notation, the bound is \(O\bigl((\tau m^2+m+k+g)\log(m+1)+(L+\log(m+1))^2\bigr)\) bit operations. It is polynomial in the input parameters. Hence the problem belongs to \(\mathrm{NP}\), completing the \(\mathrm{NP}\)-completeness proof.

Polynomial algorithm for one support type.

Suppose \(\tau=1\), and let \(t\) be its ranking. Its mass is necessarily \(1\). Write \(p(x)\) for the position of candidate \(x\) in \(t\).

Fix a feasible base \(B\) of size \(k\). Form \(\sigma_B\) by listing the elements of \(B\) in their relative order in \(t\), followed by the elements outside \(B\), again in their relative order in \(t\).

Every ranking with top set \(B\) must reverse every pair consisting of an element outside \(B\) that precedes an element of \(B\) in \(t\). The ranking \(\sigma_B\) reverses exactly these forced pairs: it preserves all relative orders within the two blocks. Therefore it minimizes distance among rankings with top set \(B\).

If \(b_1,\ldots,b_k\) are the elements of \(B\) in their order in \(t\), then exactly \(p(b_j)-j\) elements outside \(B\) precede \(b_j\). Consequently,
\[ d_{\mathrm{KT}}(\sigma_B,t) =\sum_{j=1}^k(p(b_j)-j) =\sum_{b\in B}p(b)-\frac{k(k+1)}2. \]
Equivalently, \(d_{\mathrm{KT}}(\sigma_B,t)=\sum_{b\in B}p(b)-k(k+1)/2\).

The second term is constant over all bases. The partition constraints require choosing exactly \(u_i\) candidates from each \(G_i\), so minimizing the first term separates across classes. In each class, choose its first \(u_i\) candidates in \(t\). These choices minimize the sum of positions because replacing any selected later candidate by an unselected earlier candidate strictly decreases it.

A scan of \(t\) selects these candidates; a second scan constructs \(\sigma_B\). Computing its distance and comparing it with \(q\) gives a conservative bit-time bound of \(O\bigl((m+k+g)\log(m+1)+(L+\log(m+1))^2\bigr)\).

Thus the single-type case is polynomial-time solvable, while allowing two support types makes the decision problem \(\mathrm{NP}\)-complete.
