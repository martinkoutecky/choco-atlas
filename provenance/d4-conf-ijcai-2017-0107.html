The continuous mirror question, as graded

Given a finite type set \(T\) with rational masses \(\mu_t\) summing to one, a finite menu \(J\) of fixed contracts with per-consumer reductions \(\ell_j\), rational costs \(b_{tj}\), a required per-consumer reduction \(\rho\), and a per-consumer cost bound \(z\), decide whether there are rational allocations \(x_{tj}\ge 0\) satisfying \(\sum_j x_{tj}\le\mu_t\) for every \(t\), \(\sum_{t,j}\ell_jx_{tj}\ge\rho\), and \(\sum_{t,j}b_{tj}x_{tj}\le z\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types \(T\) with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a nonempty finite menu \(J\) of \(m=|J|\) offered contracts, nonnegative binary-rational declared reductions \(\ell_j\), nonnegative binary-rational per-consumer bids \(b_{tj}\), and nonnegative binary-rational thresholds \(\rho,z\). Bids are supplied directly; the cost bound concerns their sum.
An allocation \(x_{tj}\in\mathbb{Q}_{\ge0}\) assigns that mass of type \(t\) to contract \(j\). A type's mass may be divided among contracts, with unused mass taking no contract. Feasibility means \(\sum_{j\in J}x_{tj}\le\mu_t\) for every \(t\), \(\sum_{t\in T,j\in J}\ell_jx_{tj}\ge\rho\), and \(\sum_{t\in T,j\in J}b_{tj}x_{tj}\le z\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is deciding whether a feasible rational allocation exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite consumers, assigning at most one contract per consumer to meet a declared reduction target within a total-bid bound is NP-hard, even for fixed-penalty contracts; with integer reductions, optimization admits a running time polynomial in the consumer count, menu size, and numerical reduction target. [Source](https://arxiv.org/pdf/1705.07300)
No result for exactly this distribution-over-types feasibility problem was identified in the literature search.

  • Specified all reductions, bids, and thresholds as nonnegative binary rationals, retaining zero values.
  • Interpreted types as supplied bid vectors and the cost bound as a bound on aggregate bids, matching the discrete objective.
  • Used a nonempty offered menu and defined its size as m and the total binary input length as L.
  • Retained finite bids as stipulated by the continuous question; no infinite bids or forbidden type-contract pairs are added.

Result

The decision problem is polynomial-time solvable in \(m,\tau,L\). Allowing each type’s mass to be divided among contracts makes the stated problem an exact rational linear-programming feasibility problem.

1. Exact linear-programming formulation

Set \(N=\tau m\), and introduce one real variable \(x_{tj}\) for each explicitly listed pair \((t,j)\in T\times J\). Define the polyhedron \(P\subseteq\mathbb{R}^{N}\) by the following inequalities:

  • \( -x_{tj}\le 0\) for every \((t,j)\in T\times J\).
  • \( \sum_{j\in J}x_{tj}\le\mu_t\) for every \(t\in T\).
  • \( -\sum_{t\in T}\sum_{j\in J}\ell_jx_{tj}\le-\rho\).
  • \( \sum_{t\in T}\sum_{j\in J}b_{tj}x_{tj}\le z\).

There are exactly \(R=N+\tau+2\) inequalities. Every coefficient and right-hand side is rational and is either an input number, its negative, or one of the constants \(0,1,-1\).

By construction, a rational allocation is feasible in the stated problem if and only if it belongs to \(P\cap\mathbb{Q}^{N}\). In particular, the cost constraint uses the supplied bids directly; no additional cost computation is necessary.

2. Real feasibility implies rational feasibility

We verify that deciding whether \(P\) is nonempty suffices, despite the requirement that allocations be rational.

For every \(x\in P\), nonnegativity and the type-capacity inequalities imply
\(0\le x_{tj}\le\mu_t\le1\).
Consequently, \(P\) is bounded. It is also closed, since it is defined by finitely many non-strict linear inequalities. Thus, if nonempty, it is compact.

A nonempty compact polyhedron has an extreme point. Here this can be seen directly: successively minimize each of the \(N\) coordinates, restricting at each step to the preceding minimizers. Compactness ensures that each minimum is attained. The final point \(v\) is extreme: if \(v\) were the midpoint of two feasible points, coordinate-by-coordinate minimality would force both points to agree with \(v\) in every coordinate.

Write the defining system as \(Ax\le d\). At an extreme point \(v\), the rows of \(A\) corresponding to tight inequalities span \(\mathbb{R}^{N}\). Indeed, otherwise there would be a nonzero vector \(h\) orthogonal to every tight row. For sufficiently small \(\varepsilon>0\), both \(v+\varepsilon h\) and \(v-\varepsilon h\) would satisfy all inequalities: tight inequalities remain equalities, and every other inequality has positive slack. This contradicts extremality.

Therefore, we can select \(N\) linearly independent tight rows, obtaining a nonsingular rational matrix \(B\) and a rational vector \(d'\) such that \(Bv=d'\). Cramer’s rule gives \(v\in\mathbb{Q}^{N}\). Hence
\(P\ne\varnothing\) if and only if \(P\cap\mathbb{Q}^{N}\ne\varnothing\).

3. Polynomial input size and running time

Let \(H\) denote the binary encoding length of the constructed linear system. A dense representation contains \(R(N+1)\) matrix and right-hand-side entries. Each entry has encoding length \(O(L+1)\), so the conservative bound
\(H=O\bigl((\tau m+\tau+2)(\tau m+1)(L+1)\bigr)\)
holds. Constructing this representation takes polynomial time in \(m,\tau,L\).

The rational linear-programming theorem states that feasibility of an explicitly represented system of rational linear inequalities is decidable in deterministic time polynomial in its dimensions and binary encoding length. This is the bit-complexity guarantee of polynomial-time rational LP algorithms; see the introduction of [Adler and Beling’s research paper](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf).

Its hypotheses hold here: the system is explicit, finite, linear, and rational. Applying such an algorithm therefore takes
\(\operatorname{poly}(N,R,H)=\operatorname{poly}(m,\tau,L)\)
bit operations. Section 2 proves that its answer is exactly the answer to the requested rational-allocation problem.

This bound uses the listed support size \(\tau\). It requires neither enumeration of unlisted possible types nor expansion of rational masses into individual consumers.

4. Why indivisible-consumer hardness does not transfer

The finite-consumer problem imposes discrete choices that are absent here. Fractional allocation can change feasibility even in the smallest instance.

Take one type with mass \(\mu_t=1\), one contract with \(\ell_j=b_{tj}=2\), and thresholds \(\rho=z=1\). The rational allocation \(x_{tj}=1/2\) meets both thresholds exactly.

If this mass instead represented one indivisible consumer, choosing no contract would fail the reduction constraint, while choosing the contract would fail the cost constraint. Thus, a feasible fractional allocation need not yield a feasible indivisible assignment.

The stated distribution-over-types problem belongs to \(\mathrm{P}\). It could consequently be NP-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).
