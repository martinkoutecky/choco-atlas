Theorem 5.4 — class: hardness

The continuous mirror question, as graded

Given a mass-one society with one type \(a\), common utility \(u:G\to\mathbb{Q}_{\ge 0}\), \(T\) rounds, per-round good capacities \(q_g\ge 0\), and threshold \(\kappa\), does there exist \(y_\sigma\ge 0\) for trajectories \(\sigma\in G^T\) such that \(\sum_\sigma y_\sigma=1\), \(\sum_{\sigma:\,\sigma_t=g}y_\sigma\le q_g\) for every round \(t\) and good \(g\), and every trajectory with \(y_\sigma>0\) satisfies \(\sum_{t=1}^{T}u(\sigma_t)\ge\kappa\)? The optimization version maximizes the essential-minimum trajectory utility.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here the society has one type \(a\) of mass \(1\), so \(\tau=1\).
Let \(G\) be a nonempty set of \(m\) goods, with common utility \(u:G\to\mathbb{Q}_{\ge0}\), capacities \(q_g\in\mathbb{Q}_{\ge0}\) satisfying \(\sum_{g\in G}q_g\ge1\), and threshold \(\kappa\in\mathbb{Q}_{\ge0}\). These rationals and the positive integer \(T\) are binary encoded; \(L\) is the total input bit length.
Capacities are renewed each round, unused capacity is allowed, and each individual receives exactly one good per round; the same good may recur in an individual's trajectory.
A feasible assignment consists of real masses \(y_\sigma\ge0\), indexed by \(\sigma\in G^T\), such that \(\sum_{\sigma\in G^T}y_\sigma=1\) and \(\sum_{\sigma:\sigma_t=g}y_\sigma\le q_g\) for every \(t\in\{1,\ldots,T\}\) and \(g\in G\). It meets the threshold when \(y_\sigma>0\) implies \(\sum_{t=1}^T u(\sigma_t)\ge\kappa\).

Is deciding whether a feasible assignment meets the threshold in \(\mathsf{P}\), or is it \(\mathsf{NP}\)-hard? State running times in \(m\), \(\tau\), \(L\), and \(T\), with polynomial time measured against the binary input length.

For finitely many agents with identical utilities and unit capacity per good per round, threshold feasibility is \(\mathsf{NP}\)-complete; exact optimization is polynomial-time solvable when \(T\) is a multiple of the number \(n\) of agents. [Source](https://arxiv.org/html/2510.04624v1#S5.SS3)
No result settling exactly the mass-assignment problem above was located in the search.

Modeling choices made when packaging the task

  • Specified a nonempty good set and a positive integer number of rounds.
  • Specified binary encoding for the rounds, utilities, capacities, and threshold, and defined L as total input bit length.
  • Required total per-round capacity at least one, carrying over the discrete assumption that there are enough goods to match every agent.
  • Specified a nonnegative rational threshold, consistent with nonnegative utilities.
  • Made explicit that capacities renew each round, unused capacity is allowed, and an individual may receive the same good in several rounds.
  • Allowed real trajectory masses, as the continuous question imposes no rationality restriction on assignments.

Result

The decision problem is \(\mathsf{NP}\)-complete, even when \(\tau=1\), every capacity is \(q_g=1/m\), all utilities and the threshold are integers, and \(m=2T\).

Consequently, a polynomial-time algorithm in the binary input length \(L\) exists if and only if \(\mathsf{P}=\mathsf{NP}\). The proof below applies directly to the stated mass-assignment model.

1. An equivalent formulation using integer count vectors

For a trajectory \(\sigma\in G^T\), define its count vector \(x(\sigma)\) by
\[ \text{} \]
\(x_g(\sigma)=|\{t:\sigma_t=g\}|\).

Thus \(x(\sigma)\in\mathbb Z_{\ge0}^m\), \(\sum_gx_g(\sigma)=T\), and its utility is \(\sum_gu(g)x_g(\sigma)\). Define

\(\mathcal H=\{x\in\mathbb Z_{\ge0}^m:\sum_gx_g=T,\ \sum_gu(g)x_g\ge\kappa\}\).

Lemma. Threshold feasibility is equivalent to feasibility of the rational linear system

\(\displaystyle p_x\ge0\quad(x\in\mathcal H),\qquad \sum_{x\in\mathcal H}p_x=1,\qquad \sum_{x\in\mathcal H}p_xx_g\le Tq_g\quad(g\in G).\)

Proof. Given a feasible trajectory assignment, aggregate the masses of trajectories having the same count vector. Then

\(\displaystyle \sum_xp_xx_g=\sum_{t=1}^T\sum_{\sigma:\sigma_t=g}y_\sigma\le Tq_g.\)

Every positive-mass count vector belongs to \(\mathcal H\).

Conversely, suppose the displayed system is feasible. For each \(x\) with positive mass, choose a length-\(T\) word containing \(x_g\) copies of each good \(g\). Distribute mass \(p_x/T\) to each of its \(T\) cyclic rotations, adding masses when rotations coincide.

At any fixed position, exactly \(x_g\) of these rotations contain \(g\). Hence the mass receiving \(g\) in each round is

\(\displaystyle \sum_xp_x\frac{x_g}{T}\le q_g.\)

Every rotation has utility \(\sum_gu(g)x_g\ge\kappa\), and the total mass is one. This proves the equivalence. \(\square\)

2. A polynomial reduction from partition

We use the classical \(\mathsf{NP}\)-complete problem \(\mathsf{PARTITION}\): given positive binary-encoded integers \(a_1,\ldots,a_n\), decide whether some \(S\subseteq\{1,\ldots,n\}\) satisfies \(2\sum_{i\in S}a_i=\sum_{i=1}^na_i\). Its \(\mathsf{NP}\)-completeness is established in [Karp’s original paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Construction and encoding length

Write

\(A=\sum_{i=1}^na_i,\qquad B=n+1,\qquad M=2nA+1,\qquad C=\sum_{i=1}^nB^{i-1}.\)

Create two goods \(g_i^0,g_i^1\) for each index \(i\), and set

\(m=2n,\qquad T=n,\qquad q_{g_i^0}=q_{g_i^1}=\frac1{2n},\qquad \kappa=MC+A.\)

Their common utilities are

\(u(g_i^0)=MB^{i-1},\qquad u(g_i^1)=MB^{i-1}+2a_i.\)

The society consists of one type of mass one. All utilities and the threshold are nonnegative integers, and the capacities sum to one.

Every utility and the threshold have bit length \(O(\log(A+1)+n\log(n+1))\). Thus the construction takes polynomial time in the source input length and produces an instance of polynomial binary length.

Every positive-mass count vector must have utility exactly the threshold

Suppose the constructed instance is feasible, and use the lemma to obtain masses \(p_x\). Put

\(\displaystyle z_g=\sum_xp_xx_g.\)

For every good, \(z_g\le Tq_g=1/2\). Also,

\(\displaystyle \sum_gz_g=\sum_xp_x\sum_gx_g=T=n.\)

There are \(2n\) goods, so their upper bounds sum to \(n\). Therefore every bound is attained: \(z_g=1/2\) for every \(g\).

Consequently, the average trajectory utility is

\(\displaystyle \sum_xp_x\sum_gu(g)x_g =\frac12\sum_{i=1}^n\bigl(u(g_i^0)+u(g_i^1)\bigr) =MC+A=\kappa.\)

Every positive-mass count vector has utility at least \(\kappa\). Since their average equals \(\kappa\), each has utility exactly \(\kappa\).

Exact utility forces a partition

Choose any positive-mass count vector \(x\). Define

\(c_i=x_{g_i^0}+x_{g_i^1},\qquad V=\sum_{i=1}^na_i x_{g_i^1}.\)

Its exact utility equation is

\(\displaystyle M\sum_{i=1}^nc_iB^{i-1}+2V=MC+A.\)

Because \(\sum_gc_g\) here is represented by \(\sum_ic_i=n\), we have

\(\displaystyle 0\le V\le nA,\qquad 0\le2V\le2nA<M,\qquad 0\le A<M.\)

Reducing the exact utility equation modulo \(M\) therefore gives \(2V=A\): the two congruent quantities are both between zero and \(M-1\). Substituting back yields

\(\displaystyle \sum_{i=1}^nc_iB^{i-1}=\sum_{i=1}^nB^{i-1}.\)

Each \(c_i\) satisfies \(0\le c_i\le n=B-1\). Both sides are therefore base-\(B\) expansions with valid digits. Uniqueness of positional representation implies \(c_i=1\) for every \(i\).

Thus \(x_{g_i^1}\in\{0,1\}\), and the set \(S=\{i:x_{g_i^1}=1\}\) satisfies

\(\displaystyle 2\sum_{i\in S}a_i=2V=A.\)

The original partition instance is a yes-instance.

A partition gives a feasible mass assignment

Conversely, suppose \(S\) satisfies \(2\sum_{i\in S}a_i=A\).

Define \(x\) by choosing \(g_i^1\) when \(i\in S\), and \(g_i^0\) otherwise, with one chosen good from each pair. Define \(\bar x\) by choosing the opposite good in every pair.

Both count vectors have total count \(n\), and both have utility \(MC+A=\kappa\), because \(S\) and its complement each have sum \(A/2\).

Assign mass \(1/2\) to each count vector. Every good then has expected count \(1/2=Tq_g\). By the lemma, these masses yield a feasible trajectory assignment meeting the threshold.

The reduction is therefore correct in both directions, proving \(\mathsf{NP}\)-hardness.

3. Membership in \(\mathsf{NP}\) with binary-encoded rounds

It remains to justify a polynomial certificate despite the potentially enormous trajectory set.

Add nonnegative slack variables to the count-vector linear system:

\(\displaystyle \sum_xp_x=1,\qquad \sum_xp_xx_g+s_g=Tq_g\quad(g\in G).\)

This system has \(r=m+1\) equality constraints. Its feasible region, when nonempty, is compact: the masses lie between zero and one, and \(0\le s_g\le Tq_g\). Hence it has an extreme point.

At an extreme point, the columns corresponding to positive variables are linearly independent. Otherwise, a nonzero dependence would allow sufficiently small perturbations in both directions, preserving all equalities and nonnegativity, contradicting extremality. Thus at most \(m+1\) variables are positive, and in particular at most \(m+1\) count vectors have positive mass.

The equality matrix is integral, with entries bounded by \(T\). Let \(D\) be the product of the denominators of the capacities. Its bit length is \(O(L)\), and multiplying the right-hand side by \(D\) gives integers of bit length \(O(L+\log(T+1))\).

The matrix has full row rank whenever \(\mathcal H\) is nonempty: the slack columns span the last \(m\) coordinates, and any count-vector column has first coordinate one. Extend the positive columns of an extreme point to a basis. Cramer’s rule, together with the determinant bound for an \(r\)-dimensional integer matrix, shows that each positive mass has numerator and denominator bit length

\(O\bigl(L+m\log(m+1)+m\log(T+1)\bigr).\)

A certificate therefore lists at most \(m+1\) integer count vectors and their rational masses. Each count-vector entry needs only \(O(\log(T+1))\) bits. All threshold, normalization, and capacity inequalities can be checked by exact rational arithmetic in polynomial time.

Since \(m\) and \(\log(T+1)\) are bounded by the binary input length, the certificate size and verification time are polynomial in \(L\). The problem belongs to \(\mathsf{NP}\).

4. Running times and encoding consequences

For the specified model, \(\tau=1\) throughout.

Let \(H=\binom{T+m-1}{m-1}\), the number of nonnegative integer count vectors summing to \(T\). Enumerating these vectors, retaining those meeting the threshold, and solving the lemma’s rational linear system takes

\((H+m+L)^{O(1)}\)

bit operations. This follows from polynomial-time rational linear programming: there are at most \(H\) variables, \(m+1\) constraints, and coefficients of polynomial bit length.

In particular:

  • For fixed \(T\), since \(H\le m^T\), this gives \(m^{O(T)}L^{O(1)}\) time.
  • For fixed \(m\), since \(H\le(T+1)^{m-1}\), this enumeration gives \((T+1)^{O(m)}L^{O(1)}\) time.
  • Certificate verification takes \((m+\tau+L+\log(T+1))^{O(1)}=L^{O(1)}\) time here.

The enumeration bound is generally exponential in the binary length of \(T\). Moreover, the reduction already has \(T=m/2\), so even a running-time bound polynomial in \(m,\tau,L,T\) would imply \(\mathsf{P}=\mathsf{NP}\). Hardness therefore persists with unary-encoded \(T\), although this reduction uses binary-encoded utilities of potentially large numerical magnitude.
