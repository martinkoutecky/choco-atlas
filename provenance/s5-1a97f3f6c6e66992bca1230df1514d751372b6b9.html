The continuous mirror question, as graded

Given candidates \(C\), a top-\(k\) ballot support \(T\), binary-rational masses \(\mu_t\ge 0\) summing to \(1\), and a binary-rational lottery \(q\) over \(C\), compute the exact worst-case metric distortion over metric realizations consistent with those ballots. Let \(r_t(i)\) be candidate \(i\)'s reported position in type \(t\), with unlisted candidates at position \(k\). Equivalently, evaluate \(1+2\max_{i^\star\in C}\max_{\ell\ge 0,\,\ell_{i^\star}=0}\frac{\sum_{t\in T}\mu_t\sum_{i\in C}q_i\min\!\left(\ell_i,\min_{j:r_t(i)<r_t(j)}\ell_j\right)}{\sum_{t\in T}\mu_t\max\!\left(0,\max_{i,j:r_t(i)<r_t(j)}(\ell_i-\ell_j)\right)}\), the mass-weighted version of the paper's exact characterization.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\ge 2\) candidates and let \(1\le k\le m\). A ballot type is an ordered list of \(k\) distinct candidates; \(r_t(i)\) is its zero-indexed position, or \(k\) if unlisted. Metric consistency requires weak distance inequalities for reported comparisons; distance ties are permitted, and unlisted candidates have no reported comparisons among themselves.
A society is given by its support: the list \(T\) of the \(\tau\) types with positive mass, each with its mass \(\mu_t\) as a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible ballots. The input also contains a binary-rational lottery \(q_i\ge0\), \(\sum_iq_i=1\); let \(L\) be the total input bit length.
For real edge lengths \(\ell\in\mathbb R_{\ge0}^{C}\), define \(g_t(i,\ell)=\min(\{\ell_i\}\cup\{\ell_j:r_t(i)<r_t(j)\})\) and \(b_t(\ell)=\max(\{0\}\cup\{\ell_i-\ell_j:r_t(i)<r_t(j)\})\).
The quantity to evaluate is the exact worst-case metric distortion \(D(T,\mu,q)=1+2\max_{a\in C}\sup_{\ell\ge0,\,\ell_a=0}\frac{\sum_{t\in T}\mu_t\sum_{i\in C}q_i g_t(i,\ell)}{\sum_{t\in T}\mu_t b_t(\ell)}\). Interpret a positive numerator over zero as \(+\infty\), and \(0/0\) as \(0\).

Is exact evaluation of \(D(T,\mu,q)\) polynomial-time in \(m,\tau,k,L\), or is it NP-hard?

For finite electorates, the exact edge-length characterization is known for every \(k\), with a matching metric construction ([Sun–Zhu](https://arxiv.org/html/2607.03564v1)).
For finite electorates reporting full rankings, a given lottery’s exact metric distortion is computable in polynomial time ([Frank–Lederer](https://staff.fnwi.uva.nl/p.lederer/research/metricdistortion.pdf)). The search located no explicit classification for the binary-rational support representation and arbitrary top-\(k\) ballots specified here.

  • Retained only positive-mass types in the support and defined L as the total input bit length.

  • Replaced nested empty minima and maxima by set expressions containing the candidate's own length and zero, respectively.

Result

Exact evaluation is polynomial-time solvable in \(m,\tau,k,L\), for every \(k\). The algorithm solves one rational linear program for each anchor candidate \(a\). It returns either \(+\infty\) or the exact rational value of \(D(T,\mu,q)\).

The proof uses the edge-length formula supplied in the question directly.

1. Definitions and normalization

For each type \(t\), define its set of reported comparisons by
\[ P_t=\{(i,j)\in C^2:r_t(i)<r_t(j)\}. \]
Thus \(P_t\) contains no comparison between two unlisted candidates.

Write
\[ N(\ell)=\sum_{t\in T}\mu_t\sum_{i\in C}q_i g_t(i,\ell), \qquad B(\ell)=\sum_{t\in T}\mu_t b_t(\ell). \]
Both functions are nonnegative. For every \(\lambda\ge0\), their definitions give
\[ N(\lambda\ell)=\lambda N(\ell), \qquad B(\lambda\ell)=\lambda B(\ell). \]

Fix an anchor \(a\), and let
\[ R_a=\sup_{\ell\ge0,\ \ell_a=0}\frac{N(\ell)}{B(\ell)} \]
with the conventions in the question. Also define
\[ H_a=\sup\{N(\ell):\ell\ge0,\ \ell_a=0,\ B(\ell)\le1\}. \]

Lemma. \(R_a=H_a\), including infinite values.

Proof. First suppose there exists an admissible \(\ell\) with \(B(\ell)=0<N(\ell)\). Then \(R_a=+\infty\) by convention. For every \(\lambda>0\), the vector \(\lambda\ell\) remains feasible for \(H_a\), and its numerator is \(\lambda N(\ell)\). Hence \(H_a=+\infty\) as well.

Otherwise, every admissible vector with zero denominator also has zero numerator. For any admissible \(\ell\) with \(B(\ell)>0\), the vector \(\ell/B(\ell)\) has denominator one and numerator \(N(\ell)/B(\ell)\). Thus every such ratio is at most \(H_a\). Ratios with zero denominator are zero, and \(H_a\ge0\), so \(R_a\le H_a\).

Conversely, consider any vector feasible for \(H_a\). If its denominator is zero, its numerator is zero. If its denominator is positive, then
\[ N(\ell) =B(\ell)\frac{N(\ell)}{B(\ell)} \le\frac{N(\ell)}{B(\ell)} \le R_a, \]
where the first inequality uses \(B(\ell)\le1\) and nonnegativity of the ratio. Taking the supremum gives \(H_a\le R_a\). This proves the lemma. \(\square\)

2. A linear program for each anchor

For the fixed anchor \(a\), introduce variables:

  • \(\ell_i\) for each \(i\in C\);
  • \(z_{ti}\) for each \(t\in T\) and \(i\in C\);
  • \(\beta_t\) for each \(t\in T\).

Let \(V_a\) be the supremum of the following linear program, interpreting an unbounded objective as \(+\infty\).

Maximize
\[ \sum_{t\in T}\sum_{i\in C}\mu_tq_i z_{ti} \]
subject to
\[ \ell_i\ge0\quad(i\in C),\qquad \ell_a=0, \]
\[ 0\le z_{ti}\le\ell_i\quad(t\in T,\ i\in C), \]
\[ z_{ti}\le\ell_j\quad(t\in T,\ (i,j)\in P_t), \]
\[ \beta_t\ge0\quad(t\in T), \]
\[ \beta_t\ge\ell_i-\ell_j\quad(t\in T,\ (i,j)\in P_t), \]
\[ \sum_{t\in T}\mu_t\beta_t\le1. \]

All constraints are linear. The all-zero assignment is feasible.

Lemma. \(V_a=H_a\).

Proof. Take any feasible assignment \((\ell,z,\beta)\). The constraints on \(z_{ti}\) imply
\[ z_{ti}\le \min\bigl(\{\ell_i\}\cup\{\ell_j:(i,j)\in P_t\}\bigr) =g_t(i,\ell). \]
The constraints on \(\beta_t\) imply
\[ \beta_t\ge \max\bigl(\{0\}\cup\{\ell_i-\ell_j:(i,j)\in P_t\}\bigr) =b_t(\ell). \]
Because all masses are positive,
\[ B(\ell)\le\sum_t\mu_t\beta_t\le1. \]
Thus \(\ell\) is feasible for \(H_a\). Moreover, every objective coefficient \(\mu_tq_i\) is nonnegative, so
\[ \sum_{t,i}\mu_tq_i z_{ti}\le N(\ell)\le H_a. \]
Taking the supremum over LP assignments proves \(V_a\le H_a\).

For the reverse inequality, take any \(\ell\) feasible for \(H_a\), and set
\[ z_{ti}=g_t(i,\ell),\qquad \beta_t=b_t(\ell). \]
The defining minimum and maximum satisfy every corresponding LP constraint. The final constraint holds because \(B(\ell)\le1\). This assignment has objective exactly \(N(\ell)\). Taking the supremum over such vectors proves \(V_a\ge H_a\). \(\square\)

Combining the two lemmas yields
\[ R_a=V_a. \]
In particular, LP unboundedness handles both a positive numerator over zero and unbounded ratios with positive denominators.

3. Size and exact bit complexity

Each LP has
\[ m+\tau m+\tau \]
variables.

A type reporting \(k\) candidates has
\[ |P_t| =\sum_{p=0}^{k-1}(m-p-1) =km-\frac{k(k+1)}2 \le km \]
reported comparisons: the candidate at position \(p\) precedes exactly \(m-p-1\) candidates. This count also applies when \(k=m\).

Consequently, each LP has \(O(m+\tau m+\tau km)\) constraints. All comparisons can be enumerated from the supplied support in polynomial time.

Its coefficients are zeros, ones, negative ones, the input masses \(\mu_t\), and the products \(\mu_tq_i\). Multiplying two binary rationals produces a rational whose encoding length is at most the sum of their encoding lengths, up to a constant. Therefore the full encoding length of each LP is polynomial in \(m,\tau,k,L\).

We use the standard rational linear-programming theorem: an explicitly encoded rational LP can be solved in time polynomial in its binary encoding length, with infeasibility and objective unboundedness detected, and with an exact rational optimum returned when the optimum is finite. This is polynomial time in the bit model, rather than merely a bound on arithmetic operations; see [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/eng/zvmmf5239).

The hypotheses apply here: every LP is explicitly represented, all coefficients are rational, and its encoding length is polynomial. Feasibility is already established by the zero assignment.

No expansion of binary-rational masses into individual voters is required.

4. Evaluation algorithm

For each \(a\in C\), construct and solve the LP above.

  • If any LP has an unbounded objective, return \(D(T,\mu,q)=+\infty\).
  • Otherwise, obtain its exact rational optimum \(V_a\), and return

\[ D(T,\mu,q)=1+2\max_{a\in C}V_a. \]

The equality follows from \(V_a=R_a\) and the defining formula for \(D\). There are \(m\) polynomial-size rational LPs, so the entire computation takes polynomial time in \(m,\tau,k,L\). This settles the stated evaluation problem for arbitrary top-\(k\) support inputs.
