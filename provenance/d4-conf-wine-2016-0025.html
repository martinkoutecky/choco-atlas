The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), an integer \(k\), and ordinal rankings over types induced by a hidden symmetric metric \(w\), construct an ordinal, universally truthful mechanism that does not observe \(w\). It may divide each type's mass among \(k\) clusters, with \(q_{tj}\ge 0\), \(\sum_j q_{tj}=\mu_t\), and \(\sum_t q_{tj}=1/k\); each individual is assigned to exactly one cluster. Can it return \(q\) with expected welfare at least half the maximum feasible welfare, where \(W(q)=\frac12\sum_{j=1}^k\sum_{t,u\in T}q_{tj}q_{uj}w_{tu}\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(m=|T|=\tau\) is also the number of ranked alternatives; \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length, and let \(\sum_{t\in T}\mu_t=1\).
Each type consists of an atomless interval of individuals of mass \(\mu_t\), with public, immutable type identities. An unknown real-valued metric \(w\) on \(T\), with \(w_{tt}=0\), gives pairwise utilities. Individuals report strict rankings of types by decreasing \(w_{tu}\), with arbitrary ordering of equal values; the supplied ranking is initially constant within each type.
For an integer \(k\ge2\), a feasible outcome has \(q_{tj}\ge0\), \(\sum_{j=1}^kq_{tj}=\mu_t\), and \(\sum_tq_{tj}=1/k\). It includes a measurable assignment of every individual to exactly one cluster realizing these masses. An individual of true type \(t\) assigned to cluster \(j\) receives utility \(\sum_uq_{uj}w_{tu}\); there are no transfers.
Define \(W(q)=\frac12\sum_{j=1}^k\sum_{t,u\in T}q_{tj}q_{uj}w_{tu}\) and \(\mathrm{OPT}(w)=\max_{q\text{ feasible}}W(q)\). A mechanism observes masses and reported rankings, but never \(w\). Universal truthfulness requires every deterministic realization to prevent a unilateral individual ranking misreport from increasing that individual's utility, for every profile of others' reports, including profiles that vary within types.
Does there exist an ordinal, universally truthful mechanism, computable in time polynomial in \(m,\tau,L,k\) on the supplied support representation, that returns rational feasible \(q\) and an individual assignment implementation with \(\mathbb E[W(q)]\ge\mathrm{OPT}(w)/2\) for every compatible metric when reports are truthful, or is this guarantee impossible?
For finite societies with \(N\) agents, \(2\le k\le N/2\), and \(k\mid N\), a polynomial-time ordinal universally truthful \(2\)-approximation for equal-size metric sum clustering is known ([original result](https://arxiv.org/pdf/1610.04069v2)); the guarantee is retained in a [later journal version](https://sekarshre.github.io/publication/ordinal_journal/ordinal_journal.pdf).
No result settling this precise atomless formulation was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted masses as atomless populations of individually assigned and individually strategic agents, rather than strategic representatives controlling entire types.
  • Made type identities and masses public and immutable; only rankings can be misreported. Truthfulness also covers reports varying within a type.
  • Specified individual utility as the integral of pairwise weights to the assigned cluster, matching the discrete aggregate utility.
  • Used a real-valued metric on types with zero diagonal and strict rankings that may order equal metric values arbitrarily.
  • Retained k at least two. The finite-agent upper bound and divisibility condition have no counterpart for an atomless population, so imposed no bound tying k to support size.
  • Required rational output masses and an implementation assigning each individual to one cluster; polynomial time is measured on compressed support inputs.
  • Set m equal to the number of supported types because these types are the ranked alternatives.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Resolved: a deterministic mechanism suffices

There exists a polynomial-time ordinal, universally truthful mechanism satisfying the requested guarantee. In fact, it achieves the stronger bound \(\mathbb E[W(q)]\ge \frac{k+1}{2k}\mathrm{OPT}(w)\).

The mechanism puts exactly one \(k\)-th of every type into each cluster. Its assignment uses fixed interval cuts and is independent of all reports.

1. Mechanism and individual implementation

For every \(t\in T\) and \(j\in\{1,\ldots,k\}\), output
\[ q^{\mathrm{mix}}_{tj}=\frac{\mu_t}{k}. \]

Use the standard mass-coordinate representation of type \(t\)'s interval, \(I_t=[0,\mu_t)\). Assign the individual with public coordinate \(x\in I_t\) to cluster \(j\) exactly when
\[ \frac{(j-1)\mu_t}{k}\le x<\frac{j\mu_t}{k}. \]
These half-open intervals partition \(I_t\), so every individual receives exactly one assignment. If the interval representation includes its right endpoint, assign that endpoint to cluster \(k\); this changes no masses.

The assignment is measurable and realizes \(q^{\mathrm{mix}}\). Moreover,
\[ \sum_{j=1}^kq^{\mathrm{mix}}_{tj}=\mu_t, \qquad \sum_{t\in T}q^{\mathrm{mix}}_{tj} =\frac{1}{k}\sum_{t\in T}\mu_t =\frac1k. \]
Thus the outcome is feasible.

2. Universal truthfulness

Define the mechanism on every individual report profile—including profiles varying within types—by the same fixed assignment above.

Fix any individual of true type \(t\), any reports of all other individuals, and any unilateral ranking misreport. Both the individual's assigned cluster and every cluster's type masses remain unchanged. Consequently, the individual's utility remains unchanged.

More explicitly, their utility in every cluster is
\[ \sum_{u\in T}q^{\mathrm{mix}}_{uj}w_{tu} =\frac1k\sum_{u\in T}\mu_u w_{tu}. \]
Hence no unilateral misreport can increase utility. The mechanism is deterministic and truthful, and therefore universally truthful when viewed as a distribution concentrated on one deterministic mechanism. It is ordinal because it requires no cardinal information.

3. A metric upper bound on every feasible outcome

Write \(s=1/k\), and define
\[ D=\sum_{t,u\in T}\mu_t\mu_u w_{tu}. \]
Fix an arbitrary feasible outcome \(q\). For each cluster \(j\), define
\[ I_j=\sum_{t,u\in T}q_{tj}q_{uj}w_{tu}, \qquad r_{vj}=\mu_v-q_{vj}, \qquad B_j=\sum_{t,v\in T}q_{tj}r_{vj}w_{tv}. \]

Feasibility implies \(r_{vj}\ge0\), \(\sum_tq_{tj}=s\), and \(\sum_vr_{vj}=1-s\). Multiplying the triangle inequality \(w_{tu}\le w_{tv}+w_{vu}\) by the nonnegative quantity \(q_{tj}q_{uj}r_{vj}\) and summing gives
\[ \begin{aligned} (1-s)I_j &=\sum_{t,u,v\in T}q_{tj}q_{uj}r_{vj}w_{tu}\\ &\le\sum_{t,u,v\in T}q_{tj}q_{uj}r_{vj}(w_{tv}+w_{vu})\\ &=2sB_j. \end{aligned} \]
For the last equality, sum over \(u\) in the first term and over \(t\) in the second, then use symmetry of \(w\).

Let \(S=\sum_j I_j=2W(q)\). The row-sum constraints yield
\[ \begin{aligned} \sum_{j=1}^k B_j &=\sum_{t,v\in T}w_{tv} \sum_{j=1}^kq_{tj}(\mu_v-q_{vj})\\ &=\sum_{t,v\in T}\mu_t\mu_vw_{tv} -\sum_{j=1}^k\sum_{t,v\in T}q_{tj}q_{vj}w_{tv}\\ &=D-S. \end{aligned} \]
Summing the cluster inequalities therefore gives
\[ (1-s)S\le2s(D-S). \]
Rearranging,
\[ (1+s)S\le2sD, \qquad W(q)\le\frac{sD}{1+s}=\frac{D}{k+1}. \]

This holds for every feasible outcome. The feasible set is nonempty and compact, and \(W\) is continuous, so its maximum exists and satisfies
\[ \mathrm{OPT}(w)\le\frac{D}{k+1}. \]

4. Approximation guarantee

For the mechanism's outcome,
\[ W(q^{\mathrm{mix}}) =\frac12\sum_{j=1}^k\sum_{t,u\in T} \frac{\mu_t\mu_u}{k^2}w_{tu} =\frac{D}{2k}. \]
Combining this identity with the upper bound proves
\[ W(q^{\mathrm{mix}}) \ge\frac{k+1}{2k}\mathrm{OPT}(w) \ge\frac12\mathrm{OPT}(w). \]
Since the mechanism is deterministic, its expected welfare equals its welfare. The proof applies to every metric on \(T\), and thus to every metric compatible with the truthful rankings.

5. Polynomial bit complexity

Write an input mass as \(\mu_t=a_t/b_t\), with positive integers encoded in binary. Each output entry is \(a_t/(kb_t)\), and each assignment boundary is \(ja_t/(kb_t)\). Their bit lengths are bounded by the input encoding length of \(\mu_t\) plus \(O(\log k)\).

The mechanism outputs \(mk\) rational entries and a finite description of the interval assignment. Computing all entries and boundaries uses polynomially many bit operations in \(m,\tau,L,k\). It requires no expansion into individual agents.

The finite results cited in the question use random equal-size partitions ([original, Theorem 4.6](https://arxiv.org/pdf/1610.04069v2), [journal, Theorem 5.1](https://sekarshre.github.io/publication/ordinal_journal/ordinal_journal.pdf)). Exact splitting within each atomless type provides the deterministic construction proved here.
