The continuous mirror question, as graded

Given a finite hospital set \(H\), supported resident types \(T\), binary-rational type masses \(\mu_t\), binary-rational hospital capacities \(\kappa_h\), strict resident preference lists, and a feasible binary-rational mass matching \(x_{t,h}\) (including an unmatched option), do there exist at most two complete strict rankings of \(T\), assignable to the hospitals, such that the matching has no blocking type pair? A pair \((t,h)\) blocks if positive mass of type \(t\) is assigned to an option it likes less than \(h\), and \(h\) either has positive spare capacity or assigns positive mass to a type ranked below \(t\).

Packaged proof task (what the prover saw — nothing else)

Let \(H\) be a nonempty hospital set, with \(m=|H|\). A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Distinct types may have identical preferences.
Each type \(t\) has a strict preference list over an acceptable subset \(A_t\subseteq H\), with every listed hospital preferred to the unmatched option \(\bot\). Each hospital has positive binary-rational capacity \(\kappa_h\).
The input includes a fixed binary-rational matching \(x_{t,o}\geq0\), for \(o\in H\cup\{\bot\}\), satisfying \(\sum_o x_{t,o}=\mu_t\), \(\sum_t x_{t,h}\leq\kappa_h\), and \(x_{t,h}=0\) whenever \(h\notin A_t\). Types may split their mass among options.
A solution consists of at most two complete strict rankings of \(T\), with each hospital adopting one ranking for all its capacity; all types are acceptable to hospitals. Under the adopted ranking, \((t,h)\) blocks precisely when \(h\in A_t\), some \(o\) with \(x_{t,o}>0\) is worse than \(h\) for \(t\), and either \(\sum_s x_{s,h}<\kappa_h\) or some \(s\) with \(x_{s,h}>0\) is ranked below \(t\) by \(h\).

Is deciding whether such rankings exist with no blocking pair solvable in polynomial time in \(m,\tau,L\), where \(L\) is the total input bit length, or is it NP-hard?

For individual residents and an integral matching, the corresponding decision problem with at most two hospital rankings is NP-complete even when every hospital has capacity one; with one ranking it is polynomial-time solvable. [Source](https://doi.org/10.2197/ipsjjip.23.202)
No result settling exactly the mass problem defined above was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive type masses to sum to one; capacities and matching entries use the same mass units.
  • Resident lists may be incomplete: only listed hospitals are acceptable, and every listed hospital is preferred to being unmatched. Unacceptable hospitals cannot receive mass or participate in blocking pairs.
  • Made feasibility explicit through nonnegative matching entries, conservation of each type's mass, and hospital capacity constraints.
  • Required positive hospital capacities and a nonempty hospital set; retained under-subscribed hospitals and their spare-capacity blocking condition.
  • Allowed distinct supported types to share resident preferences; hospital rankings distinguish the supplied types.
  • Specified that each hospital adopts one complete strict ranking for its entire capacity, while the fixed matching may split a type's mass among options.

Result

The decision problem is NP-complete, even when all masses and capacities are equal dyadic rationals and the fixed matching assigns every type entirely to one option.

The integral hardness result transfers by representing each resident as a separate type and scaling both assignments and capacities. Normalization does not change which pairs block.

1. Membership in NP

A certificate consists of two permutations of \(T\) and, for each hospital, a choice of which permutation to adopt. A solution using one ranking can be represented by repeating that ranking. The certificate has polynomial length.

For each hospital \(h\), define its load \(b_h=\sum_{s\in T}x_{s,h}\), its assigned-type set \(S_h=\{s\in T:x_{s,h}>0\}\), and its desiring-type set
\(D_h=\{t\in T:h\in A_t\text{ and }x_{t,o}>0\text{ for some option }o\text{ worse than }h\}\).

These sets are computable from the input in polynomial time. Under a proposed adopted ranking:

  • If \(b_h<\kappa_h\), hospital \(h\) participates in no blocking pair exactly when \(D_h=\varnothing\).
  • If \(b_h=\kappa_h\), hospital \(h\) participates in no blocking pair exactly when every \(s\in S_h\) precedes every \(t\in D_h\) with \(s\ne t\).

For the second assertion, a desiring type \(t\) blocks exactly when an assigned type is ranked below it. Every distinct assigned type must therefore precede \(t\). The exclusion \(s=t\) is necessary because a type cannot be ranked below itself, including when its mass is split.

Thus the certificate can be verified using polynomially many comparisons and exact rational operations. Adding and comparing input rationals takes polynomial bit complexity: a common denominator can be formed whose bit length is at most the sum of the input denominator bit lengths. Consequently, the problem belongs to \(\mathrm{NP}\).

2. The integral hardness theorem being used

Lee, Miyazaki, and Iwama define \(2\)-SHPL as follows: given individual residents, their strict preference lists over acceptable hospitals, hospital capacities, and a fixed integral matching, decide whether complete strict hospital preference lists of at most two kinds can make that matching stable. Their Theorem 2 establishes NP-completeness even when every hospital has capacity one. Completeness of the hospital lists means every resident is acceptable to every hospital, as required here. [Finding Witnesses for Stability in the Hospitals/Residents Problem, Sections 2.1 and 3.2](https://www.jstage.jst.go.jp/article/ipsjjip/23/2/23_202/_pdf).

We give a polynomial reduction from that capacity-one problem.

3. Construction of the normalized mass instance

Let a source instance have residents \(R=\{r_1,\ldots,r_n\}\), a nonempty hospital set \(H\), and fixed feasible integral matching \(M\). We may restrict to \(n\geq1\); the hardness theorem’s construction has positive numbers of residents and hospitals.

Let \(N=2^{\lceil\log_2 n\rceil}\), so \(n\leq N<2n\), and put \(\delta=1/N\).

Construct the target instance as follows.

  • For each resident \(r_i\), introduce a distinct type \(t_i\) with exactly the same acceptable hospitals and strict preferences.
  • Introduce \(N-n\) additional dummy types. Each dummy type has an empty acceptable set.
  • Give every type mass \(\mu_t=\delta\).
  • Retain the hospital set \(H\), and give every hospital capacity \(\kappa_h=\delta\).
  • For a real type \(t_i\), put its entire mass at \(M(r_i)\), interpreting an unmatched resident as assigned to \(\bot\). Put every dummy type’s entire mass at \(\bot\). Set all other matching entries to zero.

Here \(\tau=N\), and the total mass is \(N\delta=1\). All masses and capacities are positive dyadic rationals. Each row of the matching sums to its type’s mass. Since source hospitals have capacity one, each target hospital receives either zero mass or exactly \(\delta\). Every positive hospital assignment is acceptable to its type because \(M\) is feasible.

The construction therefore satisfies every target input requirement. Distinct residents remain distinct types even if their preferences coincide; the task explicitly permits this.

The output has polynomial size: \(\tau<2n\), each numerical entry uses \(O(\log n)\) bits, and even an explicitly written full matching matrix has only \(N(m+1)\) entries.

4. Blocking pairs are preserved exactly

Fix any complete ranking of the real types, identified with a ranking of the source residents. Extend it to all target types by placing the dummy types afterward in any fixed order.

Consider a real resident \(r_i\) and an acceptable hospital \(h\).

Resident-side condition. The only positive matching entry of \(t_i\) is at \(M(r_i)\). Hence some positive-mass option is worse than \(h\) exactly when \(r_i\) is unmatched or prefers \(h\) to its assigned hospital. This is precisely the source resident-side blocking condition.

Hospital-side condition. There are two cases.

  • If \(h\) is empty in \(M\), its target load is zero, which is strictly below \(\delta=\kappa_h\). Thus the vacancy condition holds in both instances.
  • If \(h\) is occupied by resident \(r_j\), its target load equals its capacity, and \(S_h=\{t_j\}\). Therefore the target hospital-side condition holds exactly when \(t_i\) is ranked above \(t_j\), equivalently when \(h\) ranks \(r_i\) above its source assignee.

It follows that \((t_i,h)\) blocks the target matching if and only if \((r_i,h)\) blocks the source matching under the corresponding adopted rankings.

A dummy type cannot form a blocking pair because it accepts no hospital.

We now obtain both directions of the reduction:

  • If the source has a stable solution using at most two complete rankings, extend each ranking by appending the dummy types and retain every hospital’s choice. Blocking-pair preservation proves that the target solution is stable.
  • If the target has a stable solution using at most two complete rankings, delete all dummy types from each ranking and retain every hospital’s choice. Restriction preserves comparisons between real types. Any source blocking pair would then produce a target blocking pair, so the resulting source solution is stable.

Thus the source instance is a yes-instance exactly when the constructed mass instance is a yes-instance.

5. Conclusion

The reduction is polynomial and preserves feasibility in both directions. Together with membership in \(\mathrm{NP}\), it proves that the stated mass problem is NP-complete. In particular, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
