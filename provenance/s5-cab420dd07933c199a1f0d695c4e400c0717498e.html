The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), a symmetric binary friendship matrix \(A\), and \(k\), compute a mass allocation \(x_{tj}\ge 0\) with \(\sum_j x_{tj}=\mu_t\) and \(\sum_t x_{tj}=1/k\). For \(U_t(j;x)=\sum_s A_{ts}x_{sj}\), require \(U_t(\ell;x)\le U_t(j;x)\) for every type \(t\), every occupied group \(j\) with \(x_{tj}>0\), and every group \(\ell\); also require that no coalition of mass \(1/k\), formed from masses \(y_{tj}\le x_{tj}\), gives each participating type \(t\) utility \(\sum_s A_{ts}\sum_j y_{sj}>kU_t(j;x)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge 1\) types with positive binary-rational masses \(\mu_t\) satisfying \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Mass is nonatomic and divisible.
Input also includes a symmetric matrix \(A\in\{0,1\}^{\tau\times\tau}\) and an integer \(k\ge 2\). Entries describe friendship between individuals of the indicated types; diagonal entries may describe friendship between distinct individuals of one type.
Find a rational allocation \(x_{tj}\ge 0\), for \(t\in T\) and \(j\in\{1,\ldots,k\}\), with \(\sum_jx_{tj}=\mu_t\) and \(\sum_tx_{tj}=1/k\). Define \(U_t(j;x)=\sum_sA_{ts}x_{sj}\).
Exact envy-freeness requires \(U_t(\ell;x)\le U_t(j;x)\) for every \(t,j,\ell\) with \(x_{tj}>0\); this compares utilities directly, without a swap or a change to group masses.
Membership in the \((k,0)\)-core requires that no real array \(y\) with \(0\le y_{tj}\le x_{tj}\) and \(\sum_{t,j}y_{tj}=1/k\) satisfies \(\sum_sA_{ts}\sum_hy_{sh}>kU_t(j;x)\) for every \((t,j)\) with \(y_{tj}>0\). Thus every participating portion must strictly improve by the prescribed factor; ties do not block.
Let \(L\) be the total input bit length and \(m=k\) the number of groups; state running times in \(m,\tau,L\).

Is computing an exactly balanced, exactly envy-free allocation in the \((k,0)\)-core polynomial-time solvable in \(k,\tau,L\), or is this search problem NP-hard?

For finite graphs with \(n\) vertices and maximum degree \(\Delta\ge 1\), an expected polynomial-time randomized algorithm achieves group sizes between \(\lfloor(1-\varepsilon)n/k\rfloor\) and \(\lceil(1+\varepsilon)n/k\rceil\), additive envy \(O(\max\{\sqrt{\Delta/k},k\}\ln(\Delta k/\varepsilon))\), and the \((k+\sqrt{k},O(k^{3/2}\ln(\Delta k/\varepsilon)))\)-core for \(6\sqrt{k\ln k/n}\le\varepsilon\le 1\); blocking coalitions obey the same size interval. Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The search problem is polynomial-time solvable. Divisibility allows every group to contain the same proportion of every type, and the resulting allocation satisfies the exact core condition.

Set \(m=k\) and output
\(x_{tj}=\mu_t/m\)
for every \(t\in T\) and \(j\in\{1,\ldots,m\}\). These entries are rational and positive.

For each type \(t\),
\(\sum_{j=1}^{m}x_{tj}=m(\mu_t/m)=\mu_t\).
For each group \(j\),
\(\sum_{t\in T}x_{tj}=(1/m)\sum_{t\in T}\mu_t=1/m\).
Thus the allocation satisfies both mass conservation and exact balance.

Define the total friend mass of type \(t\) by
\(d_t=\sum_{s\in T}A_{ts}\mu_s\).
For every group \(j\),
\(U_t(j;x)=\sum_{s\in T}A_{ts}(\mu_s/m)=d_t/m\).
Consequently, all groups give type \(t\) identical utility. Every required envy-freeness inequality holds with equality.

To verify the core condition, consider any real array \(y\) satisfying the stated coalition constraints, and write
\(z_s=\sum_{h=1}^{m}y_{sh}\).
Since \(0\le y_{sh}\le x_{sh}\), we have
\(0\le z_s\le\sum_{h=1}^{m}x_{sh}=\mu_s\).
Because every matrix entry is nonnegative, for every type \(t\) and group \(j\),
\(\sum_{s\in T}A_{ts}z_s\le\sum_{s\in T}A_{ts}\mu_s=d_t=mU_t(j;x)\).
Thus no participating portion can strictly improve by the prescribed factor. In particular, a coalition of mass \(1/m>0\) has a positive entry, and that entry cannot satisfy the blocking inequality. Hence the allocation belongs to the \((k,0)\)-core. This argument accommodates arbitrary real coalitions and diagonal friendship entries.

For the bit complexity, write each input mass as \(\mu_t=p_t/q_t\), with positive integers represented in binary. Output each entry as \(p_t/(mq_t)\); reduction to lowest terms is unnecessary. Each entry uses \(O(L+\log m)\) bits. Computing the denominators with elementary integer multiplication and explicitly writing all entries takes
\(O\!\left(L+\tau(L+\log m)^2+m\tau(L+\log m)\right)\)
bit operations. This is polynomial in \(m=k,\tau,L\), and the output length is \(O(m\tau(L+\log m))\).

The uniform allocation settles the stated problem for every allowed input; no approximation theorem is needed.
