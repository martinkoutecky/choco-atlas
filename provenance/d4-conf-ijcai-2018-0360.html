The continuous mirror question, as graded

Given a finite set of complete agent types \(\mathcal T\), rational masses \(\mu_\theta>0\) summing to one, and utilities \(u_\theta(\rho,s_\kappa)=v_\theta(\rho)+w_\theta(s_\kappa)\), choose nonnegative masses \(x_{\theta\kappa\rho}\) to maximize \(\min_{x_{\theta\kappa\rho}>0}u_\theta(\rho,s_\kappa)\), subject to \(\sum_{\kappa,\rho}x_{\theta\kappa\rho}=\mu_\theta\) for every \(\theta\) and \(\sum_\kappa x_{\theta\kappa\rho}=\sum_\lambda x_{\rho\theta\lambda}\) for every \(\theta,\rho\). Here \(x_{\theta\kappa\rho}\) is the mass of type-\(\theta\) agents who receive a service from type \(\kappa\) and supply their service to type \(\rho\); determine the optimum and its complexity in \(|\mathcal T|\) and the input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(\mathcal T\): the list of \(\tau\geq 1\) complete types with positive binary-rational masses \(\mu_\theta\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type \(\theta\) supplies a service labelled \(s_\theta\); there are \(m=\tau\) indexed service labels. Agents of the same type have identical utilities, given by binary-rational tables \(v_\theta(\rho)\) and \(w_\theta(s_\kappa)\), with arbitrary signs and ties allowed. Set \(u_\theta(\rho,s_\kappa)=v_\theta(\rho)+w_\theta(s_\kappa)\).
An allocation consists of real masses \(x_{\theta\kappa\rho}\geq 0\), representing type-\(\theta\) agents receiving service from type \(\kappa\) and supplying service to type \(\rho\), satisfying
\(\sum_{\kappa,\rho\in\mathcal T}x_{\theta\kappa\rho}=\mu_\theta\) for every \(\theta\in\mathcal T\), and \(\sum_{\kappa\in\mathcal T}x_{\theta\kappa\rho}=\sum_{\lambda\in\mathcal T}x_{\rho\theta\lambda}\) for every \(\theta,\rho\in\mathcal T\).
All triples are permitted, including exchanges within a type and retention of one's own service. Individual rationality is not required.
The objective is \(\operatorname{OPT}=\max_x\min\{u_\theta(\rho,s_\kappa):x_{\theta\kappa\rho}>0\}\). Let \(L\) be the total binary input length.

Is computing \(\operatorname{OPT}\) polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?

For finitely many agents, maximizing the minimum realized utility over bijections between agents and their endowed services is NP-hard even with additively separable utilities (Lesca and Todo, 2018).

Modeling choices made when packaging the task

  • Utility encoding was unspecified: use explicitly listed binary-rational component tables, permitting arbitrary signs as in the discrete real-valued domain and permitting ties as in the hardness construction.
  • The service-count parameter was unspecified: use one indexed service label per supported type, so m equals tau; labels need not have distinct utility values.
  • The domain of allocation masses was unspecified: allow nonnegative real masses to represent divisible populations.
  • Complete types mean that all agents within a type supply the same service label and have identical utility tables.
  • Make explicit that retention and exchanges within a type are allowed, and that no individual-rationality constraint is imposed, consistently with the discrete minimum-utility optimization problem.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Computing \(\operatorname{OPT}\) is polynomial-time solvable for the stated model with real, divisible masses. At any fixed utility threshold, feasibility is a rational linear-programming problem. The optimum can be found by searching the finitely many utility values.

1. The optimum belongs to a finite candidate set

Define
\[ c_{\theta\kappa\rho} = v_\theta(\rho)+w_\theta(s_\kappa), \qquad C=\{c_{\theta\kappa\rho}:\theta,\kappa,\rho\in\mathcal T\}. \]

Here and below, these are exact rational values. There are at most \(\tau^3\) distinct candidates.

Every feasible allocation satisfies
\[ \sum_{\theta,\kappa,\rho}x_{\theta\kappa\rho} = \sum_\theta\mu_\theta = 1. \]
Thus its positive support is nonempty, and its minimum realized utility is an element of \(C\).

The feasible set is also nonempty: set \(x_{\theta\theta\theta}=\mu_\theta\) for every \(\theta\), and set all other variables to zero. The mass constraints hold. For a balance constraint indexed by \((\theta,\rho)\), both sides equal \(\mu_\theta\) when \(\theta=\rho\), and both sides equal zero otherwise.

Consequently, the set of achieved objective values is a nonempty subset of the finite set \(C\). It therefore has a maximum, and \(\operatorname{OPT}\in C\). This establishes attainment without requiring continuity of the objective.

2. Threshold feasibility is linear programming

Fix a rational threshold \(q\), and define the allowed triples by
\[ A_q=\{(\theta,\kappa,\rho)\in\mathcal T^3: c_{\theta\kappa\rho}\geq q\}. \]

Consider the following rational linear feasibility problem. Introduce \(z_{\theta\kappa\rho}\geq0\) only for triples in \(A_q\), and impose:

\[ \sum_{\substack{\kappa,\rho\in\mathcal T\\ (\theta,\kappa,\rho)\in A_q}} z_{\theta\kappa\rho} = \mu_\theta \qquad (\theta\in\mathcal T), \]

\[ \sum_{\substack{\kappa\in\mathcal T\\ (\theta,\kappa,\rho)\in A_q}} z_{\theta\kappa\rho} - \sum_{\substack{\lambda\in\mathcal T\\ (\rho,\theta,\lambda)\in A_q}} z_{\rho\theta\lambda} = 0 \qquad (\theta,\rho\in\mathcal T). \]

Empty sums mean zero.

Claim. This linear program is feasible if and only if an allocation has minimum realized utility at least \(q\).

Proof. Suppose such an allocation \(x\) exists. Every triple with positive mass has utility at least \(q\), so every triple outside \(A_q\) has mass zero. Restricting \(x\) to \(A_q\) gives a feasible solution \(z\).

Conversely, extend a feasible \(z\) by assigning zero to every triple outside \(A_q\). The resulting \(x\) satisfies precisely the allocation constraints. Every positive coordinate belongs to \(A_q\), so every realized utility is at least \(q\). Its positive support is nonempty because its total mass is \(1\). This proves the claim.

In particular, the support condition introduces no strict inequalities into the feasibility problem.

3. Exact algorithm and polynomial running time

Use the standard polynomial-time theorem for rational linear programming: feasibility of a finite system of rational linear equalities and inequalities can be decided deterministically in time polynomial in its total binary encoding length. Equalities are permitted because each can be replaced by two inequalities.

Its hypotheses hold here:

  • There are at most \(\tau^3\) variables.
  • There are \(\tau+\tau^2\) equality constraints, together with nonnegativity constraints.
  • After cancellation, every constraint coefficient belongs to \(\{-1,0,1\}\).
  • The right-hand sides are the input masses and zeros.
  • The entire system has encoding length polynomial in \(\tau\) and \(L\).

The algorithm is therefore:

  • Compute all values \(c_{\theta\kappa\rho}\), remove duplicates, and sort them as \(q_1<\cdots<q_K\), where \(K\leq\tau^3\).
  • For a queried \(q_i\), solve the threshold feasibility problem above.
  • Return the largest feasible candidate.

Feasibility is monotone: if \(q_i\) is feasible, every smaller candidate is feasible. Binary search therefore uses at most \(O(\log(K+1))\) feasibility calls. The smallest candidate is feasible because it allows every triple and hence allows the diagonal allocation constructed in Section 1.

For completeness, candidate arithmetic is polynomial in the input length. Adding two binary-encoded rationals produces a rational with encoding length at most a constant multiple of their combined encoding length. Exact comparison uses integer cross-products of polynomial bit length. Thus candidate construction, sorting, threshold classification, and every linear-programming call all take polynomial time in \(\tau,L\).

By Section 1, the optimum is a candidate. By Section 2, a candidate is feasible exactly when an allocation achieves at least that value. Hence the returned candidate equals \(\operatorname{OPT}\). Since \(m=\tau\), this is polynomial time in \(m,\tau,L\).

4. Why finite-agent hardness does not transfer

The distinction is divisibility. For \(n\) equally weighted finite agents, the aggregate coordinates of a bijection necessarily satisfy \(n x_{\theta\kappa\rho}\in\mathbb Z_{\geq0}\). The present formulation allows arbitrary nonnegative real coordinates and imposes no such integrality conditions.

The cited finite-agent hardness therefore does not contradict the polynomial-time algorithm for this model.
