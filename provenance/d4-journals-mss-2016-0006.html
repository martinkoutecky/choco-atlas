The continuous mirror question, as graded

Given \(m\) alternatives, a rational distribution \(\mu\) supported on \(\tau\) rankings, and an explicitly listed subgroup \(U\le S_m\) of alternative relabelings, let \(U\mu=\{\psi\mu:\psi\in U\}\) and \(B(\nu)=\arg\max_{c}\sum_q\nu_q(m-\operatorname{rank}_q(c))\). Count and compactly describe the deterministic rules \(f:U\mu\to C\) satisfying \(f(\nu)\in B(\nu)\) and \(f(\psi\nu)=\psi f(\nu)\) for every \(\nu\in U\mu\) and \(\psi\in U\).

Packaged proof task (what the prover saw — nothing else)

Let \(C=\{1,\ldots,m\}\), with \(m\ge2\). Rankings are strict linear orders. A society is given by its support: the list of \(\tau\) distinct rankings with positive binary rational masses \(\mu_q\), summing to \(1\); \(\tau\) is the support size, not the number of possible rankings.
The input also lists every element of a subgroup \(U\le S_m\), each as a permutation of \(C\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L,|U|\).
Relabeling replaces each alternative \(c\) in a ranking by \(\psi(c)\), and \((\psi\nu)_q=\nu_{\psi^{-1}q}\), with unlisted rankings having mass zero. Let \(U\mu=\{\psi\mu:\psi\in U\}\), identifying equal distributions.
Let \(B(\nu)\) be the Borda winner set, retaining all score ties. Count exactly the distinct functions \(f:U\mu\to C\) satisfying \(f(\nu)\in B(\nu)\) and \(f(\psi\nu)=\psi f(\nu)\) for every \(\nu\in U\mu\) and \(\psi\in U\).
The computational output consists of the binary count and a list of the distinct functions, each represented by its value table on the distinct distributions in \(U\mu\).

Can this counting and description problem be solved in time polynomial in \(m,\tau,L,|U|\), or is it NP-hard under polynomial-time Turing reductions?

Result

The problem is polynomial-time solvable, including the complete list of functions.

Let
\[ \]
\(H=\operatorname{Stab}_U(\mu)=\{h\in U:h\mu=\mu\}\), and define
\(A=B(\mu)\cap\{c\in C:h(c)=c\text{ for every }h\in H\}\).

The exact count is \(|A|\). For each \(a\in A\), the corresponding function is
\(f_a(\psi\mu)=\psi(a)\).
In particular, there are at most \(m\) functions, each with at most \(|U|\) table entries.

We prove this characterization and give an exact polynomial-time algorithm.

1. Equivariance of Borda winners

Write a ranking as \(q=(q_1,\ldots,q_m)\), with the most preferred alternative first. Let \(\operatorname{pos}_q(c)\) be the position of \(c\) in \(q\). Use the Borda score
\(s_\nu(c)=\sum_q\nu_q\bigl(m-\operatorname{pos}_q(c)\bigr)\),
where the sum ranges over rankings with positive mass. Thus
\(B(\nu)=\{c\in C:s_\nu(c)=\max_{d\in C}s_\nu(d)\}\).

Relabeling preserves positions:
\(\operatorname{pos}_{\psi q}(\psi c)=\operatorname{pos}_q(c)\).
Moreover, the mass of \(\psi q\) in \(\psi\nu\) is \(\nu_q\). Consequently,
\(s_{\psi\nu}(\psi c)=s_\nu(c)\).

Since \(\psi\) is a bijection of \(C\), this proves
\(B(\psi\nu)=\psi B(\nu)\),
including all score ties.

2. Exact characterization of the functions

Relabeling defines a group action: for \(g,h\in U\),
\(g(h\nu)=(gh)\nu\).
In particular, \(H\) is a subgroup of \(U\).

Proposition. Evaluation at \(\mu\) gives a bijection between the requested functions and \(A\).

Necessity. Suppose \(f\) satisfies the requirements, and put \(a=f(\mu)\). The winner requirement gives \(a\in B(\mu)\). For every \(h\in H\), equivariance gives
\(a=f(\mu)=f(h\mu)=h f(\mu)=h(a)\).
Thus \(a\in A\).

Also, for every \(\psi\in U\),
\(f(\psi\mu)=\psi f(\mu)=\psi(a)\).
Therefore \(a\) determines the entire function uniquely.

Sufficiency. Fix \(a\in A\), and define \(f_a(\psi\mu)=\psi(a)\). Three checks are required.

  • Well-definedness. If \(\psi\mu=\phi\mu\), then applying \(\phi^{-1}\) gives \((\phi^{-1}\psi)\mu=\mu\). Hence \(\phi^{-1}\psi\in H\). Since \(a\) is fixed by every element of \(H\), we obtain \(\phi^{-1}\psi(a)=a\), and therefore \(\psi(a)=\phi(a)\).
  • Winner requirement. Since \(a\in B(\mu)\), Borda equivariance gives \(\psi(a)\in B(\psi\mu)\).
  • Equivariance. For \(g,\psi\in U\), the group action and the definition give

\(f_a(g(\psi\mu))=f_a((g\psi)\mu)=(g\psi)(a)=g f_a(\psi\mu)\).

Thus \(f_a\) satisfies both requirements. Finally, different \(a\)'s give different functions because \(f_a(\mu)=a\). This proves the proposition.

Consequently, the exact count is
\(N=\left|B(\mu)\cap\operatorname{Fix}_C(H)\right|\),
where \(\operatorname{Fix}_C(H)\) denotes the alternatives fixed by every element of \(H\). If this intersection is empty, the count is zero and the function list is empty.

3. Exact arithmetic for binary rational masses

Write the input masses as \(\mu_{q_i}=a_i/b_i\), with positive integers \(a_i,b_i\), for \(1\leq i\leq\tau\). Reduction to lowest terms is unnecessary.

Define
\(D=\prod_{i=1}^{\tau}b_i\)
and
\(w_i=a_i(D/b_i)\).

Each division is exact. We have
\(\mu_{q_i}=w_i/D\)
and
\(\sum_{i=1}^{\tau}w_i=D\).

The denominator bit lengths sum to at most \(L\), so \(D\) has at most \(L+1\) bits. Since the masses are positive and sum to one, each \(w_i\) satisfies \(1\leq w_i\leq D\).

Compute the integer Borda scores
\(S(c)=\sum_{i=1}^{\tau}w_i\bigl(m-\operatorname{pos}_{q_i}(c)\bigr)\).
These satisfy \(S(c)=D s_\mu(c)\). Multiplication by the positive integer \(D\) preserves every score comparison and tie, so their maximizers are exactly \(B(\mu)\).

Furthermore,
\(0\leq S(c)\leq(m-1)D\).
Thus all score calculations use integers with \(O(L+\log(m+1))\) bits. No expansion into \(D\) individual voters is needed.

4. Algorithm and output representation

Let \(n=|U|\). Use the following algorithm.

  • Compute \(D\), the integer weights \(w_i\), and \(B(\mu)\).
  • For every listed \(\psi\in U\), construct the support representation

\(\{(\psi q_i,w_i):1\leq i\leq\tau\}\),
with the shared denominator \(D\).

  • Compare these representations exactly, retaining one representative \(\psi_j\) for each distinct distribution \(\nu_j=\psi_j\mu\). This produces the complete orbit without duplicates.
  • Retain precisely those \(\psi\) whose transformed distribution equals \(\mu\). These permutations constitute \(H\).
  • Compute \(A\) by retaining the alternatives in \(B(\mu)\) fixed by every permutation in \(H\).
  • Output \(|A|\) in binary. For each \(a\in A\), output the table row

\((\psi_1(a),\ldots,\psi_r(a))\),
where \(r=|U\mu|\).

For step 3, exact equality can be checked by matching rankings and their integer weights. Relabeling is bijective on rankings, so every transformed support still consists of exactly \(\tau\) distinct rankings. Equal transformed supports with equal corresponding weights represent equal distributions, including their zero masses on unlisted rankings.

The output includes the ordered domain \((\nu_1,\ldots,\nu_r)\) once, represented by its support lists. Each row then specifies one function's value on every distinct distribution. The proposition proves that these rows list all requested functions exactly once.

5. Polynomial running time

Set \(k=\lceil\log_2(m+1)\rceil\) and \(K=L+k+2\).

A deliberately conservative bound for a straightforward implementation is
\(O\bigl(n^2\tau^2m^2K^2\bigr)\)
elementary bit operations, using schoolbook integer arithmetic and direct support comparisons. Explicitly:

  • Computing the common denominator and weights costs \(O(\tau K^2)\).
  • Computing all Borda scores costs \(O(m\tau K^2)\).
  • Constructing the transformed supports costs at most \(O(n\tau m^2k)\), even if permutation values are located by linear scans.
  • Comparing at most \(n^2\) pairs of transformed distributions costs \(O(n^2\tau^2(mk+K))\): compare every potentially matching pair of support rankings and weights.
  • Testing fixed alternatives and constructing all function tables costs at most \(O(nm^2k)\).

All these costs fit the displayed bound, which is polynomial in \(m,\tau,L,|U|\).

There are at most \(n\) distinct distributions and at most \(m\) functions. With the domain represented once, the output has size
\(O\bigl(n\tau(mk+K)+mnk+k\bigr)\)
bits. Thus the required explicit description also has polynomial size.

The related finite-profile framework appears in [Bubboloni–Gori](https://arxiv.org/html/1506.06069). The argument above handles the given rational distributions directly and permits arbitrary stabilizers.
