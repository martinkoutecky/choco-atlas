The continuous mirror question, as graded

Given an issue set \(PS_n\), a finite support \(T\) of utility types with positive rational masses \(\mu_t\) summing to \(1\), a satisfiable \(k\)-cube goalbase \(G_t\) with positive rational weights for each type, and a rational threshold \(B\), does there exist a package \(X \subseteq PS_n\) such that \(\sum_{t \in T}\mu_t \sum_{(\varphi,w)\in G_t:\,X\models\varphi} w \ge B\)? Equivalently, compute a package maximizing the population’s average utility.

Packaged proof task (what the prover saw — nothing else)

Let \(PS\) be a set of \(m\) Boolean issues, and fix an integer \(k\ge 2\). A package \(X\subseteq PS\) sets exactly the issues in \(X\) to true; every package is admissible.
A society is given by its support: a list \(T\) of \(\tau\) utility types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has an explicitly listed finite multiset \(G_t\) of weighted goals \((\varphi,w)\), with strictly positive binary rational weights. Each goal is individually satisfiable and is a conjunction of literals with at most \(k\) atom occurrences; negated literals and the empty conjunction \(\top\) are allowed. Goals need not be jointly satisfiable.
Given a binary rational threshold \(B\), decide whether some package satisfies \(\sum_{t\in T}\mu_t\sum_{(\varphi,w)\in G_t:\,X\models\varphi}w\ge B\), counting multiset occurrences separately.
Let \(L\) be the total binary input length, including all goal lists, masses, weights, and the threshold. State running times in \(m,\tau,L\), and \(k\).

Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard, for each fixed \(k\ge 2\)?

For a single utility function represented by positively weighted, individually satisfiable \(k\)-cubes, the threshold decision problem is \(\mathrm{NP}\)-complete for every fixed \(k\ge 2\). For goals restricted to literals, it is polynomial-time solvable.

  • Restricted k to fixed integers at least 2, matching the anchor's hardness regime.
  • Interpreted a satisfiable k-cube goalbase as requiring each goal individually to be satisfiable, without requiring joint satisfiability.
  • Specified that k bounds atom occurrences, allows negated literals, and permits the empty conjunction, following the supplied definitions.
  • Made goalbases explicit finite multisets and counted repeated goals separately.
  • Used m for the number of issues and L for the total binary input length.

Classification

For every fixed \(k\ge 2\), the problem is \(\mathrm{NP}\)-complete. Hardness already holds with support size \(\tau=1\). Thus it is polynomial-time solvable if and only if \(\mathrm{P}=\mathrm{NP}\).

Exact arithmetic and membership in \(\mathrm{NP}\)

Index all goal occurrences by \(j=1,\ldots,N\), preserving multiset multiplicities. Let \(t(j)\) be the type containing occurrence \(j\). Write the input rationals as \(\mu_t=a_t/b_t\), \(w_j=c_j/d_j\), and \(B=e/f\), with positive denominators. The numerator \(e\) may be negative.

Define the positive integer \(D=f\prod_{t\in T}b_t\prod_{j=1}^{N}d_j\). For each occurrence, define \(C_j=a_{t(j)}c_jD/(b_{t(j)}d_j)\), and define \(H=eD/f\). These are integers because each displayed denominator divides \(D\).

Multiplication by \(D>0\) shows that the required inequality is exactly equivalent to \(\sum_{j:\,X\models\varphi_j}C_j\ge H\). This transformation retains every multiset occurrence separately.

The sum of the binary lengths of all input denominators is at most \(L\), so \(D\) has \(O(L)\) bits. Each \(C_j\), \(H\), and every partial sum of the \(C_j\) also has \(O(L)\) bits: multiplication contributes at most the sum of the factor lengths, and summing \(N\le L\) terms adds at most \(O(\log L)\) bits. Consequently, using ordinary integer arithmetic, all these integers can be computed in \(O(\tau+L^3)\) bit operations.

A certificate specifies truth values for the distinct issues occurring in goals. There are at most \(L\) such issues, and the certificate extends to a package by setting all other issues false. A verifier evaluates each listed conjunction, adds its \(C_j\) when satisfied, and compares the sum with \(H\). An empty conjunction is always satisfied. Evaluation and summation take \(O(L^2)\) bit operations after preprocessing.

Thus verification takes \(O(\tau+L^3)\) bit operations and uses a certificate of polynomial length in \(L\). The problem belongs to \(\mathrm{NP}\).

Hardness for every fixed \(k\ge 2\)

Use the single-utility, positively weighted \(2\)-cube threshold problem whose \(\mathrm{NP}\)-completeness is given in the question.

Given an instance with issue set \(PS\), goal multiset \(G\), and threshold \(B\), construct a society with exactly one type \(t\), mass \(\mu_t=1\), and goal multiset \(G_t=G\). Keep \(PS\) and \(B\) unchanged.

Every required hypothesis holds:

  • The sole mass is a positive binary rational, and the masses sum to \(1\).
  • All goal weights remain strictly positive binary rationals.
  • Every goal remains individually satisfiable.
  • Each goal has at most \(2\le k\) atom occurrences.
  • Every package remains admissible.

For every package \(X\), the constructed objective equals the original utility: \(\sum_{t\in T}\mu_t\sum_{(\varphi,w)\in G_t:\,X\models\varphi}w=\sum_{(\varphi,w)\in G:\,X\models\varphi}w\).

Hence the original instance is a yes-instance exactly when the constructed instance is a yes-instance. The construction takes \(O(L)\) time and adds only constant encoding overhead. It proves \(\mathrm{NP}\)-hardness for every fixed \(k\ge2\), already at \(\tau=1\). Together with membership, this proves the classification.

Running times and the literal boundary

An explicit exhaustive algorithm performs the integer preprocessing above, then checks all \(2^m\) packages. A valid bit-operation bound is \(O(m+\tau+L^3+2^mL^2)\). More precisely, enumeration can be restricted to the \(r\le m\) issues appearing in goals, replacing \(2^m\) by \(2^r\). There is no additional dependence on \(k\) in these bounds because \(L\) already counts every literal occurrence.

For comparison, if goals are restricted to literals and empty conjunctions, let \(C_{\top}\) be the total scaled weight of empty goals, and let \(P_i\) and \(Q_i\) be the total scaled weights of positive and negative goals for issue \(i\). Then the maximum scaled utility is exactly \(C_{\top}+\sum_{i=1}^{m}\max\{P_i,Q_i\}\): each issue can independently be set to whichever value gives the larger contribution. Comparing this value with \(H\) decides that restriction in \(O(m+\tau+L^3)\) bit operations.
