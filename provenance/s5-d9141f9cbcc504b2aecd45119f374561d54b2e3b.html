The continuous mirror question, as graded

Given four additive valuation types of mass \(1/4\) over nine indivisible good categories, each with supply \(1/4\) per capita, does there exist a complete mass assignment of integral bundles such that every positive-mass type-bundle pair satisfies \(\mathrm{EFX}_0\) against every bundle receiving positive mass?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass encoded as a binary rational; \(\tau\) counts supported types, not possible types. Here \(\tau=4\), each type has mass \(1/4\), and total mass is \(1\).
There are \(m=9\) indivisible good categories, each with supply \(1/4\) per capita. Each type \(i\) has additive valuations specified by nonnegative binary rationals \(v_i(g)\); zero values and ties are allowed, with no valuation normalization.
An integral bundle is a subset \(B\subseteq G\), including the empty subset: a recipient receives at most one good of each category. A mass assignment consists of nonnegative real numbers \(x_{i,B}\).
Completeness means \(\sum_{B\subseteq G}x_{i,B}=1/4\) for each type \(i\), and \(\sum_i\sum_{B\ni g}x_{i,B}=1/4\) for each category \(g\).
The assignment satisfies \(\mathrm{EFX}_0\) if, whenever \(x_{i,B}>0\) and \(\sum_jx_{j,C}>0\), every \(g\in C\) satisfies \(v_i(B)\ge v_i(C\setminus\{g\})\). This includes comparisons within the same type and removal of zero-valued goods; empty target bundles impose no condition.
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\), retaining the restrictions \(m=9\) and \(\tau=4\).

Is deciding whether such a complete mass assignment exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For four discrete agents with nonnegative additive real valuations and at most nine goods, a complete \(\mathrm{EFX}_0\) allocation always exists. [Alkassar–Fouz–Mehlhorn](https://arxiv.org/html/2608.08590v1)

Theorem 1 of [Alkassar–Fouz–Mehlhorn](https://arxiv.org/html/2608.08590v1) states that four agents with nonnegative additive real valuations and at most nine goods admit a complete \(\mathrm{EFX}_0\) allocation. Its definition permits empty bundles and requires removal of zero-valued goods as well.

All hypotheses hold here: nonnegative binary rationals are nonnegative real numbers, there are exactly four agents and nine goods, and neither strict positivity nor normalization is required. Thus there is a partition \((A_1,A_2,A_3,A_4)\) of \(G\) such that, whenever \(i\ne j\) and \(g\in A_j\),

\(v_i(A_i)\ge v_i(A_j\setminus\{g\})\).

2. Transfer to a complete mass assignment

Define \(x_{i,A_i}=1/4\) for every type \(i\), and set every other \(x_{i,B}\) to zero.

Type completeness. Each type receives exactly one supported bundle, so \(\sum_{B\subseteq G}x_{i,B}=1/4\).

Category completeness. Since the bundles form a partition, every category \(g\) belongs to exactly one \(A_i\). Consequently, \(\sum_i\sum_{B\ni g}x_{i,B}=1/4\).

The full mass \(\mathrm{EFX}_0\) condition. Suppose \(x_{i,B}>0\) and \(\sum_jx_{j,C}>0\). By construction, \(B=A_i\), and \(C=A_j\) for some \(j\). For every \(g\in C\):

  • If \(j\ne i\), the required inequality follows from discrete \(\mathrm{EFX}_0\).
  • If \(j=i\), additivity and nonnegativity give \(v_i(B)-v_i(C\setminus\{g\})=v_i(g)\ge0\).

Empty target bundles impose no condition. This verifies every comparison required in the question, including comparisons within a type and removal of zero-valued goods.

Therefore the constructed assignment is complete and satisfies \(\mathrm{EFX}_0\).
