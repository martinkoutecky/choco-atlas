The continuous mirror question, as graded

Given a candidate set \(C\) of size \(m\), committee size \(k\), a decomposable committee scoring rule with polynomial-time computable rational component scores, a partial committee \(W\subseteq C\) with \(|W|<k\), and a society supported on \(\tau\) complete rankings \(t\), each with positive rational mass \(\mu_t\) summing to \(1\), define \(Q_\mu(S)=\sum_t\mu_t f_{m,|S|}(\operatorname{pos}_t(S))\) and \(Q_\mu(\varnothing)=0\). Compute, exactly, for every \(c\in C\setminus W\), \(B_\mu(c;k,W)=\sum_{S\subseteq C:\,W\subseteq S,\,|S|=k-1}\bigl(Q_\mu(S\cup\{c\})-Q_\mu(S)\bigr)\), and return a candidate maximizing this value. Is this computable in time polynomial in \(m\), \(\tau\), and the input bit length \(L\)?

A decomposable committee scoring rule is specified by binary rational tables \(\gamma^{(j)}_{m,s}:\{1,\ldots,m\}\to\mathbb Q\), for \(1\leq j\leq s\leq m\), each non-increasing; scores may have either sign. Define \(f_{m,s}(i_1,\ldots,i_s)=\sum_{j=1}^{s}\gamma^{(j)}_{m,s}(i_j)\) for increasing position tuples. No consistency between different committee sizes is required.
For nonempty \(S\subseteq C\), let \(\operatorname{pos}_t(S)\) be its members' positions in ranking \(t\), sorted increasingly, with position \(1\) best. Set \(Q_\mu(S)=\sum_t\mu_t f_{m,|S|}(\operatorname{pos}_t(S))\) and \(Q_\mu(\varnothing)=0\).

Result

The problem is polynomial-time solvable, including exact output of every value and a maximizing candidate. The proof below gives an explicit counting algorithm and bounds its bit complexity.

The cited paper establishes the corresponding discrete-election result in Theorem 2. Here we prove the rational-mass formulation directly, without expanding rational masses into voters. [Faliszewski, Lackner, Peters, and Talmon, *Effective Heuristics for Committee Scoring Rules*](https://martin.lackner.xyz/publications/effheur.pdf).

1. A counting lemma for aggregate committee scores

Fix a ranking \(t\), and write \(p_t(a)\) for the position of candidate \(a\). Define its individual committee score by

\(q_t(T)=f_{m,|T|}(\operatorname{pos}_t(T))\) for nonempty \(T\), and \(q_t(\varnothing)=0\).

For disjoint sets \(R,E\subseteq C\) and \(0\leq s\leq m\), define

\[ H_t(s;R,E)= \sum_{\substack{T\subseteq C\setminus E\\R\subseteq T,\ |T|=s}}q_t(T). \]

Thus \(R\) contains required candidates and \(E\) contains excluded candidates. We will evaluate this sum without enumerating committees.

Let \(F=C\setminus(R\cup E)\), the set of optional candidates. For each \(a\in C\setminus E\), define

\[ \begin{aligned} r_{<}(a)&=|\{b\in R:p_t(b)<p_t(a)\}|,\\ r_{>}(a)&=|\{b\in R:p_t(b)>p_t(a)\}|,\\ u_{<}(a)&=|\{b\in F:p_t(b)<p_t(a)\}|,\\ u_{>}(a)&=|\{b\in F:p_t(b)>p_t(a)\}|. \end{aligned} \]

Use the convention \(\binom{n}{h}=0\) when \(h<0\) or \(h>n\).

Lemma. For \(s\geq1\), the number of admissible committees in which \(a\) is the \(j\)-th best-ranked member is

\[ N_t(a,j;s,R,E)= \binom{u_{<}(a)}{j-1-r_{<}(a)} \binom{u_{>}(a)}{s-j-r_{>}(a)}. \]

Consequently,

\[ H_t(s;R,E)= \sum_{a\in C\setminus E}\sum_{j=1}^{s} \gamma^{(j)}_{m,s}(p_t(a))\,N_t(a,j;s,R,E). \tag{1} \]

For \(s=0\), \(H_t(0;R,E)=0\).

Proof. An admissible committee containing \(a\) must contain every candidate in \(R\). To make \(a\) its \(j\)-th best-ranked member, it must have exactly \(j-1\) members above \(a\) and \(s-j\) below it. The required candidates already supply \(r_{<}(a)\) and \(r_{>}(a)\) of these members. Therefore we must choose exactly

\[ j-1-r_{<}(a) \quad\text{and}\quad s-j-r_{>}(a) \]

optional candidates above and below \(a\), respectively.

These choices are independent because the two sets are disjoint. If \(a\) is optional, it is included separately; the strict position inequalities ensure that neither optional set contains \(a\). Each pair of choices therefore gives exactly one admissible committee, and every such committee gives exactly one pair. This proves the count, including impossible cases through the binomial convention.

By decomposability, each committee contributes \(\gamma^{(j)}_{m,s}(p_t(a))\) for its member \(a\) of committee rank \(j\). Summing these contributions and regrouping by \(a,j\) proves (1). At size zero, every contributing committee has score zero. \(\square\)

2. Expressing the restricted Banzhaf values

Fix \(c\in C\setminus W\). Coalitions containing \(c\) contribute zero, so

\[ B_\mu(c;k,W)= \sum_{\substack{S\subseteq C\setminus\{c\}\\W\subseteq S,\ |S|=k-1}} \bigl(Q_\mu(S\cup\{c\})-Q_\mu(S)\bigr). \]

The map \(S\mapsto S\cup\{c\}\) is a bijection from this coalition family to

\[ \{T\subseteq C:W\cup\{c\}\subseteq T,\ |T|=k\}. \]

Its inverse is \(T\mapsto T\setminus\{c\}\). Expanding \(Q_\mu\) and interchanging finite sums therefore gives

\[ B_\mu(c;k,W)= \sum_t\mu_t\Bigl( H_t(k;W\cup\{c\},\varnothing) - H_t(k-1;W,\{c\}) \Bigr). \tag{2} \]

Equations (1) and (2) are an explicit exact algorithm. They use the size-\(k\) and size-\((k-1)\) tables separately, so they require no consistency between committee sizes.

For \(k=1\), necessarily \(W=\varnothing\); the second aggregate is zero, and (2) gives \(B_\mu(c;1,\varnothing)=Q_\mu(\{c\})\). Thus this boundary case needs no size-zero scoring table.

3. Polynomial arithmetic-operation count

Precompute all binomial coefficients with upper argument at most \(m\) using Pascal’s recurrence. This takes \(O(m^2)\) integer additions.

For a fixed ranking and fixed \(R,E\), all four counts in the lemma can be computed in \(O(m)\) time by scanning the ranking and maintaining prefix counts. Formula (1) then has at most \(ms\) terms.

For each candidate, equation (2) requires two aggregates per ranking, with sizes at most \(k\). There are at most \(m\) candidates and \(\tau\) rankings. Hence, apart from reading and preparing the input, the algorithm uses

\[ O(m^2+\tau m^2k) \]

arithmetic operations. The exponentially many committees have been replaced by binomial counts.

4. Polynomial bit complexity and exact maximization

An arithmetic-operation bound alone is insufficient for binary rational input. We now bound all integer lengths.

Write each mass as \(\mu_t=a_t/b_t\), and each table entry as \(p_e/q_e\), with positive denominators. Let

\[ D=\left(\prod_t b_t\right)\left(\prod_e q_e\right), \]

where the second product ranges over all supplied table entries, including repeated denominator values as separate factors.

The sum of the denominator encoding lengths is at most \(L\), so \(D\) has \(O(L)\) bits. For every mass and table entry, \(b_tq_e\) divides \(D\). Thus

\[ G_{t,e}=a_tp_e\,\frac{D}{b_tq_e} \]

is an integer satisfying

\[ \mu_t\,\frac{p_e}{q_e}=\frac{G_{t,e}}{D}. \]

We can consequently evaluate (1) and (2) entirely with integer numerators over the common denominator \(D\).

Each input numerator has \(O(L)\) bits, so every \(G_{t,e}\) has \(O(L)\) bits. Moreover,

\[ \binom{n}{h}\leq 2^n \]

for valid arguments. In a coefficient \(N_t\), the two upper arguments satisfy \(u_{<}(a)+u_{>}(a)\leq m\); hence \(N_t\leq2^m\). Each scaled summand therefore has \(O(L+m)\) bits.

For one candidate, the numerator is a signed sum of at most \(2\tau mk\) such terms. Every intermediate partial sum has

\[ O\bigl(L+m+\log(\tau mk+1)\bigr) \]

bits, because its absolute value is bounded by the sum of the absolute values of its terms. Standard integer addition, multiplication, and exact division on these lengths take polynomial time. Constructing \(D\) and the scaled entries also takes polynomial time in the stated parameters.

Thus every output has a polynomial-length representation \(N_c/D\). Since \(D>0\), comparing the integers \(N_c\) determines a maximizing candidate exactly. Such a candidate exists because \(|W|<k\leq m\) implies \(C\setminus W\neq\varnothing\). Fractions may optionally be reduced using the polynomial-time Euclidean algorithm.

This proves polynomial-time solvability in \(m,\tau,k,L\). Signed scores cause no difficulty, and the algorithm does not require their assumed monotonicity.
