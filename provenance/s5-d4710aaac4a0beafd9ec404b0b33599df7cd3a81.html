The anchor (named result in the paper)

Theorem 7 — class: hardness

The continuous mirror question, as graded

Given finitely many lane types \(t\), each with binary-rational mass \(\mu_t\), unit processing cost \(c_t\), and match value \(z_t\), with equal proposer and receiver mass in each lane and no acceptable cross-lane pairs, choose processed mass \(x_t\) satisfying \(0\le x_t\le\mu_t\) and \(\sum_t c_t x_t\le B\). Does there exist such a choice with \(\sum_t z_t x_t\ge R\)? Each unit of processed mass yields an integral one-to-one match.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) lane types with positive binary-rational masses \(\mu_t\). Here \(\tau\) is the support size, not the number of possible types; there are \(m=\tau\) represented lanes. Masses need not sum to one. Let \(L\) be the total binary input length.
Each lane contains atomless proposer and receiver populations, each of mass \(\mu_t\). Only designated bilateral partners within that lane are acceptable, and both strictly prefer matching to remaining unmatched; there are no acceptable cross-lane pairs.
Initially no pair is authorized. Processing any mass \(x_t\in[0,\mu_t]\) authorizes equally much paired proposer and receiver mass, costs \(c_t x_t\), and yields match value \(z_t x_t\). Authorizations remain executable through settlement. Individuals receive whole one-to-one matches, but processed mass is divisible, with no integrality requirement on \(x_t\).
The unit costs \(c_t\), unit match values \(z_t\), budget \(B\), and threshold \(R\) are nonnegative integers encoded in binary. Decide whether there exist real masses \(x_t\) satisfying \(0\le x_t\le\mu_t\), \(\sum_t c_t x_t\le B\), and \(\sum_t z_t x_t\ge R\).

Is this continuous budgeted processing decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

The discrete budgeted recommendation problem is NP-complete, and its restriction to isolated bilateral pairs, empty initial consideration, and unit display capacity is weakly NP-complete. That restriction also admits a pseudo-polynomial algorithm and an FPTAS.

Modeling choices made when packaging the task

  • Specified costs, match values, budget, and threshold as nonnegative binary-encoded integers, following the discrete budgeted discovery definition.
  • Used unnormalized positive rational masses, since the discrete definition supplies population counts rather than probability normalization.
  • Interpreted integral one-to-one matches as whole matches for individuals in atomless populations; processed lane mass remains divisible and is not constrained to be an integer.
  • Specified designated bilateral partners within each lane, preserving the isolated-pair restriction rather than introducing additional acceptable partners.
  • Specified empty initial authorization and persistent execution rights through settlement, carrying over the discrete restriction and its cumulative settlement model.
  • Defined the requested size parameter m as the number of represented lanes, equal to the support size tau.

Conclusion

The problem is solvable in polynomial time by an exact fractional knapsack algorithm. Divisibility of the processed masses is essential: the algorithm may process only part of one lane.

Here \(m=\tau\), so the algorithm operates directly on the given support without enumerating any additional types.

Algorithm

First process every zero-cost lane completely. This is feasible and cannot decrease the value because all values are nonnegative. Their total contribution is

\(F=\sum_{t:c_t=0}z_t\mu_t.\)

Relabel the remaining \(n\) lanes, all of which have positive costs, in nonincreasing order of value per unit cost:

\(\dfrac{z_1}{c_1}\ge\dfrac{z_2}{c_2}\ge\cdots\ge\dfrac{z_n}{c_n}.\)

Define cumulative costs \(C_0=0\) and \(C_j=\sum_{i=1}^{j}c_i\mu_i\).

If \(C_n\le B\), process every lane completely. The maximum value is then

\(V^*=F+\sum_{i=1}^{n}z_i\mu_i.\)

This also covers \(n=0\).

Otherwise, let \(k\) be the smallest index such that \(C_k>B\). Then \(C_{k-1}\le B<C_k\). Set

\(x_i^*=\mu_i\) for \(i<k\), \(x_k^*=(B-C_{k-1})/c_k\), and \(x_i^*=0\) for \(i>k\).

Because \(c_k>0\) and \(C_k=C_{k-1}+c_k\mu_k\), we have \(0\le x_k^*<\mu_k\). The total cost of these positive-cost lanes is exactly \(B\), so the proposed processing is feasible. Its value is

\(V^*=F+\sum_{i<k}z_i\mu_i+\dfrac{z_k}{c_k}(B-C_{k-1}).\)

Return yes exactly when \(V^*\ge R\).

Proof of optimality

When \(C_n\le B\), processing all lanes is feasible. Every feasible vector satisfies \(z_tx_t\le z_t\mu_t\), because \(z_t\ge0\) and \(x_t\le\mu_t\). Thus full processing attains an upper bound on every feasible value.

Now suppose \(C_n>B\), and define \(\lambda=z_k/c_k\). In particular, \(\lambda\ge0\). Let \(y\) be any feasible processing vector.

The zero-cost lanes contribute at most \(F\). For the positive-cost lanes,

\(\sum_{i=1}^{n}z_i y_i=\lambda\sum_{i=1}^{n}c_i y_i+\sum_{i=1}^{n}(z_i-\lambda c_i)y_i.\)

Feasibility and \(\lambda\ge0\) bound the first term by \(\lambda B\). The ratio ordering gives:

  • For \(i<k\), \(z_i-\lambda c_i\ge0\), so \((z_i-\lambda c_i)y_i\le(z_i-\lambda c_i)\mu_i\).
  • For \(i=k\), \(z_i-\lambda c_i=0\).
  • For \(i>k\), \(z_i-\lambda c_i\le0\), so \((z_i-\lambda c_i)y_i\le0\), since \(y_i\ge0\).

Consequently, the value of \(y\), including its zero-cost lanes, is at most

\(F+\lambda B+\sum_{i<k}(z_i-\lambda c_i)\mu_i =F+\sum_{i<k}z_i\mu_i+\lambda(B-C_{k-1}) =V^*.\)

The constructed vector attains this bound. Hence \(V^*\) is the exact maximum, including when ratios are tied or some values are zero. Comparing it with \(R\) therefore decides the problem.

Binary running time

All computations can be performed with exact rational arithmetic.

Write each input mass as \(\mu_t=a_t/b_t\), with positive binary-encoded integers \(a_t,b_t\). A finite binary-fraction encoding can also be converted to this representation with polynomial overhead.

Sorting requires \(O(\tau\log\tau)\) comparisons. Each ratio comparison uses only integer cross-products:

\(\dfrac{z_i}{c_i}\ge\dfrac{z_j}{c_j}\quad\Longleftrightarrow\quad z_i c_j\ge z_j c_i.\)

These integers have bit lengths polynomial in \(L\).

To bound the subsequent arithmetic, take the common denominator \(Q=\prod_{t=1}^{\tau}b_t\). Its bit length is at most \(1+\sum_t\log_2 b_t\), hence \(O(L)\). Writing \(\mu_t=A_t/Q\), where \(A_t=a_t(Q/b_t)\), gives numerators of \(O(L)\) bits. Cumulative costs and values consequently have numerators of \(O(L+\log\tau)\) bits.

In the partial-lane case,

\(x_k^*=\dfrac{BQ-\sum_{i<k}c_iA_i}{Qc_k}.\)

The optimal value can likewise be represented using denominator \(Qc_k\), with numerator and denominator of polynomial bit length. Thus the comparison \(V^*\ge R\) is an exact integer comparison of polynomial size. Computing these quantities requires only polynomially many arithmetic operations on polynomial-length integers.

The complete algorithm therefore runs in polynomial time in \(m,\tau,L\).

Relation to the discrete problem

The stated NP-completeness results concern indivisible recommendations. Here the fractional lane amount \(x_k^*\) is explicitly permitted. The optimality proof above depends on that permission and fully resolves this continuous problem.

Thus the problem belongs to \(\mathrm{P}\); it cannot be NP-hard under polynomial-time many-one reductions unless \(\mathrm{P}=\mathrm{NP}\).
