The continuous mirror question, as graded

Given a capacitated shared supply network \(G\), a sink player \(r\), and \(\tau\) terminal types with rational masses \(\mu_t>0\), \(\sum_t\mu_t=1\), source locations \(s_t\), and per-agent demands \(d_t\), choose path flows \(x_{tP}\geq 0\) satisfying \(\sum_P x_{tP}\leq \mu_t d_t\) and the network capacities. Type \(t\)'s per-capita payoff is \(u_t=(\sum_P x_{tP})/\mu_t\), and the sink's payoff is total routed mass. Coalitions may include the sink and any submasses \(q_t\leq\mu_t\), routing their demands through the same network; coalitions without the sink have no commodities. Does there exist a polynomial-time algorithm, in the network size, \(\tau\), and input bit length, that computes a core allocation simultaneously maximizing the sink's payoff and \(\min_t u_t\) over feasible allocations?

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,E)\) be a finite undirected shared supply network, with \(m=|V|+|E|\), sink player \(r\in V\), and nonnegative binary-rational node capacities \(c_v\), counting endpoints as well as internal nodes.
A society is given by its support: the list of \(\tau\geq1\) terminal types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Each type has source \(s_t\in V\setminus\{r\}\) and nonnegative binary-rational per-agent demand \(d_t\). Let \(L\) be the total input bit length.
For each simple \(s_t\)-to-\(r\) path \(P\), choose divisible flows \(x_{tP}\geq0\) with \(\sum_Px_{tP}\leq\mu_td_t\) and \(\sum_t\sum_{P\ni v}x_{tP}\leq c_v\). Every member of type \(t\) receives \(u_t=\mu_t^{-1}\sum_Px_{tP}\); the sink receives \(R=\sum_t\sum_Px_{tP}\). There are no side payments.
A coalition consists of an optional sink and real submasses \(0\leq q_t\leq\mu_t\); it is nonempty and proper when it contains some player but omits the sink or a positive mass of terminal agents. Infrastructure is shared and is not itself a set of additional players.
With the sink present, coalition flows \(y_{tP}\geq0\) use the same entire network and original capacities, replacing demand bounds by \(q_td_t\). They block precisely when \(q_t^{-1}\sum_Py_{tP}>u_t\) for every \(t\) with \(q_t>0\), and \(\sum_t\sum_Py_{tP}>R\). Without the sink, all coalition payoffs are zero. An allocation is in the core if no such coalition blocks.
Write \(R^*=\max_xR(x)\) and \(F^*=\max_x\min_tu_t(x)\), taking both maxima separately over all feasible allocations.

Is computing a core allocation satisfying simultaneously \(R=R^*\) and \(\min_tu_t=F^*\) possible in time polynomial in \(m,\tau,L\), or is this computational problem NP-hard?

For finite node players with single-sink demands, a polynomial-time algorithm computes a core allocation simultaneously maximizing social welfare and minimum payoff. [Beeson–Shepherd](https://arxiv.org/pdf/2001.09911v2).
No result settling the precise submass-coalition problem above was located in the literature search.

  • Specified an undirected network with node capacities charged at all vertices of each simple path, including endpoints, following the discrete flow definition.
  • Specified nonnegative binary-rational capacities and demands; zero capacities and zero demands remain permitted.
  • Required at least one supported terminal type and excluded sources equal to the sink; multiple types may share a source.
  • Made the graded question's shared-network convention explicit: infrastructure is available to every coalition at its original capacities and introduces no additional players.
  • Specified real coalition submasses, nonempty proper coalitions, and strict improvement for every participating type and the sink, following the discrete core's strict blocking convention.
  • Interpreted per-capita payoffs as uniform within each type, including participating submasses.
  • Defined simultaneous maximization using the two separate unrestricted feasible optima, rather than a lexicographic objective.
  • Defined network size and total input bit length for the running-time target.

Result

The problem is polynomial-time solvable in \(m,\tau,L\). A core allocation attaining both separately defined optima always exists and can be computed exactly.

The proof has two main ingredients: every maximum-throughput allocation belongs to the stated core, and any feasible vector of type totals can be increased coordinatewise to a maximum-throughput vector.

1. Maximum throughput implies core membership

Let \(x\) be a feasible allocation with \(R(x)=R^*\). All terminal payoffs are nonnegative.

A nonempty coalition without the sink cannot block: its members receive zero, which cannot strictly improve their nonnegative payoffs.

Now consider a coalition containing the sink, with submasses \(q_t\), and any feasible coalition flow \(y\). Since \(d_t\) is nonnegative and \(q_t\leq\mu_t\), its demand bounds satisfy
\[ \sum_P y_{tP}\leq q_td_t\leq\mu_td_t. \]
Its paths and node-capacity constraints are exactly those available to the full society. Consequently, \(y\) is also a feasible allocation for the full society, and hence
\[ \sum_t\sum_P y_{tP}\leq R^*. \]
The sink therefore cannot strictly improve on \(R(x)=R^*\).

Thus every feasible allocation with \(R=R^*\) belongs to the core, including against coalitions with arbitrary real submasses. This argument does not require the coalition to be proper.

2. A polynomial-size flow representation

Write \(D_t=\mu_td_t\) and \(D=\sum_tD_t\). If \(D=0\), every feasible allocation is zero, so \(R^*=F^*=0\); the zero allocation solves the problem. Assume henceforth that \(D>0\).

Construct a directed network \(H\), with source \(\sigma\) and sink \(\omega=r^{\mathrm{out}}\), as follows.

  • Replace each \(v\in V\) by \(v^{\mathrm{in}},v^{\mathrm{out}}\), joined by an arc of capacity \(c_v\).
  • For each undirected edge \(\{u,v\}\), add an arc \(u^{\mathrm{out}}\to v^{\mathrm{in}}\) of capacity \(D\) when \(u\ne r\), and an arc \(v^{\mathrm{out}}\to u^{\mathrm{in}}\) of capacity \(D\) when \(v\ne r\).
  • For each supported type \(t\), introduce a vertex \(a_t\) and arcs

\(\sigma\to a_t\) and \(a_t\to s_t^{\mathrm{in}}\), each of capacity \(D_t\).

Let \(e_t\) denote the arc \(\sigma\to a_t\). A feasible flow obeys arc capacities and conservation at every vertex other than \(\sigma,\omega\). There are no arcs entering \(\sigma\) or leaving \(\omega\).

The network has \(O(|V|+\tau)\) vertices and \(O(m+\tau)\) arcs. Separate type vertices preserve type identities even when several types have the same source.

Representation claim. A vector \(z=(z_t)\) is attainable as the type totals of an allocation in the original problem if and only if \(H\) has a feasible flow \(f\) with \(f(e_t)=z_t\).

To prove the forward direction, send each original path flow along its corresponding split-vertex path, preceded by \(\sigma\to a_t\to s_t^{\mathrm{in}}\). The split arc at \(v\) carries precisely the total original flow using \(v\), so its capacity is respected, including at sources and the sink. Each connector arc carries at most the total flow, which is at most \(D\).

For the converse, first remove directed cycles from \(f\): subtract the minimum flow on a positive directed cycle, repeating until no such cycle remains. Each subtraction eliminates at least one positive arc and increases none. No directed cycle contains \(\sigma\), so every \(f(e_t)\) is preserved.

Decompose the remaining flow into simple \(\sigma\)-to-\(\omega\) paths. Such a path starts with exactly one \(e_t\), then visits \(a_t\) and \(s_t^{\mathrm{in}}\). Every visit to an original vertex uses its split arc. Simplicity of the directed path therefore prevents any original vertex from being visited twice. Removing the auxiliary vertices gives a simple \(s_t\)-to-\(r\) path.

The resulting path allocation has type totals \(f(e_t)\). Its node usage is bounded by the flow on the corresponding split arcs, and therefore by \(c_v\). This proves the claim.

In particular, the flow value is \(R=\sum_tf(e_t)\), and type \(t\)'s payoff is \(u_t=f(e_t)/\mu_t\).

3. Coordinatewise extension to maximum throughput

Lemma. For every feasible flow \(f\) in \(H\), there exists a globally maximum-value feasible flow \(g\) satisfying \(g(e_t)\geq f(e_t)\) for every type \(t\).

Proof. Among all feasible flows satisfying these additional lower bounds, choose one, \(g\), of maximum value. Such a flow exists: the feasible set contains \(f\), is closed, and is bounded by the finite arc capacities.

For each original arc \(b:p\to q\), its residual network has:

  • a forward arc \(p\to q\) when its residual capacity \(C_b-g(b)\) is positive;
  • a reverse arc \(q\to p\) when \(g(b)\) is positive, with residual capacity \(g(b)\).

Suppose there is a residual path from \(\sigma\) to \(\omega\). Removing repetitions gives a simple residual path. Augmenting by the positive minimum residual capacity along this path gives another feasible flow of strictly greater value.

Every reverse residual arc corresponding to \(e_t\) enters \(\sigma\). A simple path starting at \(\sigma\) cannot use such an arc, since it would revisit \(\sigma\). Thus augmentation does not decrease any \(g(e_t)\). It preserves all the additional lower bounds, contradicting the choice of \(g\).

There is consequently no residual \(\sigma\)-to-\(\omega\) path. Let \(S\) be the vertices reachable from \(\sigma\) in the residual network. Then \(\omega\notin S\). Every original arc leaving \(S\) is saturated; every original arc entering \(S\) has zero flow, because otherwise its reverse residual arc would make its tail reachable.

Summing conservation over \(S\) shows that the value of \(g\) equals the capacity of the cut leaving \(S\). Every feasible flow has value at most that capacity. Hence \(g\) is globally maximum, proving the lemma. \(\square\)

By the representation claim, this also proves that every feasible allocation admits a maximum-throughput allocation whose payoff to each type is at least its original payoff. Paths may be rerouted during this extension.

4. Computing and attaining both optima

Solve the following rational linear program. Its variables are an arc flow \(f\) in \(H\) and a scalar \(\lambda\):

Maximize \(\lambda\), subject to:

  • \(f\) being feasible in \(H\);
  • \(\lambda\geq0\);
  • \(f(e_t)\geq\mu_t\lambda\) for every type \(t\).

The representation claim and the positivity of every \(\mu_t\) imply that its optimum is exactly \(F^*\). Indeed, its constraints are equivalent to requiring \(u_t\geq\lambda\) for all supported types.

Let \(f^F\) be an optimal flow. Apply the extension lemma to obtain a maximum-value flow \(g\) with \(g(e_t)\geq f^F(e_t)\) for all \(t\). Then
\[ \frac{g(e_t)}{\mu_t}\geq \frac{f^F(e_t)}{\mu_t}\geq F^*. \]
Its corresponding allocation has \(R=R^*\) and minimum payoff at least \(F^*\). Since \(F^*\) was defined as the maximum minimum payoff over all feasible allocations, that minimum must equal \(F^*\).

To compute such a flow directly, solve a second rational linear program:

Maximize \(\sum_tf(e_t)\), subject to \(f\) being feasible in \(H\) and \(f(e_t)\geq\mu_tF^*\) for every \(t\).

The preceding extension argument proves that this program contains a globally maximum-value flow. Every optimizer therefore yields both required equalities. Section 1 proves its core membership.

5. Exact polynomial-time complexity and output

Both programs have \(O(m+\tau)\) variables and constraints.

All their coefficients have polynomial encoding length in the input size. In particular, the products \(D_t=\mu_td_t\) and their sum \(D\) can be computed with polynomial bit length. The first feasible region is nonempty, since zero flow with \(\lambda=0\) is feasible. It is bounded: arc flows have finite capacity bounds, and \(\lambda\leq d_t\) for every \(t\). The second region is nonempty by the first optimizer and is also bounded.

The standard exact rational linear-programming theorem therefore applies: these programs can be optimized, returning rational optimizers of polynomial encoding length, in time polynomial in their dimensions and coefficient encoding length. In particular, \(F^*\), used in the second program, has polynomial encoding length.

Finally, convert the second optimizer into the requested path allocation using the cycle removal and path decomposition from Section 2. Each subtraction eliminates at least one positive arc without introducing any new positive arc. Thus only \(O(m+\tau)\) paths need be output, each of polynomial length.

These operations also preserve polynomial bit complexity. A common denominator for the optimizer's arc values has polynomial bit length; all subsequent subtractions and extracted path weights can use that denominator.

The resulting exact allocation is computable in time polynomial in \(m,\tau,L\), belongs to the core, and satisfies simultaneously \(R=R^*\) and \(\min_tu_t=F^*\).

6. Relation to the cited result

The proof of Theorem 2 in [Beeson–Shepherd](https://arxiv.org/pdf/2001.09911v2) also uses extension of single-sink flows without decreasing terminal totals. The argument above explicitly handles mass-weighted fairness, repeated source locations, endpoint capacities, exact bit complexity, and the stipulated real-submass coalitions.
