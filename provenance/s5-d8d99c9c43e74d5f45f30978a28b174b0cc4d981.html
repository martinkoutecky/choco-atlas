Result

The explicitly listed mass-assignment problem is polynomial-time solvable, including infeasibility detection and computation of an exact optimal assignment.

The algorithm uses at most \(O(1+\log(M+1))\) rational linear-programming calls. The essential observation is that requiring a fairness threshold simply forbids traces whose credited-goal counts fall below it.

1. Fairness thresholds are linear constraints

Let \(\mathcal I=\{(i,p):1\le i\le\tau,\ p\in P_i\}\), and define each trace’s score by

\(H_{ip}=\sum_{j=1}^{m}h_{ipj}\).

Let \(K\) denote the feasible set specified in the question. For every \(x\in K\),

\(\sum_{(i,p)\in\mathcal I}x_{ip}=\sum_{i=1}^{\tau}\mu_i=1\).

Consequently, the support of \(x\) is nonempty, and \(F(x)\) is well-defined.

For a threshold \(q\), define

\(K(q)=\{x\in K:x_{ip}=0\text{ whenever }H_{ip}<q\}\).

Threshold lemma. For every feasible assignment \(x\),

\(F(x)\ge q\quad\Longleftrightarrow\quad x\in K(q)\).

Proof. If \(F(x)\ge q\), every trace receiving positive mass has score at least \(q\). Thus every trace with score below \(q\) receives zero mass. Conversely, if those traces receive zero mass, every trace in the nonempty support has score at least \(q\), so its minimum score is at least \(q\). \(\square\)

In particular, testing whether fairness at least \(q\) is achievable is precisely the feasibility test for the following rational linear system, with variables only for traces satisfying \(H_{ip}\ge q\):

  • \(x_{ip}\ge0\);
  • \(\sum_{p\in P_i:H_{ip}\ge q}x_{ip}=\mu_i\), for each type \(i\);
  • \(\sum_{(i,p):H_{ip}\ge q}x_{ip}h_{ipj}=d_j\), for each template \(j\);
  • \(\sum_{(i,p):H_{ip}\ge q}x_{ip}a_{ipr}\le b_r\), for each resource \(r\).

An empty sum is zero. Hence, if a supported type has no remaining trace, its positive mass makes this system infeasible.

2. Computing the maximum fairness

If some \(P_i\) is empty, the instance is immediately infeasible because \(\mu_i>0\). Otherwise, let

\(q_1<q_2<\cdots<q_t\)

be the distinct scores among all listed traces. Here \(1\le t\le M\).

Every feasible assignment satisfies

\(F(x)\in\{q_1,\ldots,q_t\}\),

because its fairness is the minimum of a nonempty subset of the listed scores. Moreover,

\(K(q_1)=K\),

and, whenever \(q\le q'\),

\(K(q')\subseteq K(q)\).

The algorithm therefore proceeds as follows:

  • Test feasibility of \(K(q_1)\). If it is empty, report infeasibility.
  • Otherwise, binary-search the ordered scores to find the largest index \(k\) for which \(K(q_k)\) is nonempty.
  • Set \(F^\star=q_k\).

Correctness. Every feasible assignment has fairness equal to a listed score. If an assignment had fairness \(q_\ell>q_k\), the threshold lemma would imply that \(K(q_\ell)\) is nonempty, contradicting maximality of \(k\).

Conversely, any \(x\in K(q_k)\) has \(F(x)\ge q_k\). Its fairness cannot exceed \(q_k\) by the preceding argument. Thus \(F(x)=q_k\), proving both optimality and attainment.

This search uses the number of listed scores, rather than their numerical magnitudes. Binary-encoded goal counts can therefore be large without causing a pseudopolynomial search.

3. Computing the minimum cost at optimal fairness

Solve the rational linear program

\(\min_{x\in K(F^\star)}\sum_{(i,p)\in\mathcal I}x_{ip}c_{ip}\).

The preceding proof establishes the exact identity

\(K(F^\star)=\{x\in K:F(x)=F^\star\}\).

Thus this program minimizes cost among precisely the assignments attaining maximum fairness.

To verify attainment, observe that every feasible coordinate satisfies

\(0\le x_{ip}\le\mu_i\le1\).

The set \(K(F^\star)\) is defined by finitely many linear equalities and non-strict inequalities, so it is closed. It is also bounded and nonempty. Hence it is compact, and the linear cost function attains a finite minimum on it.

The standard polynomial-time theorem for rational linear programming supplies exact feasibility detection and an exact rational optimum when the optimum exists and is finite. Its hypotheses hold here: the constraints and objective have rational coefficients with finite binary encodings. See [Khachiyan’s polynomial algorithms for linear programming](https://www.sciencedirect.com/science/article/abs/pii/0041555380900610).

Although assignments are allowed to use real masses, the algorithm can consequently return a rational optimal assignment. Its denominators need not be powers of two.

4. Running time and bit complexity

Define \(T_{\mathrm{LP}}(n,k,B)\) to be a polynomial bit-time bound for exact rational linear programming with at most \(n\) variables, at most \(k\) inequality rows, and total encoding length at most \(B\).

Each program above has at most \(M\) variables. After replacing each equality with two inequalities and counting nonnegativity constraints, it has at most

\(k=2(\tau+m)+R+M\)

inequality rows.

Restricting the menu uses existing coefficients. A dense encoding, including the type-membership coefficients and nonnegativity rows, has length bounded by

\(B=O\!\left(L+M(\tau+m+R+M+1)\right)\).

This bound allows for explicitly writing zero and unit coefficients; it is polynomial in all the requested parameters.

All scores have \(O(L)\) bits. A conservative bound for computing them and sorting the distinct values is

\(O\!\left(mML+ML\log(M+1)\right)\)

bit operations. There are one initial feasibility call, \(O(\log(M+1))\) further feasibility calls, and one cost-optimization call. Including construction of their encodings, the total time is bounded by

\(O\!\left(mML+ML\log(M+1)+(1+\log(M+1))\left[B+T_{\mathrm{LP}}(M,k,B)\right]\right)\).

In particular, writing \(S=M+m+\tau+R+L+1\), this is

\(O\!\left((1+\log(M+1))S^{O(1)}\right)\)

bit time. The returned optimal masses and cost have polynomial-length rational encodings.

This is a polynomial bound in the binary input size; no claim of strongly polynomial running time is needed.
