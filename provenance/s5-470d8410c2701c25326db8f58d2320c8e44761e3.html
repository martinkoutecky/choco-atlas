The continuous mirror question, as graded

Given finite job types \(A\) and machine types \(B\), acceptable type pairs, strict type rankings, rational job masses \(\mu_a\), rational machine masses \(\rho\nu_b\), job sizes \(q_a\), and capacities \(Q_b\), decide whether one can compute a machine-optimal stable distribution of integral local configurations in time polynomial in the support size and input bit length. A configuration \(S\) assigns an integer number \(n_a(S)\) of jobs of each type to one machine; rational masses \(z_{b,S}\) must satisfy \(\sum_S z_{b,S}=\rho\nu_b\) and \(\sum_{b,S}z_{b,S}n_a(S)\le\mu_a\). Each configuration must satisfy the paper’s relaxed capacity condition, and if positive mass of type-\(a\) jobs prefers type \(b\) to its assignment, every configuration used by type-\(b\) machines must have at least \(Q_b\) load from types they rank above \(a\). Among stable outputs, require the machine-type configuration distribution to stochastically dominate every alternative under the stated lexicographic configuration order.

Packaged proof task (what the prover saw — nothing else)

Let \(A,B\) be nonempty finite sets of job and machine types, with \(m=|B|\), acceptable pairs \(E\subseteq A\times B\), and strict rankings of acceptable opposite types. Unassignment is every job type's last choice.
A society is given by its support: the list of its \(\tau=|A|+|B|\) positive-mass types and their binary rational masses; \(\tau\) counts supported types, not possible types. Take \(\mu_a,\nu_b>0\), \(\sum_a\mu_a=\sum_b\nu_b=1\), and \(\rho>0\), so machine type \(b\) has mass \(\rho\nu_b\). Sizes \(q_a>0\) and capacities \(Q_b>0\) are binary rationals; \(L\) is the total input bit length.
A configuration \(S\) for \(b\) is a vector \(n_a(S)\in\mathbb Z_{\ge0}\), zero on unacceptable pairs. The empty configuration is allowed; otherwise, if \(w\) is its worst represented type under \(b\)'s ranking, require \(\sum_a q_a n_a(S)-q_w<Q_b\): remove one job, not every job of type \(w\). Configurations are implicit in the input.
A distribution is represented by a finite list of configurations with binary integer counts and positive binary rational masses \(z_{b,S}\). Require \(\sum_S z_{b,S}=\rho\nu_b\), and set \(y_{ab}=\sum_S z_{b,S}n_a(S)\), \(u_a=\mu_a-\sum_b y_{ab}\ge0\).
It is stable if, for every \((a,b)\in E\), whenever \(u_a+\sum_{c:\,b\succ_a c}y_{ac}>0\), every configuration \(S\) with \(z_{b,S}>0\) satisfies \(\sum_{a':\,a'\succ_b a}q_{a'}n_{a'}(S)\ge Q_b\). Copies of the same type are indifferent; only strictly better types count in this inequality.
Order configurations lexicographically by their count vectors in \(b\)'s preference order: at the first differing type, the larger count is better. Write \(S\succeq_b T\) for this weak order.
A stable distribution \(z\) is machine-optimal if, for every stable distribution \(z'\), every \(b\), and every admissible threshold configuration \(T\), \(\sum_{S\succeq_b T}z_{b,S}\ge\sum_{S\succeq_b T}z'_{b,S}\).

Is computing a machine-optimal stable distribution, or determining that none exists, solvable in time polynomial in \(m,\tau,L\), or is this problem NP-hard?

For individually listed jobs and machines with strict individual rankings, a lexicographically machine-optimal relaxed unsplit stable assignment always exists and is computable in \(O(|E|)\) time. [Cseh–Dean](https://arxiv.org/html/1411.6818)
No result settling this exact distribution-over-integral-configurations problem was located in the literature search.

  • Normalized job masses and machine-type proportions separately to one, with a positive binary rational ratio \(\rho\) giving total machine mass; required positive sizes and capacities.
  • Defined \(m=|B|\), \(\tau=|A|+|B|\), and \(L\) as total input bit length.
  • Allowed empty configurations and specified that the strict relaxed capacity condition removes exactly one job of the worst represented type.
  • Made unassigned mass explicit and ranked unassignment below every acceptable machine, matching the dummy-machine convention.
  • Treated copies of the same type as indifferent and retained the graded question's stability requirement using only strictly better types.

  • Used implicit input configurations and a finite explicit representation of positive output masses, with binary counts and rational weights.

Result

The problem is \(\mathrm{NP}\text{-hard}\), already with \(m=1\).

More precisely, deciding that no machine-optimal stable distribution exists is \(\mathrm{NP}\text{-hard}\); deciding existence is \(\mathrm{coNP}\text{-hard}\). The reduction below always supplies an explicit stable distribution. Thus the difficulty persists even when stable-distribution existence is guaranteed.

Consequently, computing a machine-optimal stable distribution or correctly reporting its nonexistence cannot take time polynomial in \(m,\tau,L\) unless \(\mathrm{P}=\mathrm{NP}\).

1. Source problem

We reduce from Equal Subset Sum: given positive binary integers \(a_1,\ldots,a_n\), decide whether there are disjoint nonempty index sets with equal sums. This problem is \(\mathrm{NP}\text{-complete}\), by Woeginger–Yu; see their [original paper](https://www.sciencedirect.com/science/article/pii/002001909290226L) and the explicit [positive-integer formulation](https://www.lamsade.dauphine.fr/~bazgan/Papers/icalp98.pdf).

Equivalently, the question is whether there exists

\[ \]
\(d\in\{-1,0,1\}^n\setminus\{0\}\quad\text{such that}\quad\sum_{i=1}^n a_i d_i=0.\)

Indeed, the positive and negative coordinates specify the two subsets. Since every \(a_i>0\), a nonzero vector satisfying this equality must have both positive and negative coordinates.

2. An integer encoding

Let

\(M=\max_i a_i,\qquad D=4n(M+1)+4,\qquad R=D^{n+1}.\)

For each index introduce two positive integer sizes:

\(p_i^+=R+D^i+a_i,\qquad p_i^-=R+D^i.\)

Define

\(K=\sum_{i=1}^n(p_i^++p_i^-)=2nR+2\sum_{i=1}^nD^i+\sum_{i=1}^n a_i.\)

Encoding lemma. Nonnegative integer solutions of

\(\sum_{i=1}^n(p_i^+x_i+p_i^-t_i)=K\)

are exactly the vectors

\(x_i=1+d_i,\qquad t_i=1-d_i,\)

where \(d\in\{-1,0,1\}^n\) and \(\sum_i a_i d_i=0\).

Proof. Put \(A_0=\sum_i a_i\) and \(H=2\sum_iD^i+A_0\). Because \(A_0\le nM<D\) and \(2<D\), these are valid base-\(D\) digits, so \(H<R\). Hence \(K<(2n+1)R\).

Every size is at least \(R\). Therefore a solution has total count

\(N=\sum_i(x_i+t_i)\le 2n.\)

Its contribution below the common \(R\) term is

\(C=\sum_iD^i(x_i+t_i)+\sum_i a_i x_i.\)

It satisfies

\(0\le C\le 2n(D^n+M)\le 2n(M+1)D^n<R.\)

The packing equation is consequently \(NR+C=2nR+H\), with both remainders in \([0,R)\). Thus \(N=2n\) and \(C=H\).

Moreover,

\(\sum_i a_i x_i\le 2nM<D,\qquad x_i+t_i\le 2n<D.\)

There are therefore no carries in the base-\(D\) expression for \(C\). Comparing its digits with those of \(H\) gives

\(x_i+t_i=2\quad\text{for every }i,\qquad\sum_i a_i x_i=A_0.\)

Set \(d_i=x_i-1\). Then \(d_i\in\{-1,0,1\}\), \(t_i=1-d_i\), and \(\sum_i a_i d_i=0\).

Conversely, substituting any vector of the stated form into the packing equation gives \(K\). This proves the lemma.

3. The society

Use one machine type \(b\) and \(2n+1\) job types:

\(A=\{a_i^+,a_i^-:1\le i\le n\}\cup\{f\}.\)

Every job type accepts \(b\). The machine ranks them strictly as

\(a_1^+\succ_b a_1^-\succ_b\cdots\succ_b a_n^+\succ_b a_n^-\succ_b f.\)

Each job type ranks its sole acceptable machine above unassignment.

Set

\(\mu_a=\frac1{2n+1}\quad(a\in A),\qquad\nu_b=1,\qquad\rho=\frac1{2n+1}.\)

Thus each job type has demand equal to the total machine mass. Assign sizes and capacity

\(q_{a_i^+}=p_i^+,\qquad q_{a_i^-}=p_i^-,\qquad q_f=K+2,\qquad Q_b=K+1.\)

In particular, \(q_f>Q_b\).

Let \(S_0\) contain exactly one job of every type. Its worst represented type is \(f\), and removing one \(f\)-job leaves load \(K<Q_b\). Thus \(S_0\) is admissible.

The distribution \(z^0\) placing mass \(\rho\) on \(S_0\) assigns every job type fully. Every stability antecedent is therefore false, so \(z^0\) is stable.

4. Every stable distribution has fixed moments and exact packings

For a configuration \(S\), define its load excluding \(f\) by

\(P(S)=\sum_{i=1}^n\bigl(p_i^+n_{a_i^+}(S)+p_i^-n_{a_i^-}(S)\bigr).\)

Let \(z\) be any stable distribution.

First, \(f\) must be fully assigned. Otherwise \(u_f>0\). Since every other type is strictly better than \(f\), stability requires

\(P(S)\ge Q_b=K+1\)

for every supported configuration. This implies

\(\sum_S z_{b,S}P(S)\ge\rho(K+1).\)

But job availability gives

\(\sum_S z_{b,S}P(S)=\sum_i(p_i^+y_{a_i^+,b}+p_i^-y_{a_i^-,b})\le\rho K,\)

a contradiction.

Second, every supported configuration contains exactly one \(f\)-job. An admissible configuration cannot contain two: removing one would leave at least \(q_f>Q_b\), and \(f\) would be its worst represented type.

Full assignment of \(f\) gives

\(\sum_S z_{b,S}n_f(S)=\mu_f=\rho.\)

Together with \(\sum_S z_{b,S}=\rho\) and \(n_f(S)\le1\), this forces \(n_f(S)=1\) throughout the positive support.

Consequently, admissibility is precisely

\(P(S)<Q_b=K+1,\)

so integrality gives \(P(S)\le K\).

Third, every other job type is also fully assigned. If some type \(a_i^\pm\) had \(u_{a_i^\pm}>0\), stability would require load at least \(Q_b\) from strictly better types in every supported configuration. Those types exclude \(f\), so their load is at most \(P(S)\le K<Q_b\), a contradiction.

It follows that every type has mean count one:

\(\frac1\rho\sum_S z_{b,S}n_a(S)=1\qquad(a\in A).\)

Finally, these moments imply

\(\frac1\rho\sum_S z_{b,S}P(S)=K.\)

Since every supported configuration satisfies \(P(S)\le K\), each must satisfy \(P(S)=K\).

We have proved that every stable distribution is supported on configurations containing one \(f\)-job and solving the exact packing equation of Section 2, with every coordinate having mean one. Conversely, any such distribution is admissible and fully assigns every type, hence is stable.

5. Dominating the explicit distribution forces equality

Suppose a stable distribution \(z\) weakly dominates \(z^0\) at every admissible threshold.

At threshold \(S_0\), dominance requires

\(\sum_{S\succeq_b S_0}z_{b,S}\ge\rho.\)

Since total machine mass is \(\rho\), every supported configuration must satisfy \(S\succeq_b S_0\).

Its count of the first ranked type is therefore at least one. That count has mean one by Section 4, so it equals one in every supported configuration.

Now consider the second ranked type. With the first coordinate fixed at one, lexicographic comparison with \(S_0\) forces its count to be at least one. Its mean is again one, so it too equals one throughout the support.

Inducting through the preference order shows that every count equals one in every supported configuration. Thus \(z=z^0\).

Therefore any machine-optimal stable distribution in this instance must equal \(z^0\).

6. The two cases

No equal subsets

If the Equal Subset Sum instance has no solution, the encoding lemma says that the only exact packing has \(x_i=t_i=1\) for every index.

Section 4 then implies that \(z^0\) is the unique stable distribution. It is consequently machine-optimal.

Equal subsets exist

Suppose a nonzero vector \(d\in\{-1,0,1\}^n\) satisfies \(\sum_i a_i d_i=0\).

Define configurations \(S^+\) and \(S^-\) by

\(n_{a_i^+}(S^\pm)=1\pm d_i,\qquad n_{a_i^-}(S^\pm)=1\mp d_i,\qquad n_f(S^\pm)=1.\)

The encoding lemma gives \(P(S^\pm)=K\). Hence both configurations are admissible.

Placing mass \(\rho/2\) on each configuration gives every type mean count one. This distribution, denoted \(z^1\), is therefore stable.

The two configurations are distinct and lie on opposite sides of \(S_0\) in lexicographic order: at their first differing coordinate, one has count two, \(S_0\) has count one, and the other has count zero. Write \(S^{\mathrm{hi}}\) for the better configuration.

At the admissible threshold \(S^{\mathrm{hi}}\),

\(\sum_{S\succeq_b S^{\mathrm{hi}}}z^0_{b,S}=0,\qquad \sum_{S\succeq_b S^{\mathrm{hi}}}z^1_{b,S}=\rho/2.\)

Thus \(z^0\) is not machine-optimal. Section 5 shows that no other stable distribution can be machine-optimal either.

7. Complexity conclusion

The construction establishes

\(\text{Equal Subset Sum has a solution}\iff\text{no machine-optimal stable distribution exists}.\)

All constructed numbers have polynomial binary length. Specifically, \(\log D=O(\log n+\log M)\), and \(R\), the sizes, and the capacity have \(O(n(\log n+\log M))\) bits. The construction has \(m=1\) and \(\tau=2n+2\), and all masses are positive binary rationals satisfying the required normalizations.

This is a polynomial many-one reduction to nonexistence. An algorithm for the requested computation would decide Equal Subset Sum with one invocation: accept exactly when it reports that no machine-optimal stable distribution exists.

The argument uses the stated removal of one worst job and the stated stochastic dominance over type configurations. The [Cseh–Dean individual-ranking theorem](https://arxiv.org/html/1411.6818) does not assert this distributional dominance property.
