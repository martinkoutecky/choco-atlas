The continuous mirror question, as graded

Given \(\tau\) ordered reach types with rational masses \(\mu_i>0\), \(\sum_{i=1}^{\tau}\mu_i=1\), and per-unit-mass cleanup costs \(q_i\), compute each type's per-capita HLRS charge. Let \(M_{<k}=\sum_{j<k}\mu_j\), \(\alpha_1=1\), and \(\alpha_k=1/2\) for \(k\ge2\). The charge is \(y_i=\alpha_iq_i+\sum_{k=i+1}^{\tau}(1-\alpha_k)\mu_kq_k/M_{<k}\); the aggregate charges should satisfy \(\sum_i\mu_i y_i=\sum_i\mu_iq_i\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) types with positive binary-rational masses \(\mu_i\), where \(\sum_{i=1}^{\tau}\mu_i=1\). Here types are occupied river reaches, ordered strictly from upstream to downstream; \(\tau\) is the support size, not the number of possible types. Set \(m=\tau\), the number of represented reaches.
Each reach has a binary-rational per-unit-mass cleanup cost \(q_i\ge0\), so its total cleanup cost is \(\mu_iq_i\). Let \(L\) be the total input bit length.
Half Local Responsibility Sharing (HLRS) assigns the most upstream type its entire local cost and every other type half its local cost; each remaining local cost is distributed uniformly per unit of strictly upstream mass.
Precisely, let \(M_{<k}=\sum_{j<k}\mu_j\), \(\alpha_1=1\), and \(\alpha_k=1/2\) for \(k\ge2\). The required per-capita charges are \(y_i=\alpha_iq_i+\sum_{k=i+1}^{\tau}(1-\alpha_k)\mu_kq_k/M_{<k}\), with empty sums zero; budget balance means \(\sum_i\mu_i y_i=\sum_i\mu_iq_i\).

Is exact computation of all these continuous HLRS charges solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For discrete ordered agents with costs \(c_i\ge0\), HLRS coincides with the Shapley value, nucleolus, and \(\tau\)-value of the cost game \(v(S)=c_1\mathbf{1}_{\{1\in S\}}+\sum_{i\in S,\,i\ge2}c_i|\{j\in S:j<i\}|/(i-1)\). [Source](https://papers.tinbergen.nl/21028.pdf)
No published complexity result for this exact mass-input computation was located in the search.

Modeling choices made when packaging the task

  • Cleanup costs were given without a sign or encoding domain; take q_i to be nonnegative binary rationals, allowing zero costs as in the discrete model.
  • Interpret each ordered reach type as one occupied reach, with a supplied strict upstream-to-downstream order and no sharing within the same reach beyond its local responsibility.
  • The question had no separate m parameter; set m=tau, the number of represented occupied reaches.
  • Interpret computation as exact rational evaluation, and L as the total input bit length.
  • Allow tau=1 and use zero for empty sums, retaining the single-reach case permitted by the discrete definition.

Conclusion

All continuous HLRS charges can be computed exactly in deterministic polynomial time in \(m,\tau,L\). The proof below accounts for the bit lengths of both the output and the intermediate integers. Here \(m=\tau\).

Exact output means representing each charge as a rational numerator and denominator in binary. Even dyadic inputs can produce non-dyadic charges.

1. Integer representation of the input

Write the input rationals as
\(\mu_i=p_i/d_i\) and \(q_i=r_i/e_i\), where \(p_i,d_i,e_i\) are positive integers and \(r_i\) is a nonnegative integer, all encoded in binary. This representation includes dyadic inputs.

Define
\(D=\prod_{i=1}^{\tau}d_i\) and \(E=\prod_{i=1}^{\tau}e_i\), and set
\(a_i=p_i(D/d_i)\) and \(b_i=r_i(E/e_i)\).

These are integers, with
\(\mu_i=a_i/D\) and \(q_i=b_i/E\).
The mass hypotheses imply
\(a_i>0\) and \(\sum_{i=1}^{\tau}a_i=D\).

For \(1\le j\le\tau-1\), define
\(A_j=\sum_{i=1}^{j}a_i\).
Consequently,
\(1\le A_j\le D\), and \(M_{<k}=A_{k-1}/D>0\) for every \(k\ge2\). Thus every division in the prescribed charge formula is well-defined.

For \(k\ge2\), its shared-cost term becomes

\(\displaystyle \frac{(1-\alpha_k)\mu_kq_k}{M_{<k}}=\frac{a_kb_k}{2EA_{k-1}}.\)

2. An exact algorithm

Choose the common denominator

\(\displaystyle H=2E\prod_{j=1}^{\tau-1}A_j,\)

where an empty product equals \(1\).

For each \(k\ge2\), compute the integer

\(\displaystyle W_k=\frac{H}{2EA_{k-1}}\,a_kb_k.\)

The division is exact because \(A_{k-1}\) is a factor in the defining product for \(H\).

Define the local-charge numerators by
\(C_1=(H/E)b_1\) and
\(C_i=(H/(2E))b_i\) for \(i\ge2\).
These divisions are also exact, and
\(C_i/H=\alpha_iq_i\).

Compute the charge numerators using a backward scan:

  • Initialize \(T=0\).
  • For \(i=\tau,\tau-1,\ldots,1\), set \(N_i=C_i+T\).
  • After setting \(N_i\), if \(i\ge2\), replace \(T\) by \(T+W_i\).

Immediately before iteration \(i\), the invariant is
\(T=\sum_{k=i+1}^{\tau}W_k\). It holds initially because the sum is empty, and the update preserves it. Hence

\(\displaystyle \frac{N_i}{H}=\alpha_iq_i+\sum_{k=i+1}^{\tau}\frac{a_kb_k}{2EA_{k-1}}=y_i.\)

Finally, reduce each fraction using
\(g_i=\gcd(N_i,H)\), and output
\((N_i/g_i)/(H/g_i)\).
This also handles \(N_i=0\), since \(\gcd(0,H)=H\).

When \(\tau=1\), the same algorithm outputs \(y_1=q_1\).

3. Bit complexity

Because \(L\) includes all input numerator and denominator bits, we have
\(D\le2^L\), \(E\le2^L\), and \(q_i\le2^L\).
Since every \(A_j\le D\),

\(\displaystyle H\le 2E D^{\tau-1}\le2^{1+\tau L}.\)

Thus \(H\) has \(O(\tau L)\) bits. Its numerical value may be large, but its binary representation has polynomial length.

To bound the numerators, observe that, for \(k\ge2\),

\(\displaystyle \frac{a_kb_k}{2EA_{k-1}}=\frac{a_kq_k}{2A_{k-1}}\le\frac{D\,2^L}{2}\le2^{2L}.\)

The inequality uses \(a_k\le D\) and \(A_{k-1}\ge1\). Since all terms are nonnegative,

\(\displaystyle 0\le y_i\le(\tau+1)2^{2L},\qquad 0\le N_i\le H(\tau+1)2^{2L}.\)

Therefore every output numerator has
\(O(\tau L+L+\log(\tau+1))\) bits. The same bound, up to a constant factor, covers every intermediate integer in the specified algorithm: the input rescaling uses products of integers with \(O(L)\) bits, the product defining \(H\) never exceeds \(H\), and the remaining calculations use these bounded factors and nonnegative sums.

Let
\(B=O((\tau+2)L+\log(\tau+1))\).
The algorithm performs \(O(\tau)\) integer arithmetic operations and \(O(\tau)\) greatest-common-divisor computations on integers with \(O(B)\) bits.

For completeness, elementary multiplication and division take \(O(B^2)\) bit operations. The Euclidean algorithm takes \(O(B)\) divisions: within every two remainder steps, the positive remainder decreases by at least a factor of two. Thus a conservative bound for each greatest-common-divisor computation is \(O(B^3)\), and the entire algorithm takes

\(\displaystyle O(\tau B^3)\)

bit operations. This is polynomial in \(\tau,L\), and hence in \(m,\tau,L\). The total output length is polynomial as well.

4. Budget balance and a small check

Reordering finite sums gives

\(\displaystyle \sum_{i=1}^{\tau}\mu_i y_i = \sum_{i=1}^{\tau}\mu_i\alpha_iq_i + \sum_{k=2}^{\tau} \frac{(1-\alpha_k)\mu_kq_k}{M_{<k}} \sum_{i<k}\mu_i. \)

The inner mass sum is exactly \(M_{<k}>0\), so it cancels its denominator. Therefore

\(\displaystyle \sum_{i=1}^{\tau}\mu_i y_i = \mu_1q_1+ \sum_{k=2}^{\tau} \bigl(\alpha_k+(1-\alpha_k)\bigr)\mu_kq_k = \sum_{i=1}^{\tau}\mu_iq_i. \)

For example, take
\(\mu_1=3/4\), \(\mu_2=1/4\), \(q_1=0\), and \(q_2=1\).
Then \(y_1=1/6\) and \(y_2=1/2\), and

\(\displaystyle \frac34\cdot\frac16+\frac14\cdot\frac12=\frac14.\)

This verifies a nontrivial instance and shows why exact rational output is necessary even for dyadic inputs.

5. Relation to the discrete game

The cited paper establishes the coincidence of discrete HLRS with the Shapley value, nucleolus, and \(\tau\)-value for its pollution cost-sharing game. [Li, Xu, and van den Brink, *Sharing the cost of cleaning up a polluted river*](https://papers.tinbergen.nl/21028.pdf).

The algorithm above follows directly from the stated continuous mass formula and needs no computation over coalitions or expansion into individual agents. It therefore establishes polynomial-time exact computation for the intended mass-input problem. Any NP-hardness claim under a polynomial-time reduction that would solve NP problems using this computation would imply \(\mathrm{P}=\mathrm{NP}\).
