The continuous mirror question, as graded

Given worker types \(R\) and firm types \(S\), each with rational mass, and a finite set \(E\) of contract categories linking types in a block-complete market, find a mass allocation \(y_e\geq 0\). Require \(\sum_{e\ni a}y_e\leq\mu_a\) for each type \(a\), and permit positive \(y_e\) only if both endpoint types choose \(e\) from \(\{e\}\). For each endpoint type \(a\) of \(e\), let \(q_{a,e}(y)\) be its unmatched mass plus the mass assigned to categories \(e'\ne e\) for which \(C_a(\{e,e'\})=\{e\}\). Is there an algorithm to find an allocation such that \(q_{r,e}(y)q_{s,e}(y)=0\) for every category \(e\) linking worker type \(r\) and firm type \(s\)?

Packaged proof task (what the prover saw — nothing else)

Let \(R\) and \(S\) be nonempty, disjoint sets of worker and firm types. A society is given by its support: the list of its \(\tau=|R|+|S|\) types with positive mass \(\mu_a\), each a binary rational; \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_{r\in R}\mu_r=\sum_{s\in S}\mu_s=1\).
Let \(E\) contain \(m\) contract categories, each linking one worker type and one firm type; multiple categories may link the same pair. The market is block-complete: every individual of either endpoint type can contract with every individual of the other endpoint type in that category, and choices depend only on categories.
For \(E_a=\{e\in E:a\text{ is an endpoint of }e\}\), input explicitly lists \(C_a(A)\subseteq A\) for every \(A\subseteq E_a\) with \(|A|\leq2\). These tables are promised to extend to maps on all subsets satisfying substitutability: \(A\subseteq B\Rightarrow C_a(B)\cap A\subseteq C_a(A)\). Also require binary acyclicity: the relation \(eP_ae'\iff e\ne e'\text{ and }C_a(\{e,e'\})=\{e\}\) has no directed cycle. Empty choices and choosing both categories are allowed; neither constitutes a strict comparison.
Call \(e\) acceptable if \(C_a(\{e\})=\{e\}\) at both endpoints. Seek rational masses \(y_e\geq0\) with \(\sum_{e\in E_a}y_e\leq\mu_a\) for every \(a\), and \(y_e=0\) for every unacceptable category.
Define \(u_a(y)=\mu_a-\sum_{e\in E_a}y_e\) and \(q_{a,e}(y)=u_a(y)+\sum_{e'\in E_a\setminus\{e\}:\,C_a(\{e,e'\})=\{e\}}y_{e'}\). An allocation is stable when \(q_{r,e}(y)q_{s,e}(y)=0\) for every acceptable category \(e\) linking \(r\) and \(s\).

Is finding such a stable allocation solvable in time polynomial in \(m\), \(\tau\), and the total input bit length \(L\), or is this search problem NP-hard?

For finite one-to-one markets, substitutability and binary acyclicity guarantee an individually rational matching with no contract that both endpoints would choose as a replacement, computable in polynomial time from singleton and pair choices ([source](https://arxiv.org/pdf/2603.23038)).
For fractional matching with ordinary preference lists, ordinally stable matchings exist even with ties ([source](https://www.ijcai.org/proceedings/2021/0013.pdf)); this does not address the stated type-mass problem with choice tables. No result settling this exact search problem was identified.

  • Defined binary strict comparisons only between distinct categories, excluding the unintended self-loops that the literal binary-acyclicity notation would create for acceptable singletons.
  • Normalized each side's total mass to one, preserving the equal worker and firm population sizes assumed in the discrete one-to-one setting.
  • Defined block-completeness as universal availability within each listed category's endpoint blocks, with choices independent of partner identity.

Under substitutability, an unacceptable contract cannot block in the discrete definition; the unqualified unmatched-mass term in the graded question incorrectly lets it do so.
  • Specified rational output masses, defined m as the number of contract categories, and retained the allocation-finding question as a search problem.

Result

Finding a stable allocation is polynomial-time solvable in \(m\), \(\tau\), and \(L\). Every promised instance has a rational stable allocation of polynomial encoding length.

The proof extends the acyclic binary comparisons to strict orders and then reduces the resulting problem to polynomial-time computation of a stable flow. The reduction handles parallel contract categories explicitly.

1. Extend the binary comparisons

Let \(E^+\) be the set of acceptable categories, and write \(E_a^+=E_a\cap E^+\). We set \(y_e=0\) for \(e\notin E^+\).

For each type \(a\), construct the directed graph on \(E_a^+\) with an arc from \(e\) to \(e'\) exactly when \(eP_ae'\). Binary acyclicity guarantees that this graph is acyclic. A topological ordering therefore gives a strict total order \(\succ_a\) satisfying

\(eP_ae'\ \Longrightarrow\ e\succ_a e'.\)

For a feasible allocation supported on \(E^+\), define

\(\widehat q_{a,e}(y)=u_a(y)+\sum_{e'\in E_a^+:\,e\succ_a e'}y_{e'}.\)

Every positive-mass category counted in \(q_{a,e}\) is also counted in \(\widehat q_{a,e}\): its strict binary comparison is preserved by \(\succ_a\). Consequently,

\(0\leq q_{a,e}(y)\leq\widehat q_{a,e}(y).\)

It therefore suffices to find an allocation satisfying

\(\widehat q_{r,e}(y)\widehat q_{s,e}(y)=0\)

for every acceptable category \(e\) linking \(r\) and \(s\).

This is a sufficient condition; we do not assume that the original choice tables are represented by the extended orders.

2. The stable-flow theorem used

Consider a directed network with source \(o\), sink \(t\), nonnegative arc capacities, and strict preference orders over incoming and outgoing arcs separately at each nonterminal vertex. A feasible flow respects capacities and satisfies conservation at every nonterminal vertex.

A directed path blocks a flow when:

  • Every arc on the path is unsaturated.
  • Its initial vertex is \(o\), or prefers the path’s first arc to another outgoing arc carrying positive flow.
  • Its final vertex is \(t\), or prefers the path’s last arc to another incoming arc carrying positive flow.

A stable flow has no blocking directed walk, hence no blocking path.

Known theorem. Such an instance always admits a stable flow. Cseh and Matuschke’s Algorithm 1 computes one using \(O(|V||A|)\) operations. Its numerical updates use residual capacities, bottleneck minima, and additions or subtractions of bottleneck amounts. See Definition 2 and Theorem 2 of [*New and simple algorithms for stable flow problems*](https://arxiv.org/pdf/1309.3701).

We apply this theorem directly, without expanding rational masses into individual agents.

3. Construct the network and recover an allocation

If \(E^+=\varnothing\), the zero allocation is feasible and stable. Henceforth suppose \(E^+\neq\varnothing\).

Omit types incident to no acceptable category from the network; their allocations remain zero. Introduce source \(o\), sink \(t\), and a distinct intermediate vertex \(z_e\) for each \(e\in E^+\).

For every remaining worker type \(r\), add \(o\to r\) with capacity \(\mu_r\). For every remaining firm type \(s\), add \(s\to t\) with capacity \(\mu_s\).

For each category \(e\) linking \(r\) and \(s\), add

\(r\to z_e\to s,\)

giving both arcs capacity \(2\).

At \(r\), rank its outgoing category arcs according to \(\succ_r\). At \(s\), rank its incoming category arcs according to \(\succ_s\). All other incoming or outgoing lists at nonterminal vertices are singletons.

This verifies the theorem’s hypotheses:

  • All capacities are positive rationals.
  • Every nonterminal vertex has both incoming and outgoing arcs.
  • Preference lists are strict.
  • There are no loops or parallel arcs: distinct categories have distinct intermediate vertices, even when their endpoint types coincide.

Compute a stable flow \(f\). Conservation at \(z_e\) gives

\(f(rz_e)=f(z_es).\)

Define their common value to be \(y_e\), and set \(y_e=0\) on unacceptable categories.

Conservation and capacities at worker and firm vertices imply

\(\sum_{e\in E_r}y_e=f(or)\leq\mu_r,\qquad \sum_{e\in E_s}y_e=f(st)\leq\mu_s.\)

Thus \(y\) is feasible. Furthermore,

\(u_r(y)=\mu_r-f(or),\qquad u_s(y)=\mu_s-f(st).\)

Normalization gives \(\mu_a\leq1\) for every type. Hence every category arc carries at most \(1\), strictly below its capacity \(2\).

4. Prove stability

Suppose, for contradiction, that an acceptable category \(e\) linking \(r\) and \(s\) satisfies

\(\widehat q_{r,e}(y)>0\quad\text{and}\quad\widehat q_{s,e}(y)>0.\)

We construct a blocking path through \(r\to z_e\to s\).

Its beginning. If \(u_r(y)>0\), prepend \(o\to r\). That arc is unsaturated because \(f(or)<\mu_r\), and the path starts at the source.

Otherwise, positivity of \(\widehat q_{r,e}\) implies that some category \(e'\) has \(y_{e'}>0\) and \(e\succ_r e'\). Start the path at \(r\). Its first arc \(r\to z_e\) is preferred to the positive-flow outgoing arc \(r\to z_{e'}\), so the initial blocking condition holds.

Its end. If \(u_s(y)>0\), append \(s\to t\). That arc is unsaturated because \(f(st)<\mu_s\), and the path ends at the sink.

Otherwise, positivity of \(\widehat q_{s,e}\) implies that some category \(e''\) has \(y_{e''}>0\) and \(e\succ_s e''\). End the path at \(s\). Its last arc \(z_e\to s\) is preferred to the positive-flow incoming arc \(z_{e''}\to s\), so the final blocking condition holds.

Both category arcs are unsaturated, as proved above. Thus these choices produce a blocking path, contradicting stability of \(f\).

Therefore, for every acceptable \(e\),

\(\widehat q_{r,e}(y)\widehat q_{s,e}(y)=0.\)

Since \(0\leq q_{a,e}(y)\leq\widehat q_{a,e}(y)\), at least one original endpoint quantity is also zero. Hence

\(q_{r,e}(y)q_{s,e}(y)=0,\)

which is exactly the requested stability condition.

5. Polynomial bit complexity

The network has at most \(\tau+m+2\) vertices and \(\tau+2m\) arcs. Constructing the comparison graphs and their topological orders is polynomial in the explicitly listed tables.

To verify exact arithmetic complexity, write each mass as \(\mu_a=p_a/d_a\), and let \(D=\prod_a d_a\). The binary length of \(D\) is \(O(L)\), because the denominators’ encoding lengths are included in \(L\).

Multiply every network capacity by \(D\). All capacities are now integers, and none exceeds \(2D\). Run the cited augmenting-path algorithm on this scaled instance. Starting from zero, its residual capacities and bottleneck amounts remain integers; additions and subtractions therefore preserve integral flow values. Feasibility bounds every flow value and residual capacity by \(2D\), so the numerical quantities have \(O(L)\) bits.

The algorithm uses \(O((\tau+m)^2)\) operations on quantities of polynomial bit length. Dividing its output by \(D\) recovers a rational stable flow: positive scaling preserves capacity comparisons and blocking conditions. Each resulting \(y_e\) has polynomial encoding length.

Thus the construction is a polynomial-time algorithm in \(m\), \(\tau\), and \(L\).

The substitutability promise requires no additional computational work: the proof uses only singleton acceptability and acyclicity of the strict binary comparisons.
