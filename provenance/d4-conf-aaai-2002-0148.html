Proposition 1 — class: other

The continuous mirror question, as graded

Given finite \(D\), \(S\), and \(T\), rational masses \(\mu_t\) summing to \(1\), rational type utilities \(u_t\), outcome distributions, response probabilities, query costs, discount factor, horizon \(H\), and value threshold \(\eta\), is there a history-contingent policy choosing standard-gamble queries \(q_i(l)\), with rational \(l\in[0,1]\), or terminal decisions, whose expected discounted per-capita utility minus query costs is at least \(\eta\)? At each response history \(h\), querying type mass \(x_{h,t}\) splits it as \(x_{h,r,t}=x_{h,t}\Pr(r\mid q_i(l),u_t)\).

Packaged proof task (what the prover saw — nothing else)

Let \(D\) and \(S=\{s_1,\ldots,s_m\}\) be nonempty finite sets of terminal decisions and outcomes. Each decision has an explicitly given rational outcome distribution \(p_d\); type \(t\) has rational utilities \(u_t:S\to[0,1]\), giving terminal reward \(R(d,t)=\sum_i p_d(s_i)u_t(s_i)\).
A society is given by its support: the list \(T\) of its \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; type remains unchanged throughout elicitation and is unobserved by the policy.
A standard-gamble query \(q_i(l)\), with rational \(l\in[0,1]\), compares \(s_i\) with reference prizes of utilities \(1\) and \(0\), received with probabilities \(l\) and \(1-l\). The reference prizes need not belong to \(S\).
Input rational error rates \(a_i,b_i\in[0,1]\) determine \(P(\mathrm{yes}\mid q_i(l),t)=a_i\) if \(u_t(s_i)<l\), and \(1-b_i\) otherwise; the probability of no is complementary. Responses are conditionally independent given type and queries.
Each query \(q_i(l)\) costs \(c_i\geq0\) per unit mass, independently of type and \(l\). Costs, discount \(\gamma\in(0,1)\), and threshold \(\eta\in\mathbb Q\) are binary rationals; the nonnegative integer query horizon \(H\) is encoded in unary.
A deterministic policy assigns one query or terminal decision to each response history, uses at most \(H\) queries on every path, and then terminates. Starting from \(x_{\varnothing,t}=\mu_t\), a queried node \(h\) splits its entire mass by \(x_{hr,t}=x_{h,t}P(r\mid q_i(l),t)\); actions cannot depend on the unobserved type.
Its value is \(V(\pi)=\sum_{h\text{ terminal}}\gamma^{|h|}\sum_t x_{h,t}R(d_h,t)-\sum_{h\text{ queried}}\gamma^{|h|}c_{i_h}\sum_t x_{h,t}\). Let \(L\) be the total input bit length; state running times in \(m,\tau,|D|,H,L\).

Is deciding whether there exists such a policy with \(V(\pi)\geq\eta\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

[Boutilier (2002)](https://www.cs.toronto.edu/~cebly/Papers/_download_/pefa.pdf) states mixture linearity of optimized query values, but supplies no discrete complexity classification.
[Conitzer and Sandholm (2003)](https://www.cs.cmu.edu/~conitzer/metareasoningIJCAI03.pdf) prove finite-state STATE-DISAMBIGUATION \(\mathrm{NP}\)-hard even with deterministic responses, and \(\mathrm{PSPACE}\)-hard generally; its reward requires certain identification, unlike the terminal rewards here.
No complexity classification for exactly the mass problem defined above was located.

Modeling choices made when packaging the task

  • Defined m as the number of outcomes, required nonempty decision and outcome sets, and used the required explicit support representation with positive masses summing to one.
  • Restored utilities in [0,1], rational outcome distributions, static unobserved types, and expected-utility terminal rewards.
  • Specified utility-zero and utility-one reference prizes for standard gambles without requiring those prizes to be available decision outcomes.
  • Replaced unspecified response probabilities by the fixed false-positive and false-negative model; equality uses the positive-response branch, as in the supplied definition.
  • Made repeated responses conditionally independent given the static type and queries.
  • Represented query costs by nonnegative rational constants per query type, independent of type and lottery parameter, avoiding an unspecified representation of a cost function over infinitely many queries.
  • Interpreted the supplied finite horizon as at most H queries followed by mandatory termination, and encoded H in unary.
  • Specified a rational discount strictly between zero and one and discounted both query costs and terminal rewards at their action depths.
  • Specified one history-dependent action for all mass at each node, with no access to type labels or discretionary selection of type-specific submasses.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification. The problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions, even with deterministic responses, utilities in \(\{0,1\}\), and \(|D|=2\). The deterministic-response restriction is \(\mathrm{NP}\)-complete. The general problem belongs to \(\mathrm{PSPACE}\).

The proof below uses the stipulated terminal rewards directly.

1. Reduction from Set Cover. Consider a Set Cover instance with nonempty universe \(U=\{e_1,\ldots,e_N\}\), subsets \(A_1,\ldots,A_M\), and budget \(k\). The question is whether at most \(k\) subsets cover \(U\). We may restrict to \(M\geq1\) and \(1\leq k\leq M\): the excluded cases are trivial, and budgets exceeding \(M\) can be capped at \(M\).

We may also delete elements with duplicate incidence vectors, since this preserves the existence of a cover. Thus the constructed element types below are distinct.

The construction follows the distinguished-state idea in [Conitzer and Sandholm, Theorem 3](https://www.cs.cmu.edu/~conitzer/metareasoningIJCAI03.pdf), but replaces their identification reward with two permitted terminal decisions.

Choose powers of two \(B,C\) satisfying

\(N+1\leq B<2(N+1),\qquad 4B(k+1)\leq C<8B(k+1).\)

Construct the following instance.

  • Types and masses: \(T=\{t_0,t_1,\ldots,t_N\}\), where \(t_0\) is distinguished, with

\(\mu_{t_0}=(B-N)/B\) and \(\mu_{t_j}=1/B\) for \(1\leq j\leq N\).

  • Outcomes: \(S=\{s_1,\ldots,s_M,z,w\}\).
  • Membership utilities: \(u_{t_0}(s_i)=0\), while \(u_{t_j}(s_i)=1\) precisely when \(e_j\in A_i\), and is \(0\) otherwise.
  • Terminal-outcome utilities: \(u_{t_0}(z)=1,\ u_{t_0}(w)=0\), while \(u_{t_j}(z)=0,\ u_{t_j}(w)=1\) for every \(j\geq1\).
  • Decisions: \(d_0\) produces \(z\) with probability \(1\); \(d_1\) produces \(w\) with probability \(1\).
  • Responses: \(a_i=b_i=0\) for every outcome.
  • Costs: membership queries cost \(0\); queries about \(z\) or \(w\) cost \(2B\).
  • Horizon, discount, and threshold: \(H=k,\ \gamma=1-1/C,\ \eta=\gamma^k\).

The outcomes \(z,w\) are ordinary outcomes with type-dependent utilities; the fixed reference prizes remain external.

All masses are positive dyadic rationals and sum to \(1\). Every positive type mass is at least \(1/B\). The terminal rewards are exactly

\(R(d_0,t_0)=1,\quad R(d_1,t_0)=0,\quad R(d_0,t_j)=0,\quad R(d_1,t_j)=1\quad(j\geq1).\)

Thus correct classification earns \(1\), and incorrect classification earns \(0\).

For a membership outcome \(s_i\), any threshold \(l\in(0,1]\) produces yes exactly for the types whose elements belong to \(A_i\). At \(l=0\), every type answers yes. Consequently, allowing arbitrary rational thresholds introduces no additional informative partitions.

Bernoulli’s inequality gives

\(\eta=(1-1/C)^k\geq1-k/C>1-1/(4B)>1-1/B.\)

In particular, \(\eta>1/2\).

2. Reward-outcome queries cannot bypass the construction. Because responses are deterministic, each type follows a unique path. At every reachable node, its mass vector consists of the original masses of the types reaching that node. Hence the total mass of a reachable node is at least \(1/B\).

Suppose a policy queries \(z\) or \(w\) at a reachable node of depth \(d\). Its discounted cost at that node is at least

\(\gamma^d(2B)(1/B)=2\gamma^d\geq2\gamma^k=2\eta>1.\)

The policy’s total discounted terminal reward is at most \(1\): every type terminates once, every reward is at most \(1\), and the masses sum to \(1\). All other costs are nonnegative. Therefore this policy has value strictly below \(0\), and cannot reach the positive threshold \(\eta\).

It follows that every policy reaching \(\eta\) uses only membership queries at reachable nodes.

3. A set cover yields a qualifying policy. Suppose \(A_{i_1},\ldots,A_{i_r}\) cover \(U\), where \(r\leq k\).

Ask their membership queries in order, using threshold \(1/2\). After the first yes response, terminate with \(d_1\). If all responses are no, terminate with \(d_0\).

Every element type eventually answers yes because the selected sets cover \(U\), and receives reward \(1\). The distinguished type always answers no and also receives reward \(1\). Every path has at most \(k\) queries, and all queried costs are zero. Consequently,

\(V(\pi)=\sum_t\mu_t\gamma^{\ell_t}\geq\sum_t\mu_t\gamma^k=\eta,\)

where \(\ell_t\leq k\) is the terminal depth for type \(t\).

4. A qualifying policy yields a set cover. Suppose no collection of at most \(k\) sets covers \(U\), and consider any policy that could reach \(\eta\). By Section 2, its reachable queries must be membership queries.

Follow the unique path taken by \(t_0\). Let \(I\) be the indices of membership outcomes queried on this path with positive thresholds. There are at most \(k\) such indices. By assumption, some element \(e_j\) lies outside \(\bigcup_{i\in I}A_i\).

The types \(t_0,t_j\) follow the same path. Indeed, inductively, whenever they have reached the same node:

  • A query with threshold \(0\) gives yes for both.
  • A query with positive threshold gives no for both, because \(u_{t_0}(s_i)=u_{t_j}(s_i)=0\).

The policy therefore selects the same terminal decision for these two types. Whichever decision it selects, one of them receives reward \(0\). Its mass is at least \(1/B\).

The undiscounted terminal reward is thus at most \(1-1/B\). Discounting cannot increase nonnegative terminal rewards, and costs cannot increase value. Hence

\(V(\pi)\leq1-1/B<\eta.\)

This contradiction proves the equivalence

\(\text{there is a set cover of size at most }k\quad\Longleftrightarrow\quad\exists\pi:\ V(\pi)\geq\eta.\)

The reduction has \(m=M+2,\ \tau=N+1,\ |D|=2,\ H=k\). Its utility table has polynomial size; \(\log B\) and \(\log C\) are logarithmic in the source parameters; and \(\eta=(C-1)^k/C^k\) uses \(O(k\log C)\) bits. Since \(k\leq M\), writing \(H\) in unary and writing \(\eta\) explicitly both take polynomial time. This completes the \(\mathrm{NP}\)-hardness proof.

5. Finite query representatives and an exact algorithm. For completeness, the continuous threshold parameter can be eliminated exactly.

For outcome \(s_i\), list its distinct support utilities as

\(v_{i,1}<\cdots<v_{i,r_i},\qquad r_i\leq\tau.\)

The response probabilities depend only on the set of types satisfying \(u_t(s_i)<l\). Representatives for all possible such sets are:

  • \(0\);
  • \(v_{i,2},\ldots,v_{i,r_i}\);
  • \(1\), if \(v_{i,r_i}<1\).

To verify completeness, thresholds at most \(v_{i,1}\) give the empty set; thresholds in \((v_{i,j},v_{i,j+1}]\) give the same set as \(v_{i,j+1}\); and thresholds above the maximum, when possible, give the same set as \(1\). The endpoint convention follows from the strict inequality \(u_t(s_i)<l\).

There are therefore at most \(K=m(\tau+1)\) representative queries. Replacing every query by its representative preserves its response probabilities and cost, hence preserves the entire policy value.

For a nonnegative mass vector \(x\), let \(F_h(x)\) be the maximum value measured from the current node with at most \(h\) further queries. Define

\(A(x)=\max_{d\in D}\sum_t x_tR(d,t).\)

For representative query \(q\), write \(\rho_{q,r,t}=P(r\mid q,t)\) and \(x^{q,r}_t=x_t\rho_{q,r,t}\). Then

\(F_0(x)=A(x),\)

and, for \(h\geq1\),

\(F_h(x)=\max\left\{A(x),\ \max_q\left[-c_q\sum_t x_t+\gamma\bigl(F_{h-1}(x^{q,\mathrm{yes}})+F_{h-1}(x^{q,\mathrm{no}})\bigr)\right]\right\}.\)

This recurrence is exact: a policy either terminates immediately or asks one query, after which its two continuation policies can be chosen independently. Induction on \(h\) proves both the upper bound and attainability. The answer is obtained by comparing \(F_H(\mu)\) with \(\eta\).

Precomputing rewards takes \(O(|D|m\tau)\) rational arithmetic operations. Depth-first evaluation of the recurrence gives the bit-time bound

\(O\!\left(\left[|D|m\tau+\bigl(2m(\tau+1)\bigr)^H\bigl(m(\tau+1)+|D|\bigr)\tau\right]\operatorname{poly}(H,L)\right).\)

Thus every fixed-horizon case is polynomial-time solvable.

To justify exact arithmetic, let \(Q\) be the product of all input denominators, so \(\log Q=O(L)\). A mass coordinate at depth \(d\) has denominator dividing \(Q^{d+1}\). A terminal contribution after another \(r\) queries has denominator dividing \(Q^{d+2r+3}\); a cost contribution has denominator dividing \(Q^{d+2r+2}\). Since \(d+r\leq H\), all these denominators divide \(Q^{2H+3}\). Summation and maximization preserve this common denominator bound.

The absolute value of any policy value is at most \(1+Hc_{\max}\). Consequently, all exact values need only \(O((H+1)L+\log(H+1))\) bits. A depth-first implementation stores only polynomially many such numbers along a recursion stack of depth \(H\). Because \(H\) is unary, this proves membership in \(\mathrm{PSPACE}\).

6. Deterministic responses give \(\mathrm{NP}\)-completeness. When every response probability is in \(\{0,1\}\), each of the \(\tau\) types follows one path of length at most \(H\). The union of these paths contains at most \(1+\tau H\) nodes. Unreachable branches can be filled with arbitrary terminal decisions without changing value.

A certificate can therefore specify a polynomial-size policy tree using representative query indices and decision indices. A verifier simulates each type’s path and evaluates exactly

\(\sum_t\mu_t\left[\gamma^{\ell_t}R(d_t,t)-\sum_{j=0}^{\ell_t-1}\gamma^j c_{i_{t,j}}\right].\)

After reward precomputation, this takes \(O(\tau H)\operatorname{poly}(H,L)\) time. The deterministic-response restriction belongs to \(\mathrm{NP}\); Sections 1–4 establish its \(\mathrm{NP}\)-hardness.

The requested classification is therefore resolved: the stated mass problem is \(\mathrm{NP}\)-hard, and a polynomial-time algorithm for unrestricted inputs would imply \(\mathrm P=\mathrm{NP}\).
