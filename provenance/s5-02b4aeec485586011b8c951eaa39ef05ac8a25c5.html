The anchor (named result in the paper)

Certified-path guarantees on bounded-in-degree graphs — class: algorithmic

The continuous mirror question, as graded

Given a rational mass distribution \(\mu\) over finitely many complete local-role types, together with a repeatable bounded-in-degree network schema realizing those roles and their competence labels, can the \(T\)-round certified-path rule be defined as a mass routing \(D\) such that it is acyclic, every delegated unit reaches a terminal type with competence gain at least \(\alpha_b-\beta_b\) in each state \(b\in\{0,1\}\), and terminal-load density is at most \(W_T\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\) types with positive binary-rational masses \(\mu_i\), summing to \(1\); \(\tau\) counts listed types, not all possible types. There are \(m=2\) states, and type \(i\) has rational competences \(p_i^b\in[0,1]\).
A complete local-role type specifies its competence vector and an ordered list of outgoing ports, each naming a target type. The repeatable network schema consists of these lists and an integer \(\Delta_{\mathrm{in}}\ge0\), with the promise that arbitrarily large finite simple directed realizations exist having \(N\mu_i\) vertices of each type, the specified outgoing neighbour types and orders, and maximum in-degree \(\Delta_{\mathrm{in}}\).
The rational thresholds satisfy \(\alpha_b>\beta_b\ge0\). A port \(i\to j\) is admissible when \(p_j^b-p_i^b\ge-\beta_b\) in both states; its score is \(e_{ij}^b=1\) if \(p_j^b-p_i^b\ge\alpha_b\), and \(e_{ij}^b=-1\) otherwise.
Set \(T=1+\lceil2\min_{b\in\{0,1\}}1/(\alpha_b-\beta_b)\rceil\) and \(W_T=\sum_{k=0}^{T}\Delta_{\mathrm{in}}^k\), with the zeroth term equal to \(1\). Initially each type has \(R_i=(0,0)\) and no selected port.
In each of \(T\) synchronous rounds, retain the current certificate and selected port, then scan admissible ports in their fixed order. Using the neighbour's previous-round certificate, replace the retained certificate by \(C=R_j+e_{ij}\), and select that port, exactly when \(C\) is coordinatewise nonnegative and coordinatewise dominates the currently retained certificate with at least one strict coordinate. Commit all updates simultaneously.
The prescribed mass routing \(D\) sends all mass arriving at a type through its final selected port; a type without one is terminal. Require the selected type graph to be acyclic and every delegating source \(i\) to reach a terminal type \(s(i)\) satisfying \(p_{s(i)}^b-p_i^b\ge\alpha_b-\beta_b\) in both states.
For a terminal type \(j\), define its load density as \(\lambda_j=\bigl(\sum_{i:s(i)=j}\mu_i\bigr)/\mu_j\), including its own mass; require \(\lambda_j\le W_T\).
Is constructing the prescribed mass routing \(D\) with these guarantees solvable in polynomial time in the binary input length, or is it NP-hard? State running times in \(m,\tau,L,\Delta_{\mathrm{in}},T\), and the number of listed ports, where \(L\) is the total input bit length and \(T\) is derived rather than unary-encoded.
For finite voters, the certified-path mechanism uses \(T\) synchronous rounds and guarantees acyclicity, the stated terminal competence margins, and terminal weight at most \(W_T\). [Verified discrete result](https://arxiv.org/html/2608.16738v1)

Classification

The prescribed mass routing is polynomial-time solvable in the binary input length. The key is that certificate growth is bounded by the number of listed types, even when the derived round count \(T\) is exponentially large.

I interpret “prescribed” as requiring exactly the final selected ports of the stated process. The finite-voter mechanism is Algorithm 3 in the [supplied paper](https://arxiv.org/html/2608.16738v1). The proof below establishes the support-encoded construction and its guarantees directly.

Let \(P\) denote the number of listed ports. Write \(\delta_b=\alpha_b-\beta_b>0\). Although the problem has \(m=2\), the bounds below display the dependence on \(m\); the argument also applies to any number of states satisfying these threshold assumptions.

1. A competence inequality for admissible walks

Consider an admissible directed walk of length \(\ell\), starting at type \(u\) and ending at type \(v\). In state \(b\), let \(a_b\) and \(c_b\) count its edges scored \(+1\) and \(-1\), respectively, and set \(E_b=a_b-c_b\).

Every \(+1\) edge increases competence by at least \(\alpha_b\). Every admissible \(-1\) edge increases it by at least \(-\beta_b\). Consequently, telescoping along the walk gives

\[ p_v^b-p_u^b \ge a_b\alpha_b-c_b\beta_b =\frac{\ell\delta_b+E_b(\alpha_b+\beta_b)}{2}. \]

In particular, a nonempty closed walk cannot have \(E_b\ge0\) in every state: its competence change would be zero, whereas the displayed lower bound would be strictly positive.

2. Every round produces an acyclic selected graph

Let \(R_i^{(t)}\) be type \(i\)'s committed certificate after round \(t\). Certificates are nonnegative integer vectors and are coordinatewise nondecreasing over time.

If type \(i\) has selected a port to \(j\) after round \(t\), let \(u\le t\) be the round of its last accepted replacement. Then

\[ R_i^{(t)}=R_j^{(u-1)}+e_{ij} \le R_j^{(t)}+e_{ij}, \]

where the inequality follows from monotonicity. This remains true when several replacements occur during a scan: take its last accepted replacement.

Suppose the selected type graph after round \(t\) contained a directed cycle. Summing these inequalities around that cycle would give a coordinatewise nonnegative total score. Section 1 rules out such a closed walk. Thus the selected type graph is acyclic after every round.

A type has no selected port exactly when its certificate is zero. Indeed, the first accepted replacement strictly dominates zero, and all subsequent replacements preserve that strict increase.

Now follow the selected path from \(i\) to its terminal type \(s\). Summing the selected-edge inequalities and using \(R_s^{(t)}=0\) gives

\[ 0\le R_i^{(t)}\le \sum_{\text{edges on the path}}e. \]

The acyclic path has at most \(\tau-1\) edges, and each score coordinate is at most \(1\). Therefore, for every type, state, and round,

\[ 0\le R_i^{(t),b}\le\tau-1. \]

This bound depends on the listed support size, not on the threshold denominators.

3. Polynomially many rounds suffice for the exact output

Define the integer potential

\[ S_t=\sum_{i=1}^{\tau}\sum_{b=1}^{m}R_i^{(t),b}. \]

The preceding bounds imply

\[ 0\le S_t\le K, \qquad K=m\tau(\tau-1). \]

If a round accepts any replacement, at least one integer certificate coordinate strictly increases. Retention and subsequent replacements cannot undo that increase, so \(S_t>S_{t-1}\).

If a round accepts no replacement, all certificates and selected ports remain unchanged. The next round receives exactly the same inputs and scans the same ordered ports, so it also changes nothing. The configuration is then permanently fixed.

There are therefore at most \(K\) rounds that change the configuration, and an unchanged round occurs by round \(K+1\). The following algorithm computes exactly the prescribed result:

  • Compute \(T\) using exact rational arithmetic.
  • Simulate synchronous rounds, preserving the stated scan order.
  • Stop after \(T\) rounds or at the first unchanged round.

The number of simulated rounds is at most

\[ Q=\min\{T,\;1+m\tau(\tau-1)\}. \]

Stopping at an unchanged round preserves the entire configuration that would be obtained after round \(T\), including its selected ports.

4. Terminal competence margins and path lengths

Apply Section 2 to the final selected graph. For a delegating source \(i\), let its path to \(s(i)\) have length \(\ell\ge1\) and score \(E\). Then \(E\ge R_i\ge0\) coordinatewise.

If \(\ell=1\), each coordinate of its single edge score must be \(+1\). Hence

\[ p_{s(i)}^b-p_i^b\ge\alpha_b\ge\delta_b. \]

If \(\ell\ge2\), Section 1 gives

\[ p_{s(i)}^b-p_i^b \ge\frac{\ell\delta_b}{2} \ge\delta_b. \]

Thus every delegating source satisfies the required terminal margin in every state.

Furthermore, competences lie in \([0,1]\), so

\[ 1\ge p_{s(i)}^b-p_i^b\ge\frac{\ell\delta_b}{2}. \]

It follows that

\[ \ell\le 2\min_b\frac1{\delta_b}\le T-1. \]

Combining this with acyclicity, every final selected path has length at most

\[ h=\min\{\tau-1,T-1\}. \]

5. The realization promise implies the mass-load bound

Let \(a_{ij}\) be the number of listed ports from type \(i\) to type \(j\), including repeated target types.

Choose any finite realization supplied by the promise, with \(N\mu_i\) vertices of type \(i\). Counting all incoming edges at vertices of type \(j\) yields

\[ N\sum_i\mu_i a_{ij}\le\Delta_{\mathrm{in}}N\mu_j. \]

After cancelling \(N\),

\[ \sum_i\mu_i a_{ij}\le\Delta_{\mathrm{in}}\mu_j. \]

This counting step uses the specified ports and the maximum in-degree bound. It requires neither constructing a realization nor expanding the masses into voters.

Let \(B\) be the selected type adjacency matrix: \(B_{ij}=1\) when type \(i\)'s final selected port targets \(j\), and \(B_{ij}=0\) otherwise. Terminal rows are zero. Since \(B_{ij}\le a_{ij}\), the mass row vector satisfies

\[ \mu B\le\Delta_{\mathrm{in}}\mu. \]

Nonnegativity of \(B\) then gives, inductively,

\[ \mu B^k\le\Delta_{\mathrm{in}}^k\mu \]

for every nonnegative integer \(k\), with the zeroth factor interpreted as \(1\).

For a terminal type \(j\), each source reaching \(j\) has one unique selected path, of length at most \(h\). Hence its total arriving mass is exactly

\[ M_j=\sum_{k=0}^{h}(\mu B^k)_j. \]

Therefore

\[ \lambda_j=\frac{M_j}{\mu_j} \le\sum_{k=0}^{h}\Delta_{\mathrm{in}}^k \le W_T. \]

This also covers \(\Delta_{\mathrm{in}}=0\).

6. Construction and running time

Represent \(D\) by one selected port index, or a terminal marker, per type. This representation has polynomial length. If terminal masses and densities are also wanted, initialize each type with mass \(\mu_i\), process the selected graph in topological order, and forward each accumulated mass through its selected port. This takes \(\tau\) rational additions.

Preprocessing examines \(mP\) competence comparisons. Each simulated round uses \(O(m(P+\tau))\) certificate additions, comparisons, and copying operations. Consequently, the simulation uses

\[ O\!\left(m(P+\tau)\min\{T,1+m\tau(\tau-1)\}\right) \]

elementary operations on integers of \(O(\log(\tau+1))\) bits, apart from port indices and counters.

For a conservative bit-complexity bound, schoolbook exact arithmetic gives total time

\[ O\!\left( [m(P+1)+\tau]L^2 + m(P+\tau)\min\{T,1+m\tau(\tau-1)\}L \right). \]

Here rational comparisons and the computation of \(T\) operate on \(O(L)\)-bit integers. Accumulated masses and terminal densities also have \(O(L)\)-bit representations: a common denominator can be chosen with bit length bounded by the total input denominator length.

There is no dependence on the numerical value of \(\Delta_{\mathrm{in}}\) beyond its encoding in \(L\). In particular, the algorithm does not enumerate a realization or materialize \(W_T\), whose binary expansion can be exponentially long.

For \(m=2\), \(Q\le1+2\tau(\tau-1)\), so the stated running time is polynomial in the binary input length. This completely settles the prescribed support-encoded construction on promised inputs.
