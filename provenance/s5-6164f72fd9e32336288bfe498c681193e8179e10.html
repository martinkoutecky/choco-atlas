Theorem 5 — class: other

The continuous mirror question, as graded

Given rational \(0\leq\alpha_1\leq\cdots\leq\alpha_m\) and rational rank proportions \(\rho_i>0\) summing to one, consider a society with buyer type \(i\) and seller type \(i\) each having mass \(\rho_i/2\), where a type \(i\) buyer and type \(j\) seller generate surplus \(\alpha_{\min(i,j)}\). For each scale \(n\) such that every \(n\rho_i\) is integral, form the finite assignment game with \(n\rho_i\) agents of each side and rank \(i\). Determine whether each type’s per-agent Shapley payoff converges as \(n\) grows through these scales, and compute the limiting vector.

Packaged proof task (what the prover saw — nothing else)

Let \(m\geq1\), with binary-rational data \(0\leq\alpha_1\leq\cdots\leq\alpha_m\) and \(\rho_i>0\), where \(\sum_{i=1}^m\rho_i=1\).
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational. Here buyer type \(i\) and seller type \(i\) each have mass \(\rho_i/2\), so \(\tau=2m\); support size means listed types, not possible types. Let \(L\) be the total input bit length.
For every positive integer \(n\) satisfying \(n\rho_i\in\mathbb Z\) for all \(i\), create \(n\rho_i\) buyers and \(n\rho_i\) sellers of rank \(i\). A rank-\(i\) buyer and rank-\(j\) seller have surplus \(\alpha_{\min(i,j)}\).
A coalition's worth is its maximum total matching surplus, using only its members; each agent participates in at most one pair, unmatched agents contribute zero, and the empty coalition has worth zero. Multiple optimal matchings require no tie-breaking.
Let \(\phi^B_{i,n}\) and \(\phi^S_{i,n}\) denote the ordinary Shapley payoffs of individual rank-\(i\) agents, without division by \(n\); agents of the same side and rank are interchangeable.

Do all \(\phi^B_{i,n}\) and \(\phi^S_{i,n}\) converge as \(n\to\infty\) through the admissible scales? Is determining convergence and computing the limiting vector polynomial-time in \(m,\tau,L\), or NP-hard?

Result

For every admissible scale \(n\) and every rank \(i\),
\[ \phi^B_{i,n}=\phi^S_{i,n}=\frac{\alpha_i}{2}. \]
Thus all requested sequences converge. Their limits are independent of the masses \(\rho_i\), and the limiting vector is exactly computable in polynomial time.

This agrees with Theorem 5.1 of [Martínez-de-Albéniz, Rafels and Ybern](https://diposit.ub.edu/server/api/core/bitstreams/261e8617-c0c2-48ea-af80-690e0180d88a/content), which identifies the Shapley value with the Becker allocation for the stated matrix form with weakly increasing diagonal values. The proof below establishes the finite formula directly, including repeated ranks and zero surplus increments.

Coalition-worth decomposition

Fix an admissible \(n\), and let \(N\) be its set of agents. Define
\[ \alpha_0=0,\qquad \Delta_k=\alpha_k-\alpha_{k-1}\geq 0 \quad (1\leq k\leq m). \]
For a coalition \(C\subseteq N\), let \(b_k(C)\) and \(s_k(C)\) be its numbers of buyers and sellers, respectively, whose ranks are at least \(k\).

We claim that its worth is
\[ v_n(C)=\sum_{k=1}^m\Delta_k\min\{b_k(C),s_k(C)\}. \tag{1} \]

For a buyer of rank \(i\) and a seller of rank \(j\), telescoping gives
\[ \alpha_{\min(i,j)} =\sum_{k=1}^m\Delta_k\,\mathbf 1_{\{i\geq k,\ j\geq k\}}. \]
Consequently, if \(M\) is any matching within \(C\), and \(t_k(M)\) counts its pairs whose two members both have rank at least \(k\), then
\[ \operatorname{surplus}(M)=\sum_{k=1}^m\Delta_k t_k(M). \]
Each such pair uses a distinct buyer and seller of rank at least \(k\). Hence
\[ t_k(M)\leq\min\{b_k(C),s_k(C)\}. \]
Since every \(\Delta_k\) is nonnegative, this proves the upper bound in (1).

To attain that bound simultaneously at all thresholds, list the coalition’s buyers and sellers in decreasing rank order. Write their ranks as
\[ u_1\geq\cdots\geq u_b,\qquad w_1\geq\cdots\geq w_s, \]
and match the agents in positions \(t\) for \(1\leq t\leq\min\{b,s\}\).

For any \(k\), the first \(b_k(C)\) buyers and the first \(s_k(C)\) sellers are exactly those of rank at least \(k\). Thus a matched position has both ranks at least \(k\) precisely when
\[ t\leq\min\{b_k(C),s_k(C)\}. \]
The constructed matching therefore satisfies
\[ t_k(M)=\min\{b_k(C),s_k(C)\} \]
for every \(k\), proving (1). If either side is empty, both sides of (1) are zero.

Shapley values of the threshold games

For each threshold \(k\), define a game on the same player set \(N\) by
\[ g_k(C)=\min\{b_k(C),s_k(C)\}. \]
Equation (1) is an identity of games:
\[ v_n=\sum_{k=1}^m\Delta_k g_k. \tag{2} \]

Recall that an agent’s ordinary Shapley payoff is its expected marginal contribution in a uniformly random ordering of all agents. This definition implies:

  • Linearity: marginal contributions, and therefore their expectations, are linear in the worth function.
  • Null-player property: an agent whose addition never changes coalition worth receives zero.
  • Relabeling symmetry: a permutation preserving every coalition’s worth also preserves the corresponding Shapley payoffs.
  • Efficiency: summing marginal contributions along any ordering telescopes to the grand-coalition worth.

In \(g_k\), agents of rank below \(k\) are null players. The active buyers and active sellers each number
\[ q_k=n\sum_{j=k}^m\rho_j. \]
This is a positive integer because \(n\) is admissible and every \(\rho_j\) is positive.

All active buyers are interchangeable in \(g_k\), as are all active sellers. Moreover, choose a bijection between the active buyers and active sellers and swap each paired buyer and seller, fixing the inactive agents. This permutation exchanges \(b_k(C)\) with \(s_k(C)\), so it preserves
\[ g_k(C)=\min\{b_k(C),s_k(C)\}. \]
Relabeling symmetry therefore makes the Shapley payoffs equal across both sides. All \(2q_k\) active agents have one common payoff.

Since \(g_k(N)=q_k\) and inactive agents receive zero, efficiency gives that common payoff as
\[ \frac{q_k}{2q_k}=\frac12. \]
Thus, for any buyer or seller \(a\) of rank \(i\),
\[ \operatorname{Sh}_a(g_k)= \begin{cases} \frac12,&k\leq i,\\ 0,&k>i. \end{cases} \]

Applying linearity to (2) now yields
\[ \operatorname{Sh}_a(v_n) =\frac12\sum_{k=1}^i\Delta_k =\frac{\alpha_i}{2}. \]
This proves the asserted formula at every admissible scale, without selecting among optimal matchings.

Convergence and computational complexity

The admissible scales are unbounded: if \(Q\) is a common multiple of the denominators of the rational masses, every positive multiple of \(Q\) is admissible. Because each payoff sequence is constant on these scales,
\[ \lim_{\substack{n\to\infty\\n\rho_j\in\mathbb Z\ \forall j}} \phi^B_{i,n} = \lim_{\substack{n\to\infty\\n\rho_j\in\mathbb Z\ \forall j}} \phi^S_{i,n} =\frac{\alpha_i}{2}. \]

On the promised input class, determining convergence always returns “yes.” Computing the limiting vector requires dividing each \(\alpha_i\) by two and writing the result for both listed types.

If \(\alpha_i=p_i/d_i\) is given by binary integers, one exact output representation is \(p_i/(2d_i)\), increasing its encoding length by at most a constant. Reduction to lowest terms, if required, also takes polynomial time. There are \(m\) divisions and \(\tau=2m\) output coordinates, with total output length \(O(L+\tau)\). No replicated population needs to be constructed.

Therefore the requested problem is polynomial-time solvable.
