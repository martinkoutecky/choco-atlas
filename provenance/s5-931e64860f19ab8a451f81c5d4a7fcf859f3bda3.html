The continuous mirror question, as graded

Given candidates \(C\), a scoring vector \(\alpha\), target candidate \(p\), and rational masses \(\mu_t\) over finite ranking-price types \(t=(\sigma_t,\pi_t)\) with \(\sum_t\mu_t=1\), decide whether deletion masses \(z_t\) exist with \(0\le z_t\le\mu_t\), \(\sum_t\pi_tz_t\le B\), and \(\sum_t(\mu_t-z_t)\alpha_{\mathrm{pos}_{\sigma_t}(p)}\ge\sum_t(\mu_t-z_t)\alpha_{\mathrm{pos}_{\sigma_t}(c)}\) for every \(c\in C\); equivalently, minimize \(\sum_t\pi_tz_t\) subject to these winner constraints.

Packaged proof task (what the prover saw — nothing else)

Given a nonempty candidate set \(C\) with \(m=|C|\), a target \(p\in C\), an input scoring vector \(\alpha\in\mathbb Z^m\) with \(\alpha_1\ge\cdots\ge\alpha_m\), and a budget \(B\in\mathbb Q_{\ge0}\), consider continuous priced control by deleting voter mass.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(t=(\sigma_t,\pi_t)\), where \(\sigma_t\) is a strict complete ranking of \(C\), \(\pi_t\in\mathbb Q_{\ge0}\) is the deletion price per unit mass, and \(\sum_t\mu_t=1\). The parameter \(\tau\) is the support size, not the number of possible types.
Let \(\operatorname{pos}_{\sigma_t}(c)\) denote the position of \(c\), counting the top position as \(1\). Deleting mass \(z_t\in\mathbb R\) costs \(\pi_tz_t\); retained mass is not renormalized, and tied maximum scorers are all winners, including when all mass is deleted.
The decision problem asks whether \(0\le z_t\le\mu_t\), \(\sum_t\pi_tz_t\le B\), and \(\sum_t(\mu_t-z_t)\alpha_{\operatorname{pos}_{\sigma_t}(p)}\ge\sum_t(\mu_t-z_t)\alpha_{\operatorname{pos}_{\sigma_t}(c)}\) for every \(c\in C\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is continuous priced control by deleting voter mass in \(\mathsf P\), or is it \(\mathsf{NP}\)-hard? If it is \(\mathsf{NP}\)-hard, is it nevertheless \(\mathsf{FPT}\) parameterized by \(m\)?

Discrete priced voter deletion for scoring rules is \(\mathsf{FPT}\) parameterized by the number of candidates ([Bredereck et al.](https://arxiv.org/pdf/1709.02850)).
Discrete unpriced voter deletion is \(\mathsf{NP}\)-complete for Borda, hence the priced problem is hard even with unit prices ([Hemaspaandra and Schnoor](https://arxiv.org/pdf/1604.05264)). No result for exactly the continuous problem above was identified in the search.

Result

Continuous priced control by deleting voter mass is in \(\mathsf P\). Consequently, it is also \(\mathsf{FPT}\) parameterized by \(m\).

This holds for the full stated problem: arbitrary binary-encoded integer scoring vectors, rational masses and prices, and an explicitly listed support of size \(\tau\).

1. Linear-program formulation

Index the supported types by \(t\in\{1,\ldots,\tau\}\). Introduce a real variable \(x_t\) for the retained mass of type \(t\), so that \(z_t=\mu_t-x_t\).

For each competitor \(c\in C\setminus\{p\}\), define the integer
\[ d_{ct}:=\alpha_{\operatorname{pos}_{\sigma_t}(p)} -\alpha_{\operatorname{pos}_{\sigma_t}(c)}. \]
Also define \(K:=\sum_{t=1}^{\tau}\pi_t\mu_t\), the cost of deleting all mass.

Consider the following rational linear feasibility problem, written here with each constraint indexed explicitly:

\(0\le x_t\le\mu_t\qquad(t\in\{1,\ldots,\tau\}),\)

\(\displaystyle\sum_{t=1}^{\tau}\pi_t x_t\ge K-B,\)

\(\displaystyle\sum_{t=1}^{\tau}d_{ct}x_t\ge0\qquad(c\in C\setminus\{p\}).\)

It has \(\tau\) variables and \(2\tau+m\) scalar inequalities.

Equivalence. Suppose first that a deletion vector satisfies the original requirements. Set \(x_t=\mu_t-z_t\). The deletion bounds give \(0\le x_t\le\mu_t\). Moreover,

\(\displaystyle\sum_t\pi_tz_t=K-\sum_t\pi_tx_t,\)

so the budget requirement is exactly the second constraint. Finally, the retained score of \(p\) minus that of \(c\) is exactly \(\sum_t d_{ct}x_t\), yielding every winner constraint.

Conversely, any feasible retained-mass vector gives \(z_t=\mu_t-x_t\). The same identities establish the deletion bounds, budget requirement, and all winner inequalities.

Thus the original instance is a yes-instance if and only if this linear system is feasible over the reals. Non-strict inequalities implement the specified tie convention, including the zero-mass society.

2. Encoding size and exact polynomial-time feasibility

We check that constructing the system does not cause an exponential increase in binary encoding length.

Each \(d_{ct}\) is the difference of two input integers, so its encoding length is \(O(L)\). All prices and mass bounds already occur in the input.

For the remaining right-hand side, write \(\pi_t=a_t/b_t\) and \(\mu_t=u_t/v_t\), with positive denominators. A common denominator for \(K\) is

\(\displaystyle D=\prod_{t=1}^{\tau}b_tv_t.\)

The binary length of \(D\) is bounded by the sum of the input denominator lengths, hence is \(O(L)\). Expressing each summand over \(D\) gives numerators of length \(O(L)\); adding \(\tau\) such numerators increases this bound by at most \(O(\log\tau)\). Since the support is explicitly listed, \(\tau\le O(L)\). Therefore \(K\), and then \(K-B\), have encoding length \(O(L)\). These quantities can be computed using polynomial-time integer arithmetic.

Consequently, a dense encoding of the linear system has length

\(S=O\!\left(\tau(m+\tau)L\right).\)

We now apply the standard rational linear feasibility theorem: feasibility over the reals of a finite system of non-strict linear inequalities with rational coefficients can be decided exactly in time polynomial in its binary encoding length. This is the polynomial-time linear-programming result of [Khachiyan](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here: every coefficient and right-hand side is rational, the system is explicitly encoded, and all inequalities are non-strict. The theorem also covers feasible sets of lower dimension, so ties require no interior-point assumption.

Constructing the coefficient table requires \(O(m\tau)\) score differences after extracting ranking positions. Including binary arithmetic and exact feasibility testing, the total running time is

\(\operatorname{poly}(m,\tau,L)=(m+\tau+L)^{O(1)}.\)

Because both \(m\) and \(\tau\) are bounded by the explicit input length, this is \(L^{O(1)}\). The bound is a bit-complexity bound; no strongly polynomial claim is needed.

3. Parameterization and the discrete comparison

A polynomial-time algorithm with running time \(O(L^k)\), for a universal constant \(k\), is also an \(\mathsf{FPT}\) algorithm parameterized by \(m\): it has the required form \(f(m)L^k\), with \(f(m)=1\).

The discrete hardness results do not establish hardness here. Discrete deletion requires integer deletion counts; this problem permits arbitrary fractional deletion mass. Relaxing those integer requirements changes feasibility, and the resulting problem is precisely the rational linear system proved equivalent above.

Therefore the stated continuous problem is polynomial-time solvable. Any \(\mathsf{NP}\)-hardness result for this exact problem under polynomial-time many-one reductions would imply \(\mathsf P=\mathsf{NP}\).
