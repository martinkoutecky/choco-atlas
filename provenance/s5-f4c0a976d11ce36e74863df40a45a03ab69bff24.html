The continuous mirror question, as graded

Given a finite tree \(T\) with rational edge lengths and a finite candidate set \(C\subseteq T\), determine whether there is a deterministic selector \(F\) from finitely supported rational probability measures on \(T\) to \(C\), with image exactly \(C\), such that no positive submeasure \(\lambda\leq\mu\) can be replaced by an equal-mass report \(\hat\lambda\) to produce \(\mu'=\mu-\lambda+\hat\lambda\) satisfying \(d(x,F(\mu'))>d(x,F(\mu))\) for \(\lambda\)-almost every true location \(x\).

Packaged proof task (what the prover saw — nothing else)

Given a nonempty finite tree \(T\) with \(m\) vertices and strictly positive binary rational edge lengths, regard each edge as a closed interval and let \(d\) be path distance. The input also contains a nonempty set \(C\subseteq T\) of \(p\) distinct candidates, encoded by edges and binary rational coordinates; let \(L\) be the total input bit length.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here types are locations anywhere in \(T\), masses sum to \(1\), and \(\tau\) is the support size, not the number of possible types.
Let \(\mathcal P_{\mathbb Q}^{\mathrm{fin}}(T)\) denote all finitely supported probability measures on \(T\) with rational masses, without a bound on support size. A deterministic anonymous selector is a function \(F:\mathcal P_{\mathbb Q}^{\mathrm{fin}}(T)\to C\); require its image to be exactly \(C\). Utility at true location \(x\) is \(d(x,F(\mu))\), with indifference at equal distances.
Require that, for every \(\mu\), every nonnegative rational-mass submeasure \(\lambda\leq\mu\) with \(\lambda(T)>0\), and every finitely supported nonnegative rational-mass report \(\hat\lambda\) on \(T\) with \(\hat\lambda(T)=\lambda(T)\), it is not the case that \(d(x,F(\mu-\lambda+\hat\lambda))>d(x,F(\mu))\) for \(\lambda\)-almost every \(x\). Coalitions may split the mass at a location and may include the whole society.
The decision input is \((T,C)\); no society or selector is supplied. State decision running times in \(m,p,L\); \(\tau\) is universally quantified, not an input bound. If society-processing running times are used, state them in \(m,p,\tau,L\).

Is deciding whether such a selector exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite societies of anonymous agents, such a group strategy-proof selector with image exactly \(C\) exists if and only if some point of \(T\) is equidistant from every candidate. [Oomine and Nagamochi (2016)](https://www.jstage.jst.go.jp/article/transinf/E99.D/3/E99.D_2015FCP0008/_article/-char/en)
No result settling this exact rational-mass selector-existence problem was located in the literature search.

Modeling choices made when packaging the task

  • Required a nonempty tree and nonempty candidate set, retaining the anchor's allowance of a single candidate.
  • Required strictly positive edge lengths to represent a tree metric without distinct points at zero distance.
  • Encoded candidates using binary rational edge coordinates so the existence question has a finite computational input; true and reported locations still range over the entire geometric tree.
  • Restricted coalition and replacement masses to rationals so reporting moves stay within the rational-mass model; partial mass at an atom may participate.
  • Made the selector's domain include every finite support size, with total society mass normalized to one.
  • Interpreted the computational question as existence of an arbitrary deterministic selector, without imposing computability, continuity, or a prescribed tie-breaking rule on it.

Result

The decision problem is in \(\mathrm P\). More precisely, such a selector exists if and only if some point of the tree is equidistant from every candidate.

The finite-agent theorem supplies necessity through a common-denominator reduction. Sufficiency follows from a selector defined directly on masses, with no bound on support size.

1. Necessity: reduce to a fixed finite number of agents

Suppose a selector \(F\) satisfying all the requirements exists. Because its image is exactly \(C\), for each \(c\in C\) choose a finitely supported rational-mass probability measure \(\mu_c\) satisfying \(F(\mu_c)=c\).

There are finitely many masses among these finitely many measures. Choose a positive integer \(n\) divisible by every denominator of these masses. Consequently, every \(\mu_c\) is an empirical measure of \(n\) equally weighted agents.

Define a finite-agent mechanism on all location profiles by

\(f(x_1,\ldots,x_n)=F\!\left(\frac1n\sum_{i=1}^{n}\delta_{x_i}\right).\)

This mechanism is deterministic and anonymous. Its image is exactly \(C\): its outputs belong to \(C\), and each witness \(\mu_c\) has a representing profile.

It is also group strategy-proof under the convention that manipulation requires every coalition member to improve strictly. Indeed, for a nonempty coalition \(S\subseteq\{1,\ldots,n\}\), let

\(\mu=\frac1n\sum_{i=1}^{n}\delta_{x_i},\qquad \lambda=\frac1n\sum_{i\in S}\delta_{x_i},\qquad \hat\lambda=\frac1n\sum_{i\in S}\delta_{\hat x_i}.\)

These are admissible measures: \(\lambda\leq\mu\), and \(\hat\lambda(T)=\lambda(T)>0\). If every agent in \(S\) strictly benefited, then the strict improvement inequality would hold at every positive-mass atom of \(\lambda\), contradicting the assumed property of \(F\). This argument also handles coalitions containing only some of the agents at a shared location.

We now apply the finite-agent theorem stated in the question: an anonymous deterministic group strategy-proof mechanism on a finite continuous tree, with full location domain and image exactly \(C\), requires a point equidistant from all candidates. The induced mechanism satisfies these hypotheses, including the same strict-improvement convention. [Oomine and Nagamochi, Theorem 1 and Definition 2](https://www.jstage.jst.go.jp/article/transinf/E99.D/3/E99.D_2015FCP0008/_pdf/-char/en).

Thus an equidistant point is necessary.

2. Sufficiency: construct a selector directly on masses

For \(|C|=1\), the constant selector has all the required properties. Hence assume \(|C|\geq2\), and suppose a point \(o\in T\) satisfies

\(d(o,c)=r\quad\text{for every }c\in C.\)

Distinctness of the candidates implies \(r>0\).

Let \(H=\bigcup_{c\in C}[o,c]\), rooted at \(o\). Subdivide the tree at \(o\) and at all candidates, retaining the original vertices. This gives a finite rooted representation of \(H\).

Every candidate is a leaf of \(H\): if another candidate were a strict descendant of a candidate \(c\), its distance from \(o\) would exceed \(d(o,c)=r\). Conversely, every leaf of \(H\) is a candidate, since \(H\) is a union of paths ending at candidates.

For a nonleaf vertex \(u\) of \(H\) and a child \(v\), define \(B(u,v)\) to be the connected component of \(T\setminus\{u\}\) containing \(v\). These components include any attached portions of the original tree outside \(H\). Fix, once and for all, an ordering of the children at each vertex.

For a society \(\mu\), define \(F(\mu)\) as follows:

  • Start at \(o\).
  • At a nonleaf vertex \(u\), choose the child \(v\) minimizing \(\mu(B(u,v))\), breaking ties by the fixed ordering.
  • Continue until reaching a leaf, and output that candidate.

This defines a deterministic anonymous selector for every society in the required domain.

2.1. The selector is group strategy-proof

Suppose, toward a contradiction, that an admissible coalition manipulation changes the output from \(a\) to \(b\), with every positive-mass coalition type strictly benefiting. Write

\(\mu'=\mu-\lambda+\hat\lambda,\qquad a=F(\mu),\qquad b=F(\mu').\)

Strict improvement requires \(a\ne b\). Let \(u\) be the first vertex where the two selected paths diverge. Let \(v_a\) and \(v_b\) be the corresponding distinct children, and put \(A=B(u,v_a)\).

Since both candidates are at distance \(r\) from the root, and \(u\) lies on both root-to-candidate paths,

\(d(u,a)=d(u,b)=r-d(o,u).\)

We claim that every point strictly preferring \(b\) to \(a\) belongs to \(A\). If \(x\notin A\), the path from \(x\) to \(a\) passes through \(u\), so

\(d(x,a)=d(x,u)+d(u,a).\)

By the triangle inequality and the equality of the two candidate distances from \(u\),

\(d(x,b)\leq d(x,u)+d(u,b)=d(x,a).\)

Thus strict preference for \(b\) is impossible outside \(A\). The assumed improvement of the coalition therefore implies \(\lambda(T\setminus A)=0\).

Let \(t=\lambda(T)=\hat\lambda(T)\). Then

\(\mu'(A)=\mu(A)-t+\hat\lambda(A)\leq\mu(A).\)

For every other child \(w\) of \(u\), disjointness of the components gives

\(\mu'(B(u,w))=\mu(B(u,w))+\hat\lambda(B(u,w)) \geq\mu(B(u,w)).\)

Originally, \(v_a\) minimized the branch mass. After the manipulation its branch mass has not increased, while every competing branch mass has not decreased. It remains selected, including under the fixed tie-breaking rule: any originally strict comparison stays strict; any originally tied competitor stays no better and had lower tie priority.

This contradicts the choice of \(u\) as a vertex where the outputs diverge. Hence no admissible coalition manipulation strictly benefits all its members.

The proof applies to arbitrary rational coalition masses, including split masses and the whole society.

2.2. The image is exactly \(C\)

It remains to prove that every candidate can be selected.

Fix \(c\in C\). List the branching vertices on the path from \(o\) to \(c\), starting with the deepest and proceeding toward the root. Construct an unnormalized measure supported on candidates as follows.

Initially the measure is zero. At a branching vertex \(u\), let \(M\) be the total mass already assigned inside the child component leading to \(c\). For each other child of \(u\), choose a candidate in its component and assign mass \(M+1\) there.

At this vertex, the component leading to \(c\) has mass \(M\), and every competing child component has mass \(M+1\). Subsequent assignments occur outside this vertex’s descendant components, so they do not change these comparisons.

There is at least one branching vertex because \(H\) has at least two leaves. The resulting measure therefore has positive finite integer total mass. Normalize it to obtain a finitely supported probability measure with rational masses.

For this society, the branch leading to \(c\) is the unique minimum at every branching vertex on its path. At vertices with one child there is no choice. Thus the selector outputs \(c\).

Since \(c\) was arbitrary, the image is exactly \(C\). This completes sufficiency and the characterization.

3. Testing the geometric condition

For \(|C|\geq2\), choose a pair \(a,b\in C\) maximizing candidate distance. Put

\(D=d(a,b),\qquad r=D/2,\)

and let \(o\) be the midpoint of \([a,b]\).

We prove that an equidistant point exists if and only if

\(d(o,c)=r\quad\text{for every }c\in C.\)

First, every candidate satisfies \(d(o,c)\leq r\). For \(c\ne o\), at least one endpoint \(e\in\{a,b\}\) lies in a different component of \(T\setminus\{o\}\) from \(c\). Therefore

\(d(c,e)=d(c,o)+r\leq D=2r,\)

where the inequality follows from maximality of the chosen candidate pair. The bound is immediate for \(c=o\).

Now suppose \(q\) is equidistant from all candidates, with common distance \(R\). Let \(z\) be the point where the path from \(q\) meets \([a,b]\). The tree-path identities give

\(d(q,a)=d(q,z)+d(z,a),\qquad d(q,b)=d(q,z)+d(z,b).\)

Equality of these distances forces \(z=o\), so \(R=d(q,o)+r\). For each candidate \(c\),

\(R=d(q,c)\leq d(q,o)+d(o,c)\leq d(q,o)+r=R.\)

Both inequalities must be equalities, yielding \(d(o,c)=r\). Conversely, if these equalities hold for all candidates, then \(o\) itself is an equidistant point.

Thus testing the midpoint of one candidate-diameter pair suffices.

4. Decision running time

Subdivide the input tree at the candidates. The resulting tree has at most \(m+p\) vertices.

The decision algorithm accepts immediately when \(p=1\). Otherwise, it:

  • Computes distances from each candidate by a tree traversal and chooses a maximum-distance candidate pair.
  • Locates their midpoint.
  • Computes distances from that midpoint and checks equality for every candidate.

Including subdivision and coordinate sorting, this uses \(O(p(m+p))\) exact rational arithmetic operations.

All intermediate rational values have \(O(L)\) bits: path lengths are sums of input rational quantities, and the midpoint adds only division by \(2\). Using elementary integer arithmetic and rational reduction, a conservative bit-operation bound is

\(O\!\left(p(m+p)L^3\right).\)

This is polynomial in the decision input parameters. No society is supplied or enumerated, and no bound on \(\tau\) enters either the algorithm or the existence proof.

If the outputs differ, the two selected paths have a first divergence vertex \(u\). Their common root distance implies

\[ d(u,a)=d(u,b)=r-d(o,u). \]

The tie-breaking conclusion also follows. A competitor originally having strictly larger mass remains strictly larger. An originally tied competitor cannot become strictly smaller, and if equality persists, its fixed priority still loses to \(v_a\).

The witness construction is valid.

Assignments made at earlier, deeper branching vertices lie in the child component leading toward \(c\). The competing components at the current vertex have not previously received mass, and assigning \(M+1\) gives exactly the stated strict comparisons.
