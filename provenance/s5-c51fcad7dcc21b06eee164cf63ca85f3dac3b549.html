The continuous mirror question, as graded

Given rational masses \(\mu_t\) over a finite set \(T\) of recipient types, item classes \(J\) with rational per-capita supplies \(q_j\), intrinsic values \(p_j\), and type eligibility sets \(E_t\), define bundles \(b\in\mathbb{Z}_{\ge 0}^{J}\) with \(b_j=0\) for \(j\notin E_t\), and utility \(u_t(b)=\sum_{j\in E_t}p_j b_j\). Let \(\mathrm{OPT}_\infty\) be the largest \(z\) for which there is a finite-support allocation \(x_{t,b}\ge 0\) satisfying \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}b_jx_{t,b}\le q_j\), and \(x_{t,b}>0\) only when \(u_t(b)\ge z\). Does a randomized algorithm, running in time polynomial in \(|T|\), \(|J|\), and the input bit length, return such an allocation with guarantee \(z\ge c\,\mathrm{OPT}_\infty\) for some universal constant \(c>0\)?

There are \(m=|J|\ge1\) item classes, with binary rational per-capita supplies \(q_j\ge0\), intrinsic values \(p_j\ge0\), and explicitly listed eligibility sets \(E_t\subseteq J\). Let \(L\) be the total input bit length.
An eligible bundle is \(b\in\mathbb Z_{\ge0}^{J}\) with \(b_j=0\) for \(j\notin E_t\); its utility is \(u_t(b)=\sum_{j\in E_t}p_jb_j\). A recipient may receive multiple copies from one class.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Yes. A deterministic polynomial-time algorithm achieves \(c=1/4\). Consequently, the requested randomized algorithm exists as well.

The proof uses a polynomial-size linear program whose flows represent mixtures of integer bundles. No discrete Santa Claus approximation theorem is needed.

1. Bounds and the zero case

Write \(U=\sum_{j\in J}p_jq_j\). Every allocation guaranteeing \(z\) satisfies

\( \displaystyle z=z\sum_t\mu_t\le \sum_{t,b}x_{t,b}u_t(b)=\sum_jp_j\sum_{t,b}b_jx_{t,b}\le U. \)

Thus \(\mathrm{OPT}_\infty\le U\).

If every intrinsic value is zero, return \(x_{t,0}=\mu_t\) and \(z=0\). Otherwise define

\( \displaystyle p_{\min}=\min\{p_j:p_j>0\}. \)

Every bundle of positive utility has utility at least \(p_{\min}\), because its copy counts are integers. Therefore, if any positive threshold is feasible, the same allocation guarantees \(p_{\min}\). In particular,

\( \displaystyle \mathrm{OPT}_\infty>0\quad\Longrightarrow\quad \mathrm{OPT}_\infty\ge p_{\min}. \)

We next construct, for each positive rational target \(a\), a polynomial-size rational linear program \(P(a)\) with these properties:

  • If \(a\) is feasible in the original problem, then \(P(a)\) is feasible.
  • From a feasible solution of \(P(a)\), we can extract an explicit feasible allocation guaranteeing \(a/2\).

The construction runs in time polynomial in the input length and the binary encoding length of \(a\).

2. Encoding bundles by binary groups

Fix a supported type \(t\). Classes of zero intrinsic value can be omitted: deleting their copies preserves utility and decreases resource consumption.

For each eligible class with \(p_j>0\), set

\( \displaystyle B_j=\left\lceil\frac{a}{p_j}\right\rceil. \)

Every eligible bundle \(b\) of utility at least \(a\) can be replaced by a bundle \(\bar b\le b\) satisfying

\( \displaystyle \bar b_j\le B_j,\qquad u_t(\bar b)\ge a. \)

Indeed, delete zero-value copies and replace each remaining \(b_j\) by \(\min\{b_j,B_j\}\). If no positive-value coordinate changes, utility is preserved. If a coordinate changes, that coordinate alone contributes \(p_jB_j\ge a\) afterward.

For each such class introduce groups containing respectively

\( \displaystyle 1,2,4,\ldots,2^{H_j}\quad\text{copies},\qquad H_j=\lfloor\log_2 B_j\rfloor. \)

Every integer count between zero and \(B_j\) has a binary expansion using these groups. Thus every truncated bundle above corresponds to selecting a subset of groups.

Let the groups for type \(t\) be indexed by \(i=1,\ldots,n_t\). Group \(i\) contains \(c_i\) copies of class \(j_i\), and has utility \(v_i=c_ip_{j_i}\). Selecting groups always produces an eligible integer bundle. Some selections may use more than \(B_j\) copies; this causes no difficulty because their actual consumption will be constrained by the linear program.

If \(n_t=0\), this type cannot receive positive utility. In that case declare \(P(a)\) infeasible.

3. Rounding utility with a proved guarantee

Suppose \(n=n_t>0\). Define

\( \displaystyle \delta_t=\frac{a}{2n},\qquad r_i=\left\lfloor\frac{\min\{v_i,a\}}{\delta_t}\right\rfloor. \)

Each \(r_i\) is an integer between zero and \(2n\). Call a subset \(S\) of groups accepted when \(\sum_{i\in S}r_i\ge n\).

Soundness. Every accepted subset has utility at least \(a/2\), since

\( \displaystyle \sum_{i\in S}v_i\ge\delta_t\sum_{i\in S}r_i\ge\delta_t n=\frac a2. \)

Completeness. Every subset of groups having utility at least \(a\) is accepted.

To prove this, first observe that

\( \displaystyle \sum_{i\in S}\min\{v_i,a\}\ge a. \)

If some selected group has utility at least \(a\), its capped utility already equals \(a\). Otherwise capping changes nothing. Consequently,

\( \displaystyle \sum_{i\in S}r_i \ge \frac{\sum_{i\in S}\min\{v_i,a\}}{\delta_t}-|S| \ge 2n-n=n. \)

Combined with the truncation and binary encoding, this proves that every original bundle meeting target \(a\) has a replacement using no additional resources that corresponds to an accepted subset.

4. A polynomial-size flow formulation

For each type \(t\), construct a layered directed acyclic multigraph. Its vertices are

\( \displaystyle (i,h),\qquad 0\le i\le n_t,\quad 0\le h\le n_t. \)

The source is \(s_t=(0,0)\), and the sink is \(d_t=(n_t,n_t)\).

For every group \(i\) and every state \(h\), introduce two arcs:

  • A skip arc from \((i-1,h)\) to \((i,h)\).
  • A take arc from \((i-1,h)\) to \((i,\min\{n_t,h+r_i\})\).

Keep these arcs distinct even when their endpoints coincide. A take arc consumes \(c_i\) copies of class \(j_i\); a skip arc consumes nothing.

Along a path, the state after processing \(i\) groups equals the sum of their selected rounded utilities, capped at \(n_t\). Therefore source-to-sink paths correspond exactly to accepted subsets. The graph has \(O(n_t^2)\) vertices and arcs.

Introduce a nonnegative flow variable \(f_{t,e}\) for each arc. The linear program \(P(a)\) requires:

  • Flow of value \(\mu_t\) from \(s_t\) to \(d_t\), with conservation at every other vertex.
  • For every class \(j\), the resource constraint

\( \displaystyle \sum_t\sum_{\substack{e\text{ is a take arc}\\j(e)=j}}c(e)f_{t,e}\le q_j. \)

Here \(j(e)\) and \(c(e)\) identify the class and copy count of the group taken on arc \(e\).

These constraints apply to actual integer copy counts; utility rounding does not relax any supply constraint.

Completeness of the linear program

Suppose an original allocation guarantees \(a\). Replace each of its bundles by the truncated, binary-encoded accepted subset constructed above. Route that bundle’s mass along the corresponding source-to-sink path.

The resulting flows have values \(\mu_t\), satisfy conservation, and consume no more of any class than the original allocation. Hence \(P(a)\) is feasible.

Extracting an allocation

Given a feasible rational flow, repeatedly choose a source-to-sink path of positive flow, subtract the minimum flow on its arcs, and record that amount as the path’s mass.

Conservation ensures that a positive-flow walk starting at the source can continue until the sink; acyclicity ensures termination. Each subtraction removes at least one positive-flow arc, so there are at most as many recorded paths as arcs. After all source flow is extracted, no residual positive flow can remain: tracing any such flow backward in the acyclic graph would reach a vertex violating conservation.

For each recorded path, give its mass to the integer bundle formed by its take arcs. The path masses sum to \(\mu_t\), and their resource consumption equals the original flow consumption. Every path is accepted, so every resulting bundle has utility at least \(a/2\).

This proves both required properties of \(P(a)\).

5. Bit complexity and explicit output

Use the standard exact rational linear-programming theorem: feasibility can be decided in polynomial time in the encoding length, and a feasible rational point can be produced with polynomial encoding length. This is the polynomial-time rational LP result originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here: \(P(a)\) is an explicitly listed finite system of rational linear equalities and inequalities. Its coefficients are copy counts, supplies, and type masses.

Furthermore,

\( \displaystyle n_t=\sum_{\substack{j\in E_t\\p_j>0}}\bigl(1+\lfloor\log_2 B_j\rfloor\bigr). \)

Thus \(n_t\), the graph size, and the coefficient encoding lengths are polynomial in the input length and the encoding length of \(a\). Large copy counts appear in binary, rather than as individually listed copies.

The path decomposition also preserves polynomial encoding length. If the returned arc flows have a common denominator \(D\), all subsequent path masses have denominator dividing \(D\). Taking \(D\) to be the product of their denominators gives polynomial binary length, because there are polynomially many arc flows of polynomial encoding length. Each path bundle is a sum of polynomially many binary integer group counts.

Consequently, the extracted allocation has polynomially many entries, with binary integer bundles and binary rational masses, and can be computed in polynomial time.

6. Choosing the target and proving the approximation

Consider the geometric targets

\( \displaystyle a_k=\frac{p_{\min}}2\,2^k,\qquad k=0,1,\ldots,\quad a_k\le U. \)

Construct and solve \(P(a_k)\) for every listed target. If any are feasible, choose the largest feasible target \(a_*\), extract its allocation, and return \(z=a_*/2\). If none are feasible, return the zero-bundle allocation and \(z=0\).

There are polynomially many targets. Indeed, every positive input rational lies between \(2^{-L}\) and \(2^L\), so

\( \displaystyle U\le m2^{2L},\qquad p_{\min}\ge2^{-L}. \)

The number of targets is therefore \(O(L+\log m)\). Their binary encoding lengths are polynomial as well.

If \(\mathrm{OPT}_\infty=0\), feasibility of the returned allocation proves the required inequality.

Now suppose \(\mathrm{OPT}_\infty>0\). Since \(\mathrm{OPT}_\infty\ge p_{\min}\), there exists a largest geometric target \(a_k\) strictly below \(\mathrm{OPT}_\infty\). It satisfies

\( \displaystyle a_k<\mathrm{OPT}_\infty\le2a_k. \)

This target is included in the list because \(a_k<U\). By the definition of supremum, there is a feasible threshold strictly greater than \(a_k\); its allocation also guarantees \(a_k\). Thus \(P(a_k)\) is feasible.

The algorithm therefore chooses \(a_*\ge a_k\) and returns

\( \displaystyle z=\frac{a_*}{2}\ge\frac{a_k}{2}\ge\frac14\,\mathrm{OPT}_\infty. \)

This argument does not assume that the supremum is attained.

The algorithm is deterministic, always returns a feasible allocation in the required representation, and runs in polynomial time in \(m,\tau,L\). Hence its expected running time also meets the requested bound.
