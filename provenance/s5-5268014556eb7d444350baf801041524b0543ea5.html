The continuous mirror question, as graded

Given finite resident types \(T\), apartment classes \(O\), rational type masses \(\mu_t\), rational supplies \(q_o\), and valuations \(v_t(o)\), choose a transport \(x_{t,o}\ge 0\) with row sums \(\mu_t\) and column sums \(q_o\) that minimizes the supremum average envy weight over finite directed cycles of distinct residents. Each unit of mass receives one indivisible apartment; \(x_{t,o}\) records the share of type \(t\) assigned to class \(o\), and an arc from resident \(i\) to resident \(j\) has weight \(v_{\theta(i)}(a(j))-v_{\theta(i)}(a(i))\).

Packaged proof task (what the prover saw — nothing else)

A society is atomless and given by its support: a list of \(\tau=|T|\) resident types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m=|O|\geq1\) apartment classes with positive binary-rational supplies \(q_o\), summing to \(1\), and positive binary-rational valuations \(v_t(o)\). Apartments within a class are interchangeable.
A feasible allocation is a real transport \(x_{t,o}\geq0\) satisfying \(\sum_o x_{t,o}=\mu_t\) and \(\sum_t x_{t,o}=q_o\). It assigns one indivisible apartment to each resident; \(x_{t,o}\) is the mass of type \(t\) receiving class \(o\).
Only positive-mass assignment cells are represented. Every such cell contains arbitrarily many distinct residents. A directed cycle has \(k\geq2\) distinct residents, although their type–class pairs may repeat.
Define \(F(x)=\sup\left\{\frac1k\sum_{\ell=1}^{k}\bigl(v_{t_\ell}(o_{\ell+1})-v_{t_\ell}(o_\ell)\bigr): k\geq2,\ x_{t_\ell,o_\ell}>0\right\}\), with \(o_{k+1}=o_1\). The optimization problem is to minimize \(F(x)\).
Given also a binary-rational threshold \(b\), the decision problem asks whether some feasible \(x\) satisfies \(F(x)\leq b\). Let \(L\) be the total input bit length, including \(b\).

Is this continuous allocation decision problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finitely many residents and equally many individual apartments, minimizing the maximum average envy-cycle weight is polynomial-time solvable by maximum-weight matching. [Discrete result](https://arxiv.org/html/2507.20253v2)
No result settling the exact atomless transport problem above was located in the literature search.

  • The distribution's normalization was unspecified; resident masses and apartment supplies both sum to one.
  • The resident realization was unspecified; use an atomless society, with only positive-mass assignment cells represented, excluding exceptional assignments to zero-mass sets.
  • Distinct residents need not have distinct types or assigned classes; allow repeated type–class pairs in cycles of any finite length at least two, excluding self-loops.
  • Valuation signs and encoding were unspecified; retain strictly positive valuations from the discrete definition and restrict them to binary rationals for computational input.
  • Apartment-class supplies are positive; classes with zero supply are omitted, and apartments within each class are interchangeable.
  • Transport entries may be real and represent population shares, while each resident receives one indivisible apartment.
  • To state a decision complexity target for the minimization question, introduce an unrestricted binary-rational threshold and include its encoding in the input length.

Result

The decision problem is in \(\mathrm{P}\). In fact, for every instance satisfying the stated hypotheses,

\(\displaystyle \min_{x\text{ feasible}} F(x)=0.\)

Consequently, the answer is yes if and only if \(b\geq 0\).

The permission to repeat type–class pairs forces the lower bound \(0\). The substantive step is proving that this bound is attainable for arbitrary supplies, masses, and valuations.

1. Every feasible allocation has a zero-weight cycle

Let \(x\) be feasible. Since its entries sum to \(1\), some cell satisfies \(x_{t,o}>0\).

By hypothesis, this cell contains at least two distinct residents. Choose these residents as a cycle of length \(2\). Both receive class \(o\), so both edge weights equal \(v_t(o)-v_t(o)=0\).

Thus \(0\) is an admissible cycle average, and

\(\displaystyle F(x)\geq 0.\)

This argument uses distinct residents, as required; only their type–class pairs repeat.

2. A welfare-maximizing transport has no positive-weight cycle

Define total welfare by

\(\displaystyle W(x)=\sum_{t\in T}\sum_{o\in O}v_t(o)x_{t,o}.\)

The feasible transport set is nonempty: \(x_{t,o}=\mu_tq_o\) satisfies both marginal constraints. It is closed and bounded in the finite-dimensional space of transport matrices, hence compact. Since \(W\) is continuous, a feasible maximizer \(x^*\) exists.

We prove that every admissible cycle under \(x^*\) has nonpositive total weight.

Fix such a cycle, represented by \((t_\ell,o_\ell)\) for \(1\leq\ell\leq k\), with \(o_{k+1}=o_1\). Its total weight is

\(\displaystyle G=\sum_{\ell=1}^{k}\bigl(v_{t_\ell}(o_{\ell+1})-v_{t_\ell}(o_\ell)\bigr).\)

Suppose, for contradiction, that \(G>0\). For each cell, define the integer multiplicities

\(\displaystyle a_{t,o}=\bigl|\{\ell:t_\ell=t,\ o_\ell=o\}\bigr|,\qquad c_{t,o}=\bigl|\{\ell:t_\ell=t,\ o_{\ell+1}=o\}\bigr|.\)

Here \(a_{t,o}\) counts removals and \(c_{t,o}\) counts additions in the cyclic reassignment. Whenever \(a_{t,o}>0\), admissibility gives \(x^*_{t,o}>0\). Therefore

\(\displaystyle \varepsilon=\frac12\min_{a_{t,o}>0}\frac{x^*_{t,o}}{a_{t,o}}>0.\)

Set

\(\displaystyle x'_{t,o}=x^*_{t,o}+\varepsilon(c_{t,o}-a_{t,o}).\)

We check feasibility explicitly.

  • Nonnegativity. If \(a_{t,o}>0\), then \(x'_{t,o}\geq x^*_{t,o}-\varepsilon a_{t,o}\geq x^*_{t,o}/2>0\). If \(a_{t,o}=0\), then \(x'_{t,o}\geq x^*_{t,o}\geq0\).
  • Type marginals. For each type \(t\), every occurrence of that type contributes one removal and one addition. Hence \(\sum_o a_{t,o}=\sum_o c_{t,o}\).
  • Class marginals. The list \(o_2,\ldots,o_k,o_1\) is a cyclic permutation of \(o_1,\ldots,o_k\). Hence \(\sum_t a_{t,o}=\sum_t c_{t,o}\) for every class \(o\).

Thus \(x'\) is feasible, including when cells repeat in the cycle. Its welfare satisfies

\(\displaystyle W(x')-W(x^*)=\varepsilon\sum_{t,o}v_t(o)(c_{t,o}-a_{t,o})=\varepsilon G>0.\)

This contradicts the maximality of \(x^*\). Therefore every admissible cycle has nonpositive total weight, and consequently \(F(x^*)\leq0\).

Section 1 gives \(F(x^*)\geq0\), so \(F(x^*)=0\). This proves the claimed minimum.

3. Exact decision complexity

On inputs satisfying the stated promises, the algorithm simply tests whether \(b\geq0\).

If \(b<0\), Section 1 excludes every feasible allocation. If \(b\geq0\), the welfare maximizer constructed existentially in Section 2 satisfies \(F(x^*)=0\leq b\).

Comparing a binary-rational number with zero takes time polynomial in its encoding length, and hence polynomial in \(m,\tau,L\). No resident expansion or allocation computation is needed for the decision problem.

If an optimal allocation is also requested, it can be obtained by maximizing \(W(x)\) over the transportation constraints. This is a rational linear program with \(\tau m\) variables, \(\tau+m\) marginal equalities, and encoding length polynomial in the input length. The polynomial-time solvability theorem for rational linear programming therefore applies.

4. Relation to the discrete result

The [cited discrete paper](https://arxiv.org/html/2507.20253v2) likewise proves that welfare-maximizing assignments have no positive envy cycle. The additional feature here is that every positive-mass cell supplies two distinct residents with identical type–class pairs, guaranteeing a zero-weight cycle. Together, these facts settle the exact atomless problem stated in the question.
