The continuous mirror question, as graded

Given a finite support \(X\subseteq\mathbb{Q}^d\) with positive rational masses \(\mu_x\) summing to \(1\), labeled candidate sites \(C\) at locations \(p_c\in\mathbb{Q}^d\), a committee \(T\subseteq C\), and a failed set \(J\subseteq C\), compute a replacement \(R\subseteq C\setminus J\), with \(|R|\le |T\cap J|\), minimizing \(\max_{x\in\operatorname{supp}(\mu)}\min_{c\in(T\setminus J)\cup R}\|x-p_c\|_2\).

A society is given by its support: a nonempty list \(X\subseteq\mathbb{Q}^d\) of \(\tau\) types with positive binary rational masses \(\mu_x\), summing to \(1\). Here \(\tau=|X|\) is the support size, not the number of possible types.
Fix any dimension \(d\geq2\). There are \(m\) labeled candidates \(C\), with locations \(p_c\in\mathbb{Q}^d\); distinct labels may share a location. The input also contains a nonempty committee \(T\subseteq C\) and a failing set \(J\subseteq C\), which may include candidates outside \(T\).
Write \(k=|T|\) and \(b=|T\cap J|\), both unrestricted input quantities. A replacement is a set \(R\subseteq C\setminus J\) with \(|R|\leq b\); every surviving member of \(T\) must remain.
Its score is \(s(R)=\max_{x\in X}\min_{c\in(T\setminus J)\cup R}\|x-p_c\|_2\), with the minimum over an empty committee defined as \(+\infty\). Compute a replacement minimizing this score; any minimizer is acceptable.
For the decision version, an additional binary rational threshold \(r\geq0\) is given, and the question is whether some replacement has \(s(R)\leq r\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L,k,b\), with \(d\) fixed.

Is this mass-society optimal-replacement decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard, for each fixed \(d\geq2\)?

Result

For every fixed \(d\geq2\), the mass-society optimal-replacement decision problem is \(\mathrm{NP}\)-complete. Computing an optimal replacement is therefore \(\mathrm{NP}\)-hard. Hardness already holds with equal masses, \(T=J\), and the fixed threshold \(r=3/4\).

The masses do not affect the stated maximum-distance objective. The relevant society parameter is the explicitly listed support size \(\tau\).

1. Exact verification and membership in \(\mathrm{NP}\)

Let \(S=T\setminus J\). A certificate consists of candidate labels specifying \(R\). We check \(R\subseteq C\setminus J\) and \(|R|\leq b\), and then check, for every \(x\in X\), whether some \(c\in S\cup R\) satisfies
\(\sum_{j=1}^{d}(x_j-p_{c,j})^2\leq r^2\).

Because \(r\geq0\), this inequality is equivalent to \(\|x-p_c\|_2\leq r\). Thus no square-root computation is required. If \(S\cup R=\varnothing\), verification rejects: the support is nonempty and the score is infinite.

Since \(d\) is fixed, each squared distance has a rational representation of \(O(L)\) bits. Schoolbook integer arithmetic gives an \(O(L^2)\) bound for each distance computation and comparison. Moreover,
\(|S\cup R|\leq(k-b)+b=k\).
Consequently, verification takes \(O(L+\tau kL^2)\) bit operations. The certificate uses \(O(b\log(m+1))\) bits, so the decision problem belongs to \(\mathrm{NP}\).

2. A polynomial reduction from discrete societies

Consider a discrete instance with a nonempty explicitly listed voter collection \(V=(v_1,\ldots,v_n)\), rational locations, and the same candidate data, committee, failures, and threshold.

Construct
\(X=\{v_i:1\leq i\leq n\}\),
removing duplicate voter locations. Write \(\tau=|X|\), and assign \(\mu_x=1/\tau\) to every \(x\in X\). These are positive binary-encoded rational masses summing to \(1\).

For every replacement \(R\), we have
\(\max_{1\leq i\leq n}\min_{c\in(T\setminus J)\cup R}\|v_i-p_c\|_2 =\max_{x\in X}\min_{c\in(T\setminus J)\cup R}\|x-p_c\|_2\).
Indeed, duplicate voter locations contribute identical terms to the maximum. This equality also holds for an empty resulting committee, when both sides are infinite.

Candidate labels, \(T\), and \(J\) are preserved. Hence the admissible replacements are identical, and each replacement has exactly the same score in both instances.

Duplicate removal takes polynomial time using exact rational comparisons. The masses add \(O(\tau\log(\tau+1))\) bits, and \(\tau\leq n\). Thus this transformation is a polynomial-time many-one reduction that preserves both decision answers and optimal replacements.

3. Applying the known hardness result

We use the planar discrete hardness construction of Sonar, Suri, and Xue. Their full version, Section 3.1 and Lemma 13, reduces Planar Monotone 3-SAT to the existence of a replacement at radius \(3/4\), with \(T=J=C_{\mathrm{cov}}\). Its reference points have integer coordinates, and its gadget offsets are \(1/5\), \(3/10\), and \(2/5\); the construction has polynomial size and polynomial coordinate encoding length. It explicitly permits distinct candidate labels at a common location. [Full proof](https://arxiv.org/pdf/2308.07268).

These properties check the encoding hypotheses needed here: the source instances have rational coordinates, a rational threshold, a nonempty voter collection, and a nonempty committee. The construction’s nonfailed candidate set contains at least \(k\) labels. Therefore its characterization using replacements of size exactly \(k\) also applies to replacements of size at most \(k\): any smaller feasible replacement can be enlarged to size \(k\), and adding candidates cannot increase the score.

Apply the transformation in Section 2 to these planar instances. It preserves feasibility, gives valid equal masses, and preserves \(b=k\) and \(r=3/4\). The mass-society decision problem in dimension \(2\) is therefore \(\mathrm{NP}\)-hard.

For any fixed \(d>2\), replace every planar location \((a_1,a_2)\) by \((a_1,a_2,0,\ldots,0)\). This preserves every Euclidean distance and increases the encoding length only polynomially. Hardness therefore holds in every fixed \(d\geq2\).

Together with Section 1, this proves \(\mathrm{NP}\)-completeness. An algorithm producing any optimal replacement would decide these instances by comparing its score with \(3/4\); thus the optimization problem is \(\mathrm{NP}\)-hard.

4. Exact algorithms and parameter dependence

The classification concerns unrestricted \(\tau\), \(k\), and \(b\). The following algorithms give explicit bounds for restricted parameters.

Enumeration: polynomial time for fixed \(b\)

We may restrict attention to replacements contained in \(A=C\setminus(J\cup T)\). Removing surviving committee members from \(R\) preserves the resulting committee and weakly decreases replacement size.

Let \(q=|A|\) and
\(E(q,b)=\sum_{i=0}^{\min(b,q)}\binom qi\).
Precompute the squared distances and each type’s distance to its closest survivor. Enumerate every subset of \(A\) of size at most \(b\), evaluating its resulting squared score, and return one with minimum score.

This computes an optimal replacement in
\(O\!\left(L+\left[m\tau+\tau(b+1)E(q,b)\right]L^2\right)\)
bit operations. For fixed \(b\), this is polynomial. Since \(b\leq k\), it is also polynomial for fixed \(k\). The algorithm handles infinite scores directly; if every replacement has infinite score, the empty replacement is a minimizer.

Dynamic programming: polynomial time for fixed \(\tau\)

For a rational squared threshold \(\alpha\geq0\), let \(U\subseteq X\) consist of the types not covered by survivors within squared distance \(\alpha\). For each \(c\in A\), define
\(H_c=\{x\in U:\|x-p_c\|_2^2\leq\alpha\}\).

Feasibility is exactly the existence of at most \(b\) sets \(H_c\) whose union is \(U\).

Process the candidates one at a time. For every \(W\subseteq U\), store the minimum number of processed candidates whose coverage union is exactly \(W\). Initially, the empty union has value \(0\), and all other values are infinite. Processing candidate \(c\) allows either retaining \(W\), or obtaining \(W\cup H_c\) at one additional candidate. These two choices exhaust all subsets of the processed candidates, proving the recurrence by induction.

The final value for \(U\) is at most \(b\) exactly when the threshold is feasible. Predecessors recover a replacement. A conservative running-time bound is
\(O(L+m\tau 2^\tau L^2)\)
bit operations.

For optimization, every finite score squared is one of the at most \(m\tau\) values \(\|x-p_c\|_2^2\): the minimum for each type and the maximum over the finite support are attained. Sort these rational values and binary-search feasibility using the same dynamic program. Monotonicity follows because increasing \(\alpha\) only adds coverage possibilities. This computes an optimal replacement in
\(O\!\left(L+m\tau 2^\tau L^2\log(2+m\tau)\right)\)
bit operations, including sorting and reconstruction.

If no nonempty committee can be formed, every score is infinite and we return the empty replacement. Otherwise, the largest relevant squared distance is feasible, so the search finds a finite optimum.

Thus fixed support size yields a polynomial-time algorithm, while unrestricted support size yields the \(\mathrm{NP}\)-complete decision problem proved above.
