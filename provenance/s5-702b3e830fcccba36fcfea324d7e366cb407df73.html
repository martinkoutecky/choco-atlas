The continuous mirror question, as graded

Given rational type masses \(\mu_1,\ldots,\mu_k>0\) summing to \(1\), and rational values \(v_1>\cdots>v_k>0\) for one divisible good, let \(M_s=\sum_{i=1}^s\mu_i\), \(v_{k+1}=0\), and \(\Phi_i=\sum_{s=i}^k (v_s-v_{s+1})/M_s\). Find the minimum \(\alpha\) and rates \(x_i\ge 0\) such that \(\sum_i\mu_i x_i=1\) and \(v_i x_i\ge\Phi_i/\alpha\) for each type. Here a type-\(i\) agent receives \(x_i/n\) in a finite replica of size \(n\), and its Shapley value is \(\Phi_i/n\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau=k\ge1\) types with positive mass, each mass encoded as a binary rational; \(\tau\) is the support size, not the number of possible types. There is one unit of one divisible good, so \(m=1\). Input masses satisfy \(\sum_{i=1}^k\mu_i=1\), and binary rational values satisfy \(v_1>\cdots>v_k>0\). Let \(L\) be the total input bit length.
Define \(M_s=\sum_{i=1}^s\mu_i\), \(v_{k+1}=0\), and the entitlement rate \(\Phi_i=\sum_{s=i}^k(v_s-v_{s+1})/M_s\).
An allocation consists of real rates \(x_i\ge0\) with \(\sum_i\mu_i x_i=1\); its type utility rate is \(v_i x_i\). Rates have no individual upper cap. In a finite replica with \(n\mu_i\) agents of each type, each receives \(x_i/n\) and has Shapley value \(\Phi_i/n\).
The optimization problem asks for the minimum \(\alpha\ge1\) and corresponding rates satisfying \(v_i x_i\ge\Phi_i/\alpha\) for every type. Its decision version additionally takes a binary rational threshold \(A\ge1\) and asks whether such rates exist with \(\alpha\le A\).

Is this continuous optimization problem solvable exactly in polynomial time in \(m,\tau,L\), or is its decision version NP-hard?

For finite societies with \(k\) valuation types, a polynomial-time algorithm computes \(k\)-approximate Shapley Value Fair allocations; the dependence on \(k\) is asymptotically tight when \(k=o(\ln n)\).
For finite societies with linear valuations, exact Shapley values and an optimal Shapley Value Fair allocation are computable in polynomial time. These results concern finite agent lists rather than the support-encoded mass problem.

Modeling choices made when packaging the task

  • The graded question omitted the domain of the approximation factor; imposed alpha ≥ 1, as required by the discrete fairness definition.
  • Specified that allocation rates are nonnegative real numbers without an individual upper cap, since they represent n times a finite agent's allocated fraction.
  • Introduced a binary rational decision threshold A ≥ 1 to make the NP-hardness alternative precise; its encoding is included in L.
  • Identified k with the support size tau and fixed m = 1; replica size n is explanatory and is not an input parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The support-encoded problem with \(m=1\) is exactly solvable in polynomial time. Define

\[ S=\sum_{i=1}^{k}\frac{\mu_i\Phi_i}{v_i}. \]

The optimal value and the unique optimal allocation are

\[ \alpha^\star=S, \qquad x_i^\star=\frac{\Phi_i}{v_iS}. \]

The decision problem answers yes exactly when \(S\le A\).

Proof of optimality

All masses and values are positive. Therefore every prefix mass satisfies \(0<M_s\le1\), and every difference \(v_s-v_{s+1}\) is positive. Consequently,

\[ \Phi_i =\sum_{s=i}^{k}\frac{v_s-v_{s+1}}{M_s} \ge\sum_{s=i}^{k}(v_s-v_{s+1}) =v_i. \]

Multiplying by \(\mu_i/v_i\) and summing gives

\[ S\ge\sum_{i=1}^{k}\mu_i=1. \]

Now let \(\alpha\ge1\) and suppose an allocation satisfies every fairness constraint. Since \(v_i>0\), these constraints imply

\[ x_i\ge\frac{\Phi_i}{\alpha v_i}. \]

Using the resource constraint and positive masses,

\[ 1=\sum_{i=1}^{k}\mu_i x_i \ge\frac{1}{\alpha}\sum_{i=1}^{k}\frac{\mu_i\Phi_i}{v_i} =\frac{S}{\alpha}. \]

Thus every feasible \(\alpha\) satisfies \(\alpha\ge S\).

Conversely, set \(\alpha=S\) and \(x_i=\Phi_i/(v_iS)\). These rates are positive, and

\[ \sum_{i=1}^{k}\mu_i x_i =\frac{1}{S}\sum_{i=1}^{k}\frac{\mu_i\Phi_i}{v_i} =1, \qquad v_i x_i=\frac{\Phi_i}{S}. \]

Hence the allocation is feasible and attains the lower bound.

For uniqueness, any optimal allocation satisfies \(x_i\ge x_i^\star\). Both allocations use exactly one unit, so

\[ \sum_{i=1}^{k}\mu_i(x_i-x_i^\star)=0. \]

Every summand is nonnegative and every \(\mu_i\) is positive; therefore \(x_i=x_i^\star\) for every type.

Exact algorithm and bit complexity

Use exact rational arithmetic:

  • Compute the prefix masses \(M_1,\ldots,M_k\).
  • Compute the entitlements backwards, using \(\Phi_k=v_k\) and, for \(i=k-1,\ldots,1\),

\[ \Phi_i=\Phi_{i+1}+\frac{v_i-v_{i+1}}{M_i}. \]

  • Compute \(S=\sum_i\mu_i\Phi_i/v_i\).
  • Return \(S\) and the rates \(\Phi_i/(v_iS)\), or compare \(S\) with the decision threshold \(A\).

This requires \(O(k)\) rational arithmetic operations. To establish polynomial running time, we must also bound the sizes of their operands.

Write each input mass as \(\mu_i=a_i/b_i\), with positive integers \(a_i,b_i\), and let \(D=\prod_i b_i\). Its bit length is \(O(L)\). Each prefix mass can be written as \(M_s=N_s/D\), where \(N_s\) is an integer satisfying \(1\le N_s\le D\), because \(0<M_s\le1\). Thus every \(M_s\) has an \(O(L)\)-bit representation.

Each difference \(v_s-v_{s+1}\), and each quotient \((v_s-v_{s+1})/M_s\), also has an \(O(L)\)-bit rational representation. A sum of at most \(k\) such rationals can use the product of their denominators as a common denominator; its numerator and denominator have \(O(kL+\log k)\) bits. This bounds each \(\Phi_i\).

Applying the same argument to the \(k\) terms \(\mu_i\Phi_i/v_i\) gives an \(O(k^2L+k\log k)\)-bit representation of \(S\). The output rates have polynomial bit length as well. Reducing fractions cannot increase these bounds. Integer arithmetic and comparisons on operands of these sizes take polynomial time.

For the decision problem, comparing \(S\) and \(A\) by cross multiplication is exact and polynomial in the combined input length, including the encoding of \(A\).

Scope

This resolves the stated continuous problem, where \(m=1\). The argument uses the explicit entitlement formula and the absence of individual rate caps; it does not require expanding rational masses into a finite agent list. It makes no claim about versions with multiple goods.
