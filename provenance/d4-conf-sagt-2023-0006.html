The continuous mirror question, as graded

Given \(m\) projects with per-member costs \(c_j\), and \(\tau\) supported types with binary-rational masses \(\mu_t\), budgets \(b_t\), and additive values \(v_{tj}\), find a set \(W\subseteq M\) maximizing \(\sum_{t}\mu_t\sum_{j\in W}v_{tj}-\sum_{j\in W}c_j\), subject to \(\sum_{j\in W}c_j\leq\sum_t\mu_t\min\!\left(b_t,\sum_{j\in W}v_{tj}\right)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) indivisible projects \(M=\{1,\ldots,m\}\). Per-member project costs \(c_j\), individual budgets \(b_t\), and additive values \(v_{tj}\) are nonnegative binary rationals; zero budgets are allowed. Assume \(\sum_t\mu_t v_{tj}\ge c_j\) for every project.
Write \(V_t(W)=\sum_{j\in W}v_{tj}\) and \(C(W)=\sum_{j\in W}c_j\). A bundle \(W\subseteq M\) is feasible exactly when \(C(W)\le\sum_t\mu_t\min\{b_t,V_t(W)\}\); the empty bundle is allowed.
This constraint expresses funding through nonnegative contributions bounded by each member's budget and value, so every member has nonnegative quasi-linear utility. Welfare is \(\mathrm{SW}(W)=\sum_t\mu_t V_t(W)-C(W)\); let \(\mathrm{OPT}\) be its maximum over feasible bundles.
An \(f(m,\tau)\)-approximation returns a feasible bundle with \(f(m,\tau)\mathrm{SW}(W)\ge\mathrm{OPT}\), where \(f\ge1\) is finite and polynomial-time computable. State running times in \(m,\tau,L\), where \(L\) is the total binary input length.

Does this problem admit a polynomial-time \(f(m,\tau)\)-approximation for some such \(f\), or is every such guarantee impossible assuming \(\mathrm{P}\ne\mathrm{NP}\), even when \(\tau=2\)?

For discrete agents with additive values, no polynomial-time \(f(m)\)-approximation exists for any polynomial-time computable finite factor, even with two agents, assuming \(\mathrm{P}\ne\mathrm{NP}\). [Source](https://link.springer.com/article/10.1007/s10458-025-09715-7)
No result specifically treating this normalized mass formulation was located in the literature search.

  • Specified nonnegative binary-rational costs, budgets, and values, allowing zero budgets as required by the discrete hardness setting.
  • Carried over the aggregate-value condition as sum_t mu_t v_tj >= c_j for each project.

  • Replaced the undefined population-size argument of an approximation factor by support size tau, retaining the two-type restriction corresponding to the anchor's two-agent restriction.

Result

Assuming \(\mathrm{P}\ne\mathrm{NP}\), no polynomial-time approximation with any finite, polynomial-time computable factor \(f(m,\tau)\) exists, even when \(\tau=2\) and both masses equal \(1/2\).

We prove this directly, including all normalization and encoding checks.

Construction

Suppose an algorithm \(\mathcal A\) returns a feasible bundle satisfying \(f(m,\tau)\mathrm{SW}(\mathcal A(I))\ge\mathrm{OPT}(I)\), in time polynomial in \(m,\tau,L\).

Reduce from the standard NP-complete positive-integer SUBSET SUM problem: given \(a_1,\ldots,a_n\) and a positive target \(T\), decide whether some \(S\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{j\in S}a_j=T\). Write \(A=\sum_{j=1}^n a_j\). Inputs with \(T>A\) can be rejected immediately, so assume \(1\le T\le A\).

Compute an integer \(K\ge f(n+1,2)\), and set \(H=KA+T+1\). Polynomial-time computability of \(f\) permits such an upper bound with polynomial binary length: round an exact numerical output upward, or round an additive-error-\(1\) approximation upward and add \(1\).

Construct \(m=n+1\) projects and exactly two types, with \(\mu_1=\mu_2=1/2\). Set their budgets to \(b_1=4T\) and \(b_2=0\).

The first \(n\) projects are ordinary projects. For each \(j\le n\), set \(c_j=a_j\), \(v_{1j}=4a_j\), and \(v_{2j}=0\).

Let \(p=n+1\) be the special project, with \(c_p=T\), \(v_{1p}=0\), and \(v_{2p}=2H\).

All costs, budgets, and values are nonnegative integers; the masses are positive binary rationals summing to \(1\). The two types are distinct. The required projectwise inequality holds:

  • For an ordinary project, \(\sum_t\mu_t v_{tj}=2a_j\ge a_j=c_j\).
  • For the special project, \(\sum_t\mu_t v_{tp}=H>T=c_p\).

Thus the constructed instance satisfies every stated hypothesis.

Exact feasibility of the special project

Fix an ordinary-project subset \(S\), and write \(x=\sum_{j\in S}a_j\). Consider \(W=S\cup\{p\}\).

Its cost is \(C(W)=x+T\). Its maximum funding is
\(\sum_t\mu_t\min\{b_t,V_t(W)\}=\frac12\min\{4T,4x\}+\frac12\min\{0,2H\}=\min\{2T,2x\}\).

Consequently, \(W\) is feasible exactly when \(x+T\le\min\{2T,2x\}\). This is equivalent to the conjunction \(x+T\le2T\) and \(x+T\le2x\), which respectively give \(x\le T\) and \(x\ge T\).

Therefore,
\(S\cup\{p\}\text{ is feasible}\Longleftrightarrow\sum_{j\in S}a_j=T\).

In particular, a feasible bundle containing \(p\) exists exactly when the SUBSET SUM instance is a yes-instance.

Welfare gap and contradiction

For any bundle \(S\) containing only ordinary projects, its welfare is
\(\mathrm{SW}(S)=2x-x=x\le A\).

If \(S\cup\{p\}\) is feasible, the previous section gives \(x=T\). Its welfare is then
\(\mathrm{SW}(S\cup\{p\})=2x+H-(x+T)=H\).

These calculations imply:

  • On a yes-instance, \(\mathrm{OPT}=H\): a feasible bundle containing \(p\) exists, every such bundle has welfare \(H\), and every other bundle has welfare at most \(A<H\).
  • On a no-instance, no feasible bundle contains \(p\).

On a yes-instance, the approximation guarantee forces
\(\mathrm{SW}(\mathcal A(I))\ge H/f(n+1,2)\ge H/K>A\),
where the strict inequality follows from \(H=KA+T+1>KA\). Since every bundle omitting \(p\) has welfare at most \(A\), the algorithm must return a bundle containing \(p\).

On a no-instance, feasibility forces its output to omit \(p\).

Thus running \(\mathcal A\) and accepting exactly when its output contains \(p\) decides SUBSET SUM.

Encoding and running time

Let \(\ell\) be the total binary length of the SUBSET SUM input. Let \(q(n+1)\) be a polynomial bound on the computation time and output length needed for the integer upper bound \(K\).

Binary summation and multiplication show that \(H\) has \(O(\ell+q(n+1))\) bits. The constructed instance has \(m=n+1\), \(\tau=2\), and total input length \(L=O(\ell+q(n+1))\). Its construction takes polynomial time in \(n,\ell\).

If the approximation algorithm runs in time \(R(m,\tau,L)=\operatorname{poly}(m,\tau,L)\), the resulting SUBSET SUM decision algorithm runs in
\(\operatorname{poly}(n,\ell)+R(n+1,2,O(\ell+q(n+1)))\),
which is polynomial in the source input length. This contradicts \(\mathrm{P}\ne\mathrm{NP}\).

Relation to the discrete formulation

Normalization also gives an exact transfer from the cited discrete model. For two discrete agents with budgets \(B_i\), values \(u_{ij}\), and costs \(C_j\), take masses \(\mu_i=1/2\), budgets \(b_i=2B_i\), values \(v_{ij}=2u_{ij}\), and costs \(c_j=C_j\). Then, for every bundle \(W\),
\(\sum_i\mu_i\min\{b_i,V_i(W)\}=\sum_i\min\{B_i,U_i(W)\}\)
and
\(\sum_i\mu_iV_i(W)-C(W)=\sum_iU_i(W)-C(W)\).

Hence feasibility and welfare are preserved exactly, with only a constant increase in each numerical encoding length. This explains why the normalized support formulation inherits the discrete inapproximability result; the direct proof above establishes it independently.
