The continuous mirror question, as graded

Given finitely many consumer classes \(r\) with rational masses \(\mu_r\), finite private-type spaces and priors, type-injective endowments, and encoded concave piecewise-linear quasilinear utilities, does there exist a feasible ex ante direct mechanism assigning bundles and transfers based on each agent's own reported type and the aggregate report distribution, which is incentive-compatible and is not blocked by any measurable coalition with class masses \(\alpha_r \leq \mu_r\)?

Packaged proof task (what the prover saw — nothing else)

A society is an atomless population given by its support: \(\tau\) ex ante consumer types (classes), with positive binary-rational masses \(\mu_r\) summing to \(1\). Thus \(\tau\) counts listed classes, not possible private-type profiles.
Class \(r\) has a finite private-type set \(T_r\). An explicitly listed rational common prior \(q\) on \(T=\prod_r T_r\) selects a profile \(t\); all members of class \(r\) receive private type \(t_r\). Every private type has positive marginal probability.
There are \(m\geq1\) divisible goods. Endowments \(e_r:T_r\to\mathbb Q_+^m\) are injective. Utilities are \(u_r(t,x,b)=w_r(t,x)+b\), where \(x\in\mathbb R_+^m\), \(b\in\mathbb R\), and each \(w_r(t,\cdot)\) is a continuous, coordinatewise nondecreasing concave function encoded as the minimum of finitely many rational affine functions. Values may depend on the entire true profile.
For coalition masses \(0\leq\alpha_r\leq\mu_r\), a direct mechanism specifies measurable bundles \(x_r(a,d,z)\in\mathbb R_+^m\) and deterministic transfers \(b_r(a,d)\in\mathbb R\), using only the member's class, own report \(a\in T_r\), the coalition's report masses \(d=(d_{ra})\), and a public random seed \(z\). Require finite expected utilities.
For every report distribution with \(\sum_a d_{ra}=\alpha_r\), feasibility requires \(\sum_{r,a}d_{ra}x_r(a,d,z)\leq\sum_{r,a}d_{ra}e_r(a)\) almost surely and \(\sum_{r,a}d_{ra}b_r(a,d)\leq0\); inequalities for goods are coordinatewise. Goods and money may be discarded, and individual transfers are unbounded.
A true type \(s\) can report \(a\) only if \(e_r(a)\leq e_r(s)\), depositing \(e_r(a)\) as collateral and consuming \(e_r(s)-e_r(a)+x_r(a,d,z)\). Bayesian incentive compatibility requires truthful reporting to weakly maximize conditional expected utility against every such deviation; a single atomless member's deviation leaves \(d\) unchanged.
Coalitions form measurably before types are realized. A positive-mass coalition blocks if its own feasible incentive-compatible mechanism, using only its members' reports and endowments, strictly raises ex ante expected utility for almost every member. The ex ante incentive-compatible core consists of feasible incentive-compatible grand-population mechanisms with no such block.

Is deciding whether this core is nonempty solvable in polynomial time, or is it NP-hard? State running times in \(m\), \(\tau\), \(k=\max_r|T_r|\), the prior support size \(h\), the total number \(p\) of encoded affine pieces, and the total input bit length \(L\).

For finite populations, injective type-dependent endowments and unrestricted transfers guarantee a nonempty ex ante incentive-compatible core, with deterministic incentive-compatible coalition worth equal to unconstrained worth ([Forges–Mertens–Vohra](https://webdoc.sub.gwdg.de/ebook/serien/e/CORE/dp2001-1.pdf)).
For a different continuum model with negligible private information and state-independent endowments, incentive-compatible ex ante core allocations exist ([Sun–Yannelis](https://www.biz.uiowa.edu/faculty/nyannelis/publications/Core_Equilibria_and_Incentives_in_Large_Asymmetric_Information_Economies.pdf)); this does not establish the computational status of the problem defined here.

Modeling choices made when packaging the task

  • Interpreted support types as ex ante consumer classes, distinguished from subsequently realized private types, and normalized their masses to sum to one.
  • The joint information structure was unspecified: chose an explicitly encoded finite common prior over class-type profiles, with all members of a class sharing its realized private type and every private type having positive marginal probability.
  • Specified rational nonnegative injective endowments, nonnegative consumption bundles, coordinatewise nondecreasing utilities, unrestricted signed monetary transfers, and rational minimum-of-affine utility encodings.
  • Allowed common-value utilities depending on the full true class-type profile rather than imposing private values.
  • Interpreted the aggregate report distribution as class-indexed report masses within the operating coalition, including report distributions outside the truthful prior support.
  • Retained randomized goods allocations, deterministic money transfers, exact feasibility at every report distribution, and free disposal of both goods and money.
  • Restored collateral-restricted reports and consumption of the undeclared residual endowment when a member underreports.
  • Specified individual Bayesian incentive compatibility with aggregates unchanged by an atomless member's unilateral deviation.
  • Specified ex ante measurable coalition formation, positive coalition mass, coalition-local information and resources, and strict ex ante improvement for almost every member.
  • Required measurable mechanisms and finite expected utilities, and made the prior support size and utility encoding size explicit complexity parameters.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is polynomial-time solvable: every valid instance has a nonempty ex ante incentive-compatible core. A deterministic core mechanism can be constructed in time polynomial in \(m,\tau,k,h,p,L\).

The crucial model feature is that an individual deviation leaves the report masses unchanged. Consequently, the mechanism can penalize a report contradicted by those masses without affecting its aggregate transfer budget.

1. Statewise supporting prices

Let \(S=\{t:q(t)>0\}\), so \(|S|=h\). Fix \(t\in S\), and write

\(\displaystyle E^t=\sum_{r=1}^{\tau}\mu_r e_r(t_r).\)

Write the encoded utility functions as

\(\displaystyle w_r(t,x)=\min_{\ell\in I_r(t)}\bigl(c_{r\ell}^t+A_{r\ell}^t\cdot x\bigr).\)

Consider the rational linear program with variables \(x_r\in\mathbb R_+^m\) and \(y_r\in\mathbb R\), objective

\(\displaystyle \max\sum_r\mu_r y_r,\)

and constraints

\(\displaystyle \sum_r\mu_r x_r\le E^t,\qquad y_r\le c_{r\ell}^t+A_{r\ell}^t\cdot x_r\quad(r,\ell).\)

This is exactly statewise welfare maximization. Its feasible bundle set is nonempty and compact: each coordinate satisfies \(0\le x_{rj}\le E_j^t/\mu_r\). Continuity of the utilities therefore implies a finite attained optimum.

Its dual has variables \(\pi^t\in\mathbb R_+^m\) and \(\lambda_{r\ell}^t\ge0\), objective

\(\displaystyle \min\left(\pi^t\cdot E^t+\sum_{r,\ell}\lambda_{r\ell}^t c_{r\ell}^t\right),\)

and constraints

\(\displaystyle \sum_\ell\lambda_{r\ell}^t=\mu_r,\qquad \sum_\ell\lambda_{r\ell}^t A_{r\ell}^t\le\mu_r\pi^t.\)

Finite-dimensional linear programming duality supplies optimal primal and dual solutions. They can be chosen rational.

Define

\(\displaystyle C_r^t=\frac{1}{\mu_r}\sum_\ell\lambda_{r\ell}^t c_{r\ell}^t.\)

For every \(x\in\mathbb R_+^m\), the minimum defining utility is at most the indicated convex combination of its affine pieces. Hence

\[\displaystyle w_r(t,x)\le \frac{1}{\mu_r}\sum_\ell\lambda_{r\ell}^t\bigl(c_{r\ell}^t+A_{r\ell}^t\cdot x\bigr)\le C_r^t+\pi^t\cdot x. \tag{1}\]

Let \(x_r^t\) denote the optimal bundles. At an optimum, \(y_r=w_r(t,x_r^t)\), because \(\mu_r>0\). The difference between the dual and primal objective values equals

\(\displaystyle \sum_r\mu_r\bigl(C_r^t+\pi^t\cdot x_r^t-w_r(t,x_r^t)\bigr)+\pi^t\cdot\left(E^t-\sum_r\mu_r x_r^t\right).\)

Every summand is nonnegative, by (1), primal feasibility, and \(\pi^t\ge0\). Strong duality makes their sum zero. Therefore

\(\displaystyle w_r(t,x_r^t)=C_r^t+\pi^t\cdot x_r^t\quad\text{for every }r,\)

and

\(\displaystyle \pi^t\cdot\left(E^t-\sum_r\mu_r x_r^t\right)=0.\)

Set

\(\displaystyle b_r^t=\pi^t\cdot\bigl(e_r(t_r)-x_r^t\bigr),\qquad V_r^t=w_r(t,x_r^t)+b_r^t.\)

It follows that

\[\displaystyle \sum_r\mu_r b_r^t=0,\qquad V_r^t=C_r^t+\pi^t\cdot e_r(t_r). \tag{2}\]

Combining (1) and (2) gives the supporting inequality

\[\displaystyle w_r(t,x)\le V_r^t+\pi^t\cdot\bigl(x-e_r(t_r)\bigr)\quad(x\ge0). \tag{3}\]

This inequality will bound every coalition’s welfare.

2. Implementing the allocation with truthful reporting

For each supported profile \(t\), define the grand population’s truthful report distribution by

\(\displaystyle D(t)_{ra}=\begin{cases}\mu_r,&a=t_r,\\0,&a\ne t_r.\end{cases}\)

Because every \(\mu_r\) is positive, \(D(t)\) uniquely determines \(t\).

Choose a finite rational \(H\ge0\) such that, for every \(t\in S\), class \(r\), and admissible false report \(a\ne t_r\),

\[\displaystyle w_r\bigl(t,e_r(t_r)-e_r(a)\bigr)-H\le V_r^t-1. \tag{4}\]

Such an \(H\) exists because there are finitely many relevant triples. For example, take the maximum of zero and all quantities

\(\displaystyle 1+w_r\bigl(t,e_r(t_r)-e_r(a)\bigr)-V_r^t.\)

If there are no admissible false reports, take \(H=0\).

Define the following deterministic grand-population mechanism:

  • At \(d=D(t)\) for \(t\in S\), report \(a=t_r\) receives bundle \(x_r^t\) and transfer \(b_r^t\). Every report \(a\ne t_r\) receives bundle zero and transfer \(-H\).
  • At every other report distribution, report \(a\) receives bundle \(e_r(a)\) and transfer zero.

The mechanism uses only the member’s class, own report, and report masses. It ignores the public random seed.

Feasibility at every report distribution

At \(d=D(t)\), all reports receiving punishment have zero mass. Consequently, aggregate goods consumption is \(\sum_r\mu_r x_r^t\le E^t\), and aggregate transfers equal zero by (2).

At every other distribution, aggregate consumption is exactly

\(\displaystyle \sum_{r,a}d_{ra}e_r(a),\)

and aggregate transfers are zero. Thus the mechanism satisfies both feasibility requirements everywhere.

It is measurable because it has finitely many exceptional report distributions. Its bundles and transfers range over finite sets, so all relevant expected utilities are finite.

Bayesian incentive compatibility

Fix a true profile \(t\in S\). Truthful reports generate \(d=D(t)\). A class-\(r\) member reporting truthfully receives utility \(V_r^t\).

An individual deviation to \(a\ne t_r\) leaves \(d\) unchanged, by the stipulated atomlessness rule. If admissible, it therefore yields consumption \(e_r(t_r)-e_r(a)\), transfer \(-H\), and utility at most \(V_r^t-1\), by (4).

Thus every admissible false report is worse in every supported true profile where it is available. Taking conditional expectations proves Bayesian incentive compatibility. The positive marginal probabilities ensure these conditional expectations are defined for every private type.

3. No positive-mass coalition can block

The grand mechanism gives each class-\(r\) member ex ante utility

\(\displaystyle U_r=\sum_{t\in S}q(t)V_r^t.\)

Consider any coalition with masses \(0\le\alpha_r\le\mu_r\), not all zero, and any feasible coalition mechanism. We will bound its truthful welfare without using its incentive compatibility.

For a supported true profile \(t\) and public seed \(z\), let \(X_r(t,z)\) and \(B_r(t)\) be its truthful bundle and transfer for an active class \(r\), meaning \(\alpha_r>0\). Feasibility implies, almost surely,

\(\displaystyle \sum_r\alpha_r X_r(t,z)\le\sum_r\alpha_r e_r(t_r),\qquad \sum_r\alpha_r B_r(t)\le0.\)

Apply (3) to every active class and sum with weights \(\alpha_r\):

\(\displaystyle \sum_r\alpha_r\bigl(w_r(t,X_r(t,z))+B_r(t)\bigr)\le\sum_r\alpha_r V_r^t+\pi^t\cdot\sum_r\alpha_r\bigl(X_r(t,z)-e_r(t_r)\bigr)+\sum_r\alpha_r B_r(t).\)

The last two terms are nonpositive because \(\pi^t\ge0\). Therefore

\(\displaystyle \sum_r\alpha_r\bigl(w_r(t,X_r(t,z))+B_r(t)\bigr)\le\sum_r\alpha_r V_r^t.\)

Taking expectations over \(z\) and \(t\), and denoting coalition ex ante utilities by \(\widetilde U_r\), gives

\[\displaystyle \sum_r\alpha_r\widetilde U_r\le\sum_r\alpha_r U_r. \tag{5}\]

Under the permitted mechanism format, all coalition members of a given class have the same ex ante utility. A block strictly improving almost every coalition member would therefore require \(\widetilde U_r>U_r\) for every active class. Since the coalition has positive mass, this contradicts (5).

The constructed grand mechanism is consequently in the ex ante incentive-compatible core.

4. Running times

For each \(t\in S\), let \(p_t=\sum_r|I_r(t)|\). The construction solves one rational primal–dual linear programming pair per supported profile:

  • The primal has \(\tau(m+1)\) variables and \(p_t+m\) main inequalities, together with bundle nonnegativity.
  • The dual has \(p_t+m\) variables, \(\tau\) equalities, and \(\tau m\) main inequalities, together with nonnegativity.

Thus each pair has size \(O(m\tau+p_t)\). Its coefficient bit length is polynomial in \(L\), including the computed aggregate endowments. Exact rational linear programming returns optimal solutions of polynomial bit length in polynomial time.

After these solves, admissibility checks and the evaluations used to choose \(H\) require

\(\displaystyle O\left(h\tau km+mk\sum_{t\in S}p_t\right)\)

rational arithmetic operations. Conservatively, \(p_t\le p\), giving \(O(hmk(\tau+p))\) operations. All operands have polynomial bit length. The finite table and fallback rule describing the mechanism also have polynomial encoding length.

Accordingly:

  • Decision: always return YES on the promised valid instances; \(O(1)\) time beyond reading the input, or \(O(L)\) including a complete read.
  • Construction: polynomial time in \(m,\tau,k,h,p,L\), using \(h\) linear programming pairs of size \(O(m\tau+p)\).

No enumeration of all \(k^\tau\) possible profiles or of coalition mass vectors is required.

5. Scope of the argument

This is a direct proof for the specified continuum mechanism model, rather than an application of the finite-player result in [Forges–Mertens–Vohra, Theorem 1](https://webdoc.sub.gwdg.de/ebook/serien/e/CORE/dp2001-1.pdf).

The implementation uses exactly the stated permission to assign transfers at zero-mass reports and the stated rule that an individual deviation leaves report masses unchanged. No continuity in report masses is required. In fact, injectivity of endowments is unnecessary for this construction.
