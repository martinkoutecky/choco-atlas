The anchor (named result in the paper)

Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given item categories \(\mathcal J\), a public function \(f:2^{\mathcal J}\to\mathbb R\), a finite set \(V\) of private values, a rational mass distribution \(\mu\) on \(V\) with support size \(\tau\), and rational per-capita supplies \(q_j\), can a direct truthful mechanism be constructed from an \(\alpha\)-approximation to the aggregate welfare problem? Aggregate assignments \(x_{v,S}\) must satisfy \(\sum_S x_{v,S}=\mu_v\) and \(\sum_{v,S:j\in S}x_{v,S}=q_j\); the benchmark is \(\operatorname{OPT}(\mu)=\max_x\sum_{v,S}v f(S)x_{v,S}\). The mechanism must specify expected bundle values and payments for a tagged agent's reports, satisfy \(v z_v-p_v\ge v z_w-p_w\) for all \(v,w\in V\), achieve welfare at least \(\frac{3\alpha}{4ab}\operatorname{OPT}(\mu)\), and run in \(\operatorname{poly}(m,\tau,L)\) time for fixed \(a,b>1\).

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal J\) contain \(m\geq1\) item categories, let \(f:2^{\mathcal J}\to\mathbb Q_{\geq0}\) be public and accessible through a value oracle, and let \(V\subseteq\mathbb Q_{\geq0}\) be a nonempty finite report domain. No monotonicity or empty-bundle normalization is imposed on \(f\).
A society is given by its support: the list of its \(\tau\) types \(v\in V\) with positive binary-rational masses \(\mu_v\), summing to \(1\); here \(V\) is precisely this support. Thus \(\tau\) is the support size, not the number of possible bundles or types. Supplies satisfy \(q_j\in\mathbb Q\cap[0,1]\).
An aggregate assignment consists of nonnegative masses \(x_{v,S}\), for \(v\in V\) and \(S\subseteq\mathcal J\), satisfying \(\sum_Sx_{v,S}=\mu_v\) and \(\sum_{v,S:j\in S}x_{v,S}=q_j\). Define \(W(x)=\sum_{v,S}v f(S)x_{v,S}\) and \(\operatorname{OPT}(\mu)=\max_x W(x)\).
Given \(\alpha\in\mathbb Q\cap(0,1]\), assume black-box access to a deterministic polynomial-time algorithm that returns a feasible \(\alpha\)-approximate aggregate assignment as a list of its nonzero entries for every rational society on \(V\), with the same public function and supplies.
A direct mechanism returns such a feasible assignment and rational expected payments \(p_v\). A tagged agent reporting \(v\) receives bundle \(S\) with probability \(x_{v,S}/\mu_v\), giving expected bundle value \(z_v=\mu_v^{-1}\sum_S f(S)x_{v,S}\). The tagged agent is infinitesimal, so changing its report leaves the society unchanged.
Truthfulness means \(v z_v-p_v\geq v z_w-p_w\) for all \(v,w\in V\), at every input society. Payments may have either sign. Let \(L\) include the binary input length and a bound on the bit length of oracle answers; count oracle queries and black-box calls as well as bit operations.

For every fixed rational \(a,b>1\), can an arbitrary such \(\alpha\)-approximation algorithm be converted into a direct truthful mechanism with \(W(x)\geq\frac{3\alpha}{4ab}\operatorname{OPT}(\mu)\) in \(\operatorname{poly}(m,\tau,L)\) time?

For finite societies of \(n\) agents, a [known conversion](https://arxiv.org/pdf/1007.3539) achieves factor \(\frac{3\alpha}{4ab}\) in time \(O((\log_a n)^{\log_b n}\operatorname{poly}(m,n))\); fixed \(a,b\) give quasi-polynomial time, while suitable varying parameters give factor \(\Omega(\alpha/\log n)\) in polynomial time.
No result settling this precise mass-based conversion problem was located.

Modeling choices made when packaging the task

  • Restricted public bundle values to nonnegative rationals: signed values can give negative optimal welfare, making the stated multiplicative guarantee impossible even for an optimal allocation. Retained the absence of free disposal and empty-bundle normalization.
  • Used nonnegative rational private multipliers, consistent with the discrete normalized multiplier vectors; did not normalize their mass-weighted mean because their scale is unrestricted.
  • Normalized total society mass to one and restricted each per-capita supply to [0,1]; retained exact supply equalities.
  • Identified the report domain V with the positive-mass support, making every report's conditional bundle distribution defined.
  • Specified infinitesimal tagged-agent deviations and identified report lotteries with conditional aggregate assignments; interpreted the stated incentive inequalities as truthfulness in expectation.
  • Specified a deterministic black box applicable to all rational societies on the fixed report domain, with sparse rational outputs, and a rational value-oracle model with bounded answer lengths.
  • Allowed signed rational payments without adding individual-rationality or budget constraints; took a and b to be fixed rational constants and α to lie in (0,1].

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Proven result

Yes. In the stated infinitesimal-agent model, the full factor \(\alpha\) can be retained in polynomial time. One black-box call and one polynomial-size rational linear program suffice.

The key is that truthfulness is checked within a fixed society. We can rearrange bundle masses among types to make expected bundle values nondecreasing, preserving every supply and weakly increasing welfare.

Write the types as \(v_1<\cdots<v_\tau\), with masses \(\mu_1,\ldots,\mu_\tau>0\).

1. A welfare-improving rearrangement

Let \(x^A\) be the black-box assignment. List its distinct supported bundles as \(S_1,\ldots,S_K\), ordered so that their oracle values satisfy \(f_1\leq\cdots\leq f_K\), where \(f_k=f(S_k)\). Define their aggregate masses by

\(y_k=\sum_{i=1}^{\tau}x^A_{i,S_k}\).

Thus \(y_k>0\) and \(\sum_k y_k=1\). Set

\(M_0=Y_0=0,\qquad M_i=\sum_{r=1}^{i}\mu_r,\qquad Y_k=\sum_{\ell=1}^{k}y_\ell.\)

Define the rearranged assignment by interval intersection:

\(\widehat x_{i,S_k}=\max\{0,\min(M_i,Y_k)-\max(M_{i-1},Y_{k-1})\}.\)

This assigns the lowest bundle values to the lowest types, allowing bundles to split across type boundaries.

Feasibility and monotonicity

The intervals \((M_{i-1},M_i]\) partition \((0,1]\), as do \((Y_{k-1},Y_k]\). Consequently,

\(\sum_k\widehat x_{i,S_k}=\mu_i,\qquad \sum_i\widehat x_{i,S_k}=y_k.\)

In particular, each item’s aggregate allocation remains unchanged:

\(\sum_{i,k:j\in S_k}\widehat x_{i,S_k}=\sum_{k:j\in S_k}y_k=q_j.\)

Moreover, if \(i<j\), \(\widehat x_{i,S_k}>0\), and \(\widehat x_{j,S_\ell}>0\), then \(k\leq\ell\): the type intervals and bundle intervals have the same left-to-right order. Hence \(f_k\leq f_\ell\).

Define \(\widehat z_i=\mu_i^{-1}\sum_k f_k\widehat x_{i,S_k}\). For \(i<j\),

\(\widehat z_j-\widehat z_i=\sum_{k,\ell}\frac{\widehat x_{i,S_k}\widehat x_{j,S_\ell}}{\mu_i\mu_j}(f_\ell-f_k)\geq0.\)

Thus the expected bundle values are nondecreasing across types.

Welfare does not decrease

We prove this explicitly for unequal type masses.

For each \(h\in\{2,\ldots,\tau\}\), let

\(a_{h,k}=\sum_{i=h}^{\tau}x^A_{i,S_k},\qquad b_{h,k}=\sum_{i=h}^{\tau}\widehat x_{i,S_k}.\)

Both vectors allocate bundle masses to the upper-type tail, so

\(0\leq a_{h,k},b_{h,k}\leq y_k,\qquad \sum_k a_{h,k}=\sum_k b_{h,k}=1-M_{h-1}.\)

Choose \(k_h\) with \(Y_{k_h-1}\leq M_{h-1}\leq Y_{k_h}\). By construction, \(b_{h,k}=0\) for \(k<k_h\), and \(b_{h,k}=y_k\) for \(k>k_h\). Therefore:

  • For \(k<k_h\), both \(f_k-f_{k_h}\) and \(b_{h,k}-a_{h,k}\) are nonpositive.
  • For \(k>k_h\), both are nonnegative.
  • For \(k=k_h\), their product is zero.

Since \(\sum_k(b_{h,k}-a_{h,k})=0\), it follows that

\(\sum_k f_k(b_{h,k}-a_{h,k})=\sum_k(f_k-f_{k_h})(b_{h,k}-a_{h,k})\geq0.\)

Finally, use the identity

\(v_i=v_1+\sum_{h=2}^{\tau}(v_h-v_{h-1})\mathbf 1_{\{i\geq h\}}.\)

The aggregate bundle masses agree between the two assignments, so the contribution involving \(v_1\) cancels. Consequently,

\(W(\widehat x)-W(x^A)=\sum_{h=2}^{\tau}(v_h-v_{h-1})\sum_k f_k(b_{h,k}-a_{h,k})\geq0.\)

When \(\tau=1\), the assignments coincide and the same conclusion holds.

This proves that the black-box support admits a feasible, monotone assignment with welfare at least \(W(x^A)\). No monotonicity or normalization of \(f\) was used.

2. Polynomial-time construction with rational output

If the black box returns rational masses, the rearrangement above is directly computable by rational arithmetic. Alternatively, the following construction uses only its bundle support and guarantees rational output.

Call the black box on the input society, collect its \(K\) distinct supported bundles, and query their values. Solve the linear program with variables \(X_{i,k}\), maximizing

\(\sum_{i=1}^{\tau}\sum_{k=1}^{K}v_i f_kX_{i,k},\)

subject to:

  • \(X_{i,k}\geq0\).
  • \(\sum_kX_{i,k}=\mu_i\) for every type \(i\).
  • \(\sum_{i,k:j\in S_k}X_{i,k}=q_j\) for every item \(j\).
  • \(\mu_{i+1}\sum_k f_kX_{i,k}\leq\mu_i\sum_k f_kX_{i+1,k}\) for \(1\leq i<\tau\).

The last constraints are exactly the inequalities \(z_i\leq z_{i+1}\), because all type masses are positive.

The rearrangement proved above witnesses feasibility and has welfare at least \(W(x^A)\). Therefore an optimal solution \(X^*\) satisfies

\(W(X^*)\geq W(x^A)\geq\alpha\operatorname{OPT}(\mu).\)

Here are the hypotheses needed for polynomial-time rational linear programming:

  • The black box has polynomial running time and explicitly lists its support, so \(K\) is polynomial in \(m,\tau,L\).
  • The program has \(\tau K\) variables and polynomially many constraints.
  • All coefficients are rational with polynomial bit length, including the products \(\mu_i f_k\).
  • The feasible region is nonempty and bounded, since \(0\leq X_{i,k}\leq\mu_i\).

The standard polynomial-time theorem for rational linear programming therefore returns an exact rational optimum with polynomial encoding length. Output its positive entries as the assignment.

This construction makes one black-box call and at most \(K\) additional value-oracle queries.

3. Rational payments and truthfulness

For the resulting assignment, calculate

\(z_i=\mu_i^{-1}\sum_k f_kX^*_{i,k}.\)

These are rational and satisfy \(z_1\leq\cdots\leq z_\tau\). Set

\(p_1=0,\qquad p_i=\sum_{h=1}^{i-1}v_h(z_{h+1}-z_h)\quad\text{for }i\geq2.\)

We verify every reporting inequality.

If \(i>j\), then \(v_h\leq v_i\) for \(j\leq h<i\), and each allocation difference is nonnegative. Hence

\(p_i-p_j=\sum_{h=j}^{i-1}v_h(z_{h+1}-z_h)\leq v_i(z_i-z_j).\)

Rearranging gives \(v_i z_i-p_i\geq v_i z_j-p_j\).

If \(i<j\), then \(v_h\geq v_i\) for \(i\leq h<j\). Thus

\(p_j-p_i=\sum_{h=i}^{j-1}v_h(z_{h+1}-z_h)\geq v_i(z_j-z_i),\)

which gives the same truthfulness inequality. The case \(i=j\) is equality.

The payments have polynomial bit length and are computable in polynomial time. Applying this construction independently at every input society establishes exactly the truthfulness condition in the question.

4. Requested guarantee

Since \(a,b>1\) and \(\operatorname{OPT}(\mu)\geq0\),

\(W(X^*)\geq\alpha\operatorname{OPT}(\mu)\geq\frac{3\alpha}{4ab}\operatorname{OPT}(\mu).\)

The decisive difference from the [referenced finite-agent model](https://arxiv.org/pdf/1007.3539) is the fixed-society incentive condition: here a tagged deviation compares entries of one monotone allocation menu, whereas a finite agent’s deviation changes the input profile.
