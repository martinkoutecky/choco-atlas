The continuous mirror question, as graded

Given an atomless population of mass \(1\), divided into \(\tau\) types with rational masses \(\mu_t>0\), and a finite list of interaction schemas \(h=(t_1,\ldots,t_{r(h)})\) with nonnegative rational weights \(w_h\), let a coalition be represented by type masses \(z_t\in[0,\mu_t]\) and have value \(\nu(z)=\sum_h w_h\prod_{j=1}^{r(h)}z_{t_j}\). Find the largest \(\epsilon\) and nonnegative type payment rates \(p_t\) such that \(\sum_t\mu_t p_t=\nu(\mu)\) and \(\sum_t p_tz_t\ge\nu(z)+\epsilon\sum_tz_t\) for every \(z\) with \(0<\sum_tz_t<1\); the weak least-core value is \(-\epsilon\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge 1\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). The population is atomless; \(\tau\) is the support size, not the number of possible types.
The input also lists \(m\) interaction schemas \(h=(t_1,\ldots,t_{r(h)})\), with \(r(h)\ge 1\), type indices in \(\{1,\ldots,\tau\}\), and nonnegative binary rational weights \(w_h\). Repeated type indices are allowed. Put \(R=\sum_h r(h)\), and let \(L\) be the total input bit length.
A coalition is any real vector \(z\) with \(0\le z_t\le\mu_t\); its value is \(\nu(z)=\sum_h w_h\prod_{j=1}^{r(h)}z_{t_j}\).
Find the largest real \(\epsilon\) and real payment rates \(p_t\ge 0\) satisfying \(\sum_t\mu_t p_t=\nu(\mu)\) and \(\sum_t p_tz_t\ge\nu(z)+\epsilon\sum_tz_t\) for every coalition with \(0<\sum_tz_t<1\). The weak least-core value is \(-\epsilon\).

Is exact computation of this optimum and an attaining payment vector solvable in time polynomial in \(m,\tau,R,L\), or is it NP-hard?

For finite populations with at least two players, nonnegative weighted nonempty hyperedges, and coalition value equal to the total weight of contained hyperedges, strong and weak least-core values and attaining allocations are computable in polynomial time ([Hatano–Yoshida](https://ojs.aaai.org/index.php/AAAI/article/view/10583)).
No result settling the complexity of the exact atomless schema model above was found in the literature search.

Modeling choices made when packaging the task

  • Required every schema to have positive arity, preserving the discrete convention that the empty coalition has value zero.
  • Allowed repeated type indices in a schema: distinct interacting individuals can have the same type, and the stated tuple-product model gives no restriction against repetition.
  • Defined m as the number of explicitly listed schemas, R as their total arity, and L as the total input bit length.
  • Specified real coalition masses, real payment rates, and a real optimization variable, with exact computation as the computational question.

Result

Exact computation is polynomial-time solvable. For every input in the stated model, the maximum is \(\epsilon^*=0\), and hence the weak least-core value is \(0\).

The availability of proper coalitions arbitrarily close to the whole population forces this upper bound. The proof below establishes attainability for arbitrary support size, schema arities, and repeated type indices.

1. Every feasible solution has \(\epsilon\le 0\)

Write \(V=\nu(\mu)\). Suppose \((\epsilon,p)\) satisfies all the constraints.

For each real \(\lambda\in(0,1)\), take the coalition \(z=\lambda\mu\). It is admissible because \(0\le z_t\le\mu_t\) and \(\sum_t z_t=\lambda\in(0,1)\). Efficiency and the coalition constraint give

\(\displaystyle \lambda V=\sum_t p_t\lambda\mu_t\ge \nu(\lambda\mu)+\epsilon\lambda.\)

By the definition of the schema value,

\(\displaystyle \nu(\lambda\mu)=\sum_h w_h\lambda^{r(h)}\prod_{j=1}^{r(h)}\mu_{t_j}.\)

Dividing the inequality by \(\lambda>0\), we obtain

\(\displaystyle \epsilon\le V-\sum_h w_h\lambda^{r(h)-1}\prod_{j=1}^{r(h)}\mu_{t_j}.\)

There are finitely many schemas, and every \(r(h)\ge 1\). Thus, as \(\lambda\) tends to \(1\) from below, the right-hand side tends to \(V-\nu(\mu)=0\). Since the inequality holds for every \(\lambda\in(0,1)\), it follows that \(\epsilon\le 0\).

2. An explicit payment vector attains \(\epsilon=0\)

For each schema \(h=(t_1,\ldots,t_{r(h)})\), assign its entire grand-coalition contribution to its first listed type. Define

\(\displaystyle p_t=\sum_{\substack{h\\t_1=t}}w_h\prod_{j=2}^{r(h)}\mu_{t_j},\)

where an empty product equals \(1\). All these rates are nonnegative.

They satisfy efficiency:

\(\displaystyle \sum_t\mu_t p_t=\sum_h w_h\mu_{t_1}\prod_{j=2}^{r(h)}\mu_{t_j}=\nu(\mu).\)

Now let \(z\) be any vector with \(0\le z_t\le\mu_t\). For each schema, all factors are nonnegative, and \(z_{t_j}\le\mu_{t_j}\) for every occurrence \(j\). Therefore

\(\displaystyle w_h\prod_{j=1}^{r(h)}z_{t_j}\le w_h z_{t_1}\prod_{j=2}^{r(h)}\mu_{t_j}.\)

This remains valid when type indices repeat: only the first occurrence is retained as a coalition factor; each other occurrence is bounded separately by its corresponding population mass.

Summing over schemas gives

\(\displaystyle \nu(z)\le\sum_h w_h z_{t_1}\prod_{j=2}^{r(h)}\mu_{t_j}=\sum_t p_tz_t.\)

Consequently, the constructed vector satisfies every required coalition inequality with \(\epsilon=0\). Together with the upper bound, this proves that the optimum is attained and equals \(0\).

3. Exact computational complexity

The construction requires only rational products and sums. Computing each schema’s contribution takes \(r(h)-1\) multiplications, followed by one multiplication by its weight and one addition to the designated rate. Initializing the rates takes \(\tau\) operations. Thus the number of rational arithmetic operations is \(O(R+m+\tau)\).

These operations also have polynomial bit complexity. To verify this, represent each input rational as a ratio of binary integers. Each numerator and denominator has at most \(L\) bits. A schema contribution contains \(r(h)\) input factors, including its weight, so its numerator and denominator have \(O(r(h)L)\) bits.

For any rate, use the product of its summands’ denominators as a common denominator. Since \(\sum_h r(h)=R\), that denominator has \(O(RL)\) bits. Each numerator term has \(O(RL)\) bits, and summing at most \(m\) such terms adds at most \(O(\log(m+1))\) bits. Thus every output rate has a rational representation of polynomial length. Intermediate arithmetic can use the same bounds, and standard integer arithmetic therefore yields polynomial running time.

If there are no schemas, the construction simply returns all rates equal to \(0\), with the same optimum.
