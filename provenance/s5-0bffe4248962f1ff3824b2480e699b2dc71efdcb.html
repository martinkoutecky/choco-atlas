The continuous mirror question, as graded

Given finite pair and non-directed-donor type sets \(T_P,T_N\), rational masses \(\mu_t\), cycle and chain limits \(K,L\), a feasible fixed first-stage pattern plan \(x\), a recourse policy \(\pi\), and a vertex-failure mass budget \(r_v\), compute the exact worst-case recovered first-stage pair mass and return attaining failure and recovery allocations. Write \(s_t=\sum_q a_{tq}x_q\). Nature removes masses \(\gamma_t^S\) from selected participants and \(\gamma_t^U\) from unselected participants, with \(0\leq\gamma_t^S\leq s_t\), \(0\leq\gamma_t^U\leq\mu_t-s_t\), and \(\sum_t(\gamma_t^S+\gamma_t^U)\leq r_v\). Recovery allocates mass to policy-allowed typed cycles and chains, labeling each used participant as selected or unselected; each pattern must contain a selected pair. Respect the surviving selected and unselected type capacities, and maximize the mass of selected pairs recovered. For first-stage-only recourse, require every used participant to be selected and set \(\gamma_t^U=0\).

A society is given by its support: disjoint pair and non-directed-donor type sets \(T_P,T_N\), listing the \(\tau=|T_P\cup T_N|\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types.
Compatibility is an input relation \(A\subseteq(T_P\cup T_N)\times T_P\), with \(m=|A|\); an arc permits donation between distinct participants of its endpoint types. Compatibility depends only on types, and diagonal arcs concern distinct participants of the same type.
A typed pattern is a cycle with between \(2\) and \(K\) pair positions, or a chain with one initial non-directed-donor position and between \(1\) and \(\ell\) pair positions, with all required arcs in \(A\). Positions represent distinct participants, but types may repeat; every admissible chain length, including prefixes, is allowed. The integer limits \(K\ge2,\ell\ge1\) are supplied in unary.
The fixed first-stage plan is an explicit list of patterns with nonnegative binary rational allocations \(x_q\). Let \(a_{tq}\) count positions of type \(t\) in pattern \(q\), and require \(s_t=\sum_q a_{tq}x_q\le\mu_t\). Selected and unselected masses of type \(t\) are \(s_t\) and \(\mu_t-s_t\).
The input policy \(\pi\) is either full recourse, allowing selected and unselected participants, or first-stage-only recourse, allowing only selected participants, including selected non-directed donors. Recovery may rearrange participants across first-stage patterns.
Nature chooses real failure masses satisfying \(0\le\gamma_t^S\le s_t\), \(0\le\gamma_t^U\le\mu_t-s_t\), and \(\sum_t(\gamma_t^S+\gamma_t^U)\le r_v\), where \(r_v\in[0,1]\) is a binary rational. For first-stage-only recourse require \(\gamma_t^U=0\). Only participants fail; compatibility arcs remain available.
Let \(\mathcal P_\pi\) contain all admissible typed patterns whose positions are labeled selected or unselected consistently with \(\pi\), with at least one selected pair position in each pattern. For \(p\in\mathcal P_\pi\), let \(a^S_{tp},a^U_{tp}\) count its labeled positions and \(b_p=\sum_{t\in T_P}a^S_{tp}\). Define \(F(\gamma)=\max_{y\ge0}\{\sum_p b_py_p:\sum_p a^S_{tp}y_p\le s_t-\gamma_t^S,\ \sum_p a^U_{tp}y_p\le\mu_t-s_t-\gamma_t^U\ \text{for every }t\}\).
The computational problem is to compute \(W=\min_\gamma F(\gamma)\) exactly and return attaining failure masses and an optimal recovery allocation, listing its nonzero pattern allocations; any attaining choices are acceptable. Let \(L\) denote the total input bit length.
Is this exact worst-case recovery problem solvable in polynomial time in \(m,\tau,L,K,\ell\), or is it NP-hard?
For finite participants and binary failures, an exact feasibility-seeking decomposition is established for the fixed-plan worst-case recovery problem, without a polynomial running-time guarantee ([discrete result](https://arxiv.org/pdf/2211.09242v3)).

Proven result

The exact worst-case recovery problem is \(\mathrm{NP}\)-hard, for either recourse policy. This holds even when \(K=2\), \(\ell=1\), there are no non-directed-donor types, all supported types have equal positive dyadic masses, and every participant is selected by an explicit feasible first-stage plan.

The proof is a polynomial-time reduction from Vertex Cover. Continuous failure masses do not invalidate the reduction.

1. A graph construction with an explicit perfect matching

Start with a Vertex Cover instance consisting of a finite simple undirected graph \(G=(V,E)\), with \(n=|V|\ge1\), and an integer \(0\le k\le n\). The question is whether some set of at most \(k\) vertices meets every edge. This decision problem is \(\mathrm{NP}\)-complete; see the [standard Vertex Cover theorem and reduction](https://www.cs.cmu.edu/~lblum/flac/Lectures_pdf/Lecture19.pdf).

Let \(N\) be the smallest power of two satisfying \(N\ge n\). Add isolated vertices to obtain a graph \(G'\) on vertices \(v_1,\ldots,v_N\). Adding isolated vertices preserves the minimum vertex-cover size.

Construct an undirected graph \(H\) by adding vertices \(w_1,\ldots,w_N\), making these new vertices a clique, and adding every edge between a vertex of \(G'\) and a new vertex. Retain all edges of \(G'\).

Write \(\operatorname{vc}(J)\) for the minimum vertex-cover size of a graph \(J\). Then

\[ \operatorname{vc}(H)=N+\operatorname{vc}(G). \]

To verify this identity, write \(\alpha(J)\) for the maximum independent-set size. A vertex set is a cover exactly when its complement is independent, so \(\operatorname{vc}(J)=|V(J)|-\alpha(J)\). Every independent set of \(H\) lies entirely in \(G'\), or consists of a single new vertex: the new vertices form a clique and are adjacent to every original vertex. Since \(G'\) is nonempty, \(\alpha(G')\ge1\), and consequently \(\alpha(H)=\alpha(G')\). Therefore

\[ \operatorname{vc}(H)=2N-\alpha(G')=N+\operatorname{vc}(G')=N+\operatorname{vc}(G). \]

Also, \(H\) has the explicit perfect matching consisting of the edges \(\{v_i,w_i\}\), for \(1\le i\le N\).

2. Constructing the society and first-stage plan

Create one pair type for each vertex of \(H\), and no non-directed-donor types. Thus \(\tau=2N\). Give every type mass

\[ c=\frac{1}{2N}. \]

These masses are positive dyadic rationals and sum to one.

For every undirected edge \(\{u,v\}\) of \(H\), include both compatibility arcs \((u,v)\) and \((v,u)\). Include no diagonal arcs. Set \(K=2\) and \(\ell=1\).

For each matching edge \(\{v_i,w_i\}\), put its two-position cycle into the first-stage plan with allocation \(c\). Each type occurs in exactly one such pattern, once. Hence

\[ s_t=c=\mu_t \]

for every type. The first-stage plan is therefore explicit and feasible, and every participant is selected.

Set \(h=N+k\) and choose failure budget

\[ r_v=hc=\frac{N+k}{2N}. \]

Because \(0\le k\le n\le N\), this budget belongs to \([0,1]\).

For either policy, every unselected failure mass must be zero because \(\mu_t-s_t=0\). Under full recourse, any pattern containing an unselected position must also receive zero allocation, by its zero-capacity resource constraint. Thus the two policies give identical recovery problems on these instances.

3. The recovery LP and its zero-value criterion

There are no chains, since there are no non-directed donors. Because \(K=2\) and diagonal arcs are absent, every usable recovery pattern is a two-position cycle corresponding to an edge of \(H\). Its two positions have distinct types and are selected, so its reward is two.

If several representations describe the same cycle, aggregate their allocations into one edge variable. Writing \(\gamma_v=\gamma_v^S\), the recovery LP is exactly

\[ F(\gamma)=2\max\left\{\sum_{e\in E(H)}y_e: y_e\ge0,\quad \sum_{e\ni v}y_e\le c-\gamma_v \text{ for every }v\in V(H)\right\}. \]

Its optimum exists: the feasible set is nonempty and closed, and summing the vertex constraints gives \(2\sum_e y_e\le1\), so it is bounded.

Define \(D(\gamma)=\{v:\gamma_v=c\}\), the set of completely failed types. Then

\[ F(\gamma)=0 \quad\Longleftrightarrow\quad D(\gamma)\text{ is a vertex cover of }H. \]

Indeed, if an edge \(\{u,v\}\) has neither endpoint in \(D(\gamma)\), both surviving masses are positive. Allocating \(\min\{c-\gamma_u,c-\gamma_v\}>0\) to that edge cycle is feasible and gives positive recovery.

Conversely, if \(D(\gamma)\) covers every edge, each edge variable is incident to a vertex with zero surviving capacity. Nonnegativity and that vertex’s constraint force the variable to zero. Thus every recovery allocation has value zero.

This criterion already shows why partially failing both endpoints cannot destroy a cycle while both retain positive mass.

4. An attaining worst case can use only complete failures

To justify minimization over real failures explicitly, normalize by \(z_v=\gamma_v/c\). The failure polytope becomes

\[ Q_h=\left\{z\in[0,1]^{2N}:\sum_v z_v\le h\right\}, \]

where \(h\) is an integer.

Every vertex of \(Q_h\) is binary. To prove this, suppose a feasible point has fractional coordinates.

  • If at least two coordinates are fractional, increase one and decrease the other by the same sufficiently small amount. Both opposite perturbations remain feasible, so the point is not a vertex.
  • If exactly one coordinate is fractional and the budget inequality is slack, that coordinate admits sufficiently small perturbations in both directions.
  • If exactly one coordinate is fractional and the budget inequality is tight, the sum of the other coordinates is an integer. Their sum plus the remaining fractional coordinate cannot equal the integer \(h\).

These cases exhaust all nonbinary points.

Next, \(F\) is concave in \(\gamma\). Given optimal recovery allocations for two failure vectors, their convex combination is feasible for the corresponding convex combination of failure vectors: the surviving-capacity vectors combine linearly. Its objective is the same convex combination of the two optimal values, proving concavity.

The bounded polytope \(Q_h\) is the convex hull of its finitely many vertices. Consequently, if \(z=\sum_j\lambda_j z^{(j)}\) is such a convex combination, concavity gives

\[ F(cz)\ge\sum_j\lambda_jF(cz^{(j)}) \ge\min_jF(cz^{(j)}). \]

Thus the minimum is attained at a vertex of \(Q_h\). Such a failure vector completely fails at most \(h\) types and leaves every other type untouched.

In particular, if \(H\) has no vertex cover of size at most \(h\), every vertex failure vector leaves an edge with both endpoint capacities equal to \(c\). Allocating \(c\) to that cycle yields value \(2c\). Therefore the constructed instances satisfy the rigorous dichotomy

\[ W=0 \quad\text{or}\quad W\ge2c=\frac1N. \]

5. Correctness and polynomial size of the reduction

The preceding results give

\[ W=0 \quad\Longleftrightarrow\quad \operatorname{vc}(H)\le h \quad\Longleftrightarrow\quad N+\operatorname{vc}(G)\le N+k \quad\Longleftrightarrow\quad \operatorname{vc}(G)\le k. \]

In the forward construction of a zero-value failure vector, choose a vertex cover of \(H\) of size at most \(h\), fail each of its types by mass \(c\), and fail nothing else. The budget is respected and the all-zero recovery allocation is optimal.

For the converse, the attaining binary failure vector established above has at most \(h\) completely failed types. If its recovery value is zero, those types form a vertex cover of \(H\), which implies the required cover bound for \(G\).

Finally, \(N<2n\), the number of compatibility arcs is

\[ m=2\left(|E|+N^2+\binom N2\right), \]

and the first-stage plan contains \(N\) patterns of length two. All rational data have binary encoding length \(O(\log N)\), and both unary limits are constant. The complete construction has polynomial size and can be performed in polynomial time.

Hence an algorithm computing the exact \(W\) in time polynomial in \(m,\tau,L,K,\ell\) would decide Vertex Cover in polynomial time. Computing \(W\) alone is already \(\mathrm{NP}\)-hard, so the requested task of also returning attaining failures and an optimal recovery allocation is \(\mathrm{NP}\)-hard. A polynomial-time algorithm for all inputs would therefore imply \(\mathrm{P}=\mathrm{NP}\).
