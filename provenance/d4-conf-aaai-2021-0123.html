The continuous mirror question, as graded

Given \(d\), a rational status quo \(r\), a finite type set \(T\subseteq\mathbb{Q}^d\), rational masses \(\mu_t>0\) summing to \(1\), and a valid finite initial coalition structure with rational per-type allocations, does every maximal run of two-coalition compromise transitions terminate at a coalition whose proposal maximizes approval mass and whose mass equals that proposal’s total approval mass? Proposals are in \(\mathbb{Q}^d\); each transition moves all approving mass from its two source coalitions into the new coalition, which must be larger than either source.

Packaged proof task (what the prover saw — nothing else)

Given \(d\geq1\), let the proposal space be \(\mathbb Q^d\) and the status quo be \(r\in\mathbb Q^d\). Type \(t\) approves \(p\) exactly when \(\|t-p\|_2<\|t-r\|_2\); equality means disapproval.
A society is given by its support: \(T\subseteq\mathbb Q^d\), with \(\tau=|T|\) positive masses \(\mu_t\in\mathbb Q\) encoded in binary and summing to \(1\). Require \(T\setminus\{r\}\neq\varnothing\); \(\tau\) counts listed types, not possible types.
The input includes \(k\) positive-mass coalitions \((a_i,p_i)\), where \(a_{it}\in\mathbb Q_{\geq0}\), \(\sum_i a_{it}=\mu_t\), and \(p_i\in\mathbb Q^d\). If \(p_i\neq r\), every type with \(a_{it}>0\) approves \(p_i\); if \(p_i=r\), only type \(r\) may have positive allocation. Distinct coalitions may support the same proposal, and a type may be split among coalitions.
Write \(s(a)=\sum_t a_t\) and \(a^p_t=a_t\mathbf1\{t\text{ approves }p\}\). A transition chooses two distinct coalitions \((a,p_a),(b,p_b)\) and any \(p\in\mathbb Q^d\setminus\{r\}\), replacing them by \((a^p+b^p,p)\), \((a-a^p,p_a)\), and \((b-b^p,p_b)\), provided \(s(a^p+b^p)>\max\{s(a),s(b)\}\). Omit zero-mass remnants; leave all other coalitions unchanged. No additional splitting or transfers are permitted.
Let \(A(p)=\sum_{t\text{ approves }p}\mu_t\) and \(M=\max_{p\in\mathbb Q^d\setminus\{r\}}A(p)\). A structure is successful if it contains \((a,p)\) with \(A(p)=s(a)=M\). A maximal run is infinite or finite with no available transition; it succeeds exactly when it is finite and its final structure is successful.
Let \(L\) be the total binary input length and \(m=d\); state running times in \(m,\tau,k,L\).

Is deciding whether every maximal run from the supplied initial structure succeeds solvable in polynomial time, or is it NP-hard?

For finite agent lists in full Euclidean proposal spaces, every maximal two-coalition compromise run succeeds; this also holds with rational proposals. [Discrete guarantee](https://link.springer.com/article/10.1007/s00355-024-01561-y).
For finite agent lists, every such run has at most \(2^n\) transitions, where \(n\) is the number of agents. [Discrete length bound](https://arxiv.org/html/2202.12594). No result explicitly treating the mass-allocation decision problem above was located.

Modeling choices made when packaging the task

  • Specified strict Euclidean approval, with distance ties treated as disapproval.
  • Made validity explicit: allocations partition each type's mass, non-status-quo coalitions contain only approvers, and status-quo coalitions contain only the status-quo type.
  • Specified that dissenting mass retains its original proposal, other coalitions remain unchanged, and transitions permit no additional splitting.
  • Omitted zero-mass coalitions and allowed separate coalitions with identical proposals.
  • Excluded societies supported entirely at the status quo, avoiding the zero-approval degeneracy in the intended success guarantee.
  • Defined maximality to include infinite runs and required finite termination for success.
  • Used m=d and included the initial coalition count k and total binary input length L in the running-time convention.

Resolution

The decision problem is polynomial-time solvable: every valid input is a YES-instance. Rational masses and the prescribed transition rule allow an exact transfer to the finite-agent theorem given in the question. The transfer is a proof device; the decision algorithm does not construct the expanded agent list.

1. The maximum approval is attained

For any proposal \(p\), its approval set is a subset of the finite support \(T\). Consequently, \(A(p)\) takes values in the finite set
\(\{\sum_{t\in S}\mu_t:S\subseteq T\}\).
The proposal domain is nonempty, so its approval values have an attained maximum \(M\).

Moreover, \(M>0\): choose \(t\in T\setminus\{r\}\). The rational proposal \(p=t\) is approved by type \(t\), since
\(\|t-t\|_2=0<\|t-r\|_2\).

2. Exact expansion into finitely many agents

Choose a positive integer \(D\) divisible by the denominators of every \(\mu_t\) and every \(a_{it}\). Then all \(D\mu_t\) and \(Da_{it}\) are nonnegative integers.

For each type \(t\), introduce \(D\mu_t\) distinct labeled agents, each located at \(t\). Labels distinguish agents even when their locations coincide. This is a finite agent list, with total length
\(N=\sum_t D\mu_t=D\).

Partition the agents of type \(t\) among the initial coalitions, assigning exactly \(Da_{it}\) to coalition \(i\). This is possible because
\(\sum_i Da_{it}=D\mu_t\).
Let \(C_i\) be the resulting labeled-agent coalition, supporting \(p_i\).

This is a valid finite-agent coalition structure:

  • If \(p_i\ne r\), every agent in \(C_i\) approves \(p_i\), by the input hypothesis.
  • If \(p_i=r\), all its agents are located at \(r\). Such agents approve no proposal, because their distance to the status quo is zero.
  • Every agent belongs to exactly one coalition.
  • Coalitions remain distinct even when they support the same proposal.

The expansion accommodates every initially split type by placing different labeled agents of that type in different coalitions.

3. Transitions correspond exactly

At any corresponding state, suppose a mass coalition \((a,p_a)\) is represented by \((C_a,p_a)\), with exactly \(Da_t\) agents of type \(t\). Thus
\(|C_a|=Ds(a)\).

For every rational proposal \(p\), all agents located at \(t\) make the same approval decision. Therefore
\(|C_a^p|=Ds(a^p)\).

Consider two distinct coalitions represented by \(C_a,C_b\). Since their agent sets are disjoint,
\(|C_a^p\cup C_b^p|=Ds(a^p+b^p)\).
Multiplication by the positive number \(D\) gives the equivalence
\[ \text{ } \]
\(s(a^p+b^p)>\max\{s(a),s(b)\}\)
if and only if
\(|C_a^p\cup C_b^p|>\max\{|C_a|,|C_b|\}\).

The moving agents represent precisely the allocation \(a^p+b^p\). The two remnants represent precisely \(a-a^p\) and \(b-b^p\). Empty agent remnants correspond to zero-mass remnants and are omitted.

Hence every mass transition lifts to a finite-agent compromise transition, using the same rational proposal. Conversely, every finite-agent compromise transition projects to an allowed mass transition. No additional splitting or transfers are introduced.

Induction on the transitions therefore lifts any mass run to a corresponding finite-agent run. An infinite mass run lifts to an infinite run. A finite terminal mass run lifts to a terminal run: any available finite-agent transition would project to an available mass transition.

4. Applying the finite-agent guarantee

We use the theorem supplied in the question: for a finite agent list in a full Euclidean proposal space, every maximal two-coalition compromise run terminates successfully; the conclusion also holds for rational proposals. The transition requires all approvers in the selected coalitions to move and the resulting coalition to exceed both original sizes. See [Theorem 3, Definition 10, and the rational-space observation following Theorem 3](https://link.springer.com/article/10.1007/s00355-024-01561-y).

All hypotheses were checked above: finitely many labeled agents, Euclidean strict approval, the full rational proposal space, a valid initial partition, and exactly the specified compromise rule.

For any rational proposal \(p\), the expanded approval count is
\(|V^p|=DA(p)\).
Its maximum is consequently \(DM\).

Now take any maximal mass run. Its lift is maximal, so the finite-agent theorem says that it is finite and ends with a coalition \((C,p)\) satisfying
\(|C|=|V^p|=DM\).
For the corresponding mass coalition \((a,p)\), this gives
\(Ds(a)=DA(p)=DM\), and therefore
\(s(a)=A(p)=M\).

Thus the original maximal run succeeds. Since the run was arbitrary, every maximal run succeeds.

5. A direct termination bound using the listed allocations

The denominator expansion is unnecessary even for proving termination. A sharper bound follows from the transition rule itself.

For each initially positive allocation \(a_{it}\), create one labeled packet of mass \(a_{it}\) and type \(t\). Let
\(B=|\{(i,t):a_{it}>0\}|\), so \(1\le B\le k\tau\).

A packet is never split: whenever its current coalition participates in a transition, approval depends only on its type, so the entire packet moves or the entire packet remains. Every reachable coalition structure therefore partitions these \(B\) packets into nonempty blocks.

For each structure, sort its coalition masses in nonincreasing order and pad with zeros to obtain a vector of length \(B\). Every transition strictly increases this vector lexicographically. Indeed, if the two selected masses are \(x,y\) and the new mass is \(c\), then \(c>\max\{x,y\}\). Both remnants have mass less than \(c\). Thus all preexisting masses at least \(c\) remain unchanged, and one additional mass \(c\) appears. At the first changed coordinate, the new vector has \(c\) and the old vector has a smaller value.

There are at most \(\operatorname{Bell}(B)\) possible mass vectors, because a partition of the packets determines its vector. Consequently every run has at most
\(\operatorname{Bell}(B)-1\le B^B-1\le(k\tau)^{k\tau}-1\)
transitions. The inequality \(\operatorname{Bell}(B)\le B^B\) follows by encoding a partition through the function sending each packet label to the least label in its block.

This bound is independent of the denominators and of \(m\). It proves finiteness directly; the finite-agent theorem supplies the success of terminal states.

6. Decision algorithm and running time

On the promised valid inputs, the algorithm simply returns YES. Its decision time is \(O(1)\), or \(O(L)\) if it reads the complete encoding.

If malformed inputs must also be rejected, the stated validity conditions can be checked in polynomial time using exact rational arithmetic. A conservative bound is
\(O\!\left(m(k\tau+\tau^2)L^3\right)\)
bit operations, including pairwise checks that the listed types are distinct. Approval is checked by comparing squared distances, so no square roots or numerical approximation are needed.

Although \(D\) can be exponentially large in \(L\), neither decision algorithm constructs the expanded society.
