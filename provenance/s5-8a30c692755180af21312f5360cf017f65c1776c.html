The continuous mirror question, as graded

Given a finite directed role graph \(H=(R,F)\), signal laws \(p_\theta(r)\), and query \((r^\star,t,s^\star,h)\), consider the population \(\Omega=R\times[0,1]\) with role masses \(\mu(\{r\}\times B)=\lambda(B)/|R|\), a shared state \(\theta\), and communication edges only between corresponding roles in the same copy \(z\); compute the queried agent’s action, or decide whether its posterior is at least \(1-2^{-g}\) or at most \(2^{-g}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here types are roles in a nonempty directed graph \(H=(R,F)\), with \(\tau=|R|\), \(m=|F|\), and mass \(1/\tau\) per role.
The population is \(\Omega=R\times[0,1]\), with \(\mu(\{r\}\times B)=\lambda(B)/\tau\) for Lebesgue-measurable \(B\). An edge \((r,v)\in F\) means that \((r,z)\) observes \((v,z)\); there are no observations between different copies.
The shared state \(\theta\in\{\mathsf T,\mathsf F\}\) has uniform prior. Private signals \(S(r,z)\in\{0,1\}\) are conditionally independent given \(\theta\), with \(\Pr[S(r,z)=1\mid\theta]=p_\theta(r)\). The input probabilities are binary rationals satisfying \(0<p_{\mathsf F}(r)\le p_{\mathsf T}(r)<1\); equality permits uninformative signals. Independence is specified through finite-dimensional distributions; no population aggregate is observed.
The structure and Bayesian rationality are common knowledge. At each integer time \(k\ge0\), agents simultaneously broadcast \(A(r,z,k)=\mathsf T\) exactly when their posterior \(b(r,z,k)=\Pr[\theta=\mathsf T\mid S(r,z),\{A(v,z,j):(r,v)\in F,\ 0\le j<k\}]\) exceeds \(1/2\); otherwise they broadcast \(\mathsf F\).
A query supplies \(r^\star\in R\), unary \(t\ge0\), private signal \(s^\star\in\{0,1\}\), and an explicitly indexed observation history \(h\) through time \(t-1\), promised jointly to have positive probability. Query the agent \((r^\star,0)\). The action problem returns its action at time \(t\); the posterior promise problem additionally supplies unary \(g\ge2\) and distinguishes \(b\ge1-2^{-g}\) from \(b\le2^{-g}\), promised that one holds. Let \(L\) be the total binary bit length of the rational data and explicitly supplied history; state running times in \(m,\tau,L,t,g\).

Is the continuous action problem in \(\mathsf P\) or \(\mathsf{NP}\)-hard? Independently, is the continuous posterior promise problem in \(\mathsf P\) or \(\mathsf{NP}\)-hard?

For finite networks, both action computation and distinguishing posteriors exponentially close to opposite endpoints are \(\mathsf{PSPACE}\)-hard, using efficiently computable real signal probabilities. No result for exactly the continuous problems defined here is established by the supplied material.

Modeling choices made when packaging the task

  • Identified society types with roles, retained the specified uniform total mass of one, and defined m as the number of directed role edges.
  • Specified a uniform binary-state prior, conditionally independent binary private signals, common knowledge of rationality, synchronous broadcasts, the observer-to-observed edge convention, and deterministic tie-breaking toward the false state.
  • Chose binary rational signal probabilities strictly between zero and one, with the true-state probability at least the false-state probability; equality represents an uninformative signal.
  • Specified independence by finite-dimensional distributions, without requiring a jointly measurable signal field or introducing population observations.
  • Fixed the queried copy to zero because the query supplies no copy coordinate and every copy has the same specified structure.
  • Required an explicitly indexed complete observation history and a positive-probability conditioning event.
  • Encoded time and the gap exponent in unary, required the gap exponent to be at least two, and made the separated-posterior promise explicit.
  • Treated action computation and posterior distinction as separate problems, preserving both alternatives in the graded question.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result. Both the continuous action problem and the continuous posterior promise problem are \(\mathsf{NP}\)-hard under polynomial-time many-one reductions. Hardness holds already at \(t=2\), on directed acyclic observation graphs, with dyadic signal probabilities.

The proof below constructs valid promised instances directly from Vertex Cover.

2. Why a single copy is a finite Bayesian process. Fix \(z\in[0,1]\), and write \(X_z=(S(r,z))_{r\in R}\). Conditional on \(\theta\), this finite vector has distribution

\(\Pr[X_z=x\mid\theta]=\prod_{r\in R}p_\theta(r)^{x_r}(1-p_\theta(r))^{1-x_r}\).

Every action in this copy is a deterministic function of \(X_z\). This follows inductively: at time zero an agent uses its own coordinate; at subsequent times its observations are previously determined functions of the same vector.

Consequently, every posterior in the queried copy is obtained by conditioning this finite product distribution. Neither signals in other copies nor population masses enter these calculations, because they are not observed. Thus the specified finite-dimensional distributions suffice.

3. Construction from Vertex Cover. We use the established \(\mathsf{NP}\)-completeness of Vertex Cover for finite simple undirected graphs. See [Karp, *Reducibility Among Combinatorial Problems*](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Let the source instance be a graph \(G=(V,E)\), with \(n=|V|\ge1\), and an integer \(K\) satisfying \(0\le K\le n\). The question is whether a vertex cover of size at most \(K\) exists. These restrictions preserve hardness, since instances outside them are trivial.

Choose any integer \(g\ge2\), and define

\(B=2(n+g+2),\qquad q=2^{-B},\qquad D=B(K+\tfrac12)\).

Because \(B\) is even, \(D\) is an integer.

Construct the following roles:

  • A vertex role \(x_v\) for each \(v\in V\).
  • An edge role \(y_e\) for each \(e\in E\).
  • A query role \(r^\star\).

For each edge \(e=\{u,v\}\), include observation edges \((y_e,x_u)\), \((y_e,x_v)\), and \((r^\star,y_e)\). There are no other observation edges. Hence

\(\tau=n+|E|+1,\qquad m=3|E|\).

Assign mass \(1/\tau\) to every role. Set the signal probabilities as follows:

\[ \text{(all formulas below use the specified binary-rational encoding)} \]

For each vertex role,

\(p_{\mathsf T}(x_v)=1-q^2,\qquad p_{\mathsf F}(x_v)=1-q\).

For each edge role,

\(p_{\mathsf T}(y_e)=p_{\mathsf F}(y_e)=\tfrac12\).

For the query role,

\(p_{\mathsf T}(r^\star)=\tfrac12,\qquad p_{\mathsf F}(r^\star)=2^{-(D+1)}\).

All probabilities are dyadic and satisfy \(0<p_{\mathsf F}\le p_{\mathsf T}<1\).

The query has \(t=2\), private signal \(s^\star=1\), and the explicitly indexed history

\(h(y_e,0)=h(y_e,1)=\mathsf F\quad\text{for every }e\in E\).

We now calculate exactly what this history means.

4. Edge roles recognize an uncovered edge. Suppress the copy coordinate, which is fixed at zero.

For a vertex role, the likelihood ratios of private signals one and zero are respectively

\(\ell_1=\dfrac{1-q^2}{1-q}=1+q>1,\qquad \ell_0=\dfrac{q^2}{q}=q<1\).

The prior odds are one. Therefore its time-zero action reveals its private signal exactly:

\(A(x_v,0)=\mathsf T\quad\Longleftrightarrow\quad S(x_v)=1\).

An edge role has an uninformative private signal, so its time-zero posterior is exactly \(1/2\). The specified tie rule gives \(A(y_e,0)=\mathsf F\).

At time one, \(y_{\{u,v\}}\) observes the two endpoint signals through their time-zero actions. Conditional independence and its uninformative private signal give posterior odds

\(\ell_{S(x_u)}\ell_{S(x_v)}\).

There are three cases:

  • Two signals equal to one give odds \((1+q)^2>1\).
  • One signal of each kind gives odds \(q(1+q)<1\), since \(q<1/2\).
  • Two signals equal to zero give odds \(q^2<1\).

Thus

\(A(y_{\{u,v\}},1)=\mathsf T\quad\Longleftrightarrow\quad S(x_u)=S(x_v)=1\).

Define the random vertex set

\(C=\{v\in V:S(x_v)=0\}\).

The supplied history holds exactly when every edge has an endpoint in \(C\), that is, when \(C\) is a vertex cover. The time-zero edge reports impose no additional restriction.

This history, together with \(S(r^\star)=1\), has positive probability under both states: the assignment with all vertex signals zero realizes it, and every signal value has strictly positive conditional probability. Hence the positive-history promise always holds.

5. Bounding the likelihood of observing a cover. Let \(k\) denote the minimum vertex-cover size of \(G\), and define

\(Z(a)=\sum_{C\subseteq V:\,C\text{ is a vertex cover}}a^{|C|}(1-a)^{n-|C|}\).

Under state \(\mathsf F\), each vertex belongs to \(C\) independently with probability \(q\). Under state \(\mathsf T\), that probability is \(q^2\). Therefore

\(\Pr[h\mid\mathsf F]=Z(q),\qquad \Pr[h\mid\mathsf T]=Z(q^2)\).

For either \(a=q\) or \(a=q^2\), we have the bounds

\(\tfrac12a^k\le Z(a)\le2^na^k\).

Here is their justification. Since \(B\ge n+1\) and \(n\le2^n\), we have \(nq\le1/2\). The elementary inequality \((1-a)^n\ge1-na\), proved by induction, consequently gives \((1-a)^n\ge1/2\) for both choices of \(a\). The contribution of any minimum cover is therefore at least

\(a^k(1-a)^{n-k}\ge a^k(1-a)^n\ge\tfrac12a^k\).

For the upper bound, every cover has size at least \(k\), so each summand is at most \(a^k\); there are at most \(2^n\) summands.

Taking ratios yields

\(2^{-n-1}q^k\le\dfrac{Z(q^2)}{Z(q)}\le2^{n+1}q^k\).

These inequalities require no knowledge of how many minimum covers exist.

6. The query posterior separates the two cases. The likelihood ratio of the query agent’s supplied private signal is

\(\dfrac{p_{\mathsf T}(r^\star)}{p_{\mathsf F}(r^\star)}=2^D\).

That signal is conditionally independent of the vertex signals. With the uniform prior, the posterior odds \(O\) at time two therefore satisfy

\(O=\dfrac{b}{1-b}=2^D\dfrac{Z(q^2)}{Z(q)}\).

Substituting \(q=2^{-B}\) and the bounds above gives

\(2^{B(K+1/2-k)-n-1}\le O\le2^{B(K+1/2-k)+n+1}\).

If \(G\) has a cover of size at most \(K\), then \(k\le K\), and

\(O\ge2^{B/2-n-1}=2^{g+1}\).

Consequently,

\(1-b=\dfrac1{1+O}<2^{-(g+1)}<2^{-g}\).

If \(G\) has no cover of size at most \(K\), integrality gives \(k\ge K+1\), and

\(O\le2^{-B/2+n+1}=2^{-(g+1)}\).

Consequently,

\(b=\dfrac O{1+O}<2^{-(g+1)}<2^{-g}\).

Thus every constructed instance satisfies the posterior promise, with the correspondence

\(\text{Vertex Cover yes}\ \Longleftrightarrow\ b\ge1-2^{-g}\),

\(\text{Vertex Cover no}\ \Longleftrightarrow\ b\le2^{-g}\).

Since \(g\ge2\), these cases also give actions \(\mathsf T\) and \(\mathsf F\), respectively. The same construction therefore proves hardness of both problems independently.

7. Encoding size and reduction time. Every vertex-role probability has bit length \(O(B)\); the query-role probabilities have bit length \(O(B(K+1))\). Including masses and the indexed history gives

\(L=O\bigl((n+K+1)B+\tau\log(\tau+1)\bigr)\).

Because \(K\le n\) and \(B=O(n+g)\), this is polynomial in the source-instance length and unary \(g\). All numerators and denominators can be written directly as binary integers, so the reduction runs in time polynomial in \(m,\tau,L,g\), with \(t=2\).

Taking \(g=2\) proves \(\mathsf{NP}\)-hardness even for a fixed posterior gap. Taking \(g=\tau\) proves hardness with posteriors within \(2^{-\tau}\) of opposite endpoints, still using polynomial-length rational inputs.

8. An exact upper bound for arbitrary inputs. For completeness, both problems admit an exhaustive algorithm whose dependence on support size is explicit.

Enumerate the \(2^\tau\) signal profiles \(x\). Write each input probability as \(p_\theta(r)=a_{\theta,r}/d_{\theta,r}\), and define

\(D_\theta=\prod_r d_{\theta,r}\),

\(W_\theta(x)=\prod_{r:x_r=1}a_{\theta,r}\prod_{r:x_r=0}(d_{\theta,r}-a_{\theta,r})\).

Then \(\Pr[x\mid\theta]=W_\theta(x)/D_\theta\). These integers have \(O(L)\) bits. Moreover, \(\sum_xW_\theta(x)=D_\theta\), so every subset sum also has \(O(L)\) bits.

Inductively compute all actions through time \(t-1\). For role \(r\) at time \(j\), group profiles by the information signature

\(\bigl(x_r,(A(v,i;x))_{(r,v)\in F,\ 0\le i<j}\bigr)\).

Within each group, sum \(W_{\mathsf T}\) and \(W_{\mathsf F}\), obtaining \(U_{\mathsf T}\) and \(U_{\mathsf F}\). The action is \(\mathsf T\) precisely when

\(U_{\mathsf T}D_{\mathsf F}>U_{\mathsf F}D_{\mathsf T}\).

Afterward, retain the profiles matching the supplied private signal and indexed history. Their corresponding sums give the exact query posterior

\(b=\dfrac{U_{\mathsf T}D_{\mathsf F}}{U_{\mathsf T}D_{\mathsf F}+U_{\mathsf F}D_{\mathsf T}}\).

The promised endpoint comparisons use integer arithmetic with \(O(L+g)\) bits.

Sorting explicit information signatures and using schoolbook integer arithmetic gives, for example, the conservative bit-operation bound

\(O\bigl(2^\tau(t+1)^2(m+\tau)(L+\tau+g+1)^3\bigr)\),

with \(g=0\) for action queries. This is polynomial for fixed support size, but both problems are \(\mathsf{NP}\)-hard when support size is part of the input. A polynomial-time algorithm for either would therefore imply \(\mathsf P=\mathsf{NP}\).
