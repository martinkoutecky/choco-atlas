Proposition 1. — class: other

The continuous mirror question, as graded

Given rational masses \(\mu\) summing to \(1\) over the six strict rankings of \(x,y,z\), decide whether the strict pairwise-majority relation cycles. Equivalently, for \(\Delta_X=\mu_{PX1}-\mu_{PX2}\) and analogously \(\Delta_Y,\Delta_Z\), test whether all three differences have the same strict sign and each satisfies \(|\Delta_i| < (|\Delta_X|+|\Delta_Y|+|\Delta_Z|)/2\).

Packaged proof task (what the prover saw — nothing else)

There are \(m=3\) alternatives, \(x,y,z\), and types are strict rankings. A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Masses sum to \(1\); absent types have mass \(0\). Let \(L\) be the total input bit length.
The ranking labels are \(P_{X1}:z\succ x\succ y\), \(P_{X2}:y\succ x\succ z\), \(P_{Y1}:x\succ y\succ z\), \(P_{Y2}:z\succ y\succ x\), \(P_{Z1}:y\succ z\succ x\), and \(P_{Z2}:x\succ z\succ y\).
Write \(a\succ_M b\) when the mass ranking \(a\) above \(b\) exceeds \(1/2\); a tie creates no strict majority edge. A cycle means \(x\succ_M y\succ_M z\succ_M x\) or its reverse.
The decision question is whether this relation cycles. Equivalently, put \(\Delta_i=\mu(P_{i1})-\mu(P_{i2})\) for \(i\in\{X,Y,Z\}\): all three differences must have the same strict sign and satisfy \(2|\Delta_i|<|\Delta_X|+|\Delta_Y|+|\Delta_Z|\).

Is deciding whether the strict pairwise-majority relation cycles solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For a finite electorate of odd size, the same sign and inequality conditions, with ranking counts replacing masses, characterize majority cycles (List, *Some Remarks on the Probability of Cycles*, attributing the characterization to Nicholas Miller). The same source establishes that independent sampling from a distribution satisfying these strict inequalities yields a cycle with probability tending to \(1\) as electorate size increases.

Modeling choices made when packaging the task

  • Expanded the undefined ranking labels using the six rankings in the supplied text.
  • Represented only positive-mass types in the support and assigned zero mass to omitted rankings.
  • Specified that equal pairwise masses produce no strict majority edge and that either orientation of the three-alternative cycle counts.
  • Defined L as the total input bit length; m is fixed at three.

Result

The decision problem is polynomial-time solvable. For \(m=3\), it can be decided in \(O(L^2)\) bit operations using elementary exact integer arithmetic.

The support size satisfies \(\tau\leq 6\), but the masses may have arbitrarily long binary encodings. Thus the bit complexity of arithmetic must still be accounted for.

1. Deriving the majority margins

For distinct alternatives \(a,b\), define
\[ M_{ab}:=\mu(a\succ b)-\mu(b\succ a). \]
Because every ranking is strict and the masses sum to \(1\), \(a\succ_M b\) holds exactly when \(M_{ab}>0\).

Using the six rankings in the question gives:

  • \(M_{xy}=\mu(P_{X1})+\mu(P_{Y1})+\mu(P_{Z2})-\mu(P_{X2})-\mu(P_{Y2})-\mu(P_{Z1})=\Delta_X+\Delta_Y-\Delta_Z\).
  • \(M_{yz}=\mu(P_{X2})+\mu(P_{Y1})+\mu(P_{Z1})-\mu(P_{X1})-\mu(P_{Y2})-\mu(P_{Z2})=-\Delta_X+\Delta_Y+\Delta_Z\).
  • \(M_{zx}=\mu(P_{X1})+\mu(P_{Y2})+\mu(P_{Z1})-\mu(P_{X2})-\mu(P_{Y1})-\mu(P_{Z2})=\Delta_X-\Delta_Y+\Delta_Z\).

Consequently, the relation cycles exactly when these three margins are all strictly positive or all strictly negative. A zero margin cannot participate in either of the two possible cycles.

These formulas also verify the stated characterization. Indeed,

\(2\Delta_X=M_{xy}+M_{zx}\),
\(2\Delta_Y=M_{xy}+M_{yz}\),
\(2\Delta_Z=M_{yz}+M_{zx}\).

If all margins are positive, all three differences are positive. Writing \(S=\Delta_X+\Delta_Y+\Delta_Z\), the margin formulas become

\(M_{xy}=S-2\Delta_Z\),
\(M_{yz}=S-2\Delta_X\),
\(M_{zx}=S-2\Delta_Y\).

Thus positivity of all margins is equivalent to positivity of all differences together with \(2\Delta_i<S\) for every \(i\in\{X,Y,Z\}\). Negating all differences proves the corresponding equivalence for negative margins. This establishes the rational-mass version of the characterization attributed to Miller in [List’s Proposition 1](https://www.nuff.ox.ac.uk/Users/list/probcycles.pdf).

2. An exact decision algorithm

Write each supported mass as \(p_t/q_t\), where \(p_t,q_t\) are binary-encoded integers and \(q_t>0\). This accommodates general binary-encoded rational numbers, including dyadic rationals.

Compute the positive common denominator \(Q=\prod_{t=1}^{\tau}q_t\). For each supported ranking \(P_t\), set \(N(P_t)=p_t(Q/q_t)\); set \(N(P)=0\) for every absent ranking. Then \(N(P)=Q\mu(P)\).

Define the integer differences \(D_i=N(P_{i1})-N(P_{i2})\). Compute

\(A=D_X+D_Y-D_Z\),
\(B=-D_X+D_Y+D_Z\),
\(C=D_X-D_Y+D_Z\).

Return yes exactly when \(A,B,C\) are all strictly positive or all strictly negative.

Correctness follows from \(A=QM_{xy}\), \(B=QM_{yz}\), and \(C=QM_{zx}\): multiplication by the positive integer \(Q\) preserves signs. In particular, the algorithm handles ties exactly.

3. Bit complexity

The binary length of \(Q\) is at most a constant plus the sum of the binary lengths of the input denominators, hence is \(O(L)\).

Moreover, each mass lies in \([0,1]\), so \(0\leq N(P)\leq Q\). Therefore every integer used above has \(O(L)\) bits, including the differences and margins.

Since \(\tau\leq 6\), the algorithm uses a constant number of integer multiplications, exact divisions, additions, and comparisons. Elementary multiplication and division on integers with \(O(L)\) bits take \(O(L^2)\) bit operations; additions and comparisons take \(O(L)\). The total running time is therefore \(O(L^2)\).

This proves membership in \(\mathrm{P}\), and hence polynomial-time solvability in the requested parameters \(m,\tau,L\). Under polynomial-time many-one reductions, \(\mathrm{NP}\)-hardness of this problem would imply \(\mathrm{P}=\mathrm{NP}\).
