The continuous mirror question, as graded

Given a rational mass profile \(\mu\) over \(\tau\) complete valuation types, a cohort scale \(N\) with \(N\mu_t\in\mathbb{Z}\), and Robertson–Webb EVAL and CUT oracles for each type valuation \(v_t\), what is the optimal worst-case query complexity of returning a partition \((X_{t,j})\) of \([0,1]\) into one bundle for each of the \(N\mu_t\) agents of type \(t\), such that \(v_t(X_{t,j})\le 1/N\) for every agent?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) complete valuation types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types. Each type specifies a nonnegative atomless additive measure \(v_t\) on \([0,1]\), normalized by \(v_t([0,1])=1\), accessible only through Robertson–Webb EVAL and CUT oracles.
The input also contains a binary integer \(N\ge2\) such that \(k_t=N\mu_t\in\mathbb Z_{>0}\); \(L\) is the total bit length of the masses and \(N\). There is no finite item parameter \(m\).
A deterministic protocol must return an explicit partition \((X_{t,j})_{t,\,1\le j\le k_t}\) of \([0,1]\), with every bundle a finite union of intervals and \(v_t(X_{t,j})\le1/N\). Shared endpoints may be assigned arbitrarily. Output interval endpoints must belong to \(\{0,1\}\) or have been returned by CUT queries; when a CUT answer is nonunique, the oracle may return any valid answer.
Complexity counts oracle calls, with exact real answers; arithmetic and output time are not charged.

What is the asymptotically optimal deterministic worst-case Robertson–Webb query complexity of this allocation problem as a function of \(N\), \(\tau\), and \(L\)?

For an explicit list of \(N\) agents, proportional chore division requires \(\Omega(N\log N)\) queries, and an \(O(N\log N)\) protocol is known. [Farhadi–Hajiaghayi](https://www.ijcai.org/proceedings/2018/0031.pdf)
No result settling the dependence on support size for this precise input and individual-bundle output model was located.

Modeling choices made when packaging the task

  • Normalized the mass profile to total mass one and made N a binary-encoded integer at least two.
  • Specified complete valuation types as nonnegative atomless additive measures normalized to value one, without imposing strictly positive densities.
  • Retained one explicit finite-union bundle per represented agent, rather than replacing the output by one aggregate bundle per type.
  • Selected deterministic protocols and worst-case behavior over all valid answers to nonunique CUT queries.
  • Made the intended Robertson–Webb output convention explicit: interval endpoints come from CUT answers or the boundaries of the chore.
  • Defined L as the bit length of the rational masses and N; oracle answers are exact reals, and only oracle calls are charged. There is no finite item parameter m.

Partial solution and new bounds

Let $\mathbf{k}=(k_1,\ldots,k_\tau)$ be any fixed admissible multiplicity vector, so that
$$ k_t\in\mathbb Z_{>0}, \qquad \sum_{t=1}^{\tau}k_t=N, \qquad \mu_t=\frac{k_t}{N}. $$
Write $Q^*(\mathbf{k})$ for the optimal deterministic worst-case query complexity for these masses, with exactly $\tau$ distinct supported valuation measures.

Define
$$ B(\mathbf{k}) = \max_{\varnothing\ne H\subseteq\{1,\ldots,\tau\}} \frac{\sum_{t\in H}k_t}{\max_{t\in H}k_t}. $$

I prove the following bounds:
$$ \boxed{ \Omega\!\left(N+B(\mathbf{k})\log N\right) \ \le\ Q^*(\mathbf{k}) \ \le\ O(N+\tau\log\tau). } $$

The lower bound is new relative to the notes. It repairs the distinct-type issue and applies to unequal multiplicities. In particular:

  • If $\max_t k_t=O(N/\tau)$, the complexity is $\Theta(N+\tau\log\tau)$.
  • For every admissible mass vector,

$$ Q^*(\mathbf{k}) = \Omega\!\left( N+\frac{\tau\log N}{1+\log(N/\tau)} \right). $$

  • Maximizing over admissible masses at fixed feasible $(N,\tau)$, without fixing their exact description length, gives $\Theta(N+\tau\log\tau)$.

A matching bound for every mass vector, and a complete statement conditioned on exact $L$, remain open here. All unqualified logarithms below have base two.

1. Uniform upper bound

We first establish the upper bound independently of the notes.

Represent type $t$ by $k_t$ labeled conceptual copies. A recursive node consists of an interval $I=[a,b]$ and a multiset $S$ containing $n$ copies. Maintain the invariant
$$ v_t(I)\le\frac nN $$
for every type represented in $S$.

At the root, $n=N$ and $I=[0,1]$, so normalization establishes the invariant. A node containing one copy assigns its interval to that copy.

For a node with $n\ge2$, put $h=\lfloor n/2\rfloor$. For every represented type $t$, query
$$ s_t=\operatorname{EVAL}_t(a,b). $$
If $s_t>0$, query
$$ c_t=\operatorname{CUT}_t\!\left(a,\frac hn s_t\right). $$
If $s_t=0$, set $c_t=a$.

Atomlessness makes the cumulative interval value continuous. When $s_t>0$, the requested value lies strictly between zero and $s_t$, so a valid cut exists and every valid answer satisfies $a<c_t<b$.

Order types by decreasing $c_t$, breaking ties deterministically, and place each type’s copies consecutively. Let $x$ be the mark of the copy in position $h$. Assign the first $h$ copies to $[a,x]$ and the others to $[x,b]$.

For a positive-value type represented on the left, $c_t\ge x$, hence
$$ v_t([a,x]) \le v_t([a,c_t]) =\frac hn s_t \le\frac hN. $$
For a positive-value type represented on the right, $c_t\le x$, hence
$$ v_t([x,b]) =s_t-v_t([a,x]) \le s_t-v_t([a,c_t]) =\frac{n-h}{n}s_t \le\frac{n-h}{N}. $$
These inequalities also hold when $s_t=0$, by nonnegativity. Thus both children satisfy the invariant.

Recursion terminates with $N$ leaves. Each leaf owner values its interval at most $1/N$. Subdivision partitions the parent up to endpoints, which have zero value. Every subdivision endpoint is a CUT answer or an inherited permitted endpoint. This also proves correctness for arbitrary valid choices of nonunique CUT answers.

For the query count, let $I_d$ be the number of type incidences among nodes at depth $d$. Because copies of each type are consecutive, at most one type occurs in both children of any split. Consequently,
$$ I_0=\tau, \qquad I_{d+1}\le I_d+2^d, \qquad I_d\le\tau+2^d-1. $$
The depth is at most $D=\lceil\log N\rceil$. Each internal incidence costs at most two queries, so
$$ Q \le2\sum_{d=0}^{D-1}I_d =O(\tau\log N+N). $$
Since $\tau\le N$,
$$ \tau\log N =\tau\log\tau+\tau\log(N/\tau) \le\tau\log\tau+\frac{N}{\ln2}. $$
Therefore
$$ Q=O(N+\tau\log\tau). $$
Processing the masses requires no oracle calls, so this upper bound has no additional dependence on $L$.

2. Endpoint lower bound

For any admissible masses, choose distinct numbers
$$ \varepsilon_t=\frac{t}{2N(\tau+1)} $$
and define valuation densities
$$ f_t(x)=1+\varepsilon_t(2x-1). $$
They are positive, normalized, and pairwise distinct. Moreover,
$$ f_t(x)>1-\frac1{2N}. $$

If $X$ is a permissible bundle for type $t$, then
$$ \frac1N\ge v_t(X) \ge\left(1-\frac1{2N}\right)|X|, $$
where $|X|$ denotes Lebesgue measure. Thus
$$ |X|\le\frac1{N-\frac12}. $$

Suppose the protocol obtains $r$ distinct interior CUT endpoints. These endpoints divide the interval into $r+1$ elementary open intervals. Ownership cannot change inside one such interval, because every output endpoint must be permitted. Each elementary interval therefore lies in one bundle and has length at most $1/(N-\frac12)$.

Their lengths sum to one, giving
$$ 1\le\frac{r+1}{N-\frac12}. $$
Integrality implies $r+1\ge N$, and hence
$$ \boxed{Q\ge r\ge N-1.} $$

For $\tau=1$, this is exact: the cumulative cuts at levels $j/N$, for $1\le j<N$, suffice.

3. Removing the distinct-type obstruction

Call a measure full-support if every nonempty open subinterval has positive value.

Finite-transcript perturbation lemma.
Given finitely many normalized, atomless, full-support measures $v_1,\ldots,v_\tau$ and a finite set $P\subseteq[0,1]$ containing $0,1$, there exist pairwise distinct measures $\widetilde v_1,\ldots,\widetilde v_\tau$ with the same properties such that
$$ \widetilde v_t([a,b])=v_t([a,b]) \qquad \text{for all }a,b\in P,\ a\le b. $$

Proof. Choose consecutive points $a<b$ of $P$. For a given measure $v_t$, continuity and full support provide $c\in(a,b)$ such that
$$ v_t([a,c])=v_t([c,b])=\frac12v_t([a,b])>0. $$
For $\lambda\in(-1,1)$, multiply the measure by $1+\lambda$ on $(a,c)$ and by $1-\lambda$ on $(c,b)$, leaving it unchanged elsewhere.

The two changes cancel, so normalization and the value of every interval with endpoints in $P$ are preserved. The multiplier is positive, preserving atomlessness and full support. Different $\lambda$ give different measures.

Choose the modified measures successively. At each step, only finitely many choices are forbidden by equality with previously chosen measures, whereas infinitely many choices are available. The resulting measures are pairwise distinct. $\square$

Now let a protocol be correct and bounded by $Q$ queries on distinct supported measures with fixed masses. Run its deterministic instructions on an arbitrary labeled family of full-support measures, allowing repetitions.

Every finite query transcript can be realized by distinct measures: apply the lemma with $P$ containing all query coordinates and CUT answers. EVAL answers are preserved. Full support makes valid CUT answers unique, and their defining equalities are preserved. Failed CUT queries remain failed because the remaining value to $1$ is preserved.

The run therefore cannot issue a $(Q+1)$st query. It also cannot enter a nonterminating computation after a finite transcript: the same transcript is realized on an admissible distinct instance, on which the computation must terminate.

At termination, include all output endpoints in $P$. The endpoint restriction makes this a finite set of previously available coordinates. Perturbation preserves every output-bundle value, as well as the output itself. Correctness on the distinct perturbed instance therefore proves correctness on the original labeled family.

Thus a bounded protocol for distinct types also works, with the same query bound, on labeled full-support measures that repeat. This is the extension needed below.

4. The published adversary used in the lower bound

I use the following property of Farhadi–Hajiaghayi’s balanced-value-tree adversary.

For a sufficiently large power of three $n$, its valuations are normalized, atomless, full-support, and have positive constant density on each of $n$ equal grid intervals, with density at most $2$. Put
$$ M(n)=\left\lfloor\frac{(\ln n)/6-1}{2}\right\rfloor. $$
The adversary maintains a realizable transcript for its first $M(n)$ queries. During this phase, an EVAL query whose endpoints lie strictly inside one grid interval reveals that interval and its density is less than $1/2$. This follows from the revealed-path invariant and the heavy-edge requirement for rich or critical leaves in Lemmas 4.5 and 4.7. [Farhadi–Hajiaghayi, Section 4](https://www.ijcai.org/proceedings/2018/0031.pdf)

After this phase, fix any consistent valuation and answer subsequent queries from it.

Independent copies of this adversary can be run on separate oracles. Interleaving queries does not change any copy’s local query count or invariant. Thus an interior EVAL query certifying grid-interval density at least $1/2$ requires more than $M(n)$ queries to that particular oracle.

This simultaneous adversary property is essential; a single-oracle worst-case lower bound alone would not justify summing lower bounds across adaptively selected types.

5. A lower bound for any subset of types

Fix a nonempty subset $H$ of type labels and write
$$ K=\sum_{t\in H}k_t, \qquad a=\max_{t\in H}k_t. $$
I prove
$$ Q^*(\mathbf{k})=\Omega\!\left(\frac Ka\log N\right). $$

It suffices to consider large $N$. Choose
$$ n=3^{\lfloor\log_3N\rfloor}, $$
so that $N/3<n\le N$ and $M(n)=\Omega(\log N)$.

For every $t\in H$, independently run the adversary of Section 4 on a valuation $w_t$. Let
$$ F_t(x)=w_t([0,x]), \qquad G_t=F_t^{-1}. $$
Full support and atomlessness make $F_t$ a continuous strictly increasing bijection.

Give the allocation protocol the valuation $u_t$ defined by
$$ u_t([x,y])=G_t(y)-G_t(x). $$
For $t\notin H$, give it the uniform valuation. These are all normalized, atomless, full-support measures. Repetitions are allowed by Section 3.

5.1 Simulating the allocation queries

An EVAL query to $u_t$ is answered using two CUT queries to $w_t$:
$$ u_t([x,y]) =\operatorname{CUT}_{w_t}(0,y) -\operatorname{CUT}_{w_t}(0,x). $$

For $\operatorname{CUT}_{u_t}(x,r)$, first obtain $z=G_t(x)$. If $z+r>1$, the query has no answer. Otherwise its answer is
$$ F_t(z+r)=\operatorname{EVAL}_{w_t}(0,z+r). $$
Indeed,
$$ u_t([x,F_t(z+r)]) =G_t(F_t(z+r))-G_t(x) =r. $$
Each allocation query therefore costs at most two underlying queries. Queries to uniform filler types require no underlying oracle calls.

Because $w_t([p,q])\le2(q-p)$,
$$ y-x =w_t([G_t(x),G_t(y)]) \le2\bigl(G_t(y)-G_t(x)\bigr). $$
Hence
$$ u_t([x,y])\ge\frac{y-x}{2}. $$
The same inequality holds for finite unions. Every permissible bundle belonging to a type in $H$ consequently has length at most $2/N$.

5.2 Many hard types receive a sufficiently long bundle

Uniform filler types collectively receive length at most
$$ \sum_{t\notin H}\frac{k_t}{N}=1-\frac KN. $$
Thus the $K$ bundles belonging to types in $H$ have total length at least $K/N$.

Let $\ell$ be the number of these bundles having length at least $1/(2N)$. Every hard bundle has length at most $2/N$, so
$$ \frac KN \le \frac{K-\ell}{2N}+\frac{2\ell}{N}. $$
Therefore $\ell\ge K/3$.

Each type has at most $a$ bundles. Consequently at least
$$ R\ge\frac{K}{3a} $$
different types in $H$ have a bundle of length at least $1/(2N)$. Select one such bundle for each of these types.

5.3 Extracting a dense grid interval

For a selected bundle $X$ owned by type $t$, map each interval $[p,q]$ of $X$ to
$$ [G_t(p),G_t(q)], $$
and call the resulting finite union $P$. Obtain its endpoints through CUT queries to $w_t$.

Strict monotonicity preserves disjointness of interval interiors, and
$$ |P|=u_t(X)\le\frac1N, \qquad w_t(P)=|X|\ge\frac1{2N}. $$
Thus $P$ has average density at least $1/2$. Some positive-length component $J$ of $P$ has density at least $1/2$.

These component densities are already known: if $J=[G_t(p),G_t(q)]$, then
$$ w_t(J)=q-p. $$

Since $|J|\le1/N\le1/n$, it intersects the interiors of at most two grid intervals. The density of $w_t$ is constant on each grid interval, so at least one intersected grid interval has density at least $1/2$. Query the middle third of each candidate grid interval. At least one answer certifies density at least $1/2$.

By Section 4, each of the $R$ selected underlying oracles has now received more than $M(n)$ queries.

5.4 Total query accounting

Suppose the allocation protocol uses $Q$ queries and obtains $r$ distinct interior CUT endpoints, with $r\le Q$. Its output can be represented, after discarding irrelevant isolated endpoints, by assigning each of the $r+1$ elementary open intervals to one bundle.

Therefore the total number $C$ of positive-length components across the selected bundles satisfies
$$ C\le r+1\le Q+1. $$
Also $R\le C$.

Simulating the allocation uses at most $2Q$ underlying queries. Mapping selected components costs at most $2C$ queries; testing candidate grid intervals costs at most $2R$. The total is at most
$$ 2Q+2C+2R\le6Q+4. $$
On the other hand, it is at least $R\,M(n)$. Hence
$$ 6Q+4 \ge R\,M(n) \ge\frac{K}{3a}M(n). $$
Since $M(n)=\Omega(\log N)$, this proves the claimed asymptotic lower bound.

Taking the maximum over $H$ and combining with the endpoint lower bound yields
$$ \boxed{ Q^*(\mathbf{k}) = \Omega\!\left(N+B(\mathbf{k})\log N\right). } $$
The finitely bounded range of smaller $N$ is covered by the endpoint bound, since $B(\mathbf{k})\le\tau\le N$ and $\log N$ is bounded in that range.

6. Consequences for unequal multiplicities

Taking $H$ to be all types gives
$$ B(\mathbf{k})\ge\frac{N}{k_{\max}}, \qquad k_{\max}=\max_t k_t. $$
Thus, whenever $k_{\max}\le C N/\tau$ for a fixed constant $C$,
$$ Q^*(\mathbf{k}) =\Omega(N+\tau\log N). $$
Together with the upper bound and $\log N\ge\log\tau$, this gives
$$ \boxed{ Q^*(\mathbf{k})=\Theta(N+\tau\log\tau). } $$
Equal multiplicities are included, but divisibility by $\tau$ is unnecessary.

There is also a stronger general lower bound than $\Omega(N)$. Put $A=N/\tau$. At least $\tau/2$ types satisfy $k_t\le2A$; otherwise their multiplicities alone would sum to more than $N$.

Partition these types into bins
$$ 2^j\le k_t<2^{j+1}. $$
There are at most
$$ d=1+\lfloor\log(2A)\rfloor $$
bins. One contains at least $\tau/(2d)$ types. Taking that bin as $H$ gives
$$ B(\mathbf{k})\ge\frac{\tau}{4d}. $$
Consequently,
$$ \boxed{ Q^*(\mathbf{k}) = \Omega\!\left( N+\frac{\tau\log N}{1+\log(N/\tau)} \right). } $$

In the previously unsettled regime $N<\tau\log\tau$, this implies, for sufficiently large $\tau$,
$$ Q^*(\mathbf{k}) = \Omega\!\left( N+\frac{\tau\log\tau}{1+\log\log\tau} \right). $$
Thus the remaining gap for arbitrary masses is at most a factor of order $1+\log\log\tau$.

7. Worst case over masses and the role of encoding

Without conditioning on exact $L$, balanced admissible masses establish the matching worst-case lower bound for every feasible pair $(N,\tau)$.

If arbitrary binary-encoded rational masses are allowed, choose positive integers $k_t$ differing by at most one and summing to $N$. Then
$$ k_{\max}=\left\lceil\frac N\tau\right\rceil \le\frac{2N}{\tau}, $$
so Section 6 applies.

For the next feasibility statement, interpret “binary-rational” as dyadic. Write
$$ N=2^a s, \qquad s\text{ odd}. $$
If $\mu_t$ is dyadic and $N\mu_t$ is integral, its reduced denominator divides $2^a$. Thus
$$ \ell_t=2^a\mu_t $$
is a positive integer, and $\sum_t\ell_t=2^a$. Feasibility therefore requires $\tau\le2^a$.

Conversely, whenever $\tau\le2^a$, choose positive integers $\ell_t$ differing by at most one and summing to $2^a$, and put
$$ \mu_t=\frac{\ell_t}{2^a}, \qquad k_t=s\ell_t. $$
These masses are admissible and satisfy
$$ k_{\max} =s\left\lceil\frac{2^a}{\tau}\right\rceil \le\frac{2N}{\tau}. $$
Thus under either interpretation,
$$ \boxed{ \text{worst case over admissible masses at fixed feasible }(N,\tau) = \Theta(N+\tau\log\tau). } $$

Under ordinary binary numerator/denominator encoding, these balanced descriptions have length $O(\tau\log N+\log N)$.

This does not establish the same lower bound for every prescribed exact value of $L$. The balanced descriptions need not belong to that exact-length input class. The fixed-vector bounds above remain valid for every admissible description, but matching lower bounds within every exact-length class have not been proved here.

8. What remains open

The uniform upper bound, the distinct-type repair, and the subset lower bound are proved. They settle every fixed mass vector with $N\ge\tau\log\tau$, every vector with bounded relative maximum multiplicity, and the worst case over masses at fixed feasible $(N,\tau)$.

Two questions remain:

  • Does every admissible multiplicity vector satisfy a worst-case lower bound $\Omega(N+\tau\log\tau)$, or can highly uneven masses permit a smaller bound?
  • With a specified rational encoding and exact description length $L$, what is the tight worst-case complexity within every feasible $(N,\tau,L)$ input class?
