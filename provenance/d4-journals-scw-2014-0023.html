Exact computation is polynomial-time solvable

The problem is solvable in time polynomial in \(m,\tau,L\). An algorithm using \(O(\tau^2)\) exact rational linear programs computes the allocations and a supporting flow.

The proof has three parts: a progressive allocation algorithm on the support, a polynomial bound on all intermediate rational numbers, and identification of the output with the egalitarian allocation in every replication.

1. The aggregate feasible polytope

Write \(T=\{1,\ldots,\tau\}\) and \(E=\{(s,t):s\in A_t\}\). Introduce per-person allocation variables \(q_t\) and aggregate flow variables \(x_{st}\) for \((s,t)\in E\).

Let \(P\) be the polytope defined by

  • \(0\le q_t\le c_t\) for every \(t\in T\);
  • \(x_{st}\ge0\) for every \((s,t)\in E\);
  • \(\sum_{s\in A_t}x_{st}=\mu_tq_t\) for every \(t\in T\);
  • \(\sum_{t:(s,t)\in E}x_{st}\le b_s\) for every \(s\in S\).

Flows outside \(E\) are understood to be zero.

The polytope \(P\) is nonempty because it contains the zero allocation and zero flow. It is compact: each \(q_t\) is bounded by \(c_t\), and each \(x_{st}\) is bounded by \(b_s\). Its dimension and rational description length are polynomial in \(m,\tau,L\).

2. A progressive algorithm on the support

Initially every type is active. Previously frozen types retain their assigned allocations.

At round \(k\), let \(I_k\) be the nonempty set of active types. Solve the linear program that maximizes \(\lambda\), subject to

  • \((q,x)\in P\);
  • every previously frozen coordinate equals its assigned value;
  • \(q_t\ge\lambda\) for every \(t\in I_k\);
  • \(\lambda\ge0\).

Denote the optimum by \(\lambda_k\). Let \(F_k\) be the feasible set with these constraints and with \(\lambda=\lambda_k\).

For each \(t\in I_k\), solve another linear program:

\(h_{kt}=\max\{q_t:(q,x)\in F_k\}.\)

Define

\(D_k=\{t\in I_k:h_{kt}=\lambda_k\}.\)

Freeze every type in \(D_k\) at allocation \(\lambda_k\), remove \(D_k\) from the active set, and continue.

Every round freezes a type

All relevant maxima exist by compactness.

Suppose \(D_k\) were empty. For each \(t\in I_k\), there would be a point of \(F_k\) with \(q_t>\lambda_k\). Average these finitely many points. Every active coordinate of the average is strictly greater than \(\lambda_k\): its corresponding witness contributes a strict inequality, while every other witness contributes a weak inequality.

The average therefore permits a value of \(\lambda\) strictly greater than \(\lambda_k\), contradicting optimality. Thus \(D_k\ne\varnothing\).

Moreover, for every \(t\in D_k\), every point of \(F_k\) satisfies \(q_t=\lambda_k\): the lower bound is \(\lambda_k\), and its maximum is also \(\lambda_k\). Consequently, freezing these coordinates preserves feasibility.

Successive levels strictly increase

If types remain active after round \(k\), each remaining type has a witness in \(F_k\) with its allocation strictly greater than \(\lambda_k\). Averaging witnesses for the remaining types gives a point at which all remaining coordinates exceed \(\lambda_k\), while every coordinate in \(D_k\) equals \(\lambda_k\).

This point is feasible for the next round with a strictly larger lower bound. Hence

\(\lambda_{k+1}>\lambda_k.\)

The algorithm terminates after \(r\le\tau\) rounds. Its output satisfies

\(q_t=\lambda_k\quad\text{for }t\in D_k.\)

The sets \(D_1,\ldots,D_r\) partition \(T\). At the final round, all remaining coordinates are forced, so the resulting allocation has a supporting flow in \(P\).

The output is Pareto efficient in the aggregate polytope

Suppose \((u,z)\in P\) satisfied \(u_t\ge q_t\) for all types, with at least one strict inequality.

Choose the earliest round \(k\) containing a type \(t\in D_k\) with \(u_t>q_t\). Earlier frozen coordinates then agree with their assigned values. Every type active at round \(k\) satisfies

\(u_a\ge q_a\ge\lambda_k.\)

Thus \((u,z)\in F_k\). But \(t\in D_k\) forces \(u_t=\lambda_k=q_t\), a contradiction.

3. Polynomial bit complexity

A bound on the number of rounds alone does not establish polynomial running time. We must bound the encoding lengths of the computed levels.

We use the standard exact rational linear-programming theorem: a rational linear program can be solved, including recovery of an exact rational optimum and an optimal solution when the optimum is finite, in time polynomial in its description length.

The following argument gives a uniform polynomial bound on all \(\lambda_k\), without a recursive denominator estimate.

A polytope using only original coefficients

After the algorithm terminates, choose a representative \(d_k\in D_k\) for each group. Define \(P^\star\) by adding to \(P\) the constraints

\(q_t=q_{d_k}\quad(t\in D_k),\)

and

\(q_{d_1}\le q_{d_2}\le\cdots\le q_{d_r}.\)

These additional constraints have coefficients in \(\{-1,0,1\}\). In particular, their description contains none of the computed values \(\lambda_k\).

The output allocation and any supporting flow belong to \(P^\star\), so this polytope is nonempty and compact.

Consider successive lexicographic maximization of

\((q_{d_1},q_{d_2},\ldots,q_{d_r})\)

over \(P^\star\). Its successive optimal values are exactly \(\lambda_1,\ldots,\lambda_r\).

To prove this, suppose the earlier representative coordinates have already been fixed at \(\lambda_1,\ldots,\lambda_{k-1}\). Every type active at round \(k\) belongs to a group \(D_\ell\) with \(\ell\ge k\). The added equalities and inequalities imply

\(q_t=q_{d_\ell}\ge q_{d_k}.\)

Therefore any such point of \(P^\star\), with \(\lambda=q_{d_k}\), is feasible for the round-\(k\) linear program. It follows that \(q_{d_k}\le\lambda_k\). The algorithm’s final allocation attains equality and satisfies all earlier equalities. This proves the assertion inductively.

Each successive maximization restricts to a nonempty face. The final face consequently contains a vertex of \(P^\star\), and every point of that face has the algorithm’s allocation coordinates.

Determinant bounds

Let \(d=|E|+\tau\) be the number of variables. The rational coefficients and right-hand sides defining \(P^\star\) have encoding length polynomial in \(m,\tau,L\).

After clearing denominators row by row, the resulting integer coefficients have polynomial bit length. At a vertex, choose \(d\) linearly independent active equations. Cramer’s rule expresses every coordinate as a ratio of integer determinants.

If the integer entries have absolute value at most \(H\), these determinants have absolute value at most \(d!H^d\). Their bit lengths are therefore at most

\(O(d\log d+d\log H),\)

which is polynomial in \(m,\tau,L\).

The selected vertex contains every \(\lambda_k\) as a coordinate \(q_{d_k}\). Hence all allocation levels have uniformly polynomial encoding length.

Total running time

There are at most \(\tau\) level-maximization linear programs and at most \(\tau^2\) coordinate-maximization linear programs. Every one has polynomially many variables and constraints. Its fixed values are levels whose encoding lengths have just been bounded polynomially.

Thus every call, and every exact comparison \(h_{kt}=\lambda_k\), takes polynomial time. One final rational feasibility linear program with all \(q_t\) fixed returns a supporting aggregate flow of polynomial encoding length.

This proves polynomial bit complexity.

4. A direct finite-population uniqueness lemma

The finite uniqueness property is discussed in [Allocation rules on networks](https://repository.bilkent.edu.tr/bitstreams/6d10df45-ec38-44ab-beed-5a690158b4e7/download). For the condition stated in the question, the following direct proof makes identification of the algorithm’s output self-contained.

Consider a finite individual set \(C\), source capacities \(B_s\), and claims \(c_i\). Assume that every nonempty source set \(U\) satisfies

\(\sum_{s\in U}B_s<\sum_{i:A_i\cap U\ne\varnothing}c_i.\)

Every efficient allocation exhausts every source

Let \(y\) be efficient and let \(f\) support it. Suppose some source has unused capacity.

Construct a directed residual graph with:

  • an arc from source \(s\) to individual \(i\) for every access edge;
  • an arc from individual \(i\) to source \(s\) whenever \(f_{si}>0\).

Start from the source with unused capacity. If a reachable individual has \(y_i<c_i\), a sufficiently small augmentation along a simple directed path increases that individual’s allocation. Reverse arcs decrease positive transfers; forward arcs increase transfers. Intermediate allocations remain unchanged, and only the starting source uses additional capacity. This contradicts efficiency.

Thus every reachable individual is at their claim. Let \(U\) and \(D\) be the reachable sources and individuals. The forward arcs imply that \(D\) is exactly the set of individuals adjacent to \(U\). The reverse arcs imply that every positive transfer entering \(D\) originates in \(U\). Consequently,

\(\sum_{i\in D}c_i=\sum_{i\in D}y_i=\sum_{s\in U}\sum_i f_{si}\le\sum_{s\in U}B_s,\)

contradicting the shortage assumption.

Therefore every source is exhausted, and every efficient allocation has total \(\sum_s B_s\).

There is at most one efficient allocation satisfying the no-transfer condition

Let \(y\) be an efficient allocation satisfying that condition. Let \(z\) be any feasible allocation with the same total, and choose supporting flows \(f,g\).

Both flows exhaust all sources. Direct each positive flow difference as follows:

  • if \(f_{si}>g_{si}\), direct an arc from \(i\) to \(s\), carrying \(f_{si}-g_{si}\);
  • if \(g_{si}>f_{si}\), direct an arc from \(s\) to \(i\), carrying \(g_{si}-f_{si}\).

Every source has zero net imbalance. An individual has outgoing minus incoming difference \(y_i-z_i\).

The elementary flow-decomposition theorem therefore decomposes these differences into cycles and paths from individuals \(j\) with \(y_j>z_j\) to individuals \(i\) with \(z_i>y_i\). One can obtain this decomposition by adding a supersource at the positive imbalances and a supersink at the negative imbalances, then decomposing the resulting flow.

Each such path permits a sufficiently small transfer from \(j\) to \(i\) at the allocation \(y\). Its reverse arcs correspond to positive transfers in \(f\); intermediate allocations and source usages remain unchanged. Furthermore,

\(y_i<z_i\le c_i.\)

The no-transfer condition therefore implies \(y_j\le y_i\) for every decomposed path.

If a path carries amount \(\delta\), its contribution to \(\sum_i y_i(z_i-y_i)\) is \(\delta(y_i-y_j)\), which is nonnegative. Cycles contribute no endpoint imbalance. Hence

\(\sum_i y_i(z_i-y_i)\ge0.\)

It follows that

\(\sum_i z_i^2-\sum_i y_i^2=2\sum_i y_i(z_i-y_i)+\sum_i(z_i-y_i)^2>0\)

whenever \(z\ne y\).

Thus \(y\) uniquely minimizes the sum of squared allocations among feasible allocations of this total. Any other efficient allocation satisfying the no-transfer condition would also uniquely minimize the same objective, which is impossible. This proves uniqueness.

5. Agreement with every replication

Fix any admissible positive integer \(N\), and put \(n_t=N\mu_t\). By admissibility and positivity, every \(n_t\) is a positive integer.

The replicated graph is connected: replacing a supported type by vertices with the same nonempty neighborhood preserves connectivity. For every nonempty \(U\subseteq S\), its shortage inequality is

\(\sum_{s\in U}Nb_s<N\sum_{t:A_t\cap U\ne\varnothing}\mu_tc_t=\sum_{i:A_i\cap U\ne\varnothing}c_i.\)

Thus the finite uniqueness lemma applies.

Lifting and aggregating flows

Given the computed supporting flow \(x\), send \(x_{st}/\mu_t\) from source \(s\) to each individual of type \(t\). Each individual receives

\(\sum_s x_{st}/\mu_t=q_t.\)

The total use of source \(s\) is

\(\sum_t n_t x_{st}/\mu_t=N\sum_t x_{st}\le Nb_s.\)

Hence the uniform allocation is feasible.

Conversely, any feasible individual allocation \(y\), supported by transfers \(f\), yields a point of \(P\) by setting

\(\bar q_t=\frac{1}{N\mu_t}\sum_{i\text{ of type }t}y_i,\qquad \bar x_{st}=\frac1N\sum_{i\text{ of type }t}f_{si}.\)

Efficiency

A Pareto improvement of the lifted allocation would produce, by aggregation, \(\bar q_t\ge q_t\) for every type and a strict inequality for at least one type. This contradicts the aggregate efficiency proved in Section 2.

The no-transfer condition

Suppose a feasible positive transfer from individual \(j\) to individual \(i\) were possible, with

\(y_i=q_t<q_u=y_j,\)

where \(i\) has type \(t\) and \(j\) has type \(u\). They have different types because the lifted allocation is uniform within each type.

Let \(t\in D_k\), so \(q_t=\lambda_k\). Since \(q_u>\lambda_k\), type \(u\) was still active in round \(k\).

By convexity of finite feasibility, any sufficiently small positive portion \(\varepsilon\) of the proposed transfer is feasible. Choose it so that

\(q_u-\frac{\varepsilon}{N\mu_u}\ge\lambda_k.\)

After aggregation, only the two coordinates change:

\(\bar q_t=q_t+\frac{\varepsilon}{N\mu_t}>\lambda_k,\qquad \bar q_u=q_u-\frac{\varepsilon}{N\mu_u}\ge\lambda_k.\)

Earlier frozen coordinates remain fixed. Every other type active in round \(k\) retains its final allocation, which is at least \(\lambda_k\). The aggregated point therefore lies in \(F_k\), contradicting the fact that \(t\in D_k\) is forced to equal \(\lambda_k\) throughout \(F_k\).

The lifted allocation satisfies the required no-transfer condition. By finite uniqueness, it is exactly the replication’s egalitarian allocation.

Since \(N\) was arbitrary, the computed \(q_t\) agrees with every individual’s allocation in every admissible replication.

Conclusion

The exact support-encoded computation problem is polynomial-time solvable. The algorithm returns exact rational allocations and a supporting aggregate flow, with polynomially bounded output length and running time.
