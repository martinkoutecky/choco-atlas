The continuous mirror question, as graded

Given a finite type set \(T\), rational population distribution \(\mu\), utility and like data \(u_t(j), b_t(j)\), and an ordered stream of item blocks \((j_r,\lambda_r)\) with \(\lambda_r\) indivisible items per unit population, evolve fluid BALANCED LIKE using load distributions \(\nu_t(\ell)\), compute its egalitarian or utilitarian welfare and the offline optimum, and determine the exact ratio or whether it is bounded by a supplied constant \(c\).

Packaged proof task (what the prover saw — nothing else)

Definitions

An instance has a finite type set \(T\), rational masses \(\mu_t>0\) with \(\sum_t\mu_t=1\), sincere like indicators \(b_t(j)\in\{0,1\}\), rational utilities \(u_t(j)\geq0\), and ordered blocks \((j_r,\lambda_r)\) with rational copy densities \(\lambda_r\geq0\).
Let \(\nu_t(\ell)\) be the mass of type \(t\) currently holding \(\ell\) indivisible copies, initially \(\nu_t(0)=\mu_t\). In block \(r\), repeatedly allocate infinitesimal copy mass to the lowest-load persons with \(b_t(j_r)=1\), uniformly over that pool, moving each selected mass from load \(\ell\) to \(\ell+1\), until \(\lambda_r\) copies per unit population are allocated; discard a block if its like pool is empty.
Let \(V_t\) be the resulting expected utility mass of type \(t\). Define \(W_{\mathrm{util}}=\sum_tV_t\) and \(W_{\mathrm{egal}}=\min_t V_t/\mu_t\). The offline optimum \(W^*_{\star}\) maximizes the same objective over fractional allocations of every block's copy mass, for \(\star\in\{\mathrm{util},\mathrm{egal}\}\).
Define FLUID-BALANCED-LIKE-RATIO to ask, given rational \(c\) and an instance with positive mechanism welfare, whether \(W^*_{\star}/W_{\star}\leq c\).

Target

Is FLUID-BALANCED-LIKE-RATIO solvable in polynomial time, or is it NP-hard, for utilitarian welfare or for egalitarian welfare?

Nearest known results

For finite individual-agent instances with general utilities, BALANCED LIKE has no constant competitive ratio for either welfare objective, even with \(2\) agents.
For fixed-order discrete instances, exact-outcome computation for BALANCED LIKE is intractable in general but tractable with \(2\) agents; neither result treats type masses or copy densities.

Status and proved results

I do not settle the classification for an unrestricted number of types. I prove the following partial results for both welfare objectives:

  • Every type’s load distribution is supported on at most two consecutive integers. Consequently, one rational number per type suffices to simulate the mechanism exactly.
  • With at most two types, FLUID-BALANCED-LIKE-RATIO is solvable in polynomial time in the ordinary binary encoding model.
  • For an arbitrary number of types, both versions belong to \(\mathrm{P}^{\mathrm{PosSLP}}\), where \(\mathrm{PosSLP}\) asks whether an integer arithmetic circuit evaluates to a positive integer.

The distinction between polynomially many arithmetic operations and polynomial bit complexity is essential here.

1. A compact exact state

Write \(n=|T|\), and let \(R\) be the number of blocks. Define the current load mass of type \(t\) by

\(m_t=\sum_{\ell\geq 0}\ell\,\nu_t(\ell).\)

Thus \(m_t/\mu_t\) is its average load. Load mass and utility mass are different quantities.

Lemma 1: two consecutive loads suffice

After every block, the load distribution of each type is supported on at most two consecutive integers.

Proof. Initially, every type is supported at load zero.

Consider a block and assume the assertion holds before it. During this block, the mechanism completely processes successive lowest occupied load levels of the liking population, until it stops, possibly partway through one level, say \(k\).

At this stopping point:

  • People initially below load \(k\) have reached load \(k\), and some may have advanced to \(k+1\).
  • People initially at load \(k\) either remain there or advance to \(k+1\).
  • People initially above load \(k\) are unchanged.

A liking type initially supported on two consecutive levels therefore has three possibilities. Its support is entirely at or below \(k\), in which case its final support is contained in \(\{k,k+1\}\); its support is contained in \(\{k,k+1\}\), in which case that remains true; or its support is entirely above \(k\), in which case it is unchanged. Nonliking types are unchanged.

This proves the induction. \(\square\)

In particular, \(m_t\) determines the entire distribution. If

\(h_t=\lfloor m_t/\mu_t\rfloor,\qquad d_t=m_t-h_t\mu_t,\)

then

\(\nu_t(h_t)=\mu_t-d_t,\qquad \nu_t(h_t+1)=d_t.\)

When \(d_t=0\), the distribution is concentrated at \(h_t\).

2. An exact block-update formula

Consider a block with density \(\lambda>0\) and nonempty liking set \(S\). Blocks with zero density or empty liking set leave the state unchanged.

For a nonnegative integer \(k\), define

\(F(k)=\sum_{t\in S}(k\mu_t-m_t)_+,\)

where \(a_+=\max\{a,0\}\).

Lemma 2: the leveling cost

The copy mass needed to raise every liking person below load \(k\) to load \(k\) is exactly \(F(k)\).

Proof. For a type supported on consecutive integers, there are two cases.

If \(m_t\leq k\mu_t\), all its occupied loads are at most \(k\), so the required copy mass is \(k\mu_t-m_t\).

If \(m_t>k\mu_t\), its lowest occupied load is at least \(k\), so the required mass is zero.

Summing gives the assertion. \(\square\)

Choose the largest nonnegative integer \(k\) satisfying \(F(k)\leq\lambda\). This integer exists because \(F(0)=0\), and is finite because \(S\) is nonempty. It satisfies

\(F(k)\leq\lambda<F(k+1).\)

Define

\(q_t=\min\{\mu_t,\max\{0,(k+1)\mu_t-m_t\}\}\quad(t\in S),\)

\(M=\sum_{t\in S}q_t,\qquad \alpha=\dfrac{\lambda-F(k)}{M}.\)

After completing all levels below \(k\), the mass of type \(t\) at load \(k\) is exactly \(q_t\). Moreover,

\(M=F(k+1)-F(k)>0,\qquad 0\leq\alpha<1.\)

Uniform allocation within the load-\(k\) pool advances an \(\alpha\) fraction of every type’s mass in that pool. Indeed, while this pool is being depleted, each type loses mass in proportion to its current pool mass; hence all type proportions remain constant.

Consequently, the exact update is

\(m'_t=m_t+(k\mu_t-m_t)_++\alpha q_t\quad(t\in S),\)

and \(m'_t=m_t\) for \(t\notin S\).

Because each allocated copy increases load by one, its utility contribution is also determined:

\(V'_t=V_t+u_t(j_r)(m'_t-m_t).\)

These formulas simulate the specified fluid mechanism exactly.

Finding the stopping level efficiently

Let \(C=\sum_t m_t\) before the block, and let \(\mu_{\min}=\min_t\mu_t\). For every nonnegative integer \(K\),

\(F(K)\geq K\sum_{t\in S}\mu_t-\sum_{t\in S}m_t\geq K\mu_{\min}-C.\)

Therefore the integer

\(U=\left\lfloor\dfrac{C+\lambda}{\mu_{\min}}\right\rfloor+2\)

satisfies \(F(U)>\lambda\). Binary search between zero and \(U\) finds \(k\).

Crucially, \(C\) is simply the sum of densities of preceding blocks with nonempty liking sets. Thus \(C\), \(U\), and every tested integer have polynomial binary encoding length in the original input length \(L\).

Each evaluation of \(F\) uses \(O(n)\) arithmetic operations and comparisons. The entire simulation therefore uses polynomially many exact rational arithmetic operations and comparisons. This statement alone does not bound the lengths of the rationals produced.

3. The offline optima are polynomial-time computable

Under the stated definition, the offline allocation is unrestricted by the like indicators. Let \(x_{tr}\) be the mass of copies from block \(r\) assigned to type \(t\). Its constraints are

\(x_{tr}\geq0,\qquad \sum_t x_{tr}=\lambda_r.\)

There is no capacity constraint on a type’s total number of copies.

For utilitarian welfare, blocks optimize independently, giving

\(W^*_{\mathrm{util}}=\sum_r\lambda_r\max_{t\in T}u_t(j_r).\)

For egalitarian welfare, the optimum is the value of the rational linear program

\(\text{maximize }z,\)

subject to

\(x_{tr}\geq0,\qquad \sum_t x_{tr}=\lambda_r,\)

\(\sum_r u_t(j_r)x_{tr}\geq\mu_t z\quad(t\in T),\qquad z\geq0.\)

These constraints express exactly the requirement that every type have average utility at least \(z\).

This linear program has polynomial size and rational input coefficients. It is feasible by assigning every block arbitrarily and taking \(z=0\). Its objective is bounded: for any fixed type \(t\),

\(z\leq \dfrac{\sum_r u_t(j_r)\lambda_r}{\mu_t}.\)

Thus exact polynomial-time rational linear programming applies, and the optimum has polynomial encoding length. The exact-solvability theorem used here is standard; see also [Dadush, Natura, and Végh’s treatment of exact linear programming](https://arxiv.org/abs/2009.04942).

Since mechanism welfare is promised positive, the target comparison is equivalent to

\(W^*_\star\leq cW_\star.\)

It remains to compute or compare the mechanism welfare.

4. Polynomial time with at most two types

Theorem 3

For instances with at most two types, both welfare-ratio problems are solvable in polynomial time in the binary input length.

Proof. One type is immediate: every nonempty liking block assigns its entire density to that type.

Now suppose there are two types, of masses

\(\mu_1=p,\qquad \mu_2=1-p,\qquad 0<p<1.\)

Before a block, write

\(m_1=x,\qquad m_2=y=C-x.\)

As established above, \(C\) is known directly from the input prefix and has polynomial encoding length.

A block liked by only type one sends \(x\) to \(x+\lambda\). A block liked by only type two leaves \(x\) unchanged. Empty liking sets have no effect.

Consider a block liked by both types, with \(\lambda>0\), and compute its stopping level \(k\) as in Section 2. We show that every possible update is fractional-linear in \(x\), with coefficients of polynomial encoding length.

Define \(q_1,q_2\) by the block formula.

Case 1: one final-pool mass is zero

If \(q_2=0\), then \(y\geq(k+1)(1-p)\). Type two has no population below or at the final processed level, and receives no copies during this block. Hence

\(x'=x+\lambda.\)

Similarly, \(q_1=0\) implies \(x'=x\).

Both cannot vanish because \(q_1+q_2>0\).

For the remaining cases, both final-pool masses are positive.

Case 2: both types are entirely at or below \(k\)

Here

\(x\leq kp,\qquad y\leq k(1-p).\)

Then

\(F(k)=k-C,\qquad q_1=p,\qquad q_2=1-p.\)

The block formula gives

\(x'=p(k+\lambda-F(k))=p(C+\lambda).\)

Case 3: both types have average load strictly between \(k\) and \(k+1\)

Here

\(kp<x<(k+1)p,\qquad k(1-p)<y<(k+1)(1-p).\)

Therefore

\(F(k)=0,\qquad q_1=(k+1)p-x,\qquad q_1+q_2=k+1-C.\)

It follows that

\(x'=x+\lambda\dfrac{(k+1)p-x}{k+1-C}.\)

This is affine in \(x\), since \(C\) is an input-prefix quantity.

Case 4: one type is at or below \(k\), and the other straddles \(k\)

Suppose first that

\(x\leq kp,\qquad k(1-p)<y<(k+1)(1-p).\)

Then

\(F(k)=kp-x,\qquad q_1=p,\qquad q_2=(k+1)(1-p)-C+x.\)

Consequently,

\(x'=p\left(k+\dfrac{\lambda-kp+x}{p+(k+1)(1-p)-C+x}\right).\)

This is fractional-linear in \(x\). Its denominator is \(q_1+q_2>0\).

If type two is the lower type, exchange the type labels, apply the same formula to \(y=C-x\), and recover

\(x'=C+\lambda-y'.\)

Substitution and subtraction preserve fractional-linearity.

These cases are exhaustive: when \(q_t>0\), either \(m_t\leq k\mu_t\) or \(k\mu_t<m_t<(k+1)\mu_t\).

Bit-length bound

Every update therefore has the form

\(x'=\dfrac{ax+b}{dx+e},\)

with a nonzero denominator at the current state. The rational coefficients depend only on \(p,C,\lambda,k\), so their encoding lengths are bounded by a polynomial in \(L\).

Clear the four coefficient denominators simultaneously. This gives integer coefficients \(a,b,d,e\), still of polynomial bit length.

If \(x=N/D\), we may represent the updated value by

\(N'=aN+bD,\qquad D'=dN+eD.\)

If \(N,D\) have at most \(B\) bits and the coefficients have at most \(H\) bits, then \(N',D'\) have at most \(B+H+O(1)\) bits. Reducing the fraction cannot increase these bounds.

Thus each block increases the necessary bit length by at most a polynomial in \(L\). There are at most \(L\) explicitly listed blocks, so every state value has polynomial bit length.

All binary searches and case comparisons consequently take polynomial time. Utility masses are sums of polynomially many products of polynomial-bit rationals, and therefore also have polynomial encoding length.

Finally, compute the appropriate offline optimum using Section 3 and compare it with \(cW_\star\). This proves the theorem. \(\square\)

5. An arithmetic-circuit upper bound for arbitrary types

Define \(\mathrm{PosSLP}\) as follows: the input is a directed acyclic arithmetic circuit with constants zero and one and operations addition, subtraction, and multiplication; the question is whether its integer output is strictly positive.

Theorem 4

For an arbitrary number of types, both welfare-ratio problems belong to \(\mathrm{P}^{\mathrm{PosSLP}}\).

Proof. Run the simulation of Section 2, representing each rational by two integer circuits for its numerator and positive denominator.

Every rational arithmetic operation adds only constantly many integer-circuit gates. For example,

\(\dfrac{A}{B}+\dfrac{D}{E}=\dfrac{AE+BD}{BE}.\)

All divisions needed in the state update are by positive quantities, so positive denominators can be maintained.

A comparison is an integer-circuit sign question:

\(\dfrac{A}{B}>\dfrac{D}{E}\quad\Longleftrightarrow\quad AE-BD>0,\qquad B,E>0.\)

Thus \(\mathrm{PosSLP}\) queries implement every comparison, including those used for positive parts, minima, and binary search. Non-strict comparisons follow by negating the corresponding strict comparison.

Input integers of polynomial bit length can be constructed with polynomially many gates using binary expansion. Previously constructed circuit nodes are shared, rather than copied.

The simulation uses polynomially many arithmetic operations and comparisons, and all binary-search integers have polynomial bit length. Hence its circuits and oracle queries have polynomial size.

Accumulate utility masses by the same circuit operations. For egalitarian welfare, find the minimum of \(V_t/\mu_t\) using circuit comparisons. Compute the offline optimum in polynomial time as in Section 3, and perform the final comparison \(W^*_\star\leq cW_\star\) with the oracle. \(\square\)

6. What remains open in this argument

The compact state representation removes the apparent difficulty caused by potentially enormous load levels. It does not establish polynomial bit complexity for arbitrary numbers of types.

For more than two types, the final-pool denominator

\(M=\sum_{t\in S}\min\{\mu_t,\max\{0,(k+1)\mu_t-m_t\}\}\)

can depend on several evolving state coordinates. The two-type fractional-linear argument does not supply a bit-length bound in that setting.

Accordingly, the unrestricted classification remains unsettled here for both objectives. A complete resolution would require a polynomial-time comparison method exploiting additional structure, or a valid hardness reduction. Neither follows from the discrete BALANCED LIKE results given in the question.
