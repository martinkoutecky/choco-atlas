The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu\in\Delta(T)\), rational nonnegative valuations \(v_{t,r}\), and fixed \(B\), let \(\mathcal A_B=\{a\in\mathbb Z_{\ge0}^{T}:1\le |a|\le B\}\) and \(u_t(a)=\frac{\sum_r(a_r-\mathbf 1[r=t])v_{t,r}}{|a|}\). Definitions. An instance has a finite type set \(T\), rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), nonnegative rational valuations \(v_{t,t'}\), and \(r\in\mathbb N\). Let \(\mathcal Z_r=\{z\in\mathbb N^{|T|}:1\le\lVert z Vert_1\le r\}\) and \(u_t(z)=(\sum_{t'}z_{t'}v_{t,t'}-v_{t,t})/\lVert z Vert_1\).

A structure is \(w\in\mathbb R_{\ge0}^{\mathcal Z_r}\) with \(\sum_z w_z=1\) and \(\sum_z w_z z_t/\lVert z Vert_1=\mu_t\) for every \(t\). For structures \(w,w'\), a type-preserving coupling is \(a_{t,z,z'}\ge0\) whose marginals are \(\sum_{z'}a_{t,z,z'}=w_z z_t/\lVert z Vert_1\) and \(\sum_z a_{t,z,z'}=w'_{z'}z_t/\lVert z' Vert_1\). Structure \(w\) is popular if every feasible \(w'\) and every such \(a\) satisfy \(\sum_{t,z,z'}a_{t,z,z'}\operatorname{sgn}(u_t(z)-u_t(z'))\ge0\).

Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Complexity of Popular Continuous Structures

Status

The supplied premises do not currently justify either polynomial-time solvability or NP-hardness for the exact continuous problem. The finite-agent \(\Sigma_2^p\)-hardness result does not transfer directly: fractional structures introduce new popular solutions that need not correspond to discrete partitions.

Nevertheless, several rigorous conclusions follow:

  • For fixed \(r\), popularity of a given rational structure is decidable by linear programming.
  • For fixed \(r\), existence belongs to \(\mathrm{NP}\).
  • If any popular structure exists, then a popular vertex of the structure polytope exists; such a vertex uses at most \(|T|\) configurations.
  • A structure assigning three distinct utility levels to any positive-mass type cannot be popular.
  • A concrete three-type instance has no popular discrete matching but does have a popular continuous structure. Thus the nearest finite hardness theorem cannot be imported by simply making every agent a type.

1. Notation and the adversarial linear program

For \(z\in\mathcal Z_r\), define

\(\alpha_{t,z}=z_t/\lVert z\rVert_1\)

and

\(c_{t,z,z'}=\operatorname{sgn}(u_t(z)-u_t(z'))\).

Let \(W\) be the structure polytope

\(W=\{w\geq 0:\sum_z\alpha_{t,z}w_z=\mu_t\text{ for every }t\in T\}\).

The equation \(\sum_z w_z=1\) is redundant: summing the type equations and using \(\sum_t\alpha_{t,z}=1\) gives

\(\sum_z w_z=\sum_t\mu_t=1\).

Fix \(w\in W\). Consider the following linear program, whose variables are \(w'\) and \(a\):

\(\displaystyle g(w)=\min\sum_{t,z,z'}c_{t,z,z'}a_{t,z,z'}\),

subject to

\(\sum_{z'}a_{t,z,z'}=\alpha_{t,z}w_z\) for every \(t,z\),

\(\sum_z a_{t,z,z'}=\alpha_{t,z'}w'_{z'}\) for every \(t,z'\),

and \(a,w'\geq0\).

The column equations and the row equations imply that \(w'\in W\). Indeed,

\(\sum_{z'}\alpha_{t,z'}w'_{z'}=\sum_{z,z'}a_{t,z,z'}=\sum_z\alpha_{t,z}w_z=\mu_t\).

The feasible set is nonempty: take \(w'=w\) and the diagonal coupling

\(a_{t,z,z}=\alpha_{t,z}w_z\).

It is compact because the total mass of \(a\) is \(\sum_t\mu_t=1\), while \(w'\) is a probability vector. Thus the minimum is attained.

By definition,

\(w\) is popular if and only if \(g(w)\geq0\).

The diagonal coupling has value \(0\), so \(g(w)\leq0\) for every \(w\). Consequently,

\(w\) is popular if and only if \(g(w)=0\).

This gives a polynomial-time popularity test whenever \(\mathcal Z_r\) is explicitly enumerable: the linear program has \(O(|T||\mathcal Z_r|^2)\) coupling variables.

2. Convexity and purification to a vertex

Proposition 1

The function \(g:W\to\mathbb R\) is convex.

Proof

Let \(w^1,w^2\in W\), let \(0\leq\lambda\leq1\), and choose optimal adversaries \((w'^1,a^1)\) and \((w'^2,a^2)\).

Set

\(w=\lambda w^1+(1-\lambda)w^2\),

\(w'=\lambda w'^1+(1-\lambda)w'^2\),

and

\(a=\lambda a^1+(1-\lambda)a^2\).

All coupling equations are linear, so \((w',a)\) is feasible against \(w\). Its objective value is

\(\lambda g(w^1)+(1-\lambda)g(w^2)\).

Since \(g(w)\) is the minimum over all adversaries,

\(g(w)\leq\lambda g(w^1)+(1-\lambda)g(w^2)\).

This is convexity. \(\square\)

Proposition 2

If a popular structure exists, then a popular vertex of \(W\) exists.

Proof

Let \(w\) be popular and write it as a convex combination of vertices,

\(w=\sum_{i=1}^k\lambda_i v^i\),

where \(\lambda_i>0\) and \(\sum_i\lambda_i=1\).

By Proposition 1,

\(0=g(w)\leq\sum_i\lambda_i g(v^i)\).

On the other hand, \(g(v^i)\leq0\) for every \(i\). Therefore

\(0\leq\sum_i\lambda_i g(v^i)\leq0\).

Hence \(g(v^i)=0\) for every \(i\) with \(\lambda_i>0\). Each such \(v^i\) is popular. \(\square\)

Corollary 3

A popular structure, if one exists, can be chosen with support size at most \(|T|\).

Proof

The polytope \(W\) is defined by \(|T|\) equality constraints and nonnegativity. Every vertex therefore has at most \(\operatorname{rank}(\alpha)\leq|T|\) positive coordinates. Apply Proposition 2. \(\square\)

3. Complexity consequence for fixed \(r\)

The number of configurations is

\(|\mathcal Z_r|=\binom{|T|+r}{r}-1\).

For every fixed \(r\), this is polynomial in \(|T|\).

Proposition 4

For every fixed \(r\), deciding whether a popular continuous structure exists belongs to \(\mathrm{NP}\).

Proof

If the answer is positive, Corollary 3 supplies a popular vertex \(w\) with at most \(|T|\) positive entries.

The constraint matrix defining \(W\) is rational. Standard determinant bounds for rational linear systems imply that every vertex has encoding length polynomial in the encoding length of the explicitly expanded matrix. Thus \(w\) is a polynomial-size certificate.

A verifier checks \(w\in W\) and then solves the adversarial linear program from Section 1. Since \(r\) is fixed, \(|\mathcal Z_r|\) is polynomial, and the verification runs in polynomial time. \(\square\)

This rules out importing the supplied \(\Sigma_2^p\)-hardness proof as a direct fixed-\(r\) reduction unless the polynomial hierarchy collapses. It does not distinguish between polynomial time and NP-hardness.

For variable succinctly encoded \(r\), Proposition 4 does not give an \(\mathrm{NP}\) upper bound: \(|\mathcal Z_r|\) can be exponential even when \(r\) is unary, for example when \(r=|T|\). An implicit separation or pricing algorithm would still be needed.

4. Exact obstruction from self-couplings

For a structure \(w\) and type \(t\), define the utility support

\(U_t(w)=\{u_t(z):\alpha_{t,z}w_z>0\}\).

Proposition 5

A structure \(w\) survives every coupling from \(w\) to itself if and only if \(|U_t(w)|\leq2\) for every \(t\in T\). In particular, every popular structure satisfies this condition.

Proof: necessity

Suppose some type \(t\) encounters configurations \(z_1,z_2,z_3\) of positive incidence mass with

\(u_t(z_1)<u_t(z_2)<u_t(z_3)\).

Start with the diagonal coupling from \(w\) to itself. Let

\(\varepsilon=\min_{i\in\{1,2,3\}}\alpha_{t,z_i}w_{z_i}>0\).

Remove mass \(\varepsilon\) from each of the three diagonal entries and insert

\(a_{t,z_1,z_2}=\varepsilon\),

\(a_{t,z_2,z_3}=\varepsilon\),

and

\(a_{t,z_3,z_1}=\varepsilon\).

This cyclic modification preserves every row and column marginal. Its contribution is

\(\varepsilon(-1-1+1)=-\varepsilon\).

Keep all other types diagonally coupled. The resulting type-preserving self-coupling has negative total margin, so \(w\) is not popular.

Proof: sufficiency for self-comparisons

Suppose a type has only two utility levels \(L<H\). Aggregate an arbitrary self-coupling by utility level. Let \(F_{L,H}\) be the mass sent from \(L\) to \(H\), and define \(F_{H,L}\) analogously.

Because the source and target distributions are identical, conservation of the mass at level \(L\) gives

\(F_{L,H}=F_{H,L}\).

All equal-level movements contribute \(0\), while the two cross-level movements contribute

\(-F_{L,H}+F_{H,L}=0\).

The same argument applies independently to every type. Thus every self-coupling has total value \(0\). \(\square\)

This is a strong restriction: fractional mixing does not allow a popular structure to spread any type over three strictly different utility levels.

5. A polynomially checkable sufficient condition

For each type \(t\), let

\(M_t=\max\{u_t(z):z_t>0,\ z\in\mathcal Z_r\}\),

and define

\(\mathcal Z^\star=\{z\in\mathcal Z_r:u_t(z)=M_t\text{ for every }t\text{ with }z_t>0\}\).

Proposition 6

If there is a feasible structure supported on \(\mathcal Z^\star\), then it is popular.

Proof

Fix such a structure \(w\), any challenger \(w'\), and any type-preserving coupling \(a\). Whenever \(a_{t,z,z'}>0\), the source configuration satisfies \(u_t(z)=M_t\), while \(u_t(z')\leq M_t\). Hence

\(\operatorname{sgn}(u_t(z)-u_t(z'))\geq0\).

Every summand in the popularity margin is nonnegative. \(\square\)

For explicitly enumerable \(\mathcal Z_r\), the existence of such a structure is an ordinary linear feasibility problem.

Two immediate completely resolved cases are:

  • If \(r=1\), the structure is unique and popular.
  • If \(|T|=1\), placing all mass on \(r e_t\) is popular, because \(u_t(k e_t)=v_{t,t}(1-1/k)\) is nondecreasing in \(k\).

6. Why the finite-agent hardness does not transfer directly

Consider \(T=\{a,b,c\}\), masses \(\mu_a=\mu_b=\mu_c=1/3\), and \(r=2\). Let diagonal valuations be \(0\), and let

\(v_{a,b}=v_{b,c}=v_{c,a}=2\),

\(v_{a,c}=v_{b,a}=v_{c,b}=1\).

Thus each type has a cyclic strict ranking: \(a\) prefers \(b\) to \(c\), \(b\) prefers \(c\) to \(a\), and \(c\) prefers \(a\) to \(b\).

Define

\(w_{e_a+e_b}=w_{e_b+e_c}=w_{e_c+e_a}=1/3\),

with all other coordinates zero. Each type receives incidence mass \(1/6+1/6=1/3\), so this is feasible.

Proposition 7

The structure \(w\) is popular.

Proof

Normalize each type’s incidence distribution to total mass \(1\). Under \(w\), every type receives its top partner with probability \(1/2\) and its second partner with probability \(1/2\).

For an arbitrary challenger \(w'\), define

\(x_{ab}=3w'_{e_a+e_b}/2\),

\(x_{bc}=3w'_{e_b+e_c}/2\),

\(x_{ca}=3w'_{e_c+e_a}/2\),

and let \(s_i\) be the normalized mass of type \(i\) assigned to either \(e_i\) or \(2e_i\). These two configurations both give utility \(0\). Feasibility gives

\(x_{ab}+x_{ca}+s_a=1\),

\(x_{ab}+x_{bc}+s_b=1\),

\(x_{bc}+x_{ca}+s_c=1\).

For a type whose target distribution assigns mass \(h\) to its top choice and mass \(s\) to utility \(0\), direct solution of the two-by-three transportation problem gives minimum normalized margin

\(d(h,s)=\max\{1/2,s\}-h\).

For \(a,b,c\), the top-choice masses are respectively \(x_{ab},x_{bc},x_{ca}\). Put

\(E=x_{ab}+x_{bc}+x_{ca}\)

and

\(S=s_a+s_b+s_c\).

Summing the three feasibility equations gives

\(2E+S=3\).

Therefore the minimum total normalized margin is

\(\sum_i\max\{1/2,s_i\}-E\)

\(=\sum_i(\max\{1/2,s_i\}+s_i/2)-3/2\)

\(\geq0\),

because each summand is at least \(1/2\). Restoring the common factor \(1/3\) does not change the sign. Thus every challenger and every coupling have nonnegative margin against \(w\). \(\square\)

In the corresponding discrete three-agent roommate instance, no popular matching exists: the three one-edge matchings defeat one another cyclically, and the all-singleton matching is defeated by every one-edge matching.

Hence a discrete no-instance can become a continuous yes-instance. This invalidates the most immediate reduction from the finite-agent hardness theorem, whose exact finite classification is documented in the [IJCAI paper](https://www.ijcai.org/proceedings/2025/419).

7. Conclusion and open classification

The exact dichotomy remains unresolved. What is proved here is:

  • For fixed \(r\), the problem is in \(\mathrm{NP}\).
  • Popularity verification is an LP problem once the configuration set is polynomially enumerable.
  • Existence reduces to maximizing the nonpositive convex function \(g\) over \(W\), with a popular solution corresponding exactly to a point where \(g=0\).
  • It suffices to search vertices, but convex maximization over a polytope is not generally a polynomial-time operation.
  • The finite-agent hardness construction cannot be transferred without a new purification gadget that excludes genuinely fractional popular vertices.

Thus neither a polynomial-time algorithm nor an NP-hardness proof is presently justified.

Claim-by-claim audit

1. Adversarial linear program

This section is correct.

  • Summing the type constraints indeed makes \(\sum_z w_z=1\) redundant because \(\sum_t\alpha_{t,z}=1\).
  • The row and column equations imply \(w'\in W\).
  • The diagonal self-coupling proves feasibility and has objective value \(0\).
  • The feasible region is bounded: both \(w'\) and \(a\) have total mass \(1\).
  • Consequently \(g(w)\leq0\), and popularity is equivalent to \(g(w)=0\).
  • When \(\mathcal Z_r\) is explicitly enumerable, the LP has polynomial size in the expanded instance.

No substantive gap occurs here.

2. Convexity and purification

Propositions 1 and 2 are correct.

The constructed convex combination of optimal adversaries is feasible against the convex combination of structures, giving

\(g(\lambda w^1+(1-\lambda)w^2)\leq\lambda g(w^1)+(1-\lambda)g(w^2)\),

which is the correct convexity inequality.

The vertex argument then correctly uses \(g(v)\leq0\) for every vertex. If a convex combination has value \(0\), convexity forces every positively weighted vertex in that decomposition to have value \(0\).

Corollary 3 is also correct: a vertex of \(\{w\geq0:Aw=\mu\}\) has at most \(\operatorname{rank}(A)\leq |T|\) positive coordinates.

3. Fixed-\(r\) NP membership

The count

\(\lvert\mathcal Z_r\rvert=\binom{|T|+r}{r}-1\)

is correct. Hence it is polynomial in \(|T|\) for every fixed \(r\).

The NP-membership argument is sound in substance, but the bit-complexity step is cited too vaguely. The write-up should state the precise standard fact being invoked: vertices of a rational polyhedron described by a polynomial-size rational matrix have rational coordinates of polynomial encoding length. It should also say explicitly that the adversarial LP can be compared exactly with \(0\) in polynomial bit complexity. These are routine clarifications and do not require new mathematics.

The observation about variable unary-encoded \(r\) is correct: when \(r=|T|\), the configuration count is exponential.

4. Self-coupling obstruction

Proposition 5 is correct.

  • With three strictly ordered utility levels, the proposed three-cycle preserves all row and column marginals and contributes \(-\varepsilon\).
  • With at most two utility levels, equality of source and target distributions forces the mass crossing from low to high to equal the mass crossing from high to low. Their signed contributions cancel.

This proves exactly the stated characterization for self-couplings and gives a valid necessary condition for popularity.

5. Maximum-utility sufficient condition

Proposition 6 is correct. If \(a_{t,z,z'}>0\), the column marginal implies \(z'_t>0\), so \(u_t(z')\leq M_t\). This implication is not written explicitly, but it is immediate.

The cases \(r=1\) and \(|T|=1\) are also correct under the conventional assumption \(r\geq1\).

6. Continuous three-type example

The continuous popularity calculation is correct in substance.

For a fixed type, normalized source mass is split equally between its top and second utility levels. Rechecking the corresponding \(2\)-by-\(3\) transportation problem confirms

\(d(h,s)=\max\{1/2,s\}-h\)

on the domain \(h\geq0\), \(s\geq0\), and \(h+s\leq1\). The identity \(2E+S=3\) and the final nonnegativity calculation are also correct.

However, two routine details should be supplied:

  • Define explicitly \(s_i=3(w'_{e_i}+w'_{2e_i})\).
  • Show the transportation calculation yielding \(d(h,s)\), and state that minimization separates across types once \(w'\) is fixed.

Because this is a small finite calculation and the asserted formula is correct, the omission is minor.

7. Claimed implication for finite-agent hardness

This inference is not established.

The cited theorem concerns unrestricted fractional hedonic games, where every nonempty subset can be a coalition; this is also how the cited paper defines the model. The paper expressly distinguishes general coalition formation from matching problems ([IJCAI paper](https://www.ijcai.org/proceedings/2025/0419.pdf)).

The prover’s example instead fixes \(r=2\) and proves only that the corresponding roommate matching instance has no popular matching. It is not a no-instance of the unrestricted three-agent fractional hedonic game. Indeed, if the grand coalition \(\{a,b,c\}\) is permitted, every agent receives utility \((2+1)/3=1\). Against any one-edge partition, one endpoint may tie, while the other endpoint and the singleton strictly prefer the grand coalition. Thus the grand coalition is popular.

Therefore the example shows that the continuous relaxation differs from a size-\(2\) matching model, but it does not by itself invalidate a direct translation of the supplied unrestricted FHG hardness construction. To justify that broader conclusion, the prover would need either:

  • a no-instance from the same unrestricted finite FHG domain whose continuous translation is a yes-instance, or
  • a proof that the cited hardness theorem remains valid under the same coalition-size restriction.

The still stronger assertion that any transfer “cannot” work without a particular purification gadget is likewise unsupported.
