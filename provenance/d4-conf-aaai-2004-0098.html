The continuous mirror question, as graded

Given Boolean variables \(V\), a finite support \(T\) of conditional preference theories \(\Gamma_t\) with rational masses \(\mu_t\) summing to \(1\), and acyclic \(G(\Gamma_t)\) for every type, compute \(M=\sum_{t:\,\Gamma_t\text{ is consistent}}\mu_t\), or decide whether \(M\ge q\) for a given rational threshold \(q\).

Packaged proof task (what the prover saw — nothing else)

Let \(V\) contain \(m\) Boolean variables, with outcomes \(\{0,1\}^{V}\). A theory \(\Gamma\) is an explicitly listed finite set of statements \(u:x>x'[W]\), where \(u\) assigns \(U\subseteq V\), \(X\in V\setminus U\), \(x,x'\in\{0,1\}\) are distinct values of \(X\), and \(W\subseteq V\setminus(U\cup\{X\})\).
Such a statement requires every outcome satisfying \(u\) and \(X=x\) to precede every outcome satisfying \(u\) and \(X=x'\) that agrees with it outside \(W\cup\{X\}\). A theory is consistent if some strict total order on outcomes satisfies all its statements; empty theories and incomplete preferences are allowed.
Define \(G(\Gamma)\) by adding edges \(Y\to X\) for every \(Y\in U\), and \(X\to Z\) for every \(Z\in W\), for each statement. Promise that \(G(\Gamma_t)\) is acyclic for every supported type.
A society is given by its support: the list \(T\) of the \(\tau\) types with positive mass, each with its mass \(\mu_t\) as a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Given also a binary rational \(q\in[0,1]\), define \(M=\sum_{t\in T:\,\Gamma_t\text{ consistent}}\mu_t\). Let \(L\) be the total input bit length, including the explicitly listed theories, masses, and threshold; state running times in \(m,\tau,L\).

Is deciding whether \(M\ge q\) in \(\mathrm{P}\) or \(\mathrm{NP}\)-hard, and can \(M\) be computed exactly in polynomial time?

Known discrete result: with acyclic \(G(\Gamma)\), consistency is equivalent to local consistency: for every outcome and variable, the value comparisons whose conditions that outcome satisfies form an acyclic relation. For Boolean variables, local consistency can be checked in time \(O(|\Gamma|^2m)\).
The established result concerns individual theories; it does not state a complexity result for the distributional mass problem.

Modeling choices made when packaging the task

  • The theory encoding was unspecified; each theory is represented by an explicit finite list of statements, matching the discrete representation.
  • The threshold domain was unspecified; take q in [0,1], matching the normalized mass domain.
  • Define m as the number of Boolean variables and L as the total input bit length, including theory descriptions and rational data.
  • Do not impose local consistency as an input promise: the discrete definition allows arbitrary theories, including empty theories and incomplete preferences.

Conclusion

The decision problem is in \(\mathrm{P}\), and \(M\) can be computed exactly in polynomial time. The crucial premise is that the support is explicitly listed: only the \(\tau\) supplied theories need to be checked.

1. Checking each supported theory

Write \(n_t=|\Gamma_t|\). We use the supplied theorem: because \(G(\Gamma_t)\) is acyclic, \(\Gamma_t\) is consistent exactly when it is locally consistent.

For Boolean variables, local inconsistency has a concrete witness: two statements about the same variable \(X\), with opposite preferences, whose conditions are compatible.

To justify this characterization:

  • A relation consisting of comparisons between the two values \(\{0,1\}\) is cyclic exactly when it contains both \(0>1\) and \(1>0\).
  • Thus local inconsistency at an outcome means that two statements impose these opposite comparisons and that the outcome satisfies both conditions.
  • Two partial Boolean assignments \(u_i,u_j\) have a common satisfying outcome exactly when they agree on every variable in \(U_i\cap U_j\). Indeed, agreement makes their union a partial assignment, which can be extended arbitrarily to all remaining variables.

Consequently, examine every pair of statements in \(\Gamma_t\). Reject the theory if a pair concerns the same variable, specifies opposite comparisons, and has compatible conditions. Otherwise accept it. By the supplied theorem and the preceding characterization, this procedure decides consistency.

The supplied running-time bound gives total consistency-checking time
\[ O\!\left(m\sum_{t\in T}n_t^2\right). \]

The sets \(W\) need not enter this local test; their effect is covered by the promised acyclicity and the supplied equivalence theorem.

2. Computing the mass exactly

Represent the input rationals as
\[ \mu_t=\frac{p_t}{d_t}, \qquad q=\frac{a}{b}, \]
with nonnegative numerators and positive denominators. This also covers dyadic binary rationals.

Let \(c_t\in\{0,1\}\) indicate whether the consistency test accepts \(\Gamma_t\). Define the common denominator
\[ D=b\prod_{t\in T}d_t \]
and integers
\[ N=\sum_{t\in T}c_t p_t\frac{D}{d_t}, \qquad Q=a\frac{D}{b}. \]
Every displayed division is exact. Direct substitution gives
\[ M=\frac{N}{D}, \qquad M\ge q\quad\Longleftrightarrow\quad N\ge Q. \]
Thus the algorithm outputs \(N/D\) as the exact mass and compares two integers to answer the decision question. If a reduced fraction is required, divide \(N,D\) by their greatest common divisor.

The bit length of \(D\) is at most
\[ 1+\log_2 b+\sum_{t\in T}\log_2 d_t=O(L). \]
Moreover, nonnegativity, the normalization of the masses, and the threshold bounds imply
\[ 0\le N\le D, \qquad 0\le Q\le D. \]
Each summand and partial sum used to construct \(N\) is likewise at most \(D\). Therefore all arithmetic uses integers with \(O(L)\) bits. Schoolbook multiplication and division give an arithmetic bound of \(O((\tau+1)L^2)\) bit operations; fraction reduction is also polynomial-time.

3. Overall complexity

Combining the supplied consistency bound with exact arithmetic gives
\[ O\!\left( L+m\sum_{t\in T}n_t^2+(\tau+1)L^2 \right). \]

For a bound polynomial solely in the input length, discard variables occurring in no statement and relabel the remaining variables. This preserves local consistency: every assignment to the occurring variables extends to an outcome, and absent variables receive no comparisons. It also preserves acyclicity, so the supplied theorem still applies.

At most \(\min\{m,L\}\) variables occur, and \(\sum_t n_t\le L\). Including polynomial-time relabeling, the resulting bound is
\[ O\!\left((\min\{m,L\}+\tau+1)L^2\right) \subseteq O(L^3). \]

Hence both exact mass computation and threshold decision are polynomial-time. In particular, the decision problem could be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).
