The continuous mirror question, as graded

Given finite agent types \(T\) with rational masses \(\mu_t\), repeated item classes \(J\) with rational per-capita supplies \(\sigma_j\), a finite deletion-closed bundle catalogue \(\mathcal B\), and valuations \(v_t(B)\in\{0,-1\}\), find or decide existence of nonnegative masses \(y_{t,B}\) satisfying \(\sum_B y_{t,B}=\mu_t\) and \(\sum_{t,B}y_{t,B}B_j=\sigma_j\), such that whenever \(y_{t,B}>0\), \(y_{u,D}>0\), and \(v_t(B)<v_t(D)\), either some \(j\) with \(B_j>0\) satisfies \(v_t(B-\mathbf e_j)\ge v_t(D)\), or some \(j\) with \(D_j>0\) satisfies \(v_t(B)\ge v_t(D-\mathbf e_j)\).

Packaged proof task (what the prover saw — nothing else)

Let \(J=\{1,\ldots,m\}\) be item classes. A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types.
The input also gives nonnegative binary-rational per-capita supplies \(\sigma_j\), a nonempty explicitly listed catalogue \(\mathcal B\subseteq\mathbb Z_{\ge0}^m\), and explicit valuation tables \(v_t:\mathcal B\to\{0,-1\}\) with \(v_t(\mathbf0)=0\). Bundle coordinates are binary encoded; deletion closure means \(B-\mathbf e_j\in\mathcal B\) whenever \(B\in\mathcal B\) and \(B_j>0\), where \(\mathbf e_j\) is the unit vector for class \(j\).
An allocation consists of real masses \(y_{t,B}\ge0\) satisfying \(\sum_{B\in\mathcal B}y_{t,B}=\mu_t\) and \(\sum_{t\in T,B\in\mathcal B}y_{t,B}B_j=\sigma_j\) for every \(j\); each individual receives one whole catalogue bundle, and all supplies are allocated.
It is EF1 if, for every \(t,u\in T\) and \(B,D\in\mathcal B\) with \(y_{t,B}>0\), \(y_{u,D}>0\), and \(v_t(B)<v_t(D)\), either some \(j\) with \(B_j>0\) satisfies \(v_t(B-\mathbf e_j)\ge v_t(D)\), or some \(j\) with \(D_j>0\) satisfies \(v_t(B)\ge v_t(D-\mathbf e_j)\). This includes comparisons within one type.

Is deciding whether such an EF1 allocation exists in \(\mathrm P\), with running time polynomial in \(m,\tau,|\mathcal B|,L\), or is it \(\mathrm{NP}\)-hard, where \(L\) is the total input bit length?

For unrestricted discrete bundles and possibly nonidentical negative Boolean valuations, a complete EF1 allocation always exists and can be computed in polynomial time ([Bhaskar et al.](https://arxiv.org/pdf/2411.19881)). For identical negative Boolean valuations, the stronger EFX allocation can be computed in polynomial time with an evaluation oracle ([Bérczi et al.](https://real.mtak.hu/206338/1/1-s2.0-S0304397524002111-main.pdf)).
No result settling this exact mass-allocation problem with an explicit deletion-closed catalogue was located.

Modeling choices made when packaging the task

  • Normalized total society mass to one so that the stated supplies are per capita; supported types have strictly positive masses.
  • Specified nonnegative rational supplies, nonnegative integer bundle coordinates, and binary encoding of coordinates.
  • Specified an explicit nonempty catalogue and explicit valuation tables, and included catalogue size and total input bit length in the complexity parameters.
  • Restored the discrete normalization that the empty bundle has value zero for every type.
  • Selected existence decision as the computational problem and allowed real allocation masses; individuals still receive whole bundles.
  • Made deletion closure precise and retained EF1 comparisons between positive-mass groups of the same type.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when every bundle has coordinates in \(\{0,1\}\), contains at most two items, and all masses and supplies are dyadic rationals.

The proof below allows arbitrary real mass splitting.

1. Membership in \(\mathrm{NP}\)

A certificate is a set \(S\subseteq T\times\mathcal B\) of permitted type–bundle pairs.

First, verify the EF1 condition for every ordered pair \((t,B),(u,D)\in S\). This is polynomial time: all valuations and all one-item deletions are explicitly available.

Next, check feasibility of the allocation equations with the additional constraints \(y_{t,B}=0\) whenever \((t,B)\notin S\). This is a rational linear program with at most \(\tau|\mathcal B|\) variables and polynomial encoding length. Rational linear-programming feasibility is decidable in polynomial time.

If this linear program is feasible, its allocation is EF1: every pair of positive coordinates belongs to \(S\), whose pairs already passed the EF1 check. Conversely, an EF1 allocation supplies a valid certificate by taking its actual support.

Thus the problem belongs to \(\mathrm{NP}\); no assumption that the initially given allocation masses are rational is needed.

2. Source problem and numerical preparation

We reduce from Independent Set: given a simple graph \(G=(V,E)\) and an integer \(k\), decide whether \(G\) has an independent set of size at least \(k\). Its \(\mathrm{NP}\)-completeness follows equivalently from Clique by complementing the graph; see [Karp’s completeness theorem](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

We may restrict to instances with \(E\ne\varnothing\) and \(1\le k<|V|\). All excluded cases are directly decidable, so they can be mapped to fixed yes- or no-instances satisfying these restrictions.

We may also assume that \(n=|V|\) is a power of two. Indeed, add isolated vertices until the vertex count is the next power of two, and increase \(k\) by the number added. Adding \(s\) isolated vertices increases the maximum independent-set size by exactly \(s\), preserving the answer. This adds fewer than the original number of vertices and preserves \(k<n\).

Write \(E=\{e_1,\ldots,e_r\}\), where \(r\ge1\). Let \(Q\) be the least power of two with \(Q\ge r\), and define positive dyadic weights by

  • \(w_{e_i}=1/Q\) for \(i<r\);
  • \(w_{e_r}=(Q-r+1)/Q\).

Their sum is \(1\). For each edge, set
\(\delta_e=(n-k)w_e/(2n)\).
Then every \(\delta_e\) is positive and dyadic, and
\(\sum_{e\in E}\delta_e=(n-k)/(2n)\).

3. Construction of the allocation instance

Types and item classes

There is one supported type for each vertex \(t\in V\), with mass \(\mu_t=1/n\).

The item classes are:

  • two special classes \(p,q\);
  • four distinct classes \(a_e,b_e,c_e,d_e\) for each edge \(e\);
  • one marker class \(h_t\) for each vertex \(t\).

All these classes are distinct. Markers will have zero supply and serve only to make the valuation tables distinct.

Catalogue

Include the zero bundle and every singleton bundle. Also include the special bundle
\(P=\mathbf e_p+\mathbf e_q\).

For each edge \(e=\{u,v\}\), choose an ordering of its endpoints and include four bundles:

  • \(D_{e,u}^{1}=\mathbf e_{a_e}+\mathbf e_{b_e}\);
  • \(D_{e,u}^{2}=\mathbf e_{c_e}+\mathbf e_{d_e}\);
  • \(D_{e,v}^{1}=\mathbf e_{a_e}+\mathbf e_{c_e}\);
  • \(D_{e,v}^{2}=\mathbf e_{b_e}+\mathbf e_{d_e}\).

The two bundles labelled \(u\), taken together, contain each of the four edge classes once. The same holds for the two bundles labelled \(v\).

Every bundle has coordinates in \(\{0,1\}\) and size at most two. The catalogue is deletion-closed because every singleton and the zero bundle are included.

Supplies

Set

  • \(\sigma_p=\sigma_q=k/n\);
  • \(\sigma_{a_e}=\sigma_{b_e}=\sigma_{c_e}=\sigma_{d_e}=\delta_e\) for each edge;
  • \(\sigma_{h_t}=0\) for every marker.

Consequently,
\(\sum_j\sigma_j=2k/n+4\sum_e\delta_e=2\).

Valuations

For every type \(t\), specify its entire valuation table as follows:

  • \(v_t(\mathbf0)=0\);
  • \(v_t(P)=v_t(\mathbf e_p)=v_t(\mathbf e_q)=-1\);
  • every singleton belonging to an edge class has value \(0\);
  • \(v_t(D_{e,u}^{i})=0\) if \(t=u\), and \(-1\) otherwise;
  • \(v_t(\mathbf e_{h_s})=-1\) if \(s=t\), and \(0\) otherwise.

In particular, the marker singletons distinguish all supported types.

Encoding size

The construction has
\(m=4r+n+2\), \(\tau=n\), and \(|\mathcal B|=8r+n+4\).

All numerical quantities have bit length polynomial in the graph input length. Because \(n,Q\) are powers of two, every mass and supply is dyadic. The explicitly listed bundle vectors and valuation tables therefore have polynomial total size.

4. Every EF1 allocation yields an independent set

Let \(y\) be any feasible allocation. Define the size of a bundle by
\(\|B\|_1=\sum_j B_j\).

The type equations give \(\sum_{t,B}y_{t,B}=1\), while the supply equations give \(\sum_{t,B}y_{t,B}\|B\|_1=2\). Hence

\(\displaystyle \sum_{t,B}y_{t,B}\bigl(2-\|B\|_1\bigr)=0.\)

Every summand is nonnegative because every catalogue bundle has size at most two. Thus every positively allocated bundle has size exactly two. No singleton or zero bundle is allocated.

Since \(P\) is the only size-two bundle containing \(p\), its aggregate allocated mass is

\(\displaystyle \sum_{t\in V}y_{t,P}=\sigma_p=k/n.\)

Define
\(I=\{t\in V:y_{t,P}>0\}\).
Each type has total mass \(1/n\), so
\(k/n=\sum_{t\in I}y_{t,P}\le |I|/n\).
Therefore \(|I|\ge k\).

We now prove that \(I\) is independent. Suppose, to the contrary, that an edge \(e=\{u,v\}\) has both endpoints in \(I\).

Consider either bundle \(D_{e,u}^{i}\). If it were allocated with positive mass to any type, type \(u\), which receives \(P\), would have an EF1 violation:

  • \(v_u(P)=-1<0=v_u(D_{e,u}^{i})\);
  • deleting either item from \(P\) leaves value \(-1\);
  • deleting either item from \(D_{e,u}^{i}\) leaves an edge singleton, of value \(0\).

Thus neither allowed deletion can remove the envy. Both bundles labelled \(u\) must consequently have zero aggregate mass. The identical argument for type \(v\) excludes both bundles labelled \(v\).

All four bundles of edge \(e\) would then have zero mass. Since singleton bundles also have zero mass, none of its four item classes could be supplied. This contradicts their positive supply \(\delta_e\).

Therefore \(I\) is an independent set of size at least \(k\). This argument uses only positivity and capacity bounds, so it applies to arbitrary real mass splitting.

5. Every sufficiently large independent set yields an EF1 allocation

Suppose \(G\) has an independent set of size at least \(k\). Taking a subset if necessary, fix an independent set \(I\) of size exactly \(k\).

Give every type in \(I\) its entire mass \(1/n\) on \(P\).

For each edge \(e=\{u,v\}\), at least one endpoint lies outside \(I\). Choose such an endpoint \(s_e\), and prescribe aggregate mass \(\delta_e\) on each of
\(D_{e,s_e}^{1}\) and \(D_{e,s_e}^{2}\).
Give all other edge bundles zero mass.

These prescribed bundles supply each of the four edge classes exactly \(\delta_e\), because the chosen pair covers each class once. Their total mass is

\(\displaystyle 2\sum_e\delta_e=(n-k)/n.\)

Distribute every chosen edge bundle equally among the \(n-k\) types outside \(I\): each such type receives mass \(\delta_e/(n-k)\) on each of the two chosen bundles for edge \(e\). Its total received mass is

\(\displaystyle \frac{2\sum_e\delta_e}{n-k}=1/n.\)

This allocation satisfies every type equation and every supply equation.

To verify EF1, consider any recipient type and any positively allocated bundle.

A type \(t\in I\). Its own bundle is \(P\), valued \(-1\). Every allocated edge bundle is labelled by a vertex outside \(I\), so type \(t\) values it at \(-1\) as well. It also values every allocated copy of \(P\) at \(-1\). Thus this type has no envy.

A type \(t\notin I\). Its own bundle is an edge bundle \(B\). If \(v_t(B)=0\), it cannot envy any bundle, since all values are at most \(0\). If \(v_t(B)=-1\), deleting either item from \(B\) leaves an edge singleton of value \(0\). Therefore, whenever it envies a bundle valued \(0\), this deletion removes the envy.

These arguments cover every positive-support comparison, including comparisons within the same type. The allocation is EF1.

6. Conclusion

The construction proves the equivalence:

\(G\) has an independent set of size at least \(k\) if and only if the constructed instance admits an EF1 allocation.

It is a polynomial-time reduction, and Section 1 establishes membership in \(\mathrm{NP}\). Thus deciding EF1 existence is \(\mathrm{NP}\)-complete, even under the stated additional restrictions. A polynomial-time algorithm in \(m,\tau,|\mathcal B|,L\) would therefore imply \(\mathrm P=\mathrm{NP}\).

This is compatible with the cited unrestricted-bundle existence results: those results permit allocations using bundles outside the prescribed catalogue. Here the catalogue restriction, combined with total supply, forces every recipient to receive exactly two items. [Bhaskar et al.](https://arxiv.org/pdf/2411.19881)
