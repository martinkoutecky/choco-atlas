The continuous mirror question, as graded

Given alternatives \(A\), a finite support \(S\) of complete rankings with positive binary-rational masses \(\mu_t\) summing to \(1\), and a designated alternative \(d\), define \(x \succ_\mu y\) when more than half the mass ranks \(x\) above \(y\), with ties producing no edge. Use this relation for the paper's upward-covering relation: \(x\) upward covers \(y\) within \(B\) if \(x \succ_\mu y\) and every \(z \in B\) with \(z \succ_\mu x\) also satisfies \(z \succ_\mu y\). A covering set \(B\) has every member in \(\mathrm{UC}_u(B)\), and every \(x \notin B\) is outside \(\mathrm{UC}_u(B \cup \{x\})\); it is minimal if no proper subset is a covering set. Decide whether \(d\) belongs to some minimal upward covering set.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a nonempty finite set of \(m\) alternatives and let \(d\in A\).
A society is given by its support: a list \(S\) of \(\tau\) distinct strict complete rankings of \(A\), each with positive binary-rational mass \(\mu_t\), where \(\sum_{t\in S}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length. State running times in \(m,\tau,L\).
For distinct \(x,y\in A\), define \(x\succ_\mu y\) iff \(\sum_{t\in S:\,x\text{ ranks above }y\text{ in }t}\mu_t>1/2\); a tie produces no edge.
For \(x,y\in B\subseteq A\), say that \(x\) upward covers \(y\) within \(B\) iff \(x\succ_\mu y\) and every \(z\in B\) satisfying \(z\succ_\mu x\) also satisfies \(z\succ_\mu y\). Let \(\mathrm{UC}_u(B)\) consist of the elements of \(B\) that no element of \(B\) upward covers within \(B\).
A set \(B\subseteq A\) is an upward covering set for \(A\) iff \(\mathrm{UC}_u(B)=B\) and every \(x\in A\setminus B\) satisfies \(x\notin\mathrm{UC}_u(B\cup\{x\})\). It is inclusion-minimal iff no proper subset is an upward covering set for the same \(A\).

Is deciding whether \(d\) belongs to some inclusion-minimal upward covering set solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For an explicitly given asymmetric, irreflexive dominance graph, this membership problem is \(\Theta_2^p\)-hard and belongs to \(\Sigma_2^p\). [Source](https://arxiv.org/abs/0901.3692v3).
No result specifically addressing the normalized rational-support society formulation was located in the literature search.

Result

The problem is \(\mathrm{NP}\)-hard. More strongly, it is \(\Theta_2^p\)-hard and belongs to \(\Sigma_2^p\).

The key is that every asymmetric, irreflexive dominance graph can be represented exactly by a normalized society with polynomially many distinct rankings and dyadic rational masses. Thus the stated graph hardness transfers to the society formulation.

1. Exact realization of a dominance graph

Let \(G=(A,E)\) be an asymmetric, irreflexive directed graph, with \(|A|=m\) and \(|E|=q\). We construct a society whose strict majority relation is exactly \(E\).

For a multiset \(V\) of rankings and distinct alternatives \(a,b\), define the unnormalized margin
\[ \]
\(M_V(a,b)=|\{t\in V:a\text{ is above }b\}|-|\{t\in V:b\text{ is above }a\}|.\)

Here multiset occurrences are counted separately. We will merge identical rankings before producing the required support.

An edge gadget

For each edge \((x,y)\in E\), list the remaining alternatives as \(r_1,\ldots,r_{m-2}\), and introduce these two rankings:

\(P_{xy}:x>y>r_1>\cdots>r_{m-2},\)

\(Q_{xy}:r_{m-2}>\cdots>r_1>x>y.\)

When \(m=2\), the lists of remaining alternatives are empty.

The two rankings contribute margin \(2\) to \(M_V(x,y)\). Their contributions cancel on every other unordered pair:

  • For two remaining alternatives, their relative orders are reversed.
  • For \(x\) and a remaining alternative, \(x\) is above that alternative in \(P_{xy}\) and below it in \(Q_{xy}\).
  • The same cancellation holds for \(y\) and a remaining alternative.

Consequently, taking one gadget for every edge gives \(2q\) ranking occurrences and, for all distinct \(a,b\),

\(M_V(a,b)=2\) if \((a,b)\in E\),

\(M_V(a,b)=-2\) if \((b,a)\in E\),

\(M_V(a,b)=0\) if neither edge is present.

Asymmetry ensures that the first two cases never occur simultaneously.

Dyadic normalization

Suppose first that \(q>0\). Let \(N\) be the smallest power of two satisfying \(N\geq 2q\). Then \(N<4q\), and \(N-2q\) is even.

Choose any ranking \(R\), and let \(R^{\mathrm{rev}}\) be its reverse. Add \((N-2q)/2\) copies of each. Each reversed pair contributes zero margin on every unordered pair, so all margins remain unchanged. The resulting multiset has exactly \(N\) occurrences.

Let \(S\) be its set of distinct rankings. If ranking \(t\) occurs \(c_t\) times, assign it mass

\(\mu_t=c_t/N.\)

These masses are positive dyadic rationals, and

\(\sum_{t\in S}\mu_t=\sum_{t\in S}c_t/N=1.\)

Thus the society satisfies both normalization and the requirement that support rankings be distinct.

For distinct \(a,b\), put \(p_{ab}=\sum_{t\in S:a\text{ is above }b}\mu_t\). Strict completeness of every ranking gives

\(2p_{ab}-1=M_V(a,b)/N.\)

Hence \(p_{ab}>1/2\) exactly when \((a,b)\in E\). Every missing unordered edge becomes an exact majority tie.

If \(q=0\) and \(m\geq 2\), use \(R\) and \(R^{\mathrm{rev}}\), each with mass \(1/2\); all pairs tie. If \(m=1\), use the unique ranking with mass \(1\). This proves exact realization for every graph under consideration.

2. Support size and construction time

Relabel alternatives by integers from \(1\) through \(m\).

For \(q>0\), there are at most two distinct rankings per edge gadget, together with the two padding rankings. Therefore

\(\tau\leq 2q+2\leq m(m-1)+2.\)

Each ranking takes \(O(m\log(m+2))\) bits. Each mass \(c_t/N\) takes \(O(\log(m+2))\) bits because \(N<4q=O(m^2)\). The output bit length therefore satisfies

\(L=O(m^3\log(m+2)).\)

The construction is polynomial time. Explicitly, generate the \(N=O(m^2)\) ranking occurrences, sort them lexicographically, and count equal consecutive rankings. There are \(O(m^2\log(m+2))\) comparisons, each costing at most \(O(m\log(m+2))\) bit operations. Including generation and writing the output, a sufficient bound is

\(O(m^3\log^2(m+2)).\)

The edgeless and singleton cases satisfy the same asymptotic bounds.

3. Preservation of covering sets and hardness

Let \(\succ_G\) denote the original graph relation and \(\succ_\mu\) the constructed majority relation. Section 1 proves

\(a\succ_G b\quad\Longleftrightarrow\quad a\succ_\mu b\)

for every pair of distinct alternatives.

Fix any subset \(B\subseteq A\) and \(x,y\in B\). Upward covering depends only on whether \(x\) dominates \(y\) and, for each \(z\in B\), whether \(z\) dominates \(x\) and \(y\). All these facts agree in the two representations. Thus upward covering within every subset agrees, and consequently their upward uncovered sets agree.

It follows that both defining conditions for an upward covering set agree:

  • Internal stability, \(\mathrm{UC}_u(B)=B\).
  • External stability, \(x\notin\mathrm{UC}_u(B\cup\{x\})\) for every \(x\in A\setminus B\).

Therefore the two representations have exactly the same upward covering sets. Since inclusion-minimality means that no proper subset is an upward covering set for the same ground set \(A\), their inclusion-minimal upward covering sets also coincide.

Keeping the designated alternative \(d\) unchanged gives a polynomial-time many-one reduction from graph membership to society membership.

The cited graph theorem applies to asymmetric, irreflexive relations, with the same upward-covering, stability, and inclusion-minimality definitions; it states \(\Theta_2^p\)-hardness for this membership problem. These hypotheses match exactly. See Definitions 1–3 and Theorem 12 in [Baumeister et al., *The Complexity of Computing Minimal Unidirectional Covering Sets*](https://webspace.maths.qmul.ac.uk/felix.fischer/publications/bbfhr_covering.pdf).

The society problem is therefore \(\Theta_2^p\)-hard. Since \(\mathrm{NP}\subseteq\Theta_2^p\), it is also \(\mathrm{NP}\)-hard.

4. Upper bound in the society parameters

For completeness, the representation also permits polynomial-time extraction of the dominance graph.

Write each mass as \(\mu_t=a_t/b_t\), with positive integers encoded in binary. Set

\(D=\prod_{t\in S}b_t,\qquad w_t=a_t(D/b_t).\)

The bit length of \(D\) is \(O(L)\), because the sum of the denominator encoding lengths is at most \(L\). Moreover, normalization gives \(\sum_t w_t=D\).

For every unordered pair \(x,y\), sum the integer weights of rankings placing \(x\) above \(y\), and compare twice this sum with \(D\). This determines the edge or tie exactly. Using schoolbook integer arithmetic, a conservative running-time bound is

\(O(\tau m^2L^2).\)

Once the graph is available, checking whether a proposed subset \(B\) is an upward covering set takes \(O(m^3)\) Boolean table operations:

  • Check each ordered pair in \(B\) for upward covering, scanning its possible witnesses in \(B\).
  • For each outside alternative \(x\), check whether some \(y\in B\) upward covers \(x\) within \(B\cup\{x\}\).

Let \(\mathcal C(B)\) denote this polynomial-time covering-set predicate. Membership is equivalent to

\(\exists B\subseteq A\;\forall C\subseteq A:\quad d\in B\ \land\ \mathcal C(B)\ \land\bigl(C\subsetneq B\Longrightarrow\neg\mathcal C(C)\bigr).\)

Both quantified subsets have \(m\)-bit encodings, and the predicate is polynomial time in \(m,\tau,L\). This establishes membership in \(\Sigma_2^p\).

Thus the requested hardness conclusion is settled, even when all masses are dyadic and \(\tau=O(m^2)\). A polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).
