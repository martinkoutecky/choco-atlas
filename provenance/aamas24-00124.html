The continuous mirror question, as graded

Given rational locations \(x_t\in[0,1]\) and masses \(\mu_t\ge0\) with \(\sum_{t=1}^{\tau}\mu_t=1\), compute an exact endpoint lottery \(\pi^\star=p^\star\delta_0+(1-p^\star)\delta_1\) maximizing \(\sum_t\mu_t\bigl(p x_t+(1-p)(1-x_t)\bigr)\) subject to \(p x_t+(1-p)(1-x_t)\ge\mu_t/2\) for every \(t\) and \(0\le p\le1\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\ge1\) distinct rational locations \(x_t\in[0,1]\), each with a positive binary-rational mass \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\). Types are locations; repeated locations are merged by adding their masses. Thus \(\tau\) is the support size, not the number of possible types.
An obnoxious facility gives utility \(|y-x_t|\) to type \(t\) when placed at \(y\). An endpoint lottery is \(\pi_p=p\delta_0+(1-p)\delta_1\), where \(\delta_y\) is point mass at \(y\) and \(p\in[0,1]\).
Its expected utility is \(u_t(p)=p x_t+(1-p)(1-x_t)\). It satisfies \(2\)-Unanimous Fair Share in expectation precisely when \(u_t(p)\ge\mu_t/2\) for every support type.
Compute an exact rational maximizer \(p^\star\) of \(\sum_{t=1}^{\tau}\mu_t u_t(p)\) subject to these inequalities and \(0\le p\le1\); any maximizer is acceptable.
Let \(L\) be the total binary input length and \(m=2\) the number of allowed facility locations. State running times in \(m,\tau,L\).

Can this exact optimization problem be solved in time polynomial in \(m,\tau,L\), or is it NP-hard?

For a finite list of agents, an explicit polynomial-time endpoint-lottery mechanism maximizes utilitarian welfare subject to expected \(2\)-Unanimous Fair Share, with each co-located group guaranteed its size divided by twice the total population. Result

The problem is polynomial-time solvable. For the specified \(m=2\), the algorithm below uses \(O(\tau)=O(m\tau)\) rational arithmetic operations and \(O(\tau L^2)=O(m\tau L^2)\) bit operations with schoolbook integer arithmetic. Its output has \(O(L)\) bits.

Here \(m\) counts allowed facility locations, while \(\tau\) counts support types.

1. Feasibility

Since the positive masses sum to \(1\), each satisfies \(\mu_t\leq 1\). At \(p=1/2\), every type receives

\(u_t(1/2)=\frac{x_t}{2}+\frac{1-x_t}{2}=\frac12\geq\frac{\mu_t}{2}.\)

Thus the feasible set is always nonempty.

2. Compute the exact feasible interval

For each support type, rewrite its constraint as

\((1-x_t)+(2x_t-1)p\geq\mu_t/2.\)

There are three cases:

  • If \(x_t>1/2\), division by the positive coefficient gives the lower bound

\(p\geq\ell_t:=\frac{\mu_t/2-(1-x_t)}{2x_t-1}\).

  • If \(x_t<1/2\), rearrangement gives the upper bound

\(p\leq r_t:=\frac{1-x_t-\mu_t/2}{1-2x_t}\).

  • If \(x_t=1/2\), utility is constantly \(1/2\), so the constraint holds for every \(p\).

Define

\(p_{\min}:=\max\bigl(\{0\}\cup\{\ell_t:x_t>1/2\}\bigr),\)

\(p_{\max}:=\min\bigl(\{1\}\cup\{r_t:x_t<1/2\}\bigr).\)

The case analysis proves both directions: a probability satisfies every constraint and belongs to \([0,1]\) if and only if it belongs to \([p_{\min},p_{\max}]\). Feasibility of \(1/2\) additionally gives

\(0\leq p_{\min}\leq 1/2\leq p_{\max}\leq 1.\)

Both interval endpoints are rational and can be computed by scanning the support once.

3. Maximize welfare

Let \(M:=\sum_{t=1}^{\tau}\mu_t x_t\). Using \(\sum_t\mu_t=1\), welfare is

\(W(p):=\sum_t\mu_t u_t(p)=1-M+(2M-1)p.\)

Consequently, return:

  • \(p^\star=p_{\max}\) if \(M>1/2\);
  • \(p^\star=p_{\min}\) if \(M<1/2\);
  • \(p^\star=1/2\) if \(M=1/2\).

For the first case, \(W\) is strictly increasing, so its maximum on the feasible interval is its right endpoint. For the second, it is strictly decreasing, so its maximum is its left endpoint. For the third, it is constant, and the selected probability is feasible.

This proves that the algorithm returns an exact rational maximizer in every case, including \(\tau=1\).

4. Bit complexity

Use the explicit binary encoding of rational numerators and denominators. Write \(x_t=a_t/b_t\) and \(\mu_t=c_t/d_t\), with positive denominators.

The bounds can be computed directly as

\(\ell_t=\frac{b_tc_t-2d_t(b_t-a_t)}{2d_t(2a_t-b_t)}\quad\text{when }2a_t>b_t,\)

\(r_t=\frac{2d_t(b_t-a_t)-b_tc_t}{2d_t(b_t-2a_t)}\quad\text{when }2a_t<b_t.\)

Each numerator and denominator has \(O(L)\) bits. Bounds are compared exactly by cross multiplication with positive denominators. Maintaining their maximum or minimum only selects an existing bound, so it does not accumulate denominators.

For the mean,

\(M=\sum_t\frac{a_tc_t}{b_td_t}.\)

Its partial sums can be represented without reduction, using the product of the processed denominators. The binary length of this product is at most

\(1+\sum_t\bigl(\log_2 b_t+\log_2 d_t\bigr)=O(L).\)

Every partial sum belongs to \([0,1]\), because its terms are nonnegative and \(\mu_tx_t\leq\mu_t\). Hence its numerator is at most its denominator and also has \(O(L)\) bits. The comparison with \(1/2\) is therefore an exact integer comparison involving \(O(L)\)-bit integers.

There are \(O(\tau)\) arithmetic operations and comparisons. Each takes at most \(O(L^2)\) bit operations using schoolbook arithmetic, establishing the claimed \(O(\tau L^2)\) bound. Reduction of fractions is unnecessary: the selected numerator and denominator already specify an exact rational output of \(O(L)\) bits.

5. Relation to the discrete formulation

The cited paper gives a welfare-optimal endpoint mechanism for finite agent lists satisfying expected unanimous fair share ([Section 5.4, Lemma 3](https://arxiv.org/html/2301.04340v2#S5.SS4)). The proof above establishes the binary-rational mass formulation directly. In particular, it avoids expanding masses into an agent list, whose length could be exponential in the input length.

Thus binary encoding of the masses does not obstruct polynomial-time exact optimization. An NP-hardness result under standard polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).
