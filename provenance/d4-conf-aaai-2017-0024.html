The continuous mirror question, as graded

Given finitely many competitor types \(T\), rational masses \(\mu_t\) summing to \(1\), a deterministic type-level winner for each match, a target type \(t^\star\), and bracket depth \(R\), can the masses be paired over \(R\) rounds so that the final mass \(2^{-R}\) is entirely of type \(t^\star\)? At round \(r\), choose match masses \(q^r_{\{a,b\}}\geq 0\) satisfying \(2q^r_{\{a,a\}}+\sum_{b\ne a}q^r_{\{a,b\}}=p_a^r\); the next-round mass of each type is the sum of match masses whose winner has that type. The question is whether such a schedule exists.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) competitor types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; set \(m=|T|=\tau\).
The input also specifies a symmetric deterministic winner table \(w(a,b)\in\{a,b\}\), with \(w(a,a)=a\), a target \(t^\star\in T\), and a nonnegative integer depth \(R\) encoded in unary. Let \(L\) be the total input bit length and \(k\) the minimum feedback arc set size of the tournament on distinct types, oriented from winner to loser.
Let \(\mathcal U\) be the unordered pairs of types, allowing repetitions. A schedule has nonnegative real match masses \(q^r_{\{a,b\}}\) for \(\{a,b\}\in\mathcal U\) and \(0\le r<R\), starts with \(p_a^0=\mu_a\), and satisfies \(2q^r_{\{a,a\}}+\sum_{b\ne a}q^r_{\{a,b\}}=p_a^r\) and \(p_c^{r+1}=\sum_{\{a,b\}\in\mathcal U:\,w(a,b)=c}q^r_{\{a,b\}}\). Thus every round pairs all surviving mass, including matches within a type, with no byes.
Feasibility means that such a schedule exists with \(p_{t^\star}^R=2^{-R}\) and \(p_a^R=0\) for every \(a\ne t^\star\).

Is this feasibility problem in \(\mathrm P\) or \(\mathrm{NP}\)-hard, with running times measured in \(m,\tau,R,L\)? If it is \(\mathrm{NP}\)-hard, is it nevertheless fixed-parameter tractable parameterized by \(k\)?

For finite players in a balanced knockout bracket, feasibility is [\(\mathrm{NP}\)-complete](https://ojs.aaai.org/index.php/AAAI/article/download/8805/8664), and admits time [\(2^{O(k^2\log k)}n^{O(1)}\)](https://ojs.aaai.org/index.php/AAAI/article/view/11132), where \(n\) counts players and \(k\) is their tournament's minimum feedback arc set size.
No result settling this precise divisible-mass problem was located.

  • Specified nonnegative real schedule variables, initial masses, round indices, and zero final mass for every other type.

  • Transferred the anchor's feedback arc set parameter to the tournament on supported types, excluding within-type matches.

Result

The divisible-mass feasibility problem is in \(\mathrm P\). It can be decided in time \((m+R+L)^{O(1)}\), with \(m=\tau\). Consequently, it is also fixed-parameter tractable parameterized by \(k\), without computing a feedback arc set.

The reason is that the defining schedule constraints form a rational linear program of polynomial encoding length.

1. Exact linear programming formulation

Introduce nonnegative real variables:

  • \(p_a^r\), for \(a\in T\) and \(0\le r\le R\);
  • \(q_{\{a,b\}}^r\), for \(\{a,b\}\in\mathcal U\) and \(0\le r<R\).

Impose the following linear equalities.

Initial masses: for every \(a\in T\),
\(p_a^0=\mu_a\).

Pairing constraints: for every \(a\in T\) and \(0\le r<R\),
\(2q_{\{a,a\}}^r+\sum_{b\ne a}q_{\{a,b\}}^r-p_a^r=0\).

Winner constraints: for every \(c\in T\) and \(0\le r<R\),
\(p_c^{r+1}-\sum_{\{a,b\}\in\mathcal U:\,w(a,b)=c}q_{\{a,b\}}^r=0\).

Terminal masses:
\(p_{t^\star}^R=2^{-R}\), and \(p_a^R=0\) for every \(a\ne t^\star\).

These constraints are linear because the winner table is fixed input: it determines which variables occur in each winner equation.

Equivalence proof. Every feasible schedule supplies values satisfying all these constraints, by the schedule definition. Conversely, every feasible assignment supplies nonnegative match masses satisfying precisely the required initial, pairing, winner, and terminal conditions. Thus its match masses constitute a feasible schedule. This proves equivalence in both directions; no additional realizability condition is needed under the stated definition.

For consistency, summing the pairing equations gives
\(2\sum_{\{a,b\}\in\mathcal U}q_{\{a,b\}}^r=\sum_{a\in T}p_a^r\).
Every unordered pair has exactly one winner, so summing the winner equations gives
\(\sum_{c\in T}p_c^{r+1}=\sum_{\{a,b\}\in\mathcal U}q_{\{a,b\}}^r\).
Induction from the initial total mass therefore yields
\(\sum_{a\in T}p_a^r=2^{-r}\).

The formulation also handles \(R=0\): there are no match variables, and feasibility requires the initial distribution itself to be concentrated on the target.

2. Polynomial encoding length and exact decision

There are \(m(m+1)/2\) unordered pairs allowing repetitions. Hence the number of variables is
\(N=(R+1)m+Rm(m+1)/2\),
and the number of equality constraints is
\(E=2(R+1)m\).
There are additionally \(N\) nonnegativity constraints.

All matrix coefficients belong to \(\{-2,-1,0,1,2\}\). The right-hand sides are input masses, zeros, and \(2^{-R}\). The input masses have total encoding length at most \(L\). Moreover, \(2^{-R}=1/2^R\) has binary rational encoding length \(O(R+1)\): the denominator has \(R+1\) binary digits.

The constraint matrix has \(O((R+1)m^2)\) nonzero entries. Recording their row and column indices therefore gives total sparse encoding length
\(O\!\left(L+R+1+(R+1)m^2\log((R+1)m+2)\right)\).
A dense encoding also has polynomial length.

We now apply the standard rational linear programming theorem: feasibility of a finite system of non-strict linear inequalities with rational coefficients over real variables is decidable in time polynomial in its binary encoding length. This is the polynomial-time feasibility result underlying [Khachiyan’s linear programming algorithm](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here: every coefficient is rational, every constraint is linear and non-strict, and each equality can be replaced by two inequalities. Consequently, the decision runs in time \((m+R+L)^{O(1)}\).

Because \(R\) is encoded in unary and the support is explicitly listed, both \(R\) and \(m\) are bounded by the input length up to encoding constants. The running time is therefore polynomial in \(L\). This uses exact rational feasibility, so it does not depend on numerical tolerances.

3. Parameterization and the finite-player comparison

A parameterized problem is fixed-parameter tractable if it admits running time \(f(k)L^C\), where \(C\) is independent of \(k\). The algorithm above has this form with \(f(k)=1\). Thus the problem is fixed-parameter tractable parameterized by \(k\), and no structural restriction on the tournament is necessary.

The cited [finite-player hardness result](https://ojs.aaai.org/index.php/AAAI/article/download/8805/8664) concerns a draw assigning indivisible players to a balanced bracket. The present problem instead permits arbitrary nonnegative real match masses. Its constraints impose no integrality or individual-player assignment requirements. The linear program is therefore exact for the stated divisible-mass problem; finite-player hardness does not establish hardness for it.
