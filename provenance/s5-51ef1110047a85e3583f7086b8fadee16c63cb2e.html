The continuous mirror question, as graded

Given finite rational masses of agent roles with strict rankings, ownership rights, and object supplies scaled with population, can one compute a feasible type-level assignment \(x_{t,o}\) such that no measurable coalition of agent mass can block under mass-lifted rectified or refined exclusion rules?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Normalize total mass to \(1\). Type \(t\) occupies an atomless interval \(A_t\) of mass \(p_t\) and has a strict ranking of \(m\) object classes and the null object \(o^*\); classes below \(o^*\) are unacceptable. There are no transfers.
Each class \(o\) has positive binary-rational supply \(q_o\), represented by an interval \(B_o\) of distinguishable units, and a nonempty owner-role set \(R_o\subseteq\{1,\ldots,\tau\}\). Every unit in \(B_o\) is jointly owned by \(C_o=\bigcup_{t\in R_o}A_t\). Supplies are per unit of population.
Write \(A=\bigcup_t A_t\). An allocation \(\mu\) is a measurable measure-preserving bijection between a measurable subset of \(A\) and a measurable subset of \(\bigcup_o B_o\); other agents receive \(o^*\), and unused supply is permitted. Preferences compare class labels \(\bar\mu(a)\), so units within a class are indifferent. Let \(\mu(D)\) denote only the real units assigned to \(D\).
All sets, inclusions and conditions are understood modulo null sets; coalitions have positive mass. Define \(\omega(D)=\bigcup_{o:C_o\subseteq D}B_o\). A coalition \(D\) is self-enforcing in \(\sigma\) when \(\sigma(D)\subseteq\omega(D)\), and minimal self-enforcing when no positive-mass proper subcoalition is self-enforcing.
Define \(D^0=D\), \(D^{k+1}=D^k\cup\mu^{-1}(\omega(D^k))\), and \(\Omega(D\mid\mu)=\omega(\bigcup_{k\geq0}D^k)\).
A blocking proposal consists of a coalition \(C\) and a feasible allocation \(\sigma\), with \(\bar\sigma(a)\succsim_t\bar\mu(a)\) almost everywhere on \(C\cap A_t\) and strict improvement on positive mass. Put \(E=\{a\in C:\bar\sigma(a)=\bar\mu(a)\}\) and \(H=\{a\in A:\bar\mu(a)\succ_t\bar\sigma(a)\}\).
Rectified blocking additionally requires \(C\) to be self-enforcing in \(\sigma\) and, for every positive-mass self-enforcing \(D\subseteq E\), \(\sigma(C\setminus D)\cap\omega(D)\cap\mu(A\setminus C)=\varnothing\).
Refined exclusion blocking additionally requires \(\mu(H)\subseteq\Omega(C\mid\mu)\); if \(E\) has positive mass, either \(E\) is self-enforcing in \(\sigma\) and \(\mu(H)\cap\Omega(E\mid\mu)=\varnothing\), or \(C\) is minimal self-enforcing in \(\sigma\).
The input selects one of these two blocking rules. Seek a nonnegative binary-rational matrix \(x_{t,o}\), including \(o^*\), with \(\sum_o x_{t,o}=p_t\) and \(\sum_t x_{t,o}\leq q_o\) for real \(o\), admitting an allocation \(\mu\) with \(x_{t,o}=\lambda(A_t\cap\bar\mu^{-1}(o))\) and no blocking coalition under the selected rule. Let \(L\) be the total input bit length.

Does such an assignment always exist for each rule? Is computing one, or correctly reporting nonexistence, polynomial-time solvable in \(m,\tau,L\), or NP-hard?

In the finite-agent model, every outcome of the generalized YRMH–IGYT mechanism belongs to both cores, so their intersection is nonempty ([source](https://arxiv.org/pdf/2005.09351)). A later discrete treatment explicitly permits unassigned objects ([source](https://arxiv.org/html/2511.21155v1)); no result settling the specified atomless problem was located.

Modeling choices made when packaging the task

  • Normalize agent mass to one and interpret rational object supplies as quantities per unit of population.
  • Represent ownership by nonempty sets of roles: every unit of a class is jointly owned by all agents in its owner roles, and control requires inclusion of those owner pools.
  • Represent assignments by measurable matchings of agent mass to object-unit mass; unused supply is allowed, following the intended discrete feasibility condition and its later correction.
  • Compare outcomes by strict class rankings including the null object; copies within a class are indifferent, and unchanged class labels define unaffected agents.
  • Use positive-mass coalitions and improvements, interpret conditions modulo null sets, and define proper subcoalitions by positive-mass difference.
  • Lift neutrality to individual object units and retain both alternatives in refined exclusion blocking, including minimal self-enforcement.
  • Interpret 'rectified or refined exclusion' as an input selecting either rule, rather than requiring simultaneous membership in both cores.
  • Require a binary-rational type-level assignment admitting an unblocked measurable realization; allow arbitrary measurable blocking proposals.

Partial resolution and general computational upper bounds

The rectified rule does not always admit an assignment. The two-class counterexample below proves this for every measurable allocation, regardless of rationality.

For refined exclusion, general existence remains unresolved here. Both rules are polynomial-time solvable when there is only one real class.

The additional general progress is a finite certificate theorem:

  • Whether a feasible matrix is blocked depends only on that matrix, not on its realization by distinguishable units.
  • If a rational matrix is blocked, it has a blocking certificate of polynomial bit length.
  • If an eligible stable matrix exists, one exists with polynomial bit length.
  • Consequently, existence belongs to $\Sigma_2^{\mathrm P}$, and an assignment or a correct report of nonexistence can be computed in deterministic time $2^{\operatorname{poly}(m,\tau,L)}$.

These upper bounds do not establish polynomial-time solvability or NP-hardness. They hold both for rationals encoded by binary numerators and denominators and, with the qualification proved in Section 7.3, for the narrower interpretation of “binary rational” as dyadic rational.

1. Basic realizability and necessary conditions

Write $\mathcal O=\{o^*,1,\ldots,m\}$ for the labels. All subsequent set statements are modulo null sets.

Every nonnegative real matrix satisfying the population and supply constraints admits an allocation. Indeed, partition each interval $A_t$ into measurable pieces of masses $x_{t,o}$. For every real class $o$, partition a subset of $B_o$ into pieces of these same masses and match corresponding pieces by measure-preserving bijections. Leave the remaining agents and units unmatched.

We use the elementary fact that equal-mass measurable subsets of finite intervals admit measure-preserving bijections modulo null sets. One way to obtain such bijections is to identify each subset with an interval of its own mass using its cumulative Lebesgue measure, and then compose these identifications.

Call an allocation individually rational if no positive mass receives an unacceptable class. Call it Pareto efficient if no feasible allocation weakly improves everyone and strictly improves positive mass.

Proposition 1. An allocation unblocked under either rule is individually rational and Pareto efficient.

Proof. If positive mass receives unacceptable classes, let $C$ be those agents and replace their assignments by $o^*$, leaving everyone else unchanged. This is feasible and strictly improves everyone in $C$. Here $E=H=\varnothing$ and $\sigma(C)=\varnothing$. It therefore satisfies both blocking rules.

If $\sigma$ is a Pareto improvement, the rectified rule permits the grand coalition: $A$ owns every class, and its neutrality condition holds because there are no outsiders. For refined exclusion, take $C$ to be precisely the strictly improved agents. Then $E=H=\varnothing$, so its additional conditions hold. $\square$

2. Rectified nonexistence with two classes

Consider this society:

| Type | Mass | Ranking |
|---|---:|---|
| $1$ | $\frac12$ | $b\succ o^*\succ c$ |
| $2$ | $\frac12$ | $b\succ c\succ o^*$ |

Let $q_b=\frac34$ and $q_c=\frac14$. Both owner-role sets are $\{1\}$. Put $M=A_1$. Thus
$$ \omega(D)= \begin{cases} B_b\cup B_c,&M\subseteq D,\\ \varnothing,&M\not\subseteq D. \end{cases} $$

Theorem 2. Every allocation in this instance has a rectified block.

Proof.

First, any putative unblocked allocation must give $b$ to every owner. Otherwise, let $C=M$ and give every owner $b$, assigning the null object outside $M$. This is feasible because $\lambda(M)<q_b$. It weakly improves all owners and strictly improves positive mass.

The coalition owns both classes, so it is self-enforcing. Its unchanged set $E$ misses positive mass of $M$. Every $D\subseteq E$ therefore owns nothing. Under the proposal, every positive-mass such $D$ receives real units, so none is self-enforcing. Neutrality is vacuous.

Second, Pareto efficiency forces all $b$-supply to be used. If some were unused, positive mass of type $2$ would lack $b$ and could receive unused units as a Pareto improvement. Consequently, type $2$ has mass $\frac14$ receiving $b$ and mass $\frac14$ receiving something else.

Choose equal positive-mass sets
$$ P\subseteq M,\qquad T\subseteq A_2\cap\bar\mu^{-1}(b),\qquad S\subseteq A_2\setminus\bar\mu^{-1}(b). $$
Let their common mass be $\varepsilon$. Put $C=M\cup S$, and construct $\sigma$ by giving:

  • $P$ the old units $\mu(T)$;
  • $S$ the old units $\mu(P)$;
  • $T$ the null object;

and leaving everyone else unchanged. Release any old real units of $S$. The equal masses and atomlessness make this feasible.

Every owner retains label $b$, while $S$ strictly improves. Thus $E=M$, and $C$ is self-enforcing. Every positive-mass proper subset of $M$ owns nothing and receives real units under $\sigma$. Hence the only positive-mass self-enforcing subset of $E$ is $M$ itself.

For $D=M$, neutrality holds because
$$ \sigma(C\setminus M)=\sigma(S)=\mu(P) $$
and injectivity gives
$$ \mu(P)\cap\mu(A\setminus C)=\varnothing. $$
This is a rectified block. $\square$

The exchange within label $b$ is essential: the owners are unchanged even though their distinguishable units change. The finite model in the cited paper assumes strict preferences over individual objects, so its nonemptiness theorem does not directly apply to this example. [Zhang, Section 2](https://arxiv.org/pdf/2005.09351).

A refined exclusion assignment for the same instance

Consider
$$ \begin{array}{c|ccc} &b&c&o^*\\ \hline 1&\frac12&0&0\\ 2&\frac14&\frac14&0 \end{array}. $$

Proposition 3. Every allocation realizing this matrix is unblocked under refined exclusion.

Proof. Only type-$2$ recipients of $c$ can strictly improve, and they must receive $b$. Let their strictly improved mass be $s>0$. All current $b$-recipients in $C$ must retain $b$. Since its supply is fully used, positive mass of current $b$-recipients must be harmed. More precisely, if their harmed mass is $h_b$, the proposed demand for $b$ is at least
$$ \frac34-h_b+s, $$
so $h_b\geq s>0$.

If $M\not\subseteq C$, then $\omega(C)=\varnothing$. The closure never expands, giving $\Omega(C\mid\mu)=\varnothing$, contrary to exclusion of the harmed agents’ old $b$-units. Hence $M\subseteq C$.

Owners already receive their top class, so $M\subseteq E$. Also, $M$ is self-enforcing in $\sigma$. Strict improvement occurs outside $M$, making it a positive-mass proper self-enforcing subcoalition of $C$. Thus $C$ cannot be minimal self-enforcing.

The remaining branch requires disjointness from $\Omega(E\mid\mu)$. But $M\subseteq E$ implies
$$ \Omega(E\mid\mu)=B_b\cup B_c, $$
which contains the positive mass of harmed agents’ old $b$-units. This is impossible. $\square$

3. Complete classification with one real class

Suppose the only real class is $b$, with supply $q>0$. Define
$$ M=C_b,\qquad V=\{a:b\succ_t o^*\text{ for the type of }a\}, $$
and
$$ v=\lambda(V),\qquad w=\lambda(M\cap V). $$

The owner-first allocation assigns $\min(q,w)$ units to accepting owners, then assigns any remaining supply to accepting nonowners until supply or acceptable demand is exhausted. All other agents receive the null object.

Theorem 4.

  • The rectified core is empty exactly when $0<w<q<v$.
  • The owner-first allocation is always unblocked under refined exclusion.
  • Finding an assignment or correctly reporting nonexistence is polynomial-time solvable for both rules in this case.

Proof.

If $q\geq v$, owner-first gives everyone their preferred label, so neither rule admits strict improvement.

Suppose $q<v$. Owner-first uses all supply. Any blocking proposal must improve positive mass from $o^*$ to $b$, thereby harming positive mass of current $b$-recipients.

For refined exclusion, such harm requires $M\subseteq C$. Otherwise the closure is stationary with no controlled class. If $q\leq w$, all current recipients belong to $M\subseteq C$ and cannot be harmed.

If $w<q<v$, every owner receives their preferred label, so $M\subseteq E$. The coalition $M$ is self-enforcing in $\sigma$, and strict improvement occurs outside it. Thus $C$ is not minimal self-enforcing. Moreover,
$$ \Omega(E\mid\mu)=B_b, $$
which rules out the required disjointness from harmed agents’ old units. This proves refined exclusion stability.

For rectified blocking, if $q\leq w$, any strictly improving self-enforcing coalition must contain $M$, hence all current recipients. Retaining their assignments exhausts supply, preventing strict improvement.

Now suppose $w=0$ and $q<v$. Owners reject $b$ and remain at $o^*$. A rectified blocking coalition must again contain $M$. Here $M\subseteq E$ is self-enforcing, so neutrality gives
$$ \sigma(C\setminus M)\cap\mu(A\setminus C)=\varnothing. $$
All $q$ units were initially used. Writing $r_C=\lambda(\mu(C))$, the units outside $\mu(A\setminus C)$ have mass exactly $r_C$. Since $\sigma(M)=\varnothing$, the proposal can assign at most $r_C$ units to $C$. Preserving its current recipients and strictly improving positive mass requires more than $r_C$, a contradiction.

These cases establish rectified existence outside $0<w<q<v$.

Finally, suppose $0<w<q<v$, and assume an unblocked allocation exists. Proposition 1 makes it individually rational and Pareto efficient. All accepting owners must receive $b$: otherwise $M$ can assign $b$ to all accepting owners and $o^*$ to rejecting owners. This is feasible because $w<q$. Since some owners improve, $E$ does not contain $M$, so every $D\subseteq E$ owns nothing and neutrality is automatic.

Pareto efficiency forces full supply use. Thus accepting owners consume mass $w$, accepting nonowners consume mass $q-w>0$, and accepting nonowners of mass $v-q>0$ remain at $o^*$.

Choose equal positive-mass sets $P,T,S$ from these three groups, respectively. Apply the exchange from Theorem 2, with coalition $C=M\cup S$. Again $E=M$. A self-enforcing proper subset of $M$ owns nothing, so its neutrality intersection is empty. For $D=M$, the improved agents receive $\mu(P)$, old units assigned inside $C$. This is a rectified block.

For the algorithm, compute $v,w$, test the displayed inequalities, and otherwise construct owner-first by processing accepting owner types before accepting nonowner types. Each step takes a minimum of remaining supply and remaining type mass. Polynomially many rational sums, differences, comparisons, and minima suffice, and their bit lengths remain polynomial. $\square$

4. Three finite structural descriptions

These descriptions will eliminate the infinite set quantifiers in a blocking proposal.

For an allocation $\rho$, define a directed graph $G_\rho$ on the types by putting an arc $t\to r$ whenever some real class $o$ satisfies
$$ \lambda(A_t\cap\bar\rho^{-1}(o))>0 \quad\text{and}\quad r\in R_o. $$
For $F\subseteq\{1,\ldots,\tau\}$, write
$$ A_F=\bigcup_{t\in F}A_t. $$

4.1 Minimal self-enforcement

Lemma 5. The minimal self-enforcing coalitions in $\rho$ are exactly the sets $A_F$ for which:

  • $F$ is a sink strongly connected component of $G_\rho$;
  • no positive mass of $A_F$ receives $o^*$.

Proof. A minimal self-enforcing coalition cannot contain positive null-assigned mass: atomlessness would provide a positive-mass proper null-only subcoalition, which is automatically self-enforcing.

Let $C$ be minimal, and let $F$ be the types wholly contained in $C$. Ownership by whole types gives
$$ \omega(C)=\omega(A_F). $$
Since $C$ receives real units and is self-enforcing, $F$ is nonempty. Also,
$$ \rho(A_F)\subseteq\rho(C)\subseteq\omega(A_F). $$
Thus $A_F$ is self-enforcing, and minimality forces $C=A_F$.

A union $A_F$ is self-enforcing precisely when no graph arc leaves $F$. If it contained more than one strongly connected component, the condensation graph on $F$ would have a proper sink component. That component would also have no outgoing arc in the full graph, contradicting minimality.

Conversely, suppose $F$ is a sink strongly connected component with no null-assigned mass. Then $A_F$ is self-enforcing. Any positive-mass self-enforcing $D\subsetneq A_F$ receives real units, hence wholly contains a nonempty set $T$ of owner types. As above, $A_T\subseteq D$ is self-enforcing, so no arc leaves $T$. Strong connectivity forbids a nonempty proper closed subset of $F$. Therefore $T=F$, contradicting properness of $D$. $\square$

4.2 Rectified neutrality

For every real class $o$, let $T_o$ be the types reachable from $R_o$ in $G_\mu$, including the starting types. Put $U_o=A_{T_o}$.

Lemma 6. Rectified neutrality is equivalent to the following tests, one for each class with $U_o\subseteq E$:
$$ \sigma(C\setminus U_o)\cap B_o\cap\mu(A\setminus C)=\varnothing. $$

Proof. Suppose $D\subseteq E$ is self-enforcing in $\sigma$ and controls $o$. It contains all types in $R_o$. Whenever it contains an entire type, that type’s class consumption is unchanged. Self-enforcement therefore forces inclusion of every owner type reached by an outgoing arc of $G_\mu$. Induction along paths gives $U_o\subseteq D$.

Conversely, if $U_o\subseteq E$, reachability makes $T_o$ closed under outgoing arcs. Unchanged class consumption then shows that $U_o$ is self-enforcing in $\sigma$ and controls $o$. It has positive mass because $R_o$ is nonempty. Original neutrality therefore implies the displayed test.

If original neutrality failed for some $D$, one of the finitely many classes $o$ controlled by $D$ would have a positive-mass violating intersection. Since $U_o\subseteq D\subseteq E$,
$$ \sigma(C\setminus D)\subseteq\sigma(C\setminus U_o), $$
so the displayed test for $o$ would fail. $\square$

4.3 Exclusion closure

For any measurable $D$, let
$$ F(D)=\{t:A_t\subseteq D\}. $$
For $S$ a set of real classes, write $B_S=\bigcup_{o\in S}B_o$.

Start with
$$ S^0=\{o:R_o\subseteq F(D)\}, $$
and iterate
$$ F^{k+1}=\{t:A_t\subseteq D\cup\mu^{-1}(B_{S^k})\}, \qquad S^{k+1}=\{o:R_o\subseteq F^{k+1}\}. $$

Lemma 7. These sets increase, stabilize after at most $m+1$ updates, and their stabilized value $S^\infty$ satisfies
$$ \Omega(D\mid\mu)=B_{S^\infty}. $$

Proof. The original coalition sequence increases, so its controlled-class sets increase. Because these class sets increase,
$$ D^{k+1}=D\cup\mu^{-1}(B_{S^k}). $$
This proves that the displayed recurrence reproduces the original closure. There are only $m$ real classes. Each nonstationary update adds a class; after a stationary update the recurrence remains stationary. $\square$

5. Polynomial-size descriptions of arbitrary blocks

Index $o^*$ by $0$. For a proposal $(C,\sigma)$ define the transition masses
$$ y_{t i c j} = \lambda\bigl( A_t\cap\bar\mu^{-1}(i)\cap\bar\sigma^{-1}(j)\cap C_c \bigr), $$
where $C_1=C$ and $C_0=A\setminus C$.

There are $2\tau(m+1)^2$ such variables. They satisfy
$$ y_{t i c j}\geq0,\qquad \sum_{c,j}y_{t i c j}=x_{t,i}, $$
and, for real $j$,
$$ \sum_{t,i,c}y_{t i c j}\leq q_j. $$

Coalition members weakly improve exactly when
$$ y_{t i 1 j}=0\qquad\text{whenever }i\succ_t j. $$
Positive-mass strict improvement is
$$ \sum_{t,i,j:\,j\succ_t i}y_{t i 1 j}>0. $$

The support of these variables means the set of coordinates that are strictly positive. The following information is determined solely by that support:

  • A type lies wholly in $C$ exactly when it has no positive coordinate with $c=0$.
  • A type lies wholly in $E$ exactly when all its positive coordinates have $c=1$ and $j=i$.
  • The set $E$ has positive mass exactly when some $y_{t i 1 i}$ is positive.
  • The graphs $G_\mu$ and $G_\sigma$ are determined by positive old-label and new-label consumption, respectively.

These assertions use $p_t>0$ and the row equations.

5.1 Refined exclusion

Self-enforcement of $E$ can be checked from support. Every positive coordinate $y_{t i 1 i}$ with real $i$ must satisfy
$$ R_i\subseteq F(E). $$

Minimal self-enforcement of $C$ can also be checked from support using Lemma 5: $C$ must consist exactly of whole types forming a null-free sink strongly connected component of $G_\sigma$.

For closure of $C$, the test
$$ A_t\subseteq C\cup\mu^{-1}(B_S) $$
is equivalent to
$$ \sum_{i\notin S,j}y_{t i 0 j}=0, $$
where $0\notin S$. This is determined by support.

For closure of $E$, its complement within an old-label cell has mass
$$ x_{t,i}-y_{t i 1 i} = \sum_{(c,j)\ne(1,i)}y_{t i c j}. $$
Thus the corresponding full-type test is again a zero test on a sum of nonnegative transition variables. Lemma 7 therefore computes both controlled-class sets from support.

Let those sets be $S_C,S_E$. Harmed agents’ old real units lie in $\Omega(C\mid\mu)$ exactly when every positive harmful transition with real old label $i$ satisfies $i\in S_C$. The disjointness condition for $E$ holds exactly when no such transition has $i\in S_E$.

Consequently, after fixing the support of $y$, every refined exclusion condition is a finite combinatorial check. The remaining conditions are linear equalities, weak inequalities, and strict positivity of the chosen coordinates.

5.2 Rectified blocking and distinguishable units

Rectified neutrality additionally refers to old unit identities. Three source categories per class suffice to record them:

  • units originally assigned outside $C$;
  • units originally assigned inside $C$;
  • originally unused units.

For real class $o$, their masses are
$$ u_{0,o}=\sum_{t,j}y_{t o 0 j},\qquad u_{1,o}=\sum_{t,j}y_{t o 1 j},\qquad u_{\mathrm u,o}=q_o-\sum_t x_{t,o}. $$

Introduce nonnegative variables $f_{s,t i c o}$, where $s\in\{0,1,\mathrm u\}$. Such a variable records the mass of class-$o$ units from source category $s$ assigned to the destination transition $(t,i,c,o)$. Require
$$ \sum_s f_{s,t i c o}=y_{t i c o} $$
and
$$ \sum_{t,i,c}f_{s,t i c o}\leq u_{s,o}. $$

These are polynomially many linear constraints.

Self-enforcement of $C$ requires every positive real destination $y_{t i 1 o}$ to satisfy
$$ R_o\subseteq F(C). $$

By Lemma 6, whenever $T_o\subseteq F(E)$, neutrality is precisely the requirement
$$ f_{0,t i 1 o}=0\qquad\text{for every }t\notin T_o. $$
Indeed, these are exactly the outside-coalition old units of $o$ assigned to $C\setminus U_o$.

After fixing the support of $y$ and $f$, these conditions are combinatorial checks followed by linear constraints.

5.3 Exactness of the description

Proposition 8. For either rule, a feasible matrix $x$ is blocked if and only if one of the support patterns described above passes its combinatorial checks and admits a solution of its linear constraints with exactly that support. This equivalence holds for every allocation realizing $x$.

Proof. A measurable proposal gives the transition masses $y$. In the rectified case, intersect each destination’s assigned units with the three old-unit source categories to obtain $f$. The preceding derivations show that all required checks and equations hold.

Conversely, fix an allocation $\mu$ realizing $x$ and a feasible solution of one valid support pattern. Partition each old-label set $A_t\cap\bar\mu^{-1}(i)$ into pieces of masses $y_{t i c j}$. Declare the pieces with $c=1$ to constitute $C$.

For refined exclusion, match each real-label destination to disjoint units of that class. The supply inequalities permit this.

For rectified blocking, first form the three actual source subsets of each $B_o$ using this $C$ and $\mu$. Their masses are exactly $u_{s,o}$. Partition enough of each source subset according to the flows $f$, and match those pieces to their designated destinations. The flow equalities and inequalities permit this matching. Assign label $0$ destinations the null object.

The constructed allocation has exactly the specified transitions and unit-source flows. Therefore all full-type tests, graph tests, closure tests, and neutrality tests hold exactly as checked. Positive strict improvement is also preserved. $\square$

In particular, the task’s requirement that a matrix admit *some* unblocked realization is equivalent to requiring that *every* realization be unblocked.

6. Blocking certificates and verification complexity

Theorem 9. Given a feasible rational matrix $x$, the existence of a block under either rule has a certificate whose bit length is polynomial in $m,\tau,L$ and the encoding length of $x$. Hence blockedness is in $\mathrm{NP}$ and stability is in $\mathrm{coNP}$.

Proof. Guess the support of the polynomially many variables $y$ and, when needed, $f$. Perform the graph, closure, self-enforcement, and neutrality checks described in Section 5. Each takes polynomial time.

For a passing support pattern, introduce a variable $\delta$ with
$$ 0\leq\delta\leq1. $$
Set absent coordinates to zero and require every coordinate declared positive to be at least $\delta$.

The resulting system has polynomially many variables and linear constraints. It has a solution with $\delta>0$ exactly when the support pattern has a blocking realization.

Every transition coordinate is at most $1$, because it is part of the population. Every flow coordinate is at most its destination transition mass. Thus the resulting feasible set, including $\delta$, is bounded and closed.

If a solution with $\delta>0$ exists, maximizing $\delta$ over this polytope gives a positive optimum attained at a vertex. At a vertex, sufficiently many independent active constraints determine all coordinates. Clear denominators in those constraints and apply Cramer’s rule. If their integer coefficients have at most $B$ bits and there are $d$ variables, determinants have at most
$$ O\bigl(d(B+\log d)\bigr) $$
bits, by the determinant expansion bound. Here $B$ and $d$ are polynomial in the supplied encoding lengths.

Therefore some certificate has polynomial bit length. A verifier checks its rational equations, inequalities, positivity, and combinatorial conditions in polynomial time. Proposition 8 makes this certificate equivalent to an actual measurable block. $\square$

7. Small stable matrices and a general finite algorithm

A short certificate of blocking does not alone bound the size of a stable matrix. The next argument supplies that missing step.

7.1 Projected blocking regions have small coefficients

Lemma 10. For fixed society data and a selected rule, the set of blocked feasible real matrices is a union of at most
$$ 2^{\operatorname{poly}(m,\tau,L)} $$
sets, each described by a conjunction of rational strict or weak linear inequalities in $x$. The coefficients in all these inequalities have polynomial bit length.

Proof. There are exponentially many supports of the polynomially many certificate variables. Discard the supports failing their combinatorial checks.

For one remaining support, use $\delta$ as in Theorem 9. After clearing denominators, write its closed linear constraints as
$$ A v\leq b+Bx+a\delta, $$
where $v$ contains the other certificate variables. Equalities are represented by two inequalities. There are polynomially many rows and columns, and all coefficients have polynomial bit length.

For fixed $(x,\delta)$, Farkas’ lemma states that this system is feasible if and only if
$$ \lambda^{\mathsf T}(b+Bx+a\delta)\geq0 $$
for every
$$ \lambda\geq0,\qquad A^{\mathsf T}\lambda=0. $$
Its hypotheses apply because this is a finite linear system and all variable restrictions have been included among its rows.

It suffices to use the extreme rays of the displayed cone. If $A$ has $k$ columns, an extreme ray has support of size at most $k+1$: on its support the nullspace must be one-dimensional, since otherwise the ray can be perturbed in two nonparallel feasible directions. Thus its support size minus one is at most $k$.

Each ray can be represented with integer coordinates given by minors after choosing independent equations on its support. Determinant bounds give polynomial bit length. There are at most exponentially many candidate supports, so at most exponentially many resulting inequalities in $(x,\delta)$, all with polynomial-size coefficients.

Finally eliminate $\delta$, retaining the requirement $\delta>0$. The inequalities with nonzero $\delta$ coefficient specify lower and upper bounds on $\delta$; those with zero coefficient remain unchanged. Feasibility requires each lower bound to be at most each upper bound, and every upper bound to be strictly positive. The bound $\delta\leq1$ ensures an upper bound is present. These conditions are sufficient as well: choose a positive number between the largest lower bound and the smallest upper bound.

Combining two bounds uses only products and sums of two polynomial-size coefficients, so coefficient lengths remain polynomial. This yields the asserted conjunction for one support. Taking the union over all supports proves the lemma. $\square$

7.2 Polynomial-size rational stable matrices
