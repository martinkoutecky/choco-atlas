The continuous mirror question, as graded

Given a finite set of provider types \(T\), rational masses \(\mu_t\), and rational piecewise-linear utilities \(u_t\) over vectors of accessible type mass, satisfying mass analogues of the common-ranking and limited-complementarity conditions, does there exist a measurable symmetric sharing relation \(W:\Omega^2\to\{0,1\}\) with no blocking measurable coalition of positive mass? If so, can one construct a finite description of such a relation, and with what complexity in \(|T|\), the input bit length, and the utility description size?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(T=\{1,\ldots,\tau\}\), with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types. Here \(m=\tau\) is the number of mass coordinates. Let \(\Omega=[0,1]\) with Lebesgue measure \(\lambda\), partitioned into consecutive type intervals \(\Omega_t\) of lengths \(\mu_t\).
Each type has a continuous, real-valued piecewise-linear utility \(u_t:B\to\mathbb R\), where \(B=\prod_s[0,\mu_s]\), specified by rational polyhedral cells and affine formulas agreeing on overlaps. Utilities incorporate fixed access to one's own data and all sharing costs; there are no payments or downstream externalities. Let \(K\) be the utility description size and \(L\) the total input bit length.
The supplied common ranking is \(1\succ\cdots\succ\tau\): for every \(t\), \(i<j\), \(a>0\), and \(x\in B\) with both additions feasible, \(u_t(x+a e_i)>u_t(x+a e_j)\), where \(e_i\) is the coordinate unit vector.
Limited complementarity means that whenever \(u_t(x+a e_i)<u_t(x)\) for a feasible \(a>0\), every nonzero \(y\geq0\) supported on \(\{i,\ldots,\tau\}\) with \(x+y\in B\) satisfies \(u_t(x+y)<u_t(x)\). These conditions are promises on the input.
An outcome is a measurable symmetric relation \(W:\Omega^2\to\{0,1\}\) with \(W(z,z)=0\). An agent \(z\in\Omega_t\) receives utility \(u_t(x_W(z))\), where \(x_W(z)_s=\int_{\Omega_s}W(z,w)\,d\lambda(w)\); sharing is bilateral, truthful, and has no capacity constraint.
A measurable coalition \(C\) with \(\lambda(C)>0\) may replace all links inside \(C\) and retain or delete its existing links to outsiders, but cannot add links to outsiders or change links between outsiders. It blocks if some resulting measurable symmetric \(W'\) weakly improves utility for almost every member of \(C\), and strictly improves utility on a positive-mass subset of \(C\). An outcome is strongly stable if no such coalition blocks.
For construction, a finite description means a Boolean formula of polynomial inequalities with rational coefficients in the two agent coordinates, defining \(W\) up to null sets; outcomes and deviations in the existence question remain unrestricted measurable relations.

Is deciding whether a strongly stable measurable sharing relation exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?
When one exists, can a strongly stable relation always be constructed with the stipulated finite description, and with what complexity in \(m,\tau,L,K\)?

For finite societies satisfying strict common ranking and limited complementarity, a strongly stable network exists and ordered match constructs one using \(O(N^2)\) preference comparisons. [Rasouli–Jordan](https://arxiv.org/pdf/2107.08630v2)
No result settling this exact atomless, piecewise-linear formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Specified an atomless Lebesgue society with consecutive type intervals and normalized total mass to one; set m equal to the number of supported type coordinates.
  • Specified continuous piecewise-linear utilities by explicit rational polyhedral cells and affine formulas; allowed signed net utilities and absorbed fixed own-data access and sharing costs into these utilities.
  • Made the undefined mass common-ranking condition precise using strict comparisons between equal positive mass additions of differently ranked types at every feasible base vector.
  • Made mass limited complementarity precise using arbitrary feasible positive mass additions and arbitrary nonzero additions supported on the rejected type and lower-ranked types.
  • Excluded zero additions from limited complementarity: the literal discrete quantification includes the empty set, which would incorrectly forbid any strictly harmful addition.
  • Restored coalition members' ability to retain or delete existing outsider links, while prohibiting new outsider links and changes between outsiders.
  • Interpreted coalition weak improvement almost everywhere and required strict improvement on positive mass, so null agents cannot supply the strict-improvement witness.
  • Specified finite output descriptions as rational polynomial-inequality formulas, without restricting the measurable outcomes quantified over by the existence question.
  • Treated the ranking and complementarity conditions as input promises and retained indifference in coalition weak-improvement comparisons.

Result

Every instance satisfying the stated promises admits a strongly stable measurable relation. Thus the promised existence problem is in \(\mathrm P\): its answer is always yes.

A stable relation can be constructed using \(O(\tau^2)\) utility comparisons and polynomial bit complexity in \(m,\tau,L,K\). Moreover, the construction uses only complete or empty type blocks, so it has the stipulated finite description.

The proof below addresses unrestricted measurable coalitions and deviations. The finite ordered-match result in [Rasouli–Jordan, Proposition 3.1](https://arxiv.org/pdf/2107.08630v2) motivates the ordering, but is not needed as a theorem.

1. A consequence of continuity and limited complementarity

We first prove the property that permits adding an entire type block at once.

Lemma 1. Let \(f:[0,b]\to\mathbb R\) be continuous and satisfy the following implication: if \(f(s)<f(r)\) for \(0\leq r<s\leq b\), then \(f(q)<f(r)\) for every \(r<q\leq b\). If \(f(b)\geq f(0)\), then \(f\) is nondecreasing on \([0,b]\).

Proof. Suppose instead that \(f(s)<f(r)\) for some \(r<s\). The implication gives \(f(b)<f(r)\).

Choose \(h\) strictly between \(f(b)\) and \(f(r)\). Since \(f(0)\leq f(b)<h<f(r)\), continuity gives \(c\in(0,r)\) with \(f(c)=h\). But \(f(b)<f(c)\), so the implication applied at \(c\) gives \(f(r)<f(c)=h\), contradicting \(f(r)>h\). \(\square\)

For any type \(t\), feasible base vector \(x\), and coordinate \(s\), limited complementarity supplies the implication in Lemma 1 for the function \(f(q)=u_t(x+q e_s)\). Consequently,

\[ u_t(x+b e_s)\geq u_t(x) \quad\Longrightarrow\quad q\longmapsto u_t(x+q e_s) \text{ is nondecreasing on }[0,b]. \]

Here and below, this uses the promise for every feasible addition size, not just infinitesimal additions.

2. Two comparison lemmas

Fix a utility \(u\) satisfying the common-ranking promise.

An elementary transfer moves an amount \(h>0\) from coordinate \(j\) to coordinate \(i<j\), keeping the resulting vector feasible. Such a transfer strictly increases utility. Indeed, if the original vector is \(v\), apply common ranking at the base \(v-h e_j\):

\[ u(v-h e_j+h e_i)>u(v). \]

We will also use a path that fills prescribed coordinate amounts in ranking order.

Let \(a\in B\), let \(S=\sum_s a_s\), and define, for \(0\leq D\leq S\),

\[ P_a(D)_s = \min\left\{a_s,\, \max\left\{0,D-\sum_{h<s}a_h\right\}\right\}. \]

Thus \(P_a(D)\) allocates total mass \(D\) to the earliest coordinates first, with coordinate bounds \(a_s\).

Assume that filling the coordinates successively from zero to \(a\) gives a nondecreasing utility path. Equivalently, utility is nondecreasing along each coordinate segment of this path. Then

\[ u(P_a(D))\leq u(a) \qquad(0\leq D\leq S). \]

Lemma 2: deletions cannot improve utility. Under this path assumption, every \(v\) with \(0\leq v\leq a\) satisfies \(u(v)\leq u(a)\).

Proof. Put \(D=\sum_s v_s\). Transform \(v\) into \(P_a(D)\) by elementary transfers.

To verify that this is possible, scan coordinates in increasing order. Once earlier coordinates match their target values, let \(R\) be the remaining total mass. The current coordinate is at most both \(a_s\) and \(R\), hence at most its target \(\min\{a_s,R\}\). Any deficit can therefore be supplied from later coordinates. Each transfer preserves feasibility and increases utility.

The procedure terminates after finitely many transfers, giving

\[ u(v)\leq u(P_a(D))\leq u(a). \]

\(\square\)

Lemma 3: rejecting a suffix survives deletions. Suppose additionally that \(a_s=0\) for all \(s\geq r\), and that

\[ u(a+y)<u(a) \]

for every feasible nonzero \(y\geq0\) supported on \(\{r,\ldots,\tau\}\). If \(v\in B\) satisfies

\[ v_s\leq a_s\quad(s<r), \qquad \sum_{s\geq r}v_s>0, \]

then \(u(v)<u(a)\).

Proof. Write \(D=\sum_s v_s\) and \(S=\sum_s a_s\).

If \(D\leq S\), transform \(v\) into \(P_a(D)\) by the same increasing-coordinate procedure. Since \(v\) has positive mass in the suffix and \(P_a(D)\) has none, at least one transfer occurs. Therefore

\[ u(v)<u(P_a(D))\leq u(a). \]

If \(D>S\), the suffix contains enough mass to fill every deficit in the earlier coordinates: its mass is \(D-\sum_{s<r}v_s\), whereas those deficits total \(S-\sum_{s<r}v_s\). Transfer mass from the suffix to fill them. The resulting vector is \(a+y\), with nonzero \(y\) supported on the suffix. Thus

\[ u(v)\leq u(a+y)<u(a). \]

\(\square\)

3. Construction by ordered type blocks

Maintain a symmetric matrix \(A\in\{0,1\}^{\tau\times\tau}\), initially zero, and vectors \(d_t=0\).

Process pairs \((i,j)\) with \(1\leq i\leq j\leq\tau\) in lexicographic order.

  • For \(i<j\), add the complete block between types \(i\) and \(j\) precisely when both comparisons hold:

\[ u_i(d_i+\mu_j e_j)\geq u_i(d_i), \qquad u_j(d_j+\mu_i e_i)\geq u_j(d_j). \]

If added, set \(A_{ij}=A_{ji}=1\) and update the two vectors accordingly.

  • For \(i=j\), add the complete block within type \(i\) precisely when

\[ u_i(d_i+\mu_i e_i)\geq u_i(d_i). \]

If added, set \(A_{ii}=1\) and update \(d_i\).

All tested additions are feasible: the tested coordinate has not previously been processed for that type and is still zero.

For each fixed type \(t\), its potential partners are processed in the order \(1,\ldots,\tau\). Every accepted coordinate segment has a weakly improving endpoint, so Lemma 1 makes that entire segment nondecreasing. The final vector \(d_t\) therefore satisfies the path assumption of Lemma 2.

There is one further invariant.

Rejection invariant. Suppose type \(t\) rejects partner type \(r\) at its current vector \(p\), meaning

\[ u_t(p+\mu_r e_r)<u_t(p). \]

Then its final vector is \(d_t=p\), and every feasible nonzero suffix addition at \(p\) strictly lowers utility.

Proof. At this moment, \(p_s=0\) for \(s\geq r\). Limited complementarity gives

\[ u_t(p+y)<u_t(p) \]

for every feasible nonzero \(y\) supported on \(\{r,\ldots,\tau\}\). Every subsequent proposed addition uses a coordinate in this suffix. It is therefore rejected, and the vector remains \(p\). \(\square\)

Define the outcome by

\[ W(z,w)=A_{ij} \quad\text{for }z\in\Omega_i,\ w\in\Omega_j,\ z\neq w, \]

and set \(W(z,z)=0\). This relation is measurable and symmetric. Every type-\(t\) agent has mass vector \(d_t\), up to irrelevant boundary conventions.

4. Stability against arbitrary measurable coalitions

Suppose, toward a contradiction, that a measurable coalition \(C\) blocks through a feasible measurable deviation \(W'\). Write \(v(z)=x_{W'}(z)\).

Let \(E\) be the set of added edges:

\[ E=\{(z,w):W(z,w)=0,\ W'(z,w)=1\}. \]

Feasibility of the deviation implies \(E\subseteq C\times C\), apart from any irrelevant null sets.

If \(E\) has product measure zero, Fubini’s theorem implies \(v(z)\leq d_t\) for almost every \(z\in\Omega_t\). Lemma 2 then gives

\[ u_t(v(z))\leq u_t(d_t) \]

almost everywhere. There can be no positive-mass set of strictly improving coalition members.

Hence \(E\) has positive product measure. Choose the lexicographically earliest unordered type pair \((i,j)\), with \(i\leq j\), whose added-edge set has positive product measure. By symmetry, either orientation of a cross-type block has the same measure.

This was an empty block in \(W\), so at least one endpoint type strictly rejected it during construction. Denote a rejecting endpoint by \(t\), and its partner by \(r\). The rejection invariant says that \(d_t\) is supported on coordinates below \(r\), and strictly rejects every nonzero suffix addition.

We now check that almost every type-\(t\) coalition member satisfies

\[ v(z)_s\leq d_{t,s}\qquad(s<r). \]

For every such \(s\), the pair connecting types \(t\) and \(s\) precedes the chosen pair:

  • If \(t=i\) and \(r=j\), the pair is \((s,i)\) when \(s<i\), and \((i,s)\) when \(i\leq s<j\).
  • If \(t=j\) and \(r=i\), it is \((s,j)\), with \(s<i\).
  • The self-block case is covered by the same reasoning.

Thus its added-edge set has measure zero. Fubini’s theorem gives no increase in that coordinate for almost every relevant agent. Existing links may only be retained or deleted.

On the other hand, positive added-edge measure in the chosen block implies that a positive-mass subset of \(C\cap\Omega_t\) satisfies \(v(z)_r>0\). For almost every member of that subset, Lemma 3 applies and yields

\[ u_t(v(z))<u_t(d_t). \]

This contradicts the coalition’s required weak improvement almost everywhere. Therefore \(W\) is strongly stable.

5. Finite description and complexity

Let \(b_0=0\) and \(b_t=\sum_{s\leq t}\mu_s\). These endpoints are rational.

Take \(I_t=[b_{t-1},b_t)\) for \(t<\tau\), and \(I_\tau=[b_{\tau-1},1]\). A formula defining the constructed relation is

\[ (z-w)^2>0 \quad\land\quad \bigvee_{\substack{1\leq i,j\leq\tau\\A_{ij}=1}} \bigl(z\in I_i\ \land\ w\in I_j\bigr). \]

Interval membership is expressible by rational polynomial inequalities and Boolean operations. The formula is symmetric and enforces a zero diagonal. It uses \(O(\tau^2)\) atomic inequalities and has \(O(\tau^2L)\) bits as a conservative bound.

There are \(\tau(\tau+1)/2\) processed pairs and \(O(\tau^2)\) utility evaluations or comparisons. Each evaluation occurs at a vertex of \(B\), with coordinates in \(\{0,\mu_s\}\).

For explicitly listed cells given by rational linear inequalities, evaluation consists of locating a containing cell and evaluating its affine formula. This takes \(O(K)\) rational arithmetic operations by direct scanning. Formulas agree on overlaps, so boundary points pose no ambiguity. All intermediate rational numbers have polynomial bit length in \(L+m\). A conservative elementary-arithmetic bound, including writing the output, is

\[ O\!\left(\tau^2K(L+m)^3+\tau^2L\right) \]

bit operations. More generally, standard rational polyhedral representations give the representation-independent statement \(O(\tau^2\operatorname{poly}(m,K,L))\).

Thus, with \(m=\tau\), construction is polynomial in the stated input parameters. The existence decision on the promised domain simply returns yes; no verification of the promises is required.

The transfer argument correctly applies strict common ranking. At the base \(v-h e_j\), both additions are feasible, and their resulting vectors are precisely the original vector and the transferred vector.

The transfer procedure in Lemma 2 is valid. After earlier coordinates have reached their targets, the remaining mass determines the current target. Because the current coordinate is bounded by both its capacity and the remaining mass, any discrepancy is a deficit that can be supplied from later coordinates. Consequently, every vector obtained solely by deleting received mass has utility at most \(u(a)\).

Both cases are correct.

When \(D>S\), the suffix mass exceeds the total earlier-coordinate deficit. Filling those deficits leaves a feasible, nonzero suffix vector \(y\). The assumed strict rejection of \(a+y\), together with the transfer comparison, establishes \(u(v)<u(a)\).

There is no missing case at \(D=S\): it belongs to the first case, where positive suffix mass still requires a transfer.

All subsequent proposals for that type lie in the same suffix. None can be accepted, so its vector remains unchanged. This establishes the rejection invariant without assuming that the other endpoint also rejects.

The resulting block relation is measurable, symmetric, and zero on the diagonal. Removing the diagonal changes no received mass.

Positive added-edge measure in the selected block supplies a positive-mass subset of rejecting-type coalition members receiving positive mass in the rejected coordinate. The rejection invariant and Lemma 3 then show that almost every member of this subset strictly loses utility.

This contradicts the coalition’s required weak improvement almost everywhere. The argument covers arbitrary measurable deviations; it does not impose a block structure on them.
