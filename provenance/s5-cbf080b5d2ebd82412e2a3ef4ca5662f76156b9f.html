The continuous mirror question, as graded

Given \(m\) alternatives and a sparse distribution \(\mu\) over complete rankings, with binary-rational masses summing to \(1\), compute the paper’s MFP refinement of the Borda co-winner set. Let \(G_\mu=\{\sigma\in S_m:\sigma\cdot\mu=\mu\}\), \(W_B(\mu)\) be the Borda co-winners, and \(F(\mu)=\{c\in W_B(\mu):\sigma(c)=c\text{ for every }\sigma\in G_\mu\}\). Choose a permutation \(\sigma^*\) maximizing the relabelled histogram \(\sigma\cdot\mu\) lexicographically; if \(F(\mu)\ne\varnothing\), return its candidate whose image under \(\sigma^*\) is highest under the fixed priority order, and otherwise return the highest-priority Borda co-winner.

Packaged proof task (what the prover saw — nothing else)

Let \(A=\{1,\ldots,m\}\), with \(m\ge 2\), and fix the priority order \(1\succ\cdots\succ m\). Types are strict complete rankings of \(A\).
A society is given by its support: the list of the \(\tau\) distinct types with positive mass, each mass a binary rational, summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length. Unlisted rankings have mass zero.
Let \(W_B(\mu)\) be the Borda co-winner set, with scores weighted by the masses.
For a candidate permutation \(\sigma\in S_m\), relabel every candidate in each ranking and define \((\sigma\cdot\mu)(R)=\mu(\sigma^{-1}(R))\). Set \(G_\mu=\{\sigma\in S_m:\sigma\cdot\mu=\mu\}\) and \(F(\mu)=\{c\in W_B(\mu):\forall\sigma\in G_\mu,\ \sigma(c)=c\}\).
Order all ranking coordinates lexicographically using the fixed candidate priority, highest-priority ranking first. Compare mass histograms lexicographically in that coordinate order, favoring larger mass at the first differing coordinate.
Choose any \(\sigma^*\in\arg\max_{\sigma\in S_m}(\sigma\cdot\mu)\). The MFP refinement returns the candidate \(c\in F(\mu)\) whose image \(\sigma^*(c)\) has highest priority when \(F(\mu)\ne\varnothing\); otherwise it returns the highest-priority candidate in \(W_B(\mu)\). The choice among maximizing permutations does not affect this output.

Is computing this MFP refinement solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

Known results: For finite profiles of complete rankings, MFP tie-breaking with a polynomial-time backup is polynomial-time computable, hence so is its Borda refinement ([Xia, Most Equitable Voting Rules](https://arxiv.org/abs/2205.14838)).
Later work gives quasipolynomial-time canonical-labeling tie-breaking for broader preference domains, using a different refinement ([Xia, Computing Most Equitable Voting Rules](https://arxiv.org/html/2410.04179v1)). No result specifically settling the binary-rational mass problem above was located.

  • Fixed the unspecified candidate priority to the order from candidate 1 through candidate m, as permitted by the discrete definition.
  • Specified that histogram coordinates include all rankings, with unlisted rankings assigned zero mass, and use the lexicographic extension of candidate priority with larger masses favored.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Computing the stated MFP refinement is deterministic polynomial-time solvable in \(m,\tau,L\). The essential fact is that a complete ranking uniquely determines the permutation sending it to \(1\succ\cdots\succ m\). Consequently, at most \(\tau\) permutations need consideration.

This is the normalization principle used in Xia’s finite-profile algorithm. Below is a direct proof that also controls the bit complexity for sparse binary-rational masses. [Xia, Algorithm 1 and its preceding explanation](https://arxiv.org/html/2205.14838v3#S5)

1. Exact arithmetic without expanding the society

Write the input as distinct rankings \(R_1,\ldots,R_\tau\), with masses \(\mu(R_i)=p_i/q_i>0\), where the numerators and denominators are binary integers. Define

\(D=\prod_{i=1}^{\tau}q_i,\qquad w_i=p_i(D/q_i).\)

Then each \(w_i\) is a positive integer, and \(\sum_i w_i=D\). Let \(h\) be the sparse integer histogram with \(h(R_i)=w_i\) and zero elsewhere. Thus \(h=D\mu\).

Multiplication by the positive constant \(D\) preserves histogram comparisons and stabilizers. It also scales every Borda score by \(D\), preserving the co-winner set. We may therefore perform every computation using \(h\).

The binary length of \(D\) is at most one plus the sum of the binary lengths of the denominators, hence is \(O(L)\). Since \(w_i\leq D\), each weight also has \(O(L)\) bits. Computing these integers takes polynomial time; no profile of \(D\) individual voters is constructed.

2. Enumerating all maximizing permutations

Let \(R^\circ=(1,\ldots,m)\), the first ranking coordinate in the specified order, and put \(w_{\max}=\max_i w_i\).

For each ranking \(R_i=(a_{i1},\ldots,a_{im})\) of weight \(w_{\max}\), define the permutation \(\alpha_i\) by

\(\alpha_i(a_{ik})=k\quad\text{for every }k\in\{1,\ldots,m\}.\)

Because \(R_i\) contains every candidate exactly once, this defines a unique permutation, and \(\alpha_i(R_i)=R^\circ\).

Lemma. Every permutation maximizing the histogram belongs to
\(C=\{\alpha_i:w_i=w_{\max}\}\).

Proof. For any permutation \(\sigma\), the first coordinate is

\((\sigma\cdot h)(R^\circ)=h(\sigma^{-1}(R^\circ))\leq w_{\max}.\)

The value \(w_{\max}\) is attainable, since
\((\alpha_i\cdot h)(R^\circ)=w_{\max}\) whenever \(w_i=w_{\max}\).

A maximizing permutation must attain this value: otherwise one of these \(\alpha_i\) produces a strictly larger histogram already at its first coordinate. Hence \(\sigma^{-1}(R^\circ)=R_i\) for some maximum-weight input ranking. Equivalently, \(\sigma(R_i)=R^\circ\), which uniquely forces \(\sigma=\alpha_i\). This proves the lemma.

In particular, \(|C|\leq\tau\). Comparing the histograms produced by these permutations therefore suffices to find all global maximizing permutations.

For completeness, these comparisons do not require listing the \(m!\) coordinates. Represent \(\alpha_i\cdot h\) by the pairs

\((\alpha_i(R_j),w_j),\quad j\in\{1,\ldots,\tau\},\)

sorted by ranking priority. Relabeling is bijective, so these rankings remain distinct.

To compare two such lists, merge them in coordinate order. A ranking occurring in only one list has positive weight there and zero in the other. A ranking occurring in both has the two listed weights. Stop at the first unequal pair of weights. Coordinates outside the union of the two supports are zero in both histograms, so omitting them cannot affect the comparison.

Let \(\mathcal M\) be the nonempty set of maximizing permutations obtained this way, and choose \(\sigma_0\in\mathcal M\).

3. Recovering the stabilizer and fixed candidates

The maximizing permutations determine the entire stabilizer:

\(G_\mu=\{\sigma_0^{-1}\eta:\eta\in\mathcal M\}.\)

Here permutation multiplication means composition, with the rightmost permutation applied first.

Proof. The histogram order is total, so all maximizing permutations produce the same histogram. Thus, for every \(\eta\in\mathcal M\),

\((\sigma_0^{-1}\eta)\cdot h =\sigma_0^{-1}\cdot(\eta\cdot h) =\sigma_0^{-1}\cdot(\sigma_0\cdot h) =h.\)

Hence \(\sigma_0^{-1}\eta\in G_\mu\).

Conversely, if \(\gamma\in G_\mu\), then

\((\sigma_0\gamma)\cdot h=\sigma_0\cdot h.\)

Therefore \(\sigma_0\gamma\) is a global maximizing permutation. The preceding lemma guarantees that it was included in our enumeration, so \(\sigma_0\gamma\in\mathcal M\). Consequently, \(\gamma=\sigma_0^{-1}(\sigma_0\gamma)\), proving the reverse inclusion.

It follows that a candidate \(c\) is fixed by every stabilizer permutation exactly when

\(\eta(c)=\sigma_0(c)\quad\text{for every }\eta\in\mathcal M.\)

Indeed, this equality is equivalent to
\((\sigma_0^{-1}\eta)(c)=c\), and the permutations \(\sigma_0^{-1}\eta\) exhaust \(G_\mu\).

This criterion also proves the asserted independence of the maximizing permutation: every \(\eta\in\mathcal M\) gives the same image to each candidate fixed by \(G_\mu\).

4. Computing the refinement and bounding its running time

For each candidate \(c\), let \(\operatorname{pos}_{R_i}(c)\) be its position in \(R_i\), starting at \(1\). Compute the integer Borda score

\(B(c)=\sum_{i=1}^{\tau}w_i\bigl(m-\operatorname{pos}_{R_i}(c)\bigr).\)

The original weighted score is \(B(c)/D\), so \(W_B(\mu)\) is exactly the set of candidates maximizing \(B(c)\).

Using the criterion proved above, compute

\(F(\mu)=\{c\in W_B(\mu):\eta(c)=\sigma_0(c)\text{ for every }\eta\in\mathcal M\}.\)

If this set is empty, return \(\min W_B(\mu)\), as required by the backup rule. Otherwise return the unique candidate in \(F(\mu)\) minimizing \(\sigma_0(c)\). Uniqueness follows from the injectivity of \(\sigma_0\). This is precisely the specified MFP refinement.

There are at most \(\tau\) candidate permutations. For each one, relabeling its support takes \(O(\tau m)\) operations, and sorting takes \(O(\tau m\log(2\tau))\) operations: comparing two rankings examines at most \(m\) entries. Comparing two sorted histograms takes \(O(\tau m)\) operations. Thus the enumeration and comparison stage uses

\(O\!\left(\tau^2m\log(2\tau)\right)\)

operations. Computing Borda scores and checking fixed candidates each require \(O(\tau m)\) additional operations.

All weights have \(O(L)\) bits. Moreover,
\(0\leq B(c)\leq(m-1)D\), so the scores have \(O(L+\log m)\) bits. Exact arithmetic on these integers, including the initial denominator conversion, has polynomial bit complexity. Therefore the entire algorithm runs in polynomial time in \(m,\tau,L\).
