Classification

For every fixed \(Q\) in the stated class, exact computation of \(\Phi\) is:

  • in \(\mathsf{FP}\) if \(Q\) is equivalent on all ABoxes to a safe UCQ;
  • \(\#\mathsf{P}\)-hard under polynomial-time Turing reductions otherwise.

In fact, the weighted-vector problem and discrete single-assertion Shapley computation for \(Q\) are polynomial-time Turing equivalent. The hardness already holds for \(\tau=1\) and \(\mu_1=1\).

Applicable discrete theorem

Let \(\operatorname{SVC}_Q\) denote the problem whose input is a partitioned ABox \(A=X\uplus E\) and a designated assertion \(e\in E\), and whose output is the ordinary Shapley value of \(e\) for the game specified in the question.

Theorem 9 of Bienvenu, Figueira, and Lafourcade gives the stated safe-UCQ/\(\#\mathsf{P}\)-hard dichotomy for \(\operatorname{SVC}_Q\). Its hypotheses match the task: an \(\mathcal{ELHI}_{\bot}\) ontology, a connected constant-free homomorphism-closed Boolean query, unary and binary ABox assertions, and arbitrary exogenous assertions. The paper uses standard names and defines entailment on inconsistent knowledge bases by truth in every model, so inconsistency entails every Boolean query. Its unrestricted rewriting notion quantifies over all ABoxes. [Definitions and Theorem 9](https://proceedings.kr.org/2024/15/kr2024-0015-bienvenu-et-al.pdf).

We use this theorem as the supplied discrete result and prove the transfer below.

Exact output has polynomial length

Write \(n_t=|E_t|\) and define
\(f_t(S)=\mathbf{1}[(X_t\cup S,T)\models q]\).
Then \(v_t(S)=f_t(S)-f_t(\varnothing)\), so for every \(e\in E_t\) and \(S\subseteq E_t\setminus\{e\}\),

\(v_t(S\cup\{e\})-v_t(S)=f_t(S\cup\{e\})-f_t(S)\).

Entailment is monotone under adding assertions: every model of the larger knowledge base is a model of the smaller one. This remains true when the larger knowledge base is inconsistent, since its model set is empty. Consequently, every marginal contribution above belongs to \(\{0,1\}\).

For \(n_t\geq 1\), the permutation definition of the Shapley value therefore gives

\(\operatorname{Sh}(E_t,v_t,e)=K_{t,e}/n_t!\),

where \(K_{t,e}\) is the number of permutations in which \(e\) has marginal contribution \(1\). In particular,
\(0\leq K_{t,e}\leq n_t!\).

Write the explicitly encoded rational mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\). Then

\(\Phi_{t,e}=a_tK_{t,e}/(b_tn_t!)\).

Because \(\sum_t\mu_t=1\) and all masses are positive, \(a_t\leq b_t\). If \(\lambda_t\) is the binary encoding length of \(\mu_t\), both numerator and denominator in this representation have bit length

\(O(\lambda_t+n_t\log(n_t+1)+1)\).

Indeed, \(n_t!\leq(n_t+1)^{n_t}\). Reducing the fraction cannot increase either length.

There are \(\sum_t n_t\leq m\) coordinates. Their combined numerical encoding length is therefore

\(O\!\left(\sum_t n_t\lambda_t+\sum_t n_t^2\log(n_t+1)+m\right) =O(mL+m^2\log(m+1)+m)\).

Coordinate labels, if included, also require only polynomial space. Types with \(E_t=\varnothing\) contribute no coordinates.

Tractable branch and running time

Suppose \(Q\) has a safe UCQ rewriting on all ABoxes. By the discrete theorem, fix an exact scalar algorithm for \(\operatorname{SVC}_Q\). Let \(p_Q(s)\) be a nondecreasing polynomial bounding its bit running time on inputs of length at most \(s\), including output as a reduced rational. Such a polynomial exists because \(Q\) is fixed.

For each explicitly listed type \(t\) and each \(e\in E_t\):

  • Run the scalar algorithm on \((X_t,E_t,e)\).
  • Multiply its output by \(\mu_t\).
  • Reduce and output the resulting fraction.

The scalar input is exactly the local game: the ontology and \(X_t\) are fixed throughout that game, and only \(E_t\) supplies players. Hence the output of this procedure is precisely \(\Phi\).

Each scalar input has length \(O(L+1)\), and there are at most \(m\) calls. Set

\(B=L+m\log(m+1)+1\).

The preceding length bound shows that each multiplication and fraction reduction operates on \(O(B)\)-bit integers. Elementary binary arithmetic gives a conservative \(O(B^3)\) bound per coordinate, including Euclidean fraction reduction. Thus the total bit running time is

\(O\!\left(L+\tau+m\,p_Q(c(L+1))+m\bigl(L+m\log(m+1)+1\bigr)^3\right)\),

for a fixed encoding constant \(c\).

Since explicit listing implies \(m+\tau=O(L)\), this is polynomial in \(L\). No enumeration of unlisted possible types is involved.

Hard branch and equivalence

Conversely, take any scalar instance \((X,E,e)\) of \(\operatorname{SVC}_Q\). Construct a society with exactly one listed type:

\(\tau=1,\quad X_1=X,\quad E_1=E,\quad \mu_1=1\).

This is a valid input, and its designated coordinate satisfies

\(\Phi_{1,e}=\operatorname{Sh}(E,v,e)\).

The construction increases input length only by encoding overhead. The full vector has polynomial length by the bound proved above, so its designated coordinate can be extracted in polynomial time. Thus one weighted-vector oracle call computes the scalar answer.

This establishes
\(\operatorname{SVC}_Q\leq_{\mathrm T}^{\mathrm P}\operatorname{Vector}_Q\).
The coordinatewise procedure in the preceding section also establishes
\(\operatorname{Vector}_Q\leq_{\mathrm T}^{\mathrm P}\operatorname{SVC}_Q\);
its arithmetic overhead is polynomial independently of scalar tractability.

If \(Q\) has no safe UCQ rewriting on all ABoxes, the discrete theorem makes \(\operatorname{SVC}_Q\) \(\#\mathsf{P}\)-hard. Composing its hardness reduction with the one-type construction proves the required hardness of \(\operatorname{Vector}_Q\), completing the classification.

\[ v_t(S\cup\{e\})-v_t(S) = f_t(S\cup\{e\})-f_t(S) \]
follows by cancellation of the same baseline term. Consequently, the scalar problem computes exactly the marginal contributions required by the task.

Entailment is monotone under adding assertions because the model set can only shrink. This argument also applies when either knowledge base is inconsistent. Since \(f_t\) is Boolean-valued, every marginal contribution is either zero or one.

In particular, if the exogenous knowledge base already entails the query, every coalition entails it and all local Shapley values are zero. This edge case is covered by the argument.

\[ \operatorname{Sh}(E_t,v_t,e)=\frac{K_{t,e}}{n_t!}, \qquad 0\leq K_{t,e}\leq n_t! \]
is correct. This is a representation bound; it does not assert that the factorial is the reduced denominator.

Types with no endogenous assertions have no required coordinates, so there is no missing designated-player case at \(n_t=0\).

\[ \Phi_{t,e}=\frac{a_tK_{t,e}}{b_tn_t!}. \]
