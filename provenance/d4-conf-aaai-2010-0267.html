The continuous mirror question, as graded

An I-flip worsens one feature \(X\) and changes an arbitrary nonempty set of features less important than \(X\), leaving all other features fixed; the changes to those less important features are unrestricted.

Can \(p\) be computed exactly in polynomial time in \(m,\tau,L\), or is this computation NP-hard? Is deciding \(p\ge q\) in P, or is it NP-hard?

Result

Exact computation of \(p\) is \(\mathrm{NP}\)-hard, and deciding \(p\ge q\) is \(\mathrm{NP}\)-hard. Both statements hold already for \(\tau=1\), binary domains, and TCP-nets with no importance edges. Consequently, polynomial-time algorithms in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

Here, hardness of exact computation means that an exact-value algorithm would solve an \(\mathrm{NP}\)-hard decision problem through one evaluation and a comparison.

1. The individual dominance problem used in the reduction

We use the following established theorem: dominance testing is \(\mathrm{NP}\)-complete for complete binary CP-nets whose dependency graph is acyclic and has at most one directed path between any two features. These networks have explicitly specified conditional preference tables. See [Boutilier et al., Theorem 15](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume21/boutilier04a.pdf).

For these networks, dominance of \(\alpha\) over \(\beta\) is equivalent to an improving-flip sequence from \(\beta\) to \(\alpha\), by the same paper’s soundness and completeness theorems, Theorems 7–8.

This is also equivalent to a worsening-flip sequence from \(\alpha\) to \(\beta\) under the question’s source-evaluated semantics. Indeed, a single-feature flip leaves that feature’s parents unchanged, because parents exclude the feature itself. Thus its conditional preference order is identical at both endpoints. Reversing an improving flip therefore gives a legal worsening flip, and conversely.

We may restrict the source problem to distinct outcomes: equal-outcome strict-dominance queries are automatically negative and can be replaced by a fixed negative query with distinct outcomes.

2. Verification of the acyclicity promise

Let \(C\) be any complete CP-net with an acyclic dependency graph. Regard \(C\) as a TCP-net with no importance edges. Its worsening moves are exactly its V-flips, since no I-flip is available.

Choose a topological ordering \(Y_1,\ldots,Y_m\) of its features. For an outcome \(o\), define \(r_i(o)\) as the position of \(o[Y_i]\) in the conditional order evaluated at \(o\), numbering positions from zero, with zero most preferred. Define the rank vector \(R(o)=(r_1(o),\ldots,r_m(o))\).

Suppose a worsening flip changes \(Y_k\), taking \(o\) to \(o'\).

  • For every \(i<k\), both \(Y_i\) and all its parents remain unchanged: every parent precedes \(Y_i\) in the topological ordering. Hence \(r_i(o')=r_i(o)\).
  • All parents of \(Y_k\) also remain unchanged. The flip chooses a strictly less preferred value in this unchanged conditional order, so \(r_k(o')>r_k(o)\).

Consequently, \(R(o')\) is strictly larger than \(R(o)\) in lexicographic order. This strict order cannot increase around a directed cycle. Therefore the entire worsening-move graph is acyclic.

Thus every source instance used below satisfies the promised outcome-graph acyclicity, rather than merely dependency-graph acyclicity.

3. Reduction to the explicit-support society

Given a source dominance instance \((C,\alpha,\beta)\), construct the society containing just the type \(N_1=C\), interpreted as above, with \(\tau=1\) and \(\mu_1=1\). Set \(q=1\).

This construction copies the domains, parent sets, conditional tables, and outcomes, and adds empty importance data and constant-size rational data. It takes polynomial time in the source bit length and produces polynomial total bit length \(L\). The domains remain binary, the network remains complete, and the promise holds by Section 2.

For the constructed instance, \(p=1\) if \(\alpha\succ_{N_1}\beta\), and \(p=0\) otherwise. Hence \(p\ge1\) holds exactly when the source dominance query is positive.

This proves \(\mathrm{NP}\)-hardness of the threshold problem by a polynomial-time many-one reduction. It also proves hardness of exact computation: compute \(p\) once and test whether the result equals one.

The degenerate threshold \(q=0\) is always accepted, but hardness holds at the fixed threshold \(q=1\).

4. Running times and the role of explicit support

For completeness, a finite exhaustive algorithm exists. Put \(S=\prod_{i=1}^{m}|D_i|\), the number of outcomes.

For each listed type, enumerate all ordered pairs of outcomes and test whether each pair forms a legal move. This test takes polynomial time in \(m,L\): evaluate the explicit tables at the source, determine the changed coordinates, and check either the V-flip condition or each possible distinguished feature for an I-flip. Reachability in the resulting explicit graph then determines whether that type contributes its mass.

The resulting exact algorithm has running time \(O(\tau S^2\operatorname{poly}(m,L))\). Since domains are explicitly listed, \(|D_i|\le L\), giving the bound \(O(\tau L^{2m}\operatorname{poly}(m,L))\).

Once the dominance indicators are known, rational aggregation takes only polynomial time in \(\tau,L\). To verify the bit-size bound, write \(\mu_j=a_j/b_j\) and use \(B=\prod_j b_j\) as a common denominator. Its bit length is at most the sum of the denominator bit lengths, hence \(O(L)\). The numerator of any selected mass sum is between zero and \(B\), because the masses are positive and sum to one. Exact addition and comparison with \(q\) therefore require only polynomial bit complexity.

Equivalently, an individual dominance oracle yields exact \(p\) using \(\tau\) oracle calls plus polynomial overhead in \(m,\tau,L\). The hardness arises already in a single dominance query; no implicitly represented distribution or probabilistic counting theorem is needed.

These arguments settle both requested hardness alternatives. They do not assert that the unrestricted threshold problem belongs to \(\mathrm{NP}\).
