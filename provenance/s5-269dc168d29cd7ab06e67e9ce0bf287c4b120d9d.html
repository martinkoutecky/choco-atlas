Theorem 1.1 — class: algorithmic

The continuous mirror question, as graded

Given rational type masses \(\mu_a\) over \(\tau\) agent types, \(k\) item classes with rational per-capita supplies \(q_j\), additive values \(v_{a,j}\), and fixed bundle bound \(B\), choose \(x_{a,b}\ge 0\) for integral bundles \(b\in\mathbb{Z}_{\ge 0}^k\) with \(\sum_j b_j\le B\), subject to \(\sum_b x_{a,b}=\mu_a\) and \(\sum_{a,b}b_jx_{a,b}=q_j\), maximizing \(W(x)=\exp(\sum_{a,b}x_{a,b}\log v_a(b))\), with zero welfare if positive mass receives zero value.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_a\) a binary rational, with \(\sum_a\mu_a=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m:=k\geq1\) item classes, nonnegative binary-rational per-capita supplies \(q_j\), and nonnegative binary-rational additive values \(v_{a,j}\). Fix an integer \(B\geq1\), independent of the input, and assume \(\sum_jq_j\leq B\). Let \(L\) be the total input bit length.
Allowed bundles are \(\mathcal B=\{b\in\mathbb Z_{\geq0}^{m}:\sum_jb_j\leq B\}\), with \(v_a(b)=\sum_jv_{a,j}b_j\). An allocation assigns mass \(x_{a,b}\geq0\) of type \(a\) to bundle \(b\), satisfying \(\sum_{b\in\mathcal B}x_{a,b}=\mu_a\) and \(\sum_{a,b\in\mathcal B}b_jx_{a,b}=q_j\) for every class \(j\).
Its welfare is \(W(x)=\exp(\sum_{a,b:x_{a,b}>0}x_{a,b}\log v_a(b))\), with \(W(x)=0\) whenever positive mass receives a zero-value bundle. Let \(\mathrm{OPT}=\max_x W(x)\).

Does this problem admit a randomized algorithm, polynomial in \(m,\tau,L\) for every fixed \(B\), returning an allocation with \(W(x)\geq\mathrm{OPT}/e\) with high probability, or is achieving this approximation NP-hard?

For finite agents and indivisible items with nonnegative additive valuations and unrestricted bundle sizes, a randomized polynomial-time \(1/e\)-approximation to geometric-mean Nash welfare is known ([Anari et al.](https://drops.dagstuhl.de/storage/00lipics/lipics-vol067-itcs2017/LIPIcs.ITCS.2017.36/LIPIcs.ITCS.2017.36.pdf)).
No result settling this approximation question for the exact mass-allocation model above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to one so the stated exponential objective is the continuous geometric mean.
  • Specified nonnegative binary-rational values and supplies, following the discrete nonnegative valuation domain and making the computational input finite.
  • Identified m with k, the number of item classes, and required at least one class and one supported type.
  • Interpreted the fixed bundle bound as a positive integer constant independent of the input.
  • Required total per-capita supply at most B to ensure feasibility under the bundle bound; retained empty bundles and zero-welfare instances.
  • Defined additive bundle values explicitly and omitted zero-mass terms from the logarithmic sum.

Result

The requested approximation is achievable deterministically in polynomial time for every fixed \(B\). In fact, the algorithm below returns an exactly feasible rational allocation satisfying \(W(x)\geq e^{-1/2}\mathrm{OPT}\). Thus the required \(1/e\) guarantee holds with probability one.

The key is that masses can be split continuously among bundles, and fixed \(B\) makes the bundle set polynomial in size. On allocations using only positive-value bundles, log welfare is a linear function of these masses.

1. Polynomially many bundles and unconditional feasibility

By introducing a slack coordinate, bundles correspond to nonnegative integer solutions of \(b_1+\cdots+b_m+b_{m+1}=B\). Therefore

\(\displaystyle |\mathcal B|=\binom{m+B}{B}=O_B(m^B).\)

For fixed \(B\), all bundles can consequently be enumerated in polynomial time. Their values \(v_a(b)\) can be computed exactly using rational arithmetic. Each bundle uses at most \(B\) items, so each computed value has polynomial encoding length.

Every valid input admits a feasible allocation. Write \(Q=\sum_jq_j\), and let \(e_j\) denote the \(j\)-th unit vector. Define

\(\displaystyle x_{a,Be_j}=\mu_a\frac{q_j}{B},\qquad x_{a,0}=\mu_a\left(1-\frac QB\right),\)

with all other entries zero. These masses are nonnegative because \(Q\leq B\), and their sum for type \(a\) is \(\mu_a\). The supply of class \(j\) allocated is

\(\displaystyle \sum_a Bx_{a,Be_j}=q_j\sum_a\mu_a=q_j.\)

This gives a polynomial-size rational allocation to return whenever the optimum welfare is zero.

2. Detecting zero optimum exactly

Let

\(\displaystyle I_+=\{(a,b):b\in\mathcal B,\ v_a(b)>0\}.\)

Define \(P_+\) by the rational linear constraints

\(\displaystyle x_{a,b}\geq0\quad((a,b)\in I_+),\)

\(\displaystyle \sum_{b:(a,b)\in I_+}x_{a,b}=\mu_a\quad\text{for every }a,\)

\(\displaystyle \sum_{(a,b)\in I_+}b_jx_{a,b}=q_j\quad\text{for every }j.\)

All omitted coordinates are understood to be zero.

Claim. Positive welfare is achievable if and only if \(P_+\) is nonempty.

Indeed, an allocation has positive welfare precisely when every bundle receiving positive mass has positive value. Such allocations are exactly the points of \(P_+\).

Thus, if \(P_+\) is empty, every feasible allocation has welfare zero, and the allocation from Section 1 meets the required guarantee. Feasibility of \(P_+\) can be decided exactly by rational linear programming.

Henceforth assume \(P_+\) is nonempty. Every coordinate satisfies \(0\leq x_{a,b}\leq\mu_a\), so \(P_+\) is compact. Define

\(\displaystyle F(x)=\sum_{(a,b)\in I_+}x_{a,b}\log v_a(b).\)

This is a continuous linear function on \(P_+\), and \(W(x)=\exp(F(x))\). Consequently, \(F\) has a maximizer \(x^\star\), and

\(\displaystyle F(x^\star)=\log\mathrm{OPT}.\)

The logarithmic coefficients need not be rational. The next step handles this without assuming exact computation or comparison of transcendental numbers.

3. Rational approximations to logarithms

Lemma. Given a positive rational \(u\) of binary encoding length \(S\), a rational \(c(u)\) satisfying \(|c(u)-\log u|\leq1/4\) can be computed in time polynomial in \(S\).

Proof. Using exact rational comparisons, write \(u=2^rs\), where \(r\) is an integer and \(1\leq s<2\). The numerator and denominator encoding lengths imply \(|r|\leq S+1\).

For \(1\leq z\leq2\), put \(t=(z-1)/(z+1)\), so \(0\leq t\leq1/3\). Integrating the geometric series for \(1/(1-t^2)\) gives

\(\displaystyle \log z=2\sum_{\ell=0}^{\infty}\frac{t^{2\ell+1}}{2\ell+1}.\)

Define the rational truncation

\(\displaystyle H_N(z)=2\sum_{\ell=0}^{N-1}\frac{t^{2\ell+1}}{2\ell+1}.\)

Its error satisfies

\(\displaystyle 0\leq\log z-H_N(z)\leq2\sum_{\ell=N}^{\infty}t^{2\ell+1}=\frac{2t^{2N+1}}{1-t^2}\leq\frac34\,9^{-N}\leq9^{-N}.\)

Set

\(\displaystyle c(u)=rH_N(2)+H_N(s).\)

Since \(\log u=r\log2+\log s\), the triangle inequality yields

\(\displaystyle |c(u)-\log u|\leq(|r|+1)9^{-N}\leq(S+2)9^{-N}.\)

Choose an integer \(N\) with \(9^N\geq4(S+2)\). This requires only \(O(\log(S+2))\) terms.

All computations are rational. The numerator and denominator lengths of the powers are \(O(NS)\); even adding the terms using products of denominators gives polynomial encoding length. Hence both the running time and the output encoding length are polynomial in \(S\). This proves the lemma. ∎

Apply the lemma to every positive bundle value, obtaining rational coefficients \(c_{a,b}\) with

\(\displaystyle |c_{a,b}-\log v_a(b)|\leq\frac14.\)

4. The rational linear program and its guarantee

Solve the rational linear program

\(\displaystyle \max_{x\in P_+}\widetilde F(x),\qquad \widetilde F(x)=\sum_{(a,b)\in I_+}c_{a,b}x_{a,b}.\)

Let \(\widehat x\) be an exact rational optimizer. Rational linear programming admits polynomial-time feasibility and optimization algorithms in the binary encoding model; see the introductory discussion in [Adler and Beling](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_1994.pdf). Here the coefficients and constraints are rational, and the feasible set is nonempty and bounded, so the theorem applies.

For every \(x\in P_+\), the type-mass constraints give

\(\displaystyle \sum_{(a,b)\in I_+}x_{a,b}=\sum_a\mu_a=1.\)

Therefore the coefficient errors imply the uniform objective bound

\(\displaystyle |\widetilde F(x)-F(x)|\leq\sum_{(a,b)\in I_+}x_{a,b}|c_{a,b}-\log v_a(b)|\leq\frac14.\)

Using this bound twice, together with optimality of \(\widehat x\) for the rational objective, gives

\(\displaystyle F(\widehat x)\geq\widetilde F(\widehat x)-\frac14\geq\widetilde F(x^\star)-\frac14\geq F(x^\star)-\frac12.\)

Exponentiating,

\(\displaystyle W(\widehat x)\geq e^{-1/2}\mathrm{OPT}\geq\frac{\mathrm{OPT}}e.\)

The returned allocation satisfies all mass and supply equalities exactly, because it is an exact feasible solution of the rational linear program.

5. Complexity and scope

There are at most \(\tau\binom{m+B}{B}\) variables and \(\tau+m\) equality constraints. For fixed \(B\), their number is polynomial in \(m,\tau,L\). Bundle values, logarithmic approximations, and the resulting linear-program coefficients all have polynomial encoding length. Exact rational linear programming therefore produces the allocation in polynomial time, with polynomial output length.

The argument also gives arbitrarily accurate multiplicative approximation. For any rational \(0<\varepsilon\leq1\), approximate each logarithmic coefficient within \(\varepsilon/2\). The same proof gives \(W(\widehat x)\geq e^{-\varepsilon}\mathrm{OPT}\); the additional precision requires polynomial time in the encoding length of \(\varepsilon\).

The finite-agent problem studied by [Anari et al.](https://drops.dagstuhl.de/storage/00lipics/lipics-vol067-itcs2017/LIPIcs.ITCS.2017.36/LIPIcs.ITCS.2017.36.pdf) requires assigning each indivisible item to one agent. In the present model, type masses may be split freely among bundles. Thus the bundle linear program used here directly describes valid allocations.
