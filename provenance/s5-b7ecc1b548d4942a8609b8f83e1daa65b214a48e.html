The continuous mirror question, as graded

Given \(m\) projects \(A\), rational costs \(q_a\), budget \(1\), and a finite-support rational distribution \(\mu\) over complete utility types \(f_t:2^A\to[0,1]\), each normalized by \(f_t(A)=1\), monotone, submodular, and satisfying \(f_t(a\mid S)\ge(1-c)f_t(\{a\})\), define \(W_\mu(S)=\sum_t\mu_t f_t(S)\). For \(m\) a power of two, a mechanism samples \(\alpha\) uniformly from \(\Lambda=\{2^{j-1}/m:1\le j\le\log_2m\}\) and observes only the mass distribution of approval reports \(R_\alpha(f_t)=\{a:f_t(\{a\})\ge\alpha\}\). Construct a randomized map from the sampled threshold and approval-mass profile to a lottery over sets \(S\subseteq A\) with \(\sum_{a\in S}q_a\le1\), such that its expected per-capita welfare is at least \(\frac{(1-\epsilon)(1-c)}{4\log m}\max_{S:\sum_{a\in S}q_a\le1}W_\mu(S)\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge2\) indivisible projects, with \(m\) a power of two, binary rational costs \(q_a\in[0,1]\), and feasible sets \(\mathcal F=\{S\subseteq A:\sum_{a\in S}q_a\le1\}\).
A society is given by its support: \(\tau\) complete utility types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types.
Each private type is a rational-valued monotone submodular function \(f_t:2^A\to[0,1]\), with \(f_t(\varnothing)=0\), \(f_t(A)=1\), and \(f_t(S\cup\{a\})-f_t(S)\ge(1-c)f_t(\{a\})\) whenever \(a\notin S\), for a public binary rational \(c\in[0,1]\).
Define \(W_\mu(S)=\sum_t\mu_t f_t(S)\). A single common threshold \(\alpha\) is sampled uniformly from \(\Lambda=\{2^{j-1}/m:1\le j\le\log_2m\}\).
The mechanism observes only the public costs and parameters, \(\alpha\), and the supported approval sets with their masses: \(p_\alpha(R)=\sum_{t:R_\alpha(f_t)=R}\mu_t\), where \(R_\alpha(f_t)=\{a:f_t(\{a\})\ge\alpha\}\). It has no utility queries or reports at other thresholds.
Given binary rational \(\epsilon\in(0,1)\), let \(L\) be the total bit length of the public parameters, costs, and observed approval-mass profile.

Does there exist a randomized mechanism, running in time polynomial in \(m,\tau,L,1/\epsilon\), that samples \(S\in\mathcal F\) and, for every admissible society, satisfies \(\mathbb E_{\alpha,\mathrm{mechanism}}[W_\mu(S)]\ge\frac{(1-\epsilon)(1-c)}{4\log_2m}\max_{T\in\mathcal F}W_\mu(T)\), or is this approximation guarantee unattainable under these information and running-time restrictions?

For finite equally weighted voters, the same welfare guarantee is stated by [Yuan and Tang](https://arxiv.org/html/2406.13586v1). For additive utilities, randomized threshold approval has distortion lower bound \(\Omega(\log m/\log\log m)\) ([Benadè et al.](https://procaccia.info/wp-content/uploads/2020/03/pb.pdf)).

Result

The guarantee is unattainable under the specified information restriction, regardless of running time. This already holds for additive utilities with \(c=0\) and equally weighted supported types.

We construct indistinguishable societies showing that every mechanism has an instance on which its expected welfare is at most \(4/\sqrt{m}\) times optimal welfare.

1. Construction and admissibility

Let \(r\geq3\), \(m=2^{2r}\), and \(k=2^r=\sqrt{m}\). Partition the projects into two sets \(C,D\), each of cardinality \(m/2\). Set costs

\[ q_a=\frac1k\quad(a\in C),\qquad q_d=1\quad(d\in D). \]

For each subset \(U\subseteq C\) of cardinality \(k\), define a society with one type for each \(d\in D\), all with mass \(\mu_d=2/m\). Write

\[ \beta=\frac{1}{2m},\qquad \gamma=1-k\beta. \]

The utility of type \(d\) is

\[ f_{d,U}(S)=\beta\,|S\cap U|+\gamma\,\mathbf{1}_{\{d\in S\}}. \]

These functions are additive with nonnegative singleton values, hence monotone and submodular. Moreover, \(f_{d,U}(\varnothing)=0\) and \(f_{d,U}(A)=k\beta+\gamma=1\), so every value lies in \([0,1]\). Every marginal equals its singleton value, satisfying the curvature condition with \(c=0\).

All costs, masses, and utility values are dyadic rationals. The masses sum to \(1\), and the types are distinct because each values a different project in \(D\). Thus the supported-type count is exactly \(\tau=m/2\).

2. All societies produce identical observations

Every allowed threshold satisfies \(1/m\leq\alpha\leq1/2\).

The singleton values on \(U\) equal \(\beta=1/(2m)<1/m\), so these projects are never approved. All other projects except the type’s own project in \(D\) have value zero. Finally,

\[ \gamma=1-\frac{1}{2k}>\frac12. \]

Consequently, for every \(U\), every \(d\in D\), and every permitted threshold,

\[ R_\alpha(f_{d,U})=\{d\}. \]

The observed profile therefore always assigns mass \(2/m\) to each singleton approval set \(\{d\}\), for \(d\in D\). It contains no information about \(U\).

For any fixed mechanism, its output distribution, including the randomness in \(\alpha\), is therefore independent of \(U\).

3. Welfare and the optimum

Aggregating the utilities gives

\[ W_U(S)=\beta\,|S\cap U|+\frac{\gamma}{|D|}\,|S\cap D|. \]

A feasible set containing a project in \(D\) must consist of that project alone: its cost is already \(1\), and every other project has positive cost. A feasible set contained in \(C\) has cardinality at most \(k\).

Thus the best feasible set contained in \(C\) is \(U\), with welfare \(k\beta=k/(2m)\). Every singleton in \(D\) has welfare

\[ \frac{\gamma}{|D|}=\frac{2}{m}-\frac{k}{m^2}<\frac{2}{m}. \]

Since \(k\geq8\), we have \(k/(2m)>2/m\). Therefore the exact optimal welfare is

\[ \operatorname{OPT}_U=\frac{k}{2m}. \]

4. Averaging proves an information lower bound

Temporarily choose \(U\) uniformly among the cardinality-\(k\) subsets of \(C\). Each \(a\in C\) belongs to \(U\) with probability \(k/|C|\).

For any fixed feasible \(S\subseteq C\), linearity of expectation yields

\[ \mathbb{E}_U[W_U(S)] =\beta\,|S|\,\frac{k}{|C|} \leq\beta\,\frac{k^2}{|C|} =\frac1m. \]

For a feasible singleton \(S=\{d\}\), with \(d\in D\), its welfare is independent of \(U\) and is strictly less than \(2/m\).

These cases exhaust all feasible outputs. Because the mechanism’s output distribution is independent of \(U\), averaging over that distribution gives

\[ \mathbb{E}_U\mathbb{E}_{\alpha,\mathrm{mechanism}}[W_U(S)]<\frac2m. \]

The family of possible \(U\) is finite. Hence at least one fixed \(U\) satisfies

\[ \mathbb{E}_{\alpha,\mathrm{mechanism}}[W_U(S)]<\frac2m. \]

For this society,

\[ \frac{\mathbb{E}_{\alpha,\mathrm{mechanism}}[W_U(S)]}{\operatorname{OPT}_U} <\frac{2/m}{k/(2m)} =\frac4{\sqrt m}. \]

This argument applies to every randomized mechanism, including mechanisms with unlimited computation.

5. Explicit contradiction to the requested guarantee

Take \(r=10\), so \(m=2^{20}\), \(k=1024\), and \(\log_2m=20\). Set \(\epsilon=1/2\) and \(c=0\).

The requested guarantee would require, for every society in the family,

\[ \mathbb{E}[W_U(S)] \geq \frac{1/2}{4\cdot20}\,\frac{1024}{2m} =\frac{16}{5m}. \]

But Section 4 supplies a society with expected welfare strictly less than \(2/m\), and \(2/m<16/(5m)\). This is a contradiction.

6. The gap in the cited argument

In [Yuan and Tang, Section 4.3, inequality (24)](https://arxiv.org/html/2406.13586v1#S4.SS3), the proof uses the assertion \(\sum_{a\in S^*}d_a^0\leq n\), where \(d_a^0\) counts voters whose singleton value for \(a\) lies in \([0,1/m]\). A voter can contribute to this count for many projects.

In the construction above, viewed as \(n=|D|\) equally weighted voters, \(S^*=U\). Every voter values every \(a\in U\) at \(\beta<1/m\), so \(d_a^0=n\) for each such project. Therefore

\[ \sum_{a\in S^*}d_a^0=kn>n. \]

The cited proof thus does not establish its stated guarantee under these premises. The counterexample settles the present question negatively, already with equally weighted voters.
