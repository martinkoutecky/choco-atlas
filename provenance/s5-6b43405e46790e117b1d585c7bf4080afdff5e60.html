The continuous mirror question, as graded

Given a tree \(T=(V,E)\), \(k\) supported resident types, and rational proportions \(\mu_i\ge 0\) with \(\sum_i\mu_i=1\), find a rational allocation \(x_{v,i}\ge 0\) satisfying \(\sum_i x_{v,i}=1\) for every \(v\) and \(\sum_v x_{v,i}=|V|\mu_i\) for every \(i\). Define \(U_i(v;x)=\frac{\sum_{w\in N(v)}x_{w,i}}{\deg(v)}\). Require that for every edge \(uv\) and types \(i\ne j\) with \(x_{u,i}>0\) and \(x_{v,j}>0\), the two residents do not both strictly prefer the other district: it is not the case that \(U_i(v;x)>U_i(u;x)\) and \(U_j(u;x)>U_j(v;x)\). Can such a stable allocation always be found in time polynomial in \(|V|\), the number of supported types, and the input bit length?

Packaged proof task (what the prover saw — nothing else)

Let \(T=(V,E)\) be a finite unweighted undirected tree with \(m=|V|\ge2\).
A society is given by its support: a list of \(\tau=k\ge2\) resident types with positive binary-rational masses \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
A feasible allocation consists of rational numbers \(x_{v,i}\ge0\) with \(\sum_i x_{v,i}=1\) for every vertex and \(\sum_v x_{v,i}=m\mu_i\) for every type.
Residents are nonatomic. Their utility at a vertex is \(U_i(v;x)=\frac{\sum_{w\in N(v)}x_{w,i}}{\deg(v)}\); an individual exchange leaves these neighborhood masses unchanged.
An allocation is stable if, for every edge \(\{u,v\}\in E\) and distinct types \(i,j\) with \(x_{u,i}>0\) and \(x_{v,j}>0\), either \(U_i(v;x)\le U_i(u;x)\) or \(U_j(u;x)\le U_j(v;x)\). Indifference does not permit a profitable exchange.

Is finding a rational stable allocation, or correctly reporting that none exists, polynomial-time solvable in \(m,\tau,L\), or is this problem NP-hard?

For indivisible residents with positive integer type counts, a local swap equilibrium on every tree exists and is computable in polynomial time, with utilities evaluated after the swap ([verified result](https://link.springer.com/article/10.1007/s10458-022-09573-7)).
No result settling this precise nonatomic allocation problem was located in the literature search.

Modeling choices made when packaging the task

  • Excluded the one-vertex tree so that every utility denominator is positive, consistent with the anchor's nontrivial domain.
  • Removed zero-mass types from the support and required at least two supported types, matching the anchor's positive type counts and type-number condition.
  • Interpreted the stated unchanged-allocation utility comparisons as exchanges of nonatomic individuals, preserving the graded stability condition.
  • Made the computational problem total by allowing a report of nonexistence, without promising equilibrium existence.
  • Used m for the number of vertices and L for total input bit length.

Conclusion

The problem is polynomial-time solvable. The uniform allocation works for every permitted tree and society. Although this is a simple witness, it resolves the entire stated input class.

Construction and feasibility

For every vertex \(v\in V\) and type \(i\in\{1,\ldots,\tau\}\), set \(x_{v,i}=\mu_i\).

These entries are rational and positive. At each vertex, \(\sum_i x_{v,i}=\sum_i\mu_i=1\). For each type, \(\sum_v x_{v,i}=m\mu_i\). Thus the allocation is feasible.

Stability

Since the tree is connected and \(m\ge2\), every vertex has positive degree. Consequently, for every vertex \(v\) and type \(i\),

\(\displaystyle U_i(v;x)=\frac{\sum_{w\in N(v)}\mu_i}{\deg(v)}=\frac{\deg(v)\mu_i}{\deg(v)}=\mu_i.\)

Fix any edge \(\{u,v\}\) and distinct types \(i,j\). Then \(U_i(v;x)=U_i(u;x)\) and \(U_j(u;x)=U_j(v;x)\). Both weak inequalities in the stability condition hold. Because indifference does not permit a profitable exchange, the allocation is stable.

Algorithm and bit complexity

Output the input mass vector at every vertex. No arithmetic or search is required. In a dense matrix representation, copying the rational encodings takes \(O(mL)\) time and output bits, hence polynomial time in \(m,\tau,L\).

A stable allocation therefore always exists under the given hypotheses, so the algorithm never needs to report nonexistence. The proof uses the specified unchanged neighborhood utilities directly and does not require the indivisible-resident result.
