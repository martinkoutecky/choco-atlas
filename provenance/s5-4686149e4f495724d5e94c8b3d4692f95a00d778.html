The continuous mirror question, as graded

Given a finite type set \(\Theta\), rational masses \(\mu_\theta\), objects \(O\), type-specific integral bundle families \(\mathcal B_\theta\), represented bihierarchical per-capita quotas, and a feasible target \(X\), compute nonnegative masses \(z_{\theta B}\) such that \(\sum_{B\in\mathcal B_\theta}z_{\theta B}=\mu_\theta\), \(X_{\theta a}=\sum_{B\ni a}z_{\theta B}\), and all aggregate quotas are satisfied.

Packaged proof task (what the prover saw — nothing else)

Given finite \(\Theta\), objects \(O\), rational masses \(\mu_\theta\), explicitly listed integral bundle families \(\mathcal B_\theta\subseteq 2^O\), and \(X\in\mathbb Q^{\Theta\times O}\), choose masses \(z_{\theta B}\ge0\) with \(\sum_{B\in\mathcal B_\theta}z_{\theta B}=\mu_\theta\) and \(X_{\theta a}=\sum_{B\ni a}z_{\theta B}\).
Aggregate quotas are rational bounds \(\ell_S\le\sum_{(\theta,a)\in S}X_{\theta a}\le u_S\) for \(S\in\mathcal H\), where \(\mathcal H\) is bihierarchical: \(\mathcal H=\mathcal H_1\mathbin{\dot\cup}\mathcal H_2\) and each \(\mathcal H_i\) is laminar.

Is this continuous implementation problem solvable in polynomial time, or is it NP-hard?

For individually listed agents, integral quotas on a bihierarchical constraint structure guarantee implementation of every feasible expected assignment, and an implementation algorithm runs in polynomial time. That result does not address masses over types and type-specific bundle families.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The problem is solvable in polynomial time in the binary encoding length of the explicitly listed input. In fact, the bihierarchical assumption is unnecessary for the continuous problem as stated.

Linear programming formulation. Let \(t=|\Theta|\), \(m=|O|\), and \(N=\sum_{\theta\in\Theta}|\mathcal B_\theta|\). Introduce one real variable \(z_{\theta B}\) for each listed pair \((\theta,B)\). Consider the following feasibility system:

  • \(z_{\theta B}\geq 0\) for every \(\theta\in\Theta\) and \(B\in\mathcal B_\theta\).
  • \(\sum_{B\in\mathcal B_\theta}z_{\theta B}=\mu_\theta\) for every \(\theta\in\Theta\).
  • \(\sum_{B\in\mathcal B_\theta:\,a\in B}z_{\theta B}=X_{\theta a}\) for every \((\theta,a)\in\Theta\times O\).

Because \(X\) is supplied as part of the input, each aggregate quota can first be checked directly: compute \(q_S=\sum_{(\theta,a)\in S}X_{\theta a}\), and reject if \(q_S<\ell_S\) or \(q_S>u_S\). These are exact comparisons of rational numbers.

Correctness. If an implementation satisfying the question’s requirements exists, its masses satisfy all three groups of constraints, and every quota check passes. Conversely, if every quota check passes and the displayed system has a feasible solution, that solution assigns nonnegative masses to allowed bundles, has the prescribed total mass for each type, and reproduces every entry of \(X\). Since the aggregate quotas depend only on \(X\), they also hold. Thus the procedure’s feasibility condition is exactly the requested implementation condition.

Polynomial running time and exact output. Let \(L\) denote the total binary input length, including the bundle lists and quota descriptions. Explicit listing ensures that \(N\) is polynomially bounded in \(L\). The system has \(N\) variables, \(t+tm\) equality constraints, and \(N\) nonnegativity constraints. Every matrix coefficient is either \(0\) or \(1\); the right-hand sides are the input rationals. Replacing each equality with two inequalities therefore gives an explicitly represented rational linear program of encoding length polynomial in \(L\).

We use the standard polynomial-time theorem for rational linear programming: feasibility of an explicitly represented rational linear system can be decided in time polynomial in its binary encoding length, and a rational feasible point can be returned when one exists. This theorem permits equality constraints and lower-dimensional feasible regions; see the [MIT notes on linear programming algorithms](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html). All its hypotheses hold here. The preliminary quota sums and comparisons also take polynomial time: adding polynomially many input rationals produces numerators and denominators of polynomial bit length.

Consequently, the algorithm either correctly reports infeasibility or returns exact rational implementation masses in polynomial time. Empty bundle families cause no exception: their sums are interpreted as \(0\), and the same feasibility test applies.

The integrality of the listed bundles means their incidence coefficients are integral; it does not impose integrality on the masses \(z_{\theta B}\). No decomposition into jointly quota-feasible integral assignments is required by the stated equations. The cited implementation theorem for individual agents is therefore unnecessary for this conclusion.
