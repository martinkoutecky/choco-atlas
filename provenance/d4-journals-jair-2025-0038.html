Theorem 1 — class: hardness

The continuous mirror question, as graded

Given \(\tau\) exposure roles with positive rational masses \(\mu_i\) summing to \(1\), a symmetric nonnegative rational interaction matrix \(a_{ij}\), and rational \(q\in(1/2,1]\), does there exist a red mass \(x_i\in[0,\mu_i]\) for each role such that \(\sum_i(\mu_i-2x_i)>0\) and \(\sum_{i:\,\sum_j a_{ij}(2x_j-\mu_j)>0}\mu_i\ge q\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) exposure types with positive binary-rational masses \(\mu_i\), where \(\sum_i\mu_i=1\); \(\tau\) is the support size, not the number of possible types. There are \(m=2\) labels, red and blue.
The input also contains a symmetric matrix \(A=(a_{ij})\in\mathbb{Q}_{\ge0}^{\tau\times\tau}\) and a binary-rational threshold \(q\in(1/2,1]\). Let \(L\) be the total input bit length. Coefficients are exposure weights: \(a_{ij}\mu_j\) is the exposure of type \(i\) to type \(j\). Diagonal entries allow exposure to other members of the same atomless type.
A labeling selects real red masses \(x_i\in[0,\mu_i]\), with blue masses \(\mu_i-x_i\). Blue must be the strict global majority: \(\sum_i(\mu_i-2x_i)>0\).
Every member of type \(i\), regardless of its own label, is under illusion exactly when \(\sum_j a_{ij}(2x_j-\mu_j)>0\). Ties and zero exposure do not count as illusion. The decision problem asks whether a labeling exists with \(\sum_{i:\,\sum_j a_{ij}(2x_j-\mu_j)>0}\mu_i\ge q\).

Is this continuous majority-illusion decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents on simple undirected graphs, existence of a binary labeling inducing illusion in at least a \(q\)-fraction is NP-complete for every fixed rational \(q\in(1/2,1]\), even on bipartite graphs ([source](https://doi.org/10.1613/jair.1.17741)). Later discrete work establishes W[1]-hardness parameterized by treewidth ([source](https://arxiv.org/html/2606.04260v1)).
No result settling the exact continuous decision problem above was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted interaction coefficients as unnormalized exposure weights, with exposure to a type proportional to its mass.
  • Allowed diagonal coefficients to describe interaction with other members of the same atomless type; excluding individual self-interaction does not remove within-type exposure.
  • Made explicit that red masses may be real, while all input numbers have binary-rational encodings.
  • Used m=2 for the fixed number of labels and L for total input bit length; q is part of the input.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is \(\mathrm{NP}\)-complete, already for the fixed threshold \(q=3/4\). This holds with positive dyadic masses and a symmetric rational matrix whose entries all lie in \([1,3]\).

The endpoint \(q=1\), however, is polynomial-time solvable. Thus the continuous problem has a different endpoint behavior from the discrete problem cited in the question.

1. Homogeneity removes the mass bounds.

Define \(y_i=2x_i-\mu_i\). Then a valid labeling satisfies

\(\displaystyle -\mu_i\le y_i\le\mu_i,\qquad \mathbf1^{\mathsf T}y<0,\)

and type \(i\) is under illusion exactly when \((Ay)_i>0\).

For any subset \(S\) of types, the following are equivalent:

  • A valid labeling makes every type in \(S\) illuded.
  • There is an unrestricted vector \(y\in\mathbb R^\tau\) satisfying \(\mathbf1^{\mathsf T}y<0\) and \((Ay)_i>0\) for every \(i\in S\).

Only the reverse implication needs proof. Given such an unrestricted vector, set

\(\displaystyle \lambda=\min_i\frac{\mu_i}{1+|y_i|}>0.\)

Then \(|\lambda y_i|<\mu_i\) for every \(i\). Positive scaling preserves all the strict inequalities, so

\(\displaystyle x_i=\frac{\mu_i+\lambda y_i}{2}\)

is a valid labeling with the required illusion types and strict blue majority.

Consequently, masses determine the objective weights but do not restrict which subsets can simultaneously be illuded.

2. Membership in \(\mathrm{NP}\), and the endpoint \(q=1\).

A certificate is a subset \(S\) with \(\sum_{i\in S}\mu_i\ge q\). By the preceding observation, its feasibility is equivalent to feasibility of the rational linear system

\(\displaystyle (Ay)_i\ge1\quad(i\in S),\qquad \mathbf1^{\mathsf T}y\le-1.\)

Indeed, a vector satisfying the strict inequalities can be scaled upward until every required positive margin, including \(-\mathbf1^{\mathsf T}y\), is at least \(1\). Conversely, this linear system gives the strict inequalities, and the preceding scaling argument supplies a valid labeling.

Rational linear feasibility is decidable in time polynomial in the number of variables, constraints, and coefficient bit lengths. Thus a deterministic polynomial-time verifier can check the certificate \(S\), proving membership in \(\mathrm{NP}\).

When \(q=1\), positivity of every mass forces every type to be illuded. Hence one simply tests

\(\displaystyle Ay\ge\mathbf1,\qquad \mathbf1^{\mathsf T}y\le-1.\)

This proves polynomial-time solvability at that endpoint.

3. Source problem and matrix construction.

We reduce from Independent Set: given a simple undirected graph \(G=(V,E)\) and an integer \(k\), decide whether an independent set of size at least \(k\) exists. Its \(\mathrm{NP}\)-completeness follows from the classical Clique theorem by graph complementation. [Karp’s original theorem](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Write \(n=|V|\) and \(r=|E|\). We may restrict to \(r\ge1\) and \(1\le k\le n\): excluded instances are decidable immediately and can be replaced by fixed yes or no instances consisting of a single edge.

Create \(N=n+r+2\) types:

  • one vertex type for each \(v\in V\);
  • one edge type for each \(e\in E\);
  • a balancing type \(b\);
  • a dummy type \(z\).

Let \(e_v\) denote the standard basis vector in \(\mathbb R^n\). Construct an integer matrix \(F\in\mathbb Z^{N\times n}\) with rows

\(\displaystyle F_v=e_v^{\mathsf T},\qquad F_{\{v,w\}}=-e_v^{\mathsf T}-e_w^{\mathsf T}.\)

Set \(F_b\) equal to the negative sum of all vertex and edge rows, and set \(F_z=0\). Therefore

\(\displaystyle F^{\mathsf T}\mathbf1=0.\)

The vertex rows form an identity matrix, so \(F\) has full column rank. In particular, \(H=F^{\mathsf T}F\) is positive definite. Define

\(\displaystyle P=FH^{-1}F^{\mathsf T},\qquad J=\mathbf1\mathbf1^{\mathsf T},\qquad A=2J+P.\)

Here \(\mathbf1\in\mathbb R^N\). Direct multiplication gives

\(\displaystyle P^{\mathsf T}=P,\qquad P^2=P,\qquad PF=F,\qquad P\mathbf1=0.\)

Thus \(P\) is the orthogonal projection onto the column space of \(F\). For standard basis vectors in \(\mathbb R^N\),

\(\displaystyle |P_{ij}|=|\langle Pe_i,Pe_j\rangle|\le\|Pe_i\|\,\|Pe_j\|\le1.\)

Consequently, \(A\) is symmetric and rational, with

\(\displaystyle 1\le a_{ij}\le3,\qquad A\mathbf1=2N\mathbf1.\)

This checks the required symmetry and nonnegativity, including the diagonal entries.

For any vector \(y\) with strict blue majority, define

\(\displaystyle t=-2\mathbf1^{\mathsf T}y>0,\qquad u=H^{-1}F^{\mathsf T}y.\)

Then

\(\displaystyle Ay=Fu-t\mathbf1.\)

In particular,

\(\displaystyle (Ay)_v=u_v-t,\qquad (Ay)_{\{v,w\}}=-u_v-u_w-t,\qquad (Ay)_z=-t<0.\)

The dummy type can therefore never be illuded under a strict blue majority.

4. Dyadic masses and the fixed threshold.

Enumerate the edges as \(e_1,\ldots,e_r\). Let \(d\) be the smallest power of two with \(d\ge r\). Choose

\(\displaystyle h=\left\lceil\log_2\bigl(8d(n+1)\bigr)\right\rceil,\qquad \varepsilon=2^{-h},\qquad \beta=\frac34-k\varepsilon.\)

Assign masses

\(\displaystyle \mu_v=\varepsilon\quad(v\in V),\)

\(\displaystyle \mu_{e_1}=\frac{(d-r+1)\beta}{d},\qquad \mu_{e_j}=\frac{\beta}{d}\quad(2\le j\le r),\)

\(\displaystyle \mu_b=\frac{\varepsilon}{2},\qquad \mu_z=1-\beta-\left(n+\frac12\right)\varepsilon.\)

Set \(q=3/4\).

Every mass is dyadic. The edge masses sum to \(\beta\), so all masses together sum to \(1\). To check positivity and the necessary weight separation, observe that

\(\displaystyle \left(n+\frac12\right)\varepsilon<\frac1{8d}\le\frac18,\qquad \beta\ge\frac34-n\varepsilon>\frac58.\)

Thus \(\mu_z>1/8\), and every other mass is positive. Moreover, every edge mass satisfies

\(\displaystyle \mu_e\ge\frac{\beta}{d}>\frac5{8d}>\left(n+\frac12\right)\varepsilon.\)

The rightmost quantity is the total mass of all vertex types and the balancing type.

5. Soundness: a successful labeling yields an independent set.

Suppose a valid labeling attains illusion mass at least \(3/4\).

First, every edge type must be illuded. Otherwise, since the dummy type is never illuded, the total illusion mass would be at most

\(\displaystyle \beta-\frac{\beta}{d}+\left(n+\frac12\right)\varepsilon<\beta<\frac34,\)

a contradiction.

Let \(I\) be the set of illuded vertex types. Using the representation \(Ay=Fu-t\mathbf1\), each \(v\in I\) satisfies \(u_v>t\). Every edge \(\{v,w\}\) satisfies

\(\displaystyle u_v+u_w<-t.\)

If both endpoints belonged to \(I\), their sum would exceed \(2t>0\), contradicting this edge inequality. Therefore \(I\) is an independent set.

Finally, if \(|I|\le k-1\), even counting the balancing type as illuded would give total illusion mass at most

\(\displaystyle \beta+(k-1)\varepsilon+\frac{\varepsilon}{2}=\frac34-\frac{\varepsilon}{2}<\frac34.\)

Hence \(|I|\ge k\).

6. Completeness: an independent set yields a successful labeling.

Conversely, suppose \(I\subseteq V\) is an independent set with \(|I|\ge k\). Define

\(\displaystyle u_v=\begin{cases}1,&v\in I,\\-2,&v\notin I.\end{cases}\)

Every edge has at most one endpoint in \(I\), so its coordinate in \(Fu\) is either \(1\) or \(4\). Every vertex coordinate belonging to \(I\) equals \(1\).

Set

\(\displaystyle y^{(0)}=Fu-\frac1{4N}\mathbf1.\)

Because \(F^{\mathsf T}\mathbf1=0\), \(PF=F\), and \(P\mathbf1=0\), we obtain

\(\displaystyle \mathbf1^{\mathsf T}y^{(0)}=-\frac14,\qquad Ay^{(0)}=Fu-\frac12\mathbf1.\)

Thus every edge coordinate and every vertex coordinate in \(I\) is strictly positive in \(Ay^{(0)}\). By Section 1, positive scaling converts \(y^{(0)}\) into a valid labeling while preserving these inequalities and the strict blue majority.

Its illusion mass is at least

\(\displaystyle \beta+|I|\varepsilon\ge\beta+k\varepsilon=\frac34.\)

This proves the reverse implication.

7. Encoding size and conclusion.

The construction has \(\tau=N=n+r+2\) types. All masses have polynomial bit length because \(d\) is a power of two with \(d<2r\), and \(h\) is logarithmic in \(d(n+1)\).

For the matrix, the balancing row has coordinate \(\deg_G(v)-1\), so the integer entries of \(F\), and hence of \(H=F^{\mathsf T}F\), have polynomially bounded magnitude. Hadamard’s determinant bound shows that the determinant and cofactors of \(H\) have polynomial bit length. Therefore \(H^{-1}\), \(P\), and \(A\) have polynomial bit length and can be computed by exact rational linear algebra in polynomial time.

We have established a polynomial-time many-one reduction satisfying

\(\displaystyle G\text{ has an independent set of size at least }k\quad\Longleftrightarrow\quad\text{the constructed society admits illusion mass at least }3/4.\)

Together with membership in \(\mathrm{NP}\), this resolves the stated decision problem as \(\mathrm{NP}\)-complete. A polynomial-time algorithm in \(m,\tau,L\) would therefore imply \(\mathrm P=\mathrm{NP}\), already with \(m=2\).
