The anchor (named result in the paper)

Proposition 18 — class: hardness

The continuous mirror question, as graded

Given destinations \(V\), colors \(C\), a finite support \(T\), and rational masses \(\mu_t>0\) summing to \(1\), where each type \(t\) has a color \(c_t\) and eligible set \(S_t\subseteq V\), decide whether there exist nonnegative flows \(x_{t,v}\) for \(v\in S_t\) such that \(\sum_{v\in S_t}x_{t,v}=\mu_t\) for every \(t\), and, writing \(q_{v,c}=\sum_{t:c_t=c}x_{t,v}\), \(\max_{c\in C}q_{v,c}-\min_{c\in C}q_{v,c}\le\epsilon\) for every \(v\in V\), given rational \(\epsilon\ge0\).

Packaged proof task (what the prover saw — nothing else)

Let \(V\) be a nonempty destination set, \(m=|V|\), and \(C\) a nonempty color set. A type \(t\) consists of a color \(c_t\in C\) and an explicitly listed eligible set \(S_t\subseteq V\).
A society is given by its support: the list \(T\) of its \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. The input also includes a binary rational \(\epsilon\ge0\); let \(L\) be the total input bit length.
Mass is divisible: an assignment consists of real flows \(x_{t,v}\ge0\) for \(v\in S_t\), satisfying \(\sum_{v\in S_t}x_{t,v}=\mu_t\) for every \(t\). Set \(x_{t,v}=0\) when \(v\notin S_t\).
Define \(q_{v,c}=\sum_{t\in T:c_t=c}x_{t,v}\). An assignment is feasible if \(\max_{c\in C}q_{v,c}-\min_{c\in C}q_{v,c}\le\epsilon\) for every \(v\in V\). All listed colors participate, including those with zero mass at a destination. Destinations may receive zero mass and have no capacity constraints; an empty eligible set makes the instance infeasible.

Is deciding whether a feasible assignment exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), \(|C|\), and \(L\).

For indivisible agents, Max-Min Fair Matching is NP-hard even with three colors, threshold zero, and maximum degree at most three on each side of the eligibility graph.
The discrete problem also admits an \(O^{\star}(m^{O(m)})\)-time algorithm. These discrete results do not classify the divisible-mass problem stated here.

Modeling choices made when packaging the task

  • Required nonempty destination and color sets so that the fairness extrema are defined on a nondegenerate domain.
  • Specified real, divisible flows; only the input masses and threshold require rational encoding.
  • Allowed empty eligible sets, treating them as infeasible, consistently with the requirement to assign every agent.
  • Specified that empty destinations are allowed and imposed no capacity or positive-load constraints, matching the anchor's variant.
  • Included every listed color in the fairness extrema, even when its mass at a destination is zero.
  • Defined m as the number of destinations and L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

The problem is in \(\mathrm{P}\). A rational linear program decides feasibility in time
\[ \bigl(m\tau+m|C|+L\bigr)^{O(1)}. \]
This bound uses the support size \(\tau\), without enumerating other possible types.

Linear programming formulation

Write \(k=|C|\) and define the eligible pairs
\[ E=\{(t,v):t\in T,\ v\in S_t\},\qquad r=|E|\le m\tau. \]
If any \(S_t\) is empty, reject: its conservation equation would require \(0=\mu_t\), whereas every supported type has positive mass.

Otherwise, introduce one variable \(x_{t,v}\) for each \((t,v)\in E\), and one auxiliary variable \(a_v\) for each destination. Consider the following rational linear system:
\[ x_{t,v}\ge 0 \qquad ((t,v)\in E), \]
\[ \sum_{v\in S_t}x_{t,v}=\mu_t \qquad (t\in T), \]
\[ a_v\ge 0 \qquad (v\in V), \]
and, for every \(v\in V\) and every listed color \(c\in C\),
\[ a_v \le \sum_{\substack{t\in T:\ c_t=c\\v\in S_t}}x_{t,v} \le a_v+\epsilon. \]
An empty sum in these constraints is zero. Thus colors with no eligible mass at a destination explicitly participate.

Proof of equivalence

A feasible assignment gives a solution of the linear system. Take its assignment flows and set
\[ a_v=\min_{c\in C}q_{v,c}. \]
The minimum exists because \(C\) is finite and nonempty. All flows are nonnegative, so \(a_v\ge0\). The fairness condition gives, for each \(c\in C\),
\[ a_v\le q_{v,c} \le \max_{d\in C}q_{v,d} \le a_v+\epsilon. \]
Conservation and nonnegativity already hold. Hence every constraint of the linear system is satisfied.

A solution of the linear system gives a feasible assignment. Use its \(x\)-variables as the assignment flows, setting ineligible flows to zero. Their conservation and nonnegativity constraints give a valid assignment. For each destination, the remaining constraints imply
\[ \min_{c\in C}q_{v,c}\ge a_v, \qquad \max_{c\in C}q_{v,c}\le a_v+\epsilon. \]
Subtracting yields
\[ \max_{c\in C}q_{v,c}-\min_{c\in C}q_{v,c}\le\epsilon. \]
Thus the assignment is feasible.

These implications also cover destinations receiving zero mass and the case \(\epsilon=0\).

Running time and exactness

The system has \(r+m\) variables, \(\tau\) equality constraints, and \(r+m+2mk\) inequality constraints. Its coefficients belong to \(\{-1,0,1\}\); its right-hand sides are drawn from \(0\), the input masses, and \(\epsilon\).

A sparse representation has \(O(r+mk+\tau+m)\) entries and constraints. Each rational right-hand side has bit length at most \(L\), and each index requires logarithmically many bits. Consequently, the system’s total encoding length is polynomial in
\[ D=m\tau+mk+L. \]
Constructing it also takes polynomial time in \(D\).

We apply the standard polynomial-time theorem for rational linear programming: a finite system of linear equalities and inequalities with rational coefficients can be tested for feasibility over the reals in time polynomial in its total binary encoding length. Its hypotheses hold here because all coefficients and right-hand sides are rational and explicitly constructible with polynomial encoding length. Therefore the total decision time is
\[ D^{O(1)} = \bigl(m\tau+m|C|+L\bigr)^{O(1)}. \]

This is an exact feasibility decision, so boundary cases require no numerical tolerance. The supplied hardness results for indivisible agents do not change this classification: the divisible model permits continuous flows and is exactly represented by the linear system above.
