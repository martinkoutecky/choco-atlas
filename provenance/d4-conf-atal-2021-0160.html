The continuous mirror question, as graded

Given a finite set \(R\) of positive integer reward types, a rational distribution \(\mu\) over \(R\), and a target \(\kappa\), consider candidate mass \(1\) and a job pool of mass \(3\), with reward-\(a\) jobs of mass \(3\mu_a\). For each multiset \(Q\) of three rewards from \(R\) summing to \(\kappa\), let \(\lambda_Q\ge 0\) be the mass of candidates assigned that triple. Does there exist \(\lambda\) such that \(\sum_Q\lambda_Q=1\) and, for every \(a\in R\), \(\sum_Q m_a(Q)\lambda_Q=3\mu_a\), where \(m_a(Q)\) counts occurrences of \(a\) in \(Q\)?

Packaged proof task (what the prover saw — nothing else)

Let \(R\subseteq\mathbb Z_{>0}\) be nonempty, with \(\tau=|R|\), and let \(\kappa\in\mathbb Z_{>0}\). A society is given by its support: the list of its \(\tau\) reward types with positive masses \(\mu_a\) encoded as binary rationals, where \(\sum_{a\in R}\mu_a=1\); \(\tau\) counts supported types, not all possible types. Rewards and \(\kappa\) are binary encoded; let \(L\) be the total input bit length.
Candidate mass is \(1\), job mass is \(3\), and reward-\(a\) jobs have mass \(3\mu_a\). Each candidate receives exactly \(m=3\) jobs with total reward \(\kappa\), and all job mass must be assigned.
Let \(\mathcal Q\) contain every multiset of three elements of \(R\) summing to \(\kappa\), allowing repeated reward types; let \(m_a(Q)\) be the multiplicity of \(a\) in \(Q\). Feasibility means that real masses \(\lambda_Q\geq0\) exist with \(\sum_{Q\in\mathcal Q}\lambda_Q=1\) and \(\sum_{Q\in\mathcal Q}m_a(Q)\lambda_Q=3\mu_a\) for every \(a\in R\).

Is this feasibility problem in \(\mathrm P\), with running time polynomial in \(\tau\) and \(L\) for fixed \(m=3\), or is it NP-hard?

For indivisible jobs, partitioning positive integer rewards into triples of equal total reward is NP-hard; assigning positive labels bijectively to a forest so that every vertex has the same neighbor-label sum is NP-hard even for disjoint unions of three-leaf stars. [Gupta–Zehavi](https://www.ifaamas.org/Proceedings/aamas2021/pdfs/p555.pdf)
Fractional equal-sum triple assignments have been studied for explicitly listed, labeled job occurrences, with triples restricted to distinct occurrences. [Joosten](https://essay.utwente.nl/61447/1/MSc_S_Joosten.pdf) No result for this precise support-encoded mass problem was identified.

Modeling choices made when packaging the task

  • The target's domain was unspecified; take it to be a positive integer encoded in binary, matching the discrete reward model.
  • Use only positive-mass support entries and normalize their masses to sum to one.
  • Encode reward values in binary and define L as the total input bit length.
  • Interpret assignment masses as nonnegative real numbers.
  • Use m=3 for the fixed number of jobs per candidate; candidate population size is replaced by normalized mass one.

Proven result

The feasibility problem belongs to \(\mathrm P\). For fixed \(m=3\), all permitted multisets can be explicitly enumerated in polynomial time, and feasibility is then decided by a rational linear program of polynomial encoding length.

The proof uses the stated fractional model, including permission to repeat reward types within a triple.

1. Enumerating the permitted triples

Write the distinct supported rewards as \(R=\{a_1,\ldots,a_\tau\}\). Enumerate every index triple satisfying \(1\leq i\leq j\leq k\leq\tau\), retaining it exactly when \(a_i+a_j+a_k=\kappa\).

Every multiset of three elements of \(R\) has a unique such index representation. Thus this procedure enumerates precisely \(\mathcal Q\), including multisets with repetitions.

There are \(\binom{\tau+2}{3}=O(\tau^3)\) index triples to inspect. Each reward and \(\kappa\) has at most \(L\) bits, so each sum and comparison takes \(O(L)\) bit operations. Consequently, enumeration takes \(O(\tau^3L)\) bit operations.

Let \(N=|\mathcal Q|\). We have \(N=O(\tau^3)\). If \(N=0\), the instance is infeasible because the required candidate mass is \(1\).

2. An exactly equivalent linear program

Assume \(N>0\), and list the retained multisets as \(Q_1,\ldots,Q_N\). Define the matrix \(A\in\mathbb Z^{\tau\times N}\) by

\(\displaystyle A_{ij}=m_{a_i}(Q_j).\)

Each entry belongs to \(\{0,1,2,3\}\). Because every multiset contains exactly three rewards, each column satisfies

\(\displaystyle \sum_{i=1}^{\tau}A_{ij}=3.\)

Set \(b_i=3\mu_{a_i}\). Consider the linear feasibility system

\(\displaystyle A\lambda=b,\qquad \lambda\in\mathbb R^N,\qquad \lambda_j\geq0\ \text{for every }j.\)

Equivalence. Any assignment feasible under the problem’s definition satisfies this system, since its equations are exactly the reward-type mass constraints.

Conversely, suppose \(\lambda\) satisfies this system. Summing its equations over all supported types gives

\(\displaystyle 3=\sum_{i=1}^{\tau}3\mu_{a_i}=\sum_{i=1}^{\tau}\sum_{j=1}^{N}A_{ij}\lambda_j=\sum_{j=1}^{N}3\lambda_j.\)

The first equality uses the premise \(\sum_{a\in R}\mu_a=1\); the last uses the column sums of \(A\). Dividing by \(3\) yields \(\sum_{j=1}^{N}\lambda_j=1\). Therefore \(\lambda\) also satisfies the required candidate-mass normalization and is feasible under the original definition.

This proves exact equivalence in both directions.

3. Polynomial bit complexity

The standard polynomial-time theorem for rational linear programming states that feasibility over the reals of a finite system of linear inequalities with binary-encoded rational coefficients can be decided exactly in time polynomial in its total encoding length. Polynomial-time solvability in this bit model is recalled in the introduction of [Adler–Beling](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf).

Its hypotheses hold here:

  • All entries of \(A\) are integers of constant encoding length.
  • Each \(b_i=3\mu_{a_i}\) is rational. Multiplying its encoded numerator by \(3\) increases its bit length by at most a constant.
  • There are \(N=O(\tau^3)\) variables and \(\tau\) equality constraints, together with nonnegativity constraints.

The standard-form description has encoding length \(O(\tau N+L)=O(\tau^4+L)\). If an inequality-only formulation is required, replace every equality by two inequalities and include the \(N\) nonnegativity inequalities. Even a dense encoding of this formulation has polynomial length, bounded by \(O((\tau+N)N+L)\).

Hence the linear-programming decision step runs in time polynomial in \(\tau\) and \(L\). Together with the enumeration bound, this proves the claimed running time. Since the support is explicitly listed, \(\tau\leq L\), so the algorithm is also polynomial in total input length alone.

Binary reward encoding causes no difficulty: the algorithm enumerates triples of supported types, without iterating through the numerical range of rewards.

4. Relation to the indivisible problem

For indivisible jobs, the number of triples of each kind must be integral. The present problem permits arbitrary nonnegative real masses, yielding exactly the linear system proved equivalent above. Thus the cited hardness of indivisible assignments does not establish hardness of this fractional problem.

The target question is completely resolved: the stated problem is polynomial-time solvable. Under polynomial-time many-one reductions, it could be NP-hard only if \(\mathrm P=\mathrm{NP}\).
