The continuous mirror question, as graded

Given a finite candidate set \(A\), a support of \(\tau\) complete evaluator rankings \(t\) with positive binary-rational masses \(\mu_t\) summing to one, and a strict-majority-margin promise, compute the exact Top Cycle and Uncovered Set of the induced tournament, where \(a\) defeats \(b\) iff \(\sum_{t:\,a\succ_t b}\mu_t>1/2\). Return the two membership vectors.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a candidate set with \(m=|A|\ge2\). A society is given by its support: a list of \(\tau\) distinct strict complete rankings \(t\) of \(A\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
For distinct candidates, define \(P_{ab}=\sum_{t:a\succ_t b}\mu_t\). Promise that some \(\delta>0\) satisfies \(|P_{ab}-1/2|\ge\delta\) for every distinct pair; no fixed lower bound on \(\delta\) is imposed. Define the loopless tournament \(T\) by \(a\succ_T b\) exactly when \(P_{ab}>1/2\).
The Top Cycle consists of candidates that reach every other candidate in \(T\). A candidate \(c\) covers \(a\) if \(c\succ_T a\) and \(c\succ_T b\) for every \(b\) with \(a\succ_T b\). The Uncovered Set consists of candidates with no coverer.
The computational problem returns the two exact membership vectors in \(\{0,1\}^m\).

Is this computation polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?

Known results: under strict pairwise margins, smooth majority-edge, reachability, and covering scores converge to the exact Top Cycle and Uncovered Set indicators as all temperatures vanish, provided the reachability path bound is at least \(m-1\).
For an explicitly given hard tournament, the Top Cycle and Uncovered Set are computable in \(O(m^2)\) and \(O(m^3)\) time, respectively.

Modeling choices made when packaging the task

  • Interpreted complete evaluator rankings as strict total orders, so distinct-pair probabilities are complementary.
  • Restricted the candidate domain to at least two candidates, avoiding the empty aggregations in the anchor's soft membership definitions.
  • Interpreted the strict-majority-margin promise as existence of a positive margin, without supplying a margin parameter or imposing a uniform lower bound.
  • Defined L as the total encoded input bit length.

Conclusion

The computation is polynomial-time solvable in \(m,\tau,L\). The weighted ranking support allows us to construct the majority tournament exactly in polynomial time. We can then compute both membership vectors in \(O(m^3)\) graph operations.

The margin promise requires no quantitative lower bound on \(\delta\): exact rational arithmetic determines every majority edge.

1. Constructing the tournament exactly

Write each input mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive integers represented in binary. A mass given as an explicit finite binary expansion can also be put in this form with representation length linear in its input length.

Define
\[ D=\prod_{t=1}^{\tau}q_t, \qquad w_t=p_t(D/q_t). \]
Every \(w_t\) is a positive integer, and normalization gives
\[ \sum_{t=1}^{\tau}w_t = D\sum_{t=1}^{\tau}\mu_t = D. \]

These integers have polynomially bounded bit lengths. Indeed,
\[ \log_2 D=\sum_{t=1}^{\tau}\log_2 q_t=O(L), \]
because the denominator representations are part of the input. Moreover, \(w_t\le D\), so every weight also has \(O(L)\) bits. Computing \(D\) and the weights uses \(O(\tau)\) integer multiplications and exact divisions on integers of \(O(L)\) bits, hence takes polynomial time.

For each ranking \(t\), record the position \(\operatorname{pos}_t(a)\) of every candidate \(a\). For every ordered pair of distinct candidates, compute
\[ S_{ab} = \sum_{\substack{t\\ \operatorname{pos}_t(a)<\operatorname{pos}_t(b)}}w_t. \]
Then
\[ P_{ab}=\frac{S_{ab}}D, \qquad a\succ_T b \quad\Longleftrightarrow\quad 2S_{ab}>D. \]

All partial sums lie between \(0\) and \(D\), so these calculations use \(O(L)\)-bit integers. Computing all sums requires \(O(\tau m^2)\) additions and ranking comparisons; determining all edges requires \(O(m^2)\) integer comparisons.

Strict completeness of each ranking implies
\[ S_{ab}+S_{ba}=D. \]
The margin promise excludes \(2S_{ab}=D\). Consequently, exactly one of \(a\succ_T b\) and \(b\succ_T a\) holds for each distinct pair, as required.

This construction processes only the \(\tau\) supplied rankings; it never enumerates all possible rankings.

2. Computing the Top Cycle

Store the resulting tournament in a Boolean adjacency matrix \(E\), where \(E_{ab}=1\) exactly when \(a\succ_T b\), and \(E_{aa}=0\).

For each candidate \(a\), perform a graph search starting at \(a\):

  • Mark \(a\) as discovered and place it in a queue.
  • Whenever a discovered vertex \(u\) is removed from the queue, inspect every candidate \(v\).
  • If \(E_{uv}=1\) and \(v\) has not been discovered, mark and enqueue \(v\).
  • Continue until the queue is empty.

The discovered vertices are exactly those reachable from \(a\). To verify this:

  • Every newly discovered vertex has an incoming edge from a previously discovered vertex. Induction on discovery order therefore supplies a directed path from \(a\) to every discovered vertex.
  • Conversely, let \(a=v_0,v_1,\ldots,v_k=b\) be a directed path. Induction on its length shows that \(v_i\) is discovered: once \(v_{i-1}\) is discovered, it is eventually processed, and its outgoing edge to \(v_i\) is inspected.

Thus the Top Cycle coordinate for \(a\) is \(1\) exactly when this search discovers all \(m\) candidates. Including \(a\) itself causes no issue, since the definition requires reachability of every other candidate.

Each vertex is processed at most once, and processing it scans \(m\) adjacency entries. A search therefore takes \(O(m^2)\) operations, and all \(m\) searches take \(O(m^3)\).

3. Computing the Uncovered Set

For each ordered pair of distinct candidates \(c,a\), evaluate
\[ C_{ca} = E_{ca}\ \land\ \bigwedge_{b\in A} \bigl(\neg E_{ab}\ \lor\ E_{cb}\bigr). \]

This expression is true exactly when \(c\) covers \(a\). Its first condition says \(c\succ_T a\). For every \(b\), its remaining condition says that if \(a\succ_T b\), then \(c\succ_T b\). These are precisely the two requirements in the definition of covering.

Consequently, the Uncovered Set coordinate for \(a\) is
\[ U_a = \neg\bigvee_{c\in A\setminus\{a\}}C_{ca}. \]
This is \(1\) exactly when \(a\) has no coverer.

There are \(m(m-1)\) possible covering pairs, each checked by scanning \(m\) candidates. This computation takes \(O(m^3)\) Boolean operations.

4. Complexity and the margin promise

Tournament construction uses \(O(\tau m^2+\tau)\) arithmetic operations on integers of \(O(L)\) bits, together with polynomial-time ranking preprocessing. Integer addition, comparison, multiplication, and division all admit polynomial-time algorithms. The subsequent graph computations use \(O(m^3)\) Boolean operations and \(O(m^2)\) graph storage.

Hence the complete algorithm runs in time polynomial in \(m,\tau,L\) and returns both exact membership vectors.

Even if a pairwise margin is extremely small, the comparison \(2S_{ab}>D\) remains an exact integer comparison of polynomial bit length. No temperature limit or numerical approximation is needed.
