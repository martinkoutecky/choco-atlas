Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Fix a finite set \(T\) of complete valuation measures on \([0,1]\) and rational masses \(\mu_t\) summing to \(1\). For each admissible \(N\) with \(N\mu_t\in\mathbb{Z}\), create \(N\mu_t\) clones of each type. In the Robertson–Webb oracle model, what is the minimum worst-case query complexity, as a function of \(N\) and \(\tau=|T|\), for a protocol to partition the cake among the clones so that every clone weakly prefers its own piece to every other piece? In particular, is a polynomial bound in \(N\) and \(\tau\) achievable?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) distinct valuation types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has a nonnegative probability measure \(v_t\) on \([0,1]\), absolutely continuous with respect to Lebesgue measure, accessible only through a Robertson–Webb oracle; zero density on intervals is allowed.
An input also specifies an integer \(N\geq2\) satisfying \(k_t=N\mu_t\in\mathbb Z_{>0}\). There are \(k_t\) clones of type \(t\), whose identical valuations are known to the protocol; oracle answers can be reused among clones.
An allocation partitions the entire cake into pieces \(A_{t,r}\), one per clone \(1\leq r\leq k_t\); each piece is a finite union of intervals, with endpoints assigned disjointly. Require \(v_t(A_{t,r})\geq v_t(A_{s,q})\) for every pair of clones.
Protocols are deterministic and adaptive; each oracle call costs one query, internal computation is uncharged, and guarantees must hold for every valid cut-query response. Let \(L\) be the binary encoding length of the support masses and \(N\); state query bounds in \(N,\tau,L\). There is no item or candidate parameter \(m\).

What is the optimal worst-case Robertson–Webb query complexity for this clone allocation problem as a function of \(N,\tau,L\)? Is there a uniform polynomial query bound, or must every protocol have superpolynomial worst-case query complexity?

For finite agent lists, [Chèze](https://link.springer.com/article/10.1007/s00355-025-01633-7) establishes \(\Pr(C\geq n^{7+b})=O(n^{-(b-1)/3+1+o(1)})\), for \(b>4\), when agents’ valuation vectors on the \(n\) equal witness intervals are independent and uniform on the probability simplex.
For arbitrary finite agent lists, [Procaccia](https://www.cs.umd.edu/~gasarch/TOPICS/cake/lbenvyfreesq.pdf) proves an \(\Omega(n^2)\) query lower bound, and [Aziz–Mackenzie](https://arxiv.org/abs/1604.03655) give a bounded protocol using at most \(n^{n^{n^{n^{n^n}}}}\) queries; that protocol also applies to clone inputs.
No result verified in the search settles the polynomial query question for the stated support-and-clone model.

  • Interpreted complete valuation measures as nonnegative, normalized, absolutely continuous measures, following the discrete valuation domain; interval densities need not be strictly positive.
  • Required every listed mass to be positive and every admissible clone count to be a positive integer; excluded the trivial single-clone case.
  • Specified that shared type identities are known and oracle information may be reused across clones.
  • Specified deterministic worst-case protocols, with guarantees over all valid cut responses, because the question did not specify protocol randomization or cut tie-breaking.
  • Specified complete allocation into finite unions of intervals, allowing disconnected pieces and assigning endpoints disjointly.
  • Defined L as the encoding length of masses and N; valuation measures remain oracle inputs, and internal computation is uncharged.

Partial solution: an exact special case and a reduction to ordinary envy-free division

The general optimum and the polynomial-versus-superpolynomial question are not resolved here. The following results are proved:

  • Every admissible multiplicity vector requires at least $\tau(N-1)$ queries in the worst case.
  • The exact optimum is $N-1$ for one type.
  • The exact optimum is $2(N-1)$ for two types with multiplicities $(N-1,1)$.
  • A uniform polynomial query bound for this support-and-clone model exists if and only if one exists for ordinary exact envy-free division among an arbitrary finite list of agents, including repeated valuations.

The last two statements advance the results in the notes. All proofs below are self-contained, except for explicitly cited general upper-bound theorems.

1. Definitions and elementary consequences

Fix $N$ and an admissible multiplicity vector
$$ \mathbf{k}=(k_1,\ldots,k_\tau),\qquad k_t\in\mathbb Z_{>0},\qquad \sum_{t=1}^{\tau}k_t=N. $$
The masses are then $\mu_t=k_t/N$.

Let $Q(N,\mathbf{k})$ denote the optimal worst-case number of queries among deterministic protocols correct for all admissible valuation profiles and every valid sequence of cut responses. Internal computation is uncharged.

Index the clones by
$$ \mathcal I=\{(t,r):1\leq t\leq\tau,\ 1\leq r\leq k_t\}. $$
For an allocation $(A_i)_{i\in\mathcal I}$, envy-freeness requires
$$ v_t(A_{t,r})\geq v_t(A_j) \qquad \text{for every }t,r,j. $$

Two immediate consequences will be useful. First, clones of the same type must receive equal values according to their common measure:
$$ v_t(A_{t,r})=v_t(A_{t,q}). $$
Indeed, the envy-freeness inequalities hold in both directions.

Second, every clone receives value at least $1/N$. If its own value is $c$, then every piece has value at most $c$ according to its measure. Since the entire cake is allocated,
$$ 1=\sum_{j\in\mathcal I}v_t(A_j)\leq Nc. $$

Absolute continuity implies that endpoints have value zero. Thus any disjoint assignment of the finitely many endpoints preserves all relevant values.

2. A finite-transcript lemma: the distinct-type promise gives no bounded-query advantage

Temporarily relax the requirement that the $\tau$ listed measures be pairwise distinct. Keep the labels and multiplicities unchanged; only the distinctness promise is removed.

Lemma: distinct completion preserving piece values

Suppose a finite Robertson–Webb transcript is generated by absolutely continuous probability measures $v_1,\ldots,v_\tau$, which may coincide. Fix also finitely many pieces, each a finite union of intervals.

There exist pairwise distinct absolutely continuous probability measures $\widetilde v_1,\ldots,\widetilde v_\tau$ that reproduce every oracle response in the transcript and preserve every specified piece value.

Proof. Form a common grid containing $0,1$, every query endpoint, and every endpoint of a specified piece. Write its positive-length cells as $J_1,\ldots,J_d$. Set
$$ w_{t,\ell}=v_t(J_\ell). $$
Endpoint values are zero, so $\sum_\ell w_{t,\ell}=1$.

For each type $t$, first replace its density by the piecewise constant density
$$ f_t(x)=\frac{w_{t,\ell}}{\lambda(J_\ell)} \qquad (x\in J_\ell), $$
where $\lambda$ denotes Lebesgue measure. This preserves every grid-cell mass, and therefore every queried interval value and specified piece value.

Because the cell masses sum to one, some cell $J_{\ell(t)}$ has $w_{t,\ell(t)}>0$. On that cell, $f_t$ is a positive constant $c_t$. Let $h_t$ equal $1$ on its left half, $-1$ on its right half, and zero elsewhere. Then $h_t$ is nonzero on a set of positive measure and has integral zero on every grid cell.

For any coefficient satisfying $|a_t|<c_t$, the density
$$ g_t=f_t+a_t h_t $$
is nonnegative and preserves all grid-cell masses.

Choose the coefficients successively. For each previously chosen density $g_s$, the equality
$$ f_t+a_t h_t=g_s \quad\text{almost everywhere} $$
excludes at most one coefficient: two different coefficients cannot yield the same density because $h_t$ is nonzero on a set of positive measure. There are only finitely many exclusions, so an admissible coefficient remains.

The resulting measures are pairwise distinct. Successful cut responses remain valid because their interval values are preserved. If infeasible cut queries are permitted, their failure responses remain valid because the corresponding suffix values are preserved. ∎

Corollary: bounded protocols extend to coincident listed measures

A protocol with worst-case bound $B$ under the distinct-type promise remains correct, with the same bound, when the listed measures may coincide.

Proof. Run the protocol on a possibly coincident profile. Every finite transcript has a distinct completion by the lemma.

If this execution attempted a $(B+1)$st query, a distinct completion of its first $B$ responses would force the same deterministic protocol to attempt that query, contradicting its bound. Likewise, an execution that failed to terminate after a finite transcript would contradict termination on a distinct completion of that transcript.

At termination, apply the lemma including all output pieces. The distinct completion produces the same transcript and allocation and gives every type the same values for every output piece. Correctness on that completion therefore implies correctness on the original profile. ∎

Consequently, removing the distinctness promise does not change the optimal finite worst-case query bound. The reverse inequality follows simply because distinct profiles form a subset of the relaxed profiles.

Scope. This extension uses a finite worst-case bound. Finite termination separately on every distinct profile, without a uniform bound, would not justify the termination argument above.

3. Proven general lower bound

Theorem

For every admissible multiplicity vector,
$$ Q(N,\mathbf{k})\geq\tau(N-1). $$

Proof. Consider any correct protocol with finite worst-case bound. By Section 2, it also works when all listed measures equal $\lambda$.

Answer every query according to $\lambda$. The protocol terminates. Under this profile, envy-freeness forces every output piece to have the same length, because every clone compares pieces by length. Hence
$$ \lambda(A_j)=\frac1N \qquad(j\in\mathcal I). $$

Form a grid containing all query and output endpoints. Let its positive-length cells be $J_1,\ldots,J_d$, and set
$$ w_\ell=\lambda(J_\ell)>0. $$

Fix a type $t$, and let $q_t$ be the number of queries to its oracle. Construct a matrix $D_t$ with $d$ columns and at most $q_t+1$ rows:

  • Include the all-ones row, which imposes normalization.
  • For each evaluation or successful cut query, include the indicator row of its queried interval.
  • If failed cuts are permitted, include the indicator row of the suffix whose available value determines feasibility.

Preserving these interval masses preserves every response to type $t$.

Take any $\delta\in\ker D_t$. For sufficiently small $\varepsilon>0$, both vectors
$$ w+\varepsilon\delta \qquad\text{and}\qquad w-\varepsilon\delta $$
have strictly positive coordinates. Their coordinates sum to one because the normalization row annihilates $\delta$. Dividing each coordinate by its cell length defines two absolutely continuous probability measures reproducing all responses to type $t$.

Keep every other type uniform. Both resulting profiles reproduce the complete transcript, so determinism gives the same output allocation. Section 2 guarantees correctness even if some listed measures coincide.

For each clone $j$, let $p_j\in\mathbb R^d$ be the indicator vector of its allocated grid cells. Fix a clone $i$ of type $t$. Correctness for both perturbations gives
$$ (p_i-p_j)\cdot(w+\varepsilon\delta)\geq0, \qquad (p_i-p_j)\cdot(w-\varepsilon\delta)\geq0 $$
for every $j$.

The unperturbed difference is zero because both pieces have length $1/N$. Thus
$$ (p_i-p_j)\cdot\delta=0 \qquad \text{for every }\delta\in\ker D_t. $$
The finite-dimensional identity
$$ (\ker D_t)^\perp=\operatorname{rowspan}(D_t) $$
therefore implies
$$ p_i-p_j\in\operatorname{rowspan}(D_t). $$

Since the allocation partitions the cells,
$$ \mathbf1=\sum_jp_j. $$
Consequently,
$$ Np_i=\mathbf1+\sum_{j\ne i}(p_i-p_j). $$
The right-hand side belongs to $\operatorname{rowspan}(D_t)$, so $p_i$ does too. Subtracting the already established differences shows that every $p_j$ belongs to that row space.

The $N$ vectors $p_j$ have disjoint supports, and each support is nonempty because its piece has length $1/N>0$. They are therefore linearly independent. Hence
$$ N\leq\operatorname{rank}(D_t)\leq q_t+1, $$
which yields $q_t\geq N-1$.

Summing over the type oracles gives
$$ \sum_{t=1}^{\tau}q_t\geq\tau(N-1). $$
Section 2 transfers this lower bound back to the distinct-type model. Protocols with infinite worst-case query complexity already satisfy the asserted lower bound. ∎

In particular, the argument counts actual type-oracle calls; sharing answers among clones does not weaken it.

4. Two exactly solved multiplicity families

One type

For $\tau=1$,
$$ Q(N,(N))=N-1. $$

Proof. Ask
$$ \operatorname{Cut}_1\left(0,\frac jN\right), \qquad 1\leq j\leq N-1. $$
Let the responses be $x_j$, with $x_0=0$ and $x_N=1$.

The cumulative function $F(x)=v_1([0,x])$ is continuous, so every requested target is attained. Monotonicity shows that every valid sequence of responses satisfies
$$ 0=x_0<x_1<\cdots<x_N=1: $$
a point attaining a larger target cannot precede or equal one attaining a smaller target.

The consecutive intervals therefore each have value $1/N$. Allocating them to the clones is envy-free and uses $N-1$ queries. Section 3 supplies the matching lower bound. ∎

Two types, one exceptional clone

For two types with multiplicities $(N-1,1)$,
$$ Q(N,(N-1,1))=2(N-1). $$

Proof. Call the majority type $a$ and the singleton type $b$.

Using $N-1$ cut queries to type $a$, partition the cake into consecutive intervals $I_1,\ldots,I_N$, each satisfying
$$ v_a(I_j)=\frac1N. $$
The preceding proof establishes correctness for every valid cut response, including valuations with zero-density intervals.

Evaluate $I_1,\ldots,I_{N-1}$ using type $b$’s oracle. Normalization determines the remaining value:
$$ v_b(I_N)=1-\sum_{j=1}^{N-1}v_b(I_j). $$

Give a maximum-value interval according to $v_b$ to the singleton, breaking ties by a fixed index order. Give the remaining intervals to the majority clones.

Every majority clone values every allocated piece at $1/N$, so none envies. The singleton receives a maximum-value piece according to its own measure, so it does not envy either.

The protocol uses $2(N-1)$ queries. Section 3, with $\tau=2$, proves that fewer cannot suffice in the worst case. ∎

Thus the support-sensitive lower bound is attained for a nontrivial two-type family for every $N$.

5. Equivalence of the polynomial-query questions

Theorem

  • The support-and-clone problem admits a uniform query bound polynomial in $N,\tau,L$.

Proof that 2 implies 1. Expand the support into its $N$ named clones and run the ordinary protocol. Implement each clone query through its type oracle.

The expanded profile satisfies the ordinary hypotheses, including when valuations repeat. Every returned cut response is valid for the queried clone. Thus the protocol’s guarantee applies to every valid response sequence. A polynomial bound in $N$ is also polynomial in $N,\tau,L$. Computing multiplicities and expanding labels use no valuation queries.

Proof that 1 implies 2. For $n$ ordinary agents, supply the clone protocol with
$$ N=\tau=n,\qquad \mu_t=\frac1n,\qquad k_t=1. $$
Using the binary rational encoding in the task, this metadata has length $L=O(n\log n)$. Therefore a bound polynomial in $N,\tau,L$ becomes polynomial in $n$.

For pairwise distinct valuations, correctness follows directly. For arbitrary valuations, including repetitions, Section 2 extends that bounded protocol to the same labelled input without the distinctness promise. The resulting allocation is an ordinary envy-free allocation. ∎

More strongly, for the canonical metadata above, the optimal finite worst-case bound equals that of the ordinary $n$-agent problem. One direction uses the extension lemma; the other runs an ordinary protocol on the restricted distinct profiles.

This establishes an equivalence, rather than merely observing that distinct ordinary profiles occur as special clone inputs. It does not prove either side of the polynomial-versus-superpolynomial dichotomy.

6. General upper bounds from external theorems

The stipulated [Aziz–Mackenzie theorem](https://arxiv.org/abs/1604.03655) gives
$$ Q(N,\mathbf{k}) \leq N^{N^{N^{N^{N^N}}}}. $$
Expand the input into $N$ named clones and simulate their queries through the type oracles. The task explicitly permits this application; reuse can only reduce the query count.

A newer external result improves this bound. Ye–Bai, Theorem 1.1, states that a deterministic Robertson–Webb protocol computes a complete envy-free allocation for nonnegative, additive, nonatomic valuations using $n^{O(1)}2^n$ queries. [September 2026 preprint](https://arxiv.org/html/2609.05191v1#S1.SS2)

Its model allows finite unions of intervals and arbitrary valid cut responses. Absolute continuity supplies nonatomicity; repeated valuations are permitted. Applying the theorem to the expanded clone list therefore gives
$$ Q(N,\mathbf{k})\leq C N^d2^N $$
for absolute constants $C,d>0$. Endpoint assignment preserves values, and internal computation is uncharged.

Using this cited external theorem, the general bounds are consequently
$$ \tau(N-1)\leq Q(N,\mathbf{k})\leq C N^d2^N. $$
The upper bound’s exponential form does not establish an exponential lower bound.

7. Encoding dependence and the probabilistic result

There cannot be a bound polynomial in $\tau,L$ alone. Take one type and $N=2^h$. Then $\mu_1=1$, the encoding length is $L=\Theta(h)$, and Section 4 gives the exact complexity

This leaves open polynomial dependence on $N,\tau,L$, as requested.

The [Chèze theorem](https://link.springer.com/article/10.1007/s00355-025-01633-7) quoted in the task concerns independent, uniformly distributed witness-interval valuation vectors. When $\tau<N$, at least two clones have identical witness vectors. Their joint distribution cannot satisfy that hypothesis: independent uniform simplex vectors are equal with probability zero.

Even when $\tau=N$, the stated high-probability estimate does not bound the maximum query count over arbitrary valuations. It therefore supplies neither a uniform polynomial upper bound nor a superpolynomial worst-case lower bound here.
