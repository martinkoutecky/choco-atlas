The continuous mirror question, as graded

Given \(N\) people represented by \(\tau\) complete baseline-access types with rational masses \(n_t/N\), agency supplies \(q_j\), and a fixed ladder \(0<\mu_1<\cdots<\mu_r\le1\), compute the maximum certified service welfare over profile-only stochastic admissions. For each positive-mass bucket profile \(a\), choose admitted masses \(z_{a\ell}\ge0\) maximizing \(\sum_{a,\ell}\mu_\ell z_{a\ell}\), subject to \(\sum_\ell z_{a\ell}\le p_a\) and \(\sum_{a,\ell:j\in S_\ell(a)}\mu_\ell z_{a\ell}\le q_j\) for every agency \(j\); output the maximizing masses or equivalent conditional admission probabilities.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) distinct complete baseline-access types \(w^t\in([0,1]\cap\mathbb Q)^m\), each with positive binary-rational mass \(p_t\), where \(\sum_t p_t=1\). Here \(\tau\) is the support size, not the number of possible types. There are \(m\ge2\) agencies with per-capita supplies \(q_j\in\mathbb Q_{\ge0}\), and a fixed input ladder \(0<\mu_1<\cdots<\mu_r\le1\) of binary rationals, with \(r\ge1\). Let \(L\) be the total binary input length; state running times in \(m,\tau,r,L\).
Set \(\mu_0=0\). Type \(t\) reports bucket profile \(a^t\), where \(a_j^t=\max\{\ell\in\{0,\ldots,r\}:\mu_\ell\le w_j^t\}\). For each positive-mass profile \(a\), define \(p_a=\sum_{t:a^t=a}p_t\) and \(S_\ell(a)=\{j:a_j<\ell\}\); equality with a threshold is unflagged.
A profile-only stochastic admission rule chooses level \(\ell\) with conditional probability \(z_{a\ell}/p_a\), independently of raw coordinates given \(a\), and chooses no service with the remaining probability. Selecting level \(\ell\) supplies \(\max\{\mu_\ell-w_j^t,0\}\) at agency \(j\), but conservatively charges \(\mu_\ell\) whenever \(j\in S_\ell(a)\).
Maximize certified service welfare \(\sum_a\sum_{\ell=1}^r\mu_\ell z_{a\ell}\), subject to \(z_{a\ell}\ge0\), \(\sum_{\ell=1}^r z_{a\ell}\le p_a\), and \(\sum_a\sum_{\ell:j\in S_\ell(a)}\mu_\ell z_{a\ell}\le q_j\) for every agency. Capacities are ex ante; the objective excludes baseline welfare and is not actual total welfare. Output exact maximizing masses or equivalent conditional probabilities.

Is this exact optimization problem solvable in time polynomial in \(m,\tau,r,L\), or is it NP-hard?

Known results: For empirical societies and fixed ladders, stochastic implementation is established with at most \(r\) variables per positive-mass profile and \(m\) capacity constraints, besides profile constraints.
The same established formulation and implementation explicitly apply to distributional societies, including the finitely supported rational inputs specified here; thus this continuous problem is already covered.

Conclusion

The exact optimization problem is polynomial-time solvable in \(m,\tau,r,L\). This holds when the ladder is part of the input and when some capacities are zero.

1. Construct only profiles present in the support

Let \(\mathcal A=\{a^t:1\le t\le\tau\}\) and \(s=|\mathcal A|\). Since each support type produces one profile, \(s\le\tau\). There is no need to enumerate all \((r+1)^m\) possible profiles.

Compute each bucket index by exact rational comparisons. In particular, the definition uses \(\mu_\ell\le w_j^t\), so equality with a threshold is unflagged. Group identical profiles and compute their masses \(p_a\).

These operations have polynomial bit complexity. To check that aggregation preserves polynomial encoding length, write each input mass as \(p_t=u_t/v_t\). For a profile \(a\), a common denominator for its mass is

\(D_a=\prod_{t:a^t=a}v_t.\)

The binary length of this product is at most the sum of the binary lengths of its factors, up to a constant, and hence is \(O(L)\). Since \(0<p_a\le1\), its numerator over this denominator also has \(O(L)\) bits. Reduction to lowest terms cannot increase these lengths.

Using a direct scan of the ladder and pairwise comparison of profiles, preprocessing takes at most

\(O\bigl((\tau mr+\tau^2m)L^2\bigr)\)

bit operations with ordinary integer arithmetic. This deliberately coarse bound suffices for polynomiality.

2. The resulting rational linear program has polynomial size

Introduce one variable \(z_{a\ell}\) for each \(a\in\mathcal A\) and \(1\le\ell\le r\). Thus the number of variables is

\(N=sr\le\tau r.\)

The objective is

\(\displaystyle \max\sum_{a\in\mathcal A}\sum_{\ell=1}^r\mu_\ell z_{a\ell}.\)

The constraints are

\(\displaystyle z_{a\ell}\ge0,\qquad \sum_{\ell=1}^r z_{a\ell}\le p_a,\)

and, for each agency \(j\),

\(\displaystyle \sum_{a\in\mathcal A}\sum_{\ell=1}^r \mu_\ell\,\mathbf 1_{\{a_j<\ell\}}z_{a\ell}\le q_j.\)

There are \(s+m\) profile and capacity constraints, plus \(N\) nonnegativity constraints. Every coefficient is zero, one, minus one, or an input threshold; every right-hand side has \(O(L)\) bits by the preceding aggregation argument.

Consequently, even a dense encoding of the entire program has length

\(B=O\bigl((m+\tau+\tau r)\tau r(L+1)\bigr).\)

This bound is polynomial in the requested parameters.

The program is feasible because \(z=0\) satisfies every constraint: all profile masses and capacities are nonnegative. It is bounded because every feasible vector satisfies

\(0\le z_{a\ell}\le p_a\le1.\)

Its feasible region is therefore a nonempty compact polytope, so the linear objective attains its maximum.

3. Exact optimization and output

Use the standard rational linear-programming theorem: an explicitly encoded rational linear program can be solved in polynomial bit time, returning an exact rational optimum when feasible with finite optimum. The ellipsoid method establishes this polynomial-time result; see [Grötschel, Lovász and Schrijver, *George Dantzig’s impact on the theory of computation*](https://doi.org/10.1016/j.disopt.2006.12.004).

All its hypotheses hold here: the program is explicitly represented, its data are rational, its encoding length is polynomial, and it has an attained finite optimum. The theorem applies also to lower-dimensional feasible regions, including those caused by zero capacities.

For completeness, exact output does not require exponentially many bits. A compact polytope has an optimal vertex. At any vertex, \(N\) linearly independent tight constraints determine its coordinates. Let \(D\) be the product of the denominators of all input masses, thresholds, and capacities. Its binary length is \(O(L)\), and every aggregated mass has denominator dividing \(D\).

Multiplying each constraint by \(D\) gives integer coefficients and right-hand sides with \(O(L)\) bits. Cramer’s rule expresses each vertex coordinate as a ratio of determinants of matrices of order \(N\). By Hadamard’s inequality, these determinants have

\(O\bigl(N(L+\log(N+1))\bigr)\)

bits. Thus an exact optimal vector has polynomial encoding length.

Combining construction with rational linear programming gives the running-time bound

\(\displaystyle O\bigl((\tau mr+\tau^2m)L^2\bigr)+\bigl((m+\tau+\tau r)\tau r(L+1)\bigr)^{O(1)}.\)

In particular, the running time is polynomial in \(m,\tau,r,L\).

4. Recover the requested stochastic rule

Given an exact maximizing vector \(z^*\), output the conditional probabilities

\(\displaystyle \pi_{a\ell}=\frac{z^*_{a\ell}}{p_a},\qquad \pi_{a0}=1-\sum_{\ell=1}^r\pi_{a\ell}.\)

Every denominator \(p_a\) is positive. Nonnegativity and the profile constraint imply that these probabilities are nonnegative and sum to one. Their computation and encoding lengths are polynomial.

The correspondence is exact in both directions: a profile-only rule with conditional level probabilities \(\pi_{a\ell}\) gives masses \(z_{a\ell}=p_a\pi_{a\ell}\); conversely, feasible masses give the probabilities above. The certified objective and conservative capacity charges are precisely the displayed linear expressions.

To verify the stated supply interpretation, the bucket definition gives

\(a_j<\ell\ \Longleftrightarrow\ w_j^t<\mu_\ell\)

for every type \(t\) in profile \(a\). Hence

\(\displaystyle \max\{\mu_\ell-w_j^t,0\}\le\mu_\ell\mathbf 1_{\{a_j<\ell\}}.\)

Since admission probabilities depend only on the profile, actual expected consumption at agency \(j\) is at most

\(\displaystyle \sum_{a\in\mathcal A}\sum_{\ell=1}^r\mu_\ell\mathbf 1_{\{a_j<\ell\}}z^*_{a\ell}\le q_j.\)

Thus the exact optimum also yields the requested implementation. The proof permits arbitrary input ladder length \(r\) and uses only profiles appearing in the finite support.
