The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), a finite template set \(\mathcal K\subseteq\mathbb Z_{\ge0}^{\tau}\setminus\{0\}\), and a total preorder \(\succcurlyeq\) on \(\mathcal K\), find \(q\ge0\) satisfying \(\sum_{a\in\mathcal K}a_tq_a=\mu_t\) for every \(t\), such that no template \(b\) has \(\sum_{a:\,b\succ a}a_tq_a>0\) for every type \(t\) with \(b_t>0\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of its \(\tau\) types with positive binary rational masses \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also explicitly lists \(\mathcal K\subseteq\mathbb Z_{\ge0}^{\tau}\setminus\{0\}\), with binary integer coordinates, and a total preorder \(\succcurlyeq\) represented by ordered indifference classes; write \(m=|\mathcal K|\) and let \(L\) be the total input bit length.
Only listed templates are admissible. All types share this ranking; \(b\succ a\) means strict preference, and indifference creates no incentive to deviate.
An allocation is \(q\in\mathbb R_{\ge0}^{\mathcal K}\) satisfying \(\sum_{a\in\mathcal K}a_tq_a=\mu_t\) for every \(t\in T\); thus template \(a\) receives type masses \(a_tq_a\).
A template \(b\) blocks \(q\) exactly when \(\sum_{a\in\mathcal K:\,b\succ a}a_tq_a>0\) for every \(t\) with \(b_t>0\): deviations may use any positive scale of \(b\). An allocation is stable if no template blocks it.

Is deciding whether a stable allocation exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? Is finding one when it exists polynomial-time solvable, or \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L\).

For finite agents with a common total preorder on all nonempty coalitions, stable partitions are exactly those generated by repeatedly selecting a strongest remaining coalition and deleting intersecting coalitions; one partition is obtainable in polynomial time in the explicit input size. [Source](https://www.lamsade.dauphine.fr/~moretti/preprints/LMR.pdf)
No result settling this exact continuous template problem was located in the literature search.

Modeling choices made when packaging the task

  • Removed zero-mass types to follow the required support representation and retained total mass one.
  • Specified explicit template and ranking representations, binary coordinate encoding, m as the template count, and L as total input bit length.
  • Interpreted blocking as allowing arbitrarily small positive scales of a template, as dictated by the graded positivity condition.
  • Retained the explicitly given admissible template set without adding singleton templates; because feasibility is not promised, the computational task includes deciding existence.

Result

Deciding whether a stable allocation exists is \(\mathrm{NP}\)-complete. Finding one is \(\mathrm{NP}\)-hard. These statements hold even with three indifference classes, equal dyadic masses, and templates having zero–one coordinates and at most four nonzero coordinates.

Both decision and construction admit an exact algorithm with running time

\( \displaystyle O\!\left(\left[\sum_{j=0}^{\min\{m,\tau\}}\binom mj\right]\operatorname{poly}(m,\tau,L)\right). \)

Thus this is at most \(2^m\operatorname{poly}(m,\tau,L)\), and also at most \((m+1)^\tau\operatorname{poly}(m,\tau,L)\). Neither problem has a polynomial-time algorithm unless \(\mathrm P=\mathrm{NP}\).

The proofs follow.

1. Stability depends only on support

For an allocation \(q\), define its support by

\( S(q)=\{a\in\mathcal K:q_a>0\}. \)

Since every summand in the blocking condition is nonnegative,

\( \displaystyle \sum_{a:\,b\succ a}a_tq_a=0 \quad\Longleftrightarrow\quad a_t=0\text{ for every }a\in S(q)\text{ with }b\succ a. \)

Consequently, \(q\) is stable exactly when

\[ \displaystyle \forall b\in\mathcal K\;\exists t\text{ with }b_t>0: \quad a_t=0\text{ for every }a\in S(q)\text{ with }b\succ a. \tag{1} \]

In particular, if \(q\) is stable and \(p\) is another feasible allocation with \(S(p)\subseteq S(q)\), then \(p\) is stable: every zero sum witnessing the stability of \(q\) remains zero for \(p\).

2. Polynomial-size certificates

Lemma. If a stable allocation exists, then one exists with at most \(\tau\) positive entries, all rational and of polynomial encoding length.

Proof. Let \(q\) be stable. Among feasible allocations supported inside \(S(q)\), choose \(p\) with the smallest support cardinality. Such a choice exists because there are finitely many possible supports.

The columns corresponding to \(S(p)\) are linearly independent. Otherwise there is a nonzero vector \(v\), indexed by \(S(p)\), satisfying

\( \displaystyle \sum_{a\in S(p)}a\,v_a=0. \)

Replacing \(v\) by \(-v\) if necessary, assume some \(v_a>0\). Define

\( \displaystyle \varepsilon=\min_{a:\,v_a>0}\frac{p_a}{v_a}>0. \)

Then \(p-\varepsilon v\) is nonnegative, satisfies the same balance equations, and has strictly smaller support. This contradicts the choice of \(p\).

Write \(r=|S(p)|\). Linear independence gives \(r\leq\tau\), and some \(r\) rows yield a nonsingular integer matrix \(B\). The positive entries of \(p\) satisfy

\( Bp_{S(p)}=\mu_I. \)

Cramer’s rule makes them rational. To bound their encoding length, let \(D_\mu\) be the product of the denominators of the selected masses. Its bit length is \(O(L)\). Clearing these denominators and using the determinant bound

\( |\det B|\leq r!\,H^r, \)

where \(H\) bounds the absolute entries, shows that each numerator and denominator has \(O(r(L+\log(r+1)))\) bits. This is polynomial in the input length.

Finally, \(p\) is stable by support containment and (1). \(\square\)

A verifier checks the balance equations and the blocking conditions by exact rational arithmetic. Processing indifference classes from worst to best, while accumulating the type masses assigned to strictly worse classes, requires \(O(m\tau)\) arithmetic operations. The certificate bounds make the bit running time polynomial in \(m,\tau,L\).

Therefore the decision problem belongs to \(\mathrm{NP}\).

3. Reduction from satisfiability

We reduce from the standard \(\mathrm{NP}\)-complete problem of satisfiability for Boolean formulas in conjunctive normal form with at most three literals per clause.

Remove tautological clauses, repeated literals, and duplicate clauses. These operations preserve satisfiability. Every remaining clause is nonempty and contains distinct variables. Let the variables be \(v_1,\ldots,v_n\), with \(n\geq1\), and let the clauses be \(F_1,\ldots,F_c\).

Types and masses

For each variable introduce types \(x_i,y_i,z_i\), and introduce two additional types \(h,k\).

To obtain equal dyadic masses, set

\( \displaystyle D=2^{\lceil\log_2(3n+2)\rceil}, \qquad d=D-(3n+2), \qquad \sigma=\frac1D. \)

Add dummy types \(w_1,\ldots,w_d\). Every type has mass \(\sigma\), so

\( \tau=D,\qquad \sum_{t\in T}\mu_t=D\sigma=1. \)

Let \(e_t\) denote the unit vector of type \(t\).

Templates and ranking

There are three indifference classes, ordered from best to worst.

| Class | Listed templates |
|---|---|
| Top | \(A_i=e_{x_i}+e_{z_i}\), \(B_i=e_{y_i}+e_{z_i}\), for every \(i\) |
| Middle | \(G_i=e_{x_i}+e_{y_i}+e_h\), for every \(i\); and clause templates \(C_j\), defined below |
| Bottom | \(X_i=e_{x_i}\), \(Y_i=e_{y_i}\), for every \(i\); \(R=e_h+e_k\); and \(W_s=e_{w_s}\), for every dummy type |

For a literal \(\ell\), define its associated type by

\( \displaystyle s(v_i)=x_i,\qquad s(\neg v_i)=y_i. \)

The clause template is

\( \displaystyle C_j=e_h+\sum_{\ell\in F_j}e_{s(\ell)}. \)

The preprocessing ensures that clause templates have zero–one coordinates. It also ensures that they are distinct from each other and from the variable templates \(G_i\): a clause contains no variable with both signs.

Every template is nonzero and has at most four nonzero coordinates. The number of templates is

\( m=5n+c+1+d. \)

Moreover, \(D<2(3n+2)\), so both \(m\) and \(\tau\) are polynomial in the formula size. Under explicit coordinate encoding, the constructed input length is

\( L=O(m\tau+\tau\log\tau+m\log m). \)

The reduction therefore takes polynomial time.

4. What feasibility forces

Let \(q\) be any feasible allocation.

Only \(R\) contains type \(k\). Its balance equation forces

\( q_R=\sigma. \)

The templates containing \(h\) are precisely \(R\) and all middle templates. Hence the balance equation for \(h\) is

\( \displaystyle q_R+\sum_iq_{G_i}+\sum_jq_{C_j}=\sigma. \)

Substituting \(q_R=\sigma\) and using nonnegativity gives

\( q_{G_i}=q_{C_j}=0 \)

for every variable and clause template.

These middle templates receive zero mass in every feasible allocation, but they remain admissible deviations.

Write

\( u_i=q_{A_i},\qquad v_i=q_{B_i}. \)

Only \(A_i,B_i\) contain \(z_i\), so its balance equation gives

\[ u_i+v_i=\sigma. \tag{2} \]

Since all middle allocations vanish, the other two balance equations give

\[ q_{X_i}=\sigma-u_i=v_i,\qquad q_{Y_i}=\sigma-v_i=u_i. \tag{3} \]

Each dummy template has allocation \(q_{W_s}=\sigma\).

In particular, every constructed instance has a feasible allocation: take \(u_i=v_i=\sigma/2\), use (3), assign \(\sigma\) to \(R\) and every dummy template, and assign zero to all middle templates.

5. Stability is equivalent to satisfiability

Variable templates force Boolean choices

The templates strictly worse than \(G_i\) are the bottom templates. By (3), their masses of types \(x_i,y_i,h\) are respectively

\( v_i,\qquad u_i,\qquad \sigma. \)

Thus \(G_i\) blocks exactly when both \(u_i>0\) and \(v_i>0\). A stable allocation must therefore satisfy

\[ \displaystyle (u_i,v_i)\in\{(\sigma,0),(0,\sigma)\}, \tag{4} \]

because of (2).

Interpret these choices as

\( v_i\text{ is true}\quad\Longleftrightarrow\quad u_i=\sigma. \)

Here the symbol \(v_i\) in the phrase “\(v_i\) is true” denotes the Boolean variable; the allocation quantity \(v_i=q_{B_i}\) is zero in that case.

For a positive literal, the mass of its associated type assigned below the middle class is

\( q_{X_i}=v_i, \)

which is zero exactly when the literal is true. For a negative literal, that mass is

\( q_{Y_i}=u_i, \)

which is zero exactly when the negative literal is true.

Clause templates enforce satisfaction

For \(C_j\), the mass of type \(h\) assigned to strictly worse templates is \(\sigma>0\). Therefore \(C_j\) does not block exactly when at least one of its literal types has zero mass below the middle class.

Under the Boolean choices (4), this means exactly that at least one literal of \(F_j\) is true.

Consequently, every stable allocation yields a satisfying assignment.

A satisfying assignment yields stability

Conversely, given a satisfying assignment, choose

\( \displaystyle (u_i,v_i)= \begin{cases} (\sigma,0),&\text{if the Boolean variable is true},\\ (0,\sigma),&\text{if it is false}. \end{cases} \)

Use the bottom allocations prescribed by (3), assign \(\sigma\) to \(R\) and each dummy template, and assign zero to all middle templates. The preceding balance equations prove feasibility.

Every listed template is nonblocking:

  • Each top template contains \(z_i\), whose mass assigned to strictly worse templates is zero.
  • Each \(G_i\) has one of its two literal types entirely allocated in the top class.
  • Each \(C_j\) has a literal type entirely allocated in the top class because the clause is satisfied.
  • Bottom templates have no strictly worse templates.

The allocation is therefore stable.

This proves the equivalence

\( \displaystyle \text{the formula is satisfiable} \quad\Longleftrightarrow\quad \text{a stable allocation exists}. \)

Together with Section 2, it establishes \(\mathrm{NP}\)-completeness.

6. Search hardness and running times

The reduction also proves search hardness directly: from any stable allocation, read the Boolean choices (4) to obtain a satisfying assignment. Thus finding a stable allocation is \(\mathrm{NP}\)-hard under polynomial-time search reductions.

A polynomial-time algorithm guaranteed to return a stable allocation on every yes-instance would imply \(\mathrm P=\mathrm{NP}\). Run it for its polynomial time bound and verify its output: on a yes-instance it returns a valid allocation, while on a no-instance no output can pass verification.

For an unconditional exact algorithm, enumerate every subset \(S\subseteq\mathcal K\) of cardinality at most \(\tau\). For each subset:

  • Check the support condition (1).
  • If it passes, solve the rational linear feasibility problem

\( \displaystyle \sum_{a\in S}a_tq_a=\mu_t\quad(t\in T),\qquad q_a\geq0\quad(a\in S). \)

Any feasible solution has support contained in \(S\), so (1) proves its stability. Conversely, the sparse-certificate lemma guarantees that a stable instance has a subset encountered by this enumeration.

The support check takes \(O(m\tau)\) Boolean operations by processing ranking classes from worst to best. Each linear program has at most \(\min\{m,\tau\}\) variables, \(\tau\) balance equations, and encoding length \(O(L)\), and is solvable in polynomial bit time. This proves the stated running-time bound for both decision and construction.

7. Relation to the finite-agent result

The [cited finite-agent theorem](https://www.lamsade.dauphine.fr/~moretti/preprints/LMR.pdf) assumes a ranking over all nonempty coalitions. Here admissibility is restricted to listed templates.

The reduction uses that restriction explicitly: \(k\) appears only in \(R\), forcing every middle template to receive zero allocation. Such templates nevertheless impose blocking conditions. Those conditions force discrete choices even though allocation quantities are continuous. Every reduced instance remains feasible, so the hardness concerns stability itself.
