The continuous mirror question, as graded

Given a finite candidate set \(C\), committee size \(k\), positional scoring vector \(s\), finite support \(T\) of complete ranking types, and rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), output a committee \(W\subseteq C\) with \(|W|=k\) maximizing \(\operatorname{CC}_{s,\mu}(W)=\sum_{t\in T}\mu_t\max_{c\in W}s(\operatorname{pos}_t(c))\).

Packaged proof task (what the prover saw — nothing else)

Definition

An instance consists of a finite candidate set \(C\), a committee size \(k\), a positional scoring vector \(s\), and a finite set \(T\) of complete ranking types with rational masses \(\mu_t\ge 0\) satisfying \(\sum_{t\in T}\mu_t=1\). For a type \(t\), let \(\operatorname{pos}_t(c)\) be candidate \(c\)'s rank. The Chamberlin--Courant score of \(W\subseteq C\) is \(\operatorname{CC}_{s,\mu}(W)=\sum_{t\in T}\mu_t\max_{c\in W}s(\operatorname{pos}_t(c))\).

Target

Is computing a size-\(k\) committee maximizing \(\operatorname{CC}_{s,\mu}(W)\) solvable in polynomial time, or is it NP-hard?

Nearest known results

For finite voter-list elections, unconstrained winner determination for the Chamberlin--Courant rule is NP-hard; the anchor establishes this already when there are no diversity or representation constraints. The formulation here instead gives voters by rational masses on ranking types.

Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Theorem

Computing a size-\(k\) committee maximizing the Chamberlin--Courant score is \(\mathrm{NP\text{-}hard}\). This remains true under the following restrictions:

  • every type has the same mass;
  • the scoring vector is the \(2\)-approval vector \(s=(1,1,0,\ldots,0)\);
  • all ranking types are distinct.

Under the standard assumption that scoring values and masses are explicitly encoded rationals, the associated decision problem is \(\mathrm{NP\text{-}complete}\).

Reduction from Vertex Cover

We reduce from the following \(\mathrm{NP\text{-}complete}\) problem.

Vertex Cover. Given a finite simple undirected graph \(G=(V,E)\) and an integer \(k\), decide whether there is a set \(X\subseteq V\) with \(|X|\leq k\) such that every edge has at least one endpoint in \(X\).

It suffices to consider instances with \(E\neq\varnothing\) and \(1\leq k\leq |V|\), since the excluded cases are decidable immediately.

Given such an instance, construct a Chamberlin--Courant instance as follows.

Candidates and committee size

Let the candidate set be \(C=V\), and retain the committee size \(k\).

Scoring vector

For \(m=|V|\), use the positional scoring vector \(s\) defined by

\(s(1)=s(2)=1\), and \(s(j)=0\) for every \(3\leq j\leq m\).

Thus a type is represented with score \(1\) precisely when the committee contains one of its two highest-ranked candidates.

Ranking types

Fix an arbitrary total order on \(V\). For every edge \(e=\{u,v\}\in E\), introduce one complete ranking type \(t_e\) which:

  • ranks \(u\) and \(v\) in the first two positions, in their fixed total-order order; and
  • ranks all remaining candidates afterward, again in the fixed total order.

Because \(G\) is simple, distinct edges have distinct sets of top-two candidates. Hence the types \(t_e\) are pairwise distinct, as required when \(T\) is a set rather than a multiset.

Assign every type the uniform mass

\(\mu_{t_e}=1/|E|\).

These masses are nonnegative rationals and satisfy \(\sum_{e\in E}\mu_{t_e}=1\).

The construction contains \(|E|\) rankings, each of length \(|V|\), and is therefore computable in time polynomial in the size of \(G\).

Exact relation between score and edge coverage

Let \(W\subseteq V\) be any committee of size \(k\). For an edge \(e=\{u,v\}\), its two endpoints occupy the first two positions of \(t_e\). Therefore

\(\max_{c\in W}s(\operatorname{pos}_{t_e}(c))=1\)

if and only if \(W\cap\{u,v\}\neq\varnothing\). Otherwise every member of \(W\) occurs at position at least \(3\), so the maximum is \(0\).

Consequently,

\(\operatorname{CC}_{s,\mu}(W)=|\{e\in E:W\cap e\neq\varnothing\}|/|E|\).

Thus the Chamberlin--Courant score of \(W\) is exactly the fraction of graph edges covered by the corresponding vertex set.

In particular,

\(\operatorname{CC}_{s,\mu}(W)=1\)

if and only if \(W\) is a vertex cover of \(G\).

Correctness of the reduction

Suppose first that \(G\) has a vertex cover \(X\) with \(|X|\leq k\). Since \(k\leq |V|\), we may add arbitrary vertices to \(X\) until obtaining a set \(W\) with \(|W|=k\). Adding vertices cannot uncover any edge, so \(W\) is still a vertex cover. The preceding identity gives \(\operatorname{CC}_{s,\mu}(W)=1\).

Conversely, suppose there is a size-\(k\) committee \(W\) with \(\operatorname{CC}_{s,\mu}(W)=1\). Every type contributes at most its mass, and all masses are positive. Hence every edge type must contribute \(1/|E|\). Equivalently, \(W\) contains an endpoint of every edge. Therefore \(W\) is a vertex cover of size \(k\).

We have proved the equivalence

\(G\) has a vertex cover of size at most \(k\) if and only if there is a size-\(k\) committee with Chamberlin--Courant score \(1\).

Therefore deciding whether the optimal score is \(1\) is \(\mathrm{NP\text{-}hard}\). An algorithm computing an optimal committee would decide this question by computing its score, so the optimization problem is also \(\mathrm{NP\text{-}hard}\).

Membership of the decision version in \(\mathrm{NP}\)

For explicitly encoded rational masses, rational scoring values, and rational threshold \(q\), a committee \(W\) is a polynomial-size certificate. For each type, one scans \(W\) to determine its highest scoring member and then sums the resulting rational contributions exactly. This requires polynomially many rational arithmetic operations on polynomial-bit-length integers. Hence the decision version belongs to \(\mathrm{NP}\).

Combined with the reduction above, the decision version is \(\mathrm{NP\text{-}complete}\).

Conclusion

Passing from a finite voter list to rational masses on ranking types does not make unrestricted Chamberlin--Courant winner determination polynomial-time solvable. Hardness already occurs with uniform masses and the very simple \(2\)-approval scoring vector.

Verification Report

Summary

The reduction correctly translates vertex coverage into Chamberlin–Courant score under uniform masses and the \(2\)-approval scoring vector. The optimization problem is therefore NP-hard, and the explicitly encoded rational-threshold decision version is in NP.

There is one minor formal gap: the claimed restriction of Vertex Cover to \(E\neq\varnothing\) and \(1\leq k\leq |V|\) is not fully justified as a many-one reduction. The argument is sound in substance, but the write-up should explicitly explain how excluded source instances are mapped to fixed valid yes- and no-instances.

Step-by-step verification

  • Source problem. Vertex Cover on finite simple undirected graphs is NP-complete. The use of covers of size at most \(k\) is standard.
  • Restriction of source instances. The prover says that excluded cases “are decidable immediately.” This is not, by itself, a complete many-one-reduction justification. A polynomial-time reduction must still output a valid target instance for every source input. This is a minor gap because it can be repaired by specifying fixed valid yes- and no-instances for the excluded cases.
  • Candidate and committee construction. Setting \(C=V\) and preserving \(k\) is valid under \(1\leq k\leq |V|\).
  • Scoring vector. The vector with \(s(1)=s(2)=1\) and all later entries zero is a valid \(2\)-approval positional scoring vector. Since \(E\neq\varnothing\), the graph has at least two vertices, so the first two positions exist.
  • Ranking types. Each edge’s endpoints are placed first and second. As the graph is simple, different edges have different unordered endpoint sets, and therefore yield different complete rankings. The claim that all types are distinct is correct.
  • Masses. Assigning mass \(1/|E|\) to each edge type is valid because \(E\neq\varnothing\). The masses are positive rational numbers and sum to \(1\).
  • Polynomial construction size. There are \(|E|\) explicitly listed rankings of length \(|V|\). Their total size is polynomial in the graph’s encoding size.
  • Score–coverage identity. For each edge \(e=\{u,v\}\), the corresponding type contributes \(1/|E|\) exactly when \(W\) contains \(u\) or \(v\). Hence

\[ \operatorname{CC}_{s,\mu}(W) = \frac{|\{e\in E:W\cap e\neq\varnothing\}|}{|E|}. \]
This identity is correct.

  • Forward implication. A vertex cover \(X\) with \(|X|\leq k\) can be padded to exactly \(k\) vertices because \(k\leq |V|\). Supersets of vertex covers remain vertex covers, so the resulting committee has score \(1\).
  • Reverse implication. If a size-\(k\) committee has score \(1\), every positive-mass edge type must attain its maximum contribution. Thus every edge has an endpoint in the committee. This correctly yields a vertex cover of size \(k\).
  • NP-hardness. The equivalence at threshold \(1\) proves NP-hardness of the decision problem. An algorithm returning an optimal committee would also decide whether the optimum equals \(1\), since the returned committee’s score is polynomial-time computable. The optimization hardness conclusion follows.
  • NP membership. A committee is a polynomial-size certificate. With explicitly encoded rational masses, scores, and threshold, its score can be computed and compared with the threshold using exact rational arithmetic with polynomially bounded bit lengths. Thus the decision version belongs to NP.

Required clarification

Explicitly describe the many-one handling of Vertex Cover inputs outside \(E\neq\varnothing\) and \(1\leq k\leq |V|\), or cite the precise NP-completeness of Vertex Cover under these restrictions.
