Result 3.8 — class: algorithmic

The continuous mirror question, as graded

Given finite types \(T\) with rational masses \(\mu_t\) summing to \(1\), finite action sets \(A_t\), security levels \(\ell_t\), and rational affine payoffs \(u_{ta}(q)\) in the population action shares \(q\), define \(\mathcal F\) by \(q_{ta}\ge 0\), \(\sum_{a\in A_t}q_{ta}=\mu_t\), and \(q_{ta}>0\Rightarrow u_{ta}(q)\ge\ell_t\). Let \(M_t\) be the greatest security-feasible payoff available to a type-\(t\) agent over actions and \(q\in\mathcal F\). Compute a feasible \(q\) maximizing \(G(q)=-\sum_{t\in T}\sum_{a\in A_t}q_{ta}\log(1+M_t-u_{ta}(q))\), or, given rational \(\varepsilon>0\), return a rational feasible \(q\) within \(\varepsilon\) of the optimum.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type has an explicitly listed nonempty action set \(A_t\); put \(m=\sum_t|A_t|\) and \(D=\{q\in\mathbb R_{\ge0}^{m}:\sum_{a\in A_t}q_{ta}=\mu_t\ \forall t\}\). The coordinate \(q_{ta}\) is population mass assigned action \(a\).
Payoffs \(u_{ta}:D\to\mathbb R\) are explicitly given rational affine functions, measured in a common fixed utility unit; coefficients and payoffs may have either sign. Supplied rational security levels satisfy \(\ell_t=\max_{a\in A_t}\min_{r\in D}u_{ta}(r)\), with an individual agent having zero mass.
Define \(\mathcal F=\{q\in D:q_{ta}>0\Rightarrow u_{ta}(q)\ge\ell_t\ \forall t,a\}\), and assume \(\mathcal F\ne\varnothing\).
Define \(M_t=\sup\{u_{ta}(q):q\in\mathcal F,\ a\in A_t,\ q_{ta}>0\}\); these benchmarks must be determined from the instance.
For \(q\in\mathcal F\), set \(G(q)=-\sum_{t\in T}\sum_{a\in A_t:q_{ta}>0}q_{ta}\log(1+M_t-u_{ta}(q))\), using the natural logarithm and assigning zero contribution to unused actions.
Given binary-rational \(\varepsilon>0\), the computational problem is to return rational \(q\in\mathcal F\) with \(G(q)\ge\sup_{r\in\mathcal F}G(r)-\varepsilon\); any such allocation is acceptable. Let \(L\) be the total binary input length, including \(\varepsilon\).

Is this computational problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite players with an explicit payoff table, maximizing \(\prod_i(1+M_i-u_i(s))^{-1}\) over profiles meeting every player's pure-strategy security level has a claimed \(O(N)\) unit-cost RAM algorithm, where \(N\) is the number of individual payoff entries. [Corley (2017)](https://www.scirp.org/journal/paperinformation?paperid=79470).
No complexity result for the specific distributional problem above was located in the searches performed.

Modeling choices made when packaging the task

  • Defined m as the total number of listed type-action pairs and L as total binary input length, including the accuracy parameter.
  • Interpreted pure-action security in an atomless society as max over actions of the minimum payoff over all population allocations; supplied security levels must equal these values.
  • Required nonempty action sets and a nonempty feasible set, preserving the discrete setting's existence of acceptable profiles.
  • Retained signed payoffs and coefficients, with utilities expressed in a common fixed unit as required by the discrete utility normalization.
  • Interpreted the type benchmark as the supremum of payoffs on positively occupied actions in feasible allocations, because positive occupancy need not define a closed set.
  • Used natural logarithms and omitted unused-action terms, whose logarithms need not be defined.
  • Selected the stated rational additive-accuracy alternative to avoid an unspecified representation of an exact real optimizer; accuracy is part of the binary input.
  • Allowed any allocation meeting the objective tolerance, without an additional tie-breaking rule.

The problem is \(\mathrm{NP}\text{-hard}\). This holds even when every type has at most three actions, all security levels are zero, all payoffs lie in \([-1,1]\), and the benchmarks are provably in \(\{0,1\}\). Consequently, a polynomial-time algorithm of the requested kind would imply \(\mathsf P=\mathsf{NP}\).

The proof gives a polynomial construction and a polynomial procedure that converts any sufficiently accurate returned allocation into an optimal Boolean assignment.

  • Source problem and construction.

We reduce from satisfiability of formulas whose clauses have between one and three literals, which is \(\mathrm{NP}\)-complete by [Karp’s theorem](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf). Let the formula be \(\Phi=C_1\land\cdots\land C_c\), with variables \(x_1,\ldots,x_n\). We may assume \(n,c\ge1\); inputs with no variables or clauses can be decided directly.

Let \(P\) be the smallest power of two satisfying \(P\ge n+c\), and put \(\delta=1/P\). Construct \(P\) types, each of mass \(\delta\):

  • One variable type \(v_i\) for each variable.
  • One clause type \(h_j\) for each clause.
  • \(P-n-c\) dummy types.

Each variable type has actions \(T,F,B\), with payoffs

\(\displaystyle u_{v_i,T}(q)=-Pq_{v_i,F},\qquad u_{v_i,F}(q)=-Pq_{v_i,T},\qquad u_{v_i,B}(q)=0.\)

For a literal \(\lambda\), define its mass signal by

\(\displaystyle w_\lambda(q)=Pq_{v_i,T}\ \text{if }\lambda=x_i,\qquad w_\lambda(q)=Pq_{v_i,F}\ \text{if }\lambda=\neg x_i.\)

Clause type \(h_j\) has one action \(a_{j,k}\) for each literal occurrence \(\lambda_{j,k}\) in \(C_j\), with payoff

\(\displaystyle u_{h_j,a_{j,k}}(q)=w_{\lambda_{j,k}}(q).\)

Each dummy type has one action with constant payoff zero. Supply \(\ell_t=0\) for every type, and choose

\(\displaystyle \varepsilon=\frac{1}{4P}=\frac{\delta}{4}.\)

These are rational affine payoffs. Since every coordinate is between zero and \(\delta\), variable payoffs lie in \([-1,0]\) and clause payoffs lie in \([0,1]\).

  • Verification of the security levels and feasibility promise.

For a variable type, the minimum over \(D\) of its \(T\)-action payoff is \(-1\): place its entire mass on \(F\). Similarly, the minimum payoff of action \(F\) is \(-1\). Action \(B\) has minimum payoff zero. Thus its security level is exactly

\(\displaystyle \max\{-1,-1,0\}=0.\)

Every clause action has minimum payoff zero over \(D\): its signal is nonnegative, and putting the referenced variable’s entire mass on \(B\) makes that signal zero. Hence each clause type also has security level zero. The dummy security levels are zero.

For variable types, feasibility is equivalent to

\(\displaystyle q_{v_i,T}q_{v_i,F}=0.\)

Indeed, positive mass on \(T\) requires \(-Pq_{v_i,F}\ge0\), forcing \(q_{v_i,F}=0\). Positive mass on \(F\) similarly forces \(q_{v_i,T}=0\). Conversely, this condition makes every used variable action’s payoff zero. Clause and dummy types impose no further restrictions, because their payoffs are always nonnegative.

In particular, putting every variable’s mass on \(B\) and allocating each clause type to any of its actions gives a feasible allocation. Thus \(\mathcal F\ne\varnothing\), regardless of whether \(\Phi\) is satisfiable.

  • Exact determination of the benchmarks.

At every feasible allocation, every used variable action has payoff zero. Therefore

\(\displaystyle M_{v_i}=0.\)

Dummy benchmarks are likewise zero.

Every clause action’s payoff is at most one, so \(M_{h_j}\le1\). To attain one, select any literal occurrence in \(C_j\), put its referenced variable’s entire mass on the truth action making that literal true, and put clause type \(h_j\)’s entire mass on the corresponding action. Put the other variables on \(B\), and allocate the remaining clause types arbitrarily.

This allocation is feasible by the preceding characterization, and the selected clause action is used with payoff one. Consequently,

\(\displaystyle M_{h_j}=1.\)

Thus all benchmarks have been derived from the instance; they are not additional supplied data.

  • Rounding any feasible allocation.

For \(q\in\mathcal F\), define a Boolean assignment \(\sigma(q)\) by declaring \(x_i\) true exactly when \(q_{v_i,T}>0\).

Every literal false under \(\sigma(q)\) has signal zero:

  • If \(x_i\) is false, the rounding definition gives \(q_{v_i,T}=0\).
  • If \(\neg x_i\) is false, then \(q_{v_i,T}>0\), and feasibility forces \(q_{v_i,F}=0\).

Let \(U(\sigma)\) denote the number of clauses unsatisfied by an assignment \(\sigma\). If \(C_j\) is unsatisfied by \(\sigma(q)\), every action of its clause type has payoff zero. Its objective contribution is therefore exactly

\(\displaystyle -\sum_{k:q_{h_j,a_{j,k}}>0}q_{h_j,a_{j,k}}\log 2=-\delta\log2.\)

For every other clause, each used payoff belongs to \([0,1]\). Since its benchmark is one, each term has logarithm \(\log(2-u)\ge0\), so that clause’s contribution is nonpositive. Variable and dummy contributions are zero.

It follows that every feasible allocation satisfies

\(\displaystyle G(q)\le-\delta\,U(\sigma(q))\log2.\)

  • Exact optimal value.

Conversely, take any Boolean assignment \(\sigma\). Put each variable type’s entire mass on its assigned truth action. For a satisfied clause, put its clause type’s entire mass on an action corresponding to a true literal; its payoff is one and its contribution is zero. For an unsatisfied clause, choose any action; its payoff is zero and its contribution is \(-\delta\log2\).

The resulting allocation is rational and feasible, and has value

\(\displaystyle G(q^\sigma)=-\delta\,U(\sigma)\log2.\)

Define \(U_*=\min_\sigma U(\sigma)\). The preceding upper bound and this construction together prove

\(\displaystyle \max_{q\in\mathcal F}G(q)=-\delta\,U_*\log2.\)

In particular, the supremum in the task is attained on these instances.

  • Every permitted approximate output yields an optimal assignment.

Let \(q\) be any output satisfying the requested guarantee. Then

\(\displaystyle G(q)\ge-\delta U_*\log2-\varepsilon.\)

Combining this with the rounding bound gives

\(\displaystyle \delta\bigl(U(\sigma(q))-U_*\bigr)\log2\le\varepsilon=\frac{\delta}{4}.\)

The difference \(U(\sigma(q))-U_*\) is a nonnegative integer. Also,

\(\displaystyle \log2=\int_1^2\frac{dx}{x}\ge\frac12>\frac14.\)

Hence the difference must be zero. Thus every valid approximate output rounds to an assignment minimizing the number of unsatisfied clauses.

To decide satisfiability, call the allocation algorithm once, round its returned rational allocation, and check whether that assignment satisfies every clause. This procedure requires no numerical evaluation of logarithms.

  • Encoding size and the explicit-table comparison.

We have \(P<2(n+c)\), support size \(\tau=P\), and total action count \(m\le3P\). All masses and \(\varepsilon\) are positive dyadic rationals. The payoff coefficients belong to \(\{0,P,-P\}\), requiring \(O(\log P)\) bits each. Even listing every affine coefficient explicitly gives an input of polynomial size in the formula’s length. Rounding uses exact positivity tests on the returned rationals and takes polynomial time in their encoding length.

Therefore a solver running in time polynomial in \(m,\tau,L\) would decide \(\mathrm{3SAT}\) in polynomial time. This proves the claimed hardness for the allocation search problem.

The result does not conflict with Corley’s explicit-table claim. His algorithm scans explicitly listed profiles and measures complexity in the number of table entries. [Corley, Result 3.8](https://www.scirp.org/journal/paperinformation?paperid=79470). Here, polynomially many affine coefficients describe a society containing exponentially many Boolean choices.
