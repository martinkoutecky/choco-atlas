The continuous mirror question, as graded

Given a finite type set \(T\), rational population masses \(\mu\), action sets \(A_t=\{0,1\}^{F_t}\), type goals and costs, observation maps, aggregate threshold objective \(\Phi(x)\), and admissible type-based contracts \(\kappa\), decide whether some \(\kappa\) has a nonempty Wardrop equilibrium set \(\mathrm{NE}_\infty(\kappa)\) and satisfies \(\forall x\in\mathrm{NE}_\infty(\kappa),\ \Phi(x)\), where \(x_{t,a}\ge0\), \(\sum_{a\in A_t}x_{t,a}=\mu_t\), and every action receiving positive mass maximizes its type's contracted utility.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
The input includes a partition \((F_t)_{t\in T}\) of \(m\) Boolean variables into nonempty sets, implicit action sets \(A_t=\{0,1\}^{F_t}\), and binary-rational thresholds \(q_j\in(0,1]\). A population state has real masses \(x_{t,a}\geq0\) with \(\sum_{a\in A_t}x_{t,a}=\mu_t\); for \(j\in F_t\), define \(b_j(x)=\mathbf1[\sum_a x_{t,a}a_j\geq q_j\mu_t]\).
For a type \(t\) considering action \(a\), let \(v^t(a,x)\) equal \(a\) on \(F_t\) and \(b(x)\) elsewhere. Its goal is an input propositional formula \(\gamma_t\) evaluated at this valuation; its cost is \(c_t(v^t(a,x))\), where an input Boolean circuit outputs a nonnegative binary-rational numerator and a positive binary-rational denominator.
An input observable set \(O\subseteq\bigcup_t F_t\), possibly empty or full, defines \(o_t(a,x)=v^t(a,x)|_O\). An admissible contract consists of arbitrary functions \(\kappa_t:\{0,1\}^{O}\to\mathbb Q_{\geq0}\), with no budget or payment cap, shared by all individuals of each type.
Contracted preferences lexicographically maximize \((\mathbf1[v^t(a,x)\models\gamma_t],\ \kappa_t(o_t(a,x))-c_t(v^t(a,x)))\). Define \(\mathrm{NE}_\infty(\kappa)\) as the population states in which every action with positive mass maximizes this pair over \(A_t\), holding \(x\) fixed; all maximizing actions are allowed, without tie-breaking.
The principal's aggregate threshold objective is \(\Phi(x)\equiv[b(x)\models\varphi]\), for an input propositional formula \(\varphi\). Let \(L\) be the total bit length of the input, including formulas, circuits and rational data; state running times in \(m,\tau,L\).

Is deciding whether there exists an admissible \(\kappa\) with \(\mathrm{NE}_\infty(\kappa)\neq\varnothing\) and \(\forall x\in\mathrm{NE}_\infty(\kappa),\ \Phi(x)\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

Discrete A-Nash Contractibility, with pure equilibria, lexicographic goals and nonnegative observation-dependent payments, is \(\Sigma_3^p\)-complete ([Hyland, Gutierrez and Wooldridge](https://arxiv.org/pdf/2305.10334)).
No result settling this specified Wardrop variant was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the unspecified population masses to total mass one and retained only positive-mass types.
  • Carried over the nonempty partition of controlled Boolean variables and the implicit Boolean action spaces.
  • Specified aggregate thresholds as positive rational fractions of the controlling type's mass, with equality making the aggregate Boolean variable true.
  • Resolved goal and cost evaluation by using the individual's own action on its controlled variables and thresholded population values on all other variables.
  • Specified succinct cost encoding by Boolean circuits returning a nonnegative rational numerator and a positive rational denominator; the source does not fix an encoding.
  • Resolved observation maps as projection of the same local-and-aggregate valuation onto a common observable variable set, allowing empty and full observability.
  • Carried over unrestricted nonnegative rational observation-dependent payments, without adding a budget, payment cap or individual-rationality condition.
  • Made goal satisfaction lexicographically dominant over payment minus cost, and retained all best responses at ties.
  • Specified the aggregate threshold objective as a propositional formula evaluated on the thresholded population valuation; equilibria may have real masses and individual deviations hold population aggregates fixed.

Proven result

The decision problem is \(\mathrm{NP}\)-hard, even with one supported type, zero costs, one observable variable, and a principal objective consisting of that variable alone. Thus a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The reduction below accounts for every mixed population equilibrium and allows all maximizing actions.

Construction

Reduce from \(\mathrm{3SAT}\). Let \(\psi(w_1,\ldots,w_n)\) be the source formula, and introduce a fresh variable \(z\).

Construct the following instance:

  • There is one type \(t\), with mass \(\mu_t=1\).
  • Its variable set is \(F_t=\{w_1,\ldots,w_n,z\}\), so \(m=n+1\) and \(\tau=1\).
  • Every threshold is \(q_j=\tfrac12\).
  • Its goal is \(\gamma_t=\neg z\lor\psi(w_1,\ldots,w_n)\).
  • Its cost is constantly zero, represented by a circuit outputting numerator \(0\) and denominator \(1\).
  • The observable set is \(O=\{z\}\).
  • The principal’s formula is \(\varphi=z\).

All required masses and thresholds are positive binary rationals, and the variable partition has one nonempty part. The goal is always attainable: every action setting \(z=0\) satisfies it.

Because this type owns every variable, \(v^t(a,x)=a\) for every action \(a\) and state \(x\). Consequently, its contracted preferences are independent of the population state.

For any fixed contract \(\kappa_t\), let \(M_\kappa\) denote the set of maximizing actions. This set is nonempty because the action set is finite. Directly from the equilibrium definition,

\(\displaystyle x\in\mathrm{NE}_\infty(\kappa)\quad\Longleftrightarrow\quad x_{t,a}>0\ \Longrightarrow\ a\in M_\kappa.\)

In particular, every distribution of total mass \(1\) supported on \(M_\kappa\) is an equilibrium.

Satisfiable formulas give successful contracts

Suppose \(\psi\) is satisfiable. Define the admissible contract by

\(\kappa_t(0)=0,\qquad \kappa_t(1)=1.\)

The lexicographic preference pairs are exactly:

| Action | Preference pair |
|---|---|
| \(a_z=0\) | \((1,0)\) |
| \(a_z=1\) and \(a|_{\{w_1,\ldots,w_n\}}\models\psi\) | \((1,1)\) |
| \(a_z=1\) and \(a|_{\{w_1,\ldots,w_n\}}\not\models\psi\) | \((0,1)\) |

The second class is nonempty by satisfiability. Its pair strictly exceeds both other pairs lexicographically. Hence

\(\displaystyle M_\kappa=\{a:a_z=1,\ a|_{\{w_1,\ldots,w_n\}}\models\psi\}.\)

Putting all mass on any member of this set gives an equilibrium, so \(\mathrm{NE}_\infty(\kappa)\neq\varnothing\).

Furthermore, every equilibrium distributes mass only among actions setting \(z=1\). Therefore, in every equilibrium,

\(\displaystyle \sum_a x_{t,a}a_z=\sum_a x_{t,a}=1.\)

Since \(q_z\mu_t=\tfrac12\), this implies \(b_z(x)=1\), and thus \(b(x)\models\varphi\).

This calculation covers arbitrary mixtures and every tie among maximizing actions.

Unsatisfiable formulas admit no successful contract

Suppose \(\psi\) is unsatisfiable, and fix any admissible contract. Write its two payments as \(p_0=\kappa_t(0)\) and \(p_1=\kappa_t(1)\).

Every action setting \(z=0\) satisfies \(\gamma_t\), whereas every action setting \(z=1\) fails \(\gamma_t\). Their preference pairs are therefore

\(\displaystyle (1,p_0)\quad\text{and}\quad(0,p_1),\)

respectively. Lexicographic goal priority makes the first pair strictly greater for every choice of the payments. Thus

\(\displaystyle M_\kappa=\{a:a_z=0\}.\)

This set is nonempty, so equilibria exist. In every equilibrium, however,

\(\displaystyle \sum_a x_{t,a}a_z=0<\tfrac12,\)

and hence \(b_z(x)=0\). Every equilibrium violates the principal’s objective. Since the contract was arbitrary, no admissible contract satisfies the requested condition.

Complexity conclusion

We have proved the equivalence

\(\displaystyle \psi\text{ is satisfiable}\quad\Longleftrightarrow\quad\text{the constructed instance admits a successful contract}.\)

If the source encoding has length \(s\), the construction has \(m=n+1\), \(\tau=1\), and \(L\) polynomial in \(s\). It can be produced in polynomial time; with standard indexed-variable encodings, its output length and construction time are \(O(s+n\log(n+1))\).

This is a polynomial-time many-one reduction from \(\mathrm{3SAT}\), establishing \(\mathrm{NP}\)-hardness. It settles the requested hardness alternative without claiming a matching complexity upper bound.
