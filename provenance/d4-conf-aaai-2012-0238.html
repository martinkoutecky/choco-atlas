The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t=p_t/D>0\) with \(\sum_t p_t=D\), and symmetric nonnegative rational values \(w_{tu}\), form for each positive integer \(r\) the graph with \(rp_t\) vertices of type \(t\), joining every distinct pair of types \(t,u\) with weight \(w_{tu}\), including distinct same-type pairs with weight \(w_{tt}\). Compute the ordinary fractional-matching-game nucleolus at each \(r\); symmetry gives a common payoff \(a_t^{(r)}\) to each vertex of type \(t\). Determine whether \(a^{(r)}\) converges as \(r\) grows and, if it does, compute its exact limit; otherwise prove nonconvergence. State complexity in the number of types and binary input length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t=p_t/D\), where \(p_t,D\) are positive integers and \(\sum_t p_t=D\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The input also gives symmetric weights \(w_{tu}\in\mathbb Q_{\geq0}\), including diagonal weights; \(L\) is the total binary input length, including the supplied common denominator \(D\).
For every integer \(r\geq1\), let \(G_r\) have \(rp_t\) vertices of type \(t\). Every pair of distinct vertices of types \(t,u\) has edge weight \(w_{tu}\), including pairs within one type; there are no loops.
For a coalition \(S\), its worth \(f_r(S)\) is the maximum weight of a fractional matching in \(G_r[S]\), with capacity one at each vertex and no odd-set constraints.
Let \(x^{(r)}\) be the ordinary nucleolus over imputations \(x\geq0\) satisfying \(\sum_i x_i=f_r(V(G_r))\). Symmetry gives a common per-vertex payoff \(a_t^{(r)}\) within each type; these payoffs are not rescaled with \(r\). A one-vertex game has payoff zero.
The computational problem is to determine whether \(a^{(r)}\) converges as \(r\to\infty\), and, when it does, compute its exact limit.

Is this convergence-and-exact-limit problem solvable in polynomial time in \(\tau\) and \(L\), or is it NP-hard?

For explicitly listed finite weighted graphs, the fractional-matching-game nucleolus is computable in polynomial time ([Chen, Lu and Zhang](https://ojs.aaai.org/index.php/AAAI/article/download/8242/8101)).
No result settling this exact replication-limit problem was located in the literature search.

  • Specified ordinary imputations with nonnegative payoffs and grand-coalition efficiency; singleton coalition worths are zero.
  • Included the supplied common denominator in the input length and retained its replication sequence without imposing a reduced representation.

Result

The problem is solvable in polynomial time in \(\tau\) and \(L\). In fact, a stronger statement holds:

Theorem. For every valid input, there is a rational vector \(a^*\), computable exactly in polynomial time, such that
\[ a^{(r)}=a^*\qquad\text{for every integer }r\geq2. \]

Thus the sequence always converges, and its limit is \(a^*\).

The proof compresses the use of fixed edges and shortest paths in the finite-graph algorithm of [Chen, Lu and Zhang](https://ojs.aaai.org/index.php/AAAI/article/download/8242/8101). The reduction and the bit-complexity argument are proved below; the algorithm never expands a graph with a number of vertices proportional to \(D\).

1. The symmetric core is independent of replication

Write \(p=(p_t)_{t\in T}\). Consider the following linear program, with one nonnegative variable \(b_{tu}\) for every unordered type pair, including diagonal pairs:

\[ F=\max\left\{ \sum_{t\leq u}w_{tu}b_{tu}: 2b_{tt}+\sum_{u\neq t}b_{tu}\leq p_t\ \text{for every }t,\quad b\geq0 \right\}. \]

Here and below, \(b_{tu}\) denotes the same unordered-pair variable whether \(t<u\) or \(u<t\). Its dual is

\[ F=\min\left\{ \sum_t p_ta_t: a_t\geq0,\quad a_t+a_u\geq w_{tu}\ (t\neq u),\quad 2a_t\geq w_{tt} \right\}. \]

Both programs are feasible, and the primal is bounded, so strong linear-programming duality applies.

Claim 1. For every \(r\geq2\), the grand-coalition worth is \(f_r(V)=rF\).

To prove the upper bound, aggregate any fractional matching in \(G_r\) by type pair. Its aggregate variables satisfy the primal capacity inequalities with right-hand side \(rp\). Dividing those variables by \(r\) gives a feasible solution for the program defining \(F\).

For the reverse bound, take an optimal aggregate solution with capacities \(rp\). Put \(n_t=rp_t\), so \(n_t\geq2\). Distribute its type-pair quantities uniformly over the actual edges:

  • For \(t\neq u\), put \(b_{tu}/(n_tn_u)\) on every edge between the two types.
  • Within type \(t\), put \(b_{tt}/\binom{n_t}{2}\) on every edge.

Every vertex of type \(t\) then has matching degree

\[ \frac{2b_{tt}+\sum_{u\neq t}b_{tu}}{n_t}\leq1. \]

The objective value is unchanged. Since scaling the capacities by \(r\) scales the aggregate optimum by \(r\), this proves the claim.

Define the polytope

\[ C=\left\{ a\geq0: \sum_t p_ta_t=F,\quad a_t+a_u\geq w_{tu}\ (t\neq u),\quad 2a_t\geq w_{tt} \right\}. \]

It is nonempty by duality. It is compact because every \(p_t\) is positive and \(0\leq a_t\leq F/p_t\).

Claim 2. For every \(r\geq2\), \(C\) is exactly the set of type-constant core allocations, expressed as per-vertex payoffs.

Necessity follows from efficiency, singleton coalitions, and two-vertex coalitions. The diagonal inequality uses two distinct vertices of type \(t\), which exist because \(rp_t\geq2\).

For sufficiency, let \(a\in C\), let \(S\) be a coalition, and let \(z\) be any fractional matching on \(S\). The pair inequalities give

\[ \sum_{\{i,j\}\subseteq S}w_{\operatorname{type}(i),\operatorname{type}(j)}z_{ij} \leq \sum_{i\in S}a_{\operatorname{type}(i)} \sum_{j:\{i,j\}\subseteq S}z_{ij} \leq \sum_{i\in S}a_{\operatorname{type}(i)}. \]

The second inequality uses nonnegativity of the payoffs and the vertex capacities. Maximizing over \(z\) proves every core inequality.

The nucleolus belongs to the core: a core allocation has all coalition surpluses nonnegative, whereas an allocation outside the core has a negative surplus and therefore cannot maximize the sorted surplus vector. By uniqueness and symmetry, the nucleolus is type-constant. Consequently, it can be computed by lexicographic optimization over the common polytope \(C\).

2. A decomposition of fractional matchings

For a coalition \(S\), use the surplus convention

\[ e_r(S,a)=\sum_{i\in S}a_{\operatorname{type}(i)}-f_r(S). \]

For an actual edge with endpoint types \(t,u\), put

\[ c_{tu}(a)=a_t+a_u-w_{tu}, \]

also when \(t=u\). Every \(c_{tu}(a)\) is nonnegative on \(C\).

We will use the following elementary property.

Lemma 3. Every finite graph has an optimal fractional matching whose positive-support components are single edges with value \(1\), or odd cycles whose edges all have value \(1/2\).

Proof. Choose an optimal extreme point of the fractional-matching polytope; such a point exists because that polytope is nonempty and bounded.

Consider a connected positive-support component with \(v\) vertices and \(m\) edges. Let \(U\) be its vertices whose capacity constraints are slack. The columns of its incidence matrix, restricted to tight capacity rows, must be linearly independent. Otherwise, a nonzero dependence gives a sufficiently small perturbation in both directions preserving the tight constraints, positivity on the support, and feasibility of the slack constraints. This contradicts extremality.

Thus \(m\leq v-|U|\). Connectivity gives \(m\geq v-1\), leaving two possibilities.

  • If the component is a tree, then \(|U|\leq1\). A tight leaf would force its incident edge to have value \(1\), preventing any other positive edge at its neighbor. Hence, in a tree with more than one edge, every leaf must be slack. Such a tree has at least two leaves, a contradiction. The component must therefore be a single edge, and extremality forces its value to be \(1\).
  • Otherwise \(m=v\), all vertices are tight, and the component is unicyclic. It cannot have a leaf, by the same tight-leaf argument, so it is a cycle. An even cycle admits an alternating perturbation and is not extreme. On an odd cycle, the tight degree equations force every edge value to be \(1/2\).

This proves the lemma. \(\square\)

Fix such an optimal matching for \(S\). Let \(I\) be its unmatched vertices, \(M\) its single-edge components, and \(\mathcal O\) its odd-cycle components. Then

\[ e_r(S,a) = \sum_{i\in I}a_{\operatorname{type}(i)} + \sum_{\{i,j\}\in M}c_{\operatorname{type}(i),\operatorname{type}(j)}(a) + \frac12\sum_{H\in\mathcal O}\sum_{\{i,j\}\in E(H)} c_{\operatorname{type}(i),\operatorname{type}(j)}(a). \]

This is an identity, and all its summands are nonnegative on \(C\).

3. Polynomially many representative coalitions

Let \(P\subseteq C\) be a nonempty polytope that is not a singleton. An affine function is called fixed on \(P\) if it is constant throughout \(P\).

A coalition is fixed precisely when its payoff sum is fixed: its worth does not depend on \(a\).

We construct a family \(\mathcal R(P)\) of nonfixed coalitions. The construction depends on \(P\) and the supplied type data, but not on \(r\).

3.1 Singleton and pair representatives

Include:

  • A singleton of type \(t\) whenever \(a_t\) is nonfixed on \(P\).
  • A two-vertex coalition with endpoint types \(t,u\) whenever \(a_t+a_u\) is nonfixed on \(P\), allowing \(t=u\).

Their surpluses are respectively \(a_t\) and \(c_{tu}(a)\).

3.2 The graph of fixed pair sums

Construct a graph \(K_P\) whose vertices are the types \(t\) for which \(a_t\) is nonfixed on \(P\). Join distinct types \(t,u\) exactly when \(a_t+a_u\) is fixed on \(P\).

Give this edge the weight \(c_{tu}\), which is a constant nonnegative rational number on \(P\).

Lemma 4. Every component of \(K_P\) is bipartite. Moreover, if \(t,u\) belong to the same component and \(a_t+a_u\) is nonfixed, then they lie in the same side of its bipartition.

Proof. For any \(a,a'\in P\), set \(d=a-a'\). Every edge of \(K_P\) imposes \(d_t+d_u=0\). Along a path, the coordinates of \(d\) therefore alternate signs.

An odd cycle would force every coordinate of \(d\) in its component to vanish, for every choice of \(a,a'\). All types in that component would then be fixed, contradicting the definition of its vertex set. Thus the component is bipartite.

If \(t,u\) were in opposite sides, an odd-length path would give \(d_t+d_u=0\) for every \(a,a'\in P\). Their pair sum would be fixed. \(\square\)

3.3 Short-cycle representatives

For each distinct pair \(t,u\) in the same component of \(K_P\) whose pair sum is nonfixed, choose a minimum-weight simple path between them. By Lemma 4, this path has even length. Add the edge between its endpoints to obtain an odd cycle, and include its vertex set in \(\mathcal R(P)\).

Also, for every type \(t\) with a neighbor in \(K_P\), choose a neighbor \(v\) minimizing \(c_{tv}\). Use two distinct vertices of type \(t\) and one vertex of type \(v\), forming a triangle. Include this coalition as well. This handles a closing edge whose endpoints have the same type.

Every selected coalition uses at most two vertices of each type and at most \(\tau+1\) vertices in total. For \(\tau\geq2\), it is therefore a proper coalition of every \(G_r\) with \(r\geq2\), since

\[ \tau+1<2\tau\leq rD. \]

The case \(\tau=1\) needs no refinement: \(C\) is already a singleton.

These cycle coalitions are nonfixed. Indeed, if \(Q\) is obtained from a fixed-edge path with endpoint types \(t,u\), then

\[ a(Q)=\frac12\left( \sum_{\{i,j\}\text{ on the path}} \bigl(a_{\operatorname{type}(i)}+a_{\operatorname{type}(j)}\bigr) +a_t+a_u \right). \]

All path-edge sums are fixed, while the closing pair sum is nonfixed. The same identity applies to the triangle with two vertices of type \(t\).

For each selected coalition, compute its worth on its actual small, loopless graph. In particular, a type represented by only one vertex has no diagonal edge.

The family \(\mathcal R(P)\) has \(O(\tau^2)\) members.

4. The representative family is exact

Lemma 5. Fix \(r\geq2\), \(a\in P\), and \(\varepsilon\geq0\). The following conditions are equivalent:

  • Every proper coalition nonfixed on \(P\) has surplus at least \(\varepsilon\).
  • Every coalition in \(\mathcal R(P)\) has surplus at least \(\varepsilon\).

Proof. Every representative is a proper, nonfixed coalition, so the first condition implies the second.

For the converse, take a proper coalition \(S\) whose payoff sum is nonfixed on \(P\), and choose an optimal matching as in Lemma 3.

Its decomposition from Section 2 expresses its payoff sum as a sum of component payoff sums. At least one component payoff sum must therefore be nonfixed. Consider such a component.

An unmatched vertex. Its type is nonfixed, so its singleton is a representative. Its contribution is at least \(\varepsilon\).

A single edge. Its endpoint payoff sum is nonfixed, so its pair coalition is a representative. Its contribution is at least \(\varepsilon\).

An odd cycle with at least two nonfixed edge sums. Each such edge has slack at least \(\varepsilon\), by the pair representatives. All other edge slacks are nonnegative, so the cycle contributes at least

\[ \frac12(2\varepsilon)=\varepsilon. \]

An odd cycle with exactly one nonfixed edge sum. Let its exceptional edge have endpoint types \(t,u\). Removing that edge leaves an even-length path of fixed edge sums.

Every vertex type on this path is nonfixed. Otherwise, fixedness of one vertex payoff and of successive edge sums would propagate along the entire path, making the exceptional edge sum fixed as well.

The projected type walk therefore lies in \(K_P\). Write \(h\) for its total fixed slack weight.

If \(t\neq u\), the selected minimum-weight simple path has weight \(h'\leq h\). If \(t=u\), the first and last edges of the projected walk are both incident with \(t\); consequently, the selected two-edge walk through a minimum-weight neighbor also has weight \(h'\leq h\).

Let \(Q\) be the corresponding representative cycle coalition. The original cycle contribution is

\[ \frac12\bigl(c_{tu}(a)+h\bigr) \geq \frac12\bigl(c_{tu}(a)+h'\bigr). \]

Putting matching value \(1/2\) on every edge of the selected odd cycle is feasible on \(Q\). Hence

\[ \frac12\bigl(c_{tu}(a)+h'\bigr) = a(Q)-\frac12\sum_{e\text{ on the selected cycle}}w_e \geq a(Q)-f_r(Q) = e_r(Q,a) \geq\varepsilon. \]

Finally, a cycle with no nonfixed edge sums cannot be the chosen nonfixed component: its vertex payoff sum is half the sum of its fixed edge payoff sums.

Thus some component contributes at least \(\varepsilon\). All remaining contributions are nonnegative, proving \(e_r(S,a)\geq\varepsilon\). \(\square\)

In particular, for every \(a\in P\),

\[ \min_{\substack{S\text{ proper}\\a(S)\text{ nonfixed on }P}}e_r(S,a) = \min_{Q\in\mathcal R(P)}e_r(Q,a). \]

Both sides are nonnegative because \(P\subseteq C\).

5. Computing the nucleolus and proving stabilization

For completeness, consider the standard lexicographic refinement procedure on a compact polytope.

At each stage, discard every surplus function fixed on the current polytope. Maximize the minimum of the remaining functions, and restrict to the maximizing set. Discarding fixed functions preserves lexicographic comparisons: inserting the same fixed multiset of numbers into two sorted vectors does not change which vector is lexicographically larger.

Each nonterminal stage decreases dimension. To see this, let the optimum minimum be \(\varepsilon\), and take a relative-interior point of the maximizing polytope. Some remaining function equals \(\varepsilon\) there. Since that function is at least \(\varepsilon\) throughout the maximizing polytope, equality at a relative-interior point makes it constant on that polytope. It was nonconstant on the preceding polytope, so dimension has decreased.

Apply this procedure starting from \(P_0=C\). By Lemma 5, each refinement can be performed by the explicit LP

\[ \max \varepsilon \quad\text{subject to}\quad a\in P_{j-1},\quad \varepsilon\geq0,\quad a(Q)-f(Q)\geq\varepsilon \quad(Q\in\mathcal R(P_{j-1})). \]

If its optimum is \(\varepsilon_j\), retain the corresponding inequalities and obtain \(P_j\).

A nonsingleton \(P_{j-1}\) always has a nonfixed coordinate, so the representative family contains a singleton and is nonempty. Since \(\dim C\leq\tau-1\), there are at most \(\tau-1\) refinements.

The terminal point is the nucleolus restricted to \(C\), and hence the ordinary nucleolus: the ordinary nucleolus lies in \(C\), as proved in Section 1.

Crucially, the whole procedure is independent of \(r\geq2\):

  • The starting polytope \(C\) is the same.
  • Fixedness is tested on the same current polytope.
  • The representative coalitions exist in every such \(G_r\).
  • Their small induced graphs, and therefore their worths, are the same.

Choosing shortest-path ties by a fixed rule therefore gives exactly the same sequence of polytopes for every \(r\geq2\). Their common terminal point is \(a^*\). This proves

\[ a^{(r)}=a^*\quad(r\geq2). \]

An exceptional one-vertex game at \(r=1\), when it occurs, does not affect the limit.

6. Polynomial running time, including exact arithmetic

The preceding construction uses only polynomially many explicit rational LPs:

  • Computing \(F\) uses \(O(\tau^2)\) variables or constraints.
  • Fixedness of each coordinate and pair sum is tested by minimizing and maximizing it over the current polytope: \(O(\tau^2)\) LPs per stage.
  • Constructing \(K_P\) and its shortest paths is polynomial.
  • Each representative worth is computed on a graph with at most \(\tau+1\) vertices.
  • Each refinement adds \(O(\tau^2)\) inequalities, and there are at most \(\tau-1\) refinements.

It remains to check that the recursively obtained rational constants have polynomial binary length.

The value \(F\) has polynomial binary length by the usual determinant bound for rational LP solutions. Every possible representative worth also has a uniform polynomial bit bound: it is the optimum of a fractional-matching LP on at most \(\tau+1\) vertices, using only supplied edge weights.

For the refinement optima, introduce separate variables \(\lambda_1,\ldots,\lambda_j\) and form the polytope

\[ \widehat P_j= \left\{ (a,\lambda): a\in C,\quad \lambda_i\geq0,\quad a(Q)-\lambda_i\geq f(Q) \text{ for }Q\in\mathcal R(P_{i-1}),\ 1\leq i\leq j \right\}. \]

This description uses the selected coalition count vectors and their worths, rather than previously computed \(\varepsilon_i\).

It is nonempty: for every \(a\in C\), taking all \(\lambda_i=0\) is feasible. It is bounded: \(a\) lies in compact \(C\), and every representative family contains a singleton, which bounds its \(\lambda_i\) from above.

Lexicographically maximizing \(\lambda_1,\ldots,\lambda_j\) over \(\widehat P_j\) gives exactly

\[ (\lambda_1,\ldots,\lambda_j)=(\varepsilon_1,\ldots,\varepsilon_j). \]

Indeed, later variables can always be set to zero, so they impose no additional restriction on the earlier optimization stages.

The resulting optimal face has a vertex, which is also a vertex of \(\widehat P_j\). Consequently, all the recorded \(\varepsilon_i\) occur as coordinates of a vertex of a rational polytope with:

  • At most \(2\tau\) variables.
  • \(O(\tau^3)\) constraints.
  • Coefficients of polynomial binary length in \(\tau\) and \(L\).

Cramer’s rule and the determinant bound therefore give a polynomial binary-length bound for all refinement optima and for the final payoff vector. This also bounds the constants and shortest-path weights used during the algorithm.

Thus all LPs and graph computations can be performed exactly in polynomial time in \(\tau\) and \(L\), completing the proof.
