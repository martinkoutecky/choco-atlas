The continuous mirror question, as graded

Given a rational distribution \(\mu\) over finitely many complete firm types and a rational circuit describing a strictly superadditive worth function \(v(x,\pi)\), where each cartel is a type-mass vector \(x\leq\mu\) and \(\pi\) is a finite partition of \(\mu\) into such vectors, decide whether there is a finite-description type-symmetric normal-form game whose composite game for every \(\pi\) has a Nash equilibrium giving each cartel \(x\) payoff \(v(x,\pi)\); construct such a game when one exists. The same question can be asked for weakly superadditive characteristic-function worth functions, matching Theorem 2.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) complete types with positive binary-rational masses \(\mu_t\), with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(m\) is the maximum type-description length and \(L\) the total input bit length. Types represent atomless, divisible populations.
A partition is an unordered finite indexed family \(\pi=(x^1,\ldots,x^k)\) of nonzero vectors in \(\mathbb R_{\geq0}^{\tau}\) satisfying \(\sum_jx^j=\mu\); repeated vectors represent distinct cartels. An embedded cartel is a designated block \(x^j\) of \(\pi\).
The input describes a real-valued worth function \(v(x^j,\pi)\), invariant under reindexing blocks, by a finite rational-arithmetic program with comparisons, conditional branches, and bounded loops over the supplied partition list; loop nesting is fixed by the program, and evaluation is defined on every admissible real input.
Strict superadditivity is promised: for distinct blocks \(x^i,x^j\), writing \(\pi'\) for their merger, \(v(x^i,\pi)+v(x^j,\pi)<v(x^i+x^j,\pi')\). The alternative input class has partition-independent worth \(v(x)\) and the same inequalities weakly. Worths may have either sign; empty-cartel worth is zero.
A finite-description type-symmetric normal-form game consists of finite nonempty action sets \(A_t\) and rational-arithmetic circuits with comparisons and conditional branches describing bounded payoff densities \(u_{t,a}(z)\), defined for every aggregate action-mass profile \(z\) satisfying \(z_{t,a}\geq0\) and \(\sum_{a\in A_t}z_{t,a}=\mu_t\). Individual identities and the cartel partition are not arguments of these circuits.
In its composite game for \(\pi\), cartel \(j\) chooses any allocation \(y^j_{t,a}\geq0\) with \(\sum_{a\in A_t}y^j_{t,a}=x^j_t\); with \(z=\sum_jy^j\), its transferable total payoff is \(U_j=\sum_{t,a}y^j_{t,a}u_{t,a}(z)\). Mixed strategies are Borel probability distributions over these allocations, independently randomized across cartels.
An implementation is one such game for which every admissible finite partition has a Nash equilibrium and every Nash equilibrium, including mixed equilibria, gives each cartel \(j\) expected payoff \(v(x^j,\pi)\).

For each promised worth-function class, is deciding implementability in \(\mathrm P\) or \(\mathrm{NP}\text{-hard}\), and what is the complexity of constructing an implementation when one exists? State running times in \(m,\tau,L\), including the description length of any constructed game.

For finite societies, every strictly superadditive partition-function game admits a normal-form Nash implementation; so does every weakly superadditive characteristic-function game ([Chan](https://arxiv.org/pdf/2402.14952v2)). These are existence results, without a polynomial-time complexity guarantee.
No result settling the continuous problem with the specifications above was located in the literature search.

1. A necessary bound for implementation

Write
$$ s(x)=\sum_{t=1}^{\tau}x_t. $$

Proposition. Every implementable worth function satisfies
$$ |v(x,\pi)|\leq B s(x) $$
for some finite constant $B$ independent of the partition and designated cartel.

Proof. There are finitely many payoff-density circuits, and each is bounded on its feasible aggregate-profile domain. Thus a common finite bound $B$ satisfies
$$ |u_{t,a}(z)|\leq B $$
for every type, action, and feasible aggregate profile.

For every realized allocation profile,
$$ |U_j| \leq\sum_{t,a}y^j_{t,a}|u_{t,a}(z)| \leq B\sum_{t,a}y^j_{t,a} =B s(x^j). $$
The same bound holds for expected payoffs under arbitrary Borel mixed strategies. Every partition has an equilibrium, and implementation identifies its expected payoffs with the prescribed worths. This proves the proposition. $\square$

Negative worths therefore create an obstruction even when the worth function itself is bounded. For example, assigning worth $-1$ to every nonempty cartel is strictly superadditive, but equal-block partitions require
$$ 1\leq \frac{B}{k} $$
for every positive integer $k$, which is impossible.

2. An explicitly implemented strictly superadditive baseline

Define
$$ b(s)=\frac{s+2s^2}{3},\qquad 0\leq s\leq1. $$
For positive $a,b$ with $a+b\leq1$,
$$ b(a+b)-b(a)-b(b)=\frac{4ab}{3}>0. $$

We will need an implementation of the characteristic worth $v(x)=b(s(x))$, including its requirement concerning every mixed equilibrium.

2.1 The game and best responses

Give every type three actions. Let
$$ Z_a=\sum_t z_{t,a},\qquad J= \begin{pmatrix} 0&-1&1\\ 1&0&-1\\ -1&1&0 \end{pmatrix}, \qquad A=I+2J, $$
and use payoff densities
$$ u_{t,a}(z)=(AZ)_a. $$
These are rational linear circuits. Because the coordinates of $Z$ are nonnegative and sum to one, every density lies in $[-2,2]$.

A cartel of mass $s_i$ can realize every aggregate allocation
$$ y_i\in\mathbb R_{\geq0}^3,\qquad \sum_a y_{i,a}=s_i. $$
Indeed, distribute every constituent type in the proportions $y_{i,a}/s_i$.

If its opponents’ aggregate allocation is $R$, its payoff is
$$ y_i^{\mathsf T}A(y_i+R) =\|y_i\|^2+y_i^{\mathsf T}AR, $$
because $J$ is skew-symmetric. Against independently mixed opponents, its expected payoff from $y_i$ is consequently
$$ \|y_i\|^2+y_i^{\mathsf T}A\mathbb E[R]. $$

This function is strictly convex on the allocation simplex. Every nonvertex is a nontrivial convex combination of vertices and has payoff strictly below the corresponding average of vertex payoffs. Hence every maximizer is a vertex $s_i e_a$.

This also proves the assertion for arbitrary Borel mixed best responses. The expected payoff of a best response equals the maximum pure payoff. The nonnegative difference between that maximum and the payoff of the chosen pure allocation must therefore vanish almost surely. Consequently, every equilibrium strategy assigns probability one to vertices.

2.2 All equilibrium payoffs

Let $p_i$ be cartel $i$’s probability vector over these vertices. Put
$$ e=(1,1,1)^{\mathsf T},\qquad r_i=p_i-\frac e3,\qquad R_i=\sum_{j\ne i}s_jr_j. $$
Since $Ae=e$, choosing vertex $s_i e_a$ gives expected payoff
$$ s_i^2+\frac{s_i(1-s_i)}3+s_i(AR_i)_a =b(s_i)+s_i(AR_i)_a. $$

At equilibrium, define the excess payoff
$$ w_i=s_i\max_a(AR_i)_a. $$
The support condition for $p_i$, together with $e^{\mathsf T}AR_i=0$, gives
$$ w_i=s_i p_i^{\mathsf T}AR_i =s_i r_i^{\mathsf T}AR_i. $$

Two estimates will force all excess payoffs to vanish. First, if $\sum_a h_a=0$, then
$$ \max_a h_a\geq\frac{\|h\|}{\sqrt6}. $$
To verify this, let $c=\max_a h_a\geq0$. The numbers $c-h_a$ are nonnegative and sum to $3c$, so
$$ \|h\|^2 =\sum_a(c-h_a)^2-3c^2 \leq(3c)^2-3c^2 =6c^2. $$

Second, direct matrix multiplication gives
$$ J^{\mathsf T}J=3I-ee^{\mathsf T}. $$
Since $e^{\mathsf T}R_i=0$ and $J$ is skew-symmetric,
$$ \|AR_i\|^2 =\|R_i+2JR_i\|^2 =13\|R_i\|^2. $$
Thus
$$ \sum_i w_i \geq\sqrt{\frac{13}{6}}\sum_i s_i\|R_i\|. $$

On the other hand, the skew-symmetric contributions cancel in the sum over ordered pairs:
$$ \sum_i w_i =\sum_{i\ne j}s_is_jr_i^{\mathsf T}Ar_j =\sum_{i\ne j}s_is_jr_i^{\mathsf T}r_j =\sum_i s_i r_i^{\mathsf T}R_i. $$
Every probability vector satisfies
$$ \left\|p_i-\frac e3\right\|^2 =\|p_i\|^2-\frac13 \leq\frac23. $$
Cauchy–Schwarz therefore yields
$$ \sum_i w_i \leq\sqrt{\frac23}\sum_i s_i\|R_i\|. $$
Comparing the two bounds forces $R_i=0$ for every cartel.

For $k\geq2$, write $R=\sum_i s_ir_i$. Then $R_i=R-s_ir_i$, and summing these identities gives
$$ 0=\sum_iR_i=(k-1)R. $$
Hence $R=0$, and then $s_ir_i=0$. Every cartel has positive mass, so $p_i=e/3$. Every equilibrium consequently gives payoff $b(s_i)$.

Conversely, independently uniform vertex choices form an equilibrium: every vertex gives payoff $b(s_i)$, and convexity excludes a profitable nonvertex deviation. When $k=1$, the grand cartel maximizes $\|y\|^2$ on the unit simplex; the maximum is $1=b(1)$, and every equilibrium attains it.

This proves implementation for every partition and every mixed equilibrium. $\square$

3. New result: characteristic-function decision is $\mathrm{NP}$-hard

3.1 Computing satisfiability with permitted bounded loops

Let $\varphi$ be a Boolean formula on $n\geq1$ variables, with encoding length $N$.

Construct a program containing $n$ syntactically nested loops over the supplied partition list. At level $\ell$:

  • Reset a local iteration counter.
  • On the first list entry, set Boolean variable $\ell$ to $0$ and execute the next level.
  • On the second entry, set it to $1$ and execute the next level.
  • On subsequent entries, execute no inner computation.

At the deepest level, evaluate $\varphi$ on the selected assignment and update a persistent Boolean flag by disjunction.

Boolean evaluation uses rational arithmetic, for example
$$ \neg q=1-q,\qquad q\wedge r=qr,\qquad q\vee r=q+r-qr $$
for $q,r\in\{0,1\}$.

Whenever the partition has at least two blocks, the program evaluates every assignment in $\{0,1\}^n$ exactly once. Its final flag, denoted $F_\varphi$, is therefore $1$ exactly when $\varphi$ is satisfiable. Block contents and ordering do not affect this result.

The program has finite nesting depth $n$, fixed by its description. Every loop is bounded by the supplied list. Writing the program takes polynomial time in $N$; a conservative bound for its description length and construction time is $O(N^2)$.

3.2 The characteristic worth

Use one fixed type with mass one. The worth program returns zero on the empty cartel and $1$ on the grand cartel. For a proper cartel of mass $0<s<1$, it computes the preceding flag and returns
$$ v_\varphi(s)=b(s)-(1-F_\varphi). $$

Every proper cartel belongs to a partition with at least two blocks: a nonzero residual mass must occur outside it. Thus the flag is correct on every admissible input where it is used.

Writing
$$ \delta_\varphi= \begin{cases} 0,&\varphi\text{ is satisfiable},\\ 1,&\varphi\text{ is unsatisfiable}, \end{cases} $$
the represented function is exactly
$$ v_\varphi(s)= \begin{cases} 0,&s=0,\\ b(s)-\delta_\varphi,&0<s<1,\\ 1,&s=1. \end{cases} $$
It is therefore partition-independent, despite the use of list loops to evaluate its description.

3.3 Verification of superadditivity

Let $a,b>0$ and $a+b\leq1$. If $a+b<1$, then
$$ v_\varphi(a+b)-v_\varphi(a)-v_\varphi(b) =\frac{4ab}{3}+\delta_\varphi>0. $$
If $a+b=1$, then
$$ v_\varphi(1)-v_\varphi(a)-v_\varphi(b) =\frac{4ab}{3}+2\delta_\varphi>0. $$

Thus every produced input satisfies strict superadditivity, and hence also the weak promise of the characteristic-function class. Its worths are bounded in absolute value by one.

3.4 Correctness and complexity of the reduction

If $\varphi$ is satisfiable, then $v_\varphi=b$, implemented in Section 2.

If $\varphi$ is unsatisfiable, use a partition into $k\geq2$ equal blocks. Each block has worth $b(1/k)-1$, and
$$ \frac{|v_\varphi(1/k)|}{1/k} =k-\frac13-\frac{2}{3k} \longrightarrow\infty. $$
The necessary bound from Section 1 excludes implementation.

Consequently,
$$ \varphi\text{ is satisfiable} \quad\Longleftrightarrow\quad v_\varphi\text{ is implementable}. $$
This is a polynomial-time many-one reduction from Boolean satisfiability, with $m$ fixed, $\tau=1$, and $L=O(N^2)$.

Therefore characteristic-function implementability is $\mathrm{NP}$-hard under the stated program encoding. The result already holds for strictly superadditive characteristic functions.

The reduction exploits succinct descriptions whose evaluation on a two-block partition can take exponential time in $L$. A uniform constant nesting bound across inputs, or a requirement that characteristic worths be supplied as loop-free circuits in $x$, would require a different hardness argument.

4. Strict partition-function decision is undecidable

4.1 A permitted machine simulation

Fix a deterministic Turing machine $M$ on blank input. Define
$$ h_M(k)= \begin{cases} 1,&M\text{ halts within its first }k\text{ steps},\\ 0,&\text{otherwise}, \end{cases} \qquad q_M(k)=k h_M(k). $$

These quantities can be computed by a rational-arithmetic program with one loop over the partition list.

For completeness, represent the tape on either side of the head by finite stacks. Choose an integer base $D$ exceeding the number of tape symbols, and assign symbols digits in $\{1,\ldots,D-1\}$. Encode a stack by
$$ \xi=\sum_{r=1}^{\ell}d_rD^{-r}. $$
The empty stack is zero. For a nonempty stack,
$$ D\xi=d_1+\eta,\qquad 0\leq\eta<1. $$
A finite collection of comparisons therefore recovers $d_1$. Popping replaces $\xi$ by $D\xi-d_1$; pushing digit $d$ replaces it by $(d+\xi)/D$. Empty-stack reads supply the blank symbol.

Finite branches encode the transition table. Each list iteration performs one machine step, increments the counter, and retains any halting flag. All divisions are by the positive constant $D$.

The simulation ignores block contents, so it is reindexing invariant. Its description can be constructed in polynomial time and length from the description of $M$.

4.2 The promised worth and reduction

Again use one type of mass one. For a designated cartel of mass $s$ in a partition with $k$ blocks, set
$$ v_M(s,\pi)=b(s)-s q_M(k). $$
Empty-cartel worth is zero.

The sequence $q_M(k)$ is nondecreasing. When blocks of masses $a,b>0$ merge, the number of blocks decreases from $k$ to $k-1$, and
$$ v_M(a+b,\pi')-v_M(a,\pi)-v_M(b,\pi) = \frac{4ab}{3} +(a+b)\bigl(q_M(k)-q_M(k-1)\bigr)>0. $$
Thus the strict promise holds for every produced input.

If $M$ never halts, the worth is exactly $b(s)$ and is implementable.

If $M$ halts, then $q_M(k)=k$ for all sufficiently large $k$. Equal-block partitions give
$$ v_M(1/k,\pi)=b(1/k)-1, $$
whose absolute worth per unit mass diverges as calculated in Section 3. Implementation is impossible.

Hence
$$ v_M\text{ is implementable} \quad\Longleftrightarrow\quad M\text{ never halts}. $$

Nonhalting is undecidable. Therefore strict partition-function implementability is undecidable with fixed $m$ and $\tau=1$. In particular, no decision algorithm has a computable running-time bound in $m,\tau,L$. Its $\mathrm{NP}$-hardness also follows from Section 3, since characteristic functions form a subclass of partition functions.

The [finite-society existence theorem cited in the task](https://arxiv.org/pdf/2402.14952v2) does not contradict this result: the present definition requires one finite-description game to work across partitions with arbitrarily many divisible-population blocks.

5. Construction: established bounds and remaining gap

5.1 Impossibility for sound construction on all promised inputs

Suppose an effective construction procedure:

  • outputs only valid implementations on inputs satisfying the strict-superadditivity promise;
  • eventually outputs an implementation whenever one exists.

Applied to $v_M$, observing an implementation output would semidecide nonhalting. This is impossible: halting is recursively enumerable, and if nonhalting were also recursively enumerable, running the two recognizers in parallel would decide halting.

Thus no such sound construction procedure exists, even if it may run forever on nonimplementable inputs.

5.2 Why this does not settle existence-promised synthesis

A procedure required to be correct only when implementability is additionally promised may output arbitrary descriptions on other inputs. Its output therefore need not recognize nonhalting.

Both reductions above illustrate the distinction sharply: every implementable instance produced by either reduction has the same constant-size baseline implementation. On those restricted families, existence-promised construction simply outputs that game.

Accordingly, neither undecidability nor the characteristic-function hardness reduction establishes a lower bound for general existence-promised synthesis.

5.3 Explicit construction bounds for proved families

For the baseline $v(x)=b(s(x))$:

  • With one fixed type, construction time and game-description length are $O(1)$.
  • With arbitrary support, separate density circuits give construction time

$$ O\!\left(L+\tau m+\tau^2\log(\tau+2)\right) $$
and description length
$$ O\!\left(\tau m+\tau^2\log(\tau+2)\right), $$
excluding a separate copy of the society description. Including that copy adds at most $O(L)$.

These bounds follow by explicitly listing three actions per type and aggregating the $\tau$ coordinates for each action in each density circuit. Binary coordinate references account for the logarithmic factor.

For explicitly supplied additive worths
$$ v(x)=\sum_t c_t x_t,\qquad c_t\in\mathbb Q, $$
give each type one action with constant density $c_t$. Every cartel has a unique allocation and receives exactly its worth. Construction time and description length are $O(L)$.

These are bounds for particular families, not for arbitrary implementable inputs.

6. What remains open

Under the program-language reading specified above, the requested decision alternatives are settled: both classes are $\mathrm{NP}$-hard, and the strictly superadditive partition-function class is additionally undecidable.

The remaining task is general synthesis under an implementability promise. No algorithm, impossibility theorem, or general output-description bound for that promise problem has been proved here for either class. Nor has the necessary linear growth bound been shown sufficient for characteristic-function implementation.
