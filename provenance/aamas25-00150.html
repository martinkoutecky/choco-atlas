The continuous mirror question, as graded

Given a finite type set \(T\) with \(|T|=\tau\), rational mass vector \(\mu\in\mathbb Q_{\ge0}^{\tau}\), finite public state \(w\), finitely encoded anonymous clone-symmetric transition maps from \((w,\mu)\) and a type-action mass vector \(z\) to successor \((w',\mu')\), finitely encoded short-sighted preference preorders over each type's personal one-step outcomes, a valuation by rational polyhedral predicates, and an \(R\text{-ATL}\) formula \(\varphi\), decide exactly whether the atomless population satisfies \(\varphi\) at \((w,\mu)\) when coalitions are measurable subsets of \(\bigsqcup_{t\in T}[0,\mu_t)\) and rationality uses pointwise strong non-dominance almost everywhere.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Initial masses need not sum to one; their positive total is conserved. There are \(m\) action names and a nonempty finite public-state set \(W\).
The population consists of persistent individuals in \(X=\bigsqcup_{t\in T}[0,\mu_t)\), with Lebesgue measure. Each coalition named in the formula is a fixed measurable subset, possibly empty. Encode the joint membership patterns of all named coalitions by immutable attributes of types, with binary-rational masses; individuals may change their other type attributes, but never their coalition memberships.
At state \(s=(w,\mu)\), each type has a nonempty available-action set. Every measurable action profile is executable and induces real masses \(z_{ta}\geq0\) with \(\sum_a z_{ta}=\mu_t\); these masses are not restricted to rationals.
Transitions are deterministic and anonymous: input rules specify \(w'\) and each type-action group's next type \(q(t,a,s,z)\), preserving membership attributes, and \(\mu'_u=\sum_{t,a:q(t,a,s,z)=u}z_{ta}\). Individuals retain their identities. Successor masses may be zero; no types outside the input list appear.
Use finite guarded rational piecewise-affine descriptions: guards are Boolean combinations of rational linear equalities and strict or weak inequalities; available actions, public successors and next-type outputs are determined by such guards. Rules are promised total and single-valued on executable profiles. Atomic valuations and preference comparisons use the same predicate encoding.
Each type at each state has a total preference preorder over personal one-step outcomes \((q(t,a,s,z),w',\mu')\); later outcomes are irrelevant, and equal one-step outcomes are indifferent. No stability assumption is imposed.
An action is strongly dominated for an individual if another available action gives a strictly preferred one-step outcome against every measurable action profile of all other individuals. A unilateral deviation has zero mass, so it leaves \(z\) unchanged, while its personal next type is recomputed. Rationality means choosing an undominated action almost everywhere in the coalition.
Strategies are pure, measurable in individuals at every finite public-state history, and have perfect recall. Ordinary capability existentially quantifies a coalition strategy against all unrestricted complement strategies. Rational capability adds the preceding rationality condition at the state where the modality is evaluated; it does not impose rationality at later histories.
The language consists of Boolean combinations of atoms and ordinary or rational coalition modalities with \(\mathsf X\), \(\mathsf G\), and \(\mathsf U\). Along every resulting path \(s_0s_1\ldots\), \(\mathsf X\psi\) requires \(\psi(s_1)\); \(\mathsf G\psi\) requires \(\psi(s_k)\) for every \(k>0\); \(\psi\mathsf U\chi\) requires some \(k>0\) with \(\chi(s_k)\) and \(\psi(s_h)\) for \(1\leq h<k\).
Is exact satisfaction of an input \(R\text{-ATL}\) formula \(\varphi\) at an input state \((w,\mu)\) solvable in polynomial time, or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), \(|W|\), \(|\varphi|\), and the total binary input length \(L\).
For explicitly represented finite concurrent games with short-sighted preferences, global \(R\text{-ATL}\) model checking is \(\mathrm{P}\)-complete ([source](https://arxiv.org/html/2502.12286v1#S7)). No result settling this precise atomless problem was located.

Result

Exact satisfaction is \(\mathrm{NP}\)-hard, already with \(\ m=2\), \(\lvert W\rvert=2\), a fixed formula of constant length, unchanged type masses, and complete indifference between outcomes.

Consequently, a running time polynomial in \(\ m,\tau,\lvert W\rvert,\lvert\varphi\rvert,L\) would imply \(\mathrm P=\mathrm{NP}\). The proof applies to both ordinary and rational capability.

Reduction from satisfiability

Let \(\ F=\bigwedge_{j=1}^{r}D_j\) be a Boolean formula in conjunctive normal form, with variables \(\ v_1,\ldots,v_n\), where each clause has at most three literals. Deciding satisfiability of these formulas is \(\mathrm{NP}\)-complete. We may assume \(\ n\geq1\): adding an unused variable preserves satisfiability.

Construct the following society.

  • There are \(\tau=n\) types \(\ t_1,\ldots,t_n\), each with initial mass \(\mu_{t_i}=1\).
  • The two action names are \(\ 0,1\), both available to every type at every state.
  • The public-state set is \(\ W=\{w_0,w_1\}\), initially \(\ w_0\).
  • The sole named coalition is the grand coalition \(\ C=X\). Every type carries its membership attribute.
  • Every individual retains its type: \(\ q(t_i,a,s,z)=t_i\) for both actions and every executable profile.
  • Preferences are universal indifference: every pair of personal one-step outcomes is indifferent.

The initial total mass is \(\ n\), which is permitted by the task.

For an executable profile, put \(\ x_i=z_{t_i,1}\). Feasibility gives

\(\ z_{t_i,0}=1-x_i,\qquad 0\leq x_i\leq1.\)

For a literal \(\ell\), define its affine value by

\(\ h_{v_i}(x)=x_i,\qquad h_{\neg v_i}(x)=1-x_i.\)

Define the guard

\(\ B_F(z)=\left(\bigwedge_{i=1}^{n}(x_i=0\ \lor\ x_i=1)\right)\land\left(\bigwedge_{j=1}^{r}\left(\sum_{\ell\in D_j}h_\ell(x)\geq1\right)\right).\)

This is a permitted Boolean combination of rational linear predicates. In particular, each clause contributes a single affine inequality involving at most three coordinates.

The public transition rules are:

  • From \(\ w_0\), move to \(\ w_1\) if \(\ B_F(z)\) holds, and otherwise remain at \(\ w_0\).
  • From \(\ w_1\), remain at \(\ w_1\).

Let the atom \(\ p\) hold exactly when the public state is \(\ w_1\). Use the fixed formula

\(\ \varphi=\langle\!\langle C\rangle\!\rangle^{\mathrm{rat}}\mathsf Xp.\)

Verification of the model assumptions

Transitions and conservation. The guards \(\ B_F\) and \(\neg B_F\) are mutually exclusive and exhaustive, so the public transition is total and single-valued. Type outputs are constant, hence are valid guarded piecewise-affine descriptions. For each type,

\(\ \mu'_{t_i}=z_{t_i,0}+z_{t_i,1}=\mu_{t_i}.\)

Thus all masses remain positive and equal to their initial values. No new type appears, individuals retain their identities, and coalition membership is preserved.

Real profiles and measurability. Every vector \(\ x\in[0,1]^n\) is realizable by a pure measurable profile: in the interval belonging to type \(\ t_i\), assign action \(\ 1\) to \(\ [0,x_i)\) and action \(\ 0\) to \(\ [x_i,1)\). These sets are measurable and have the required masses.

Preferences and rationality. Universal indifference is a total preorder, represented by a constantly true comparison predicate. Its strict part is empty. Therefore no available action is strongly dominated: no alternative gives a strictly preferred outcome against any profile, let alone every profile. Every executable strategy is consequently rational at the initial state.

A chosen initial profile extends to a strategy by prescribing action \(\ 0\) at every later history. Availability is unconditional, and the resulting action assignment is measurable at every history.

Correctness of the reduction

We prove

\(\ F\text{ is satisfiable}\quad\Longleftrightarrow\quad(w_0,\mu)\models\varphi.\)

Forward direction. Let \(\ b\in\{0,1\}^n\) satisfy \(\ F\). Choose action \(\ b_i\) for every individual of type \(\ t_i\). Then \(\ x_i=b_i\), so all endpoint conditions hold.

For Boolean coordinates, \(\ h_\ell(b)\) equals \(\ 1\) exactly when literal \(\ell\) is true, and otherwise equals \(\ 0\). Each satisfied clause therefore has literal-value sum at least \(\ 1\). Thus \(\ B_F(z)\) holds, and the first successor has public state \(\ w_1\), where \(\ p\) is true.

The strategy is rational by complete indifference. Since \(\ C=X\), the complement is empty and has no choices. Determinism gives a unique resulting path. Hence the rational coalition enforces \(\mathsf Xp\).

Reverse direction. Suppose \(\ (w_0,\mu)\models\varphi\). The witnessing strategy supplies an executable initial profile, with real coordinates \(\ x_i=z_{t_i,1}\). Because the first successor satisfies \(\ p\), its public state is \(\ w_1\). From \(\ w_0\), this occurs only when \(\ B_F(z)\) holds.

Its endpoint conditions imply \(\ x_i\in\{0,1\}\) for every \(\ i\). Define the Boolean assignment \(\ b_i=x_i\). Every clause inequality says that the sum of its Boolean literal values is at least \(\ 1\), so at least one literal is true. Thus \(\ b\) satisfies every clause of \(\ F\).

This direction explicitly excludes fractional false positives: although arbitrary real splits are executable, a successful profile must satisfy every endpoint condition.

The equivalence also holds for \(\langle\!\langle C\rangle\!\rangle\mathsf Xp\), because rationality excludes no strategy.

Encoding size and running-time consequences

Using sparse linear expressions and binary type indices, the construction has

\(\ m=2,\qquad\tau=n,\qquad\lvert W\rvert=2,\qquad\lvert\varphi\rvert=O(1),\qquad L=O((n+r)\log(n+1)).\)

There are \(\ O(n+r)\) predicate and rule occurrences. All numerical coefficients, constants, and initial masses have bounded binary length. Writing the construction takes \(\ O((n+r)\log(n+1))\) time under this encoding; in particular, the reduction is polynomial.

The restricted family constructed above is itself \(\mathrm{NP}\)-complete. A certificate consists of \(\tau\) Boolean choices, and checking the guard takes polynomial time in \(\ L\). Enumerating these choices gives a decision procedure for this family in \(\ O(2^\tau\operatorname{poly}(L))\) time. This is an upper bound for the restricted family, not for arbitrary temporal formulas in the full model.

Thus even a bound of the form \(\ f(m,\lvert W\rvert,\lvert\varphi\rvert)\operatorname{poly}(\tau,L)\) for the full problem would imply \(\mathrm P=\mathrm{NP}\), since those three arguments are fixed in the reduction.

The cited finite-game result establishes polynomial-time model checking for explicitly represented finite games with short-sighted preferences. [Li, Lorini, and Mittelmann, Section 7](https://arxiv.org/html/2502.12286v1#S7). Here, the guarded representation compactly encodes the search over Boolean profiles. The reduction proves that computing even this one-step capability from that representation is already \(\mathrm{NP}\)-hard.
