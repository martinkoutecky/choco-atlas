Theorem 3 — class: hardness

The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) summing to \(1\), nonnegative-weight issue formulas built from \(\land\), \(\lor\), and quota tests \(z_t\ge q\) for rational \(q\), nonnegative payment rates \(p_t\) with \(\sum_t\mu_t p_t=V(\mu)\), and a rational goal \(\gamma\), decide whether some proper nonempty coalition mass vector \(z\) with \(0\le z_t\le\mu_t\) satisfies \(V(z)-\sum_t p_tz_t>\gamma\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\) explicitly represented Boolean issue formulas \(F_j\), built using \(\land\), \(\lor\), parentheses, and atoms \(z_t\ge q\) with \(q\in\mathbb Q\); issue weights satisfy \(w_j\in\mathbb Q_{\ge0}\). Define \(V(z)=\sum_{j:F_j(z)=\mathrm{true}}w_j\); a quota test is true at equality.
The input also gives payment rates \(p_t\in\mathbb Q_{\ge0}\) satisfying \(\sum_t\mu_t p_t=V(\mu)\), and a goal \(\gamma\in\mathbb Q\). A coalition is a real vector \(z\) with \(0\le z_t\le\mu_t\); it is proper and nonempty exactly when \(0<\sum_t z_t<1\).
Decide whether such a coalition satisfies \(V(z)-\sum_t p_tz_t>\gamma\). Let \(L\) be the total binary input length, including formula encodings; state running times in \(m,\tau,L\).

Is this continuous MOST-VIOLATED-COALITION decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite agents, MOST-VIOLATED-COALITION is \(\mathrm{NP}\)-complete for MC-nets with nonnegative pattern weights and both \(\land\) and \(\lor\) allowed ([Li–Conitzer](https://users.cs.duke.edu/~conitzer/complexityAAMAS14.pdf)). No result settling the exact continuous quota-formula problem above was identified in the literature search.

Modeling choices made when packaging the task

  • Defined the previously unspecified V as the sum of the weights of satisfied issue formulas, following MC-net valuation.
  • Made weights and payment rates binary rationals so the decision problem has a finite input encoding.
  • Interpreted coalition coordinates as real masses and proper nonemptiness as total coalition mass strictly between zero and one.
  • Removed zero-mass types from the supplied support and defined m as the number of issues and L as the total binary input length.
  • Retained arbitrary rational quotas as stated, including thresholds that are always true or always false; imposed no superadditivity promise.

Result

The problem is \(\mathrm{NP}\)-complete under polynomial-time many-one reductions. Hardness holds even when all masses are equal dyadic rationals, all issue weights are \(1\), and every issue formula is a disjunction of two atoms. Thus a polynomial-time algorithm for the general problem would imply \(\mathrm P=\mathrm{NP}\).

The proof below handles the budget condition, fractional coalitions, properness, and the strict objective inequality explicitly.

1. Finite certificates for the continuous problem

Write \(\Phi(z)=V(z)-\sum_{t\in T}p_tz_t\). For each type \(t\), define
\[ D_t=\{0\}\cup\{q:0<q\leq\mu_t\text{ and the atom }z_t\geq q\text{ occurs in the input}\}. \]
In the required inline notation, this is \(D_t=\{0\}\cup\{q:0<q\leq\mu_t\text{ and }z_t\geq q\text{ occurs in the input}\}\).

Rounding lemma. For every feasible coalition \(z\), there exists \(y\in\prod_{t\in T}D_t\) such that \(y_t\leq z_t\) for every \(t\), every input atom has the same truth value at \(y\) and \(z\), and \(\Phi(y)\geq\Phi(z)\).

Proof. Set \(y_t=\max\{d\in D_t:d\leq z_t\}\), which exists because \(0\in D_t\).

Consider an input atom \(z_t\geq q\).

  • If \(q\leq0\), it is true at both vectors.
  • If \(q>\mu_t\), it is false at both vectors.
  • If \(0<q\leq\mu_t\), then \(q\in D_t\). When \(z_t\geq q\), the definition of \(y_t\) gives \(y_t\geq q\). When \(z_t<q\), the inequality \(y_t\leq z_t\) gives \(y_t<q\).

Thus all atoms, and consequently all formulas, have identical truth values. Hence \(V(y)=V(z)\). Since each \(p_t\geq0\) and \(y_t\leq z_t\), we obtain \(\Phi(y)\geq\Phi(z)\). This proves the lemma.

The only difficulty is that rounding a nonempty coalition might produce the zero vector. The following observation handles that case.

Zero-vector observation. If \(V(0)>\gamma\), a proper nonempty coalition satisfying the strict inequality exists.

Proof. Put \(\delta=V(0)-\gamma>0\), choose any type \(r\), and set
\( \varepsilon=\min\{\mu_r/2,\delta/[2(p_r+1)]\} \).
Let \(z_r=\varepsilon\) and let every other coordinate be zero. Then
\(0<\sum_tz_t=\varepsilon\leq1/2<1\).

Every formula is monotone in the coordinates: atoms are monotone, and both allowed connectives preserve monotonicity. Nonnegative issue weights therefore imply \(V(z)\geq V(0)\). Moreover, \(p_r\varepsilon\leq\delta/2\), so
\(\Phi(z)\geq V(0)-\delta/2=\gamma+\delta/2>\gamma\).

Now suppose \(V(0)\leq\gamma\) and a proper nonempty witness \(z\) exists. Apply the rounding lemma. The resulting \(y\) remains proper because \(\sum_ty_t\leq\sum_tz_t<1\). It is nonempty: otherwise, equality of formula truth values would give \(V(z)=V(0)\), and consequently
\(\Phi(z)\leq V(0)\leq\gamma\), contradicting the witness inequality.

We have therefore proved the exact characterization:

The answer is yes if and only if either \(V(0)>\gamma\), or there exists a proper nonempty vector \(y\in\prod_tD_t\) with \(\Phi(y)>\gamma\).

Each coordinate of such a grid witness is either zero or an input quota. A certificate can specify its input occurrence, using \(O(\tau\log(L+1))\) bits altogether. Formula evaluation and exact rational comparisons take polynomial time. This proves membership in \(\mathrm{NP}\).

2. A polynomial reduction from unweighted MAX-CUT

We use the known \(\mathrm{NP}\)-completeness of unweighted MAX-CUT: given a simple undirected graph \(G=(U,E)\) and a positive integer \(K\), decide whether some vertex subset has at least \(K\) crossing edges. This is the Simple Max Cut problem established by [Garey, Johnson, and Stockmeyer](https://doi.org/10.1016/0304-3975%2876%2990059-1).

Let \(n=|U|\geq2\), and choose \(N=2^{\lceil\log_2n\rceil}\). Add isolated vertices to obtain a graph \(\widehat G\) on \(N\) vertices. This preserves every attainable cut size, and \(n\leq N<2n\).

Construct the society as follows.

  • There is one type per vertex of \(\widehat G\), so \(\tau=N\).
  • Every type has mass \(\mu_t=1/N\).
  • For each edge \(e=\{u,v\}\), introduce the issue

\(F_e(z)=(z_u\geq1/N)\lor(z_v\geq1/N)\), with weight \(w_e=1\).

  • Set \(p_t=N\deg_{\widehat G}(t)/2\).
  • Set \(\gamma=(2K-1)/4\).

All masses are positive dyadic rationals, and all payments and weights are nonnegative rationals. There are \(m=|E|\) issues.

The budget condition holds

At the grand coalition, every issue is true, so \(V(\mu)=|E|\). By the degree-sum identity,

\(\displaystyle \sum_t\mu_tp_t=\sum_t\frac1N\frac{N\deg_{\widehat G}(t)}2=\frac12\sum_t\deg_{\widehat G}(t)=|E|=V(\mu).\)

Thus the constructed instance satisfies the required payment condition exactly.

Coalitions containing whole types encode cuts

For a vertex subset \(S\), let \(z^S_t=\mu_t\) when \(t\in S\), and \(z^S_t=0\) otherwise.

Write \(a(S)\) for the number of edges with both endpoints in \(S\), and \(c(S)\) for the number with exactly one endpoint in \(S\). An issue is true precisely when its edge has an endpoint in \(S\). Consequently,
\(V(z^S)=a(S)+c(S)\).

The degree sum over \(S\) equals \(2a(S)+c(S)\), so

\(\displaystyle \sum_tp_tz^S_t=\frac12\sum_{t\in S}\deg_{\widehat G}(t)=a(S)+\frac{c(S)}2.\)

Subtracting gives the central identity
\(\Phi(z^S)=c(S)/2\).

If \(c(S)\geq K\), then \(K\geq1\) implies that \(S\) is nonempty and proper. Hence \(z^S\) is a proper nonempty coalition, and

\(\displaystyle \Phi(z^S)=\frac{c(S)}2\geq\frac K2>\frac{2K-1}4=\gamma.\)

Thus every yes-instance of MAX-CUT yields a yes-instance of the continuous problem.

Fractional coalitions cannot improve the reduction

Conversely, suppose a proper nonempty real coalition \(z\) satisfies \(\Phi(z)>\gamma\). Define its set of fully included types by
\(S=\{t:z_t=\mu_t\}\).

Because \(0\leq z_t\leq\mu_t=1/N\), the atom \(z_t\geq1/N\) is true exactly when \(t\in S\). Therefore,
\(V(z)=a(S)+c(S)\).

Nonnegative payments give

\(\displaystyle \sum_tp_tz_t\geq\sum_{t\in S}p_t\mu_t=a(S)+\frac{c(S)}2.\)

It follows that \(\Phi(z)\leq c(S)/2\). Combining this with the strict witness inequality yields

\(\displaystyle \frac{c(S)}2>\frac{2K-1}4,\qquad c(S)>K-\frac12.\)

Since \(c(S)\) is an integer, \(c(S)\geq K\). Isolated padding vertices affect no crossing edges, so the original graph also has a cut of size at least \(K\).

This proves both directions of the reduction. The quarter-unit offset in \(\gamma\) explicitly converts the integer MAX-CUT threshold into the required strict inequality.

3. Encoding size and running times

The reduction has \(\tau=N<2n\), \(m=|E|\), and output length
\(L=O((m+\tau)\log(\tau+1)+\log(K+1))\).
Degrees, payments, and formulas can all be constructed in polynomial time.

For general instances, the certificate verification above takes
\((m+\tau+L)^{O(1)}\) bit operations.

There is also an exact deterministic algorithm: first check \(V(0)>\gamma\), then enumerate the quota grid and test every proper nonempty point. If \(a_t=|D_t|-1\), the grid contains \(\prod_t(a_t+1)\) points. Since the total number of atom occurrences is at most \(L\), this gives running time

\(\displaystyle O\!\left((L+1)^\tau(m+\tau+L)L^3\right)\)

as a conservative bound using elementary exact integer arithmetic. In particular, the problem is polynomial-time solvable for every fixed support size \(\tau\), while it is \(\mathrm{NP}\)-complete when \(\tau\) is part of the input.
