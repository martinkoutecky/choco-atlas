The continuous mirror question, as graded

Classify this problem parameterized by \(K\), with input size measured in \(m,\tau\), and the mass bit length \(L\).

A society is given by its support: distinct approval types \(A_1,\ldots,A_\tau\subseteq C\), each with \(|A_i|\le p\), and positive binary-rational masses \(\mu_i\) satisfying \(\sum_i\mu_i=1\). Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

Classification

For every fixed \(p\ge 2\), the problem is \(\mathrm{NP}\)-complete and is \(\mathrm{W}[1]\)-hard parameterized by \(K\). Consequently, an exact algorithm with running time \(f(K)\operatorname{poly}(m,\tau,L)\) would imply \(\mathrm{FPT}=\mathrm{W}[1]\).

The hardness holds even when every approval type has size at most \(2\) and every mass is a dyadic rational.

Membership in \(\mathrm{NP}\) and an exact enumeration algorithm

Write each mass as \(\mu_i=a_i/b_i\), and write \(\theta=a_\theta/b_\theta\), with positive denominators. Set

\(D=b_\theta\prod_{i=1}^{\tau}b_i,\qquad w_i=a_i(D/b_i),\qquad H=a_\theta(D/b_\theta).\)

Then a committee \(W\) satisfies the threshold exactly when

\(\displaystyle \sum_{i:A_i\cap W\ne\varnothing}w_i\ge H.\)

These are integer computations. Since \(L\) is the total numerical bit length, \(D\), the \(w_i\), and \(H\) have \(\mathrm{O}(L)\) bits. Moreover, every represented-mass sum is at most \(D\), because the masses are positive and sum to \(1\). Constructing these integers takes \(\mathrm{O}((\tau+1)L^2)\) bit operations using elementary arithmetic.

A certificate lists the selected candidates. Its size is polynomial in the input length, since at most \(m\) candidates can be selected. Checking its cardinality, scanning the approval types, and computing the integer sum all take polynomial time in \(m,\tau,L\). Thus the problem belongs to \(\mathrm{NP}\).

For completeness, let \(k=\min\{K,m\}\). Represented mass is monotone under adding candidates: any type intersecting \(W\) also intersects every superset of \(W\). Therefore every feasible committee can be extended to size exactly \(k\) without decreasing its represented mass.

Enumerating all size-\(k\) committees consequently gives an exact algorithm with running time

\(\displaystyle \mathrm{O}\!\left(\binom{m}{k}\operatorname{poly}(m,\tau,L)\right).\)

In particular, this is an XP algorithm parameterized by \(K\), with running time bounded by \((m+1)^K\operatorname{poly}(m,\tau,L)\). It does not establish FPT tractability.

A reduction preserving \(K\)

We use the supplied result that explicitly listed, unweighted voters with approval sets of size at most \(p\) give an \(\mathrm{NP}\)-complete and \(\mathrm{W}[1]\)-hard decision problem parameterized by committee size, including the case \(p=2\). This is the bounded-frequency maximum-coverage problem studied by [Skowron–Faliszewski](https://arxiv.org/html/1309.4405).

Consider such a discrete instance with candidates \(C\), explicitly listed voters \(B_1,\ldots,B_n\), committee limit \(K\), and integer target \(t\). Its question is whether some committee represents at least \(t\) voters.

We may restrict to \(n\ge1\) and \(0\le t\le n\): other cases are immediately decidable and can be mapped to fixed yes- or no-instances with committee limit \(0\).

Aggregate identical ballots. For each distinct approval type \(A\), define

\(\displaystyle d_A=\bigl|\{j:B_j=A\}\bigr|.\)

Choose the power of two

\(\displaystyle Q=2^{\lceil\log_2(n+1)\rceil}.\)

Thus \(n<Q\le2n\). Construct the support-and-mass instance as follows:

  • For each occurring nonempty type \(A\), assign mass \(\mu_A=d_A/Q\).
  • Include exactly one empty type, assigning it mass \(\mu_{\varnothing}=(d_{\varnothing}+Q-n)/Q\), where \(d_{\varnothing}=0\) if no original voter has an empty ballot.
  • Set \(\theta=t/Q\), and retain the same candidates and committee limit \(K\).

Every included mass is positive. In particular, the empty type has positive mass because \(Q>n\). The masses sum to

\(\displaystyle \frac{\sum_{A\ne\varnothing}d_A+d_{\varnothing}+Q-n}{Q}=1.\)

All approval types are distinct and have size at most \(p\). Every mass is dyadic, and the output support size is at most \(n+1\).

For every committee \(W\), the empty type contributes no represented mass. Hence

\(\displaystyle \sum_{A:A\cap W\ne\varnothing}\mu_A =\frac{|\{j:B_j\cap W\ne\varnothing\}|}{Q}.\)

Therefore,

\(\displaystyle \sum_{A:A\cap W\ne\varnothing}\mu_A\ge\theta \quad\Longleftrightarrow\quad |\{j:B_j\cap W\ne\varnothing\}|\ge t.\)

This proves both directions of the reduction.

Because the voters are explicitly listed, aggregating their types takes polynomial time in the source input length. The new numerators and denominators have \(\mathrm{O}(\log(n+1))\) bits, so the output also has polynomial size. Crucially, the parameter remains exactly \(K\).

Applying this reduction to the hard discrete instances with approval size at most \(2\) proves hardness for every fixed \(p\ge2\). Together with membership in \(\mathrm{NP}\), it proves \(\mathrm{NP}\)-completeness.

Consequence for exact FPT algorithms

Suppose the weighted support problem admitted an exact algorithm running in

\(\displaystyle f(K)(m+\tau+L)^c,\)

where \(f\) is computable and \(c\) is independent of \(K\). Composing it with the polynomial-time reduction above would give an FPT algorithm for the supplied \(\mathrm{W}[1]\)-hard discrete problem, because the output size is polynomial and \(K\) is preserved. This would imply \(\mathrm{FPT}=\mathrm{W}[1]\).

Thus, under the standard assumption \(\mathrm{FPT}\ne\mathrm{W}[1]\), the answer to the exact FPT question is no.

This argument establishes \(\mathrm{W}[1]\)-hardness; it does not assert \(\mathrm{W}[1]\)-membership for arbitrary binary-rational weights. Such membership is unnecessary for the stated obstruction to exact FPT time.
