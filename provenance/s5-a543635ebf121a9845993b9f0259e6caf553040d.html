Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) collaboration types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types. Each collaboration has \(m=2\) members and interacts only internally. All parameters are binary rationals; \(L\) is the total input bit length.
For each type \(t\), assume \(V_{H,t}>V_{L,t}>0\), \(a_t\in(1/2,1]\), \(c_t,D_t>0\), and \(V_{H,t}/V_{L,t}>\max\{(14a_t-5)/(6a_t-1),(2a_t+1)/(3-2a_t)\}\).
Members simultaneously choose contributions \(d_i\in\{0,D_t\}\), observe both contributions, then simultaneously choose efforts \(e_i\in\{0,1\}\). Reports are truthful; individual correctness probabilities are \(1/2\) without effort and \(a_t\) with effort. Majority voting breaks report ties uniformly.
Team accuracy is \(P_t(e)=1/2+(2a_t-1)(e_H+e_L)/4\). Equal Allocation (EA) gives each member half the contribution pool, with payoff \(U_{i,t}(d,e)=V_{i,t}P_t(e)+(d_H+d_L)/2-d_i-c_te_i\).
Use pure subgame-perfect equilibrium, selecting effort \(1\) whenever a member is indifferent in an effort subgame. Write its realized profile as \(s_t=(d_{H,t},d_{L,t},e_{H,t},e_{L,t})\).
Compute every \(s_t\), each profile mass \(M(s)=\sum_{t:s_t=s}\mu_t\), cohort accuracy \(A=\sum_t\mu_tP_t(e_t)\), and cohort welfare \(W=\sum_t\mu_t[U_{H,t}(s_t)+U_{L,t}(s_t)]\), all exactly.

Result

The exact computation problem is polynomial-time solvable for \(m=2\). More precisely, with binary-encoded rational inputs and outputs, it belongs to \(\mathrm{FP}\).

The proof below derives the selected subgame-perfect equilibrium directly, then bounds the bit complexity of computing all requested outputs. Its equilibrium characterization agrees with Theorem 1 of the [linked paper](https://arxiv.org/pdf/2310.11751).

1. Effort decisions in every subgame

Fix a supported type \(t\). Define

\(\alpha_t=(2a_t-1)/4\), \(\theta_{L,t}=\alpha_tV_{L,t}\), and \(\theta_{H,t}=\alpha_tV_{H,t}\).

Because \(a_t>1/2\) and \(V_{H,t}>V_{L,t}>0\), these thresholds satisfy

\(0<\theta_{L,t}<\theta_{H,t}\).

For either member \(i\in\{H,L\}\), fix any contribution history \(d=(d_H,d_L)\) and any effort choice \(e_{-i}\) by the other member. The payoff difference between exerting and withholding effort is

\(U_{i,t}(d,1,e_{-i})-U_{i,t}(d,0,e_{-i})=V_{i,t}\alpha_t-c_t.\)

Indeed, changing \(e_i\) from zero to one raises team accuracy by exactly \(\alpha_t\), leaves the contribution transfer unchanged, and incurs cost \(c_t\).

This difference is independent of both the contribution history and the other member’s effort. Consequently, applying the stipulated selection of effort one at indifference gives the uniquely selected effort action

\(e_{i,t}^{*}=\mathbf{1}\{c_t\leq\theta_{i,t}\}.\)

Thus the selected effort equilibrium is identical after every contribution history, including histories that will not occur in equilibrium. The ordering of the thresholds yields exactly three cases:

| Condition | Selected effort profile |
|---|---|
| \(c_t\leq\theta_{L,t}\) | \((1,1)\) |
| \(\theta_{L,t}<c_t\leq\theta_{H,t}\) | \((1,0)\) |
| \(\theta_{H,t}<c_t\) | \((0,0)\) |

In particular, equality at either threshold is handled exactly as required.

2. Contribution decisions and subgame perfection

Since the selected continuation effort is independent of contributions, changing member \(i\)’s contribution from zero to \(D_t\) changes their continuation payoff by

\(U_{i,t}(D_t,d_{-i},e_t^{*})-U_{i,t}(0,d_{-i},e_t^{*})=D_t/2-D_t=-D_t/2<0.\)

Therefore, zero contribution is strictly dominant in the induced contribution game. Its unique equilibrium is \((d_{H,t},d_{L,t})=(0,0)\).

Choosing these contributions and the selected effort equilibrium after every contribution history defines a pure subgame-perfect equilibrium: play is a Nash equilibrium in every effort subgame, and the initial contribution choices are strict best responses given those continuations. A deviation that also changes subsequent effort cannot improve upon this comparison, because the selected continuation effort already maximizes the deviator’s payoff.

Conversely, every pure subgame-perfect equilibrium satisfying the effort selection rule must use those effort actions after every history and hence must use zero contributions initially. Thus the selected realized profile is uniquely determined:

| Condition | \(s_t=(d_{H,t},d_{L,t},e_{H,t},e_{L,t})\) |
|---|---|
| \(c_t\leq\theta_{L,t}\) | \((0,0,1,1)\) |
| \(\theta_{L,t}<c_t\leq\theta_{H,t}\) | \((0,0,1,0)\) |
| \(\theta_{H,t}<c_t\) | \((0,0,0,0)\) |

The stronger valuation-ratio assumption in the question is unnecessary for this EA argument. The proof uses only the stated payoff, \(a_t>1/2\), \(V_{H,t}>V_{L,t}>0\), and \(D_t>0\), all of which hold on the promised input domain.

3. Exact profile masses, accuracy, and welfare

Partition the explicitly listed support into

\(T_2=\{t\in T:c_t\leq\theta_{L,t}\}\),

\(T_1=\{t\in T:\theta_{L,t}<c_t\leq\theta_{H,t}\}\),

\(T_0=\{t\in T:\theta_{H,t}<c_t\}\).

For \(j\in\{0,1,2\}\), define \(B_j=\sum_{t\in T_j}\mu_t\), with an empty sum equal to zero. The profile masses are exactly

\(M((0,0,1,1))=B_2\),

\(M((0,0,1,0))=B_1\),

\(M((0,0,0,0))=B_0\).

Every other profile has mass zero. Since the sets partition the support, \(B_0+B_1+B_2=1\).

The per-type accuracy \(p_t=P_t(e_t^{*})\) and welfare \(w_t=U_{H,t}(s_t)+U_{L,t}(s_t)\) are:

| Type set | \(p_t\) | \(w_t\) |
|---|---|---|
| \(T_2\) | \(a_t\) | \((V_{H,t}+V_{L,t})a_t-2c_t\) |
| \(T_1\) | \((2a_t+1)/4\) | \((V_{H,t}+V_{L,t})(2a_t+1)/4-c_t\) |
| \(T_0\) | \(1/2\) | \((V_{H,t}+V_{L,t})/2\) |

To justify the welfare column, summing the two given payoffs cancels all contribution transfers:

\(U_{H,t}(d,e)+U_{L,t}(d,e)=(V_{H,t}+V_{L,t})P_t(e)-c_t(e_H+e_L).\)

Therefore the requested cohort quantities are computed exactly by

\(A=\sum_{t\in T_2}\mu_ta_t+\sum_{t\in T_1}\mu_t(2a_t+1)/4+B_0/2\),

and

\(W=\sum_{t\in T}\mu_tw_t\),

using the explicit welfare expressions in the table.

4. Polynomial bit complexity

Interpret a binary rational in the standard explicit encoding as an integer numerator and a positive integer denominator, both written in binary. The following argument also covers explicitly encoded dyadic rationals.

Let \(\ell_t\) be the total encoding length of type \(t\), including its mass. Then \(\sum_{t\in T}\ell_t\leq L\).

Exact comparisons. Write \(a_t=p/q\), \(V_{i,t}=r/s\), and \(c_t=u/v\), with positive denominators. The threshold test is equivalent to

\(c_t\leq\theta_{i,t}\quad\Longleftrightarrow\quad4uqs\leq(2p-q)rv.\)

Both integers in this comparison have \(O(\ell_t)\) bits. Thus each type can be classified using two exact integer comparisons and a constant number of integer operations.

Exact summands. Each mass, accuracy, or welfare summand uses a constant number of rational additions and multiplications on that type’s inputs. It therefore admits a numerator-denominator representation with \(O(\ell_t)\) bits.

Exact accumulation. Consider any requested sum, writing its nonzero summands as \(n_t/b_t\), with \(b_t>0\). A common denominator is

\(Q=\prod_t b_t.\)

Its bit length is at most the sum of the denominator bit lengths, hence \(O(L)\). Each summand has absolute value at most \(2^{O(\ell_t)}\), so every partial sum has absolute value at most \(\tau\,2^{O(L)}\). Representing a partial sum over the corresponding product denominator therefore requires \(O(L+\log\tau)\) numerator bits as well.

These bounds also hold during sequential accumulation: multiplying denominators and cross-multiplying numerators never requires integers exceeding that polynomial bit-length bound. Optional reduction to lowest terms uses the polynomial-time Euclidean algorithm.

The algorithm consequently performs \(O(\tau)\) rational operations on integers of polynomially bounded bit length. Standard exact integer arithmetic gives running time \(O(\tau\,\operatorname{poly}(L))\). The output consists of \(\tau\) profiles, at most three nonzero profile masses, and two rational cohort quantities, all of polynomial total length.

Because collaborations interact only internally, classifying one type requires no equilibrium calculation involving other types. The explicit support is scanned once; no enumeration of unsupported types or joint societal profiles is required.

This establishes polynomial-time exact computation for the stipulated \(m=2\) problem.
