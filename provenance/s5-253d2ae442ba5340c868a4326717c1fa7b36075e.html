The continuous mirror question, as graded

Given a finite transaction set \(X\), an ordered subset \(H=(h_1,\ldots,h_k)\), and a rational distribution \(\mu\) over strict rankings of \(X\), where every supported ranking puts \(h_i\) before \(h_j\) whenever \(i<j\), form the weighted pairwise graph using \(w_\mu(x,y)=\sum_{t:\,x\prec_t y}\mu_t\) and apply the paper’s ranked-pairs procedure with fixed tie-breaking. Compute its output ordering \(\sigma\): does \(\sigma\) preserve the order of \(H\)?

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a labeled transaction set, \(m=|X|\), and \(H=(h_1,\ldots,h_k)\) a sequence of distinct members of \(X\), with \(2\leq k\leq m\).
A society is given by its support: a list of \(\tau\) strict rankings of \(X\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
Every supported ranking satisfies \(h_i\prec_t h_j\) whenever \(i<j\). Define \(w_\mu(x,y)=\sum_{t:x\prec_t y}\mu_t\) and \(E=\{(x,y):x\neq y,\ w_\mu(x,y)>1/2\}\). Promise that \((X,E)\) is strongly connected, representing one batch.
Process the edges of \(E\) in decreasing weight, breaking equal weights lexicographically by their endpoint labels. Starting with an empty graph, lock each edge unless adding it creates a directed cycle; discard each processed edge from consideration.
The output \(\sigma\) is a topological ordering of the locked graph, choosing the smallest labeled available vertex at each step. Preservation means \(h_i\prec_\sigma h_j\) for every \(i<j\).

Can \(\sigma\) and the decision whether it preserves \(H\) be computed in polynomial time in \(m,\tau,L,k\), or is this computational task NP-hard?

For finite electorates, ranked-pairs batch ordering preserves a unanimously reported order of honest transactions within a batch. [Vafadar and Khabbazian](https://d-nb.info/1367162424/34)
Fixed-tie ranked-pairs winner determination using majority-margin weights is polynomial-time computable; this is a neighboring discrete formulation. [IJCAI 2024](https://www.ijcai.org/proceedings/2024/0326.pdf)
No result specifically addressing this rational-support formulation was identified in the sources checked.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one and retained only positive-mass supported rankings.
  • Settled the unspecified edge set as strict-majority edges; pairwise ties contribute no edge.
  • Restored the batch-ordering domain by requiring the majority graph to be strongly connected.
  • Made fixed edge tie-breaking lexicographic in transaction labels and specified the same label priority for topological-order choices.
  • Interpreted violation of previously established orders as creation of a directed cycle in the locked graph.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The task is polynomial-time solvable. Moreover, under the stated unanimity hypothesis, the output always preserves \(H\). The argument below computes the specified \(\sigma\) exactly and proves preservation directly for rational support.

  • Exact computation of the weights. Write each mass as \(\mu_t=a_t/b_t\), where the positive integers \(a_t,b_t\) are encoded in binary. Define

\[ D=\prod_{t=1}^{\tau}b_t, \qquad A_t=a_t(D/b_t). \]
Thus \(\mu_t=A_t/D\). Normalization gives \(\sum_t A_t=D\).

The bit length of \(D\) is at most \(1+\sum_t\log_2 b_t\), hence is \(O(L)\). Because \(0<A_t\leq D\), each \(A_t\) also has \(O(L)\) bits. These integers can therefore be computed in polynomial time using integer multiplication and exact division.

For each supported ranking, record the position of every transaction. Then, for every ordered pair of distinct transactions, compute
\[ S(x,y)=\sum_{t:x\prec_t y}A_t. \]
Every partial sum lies between \(0\) and \(D\), so these computations use only \(O(L)\)-bit integers. There are \(O(\tau m^2)\) summand inspections.

Since \(w_\mu(x,y)=S(x,y)/D\), membership in \(E\) is determined exactly by the integer comparison \(2S(x,y)>D\). Likewise, comparing two edge weights is equivalent to comparing their numerators \(S(x,y)\), because their denominators coincide. Sorting the at most \(m(m-1)\) edges by decreasing numerator, with the stipulated lexicographic tie-breaking, therefore takes polynomial time.

  • Exact simulation of locking and the output ordering. Maintain the current locked graph \(G\), initially empty. When processing \((x,y)\), search \(G\) for a directed path from \(y\) to \(x\). Lock the edge precisely when no such path exists.

To justify this test, assume \(G\) is acyclic. If a path from \(y\) to \(x\) exists, adding \((x,y)\) completes a directed cycle. Conversely, any cycle created by adding \((x,y)\) must contain that new edge, because \(G\) previously had no cycle. Removing the new edge from this cycle leaves a directed path from \(y\) to \(x\) in \(G\).

Thus the test implements exactly the specified locking rule and maintains acyclicity by induction. Each reachability search takes \(O(m^2)\) graph operations, and there are \(O(m^2)\) processed edges, giving \(O(m^4)\) graph operations overall. Each processed edge is permanently removed from consideration, as required.

Finally, repeatedly select the smallest labeled vertex of indegree zero, output it, and delete it together with its outgoing edges. Every nonempty finite acyclic graph has such a vertex: otherwise, repeatedly following an incoming edge would eventually repeat a vertex and produce a directed cycle. This procedure therefore terminates and computes exactly the stipulated \(\sigma\). Maintaining indegrees and scanning the remaining vertices takes \(O(m^2)\) operations.

For an explicit conservative bit bound, let \(B=L+\lceil\log_2(m+\tau+k+2)\rceil\). Elementary integer arithmetic, label comparisons, and graph bookkeeping give a total bound of
\[ O\!\left((\tau m^2+m^2\log m+m^4+k)B^2\right). \]
This is polynomial in all the requested parameters. It does not expand the support into an electorate whose size could be exponentially large.

  • Every unanimous edge is locked. Define the set of unanimous edges by

\[ U=\{(x,y):x\ne y,\ w_\mu(x,y)=1\}. \]
Because every supported ranking has positive mass and the masses sum to \(1\), an edge belongs to \(U\) if and only if every supported ranking places its first endpoint before its second. Indeed, a supported ranking with the reverse order would contribute positive mass missing from \(w_\mu(x,y)\), making that weight strictly less than \(1\).

The graph \((X,U)\) is acyclic. To see this, choose any supported ranking, which exists because the masses sum to \(1\). Every edge of \(U\) points forward in that strict ranking. A directed cycle would force a transaction to precede itself by transitivity, contradicting strictness.

Every edge weight is at most \(1\). Consequently, the algorithm processes all edges of \(U\) before any edge outside \(U\). During this initial phase, adding the next unanimous edge produces a subgraph of \((X,U)\), which is acyclic. Hence every unanimous edge is accepted, regardless of how ties among them are broken.

  • Preservation and the complexity conclusion. The hypothesis on \(H\) implies \(w_\mu(h_i,h_j)=1\) for every \(i<j\). By the preceding step, every edge \((h_i,h_j)\) is locked. Later processing only adds edges; it never removes locked edges. Therefore the final locked graph contains all these edges.

Every topological ordering of that graph, including the specified \(\sigma\), must satisfy \(h_i\prec_\sigma h_j\) for every \(i<j\). Thus preservation always holds on promised inputs. Alternatively, after computing \(\sigma\), it can be checked in \(O(k)\) position comparisons by verifying that the positions of successive members of \(H\) strictly increase.

The strong-connectivity promise is compatible with this proof but is unnecessary for either conclusion. The unanimity argument extends Proposition 4 of [Vafadar and Khabbazian](https://d-nb.info/1367162424/34) directly to positive rational masses. The algorithm also agrees with the fixed-tie tractability discussed in the [IJCAI 2024 paper](https://www.ijcai.org/proceedings/2024/0326.pdf); the explicit bit bound above establishes it for the present support representation.
