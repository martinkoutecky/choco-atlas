The continuous mirror question, as graded

Given finite supported agent types \(I\) with rational masses \(\alpha_i>0\), room types \(J\) with rational supplies \(\beta_j>0\), and rational valuations \(v_{ij}\), rent bounds \(\ell_j,u_j\), and per-capita total rent \(\rho\), where \(\sum_i\alpha_i=\sum_j\beta_j=1\), decide whether there are prices \(p_j\) and assignments of mass \(x_{ij}\geq 0\) such that \(\sum_jx_{ij}=\alpha_i\), \(\sum_ix_{ij}=\beta_j\), \(\ell_j\leq p_j\leq u_j\), and \(\sum_j\beta_jp_j=\rho\), with \(v_{ij}-p_j=\max_{k\in J}(v_{ik}-p_k)\) whenever \(x_{ij}>0\). Return a feasible mass assignment and prices, or correctly report infeasibility.

Room types \(J\) have positive binary-rational supplies \(\beta_j\); let \(m=|J|\), with \(\sum_i\alpha_i=\sum_j\beta_j=1\).
The remaining input consists of binary-rational valuations \(v_{ij}\geq0\), finite rent bounds \(\ell_j\leq u_j\) of either sign, and per-capita total rent \(\rho\in\mathbb{Q}\). Let \(L\) be the total input bit length.
A feasible allocation consists of prices \(p_j\in\mathbb{R}\) and divisible assignments \(x_{ij}\in\mathbb{R}_{\geq0}\) satisfying \(\sum_jx_{ij}=\alpha_i\), \(\sum_ix_{ij}=\beta_j\), \(\ell_j\leq p_j\leq u_j\), and \(\sum_j\beta_jp_j=\rho\).

Result

Feasibility is in \(\mathrm{P}\). An exact rational linear program computes feasible assignments and prices, or correctly reports infeasibility, in time polynomial in \(m,\tau,L\).

The key is that envy-freeness can be imposed by linear inequalities together with one linear equality.

1. Linear-programming formulation

Introduce assignment variables \(x_{ij}\), price variables \(p_j\), and utility variables \(z_i\). The variables \(p_j,z_i\) are unrestricted in sign.

Consider the following rational linear feasibility system:

\(\displaystyle x_{ij}\geq 0 \qquad(i\in I,\ j\in J),\)

\(\displaystyle \sum_{j\in J}x_{ij}=\alpha_i \qquad(i\in I),\)

\(\displaystyle \sum_{i\in I}x_{ij}=\beta_j \qquad(j\in J),\)

\(\displaystyle \ell_j\leq p_j\leq u_j \qquad(j\in J),\)

\(\displaystyle \sum_{j\in J}\beta_jp_j=\rho,\)

\(\displaystyle z_i+p_j\geq v_{ij} \qquad(i\in I,\ j\in J),\)

and

\[\displaystyle \sum_{i\in I}\sum_{j\in J}v_{ij}x_{ij} =\sum_{i\in I}\alpha_i z_i+\rho. \tag{1}\]

Every displayed constraint is linear: masses, supplies, valuations, bounds, and total rent are input constants.

We prove that this system is feasible exactly when the original problem is feasible.

2. Every envy-free allocation satisfies the system

Suppose \((x,p)\) is a feasible envy-free allocation. Define

\(\displaystyle z_i=\max_{k\in J}(v_{ik}-p_k).\)

These maxima exist because \(J\) is finite and nonempty. By definition, \(z_i+p_j\geq v_{ij}\) for every pair.

If \(x_{ij}>0\), envy-freeness gives \(v_{ij}-p_j=z_i\). Consequently, for every pair, including those with zero assignment,

\(\displaystyle v_{ij}x_{ij}=(z_i+p_j)x_{ij}.\)

Summing and using the prescribed marginals and total rent yields

\(\displaystyle \begin{aligned} \sum_{i,j}v_{ij}x_{ij} &=\sum_{i,j}(z_i+p_j)x_{ij}\\ &=\sum_i z_i\sum_jx_{ij} +\sum_jp_j\sum_ix_{ij}\\ &=\sum_i\alpha_i z_i+\sum_j\beta_jp_j\\ &=\sum_i\alpha_i z_i+\rho. \end{aligned} \)

Thus equation \((1)\) holds. All remaining constraints are original feasibility requirements.

3. Every solution of the system is envy-free

Conversely, suppose \((x,p,z)\) satisfies the linear system. Define the slack

\(\displaystyle s_{ij}=z_i+p_j-v_{ij}.\)

The utility inequalities imply \(s_{ij}\geq0\). Using the marginal equations, total-rent equation, and equation \((1)\), we obtain

\(\displaystyle \begin{aligned} \sum_{i,j}x_{ij}s_{ij} &=\sum_{i,j}x_{ij}(z_i+p_j-v_{ij})\\ &=\sum_i\alpha_i z_i+\sum_j\beta_jp_j -\sum_{i,j}v_{ij}x_{ij}\\ &=\sum_i\alpha_i z_i+\rho-\sum_{i,j}v_{ij}x_{ij}\\ &=0. \end{aligned} \)

Each summand is nonnegative. Therefore every summand is zero. In particular,

\(\displaystyle x_{ij}>0\quad\Longrightarrow\quad z_i+p_j=v_{ij}.\)

For any such pair and every \(k\in J\), the utility inequality for \((i,k)\) gives

\(\displaystyle v_{ij}-p_j=z_i\geq v_{ik}-p_k.\)

This is precisely the required envy-freeness condition. The other constraints already ensure feasibility of assignments and prices.

Hence the linear formulation is exact.

4. Polynomial running time and exact output

The system has \(\tau m+m+\tau\) variables and \(\mathrm{O}(\tau m+m+\tau)\) constraints. Every coefficient is an input rational, its negation, or one of the constants zero and one. Thus the system has encoding length polynomial in \(m,\tau,L\).

Apply the standard polynomial-time theorem for rational linear programming: a rational system of linear equalities and weak inequalities can be tested for feasibility, and a rational feasible point produced when one exists, in time polynomial in its dimensions and binary encoding length. All hypotheses hold here.

For completeness, the formulation also has no issue with unbounded utility variables. At any feasible point, positivity of \(\alpha_i\) guarantees some \(j\) with \(x_{ij}>0\). Section 3 then implies

\(\displaystyle z_i=\max_{j\in J}(v_{ij}-p_j).\)

Consequently,

\(\displaystyle \max_{j\in J}(v_{ij}-u_j) \leq z_i\leq \max_{j\in J}(v_{ij}-\ell_j). \)

Assignments satisfy \(0\leq x_{ij}\leq\alpha_i\), and prices have their finite input bounds. The feasible set is therefore a bounded rational polyhedron. If nonempty, it has a rational vertex whose coordinate encoding lengths are polynomially bounded by the standard determinant bounds for rational linear systems. Exact rational output is therefore sufficient even though the problem permits real solutions.

The algorithm solves the stated system. If it is infeasible, Section 2 proves that the original problem is infeasible. Otherwise, it returns the \(x,p\) coordinates, whose validity follows from Section 3.

The slack argument is the transportation analogue of the welfare characterization for discrete rent division discussed in [Gangam, Taherijam, and Vazirani, Section 3.2](https://arxiv.org/html/2510.05434v1#S3.SS2). Here it applies directly to the supported masses; no expansion into individual agents or denominator-sized population is needed.
