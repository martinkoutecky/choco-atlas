The continuous mirror question, as graded

Given a finite set of claim types \(Q\), rational masses \(\mu_q>0\) with \(\sum_{q\in Q}\mu_q=1\), rational claims \(q\), a per-capita estate \(e\in[0,\bar c]\), and \(\theta\in[0,1]\), where \(\bar c=\sum_{q\in Q}\mu_q q\), compute the TAL award \(a_q\) for each type such that \(\sum_{q\in Q}\mu_q a_q=e\). Use \(a_q=\min\{\theta q,\lambda\}\) when \(e\le\theta\bar c\), and \(a_q=\max\{\theta q,q-\ell\}\) when \(e\ge\theta\bar c\), choosing the threshold to satisfy balance.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a finite list \(Q\) of \(\tau\) distinct nonnegative rational claim types, each with positive binary-rational mass \(\mu_q\), with \(\sum_{q\in Q}\mu_q=1\). Here \(\tau\) is the support size, not the number of possible types.
Input also includes binary rationals \(\theta\in[0,1]\) and \(e\in[0,\bar c]\), where \(\bar c=\sum_{q\in Q}\mu_q q>0\). Awards are per capita within each type.
The TAL awards satisfy \(a_q=\min\{\theta q,\lambda\}\) if \(e\leq\theta\bar c\), and \(a_q=\max\{\theta q,q-\ell\}\) if \(e\geq\theta\bar c\), with a common threshold \(\lambda\geq0\) or \(\ell\geq0\) chosen so that \(\sum_{q\in Q}\mu_q a_q=e\). At \(e=\theta\bar c\), set \(a_q=\theta q\); thresholds need not be unique.
An allocation must satisfy \(0\leq a_q\leq q\) and, whenever \(q\leq r\), both \(a_q\leq a_r\) and \(q-a_q\leq r-a_r\). The computational problem is to output all TAL awards exactly as binary rationals.
Measure running time in \(\tau\) and the total input bit length \(L\), including \(\theta\) and \(e\); there is no separate candidate or item parameter \(m\).

Is exact computation of these mass-based TAL awards solvable in time polynomial in \(\tau\) and \(L\), or is it NP-hard?

For finite lists of creditors, a recursive coalitional procedure yields exactly the TAL allocation for every \(\theta\in[0,1]\); this is a characterization, not a complexity classification. [Moreno-Ternero](https://theeconomics.uma.es/malagawpseries/Papers/METCwp2010-11.pdf)
No result settling the exact rational-support mass problem was located in the literature search.

Conclusion and encoding convention

Exact computation is polynomial-time solvable in \(\tau\) and \(L\), using binary-encoded numerator–denominator pairs for rational output.

If “binary rational” requires a terminating binary expansion, exact outputs need not exist even for dyadic inputs; an example appears below. I therefore use the intended exact-rational interpretation.

The proof follows directly from the given threshold formulas. It does not require implementing the coalitional characterization in [Moreno-Ternero’s paper](https://theeconomics.uma.es/malagawpseries/Papers/METCwp2010-11.pdf).

1. An exact weighted threshold algorithm

Consider nonnegative rational caps \(b_1\leq\cdots\leq b_\tau\), positive rational masses \(\mu_1,\ldots,\mu_\tau\) summing to \(1\), and a rational target \(T\) satisfying
\[ 0\leq T\leq M:=\sum_{i=1}^{\tau}\mu_i b_i. \]
We first solve
\[ F(x):=\sum_{i=1}^{\tau}\mu_i\min\{b_i,x\}=T, \qquad x\geq0. \]

Set \(b_0=0\). For \(0\leq k\leq\tau\), define
\[ A_k:=\sum_{i=1}^{k}\mu_i b_i, \qquad B_k:=\sum_{i=k+1}^{\tau}\mu_i, \qquad H_k:=A_k+B_kb_k. \]
Empty sums are zero. In particular, \(H_0=0\) and \(H_\tau=M\).

For \(0\leq k<\tau\),
\[ H_{k+1}-H_k =B_k(b_{k+1}-b_k)\geq0. \]
Indeed, \(A_{k+1}=A_k+\mu_{k+1}b_{k+1}\) and \(B_{k+1}=B_k-\mu_{k+1}\), so
\[ H_{k+1}=A_k+B_kb_{k+1}. \]

Thus the intervals \([H_k,H_{k+1}]\) cover \([0,M]\). A linear scan finds an index \(k<\tau\) with
\[ H_k\leq T\leq H_{k+1}. \]
Since the masses are positive, \(B_k>0\). Define
\[ x:=\frac{T-A_k}{B_k}. \]
The interval inequalities imply
\[ b_k\leq x\leq b_{k+1}. \]
Consequently, for \(i\leq k\), \(\min\{b_i,x\}=b_i\); for \(i>k\), \(\min\{b_i,x\}=x\). Therefore
\[ F(x)=A_k+B_kx=T. \]

This proves an exact algorithm: compute the prefix sums, locate an interval, and perform one rational division. It also covers zero caps, repeated caps, and both endpoint targets.

Although thresholds can be nonunique, the resulting capped vector is unique. If \(x\leq y\) and \(F(x)=F(y)\), then
\[ 0=\sum_{i=1}^{\tau}\mu_i \bigl(\min\{b_i,y\}-\min\{b_i,x\}\bigr). \]
Every summand is nonnegative. Positivity of every \(\mu_i\) forces every component difference to vanish.

2. Applying the algorithm to TAL

Sort the support as \(q_1<\cdots<q_\tau\), carrying the corresponding masses along. Compute
\[ \bar c=\sum_{i=1}^{\tau}\mu_iq_i \]
and compare \(e\) with \(\theta\bar c\) exactly.

Case \(e=\theta\bar c\)

Output
\[ a_i=\theta q_i, \]
as prescribed.

Case \(e<\theta\bar c\)

Apply the weighted threshold algorithm with
\[ b_i=\theta q_i, \qquad T=e. \]
These caps are nonnegative and sorted, and
\[ 0\leq T<\sum_i\mu_i b_i=\theta\bar c. \]
The algorithm produces \(\lambda\geq0\) satisfying the required budget. Output
\[ a_i=\min\{\theta q_i,\lambda\}. \]

Case \(e>\theta\bar c\)

Write \(d_i=q_i-a_i\) for the loss. The given upper-branch formula is equivalent to
\[ d_i =q_i-\max\{\theta q_i,q_i-\ell\} =\min\{(1-\theta)q_i,\ell\}. \]
Apply the weighted threshold algorithm with
\[ b_i=(1-\theta)q_i, \qquad T=\bar c-e. \]
Its hypotheses hold because
\[ 0\leq\bar c-e<(1-\theta)\bar c =\sum_i\mu_i b_i. \]
It produces \(\ell\geq0\) and losses with total mass-weighted loss \(\bar c-e\). Output
\[ a_i=q_i-d_i=\max\{\theta q_i,q_i-\ell\}. \]
Their total award is exactly
\[ \sum_i\mu_i a_i =\bar c-\sum_i\mu_i d_i=e. \]

Thus every branch computes precisely the specified TAL awards.

3. Verification of the allocation constraints

For the lower branch, \(0\leq\theta\leq1\) and \(\lambda\geq0\) give
\[ 0\leq a_q=\min\{\theta q,\lambda\}\leq q. \]
The award is nondecreasing in \(q\). Its loss can be written as
\[ q-a_q=\max\{(1-\theta)q,q-\lambda\}, \]
which is also nondecreasing: both functions inside the maximum are nondecreasing.

For the upper branch,
\[ a_q=\max\{\theta q,q-\ell\} \]
is nondecreasing and lies in \([0,q]\). Its loss
\[ q-a_q=\min\{(1-\theta)q,\ell\} \]
is nondecreasing.

At equality, awards and losses are respectively \(\theta q\) and \((1-\theta)q\), so the same constraints hold. Hence the computed awards satisfy all required allocation conditions.

4. Polynomial bit complexity

Counting arithmetic operations alone is insufficient; we must also bound their operand sizes.

Let \(D\) be the product of the positive denominators of all input rationals. Because their binary encodings contribute to \(L\),
\[ \log_2D=O(L). \]
Using this common denominator, write
\[ q_i=\frac{c_i}{D}, \qquad \mu_i=\frac{m_i}{D}, \qquad \theta=\frac{h}{D}, \qquad e=\frac{z}{D}. \]
All these integer numerators have \(O(L)\) bits. Moreover,
\[ \sum_i m_i=D, \qquad 0\leq h\leq D. \]

In either threshold branch, put \(u=h\) or \(u=D-h\), respectively. Then
\[ b_i=\frac{uc_i}{D^2}. \]
Define integer prefix and suffix sums
\[ S_k:=\sum_{i=1}^{k}m_ic_i, \qquad W_k:=\sum_{i=k+1}^{\tau}m_i. \]
Thus
\[ A_k=\frac{uS_k}{D^3}, \qquad B_k=\frac{W_k}{D}. \]

The target has the form \(T=v/D^3\), where
\[ v= \begin{cases} zD^2,&\text{lower branch},\\ DS_\tau-zD^2,&\text{upper branch}. \end{cases} \]
Accordingly, the selected threshold is
\[ x=\frac{v-uS_k}{D^2W_k}. \]

Every integer in these expressions has \(O(L+\log\tau)\) bits: products contain only a bounded number of input-sized factors, and sums contain at most \(\tau\) terms. Breakpoint comparisons can likewise be performed by integer comparisons:
\[ uS_k+uW_kc_k \leq v \leq uS_k+uW_kc_{k+1}. \]

For the selected index, \(1\leq W_k\leq D\). Each capped award or loss can therefore be represented with denominator \(D^2W_k\leq D^3\). Subtracting a loss from \(q_i\) preserves this denominator bound. Thus every output rational has polynomial bit length; reduction to lowest terms uses a polynomial-time greatest-common-divisor computation.

Sorting takes \(O(\tau\log(\tau+1))\) rational comparisons. Prefix sums, the interval scan, and output construction take \(O(\tau)\) additional arithmetic operations. All operate on integers of polynomial bit length. The total running time is therefore
\[ O\!\left(\tau\log(\tau+1)\, \operatorname{poly}(L+\log\tau)\right). \]
No expansion of a mass into individual creditors, and no additional item parameter, is needed.

5. If output is required to be dyadic

Consider the entirely dyadic input
\[ Q=\{1,2\},\qquad \mu_1=\frac14,\qquad \mu_2=\frac34,\qquad \theta=1,\qquad e=\frac54. \]
Here \(\bar c=7/4\). The lower-branch awards are
\[ a_1=1,\qquad a_2=\frac43, \]
because
\[ \frac14\cdot1+\frac34\cdot\frac43=\frac54, \]
and these awards correspond to \(\lambda=4/3\). Uniqueness follows from Section 1.

Since \(4/3\) has no terminating binary expansion, dyadic-only output is impossible on this input. Binary-encoded rational pairs provide the exact polynomial-time solution proved above.
