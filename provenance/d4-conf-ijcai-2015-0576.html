The continuous mirror question, as graded

Given a finite candidate set \(C\), candidate preference orders, a priority order, and a finite support of voter rankings with binary-rational masses summing to \(1\), decide whether there is an active set \(A\subseteq C\) that is a pure Nash equilibrium under plurality by mass, the paper’s tie-breaking rule, and its laziness preference; in the winner-constrained variant, also require a specified candidate to win. For the dynamics variants, decide whether a legal sequence of joins from the empty set or withdrawals from \(C\) terminates at a specified active set or with a specified winner.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set, \(m=|C|\), with a strict preference order \(\succ_c\) over \(C\) for each candidate and a strict priority order \(\lhd\). Candidate preferences need not rank themselves first.
A society is given by its support: \(\tau\) distinct strict voter rankings over \(C\), each with positive binary-rational mass, summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
For nonempty \(A\subseteq C\), voters vote sincerely under plurality by mass, restricted to \(A\); score ties favor the earliest candidate in \(\lhd\). Define \(w(\emptyset)\) as the earliest candidate in \(\lhd\).
Candidate \(c\) strictly prefers state \(B\) to state \(A\) exactly when \(w(B)\succ_c w(A)\), or when \(w(B)=w(A)\) and \(c\in A\setminus B\). Each candidate chooses participation or abstention; a pure Nash equilibrium permits no profitable unilateral toggle.
The equilibrium problems ask whether some equilibrium exists, or whether one exists with specified winner \(p\in C\).
Join dynamics start at \(\emptyset\) and permit only profitable single-candidate joins; withdrawal dynamics start at \(C\) and permit only profitable single-candidate withdrawals. Moves cannot be reversed, and termination means no permitted profitable move remains. Each dynamics variant asks whether some terminal sequence ends at specified \(A_*\subseteq C\), or with specified winner \(p\).

For each of these six decision problems over rational-mass societies, is it in \(\mathrm{P}\) or \(\mathrm{NP}\)-hard?

For finite voter lists, equilibrium existence and specified-winner equilibrium existence are \(\mathrm{NP}\)-complete even when every candidate ranks herself first; the four terminal-dynamics problems are also stated to be \(\mathrm{NP}\)-complete in [Obraztsova et al. (2015)](https://www.ijcai.org/Proceedings/15/Papers/092.pdf).
The [later journal treatment](https://link.springer.com/article/10.1007/s11238-025-10113-4) retains equilibrium hardness and proves specified-winner withdrawal hardness, but omits the other three dynamics hardness claims. No result explicitly treating these rational-mass input problems was located.

Modeling choices made when packaging the task

  • Required a nonempty candidate set so the designated empty-election winner exists.
  • Made all voter rankings, candidate preferences, and the priority order strict; retained unrestricted candidate preferences rather than imposing self-support.
  • Defined the empty-election winner as the first candidate in the priority order.
  • Specified laziness lexicographically: a better winner takes precedence, while unchanged winners favor abstention.
  • Specified legal dynamics as profitable unilateral moves in the permitted direction, with no reversal and termination only when no such move remains.
  • Defined L as total input bit length and made specified winners members of C and specified terminal sets subsets of C.
  • Imposed no analogue of odd voter count: it is a simplifying assumption for discrete dynamics properties, whose stated scope extends to the general case.

1. Exact winner computation is polynomial

Write the supported rankings as \(\rho_1,\ldots,\rho_\tau\), with masses \(\mu_i=a_i/b_i\), where positive integer numerators and denominators are encoded in binary.

Define

\(\displaystyle D=\prod_{i=1}^{\tau}b_i,\qquad \alpha_i=a_i(D/b_i).\)

Then every \(\alpha_i\) is a positive integer and \(\sum_i\alpha_i=D\). The binary length of \(D\) is at most the sum of the denominator lengths, hence is \(O(L)\). Each \(\alpha_i\), and every score sum, also has \(O(L)\) bits.

For nonempty \(A\), scan each ranking to find its first member of \(A\), and give that candidate integer weight \(\alpha_i\). These integer scores are precisely the mass scores multiplied by \(D\), so score comparisons and ties are preserved exactly. Apply \(\lhd\) to tied maximum scores. For \(A=\emptyset\), return the earliest candidate in \(\lhd\).

Using ordinary integer arithmetic, a conservative bit-operation bound, including preprocessing, is

\(\displaystyle Q(m,\tau,L)=O\!\left((\tau+1)L^2+(\tau m+\tau+m)L\right).\)

Thus winner computation is polynomial in \(m,\tau,L\). No expansion into individual voters is required.

2. All six problems belong to \(\mathrm{NP}\)

For \(c\notin A\), joining is profitable exactly when

\(\displaystyle w(A\cup\{c\})\succ_c w(A).\)

There is no equal-winner improvement from joining, because the secondary preference favors abstention.

For \(c\in A\), withdrawing is profitable exactly when

\(\displaystyle w(A\setminus\{c\})\succ_c w(A)\quad\text{or}\quad w(A\setminus\{c\})=w(A).\)

These predicates can be checked using exact winner computation and the supplied candidate preference orders.

Equilibrium certificates

A certificate is a subset \(A\subseteq C\), represented by \(m\) bits. Compute its winner and check every candidate’s unilateral toggle. Reject precisely when some toggle satisfies the appropriate profitable-move predicate above.

This verifies equilibrium existence in \(O(mQ(m,\tau,L))\) time. For specified-winner equilibrium existence, additionally check \(w(A)=p\), within the same bound.

Dynamics certificates

A certificate is an ordered list of at most \(m\) distinct candidates.

For join dynamics, start at \(\emptyset\) and add the listed candidates in order. For withdrawal dynamics, start at \(C\) and remove them in order. Check that every move is permitted and profitable.

At the final state \(A\), check:

  • the requested endpoint condition, namely \(A=A_*\) or \(w(A)=p\);
  • absence of every remaining permitted profitable move.

For joins, the terminality check concerns candidates outside \(A\). For withdrawals, it concerns candidates inside \(A\). It does not require the endpoint to be a Nash equilibrium.

There are at most \(m\) moves and at most \(m\) terminality checks. Each certificate therefore has polynomial length and is verifiable in \(O(mQ(m,\tau,L))\) time. All four dynamics problems belong to \(\mathrm{NP}\).

3. Finite voter lists embed faithfully into rational-mass input

Let a finite-list instance have \(n\) voters. Group identical rankings. If the resulting distinct rankings have multiplicities \(k_1,\ldots,k_\tau\), assign mass

\(\displaystyle \mu_i=k_i/n.\)

These masses are positive and sum to \(1\). For every nonempty \(A\subseteq C\) and \(c\in A\),

\(\displaystyle \operatorname{score}_{\mathrm{mass}}(c,A)=\operatorname{score}_{\mathrm{list}}(c,A)/n.\)

Consequently, all score comparisons, score ties, and winners are identical in the two representations. Their empty-state winners are identical because the priority order is unchanged.

Candidate preferences and participation states are also unchanged. Therefore, for every unilateral toggle, profitability is identical. It follows that the mapping preserves:

  • every equilibrium and its winner;
  • every profitable join sequence;
  • every profitable withdrawal sequence;
  • terminality and both types of endpoint conditions.

The transformation is polynomial in the explicit finite-list input length \(N\): grouping can, for example, be implemented within \(O(N^2)\) bit operations. There are at most \(n\) supported rankings, and each mass needs \(O(\log(n+1))\) bits for its numerator and denominator. The output length is therefore polynomial in \(N\).

This is a polynomial-time many-one reduction from each finite-list problem to its rational-mass counterpart.

The transfer also works if masses must be dyadic

If “binary-rational” is intended to require denominators that are powers of two, the preceding normalization can be replaced by the following construction.

Choose the smallest power of two \(T\) satisfying \(T\geq n(n+1)\), and put

\(\displaystyle K=\lfloor T/n\rfloor,\qquad R=T-Kn.\)

Then \(0\leq R<n<K\). Give each original ranking with multiplicity \(k_i\) mass \(Kk_i/T\). If \(R>0\), add mass \(R/T\) to the ranking that lists candidates in priority order. Merge this ranking with an existing identical ranking if necessary.

The total mass is \(1\), every retained mass is positive and dyadic, and the support size is at most \(n+1\).

To prove winner preservation, fix nonempty \(A\) and let \(e\) be its earliest candidate in \(\lhd\). In integer units with denominator \(T\), every original score is multiplied by \(K\), and only \(e\) receives the additional \(R\) units.

Let \(a\) be the original winner, with original maximum score \(M\).

  • If \(e=a\), the extra units reinforce \(a\)’s victory.
  • If \(e\ne a\), then \(e\)’s original score is at most \(M-1\): if it were \(M\), its priority would make it the original winner. Its new score is therefore at most \(K(M-1)+R<KM\). Every other candidate’s score is simply multiplied by \(K\), preserving their comparisons and priority ties.

Thus the winner remains \(a\) for every subset. Since \(T<2n(n+1)\), the construction still has polynomial output length and running time.

4. Applying the finite-list hardness results

The finite-list theorems concern the same lazy participation preferences, sincere restricted plurality voting, fixed priority tie-breaking, and earliest-priority empty-state winner. Their dynamics start from \(\emptyset\) or \(C\), respectively, allow only the indicated profitable moves, and prohibit reversals. These hypotheses match the present task.

The representation transformation leaves the candidate set, candidate preferences, priority order, specified winner, and specified terminal set unchanged. Section 3 proves that it also preserves the entire profitable-move relation.

Hence each finite-list hardness reduction can be composed with this transformation. All six rational-mass problems are \(\mathrm{NP}\)-hard. Together with Section 2, they are \(\mathrm{NP}\)-complete.

For the two equilibrium problems, the hardness also retains the restriction that every candidate ranks herself first: the transformation changes only the society’s representation.

5. Additional bounds in the requested parameters

All six problems have deterministic algorithms running in

\(\displaystyle O\!\left(2^m mQ(m,\tau,L)\right).\)

For equilibria, enumerate every subset and verify it. For dynamics, compute reachability in the directed subset graph whose edges are profitable permitted moves. Each edge changes cardinality by one, so processing subsets by increasing cardinality for joins, or decreasing cardinality for withdrawals, computes reachability. Check the requested condition and terminality at reachable endpoints.

The equilibrium problems additionally admit a support-size bound. In an equilibrium, every participating candidate must have positive score. Indeed, if candidate \(c\) has zero score, no supported ranking votes for \(c\); removing \(c\) leaves every voter’s chosen candidate, and hence the winner, unchanged. Laziness then makes withdrawal profitable.

Since each supported ranking contributes positive mass to exactly one participating candidate, an equilibrium has at most \(\tau\) participants. Enumerating only such subsets gives running time

\(\displaystyle O\!\left((m+1)^\tau mQ(m,\tau,L)\right).\)

This uses the actual support size \(\tau\), irrespective of the denominators or any expanded voter population.
