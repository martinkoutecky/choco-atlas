The continuous mirror question, as graded

Given a finite type set \(T\), rational population masses \(\mu_t\), rational per-capita chore supplies \(q\in\mathbb{Q}_{\ge 0}^m\), additive type costs \(c_t\), and comparison access to each \(c_t\), compute a finite-support allocation \(z_{t,b}\) over integral bundles \(b\in\mathbb{Z}_{\ge 0}^m\) satisfying \(\sum_b z_{t,b}=\mu_t\), \(\sum_{t,b}z_{t,b}b_e=q_e\) for every chore category \(e\), and, for every supported nonempty bundle, some \(e\) with \(b_e>0\) and \(c_t(b-\mathbf{1}_e)\le c_t(q)\). Determine the comparison-query complexity, especially for fixed \(|T|\) as \(m\) grows.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq1\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) chore categories with per-capita supplies \(q\in\mathbb{Q}_{\geq0}^m\). Let \(L\) be the total bit length of the explicit input, including masses and supplies.
Each type has hidden nonnegative additive costs \(c_t(x)=\sum_{e=1}^m a_{t,e}x_e\), with \(a_{t,e}\in\mathbb{R}_{\geq0}\). Costs are accessible exclusively through comparisons.
A query \(\operatorname{Comp}_t(b,d)\), for binary-encoded \(b,d\in\mathbb{Z}_{\geq0}^m\), returns \(b\) when \(c_t(b)\leq c_t(d)\), and \(d\) otherwise; each query costs one comparison.
Compute a finite list of positive binary rational masses \(z_{t,b}\) on integral bundles satisfying \(\sum_b z_{t,b}=\mu_t\) and \(\sum_{t,b}z_{t,b}b_e=q_e\) for every category \(e\).
Every supported nonempty bundle must satisfy \(c_t(b-\mathbf{1}_e)\leq c_t(q)\) for some \(e\) with \(b_e>0\), where \(\mathbf{1}_e\) is the unit vector; empty bundles are permitted.

Is this allocation problem polynomial-time solvable with comparison access, or is it NP-hard even with polynomial-time comparison oracles? What is its optimal deterministic comparison-query complexity, particularly for fixed \(\tau\) as \(m\) grows? State running times and query bounds in \(m,\tau,L\).

For finite societies with \(n\) agents and \(k\) individual chores, PROP1 allocations can be computed using \(O(n^3\log k)\) comparisons; for fixed \(n\geq2\), deterministic algorithms require \(\Omega(\log k)\) comparisons. [Source](https://arxiv.org/html/2609.08687v1)
No result settling this precise population-mass problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total population mass to one so that the supplied per-capita vector q is also aggregate supply and c_t(q) is the proportional benchmark.
  • Specified hidden costs as nonnegative real additive coefficients, retaining the discrete cost domain and exclusive comparison access.
  • Extended bundle comparisons to arbitrary nonnegative integral count vectors, with binary encoding and ties favoring the first argument; fractional vectors such as q are not query arguments.
  • Specified an explicit finite-support output with binary rational allocation masses and allowed empty bundles.
  • Defined L using the explicit input, since hidden real costs have no supplied numerical encoding; comparison calls have unit oracle cost.
  • Used deterministic algorithms for query complexity and polynomial-time comparison oracles for the NP-hardness alternative.

Proven progress and remaining gap

The allocation problem is polynomial-time solvable with comparison access.

A sharper query bound than the one in the notes can be proved. Define the total fractional supply by
$$ R=\sum_{e=1}^m\bigl(q_e-\lfloor q_e\rfloor\bigr). $$
There is a deterministic algorithm using
$$ O\!\left(\tau m\log(\lceil R\rceil+1)\right) $$
comparisons, with bit running time
$$ O(\tau m^2L^2) $$
when oracle calls cost one operation. It outputs at most $\tau(m+1)$ supported type–bundle pairs. If $R\leq1$, no comparisons are necessary.

This determines the optimal worst-case comparison complexity on a substantial class: for fixed $\tau$ and any fixed constant $C>1$, instances with $R\leq C$ have deterministic worst-case complexity $\Theta(m)$.

For unrestricted supplies and fixed $\tau$, the bounds remain
$$ \Omega(m) \quad\text{and}\quad O(m\log(m+1)). $$
Thus the general optimal comparison complexity is still unresolved.

1. A rounding lemma using partially ordered blocks

Fix one type, with nonnegative coefficients $a_e$, and suppress its type index. Write
$$ q_e=f_e+r_e,\qquad f_e=\lfloor q_e\rfloor,\qquad 0\leq r_e<1. $$
Let
$$ I=\{e:r_e>0\},\qquad s=|I|,\qquad R=\sum_e r_e. $$

If $R=0$, the single bundle $f=q$ suffices. Assume henceforth that $R>0$, and put
$$ N=\lceil R\rceil. $$

1.1 Constructing the blocks

For the moment, conceptually order the categories in $I$ by nonincreasing cost:
$$ a_{\pi_1}\geq a_{\pi_2}\geq\cdots\geq a_{\pi_s}. $$
Resolve equal costs by a fixed order of category labels. Define
$$ S_0=0,\qquad S_i=\sum_{\ell=1}^i r_{\pi_\ell}. $$

For every block $j\in\{1,\ldots,N\}$, define
$$ w_{j,\pi_i} = \operatorname{length}\!\left( [S_{i-1},S_i]\cap[j-1,j] \right), $$
and set other entries to zero.

These weights have the following properties:
$$ \sum_j w_{j,e}=r_e, $$
$$ \sum_e w_{j,e}=1 \quad\text{for }j<N, $$
and
$$ \sum_e w_{N,e}=R-N+1\in(0,1]. $$

Moreover, adjacent blocks are ordered by cost: if $w_{j,e}>0$ and $w_{j+1,d}>0$, then
$$ a_e\geq a_d. $$
Indeed, their positive-length segments occur in that order in the conceptually sorted sequence. A category spanning the boundary has the same coefficient on both sides.

The algorithm will compute these block memberships without sorting within the blocks. Section 2 proves the required query bound.

1.2 A finite rational distribution

Within each block $j$, place consecutive, disjoint intervals of lengths $w_{j,e}$ in $[0,1)$, in any fixed order.

For a full block, these intervals cover $[0,1)$. If the final block has total weight less than one, leave its remaining interval unassigned.

Given $u\in[0,1)$, each block selects the category whose interval contains $u$, or selects nothing if $u$ belongs to its unassigned interval. Let $y_e(u)$ count how many blocks select category $e$. Define
$$ b(u)=f+y(u). $$

Partition $[0,1)$ at every interval endpoint. On each positive-length resulting interval, $b(u)$ is constant. Choose its rational midpoint and assign that bundle probability equal to the interval length. Merge duplicate bundles if desired.

All probabilities are positive binary rationals, and the distribution is finite.

For each category,
$$ \mathbb E[y_e]=\sum_j w_{j,e}=r_e. $$
Consequently,
$$ \mathbb E[b]=f+r=q. $$

A category can span at most two blocks because $r_e<1$. Thus $y_e$ can equal two; this is permitted by the problem.

1.3 Every supported bundle satisfies PROP1

Define the fractional cost in block $j$ by
$$ A_j=\sum_e w_{j,e}a_e. $$
Then
$$ \sum_{j=1}^N A_j=\sum_e r_ea_e=c(r). $$

If $N=1$, the rounded vector $y$ is either empty or a singleton. Removing its selected chore, when present, leaves $f$, whose cost satisfies
$$ c(f)\leq c(q). $$
If $y$ is empty, any nonempty $f$ also satisfies the required condition after removing any chore.

Suppose now that $N\geq2$. The first block is full, so it selects some category $e_1$.

For each $j\geq2$, let $C_j$ be the cost of the category selected by block $j$, or zero if it selects nothing. Every coefficient in block $j-1$ is at least $C_j$. Since block $j-1$ has total weight one,
$$ C_j\leq A_{j-1}. $$
This also holds for an unassigned final-block outcome because costs are nonnegative.

Removing one occurrence of $e_1$ therefore gives
$$ c(y-\mathbf 1_{e_1}) = \sum_{j=2}^N C_j \leq \sum_{j=1}^{N-1}A_j \leq c(r). $$
Since $b_{e_1}>0$,
$$ c(b-\mathbf 1_{e_1}) = c(f)+c(y-\mathbf 1_{e_1}) \leq c(f)+c(r) = c(q). $$

This proves PROP1 for every supported bundle, including when a category is selected by two blocks.

1.4 Support size

Let $P$ be the number of positive block–category pieces. There are $s$ original segments and $N-1$ internal block boundaries. Each boundary splits at most one segment, so
$$ P\leq s+N-1. $$

If $R$ is integral, all $N$ blocks are full. A full block with $p_j$ positive pieces contributes at most $p_j-1$ interior endpoints. Thus the union has at most
$$ P-N\leq s-1 $$
interior endpoints, giving at most $s$ supported bundles.

If $R$ is not integral, the partial final block contributes at most $p_N$ interior endpoints, including the endpoint preceding its unassigned interval. The total is at most
$$ P-(N-1)\leq s, $$
giving at most $s+1$ supported bundles.

In every case, the support size is at most $m+1$.

2. Computing the blocks with fewer comparisons

Only the categories intersecting the integer cuts
$$ 1,2,\ldots,N-1 $$
and the categories’ memberships between those cuts need to be determined.

2.1 Linear-query weighted selection

Given positive rational weights on categories and a target cumulative weight, weighted selection finds the category whose interval contains the target in the cost-sorted order. It also partitions the other categories into those preceding and following it.

This requires $O(s)$ coefficient comparisons.

To justify that bound, use median-of-medians selection:

  • Divide the categories into groups of five and sort each group.
  • Recursively select a median of their medians as pivot.
  • Partition around the pivot and add the rational weights on each side.
  • Either the target lies in the pivot’s weight interval, or recurse on the appropriate side with an adjusted target.

The choice of recursive side depends on weights, but its size bound depends only on cardinality. Whichever side is retained, at least $3s/10-O(1)$ categories are discarded. The comparison recurrence is therefore
$$ T(s)\leq T(\lceil s/5\rceil)+T(7s/10+O(1))+O(s), $$
which gives $T(s)=O(s)$.

Each coefficient comparison is implementable using unit-bundle queries. At most two queries distinguish strict order from equality, after which category labels resolve ties. No numerical coefficient access is used.

2.2 Selecting all required cuts

Choose the median of the remaining requested integer cuts and perform weighted selection at that cut. Remove the selected pivot category and recurse on the categories and cuts on either side.

Because every $r_e<1$, a category’s weight interval can contain at most one integer cut. Thus the pivot category requires no further selection. Its possible split between adjacent blocks is determined by rational arithmetic.

The requested cuts are divided approximately in half at each recursion. Consequently, the recursion has $O(\log N)$ levels. At each level, the category lists in the different subproblems are disjoint, so their total size is at most $s$.

The total number of coefficient comparisons is therefore
$$ O(s\log N) \quad\text{when }N\geq2. $$
When $N=1$, there are no cuts and no comparisons.

Once these selections are complete, every category has a known block membership, or a known rational split across two adjacent blocks. The construction in Section 1 can then be executed without further cost queries.

3. Combining types and bounding running time

Apply the preceding construction independently to every type $t$, obtaining probabilities $p_{t,b}$. Output
$$ z_{t,b}=\mu_t p_{t,b}. $$
Then
$$ \sum_b z_{t,b}=\mu_t $$
and, for every category,
$$ \sum_{t,b}z_{t,b}b_e = \sum_t\mu_t q_e = q_e. $$
Every supported type–bundle pair satisfies the appropriate type’s PROP1 condition.

The comparison bound is
$$ O\!\left(\tau s\log(\lceil R\rceil+1)\right) \subseteq O\!\left(\tau m\log(\lceil R\rceil+1)\right). $$
Since $R<m$, this is also
$$ O(\tau m\log(m+1)). $$

If $R\leq1$, the construction simply uses $f+\mathbf 1_e$ with probability $r_e$, and $f$ with probability $1-R$ when positive. It uses zero queries.

For encoding, let $D$ be the product of the supply denominators. Its binary length is $O(L)$. Residuals, block pieces, interval endpoints, and probabilities can all be represented over denominator $D$, with $O(L)$-bit numerators. Multiplication by $\mu_t$ preserves an $O(L)$ bit bound.

Every output coordinate is one of
$$ f_e,\qquad f_e+1,\qquad f_e+2, $$
so it also has $O(L)$ bits.

Weighted selection, rational endpoint sorting, and explicit construction of at most $m+1$ bundles per type fit within the conservative elementary-arithmetic bound
$$ O(\tau m^2L^2). $$
This counts comparisons as unit operations. If the comparison oracles run in polynomial time in their query lengths, the complete algorithm remains polynomial-time.

4. A linear lower bound, including bounded fractional supply

The following proof permits arbitrary integral query bundles, including repeated categories and arbitrarily large binary-encoded multiplicities.

All logarithms in this section have base two.

4.1 Hidden-cost instances

Fix a rational constant
$$ 1<\alpha\leq2. $$
For $m\geq3$, take one type of mass one and supplies
$$ q_e=\frac{\alpha}{m} \quad\text{for every }e. $$
These supplies have fractional total $R=\alpha$.

Put
$$ h=\left\lfloor\frac{m-1}{2}\right\rfloor. $$
For each hidden set $H$ of size $h$, let
$$ a_e= \begin{cases} 1,&e\in H,\\ 0,&e\notin H. \end{cases} $$
The benchmark satisfies
$$ c(q)=\frac{\alpha h}{m}<1. $$

An integral bundle is valid exactly when
$$ \sum_{e\in H}b_e\leq1. $$
Indeed, two costly chores leave cost at least one after any single removal. One costly chore can be removed, and a bundle containing none already has cost zero. Empty bundles are permitted.

These are polynomial-time comparison oracles: they compare sums of query coordinates indexed by $H$.

4.2 How many hidden sets can share one output?

Fix an output distribution $p_b$ satisfying
$$ \sum_b p_b=1, \qquad \sum_b p_b b_e=\frac{\alpha}{m}. $$
Let $\mathcal F$ be the family of hidden sets for which this output is valid.

Define
$$ U=\{e:b_e\leq1\text{ in every supported bundle}\}. $$
Every $H\in\mathcal F$ lies in $U$, because a supported bundle repeating a category in $H$ would be invalid.

For each supported bundle, define
$$ S_b=\{e\in U:b_e=1\}. $$
Validity implies
$$ |H\cap S_b|\leq1 \quad\text{for every }H\in\mathcal F. $$

If $\mathcal F$ is nonempty, choose $H$ uniformly from it, and let $X$ be its indicator vector on $U$. Its Shannon entropy is
$$ \mathsf H(X)=\log|\mathcal F|. $$

Set
$$ \lambda_b=\frac{m}{\alpha}p_b. $$
For every $e\in U$,
$$ \sum_{b:e\in S_b}\lambda_b = \frac{m}{\alpha}\sum_b p_b b_e = 1. $$

We now prove the needed fractional-cover entropy inequality:
$$ \mathsf H(X)\leq\sum_b\lambda_b\mathsf H(X_{S_b}). $$
Order the coordinates of $U$. By the entropy chain rule, each restricted entropy is the sum of coordinate entropies conditioned on preceding coordinates within that restriction. Conditioning on all preceding coordinates can only decrease each term. Multiplying by $\lambda_b$ and summing gives the full chain-rule expression for $\mathsf H(X)$, because each coordinate has total covering weight one.

Here, the chain rule follows by factoring joint probabilities into conditional probabilities. The fact that conditioning decreases entropy follows from concavity of entropy: a conditional distribution with less information is a mixture of distributions with more information.

Since $X_{S_b}$ has at most one nonzero coordinate, it has at most $1+|S_b|$ possible values. Hence
$$ \mathsf H(X_{S_b})\leq\log(1+|S_b|). $$
The entropy bound follows from concavity and symmetry: among distributions on a fixed number of states, the uniform distribution maximizes entropy.

Furthermore,
$$ \sum_b p_b|S_b| = \sum_{e\in U}\sum_b p_b b_e = \frac{\alpha|U|}{m} \leq\alpha. $$
By concavity of the logarithm,
$$ \log|\mathcal F| \leq \frac{m}{\alpha}\sum_b p_b\log(1+|S_b|) \leq \frac{m}{\alpha}\log(1+\alpha). $$
Therefore every fixed output is compatible with at most
$$ (1+\alpha)^{m/\alpha} $$
hidden sets.

4.3 Decision-tree counting

A deterministic algorithm using at most $Q$ comparisons has at most $2^Q$ leaves. Each leaf produces one fixed output, regardless of the sizes of its query coordinates.

Correctness for all hidden sets therefore requires
$$ 2^Q(1+\alpha)^{m/\alpha}\geq\binom mh. $$

The chosen binomial coefficient is at least half a largest binomial coefficient. For odd $m$ it is central; for even $m$ its ratio to the central coefficient is at least one half. Since the largest coefficient is at least $2^m/(m+1)$,
$$ Q\geq \left(1-\frac{\log(1+\alpha)}{\alpha}\right)m -1-\log(m+1). $$

The coefficient of $m$ is positive for every fixed $\alpha>1$. Indeed, for
$$ g(x)=x-\log_2(1+x), $$
we have $g(1)=0$ and
$$ g'(x)=1-\frac{1}{(1+x)\ln2}>0 \quad\text{for }x\geq1, $$
because $\ln2>1/2$. Thus $g(\alpha)>0$.

This proves an $\Omega(m)$ lower bound. For fixed $\alpha$, these instances have input length $L=O(m\log m)$.

For any prescribed support size $\tau$, give all types the same hidden cost vector and positive masses summing to one. Aggregating their output masses produces exactly the distribution used above. Hence the same lower bound holds for every fixed $\tau$.

5. Consequences and open points

Fix $\tau$ and a constant $C>1$. The algorithm uses $O(m)$ comparisons on every instance with $R\leq C$. Choose a fixed rational $\alpha$ with
$$ 1<\alpha\leq\min\{C,2\}. $$
The lower-bound family has $R=\alpha$ and requires $\Omega(m)$ comparisons. Thus the worst-case complexity on this class is precisely
$$ \Theta(m). $$

For $R\leq1$, the zero-query construction proves that the optimal comparison complexity is zero.

For unrestricted $R$, the algorithm establishes polynomial-time solvability, but its worst-case comparison bound remains $O(\tau m\log(m+1))$. The lower bound proves only $\Omega(m)$ and does not determine the optimal dependence on $\tau$.

The cited finite-agent theorem gives $O(n^3\log k)$ comparisons for allocations to individually identified agents. Its model differs from the exact rational population distributions required here; it does not supply the missing general bound. [Lin, Liu, Tao, and Zhou](https://arxiv.org/html/2609.08687v1)
