The continuous mirror question, as graded

Given rational masses \(\mu_t\) over a finite type support \(T\), discrete categories \(J\) with per-capita supplies \(q_j\), utilities \(v_{tj}\), welfare values \(a_{tj}\), and threshold \(K\), decide whether assignment shares \(p_{tj}\ge 0\) exist such that \(\sum_j p_{tj}\le 1\), \(\sum_t\mu_t p_{tj}\le q_j\), and welfare \(\sum_t\mu_t\sum_j a_{tj}p_{tj}\ge K\), while no feasible shares \(p'\) weakly increase every positive-mass type’s average utility \(u_t=\sum_jv_{tj}p_{tj}\) and strictly increase at least one.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) categories \(J\), binary-rational per-capita supplies \(q_j\ge0\), explicitly listed admissible pairs \(E\subseteq T\times J\), rational utilities \(v_{tj}\), rational welfare coefficients \(a_{tj}\), and rational threshold \(K\). Utilities and welfare coefficients may have either sign; utility ties are allowed without tie-breaking. Let \(L\) be the total input bit length.
A feasible assignment has real shares \(p_{tj}\ge0\), with \(p_{tj}=0\) outside \(E\), \(\sum_jp_{tj}\le1\) for every type, and \(\sum_t\mu_tp_{tj}\le q_j\) for every category. Unassigned mass has zero utility and welfare.
Define \(u_t(p)=\sum_jv_{tj}p_{tj}\) and \(W(p)=\sum_t\mu_t\sum_ja_{tj}p_{tj}\). An assignment is Pareto-optimal if no feasible \(p'\) satisfies \(u_t(p')\ge u_t(p)\) for every type and strict inequality for at least one; the competing assignment need not meet the welfare threshold.

Is deciding whether a feasible Pareto-optimal assignment with \(W(p)\ge K\) exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L\).

Known results: welfare-threshold feasibility under Pareto-optimality for a bounded rational polyhedron with linear payoffs (Max-Pareto) is \(\mathrm{NP}\)-complete, already for fractional bipartite matching polytopes with inadmissible pairs. This anchor concerns continuous variables as well as integral matching instances; no separately stated result for the normalized type-mass formulation was located. [Source](https://arxiv.org/html/2509.18073v1)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result

The decision problem is \(\mathrm{NP}\)-complete. Thus it is \(\mathrm{NP}\)-hard, and a running time polynomial in \(m,\tau,L\) exists only if \(\mathrm{P}=\mathrm{NP}\).

The normalization of masses and supplies does not remove the stated fractional-matching hardness. The reduction below works even when all masses and supplies are dyadic rationals.

2. The hardness result being used

We use the supplied hardness anchor in its following specific form. Given a bipartite graph with agents \(i\in\{1,\ldots,n\}\), objects \(j\in\{1,\ldots,r\}\), and admissible edges \(F\), consider the fractional polytope

\( X=\left\{x\in\mathbb{R}_{\geq0}^{F}: \sum_{j:(i,j)\in F}x_{ij}\leq1\ \text{for every }i,\quad \sum_{i:(i,j)\in F}x_{ij}\leq1\ \text{for every }j \right\}. \)

Agent utilities are \(U_i(x)=\sum_{j:(i,j)\in F}b_{ij}x_{ij}\), and welfare is \(C(x)=\sum_{(i,j)\in F}c_{ij}x_{ij}\). Deciding whether some Pareto-optimal \(x\in X\) satisfies \(C(x)\geq H\) is \(\mathrm{NP}\)-hard. Here Pareto-optimality compares against every fractional point of \(X\).

This is the fractional matching specialization constructed in Theorem 14 of [*Pareto-Optimal Linear Programming*](https://arxiv.org/html/2509.18073v1#S5). Its hard instances have positive integer edge utilities and welfare coefficients in \(\{0,1\}\).

3. Reduction to normalized type masses

Take an instance of that fractional problem with \(n\geq1\). Let \(N\) be the smallest power of two satisfying \(N\geq n\), so \(n\leq N<2n\).

Construct the society as follows:

  • Each source agent becomes a type \(i\), with mass \(\mu_i=1/N\).
  • If \(n<N\), add one type \(d\) with mass \(\mu_d=(N-n)/N\) and no admissible pairs.
  • Set \(m=r\), and give every category supply \(q_j=1/N\).
  • Preserve the source edges: \(E=F\).
  • On every admissible pair, set \(v_{ij}=b_{ij}\) and \(a_{ij}=c_{ij}\).
  • Set the new threshold to \(K=H/N\).

Every listed mass is positive, their sum is one, and all masses and supplies are dyadic. The support size satisfies \(n\leq\tau\leq n+1\).

For the original types, identify \(p_{ij}=x_{ij}\). Their row constraints are identical to those defining \(X\). Each category constraint is equivalent to its source constraint because

\( \sum_{i=1}^{n}\mu_i p_{ij}\leq q_j \quad\Longleftrightarrow\quad \frac1N\sum_{i=1}^{n}p_{ij}\leq\frac1N \quad\Longleftrightarrow\quad \sum_{i=1}^{n}p_{ij}\leq1. \)

The additional type, when present, must have every share zero. Consequently, this identification is a bijection between the two feasible sets.

For every original type, \(u_i(p)=U_i(x)\); the additional utility coordinate is constantly zero. Therefore a feasible point dominates another in the society exactly when the corresponding source point dominates it. In particular,

\( p\text{ is Pareto-optimal} \quad\Longleftrightarrow\quad x\text{ is Pareto-optimal in }X. \)

Furthermore,

\( W(p)=\frac1N C(x), \qquad W(p)\geq K \quad\Longleftrightarrow\quad C(x)\geq H. \)

Thus the source and constructed instances have the same answer.

All new numerical encodings add only polynomially many bits: \(N\) has \(O(\log n)\) bits, and dividing a rational threshold by \(N\) increases its encoding length by \(O(\log n)\). The construction has polynomial running time and output length in the source input size. Hence the requested problem is \(\mathrm{NP}\)-hard.

4. Polynomial-size witnesses

We now prove membership in \(\mathrm{NP}\), including the issue that feasible assignments may initially have real coordinates.

Write \(e=|E|\), retaining only admissible coordinates, and let \(P\subseteq\mathbb{R}^{e}\) be the feasible polytope. It is nonempty because zero is feasible. It is bounded because nonnegativity and the row constraints imply \(0\leq p_{tj}\leq1\).

Suppose a Pareto-optimal \(p\in P\) satisfies \(W(p)\geq K\). Since a bounded polyhedron is the convex hull of its finitely many vertices, write

\( p=\sum_{\ell=1}^{h}\alpha_\ell z^\ell, \qquad \alpha_\ell>0, \qquad \sum_{\ell=1}^{h}\alpha_\ell=1, \)

where each \(z^\ell\) is a vertex of \(P\).

Every \(z^\ell\) is Pareto-optimal. Indeed, if some feasible \(y\) dominated \(z^\ell\), then

\( p'=p+\alpha_\ell(y-z^\ell) =\alpha_\ell y+\sum_{k\neq\ell}\alpha_k z^k \)

would be feasible by convexity. For every type \(t\),

\( u_t(p')-u_t(p)=\alpha_\ell\bigl(u_t(y)-u_t(z^\ell)\bigr). \)

These differences would all be nonnegative and at least one strictly positive, contradicting Pareto-optimality of \(p\).

By linearity, \(W(p)=\sum_\ell\alpha_\ell W(z^\ell)\). Hence at least one of these Pareto-optimal vertices satisfies \(W(z^\ell)\geq W(p)\geq K\).

Such a vertex has polynomial encoding length. For \(e>0\), choose \(e\) linearly independent active constraints determining it. Clearing denominators separately in each row produces integer coefficients with \(O(L)\) bits. Cramer’s rule and the determinant bound \(e!\,2^{O(eL)}\) show that each coordinate has \(O(e(L+\log(e+1)))\) bits. The entire vertex therefore has polynomially many bits.

5. Verification and running times

Given a rational candidate \(p\), check feasibility and \(W(p)\geq K\) by exact rational arithmetic. To check Pareto-optimality, solve the rational linear program

\( \max_{y\in P}\ \sum_{t\in T}\bigl(u_t(y)-u_t(p)\bigr) \quad\text{subject to}\quad u_t(y)\geq u_t(p)\ \text{for every }t. \)

The point \(y=p\) is feasible, so the optimum is nonnegative. Every summand is constrained to be nonnegative. Thus the optimum is positive exactly when some feasible assignment dominates \(p\); otherwise it is zero.

There are \(e\leq m\tau\) variables and \(e+m+2\tau\) inequalities. The program is feasible and bounded, and all its data have polynomial encoding length. Polynomial-time rational linear programming therefore gives a verifier running in \(\operatorname{poly}(m,\tau,L)\) time. No restriction on utility signs or ties was used. Combined with the vertex-witness argument, this proves membership in \(\mathrm{NP}\).

For an explicit deterministic upper bound, enumerate subsets of \(e\) constraints among the \(e+\tau+m\) constraints defining \(P\). Solve each nonsingular system and check the resulting candidate as above. Every vertex occurs among these candidates, so the running time is

\( \binom{e+\tau+m}{e}\operatorname{poly}(m,\tau,L) \leq 2^{O(m\tau)}\operatorname{poly}(m,\tau,L). \)

If \(e=0\), the unique assignment is zero, and the answer is yes exactly when \(K\leq0\).
