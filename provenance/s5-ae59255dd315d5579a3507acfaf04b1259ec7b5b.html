The continuous mirror question, as graded

Given finite worker-type and firm-type sets \(I\) and \(J\), rational masses \(\alpha_i\) and \(\beta_j\) of equal total, and each type's strict rankings over opposite-side types in states \(A\) and \(B\), does there exist a mass assignment \(x_{ij}\ge 0\) with \(\sum_j x_{ij}=\alpha_i\) and \(\sum_i x_{ij}=\beta_j\) such that, for every state \(r\in\{A,B\}\) and type pair \((i,j)\), either \(U^r_{ij}(x)=0\) or \(V^r_{ij}(x)=0\)?

Packaged proof task (what the prover saw — nothing else)

Let \(I\) and \(J\) be nonempty finite sets of worker and firm types. A society is given by its support: the list of its \(\tau=|I|+|J|\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Masses satisfy \(\sum_i\alpha_i=\sum_j\beta_j=M>0\), with no requirement that \(M=1\).
In each state \(r\in\{A,B\}\), every type has a strict complete ranking of opposite-side types, denoted \(\succ_i^r\) for workers and \(\succ_j^r\) for firms. Individuals within a type are indifferent between partners of the same type.
Let \(k\) count the worker and firm types whose rankings differ between states, and impose \(k\le K\), where \(K\) is a fixed constant independent of input size. Let \(m=\max\{|I|,|J|\}\) and let \(L\) be the total binary input length; state running times in \(m,\tau,L,K\).
A mass assignment is a real matrix \(x\ge0\) satisfying \(\sum_jx_{ij}=\alpha_i\) and \(\sum_ix_{ij}=\beta_j\). Define \(U_{ij}^r(x)=\sum_{j':\,j\succ_i^r j'}x_{ij'}\) and \(V_{ij}^r(x)=\sum_{i':\,i\succ_j^r i'}x_{i'j}\), the masses assigned strictly worse partners than the proposed pair.
Call \(x\) robust stable if, for every \(r\in\{A,B\}\) and \((i,j)\in I\times J\), either \(U_{ij}^r(x)=0\) or \(V_{ij}^r(x)=0\). The decision problem asks whether such an assignment exists.

For every fixed \(K\), is this decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard for some fixed \(K\)?

For discrete agents with strict complete preferences, robust stable matching existence and construction are polynomial-time solvable when only constantly many agents change rankings. [Gangam et al.](https://arxiv.org/html/2304.02590v3)
For a single state with unit agent capacities, maximizing the number of fully matched agents under ordinal stability is polynomial-time solvable in bipartite markets without ties. [Chen, Roy and Sorge](https://www.ijcai.org/proceedings/2021/0013.pdf) No result settling the exact two-state mass problem above was located.

Modeling choices made when packaging the task

  • Defined the missing U and V terms as masses assigned strictly worse opposite-side types, matching the discrete blocking-pair condition.
  • Restored the anchor's constant-change restriction as at most K changing supported types, for a fixed constant K; counted types rather than their masses.
  • Required nonempty supports, positive binary-rational masses, and equal positive total mass; retained arbitrary common total rather than imposing normalization.
  • Specified complete strict rankings over opposite-side types and indifference between individuals of the same type.
  • Allowed real divisible assignments and defined m as the maximum opposite-side ranking length and L as total binary input length.

Result

For every fixed \(K\), the decision problem is in \(\mathrm P\). A robust stable assignment can also be constructed in polynomial time.

The key is to enumerate the worst assigned partner type in state \(B\) for each changed type. Each enumeration reduces the problem to finding a state-\(A\) stable allocation with specified entries forbidden. This latter problem is polynomial-time solvable through stable flows.

1. A polynomial-time subproblem

Consider a single state with strict type rankings and the given masses. Let \(F\subseteq I\times J\) be any set of pairs. We first establish that the following problem is polynomial-time solvable:

Find a stable mass assignment \(x\) satisfying \(x_{ij}=0\) for every \((i,j)\in F\).

The forbidden pairs remain potential blocking pairs; their assignment entries must merely be zero.

We use the following known result. In a capacitated directed network, each nonterminal vertex strictly ranks its incoming and outgoing arcs separately. A blocking walk consists of unsaturated arcs; its initial vertex is the source or prefers its first arc to some positive-flow outgoing arc, and its final vertex is the sink or prefers its last arc to some positive-flow incoming arc. A stable flow has no blocking walk.

Stable-flow theorem with forbidden arcs. Given such a network and a set \(P\) of arcs required to carry zero flow, one can find a stable flow avoiding \(P\), or determine nonexistence, in \(O((|P|+1)|E|\log(|V|+2))\) arithmetic operations. Stability is tested in the original network, including forbidden arcs. This follows from Section 4.3 and Theorem 5 of [Cseh and Matuschke, *New and simple algorithms for stable flow problems*](https://arxiv.org/pdf/1309.3701).

Reduction and hypothesis checks

Construct a directed network with vertex set \(\{s,t\}\cup I\cup J\) and arcs

\[ s\longrightarrow i,\qquad i\longrightarrow j,\qquad j\longrightarrow t. \]

Their capacities are, respectively, \(\alpha_i\), \(2M\), and \(\beta_j\).

Worker \(i\) ranks its outgoing arcs according to its firm ranking. Firm \(j\) ranks its incoming arcs according to its worker ranking. The remaining lists at nonterminal vertices contain a single arc. Thus all required rankings are strict. All capacities are positive rational numbers, and every nonterminal vertex has incoming and outgoing arcs.

Declare \(i\longrightarrow j\) forbidden exactly when \((i,j)\in F\).

Every stable flow in this network saturates all terminal arcs. Indeed, let its value be \(T\). Capacity constraints give \(T\le M\). If \(T<M\), there are types \(i,j\) with

\[ f(si)<\alpha_i,\qquad f(jt)<\beta_j. \]

Also \(f(ij)\le T\le M<2M\). Hence \(s,i,j,t\) is an unsaturated source-to-sink walk, which blocks. This contradicts stability. Therefore \(T=M\). Since the capacities leaving the source and entering the sink each sum to \(M\), every terminal arc is saturated.

Consequently, setting \(x_{ij}=f(ij)\) gives precisely the required row and column sums.

Conversely, every mass assignment defines a flow by setting \(f(si)=\alpha_i\), \(f(ij)=x_{ij}\), and \(f(jt)=\beta_j\). Its terminal arcs are saturated, whereas every middle arc is unsaturated because \(x_{ij}\le M<2M\). Therefore the only possible blocking walks are single middle arcs \(i\longrightarrow j\). Such an arc blocks exactly when there is positive flow on a worse outgoing arc of \(i\) and a worse incoming arc of \(j\), that is, exactly when

\[ U_{ij}(x)>0\quad\text{and}\quad V_{ij}(x)>0. \]

This proves the equivalence between stable flows avoiding the forbidden arcs and stable mass assignments avoiding \(F\). In particular, it proves the claimed polynomial-time subproblem.

2. Enumerating cutoffs for changed types

Let \(C_I\subseteq I\) and \(C_J\subseteq J\) be the changed worker and firm types. Write \(p=|C_I|\), \(q=|C_J|\), and \(k=p+q\le K\).

For each \(i\in C_I\), choose a firm type \(w_i\in J\). For each \(j\in C_J\), choose a worker type \(v_j\in I\).

The choices are intended to represent worst assigned partners under state-\(B\) rankings. There are

\[ |J|^p|I|^q\le m^k \]

choice tuples.

For a fixed tuple, impose the following zero-entry restrictions.

Changed worker support restrictions. For every \(i\in C_I\), require

\[ x_{ih}=0\qquad\text{whenever }w_i\succ_i^B h. \]

Changed worker blocking restrictions. For every \(i\in C_I\) and every \(j\) satisfying \(j\succ_i^B w_i\), require

\[ x_{hj}=0\qquad\text{for every }h\text{ satisfying }i\succ_j^B h. \]

Changed firm support restrictions. For every \(j\in C_J\), require

\[ x_{hj}=0\qquad\text{whenever }v_j\succ_j^B h. \]

Changed firm blocking restrictions. For every \(j\in C_J\) and every \(i\) satisfying \(i\succ_j^B v_j\), require

\[ x_{ih}=0\qquad\text{for every }h\text{ satisfying }j\succ_i^B h. \]

Let \(F(w,v)\) be the union of all pairs whose entries are required to vanish. Apply the subproblem from Section 1 to state \(A\) with forbidden set \(F(w,v)\).

The algorithm accepts and returns an assignment if any tuple succeeds. Otherwise, it rejects.

No restriction requires the guessed cutoff itself to receive positive mass. This does not affect correctness, as shown next.

3. Soundness

Suppose a tuple succeeds, producing a state-\(A\) stable mass assignment \(x\) obeying its restrictions. We prove stability in state \(B\), considering an arbitrary pair \((i,j)\).

Case 1: The worker type is changed

Suppose \(i\in C_I\).

If \(j\succ_i^B w_i\), the changed worker blocking restrictions force every entry counted in \(V_{ij}^B(x)\) to vanish. Thus \(V_{ij}^B(x)=0\).

Otherwise, strict completeness implies that either \(j=w_i\) or \(w_i\succ_i^B j\). Every partner strictly worse than \(j\) is then strictly worse than \(w_i\). The changed worker support restrictions consequently give \(U_{ij}^B(x)=0\).

Thus every pair incident to a changed worker is stable in state \(B\).

Case 2: Only the firm type is changed

Suppose \(i\notin C_I\) and \(j\in C_J\).

If \(i\succ_j^B v_j\), the changed firm blocking restrictions give \(U_{ij}^B(x)=0\).

Otherwise, either \(i=v_j\) or \(v_j\succ_j^B i\). Every worker strictly worse than \(i\) is strictly worse than \(v_j\), so the changed firm support restrictions give \(V_{ij}^B(x)=0\).

Case 3: Neither type is changed

Both relevant rankings agree between states. Hence

\[ U_{ij}^B(x)=U_{ij}^A(x),\qquad V_{ij}^B(x)=V_{ij}^A(x). \]

State-\(A\) stability therefore implies state-\(B\) stability for this pair.

These cases cover all pairs. The returned assignment is robust stable.

4. Completeness

Suppose \(x\) is a robust stable assignment.

Because every supported type has positive mass, every row and column of \(x\) has a positive entry. Strict rankings and finiteness therefore define a unique worst positive-mass partner in state \(B\) for every type.

For each \(i\in C_I\), choose \(w_i\) to be that worker type’s worst positive-mass firm. For each \(j\in C_J\), choose \(v_j\) to be that firm type’s worst positive-mass worker.

By definition, \(x\) obeys both families of support restrictions.

Now let \(i\in C_I\) and \(j\succ_i^B w_i\). Since \(x_{iw_i}>0\), this entry contributes to \(U_{ij}^B(x)\), yielding

\[ U_{ij}^B(x)\ge x_{iw_i}>0. \]

State-\(B\) stability implies \(V_{ij}^B(x)=0\). Since its summands are nonnegative, every entry required to vanish by the corresponding changed worker blocking restriction is indeed zero.

Similarly, if \(j\in C_J\) and \(i\succ_j^B v_j\), then

\[ V_{ij}^B(x)\ge x_{v_jj}>0. \]

Stability implies \(U_{ij}^B(x)=0\), establishing the corresponding changed firm blocking restrictions.

Thus \(x\) is state-\(A\) stable and avoids \(F(w,v)\) for this enumerated tuple. The polynomial-time subproblem must succeed on that tuple. Therefore the algorithm accepts whenever a robust stable assignment exists.

5. Running time and binary masses

The network has \(\tau+2\) vertices and

\[ |I||J|+\tau=O(m^2) \]

arcs. Each forbidden set can be constructed in \(O((k+1)m^2)\) operations using rank tables, and contains at most \(|I||J|\) arcs. The stable-flow subroutine consequently uses \(O(m^4\log(\tau+2))\) arithmetic operations per tuple.

Including enumeration, the arithmetic-operation bound is

\[ O\!\left( m^k\bigl((k+1)m^2+m^4\log(\tau+2)\bigr) \right). \]

This bound does not depend on the numerical magnitude of the masses.

To obtain a binary running-time bound, multiply every mass by the product \(D\) of its input denominators. The binary length of \(D\), and of every resulting integer mass, is \(O(L)\). Scaling by \(D>0\) preserves all zero-versus-positive stability conditions.

The forbidden-flow algorithm can use integer auxiliary capacities and exact augmentation arithmetic. Its intermediate flow values have polynomial binary length: capacities have \(O(L)\) bits, and the auxiliary networks have \(O(m^2)\) arcs. Thus each arithmetic operation has polynomial bit cost. For example, a conservative bound is

\[ O\!\left( L^3+(K+1)m^{K+4}\log(\tau+2)(L+\tau)^2 \right). \]

The same algorithm constructs a rational robust assignment by dividing the resulting middle-arc flows by \(D\). Neither normalization to \(M=1\) nor expansion into individual agents is needed.

Therefore the stated problem is polynomial-time solvable for every fixed \(K\).
