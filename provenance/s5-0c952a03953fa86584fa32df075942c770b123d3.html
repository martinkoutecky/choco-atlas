The continuous mirror question, as graded

Given \(M\), rational conditional type masses \(\mu^\theta\) on \(T=\{U,I_1,\ldots,I_M\}\), prior \(\pi\), and threshold \(q\), apply the Proposition \(1\) equilibrium rule to a uniformly random ordering of the high-multiplicity population, compute the limiting expected correct-action fraction \(W_d=\sum_\theta \pi(\theta)\nu_d^\theta(\theta)\), and decide whether \(W_d\ge q\).

Packaged proof task (what the prover saw — nothing else)

Let \(M\ge1\), with ordered actions \(0<1<\cdots<M\) and true state \(\theta\in\{1,\ldots,M\}\); action \(0\) is never correct. Type \(U\) has no signal, and type \(I_j\) has signal \(j\).
Input consists of a rational prior \(\pi\), conditional probability masses \(\mu^\theta\) on \(T=\{U,I_1,\ldots,I_M\}\), and rational \(q\in[0,1]\); all probabilities are nonnegative and each distribution sums to one.
A society is given by its support: the list of types with positive mass, each mass a binary rational. Let \(\tau\) be the size of the union of the conditional supports, not the number of possible types, and \(L\) the total input bit length; state running times in \(M,\tau,L\).
Agents act sequentially and observe all preceding actions. Apply the following prescribed rule \(d\), using counts before the current move.
Let \(S\) be the previously chosen positive actions and \(R\subseteq S\) those chosen at least twice. Define \(h=0\) if \(S=\varnothing\); otherwise, define \(h=\min(R\setminus\{\max S\})\) when this set is nonempty, and \(h=\max S\) otherwise.
Type \(U\) chooses \(h\). Type \(I_j\) chooses \(j\) if \(j\in S\) or \(R=\varnothing\), and chooses \(h\) otherwise. These rules also specify the first move.
For each state and each positive integer \(N\) making all \(N\mu^\theta(t)\) integral, uniformly permute a population containing exactly \(N\mu^\theta(t)\) agents of each type \(t\).
Let \(C_{N,d}^\theta(a)\) count agents choosing \(a\), and define \(\nu_d^\theta(a)=\lim_{N\to\infty}\mathbb E[C_{N,d}^\theta(a)/N]\) along these admissible population sizes; set \(W_d=\sum_{\theta=1}^M\pi(\theta)\nu_d^\theta(\theta)\).

Does this limiting expected fraction exist for every input, and is deciding \(W_d\ge q\) in \(\mathrm P\) or \(\mathrm{NP}\)-hard?

For finitely many agents, continuum actions, and atomless erroneous signals, the rule above on reachable histories is the unique Nash equilibrium under the specified signal-following and action-order tie breaks; this is an equilibrium characterization, not a complexity classification. [Banerjee (1992)](https://economics.mit.edu/sites/default/files/publications/banerjee92herd.pdf)
No complexity classification for this exact finite-support, conditional-mass limiting problem was located in the literature search.

Modeling choices made when packaging the task

  • Defined the true states and signal labels as 1 through M, ordered by their labels, with 0 reserved for the uninformed default and excluded from correct states.
  • Normalized every conditional mass distribution and the prior to total mass one; allowed zero probabilities and restricted the rational threshold to [0,1].
  • Interpreted high multiplicity as exact integer replication of rational conditional masses, followed by a uniformly random permutation, with the limit taken over admissible population sizes.
  • Defined the limiting action masses as limits of expected empirical action fractions, rather than assuming a deterministic limiting outcome.
  • Completed histories with multiple repeated nonmaximum actions by choosing the smallest such action. This agrees with the specified rule wherever its selected nonmaximum action is unique.
  • Treated the rule as prescribed behavior for arbitrary conditional distributions, without claiming that it remains a Bayesian equilibrium after replacing atomless signals by finitely many signal labels.
  • Included existence of the limit in the target because the graded question assumes it without defining or establishing it.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

All the limiting expected fractions exist. Moreover, deciding \(W_d\ge q\) is in \(\mathrm P\).

An exact algorithm uses \(O(M\tau^2)\) rational arithmetic operations. A conservative bit-operation bound is
\(O\!\left(L+M\tau^2\bigl(L+\tau\log(\tau+1)\bigr)^3\right)\).

1. Reachable histories and eventual behavior

Fix a state and suppress its superscript. Write
\(u=\mu(U)\), \(p_j=\mu(I_j)\), \(J=\{j:p_j>0\}\), \(s=|J|\), and \(b=\sum_{j\in J}p_j=1-u\).
For \(A\subseteq J\), write \(p(A)=\sum_{j\in A}p_j\).

If \(b=0\), every agent is uninformed. Every action is then \(0\), so
\(\nu(0)=1\) and \(\nu(a)=0\) for every positive \(a\).
Henceforth assume \(b>0\).

Before the first positive action, every uninformed agent chooses \(0\). The first informative agent chooses its signal.

After that first positive action, while \(R=\varnothing\), an informative agent chooses its signal. A previously unseen signal enlarges \(S\), whereas an already seen signal causes the first positive repetition. An uninformed agent chooses \(\max S\), also causing a positive repetition.

Let \(A\) be the set \(S\) immediately after the first positive repetition.

Claim. From that moment onward, \(S=A\).

Indeed, \(R\) remains nonempty. An informative agent whose signal belongs to \(A\) chooses that signal; every other agent chooses \(h\in A\). Thus no further positive action can enter \(S\).

Once every action in \(A\) has been chosen at least twice, \(R=A\). If \(A\) is a singleton, \(h=\min A\). Otherwise,
\(\min(A\setminus\{\max A\})=\min A\), so again \(h=\min A\).
Consequently, from then onward the type-to-action assignment is

\(f_A(U)=\min A\), and
\(f_A(I_j)=j\) if \(j\in A\), while \(f_A(I_j)=\min A\) otherwise.

The fraction assigned to a positive action \(a\) under this assignment is therefore

\(g_A(a)=p_a\mathbf 1_{\{a\in A\}}+(1-p(A))\mathbf 1_{\{a=\min A\}}\),

where \(p_a=0\) when \(a\notin J\). Also set \(g_A(0)=0\).
These fractions are nonnegative and sum to one.

2. Existence of the population limits

We now justify using the eventual assignment despite the transient and the sampling without replacement.

For each sufficiently large admissible \(N\), every informative type in \(J\) has at least two population members. Let \(H_N\) be the first position by which every such type has appeared at least twice, and let \(A_N\) be the set at the first positive repetition.

That repetition occurs by \(H_N\). Every \(j\in A_N\) chooses \(j\) whenever its informative type appears: before the repetition this follows from \(R=\varnothing\), and afterward it follows from \(j\in S\). Thus, by \(H_N\), every action in \(A_N\) has been chosen twice. All subsequent actions follow \(f_{A_N}\).

Applying \(f_{A_N}\) hypothetically to the entire population would give exactly \(Ng_{A_N}(a)\) choices of \(a\). Only the first \(H_N\) agents can differ from that assignment. Hence, for every action \(a\),

\(\left|C_{N,d}(a)/N-g_{A_N}(a)\right|\le H_N/N\).

Consider also an infinite sequence of independent types with distribution \(\mu\). Define \(H\) and \(A\) analogously.

Every informative type has positive probability. For \(K\ge2\), a union bound gives

\(\Pr(H>K)\le\sum_{j\in J}\left((1-p_j)^K+Kp_j(1-p_j)^{K-1}\right)\longrightarrow0\).

In particular, \(H\) is finite almost surely.

For a fixed word \(w_1,\ldots,w_K\) over the conditional support, let \(c_{r-1}(t)\) count its occurrences of \(t\) before position \(r\). For sufficiently large admissible \(N\), the probability of this prefix in the uniformly permuted population is

\(\prod_{r=1}^K\frac{N\mu(w_r)-c_{r-1}(w_r)}{N-r+1}\longrightarrow\prod_{r=1}^K\mu(w_r)\).

There are only finitely many words of length \(K\). Consequently, every event or bounded function determined by this prefix converges to its independent-sampling counterpart. In particular,
\(\Pr(H_N>K)\longrightarrow\Pr(H>K)\).

The deterministic error bound now implies

\(\limsup_{N\to\infty}\mathbb E\left[\left|C_{N,d}(a)/N-g_{A_N}(a)\right|\right]\le\Pr(H>K)\),

because the error is at most \(K/N\) on \(H_N\le K\), and at most one otherwise. Letting \(K\) tend to infinity makes this bound zero.

Furthermore, \(g_{A_N}(a)\mathbf 1_{\{H_N\le K\}}\) is a bounded function of the first \(K\) types. Therefore,

\(\mathbb E[g_{A_N}(a)\mathbf 1_{\{H_N\le K\}}]\longrightarrow \mathbb E[g_A(a)\mathbf 1_{\{H\le K\}}]\).

Since all these fractions lie in \([0,1]\), removing the indicators introduces errors at most \(\Pr(H_N>K)\) and \(\Pr(H>K)\), respectively. Taking the population limit and then letting \(K\) grow proves
\(\mathbb E[g_{A_N}(a)]\longrightarrow\mathbb E[g_A(a)]\).

Combining the two conclusions establishes, along all admissible population sizes,

\(\boxed{\nu(a)=\mathbb E[g_A(a)]}\).

This proves existence for every action and every state. When \(b>0\), it also proves \(\nu(0)=0\).

3. Distribution of the frozen set

Work henceforth with the independent sequence.

For a nonempty \(A\subseteq J\), put \(k=|A|\). To obtain this frozen set:

  • An arbitrary initial sequence of uninformed types chooses \(0\).
  • The next \(k\) types are the distinct informative types indexed by \(A\), in some order.
  • The next type is either uninformed or an informative type indexed by \(A\), causing the first positive repetition.

For a fixed ordering, summing over the number of initial uninformed types gives probability

\(\sum_{r=0}^{\infty}u^r\left(\prod_{j\in A}p_j\right)(u+p(A)) =\frac1b\left(\prod_{j\in A}p_j\right)(u+p(A))\).

There are \(k!\) possible orderings, and their events are disjoint. Thus

\(\boxed{\Pr(A\text{ is the frozen set})= \frac{|A|!}{b}\left(\prod_{j\in A}p_j\right)(u+p(A))}\).

These events exhaust all possibilities: after the first informative type, at most \(s\) further moves can occur before a repetition.

Although this distribution has exponentially many possible sets, the expectations needed below can be summed in polynomial time.

4. An exact formula for a target action

Fix \(a\in J\), and write \(x=p_a\). Define
\(B=J\setminus\{a\}\) and \(D=\{j\in J:j>a\}\).

For any \(E\subseteq J\), define

\(e_k(E)=\sum_{\substack{C\subseteq E\\|C|=k}}\prod_{j\in C}p_j\),

\(t_k(E)=\sum_{\substack{C\subseteq E\\|C|=k}}p(C)\prod_{j\in C}p_j\),

\(v_k(E)=\sum_{\substack{C\subseteq E\\|C|=k}}p(C)^2\prod_{j\in C}p_j\).

The empty-subset conventions are \(e_0(E)=1\) and \(t_0(E)=v_0(E)=0\).

Contribution from informative agents following their own signal

Action \(a\) belongs to the frozen set precisely when it appears before the first repetition. Immediately before its introduction, the informative signals observed since the first positive action form an ordered sequence of distinct elements of some \(C\subseteq B\).

For each such ordering, summing over the initial uninformed types gives probability
\(x\prod_{j\in C}p_j/b\).
There are \(|C|!\) orderings. These events are disjoint, since they specify the history through the introduction of \(a\). Hence

\(\Pr(a\in A)=\frac{x}{b}\sum_{k=0}^{|B|}k!\,e_k(B)\).

The first term in \(\mathbb E[g_A(a)]\) is consequently

\(\frac{x^2}{b}\sum_{k=0}^{|B|}k!\,e_k(B)\).

Contribution from agents choosing the eventual minimum

The frozen sets whose minimum is \(a\) are exactly \(\{a\}\cup C\), where \(C\subseteq D\).
Using their distribution from Section 3 gives

\(\mathbb E[(1-p(A))\mathbf 1_{\{\min A=a\}}] =\frac{x}{b}\sum_{C\subseteq D}(|C|+1)! \left(\prod_{j\in C}p_j\right)(u+x+p(C))(1-x-p(C))\).

The required expansion is

\((u+x+z)(1-x-z)=(u+x)(1-x)+(1-u-2x)z-z^2\).

Grouping subsets by cardinality therefore yields the exact formula

\(\boxed{\displaystyle \nu(a)= \frac{x^2}{b}\sum_{k=0}^{|B|}k!\,e_k(B) +\frac{x}{b}\sum_{k=0}^{|D|}(k+1)! \left((u+x)(1-x)e_k(D)+(1-u-2x)t_k(D)-v_k(D)\right)}\).

If \(a\notin J\), then \(\nu(a)=0\), since an action absent from the informative support can never be introduced.

5. Computing the formula

The three coefficient arrays can be computed without enumerating subsets.

Start with \(e_0=1\), \(t_0=v_0=0\), and all other entries zero. When adding a new index of mass \(w\), update simultaneously using

\(e'_k=e_k+w e_{k-1}\),

\(t'_k=t_k+w t_{k-1}+w^2e_{k-1}\),

\(v'_k=v_k+w v_{k-1}+2w^2t_{k-1}+w^3e_{k-1}\),

with negative-index entries interpreted as zero.

To verify these recurrences, partition subsets into those excluding the new index and those including it. An including subset contributes a factor \(w\) to its product, and its mass changes from \(z\) to \(z+w\). The last two recurrences then follow by expanding \(w(z+w)\) and \(w(z+w)^2\).

Adding \(r\) indices requires \(O(r^2)\) rational arithmetic operations. For a fixed target action, compute \(e_k(B)\) and the three arrays for \(D\), then evaluate the formula.

For each state \(\theta\), only the target action \(a=\theta\) is needed. Each conditional informative support has size at most \(\tau\). Thus computing all contributions and
\(W_d=\sum_{\theta=1}^M\pi(\theta)\nu_d^\theta(\theta)\)
uses \(O(M\tau^2)\) rational arithmetic operations.

6. Bit complexity and exact comparison

Polynomially many rational operations alone would not suffice without controlling their bit lengths. We supply that control.

For a fixed state, let \(Q\) be the product of the denominators of its listed conditional masses. Its bit length is bounded by that state's input length. Every mass has denominator dividing \(Q\), and we may write \(b=B_0/Q\) with an integer \(1\le B_0\le Q\).

Each monomial defining \(e_k,t_k,v_k\) contains any individual mass to exponent at most three. The same is true of the polynomials in the formula for \(\nu(a)\) before division by \(b\). Thus their denominators divide \(Q^3\); after that division, denominators divide \(Q^3B_0\).

Also, \(e_k,t_k,v_k\) all lie in \([0,1]\): the subset masses are at most one, and
\(e_k\le(\sum_jp_j)^k/k!\le1\).
The factorials and finite sums therefore give intermediate numerators of bit length
\(O(L+\tau\log(\tau+1))\).
Reducing fractions after each operation preserves this bound; unreduced operands during an individual operation increase it only by a constant factor.

For the final sum over states, its denominator divides the product of the state bounds \(Q_\theta^3B_{0,\theta}\) and the input prior denominators. The bit length of this product is \(O(L)\). Hence summing the state contributions also respects the stated polynomial bound.

Writing \(\mathcal B=L+\tau\log(\tau+1)\), elementary integer arithmetic and fraction reduction can conservatively be performed in \(O(\mathcal B^3)\) bit operations per rational operation. Including input processing, the resulting bound is

\(O\!\left(L+M\tau^2\mathcal B^3\right)\).

Finally, compare the computed rational \(W_d\) with the input rational \(q\) by cross-multiplying their positive denominators. This comparison is exact, including equality.

Thus the limits exist for every input, and the requested threshold problem is polynomial-time solvable.
