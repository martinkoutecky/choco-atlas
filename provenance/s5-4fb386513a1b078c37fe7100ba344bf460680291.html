The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), an explicit finite set \(Q\subseteq\mathbb{N}^{T}\setminus\{0\}\) of feasible team compositions containing every singleton, and rational team values \(w(q)\), choose real team frequencies \(z_q\ge 0\) to maximize \(\sum_{q\in Q}w(q)z_q\), subject to \(\sum_{q\in Q}q_tz_q=\mu_t\) for each \(t\in T\). For fixed maximum team size \(b\), does this continuous coalition-structure problem admit an efficient algorithm?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input explicitly lists \(Q\subseteq\mathbb{Z}_{\ge0}^{T}\setminus\{0\}\), containing every unit vector \(e_t\), and arbitrary signed binary-rational values \(w(q)\). These are exactly the feasible team compositions; \(q_t\) counts members of type \(t\).
Fix a positive integer \(b\) and require \(\sum_{t\in T}q_t\le b\) for every \(q\in Q\). Let \(m=|Q|\), and let \(L\) be the total binary input length.
A continuous coalition structure consists of real frequencies \(z_q\ge0\) satisfying \(\sum_{q\in Q}q_tz_q=\mu_t\) for every \(t\in T\); its value is \(\sum_{q\in Q}w(q)z_q\). Frequencies need not sum to one. Given a binary-rational threshold \(K\), decide whether a structure of value at least \(K\) exists.

For each fixed \(b\), is this continuous coalition-structure decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L\), with dependence on \(b\) explicit.

For finite agents, DyPE correctly maximizes the sum of coalition values over exhaustive disjoint partitions into coalitions inducing connected subgraphs of a given synergy graph. [Vinyals et al.](https://arxiv.org/pdf/1310.6704)

Classification

The problem belongs to \(\mathrm{P}\) for every fixed positive integer \(b\). More strongly, it remains in \(\mathrm{P}\) when \(b\) varies, because the feasible compositions \(Q\) are explicitly listed.

A deterministic running-time bound is \((L+m^2+m\tau)^{O(1)}\) bit operations, where the exponent and constants are absolute and independent of \(b\). Thus any polynomial-time many-one NP-hardness result for this problem would imply \(\mathrm{P}=\mathrm{NP}\).

1. Exact linear-programming formulation

Order the types and listed compositions. Define the matrix \(A\in\mathbb{Z}_{\geq 0}^{\tau\times m}\) and vector \(c\in\mathbb{Q}^m\) by \(A_{t,q}=q_t\) and \(c_q=w(q)\). Write \(\mu=(\mu_t)_{t\in T}\).

The optimization problem is precisely the rational linear program

\(\displaystyle \max\{c^{\mathsf T}z:Az=\mu,\ z\in\mathbb{R}_{\geq 0}^{m}\}.\)

This formulation uses one variable for each explicitly listed composition. Its constraints are exactly the type-mass conservation equations in the question. No constraint requiring the frequencies to sum to one is added.

The decision problem is therefore equivalent to feasibility of the rational system

\(\displaystyle Az\leq\mu,\qquad -Az\leq-\mu,\qquad -z\leq 0,\qquad -c^{\mathsf T}z\leq-K.\)

Indeed, the first two families together enforce \(Az=\mu\), the third enforces nonnegative frequencies, and the last enforces value at least \(K\). Consequently, solutions of this system and qualifying coalition structures coincide.

2. Feasibility and attainment

The conservation constraints are always feasible. Since every unit vector belongs to \(Q\), set \(z_{e_t}=\mu_t\) for every \(t\), and set all other frequencies to zero. This gives \(Az=\mu\).

For boundedness, define the size of a composition by \(s_q=\sum_{t\in T}q_t\). Every listed composition is nonzero, so \(1\leq s_q\leq b\). Summing the conservation equations gives

\(\displaystyle 1=\sum_{t\in T}\mu_t=\sum_{q\in Q}s_qz_q.\)

Nonnegativity and the bounds on \(s_q\) therefore imply

\(\displaystyle \frac{1}{b}\leq\sum_{q\in Q}z_q\leq 1.\)

In particular, every frequency satisfies \(0\leq z_q\leq 1\). The feasible set is closed, because it is defined by linear equalities and non-strict inequalities, and bounded, because it lies in \([0,1]^m\). It is nonempty by the singleton construction, hence compact.

The linear objective is continuous and therefore attains a finite maximum. Arbitrary signed values \(w(q)\) cause no difficulty.

3. Exact decision and running time

We use the standard polynomial-time rational linear-feasibility theorem: an explicitly encoded system of non-strict linear inequalities with rational coefficients can be tested for real feasibility by a deterministic algorithm using polynomially many bit operations in its total binary encoding length. The theorem handles lower-dimensional feasible sets and decides feasibility exactly; it does not require a strict-feasibility assumption or a numerical tolerance. See [Nemirovski’s treatment of polynomial solvability over the rationals, Section 8.4](https://www2.isye.gatech.edu/~nemirovs/OPTIII_LectureNotes2020.pdf).

The system above satisfies every hypothesis:

  • It has \(m\) real variables and \(m+2\tau+1\) explicitly specified inequalities.
  • All coefficients are rational: composition entries are integers, and masses, values, and the threshold are binary rationals.
  • All inequalities are non-strict.

Let \(S\) be its dense binary encoding length. The composition matrix and mass vector are copied twice, the value vector and threshold once, and the nonnegativity constraints introduce an identity matrix. Copied input coefficients contribute \(O(L)\) bits. Added zero entries and unit coefficients contribute \(O(m\tau+m^2)\) bits. Thus

\(\displaystyle S=O(L+m\tau+m^2).\)

Constructing the system and applying rational linear feasibility consequently takes

\(\displaystyle (L+m\tau+m^2)^{O(1)}\)

bit operations. The exponent and constants do not depend on \(b\). Every actual composition coordinate is already encoded in \(L\); the algorithm has no additional dependence on \(b\). In particular, it also works when \(b\) is variable.

For an alternative bound displaying the fixed-\(b\) dependence through the support size, the number of possible nonzero compositions of size at most \(b\) is

\(\displaystyle \binom{\tau+b}{b}-1.\)

To verify this count, introduce a slack coordinate \(q_0=b-\sum_{t\in T}q_t\). Nonnegative compositions of size at most \(b\) then correspond bijectively to nonnegative integer vectors with \(\tau+1\) coordinates summing to \(b\), of which stars and bars gives \(\binom{\tau+b}{b}\). Remove the zero composition.

Hence

\(\displaystyle m\leq\binom{\tau+b}{b}-1\leq(\tau+1)^b,\)

where the last inequality follows by representing each such count vector by a word of length \(b\) over \(\tau+1\) symbols. Substitution gives the additional bound

\(\displaystyle \bigl(L+(\tau+1)^b\bigr)^{O(1)},\)

again with an absolute exponent. The algorithm processes the supplied list \(Q\); it need not enumerate all possible compositions.

For \(b=1\), only unit vectors are possible, so the unique feasible structure has value \(\sum_{t\in T}\mu_tw(e_t)\). The linear-programming argument settles every larger \(b\) as well.

4. Relation to finite-agent DyPE

[Vinyals et al.](https://arxiv.org/pdf/1310.6704) define finite-agent coalition structures as exhaustive disjoint partitions and prove that DyPE optimizes over graph-feasible partitions. Those partition constraints impose discrete allocation requirements.

The present task expressly permits arbitrary nonnegative real frequencies. Its listed compositions and conservation equations therefore give an exact linear program. The classification proved here applies directly to the stated supported-mass model, without requiring a transfer from the finite-agent result.
