The continuous mirror question, as graded

Given a finite ordered shift template \(W\), an integer \(D\), finite worker types \(T\), rational type masses \(\mu_t\), and rational additive values \(a_{t,g}\), consider replications \(W^k\) with \(kD\mu_t\) integral. For each type define \(C_{t,k}=\max_{\mathcal Q}\min_{B\in\mathcal Q}u_t(B)\), over partitions of \(W^k\) into \(kD\) contiguous blocks, and \(\beta_t=\liminf_k C_{t,k}\). Let \(\mathcal P_W\) be the limiting empirical distributions of blocks in such partitions. Can one give a finite or compressed algorithm that outputs masses \(x_{t,b}\ge 0\) with \(\sum_b x_{t,b}=\mu_t\), aggregate block distribution in \(\mathcal P_W\), and \(x_{t,b}>0\Rightarrow u_t(b)\ge\beta_t\)?

Packaged proof task (what the prover saw — nothing else)

Let \(W=(g_1,\ldots,g_m)\) be a nonempty ordered list of indivisible goods, and let \(1\le D\le m\) be an integer. A society is given by its support: the list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Each type has nonnegative rational additive values \(a_{t,j}\), without utility normalization. Let \(L\) be the total input bit length.
Write \(W^k\) for linear concatenation of \(k\) copies, with values repeated periodically. Let \(K=\{k\ge1:kD\mu_t\in\mathbb Z\text{ for every }t\}\). Every partition below covers all of \(W^k\) with exactly \(kD\) nonempty contiguous blocks; cuts may cross copy boundaries, but the endpoints are not identified.
A block type is \(b=(s,\ell)\), where \(1\le s\le m\) is its starting position modulo \(m\) and \(\ell\ge1\) its length; define \(u_t(s,\ell)=\sum_{r=0}^{\ell-1}a_{t,1+((s+r-1)\bmod m)}\).
Define \(C_{t,k}=\max_{\mathcal Q}\min_{B\in\mathcal Q}u_t(B)\) over these partitions, and \(\beta_t=\liminf_{k\to\infty,\,k\in K}C_{t,k}\).
For a partition \(\mathcal Q\), let \(p_{\mathcal Q}(b)\) be the number of its blocks of type \(b\), divided by \(kD\). Let \(\mathcal P_W\) consist of probability distributions \(p\) for which some \(k_i\in K\) tending to infinity and partitions \(\mathcal Q_i\) satisfy \(\sum_b|p_{\mathcal Q_i}(b)-p(b)|\to0\).
An admissible allocation has \(x_{t,b}\ge0\), \(\sum_bx_{t,b}=\mu_t\), \((\sum_tx_{t,b})_b\in\mathcal P_W\), and \(x_{t,b}>0\Rightarrow u_t(b)\ge\beta_t\). Its exact output representation is either a finite list of nonzero rational masses with binary block indices, or rational generating functions \(F_{t,s}(z)=\sum_{\ell\ge1}x_{t,(s,\ell)}z^\ell\), represented by numerator and denominator polynomials with binary rational coefficients.

Is constructing an admissible allocation in this representation solvable in polynomial bit time in \(m,\tau,L,\log D\), or is this construction problem NP-hard?

For finite agents with nonnegative additive values on an ordered goods list, a contiguous allocation meeting every agent’s contiguous maximin share always exists and is computable in polynomial time. The corresponding existence and algorithmic result also holds on trees ([Bouveret et al.](https://www.dominik-peters.de/publications/cakecutting.pdf)); no result settling the exact replicated limiting-distribution problem above was located.

Modeling choices made when packaging the task

  • Values are nonnegative rational goods utilities, as in the discrete definition; no utility normalization is imposed.
  • Masses are positive binary rationals summing to one, so kD is the total replicated population.
  • The template is nonempty and 1 ≤ D ≤ m, ensuring that partitions into kD nonempty blocks exist.
  • Replication means linear concatenation; blocks may cross copy boundaries, and every finite partition allocates all goods.
  • Both the liminf and limiting distributions use replication indices for which every replicated type population is integral.
  • A block is identified by its starting template position and positive integer length, retaining positional distinctions even when goods have equal values.
  • Limiting empirical distributions use total variation convergence on the countable block-type space; no additional convergence of length moments is required.
  • Exact finite outputs use sparse rational masses and binary indices; exact compressed outputs use rational generating functions with explicitly encoded rational polynomial coefficients.

Result

The construction problem is solvable in polynomial bit time in \(m,\tau,L,\log D\). In fact, a finite rational output always suffices: the algorithm returns an admissible allocation supported on block lengths at most \(2m-1\).

The proof has three ingredients:

  • Each benchmark \(\beta_t\) is exactly computable using a finite greedy-transition system.
  • Finite rational limiting distributions admit a characterization by flow conservation and a mean-length inequality.
  • These conditions yield a polynomial-size rational linear program whose feasibility follows from a finite-agent path argument.

1. Replication indices and benchmark candidates

Write each mass in reduced form as \(\mu_t=p_t/q_t\). Define

\[ Q=\operatorname{lcm}_{t\in T}\frac{q_t}{\gcd(q_t,D)}. \]

Then \(K=\{Q,2Q,3Q,\ldots\}\): indeed, \(kD\mu_t\) is integral precisely when \(q_t\) divides \(kD\). Moreover, \(\log Q\leq\sum_t\log q_t\), so \(Q\) has polynomial encoding length, even though its numerical value need not be polynomially bounded.

For each type, put

\[ A_t=\sum_{j=1}^{m}a_{t,j}. \]

Every partition of \(W^k\) into \(kD\) blocks has total type-\(t\) utility \(kA_t\). Consequently,

\[ 0\leq C_{t,k}\leq \frac{A_t}{D}\leq A_t. \]

Define the finite rational set

\[ S_t=\{0\}\cup \left\{u_t(s,\ell): 1\leq s\leq m,\ 1\leq\ell\leq m,\ u_t(s,\ell)\leq A_t/D \right\}. \]

Claim. For every \(k\in K\), \(C_{t,k}\in S_t\).

Proof. The optimum is attained because there are finitely many partitions. Let \(B\) attain the minimum utility in an optimal partition.

If \(C_{t,k}<A_t\), then \(B\) has length less than \(m\): any \(m\) consecutive goods have utility \(A_t\), and nonnegativity implies that every longer block has utility at least \(A_t\). Thus its utility occurs among the listed candidates.

If \(C_{t,k}=A_t\), this value is \(u_t(s,m)\) for every start \(s\). This also covers \(A_t=0\). \(\square\)

Because the sequence takes values in a finite set, its liminf \(\beta_t\) belongs to \(S_t\), and

\[ C_{t,k}\geq\beta_t \quad\text{for all sufficiently large }k\in K. \]

Equivalently, \(\beta_t\) is the largest candidate \(q\in S_t\) for which \(C_{t,k}\geq q\) eventually throughout \(K\).

2. Exact polynomial-time computation of \(\beta_t\)

Fix a type \(t\) and a candidate \(q\in S_t\). Suppress \(t\) from the notation.

For each starting position \(s\), define

\[ h_q(s)=\min\{\ell\in\{1,\ldots,m\}:u_t(s,\ell)\geq q\}. \]

This minimum exists because \(q\leq A_t\). When \(q=0\), it equals \(1\), respecting the requirement that blocks be nonempty.

On the infinite periodic goods list, let

\[ f_q(x)=x+h_q\!\left(1+(x\bmod m)\right), \qquad x\geq0, \]

and define \(x_0=0\), \(x_{i+1}=f_q(x_i)\). Here \(x_i\) is the endpoint of the \(i\)-th greedily chosen block.

2.1. Greedy feasibility

The map \(f_q\) is nondecreasing. To see this, suppose \(x\leq y\). The interval ending at \(f_q(y)\) and starting immediately after \(y\) has utility at least \(q\). The interval starting immediately after \(x\) and ending at the same point contains it, so nonnegativity implies that it also has utility at least \(q\). Therefore \(f_q(x)\leq f_q(y)\).

It follows that

\[ C_{t,k}\geq q \quad\Longleftrightarrow\quad x_{kD}\leq km. \]

For necessity, let \(y_i\) be the endpoints of any qualifying partition, with \(y_0=0\). Minimality gives \(y_i\geq f_q(y_{i-1})\); monotonicity and induction give \(y_i\geq x_i\).

For sufficiency, take the first \(kD-1\) greedy blocks and extend the final greedy block to endpoint \(km\). All blocks remain nonempty, and extension cannot decrease utility.

2.2. Eventual behavior of the greedy system

The next increment depends only on \(x_i\bmod m\). Thus the residue sequence enters a cycle after a transient of length \(a\), with cycle length \(r\), where \(a+r\leq m\).

Set

\[ H=x_{a+r}-x_a. \]

The repeated residue implies that \(H\) is a positive multiple of \(m\). Periodicity gives, for \(0\leq j<r\) and every integer \(v\geq0\),

\[ x_{a+j+vr}=x_{a+j}+vH. \]

Writing \(n=a+j+vr\), we obtain the exact identity

\[ D x_n-mn = D x_{a+j}-m(a+j)+v(DH-mr). \]

Consequently:

  • If \(DH<mr\), every sufficiently large \(k\in K\) satisfies \(x_{kD}\leq km\).
  • If \(DH>mr\), every sufficiently large \(k\in K\) violates that inequality.
  • If \(DH=mr\), feasibility depends on the constant term for the cycle positions visited by \(n=kD\).

To identify those positions, put \(g=\gcd(QD,r)\). Since \(k\in K\), the possible values of \(n\) are the positive multiples of \(QD\). A cycle position \(j\) is visited infinitely often precisely when

\[ g\mid(a+j). \]

This is the usual solvability condition for \(QD h\equiv a+j\pmod r\); every solvable residue has infinitely many positive solutions.

Thus, in the equality case, eventual feasibility throughout \(K\) holds precisely when

\[ D x_{a+j}\leq m(a+j) \quad\text{for every }0\leq j<r \text{ with }g\mid(a+j). \]

This completely decides whether \(C_{t,k}\geq q\) eventually. Testing all \(q\in S_t\) and taking the largest passing candidate computes \(\beta_t\) exactly.

2.3. Complexity and the endpoint issue

There are at most \(m^2+1\) candidates per type. Each transition table is obtained from utility sums over at most \(m\) goods, and cycle detection visits at most \(m\) states. All recorded endpoints are at most \(m^2\). Computing \(\gcd(QD,r)\) uses integers of polynomial encoding length.

All utility sums, candidate comparisons, and integer operations therefore take polynomial bit time.

The equality test is necessary. For example, consider one type with values \(W=(1,2,1)\) and \(D=2\). At threshold \(2\), the greedy endpoints satisfy

\[ x_{2k}=3k+1 \quad\text{for every }k\geq1. \]

Hence threshold \(2\) is infeasible on every linear \(W^k\), despite a periodic cycle having mean length \(3/2=m/D\). Every nonempty block has utility at least \(1\); since the possible bottlenecks are integral and at most \(2\), this instance has \(C_{t,k}=\beta_t=1\).

3. Characterizing finite rational limiting distributions

For a block \(b=(s,\ell)\), define its terminal residue by

\[ e(b)=1+((s+\ell-1)\bmod m). \]

Think of \(b\) as a directed edge from \(s\) to \(e(b)\), with length \(\ell\).

Proposition. A finite-support rational probability distribution \(p\) belongs to \(\mathcal P_W\) if and only if

\[ \sum_{b:\,s(b)=v}p_b = \sum_{b:\,e(b)=v}p_b \quad\text{for every }v\in\{1,\ldots,m\}, \]

and

\[ \sum_b\ell(b)p_b\leq \frac mD. \]

3.1. Necessity

A partition of \(W^k\) describes a residue walk starting at \(1\) and ending at \(1\), because its total length is \(km\). Thus its empirical distribution satisfies flow conservation exactly.

Also, every empirical distribution satisfies

\[ \sum_b\ell(b)p_{\mathcal Q}(b)=\frac{km}{kD}=\frac mD. \]

Under convergence in the prescribed sum of absolute differences, sums against bounded indicator functions converge. Flow conservation therefore passes to the limit.

For any positive integer \(R\),

\[ \sum_b\min\{\ell(b),R\}p_b = \lim_i\sum_b\min\{\ell(b),R\}p_{\mathcal Q_i}(b) \leq \frac mD. \]

Letting \(R\) increase proves the mean-length inequality.

3.2. Sufficiency when \(D<m\)

Put \(c=m/D>1\). Choose a positive integer \(N\) such that every

\[ h_b=Np_b \]

is integral. Form the directed multigraph having \(h_b\) copies of edge \(b\). It is balanced at every vertex.

Each weakly connected component containing edges has an Euler circuit: its underlying graph is connected and every vertex has equal in-degree and out-degree. Choose a starting vertex \(v_i\) for each such component.

Any residue can be reached from any other by a single block of length at most \(m\). For each component, connect residue \(1\) to \(v_i\), traverse an Euler circuit containing \(R h_b\) copies of every component edge, and connect back to \(1\). Concatenating these walks produces a closed walk at \(1\).

Let \(J\) and \(A\) be the total number and total length of connector edges. These are independent of \(R\). Put

\[ H=\sum_b h_b\ell(b)\leq cN. \]

The resulting walk has \(RN+J\) blocks and length \(RH+A\), which is a multiple of \(m\).

Choose an integer \(B\) satisfying

\[ B\geq J+1, \qquad (c-1)B\geq A-J. \]

Let \(k_R\) be the smallest positive multiple of \(Q\) such that \(k_RD\geq RN+B\), and set

\[ \delta_R=k_RD-RN. \]

Then \(B\leq\delta_R<B+QD\). The number of additional blocks required is

\[ n_R=\delta_R-J\geq1. \]

The remaining length is

\[ Z_R=k_Rm-(RH+A) \geq c\delta_R-A \geq\delta_R-J=n_R. \]

It can therefore be partitioned into \(n_R\) nonempty blocks, for example \(n_R-1\) singletons followed by one block containing all remaining goods. We now have a partition of \(W^{k_R}\) into exactly \(k_RD\) blocks.

The prescribed edges constitute exactly \(RN\) of its blocks and have relative distribution \(p\). Thus, for some probability distribution \(r_R\) of the auxiliary blocks,

\[ p_{\mathcal Q_R} = \frac{RN}{k_RD}p + \frac{\delta_R}{k_RD}r_R, \]

and consequently

\[ \sum_b|p_{\mathcal Q_R}(b)-p_b| \leq \frac{2\delta_R}{k_RD} \longrightarrow0. \]

Here \(\delta_R\) is bounded independently of \(R\), while \(k_R\) tends to infinity through \(K\). Hence \(p\in\mathcal P_W\).

These auxiliary blocks need not meet utility thresholds: the definition of \(\mathcal P_W\) uses unrestricted partitions. Their frequency vanishes in the limit.

3.3. Sufficiency when \(D=m\)

Now the mean-length bound is \(1\). Since every length is at least \(1\), \(p\) must be supported on singleton blocks. Flow conservation around the directed residue cycle implies

\[ p_{(s,1)}=\frac1m \quad\text{for every }s. \]

This is exactly the empirical distribution of the singleton partition of every \(W^k\). Thus it belongs to \(\mathcal P_W\). This completes the proposition.

The inequality rather than equality in the characterization is essential: vanishingly few auxiliary blocks can carry a positive fraction of the total length.

4. A finite linear program

Every benchmark satisfies \(\beta_t\leq A_t\). Therefore every block of length at least \(m\) meets every type’s benchmark.

Define a shortening map by

\[ \widehat\ell= \begin{cases} \ell,&\ell<m,\\ m+((\ell-m)\bmod m),&\ell\geq m. \end{cases} \]

It has the following properties:

  • \(1\leq\widehat\ell\leq2m-1\) and \(\widehat\ell\leq\ell\).
  • The block \((s,\widehat\ell)\) has the same terminal residue as \((s,\ell)\).
  • If \(\ell\geq m\), then \(u_t(s,\widehat\ell)\geq A_t\geq\beta_t\).

Consequently, shortening preserves flow conservation and type masses, decreases mean length, and preserves all benchmark requirements.

Let

\[ E=\{(s,\ell):1\leq s\leq m,\ 1\leq\ell\leq2m-1\}, \qquad E_t=\{b\in E:u_t(b)\geq\beta_t\}. \]

Introduce variables \(x_{t,b}\) only for \(b\in E_t\). Consider the rational linear system

\[ x_{t,b}\geq0, \]

\[ \sum_{b\in E_t}x_{t,b}=\mu_t \quad\text{for every }t, \]

\[ \sum_t\sum_{\substack{b\in E_t\\s(b)=v}}x_{t,b} = \sum_t\sum_{\substack{b\in E_t\\e(b)=v}}x_{t,b} \quad\text{for every }v, \]

\[ D\sum_t\sum_{b\in E_t}\ell(b)x_{t,b}\leq m. \]

Every rational feasible point is an admissible allocation. Indeed, its marginal \(p_b=\sum_t x_{t,b}\) is a finite rational probability distribution satisfying the proposition. Hence \(p\in\mathcal P_W\), and every positive variable meets its type’s benchmark.

It remains to prove that this system is nonempty.

5. Feasibility from a finite-agent path argument

The finite tree MMS theorem is established by [Bouveret et al.](https://www.dominik-peters.de/publications/cakecutting.pdf). For the present proof, the following elementary path argument directly covers nonnegative values without normalization.

Lemma. Suppose an ordered list contains at least \(n\) goods. There are \(n\) agents with nonnegative additive values and thresholds \(q_i\). If each agent has a partition of the entire list into \(n\) nonempty contiguous blocks, each worth at least \(q_i\), then there is a contiguous allocation giving every agent utility at least its threshold.

Proof. Induct on \(n\). The assertion for \(n=1\) follows from the hypothesis.

For each agent, find its shortest nonempty prefix worth at least its threshold. Such a prefix exists because the first block of a witnessing partition qualifies. Allocate a shortest of these prefixes to an agent attaining it.

For any remaining agent \(j\), the allocated prefix is contained in the first block of its witnessing partition: its length is at most \(j\)’s shortest qualifying prefix, which is at most the length of that first block.

Delete the allocated prefix. If the first witnessing block has a nonempty remainder, merge that remainder with the second block; otherwise simply discard the first block. This gives a partition of the remaining suffix into \(n-1\) nonempty blocks, all worth at least \(q_j\). The merge cannot reduce the second block’s utility because values are nonnegative.

Apply induction to the remaining agents and suffix. \(\square\)

Now choose a sufficiently large \(k\in K\) that

\[ C_{t,k}\geq\beta_t \quad\text{for every }t. \]

Such a \(k\) exists by Section 1 and finiteness of \(T\).

Create \(kD\mu_t\) agents of each type \(t\), giving \(kD\) agents altogether. Each type has a witnessing partition into \(kD\) blocks worth at least \(C_{t,k}\). The lemma therefore gives a partition of \(W^k\), assigning exactly one nonempty block to each agent, in which every type-\(t\) recipient obtains utility at least \(\beta_t\).

Shorten every assigned block using the map from Section 4. Record each resulting type-labelled frequency, divided by \(kD\).

These rational frequencies satisfy the linear system:

  • Each type receives total mass \(\mu_t\).
  • Shortening preserves each edge’s start and terminal residue, so flow conservation holds.
  • The original total length is \(km\); shortening decreases it, giving mean length at most \(m/D\).
  • Every shortened block still meets its recipient’s benchmark.

Thus the linear program is feasible. The possibly large finite society is used only to prove feasibility; the algorithm never constructs it.

6. Polynomial bit complexity and output

The algorithm is now explicit:

  • Compute \(Q\).
  • Compute every \(\beta_t\) by the candidate-and-cycle procedure.
  • Form the finite linear program.
  • Find a rational feasible point and output its nonzero entries.

The benchmark procedure is polynomial by Section 2. Constructing the sets \(E_t\) requires only polynomially many exact utility comparisons.

The linear program has at most \(\tau m(2m-1)\) variables, \(\tau\) type-mass equations, \(m\) flow equations, and one mean-length inequality. Its coefficients are input masses and integers of magnitude at most \(D(2m-1)\), so their bit lengths are polynomial in \(L,\log m,\log D\).

Its feasible region is nonempty and bounded, since nonnegativity and the type-mass equations imply \(x_{t,b}\leq\mu_t\). Standard exact rational linear programming therefore finds a rational feasible point in polynomial bit time.

For completeness, polynomial output length also follows from vertex bounds. After clearing denominators, all coefficients have polynomial bit length. A vertex is determined by a nonsingular subsystem of active constraints. Cramer’s rule and Hadamard’s determinant bound give polynomial bit lengths for its coordinates.

The returned finite list has polynomially many entries, rational masses of polynomial bit length, and block indices satisfying \(s\leq m\) and \(\ell\leq2m-1\). By Sections 3–5, it is an admissible allocation in the requested exact representation.
