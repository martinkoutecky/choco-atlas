Theorem measurecomp — class: algorithmic

The continuous mirror question, as graded

Given a finite candidate set \(C\), a target \(c\in C\), and a distribution \(\mu\) over \(\tau\) voter types, compute the exact critical endowment \(\omega^*(c;\mu)\) and a type coalition attaining it. Each type specifies a complete ranking and an approval set; let \(D_c\) be the types that disapprove \(c\), and let \(B_R(c)\) be the candidates every type in \(R\subseteq D_c\) strictly ranks above \(c\). With \(\nu(X)=|X|/|C|\), the value is \(\min_{\varnothing\ne R\subseteq D_c}(1-\nu(B_R(c)))/\sum_{t\in R}\mu_t\), or \(\infty\) if \(D_c\) is empty.

Packaged proof task (what the prover saw — nothing else)

Given a nonempty finite candidate set \(C\) with \(m=|C|\) and a target \(c\in C\), a society is given by its support: a list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
Each type specifies a complete transitive ranking, allowing ties, and an approval set \(A_t\) consisting of an initial segment of whole indifference classes; empty and full approval sets are allowed. Write \(d\succ_t c\) for strict preference.
Define \(D_c=\{t:c\notin A_t\}\), \(B_R(c)=\{d\in C:d\succ_t c\text{ for every }t\in R\}\), and \(\nu(X)=|X|/m\). A type coalition \(R\) includes the entire mass of every selected type.
For \(D_c\ne\varnothing\), define \(\omega^*(c;\mu)=\min_{\varnothing\ne R\subseteq D_c}\frac{1-\nu(B_R(c))}{\sum_{t\in R}\mu_t}\). For \(D_c=\varnothing\), set \(\omega^*(c;\mu)=\infty\); no attaining coalition is required in that case. Any minimizing coalition is acceptable when several tie.

Can \(\omega^*(c;\mu)\) and an attaining type coalition be computed exactly in time polynomial in \(m,\tau,L\), or is this problem NP-hard?

For a finite list of \(n\) equally weighted voters and \(m\) candidates, exact critical endowment computation is known to take \(O((mn)^{1+o(1)})\) time. That guarantee concerns an explicitly listed electorate, rather than a support representation with binary-rational masses.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one, matching the discrete normalization by electorate size.
  • Interpreted complete rankings as complete transitive weak orders, allowing ties as in the utility-based discrete definition.
  • Required approval sets to be initial segments of whole indifference classes, preserving consistency with utility thresholds; empty and full approval sets remain admissible.
  • Made type coalitions include whole type masses, as specified by the graded minimization over subsets of types.
  • When there are no disapproving types, retained the infinite value and waived the impossible requirement of an attaining nonempty coalition; otherwise any minimizing coalition may be returned.
  • Defined L as the total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is polynomial-time solvable, including exact computation of an attaining type coalition. Binary-rational masses can be handled directly by an integer-capacity minimum-cut algorithm.

1. Reformulating the objective. If \(D_c=\varnothing\), return \(\infty\); this is exactly the stipulated case. Henceforth assume \(D_c\ne\varnothing\).

For every \(t\in D_c\), define
\[ S_t=\{d\in C:\text{it is not the case that }d\succ_t c\}. \]
Then, for every nonempty \(R\subseteq D_c\), taking complements in the definition of \(B_R(c)\) gives
\[ C\setminus B_R(c)=\bigcup_{t\in R}S_t. \]
Write \(k(R)=|\bigcup_{t\in R}S_t|\). Because strict preference is irreflexive, \(c\in S_t\) for every \(t\), and therefore \(1\le k(R)\le m\).

Represent each input mass as \(\mu_t=p_t/q_t\), with positive integers \(p_t,q_t\), and set
\[ Q=\prod_{t=1}^{\tau}q_t,\qquad w_t=p_t(Q/q_t). \]
These are positive integers, and the normalization of the masses implies \(\sum_t w_t=Q\). Moreover, \(Q\) has \(O(L)\) bits: its bit length is bounded by the sum of the denominator bit lengths, up to an additive constant.

For \(R\subseteq D_c\), let \(W(R)=\sum_{t\in R}w_t\). Thus, for nonempty \(R\),
\[ \frac{1-\nu(B_R(c))}{\sum_{t\in R}\mu_t} =\frac{Q}{m}\frac{k(R)}{W(R)}. \]
Consequently, it suffices to compute
\[ \lambda^*=\min_{\varnothing\ne R\subseteq D_c}\frac{k(R)}{W(R)}. \]

2. An exact minimum-cut oracle. We first construct a polynomial-time procedure that, for any nonnegative rational \(\lambda=a/b\), where \(a\ge0\) and \(b>0\) are integers, decides whether \(\lambda^*<\lambda\).

Let \(W_D=\sum_{t\in D_c}w_t\). Construct a directed network with source \(s\), sink \(z\), one vertex for each type in \(D_c\), and one vertex for each candidate. Its arcs and capacities are:

  • \(s\to t\), with capacity \(a w_t\), for every \(t\in D_c\).
  • \(t\to d\), with capacity \(M=aW_D+bm+1\), whenever \(d\in S_t\).
  • \(d\to z\), with capacity \(b\), for every \(d\in C\).

All capacities are nonnegative integers.

The cut whose source side consists only of \(s\) has capacity \(aW_D<M\). Therefore no minimum cut crosses a capacity-\(M\) arc.

Let \(R\) be the type vertices on the source side of a minimum cut, and let \(U\) be its candidate vertices. The absence of crossed capacity-\(M\) arcs implies
\[ \bigcup_{t\in R}S_t\subseteq U. \]
In fact equality holds. If a candidate in \(U\) belonged to none of the sets \(S_t\) with \(t\in R\), moving that candidate to the sink side would cross no new type-to-candidate arc and would decrease the cut capacity by \(b>0\).

Define \(k(\varnothing)=W(\varnothing)=0\). The minimum-cut value is therefore exactly
\[ aW_D+\min_{R\subseteq D_c}\bigl(bk(R)-aW(R)\bigr). \]
Indeed, the preceding argument establishes this form for a minimum cut; conversely, every \(R\subseteq D_c\) gives a cut of that capacity by choosing its candidate union as the candidate source side.

Since the empty coalition contributes zero, the minimum-cut value is strictly less than \(aW_D\) precisely when some nonempty \(R\) satisfies
\[ bk(R)-aW(R)<0. \]
Because \(W(R)>0\), this is equivalent to \(k(R)/W(R)<a/b\), and hence to \(\lambda^*<\lambda\).

Whenever the oracle answers yes, its minimum cut also supplies a nonempty coalition with ratio strictly below \(\lambda\).

3. Recovering an exact optimum. Every coalition ratio has the form \(k/W\), where \(k\) is an integer and \(1\le W\le Q\). Two distinct such ratios satisfy
\[ \left|\frac{k_1}{W_1}-\frac{k_2}{W_2}\right| =\frac{|k_1W_2-k_2W_1|}{W_1W_2} \ge\frac{1}{Q^2}, \]
because the numerator is a nonzero integer.

Start with \(\ell=0\) and \(h=m+1\). Since every coalition ratio is positive and at most \(m\), initially
\[ \ell\le\lambda^*<h. \]
Perform exact rational bisection. At the midpoint \(x\), use the oracle:

  • If \(\lambda^*<x\), replace \(h\) by \(x\).
  • Otherwise, replace \(\ell\) by \(x\).

The invariant is preserved. After \(O(\log(m+1)+\log Q)\) iterations, the interval satisfies
\[ h-\ell<\frac{1}{Q^2}. \]

Now run the oracle at \(h\) and extract its coalition \(R_h\). Since \(\lambda^*<h\), this coalition is nonempty, and
\[ \lambda^*\le\frac{k(R_h)}{W(R_h)}<h. \]
If its ratio differed from \(\lambda^*\), the separation bound would give a difference of at least \(1/Q^2\). But both ratios lie in \([\ell,h)\), whose width is smaller than that. Thus
\[ \frac{k(R_h)}{W(R_h)}=\lambda^*. \]
Return \(R_h\) and the exact rational value
\[ \omega^*(c;\mu)=\frac{Q\,k(R_h)}{m\,W(R_h)}. \]

4. Bit complexity. The network has \(O(m+\tau)\) vertices and \(O(m\tau+m+\tau)\) arcs. Since \(\log Q=O(L)\), the algorithm makes \(O(L+\log(m+1))\) minimum-cut calls.

After that many bisection steps, each queried dyadic rational has numerator and denominator of \(O(L+\log(m+1))\) bits. The same bound holds for all network capacities, including \(M\).

For completeness, Edmonds–Karp computes a maximum flow and an associated minimum cut in a directed network with nonnegative integer capacities using \(O(VE^2)\) arithmetic operations. Its hypotheses hold here. Flow and residual-capacity values have polynomial bit length, so its arithmetic operations also take polynomial bit time. Constructing the sets, scaling the masses, performing bisection, and evaluating the returned ratio likewise take polynomial time.

Therefore the entire computation is polynomial in \(m,\tau,L\). It never expands a type into individual voters, so the possibly enormous denominator of a binary-rational mass does not create an enormous electorate.
