The continuous mirror question, as graded

Given a finite FEN role template \(R\) with the paper’s preference ballots and within-cell dependency links, consider a nonatomic unit mass of cells, each containing one agent of every role in \(R\), with agents in other cells neutral. For each partition \(P\) of \(R\), let \(\lambda_P\) be the mass of cells assigned \(P\). Does there exist \(\lambda_P \ge 0\), with \(\sum_P \lambda_P=1\), such that every partition with \(\lambda_P>0\) is Nash-stable under the paper’s preferences?

Packaged proof task (what the prover saw — nothing else)

Let \(R\) be a nonempty set of \(m\) roles. Each role \(i\) specifies disjoint friend and enemy sets \(F_i,E_i\subseteq R\setminus\{i\}\), with \(|F_i\cup E_i|\le d\) for a fixed constant \(d\), and a weak order on each set; \(\triangleright_i\) denotes strict preference. Links are directed, and all unlisted roles are neutral.
For a coalition \(C\) containing \(i\), define dissatisfaction by \(\delta_i(C)=\sum_{f\in F_i\setminus C}(1+|\{b\in F_i:f\triangleright_i b\}|)+\sum_{b\in E_i\cap C}(1+|\{f\in E_i:f\triangleright_i b\}|)\). Lower dissatisfaction is preferred; equal values remain tied.
The society consists of a nonatomic unit mass of cells, each containing one agent of every role. Links connect only agents in the same cell; agents in different cells are neutral. A society is given by its support: the list of its \(\tau\) positive-mass types, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here the types are the labeled roles, each of mass \(1\), so \(\tau=m\) and total agent mass is \(m\).
An allocation assigns each cell a partition \(P\) of \(R\) into nonempty blocks. Write \(P(i)\) for the block containing \(i\). Call \(P\) Nash-stable if \(\delta_i(P(i))\le\delta_i(B\cup\{i\})\) for every \(i\) and every \(B\in P\cup\{\varnothing\}\). Thus deviations include forming a singleton and require no consent.
Let \(\lambda_P\in\mathbb R_{\ge0}\) be the mass of cells assigned \(P\). The decision problem asks whether \(\sum_P\lambda_P=1\) and every \(P\) with \(\lambda_P>0\) is Nash-stable. Partitions and allocation masses are not supplied as input. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\), with the fixed degree bound \(d\) explicit.

Is this continuous allocation-existence problem solvable in polynomial time, or is it NP-hard?

Discrete Nash-stable partition existence under these preferences is NP-complete, even with at most six known neighbors per agent. [Rey and Rey (2022)](https://arxiv.org/pdf/2201.13158)
No result settling exactly this nonatomic cell-allocation problem was identified in the literature search.

  • Interpreted labeled roles as the society's supported agent types, each with mass one: unit cell mass therefore gives total agent mass m, rather than unit agent mass.

Result

The problem is \(\mathrm{NP}\)-complete already for the fixed degree bound \(d=6\). The same holds for every fixed \(d\ge 6\). Thus, unless \(\mathrm{P}=\mathrm{NP}\), nonatomic allocation does not yield a polynomial-time algorithm for the stated class.

The proof uses the supplied discrete hardness theorem and an exact equivalence between discrete and continuous existence. It does not assert hardness for every smaller degree bound.

1. Allocation existence is equivalent to partition existence

Let \(\mathcal P(R)\) be the set of all partitions of \(R\), and let
\[ \mathcal S=\{P\in\mathcal P(R):P\text{ is Nash-stable}\}. \]
Both sets are finite because \(R\) is finite.

Proposition. A feasible allocation exists if and only if \(\mathcal S\ne\varnothing\).

Proof. Suppose an allocation \((\lambda_P)_{P\in\mathcal P(R)}\) is feasible. Its entries are nonnegative and sum to \(1\). Consequently, at least one partition \(P_*\) has \(\lambda_{P_*}>0\). The feasibility condition then requires \(P_*\) to be Nash-stable, so \(\mathcal S\ne\varnothing\).

Conversely, suppose \(P_*\in\mathcal S\). Set
\[ \lambda_{P_*}=1,\qquad \lambda_P=0\quad\text{for }P\ne P_*. \]
These masses satisfy every allocation constraint. They are realized by assigning \(P_*\) to every cell. Each cell contains one agent of each role, so this assignment uses the entire unit mass of every role. \(\square\)

In particular, every feasible instance has a feasible allocation supported on one partition, with rational mass \(1\). Arbitrary real allocation masses create no additional existence possibilities.

2. Polynomial verification of a certificate

A certificate specifies one partition. Encode it by a function
\[ p:R\longrightarrow\{1,\ldots,m\}, \]
where equal labels identify agents in the same block. The nonempty fibers of any such function form a partition. Its encoding requires \(O(m\log(m+1))\) bits.

Define the positive weights
\[ a_{if}=1+|\{g\in F_i:f\triangleright_i g\}|, \qquad b_{ie}=1+|\{g\in E_i:g\triangleright_i e\}|. \]
Also define
\[ A_i=\sum_{f\in F_i}a_{if}, \qquad u_i(C)= \sum_{f\in F_i\cap C}a_{if} - \sum_{e\in E_i\cap C}b_{ie}. \]
Expanding the given dissatisfaction formula gives
\[ \delta_i(C)=A_i-u_i(C). \]
Thus lower dissatisfaction is exactly equivalent to higher \(u_i\), including ties.

The weights can be computed by comparing all pairs within each listed set, using \(O(m(d+1)^2)\) operations. Every weight is at most \(\max\{1,d\}\), and every utility has absolute value at most \(d^2\).

For each role \(i\), compute its current utility
\[ v_i=u_i(P(i)). \]
A singleton has utility \(0\), so reject if \(v_i<0\).

It remains to check possible destination blocks. Only blocks containing a friend of \(i\) need explicit examination. Indeed, if \(B\cap F_i=\varnothing\), then
\[ u_i(B\cup\{i\})=-\sum_{e\in E_i\cap B}b_{ie}\le 0\le v_i. \]
Such a block cannot give a strictly improving deviation. There are at most \(|F_i|\le d\) distinct blocks containing friends. For each, compute its destination utility by scanning the at most \(d\) listed neighbors, and reject precisely when that utility exceeds \(v_i\).

These checks cover every allowed deviation: the singleton, every block containing a friend, and all remaining blocks by the displayed inequality. Therefore acceptance is equivalent to Nash stability.

On a word RAM with words large enough for input addresses and role labels, certificate verification takes
\[ O\bigl(L+m(d+1)^2\bigr) = O\bigl(L+\tau(d+1)^2\bigr), \qquad \tau=m. \]
All arithmetic uses integers of \(O(\log(d+2))\) bits, and labels use \(O(\log(m+1))\) bits, so the verification also has polynomial bit complexity.

By the proposition, this finite certificate proves membership of the continuous problem in \(\mathrm{NP}\).

3. Hardness reduction and hypothesis checks

The supplied discrete theorem states that Nash-stable partition existence is \(\mathrm{NP}\)-complete for these preferences even with at most six known neighbors. In the cited paper, Proposition 4 gives the dissatisfaction characterization used here, and Theorem 21 establishes discrete existence hardness with degree bound \(6\). Its model allows directed links, neutral unlisted players, and indifferences. [Rey and Rey, *FEN-Hedonic Games with Distance-Based Preferences*](https://arxiv.org/pdf/2201.13158).

Given an instance of that discrete problem with \(m\) players, construct the continuous instance as follows:

  • Make each player a distinct labeled role.
  • Copy its friend set, enemy set, and weak orders without alteration.
  • Specify a unit mass of cells, each containing one agent of every role.
  • List the \(m\) role types, each with binary rational mass \(1\).

This is a polynomial-time construction. It copies the preference data and adds \(m\) support records; its output length and construction time are \(O(L_{\mathrm{disc}}+m\log(m+1))\). The resulting support size is exactly \(\tau=m\), and the degree bound remains \(6\).

For every partition, each role’s dissatisfaction and every deviation comparison are unchanged. Hence the discrete instance has a Nash-stable partition if and only if the constructed instance has one. By Section 1, this is equivalent to feasible allocation existence.

The reduction therefore establishes \(\mathrm{NP}\)-hardness at fixed \(d=6\). Such instances also satisfy every larger fixed degree bound. Together with Section 2, this proves the claimed \(\mathrm{NP}\)-completeness.

4. Explicit deterministic upper bound

For completeness, enumerate all \(m^m\) block-label functions and apply the verifier above. Every partition appears among these functions, although some appear repeatedly. Preprocessing the input and weights once gives running time
\[ O\bigl(L+m^m\,m(d+1)^2\bigr) = O\bigl(L+\tau^\tau\,\tau(d+1)^2\bigr), \qquad \tau=m. \]

The complexity obstruction is finding a stable partition; once one is found, assigning it mass \(1\) completes the allocation.
