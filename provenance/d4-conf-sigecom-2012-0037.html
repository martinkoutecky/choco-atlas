The continuous mirror question, as graded

Given a finite candidate set \(C\), a finite set \(T\) of complete ranking types over \(C\), a rational distribution \(\mu\) on \(T\), and an integer \(k\), does there exist a sequence of valid declonings whose pushforward distribution \(\delta_{\#}\mu\) is single-crossing—its positive-mass types admitting an order in which every pairwise preference is a prefix or suffix—and whose resulting candidate set \(C'\) satisfies \(|C'|\ge k\)?

Packaged proof task (what the prover saw — nothing else)

Given a nonempty candidate set \(C\), let \(m=|C|\). A society is given by its support: a list \(T\) of \(\tau\) distinct strict complete ranking types, each with positive binary-rational mass \(\mu(t)\), with \(\sum_{t\in T}\mu(t)=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(k\ge1\) be a binary-encoded integer and \(L\) the total input bit length; state running times in \(m,\tau,L\), and \(k\).
At any stage, a clone set is a nonempty subset of the current candidates that forms a contiguous block in every positive-mass ranking. A valid decloning replaces such a block by one fresh candidate in every ranking; all other relative preferences remain unchanged. Any clone set is eligible, including the entire candidate set and sets that overlap other clone sets.
A finite sequence, possibly empty, induces a ranking map \(\delta\) and final candidate set \(C'\). Its pushforward is \((\delta_{\#}\mu)(r)=\sum_{t:\delta(t)=r}\mu(t)\), so coinciding output rankings have their masses added. Each move acts uniformly on all mass.
The output is single-crossing if its distinct positive-mass rankings admit a linear order in which, for every distinct \(a,b\in C'\), the rankings preferring \(a\) to \(b\) form a prefix or suffix, possibly empty or the whole order. This order is not supplied.

Is deciding whether some valid decloning sequence yields a single-crossing distribution with \(|C'|\ge k\) solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For explicitly listed finite voters, this decision problem is \(\mathrm{NP}\)-complete; with the voter order fixed, it is polynomial-time solvable. [Verified results](https://home.agh.edu.pl/~faliszew/decloning.pdf).
No result addressing exactly the distribution-input problem above was located in the literature search.

Modeling choices made when packaging the task

  • Specified strict complete rankings, a nonempty candidate set, normalized positive rational support masses, and a positive binary-encoded threshold.
  • Defined valid decloning using contiguity in every current positive-mass ranking, without restricting eligibility to clone sets disjoint from all other clone sets.
  • Allowed an empty sequence and decloning of the entire candidate set, consistent with the discrete operation.
  • Specified uniform action on all mass and addition of masses when output rankings coincide.
  • Specified that the witnessing order is chosen freely over distinct output support rankings and that empty and whole prefixes or suffixes are permitted.
  • Defined L as the total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete. The hardness for explicitly listed voters transfers to the stated distribution model because clone eligibility and single-crossing feasibility depend only on the support, not on positive masses or ranking multiplicities.

The boundary cases are immediate: if \(k=1\), collapsing the entire candidate set gives a yes-instance; if \(k>m\), no decloning can leave sufficiently many candidates. The proof below settles the general problem.

1. Support and multiplicity invariance

For a finite list of rankings \(R\), let \(\operatorname{supp}(R)\) denote its set of distinct rankings.

Lemma 1. A candidate subset is a clone set for \(R\) if and only if it is a clone set for \(\operatorname{supp}(R)\). Moreover, \(R\) admits a single-crossing voter order if and only if its distinct rankings admit a single-crossing order.

Proof. Clone eligibility requires contiguity in every ranking. Repeating a ranking neither adds nor removes a contiguity constraint.

For single-crossingness, fix a candidate pair. Along an order of rankings, the pair’s comparison is a binary sequence. Its preferred side forms a prefix or suffix exactly when this sequence changes value at most once.

Suppose first that \(R\) has a single-crossing order. Retain one occurrence of each distinct ranking, preserving their order. A subsequence of a binary sequence with at most one change also has at most one change. The resulting order therefore witnesses single-crossingness of \(\operatorname{supp}(R)\).

Conversely, order the distinct rankings in a single-crossing order and replace each ranking by a consecutive group containing all its occurrences in \(R\). Repeating a binary value consecutively creates no additional changes. This gives a single-crossing order of all voters. \(\square\)

Lemma 2. For any ranking map \(\delta\) induced by valid decloning, the positive-mass support of the pushforward distribution is exactly \(\delta(T)\). Consequently, whether the output is single-crossing is independent of the particular positive masses on \(T\).

Proof. For every output ranking \(r\),

\( (\delta_{\#}\mu)(r)=\sum_{t\in T:\,\delta(t)=r}\mu(t). \)

Every summand is positive. Thus the sum is positive exactly when its indexing set is nonempty, which is equivalent to \(r\in\delta(T)\).

Move eligibility also depends only on the current support. Indeed, contiguity is required in every positive-mass ranking, and merging coincident rankings does not change that requirement. Inductively, changing the positive masses preserves every valid sequence and its output support. \(\square\)

In particular, output collisions cause no difficulty: merging their masses preserves precisely the set relevant to single-crossingness.

2. Every sequence has a partition certificate

A partition \(\mathcal P=\{B_1,\ldots,B_q\}\) of \(C\) is a clone partition if every block \(B_i\) is contiguous in every original ranking. Its quotient ranking replaces each block by its label.

Lemma 3. Up to candidate renaming, the outputs obtainable by arbitrary finite valid decloning sequences are exactly the quotients by clone partitions of the original candidate set.

Proof. Track the original candidates represented by each current candidate.

Initially, each current candidate represents its singleton. Maintain the following invariant: these represented sets partition \(C\), each is contiguous in every original ranking, and each current ranking is obtained by replacing those original blocks by their current representatives.

Suppose a move contracts a current clone set \(D\). Its new representative corresponds to the union \(B\) of the original blocks represented by the members of \(D\). In every current ranking, the members of \(D\) occur consecutively. Expanding their represented blocks therefore shows that \(B\) occurs consecutively in the corresponding original ranking. The contraction preserves the invariant.

At termination, the represented sets consequently form a clone partition, and the output is its quotient.

Conversely, let \(\mathcal P\) be a clone partition. Contract its nonsingleton blocks in any order. A remaining block stays contiguous: contracting another, disjoint block removes no member of it and inserts no candidate between its members. Every contraction is therefore valid, and the resulting rankings are the quotient rankings. Singleton representatives can be renamed without affecting any comparison. \(\square\)

This argument includes the entire candidate set and arbitrary overlapping choices during a sequence. No restriction to a prescribed hierarchy of clone sets is needed.

3. Polynomial reduction from explicitly listed voters

We use the following supplied finite-profile theorem:

Given an explicitly listed profile of strict complete rankings and a positive threshold \(k\), deciding whether decloning can produce a single-crossing profile with at least \(k\) candidates is \(\mathrm{NP}\)-complete.

This is Theorem 6.4 of Elkind, Faliszewski, and Slinko. Their decloning operation replaces any clone block by a fresh candidate, including clone sets that are not supports of hierarchical subfamilies; their Definition 6.1 uses existence of a voter order with the same prefix-or-suffix condition as here. Thus the theorem’s hypotheses match the finite-profile version needed below. [Clone Structures in Voters’ Preferences, pp. 8, 11, and 27](https://home.agh.edu.pl/~faliszew/decloning.pdf)

Take a source instance with nonempty explicitly listed profile \(R=(R_1,\ldots,R_n)\), candidate set \(C\), and threshold \(k\). Remove duplicate rankings to obtain \(T=\{t_1,\ldots,t_\tau\}\), where \(\tau\le n\).

We assign positive dyadic masses, so the construction works even if “binary-rational” is interpreted as requiring a power-of-two denominator. Set

\(h=\lceil\log_2\tau\rceil,\qquad D=2^h.\)

Define

\(\mu(t_i)=1/D\quad\text{for }1\le i<\tau,\qquad \mu(t_\tau)=(D-\tau+1)/D.\)

Since \(D\ge\tau\), every mass is positive. Their sum is

\(\sum_{i=1}^{\tau}\mu(t_i)=((\tau-1)+(D-\tau+1))/D=1.\)

For \(\tau=1\), this simply assigns mass \(1\).

We retain the same candidate set and threshold \(k\).

Correctness. By Lemma 1, the original profile and its support have identical clone constraints. By Lemma 2, assigning positive masses does not change move eligibility at any stage. Hence a sequence is valid in the source instance exactly when it is valid in the constructed distribution instance.

For any such sequence, the finite output profile has distinct-ranking support \(\delta(T)\), and the distribution output has the same positive-mass support. Lemma 1 says that the finite output is single-crossing exactly when this support is single-crossing. Both outputs also have the same number of candidates. Therefore,

\((C,R,k)\text{ is a yes-instance}\quad\Longleftrightarrow\quad (C,T,\mu,k)\text{ is a yes-instance}.\)

Size and running time. Deduplication can be performed by lexicographically sorting the \(n\) length-\(m\) rankings, using \(O(nm\log(n+1))\) comparisons of candidate identifiers. Every constructed mass uses \(O(\log(\tau+1))\) bits. With candidates indexed by integers, the output length is

\(O\!\left(\tau m\log(m+1)+\tau\log(\tau+1)+\log(k+1)\right).\)

The construction is polynomial in the source input length and uses no iteration proportional to the numeric value of \(k\). It is therefore a polynomial-time many-one reduction, proving \(\mathrm{NP}\)-hardness.

4. Membership in \(\mathrm{NP}\)

A certificate consists of:

  • A partition \(\mathcal P=\{B_1,\ldots,B_q\}\) of \(C\), with \(q\ge k\).
  • A permutation of the \(\tau\) input ranking types, interpreted as an order of their quotient rankings.

The quotient rankings in this second component may coincide.

The verifier performs the following checks.

Partition and eligibility. Check that every candidate belongs to exactly one nonempty block. For each input ranking, replace each candidate by its block label and check that every label appears in one contiguous run. This is exactly the condition that every partition block is a clone set.

Quotient construction. Replace each run by one occurrence of its label. Each resulting row is a strict complete ranking of the \(q\) blocks.

Single-crossing order. Check that the certificate lists every input type exactly once. For every distinct pair of block labels, scan their comparison along that order and reject if it changes more than once.

If these checks pass, Lemma 3 supplies a valid decloning sequence. By Lemma 1, deleting repeated quotient rankings preserves single-crossingness, and Lemma 2 identifies the remaining rankings with the output distribution’s support. Thus acceptance is sound.

Conversely, any successful sequence gives a clone partition by Lemma 3. Order its distinct output rankings in a single-crossing order, and place all input types yielding the same output ranking consecutively. This supplies a certificate that passes every check. Thus the verifier is complete.

The certificate has length

\(O\!\left(m\log(m+1)+\tau\log(\tau+1)\right).\)

After indexing candidates and constructing quotient positions, verification uses \(O(\tau m+\tau q^2)\) elementary operations. Including input reading, its running time is

\(O(L+\tau m^2)\)

on a word-RAM with \(O(\log(L+2))\)-bit index words; it is polynomial in the bit model as well. The threshold is handled by binary comparison, so dependence on \(k\) is through its encoding length, already included in \(L\).

Conclusion

The stated distribution-input problem is \(\mathrm{NP}\)-complete, even when all masses are positive dyadic rationals sharing a denominator at most \(2\tau\). The reduction handles both merged output rankings and unrestricted valid decloning sequences.
