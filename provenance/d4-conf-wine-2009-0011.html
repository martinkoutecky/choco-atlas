The continuous mirror question, as graded

Given fixed sites \(V\), a connected set of corridor types \(T\subseteq {V\choose 2}\), and positive rational masses \(\mu_t\) summing to \(1\), form \(G_N\) with \(N\mu_t\) parallel edges of type \(t\), for integers \(N\) making all multiplicities integral. In the spanning-connectivity game on \(G_N\), let \(\nu_N(e)\) be the nucleolus allocation to an edge of type \(t\). Do the limits \(a_t=\lim_{N\to\infty}N\nu_N(e)\) exist for every type, and can their exact values be computed in time polynomial in \(|V|,\tau,L\), where \(\tau=|T|\) and \(L\) is the mass encoding length?

Packaged proof task (what the prover saw — nothing else)

Let \(V\) be a set of \(m\geq 3\) sites and let \(T\subseteq\binom{V}{2}\) satisfy that \((V,T)\) is connected.
A society is given by its support: the list of the \(\tau=|T|\) corridor types with positive masses \(\mu_t\), each encoded as a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total mass encoding length.
For each positive integer \(N\) with all \(N\mu_t\) integral, let \(G_N=(V,E_N)\) be the undirected, unweighted multigraph having \(N\mu_t\) distinct parallel edges of type \(t\).
The players are \(E_N\); a coalition \(S\subseteq E_N\) has value \(v_N(S)=1\) exactly when \((V,S)\) is connected, and otherwise has value zero. Allocations satisfy \(x_e\geq 0\) and \(\sum_{e\in E_N}x_e=1\).
Let \(\nu_N\) be the standard nucleolus of this game and let \(\nu_N(t)\) denote its common allocation to edges of type \(t\), which are interchangeable. Limits are along all admissible integers \(N\); equivalently, use the tail with \(N\mu_t\geq 2\) for every type, where \(G_N\) has no bridges.

Do all limits \(a_t=\lim_{N\to\infty}N\nu_N(t)\) exist as finite rational numbers, and, if so, is computing \((a_t)_{t\in T}\) exactly polynomial-time in \(m,\tau,L\), or is it NP-hard?

For explicitly represented connected graphs without bridges, the discrete nucleolus has a layer formula and is computable in time polynomial in the number of vertices and edges ([Aziz, Lachish, Paterson and Savani, 2009](https://arxiv.org/pdf/0909.5293v2)).
No result settling this precise mass-limit problem was located in the literature search.

Modeling choices made when packaging the task

  • The number of sites was unspecified; imposed at least three sites, as required by the discrete spanning-connectivity definition.
  • Specified that each parallel edge is a distinct player and that a coalition wins precisely when it connects all sites, with total allocation normalized to one.
  • Made the limiting sequence explicit as all positive integers giving integral multiplicities; the equivalent tail with every multiplicity at least two carries the anchor's no-bridge condition without restricting the support graph.
  • Interpreted exact output as binary rational values and therefore included rationality of the limits in the existence question.

2. A replication-independent least-core polytope

Write \(H=(V,T)\), and let \(\mathcal B\) be its family of spanning trees. For \(a\in\mathbb R_{\geq 0}^{T}\), define

\(w(a)=\min_{B\in\mathcal B}\sum_{t\in B}a_t.\)

Define the compact polytope

\(\Delta_\mu=\{a\in\mathbb R_{\geq 0}^{T}:\sum_{t\in T}\mu_ta_t=1\},\)

the number

\(c=\max_{a\in\Delta_\mu}w(a),\)

and its optimal face

\(P=\{a\in\Delta_\mu:\sum_{t\in B}a_t\geq c\text{ for every }B\in\mathcal B\}.\)

These definitions involve only the support and masses. Compactness follows from \(0\leq a_t\leq 1/\mu_t\). Moreover, \(a_t=1\) for every \(t\) is feasible and has \(w(a)=m-1\), so \(c>0\).

For a nonnegative allocation \(x\) on \(G_N\), every winning coalition contains a spanning tree. Consequently, its minimum winning-coalition allocation equals

\(M_N(x)=\min_{F\text{ spanning tree of }G_N}\sum_{e\in F}x_e.\)

Using the convention \(e_x(S)=v_N(S)-x(S)\), losing coalitions have nonpositive excess. Winning coalitions have maximum excess \(1-M_N(x)\), which is nonnegative. Hence the least core consists exactly of allocations maximizing \(M_N(x)\). Since \(m\geq 3\), every singleton has value zero, so the allocation domain in the question is precisely the usual imputation domain.

Lemma: every least-core allocation is constant within each type

Let \(x\) maximize \(M_N\), and put

\(b_t=\min\{x_e:e\text{ has type }t\}.\)

A spanning tree contains at most one edge of any type. Conversely, each support spanning tree can be realized using a minimum-allocation copy of each of its types. Therefore

\(M_N(x)=\min_{B\in\mathcal B}\sum_{t\in B}b_t.\)

Give every copy of type \(t\) allocation \(b_t\), obtaining \(y\), and set \(s=\sum_e y_e\). Then \(y\leq x\), \(s\leq 1\), and \(M_N(y)=M_N(x)\).

The uniform allocation has minimum spanning-tree allocation \((m-1)/N>0\), so \(M_N(x)>0\) and \(s>0\). If any parallel copies have unequal allocations, then \(s<1\), and the normalized allocation \(y/s\) satisfies

\(M_N(y/s)=M_N(x)/s>M_N(x),\)

contradicting optimality. Thus every type receives a common per-edge allocation. \(\square\)

Now write that common allocation as \(x_e=a_t/N\). Normalization becomes

\(\sum_{e\in E_N}x_e=\sum_{t\in T}N\mu_t(a_t/N)=\sum_{t\in T}\mu_ta_t=1,\)

and

\(M_N(x)=w(a)/N.\)

It follows that, for every admissible \(N\), the entire least core is precisely

\(C_N=\{x:x_e=a_t/N\text{ for type }t,\ a\in P\},\)

and its maximum minimum spanning-tree allocation is \(c/N\).

3. The discrete structural theorem used

The following combines Definition 7, Theorem 3, Definition 13, Theorem 5, and Proposition 6 of [Aziz, Lachish, Paterson and Savani](https://arxiv.org/pdf/0909.5293v2).

For a connected undirected unweighted multigraph with at least three vertices and no bridges, let \(C\) be its least core. Let \(D\) contain the edges assigned zero throughout \(C\). Partition the remaining edges by the equivalence relation

\(e\sim f\quad\Longleftrightarrow\quad x_e=x_f\text{ for every }x\in C.\)

These are the nondegenerate prime-partition blocks. There is a partial order on these blocks such that \(C\) consists exactly of normalized nonnegative vectors that vanish on \(D\), are constant on each block, and satisfy \(x_B\geq x_C\) whenever \(B\) precedes \(C\).

Let \(h(B)\) be the maximum number of blocks in a chain starting at \(B\), so sinks have height one. The nucleolus assigns

\(\nu(e)=\dfrac{h(B)}{\sum_C h(C)|C|}\quad(e\in B),\)

and zero on \(D\).

All hypotheses hold for the tail in the question: connectivity is inherited from \(H\), and when every type has at least two copies, removing any individual edge leaves its endpoints joined by another parallel edge. Thus \(G_N\) has no bridges.

4. Recovering the partition and order from \(P\)

Define

\(T_0=\{t\in T:a_t=0\text{ for every }a\in P\}.\)

On \(T\setminus T_0\), define

\(t\sim u\quad\Longleftrightarrow\quad a_t=a_u\text{ for every }a\in P.\)

Let \(\mathcal Q\) be the resulting set of classes. For \(B\in\mathcal Q\), write \(a_B\) for its common coordinate and

\(\mu(B)=\sum_{t\in B}\mu_t>0.\)

The correspondence between \(P\) and \(C_N\) shows that the degenerate edges of \(G_N\) are exactly the copies of types in \(T_0\), and its nondegenerate prime blocks are exactly the unions of copies of classes \(B\in\mathcal Q\). Their cardinalities are

\(|B_N|=N\mu(B).\)

In particular, the partition is independent of \(N\).

For distinct classes \(B,C\), define a relation using only \(P\):

\(B\succ C\quad\Longleftrightarrow\quad a_B\geq a_C\text{ for every }a\in P.\)

We next verify that this relation is exactly the reachability relation of the discrete theorem’s order.

If \(B\) precedes \(C\) along a chain, the theorem’s inequalities imply \(a_B\geq a_C\) throughout \(P\).

Conversely, suppose there is no chain from \(B\) to \(C\). Let \(U\) consist of \(C\) and all its ancestors in the discrete order. Then \(B\notin U\). Set

\(y_A=1\text{ for }A\in U,\qquad y_A=0\text{ for }A\notin U,\)

and set all coordinates in \(T_0\) to zero.

This vector satisfies every order inequality: if a child belongs to \(U\), its parent also belongs to \(U\). Normalize it by

\(a_t=\dfrac{y_{[t]}}{\sum_{A\in U}\mu(A)}\quad(t\notin T_0),\qquad a_t=0\quad(t\in T_0).\)

The denominator is positive. By the theorem’s exact characterization of the least core, this normalized vector belongs to \(P\). But it has \(a_B=0<a_C\), so \(B\succ C\) fails.

Thus \(\succ\) recovers the discrete reachability relation exactly. In particular, the order and its heights are independent of \(N\).

Define

\(h(B)=1+\max\{h(C):B\succ C\},\)

with the maximum of an empty set equal to zero. Set \(h_t=h([t])\) outside \(T_0\), and \(h_t=0\) on \(T_0\). There is at least one nondegenerate class because every point of \(P\) has weighted sum one. Hence

\(Z=\sum_{t\in T}\mu_th_t>0.\)

Applying the discrete layer formula gives, for every admissible \(N\) in the tail,

\(\nu_N(t)=\dfrac{h_t}{\sum_{B\in\mathcal Q}h(B)|B_N|} =\dfrac{h_t}{NZ}.\)

Consequently,

\(\boxed{a_t=\lim_{N\to\infty}N\nu_N(t)=\dfrac{h_t}{\sum_{u\in T}\mu_uh_u}.}\)

This proves exact constancy on the tail. Since the heights are integers and the masses are rational, every \(a_t\) is finite and rational.

5. Exact polynomial-time computation

It remains to compute \(P\), its universal equalities, and its universal order inequalities without expanding \(G_N\).

Computing the optimal value

Compute \(c\) by the linear program

\(\max z,\)

subject to

\(a_t\geq 0,\qquad \sum_t\mu_ta_t=1,\qquad z\geq 0,\)

and

\(\sum_{t\in B}a_t\geq z\qquad(B\in\mathcal B).\)

Although there can be exponentially many tree constraints, they have a polynomial-time strong separation oracle. After checking the explicit constraints, compute a minimum spanning tree of \(H\) with edge weights \(a_t\). If its weight is below \(z\), its incidence vector supplies a violated constraint; otherwise all tree constraints hold.

The same oracle works for optimization over \(P\), replacing \(z\) by the computed value \(c\).

For completeness, the rational-polyhedron hypotheses needed for exact optimization are satisfied. Put \(\mu_{\min}=\min_t\mu_t\). Every feasible point obeys

\(0\leq a_t\leq 1/\mu_{\min},\qquad 0\leq z\leq (m-1)/\mu_{\min}.\)

These bounds have polynomial encoding length. Every constraint row has polynomial encoding length: tree coefficients are zero or one, and the remaining coefficients are the input masses. Cramer’s rule applied to a vertex-defining subsystem of at most \(\tau+1\) independent rows gives a polynomial bound on vertex encoding length, including the encoding length of \(c\). After fixing \(c\), the same bounds apply to \(P\).

Therefore the exact strong separation–optimization theorem for well-described rational polyhedra applies, including when the optimal face has lower dimension. It yields polynomial-time exact optimization for these LPs. See Grötschel, Lovász and Schrijver, [*Geometric Algorithms and Combinatorial Optimization*, the chapters on rational polyhedra](https://link.springer.com/book/10.1007/978-3-642-78240-4).

Computing the partition and order

Perform the following exact optimizations over \(P\):

  • For each \(t\), compute \(\max_{a\in P}a_t\). The type belongs to \(T_0\) exactly when this maximum is zero.
  • For each pair \(t,u\), compute the minimum and maximum of \(a_t-a_u\). The types are equivalent exactly when both values are zero.
  • For representatives of distinct nondegenerate classes \(B,C\), compute \(\min_{a\in P}(a_B-a_C)\). Then \(B\succ C\) exactly when this minimum is nonnegative.

There are \(O(\tau^2)\) such LPs. All comparisons are exact rational comparisons. Compute the heights in the resulting acyclic order, then return \(h_t/Z\).

Finally, \(0\leq h_t\leq |\mathcal Q|\leq\tau\). If \(\mu_t=p_t/q_t\), a common denominator \(Q=\prod_tq_t\) has encoding length at most \(L\), and

\(Z=\dfrac{\sum_t h_tp_t(Q/q_t)}{Q}.\)

Thus the returned rational numbers also have polynomial encoding length.

The complete algorithm is polynomial in \(m,\tau,L\), and never constructs any \(G_N\).
