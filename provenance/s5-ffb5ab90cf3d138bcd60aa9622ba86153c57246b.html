The continuous mirror question, as graded

Given a finite item set, respondent types \(\Theta\) with rational masses \(\mu_\theta\), item assignments, and an explicitly represented finite-state model specifying each type's beliefs about its binary signal and the resulting per-item report shares, is truthful play a strict Bayesian Nash equilibrium of the nonatomic top-flop game? Each respondent observes \(T\in\{0,1\}\), chooses top or flop, and ratings are per-capita shares of reports equal to \(1\).

Packaged proof task (what the prover saw — nothing else)

There are \(m\geq2\) items, labeled \(1,\ldots,m\). A nonatomic society is given by its support: the list of \(\tau\) respondent types with positive masses \(\mu_\theta\), each a binary rational; \(\tau\) is the support size, not the number of possible types. Each type has an assigned item \(\ell_\theta\), and \(\sum_{\theta:\ell_\theta=k}\mu_\theta=1/m\) for every item \(k\).
An explicitly listed state space \(\Omega\), of size \(s\), specifies binary-rational fractions \(x_\theta(\omega)\in[0,1]\) of each type receiving signal \(1\). Each type has an explicitly tabulated subjective joint probability distribution \(P_\theta\) on \(\Omega\times\{0,1\}\), with \(P_\theta(T=t)>0\) for both signals; different types may have different priors. Require \(P_\theta(\omega,1)=x_\theta(\omega)\sum_{t\in\{0,1\}}P_\theta(\omega,t)\).
Respondents observe only their type and signal \(T\). Their actions are \(1\) (top) and \(0\) (flop). Under truthful play, the per-capita rating is \(R_k(\omega)=m\sum_{\theta:\ell_\theta=k}\mu_\theta x_\theta(\omega)\); an individual deviation has zero mass and leaves ratings unchanged.
Set \(h(k)=k+1\) for \(k<m\) and \(h(m)=1\). A respondent assigned item \(k\) receives a fixed desirable prize for top exactly when \(R_k>R_{h(k)}\), and for flop exactly when \(R_k<R_{h(k)}\); otherwise the payoff is zero, including ties. Preferences strictly follow conditional winning probabilities. The model and preferences are common knowledge.
Truthful play means choosing action \(T\). Strict Bayesian Nash equilibrium means that, for every supported type and each signal, its truthful action is strictly preferred to the other action when everyone else plays truthfully. Beliefs are unrestricted apart from the stated validity conditions. Let \(L\) be the total binary input length; state running times in \(m,\tau,s,L\).

Is deciding whether truthful play is a strict Bayesian Nash equilibrium of this nonatomic top-flop game in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite societies with equally many respondents per item, truthful play is a strict equilibrium under nondegenerate identical rating marginals, strict comparative informativeness of own-item ratings, independence both unconditionally and conditional on the respondent’s signal, and common knowledge of beliefs and probability-based preferences. [Baillon–Xu](https://doi.org/10.3982/TE4343).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The decision problem is in \(\mathrm{P}\). An exact algorithm runs in \(O((m+\tau)sL^2)\) bit operations using ordinary integer arithmetic.

For each item \(k\) and state \(\omega\), define
\(\delta_k(\omega)=\operatorname{sgn}(R_k(\omega)-R_{h(k)}(\omega))\), where the sign is \(1\), \(0\), or \(-1\).

Fix a supported type \(\theta\), assigned item \(k=\ell_\theta\), and a signal \(t\). Because an individual deviation has zero mass, choosing a different action leaves all ratings unchanged. Consequently, the winning probabilities from actions \(1\) and \(0\) are respectively
\(W_\theta(1\mid t)=P_\theta(R_k>R_{h(k)}\mid T=t)\) and
\(W_\theta(0\mid t)=P_\theta(R_k<R_{h(k)}\mid T=t)\).

Subtracting these probabilities gives
\(W_\theta(1\mid t)-W_\theta(0\mid t)=\sum_{\omega\in\Omega}\delta_k(\omega)P_\theta(\omega,t)/P_\theta(T=t)\).
Indeed, a state contributes positively when only top wins, negatively when only flop wins, and zero when the ratings tie.

Define the exact rational score
\(D_{\theta,t}=\sum_{\omega\in\Omega}\delta_{\ell_\theta}(\omega)P_\theta(\omega,t)\).
The hypothesis \(P_\theta(T=t)>0\) ensures that this score has the same sign as the difference in conditional winning probabilities. Since preferences strictly follow those probabilities, truthful action \(1\) is strictly preferred after signal \(1\) exactly when \(D_{\theta,1}>0\); truthful action \(0\) is strictly preferred after signal \(0\) exactly when \(D_{\theta,0}<0\).

Thus truthful play is a strict Bayesian Nash equilibrium if and only if, for every supported type \(\theta\), both \(D_{\theta,1}>0\) and \(D_{\theta,0}<0\). This criterion checks every required type and signal, so it is both necessary and sufficient. In particular, equality in either score fails strictness.

The algorithm implements this criterion directly:

  • For every state, accumulate \(R_k(\omega)=m\sum_{\theta:\ell_\theta=k}\mu_\theta x_\theta(\omega)\) for every item.
  • Compare each rating with its cyclic neighbor to compute every \(\delta_k(\omega)\).
  • For each type and each signal, sum the corresponding signed joint probabilities to obtain \(D_{\theta,t}\).
  • Accept precisely when all the required strict inequalities hold.

Computing ratings requires \(O(\tau s+ms)\) arithmetic operations. Computing their signs requires \(O(ms)\) rational comparisons, and computing all scores requires \(O(\tau s)\) rational additions. No posterior distributions need to be constructed: their positive normalizing constants do not affect the comparisons.

To justify the bit complexity, use the standard explicit binary encoding of rational numbers. Each rating is a sum of products of input rationals. It can be represented over the product of the denominators appearing in those terms. The sum of their encoded bit lengths is at most \(O(L)\), so that denominator has \(O(L)\) bits. All partial rating sums are nonnegative and bounded by \(1\) after multiplication by \(m\), so their numerators also have \(O(L)\) bits.

Likewise, a score can be accumulated over the product of its input probability denominators, which has \(O(L)\) bits. Every partial signed sum has absolute value at most the corresponding sum of probabilities, hence at most \(1\); its numerator therefore has \(O(L)\) bits. Rational comparisons use cross-products of integers of \(O(L)\) bits. Ordinary integer addition and multiplication consequently give an \(O(L^2)\) upper bound per arithmetic operation or comparison, proving the stated total bound.

The input validity conditions can also be checked within this bound, if validity is not promised: they involve rational bounds, sums, and the explicitly given consistency equalities.

This proof uses the supplied state tables and subjective distributions directly. It requires no independence, identical marginals, or comparative informativeness assumptions. Since every item has positive assigned mass, \(\tau\geq m\); the running-time bound can therefore also be written \(O(\tau sL^2)\).
