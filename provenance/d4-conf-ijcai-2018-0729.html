The continuous mirror question, as graded

Given \(\tau\) consistent propositional goals \(\gamma_t\) over \(m\) Boolean issues with binary-rational masses \(\mu_t>0\) summing to \(1\), a set of issues \(S\), and a partial assignment \(\rho:S\to\{0,1\}\), is there a configuration \(v\) agreeing with \(\rho\) that maximizes \(\sum_{t:v\models\gamma_t}\mu_t\) over all configurations satisfying at least one supported goal?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq 1\) goal types \(\gamma_t\), each with positive binary-rational mass \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each goal is a satisfiable propositional formula, given explicitly using \(\land,\lor,\neg,\to\), over \(m\geq1\) Boolean issues \(I=\{1,\ldots,m\}\). All configurations \(v\in\{0,1\}^m\) are feasible; there are no integrity constraints.
Define \(D=\{v:\exists t,\ v\models\gamma_t\}\), \(a(v)=\sum_{t:v\models\gamma_t}\mu_t\), and \(W=\operatorname*{arg\,max}_{v\in D}a(v)\); every tied maximizer belongs to \(W\).
The input also contains \(S\subseteq I\) and \(\rho:S\to\{0,1\}\). Decide whether some \(v\in W\) satisfies \(v|_S=\rho\); maximization is global, before imposing \(\rho\).
Let \(L\) be the total binary input length, including formulas, masses, and the partial assignment. State running times in \(m,\tau,L\).

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite list of equally weighted agents with satisfiable propositional goals, deciding whether a global approval maximizer extends a given partial assignment is \(\Theta_2^p\)-complete. [Source](https://www.ijcai.org/proceedings/2018/0065.pdf)
No result settling exactly the support-encoded rational-mass version was identified in the literature search.

Modeling choices made when packaging the task

  • Specified explicit propositional-formula encoding using the discrete definition's connectives, rather than an explicit list of satisfying configurations.
  • Made consistency a promise of satisfiability and specified nonempty support and a positive number of issues.
  • Carried over unrestricted feasibility of Boolean configurations, with no integrity constraints.
  • Retained every tied maximizer and clarified that the partial assignment filters global winners rather than restricting the maximization domain.
  • Defined L as total binary input length, including formula encodings, rational masses, and the partial assignment.

Result

The problem is \(\mathrm{NP}\)-hard, even with support size \(\tau=2\), fixed dyadic masses, and a partial assignment prescribing just one issue. Consequently, it has no algorithm polynomial in \(m,\tau,L\) unless \(\mathrm{P}=\mathrm{NP}\).

Already \(\tau=1\) is hard: for a SAT instance \(\varphi\), the satisfiable goal \(z\lor\varphi\), with a fresh issue \(z\), has a winner extending \(z=0\) exactly when \(\varphi\) is satisfiable. The following reduction additionally makes global maximization select between different approval scores.

Hardness with two satisfiable goal types

We use the standard fact that satisfiability of explicitly represented propositional CNF formulas is \(\mathrm{NP}\)-complete.

Let \(\varphi\) be such a formula over issues \(x_1,\ldots,x_n\). Introduce a fresh issue \(z\), and construct the society

\(\displaystyle \gamma_1=\neg z\lor\varphi,\qquad \mu_1=\frac34,\qquad \gamma_2=z,\qquad \mu_2=\frac14.\)

Set \(S=\{z\}\) and \(\rho(z)=1\).

Validity of the constructed instance.

  • The support size is \(\tau=2\), and the issue count is \(m=n+1\).
  • Both masses are positive binary rationals and sum to one.
  • The goal \(\gamma_1\) is satisfiable by every configuration with \(z=0\), regardless of \(\varphi\).
  • The goal \(\gamma_2\) is satisfiable by every configuration with \(z=1\).
  • The two goals are distinct even semantically: a configuration with \(z=0\) satisfies \(\gamma_1\) and falsifies \(\gamma_2\).
  • Every configuration satisfies at least one goal. Thus \(D=\{0,1\}^{n+1}\).
  • All formulas use allowed connectives, and the construction has polynomial output length and takes polynomial time in the SAT input length.

The approval score is determined exactly by the following table.

| Configuration condition | Satisfied goals | Approval score |
|---|---|---|
| \(z=0\) | \(\gamma_1\) only | \(3/4\) |
| \(z=1\) and \(\varphi\) true | Both goals | \(1\) |
| \(z=1\) and \(\varphi\) false | \(\gamma_2\) only | \(1/4\) |

We now prove both directions.

If \(\varphi\) is satisfiable, extend any satisfying assignment by \(z=1\). Its score is \(1\), the largest possible score because the total mass is \(1\). It therefore belongs to \(W\) and extends \(\rho\). In fact,

\(\displaystyle W=\{v:v(z)=1\text{ and }v\models\varphi\}.\)

If \(\varphi\) is unsatisfiable, every configuration with \(z=1\) has score \(1/4\), whereas every configuration with \(z=0\) has score \(3/4\). Hence

\(\displaystyle W=\{v:v(z)=0\},\)

so no winner extends \(\rho\).

Consequently,

\(\displaystyle \varphi\text{ is satisfiable}\quad\Longleftrightarrow\quad \exists v\in W\text{ with }v|_S=\rho.\)

This is a polynomial-time many-one reduction from SAT. It proves hardness while retaining all tied global maximizers and performing maximization before imposing the partial assignment.

Exact arithmetic and upper bounds

The rational masses also admit a direct algorithm without expanding the society into individual agents.

Write each mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive binary-encoded integers. Define

\(\displaystyle Q=\prod_{t=1}^{\tau}q_t,\qquad w_t=p_t\frac{Q}{q_t},\qquad A(v)=\sum_{t:v\models\gamma_t}w_t.\)

Each \(w_t\) is an integer, and

\(\displaystyle \sum_{t=1}^{\tau}w_t=Q,\qquad a(v)=A(v)/Q.\)

The binary length of \(Q\) is at most one plus the sum of the binary lengths of the denominators, hence is \(O(L)\). Moreover, \(0<w_t\le Q\). Thus all these integers can be computed and manipulated in polynomial time in \(L\).

Because at least one goal is satisfiable and every mass is positive, some configuration has positive score. Configurations outside \(D\) have score zero. Therefore maximizing \(A\) over all configurations gives exactly the original winner set \(W\).

Deterministic enumeration

Enumerate all configurations, compute their integer scores, and maintain:

  • the largest score seen globally;
  • the largest score seen among configurations extending \(\rho\).

The two maxima are equal exactly when the answer is yes. Formula evaluation and integer arithmetic take polynomial time per configuration, giving running time

\(\displaystyle O\!\left(2^m\operatorname{poly}(m,\tau,L)\right).\)

More precisely, only issues occurring in a goal or in \(S\) need to be enumerated. If their number is \(r\), then \(r\le m\) and \(r=O(L)\), and the running time is

\(\displaystyle O\!\left(2^r\operatorname{poly}(L)\right).\)

Assignments to these issues extend arbitrarily to unused issues without changing any score or prescribed value.

Polynomial time with an NP oracle

For an integer threshold \(k\), consider the question

\(\displaystyle \exists v\in\{0,1\}^{m}\quad A(v)\ge k.\)

This predicate belongs to \(\mathrm{NP}\): a certificate specifies the relevant issue values, and the formulas and integer score can be checked in polynomial time.

Binary search on the integer interval from \(0\) to \(Q\) finds the global maximum \(M\) using \(O(\log(Q+1))=O(L)\) oracle queries. One additional query asks

\(\displaystyle \exists v\quad v|_S=\rho\text{ and }A(v)\ge M.\)

Since \(M\) is the global maximum, this query is equivalent to the required winner-extension question. Thus the problem belongs to \(\mathrm{P}^{\mathrm{NP}}\), with \(O(L)\) NP-oracle calls and polynomial overhead in \(m,\tau,L\).

Scope of the conclusion

The supplied [IJCAI paper, Theorem 3](https://www.ijcai.org/proceedings/2018/0065.pdf), establishes \(\Theta_2^p\)-completeness for explicitly listed equally weighted agents. The reduction above directly settles the requested polynomial-time-versus-hardness question for support-encoded masses, including dyadic masses.

In particular, a constant support size does not guarantee tractability: the formulas themselves retain SAT hardness.
