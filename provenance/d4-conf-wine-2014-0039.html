Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given rational masses \(\mu_t=N_t/N\) for \(\tau\) complete valuation types, a type-indexed packing relaxation \(P_\mu\subseteq[0,1]^d\) with \(d\) depending on types and bundle options, an optimal fractional welfare point \(x^\star\), and an efficient \(\alpha\)-integrality-gap verifier returning feasible integral count-allocation patterns, can one output a lottery \((\lambda_j,z^j)\) over those patterns with \(\left\|\sum_j\lambda_j z^j-x^\star/\alpha\right\|_2\le\epsilon\) using \(O(d\epsilon^{-2})\) verifier calls independently of \(N\)? Each pattern records how many members of each type receive each integral bundle.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) complete valuation types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) goods; each type has explicitly supplied nonnegative rational bundle valuations, with empty-bundle value \(0\), and an explicit list \(B_t\) of permitted nonempty bundles. Put \(d=\sum_t|B_t|\ge1\).
A binary integer \(N\ge1\) is supplied with \(N_t=N\mu_t\in\mathbb Z_{>0}\). Coordinates \(x_{t,b}\) represent allocated mass. Unallocated mass is permitted.
The input includes a nonempty rational polytope \(P_\mu\subseteq[0,1]^d\), given by linear inequalities, satisfying \(\sum_{b\in B_t}x_{t,b}\le\mu_t\) and the packing property: \(0\le y\le x\in P_\mu\Rightarrow y\in P_\mu\).
Feasible integral count patterns are exactly \(c\in\mathbb Z_{\ge0}^d\) with \(c/N\in P_\mu\); write \(S_N=\{c/N:c\text{ is feasible}\}\). Counts specify how many type members receive each bundle, without listing individual members.
Given also are rational \(\alpha\ge1\), \(0<\epsilon<1\), a rational welfare maximizer \(x^\star\in\operatorname*{arg\,max}_{x\in P_\mu}\sum_{t,b}v_t(b)x_{t,b}\), and a verifier \(\mathcal A\) returning \(z\in S_N\) for every nonnegative rational \(w\), with \(\alpha w\cdot\mathcal A(w)\ge\max_{x\in P_\mu}w\cdot x\). The verifier runs in polynomial time in the input and query bit lengths.
The requested output is a finite lottery with rational \(\lambda_j\ge0\), \(\sum_j\lambda_j=1\), and normalized feasible count patterns \(z^j\in S_N\), satisfying \(\left\|\sum_j\lambda_jz^j-x^\star/\alpha\right\|_2\le\epsilon\). Let \(L\) be the total binary input length.

Is this lottery construction polynomial-time solvable in \(m,\tau,d,L,\epsilon^{-1}\), using \(O(d\epsilon^{-2})\) verifier calls independently of \(N\), or is it NP-hard even with the promised efficient verifier?

For binary allocation coordinates in a packing polytope, an \(\epsilon\)-accurate decomposition of \(x^\star/\alpha\) uses at most \(\lceil n\epsilon^{-2}\rceil-1\) verifier calls ([Kraft–Fadaei–Bichler](https://pub.dss.in.tum.de/bichler-research/2014_kraft_convex_decomposition.pdf)).
The checked sources do not explicitly settle the support-encoded normalized count-pattern formulation above.

Modeling choices made when packaging the task

  • Normalized each integral count vector by N so that patterns, fractional coordinates, and the Euclidean error all use mass units.
  • Retained N as an explicitly supplied binary population-resolution parameter: the masses alone do not determine the lattice of feasible count patterns.
  • Required positive masses summing to one, nonnegative rational valuations, zero empty-bundle value, and explicit bundle options and valuation tables.
  • Represented the packing relaxation by explicit rational linear inequalities and defined feasible count patterns by membership of their normalized vectors in that relaxation.
  • Allowed unallocated mass and imposed type-capacity inequalities rather than equalities, preserving the downward closure required by the discrete setting.
  • Specified the verifier guarantee for every nonnegative rational objective, rather than only the welfare objective.
  • Required rational lottery weights and measured running time in the full binary input length and inverse accuracy; independence from N allows its encoding length.

Result

The lottery construction is polynomial-time solvable under the stated verifier promise. It uses at most \(\lceil d\epsilon^{-2}\rceil-1\) verifier calls, independently of \(N\), and produces rational weights of polynomial bit length.

The proof below applies to any supplied rational feasible point \(x^\star\); its welfare optimality is not needed.

1. Extending the verifier to signed directions

Index the allocation coordinates by \(i\in\{1,\ldots,d\}\), and write \(P=P_\mu\) and \(q=x^\star/\alpha\). Since \(x^\star\in[0,1]^d\) and \(\alpha\ge1\), we have \(q\in[0,1]^d\).

First, \(0\in S_N\): choose any \(x\in P\), which exists by nonemptiness, and apply packing to \(0\le x\).

For any rational vector \(r\in\mathbb Q^d\), define \(r_i^+=\max\{r_i,0\}\). Make one verifier call \(a=\mathcal A(r^+)\), and define

\(\displaystyle T(r)_i=\begin{cases}a_i,&r_i\ge0,\\0,&r_i<0.\end{cases}\)

This modification preserves count integrality. Indeed, writing \(a=c/N\), it merely replaces some integer counts \(c_i\) by zero. Moreover, \(0\le T(r)\le a\), so packing gives \(T(r)\in S_N\).

The verifier guarantee implies

\(\displaystyle r\cdot T(r)=r^+\cdot a \ge\frac1\alpha\max_{x\in P}r^+\cdot x \ge\frac1\alpha r^+\cdot x^\star \ge\frac1\alpha r\cdot x^\star =r\cdot q.\)

The last inequality uses \(x^\star\ge0\). Consequently,

\[\displaystyle r\cdot\bigl(T(r)-q\bigr)\ge0.\tag{1}\]

Thus one nonnegative-weight verifier call supplies a feasible normalized count pattern satisfying the needed inequality in any rational signed direction.

2. Algorithm and lottery

Set

\(\displaystyle K=\left\lceil d\epsilon^{-2}\right\rceil-1.\)

Initialize \(z^0=0\) and \(y_0=0\). For \(k=0,\ldots,K-1\), perform:

  • Compute \(r_k=q-y_k\).
  • Obtain \(z^{k+1}=T(r_k)\), using one verifier call.
  • Set \(\displaystyle y_{k+1}=\frac{(k+1)y_k+z^{k+1}}{k+2}\).

Induction on \(k\) gives

\[\displaystyle y_k=\frac1{k+1}\sum_{j=0}^{k}z^j.\tag{2}\]

Return the patterns \(z^0,\ldots,z^K\), each with weight

\(\displaystyle \lambda_j=\frac1{K+1}.\)

Every pattern belongs to \(S_N\), every weight is rational and positive, and the weights sum to one. Repeated patterns may be combined by adding their weights.

3. Error bound

Define \(E_k=\|y_k-q\|_2^2\). Applying (1) with \(r_k=q-y_k\) yields

\[\displaystyle (y_k-q)\cdot(z^{k+1}-q)\le0.\tag{3}\]

Also, since \(z^{k+1},q\in[0,1]^d\),

\[\displaystyle \|z^{k+1}-q\|_2^2\le d.\tag{4}\]

Subtracting \(q\) from the update gives

\(\displaystyle y_{k+1}-q =\frac{k+1}{k+2}(y_k-q)+\frac1{k+2}(z^{k+1}-q).\)

Expanding the squared norm and using (3) and (4), we obtain

\[\displaystyle E_{k+1} \le\frac{(k+1)^2E_k+d}{(k+2)^2}.\tag{5}\]

We claim that

\[\displaystyle E_k\le\frac d{k+1}\qquad\text{for every }k\ge0.\tag{6}\]

For \(k=0\), this follows from \(y_0=0\) and \(q\in[0,1]^d\). If (6) holds at \(k\), then (5) gives

\(\displaystyle E_{k+1} \le\frac{(k+1)^2\,d/(k+1)+d}{(k+2)^2} =\frac{d(k+2)}{(k+2)^2} =\frac d{k+2}.\)

This proves (6) by induction. Since \(K+1=\lceil d\epsilon^{-2}\rceil\),

\(\displaystyle \left\|\sum_{j=0}^{K}\lambda_jz^j-\frac{x^\star}{\alpha}\right\|_2^2 =E_K \le\frac d{K+1} \le\epsilon^2.\)

The returned lottery therefore satisfies the requested error bound.

4. Bit complexity and dependence on population size

The averaging rule keeps all arithmetic polynomially bounded.

Write \(z^j=c^j/N\). Each \(c_i^j\) is an integer between zero and \(N\). Maintaining the integer sums

\(\displaystyle C_i^{(k)}=\sum_{j=1}^{k}c_i^j\)

gives the exact representation

\(\displaystyle (y_k)_i=\frac{C_i^{(k)}}{N(k+1)},\qquad 0\le C_i^{(k)}\le kN.\)

Thus each coordinate of \(y_k\) has bit length \(O(\log N+\log(k+1))\). Each coordinate of \(q=x^\star/\alpha\) has bit length \(O(L)\), so the coordinates of the actual nonnegative verifier query \((q-y_k)^+\) have bit length \(O(L+\log(K+1))\).

If the verifier returns rational coordinates rather than integer counts, multiplying them by \(N\) recovers the exact integer counts promised by membership in \(S_N\). These can then be stored in canonical count form. This conversion is polynomial-time because the verifier’s output length is bounded by its promised polynomial running time.

There are \(K=O(d\epsilon^{-2})\) calls. Outside the verifier, each iteration uses polynomially many arithmetic operations on numbers of polynomial bit length. The output has \(K+1\) patterns, each encoded using \(d\) binary counts and the common denominator \(N\), together with weights \(1/(K+1)\).

Hence the total running time and output length are polynomial in \(m,\tau,d,L,\epsilon^{-1}\). The number of verifier calls has no dependence on \(N\); the arithmetic and output depend on its binary encoding through \(\log N\). No individual society members are enumerated.

5. Stronger bound from mass normalization

The supplied type constraints imply, for every \(z\in S_N\),

\(\displaystyle \sum_i z_i =\sum_t\sum_{b\in B_t}z_{t,b} \le\sum_t\mu_t=1.\)

Likewise, \(\sum_iq_i\le1/\alpha\le1\). For nonnegative vectors with coordinate sum at most one, the squared Euclidean norm is at most one. Therefore,

\(\displaystyle \|z-q\|_2^2 =\|z\|_2^2+\|q\|_2^2-2z\cdot q \le2.\)

Together with the cube bound, this gives \(\|z-q\|_2^2\le D\), where \(D=\min\{d,2\}\). Also, \(E_0=\|q\|_2^2\le1\le D\). Replacing \(d\) by \(D\) throughout the same induction proves that only

\(\displaystyle \left\lceil\min\{d,2\}\epsilon^{-2}\right\rceil-1\)

calls are necessary. In particular, the mass-normalized formulation admits an \(O(\epsilon^{-2})\) call bound.

The signed-direction truncation is the same packing argument used in Lemma 1 of [Kraft–Fadaei–Bichler](https://pub.dss.in.tum.de/bichler-research/2014_kraft_convex_decomposition.pdf). Here it preserves the normalized count grid directly, and the explicit averaging proof establishes both convergence and polynomial bit complexity for the support-encoded formulation.
