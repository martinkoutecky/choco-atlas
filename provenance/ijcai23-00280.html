The continuous mirror question, as graded

Given a connected graph \(G=(V,E)\), rational block capacities \(b_v>0\), a finite ordered type set \(T\) with rational values \(\theta_t\in[0,1]\), and rational masses \(\mu_t\ge0\) satisfying \(\sum_t\mu_t=\sum_v b_v\), find a matrix \(\rho\in\mathbb{Q}_{\ge0}^{V\times T}\) with \(\sum_t\rho_{v,t}=b_v\) and \(\sum_v\rho_{v,t}=\mu_t\) such that no exchange of any \(0<\varepsilon\le\min\{\rho_{v,t},\rho_{w,s}\}\) between blocks \(v,w\) and types \(t,s\) strictly lowers both participants' costs. Here \(D_t(v;\rho)=\max\{|\theta_t-\theta_r|:\exists u\in N(v),\rho_{u,r}>0\}\), with both post-exchange costs evaluated in the resulting arrangement \(\rho'\).

Packaged proof task (what the prover saw — nothing else)

Given a connected simple undirected graph \(G=(V,E)\) with \(m=|V|\ge2\), each block \(v\) has a binary rational capacity \(b_v>0\).
A society is given by its support: the list \(T\) of its \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational; \(\tau\) is the support size, not the number of possible types. Type values \(\theta_t\in[0,1]\) are binary rationals listed in nondecreasing order, and \(\sum_t\mu_t=\sum_v b_v\); total mass need not equal \(1\).
An arrangement is \(\rho\in\mathbb Q_{\ge0}^{V\times T}\) satisfying \(\sum_t\rho_{v,t}=b_v\) and \(\sum_v\rho_{v,t}=\mu_t\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).
For any nonnegative real arrangement, define \(D_t(v;\rho)=\max\{ |\theta_t-\theta_r|:u\in N_G(v),\ \rho_{u,r}>0\}\), where \(N_G(v)\) is the set of adjacent blocks.
An exchange chooses distinct blocks \(v,w\), distinct types \(t,s\), and a real amount \(0<\varepsilon\le\min\{\rho_{v,t},\rho_{w,s}\}\). It subtracts \(\varepsilon\) from entries \((v,t),(w,s)\) and adds it to \((w,t),(v,s)\), yielding \(\rho'\); all other entries stay fixed.
The exchange is profitable precisely when \(D_t(w;\rho')<D_t(v;\rho)\) and \(D_s(v;\rho')<D_s(w;\rho)\). An arrangement is stable if it admits no profitable exchange, including exchanges between nonadjacent blocks and exchanges exhausting an entry.

Is finding a rational stable arrangement, or determining that none exists, solvable in polynomial time in \(m,\tau,L\), or is this computational problem NP-hard?

For indivisible agents, with exactly one agent per vertex, a swap equilibrium always exists and can be computed in \(O(|E|)\) time when agent types are already sorted. [Verified source](https://arxiv.org/pdf/2305.06819).
No result settling this exact divisible-mass problem was located in the literature search.

Modeling choices made when packaging the task

  • Specified a simple undirected graph with at least two vertices, preserving the intended absence of isolated agents and ensuring every cost maximum is defined.
  • Removed zero-mass types from the input support; retained arbitrary positive total mass equal to total block capacity rather than imposing probability normalization.
  • Specified nondecreasing type values, allowing equal values as in the discrete model.
  • Made the exchange update and the two participants' destination costs explicit; exchanges may involve any distinct blocks, without an adjacency restriction.
  • Quantified exchange amounts over the reals and extended the cost definition to real arrangements, while retaining rational output arrangements.
  • Included determining nonexistence because equilibrium existence for divisible masses is not supplied by the discrete result.

Result

The problem is solvable in polynomial time. A rational stable arrangement always exists.

The decisive feature is that the stated model permits every type to have positive mass at every block. The construction below works for arbitrary capacities, masses, support size, and connected graphs under the given hypotheses.

Construction and feasibility

Let \(B=\sum_{v\in V}b_v=\sum_{t\in T}\mu_t>0\). Define

\[ \rho_{v,t}=\frac{b_v\mu_t}{B}. \]

Every entry is a positive rational. The required marginal constraints hold because

\[ \sum_{t\in T}\rho_{v,t} =\frac{b_v}{B}\sum_{t\in T}\mu_t=b_v, \qquad \sum_{v\in V}\rho_{v,t} =\frac{\mu_t}{B}\sum_{v\in V}b_v=\mu_t. \]

For each type \(t\), put \(C_t=\max_{r\in T}|\theta_t-\theta_r|\). Since \(G\) is connected and \(m\ge2\), every block has a neighbor. Every type occurs at every neighboring block, so

\[ D_t(v;\rho)=C_t \qquad\text{for every }v\in V,\ t\in T. \]

Stability, including exhausting exchanges

We first establish a property valid for any feasible arrangement.

Lemma. If an exchange moves type \(t\) from \(v\) to \(w\), yielding \(\rho'\), then \(D_t(w;\rho')\ge D_t(w;\rho)\).

Proof. The only entries that decrease are \((v,t)\) and \((w,s)\). Because the graph is simple, \(w\notin N_G(w)\), so decreasing \((w,s)\) removes no type from the neighborhood used to evaluate \(D_t(w;\rho)\).

If \(v\) is adjacent to \(w\), decreasing \((v,t)\) can remove type \(t\) from that neighborhood. Its distance from type \(t\) is zero.

If \(D_t(w;\rho)>0\), choose a neighboring positive entry attaining this maximum. Its type differs from \(t\), so neither decreased entry can remove it. Hence its distance remains available after the exchange. If \(D_t(w;\rho)=0\), the inequality follows from nonnegativity. This covers both adjacent and nonadjacent exchanges and arbitrary allowed amounts, including amounts exhausting an entry. \(\square\)

Apply the lemma to the constructed arrangement. For every proposed exchange,

\[ D_t(w;\rho')\ge D_t(w;\rho)=C_t=D_t(v;\rho). \]

Thus the strict inequality required for type \(t\) to profit is impossible. No exchange is profitable, and \(\rho\) is stable.

In fact, the same proof shows that every feasible arrangement with all entries positive is stable.

Binary complexity

Write the input rationals as \(b_v=p_v/q_v\) and \(\mu_t=a_t/d_t\), using positive binary integers. Compute

\[ Q=\prod_{v\in V}q_v, \qquad P=\sum_{v\in V}p_v\frac{Q}{q_v}. \]

Then \(B=P/Q\), and output

\[ \rho_{v,t}=\frac{p_va_tQ}{q_vd_tP}. \]

The integers \(Q\) and \(P\) have \(O(L)\) bits: the bit lengths of the denominator factors sum to at most \(L\), and summing the numerator terms adds at most \(O(\log m)\) bits. Consequently, every output numerator and denominator has \(O(L)\) bits, and the total output length is \(O(m\tau L)\).

Using elementary integer arithmetic, including reduction of output fractions if desired, a conservative running-time bound is \(O(m\tau L^3)\) bit operations. This is polynomial in \(m,\tau,L\). The algorithm always returns the displayed stable arrangement.

Verdict

The prover resolves the stated problem correctly: a rational stable arrangement always exists, and the displayed construction computes one in polynomial time. No gaps or false statements were found.

Step-by-step verification

1. Construction and feasibility

The total mass \(B\) is positive because every capacity is positive. The support is nonempty because its masses sum to \(B>0\).

Consequently, each entry
\[ \rho_{v,t}=\frac{b_v\mu_t}{B} \]
is a positive rational. Both marginal calculations are correct: summing over types gives \(b_v\), and summing over vertices gives \(\mu_t\). Thus the construction satisfies every feasibility requirement.

2. Initial disutilities

A connected graph with \(m\ge2\) has no isolated vertices. Since every entry of the constructed arrangement is positive, every type occurs in every vertex’s neighborhood. Therefore
\[ D_t(v;\rho)=\max_{r\in T}|\theta_t-\theta_r|=C_t \]
for every vertex and type.

The maximum exists because the support is finite and nonempty. Neither strict ordering nor distinctness of type values is needed.

3. The monotonicity lemma

The lemma is valid for any feasible arrangement under the stated exchange rule.

An exchange decreases only \((v,t)\) and \((w,s)\). The second entry lies outside the neighborhood of \(w\), since the graph has no self-loops. The first can affect that neighborhood only when \(v\) and \(w\) are adjacent, and its distance from type \(t\) is zero.

If \(D_t(w;\rho)>0\), an entry attaining that maximum has a type different from \(t\). It is therefore neither decreased entry and remains positive after the exchange. Its distance remains available in the destination maximum.

If \(D_t(w;\rho)=0\), the asserted inequality follows from nonnegativity. The post-exchange maximum remains well-defined: exchanges preserve all row sums, every row has positive capacity, and \(w\) has a neighbor.

This reasoning covers nonadjacent blocks, arbitrary allowed real amounts, and exchanges exhausting either or both decreased entries.

4. Stability conclusion

For the constructed arrangement, the lemma gives
\[ D_t(w;\rho')\ge D_t(w;\rho)=C_t=D_t(v;\rho). \]
This directly excludes the strict improvement required for type \(t\). Since profitability requires both strict improvements, no profitable exchange exists.

The additional claim that every feasible arrangement with all entries positive is stable follows from precisely the same reasoning.

5. Boundary cases

The proof also covers:

  • A single supported type: no exchange with distinct types is available.
  • Coincident type values, including all values equal: zero disutilities cannot strictly improve.
  • Arbitrary positive capacities and masses, without normalization to total mass \(1\).
  • A graph consisting of two connected vertices.
  • Rational input arrangements tested against real exchange amounts.

No omitted boundary case affects the conclusion.

6. Binary complexity

The definitions of \(Q\) and \(P\) correctly give \(B=P/Q\). Substituting into the construction yields exactly
\[ \rho_{v,t}=\frac{p_va_tQ}{q_vd_tP}. \]

The bit length of \(Q\) is bounded by the sum of the input denominator lengths. Each summand defining \(P\) has \(O(L)\) bits; summing \(m\) such terms adds at most \(O(\log m)\) bits. Since \(m\) is bounded by the input length, \(P\) also has \(O(L)\) bits.

All output numerators and denominators consequently have \(O(L)\) bits, giving total output length \(O(m\tau L)\). Unreduced fractions already represent valid rational outputs; optional reduction preserves these bounds.

The stated conservative running time \(O(m\tau L^3)\) bit operations accommodates the integer products, exact divisions, sums, and optional fraction reductions using elementary arithmetic. The polynomial-time conclusion is justified.

None. The proof is self-contained and does not depend on the cited indivisible-agent result.
