The anchor (named result in the paper)

Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given a finite-support distribution \(\mu\) over types \(t\), each a nonempty ordered tuple of rational locations in \([0,1]\), find a deterministic direct mechanism \(F\) returning \(F(\mu)\in[0,1]\). Define \(D_t(y)=\sum_j |y-x_{tj}|\), \(\delta_t=\min_{z\in[0,1]}D_t(z)\), \(\Delta_t=\max_{z\in[0,1]}D_t(z)\), and \(s_t(y)=1-(D_t(y)-\delta_t)/(\Delta_t-\delta_t)\). Require that no positive-mass coalition, jointly changing its reported types, can make almost all its members strictly better off, and that \(\max_{y\in[0,1]}\sum_t\mu_t s_t(y)\leq 2\sum_t\mu_t s_t(F(\mu))\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(m\) be the maximum tuple length and \(L\) the total input bit length.
A type is a nonempty tuple \(t=(x_{t1},\ldots,x_{tk_t})\) of rational locations with \(0\leq x_{t1}\leq\cdots\leq x_{tk_t}\leq1\); repetitions are allowed. Tuple length is public and cannot be misreported.
For \(y\in[0,1]\), define \(D_t(y)=\sum_{j=1}^{k_t}|y-x_{tj}|\), \(\delta_t=\min_{z\in[0,1]}D_t(z)\), \(\Delta_t=\max_{z\in[0,1]}D_t(z)\), and \(s_t(y)=1-(D_t(y)-\delta_t)/(\Delta_t-\delta_t)\). Admissible true and reported types satisfy \(\Delta_t>\delta_t\).
A deterministic direct mechanism \(F\) maps every admissible society to a rational facility location in \([0,1]\), without payments; satisfaction is evaluated at the true type.
A coalition deviation is a finitely supported array of real masses \(q_{tu}\geq0\), with \(\sum_uq_{tu}\leq\mu_t\), \(\sum_{t,u}q_{tu}>0\), and \(k_u=k_t\) whenever \(q_{tu}>0\). It produces \(\mu'_v=\mu_v-\sum_uq_{vu}+\sum_tq_{tv}\), which must be an admissible rational-mass society.
Group strategy-proofness means that every such deviation satisfies \(\sum_{t,u:\,s_t(F(\mu'))\leq s_t(F(\mu))}q_{tu}>0\): a positive mass of coalition members fails to improve strictly.

Does there exist a deterministic group strategy-proof mechanism \(F\), computable in time polynomial in \(m,\tau,L\), such that every admissible society satisfies \(\max_{y\in[0,1]}\sum_t\mu_t s_t(y)\leq2\sum_t\mu_t s_t(F(\mu))\), or is such a mechanism impossible?

The finite-agent model admits a deterministic group strategy-proof mechanism with approximation ratio \(2\) for total sum-variant satisfaction ([source](https://arxiv.org/html/2512.22873v1)).
No result settling this precise distribution model was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total mass to one, as required by the distribution interpretation.
  • Preserved tuple length under misreports, following the fixed-length reporting domain in the discrete definition; allowed repeated locations.
  • Excluded true and reported types with zero satisfaction denominator. The available full version gives no convention for these degenerate types.
  • Allowed coalitions to contain arbitrary portions of each type and split those portions among finitely many reports; required the resulting society to remain in the rational finite-support input domain.
  • Interpreted almost-all strict improvement literally: every deviation must leave a positive coalition mass without strict improvement.
  • Required rational facility outputs for exact finite computation, and defined m as maximum tuple length and L as total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Answer and mechanism

Yes. Define \(F(\mu)=\tfrac12\) for every admissible society. This constant mechanism, also considered for minimum satisfaction in the [cited paper](https://arxiv.org/html/2512.22873v1), satisfies the requested guarantee for every society in the distribution model.

Pointwise satisfaction bound

Fix an admissible type \(t\). The function \(D_t\) is continuous and convex because it is a finite sum of absolute-value functions. Since \(\Delta_t>\delta_t\), the function

\(s_t(y)=\dfrac{\Delta_t-D_t(y)}{\Delta_t-\delta_t}\)

is concave and satisfies \(0\leq s_t(y)\leq1\) on \([0,1]\). Continuity on the compact interval ensures that some \(z\in[0,1]\) minimizes \(D_t\), so \(s_t(z)=1\).

We prove \(s_t(\tfrac12)\geq\tfrac12\).

If \(z\leq\tfrac12\), set \(\lambda=\dfrac{1}{2(1-z)}\). Then \(\tfrac12\leq\lambda\leq1\) and \(\tfrac12=\lambda z+(1-\lambda)1\). Concavity and nonnegativity give

\(s_t(\tfrac12)\geq\lambda s_t(z)+(1-\lambda)s_t(1)\geq\lambda\geq\tfrac12.\)

If \(z>\tfrac12\), set \(\lambda=\dfrac{1}{2z}\). Again \(\tfrac12\leq\lambda\leq1\), and now \(\tfrac12=\lambda z+(1-\lambda)0\). Consequently,

\(s_t(\tfrac12)\geq\lambda s_t(z)+(1-\lambda)s_t(0)\geq\lambda\geq\tfrac12.\)

Thus the bound holds for every admissible type, irrespective of tuple length or repetitions.

Approximation guarantee

Write \(S_\mu(y)=\sum_t\mu_t s_t(y)\). Since the masses sum to \(1\), the pointwise bound implies

\(S_\mu(F(\mu))=S_\mu(\tfrac12)\geq\sum_t\mu_t\,\tfrac12=\tfrac12.\)

Also, \(s_t(y)\leq1\) for every type and location, hence \(S_\mu(y)\leq1\). Therefore,

\(\max_{y\in[0,1]}S_\mu(y)\leq1\leq2S_\mu(F(\mu)).\)

The factor \(2\) is attained by this mechanism: for the society consisting solely of \(t=(0)\), one has \(s_t(y)=1-y\), so optimal satisfaction is \(1\) and midpoint satisfaction is \(\tfrac12\).

Group strategy-proofness and computation

For every permitted deviation, \(F(\mu')=F(\mu)=\tfrac12\). Every coalition member therefore has exactly the same true satisfaction before and after deviating. In particular,

\(\sum_{t,u:\,s_t(F(\mu'))\leq s_t(F(\mu))}q_{tu}=\sum_{t,u}q_{tu}>0.\)

This proves precisely the required group strategy-proofness condition, including deviations using real masses.

Finally, the output is the fixed rational number \(\tfrac12\), with constant encoding length and constant computation time on the promised admissible inputs. It is therefore computable in time polynomial in \(m,\tau,L\).
