Theorem 4.1 — class: algorithmic

The continuous mirror question, as graded

Given runway levels \(1,\ldots,H\), costs \(0=c_0\le c_1\le\cdots\le c_H\), and a finite-support distribution \(\mu\) over movement types \((r,S)\), where \(S\) is the nonempty set of operating airlines, compute the fee density attributed to each \(a\in S\) and the resulting type and airline aggregate fees. For \(M_{a,t}=\sum_{(r,S):\,r\ge t,\,a\in S}\mu_{r,S}\) and \(A_t=\{a:M_{a,t}>0\}\), the density is \(\lambda_{(r,S),a}=\sum_{t=1}^{r}(c_t-c_{t-1})/(|A_t|M_{a,t})\); the type density is \(\sum_{a\in S}\lambda_{(r,S),a}\), and aggregate fees are obtained by weighting densities by type mass.

Packaged proof task (what the prover saw — nothing else)

Let \(m,H\ge1\) be the numbers of airlines and runway levels, with explicitly listed binary-rational costs \(0=c_0\le c_1\le\cdots\le c_H\). A movement type is \((r,S)\), where \(r\in\{1,\ldots,H\}\) and \(\varnothing\ne S\subseteq\{1,\ldots,m\}\) lists its operating airlines.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; require \(\sum_{(r,S)}\mu_{r,S}=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length, including the explicitly listed airline sets.
Define \(M_{a,t}=\sum_{(r,S):\,r\ge t,\,a\in S}\mu_{r,S}\) and \(A_t=\{a:M_{a,t}>0\}\).
For each supported \((r,S)\) and \(a\in S\), define the attributed fee density \(\lambda_{(r,S),a}=\sum_{t=1}^{r}\frac{c_t-c_{t-1}}{|A_t|M_{a,t}}\); these denominators are positive.
The type density is \(d_{r,S}=\sum_{a\in S}\lambda_{(r,S),a}\), its aggregate fee is \(F_{r,S}=\mu_{r,S}d_{r,S}\), and airline \(a\)'s aggregate fee is \(G_a=\sum_{(r,S):\,a\in S}\mu_{r,S}\lambda_{(r,S),a}\), with empty sums equal to zero. Compute all these quantities exactly as binary rationals; state running times in \(m,\tau,H,L\).

Is exact computation of these fee densities and aggregate fees solvable in polynomial time, or is it NP-hard?

For a finite list of movements, the configuration-value fee rule has an explicit polynomial-time expression, summing attributed fees over each movement's operating airlines ([Saavedra-Nieves and Fiestras-Janeiro](https://arxiv.org/pdf/2507.02894v1)). No prior result settling this exact distribution-based computation was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted distribution as a probability distribution, so the positive support masses sum to one.
  • Restricted costs to binary rationals and required the full cost list explicitly, making exact computational complexity well-defined.
  • Used m for the number of airlines, retained H for runway levels, and defined L as the total input bit length.
  • Specified exact binary-rational outputs and defined airline aggregates using only each airline's attributed density, matching the discrete representative-fee convention.
  • Allowed unused airlines and runway levels; unused airlines have zero aggregate fee, and densities are requested only on supported types and their operating airlines.

Result and representation

The specified fees are exactly computable in polynomial time in \(m,\tau,H,L\). The essential point is that the support is explicitly listed, and the rational numbers produced by the calculation have polynomially bounded bit lengths.

Here, an exact binary rational means a numerator and a positive denominator, both written in binary. Outputs need not be dyadic: for example, one supported type with mass \(1\), cost \(1\), and three operating airlines gives each airline attributed density \(1/3\).

There is one output-size qualification. If \(m\) is encoded in binary, explicitly listing \(m\) airline fees need not take polynomial time in \(L\). We give a polynomial bound in the requested parameters, including this output cost. Listing the active airlines’ fees and specifying that all remaining fees are zero takes polynomial time in \(L\) alone.

Exact algorithm

Index the supported types by \(i\in\{1,\ldots,\tau\}\), writing them as \((r_i,S_i)\) with mass \(\mu_i\). Define

\(\displaystyle I=\sum_{i=1}^{\tau}|S_i|,\qquad U=\bigcup_{i=1}^{\tau}S_i,\qquad q=|U|.\)

Thus \(q\le m\) and \(I\le\tau m\). Because every airline set is explicitly listed, also \(q\le I\le L\). We maintain tables only for airlines in \(U\); every other airline has aggregate fee zero.

Write the input masses and costs as

\(\displaystyle \mu_i=\frac{p_i}{b_i},\qquad c_t=\frac{x_t}{y_t},\)

where the denominators are positive integers. Put

\(\displaystyle Q=\prod_{i=1}^{\tau}b_i,\qquad R=\prod_{t=1}^{H}y_t,\qquad u_i=p_i(Q/b_i),\qquad C_t=x_t(R/y_t),\)

and set \(C_0=0\). All these quantities are integers, and

\(\displaystyle \mu_i=\frac{u_i}{Q},\qquad c_t=\frac{C_t}{R}.\)

1. Compute the tail masses and active counts

Initialize an integer table \(E_{a,r}\) to zero. For every supported type \(i\) and every \(a\in S_i\), add \(u_i\) to \(E_{a,r_i}\). Compute suffix sums

\(\displaystyle N_{a,H+1}=0,\qquad N_{a,t}=E_{a,t}+N_{a,t+1}.\)

By the definition of \(E\),

\(\displaystyle N_{a,t}=\sum_{\substack{i:\ r_i\ge t\\a\in S_i}}u_i=Q M_{a,t}.\)

Consequently, the active-airline count is

\(\displaystyle k_t=\bigl|\{a\in U:N_{a,t}>0\}\bigr|=|A_t|.\)

These steps use \(O(I+qH)\) integer additions and comparisons.

2. Construct one denominator for all attributed densities

Define the positive integer

\(\displaystyle D=R\prod_{\substack{a\in U,\ 1\le t\le H\\N_{a,t}>0}}(k_tN_{a,t}).\)

Whenever \(N_{a,t}>0\), the integer \(Rk_tN_{a,t}\) divides \(D\). Hence

\(\displaystyle W_{a,t}=(C_t-C_{t-1})Q\,\frac{D}{Rk_tN_{a,t}}\)

is an exactly computable nonnegative integer. It satisfies

\(\displaystyle \frac{W_{a,t}}{D} =\frac{c_t-c_{t-1}}{|A_t|M_{a,t}}.\)

For \(N_{a,t}=0\), set \(W_{a,t}=0\), without performing a division. Form prefix sums

\(\displaystyle Z_{a,0}=0,\qquad Z_{a,r}=Z_{a,r-1}+W_{a,r}.\)

If \(a\in S_i\) and \(t\le r_i\), then \(M_{a,t}\ge\mu_i>0\). Thus every summand required for that type is included, and

\(\displaystyle \lambda_{(r_i,S_i),a}=\frac{Z_{a,r_i}}{D}.\)

3. Compute the requested densities and aggregate fees

For each supported type, let

\(\displaystyle T_i=\sum_{a\in S_i}Z_{a,r_i}.\)

Then output

\(\displaystyle d_{r_i,S_i}=\frac{T_i}{D},\qquad F_{r_i,S_i}=\frac{u_iT_i}{QD}.\)

For each active airline, accumulate

\(\displaystyle V_a=\sum_{i:\ a\in S_i}u_iZ_{a,r_i}\)

and output

\(\displaystyle G_a=\frac{V_a}{QD}.\)

For \(a\notin U\), output \(G_a=0\). These formulas equal the quantities in the question by substitution of \(\mu_i=u_i/Q\) and \(\lambda_{(r_i,S_i),a}=Z_{a,r_i}/D\).

Finally, reduce each fraction by the greatest common divisor of its numerator and denominator if canonical output is desired.

Bit lengths and running time

We now bound the sizes of all integers used, so the algorithm is polynomial in the bit model.

Because the denominator encodings are part of the input,

\(\displaystyle \log_2 Q\le L,\qquad \log_2 R\le L.\)

The normalized, positive masses imply

\(\displaystyle 0\le N_{a,t}\le Q.\)

Also \(k_t\le q\). Therefore

\(\displaystyle \log_2 D \le \log_2 R+qH(\log_2 q+\log_2 Q) =O((qH+1)L).\)

Here \(\log_2 q\le L\), since \(q\le L\).

The output numerators satisfy the same asymptotic bound. Indeed, for every positive \(N_{a,t}\),

\(\displaystyle \frac{W_{a,t}}{D} =\frac{Q(c_t-c_{t-1})}{k_tN_{a,t}} \le Q(c_t-c_{t-1}).\)

Summing gives \(Z_{a,r}\le DQc_H\). Since \(c_H\le 2^L\), this bounds the bit length of every \(Z_{a,r}\) by \(\log_2 D+O(L)\). Summing at most \(I\) terms and multiplying by \(u_i\le Q\) preserves the bound

\(\displaystyle B=O((qH+1)L)\)

for every integer used by the algorithm.

There are \(O(qH+I+H+\tau)\) arithmetic operations, apart from writing inactive-airline outputs. Schoolbook multiplication and division on \(B\)-bit integers take \(O(B^2)\) bit operations. A conservative bound for Euclidean greatest-common-divisor computation is \(O(B^3)\): there are \(O(B)\) divisions, because the remainder decreases by at least a factor of two every two divisions.

Including fraction reduction and allowing explicit airline labels in the output, the running time is therefore

\(\displaystyle O\!\left(mL+(qH+I+H+\tau)\bigl((qH+1)L\bigr)^3\right).\)

Using \(q\le m\) and \(I\le\tau m\), a bound solely in the requested parameters is

\(\displaystyle O\!\left(mL+(mH+\tau m+H+\tau)\bigl((mH+1)L\bigr)^3\right).\)

This is polynomial in \(m,\tau,H,L\).

For compact output, the \(mL\) term disappears. Since \(q,I,H,\tau\le L\), the displayed bound is then \(O(L^{11})\). This deliberately conservative bound suffices to establish polynomial-time exact computation.

Aggregate identity and conclusion

The airline aggregates also admit a simpler expression. Rearranging finite sums gives

\(\displaystyle G_a =\sum_{\substack{1\le t\le H\\M_{a,t}>0}} \frac{c_t-c_{t-1}}{|A_t|M_{a,t}} \sum_{\substack{i:\ r_i\ge t\\a\in S_i}}\mu_i =\sum_{t:\ a\in A_t}\frac{c_t-c_{t-1}}{|A_t|}. \)

Let \(\rho=\max_i r_i\). Every supported airline set is nonempty and every supported mass is positive, so \(A_t\ne\varnothing\) exactly when \(t\le\rho\). Consequently,

\(\displaystyle \sum_{i=1}^{\tau}F_{r_i,S_i} =\sum_{a=1}^{m}G_a =\sum_{t=1}^{\rho}(c_t-c_{t-1}) =c_\rho.\)

This identity also verifies total cost recovery by the computed fees.

Thus the stated computation is polynomial-time solvable. Under the usual polynomial-time reductions, an NP-hardness result for this computation would imply \(\mathrm{P}=\mathrm{NP}\).
