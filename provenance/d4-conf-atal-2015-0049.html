The continuous mirror question, as graded

Given a finite support \(T\) of valuation types, rational masses \(\mu_t>0\) summing to \(1\), and normalized atomless valuation oracles \(V_t\), can a query protocol whose query count is bounded as a function of \(\tau=|T|\) find pairwise-disjoint connected intervals \(P_t\), with free disposal, such that \(V_t(P_t)\ge V_t(P_s)\) for all \(t,s\) and \(V_t(P_t)>0\) for every type?

Conclusion

A deterministic bounded-query protocol exists. Its query complexity is \(O(\tau 2^\tau)\). In fact, it can guarantee \(V_t(P_t)\geq 2^{-(\tau-1)}\) for every type \(t\).

Applicable theorem

Theorem 1 of Segal-Halevi, Hassidim, and Aumann, *Waste Makes Haste*, gives an envy-free allocation among \(n\) agents with free disposal, assigning each agent a connected piece of value at least \(2^{-(n-1)}\), using \(O(n2^n)\) queries. Its valuation model consists of nonnegative, normalized measures absolutely continuous with respect to length. The paper implements its queries using Robertson–Webb evaluation and mark queries. Algorithm 1 uses a fixed agent order; finite choices can be resolved by fixed tie-breaking rules, yielding a deterministic protocol. [Source: Theorem 1, Section 2, and Section 4](https://arxiv.org/html/1511.02599).

We apply this known theorem as supplied in the task.

Reduction and verification

Enumerate the support as \(T=\{t_1,\ldots,t_\tau\}\). Construct an instance with \(n=\tau\) agents by setting \(W_i=V_{t_i}\). A query to agent \(i\) is answered by the given oracle for type \(t_i\), so this construction introduces no additional valuation queries.

All theorem hypotheses hold:

  • The cake is \([0,1]\), as required.
  • Each \(W_i\) is a nonnegative, countably additive measure, absolutely continuous with respect to length, with \(W_i([0,1])=1\), directly by the premises.
  • Free disposal is permitted, and the required pieces are connected intervals.

Run the theorem’s protocol, obtaining pairwise disjoint intervals \(X_1,\ldots,X_\tau\), and set \(P_{t_i}=X_i\). For every pair of indices \(i,j\), its envy-freeness guarantee gives
\(V_{t_i}(P_{t_i})=W_i(X_i)\geq W_i(X_j)=V_{t_i}(P_{t_j})\).
Its value guarantee gives
\(V_{t_i}(P_{t_i})\geq 2^{-(\tau-1)}>0\).
Thus every allocation requirement in the question is satisfied. Absolute continuity implies that every singleton has value zero, so endpoint ownership does not affect these inequalities.

The masses \(\mu_t\) do not enter this construction: the stated feasibility conditions depend only on the indexed valuation measures. In particular, there is no need to expand rational masses into additional agents.

For \(\tau=1\), assign the entire cake with zero queries. For larger support sizes, the theorem provides a universal constant \(C\), enlarged if necessary to cover finitely many small sizes, such that the query count is at most \(f(\tau)=\lceil C\tau 2^\tau\rceil\). This bound is independent of the masses, their bit lengths, and the valuation measures.
