Input a finite project set \(P\), timesteps \([\ell]\), and an explicitly listed rational distribution \(\mu=(\mu_1,\ldots,\mu_R)\) over complete disapproval types \(D^r=(D^r_1,\ldots,D^r_\ell)\), with \(m=|P|\). Complexity of Checkpoint-Constrained Scheduling

Precise decision problem

Assume the positive-mass types are given by an explicit finite list with binary-encoded rational masses. Let the checkpoint list be

\(\mathcal A=\{(t_1,\lambda_1),\ldots,(t_q,\lambda_q)\}\).

The feasibility problem asks whether there exists a schedule \(o\in P^\ell\) such that

\(d_\theta(o^{(t_j)})\leq \lambda_j\)

for every checkpoint \(j\in[q]\) and every type \(\theta\) with \(\mu_\theta>0\).

Under this standard explicit-support encoding, the problem is \(\mathsf{NP}\)-complete.

Lemma: numerical masses are irrelevant

Let \(\mu\) and \(\nu\) be two mass vectors over the same temporal-disapproval types, and suppose

\(\{\theta:\mu_\theta>0\}=\{\theta:\nu_\theta>0\}\).

Then a schedule is feasible under \(\mu\) if and only if it is feasible under \(\nu\).

Proof

Every checkpoint constraint is imposed separately on every positive-mass type. Neither the prefix disutility \(d_\theta(o^{(t)})\) nor its upper bound contains the value of the mass. Hence feasibility depends only on the support of the mass vector. \(\square\)

Membership in \(\mathsf{NP}\)

A certificate is a schedule \(o=(o_1,\ldots,o_\ell)\in P^\ell\), whose encoding length is \(O(\ell\log |P|)\).

For each explicitly listed positive-mass type \(\theta\), compute the prefix sums

\(s_{\theta,t}=\sum_{k=1}^{t}\mathbf 1[o_k\in D_{\theta,k}]\).

Then check \(s_{\theta,t_j}\leq\lambda_j\) for every checkpoint \(j\). This takes time polynomial in the explicit input size. Therefore the problem belongs to \(\mathsf{NP}\).

Reduction from the finite-agent problem

Take an instance of the known finite-agent checkpoint-feasibility problem. Let its agent set be \(N=[n]\), and let agent \(i\) have temporal disapproval profile

\((D_{i,1},\ldots,D_{i,\ell})\).

Define an equivalence relation on agents by

\(i\sim i'\)

if and only if \(D_{i,k}=D_{i',k}\) for every \(k\in[\ell]\). For each equivalence class \(C\), introduce one type \(\theta_C\) with

\(D_{\theta_C,k}=D_{i,k}\)

for any \(i\in C\), and assign it rational mass

\(\mu_{\theta_C}=\frac{|C|}{n}\).

These masses are positive, sum to \(1\), and have binary encoding length \(O(\log n)\). The project set, horizon, checkpoints, and thresholds are copied unchanged.

For every schedule \(o\), every class \(C\), every \(i\in C\), and every prefix \(t\),

\(d_{\theta_C}(o^{(t)})=d_i(o^{(t)})\),

because \(\theta_C\) and \(i\) have exactly the same temporal disapproval profile. Consequently,

\(\forall C\;\forall j,\ d_{\theta_C}(o^{(t_j)})\leq\lambda_j\)

holds if and only if

\(\forall i\in N\;\forall j,\ d_i(o^{(t_j)})\leq\lambda_j\).

Thus the constructed mass-described instance admits a feasible schedule exactly when the original finite-agent instance does.

The equivalence classes and their masses can be computed in polynomial time by comparing or sorting the explicitly represented profiles. This is therefore a polynomial-time many-one reduction.

Since the finite-agent problem is \(\mathsf{NP}\)-hard by the given premise, the mass-described problem is also \(\mathsf{NP}\)-hard. Together with membership in \(\mathsf{NP}\), it is \(\mathsf{NP}\)-complete.

Preservation of the stated restrictions

The reduction does not change the number of projects or checkpoints. Hence hardness already holds with \(m=2\) and one checkpoint.

Moreover, if at a given timestep each project is disapproved by at most \(2\) finite agents, then it is disapproved by at most \(2\) positive-mass types after aggregation: every such type contains at least one distinct disapproving agent. Thus the natural type-support analogue of the incidence restriction is preserved.

Distinction from verification

If a particular schedule \(o\) is supplied as part of the input and the question is only whether that schedule satisfies all constraints, the problem is polynomial-time solvable by the prefix-sum calculation above.

The \(\mathsf{NP}\)-completeness result concerns the existential problem of deciding whether some feasible schedule exists.
