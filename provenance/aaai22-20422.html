The continuous mirror question, as graded

Given \(m,k\), a rational distribution \(\mu\) over nonempty approval types \(\sigma\subseteq\Sigma\), and a \(k\)-committee \(A\), decide whether there exists a non-trivial monotone ABCS scoring function \(f\) such that \(A\in\arg\max_{|C|=k}\sum_{\sigma}\mu_{\sigma}f(|C\cap\sigma|,|\sigma|)\).

Packaged proof task (what the prover saw — nothing else)

Let \(\Sigma\) be a set of \(m\) candidates, let \(1<k<m\), and let \(A\subseteq\Sigma\) have size \(k\). Approval types are nonempty proper subsets \(\sigma\subsetneq\Sigma\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Require \(\sum_\sigma\mu_\sigma=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length. State running times in \(m,\tau,L,k\).
An approval-based committee scoring (ABCS) function is \(f:X_{m,k}\to\mathbb R_{\ge0}\), where \(X_{m,k}=\{(x,y)\in\mathbb Z^2:1\le y\le m-1,\ \max\{0,y-m+k\}\le x\le\min\{k,y\}\}\). It is nondecreasing in \(x\) for each fixed \(y\); non-trivial means that \(f\) is not identically zero. No baseline normalization is imposed.
Define \(S_f(C)=\sum_\sigma\mu_\sigma f(|C\cap\sigma|,|\sigma|)\). A committee is winning when it maximizes this score among all size-\(k\) committees; ties are allowed.
Is deciding whether there exists a non-trivial ABCS function \(f\) for which \(A\) is winning solvable in polynomial time, or is it NP-hard?
For finite approval profiles, the corresponding existence problem is \(\mathrm{coW}[1]\)-hard parameterized by \(k\) (Caragiannis and Fehrs, *The Complexity of Learning Approval-Based Multiwinner Voting Rules*, 2022).

1. Answer under the stated definition

The stated problem is polynomial-time solvable: every valid instance is a YES-instance. The definition permits the constant function \(f(x,y)=1\).

To address the mathematically substantive interpretation as well, I will also analyze the variant requiring a strict increase in \(x\) somewhere. That variant is \(\mathrm{coNP}\)-complete.

Proof for the stated problem

Define \(f(x,y)=1\) for every \((x,y)\in X_{m,k}\). This function is nonnegative, nondecreasing in \(x\), and not identically zero. Every size-\(k\) committee \(C\) satisfies

\[ S_f(C)=\sum_\sigma\mu_\sigma=1. \]

Thus every committee maximizes the score, including \(A\). Ties are allowed, so this proves the claim.

On promised valid inputs, the decision algorithm simply returns YES, in time \(O(1)\), independently of \(m,\tau,L,k\). If input validity must also be checked, this takes \(\operatorname{poly}(m,\tau,L,k)\) time using exact rational arithmetic. The witness has a constant-size description; explicitly tabulating it takes \(O(mk)\) entries.

2. Baseline normalization changes non-triviality

For each ballot size \(y\), put

\[ \ell_y=\max\{0,y-m+k\},\qquad u_y=\min\{k,y\}. \]

Given any admissible function \(f\), define its normalized version by

\[ g(x,y)=f(x,y)-f(\ell_y,y). \]

Monotonicity implies \(g(x,y)\geq 0\), and \(g\) remains nondecreasing in \(x\). Moreover,

\[ S_g(C)=S_f(C)-\sum_\sigma\mu_\sigma f(\ell_{|\sigma|},|\sigma|). \]

The subtracted quantity is independent of \(C\). Consequently, \(f\) and \(g\) have exactly the same winning committees.

However, normalization need not preserve the task’s non-triviality condition. In particular, the constant witness from Section 1 normalizes to the zero function.

The full version of Caragiannis and Fehrs explicitly assumes \(f(\ell_y,y)=0\) for every \(y\); see Section 2, footnote 2. Their non-triviality condition therefore excludes every function depending only on ballot size. This explains why their hardness result does not apply to the definition in this task. [Full paper](https://arxiv.org/pdf/2110.00254)

For the remainder, define the strict-increase variant by replacing “not identically zero” with the requirement that

\[ f(x,y)>f(x-1,y) \]

for at least one feasible adjacent pair. By the normalization argument above, this is equivalent to requiring a normalized function \(g\) that is not identically zero.

3. An exact linear formulation of the strict-increase variant

Define the increment index set

\[ I=\{(x,y):1\leq y\leq m-1,\ \ell_y<x\leq u_y\}. \]

For a normalized scoring function, let

\[ d_{x,y}=g(x,y)-g(x-1,y). \]

Monotonicity is equivalent to \(d_{x,y}\geq 0\), and the function is recovered by

\[ g(z,y)=\sum_{x=\ell_y+1}^{z}d_{x,y}. \]

It is nonzero precisely when at least one increment is positive. Since multiplying scores by a positive constant preserves all winners, we may impose

\[ \sum_{(x,y)\in I}d_{x,y}=1. \]

The number of variables is exactly

\[ q=|I|=k(m-k). \]

Indeed, for each \(x\in\{1,\ldots,k\}\), the permitted ballot sizes are \(x\leq y\leq m-k+x-1\), giving exactly \(m-k\) choices.

For each size-\(k\) committee \(C\), define the rational vector \(a_C\), indexed by \(I\), by

\[ a_{C,(x,y)} =\sum_{\sigma:|\sigma|=y}\mu_\sigma \left( \mathbf{1}_{\{|A\cap\sigma|\geq x\}} -\mathbf{1}_{\{|C\cap\sigma|\geq x\}} \right). \]

Expanding the scores in increments and exchanging the finite sums gives

\[ S_g(A)-S_g(C)=a_C\cdot d. \]

Therefore the strict-increase variant is equivalent to feasibility of

\[ d\geq 0,\qquad \sum_{(x,y)\in I}d_{x,y}=1,\qquad a_C\cdot d\geq 0 \quad\text{for every size-\(k\) committee }C. \]

Both directions are exact: a suitable scoring function supplies feasible normalized increments, and feasible increments reconstruct a suitable scoring function.

There are \(\binom{m}{k}\) committee constraints. Each coefficient is computable from the listed support, with bit length polynomial in \(L\). Enumerating committees and solving this rational linear program consequently takes

\[ \operatorname{poly}\!\left(m,\tau,L,k,\binom{m}{k}\right) \]

time. In particular, this is polynomial for each fixed \(k\). The dependence on support size is through \(\tau\), rather than through the number of possible approval types.

4. A polynomial certificate for NO-instances

Proposition. The strict-increase variant belongs to \(\mathrm{coNP}\).

Let

\[ \Delta=\{d\in\mathbb{R}^{q}:d\geq 0,\ \sum_{i=1}^{q}d_i=1\}, \qquad H_C=\{d\in\mathbb{R}^{q}:a_C\cdot d\geq 0\}. \]

The linear formulation says that the instance is YES exactly when \(\Delta\cap\bigcap_C H_C\) is nonempty.

Use finite Helly’s theorem: if a finite family of convex subsets of \(\mathbb{R}^{q}\) has empty intersection, some subfamily of at most \(q+1\) sets already has empty intersection.

Its hypotheses hold here: the family is finite, and the simplex and all halfspaces are convex subsets of \(\mathbb{R}^{q}\). Furthermore, every \(H_C\) contains the origin. Thus any subfamily with empty intersection must include \(\Delta\).

It follows that every NO-instance admits committees \(C_1,\ldots,C_r\), with

\[ r\leq q=k(m-k), \]

such that

\[ \Delta\cap H_{C_1}\cap\cdots\cap H_{C_r}=\varnothing. \]

These committees form a polynomial-size certificate. A verifier checks their sizes, computes their coefficient vectors from the support, and solves the resulting rational linear feasibility problem.

The verification time is \(\operatorname{poly}(m,\tau,L,k)\). An infeasible subsystem certifies that the full system is infeasible; Helly’s theorem ensures that every NO-instance has such a certificate. This proves membership in \(\mathrm{coNP}\).

5. Hardness of the strict-increase variant

The needed published result is stronger than an abstract parameterized-hardness assertion: Caragiannis and Fehrs’ proof of Theorem 14 gives a polynomial-time reduction from the complement of Independent Set to their normalized existence problem, with \(k\) equal to the requested independent-set size. Its constructed ballots are nonempty proper subsets. [Theorem 14 and its proof](https://arxiv.org/pdf/2110.00254)

Apply that result to an explicitly listed finite profile \(P\) of \(n\) voters. Let \(n_\sigma\) be the number of occurrences of type \(\sigma\). Replace the profile by its support with masses

\[ \mu_\sigma=\frac{n_\sigma}{n}. \]

This transformation satisfies all relevant hypotheses:

  • Every listed mass is a positive rational encoded in binary.
  • The masses sum to one.
  • The support contains at most \(n\) types.
  • Each numerator and denominator requires \(O(\log n)\) bits.
  • Ballot validity and the designated committee are preserved.

The transformation has polynomial running time and output length in the explicit profile’s input length. Crucially, for every scoring function and committee,

\[ S_f(C)=\frac{1}{n}\operatorname{sc}_f(C,P). \]

Hence every score comparison, including every tie, is preserved exactly. Normalized nonzero functions are precisely the normalized representatives of functions satisfying the strict-increase condition established in Section 2.

Composing the published reduction with this support conversion proves \(\mathrm{coNP}\)-hardness. Together with Section 4, this yields:

The strict-increase variant is \(\mathrm{coNP}\)-complete.

Under polynomial-time many-one reductions, calling this variant \(\mathrm{NP}\)-hard would imply \(\mathrm{NP}=\mathrm{coNP}\). Under polynomial-time Turing reductions it is \(\mathrm{NP}\)-hard, since one may negate the answer to a query produced by the reduction from the complement of Independent Set.

The task as explicitly defined, however, remains the constant-YES problem proved in Section 1.
