The continuous mirror question, as graded

Given \(m,k\), a rational distribution \(\mu\) over nonempty approval types \(\sigma\subseteq\Sigma\), and a \(k\)-committee \(A\), decide whether there exists a non-trivial monotone ABCS scoring function \(f\) such that \(A\in\arg\max_{|C|=k}\sum_{\sigma}\mu_{\sigma}f(|C\cap\sigma|,|\sigma|)\).

Packaged proof task (what the prover saw — nothing else)

Let \(\Sigma\) contain \(m\) candidates, let \(1<k<m\), and let \(A\subseteq\Sigma\) have size \(k\). Approval types are nonempty proper subsets \(\sigma\subsetneq\Sigma\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational, with \(\sum_\sigma\mu_\sigma=1\). Here \(\tau\) is the support size, not the number of possible approval types; let \(L\) be the total input bit length. State running times in \(m,\tau,L,k\).
Define \(X_{m,k}=\{(x,y)\in\mathbb Z^2:1\le y\le m-1,\ \max\{0,y-m+k\}\le x\le\min\{k,y\}\}\). An ABCS scoring function is \(f:X_{m,k}\to\mathbb R_{\ge0}\), nondecreasing in its first argument for each fixed second argument. Non-trivial means \(f\not\equiv0\); no baseline normalization is imposed.
For each committee \(C\), define \(S_f(C)=\sum_\sigma\mu_\sigma f(|C\cap\sigma|,|\sigma|)\). All committees attaining the maximum score win, including ties.

Is deciding whether there exists such a non-trivial scoring function \(f\) with \(S_f(A)\ge S_f(C)\) for every \(k\)-committee \(C\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite approval profiles, TARGETABCS is reported to be \(\mathrm{coW}[1]\)-hard parameterized by \(k\). [Caragiannis and Fehrs](https://cs.au.dk/~iannis/publ/C106-aaai22.pdf)
The literature search located no classification explicitly addressing this rational-mass formulation.

1. Answer under the stated definition

The problem is in \(\mathrm P\). Every valid instance is YES. Indeed, the constant function \(f(x,y)=1\) satisfies the stated definition of non-triviality. Below, I also classify the distinct variant requiring a positive scoring increment.

For completeness, verify the constant witness:

  • It is nonnegative and nondecreasing in its first argument.
  • It is not identically zero.
  • For every \(k\)-committee \(C\), its score is \(S_f(C)=\sum_\sigma\mu_\sigma=1\).

Consequently, \(S_f(A)=S_f(C)\) for every committee \(C\). Since ties win, \(A\) wins.

On promised valid inputs, the decision algorithm simply returns YES in \(O(1)\) time, independently of \(m,\tau,L,k\). Reading and validating the input, if required, takes \(\operatorname{poly}(m,\tau,L,k)\) time. The witness has a constant-size description; explicitly listing its values requires \(O(mk)\) entries.

2. Why baseline normalization changes the question

Define \(a_y=\max\{0,y-m+k\}\) and \(b_y=\min\{k,y\}\). For any admissible \(f\), define its baseline-normalized version by \(g(x,y)=f(x,y)-f(a_y,y)\).

Monotonicity implies that \(g\) is nonnegative and nondecreasing, with \(g(a_y,y)=0\). Moreover,

\(S_g(C)=S_f(C)-\sum_\sigma\mu_\sigma f(a_{|\sigma|},|\sigma|)\).

The subtracted quantity is independent of \(C\). Thus normalization preserves every score comparison and every winning committee.

However, it does not preserve the specified non-triviality condition: the nonzero constant witness becomes the zero function.

This distinction is explicit in the full version of Caragiannis–Fehrs: Section 2, footnote 2 imposes \(f(a_y,y)=0\) throughout and identifies functions depending only on ballot size with the trivial rule. Their hardness result therefore concerns a different non-triviality requirement. [Full version](https://arxiv.org/pdf/2110.00254#page=5)

3. The positive-increment variant: an exact linear formulation

Consider the following separately defined variant: require \(f(a_y,y)=0\) for every \(y\), and require \(f\not\equiv0\). Equivalently, without fixing baselines, require at least one positive increment in the first argument.

Let \(D=\{(j,y):1\le y\le m-1,\ a_y<j\le b_y\}\). Introduce increments \(\delta_{j,y}=f(j,y)-f(j-1,y)\) for \((j,y)\in D\).

Normalized admissible functions correspond exactly to vectors \(\delta\ge0\), through \(f(x,y)=\sum_{j=a_y+1}^{x}\delta_{j,y}\). Such a function is nonzero exactly when \(\sum_{(j,y)\in D}\delta_{j,y}>0\). Positive scaling preserves score comparisons, so we may impose \(\sum_{(j,y)\in D}\delta_{j,y}=1\).

There are exactly \(d=|D|=k(m-k)\) variables. To verify this count, the map \((j,y)\mapsto(j,y-j)\) is a bijection from \(D\) to \(\{1,\ldots,k\}\times\{0,\ldots,m-k-1\}\):

  • The bounds defining \(D\) imply \(1\le j\le k\), \(j\le y\), and \(y-j\le m-k-1\).
  • Conversely, these three inequalities imply \(a_y<j\le b_y\), with \(1\le y\le m-1\).

For a committee \(C\), define its threshold-mass vector by

\(p_{j,y}(C)=\sum_{\sigma:\,|\sigma|=y,\ |C\cap\sigma|\ge j}\mu_\sigma\).

Expanding the finite sums gives \(S_f(C)=\sum_{(j,y)\in D}p_{j,y}(C)\delta_{j,y}\). Therefore the variant is YES precisely when the following system is feasible:

\(\delta_{j,y}\ge0\quad\text{for every }(j,y)\in D,\)

\(\sum_{(j,y)\in D}\delta_{j,y}=1,\)

\(\sum_{(j,y)\in D}\bigl(p_{j,y}(A)-p_{j,y}(C)\bigr)\delta_{j,y}\ge0\quad\text{for every }k\text{-committee }C.\)

These are weak inequalities, so the formulation preserves ties.

All coefficients are computed directly from the \(\tau\) supported types. Their bit lengths are polynomial in \(L\): a common denominator obtained by multiplying the input denominators has bit length at most their total input bit length, and each threshold mass lies in \([0,1]\).

Enumerating the committees and solving this rational linear program takes

\(\operatorname{poly}\!\left(\binom{m}{k},m,\tau,L,k\right)\)

time. No expansion of rational masses into individual voters is needed.

4. The positive-increment variant belongs to \(\mathrm{coNP}\)

Let \(\Delta=\{\delta\in\mathbb R^d:\delta\ge0,\ \sum_i\delta_i=1\}\). For each committee \(C\), let \(H_C\) be the halfspace defined by its score-comparison inequality.

All these sets lie in the affine space \(E=\{\delta:\sum_i\delta_i=1\}\), whose dimension is \(d-1\). The linear formulation says that the variant is NO exactly when \(\Delta\cap\bigcap_C H_C=\varnothing\).

Apply Helly’s theorem: a finite family of convex subsets of an affine space of dimension \(r\) has empty intersection only if some subfamily of at most \(r+1\) sets has empty intersection. Here the family is finite, every member is convex, and \(r=d-1\). Thus at most \(d\) sets suffice.

In particular, there are at most \(d\) committees \(C_1,\ldots,C_q\) such that \(\Delta\cap H_{C_1}\cap\cdots\cap H_{C_q}=\varnothing\). If Helly’s subfamily omits \(\Delta\), adjoining \(\Delta\) preserves emptiness.

A NO certificate therefore lists at most \(k(m-k)\) committees. A verifier computes their coefficient vectors and checks infeasibility of the resulting rational linear program in \(\operatorname{poly}(m,\tau,L,k)\) time.

Under the usual explicit candidate encoding, this certificate and verification time are polynomial in the input length. Hence the variant is in \(\mathrm{coNP}\).

A useful additional observation is that an absent ballot size makes this variant YES. If no supported type has size \(y\), choose one positive increment at that size and set every other increment to zero. Every supported ballot then contributes zero to every committee. Such an increment exists because \(a_y<b_y\) whenever \(1\le y<m\) and \(0<k<m\).

5. Hardness transfers to rational support for the normalized variant

The known result needed here is precise: the proof of Caragiannis–Fehrs, Theorem 14, gives a polynomial-time many-one reduction from the complement of Independent Set to normalized TARGETABCS. Its instances use nonempty proper ballots, weak monotonicity, normalized nonzero scoring functions, and winning with ties. These hypotheses match the variant defined above. [Theorem 14 and its proof](https://arxiv.org/pdf/2110.00254#page=11)

Because Independent Set is \(\mathrm{NP}\)-complete, this establishes \(\mathrm{coNP}\)-hardness for the finite-profile variant.

It remains to verify that support compression preserves this reduction. Suppose a finite profile contains \(N\) voters and type \(\sigma\) occurs \(n_\sigma\) times. Assign the binary-encoded rational mass \(\mu_\sigma=n_\sigma/N\). Then, for every scoring function and committee,

\(S_f(C)=\sum_\sigma\frac{n_\sigma}{N}f(|C\cap\sigma|,|\sigma|)=\frac1N\sum_{i=1}^{N}f(|C\cap\sigma_i|,|\sigma_i|)\).

Thus compression preserves every score comparison, including equality, and preserves the existence question exactly.

Grouping identical ballots takes polynomial time in the explicit finite-profile size. The resulting support satisfies \(\tau\le N\), and each mass requires \(O(\log N)\) bits. Consequently, the published polynomial reduction remains polynomial after compression.

Combining this hardness transfer with Section 4 proves that the normalized positive-increment variant is \(\mathrm{coNP}\)-complete. This classification does not apply to the stated normalization-free problem, whose constant witness settles every instance.
