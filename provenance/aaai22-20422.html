The continuous mirror question, as graded

Given \(m,k\), a rational distribution \(\mu\) over nonempty approval types \(\sigma\subseteq\Sigma\), and a \(k\)-committee \(A\), decide whether there exists a non-trivial monotone ABCS scoring function \(f\) such that \(A\in\arg\max_{|C|=k}\sum_{\sigma}\mu_{\sigma}f(|C\cap\sigma|,|\sigma|)\).

Packaged proof task (what the prover saw — nothing else)

Definitions. Let Σ be a candidate set of size \(m\), and let \(\mu\) be explicitly given by its positive rational masses \(\mu_\sigma\) on nonempty proper types \(\sigma\subsetneq\Sigma\), with \(\sum_\sigma\mu_\sigma=1\). A committee has size \(k\).
An ABCS scoring function is a nonzero \(f:X_{m,k} o\mathbb R_{\geq0}\), monotone in its first argument, where \(X_{m,k}=\{(x,y):1\leq y\leq m-1,\ \max\{0,y-m+k\}\leq x\leq\min\{k,y\}\}\).
For a committee \(C\), its score is \(S_f(C)=\sum_\sigma\mu_\sigma f(|C\cap\sigma|,|\sigma|)\). The given committee \(A\) is winning when \(A\in\arg\max_{|C|=k}S_f(C)\).

Target. Is this continuous problem solvable in polynomial time, or is it NP-hard?
If it is NP-hard, is it fixed-parameter tractable when parameterized by \(k\)?

Nearest known results. For explicitly listed finite approval profiles, the corresponding TARGETABCS problem is coW[1]-hard parameterized by \(k\).

Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Result

Under the stated definitions, the problem is polynomial-time solvable—in fact, every valid instance is a YES-instance.

Proof

Define \(f:X_{m,k}\to\mathbb R_{\geq 0}\) by

\[ f(x,y)=1 \]

for every \((x,y)\in X_{m,k}\).

This function satisfies every stated requirement:

  • It is nonzero.
  • It is nonnegative.
  • For each fixed \(y\), it is monotone in \(x\), since \(f(x,y)=f(x+1,y)=1\) whenever both arguments belong to \(X_{m,k}\).

For every committee \(C\) of size \(k\), its score is

\[ S_f(C) =\sum_{\sigma}\mu_\sigma f(|C\cap\sigma|,|\sigma|) =\sum_{\sigma}\mu_\sigma =1. \]

Thus every size-\(k\) committee receives exactly the same score. In particular,

\[ A\in\operatorname*{arg\,max}_{|C|=k}S_f(C). \]

Hence a valid witnessing scoring function exists for every input instance.

Complexity Consequences

The decision algorithm can simply return YES. It therefore runs in constant time on promised well-formed inputs, and certainly in polynomial time.

The parameterized problem is also fixed-parameter tractable with respect to \(k\), again because the answer is always YES.

The quoted hardness result for finite approval profiles cannot apply to the problem exactly as defined here. Such a result must impose an additional nontriviality condition excluding committee-independent scoring functions—for example, requiring at least one strict marginal increase,

\[ f(x+1,y)>f(x,y), \]

or imposing a normalization such as \(f(0,y)=0\) together with positivity at some attainable \(x>0\). Merely requiring \(f\neq 0\) does not exclude the constant function.

Verification Report

Summary

The prover’s conclusion is correct under the definitions as written. The constant scoring function is admissible and makes every size-\(k\) committee a winner. Therefore every well-formed instance is a YES-instance, yielding a polynomial-time—and indeed constant-decision—algorithm.

Step-by-step verification

  • Admissibility of the proposed function.

The function \(f(x,y)=1\) is defined on all of \(X_{m,k}\), is nonzero, takes only nonnegative values, and is monotone in its first argument. Equality between consecutive values is permitted because “monotone” does not require strict increase.

  • Applicability to committee/type pairs.

For every size-\(k\) committee \(C\) and type \(\sigma\) of size \(y\), the intersection size \(x=|C\cap\sigma|\) satisfies
\[ \max\{0,y-m+k\}\leq x\leq\min\{k,y\}, \]
so \((|C\cap\sigma|,|\sigma|)\in X_{m,k}\). Thus every evaluation of \(f\) in the score is defined.

  • Score calculation.

Substituting \(f=1\) gives
\[ S_f(C)=\sum_\sigma\mu_\sigma=1, \]
using the stated normalization of \(\mu\). This calculation is correct for every size-\(k\) committee.

  • Winning condition.

Since all feasible committees have the same score, every such committee lies in the argmax. Hence the given committee \(A\) is winning, assuming—as part of a well-formed instance—that \(A\) has size \(k\).

  • Complexity conclusion.

On the promised domain of well-formed instances, an algorithm that always returns YES is correct. It is polynomial-time and fixed-parameter tractable with respect to \(k\).

  • Relationship to the quoted hardness result.

The observation that the finite-profile hardness result cannot apply unchanged is justified: the admissible constant function trivializes the existential winning-function question. The suggested additional restrictions are illustrative and are not needed for the proof.

No substantive gaps, false claims, or missing lemmas were found.
