The continuous mirror question, as graded

Given a support of operational roles \(T\), positive rational masses \(\mu_t\) summing to \(1\), and an undirected graph \(H\) on \(T\), define \(v_H(S)=1\) when the induced graph \(H[S]\) is connected and \(0\) otherwise, with \(v_H(\varnothing)=0\). Compute exactly, for each \(t\in T\), the cohort total \(\Phi_t=\mu_t q_t\), where \(q_t=\sum_{S\subseteq T\setminus\{t\}}\frac{|S|!(|T|-|S|-1)!}{|T|!}(v_H(S\cup\{t\})-v_H(S))\).

A society is given by its support: a nonempty list \(T\) of \(\tau\) operational types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The input also contains a simple undirected graph \(H=(T,E)\), possibly disconnected. Put \(m=|E|\), and let \(L\) be the total binary input length.
For \(S\subseteq T\), define \(v_H(S)=1\) if \(S\ne\varnothing\) and \(H[S]\) is connected, and \(v_H(S)=0\) otherwise; singletons are connected.
For each \(t\in T\), define \(q_t=\sum_{S\subseteq T\setminus\{t\}}\frac{|S|!(\tau-|S|-1)!}{\tau!}\bigl(v_H(S\cup\{t\})-v_H(S)\bigr)\) and the cohort total \(\Phi_t=\mu_tq_t\). The computational problem is to compute all \(\Phi_t\) exactly as rational numbers.

Is this exact computation solvable in time polynomial in \(m,\tau,L\), or is it NP-hard under polynomial-time Turing reductions?

The hardness theorem applies to the stated game

We use the supplied discrete connectivity-game hardness result: given a simple undirected graph, computing the Shapley value of every vertex for the game assigning value one to nonempty connected induced coalitions and zero otherwise is \(\#\mathrm{P}\)-hard under polynomial-time Turing reductions. This is Definition 2 and Theorem 2 of [Michalak et al., *Computational Analysis of Connectivity Games*](https://www.ijcai.org/Proceedings/13/Papers/052.pdf).

Its hypotheses match the present problem: players are vertices, connectivity is within the induced coalition, the empty coalition has value zero, and singletons are connected. Disconnected input graphs are permitted.

For a graph with vertex set \(T\), the ordinary Shapley value of vertex \(t\) is therefore exactly the quantity \(q_t\) in the question. In particular, the masses do not enter the definition of \(q_t\).

A polynomial reduction using positive dyadic masses

Let \(G=(V,E)\) be an instance of the discrete problem, with \(n=|V|\geq 1\). Enumerate its vertices as \(v_1,\ldots,v_n\). We construct a society whose support is \(T=V\) and whose graph is \(H=G\).

To accommodate even the restrictive interpretation of “binary-rational” as “dyadic rational,” set

\(D=2^{\lceil\log_2 n\rceil}\),

and assign

\(\mu_{v_j}=1/D\quad(1\leq j<n),\qquad \mu_{v_n}=(D-n+1)/D.\)

Since \(D\geq n\), every mass is positive. Moreover,

\(\displaystyle\sum_{j=1}^{n}\mu_{v_j}=\frac{n-1+D-n+1}{D}=1.\)

Thus the constructed society satisfies every input requirement, including when \(n=1\). Each mass has encoding length \(O(\log(n+1))\), so all mass labels together require \(O(n\log(n+1))\) bits. The construction preserves the graph and uses support size \(\tau=n\); there is no expansion into a larger collection of possible types.

Make one oracle call for all exact cohort totals. For each vertex, recover

\(\displaystyle q_{v_j}=\frac{\Phi_{v_j}}{\mu_{v_j}}.\)

This division is valid because every mass is nonzero. Since \(H=G\), the recovered vector is precisely the requested discrete Shapley vector.

It remains to verify that exact arithmetic and oracle output lengths are polynomially bounded.

Exact arithmetic and the complexity conclusion

For any vertex \(t\), write

\(\displaystyle a_t=\sum_{S\subseteq T\setminus\{t\}}|S|!(n-|S|-1)!\bigl(v_H(S\cup\{t\})-v_H(S)\bigr).\)

Every summand is an integer, and \(q_t=a_t/n!\). Each marginal contribution belongs to \(\{-1,0,1\}\). Furthermore,

\(\displaystyle\sum_{S\subseteq T\setminus\{t\}}|S|!(n-|S|-1)!=n!.\)

Indeed, for a fixed predecessor set \(S\), precisely \(|S|!(n-|S|-1)!\) permutations place exactly the vertices of \(S\) before \(t\); these cases partition all permutations. Consequently, \(|a_t|\leq n!\).

If \(\mu_t=p_t/d_t\) is given by binary integers, then

\(\displaystyle\Phi_t=\frac{p_ta_t}{d_tn!}.\)

Its numerator and denominator therefore have \(O(L+n\log(n+1))\) bits. Reducing this fraction, or dividing it by a nonzero input mass, takes polynomial time using integer arithmetic. The complete output vector also has polynomial length.

We have thus given a polynomial-time, one-call reduction from the discrete Shapley-vector problem to the mass-labelled problem. Composing it with the supplied hardness reduction proves \(\#\mathrm{P}\)-hardness.

For the requested decision-complexity consequence, this oracle can compute the number of satisfying assignments of a Boolean formula by that composition. Testing whether the resulting count is positive decides satisfiability. Hence the cohort-total problem is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions.

A polynomial-time algorithm in \(m,\tau,L\) would therefore imply \(\mathrm{P}=\mathrm{NP}\). No separate hardness theorem for the mass-labelled formulation is needed.
