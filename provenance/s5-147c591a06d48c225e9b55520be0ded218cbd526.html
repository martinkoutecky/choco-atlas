The continuous mirror question, as graded

Given a finite conflict graph \(G=(V,E)\) with a supplied \(\ell\)-expression, a finite support \(T\) of complete valuation types with rational masses \(\mu_t\ge 0\) summing to \(1\), integer profits \(p_t(v)\ge 0\), and rational per-capita stocks \(b_v\ge 0\), what is the largest integer \(q\) for which there exist nonnegative rational masses \(x_{t,S}\), over types \(t\in T\) and independent sets \(S\) of \(G\), such that \(\sum_{S:p_t(S)\ge q}x_{t,S}=\mu_t\) for every \(t\), and \(\sum_{t\in T}\sum_{S\ni v,\ p_t(S)\ge q}x_{t,S}\le b_v\) for every \(v\in V\)?

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,E)\) be a finite simple undirected conflict graph with \(m=|V|\), supplied with an \(\ell\)-expression \(\sigma\). Fix a positive integer \(\ell\); the support size is unrestricted.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) counts supported types, not all possible types.
Each type specifies its complete additive valuation \(p_t:V\to\mathbb Z_{\ge0}\), encoded in binary; write \(p_t(S)=\sum_{v\in S}p_t(v)\). Each item has binary rational per-capita stock \(b_v\ge0\). Let \(L\) be the total input bit length, including \(\sigma\).
For an integer threshold \(q\ge0\), let \(\mathcal I_t(q)=\{S\subseteq V:S\text{ is independent in }G,\ p_t(S)\ge q\}\). Feasibility means that rational masses \(x_{t,S}\ge0\), indexed by \(S\in\mathcal I_t(q)\), satisfy \(\sum_{S\in\mathcal I_t(q)}x_{t,S}=\mu_t\) for every type and \(\sum_{t\in T}\sum_{S\in\mathcal I_t(q):v\in S}x_{t,S}\le b_v\) for every item. Empty bundles are allowed; stocks may remain unused.
The optimization problem asks for the largest feasible integer \(q\).

For each fixed \(\ell\), is threshold feasibility in \(\mathsf P\), or is it \(\mathsf{NP}\)-hard? State running times in \(m,\tau,L,\ell\), and \(|\sigma|\).

For discrete agents, maximizing the minimum profit over pairwise disjoint independent bundles admits time \(\mathcal O(4^{k\ell}|\sigma|(Q+1)^{2k})\), where \(k\) is the number of agents and \(Q=\max_j p_j(V)\); this is pseudo-polynomial for fixed \(k,\ell\). [Source](https://link.springer.com/article/10.1007/s40314-023-02437-0).
The discrete problem is weakly \(\mathsf{NP}\)-hard even on edgeless graphs with two identical agents. [Source](https://link.springer.com/article/10.1007/s00453-022-01079-8). No result settling the exact mass problem above was located.

Result

For every fixed positive integer \(\ell\), threshold feasibility is \(\mathsf{NP}\)-complete. Hardness already holds when \(\tau=1\), \(G\) is edgeless, and every stock equals \(\tfrac12\).

There is also an exact pseudo-polynomial algorithm. For some fixed polynomial \(P\), threshold feasibility can be decided in
\[ \]
\( \displaystyle \mathcal O\!\left( L+ P(m+\tau+L+\ell)\, \tau\,4^\ell(|\sigma|+1)(q+1)^2 \right) \)
bit operations. The proof below establishes this bound without treating \(\tau\) as a constant.

Let \(U=\min_{t\in T}p_t(V)\). The largest feasible integer threshold can be computed in
\( \displaystyle \mathcal O\!\left( L+ P(m+\tau+L+\ell)\, \tau\,4^\ell(|\sigma|+1)(U+1)^2 \log(U+2) \right). \)

These are pseudo-polynomial bounds because valuations and thresholds are encoded in binary. In particular, a polynomial-time algorithm in the input length for any fixed positive \(\ell\) would imply \(\mathsf P=\mathsf{NP}\).

1. Hardness for one type on an edgeless graph

We reduce from the standard \(\mathsf{NP}\)-complete problem Partition: given positive integers \(a_1,\ldots,a_m\) in binary, determine whether a subset has half their total sum. Its \(\mathsf{NP}\)-completeness is a classical result of [Karp](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Write \(A=\sum_{i=1}^m a_i\). Construct the following instance:

  • \(G\) is edgeless, with vertices \(v_1,\ldots,v_m\).
  • There is one supported type \(t\), with \(\mu_t=1\).
  • Set \(p_t(v_i)=2a_i\).
  • Set \(b_{v_i}=\tfrac12\) for every item.
  • Set \(q=A\).

The graph has a one-label expression consisting of vertex creation and disjoint union, with \(\mathcal O(m)\) operation nodes. This is also an \(\ell\)-expression for every positive \(\ell\), since additional labels need not be used. The entire construction has polynomial encoding length.

A partition gives a feasible mass allocation

Suppose \(S\subseteq V\) corresponds to a partition, so that \(p_t(S)=A\). Since \(p_t(V)=2A\), its complement also has value \(A\).

Assign mass \(\tfrac12\) to \(S\) and mass \(\tfrac12\) to \(V\setminus S\). Both bundles meet the threshold, their masses sum to one, and every item is consumed with mass exactly \(\tfrac12\). Hence the instance is feasible.

A feasible mass allocation gives a partition

Conversely, suppose the constructed instance is feasible. Suppress the type index, and let
\(c_i=\sum_{S:\,v_i\in S}x_S\)
be the consumed mass of item \(v_i\). Thus \(c_i\le\tfrac12\).

Every bundle receiving positive mass has value at least \(A\), and the masses sum to one. Consequently,
\( \displaystyle A \le \sum_S x_Sp_t(S) = \sum_{i=1}^m 2a_i c_i \le \sum_{i=1}^m 2a_i\cdot\tfrac12 = A. \)

Both inequalities are therefore equalities. In particular,
\( \displaystyle \sum_S x_S\bigl(p_t(S)-A\bigr)=0. \)

Each summand is nonnegative. Hence every bundle receiving positive mass has value exactly \(A\). At least one such bundle exists because the total mass is one. For that bundle,
\( \displaystyle \sum_{i:\,v_i\in S}a_i=\frac A2, \)
which is a partition.

This argument also handles odd \(A\): no subset of the even item values can sum to the odd threshold \(A\).

Thus threshold feasibility is \(\mathsf{NP}\)-hard under the stated restrictions. Fractional allocation does not invalidate the reduction: the stock constraints force the average value to equal the threshold, and therefore force exact equality for every positively weighted bundle.

2. Polynomial certificates: membership in \(\mathsf{NP}\)

Fix any feasible instance and threshold. Introduce stock slack variables \(s_v\ge0\), obtaining
\( \displaystyle \sum_{S\in\mathcal I_t(q)}x_{t,S}=\mu_t, \qquad \sum_{t,S:\,v\in S}x_{t,S}+s_v=b_v. \)

There are \(r=m+\tau\) equations. Their coefficient matrix has only zero and one entries:

  • A bundle column has a one in its type row and in the rows of its items.
  • A slack column has a one only in its item row.

Although there may be exponentially many bundle columns, there is a feasible solution whose positive columns are linearly independent.

Indeed, take a feasible solution with minimum support. If its positive columns were dependent, there would be a nonzero vector \(d\), supported on those columns, with \(Ad=0\). Every column is nonzero and nonnegative, so \(d\) must have both positive and negative coordinates. Moving in direction \(d\) until the first positive coordinate becomes zero preserves all equations and nonnegativity, while reducing the support. This contradicts minimality.

Therefore at most \(r\) coordinates are positive, and in particular at most \(m+\tau\) bundles receive positive mass.

These masses also have polynomial encoding length. Let \(s\le r\) be the number of positive coordinates. Select \(s\) rows making the corresponding \(s\)-column matrix an invertible square matrix \(B\). Let \(D\) be the product of the denominators appearing in the masses and stocks. Its bit length is \(\mathcal O(L)\). The positive coordinates solve
\( \displaystyle Bz=h, \)
where \(Dh\) is integral with entries of bit length \(\mathcal O(L)\).

By Cramer’s rule, each coordinate is a ratio with denominator \(D\det B\). Hadamard’s inequality gives
\( \displaystyle |\det B|\le s^{s/2}. \)
Applying the same inequality to the matrices with one column replaced by \(Dh\) bounds the numerator bit lengths by
\(\mathcal O(L+s\log(s+1))\).
Thus every positive mass has polynomial bit length.

A certificate lists the selected bundles, their types, and their rational masses. A verifier checks independence, threshold values, type totals, and stock inequalities using exact rational arithmetic in time polynomial in \(m,\tau,L,\ell,|\sigma|\).

Hence threshold feasibility belongs to \(\mathsf{NP}\). Together with Section 1, this proves the claimed \(\mathsf{NP}\)-completeness.

3. An exact allocation LP with a bounded dual

To obtain the algorithm, consider the finite linear program
\( \displaystyle \max \sum_{t\in T}\sum_{S\in\mathcal I_t(q)}x_{t,S} \)
subject to
\( \displaystyle \sum_{S\in\mathcal I_t(q)}x_{t,S}\le\mu_t \quad(t\in T), \)
\( \displaystyle \sum_{t,S:\,v\in S}x_{t,S}\le b_v \quad(v\in V), \qquad x_{t,S}\ge0. \)

The zero allocation is feasible, and the objective is at most \(\sum_t\mu_t=1\). Its optimum equals one exactly when the original threshold problem is feasible: an objective value of one forces every type inequality to be tight because all type deficits are nonnegative and sum to zero.

The dual is
\( \displaystyle \min\left(\sum_t\mu_t a_t+\sum_v b_v y_v\right) \)
subject to
\( \displaystyle a_t+\sum_{v\in S}y_v\ge1 \quad(t\in T,\ S\in\mathcal I_t(q)), \qquad a_t,y_v\ge0. \)

We may additionally impose \(a_t\le1\) and \(y_v\le1\). To see this, truncate every coordinate exceeding one to one. Any affected constraint then contains a coordinate equal to one and has all other coordinates nonnegative, so it remains satisfied. Unaffected constraints remain satisfied as well. Since objective coefficients are nonnegative, truncation cannot increase the objective.

Thus the dual has \(m+\tau\) variables in a known bounded cube. Its constraint coefficients are zero or one, and its objective has input bit length \(\mathcal O(L)\). It is nonempty: take every \(a_t=1\) and every \(y_v=0\).

The rational separation–optimization theorem allows exact optimization of such a bounded rational polytope with polynomially many separation calls and polynomial arithmetic overhead; see [Grötschel, Lovász, and Schrijver](https://www.zib.de/userpage/groetschel/pubnew/paper/groetschellovaszschrijver1981a.pdf). Here the dimension, coefficient encoding lengths, objective encoding length, and bounding cube all satisfy its polynomial-size hypotheses.

It remains to supply a separation oracle.

4. Separation using the supplied expression

After checking the cube constraints, separation reduces, for each supported type \(t\), to computing
\( \displaystyle C_t(y)= \min\left\{ \sum_{v\in S}y_v: S\text{ independent in }G,\ p_t(S)\ge q \right\}. \)

Set \(C_t(y)=+\infty\) if no qualifying bundle exists. A violated constraint exists precisely when some \(a_t+C_t(y)<1\). A minimizing bundle supplies that constraint.

Dynamic programming states

Fix \(t\). At every node of the expression tree, let \(H\) be its labeled graph. For
\(M\subseteq\{1,\ldots,\ell\}\)
and \(h\in\{0,\ldots,q\}\), store
\( \displaystyle D_H(M,h)= \min\left\{ \sum_{v\in S}y_v: S\subseteq V(H)\text{ independent}, \ \operatorname{labels}_H(S)=M, \ \min\{q,p_t(S)\}=h \right\}. \)

An impossible state has value \(+\infty\). Store predecessor choices to recover a minimizing bundle.

Capping profit at \(q\) is valid because profits are nonnegative and
\( \displaystyle \min\{q,u+v\} = \min\{q,\min\{q,u\}+\min\{q,v\}\} \)
for all nonnegative \(u,v\).

Expression operations

  • Create a vertex \(v\) with label \(i\).

The empty selection gives state \((\varnothing,0)\) with cost zero. Selecting \(v\) gives state \((\{i\},\min\{q,p_t(v)\})\) with cost \(y_v\).

  • Disjoint union \(H=H_1\oplus H_2\).

Combine every pair of finite states, producing
\( \displaystyle \left(M_1\cup M_2,\ \min\{q,h_1+h_2\}\right) \)
with cost \(D_{H_1}(M_1,h_1)+D_{H_2}(M_2,h_2)\). Take the minimum over all ways to obtain each state. There are no edges between the children, so their independent selections combine freely.

  • Join distinct labels \(i,j\).

Discard exactly the states containing both labels. Such a selection acquires an edge between two selected vertices. Every other state remains valid with its existing cost.

  • Relabel \(i\) to \(j\).

Replace each mask containing \(i\) by \((M\setminus\{i\})\cup\{j\}\); leave other masks unchanged. When states coincide, retain the minimum cost. Relabeling changes neither independence nor profit.

Induction over the expression tree proves the stated meaning of every table. At the root,
\( \displaystyle C_t(y)=\min_M D_G(M,q). \)

Running time

There are at most \(2^\ell(q+1)\) states per expression node. A disjoint union examines at most \(4^\ell(q+1)^2\) state pairs. Including mask manipulation, one type requires
\( \displaystyle \mathcal O\!\left(\ell\,4^\ell|\sigma|(q+1)^2\right) \)
arithmetic operations. Unary operations are bounded by this same expression.

Run the dynamic program independently for all \(\tau\) supported types. Oracle queries have polynomial rational encoding length, and each finite table entry is a sum of at most \(m\) query coordinates, so exact arithmetic has polynomial bit overhead.

Combining this oracle with exact dual optimization gives the running time stated at the beginning. The dependence on support size is polynomial; it does not occur in the exponent of \(q+1\).

5. Computing the optimal threshold

Threshold zero is feasible by assigning every type its empty bundle. A threshold exceeding
\(U=\min_t p_t(V)\)
is infeasible because at least one positive-mass type then has no qualifying bundle.

Feasibility is monotone: if an allocation meets threshold \(q\), it also meets every smaller nonnegative threshold. Binary search on the integers from zero to \(U\) therefore computes the optimum with \(\mathcal O(\log(U+2))\) feasibility calls. Bounding each call by its running time at \(q=U\) gives the optimization bound above.

Computing this optimum is \(\mathsf{NP}\)-hard, since it would decide threshold feasibility by comparison with the requested threshold.
