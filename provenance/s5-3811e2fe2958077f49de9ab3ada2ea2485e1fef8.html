Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given candidates \(C\) and an explicit support of \(\tau\) strict-partial-order ballot types with positive rational masses \(\mu_t\) summing to one, compute a Schulze-maximal candidate and determine whether it is unique.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set with \(m=|C|\). A society is given by its support: the list of \(\tau\) strict-partial-order ballot types with positive binary rational masses \(\mu_t\) satisfying \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type is represented by its relation matrix; write \(x\succ_t y\) when it strictly prefers \(x\) to \(y\). Incomparable pairs contribute to neither direction.
Define \(P(x,y)=\sum_{t:x\succ_t y}\mu_t\). The complete directed graph on \(C\) has weight \(w(x,y)=P(x,y)-P(y,x)\) for every \(x\ne y\), retaining negative and zero weights.
For distinct candidates, define \(B(x,y)=\max_{\pi:x\leadsto y}\min_{e\in\pi}w(e)\), where paths may use any candidates in \(C\).
A candidate \(p\) is Schulze-maximal if \(B(p,y)\ge B(y,p)\) for every \(y\ne p\). Compute any such candidate and determine whether it is the only Schulze-maximal candidate; apply no tie-breaking or perturbation.
Let \(L\) be the total binary input length. State running times in \(m,\tau,L\).

Can this computation and uniqueness determination be performed in deterministic time polynomial in \(m,\tau,L\), or is the problem NP-hard?

For discrete elections, given the pairwise margin matrix, a maximal candidate and its uniqueness can be determined in randomized expected time \(O(m^2\log m)\). [Source](https://arxiv.org/pdf/2411.18790)
No separate result specifically addressing normalized rational support input was verified.

Modeling choices made when packaging the task

  • Required a nonempty candidate set so that a maximal candidate exists.
  • Specified relation-matrix encoding for each strict partial order and defined L as the total binary input length.
  • Used mass-weighted pairwise margins, with incomparable ballot pairs contributing to neither direction.
  • Retained all directed edges, including negative and zero margins, following the discrete graph definition.
  • Allowed beatpaths through the entire candidate set and interpreted uniqueness before any tie-breaking or perturbation.

Result

The computation and uniqueness determination are deterministically polynomial-time solvable. An explicit bound, using elementary binary arithmetic, is

\(O\!\left(L+\tau L^2+(m^2\tau+m^3)L\right)\)

bit operations. The algorithm retains all negative and zero weights and uses no tie-breaking.

We prove the bound and correctness directly. The strongest-path computation is the max–min version of Floyd–Warshall, also discussed in the [cited paper](https://arxiv.org/pdf/2411.18790).

1. Construct integer margins of polynomial bit length

Write each supplied mass as \(\mu_t=a_t/b_t\), where \(a_t,b_t\) are positive binary integers. Reduced fractions are unnecessary. Define

\(D=\prod_{t=1}^{\tau}b_t,\qquad n_t=a_t(D/b_t).\)

Each division is exact, and normalization gives

\(\sum_{t=1}^{\tau}n_t=D.\)

Consequently, every \(n_t\) is a positive integer at most \(D\). Moreover,

\(\log_2 D=\sum_{t=1}^{\tau}\log_2 b_t\le L,\)

so \(D\) and every \(n_t\) have \(O(L)\) bits. Their numerical values can be large, but their binary representations remain polynomial in the input length.

For distinct candidates, compute

\(W(x,y)=\sum_{t=1}^{\tau}n_t\bigl(\mathbf{1}[x\succ_t y]-\mathbf{1}[y\succ_t x]\bigr).\)

The relation matrices supply the two indicators directly. Incomparability contributes zero. By construction,

\(W(x,y)=D\,w(x,y),\qquad -D\le W(x,y)\le D.\)

Using elementary multiplication and division, constructing \(D\) and all \(n_t\) costs \(O(\tau L^2)\) bit operations. Computing every margin costs \(O(m^2\tau L)\): each contribution requires adding or subtracting an \(O(L)\)-bit integer. All partial sums also have absolute value at most \(D\), because the total of all \(n_t\) is \(D\).

Let \(B_W\) denote strongest-path strengths computed with weights \(W\). Since \(D\) is positive, multiplication by \(D\) commutes with both minimum and maximum. Thus, for distinct candidates,

\(B_W(x,y)=D\,B(x,y).\)

In particular, all comparisons defining Schulze maximality are preserved exactly.

2. Compute every strongest-path strength

If \(m=1\), return the sole candidate and report uniqueness. Henceforth assume \(m\ge 2\), and enumerate the candidates as \(c_1,\ldots,c_m\).

Every walk between distinct endpoints can be shortened to a simple path by deleting segments between repeated vertices. Deletion removes edges, so it cannot decrease the minimum edge weight. Therefore strongest-path strengths are attained among the finitely many simple paths. This argument applies equally to negative, zero, and positive weights.

Initialize

\(F^{(0)}(x,y)=W(x,y)\quad\text{for }x\ne y,\qquad F^{(0)}(x,x)=+\infty.\)

The diagonal is an algorithmic sentinel representing an empty path; it does not change the problem’s definition for distinct candidates.

For \(k=1,\ldots,m\), compute

\(F^{(k)}(x,y)=\max\!\left\{F^{(k-1)}(x,y),\ \min\!\left(F^{(k-1)}(x,c_k),F^{(k-1)}(c_k,y)\right)\right\}.\)

Two matrices suffice to implement successive stages.

Invariant. For distinct \(x,y\), the entry \(F^{(k)}(x,y)\) is the maximum bottleneck strength among simple paths from \(x\) to \(y\) whose internal vertices belong to \(\{c_1,\ldots,c_k\}\). Diagonal entries remain \(+\infty\).

Proof. At stage zero, the only admissible simple path between distinct endpoints is their direct edge.

For the induction step, first suppose neither endpoint is \(c_k\). An admissible simple path either avoids \(c_k\), or uses it exactly once as an internal vertex. In the latter case, splitting there gives two paths whose internal vertices belong to the preceding set. Its strength is therefore at most the second term in the recurrence.

Conversely, paths attaining the two entries in that second term can be concatenated. The resulting walk has the stated bottleneck strength and uses only permitted internal vertices. Deleting repeated-vertex segments produces an admissible simple path with at least that strength. The first term is already attainable by the induction hypothesis. These observations prove equality.

If an endpoint is \(c_k\), adding \(c_k\) to the permitted internal vertices introduces no new simple paths: an endpoint cannot also be an internal vertex. The recurrence leaves the entry unchanged because \(F^{(k-1)}(c_k,c_k)=+\infty\). Diagonal entries remain \(+\infty\) as well. This proves the invariant. \(\square\)

At the final stage every candidate is permitted as an internal vertex, so

\(F^{(m)}(x,y)=B_W(x,y)\quad\text{for all }x\ne y.\)

There are \(O(m^3)\) updates. Each performs only comparisons and selections among \(O(L)\)-bit integers and the sentinel, costing \(O(m^3L)\) bit operations. No path arithmetic enlarges the stored numbers.

3. Prove that a maximal candidate exists

Define strict strongest-path dominance by

\(x\triangleright y\quad\Longleftrightarrow\quad B_W(x,y)>B_W(y,x),\)

for distinct candidates.

We first establish the concatenation inequality. For pairwise distinct \(x,y,z\),

\(B_W(x,z)\ge\min\{B_W(x,y),B_W(y,z)\}.\)

Indeed, concatenate paths attaining the two strengths, then delete repeated-vertex segments. The resulting simple path cannot have a smaller bottleneck.

Lemma. The relation \(\triangleright\) is a strict partial order.

Proof. It is irreflexive by definition and asymmetric because opposite strict inequalities cannot both hold.

To prove transitivity, suppose \(x\triangleright y\) and \(y\triangleright z\). Asymmetry ensures that the three candidates are distinct. Set

\(a=B_W(x,y),\qquad b=B_W(y,z),\qquad d=B_W(z,x).\)

The assumptions give

\(B_W(y,x)<a,\qquad B_W(z,y)<b.\)

We claim \(d<\min\{a,b\}\). Otherwise:

  • If \(a\le b\), concatenation through \(z\) gives

\(B_W(y,x)\ge\min\{b,d\}\ge a\), a contradiction.

  • If \(b<a\), concatenation through \(x\) gives

\(B_W(z,y)\ge\min\{d,a\}\ge b\), also a contradiction.

Thus, using concatenation through \(y\),

\(B_W(x,z)\ge\min\{a,b\}>d=B_W(z,x).\)

Hence \(x\triangleright z\), proving transitivity. \(\square\)

Every strict partial order on a finite nonempty set has an element with no strict dominator. For completeness, if every candidate had a dominator, repeatedly choosing one would eventually repeat a candidate. Transitivity would then imply that this candidate strictly dominates itself, contradicting irreflexivity.

A candidate \(p\) has no strict dominator precisely when

\(B_W(p,y)\ge B_W(y,p)\quad\text{for every }y\ne p.\)

Positive scaling shows that this is exactly the required Schulze-maximality condition. A suitable candidate therefore always exists.

4. Select a candidate and determine uniqueness

Scan the computed matrix and form

\(S=\{p\in C:\ F^{(m)}(p,y)\ge F^{(m)}(y,p)\text{ for every }y\ne p\}.\)

The preceding proof shows that \(S\) is nonempty and consists exactly of all Schulze-maximal candidates.

Return any member of \(S\), and report that it is the only Schulze-maximal candidate exactly when \(|S|=1\). Choosing which member to output does not alter any comparison or the uniqueness determination.

This scan costs \(O(m^2L)\) bit operations.

5. Running time and conclusion

Including input reading, integer-margin construction, strongest-path computation, and the final scan, the total deterministic running time is

\(O\!\left(L+\tau L^2+m^2\tau L+m^3L\right).\)

Here \(\tau\) is precisely the number of listed ballot types. The algorithm neither enumerates other ballot types nor expands masses into individual voters.

Thus both requested outputs are computable in deterministic time polynomial in \(m,\tau,L\), with exact treatment of ties, incomparability, and signed weights.
