Result

Under the stated exact population measure, \(T\) is feasible and attains optimal welfare in every society. Consequently, \(D(T)=1\), so the proposed bound \(D(T)\leq e/(e-1)\) holds.

The decisive feature is that UF balances favorite-bundle demand in the realized population itself. There is therefore enough supply to give every realized mass its individually optimal bundle simultaneously.

1. Feasibility

Fix an item class \(g\). For type \(t\), UF gives

\(\Pr_{\nu_t}(g\in S)=\dfrac{\binom{K-1}{b_t-1}}{\binom{K}{b_t}}=\dfrac{b_t}{K}.\)

Indeed, exactly \(\binom{K-1}{b_t-1}\) of the equally likely \(b_t\)-subsets contain \(g\).

The rule \(T\) assigns bundle \(S\) to each realized \((t,v,S)\)-mass. This is measurable because \(S\) takes values in a finite set. Each assigned bundle contains exactly \(b_t\) distinct classes, so it satisfies the individual bundle constraint.

Since the population measure is exactly \(\mu_t\nu_t\), aggregate consumption of class \(g\) is

\(\displaystyle \sum_t\mu_t\mathbb E_{\nu_t}[\mathbf 1_{\{g\in S\}}]=\frac1K\sum_t\mu_t b_t=s_g.\)

Thus \(T\) satisfies every supply constraint, with equality.

2. Pointwise welfare maximization

Fix a realized \((t,v,S)\). Because \(S\) consists of the first \(b_t\) classes in a ranking by nonincreasing value, including the specified tie-breaking, we have

\(v_g\geq v_h\qquad\text{whenever }g\in S,\ h\notin S.\)

Let \(B\) be any permitted bundle, so \(|B|\leq b_t=|S|\). Put \(C=B\setminus S\) and \(D=S\setminus B\). Then

\(|C|\leq |D|,\)

because \(|B|\leq |S|\). Choose an injection \(f:C\to D\). Every \(h\in C\) satisfies \(v_{f(h)}\geq v_h\), while all unmatched classes in \(D\) have nonnegative values. Hence

\(\displaystyle \sum_{g\in S}v_g-\sum_{g\in B}v_g =\sum_{h\in C}(v_{f(h)}-v_h)+\sum_{g\in D\setminus f(C)}v_g \geq 0.\)

This proves that \(S\) maximizes welfare among all permitted bundles. Ties cause no difficulty because the inequalities are weak.

3. Global optimality and sharp distortion

Consider any feasible mass allocation \(A\), including one observing cardinal values. At each realization it splits mass among permitted bundles. Every such bundle satisfies the pointwise inequality proved above, so their weighted average does too:

\(\displaystyle \mathbb E_A\!\left[\sum_{g\in B}v_g\,\middle|\,t,v,S\right]\leq\sum_{g\in S}v_g.\)

Integrating and multiplying by the type masses yields \(W(A)\leq W(T)\). These integrals are finite, since both sides are bounded by

\(\displaystyle \sum_t\mu_t\mathbb E_{F_t}\!\left[\sum_{g=1}^{K}v_g\right]<\infty.\)

Taking the supremum gives \(\mathrm{OPT}\leq W(T)\). Feasibility of \(T\) gives the reverse inequality. Therefore

\(\mathrm{OPT}=W(T).\)

In every society included in the distortion supremum, positive optimal welfare thus implies \(W(T)>0\), and the ratio equals \(1\). This domain is nonempty—for example, take one class, one type of mass \(1\), and deterministic value \(1\). Consequently, the sharp distortion is \(D(T)=1\).

4. Relation to the cited discrete result

The cited paper allocates finitely many individual items to agents whose valuations are drawn randomly; feasibility must hold for each realized profile. Its UF assumption does not eliminate realized competition for items. [Source, Section 2](https://arxiv.org/html/2602.11404v1)

Here, the population is exactly the law-weighted mass. UF therefore gives exact aggregate balance, as established in Section 1. The discrete lower bound does not transfer to this model.
