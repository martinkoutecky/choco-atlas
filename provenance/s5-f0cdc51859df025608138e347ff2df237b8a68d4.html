The continuous mirror question, as graded

Given a finite directed network template with private arc types \(T\), public arc types \(U\), rational masses \(\mu_t\) summing to \(1\), and rational public capacities \(b_u\), form each admissible \(k\)-clone game using \(k\mu_t\) private unit arcs of type \(t\) and \(kb_u\) public unit arcs of type \(u\). Let \(a_t^{(k)}\) be the common payoff of type-\(t\) owners in that game’s nucleon. Under the promise that \(a^{(k)}\) converges, compute an approximation to \(a=\lim_k a^{(k)}\) within rational precision \(\delta>0\), in time polynomial in the template size, type counts, input bit length, and \(\log(1/\delta)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) private arc types with positive binary-rational masses \(\mu_r\), summing to \(1\); \(\tau\) counts supported types, not all possible types.
The input is a finite directed multigraph template \((V,T\sqcup U;s,z)\), with \(s\ne z\), private types \(T\), and positive binary-rational public capacities \(b_u\). Each type specifies its endpoints. Every arc lies on a simple directed \(s\)-\(z\) path, at least one such path exists, and every such path contains a private type. Set \(m=|V|+|T|+|U|\), \(\tau=|T|\), and let \(L\) be the total input bit length.
An admissible positive integer \(k\) makes every \(k\mu_r\) and \(kb_u\) integral. Replace each private type \(r\) by \(k\mu_r\) parallel unit-capacity arcs, each owned by a distinct player, and each public type \(u\) by \(kb_u\) parallel unit-capacity arcs available freely to every coalition.
For the resulting player set \(N_k\), coalition worth \(\gamma_k(S)\) is the maximum flow using its owned arcs and all public arcs. Allocations satisfy \(x_i\ge0\) and \(\sum_{i\in N_k}x_i=\gamma_k(N_k)\). The nucleon consists of allocations lexicographically maximizing the sorted, nondecreasing list of \((x(S)-\gamma_k(S))/\gamma_k(S)\) over all nonempty proper coalitions; zero-worth coalitions have relative excess \(+\infty\).
For sufficiently large admissible \(k\), the nucleon is a singleton; let \(a_r^{(k)}\) be its common payoff to owners of type \(r\). These are individual payoffs, without further normalization. Promise that \(a^{(k)}\) converges along all admissible integers to \(a\); no convergence rate is supplied. Given binary-rational \(\delta>0\), the computational problem is to produce rational \(\widehat a\) satisfying \(\|\widehat a-a\|_\infty\le\delta\).

Is this promised limit-computation problem solvable in time polynomial in \(m\), \(\tau\), \(L\), and \(\log(2+1/\delta)\), or is it NP-hard?

For explicitly listed unit-capacity networks satisfying the stated path conditions, the nucleon is computable in polynomial time and is unique whenever two source–sink paths can be chosen without sharing private arcs. [Verified discrete result](https://arxiv.org/pdf/2401.13535).
No result settling this exact promised clone-limit problem was located in the literature search.

Modeling choices made when packaging the task

  • Each arc type specifies one ordered pair of endpoints; clones are parallel arcs with those endpoints.
  • Public capacities are nonnegative; zero-capacity public types are omitted, leaving positive capacities on the listed public types.
  • Carried over both path assumptions and required an existing source–sink path with distinct source and sink, excluding the empty-network degeneracy.
  • Admissible clone sizes are positive integers making all private and public multiplicities integral; convergence is along all such integers.
  • Defined type payoffs only for sufficiently large admissible clone sizes, where the nucleon is unique; this discards only finitely many sizes and resolves the small-game set-valued exception.

2. Flow values and the least-core type-payoff polytope

For a vertex set $A$ containing $s$ and excluding $z$, let $D(A)$ be the types leaving $A$. Call $A$ a *private cut* when $D(A)$ contains no public type. Define

$$ c=\min_{A\text{ a private cut}}\sum_{r\in D(A)\cap T}\mu_r. $$

A private cut exists: the vertices reachable from $s$ using only public types form one. This set excludes $z$, since a public $s$–$z$ walk would contain a simple public $s$–$z$ path. Every private cut intersects an existing $s$–$z$ path, so positivity of the masses gives

$$ 0<c\le 1. $$

Let $\nu$ be the maximum flow with private capacities $\mu_r$ and public capacities $b_u$, and put

$$ \rho=\frac{\nu}{c}. $$

Positive capacities and an existing path give $\nu>0$. A minimum private cut bounds the flow, so

$$ 0<\nu\le c,\qquad 0<\rho\le 1. $$

Both values are computable exactly in polynomial time. To compute $c$, give every public type capacity $2$. A private cut has capacity at most $1$, whereas every cut containing a public type has capacity at least $2$.

For every admissible $k$, aggregation and scaling give

$$ |N_k|=k,\qquad \gamma_k(N_k)=k\nu. $$

Let $\mathcal C$ be the set of distinct incidence vectors of minimum private cuts, and define the normalized polytope

$$ \mathcal P=\operatorname{conv}(\mathcal C). $$

I first establish the least-core characterization needed below.

Proposition 1. For every admissible $k>\tau$, the optimum minimum payoff-to-worth ratio is $\rho$. Every allocation attaining it pays all clones of each type equally. Its individual type-payoff vector has the form $\rho p$, where $p\in\mathcal P$. Conversely, every $p\in\mathcal P$ induces such an allocation.

*Proof.* Temporarily give each public type capacity $k$ and each private type capacity $k\mu_r$. A minimum private cut has capacity $kc$, while a cut containing a public type has capacity at least $k\ge kc$. Integral maximum flow therefore provides $kc$ simple paths with disjoint private clones; public clones may be shared.

Every simple path uses at most $\tau$ private players, so its private-player coalition is nonempty and proper when $k>\tau$. If an allocation has minimum payoff-to-worth ratio $\lambda$, each of the packed path coalitions receives at least $\lambda$. Their private-player sets are disjoint, hence

$$ kc\,\lambda\le k\nu. $$

Thus $\lambda\le\rho$.

Paying $\rho$ to each clone crossing a minimum private cut, and zero elsewhere, achieves this bound. Indeed, its total payment is $k\nu$, and every coalition’s flow is bounded by its number of clones crossing that cut.

More generally, an allocation attains the bound exactly when

$$ x(C(P))\ge\rho $$

for every simple path $P$, where $C(P)$ is its private-player set. Necessity follows from the first-stage coalition inequalities. For sufficiency, decompose an integral maximum coalition flow into arc-disjoint simple paths. Their private-player sets are disjoint subsets of the coalition, so summing the path inequalities gives $x(S)\ge\rho\gamma_k(S)$.

Now normalize by setting $y_i=x_i/\rho$. Then

$$ \sum_i y_i=kc,\qquad y(C(P))\ge1. $$

Give private clone $i$ length $y_i$ and public arcs length zero. Let $\phi(v)$ be the shortest distance from $s$, truncated at $1$; assign isolated unreachable vertices potential $1$. All vertices incident with arcs are reachable by the stated path condition. The path inequalities imply $\phi(s)=0$ and $\phi(z)=1$. Moreover,

$$ y_i\ge(\phi(v)-\phi(u))_+ $$

for a private clone $i=(u,v)$, and $\phi(v)\le\phi(u)$ for a public arc.

For $t\in(0,1)$, the set $A_t=\{v:\phi(v)<t\}$ is a private cut. Integrating its number of outgoing private clones yields

$$ kc \le \int_0^1 |D_k(A_t)|\,dt = \sum_{i=(u,v)}(\phi(v)-\phi(u))_+ \le \sum_i y_i = kc. $$

All inequalities are equalities. Each nonnegative difference
$y_i-(\phi(v)-\phi(u))_+$ therefore vanishes. Thus clone payoffs depend only on their endpoints, and in particular are equal within each type.

Almost every threshold cut is minimum. Consequently, the common normalized payoff $p_r$ satisfies

$$ p_r=\int_0^1\chi_r^{A_t}\,dt. $$

This is a convex combination of minimum private-cut incidence vectors, so $p\in\mathcal P$. Conversely, convex combinations of the cut allocations constructed above remain efficient and satisfy all first-stage inequalities. $\square$

In particular,

$$ 0\le p_r\le1,\qquad \sum_r\mu_rp_r=c $$

on $\mathcal P$. The promised limit therefore has the form

$$ a=\rho p^\infty,\qquad p^\infty\in\mathcal P. $$

The polytope has the following polynomial-size extended formulation:

$$ p_r\ge0,\qquad \sum_r\mu_rp_r=c, $$

$$ 0\le\phi(v)\le1,\qquad \phi(s)=0,\qquad \phi(z)=1, $$

$$ p_r+\phi(u)-\phi(v)\ge0 \quad\text{for each private type }r=(u,v), $$

$$ \phi(u)-\phi(v)\ge0 \quad\text{for each public type }(u,v). $$

The potential inequalities imply all path inequalities by telescoping. Conversely, truncated shortest-path potentials supply the formulation for every $p\in\mathcal P$. The threshold-cut argument above, now weighted by $\mu_r$, identifies its projection with $\mathcal P$.

3. A polynomial-size family of nonnegative affine functions

The next construction reduces every coalition’s normalized excess to a nonnegative integer combination of a small family of affine functions on $\mathcal P$.

Compute a maximum flow of value $c$ with private capacities $\mu_r$ and public capacities $2$. Remove circulations and decompose it as

$$ f=\sum_{j=1}^{h}w_j\chi^{P_j}, \qquad w_j>0,\qquad \sum_jw_j=c, $$

where the $P_j$ are simple paths and $h$ is at most the number of template arcs. Let $H$ be the union of these paths, and $W$ their vertex set.

For every $p\in\mathcal P$,

$$ c \le \sum_jw_jp(P_j) = \sum_{r\in T}f_rp_r \le \sum_r\mu_rp_r = c. $$

Here $p(P)$ denotes the sum of private-type payoffs on $P$. Equality gives two facts:

$$ p(P_j)=1 \quad\text{for every }j, $$

and

$$ p_r=0 \quad\text{whenever }f_r<\mu_r. $$

In particular, every private type outside $H$ has identically zero payoff.

For each $w\in W$, choose one path $P_j$ containing it, and define $\phi_p(w)$ as the private payoff on that path’s $s$–$w$ prefix. This is a linear function of $p$.

These definitions agree for different choices of path. Indeed, truncated shortest-path potentials satisfy nonnegative reduced-cost inequalities, and each $P_j$ has total length $1$. Their reduced costs therefore sum to zero along $P_j$, forcing every arc on it to be tight. Thus the prefix sum equals the potential at $w$, independently of the selected path.

A *jump* is a directed path $Q$ from $u\in W$ to $v\in W$, with all internal vertices outside $W$ and no arc in $H$. Its private payoff is identically zero. Hence its endpoint difference

$$ d_{uv}(p)=\phi_p(u)-\phi_p(v) $$

satisfies

$$ 0\le d_{uv}(p)\le1 $$

on $\mathcal P$.

There are at most $|V|^2$ jump pairs. Their existence and representative paths can be found by reachability searches with the other vertices of $W$ deleted.

For each jump pair, choose a path from the decomposition containing $u$, and another containing $v$. Consider the first path’s $s$–$u$ prefix and the second path’s $v$–$z$ suffix.

  • If these two subpaths are vertex-disjoint, their concatenation with the jump is a simple $s$–$z$ path $P^{uv}$, and

$$ p(P^{uv})-1=d_{uv}(p). $$

  • Otherwise, choose the last vertex $w$ of the prefix that also belongs to the suffix. The $w$–$u$ prefix subpath, the jump, and the $v$–$w$ suffix subpath form a simple directed cycle $C^{uv}$. The choice of $w$ ensures that the two support subpaths have no other intersection. Telescoping gives

$$ d_{uv}(p)=p(C^{uv}) = \sum_{r\in C^{uv}\cap T}p_r. $$

Define the family $\mathcal F$ to consist of:

  • every coordinate function $p_r$;
  • $d_{uv}$ for every jump pair for which the construction chose an $s$–$z$ path.

All these functions are nonnegative on $\mathcal P$, and

$$ |\mathcal F|\le\tau+|V|^2. $$

Jump differences for which a cycle was chosen are sums of coordinate functions and need not be included separately.

Lemma 2. For every positive-worth coalition $S$, its normalized excess

$$ E_S(p)=p(S)-\gamma_k(S) $$

is a nonnegative integer combination of functions in $\mathcal F$.

*Proof.* Fix an integral maximum flow for $S$, decomposed into $q=\gamma_k(S)$ arc-disjoint simple paths. The unused private players contribute their nonnegative coordinate payoffs.

A path can be decomposed into subpaths in $H$ and jumps between consecutive visits to $W$. Support subpaths have payoff equal to their endpoint potential increase, while jumps have payoff zero. Telescoping therefore gives

$$ p(P)-1=\sum_{\text{jumps of }P}d_{uv}(p). $$

Replace every cycle-type jump difference by its coordinate-sum expression. Summing over the $q$ flow paths and the unused private players proves the assertion. The decomposition is chosen from the coalition network and is independent of $p$. $\square$

Let $\mathcal I$ be the functions in $\mathcal F$ that are nonconstant on $\mathcal P$. If $\mathcal P$ is not a singleton, $\mathcal I$ is nonempty, since it contains every nonconstant coordinate. Set

$$ \alpha(p)=\min_{g\in\mathcal I}g(p), \qquad M=\max_{p\in\mathcal P}\alpha(p), $$

and define

$$ \mathcal Q=\{p\in\mathcal P:\alpha(p)=M\}. $$

Nonnegativity and Lemma 2 imply the useful inequality

$$ E_S(p)\ge\alpha(p) $$

whenever $E_S$ is nonconstant on $\mathcal P$.

4. Universally tight paths and a common asymptotic denominator

Call a simple path *universally tight* if

$$ p(P)=1 \quad\text{for every }p\in\mathcal P. $$

Choose $p^\circ$ in the relative interior of $\mathcal P$. Give private arcs length $p^\circ_r$ and public arcs length zero, and use truncated shortest-path potentials $\phi^\circ$. Let $G_0$ contain exactly the arcs of zero reduced cost:

$$ p^\circ_r+\phi^\circ(u)-\phi^\circ(v)=0 $$

for private types, and

$$ \phi^\circ(u)-\phi^\circ(v)=0 $$

for public types.

The simple $s$–$z$ paths in $G_0$ are exactly the universally tight paths. To justify this, every path has nonnegative slack $p(P)-1$, and its slack at $p^\circ$ is the sum of its nonnegative reduced costs. Furthermore, an affine function nonnegative on a polytope and zero at a relative-interior point is identically zero: otherwise moving a small distance from that point in the opposite direction would make it negative.

Let $F_0$ be the maximum flow in $G_0$, using the actual template capacities $\mu_r,b_u$. Each decomposition path $P_j$ is universally tight, and all its capacities are positive. Hence

$$ 0<F_0\le\nu. $$

Although $G_0$ was constructed using $p^\circ$, its path family is intrinsic. In particular, the maximum number of universally tight paths that can be packed in the clone network is exactly $kF_0$.

For a fixed $p$ in the relative interior of $\mathcal P$, construct its zero-reduced-cost graph in the same way. It has the same $s$–$z$ path family. Let $\eta_p>0$ be the smallest positive reduced cost; if none exists, set $\eta_p=1$.

For any coalition flow decomposition, write $q_0$ for the number of universally tight paths and $q_1$ for the remaining paths. Each remaining path contributes slack at least $\eta_p$, so

$$ q_0\le kF_0,\qquad q_1\eta_p\le E_S(p). $$

Consequently,

$$ \gamma_k(S)\le kF_0+\frac{E_S(p)}{\eta_p}. $$

Every function in $\mathcal I$ is strictly positive at a relative-interior point: a nonconstant nonnegative affine function cannot vanish there. Thus $\alpha(p)>0$. For every nonconstant coalition excess,

$$ \frac{E_S(p)}{\gamma_k(S)} \ge \frac{E_S(p)}{kF_0+E_S(p)/\eta_p} \ge \frac{\alpha(p)}{kF_0+\alpha(p)/\eta_p}. $$

The final inequality follows because the function of $E_S(p)$ in the middle expression is increasing.

5. Coalition witnesses for individual affine functions

The reverse estimate requires a coalition realizing each $g\in\mathcal I$ alone, while carrying nearly $kF_0$ units of flow.

There is a constant $C$, polynomially bounded in $m$, such that for every sufficiently large admissible $k$ and every $g\in\mathcal I$, a nonempty proper coalition $S_g^{(k)}$ satisfies

$$ E_{S_g^{(k)}}(p)=g(p) \quad\text{for all }p\in\mathcal P, $$

and

$$ \gamma_k(S_g^{(k)})\ge kF_0-C. $$

Here is the construction and the worth calculation.

For a coordinate function $g(p)=p_r$, reserve two distinct clones of type $r$. Pack a maximum flow in the clone version of $G_0$ avoiding both, and let its value be $q$. Reducing a single type’s capacity by two reduces every cut capacity by at most two; therefore

$$ q\ge kF_0-2. $$

Take the private players used by this flow and add one reserved clone. The other reserved clone keeps the coalition proper. Its normalized payoff is $q+p_r$.

Because $p_r$ is nonconstant and lies in $[0,1]$, a relative-interior point satisfies $p^\circ_r<1$. The coalition can send $q$ units, while its normalized payoff at $p^\circ$ is less than $q+1$. All normalized coalition payoffs bound coalition worth from below by Proposition 1. Integrality therefore forces its worth to equal $q$. Its excess is exactly $p_r$ throughout $\mathcal P$.

For a path-type function $g=d_{uv}$, take the explicit simple path $P^{uv}$ constructed above. Select one clone of each of its arc types, and reserve one additional private clone of a type occurring on this path. Such a private type exists by the path assumption.

Pack a maximum flow in $G_0$ avoiding the selected path arcs and the additional reserved clone. At most $|P^{uv}|+1$ unit capacities were removed, so its value $q_0$ satisfies

$$ q_0\ge kF_0-(|P^{uv}|+1). $$

Add the selected path to this flow, and take the private players used. The additional reserved clone is omitted, making the coalition proper. It sends at least $q=q_0+1$ units and has normalized payoff

$$ q+d_{uv}(p). $$

The function $d_{uv}$ is nonconstant and lies in $[0,1]$, so $d_{uv}(p^\circ)<1$. As before, the core inequality and integrality force the coalition worth to be exactly $q$. Its excess is therefore $d_{uv}$ identically.

For example, $C=m+2$ works for both constructions once the required clone counts and positive flow values are available. These conditions hold for all sufficiently large admissible $k$.

6. A proved necessary condition on the limit

For sufficiently large admissible $k$, define

$$ f_k(p)= \min_{\substack{ \varnothing\ne S\subsetneq N_k\\ \gamma_k(S)>0\\ E_S\text{ nonconstant on }\mathcal P }} \frac{E_S(p)}{\gamma_k(S)}, $$

and let

$$ v_k=\max_{p\in\mathcal P}f_k(p). $$

This is the first remaining lexicographic stage after restricting to the least core. Indeed, on that face the original relative excess is

$$ \frac{x(S)-\gamma_k(S)}{\gamma_k(S)} = (\rho-1)+\rho\frac{E_S(p)}{\gamma_k(S)}. $$

The same positive affine transformation applies to every finite entry. Entries constant throughout $\mathcal P$ can be deleted for lexicographic comparison: merging the same fixed multiset into two sorted lists preserves their lexicographic ordering. Thus every normalized nucleon vector maximizes $f_k$.

The witnesses in Section 5 give, for every $p\in\mathcal P$,

$$ f_k(p)\le\frac{\alpha(p)}{kF_0-C}. $$

Section 4 gives, for each fixed relative-interior point $p$,

$$ f_k(p)\ge \frac{\alpha(p)}{kF_0+\alpha(p)/\eta_p}. $$

Therefore

$$ \lim_{k\to\infty}k f_k(p)=\frac{\alpha(p)}{F_0} $$

at every fixed relative-interior point, along admissible integers.

These bounds also imply

$$ \lim_{k\to\infty}k v_k=\frac{M}{F_0}. $$

For the upper bound, use $\alpha(p)\le M$. For the lower bound, take any maximizer of $\alpha$ and mix it with a relative-interior point. These mixtures are relative-interior points and their $\alpha$ values approach $M$, by continuity.

Now let $p^{(k)}=a^{(k)}/\rho$. Since $p^{(k)}$ maximizes $f_k$,

$$ \alpha(p^{(k)}) \ge (kF_0-C)v_k. $$

The right-hand side tends to $M$, while $\alpha\le M$. Continuity and the promised convergence prove the following result.

Theorem 3. If $\mathcal P$ is not a singleton, then the promised normalized limit satisfies

$$ \boxed{\frac{a}{\rho}\in\mathcal Q.} $$

This is a necessary condition, rather than a complete characterization when $\mathcal Q$ has more than one point.

7. Polynomial-time consequences

All objects defining $\mathcal Q$ can be computed with polynomial bit complexity.

The maximum flow defining $H$ and its path decomposition have polynomial size. Jump pairs, representative jumps, and their path-or-cycle witnesses require polynomially many graph searches.

On $W$, each potential is an explicitly known linear function:

$$ \phi_p(w)= \sum_{r\text{ on a chosen support prefix}}p_r. $$

Thus all functions in $\mathcal F$ have polynomial-size rational descriptions. Whether a function is constant on $\mathcal P$ can be tested by comparing its exact minimum and maximum using the extended formulation.

Finally, $M$ and $\mathcal Q$ are obtained from the compact LP

$$ \text{maximize }t $$

subject to

$$ p\in\mathcal P,\qquad g(p)\ge t \quad\text{for every }g\in\mathcal I. $$

Its coefficients and dimensions have polynomial encoding length. Coordinate minimization and maximization over its optimal face detect whether $\mathcal Q$ is a singleton.

Consequently, whenever $\mathcal Q=\{p^*\}$, Theorem 3 gives

$$ a=\rho p^*. $$

This is an exact polynomial-time computation; no convergence rate or clone expansion is needed.

8. Exact solution when there are two minimum-cut incidence vectors

Suppose

$$ \mathcal C=\{\chi^0,\chi^1\}, \qquad \chi^0\ne\chi^1. $$

Write

$$ p(t)=(1-t)\chi^0+t\chi^1, \qquad 0\le t\le1. $$

Every nonconstant private coordinate is either $t$ or $1-t$. Both kinds occur: the two vectors have the same positive weighted cut mass, so their difference cannot have only one sign.

At either endpoint, every support-prefix potential is an integer in $[0,1]$, hence is $0$ or $1$. Each jump difference is nonnegative and at most $1$. It therefore has endpoint values in $\{0,1\}$. Every nonconstant path-type function is consequently also either $t$ or $1-t$.

It follows that

$$ \alpha(p(t))=\min\{t,1-t\}. $$

The unique maximizer is $t=1/2$. Theorem 3 proves the exact formula

$$ \boxed{ a=\frac{\rho}{2}(\chi^0+\chi^1). } $$

Equivalently, a type receives $0$, $\rho/2$, or $\rho$ according as it crosses neither, exactly one, or both incidence vectors.

This covers every instance with $\dim\mathcal P=1$. Indeed, a line contains at most two distinct Boolean vectors: choose a coordinate on which two differ; its Boolean value determines which of those two points a further collinear Boolean vector could be. Thus a one-dimensional convex hull of Boolean vectors has exactly two such vectors.

The class is detectable in polynomial time without enumerating cuts. Compute a relative-interior point of the extended formulation and the dimension of its projected affine hull. If that dimension is one, optimizing any nonconstant coordinate over $\mathcal P$ recovers its two endpoints.

For example, take private types

$$ r_0:s\to v,\qquad r_1:v\to z,\qquad r_2:v\to z $$

with masses

$$ \mu_0=\frac12,\qquad \mu_1=\frac13,\qquad \mu_2=\frac16, $$

and no public types. The two minimum private-cut incidence vectors are

$$ (1,0,0),\qquad (0,1,1). $$

Here $\nu=c=1/2$, so the limit is

$$ a=\left(\frac12,\frac12,\frac12\right). $$

9. What remains open

The general complexity classification remains unresolved here. The new LP gives a necessary limit-selection condition and an exact algorithm whenever its optimal face is a singleton.

When $\mathcal Q$ has positive dimension, later lexicographic stages may select a particular point within it. The estimates proved above concern the leading value of the first remaining stage; they do not justify recursively applying the same construction to later faces. In particular, lower-order finite-clone effects have not been controlled.

Thus the remaining task is either to characterize that subsequent selection with the required bit-complexity bound, or to prove hardness with a controlled approximation gap.
