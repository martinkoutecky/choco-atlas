The continuous mirror question, as graded

Given a rational high-multiplicity peer election with voter-type masses \(\mu\), integer candidate-copy multiplicities \(q\), a compact copy-level functional delegation graph with transitive approvals \(A_t\), and committee size \(k\), compute a \(k\)-committee maximizing \(\mathrm{PAV}_\mu(w)=\sum_{t\in T}\mu_t H_{\sum_{u\in A_t}w_u}\), and determine whether weighted Liquid d’Hondt/sequential PAV always returns that optimum in polynomial time.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) distinct approval types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Use this compact encoding: there are \(m\) candidate classes \(C_u\), each containing \(q_u\in\mathbb{Z}_{>0}\) distinct copies; the multiplicities are binary encoded. Each type is explicitly specified by \(A_t\subseteq\{1,\ldots,m\}\), meaning approval of every copy in those classes. A surjective map \(r:\{1,\ldots,m\}\to T\) assigns every copy in \(C_u\) its voter type \(r(u)\).
The expanded copies are simultaneously voters and candidates. Promise that their specified approvals are exactly positive-length reachability in some functional delegation graph on these copies, with one outgoing edge per copy and self-loops allowed. Thus a copy approves itself precisely when it lies on a directed cycle. The incidence lists and \(r\) encode the graph's reachability without expanding the copies.
The total mass \(\mu_t\) is shared equally among copies having type \(t\), independently of their candidate multiplicities. Let \(L\) be the total input bit length, including a binary-encoded committee size \(1\leq k\leq\sum_u q_u\) and a tie-breaking order on classes; copies within each class are ordered by index.
A committee is an integer count vector \(w\) with \(0\leq w_u\leq q_u\) and \(\sum_u w_u=k\). Its objective is \(\mathrm{PAV}_{\mu}(w)=\sum_{t\in T}\mu_t H_{s_t(w)}\), where \(s_t(w)=\sum_{u\in A_t}w_u\), \(H_0=0\), and \(H_j=\sum_{i=1}^{j}1/i\).
Starting at \(w=0\), weighted sequential PAV adds one available copy maximizing \(\sum_{t:u\in A_t}\mu_t/(s_t(w)+1)\); weighted Liquid d’Hondt instead maximizes \((\sum_{t:u\in A_t}\mu_t)/(s_{r(u)}(w)+1)\). Each performs \(k\) additions with the specified tie-breaking.

Is exact maximization of \(\mathrm{PAV}_{\mu}\) polynomial-time solvable in \(m,\tau,L\), or NP-hard?
Do weighted Liquid d’Hondt and sequential PAV always produce an optimum, and can their final count vectors be computed in polynomial time in \(m,\tau,L\)?

For finite, explicitly listed, unweighted liquid peer elections, Liquid d’Hondt, sequential PAV and PAV are equivalent as outcome correspondences under suitable tie-breaking, giving polynomial-time PAV optimization. [Grossi, Lisowski and Papasotiropoulos](https://arxiv.org/html/2608.13085v1).
No result settling this exact rational-mass, binary-multiplicity problem was identified in the literature search.

Modeling choices made when packaging the task

  • The compact graph encoding was unspecified. Use explicit approval incidence between voter types and interchangeable candidate-copy classes, together with each class's voter type, and promise that the expanded incidence is positive-length reachability of a functional graph.
  • The relationship between voter masses and candidate multiplicities was unspecified. Keep them independent, normalize total voter mass to one, and distribute each type's mass equally among its associated peer copies.
  • The committee domain was unspecified. Retain distinct indivisible candidate copies and integer class counts bounded by their multiplicities.
  • Encode positive multiplicities and the feasible positive committee size in binary; measure polynomial time in the compact input length and return committee counts.
  • Define the two weighted rules separately using, respectively, weighted marginal PAV gain and weighted support divided by the candidate copy's own satisfaction plus one.
  • Fix class and within-class tie-breaking, and use positive-length reachability so that self-approval occurs only on cycles.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Exact PAV maximization is polynomial-time solvable in \(m,\tau,L\). Both weighted sequential PAV and weighted Liquid d’Hondt always return an optimum. Under the same specified tie-breaking, they make the same choices, and their final count vectors are computable in polynomial time without expanding the copies.

The proof below establishes the weighted, compactly encoded result independently of the explicitly listed unweighted equivalence in [Grossi, Lisowski and Papasotiropoulos, Theorem 12](https://arxiv.org/html/2608.13085v1).

1. The reachability promise implies laminar supporter sets

Let \(V\) denote the expanded set of copies, used only for the proof. Fix a functional graph witnessing the promise. For \(v\in V\), let \(\mathcal R(v)\) be its positive-length reachability set. For a candidate copy \(c\), define its supporter set by

\(\displaystyle \mathcal P(c)=\{v\in V:c\in\mathcal R(v)\}.\)

For each class \(u\), define the explicitly computable set

\(\displaystyle S_u=\{t\in T:u\in A_t\}.\)

Writing \(V_t\) for the copies whose voter type is \(t\), the encoding gives, for every \(c\in C_u\),

\(\displaystyle \mathcal P(c)=\bigcup_{t\in S_u}V_t.\)

Every \(V_t\) is nonempty because \(r\) is surjective. Consequently, equality, inclusion, and disjointness of the sets \(S_u\) exactly reflect those relations between the corresponding expanded supporter sets.

Lemma 1. The nonempty sets \(S_u\) form a laminar family: any two are disjoint or one contains the other.

Proof. Suppose \(\mathcal P(c)\cap\mathcal P(d)\neq\emptyset\). Some vertex \(v\) reaches both \(c\) and \(d\). Because the graph is functional, both occur on the same forward orbit. Thus either \(c=d\), \(c\) reaches \(d\), or \(d\) reaches \(c\).

If \(c\) reaches \(d\), transitivity gives \(\mathcal P(c)\subseteq\mathcal P(d)\); the reverse case gives the reverse inclusion. Translating through the nonempty type groups proves the lemma. \(\square\)

This is laminarity of candidate supporter sets; no laminarity assumption on voter approval sets is needed.

2. Strict containment forces an order of selection

Call a count vector \(w\) hierarchical if

\(\displaystyle S_v\subsetneq S_u,\quad S_v\neq\emptyset,\quad w_v>0 \quad\Longrightarrow\quad w_u=q_u.\)

Thus selecting a candidate with nonempty support requires exhausting every class with a properly larger supporter set.

Lemma 2. Every optimal committee is hierarchical. Moreover, an optimal committee contains a candidate with empty support only if all candidates with nonempty support are selected.

Proof. Suppose \(S_v\subsetneq S_u\), \(w_v>0\), and \(w_u<q_u\). Replace one selected copy from \(C_v\) by an available copy from \(C_u\).

For types in \(S_v\), satisfaction is unchanged. For types in \(S_u\setminus S_v\), it increases by one. All other satisfactions are unchanged. The objective therefore increases by

\(\displaystyle \sum_{t\in S_u\setminus S_v}\frac{\mu_t}{s_t(w)+1}>0.\)

The inequality is strict because the difference set is nonempty and every mass is positive. Hence such a pair cannot occur in an optimum.

The same exchange applies when \(S_v=\emptyset\) and \(S_u\neq\emptyset\), proving the second assertion. \(\square\)

Sequential PAV also maintains hierarchy. Indeed, at every state its marginal score for class \(u\) is

\(\displaystyle G_u(w)=\sum_{t\in S_u}\frac{\mu_t}{s_t(w)+1}.\)

Whenever \(S_v\subsetneq S_u\),

\(\displaystyle G_u(w)-G_v(w)= \sum_{t\in S_u\setminus S_v}\frac{\mu_t}{s_t(w)+1}>0.\)

Therefore, sequential PAV cannot select from \(C_v\) while \(C_u\) remains available. A nonempty supporter set always has positive marginal score, so empty-support candidates are selected only after all others have been exhausted.

3. Optimal committees are obtained from compressed quotient sequences

Let \(\mathcal F\) be the family of distinct nonempty supporter sets among the \(S_u\), and put \(p=|\mathcal F|\leq m\). For each \(S\in\mathcal F\), define

\(\displaystyle Q_S=\sum_{u:S_u=S}q_u,\qquad M_S=\sum_{t\in S}\mu_t,\qquad a_S=\sum_{\substack{B\in\mathcal F\\S\subsetneq B}}Q_B.\)

Here \(Q_S\) is the number of candidates with supporter set \(S\), \(M_S\) is their total supporting voter mass, and \(a_S\) is the capacity of all their strict ancestors.

Associate with \(S\) the decreasing sequence

\(\displaystyle \rho_{S,j}=\frac{M_S}{a_S+j}, \qquad 1\leq j\leq Q_S.\)

These sequences are represented by their parameters; they will never be explicitly expanded.

For a committee, write

\(\displaystyle x_S=\sum_{u:S_u=S}w_u.\)

Lemma 3. For every hierarchical committee,

\(\displaystyle \mathrm{PAV}_\mu(w)= \sum_{S\in\mathcal F}\sum_{j=1}^{x_S}\rho_{S,j}.\)

Proof. Fix a type \(t\). By laminarity, the sets in \(\mathcal F\) containing \(t\) form a chain. Hierarchy implies that before any selected candidates from a node on this chain, every strict ancestor is full.

Thus the selected contributions along this chain have consecutive harmonic denominators: a selected block at \(S\) contributes denominators \(a_S+1,\ldots,a_S+x_S\). Together these blocks contribute exactly \(H_{s_t(w)}\).

Multiplying by \(\mu_t\), summing over types, and interchanging the finite sums yields

\(\displaystyle \sum_t\mu_tH_{s_t(w)} =\sum_{S\in\mathcal F} \left(\sum_{t\in S}\mu_t\right) \sum_{j=1}^{x_S}\frac1{a_S+j}. \)

Candidates with empty support contribute nothing. \(\square\)

The quotient sequences respect hierarchy strictly. If \(S\subsetneq B\), then \(M_S<M_B\), and

\(\displaystyle a_S\geq a_B+Q_B.\)

Consequently,

\(\displaystyle \rho_{B,Q_B} =\frac{M_B}{a_B+Q_B} > \frac{M_S}{a_S+1} =\rho_{S,1}. \)

Thus every quotient belonging to an ancestor exceeds every quotient belonging to a descendant.

Let

\(\displaystyle N_+=\sum_{S\in\mathcal F}Q_S,\qquad K=\min\{k,N_+\}.\)

Select the \(K\) largest quotients from all the sequences, counting multiplicities. Within each sequence, the selected entries form a prefix because that sequence is strictly decreasing. The preceding ancestor inequality ensures that selecting any entry at \(S\) selects every entry at every strict ancestor. Therefore these prefixes define a feasible hierarchical committee with \(K\) positive-support candidates. If \(k>N_+\), add \(k-N_+\) empty-support candidates.

Proposition 4. This committee maximizes \(\mathrm{PAV}_\mu\).

Proof. By Lemma 2, every optimum is hierarchical and contains exactly \(K\) positive-support candidates. By Lemma 3, its score is the sum of \(K\) entries from the quotient sequences. This cannot exceed the sum of their \(K\) largest entries. The construction attains that sum and is feasible. \(\square\)

Sequential PAV follows the same quotient order

At a hierarchical state, call an unfilled node \(S\) available at the frontier if all its strict ancestors are full.

No strict descendant of an unfilled frontier node can have selected candidates. Hence, for every \(t\in S\),

\(\displaystyle s_t(w)=a_S+x_S.\)

Its live sequential-PAV marginal is therefore

\(\displaystyle G_S(w)=\frac{M_S}{a_S+x_S+1} =\rho_{S,x_S+1}.\)

A node outside the frontier has an available strict ancestor, whose live marginal is strictly larger. Sequential PAV therefore selects a frontier node.

Likewise, the largest remaining static quotient belongs to a frontier node: otherwise an unselected ancestor quotient would be strictly larger. Thus sequential PAV selects the quotients in decreasing order. For classes with the same supporter set, their live scores always coincide, so their copies are used in the prescribed class order and then index order.

This proves that sequential PAV returns the optimum of Proposition 4, including with the specified tie-breaking.

4. Weighted Liquid d’Hondt has exactly the same scores along this sequence

The following graph argument accounts for the denominator \(s_{r(u)}(w)+1\), including positive-length reachability and partially selected cycles.

Lemma 5. Let \(W\) be a hierarchical expanded committee and \(c\notin W\) an available candidate. For every supporter \(v\in\mathcal P(c)\),

\(\displaystyle W\cap\mathcal R(v)=W\cap\mathcal R(c).\)

Proof. Because \(v\) reaches \(c\), transitivity gives

\(\displaystyle W\cap\mathcal R(c)\subseteq W\cap\mathcal R(v).\)

For the reverse inclusion, suppose \(y\in W\cap\mathcal R(v)\) but \(y\notin\mathcal R(c)\). On the forward orbit of \(v\), the vertex \(y\) must occur before \(c\), and \(y\) reaches \(c\). Moreover, \(y\) cannot lie on a directed cycle: if it did, any reachable \(c\) would lie on that cycle and would reach \(y\).

Therefore \(y\notin\mathcal P(y)\), whereas \(y\in\mathcal P(c)\). Transitivity also gives \(\mathcal P(y)\subseteq\mathcal P(c)\). Hence

\(\displaystyle \mathcal P(y)\subsetneq\mathcal P(c).\)

The set \(\mathcal P(y)\) is nonempty because \(v\) supports \(y\). Hierarchy now implies that every candidate with supporter set \(\mathcal P(c)\) is selected, contradicting \(c\notin W\). \(\square\)

Take an available copy \(c\in C_u\). Its own satisfaction is \(s_{r(u)}(w)=|W\cap\mathcal R(c)|\). Lemma 5 shows that every type supporting \(c\) has exactly this satisfaction. Consequently,

\(\displaystyle G_u(w) =\sum_{t\in S_u}\frac{\mu_t}{s_t(w)+1} =\frac{\sum_{t\in S_u}\mu_t}{s_{r(u)}(w)+1}. \)

The right-hand side is precisely the weighted Liquid d’Hondt score. For empty-support classes, both scores are zero.

Starting from the empty committee, induction proves that both rules make the same next choice: their scores coincide at the current hierarchical state, they use the same tie-breaking, and sequential PAV preserves hierarchy. Therefore their entire sequences coincide, and both return an optimum.

5. Exact polynomial-time computation without expanding the sequences

It remains to compute the largest \(K\) quotient entries using binary-encoded capacities.

For a positive rational \(z\), define

\(\displaystyle R_{\geq}(z)= \sum_{S\in\mathcal F} \operatorname{clamp}_{[0,Q_S]} \left(\left\lfloor\frac{M_S}{z}\right\rfloor-a_S\right), \)

where \(\operatorname{clamp}_{[0,Q]}(b)=\min\{Q,\max\{0,b\}\}\).

This is exactly the number of quotient entries at least \(z\): the inequality \(\rho_{S,j}\geq z\) is equivalent to \(j\leq M_S/z-a_S\).

Let \(\theta\) be the \(K\)-th largest quotient. It can be found as follows.

  • For each \(S\), binary-search for the smallest \(j_S\in\{1,\ldots,Q_S\}\) satisfying

\(R_{\geq}(\rho_{S,j_S})\geq K\).
If no such index exists, omit that sequence.

  • Set

\(\displaystyle \theta=\max_S\rho_{S,j_S}\)
over the sequences not omitted.

To verify this procedure, any value greater than \(\theta\) has fewer than \(K\) entries at least that value. Hence each sequence’s first crossing value is at most \(\theta\). A sequence containing the actual \(K\)-th value crosses precisely at that value, so the maximum of the crossing values is exactly \(\theta\).

The predicate used in each binary search is monotone because \(\rho_{S,j}\) decreases with \(j\).

Recovering counts and breaking ties

The number of entries at \(S\) strictly greater than \(\theta\) is

\(\displaystyle b_S= \operatorname{clamp}_{[0,Q_S]} \left(\left\lceil\frac{M_S}{\theta}\right\rceil-a_S-1\right). \)

Initially select these \(b_S\) entries. Each positive quotient sequence is strictly decreasing, so it contains at most one entry equal to \(\theta\). Thus there are at most \(p\) remaining tied entries to consider.

Within each node, enumerate its candidate copies by the specified class order and then index order. The possible tied entry at \(S\) corresponds to copy number \(b_S+1\) in this local enumeration. Select the required number of tied entries according to their candidate tie-breaking order.

An entry’s class and index are found from cumulative sums of class multiplicities. Similarly, distributing a selected node prefix among its classes requires only scanning those classes. If \(k>N_+\), fill the empty-support classes in their prescribed order, using their capacities directly.

Bit complexity

All operations use compact input data:

  • The sets \(S_u\), their distinct nodes, and all inclusion relations are computable in polynomial time from the incidence lists.
  • Every capacity and offset is at most \(N=\sum_uq_u\), whose binary length is polynomial in \(L\).
  • Each mass sum \(M_S\), quotient, comparison, floor, and ceiling involves rational numbers of polynomial bit length. A common denominator obtained by multiplying input denominators already has bit length bounded by their total encoded length.
  • Each rank query examines at most \(p\) sequences. There are at most \(p\) binary searches, each using \(O(\log(N+1))\) rank queries.

The quotient-selection stage therefore uses \(O(p^2\log(N+1))\) exact arithmetic operations on polynomial-length integers. Preprocessing, tie-breaking, and conversion to class counts are also polynomial.

Here exact maximization means returning an optimal count vector. The algorithm does not construct harmonic numbers or expand the optimal objective into a numerator-denominator representation; such a representation can be much larger than the compact input.
