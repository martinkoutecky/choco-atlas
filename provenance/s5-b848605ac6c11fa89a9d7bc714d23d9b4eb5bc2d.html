The continuous mirror question, as graded

Given finite \(C\), rational \(\mu\) over \(T=\mathcal L(C)\), and \(\alpha\in[0,1]\), compute \(a\in C\) and \(\pi\ge 0\) satisfying \(\sum_c\pi(t,c)=\mu_t\), \(\sum_t\pi(t,c)=q_\mu(c)\), where \(q_\mu(c)=\sum_{t:\operatorname{top}(t)=c}\mu_t\), and \(\pi(t,c)>0\) only if \(a\succeq_t c\). Prove the worst-case bound \(\sup_d \operatorname{SC}_\mu(a,d)/\min_b\operatorname{SC}_\mu(b,d)\le 2+\alpha\) over measurable populations and compatible \(\alpha\)-decisive metrics, and determine whether the bound is tight.

Packaged proof task (what the prover saw — nothing else)

Definitions

Let \(C\) be finite, \(T=\mathcal L(C)\), and let rational probability mass \(\mu\) be given explicitly by its positive-support types and binary weights. Write \(q_\mu(c)=\sum_{t:\operatorname{top}(t)=c}\mu_t\), and let \(a\succeq_t c\) mean that \(a=c\) or \(t\) ranks \(a\) above \(c\).
A feasible continuous PluralityMatching output is \(a\in C\) and \(\pi:T\times C\to\mathbb R_{\ge0}\) with \(\sum_c\pi(t,c)=\mu_t\), \(\sum_t\pi(t,c)=q_\mu(c)\), and \(\pi(t,c)>0\) only if \(a\succeq_t c\).
A compatible measurable population is a probability space partitioned into type sets of masses \(\mu_t\), embedded with \(C\) in a metric \(d\) consistent with each type's ranking. It is \(\alpha\)-decisive if \(d(x,\operatorname{top}(t))\le\alpha d(x,c)\) for every agent \(x\) of type \(t\) and \(c\ne\operatorname{top}(t)\); set \(\operatorname{SC}_\mu(c,d)=\int d(x,c)\,d\mu(x)\).

Target

Is computing a feasible \(a,\pi\) polynomial-time solvable, or NP-hard? Does every feasible output have worst-case distortion at most \(2+\alpha\), and is this bound tight for \(m=|C|\ge3\)?

Nearest known results

For finite electorates, a candidate whose integral domination graph has a perfect matching is computable in strongly polynomial time; the corresponding PluralityMatching rule has tight distortion \(2+\alpha\) for \(m\ge3\).

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

Result and conventions

Computing a feasible output is polynomial-time solvable in the binary input length. For every \(\alpha\in[0,1]\), every feasible output satisfies the distortion bound \(2+\alpha\), and this uniform bound is tight for every \(m\ge3\).

The usual parameter range is \(\alpha\in[0,1]\). If the definition permits arbitrary \(\alpha\ge0\), the sharp bound is \(2+\min\{\alpha,1\}\).

Write \(S=\{t:\mu_t>0\}\) and \(k=|S|\). We represent \(\pi\) by its entries on \(S\times C\), with all other entries implicitly zero.

1. Existence for rational distributions

We use the supplied finite-electorate existence theorem: for every finite electorate \(V\) with linear rankings, there exist a candidate \(a\) and a bijection \(M:V\to V\) such that \(a\succeq_i\operatorname{top}(M(i))\) for every voter \(i\). This is Corollary 1 of [Gkatzelis–Halpern–Shah, *Resolving the Optimal Metric Distortion Conjecture*](https://daniel-halpern.com/files/optimal-metric-distortion.pdf).

Choose a positive common denominator \(D\) for the rational numbers \(\mu_t\), and set \(n_t=D\mu_t\). These are nonnegative integers satisfying \(\sum_{t\in S}n_t=D\).

For an existence argument, form a finite electorate containing \(n_t\) copies of each type \(t\). The cited theorem applies because this electorate is finite and every voter has a linear ranking. Let \(a,M\) be its guaranteed candidate and bijection. Define

\(\displaystyle \pi(t,c)=\frac{1}{D}\left|\{i:\operatorname{type}(i)=t,\ \operatorname{top}(M(i))=c\}\right|.\)

There are exactly \(n_t\) voters of type \(t\), so

\(\displaystyle \sum_{c\in C}\pi(t,c)=\frac{n_t}{D}=\mu_t.\)

Because \(M\) is a bijection, its images include each voter exactly once. Consequently,

\(\displaystyle \sum_{t\in S}\pi(t,c)=\frac{|\{j:\operatorname{top}(j)=c\}|}{D}=q_\mu(c).\)

Finally, positivity of \(\pi(t,c)\) implies that some matched pair satisfies \(\operatorname{type}(i)=t\) and \(\operatorname{top}(M(i))=c\). The matching property then gives \(a\succeq_t c\). Thus \((a,\pi)\) is feasible.

The potentially large replicated electorate is used only to prove existence.

2. A polynomial-time algorithm

Write each positive input weight as \(\mu_t=u_t/v_t\), and take \(D=\prod_{t\in S}v_t\). The binary length of \(D\) is at most the sum of the binary lengths of these denominators. Thus \(D\), the integers \(n_t=D\mu_t\), and the integers

\(\displaystyle Q_c=\sum_{t:\operatorname{top}(t)=c}n_t=Dq_\mu(c)\)

can all be computed in polynomial time and have polynomial binary length.

For each candidate \(a\), construct a directed flow network with a source \(s\), one vertex for each \(t\in S\), one vertex for each \(c\in C\), and a sink \(z\). Its arcs are:

  • \(s\to t\), with capacity \(n_t\);
  • \(t\to c\), with capacity \(D\), whenever \(a\succeq_t c\);
  • \(c\to z\), with capacity \(Q_c\).

Equivalence. This network has a flow of value \(D\) if and only if \(a\) admits a feasible \(\pi\).

Indeed, a flow of value \(D\) saturates every source arc and every sink arc: each of these two collections has total capacity \(D\). Conservation therefore shows that

\(\displaystyle \pi(t,c)=f(t,c)/D\)

has the required row and column sums. Its positive entries occur only on permitted arcs.

Conversely, any feasible \(\pi\) gives a flow by setting \(f(t,c)=D\pi(t,c)\), \(f(s,t)=n_t\), and \(f(c,z)=Q_c\). The middle-arc capacities hold because \(\pi(t,c)\le\mu_t\le1\).

Each network has \(k+m+2\) vertices and at most \(km+k+m\) arcs. An integer maximum-flow algorithm such as Edmonds–Karp uses a polynomial number of arithmetic operations, independent of the numerical value of \(D\). All capacities and flow values have polynomial binary length. Testing all \(m\) candidates is therefore polynomial-time in the original input length.

Section 1 guarantees that at least one test succeeds. Returning that candidate and the normalized flow completes the algorithm.

3. Distortion for arbitrary measurable populations

Let \((a,\pi)\) be any feasible output. Fix a compatible \(\alpha\)-decisive population, with probability measure \(\nu\), and let \(X_t\) denote its measurable type sets, so \(\nu(X_t)=\mu_t\). Fix any comparison candidate \(b\).

For each \(t\in S\), define \(\lambda_{t,c}=\pi(t,c)/\mu_t\). These numbers are nonnegative and sum to one.

Whenever \(\lambda_{t,c}>0\), feasibility and metric consistency imply

\(\displaystyle d(x,a)\le d(x,c)\le d(x,b)+d(b,c)\qquad(x\in X_t).\)

Averaging over \(c\) gives

\(\displaystyle d(x,a)\le d(x,b)+\sum_{c\in C}\lambda_{t,c}d(b,c).\)

Integrating over all type sets and using the column sums of \(\pi\), we obtain

\(\displaystyle \operatorname{SC}_\mu(a,d)\le \operatorname{SC}_\mu(b,d)+\sum_{t\in S}\sum_{c\in C}\pi(t,c)d(b,c)=\operatorname{SC}_\mu(b,d)+\sum_{c\in C}q_\mu(c)d(b,c).\)

It remains to bound the last sum. For an agent \(x\) whose top candidate is \(c\ne b\), the triangle inequality and decisiveness give

\(\displaystyle d(b,c)\le d(b,x)+d(x,c)\le(1+\alpha)d(x,b).\)

Integrating this inequality over agents whose top candidate is \(c\), and then summing over \(c\ne b\), yields

\(\displaystyle \sum_{c\in C}q_\mu(c)d(b,c)\le(1+\alpha)\int_{\{x:\operatorname{top}(x)\ne b\}}d(x,b)\,d\nu(x)\le(1+\alpha)\operatorname{SC}_\mu(b,d).\)

Here the term for \(c=b\) vanishes because \(d(b,b)=0\). Combining the inequalities proves

\(\displaystyle \operatorname{SC}_\mu(a,d)\le(2+\alpha)\operatorname{SC}_\mu(b,d).\)

This holds for every comparison candidate \(b\), and hence for an optimal candidate.

The argument uses only finite sums and integrals of nonnegative measurable functions, so it also holds as an extended-real inequality. For the usual distortion ratio, one considers populations with finite positive optimal social cost. If the optimal cost is zero, the inequality forces the output’s cost to be zero as well.

4. Tightness survives aggregation into types

We now use precisely the supplied finite-electorate tightness result: for every \(m\ge3\), every \(\alpha\in[0,1]\), and every \(\varepsilon>0\), there is a finite electorate, a compatible \(\alpha\)-decisive metric, and a candidate \(a\) admitting an integral domination matching whose cost ratio is at least \(2+\alpha-\varepsilon\). See Theorem 1 of [Gkatzelis–Halpern–Shah](https://daniel-halpern.com/files/optimal-metric-distortion.pdf).

Let such an electorate have \(n\) voters. Define the rational distribution

\(\displaystyle \mu_t=\frac{|\{i:\operatorname{type}(i)=t\}|}{n}.\)

Its positive-support rankings and rational weights constitute an input of the required form. Give each original voter probability mass \(1/n\). This is a compatible measurable population: its type sets have masses \(\mu_t\), and its metric and decisiveness are unchanged.

Aggregate the integral matching exactly as in Section 1, now dividing by \(n\). This produces a feasible \((a,\pi)\) for the distribution.

For every candidate \(c\), normalization gives

\(\displaystyle \operatorname{SC}_\mu(c,d)=\frac{1}{n}\sum_{i=1}^{n}d(i,c).\)

Thus normalization preserves every social-cost ratio, including the ratio to the optimal candidate. The resulting feasible output has distortion at least \(2+\alpha-\varepsilon\).

Since \(\varepsilon>0\) was arbitrary, no smaller uniform bound is possible. Together with Section 3, this proves tightness for every \(m\ge3\).

5. Parameters above one

Metric consistency implies \(d(x,\operatorname{top}(x))\le d(x,c)\). Every compatible population is therefore \(1\)-decisive.

Consequently, for \(\alpha\ge1\), Section 3 gives the stronger bound \(3\). Conversely, every \(1\)-decisive example is also \(\alpha\)-decisive, so the lower bound for \(\alpha=1\) still applies. Hence the sharp bound over all nonnegative parameters is \(2+\min\{\alpha,1\}\).
