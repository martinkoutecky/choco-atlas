The continuous mirror question, as graded

Given types \(t\) with rational masses \(\mu_t\), machine classes \(j\) with per-population supplies \(q_j\), weights \(w_{tj}\), and integer parallelism caps \(k_t\), find the maximum welfare and an optimal assignment of mass to integral bundles. For bundle \(a\in\mathbb Z_{\ge 0}^{J}\), let \(y_{t,a}\) be the mass of type \(t\) receiving it; solve \(\max_{y\ge 0}\sum_{t,a} y_{t,a}\sum_j a_jw_{tj}\), subject to \(\sum_a y_{t,a}=\mu_t\) for each \(t\), \(\sum_{t,a}a_jy_{t,a}\le q_j\) for each \(j\), and \(y_{t,a}=0\) whenever \(\sum_j a_j>k_t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive masses \(\mu_t\), each a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) machine classes, with binary rational supplies \(q_j\ge0\) per unit population and binary rational weights \(w_{tj}\ge0\). Each type has a positive integer parallelism cap \(k_t\), encoded in binary; weights need not be normalized.
A bundle comprises whole machine units: \(A_t=\{a\in\mathbb Z_{\ge0}^{m}:\sum_j a_j\le k_t\}\). Multiple units of the same class are permitted, and the empty bundle is permitted.
An assignment splits each type's mass among bundles: \(y_{t,a}\ge0\), with \(\sum_{a\in A_t}y_{t,a}=\mu_t\) and \(\sum_t\sum_{a\in A_t}a_jy_{t,a}\le q_j\). Supplies may remain unused.
Its welfare is \(\sum_t\sum_{a\in A_t}y_{t,a}\sum_j a_jw_{tj}\). The computational problem is to find the exact maximum and an optimal assignment, represented by its positive bundle masses.

Is this continuous welfare-maximization problem solvable in polynomial time, or is it NP-hard? State running times in \(m\), \(\tau\), the total input bit length \(L\), and the caps \(k_t\).

For finitely many users and individually listed machines, the maximum welfare with nonnegative additive weights and per-user parallelism caps equals a maximum-weight bipartite matching value and is computable in polynomial time. [Source](https://arxiv.org/abs/cs/0502019).
No result settling exactly the mass-allocation problem specified above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive type masses to sum to one, interpreting supplies as machine units per unit population.
  • Set supplies and weights to nonnegative binary rationals; retained unnormalized weights because normalization is not a condition of the welfare algorithm.
  • Used m for the number of machine classes, required nonempty society and class sets, and specified positive integer caps encoded in binary.
  • Interpreted machine classes as collections of interchangeable whole machine units, retaining the graded question's permission to receive multiple units of a class.

Conclusion

The problem is solvable exactly in polynomial time in \(m\), \(\tau\), and the total input bit length \(L\). The caps affect the bit complexity through their binary encodings, rather than through their numerical values.

An optimal assignment can be represented using at most \(\tau(m+1)\) positive bundle masses. The key is that every feasible average allocation can be realized using only the empty bundle and bundles containing \(k_t\) units of one class.

1. An exact compact formulation

For each type \(t\) and class \(j\), define the aggregate number of allocated units per unit population by

\(x_{tj}=\sum_{a\in A_t}a_jy_{t,a}\).

Every feasible assignment satisfies

\(x_{tj}\ge 0,\qquad \sum_{j=1}^{m}x_{tj}\le \mu_tk_t,\qquad \sum_{t=1}^{\tau}x_{tj}\le q_j.\)

Indeed, the type constraint follows from

\(\sum_jx_{tj}=\sum_{a\in A_t}y_{t,a}\sum_ja_j\le k_t\sum_{a\in A_t}y_{t,a}=\mu_tk_t.\)

By additivity, its welfare equals

\(\sum_{t=1}^{\tau}\sum_{j=1}^{m}w_{tj}x_{tj}.\)

Conversely, suppose \(x\) satisfies these aggregate constraints. Let \(e_j\) be the \(j\)-th coordinate vector. Since \(k_t\) is a positive integer, both \(0\) and \(k_te_j\) belong to \(A_t\). Set

\(y_{t,k_te_j}=\dfrac{x_{tj}}{k_t},\qquad y_{t,0}=\mu_t-\dfrac{\sum_jx_{tj}}{k_t},\)

and set every other bundle mass to zero.

These masses are nonnegative and sum to \(\mu_t\). Their class-\(j\) consumption is exactly

\(\sum_t k_t y_{t,k_te_j}=\sum_t x_{tj}\le q_j,\)

and their welfare is exactly \(\sum_{t,j}w_{tj}x_{tj}\).

Thus the original problem is equivalent, in both directions and with identical objective values, to the linear program

\(\displaystyle \max_{x\ge 0}\ \sum_{t,j}w_{tj}x_{tj}\)

subject to

\(\displaystyle \sum_jx_{tj}\le \mu_tk_t\quad\text{for every }t,\qquad \sum_tx_{tj}\le q_j\quad\text{for every }j.\)

This program has \(m\tau\) variables and \(\tau+m\) inequality constraints. Its feasible region is nonempty, since \(x=0\) is feasible, and compact, since \(0\le x_{tj}\le\mu_tk_t\). Consequently, an optimum exists.

2. Exact polynomial-time computation

The compact program already establishes polynomial-time solvability by exact rational linear programming: its encoding length is polynomial in \(m,\tau,L\), including the products \(\mu_tk_t\).

An explicit arithmetic-operation bound follows from a transportation formulation. Write

\(b_t=\mu_tk_t,\qquad B=\sum_tb_t,\qquad Q=\sum_jq_j.\)

Construct a directed bipartite network with:

  • one supply node for each type, with supply \(b_t\);
  • one additional supply node, with supply \(Q\);
  • one demand node for each class, with demand \(q_j\);
  • one additional demand node, with demand \(B\).

Include all arcs from supply nodes to demand nodes, without upper capacities. An arc from type \(t\) to class \(j\) has cost \(-w_{tj}\); every arc incident to an additional node has cost zero.

To verify the reduction, let \(x\) satisfy the compact constraints and put \(X=\sum_{t,j}x_{tj}\). Extend \(x\) to a flow by assigning:

| Arc | Flow |
|---|---|
| Type \(t\) to class \(j\) | \(x_{tj}\) |
| Type \(t\) to additional demand node | \(b_t-\sum_jx_{tj}\) |
| Additional supply node to class \(j\) | \(q_j-\sum_tx_{tj}\) |
| Additional supply node to additional demand node | \(X\) |

All these flows are nonnegative. The additional supply node sends \(Q-X+X=Q\), and the additional demand node receives \(B-X+X=B\), so every balance equation holds.

Conversely, in any feasible transportation flow, the real type-to-class flows satisfy the compact inequalities, because the remaining outgoing and incoming flows are nonnegative. Its cost is exactly \(-\sum_{t,j}w_{tj}x_{tj}\). Hence minimum cost equals negative maximum welfare.

The network has

\(N=\tau+m+2,\qquad E=(\tau+1)(m+1).\)

It is feasible, and every arc flow is bounded by the total supply \(B+Q\), so its objective is bounded. Orlin’s strongly polynomial algorithm for uncapacitated minimum-cost flow therefore gives the arithmetic-operation bound

\(\displaystyle O\!\left(N\log N\left(E+N\log N\right)\right).\)

This is the standard bound from [Orlin, *A Faster Strongly Polynomial Minimum Cost Flow Algorithm*](https://pubsonline.informs.org/doi/10.1287/opre.41.2.338).

For exact rational inputs, one may first multiply all supplies and demands by a common denominator, and separately multiply all costs by a common denominator. The products of the input denominators have bit length \(O(L)\); the resulting integer data likewise have polynomial bit length. These scalings preserve optimality, and scaling the resulting flows back recovers the exact rational solution.

Thus the bit running time is \(\operatorname{poly}(m,\tau,L)\). The displayed arithmetic bound is independent of the numerical values of the caps. In particular, there is no factor proportional to \(k_t\), nor any enumeration of the \(\binom{k_t+m}{m}\) possible bundles.

3. Producing the requested assignment

After computing an exact optimal \(x\), apply the formulas from Section 1 and output only positive masses.

For each type, there are at most \(m\) positive masses on bundles \(k_te_j\), plus one on the empty bundle. Hence the output contains at most \(\tau(m+1)\) positive bundle masses.

Reconstruction takes \(O(m\tau)\) rational arithmetic operations. Each bundle coordinate is either zero or the binary-encoded integer \(k_t\), and the rational masses have polynomial encoding length. Even when bundle vectors are written densely, the complete output has polynomial size.

This settles the specified mass-allocation problem, including exact welfare computation and an explicit optimal assignment.
