The continuous mirror question, as graded

Given rational type masses μ_t, where each type has eligibility set \(F_t\) and claim \(x_t\), and per-capita resource supplies \(r_a\) satisfying \(∑_{a∈A} r_a ≤ ∑_{t:F_t\cap A\ne\varnothing}\mu_t x_t\) for every \(A\subseteq Q\), compute the unique feasible per-type allocation \(y_{ta}\ge 0\) minimizing \(∑_t\mu_t[\sum_{a\in F_t}y_{ta}^2+(x_t-\sum_{a\in F_t}y_{ta})^2]\), subject to \(∑_{a\in F_t}y_{ta}\le x_t\) and \(∑_{t:a\in F_t}\mu_t y_{ta}=r_a\).

Packaged proof task (what the prover saw — nothing else)

Let \(Q\) be a nonempty set of \(m\) resources. A society is given by its support: the list of its \(\tau\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has a nonempty eligibility set \(F_t\subseteq Q\) and a nonnegative rational per-person claim \(x_t\). Every resource belongs to some \(F_t\), and has a nonnegative rational per-capita supply \(r_a\). Let \(L\) be the total binary input length.
Inputs satisfy \(\sum_{a\in A}r_a\leq\sum_{t:F_t\cap A\neq\varnothing}\mu_t x_t\) for every \(A\subseteq Q\).
An allocation specifies per-person amounts \(y_{ta}\geq0\) for \(a\in F_t\), with \(\sum_{a\in F_t}y_{ta}\leq x_t\) and \(\sum_{t:a\in F_t}\mu_t y_{ta}=r_a\).
The computational problem is to compute exactly the unique feasible minimizer of \(\sum_t\mu_t[\sum_{a\in F_t}y_{ta}^2+(x_t-\sum_{a\in F_t}y_{ta})^2]\).

Is this exact allocation problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite agent lists, strictly convex edge costs and convex loss costs define a unique, symmetric, continuous allocation unchanged when an edge is deleted and its flow is subtracted from both endpoint capacities. [Moulin–Sethuraman](https://www.columbia.edu/~js1353/pubs/consistentflowA6.pdf).
Exact convex quadratic programming with rational data is polynomial-time solvable. [Kozlov–Tarasov–Khachiyan](https://www.mathnet.ru/eng/zvmmf5189).

Modeling choices made when packaging the task

  • Normalized masses to sum to one because the society is a distribution and supplies are per capita.
  • Specified claims and supplies as nonnegative binary rationals; zero claims and supplies remain permitted.
  • Restored nonempty eligibility sets and coverage of every resource, as required by the discrete model.
  • Interpreted compute as exact computation and defined L as the total binary input length.

Exact allocation is polynomial-time solvable

The unique allocation can be computed exactly in time polynomial in \(m,\tau,L\), in the binary bit model. The key is to formulate the problem using only the listed types and eligibility edges.

1. The promised inequalities guarantee feasibility

Write \(c_t=\mu_t x_t\) and \(R=\sum_{a\in Q}r_a\). If \(R=0\), the allocation \(y_{ta}=0\) is feasible. Suppose henceforth that \(R>0\).

Construct a directed network with source \(s\), one vertex per resource, one vertex per listed type, and sink \(z\). Its arcs and capacities are:

  • \(s\to a\), with capacity \(r_a\);
  • \(a\to t\) whenever \(a\in F_t\), with capacity \(R\);
  • \(t\to z\), with capacity \(c_t\).

Consider any cut separating \(s\) from \(z\). Let \(A\) be its resource vertices on the source side, and \(T\) its type vertices on that side.

If an eligibility arc crosses the cut, its capacity alone is \(R\), so the cut capacity is at least \(R\). Otherwise, every type eligible for a resource in \(A\) belongs to \(T\). Thus the cut capacity is

\(R-\sum_{a\in A}r_a+\sum_{t\in T}c_t \ge R-\sum_{a\in A}r_a+\sum_{t:F_t\cap A\ne\varnothing}\mu_t x_t \ge R.\)

The final inequality is precisely the input promise. By the max-flow/min-cut theorem, a flow of value \(R\) exists. All arcs leaving \(s\) must consequently be saturated.

Let \(f_{at}\) denote its flow on \(a\to t\). Since \(\mu_t>0\), setting \(y_{ta}=f_{at}/\mu_t\) gives

\(\sum_{t:a\in F_t}\mu_t y_{ta}=r_a,\qquad \sum_{a\in F_t}y_{ta}\le c_t/\mu_t=x_t.\)

Hence the allocation polytope is nonempty. This argument uses the subset inequalities to prove feasibility; an algorithm need not enumerate them.

2. A polynomial-size quadratic program

Define the listed edge set \(E=\{(t,a):a\in F_t\}\), and put \(n=|E|\). Then \(n\le m\tau\).

Introduce one nonnegative loss variable \(\ell_t\) for each type. Consider the quadratic program

\(\displaystyle \min_{y,\ell}\ \sum_{t=1}^{\tau}\mu_t \left(\sum_{a\in F_t}y_{ta}^{\,2}+\ell_t^{\,2}\right),\)

subject to

\(\displaystyle \sum_{a\in F_t}y_{ta}+\ell_t=x_t \quad\text{for every type }t,\)

\(\displaystyle \sum_{t:a\in F_t}\mu_t y_{ta}=r_a \quad\text{for every resource }a,\)

and \(y_{ta}\ge0,\ \ell_t\ge0\).

The type equations force
\(\ell_t=x_t-\sum_{a\in F_t}y_{ta}\).
Consequently, feasible allocations correspond bijectively to feasible points of this program, and their objective values agree.

There are \(d=n+\tau\le\tau(m+1)\) variables, \(m+\tau\) equalities, and \(d\) nonnegativity constraints. Every coefficient is rational and is either an input coefficient or a number of constant encoding length. Even a dense encoding therefore has length polynomial in \(m,\tau,L\).

3. Existence and uniqueness

Every feasible coordinate \(y_{ta}\) and \(\ell_t\) lies between \(0\) and \(x_t\). The feasible set is therefore closed, bounded, and, by Section 1, nonempty. The continuous objective attains its minimum.

Let \(v\) collect all variables. The objective is \(\frac12v^{\mathsf T}Hv\), where \(H\) is diagonal: every coordinate belonging to type \(t\) has diagonal entry \(2\mu_t\).

Because all masses are positive, for every nonzero vector \(h\),

\(h^{\mathsf T}Hh =2\sum_t\mu_t\left(\sum_{a\in F_t}h_{ta}^{\,2}+h_{\ell_t}^{\,2}\right)>0.\)

Thus \(H\) is positive definite, and the objective is strictly convex. The feasible set is convex, so two distinct minimizers are impossible: their midpoint would have strictly smaller objective value. The minimizer, and hence its allocation component, is unique.

4. Exact rational output has polynomial length

For completeness, rationality here follows directly from a linear system; it is not merely an approximation claim.

Write the equality constraints as \(Bv=b\), and let \(v^*\) be the minimizer. Define its positive support \(J=\{j:v_j^*>0\}\). If \(J\) is empty, \(v^*=0\) is rational.

Otherwise, restrict \(B\) to the columns in \(J\), and select a maximal linearly independent collection of its rows. Call the resulting full-row-rank matrix \(C\), and let \(b_C\) contain the corresponding right-hand sides. Let \(H_J\) be the principal submatrix of \(H\).

For any \(h\in\ker C\), all original equality rows also annihilate \(h\), because the selected rows span their row space. Moreover, both \(v_J^*+\varepsilon h\) and \(v_J^*-\varepsilon h\), extended by zero outside \(J\), remain nonnegative for sufficiently small positive \(\varepsilon\). Optimality therefore gives

\(h^{\mathsf T}H_Jv_J^*=0.\)

The orthogonal complement of \(\ker C\) is the row space of \(C\). Hence there is a vector \(\lambda\) satisfying

\(H_Jv_J^*+C^{\mathsf T}\lambda=0,\qquad Cv_J^*=b_C.\)

This square system is nonsingular. Indeed, a homogeneous solution \((u,\eta)\) satisfies

\(H_Ju+C^{\mathsf T}\eta=0,\qquad Cu=0.\)

Multiplication by \(u^{\mathsf T}\) gives \(u^{\mathsf T}H_Ju=0\), so positive definiteness implies \(u=0\). Full row rank of \(C\) then implies \(\eta=0\).

All system coefficients are rational, and its dimension is at most \(2d\). Clearing denominators produces integer coefficients of polynomial bit length: the logarithm of a product of denominators is the sum of their logarithms. Cramer’s rule expresses every solution coordinate as a ratio of determinants. The bound
\(|\det M|\le k!M_{\max}^{\,k}\)
for a \(k\)-dimensional integer matrix shows that these determinants also have polynomial bit length. Thus the exact allocation has polynomial output length.

This argument establishes an output bound; it does not require an algorithm to guess or enumerate \(J\).

5. Applying exact quadratic programming

The Kozlov–Tarasov–Khachiyan theorem gives a deterministic algorithm that computes an exact optimal point of a convex quadratic program with rational data in time polynomial in its binary encoding length, when the constraints are feasible and the objective is bounded below. The original integer-data formulation extends to rational data by clearing constraint denominators and multiplying the objective by a positive common denominator; these operations preserve feasibility and minimizers and cause only polynomial encoding growth. [Kozlov–Tarasov–Khachiyan, *The polynomial solvability of convex quadratic programming*](https://www.mathnet.ru/eng/zvmmf5189).

Every hypothesis holds here: the program has rational coefficients, a positive definite quadratic matrix, and a nonempty compact feasible set. Its encoding length is polynomial in \(m,\tau,L\). Applying the theorem and retaining the \(y\)-coordinates therefore computes exactly the requested unique allocation in polynomial time.

No expansion of rational masses into individual agents is needed.
