The continuous mirror question, as graded

Given a finite alternative set \(S\), a current Reality \(R\in S\), an agenda order, and a society represented by \(\tau\) strict rankings \(t\) with positive rational masses \(\mu_t\) summing to \(1\), with no ties in the majority comparisons used, compute the winner returned by Algorithm 1: form \(S_R=\{s\in S\setminus\{R\}:\sum_{t:s\succ_t R}\mu_t>1/2\}\), run the agenda on \(S_R\) starting with \(R\), and return the final alternative if it wins every required comparison, or \(R\) otherwise.

Packaged proof task (what the prover saw — nothing else)

Let \(S\) be a finite alternative set with \(m=|S|\geq 1\), a distinguished current Reality \(R\in S\), and a supplied linear agenda order on \(S\).
A society is given by its support: the list of the \(\tau\) strict rankings of \(S\) with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For distinct alternatives, write \(a\triangleright b\) when \(\sum_{t:a\succ_t b}\mu_t>1/2\). Promise that every majority comparison used below is untied.
Form \(S_R=\{s\in S\setminus\{R\}:s\triangleright R\}\). If this set is empty, return \(R\). Otherwise initialize an incumbent to \(R\), visit each member of \(S_R\) in the restricted agenda order, and replace the incumbent by the majority winner of its comparison with the visited alternative.
Let \(c\) be the final incumbent. Compare \(c\) with every other member of \(S_R\) that it has not already faced during the agenda; return \(c\) if it wins every extra comparison, and return the original \(R\) otherwise. The rankings and original Reality remain fixed throughout.

Is computing the returned alternative solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite electorates, this procedure satisfies the conservative Reality-aware Condorcet criterion: it elects the Condorcet winner of \(S_R\) whenever one exists, and elects \(R\) otherwise.

Modeling choices made when packaging the task

  • Made the supplied agenda a linear order on the alternatives, restricted to the Reality-viable set during execution.
  • Specified that the required final comparisons are against members of the Reality-viable set that the final incumbent has not previously faced.
  • Distinguished the changing incumbent from the original Reality: viability, rankings, and the fallback alternative remain fixed throughout execution.
  • Specified the empty viable-set outcome and defined L as the total input bit length.

Conclusion

Computing the returned alternative is polynomial-time solvable. With exact arithmetic, a running-time bound is \(O(\tau L^2+\tau mL)\). The stated conservative Reality-aware Condorcet criterion also holds for the supplied rational masses.

Exact majority comparisons

Write each mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive integers encoded in binary. Define \(Q=\prod_{t=1}^{\tau}q_t\) and \(W_t=p_t(Q/q_t)\). Then \(\mu_t=W_t/Q\), and normalization gives \(\sum_{t=1}^{\tau}W_t=Q\).

The bit length of \(Q\) is \(O(L)\), because the sum of the denominators’ bit lengths is bounded by the input length. Each \(W_t\) also has \(O(L)\) bits: positivity and normalization imply \(W_t\leq Q\). Computing \(Q\) and all \(W_t\) takes \(O(\tau L^2)\) bit operations using schoolbook integer arithmetic.

For each ranking, construct a position table \(\operatorname{pos}_t(a)\). Thus \(a\succ_t b\) exactly when \(\operatorname{pos}_t(a)<\operatorname{pos}_t(b)\). These tables take \(O(\tau m\log(m+1))\) bit operations to construct.

For distinct \(a,b\), compute \(A(a,b)=\sum_{t:\operatorname{pos}_t(a)<\operatorname{pos}_t(b)}W_t\). Then \(a\triangleright b\) exactly when \(2A(a,b)>Q\). All partial sums are at most \(Q\), so a comparison takes \(O(\tau L)\) bit operations with indexed position tables. The untied-comparison promise makes each required comparison decisive.

Number of comparisons and running time

Let \(k=|S_R|\).

  • Constructing \(S_R\) requires \(m-1\) majority comparisons.
  • If \(k>0\), the agenda requires \(k\) comparisons.
  • The final verification requires at most \(k-1\) comparisons.

Consequently, there are at most \(3(m-1)\) majority comparisons. Record the agenda’s compared pairs; after finding its final incumbent \(c\), scan this record to identify the alternatives already faced by \(c\). The record and scan require \(O(m)\) entries and operations.

Combining preprocessing and comparison costs gives \(O(\tau L^2+\tau mL)\), since \(\log(m+1)=O(L)\) for the explicit input representation. This is polynomial in \(m,\tau,L\).

Proof of the Condorcet criterion

A Condorcet winner of \(S_R\) is an alternative \(w\in S_R\) satisfying \(w\triangleright s\) for every \(s\in S_R\setminus\{w\}\).

If \(S_R\) is empty, the procedure returns \(R\) as specified. Assume henceforth that \(S_R\) is nonempty.

The final incumbent won every comparison it faced

Each eligible alternative is visited exactly once. If an incumbent loses, it is replaced and cannot become incumbent again: its visit has already occurred.

Therefore, the final incumbent \(c\) cannot have lost an agenda comparison. Moreover, \(c\in S_R\), because the first visited alternative defeats \(R\), and every subsequent incumbent belongs to \(S_R\).

If the final verification accepts \(c\), then \(c\) defeats every other member of \(S_R\): it defeated those it faced during the agenda, and the verification checks all remaining members. Thus every returned alternative other than \(R\) is a Condorcet winner of \(S_R\).

Any Condorcet winner becomes the final incumbent

Suppose \(w\) is a Condorcet winner of \(S_R\). Immediately before \(w\)'s visit, the incumbent is either \(R\) or an earlier visited member of \(S_R\).

Because \(w\in S_R\), it defeats \(R\). Because it is a Condorcet winner of \(S_R\), it defeats every other possible incumbent. Hence \(w\) becomes incumbent when visited. It defeats every subsequently visited alternative, so it remains the final incumbent. It also wins every extra comparison and is returned.

These two statements prove that the procedure returns the Condorcet winner of \(S_R\) whenever one exists, and returns \(R\) otherwise. Uniqueness follows because two distinct Condorcet winners would each have to defeat the other, which strict majority comparisons cannot permit.

Thus the problem belongs to \(\mathrm{P}\); NP-hardness under polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).
