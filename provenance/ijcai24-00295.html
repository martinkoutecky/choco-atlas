The continuous mirror question, as graded

Given a finite action set \(A\), finite type set \(\Theta\), rational masses \(\mu_\theta\ge 0\) with \(\sum_{\theta\in\Theta}\mu_\theta=1\), rational type payoff tables \(p_\theta(a),p_\theta^*(a)\), and a common goal action \(g\) satisfying \(p_\theta(g)\ge p_\theta(a)\), define \(h_\theta(a)=p_\theta(g)-p_\theta(a)\), \(t_\theta(a)=p_\theta^*(a)-p_\theta(g)\), and \(\Delta_\theta=p_\theta^*(g)-p_\theta(g)\). Find a finite hazing sequence \(S=(a_0,\ldots,a_{\ell-1},g,g,\ldots)\) minimizing \(\mathcal H_\mu(S)=\sum_{\theta}\mu_\theta\sum_{i=0}^{\ell-1}h_\theta(a_i)\), subject for every \(\theta\) with \(\mu_\theta>0\) to \(\sum_{i=0}^{k-1}h_\theta(a_i)>t_\theta(a_k)\) for every \(k<\ell\) and \(\sum_{i=0}^{\ell-1}h_\theta(a_i)>\Delta_\theta\); the decision version asks whether \(\mathcal H_\mu(S)\le B\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(\Theta\) of \(\tau\ge 1\) types with positive binary-rational masses \(\mu_\theta\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Let \(A\) be a finite action set, \(m=|A|\ge 2\), with a designated common goal action \(g\). Each type has signed binary-rational tables \(p_\theta(a)\) and \(p_\theta^*(a)\): respectively, its payoff from following the prescribed action and its maximum payoff from choosing a different action against a partner following it.
Require \(p_\theta(g)>p_\theta(a)\) for every \(a\ne g\), and \(\Delta_\theta=p_\theta^*(g)-p_\theta(g)>0\). Define \(h_\theta(a)=p_\theta(g)-p_\theta(a)\) and \(t_\theta(a)=p_\theta^*(a)-p_\theta(g)\); thresholds may have either sign.
A plan is one common deterministic sequence \(S=(a_0,\ldots,a_{\ell-1},g,g,\ldots)\), with finite \(\ell\ge 1\), \(a_i\in A\setminus\{g\}\), and unrestricted repetitions. Deviations trigger a restart of this sequence. Society masses are divisible; rounds and action occurrences remain discrete.
Feasibility means, for every \(\theta\in\Theta\), \(\sum_{i=0}^{k-1}h_\theta(a_i)>t_\theta(a_k)\) for every \(0\le k<\ell\), and \(\sum_{i=0}^{\ell-1}h_\theta(a_i)>\Delta_\theta\); the empty sum is \(0\).
Given a binary-rational budget \(B\ge 0\), decide whether a feasible plan satisfies \(\mathcal H_\mu(S)=\sum_{\theta\in\Theta}\mu_\theta\sum_{i=0}^{\ell-1}h_\theta(a_i)\le B\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For a single payoff table, rational-input OptRep is strongly \(\mathrm{NP}\)-hard, and its decision version is strongly \(\mathrm{NP}\)-complete; the integer-input version has a pseudopolynomial algorithm. [Verified discrete results](https://arxiv.org/html/2406.00851v1).
No result for exactly the distributional formulation above was identified in the literature search.

Modeling choices made when packaging the task

  • Removed zero-mass types from the input support and defined L as total binary input length.
  • Carried over OptRep's positive hazing costs by requiring every non-goal action to have strictly smaller cooperative payoff than the goal for every supported type.
  • Carried over the positive final hazing threshold by requiring Delta_theta > 0 for every supported type.
  • Restricted the finite hazing prefix to non-goal actions, as in OptRep's positive-cost action domain; repetitions are unrestricted and its length is not an input bound.
  • Required at least two actions so that deviation payoffs from a different action are defined; payoff tables may be signed and thresholds need not be nonnegative.
  • Set the decision budget domain to nonnegative binary rationals and retained the strict feasibility inequalities, including the condition at the first round.
  • Made explicit that the distribution replaces the society representation only: all types follow the same deterministic sequence, with discrete rounds and action occurrences.

Result

The decision problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard and admits a polynomial-time algorithm if and only if \(\mathrm P=\mathrm{NP}\).

The single-type case already embeds OptRep: set \(\mu_1=1\), \(p_1(g)=0\), \(p_1(a)=-h(a)\), \(p_1^*(a)=t(a)\), and \(p_1^*(g)=\Delta\). Both feasibility and the budget then agree exactly with the single-table formulation. [OptRep definition and hardness results](https://arxiv.org/html/2406.00851v1).

Below is a direct hardness proof for societies with multiple types, followed by a proof of membership in \(\mathrm{NP}\). The hardness construction uses integer payoffs and dyadic masses and budget.

1. Direct reduction from exact cover

We use Exact Cover by 3-Sets, the standard \(\mathrm{NP}\)-complete problem: given a universe \(U\) with \(|U|=3q\), where \(q\ge 1\), and three-element subsets \(C_1,\ldots,C_s\), decide whether some \(q\) of these subsets partition \(U\). We may assume \(s\ge 1\), since empty-family instances are trivial. [X3C formulation and hardness](https://doi.org/10.1162/COLI_a_00220).

Construction

Let \(d=q+1\), let \(N\) be the least power of two satisfying \(N\ge 3q\), and put \(r=N-3q\). Since a power of two cannot be divisible by three, \(r>0\).

Create one action \(a_j\) for each \(C_j\), together with the goal action \(g\). Thus \(m=s+1\).

Create one type for each element \(x\in U\), with mass \(\mu_x=1/N\), and one additional type \(\star\), with mass \(\mu_\star=r/N\). These masses are positive dyadic rationals and satisfy

\(\displaystyle \sum_{x\in U}\mu_x+\mu_\star=\frac{3q+r}{N}=1.\)

For every type, set \(p_\theta(g)=0\) and \(p_\theta^*(a_j)=-1\).

For element type \(x\), set

\(\displaystyle h_x(a_j)=\begin{cases}d,&x\in C_j,\\1,&x\notin C_j,\end{cases}\qquad p_x(a_j)=-h_x(a_j),\qquad p_x^*(g)=q.\)

For the additional type, set

\(\displaystyle h_\star(a_j)=d,\qquad p_\star(a_j)=-d,\qquad p_\star^*(g)=1.\)

Consequently, every non-goal action has strictly lower prescribed payoff than \(g\), and all goal deviation gaps are positive:

\(\displaystyle \Delta_x=q,\qquad \Delta_\star=1.\)

Moreover, every intermediate threshold is \(t_\theta(a_j)=-1\). All intermediate feasibility inequalities therefore hold for every sequence, including its first action, because every accumulated hazing is nonnegative.

Each action contains exactly three elements, so its society-weighted hazing cost is the same positive number

\(\displaystyle c=\sum_\theta\mu_\theta h_\theta(a_j)=\frac{3d+(3q-3)+rd}{N}.\)

Set \(B=qc\). This is a dyadic rational. Every plan of length \(\ell\) has cost \(\ell c\), and hence

\(\displaystyle \mathcal H_\mu(S)\le B\quad\Longleftrightarrow\quad \ell\le q.\)

Forward implication

Suppose \(C_{j_1},\ldots,C_{j_q}\) form an exact cover. Use the corresponding \(q\) actions in any order.

Every element type encounters an action containing its element. Its total hazing is therefore at least \(d=q+1>q=\Delta_x\).

The additional type receives total hazing \(qd>1=\Delta_\star\). Intermediate feasibility holds because all thresholds are negative. Finally, the cost is \(qc=B\).

Thus the constructed society is a yes-instance.

Reverse implication, including unrestricted repetitions

Suppose a feasible plan satisfies the budget. Its length obeys \(1\le\ell\le q\).

If some element \(x\) belongs to none of the selected subsets, every selected action contributes exactly \(1\) to its hazing. Its total is then \(\ell\le q=\Delta_x\), contradicting the strict final inequality.

Thus the selected subset occurrences cover all \(3q\) elements. Since every occurrence contains three elements,

\(\displaystyle 3q=\left|\bigcup_{i=0}^{\ell-1}C_{j_i}\right|\le\sum_{i=0}^{\ell-1}|C_{j_i}|=3\ell\le3q.\)

Every inequality must be equality. Hence \(\ell=q\), and the selected subsets are pairwise disjoint: any overlap would make the union strictly smaller than the sum of their cardinalities. In particular, no subset can be repeated.

The selected subsets therefore form an exact cover.

Encoding and construction time

Before any merging of identical types, the construction has \(\tau=3q+1\). Identical payoff tables may be merged by adding their masses; this preserves feasibility and cost.

All payoff entries are integers of magnitude at most \(q+1\). Mass denominators are \(N<6q\), and the budget numerator and denominator are polynomially bounded in \(q\). The explicit tables have length \(O(m\tau\log(2\tau))\) and can be constructed within that time.

This proves \(\mathrm{NP}\)-hardness for the stated distributional formulation.

2. Membership in \(\mathrm{NP}\)

An explicit action sequence may have exponential length. We instead prove that every yes-instance has a short description using blocks of repeated actions.

Lemma: each action can occur in one block

Every feasible plan can be rearranged, preserving its action multiplicities and cost, so that each non-goal action occurs in at most one contiguous block.

Proof. Write \(H_\theta\) for the accumulated hazing of type \(\theta\). Since every \(h_\theta(a)>0\), an action that is feasible at some accumulated vector remains feasible after any further actions.

Take the first action \(a\) in the current sequence, and move all its later occurrences immediately after its first occurrence.

The first occurrence remains feasible. Each subsequent occurrence in the resulting block is feasible because its accumulated hazing is componentwise larger.

For any occurrence of another action \(b\), its preceding occurrences of actions other than \(a\) are unchanged. Some occurrences of \(a\) may have moved from after \(b\) to before it, but none have moved in the opposite direction. Its accumulated hazing therefore increases componentwise or stays unchanged, preserving its strict feasibility inequalities.

The final totals and cost remain unchanged. Fix this first block and repeat the argument on the remaining suffix. Each step fixes one previously ungrouped action, so after at most \(m-1\) steps every action occupies one block. \(\square\)

Polynomial bounds on encoded multiplicities

For a non-goal action define its positive cost

\(\displaystyle c(a)=\sum_{\theta\in\Theta}\mu_\theta h_\theta(a).\)

Let \(D\) be the product of the denominators of all payoff-table entries, and let \(E\) be the product of the denominators of all masses and of \(B\), using the usual binary numerator-denominator encoding.

Then \(Dh_\theta(a)\) and \(E\mu_\theta\) are positive integers. Consequently,

\(\displaystyle DEc(a)=\sum_\theta(E\mu_\theta)(Dh_\theta(a))\)

is a positive integer, giving \(c(a)\ge 1/(DE)\).

Any plan within budget therefore satisfies

\(\displaystyle \frac{\ell}{DE}\le\mathcal H_\mu(S)\le B,\qquad\text{so}\qquad \ell\le BDE.\)

The integers \(D,E\), and the rational \(B\), have \(O(L)\) bits. Thus \(BDE\le2^{O(L)}\), and every action multiplicity has \(O(L)\) bits. If \(B=0\), no nonempty plan can satisfy the budget.

Certificate and verification

A certificate consists of distinct non-goal actions \(b_1,\ldots,b_k\), where \(1\le k\le m-1\), and positive binary-encoded multiplicities \(n_1,\ldots,n_k\). It represents the prefix consisting of \(n_1\) copies of \(b_1\), followed by \(n_2\) copies of \(b_2\), and so on.

The verifier starts with \(H_\theta=0\). For each block \(j\), it checks

\(\displaystyle H_\theta>t_\theta(b_j)\quad\text{for every }\theta,\)

and then updates \(H_\theta\leftarrow H_\theta+n_jh_\theta(b_j)\).

Checking the first occurrence suffices for the entire block because all hazing increments are positive. Finally, the verifier checks

\(\displaystyle H_\theta>\Delta_\theta\quad\text{for every }\theta,\qquad \sum_\theta\mu_\theta H_\theta\le B.\)

All comparisons are exact rational comparisons. The block lemma proves certificate completeness; the block checks prove soundness.

The certificate uses \(O(mL)\) bits. Using common denominators and elementary integer arithmetic, verification takes at most \(O(m\tau L^3)\) bit operations, a conservative polynomial bound. Hence the problem belongs to \(\mathrm{NP}\).

3. Conclusion and running-time consequence

The direct reduction and polynomial certificate establish \(\mathrm{NP}\)-completeness. Divisible society masses do not remove the hardness caused by discrete action occurrences in a common plan.

For completeness, enumerating all block orders and all multiplicities bounded by \(\lfloor BDE\rfloor\) gives a deterministic decision algorithm with running time \(2^{O(mL)}\operatorname{poly}(m,\tau,L)\).
