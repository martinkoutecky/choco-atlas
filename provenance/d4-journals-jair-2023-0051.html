The continuous mirror question, as graded

Given a finite type set \(\Theta\), finite resource-class set \(\mathcal R\), rational society distribution \(\mu\), integral initial bundle \(B_\theta\) and additive utility vector \(u_\theta\) for each type, fixed \(b\ge2\), and threshold \(k\), with per-capita resource supply \(q_r=\sum_{\theta\in\Theta}\mu_\theta b_{\theta r}\), decide whether there is a measurable mass assignment to integral local sharing configurations such that every individual retains its initial bundle, participates in at most \(b\) sharings, each resource token is shared with at most one recipient, any two types may share, and final utility is at least \(k\) for \(\mu\)-almost every agent; equivalently, maximize the essential minimum final utility.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types \(\Theta\) with positive masses \(\mu_\theta\) encoded as binary rationals, with \(\sum_\theta\mu_\theta=1\). Each type represents an atomless population; \(\tau\) is the support size, not the number of possible types.
There are \(m=|\mathcal R|\) resource classes. Each type has an initial bundle \(B_\theta=(b_{\theta r})_{r\in\mathcal R}\in\mathbb N_0^m\) of distinct tokens and additive utilities \(u_{\theta r}\in\mathbb N_0\). Bundle counts, utilities, and threshold \(k\in\mathbb N_0\) are binary encoded; \(L\) is the total input bit length. Fix an integer \(b\ge2\).
A sharing gives one initially owned token to one other individual's access, while its owner retains access; both obtain their full utility. Tokens cannot be shared again or relayed. Any distinct individuals may share, including individuals of the same type. Each individual may give and receive at most \(b\) tokens in total; multiple tokens shared with one partner count separately. There are no sharing costs.
An integral local configuration \(C=(D,I)\) for type \(\theta\) specifies nonnegative integer counts \(D_{\phi r}\) of owned class-\(r\) tokens shared to type \(\phi\), and \(I_{\phi r}\) of class-\(r\) tokens received from owners of type \(\phi\), with \(\sum_\phi D_{\phi r}\le b_{\theta r}\) and \(\sum_{\phi,r}(D_{\phi r}+I_{\phi r})\le b\). Its final utility is \(U_\theta(C)=\sum_r u_{\theta r}(b_{\theta r}+\sum_\phi I_{\phi r})\).
A mass assignment consists of nonnegative real masses \(x_{\theta C}\) on these implicitly defined configurations, satisfying \(\sum_C x_{\theta C}=\mu_\theta\) and, for every \(\theta,\phi,r\), \(\sum_C x_{\theta C}D_{\phi r}(C)=\sum_C x_{\phi C}I_{\theta r}(C)\). These equalities match outgoing and incoming sharing incidences; all tokens are initially owned, with per-capita supply \(q_r=\sum_\theta\mu_\theta b_{\theta r}\). Feasibility requires \(U_\theta(C)\ge k\) whenever \(x_{\theta C}>0\), so the bound holds almost everywhere, rather than merely in expectation.

For each fixed \(b\ge2\), is deciding whether such a feasible mass assignment exists solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

The finite-agent counterpart is NP-hard for every fixed \(b\ge2\), even with unrestricted pairwise sharing; with \(b=1\), it is polynomial-time solvable by matching. [Source](https://www.jair.org/index.php/jair/article/download/15001/26992/37188).
No result settling this exact atomless, integral-local-configuration problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the society distribution to total mass one and interpreted each positive-mass type as an atomless population.
  • Specified nonnegative integer utilities and a nonnegative integer threshold, following the discrete domains; encoded these and integral bundle multiplicities in binary.
  • Interpreted resource classes as collections of distinct tokens with identical utility within each class, rather than treating repeated copies as a single resource.
  • Specified that the participation bound counts tokens both given and received, including multiple tokens shared with the same partner.
  • Made explicit full utility for owners and recipients, no sharing costs, and the prohibition on relaying received tokens.
  • Allowed sharing between distinct individuals of the same type, while excluding sharing with oneself.
  • Defined mass feasibility through owner-type, recipient-type, and resource-class incidence balance, with arbitrary nonnegative real configuration masses and an almost-everywhere utility requirement.

Result

For every fixed \(b\ge 2\), the decision problem is solvable in time polynomial in \(m,\tau,L\).

The proof enumerates all integral local configurations and then solves an exact rational linear feasibility problem. The number of configurations is polynomial because \(b\) is fixed.

1. Enumerating the local configurations

For a fixed type \(\theta\), a configuration has \(2\tau m\) nonnegative integer coordinates: the outgoing counts \(D_{\phi r}\) and incoming counts \(I_{\phi r}\). Their total is at most \(b\).

Let \(d=2\tau m\). The number of nonnegative integer vectors with \(d\) coordinates and coordinate sum at most \(b\) is

\(\displaystyle \binom{d+b}{b}.\)

Indeed, adjoining a slack coordinate equal to \(b\) minus the coordinate sum gives a bijection with the nonnegative integer vectors having \(d+1\) coordinates and sum exactly \(b\); stars and bars gives the stated count. This also covers \(d=0\), when there is one empty vector.

For fixed \(b\), this count is polynomial in \(m,\tau\). An explicit enumeration procedure lists all multisets of size \(b\) over the \(d\) coordinate labels and one slack label. The multiplicity of each coordinate label gives its count.

For each type \(\theta\), retain precisely the candidates satisfying both:

  • Ownership: \(\sum_{\phi\in\Theta}D_{\phi r}\le b_{\theta r}\) for every \(r\in\mathcal R\).
  • Utility: \(\displaystyle \sum_{r\in\mathcal R}u_{\theta r}\left(b_{\theta r}+\sum_{\phi\in\Theta}I_{\phi r}\right)\ge k.\)

Denote the resulting set by \(\mathcal C_\theta\). By construction, it contains exactly the integral local configurations that obey the incidence bound, the ownership restrictions, and the required utility threshold.

Consequently, the total number of retained configurations satisfies

\(\displaystyle N:=\sum_{\theta\in\Theta}|\mathcal C_\theta|\le \tau\binom{2\tau m+b}{b}.\)

No enumeration up to the numerical values of the bundle counts or utilities is needed.

2. The explicit linear program

Introduce a nonnegative real variable \(x_{\theta C}\) for every \(\theta\in\Theta\) and \(C\in\mathcal C_\theta\). Impose the type-mass equations

\(\displaystyle \sum_{C\in\mathcal C_\theta}x_{\theta C}=\mu_\theta \qquad(\theta\in\Theta),\)

and the incidence-balance equations

\(\displaystyle \sum_{C\in\mathcal C_\theta}x_{\theta C}D_{\phi r}(C)=\sum_{C\in\mathcal C_\phi}x_{\phi C}I_{\theta r}(C)\qquad(\theta,\phi\in\Theta,\ r\in\mathcal R).\)

There are \(N\) variables and \(\tau+\tau^2m\) equations, together with nonnegativity constraints. If some \(\mathcal C_\theta\) is empty, its mass equation is impossible because \(\mu_\theta>0\), so the algorithm may immediately reject.

Equivalence. Suppose first that the original instance has a feasible mass assignment. Every configuration receiving positive mass satisfies the ownership restrictions, incidence bound, and utility threshold; hence it belongs to \(\mathcal C_\theta\). Restricting the assignment to the retained configurations therefore satisfies the displayed linear program.

Conversely, suppose the linear program has a feasible solution. Assign its values to the retained configurations and assign zero mass to every other configuration. The displayed equations are exactly the required mass and incidence-balance equations. Every configuration assigned positive mass belongs to \(\mathcal C_\theta\), so its utility is at least \(k\). Thus this is a feasible mass assignment in the sense of the question.

In particular, the utility guarantee holds configuration by configuration. The linear program does not replace it with an expected-utility constraint.

The per-capita token supply also requires no additional constraint. For each resource class \(r\), the total outgoing incidence mass satisfies

\(\displaystyle \sum_{\theta\in\Theta}\sum_{C\in\mathcal C_\theta}x_{\theta C}\sum_{\phi\in\Theta}D_{\phi r}(C)\le \sum_{\theta\in\Theta}\mu_\theta b_{\theta r}=q_r.\)

This follows from the ownership restriction in each retained configuration and the type-mass equations. Summing the balance equations shows that the total incoming incidence mass equals this outgoing mass.

3. Bit complexity and exact feasibility

Configuration enumeration and filtering take polynomial time for fixed \(b\). Each coordinate is at most \(b\). Ownership checks compare such small counts against binary-encoded bundle counts.

Utility checks use exact integer arithmetic. Each product \(u_{\theta r}b_{\theta r}\) has bit length at most the sum of the bit lengths of its factors. Summing over the resource classes adds at most a logarithmic number of bits. The incoming utility contribution contains at most \(b\) incidences. Thus every utility check uses numbers of bit length polynomial in the input length, even when the numerical bundle counts and utilities are large.

All linear-program coefficients are integers of absolute value at most \(b\), apart from the rational right-hand sides \(\mu_\theta\). To check the coefficient bound explicitly, in the balance row indexed by \((\theta,\phi,r)\), the coefficient of \(x_{\gamma C}\) is

\(\displaystyle \mathbf 1_{\gamma=\theta}D_{\phi r}(C)-\mathbf 1_{\gamma=\phi}I_{\theta r}(C).\)

For \(\theta=\phi=\gamma\), this becomes \(D_{\theta r}(C)-I_{\theta r}(C)\), which still has absolute value at most \(b\). Thus same-type sharing is included without changing the size bound.

The matrix dimensions and its total rational encoding length are consequently polynomial in \(m,\tau,L\) for fixed \(b\).

We now apply the standard polynomial-time theorem for rational linear programming: feasibility of a finite system of non-strict linear inequalities with rational coefficients can be decided in time polynomial in its total binary encoding length. Equalities are replaced by pairs of inequalities. The theorem decides feasibility over the reals and applies also to systems whose feasible set has empty interior. See [Khachiyan, “Polynomial algorithms in linear programming”](https://doi.org/10.1016/0041-5553(80)90061-0).

All its hypotheses hold here: the system is explicit, finite, rational, and of polynomial encoding length. Solving it therefore decides the original problem in polynomial time.

4. Scope of the conclusion

The argument preserves the integrality of every individual's local configuration. Only the masses assigned to configurations are real-valued, exactly as the problem specifies.

For a finite population, assigning integral numbers of individuals to configurations would impose additional integrality restrictions on those masses. The present linear program permits an atomless type population to split among configurations. Therefore the polynomial-time result does not imply a polynomial-time algorithm for the stated finite-agent counterpart.

The same proof works for every fixed nonnegative incidence bound; the requested cases \(b\ge 2\) are fully settled.
