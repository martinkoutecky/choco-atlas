The continuous mirror question, as graded

Given rational type masses \(\mu_t\), finitely many states, rational piecewise-linear worth functions \(V_s(q)\) for coalition masses \(q\in[0,\mu]\), and type-specific increasing state-separable utilities, find a state-contingent per-capita payoff schedule in the mass analogue of the Weak Sequential Core. Define that analogue by the paper's characterization: each state's allocation is in the full-population core, and no positive-mass coalition \(q\) can improve every participating type's utility using allocations in the cores of its restricted games in every state. Require each \(V_s\) to have increasing differences, meaning \(V_s(q+\delta)-V_s(q)\le V_s(r+\delta)-V_s(r)\) whenever \(q\le r\) and \(r+\delta\le\mu\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\ge1\) types with positive masses \(\mu_t\), each a binary rational; \(\tau\) is the support size, not the number of possible types. Write \(\mu=(\mu_t)_t\); total mass need not equal one. There are \(m\ge1\) states.
For each state, the input gives a continuous rational piecewise-linear worth function \(V_s:[0,\mu]\to\mathbb R\), with \(V_s(0)=0\), by an explicit rational polyhedral subdivision and affine formulas. Assume \(V_s(q+\delta)-V_s(q)\le V_s(r+\delta)-V_s(r)\) whenever \(0\le q\le r\), \(\delta\ge0\), and \(r+\delta\le\mu\), with vector inequalities interpreted coordinatewise.
Type \(t\) has utility \(u_t(z)=\sum_{s=1}^m u_{ts}(z_s)\), where each \(u_{ts}:\mathbb R\to\mathbb R\) is continuous, strictly increasing, and rational piecewise-linear, given by breakpoints and affine formulas. Worths and payoffs may be negative; state weights are absorbed into these utilities.
A coalition is any real mass vector \(0\ne q\in[0,\mu]\). Its state-\(s\) restricted core is \(C_s(q)=\{y\in\mathbb R^\tau:\sum_t q_ty_t=V_s(q),\ \sum_t r_ty_t\ge V_s(r)\text{ for every }0\le r\le q\}\); coordinates with \(q_t=0\) are irrelevant. Payoffs are per capita and constant within each participating type.
The mass Weak Sequential Core consists of schedules \(x=(x_{st})\) with \(x_s\in C_s(\mu)\) in every state, for which there is no coalition \(q\) and schedule \(y\) satisfying \(y_s\in C_s(q)\) in every state and \(u_t((y_{st})_s)>u_t((x_{st})_s)\) for every \(t\) with \(q_t>0\). Coalitions include the full society.
Exact search means finding such a schedule, represented by real algebraic coordinates, or reporting that none exists. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is the mass Weak Sequential Core necessarily nonempty under these assumptions? Is its exact search problem polynomial-time solvable in \(m,\tau,L\), or NP-hard?

For finite-player TU games with uncertainty, convexity of every state game guarantees a nonempty Weak Sequential Core for continuous increasing state-separable utilities. [Habis and Herings](https://cris.maastrichtuniversity.nl/ws/files/64776031/Herings_2011_transferable_utility_games_with_uncertainty.pdf)
No result settling this exact mass problem was identified in the literature search.

Modeling choices made when packaging the task

  • Masses are a positive rational vector with arbitrary finite total mass; no probability normalization is imposed.
  • Worth functions are continuous, normalized to zero at the empty coalition, and explicitly encoded by rational polyhedral subdivisions and affine formulas; signed worths are allowed.
  • The unspecified utility encoding is fixed to continuous rational piecewise-linear functions on the whole real line. Increasing means strictly increasing, consistent with the strict-improvement interpretation used in the discrete characterization.
  • Schedules and deviations assign one per-capita payoff per type and state; restricted-core inequalities apply to every real subcoalition mass vector.
  • Blocking requires strict utility improvement for every positive-mass participating type and permits the full society to deviate.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The mass Weak Sequential Core is necessarily nonempty, and exact search is polynomial-time solvable. In fact, a suitable schedule has rational coordinates and can be computed using only \(m\tau\) worth-function evaluations.

The construction adapts the common-order marginal allocation in Theorem 5.3 of [Habis and Herings](https://cris.maastrichtuniversity.nl/ws/files/64776031/Herings_2011_transferable_utility_games_with_uncertainty.pdf). The additional argument needed for real mass coalitions is an average-marginal bound, proved below.

1. An average-marginal bound

Fix a state and write its worth function as \(V\). Let \(e_t\) be the unit vector for type \(t\).

Lemma. Suppose \(0\le a\le b\), \(0<h\le H\), and \(b+He_t\le\mu\). Then

\( \displaystyle \frac{V(a+he_t)-V(a)}{h} \le \frac{V(b+He_t)-V(b)}{H}. \)

Proof. First, the assumed increasing-marginal-worth condition, applied with increment \(he_t\), gives

\( V(a+he_t)-V(a)\le V(b+he_t)-V(b). \)

It remains to compare average increments of different lengths at the same base \(b\).

Define \(f(z)=V(b+ze_t)\) for \(0\le z\le H\). For any \(0\le\alpha<\gamma\le H\), put \(d=(\gamma-\alpha)/2\). Applying the assumption at the ordered base vectors \(b+\alpha e_t\) and \(b+(\alpha+d)e_t\), with increment \(de_t\), yields

\( f(\alpha+d)-f(\alpha)\le f(\gamma)-f(\alpha+d). \)

Consequently,

\( \displaystyle f\!\left(\frac{\alpha+\gamma}{2}\right) \le \frac{f(\alpha)+f(\gamma)}2. \)

Thus \(f\) is midpoint convex. Iterating this inequality proves the convexity inequality for dyadic interpolation parameters; continuity of \(f\) extends it to every interpolation parameter. In particular,

\( \displaystyle f(h)\le \left(1-\frac hH\right)f(0)+\frac hH f(H). \)

Rearranging gives

\( \displaystyle \frac{V(b+he_t)-V(b)}h \le \frac{V(b+He_t)-V(b)}H. \)

Combining the two inequalities proves the lemma. No sign restriction on the worths or increments was used.

2. Constructing a schedule in every state core

Fix any ordering of the support types, and label them \(1,\ldots,\tau\) in that order. Define the prefix mass vectors

\( P_0=0,\qquad P_i=\sum_{j=1}^{i}\mu_j e_j \quad (1\le i\le\tau). \)

Use this same order in every state. Define the per-capita schedule by

\( \displaystyle x_{si}=\frac{V_s(P_i)-V_s(P_{i-1})}{\mu_i} \quad (1\le s\le m,\ 1\le i\le\tau). \)

The divisions are valid because every listed type has positive mass.

Proposition. For every state \(s\), the vector \(x_s\) belongs to \(C_s(\mu)\).

Proof. Efficiency follows by telescoping:

\( \displaystyle \sum_{i=1}^{\tau}\mu_i x_{si} = \sum_{i=1}^{\tau}\bigl(V_s(P_i)-V_s(P_{i-1})\bigr) = V_s(\mu), \)

where \(V_s(0)=0\).

Now fix an arbitrary real vector \(r\) with \(0\le r\le\mu\). Define its prefixes by

\( R_0=0,\qquad R_i=\sum_{j=1}^{i}r_j e_j. \)

For an index \(i\) with \(r_i>0\), apply the lemma with

\( a=R_{i-1},\qquad b=P_{i-1},\qquad h=r_i,\qquad H=\mu_i. \)

Its hypotheses hold: \(R_{i-1}\le P_{i-1}\), \(r_i\le\mu_i\), and \(P_{i-1}+\mu_i e_i=P_i\le\mu\). Therefore,

\( V_s(R_i)-V_s(R_{i-1}) \le r_i\frac{V_s(P_i)-V_s(P_{i-1})}{\mu_i} = r_i x_{si}. \)

If \(r_i=0\), the same inequality holds because both sides are zero. Summing over all indices gives

\( \displaystyle V_s(r) = \sum_{i=1}^{\tau}\bigl(V_s(R_i)-V_s(R_{i-1})\bigr) \le \sum_{i=1}^{\tau}r_i x_{si}. \)

This proves every inequality required by \(C_s(\mu)\), including those for fractional mass vectors.

3. No real mass coalition blocks the schedule

Proposition. The constructed schedule belongs to the mass Weak Sequential Core.

Proof. Consider any nonzero coalition \(q\in[0,\mu]\) and any schedule \(y\) with \(y_s\in C_s(q)\) in every state. We show that at least one participating type cannot strictly improve.

Let

\( k=\max\{i:q_i>0\}, \qquad a=q-q_k e_k. \)

Because no type after \(k\) participates, \(a\le P_{k-1}\).

Fix a state \(s\). Coalition efficiency and the restricted-core inequality for the subcoalition \(a\le q\) give, respectively,

\( \displaystyle \sum_i q_i y_{si}=V_s(q), \qquad \sum_i a_i y_{si}\ge V_s(a). \)

Subtracting yields

\( q_k y_{sk}\le V_s(q)-V_s(a). \)

Apply the lemma with base vectors \(a,P_{k-1}\) and lengths \(q_k,\mu_k\). Since \(q=a+q_k e_k\), it follows that

\( \displaystyle y_{sk} \le \frac{V_s(a+q_k e_k)-V_s(a)}{q_k} \le \frac{V_s(P_k)-V_s(P_{k-1})}{\mu_k} = x_{sk}. \)

This inequality holds in every state, for the same participating type \(k\). Since each \(u_{ks}\) is increasing,

\( \displaystyle u_k((y_{sk})_{s=1}^{m}) = \sum_{s=1}^{m}u_{ks}(y_{sk}) \le \sum_{s=1}^{m}u_{ks}(x_{sk}) = u_k((x_{sk})_{s=1}^{m}). \)

Thus type \(k\) does not strictly improve. The coalition cannot block.

The argument applies to every real mass coalition, including the full society. Together with state-core feasibility, it establishes the proposition.

4. Exact search and running time

The algorithm is:

  • Order the \(\tau\) support types arbitrarily.
  • Form the prefix vectors \(P_0,\ldots,P_\tau\).
  • Evaluate \(V_s(P_i)\) for every state \(s\) and every \(1\le i\le\tau\); use the given value \(V_s(P_0)=0\).
  • Output \(x_{si}=(V_s(P_i)-V_s(P_{i-1}))/\mu_i\).

Each prefix is rational. A continuous rational piecewise-linear function given by an explicit polyhedral subdivision can be evaluated at a rational point by finding a containing cell and evaluating its affine formula. On a shared boundary, continuity ensures that the incident formulas agree.

For cells described by rational inequalities, scanning the explicit descriptions uses polynomially many exact rational operations. If cells are given by rational vertex descriptions instead, membership can be tested by rational linear programming: the point must be a convex combination of the listed vertices. These membership problems also have size polynomial in \(L\).

The rational values \(V_s(P_i)\), and hence the output coordinates, have bit lengths polynomial in \(L\): each evaluation substitutes input rational masses into an input rational affine formula, and the construction then uses subtraction and division by an input positive rational.

Consequently, the running time is

\( O\!\left(m\tau\,\operatorname{poly}(L)\right) \)

bit operations, with polynomial output length. Rational coordinates are already a permitted special case of real algebraic coordinates.

The algorithm always returns a valid schedule, so on the promised input class the “none exists” outcome is unnecessary. This settles both nonemptiness and polynomial-time exact search.
