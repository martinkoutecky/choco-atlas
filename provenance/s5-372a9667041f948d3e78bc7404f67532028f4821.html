The continuous mirror question, as graded

Given a finite type set \(T\), rational type masses \(\mu_t\) summing to \(1\), a compatibility relation \(E\), and unit surplus for compatible pairs, define the fluid matching value \(\nu(s)\) for any subpopulation \(s\) by maximizing partnership mass subject to each type's capacity. Does there exist a measurable nonnegative payoff function \(u\) on the nonatomic population, with \(\int u=\nu(\mu)\), such that the measure of compatible unordered pairs whose payoffs sum to less than \(1\) is at most a given rational threshold \(q\)? Count cross-type pairs with product measure and same-type unordered pairs with half the product measure.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types. Let \(T=\{1,\ldots,\tau\}\), with \(\sum_t\mu_t=1\).
Compatibility is specified by \(E\subseteq\{(t,t'):t\leq t'\}\); \((t,t)\in E\) permits partnerships between distinct individuals of type \(t\). Every compatible partnership has unit surplus. Write \(m=|E|\) and let \(L\) be the total binary input length, including the rational threshold \(q\geq0\).
For \(0\leq s_t\leq\mu_t\), define \(\nu(s)=\max\{\sum_{e\in E}y_e:y_e\geq0,\ \sum_{e\in E}a_{te}y_e\leq s_t\text{ for every }t\}\), where \(a_{te}\) counts occurrences of \(t\) among the two endpoints of \(e\), so a same-type partnership consumes twice its partnership mass.
Realize the population as disjoint intervals \(\Omega_t\) of lengths \(\mu_t\), with Lebesgue measure \(\lambda\), and put \(\Omega=\bigcup_t\Omega_t\). An imputation is any measurable integrable \(u:\Omega\to\mathbb R_{\geq0}\) with \(\int_\Omega u\,d\lambda=\nu(\mu)\); it may vary within each type.
Its blocking-pair measure is \(B(u)=\sum_{(t,t')\in E}c_{tt'}\int_{\Omega_t\times\Omega_{t'}}\mathbf1_{\{u(x)+u(y)<1\}}\,d(\lambda\otimes\lambda)\), where \(c_{tt'}=1\) for \(t<t'\) and \(c_{tt}=\tfrac12\). Individual self-pairs have measure zero.
The decision problem asks whether an imputation satisfying \(B(u)\leq q\) exists.

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite simple graphs with unit edge weights, deciding whether a nonnegative allocation of the maximum matching value has at most \(k\) blocking edges is NP-complete ([source](https://doi.org/10.1007/s00182-011-0273-y)).
No published complexity classification for the exact nonatomic decision problem above was located.

Modeling choices made when packaging the task

  • Specified compatibility as unordered type pairs, allowing same-type compatibility between distinct individuals, as required by the graded question's same-type pair measure.
  • Made fluid matching explicit: partnership masses are nonnegative real numbers, unmatched mass is allowed, and same-type partnerships consume twice their partnership mass.
  • Realized the nonatomic population using Lebesgue intervals and allowed arbitrary measurable integrable payoffs within each type.
  • Restricted the previously unspecified threshold to nonnegative binary rationals, following the discrete decision problem's threshold domain.
  • Defined m as the number of compatible type pairs and L as the total binary input length.

Conclusion

The decision problem is polynomial-time solvable: every valid instance has answer YES. In fact, every society in the question admits an imputation with blocking-pair measure \(0\).

This follows directly from the LP definition of the available surplus. It is a structural property of the stated model, rather than a degenerate special case.

Proof

Let \(A=(a_{te})\) be the endpoint-incidence matrix. The LP defining the grand-coalition surplus is

\(\displaystyle \nu(\mu)=\max\left\{\sum_{e\in E}y_e:Ay\leq\mu,\ y\geq0\right\}.\)

It is feasible because \(y=0\) is feasible. Every column of \(A\) sums to \(2\), including columns for same-type partnerships. Consequently, every feasible \(y\) satisfies

\(\displaystyle 2\sum_{e\in E}y_e=\sum_{t\in T}(Ay)_t\leq\sum_{t\in T}\mu_t=1.\)

Thus the primal optimum is finite. Its dual is

\(\displaystyle \min\left\{\sum_{t\in T}\mu_t p_t:p_t\geq0,\ \sum_{t\in T}a_{te}p_t\geq1\text{ for every }e\in E\right\}.\)

For a cross-type edge \((t,t')\), the dual constraint is \(p_t+p_{t'}\geq1\). For a same-type edge \((t,t)\), it is \(2p_t\geq1\).

The dual is feasible: set \(p_t=\tfrac12\) for every \(t\). By finite-dimensional LP strong duality, since the primal is feasible and has finite optimum, there exists an optimal dual vector \(p^*\) satisfying

\(\displaystyle \sum_{t\in T}\mu_t p_t^*=\nu(\mu).\)

Define the allocation by \(u(x)=p_t^*\) whenever \(x\in\Omega_t\). This function is nonnegative, measurable, and integrable, and

\(\displaystyle \int_\Omega u\,d\lambda=\sum_{t\in T}\mu_t p_t^*=\nu(\mu).\)

Hence it is an imputation.

For every compatible cross-type pair, dual feasibility gives

\(\displaystyle u(x)+u(y)=p_t^*+p_{t'}^*\geq1.\)

For every compatible same-type pair, it gives

\(\displaystyle u(x)+u(y)=2p_t^*\geq1.\)

Therefore every indicator appearing in the definition of \(B(u)\) vanishes. In particular, equality at \(1\) does not block, because blocking requires a strict inequality. Thus \(B(u)=0\leq q\).

The argument also covers \(E=\varnothing\): both the surplus and the blocking-pair measure are zero.

Complexity and the finite-graph distinction

On inputs satisfying the stated promises, a decision algorithm simply returns YES. If an explicit imputation is desired, an optimal rational dual solution can be computed by rational linear programming in time polynomial in \(m,\tau,L\).

The finite-graph hardness does not transfer because the surplus here is a fractional matching optimum. For example, with three types of mass \(\tfrac13\), all three cross-type edges, and no loops, assigning partnership mass \(\tfrac16\) to each edge achieves \(\nu(\mu)=\tfrac12\). The allocation \(u\equiv\tfrac12\) spends exactly this surplus and blocks no pair. By comparison, an ordinary three-vertex triangle has integral maximum matching size \(1\), while its fractional maximum matching value is \(\tfrac32\). That difference in the available budget is decisive.
