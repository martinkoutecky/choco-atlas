The continuous mirror question, as graded

Given a finite metric support \(X\), finite candidate set \(F\), integer \(k\), and rational public location masses \(\lambda_x\), compute a set \(A\subseteq F\) with \(|A|=k\). For every hidden distribution \(\mu\) on \(X\times\{M,S\}\) satisfying \(\mu_{x,M}+\mu_{x,S}=\lambda_x\), let \(r=\sum_x\mu_{x,M}\), \(c_M(x,A)=\max_{a\in A}d(x,a)\), \(c_S(x,A)=\frac{1}{k}\sum_{a\in A}d(x,a)\), and \(\mathrm{SC}_{\mu}(A)=\sum_{x,\theta}\mu_{x,\theta}c_\theta(x,A)\). Find a deterministic rule using only \(\lambda\) such that \(\mathrm{SC}_{\mu}(A)\leq (3-\frac{4}{k}+\frac{2r}{k})\min_{B\in{F\choose k}}\mathrm{SC}_{\mu}(B)\) for every compatible \(\mu\).

Packaged proof task (what the prover saw — nothing else)

Given nonempty finite location support \(X\), a finite candidate set \(F\) with \(m=|F|\), an explicitly tabulated binary-rational metric \(d\) on \(X\cup F\), and an integer \(2\leq k\leq m\), choose \(A\subseteq F\) with \(|A|=k\).
Public location masses satisfy \(\lambda_x\in\mathbb{Q}_{>0}\) and \(\sum_{x\in X}\lambda_x=1\). A compatible hidden society is any nonnegative real distribution \(\mu\) on \(X\times\{M,S\}\) with \(\mu_{x,M}+\mu_{x,S}=\lambda_x\); write \(r(\mu)=\sum_x\mu_{x,M}\).
A society is represented by its support: the list of its \(\tau\) positive-mass types, each with a binary-rational mass; \(\tau\) counts supported types, not possible types. Here that society is hidden: only its location marginal is supplied, with \(s=|X|\) and hidden support size \(\tau\leq2s\). The guarantee also covers real hidden masses.
Define \(c_M(x,A)=\max_{a\in A}d(x,a)\), \(c_S(x,A)=\frac1k\sum_{a\in A}d(x,a)\), and \(\mathrm{SC}_{\mu}(A)=\sum_{x\in X,\theta\in\{M,S\}}\mu_{x,\theta}c_\theta(x,A)\).
The required guarantee is \(\mathrm{SC}_{\mu}(A)\leq\left(3-\frac4k+\frac{2r(\mu)}k\right)\min_{B\subseteq F,\,|B|=k}\mathrm{SC}_{\mu}(B)\) simultaneously for every compatible \(\mu\). The rule receives only \((X,F,d,k,\lambda)\); neither \(\mu\) nor \(r(\mu)\) is supplied. Let \(L\) be the total binary input length.

Is this approximation guarantee achievable by a deterministic rule running in time polynomial in \(m,s,\tau,k,L\)?

For discrete societies, a deterministic rule using public locations alone achieves the factor \(3-\frac4k+\frac{2|M|}{kn}\), where \(n\) is the number of agents and \(M\) the max-type agents. [Source](https://arxiv.org/html/2606.26074v1#Thmtheorem2.2)

Result and deterministic rule

Yes. The guarantee is achievable in time polynomial in \(m,s,k,L\), independently of the hidden support size \(\tau\).

For every candidate \(a\in F\), compute its public weighted score
\(w(a)=\sum_{x\in X}\lambda_x d(x,a)\).
Return the \(k\) candidates with smallest scores, breaking ties by their order in the input. Denote this committee by \(A\).

The proof uses the supplied discrete theorem, rational replication, and continuity. Replication is only a proof device.

1. The rule minimizes the public all-sum objective

For any committee \(B\), define
\(Q_\lambda(B)=\sum_{x\in X}\lambda_x c_S(x,B)\).
Interchanging the finite sums gives
\(Q_\lambda(B)=\frac1k\sum_{b\in B}w(b)\).

Consequently, choosing the \(k\) smallest scores minimizes \(Q_\lambda\) over all committees of size \(k\).

The cited [Theorem 2.2](https://arxiv.org/html/2606.26074v1#Thmtheorem2.2) states precisely that an all-sum optimal committee satisfies the discrete mixed-cost bound with factor \(3-\frac4k+\frac{2|M|}{kn}\). Its formulation applies to any all-sum optimum. Agents may share locations; the paper explicitly allows this in its examples.

2. Guarantee for rational hidden masses

Fix an arbitrary compatible society whose masses are rational. Choose a positive integer \(N\) such that every \(N\mu_{x,\theta}\) is an integer.

Construct a discrete society with \(N\mu_{x,M}\) max-type agents and \(N\mu_{x,S}\) sum-type agents at each location \(x\). Its total population is
\(n=\sum_{x,\theta}N\mu_{x,\theta}=N\).
Its public location counts are \(N\lambda_x\), and its max-type fraction is
\(|M|/n=\sum_x\mu_{x,M}=r(\mu)\).

The metric remains the given metric on locations: replicated agents are labels assigned to those locations. For every committee \(B\), its discrete mixed social cost is exactly \(N\mathrm{SC}_\mu(B)\), and its discrete all-sum social cost is exactly \(NQ_\lambda(B)\).

By Section 1, our fixed committee \(A\) is all-sum optimal for this discrete society. All hypotheses of the supplied discrete theorem therefore hold: a finite population with public locations, max or normalized sum costs, the given metric, and a committee of size \(k\). Applying that theorem and cancelling \(N\) yields

\(\mathrm{SC}_\mu(A)\leq\left(3-\frac4k+\frac{2r(\mu)}k\right)\min_{|B|=k}\mathrm{SC}_\mu(B)\).

This proves the guarantee for every rational compatible society. The committee \(A\) depends only on the public scores, so it is the same committee throughout these applications.

3. Extension to real hidden masses

Now fix an arbitrary compatible society with real masses. Write \(h_x=\mu_{x,M}\), so \(0\leq h_x\leq\lambda_x\) and \(\mu_{x,S}=\lambda_x-h_x\).

Choose a positive integer \(D\) with \(D\lambda_x\) integral for every \(x\). For every positive integer \(t\), define
\(h_x^{(t)}=\frac{\lfloor Dt h_x\rfloor}{Dt}\),
and let
\(\mu_{x,M}^{(t)}=h_x^{(t)}\),
\(\mu_{x,S}^{(t)}=\lambda_x-h_x^{(t)}\).

These masses are rational, nonnegative, and have exactly the required marginal. Moreover,
\(0\leq h_x-h_x^{(t)}<1/(Dt)\),
so they converge coordinatewise to \(\mu\).

For any fixed committee \(B\),

\(\mathrm{SC}_\mu(B)=Q_\lambda(B)+\sum_x h_x\bigl(c_M(x,B)-c_S(x,B)\bigr)\).

Thus committee costs and \(r(\mu)=\sum_xh_x\) are continuous functions of the hidden masses.

Set \(\beta(u)=3-\frac4k+\frac{2u}k\). Since \(k\geq2\) and \(u\in[0,1]\), we have \(\beta(u)\geq1\). Section 2 consequently implies, for every fixed committee \(B\),

\(\mathrm{SC}_{\mu^{(t)}}(A)\leq\beta(r(\mu^{(t)}))\mathrm{SC}_{\mu^{(t)}}(B)\).

Taking limits gives
\(\mathrm{SC}_\mu(A)\leq\beta(r(\mu))\mathrm{SC}_\mu(B)\).
This holds for every committee \(B\). Because there are finitely many such committees, choosing a minimizer proves the required guarantee for \(\mu\).

The real society was arbitrary, establishing the simultaneous guarantee.

4. Binary running time

The algorithm computes \(ms\) rational products and their sums, then sorts \(m\) exact rational scores. Each score has polynomial binary length: a common denominator can be formed by multiplying the denominators occurring in its summands, whose total binary length is polynomial in \(L\). Exact arithmetic and comparisons therefore take polynomial time.

The algorithm neither constructs the replicated society nor computes the limiting sequence. It reads no hidden masses, \(r(\mu)\), or \(\tau\). Its running time is polynomial in \(m,s,k,L\), hence also polynomial in the parameters requested.
