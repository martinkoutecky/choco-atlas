The continuous mirror question, as graded

Given \(M\) with \(|M|=m\), fixed \(k,t\), and an explicitly listed rational distribution \(\mu=(\mu_A)_{A\subseteq M}\) over approval-set types, output \(W\in\binom{M}{k}\) such that for every \(\ell\in\{1,\ldots,m\}\), \(\sum_{A:\,|A|\ge\ell,\ |A\cap W|<t}\mu_A\le H(m,\ell,k;t-1)\); equivalently, compute the mass version of Algorithm 1 and certify its FVR envelope.

Packaged proof task (what the prover saw — nothing else)

Let \(M\) be an explicitly listed candidate set with \(|M|=m\), and fix integers \(1\le t\le k<m\). A type is an approval set \(A\subseteq M\); empty and full approval sets are allowed.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational, with \(\sum_A\mu_A=1\). Here \(\tau\) is the support size, not the number of possible approval sets. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\), with their dependence on the fixed parameters \(k,t\) explicit.
Write \(H(m,\ell,k;t-1)=\binom{m}{k}^{-1}\sum_{r=0}^{t-1}\binom{\ell}{r}\binom{m-\ell}{k-r}\), with binomial coefficients outside their valid ranges equal to zero.
The required output is a committee \(W\subseteq M\), \(|W|=k\), satisfying \(\sum_{A:\,|A|\ge\ell,\ |A\cap W|<t}\mu_A\le H(m,\ell,k;t-1)\) simultaneously for every integer \(1\le\ell\le m\). Any committee satisfying these inequalities is admissible.

Is this committee search problem solvable in polynomial time in \(m,\tau,L\) for every fixed \(k,t\), or is it NP-hard for some fixed \(k,t\)?

For explicitly listed finite voters, a polynomial-time sequential rule attains this envelope simultaneously at every approval-size threshold for each fixed \(k,t\). [Halpern, Procaccia, and Suksompong](https://arxiv.org/html/2505.01395v1).
No result treating exactly the rational support-mass search problem was identified in the literature search.

  • Made normalization explicit: listed masses are positive binary rationals summing to one; unlisted types have zero mass.
  • Retained arbitrary approval subsets, including empty and full approval sets.
  • Defined H explicitly and fixed the convention for out-of-range binomial coefficients.
  • Interpreted the required output as any committee satisfying the stated envelope, rather than a prescribed sequential algorithm's output; no tie-breaking is therefore required.

Result

The search problem is polynomial-time solvable for every fixed \(k,t\). In fact, the algorithm below is polynomial even when \(k,t\) are part of the input.

The cited paper uses conditional expectations for its sequential rule. The following argument proves the rational-mass extension directly and bounds its exact-arithmetic cost. [Halpern, Procaccia, and Suksompong, Section 3.3](https://arxiv.org/html/2505.01395v1#S3.SS3).

1. A score that implies all threshold inequalities

Index the supported types by \(i=1,\ldots,\tau\), with approval sets \(A_i\), sizes \(a_i=|A_i|\), and masses \(\mu_i\). Define

\(C_0=\binom{m}{k},\qquad N(a)=\sum_{r=0}^{t-1}\binom{a}{r}\binom{m-a}{k-r},\qquad q(a)=N(a)/C_0.\)

For any approval set of size \(a\), exactly \(N(a)\) committees contain fewer than \(t\) approved candidates: the summand counts committees containing exactly \(r\) approved candidates. Consequently, \(q(a)\) is its failure probability under a uniformly random committee.

The function \(q\) is nonincreasing. Indeed, for \(a\le b\), choose nested approval sets \(B_a\subseteq B_b\) of those sizes. For every committee \(W\), the inequality \(|B_b\cap W|<t\) implies \(|B_a\cap W|<t\). Taking probabilities proves \(q(b)\le q(a)\).

Let \(I=\{i:q(a_i)>0\}\), and define the weighted failure score

\(F(W)=\sum_{i\in I}\frac{\mu_i}{q(a_i)}\,\mathbf{1}[|A_i\cap W|<t].\)

For a uniformly random committee \(W\), linearity of expectation gives

\(\mathbb{E}[F(W)]=\sum_{i\in I}\frac{\mu_i}{q(a_i)}q(a_i)=\sum_{i\in I}\mu_i\le 1.\)

Claim. Every committee satisfying \(F(W)\le 1\) is admissible.

Proof. Fix a threshold \(\ell\).

If \(q(\ell)=0\), every approval set of size at least \(\ell\) has failure probability zero, by monotonicity. Since every committee has positive probability under the uniform distribution, none of these sets can fail on any committee. The required left-hand side is therefore zero.

Suppose \(q(\ell)>0\). A failing supported type necessarily belongs to \(I\): otherwise no committee could fail that type. Moreover, when \(a_i\ge\ell\), monotonicity gives \(q(a_i)\le q(\ell)\), and hence

\(\mu_i=q(a_i)\frac{\mu_i}{q(a_i)}\le q(\ell)\frac{\mu_i}{q(a_i)}.\)

Summing over the failing types of size at least \(\ell\) yields

\(\sum_{i:\,a_i\ge\ell,\ |A_i\cap W|<t}\mu_i\le q(\ell)F(W)\le q(\ell)=H(m,\ell,k;t-1).\)

The same score condition proves the inequality for every \(\ell\), establishing the claim. \(\square\)

This argument includes empty and full approval sets. An empty set has \(q(0)=1\); a full set has \(q(m)=0\) and never fails because \(t\le k\).

2. Finding a suitable committee by conditional expectations

For a partial committee \(S\), with \(j=|S|\le k\), define

\(\Phi(S)=\mathbb{E}[F(W)\mid S\subseteq W],\)

where the completion is uniform among all committees containing \(S\).

For each supported type, write \(h_i=|A_i\cap S|\), \(b_i=|A_i\setminus S|\), \(n=m-j\), and \(d=k-j\). The number of completions that fail type \(i\) is

\(U_i(S)=\begin{cases}\displaystyle\sum_{r=0}^{t-1-h_i}\binom{b_i}{r}\binom{n-b_i}{d-r},&h_i<t,\\[4pt]0,&h_i\ge t.\end{cases}\)

This formula counts completions choosing exactly \(r\) approved candidates from the remaining candidates. Thus

\(\Phi(S)=\sum_{i\in I}\frac{\mu_i}{q(a_i)}\frac{U_i(S)}{\binom{n}{d}}.\)

When \(j<k\), these conditional expectations satisfy

\(\frac{1}{m-j}\sum_{x\in M\setminus S}\Phi(S\cup\{x\})=\Phi(S).\)

To verify the identity, each completion containing \(S\) appears in exactly \(d\) of the sums indexed by \(x\), one for each of its additional members. The normalization follows from

\(n\binom{n-1}{d-1}=d\binom{n}{d}.\)

Therefore some candidate \(x\) satisfies \(\Phi(S\cup\{x\})\le\Phi(S)\).

The algorithm starts with \(S=\varnothing\) and repeatedly adds a candidate minimizing \(\Phi(S\cup\{x\})\), breaking ties arbitrarily. After \(k\) steps, the resulting committee \(W\) satisfies

\(F(W)=\Phi(W)\le\Phi(\varnothing)=\mathbb{E}[F(W)]\le1.\)

Section 1 then proves its admissibility.

3. Exact arithmetic and running time

Write each input mass as \(\mu_i=p_i/d_i\), with positive integers \(p_i,d_i\). Their total encoding length is at most \(L\). For \(i\in I\), let \(N_i=N(a_i)>0\), and construct the common denominator

\(E=\prod_{i\in I}d_iN_i,\)

using \(E=1\) if \(I\) is empty. Define integer weights

\(v_i=\frac{p_iC_0E}{d_iN_i}.\)

These are integers because each \(d_iN_i\) divides \(E\), and they satisfy \(v_i/E=\mu_i/q(a_i)\). Consequently,

\(\Phi(S)=\frac{\sum_{i\in I}v_iU_i(S)}{E\binom{m-|S|}{k-|S|}}.\)

For all candidate extensions of a fixed \(S\), the denominator is identical. The algorithm can therefore select its next candidate by comparing the integer numerators \(\sum_{i\in I}v_iU_i(S\cup\{x\})\). No numerical approximation is needed.

Let

\(B=L+(\tau+2)k\lceil\log_2(m+1)\rceil+\lceil\log_2(\tau+1)\rceil+2.\)

All integers used have \(O(B)\) bits:

  • Since \(N_i\le C_0\le m^k\), the product \(E\) has at most \(O(L+\tau k\log(m+1))\) bits.
  • Since \(\mu_i\le1\) and \(N_i\ge1\), each weight satisfies \(v_i=E\mu_iC_0/N_i\le EC_0\).
  • Each completion count satisfies \(U_i(S)\le C_0\), so every comparison numerator is at most \(\tau EC_0^2\).

Precompute \(\binom{u}{r}\) for \(0\le u\le m\), \(0\le r\le k\), using Pascal’s recurrence in \(O(mk)\) integer additions. Store approval membership indicators and maintain the intersection counts with \(S\).

There are at most \(km\) candidate-extension evaluations. Each evaluation uses at most \(t\) summands for each of the \(\tau\) supported types. Using schoolbook integer arithmetic, including multiplication and exact division, gives the bit-operation bound

\(O\!\left(L+km\tau t\,B^2\right).\)

This also covers preprocessing and construction of the integer weights.

For fixed \(k,t\), the bound becomes

\(O_{k,t}\!\left(L+m\tau\bigl(L+\tau\log(m+1)\bigr)^2\right),\)

which is polynomial in \(m,\tau,L\). Moreover, because \(t\le k<m\), the displayed general bound is polynomial when the parameters vary as well.

Conclusion

The weighted score provides both existence and an exact polynomial-time construction for rational support masses. No expansion into individual voters is required, and all approval-size thresholds are satisfied simultaneously.

The treatment of zero probabilities is also correct: every committee has strictly positive uniform probability, so failure probability zero means no committee fails that approval set.
