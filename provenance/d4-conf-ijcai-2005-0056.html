Proposition 2 — class: algorithmic

The continuous mirror question, as graded

Given a finite support \(T\) with rational masses \(\mu_t\), and for each type \(t\) a feasible set \(F_t\) and uncertain GAI utility set \(U_t\), where members of that type share the same latent utility, determine the worst-case number of adaptive threshold queries needed to return recommendations \(x_t\in F_t\) such that \(\max_{(u_t)\in\prod_{t\in T}U_t}\sum_{t\in T}\mu_t[\max_{y\in F_t}u_t(y)-u_t(x_t)]\le\epsilon\). In particular, can query allocation using the masses improve on running HLG independently with per-type tolerances \(\epsilon_t\) satisfying \(\sum_t\mu_t\epsilon_t\le\epsilon\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). The parameter \(\tau\) is the support size, not the number of possible types.
There are \(m\) Boolean attributes. Each nonempty feasible set \(F_t\subseteq\{0,1\}^m\) is specified by a Boolean constraint formula. Type \(t\) has a GAI utility \(u_t(x)=\sum_{k=1}^{K_t}f_{tk}(x[S_{tk}])\), with explicitly listed factor tables and scopes \(S_{tk}\). Initially, every table entry lies independently in a finite interval \([a_{tkz},b_{tkz}]\) with signed binary-rational endpoints; these intervals define \(U_t\). Utilities use a common cardinal scale. Let \(n\) be the total number of table entries and \(L\) the total input bit length.
Each type has one fixed latent parameter vector shared by its entire mass; vectors of different types are independent. A unit-cost query selects a type, a table entry \(p\), and a rational threshold \(q\), and receives the truthful answer to \(p\le q\). Queries may depend on previous answers. Let \(U_t^h\) be the closure of the parameter vectors consistent with transcript \(h\).
For binary-rational \(\epsilon>0\), a deterministic strategy must terminate on every consistent answer sequence with one recommendation \(x_t\in F_t\) per type satisfying \(\max_{(u_t)\in\prod_tU_t^h}\sum_t\mu_t[\max_{y\in F_t}u_t(y)-u_t(x_t)]\le\epsilon\). Let \(Q^*\) be the minimum possible worst-case total number of queries. The decision input additionally contains a binary-encoded integer \(B\ge0\).
The independent HLG baseline fixes positive tolerances \(\epsilon_t\) with \(\sum_t\mu_t\epsilon_t\le\epsilon\), then separately queries each type's widest parameter interval at its midpoint until that type admits a recommendation of maximum regret at most \(\epsilon_t\). Optimize this baseline over the tolerances; fix arbitrary deterministic tie-breaking.
Is deciding whether \(Q^*\le B\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? Can mass-aware adaptive strategies improve the optimized independent HLG baseline's worst-case query count? State running times in \(m,\tau,n,L\) and the budget encoding length.
For one decision maker with \(n_0\) parameters, HLG guarantees regret at most \(\epsilon\) after \(n_0\lceil\log_2(M/\epsilon)\rceil\) queries when \(M>\epsilon\), where \(M=\sum_k\max_z(b_{kz}-a_{kz})\); this is a query bound, not a polynomial-time planning theorem. [Verified source](https://www.cs.toronto.edu/~cebly/Papers/BPPS-aij06.pdf).
No result settling this exact mass-weighted adaptive query-budget problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized positive masses to sum to one because the continuous society is a distribution.
  • Specified Boolean attributes, nonempty feasible sets represented by Boolean formulas, and explicitly listed GAI factor tables, following the discrete constraint-based model.
  • Restricted initial utility uncertainty to independent finite parameter intervals with rational endpoints, matching the HLG setting; allowed signed utilities and fixed a common cardinal scale across types.
  • Made latent utilities fixed throughout elicitation, charged one query independently of type mass, and required a single deterministic recommendation for each type.
  • Allowed adaptive rational thresholds with truthful answers to the weak comparison p <= q; used closures of transcript-consistent parameter sets so the displayed maximum exists and equals the corresponding supremum over strictly consistent vectors.
  • Required positive rational epsilon and introduced a binary-encoded nonnegative query budget to give the worst-case query-number question a decision formulation.
  • Defined the comparison baseline using tolerances fixed before answers, optimized over those tolerances, with arbitrary fixed deterministic tie-breaking.
  • Interpreted HLG's midpoint as (a+b)/2; the printed half-width expression does not implement the stated interval-halving operation.

Results

The decision problem is \(\mathrm{NP}\)-hard, even with \(\tau=1\), \(n=4\), and the fixed positive budget \(B=1\). Thus a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The permitted adaptive strategies can improve the optimized independent HLG baseline by an unbounded factor. Below, a family with \(m=1\), \(\tau=2\), and \(n=4\) has \(Q^*=2\), while the optimized baseline requires exactly \(2k\) queries, with input length \(L=\Theta(k)\).

These conclusions do not require assuming that minimax regret or optimal query planning is polynomial-time computable.

1. Regret decomposes across types

For a consistent transcript \(h\), write the closed parameter interval of entry \(z\) in factor \(k\) of type \(t\) as \([a^h_{tkz},b^h_{tkz}]\). Coordinate threshold queries preserve the product structure of the uncertainty sets.

For feasible recommendations \(x,y\in F_t\), define

\[ D^h_{tk}(x,y)= \begin{cases} 0,&x[S_{tk}]=y[S_{tk}],\\ b^h_{tk,y[S_{tk}]}-a^h_{tk,x[S_{tk}]},& x[S_{tk}]\ne y[S_{tk}]. \end{cases} \]

Here and below, the displayed mathematics uses the equivalent notation \(D^h_{tk}(x,y)\) when referenced in prose.

If the two local assignments coincide, their utility contributions cancel. Otherwise, the two table entries are independent, so their difference is maximized by putting the entry used by \(y\) at its upper endpoint and the entry used by \(x\) at its lower endpoint. Independence between all entries therefore gives

\[ R_t^h(x):=\max_{u_t\in U_t^h} \left[\max_{y\in F_t}u_t(y)-u_t(x)\right] =\max_{y\in F_t}\sum_k D^h_{tk}(x,y). \]

Define \(r_t(h)=\min_{x\in F_t}R_t^h(x)\).

For fixed recommendations, independence between types implies

\[ \max_{(u_t)\in\prod_tU_t^h} \sum_t\mu_t\left[\max_{y\in F_t}u_t(y)-u_t(x_t)\right] =\sum_t\mu_tR_t^h(x_t). \]

Indeed, the left side is at most the right side, and equality follows by choosing, independently for every type, a parameter vector attaining its maximum. Such maxima exist because the closed uncertainty boxes are compact and the feasible sets are finite.

Recommendations can also be chosen independently. Consequently, a transcript admits valid recommendations exactly when

\[ \sum_t\mu_t r_t(h)\le\epsilon. \]

This is a stopping criterion, not an efficient planning theorem.

2. Hardness with a fixed positive budget

We give a polynomial-time many-one reduction from Boolean satisfiability.

Let \(\Phi(z_1,\ldots,z_d)\) be the input formula. Construct one type with mass \(1\). Its attributes are \(z_1,\ldots,z_d\) and two selector bits \(s\). Set

\[ F=\left\{(z,s): \bigl(s\ne 11\ \land\ z=0^d\bigr) \ \lor\ \bigl(s=11\ \land\ \Phi(z)\bigr)\right\}. \]

This set is always nonempty: it contains the three fallback outcomes with selectors \(00,01,10\).

Use one factor, with scope consisting of the selector bits:

| Selector | Utility-table interval |
|---|---|
| \(00\) | \([0,2]\) |
| \(01\) | \([0,2]\) |
| \(10\) | \([0,2]\) |
| \(11\) | \([2,2]\) |

The three uncertain entries are independent. Set \(\epsilon=1\) and \(B=1\).

If the formula is satisfiable

A feasible outcome with selector \(11\) has utility \(2\) for every parameter vector. Every other feasible outcome has utility at most \(2\). Recommending any satisfying outcome therefore has regret zero without queries.

Thus \(Q^*=0\).

If the formula is unsatisfiable

Only the three fallback outcomes are feasible.

Consider any strategy using at most one query. Follow the answer consistent with all three uncertain entries being zero. At least two uncertain entries remain unqueried.

Whatever fallback outcome the strategy recommends, there is a different fallback outcome whose entry remains unqueried. Keep the recommended outcome’s entry at zero and set that other entry to \(2\). This parameter vector remains consistent with the transcript: the changed entry was not queried, and every queried entry retains its value.

The recommendation therefore has maximum regret at least \(2\), exceeding \(\epsilon\). Hence \(Q^*>1\).

In fact, \(Q^*=2\). Query the first fallback entry at threshold \(1\). If the answer is \(p>1\), recommend that outcome. Its closed posterior lower bound is \(1\), so its maximum regret is at most \(1\). Otherwise, query the second entry at threshold \(1\). If it exceeds \(1\), recommend it; otherwise, recommend the third outcome. In the last case, both competing utilities are at most \(1\), while the recommended utility is at least zero.

Thus the reduction has

\[ \Phi\text{ satisfiable}\quad\Longleftrightarrow\quad Q^*\le 1. \]

The construction has \(m=d+2\), \(\tau=1\), \(n=4\), constant-length numerical data, and a constant-length budget encoding. Its construction time is polynomial in the formula size. This proves \(\mathrm{NP}\)-hardness even for the fixed positive budget \(B=1\).

3. An unbounded improvement over optimized HLG

Fix an integer \(k\ge2\), and let \(c=2^{-k}\).

There are two types, with masses

\[ \mu_1=\frac14,\qquad \mu_2=\frac34. \]

Each type has one Boolean attribute, both outcomes feasible, and one utility table:

| Outcome | Type \(t\)'s utility |
|---|---|
| \(0\) | The known value \(c\) |
| \(1\) | An independent parameter \(p_t\in[0,1]\) |

Set \(\epsilon=c/8\). The two parameters belong to different types and are independent.

The optimal query count is two

For an unqueried type, recommending outcome \(1\) has maximum regret \(c\): its utility might be zero. Recommending outcome \(0\) has maximum regret \(1-c\). Since \(c\le1/4\), its minimax regret is exactly \(c\).

After at most one query, some type remains entirely unqueried. By the decomposition above, every recommendation then has social maximum regret at least

\[ \min(\mu_1,\mu_2)c=\frac c4>\frac c8=\epsilon. \]

Thus \(Q^*\ge2\).

For the matching upper bound, query each \(p_t\) at threshold \(c\). If \(p_t\le c\), recommend outcome \(0\); otherwise, recommend outcome \(1\). Each recommendation has regret zero throughout the corresponding closed posterior interval.

Therefore \(Q^*=2\).

Every valid tolerance allocation forces \(2k\) HLG queries

Let \(\epsilon_1,\epsilon_2>0\) satisfy the baseline’s tolerance constraint

\[ \frac14\epsilon_1+\frac34\epsilon_2\le\frac c8. \]

It follows that \(\epsilon_1\le c/2<c\) and \(\epsilon_2\le c/6<c\).

For either type, the only positive-width interval is the interval for \(p_t\). HLG therefore repeatedly bisects that interval.

Consider the consistent parameter value \(p_t=0\). After \(j\) queries, the closed interval is \([0,2^{-j}]\). Its minimax regret is

\[ \min\left(c,\max(0,2^{-j}-c)\right). \]

For \(j<k\), we have \(2^{-j}\ge2c\), so this regret equals \(c\). Since the allocated tolerance is strictly smaller than \(c\), HLG cannot stop before query \(k\).

Conversely, HLG always stops within \(k\) queries. Its successive thresholds along the all-yes branch are \(2^{-1},\ldots,2^{-k}=c\). A no answer at any of these thresholds gives a posterior lower bound at least \(c\), making outcome \(1\) optimal. If all answers are yes, the final upper bound is \(c\), making outcome \(0\) optimal.

Thus each type has worst-case HLG count exactly \(k\), for every admissible tolerance allocation. The simultaneous parameter vector \(p_1=p_2=0\) realizes both worst cases. Consequently,

\[ Q_{\mathrm{HLG,opt}}=2k,\qquad Q^*=2. \]

The improvement factor is \(k\), which is unbounded. This already holds for a fixed query order; adaptation of subsequent query choices is unnecessary for the separation.

Here \(m=1\), \(\tau=2\), \(n=4\), and \(L=\Theta(k)\). The two-query strategy takes \(O(L)\) bit operations to read and emit its thresholds. A direct exact implementation of HLG takes \(O(k^2+L)\) bit operations on this family.

4. Query bounds and computational running times

Let \(s\) be the budget encoding length, and let \(n_t\) be type \(t\)'s number of table entries. Define

\[ M_t=\sum_k\max_z(b_{tkz}-a_{tkz}) \]

and let \(H_t=0\) when \(M_t\le\epsilon\), and otherwise \(H_t=n_t\lceil\log_2(M_t/\epsilon)\rceil\). Put \(H=\sum_tH_t\).

Choosing \(\epsilon_t=\epsilon\) for every type is admissible because the masses sum to one. The HLG guarantee stipulated in the question therefore yields \(Q^*\le H\). This uses the query guarantee associated with [Propositions 1–2 of Boutilier et al.](https://www.cs.toronto.edu/~cebly/Papers/BPPS-aij06.pdf).

Binary-rational encoding gives \(M_t/\epsilon\le n\,2^{O(L)}\), so

\[ H=O\bigl(n(L+\log(n+1))\bigr). \]

Thus polynomially many queries always suffice, although computing an optimal strategy is \(\mathrm{NP}\)-hard.

Evaluating a stopping condition

At a specified transcript, enumerate all Boolean assignments, test feasibility, and evaluate every feasible recommendation–competitor pair using Section 1. If posterior endpoints have bit length at most \(\lambda\), this takes

\[ O\left(\tau\,4^m\operatorname{poly}(m,n,L+\lambda)\right). \]

HLG midpoint queries produce endpoints of bit length \(O(L+H)\). Hence an exact implementation of the independent baseline with tolerances \(\epsilon_t=\epsilon\) has running time

\[ O\left((H+\tau)\,4^m \operatorname{poly}(m,\tau,n,L+H)\right). \]

This implements one admissible baseline; it does not assert polynomial-time optimization over tolerances.

A finite exact algorithm for the decision problem

For completeness, arbitrary rational thresholds do not prevent a finite exact search. A deliberately coarse upper bound is

\[ \operatorname{poly}(m,\tau,n,L+s) + 2^{\,2^{\,O(H+m\tau+n+\log(L+2))}}. \]

Here is a justification.

First, if \(B\ge H\), answer yes. Otherwise put \(b=B<H\). Enumerate full binary trees of depth \(b\), label every internal node by a queried entry, and label every leaf by a feasible recommendation for each type. Early termination can be padded with extra queries while retaining the recommendation, because additional information cannot increase maximum regret.

For any fixed labeling, introduce one threshold variable for each internal node. For each leaf and each feasible tuple of competing outcomes, a violating parameter vector is described by:

  • the initial parameter bounds;
  • the weak or strict comparisons defining that leaf’s transcript;
  • a strict weighted utility-loss inequality exceeding \(\epsilon\).

These are rational linear inequalities in the \(n\) latent parameters and the threshold variables. Requiring no such violating vector is equivalent to validity on the transcript closure: if a continuous loss exceeds \(\epsilon\) at a point in the closure, it also exceeds \(\epsilon\) at a sufficiently nearby consistent point.

Eliminate the \(n\) latent parameters by Fourier–Motzkin elimination, retaining strict inequalities. Each violating set projects to a conjunction of rational linear inequalities in the thresholds. Starting with at most \(2n+b+1\) inequalities, elimination produces at most

\[ (2n+b+2)^{2^{n+1}} \]

inequalities, with coefficient bit lengths bounded by \(2^{O(n)}\operatorname{poly}(L+b)\).

There are at most \(2^{b+m\tau}\) projected violating sets. To avoid all of them, enumerate a choice of one violated defining inequality from each set. Each choice gives a rational linear feasibility problem in the threshold variables.

Strict feasibility is decidable by adding a common positive slack variable and solving a rational linear program. A feasible choice has rational thresholds: a nonempty rational polyhedron has a rational point, and positive slack preserves all strict inequalities.

There are at most \(2^b-1\) threshold variables. Counting tree labelings, elimination output, and inequality choices yields the stated doubly exponential bound. Since \(b<H\), the numerical value of a very large binary-encoded budget never needs to be expanded into a tree.

Conclusion

Both target questions are settled: deciding \(Q^*\le B\) is \(\mathrm{NP}\)-hard, and the optimized independent HLG baseline can be worse by an unbounded factor. The exact complexity class and a tight general running-time bound are not determined by these proofs.
