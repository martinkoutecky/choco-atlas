The continuous mirror question, as graded

Given a finite category set \(M\), negative-Boolean valuation types \(T\) with \(v_t(\varnothing)=1\), rational masses \(\mu_t>0\) summing to \(1\), and feasible rational supplies \(q_e\in[0,1]\) for \(e\in M\), determine whether there are nonnegative rational masses \(x_{t,S}\) over types \(t\in T\) and integral bundles \(S\subseteq M\) such that \(\sum_{S\subseteq M}x_{t,S}=\mu_t\) for each \(t\), \(\sum_{t\in T,\,S\ni e}x_{t,S}=q_e\) for each \(e\), and every type-and-bundle pair with \(x_{t,S}>0\) satisfies the paper's \(\mathrm{EFX}^{+}_{0}\) comparison against every bundle \(R\) with \(\sum_t x_{t,R}>0\); if feasible, construct such an assignment.

Packaged proof task (what the prover saw — nothing else)

Let \(M\) be a finite category set with \(m=|M|\). A society is given by its support: the list \(T\) of its \(\tau\geq1\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has an arbitrary, possibly nonmonotone valuation \(v_t:2^M\to\{0,1\}\) satisfying \(v_t(\varnothing)=1\), represented by a Boolean circuit on bundle incidence vectors. Supplies \(q_e\in[0,1]\) are binary rationals; let \(L\) be the total input bit length, including circuits.
An assignment consists of rational masses \(x_{t,S}\geq0\), for integral bundles \(S\subseteq M\), satisfying \(\sum_{S\subseteq M}x_{t,S}=\mu_t\) and \(\sum_{t\in T}\sum_{S\ni e}x_{t,S}=q_e\).
It satisfies \(\mathrm{EFX}^{+}_{0}\) if, whenever \(x_{t,S}>0\) and \(\sum_u x_{u,R}>0\), either \(v_t(S)\geq v_t(R)\), or \(v_t(S\setminus\{e\})=1\) for every \(e\in S\). In the latter case \(S\neq\varnothing\) automatically. This comparison applies also within a type and when bundles share categories.

Is deciding whether such an assignment exists in \(\mathrm{P}\), with a feasible assignment constructible in time polynomial in \(m,\tau,L\), or is the decision problem \(\mathrm{NP}\)-hard?

For finitely many agents with these valuations, a complete partition satisfying \(\mathrm{EFX}^{+}_{0}\) always exists and is computable in polynomial time with value-oracle access ([Shah–Verma](https://arxiv.org/html/2608.29497v1)).
For identical negative-Boolean valuations, polynomial-time construction was already known ([Bérczi et al.](https://real.mtak.hu/206338/1/1-s2.0-S0304397524002111-main.pdf)). No result settling this exact mass-and-supply problem was located.

Modeling choices made when packaging the task

  • The valuation encoding was unspecified. Use Boolean circuits implementing value queries, and include their descriptions in L, to give P and NP-hardness their usual finite-input meanings.
  • Expand negative-Boolean valuations using the supplied translated convention: values belong to {0,1}, the empty bundle has value 1, and no monotonicity is required.
  • Resolve the undefined EFX comparison using its exact specialization to this domain: an envious recipient must value every one-category deletion of its own bundle at 1.
  • For overlapping category bundles, interpret deletion tests separately on the recipient and comparison sides; sharing a category does not delete it from both bundles simultaneously.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is \(\mathrm{NP}\)-complete, even with a single type, mass \(\mu_t=1\), and supplies restricted to \(\{1/2,1\}\). Thus a polynomial-time decision-and-construction algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

1. A polynomial reduction from satisfiability.

Let \(\varphi\) be a Boolean formula on variables \(y_1,\ldots,y_n\). Construct an instance with one type and category set

\(M=\{e_1,\ldots,e_n,g,h,w\},\)

where the last three categories are distinct additional categories. Set

\(\mu_t=1,\qquad q_g=q_h=1,\qquad q_w=q_{e_i}=1/2\quad(1\leq i\leq n).\)

For a bundle \(S\), let \(y_i(S)=1\) exactly when \(e_i\in S\). Define the valuation by the following Boolean expression, interpreting bracketed statements as their truth values:

\(v(S)=[S=\varnothing]\lor[w\in S]\lor\bigl([g\in S]\land[h\in S]\land\varphi(y_1(S),\ldots,y_n(S))\bigr).\)

This valuation satisfies \(v(\varnothing)=1\). Its circuit consists of the formula circuit, membership tests, and an empty-bundle test, so the construction has polynomial size.

Write \(x_S=x_{t,S}\). We prove that the constructed instance is feasible exactly when \(\varphi\) is satisfiable.

Necessity. Suppose a feasible assignment exists. Since total mass is \(1\) and \(q_g=q_h=1\),

\(\sum_{S:g\notin S}x_S=0,\qquad \sum_{S:h\notin S}x_S=0.\)

Nonnegativity therefore implies that every positively assigned bundle contains both \(g\) and \(h\).

Since \(q_w=1/2\), there is a positively assigned bundle \(R\) containing \(w\), and there is a positively assigned bundle \(S\) not containing \(w\). By definition, \(v(R)=1\).

We claim that every positively assigned bundle \(S\) without \(w\) encodes a satisfying assignment. Otherwise, such a bundle has \(v(S)=0\). But \(S\setminus\{g\}\) still contains \(h\), so it is nonempty; it contains neither \(g\) nor \(w\). Consequently, all three disjuncts in the valuation definition are false, and

\(v(S\setminus\{g\})=0.\)

The supported pair \(S,R\) then violates the specified EFX condition: \(v(S)<v(R)\), while deletion of \(g\in S\) does not give value \(1\). This contradiction proves the claim. In particular, \(\varphi\) is satisfiable.

This argument uses the stipulated comparison between bundles assigned within the same type.

Sufficiency. Suppose \(a=(a_1,\ldots,a_n)\in\{0,1\}^n\) satisfies \(\varphi\). Define

\(S_a=\{g,h\}\cup\{e_i:a_i=1\},\)

\(R_a=\{g,h,w\}\cup\{e_i:a_i=0\}.\)

Assign mass \(1/2\) to each bundle and zero elsewhere. Both bundles contain \(g,h\); exactly one contains \(w\); and, for every \(i\), exactly one contains \(e_i\). Hence all mass and supply equalities hold.

Moreover, \(v(S_a)=1\) because \(a\) satisfies \(\varphi\), and \(v(R_a)=1\) because \(w\in R_a\). Every supported bundle therefore has value \(1\). Every comparison satisfies the first EFX alternative, so this assignment is actually envy-free.

We have established a polynomial many-one reduction from Boolean satisfiability. Thus the decision problem is \(\mathrm{NP}\)-hard under the stated restrictions.

2. Polynomial-size certificates and membership in \(\mathrm{NP}\).

We now prove membership for the full problem, including arbitrary support size \(\tau\) and binary rational masses and supplies.

Let \(d=\tau+m\). Associate to each pair \((t,S)\) a column \(a_{t,S}\in\{0,1\}^{d}\): its type coordinates indicate \(t\), and its category coordinates indicate membership in \(S\). The assignment equalities are

\(Ax=b,\qquad b=((\mu_t)_{t\in T},(q_e)_{e\in M}).\)

First, EFX is preserved when the support shrinks: every ordered pair remaining in the support was already present before. Thus reweighting a subset of a fair support preserves fairness whenever the assignment equalities remain satisfied.

Suppose a feasible fair assignment exists. Among assignments satisfying the equalities whose supports are subsets of this assignment’s support, choose one with the fewest positive coordinates. Denote its support by \(P\).

The columns indexed by \(P\) are linearly independent. To prove this, suppose instead that there is a nonzero rational dependence

\(\sum_{j\in P}c_j a_j=0.\)

Summing the type coordinates gives \(\sum_{j\in P}c_j=0\), because each column has exactly one type coordinate equal to \(1\). Hence the nonzero vector \(c\) has both positive and negative entries. Set

\(\varepsilon=\min_{j:c_j>0}\frac{x_j}{c_j}>0,\qquad x'_j=x_j-\varepsilon c_j.\)

Then \(x'\) is rational, nonnegative, and satisfies \(Ax'=b\). At least one positive coordinate becomes zero, and no coordinate outside \(P\) becomes positive. This contradicts minimality of the support.

Consequently, the support size \(r=|P|\) satisfies \(r\leq d\).

The masses also admit polynomial-size encodings. Select \(r\) rows on which these independent columns form an invertible matrix \(B\in\{0,1\}^{r\times r}\), and let \(b'\) contain the corresponding entries of \(b\). Let \(D\) be the product of the denominators of all entries of \(b\). Its binary length is \(O(L)\), and \(Db'\) is an integer vector with entries between \(0\) and \(D\).

By Cramer’s rule,

\(x_j=\frac{\det B_j}{D\det B},\)

where \(B_j\) replaces column \(j\) of \(B\) by \(Db'\). The determinant expansion gives

\(|\det B|\leq r!,\qquad |\det B_j|\leq r!D.\)

Thus each mass has numerator and denominator of binary length \(O(L+r\log r)\). A feasible instance therefore has a certificate listing at most \(\tau+m\) type–bundle pairs and polynomial-size rational masses.

A verifier checks nonnegativity, all mass and supply equalities, and the EFX condition for every ordered pair of listed entries. Circuit evaluation and the required single-category deletions take polynomial time. Since every globally supported bundle appears in the list, these checks cover precisely the comparisons required by the problem. The decision problem belongs to \(\mathrm{NP}\).

3. Relation to the partition existence results.

The cited results concern complete partitions of a finite item set: [Shah–Verma, Theorem 3](https://arxiv.org/html/2608.29497v1), and [Bérczi et al., Theorem 9](https://real.mtak.hu/206338/1/1-s2.0-S0304397524002111-main.pdf). The reduction imposes a different requirement: both categories \(g,h\) must occur in every positively assigned bundle. Distinct supported bundles therefore share these categories, whereas distinct bundles in a partition are disjoint. Those existence theorems do not enforce the marginal supply equalities used here.

The reduction and certificate argument together completely settle the requested complexity question.
