The continuous mirror question, as graded

Given a binary-rational type distribution \(\mu\) over per-node weight levels \(w_t>0\), with \(\sum_t \mu_t w_t=1\), population scale \(N\), and \(k\) queries per node, sort types by weight to form the non-increasing rank profile \(a_\mu(u)\), \(u\in[0,1]\). Choose a cutoff \(q\in[0,1]\), allowing a boundary type’s mass to be split, so that the top mass \(q\) gossips and the rest answers individual queries. Find a cutoff minimizing \(C(q)=\max\{Nq,\;k\,\operatorname*{ess\,sup}_{u>q}a_\mu(u)\}\), taking the second term as zero if no mass remains.

Conclusion

Exact cutoff minimization is polynomial-time solvable in \(\tau\) and \(L\). An optimal cutoff occurs at a cumulative mass boundary between distinct weight levels. There are at most \(\tau+1\) such candidates, and their costs can be compared using exact rational arithmetic.

The proof is self-contained; the [cited paper](https://arxiv.org/pdf/2012.08313) provides background rather than a complexity result used here.

1. Group equal weight levels

Let the distinct supported weights, in decreasing order, be
\[ v_1>v_2>\cdots>v_r>0, \qquad r\leq\tau. \]
For each level, define its total mass
\[ M_i=\sum_{t:w_t=v_i}\mu_t. \]
Every \(M_i\) is positive, and \(\sum_{i=1}^r M_i=1\). Define the cumulative masses
\[ P_0=0, \qquad P_i=\sum_{h=1}^i M_h \quad (1\leq i\leq r). \]
Thus
\[ 0=P_0<P_1<\cdots<P_r=1. \]

Except at interval endpoints, which have Lebesgue measure zero, the function \(a_\mu\) equals \(v_i\) on the interval between \(P_{i-1}\) and \(P_i\). Grouping equal weights therefore does not change the objective.

2. Essential supremum and boundary reduction

Fix \(i\in\{1,\ldots,r\}\) and a cutoff satisfying
\[ P_{i-1}\leq q<P_i. \]
The remaining interval \((q,1]\) contains a set of measure \(P_i-q>0\) on which \(a_\mu=v_i\). All remaining weights are at most \(v_i\), apart from irrelevant endpoint values. Consequently,
\[ \operatorname*{ess\,sup}_{u\in(q,1]}a_\mu(u)=v_i, \]
and hence
\[ C(q)=\max\{Nq,kv_i\}. \]

Since \(q\geq P_{i-1}\) and \(N>0\),
\[ C(q)\geq\max\{NP_{i-1},kv_i\}=C(P_{i-1}). \]
Thus any cutoff strictly inside a weight-level interval can be replaced by its left boundary without increasing its cost. This includes cutoffs that split a type.

Every \(q<1\) belongs to exactly one such interval, while \(q=1=P_r\) is itself a boundary. Therefore,
\[ \min_{q\in[0,1]}C(q) = \min_{0\leq j\leq r}C(P_j). \]
In particular, a minimum exists and is attained at one of these finitely many rational boundaries.

To evaluate them uniformly, set \(v_{r+1}=0\). At \(P_j\), all mass of the first \(j\) weight levels has been removed. For \(j<r\), the next level has positive remaining mass, so
\[ C(P_j)=\max\{NP_j,kv_{j+1}\}. \]
For \(j=r\), the convention at \(q=1\) gives the same formula:
\[ C(P_r)=\max\{N,0\}=N. \]

3. Exact algorithm

Perform the following steps:

  • Sort the supported types by decreasing weight and group equal weights.
  • Compute \(P_0,\ldots,P_r\).
  • Compute, using exact rational arithmetic,

\[ B_j=\max\{NP_j,kv_{j+1}\}, \qquad 0\leq j\leq r. \]

  • Choose any index \(j^\star\) attaining the smallest \(B_j\), and return

\[ q^\star=P_{j^\star}. \]

The boundary reduction proves that this returned cutoff is globally optimal. Choosing the smallest minimizing index gives a deterministic rule for ties.

4. Bit complexity

Use the standard explicit encoding of rational numbers by binary numerators and positive binary denominators. Write each input mass as \(\mu_t=a_t/b_t\), and let
\[ D=\prod_{t=1}^{\tau}b_t. \]
The bit length of \(D\) is at most the sum of the bit lengths of the input denominators, up to a constant, and is therefore \(O(L)\).

Each mass can be represented exactly as
\[ \mu_t=\frac{a_t(D/b_t)}{D}. \]
Because the masses are positive and sum to one, every cumulative mass has the form
\[ P_j=\frac{A_j}{D}, \qquad 0\leq A_j\leq D. \]
Thus all cumulative masses have representations of \(O(L)\) bits.

Weight comparisons use cross multiplication of their input numerators and denominators. The products defining \(NP_j\) and \(kv_{j+1}\), and the cross products needed to compare candidate costs, also have \(O(L)\) bits: the encodings of \(N\) and \(k\) are already included in \(L\).

With schoolbook integer arithmetic, each required multiplication, division, or rational comparison costs \(O(L^2)\) bit operations. Sorting requires \(O(\tau\log(\tau+1))\) comparisons. Constructing the common denominator, cumulative masses, and candidate costs requires \(O(\tau)\) additional arithmetic operations. A valid overall bound is therefore
\[ O\!\left(\tau\log(\tau+1)L^2\right). \]

The returned cutoff also has \(O(L)\) output bits. No enumeration proportional to the numerical values of \(N\) or \(k\) is required.

5. Classification

The algorithm and proof settle the stated continuous cutoff problem for every valid input, without any Zipf assumption. Exact minimization is polynomial-time solvable. Under standard polynomial-time reductions, an NP-hardness classification for its threshold decision version would therefore imply \(\mathrm{P}=\mathrm{NP}\).
