The continuous mirror question, as graded

Given a connected graph \(G=(V,E)\), rational capacities \(b_v>0\) with \(\sum_{v\in V}b_v=1\), and a two-type population distribution \(\mu=(\mu_1,\mu_2)\), decide whether there exists a mass assignment \(x_{\ell v}\ge0\) satisfying \(\sum_{\ell=1}^2x_{\ell v}=b_v\) and \(\sum_{v\in V}x_{\ell v}=\mu_\ell\), such that no pair of infinitesimal households of distinct types has a mutually profitable swap. Here \(u_\ell(v;x)=0\) when the neighbourhood has zero mass, and otherwise \(u_\ell(v;x)=\frac{\sum_{w\in N(v)}x_{\ell w}}{\sum_{k=1}^2\sum_{w\in N(v)}x_{kw}}\); a swap from \(u\) and \(v\) is profitable exactly when \(x_{\ell u}x_{kv}>0\), \(\ell\ne k\), and \(u_\ell(v;x)>u_\ell(u;x)\) and \(u_k(u;x)>u_k(v;x)\).

Packaged proof task (what the prover saw — nothing else)

For each \(v\in V\), let \(N(v)\) be its neighbourhood. The input consists of a connected graph \(G=(V,E)\), rational \(b_v>0\) with \(\sum_{v\in V}b_v=1\), and rational \(\mu_1,\mu_2\ge 0\) with \(\mu_1+\mu_2=1\). An assignment has \(x_{\ell v}\ge0\), \(\sum_{\ell=1}^2x_{\ell v}=b_v\), and \(\sum_{v\in V}x_{\ell v}=\mu_\ell\). Define \(u_\ell(v;x)=0\) if \(\sum_{k=1}^2\sum_{w\in N(v)}x_{kw}=0\), and otherwise \(u_\ell(v;x)=\frac{\sum_{w\in N(v)}x_{\ell w}}{\sum_{k=1}^2\sum_{w\in N(v)}x_{kw}}\). It is stable if no \(u,v\in V\) and \(\ell\ne k\) satisfy \(x_{\ell u}x_{kv}>0\), \(u_\ell(v;x)>u_\ell(u;x)\), and \(u_k(u;x)>u_k(v;x)\).

Target. Is deciding whether such a stable mass assignment exists solvable in polynomial time, or is it NP-hard?

Nearest known results. For finite two-type Schelling games with every vertex occupied and the same fraction-of-own-type utility, deciding whether a swap-equilibrium exists is NP-complete (Kreisel, Boehmer, Froese, and Niedermeier, 2022). No result for the mass-assignment formulation above is included here.

Answer

The decision problem is polynomial-time solvable. In fact, every valid input admits a stable mass assignment, so the decision algorithm always answers “yes.”

1. Reduction to one type

Let

\[ \(y_v:=x_{1v}\). \]

Then \(x_{2v}=b_v-y_v\), and the feasible set for \(y\) is

\[ \(K:=\left\{y\in\mathbb R^V:0\le y_v\le b_v\text{ for every }v,\ \sum_{v\in V}y_v=\mu_1\right\}\). \]

This set is nonempty because \(y_v=\mu_1b_v\) belongs to \(K\). It is also compact and convex.

Suppose first that \(|V|\ge2\). Since \(G\) is connected, every vertex has a neighbor. Define

\[ \(B_v:=\sum_{w\in N(v)}b_w>0\) \]

and

\[ \(q_v(y):=\frac{\sum_{w\in N(v)}y_w}{B_v}\). \]

The denominator in the utility definition is independent of the assignment:

\[ \(\sum_{k=1}^2\sum_{w\in N(v)}x_{kw} =\sum_{w\in N(v)}(x_{1w}+x_{2w}) =\sum_{w\in N(v)}b_w =B_v\). \]

Consequently,

\[ \(u_1(v;x)=q_v(y),\qquad u_2(v;x)=1-q_v(y)\). \]

Each \(q_v\) is a linear, hence continuous, function of \(y\).

2. Exact form of a blocking pair

Consider first a potential blocking pair with \(\ell=1\) and \(k=2\). Its conditions become

\[ \(y_u>0,\qquad y_v<b_v,\qquad q_v(y)>q_u(y)\), \]

because

\[ \(u_2(u;x)>u_2(v;x)\iff 1-q_u(y)>1-q_v(y)\iff q_v(y)>q_u(y)\). \]

If instead \(\ell=2\) and \(k=1\), interchanging the names of \(u\) and \(v\) gives the same condition. Therefore an assignment is stable exactly when

\[ \(y_u>0\text{ and }y_v<b_v\quad\Longrightarrow\quad q_u(y)\ge q_v(y)\) \]

for all \(u,v\in V\).

Thus every vertex carrying positive type-\(1\) mass must have weakly greater type-\(1\) neighborhood fraction than every vertex having room for additional type-\(1\) mass.

3. A best-response correspondence

For \(y,a\in K\), define

\[ \(\Phi(y,a):=\sum_{v\in V}q_v(y)a_v\). \]

For fixed \(y\), define the correspondence

\[ \(F(y):=\operatorname*{arg\,max}_{a\in K}\Phi(y,a)\). \]

We verify the hypotheses of Kakutani’s fixed-point theorem.

  • The domain \(K\) is a nonempty compact convex subset of the finite-dimensional space \(\mathbb R^V\).
  • For every \(y\in K\), the function \(a\mapsto\Phi(y,a)\) is linear and continuous. Hence \(F(y)\) is nonempty and compact because the maximum is attained on \(K\).
  • The set \(F(y)\) is convex: if \(a,a'\) both maximize the same linear functional, then every convex combination of \(a\) and \(a'\) also maximizes it.
  • The function \(\Phi\) is jointly continuous. Since the feasible set \(K\) is fixed and compact, the Berge maximum theorem implies that \(F\) is upper hemicontinuous. Equivalently, this can be checked directly: if \(y^{(n)}\to y\), \(a^{(n)}\to a\), and \(a^{(n)}\in F(y^{(n)})\), then for every \(c\in K\),

\[ \(\Phi(y^{(n)},a^{(n)})\ge\Phi(y^{(n)},c)\). \]

Taking limits gives \(\Phi(y,a)\ge\Phi(y,c)\), so \(a\in F(y)\).

Kakutani’s theorem therefore yields some \(y^*\in K\) satisfying

\[ \(y^*\in F(y^*)\). \]

4. Every fixed point is stable

Suppose, toward a contradiction, that \(y^*\) is not stable. By the characterization above, there are vertices \(u,v\) such that

\[ \(y^*_u>0,\qquad y^*_v<b_v,\qquad q_v(y^*)>q_u(y^*)\). \]

Choose

\[ \(0<\delta\le\min\{y^*_u,b_v-y^*_v\}\) \]

and transfer \(\delta\) units of type-\(1\) mass from \(u\) to \(v\):

\[ \(a:=y^*-\delta e_u+\delta e_v\). \]

The coordinate bounds remain satisfied, and \(\sum_w a_w=\sum_w y^*_w=\mu_1\), so \(a\in K\). But

\[ \(\Phi(y^*,a)-\Phi(y^*,y^*) =\delta\bigl(q_v(y^*)-q_u(y^*)\bigr)>0\). \]

This contradicts \(y^*\in F(y^*)\). Hence \(y^*\) is stable.

Setting

\[ \(x_{1v}:=y^*_v,\qquad x_{2v}:=b_v-y^*_v\) \]

produces the required stable mass assignment.

5. The one-vertex case

If \(V=\{v\}\), then \(b_v=1\). Set

\[ \(x_{1v}=\mu_1,\qquad x_{2v}=\mu_2\). \]

The neighborhood is empty, so both utilities are \(0\). No strict utility inequalities can hold, and the assignment is stable.

6. Complexity consequence

Every connected valid instance, including the one-vertex instance, admits a stable assignment. Therefore the existence language contains every promised input. A decision algorithm can simply answer “yes,” and hence runs in constant time after input validation.

This does not imply that constructing a stable assignment by a particular representation is computationally easy; the fixed-point proof is existential. It completely settles the stated existence decision problem.
