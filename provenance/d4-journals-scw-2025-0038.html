The continuous mirror question, as graded

Given a binary agenda of \(r\) issues, a finite support \(T\subseteq\{0,1\}^r\) with rational masses \(\mu_t>0\) summing to \(1\), a candidate slate \(C\) with preference vectors \(a_c\in\{0,1\}^r\), and an odd committee size \(k\le |C|\), assume no issue is tied in the society: \(\sum_{t:t_i=1}\mu_t\ne 1/2\) for every issue \(i\). Define \(b_i=1\) when \(\sum_{t:t_i=1}\mu_t>1/2\), and \(b_i=0\) otherwise. Find a set \(D\subseteq C\) of exactly \(k\) candidates maximizing \(\sum_{i=1}^r \mathbf{1}[\mathbf{1}[\sum_{c\in D}a_{c,i}>k/2]=b_i]\).

Packaged proof task (what the prover saw — nothing else)

Let \(r\ge 1\) be the number of binary issues and \(C\) a slate of \(m\) individually identified candidates, each with a vector \(a_c\in\{0,1\}^r\); different candidates may have identical vectors. Let \(k\) be an odd integer with \(1\le k\le m\).
A society is given by its support: a list \(T\subseteq\{0,1\}^r\) of \(\tau\) types with positive masses \(\mu_t\) encoded as binary rationals, satisfying \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(r,m,\tau,L,k\).
Assume \(\sum_{t:t_i=1}\mu_t\ne 1/2\) on every issue, and define \(b_i=1\) if this sum exceeds \(1/2\), and \(b_i=0\) otherwise.
For a committee \(D\subseteq C\) with \(|D|=k\), let \(y_i(D)=1\) if \(\sum_{c\in D}a_{c,i}>k/2\), and \(y_i(D)=0\) otherwise. Its agreement score is \(A(D)=|\{i\in\{1,\ldots,r\}:y_i(D)=b_i\}|\). Candidates have equal voting weight, and committee membership is integral.

Is maximizing \(A(D)\) over committees of exactly \(k\) candidates polynomial-time solvable, or is it NP-hard?

For the discrete version with the voter-majority outcome known on every issue, maximizing majority agreement over an odd committee of prescribed size is NP-hard.
That result concerns the discrete formulation; no separate complexity classification for the rational-mass formulation is supplied here.

Modeling choices made when packaging the task

  • Require at least one issue, consistent with the discrete definition's normalization by the number of issues.
  • Treat candidates as individually identified members of a slate, allowing identical preference vectors, as the discrete model does.
  • Define L as the total input bit length and m as the number of candidates.
  • Keep committee membership integral and candidate voting weights equal; only the society is represented by masses.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Maximizing majority agreement is NP-hard, even when \(\tau=1\), the sole mass is \(1\), and the voter-majority vector is \(b=(1,\ldots,1)\). The decision problem asking whether some committee achieves agreement on every issue is NP-complete.

Why rational masses preserve the supplied hardness result.

Any prescribed majority vector \(b\in\{0,1\}^r\) can be realized by the support \(T=\{b\}\) with \(\mu_b=1\). On issue \(i\), the mass supporting \(1\) is exactly \(b_i\), so the majority is strict and equals \(b_i\).

Consequently, an instance of the discrete problem with known majority vector \(b\) can be transformed by retaining its candidates and committee size and replacing its society by this single-type society. Every committee retains exactly the same agreement score. The new society requires only \(O(r)\) bits. Thus the NP-hardness supplied in the question transfers directly.

The following independent reduction also establishes hardness with \(b=(1,\ldots,1)\).

Explicit reduction from Vertex Cover.

Use the standard NP-complete Vertex Cover problem: given a simple graph \(G=(V,E)\) and an integer \(h\), decide whether there is a set of at most \(h\) vertices meeting every edge. We may restrict to \(1\le h\le n\), where \(n=|V|\). Indeed, instances outside this range are immediately decidable and can be replaced by fixed yes or no instances within the range.

Write \(e=|E|\). Construct:

  • One candidate \(v\) for each vertex \(v\in V\).
  • A set \(H\) of \(h\) additional candidates.
  • One further candidate \(z\).
  • One forcing issue \(f\), and one issue for each edge.

Set \(k=2h+1\). Thus \(m=n+h+1\), \(r=e+1\), and \(k\le m\) because \(h\le n\). The strict committee-majority threshold is \(h+1\).

Define the candidate vectors as follows:

  • On issue \(f\), exactly the candidates in \(H\cup\{z\}\) have position \(1\).
  • On the issue corresponding to edge \(\{u,v\}\), exactly the candidates in \(H\cup\{u,v\}\) have position \(1\).

Use the society consisting of the all-ones type with mass \(1\). Hence every issue has voter-majority outcome \(1\), with no ties.

We prove that the constructed instance admits a committee agreeing on all \(r\) issues if and only if \(G\) has a vertex cover of size at most \(h\).

Suppose first that \(G\) has such a cover. Since \(n\ge h\), enlarge it, if necessary, to a set \(S\subseteq V\) of exactly \(h\) vertices. Enlarging a cover preserves the cover property. Select the committee \(D=H\cup\{z\}\cup S\), which has size \(2h+1\).

On issue \(f\), this committee contains \(h+1\) candidates with position \(1\). On every edge issue, all \(h\) candidates in \(H\) have position \(1\), and at least one selected endpoint also has position \(1\). Thus \(D\) achieves agreement on every issue.

Conversely, suppose a committee \(D\) of size \(2h+1\) agrees on every issue. On issue \(f\), there are only \(h+1\) candidates in the entire slate with position \(1\). Achieving the threshold \(h+1\) therefore forces \(H\cup\{z\}\subseteq D\). The remaining \(h\) members form a set \(S\subseteq V\).

For an edge \(\{u,v\}\), the number of selected candidates with position \(1\) is exactly \(h+|S\cap\{u,v\}|\). Agreement requires this number to be at least \(h+1\), so \(S\) contains an endpoint of every edge. Therefore \(S\) is a vertex cover.

This proves the equivalence. The construction has \(\tau=1\) and an explicitly encoded output of size \(O(rm+m\log(m+1))\), hence is polynomial in the graph input size. An algorithm maximizing agreement would decide Vertex Cover by testing whether its optimum equals \(r\).

Exact arithmetic, membership in NP, and running times.

For the general rational-mass input, write \(\mu_t=p_t/q_t\), where \(q_t>0\), and define \(Q=\prod_{t\in T}q_t\) and \(w_t=p_t(Q/q_t)\). Then the majority condition on issue \(i\) is exactly

\[ 2\sum_{t:t_i=1}w_t>Q. \]

The integer \(Q\) has \(O(L)\) bits: its bit length is bounded by the sum of the input denominator lengths. Each \(w_t\) also has \(O(L)\) bits, since positivity and normalization imply \(0<w_t\le Q\). Thus elementary integer arithmetic computes all majorities in \(O(L+r\tau L^2)\) bit operations. The no-tie promise makes every resulting \(b_i\) unambiguous.

Given a proposed committee, checking its membership and cardinality and calculating its agreement score takes polynomial time; a sufficient bound, including majority preprocessing, is

\[ O\!\left(L+r\tau L^2+rk\log(k+1)+r\log(r+1)\right). \]

Therefore the decision problem with a supplied agreement threshold belongs to NP. Together with the reduction above, even its perfect-agreement restriction is NP-complete.

For completeness, exact exhaustive optimization has the upper bound

\[ O\!\left( L+r\tau L^2+ \binom{m}{k}\bigl(rk\log(k+1)+r\log(r+1)\bigr) \right). \]

In particular, fixed \(k\) permits polynomial-time enumeration. When \(k\) is part of the input, the NP-hardness result rules out a polynomial-time exact algorithm unless \(\mathrm{P}=\mathrm{NP}\).
