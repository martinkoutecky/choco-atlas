The continuous mirror question, as graded

Given a finite type set \(T\), positive rational masses \(\mu_t\) summing to \(1\), permitted arcs \(A\), exactly three sink types \(S\), and a cap \(\lambda\), does there exist a nonnegative flow \(x_{tu}\) on \(A\) such that \(\sum_{u:(t,u)\in A}x_{tu}=\mu_t+\sum_{r:(r,t)\in A}x_{rt}\) for every \(t\notin S\), and \(\mu_s+\sum_{r:(r,s)\in A}x_{rs}\leq\lambda\mu_s\) for every \(s\in S\)? Equivalently, can an atomless population route all represented vote mass to sinks while keeping each sink’s average load per member at most \(\lambda\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also specifies permitted arcs \(A\subseteq\{(t,u)\in T\times T:t\ne u\}\), exactly three sinks \(S\subseteq T\), and a positive binary rational cap \(\lambda\). The sinks are exactly the types with no outgoing permitted arc; the input graph may contain cycles.
Mass may split among permitted arcs. Feasibility means that nonnegative real flows \(x_{tu}\) satisfy \(\sum_{u:(t,u)\in A}x_{tu}=\mu_t+\sum_{r:(r,t)\in A}x_{rt}\) for every \(t\in T\setminus S\), and \(\mu_s+\sum_{r:(r,s)\in A}x_{rs}\le\lambda\mu_s\) for every \(s\in S\). Thus the cap includes each sink's own mass and bounds its average represented mass per member.
Let \(m=|A|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this continuous delegation feasibility problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite unit-weight voters, choosing one outgoing arc per non-sink so that the chosen graph is acyclic and each sink represents at most a given number of voters, including itself, is NP-complete even with exactly three sinks. [Dey–Maiti–Sharma](https://arxiv.org/pdf/2011.14192v1)
For finite unit-weight voters allowed to split votes fractionally, minimizing the largest total sink load is polynomial-time solvable; this result uses unit supplies and absolute sink loads rather than arbitrary type masses and average loads. [Dey–Maiti–Sharma](https://arxiv.org/pdf/2011.14192v1)

Result

The problem is in \(\mathrm{P}\). With exactly three sinks, feasibility can be decided by three graph searches and eight exact rational inequalities, in \(\mathcal{O}((m+\tau)L^2)\) bit operations using elementary arithmetic.

The proof accounts for arbitrary positive rational masses, each sink’s own mass, and cycles in the permitted graph.

1. An exact feasibility criterion

For each type \(t\), define
\(R(t)=\{s\in S:\text{there is a directed path from }t\text{ to }s\}\).
Allow paths of length zero. Because sinks have no outgoing arcs, \(R(s)=\{s\}\) for every \(s\in S\).

For \(H\subseteq S\), put
\(Q_H=\{t\in T:R(t)\subseteq H\}\).
Thus \(Q_H\) contains the types whose reachable sinks all belong to \(H\). Types that cannot reach any sink belong to every \(Q_H\), including \(Q_{\varnothing}\).

Claim. The instance is feasible if and only if, for every \(H\subseteq S\),
\[ \sum_{t\in Q_H}\mu_t\le \lambda\sum_{s\in H}\mu_s. \]

There are exactly \(2^3=8\) inequalities. The inequality for \(H=\varnothing\) detects types that cannot reach a sink.

2. Necessity, including graphs with cycles

Suppose \(x\) is feasible, and write
\(\ell_s=\mu_s+\sum_{r:(r,s)\in A}x_{rs}\)
for the total load at sink \(s\).

Fix \(H\subseteq S\). The set \(Q_H\) is closed under outgoing permitted arcs: if \(t\in Q_H\) and \((t,u)\in A\), then every sink reachable from \(u\) is reachable from \(t\), so \(R(u)\subseteq R(t)\subseteq H\). Hence \(u\in Q_H\). Also, \(Q_H\cap S=H\).

For each non-sink, outgoing flow minus incoming flow equals \(\mu_t\). For a sink \(s\), outgoing flow minus incoming flow equals \(\mu_s-\ell_s\). Summing these identities over \(Q_H\), internal flows cancel. Since no permitted arc leaves \(Q_H\), this gives
\[ \sum_{s\in H}\ell_s = \sum_{t\in Q_H}\mu_t + \sum_{\substack{(r,t)\in A\\r\notin Q_H,\ t\in Q_H}}x_{rt}. \]

The boundary term is nonnegative. Therefore
\[ \sum_{t\in Q_H}\mu_t \le \sum_{s\in H}\ell_s \le \lambda\sum_{s\in H}\mu_s. \]

This argument uses only conservation and nonnegativity; cycles cause no difficulty.

3. Sufficiency

Assume all eight inequalities hold. Construct a finite directed network with source \(a\), terminal \(b\), a vertex \(v_t\) for every type, and a separate vertex \(z_s\) for every sink. Its arcs and capacities are:

  • \(a\to v_t\), with capacity \(\mu_t\);
  • \(v_t\to z_s\) whenever \(s\in R(t)\), with capacity \(1\);
  • \(z_s\to b\), with capacity \(c_s=\lambda\mu_s\).

All capacities are finite and nonnegative, so the max-flow/min-cut theorem applies.

Consider any source–terminal cut. Let \(J\subseteq T\) be the types whose vertices \(v_t\) lie on the source side, and let \(H\subseteq S\) be the sinks whose vertices \(z_s\) lie on that side.

If some arc \(v_t\to z_s\) crosses the cut, its capacity alone is \(1\), so the cut capacity is at least \(1\).

Otherwise, every type in \(J\) has all its reachable sinks in \(H\), giving \(J\subseteq Q_H\). The cut capacity is then
\[ \sum_{t\notin J}\mu_t+\sum_{s\in H}c_s = 1-\sum_{t\in J}\mu_t+\lambda\sum_{s\in H}\mu_s \ge 1-\sum_{t\in Q_H}\mu_t+\lambda\sum_{s\in H}\mu_s \ge 1. \]

Thus every cut has capacity at least \(1\). The cut containing only the source has capacity \(\sum_t\mu_t=1\). By max-flow/min-cut, a flow of value \(1\) exists.

Every arc leaving \(a\) must consequently be saturated. Writing \(y_{ts}\) for the flow on \(v_t\to z_s\), we obtain
\[ \sum_{s\in R(t)}y_{ts}=\mu_t, \qquad \sum_{t:s\in R(t)}y_{ts}\le\lambda\mu_s. \]

We now convert this assignment into permitted delegation flows. For each pair with \(y_{ts}>0\), choose a simple directed path from \(t\) to \(s\) and send \(y_{ts}\) along it. When \(t=s\), use the length-zero path. Define \(x_{uv}\) as the sum of these routed amounts over paths using \((u,v)\).

At a non-sink \(t\), every path passing through contributes equally to incoming and outgoing flow. Paths starting there contribute total \(\sum_s y_{ts}=\mu_t\), and no path ends there. Hence its required conservation equation holds.

At sink \(s\), its own assigned mass is \(y_{ss}=\mu_s\), since \(R(s)=\{s\}\). Every other amount assigned to \(s\) arrives on a permitted arc. Consequently,
\[ \mu_s+\sum_{r:(r,s)\in A}x_{rs} = \sum_{t:s\in R(t)}y_{ts} \le\lambda\mu_s. \]

Thus \(x\) is feasible, proving sufficiency.

4. Algorithm and binary running time

For each of the three sinks, search the reversed permitted graph. These searches identify every \(R(t)\) in \(\mathcal{O}(m+\tau)\) graph operations. Then accumulate \(\sum_{t\in Q_H}\mu_t\) for each of the eight subsets \(H\), and test the criterion.

To verify exact arithmetic bounds, write the input rationals as \(\mu_t=a_t/b_t\) and \(\lambda=a/b\), with positive integer denominators, and set
\[ D=b\prod_{t\in T}b_t. \]

Because the total binary input length is \(L\), the integer \(D\) has \(\mathcal{O}(L)\) bits. Define integers
\[ W_t=\frac{a_tD}{b_t}, \qquad K_s=\frac{aa_sD}{bb_s}. \]

These divisions are exact, and all resulting integers have \(\mathcal{O}(L)\) bits. Each feasibility test becomes the integer comparison
\[ \sum_{t\in Q_H}W_t\le\sum_{s\in H}K_s. \]

Computing the common denominator and scaled integers takes \(\mathcal{O}(\tau L^2)\) bit operations with elementary multiplication and division. Accumulating and checking the eight inequalities takes \(\mathcal{O}(\tau L)\) further bit operations. Including graph processing and input parsing, a conservative overall bound is
\[ \mathcal{O}((m+\tau)L^2). \]

This bound depends on the listed support size \(\tau\); it requires no expansion into individual voters or enumeration of unlisted possible types.

5. Relation to the cited results

[Dey–Maiti–Sharma, Theorem 6](https://arxiv.org/pdf/2011.14192v1) gives a polynomial-time linear-programming formulation for fractional delegation with unit supplies and absolute sink loads. Here, arbitrary supplies remain compatible with flow conservation, and the average-load cap becomes the fixed sink capacity \(\lambda\mu_s\).

The discrete hardness result concerns selecting one outgoing arc per non-sink. The continuous problem permits the splitting used in the sufficiency proof. Its feasibility is therefore polynomial-time decidable.
