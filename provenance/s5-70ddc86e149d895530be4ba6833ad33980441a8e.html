The continuous mirror question, as graded

Given finitely many item categories \(J\), common per-item values \(w_j\in\mathbb{Q}_{\ge 0}\), recipient masses \(\mu_3,\mu_6\in\mathbb{Q}_{\ge 0}\) with \(\mu_3+\mu_6=1\), and per-capita supplies \(\nu_j\in\mathbb{Q}_{\ge 0}\) satisfying \(\sum_j\nu_j=3\mu_3+6\mu_6\), does there exist a mass assignment \(x_{s,b}\ge 0\) to integral bundle patterns \(b\in\mathbb{Z}_{\ge 0}^{J}\), where \(\sum_j b_j=s\in\{3,6\}\), such that \(\sum_b x_{s,b}=\mu_s\), \(\sum_{s,b}b_jx_{s,b}=\nu_j\), and every pair of positively used patterns \(b,c\) satisfies \(w\cdot b\ge w\cdot c-\max_{j:c_j>0}w_j\)?

Let \(J\) be a nonempty set of item categories, with \(m=|J|\), common additive per-item values \(w_j\in\mathbb{Q}_{\ge0}\), and supplies \(\nu_j\in\mathbb{Q}_{\ge0}\).
A society is given by its support: the list of the \(\tau\) recipient types with positive mass, each mass a binary rational. Here types are required bundle sizes \(s\in\{3,6\}\); absent types have mass zero, \(\mu_3+\mu_6=1\), and \(\tau\) is the support size, not the number of possible types.
Supplies are per unit of recipient mass and satisfy \(\sum_{j\in J}\nu_j=3\mu_3+6\mu_6\). Let \(L\) be the total binary input bit length; state running times in \(m,\tau,L\).
For each \(s\in\{3,6\}\), define integral bundle patterns \(B_s=\{b\in\mathbb{Z}_{\ge0}^{J}:\sum_j b_j=s\}\); categories may occur repeatedly in a bundle.
A feasible assignment consists of real masses \(x_{s,b}\ge0\) satisfying \(\sum_{b\in B_s}x_{s,b}=\mu_s\) and \(\sum_{s\in\{3,6\}}\sum_{b\in B_s}b_jx_{s,b}=\nu_j\) for every \(j\in J\).
Require EF1 for every ordered pair of positively used patterns: whenever \(x_{s,b}>0\) and \(x_{t,c}>0\), require \(w\cdot b\ge w\cdot c-\max_{j:c_j>0}w_j\).

Is deciding whether such an assignment exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite recipients and individually listed goods with identical additive utilities, deciding EF1 existence with prescribed bundle sizes is strongly NP-complete, even when all sizes belong to \(\{3,6\}\). [Source](https://link.springer.com/article/10.1007/s00453-026-01401-8)

Result

The mass-assignment problem is solvable in polynomial time in \(m,\tau,L\).

The proof uses two facts: identical utilities reduce EF1 to a common scalar threshold, and the fixed bundle sizes make it possible to enumerate all patterns in polynomial time.

1. EF1 is equivalent to a common threshold

Let \(T=\{s\in\{3,6\}:\mu_s>0\}\), so \(|T|=\tau\). Patterns of absent types necessarily have zero mass and can be omitted.

For each pattern \(b\in B_s\), define
\[ \]
\(V(b)=\sum_{j\in J}w_jb_j,\qquad M(b)=\max_{j:b_j>0}w_j,\qquad R(b)=V(b)-M(b).\)

The maximum is well-defined because \(s\) is positive. Here \(R(b)\) is the bundle’s value after removing one maximum-value item, including when that category occurs repeatedly.

Lemma. A nonempty collection \(S\) of patterns satisfies EF1 for every ordered pair precisely when there is a real number \(a\) such that
\(R(b)\le a\le V(b)\) for every \(b\in S\).
Moreover, when EF1 holds, one can choose \(a=\min_{b\in S}V(b)\).

Proof. Suppose EF1 holds, and choose \(b_*\in S\) minimizing \(V(b)\). For every \(c\in S\), EF1 for the ordered pair \((b_*,c)\) gives
\(R(c)\le V(b_*)\).
By minimality, \(V(b_*)\le V(c)\). Thus \(a=V(b_*)\) has the required property.

Conversely, if such an \(a\) exists, then for every \(b,c\in S\),
\(V(b)\ge a\ge R(c)=V(c)-M(c)\),
which is exactly the required EF1 inequality. This proves the lemma.

2. Polynomially many candidate thresholds

Let
\(\mathcal P=\{(s,b):s\in T,\ b\in B_s\}\)
and write \(N=|\mathcal P|\). Counting nonnegative integer vectors with coordinate sum \(s\) gives
\(N=\sum_{s\in T}\binom{m+s-1}{s}\le\tau\binom{m+5}{6}=O(\tau m^6)\).

All these patterns can therefore be enumerated in polynomial time. Define the set of candidate thresholds
\(A=\{V(b):(s,b)\in\mathcal P\}\);
it has at most \(N\) elements.

Every feasible assignment has nonempty positive support, since its total recipient mass is one. By the lemma, if it satisfies EF1, a valid threshold is the minimum value of a positively used pattern. Consequently, some threshold in \(A\) suffices whenever an EF1 assignment exists.

3. Linear program for a fixed threshold

For each \(a\in A\), retain precisely the patterns
\(\mathcal P(a)=\{(s,b)\in\mathcal P:R(b)\le a\le V(b)\}\).

Test feasibility of the following linear program, whose variables are \(x_{s,b}\) for \((s,b)\in\mathcal P(a)\):

  • \(x_{s,b}\ge0\) for every retained pattern.
  • \(\sum_{b:(s,b)\in\mathcal P(a)}x_{s,b}=\mu_s\) for every \(s\in T\).
  • \(\sum_{(s,b)\in\mathcal P(a)}b_jx_{s,b}=\nu_j\) for every \(j\in J\).

An empty sum is interpreted as zero. Accept if at least one of these programs is feasible; otherwise reject.

Soundness. Suppose one program is feasible. Extend its solution by assigning zero mass to all omitted patterns. The displayed equations give exactly the required type masses and category supplies. Every positively used pattern satisfies \(R(b)\le a\le V(b)\), so the lemma proves EF1.

Completeness. Suppose an EF1 assignment exists. Let \(S\) be its positive support and set \(a=\min_{b\in S}V(b)\). Section 2 shows that \(a\in A\), and the lemma shows that every positively used pattern belongs to \(\mathcal P(a)\). Restricting the assignment to these variables therefore gives a feasible solution of the program for \(a\).

Thus the algorithm decides exactly the stated problem.

4. Bit complexity and running time

Each pattern contains at most six items. Its value is therefore a sum of at most six input rationals, with repetitions permitted. The rational numbers \(V(b)\), \(M(b)\), and \(R(b)\) have \(O(L)\) binary bits and can be computed and compared exactly in polynomial time.

For each threshold, the linear program has at most \(N\) variables and \(m+\tau\) equality constraints. Its matrix entries belong to \(\{0,1,\ldots,6\}\), and its right-hand sides are input rationals. In standard form, its encoding length is
\(O((m+\tau)N+L)\).

Rational linear-program feasibility over real variables is decidable in polynomial time in the binary encoding length, including systems whose feasible sets have empty interior. These hypotheses apply directly to the programs above. See [Khachiyan’s polynomial-time linear-programming theorem](https://www.mathnet.ru/eng/dan42319).

Using elementary exact rational arithmetic, enumeration and filtering take
\(O(N^2L^2)\) bit operations. If \(p(K)\) bounds rational linear-program feasibility for encoding length \(K\), the total running time is
\(O\!\left(N^2L^2+N\,p((m+\tau)N+L)\right)\).

Substituting \(N=O(\tau m^6)\) yields
\(O\!\left(\tau^2m^{12}L^2+\tau m^6\,p(\tau(m+\tau)m^6+L)\right)\),
which is polynomial in \(m,\tau,L\). This includes both support sizes \(\tau=1\) and \(\tau=2\).

5. Relation to finite-recipient hardness

The supplied [finite-recipient hardness result](https://link.springer.com/article/10.1007/s00453-026-01401-8) concerns integral numbers of recipients using each pattern. With \(n\) equally weighted finite recipients, normalized pattern masses must additionally satisfy \(nx_{s,b}\in\mathbb Z_{\ge0}\).

The present formulation allows arbitrary real pattern masses. Its threshold subproblems are linear programs without those integrality restrictions, so the polynomial-time result does not contradict finite-recipient hardness.
