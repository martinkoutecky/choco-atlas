The continuous mirror question, as graded

Given a finite support \(T\) with rational masses \(\rho_t\) summing to \(1\), and a rational expected-bill table \(\ell_{tk}\) for each type \(t\) and tariff \(k\in\Gamma\), find mass assignments \(x_{tk}\geq 0\) minimizing \(\sum_{t\in T}\sum_{k\in\Gamma}x_{tk}\ell_{tk}\), subject to \(\sum_{k\in\Gamma}x_{tk}=\rho_t\). Report the tariff masses \(s_k=\sum_{t\in T}x_{tk}\); types are exact classes with identical forecast parameters and tariff eligibility, and tied types may split.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) exact types with positive binary-rational masses \(\rho_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq 1\) tariffs \(\Gamma\). Each type has identical forecast parameters and eligibility within its class; its nonempty eligible set \(E_t\subseteq\Gamma\) is supplied explicitly. For every eligible pair, the input supplies a nonnegative binary-rational expected individual bill \(\ell_{tk}\).
An assignment consists of masses \(x_{tk}\geq 0\), with \(x_{tk}=0\) for \(k\notin E_t\) and \(\sum_{k\in\Gamma}x_{tk}=\rho_t\). Bills remain fixed under assignment; there is no demand pooling, tariff capacity, or group discount. Types may split, and ties require no prescribed tie-breaking.
Minimize \(\sum_{t\in T}\sum_{k\in E_t}x_{tk}\ell_{tk}\), returning an optimal assignment and tariff masses \(s_k=\sum_{t\in T}x_{tk}\). Let \(L\) be the total input bit length.

Is this exact mass-assignment problem solvable in time polynomial in \(m,\tau,L\), or is its decision version—whether the minimum bill is at most a supplied binary-rational budget \(B\geq 0\)—\(\mathrm{NP}\)-hard?

For discrete individual choice under Gaussian prediction-of-use tariffs, the minimizing tariff is constant between consecutive pairwise coefficient-of-variation thresholds, after dominated and duplicate tariffs are removed ([Robu et al.](https://doi.org/10.1109/TSG.2017.2660580)). This is a structural result, not a hardness classification.
No prior result specifically addressing the stated rational-table mass-assignment problem was verified.

Modeling choices made when packaging the task

  • Eligibility was mentioned without assignment constraints: supply nonempty eligible sets explicitly and forbid assignments outside them; the discrete model is the special case where every tariff is eligible.
  • The bill table's sign was unspecified: require nonnegative rational bills, consistent with positive expected consumption and nonnegative tariff penalties.
  • Require a nonempty tariff set and at least one eligible tariff per type to ensure feasibility.
  • Treat the expected-bill table as exact input, without requiring reconstruction from Gaussian forecast parameters.
  • Interpret this as individual choice: assignment does not change bills through aggregation, discounts, or capacity effects.
  • Allow arbitrary splitting and no prescribed tie-breaking, including at tariff indifference points.
  • Introduce a nonnegative rational budget for the decision version and include its encoding in the input bit length.

Result

The exact mass-assignment problem is solvable in polynomial time. Its decision version belongs to \(\mathrm{P}\); consequently, it can be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).

The essential premises are that bills are fixed and each type has its own mass constraint. There is no constraint coupling the tariff choices of different types.

Optimal assignment and proof

For each type \(t\in T\), define

\(c_t=\min_{k\in E_t}\ell_{tk}.\)

The minimum exists because \(E_t\) is finite and nonempty. Choose any tariff \(k_t\in E_t\) attaining it, and set

\(x^*_{tk}=\begin{cases}\rho_t,&k=k_t,\\0,&k\ne k_t.\end{cases}\)

This assignment is feasible: every assigned tariff is eligible, every entry is nonnegative, and the entries for type \(t\) sum to \(\rho_t\).

For any feasible assignment \(x\), nonnegativity and the definition of \(c_t\) give

\(\displaystyle \sum_{k\in E_t}x_{tk}\ell_{tk}\ \geq\ \sum_{k\in E_t}x_{tk}c_t\ =\ \rho_t c_t.\)

Summing over types establishes the lower bound

\(\displaystyle \sum_{t\in T}\sum_{k\in E_t}x_{tk}\ell_{tk}\ \geq\ \sum_{t\in T}\rho_t c_t.\)

The constructed assignment attains this bound, because it assigns each type entirely to a tariff charging \(c_t\). Therefore the exact optimum is

\(\displaystyle V^*=\sum_{t\in T}\rho_t\min_{k\in E_t}\ell_{tk},\)

and its tariff masses are

\(\displaystyle s_k^*=\sum_{\{t\in T:\,k_t=k\}}\rho_t.\)

Thus splitting is permitted but unnecessary for finding an optimum. More precisely, a feasible assignment is optimal exactly when it assigns positive mass only to minimizing tariffs. Indeed, its excess cost is

\(\displaystyle \sum_{t\in T}\sum_{k\in E_t}x_{tk}(\ell_{tk}-c_t),\)

a sum of nonnegative terms. This sum vanishes exactly when every term vanishes. Ties therefore introduce no difficulty.

Algorithm and exact arithmetic complexity

Let \(N=\sum_{t\in T}|E_t|\), so \(N\leq m\tau\).

The algorithm scans each eligible list, selects a tariff with the smallest bill using exact rational comparisons, constructs \(x^*\), and adds the masses assigned to each tariff. For the decision problem, it additionally computes \(V^*\) and compares it exactly with \(B\).

To verify polynomial bit complexity, write the input rationals as

\(\rho_t=a_t/b_t,\qquad \ell_{tk}=p_{tk}/q_{tk},\)

with nonnegative integer numerators and positive integer denominators encoded in binary. Comparing two bills requires comparing the integers \(p_{tk}q_{tj}\) and \(p_{tj}q_{tk}\). Each has bit length at most \(2L\), so each comparison takes polynomial time using ordinary integer arithmetic. There are at most \(N\) such comparisons.

Exact summation also has polynomial bit complexity. For tariff masses, use the common denominator

\(\displaystyle D_\rho=\prod_{t\in T}b_t.\)

Its bit length is bounded by the sum of the input denominator lengths, plus a constant, and hence is \(O(L)\). The numerator representing \(s_k^*\) is

\(\displaystyle S_k=\sum_{\{t:\,k_t=k\}}a_t(D_\rho/b_t).\)

Every quotient is an integer. Since the input masses sum to \(1\), we have \(0\leq S_k\leq D_\rho\), so these numerators also have \(O(L)\) bits.

For the objective, a common denominator is

\(\displaystyle D_V=\prod_{t\in T}(b_tq_{t k_t}),\)

and the exact numerator is

\(\displaystyle A_V=\sum_{t\in T}a_t p_{t k_t}\frac{D_V}{b_tq_{t k_t}}.\)

The denominator again has \(O(L)\) bits: its factors are denominators of distinct selected input entries. Moreover, \(V^*\) is a weighted average of the selected bills because \(\sum_t\rho_t=1\). Each input bill is at most \(2^L\), giving

\(0\leq A_V=D_VV^*\leq D_V2^L.\)

Thus \(A_V\) also has \(O(L)\) bits. All intermediate partial sums obey the same bound because their summands are nonnegative. Constructing these integers requires only polynomially many exact integer operations on polynomial-length operands.

Finally, writing \(B=u/v\) with \(v>0\), the decision test is the integer comparison

\(vA_V\leq uD_V.\)

This is polynomial-time as well, with the budget encoding included in the decision input length. A dense assignment has \(m\tau\) entries, and all output rationals have polynomial-length representations. Consequently, returning both the assignment and tariff masses takes time polynomial in \(m,\tau,L\).

Relation to the tariff-threshold result

The stated coefficient-of-variation structure is unnecessary for this problem. Here every eligible bill is supplied explicitly as an exact rational. The proof above follows directly from the fixed bills and independent type constraints, without any assumptions about Gaussian prediction or tariff thresholds.
