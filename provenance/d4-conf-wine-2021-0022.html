The continuous mirror question, as graded

Given a finite catalogue of good categories \(M\), a finite support \(\mathcal T\) of initial agent types \(t=(S_t,D_t)\), and rational masses \(\mu_t\) summing to \(1\), what is the maximum total number of exchanges per unit mass achievable by a finite schedule of legal dynamic cycle actions? Each agent holds and demands integral sets of categories; copies are interchangeable, and a cycle action of mass \(\lambda\) uses disjoint cohorts of each participating type, updates their states by the paper’s cycle rule, and cannot use more mass of a type than is available.

Packaged proof task (what the prover saw — nothing else)

Let \(M\) be a set of \(m\) item classes. A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a binary-encoded initial bundle \(b_t\in\mathbb Z_{\geq0}^{M}\) of class copies and a demand set \(D_t\subseteq M\), with \(b_t(j)=0\) for every \(j\in D_t\). Every class has positive aggregate initial supply; copies have individual owners.
A current agent state is \(s=(b,D)\). Receiving a class removes it permanently from that agent's demand set; received copies may subsequently be traded. Agents accept any currently demanded class in exchange for one currently owned copy.
A mass-cycle step selects \(k\geq2\) pairwise disjoint cohorts of equal real mass \(\delta>0\), in states \((b_i,D_i)\), and classes \(j_i\in D_i\), with indices cyclic and \(b_i(j_{i-1})\geq1\).
Cohort \(i\) receives one copy of \(j_i\) per agent from cohort \(i+1\), gives one copy of \(j_{i-1}\), and moves simultaneously to \((b_i-e_{j_{i-1}}+e_{j_i},D_i\setminus\{j_i\})\), where \(e_j\) is the unit vector for class \(j\).
States and class labels may repeat around a cycle, but participating agents and transferred copies are distinct. All cohorts must be available before the step; repeated use of a state consumes the sum of its selected cohort masses. Cohorts may split across later steps.
An execution is a finite sequence of such steps, possibly empty, with value \(\sum_C k_C\delta_C\), the total exchanges per unit population. The input also contains a binary rational threshold \(Q\geq0\); let \(L\) be the total input bit length. State running times in \(m,\tau,L\).

Is deciding whether an execution has value at least \(Q\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents and individually identified items, maximizing exchanges over dynamic cycle executions is NP-hard; optimal static executions, which transfer each item at most once, are computable in polynomial time. [Discrete results](https://arxiv.org/pdf/2110.14271).
No result settling this precise continuous mass-cycle problem was located.

Modeling choices made when packaging the task

  • Normalized total population mass to one, so the execution value directly measures exchanges per unit population.
  • Encoded integral bundle multiplicities in binary; demand is for a class once, rather than for a specified number of copies, and excludes initially owned classes.
  • Required positive aggregate supply for every listed class and individual ownership of copies, carrying over the discrete ownership condition without imposing uniqueness of class labels.
  • Allowed arbitrary positive real step masses and imposed simultaneous availability of disjoint participating cohorts, including aggregate availability when a state repeats.
  • Allowed repeated states and class labels around a cycle when they represent distinct agents and copies; imposed no cycle-length bound.
  • Made demand removal permanent and explicitly allowed received copies to be traded again.
  • Took the threshold to be nonnegative and allowed the empty execution; retained finite execution semantics rather than replacing attainable values with a supremum.

In particular, the problem is polynomial-time solvable for every fixed $m$.

Throughout, agents may split into arbitrarily small cohorts. None of the arguments imposes indivisibility on population mass.

1. Which demands can ever be satisfied?

Construct the initial trading graph $G$ with vertex set consisting of the types and classes. Its arcs are

$$ j\longrightarrow t \quad\text{if }b_t(j)>0, \qquad t\longrightarrow j \quad\text{if }j\in D_t. $$

Write $C(v)$ for the strongly connected component containing vertex $v$, and define

$$ A_t=\{j\in D_t:C(j)=C(t)\}, \qquad d_t=|A_t|. $$

Thus $A_t$ consists of the demands of type $t$ lying in its initial strongly connected component.

Proposition 1

A positive mass of type-$t$ agents can receive class $j\in D_t$ in some execution if and only if $j\in A_t$. Moreover, every such demand can receive positive mass in a single step from the initial society.

Proof

Keep an agent’s initial type as a permanent auxiliary label.

First, an agent never owns a currently demanded class. This holds initially by hypothesis. Receiving a class removes it from the demand set, and giving a copy cannot violate the property.

Suppose inductively that every previous transfer has occurred within one strongly connected component of $G$. Collapse each current state to its initial type. Every current demand arc is an initial demand arc. Every current ownership arc is either:

  • an initial ownership arc; or
  • an arc $j\longrightarrow t$ created when a type-$t$ agent received $j$.

In the second case, the inductive hypothesis gives $C(j)=C(t)$. Consequently, all newly created arcs lie within initial strongly connected components.

A current trading cycle becomes a directed closed walk in this collapsed graph. Its projection onto the condensation graph of $G$ cannot use an arc between distinct components: the condensation graph is acyclic, and such an arc would belong to a nontrivial directed closed walk. Hence every transfer in the current step also stays within an initial component. Induction proves necessity.

Conversely, suppose $C(t)=C(j)$ and $j\in D_t$. The arc $t\longrightarrow j$ lies on a simple directed cycle of $G$: append a shortest directed path from $j$ to $t$. This cycle alternates between types and classes. It contains at least two types, since an initial type cannot both own and demand the same class.

Select a cohort of mass

$$ 0<\delta\leq \min\{\mu_u:u\text{ is a type on this cycle}\} $$

from each participating type. Every required giving class is initially owned, and every receiving class is initially demanded. Executing this cycle gives a positive mass of type-$t$ agents class $j$. $\square$

The sets $A_t$ are computable in time polynomial in $m,\tau,L$. In particular, every execution has value at most

$$ H=\sum_t\mu_t d_t. $$

2. Polynomial-time computable bounds

I use “static” in the sense of the question: each individually owned copy is transferred at most once.

2.1. The exact static optimum

For every initially owned class, introduce a variable $a_{tj}$ representing the mass of copies of $j$ given by type $t$. For every demanded class, introduce $z_{tj}$ representing the mass received by type $t$. Missing variables are interpreted as zero.

Consider the linear program

$$ \begin{aligned} \text{maximize}\quad &\sum_t\sum_{j\in D_t}z_{tj},\\ 0\leq a_{tj}&\leq \mu_t b_t(j),\\ 0\leq z_{tj}&\leq \mu_t,\\ \sum_j a_{tj}&=\sum_j z_{tj} &&\text{for every }t,\\ \sum_t a_{tj}&=\sum_t z_{tj} &&\text{for every }j. \end{aligned} $$

Let its optimum be $S$.

Proposition 2

$S$ is exactly the maximum value of a static execution. It is attained and computable in polynomial time in $m,\tau,L$.

Proof

Every static execution satisfies the displayed constraints. A copy given in a static execution must be given by its initial owner: a different owner could possess it only after an earlier transfer. Demand permanence gives the bounds $z_{tj}\leq\mu_t$. Conservation gives both sets of balance equations.

It remains to prove that the LP optimum is attainable. The feasible region is bounded and rational, so it has a rational optimum.

Fix a rational feasible solution. For a type $t$, put

$$ r_t=\sum_j a_{tj}=\sum_j z_{tj}. $$

If $r_t=0$, assign no exchanges to this type. Otherwise, for initially owned classes $p$ and demanded classes $q$, define

$$ g_{pq}=\frac{a_{tp}z_{tq}}{\mu_t r_t}. $$

Then

$$ \sum_q g_{pq}=\frac{a_{tp}}{\mu_t}\leq b_t(p), \qquad \sum_p g_{pq}=\frac{z_{tq}}{\mu_t}\leq 1. $$

The polytope of nonnegative matrices satisfying these row and column bounds has integral vertices. Indeed, its constraint matrix is the vertex-edge incidence matrix of a bipartite graph; changing signs on one part gives a directed incidence matrix, which is totally unimodular. Adding slack variables preserves total unimodularity, and the bounds are integers.

Therefore $g$ is a convex combination of integral matrices satisfying the same bounds. The coefficients can be chosen rational: the equations defining a convex decomposition form a feasible rational linear system.

Each integral matrix specifies an individual agent’s planned static exchanges. Each demanded class occurs at most once, and at most $b_t(p)$ copies of initial class $p$ are selected. Its number of selected giving slots equals its number of receiving slots.

Do this for every type and choose a common denominator $N$ for all resulting cohort masses. We obtain a finite population of $N$ agents with integer numbers of planned slots.

Form a directed bipartite multigraph whose vertices are these agents and the classes. For each selected original copy of class $j$, add an arc from $j$ to its owner. For each planned receipt of $j$, add an arc from the receiving agent to $j$. Every vertex is balanced:

  • an agent has equally many giving and receiving slots;
  • a class is balanced by the LP’s class equation.

A finite balanced directed multigraph decomposes into simple directed cycles. Execute these cycles. Every giving edge names an original copy still owned until that edge is used. Every receiving edge names a distinct planned demand of its agent, so that demand remains available until used. Thus every cycle is valid, and no received copy is subsequently given.

Finally, replace each finite agent by a cohort of mass $1/N$. This realizes the same static execution in the continuous society, with value $\sum_{t,j}z_{tj}$.

The LP has $O(\tau m)$ variables and constraints and polynomial encoding length. Polynomial-time rational linear programming therefore computes $S$. $\square$

2.2. A stronger upper bound for dynamic executions

Define

$$ I_t=\{j:b_t(j)>0,\ C(j)=C(t)\}. $$

Introduce variables:

  • $c_t$: mass of type-$t$ agents that participate at least once;
  • $a_{tj}$, for $j\in I_t$: original copies given;
  • $z_{tj}$, for $j\in A_t$: received copies retained at the end.

Consider the LP

$$ \begin{aligned} \text{maximize}\quad &\sum_t d_t c_t,\\ 0\leq c_t&\leq\mu_t,\\ 0\leq a_{tj}&\leq b_t(j)c_t &&(j\in I_t),\\ 0\leq z_{tj}&\leq c_t &&(j\in A_t),\\ \sum_j a_{tj}&=\sum_j z_{tj}\geq c_t &&\text{for every }t,\\ \sum_t a_{tj}&=\sum_t z_{tj} &&\text{for every }j. \end{aligned} $$

Let its optimum be $U$.

Proposition 3

Every dynamic execution has value at most $U$, and

$$ U\leq H. $$

The bound $U$ is computable in polynomial time in $m,\tau,L$.

Proof

Consider an individual agent that participates.

Its first exchange gives an original copy. Also, it can never receive any class present in its initial bundle, because none of those classes belongs to its initial demand set.

Let $r$ be the number of original copies it gives during the execution. Every other copy it receives belongs to its initial demand set, and it receives each such class at most once. Since every exchange preserves its bundle size, it retains exactly $r$ received copies at the end. In particular, $r\geq1$.

Aggregating over participating agents gives

$$ a_{tj}\leq b_t(j)c_t,\qquad z_{tj}\leq c_t,\qquad \sum_j a_{tj}=\sum_j z_{tj}\geq c_t. $$

Proposition 1 restricts these classes to $I_t$ and $A_t$.

For each class, the number of original copies that leave their initial owners equals the number held as received copies at the end. This proves the class balance equation.

Finally, each participating type-$t$ agent receives at most $d_t$ classes. Hence the execution’s value is at most $\sum_t d_t c_t$, which is at most $U$. The inequality $U\leq H$ follows from $c_t\leq\mu_t$.

This LP also has $O(\tau m)$ variables and constraints with polynomial encoding length. $\square$

Consequently:

  • If $Q\leq S$, the answer is yes.
  • If $Q>U$, the answer is no.

Equality with $U$ requires additional reasoning, as the next example shows.

3. A compact upper bound need not be attainable

Take five classes $x,y,z,v,w$ and four types:

| Type | Mass | Initial bundle | Demand set |
|---|---:|---|---|
| $P$ | $3/8$ | one $x$, one $v$ | $\{y,w\}$ |
| $A$ | $1/4$ | one $w$ | $\{x,z,v\}$ |
| $B$ | $1/4$ | one $v$ | $\{x,y,z\}$ |
| $C$ | $1/8$ | one $y$, one $z$ | $\{x,w\}$ |

Every class has positive aggregate initial supply.

All vertices lie in one initial strongly connected component. For example,

$$ x\longrightarrow P\longrightarrow w\longrightarrow A \longrightarrow v\longrightarrow B\longrightarrow y \longrightarrow C\longrightarrow x $$

is a directed cycle, and the additional path $A\longrightarrow z\longrightarrow C$ incorporates $z$. Thus

$$ H=\frac38\cdot2+\frac14\cdot3+\frac14\cdot3+\frac18\cdot2 =\frac52. $$

A static execution activates the entire population:

  • A mass $1/8$ of $P$ exchanges $x$ for $y$ with all of $C$.
  • The remaining mass $1/4$ of $P$, all of $A$, and all of $B$ execute the cycle

$$ P:\ x\mapsto w,\qquad A:\ w\mapsto v,\qquad B:\ v\mapsto x. $$

Every agent participates once. Its associated variables are feasible for the upper-bound LP with $c_t=\mu_t$. Therefore $U=H=5/2$.

Proposition 4

No execution in this society has value $5/2$.

Proof

Suppose an execution attained $H$. Since $H$ counts every initial demand and no agent can receive a demanded class twice, all demands would have to be satisfied, except possibly on sets of mass zero.

In particular, all $P$ agents participate. Each participating agent retains at least one received copy, by the argument in Proposition 3. Hence $P$ agents hold at least $3/8$ copies of classes $y,w$ at the end.

The total supply of these two classes is exactly

$$ \operatorname{supply}(y)+\operatorname{supply}(w) =\frac18+\frac14=\frac38. $$

Thus every copy of $y$ and $w$ is held by $P$ at the end.

Let $a_{Cy}$ and $a_{Cz}$ denote the masses of original copies given by $C$. Every initial $y$ copy has left $C$, so $a_{Cy}=1/8$. No $C$ agent retains a received $w$, since every $w$ copy is held by $P$.

The only other class $C$ can receive is $x$, once per agent. Consequently, the total mass of received copies retained by $C$ is at most $1/8$. Bundle-size conservation gives

$$ \frac18+a_{Cz} =a_{Cy}+a_{Cz} =\text{mass of received copies retained by }C \leq\frac18. $$

Therefore $a_{Cz}=0$.

All initial $z$ copies belong to $C$. If none leaves its initial owner, no other agent can ever receive $z$. This contradicts satisfaction of the $z$ demands of types $A$ and $B$. $\square$

This example disproves the inference that activating agents through static exchanges suffices to satisfy all their accessible demands dynamically. It does not establish whether the supremum of execution values in this example equals $5/2$.

4. A polynomial-time solvable subclass

Proposition 5

If $d_t\leq1$ for every type, then the dynamic optimum equals $S$. The threshold problem is therefore polynomial-time solvable.

Proof

By Proposition 1, each agent can receive at most one class during the entire execution. An agent that receives a copy consequently cannot participate in a later exchange. Thus no received copy can be transferred again.

Every dynamic execution is therefore static. Proposition 2 computes and attains the optimum. $\square$

This includes all instances with $m=2$. Writing the classes as $x,y$, define

$$ \alpha=\sum_{\substack{t:\ b_t(x)>0\\ y\in D_t}}\mu_t, \qquad \beta=\sum_{\substack{t:\ b_t(y)>0\\ x\in D_t}}\mu_t. $$

The optimum is

$$ 2\min\{\alpha,\beta\}. $$

Indeed, agents with no copies cannot participate, agents owning both classes have no demands, and every remaining participating agent belongs to one of these two groups and can exchange only once. Matching equal masses of the groups attains the bound. For $m\leq1$, the optimum is zero.

5. An exact algorithm for fixed $m$

The following argument handles finite executions and the exact comparison with $Q$, including equality.

5.1. A bounded set of agent states

Fix an initial type $t$ and write $d=|D_t|$.

Every state descended from this type can be represented by:

  • $R\subseteq D_t$, the classes already received;
  • $F\subseteq R$, the received classes still held;
  • nonnegative integers $a_j$, for $j\notin D_t$, counting original copies given.

The current state satisfies

$$ D=D_t\setminus R, $$

and

$$ b(j)= \begin{cases} b_t(j)-a_j,&j\notin D_t,\\ 1,&j\in F,\\ 0,&j\in D_t\setminus F. \end{cases} $$

Furthermore,

$$ 0\leq a_j\leq b_t(j), \qquad \sum_{j\notin D_t}a_j=|F|. $$

These identities follow because initial classes cannot be received, demanded classes are received at most once, and bundle size is conserved.

There are $3^d$ choices for the status of the initially demanded classes. There are at most

$$ \binom{(m-d)+d}{d}=\binom md $$

nonnegative vectors $a$ whose coordinate sum is at most $d$. Thus the number of candidate states for this initial type is at most

$$ 3^d\binom md\leq4^m. $$

Some candidates may be unreachable; retaining them causes no difficulty because their initial mass is zero.

Keeping initial-type labels, the total number of candidate states is therefore at most

$$ N\leq\tau4^m. $$

Each state has an encoding length polynomial in $L$: every original coordinate decreases by at most $m$, regardless of its binary-encoded initial magnitude.

Keeping initial-type labels is legitimate. A cohort containing several initial types can be partitioned by those types. Taking a common refinement of these finite partitions around a cycle decomposes the step into finitely many steps with constant initial-type labels and the same resulting state masses.

5.2. Cycles need at most $m$ participants

Represent a participant that gives class $p$ and receives class $q$ by an edge

$$ p\longrightarrow q $$

labelled with its current state. We have $p\neq q$, since a currently demanded class is not owned.

A mass-cycle is a directed closed walk in this class graph. Every closed walk decomposes into simple directed cycles while preserving its individual labelled edges. Each resulting cycle has between two and $m$ edges.

Execute these cycles using the originally selected cohorts, reserving those cohorts until their corresponding cycle is executed. They remain available because the original cohorts were disjoint. Each participant gives and receives the same classes as in the original step. Redirecting copies of the same class is permitted.

Hence the resulting states and total value are preserved, and it suffices to use cycles with at most $m$ participants.

Importantly, a state label may occur several times within one such cycle. Its required mass is the sum over those occurrences.

5.3. Reduction to finite continuous Petri-net coverability

Make one place for each candidate labelled state and one additional place recording accumulated value.

For every state $s=(b,D)$ and classes $p,q$ with $b(p)>0$ and $q\in D$, create the primitive labelled edge $p\longrightarrow q$. There are at most

$$ E\leq Nm^2 $$

such edges.

Enumerate all simple class cycles among these edges. There are at most

$$ \sum_{k=2}^{m}E^k\leq mE^m $$

when $E\geq1$.

A cycle of length $k$ becomes one Petri-net transition:

  • its input multiplicity at state $s$ is the number of cohorts selected in state $s$;
  • its output multiplicities count the corresponding successor states;
  • it adds $k$ to the value place.

Firing this transition by amount $\delta$ requires, before firing, mass $\delta$ times each input multiplicity. It therefore enforces exactly the question’s availability rule for repeated states. Its value contribution is $k\delta$.

Initialize the state places with the given masses and the value place with zero. The target marking has zero in every state place and $Q$ in the value place. Covering this marking is precisely achieving value at least $Q$.

For an explicitly given finite Petri net with nonnegative integer input and output matrices and binary-rational markings, continuous coverability using rational firing amounts is polynomial-time decidable. This is the Fraca–Haddad theorem, stated as Proposition 2.4 in [*The Logical View on Continuous Petri Nets*](https://lsv.ens-paris-saclay.fr/Publis/PAPERS/PDF/BFHH-tocl17.pdf). Its semantics uses finite firing sequences. The constructed net satisfies its hypotheses: all multiplicities are nonnegative integers, and both markings are binary rational.

Allowing real firing amounts does not change this decision. For any fixed finite transition sequence, the availability inequalities and value requirement are rational linear constraints in its firing amounts. If positive real amounts satisfy them, choose a positive rational number smaller than every amount and impose it as a common lower bound. The resulting feasible rational linear system has a rational solution. Thus a real witness implies a rational witness with the same transition sequence.

The net construction is therefore exact for the problem as stated.

Proposition 6

The threshold problem is decidable in time

$$ (\tau4^m m^2)^{O(m)}\operatorname{poly}(L) = \tau^{O(m)}2^{O(m^2)}\operatorname{poly}(L). $$

Proof

The candidate-state set has size at most $\tau4^m$, and the number of cycle transitions is at most $m(\tau4^m m^2)^m$. Their encodings have polynomial length per transition. Apply polynomial-time continuous coverability to this explicit net. $\square$

6. Remaining classification question

The state expansion gives a polynomial algorithm for fixed $m$, but its size is exponential when $m$ varies. The compact LP bounds avoid that expansion, but Proposition 4 proves that the upper bound is not always attainable.

A general polynomial algorithm would need an exact formulation that captures the additional execution constraints. A hardness proof would need a reduction whose choices remain hard despite arbitrary cohort splitting. Neither is established above.
