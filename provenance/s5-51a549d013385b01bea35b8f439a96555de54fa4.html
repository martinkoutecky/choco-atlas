The continuous mirror question, as graded

Given candidates \(C\), a common order \(L_0\), a target \(p\), fixed \(r \ge 3\), a listed support of \(\tau\) complete rankings that are \(2\)-peaked with respect to \(L_0\), and rational masses \(\mu_t \ge 0\) summing to \(1\), decide for a rational budget \(\rho\) whether there are deleted masses \(x_t\) with \(0 \le x_t \le \mu_t\) and \(\sum_t x_t \le \rho\) such that \(p\) is an \(r\)-Approval winner in the remaining society: \(\sum_t(\mu_t-x_t)a_t(p) \ge \sum_t(\mu_t-x_t)a_t(c)\) for every \(c \in C\), where \(a_t(c)\) is \(1\) if \(c\) is in type \(t\)’s top \(r\), and \(0\) otherwise.

Packaged proof task (what the prover saw — nothing else)

Fix an integer \(r\ge 3\). Input consists of a candidate set \(C\) with \(m=|C|\ge r\), a linear order \(L_0\) of \(C\), a target \(p\in C\), and a rational budget \(\rho\in[0,1]\).
A society is given by its support: a list of \(\tau\) distinct strict complete rankings, each with positive binary rational mass \(\mu_t\), with \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
Each ranking must be \(2\)-peaked with respect to \(L_0\): the order \(L_0\) can be partitioned into one or two nonempty contiguous blocks such that the ranking restricted to each block is single-peaked on that block. The partition may depend on the ranking.
Let \(a_t(c)\) indicate whether \(c\) is among ranking \(t\)'s top \(r\) candidates. A deletion chooses real masses \(0\le x_t\le\mu_t\) with \(\sum_{t=1}^{\tau}x_t\le\rho\). It succeeds if \(\sum_{t=1}^{\tau}(\mu_t-x_t)a_t(p)\ge\sum_{t=1}^{\tau}(\mu_t-x_t)a_t(c)\) for every \(c\in C\). Ties count as winning; deleting all mass is permitted and gives every candidate score zero.
Is deciding whether a successful deletion exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard, for every fixed \(r\ge3\)? State running times in \(m,\tau,L\), with any dependence on \(r\) explicit.
For finite societies with indivisible votes, constructive control by deleting votes in \(2\)-peaked \(r\)-Approval elections is \(\mathrm{NP}\)-complete for every fixed \(r\ge3\), both when ties count as winning and when a unique winner is required.

Modeling choices made when packaging the task

  • Restricted the rational budget to [0,1], matching the discrete budget range from zero to the total number of votes under total-mass normalization.
  • Required m >= r so that every ranking has exactly r approved candidates.
  • Omitted zero-mass rankings from the listed support and required its masses to be positive.
  • Specified real-valued deleted masses to make divisibility explicit.
  • Explicitly permitted deletion of the entire society: the discrete definition permits deleting all votes, and the nonunique-winner model then treats every candidate as a winner.

Result

The decision problem is in \(\mathrm{P}\) for every fixed \(r\ge 3\). In fact, the same algorithm works when \(r\) is part of the input and for unrestricted rankings.

The essential feature is that deletion masses are divisible: the feasibility conditions form a rational linear program of polynomial size.

Exact linear-programming formulation

For each listed ranking \(t\), compute its approval indicators \(a_t(c)\in\{0,1\}\). Introduce a real variable \(y_t\) representing the mass retained from that ranking.

Consider the following system:

\(0\le y_t\le\mu_t\qquad(t=1,\ldots,\tau),\)

\(\displaystyle\sum_{t=1}^{\tau}y_t\ge 1-\rho,\)

\(\displaystyle\sum_{t=1}^{\tau}\bigl(a_t(p)-a_t(c)\bigr)y_t\ge0\qquad(c\in C\setminus\{p\}).\)

This system has \(\tau\) variables and \(2\tau+m\) inequalities.

Correctness. Suppose a successful deletion \(x\) exists. Set \(y_t=\mu_t-x_t\). The deletion bounds imply \(0\le y_t\le\mu_t\). Because the original masses sum to one,

\(\displaystyle\sum_{t=1}^{\tau}y_t=1-\sum_{t=1}^{\tau}x_t\ge1-\rho.\)

The final score of candidate \(c\) is \(\sum_t y_ta_t(c)\). Thus every winning inequality in the system holds.

Conversely, suppose the system has a feasible real solution \(y\). Define \(x_t=\mu_t-y_t\). Then \(0\le x_t\le\mu_t\), and

\(\displaystyle\sum_{t=1}^{\tau}x_t=1-\sum_{t=1}^{\tau}y_t\le\rho.\)

For every opponent \(c\), the corresponding inequality says exactly that the retained score of \(p\) is at least the retained score of \(c\). Therefore \(x\) is a successful deletion.

Consequently, the input is a yes-instance if and only if this linear program is feasible. This equivalence uses no assumption about peakedness.

Bit complexity and running time

We use the standard exact rational linear-programming theorem: feasibility of a finite system of non-strict linear inequalities with binary-encoded rational coefficients is decidable in time polynomial in its total encoding length. The theorem applies to feasibility over the reals and includes feasible sets of lower dimension; thus exact ties cause no difficulty. See [MIT’s notes on polynomial-time linear programming](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html).

All hypotheses hold here:

  • Every matrix coefficient belongs to \(\{-1,0,1\}\).
  • The right-hand sides are zero, the input masses \(\mu_t\), and \(1-\rho\).
  • Computing \(1-\rho\) increases its encoding length by at most a constant.
  • There are only \(\tau\) variables, one for each listed support ranking.

Using a conservative dense encoding, the linear program has total bit length

\(B=O\bigl(L+\tau(m+\tau)\bigr).\)

Extracting the approval indicators takes \(O(\tau m)\) ranking-entry operations: initialize the indicators and mark each ranking’s first \(r\) candidates. Writing the dense constraint matrix takes \(O\bigl(\tau(m+\tau)\bigr)\) coefficient operations. All rational data can be copied from the input except for the single subtraction defining \(1-\rho\).

The resulting total running time is therefore

\(\displaystyle\bigl(L+\tau(m+\tau)\bigr)^{O(1)}\)

bit operations, with an absolute polynomial exponent independent of \(r\). The only use of \(r\) is identifying the first \(r\) entries of each ranking, requiring \(O(\tau r)\) markings. Since \(r\le m\), the stated bound is uniform in \(r\). As \(m,\tau\le L\), it is also polynomial in \(L\) alone.

The rankings’ promised \(2\)-peakedness need not be checked or exploited.

Boundary cases and indivisible votes

When \(\rho=1\), retaining zero mass is feasible and gives every candidate score zero, as required by the stated convention. For smaller budgets, the same system makes the required decision.

The supplied NP-completeness result for indivisible votes does not contradict this conclusion. In an indivisible society with \(N\) voters, deleting mass from a ranking type is restricted to integer multiples of \(1/N\). Those discrete restrictions are absent here. The continuous linear program decides exactly the task as stated; its feasible solutions need not satisfy the discrete restrictions.
