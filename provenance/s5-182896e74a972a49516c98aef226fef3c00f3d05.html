The continuous mirror question, as graded

Given a finite candidate set \(X\), rational masses \(\nu_{\pi,a}\) of fixed voters of ranking \(\pi\) and per-unit weight \(a\), and rational masses \(\rho_a\) of strategic voters of weight \(a\), with all strategic voters sharing target \(c\) and allowed every ranking, does there exist a rational allocation \(q_{a,\pi}\ge 0\), with \(\sum_{\pi}q_{a,\pi}=\rho_a\), that makes \(c\) the unique Schulze winner? The masses sum to \(1\); the resulting pairwise margin is \(\omega_q(x,y)=\sum_{\pi,a}\nu_{\pi,a}a\,\sigma_\pi(x,y)+\sum_a a\sum_\pi q_{a,\pi}\sigma_\pi(x,y)\), where \(\sigma_\pi(x,y)=1\) if \(\pi\) ranks \(x\) above \(y\), and \(-1\) otherwise.

Result

The problem is polynomial-time solvable in \(m,\tau,L\). In fact, whenever a successful rational allocation exists, there is a successful allocation in which every strategic type uses the same ranking.

The distinction between an existential integer representation and the integer instance actually used by the algorithm is essential.

1. The discrete result needed

We use the following strengthening of the stated discrete theorem.

Discrete unanimity theorem. For a finite election with strict rankings and positive integer voter weights, if some assignment of rankings to a coalition makes \(c\) the unique margin-Schulze winner, then some single ranking, used by every coalition member, makes \(c\) the unique winner.

This is established by Müller and Kosub’s Algorithm 2 and Corollary 9, and stated explicitly in footnote 5. Their definition retains signed margins, and their unique-winner condition uses strict comparisons of path strengths, exactly as here. Their decision algorithm uses \(O(nm^2+m^5)\) arithmetic operations for \(n\) voters. [Müller and Kosub, *A Note on the Complexity of Manipulating Weighted Schulze Voting*, Sections 2–3](https://arxiv.org/pdf/1808.09226).

We apply this theorem only to finite elections with positive integer weights.

For any edge-weight function \(\omega\) and positive scalar \(D\), path strengths satisfy

\(S_{D\omega}(x,y)=D S_\omega(x,y)\).

Indeed, multiplication by \(D\) commutes with the minimum along each path and the maximum over paths. Consequently, positive scaling preserves every strict winner comparison.

2. Rational success implies unanimous success

Write

\(F(x,y)=\sum_{\pi,a}\nu_{\pi,a}a\sigma_\pi(x,y)\),

and let

\(W=\sum_a a\rho_a\)

be the total strategic weight.

Lemma. If a rational allocation makes \(c\) the unique winner, then there is a ranking \(\zeta\) such that assigning every strategic type entirely to \(\zeta\) makes \(c\) the unique winner.

Proof. Suppose \(q\) is a successful rational allocation. There are finitely many allocation coordinates, since both the strategic support and the set of rankings are finite.

Choose a positive integer \(D\) divisible by the denominators of all input masses and all coordinates of \(q\). Construct a finite integer-weight election as follows:

  • For each fixed type \((\pi,a)\), create one fixed voter with ranking \(\pi\) and weight \(Da\nu_{\pi,a}\).
  • For each positive coordinate \(q_{a,\pi}\), create one coalition member with weight \(Da q_{a,\pi}\), initially assigned ranking \(\pi\).

Every created weight is a positive integer. The resulting margin on each edge is exactly \(D\omega_q(x,y)\), so \(c\) is its unique winner.

By the discrete unanimity theorem, some common ranking \(\zeta\) makes \(c\) the unique winner when used by all these coalition members. Their total weight is

\(\sum_{a,\pi}Da q_{a,\pi}=D\sum_a a\rho_a=DW\).

Thus the resulting margins are

\(D\bigl(F(x,y)+W\sigma_\zeta(x,y)\bigr)\).

In the original society, define \(q^\zeta_{a,\zeta}=\rho_a\) and \(q^\zeta_{a,\pi}=0\) for \(\pi\ne\zeta\). This is a feasible rational allocation, with margins

\(\omega_{q^\zeta}(x,y)=F(x,y)+W\sigma_\zeta(x,y)\).

Positive scaling preserves the strict winner comparisons, so \(q^\zeta\) succeeds. This proves the lemma.

The converse is immediate: a unanimous rational allocation is an allowed allocation. Therefore rational manipulation exists if and only if unanimous manipulation exists.

The integer \(D\) in this proof may depend on an unknown allocation. It is used only to establish the equivalence; the algorithm never constructs it.

3. A polynomial-size integer instance

The cases \(m=1\) and \(W=0\) are immediate: answer yes for \(m=1\); when \(W=0\), compute the fixed election’s path strengths and check the required strict inequalities.

If there are no fixed types and \(W>0\), answer yes: placing \(c\) first gives \(S(c,x)=W\) and \(S(x,c)=-W\) for every opponent.

Otherwise, let \(D_0\) be the product of the denominators of the input masses only. Construct a discrete instance containing:

  • One fixed voter of weight \(D_0a\nu_{\pi,a}\) and ranking \(\pi\) for each fixed support type.
  • One manipulator of weight \(M=D_0W\), with target \(c\).

All weights are positive integers. If the manipulator uses ranking \(\zeta\), its election has margins

\(\omega^{\mathrm{disc}}_\zeta(x,y)=D_0\bigl(F(x,y)+W\sigma_\zeta(x,y)\bigr)\).

By scaling and the lemma, this discrete instance admits a successful manipulation exactly when the original rational society does. Apply the discrete polynomial-time algorithm to this instance.

This construction uses at most \(\tau+1\) voters. It does not enumerate rankings or expand masses into individual voters.

4. Bit complexity and conclusion

The sum of the binary lengths of the input denominators is at most \(L\), so \(D_0\) has \(O(L)\) bits.

Let \(a_{\max}\) be the largest input weight. Because all masses are nonnegative and sum to one, the total integer weight in the constructed election satisfies

\(D_0\bigl(\sum_{\pi,a}a\nu_{\pi,a}+\sum_a a\rho_a\bigr)\le D_0a_{\max}\).

Hence every constructed voter weight and every margin has \(O(L)\) bits. Constructing these weights takes polynomial time using exact integer arithmetic.

For completeness, the cited decision algorithm’s numerical bounds take values among the fixed margins plus \(M\), with a sufficiently large sentinel. Its arithmetic therefore remains on \(O(L)\)-bit integers. Using schoolbook arithmetic, a conservative overall bit-operation bound is

\(O\bigl((\tau m^2+m^5)(L+\log m)^2\bigr)\).

Thus the decision problem is polynomial-time solvable in the requested parameters. All comparisons are exact, including the strict inequalities required for a unique winner.
