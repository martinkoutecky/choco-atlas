The continuous mirror question, as graded

Given a finite support \(T\) of rational normalized two-resource demand types \(d_t\in(0,1]^2\), with \(\max_r d_{tr}=1\), and positive rational masses \(\mu_t\) summing to \(1\), find a per-member bundle \(a_t=y_td_t\) for each type, subject to \(\sum_t\mu_ta_{tr}\le1\). Let \(u_t(a)=\min_r a_r/d_{tr}\); require continuous SI \(y_t\ge1\), type-level EF \(u_t(a_t)\ge u_t(a_s)\) for all \(t,s\), and PO. Start with \(a_t=d_t\), then apply mass-weighted UNB: raise the resource-1 allocations of supported types in \(G_2=\{t:d_{t1}<1\}\) with the least current \(a_{t1}\), advancing tied types together and weighting resource use by \(\mu_t\). After renaming resources so \(\alpha=\sum_{t\in G_2}\mu_t\le\tfrac12\), is there an exact rational implementation polynomial in support size \(\tau=|T|\) and bit length \(L\), with worst-case fair-ratios against optimal feasible SI-and-EF allocations \(\mathrm{FRSW}=1+\alpha\) and \(\mathrm{FRUtil}=1/(1-\alpha)\)?

Use resource labels satisfying \(G_1=\{t:d_{t1}=1\}\), \(G_2=\{t:d_{t1}<1\}\), and \(\alpha=\sum_{t\in G_2}\mu_t\in(0,\tfrac12]\); thus \((1,1)\) belongs to \(G_1\).
Mass-weighted UNB starts at \(a_t=d_t\). While both resources have slack, let \(P\) be the types in \(G_2\) with least current \(a_{t1}\), and increase their bundles by \((\delta,\delta/d_{t1})\) together until another type in \(G_2\) joins the minimum or a resource is exhausted; consumption is weighted by \(\mu_t\). Yes. Mass-weighted UNB has an exact rational implementation polynomial in the support size and input bit length. It returns an SI, EF, PO allocation, and both stated fair-ratios hold.

Throughout, “binary-rational” means a rational number whose numerator and denominator are encoded in binary. This is the interpretation compatible with allowing every rational \(\alpha\).

1. A water-level description

Write the demands as
\[ \text{not used} \]
For \(t\in G_1\), put \(c_t=d_{t2}\), so \(d_t=(1,c_t)\). For \(t\in G_2\), put \(b_t=d_{t1}\), so \(d_t=(b_t,1)\), where \(0<b_t<1\).

For a water level \(\lambda\ge0\), define
\(y_t(\lambda)=1\) for \(t\in G_1\), and
\(y_t(\lambda)=\max\{1,\lambda/b_t\}\) for \(t\in G_2\).

Thus a type in \(G_2\) receives first-resource amount
\(a_{t1}(\lambda)=\max\{b_t,\lambda\}\).
The aggregate resource consumptions are

\[ \text{not used} \]
\(C_1(\lambda)=1-\alpha+\sum_{t\in G_2}\mu_t\max\{b_t,\lambda\}\),

\(C_2(\lambda)=\sum_{t\in G_1}\mu_tc_t+\sum_{t\in G_2}\mu_t\max\{1,\lambda/b_t\}\).

Let \(\beta=\min_{t\in G_2}b_t\). At \(\lambda=\beta\), this is exactly the initial allocation \(a_t=d_t\). Increasing \(\lambda\) raises precisely the types currently having the least first-resource amount, with the increments prescribed in the question. Therefore this parametrization describes the specified UNB process exactly.

Initially both consumptions are at most \(1\), and

\(C_1(\beta)=1-\alpha+\sum_{t\in G_2}\mu_tb_t<1\).

If \(C_2(\beta)=1\), UNB stops immediately. Otherwise both consumptions are continuous and strictly increasing on \([\beta,\infty)\): the types attaining \(\beta\) contribute positive slopes to both resources. Moreover,

\(C_1(1)=1-\alpha+\sum_{t\in G_2}\mu_t=1\).

Consequently there is a first exhaustion level \(\lambda_*\in[\beta,1]\). UNB returns \(a_t=y_t(\lambda_*)d_t\).

2. Exact polynomial-time implementation

Sort the distinct numbers \(b_t\), and append \(1\). These are the only water-level breakpoints.

On an interval between consecutive breakpoints, let
\(H=\{t\in G_2:b_t\le\lambda\}\) be the active types. Throughout that interval,

\(C_r(\lambda)=A_r+B_r\lambda\),

where

\(A_1=1-\alpha+\sum_{t\in G_2\setminus H}\mu_tb_t,\qquad B_1=\sum_{t\in H}\mu_t\),

\(A_2=\sum_{t\in G_1}\mu_tc_t+\sum_{t\in G_2\setminus H}\mu_t,\qquad B_2=\sum_{t\in H}\mu_t/b_t\).

Both slopes are positive. The candidate exhaustion levels are therefore the exact rationals

\(\lambda_r=(1-A_r)/B_r,\qquad r\in\{1,2\}\).

Starting at \(\beta\), inspect the intervals in increasing order. If the smaller candidate lies within the current interval, return that level. Otherwise proceed to the next breakpoint. Exhaustion at an endpoint terminates the algorithm. Since \(C_1(1)=1\), termination is guaranteed.

There are at most \(\tau\) intervals. Recomputing the four coefficients from their displayed formulas on each interval uses \(O(\tau^2)\) rational arithmetic operations, in addition to sorting.

This is also polynomial in bit complexity. Each coefficient is a sum of input rationals, products of two input rationals, or quotients of two input rationals. A common denominator can be formed using products of their denominators, and, for the quotients, the relevant input numerators. The combined bit lengths of these factors are \(O(L)\). Summing at most \(\tau\) terms adds at most \(O(\log\tau)\) bits. Forming \(\lambda_r\), comparing candidates, and producing \(\lambda_*/b_t\) consequently uses rationals of polynomially bounded bit length.

Thus the algorithm returns an exact rational allocation in time polynomial in \(\tau,L\), hence polynomial in \(m,\tau,L\) for the stipulated \(m=2\).

3. SI, EF, and unrestricted Pareto optimality

Share incentive

Every returned multiplier satisfies \(y_t\ge1\), directly from its definition.

Envy-freeness

We check all ordered pairs of groups.

For \(t,s\in G_1\), both have utility \(1\), and the first coordinate gives
\(u_t(a_s)\le a_{s1}/d_{t1}=1=y_t\).

For \(t\in G_1\), \(s\in G_2\), the bound \(\lambda_*\le1\) gives
\(a_{s1}=\max\{b_s,\lambda_*\}\le1\). Hence
\(u_t(a_s)\le a_{s1}/d_{t1}\le1=y_t\).

For \(t\in G_2\), \(s\in G_1\), the second coordinate gives
\(u_t(a_s)\le a_{s2}/d_{t2}=c_s\le1\le y_t\).

Finally, suppose \(t,s\in G_2\). If \(b_t\le b_s\), then
\(y_t=\max\{1,\lambda_*/b_t\}\ge\max\{1,\lambda_*/b_s\}=y_s\).
Using the second coordinate, \(u_t(a_s)\le y_s\le y_t\).

If \(b_t>b_s\), then
\(a_{t1}=\max\{b_t,\lambda_*\}\ge\max\{b_s,\lambda_*\}=a_{s1}\).
Using the first coordinate,
\(u_t(a_s)\le a_{s1}/b_t\le a_{t1}/b_t=y_t\).

These cases establish EF.

Pareto optimality

At termination, some resource \(r_*\) has consumption exactly \(1\).

Consider any alternative allocation with utility at least \(y_t\) for every type. Even allowing wasteful alternative bundles, its bundle for type \(t\) must have coordinate \(r_*\) at least \(y_td_{tr_*}\). If some type \(s\) obtains strictly greater utility, its coordinate \(r_*\) must be strictly greater than \(y_sd_{sr_*}\).

Because \(\mu_s>0\) and \(d_{sr_*}>0\), aggregate consumption of resource \(r_*\) would then exceed \(1\). This contradicts feasibility. Hence the allocation is PO without imposing SI or EF on improvements.

4. Exact correspondence with equal-weight instances

The following correspondence transfers approximation guarantees; it is not used to implement the algorithm.

Choose an integer \(N\) such that \(n_t=N\mu_t\) is a positive integer for every type. Replace type \(t\) by \(n_t\) identical equal-weight agents with demand \(d_t\). There are \(N\) agents altogether.

Given a type allocation \(a_t=y_td_t\), give each corresponding agent the bundle

\(\widetilde a_i=a_t/N,\qquad \widetilde y_i=y_t/N\).

Feasibility is preserved exactly, since

\(\sum_i\widetilde a_{ir}=\sum_t n_ta_{tr}/N=\sum_t\mu_ta_{tr}\).

The equal-weight SI condition is \(\widetilde y_i\ge1/N\), equivalent to \(y_t\ge1\). Homogeneity of Leontief utility shows that all EF inequalities are preserved.

Conversely, in any non-wasteful EF allocation of the replicated instance, agents with identical demands have identical multipliers. Indeed, for two such agents \(i,j\), their mutual EF inequalities give
\(\widetilde y_i\ge\widetilde y_j\) and
\(\widetilde y_j\ge\widetilde y_i\).
Their common bundle can therefore be multiplied by \(N\) to recover a type allocation.

Thus there is a bijection between the two feasible SI, EF benchmark sets.

Both objectives are preserved:

\(\sum_i\widetilde y_i=\sum_t n_ty_t/N=\sum_t\mu_ty_t\),

and

\(\min_r\sum_i\widetilde a_{ir}=\min_r\sum_t\mu_ta_{tr}\).

The maxima in these benchmark sets exist. In the type formulation, feasibility bounds \(y_t\le1/\mu_t\), using a dominant coordinate of type \(t\). SI and EF are closed linear inequalities, and the initial allocation is feasible and satisfies both. The benchmark set is therefore nonempty and compact, and both objectives are continuous.

Correspondence of the mechanisms

Equal-weight UNB starts each replicated agent at \(d_t/N\), exactly the scaled weighted initial allocation.

If the weighted active set is \(P\), its replicated active set consists of all \(n_t\) agents for \(t\in P\). A weighted increment \((\delta,\delta/b_t)\) corresponds to per-agent increment
\((\delta/N,\delta/(Nb_t))\).
The total replicated consumption increments are

\(\sum_{t\in P}n_t\delta/N=\delta\sum_{t\in P}\mu_t\),

\(\sum_{t\in P}n_t\delta/(Nb_t)=\delta\sum_{t\in P}\mu_t/b_t\).

These equal the weighted consumption increments. Meeting levels scale by \(1/N\), so meeting and exhaustion events correspond exactly. Induction over the successive events proves that the two UNB outputs correspond.

Finally, the minority proportion is unchanged:

\(|\widetilde G_2|/N=\sum_{t\in G_2}n_t/N=\alpha\).

The prescribed treatment of \((1,1)\) is also unchanged.
