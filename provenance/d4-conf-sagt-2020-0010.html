Theorem 5.1 — class: algorithmic

The continuous mirror question, as graded

Given rational type masses \(\mu_t>0\) summing to \(1\), positive integer weights \(w_t\), and a rational quota fraction \(\theta\in(0,1)\), let \(\bar w=\sum_t\mu_t w_t\). For sufficiently large population sizes \(N\) such that \(N\mu_t\) and \(N\theta\bar w\) are integers, form the weighted voting game with \(N\mu_t\) voters of type \(t\), each of weight \(w_t\), and quota \(N\theta\bar w\). Let \(x_t^{(N)}\) be the common per-voter nucleolus payoff for type \(t\), and set \(p_t^{(N)}=N x_t^{(N)}\). Determine whether \(p^{(N)}\) converges over these admissible \(N\); if it does, compute its limit.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\geq1\) types with positive binary rational masses \(\mu_t\) summing to \(1\), positive binary integer weights \(w_t\), and a binary rational quota fraction \(\theta\in(0,1)\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. There is no separate parameter \(m\).
Put \(\bar w=\sum_t\mu_t w_t\). An admissible population size is a positive integer \(N\) for which every \(N\mu_t\) and \(N\theta\bar w\) is integral. Consider all admissible \(N\) sufficiently large that \(N\theta\bar w>\max_t w_t\).
The replicated game has \(N\mu_t\) voters of weight \(w_t\); a coalition has value \(1\) exactly when its total weight is at least \(N\theta\bar w\), and otherwise has value \(0\). Use the standard nucleolus over imputations, with grand-coalition value \(1\). Symmetry gives a common payoff \(x_t^{(N)}\) within each type; set \(p_t^{(N)}=Nx_t^{(N)}\).

Is deciding whether \(p^{(N)}\) converges as admissible \(N\to\infty\), and computing its exact limit when it does, solvable in polynomial time in \(\tau,L\), or is this problem NP-hard?

Discrete weighted voting nucleoli admit a pseudopolynomial-time algorithm ([Könemann–Toth](https://arxiv.org/pdf/2005.10853)).
The exact replication setting is already covered by Kurz–Napel–Nohn: sufficiently many replicas have nucleolus equal to normalized voting weights, implying eventual equality \(p_t^{(N)}=w_t/\bar w\) and polynomial-time limit computation ([primary source](https://www.vwl4.uni-bayreuth.de/pool/Publikationen_Napel/2014_the_nucleolus_of_large_majority_games.pdf)). Thus this target is already settled.

Modeling choices made when packaging the task

  • Made 'sufficiently large' explicit by requiring the quota to exceed every individual weight, so all singleton values are zero and the imputation domain is nonempty.
  • Interpreted computation as exact limit computation from binary-encoded support data; population size is a sequence index, not an additional input.
  • Omitted a separate parameter m because this voting problem has no candidates or other underlying object counted by m.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is polynomial-time solvable. Every society satisfying the stated hypotheses has a convergent sequence, with exact limit

\(\displaystyle \lim_{\substack{N\to\infty\\N\text{ admissible}}}p_t^{(N)}=\frac{w_t}{\bar w}\qquad(t=1,\ldots,\tau).\)

In fact, this equality holds for every sufficiently large admissible \(N\).

1. Admissible sizes are unbounded

Put \(c=\theta\bar w\). Write each \(\mu_t=a_t/b_t\) and \(c=a_0/b_0\) in lowest terms, with positive denominators, and define

\(\displaystyle D=\operatorname{lcm}(b_0,b_1,\ldots,b_\tau).\)

For a reduced rational \(a/b\), integrality of \(Na/b\) is equivalent to \(b\mid N\): coprimality of \(a\) and \(b\) implies that \(b\mid Na\) exactly when \(b\mid N\). Consequently, the admissible sizes are precisely the positive multiples of \(D\).

Because \(c>0\), all sufficiently large such multiples also satisfy \(Nc>\max_t w_t\). Thus the sequence in the question has an unbounded domain.

2. The applicable theorem

We use Proposition 2 of Kurz–Napel–Nohn. For a weighted majority game represented by integer weights, let \(M\) be the largest weight, \(r\) the number of distinct weight values, \(m^\circ\) the minimum multiplicity of a weight value, and \(\widehat q\) the quota divided by total weight. The proposition states that the nucleolus equals the normalized weight vector whenever

\(\displaystyle \min\{\widehat q,1-\widehat q\}\,m^\circ>2rM^2.\)

Their definition is the nucleolus over imputations, as required here. [Kurz–Napel–Nohn, Sections 2–3, Proposition 2](https://www.vwl4.uni-bayreuth.de/pool/Publikationen_Napel/2014_the_nucleolus_of_large_majority_games.pdf).

3. Verification and eventual equality

Define

\(\displaystyle M=\max_t w_t,\qquad \mu_{\min}=\min_t\mu_t>0,\qquad \delta=\min\{\theta,1-\theta\}>0.\)

For admissible \(N\), the replicated game has positive integer weights and total weight

\(\displaystyle W_N=\sum_{t=1}^{\tau}N\mu_t w_t=N\bar w.\)

Its quota is \(q_N=N\theta\bar w\), so its normalized quota is exactly \(\widehat q_N=\theta\).

There are at most \(\tau\) distinct weight values. For any occurring weight \(a\), its multiplicity is

\(\displaystyle m_a(N)=N\sum_{\{t:w_t=a\}}\mu_t\geq N\mu_{\min}.\)

Hence \(m^\circ(N)\geq N\mu_{\min}\). In particular, repeated weight values among the listed types cause no difficulty.

Choose

\(\displaystyle N_0=1+\left\lfloor\max\left\{\frac{2\tau M^2}{\delta\mu_{\min}},\frac{M}{\theta\bar w}\right\}\right\rfloor.\)

For every admissible \(N\geq N_0\), the quota exceeds \(M\), and

\(\displaystyle \delta m^\circ(N)\geq\delta N\mu_{\min}>2\tau M^2\geq2rM^2.\)

All hypotheses of Proposition 2 therefore hold. Each voter of type \(t\) receives its normalized weight,

\(\displaystyle x_t^{(N)}=\frac{w_t}{W_N}=\frac{w_t}{N\bar w}.\)

Multiplication by \(N\) gives

\(\displaystyle p_t^{(N)}=\frac{w_t}{\bar w}\qquad(N\geq N_0,\ N\text{ admissible}).\)

This proves eventual constancy and the asserted limit.

4. Exact computation in polynomial time

The algorithm returns “convergent” and computes \((w_t/\bar w)_{t=1}^{\tau}\). It need not construct any replicated game.

To verify the bit complexity, write the input masses as \(\mu_t=a_t/b_t\), and set

\(\displaystyle B=\prod_{t=1}^{\tau}b_t,\qquad A=\sum_{t=1}^{\tau}a_t w_t(B/b_t).\)

Then \(\bar w=A/B\), and the exact output coordinates are

\(\displaystyle \frac{w_tB}{A},\)

reduced using greatest common divisors.

The binary length of \(B\) is at most the sum of the input denominator lengths plus a constant, hence is \(O(L)\). Because the masses sum to one, \(\bar w\leq M\), so \(A=B\bar w\leq BM\). Thus \(A\) and every numerator \(w_tB\) also have \(O(L)\) bits. All divisions \(B/b_t\) are exact. Polynomially many integer arithmetic and greatest-common-divisor operations on these integers compute the output in time polynomial in \(\tau,L\).

Therefore both convergence determination and exact limit computation are polynomial-time solvable under the stated hypotheses.
