Theorem 4.3 — class: hardness

The continuous mirror question, as graded

Given finitely many types \(t=(s_t,e_t,d_t)\) with rational masses \(\mu_t\), a fixed type order refining increasing \(d_t\), and a rational piecewise-constant per-capita capacity profile \(b(x)\), choose measures \(\lambda_t\) over starts \(a\in[s_t,e_t-d_t]\). Each unit of mass assigned at \(a\) receives the whole interval \([a,a+d_t]\); require \(\lambda_t([s_t,e_t-d_t])\le\mu_t\) and \(\sum_t\lambda_t([x-d_t,x]\cap[s_t,e_t-d_t])\le b(x)\) almost everywhere. What is the exact computational complexity of lexicographically maximizing the served-mass vector in the given type order?

Packaged proof task (what the prover saw — nothing else)

The resource is \([0,1]\). A society is given by its support: the list of \(\tau\ge1\) distinct types \(t=(s_t,e_t,d_t)\) with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. All type coordinates are binary rationals satisfying \(0\le s_t<e_t\le1\) and \(0<d_t\le e_t-s_t\).
The input includes a total type order refining increasing \(d_t\), with ties fixed, and a nonnegative per-capita capacity profile \(b\) on \([0,1]\), explicitly specified on \(m\) pieces by binary-rational breakpoints and values. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
An allocation consists of finite nonnegative Borel measures \(\lambda_t\) on \(A_t=[s_t,e_t-d_t]\), allowing atoms. Each unit of mass starting at \(a\) receives the entire uninterrupted interval \([a,a+d_t]\).
Feasibility means \(\lambda_t(A_t)\le\mu_t\) for every type and \(\sum_t\lambda_t([x-d_t,x]\cap A_t)\le b(x)\) for Lebesgue-almost every \(x\in[0,1]\). Unserved mass is allowed.
The objective is the lexicographically maximum served-mass vector \((\lambda_t(A_t))_t\) in the input order; earlier types' start measures may change while their served masses remain fixed.

Is computing this exact lexicographically maximum served-mass vector solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents receiving disjoint uninterrupted intervals, computing the serial-dictatorship allocation in increasing required-length order is NP-hard ([Ihara et al., 2017](https://doi.org/10.1527/tjsai.AG16-E)). No verified result settling this precise measure-valued problem was located.

Modeling choices made when packaging the task

  • Fixed the resource domain to [0,1] and imposed rational coordinates with 0 ≤ s_t < e_t ≤ 1 and 0 < d_t ≤ e_t − s_t, following the discrete utility domain.
  • Normalized positive masses to sum to one, interpreting the society as a distribution and capacity as per capita.
  • Specified capacity as nonnegative, with an explicit finite rational partition; m counts its pieces and L is the total input bit length.
  • Interpreted start measures as finite nonnegative Borel measures, allowing atoms and leaving unserved mass unallocated.
  • Conditioned on the supplied total order, fixing equal-length ties rather than averaging over random orders.
  • Specified that the exact output sought is the optimal served-mass vector and that earlier start measures may be rearranged while preserving earlier served masses.

Result

Computing the exact lexicographically maximum served-mass vector is NP-hard, even with \(m=2\), strictly positive piecewise constant capacity, and dyadic input numbers.

More precisely, deciding whether the lexicographic optimum serves every type fully is NP-hard. The proof below is a direct reduction from PARTITION for the measure-valued model.

1. A saturation lemma

The key fact is that divisible mass cannot fill a common window perfectly unless the available lengths admit an exact tiling of that window.

Lemma. Let \(H>0\), \(\beta>0\), and let finitely many types have lengths \(d_t\in(0,H]\). Suppose finite nonnegative measures \(\lambda_t\), supported on \([0,H-d_t]\), satisfy

\(\displaystyle \sum_t\lambda_t([x-d_t,x]\cap[0,H-d_t])\leq\beta\)

for almost every \(x\in[0,H]\), and

\(\displaystyle \sum_t d_t\lambda_t([0,H-d_t])=\beta H.\)

Then there is a finite sequence of available lengths, allowing repetitions, whose sum is \(H\).

Proof. Extend the start measures to the real line by zero. Define the start and end measures

\(\displaystyle S=\sum_t\lambda_t,\qquad E=\sum_t(a\mapsto a+d_t)_{\#}\lambda_t.\)

Using half-open allocated intervals, define the occupancy

\(\displaystyle g(x)=\sum_t\int \mathbf 1_{[a,a+d_t)}(x)\,d\lambda_t(a).\)

The closed-interval occupancy in the hypothesis differs from \(g(x)\) by \(E(\{x\})\). A finite measure has at most countably many atoms, so these occupancies agree almost everywhere.

Tonelli’s theorem gives

\(\displaystyle \int_0^H g(x)\,dx=\sum_t d_t\lambda_t([0,H-d_t])=\beta H.\)

Since \(g\leq\beta\) almost everywhere on \([0,H]\), it follows that \(g=\beta\) almost everywhere there. Outside that window, \(g=0\).

For every real \(x\),

\(\displaystyle g(x)=S((-\infty,x])-E((-\infty,x]).\)

Consequently, \(g\) is right-continuous. Two right-continuous functions that agree almost everywhere agree everywhere: a nonzero difference at a point would, by right-continuity, persist on an interval of positive length. Thus

\(\displaystyle g(x)=\beta\mathbf 1_{[0,H)}(x)\)

everywhere. Comparing cumulative distribution functions yields the measure identity

\(\displaystyle S-E=\beta\delta_0-\beta\delta_H.\)

No interval ends at zero, so \(E(\{0\})=0\), and hence \(S(\{0\})=\beta>0\). Some type therefore has a positive start atom at zero. Follow that interval to its endpoint.

At any resulting endpoint \(x\in(0,H)\), the arriving atom makes \(E(\{x\})>0\). The balance identity gives \(S(\{x\})=E(\{x\})>0\), so another available interval starts at \(x\).

Continue this construction. Every step increases the position by at least \(\min_t d_t>0\), and every endpoint lies in \([0,H]\). Therefore the construction must terminate after finitely many steps. It cannot terminate in \((0,H)\), where balance guarantees another departure, so it terminates at \(H\). The selected lengths sum to \(H\). ∎

This lemma permits arbitrary nonatomic start measures and arbitrary splitting of each type’s mass.

2. Encoding PARTITION by exact length sums

Take a PARTITION instance with positive integer weights \(w_1,\ldots,w_n\), where \(n\geq2\), and write

\(\displaystyle W=\sum_{i=1}^n w_i.\)

We may assume \(W\) is even: multiplying every input weight by two preserves the answer and makes the total even.

Define the positive integers

\(\displaystyle R=n+1,\qquad K=nW+1,\qquad S=\sum_{i=1}^n R^{i-1},\)

\(\displaystyle U=KS+W,\qquad M=(n+1)U.\)

For each input weight, introduce two integer lengths:

\(\displaystyle \ell_i^-=M+KR^{i-1},\qquad \ell_i^+=M+KR^{i-1}+w_i.\)

Set the target length to

\(\displaystyle C=nM+KS+\frac W2.\)

Encoding claim. A multiset of the \(2n\) available lengths sums to \(C\) if and only if the PARTITION instance is feasible. Every such multiset contains exactly one of \(\ell_i^-,\ell_i^+\) for each \(i\).

Proof. Every available length lies between \(M\) and \(M+U\), while

\(\displaystyle nM\leq C<(n+1)M.\)

A multiset containing at least \(n+1\) lengths therefore exceeds \(C\). A multiset containing at most \(n-1\) lengths has total at most

\(\displaystyle (n-1)(M+U)<nM\leq C,\)

because \((n-1)U<M\). Thus an exact representation contains exactly \(n\) lengths.

Let \(x_i\) and \(y_i\) denote the multiplicities of \(\ell_i^+\) and \(\ell_i^-\), and put \(c_i=x_i+y_i\). Subtracting the common contribution \(nM\) gives

\(\displaystyle K\sum_i c_iR^{i-1}+\sum_i x_iw_i=KS+\frac W2.\)

Both \(\sum_i x_iw_i\) and \(W/2\) belong to \([0,K)\): indeed, there are \(n\) selected lengths and \(\sum_i x_iw_i\leq nW<K\). Reduction modulo \(K\) therefore gives

\(\displaystyle \sum_i x_iw_i=\frac W2,\qquad \sum_i c_iR^{i-1}=S.\)

Each \(c_i\) lies in \(\{0,\ldots,n\}\), and \(R=n+1\). Uniqueness of base-\(R\) expansions now forces \(c_i=1\) for every \(i\). The indices for which \(x_i=1\) form a partition subset.

Conversely, a subset whose weights sum to \(W/2\) gives an exact representation: choose \(\ell_i^+\) for indices in that subset and \(\ell_i^-\) for the remaining indices. ∎

The lengths are all distinct and already ordered:

\(\displaystyle \ell_1^-<\ell_1^+<\ell_2^-<\ell_2^+<\cdots<\ell_n^-<\ell_n^+.\)

Indeed, \(0<w_i<K\), whereas consecutive base contributions differ by at least \(K\).

3. Constructing the society

Choose

\(\displaystyle Q=\lceil\log_2 C\rceil+1,\qquad h=2^{-Q},\qquad H=Ch.\)

Then \(0<H\leq1/2\). Choose also

\(\displaystyle r=\lceil\log_2 n\rceil+1,\qquad \beta=2^{-r},\qquad \mu_0=1-n\beta.\)

Here \(n\beta\leq1/2\), so \(\mu_0\geq1/2>0\).

For each \(i\), create the two types

\(\displaystyle t_i^-=(0,H,h\ell_i^-),\qquad t_i^+=(0,H,h\ell_i^+),\)

each with mass \(\beta/2\).

Add one further type

\(\displaystyle t_0=(H,1,1-H)\)

with mass \(\mu_0\). Define the two-piece capacity profile by

\(\displaystyle b(x)= \begin{cases} \beta,&0\leq x<H,\\ \mu_0,&H\leq x\leq1. \end{cases}\)

All coordinates, masses, breakpoints, and capacity values are dyadic. The masses sum to one because

\(\displaystyle 2n\frac{\beta}{2}+\mu_0=n\beta+(1-n\beta)=1.\)

All type lengths satisfy the required window bounds. In particular, each encoded integer length is at most \(M+U<nM\leq C\), so its scaled length is strictly less than \(H\).

Supply the type order

\(\displaystyle t_1^-,t_1^+,\ldots,t_n^-,t_n^+,t_0.\)

The encoded lengths are strictly increasing as proved above. Moreover, they are all smaller than \(H\leq1/2\), while the last type has length \(1-H\geq1/2\). Thus this order refines increasing required length, with no ties.

The constructed instance has

\(\displaystyle m=2,\qquad \tau=2n+1.\)

4. Full service is equivalent to PARTITION

Full service implies a partition

Suppose every type is served fully. The encoded types occupy only \([0,H]\), while \(t_0\) occupies only \([H,1]\); their intersection at \(H\) is irrelevant to almost-everywhere feasibility.

The total length-weighted served mass of the encoded types is

\(\displaystyle \sum_{i=1}^n\frac{\beta}{2}h(\ell_i^-+\ell_i^+) =\beta h\left(nM+KS+\frac W2\right) =\beta H. \)

Their capacity on \([0,H]\) is \(\beta\). The saturation lemma therefore gives a sequence of encoded lengths whose scaled sum is \(H\). Dividing by \(h\), the corresponding integer lengths sum to \(C\).

The encoding claim then produces a subset of the input weights summing to \(W/2\).

A partition implies full service

Conversely, suppose \(I\subseteq\{1,\ldots,n\}\) satisfies

\(\displaystyle \sum_{i\in I}w_i=W/2.\)

Construct a first tiling of \([0,H]\) using \(t_i^+\) when \(i\in I\) and \(t_i^-\) otherwise. The encoding claim shows that these lengths sum to \(H\). Assign mass \(\beta/2\) to the start of each interval in this tiling.

Construct a second tiling using the opposite choice from each pair. Its selected weights also sum to \(W/2\), so it too tiles \([0,H]\). Again assign mass \(\beta/2\) to each interval’s start.

Every encoded type appears exactly once across the two tilings, and hence receives exactly its prescribed mass \(\beta/2\). Each tiling contributes occupancy \(\beta/2\) almost everywhere on \([0,H]\), so their combined occupancy is \(\beta\).

Finally, put an atom of mass \(\mu_0\) at the unique permitted start \(H\) of type \(t_0\). Its occupancy equals \(\mu_0\) almost everywhere on \([H,1]\).

Thus all types are served fully, with feasible capacity usage. The finitely many interval endpoints cause no difficulty because feasibility is required only almost everywhere.

We have proved

\(\displaystyle \text{PARTITION is feasible} \quad\Longleftrightarrow\quad \text{the constructed society admits full service}. \)

5. Passing to the lexicographic objective

Let \(\boldsymbol{\mu}\) be the prescribed mass vector in the supplied type order. Every feasible served-mass vector is bounded coordinatewise by \(\boldsymbol{\mu}\).

Consequently, if full service is feasible, \(\boldsymbol{\mu}\) is the lexicographic optimum. Conversely, an attained lexicographic optimum equal to \(\boldsymbol{\mu}\) certifies full-service feasibility.

The next section establishes attainment and an exact finite formulation. Therefore,

\(\displaystyle \text{PARTITION is feasible} \quad\Longleftrightarrow\quad \text{the exact lexicographic optimum equals }\boldsymbol{\mu}. \)

This argument optimizes over all start measures simultaneously. It respects the permission to rearrange earlier types’ measures while fixing their served masses.

Reduction size and running time

Each integer used in the construction has bit length

\(\displaystyle O\bigl(n\log(n+1)+\log W\bigr).\)

Thus the constructed allocation instance has total input length

\(\displaystyle L=O\bigl(n^2\log(n+1)+n\log W\bigr).\)

The construction uses polynomially many arithmetic operations on integers of polynomial bit length, so it is computable in polynomial time in the PARTITION input length.

An exact allocation algorithm running in \(\operatorname{poly}(m,\tau,L)\) time would therefore decide PARTITION in polynomial time: construct this instance, compute its optimum, and compare it with \(\boldsymbol{\mu}\). This proves the claimed NP-hardness.

6. An exact finite formulation and upper bound

For piecewise constant capacity profiles, there is an exact finite LP formulation. Its grid size can be exponential in the input bit length, so it does not contradict the reduction.

Choose a common denominator \(D\) for all window endpoints, lengths, and capacity breakpoints, and set \(h=1/D\). Every relevant coordinate is then a grid point, and every duration is an integer multiple of \(h\).

Rounding claim. Mapping every start \(a\) to \(h\lfloor a/h\rfloor\) preserves served masses and feasibility.

First, this map preserves the permitted start domain because both endpoints of \(A_t\) are grid points.

To check capacity, consider a grid cell with right endpoint \(c\). For a type whose duration is a multiple of \(h\), its rounded occupancy at any interior point of this cell is exactly

\(\displaystyle \lambda_t([c-d_t,c)\cap A_t).\)

Choose feasible points approaching \(c\) from the left within the cell. The original occupancy indicators converge pointwise to the indicator of \([c-d_t,c)\). Bounded convergence shows that the total rounded occupancy is the limit of the original occupancies at those points. Each is bounded by the cell’s constant capacity, so the rounded allocation is feasible. Served masses are preserved by pushforward. ∎

Hence it suffices to use one nonnegative LP variable for each permitted type-and-grid-start pair. Impose one capacity inequality per grid cell and one mass inequality per type. Conversely, every feasible solution of this LP gives a feasible atomic allocation.

The LP has at most \(\tau(D+1)\) variables and \(D+\tau\) inequalities. It is nonempty and bounded, so successive maximization of the \(\tau\) served-mass objectives attains the lexicographic optimum and gives exact rational values.

Standard rational LP algorithms give an exact running time polynomial in \(m,\tau,D,L\), including the successive optimizations. Taking the product of the encoded denominators ensures \(D\leq2^{O(L)}\). Thus an upper bound is

\(\displaystyle \operatorname{poly}(m,\tau,L)\,2^{O(L)}.\)

The established classification is NP-hard, already for two capacity pieces. A running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
