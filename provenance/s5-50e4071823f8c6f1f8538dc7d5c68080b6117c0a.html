The continuous mirror question, as graded

Given a finite institution set \(I\), a finite type set \(T\), an owner \(o(t)\in I\) for each type, rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), and a compatibility relation \(\Gamma\) on types, decide whether there is a feasible mass matching \(x\) with no blocking coalition. A feasible \(x\) assigns nonnegative mass \(x_{tu}\) to each compatible unordered type pair, consuming \(2x_{tt}+\sum_{u\ne t}x_{tu}\le\mu_t\) of type \(t\); institution \(i\)’s utility is the total mass of its types matched. A coalition \(S\subseteq I\) blocks if a feasible mass matching \(y\), using only types owned by \(S\), gives every \(i\in S\) strictly more matched mass than \(x\).

Packaged proof task (what the prover saw — nothing else)

Let \(I\) be a nonempty institution set, with \(m=|I|\). A society is given by its support: a list \(T\) of \(\tau\) types with positive masses \(\mu_t\in\mathbb{Q}_{>0}\) encoded in binary, where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Each type has an owner \(o(t)\in I\), and every institution owns a positive-mass type.
An explicitly given symmetric compatibility relation specifies allowed unordered pairs, including optional pairs \(\{t,t\}\), which represent exchanges between distinct individuals of the same type.
A mass matching has real coordinates \(x_{tu}\geq0\) on compatible pairs, with all other coordinates zero, and satisfies \(d_t(x):=2x_{tt}+\sum_{u\ne t}x_{tu}\leq\mu_t\). Institution \(i\) receives utility \(u_i(x):=\sum_{o(t)=i}d_t(x)\).
A nonempty coalition \(S\subseteq I\) blocks \(x\) if another feasible mass matching \(y\), using only types owned by \(S\) and their original capacities, satisfies \(u_i(y)>u_i(x)\) for every \(i\in S\). The weak core consists of matchings with no such coalition.

Is deciding whether this weak core is nonempty in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and the total binary input length \(L\).

For indivisible vertices, weak-core nonemptiness is \(\mathrm{NP}\)-hard even when each institution owns at most seven vertices. [Csáji–Király–Mészáros-Karkus](https://arxiv.org/abs/2409.01452)
Biró–Fleiner establish existence for a fractional NTU core defined through activity domination; that definition differs from the aggregate-utility blocking condition above. No result settling this exact mass problem was located. [Biró–Fleiner](https://real.mtak.hu/26264/7/BF16do_last.pdf)

Modeling choices made when packaging the task

  • Remove zero-mass types from the supplied list so that it is exactly the positive-mass support.
  • Require a nonempty institution set and positive total mass for every institution, reflecting nonempty partition classes.
  • Take compatibility to be symmetric and explicitly encoded; diagonal compatibility permits matching distinct individuals of the same type.
  • Allow real matching coordinates, since only the input masses were specified as rational.
  • Require blocking coalitions to be nonempty, excluding vacuous blocking by the empty coalition.

Result

The weak core is always nonempty. Consequently, deciding nonemptiness is in \(\mathrm{P}\).

The crucial property is balancedness of the ordinary NTU game defined by aggregate institution utilities. This follows directly from averaging feasible mass matchings with balanced coalition weights.

1. The associated NTU game

For each nonempty coalition \(S\subseteq I\), let \(P(S)\) denote its feasible mass matchings, extended by zero on all pairs involving a type owned outside \(S\). Define

\(V(S):=\{v\in\mathbb{R}^{S}:\text{there exists }y\in P(S)\text{ with }v_i\leq u_i(y)\text{ for every }i\in S\}.\)

This downward closure is an auxiliary construction; it does not change the blocking definition. Indeed, a vector \(v\in V(S)\) strictly exceeding a proposed utility vector is witnessed by an actual matching whose utilities also strictly exceed that vector.

Write \(M_i:=\sum_{o(t)=i}\mu_t\). We verify the regularity conditions for an NTU core existence theorem.

  • Nonemptiness and compact matching sets. The zero matching belongs to \(P(S)\). The set \(P(S)\) is closed, since it is defined by finitely many non-strict linear inequalities. Every coordinate is bounded: for a non-loop pair, \(y_{tu}\leq\min\{\mu_t,\mu_u\}\), and for a loop, \(y_{tt}\leq\mu_t/2\). Thus \(P(S)\) is compact.
  • Comprehensiveness. If \(v\in V(S)\) and \(w\leq v\) coordinatewise, the matching witnessing membership of \(v\) also witnesses membership of \(w\).
  • Closedness. Suppose \(v^{(k)}\in V(S)\) converges to \(v\), and choose witnesses \(y^{(k)}\in P(S)\). Compactness provides a convergent subsequence with limit \(y\in P(S)\). Since utilities are linear and hence continuous, \(u_i(y)\geq v_i\) for every \(i\in S\). Therefore \(v\in V(S)\).
  • Upper bounds and individual rationality. Every \(v\in V(S)\) satisfies \(v_i\leq M_i\). Let \(b_i:=\max_{y\in P(\{i\})}u_i(y)\), which exists by compactness. Singleton maximizing matchings use disjoint type sets, so their sum is feasible for \(S\). Hence the individually rational portion

\(V(S)\cap\prod_{i\in S}[b_i,\infty)\)
is nonempty, closed, and contained in the bounded box \(\prod_{i\in S}[b_i,M_i]\).

Disjoint coalition matchings can also be added, so the game is superadditive.

2. Balancedness

A family of nonnegative weights \(\lambda_S\), indexed by nonempty coalitions, is balanced when

\(\sum_{S\ni i}\lambda_S=1\qquad\text{for every }i\in I.\)

The game is balanced in Scarf’s sense if, whenever a common vector \(q\in\mathbb{R}^{I}\) satisfies \(q|_S\in V(S)\) for every coalition with positive weight, then \(q\in V(I)\).

Fix such weights and such a vector \(q\). For each \(S\) with \(\lambda_S>0\), choose \(y^S\in P(S)\) satisfying

\(u_i(y^S)\geq q_i\qquad(i\in S).\)

Define the coordinatewise weighted sum

\(z:=\sum_{S:\lambda_S>0}\lambda_S y^S.\)

It has nonnegative coordinates and uses only compatible pairs. For any type \(t\), a matching \(y^S\) has \(d_t(y^S)=0\) unless \(o(t)\in S\). Consequently, by linearity,

\(d_t(z)=\sum_{S\ni o(t)}\lambda_S d_t(y^S)\leq\mu_t\sum_{S\ni o(t)}\lambda_S=\mu_t.\)

This calculation also covers loops, since their contribution \(2y_{tt}\) is linear. Thus \(z\in P(I)\).

Similarly, an institution outside \(S\) receives zero utility from \(y^S\). Therefore, for every \(i\in I\),

\(u_i(z)=\sum_{S\ni i}\lambda_Su_i(y^S)\geq\sum_{S\ni i}\lambda_Sq_i=q_i.\)

Hence \(q\in V(I)\), proving balancedness. The identical argument applies within every nonempty institution subset.

3. Applying the ordinary NTU core theorem

Scarf’s balanced NTU core theorem states that a finite balanced NTU game with nonempty, closed, comprehensive coalition utility sets and bounded individually rational portions has a nonempty core under blocking that strictly improves every coalition member. This is the ordinary NTU core theorem, recalled separately from the activity-based fractional core in [Biró–Fleiner, introduction and Section 2.1](https://real.mtak.hu/26264/7/BF16do_last.pdf).

All its hypotheses were checked above. It therefore supplies \(v^\star\in V(I)\) such that no nonempty \(S\subseteq I\) admits \(w\in V(S)\) with

\(w_i>v^\star_i\qquad\text{for every }i\in S.\)

By the definition of \(V(I)\), choose an actual matching \(x^\star\in P(I)\) with \(u_i(x^\star)\geq v^\star_i\) for every institution.

If a coalition \(S\) blocked \(x^\star\) through \(y\in P(S)\), then

\(u_i(y)>u_i(x^\star)\geq v^\star_i\qquad(i\in S).\)

But \(u(y)|_S\in V(S)\), contradicting the core property of \(v^\star\). Thus \(x^\star\) belongs to the weak core specified in the task.

The final step is necessary: it converts a core point of the auxiliary downward-closed utility game into a feasible matching with the required aggregate utilities.

4. Running time and scope

On the promised domain of valid inputs, the decision algorithm simply returns YES. Its running time is \(\mathrm{O}(1)\), independently of \(m\), \(\tau\), and \(L\). If the implementation reads the entire input before answering, its running time is \(\mathrm{O}(L)\). Validating the binary rational data, if required, can be done in \(\operatorname{poly}(L)\) time.

These bounds concern deciding nonemptiness. The existence proof does not establish a polynomial-time algorithm for constructing a core matching.

The substantive reason the indivisible hardness does not carry over is the averaging step: \(z=\sum_S\lambda_Sy^S\) is an admissible mass matching, whereas a weighted sum of indivisible matchings need not be an admissible indivisible matching.
