The continuous mirror question, as graded

Given a finite set of role types \(T\), rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), and strict type rankings inducing the paper's \(\mathcal B\)-preferences, does there exist a finite-support family of rational frequencies \(q_v\ge 0\) over nonzero integer team profiles \(v\in\mathbb Z_{\ge 0}^{T}\) such that \(\sum_v q_vv_t=\mu_t\) for every type \(t\), and no member of any used team profile can move to another used profile or form a singleton, strictly improve, and be accepted by every member of the receiving team?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(m=|T|=\tau\); \(\tau\) counts supported types, not possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Each type \(t\) has a strict ranking of \(T\cup\{a_t\}\), where \(a_t\) represents being alone. A teammate type is unacceptable precisely when ranked below \(a_t\); other members of one's own type are evaluated by their type label.
A team profile is any \(v\in\mathbb Z_{\geq0}^{T}\setminus\{0\}\), with no size bound. Write \(e_t\) for the unit vector of type \(t\). For a member of type \(t\), evaluate teammates in \(v-e_t\): any unacceptable teammate makes the profile unacceptable. All unacceptable profiles are tied below all acceptable profiles. Among acceptable profiles, compare the highest-ranked teammate type, using \(a_t\) when there are no teammates; equal best types give indifference, without a size tie-break. Denote this profile preference by \(\succeq_t^B\).
An allocation consists of finitely supported rational frequencies \(q_v\geq0\) satisfying \(\sum_v q_vv_t=\mu_t\) for every \(t\). Frequencies measure teams and need not sum to one; a profile is used when \(q_v>0\).
The allocation is individually stable if no used \(v\) and type \(t\) with \(v_t>0\) satisfy either \(e_t\succ_t^B v\), or, for some used receiving profile \(w\), both \(w+e_t\succ_t^B v\) and \(w+e_t\succeq_s^B w\) for every \(s\) with \(w_s>0\). A receiving team is distinct from the departing team but may have the same profile, so \(w=v\) is allowed. Departing teammates have no veto.

Is deciding whether such an individually stable mass allocation exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite societies, individually stable partition existence under these veto-based best-member preferences is \(\mathrm{NP}\)-complete even with strict rankings over players ([source](https://arxiv.org/html/1105.1824v2)). No result settling exactly the mass-allocation problem above was located in the literature search.

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when every supported type has the same mass.

The proof adapts the clause-and-variable construction of [Aziz, Harrenstein, and Pyrga, Theorem 5.1](https://arxiv.org/html/1105.1824v2). Two changes are essential for mass allocations: literal types accept their own type, and one type in each clause gadget accepts its own type. The argument below proves directly that these changes prevent fractional allocations from bypassing the construction.

1. Two elementary properties

Call a profile individually rational if every member regards it as acceptable. Every used profile in an individually stable allocation is individually rational: a member of an unacceptable profile strictly prefers being alone.

For an individually rational receiving profile \(w\), its incumbents accept the addition of type \(t\) precisely when every incumbent type ranks \(t\) above its alone option. Indeed:

  • An incumbent who finds \(t\) unacceptable obtains an unacceptable profile and strictly loses.
  • Otherwise, adding an acceptable teammate preserves acceptability and cannot worsen the best teammate.

We use these observations throughout.

2. The reduction

2.1. The source problem

We reduce from satisfiability of CNF formulas satisfying these conditions:

  • Every clause is nonempty and contains no repeated literal or complementary pair.
  • Every variable occurs with both polarities.

This restriction remains \(\mathrm{NP}\)-hard. To see this, start with a \(3\)-SAT instance and remove tautological clauses and repeated literals. Introduce fresh variables \(h,k\), add the clauses

\[ (h),\qquad(k),\qquad(\neg h\vee k),\qquad(\neg k\vee h), \]

and, for every original variable \(p\), add

\[ (p\vee h),\qquad(\neg p\vee h). \]

The new clauses force \(h,k\) to be true and otherwise impose no restriction on the original variables. Both polarities of every variable now occur, and no added clause contains a complementary pair.

Let the resulting formula have \(n\) variables, \(k\) clauses, and \(d\) literal occurrences.

2.2. Types and masses

Introduce:

  • An anchor type \(c_p\) for each variable \(p\).
  • A separate occurrence type \(\ell_{X,p,\sigma}\) for each occurrence of polarity \(\sigma\in\{+,-\}\) of variable \(p\) in clause \(X\).
  • Five gadget types \(b_1^X,\ldots,b_5^X\) for each clause \(X\).

Write \(C_p^\sigma\) for all occurrence types of variable \(p\) with polarity \(\sigma\), \(\mathcal O\) for all occurrence types, and \(\mathcal D_X\) for the occurrence types belonging to clause \(X\).

There are \(N=5k+n+d\) types. Give every type mass \(1/N\). Thus \(m=\tau=N\).

2.3. Strict rankings

In the lists below, a bracketed set means its members are placed in any fixed strict order. Empty sets are omitted. Every unlisted type is placed below the alone option, in an arbitrary strict order.

For an occurrence type \(\ell=\ell_{X,p,\sigma}\), use

\[ c_p \succ_\ell [C_p^\sigma\setminus\{\ell\}] \succ_\ell b_1^X \succ_\ell [\mathcal O\setminus(C_p^+\cup C_p^-)] \succ_\ell \ell \succ_\ell a_\ell. \]

In particular, opposite polarities of the same variable are unacceptable to one another, whereas an occurrence type accepts its own type.

For the anchor \(c_p\), use

\[ [C_p^+\cup C_p^-]\succ_{c_p}a_{c_p}. \]

The anchor finds its own type unacceptable.

For each clause \(X\), use

\[ b_2^X \succ_{b_1^X}[\mathcal D_X] \succ_{b_1^X}b_5^X \succ_{b_1^X}b_1^X \succ_{b_1^X}a_{b_1^X}, \]

and

\[ b_{i+1}^X\succ_{b_i^X}b_{i-1}^X\succ_{b_i^X}a_{b_i^X} \qquad(i\in\{2,3,4\}), \]

with

\[ b_1^X\succ_{b_5^X}b_4^X\succ_{b_5^X}a_{b_5^X}. \]

Among the gadget types, only \(b_1^X\) accepts its own type.

3. The clause gadget forces a literal

We prove the structural property needed for the reduction.

Lemma. In every individually stable allocation of the constructed instance, for every clause \(X\):

  • All mass of \(b_2^X,b_3^X\) is assigned to the profile \(e_{b_2^X}+e_{b_3^X}\).
  • All mass of \(b_4^X,b_5^X\) is assigned to the profile \(e_{b_4^X}+e_{b_5^X}\).
  • Every used profile containing \(b_1^X\) contains at least one occurrence type from \(\mathcal D_X\).

Proof. Fix \(X\), abbreviate its gadget types by \(1,\ldots,5\), and put \(c=1/N\).

Individual rationality and the rankings imply that the only possible used profiles involving types \(2,\ldots,5\) are:

| Member type | Possible profiles |
|---|---|
| \(2\) | \(e_2,\ e_2+e_3,\ h e_1+e_2\) |
| \(3\) | \(e_3,\ e_2+e_3,\ e_3+e_4\) |
| \(4\) | \(e_4,\ e_3+e_4,\ e_4+e_5\) |
| \(5\) | \(e_5,\ e_4+e_5,\ h e_1+e_5\) |

Here \(h\geq1\) is an integer. Types \(2,\ldots,5\) cannot occur twice because they reject their own type. Their rankings exclude outside types, and individual rationality excludes triples of consecutive gadget types.

First suppose that some profile \(h e_1+e_2\) is used. Any member of type \(1\) outside a profile containing type \(2\) would strictly prefer joining this receiving profile: type \(2\) is its highest-ranked teammate, and both incumbent types accept another type-\(1\) member. Consequently, all mass of type \(1\) must be in profiles containing type \(2\). In particular, no profile containing both \(1\) and \(5\) is used.

Type \(5\) is therefore assigned only to \(e_5\) and \(e_4+e_5\). If \(e_5\) is used, every type-\(4\) member outside \(e_4+e_5\) can strictly improve by joining it, with consent. Hence all type-\(4\) mass must be in \(e_4+e_5\). Its frequency must then equal \(c\), exhausting the entire type-\(5\) mass and contradicting positive frequency of \(e_5\).

Thus \(e_5\) is absent. All type-\(5\) mass, and therefore all type-\(4\) mass, is in \(e_4+e_5\).

Type \(3\) can now occur only in \(e_3\) or \(e_2+e_3\). If \(e_3\) is used, a type-\(2\) member of the assumed profile \(h e_1+e_2\) can strictly improve by joining it, with consent. Therefore \(e_3\) is absent. All type-\(3\) mass is in \(e_2+e_3\), whose frequency must equal \(c\). This exhausts the type-\(2\) mass, contradicting the assumed used profile \(h e_1+e_2\).

We have proved that no profile containing both \(1\) and \(2\) is used.

Next, \(e_2\) cannot be used. Type \(1\) has positive mass, and every type-\(1\) member currently has a best teammate below type \(2\). Such a member could join \(e_2\), strictly improving and receiving consent. Hence all type-\(2\) mass lies in \(e_2+e_3\). Equal masses force all type-\(3\) mass into the same profile.

If \(e_4\) were used, a type-\(3\) member of \(e_2+e_3\) could strictly improve by joining it, with consent. Thus \(e_4\) is absent. Since type \(3\) is entirely in \(e_2+e_3\), type \(4\) must be entirely in \(e_4+e_5\). Equal masses then put all type-\(5\) mass there too.

A profile containing type \(1\) consequently contains neither \(2\) nor \(5\). Its only possible other labels are occurrence types from \(\mathcal D_X\). Suppose such a profile has no occurrence type; it is then \(h e_1\). A type-\(5\) member of \(e_4+e_5\) strictly prefers joining it. Every incumbent type-\(1\) member consents because type \(5\) ranks above both the own-type label and the alone option. This contradicts stability.

Every used profile containing type \(1\) therefore contains a clause occurrence type. This proves the lemma. \(\square\)

4. Correctness of the reduction

4.1. A satisfying assignment gives a stable allocation

Let \(f\) be a satisfying assignment. Construct the following teams:

  • For each clause \(X\), the pairs \(\{b_2^X,b_3^X\}\) and \(\{b_4^X,b_5^X\}\).
  • For each clause \(X\), one team containing \(b_1^X\) and all occurrence types in \(\mathcal D_X\) whose literals are true under \(f\).
  • For each variable \(p\), one team containing \(c_p\) and all occurrence types of \(p\) whose literals are false under \(f\).

Every type occurs exactly once. Giving each resulting profile frequency \(1/N\) therefore supplies precisely the required masses. Every clause team contains an occurrence type, and every anchor team contains occurrence types because both polarities occur.

All these profiles are individually rational. We check all possible strict improvements.

An occurrence type in an anchor team already has its highest-ranked teammate, \(c_p\). An occurrence type in a clause team has best teammate \(b_1^X\). Its only higher-ranked labels are:

  • Its anchor, whose team contains opposite-polarity occurrence types that it rejects.
  • Other occurrence types of its own variable and polarity. Each such occurrence belongs to a different clause and is accompanied by that other clause’s \(b_1\) type, which the departing occurrence rejects.

Thus occurrence types cannot improve feasibly.

An anchor accepts only occurrence types of its own variable. Every receiving team other than its current profile contains an unacceptable label: either another anchor, a gadget type, or the \(b_1\) type accompanying a true occurrence. Joining its own profile would introduce an unacceptable second anchor.

For the clause gadget:

  • Type \(b_2^X\) has its highest-ranked teammate.
  • Type \(b_3^X\) could improve only through \(b_4^X\), whose team contains unacceptable \(b_5^X\).
  • Type \(b_4^X\) has its highest-ranked teammate.
  • Type \(b_5^X\) could improve only through \(b_1^X\), whose team contains unacceptable occurrence types.
  • Type \(b_1^X\) could improve through \(b_2^X\), but that team contains unacceptable \(b_3^X\). Any higher-ranked clause occurrence absent from its current team is in an anchor team containing an unacceptable anchor.

Finally, joining another team of the same profile cannot create a strict improvement: it either preserves the best teammate or introduces an unacceptable own-type copy.

There is no permitted strict improvement, including one with receiving profile equal to the departing profile. The allocation is individually stable.

4.2. A stable allocation gives a satisfying assignment

Let an individually stable allocation exist.

For each variable \(p\), choose any used profile \(W_p\) containing \(c_p\); one exists because its mass is positive. Individual rationality implies:

  • \(W_p\) contains exactly one anchor.
  • Its other members, if any, are occurrence types of \(p\).
  • Those occurrence types all have one polarity, since opposite polarities reject one another.

Suppose \(W_p\) contains polarity \(\sigma\). No occurrence type \(\ell_{X,p,\sigma}\) can occur in a used profile containing \(b_1^X\). Otherwise, that occurrence strictly prefers joining \(W_p\), obtaining its highest-ranked teammate \(c_p\). The destination is acceptable to it, even if another copy of its own type is already there. All incumbents consent: the anchor accepts it, and same-polarity occurrence types accept it.

If \(W_p\) is a singleton anchor, the same argument excludes both polarities from profiles containing their clause’s \(b_1\) type.

Define an assignment by making polarity opposite to the one in \(W_p\) true. If \(W_p\) is a singleton, assign \(p\) arbitrarily.

By the clause lemma and positive mass of \(b_1^X\), every clause \(X\) has a used profile containing \(b_1^X\) and at least one occurrence type. Every such occurrence has the polarity made true by the assignment above. Thus every clause is satisfied.

This proves the equivalence and establishes \(\mathrm{NP}\)-hardness.

5. Membership in \(\mathrm{NP}\)

Unbounded team sizes require a certificate argument; merely guessing bounded profiles would not suffice.

5.1. Finite behavioral patterns

For a profile \(v\), define its pattern by

\[ b(v)_t=\min\{v_t,2\}. \]

The pattern records absence, exactly one member, or at least two members of each type.

A member’s evaluation of \(v\) depends only on \(b(v)\): the teammate labels are determined by this information, including whether another member of its own type is present.

For a move into \(w\), the entering member evaluates the labels present in \(w\), while incumbent consent is characterized in Section 1. Both depend only on the patterns of the departing and receiving profiles. Consequently, stability depends only on the set of used patterns.

Furthermore, deleting profiles and reweighting the remaining profiles preserves stability whenever the mass equations remain satisfied.

Any feasible allocation can be reduced to at most \(m\) used profiles. Indeed, if more than \(m\) profile vectors are used, they are linearly dependent. Choose a nonzero rational dependence \(\sum_v\alpha_vv=0\). Its coefficients have both signs because the profile vectors are nonzero and nonnegative. Subtract a suitable multiple of this dependence from the positive frequencies so that all frequencies remain nonnegative and at least one becomes zero. Iterate. Thus an existing stable allocation uses at most \(m\) patterns.

5.2. Realizing selected patterns by a small rational allocation

Fix \(r\leq m\) patterns \(b^1,\ldots,b^r\), each individually rational and mutually stable, including each pattern’s comparison with itself. Put

\[ D_j=\{t:b_t^j=2\}. \]

For pattern \(j\), let \(x_j\) denote total team frequency, and let \(z_{jt}\) denote mass beyond its base count in coordinate \(t\in D_j\). The mass equations become

\[ \mu_t=\sum_{j=1}^r b_t^j x_j+ \sum_{j:t\in D_j}z_{jt}. \]

Require \(z_{jt}\geq0\) and strictly positive \(x_j\). Test the latter by maximizing \(\delta\) subject to \(x_j\geq\delta\geq0\).

There are polynomially many variables and constraints, with polynomial input bit length. The feasible region is bounded: summing the mass equations gives

\[ 1=\sum_j\|b^j\|_1x_j+\sum_{j,t}z_{jt}. \]

Since every pattern is nonzero, all variables, including \(\delta\), are bounded by \(1\). If the selected patterns occur in an allocation, the optimum has \(\delta>0\).

A rational optimal vertex has polynomial bit length. This follows from Cramer’s rule applied to a nonsingular system defining that vertex: its dimension and coefficient bit lengths are polynomial in \(m,L\).

It remains to realize these variables by integer profiles. For each \(j\), choose

\[ K_j=\max\left\{1,\left\lceil \frac{\sum_{t\in D_j}z_{jt}}{x_j} \right\rceil\right\}. \]

Use the profile \(b^j+K_je_t\) with frequency \(z_{jt}/K_j\) for each \(t\in D_j\), and the profile \(b^j\) with frequency

\[ x_j-\sum_{t\in D_j}\frac{z_{jt}}{K_j}. \]

The final frequency is nonnegative by the choice of \(K_j\). These profiles all have pattern \(b^j\), and their mass contribution is exactly the prescribed base mass plus \(z_{jt}\). Their total frequency is \(x_j>0\).

This constructs a stable rational allocation using at most \(m(m+1)\) profiles, with polynomial bit length for all counts and frequencies.

Such a certificate can be verified in polynomial time by checking the mass equations, individual rationality, and every departure-type/receiving-profile combination. Hence the problem belongs to \(\mathrm{NP}\).

6. Running times and conclusion

The hardness construction has \(m=\tau=5k+n+d\). Its explicit rankings and masses have bit length \(L=O(m^2\log(m+1))\), and the construction takes \(O(m^2\log(m+1))\) bit operations.

Certificate verification takes \(\operatorname{poly}(m,\tau,L)\) time.

The pattern argument also supplies a deterministic algorithm: enumerate sets of at most \(m\) patterns among the \(3^m-1\) nonzero patterns, check stability, and solve the corresponding linear program. Its running time is

\[ 2^{O(\tau^2)}\operatorname{poly}(m,\tau,L), \]

using \(m=\tau\).

Together, the reduction and certificate argument establish \(\mathrm{NP}\)-completeness for exactly the mass-allocation problem stated, even with equal positive masses and strict rankings.
