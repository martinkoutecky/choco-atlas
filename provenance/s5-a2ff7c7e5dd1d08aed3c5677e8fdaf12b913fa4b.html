The continuous mirror question, as graded

Given a finite path of locations, object classes \(\mathcal O\), and types \(t=(v,\succeq_t,e_t)\) with rational initial masses \(\mu_t\), a target type \(t^\star\), target class \(o^\star\), and rational threshold \(\theta>0\), is there a finite sequence of mass swaps after which at least \(\theta\) mass of type \(t^\star\) holds \(o^\star\)? A swap chooses types at adjacent locations currently holding classes \(a,b\) and exchanges equal mass \(\delta\) when \(b\succeq_t a\) and \(a\succeq_{t'} b\).

Packaged proof task (what the prover saw — nothing else)

Let the locations form the path \(1,\ldots,q\), and let \(\mathcal O\) contain \(m\) object classes. A type \(t=(v_t,\succeq_t,e_t)\) has a fixed location, a weak preference order over all classes, and an initial endowed class \(e_t\in\mathcal O\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
A state records nonnegative real masses \(x_{t,o}\), with \(\sum_o x_{t,o}=\mu_t\); initially \(x_{t,e_t}=\mu_t\) and all other entries vanish. Each unit of society mass holds one unit of object mass.
A swap selects types \(t,t'\) with \(|v_t-v_{t'}|=1\), distinct classes \(a,b\), and real mass \(0<\delta\le\min(x_{t,a},x_{t',b})\), provided \(b\succeq_t a\) and \(a\succeq_{t'}b\). It subtracts \(\delta\) from \(x_{t,a},x_{t',b}\) and adds it to \(x_{t,b},x_{t',a}\). Indifference for both participants is allowed; types and locations remain fixed.
Given a supported target type \(t^\star\), a target class \(o^\star\), and a binary rational threshold \(\theta>0\), mass-swap reachability asks whether some finite sequence of swaps, possibly empty, reaches \(x_{t^\star,o^\star}\ge\theta\); limiting states alone do not qualify.

Is mass-swap reachability on paths solvable in polynomial time in \(m,\tau,q,L\), or is it NP-hard?

Discrete object reachability with weak preferences is NP-hard even on paths. [Huang–Xiao](https://arxiv.org/html/1909.07557v2)
Continuous Petri-net reachability is polynomial-time decidable, a related result for a different problem. [Blondin–Haase](https://www.cs.ox.ac.uk/people/christoph.haase/home/publication/bh-17/bh-17.pdf) No result for exactly the mass-swap problem above was located.

Result

Mass-swap reachability on paths is polynomial-time solvable in \(m,\tau,q,L\). The proof reduces the question to finite reachability in a continuous Petri net. In particular, it preserves the requirement that the threshold be attained by a finite sequence.

1. The continuous Petri-net theorem used

A continuous Petri net has finitely many places and transitions, with nonnegative integer input and output vectors \(\operatorname{Pre}_r,\operatorname{Post}_r\) for each transition \(r\). At a nonnegative marking \(z\), firing \(r\) by a rational amount \(\alpha\in(0,1]\) is permitted when \(z\ge\alpha\operatorname{Pre}_r\), and produces \(z+\alpha(\operatorname{Post}_r-\operatorname{Pre}_r)\).

We use the following established theorem:

Given such a net and two nonnegative rational markings, all encoded in binary, existence of a finite firing sequence between them is decidable in polynomial time.

This follows from Theorems 3.3 and 3.6 of [Blondin–Haase, *Logics for Continuous Reachability in Petri Nets and Vector Addition Systems with States*](https://www.cs.ox.ac.uk/people/christoph.haase/home/publication/bh-17/bh-17.pdf). Their Section II-A defines reachability using finite firing sequences with the semantics above.

We next verify that this theorem applies to the problem as stated.

2. Swaps are exactly Petri-net transitions

Let \(S\) be the set of supported types. Construct a net \(N\) with place set \(P=S\times\mathcal O\). Interpret the marking of place \((t,o)\) as \(x_{t,o}\).

For every tuple \((t,t',a,b)\) satisfying

\(\lvert v_t-v_{t'}\rvert=1,\qquad a\ne b,\qquad b\succeq_t a,\qquad a\succeq_{t'}b,\)

include a transition whose input places are \((t,a)\) and \((t',b)\), each with coefficient one, and whose output places are \((t,b)\) and \((t',a)\), each with coefficient one. All other coefficients are zero.

These four places are distinct: adjacency implies \(t\ne t'\), and the construction requires \(a\ne b\). Consequently, firing this transition by amount \(\delta\) is enabled exactly when

\(0<\delta\le\min(x_{t,a},x_{t',b}),\)

and its effect is exactly the prescribed swap.

Set the initial marking to \(u_{t,o}=\mu_t\) when \(o=e_t\), and to zero otherwise.

Every transition preserves each type’s total mass. Indeed, for each participating type, it consumes and produces the same amount. Thus every marking reachable in \(N\) satisfies

\(\sum_{o\in\mathcal O}x_{t,o}=\mu_t\quad\text{for every }t\in S.\)

It also preserves the total mass of every object class. In particular, every reachable marking is a valid society state, and its total mass is one. Every enabled firing therefore has amount at most one.

Hence finite rational firing sequences in \(N\) correspond exactly to finite swaps with rational amounts. Weak preferences, including mutual indifference, are captured by the two preference tests in the construction.

3. Real firing amounts do not change the answer

The problem permits real swap amounts, whereas the theorem above uses rational amounts. The following argument bridges that difference without replacing reachability by its closure.

Lemma. If a finite real-valued swap sequence attains \(x_{t^\star,o^\star}\ge\theta\), then a finite rational-valued swap sequence does so.

Proof. An empty witnessing sequence already has a rational final state. Otherwise, fix the transitions \(r_1,\ldots,r_k\) of a witnessing sequence, and let its positive real amounts be \(\delta_1,\ldots,\delta_k\).

Write \(c_i=\operatorname{Post}_{r_i}-\operatorname{Pre}_{r_i}\). For variable amounts \(d_1,\ldots,d_k\), the marking immediately before transition \(r_i\) is

\(u+\sum_{j<i}d_jc_j.\)

Thus enablement of the fixed sequence is expressed by the linear inequalities

\(u+\sum_{j<i}d_jc_j\ge d_i\operatorname{Pre}_{r_i}\quad\text{for }i=1,\ldots,k.\)

The target condition is the linear inequality

\(\left(u+\sum_{i=1}^kd_ic_i\right)_{t^\star,o^\star}\ge\theta.\)

All coefficients and constants are rational. Choose a positive rational \(\varepsilon<\min_i\delta_i\), and add the inequalities \(d_i\ge\varepsilon\). The resulting rational polyhedron is nonempty, since it contains \((\delta_1,\ldots,\delta_k)\).

For completeness, every nonempty polyhedron defined by rational linear inequalities contains a rational point. To see this, take any real feasible point and impose as equalities all inequalities tight there. Gaussian elimination gives a rational particular solution and a rational basis for the resulting affine space. Rational points are therefore dense in that affine space. A sufficiently close rational point preserves all remaining inequalities, since each has positive slack at the chosen point.

Apply this fact to obtain rational amounts \(d_1,\ldots,d_k\). They are positive, satisfy every enablement constraint, and attain the threshold. Each intermediate marking is nonnegative and preserves total mass one, so these amounts are also at most one. They therefore give a valid rational swap sequence. \(\square\)

The converse is immediate because rational amounts are real amounts. Thus the two versions have identical yes-instances.

4. Reducing the threshold to a fixed final marking

Let \(p^\star=(t^\star,o^\star)\). Define the rational marking \(w\) by

\(w_{p^\star}=\theta,\qquad w_p=0\quad\text{for every }p\ne p^\star.\)

Construct an auxiliary net \(N^-\) by adding, for every place \(p\in P\), a deletion transition \(d_p\) that consumes one unit from \(p\) and produces nothing.

We claim:

\(N\text{ has a finite rational run from }u\text{ to some }x\text{ with }x_{p^\star}\ge\theta\)

if and only if

\(N^-\text{ has a finite rational run from }u\text{ to }w.\)

Forward implication. Suppose \(N\) reaches such an \(x\). Since every coordinate of \(x\) is nonnegative, \(x\ge w\). For each place \(p\), append a deletion firing of amount \(x_p-w_p\), omitting it when that amount is zero.

Each deletion is enabled and has rational amount at most one, since \(x\) has total mass one. These finitely many deletions leave exactly \(w\).

Reverse implication. Suppose \(N^-\) reaches \(w\). Remove every deletion firing from this finite sequence, retaining all swap transitions and their amounts. We show that the retained sequence is enabled in \(N\).

Process the auxiliary sequence in order. Let \(y\) be its current marking, and let \(z\) be the marking obtained by executing only its swap firings so far. Maintain the invariant \(z\ge y\), which initially holds with equality.

If the next auxiliary firing is a deletion, leave \(z\) unchanged. The marking \(y\) decreases, so domination remains true.

If the next firing is a swap transition \(r\) of amount \(\alpha\), its enablement at \(y\) gives

\(y\ge\alpha\operatorname{Pre}_r.\)

Because \(z\ge y\), the same firing is enabled at \(z\). Both markings then change by the same vector \(\alpha(\operatorname{Post}_r-\operatorname{Pre}_r)\), preserving domination.

This proves the invariant inductively. At the end, the retained finite sequence reaches a marking \(z\ge w\). It uses only transitions of \(N\), so it is a valid swap sequence and satisfies \(z_{p^\star}\ge\theta\). \(\square\)

The deletion transitions are only an algorithmic device; the reverse implication proves that they introduce no false positive for the original problem.

5. Polynomial size and conclusion

The auxiliary net has exactly \(\tau m\) places. There are at most \(\tau(\tau-1)m(m-1)\) candidate swap transitions and \(\tau m\) deletion transitions.

Each swap transition has four nonzero entries, and each deletion transition has one. All transition coefficients belong to \(\{0,1\}\). We can enumerate the candidate swaps, test adjacency, and check the two preference comparisons in polynomial time from the supplied type descriptions.

The initial marking contains the supplied rational masses, and the final marking contains only \(\theta\) and zeros. Their binary encoding lengths are polynomial in \(L\). Hence the complete continuous Petri-net instance has size polynomial in \(m,\tau,q,L\).

Apply the polynomial-time finite-reachability theorem to \(N^-\), \(u\), and \(w\). Section 4 identifies its answer with rational mass-swap reachability, and Section 3 identifies that answer with the original real-valued problem. This settles the requested classification.

The same proof applies to any explicitly given location graph: its edges simply determine which swap transitions are included.
