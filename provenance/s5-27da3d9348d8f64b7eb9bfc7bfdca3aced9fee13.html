The continuous mirror question, as graded

Given rational type masses \((\mu_t)_{t\in T}\), per-capita object-class supplies \((b_q)_{q\in Q}\), and a partial top-\(k\) ranking \(P_t\) for each type, decide whether there is an assignment giving each applicant one seat, represented by masses \(x_{tq}\ge 0\) with \(\sum_q x_{tq}=\mu_t\) and \(\sum_t x_{tq}=b_q\), that is Pareto optimal under every completion of every applicant’s ranking consistent with their revealed prefix. For every such completion, no feasible reassignment may weakly improve all applicants and strictly improve a positive mass of them.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\). Here \(\tau=|T|\) is the support size, not the number of possible rankings. Normalize \(\sum_t\mu_t=1\).
There are \(m\geq1\) object classes \(Q\), with positive binary rational supplies \(b_q\) satisfying \(\sum_q b_q=1\). Each type reveals a strict prefix \(P_t\) of length \(1\leq k_t\leq m\); every listed class is preferred to every unlisted class, whose order is unrestricted. Seats within a class are interchangeable.
Represent type \(t\) by an atomless interval \(A_t\) of measure \(\mu_t\), and let \(A\) be their disjoint union with measure \(\lambda\). An assignment is a measurable map \(f:A\to Q\), represented by real masses \(x_{tq}=\lambda(A_t\cap f^{-1}(q))\geq0\), with \(\sum_qx_{tq}=\mu_t\) and \(\sum_tx_{tq}=b_q\).
A completion is any measurable assignment of a strict total ranking \(R_a\) to each applicant \(a\in A_t\), beginning with \(P_t\); applicants of the same type may complete independently. The assignment is necessarily Pareto optimal if, for every completion, no measurable assignment \(g:A\to Q\) with the same supplies satisfies \(g(a)\succeq_{R_a}f(a)\) almost everywhere and \(\lambda(\{a:g(a)\succ_{R_a}f(a)\})>0\).

Is deciding whether such a necessarily Pareto optimal assignment exists solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard, where \(L\) is the total binary input length?

For finite societies with equally many applicants and distinct objects, existence is decidable in polynomial time: a necessarily Pareto optimal matching exists exactly when some matching assigns at least \(n-1\) of the \(n\) applicants revealed objects. [Verified source](https://ojs.aaai.org/index.php/AAAI/article/download/16690/16497).
No result settling this exact atomless, independently completed problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalize total applicant mass and total per-capita supply to one, preserving the balanced discrete allocation model.
  • Require positive supplies for the listed object classes, corresponding to objects actually present in the discrete instance.
  • Allow type-specific prefix lengths from one through m, as in the discrete preference domain; completions retain both the prefix order and its precedence over all unlisted classes.
  • Interpret masses as partitions of an atomless applicant population, with each applicant receiving one seat and seats within each object class interchangeable.
  • Allow applicants sharing a revealed type to complete their rankings independently, preserving the discrete applicant-level quantifier.
  • Allow real assignment masses and measurable reassignments; interpret weak improvement almost everywhere and strict improvement on a set of positive measure.

Result

The decision problem is polynomial-time solvable in \(m,\tau,L\).

The key characterization is that a necessarily Pareto optimal assignment exists exactly when some class can serve as a common fallback, in the following precise sense.

Write the revealed prefix of type \(t\) as \(P_t=(p_{t,1},\ldots,p_{t,k_t})\). For a candidate fallback class \(c\), define:

  • If \(c=p_{t,j}\), let \(D_t(c)=\{p_{t,1},\ldots,p_{t,j}\}\).
  • If \(c\) is unlisted, let \(D_t(c)=\{p_{t,1},\ldots,p_{t,k_t}\}\cup\{c\}\).

Thus \(D_t(c)\) consists of \(c\) together with all classes that type \(t\) certainly prefers to \(c\).

Theorem. A necessarily Pareto optimal assignment exists if and only if there is a class \(c\in Q\) and a feasible mass matrix \(x\) satisfying \(x_{tq}=0\) whenever \(q\notin D_t(c)\).

I prove this characterization and then give its polynomial-time implementation.

1. Trading cycles characterize a fixed assignment

For a feasible assignment \(f\), with mass matrix \(x\), define a directed graph \(G_x\) on the object classes. For distinct classes \(q,r\), include the edge \(q\to r\) if some type \(t\) satisfies:

  • \(x_{tq}>0\); and
  • some strict ranking beginning with \(P_t\) ranks \(r\) above \(q\).

The possible-preference condition has a simple form:

  • If \(q\) is listed, \(r\) must occur before \(q\) in \(P_t\).
  • If \(q\) is unlisted, every \(r\ne q\) can be ranked above \(q\).

Lemma. The assignment \(f\) is necessarily Pareto optimal if and only if \(G_x\) is acyclic.

Proof, cycle implies failure. Suppose \(G_x\) contains a simple directed cycle \(q_1\to q_2\to\cdots\to q_\ell\to q_1\), where \(\ell\geq2\). Put \(q_{\ell+1}=q_1\). For each edge, choose a witnessing type \(t_i\), so that \(x_{t_iq_i}>0\) and a compatible ranking can place \(q_{i+1}\) above \(q_i\).

Choose \(0<\varepsilon\leq\min_i x_{t_iq_i}\). Atomlessness gives measurable subsets \(B_i\subseteq A_{t_i}\cap f^{-1}(q_i)\) of measure \(\varepsilon\). These subsets are disjoint because the classes \(q_i\) are distinct.

Give every applicant in \(B_i\) a compatible ranking that places \(q_{i+1}\) above \(q_i\), and choose any compatible ranking elsewhere. This is a measurable completion: it is constant on each of finitely many measurable pieces. Even if a type occurs several times on the cycle, independent completion permits the different subsets to receive different rankings.

Define \(g(a)=q_{i+1}\) on \(B_i\), and \(g(a)=f(a)\) elsewhere. Each cycle class loses and gains mass \(\varepsilon\), so supplies are preserved. Every applicant in the union of the \(B_i\) strictly improves, and everyone else keeps the same class. Thus \(f\) fails necessary Pareto optimality.

Proof, failure implies a cycle. Conversely, suppose a completion and a measurable assignment \(g\) Pareto improve \(f\). For distinct \(q,r\), put \(h_{qr}=\lambda(\{a:f(a)=q,\ g(a)=r\})\).

Because both assignments use the same supplies, at every class \(q\),

\(\displaystyle \sum_{r\ne q}h_{qr}=\sum_{r\ne q}h_{rq}.\)

Whenever \(h_{qr}>0\), some type contributes positive measure to these moves. Outside the exceptional null set in the Pareto condition, such applicants strictly prefer \(r\) to \(q\), since their rankings are strict and the classes differ. Consequently, \(q\to r\) is an edge of \(G_x\).

The positive-measure strict improvement guarantees that at least one \(h_{qr}\) is positive. Starting with such an edge, conservation ensures that its destination has a positive outgoing edge. Continuing in the finite graph eventually repeats a vertex, producing a directed cycle. This proves the lemma.

2. Necessity of a fallback class

Suppose \(f\) is necessarily Pareto optimal. By the lemma, \(G_x\) is acyclic.

Every finite nonempty acyclic directed graph has a vertex with no incoming edges: otherwise, following predecessors would eventually repeat a vertex and produce a cycle. Choose such a class \(c\).

Consider any \(x_{tr}>0\) with \(r\ne c\). Since \(r\to c\) is absent:

  • The class \(r\) must be listed by type \(t\). If it were unlisted, a compatible completion could rank \(c\) above \(r\), creating the edge.
  • If \(c\) is also listed, \(r\) must occur before \(c\). Otherwise \(c\) would already be revealed as preferred to \(r\), again creating the edge.

Therefore \(r\in D_t(c)\). Since \(c\in D_t(c)\) by definition, the entire matrix satisfies \(x_{tq}=0\) outside \(D_t(c)\).

This proves necessity.

3. Sufficiency of a feasible fallback allocation

Fix a class \(c\) for which the restricted mass constraints are feasible.

Define a cost for every type-class pair by setting \(\rho_t(p_{t,j})=j\) for listed classes, and \(\rho_t(q)=k_t+1\) for unlisted classes. Among all feasible matrices supported on the sets \(D_t(c)\), choose \(x\) minimizing

\(\displaystyle C(x)=\sum_{t\in T}\sum_{q\in Q}\rho_t(q)x_{tq}.\)

A minimizer exists: the feasible set is nonempty, closed, and bounded, and the objective is continuous. Partitioning each atomless interval realizes \(x\) as a measurable assignment \(f\).

I claim that \(f\) is necessarily Pareto optimal. Fix any completion, and suppose \(g\) Pareto improves \(f\).

First, the applicants assigned \(c\) cannot change on a set of positive measure. Every applicant assigned a class other than \(c\) receives a class in \(D_t(c)\setminus\{c\}\), which is strictly preferred to \(c\) under every completion. Hence the weak-improvement condition implies

\(g^{-1}(c)\subseteq f^{-1}(c)\quad\text{up to a null set}.\)

Both sets have measure \(b_c\), so they agree up to a null set. Thus applicants originally assigned \(c\) keep \(c\) almost everywhere.

Second, every other strict improvement decreases the revealed-rank cost. An applicant originally assigned \(q\ne c\) receives a listed class. A class strictly preferred to \(q\) must occur earlier in the revealed prefix. It therefore belongs to \(D_t(c)\) and has strictly smaller \(\rho_t\).

Consequently, the mass matrix \(y\) of \(g\) is feasible for the same restricted problem. Pointwise cost does not increase almost everywhere and decreases by at least one on every strictly improved applicant. Since the strict-improvement set has positive measure,

\(\displaystyle C(y)<C(x),\)

contradicting minimality. Thus no completion admits a Pareto improvement, proving sufficiency and the theorem.

4. Polynomial-time decision algorithm

For each candidate \(c\in Q\), build a capacitated network with:

  • An arc from the source to each type \(t\), of capacity \(\mu_t\).
  • An arc from type \(t\) to class \(q\) whenever \(q\in D_t(c)\), of capacity \(1\).
  • An arc from each class \(q\) to the sink, of capacity \(b_q\).

A flow of value \(1\) exists exactly when the restricted mass constraints are feasible. Indeed, total source capacity and total sink capacity both equal \(1\), so a value-\(1\) flow saturates all type-mass and class-supply arcs. The intermediate flows then give precisely the required matrix.

Accept if any candidate admits a flow of value \(1\); otherwise reject. The characterization proves both answers correct.

Each network has \(\tau+m+2\) vertices and at most \(\tau m+\tau+m\) arcs. There are \(m\) networks.

For exact binary arithmetic, multiply all capacities by the product of their input denominators. This product has binary length bounded by the sum of those denominator lengths, hence polynomial in \(L\). The resulting capacities are integers of polynomial binary length. A capacity-independent maximum-flow algorithm, such as Edmonds–Karp, therefore runs in polynomial time in \(m,\tau,L\). No expansion into individual applicants is required.

An explicit necessarily Pareto optimal assignment can also be obtained by computing a minimum-cost flow of value \(1\) in an accepted network, with cost \(\rho_t(q)\) on each type-to-class arc.

The case \(m=1\) is included: its sole fallback network is feasible, and no applicant can strictly improve.
