The continuous mirror question, as graded

Given a finite set \(T\) of interchangeable patient–donor types with masses \(\mu_t\), a typed compatibility system generating admissible cycle or set patterns \(\mathcal P\), pattern incidences \(a_{Pt}\), weights \(w_P\), color contents \(v_{P\ell}\), proportionality vector \(\vec p\), and \(\gamma\ge1\), compute a nonzero mass packing \(x_P\ge0\) maximizing \(W(x)=\sum_{P\in\mathcal P}w_Px_P\), subject to \(\sum_Pa_{Pt}x_P\le\mu_t\) and \(N_\ell(x)\le\gamma(p_\ell/p_q)N_q(x)\) for all colors with \(p_\ell,p_q>0\), where \(N_\ell(x)=\sum_Pv_{P\ell}x_P\) and \(N(x)=\sum_\ell N_\ell(x)>0\).

1. Result

The continuous mass problem is polynomial-time solvable exactly. Consequently, a deterministic algorithm achieves approximation factor \(1\), and hence the requested factor \(k+k\exp(-k)\), for every input \(\gamma\ge1\).

This conclusion concerns the stated model: patterns are explicitly listed, and their assigned masses may be arbitrary nonnegative real numbers. Repeated occurrences of a type are accounted for by their consumption coefficients.

2. Linear formulation and boundedness

Define the positive-proportion colors and pattern sizes by
\(I=\{\ell:p_\ell>0\}\) and \(s_P=\sum_ta_{Pt}\). Thus \(1\le s_P\le k\).

Let \(F\) consist of all vectors satisfying:

  • \(x_P\ge0\) for every pattern \(P\);
  • \(\sum_Pa_{Pt}x_P\le\mu_t\) for every type \(t\);
  • \(\sum_P(p_qv_{P\ell}-\gamma p_\ell v_{Pq})x_P\le0\) for every distinct \(\ell,q\in I\);
  • \(\sum_Pv_{P\ell}x_P=0\) for every \(\ell\notin I\).

For \(\ell,q\in I\), multiplication of the original fairness inequality by the positive number \(p_q\) gives exactly the third constraint. Pairs with \(\ell=q\) impose no additional restriction, since \(\gamma\ge1\) and \(N_\ell(x)\ge0\). The fourth constraint handles precisely the zero-proportion colors.

Therefore, \(F\) captures all packing and fairness constraints, allowing the zero packing temporarily. Every constraint is linear with rational coefficients.

Write the total packed participant mass as
\(S(x)=\sum_\ell N_\ell(x)=\sum_Ps_Px_P\).
Summing the type-capacity inequalities gives
\(S(x)=\sum_t\sum_Pa_{Pt}x_P\le\sum_t\mu_t=1\).

Since \(s_P\ge1\) and all coordinates are nonnegative, each coordinate satisfies \(0\le x_P\le1\). Hence \(F\) is bounded. It is also closed and contains zero, so it is a nonempty compact rational polytope.

Moreover, \(S(x)>0\) is equivalent to \(x\ne0\). By the promise in the question, some \(y\in F\) satisfies \(S(y)>0\).

3. An exact algorithm, including the nonzero requirement

First solve the rational linear program
\(\max\{W(x):x\in F\}\).
Let its optimum be \(z\), and let \(x^*\) be an optimal solution. Compactness ensures that this optimum exists. Nonnegative weights imply \(z\ge0\).

There are two cases.

Case \(z>0\). Since \(W(0)=0\), the solution \(x^*\) is nonzero. It therefore satisfies every requirement of the original problem. Every original feasible packing belongs to \(F\), so \(W(x^*)=z=\mathrm{OPT}_\gamma\).

Case \(z=0\). Solve a second rational linear program,
\(\max\{S(x):x\in F\}\),
and return an optimal solution \(\widehat x\). The promised vector \(y\) gives
\(S(\widehat x)\ge S(y)>0\), so \(\widehat x\) is nonzero.

For every \(x\in F\), nonnegative weights and the first optimum give
\(0\le W(x)\le z=0\). Thus \(W(\widehat x)=0=\mathrm{OPT}_\gamma\).

In both cases the algorithm returns a nonzero fair packing attaining the optimum. In particular, the exclusion of zero does not cause nonattainment.

4. Binary encoding and running time

We use the standard rational linear-programming theorem: an explicitly represented rational LP can be solved exactly in time polynomial in its dimensions and binary encoding length; when a finite optimum exists, an optimal rational solution can be returned. This is polynomial time in the bit model, following the classical polynomial-time solvability of linear programming. [Khachiyan (1979)](https://www.mathnet.ru/eng/dan42319)

Here its hypotheses hold:

  • There are \(m\) variables.
  • Counting nonnegativity constraints and retaining equalities, there are at most \(R=m+\tau+c^2+c\) constraints.
  • Both LPs are feasible and bounded.
  • All coefficients are explicitly computable rational numbers.

To bound their encoding, put \(h=\lceil\log_2(k+1)\rceil\). Each \(v_{P\ell}\) and \(s_P\) is an integer between zero and \(k\). Each fairness coefficient
\(p_qv_{P\ell}-\gamma p_\ell v_{Pq}\)
uses a constant number of rational arithmetic operations on input rationals and such integers, and therefore has binary length \(O(L+h+1)\).

A conservative bound for the dense encoding length of either LP is consequently
\(B=O\bigl(L+(m+1)(R+1)(L+h+1)\bigr)\).
Constructing these LPs takes polynomial time in the same parameters. At most two exact LP solves are required, giving total bit complexity
\(\operatorname{poly}\bigl(m,\tau,c,L,\log(k+1)\bigr)\).

The returned coordinates have polynomial binary encoding length. They need not be dyadic rationals; arbitrary rational coordinates are valid because the model permits real masses. No enumeration of additional types or patterns is required.

5. Approximation guarantee and the discrete comparison

The algorithm is deterministic and returns \(W(x)=\mathrm{OPT}_\gamma\). The nonzero-feasibility promise implies that some pattern exists, and hence \(k\ge1\). Therefore,
\((k+k\exp(-k))\mathbb E[W(x)]=(k+k\exp(-k))\mathrm{OPT}_\gamma\ge\mathrm{OPT}_\gamma\).

The discrete problem in the cited paper optimizes over distributions on packings of pairwise disjoint sets. [Duppala et al. (2023)](https://www.ijcai.org/proceedings/2023/0044.pdf) The mass problem specified here has its entire feasible region described by the explicit linear constraints above; it requires no integral packing or sampling realization. Its polynomial-time solvability follows directly from that formulation.
