The continuous mirror question, as graded

Given a finite type set \(T\), positive rational masses \(\mu_a\) summing to \(1\), per-institution external cash flows \(e_a\), and nonnegative rational exposure densities \(\ell_{ab}\) from debtor type \(a\) to creditor type \(b\), define \(\tau_a=\sum_b\mu_b\ell_{ab}\). Under proportional allocation, compute the per-type payments \(p_b\) satisfying \(p_b=\min\{\tau_b,\ e_b+\sum_{a:\tau_a>0}\mu_a\ell_{ab}p_a/\tau_a\}\), assuming every positive-exposure risk orbit has positive mass-weighted external cash flow.

Packaged proof task (what the prover saw — nothing else)

A society is specified by its support \(T\): the list of \(\tau=|T|\ge2\) types with positive binary-rational masses \(\mu_a\), summing to \(1\); \(\tau\) counts supported types, not possible types.
For each type, external cash flow per institution is \(e_a\in\mathbb Q_{\ge0}\). Exposure densities \(\ell_{ab}\in\mathbb Q_{\ge0}\) run from debtor \(a\) to creditor \(b\), with \(\ell_{aa}=0\). Define per-institution obligations \(d_a=\sum_{b\in T}\mu_b\ell_{ab}\).
The exposure graph has edge \(a\to b\) exactly when \(\ell_{ab}>0\). For every \(a\) with \(d_a>0\), let \(O(a)\) contain all types reachable from \(a\) by a positive-length directed path, and require \(\sum_{b\in O(a)}\mu_be_b>0\).
Under proportional allocation, a clearing vector satisfies \(0\le p_b\le d_b\) and \(p_b=\min\{d_b,e_b+\sum_{a:d_a>0}\mu_a\ell_{ab}p_a/d_a\}\) for every \(b\in T\); thus \(p_b=0\) when \(d_b=0\). The computational problem is to compute this vector exactly.
Let \(L\) be the total binary input length. There is no independent candidate or alternative parameter \(m\); the network dimension is \(\tau\). State running times in \(\tau\) and \(L\).

Is exact computation of the clearing vector for this distribution-based problem possible in polynomial time, or is it NP-hard?

For finite-agent regular networks with strongly monotonic division rules, the fictitious default algorithm reaches the clearing vector within \(n\) iterations ([Koster](https://cendef.uva.nl/binaries/content/assets/subsites/cendef/working-papers-2019/a-note-on-uniqueness-of-clearing-prices-in-financial-systems-mk.pdf)).
Finite-agent proportional clearing has an efficient algorithm and a unique vector under regularity ([Eisenberg–Noe](https://pubsonline.informs.org/doi/10.1287/mnsc.47.2.236.9835)). No result explicitly treating the support-and-mass formulation above was located.

Result

The clearing vector is unique under the stated regularity condition and can be computed exactly in time \((\tau+L)^{O(1)}\). The masses can be incorporated into a network with exactly \(\tau\) nodes; expanding rational masses into individual institutions is unnecessary.

The proof below gives an explicit linear program and verifies both uniqueness and polynomial bit complexity.

1. Incorporating the type masses

For every supported type, define aggregate payments, obligations, and external cash flows by

\[ x_a=\mu_a p_a,\qquad D_a=\mu_a d_a,\qquad E_a=\mu_a e_a. \]

Define aggregate nominal liabilities by

\[ W_{ab}=\mu_a\mu_b\ell_{ab}. \]

Then \(\sum_b W_{ab}=D_a\). Set

\[ \Pi_{ab}= \begin{cases} W_{ab}/D_a=\mu_b\ell_{ab}/d_a,&D_a>0,\\ 0,&D_a=0. \end{cases} \]

Thus \(\Pi\) is nonnegative, and its row sums equal one for types with positive obligations and zero otherwise.

Multiplying the original equation for type \(b\) by \(\mu_b>0\) gives exactly

\[ x_b=\min\left\{D_b,\ E_b+\sum_{a\in T}\Pi_{ab}x_a\right\}. \tag{1} \]

Conversely, every solution of (1) yields an original clearing vector through \(p_b=x_b/\mu_b\). This is a bijection, including when \(D_b=0\), where both corresponding payments vanish.

Because all masses are positive, \(W_{ab}>0\) exactly when \(\ell_{ab}>0\). Hence the exposure graph and all reachable sets are preserved. Moreover, the stated regularity condition becomes

\[ \sum_{b\in O(a)}E_b>0\qquad\text{whenever }D_a>0. \tag{2} \]

These are finite-network proportional clearing equations, explaining the applicability of the Eisenberg–Noe framework. The following argument proves the needed properties directly. [Eisenberg–Noe, *Systemic Risk in Financial Systems*](https://pubsonline.informs.org/doi/10.1287/mnsc.47.2.236.9835).

2. Existence of a greatest clearing vector

Write \(D=(D_a)_{a\in T}\), and define \(F:[0,D]\to[0,D]\) coordinatewise by

\[ F_b(x)=\min\left\{D_b,\ E_b+\sum_a\Pi_{ab}x_a\right\}. \]

Nonnegativity of \(E\) and \(\Pi\) ensures that \(F\) maps this box into itself. It is continuous and coordinatewise monotone.

Start with \(x^{(0)}=D\) and set \(x^{(k+1)}=F(x^{(k)})\). Since \(F(D)\le D\), monotonicity inductively gives

\[ 0\le x^{(k+1)}\le x^{(k)}\le D. \]

Each coordinate therefore converges. Denote the limit by \(x^+\). Continuity gives \(F(x^+)=x^+\).

If \(z\) is any other clearing vector, then \(z\le D=x^{(0)}\). From \(z\le x^{(k)}\), monotonicity gives

\[ z=F(z)\le F(x^{(k)})=x^{(k+1)}. \]

Taking limits proves \(z\le x^+\). Thus \(x^+\) is the greatest clearing vector.

3. Regularity implies uniqueness

Let \(z\) be any clearing vector and set \(\delta=x^+-z\ge0\).

For real numbers \(u\ge v\), the capped function satisfies

\[ 0\le\min\{c,u\}-\min\{c,v\}\le u-v. \]

Applying this to the clearing equations yields

\[ 0\le\delta_b\le\sum_a\Pi_{ab}\delta_a. \tag{3} \]

If \(D_a=0\), both payments are zero, so \(\delta_a=0\). Consequently,

\[ \sum_b\sum_a\Pi_{ab}\delta_a =\sum_{a:D_a>0}\delta_a =\sum_a\delta_a. \]

The nonnegative gaps in (3) therefore sum to zero. Each gap must vanish:

\[ \delta_b=\sum_a\Pi_{ab}\delta_a\qquad\text{for every }b. \tag{4} \]

Suppose that \(S=\{a:\delta_a>0\}\) is nonempty. Every member of \(S\) has positive obligations. Also, if \(a\in S\) and \(\ell_{ab}>0\), then \(\Pi_{ab}>0\), and (4) implies

\[ \delta_b\ge\Pi_{ab}\delta_a>0. \]

Thus \(S\) is closed under outgoing edges. In particular, \(O(a)\subseteq S\) for every \(a\in S\), and

\[ \sum_{b\in S}\Pi_{ab}=1\qquad(a\in S). \tag{5} \]

For each \(b\in S\), we have \(z_b<x_b^+\le D_b\). Therefore the clearing equation for \(z_b\) uses its cash-flow branch:

\[ z_b=E_b+\sum_a\Pi_{ab}z_a. \]

Summing over \(S\) and using (5) gives

\[ \sum_{b\in S}z_b =\sum_{b\in S}E_b+\sum_{a\in S}z_a +\sum_{a\notin S}z_a\sum_{b\in S}\Pi_{ab}. \]

Canceling the identical payment sums yields

\[ 0=\sum_{b\in S}E_b +\sum_{a\notin S}z_a\sum_{b\in S}\Pi_{ab}. \]

Every term is nonnegative, so \(E_b=0\) throughout \(S\). For any \(a\in S\), closure now implies

\[ \sum_{b\in O(a)}E_b=0, \]

contradicting (2). Hence \(S\) is empty and \(z=x^+\). This proves uniqueness.

4. A linear program that computes the vector

Consider the rational linear program with \(\tau\) variables:

\[ \text{maximize }\sum_{b\in T}x_b \]

subject to, for every \(b\in T\),

\[ 0\le x_b\le D_b,\qquad x_b-\sum_{a\in T}\Pi_{ab}x_a\le E_b. \tag{6} \]

It has \(3\tau\) scalar inequalities. Its feasible region is nonempty because it contains zero, and bounded because it lies in \([0,D]\).

We claim that its unique optimizer is \(x^+\). Let \(y\) be feasible. Conditions (6) imply \(y\le F(y)\). Since \(y\le D=x^{(0)}\), induction gives

\[ y\le F(y)\le F(x^{(k)})=x^{(k+1)} \]

whenever \(y\le x^{(k)}\). Therefore \(y\le x^+\).

The clearing vector \(x^+\) itself is feasible. Every distinct feasible vector has at least one strictly smaller coordinate and none larger, so its objective value is strictly smaller. This proves the claim.

The algorithm is therefore:

  • Compute \(D,E,\Pi\) using rational arithmetic.
  • Solve (6) exactly.
  • Return \(p_a=x_a/\mu_a\) for every supported type.

5. Exactness and running time

Assume the usual binary encoding of rational numerators and denominators, with total input length \(L\).

Every derived coefficient has \(O(L)\) bits. To see the only potentially problematic step, computing

\[ d_a=\sum_b\mu_b\ell_{ab}, \]

one may use the product of the denominators appearing in that row and in the masses as a common denominator. Its bit length is bounded by the sum of their input lengths. Each resulting numerator term has \(O(L)\) bits, and summing at most \(\tau\) terms adds only \(O(\log\tau)\) bits. Since the support is explicitly listed, \(\log\tau=O(L)\). Subsequent products and quotients defining \(D,E,\Pi\) preserve the \(O(L)\) bound.

Consequently, the linear program has total binary encoding length \(O(\tau^2L)\). The standard rational linear-programming theorem provides an exact rational optimizer in deterministic time polynomial in the number of variables, constraints, and binary encoding length. Its hypotheses hold here: all data are rational, feasibility was proved, and the feasible region is bounded. Exact polynomial-time rational LP methods are discussed in [Gleixner–Steffy, *Linear Programming using Limited-Precision Oracles*, Section 1.3](https://arxiv.org/html/1912.12820).

The output also has polynomial encoding length. Indeed, the unique LP optimizer is a vertex: otherwise it would be a nontrivial convex combination of feasible points, which would necessarily also optimize the linear objective, contradicting uniqueness. At a vertex, \(\tau\) linearly independent active inequalities determine the coordinates. Clearing denominators separately in these rows gives integer coefficients with \(O(\tau L)\) bits. Hadamard’s determinant bound and Cramer’s rule then bound each coordinate’s numerator and denominator by

\[ O(\tau^2L+\tau\log\tau) \]

bits. Dividing by the input mass \(\mu_a\) adds only \(O(L)\) bits.

Thus preprocessing, exact optimization, and conversion back to per-institution payments all take total bit time \((\tau+L)^{O(1)}\). This settles the stated problem as polynomial-time solvable.
