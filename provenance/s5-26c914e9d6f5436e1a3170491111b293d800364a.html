The continuous mirror question, as graded

Given projects \(P\), per-capita costs \(c(p)>0\), a per-capita budget \(B\), a preselected set \(P_0\), an MES budget \(B_{\mathrm{MES}}\ge c(P_0)\), and rational approval-type masses \(\mu_A\) summing to \(1\), compute the Value-Based Mass-MES output \(Q\supseteq P_0\). Let \(q_p=\sum_{A\ni p}\mu_A\), define the Value-Based threshold using \(q_p\), and assign type \(A\) its payment \(\pi_A=\sum_{p\in A\cap P_0}c(p)/\max\{q_p,q^*\}\). Rebalance to type budgets \(b_A\) maximizing \(\min_{\mu_A>0}(\pi_A+b_A)\), subject to \(\sum_A\mu_A b_A=B_{\mathrm{MES}}-c(P_0)\) and \(b_A\ge0\); then run MES using \(\sum_{A\ni p}\mu_A\min\{b_A,\rho(p)c(p)\}=c(p)\). Does the resulting \(Q\) satisfy mass-EJR+: for every \(p\notin Q\) and every subpopulation \(\nu_A\in[0,\mu_A]\) supported on types approving \(p\), with \(\sigma=\sum_A\nu_A>0\), is there an \(A\) with \(\nu_A>0\) such that \(c(A\cap Q)+c(p)>\alpha_{\mathrm{VB}}B\sigma\), where \(\alpha_{\mathrm{VB}}=\min_{\mu_A>0}(\pi_A+b_A)/B\)?

A society is given by its support: the list of the \(\tau\) approval types \(A\subseteq P\) with positive binary-rational masses \(\mu_A\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. All numerical inputs are binary rationals; \(L\) is the total input bit length. State any running times in \(m,\tau,L\).
Type \(A\) has cost satisfaction \(c(A\cap S)\). Set \(q_p=\sum_{A\ni p}\mu_A\), and require \(q_p>0\) for every project.
Define \(U(p)=\{r\in P_0:q_r\ge q_p\}\) and \(q^*=\max\bigl(\{q_p:p\in P\setminus P_0,\ c(U(p))+c(p)\le B_{\mathrm{MES}}\}\cup\{0\}\bigr)\).
Set \(\pi_A=\sum_{p\in A\cap P_0}c(p)/\max\{q_p,q^*\}\). Choose nonnegative initial budgets maximizing \(\min_A(\pi_A+b_A)\), subject to \(\sum_A\mu_A b_A=B_{\mathrm{MES}}-c(P_0)\); use the water-filling allocation \(b_A=\max\{0,t-\pi_A\}\) satisfying this equality. If the remaining budget is zero, set every \(b_A=0\).
Define \(\alpha_{\mathrm{VB}}=\min_A(\pi_A+b_A)/B\) from these initial budgets. Initialize \(Q=P_0\) and remaining budgets \(r_A=b_A\).
For each unselected project, find the least \(\rho(p)\ge0\) satisfying \(\sum_{A\ni p}\mu_A\min\{r_A,\rho(p)c(p)\}=c(p)\), if one exists. Select a project minimizing \(\rho(p)\), add it to \(Q\), and subtract \(\min\{r_A,\rho(p)c(p)\}\) from each approving type's remaining budget. Stop when no such project exists; ties may be broken arbitrarily.
Call \(Q\) mass-EJR+ if, for every \(p\notin Q\) and every real subpopulation \(0\le\nu_A\le\mu_A\) with \(\nu_A=0\) whenever \(p\notin A\) and \(\sigma=\sum_A\nu_A>0\), some type with \(\nu_A>0\) satisfies \(c(A\cap Q)+c(p)>\alpha_{\mathrm{VB}}B\sigma\).

Conclusion

Value-Based Mass-MES always satisfies mass-EJR+ on the stated inputs, for every MES tie-breaking. The proof transfers the finite-voter theorem exactly; arbitrary real subpopulations require no approximation.

Write \(\mathcal A\) for the given support, and set
\( D=B_{\mathrm{MES}}-c(P_0) \)
and
\( h=\min_{A\in\mathcal A}(\pi_A+b_A)=\alpha_{\mathrm{VB}}B. \)
All endowments are nonnegative, so \(h\geq 0\).

1. The finite-voter theorem used

For a finite society with \(n\) voters, project costs \(C\), overall budget \(H\), MES budget \(H_{\mathrm{MES}}\), and preselected set \(P_0\), let \(\widehat\pi_i,\widehat b_i\) be the Value-Based payments and rebalanced initial budgets. Define
\( \widehat\alpha =n\min_i(\widehat\pi_i+\widehat b_i)/H. \)

The finite-voter guarantee states that every resulting outcome \(Q\), under arbitrary MES ties, has the following property: for every \(p\notin Q\) and every nonempty voter set \(T\) whose members all approve \(p\), some \(i\in T\) satisfies
\( C(A_i\cap Q)+C(p)> \widehat\alpha H\,|T|/n. \)
This is the supplied discrete result, stated as Theorem 5 in [Baychkov, Brill, and Utke](https://arxiv.org/html/2606.23320v2#S5).

We verify that an exact finite instance realizes the specified mass algorithm.

2. Exact finite representation and initialization

Because every \(\mu_A\) is rational, there is a positive integer \(n\) such that
\( n_A=n\mu_A \)
is a positive integer for every \(A\in\mathcal A\). Since the masses sum to one, \(\sum_A n_A=n\).

Construct a finite society containing \(n_A\) voters with approval set \(A\). Scale costs and budgets by setting
\( C(p)=nc(p),\qquad H=nB,\qquad H_{\mathrm{MES}}=nB_{\mathrm{MES}}. \)

The required hypotheses hold: costs are positive,
\( 0<H_{\mathrm{MES}}\leq H, \)
and
\( C(P_0)\leq H_{\mathrm{MES}}. \)
Moreover, each project has
\( |N_p|=\sum_{A\ni p}n_A=nq_p>0 \)
supporters.

Multiplication by \(n>0\) preserves all support comparisons. Consequently, the finite upper contour set of \(p\) is exactly \(U(p)\). Its threshold eligibility condition is
\( C(U(p))+C(p)\leq H_{\mathrm{MES}}, \)
which is equivalent to
\( c(U(p))+c(p)\leq B_{\mathrm{MES}}. \)
Thus the finite Value-Based threshold is \(v^*=nq^*\), including when both thresholds are zero.

For a voter of type \(A\), the finite prepayment therefore equals
\( \widehat\pi_i =\sum_{p\in A\cap P_0} \frac{nc(p)}{\max\{nq_p,nq^*\}} =\pi_A. \)

If \(D>0\), assign every voter of type \(A\) the budget \(b_A=\max\{0,t-\pi_A\}\). These budgets are precisely the finite water-filling allocation, because its equation becomes
\( \sum_i\max\{0,t-\widehat\pi_i\} =n\sum_A\mu_A\max\{0,t-\pi_A\} =nD. \)
The right-hand side is the finite remaining budget
\( H_{\mathrm{MES}}-C(P_0). \)

If \(D=0\), every finite initial budget must be zero, matching the stated mass initialization. In either case,
\( \widehat\alpha =\frac{n\min_A(\pi_A+b_A)}{nB} =\alpha_{\mathrm{VB}}. \)

For completeness, the theorem’s comparison with the available budget share also holds. The mass allocation assigning \(D\) to every type is feasible and gives every type endowment at least \(D\). Optimality of the prescribed initialization implies \(h\geq D\), hence
\( \widehat\alpha=\alpha_{\mathrm{VB}}\geq D/B. \)

3. Exact correspondence of every MES execution

Fix any execution of mass-MES, including all its tie choices. We show that the finite instance can follow exactly the same project sequence.

Initially, all finite voters of type \(A\) have remaining budget \(r_A=b_A\). Suppose this correspondence holds before a selection. For an unselected project \(p\), the finite affordability equation at price \(\widehat\rho\) is
\( \sum_{A\ni p}n_A \min\{r_A,\widehat\rho C(p)\}=C(p). \)
Substituting the scaled quantities and dividing by \(n\) gives
\( \sum_{A\ni p}\mu_A \min\{r_A,(n\widehat\rho)c(p)\}=c(p). \)

Therefore a finite price exists exactly when a mass price exists, and their least values satisfy
\( \widehat\rho(p)=\rho(p)/n. \)
This positive common scaling preserves price comparisons and ties.

When the corresponding project is selected, each approving finite voter pays
\( \min\{r_A,\widehat\rho(p)C(p)\} =\min\{r_A,\rho(p)c(p)\}, \)
exactly the mass algorithm’s decrement. This proves the correspondence inductively. The stopping conditions also coincide.

Hence every mass-MES outcome \(Q\) is an outcome of the finite Value-Based MES instance under a corresponding permitted tie-breaking.

4. Arbitrary real subpopulations

Fix \(p\notin Q\) and any subpopulation satisfying the question’s conditions. Let
\( I=\{A\in\mathcal A:\nu_A>0\}, \qquad M=\sum_{A\in I}\mu_A. \)
Because \(\sigma=\sum_A\nu_A>0\), the set \(I\) is nonempty. Every type in \(I\) approves \(p\), and \(\nu_A\leq\mu_A\) implies \(M\geq\sigma\).

In the finite society, take \(T\) to contain all voters of every type in \(I\). Then
\( |T|=nM. \)
The finite theorem supplies a voter of some type \(A\in I\) for which
\( n\bigl(c(A\cap Q)+c(p)\bigr) > \alpha_{\mathrm{VB}}(nB)\frac{nM}{n}. \)
Dividing by \(n>0\), and using \(h\geq0\) and \(M\geq\sigma\), yields
\( c(A\cap Q)+c(p) > \alpha_{\mathrm{VB}}BM =hM \geq h\sigma =\alpha_{\mathrm{VB}}B\sigma. \)

Since \(A\in I\), this type has \(\nu_A>0\), as required. The strict inequality is preserved even when \(M=\sigma\). Thus the argument covers arbitrary real subpopulations, including boundary cases, and proves mass-EJR+ for every tie-breaking.
