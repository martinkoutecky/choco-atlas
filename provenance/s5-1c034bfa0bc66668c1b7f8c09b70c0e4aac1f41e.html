The continuous mirror question, as graded

Result

Yes. There is a deterministic algorithm, polynomial in \(m,\tau,L,D,s\), that returns a rational estimate \(\widehat W\) satisfying
\[ \frac{\mathrm{OPT}}{4}\leq \widehat W\leq \mathrm{OPT}. \]
It detects \(\mathrm{OPT}=0\) exactly.

The argument works directly with the supported population. It does not expand rational masses or supplies into finite agents.

1. Valuation properties and exact zero detection

For a matroid \(M\) with element weights \(w_j\geq0\), its weighted rank valuation is
\[ r_w(S)=\max\left\{\sum_{j\in I}w_j:I\subseteq S,\ I\text{ independent in }M\right\}. \]

This function can be evaluated exactly in polynomial time: process the elements of \(S\) in nonincreasing weight order, retaining an element when independence is preserved.

It is also normalized, monotone, and submodular. To verify submodularity, let \(0=a_0<a_1<\cdots<a_k\) be the distinct positive weights and put \(E_\ell=\{j:w_j\geq a_\ell\}\). Greedy produces an independent set whose intersection with each \(S\cap E_\ell\) has cardinality \(r_M(S\cap E_\ell)\). Consequently,
\[ r_w(S)=\sum_{\ell=1}^{k}(a_\ell-a_{\ell-1})r_M(S\cap E_\ell). \]
Each summand is a nonnegative multiple of a matroid rank function restricted to a fixed subset, hence is submodular. Therefore every \(v_t\), being a sum of these functions, has the same properties and admits polynomial-time exact evaluation.

Define
\[ E_t=\{j\in[m]:v_t(\{j\})>0\}. \]
Normalization and submodularity imply
\[ v_t(S)\leq\sum_{j\in S}v_t(\{j\}). \]
Thus every positive-valued bundle contains an element of \(E_t\).

Claim. Positive welfare is feasible if and only if there are numbers \(y_{t,j}\geq0\), supported on \(j\in E_t\), satisfying
\[ \sum_{j\in E_t}y_{t,j}=\mu_t,\qquad \sum_t y_{t,j}\leq\rho_j. \]

Indeed, from an allocation using only positive-valued bundles, choose one element of \(S\cap E_t\) for each occupied bundle \(S\), and transfer that bundle’s mass to the chosen singleton. This preserves type masses and cannot increase any item’s consumption. Conversely, such singleton masses themselves constitute an allocation with positive welfare.

These conditions are a bipartite flow problem: source-to-type capacities are \(\mu_t\), type-to-eligible-item capacities are \(1\), and item-to-sink capacities are \(\rho_j\). Positive welfare is feasible precisely when the maximum flow equals \(1\). Rational maximum flow is polynomial-time computable.

If this test fails, every allocation gives positive mass a zero-valued bundle, so \(\mathrm{OPT}=0\). Henceforth assume it succeeds.

Since total population mass is \(1\), replace each supply by \(\min\{\rho_j,1\}\). This preserves the feasible allocations.

2. The population problem is exactly a configuration LP

Let \(q\) be the smallest positive input weight, and let \(Q\) be the sum of all element weights across all listed matroid components. The successful flow test guarantees that \(q\) exists. Every positive valuation satisfies
\[ q\leq v_t(S)\leq Q. \]

Set
\[ f_t(S)=v_t(S)/q,\qquad \mathcal P_t=\{S:f_t(S)>0\}. \]
For \(S\in\mathcal P_t\), define \(g_t(S)=\log f_t(S)\).

Let \(U=Q/q\), and choose a positive integer \(B\), polynomially bounded in the input length, with \(\log U\leq B\). For example, one more than the binary length of the numerator of \(U\) suffices. Then \(0\leq g_t(S)\leq B\).

The normalized optimal logarithmic welfare is exactly the LP value
\[ z=\max_x\sum_t\sum_{S\in\mathcal P_t}x_{t,S}g_t(S), \]
subject to
\[ \sum_{S\in\mathcal P_t}x_{t,S}=\mu_t,\qquad \sum_t\sum_{\substack{S\in\mathcal P_t\\j\in S}}x_{t,S}\leq\rho_j,\qquad x_{t,S}\geq0. \]
Its feasible region is nonempty by the flow test and compact because every variable lies between \(0\) and its type mass. Thus its maximum exists. Since the total allocated mass equals \(1\),
\[ \mathrm{OPT}=q\exp(z). \]

For a fully rational computation, fix \(\delta=1/100\). Use a deterministic logarithm evaluator to produce rational coefficients \(\widetilde g_t(S)\in[0,B]\) with
\[ |\widetilde g_t(S)-g_t(S)|\leq\delta. \]
These coefficients have polynomial bit length and are polynomial-time computable from a bundle.

Let \(\widetilde z\) be the resulting rational LP value. Every feasible allocation has total mass \(1\), so its objective changes by at most \(\delta\). Therefore
\[ |z-\widetilde z|\leq\delta,\qquad 0\leq\widetilde z\leq B. \]

By finite-dimensional LP duality, its dual is
\[ \widetilde z=\min_{\alpha,p}\left(\sum_t\mu_t\alpha_t+\sum_j\rho_jp_j\right), \]
where \(\alpha_t\) is unrestricted, \(p_j\geq0\), and
\[ \alpha_t+\sum_{j\in S}p_j\geq\widetilde g_t(S) \quad\text{for every }t,\ S\in\mathcal P_t. \]

We next construct a polynomial-time pricing oracle with additive error less than \(1\).

3. A cost-preserving approximate covering subroutine

We use the following known theorem: a nonnegative monotone submodular function can be maximized under one knapsack constraint with approximation factor \(1-1/e\), deterministically using polynomially many value evaluations. [Sviridenko’s theorem](https://thibaut.horel.org/submodularity/papers/sviridenko2004.pdf) applies to nonnegative integer costs; rational costs can be scaled to integers with polynomial bit length.

Zero-cost elements cause no difficulty. Include them all first, and apply the theorem to the residual function
\[ h(A)=f(Z\cup A)-f(Z), \]
where \(Z\) is the set of zero-cost elements. A factor guarantee for \(h\) gives the same factor guarantee for the total value, because \(f(Z)\geq0\).

Covering lemma. Given nonnegative rational costs \(p_j\) and an attainable target \(V>0\), one can find a set \(A\) with
\[ f_t(A)\geq V/2,\qquad p(A)\leq\min\{p(S):f_t(S)\geq V\}, \]
in polynomial time.

Proof. Scale the costs to nonnegative integers \(c_j\), and let
\[ C^*=\min\{c(S):f_t(S)\geq V\}. \]
At any integer budget \(C\geq C^*\), the knapsack approximation returns value at least
\[ (1-1/e)V>V/2. \]

Binary-search integer budgets between \(0\) and \(\sum_jc_j\), declaring success when the returned value is at least \(V/2\). Maintain a failed lower endpoint, initially the virtual endpoint \(-1\), and a successful upper endpoint.

Every failed budget is strictly less than \(C^*\). At termination the endpoints are consecutive integers, so the successful upper endpoint is at most \(C^*\). Its returned set proves the claim.

This reasoning does not require success to be monotone below \(C^*\). The number of calls is polynomial in the bit length of \(\sum_jc_j\), rather than its numerical magnitude. \(\square\)

4. An additive-error pricing oracle

Fix a type \(t\) and prices \(p\geq0\). Consider targets
\[ V_k=(5/4)^k \]
from \(1\) until the first target exceeding \(U\). There are polynomially many targets because their number is \(O(\log U)\).

Skip targets exceeding \(f_t([m])\). Apply the covering lemma to every remaining target, obtaining candidate bundles \(A_k\). Return a candidate maximizing
\[ \widetilde g_t(A_k)-p(A_k). \]

For any \(S\in\mathcal P_t\), choose the largest target \(V_k\leq f_t(S)\). Then
\[ V_k>\frac45f_t(S). \]
The corresponding candidate satisfies
\[ p(A_k)\leq p(S),\qquad f_t(A_k)\geq V_k/2>\frac25f_t(S). \]
Using the two logarithm approximation errors gives
\[ \widetilde g_t(A_k)-p(A_k) \geq \widetilde g_t(S)-p(S)-\log(5/2)-2\delta. \]
The constant \(\log(5/2)+2/100\) is less than \(1\): the exponential series gives \(e^{49/50}>5/2\).

Consequently, the returned bundle \(A_t\) satisfies
\[ \widetilde g_t(A_t)-p(A_t) \geq \max_{S\in\mathcal P_t}\{\widetilde g_t(S)-p(S)\}-1. \]

This yields the required dual oracle:

  • If a returned bundle violates its dual constraint, return that constraint as a valid separating inequality.
  • Otherwise every dual constraint satisfies

\[ \alpha_t+p(S)\geq\widetilde g_t(S)-1. \]

In the second case, replacing every \(\alpha_t\) by \(\alpha_t+1\) makes the dual genuinely feasible. Its objective increases by exactly
\[ \sum_t\mu_t=1. \]

This is the crucial population-specific observation: the oracle error contributes a universal constant, independently of the number or sizes of the listed masses.

5. Polynomial optimization despite approximate acceptance

Here we justify the optimization step, including boundedness and numerical encoding.

Put \(n=m+\tau\). The dual feasible polyhedron contains no affine line. A line direction must have zero price coordinates because prices are nonnegative. Its type coordinates must then also vanish, because each type has at least one positive-bundle constraint.

The dual has a finite attained optimum by LP duality. Its optimal face therefore contains a vertex. At a vertex, \(n\) independent active constraints determine the coordinates. Their coefficient matrix has entries in \(\{-1,0,1\}\), while their right-hand sides have absolute value at most \(B\). Cramer’s rule gives an optimal vertex \((\alpha^*,p^*)\) satisfying
\[ |\alpha_t^*|\leq R_0,\qquad p_j^*\leq R_0,\qquad R_0=n!B. \]
Indeed, the nonzero integer determinant has absolute value at least \(1\), and each replacement determinant is bounded by \(n!B\).

Set
\[ R=2(R_0+2),\qquad \eta=1/100. \]
For an objective threshold \(h\), let \(K(h)\) consist of genuinely dual-feasible points satisfying the additional bounds
\[ -R\leq\alpha_t\leq R,\qquad 0\leq p_j\leq R, \]
and
\[ \sum_t\mu_t\alpha_t+\sum_j\rho_jp_j\leq h. \]

Apply the ellipsoid method as follows. Check the box and objective constraints exactly; then use the pricing oracle. Every rejected point supplies a valid cut preserving \(K(h)\). An accepted point need only satisfy the relaxed bundle inequalities from Section 4.

We use the standard ellipsoid volume guarantee: for a set inside a known ball, polynomially many valid rational central cuts either produce an accepted point or reduce the containing volume below that of a prescribed radius-\(r\) ball. Its rational implementation runs in polynomial time in the dimension, coefficient encoding lengths, and \(\log(R/r)\). [Ellipsoid-method reference](https://www.cs.princeton.edu/~smattw/Teaching/521FA21/ellipsoid.pdf)

To check the required interior-ball condition, define
\[ \varepsilon=\frac{\eta}{4n},\qquad r=\frac{\eta}{16n^2}. \]
Increase every coordinate of \((\alpha^*,p^*)\) by \(\varepsilon\).

Every bundle constraint then has slack at least \(\varepsilon\), and every price is at least \(\varepsilon\). The box boundaries remain at distance greater than \(1\). Moreover, because the supplies were capped,
\[ \sum_t\mu_t+\sum_j\rho_j\leq m+1\leq n. \]
Hence the objective increases by at most \(n\varepsilon=\eta/4\).

Changing this perturbed point within a Euclidean ball of radius \(r\) changes any bundle-constraint left-hand side, or the objective, by at most \(nr=\varepsilon/4\). Therefore
\[ h\geq\widetilde z+\eta \quad\Longrightarrow\quad K(h)\text{ contains a radius-}r\text{ ball}. \]

The ellipsoid test consequently has two rigorous outcomes:

  • Acceptance: shifting type variables upward by \(1\) proves

\[ \widetilde z\leq h+1. \]

  • Termination without acceptance: the volume guarantee and the interior-ball implication prove

\[ h<\widetilde z+\eta. \]

Test thresholds \(h=0,\eta,2\eta,\ldots,B+1\), stopping at the first accepted threshold \(h_*\). Acceptance must occur, since thresholds at least \(\widetilde z+\eta\) cannot terminate without acceptance. There are polynomially many thresholds.

Acceptance gives \(h_*\geq\widetilde z-1\). If \(h_*>0\), failure at the preceding threshold gives \(h_*<\widetilde z+2\eta\). If \(h_*=0\), the same upper bound follows from \(\widetilde z\geq0\). Thus
\[ \widetilde z-1\leq h_*\leq\widetilde z+2\eta. \]

6. Returning the multiplicative estimate

Combining this with \(|z-\widetilde z|\leq1/100\) yields
\[ z-\frac{101}{100}\leq h_*\leq z+\frac3{100}. \]
Define
\[ A=q\exp\left(h_*-\frac3{100}\right). \]
Compute a rational \(\widehat W\) with
\[ e^{-1/100}A\leq\widehat W\leq A. \]
Such a certified constant-relative-precision exponential approximation is polynomial-time computable. Its output has polynomial bit length because \(h_*\leq B+1\) and \(q\) has polynomial encoding length.

The upper bound gives \(\widehat W\leq q e^z=\mathrm{OPT}\). The lower bound gives
\[ \widehat W\geq e^{-21/20}\mathrm{OPT}>\frac{\mathrm{OPT}}4. \]
For the last inequality, \(e<3\) and \(e^{1/20}\leq20/19\), so \(e^{21/20}<60/19<4\).

7. Complexity and relation to the cited results

All valuation evaluations use polynomially many independence tests and rational operations. The target grid, covering searches, ellipsoid iterations, and objective-threshold grid all have polynomial length. Their numerical dependence is on binary encoding lengths, including those of the rational masses and supplies. Thus the complete algorithm runs in time polynomial in \(m,\tau,L,D,s\).

The pricing mechanism is related to the configuration-LP approximation in [Feng–Hu–Li–Zhang, Lemma 3.1 and Appendix B.1](https://arxiv.org/html/2411.02942#S3.SS1). The proof above establishes its transfer to the present formulation directly: arbitrary supplies enter the dual objective, and arbitrary type masses enter through coefficients summing to \(1\). No finite-agent approximation or population expansion is needed.
