The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to one, symmetric pair utilities \(w_{tu}\), and coalition capacity \(C\), choose nonnegative densities \(y_q\) for every integer type composition \(q\) with \(1 \le |q| \le C\), satisfying \(\sum_q q_t y_q = \mu_t\), to maximize \(\sum_q v(q)y_q\), where \(v(q) = \sum_{t<u} w_{tu} q_t q_u + \sum_t w_{tt} \binom{q_t}{2}\); decide whether the optimum is at least a rational threshold \(B\).

Complexity Classification

Let \(\operatorname{OPT}(T,\mu,C,a)\) denote the maximum value of a fractional formation.

Theorem.

  • When \(C\) is part of the input, deciding whether \(\operatorname{OPT}\ge K\) is \(\mathrm{NP\text{-}complete}\).
  • For every fixed \(C\ge 1\), the problem is polynomial-time solvable.
  • With \(C\) encoded in binary, the problem is fixed-parameter tractable parameterized by \(\operatorname{twc}(H)\).

The last statement contrasts with the stated \(\mathrm{W[1]}\)-hardness of the discrete problem: fractional pattern rates permit an LP with an FPT pricing oracle.

1. Configuration LP and membership in \(\mathrm{NP}\)

For a pattern \(q\), write

\[ w(q)=\sum_t a_{tt}\binom{q_t}{2}+\sum_{t<u}a_{tu}q_tq_u. \]

The optimization problem is the rational linear program

\[ \max \sum_q w(q)z_q \]

subject to

\[ \sum_q q_tz_q=\mu_t \quad\text{for every }t\in T, \qquad z_q\ge 0. \]

It is always feasible because singleton patterns suffice. Moreover,

\[ \sum_q |q|z_q =\sum_q\sum_tq_tz_q =\sum_t\mu_t =1, \]

so its feasible region is bounded.

There is therefore an optimal basic feasible solution. Since there are \(|T|\) equality constraints, such a solution uses at most \(|T|\) patterns. Every coordinate of every pattern is at most \(C\), and Cramer’s rule gives polynomial encoding length for the corresponding rates \(z_q\): the relevant determinants involve matrices of dimension at most \(|T|\) with entries bounded by \(C\), together with the rational masses.

Thus a certificate consists of at most \(|T|\) patterns and their rational rates. Feasibility and value can be checked in polynomial time. Consequently, the variable-\(C\) problem belongs to \(\mathrm{NP}\).

2. Polynomial time for every fixed capacity

The number of patterns of size at most \(C\) is

\[ \sum_{r=1}^{C}\binom{|T|+r-1}{r} =\binom{|T|+C}{C}-1. \]

For fixed \(C\), this is \(O(|T|^C)\). We can enumerate all patterns, calculate their values, and solve the resulting explicit rational LP in polynomial time.

In particular:

  • For \(C=1\), every pattern has value \(0\), so the answer is yes exactly when \(K\le 0\).
  • For \(C=2\), the LP has \(O(|T|^2)\) columns.
  • For every fixed \(C\ge 3\), it still has polynomially many columns, even though the corresponding discrete partition problem is NP-complete.

3. NP-hardness when \(C\) is input

We reduce from \(\mathrm{CLIQUE}\). Let \(G=(V,E)\) and \(k\) be an instance, where \(2\le k\le |V|\). Set

\[ C=k+1. \]

3.1 A universal upper bound

For every pattern \(q\), each unordered pair of positions in the pattern contributes at most \(1\). Hence

\[ w(q)\le \binom{|q|}{2} \le \frac{C-1}{2}|q|. \]

Every fractional formation therefore satisfies

\[ \sum_qw(q)z_q \le \frac{C-1}{2}\sum_q|q|z_q =\frac{C-1}{2}. \]

Equality holds only if every positive-rate pattern has size exactly \(C\) and every unordered pair of its positions is compatible. For repeated copies of a type \(t\), this requires \(a_{tt}=1\).

3.2 Construction

Introduce one special type \(s\). For each \(v\in V\), introduce:

  • the original type \(v\);
  • a reservoir type \(x_v\);
  • \(k=C-1\) filler types \(F_v=\{f_v^1,\ldots,f_v^k\}\).

The loopless compatibility graph contains:

  • the edge \(sv\) for every \(v\in V\);
  • the edge \(uv\) between original types exactly when \(uv\in E(G)\);
  • all edges within \(F_v\);
  • all edges from \(v\) to \(F_v\);
  • all edges from \(x_v\) to \(F_v\).

There are no other inter-type compatibilities.

For diagonal compatibilities, set

\[ a_{x_vx_v}=1 \]

for every \(v\), and set all other diagonal bits to \(0\).

Let \(n=|V|\), let

\[ D=1+2Cn, \qquad \varepsilon=\frac1D, \]

and assign masses

\[ \mu_s=\varepsilon,\qquad \mu_v=\varepsilon,\qquad \mu_{f_v^j}=\varepsilon,\qquad \mu_{x_v}=C\varepsilon. \]

Indeed,

\[ \mu_s+\sum_{v\in V} \left(\mu_v+\sum_{j=1}^{k}\mu_{f_v^j}+\mu_{x_v}\right) = \varepsilon+n\bigl(\varepsilon+(C-1)\varepsilon+C\varepsilon\bigr) =1. \]

Set the threshold to

\[ K=\frac{C-1}{2}. \]

3.3 Completeness of the reduction

Suppose \(S\subseteq V\) is a clique of size \(k=C-1\).

Use the pattern \(\{s\}\cup S\) at rate \(\varepsilon\). For every \(v\notin S\), use \(\{v\}\cup F_v\) at rate \(\varepsilon\). For every \(v\in S\), use \(\{x_v\}\cup F_v\) at rate \(\varepsilon\).

Finally, use the pattern consisting of \(C\) copies of \(x_v\):

  • at rate \(\varepsilon\) if \(v\notin S\);
  • at rate \((C-1)\varepsilon/C\) if \(v\in S\).

The mass equations hold:

  • \(s\) and every original type are used exactly at rate \(\varepsilon\);
  • every filler is used exactly at rate \(\varepsilon\);
  • if \(v\in S\), then \(x_v\) contributes mass

\(\varepsilon+(C-1)\varepsilon=C\varepsilon\);

  • if \(v\notin S\), its repeated-type pattern contributes mass \(C\varepsilon\).

Every used pattern has size \(C\) and all its position-pairs are compatible. For the repeated \(x_v\)-pattern, this uses \(a_{x_vx_v}=1\). The formation therefore reaches the upper bound \(K=(C-1)/2\).

3.4 Soundness of the reduction

Conversely, suppose a formation has value at least \(K\). By the universal upper bound, its value equals \(K\). Therefore every positive-rate pattern has size \(C\) and all its position-pairs are compatible.

Because \(\mu_s=\varepsilon>0\), some positive-rate pattern contains \(s\). Since \(a_{ss}=0\), it contains \(s\) exactly once. The only neighbors of \(s\) are original types, so its other \(C-1=k\) positions contain original types.

No original type can be repeated because its diagonal compatibility is \(0\). The \(k\) original types are therefore distinct. Since every pair of positions must be compatible, they induce a \(k\)-clique in \(G\).

Thus the constructed instance reaches \(K\) if and only if \(G\) has a clique of size \(k\). The construction is polynomial, proving NP-hardness. Together with membership in \(\mathrm{NP}\), the variable-\(C\) problem is \(\mathrm{NP\text{-}complete}\).

4. The dual and its pricing problem

Types of zero mass can be deleted: their mass equations imply that no positive-rate pattern can contain them. Hence assume \(\mu_t>0\) for every remaining type.

The dual LP is

\[ \min \sum_t\mu_ty_t \]

subject to

\[ \sum_tq_ty_t\ge w(q) \quad\text{for every pattern }q. \]

Separation amounts to computing

\[ \max_{\substack{q\in\mathbb Z_{\ge0}^{T}\\1\le |q|\le C}} \left(w(q)-\sum_tq_ty_t\right). \]

A violated constraint exists exactly when this maximum is positive.

Singleton constraints imply \(y_t\ge0\). The vector with every coordinate equal to \((C-1)/2\) is dual feasible by the universal upper bound. Consequently, an optimal dual solution can be sought in the rational box

\[ 0\le y_t\le \frac{C-1}{2\mu_t}. \]

It therefore suffices to give an FPT exact separation oracle.

5. Structure of an optimal pricing pattern

Lemma 1: Clique-support lemma

For every price vector \(y\), there is an optimal pricing pattern whose positive support is a clique of the loopless graph \(H\).

Proof

Let \(i\) and \(j\) be nonadjacent types occurring positively in a pattern. Fix all other coordinates and fix \(s=q_i+q_j\). Put \(q_i=x\) and \(q_j=s-x\).

Because \(a_{ij}=0\), the part of the reduced value depending on \(x\) has the form

\[ a_{ii}\binom{x}{2} +a_{jj}\binom{s-x}{2} +b_ix+b_j(s-x) \]

for constants \(b_i,b_j\). Its quadratic coefficient is

\[ \frac{a_{ii}+a_{jj}}2\ge0. \]

It is therefore convex in \(x\), so its maximum on the integer interval \(0\le x\le s\) occurs at \(x=0\) or \(x=s\). Thus all copies can be moved to one of \(i,j\) without decreasing the reduced value.

Repeatedly applying this operation eliminates every nonadjacent pair from the support. The resulting support is a clique. \(\square\)

Lemma 2: Only sizes \(1\) and \(C\) need be considered

Fix a clique \(A\subseteq T\). Among patterns supported in \(A\), the best reduced value with size between \(1\) and \(C\) is attained at size \(1\) or size \(C\).

Proof

Let \(d_i=a_{ii}\). If a pattern supported in \(A\) has total size \(r\), then all inter-type pairs are compatible, so

\[ w(q) =\binom r2-\sum_{i\in A:d_i=0}\binom{q_i}{2}. \]

For each \(i\in A\), define its successive marginal terms by

\[ \gamma_{i,j}=-y_i-(1-d_i)(j-1), \qquad j=1,2,\ldots. \]

For a fixed \(r\), maximizing the reduced value apart from \(\binom r2\) is equivalent to choosing the \(r\) largest terms from all the sequences \((\gamma_{i,j})_{j\ge1}\). Let these selected values, in nonincreasing order, be

\[ \delta_1\ge\delta_2\ge\cdots. \]

Prefix feasibility is automatic: if \(\gamma_{i,j}\) is selected, then every preceding term of its nonincreasing sequence can also be selected.

Thus the optimum for total size \(r\) is

\[ \Phi_A(r)=\binom r2+\sum_{\ell=1}^{r}\delta_\ell. \]

Every sequence is either constant or decreases by exactly \(1\). Therefore

\[ \delta_{r+1}\ge\delta_r-1. \]

Indeed, a successor of a term realizing \(\delta_r\) is still available and has value at least \(\delta_r-1\). Hence

\[ \bigl(\Phi_A(r+1)-\Phi_A(r)\bigr) - \bigl(\Phi_A(r)-\Phi_A(r-1)\bigr) = 1+\delta_{r+1}-\delta_r \ge0. \]

Thus \(\Phi_A\) is discretely convex. A convex sequence on \(\{1,\ldots,C\}\) attains its maximum at an endpoint, proving the lemma. \(\square\)

Exact computation for a fixed clique

For size \(C\), only the first \(C\) terms of each marginal sequence matter. The \(C\) largest terms among these implicit arithmetic progressions can be found in time polynomial in

\[ |A|,\quad \log C,\quad\text{and the encoding length of }y. \]

For a rational threshold \(\theta\), the number of terms larger than \(\theta\) in each sequence is computable directly by integer division. This gives a rank oracle. The candidate values are of the form \(-y_i-j\), with \(0\le j<C\), or the constant value \(-y_i\). Their encoding lengths are polynomial, and distinct candidates have inverse-exponentially bounded separation in the input length. Exact binary search using the rank oracle therefore identifies the \(C\)-th largest value in polynomially many steps. Arithmetic-series formulas then give both the optimum value and an optimizing multiplicity vector.

Thus binary encoding of \(C\) causes no pseudo-polynomial dependence on \(C\).

6. FPT pricing from a twin cover

Let \(X\) be a twin cover of \(H\), with \(|X|=k\). Under the standard twin-cover decomposition, every component \(B\) of \(H-X\) is a clique, and all vertices of \(B\) have the same neighborhood \(N_X(B)\) in \(X\). This is the standard characterization from [Ganian’s twin-cover paper](https://doi.org/10.46298/dmtcs.2136).

Every clique of \(H\):

  • has an intersection \(S\subseteq X\) that is a clique in \(H[X]\);
  • intersects at most one component \(B\) of \(H-X\);
  • if it intersects \(B\), then \(S\subseteq N_X(B)\).

Enumerate every subset \(S\subseteq X\). If \(S\) is a clique, examine:

  • the pool \(S\);
  • for every component \(B\) with \(S\subseteq N_X(B)\), the pool \(S\cup B\).

Every clique support is contained in one of these pools. Conversely, every such pool is a clique. Allowing zero multiplicities means it is unnecessary to enumerate subsets of \(B\).

There are at most

\[ 2^k\bigl(1+\text{number of components of }H-X\bigr) \]

candidate pools. For each one, Lemma 2 and the exact marginal-selection algorithm compute the best reduced value in polynomial time. Singleton patterns are checked separately.

Hence pricing runs in time

\[ 2^{O(k)}\,|I|^{O(1)}, \]

where \(|I|\) is the binary input length, including \(\log C\).

A twin cover of size \(k\) can itself be found in FPT time. One direct method forms the graph of edges whose endpoints are not true twins. Every twin cover must cover each such edge, so the usual bounded-search-tree algorithm for vertex cover runs in \(2^{O(k)}|T|^{O(1)}\) time.

7. From pricing to the fractional optimum

The preceding algorithm is an exact strong separation oracle for the bounded dual polyhedron. The standard rational ellipsoid optimization–separation theorem therefore computes its optimum in

\[ 2^{O(\operatorname{twc}(H))}\,|I|^{O(1)} \]

time. Strong LP duality then gives the primal fractional optimum, which can be compared exactly with \(K\).

Thus the problem is FPT parameterized by \(\operatorname{twc}(H)\), even when \(C\) is binary-encoded and unbounded.

Final classification

The fractional and discrete problems have different fixed-capacity behavior. The discrete problem retains an integral partition constraint and is NP-complete for fixed \(C\ge3\). The fractional problem is an explicit polynomial-size LP for every fixed \(C\). When \(C\) varies, the exponentially large pattern family restores NP-hardness, but twin cover makes its pricing problem fixed-parameter tractable.

  • polynomial-time solvability for every fixed \(C\);

No false central step or counterexample was found. The FPT argument has minor presentation gaps concerning ties in the marginal-selection lemma and the exact ellipsoid implementation, but these require clarification rather than new mathematics.

1. Configuration LP and NP membership

This part is correct.

  • Singleton patterns establish feasibility.
  • Summing the mass equations gives \(\sum_q |q|z_q=1\). Since every pattern has \(|q|\ge1\), this bounds every variable and hence the finite-dimensional feasible polytope.
  • A basic feasible solution has at most \(|T|\) positive variables because there are at most \(|T|\) linearly independent equality constraints.
  • Every certified pattern has \(|T|\) coordinates, each bounded by \(C\), so its binary encoding is polynomial in the input length.
  • Cramer’s rule gives polynomial-bit rational rates: the relevant subdeterminants have dimension at most \(|T|\), integer entries bounded by \(C\), and right-hand sides given by the rational masses.

Thus a polynomial-size certificate exists and can be checked exactly. The NP-membership claim is rigorous.

2. Fixed-capacity algorithm

The stars-and-bars count

\(\sum_{r=1}^{C}\binom{|T|+r-1}{r}=\binom{|T|+C}{C}-1\)

is correct. For fixed \(C\), this is polynomial in \(|T|\), so explicit pattern enumeration followed by rational LP optimization is polynomial time.

The special cases \(C=1\) and \(C=2\) are also correctly described.

3. NP-hardness reduction

The reduction from CLIQUE is correct.

Upper bound

For every pattern, \(w(q)\le\binom{|q|}{2}\le (C-1)|q|/2\). Summing against \(z_q\) and using \(\sum_q|q|z_q=1\) gives the claimed global bound \((C-1)/2\).

Because both inequalities have nonnegative slack, equality in the total value forces every positive-rate pattern to have size \(C\) and every positional pair in it to be compatible.

Construction and normalization

The mass calculation is correct:

\(\varepsilon+n(\varepsilon+(C-1)\varepsilon+C\varepsilon)=\varepsilon(1+2Cn)=1\).

Since \(C=k+1\le |V|+1\), the \(O(|V|k)\) introduced types and the compatibility description have polynomial size.

Completeness

All listed patterns have size \(C\). Their compatibility claims and mass contributions check out:

  • \(\{s\}\cup S\) is compatible precisely because \(S\) is a clique;
  • \(\{v\}\cup F_v\) and \(\{x_v\}\cup F_v\) are compatible by construction;
  • the repeated \(x_v\)-pattern is compatible because \(a_{x_vx_v}=1\);
  • for \(v\in S\), the total \(x_v\)-mass is \(\varepsilon+(C-1)\varepsilon=C\varepsilon\);
  • for \(v\notin S\), the repeated pattern supplies \(C\varepsilon\).

Thus the upper bound is attained.

Soundness

If the upper bound is attained, a positive-rate pattern containing \(s\) must exist. Because \(a_{ss}=0\), it contains one copy of \(s\). Its remaining \(C-1=k\) positions must be original types, since those are the only neighbors of \(s\). Their diagonal bits are zero, so they are distinct. Pairwise compatibility then makes them a \(k\)-clique in the original graph.

The reduction therefore proves NP-hardness.

4. Dual formulation and bounded search region

The dual is derived correctly. Deleting zero-mass types is valid because their primal mass equations prohibit their occurrence in every positive-rate pattern.

Singleton constraints imply \(y_t\ge0\). The uniform vector \(y_t=(C-1)/2\) is dual feasible. Consequently, some optimal solution has objective at most \((C-1)/2\), and nonnegativity then yields \(y_t\le(C-1)/(2\mu_t)\) for every remaining type.

The pricing objective and the criterion that a violation exists exactly when its maximum is positive are correct.

5. Pricing structure

Clique-support lemma

The pairwise consolidation argument is valid. For two nonadjacent supported types, holding their total multiplicity fixed produces a convex univariate quadratic. An endpoint therefore eliminates one of the two types without decreasing the reduced value. Each application strictly reduces support size, so the process terminates with clique support.

Endpoint-size lemma

The identity

\(w(q)=\binom r2-\sum_{i:a_{ii}=0}\binom{q_i}{2}\)

is correct for clique-supported patterns. The marginal sequences correctly represent the remaining objective, and the inequality \(\delta_{r+1}\ge\delta_r-1\) implies discrete convexity of \(\Phi_A\). Hence a maximum occurs at \(r=1\) or \(r=C\).

There are two minor rigor problems in the written proof:

  • “Prefix feasibility is automatic” is imprecise in the presence of ties. An arbitrary selection of the \(r\) largest labeled terms need not itself be prefix-closed. The prover must state an existence or tie-exchange formulation.
  • The sentence claiming that “a successor of a term realizing \(\delta_r\) is still available” is not literally guaranteed for an arbitrary realizing term; that successor might already be among the chosen terms. The inequality is still sound, but the choice of the relevant selected term must be specified.

These are expositional gaps, not failures of the lemma.

Exact marginal selection

The proposed rank-oracle method is plausible and polynomial in \(\log C\), but the exactness discussion is compressed. To make it fully verifiable, the prover should explicitly state:

  • the rational search interval;
  • a concrete lower bound on the separation between distinct candidates;
  • the stopping criterion;
  • how the exact threshold candidate and tie multiplicity are recovered;
  • how constant sequences are truncated to \(C\) relevant copies.

These are routine bit-complexity details and do not require a new algorithmic idea.

6. Twin-cover enumeration

The structural claims agree with the original definition and properties of twin cover: after deleting a twin cover, the remaining components are cliques of true twins, and deleting all non-twin edges reduces computation of twin cover to vertex cover. This is confirmed in [Ganian’s paper](https://dmtcs.episciences.org/2136/pdf).

The clique enumeration is correct:

  • a clique intersects at most one component of \(H-X\);
  • its intersection with \(X\) must be a clique;
  • if it uses a component \(B\), that intersection must lie in \(N_X(B)\);
  • every resulting pool \(S\cup B\) is a clique;
  • zero multiplicities allow one pool to represent all its subcliques.

The claimed \(2^{O(k)}|I|^{O(1)}\) pricing time follows.

7. Ellipsoid step

The conclusion is substantively correct, but the implementation is slightly underspecified. The bounded polyhedron is the dual intersected with the displayed coordinate box, so a complete strong-separation oracle must also separate violations of those box constraints. The prover should additionally record the polynomial encoding bounds for returned pattern inequalities and invoke the exact rational optimization–separation theorem with those hypotheses.

These are standard and easy additions, but they are necessary for a fully formal exact-FPT claim.

Final verdict

The NP-completeness reduction and fixed-\(C\) algorithm are fully rigorous. The FPT direction is sound in substance; its remaining issues are limited to exact tie handling and standard bit-complexity details. The output therefore resolves the target with minor gaps.
