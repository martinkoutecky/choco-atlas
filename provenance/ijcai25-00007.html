The continuous mirror question, as graded

Given a finite set of repeatable item classes \(A\), complete agent types \(\Theta\), rational type masses \(\mu\), rational per-capita inventories \(\rho\), and succinct monotone valuations \(V_t\) on integral bundles of class copies, find a finitely supported rational table \(z_{t,B}\) satisfying \(\sum_B z_{t,B}=\mu_t\) and \(\sum_{t,B}z_{t,B}b_a(B)=\rho_a\), with \(B\subseteq A_t\) whenever \(z_{t,B}>0\), such that every two supported cells satisfy EF1: \(z_{t,B},z_{u,B'}>0\) implies \(\exists a\in B'\) with \(V_t(B)\ge V_t(B'\setminus\{a\})\).

Definitions

Let \(H=(R,E)\) be a multigraph with \(|R|=10\). Each edge type \(e\) has symmetric additive weight \(w_e\); a role \(r\)'s value for an integral bundle \(B\in\mathbb Z_{\ge0}^{E}\) is \(V_r(B)=\sum_{e\ni r}w_e b_e(B)\). A bundle for \(r\) may contain only incident edge types.
A finite-support mass orientation is a family \(\lambda_{r,B}\ge0\) with \(\sum_B\lambda_{r,B}=\mu_r\) and \(\sum_{r,B}\lambda_{r,B}b_e(B)=\rho_e\) for every \(e\). It is EFX if, whenever \(\lambda_{r,A}\lambda_{s,B}>0\), then for every \(e\) with \(b_e(B)>0\), \(V_r(A)\ge V_r(B-\{e\})\), where \(B-\{e\}\) removes one copy of \(e\).
