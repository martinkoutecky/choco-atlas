The continuous mirror question, as graded

Given rational masses \(\mu\) over \(\tau\) complete agent types, per-capita resource capacities, integral outcomes \(\alpha\in\Gamma\), valuation vectors \(v_t\), and permutation-invariant polyhedral predictors \(T_t(\mu_{-t})\), compute an efficient aggregate allocation and each positive-mass type's normalized weakest-type price \(p_t=\min_{\widehat v\in T_t(\mu_{-t})}\left(\max_{\alpha\in\Gamma}\{\widehat v[\alpha]+B_{\mu,-t}(\alpha)\}-B_{\mu,-t}(\alpha_t^\star)\right)\), where \(B_{\mu,-t}(\alpha)\) is the normalized residual optimum when a tagged unit receives \(\alpha\), using time polynomial in \(\tau\) and the input encoding relative to an aggregate welfare/separation oracle.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) complete types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\) resources with nonnegative rational per-capita capacities \(c\), and a finite nonempty set \(\Gamma\) of integral individual outcomes. Each outcome has nonnegative integer resource consumption \(a(\alpha)\); each type has nonnegative rational per-capita values \(v_t[\alpha]\). Include a zero-consumption, zero-value outcome.
An aggregate allocation consists of rational masses \(x_{t,\alpha}\geq0\), with \(\sum_\alpha x_{t,\alpha}=\mu_t\) and \(\sum_{t,\alpha}x_{t,\alpha}a(\alpha)\leq c\); efficiency maximizes \(\sum_{t,\alpha}x_{t,\alpha}v_t[\alpha]\). Individual outcomes remain integral, while each type's mass may be split.
Write \(W(\nu,b)\) for this aggregate welfare optimum with masses \(\nu\) and capacities \(b\), retaining the reported valuations. A tagged unit has input binary-rational mass \(h\), where \(0<h\leq\min_t\mu_t\) and \(h a(\alpha)\leq c\) for every \(\alpha\in\Gamma\).
For each type, define \(\mu_{-t}=\mu-h e_t\) without renormalizing and \(B_{\mu,-t}(\alpha)=h^{-1}W(\mu_{-t},c-h a(\alpha))\). Thus the tag receives one common integral outcome and the remaining society is allocated by masses.
The evaluated predictors \(T_t(\mu_{-t})\subseteq\mathbb R_{\geq0}^{\Gamma}\) are supplied as nonempty rational polyhedra described by finitely many explicit linear inequalities; they depend only on the residual complete-type masses and are invariant under relabeling agents. They need not contain \(v_t\).
Let \(\alpha_t^\star\) maximize \(v_t[\alpha]+B_{\mu,-t}(\alpha)\), breaking ties by a supplied total order. Compute an efficient aggregate allocation and, for every positive-mass type, the tagged unit's per-capita price \(p_t=\min_{\widehat v\in T_t(\mu_{-t})}\max_{\alpha\in\Gamma}\{\widehat v[\alpha]+B_{\mu,-t}(\alpha)\}-B_{\mu,-t}(\alpha_t^\star)\).
An exact welfare oracle returns optimal values and maximizing allocations for aggregate instances, including instances with one tagged mass constrained to a single integral outcome, either fixed or optimized, and arbitrary nonnegative rational tagged valuations. Outcome consumptions and reported values are exactly evaluable; all representations, predictor constraints, numeric data, and the tag mass have total bit length \(L\).
Target. Is this exact allocation-and-price computation in \(\mathrm P\) relative to the stated welfare oracle, with polynomially many oracle calls and additional time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard even when that oracle is polynomial-time implementable?
Nearest known results. For finite agents, polyhedrally described weakest-type computations admit polynomially many exact welfare-oracle calls and polynomial additional time in the predictor encoding ([verified result](https://arxiv.org/html/2302.14234v5#S3.SS3)). No result settling this exact mass-and-tag formulation was located.

Modeling choices made when packaging the task

  • Normalized society masses to sum to one; interpreted capacities and valuations per capita and aggregate allocations as divisible masses over integral individual outcomes.
  • Introduced an explicit positive rational tagged mass h, because removing an unspecified unit from a probability distribution is undefined. Required h not to exceed any supported type's mass and required every tagged outcome to fit the capacities.
  • Defined residual masses by removing only the tagged mass, retaining the rest of its type, without renormalizing; defined normalized residual welfare by dividing its optimum by h.
  • Defined alpha_t^star through a separate efficient allocation with the tagged mass constrained to one integral outcome. An unrestricted aggregate optimum can split a type and therefore need not determine a single outcome for that type.
  • Required nonempty rational predictor polyhedra in the nonnegative valuation domain, supplied after evaluation; no correctness guarantee is imposed.
  • Specified nonnegative resource consumption and capacities, a zero-consumption zero-value outcome, and a supplied total order for outcome ties.
  • Specified that the welfare oracle handles residual aggregate instances and one integral tagged recipient, returns optimizing allocations as well as values, and accepts hypothetical tagged valuations.

Conclusion and encoding convention

The computation is in \(\mathrm P\) relative to the stated welfare oracle, under the ordinary explicit encoding of the supplied finite total order. I also prove the same conclusion for a succinct outcome space when the supplied order has a polynomial-time evaluable integer priority of polynomial bit length, usable in tagged-valuation queries.

The main observation is stronger than a general separation-oracle argument: each predictor minimization reduces to a polynomial-size explicit linear program, using only residual-welfare queries for coordinates appearing in the predictor constraints.

Here, “explicit linear inequalities” means ordinary lists of rational coefficients and named valuation coordinates. No succinctly specified, exponentially long rows are used.

1. Residual welfare is well defined

Fix a supported type \(t\). Write \(\nu=\mu-h e_t\), and abbreviate
\(B_t(\alpha)=h^{-1}W(\nu,c-h a(\alpha))\).

The assumptions give \(\nu\geq0\) and \(c-h a(\alpha)\geq0\). Assigning every residual mass to the zero outcome is feasible. Furthermore, every allocation variable lies between zero and its type’s residual mass. Thus the residual feasible set is a nonempty compact polytope, and its welfare maximum is attained.

Let \(\alpha_0\) be the zero-consumption, zero-value outcome, and define
\(b_t=h^{-1}W(\nu,c)=B_t(\alpha_0)\).

Because consumption is nonnegative, every allocation feasible at capacities \(c-h a(\alpha)\) is feasible at capacities \(c\). Nonnegative reported values also imply nonnegative welfare. Consequently,
\(0\leq B_t(\alpha)\leq b_t\) for every \(\alpha\in\Gamma\).

This bound is the key to eliminating unmentioned outcome coordinates.

2. An exact, small linear program for the weakest value

Let \(S_t\subseteq\Gamma\) contain exactly the valuation coordinates with nonzero coefficients in the supplied predictor inequalities. Its size is bounded by the predictor encoding length.

After collecting coefficients, write the predictor as
\(T_t=\{u\in\mathbb R_{\geq0}^{\Gamma}:A_t u_{S_t}\leq d_t\}\).

Coordinates outside \(S_t\) are constrained only to be nonnegative. For any \(u\in T_t\), define \(u'\) by retaining its coordinates in \(S_t\) and setting every other coordinate to zero. Then \(u'\in T_t\), and
\(\max_{\alpha}\{u'[\alpha]+B_t(\alpha)\}\leq\max_{\alpha}\{u[\alpha]+B_t(\alpha)\}\).

Therefore the minimization may be restricted to valuations supported on \(S_t\).

For such a valuation, represented by \(y\in\mathbb R_{\geq0}^{S_t}\), its objective is exactly
\(\max\bigl(\{b_t\}\cup\{y_\alpha+B_t(\alpha):\alpha\in S_t\}\bigr)\).

To verify this equality:

  • Every coordinate outside \(S_t\) contributes \(B_t(\alpha)\leq b_t\).
  • If \(\alpha_0\notin S_t\), its contribution equals \(b_t\).
  • If \(\alpha_0\in S_t\), its contribution is \(y_{\alpha_0}+b_t\geq b_t\).

Hence, defining
\(q_t=\min_{u\in T_t}\max_{\alpha\in\Gamma}\{u[\alpha]+B_t(\alpha)\}\),
we obtain the explicit linear program
\[ \text{minimize }z \quad\text{subject to}\quad A_t y\leq d_t,\qquad y\geq0,\qquad z\geq b_t,\qquad z\geq y_\alpha+B_t(\alpha)\quad(\alpha\in S_t). \]

The program has \(|S_t|+1\) variables and polynomially many explicitly encoded constraints.

Its optimum is attained. Indeed, nonemptiness of \(T_t\) provides a feasible \(y\), and then some finite feasible \(z_0\). Restricting to \(z\leq z_0\) gives
\(b_t\leq z\leq z_0\) and \(0\leq y_\alpha\leq z_0-B_t(\alpha)\leq z_0\).
This nonempty restricted feasible set is closed and bounded, so minimizing \(z\) over it attains the global optimum.

Computing its coefficients requires one query for \(W(\nu,c)\), and one fixed-tag or residual-welfare query for each \(\alpha\in S_t\). No enumeration of the remaining outcomes is required.

The coordinate-elimination idea is also present in the finite-agent result, [Theorem 3.9 of the supplied paper](https://arxiv.org/html/2302.14234v5#S3.SS3). The additional simplification here comes from the zero-consumption outcome and monotonicity in capacities.

3. Exact arithmetic has polynomial bit complexity

It remains to justify that the residual-welfare coefficients do not acquire exponentially many bits.

Put \(r=\tau+m\). After introducing resource slacks, each residual allocation problem has \(r\) equality rows:
\[ \sum_{\beta\in\Gamma}x_{s,\beta}=\nu_s,\qquad \sum_{s,\beta}a_j(\beta)x_{s,\beta}+s_j=b_j,\qquad x,s\geq0. \]

Its constraint matrix is integral. The type rows contain indicators, the resource rows contain integer consumptions, and slack columns contain indicators.

An optimal basic feasible solution exists. Its basis contains at most \(r\) columns. Cramer’s rule bounds its rational coordinates using a basis determinant and the denominators of the right-hand side.

These quantities have polynomial bit length:

  • Each right-hand-side entry is an input mass or capacity, or a difference involving \(h\). Its bit length is polynomial in \(L\).
  • Taking the product of the denominators of the \(r\) right-hand-side entries gives a common denominator of polynomial bit length.
  • Basis entries have polynomial bit length. For explicit outcomes this follows directly from the input encoding; alternatively, tag feasibility gives \(a_j(\alpha)\leq c_j/h\).
  • Hadamard’s determinant bound gives polynomial bit length for every \(r\)-column basis determinant.
  • At most \(r\) allocation variables are positive at a basic solution. Summing their products with the reported rational values preserves polynomial bit length.

Thus every \(W(\nu,c-h a(\alpha))\), and consequently every \(B_t(\alpha)\), has polynomial bit length. Division by \(h\) adds only polynomially many bits, even when \(h\) is numerically very small.

The linear program in Section 2 therefore has polynomial total encoding length. We use the standard exact rational linear-programming theorem: an explicitly encoded rational linear program can be optimized in polynomial bit complexity, with feasibility and boundedness decided as part of the computation. Here feasibility and a finite attained optimum were verified above. See, for example, the [MIT notes on linear-programming size and complexity](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/908fe54d659623efadda2d033b895caf_notes_lp.pdf).

4. Computing the prescribed tagged outcome

For an explicitly supplied ordered list of outcomes, compute \(B_t(\alpha)\) for every outcome and select the first maximizer of
\(v_t[\alpha]+B_t(\alpha)\)
in that order.

This uses at most \(\tau|\Gamma|\) residual-welfare queries. Since an explicit order list contributes to \(L\), this is polynomial in the required parameters. Values already queried for Section 2 can be reused.

One must respect this tie-breaking rule: an arbitrary maximizing tagged outcome need not give the prescribed price.

For example, take one type of mass \(1\), tag mass \(h=1/2\), capacity \(c=1/2\), and two outcomes: the zero outcome and an outcome with consumption \(1\) and value \(2\). Then
\(B_t(\alpha_0)=2\) and \(B_t(\alpha_1)=0\), while both tagged scores equal \(2\). For the predictor containing only the zero valuation, \(q_t=2\). The price is \(0\) if the order selects \(\alpha_0\), and \(2\) if it selects \(\alpha_1\).

For completeness, there is also a polynomial-call implementation for potentially exponential outcome spaces with a suitably encoded priority order.

Assume an integer priority \(\rho(\alpha)\) is efficiently evaluable, larger priorities are preferred, and
\(0\leq\rho(\alpha)\leq R\),
where \(R\) has polynomial bit length. Assume the oracle accepts the resulting composed tagged valuation in polynomial-size representation.

By Section 3, a computable polynomial bound \(K\) exists such that every score
\(f_t(\alpha)=v_t[\alpha]+B_t(\alpha)\)
has reduced denominator at most \(2^K\). Two distinct scores therefore differ by at least \(2^{-2K}\).

Choose a positive binary rational \(\varepsilon\), of polynomial bit length, satisfying
\(\varepsilon R<2^{-2K}\).
Query the optimized-tag oracle with the nonnegative tagged valuation
\(w_t[\alpha]=v_t[\alpha]+\varepsilon\rho(\alpha)\).

For a fixed tag outcome \(\alpha\), the optimized total welfare is
\(h w_t[\alpha]+W(\nu,c-h a(\alpha)) =h(f_t(\alpha)+\varepsilon\rho(\alpha))\).

The perturbation cannot reverse unequal original scores, and among equal scores it selects exactly the preferred outcome. Thus the returned tagged outcome is \(\alpha_t^\star\).

If the oracle returns total welfare \(Q_t\), its residual allocation must be optimal conditional on that tagged outcome; otherwise replacing it by a better residual allocation would increase \(Q_t\). Hence
\(B_t(\alpha_t^\star)=Q_t/h-w_t[\alpha_t^\star]\).

This computes the required subtraction term with one optimized-tag query per type.

5. Complete algorithm and complexity

The algorithm is:

  • Query the aggregate welfare oracle on \((\mu,c)\), and return its maximizing aggregate allocation.
  • For each supported type \(t\), compute \(b_t\) and the values \(B_t(\alpha)\) for \(\alpha\in S_t\).
  • Solve the explicit linear program from Section 2 to obtain \(q_t\).
  • Find the prescribed tagged maximizer as in Section 4.
  • Return \(p_t=q_t-B_t(\alpha_t^\star)\).

Every returned price equals the expression in the question by Sections 2 and 4.

With an explicit order list, a valid upper bound on the number of welfare queries is
\(1+\tau+\sum_t|S_t|+\tau|\Gamma|\),
which is polynomial in \(m,\tau,L\). All additional computation has polynomial bit complexity.

With succinct outcomes and the integer-priority encoding described above, the query bound improves to
\(1+\sum_t(|S_t|+2)\).

The algorithm never expands masses into individual agents and never renormalizes residual masses. The aggregate allocation and the separate tagged optimizations are computed exactly as defined.

Thus, with the stated explicit encoding—and also with the specified conventional succinct-order encoding—the allocation-and-price computation is polynomial-time solvable relative to the welfare oracle. If that oracle is polynomial-time implementable, the entire computation is polynomial-time implementable.
