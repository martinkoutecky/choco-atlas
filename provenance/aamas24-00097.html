The anchor (named result in the paper)

Theorem 4.10 — class: hardness

The continuous mirror question, as graded

Given a bounded-degree tree \(F=(V,E)\), rational house values \(h_1,\ldots,h_q\), and rational masses \(\nu_1,\ldots,\nu_q\) with \(\sum_j\nu_j=1\), consider a continuum of exchangeable copies of \(F\) with pooled house supply \(n\nu_j\) per copy on average, where \(n=|V|\). Choose a distribution \(p\) over configurations \(a:V\to\{1,\ldots,q\}\) satisfying \(\sum_a p_a=1\) and \(\sum_a p_a|\{v:a(v)=j\}|=n\nu_j\), minimizing \(\sum_a p_a\sum_{\{u,v\}\in E}|h_{a(u)}-h_{a(v)}|\).

Packaged proof task (what the prover saw — nothing else)

Let \(F=(V,E)\) be an explicitly given nonempty undirected tree, with \(n:=|V|\) and maximum degree at most a fixed constant \(\Delta\).
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here the types are house values \(0\le h_1<\cdots<h_q\), with \(h_j\in\mathbb Q\), \(\nu_j\in\mathbb Q_{>0}\), \(\sum_j\nu_j=1\), and \(\tau=q\).
There is a continuum of copies of \(F\), of total copy mass one, sharing a pooled supply of \(n\nu_j\) houses of type \(j\). Each vertex receives one house.
A configuration is any map \(a:V\to\{1,\ldots,q\}\). An allocation is a distribution \((p_a)_a\), with \(p_a\in\mathbb R_{\ge0}\), satisfying \(\sum_a p_a=1\) and \(\sum_a p_a|\{v\in V:a(v)=j\}|=n\nu_j\) for every \(j\); there are no supply constraints within individual copies.
Its cost is \(C(p):=\sum_a p_a\sum_{\{u,v\}\in E}|h_{a(u)}-h_{a(v)}|\). Given a binary rational threshold \(B\ge0\), decide whether some feasible allocation has \(C(p)\le B\).
Use \(m:=n\), and let \(L\) be the total binary input length, including the tree, values, masses, and threshold; state running times in \(m,\tau,L\), with \(\Delta\) fixed.

Is this pooled-supply decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard, on trees of bounded maximum degree?

For the discrete version, assigning a multiset of \(n\) nonnegative house values bijectively to the vertices is NP-hard on bounded-degree trees, and a polynomial-time \(O(\log n)\)-approximation is known ([source](https://arxiv.org/html/2307.12482v2)).
No result settling this exact continuous formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Restricted rational house values to nonnegative values, following the discrete model; equal-valued supply types are merged and their masses added.
  • Interpreted bounded degree as a fixed constant bound independent of input size, and required a nonempty tree.
  • Normalized total copy mass to one, consistent with the specified average supply per copy.
  • Made distribution weights explicitly nonnegative real numbers.
  • Expressed exact minimization as a decision problem using a nonnegative binary rational cost threshold.
  • Set m equal to the number of vertices and tau equal to the number of positive-mass house-value types; defined L as total binary input length.

Conclusion

The stated pooled-supply problem is in \(\mathrm P\): every valid instance has optimal cost \(\mathbf{0}\), so every allowed threshold \(B\ge 0\) gives a YES answer.

This holds even when \(m\ge 2\) and \(\tau\ge 2\). It follows from the explicit permission to pool supply across copies, without supply constraints within individual copies.

A feasible allocation of zero cost

For each \(j\in\{1,\ldots,\tau\}\), define the constant configuration
\[ a^{(j)}(v)=j\qquad\text{for every }v\in V. \]
Assign probabilities
\[ p_{a^{(j)}}=\nu_j, \qquad p_a=0\quad\text{for every other configuration }a. \]

These are distinct configurations because \(V\ne\varnothing\). The probabilities are nonnegative and sum to one by the hypotheses on the masses.

For each type \(k\), its expected number of assigned houses is
\[ \sum_a p_a\,|\{v\in V:a(v)=k\}| =\sum_{j=1}^{\tau}\nu_j\,m\,\mathbf 1_{\{j=k\}} =m\nu_k. \]
Thus every pooled-supply constraint holds exactly.

In each configuration receiving positive probability, the endpoints of every edge have identical house values. Consequently,
\[ C(p) =\sum_{j=1}^{\tau}\nu_j \sum_{\{u,v\}\in E}|h_j-h_j| =0. \]
Every allocation has nonnegative cost, since each summand in its cost is nonnegative. Therefore the minimum is exactly zero.

Characterization of all optimal allocations

In fact, the allocation above is the unique optimal distribution for the given tree.

To prove this, suppose \(C(p)=0\). The configuration costs and probabilities are nonnegative, so every configuration \(a\) with \(p_a>0\) must have zero cost. Each of its edge costs must therefore vanish:
\[ h_{a(u)}=h_{a(v)} \qquad\text{for every }\{u,v\}\in E. \]
Because the values are strictly increasing, this implies \(a(u)=a(v)\). Connectivity then implies that \(a\) is constant on \(V\). For the single-vertex tree, every configuration is already constant.

Hence an optimal distribution is supported only on the configurations \(a^{(j)}\). Its supply constraint for type \(j\) becomes
\[ m\,p_{a^{(j)}}=m\nu_j. \]
Since \(m>0\), necessarily \(p_{a^{(j)}}=\nu_j\), proving uniqueness.

Complexity and the discrete comparison

On inputs satisfying the stated promises, the decision algorithm simply returns YES. Including reading the input, its running time is \(O(m+\tau+L)=O(L)\). An explicit optimal witness listing all \(\tau\) configurations can be produced in
\[ O\!\left(L+m\tau\left\lceil\log_2(\tau+1)\right\rceil\right) \]
bit operations, using the input vertex order and copying the rational masses without arithmetic. The degree bound is unnecessary.

The cited discrete problem requires a bijection from vertices to a fixed multiset of houses. [The paper’s model](https://arxiv.org/html/2307.12482v2) imposes that requirement within the single graph. Here, a fraction \(\nu_j\) of copies may receive exclusively type \(j\), consuming exactly \(m\nu_j\) houses from the pooled supply. Thus the discrete hardness does not transfer. A nonzero optimum would require an additional constraint absent from the stated formulation.
