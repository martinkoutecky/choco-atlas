The continuous mirror question, as graded

Given candidates \(C\), committee limit \(k\), a fixed tie-breaking order, and a rational distribution \(\mu\) over \(\tau\) ballot types \(t=(A_t,D_t)\), find \(T\subseteq C\). For each \(U\subseteq C\), retain disapprovals \(D_t\cap U\), set \(a_\mu(c)=\sum_{t:c\in A_t}\mu_t\) and \(d_{\mu,U}(c)=\sum_{t:c\in D_t\cap U}\mu_t\), and make \(c\) eligible when \(a_\mu(c)>d_{\mu,U}(c)\), at price \(p_U(c)=a_\mu(c)/(a_\mu(c)-d_{\mu,U}(c))\). Run weighted Tax-MES with initial per-unit budgets \(k\) and affordability condition \(\sum_{t:c\in A_t}\mu_t\min(b_t,\rho)=p_U(c)\), updating each \(b_t\) after a purchase. Writing \(W_U\) for the resulting positive committee, require that no candidate outside \(T\) belongs to \(W_T\), and that for every \(c\in T\setminus W_T\), candidate \(c\) belongs to \(W_{T\setminus\{c\}}\).

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) of size \(m\), an integer \(1\leq k\leq m\), and a fixed strict tie-breaking order on \(C\), each ballot type is \(t=(A_t,D_t)\), where \(A_t,D_t\subseteq C\) and \(A_t\cap D_t=\emptyset\); unlisted candidates are neutral.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. State running times in \(m,\tau,L,k\).
For every \(U\subseteq C\), retain disapprovals \(D_t\cap U\). Define \(a_\mu(c)=\sum_{t:c\in A_t}\mu_t\) and \(d_{\mu,U}(c)=\sum_{t:c\in D_t\cap U}\mu_t\). Only candidates with \(a_\mu(c)>d_{\mu,U}(c)\) are eligible, at fixed price \(p_U(c)=a_\mu(c)/(a_\mu(c)-d_{\mu,U}(c))\).
Define weighted Tax-MES as follows: initially each type has per-unit budget \(b_t=k\). In each round, for every unelected eligible candidate find the least \(\rho\geq0\) satisfying \(\sum_{t:c\in A_t}\mu_t\min(b_t,\rho)=p_U(c)\), if one exists; purchase the candidate with smallest such \(\rho\), resolving ties by the given order.
For its approving types update \(b_t\gets b_t-\min(b_t,\rho)\); other budgets stay unchanged. Stop when no candidate is affordable or \(k\) candidates have been purchased, without a completion phase. Let \(W_U\subseteq C\) be the purchased committee; every counterfactual run starts with fresh budgets.
Seek \(T\subseteq C\) satisfying \(W_T\subseteq T\) (Counterfactual Veto Deletion, CVD) and \(c\in W_{T\setminus\{c\}}\) for every \(c\in T\setminus W_T\) (Maximal Veto Deletion, MVD).

Is finding such a set \(T\), or correctly reporting that none exists, solvable in polynomial time in \(m,\tau,L,k\), or is this problem NP-hard?

For finite electorates, every polynomial-time computable resolute rule admits a polynomial-time computable set satisfying CVD and the weaker IMVD condition: deleting any \(c\in T\setminus W_T\) makes CVD fail. This does not require that \(c\) itself wins after deletion. [Source](https://arxiv.org/html/2503.01985v2#S3.SS3).
Finite-electorate PAV and Phragmén can fail to admit any CVD–MVD set; that result concerns different rules. [Source](https://arxiv.org/html/2503.01985v2#S3.SS3). No result settling the specified weighted Tax-MES problem was located.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one, making the stated per-unit initial budget k a total election budget of k.
  • Specified disjoint approval and disapproval sets, neutrality for other candidates, and the domain 1 ≤ k ≤ m.
  • Specified least-affordability selection, supporter-only budget updates, fresh budgets for every counterfactual run, and termination without completion.
  • Allowed reporting nonexistence because the graded question imposes MVD, whose satisfiability is not guaranteed by the anchor.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is polynomial-time solvable. In fact, every instance of the specified weighted Tax-MES rule admits a set satisfying both CVD and MVD.

The key is that changing vetoes against an unelected candidate has no effect on the run unless that candidate becomes elected.

1. Locality of veto deletion

For any candidate \(x\),
\(d_{\mu,U}(x)=d_{\mu,C}(x)\) if \(x\in U\), and \(d_{\mu,U}(x)=0\) otherwise. Consequently, replacing \(U\) by \(U\setminus\{c\}\) changes only the eligibility and price of \(c\). Approvals, initial budgets, and every other candidate’s eligibility and price remain identical.

A *purchase trace* records the ordered purchased candidates, their payment thresholds, and the budgets after every purchase.

Lemma. Suppose \(c\in U\setminus W_U\). If \(c\notin W_{U\setminus\{c\}}\), then the runs for \(U\) and \(U\setminus\{c\}\) have identical purchase traces.

*Proof.* Write \(U'=U\setminus\{c\}\). Both runs start with identical budgets. Inductively, suppose their purchases, thresholds, and budgets agree through the first \(r\) purchases.

If \(r=k\), both runs stop. Otherwise, at their common budget state, every remaining candidate other than \(c\) has the same eligibility, affordability, and least payment threshold in both runs.

If the \(U\)-run next purchases \(x\), then \(x\ne c\), by the hypothesis \(c\notin W_U\). Among candidates other than \(c\), \(x\) minimizes the payment threshold, with ties resolved by the fixed order. The same comparison holds in the \(U'\)-run. That run cannot stop, because \(x\) is affordable. It cannot purchase \(c\), by the hypothesis \(c\notin W_{U'}\). Thus it purchases \(x\), at the same threshold. The identical supporter sets and update formula give identical new budgets.

If instead the \(U\)-run stops before reaching \(k\), no remaining candidate other than \(c\) is affordable in either run. The \(U'\)-run cannot purchase \(c\), again by hypothesis, so it also stops.

Induction proves equality of the complete traces. \(\square\)

Corollary. If \(W_U\subseteq U\) and \(c\in U\setminus W_U\), then
\(W_{U\setminus\{c\}}\subseteq U\setminus\{c\}\) holds if and only if
\(c\notin W_{U\setminus\{c\}}\).

*Proof.* The forward implication follows because \(c\notin U\setminus\{c\}\). For the reverse implication, the lemma gives
\(W_{U\setminus\{c\}}=W_U\subseteq U\setminus\{c\}\). \(\square\)

Thus, at a CVD set, deleting a losing candidate makes CVD fail precisely when that candidate becomes elected. For this rule, CVD–IMVD therefore implies CVD–MVD. This supplies the additional property needed beyond the general [CVD–IMVD guarantee in the cited paper](https://arxiv.org/html/2503.01985v2#S3.SS3).

2. Algorithm and correctness

Use the following algorithm. Every Tax-MES evaluation starts with fresh budgets.

  • Set \(T=C\), and compute \(W=W_C\).
  • Scan the candidates in \(T\setminus W\). For each \(c\), compute \(W_{T\setminus\{c\}}\).
  • If \(c\notin W_{T\setminus\{c\}}\), replace \(T\) by \(T\setminus\{c\}\) and restart the scan.
  • If an entire scan makes no deletion, return \(T\).

We prove the invariant that \(W_T=W\) and \(W\subseteq T\).

Initially this holds because \(T=C\). Whenever the algorithm deletes \(c\), we have \(c\in T\setminus W_T\) and \(c\notin W_{T\setminus\{c\}}\). The lemma implies that this deletion preserves the entire purchase trace, hence preserves \(W_T=W\). Since \(c\notin W\), the inclusion \(W\subseteq T\) also persists.

Each successful deletion strictly decreases \(|T|\), so there are at most \(m\) deletions. The algorithm therefore terminates. Its invariant proves CVD for the returned set. At termination, every \(c\in T\setminus W_T\) was tested against the final set \(T\), and no deletion was accepted. Hence
\(c\in W_{T\setminus\{c\}}\) for every such \(c\), proving MVD.

The algorithm uses at most \(1+m(m+1)\) Tax-MES evaluations: one initial evaluation and at most \(m\) tests in each of at most \(m+1\) scans.

It remains to show that these evaluations take polynomial bit time for the support-encoded rational input.

3. Exact evaluation of weighted Tax-MES

Write each mass as \(\mu_t=u_t/v_t\), with positive integers \(u_t,v_t\), and define
\(Q=\prod_{t=1}^{\tau}v_t\) and \(w_t=u_tQ/v_t\).

Then all \(w_t\) are positive integers,
\(\mu_t=w_t/Q\), and \(\sum_t w_t=Q\). Because the denominator encodings are part of the input,
\(\log_2 Q\le L\).

For a candidate \(c\), define
\(s_c=\sum_{t:c\in A_t}w_t\) and
\(n_c=s_c-\sum_{t:c\in D_t\cap U}w_t\).
The candidate is eligible exactly when \(n_c>0\); its price is then
\(p_U(c)=s_c/n_c\), where \(1\le n_c\le s_c\le Q\).

Represent all current budgets using a common denominator:
\(b_t=x_t/H\), with integers \(H>0\) and \(0\le x_t\le kH\).

For an eligible candidate, first compute its supporters’ total remaining funds,
\(\sum_{t:c\in A_t}w_tx_t/(QH)\).
If this is below its price, the candidate is unaffordable.

Otherwise, sort its supporters by their budgets. The function
\(f_c(\rho)=\sum_{t:c\in A_t}\mu_t\min(b_t,\rho)\)
is continuous and piecewise affine, with breakpoints at those budgets. Affordability and positive price ensure that the least solution occurs in a segment having positive slope.

On any such segment, let \(I\) be the supporters whose budgets are capped, and let \(J\) be the remaining supporters. Put
\(E=\sum_{t\in I}w_tx_t\) and \(S=\sum_{t\in J}w_t>0\).
The affordability equation becomes
\(E/(QH)+(S/Q)\rho=s_c/n_c\), giving the exact threshold

\(\displaystyle \rho=\frac{s_cQH-n_cE}{n_cHS}.\)

Scanning the sorted breakpoints finds the segment containing this value. This also handles equality with the supporters’ total funds: the least threshold is then their largest positive budget.

Thus each candidate’s threshold is computable by sorting and a linear scan. Exact rational comparison, followed by the given tie-breaking order, determines the next purchase.

4. Bit lengths and running time

Initially \(H=1\). Suppose a purchased candidate has threshold expressed by the preceding formula. All updated budgets can be represented with denominator
\(H'=Hn_cS\): subtracting the threshold from an approving type’s budget, and taking the maximum with zero, uses this denominator; other types’ numerators are simply rescaled.

Because \(n_c\le Q\) and \(S\le Q\), we have \(H'\le HQ^2\). After \(r\) purchases,

\(\displaystyle H\le Q^{2r},\qquad \log_2H\le 2rL.\)

Moreover, \(0\le x_t\le kH\). Since \(r\le k\), budget numerators and denominators, threshold numerators and denominators, and intermediate comparison quantities all have bit length
\(O(kL+\log_2(k+1))\).

Set
\(B=kL+\lceil\log_2(k+1)\rceil+1\).
Using elementary integer arithmetic, each arithmetic operation or rational comparison costs \(O(B^2)\) bit operations. Computing one candidate’s threshold takes
\(O(\tau\log_2(\tau+1))\) such operations. There are at most \(m\) candidate evaluations per round and \(k+1\) rounds, including a possible final affordability check. Therefore one Tax-MES run costs

\(\displaystyle O\!\left(km\tau\log_2(\tau+1)B^2\right)\)

bit operations after preprocessing. Constructing the common mass denominator and integer weights takes \(O(L^3)\) bit operations by elementary arithmetic; candidate mass sums fit within the stated overall bound.

Combining this with the number of counterfactual evaluations gives the explicit polynomial upper bound

\(\displaystyle O\!\left(L^3+m^3k\tau\log_2(\tau+1)\bigl(kL+\log_2(k+1)+1\bigr)^2\right).\)

This uses the listed support of size \(\tau\), without expanding the rational masses into individual voters. The existence proof and the bit-complexity bound together completely resolve the specified problem.
