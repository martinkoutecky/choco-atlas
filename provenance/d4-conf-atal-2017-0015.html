The continuous mirror question, as graded

Given a star \(H=(T,F)\), rational masses \(\mu_t>0\) summing to \(1\), and a succinct exact evaluator for a continuous nonnegative worth function \(V:\prod_{t\in T}[0,\mu_t]\to\mathbb{R}_{\ge 0}\) with \(V(0)=0\), decide whether there is a per-capita payoff vector \(p\in\mathbb{R}_{\ge 0}^{T}\) such that \(\sum_t\mu_t p_t=V(\mu)\) and \(\sum_t z_t p_t\ge V(z)\) for every \(z\in\prod_{t\in T}[0,\mu_t]\) whose positive-support types induce a connected subgraph of \(H\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of the \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The input includes an undirected star \(H=(T,F)\), with \(m=|F|\), and an exact evaluator represented by a rational arithmetic formula using \(+,-,\times,\min,\max\). Let \(L\) be the total input bit length. The formula defines a continuous function \(V:\prod_{t\in T}[0,\mu_t]\to\mathbb R_{\ge0}\), with \(V(0)=0\); nonnegativity and normalization are promises.
A coalition is a mass vector \(z\) in this box. It is feasible if \(z=0\) or its positive support \(\{t:z_t>0\}\) induces a connected subgraph of \(H\); singleton supports and arbitrarily small positive masses are allowed.
The continuous core consists of per-capita vectors \(p\in\mathbb R_{\ge0}^{T}\) satisfying \(\sum_{t\in T}\mu_t p_t=V(\mu)\) and \(\sum_{t\in T}z_t p_t\ge V(z)\) for every feasible \(z\). No cohesiveness, superadditivity, or supermodularity is assumed.

Is deciding whether this continuous core is nonempty solvable in time polynomial in \(m,\tau,L\), or is it NP-hard under polynomial-time Turing reductions?

For finite players, core nonemptiness with nonnegative, polynomial-time evaluable worths is coNP-complete even on stars; on trees, it is equivalent to cohesiveness, meaning that no partition into connected coalitions has total worth exceeding the grand coalition's worth ([source](https://www.ifaamas.org/Proceedings/aamas2017/pdfs/p299.pdf)). No result settling the continuous problem with the specified evaluator representation was located.

Modeling choices made when packaging the task

  • The succinct exact evaluator had no specified encoding. It is represented by a rational arithmetic formula with addition, subtraction, multiplication, minimum, and maximum; this gives exact polynomial-time evaluation on rational inputs and a defined extension to real inputs.
  • The empty coalition is feasible by convention, matching the discrete definition; its constraint is redundant because V(0)=0.
  • The parameter m is the number of graph edges, and L includes the graph, masses, and evaluator.
  • Hardness uses polynomial-time Turing reductions because the anchor establishes coNP-completeness for the yes question of nonemptiness.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Deciding continuous-core nonemptiness is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. More strongly, it is \(\mathrm{coNP}\)-hard under polynomial-time many-one reductions, even with uniform dyadic masses, a continuous piecewise-affine evaluator, and \(V(\mu)=1\).

The finite-player star result appears in [Igarashi, Theorem 5.9](https://www.ifaamas.org/Proceedings/aamas2017/pdfs/p299.pdf). The following reduction directly establishes hardness for the specified continuous formula representation.

1. A consequence of continuity.

For any connected graph \(H\), the feasible coalition vectors are dense in the entire box. Indeed, for any vector \(z\) in the box and \(0<\varepsilon<1\), define
\[ z^{(\varepsilon)}=(1-\varepsilon)z+\varepsilon\mu. \]
Every coordinate of \(z^{(\varepsilon)}\) is positive, so its support is the connected graph \(H\). Moreover, \(z^{(\varepsilon)}\) converges to \(z\).

Consequently, if \(p\) satisfies every feasible-coalition inequality, continuity gives
\[ \sum_t z_t p_t =\lim_{\varepsilon\to0}\sum_t z_t^{(\varepsilon)}p_t \ge \lim_{\varepsilon\to0}V(z^{(\varepsilon)}) =V(z). \]
Thus, in this continuous model, the inequalities for feasible coalitions imply the inequalities for the whole box. The reduction below nevertheless supplies an explicitly feasible violating coalition.

2. A continuous satisfiability detector.

Let \(\Phi\) be a \(\mathrm{3SAT}\) instance with variables \(u_1,\ldots,u_n\) and clauses \(K_1,\ldots,K_q\), where \(n,q\ge1\).

For \(x\in[0,1]^n\), define each literal’s value by
\[ \lambda_{u_i}(x)=x_i,\qquad \lambda_{\neg u_i}(x)=1-x_i. \]
Define
\[ C_\Phi(x)=\min_{1\le j\le q}\ \max_{\ell\in K_j}\lambda_\ell(x), \qquad D(x)=\sum_{i=1}^n\min(x_i,1-x_i), \]
and
\[ A_\Phi(x)=\max\bigl(0,C_\Phi(x)-D(x)\bigr). \]

Lemma. If \(\Phi\) is unsatisfiable, then \(A_\Phi(x)=0\) throughout \([0,1]^n\). If \(\Phi\) is satisfiable, some \(a\in\{0,1\}^n\) satisfies \(A_\Phi(a)=1\).

Proof. Given any \(x\), round its coordinates to the Boolean assignment
\[ a_i= \begin{cases} 0,&x_i<1/2,\\ 1,&x_i\ge1/2. \end{cases} \]
Write \(d_i=\min(x_i,1-x_i)\). Every literal that is false under \(a\) has continuous value exactly \(d_i\): a false positive literal has \(a_i=0\) and value \(x_i=d_i\); a false negative literal has \(a_i=1\) and value \(1-x_i=d_i\).

If \(\Phi\) is unsatisfiable, some clause \(K_j\) is false under \(a\). All its literals therefore have values bounded by \(D(x)\), giving
\[ C_\Phi(x) \le \max_{\ell\in K_j}\lambda_\ell(x) \le D(x). \]
Hence \(A_\Phi(x)=0\).

Conversely, at a satisfying Boolean assignment \(a\), every clause has maximum literal value \(1\), while \(D(a)=0\). Therefore \(A_\Phi(a)=1\). This proves the lemma.

3. Constructing the society and evaluator.

Let
\[ N=2^{\lceil\log_2(n+1)\rceil}. \]
Construct a star with \(N\) types: a center \(c\), variable leaves \(t_1,\ldots,t_n\), and \(N-n-1\) additional leaves. Give every type mass
\[ \mu_t=\frac1N. \]
These masses are positive dyadic rationals and sum to \(1\).

For any coalition \(z\), put
\[ x_i=Nz_{t_i},\qquad y=Nz_c. \]
All these normalized coordinates lie in \([0,1]\). Define
\[ B_\Phi(z)=\min\bigl(y,1-y,A_\Phi(x)\bigr), \qquad V_\Phi(z)=\sum_{t\in T}z_t+B_\Phi(z). \]

This evaluator meets every promise:

  • It is a rational arithmetic formula using only the permitted operations. Multiplication occurs only by the integer constant \(N\).
  • It is continuous and piecewise affine.
  • Since \(y\), \(1-y\), and \(A_\Phi(x)\) are nonnegative throughout the box, \(B_\Phi(z)\ge0\), so \(V_\Phi(z)\ge0\).
  • At \(z=0\), the gate coordinate is \(y=0\), giving \(B_\Phi(0)=0\) and \(V_\Phi(0)=0\).
  • At the grand coalition, \(y=1\), so \(B_\Phi(\mu)=0\) and

\[ V_\Phi(\mu)=\sum_t\mu_t=1. \]

4. The singleton constraints force a unique candidate payoff.

Let \(e_t\) denote the coordinate unit vector for type \(t\). The full-mass singleton coalition \(\mu_t e_t\) is feasible.

If \(t=c\), its gate coordinate is \(y=1\); otherwise it is \(y=0\). In either case the bonus vanishes, and
\[ V_\Phi(\mu_t e_t)=\mu_t. \]
Every core vector must therefore satisfy
\[ \mu_t p_t\ge\mu_t, \]
hence \(p_t\ge1\) for every type.

Efficiency requires
\[ \sum_t\mu_t p_t=V_\Phi(\mu)=1=\sum_t\mu_t. \]
Because every \(\mu_t\) is positive and every \(p_t-1\) is nonnegative, this equality forces \(p_t=1\) for every type. Thus the only possible core vector is \(\mathbf1\).

5. Correctness of the reduction.

Suppose first that \(\Phi\) is unsatisfiable. By the lemma, \(A_\Phi(x)=0\) everywhere. Consequently,
\[ B_\Phi(z)=0,\qquad V_\Phi(z)=\sum_t z_t \]
throughout the box. The vector \(p=\mathbf1\) satisfies efficiency and every coalitional inequality with equality. The core is therefore nonempty.

Now suppose that \(\Phi\) has a satisfying assignment \(a\in\{0,1\}^n\). Choose the coalition
\[ z_c=\frac1{2N},\qquad z_{t_i}=\frac{a_i}{N}, \]
and give every additional leaf mass zero. Its support contains the center and some subset of its leaves, so it induces a connected subgraph, including when that subset is empty.

Here \(y=1/2\), \(x=a\), and \(A_\Phi(a)=1\). Hence
\[ B_\Phi(z)=\frac12,\qquad V_\Phi(z)=\sum_t z_t+\frac12. \]
The unique candidate payoff \(p=\mathbf1\) violates this feasible coalition’s inequality:
\[ \sum_t z_t p_t=\sum_t z_t<V_\Phi(z). \]
Thus the core is empty.

We have proved the exact equivalence
\[ \Phi\text{ is unsatisfiable} \quad\Longleftrightarrow\quad \operatorname{Core}(V_\Phi,H,\mu)\ne\varnothing. \]

6. Encoding size and complexity conclusion.

Since \(N<2(n+1)\), the construction has
\[ \tau=N,\qquad m=N-1, \]
both polynomial in the source input size. Every mass and scaling constant has \(O(\log(n+2))\) bits.

After expanding the definitions, the evaluator is an arithmetic formula, without any need for shared subexpressions. The baseline sum uses \(O(N)\) operations, the clause detector uses \(O(q)\), and the rounding penalty uses \(O(n)\). Nested binary minima and maxima implement all displayed multiargument operations. Thus the total output bit length \(L\) is polynomial in the \(\mathrm{3SAT}\) input length.

The equivalence above gives a polynomial-time many-one reduction from \(\mathrm{3UNSAT}\) to core nonemptiness. Therefore core nonemptiness is \(\mathrm{coNP}\)-hard. A polynomial-time algorithm with a core-nonemptiness oracle decides \(\mathrm{3SAT}\) using one query and reversing its answer, establishing the requested \(\mathrm{NP}\)-hardness under polynomial-time Turing reductions.

In particular, an algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
