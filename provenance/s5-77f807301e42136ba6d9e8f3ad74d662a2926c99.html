The continuous mirror question, as graded

Given an explicit finite set of complete agent types \(\Theta\), rational masses \(\mu\in\Delta(\Theta)\), a world \(w\in\{L,H\}\), the common prior and signal channel, and the paper's fixed Wisdom-of-the-Crowd mechanism, compute the winner \(a_w\) under truthful reports and decide whether, for every \(w\), it equals the continuous majority wish: \(a_w=\mathrm{acc}\) iff \(\mu(\{\theta:v_\theta(w,\mathrm{acc})>v_\theta(w,\mathrm{rej})\})>1/2\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(\Theta\) of \(\tau\) complete utility types with positive binary rational masses \(\mu_\theta\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. There are \(m=2\) alternatives, \(\mathrm{acc},\mathrm{rej}\), and worlds \(L,H\).
Each type specifies \(v_\theta:\{L,H\}\times\{\mathrm{acc},\mathrm{rej}\}\to\{0,\ldots,B\}\), with \(B\in\mathbb Z_{>0}\), \(v_\theta(H,\mathrm{acc})>v_\theta(L,\mathrm{acc})\), \(v_\theta(H,\mathrm{rej})<v_\theta(L,\mathrm{rej})\), and strict preferences between alternatives in each world.
Partition types into \(F\), always preferring acceptance; \(U\), always preferring rejection; and \(C\), preferring rejection in \(L\) and acceptance in \(H\). Write \(\alpha_X=\mu(X)\). Assume the acceptance-preferring mass differs from \(1/2\) in each world.
The common-knowledge prior and type-independent signal channel are binary rationals: \(P_L,P_H>0\), \(P_L+P_H=1\), \(p_{sw}>0\), \(p_{\ell w}+p_{hw}=1\), and \(p_{hH}>p_{hL}\), for \(s\in\{\ell,h\}\), \(w\in\{L,H\}\). The class masses are also common knowledge.
In world \(w\), type \(\theta\)'s mass receiving signal \(s\) is exactly \(\mu_\theta p_{sw}\). Truthful reports identify the preference class and, for contingent mass, the received signal.
The fixed mechanism treats all \(F\) signals as \(h\) and all \(U\) signals as \(\ell\); their predictions are set to \(0\) and \(1\), respectively. Contingent mass receiving \(s\) predicts \(\delta_s=\alpha_F+\alpha_C\frac{P_Lp_{sL}p_{hL}+P_Hp_{sH}p_{hH}}{P_Lp_{sL}+P_Hp_{sH}}\).
Let \(\nu_w\) be the mass distribution of these predictions and use its lower weighted median \(d_w=\inf\{z\in[0,1]:\nu_w([0,z])\geq1/2\}\). If \(\alpha_F>1/2\), output acceptance; otherwise if \(\alpha_U>1/2\), output rejection; otherwise output acceptance exactly when the treated \(h\)-report mass exceeds \(d_w\), and rejection on equality. Denote the output by \(a_w\).

Can both truthful winners \(a_L,a_H\) be computed and the condition \(\forall w\in\{L,H\}:\ a_w=\mathrm{acc}\iff\mu(\{\theta:v_\theta(w,\mathrm{acc})>v_\theta(w,\mathrm{rej})\})>1/2\) decided in polynomial time, or is this problem \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L,\log B\), where \(L\) is the total input bit length.

For finite odd-sized societies, truthful reports yield the majority wish with exponentially small failure probability in the number of contingent voters. [Source](https://arxiv.org/pdf/2108.03749)
Existing infinite-population analysis asserts correct truthful outcomes for fixed parameters; it does not give a complexity classification for explicitly encoded rational masses. [Source](https://papers.nips.cc/paper_files/paper/2021/file/0e900ad84f63618452210ab8baae0218-Supplemental.pdf)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Both truthful winners can be computed in deterministic polynomial time. Moreover, the stated correctness condition holds for every input satisfying the hypotheses.

An explicit bound, using elementary integer arithmetic, is \(O\!\left(L+m\tau\log(B+1)+(\tau+1)L^2\right)\) bit operations, with \(m=2\). The algorithm processes only the listed support; it does not enumerate possible utility types.

1. Preference classes and majority wishes

Define the utility difference \(\Delta_\theta(w)=v_\theta(w,\mathrm{acc})-v_\theta(w,\mathrm{rej})\). The utility assumptions imply

\(\Delta_\theta(H)-\Delta_\theta(L)=\bigl(v_\theta(H,\mathrm{acc})-v_\theta(L,\mathrm{acc})\bigr)+\bigl(v_\theta(L,\mathrm{rej})-v_\theta(H,\mathrm{rej})\bigr)>0.\)

Strict preferences mean neither difference is zero. Consequently, the only possible sign patterns are positive in both worlds, negative in both worlds, or negative in \(L\) and positive in \(H\). These are precisely the classes \(F,U,C\).

Thus the acceptance-preferring masses are

\(M_L=\alpha_F,\qquad M_H=\alpha_F+\alpha_C=1-\alpha_U.\)

The hypothesis excluding majority ties therefore implies

\(\alpha_F\ne\tfrac12,\qquad \alpha_U\ne\tfrac12.\)

There are three exhaustive cases:

  • If \(\alpha_F>\tfrac12\), the mechanism accepts in both worlds. Both acceptance-preferring masses exceed \(\tfrac12\).
  • If \(\alpha_U>\tfrac12\), the mechanism rejects in both worlds. Both acceptance-preferring masses are below \(\tfrac12\).
  • Otherwise, \(\alpha_F<\tfrac12\) and \(\alpha_U<\tfrac12\). The majority wishes are rejection in \(L\) and acceptance in \(H\).

The first two cases cannot overlap because \(\alpha_F+\alpha_U\le1\). It remains to prove the mechanism’s outputs in the third case.

2. Strict separation of predictions and report masses

Assume henceforth that \(\alpha_F,\alpha_U<\tfrac12\). Then

\(\alpha_C=1-\alpha_F-\alpha_U>0.\)

Write \(x=p_{hL}\) and \(y=p_{hH}\). Positivity and normalization of the channel imply \(0<x<y<1\).

For each signal \(s\), define

\(D_s=P_Lp_{sL}+P_Hp_{sH},\qquad r_s=\dfrac{P_Hp_{sH}}{D_s}.\)

Both terms in \(D_s\) are strictly positive, so \(D_s>0\) and \(0<r_s<1\). The prediction formula becomes

\(\delta_s=\alpha_F+\alpha_Cq_s,\qquad q_s=(1-r_s)x+r_sy.\)

Because \(q_s\) is a strictly positive convex combination of the distinct numbers \(x,y\),

\(x<q_s<y.\)

In world \(w\), the treated \(h\)-report mass is exactly

\(t_w=\alpha_F+\alpha_Cp_{hw}.\)

Indeed, all friendly mass reports treated signal \(h\), no unfriendly mass does, and contingent mass receiving \(h\) is exactly \(\alpha_Cp_{hw}\). Multiplying the preceding strict inequalities by \(\alpha_C>0\) gives

\(t_L<\delta_s<t_H\qquad\text{for both }s\in\{\ell,h\}.\)

For completeness, the predictions are strictly ordered. Since \(p_{\ell L}=1-x\) and \(p_{\ell H}=1-y\),

\(r_h-r_\ell=\dfrac{P_LP_H\bigl(y(1-x)-x(1-y)\bigr)}{D_hD_\ell}=\dfrac{P_LP_H(y-x)}{D_hD_\ell}>0.\)

Therefore,

\(\delta_h-\delta_\ell=\alpha_C(y-x)(r_h-r_\ell)=\dfrac{\alpha_CP_LP_H(y-x)^2}{D_hD_\ell}>0.\)

Also, \(0<q_s<1\) and \(\alpha_C>0\) imply \(0<\delta_\ell<\delta_h<1\).

3. The lower weighted median and truthful outputs

Let \(\mathsf{Dirac}_z\) denote a unit point mass at \(z\). The prediction distribution in world \(w\) is exactly

\(\nu_w=\alpha_F\mathsf{Dirac}_0+\alpha_Cp_{\ell w}\mathsf{Dirac}_{\delta_\ell}+\alpha_Cp_{hw}\mathsf{Dirac}_{\delta_h}+\alpha_U\mathsf{Dirac}_1.\)

The cumulative mass at \(0\) is \(\alpha_F<\tfrac12\). The cumulative mass at \(\delta_h\) is

\(\alpha_F+\alpha_Cp_{\ell w}+\alpha_Cp_{hw}=\alpha_F+\alpha_C=1-\alpha_U>\tfrac12.\)

Since there are no other prediction values between \(0\) and \(\delta_h\), the lower weighted median is

\(d_w=\begin{cases}\delta_\ell,&\alpha_F+\alpha_Cp_{\ell w}\ge\tfrac12,\\ \delta_h,&\alpha_F+\alpha_Cp_{\ell w}<\tfrac12.\end{cases}\)

This formula includes equality correctly: if the cumulative mass reaches exactly \(\tfrac12\) at \(\delta_\ell\), the lower median is \(\delta_\ell\).

Both possible median values lie strictly between \(t_L\) and \(t_H\). Hence

\(t_L<d_L,\qquad t_H>d_H.\)

The mechanism therefore rejects in \(L\) and accepts in \(H\). Its report-versus-median equality rule is never invoked in this case.

Together with Section 1, this proves the complete output formula

\((a_L,a_H)=\begin{cases}(\mathrm{acc},\mathrm{acc}),&\alpha_F>\tfrac12,\\ (\mathrm{rej},\mathrm{rej}),&\alpha_U>\tfrac12,\\ (\mathrm{rej},\mathrm{acc}),&\alpha_F<\tfrac12\text{ and }\alpha_U<\tfrac12.\end{cases}\)

Each case agrees with the majority wishes in both worlds, proving the requested equivalence.

4. Exact algorithm and bit complexity

The algorithm is:

  • Scan the \(\tau\) listed types and classify each using its preference comparisons in the two worlds.
  • Sum their rational masses to obtain \(\alpha_F\) and \(\alpha_U\).
  • Compare these two masses with \(\tfrac12\) and apply the output formula above.
  • Return “yes” for the correctness condition.

The proof justifies omitting numerical computation of the predictions and medians.

To bound exact arithmetic, write each input mass as \(a_i/b_i\), with positive integer denominator. A class sum can be maintained without reducing fractions: adding \(a/b\) to \(A/D\) produces

\(\dfrac{A}{D}+\dfrac{a}{b}=\dfrac{Ab+aD}{Db}.\)

Every intermediate denominator is a product of denominators from a subset of the input. Its bit length is \(O(L)\), because the sum of the input denominator lengths is at most \(L\). Every intermediate class sum lies in \([0,1]\), so its nonnegative numerator is at most its denominator and also has \(O(L)\) bits.

There are \(O(\tau)\) rational additions. Schoolbook multiplication and addition therefore give \(O((\tau+1)L^2)\) bit operations for accumulation and final comparisons. Comparing \(A/D\) with \(\tfrac12\) requires only comparing \(2A\) with \(D\).

Reading the input costs \(O(L)\). Utility classification costs \(O(m\tau\log(B+1))\) bit operations, where \(m=2\). Thus the total stated bound follows. In particular, dependence on the utility bound is through its binary length, and dependence on the society is through its explicitly listed support size.

Both tasks are therefore polynomial-time solvable. An NP-hardness classification for winner computation under polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).
