The continuous mirror question, as graded

Given \(K\), finitely many types \(t\) with rational masses \(\mu_t\), strict separable rankings over the \(2^K\) outcomes, and initial integer ballot bundles \(\omega_t\), determine whether there is a finite sequence of mass trades from the initial state to a state with no feasible blocking trade. In each state, \(\lambda_{t,v}\) is the mass of type \(t\) holding bundle \(v\in\mathbb{Z}_{\ge 0}^K\); a trade reassigns mass among bundles, conserves the total supply of votes on each proposal, and requires every participating agent to strictly prefer the resulting outcome. A proposal passes when its supporting vote mass exceeds its opposing vote mass, and a tie fails. Return a finite path to stability or report that none exists.

Packaged proof task (what the prover saw — nothing else)

There are \(m=K\geq1\) binary proposals. A society is given by its support: the list of its \(\tau\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Each type has an explicitly listed strict ranking \(\succ_t\) of all outcomes \(A\subseteq\{1,\ldots,m\}\), promised representable by \(u_t(A)=\sum_{k\in A}z_{t,k}\) with nonzero signed values. Type \(t\) supports proposal \(k\) exactly when \(z_{t,k}>0\), equivalently \(\{k\}\succ_t\varnothing\). Every proposal has both supporting and opposing types.
The input gives each type an initial bundle \(\omega_t\in\mathbb Z_{\geq0}^{m}\), encoded in binary. Each proposal's supply \(S_k=\sum_t\mu_t\omega_{t,k}\) is positive. A state is a finitely supported array of nonnegative rational masses \(\lambda_{t,v}\), indexed by integer bundles \(v\in\mathbb Z_{\geq0}^{m}\), satisfying \(\sum_v\lambda_{t,v}=\mu_t\) and \(\sum_{t,v}\lambda_{t,v}v_k=S_k\). Initially all type \(t\) mass holds \(\omega_t\).
The outcome \(A(\lambda)\) contains proposal \(k\) exactly when its supporting vote mass exceeds its opposing vote mass; ties fail. Each holder casts every vote according to its type's support direction.
A trade from \(\lambda\) to a distinct state \(\lambda'\) is a finitely supported nonnegative rational array \(q_{t,v,w}\) with \(\sum_wq_{t,v,w}=\lambda_{t,v}\) and \(\sum_vq_{t,v,w}=\lambda'_{t,w}\). Whenever \(q_{t,v,w}>0\) and \(v\neq w\), require \(A(\lambda')\succ_t A(\lambda)\). Thus only agents whose bundles change participate, every participant strictly gains myopically, and each proposal's supply is conserved. Coalitions are unrestricted; gifts and redundant transfers are allowed, with no payments or individual vote-budget constraint.
A state is stable if no such trade exists. The reachability problem asks whether a finite sequence of trades reaches a stable state, allowing a sequence of length zero; its constructive version returns such a path or reports that none exists.

Is deciding this finite reachability problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite odd committees with integer ballots, odd positive supplies on every proposal, and strict additively separable preferences, a stable allocation is always reachable by finitely many improving trades; this is an existence result without a polynomial-time guarantee ([Casella–Palfrey](https://www.its.caltech.edu/~trp/VoteTrading_Oct_10_2018.pdf)).
No result settling this exact rational-mass reachability problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one.
  • Specified explicit outcome-ranking input and interpreted separability as additive representability, matching the discrete model.
  • Required at least one proposal, positive supply on every proposal, and both supporting and opposing types on every proposal.
  • Used the supplied tie-fails convention in place of discrete oddness restrictions, which have no natural meaning for divisible masses.
  • Specified finitely supported rational states and rational mass transfers so that paths have finite exact encodings; integer bundles remain unrestricted in size.
  • Defined participation by actual bundle changes and required every positive mass of participants to strictly gain; allowed unrestricted coalitions, gifts, and redundant transfers.
  • Allowed a zero-length path when the initial allocation is stable and separated the decision complexity target from constructive path output.

Result

Every promised instance has a stable state reachable by finitely many improving trades. Consequently, the decision problem is in \(\mathrm P\): the answer is always YES.

Below I prove this and give a constructive algorithm with running time \(2^{O(m\tau L)}\). This does not establish a polynomial running time for the constructive version.

The potential argument adapts the finite-allocation method in [Casella–Palfrey](https://www.its.caltech.edu/~trp/VoteTrading_Oct_10_2018.pdf). The additional points proved here are that even supplies with ties failing cause no obstruction, and that stability on a suitable integer lattice implies stability against all rational-mass trades.

1. A finite lattice of aggregate allocations

Choose a positive integer \(D\) divisible by every denominator occurring in the masses \(\mu_t\). Define

\[ a_t=D\mu_t,\qquad N_k=DS_k=\sum_t a_t\omega_{t,k}. \]

Thus every \(a_t\) and \(N_k\) is a positive integer, and \(\sum_t a_t=D\).

For a state \(\lambda\), define its aggregate vote holdings by

\[ x_{t,k}(\lambda)=\sum_v\lambda_{t,v}v_k. \]

We shall construct a path whose scaled aggregates

\[ n_{t,k}=Dx_{t,k}(\lambda) \]

are nonnegative integers. They satisfy \(\sum_t n_{t,k}=N_k\). Initially,

\[ n^0_{t,k}=a_t\omega_{t,k}. \]

Let \(\mathcal N\) denote the finite set of all nonnegative integer matrices satisfying these column-sum constraints. Its cardinality is

\[ Q=\prod_{k=1}^{m}\binom{N_k+\tau-1}{\tau-1}. \]

We next realize every matrix in \(\mathcal N\) by a canonical admissible state.

For a fixed type \(t\), write

\[ n_{t,k}=a_tb_{t,k}+r_{t,k}, \qquad 0\leq r_{t,k}<a_t. \]

For each integer \(j\) with \(1\leq j\leq a_t\), define the integer bundle

\[ v^{(j)}_{t,k}=b_{t,k}+\mathbf 1_{\{j\leq r_{t,k}\}}. \]

Assign mass \(1/D\) to each of these bundles, combining identical bundles. The resulting type distribution has total mass \(a_t/D=\mu_t\), and

\[ \sum_v\lambda_{t,v}v_k =\frac{a_tb_{t,k}+r_{t,k}}{D} =\frac{n_{t,k}}{D}. \]

The bundle changes only at the at most \(m\) remainder thresholds. Hence there are at most \(m+1\) distinct bundles per type. Denote the resulting state by \(\Lambda(n)\).

This construction is deterministic. In particular, unchanged rows of \(n\) give unchanged type distributions. Moreover, \(\Lambda(n^0)\) is exactly the prescribed initial state, because all its remainders are zero.

2. Exact characterization of feasible outcome changes

Fix \(n\in\mathcal N\). Let

\[ p_k(n)=\sum_{t:z_{t,k}>0}n_{t,k}, \qquad H_k=\left\lfloor\frac{N_k}{2}\right\rfloor. \]

Because \(p_k(n)\) is an integer, proposal \(k\) passes precisely when \(p_k(n)\geq H_k+1\). Write \(A=A(\Lambda(n))\).

Consider any different outcome \(B\). Define the set of types that strictly gain by

\[ C=C(A,B)=\{t:B\succ_t A\}. \]

For each changed proposal \(k\in A\triangle B\), let \(R_k\subseteq C\) consist of the types favoring its status in \(B\). Thus \(R_k\) consists of supporting types when \(k\in B\), and opposing types when \(k\notin B\).

Define the available donor stock and the required integer transfer by

\[ W_k=\sum_{t\in C\setminus R_k}n_{t,k}, \]

\[ d_k= \begin{cases} H_k+1-p_k(n),&k\in B\setminus A,\\ p_k(n)-H_k,&k\in A\setminus B. \end{cases} \]

Both expressions for \(d_k\) are positive integers.

Feasibility lemma. There exists a rational-mass trade from \(\Lambda(n)\) producing outcome \(B\) if and only if, for every \(k\in A\triangle B\),

\[ R_k\neq\varnothing \quad\text{and}\quad W_k\geq d_k. \]

When these conditions hold, there is such a trade to a canonical state \(\Lambda(n')\), with integer aggregates, that leaves every unchanged proposal’s holdings unchanged and sets

\[ p_k(n')= \begin{cases} H_k+1,&k\in B\setminus A,\\ H_k,&k\in A\setminus B. \end{cases} \]

Necessity

Suppose a rational trade produces \(B\). Every type outside \(C\) must have exactly the same distribution afterward: any positive off-diagonal entry in its trade array would require \(B\succ_t A\), contrary to its exclusion from \(C\).

Supply conservation therefore implies that the pooled holdings of \(C\) are conserved separately on every proposal.

If \(R_k\) were empty, all types in \(C\) would cast their votes against the status specified by \(B\). Redistributing their conserved pool could not change the tally on proposal \(k\). Thus \(R_k\neq\varnothing\).

Measure all aggregate holdings in units of \(1/D\), including the possibly nonintegral scaled holdings after the rational trade. The largest possible increase in votes favoring the new status is at most \(W_k\): the gaining types can add at most their entire original donor stock to that side.

If \(k\in B\setminus A\), passing requires

\[ W_k>\frac{N_k}{2}-p_k(n). \]

Since \(W_k\) and \(p_k(n)\) are integers, this implies

\[ W_k\geq H_k+1-p_k(n)=d_k. \]

If \(k\in A\setminus B\), failure requires a decrease in supporting votes of at least \(p_k(n)-N_k/2\). Therefore

\[ W_k\geq p_k(n)-\frac{N_k}{2}. \]

Again using integrality,

\[ W_k\geq p_k(n)-H_k=d_k. \]

These arguments include even \(N_k\), where failure at equality is permitted.

Sufficiency and lifting to a trade

For each changed proposal, transfer exactly \(d_k\) integer units from types in \(C\setminus R_k\) to a type in \(R_k\). The inequality \(W_k\geq d_k\) permits this, using donors successively until the required amount is collected. Leave all other proposal holdings unchanged.

The resulting matrix \(n'\) is nonnegative, conserves every column sum, and has the asserted supporting tallies. Its outcome is exactly \(B\). Only rows belonging to \(C\) can change.

To lift this aggregate operation, use a diagonal coupling for every type outside \(C\). For a type inside \(C\), any rational coupling between its distributions in \(\Lambda(n)\) and \(\Lambda(n')\) works. For example,

\[ q_{t,v,w} =\frac{\Lambda(n)_{t,v}\Lambda(n')_{t,w}}{\mu_t} \]

has the required marginals. Every off-diagonal participant belongs to \(C\), so strictly prefers \(B\) to \(A\). Since \(A\neq B\), the resulting state is distinct.

This proves the lemma. In particular, a canonical lattice state without an integer improving transition is stable against arbitrary rational trades.

3. A trading rule with a strictly increasing potential

Call proposal \(k\) *marginal* at \(n\) when

\[ p_k(n)\in\{H_k,H_k+1\}. \]

Let \(M(n)\) be the number of marginal proposals.

The feasibility lemma lets us choose every trade so that all changed proposals become marginal and all unchanged proposal holdings remain fixed. Consequently, \(M\) never decreases. If any changed proposal was previously nonmarginal, \(M\) strictly increases.

Fix the ordering \(1,\ldots,\tau\) of the listed types. Choose additive utility representations promised by the input, solely for the proof, and define

\[ \sigma_t(n)=\sum_{k=1}^{m}|z_{t,k}|n_{t,k}. \]

The algorithm does not need to compute these representations or scores.

At each nonstable canonical state, apply the following rule:

  • If some feasible outcome change flips a nonmarginal proposal, select one and perform the transfers from the feasibility lemma.
  • Otherwise, select any feasible different outcome \(B\). All its changed proposals are marginal. Put \(C=C(A,B)\) and \(i=\min C\), and perform the specialized transfers described next.

In the second case, every changed proposal requires exactly one integer unit.

For every changed proposal whose new status type \(i\) favors, choose \(i\) as the recipient of that unit.

For every changed proposal whose old status type \(i\) favors, choose \(i\) as the donor if \(n_{i,k}>0\); otherwise choose another available donor. A recipient and sufficient donor stock exist by the feasibility lemma.

Let \(F_i\) be the changed proposals whose new status type \(i\) favors, and \(E_i\) those whose old status it favors. Because \(B\succ_i A\) and utilities are additive,

\[ \sum_{k\in F_i}|z_{i,k}| - \sum_{k\in E_i}|z_{i,k}| =u_i(B)-u_i(A)>0. \]

Type \(i\) receives one unit on every proposal in \(F_i\) and loses at most one unit on every proposal in \(E_i\). Hence

\[ \sigma_i(n')-\sigma_i(n) \geq \sum_{k\in F_i}|z_{i,k}| - \sum_{k\in E_i}|z_{i,k}| >0. \]

Every earlier type lies outside \(C\), because \(i=\min C\), so all its holdings and scores remain unchanged.

Now consider the tuple

\[ \Phi(n)=\bigl(M(n),\sigma_1(n),\ldots,\sigma_\tau(n)\bigr) \]

ordered lexicographically.

In the first case, its first coordinate strictly increases. In the second case, its first coordinate remains unchanged, all score coordinates before \(i\) remain unchanged, and coordinate \(i\) strictly increases. Thus every selected trade strictly increases \(\Phi\).

4. Finite termination and rational stability

The feasible integer matrices form the finite set \(\mathcal N\). Strict increase of \(\Phi\) therefore prevents any matrix from occurring twice.

This finiteness is essential: termination is not being inferred merely from boundedness of real-valued scores.

Consequently, the trading rule executes at most \(Q-1\) trades. At its terminal matrix, no different outcome satisfies the feasibility conditions. The feasibility lemma then rules out every rational trade producing a different outcome.

A trade preserving the outcome is also impossible: no type strictly prefers an outcome to itself, so all entries of its trade array would have to be diagonal, yielding the identical state.

The terminal canonical state is therefore stable under the exact definition in the question. Since the initial state is \(\Lambda(n^0)\), the constructed sequence starts at the prescribed allocation.

This completes the reachability proof.

5. Algorithms and running times

The decision algorithm returns YES on every promised instance. Its running time is \(O(1)\) once the input is available, or \(O(L)\) including reading the input.

For the constructive algorithm, build rank lookup tables from the explicitly listed rankings. At each state, enumerate all \(2^m\) outcomes \(B\), compute \(C(A,B)\), and check the feasibility inequalities. Prefer a feasible change involving a nonmarginal proposal; otherwise use the priority transfers above.

This requires \(O(m\tau2^m)\) arithmetic operations per iteration. Each canonical state has at most \(\tau(m+1)\) positive entries. A greedy transportation coupling gives each type at most \(2m+1\) positive trade entries: successively match the remaining row and column masses, assigning their minimum and exhausting at least one of them.

For the numerical bounds, choosing \(D\) as the least common multiple of the input denominators gives

\[ D\leq 2^L, \qquad N_k=DS_k\leq D\max_t\omega_{t,k}\leq 2^{2L}. \]

Thus all integers manipulated by the algorithm have \(O(L)\) bits. The canonical masses and greedy coupling entries are integer multiples of \(1/D\), also with \(O(L)\)-bit representations.

The constructive running time is bounded by

\[ O\!\left(Qm\tau2^m\,\operatorname{poly}(L+m+\tau)\right), \qquad Q=\prod_{k=1}^{m}\binom{N_k+\tau-1}{\tau-1}. \]

Since

\[ Q\leq\prod_{k=1}^{m}(N_k+1)^{\tau-1} \leq(2^{2L}+1)^{m(\tau-1)}, \]

this is \(2^{O(m\tau L)}\) bit operations. The algorithm returns an explicit rational path and never needs to report nonexistence on a promised instance.
