The continuous mirror question, as graded

Given rational type masses \(\mu_p\) and rational per-capita supplies \(q_r\), with each type \(p\) desiring resource classes \(D_p\) at values \(v_r\), allocate mass \(x_{p,b}\) to integer bundles \(b\in\mathbb{Z}_{\ge 0}^{R}\). Subject to \(\sum_b x_{p,b}=\mu_p\) and \(\sum_{p,b}b_r x_{p,b}\le q_r\), compute the largest \(T\) such that every assigned bundle has value \(\sum_{r\in D_p}v_rb_r\ge T\), or an additive-\(\epsilon\) approximation to it.

Packaged proof task (what the prover saw — nothing else)

Let \(R\) be a set of \(m\ge1\) resource classes, with binary-rational values \(v_r\ge0\) and per-capita supplies \(q_r\ge0\).
A society is given by its support: \(\tau\ge1\) types with positive binary-rational masses \(\mu_p\), normalized by \(\sum_p\mu_p=1\), and explicitly listed desire sets \(D_p\subseteq R\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
An allocation consists of nonnegative real masses \(x_{p,b}\), with finite support, over bundles \(b\in\mathbb Z_{\ge0}^{R}\); require \(b_r=0\) for \(r\notin D_p\). Repeated units of a class are allowed, with no individual bundle cap.
Feasibility at \(T\ge0\) means \(\sum_bx_{p,b}=\mu_p\), \(\sum_{p,b}b_rx_{p,b}\le q_r\), and \(x_{p,b}>0\Rightarrow\sum_{r\in D_p}v_rb_r\ge T\). Unused supply is allowed. Let \(\mathrm{OPT}\) be the supremum of feasible thresholds.

For every fixed rational \(\delta>0\), can \(\mathrm{OPT}\) be estimated by a number \(\widehat T\) satisfying \(\mathrm{OPT}/(23/6+\delta)\le\widehat T\le\mathrm{OPT}\) in time polynomial in \(m,\tau,L\), or is achieving this guarantee NP-hard for some fixed \(\delta>0\)?

For discrete restricted max-min allocation, the configuration LP has integrality gap at most \(23/6\), yielding polynomial-time value estimation within \(23/6+\delta\). [Cheng–Mao, 2018](https://arxiv.org/abs/1807.04152)
Later discrete work improves the gap bound to \(3+21/26\) and gives a polynomial-time \((4+\delta)\)-approximation algorithm for fixed \(\delta>0\). [Cheng–Mao, 2019](https://drops.dagstuhl.de/storage/00lipics/lipics-vol132-icalp2019/LIPIcs.ICALP.2019.38/LIPIcs.ICALP.2019.38.pdf)

  • Normalize total society mass to one so that the supplies have their stated per-capita meaning.
  • Take resource values and supplies to be nonnegative binary rationals, consistent with restricted nonnegative valuations.
  • Allow nonnegative real allocation masses with finite support, and define the optimal threshold by its supremum.
  • Restrict bundles to desired classes, as discrete configurations do; zero-value units can be omitted.
  • Retain unrestricted integer multiplicities within resource classes from the graded question; impose no bundle cap derived from aggregate supply.
  • Allow empty desire sets and zero supplies, which the discrete definition does not exclude.

1. Result

The requested guarantee is achievable in polynomial time. In fact, the mass model admits a polynomial-time \(3\)-factor value estimate:

\[ \frac{\mathrm{OPT}}{3}\le \widehat T\le \mathrm{OPT}. \]

The proof uses a conversion to allocations in which each bundle contains repeated units of a single resource class. Divisibility of the type masses makes these allocations accessible through a polynomial-size flow problem.

2. A flow test for single-class bundles

Let \(R_+=\{r\in R:v_r>0\}\). For a positive rational threshold \(s\), define

\[ k_r(s)=\left\lceil\frac{s}{v_r}\right\rceil \qquad(r\in R_+). \]

Consider allocations using only bundles \(k_r(s)e_r\), where \(e_r\) is the unit vector of class \(r\). Every such bundle has value at least \(s\).

Writing \(y_{p,r}\) for the mass of type \(p\) assigned this bundle, feasibility is exactly the following system:

\[ \sum_{r\in D_p\cap R_+}y_{p,r}=\mu_p,\qquad \sum_p k_r(s)y_{p,r}\le q_r,\qquad y_{p,r}\ge0. \]

It can be tested by a maximum-flow network:

  • A source-to-type arc has capacity \(\mu_p\).
  • A type-to-class arc exists when \(r\in D_p\cap R_+\), and has capacity \(1\).
  • A class-to-sink arc has capacity \(q_r/k_r(s)\).

A flow of value \(1\) saturates every source-to-type arc, since their capacities sum to \(1\). Its type-to-class flows give precisely the required masses \(y_{p,r}\). Conversely, any feasible masses give such a flow. Capacity \(1\) on a type-to-class arc is sufficient because \(y_{p,r}\le\mu_p\le1\).

Call this test \(F(s)\). Whenever \(F(s)\) succeeds, \(s\) is feasible in the original model. The resulting allocation has at most \(m\) bundles per type.

3. The conversion lemma

Lemma. For every \(s>0\), feasibility of threshold \(2s\) in the original model implies that \(F(s)\) succeeds.

Proof. Fix an allocation feasible at \(2s\), and abbreviate \(k_r=k_r(s)\). For every bundle \(b\) assigned positive mass, put

\[ A_b=\sum_{r\in R_+}\frac{b_r}{k_r}. \]

First, \(A_b\ge1\). If \(b_r\ge1\) for some class with \(v_r\ge s\), then \(k_r=1\), which proves the assertion. Otherwise every positive-valued class used in \(b\) has \(v_r<s\). For these classes,

\[ k_rv_r =\left\lceil\frac{s}{v_r}\right\rceil v_r <s+v_r<2s. \]

Consequently,

\[ 2s\le\sum_{r\in R_+}v_rb_r \le 2s\sum_{r\in R_+}\frac{b_r}{k_r} =2sA_b, \]

again giving \(A_b\ge1\).

Now replace each mass \(x_{p,b}\) by single-class bundle masses, defining

\[ y_{p,r}=\sum_b x_{p,b}\frac{b_r/k_r}{A_b} \qquad(r\in D_p\cap R_+). \]

The denominators are positive, and the sums are finite by the allocation’s finite-support requirement. For each type,

\[ \sum_r y_{p,r} =\sum_b x_{p,b}\frac{A_b}{A_b} =\mu_p. \]

For each resource class, using \(A_b\ge1\),

\[ \sum_p k_ry_{p,r} =\sum_{p,b}x_{p,b}\frac{b_r}{A_b} \le\sum_{p,b}x_{p,b}b_r \le q_r. \]

Thus the replacement is feasible and uses only the bundles tested by \(F(s)\). Each replacement bundle has value at least \(s\). This proves the lemma.

4. Detecting zero optimum and obtaining bounds

Threshold \(0\) is always feasible, by assigning the empty bundle to every type. Also, every feasible threshold \(T\) satisfies

\[ T =T\sum_{p,b}x_{p,b} \le\sum_{p,b}x_{p,b}\sum_r v_rb_r \le\sum_r v_rq_r. \]

Hence, with \(W=\sum_r v_rq_r\), we have \(0\le\mathrm{OPT}\le W\).

If \(R_+\) is empty, return \(0\). Otherwise define

\[ v_{\min}=\min_{r\in R_+}v_r. \]

At this threshold, \(k_r(v_{\min})=1\) for every positive-valued class.

I claim that if \(F(v_{\min})\) fails, then \(\mathrm{OPT}=0\). To prove this, suppose some positive threshold were feasible. Every assigned bundle would contain at least one positive-valued unit. Let

\[ C_b=\sum_{r\in R_+}b_r\ge1. \]

Replace mass \(x_{p,b}\) by masses \(x_{p,b}b_r/C_b\) receiving one unit of class \(r\). These replacement masses sum to \(x_{p,b}\), and the consumption of each class is at most its original consumption because \(C_b\ge1\). Every replacement bundle has value at least \(v_{\min}\). This would make \(F(v_{\min})\) succeed, a contradiction.

Thus a failed initial test correctly yields output \(0\). If it succeeds, \(v_{\min}\) is a feasible positive starting threshold.

5. The algorithm and its guarantee

When \(F(v_{\min})\) succeeds, initialize \(s=v_{\min}\). Repeatedly test \(F(3s/2)\):

  • If it succeeds, replace \(s\) by \(3s/2\).
  • If it fails, return \(\widehat T=s\).

Every retained \(s\) is feasible, so \(\widehat T\le\mathrm{OPT}\).

At termination, \(F(3s/2)\) fails. The conversion lemma implies that threshold \(3s\) is infeasible. Feasibility is downward closed: an allocation feasible at a threshold is feasible at every smaller threshold. Therefore no threshold at least \(3s\) is feasible, and

\[ \mathrm{OPT}\le3s=3\widehat T. \]

This argument does not require the supremum defining \(\mathrm{OPT}\) to be attained.

Since \(3<23/6+\delta\) for every \(\delta>0\), the output satisfies the requested guarantee.

6. Polynomial running time

Every successful test produces a feasible threshold at most \(W\). The search therefore terminates after at most

\[ O\!\left(1+\log_{3/2}\frac{W}{v_{\min}}\right) \]

tests.

The binary input encoding gives \(v_{\min}\ge2^{-L}\), and each input value and supply is at most \(2^L\). Thus \(W\le m2^{2L}\), so the number of tests is \(O(L+\log m)\).

After \(j\) successful iterations, the tested thresholds have the form \(v_{\min}(3/2)^j\), with polynomial binary encoding length. Each integer \(k_r(s)\) is computed by exact rational arithmetic and also has polynomial encoding length. Consequently, every flow capacity has polynomial encoding length.

Each network has \(m+\tau+2\) vertices and at most \(m\tau+m+\tau\) arcs. Exact maximum flow with rational capacities is polynomial-time: clearing denominators produces integer capacities of polynomial total encoding length, to which a standard polynomial-time maximum-flow algorithm applies.

The entire algorithm consequently runs in time polynomial in \(m,\tau,L\). Large bundle counts are represented in binary; neither populations nor supplies are expanded into individual copies.
