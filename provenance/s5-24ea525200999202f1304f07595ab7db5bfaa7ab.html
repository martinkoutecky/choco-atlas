The continuous mirror question, as graded

For two homogeneous types with masses \(\mu_A=\mu_B=1/2\), suppose the unknown cost is a coverage function and each sample is the limiting mass vector \(x=(1/4,1/4)\) obtained by including each clone independently with probability \(1/2\); the input also gives \(C(\mu)\). Can any estimator using polynomially many such cost observations approximate both types’ clone-limit aggregate Shapley shares within a fixed constant factor for every such coverage cost? In the hard pair, the two costs swap feature weights \(1\) and \(M\), yet agree at every observed vector and at \(\mu\), while their type shares are \((1,M)\) and \((M,1)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here \(\tau=2\), the types are \(A,B\), and \(\mu_A=\mu_B=1/2\).
An unknown coverage cost has a finite universe \(U\) and sets \(T_A,T_B\subseteq U\), identical for all clones of each type. For \(x\in[0,1/2]^2\), define \(C(x)=\left|\bigcup_{t\in\{A,B\}:x_t>0}T_t\right|\), with the empty union having cost zero. The universe and sets are not supplied.
For each positive integer \(k\), form a game with \(k\) clones of each type, each of mass \(1/(2k)\), where a coalition costs the cardinality of its covered union. Define the clone-limit aggregate share \(\Phi_t=\lim_{k\to\infty}\sum_{i\text{ of type }t}\phi_i^{(k)}\), where \(\phi^{(k)}\) is the ordinary Shapley value.
The estimator receives the support, \(C(\mu)\), and \(m\) exact observations \((x,C(x))\), each with \(x=(1/4,1/4)\). These are limiting mass observations from independently including each clone with probability \(1/2\); no finite-clone fluctuations, feature descriptions, or additional cost queries are available.
Let \(L\) be the binary encoding length of the support, grand-coalition cost, one observation, and confidence parameter \(\delta\in(0,1)\). Express runtime bounds in \(m,\tau,L,1/\delta\); estimator runtime is unrestricted in the question below.

Does there exist a fixed \(\alpha\in(0,1)\) and an estimator using \(m=\operatorname{poly}(\tau,L,1/\delta)\) observations such that, for every such coverage cost and every \(\delta\in(0,1)\), simultaneously \(\alpha\Phi_t\leq\widehat\Phi_t\leq\Phi_t/\alpha\) for both types with probability at least \(1-\delta\), or is every fixed factor impossible?

Discrete coverage games admit no fixed-factor approximation of all Shapley values from polynomially many uniform coalition samples, even with unrestricted computation and the grand-coalition cost supplied. [Statistical Cost Sharing](https://papers.neurips.cc/paper/7202-statistical-cost-sharing.pdf)

Modeling choices made when packaging the task

  • Defined homogeneous continuous coverage by a finite universe and one coverage set per type, with a feature covered whenever a covering type has positive coalition mass.
  • Used unweighted cardinality coverage, matching the discrete definition; positive integer feature weights are represented by duplicate features.
  • Defined the clone limit using equal numbers of equal-mass clones, holding the coverage sets fixed as the clone count grows.
  • Interpreted observations as exact limiting mass vectors, without finite-clone fluctuations or access to the hidden coverage representation.
  • Specified simultaneous multiplicative approximation with confidence for both aggregate shares, including exact zero for a zero share; under cardinality coverage, nonzero aggregate shares are bounded away from zero.
  • Kept costs finite without normalizing total cost; a fixed finite universe satisfies the discrete polynomial cost bound for sufficiently large clone counts.
  • Defined encoding length using one observation to avoid making a polynomial sample bound depend circularly on the number of repeated observations.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Every fixed approximation factor is impossible, even with arbitrarily many observations and unrestricted computation. This holds with both coverage sets nonempty and both aggregate Shapley shares strictly positive.

1. Exact aggregate shares in every clone game

Write \(a=|T_A\setminus T_B|\), \(b=|T_B\setminus T_A|\), and \(c=|T_A\cap T_B|\).

For each covered element \(u\), define a component game whose cost is one when the coalition contains a clone covering \(u\), and zero otherwise. The coverage cost is the sum of these component costs.

By the permutation definition of the Shapley value, a clone’s share in a component game is the probability that it is the first clone covering that element. If exactly \(r\) clones cover the element, each has probability \(1/r\): the relative order of those clones in a uniform random permutation is uniform. Taking expectations commutes with the finite sum over elements.

An element exclusive to \(A\) is covered by its \(k\) clones, so each receives \(1/k\). A shared element is covered by all \(2k\) clones, so each receives \(1/(2k)\). Thus every \(A\)-clone and every \(B\)-clone respectively have shares

\( \phi_A^{(k)}=\dfrac{a}{k}+\dfrac{c}{2k},\qquad \phi_B^{(k)}=\dfrac{b}{k}+\dfrac{c}{2k}. \)

Summing over the \(k\) clones of each type gives

\( \sum_{i\text{ of type }A}\phi_i^{(k)}=a+\dfrac c2,\qquad \sum_{i\text{ of type }B}\phi_i^{(k)}=b+\dfrac c2. \)

These quantities are independent of \(k\). Consequently, the limits exist and equal

\( \Phi_A=a+\dfrac c2,\qquad \Phi_B=b+\dfrac c2. \)

2. Two indistinguishable costs with incompatible shares

Fix any proposed factor \(\alpha\in(0,1)\). Choose an integer \(q>\alpha^{-2}\), and let \(U=\{1,\ldots,q+1\}\). Consider two coverage costs:

| Cost | \(T_A\) | \(T_B\) | \((\Phi_A,\Phi_B)\) |
|---|---|---|---|
| First | \(\{1,\ldots,q\}\) | \(\{q+1\}\) | \((q,1)\) |
| Second | \(\{q+1\}\) | \(\{1,\ldots,q\}\) | \((1,q)\) |

The shares follow from Section 1, since the sets are disjoint.

Both societies have the prescribed support and masses. For both costs, the grand-coalition cost is \(q+1\). Moreover, every allowed observation has both coordinates positive, and hence covers the entire union. Every observation is therefore exactly

\( (x,C(x))=\bigl((1/4,1/4),q+1\bigr). \)

Thus the estimator receives identical inputs under the two costs, for every observation count \(m\).

For the first cost, successful approximation requires

\( \widehat\Phi_A\in[\alpha q,q/\alpha]. \)

For the second, it requires

\( \widehat\Phi_A\in[\alpha,1/\alpha]. \)

These intervals are disjoint, because \(q>\alpha^{-2}\) implies \(\alpha q>1/\alpha\). Therefore no output vector can succeed simultaneously for both costs.

3. Randomization and confidence cannot resolve the ambiguity

Set \(\delta=1/4\). Since the estimator’s inputs are identical, its output has the same probability distribution \(Q\) under both costs, including any internal randomness.

Let \(E_1\) and \(E_2\) be the sets of outputs successfully approximating both types for the first and second costs, respectively. Section 2 proves \(E_1\cap E_2=\varnothing\). Hence

\( Q(E_1)+Q(E_2)=Q(E_1\cup E_2)\leq 1. \)

At least one cost therefore has success probability at most \(1/2\), contradicting the required probability \(1-\delta=3/4\).

Here \(\tau=2\), \(1/\delta=4\), and the common binary input length is \(L=O(1+\log(q+1))\). The contradiction holds for every \(m\), including \(m=\operatorname{poly}(\tau,L,1/\delta)\), and for unrestricted runtime. Indeed, even the entire infinite sequence of permitted observations is identical.

This is a direct proof for the specified limiting-mass observations; no transfer of the discrete uniform-coalition lower bound from [Statistical Cost Sharing](https://papers.neurips.cc/paper/7202-statistical-cost-sharing.pdf) is needed.

An \(A\)-exclusive element has exactly \(k\) covering clones, while a shared element has exactly \(2k\). The displayed individual shares therefore follow correctly. Elements exclusive to the other type contribute zero.

The argument applies to every \(m\), so it excludes polynomial sample bounds and unrestricted computation alike. The cited discrete lower bound is unnecessary and is not used as a premise.
