The continuous mirror question, as graded

Given \(m\) candidates and a support \(S\) of \(\tau\) complete rankings with positive rational masses \(\mu_R\) summing to \(1\), compute the candidates that can rank first under some legal tie order in ranked pairs applied to \(w_\mu(a,b)=\sum_{R\in S}\mu_R(\mathbf{1}[a\succ_R b]-\mathbf{1}[b\succ_R a])\). The decision version asks whether a specified candidate belongs to that winner set.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a set of \(m\geq 1\) candidates. A society is given by its support: a list \(S\) of \(\tau\) distinct strict complete rankings, each with positive binary rational mass \(\mu_R\), with \(\sum_{R\in S}\mu_R=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
For distinct candidates define \(w_\mu(a,b)=\sum_{R\in S}\mu_R(\mathbf{1}[a\succ_R b]-\mathbf{1}[b\succ_R a])\). Process all directed edges \((a,b)\) with \(w_\mu(a,b)\geq 0\) in decreasing weight order, permitting any permutation within each equal-weight tier; zero margins contribute both orientations.
Starting with the empty directed graph on \(A\), lock each processed edge exactly when adding it preserves acyclicity, and otherwise discard it. A candidate is a possible winner if it can appear first in a topological ordering of the final graph for some permitted edge order. The decision input also specifies \(c\in A\); the associated computation asks for the entire possible-winner set.

Is deciding whether \(c\) is a possible winner in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite electorates, attainable rankings have a bottleneck-path characterization: every forward pair must have a path of forward nonnegative-margin edges whose minimum margin is at least the reverse margin. [Wang et al.](https://arxiv.org/pdf/1901.09791)
For finite electorates, specified-candidate winner membership is \(\mathrm{NP}\)-complete, whereas checking an entire proposed outcome ranking is polynomial-time. [Brill and Fischer](https://webspace.maths.qmul.ac.uk/felix.fischer/publications/bf_ranked.pdf)

Result

Specified-candidate possible-winner membership is \(\mathrm{NP}\)-complete for the normalized binary-rational support representation in the question. Consequently, computing the entire possible-winner set is \(\mathrm{NP}\)-hard, and a polynomial-time algorithm for either task exists if and only if \(\mathrm{P}=\mathrm{NP}\).

The proof requires no expansion of an arbitrary rational input into individual voters.

1. Exact arithmetic and membership in \(\mathrm{NP}\)

Write each input mass as \(\mu_R=p_R/q_R\), where the positive integers \(p_R,q_R\) are encoded in binary. Define

\(Q=\prod_{R\in S}q_R\), and \(M(a,b)=\sum_{R\in S}p_R(Q/q_R)\bigl(\mathbf{1}[a\succ_R b]-\mathbf{1}[b\succ_R a]\bigr)\).

Then \(w_\mu(a,b)=M(a,b)/Q\). The binary length of \(Q\) is \(O(L)\). Moreover, normalization gives

\(\sum_{R\in S}p_R(Q/q_R)=Q\),

so \(|M(a,b)|\leq Q\). Thus all margins, signs, and comparisons—including equality of weights—can be computed exactly in time polynomial in \(m,\tau,L\).

Let \(E=\{(a,b):a\ne b,\ M(a,b)\geq 0\}\). A certificate is a permutation of \(E\), of length at most \(m(m-1)\). Its encoding length is \(O(m^2\log(m+1))\).

A verifier performs the following steps:

  • Check that the certificate lists each edge of \(E\) exactly once and that its weights are nonincreasing.
  • Simulate the locking procedure. In the current acyclic graph, adding \((a,b)\) creates a cycle exactly when there is already a directed path from \(b\) to \(a\); this can be checked by graph search.
  • Accept exactly when \(c\) has indegree zero in the final graph.

The last condition is equivalent to \(c\) appearing first in a topological ordering. Necessity follows because an incoming edge would have to precede \(c\). For sufficiency, take a topological ordering of the graph with \(c\) removed and prepend \(c\); no edge enters \(c\), so the resulting order respects every edge.

There are \(O(m^2)\) graph searches, each taking \(O(m^2)\) time with a straightforward implementation. Together with the exact arithmetic above, verification is polynomial in \(m,\tau,L\). Therefore the decision problem belongs to \(\mathrm{NP}\).

For \(m=1\), the certificate is empty and the sole candidate wins.

2. Matching the finite-electorate rule

We use the following established theorem: given an explicit finite preference profile consisting of strict complete rankings, and a specified candidate, deciding whether that candidate is a ranked-pairs winner under unrestricted tie-breaking is \(\mathrm{NP}\)-complete. The explicit-profile input convention and the hardness statement appear in Section 3 and Theorem 1 of [Brill and Fischer](https://webspace.maths.qmul.ac.uk/felix.fischer/publications/bf_ranked.pdf).

Their procedural presentation considers each unordered pair once. A positive-margin pair is attempted in its majority direction; a zero-margin pair has its attempted direction chosen by tie-breaking. If the attempted direction creates a cycle, the reverse direction is added. We now prove that this convention yields exactly the same possible rankings as the procedure in the question.

Reachability lemma

For any acyclic directed graph \(G\), if adding \((a,b)\) creates a cycle, then \(G\) already contains a path from \(b\) to \(a\). Consequently, adding the reverse edge \((b,a)\) changes neither acyclicity nor reachability.

Indeed, a cycle using the new edge consists of \((a,b)\) followed by an existing path from \(b\) to \(a\). Conversely, that path together with \((a,b)\) creates a cycle. Since the reverse edge connects vertices already joined in its direction, any path using it can be replaced by a path already present in \(G\).

Thus adding the reverse edge after a rejection has no effect on subsequent locking decisions, which depend only on reachability.

Zero-margin pairs

Consider the first processed orientation of a zero-margin pair, say \((a,b)\).

  • If it is locked, there is thereafter a path from \(a\) to \(b\).
  • If it is rejected, there is already a path from \(b\) to \(a\).

In either case, the endpoints become comparable by reachability. When the other orientation is eventually processed, it is either rejected or added redundantly. It therefore changes no reachability.

Hence a directed-edge schedule induces an unordered-pair schedule by retaining the positive-margin edges and only the first occurrence of each zero-margin pair. At a zero-margin pair, use that first orientation as the attempted direction. The reachability lemma proves, inductively through the schedule, that the two procedures have identical reachability.

Conversely, take any permitted unordered-pair schedule with its chosen zero-margin orientations. Construct a directed-edge schedule by processing:

  • its positive-margin edges in the prescribed order;
  • its chosen zero-margin orientations in the prescribed order;
  • all remaining zero-margin orientations.

This is permitted because all edges in the last two groups have weight zero. The same induction gives identical reachability after the first two groups, and the remaining edges change no reachability.

Finally, the unordered-pair procedure produces an acyclic graph containing one orientation of every unordered pair. Such a graph has a unique topological ordering: two distinct topological orderings would disagree on some pair, contradicting its edge. Because the corresponding directed-edge procedure has identical reachability, its topological ordering is the same.

Therefore the two conventions have exactly the same attainable rankings and possible winners, including when zero margins occur.

3. Polynomial reduction to normalized support

Let a finite-electorate instance be an explicit list \(P=(R_1,\ldots,R_n)\), with \(n\geq 1\), together with its specified candidate \(c\). For each distinct ranking \(R\) appearing in the list, let \(k_R\) be its multiplicity. Output

\(S=\{R:k_R>0\}\), with \(\mu_R=k_R/n\),

and retain the candidate \(c\).

This is a valid target input: the rankings are distinct, every mass is positive, and \(\sum_{R\in S}\mu_R=1\).

If \(\Delta_P(a,b)\) denotes the integer majority margin in the finite electorate, then

\(w_\mu(a,b)=\frac{1}{n}\sum_{i=1}^{n}\bigl(\mathbf{1}[a\succ_{R_i}b]-\mathbf{1}[b\succ_{R_i}a]\bigr)=\Delta_P(a,b)/n\).

Multiplication by the common positive factor \(1/n\) preserves signs, equalities, and all strict comparisons between margins. Therefore it preserves the permitted schedules and every locking decision. By Section 2,

\(c\text{ wins the finite-electorate instance}\ \Longleftrightarrow\ c\text{ is a possible winner of the normalized-support instance}\).

The transformation has polynomial size and running time. In particular, \(\tau\leq n\), each multiplicity and denominator uses \(O(\log(n+1))\) bits, and all output rankings already occur in the explicit source input. Grouping identical rankings and counting their occurrences is polynomial-time.

This is a polynomial many-one reduction from the finite-electorate problem. Its \(\mathrm{NP}\)-hardness, together with Section 1, establishes \(\mathrm{NP}\)-completeness.

The conclusion also holds for dyadic masses

If “binary rational” is intended to require denominators that are powers of two, the reduction can be adjusted.

Duplicate every source voter, obtaining \(2n\) voters. Let \(N\) be the smallest power of two with \(N\geq 2n\); then \(N<4n\). Add \((N-2n)/2\) pairs of voters, each pair consisting of an arbitrary ranking and its reverse. Every added pair contributes zero to every margin.

The resulting electorate has \(N\) voters and margins \(2\Delta_P(a,b)\). Compressing and normalizing gives dyadic masses \(k_R/N\) and margins \(2\Delta_P(a,b)/N\). The scale remains positive and common, and the construction remains polynomial-size. Hence hardness holds even under this stronger restriction.

4. Computing the entire winner set

An algorithm returning the entire possible-winner set would decide specified-candidate membership by testing whether \(c\) appears in its output. Thus that computation is \(\mathrm{NP}\)-hard.

Conversely, a polynomial-time membership algorithm would compute the whole set using one call for each of the \(m\) candidates. Consequently, polynomial-time computation of the entire set is equivalent to polynomial-time specified-candidate membership, and hence to \(\mathrm{P}=\mathrm{NP}\).
