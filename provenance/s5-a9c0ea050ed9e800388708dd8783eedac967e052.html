The continuous mirror question, as graded

Given a finite set of complete types \(T\) with rational masses \(\mu_t\), rational per-capita bounds \(q_t\), strict preferences over a finite set of activity templates \(E\), rational contributions \(a_{te}\), and template capacities \(\kappa_e\), determine the complexity of outputting a rational stable allocation \(x_e\). Feasibility requires \(x_e\leq\kappa_e\) and \(\sum_{e:\,t\in e}a_{te}x_e\leq\mu_tq_t\); every unsaturated template must have a participating type whose bound is exhausted by activities that type weakly prefers to it. In particular, is there an algorithm polynomial in \(|T|\), \(|E|\), and the input bit length?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of \(\tau=|T|\) complete types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) counts supported types, not all possible types.
There are \(m=|E|\) explicitly listed activity templates, each with a nonempty participant set \(S_e\subseteq T\); distinct templates may have identical participant sets. Each type strictly ranks its incident templates; write \(f\succeq_t e\) when \(f=e\) or \(t\) prefers \(f\).
The input includes nonnegative rational per-capita bounds \(q_t\), nonnegative rational capacities \(\kappa_e\), and rational contributions \(a_{te}>0\) exactly when \(t\in S_e\), with \(a_{te}=0\) otherwise. Let \(L\) be the total binary input length, including participant sets and rankings.
An allocation is a rational vector \(x\geq0\) satisfying \(x_e\leq\kappa_e\) and \(\sum_{e\in E}a_{te}x_e\leq\mu_tq_t\) for every type \(t\).
It is stable if every template \(e\) with \(x_e<\kappa_e\) has a participant \(t\in S_e\) satisfying \(\sum_{f:\,t\in S_f,\ f\succeq_t e}a_{tf}x_f=\mu_tq_t\). The search problem asks for any rational stable allocation.

Can a rational stable allocation always be found in time polynomial in \(m,\tau,L\), or is this total search problem NP-hard?

For finite individual players, stable allocations with contributions always exist; the constructive existence result supplies no polynomial running-time bound (Biró–Fleiner).
Finding a stable fractional hypergraph matching with unit vertex bounds and unit contributions is PPAD-complete even at maximum degree three, and polynomial-time solvable at maximum degree two ([Ishizuka–Kamiyama](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ISAAC.2018.11)).

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, interpreting the society as a probability distribution.
  • Specified nonnegative rational per-capita bounds and template capacities, matching the finite-player domains.
  • Required every template to have a nonempty participant set and contributions to be strictly positive exactly for participants, and zero otherwise.
  • Specified strict rankings only over incident templates, with weak preference meaning strict preference or equality of templates.
  • Allowed distinct templates with identical participant sets, preserving the multiple-activity model.
  • Required nonnegative rational allocation coordinates and defined the total input bit length and template-count parameter explicitly.

Proven classification

The search problem is \(\mathrm{PPAD}\)-complete, even when every type participates in at most three templates, all positive contributions are \(\mathrm{1}\), and all capacities and effective type bounds are \(\mathrm{1}\).

Consequently, a polynomial-time algorithm exists if and only if every problem in \(\mathrm{PPAD}\) has a polynomial-time solution algorithm. This does not establish \(\mathrm{NP}\)-hardness. Thus I can prove a precise complexity classification, but cannot unconditionally settle the stated polynomial-time versus \(\mathrm{NP}\)-hard alternative.

Throughout, write \(b_t=\mu_tq_t\). These products are computable exactly with polynomial binary encoding length.

1. Hardness with explicitly supported types

Ishizuka–Kamiyama’s Theorem 2 states that finding a stable fractional hypergraph matching is \(\mathrm{PPAD}\)-complete at maximum vertex degree three. Their stability condition requires, for each hyperedge \(e\), a vertex \(v\in e\) satisfying
\(\sum_{f\ni v,\ f\succeq_v e}x_f=1\). [Ishizuka–Kamiyama](https://drops.dagstuhl.de/storage/00lipics/lipics-vol123-isaac2018/LIPIcs.ISAAC.2018.11/LIPIcs.ISAAC.2018.11.pdf)

Take such an instance with vertices \(V=\{v_1,\ldots,v_n\}\), where \(n\geq1\), and nonempty hyperedges. Construct one supported type per vertex and one template per hyperedge. Preserve incidence and rankings, and set
\(a_{te}=1\) on incidences and \(\kappa_e=1\).

The normalization of masses can be satisfied even if “binary-rational” means dyadic. Let \(N=2^{\lceil\log_2 n\rceil}\), and set

\(\mu_{v_i}=1/N\) for \(i<n\), and \(\mu_{v_n}=(N-n+1)/N\).

All masses are positive dyadic rationals and sum to one. Set \(q_t=1/\mu_t\). Then \(b_t=1\) for every type. These numbers have encoding length \(O(\log n)\).

The allocation constraints become precisely

\(x_e\geq0,\qquad x_e\leq1,\qquad \sum_{e\ni t}x_e\leq1.\)

The explicit edge bounds are redundant: each edge has a participant whose vertex constraint implies \(x_e\leq1\).

We must check the apparent difference between the two stability definitions.

  • If \(x_e<1\), the society’s stability condition is exactly the source condition.
  • If \(x_e=1\), choose any participant \(t\in S_e\). Feasibility gives

\(1=x_e\leq\sum_{f:\,t\in S_f,\ f\succeq_t e}x_f\leq\sum_{f:\,t\in S_f}x_f\leq1\).
Hence the source condition also holds.

Thus the two instances have exactly the same stable allocations. The output transformation is the identity, and the construction is polynomial. In particular, \(\tau=n\): no enumeration of unsupported types occurs.

This proves \(\mathrm{PPAD}\)-hardness under the stated restrictions.

2. Membership for arbitrary contributions and capacities

Removing zero bounds

If \(b_t=0\), feasibility and positive incident contributions force \(x_e=0\) for every incident template. Likewise, \(\kappa_e=0\) forces \(x_e=0\).

Delete all templates forced to zero by either reason, and delete types with zero effective bound. Restrict the remaining rankings accordingly.

Any stable allocation of the reduced instance extends by zero to a stable allocation of the original instance:

  • A deleted template with zero capacity has no stability requirement.
  • A deleted template with positive capacity has a participant with \(b_t=0\). Every incident allocation at that participant is zero, so its required prefix sum equals \(b_t\).
  • For a surviving template, deleted coordinates contribute zero to every prefix sum.

If no templates remain, the all-zero allocation therefore solves the original instance. Otherwise, all remaining capacities and type bounds are positive.

The computational Scarf theorem

We use the following established result. Suppose a rational matrix \(A\) has \(r\) rows, its first \(r\) columns form the identity, \(b\geq0\), and \(\{z\geq0:Az=b\}\) is bounded. Suppose an ordinal matrix \(C\) satisfies
\(C_{i,i}<C_{i,k}<C_{i,j}\)
for activity columns \(k>r\) and other identity columns \(j\leq r\), \(j\neq i\).

Scarf’s lemma provides a set \(J\) of \(r\) columns supporting a feasible vector and satisfying: for every column \(k\), some row \(i\) has
\(C_{i,k}\leq C_{i,j}\) for all \(j\in J\).
Finding such a set belongs to \(\mathrm{PPAD}\), including degenerate rational inputs. [Kintali–Poplawski–Rajaraman–Sundaram–Teng, Theorems 5.1–5.2](https://arxiv.org/pdf/0904.1435)

Here is a polynomial reduction satisfying those hypotheses.

Constructing the matrices

Let the reduced instance have \(M>0\) templates. Introduce one row for each remaining type and one additional row \(c_e\) for each template. Let their total number be \(r\).

Define the activity matrix \(B\) by

\(B_{t,e}=a_{te},\qquad B_{c_f,e}=\begin{cases}1&f=e,\\0&f\neq e.\end{cases}\)

Set \(b_{c_e}=\kappa_e\), retaining \(b_t\) on type rows. Introduce one slack column \(s_i\) per row and put \(A=[I_r\mid B]\). Thus

\(Az=b,\qquad z=(s,x)\geq0\)

is exactly the reduced allocation system with slacks.

This feasible set is nonempty, since \(x=0,\ s=b\). It is bounded because \(0\leq x_e\leq\kappa_e\) and \(0\leq s_i\leq b_i\).

Construct \(C\) row by row:

  • Give the row’s own slack column value zero.
  • Give its incident activity columns distinct values in \(\{1,\ldots,M\}\). At a type row, larger values mean more preferred templates. At a capacity row, its sole incident template has value one.
  • Give nonincident activity columns distinct values in \(\{M+1,\ldots,2M\}\).
  • Give all other slack columns distinct values greater than \(2M\).

These choices satisfy every required ordinal inequality. Both matrices and the right-hand side have polynomial encoding length.

Why every returned solution is stable

Obtain a Scarf set \(J\), and choose a nonnegative feasible vector \(z=(s,x)\) supported on \(J\). Such a rational vector can be computed by polynomial-time rational linear programming.

Fix an activity column \(e\). Scarf domination supplies a row \(i\) such that

\(C_{i,e}\leq C_{i,j}\quad\text{for every }j\in\operatorname{supp}(z).\)

First, \(s_i=0\). Otherwise its own slack column would belong to the support and have value zero, whereas \(C_{i,e}>0\), contradicting domination.

Second, \(e\) is incident to row \(i\). Indeed, the row equation, \(s_i=0\), and \(b_i>0\) imply that some incident activity \(f\) has \(x_f>0\). Therefore \(C_{i,f}\leq M\). A nonincident \(e\) would have \(C_{i,e}>M\), again contradicting domination.

There are now two cases.

  • If \(i=c_e\), its row equation gives \(x_e=\kappa_e\).
  • If \(i=t\) is a type row, domination excludes positive allocation to every incident template ranked below \(e\). Since \(s_t=0\), the row equation consequently gives

\(\sum_{f:\,t\in S_f,\ f\succeq_t e}a_{tf}x_f=b_t\).

Hence every template is either at capacity or has the required participant witness. Extending by zero gives a stable allocation of the original instance.

All preprocessing, matrix construction, and output recovery take polynomial time in \(m,\tau,L\). This proves membership in \(\mathrm{PPAD}\), and together with Section 1 proves completeness.

3. Rational output size and verification

The argument also establishes existence of a stable allocation with polynomial encoding length; it does not merely establish real-valued existence.

For a returned Scarf set \(J\), consider

\(P_J=\{z\geq0:Az=b,\ z_j=0\text{ for }j\notin J\}.\)

This is a nonempty bounded rational polytope, so it has a vertex. At a vertex, a full-rank collection of active constraints determines the coordinates.

For completeness, clear denominators in those equations. Their integer coefficients have at most \(H\) bits, where \(H\) is polynomial in the input length. With \(d\leq r+M\) variables, the determinants appearing in Cramer’s rule have absolute value at most \(d!\,2^{dH}\). Their binary lengths are therefore \(O(dH+d\log d)\). Each coordinate, and hence the complete allocation, has polynomial encoding length.

Every feasible vector supported on \(J\) satisfies the domination argument above, so choosing this vertex preserves stability.

Given a polynomial-length rational allocation, feasibility and stability are verifiable by exact rational arithmetic: evaluate the bounds and all preference-prefix sums. Thus the relation restricted to polynomial-length stable allocations is a total, polynomially verifiable search relation, belonging to \(\mathrm{TFNP}\).

4. What this says about the requested alternative

The two reductions prove the equivalence:

The society problem has a deterministic polynomial-time algorithm exactly when every \(\mathrm{PPAD}\) problem does.

Accordingly, under the assumption that some \(\mathrm{PPAD}\) problem lacks such an algorithm, the answer to the polynomial-time question is negative. No unconditional separation is proved here.

The distinction from \(\mathrm{NP}\)-hardness matters. Under the usual decision-to-search many-one reduction, \(\mathrm{NP}\)-hardness of this total search problem would imply \(\mathrm{NP}=\mathrm{coNP}\). Here is the argument, with the reduction convention explicit.

Suppose polynomial-time functions \(F,G\) transform a Boolean formula \(\varphi\) into a valid society instance \(F(\varphi)\), with \(G(\varphi,x)\) correctly deciding satisfiability for every stable allocation \(x\) of that instance.

An unsatisfiable formula then has a polynomial-size certificate: a short stable allocation \(x\) of \(F(\varphi)\) for which \(G(\varphi,x)\) answers “unsatisfiable.” Existence follows from Section 3, and verification is polynomial. A satisfiable formula has no such certificate because the reduction must be correct for every solution. Thus unsatisfiability belongs to \(\mathrm{NP}\), implying \(\mathrm{NP}=\mathrm{coNP}\).

This is a conditional obstruction to that notion of \(\mathrm{NP}\)-hardness, not a proof that it is impossible. The rigorously established result is \(\mathrm{PPAD}\)-completeness; neither an unconditional polynomial-time algorithm nor an \(\mathrm{NP}\)-hardness reduction is supplied.
