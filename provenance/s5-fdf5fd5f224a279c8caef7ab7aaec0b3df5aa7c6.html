The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), and a rational mass distribution \(\mu\) over approval types \(t\subseteq C\), find \(W\subseteq C\) with \(|W|=k\) containing an affordable \(R\subseteq W\) of maximum cardinality, with witness payments \(x_{t,c}\ge0\) satisfying \(x_{t,c}=0\) when \(c\notin t\), \(\sum_{c\in C}x_{t,c}\le k\mu_t\), and \(\sum_t x_{t,c}=1\) for \(c\in R\) and \(0\) otherwise.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be an explicitly listed set of \(m\ge1\) candidates and let \(k\in\{1,\ldots,m\}\).
A society is given by its support: a list \(T\) of \(\tau\) distinct approval types \(t\subseteq C\), each with positive binary rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Empty approval types and unsupported candidates are allowed. Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
A set \(R\subseteq C\) is affordable if there are real payments \(x_{t,c}\ge0\) satisfying \(x_{t,c}=0\) whenever \(c\notin t\), \(\sum_{c\in C}x_{t,c}\le k\mu_t\) for every \(t\in T\), and \(\sum_{t\in T}x_{t,c}=\mathbf{1}_{\{c\in R\}}\) for every \(c\in C\). Each funded candidate costs one unit.
The computational problem is to find \(W\subseteq C\), \(R\subseteq W\), and witness payments, with \(|W|=k\) and \(|R|\) maximum among all affordable subsets of \(C\). Any optimum and any completion to \(W\) are permitted.

Is this computational problem solvable in time polynomial in \(m,\tau,k,L\), or is it \(\mathsf{NP}\)-hard?

For a finite electorate with equal individual budgets, finding a committee containing a maximum-cardinality affordable set is NP-hard; checking affordability of a specified set is polynomial-time solvable. [Source](https://arxiv.org/html/2608.06156v1)
No result explicitly treating this rational-mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the mass distribution to total mass one, preserving total budget k.
  • Specified an explicitly listed nonempty candidate set and integer committee size between one and m, following the discrete domain.
  • Specified that cardinality is maximized globally over all affordable candidate subsets, rather than only within a previously chosen committee.
  • Allowed empty approval types and unsupported candidates, as the discrete definition imposes no exclusions.
  • Allowed arbitrary optimal solutions and arbitrary committee completions, following the rule's treatment of ties.
  • Specified real nonnegative payments and defined L as total input bit length.

Result

The problem is \(\mathsf{NP}\)-hard. In fact, deciding whether an affordable set of cardinality \(k\) exists is \(\mathsf{NP}\)-complete.

The finite-electorate hardness transfers to the rational-mass formulation by a polynomial-time aggregation that preserves affordability exactly.

1. Affordable sets and completion

For any affordable set \(R\), summing the payment constraints gives
\( |R| =\sum_{c\in C}\sum_{t\in T}x_{t,c} \leq\sum_{t\in T}k\mu_t =k. \)

Consequently, every affordable set can be completed to a committee of size \(k\), since \(m\geq k\). Thus the completion requirement introduces no additional restriction on the optimization over \(R\).

2. Aggregation preserves affordability

Consider an explicitly listed finite electorate with \(n\geq1\) voters. Voter \(i\) approves \(A_i\subseteq C\) and has budget \(k/n\).

Let \(T\) consist of the distinct approval sets occurring in this electorate. For each \(t\in T\), define
\( I_t=\{i:A_i=t\},\qquad n_t=|I_t|,\qquad \mu_t=\frac{n_t}{n}. \)
Every retained mass is positive, and \(\sum_{t\in T}\mu_t=1\).

Lemma. A set \(R\subseteq C\) is affordable in the finite electorate if and only if it is affordable in this rational-mass instance.

Proof. Suppose individual payments \(p_{i,c}\) witness finite-electorate affordability. Set
\( x_{t,c}=\sum_{i\in I_t}p_{i,c}. \)
These payments are nonnegative and vanish when \(c\notin t\). Moreover,
\( \sum_{c\in C}x_{t,c} =\sum_{i\in I_t}\sum_{c\in C}p_{i,c} \leq n_t\frac{k}{n} =k\mu_t. \)
Their candidate totals satisfy
\( \sum_{t\in T}x_{t,c} =\sum_{i=1}^{n}p_{i,c} =\mathbf{1}_{\{c\in R\}}. \)
They therefore witness rational-mass affordability.

Conversely, suppose \(x_{t,c}\) witnesses rational-mass affordability. For every \(i\in I_t\), set
\( p_{i,c}=\frac{x_{t,c}}{n_t}. \)
This division is valid because \(n_t>0\). Payments respect approvals, and
\( \sum_{c\in C}p_{i,c} \leq\frac{k\mu_t}{n_t} =\frac{k}{n}. \)
Finally,
\( \sum_{i=1}^{n}p_{i,c} =\sum_{t\in T}n_t\frac{x_{t,c}}{n_t} =\mathbf{1}_{\{c\in R\}}. \)
Thus these individual payments witness finite-electorate affordability. \(\square\)

In particular, aggregation preserves the entire family of affordable subsets, and hence its maximum cardinality.

3. Polynomial-time hardness reduction

The cited paper proves that, for an explicitly listed finite electorate with individual budgets \(k/n\), deciding whether an affordable set of size \(k\) exists is \(\mathsf{NP}\)-hard. Its proof reduces from Exact Cover by 3-Sets; the constructed instances satisfy \(n\geq1\) and \(1\leq k\leq m\). See [Theorem 5.3 and its proof](https://arxiv.org/html/2608.06156v1#S5.Thm3).

Given such a finite instance, construct the rational-mass instance from Section 2, retaining the same \(C\) and \(k\).

This construction has polynomial size:

  • There are at most \(n\) distinct approval types.
  • Each type can be represented by an incidence vector of length \(m\).
  • Each mass \(n_t/n\) has numerator and denominator using at most \(O(\log(n+1))\) bits.

Thus the resulting total input length \(L\) is polynomial in the finite instance’s length. Grouping identical approval vectors and counting their multiplicities also takes polynomial time. Empty approval types and unsupported candidates cause no difficulty because the target formulation permits both.

Now suppose the requested optimization problem had an algorithm polynomial in \(m,\tau,k,L\). Run it on the aggregated instance and obtain its optimal set \(R\). By the lemma and the bound \(|R|\leq k\),
\( |R|=k \quad\Longleftrightarrow\quad \text{the original finite instance has an affordable set of size }k. \)

Reading \(|R|\) would therefore solve the cited \(\mathsf{NP}\)-hard decision problem in polynomial time. This proves the requested computational problem is \(\mathsf{NP}\)-hard.

The argument applies to every permitted optimum: all optimal sets have the same cardinality, and the arbitrary completion to \(W\) does not affect the test.

4. Exact affordability verification and payment witnesses

For completeness, the rational masses do not obstruct polynomial-time verification.

Fix \(R\subseteq C\). Construct a directed network with source \(s\), one node for each type, one node for each candidate in \(R\), and sink \(z\). Its arcs and capacities are:

  • \(s\to t\), with capacity \(k\mu_t\);
  • \(t\to c\), with capacity \(k\), whenever \(c\in t\cap R\);
  • \(c\to z\), with capacity \(1\).

The intermediate capacity \(k\) imposes no additional restriction, since the total source capacity is \(k\).

Payments witnessing affordability give a flow of value \(|R|\). Conversely, a flow of value \(|R|\) saturates every candidate-to-sink arc, because their capacities sum to \(|R|\). Its type-to-candidate flows, extended by zero outside \(R\), then satisfy every payment constraint. Hence affordability is equivalent to maximum-flow value \(|R|\).

Write \(\mu_t=a_t/b_t\) with positive integer denominators, and let \(D=\prod_{t\in T}b_t\). The bit length of \(D\) is at most the sum of the denominator bit lengths, hence is \(O(L)\). Multiplying all capacities by \(D\) gives integer capacities of polynomial bit length. A polynomial-time maximum-flow algorithm, such as Edmonds–Karp, computes an integral flow in the scaled network. Dividing by \(D\) gives exact rational payment witnesses of polynomial encoding length.

Therefore the decision problem asking for an affordable set of size \(k\) belongs to \(\mathsf{NP}\): guess that set and verify affordability by this flow computation. Together with Section 3, it is \(\mathsf{NP}\)-complete.

The requested optimization problem consequently has no polynomial-time algorithm unless \(\mathsf{P}=\mathsf{NP}\).
