The continuous mirror question, as graded

Given alternatives \(A\), a finite support \(T\) of complete rational value profiles \(v_t:A\to\mathbb{Q}\) on a common scale, and rational masses \(\mu_t\geq 0\) with \(\sum_{t\in T}\mu_t=1\), let \(P_t\) be the weak order induced by \(v_t\). For each ranking \(o\in O(A)\), define \(W_\mu(o)=\sum_{t\in T}\mu_t\sum_{(a,b)\in o\cap P_t}(v_t(a)-v_t(b))\). Find all rankings maximizing \(W_\mu\) and return their transitive-closure group order, as in Theorem 1(a).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a nonempty set of \(m\) alternatives. A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies a complete profile \(v_t:A\to\mathbb Q\) on a common scale; values may be negative or tied, and no individual rescaling is performed. Let \(L\) be the total binary input length.
Let \(O(A)\) consist of all strict rankings, represented as reflexive binary relations with \((a,b)\in o\) when \(a\) precedes \(b\). Define \(P_t=\{(a,b):v_t(a)\geq v_t(b)\}\).
For \(o\in O(A)\), define \(W_\mu(o)=\sum_{t\in T}\mu_t\sum_{(a,b)\in o\cap P_t}(v_t(a)-v_t(b))\), and let \(\mathcal M=\operatorname*{arg\,max}_{o\in O(A)}W_\mu(o)\).
The requested output is an ordered partition whose strict refinements are exactly \(\mathcal M\), together with the group relation \(R=\operatorname{TC}(\bigcup_{o\in\mathcal M}o)\). Retain every maximizing ranking; impose no tie-breaking.

Can this output be computed in time polynomial in \(m,\tau,L\), or is deciding whether \(\max_{o\in O(A)}W_\mu(o)\geq q\), for a binary rational input \(q\), NP-hard?

For finite lists of individuals, the transitive closure of all rankings maximizing the unweighted sum of these individual scores is the additive constitution's group weak order ([published result](https://www.scielo.org.mx/scielo.php?lng=en&nrm=iso&pid=S1870-66222014000200005&script=sci_arttext)). Result

The requested output is computable in polynomial time. Define the mass-weighted mean value of each alternative by

\( s(a)=\sum_{t\in T}\mu_t v_t(a). \)

The ordered partition consists of the level sets of \(s\), in decreasing order. Its strict refinements are exactly \(\mathcal M\), and

\( R=\{(a,b)\in A^2:s(a)\geq s(b)\}. \)

The threshold decision problem is therefore in \(\mathrm P\). The proof below applies directly to binary rational masses, without expanding the support into a list of individuals.

1. Pairwise score identity

For a rational number \(x\), write \(x_+=\max\{x,0\}\). For distinct alternatives \(a,b\), define

\( c(a,b)=\sum_{t\in T}\mu_t\bigl(v_t(a)-v_t(b)\bigr)_+. \)

If a ranking places \(a\) before \(b\), this unordered pair contributes exactly \(c(a,b)\) to its score. Indeed, type \(t\) contributes \(v_t(a)-v_t(b)\) precisely when that difference is nonnegative; otherwise it contributes zero. Equality also contributes zero. Reflexive pairs contribute zero.

Consequently, if \(o\) lists the alternatives as \(a_1,\ldots,a_m\), then

\( W_\mu(o)=\sum_{1\leq i<j\leq m}c(a_i,a_j). \)

For every rational \(x\), the identity \(x_+-(-x)_+=x\) follows by considering the cases \(x\geq0\) and \(x<0\). Applying it to each type gives

\( c(a,b)-c(b,a) =\sum_{t\in T}\mu_t\bigl(v_t(a)-v_t(b)\bigr) =s(a)-s(b). \)

Thus the better orientation of every pair is determined by the same scalar function \(s\):

  • If \(s(a)>s(b)\), placing \(a\) before \(b\) gives a strictly larger contribution.
  • If \(s(a)=s(b)\), both orientations give equal contributions.

No assumption about the signs or distinctness of individual values was used.

2. Exact characterization of every maximizer

Let \(\binom A2\) denote the set of unordered pairs of distinct alternatives, and put

\( U=\sum_{\{a,b\}\in\binom A2}\max\{c(a,b),c(b,a)\}. \)

Every ranking selects one orientation for each unordered pair. Therefore \(W_\mu(o)\leq U\) for every \(o\in O(A)\).

Now take any ranking whose means are nonincreasing:

\( s(a_1)\geq s(a_2)\geq\cdots\geq s(a_m). \)

For every \(i<j\), the pairwise identity gives \(c(a_i,a_j)\geq c(a_j,a_i)\). This ranking attains the maximum contribution of every pair simultaneously. Hence its score is \(U\), and

\( \max_{o\in O(A)}W_\mu(o)=U. \)

To prove the converse without any cancellation argument, observe that every ranking satisfies

\( U-W_\mu(o) =\sum_{1\leq i<j\leq m}\bigl(s(a_j)-s(a_i)\bigr)_+. \)

Indeed, the summand associated with \(i<j\) is
\(\max\{c(a_i,a_j),c(a_j,a_i)\}-c(a_i,a_j)\), which equals the displayed positive part by the pairwise identity.

Every summand is nonnegative. The deficit is zero if and only if \(s(a_i)\geq s(a_j)\) for every \(i<j\). We have therefore proved

\( \mathcal M =\{(a_1,\ldots,a_m):s(a_1)\geq\cdots\geq s(a_m)\}. \)

Let \(\lambda_1>\cdots>\lambda_k\) be the distinct mean values and define \(B_i=\{a\in A:s(a)=\lambda_i\}\). Each block is nonempty, the blocks partition \(A\), and the strict refinements of

\( (B_1,\ldots,B_k) \)

are exactly \(\mathcal M\). Arbitrary permutations inside every block are retained.

3. The union and its transitive closure

Define \(Q=\{(a,b):s(a)\geq s(b)\}\). We prove that the union of the maximizing rankings already equals \(Q\).

Every maximizing ranking orders alternatives by nonincreasing mean, so every pair belonging to such a ranking belongs to \(Q\). Thus

\( \bigcup_{o\in\mathcal M}o\subseteq Q. \)

Conversely:

  • If \(s(a)>s(b)\), every maximizing ranking places \(a\) before \(b\).
  • If \(s(a)=s(b)\) and \(a\neq b\), a permutation of their common block can place \(a\) before \(b\), and that refinement is maximizing.
  • If \(a=b\), the pair belongs to every ranking by reflexivity.

These cases prove the reverse inclusion. Moreover, \(Q\) is transitive: \(s(a)\geq s(b)\) and \(s(b)\geq s(c)\) imply \(s(a)\geq s(c)\). Hence

\( R=\operatorname{TC}\!\left(\bigcup_{o\in\mathcal M}o\right) =\bigcup_{o\in\mathcal M}o =Q. \)

For \(m=1\), the same characterization applies, the score is zero, and the relation contains just the reflexive pair.

4. Polynomial-time computation with exact arithmetic

We give an integer implementation to justify the binary complexity bound.

Write every input rational with a positive denominator. Let \(D\) be the product of all denominators of the masses and profile values; for the threshold problem, include the denominator of \(q\) as well. The binary length of \(D\) is at most the sum of the denominator lengths, and hence is \(O(L)\), taking \(L\) to include the threshold when present.

For each type and alternative, compute

\( X_{t,a}=D\mu_t v_t(a). \)

This is an integer: the denominator of the product \(\mu_t v_t(a)\) divides the product of its two input denominators, which divides \(D\). These integers have \(O(L)\) bits. Their sums have \(O(L+\log\tau)\) bits, also \(O(L)\) because the input explicitly lists all types.

Compute

\( S_a=\sum_{t\in T}X_{t,a}=Ds(a). \)

Sorting the integers \(S_a\) and grouping equal values produces the required ordered partition. Output the relation by testing \(S_a\geq S_b\) for each pair. This uses \(O(m\tau+m\log m+m^2)\) integer arithmetic operations and comparisons on polynomial-length integers.

For the threshold problem, positivity of each \(\mu_t\) gives

\( C_{a,b} =\sum_{t\in T}\max\{X_{t,a}-X_{t,b},0\} =Dc(a,b). \)

Thus the scaled optimum is the integer

\( N=\sum_{\{a,b\}\in\binom A2}\max\{C_{a,b},C_{b,a}\} =DU. \)

Compute \(N\) using \(O(\tau m^2)\) arithmetic operations and compare it with the integer \(Dq\). Since \(D>0\),

\( \max_o W_\mu(o)\geq q \quad\Longleftrightarrow\quad N\geq Dq. \)

All intermediate integers have polynomial binary length, so both the output computation and the threshold decision take polynomial bit time.

For equal masses, ordering by \(s\) is equivalent to ordering by summed individual values, the additive constitution described in the [cited paper](https://www.scielo.org.mx/scielo.php?pid=S1870-66222014000200005&script=sci_arttext). The argument above additionally establishes the exact maximizing set and computational complexity for the rational-mass formulation.
