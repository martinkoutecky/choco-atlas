The anchor (named result in the paper)

Proposition 14 — class: algorithmic

The continuous mirror question, as graded

Given a finite supported type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), and each type's friend, neutral, and enemy rankings over types, can the atomless population be measurably partitioned into coalitions so that almost every type-\(t\) agent's coalition contains all mass of every friend type and zero mass of every enemy type?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of its \(\tau\geq 1\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible preference types; set \(m=|T|=\tau\), and let \(L\) be the total input bit length.
Each type \(t\) partitions \(T\) into friend, neutral, and enemy sets \(F_t,N_t,E_t\), with weak rankings on \(F_t\) and \(E_t\); neutral types are indifferent. Sets may be empty, and relationships need not be symmetric. Classification of \(t\) itself concerns other agents of type \(t\).
Realize the society as disjoint intervals \(X_t\) of lengths \(\mu_t\), with Lebesgue measure \(\lambda\), and put \(X=\bigsqcup_{t\in T}X_t\). A coalition structure \(\Gamma\) is a partition of \(X\) into nonempty measurable sets, with no restriction on their number or masses; types may split across coalitions. Write \(\Gamma(x)\) for the cell containing \(x\).
Call \(\Gamma\) perfect if there is a measurable set \(G\subseteq X\) with \(\lambda(X\setminus G)=0\) such that, for every \(t\) and \(x\in G\cap X_t\), \(\lambda(\Gamma(x)\cap X_s)=\mu_s\) for every \(s\in F_t\), and \(\lambda(\Gamma(x)\cap X_s)=0\) for every \(s\in E_t\). Neutral masses are unrestricted.

Is deciding whether such a perfect coalition structure exists in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite agents, verification and existence of perfect partitions are in \(\mathrm{P}\); possible and necessary perfection coincide with containing every friend and no enemy. This is established in the [2015 result](https://aamas.csc.liv.ac.uk/Proceedings/aamas2015/aamas/p1229.pdf) and confirmed in the [2020 full version](https://www.lamsade.dauphine.fr/~lang/papers/KerkmannLRRSS20.pdf).
No result settling this exact atomless existence problem was located in the literature search.

Modeling choices made when packaging the task

  • Realized the atomless population by disjoint Lebesgue intervals with the prescribed masses.
  • Made measurable partition precise through measurable cells and a measurable full-measure set of agents satisfying the conditions; allowed arbitrarily many cells, including zero-mass cells, without imposing a minimum coalition mass.
  • Allowed each type to split across coalitions, as individual agents rather than whole types are partitioned.
  • Interpreted same-type classification as applying to other agents of that type; excluding an agent herself changes no mass.
  • Used weak rankings for friends and enemies, indifference among neutrals, possibly empty categories, and potentially asymmetric relationships, following the discrete domain.
  • Set m equal to the support size because this problem has no separate candidate or alternative set; defined L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Polynomial-time decidability

The decision problem is in \(\mathrm{P}\). A friendship requirement forces both endpoint types into a single coalition up to null sets. These constraints propagate along undirected friendship paths. Types with no incident friendship requirement can instead be partitioned into singletons.

The finite-agent friendship-component algorithm appears in Proposition 26 and Corollary 28 of the [2020 full version](https://www.lamsade.dauphine.fr/~lang/papers/KerkmannLRRSS20.pdf). The proof below establishes the exact atomless criterion, including self-classifications and unrestricted measurable partitions.

1. Definitions and criterion

Construct an undirected graph \(H\) on \(T\). For distinct types \(t,s\), put an edge between them if \(s\in F_t\) or \(t\in F_s\). Include a loop at \(t\) if \(t\in F_t\).

Call a connected component active if it contains at least one edge, counting loops. Every inactive component is therefore a single type that neither names any friend nor is named as a friend.

Theorem. A perfect coalition structure exists if and only if every active component \(C\) satisfies

\[ E_t\cap C=\varnothing \quad\text{for every }t\in C. \]

Here and below, the displayed formulas are understood as mathematical expressions; equivalently, the criterion is \(E_t\cap C=\varnothing\) for every type \(t\) in every active component \(C\).

We prove both directions directly.

2. A friendship edge forces full masses into one cell

Lemma. Suppose \(\Gamma\) is perfect, witnessed by a measurable conull set \(G\). If \(s\in F_t\), then some cell \(A\in\Gamma\) satisfies both \(\lambda(A\cap X_t)=\mu_t\) and \(\lambda(A\cap X_s)=\mu_s\).

Proof. Since \(G\) is conull and \(\mu_t>0\), we have \(\lambda(G\cap X_t)=\mu_t>0\). Choose \(x\in G\cap X_t\), and let \(A=\Gamma(x)\). Perfection gives \(\lambda(A\cap X_s)=\mu_s\).

For any \(y\in G\cap X_t\), perfection likewise gives \(\lambda(\Gamma(y)\cap X_s)=\mu_s\). If \(\Gamma(y)\ne A\), these are disjoint cells of a partition. Their intersections with \(X_s\) would consequently be disjoint measurable sets, each of measure \(\mu_s\). Hence \(2\mu_s\leq\lambda(X_s)=\mu_s\), contradicting \(\mu_s>0\).

Thus every point of \(G\cap X_t\) belongs to \(A\). It follows that \(\lambda(A\cap X_t)\geq\lambda(G\cap X_t)=\mu_t\). The reverse inequality follows from \(A\cap X_t\subseteq X_t\), proving equality.

This argument also applies when \(s=t\). \(\square\)

We also use the following immediate consequence of disjointness: two cells containing the full mass of the same positive-mass type must be the same cell. Indeed, distinct such cells would again imply \(2\mu_t\leq\mu_t\).

3. Necessity of the criterion

Assume that \(\Gamma\) is perfect, and fix an active component \(C\).

For each friendship edge in \(C\), the lemma provides a cell containing the full masses of its endpoint types. If two edges share a vertex, their associated cells contain the full mass of that vertex and therefore coincide.

Connectivity propagates this equality along paths. Since every vertex of an active component is incident to an edge, there is one cell \(A_C\) such that \(\lambda(A_C\cap X_t)=\mu_t\) for every \(t\in C\). For a component consisting of one vertex with a loop, this conclusion follows directly from the lemma.

Suppose that \(s\in E_t\cap C\) for some \(t\in C\). Because \(G\) is conull, \(\lambda(A_C\cap G\cap X_t)=\mu_t>0\). Choose a point \(x\) in this intersection. Its cell is \(A_C\), so perfection requires \(\lambda(A_C\cap X_s)=0\). But \(s\in C\) implies \(\lambda(A_C\cap X_s)=\mu_s>0\), a contradiction.

Thus \(E_t\cap C=\varnothing\) for every \(t\in C\). This includes the prohibition of self-enmity within an active component.

4. Sufficiency: an explicit measurable partition

Assume the criterion holds.

For each active component \(C\), create the coalition \(B_C=\bigcup_{t\in C}X_t\). For every point \(x\) whose type belongs to an inactive component, create the singleton coalition \(\{x\}\).

These sets form a partition of \(X\): the component coalitions are disjoint, and the remaining points are partitioned into singletons. Every cell is nonempty and measurable. Each \(B_C\) is a finite union of measurable intervals, and each singleton is measurable.

We verify perfection for every point, so we may take \(G=X\).

If \(x\in X_t\) and \(t\) belongs to an active component \(C\), then \(\Gamma(x)=B_C\).

  • If \(s\in F_t\), the friendship edge puts \(s\) in \(C\). Hence \(\lambda(B_C\cap X_s)=\mu_s\).
  • If \(s\in E_t\), the criterion gives \(s\notin C\). Hence \(B_C\cap X_s=\varnothing\), and its measure is zero.

If \(t\) belongs to an inactive component, then \(F_t=\varnothing\) and \(\Gamma(x)=\{x\}\). All friendship requirements are vacuous. For every \(s\in E_t\), atomlessness gives \(\lambda(\{x\}\cap X_s)=0\).

Therefore the constructed partition is perfect. This proves sufficiency and completes the theorem. \(\square\)

5. Algorithm and complexity

The theorem gives the following decision procedure.

  • Construct \(H\), retaining whether each vertex has a friendship loop.
  • Compute its connected components and mark the active ones.
  • Inspect every directed enemy relation \(s\in E_t\). Reject precisely when \(t\) and \(s\) belong to the same active component.
  • Accept otherwise.

There are at most \(m^2\) friend relations and at most \(m^2\) enemy relations. Graph construction, component computation, and the final scan require \(O(m^2)\) elementary graph operations. Reading the encoding takes time polynomial in \(L\); vertex indices have polynomially bounded bit length. Consequently, the total running time is polynomial in \(m,\tau,L\), with \(m=\tau\).

The algorithm uses neither the numerical values of the masses nor the weak rankings. Positivity of each mass is essential to the rigidity lemma; the rankings impose no additional condition in the stated definition of perfection.

The possibly uncountable partition in the sufficiency proof is an explicit mathematical witness. The decision algorithm only needs the finite component data.

6. Boundary cases

If all friend sets are empty, the singleton partition is perfect, regardless of enemy classifications.

In particular, one type with \(F_t=\varnothing\) and \(E_t=\{t\}\) is feasible. Conversely, if \(a\) names \(b\) as a friend and \(b\in E_b\), the component containing them is active and violates the criterion, so no perfect partition exists.

Thus singleton coalitions handle unrestricted friendship-free types, while the positive masses make every friendship component subject to a finite, exact compatibility test.
