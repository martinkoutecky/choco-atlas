The continuous mirror question, as graded

Given \(q\) good classes with common values \(w_j\), a per-person capacity \(H\), and types \(t\in T\) with rational masses \(\mu_t\) and initial integral bundles \(b_t^0\in\mathbb{Z}_{\ge 0}^q\), where \(\sum_t\mu_t=1\) and supply per unit population is \(s_j=\sum_t\mu_t b^0_{t,j}\), does there exist a finite rational distribution \(x_{t,b}\ge 0\) over integral final bundles \(b\in\mathbb{Z}_{\ge 0}^q\), \(\sum_j b_j\le H\), such that \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}x_{t,b}b_j=s_j\), and \(\sum_{t,b}x_{t,b}\sum_j\max\{b^0_{t,j}-b_j,0\}\le K\), while every pair \(b,c\) used with positive mass satisfies \(w\cdot b\ge w\cdot c-\max_{j:c_j>0}w_j\), taking the maximum as \(0\) when \(c\) is empty?

A society is given by its support: the list of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\), and initial bundles \(b_t^0\in\mathbb Z_{\ge0}^{q}\). Here \(\tau\) is the support size, not the number of possible types; types describe initial bundles. All numerical inputs are binary encoded, and \(L\) is their total input bit length.
Set \(s_j=\sum_t\mu_t b^0_{t,j}\) and \(\mathcal B_H=\{b\in\mathbb Z_{\ge0}^{q}:\sum_j b_j\le H\}\); this bundle set is implicit. Initial bundles need not satisfy the final capacity.
A feasible reallocation is a finitely supported family \(x_{t,b}\in\mathbb Q_{\ge0}\), indexed by \(t\in T\) and \(b\in\mathcal B_H\), satisfying \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}x_{t,b}b_j=s_j\), and \(\sum_{t,b}x_{t,b}\sum_j\max\{b^0_{t,j}-b_j,0\}\le K\). Thus a type's mass may split among integral bundles, all supply is allocated, and cost counts goods removed from their original holders.

For finitely many agents and explicitly listed indivisible goods, deciding whether EF1 can be reached by changing at most a given number of owners is NP-complete under identical additive valuations, and weakly NP-hard already for three agents. [Discrete results](https://arxiv.org/html/2608.30669v1)

Result

The exact mass problem is \(\mathrm{NP}\)-complete, even with \(\tau=3\) and masses \(\frac12,\frac14,\frac14\).

The hardness reduction below explicitly accommodates splitting a type among multiple bundles. An exact algorithm runs in

\(\displaystyle \binom{H+m}{m}^{O(1)}\operatorname{poly}(m,\tau,L).\)

1. A consequence of a tight removal budget

Write \(|b|=\sum_j b_j\). For an initial bundle \(a\) and final bundle \(b\), define

\(\displaystyle d_a(b)=\sum_j\max\{a_j-b_j,0\},\qquad e_a(b)=\sum_j\max\{b_j-a_j,0\}.\)

These quantities satisfy

\(\displaystyle |b|=|a|-d_a(b)+e_a(b).\)

Consequently, if \(|a|=H+n\) and \(|b|\le H\), then

\(\displaystyle d_a(b)\ge n+e_a(b)\ge n.\)

Equality \(d_a(b)=n\) therefore forces \(e_a(b)=0\), \(|b|=H\), and \(b\le a\) coordinatewise.

Also, if \(|a|=H\) and \(d_a(b)=0\), then \(b\ge a\); the capacity restriction forces \(b=a\).

These observations apply separately to every bundle receiving positive mass.

2. Reduction from PARTITION

We use the standard \(\mathrm{NP}\)-complete PARTITION problem: given positive integers \(p_1,\ldots,p_n\), decide whether some subset has half their total sum. See [Karp, *Reducibility among Combinatorial Problems*](https://doi.org/10.1007/978-1-4684-2001-2_9).

Set

\(\displaystyle a_i=2p_i,\qquad B=\sum_{i=1}^n p_i,\qquad M=2B+1.\)

Thus \(\sum_i a_i=2B\), and the PARTITION instance is positive exactly when some \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in I}a_i=B\).

Construction

There are \(m=n+3\) classes:

| Class | Common value |
|---|---:|
| Item class \(i\), for each \(i\in\{1,\ldots,n\}\) | \(a_i\) |
| Marker class | \(M\) |
| Anchor class | \(B\) |
| Filler class | \(0\) |

Set \(H=n+1\) and \(K=n/4\). The three types have the following initial bundles:

| Type | Mass | Item classes | Markers | Anchor goods | Fillers |
|---|---:|---|---:|---:|---:|
| Anchor \(A\) | \(\frac12\) | None | \(0\) | \(1\) | \(n\) |
| Donor \(D\) | \(\frac14\) | One of each | \(1\) | \(0\) | \(n\) |
| Receiver \(R\) | \(\frac14\) | None | \(1\) | \(0\) | \(0\) |

Their initial bundle sizes are \(H,2n+1,1\), respectively. The donor initially exceeds final capacity, as the task permits.

All values and bundles have polynomial encoding length. The masses are dyadic, and \(H\) is linear in \(n\).

Forward implication

Suppose \(\sum_{i\in I}a_i=B\), and put \(r=|I|\). Assign each type a single final bundle:

  • \(A\) keeps its initial bundle.
  • \(D\) receives the item classes in \(I\), one marker, and \(n-r\) fillers.
  • \(R\) receives the complementary item classes, one marker, and \(r\) fillers.

Each bundle contains \(H\) goods.

Supply is conserved. Every item class initially has supply \(\frac14\), and appears finally in exactly one of the equal-mass types \(D,R\). Markers and anchor goods are unchanged. Final filler supply is

\(\displaystyle \frac12n+\frac14(n-r)+\frac14r=\frac34n,\)

which equals initial filler supply.

The donor loses \(n-r\) item goods and \(r\) fillers, so total removal cost is \(\frac14n=K\).

The three bundle values are \(B,B+M,B+M\). Their values after removing a most valuable good are \(0,B,B\), respectively. Hence every bundle’s value is at least every other bundle’s reduced value, which is exactly the required EF1 condition.

Reverse implication, including arbitrary mass splitting

Suppose a feasible EF1 reallocation exists.

First, the budget fixes the anchor and restricts every donor bundle. Each donor bundle requires at least \(n\) removals by Section 1. Donor mass alone therefore contributes at least

\(\displaystyle \mu_D n=\frac n4=K.\)

Since all costs are nonnegative, equality must hold throughout. Every positively used donor bundle has removal cost exactly \(n\), and every positively used anchor or receiver bundle has removal cost zero.

Section 1 now implies:

  • Every anchor bundle equals its initial bundle, and has value \(B\).
  • Every donor bundle is a coordinatewise subbundle of its initial bundle.

Second, EF1 bounds every used bundle’s value. The largest class value is \(M\): indeed, each \(a_i\le 2B<M\). Comparing the fixed anchor bundle against any used bundle \(b\) gives

\(\displaystyle B\ge w\cdot b-\max_{j:b_j>0}w_j,\)

and therefore

\(\displaystyle w\cdot b\le B+M.\)

Third, conservation makes this bound tight for every donor and receiver bundle. Initial total value is

\(\displaystyle \frac12B+\frac14(2B+M)+\frac14M=B+\frac M2.\)

The fixed anchor mass contributes \(\frac12B\). Supply conservation thus requires the donor and receiver masses together to contribute

\(\displaystyle \frac12(B+M).\)

Their combined mass is \(\frac12\), and every bundle they use has value at most \(B+M\). Consequently, every positively used donor or receiver bundle has value exactly \(B+M\). Explicitly,

\(\displaystyle \sum_{t\in\{D,R\}}\sum_b x_{t,b}\bigl(B+M-w\cdot b\bigr)=0,\)

and every summand is nonnegative.

Finally, any donor bundle supplies a partition. At least one donor bundle is used because \(\mu_D=\frac14>0\). It is a subbundle of the donor’s initial bundle, so it contains no anchor good and at most one good from each item class.

It must contain its marker. Otherwise its value would be at most \(\sum_i a_i=2B<B+M\). Removing that marker from its value leaves

\(\displaystyle \sum_{i:b_i=1}a_i=B.\)

This is a solution of the original PARTITION instance.

Thus the construction is an equivalence even when types may split arbitrarily, proving \(\mathrm{NP}\)-hardness with three types.

3. Polynomial-size certificates

We prove membership in \(\mathrm{NP}\), accounting for both the implicit bundle set and rational masses.

Take any feasible EF1 reallocation, and restrict attention to its positively used type–bundle pairs. Add a nonnegative slack variable \(z\) to write the budget as

\(\displaystyle \sum_{t,b}d_{b_t^0}(b)x_{t,b}+z=K.\)

Together with the type-mass and supply equations, this is a nonnegative linear system with

\(\displaystyle r=\tau+m+1\)

rows and integer coefficient matrix.

Among its nonnegative rational solutions, choose one with the fewest positive coordinates, counting \(z\). The columns corresponding to those positive coordinates are linearly independent. Otherwise, a nonzero rational dependence \(d\) among them would allow the following elimination: change its sign so some \(d_i>0\), set

\(\displaystyle \varepsilon=\min_{i:d_i>0}\frac{y_i}{d_i},\)

and replace \(y\) by \(y-\varepsilon d\). This preserves the equations and nonnegativity while eliminating at least one positive coordinate, contradicting minimality.

There are therefore at most \(r\) positive coordinates, and hence at most \(\tau+m+1\) positively used type–bundle pairs. Removing bundles preserves EF1, so this smaller solution is still EF1.

Its rational entries also have polynomial bit length. To see this, select a nonsingular square row minor of the independent columns and apply Cramer’s rule. Matrix entries are bounded by

\(\displaystyle U=\max\left\{1,H,\max_t|b_t^0|\right\},\)

whose bit length is polynomial in \(L\). The right-hand side consists of \(\mu_t,s_j,K\), also of polynomial bit length: a common denominator is obtained by multiplying the input denominators. Determinants of order at most \(r\), with entries bounded by \(U\), have absolute value at most \(r!U^r\). Clearing the right-hand-side denominators gives the same polynomial bit bound for the relevant numerator determinants.

A certificate can consequently list at most \(\tau+m+1\) triples \((t,b,x_{t,b})\), all of polynomial encoding length. Exact rational arithmetic verifies capacity, type masses, supplies, budget, and every ordered EF1 comparison in

\(\displaystyle \operatorname{poly}(m,\tau,L,\log(H+1))\)

bit operations. Since \(H\) is part of the binary input, this is polynomial in input length.

The problem is therefore in \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness.

4. An exact algorithm and running times

Define

\(\displaystyle V(b)=w\cdot b,\qquad \Delta(b)=\max_{j:b_j>0}w_j,\)

with \(\Delta(0)=0\).

For any nonempty finite set \(S\) of bundles, let \(a=\min_{b\in S}V(b)\). Then \(S\) satisfies EF1 exactly when

\(\displaystyle V(c)-\Delta(c)\le a\quad\text{for every }c\in S.\)

Necessity follows by comparing a minimum-value bundle against \(c\). Conversely, \(V(b)\ge a\ge V(c)-\Delta(c)\) proves every ordered EF1 comparison.

There are

\(\displaystyle N=|\mathcal B_H|=\binom{H+m}{m}\)

capacity-feasible bundles. Enumerate them and their values. For each distinct candidate \(a\in\{V(b):b\in\mathcal B_H\}\), define

\(\displaystyle S_a=\{b\in\mathcal B_H:a\le V(b)\le a+\Delta(b)\}.\)

Solve the rational linear feasibility problem consisting of the original mass, supply, and budget constraints, allowing only bundles in \(S_a\).

This procedure is exact:

  • Every feasible EF1 reallocation is included in the iteration for its minimum used value.
  • Any solution supported in \(S_a\) satisfies EF1, since \(V(b)\ge a\ge V(c)-\Delta(c)\).
  • Each LP has rational coefficients and is bounded by its type-mass constraints. If it is nonempty, it has a rational solution, as required.

There are at most \(N\) LPs, each with at most \(\tau N\) variables and polynomially bounded coefficient bit lengths. Polynomial-time rational linear programming therefore gives total running time

\(\displaystyle N^{O(1)}\operatorname{poly}(m,\tau,L).\)

Polynomial-time LP algorithms are a standard established result; see, for example, [Lee and Sidford](https://arxiv.org/abs/1312.6677).

Using \(N\le(H+1)^m\) and \(N\le(m+1)^H\), the bound can also be written in either form:

\(\displaystyle (H+1)^{O(m)}\operatorname{poly}(m,\tau,L),\)

\(\displaystyle (m+1)^{O(H)}\operatorname{poly}(m,\tau,L).\)

Thus fixed \(H\) gives polynomial time; fixed \(m\) gives a bound polynomial in the numerical capacity \(H\). For unrestricted \(m\), a running time polynomial in \(m,\tau,L,H\) would imply \(\mathrm P=\mathrm{NP}\), because the reduction already has \(\tau=3\) and \(H=n+1\).
