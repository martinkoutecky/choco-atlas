The continuous mirror question, as graded

Given a finite support \(T\), positive rational masses \(\mu_t\) summing to \(1\), and a symmetric relation \(w:T\times T\to\{-\infty,1\}\) with \(w_{tt}=1\), choose a finite set of groups and nonnegative masses \(x_{t,g}\) such that \(\sum_g x_{t,g}=\mu_t\) and \(x_{t,g}x_{s,g}=0\) for every enemy pair \(w_{ts}=-\infty\); maximize \(\Phi(x)=\sum_g\sum_{t,s:w_{ts}=1}x_{t,g}x_{s,g}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) counts supported types, not possible types; \(m=\tau\) is the number of vertices in the type graph, and \(L\) is the total input bit length.
The input also gives an explicit symmetric relation \(w:T\times T\to\{-\infty,1\}\), with \(w_{tt}=1\); pairs of weight \(-\infty\) are enemies.
A feasible allocation chooses any finite set \(G\) of groups and real masses \(x_{t,g}\geq0\) satisfying \(\sum_{g\in G}x_{t,g}=\mu_t\) and \(x_{t,g}x_{s,g}=0\) whenever \(w_{ts}=-\infty\). Mass may be divided among groups; each portion belongs to one group, and there is no stability requirement.
Maximize \(\Phi(x)=\sum_{g\in G}\sum_{(t,s)\in T^2:w_{ts}=1}x_{t,g}x_{s,g}\), counting ordered pairs and including same-type interactions. Let \(\mathrm{OPT}\) be the supremum over feasible allocations; algorithmic allocations are represented by explicit binary rational masses.

For each fixed \(0<\varepsilon<1\), can a feasible allocation satisfying \(\Phi(x)\geq\tau^{\varepsilon-1}\mathrm{OPT}\) be computed in time polynomial in \(m,\tau,L\), or is achieving this approximation guarantee NP-hard?

For finite agents with symmetric weights in \(\{-\infty,1\}\), maximum-welfare partitioning admits no polynomial-time \(n^{\varepsilon-1}\)-approximation for any fixed \(0<\varepsilon<1\), unless \(\mathrm{P}=\mathrm{NP}\); the accompanying argument treats the shifted objective \(\sum_g|X_g|^2=f(P)+n\). Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed \(0<\varepsilon<1\), achieving the guarantee \(\Phi(x)\geq\tau^{\varepsilon-1}\mathrm{OPT}\) is \(\mathrm{NP}\)-hard. Consequently, no polynomial-time algorithm achieves it unless \(\mathrm{P}=\mathrm{NP}\).

The key fact is that every feasible divisible allocation can be converted into an allocation that assigns each type wholly to one group, without decreasing welfare.

1. Removing division without decreasing welfare

Define the friendship graph on \(T\) by making distinct types \(t,s\) adjacent precisely when \(w_{ts}=1\). For any feasible allocation, the positive support of each group is a clique. Thus, writing \(M_g=\sum_{t\in T}x_{t,g}\), the ordered-pair convention and same-type interactions give

\(\displaystyle \Phi(x)=\sum_{g\in G}M_g^2.\)

Lemma. Every feasible allocation using finitely many groups can be converted into a feasible allocation in which each type belongs wholly to one group, with no decrease in \(\Phi\). For explicitly represented rational allocations, this conversion takes polynomial time in the input and allocation encoding lengths.

Proof. Fix a type \(t\), and hold all other types’ masses fixed. Let

\(\displaystyle I_t=\{g\in G:x_{t,g}>0\},\qquad a_g=\sum_{s\ne t}x_{s,g}.\)

Because \(\mu_t>0\), the set \(I_t\) is nonempty. Choose \(h\in I_t\) maximizing \(a_h\). Move all of type \(t\)’s mass to \(h\): replace \(x_{t,h}\) by \(\mu_t\) and every other \(x_{t,g}\) by zero.

This preserves feasibility. Every other type currently present in \(h\) is compatible with \(t\), since \(t\) already had positive mass there. Removing \(t\) from other groups creates no enemy pair.

Before the move,

\(\displaystyle \Phi(x)=\sum_{g\in G}a_g^2+2\sum_{g\in I_t}a_gx_{t,g}+\sum_{g\in I_t}x_{t,g}^2.\)

The choice of \(h\), nonnegativity, and \(\sum_{g\in I_t}x_{t,g}=\mu_t\) imply

\(\displaystyle \sum_{g\in I_t}a_gx_{t,g}\leq a_h\mu_t,\qquad \sum_{g\in I_t}x_{t,g}^2\leq\left(\sum_{g\in I_t}x_{t,g}\right)^2=\mu_t^2.\)

After the move, welfare is exactly

\(\displaystyle \sum_{g\in G}a_g^2+2a_h\mu_t+\mu_t^2,\)

so it has not decreased.

Process every type once. Processing another type never divides an already processed type. At the end, every type belongs wholly to one group; deleting empty groups leaves at most \(\tau\) groups.

For rational inputs, the procedure uses only rational sums, comparisons, and assignments of zero or an input mass. Every intermediate entry is either an original allocation entry, zero, or some \(\mu_t\). Exact arithmetic therefore has polynomial bit complexity, and the number of operations is polynomial in the explicit representation length. \(\square\)

Corollary. The supremum is attained, and

\(\displaystyle \mathrm{OPT}= \max_{\mathcal P}\sum_{C\in\mathcal P}\left(\sum_{t\in C}\mu_t\right)^2,\)

where \(\mathcal P\) ranges over partitions of \(T\) into friendship cliques.

Indeed, every finite feasible allocation is dominated by such a partition allocation. Conversely, every such partition defines a feasible allocation. There are finitely many partitions, and their allocations use the rational input masses.

2. Hardness reduction

We use the following established theorem: for every fixed \(0<\delta<1\), finding a clique of size at least \(n^{\delta-1}\omega(H)\) in an arbitrary \(n\)-vertex graph \(H\) is \(\mathrm{NP}\)-hard, where \(\omega(H)\) denotes its maximum clique size. This is the maximization formulation of [Zuckerman’s Theorem 1.1](https://theoryofcomputing.org/articles/v003a006/v003a006.pdf).

Fix \(0<\varepsilon<1\). Suppose a polynomial-time algorithm always outputs an explicit rational feasible allocation satisfying the requested guarantee.

Given a nonempty graph \(H=(V,E)\) with \(n\) vertices, construct a society by setting:

  • \(T=V\), so \(m=\tau=n\);
  • \(\mu_t=1/n\) for every type;
  • \(w_{tt}=1\);
  • for distinct \(t,s\), set \(w_{ts}=1\) when \(\{t,s\}\in E\), and \(w_{ts}=-\infty\) otherwise.

This is a valid instance. Its relation is symmetric, all masses are positive and sum to one, and its total encoding length is polynomial in \(n\): the numerator and denominator of each mass require \(O(\log n)\) bits.

Write \(\omega=\omega(H)\). Placing a maximum clique in one group and every remaining vertex in a singleton group gives a feasible allocation with welfare

\(\displaystyle \frac{\omega^2+n-\omega}{n^2}\geq\frac{\omega^2}{n^2}.\)

Consequently, the hypothetical algorithm outputs \(x\) satisfying

\(\displaystyle \Phi(x)\geq n^{\varepsilon-1}\mathrm{OPT} \geq n^{\varepsilon-1}\frac{\omega^2}{n^2}.\)

Apply the lemma to obtain a clique partition \(\mathcal P=\{C_1,\ldots,C_k\}\) whose allocation has welfare at least \(\Phi(x)\). Every nonempty group contains at least one vertex, so \(k\leq n\). Therefore,

\(\displaystyle Q:=\sum_{i=1}^{k}|C_i|^2 =n^2\Phi(\mathcal P)\geq n^{\varepsilon-1}\omega^2.\)

Let \(b=\max_i|C_i|\). Since each group has size at most \(b\),

\(\displaystyle Q\leq kb^2\leq nb^2.\)

Combining the inequalities yields

\(\displaystyle b\geq\omega\,n^{\varepsilon/2-1}.\)

Thus, returning the largest group produces a clique with the forbidden guarantee for \(\delta=\varepsilon/2\). All hypotheses of the cited theorem hold: \(H\) is arbitrary, \(\delta\) is fixed and lies strictly between zero and one, and construction, allocation processing, and clique extraction all take polynomial time. This contradicts the theorem unless \(\mathrm{P}=\mathrm{NP}\).

3. Why the shifted objective causes no gap

For equal masses, a whole-type partition satisfies

\(\displaystyle n^2\Phi(\mathcal P)=\sum_{C\in\mathcal P}|C|^2=f(\mathcal P)+n,\)

where \(f\) is finite-agent welfare excluding self-interactions.

The proof above works directly with \(\sum_C|C|^2\); it never subtracts the additive term \(n\). Its approximation guarantee therefore applies exactly to the objective in the question. The conversion lemma supplies the necessary justification that division cannot evade the hardness.

1. Objective and feasibility

The friendship graph correctly represents compatibility between distinct types. Feasibility implies that each group’s positive support is a clique: two enemy types cannot both have positive mass in the same group.

Consequently, the identity \(\Phi(x)=\sum_{g\in G}M_g^2\) is correct. Expanding each square counts all ordered pairs of types present in the group, including diagonal terms. Every such pair has weight \(1\); terms involving absent types vanish.

Empty groups contribute zero and cause no difficulty.

2. Removing division

The lemma is valid for every finite feasible allocation, including allocations with real masses.

  • Destination exists. Positive \(\mu_t\), conservation of mass, and finiteness of \(G\) ensure that \(I_t\) is finite and nonempty. Thus a maximizer of \(a_g\) over \(I_t\) exists.
  • Feasibility is preserved. Because \(x_{t,h}>0\) before the move, every other type with positive mass in \(h\) is compatible with \(t\). Increasing its mass there introduces no enemy pair. Removing its mass elsewhere also preserves feasibility. The move preserves nonnegativity and total mass \(\mu_t\).
  • The welfare expansion is exact. With other types fixed, the group mass is \(a_g+x_{t,g}\). Expanding its square gives precisely the three terms displayed in the proof.
  • Both inequalities are valid. The maximality of \(a_h\), together with nonnegative masses, gives

\(\sum_{g\in I_t}a_gx_{t,g}\leq a_h\mu_t\).
The inequality
\(\sum_{g\in I_t}x_{t,g}^2\leq\mu_t^2\)
follows because the cross terms in the square of their sum are nonnegative.

  • Sequential processing works. Processing a type changes only that type’s entries. Therefore, a previously processed type remains assigned wholly to its chosen group. Feasibility and nondecreasing welfare hold after every move.
  • The final group bound is correct. After deleting empty groups, each remaining group contains at least one whole type. Since each type belongs to exactly one group, there are at most \(\tau\) groups.

The polynomial-time claim also holds. Entries remain original allocation entries, zero, or input masses. Exact sums and comparisons of these rationals have polynomial bit complexity in the combined input and allocation encoding lengths. Explicit representation bounds the number of entries and groups that must be processed.

The corollary follows from the lemma.

Every finite feasible allocation is dominated by a partition into friendship cliques. Conversely, every such partition yields a feasible allocation using the original masses. There are finitely many partitions of the finite set \(T\), so their maximum exists and equals the stated supremum.

The resulting optimal allocation has rational masses. Thus neither real-valued allocations nor an unbounded choice of finite group counts creates an attainment or representation gap.

\(\bigl(\omega^2+n-\omega\bigr)/n^2\).
Since \(1\leq\omega\leq n\), this is at least \(\omega^2/n^2\).

The assumed approximation guarantee therefore implies
\(\Phi(x)\geq n^{\varepsilon-1}\omega^2/n^2\).
Applying the conversion lemma preserves this lower bound and yields a clique partition satisfying
\(Q=\sum_i|C_i|^2\geq n^{\varepsilon-1}\omega^2\).

\(b\geq\omega n^{\varepsilon/2-1}\).

For equal masses, the identity
\(n^2\Phi(\mathcal P)=\sum_C|C|^2=f(\mathcal P)+n\)
correctly accounts for ordered interactions and the omitted diagonal terms in \(f\).

The hardness proof operates directly on the sum of squared group sizes. It does not transfer a multiplicative approximation through subtraction of \(n\). Consequently, the shifted objective creates no gap.
