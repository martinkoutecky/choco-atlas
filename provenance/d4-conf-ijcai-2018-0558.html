The continuous mirror question, as graded

Given \(m\) candidates, committee size \(k\), a rational distribution \(\mu\) over a support \(T\) of complete rankings, a fixed rule \(r\in\{\text{egalitarian-SNTV},\text{egalitarian-Bloc},\text{egalitarian-}k\text{-Borda}\}\), and a threshold \(q\), decide whether there is a committee \(W\subseteq C\) with \(|W|=k\) such that \(\min_{t\in T} f^r_{m,k}(\operatorname{pos}_t(W))\ge q\); determine the complexity in \(m\), \(|T|\), and the input bit length.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\ge 1\) candidates, let \(1\le k\le m\), and let \(q\in\mathbb{Q}\) be a binary-encoded threshold.
A society is given by its support: a nonempty list \(T\) of \(\tau\) distinct strict complete rankings, each with positive binary-rational mass \(\mu(t)\), where \(\sum_{t\in T}\mu(t)=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
For \(W\subseteq C\) with \(|W|=k\), define \(s_t^r(W)\) as follows: egalitarian-SNTV uses the number of selected candidates ranked first; egalitarian-Bloc uses the number ranked among the first \(k\); egalitarian-\(k\)-Borda uses the sum of their Borda scores.
For a fixed rule \(r\) among these three, the decision problem asks whether some such \(W\) satisfies \(\min_{t\in T}s_t^r(W)\ge q\). Scores are unweighted by mass, and threshold equality is accepted.

For each fixed rule \(r\), is this decision problem in \(\mathrm{P}\) or NP-hard, with running times expressed in \(m,\tau,k,L\)?

For finite voter lists, egalitarian-SNTV is in \(\mathrm{P}\), while the threshold problems for egalitarian-Bloc and egalitarian-\(k\)-Borda are NP-hard; egalitarian scores are also invariant under voter duplication. [Verified source](https://www.ijcai.org/proceedings/2018/0008.pdf).
The support formulation therefore inherits these classifications; this is an inference from the definitions and verified results, so the stated target is already settled.

  • Specified a binary-rational threshold with unrestricted sign and defined L as the total input bit length.

Classification

For each fixed rule, with \(k\) part of the input, the support formulation has the following complexity:

| Rule | Complexity |
|---|---|
| Egalitarian-SNTV | \(\mathrm{P}\) |
| Egalitarian-Bloc | \(\mathrm{NP}\)-complete |
| Egalitarian-\(k\)-Borda | \(\mathrm{NP}\)-complete |

The hardness statements already hold when all support masses equal \(1/\tau\). Below, we prove the transfer from finite voter lists and give explicit algorithmic bounds.

1. Integer scores and irrelevant masses

Write \(\operatorname{pos}_t(c)\) for the position of candidate \(c\) in ranking \(t\), with the first position numbered \(1\). The three scores are

  • SNTV: \(s_t(W)=|W\cap\{c:\operatorname{pos}_t(c)=1\}|\).
  • Bloc: \(s_t(W)=|W\cap\{c:\operatorname{pos}_t(c)\le k\}|\).
  • \(k\)-Borda: \(s_t(W)=\sum_{c\in W}(m-\operatorname{pos}_t(c))\).

Every score is a nonnegative integer. Consequently, putting \(Q=\lceil q\rceil\), the acceptance condition is exactly

\(s_t(W)\ge Q\quad\text{for every }t\in T.\)

This equivalence includes threshold equality. Computing \(Q\) from the binary-rational encoding takes \(O(L^2)\) bit operations using ordinary integer division.

The masses never occur in these inequalities. Their positivity ensures that every listed ranking belongs to the support; their magnitudes have no further effect.

2. A polynomial-time algorithm for SNTV

Let \(F=\{c\in C:c\text{ is ranked first in some }t\in T\}\), and put \(d=|F|\).

For every committee \(W\) and ranking \(t\), its SNTV score belongs to \(\{0,1\}\). Moreover,

\(\min_{t\in T}s_t(W)=1\quad\Longleftrightarrow\quad F\subseteq W.\)

Indeed, a ranking gives score \(1\) precisely when its unique first-ranked candidate is selected. Requiring this for every ranking requires exactly the inclusion \(F\subseteq W\).

A size-\(k\) committee containing \(F\) exists precisely when \(d\le k\): necessity follows from cardinality, and sufficiency follows by adding \(k-d\) candidates from \(C\setminus F\), since \(k\le m\).

Thus the decision algorithm is:

  • If \(q\le0\), accept.
  • If \(q>1\), reject.
  • If \(0<q\le1\), accept precisely when \(d\le k\).

On a standard word RAM with candidate identifiers indexed by \(1,\ldots,m\), reading the input, comparing \(q\) with \(0,1\), and marking the first-ranked candidates takes \(O(L+m+\tau)\) time. This proves membership in \(\mathrm{P}\), including rational thresholds.

3. Polynomial reduction from finite voter lists

The external result we use is Theorem 1 of Aziz, Faliszewski, Grofman, Slinko, and Talmon: for finite lists of strict complete rankings, deciding whether a size-\(k\) committee has egalitarian score at least a given threshold is NP-hard for both Bloc and \(k\)-Borda. Their scoring definitions agree with those above, including Borda score \(m-\operatorname{pos}_t(c)\). [Egalitarian Committee Scoring Rules, Sections 2–3 and Theorem 1](https://www.ijcai.org/proceedings/2018/0008.pdf).

Fix either of these two rules. Given a finite-list instance with nonempty voter list \(V\), construct a support instance as follows:

  • Keep the same candidates, committee size, and threshold.
  • Remove repeated rankings from \(V\), obtaining \(T\).
  • Assign every \(t\in T\) mass \(\mu(t)=1/|T|\).

This produces a valid society: the rankings are distinct, every mass is a positive binary rational, and the masses sum to \(1\).

For every committee \(W\),

\(\min_{v\in V}s_v(W)=\min_{t\in T}s_t(W).\)

To justify this equality, every ranking appearing in \(V\) appears in \(T\), and each ranking in \(T\) appears in \(V\). Repetition therefore changes neither the set of score values nor its minimum. Hence the original instance and the constructed instance have identical answers.

The construction is polynomial in the original input length. Rankings can be sorted and deduplicated in polynomial time; there are at most \(|V|\) remaining rankings; and each mass \(1/|T|\) needs \(O(\log(|V|+1))\) bits.

This is a polynomial-time many-one reduction. The cited finite-list hardness theorem therefore proves NP-hardness of both support problems, even with uniform masses.

Conversely, any support instance can be converted into a finite voter list containing each support ranking once, discarding the masses. The same equality proves that this conversion preserves the answer. No expansion of rational masses into voter multiplicities is needed.

4. Verification and explicit running times

A certificate is a list of \(k\) distinct candidates. Its length is polynomial in \(L\). After checking that it defines a valid committee, compute its score for each support ranking and compare every score with \(Q\).

The scores are bounded respectively by \(1\), \(k\), and \(k(m-1)\), so they use \(O(\log(m+1))\) bits because \(k\le m\). All verification steps take polynomial time in \(L\). Thus all three problems belong to \(\mathrm{NP}\); combined with Section 3, this establishes NP-completeness for Bloc and \(k\)-Borda.

For completeness, an explicit exact algorithm for any of the rules enumerates the \(\binom{m}{k}\) committees. Precompute each ranking’s candidate scores in \(O(m\tau)\) word operations. Evaluating one committee then takes \(O(\tau k)\) word operations.

Using words of \(O(\log(m\tau+2))\) bits, a valid total upper bound is

\(O\!\left(L^2+m\tau+\binom{m}{k}\tau k\right)\)

word operations, including threshold preprocessing. A corresponding conservative bit-operation bound is

\(O\!\left(L^2+\left(m\tau+\binom{m}{k}\tau k\right)\log(m\tau+2)\right).\)

In particular, fixed \(k\) gives a polynomial-time algorithm for every rule. The NP-completeness classifications concern unrestricted input \(k\).

\[ \min_{t\in T}s_t(W)=1 \quad\Longleftrightarrow\quad F\subseteq W. \]

The committee-extension argument is valid: if \(d\le k\), then \(k-d\le m-d\), so sufficiently many candidates remain outside \(F\).
