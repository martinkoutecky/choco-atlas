The continuous mirror question, as graded

Given an even candidate set \(X\) and a rational distribution \(\mu\) over complete rankings of \(X\), compute an extended dominating \(m/2\)-subset graph \(G\) maximizing \(\sum_{(x,y)\in E(G)} d_\mu(x,y)\), where \(d_\mu(x,y)=\sum_{t:x\succ_t y}\mu_t-\sum_{t:y\succ_t x}\mu_t\). The graph is a tournament whose upper set has size \(m/2\) and dominates its complement; the question is to return a maximizing graph, equivalently its selected upper set and internal orientations.

Packaged proof task (what the prover saw — nothing else)

Let \(X\) have even cardinality \(m\geq4\). A society is given by its support: a list of \(\tau\) distinct strict complete rankings \(\succ_t\) of \(X\), each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length. State running times in \(m,\tau,L\).
Define \(d_\mu(x,y)=\sum_{t:x\succ_t y}\mu_t-\sum_{t:y\succ_t x}\mu_t\); zero margins are allowed.
An extended dominating \(m/2\)-subset graph is a tournament \(G\) on \(X\) with a subset \(A\subset X\), \(|A|=m/2\), such that \((x,y)\in E(G)\) for every \(x\in A\), \(y\in X\setminus A\). Orientations within both parts are unrestricted, including cycles.
The computational problem is to return any such graph maximizing \(\sum_{(x,y)\in E(G)}d_\mu(x,y)\); any maximizing graph is acceptable when optima tie.

Is this optimization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite profiles of strict rankings, maximizing the corresponding sum of integer pairwise margins is NP-hard even when the upper subset has size \(m/2\); with internal edges omitted, the maximizing subsets are those with the highest Borda scores. Classification

The optimization problem is \(\mathrm{NP}\)-hard. In particular, a running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The reduction preserves every maximizing graph, so allowing arbitrary choices among tied optima does not change this conclusion.

Reduction from finite profiles

Use the finite-profile hardness result given in the question: returning an extended dominating \(m/2\)-subset graph maximizing the sum of integer pairwise margins is \(\mathrm{NP}\)-hard. This is Proposition 8 of [Lang, Monnot, Slinko and Zwicker](https://www.lamsade.dauphine.fr/~lang/papers/JL-JM-AS-WZ-long.pdf), for the same graph class and the same objective before normalization.

Let a source instance consist of an explicitly listed profile \(V=(V_1,\ldots,V_n)\) of strict complete rankings on \(X\), where \(m=|X|\) is even. Define its integer margin by

\(M_V(x,y)=|\{i:x\succ_{V_i}y\}|-|\{i:y\succ_{V_i}x\}|.\)

List the distinct rankings occurring in \(V\) as \(\succ_1,\ldots,\succ_\tau\), and let \(c_t\) be the number of occurrences of \(\succ_t\). Construct the target society by setting

\(\mu_t=c_t/n.\)

This satisfies every input requirement: the rankings are distinct and strict, each mass is positive, and \(\sum_{t=1}^{\tau}\mu_t=1\).

For every pair of distinct alternatives,

\(d_\mu(x,y)=\frac{1}{n}\left(\sum_{t:x\succ_t y}c_t-\sum_{t:y\succ_t x}c_t\right)=\frac{M_V(x,y)}{n}.\)

Consequently, for every feasible tournament \(G\),

\(\sum_{(x,y)\in E(G)}d_\mu(x,y)=\frac{1}{n}\sum_{(x,y)\in E(G)}M_V(x,y).\)

The feasible graphs depend only on \(X\) and the required subset size, so they are identical in the source and target instances. Since \(1/n>0\), the displayed identity preserves all comparisons and all ties between their objective values. Thus any graph returned by a target optimizer also solves the source instance.

Polynomial encoding size

Repeated rankings can be grouped by sorting the explicitly listed profile and counting equal rankings. This takes polynomial time in the source input length.

Moreover, \(\tau\leq n\), and each fraction \(c_t/n\) requires \(O(\log(n+1))\) bits. The constructed target input therefore has length

\(L=O\!\left(\tau m\log m+\tau\log(n+1)\right),\)

which is polynomial in the source input length. Reducing fractions, if required by the encoding, also takes polynomial time.

Hence an algorithm polynomial in \(m,\tau,L\) for the target problem would solve the known \(\mathrm{NP}\)-hard source problem in polynomial time. This completes the hardness proof.

Exact computation and running times

The hardness is not caused by difficulty computing rational margins.

Write each input mass as \(\mu_t=a_t/b_t\), with positive integers encoded in binary. Set

\(D=\prod_{t=1}^{\tau}b_t,\qquad w_t=a_t(D/b_t).\)

The integer \(D\) has \(O(L)\) bits. Since the masses sum to one, \(\sum_t w_t=D\). Define

\(N(x,y)=\sum_{t:x\succ_t y}w_t-\sum_{t:y\succ_t x}w_t.\)

Then \(d_\mu(x,y)=N(x,y)/D\), with \(|N(x,y)|\leq D\). Using ordinary integer arithmetic, all margins can be computed within the conservative bound \(O(\tau m^2L^2)\) bit operations.

For completeness, there is an exact exhaustive algorithm with running time

\(O\!\left(\tau m^2L^2+\binom{m}{m/2}m^2L\right).\)

To justify it, fix a subset \(A\) of size \(m/2\). Its cross edges are forced. Every internal edge can be chosen independently because internal cycles are permitted. Thus the best score for this subset is

\(F_\mu(A)=\sum_{\substack{x\in A\\y\notin A}}d_\mu(x,y)+\sum_{\{x,y\}\subseteq A}|d_\mu(x,y)|+\sum_{\{x,y\}\subseteq X\setminus A}|d_\mu(x,y)|.\)

Enumerate all such subsets and evaluate \(D F_\mu(A)\) using the integer margins. Each evaluation takes \(O(m^2L)\) bit operations. For a maximizing subset, orient each internal pair toward its positive margin; choose either direction when its margin is zero. The resulting graph achieves the global optimum.

Why the Borda simplification does not apply

Let \(b_\mu(x)=\sum_{y\neq x}d_\mu(x,y)\). Antisymmetry gives

\(\sum_{\substack{x\in A\\y\notin A}}d_\mu(x,y)=\sum_{x\in A}b_\mu(x),\)

because the margins of pairs entirely inside \(A\) cancel. This proves the Borda characterization when internal edges are omitted.

For the present problem, however, the two internal absolute-margin sums in \(F_\mu(A)\) also contribute and depend on \(A\). The finite-profile reduction preserves precisely this full objective.
