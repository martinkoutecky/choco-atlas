The continuous mirror question, as graded

Given rational masses \(\mu=(\mu_{j,r})\) over finitely many protected-group and merit types \(t=(j,r)\), their within-group type order, \(k\), and a quota map producing integer bounds \(L_j(\mu),U_j(\mu)\), output an exact sample from \(D_\mu\): choose \(x\) uniformly from \(\{x\in\mathbb Z_{\ge0}^{\ell}:\sum_jx_j=k,\ L_j(\mu)\le x_j\le U_j(\mu)\}\), then choose uniformly a group word with counts \(x_j\) and apply the canonical within-group type fill; return infeasibility if the set is empty.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types \((j,r)\) with positive mass \(\mu_{j,r}\), each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types; \(j\in\{1,\ldots,\ell\}\) labels disjoint protected groups and \(r\) ranges over \(m\) merit labels. Each group has a supplied strict order of its supported types, best first.
Masses are measured in population units, without normalization: \(M=\sum_{j,r}\mu_{j,r}\), and the ranking length satisfies \(k\in\mathbb Z_{>0}\) and \(k<M\). Each rank holds one unit of mass.
A fixed polynomial-time computable quota map takes \((\mu,k)\) and returns integer bounds satisfying \(0\le L_j(\mu,k)\le U_j(\mu,k)\le\min\{k,\lfloor\sum_r\mu_{j,r}\rfloor\}\).
Define \(S_\mu=\{x\in\mathbb Z_{\ge0}^{\ell}:\sum_jx_j=k,\ L_j(\mu,k)\le x_j\le U_j(\mu,k)\text{ for every }j\}\). If this set is empty, return infeasibility. Otherwise, \(D_\mu\) chooses \(x\) uniformly from \(S_\mu\), then chooses uniformly a word \(y\in\{1,\ldots,\ell\}^k\) containing exactly \(x_j\) occurrences of each group.
Canonical fill processes ranks in order, taking the next unit of remaining mass from the assigned group in its supplied type order. A unit may cross type boundaries; output each rank as its list of type labels and rational portions. This defines \(D_\mu\) on filled rankings.
Let \(L\) be the total binary input length. Running times are measured in \(m,\tau,\ell,k,L\), using independent unbiased random bits.

Does exact sampling from \(D_\mu\), with infeasibility reporting, admit an algorithm with expected running time polynomial in \(m,\tau,\ell,k,L\), or is this problem NP-hard?

For finite item lists, uniform feasible group-count sampling has an \(O(k^2\ell)\) algorithm; conditional group words and within-group filling complete the ranking sample. These verified guarantees concern finite items rather than rational-mass fills. [Gorantla, Deshpande and Louis](https://arxiv.org/html/2203.00887v3)

Modeling choices made when packaging the task

  • The mass normalization and amount represented by one rank were undefined. Use unnormalized population mass, one unit per rank, and total mass M greater than k, matching selection of k items from a larger population.
  • Canonical within-group type fill was undefined for fractional masses. Consume mass from the best remaining type first, permitting a rank to contain rational portions from consecutive types.
  • Group availability was omitted. Require quota upper bounds not to exceed the floor of the group's total mass, so every permitted group count can be filled.
  • The quota map's representation and computational cost were unspecified. Treat it as fixed and polynomial-time computable from the society and k.
  • Use nonnegative integer quota bounds, as permitted by the exact-sampling algorithm, including zero representation.
  • Resolve within-group ties through the supplied strict type order; no comparison across groups is required.
  • Exact sampling's randomness and runtime convention were unspecified. Use unbiased random bits and expected bit running time polynomial in the explicit output length parameter k as well as the input parameters.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Exact sampling admits an expected polynomial-time algorithm

Under the stated assumptions, exact sampling from \(D_\mu\), with correct infeasibility reporting, has expected running time polynomial in \(m,\tau,\ell,k,L\).

The count-vector dynamic program is the same combinatorial construction used for finite items by [Gorantla, Deshpande and Louis, Section 4.1](https://arxiv.org/html/2203.00887v3#S4.SS1). Below, we prove its correctness directly, implement all randomness with unbiased bits, and establish the additional bounds needed for rational-mass filling.

1. Exact uniform integers from unbiased bits

For a positive integer \(N\), an exact uniform sample from \(\{0,\ldots,N-1\}\) can be generated as follows.

If \(N=1\), return zero. Otherwise, set \(b=\lceil\log_2 N\rceil\), generate \(b\) independent unbiased bits, and interpret them as an integer \(Z\in\{0,\ldots,2^b-1\}\). Accept when \(Z<N\); otherwise repeat with fresh bits.

Every accepted value has the same probability. More explicitly, writing \(p=N/2^b\), the probability of eventually returning any fixed \(z<N\) is

\(\displaystyle \sum_{t=1}^{\infty}(1-p)^{t-1}2^{-b}=\frac{2^{-b}}{p}=\frac1N.\)

Since \(p>1/2\), the expected number of trials is less than two. Thus this procedure terminates almost surely and uses expected \(O(1+\log N)\) bit operations.

2. Counting feasible vectors and reporting infeasibility

Evaluate the supplied quota map and abbreviate its outputs by \(L_j,U_j\).

For \(j\in\{1,\ldots,\ell+1\}\) and \(s\in\{0,\ldots,k\}\), define \(C_j(s)\) as the number of integer vectors \((x_j,\ldots,x_\ell)\) satisfying their quota bounds and having coordinate sum \(s\).

For the empty suffix, initialize

\(\displaystyle C_{\ell+1}(0)=1,\qquad C_{\ell+1}(s)=0\quad\text{for }s>0.\)

Compute the remaining entries in decreasing order of \(j\), using

\(\displaystyle C_j(s)=\sum_{a=L_j}^{\min\{U_j,s\}} C_{j+1}(s-a),\)

where an empty sum is zero.

Correctness. Partition the vectors counted by \(C_j(s)\) according to their first coordinate \(a=x_j\). Its possible values are precisely those in the displayed sum. For each such \(a\), the remaining coordinates must satisfy their own bounds and sum to \(s-a\), giving exactly \(C_{j+1}(s-a)\) possibilities. These cases are disjoint and exhaustive. Induction from the empty suffix therefore proves every table entry correct.

Consequently, \(C_1(k)=|S_\mu|\). If \(C_1(k)=0\), return infeasibility.

There are \((\ell+1)(k+1)\) entries, each requiring at most \(k+1\) additions. Every counted vector has coordinates in \(\{0,\ldots,k\}\), so

\(\displaystyle C_j(s)\le (k+1)^\ell.\)

Thus all entries have at most \(B=1+\lceil\ell\log_2(k+1)\rceil\) bits. The dynamic program takes \(O(\ell k^2 B)\) bit operations with ordinary binary addition.

3. Sampling the count vector and conditional word

Assume now that \(C_1(k)>0\).

Uniform count vector

Start with remaining sum \(s=k\). At group \(j\), assign each candidate \(a\in\{L_j,\ldots,\min(U_j,s)\}\) the integer weight \(C_{j+1}(s-a)\). Their total is \(C_j(s)>0\).

Draw an exact uniform integer from \(\{0,\ldots,C_j(s)-1\}\), partition this interval into consecutive blocks of those weights, and choose \(x_j=a\) when the sampled integer lies in its block. Then replace \(s\) by \(s-a\).

Zero-weight blocks cannot be selected, so the next state always has a positive completion count. At the terminal state, positivity of \(C_{\ell+1}(s)\) forces \(s=0\). Hence the algorithm produces a feasible vector.

For any fixed feasible \(x\), let \(s_j=k-\sum_{h<j}x_h\). Its probability is

\(\displaystyle \Pr(X=x)=\prod_{j=1}^{\ell}\frac{C_{j+1}(s_j-x_j)}{C_j(s_j)}=\frac{C_{\ell+1}(0)}{C_1(k)}=\frac1{|S_\mu|}.\)

The product telescopes because \(s_{j+1}=s_j-x_j\). Therefore \(X\) is exactly uniform on \(S_\mu\).

This stage makes \(\ell\) uniform-integer draws on at most \(B\)-bit ranges and scans at most \(k+1\) weights per group, so its expected bit complexity is polynomial.

Uniform word conditional on the counts

Given \(x\), initialize remaining counts \(c_j=x_j\). When \(n=\sum_j c_j>0\) positions remain, draw uniformly from \(\{0,\ldots,n-1\}\). Partition this interval into blocks of sizes \(c_1,\ldots,c_\ell\), emit the selected group \(j\), and decrement \(c_j\).

Thus the next group has conditional probability \(c_j/n\).

For any fixed word \(y\) with counts \(x\), multiplying its successive transition probabilities gives

\(\displaystyle \Pr(Y=y\mid X=x)=\frac{\prod_{j=1}^{\ell}x_j!}{k!}.\)

Indeed, occurrences of group \(j\) contribute the numerator factors \(x_j,x_j-1,\ldots,1\), while the denominators are \(k,k-1,\ldots,1\). The resulting probability is identical for every word with these counts, proving conditional uniformity.

There are \(k\) draws on ranges of size at most \(k\), with at most \(\ell\) blocks scanned per draw. The expected running time is polynomial in \(k,\ell\).

4. Rational canonical filling is exact and polynomial

Write each supported mass as \(\mu_{j,r}=a_{j,r}/b_{j,r}\), with positive integer numerator and denominator represented in binary. Form the common denominator

\(\displaystyle Q=\prod_{(j,r)\text{ supported}}b_{j,r}\)

and the integer masses

\(\displaystyle A_{j,r}=a_{j,r}(Q/b_{j,r}).\)

Because the total input length is \(L\), the binary lengths of \(Q\) and every \(A_{j,r}\) are \(O(L)\). Computing them uses polynomial-time integer multiplication and exact division. Only their binary representations are stored.

Maintain, for each group, a pointer into its supplied type order and the remaining integer mass of its current type. To fill a rank assigned to group \(j\), initialize the rank’s remaining capacity to \(Q\). Repeatedly take the minimum of that capacity and the current type’s remaining integer mass, output that type with portion \(h/Q\), and subtract \(h\) from both quantities. Advance the group pointer whenever a type is exhausted.

The fill cannot run out of mass. Let \(G_j=\sum_r\mu_{j,r}\). Before the \(q\)-th occurrence of group \(j\), exactly \(q-1\) population units have been consumed from it. Since \(q\le x_j\) and the quota promise gives

\(\displaystyle x_j\le U_j\le\lfloor G_j\rfloor\le G_j,\)

its remaining mass is

\(\displaystyle G_j-(q-1)\ge x_j-(q-1)\ge1.\)

Thus every assigned rank can be filled completely. Taking types in pointer order is exactly the specified canonical fill.

The output has polynomial size. Every emitted portion either exhausts a type or completes a rank, possibly both. Charge it to the exhausted type when there is one, and otherwise to the completed rank. Each supported type is exhausted at most once, and each rank completes once. Hence there are at most \(\tau+k\) emitted portions.

Each portion satisfies \(0<h\le Q\), so its numerator and denominator have \(O(L)\) bits. All residual integer masses also have \(O(L)\) bits because they only decrease. The fill therefore takes polynomial time in \(\tau,k,L\), including writing its type labels and rational portions. If reduced fractions are required, polynomial-time greatest-common-divisor computations suffice.

5. Distribution and total running time

The algorithm reports infeasibility exactly when \(S_\mu\) is empty. Otherwise:

  • It samples \(X\) uniformly from \(S_\mu\).
  • Conditional on \(X\), it samples \(Y\) uniformly among words with those counts.
  • It applies the prescribed deterministic canonical fill.

These are precisely the defining stages of \(D_\mu\), so the resulting filled ranking has exactly that distribution.

Quota evaluation and rational preprocessing are polynomial by assumption and the bounds above. The dynamic program, both sampling stages, and output generation have polynomial expected bit complexity in \(m,\tau,\ell,k,L\). All randomness uses independent unbiased bits.

This establishes the requested expected polynomial-time algorithm. The dependence is on the numerical parameter \(k\), as explicitly allowed in the question.
