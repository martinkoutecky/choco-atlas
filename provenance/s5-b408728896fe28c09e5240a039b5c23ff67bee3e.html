The continuous mirror question, as graded

Given candidates \(C\), target \(p\), registered plurality score masses \(s_c\), a finite set \(R\) of disjoint eligible group-template types, available mass \(\mu_r\) of each type, and bundle composition \(b_{r,c}\) giving the number of \(c\)-supporters per group copy, does there exist an activation mass \(x_r\) for each template such that \(0\le x_r\le\mu_r\), \(\sum_{r\in R}x_r\le\beta\), and \(s_p+\sum_{r\in R}b_{r,p}x_r\ge s_c+\sum_{r\in R}b_{r,c}x_r\) for every \(c\ne p\)?

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m\ge 2\), a target \(p\in C\), registered plurality score masses \(s_c\in\mathbb Q_{\ge 0}\), and an activation budget \(\beta\in\mathbb Q_{\ge 0}\), consider constructive control by adding disjoint groups.
Each eligible group-template type \(r\in R\) has available group-copy mass \(\mu_r\in\mathbb Q_{>0}\) and composition \(b_{r,c}\in\mathbb Z_{\ge 0}\), with \(\sum_{c\in C}b_{r,c}\ge 1\). Each member supports exactly one candidate. Different group copies share no voters, and eligible voters are disjoint from registered voters.
Activating mass \(x_r\in\mathbb R_{\ge 0}\) costs \(x_r\) and adds \(b_{r,c}x_r\) supporters of candidate \(c\). Partial activation is allowed; ties count as victories for \(p\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here types are tagged registered favorite-candidate types and eligible group-template types; \(\tau=|\{c:s_c>0\}|+|R|\) is the support size, not the number of possible types. Masses need not sum to one.
All numerical input is binary encoded; let \(L\) be its total bit length and \(k=\lceil\beta\rceil\). State running times in \(m,\tau,L\), and \(k\) when parameterized.
Decide whether there exist activation masses satisfying \(0\le x_r\le\mu_r\), \(\sum_{r\in R}x_r\le\beta\), and \(s_p+\sum_{r\in R}b_{r,p}x_r\ge s_c+\sum_{r\in R}b_{r,c}x_r\) for every \(c\in C\setminus\{p\}\).

Result

The continuous decision problem is in \(\mathrm P\). Consequently, it is also fixed-parameter tractable with respect to \(k=\lceil\beta\rceil\), with running time independent of \(k\) except through the binary input length. The discrete hardness results do not transfer to this formulation.

1. Exact linear-programming formulation

Let \(n=|R|\). By the definition of support size, \(n\le\tau\). For candidates whose registered type is absent from the support, set \(s_c=0\).

Introduce one real variable \(x_r\) for each listed eligible group-template type. Consider the following rational linear feasibility problem:

\(\displaystyle -x_r\le 0,\qquad x_r\le\mu_r \quad\text{for every }r\in R,\)

\(\displaystyle \sum_{r\in R}x_r\le\beta,\)

\(\displaystyle \sum_{r\in R}(b_{r,c}-b_{r,p})x_r\le s_p-s_c \quad\text{for every }c\in C\setminus\{p\}.\)

This system has \(n\) variables and \(2n+m\) inequalities.

Claim. The control instance is a yes-instance if and only if this linear system is feasible.

Proof. Suppose a successful activation vector exists. Its availability and budget constraints give the first two families of inequalities. For every rival \(c\), its victory condition rearranges as

\(\displaystyle s_p+\sum_{r\in R}b_{r,p}x_r \ge s_c+\sum_{r\in R}b_{r,c}x_r \quad\Longleftrightarrow\quad \sum_{r\in R}(b_{r,c}-b_{r,p})x_r\le s_p-s_c. \)

Thus the vector satisfies the linear system.

Conversely, suppose the linear system has a feasible vector. Its bounds permit precisely the partial activations allowed in the question. Disjointness ensures that contributions from different group copies add without double-counting voters. The budget inequality gives an affordable activation, and reversing the displayed rearrangement proves that \(p\)'s score is at least every rival's score. Since ties count as victories, the activation succeeds. This proves both directions.

If \(R\) is empty, the decision reduces directly to checking \(s_p\ge s_c\) for every rival.

2. Binary encoding and polynomial running time

We use the standard rational linear-programming theorem: feasibility of a finite system of non-strict linear inequalities with binary-encoded rational coefficients can be decided exactly in deterministic time polynomial in its encoding length. This is the polynomial-time linear-programming result of [Khachiyan](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here:

  • All coefficients and right-hand sides are rational.
  • Every constraint is linear and non-strict.
  • Every variable is continuous; there are no integrality requirements.

The construction also has polynomial encoding size. Each integer difference \(b_{r,c}-b_{r,p}\) has bit length \(O(L+1)\). For a rational difference, writing \(s_p=a/d\) and \(s_c=e/f\) gives

\(\displaystyle s_p-s_c=\frac{af-ed}{df},\)

whose numerator and denominator have bit length \(O(L+1)\). These differences can be computed with polynomial-time integer arithmetic.

Writing the constraint matrix densely therefore gives an encoding length \(B\) bounded by

\(\displaystyle B=O\!\left((m+\tau)(\tau+1)(L+1)\right).\)

Construction followed by exact rational linear programming takes

\(\displaystyle T(m,\tau,L)=(m+\tau+L)^{O(1)}\)

bit operations. Under the stated explicit input encoding, this is polynomial in input size. In particular, the algorithm expands neither the available masses into individual copies nor the compositions into individual voters.

The theorem decides exact feasibility, including feasible regions of lower dimension, so exact ties require no numerical tolerance assumption.

Thus the problem belongs to \(\mathrm P\); it could be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm P=\mathrm{NP}\).

3. Parameterization and the discrete comparison

The same algorithm has running time

\(\displaystyle T(k,m,\tau,L)=f(k)(m+\tau+L)^{O(1)},\qquad f(k)=1.\)

Hence the continuous problem is FPT with respect to \(k=\lceil\beta\rceil\). Its budget bounds total activated mass, which can be distributed among many template types.

The cited paper's [Theorem 4](https://fpt.akt.tu-berlin.de/publications/voter_control_tamc17.pdf) establishes discrete hardness for disjoint bundles. Fractional activation changes feasibility, as the following instance demonstrates.

Take \(C=\{p,a,b\}\), registered scores \((s_p,s_a,s_b)=(0,1,1)\), budget \(\beta=1\), and two disjoint group types with \(\mu_1=\mu_2=1\). In candidate order \((p,a,b)\), their compositions are

\(\displaystyle b_1=(2,2,0),\qquad b_2=(2,0,2).\)

With whole-group activation, the budget permits only neither group or one group. The respective final scores are \((0,1,1)\), \((2,3,1)\), and \((2,1,3)\); all fail.

With continuous activation, \(x_1=x_2=\tfrac12\) costs exactly \(1\) and gives final scores \((2,2,2)\). Thus \(p\) wins.

This verifies that replacing discrete selections by continuous masses can turn a no-instance into a yes-instance. The complete polynomial-time argument above applies to the continuous formulation itself.
