The continuous mirror question, as graded

Given binary issues, a common legal order \(O\), a finite support \(T\) of complete compact acyclic CP-net types, rational masses \(\mu_t\), type weights \(w_t\), target outcome \(p\), action \(A\in\{IV,DV,IV+DV\}\), and reachable transitions with \(C_{\mathrm{level}}\) costs \(\gamma(t,t')\), choose transfers \(x_{t,t'}\ge0\) for \(t\ne t'\) with \(\sum_{t'\ne t}x_{t,t'}\le\mu_t\) to minimize \(\sum_{t\ne t'}\gamma(t,t')x_{t,t'}\), subject to the resulting masses satisfying the weighted sequential-majority inequalities for \(p\) and forbidding transitions from a type whose top outcome is not \(p\) to one whose top outcome is \(p\); decide whether the optimum is at most \(\beta\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
There are \(m\ge1\) binary issues, a target \(p\in\{0,1\}^m\), and a common order \(O\). Each type consists of a positive binary-integer weight and a complete acyclic CP-net with strict conditional preferences, explicitly represented tables, and at most a fixed constant number of parents per issue; every parent precedes its child in \(O\).
Input explicitly lists the reachable destination types \(U\supseteq T\) and transitions \(E\subseteq T\times U\), excluding identity transitions; set \(\mu_s=0\) outside \(T\). Transitions preserve weights and dependency graphs and reverse conditional preference statements only: \(IV\) permits parentless issues, \(DV\) permits issues with parents, and \(IV+DV\) permits both. The list includes all destinations and transitions permitted by the selected action.
For a source type \(t\), let \(\ell_t(X)=1\) for parentless issues and otherwise \(\ell_t(X)=1+\max_{Y\text{ parent of }X}\ell_t(Y)\), and let \(k_t=\max_X\ell_t(X)\). The unit-multiplier \(C_{\mathrm{level}}\) cost is \(\gamma(t,s)=\sum_X f_{t,s}(X)(k_t+1-\ell_t(X))\), where \(f_{t,s}(X)\) counts changed table entries at \(X\); all table entries may be changed when the action permits their issue.
Write \(\operatorname{top}(s)\) for the unique most preferred outcome. Forbid transitions with \(\operatorname{top}(t)\ne p\) and \(\operatorname{top}(s)=p\). Choose real transfers \(x_{t,s}\ge0\) with \(\sum_s x_{t,s}\le\mu_t\); resulting masses are \(\nu_s=\mu_s-\sum_r x_{s,r}+\sum_t x_{t,s}\), with missing transfers zero.
Sequential majority follows \(O\), allowing either value at a tie. Let \(a_{s,j}(p)\) indicate that type \(s\) prefers \(p_j\) in the table entry whose parents are assigned their values in \(p\). Thus \(p\) is a winning outcome exactly when \(\sum_{s\in U}\nu_s w_s a_{s,j}(p)\ge\tfrac12\sum_{s\in U}\nu_s w_s\) for every issue \(j\).
Given a nonnegative binary-rational budget \(\beta\), the decision problem asks whether such transfers satisfy these inequalities and \(\sum_{(t,s)\in E}\gamma(t,s)x_{t,s}\le\beta\). Let \(L\) be the total input bit length; state running times in \(m,\tau,|U|,|E|,L\).

Is this continuous weighted negative sequential-majority bribery problem with \(C_{\mathrm{level}}\) costs in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For indivisible voters, weighted negative sequential-majority bribery is \(\mathrm{NP}\)-complete for all three actions and every considered cost scheme, including unit-multiplier \(C_{\mathrm{level}}\); the unweighted negative \(C_{\mathrm{level}}\) version is polynomial-time solvable. [Dorn and Krüger](https://arxiv.org/pdf/1410.5186v3)

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one; weights are positive binary integers and the budget is a nonnegative binary rational.
  • Interpreted the given reachable transitions as an explicit complete list, including destination types initially having zero mass; their number is a separate input parameter, not part of the support size.
  • Transfers preserve the source's weight and dependency graph; only conditional preference statements change.
  • Used unit individual cost multipliers because no multiplier vector was specified and the discrete hardness holds with all multipliers equal to one.
  • Used weak majority inequalities and branching at ties, consistent with the stated inequalities and the co-winner convention.
  • Allowed changes to all action-permitted table entries, including entries outside the target's evaluation path, rather than imposing the informal one-flip-per-issue simplification.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The stated continuous problem belongs to \(\mathrm{P}\) for each of \(IV\), \(DV\), and \(IV+DV\). The proof uses an exact rational linear program whose size is polynomial in the explicitly listed input.

The explicit representation of \(U\) and \(E\) is essential to this running-time statement.

1. Computing the permitted transfers and costs

Let \(d\) be the fixed upper bound on the number of parents per issue. Each conditional preference table has at most \(2^d\) entries.

For each type \(s\in U\), its top outcome can be computed by traversing \(O\), assigning each issue its preferred value given the already assigned parents. To justify this procedure, call its output \(g\). Starting from any other outcome, traverse \(O\) and correct each coordinate that differs from \(g\). Whenever a correction is necessary, all parents already have their values in \(g\), so the correction is a strictly improving flip. Thus every other outcome has an improving path to \(g\). At \(g\), every issue has its locally preferred value, so there is no improving flip. This proves that \(g=\operatorname{top}(s)\).

Delete precisely the forbidden transitions, obtaining

\( F=\{(t,s)\in E:\text{ it is not the case that }\operatorname{top}(t)\ne p\text{ and }\operatorname{top}(s)=p\}. \)

A deleted transition must carry zero mass, so deleting these variables preserves feasibility. Write \(q=|F|\), with \(q\le |E|\).

For each source \(t\), compute its levels in order \(O\). Because parents precede children, the defining recurrence directly computes every \(\ell_t(X)\) and \(k_t\). For each edge \((t,s)\in F\), compare the two explicit preference tables to compute every \(f_{t,s}(X)\), and hence \(\gamma(t,s)\).

A directed path contains at most \(m\) issues. Consequently,

\( 1\le \ell_t(X)\le k_t\le m,\qquad 0\le f_{t,s}(X)\le 2^d, \)

and therefore

\( 0\le \gamma(t,s)\le 2^d m^2. \)

Thus costs have \(O(\log(m+1))\) bits. This computation compares all table entries, including entries whose parent assignments differ from \(p\).

Also compute \(a_{s,j}(p)\) by looking up the table entry with parent values prescribed by \(p\).

These computations require \(O(m(|U|+\tau+|E|))\) table and graph operations for fixed \(d\), apart from polynomial overhead for reading and indexing the binary input.

2. Linear expressions for the majority conditions

Define the initial total voting weight and initial support for issue \(j\) by

\( W=\sum_{t\in T}\mu_t w_t,\qquad H_j=\sum_{t\in T}\mu_t w_t a_{t,j}(p). \)

For nonnegative transfers satisfying the source-capacity constraints, the resulting masses are nonnegative. Indeed, the mass removed from a source is at most its original mass, and incoming mass is nonnegative. Types outside \(T\) have no outgoing transfers. Summing the mass equations also gives \(\sum_{s\in U}\nu_s=1\).

Every transition preserves weight. Consequently,

\( \sum_{s\in U}\nu_s w_s =W+\sum_{(t,s)\in F}x_{t,s}(w_s-w_t) =W. \)

Likewise, expanding the resulting support for issue \(j\) gives

\( \sum_{s\in U}\nu_s w_s a_{s,j}(p) =H_j+\sum_{(t,s)\in F}w_t\bigl(a_{s,j}(p)-a_{t,j}(p)\bigr)x_{t,s}. \)

Define

\( D_{j,t,s}=2w_t\bigl(a_{s,j}(p)-a_{t,j}(p)\bigr),\qquad b_j=W-2H_j. \)

The required majority inequality is therefore exactly

\( \sum_{(t,s)\in F}D_{j,t,s}x_{t,s}\ge b_j. \)

These inequalities characterize the possibility of producing \(p\) sequentially. Necessity follows because a trajectory producing \(p\) has the parent values prescribed by \(p\) at each issue. For sufficiency, proceed inductively through \(O\): when the preceding decisions agree with \(p\), the displayed inequality permits choosing \(p_j\), including at a tie.

3. The linear program and its exact equivalence

Use one real variable \(x_{t,s}\) for each \((t,s)\in F\). Consider the following feasibility problem:

| Constraint | Range |
|---|---|
| \(\displaystyle x_{t,s}\ge 0\) | \((t,s)\in F\) |
| \(\displaystyle \sum_{s:(t,s)\in F}x_{t,s}\le\mu_t\) | \(t\in T\) |
| \(\displaystyle \sum_{(t,s)\in F}D_{j,t,s}x_{t,s}\ge b_j\) | Each issue \(j\) |
| \(\displaystyle \sum_{(t,s)\in F}\gamma(t,s)x_{t,s}\le\beta\) | Budget |

This program has \(q\) variables and \(q+\tau+m+1\) inequalities, counting nonnegativity.

Bribery implies LP feasibility. Every permitted bribery uses only edges in \(F\). Its transfers satisfy nonnegativity, source capacities, and the budget. The calculation in Section 2 converts its majority conditions into the LP majority constraints.

LP feasibility implies bribery. A feasible vector specifies transfers along permitted, non-forbidden transitions. Its source capacities guarantee valid resulting masses. Its budget constraint gives the required cost bound. Section 2 shows that its majority constraints permit sequential majority to produce \(p\).

Thus the decision problem and this LP have exactly the same answer. No integrality condition is needed: the task expressly permits real transfers.

4. Bit complexity and running time

Every coefficient is rational. The transition coefficients satisfy

\( D_{j,t,s}\in\{-2w_t,0,2w_t\}, \)

so their bit lengths are \(O(L)\). The costs have the smaller bound established in Section 1, and the capacities and budget are input rationals.

It remains to bound the computed right-hand sides \(b_j\). Write each input mass as \(\mu_t=u_t/v_t\), with positive integer denominator \(v_t\), and use the common denominator

\( Q=\prod_{t\in T}v_t. \)

The bit length of \(Q\) is at most the sum of the denominator bit lengths, plus a constant, and is therefore \(O(L)\). Moreover,

\( b_j=\frac{\sum_{t\in T}u_t(Q/v_t)w_t(1-2a_{t,j}(p))}{Q}. \)

Each numerator summand has \(O(L)\) bits; summing \(\tau\) such terms adds at most \(O(\log(\tau+1))\) bits. Because the support is explicitly listed, this is still \(O(L)\). Thus every LP coefficient and right-hand side has \(O(L)\) bits.

A dense encoding, including nonnegativity rows, consequently has length

\( B=O\bigl((q+1)(q+\tau+m+1)L\bigr). \)

All preprocessing and matrix construction use polynomially many operations on integers of \(O(L)\) bits. For example, using elementary integer arithmetic, a conservative construction bound is

\( O\Bigl(\bigl[m(|U|+\tau+|E|)+(q+1)(q+\tau+m+1)\bigr]L^2\Bigr). \)

The standard rational linear-programming theorem decides feasibility over the reals exactly in time polynomial in the binary encoding length; it also finds a rational feasible point when one exists. This includes lower-dimensional feasible regions and equality at the budget or majority thresholds. See the ellipsoid theorem in [Yang Cai’s dissertation](https://www.cs.yale.edu/homes/cai/publication/thesis/thesis.pdf).

Applying that theorem adds \(\operatorname{poly}(B)\) bit operations. The resulting total running time is therefore

\( \operatorname{poly}(m,\tau,|U|,|E|,L), \)

and, because all these objects are explicitly represented, it is polynomial in \(L\). This is a bit-complexity bound; it does not depend polynomially on the numerical magnitudes of the weights or denominators.

If \(q=0\), feasibility reduces directly to checking \(H_j\ge W/2\) for every issue.

5. Scope of the conclusion

The same proof applies to all three actions: the selected action changes the permitted edge list and computed costs, while the feasibility formulation remains linear.

The indivisible-voter hardness result supplied in the question does not establish hardness here. Indivisible transfers require discrete restrictions absent from this model; solving the continuous LP does not solve those discrete restrictions.

Accordingly, the stated continuous problem is polynomial-time solvable. It could also be \(\mathrm{NP}\)-hard only if \(\mathrm{P}=\mathrm{NP}\).
