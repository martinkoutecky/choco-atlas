The continuous mirror question, as graded

Given \(k\) rational, piecewise-linear, nondecreasing concave production functions \(p_i:[0,1]\to\mathbb{Q}_{\ge0}\), with \(p_i(0)=0\), an initial allocation \(x^0\in\Delta_k\), and a resource \(q\) whose marginal output exceeds that of every other resource at every feasible load, determine the least number \(R\) of rounds needed for \(p_q(1)-\sum_i p_i(x_i^R)\le\varepsilon\). In each synchronous round, each infinitesimal unit of mass samples a resource uniformly and switches when its offered marginal output exceeds its current one; offers use the pre-round allocation, and marginal values at kinks use the appropriate one-sided slopes.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here agents are identical, so \(\tau=1\), with total mass \(1\), and there are \(m=k\ge2\) resources.
Input consists of continuous, nondecreasing, concave piecewise-linear functions \(p_i:[0,1]\to\mathbb R_{\ge0}\), specified by binary-rational breakpoints and values with \(p_i(0)=0\); a binary-rational allocation \(x^0\in\Delta_k\); a resource \(q\); and a binary-rational tolerance \(\varepsilon>0\). Every segment slope of \(p_q\) strictly exceeds every segment slope of every \(p_i\) with \(i\ne q\).
At load \(x_i>0\), incumbents receive marginal value \(p'_{i,-}(x_i)\); an arriving unit is offered \(p'_{i,+}(x_i)\) when \(x_i<1\). These are the left and right slopes at kinks, respectively.
In each synchronous round, exactly \(1/k\) of the mass at each resource samples each destination, including its current resource. For distinct resources \(i,j\), mass \(x_i/k\) moves from \(i\) to \(j\) precisely when \(p'_{j,+}(x_j)>p'_{i,-}(x_i)\); otherwise it stays. All comparisons use pre-round loads, all transfers occur simultaneously, and ties retain the current resource. Empty sources and full destinations require no comparison.
Define \(R=\min\{r\in\mathbb Z_{\ge0}:p_q(1)-\sum_{i=1}^k p_i(x_i^r)\le\varepsilon\}\), with \(R=\infty\) if the set is empty. Let \(B\) be the total number of linear segments and \(L\) the total binary input length.

Is computing the least round \(R\), encoded in binary, polynomial-time solvable, or is its threshold decision problem NP-hard?
The threshold problem asks whether \(R\le T\) for an input binary integer \(T\ge0\); state running times in \(m,\tau,B,L\), including the encodings of \(\varepsilon\) and \(T\).

For finite societies with a strictly dominant resource, sequential uniform-sampling marginal-payment dynamics have expected convergence time \(O(k\ln n)\) for \(n>2\). [Bachrach–Rosenschein](https://www.ifaamas.org/Proceedings/aamas08/proceedings/pdf/paper/AAMAS08_0037.pdf)
No result settling this exact synchronous mass hitting-time problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted rational piecewise-linear functions as real-valued continuous functions specified by rational breakpoints and values; a nonconstant continuous function cannot have only rational values throughout a real interval.
  • Normalized the identical society to one supported type of mass 1; the initial allocation distributes that mass across resources.
  • Made continuum sampling deterministic: each source sends exactly a 1/k fraction to each sampled destination before acceptance decisions.
  • Used left slopes for incumbents and right slopes for arrivals, matching removal and addition marginal production; ties cause no switch.
  • Interpreted dominance globally across feasible loads, using strict segment-slope separation as required by the graded question's 'exceeds' condition.
  • Took epsilon to be a positive binary rational, allowed round 0, and defined the minimum of an empty hitting-time set as infinity.
  • Specified binary output and a binary threshold decision formulation to make the complexity question precise.

Result and encoding

Computing the least round \(R\) is polynomial-time solvable. The threshold problem belongs to \(\mathrm{P}\), and thus is not NP-hard under polynomial-time many-one reductions unless \(\mathrm{P}=\mathrm{NP}\).

We use the standard explicit binary encoding of rational numbers: numerators and denominators are written in binary. In particular, their bit lengths contribute to \(L\). For the threshold problem, \(L\) also includes the binary encoding of \(T\).

The key point is that strict dominance gives a polynomial bound on the number of rounds, even though \(\varepsilon\) may be exponentially small. Exact simulation up to that bound then finds the first qualifying round.

1. Exact contraction of the mass outside the dominant resource

Write

\[ \text{ } \]

Let \(s_r=1-x_q^r=\sum_{i\ne q}x_i^r\), and let \(\alpha=(k-1)/k\).

Suppose \(s_r>0\). Then \(x_q^r<1\), so arrivals at \(q\) are permitted. At any positive-load source \(i\ne q\), the incumbent left slope is a segment slope of \(p_i\), while the offered right slope at \(q\) is a segment slope of \(p_q\). Strict dominance therefore forces exactly \(x_i^r/k\) to move from \(i\) to \(q\).

Conversely, no positive mass leaves \(q\): its incumbent left slope strictly exceeds every offered slope at another resource. Transfers between other resources do not affect their total mass. Consequently,

\(x_q^{r+1}=x_q^r+s_r/k,\qquad s_{r+1}=\alpha s_r.\)

If \(s_r=0\), all mass is already at \(q\), and it stays there. Thus, in every case,

\(\displaystyle s_r=\alpha^r s_0.\)

This argument applies at kinks because both one-sided slopes are among the respective resource’s segment slopes.

2. Bounding the welfare gap

Define

\(a=\min\{\text{segment slopes of }p_q\},\)

\(M=\max\{\text{segment slopes of }p_q\},\)

\(b=\max\{\text{segment slopes of }p_i:i\ne q\}.\)

The hypotheses imply \(a>b\ge0\), and hence \(M>0\).

For any allocation \(x\in\Delta_k\), put \(s=1-x_q\). Summing slope times interval length over the finitely many segments gives

\(as\le p_q(1)-p_q(x_q)\le Ms.\)

Also, since \(p_i(0)=0\) and every slope of each \(p_i\), \(i\ne q\), is at most \(b\),

\(\displaystyle 0\le\sum_{i\ne q}p_i(x_i)\le b\sum_{i\ne q}x_i=bs.\)

Therefore the welfare gap \(G(x)=p_q(1)-\sum_i p_i(x_i)\) satisfies

\(\displaystyle (a-b)s\le G(x)\le Ms.\)

In particular, \(p_q(1)\) is indeed the maximum welfare, uniquely attained when all mass is at \(q\). Along the trajectory,

\(\displaystyle 0\le G(x^r)\le M\alpha^r s_0\le M\alpha^r.\)

3. A polynomial bound on the hitting time

Let \(d\) be the least nonnegative integer satisfying

\(M\le 2^d\varepsilon,\)

and set \(H=kd\).

For every integer \(k\ge2\), the binomial theorem gives

\(\displaystyle \alpha^{-k}=\left(1+\frac1{k-1}\right)^k\ge1+\frac{k}{k-1}>2.\)

Hence \(\alpha^k<1/2\). If \(d>0\), it follows that

\(\displaystyle G(x^H)\le M(\alpha^k)^d\le M2^{-d}\le\varepsilon.\)

If \(d=0\), the same conclusion at round zero follows from \(G(x^0)\le M\le\varepsilon\). Thus

\(\boxed{R\le H=kd.}\)

It remains to bound \(d\) in terms of the input encoding. A segment slope is

\(\displaystyle \frac{v_1-v_0}{t_1-t_0},\)

where \(t_0<t_1\) and all four entries are input rationals. Subtraction and division produce a rational with numerator and denominator of \(O(L)\) bits. Therefore \(M/\varepsilon\) also has \(O(L)\)-bit numerator and denominator, so \(d=O(L)\).

The integer \(d\) can be computed exactly by repeated doubling and rational comparison, using \(O(L)\) iterations. We conclude that

\(\boxed{R=O(kL).}\)

In particular, \(R\) is always finite for the stated positive tolerance.

4. Exact simulation has polynomial bit complexity

Choose \(D_0\) to be the product of the denominators of the initial coordinates. Its bit length is \(O(L)\). Represent every coordinate at round \(r\) as

\(\displaystyle x_i^r=\frac{N_i^r}{D_r},\qquad D_r=D_0k^r.\)

For distinct resources \(i,j\), let \(u_{ij}^r\in\{0,1\}\) indicate whether the transfer from \(i\) to \(j\) occurs. Set this indicator to zero for an empty source or full destination; otherwise determine it using the specified strict comparison of the right and left slopes. Let \(h_i^r=\sum_{j\ne i}u_{ij}^r\).

The synchronous update is exactly

\(\displaystyle N_i^{r+1}=(k-h_i^r)N_i^r+\sum_{j\ne i}u_{ji}^rN_j^r,\qquad D_{r+1}=kD_r.\)

Indeed, each outgoing or incoming transfer has mass \(N_i^r/(kD_r)\). This formula computes all transfers from the pre-round numerators.

Since \(h_i^r\le k-1\), the new numerators are nonnegative. Summing the update over all resources cancels outgoing and incoming terms, giving \(\sum_iN_i^{r+1}=kD_r=D_{r+1}\). Thus the representation remains an allocation, and \(0\le N_i^r\le D_r\).

Throughout rounds through \(H\), numerator and denominator bit lengths are therefore

\(O(L+H\log k).\)

All remaining operations are exact rational operations:

  • Locate each load among its resource’s breakpoints, selecting the appropriate left and right segments separately at a kink.
  • Compare the selected slopes strictly, retaining ties.
  • Evaluate the piecewise-linear functions and compare the welfare gap with \(\varepsilon\).

For a concrete arithmetic bound, write every segment as \(p_i(t)=A_{i,\ell}t+C_{i,\ell}\). Each coefficient has \(O(L)\)-bit numerator and denominator. A common denominator \(Q\) for all these coefficients, \(p_q(1)\), and \(\varepsilon\) has \(O(BL)\) bits, by taking the product of their denominators.

Consequently, welfare evaluation and its comparison with \(\varepsilon\) can use integer arithmetic with

\(S=O(BL+H\log k)\)

bits. Scanning all breakpoint lists takes \(O(B)\) comparisons per round, and determining all transfers takes \(O(k^2)\) comparisons. With schoolbook integer arithmetic, a conservative total bit-operation bound, including preprocessing, is

\(\displaystyle O\!\left(L+(H+1)(B+k^2)(BL+H\log k)^2\right).\)

5. Algorithms and running times

To compute \(R\), compute \(H\), then inspect the welfare predicate at rounds \(0,1,\ldots,H\), simulating each intervening round exactly. Return the first successful round. Section 3 guarantees that one exists.

This scan establishes minimality directly; it requires no assumption that synchronous welfare is monotone.

For the threshold problem, if \(T\ge H\), return yes. Otherwise scan rounds \(0,\ldots,T\), returning yes exactly when some inspected round satisfies the welfare predicate. Merely checking round \(T\) is unnecessary.

Substituting \(m=k\), \(\tau=1\), and \(H=O(mL)\), both algorithms have the conservative polynomial running-time bound

\(\displaystyle O\!\left(L+mL(B+m^2)(BL+mL\log m)^2\right).\)

Here \(L\) includes \(\varepsilon\), and includes \(T\) for threshold decision. There is no dependence polynomial in the numerical value of \(T\): at most \(O(mL)\) rounds are simulated. The binary output for \(R\) has \(O(\log(mL+1))\) bits.

The cited finite-agent expected convergence bound is a separate result; this proof uses the deterministic mass recurrence directly. See [Bachrach–Rosenschein, Section 7](https://www.ifaamas.org/Proceedings/aamas08/proceedings/pdf/paper/AAMAS08_0037.pdf).
