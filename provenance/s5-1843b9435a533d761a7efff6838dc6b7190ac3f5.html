Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given \(d\) good classes with per-unit-population supplies \(q_j\in\mathbb{Q}_{\ge 0}\), and \(\tau\) types \(t\) with rational masses \(\mu_t\ge 0\) summing to \(1\), where type \(t\) has nonnegative additive values \(v_{tj}\) and divisibility set \(D_t\), define \(M_t=\sup_P \operatorname*{ess\,inf}_{b\sim P} v_t\cdot b\), over distributions \(P\) on valid type-\(t\) bundles satisfying \(\mathbb{E}_P[b_j]\le q_j\) for each \(j\). Given the exact \(M_t\), compute a finite-support allocation with rational bundle masses \(x_{t,b}\): for \(j\notin D_t\), \(b_j\in\mathbb{Z}_{\ge 0}\), and for \(j\in D_t\), \(b_j\in\mathbb{Q}_{\ge 0}\); require \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}x_{t,b}b_j\le q_j\), and \(v_t\cdot b\ge 3M_t/5\) whenever \(x_{t,b}>0\). Is such an allocation computable in time polynomial in \(d,\tau\), and the binary input length?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types.
There are \(m=d\ge1\) good classes, with per-unit-population supplies \(q_j\in\mathbb Q_{\ge0}\). Each type has additive unit values \(v_{tj}\in\mathbb Q_{\ge0}\) and a divisibility set \(D_t\subseteq\{1,\ldots,d\}\).
A valid type-\(t\) bundle belongs to \(B_t=\{b\in\mathbb R_{\ge0}^d:b_j\in\mathbb Z_{\ge0}\text{ for }j\notin D_t\}\), with value \(v_t\cdot b\). Class quantities count units; there is no individual upper bound on a bundle coordinate.
Define \(M_t=\sup_P\operatorname*{ess\,inf}_{b\sim P}v_t\cdot b\), where \(P\) ranges over Borel probability distributions on \(B_t\) satisfying \(\mathbb E_P[b_j]\le q_j\) for every \(j\).
The exact values \(M_t\in\mathbb Q_{\ge0}\) are supplied, with their correctness promised. Let \(L\) be the total binary input length, including these values.
An allocation is a finite list of rational bundles \(b\in B_t\cap\mathbb Q^d\) and masses \(x_{t,b}\in\mathbb Q_{\ge0}\), satisfying \(\sum_bx_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_j\le q_j\) for every \(j\). Unused supply is allowed.

Can an allocation satisfying \(v_t\cdot b\ge\frac35M_t\) whenever \(x_{t,b}>0\) always be computed in time polynomial in \(d=m\), \(\tau\), and \(L\)?

For finitely many agents with subjective divisibility, a \(\frac35\)-MMS allocation always exists and is computable in polynomial time when exact MMS values are supplied ([source](https://arxiv.org/html/2608.26801v1)).
No result settling this precise distribution-over-types problem was located in the literature search.

Modeling choices made when packaging the task

  • Take all unit values to be nonnegative binary rationals, and include the supplied exact rational benchmarks in the input length; their correctness is a promise.
  • Interpret benchmark distributions as Borel probability distributions with real divisible coordinates and integer indivisible coordinates; output bundles have rational divisible coordinates.
  • Interpret good classes as quantities of interchangeable units, retaining the stated integer-coordinate model without a per-bundle unit cap.
  • Allow zero benchmarks without scaling them, retain zero supplies and values, and allow unused supply.
  • Identify the general goods parameter m with the number d of good classes.

Result

Yes. Such an allocation can always be computed in time polynomial in \(d\), \(\tau\), and \(L\).

The crucial feature is that every type’s benchmark uses the same expected supply vector \(q\). Consequently, distributions feasible for individual types can be combined using the weights \(\mu_t\). We construct each distribution by a polynomial-size rational linear program.

The [cited finite-agent theorem](https://arxiv.org/html/2608.26801v1) is not needed for this construction.

1. Reduction to one type

Suppose that, for each type \(t\), we compute a finite rational distribution \(P_t\) satisfying

\(P_t[v_t\cdot b\ge \frac35M_t]=1,\qquad \mathbb E_{P_t}[b_j]\le q_j\quad\text{for every }j.\)

Assign each bundle in \(P_t\) its probability multiplied by \(\mu_t\). The total mass assigned to type \(t\) is then \(\mu_t\), and total consumption of class \(j\) is at most

\(\sum_t\mu_t\mathbb E_{P_t}[b_j]\le \sum_t\mu_tq_j=q_j.\)

Thus it suffices to solve the following single-type problem in polynomial time.

Fix a type and abbreviate its data by \(v,D,M\). If \(M=0\), the distribution concentrated on the zero bundle suffices. Henceforth assume \(M>0\).

2. A finite rounding construction

Set

\(R=3d,\qquad h=\frac{M}{5d}.\)

For each coordinate \(j\), define a finite set of choices. If \(v_j=0\), the only choice is \(k=0\), with quantity \(a_j(0)=0\). If \(v_j>0\), allow every integer \(k\in\{0,\ldots,R\}\), with quantity

\(a_j(k)=\begin{cases} kh/v_j,&j\in D,\\ \lceil kh/v_j\rceil,&j\notin D. \end{cases}\)

These quantities are rational and satisfy the coordinate’s divisibility requirement. Moreover,

\(v_j a_j(k)\ge kh.\)

We will use only bundles obtained by choosing one such quantity for each coordinate, with choice indices satisfying

\(\sum_{j=1}^d k_j\ge R.\)

Every such bundle has value at least

\(\sum_jv_ja_j(k_j)\ge h\sum_jk_j\ge hR=\frac35M.\)

Although the number of these bundles can be exponential, a polynomial-size flow network will represent their distributions.

Rounding lemma

Claim. Every valid bundle \(b\) with \(v\cdot b\ge\frac45M\) has a coordinatewise smaller bundle from the construction above whose choice indices sum to at least \(R\).

Proof. Define

\(k_j=\min\{R,\lfloor v_jb_j/h\rfloor\}.\)

For \(v_j=0\), this gives \(k_j=0\). For \(v_j>0\), we have \(k_jh/v_j\le b_j\). Therefore:

  • If \(j\in D\), then \(a_j(k_j)=k_jh/v_j\le b_j\).
  • If \(j\notin D\), then \(b_j\) is an integer, so \(\lceil k_jh/v_j\rceil\le b_j\).

Thus \(a_j(k_j)\le b_j\) in every coordinate.

If any \(k_j=R\), their sum is at least \(R\). Otherwise no truncation occurs, and the inequality \(\lfloor z\rfloor\ge z-1\) gives

\(h\sum_jk_j\ge \sum_jv_jb_j-dh\ge \frac45M-\frac15M=\frac35M=hR.\)

Since \(h>0\), this again implies \(\sum_jk_j\ge R\). This proves the claim. \(\square\)

Existence of a feasible rounded distribution

By the definition of \(M\) as a supremum, and because \(\frac45M<M\), there exists an admissible Borel probability distribution \(P\) whose essential infimum of value is greater than \(\frac45M\). In particular,

\(v\cdot b\ge\frac45M\quad\text{almost surely under }P.\)

This step does not assume that the supremum defining \(M\) is attained.

Apply the rounding lemma to its bundles. The rounding map is Borel measurable: each index is obtained by composing a continuous coordinate function with floor and truncation. Its image is finite.

The resulting distribution is supported on the constructed bundles, each worth at least \(\frac35M\). Coordinatewise domination also gives

\(\mathbb E[a_j(k_j)]\le \mathbb E_P[b_j]\le q_j.\)

This establishes feasibility. The probabilities in this existence argument need not be rational; the next step computes rational probabilities.

3. Computing the distribution by a flow linear program

Construct a directed acyclic graph with vertices

\((j,s),\qquad j\in\{0,\ldots,d\},\quad s\in\{0,\ldots,R\}.\)

Here \(j\) records how many coordinates have been chosen, and \(s\) records the accumulated choice indices, truncated at \(R\).

For every coordinate \(j\), state \(s\), and allowed choice \(k\), add an edge

\((j-1,s)\longrightarrow (j,\min\{R,s+k\}).\)

Label this edge by the quantity \(a_j(k)\). Parallel edges, when present, are retained as distinct choices.

Let the source be \((0,0)\) and the sink be \((d,R)\). Introduce a nonnegative variable \(f_e\) for each edge. Impose:

  • Unit flow from the source to the sink, with flow conservation at every other vertex.
  • For every coordinate \(j\), the supply constraint

\(\sum_{\substack{e\text{ chooses}\\\text{coordinate }j}}a_j(k(e))f_e\le q_j.\)

These are rational linear constraints.

Every source-to-sink path chooses exactly one quantity for each coordinate. Induction along the path shows that its final state is

\(\min\{R,\sum_jk_j\}.\)

Consequently, reaching the sink means \(\sum_jk_j\ge R\), and the associated bundle is valid and worth at least \(\frac35M\).

Conversely, every choice sequence with \(\sum_jk_j\ge R\) determines a source-to-sink path. The rounded distribution established in Section 2 therefore induces a feasible unit flow: assign each edge the probability that its corresponding path uses it. Its expected coordinate consumption is exactly the left-hand side of the associated supply constraint.

Thus the linear program is feasible.

Rational output and path decomposition

We use the standard polynomial-time theorem for rational linear programming: feasibility can be decided, and a rational feasible point of polynomial encoding length can be returned, in time polynomial in the system’s binary encoding length. Its hypotheses hold here because every constraint coefficient and right-hand side is rational.

Decompose the returned flow into source-to-sink paths. Repeatedly choose a path of positive-flow edges, subtract the minimum flow on that path, and record that minimum as its probability.

Such a path exists whenever positive flow remains: conservation permits extending a positive-flow edge through each intermediate layer, and only the designated sink can absorb flow. Every subtraction sets at least one positive edge to zero. Hence there are at most as many paths as edges. Once the source’s remaining flow is zero, acyclicity and conservation imply that no flow remains anywhere.

The recorded probabilities are rational, sum to \(1\), and reproduce all edge flows. The resulting bundle distribution therefore satisfies every supply constraint and the required value guarantee.

4. Polynomial running time and output size

The graph has \((d+1)(R+1)\) vertices and at most

\(d(R+1)^2=O(d^3)\)

edges, since \(R=3d\).

Each candidate quantity is formed from an input value \(M\), an input value \(v_j\), and integers bounded by \(5d\), using rational arithmetic and possibly a ceiling. Its binary encoding length is polynomial in \(L+\log d\). This remains true even when an indivisible quantity is numerically very large: its integer value is encoded in binary.

The linear program therefore has polynomial encoding length. Rational linear programming returns a feasible flow of polynomial encoding length, and path decomposition produces at most \(O(d^3)\) bundles.

The decomposition also has polynomial bit complexity. To see this explicitly, take the product of the denominators of the returned edge flows as a common denominator. Its bit length is at most the sum of their denominator bit lengths, hence polynomial. All subsequent subtraction operations preserve this common denominator, and remaining flows and path probabilities lie between \(0\) and \(1\).

Perform this construction separately for every type with positive \(M_t\), and use the zero bundle for every remaining type. Multiply the resulting probabilities by \(\mu_t\). The masses remain rational with polynomial encoding length. Section 1 proves that their combined consumption is at most \(q\).

This completes the polynomial-time algorithm and its correctness proof.

5. A stronger consequence

The same argument works for every fixed rational \(\alpha\in(0,1)\).

For a positive benchmark \(M\), choose

\(R=\left\lceil\frac{2\alpha d}{1-\alpha}\right\rceil,\qquad h=\frac{\alpha M}{R}.\)

Then \(dh\le\frac{1-\alpha}{2}M\). The supremum definition supplies an admissible distribution with values at least \(\frac{1+\alpha}{2}M\) almost surely. The rounding lemma, with these parameters, preserves value at least

\(\frac{1+\alpha}{2}M-dh\ge\alpha M.\)

The flow construction is unchanged. Its size is polynomial in \(d\) and \(\frac1{1-\alpha}\), so every fixed ratio strictly below \(1\) is achievable in polynomial time. No assertion about computing the exact ratio \(1\) is needed for the target question.
