The continuous mirror question, as graded

Given a finite issue set \(P\), behavioral types \(T\) with positive rational masses \(\mu_t\) summing to \(1\), successor maps \(f_p:T\to T\), and initial binary opinions \(b^0:T\times P\to\{0,1\}\), determine whether there is a \(K\) such that \(b^{k+1}_{t,p}=b^k_{t,p}\) for every \(k\ge K\), \(t\in T\), and \(p\in P\). If so, return the eventual opinions and their mass shares; otherwise, return an issue and a disagreeing cycle witnessing nonconvergence.

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a nonempty issue set with \(m=|P|\). A society is given by its support: a nonempty list \(T\) of \(\tau=|T|\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has an initial opinion \(b^0_{t,p}\in\{0,1\}\) on each issue. Issues are logically independent. For each issue, an explicitly supplied, fixed map \(f_p:T\to T\) specifies whose opinion each type copies; self-copying is allowed.
Updates are synchronous: \(b^{k+1}_{t,p}=b^k_{f_p(t),p}\) for every \(k\in\mathbb N\), type and issue. Masses remain fixed, and everyone of a given type shares its opinion.
Decide whether there exists \(K\in\mathbb N\) such that \(b^{k+1}_{t,p}=b^k_{t,p}\) for all \(k\ge K\), \(t\in T\), and \(p\in P\). If so, return the eventual opinions \(b^\infty_{t,p}\) and shares \(s_{p,x}=\sum_{t:b^\infty_{t,p}=x}\mu_t\) for \(x\in\{0,1\}\); otherwise return an issue and a directed cycle of its successor map containing two different initial opinions.
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this convergence decision problem in \(\mathrm P\), or is it NP-hard? Can the specified eventual opinions and mass shares, or a disagreeing-cycle witness, be computed in polynomial time in \(m,\tau,L\)?

For finite lists of agents, Boolean DeGroot convergence is characterized by a modal fixed-point formula and is decidable in polynomial time. [Christoff–Grossi](https://arxiv.org/pdf/1612.08048)

Result

The convergence decision problem belongs to \(\mathrm P\). The eventual opinions and exact mass shares, or the required disagreeing-cycle witness, can all be computed in polynomial time.

More precisely, the graph computation takes \(O(m\tau)\) elementary operations with indexed access. Including binary input processing and exact rational arithmetic, a conservative bound for the entire task is \(O(m\tau L^2)\) bit operations.

The characterization is:

The society converges if and only if, for every issue, every directed cycle of its successor map has a constant initial opinion.

The proof below works directly on the supplied support of size \(\tau\); it requires no expansion of masses into individual agents.

1. Opinions along successor paths

Fix an issue \(p\). Write \(f_p^0(t)=t\), and let \(f_p^k\) denote the \(k\)-fold composition of \(f_p\).

For every type \(t\) and every \(k\in\mathbb N\),

\[ b^k_{t,p}=b^0_{f_p^k(t),p}. \]

Indeed, the identity holds at \(k=0\). If it holds at \(k\), the update rule gives

\[ b^{k+1}_{t,p} =b^k_{f_p(t),p} =b^0_{f_p^k(f_p(t)),p} =b^0_{f_p^{k+1}(t),p}. \]

Thus the opinion of a type reads the initial opinions along its forward successor path. The masses do not occur in this identity.

Because \(f_p\) is a function on a finite set, every forward path eventually enters a directed cycle. To see this explicitly, among the first \(\tau+1\) vertices of the path there must be a repetition. Taking the first repetition decomposes the path into a prefix of distinct vertices followed by a cycle of distinct vertices.

Let \(d_p(t)\) be the number of steps before the path first enters that cycle, and let \(C_p(t)\) be the cycle it enters. If the cycle has length \(r\), its vertices and the preceding prefix are distinct, so

\[ d_p(t)+r\le \tau, \qquad d_p(t)\le \tau-1. \]

2. Proof of the convergence characterization

A disagreeing cycle prevents convergence

Suppose that, for some issue \(p\), there is a directed cycle

\[ (c_0,c_1,\ldots,c_{r-1}), \qquad f_p(c_i)=c_{(i+1)\bmod r}, \]

whose initial opinions are not all equal.

Choose indices \(i,j\) with \(b^0_{c_i,p}\ne b^0_{c_j,p}\), and let \(\delta\in\{1,\ldots,r-1\}\) satisfy \(j\equiv i+\delta\pmod r\). The path identity implies, for every \(q\in\mathbb N\),

\[ b^{qr}_{c_i,p}=b^0_{c_i,p}, \qquad b^{qr+\delta}_{c_i,p}=b^0_{c_j,p}. \]

Both sequences of times are unbounded, and the corresponding opinions differ. Hence the opinion of \(c_i\) is not eventually constant.

The requested convergence condition would make every opinion constant from time \(K\) onward: repeated use of \(b^{k+1}_{t,p}=b^k_{t,p}\) gives \(b^k_{t,p}=b^K_{t,p}\) for every \(k\ge K\). The disagreeing cycle therefore contradicts convergence.

Constant cycle opinions imply convergence

Conversely, suppose every cycle of every \(f_p\) has a constant initial opinion. For a cycle \(C\), denote that common opinion by \(x_{p,C}\in\{0,1\}\).

For any type \(t\), once \(k\ge d_p(t)\), the vertex \(f_p^k(t)\) lies on \(C_p(t)\). Therefore,

\[ b^k_{t,p}=b^0_{f_p^k(t),p} =x_{p,C_p(t)} \qquad\text{for every }k\ge d_p(t). \]

Consequently, the eventual opinion is

\[ b^\infty_{t,p}=x_{p,C_p(t)}. \]

Since the sets of issues and types are finite, a common stabilization time is

\[ K=\max_{p\in P,\ t\in T}d_p(t)\le \tau-1. \]

For every \(k\ge K\), every type and issue already has its eventual opinion, proving the required convergence condition.

This completes both directions of the characterization.

3. Computing eventual opinions or a witness

For each issue, consider the functional graph with vertices \(T\) and edges \(t\to f_p(t)\). The following traversal computes all eventual opinions or finds a disagreeing cycle.

Maintain three states for each vertex: unvisited, active on the current path, and finished. Also maintain the current path and the position of each active vertex on it.

Starting at an unvisited vertex, follow successors, appending and marking vertices active, until one of two events occurs:

  • The successor is active. Its recorded position identifies the cycle as a suffix of the current path. Check whether the initial opinions on that suffix are all equal.

If they differ, return the issue and the cycle in successor order. By Section 2, this is a valid nonconvergence witness.

Otherwise, assign the cycle’s common opinion to every vertex on the current path and mark those vertices finished. This assignment is correct because every vertex on that path eventually reaches the identified cycle.

  • The successor is finished. Assign its previously computed eventual opinion to every vertex on the current path and mark them finished. This is correct because their forward paths join a path whose eventual opinion has already been established.

Repeat until all vertices are finished.

Every vertex enters a current path at most once and is finished once. Each successor edge is examined at most once during path extension. Cycle checks and assignments also inspect each vertex at most a constant number of times. Thus the traversal takes \(O(\tau)\) indexed operations per issue and \(O(m\tau)\) overall.

A returned witness contains at most \(\tau\) distinct types. Its correctness can also be checked directly: verify the successor edges, including the closing edge, and verify that two initial opinions differ.

4. Exact mass shares and their binary size

Suppose the traversal succeeds for every issue. Write each input mass as

\[ \mu_t=\frac{a_t}{d_t}, \qquad a_t,d_t\in\mathbb Z_{>0}, \]

with numerator and denominator encoded in binary. Define a common denominator and integer weights by

\[ D=\prod_{t\in T}d_t, \qquad w_t=a_t\frac{D}{d_t}. \]

These are exact integers, and \(w_t/D=\mu_t\). For each issue, compute

\[ N_{p,1}=\sum_{t:\ b^\infty_{t,p}=1}w_t. \]

The requested shares are then

\[ s_{p,1}=\frac{N_{p,1}}{D}, \qquad s_{p,0}=\frac{D-N_{p,1}}{D}. \]

The second equality uses the input hypothesis \(\sum_t\mu_t=1\).

The possibly large numerical value of \(D\) causes no exponential binary output. Specifically,

\[ \log_2 D=\sum_t\log_2 d_t\le L, \]

so \(D\) has \(O(L)\) bits. Positivity and normalization imply \(\mu_t\le1\), hence \(w_t\le D\). They also imply \(0\le N_{p,1}\le D\). Every integer in the displayed share representations therefore has \(O(L)\) bits.

The output consists of \(m\tau\) eventual-opinion bits and \(2m\) rational shares, with total size \(O(m\tau+mL)\). Fractions with zero numerator are allowed, as required when a share is zero.

5. Running time and complexity conclusion

The following bounds distinguish graph operations from binary arithmetic:

| Computation | Running time |
|---|---:|
| Functional-graph traversal and opinion assignment | \(O(m\tau)\) indexed operations |
| Constructing \(D\) and all \(w_t\), using schoolbook arithmetic | \(O(\tau L^2)\) bit operations |
| Computing all share numerators | \(O(m\tau L)\) bit operations |
| Writing the successful output | \(O(m\tau+mL)\) bit operations |

For the arithmetic bound, each multiplication or exact division involves \(O(L)\)-bit integers and costs \(O(L^2)\) with elementary binary algorithms. Each share accumulation adds \(O(L)\)-bit integers.

A conservative overall bound, including parsing and a sequential implementation of the graph tables, is \(O(m\tau L^2)\) bit operations. For example, implementing each indexed graph access by scanning an \(O(L)\)-bit table gives \(O(m\tau L)\) graph-processing time, which fits this bound. The exact fractions above need not be reduced to satisfy the output specification.

Because the initial-opinion table is explicitly supplied, \(m\tau\le L\). Thus the overall bound is polynomial in \(L\), establishing membership in \(\mathrm P\). NP-hardness under polynomial-time many-one reductions would consequently imply \(\mathrm P=\mathrm{NP}\).

6. Relation to the cited result

Theorem 3 of [Christoff–Grossi, *Liquid Democracy: An Analysis in Binary Aggregation and Diffusion*](https://arxiv.org/pdf/1612.08048#page=22) states the same cycle characterization for finite-agent Boolean DeGroot processes.

Here its graph hypotheses hold directly on \(T\): the support is finite, every issue has one fixed successor per type, and updates copy that successor synchronously. Sections 1–2 independently prove the characterization for this input model. Sections 3–5 establish the support-size running time and the additional exact mass-share computation.
