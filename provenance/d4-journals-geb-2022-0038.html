The continuous mirror question, as graded

Given a finite set of types \(T\), rational masses \(\mu_t>0\) summing to \(1\), integer capacities \(q_t\), rankings \(\succ_t\) of good types, and a schedule containing each type \(t\) exactly \(q_t\) times, compute the resulting type-level circulation. At each scheduled phase for type \(t\), assign mass \(\mu_t\) one unit of acceptable goods per unit of agent mass, choosing the lexicographically best assignment in \(\succ_t\) among those that leave an individually rational completion for all remaining mass. Each good type \(u\) supplies \(q_u\mu_u\); the final allocation must use all supplies and leave every type with an acceptable bundle.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq2\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type owns its own good type, so the number of good types is \(m=\tau\). Input includes binary-encoded capacities \(q_t\in\mathbb Z_{\geq0}\), strict complete rankings \(\succ_t\) of \(T\), and an explicitly listed schedule \(\pi\) containing each \(t\) exactly \(q_t\) times; let \(Q=\sum_tq_t\) and let \(L\) be the total input bit length.
Good \(u\) is acceptable to \(t\) exactly when \(u=t\) or \(u\succ_t t\). Goods are divisible; an acceptable bundle contains no positive quantity of an unacceptable good.
A type-level circulation is a nonnegative matrix \(X\) with \(\sum_uX_{tu}=q_t\mu_t\), \(\sum_tX_{tu}=q_u\mu_u\), and \(X_{tu}=0\) whenever \(u\) is unacceptable to \(t\). A partial allocation \(x\) has an individually rational completion when such an \(X\) exists with \(X\geq x\) coordinatewise.
Start with \(x=0\). At each scheduled occurrence of \(t\), choose a nonnegative increment \(z\) with \(\sum_uz_u=\mu_t\), supported on acceptable goods, such that adding \(z\) to row \(t\) leaves an individually rational completion. Choose the lexicographically greatest \(z\), with coordinates ordered by \(\succ_t\), and retain all earlier assignments. Output the final matrix exactly, as binary rationals.

Can this resulting circulation be computed in time polynomial in \(m,\tau,Q,L\), or is its computation NP-hard?

For discrete agents with indivisible goods and an explicitly listed schedule, Single-Serial-IR outcomes can be computed in \(O(n^6Q)\) time, where \(n\) is the number of agents and \(Q\) the schedule length. [Source](https://doi.org/10.1016/j.geb.2022.10.006). This result concerns indivisible unit choices and does not establish the complexity of the mass-valued phases defined here.

Modeling choices made when packaging the task

  • Specified strict complete rankings and defined acceptable goods as those ranked at least as highly as the type's own good, including the own good.
  • Carried over nonnegative integer capacities, allowing zero, and the requirement of at least two participating types.
  • Identified types with their agent-specific good types, so m equals tau.
  • Specified binary capacities, an explicitly listed schedule, and total input bit length L; Q measures the schedule length.
  • Interpreted phase assignments as divisible aggregate quantities, allowing a phase's mass to split among acceptable good types.
  • Defined completion by coordinatewise preservation of all earlier assignments, exact row and column totals, and exclusion of every unacceptable good.
  • Specified exact binary-rational output for the resulting circulation.

Result

The resulting circulation can be computed exactly in time polynomial in \(m,\tau,Q,L\). The key is that each phase is a transportation problem, and all lexicographic optima remain integral after scaling by a single common denominator.

If \(Q=0\), the output is the zero matrix. Henceforth assume \(Q>0\).

1. A common denominator

Write each input mass as \(\mu_t=p_t/d_t\), with positive integers \(p_t,d_t\), and set

\(D=\prod_{t\in T}d_t,\qquad a_t=D\mu_t.\)

Then every \(a_t\) is a positive integer, and \(\sum_t a_t=D\). The binary length of \(D\) is \(O(L)\), because the sum of the binary lengths of the input denominators is at most \(L\). If “binary rational” means dyadic rational, \(D\) is also a power of two.

We work in units of \(1/D\). Thus the prescribed total for row and column \(t\) is \(q_ta_t\), and an occurrence of type \(t\) assigns exactly \(a_t\) scaled units.

Let \(b=Dx\) denote the scaled partial allocation. We will prove inductively that \(b\) remains integral.

2. Each phase is a transportation problem

Suppose the next scheduled type is \(t\), and define the residual row and column totals by

\(R_s=q_sa_s-\sum_u b_{su},\qquad C_u=q_ua_u-\sum_s b_{su}.\)

The induction invariant is that \(b\) has an acceptable completion with the prescribed totals. In particular, all these residual totals are nonnegative.

If \(t\) has already occurred \(k_t\) times, then its row has received exactly \(k_ta_t\) scaled units. Because another occurrence remains,

\(R_t=(q_t-k_t)a_t\geq a_t.\)

Construct a transportation problem with:

  • a current row for \(t\), of supply \(a_t\);
  • a future row for \(t\), of supply \(R_t-a_t\);
  • one row for each \(s\neq t\), of supply \(R_s\);
  • one column for each good \(u\), of demand \(C_u\).

Both rows associated with \(t\) have edges precisely to goods acceptable to \(t\). Every other row has edges precisely to goods acceptable to its type. Variables on allowed edges are nonnegative.

Let \(w_u\) be the amount sent from the current row to column \(u\). The feasible vectors \(w\) are exactly the scaled feasible increments in the question.

Indeed, given such a transportation flow, combine the current and future rows of \(t\), and add all residual assignments to \(b\). This yields an acceptable completion containing \(b+w\).

Conversely, suppose \(b+w\) has a scaled completion \(F\). Use \(w\) as the current row, \(F_{tu}-b_{tu}-w_u\) as the future row, and \(F_{su}-b_{su}\) for every other row. These quantities are nonnegative and have exactly the required supplies and demands.

The transportation problem is feasible: take any residual completion of \(b\), and split \(a_t\) units from its row \(t\) into the current row. Divisibility and \(R_t\geq a_t\) permit this split.

Its feasible set is compact, since each variable is nonnegative and bounded by the total residual supply. Consequently, each successive coordinate maximum needed for lexicographic optimization exists.

3. Integrality of transportation optima

We use the following lemma, including its proof to address exactness.

Lemma. Consider a feasible transportation problem on any finite bipartite graph, with nonnegative integer row supplies and column demands. Every linear objective has an integral optimal solution.

Proof. The feasible set is compact, so an optimum exists. Among all optimal solutions, choose one with the fewest positive variables.

Suppose its positive-support graph contains a cycle. A bipartite cycle has even length. Alternately add and subtract a sufficiently small quantity along its edges. Both signs of this perturbation preserve all row and column totals and remain nonnegative.

If the objective changes under this perturbation, one sign improves it, contradicting optimality. Therefore the objective is unchanged. Choose the perturbation magnitude so that an edge being decreased reaches zero. This preserves optimality and strictly reduces the number of positive variables, another contradiction.

Thus the positive-support graph is a forest. At a leaf, the value of its sole positive incident edge equals that vertex’s remaining supply or demand, which is an integer. Remove this edge and leaf, and subtract its integer value from the neighboring vertex’s remaining total. Repeating this process shows that every positive variable is integral. \(\square\)

Now consider a phase in which some current-row coordinates have already been fixed to integer values. Fixing such an edge to value \(v\) is equivalent to deleting the edge and subtracting \(v\) from its row supply and column demand. Hence the remaining problem is again a transportation problem with integer margins.

Applying the lemma to the next current-row coordinate proves that its maximum is an integer. Inducting over the ranking proves that the entire lexicographically greatest vector \(w\) is integral.

This applies to the optimization over all real feasible flows, so restricting the coordinate search to integers does not change the specified outcome.

4. Computing a phase by max-flow tests

Process acceptable goods in the order specified by \(\succ_t\). Unacceptable coordinates are identically zero.

Suppose earlier current-row coordinates have been fixed, and the next coordinate is \(w_j\). Its maximum lies in the integer interval \([0,a_t]\), by the preceding lemma.

For an integer \(h\) in this interval, test whether there is a feasible transportation flow satisfying the fixed coordinates and \(w_j\geq h\):

  • Delete previously fixed current-row edges, subtracting their fixed values from the corresponding margins.
  • Reserve \(h\) units on the current-row edge to column \(j\): subtract \(h\) from that row’s remaining supply and from column \(j\)’s remaining demand, and retain the edge for any additional flow.
  • Reject if a resulting margin is negative.
  • Otherwise test the remaining transportation problem by maximum flow.

For the last step, add a source with an edge to each row, whose capacity is that row’s supply. Add an edge from each column to a sink, whose capacity is that column’s demand. Every allowed row-column edge receives capacity

\(N=\sum_s q_sa_s\leq QD.\)

This bound cannot exclude any feasible transportation flow, since every edge carries at most the total supply. The problem is feasible exactly when a maximum flow saturates all source-row edges: total row supply equals total column demand, so such saturation also forces every column demand to be met.

The feasibility predicate is monotone in \(h\). Binary search therefore finds the largest feasible integer \(h\). Since the real coordinate optimum is integral, this is its exact maximum. Fix that value and continue.

After every current-row coordinate has been fixed, their sum is \(a_t\), because the remaining constraints are feasible. Update

\(b_{tu}\leftarrow b_{tu}+w_u.\)

The updated matrix is integral and has an acceptable completion, establishing the induction invariant for the next phase.

Sequential coordinate maximization is precisely lexicographic maximization: every coordinate is maximized subject to the already optimal values of all preceding coordinates. Thus the computed increment agrees with the rule in the question.

5. Correctness of the final output

Initially, the diagonal matrix with entries \(q_ta_t\) is an acceptable completion of \(b=0\), since every type accepts its own good.

The preceding construction therefore applies inductively to every occurrence in the schedule.

At the end, each type \(t\) has received exactly \(q_ta_t\) scaled units. Let \(F\geq b\) be an acceptable completion guaranteed by the invariant. For every row \(t\),

\(\sum_u(F_{tu}-b_{tu})=q_ta_t-q_ta_t=0.\)

All differences are nonnegative, so they are all zero. Hence \(F=b\): the final matrix itself has the prescribed column totals and is an acceptable circulation.

Returning \(b/D\) therefore gives exactly the requested outcome.

6. Polynomial bit complexity

Each feasibility network has at most \(2\tau+3\) vertices and \(O(\tau^2)\) edges. All capacities are integers at most \(QD\), with binary length

\(O(L+\log(Q+1)).\)

The shortest-augmenting-path maximum-flow algorithm uses \(O(VE^2)\) elementary operations independently of capacity magnitudes. Thus each feasibility test uses \(O(\tau^5)\) operations on integers of the above bit length. [Edmonds and Karp](https://ftp.eecs.umich.edu/~pettie/matching/Edmonds-Karp-network-flow.pdf)

There are at most \(m=\tau\) optimized coordinates per occurrence. Each binary search uses \(O(1+\log(D+1))=O(L+1)\) feasibility tests. Across the explicit schedule, this gives

\(O\!\left(Q\tau^6(L+1)\right)\)

elementary flow operations, in addition to polynomial preprocessing. Accounting for integer arithmetic still gives polynomial bit complexity in \(m,\tau,Q,L\).

Finally, each output entry is \(b_{tu}/D\), with \(0\leq b_{tu}\leq QD\). Thus every entry has polynomial encoding length. Exact reduction of the fractions, if desired, also takes polynomial time.
