The continuous mirror question, as graded

Given rational type masses \(\mu_t>0\) summing to \(1\), rational per-claimant liabilities \(\ell_t>0\), and a per-capita estate \(A\) with \(0<A<L=\sum_t\mu_t\ell_t\), define the worth of coalition mass vector \(z\), where \(0\le z_t\le\mu_t\), by \(V(z)=\max\{0,A-\sum_t(\mu_t-z_t)\ell_t\}\). Compute for every type its continuous Shapley density \(\phi_t=\int_0^1\partial_{z_t}V(x\mu)\,dx\) and total type allocation \(\Psi_t=\mu_t\phi_t\), outputting exact rational values.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\ge 1\) types with positive masses \(\mu_t\), each encoded as a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a binary-rational per-claimant liability \(\ell_t>0\). The binary-rational per-capita estate satisfies \(0<A<D\), where \(D=\sum_t\mu_t\ell_t\).
For coalition masses \(z\in\prod_t[0,\mu_t]\), define \(V(z)=\max\{0,A-\sum_t(\mu_t-z_t)\ell_t\}\).
Define the continuous Shapley density and total allocation by \(\phi_t=\int_0^1\partial_{z_t}V(x\mu)\,dx\) and \(\Psi_t=\mu_t\phi_t\). Interpret the integral using the almost-everywhere derivative; assign arbitrary values at points where it is undefined.
The computational problem is to compute all \(\phi_t\) and \(\Psi_t\) as exact rational values. Let \(L\) be the total binary input bit length; state running times in \(\tau\) and \(L\). There is no independent \(m\) parameter.

Is this exact computation problem solvable in polynomial time in \(\tau\) and \(L\), or is it NP-hard?

For discrete games \(v(S)=f(\sum_{j\in S}a_j)\), all Shapley values admit an \(O(Kn^3\log n)\)-time, \(O(n^2K)\)-space algorithm when integer weights satisfy \(a_j\le 2^n\), \(f\) is evaluable in linear time and space, and coalition values are bounded by \(n^\alpha\) for a fixed \(\alpha>0\), where \(K=\sum_j a_j\); this is pseudo-polynomial ([Illés](https://arxiv.org/html/2205.12324v2)).
Exact discrete bankruptcy Shapley computation is \(\#\mathrm{P}\)-complete and has a pseudo-polynomial algorithm ([Aziz](https://doi.org/10.1016/j.orl.2013.06.004)). No result settling this exact continuous computational problem was located.

Modeling choices made when packaging the task

  • Specified that the estate A is a binary rational, as required for a finite exact-computation input.
  • Interpreted the derivative integral almost everywhere, with arbitrary values at undefined points.
  • Renamed total liability from L to D so that L denotes total input bit length.
  • Used running-time parameters tau and L because this model has no independent m parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is solvable in polynomial time. For every supported type \(t\),

\(\displaystyle \phi_t=\frac{A\ell_t}{D},\qquad \Psi_t=\frac{A\mu_t\ell_t}{D},\qquad D=\sum_{s=1}^{\tau}\mu_s\ell_s.\)

These exact rational values can be computed in \(O(\tau L^2)\) bit operations using elementary integer arithmetic.

Proof of the formulas

Define the affine function

\(\displaystyle H(z)=A-D+\sum_{s=1}^{\tau}z_s\ell_s.\)

Then \(V(z)=\max\{0,H(z)\}\). Along the proportional path \(z=x\mu\),

\(\displaystyle H(x\mu)=A-D+x\sum_{s=1}^{\tau}\mu_s\ell_s=A-D+xD.\)

Because \(0<A<D\), the unique zero occurs at

\(\displaystyle x_*=1-\frac{A}{D}\in(0,1).\)

Fix a type \(t\). For \(x\in(0,1)\), positivity of every \(\mu_s\) ensures that \(x\mu\) lies in the interior of the coalition box.

If \(x<x_*\), then \(H(x\mu)<0\). Continuity of \(H\) gives a neighborhood of \(x\mu\) on which \(V\) is identically zero. Consequently, \(\partial_{z_t}V(x\mu)=0\).

If \(x>x_*\), then \(H(x\mu)>0\). On a neighborhood of \(x\mu\), the function \(V\) equals \(H\), so \(\partial_{z_t}V(x\mu)=\ell_t\).

The point \(x_*\), together with the two endpoints, has measure zero. Assigning arbitrary values there therefore does not change the integral. Thus,

\(\displaystyle \phi_t=\int_{x_*}^{1}\ell_t\,dx=\ell_t(1-x_*)=\frac{A\ell_t}{D}.\)

Multiplying by \(\mu_t\) gives the stated formula for \(\Psi_t\). In particular, the total allocation satisfies

\(\displaystyle \sum_{t=1}^{\tau}\Psi_t=\frac{A}{D}\sum_{t=1}^{\tau}\mu_t\ell_t=A.\)

Exact computation and bit complexity

Write the binary rational inputs as

\(\displaystyle \mu_t=\frac{p_t}{q_t},\qquad \ell_t=\frac{r_t}{s_t},\qquad A=\frac{u}{v},\)

where all numerators and denominators are positive integers encoded in binary. Define

\(\displaystyle Q=\prod_{t=1}^{\tau}q_ts_t,\qquad N=\sum_{t=1}^{\tau}p_tr_t\frac{Q}{q_ts_t}.\)

Every displayed division in the definition of \(N\) is exact, and \(D=N/Q\). Hence an algorithm can output

\(\displaystyle \phi_t=\frac{ur_tQ}{vs_tN},\qquad \Psi_t=\frac{up_tr_tQ}{vq_ts_tN}.\)

We now bound the integer sizes:

  • The bit length of \(Q\) is \(O(L)\), since the sum of the input denominator lengths is at most \(L\).
  • Each summand defining \(N\) has \(O(L)\) bits. Summing \(\tau\) such integers adds at most \(O(\log\tau)\) bits. Since the input explicitly lists all supported types, \(\tau=O(L)\), so \(N\) also has \(O(L)\) bits.
  • Each output numerator and denominator is a product of a constant number of integers of \(O(L)\) bits, and therefore has \(O(L)\) bits.

Constructing \(Q\), constructing \(N\), and producing all output fractions require \(O(\tau)\) integer arithmetic operations. Schoolbook multiplication and division on these integers take \(O(L^2)\) bit operations each. If reduced fractions are required, binary greatest-common-divisor computation and exact division also take \(O(L^2)\) bit operations per fraction.

Therefore the total running time is \(O(\tau L^2)\), with total output length \(O(\tau L)\).

Why the discrete complexity results do not obstruct this computation

Under the specified continuous definition, the derivative is integrated along one proportional path. On that path, \(H(x\mu)\) is affine and crosses zero exactly once. Computing the integral therefore requires only its crossing point and the constant derivative on either side. No enumeration of discrete coalitions or permutations is involved.
