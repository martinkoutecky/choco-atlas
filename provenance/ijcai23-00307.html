The continuous mirror question, as graded

Given two teams, a finite set of complete types \(T\), rational masses \(\lambda_t\ge0\), type preferences \(\succeq_t\), rational nonnegative values satisfying \(v_1(t)=v_2(t)\), and a rational allocation \(x=(x_{it})\) with \(\sum_i x_{it}=\lambda_t\) and \(\left|\sum_t x_{1t}-\sum_t x_{2t}\right|\le1\), decide whether \(x\) is Pareto optimal under divisible type-mass transport: does there exist \(z_{i,j,t}\ge0\) and \(y_{jt}=\sum_i z_{i,j,t}\) such that \(\sum_j z_{i,j,t}=x_{it}\), \(z_{i,j,t}=0\) whenever \(j\not\succeq_t i\), \(V_i(y)\ge V_i(x)\) for both teams, and either \(V_i(y)>V_i(x)\) for some team or positive mass moves along a strict preference \(j\succ_t i\)?

Packaged proof task (what the prover saw — nothing else)

There are \(m=2\) teams. A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\lambda_t\). Here \(\tau\) is the support size, not the number of possible types; masses need not sum to \(1\).
Each complete type specifies a complete, transitive weak preference \(\succeq_t\) over the teams and a binary-rational value \(v(t)\ge0\), identical for both teams. Ties are permitted; \(\succ_t\) denotes strict preference. For an allocation \(a\), define \(V_i(a)=\sum_{t\in T}v(t)a_{it}\).
The input includes a nonnegative binary-rational allocation \(x\) satisfying \(\sum_{i=1}^2x_{it}=\lambda_t\) and \(\left|\sum_t x_{1t}-\sum_t x_{2t}\right|\le1\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A Pareto improvement is a nonnegative real transport \(z_{i,j,t}\) with \(\sum_jz_{i,j,t}=x_{it}\), \(z_{i,j,t}=0\) unless \(j\succeq_t i\), and resulting allocation \(y_{jt}=\sum_i z_{i,j,t}\), such that \(V_i(y)\ge V_i(x)\) for both teams and either some team inequality is strict or \(\sum_{t,i,j:\,j\succ_t i}z_{i,j,t}>0\). The resulting allocation need not be balanced. Call \(x\) Pareto optimal if no such improvement exists.

Is deciding whether an input allocation admits a Pareto improvement in \(\mathrm{P}\) or \(\mathrm{NP}\)-hard, equivalently is testing Pareto optimality in \(\mathrm{P}\) or \(\mathrm{coNP}\)-hard?

For indivisible players, testing Pareto optimality is \(\mathrm{coNP}\)-complete even with two teams, identical nonnegative valuations, and a balanced input allocation; thus deciding improvement existence is \(\mathrm{NP}\)-complete. [Source](https://arxiv.org/pdf/2206.05879).
No result settling exactly the divisible transport problem defined here was identified in the literature search.

  • Required the input allocation to be nonnegative and defined additive team utilities explicitly.
  • Allowed real-valued transport witnesses; input masses, values, and allocations remain binary rationals.

  • Set the team-count parameter to m=2 and defined L as total input bit length.
  • Expressed the NP-hardness alternative for improvement existence, with the equivalent coNP-hardness alternative for Pareto-optimality testing.

Result

Both deciding improvement existence and testing Pareto optimality are in \(\mathrm{P}\). For the promised inputs with \(m=2\), either decision can be made in \(O(L)\) bit time by scanning the \(\tau\) supported types. An improvement, when one exists, needs at most two nonzero off-diagonal transport entries.

The proof applies to arbitrary input allocations satisfying the mass constraints; the balance assumption is unnecessary.

1. Conservation forces both team values to remain unchanged

For any feasible transport \(z\), its resulting allocation satisfies, for every type \(t\),

\(\displaystyle \sum_{j=1}^{2}y_{jt}=\sum_{i=1}^{2}\sum_{j=1}^{2}z_{i,j,t}=\sum_{i=1}^{2}x_{it}=\lambda_t.\)

Because the teams have identical valuations, it follows that

\(\displaystyle V_1(y)+V_2(y)=\sum_{t\in T}v(t)\lambda_t=V_1(x)+V_2(x).\)

Consequently, if both teams weakly gain, neither can strictly gain: necessarily \(V_i(y)=V_i(x)\) for each \(i\in\{1,2\}\). Thus a feasible transport is a Pareto improvement exactly when it preserves both team values and transports a positive amount along strictly preferred moves.

Write

\(\displaystyle A=\sum_{t\in T}v(t)z_{1,2,t},\qquad B=\sum_{t\in T}v(t)z_{2,1,t}.\)

The row constraints give

\(\displaystyle V_1(y)-V_1(x)=B-A,\qquad V_2(y)-V_2(x)=A-B.\)

Hence preservation of both values is equivalent to \(A=B\).

2. Exact characterization

For distinct teams \(i,j\), define

\(\displaystyle P_{ij}=\{t\in T:v(t)>0,\ x_{it}>0,\ j\succeq_t i\},\)

\(\displaystyle S_{ij}=\{t\in T:v(t)>0,\ x_{it}>0,\ j\succ_t i\}.\)

Thus \(P_{ij}\) contains the positive-value types with available mass that may move from \(i\) to \(j\), while \(S_{ij}\) contains those for which that move is strictly preferred.

Let \(Z\) denote the following condition:

\(\displaystyle \exists\,t\in T,\ i\ne j:\quad v(t)=0,\quad x_{it}>0,\quad j\succ_t i.\)

Theorem. The allocation admits a Pareto improvement if and only if at least one of these conditions holds:

  • \(Z\).
  • \(S_{12}\ne\varnothing\) and \(P_{21}\ne\varnothing\).
  • \(S_{21}\ne\varnothing\) and \(P_{12}\ne\varnothing\).

Necessity

Suppose \(z\) is a Pareto improvement. By Section 1, both team values are unchanged. The required strictness therefore implies

\(\displaystyle \sum_{t,i,j:\,j\succ_t i}z_{i,j,t}>0.\)

This is a finite sum of nonnegative terms, so some strictly preferred move satisfies \(z_{i,j,t}>0\). The row constraint implies \(x_{it}\ge z_{i,j,t}>0\).

If \(v(t)=0\), condition \(Z\) holds.

Otherwise, \(v(t)>0\), and therefore \(t\in S_{ij}\). Suppose first that \((i,j)=(1,2)\). Then

\(\displaystyle A\ge v(t)z_{1,2,t}>0.\)

Since \(A=B\), we also have \(B>0\). Nonnegativity of all its summands implies that some type \(u\) satisfies \(v(u)z_{2,1,u}>0\). Hence \(v(u)>0\), \(x_{2u}>0\), and feasibility requires \(1\succeq_u2\). Thus \(u\in P_{21}\), proving condition 2.

For \((i,j)=(2,1)\), the same argument with the teams interchanged proves condition 3.

Sufficiency

If \(Z\) holds, choose a witnessing type \(t\) and direction \(i\) to \(j\). Transfer the entire amount \(x_{it}>0\) to \(j\), leaving every other allocation entry in place. This transport is permitted and strictly preferred. Since \(v(t)=0\), it changes neither team value and is therefore a Pareto improvement.

Now suppose \(S_{ij}\ne\varnothing\) and \(P_{ji}\ne\varnothing\), for distinct teams \(i,j\). Choose \(t\in S_{ij}\) and \(u\in P_{ji}\).

These types are distinct. Indeed, \(j\succ_t i\) excludes \(i\succeq_t j\), so \(t\) cannot also belong to \(P_{ji}\).

Set

\(\displaystyle d=\min\{v(t)x_{it},\,v(u)x_{ju}\}>0,\qquad \alpha=\frac{d}{v(t)},\qquad \beta=\frac{d}{v(u)}.\)

By construction,

\(\displaystyle 0<\alpha\le x_{it},\qquad 0<\beta\le x_{ju}.\)

Starting from the identity transport, make precisely these changes:

  • Set \(z_{i,j,t}=\alpha\) and \(z_{i,i,t}=x_{it}-\alpha\).
  • Set \(z_{j,i,u}=\beta\) and \(z_{j,j,u}=x_{ju}-\beta\).

All other off-diagonal entries remain zero, and all other diagonal entries remain their original masses.

Every entry is nonnegative, and every row sum remains correct. Both moves are permitted by the definitions of \(S_{ij}\) and \(P_{ji}\). Their transferred values are equal:

\(\displaystyle v(t)\alpha=d=v(u)\beta.\)

Thus both team values remain unchanged. The move of type \(t\) is strictly preferred and has mass \(\alpha>0\), so this transport is a Pareto improvement. This proves sufficiency and completes the characterization.

3. Algorithm and bit complexity

Scan the support once, recording five Boolean flags:

  • Whether \(Z\) holds.
  • Whether each of \(P_{12},P_{21},S_{12},S_{21}\) is nonempty.

Return “improvement exists” exactly when the Boolean condition in the theorem holds. Negating that answer tests Pareto optimality.

For each type, the algorithm examines only its preference relation and whether \(v(t)\), \(x_{1t}\), and \(x_{2t}\) are zero or positive. It performs no rational additions, multiplications, or comparisons between positive magnitudes.

In terms of the requested parameters, it uses \(O(m^2\tau)\) elementary tests, which is \(O(\tau)\) because \(m=2\). Reading and testing the explicitly encoded rational numbers takes total \(O(L)\) bit time. Thus the decision running time is \(O(L+m^2\tau)=O(L)\) for these inputs.

The witness construction also has polynomial bit complexity. Products, quotients, and differences of the finitely many selected input rationals have \(O(L)\)-bit numerator and denominator representations. Exact construction takes \(O(L^2)\) bit operations using elementary integer arithmetic. The witness need not be dyadic: the problem permits real transports, and the construction supplies rational ones.

4. Relation to the indivisible hardness result

The cited paper proves the indivisible hardness statement in Theorem 4.1 using a reduction from \(\mathrm{Subset\ Sum}\). Its construction requires an exact equality between the value of one transferred participant and the total value of a transferred subset. [Igarashi et al., Theorem 4.1](https://arxiv.org/pdf/2206.05879).

For the divisible problem, whenever positive-value permitted moves exist in opposite directions and at least one is strictly preferred, the construction above matches their transferred values by choosing suitable fractions. This establishes polynomial-time solvability for exactly the transport model in the question, including ties, zero values, arbitrary positive type masses, and unrestricted balance of the resulting allocation.
