Theorem 5 — class: algorithmic

The continuous mirror question, as graded

Given \(k\) divisible tasks, requester types \(a\) with positive rational masses \(r_a\), linear values \(v_{a\ell}\), and per-person budgets \(B_a\), and worker types \(b\) with positive rational masses \(s_b\), disutilities \(c_{b\ell}>0\), and per-person earning requirements \(E_b\), assume \(\sum_a r_a B_a=\sum_b s_b E_b\). Find prices \(p_\ell>0\) and per-type bundles \(x_a,y_b\geq 0\) such that each requester type maximizes \(\sum_\ell v_{a\ell}x_{a\ell}\) subject to \(\sum_\ell p_\ell x_{a\ell}\leq B_a\), each worker type minimizes \(\sum_\ell c_{b\ell}y_{b\ell}\) subject to \(\sum_\ell p_\ell y_{b\ell}\geq E_b\), and \(r_a\sum_a x_{a\ell}= \sum_b s_b y_{b\ell}\) for every task \(\ell\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types with positive masses encoded as binary rationals; \(\tau\) is the support size, not the number of possible types. Types are partitioned into nonempty requester and worker sets \(A,W\), with masses \(r_a,s_b\); masses need not sum to one.
There are \(m:=k\geq1\) divisible tasks, with no fixed supply or upper bounds on quantities. All numerical input is rational; \(L\) is its total binary encoding length.
Requester type \(a\) has values \(v_{a\ell}\geq0\) and per-person budget \(B_a>0\). Worker type \(b\) has costs \(c_{b\ell}>0\) and per-person earning requirement \(E_b>0\). Every requester values some task positively, and every task is valued positively by some requester.
Assume \(\sum_{a\in A}r_aB_a=\sum_{b\in W}s_bE_b\). An equilibrium consists of prices \(p\in\mathbb R_{>0}^{m}\) and per-person bundles \(x_a,y_b\in\mathbb R_{\geq0}^{m}\).
Each \(x_a\) maximizes \(\sum_\ell v_{a\ell}x_{a\ell}\) subject to \(\sum_\ell p_\ell x_{a\ell}\leq B_a\); each \(y_b\) minimizes \(\sum_\ell c_{b\ell}y_{b\ell}\) subject to \(\sum_\ell p_\ell y_{b\ell}\geq E_b\). Any optimal bundle is permitted when choices tie.
Market clearing requires \(\sum_{a\in A}r_ax_{a\ell}=\sum_{b\in W}s_by_{b\ell}\) for every task \(\ell\). Prices have no imposed normalization.

Can an exact equilibrium for this support-encoded society be computed in time polynomial in \(m,\tau,L\), or is this computation NP-hard?

For a finite list of individual requesters and workers under these conditions, exact competitive equilibrium computation admits a polynomial-time algorithm, including an algorithm using a rounded LP and exact extraction. No separate result for the support-encoded mass formulation is verified here.

Result

An exact equilibrium is computable in time polynomial in \(m,\tau,L\), using the finite-agent polynomial-time algorithm supplied in the question.

The key is an exact reduction to a society with one individual per supported type. Masses are absorbed into budgets and earning requirements.

Constructing the finite society

For each requester type \(a\in A\), create one requester with the same values \(v_{a\ell}\) and budget \(\widehat B_a:=r_aB_a\).

For each worker type \(b\in W\), create one worker with the same costs \(c_{b\ell}\) and earning requirement \(\widehat E_b:=s_bE_b\).

The resulting finite society has exactly \(\tau\) individuals and \(m\) tasks. All transformed budgets and earning requirements are positive rationals. Values, costs, and task divisibility are unchanged, so the positivity and valuation-coverage assumptions hold. Moreover,

\(\displaystyle \sum_{a\in A}\widehat B_a=\sum_{a\in A}r_aB_a=\sum_{b\in W}s_bE_b=\sum_{b\in W}\widehat E_b.\)

Thus the transformed instance satisfies every hypothesis of the finite-agent result stated in the question.

Exact correspondence of equilibria

Fix any price vector \(p\in\mathbb R_{>0}^{m}\). We prove that equilibria correspond through the transformations \(X_a:=r_ax_a\) and \(Y_b:=s_by_b\), with prices unchanged.

Requester optimality

Because \(r_a>0\), multiplication by \(r_a\) is a bijection between the two requester feasible sets:

\(\displaystyle \{x\in\mathbb R_{\geq0}^{m}:p\cdot x\leq B_a\}\longleftrightarrow\{X\in\mathbb R_{\geq0}^{m}:p\cdot X\leq r_aB_a\}.\)

Under this bijection,

\(\displaystyle \sum_{\ell=1}^{m}v_{a\ell}X_\ell=r_a\sum_{\ell=1}^{m}v_{a\ell}x_\ell.\)

Multiplication of an objective by a positive constant preserves all comparisons between feasible objective values. Consequently, \(x_a\) is optimal for the original requester problem if and only if \(X_a=r_ax_a\) is optimal for the transformed requester problem. This equivalence includes every tied optimum.

Worker optimality

Similarly, multiplication by \(s_b>0\) is a bijection

\(\displaystyle \{y\in\mathbb R_{\geq0}^{m}:p\cdot y\geq E_b\}\longleftrightarrow\{Y\in\mathbb R_{\geq0}^{m}:p\cdot Y\geq s_bE_b\}.\)

The objective satisfies

\(\displaystyle \sum_{\ell=1}^{m}c_{b\ell}Y_\ell=s_b\sum_{\ell=1}^{m}c_{b\ell}y_\ell.\)

Since the multiplier is positive, \(y_b\) minimizes the original worker objective if and only if \(Y_b=s_by_b\) minimizes the transformed objective, again including ties.

Market clearing

For each task \(\ell\), the original clearing equation is equivalent to the finite society’s clearing equation:

\(\displaystyle \sum_{a\in A}r_ax_{a\ell}=\sum_{b\in W}s_by_{b\ell}\quad\Longleftrightarrow\quad\sum_{a\in A}X_{a\ell}=\sum_{b\in W}Y_{b\ell}.\)

Therefore the transformations give a bijection between the two sets of equilibria. In particular, from any equilibrium \((p,X,Y)\) of the finite society, recover an equilibrium of the support-encoded society by setting \(x_a:=X_a/r_a\) and \(y_b:=Y_b/s_b\).

Prices remain strictly positive, and neither transformation introduces a price normalization.

Algorithm and bit complexity

The algorithm is:

  • Construct the finite society above.
  • Run the exact polynomial-time finite-agent algorithm given in the question.
  • Divide each resulting requester bundle by its requester mass and each worker bundle by its worker mass.

To check the encoding bound, write a mass and budget as \(r_a=u/v\) and \(B_a=w/z\), using positive binary integers. Their product can be represented exactly as \(\widehat B_a=uw/(vz)\). The binary lengths of the product numerator and denominator are at most the sums of the corresponding factor lengths. The same argument applies to each \(\widehat E_b\). Thus constructing the transformed instance takes polynomial time, and its encoding length is polynomial in the original length \(L\). There is no expansion into a number of individuals proportional to the numerical masses.

The invoked finite-agent algorithm therefore runs in time polynomial in \(m,\tau,L\). Its explicitly encoded exact output has polynomial length. Dividing its bundle coordinates by positive input rationals requires polynomial-time rational arithmetic and increases their encoding lengths by at most the lengths of the relevant masses, up to constant overhead. There are \(m\tau\) bundle coordinates.

This proves the claimed polynomial-time bound for the complete computation, including exact recovery of per-person bundles.
