Result

The specified atomless optimization problem is polynomial-time solvable. An optimal distribution has at most two rational atoms, and its exact value is

\(V^*(\lambda,q)=\min\left\{1,\lambda+\frac{\lambda}{q}\right\}.\)

This result concerns precisely the stated model, with \(m=2\), \(\tau=1\), and receivers observing only their own recommendations.

1. Obedience constraints

For a Borel probability measure \(\rho\) on \([0,1]\), define its mean by

\(\mu=\int_{[0,1]}\alpha\,d\rho(\alpha).\)

Each receiver receives recommendation \(x\) with probability \(1\) conditional on state \(X\), and with probability \(\mu\) conditional on state \(Y\). Because \(\lambda>0\), recommendation \(x\) has positive unconditional probability. Bayes’ rule gives

\(\Pr(X\mid x)=\frac{\lambda}{\lambda+(1-\lambda)\mu}.\)

Thus a receiver sincerely follows recommendation \(x\) exactly when

\(\frac{\lambda}{\lambda+(1-\lambda)\mu}\ge\frac12 \quad\Longleftrightarrow\quad \mu\le\frac{\lambda}{1-\lambda}.\)

Equality is permitted by the specified tie-breaking rule.

Recommendation \(y\) never occurs in state \(X\). Whenever it has positive probability, its posterior probability of \(X\) is therefore \(0\), so it is strictly followed. If its probability is zero, no obedience condition is required for it.

Consequently, the stated mean constraint is both necessary and sufficient for obedience. Under obedience, the vote mass for \(x\) in state \(Y\) is exactly \(\alpha\).

2. Upper bound for every Borel distribution

Set \(r=\lambda/(1-\lambda)\), and write \(p=\rho([q,1])\). Since \(\alpha\) is nonnegative everywhere and at least \(q\) on \([q,1]\),

\(\mu=\int_{[0,1]}\alpha\,d\rho(\alpha) \ge\int_{[q,1]}\alpha\,d\rho(\alpha) \ge q\,\rho([q,1])=qp.\)

Feasibility implies \(\mu\le r\). Since also \(p\le1\), every feasible distribution satisfies

\(p\le\min\left\{1,\frac rq\right\}.\)

The sender’s objective is increasing in \(p\), because \(1-\lambda>0\). Hence its value is bounded above by

\(\lambda+(1-\lambda)\min\left\{1,\frac rq\right\} =\min\left\{1,\lambda+\frac{\lambda}{q}\right\}.\)

This argument applies to arbitrary Borel probability measures, without any assumption of finite support.

3. An optimal distribution attaining the bound

Let \(\delta_t\) denote the probability measure concentrated at \(t\). Define

\(p^*=\min\left\{1,\frac{\lambda}{(1-\lambda)q}\right\}, \qquad \rho^*=(1-p^*)\delta_0+p^*\delta_q.\)

Both atom locations belong to \([0,1]\), and both probabilities are nonnegative and sum to \(1\). Its mean is

\(\int_{[0,1]}\alpha\,d\rho^*(\alpha)=p^*q=\min\{q,r\}\le r.\)

Thus \(\rho^*\) is feasible, and Section 1 establishes obedience.

Because \(q>0\), the atom at \(0\) is losing. Because the implementation threshold is inclusive, the atom at \(q\) is winning. Therefore

\(\rho^*([q,1])=p^*.\)

The resulting objective equals the upper bound from Section 2, proving optimality.

Explicitly:

  • If \(\lambda<q/(1+q)\), then \(p^*=\lambda/((1-\lambda)q)\), the mean constraint binds, and \(V^*=\lambda+\lambda/q\).
  • If \(\lambda\ge q/(1+q)\), then \(\rho^*=\delta_q\) and \(V^*=1\).

At the boundary, obedience can hold with posterior exactly \(1/2\); the stipulated tie-breaking rule ensures attainment.

4. Exact algorithm and bit complexity

Write the rational inputs as \(\lambda=a/b\) and \(q=c/d\), where \(0<a<b\) and \(0<c\le d\). These integers have total bit length \(O(L)\).

Compare the integers \(ad\) and \(c(b-a)\).

  • If \(ad\ge c(b-a)\), output \(\rho^*=\delta_{c/d}\) and \(V^*=1\).
  • Otherwise, output atom locations \(0,c/d\), with respective probabilities

\(\frac{c(b-a)-ad}{c(b-a)} \quad\text{and}\quad \frac{ad}{c(b-a)},\)

and exact value

\(V^*=\frac{a(c+d)}{bc}.\)

All output numerators and denominators have \(O(L)\) bits. The algorithm uses a constant number of integer additions, subtractions, multiplications, and comparisons. Ordinary binary arithmetic therefore gives running time \(O(L^2)\) bit operations and output length \(O(L)\). Fractions may be output without reduction.

Since \(m=2\) and \(\tau=1\) throughout this problem, this is polynomial time in \(m,\tau,L\). No discretization or approximation of the measure space is needed.

The construction follows the minimal-winning-coalition/empty-coalition pattern described for finite sincere voters by [Kerman, Herings, and Karos](https://onlinelibrary.wiley.com/doi/full/10.1111/jpet.12671). The proof above independently establishes exact optimality in the stated atomless model.
