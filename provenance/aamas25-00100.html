The continuous mirror question, as graded

Given rational masses \(r,b,a\ge 0\) with \(r+b+a=1\), define the asynchronous complete-mixing pull process on every finite lift satisfying \(Nr,Nb,Na\in\mathbb{Z}\). Compute the common probability \(p_R(\mu)\) that the lift reaches red consensus; when \(r+b>0\), \(p_R(\mu)=\frac{r}{r+b}\), while \(r+b=0\) yields no consensus.

Packaged proof task (what the prover saw — nothing else)

A society \(\mu\) is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. The types are red, blue, and agnostic, with masses \(r,b,a\geq 0\) satisfying \(r+b+a=1\); omitted types have mass zero. Here \(m=2\) is the number of opinion colours, \(\tau\leq 3\) is the support size, and \(L\) is the total input bit length.
For every positive integer \(N\) with \(Nr,Nb,Na\in\mathbb Z\), a finite lift has these numbers of nodes in the three initial states. For \(N\geq 2\), each step independently chooses a node uniformly and then a different node uniformly; the first copies the second's state if it is red or blue, and otherwise remains unchanged. A single-node lift remains unchanged.
Red consensus means that every node is red, including consensus already present initially. Let \(p_R(\mu)\) denote the common probability of eventually reaching red consensus across all finite lifts; an all-agnostic lift never reaches an opinion consensus and has red-consensus probability zero. The computational output is an exact binary rational.

Is exact computation of \(p_R(\mu)\) polynomial-time in \(m,\tau,L\), or is it NP-hard?

The discrete complete-graph result gives red-consensus probability equal to the initial fraction of red nodes among non-agnostic nodes. [Verified extended version](https://arxiv.org/html/2502.15029v1#S3.SS1) establishes this for every finite lift with a non-agnostic node, so it already determines the lift-defined quantity as \(r/(r+b)\) when \(r+b>0\). Result

Exact computation is polynomial-time solvable. If \(r+b=0\), then \(p_R(\mu)=0\); otherwise,
\(p_R(\mu)=r/(r+b)\).

This agrees with [Corollary 3.3 of the cited extended version](https://arxiv.org/html/2502.15029v1#S3.SS1), which treats the asynchronous complete-graph process. Below is a self-contained proof, including the boundary cases and bit complexity.

An exact rational output is understood as a numerator and positive denominator written in binary.

1. Consensus occurs almost surely when an opinion is present

Fix an admissible lift with \(N\geq 2\), initially containing at least one non-agnostic node. A non-agnostic node never becomes agnostic, so an opinion remains present at every time.

From any current configuration, choose a non-agnostic node \(j\). Consider the next \(N-1\) steps in which every other node, in a fixed order, copies \(j\). Node \(j\) is never updated during this sequence, so its colour remains fixed. At the end, every node has its colour.

Every specified ordered pair has probability \(1/[N(N-1)]\). Independence therefore gives this sequence probability
\(\varepsilon_N=[N(N-1)]^{-(N-1)}>0\).

Let \(T\) be the first time of red or blue consensus, including time zero. Conditional on any history without consensus, the probability of reaching consensus within the next \(N-1\) steps is at least \(\varepsilon_N\). Iterating this bound gives
\(\mathbb P(T>k(N-1))\leq(1-\varepsilon_N)^k\)
for every nonnegative integer \(k\). The right-hand side tends to zero. Thus \(T\) is finite almost surely.

2. The fraction of red nodes among opinionated nodes is a martingale

Let \(R_t,B_t,A_t\) be the three node counts after \(t\) steps, and put \(C_t=R_t+B_t\). Because an opinion is initially present and cannot disappear into the agnostic state, \(C_t\geq 1\). Define
\(X_t=R_t/C_t\).

Condition on the complete history through time \(t\), and abbreviate the current counts by \(R,B,A,C\). Write \(D=N(N-1)\). The only events that change \(X_t\) are:

| Update | Conditional probability | Change in \(X_t\) |
|---|---:|---:|
| Blue copies red | \(BR/D\) | \(1/C\) |
| Red copies blue | \(RB/D\) | \(-1/C\) |
| Agnostic copies red | \(AR/D\) | \(B/[C(C+1)]\) |
| Agnostic copies blue | \(AB/D\) | \(-R/[C(C+1)]\) |

For example, when an agnostic node becomes red, the change is
\((R+1)/(C+1)-R/C=(C-R)/[C(C+1)]=B/[C(C+1)]\).
When it becomes blue, the change is
\(R/(C+1)-R/C=-R/[C(C+1)]\).

Each probability follows by counting the eligible ordered pairs. Events whose probability is zero contribute nothing. Every remaining event leaves \(X_t\) unchanged. Consequently, the conditional expected increment is
\((BR-RB)/(DC)+(ARB-ABR)/[DC(C+1)]=0\).

Thus \(X_t\) is a martingale. It is bounded between zero and one, so
\(\mathbb E[X_t]=X_0\) for every \(t\).

By Section 1, consensus occurs almost surely. Consensus is absorbing, and \(X_t\) thereafter equals one at red consensus and zero at blue consensus. Hence \(X_t\) converges almost surely to the indicator of eventual red consensus. Since \(|X_t|\leq 1\), dominated convergence applies and yields
\(\mathbb P(\text{eventual red consensus})=\lim_{t\to\infty}\mathbb E[X_t]=X_0\).

3. The probability is independent of the lift

For every admissible lift with \(r+b>0\) and \(N\geq 2\), the preceding proof gives
\(X_0=Nr/(Nr+Nb)=r/(r+b)\).

For an admissible single-node lift, integrality and the total mass condition force that node to be initially red, blue, or agnostic. Its unchanged state gives the stated probability in each case.

If \(r+b=0\), every lift is all agnostic and remains so. Its red-consensus probability is zero.

Admissible lifts exist because the masses are rational: any positive common multiple of their denominators is admissible. Therefore the common lift-defined quantity exists and has the claimed formula.

4. Exact computation and bit complexity

Treat an omitted red or blue mass as \(0/1\). Write
\(r=u/v\) and \(b=w/z\), with nonnegative integer numerators and positive integer denominators.

Compute \(U=uz\) and \(V=wv\). If \(U+V=0\), output \(0/1\). Otherwise output
\(U/(U+V)\), optionally reducing it by \(\gcd(U,U+V)\).

This is correct because
\(r/(r+b)=uz/(uz+wv)\).

All intermediate integers have \(O(L)\) bits. Elementary multiplication and addition take polynomial time, and the Euclidean algorithm with elementary division gives a conservative \(O(L^3)\) bound for reduction. Reading the support also takes polynomial time. Thus computation is polynomial-time in \(m,\tau,L\), with \(m=2\) and \(\tau\leq 3\); no finite lift needs to be constructed or simulated.

If “binary rational” instead requires a finite binary expansion, that output convention is insufficient: the dyadic input \(r=1/4,b=1/2,a=1/4\) has output \(1/3\). Binary numerator–denominator encoding represents the exact answer.
