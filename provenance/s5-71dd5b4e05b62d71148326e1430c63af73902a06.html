The continuous mirror question, as graded

Given projects \(A\) with positive integer costs \(c(a)\), budget \(L\), a nonincreasing worth vector \(\alpha\) with \(\alpha(1)=L\), and a distribution \(\mu\) over \(\tau\) supported complete weak-ranking types with binary-rational masses, define \(B_t=\{a\in A:c(a)\leq\alpha(r_t(a))\}\). Find a feasible whole-project slate \(S\subseteq A\), with \(c(S)\leq L\), maximizing \(\sum_t\mu_t c(B_t\cap S)\).

A society is given by its support: the list of \(\tau\) complete weak-ranking types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type is an ordered partition \(E^t_1\succ\cdots\succ E^t_{k_t}\) into nonempty indifference classes; \(r_t(a)=j\) when \(a\in E^t_j\). Define \(B_t=\{a\in A:c(a)\leq\alpha(r_t(a))\}\) and \(c(X)=\sum_{a\in X}c(a)\).
The problem is to find a whole-project slate \(S\subseteq A\) with \(c(S)\leq B\) maximizing \(\sum_t\mu_t c(B_t\cap S)\). Any maximizing slate is acceptable. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\), and \(B\).

Is computing an optimal slate for this mass-based problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For a finite list of agents, this cost-worthy optimization is \(\mathrm{NP}\)-hard when \(\alpha(1)=B\), and a pseudopolynomial algorithm with running time \(O(m^2n\alpha(1))\) is known, where \(n\) is the number of agents ([source](https://arxiv.org/pdf/2207.07981v1)).

Result

Computing an optimal slate is \(\mathrm{NP}\)-hard, even when \(\tau=1\) and the unique type has mass \(1\). For arbitrary rational masses, an exact pseudopolynomial algorithm runs in

\(O\!\left((m+\tau)L^2+m\tau L+m(B+1)L\right)\)

bit operations. Thus the binary encoding of \(B\) prevents this bound from establishing polynomial-time solvability.

1. Hardness with a single type

Reduce from positive-integer Subset Sum, which is \(\mathrm{NP}\)-complete. Given positive integers \(x_1,\ldots,x_m\) and target \(T\geq1\), construct:

  • Projects \(a_1,\ldots,a_m\), with \(c(a_i)=x_i\).
  • Budget \(B=T\) and worth vector \(\alpha=(T,0,\ldots,0)\).
  • One type, of mass \(\mu_1=1\), whose sole indifference class is \(E^1_1=A\).

Every input requirement holds. In particular, the ranking is complete and \(\alpha\) is nonincreasing with \(\alpha(1)=B\). The construction has polynomial encoded size.

Here \(B_1=\{a_i:x_i\leq T\}\). Every feasible slate lies in \(B_1\), because costs are positive. Consequently, its objective is exactly

\(\mu_1c(B_1\cap S)=c(S)\).

The optimal value equals \(T\) if and only if the Subset Sum instance has a solution. Any returned maximizing slate decides this by checking its cost, regardless of ties. Hence computing an optimal slate is \(\mathrm{NP}\)-hard.

This is the single-agent reduction underlying Theorem 4 of the [cited paper](https://arxiv.org/pdf/2207.07981v1), applied directly to mass \(1\). Hardness also holds with a strict ranking: choose \(\alpha=(B,\ldots,B)\), so every affordable project is approved at every rank.

2. Exact treatment of rational masses

Write \(\mu_t=p_t/d_t\), with positive integers \(p_t,d_t\) encoded in binary. Define

\(Q=\prod_{t=1}^{\tau}d_t,\qquad w_t=p_t(Q/d_t).\)

Each \(w_t\) is a positive integer. The normalization assumption gives

\(\sum_{t=1}^{\tau}w_t=Q\sum_{t=1}^{\tau}\mu_t=Q.\)

For every project, define its integer profit

\(v(a)=c(a)\sum_{t:a\in B_t}w_t.\)

Expanding the finite sums proves, for every slate \(S\),

\(Q\sum_{t=1}^{\tau}\mu_t c(B_t\cap S)=\sum_{a\in S}v(a).\)

Since \(Q>0\), the maximizing slates are unchanged. Thus the problem becomes an exact whole-item knapsack problem with weight \(c(a)\) and profit \(v(a)\).

Crucially, denominator clearing requires only polynomial bit length:

\(\log_2 Q=\sum_{t=1}^{\tau}\log_2 d_t\leq L.\)

Discard projects costing more than \(B\), since none can belong to a feasible slate. Every remaining profit satisfies \(0\leq v(a)\leq BQ\). Moreover, every feasible slate satisfies

\(\sum_{a\in S}v(a)\leq Qc(S)\leq QB.\)

Because \(\log_2 B\leq L\), all these integers have \(O(L)\) bits. No expansion into individual agents is needed.

3. Dynamic program and running time

Enumerate the remaining projects as \(a_1,\ldots,a_q\), where \(q\leq m\), and put \(c_i=c(a_i)\), \(v_i=v(a_i)\).

For integers \(0\leq i\leq q\) and \(0\leq b\leq B\), let \(D_i(b)\) be the maximum integer profit of a subset of the first \(i\) projects costing at most \(b\). Initialize \(D_0(b)=0\).

If \(c_i>b\), set \(D_i(b)=D_{i-1}(b)\). Otherwise, set

\(D_i(b)=\max\{D_{i-1}(b),\,D_{i-1}(b-c_i)+v_i\}.\)

To justify the recurrence, partition feasible subsets according to whether they contain \(a_i\). A subset omitting it has profit at most \(D_{i-1}(b)\). Removing it from a subset containing it leaves a subset costing at most \(b-c_i\), with profit at most \(D_{i-1}(b-c_i)\). Conversely, an optimal subset for either preceding state realizes the corresponding candidate. Induction therefore proves every table entry correct.

Store a maximizing choice at each entry. Backtracking from \(D_q(B)\) returns an optimal whole-project slate; either choice is valid when candidates tie.

The bit-operation bounds are:

  • Compute \(Q\) and all \(w_t\) using schoolbook multiplication and division: \(O(\tau L^2)\).
  • Determine approval memberships and accumulate supporting weights: \(O(m\tau L)\).
  • Compute all profits: \(O(mL^2)\).
  • Fill the table: \(O(m(B+1)L)\), since each entry uses arithmetic and comparison on \(O(L)\)-bit integers.

Including parsing and reconstruction, this yields

\(O\!\left((m+\tau)L^2+m\tau L+m(B+1)L\right).\)

The dependence is on the listed support size \(\tau\). The algorithm is polynomial whenever \(B\) is polynomially bounded in \(L\), but is pseudopolynomial for unrestricted binary-encoded budgets.

4. Decision complexity

For completeness, consider the decision version with an additional binary-rational threshold \(K=u/v\), where \(v>0\). A certificate is a slate \(S\).

Its feasibility is checked by summing its costs. Its objective reaches the threshold exactly when

\(v\sum_{a\in S}v(a)\geq uQ.\)

The integers involved have polynomial bit length in the instance and threshold encodings, so verification takes polynomial time. The decision problem belongs to \(\mathrm{NP}\); the reduction in Section 1 proves it \(\mathrm{NP}\)-complete.

Therefore the rational-mass formulation is \(\mathrm{NP}\)-hard, with an exact pseudopolynomial algorithm, and is polynomial-time solvable only if \(\mathrm{P}=\mathrm{NP}\).
