The continuous mirror question, as graded

Given \(g\) divisible goods with market values \(m_a>0\), DPR parameters \(K>1\) and \(q\), and a finite support \(T\) of claimant types \(t=(r_{t1},\ldots,r_{tg},ω_t)\) with rational masses \(μ_t>0\), \(∑_tμ_t=1\), and \(∑_tμ_tω_t=1\), set \(\hat u_{ta}=K^{r_{ta}-q-1}m_a\). Choose \(y_{ta}≥0\), the aggregate fraction of good \(a\) allocated to type \(t\), subject to \(∑_t y_{ta}=1\) for each good. Return a feasible allocation maximizing \(\min_{t∈T}\frac{\sum_a\hat u_{ta}y_{ta}}{\mu_t\omega_t\sum_a\hat u_{ta}}\). In a finite realization with \(Nμ_t\) claimants of type \(t\), each receives \(y_{ta}/(Nμ_t)\) of good \(a\), recovering the paper’s normalized egalitarian objective.

Packaged proof task (what the prover saw — nothing else)

There are \(g\geq1\) divisible goods, one unit each, with positive rational market values \(m_a\), a rational \(K>1\), and a positive integer \(q\) encoded in unary.

Type \(t=(r_{t1},\ldots,r_{tg},\omega_t)\) has integer ratings \(r_{ta}\in\{1,\ldots,2q+1\}\) and positive rational entitlement density \(\omega_t\), with \(\sum_t\mu_t=\sum_t\mu_t\omega_t=1\). All rational inputs use binary encoding; \(L\) is the total input bit length.
Utilities are additive and linear, with \(\hat u_{ta}=K^{r_{ta}-q-1}m_a\). An allocation specifies aggregate fractions \(y_{ta}\geq0\) satisfying \(\sum_t y_{ta}=1\) for every good.
Compute an exact allocation maximizing \(\min_{t\in T}\frac{\sum_a\hat u_{ta}y_{ta}}{\mu_t\omega_t\sum_a\hat u_{ta}}\); any maximizer is acceptable.
For a finite realization with \(N\mu_t\) claimants of type \(t\), each has entitlement \(\omega_t/N\) and receives \(y_{ta}/(N\mu_t)\) of good \(a\).

Is this optimization problem solvable in polynomial time in \(g,\tau,q,L\), or is it NP-hard?

For finitely many claimants, an optimal basic egalitarian allocation splits at most \(n-1\) goods, where \(n\) is the number of claimants; the finite allocation problem has a linear programming formulation. [Source](https://arxiv.org/pdf/1910.01615v4).
No result explicitly addressing this support-encoded mass formulation was identified in the literature search.

Result

The problem is solvable exactly in polynomial time in \(g,\tau,q,L\). The proof uses a rational linear program whose size depends on the explicitly listed support, without expanding the masses into individual claimants.

1. An exact linear programming formulation

For every supported type \(t\), define
\(d_t=\mu_t\omega_t\), \(U_t=\sum_{a=1}^{g}\hat u_{ta}\), and \(b_t=d_tU_t\).
The hypotheses imply \(d_t>0\), \(U_t>0\), and \(\sum_{t\in T}d_t=1\).

Introduce a variable \(z\) representing the minimum normalized utility. Consider the following linear program:

  • Maximize \(z\).
  • Require \(\sum_{t\in T}y_{ta}=1\) for every good \(a\).
  • Require \(\sum_{a=1}^{g}\hat u_{ta}y_{ta}\geq b_tz\) for every type \(t\).
  • Require \(y_{ta}\geq0\) and \(z\geq0\).

This program has \(g\tau+1\) variables.

For any feasible allocation \(y\), let
\(F(y)=\min_{t\in T}\frac{\sum_a\hat u_{ta}y_{ta}}{d_tU_t}\).
Because every denominator is positive, the utility constraints are equivalent to \(z\leq F(y)\). Moreover, \(F(y)\geq0\), so \((y,F(y))\) is feasible. Consequently, maximizing \(z\) in the linear program is exactly equivalent to the requested optimization.

Feasibility and boundedness. Set \(y_{ta}=d_t\) for every \(t,a\). Since \(\sum_td_t=1\), this is a feasible allocation, and every type has normalized utility
\(\frac{d_tU_t}{d_tU_t}=1\).
Thus \(z=1\) is feasible.

For any feasible solution, the allocation constraints imply \(0\leq y_{ta}\leq1\). Therefore
\(b_tz\leq\sum_a\hat u_{ta}y_{ta}\leq U_t\),
and hence \(z\leq1/d_t\) for every \(t\). Some type satisfies \(d_t\geq1/\tau\), because the positive numbers \(d_t\) sum to one. Thus \(z\leq\tau\).

The feasible region is therefore nonempty, closed, and bounded. Its maximum is attained, and its optimal value satisfies \(1\leq z^*\leq\tau\).

2. The coefficients have polynomial encoding length

A polynomial number of LP variables and constraints is insufficient by itself: we must also bound the binary lengths of the coefficients.

Write \(K=p/h\), where \(p,h\) are positive integers. Their bit lengths are at most \(L\). For every \(t,a\), the exponent
\(e_{ta}=r_{ta}-q-1\)
satisfies \(-q\leq e_{ta}\leq q\).

If \(e_{ta}\geq0\), then \(K^{e_{ta}}=p^{e_{ta}}/h^{e_{ta}}\); otherwise,
\(K^{e_{ta}}=h^{-e_{ta}}/p^{-e_{ta}}\).
In either case, its numerator and denominator have \(O((q+1)L)\) bits. Multiplication by \(m_a\) preserves this bound up to a constant factor. Hence every utility coefficient \(\hat u_{ta}\) has bit length at most
\(C=O((q+1)L)\).

These coefficients can be computed exactly in polynomial time: repeated multiplication requires at most \(q\) multiplications per power, and all intermediate integers have polynomial bit length.

To bound \(U_t\), write each utility as
\(\hat u_{ta}=\alpha_{ta}/\beta_{ta}\), with numerator and denominator having at most \(C\) bits. A common denominator is
\(D_t=\prod_{a=1}^{g}\beta_{ta}\).
It has \(O(gC)\) bits. With this denominator, the numerator of \(U_t\) is
\(\sum_{a=1}^{g}\alpha_{ta}\prod_{j\neq a}\beta_{tj}\),
which has \(O(gC+\log g)\) bits. Reduction to lowest terms can only decrease these lengths.

Finally, \(d_t=\mu_t\omega_t\) has \(O(L)\) bits, so \(b_t=d_tU_t\) has
\(O(g(q+1)L+\log g)\) bits. All these rational operations take polynomial time.

Thus the entire linear program has encoding length polynomial in \(g,\tau,q,L\), even if represented as a dense matrix. The unary encoding of \(q\) ensures that this construction is polynomial in the original input length.

3. Exact optimization and output size

We apply the standard polynomial-time theorem for rational linear programming: given explicitly encoded rational constraints and a rational linear objective, one can compute an exact rational optimizer of a nonempty bounded feasible region in time polynomial in the total encoding length. The ellipsoid method provides this guarantee, including an optimal vertex; see [Yang Cai’s thesis, Theorem 1](https://www.cs.yale.edu/homes/cai/publication/thesis/thesis.pdf#page=38).

All hypotheses have been checked: our coefficients are rational and computable in polynomial time, the full constraint list has polynomial size, and the feasible region is nonempty and bounded. Applying the theorem and returning the allocation coordinates of its optimizer therefore solves the task exactly.

There is also no hidden exponential output requirement. To see this directly, put \(D=g\tau+1\), and let \(B\) bound the bit length of any LP coefficient. At a vertex, there are \(D\) linearly independent active constraints determining the coordinates. Indeed, if the active constraint normals did not span the ambient space, a nonzero orthogonal direction would permit sufficiently small feasible perturbations in both directions, contradicting extremality.

Clearing denominators separately in these constraints gives an integer linear system with entries of \(H=O(DB)\) bits. By Cramer’s rule, each coordinate is a ratio of determinants. Hadamard’s inequality bounds the absolute values of the numerator and denominator determinants by
\(D^{D/2}2^{DH}\).
Their bit lengths are therefore \(O(DH+D\log D)\), which is polynomial. An exact optimal allocation consequently has polynomial total output length.

4. Why aggregation preserves finite realizations

Let \(N\) be any integer such that \(n_t=N\mu_t\) is an integer for every \(t\). Such an \(N\) exists because all masses are rational.

Given an aggregate allocation \(y\), assign each of the \(n_t\) claimants of type \(t\) the fractions
\(x_{tia}=y_{ta}/n_t\).
Their normalized utility is exactly
\(\frac{\sum_a\hat u_{ta}x_{tia}}{(\omega_t/N)U_t} =\frac{\sum_a\hat u_{ta}y_{ta}}{\mu_t\omega_tU_t}\).
Thus the prescribed equal division within each type realizes the aggregate objective.

Conversely, suppose an arbitrary finite allocation gives every claimant normalized utility at least \(\rho\). Aggregate it by setting
\(y_{ta}=\sum_{i=1}^{n_t}x_{tia}\).
Summing the utility inequalities over claimants of type \(t\) yields
\(\sum_a\hat u_{ta}y_{ta}\geq n_t\rho(\omega_t/N)U_t =\rho\mu_t\omega_tU_t\).
The aggregate allocation therefore achieves objective at least \(\rho\).

These two directions prove equality of the finite and aggregate optimal values. The algorithm above computes their common optimum using only the support-sized formulation.
