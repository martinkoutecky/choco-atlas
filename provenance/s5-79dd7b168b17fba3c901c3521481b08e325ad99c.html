Proposition 1 — class: algorithmic

The continuous mirror question, as graded

Given a finite-support distribution μ over positive rational valuation vectors \(v\in\mathbb{Q}_{>0}^k\), represented by τ supported vectors and positive binary-rational masses summing to 1, return every supported \(v\) for which there is no other supported \(w\) with \(w\succ v\). The output may include each maximal type’s mass μ_v.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(S\) of \(\tau\) distinct types \(v\in\mathbb{Q}_{>0}^{k}\), each with a positive binary-rational mass \(\mu_v\), with \(\sum_{v\in S}\mu_v=1\). Here \(\tau\) is the support size, not the number of possible types.
The dimension \(k\geq1\) is a fixed constant; set \(m=k\). Let \(L\) be the total binary encoding length of the input.
Write \(w\succ v\) when \(w^j\geq v^j\) for every coordinate \(j\), with strict inequality in at least one coordinate. Coordinate ties are allowed.
Return every \(v\in S\) for which no \(w\in S\) satisfies \(w\succ v\), optionally together with its mass \(\mu_v\).

Is this enumeration problem solvable in polynomial time, or is it NP-hard, for fixed \(k\)? Express running times in \(m\), \(\tau\), and \(L\).

For finite sets of \(n\) vectors, the known discrete algorithm computes all nondominated vectors in \(O(n\log n)\) time for \(k=2,3\), and \(O(n(\log n)^{k-2})\) time for fixed \(k\geq4\), in the coordinate-comparison model.

Modeling choices made when packaging the task

  • The graded question did not specify whether the dimension varies; retain the supplied discrete setting's fixed positive integer dimension k and identify m with k.
  • Define L as the total binary encoding length of the support vectors, masses, and dimension.
  • Resolve the undefined dominance symbol using coordinatewise weak inequality with at least one strict inequality; allow coordinate ties.

Conclusion

The problem is polynomial-time solvable for every fixed \(k=m\). In fact, a direct algorithm is polynomial even when \(m\) is part of the input. The masses do not affect which types are nondominated.

A complete direct algorithm

For each \(v\in S\), inspect every \(w\in S\setminus\{v\}\). Declare \(v\) dominated exactly when some inspected \(w\) satisfies both:

  • \(w^j\geq v^j\) for every \(j\in\{1,\ldots,m\}\);
  • \(w^j>v^j\) for at least one such \(j\).

Output \(v\) if no inspection declares it dominated, copying \(\mu_v\) if requested.

If the algorithm discards \(v\), its successful inspection supplies a witness \(w\succ v\). Conversely, if \(v\) is dominated, its dominator belongs to the explicitly listed support and is inspected. Thus the output is exactly the required set, including when coordinates tie.

There are at most \(m\tau(\tau-1)\) coordinate comparisons, so the coordinate-comparison running time is \(O(m\tau^2)\).

For bit complexity, write two input coordinates as \(a/b\) and \(c/d\), with positive denominators. Their comparison is equivalent to comparing the integers \(ad\) and \(bc\). Each input integer has at most \(L\) bits; schoolbook multiplication therefore performs each rational comparison in \(O(L^2)\) bit operations. Including reading the input and writing the output gives the valid bound

\(T_{\mathrm{bit}}=O(L+m\tau^2L^2).\)

This already proves polynomial-time solvability.

Using the supplied faster bounds, with ties handled explicitly

For \(m=1\), retain the type with largest coordinate. Because the types are distinct, that maximum is unique. This takes \(O(\tau)\) comparisons.

For larger dimensions, the supplied discrete algorithms give faster bounds. The following preprocessing establishes that coordinate ties cause no difficulty even if an implementation requires distinct values in each coordinate.

Order the vectors increasingly in lexicographic order, and let \(i(v)\in\{1,\ldots,\tau\}\) be the position of \(v\). For each coordinate \(j\), sort the vectors by the pair \((v^j,i(v))\), and let \(r_j(v)\) be the position in that order. Replace \(v\) by

\(r(v)=(r_1(v),\ldots,r_m(v)).\)

Each transformed coordinate has distinct values. Moreover, for distinct \(v,w\),

\(w\succ v\quad\Longleftrightarrow\quad r_j(w)>r_j(v)\text{ for every }j.\)

To prove the forward implication, suppose \(w\succ v\). At the first coordinate where they differ, \(w\) has the larger value, so \(i(w)>i(v)\). In any coordinate where \(w^j>v^j\), its sorting pair is larger because of the first component. Where \(w^j=v^j\), its sorting pair is larger because \(i(w)>i(v)\). Hence every transformed coordinate is larger.

For the reverse implication, \(r_j(w)>r_j(v)\) rules out \(w^j<v^j\), by the primary sorting key. Consequently \(w^j\geq v^j\) in every coordinate. Since the original vectors are distinct, at least one inequality is strict. Thus \(w\succ v\).

The transformation therefore preserves exactly the nondominated vectors. Lexicographic sorting costs \(O(m\tau\log(\tau+1))\) coordinate comparisons, and sorting all coordinate pairs has the same bound.

Let \(h=\max\{1,\lceil\log_2\tau\rceil\}\). Applying the supplied algorithms to the transformed vectors, and translating the output back to the original types, gives total coordinate-comparison running times

\(T_{\mathrm{comp}}(m,\tau)= \begin{cases} O(\tau), & m=1,\\ O(\tau h), & m=2,3,\\ O(\tau h^{m-2}), & \text{fixed }m\geq4. \end{cases}\)

The constants may depend on the fixed dimension \(m\). The preprocessing cost is included: for \(m\geq4\), \(h^{m-2}\geq h\).

Charging \(O(L^2)\) bit operations per comparison-model step is a conservative bound: it covers rational comparisons during preprocessing, comparisons of integer ranks, and bookkeeping on input-sized indices. Thus corresponding bit-time bounds are

\(T_{\mathrm{bit}}(m,\tau,L)= \begin{cases} O(L+\tau L^2), & m=1,\\ O(L+\tau hL^2), & m=2,3,\\ O(L+\tau h^{m-2}L^2), & \text{fixed }m\geq4. \end{cases}\)

The output has encoding length at most \(L\), since it is a subset of the input records. Because the support is explicitly listed, \(\tau\leq L\), so all these bounds are polynomial in \(L\) for fixed \(m\).

Complexity classification

The requested enumeration is polynomial-time solvable. Accordingly, an NP-hardness claim under ordinary polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).
