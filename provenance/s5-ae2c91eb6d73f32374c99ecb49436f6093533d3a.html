The continuous mirror question, as graded

Given an axis-ordered set of categories \(R\), finite types \(T\) with strict single-peaked rankings and current categories, and rational masses \(\mu_t\), let \(q_j\) be the mass initially at category \(r_j\). Does there exist a reallocation \(x_{t,j}\ge 0\) with \(\sum_j x_{t,j}=\mu_t\), \(\sum_t x_{t,j}=q_j\), assigning each type only to its current or a strictly preferred category, and assigning positive total mass to strictly preferred categories?

Packaged proof task (what the prover saw — nothing else)

Let \(R=\{r_1,\ldots,r_m\}\), with \(m\geq1\), have a supplied common axis \(r_1\lhd\cdots\lhd r_m\). Each type \(t\) consists of an explicitly listed strict complete ranking \(\succ_t\), single-peaked on this axis, and a current category \(c_t\in R\).
A society is given by its support: the list \(T\) of its \(\tau\geq1\) types with positive masses \(\mu_t\), each encoded as a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
The conserved supply of category \(r_j\) is \(q_j=\sum_{t:c_t=r_j}\mu_t\); zero supplies are allowed. A reallocation may split each type's mass and consists of real numbers \(x_{t,j}\geq0\) satisfying \(\sum_jx_{t,j}=\mu_t\) and \(\sum_tx_{t,j}=q_j\).
Call it an improvement if \(x_{t,j}=0\) whenever \(r_j\neq c_t\) and \(r_j\not\succ_t c_t\), and \(\sum_{t\in T}\sum_{j:r_j\succ_t c_t}x_{t,j}>0\).

Is deciding whether such an improvement exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For discrete house markets with one distinct house per agent and strict single-peaked preferences, the Diver checks Pareto-optimality in \(\mathcal{O}(n)\) time under unit-cost preference queries. [Beynier et al.](https://simonrey.fr/assets/publications/BMRS20.pdf)
No result explicitly treating this support-encoded mass decision problem was identified in the search.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, interpreting the society as a probability distribution.
  • Specified explicit complete ranking lists and defined L as the total input bit length.
  • Allowed real-valued reallocations and splitting of a type's mass, as intended by the continuous question.
  • Allowed zero-supply categories because supplies are defined by initial masses; imposed no equal-supply requirement.
  • Used nonempty category and support sets; retained strict preferences, so no tie-breaking convention is needed.

Result

The decision problem is solvable in polynomial time in \(m,\tau,L\). In fact, the algorithm below works for arbitrary strict complete rankings; single-peakedness is unnecessary.

The key characterization is that an improvement exists exactly when a certain directed graph contains a directed cycle.

The category graph

Construct a directed graph \(G\) with vertex set \(R\). For distinct categories \(r_i,r_j\), include an edge \(r_i\to r_j\) if there exists a listed type \(t\) such that \(c_t=r_i\) and \(r_j\succ_t r_i\). Store one such type as a witness for each edge.

We prove the characterization in both directions.

An improvement implies a directed cycle

Suppose \(x\) is an improvement. For \(i\ne j\), define the aggregate mass moving from \(r_i\) to \(r_j\) by

\(f_{ij}=\sum_{t:c_t=r_i}x_{t,j}\).

Each \(f_{ij}\) is nonnegative. If \(f_{ij}>0\), some type currently at \(r_i\) receives positive mass of \(r_j\). The improvement restriction implies that this type strictly prefers \(r_j\) to \(r_i\). Consequently, \(r_i\to r_j\) is an edge of \(G\).

At each category \(r_i\), the outgoing and incoming masses are equal. Indeed, the row constraints give

\(\sum_{j\ne i}f_{ij}=\sum_{t:c_t=r_i}(\mu_t-x_{t,i})=q_i-\sum_{t:c_t=r_i}x_{t,i}\),

whereas the column constraint gives

\(\sum_{j\ne i}f_{ji}=\sum_{t:c_t\ne r_i}x_{t,i}=q_i-\sum_{t:c_t=r_i}x_{t,i}\).

Thus \(f\) is a nonnegative circulation on the edges of \(G\). Since every allowed move away from the current category is a strict improvement, the improvement condition says precisely that \(\sum_{i\ne j}f_{ij}>0\).

For completeness, every nonzero nonnegative circulation contains a directed cycle: start with an edge carrying positive mass. At its destination, positive incoming mass and flow conservation imply positive outgoing mass, so the walk can continue along another positive edge. Because the graph is finite, a vertex eventually repeats. Stop at the first repetition; the segment between the two occurrences is a directed cycle. All its edges belong to \(G\).

A directed cycle implies an improvement

Conversely, suppose \(G\) contains a simple directed cycle

\(r_{i_1}\to r_{i_2}\to\cdots\to r_{i_k}\to r_{i_1}\),

where \(k\ge 2\). Put \(i_{k+1}=i_1\). For each edge, choose a witness type \(t_\ell\) satisfying

\(c_{t_\ell}=r_{i_\ell}\quad\text{and}\quad r_{i_{\ell+1}}\succ_{t_\ell}r_{i_\ell}\).

These witness types are distinct: their current categories are the distinct vertices of the simple cycle.

All listed masses are positive, so

\(\varepsilon=\min_{1\le\ell\le k}\mu_{t_\ell}>0\).

Start from the current allocation, which assigns all of type \(t\)'s mass to \(c_t\). For each witness type \(t_\ell\), replace its allocation by

\(x_{t_\ell,i_\ell}=\mu_{t_\ell}-\varepsilon,\qquad x_{t_\ell,i_{\ell+1}}=\varepsilon\),

with zero mass at its other categories. Leave every other type at its current category.

Nonnegativity follows from the choice of \(\varepsilon\), and every row still sums to its prescribed mass. Each cycle category loses exactly \(\varepsilon\) from its outgoing witness and gains exactly \(\varepsilon\) from the preceding witness. Therefore every column still sums to its conserved supply.

Every reassigned portion goes to a strictly preferred category, and the total strictly improved mass is \(k\varepsilon>0\). Hence this allocation is an improvement.

This also handles zero supplies. If \(q_i=0\), positivity of the listed masses implies that no type has current category \(r_i\). Such a vertex has no outgoing edge and cannot belong to a directed cycle.

Algorithm and running time

For each type, scan its explicitly listed ranking and add edges from its current category to every category ranked above it. Then test the resulting directed graph for a cycle using depth-first search.

Parallel edges can be retained, so constructing the graph requires no deduplication. There are at most \(\tau(m-1)\) edges. Construction and cycle detection therefore require \(\mathcal{O}(\tau m+m)\) word operations after reading the input, or \(\mathcal{O}(L+\tau m+m)\) total time when charging \(\mathcal{O}(L)\) for input reading.

To make the bit-complexity claim explicit, let \(N=L+\tau m+m+2\). The algorithm uses \(\mathcal{O}(N)\) operations on indices of \(\mathcal{O}(\log N)\) bits and stores \(\mathcal{O}(N)\) such words. A straightforward sequential-tape simulation, scanning the stored words for each access, gives a conservative \(\mathcal{O}(N^3)\) bit-time bound. Thus the decision procedure is polynomial in all three requested parameters.

No rational arithmetic on the masses is needed for the decision. Their positivity suffices for the cycle construction; their magnitudes affect the amount exchangeable, but not the existence of an improvement.

The cited [Diver paper](https://simonrey.fr/assets/publications/BMRS20.pdf) addresses a discrete market with one distinct resource per agent. The proof above directly handles the supplied support encoding and does not expand rational masses into individual agents.
