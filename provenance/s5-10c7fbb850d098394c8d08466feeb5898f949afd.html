The continuous mirror question, as graded

Given type masses \(\mu_t>0\) summing to \(1\), and two finite lists of weighted-majority clauses with rational quotas and coefficients in \(\{0,1\}\), decide whether the unions define the same winning function for every \(x\in\prod_t[0,\mu_t]\), where each clause wins when its weighted mass reaches its quota.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq1\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
A coalition is any real vector \(x\in\prod_{t=1}^{\tau}[0,\mu_t]\), with \(x_t\) the participating mass of type \(t\).
The input contains two nonempty finite clause lists \(A,B\). Each clause \(c\) has coefficients \(a_{ct}\in\{0,1\}\) and a nonnegative binary rational quota \(q_c\), and wins exactly when \(\sum_{t=1}^{\tau}a_{ct}x_t\geq q_c\); equality wins.
For \(D\in\{A,B\}\), define \(F_D(x)=1\) exactly when at least one clause in \(D\) wins, and otherwise \(F_D(x)=0\). Quotas may be zero or exceed the clause's total available weighted mass.
Let \(m=|A|+|B|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is deciding whether \(F_A(x)=F_B(x)\) for every \(x\in\prod_{t=1}^{\tau}[0,\mu_t]\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite players and indivisible coalitions, equivalence of two unions of weighted majority games is \(\mathrm{coNP}\)-complete even with all weights in \(\{0,1\}\). [Source](https://arxiv.org/pdf/1602.04328)
No result settling exactly the continuous problem stated here was located in the literature search.

  • Restricted quotas to nonnegative binary rationals, following the discrete definition; retained zero quotas and quotas exceeding available weighted mass.
  • Took both clause lists to be nonempty, matching unions of a positive number of weighted majority games.
  • Defined m as the total number of input clauses and L as the total binary input length, since there are no candidates in this problem.

Result

The stated continuous equivalence problem belongs to \(\mathrm{P}\). It can be decided using at most \(m\) rational linear programs, each with \(\tau+1\) variables and at most \(m+2\tau+3\) inequalities. The total running time is \(m\,\operatorname{poly}(m,\tau,L)\) in the binary Turing model.

The proof explicitly preserves the convention that equality wins.

1. Characterizing a counterexample

Write \(X=\prod_{t=1}^{\tau}[0,\mu_t]\), and abbreviate a clause’s weighted sum as \(a_cx=\sum_{t=1}^{\tau}a_{ct}x_t\).

The implication \(F_A(x)\leq F_B(x)\) fails somewhere in \(X\) exactly when there exist a clause \(c\in A\) and a vector \(x\in X\) such that

\[ a_cx\geq q_c \quad\text{and}\quad a_dx<q_d\ \text{for every }d\in B. \]

Indeed, \(F_A(x)=1\) means that at least one clause of \(A\) wins, whereas \(F_B(x)=0\) means that every clause of \(B\) loses. Because equality wins, each losing inequality must be strict.

Thus it suffices to test this system separately for each \(c\in A\), and then repeat with \(A\) and \(B\) exchanged.

2. A linear program that handles strict inequalities exactly

For a clause \(c\) and a nonempty opposing list \(D\), define the linear program \(P(c,D)\):

\[ \begin{aligned} \text{maximize}\quad &\varepsilon\\ \text{subject to}\quad &0\leq x_t\leq\mu_t &&(t=1,\ldots,\tau),\\ &a_cx\geq q_c,\\ &a_dx+\varepsilon\leq q_d &&(d\in D),\\ &0\leq\varepsilon\leq1. \end{aligned} \]

Lemma. There exists \(x\in X\) at which \(c\) wins and every clause of \(D\) loses if and only if \(P(c,D)\) is feasible and its optimal value is strictly positive.

Proof. Suppose first that such an \(x\) exists. Each gap \(q_d-a_dx\) is positive. Since \(D\) is finite and nonempty, the number

\[ \varepsilon_0=\min\bigl(\{1\}\cup\{q_d-a_dx:d\in D\}\bigr) \]

is positive. The pair \((x,\varepsilon_0)\) satisfies every constraint of \(P(c,D)\). Consequently its optimal value is positive.

Conversely, suppose the program is feasible with positive optimal value. Its feasible set is closed and contained in the bounded box \(X\times[0,1]\), hence is compact. Therefore the optimum is attained at some \((x^\ast,\varepsilon^\ast)\) with \(\varepsilon^\ast>0\). The constraints give

\[ a_cx^\ast\geq q_c, \qquad a_dx^\ast\leq q_d-\varepsilon^\ast<q_d \quad(d\in D). \]

Thus \(c\) wins and every opposing clause loses. This proves the lemma. \(\square\)

In particular, feasibility alone is insufficient: a feasible program whose optimal slack is zero supplies no counterexample.

3. Algorithm and correctness

Run the following procedure:

  • For every \(c\in A\), solve \(P(c,B)\). If any program has positive optimal value, return not equivalent.
  • For every \(c\in B\), solve \(P(c,A)\). If any program has positive optimal value, return not equivalent.
  • Otherwise return equivalent.

Infeasible programs do not trigger rejection.

By the lemma, rejection in the first step is equivalent to the existence of an \(x\in X\) with \(F_A(x)=1\) and \(F_B(x)=0\). Rejection in the second step is equivalent to the existence of an \(x\in X\) with the reverse values. Since both functions take values in \(\{0,1\}\), these are exactly the two ways they can differ. Therefore the algorithm is correct.

The argument includes all allowed degeneracies:

  • If the selected clause has quota exceeding its available weighted mass, its program is infeasible.
  • If an opposing clause has quota zero, nonnegativity forces \(\varepsilon=0\), correctly preventing a counterexample against that always-winning clause.
  • Winning regions confined to boundary faces remain admissible because all winning constraints are non-strict.

4. Binary running time

We use the standard rational linear-programming theorem: feasibility and optimization for explicitly represented rational linear programs can be performed in time polynomial in their binary encoding length, with exact rational output when a finite optimum exists. This is the polynomial-time linear-programming result originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here. Every coefficient and right-hand side is rational, and every feasible program is bounded. The theorem also applies to feasible sets of lower dimension; no interior-point assumption is needed. Exact output permits an exact comparison of the optimal value with zero.

Each program has \(\tau+1\) variables and \(|D|+2\tau+3\) inequalities. Even using dense matrices, its encoding length is bounded by

\[ H=O\bigl(L+(m+\tau)(\tau+1)\bigr). \]

The additional entries are constants from \(\{-1,0,1\}\); the input rational numbers are copied without any increase in their bit lengths.

Let \(T_{\mathrm{LP}}(n,k,h)\) denote a polynomial bit-time bound for rational linear programming with \(n\) variables, \(k\) inequalities, and encoding length at most \(h\). Including construction of all programs, the running time is

\[ O\!\left( m\left[H+ T_{\mathrm{LP}}(\tau+1,m+2\tau+3,H)\right] \right) = m\,\operatorname{poly}(m,\tau,L). \]

This bound uses the listed support size \(\tau\), without enumerating any other possible types.

5. Why the indivisible result does not transfer

The cited discrete equivalence problem is \(\mathrm{coNP}\)-complete even with weights in \(\{0,1\}\), as stated in Proposition 4 of [Kurz, Molinero, Olsen, and Serna](https://arxiv.org/pdf/1602.04328). In that setting, the counterexample systems additionally require indivisible choices. Here those choices are real variables, so the systems become linear programs.

The distinction already appears in a small example. Take \(\tau=2\) and \(\mu_1=\mu_2=\tfrac12\). Let \(A\) consist of \(x_1+x_2\geq\tfrac12\), and let \(B\) consist of \(x_1\geq\tfrac12\) and \(x_2\geq\tfrac12\). The two unions agree at every indivisible coalition \(x\in\{0,\tfrac12\}^2\). Nevertheless, at \(x=(\tfrac14,\tfrac14)\), the clause in \(A\) wins while both clauses in \(B\) lose.

Thus discrete equivalence and continuous equivalence are different questions, and the continuous question stated here is completely settled by the algorithm above.
