The continuous mirror question, as graded

Given finitely many site types \(t\), each with \(n_t\) samples per site and rational population share \(\mu_t\), and positive parameters \(\mu_e,\sigma^2\), choose \(x_t\in[0,\mu_t]\), the mass of type \(t\) assigned to one macroscopic federation; the remaining mass learns locally. What choice minimizes limiting weighted error per site, \(\sum_t[(\mu_t-x_t)\mu_e+x_t n_t\sigma^2]\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\geq1\) site types with positive masses \(\mu_t\), each encoded as a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Type \(t\) has a fixed sample count \(n_t\in\mathbb Z_{\geq1}\). The noise parameter \(\mu_e\) and heterogeneity parameter \(\sigma^2\) are positive binary rationals. Let \(m=\max_t n_t\) and let \(L\) be the total input bit length.
Choose divisible masses \(x_t\in[0,\mu_t]\) for a single macroscopic federation; all remaining mass learns locally. The federation may be absent, meaning \(x_t=0\) for every type.
A local type-\(t\) site has error \(\mu_e/n_t\); a federating site has limiting error \(\sigma^2\). Weight each site's error by its sample count, so the objective per site is \(F(x)=\sum_{t=1}^{\tau}[(\mu_t-x_t)\mu_e+x_t n_t\sigma^2]\). Any minimizer is acceptable when costs tie.

Is exact minimization of \(F\) over these feasible masses solvable in polynomial time in \(\tau\), \(\log m\), and \(L\), or is it NP-hard?

For an explicitly listed finite society, minimizing total sample-weighted error over all coalition partitions is polynomial-time solvable; an optimum consists of one coalition formed in ascending sample-count order and local learners ([Donahue–Kleinberg, 2021](https://papers.nips.cc/paper/2021/file/09a5e2a11bea20817477e0b1dfe2cc21-Paper.pdf)).
No prior result addressing exactly the continuous problem stated here was identified in the literature search.

Modeling choices made when packaging the task

  • Population shares are normalized to sum to one, and the support is nonempty.
  • Sample counts are positive integers encoded in binary, matching their interpretation as numbers of observations.
  • The positive model parameters are binary rationals so computational complexity has a finite input encoding.
  • An absent federation is allowed, preserving the finite model's all-local arrangement and the stated closed feasible intervals.
  • The objective is sample-weighted error divided by the number of sites, without an additional division by average sample count.
  • Define m as the maximum sample count and L as total input bit length; use log m in running-time bounds because sample counts are binary encoded.
  • All tied minimizers are permitted; no stability or participation constraints are imposed.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Exact minimization is polynomial-time solvable in \(\tau\), \(\log m\), and \(L\). Under the stated objective, each type can be optimized independently.

1. Exact optimizer and proof. Define the cost difference
\[ c_t=n_t\sigma^2-\mu_e. \]
Using \(\sum_{t=1}^{\tau}\mu_t=1\), the objective becomes
\[ F(x)=\mu_e+\sum_{t=1}^{\tau}c_t x_t. \]
The feasible set is the Cartesian product \(\prod_{t=1}^{\tau}[0,\mu_t]\). Thus selecting any permitted value for one coordinate imposes no restriction on another coordinate.

Choose
\[ x_t^*= \begin{cases} \mu_t,&n_t\sigma^2<\mu_e,\\ 0,&n_t\sigma^2\geq\mu_e. \end{cases} \]
This vector is feasible. For any feasible \(x\),
\[ F(x)-F(x^*)=\sum_{t=1}^{\tau}c_t(x_t-x_t^*). \]
Every summand is nonnegative:

  • If \(c_t<0\), then \(x_t^*=\mu_t\) and \(x_t-\mu_t\leq0\).
  • If \(c_t>0\), then \(x_t^*=0\) and \(x_t\geq0\).
  • If \(c_t=0\), the summand is zero.

Consequently, \(F(x)\geq F(x^*)\) for every feasible \(x\), proving global optimality.

This also characterizes every minimizer: it must select \(x_t=\mu_t\) when \(c_t<0\), select \(x_t=0\) when \(c_t>0\), and may select any \(x_t\in[0,\mu_t]\) when \(c_t=0\). Indeed, equality in the displayed sum requires each nonnegative summand to vanish.

The exact minimum is therefore
\[ F_{\min}=\sum_{t=1}^{\tau}\mu_t\min\{\mu_e,n_t\sigma^2\}. \]

2. Exact arithmetic and bit complexity. Write the input parameters as \(\mu_e=a/b\) and \(\sigma^2=c/d\), where \(a,b,c,d\) are positive integers. Reduction to lowest terms is unnecessary. Since \(bd>0\),
\[ n_t\sigma^2<\mu_e \quad\Longleftrightarrow\quad n_tbc<ad. \]
Hence the algorithm computes \(bc\) and \(ad\) once, scans the explicitly listed types, and compares the integers \(n_tbc\) and \(ad\). It outputs either the given rational \(\mu_t\) or zero for each coordinate.

Let \(B=L+\lceil\log_2(m+1)\rceil\). All integers in these comparisons have \(O(B)\) bits. Ordinary integer multiplication and comparison therefore yield an \(O(\tau B^2+L)\) bit-operation bound for producing the optimizer. Its output length is \(O(L+\tau)\), since every nonzero coordinate copies an input mass.

If the exact minimum value is also requested, each term in its formula is a rational with \(O(B)\)-bit numerator and denominator. Summing the \(\tau\) terms using products of denominators produces intermediate integers of at most \(O(\tau B+\log(\tau+1))\) bits. Thus exact evaluation is polynomial-time as well.

3. Interpretation. The optimizer federates all mass of precisely those types satisfying \(n_t<\mu_e/\sigma^2\), with optional participation at equality. After ordering types by sample count, these types form an initial segment; sorting is unnecessary for the algorithm. If none satisfies the strict inequality, the absent federation is optimal.

The conclusion follows directly from the continuous objective and requires no transfer of the finite-agent theorem in the cited [Donahue–Kleinberg paper](https://papers.nips.cc/paper/2021/file/09a5e2a11bea20817477e0b1dfe2cc21-Paper.pdf).
