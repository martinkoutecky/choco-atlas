The continuous mirror question, as graded

Given candidates \(C\), an addable pool \(D\), a target \(p\in C\), and a distribution \(\mu\) over \(\tau\) ranking types on \(C\cup D\), where each type has positive binary-rational mass and \(\sum_t\mu_t=1\), does some subset \(D'\subseteq D\) make \(p\) a Copeland\(_\alpha\) winner in \(C\cup D'\)? For each pair \(x,y\), the type masses preferring each candidate determine whether the pairwise result is a win, loss, or tie; a tie awards \(\alpha\) points to each candidate.

Packaged proof task (what the prover saw — nothing else)

Fix a rational \(\alpha\) with \(0<\alpha<1\). The input consists of disjoint finite candidate sets \(C,D\), a distinguished \(p\in C\), and a society of strict linear ranking types on \(C\cup D\). Put \(m=|C\cup D|\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For any chosen subset \(D'\subseteq D\), restrict every ranking to \(C\cup D'\), keeping its mass unchanged. Use Copeland\(_\alpha\), with pairwise majorities determined by mass and a pairwise tie awarding \(\alpha\) points to each candidate. Every candidate with maximum score is a winner; no tie-breaking is applied. Any subset, including the empty subset, may be added, with no cardinality budget.

Is deciding whether some \(D'\subseteq D\) makes \(p\) a winner solvable in polynomial time in \(m,\tau,L\), or is it NP-hard, for each fixed rational \(\alpha\in(0,1)\)?

For explicitly listed finite voters with strict rankings, unlimited constructive candidate addition is NP-hard for every fixed rational \(\alpha\in(0,1)\); at \(\alpha\in\{0,1\}\), it is in P. These results are verified in the [full treatment](https://arxiv.org/pdf/0809.4484). No result explicitly treating the normalized rational-mass support model was located in the search.

Modeling choices made when packaging the task

  • The question left alpha's domain and input status unspecified; fix a rational alpha strictly between zero and one, as required by the anchor.
  • Interpret ranking types as strict linear orders over all enrolled and addable candidates.
  • Interpret winner in the nonunique-winner sense: sharing the maximum score suffices, without tie-breaking.
  • Require C and D to be disjoint, and restrict rankings after candidate addition while preserving all masses.
  • Define m as the total number of enrolled and addable candidates and L as the total input bit length.

Result

For every fixed rational \(\alpha\in(0,1)\), the problem is \(\mathsf{NP}\)-complete. Thus a polynomial-time algorithm in \(m,\tau,L\) exists only if \(\mathsf{P}=\mathsf{NP}\).

The proof consists of a polynomial-time transfer of the stated finite-voter hardness result and an exact polynomial-time verifier.

1. Transferring finite-voter hardness

Theorem 4.10 of Faliszewski, Hemaspaandra, Hemaspaandra, and Rothe establishes \(\mathsf{NP}\)-hardness of unlimited constructive candidate addition for every fixed rational \(\alpha\in(0,1)\), including the nonunique-winner model with explicitly listed voters having strict linear rankings. Their term “rational voters” means voters with transitive rankings. Thus the theorem matches the parameter, ranking, addition, and winner conventions required here. [Full treatment, Theorem 4.10 and Section 2.1](https://arxiv.org/pdf/0809.4484).

Take such a finite-voter instance with a nonempty electorate \(V=(v_1,\ldots,v_n)\), where every ballot ranks \(C\cup D\). Keep \(C,D,p\) unchanged. Let \(R_1,\ldots,R_\tau\) be the distinct rankings occurring among the ballots, and define

\[ \text{(formula rendered below)} \]

\(k_t=|\{i:v_i=R_t\}|,\qquad \mu_t=k_t/n.\)

Output exactly these \(\tau\) rankings with their masses. Every mass is positive, and \(\sum_{t=1}^{\tau}\mu_t=1\), so this is a valid support representation.

Polynomial size and construction time. Let \(N\) denote the source input bit length. Identical ballots can be grouped by direct comparisons in polynomial time, for example \(O(N^2)\). We have \(\tau\le n\), and every numerator and denominator uses \(O(\log(n+1))\) bits. The output length is therefore \(O(N+n\log(n+1))\), which is polynomial in \(N\). Only rankings that actually occur are listed; no enumeration of all possible rankings is needed.

Preservation of every possible addition. Fix any \(D'\subseteq D\), and put \(S=C\cup D'\). Restriction to \(S\) preserves the relative order of each pair \(x,y\in S\). Consequently, for distinct \(x,y\in S\),

\(\displaystyle \sum_{t:x\succ_{R_t}y}\mu_t=\frac{|\{i:x\succ_{v_i}y\}|}{n}.\)

Equivalently, their rational-mass majority margin is

\(\displaystyle \sum_{t:x\succ_{R_t}y}\mu_t-\sum_{t:y\succ_{R_t}x}\mu_t=\frac{|\{i:x\succ_{v_i}y\}|-|\{i:y\succ_{v_i}x\}|}{n}.\)

Because \(n>0\), this margin has exactly the same sign as the finite-voter margin. Hence every pairwise win, loss, and tie is preserved. Since both elections use the same \(\alpha\), every candidate has exactly the same Copeland score in the two elections on \(S\).

Thus, for every \(D'\subseteq D\), including \(D'=\varnothing\), the distinguished candidate \(p\) is a winner before the transformation if and only if it is a winner afterward. This proves a polynomial-time many-one reduction and establishes \(\mathsf{NP}\)-hardness.

2. Exact verification in polynomial time

A certificate is the characteristic vector of \(D'\subseteq D\), using at most \(m\) bits. We now bound the time needed to verify it without expanding the society into individual voters.

Write each input mass as \(\mu_t=a_t/b_t\), with positive binary integers \(a_t,b_t\). Define

\(Q=\prod_{t=1}^{\tau}b_t,\qquad W_t=a_t(Q/b_t).\)

These are integers, and normalization gives \(\sum_tW_t=Q\). Moreover,

\(\displaystyle \log_2 Q=\sum_t\log_2 b_t\le L,\)

so \(Q\), all \(W_t\), and all partial sums of the weights have \(O(L)\) bits. Using schoolbook integer arithmetic, computing \(Q\) and the \(W_t\) takes \(O(\tau L^2)\) bit operations.

Precompute each candidate’s position in every ranking. For each unordered pair of distinct candidates \(x,y\in C\cup D\), compute the integer margin

\(\displaystyle M(x,y)=\sum_{t:x\succ_{R_t}y}W_t-\sum_{t:y\succ_{R_t}x}W_t.\)

Its sign determines the pairwise outcome exactly, since the corresponding mass margin is \(M(x,y)/Q\). All pairwise margins can be computed in \(O(\tau m^2L)\) bit operations after constructing the position tables.

Write the fixed parameter as \(\alpha=u/v\), where \(u,v\) are fixed positive integers and \(u<v\). For \(S=C\cup D'\), let \(w_S(x)\) and \(t_S(x)\) count, respectively, the candidates in \(S\setminus\{x\}\) against which \(x\) wins and ties. Its score is

\(\operatorname{score}_S(x)=w_S(x)+(u/v)t_S(x).\)

Compare scores using the integer quantities

\(v\,w_S(x)+u\,t_S(x).\)

Because \(u,v\) are fixed, these integers have \(O(\log(m+1))\) bits. Computing and comparing all scores takes \(O(m^2\log(m+1))\) bit operations. Accept precisely when

\(\operatorname{score}_S(p)\ge\operatorname{score}_S(x)\quad\text{for every }x\in S.\)

A convenient conservative bound for the complete verifier, including input processing, is \(O((1+\tau m^2)L^2)\) bit operations. This is polynomial in the required parameters, proving membership in \(\mathsf{NP}\).

Together with Section 1, this establishes \(\mathsf{NP}\)-completeness for every fixed rational \(\alpha\in(0,1)\).
