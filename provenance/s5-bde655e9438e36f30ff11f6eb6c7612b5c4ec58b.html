The continuous mirror question, as graded

Given colleges \(j\in\{1,\ldots,m\}\), applicant types \(t\in T\) with binary-rational masses \(\mu_t\) summing to \(1\), and each type’s strict college preferences and integer scores \(s_{tj}\), let rational per-capita quotas be \(q_j\). A threshold vector \(\theta\) assigns each type to its most-preferred eligible college with \(s_{tj}\ge\theta_j\), or leaves it unmatched; let \(\ell_j(\theta)\) be the assigned mass at college \(j\). Compute the componentwise least and greatest threshold vectors satisfying \(\ell_j(\theta)\le q_j\) for every \(j\), with lowering any positive \(\theta_j\) by one making that college’s assigned mass exceed \(q_j\); give an exact algorithm polynomial in \(m\), \(\tau=|T|\), and input bit length \(L\), or show that no such algorithm exists unless \(\mathrm{P}=\mathrm{NP}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types. There are \(m\ge 1\) colleges. Each type strictly ranks all colleges above being unmatched and has binary-encoded integer scores \(s_{tj}\in\{1,\ldots,M\}\), where \(M=\max_{t,j}s_{tj}\). College quotas \(q_j\) are nonnegative binary rationals; \(L\) is the total input bit length.
A threshold vector belongs to \(\{0,\ldots,M+1\}^m\). It assigns the entire mass of each type to its most-preferred college satisfying \(s_{tj}\ge\theta_j\), or leaves that mass unmatched. Equal scores are never separated by tie-breaking. Write \(\ell_j(\theta)\) for the assigned mass at college \(j\).
Call \(\theta\) stable if \(\ell_j(\theta)\le q_j\) for every college and, whenever \(\theta_j>0\), replacing only \(\theta_j\) by \(\theta_j-1\) makes college \(j\)'s assigned mass exceed \(q_j\). Order threshold vectors componentwise.

Can the componentwise least and greatest stable threshold vectors be computed exactly in time polynomial in \(m,\tau,L\), or is this computation NP-hard?

For explicitly listed discrete applicants, polynomial algorithms compute both extreme stable score vectors, using \(O(m^2n)\) decreasing updates and \(O(mn)\) increasing updates. [Discrete result](https://doi.org/10.3390/a7010032)
Continuum matching admits a characterization by market-clearing cutoffs, but the verified result assumes every score indifference class has zero mass, excluding the positive-mass score ties here. [Continuum result](https://eduardomazevedo.github.io/papers/Azevedo-Leshno-Supply-and-Demand-Matching.pdf)

Result

Both the componentwise least and greatest stable threshold vectors can be computed exactly in time polynomial in \(m,\tau,L\).

The proof uses a monotone map whose fixed points are exactly the stable vectors. Each coordinate of this map takes at most \(\tau+1\) values, so iteration is polynomial even when scores and masses are binary encoded.

1. The smallest feasible threshold at one college

Let \(X=\{0,\ldots,M+1\}^m\), with the componentwise order. Write \(k\succ_t j\) when type \(t\) prefers college \(k\) to college \(j\).

For \(x\in X\), define
\[ A_j(x)=\{t\in T:\text{ for every }k\succ_t j,\ s_{tk}<x_k\}. \]
Thus, \(A_j(x)\) contains precisely the types with no eligible college preferred to \(j\). It depends only on the coordinates other than \(j\).

If college \(j\)'s threshold is replaced by \(r\), its load is therefore
\[ D_j(r;x)=\sum_{\substack{t\in A_j(x)\\s_{tj}\ge r}}\mu_t. \]
Indeed, a type chooses \(j\) exactly when it is eligible there and has no eligible college it prefers.

For fixed \(x\), this load is nonincreasing in \(r\). Moreover, \(D_j(M+1;x)=0\le q_j\). Hence the following minimum exists:
\[ F_j(x)=\min\{r\in\{0,\ldots,M+1\}:D_j(r;x)\le q_j\}. \]
Set \(F(x)=(F_1(x),\ldots,F_m(x))\).

2. Stable vectors are exactly the fixed points

Lemma. A vector \(x\in X\) is stable if and only if \(F(x)=x\).

Proof. Suppose first that \(x\) is stable. Feasibility gives
\[ D_j(x_j;x)=\ell_j(x)\le q_j, \]
so \(F_j(x)\le x_j\).

If this inequality were strict, integrality would give \(x_j>0\) and \(x_j-1\ge F_j(x)\). Since load is nonincreasing in the college's own threshold,
\[ D_j(x_j-1;x)\le D_j(F_j(x);x)\le q_j. \]
This contradicts stability. Consequently, \(F_j(x)=x_j\) for every \(j\).

Conversely, suppose \(F(x)=x\). The definition of \(F_j\) gives feasibility at every college. If \(x_j>0\), minimality of \(F_j(x)\) gives
\[ D_j(x_j-1;x)>q_j. \]
These are exactly the two conditions defining stability. \(\square\)

3. The map is monotone and has few coordinate values

Lemma. If \(x\le y\), then \(F(x)\le F(y)\).

Proof. If a type has no eligible college preferred to \(j\) at \(x\), it still has none at \(y\), because every threshold has weakly increased. Thus
\[ A_j(x)\subseteq A_j(y). \]
Since masses are positive, for every \(r\),
\[ D_j(r;x)\le D_j(r;y). \]
Every threshold feasible against \(y\)'s other coordinates is therefore feasible against \(x\)'s other coordinates. Taking the smallest feasible threshold proves \(F_j(x)\le F_j(y)\). \(\square\)

Lemma. For every \(x\in X\),
\[ F_j(x)\in C_j:=\{0\}\cup\{s_{tj}+1:t\in T\}. \]
In particular, \(|C_j|\le\tau+1\).

Proof. Let \(r=F_j(x)>0\). Minimality implies
\[ D_j(r-1;x)>q_j\ge D_j(r;x). \]
The difference between these loads is
\[ D_j(r-1;x)-D_j(r;x) =\sum_{\substack{t\in A_j(x)\\s_{tj}=r-1}}\mu_t. \]
It is positive, so some listed type has score \(r-1\) at \(j\). Therefore \(r=s_{tj}+1\). \(\square\)

This lemma accounts for score gaps: the algorithms never need to traverse all integers up to \(M\).

4. Computing and proving both extremes

Use synchronous iteration, meaning that every coordinate of an update uses the preceding vector.

For the least vector, start with \(a^{(0)}=(0,\ldots,0)\) and repeatedly set
\[ a^{(k+1)}=F(a^{(k)}). \]
Because \(a^{(0)}\le F(a^{(0)})\), monotonicity proves inductively that
\[ a^{(0)}\le a^{(1)}\le a^{(2)}\le\cdots. \]
Every coordinate belongs to \(C_j\), including its initial value. It can therefore strictly increase at most \(\tau\) times. Every strict vector update increases at least one coordinate, so there are at most \(m\tau\) strict updates. The iteration reaches a fixed point \(a^*\), which is stable by Section 2.

For any stable vector \(z\), initially \(a^{(0)}\le z\). If \(a^{(k)}\le z\), then
\[ a^{(k+1)}=F(a^{(k)})\le F(z)=z. \]
Thus \(a^*\le z\) for every stable \(z\). Hence \(a^*\) is the componentwise least stable vector.

For the greatest vector, start with \(b^{(0)}=(M+1,\ldots,M+1)\) and repeatedly set
\[ b^{(k+1)}=F(b^{(k)}). \]
Since \(F(b^{(0)})\le b^{(0)}\), monotonicity proves
\[ b^{(0)}\ge b^{(1)}\ge b^{(2)}\ge\cdots. \]
After its first update, each coordinate belongs to \(C_j\). Counting a possible initial value outside \(C_j\), each coordinate can strictly decrease at most \(\tau+1\) times. Thus there are at most \(m(\tau+1)\) strict updates, and the iteration reaches a stable fixed point \(b^*\).

For every stable \(z\), initially \(z\le b^{(0)}\). Inductively,
\[ z=F(z)\le F(b^{(k)})=b^{(k+1)}. \]
Consequently, \(z\le b^*\) for every stable \(z\). Hence \(b^*\) is the componentwise greatest stable vector.

5. Exact evaluation and bit complexity

For each college, sort the types by decreasing score once, keeping equal scores in a single group.

To evaluate \(F(x)\), first compute all memberships in \(A_j(x)\). For each type, traverse its preference list from best to worst, maintaining whether an eligible college has already appeared. Just before examining \(j\), that type belongs to \(A_j(x)\) exactly when no such college has appeared. This takes \(O(m\tau)\) operations.

For each college \(j\), scan its score groups in decreasing order, accumulating the masses of types belonging to \(A_j(x)\).

  • If the complete sum is at most \(q_j\), return \(F_j(x)=0\).
  • Otherwise, let \(v\) be the score of the first group whose inclusion makes the cumulative mass exceed \(q_j\). Return \(F_j(x)=v+1\).

To verify the second rule, the load at \(v+1\) is the preceding cumulative sum, which is feasible. Every integer threshold at most \(v\) includes the overflowing prefix and is infeasible. Thus \(v+1\) is exactly the smallest feasible threshold. Equal-score groups are always included or excluded together.

These scans take another \(O(m\tau)\) operations per evaluation. Together with sorting and the iteration bounds, both algorithms use
\[ O\!\left(m\tau\log(\tau+1)+m^2\tau^2\right) \]
arithmetic operations and comparisons.

For exact arithmetic, write the input masses and quotas as rational numerator–denominator pairs, and let \(Q\) be the product of their denominators. Its bit length is \(O(L)\), because the sum of the input denominator lengths is at most \(L\). Scale every mass and quota by \(Q\).

The scaled masses are integers summing to \(Q\), so every accumulated load has \(O(L)\) bits. Scaled quotas also have \(O(L)\) bits. Scores and thresholds have \(O(L)\) bits as well. Standard integer arithmetic therefore implements every operation in polynomial time in \(L\).

The resulting bit complexity is polynomial in \(m,\tau,L\), with no expansion into individual applicants.

6. Relation to the cited results

This is a direct support-based proof of the score-update approach underlying the [discrete algorithms](https://www.mdpi.com/1999-4893/7/1/32). The [continuum paper](https://eduardomazevedo.github.io/papers/Azevedo-Leshno-Supply-and-Demand-Matching.pdf) assumes zero mass on score indifference classes in Assumption 1. The proof above handles the positive-mass ties explicitly by processing whole score groups.
