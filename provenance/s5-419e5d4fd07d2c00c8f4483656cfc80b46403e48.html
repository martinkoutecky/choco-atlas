The continuous mirror question, as graded

Given candidates \(C\), an explicit support \(T\) of ranking types with rational masses \(\mu_t\) summing to \(1\), transitively closed precedence constraints \(W\), and a pair \((x,y)\), define \(\Delta_\mu(u,v)=\sum_{t\in T}\mu_t(\mathbf{1}[u\succ_t v]-\mathbf{1}[v\succ_t u])\) and \(Z=C\setminus(L_y(W)\cup R_x(W)\cup\{x,y\})\). Decide whether \(\Delta_\mu(x,y)>\min_{a\in[0,1]}\sum_{z\in Z}\max(0,a\Delta_\mu(y,z)+(1-a)\Delta_\mu(z,x))\). A yes answer certifies that \(x\) precedes \(y\) in every minimizer of \(K_\mu(\pi)=\sum_{t\in T}\mu_t d_{KT}(\pi,t)\); a no answer only means this test does not certify the pair.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq2\) candidates. A society is given by its support: a list \(T\) of \(\tau\) distinct complete strict ranking types, each with positive binary rational mass \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
A median is any complete strict ranking minimizing \(K_\mu(\pi)=\sum_{t\in T}\mu_t d_{KT}(\pi,t)\), using Kendall–tau distance; retain all minimizers without tie-breaking.
The input also contains distinct \(x,y\in C\) and an explicitly listed transitively closed strict partial order \(W\subseteq C\times C\), promised to be respected by every median; \((u,v)\in W\) means that \(u\) precedes \(v\).
Define \(L_y(W)=\{z\in C:(z,y)\in W\}\), \(R_x(W)=\{z\in C:(x,z)\in W\}\), and \(Z=C\setminus(L_y(W)\cup R_x(W)\cup\{x,y\})\).
Define \(\Delta_\mu(u,v)=\sum_{t\in T}\mu_t(\mathbf{1}[u\succ_t v]-\mathbf{1}[v\succ_t u])\), where \(u\succ_t v\) means that type \(t\) ranks \(u\) before \(v\).
The decision test accepts exactly when \(\Delta_\mu(x,y)>\min_{a\in[0,1]}\sum_{z\in Z}\max(0,a\Delta_\mu(y,z)+(1-a)\Delta_\mu(z,x))\); the empty sum is zero and equality rejects. Acceptance certifies precedence in every median; rejection only means this test does not certify it.

Is this decision test solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite voting profiles, the corresponding single-pair test takes \(O(|Z|^2)\) arithmetic operations once the cumulative pairwise margins are supplied. [Source](https://arxiv.org/html/2506.15097v2#S3.SS1).
No separate result for this exact rational-support input problem was located in the literature search.

Modeling choices made when packaging the task

  • The ranking domain is complete strict total orders, as in the discrete definition.
  • The constraints W are a strict partial order promised to hold in every unconstrained median; transitive closure alone would not justify the stated certification.
  • All unconstrained minimizers are retained, without tie-breaking.
  • The queried candidates are distinct, so there are at least two candidates; an empty interference set is allowed and its sum is zero.
  • The running-time notation uses m for the number of candidates and L for the total encoded input length, including the support, rational masses, constraints, and queried pair.

Result

The decision test is polynomial-time solvable in \(m,\tau,L\), with exact treatment of equality. The proof below establishes both a finite set of points at which the minimum can be attained and polynomial bounds on all integers used in the computation.

1. Compute integer-scaled margins

Write each input mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive binary-encoded integers. Define

\(D=\prod_{t\in T}q_t\), and \(w_t=p_t(D/q_t)\).

Then each \(w_t\) is a positive integer. The normalization hypothesis gives

\(\sum_{t\in T}w_t=D\).

For distinct candidates \(u,v\), define the integer margin

\(M(u,v)=\sum_{t\in T}w_t\bigl(\mathbf{1}[u\succ_t v]-\mathbf{1}[v\succ_t u]\bigr)\).

Thus \(\Delta_\mu(u,v)=M(u,v)/D\), and \(|M(u,v)|\leq D\).

Construct \(Z\) directly from the explicitly listed relation \(W\). Put \(n=|Z|\), and define

\(d=M(x,y)\), \(A_z=M(y,z)\), and \(B_z=M(z,x)\) for \(z\in Z\).

Because \(D>0\), multiplying the original strict inequality by \(D\) shows that the test accepts exactly when

\(d>\min_{a\in[0,1]}G(a)\), where \(G(a)=\sum_{z\in Z}\max\{0,B_z+a(A_z-B_z)\}\).

This scaling uses the support as supplied; it does not expand the masses into individual votes.

2. A finite set suffices for minimization

Define

\(S=\{0,1\}\cup\left\{\dfrac{B_z}{B_z-A_z}:z\in Z,\ A_zB_z<0\right\}\).

There are at most \(n+2\) elements in \(S\).

Lemma. We have \(\min_{a\in[0,1]}G(a)=\min_{a\in S}G(a)\).

Proof. For each \(z\), consider the affine function

\(h_z(a)=B_z+a(A_z-B_z)\).

Its endpoint values are \(h_z(0)=B_z\) and \(h_z(1)=A_z\).

If \(A_zB_z<0\), the slope is nonzero and its unique zero is

\(a_z=B_z/(B_z-A_z)\in(0,1)\).

If \(A_zB_z\geq0\), there is no isolated zero in the open interval: the function has constant sign there, unless it is identically zero. Any endpoint zero is already included in \(S\).

List the distinct elements of \(S\) in increasing order as \(s_0<\cdots<s_r\). On each interval \([s_i,s_{i+1}]\), every summand \(\max\{0,h_z(a)\}\) agrees throughout with either zero or \(h_z(a)\). Endpoint zeros do not affect this assertion because the two expressions agree there. Hence \(G\) is affine on that interval.

For \(a=(1-\lambda)s_i+\lambda s_{i+1}\), with \(\lambda\in[0,1]\), it follows that

\(G(a)=(1-\lambda)G(s_i)+\lambda G(s_{i+1})\geq\min\{G(s_i),G(s_{i+1})\}\).

Consequently, some point of \(S\) attains the global minimum. This proves the lemma.

This is the breakpoint principle underlying the finite-profile algorithm in [Section 3.1 of the supplied source](https://arxiv.org/html/2506.15097v2#S3.SS1). The remaining issue for the present input model is exact bit complexity.

3. Decide the strict inequality using integers

Represent each point of \(S\) as \(p/q\), with integers \(q>0\) and \(0\leq p\leq q\). Reduction to lowest terms is unnecessary.

For the endpoints, use \(0/1\) and \(1/1\). For an interior breakpoint \(B_z/(B_z-A_z)\), multiply numerator and denominator by the same sign to make the denominator positive.

For each such representation, compute

\(H(p,q)=\sum_{z\in Z}\max\{0,pA_z+(q-p)B_z\}\).

Since \(q>0\),

\(G(p/q)=H(p,q)/q\).

Therefore the algorithm accepts if and only if at least one candidate point satisfies the exact integer comparison

\(qd>H(p,q)\).

Indeed, such a comparison implies \(d>\min_{a\in S}G(a)\). Conversely, if \(d>\min_{a\in S}G(a)\), the comparison holds at a minimizing candidate point. The lemma makes this precisely the original acceptance condition.

The algorithm rejects if no comparison succeeds. In particular, equality with the minimum rejects.

When \(Z=\varnothing\), every value of \(H\) is zero, so the algorithm accepts exactly when \(d>0\), as required.

4. Polynomial bit complexity

The total binary encoding length of the denominators is at most \(L\). Consequently,

\(\log_2 D=\sum_{t\in T}\log_2 q_t\leq L\).

Thus \(D\), every \(w_t\), and every integer margin have \(O(L+1)\) bits. The products defining \(D\), the exact divisions \(D/q_t\), and the weighted margin sums can all be computed in polynomial time.

Every interior breakpoint has a representation satisfying

\(q=|B_z-A_z|\leq2D\), and \(0<p<q\).

Thus its numerator and denominator also have \(O(L+1)\) bits. These bounds also hold for the endpoint representations, with \(q=1\).

For every candidate point and every \(z\),

\(|pA_z+(q-p)B_z|\leq p|A_z|+(q-p)|B_z|\leq qD\).

It follows that

\(0\leq H(p,q)\leq nqD\leq2nD^2\), and \(|qd|\leq2D^2\).

All integers used in the evaluations and comparisons therefore have \(O(L+\log(n+1)+1)\) bits. Ordinary integer arithmetic on these numbers takes polynomial time.

To bound the number of operations, first record each candidate’s position in each listed ranking. This uses \(O(\tau m)\) entries. Computing the \(2n+1\) required margins then uses \(O(\tau(n+1))\) integer additions or subtractions. Reading \(W\) and constructing \(Z\) takes polynomial time, since \(W\) is explicitly listed and has at most \(m(m-1)\) pairs.

Finally, there are at most \(n+2\) candidate points, each requiring \(O(n+1)\) integer operations. This gives \(O((n+1)^2)\) evaluation operations, each of polynomial bit complexity. Since \(n\leq m-2\), the entire algorithm runs in polynomial time in \(m,\tau,L\).

5. Scope of the conclusion

The target decision test is resolved: it belongs to \(\mathrm{P}\). The algorithm uses the supplied \(W\) to construct \(Z\); it does not need to verify the promise that every median respects \(W\).

Thus the promised rational-support formulation creates no computational obstruction to evaluating this test. An NP-hardness result under polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).
