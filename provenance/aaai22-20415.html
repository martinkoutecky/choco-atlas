The continuous mirror question, as graded

Given a finite type set \(\mathcal T\), rational masses \(\mu\) with \(\sum_a\mu_a=1\), rational AEG utilities \(v_{ab}\in\{-M,1\}\), and a support bound \(Q\), decide whether there exists a finite-support partition \(\lambda=\sum_{\ell=1}^{q}\rho_\ell\delta_{z^\ell}\), with \(q\le Q\) and \(\sum_{\ell}\rho_\ell z^\ell=\mu\), such that no occupied coalition \(z\) admits a type-\(a\) move to an occupied coalition \(y\) satisfying \(z_a>0\), \(U_a(y)>U_a(z)\), and \(\operatorname{in}_a(y)\ge\operatorname{out}_a(y)\), where \(U_a(z)=\sum_bv_{ab}z_b\), \(\operatorname{in}_a(y)=\sum_{b:v_{ba}>0}y_b\), and \(\operatorname{out}_a(y)=\sum_{b:v_{ba}<0}y_b\).

Packaged proof task (what the prover saw — nothing else)

Definitions

Let \(\mathcal T\) be finite, \(\mu\in\mathbb Q_{\ge0}^{\mathcal T}\) with \(\sum_a\mu_a=1\), \(M\in\mathbb Q_{>0}\), \(v_{ab}\in\{-M,1\}\), and \(Q\in\mathbb N\). Let \(\Delta(\mathcal T)=\{z\in\mathbb R_{\ge0}^{\mathcal T}:\sum_a z_a=1\}\). A finite-support partition is \(\lambda=\sum_{\ell=1}^q\rho_\ell\delta_{z^\ell}\), where \(q\le Q\), \(\rho_\ell>0\), \(z^\ell\in\Delta(\mathcal T)\), and \(\sum_\ell\rho_\ell z^\ell=\mu\); its occupied coalitions are its support points. Set \(U_a(z)=\sum_bv_{ab}z_b\), \(\operatorname{in}_a(y)=\sum_{b:v_{ba}>0}y_b\), and \(\operatorname{out}_a(y)=\sum_{b:v_{ba}<0}y_b\). The partition is majority-in stable if no occupied \(z,y\) and type \(a\) satisfy \(z_a>0\), \(U_a(y)>U_a(z)\), and \(\operatorname{in}_a(y)\ge\operatorname{out}_a(y)\).

Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Theorem

The finite-support continuous majority-in-stability existence problem is polynomial-time solvable. In fact, every valid instance with \(Q\ge 1\) is a YES-instance.

Proof

Choose the one-point distribution

\[ \lambda=\delta_\mu. \]

Equivalently, set \(q=1\), \(\rho_1=1\), and \(z^1=\mu\).

This is feasible because the hypotheses give \(\mu_a\ge 0\) for every \(a\in\mathcal T\) and

\[ \sum_{a\in\mathcal T}\mu_a=1. \]

Hence \(\mu\in\Delta(\mathcal T)\). Moreover,

\[ \sum_{\ell=1}^q\rho_\ell z^\ell = 1\cdot\mu = \mu, \]

and \(q=1\le Q\).

It remains to verify majority-in stability. The only occupied coalition is \(\mu\). Therefore, any two occupied coalitions \(z,y\) necessarily satisfy

\[ z=y=\mu. \]

For every type \(a\in\mathcal T\),

\[ U_a(y) = \sum_{b\in\mathcal T}v_{ab}\mu_b = U_a(z). \]

Consequently, the strict-improvement condition \(U_a(y)>U_a(z)\) is false. Thus no triple consisting of occupied \(z,y\) and a type \(a\) can satisfy all three blocking conditions, irrespective of whether \(z_a>0\) or \(\operatorname{in}_a(y)\ge\operatorname{out}_a(y)\).

Therefore \(\delta_\mu\) is always a majority-in stable finite-support partition.

Complexity consequence

On the promised input domain \(Q\in\mathbb N\) with \(Q\ge1\), an algorithm may always return YES. Thus the problem belongs to \(\mathrm P\); indeed, apart from reading or validating the input, its answer is constant.

If the convention \(0\in\mathbb N\) is used, the complete classification is still immediate: return NO when \(Q=0\), since no nonempty probability distribution can have support size at most zero, and return YES when \(Q\ge1\).

The cited finite-agent hardness result does not transfer because the present definition permits a single occupied coalition and only allows deviations toward occupied coalitions. With one occupied coalition, strict improvement is impossible.

Verdict

The prover’s argument is fully correct and resolves the target problem as defined. The key observation is valid: deviations are permitted only toward occupied coalitions, so a partition with exactly one occupied coalition admits no strict utility improvement.

Step-by-step audit

  • Construction of the partition.

The choice \(\lambda=\delta_\mu\), with \(q=1\), \(\rho_1=1\), and \(z^1=\mu\), satisfies the required form.

  • Simplex membership.

From \(\mu_a\ge 0\) for all \(a\) and \(\sum_a\mu_a=1\), it follows directly that \(\mu\in\Delta(\mathcal T)\).

  • Barycenter condition.

The equality
\[ \sum_{\ell=1}^q\rho_\ell z^\ell=\mu \]
holds because the sole term is \(1\cdot\mu\).

  • Support bound and weight conditions.

For \(Q\ge1\), \(q=1\le Q\). The sole weight is strictly positive. Thus all finite-support partition requirements are met.

  • Stability verification.

The only occupied coalition is \(\mu\). Hence any occupied \(z,y\) satisfy \(z=y=\mu\). Consequently,
\[ U_a(y)=U_a(z) \]
for every type \(a\). The required strict inequality \(U_a(y)>U_a(z)\) is therefore false for every candidate triple. This suffices to exclude a blocking triple regardless of the other two conditions.

  • Complexity conclusion.

On valid instances with \(Q\ge1\), the constant answer YES is correct. If \(0\in\mathbb N\), the separate \(Q=0\) case is also correctly handled: no partition can satisfy the barycenter condition with zero support because \(\mu\) has total mass \(1\).

  • Relation to the nearest known result.

The stated reason the finite-agent hardness theorem does not transfer is consistent with the definitions: the continuous formulation permits the one-coalition partition, and deviations are restricted to already occupied coalitions.

No unjustified step, missing hypothesis, computational error, or relevant edge case remains.
