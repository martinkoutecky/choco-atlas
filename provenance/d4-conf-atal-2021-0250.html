The anchor (named result in the paper)

Theorem 4.2 — class: hardness

The continuous mirror question, as graded

Given a finite project set \(P\), supported voter types \(\Pi_1,\ldots,\Pi_\tau\) that are partitions of \(P\), positive rational masses \(\mu_1,\ldots,\mu_\tau\) summing to \(1\), and a rational threshold \(q\), does there exist a partition \(S\) of \(P\) such that \(\sum_{i=1}^{\tau}\mu_i\,|\{A\in\Pi_i:A\in S\}|\ge q\)? Equivalently, find a partition \(S\) maximizing this mass-weighted total complementarity utility.

Packaged proof task (what the prover saw — nothing else)

Given a finite project set \(P\) with \(m\ge 1\), a society is given by its support: an explicit list of \(\tau\ge 1\) distinct partition types \(\Pi_1,\ldots,\Pi_\tau\), each with positive binary rational mass \(\mu_i\), where \(\sum_{i=1}^{\tau}\mu_i=1\). Here \(\tau\) is the support size, not the number of possible partition types. Let \(L\) be the total bit length of the input, including a binary rational threshold \(q\in\mathbb{Q}\).
For an output partition \(S\) of \(P\), type \(i\) has complementarity utility \(u_i(S)=|\{A\in\Pi_i:A\in S\}|\): only exact block matches count. Any partition of \(P\) is admissible, including partitions containing blocks absent from every supported type.
The decision problem asks whether some \(S\) satisfies \(\sum_{i=1}^{\tau}\mu_i u_i(S)\ge q\). State running times in \(m,\tau,L\).

Is this mass-weighted complementarity partition aggregation decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite list of voters with unweighted total complementarity utility, the corresponding decision problem is NP-hard. [Source](https://www.ifaamas.org/Proceedings/aamas2021/pdfs/p665.pdf)
No result explicitly treating this normalized rational-mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Made the input encoding explicit: partition types are listed explicitly and L is the total input bit length.
  • Used distinct supported types, combining identical partitions into one type with their summed mass.
  • Made the nonempty-domain convention explicit by taking m and tau at least one.
  • Kept the output domain as all partitions of P, without restricting output blocks to blocks submitted by supported types.

Result

The decision problem is \(\mathrm{NP}\)-complete under polynomial-time many-one reductions. Thus it has no algorithm polynomial in \(m,\tau,L\) unless \(\mathrm{P}=\mathrm{NP}\).

The normalization of masses does not remove hardness: repeated voters can be compressed into distinct partition types, with their multiplicities represented by rational masses.

Reduction from unweighted complementarity aggregation

We use the following known result: given a project set \(P\), an explicit list of voter partitions \(R_1,\ldots,R_n\), and an integer threshold \(K\), deciding whether a partition \(S\) satisfies
\(\sum_{j=1}^{n}|\{A\in R_j:A\in S\}|\ge K\)
is \(\mathrm{NP}\)-hard. The utility is precisely the exact-block-match utility in the question, and the output may be any partition of \(P\). This is Total-COMP in Definition 2.3 and Section 4.1, with hardness established by Theorem 4.2 of [Jain, Talmon, and Bulteau (2021)](https://www.ifaamas.org/Proceedings/aamas2021/pdfs/p665.pdf).

Take such an instance with \(n\ge 1\). Group identical voter partitions. Let \(\Pi_1,\ldots,\Pi_\tau\) be the resulting distinct types, and let \(c_i\) denote the number of voters whose partition equals \(\Pi_i\). Define
\(\mu_i=c_i/n\) and \(q=K/n\).

This gives a valid instance of the requested formulation:

  • Each \(\mu_i\) is a positive rational number.
  • The supported partitions are distinct, and \(\tau\le n\).
  • Because \(\sum_{i=1}^{\tau}c_i=n\), the masses sum to one.
  • The project set and the admissible output partitions are unchanged.

For every partition \(S\) of \(P\), grouping the identical summands gives
\[ \sum_{i=1}^{\tau}\mu_i u_i(S) = \frac{1}{n}\sum_{i=1}^{\tau}c_i|\{A\in\Pi_i:A\in S\}| = \frac{1}{n}\sum_{j=1}^{n}|\{A\in R_j:A\in S\}|. \]
Since \(n>0\), this proves the equivalence
\[ \sum_{i=1}^{\tau}\mu_i u_i(S)\ge q \quad\Longleftrightarrow\quad \sum_{j=1}^{n}|\{A\in R_j:A\in S\}|\ge K. \]
Consequently, the original instance is a yes-instance exactly when the constructed instance is a yes-instance. This equivalence includes outputs containing unsupported blocks.

The construction has polynomial bit complexity. Canonically representing each partition by its project-to-block labels allows identical types to be grouped in polynomial time. Each mass \(c_i/n\) requires \(O(\log(n+1))\) bits, and \(K/n\) requires \(O(\log(|K|+1)+\log(n+1))\) bits. Thus the output length is polynomial in the original explicit input length. No voter expansion is needed.

This establishes \(\mathrm{NP}\)-hardness.

Membership in \(\mathrm{NP}\) and verification time

Relabel the projects as \(P=\{1,\ldots,m\}\). A certificate assigns each project a block label in \(\{1,\ldots,m\}\); projects with the same label form one block. Every partition has such a representation, using \(O(m\log(m+1))\) bits.

Represent blocks by incidence vectors of length \(m\). Each input partition and the certificate partition have at most \(m\) blocks. Comparing every pair of blocks therefore computes all utilities \(u_i(S)\) in \(O(\tau m^3)\) elementary bit comparisons.

The threshold comparison can also be performed exactly in polynomial time. Write \(\mu_i=a_i/b_i\) and \(q=c/d\), with positive denominators, and define
\[ D=d\prod_{i=1}^{\tau}b_i. \]
Then the required comparison is the integer comparison
\[ \sum_{i=1}^{\tau}a_i u_i(S)\frac{D}{b_i} \ge c\frac{D}{d}. \]
The bit length of \(D\) is \(O(L)\), because the total encoded denominator length is at most \(L\). Moreover, \(0\le u_i(S)\le m\) and \(\sum_i\mu_i=1\), so the integer on the left is at most \(mD\). All integers involved have \(O(L+\log(m+1))\) bits, including the right side.

Using schoolbook integer arithmetic, a conservative total verification bound, including representation conversion, is
\[ O\!\left( \tau m^3+ (\tau+1)\bigl(L+m\log(m+1)\bigr)^2 \right). \]
This is polynomial in \(m,\tau,L\), proving membership in \(\mathrm{NP}\).

Conclusion and deterministic upper bound

Combining the reduction and certificate verification proves \(\mathrm{NP}\)-completeness.

For an explicit deterministic upper bound, enumerate all \(m^m\) project-to-block label assignments and verify each. These assignments represent every partition, although some partitions occur repeatedly. The resulting running time is
\[ O\!\left( m^m\left[ \tau m^3+ (\tau+1)\bigl(L+m\log(m+1)\bigr)^2 \right] \right). \]
The hardness transfer and exact rational verification settle the normalized support formulation completely.
