The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), and a type-invariant Boolean preference formula \(\varphi_t\) for each type, decide whether there is a mass allocation \(x_{t,S}\ge 0\) over coalition supports \(S\subseteq T\), with \(x_{t,S}>0\) only when \(t\in S\) and \(\sum_{S\ni t}x_{t,S}=\mu_t\), that is AE-FX stable against profitable tagged infinitesimal individual deviations and Pareto-optimal by satisfied mass of each type.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). The support size \(\tau\) is not the number of possible types. Each type has an explicitly represented Boolean formula \(\varphi_t\) whose variable \(r\in T\) means that another individual of type \(r\) is present; satisfaction is preferred to dissatisfaction, with indifference within each class. Let \(m\) be the total formula length and \(L\) the total input bit length; state running times in \(m,\tau,L\).
An allocation consists of real masses \(x_{t,S}\geq 0\) for nonempty \(S\subseteq T\), with \(x_{t,S}=0\) for \(t\notin S\) and \(\sum_{S\ni t}x_{t,S}=\mu_t\). A support \(S\) is occupied exactly when \(x_{t,S}>0\) for every \(t\in S\); otherwise all its entries must be zero. It represents one coalition with exactly those positive-mass types. Write \(u_t(S)=\varphi_t(\mathbf 1_S)\).
A tagged infinitesimal individual contributes no mass but its type is visible to Boolean presence tests. Leaving does not change its source coalition's positive-mass support. Entering an occupied coalition \(D\) gives the entrant utility \(u_t(D\cup\{t\})\) and each incumbent type \(r\in D\) utility \(u_r(D\cup\{t\})\); forming a new singleton gives the entrant utility \(\varphi_t(\mathbf 0)\).
An allocation is AE-FX stable if, for every \(x_{t,S}>0\), there is no strictly profitable tagged deviation either to a new singleton or to another occupied coalition \(D\) with \(u_r(D\cup\{t\})\geq u_r(D)\) for every \(r\in D\). Exit requires no approval; singleton entry requires none.
Define satisfied mass \(h_t(x)=\sum_{S\ni t}x_{t,S}u_t(S)\). An allocation is Pareto-optimal if no feasible allocation \(y\), whether stable or not, satisfies \(h_t(y)\geq h_t(x)\) for every \(t\), with strict inequality for some type.

Is deciding whether an AE-FX stable, Pareto-optimal allocation exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents with Boolean preferences, existence of a Pareto-optimal AE-FX stable partition is \(\Sigma_2^p\)-complete. [Source](https://proceedings.kr.org/2026/23/)
No result settling this exact continuous formulation was located.

Modeling choices made when packaging the task

  • Required each occupied coalition support to equal exactly the types with positive allocated mass; partial occupancy under a larger support label is disallowed.
  • Interpreted formula variables as presence of other individuals of a type, including other individuals of the evaluator's own type. In a positive-mass coalition, removing one tagged individual leaves that type present.
  • Defined tagged infinitesimal entry to make the entrant's type visible despite its zero mass, while exit leaves the source's positive-mass support unchanged.
  • Included deviations to a newly formed singleton, evaluated with all other-individual presence variables false, and imposed no approval requirement for that move.
  • Allowed real allocation masses and evaluated Pareto dominance against all feasible allocations, without imposing stability on the dominating allocation.
  • Defined m as total explicit formula length and L as total input bit length, since the question supplied no separate candidate or alternative count.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is \(\mathrm{NP}\)-hard, even when all masses are equal dyadic rationals. The reduction below uses formulas that do not mention their own type.

1. Pareto optimality forbids partial satisfaction

For every Pareto-optimal allocation \(\,x\), each type satisfies \(h_t(x)\in\{0,\mu_t\}\).

Indeed, suppose \(0<h_t(x)<\mu_t\). There are occupied supports \(S_+\) and \(S_-\) containing \(t\) with \(u_t(S_+)=1\) and \(u_t(S_-)=0\). Choose \(0<\varepsilon<x_{t,S_-}\), decrease \(x_{t,S_-}\) by \(\varepsilon\), and increase \(x_{t,S_+}\) by \(\varepsilon\).

Both supports remain occupied, every type’s total mass remains unchanged, and all other entries remain unchanged. Thus every other type’s satisfied mass is unchanged, while \(h_t\) increases by \(\varepsilon\). This contradicts Pareto optimality.

2. A three-type obstruction

Consider types \(a,b,c\), with arbitrary positive masses, whose formulas are

\(\psi_a=b\land\neg c,\qquad \psi_b=c\land\neg a,\qquad \psi_c=a\land\neg b.\)

Allow any number of additional types, all with identically true formulas. We prove that this society has no Pareto-optimal allocation.

First, at most one of \(a,b,c\) can be fully satisfied. If \(h_a(x)=\mu_a\), every occupied support containing \(a\) satisfies \(\psi_a\). Such a support exists because \(\mu_a>0\). It contains \(b\) and excludes \(c\), so \(b\) is dissatisfied there. Occupancy requires strictly positive \(b\)-mass there, implying \(h_b(x)<\mu_b\). Likewise,

\(h_b(x)=\mu_b\Longrightarrow h_c(x)<\mu_c,\qquad h_c(x)=\mu_c\Longrightarrow h_a(x)<\mu_a.\)

These implications exclude every pair of fully satisfied gadget types.

Now suppose \(x\) were Pareto-optimal. Section 1 implies that each gadget type has satisfied mass either zero or its full mass. Consequently, either none is fully satisfied or exactly one is.

The following table gives a feasible allocation \(y\) that dominates \(x\) in every case. Every additional type is placed in its own singleton. A split type places half its mass in each listed support; every other gadget type places all its mass in its unique listed support.

| Fully satisfied gadget types in \(x\) | Gadget supports occupied in \(y\) | Split type | \((h_a(y),h_b(y),h_c(y))\) |
|---|---|---|---|
| None | \(\{a,b\},\{c\}\) | None | \((\mu_a,0,0)\) |
| Only \(a\) | \(\{a,b\},\{b,c\}\) | \(b\) | \((\mu_a,\mu_b/2,0)\) |
| Only \(b\) | \(\{b,c\},\{c,a\}\) | \(c\) | \((0,\mu_b,\mu_c/2)\) |
| Only \(c\) | \(\{c,a\},\{a,b\}\) | \(a\) | \((\mu_a/2,0,\mu_c)\) |

All listed supports have strictly positive mass of every member because all masses are positive. The utility calculations follow directly from the three formulas: in \(\{a,b\}\), only \(a\) is satisfied; in \(\{b,c\}\), only \(b\) is satisfied; and in \(\{c,a\}\), only \(c\) is satisfied. Every gadget singleton is dissatisfied.

Each row preserves every fully satisfied type and strictly improves another type. Additional types remain fully satisfied. Hence \(y\) Pareto-dominates \(x\), a contradiction.

3. Polynomial reduction from satisfiability

We use the standard \(\mathrm{NP}\)-completeness of \(\mathrm{CNF}\) satisfiability. Let \(F(z_1,\ldots,z_n)\) be an input formula of length \(\ell\).

Set \(\tau=2^{\lceil\log_2(n+3)\rceil}\). Create types \(a,b,c,z_1,\ldots,z_n\), adding padding types until there are exactly \(\tau\) types. Give every type mass \(\mu_t=1/\tau\). These masses are positive dyadic rationals and sum to one.

Define

\(\varphi_a=(b\land\neg c)\lor F,\qquad \varphi_b=(c\land\neg a)\lor F,\qquad \varphi_c=(a\land\neg b)\lor F.\)

Every variable type and padding type receives the tautology \(a\lor\neg a\).

The construction has \(\tau<2(n+3)\) and total formula length \(m=3\ell+O(\tau)\). Its total bit length \(L\) is polynomial in the source input length. With indexed variable names, construction takes \(O(m+\tau+L)\) time.

Satisfiable formulas give yes-instances. Suppose \(\eta\) satisfies \(F\). Let

\(S=\{a,b,c\}\cup\{z_i:\eta(z_i)=1\}.\)

Place all the mass of every type in \(S\) into this one coalition. Place each type outside \(S\) into its own singleton. This is feasible: every member of every occupied support has strictly positive mass.

The assignment represented by \(S\) satisfies \(F\), so all three gadget types are satisfied. Every other type has a tautological formula. Thus \(h_t(x)=\mu_t\) for every type.

Since every feasible allocation satisfies \(h_t\leq\mu_t\), this allocation is Pareto-optimal. It is also AE-FX stable: every individual’s current utility is already one, and neither entry nor singleton formation can yield a strictly higher Boolean utility.

Unsatisfiable formulas give no-instances. Suppose \(F\) is unsatisfiable. It evaluates to zero on every support indicator vector. Therefore the three gadget formulas reduce exactly to the formulas in Section 2, while all additional types remain always satisfied.

Section 2 proves that this instance has no Pareto-optimal allocation. In particular, it has no allocation that is both Pareto-optimal and AE-FX stable.

We have therefore established the exact equivalence

\(F\text{ is satisfiable}\quad\Longleftrightarrow\quad \text{the constructed society admits an AE-FX stable, Pareto-optimal allocation}.\)

4. Complexity conclusion

This is a polynomial-time many-one reduction, proving \(\mathrm{NP}\)-hardness. Consequently, an algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The strict occupancy condition is essential to the obstruction: the positive helper mass required by one type’s satisfaction prevents another type from being fully satisfied, while splitting that helper mass supplies a Pareto improvement.
