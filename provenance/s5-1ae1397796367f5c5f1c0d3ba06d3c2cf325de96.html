The continuous mirror question, as graded

Given types \(S=\{1,\ldots,\tau\}\) with binary-rational masses \(\mu_s>0\) summing to \(1\), feasible deployments \(x^1,\ldots,x^k\in X_\alpha\), rational utilities \(u_s(x^j)\in[0,1]\), and a supplied rational lottery \(p\in\Delta_k\), define \(\bar u_s(p)=\sum_j p_j u_s(x^j)\) and \(\Phi_\mu(p)=\sum_{s,s'}\mu_s\mu_{s'}|\bar u_s(p)-\bar u_{s'}(p)|\). Given \(\epsilon>0\) and a horizon \(T\ge\lceil L/\epsilon\rceil\), where \(L\) is a Lipschitz constant of \(\Phi_\mu\) in \(p\) under the coordinatewise maximum norm, construct counts \(q_j\in\mathbb Z_{\ge0}\), \(\sum_j q_j=T\), such that \(\Phi_\mu(q/T)\le\Phi_\mu(p)+\epsilon\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\ge1\) types with positive binary-rational masses \(\mu_s\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(k\ge1\) explicitly supplied deployments \(x^j\in\mathbb Q^m\), each promised admissible in every period, with unrestricted repetition and no constraints linking periods. Their time-invariant utilities \(u_s(x^j)\in[0,1]\cap\mathbb Q\) are supplied explicitly; deployment feasibility is not part of the computational task.
For \(r\in\Delta_k\), define \(\bar u_s(r)=\sum_{j=1}^k r_j u_s(x^j)\) and \(\Phi_\mu(r)=\sum_{s=1}^\tau\sum_{s'=1}^\tau\mu_s\mu_{s'}|\bar u_s(r)-\bar u_{s'}(r)|\).
The input includes a rational lottery \(p\in\Delta_k\), binary rationals \(\epsilon>0\) and \(\Lambda\ge0\), and a binary-encoded integer \(T\ge\max\{1,\lceil\Lambda/\epsilon\rceil\}\). It is promised that \(|\Phi_\mu(r)-\Phi_\mu(r')|\le\Lambda\|r-r'\|_\infty\) for all \(r,r'\in\Delta_k\). Let \(L\) be the total input bit length.
The construction problem asks for binary-encoded counts \(q\in\mathbb Z_{\ge0}^k\) with \(\sum_jq_j=T\) and \(\Phi_\mu(q/T)\le\Phi_\mu(p)+\epsilon\).

Can this construction problem be solved in time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For a finite list of stakeholders, a polynomial-time construction attaining the supplied lottery's unfairness plus \(\epsilon\) at horizons \(T\ge\lceil\Lambda/\epsilon\rceil\) is claimed under a Lipschitz assumption by [Lodi, Sankaranarayanan, and Wang](https://arxiv.org/pdf/2212.10070v1). No separate result settling this exact mass-weighted construction problem was verified.

  • Specified binary encoding for epsilon, the Lipschitz bound, T, and the output counts, and required T to be positive even when the Lipschitz bound is zero.

Result

The construction problem is solvable in deterministic polynomial time. This holds for every input satisfying the promises, including arbitrary support masses. The key is to round the supplied lottery while preserving its total mass.

Write \(\Delta_k=\{r\in\mathbb R_{\ge0}^k:\sum_{j=1}^k r_j=1\}\).

Construction and rounding bound

For each \(\ j\in\{1,\ldots,k\}\), define

\(a_j=\lfloor Tp_j\rfloor,\qquad f_j=Tp_j-a_j,\qquad D=T-\sum_{j=1}^k a_j.\)

Since \(p\in\Delta_k\),

\(D=\sum_{j=1}^k f_j.\)

Thus \(D\) is an integer satisfying \(0\le D<k\), because \(0\le f_j<1\) for every coordinate.

If \(D=0\), set \(q_j=a_j\) for every coordinate. Otherwise, choose the first \(D\) indices having \(f_j>0\), and increase \(a_j\) by one at precisely those indices to obtain \(q_j\).

This choice is possible: if \(h\) coordinates have positive fractional parts, then, for \(D>0\),

\(D=\sum_{j:f_j>0}f_j<h.\)

The resulting counts are nonnegative integers, and

\(\sum_{j=1}^k q_j=\sum_{j=1}^k a_j+D=T.\)

For an increased coordinate, \(|q_j-Tp_j|=1-f_j<1\), since its fractional part is positive. For every other coordinate, \(|q_j-Tp_j|=f_j<1\). Consequently,

\(\left\|q/T-p\right\|_\infty<1/T.\)

This argument also covers \(D=0\): then all fractional parts vanish and \(q/T=p\).

Unfairness guarantee

The counts satisfy \(q/T\in\Delta_k\), so the promised Lipschitz inequality applies:

\(\Phi_\mu(q/T)\le\Phi_\mu(p)+\Lambda\left\|q/T-p\right\|_\infty\le\Phi_\mu(p)+\Lambda/T.\)

The horizon promise and positivity of \(\epsilon\) imply

\(T\ge\lceil\Lambda/\epsilon\rceil\ge\Lambda/\epsilon,\qquad \Lambda/T\le\epsilon.\)

Therefore,

\(\Phi_\mu(q/T)\le\Phi_\mu(p)+\epsilon.\)

This includes \(\Lambda=0\), since \(T\ge1\). Moreover, using deployment \(j\) exactly \(q_j\) times is feasible: every deployment is admissible in every period, repetition is unrestricted, and periods have no linking constraints.

Bit complexity

Represent each input probability as \(p_j=A_j/B_j\), with \(A_j\ge0\) and \(B_j>0\) integers encoded in binary. Compute the quotient and remainder of \(TA_j\) divided by \(B_j\). The quotient is \(a_j\), and a positive remainder is equivalent to \(f_j>0\). Thus no fractional arithmetic or sorting is required.

Each input integer has at most \(L\) bits, and each product \(TA_j\) has at most \(2L\) bits. Standard exact integer multiplication and division therefore take polynomial time. Computing all quotients, computing \(D\), and scanning for the first \(D\) positive remainders requires only a number of arithmetic operations linear in \(k\).

Every output count satisfies \(0\le q_j\le T\), so the total output length is \(O(k\log(T+1))\), which is polynomial in \(k,L\). The algorithm never enumerates the periods. It consequently runs in time polynomial in \(m,\tau,k,L\), even when \(T\) is exponentially large in the remaining input parameters.

The cited paper states the related guarantee in Theorem 4.4 and uses floor rounding followed by unit increments in Appendix B.4. [Lodi, Sankaranarayanan, and Wang](https://arxiv.org/html/2212.10070v1#A2.SS4). The proof above independently establishes the exact mass-weighted construction and its binary-encoding complexity.
