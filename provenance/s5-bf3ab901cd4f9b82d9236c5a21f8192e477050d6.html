The anchor (named result in the paper)

Theorem 3.4 — class: algorithmic

The continuous mirror question, as graded

Given finitely many complete agent types \(T\) with masses \(\mu_t\), indivisible goods \(G\), monotone valuations \(v_t:2^G\to\mathbb{R}_{\ge0}\), and baseline per-capita supplies \(q_g\), define \(u_t\) as the largest value supportable for a unit mass of type \(t\) by an aggregate distribution over integral bundles under \(q\). Find \(y\ge0\) and masses \(z_{t,B}\ge0\) minimizing \(\sum_{g\in G}y_g\), subject to \(\sum_B z_{t,B}=\mu_t\), \(z_{t,B}>0\Rightarrow v_t(B)\ge u_t\), and \(\sum_{t,B\ni g}z_{t,B}\le q_g+y_g\) for every \(g\).

Packaged proof task (what the prover saw — nothing else)

Let \(G\) contain \(m\ge1\) indivisible goods. A society is given by its support: the list of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types.
Each type has a monotone valuation \(v_t:2^G\to\mathbb Q_{\ge0}\), with \(v_t(\varnothing)=0\), given by its complete table of bundle values. Baseline per-capita supplies \(q_g\in\mathbb Q_{>0}\) and budget \(K\in\mathbb Q_{\ge0}\) are binary encoded; \(L\) is the total input bit length, including valuation tables.
Define \(u_t\) as the largest \(a\ge0\) for which there exist bundle masses \(x_B\ge0\) satisfying \(\sum_{B\subseteq G}x_B=1\), \(\sum_{B\ni g}x_B\le q_g\) for every \(g\), and \(x_B>0\Rightarrow v_t(B)\ge a\). These benchmarks are defined from the input, not supplied separately.
An allocation consists of augmentation quantities \(y_g\ge0\) and masses \(z_{t,B}\ge0\), satisfying \(\sum_{B\subseteq G}z_{t,B}=\mu_t\), \(z_{t,B}>0\Rightarrow v_t(B)\ge u_t\), and \(\sum_t\sum_{B\ni g}z_{t,B}\le q_g+y_g\). Bundles are subsets, so each recipient receives at most one instance of each good; unused supply is permitted. Augmentation costs \(\sum_g y_g\).

Is deciding whether an allocation of cost at most \(K\) exists in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite societies with monotone valuations and supplied MMS partitions, a randomized polynomial-time algorithm achieves exact MMS using at most \(m/e\) total extra copies and \(O(\ln m/\ln\ln m)\) extra copies per good, with arbitrarily high success probability. [Source](https://arxiv.org/html/2502.09377v3).
For uniform supplies \(q_g=b\in(0,1]\), the benchmark \(u_t\) coincides with the anyprice share, whose fractional-partition characterization is known; this does not classify the augmentation problem above. [Source](https://arxiv.org/html/2503.10513).

Modeling choices made when packaging the task

  • Normalized society mass to one so that baseline per-capita supplies and aggregate allocation supplies use the same units.
  • Specified complete valuation tables with nonnegative binary-rational entries; the question did not specify a computational representation.
  • Carried over normalization of valuations at the empty bundle.
  • Took baseline supplies to be positive binary rationals, consistent with goods having positive original supply; no upper bound is imposed.
  • Interpreted the supportable benchmark as a guaranteed minimum value over positive-mass bundles, rather than expected utility, following the maximin benchmark.
  • Made benchmark computation part of the problem because the continuous question does not supply benchmarks or attaining distributions.
  • Allowed fractional nonnegative augmentation and unused supply, retaining the stated inequalities and the discrete allocation-with-copies convention.
  • Introduced a nonnegative binary-rational budget to express the exact minimization question as a decision problem.

Result

The problem is in \(\mathrm P\). In fact, every valid instance admits an allocation of cost \(\,0\).

This holds for arbitrary supported types and nonuniform supplies. The decisive feature is that the allocation permits fractional bundle masses: benchmark-achieving distributions for the individual types can be combined using the normalized type masses.

1. Each benchmark is attained

Fix a type \(\,t\), and let \(\,D_t=\{v_t(B):B\subseteq G\}\), a finite set of rational values.

Call a threshold \(\,a\ge0\) feasible if there is a distribution satisfying the constraints in the definition of \(\,u_t\). The threshold \(\,0\) is feasible: put all mass on \(\,\varnothing\).

Suppose \(\,a\) is feasible, witnessed by \(\,x\). Since \(\,\sum_Bx_B=1\), its support is nonempty. Therefore

\(\displaystyle d=\min\{v_t(B):x_B>0\}\)

exists, belongs to \(\,D_t\), and satisfies \(\,d\ge a\). The same distribution witnesses feasibility of \(\,d\).

Consequently, the largest feasible element of \(\,D_t\) exists and is at least every feasible threshold. It is exactly \(\,u_t\). In particular, there is a distribution \(\,x^{(t)}\) satisfying

\(\displaystyle x^{(t)}_B\ge0,\qquad \sum_{B\subseteq G}x^{(t)}_B=1,\)

\(\displaystyle \sum_{\substack{B\subseteq G\\g\in B}}x^{(t)}_B\le q_g\qquad(g\in G),\)

and \(\,x^{(t)}_B>0\Rightarrow v_t(B)\ge u_t\).

Thus the benchmark is achieved, rather than merely approached.

2. Combining the witnesses gives zero augmentation

Choose such a witness independently for every supported type. Define

\(\displaystyle z_{t,B}=\mu_t x^{(t)}_B,\qquad y_g=0.\)

We verify every allocation constraint.

Type masses. For every type \(\,t\),

\(\displaystyle \sum_{B\subseteq G}z_{t,B}=\mu_t\sum_{B\subseteq G}x^{(t)}_B=\mu_t.\)

Benchmark guarantees. Since \(\,\mu_t>0\), positivity of \(\,z_{t,B}\) implies positivity of \(\,x^{(t)}_B\). Hence \(\,v_t(B)\ge u_t\) whenever \(\,z_{t,B}>0\).

Supply bounds. For every good \(\,g\),

\(\displaystyle \sum_t\sum_{\substack{B\subseteq G\\g\in B}}z_{t,B} =\sum_t\mu_t\sum_{\substack{B\subseteq G\\g\in B}}x^{(t)}_B \le\sum_t\mu_t q_g =q_g,\)

where the final equality uses \(\,\sum_t\mu_t=1\).

All bundles remain subsets of \(\,G\), as required. The augmentation cost is \(\,\sum_gy_g=0\). Since augmentation quantities must be nonnegative, this also proves that the minimum cost is exactly \(\,0\).

3. Decision and constructive complexity

On inputs satisfying the stated hypotheses, the decision algorithm simply returns YES, because \(\,K\ge0\). Thus the decision problem is polynomial-time solvable without computing the benchmarks.

One can additionally compute all benchmarks and a rational allocation in polynomial time. Let \(\,N=2^m\). For each type and each distinct table value \(\,d\in D_t\), test feasibility of the rational linear system

\(\displaystyle x_B\ge0,\qquad \sum_{B\subseteq G}x_B=1,\qquad \sum_{\substack{B\subseteq G\\g\in B}}x_B\le q_g\quad(g\in G),\)

together with \(\,x_B=0\) for every bundle whose value is below \(\,d\).

The largest feasible candidate is \(\,u_t\), by Section 1. A feasible solution at that candidate supplies \(\,x^{(t)}\).

We use the standard rational linear-programming theorem: feasibility can be decided, and a rational feasible solution found when one exists, in time polynomial in the explicitly encoded system’s bit length. This is the bit-complexity guarantee provided by polynomial-time LP algorithms; see [MIT’s linear-programming algorithm notes](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html).

Here each system has \(\,N\) variables and polynomial encoding length in \(\,m,N,L\): its coefficients are input rationals or \(\,0,1\). There are at most \(\,\tau N\) feasibility tests. Because the input contains all \(\,\tau N\) valuation entries, \(\,\tau N=O(L)\). Thus the entire construction runs in time polynomial in \(\,m,\tau,L\). Multiplication by the input masses yields the rational allocation from Section 2 within the same polynomial bound.

4. Scope of the conclusion

The [cited finite-society augmentation result](https://arxiv.org/html/2502.09377v3) concerns assignments to individual agents. The present model allows each type’s mass to be split among bundles in arbitrary proportions. The proof above uses precisely that freedom and requires no rounding to individual assignments.

Accordingly, the stated fractional-mass problem is completely resolved.
