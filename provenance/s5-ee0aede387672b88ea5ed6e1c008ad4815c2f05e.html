The continuous mirror question, as graded

Given candidates \(C\), rankings \(\sigma_1,\ldots,\sigma_\tau\) with positive rational masses \(\mu_i\) summing to \(1\), and an output cap \(q\), output \(\min\{q, |\arg\min_{\pi\in\mathcal{L}(C)} \sum_{i=1}^{\tau}\mu_i d_{KT}(\pi,\sigma_i)|\}\) distinct rankings attaining the minimum.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set with \(m=|C|\), and let \(\mathcal L(C)\) denote its strict complete rankings.
A society is given by its support: \(\tau\) distinct rankings \(\sigma_i\), each with positive binary rational mass \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length.
Given a positive binary integer cap \(q\), define \(F(\pi)=\sum_{i=1}^{\tau}\mu_i d_{KT}(\pi,\sigma_i)\), using Kendall–tau distance, and \(K=\arg\min_{\pi\in\mathcal L(C)}F(\pi)\). Output \(\min\{q,|K|\}\) distinct members of \(K\); any selection and output order are allowed, with no tie-breaking restriction.
Define the unanimity order by \(a\succ_\rho b\) precisely when every support ranking places \(a\) before \(b\). Let \(G\) have vertex set \(C\) and an edge between distinct candidates precisely when they are incomparable in \(\rho\); unanimity width is \(w=\operatorname{pw}(G)\). No path decomposition is supplied.

Is this enumeration problem solvable in time polynomial in \(m,\tau,L,q\), or is it NP-hard?
If it is NP-hard, is it FPT in the combined parameter \((w,q)\), with running time \(f(w,q)\operatorname{poly}(m,\tau,L)\)?

For explicitly listed unweighted voters, distinct optimal enumeration admits time \(2^{O(w)}q\operatorname{poly}(m,n)\), where \(n\) is the number of voters ([De et al.](https://arxiv.org/pdf/2309.03517)).
Finding one unweighted Kemeny ranking is NP-hard even with four voters ([Bachmeier et al.](https://arxiv.org/pdf/1704.06304)). No result for exactly the rational-mass capped enumeration problem was located.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The problem is \(\mathrm{NP}\)-hard already for \(q=1\) and \(\tau\le4\). It is also fixed-parameter tractable in \((w,q)\), with running time \(2^{O(w)}q\operatorname{poly}(m,\tau,L)\), without a supplied path decomposition. The following proof handles the binary rational masses directly.

  • NP-hardness. Consider an instance with four explicitly listed unweighted votes \(\eta_1,\ldots,\eta_4\). Finding an optimal Kemeny ranking for such profiles is \(\mathrm{NP}\)-hard, by [Bachmeier et al., Theorem 4](https://arxiv.org/pdf/1704.06304).

Merge identical votes. For each distinct ranking \(\sigma_i\), let \(t_i\) be its multiplicity and set \(\mu_i=t_i/4\). These are positive binary rational masses summing to \(1\), and the resulting support has \(\tau\le4\). For every ranking \(\pi\),

\(\displaystyle F(\pi)=\frac14\sum_{j=1}^{4}d_{KT}(\pi,\eta_j).\)

Consequently, the two instances have exactly the same optimal rankings. Set \(q=1\). Any valid output supplies an optimal ranking for the original instance. The transformation has polynomial size, proving the claimed hardness. In particular, a polynomial-time algorithm in \(m,\tau,L,q\) would imply \(\mathrm P=\mathrm{NP}\).

  • Exact arithmetic and unanimity. Write \(\mu_i=a_i/b_i\), where \(a_i,b_i\) are positive integers. Define

\(\displaystyle D=\prod_{i=1}^{\tau}b_i,\qquad h_i=a_i(D/b_i).\)

Then \(h_i\) is an integer and \(\sum_i h_i=D\). For distinct candidates \(u,v\), define the integer cost of placing \(u\) before \(v\) by

\(\displaystyle c(u,v)=\sum_{i:\,v\succ_{\sigma_i}u}h_i.\)

Counting disagreements separately for every unordered candidate pair gives

\(\displaystyle \Phi(\pi):=DF(\pi)=\sum_{u\succ_\pi v}c(u,v).\)

Thus minimizing \(\Phi\) is equivalent to minimizing \(F\). The binary length of \(D\) is at most the sum of the denominator lengths, hence \(O(L)\). Moreover, \(0\le c(u,v)\le D\), and every ranking score is at most \(\binom m2D\). All arithmetic below therefore uses integers with \(O(L+\log m)\) bits; no voter expansion is required.

Every optimal ranking respects unanimity. To prove this, suppose \(a\succ_\rho b\) but a ranking \(\pi\) places \(b\) before \(a\). Obtain \(\pi'\) by exchanging their positions.

Fix a support ranking \(\sigma_i\). The disagreement on \(\{a,b\}\) decreases by \(1\). Candidates outside the segment between their positions contribute no change. For a candidate \(x\) inside that segment, the only possible orders in \(\sigma_i\), because \(a\succ_{\sigma_i}b\), are

\(\displaystyle x\succ_{\sigma_i}a\succ_{\sigma_i}b,\qquad a\succ_{\sigma_i}x\succ_{\sigma_i}b,\qquad a\succ_{\sigma_i}b\succ_{\sigma_i}x.\)

On the two pairs \(\{a,x\},\{b,x\}\), the total disagreement decreases by \(0,2,0\), respectively. Therefore

\(\displaystyle d_{KT}(\pi',\sigma_i)\le d_{KT}(\pi,\sigma_i)-1.\)

Summing with the masses gives \(F(\pi')\le F(\pi)-1\), so \(\pi\) cannot be optimal.

Define \(a\preceq b\) when \(a=b\) or \(a\succ_\rho b\). This is a partial order: it is the intersection of the support rankings’ precedence orders. We have proved that every member of \(K\) is a linear extension of \(\preceq\).

  • There are few possible prefix sets. An order ideal is a set \(I\subseteq C\) such that \(b\in I\) and \(a\preceq b\) imply \(a\in I\). Prefix sets of linear extensions are order ideals.

Let \(\mathcal I\) denote all order ideals. We will enumerate them without computing a path decomposition, using the bound

\(\displaystyle |\mathcal I|\le1+m2^w.\)

First, every nonempty induced subgraph of \(G\) has a vertex of degree at most \(w\). Indeed, restrict an existing width-\(w\) path decomposition of \(G\) to that induced subgraph. Choose a vertex \(v\) whose last bag index \(t\) is smallest. If \(u\) is a neighbor of \(v\), some bag of index at most \(t\) contains both. The last bag containing \(u\) has index at least \(t\). The interval property of path decompositions therefore puts \(u\) in bag \(t\). That bag contains \(v\) and all its neighbors, so \(v\) has degree at most \(w\).

Consequently, repeatedly removing a minimum-degree vertex produces, in polynomial time, an ordering \(v_1,\ldots,v_m\) in which each vertex has at most \(d\le w\) later neighbors. The algorithm computes this ordering directly from \(G\); the decomposition is used only to justify the bound.

Every nonempty clique has a unique earliest vertex \(v_j\), and all its other vertices belong to the later-neighbor set of \(v_j\). Enumerate every subset of that set and retain it precisely when its union with \(\{v_j\}\) is a clique. This enumerates every clique exactly once, using at most \(m2^d\) subset tests.

Antichains of \(\preceq\) are exactly cliques of \(G\). Furthermore, order ideals are in bijection with antichains: an ideal maps to its maximal elements, and an antichain \(A\) maps to

\(\displaystyle \downarrow A=\{x\in C:\text{ there exists }a\in A\text{ with }x\preceq a\}.\)

To verify the bijection, every element of a finite ideal lies below a maximal element, so \(I=\downarrow\operatorname{Max}(I)\). Conversely, \(\downarrow A\) is an ideal. Its maximal elements are exactly \(A\): each maximal element must equal some element of \(A\) above it, and an element of \(A\) cannot have a strictly larger element in \(\downarrow A\) without contradicting the antichain property.

Thus enumerate the empty ideal and the downward closures of the enumerated nonempty cliques. This constructs \(\mathcal I\) in \(2^{O(w)}\operatorname{poly}(m,\tau,L)\) time.

  • Dynamic programming over ideals. Construct a directed acyclic graph with vertex set \(\mathcal I\). For each \(I\in\mathcal I\), a candidate \(v\notin I\) is eligible when all its strict predecessors belong to \(I\). For every eligible candidate, add the edge

\(\displaystyle I\longrightarrow J=I\cup\{v\},\qquad g(I,v)=\sum_{u\in I}c(u,v).\)

Eligibility guarantees that \(J\) is an ideal. Every proper ideal has an eligible candidate: take a minimal element of its complement.

Paths from \(\varnothing\) to \(C\) correspond bijectively to linear extensions, by reading the appended candidates. The total edge cost equals \(\Phi\), because each candidate pair is charged exactly once, when its later member is appended.

Let \(H(I)\) be the minimum cost of a path from \(I\) to \(C\). Compute it in decreasing order of ideal cardinality:

\(\displaystyle H(C)=0,\qquad H(I)=\min_{\substack{v\notin I\\v\text{ eligible}}} \bigl(g(I,v)+H(I\cup\{v\})\bigr).\)

This recurrence is exact: the first edge chooses the next candidate, and its cost depends only on the set \(I\), not on the ordering of its elements. All successor states have already been computed.

By the unanimity argument, some global optimum—and indeed every global optimum—is represented by this graph. Hence \(H(\varnothing)=\min_\pi\Phi(\pi)\).

  • Enumeration with the required stopping rule. Retain an edge \(I\longrightarrow J=I\cup\{v\}\) precisely when

\(\displaystyle H(I)=g(I,v)+H(J).\)

Call such an edge tight. Every nonterminal state has a tight outgoing edge.

Every complete tight path has cost \(H(\varnothing)\), by telescoping these equalities. Conversely, for any complete path, its excess cost over \(H(\varnothing)\) is

\(\displaystyle \sum_{I\to J} \bigl(g(I,v)+H(J)-H(I)\bigr).\)

Each summand is nonnegative by the recurrence. An optimal path therefore has every summand equal to zero. Complete tight paths are consequently in bijection with \(K\).

Perform depth-first enumeration of complete tight paths, outputting their candidate sequences. Shared ideal states must be revisited for different prefixes; the traversal enumerates paths, not merely graph vertices. Distinct paths produce distinct rankings.

Stop immediately after \(q\) outputs, or when the traversal is exhausted. This outputs exactly \(\min\{q,|K|\}\) distinct optimal rankings. Exhaustion certifies that all optima have been output; no counting oracle is needed.

  • Running time. There are at most \(1+m2^w\) states and at most \(m\) outgoing edges per state. Ideal construction, edge construction, and dynamic programming therefore take \(2^{O(w)}\operatorname{poly}(m,\tau,L)\) time, including exact arithmetic.

If \(r=\min\{q,|K|\}\), the depth-first traversal visits at most \(1+mr\) nodes in its unfolded recursion tree. Every visited prefix extends to a complete tight path, and before termination every visited node is an ancestor of an emitted leaf. Scanning each node’s at most \(m\) outgoing edges takes \(q\operatorname{poly}(m,\tau,L)\) time.

To keep output counters short even when the binary cap is enormous, replace it by \(\min\{q,m!\}\); this preserves the requested output number and bounds counter lengths by \(O(m\log m)\). Reading the cap is covered by its input length.

The resulting total bound is

\(\displaystyle (2^{O(w)}+q)\operatorname{poly}(m,\tau,L) \ \subseteq\ 2^{O(w)}q\operatorname{poly}(m,\tau,L),\)

since \(q\ge1\). This proves the requested fixed-parameter tractability.
