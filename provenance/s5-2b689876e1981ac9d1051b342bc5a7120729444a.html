The continuous mirror question, as graded

Given a finite support \(T\) of types with rational masses \(\mu_t>0\) summing to \(1\), categories \(C\) with rational supply masses \(\rho_c\), and category-specific priority tiers, compute a rational assignment \(x_{tc}\). Each type records its eligibility and beneficiary status for each category, with \(B_c\subseteq E_c\). Require \(x_{tc}\ge 0\), \(\sum_c x_{tc}\le\mu_t\), \(\sum_t x_{tc}\le\rho_c\), and \(x_{tc}=0\) when \(t\notin E_c\). Let \(u_t=\mu_t-\sum_c x_{tc}\). For every category \(c\), require \(u_s=0\) whenever \(s\) has higher priority than \(t\) in \(c\) and \(x_{tc}>0\). Compute an assignment maximizing lexicographically \((\sum_{t,c}x_{tc},\sum_c\sum_{t\in B_c}x_{tc})\), with complexity measured in \(|T|\), \(|C|\), and the binary input length \(L\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) counts listed types, not all possible types. There are \(m=|C|\ge1\) categories, each with positive binary rational supply \(\rho_c\); supplies need not sum to \(1\).
Each category supplies an ordered partition of \(T\) into priority tiers and sets \(B_c\subseteq E_c\subseteq T\), both unions of initial tiers. Rankings across categories are independent. Types within a tier tie; write \(s\succ_c t\) for strictly higher priority. Individuals have unit demand and are indifferent among eligible categories.
A rational assignment satisfies \(x_{tc}\ge0\), \(\sum_c x_{tc}\le\mu_t\), \(\sum_t x_{tc}\le\rho_c\), and \(x_{tc}=0\) for \(t\notin E_c\). Define \(u_t=\mu_t-\sum_c x_{tc}\).
Respecting priorities means \(x_{tc}>0\) and \(s\succ_c t\) imply \(u_s=0\), for every \(c\) and \(s,t\). Ties impose no additional constraint.
Compute such an assignment lexicographically maximizing \(\bigl(\sum_{t,c}x_{tc},\sum_c\sum_{t\in B_c}x_{tc}\bigr)\) over assignments satisfying these constraints; any maximizer is acceptable.

Is this continuous optimization problem solvable in polynomial time in \(m,\tau,L\), where \(L\) is the total binary input length, or is it NP-hard?

For discrete unit-demand agents with strict category priorities and beneficiary and eligibility thresholds, IMMAM produces a priority-respecting assignment maximizing total assignments and then beneficiary assignments; its optimized implementation runs in \(O(qnm^4)\), with \(n\) agents and \(q\) units. [Source](https://arxiv.org/html/2309.13766v3).
No result settling this exact rational-mass problem was identified in the literature search.

Modeling choices made when packaging the task

  • Required nonempty support and category sets and strictly positive category supplies, carrying over the discrete universal-domain conditions.
  • Required beneficiary and eligibility sets to be unions of initial priority tiers, preserving the threshold structure rather than merely requiring set inclusion.
  • Interpreted the given priority tiers as ties among types, with no priority constraint within a tier and no additional tie-breaking.
  • Kept total society mass normalized to one; category supplies use the same units but have no normalization or scarcity restriction.
  • Made explicit unit demand, indifference among eligible categories, and acceptance of any lexicographic maximizer.

Result

The problem is solvable in polynomial time in \(m,\tau,L\). Three exact rational linear programs suffice.

The key is to optimize a third, auxiliary objective that rewards higher-priority assignments within each category. An exchange argument then proves that every optimizer of the three objectives respects priorities.

1. The linear relaxation and auxiliary objective

Let \(P\) be the set of assignments satisfying all the stated constraints except priority respect:

\(P=\left\{x\in\mathbb{R}_{\geq0}^{T\times C}:\ \sum_{c\in C}x_{tc}\leq\mu_t\ \text{for every }t,\quad \sum_{t\in T}x_{tc}\leq\rho_c\ \text{for every }c,\quad x_{tc}=0\ \text{if }t\notin E_c\right\}.\)

This is a nonempty rational polytope: the zero assignment belongs to it, and every coordinate satisfies \(0\leq x_{tc}\leq\mu_t\). Thus every linear objective attains its maximum on \(P\).

Define the two required objectives by

\(A(x)=\sum_{t\in T}\sum_{c\in C}x_{tc},\qquad B(x)=\sum_{c\in C}\sum_{t\in B_c}x_{tc}.\)

For each category \(c\), number its priority tiers from highest to lowest, starting at \(1\). Let \(r_c(t)\) be the tier containing \(t\), and put

\(w_{tc}=\tau-r_c(t),\qquad G(x)=\sum_{t\in T}\sum_{c\in C}w_{tc}x_{tc}.\)

The coefficients are nonnegative integers at most \(\tau-1\). Crucially,

\(s\succ_c t\quad\Longrightarrow\quad w_{sc}>w_{tc}.\)

No comparison of weights across different categories is needed.

2. Algorithm

Solve the following three linear programs exactly, in order:

  • Compute \(a^\star=\max\{A(x):x\in P\}\).
  • Compute \(b^\star=\max\{B(x):x\in P,\ A(x)=a^\star\}\).
  • Return any rational optimizer \(x^\star\) of

\(\max\{G(x):x\in P,\ A(x)=a^\star,\ B(x)=b^\star\}\).

Each feasible region is nonempty and compact. Each subsequent region contains an optimizer of the preceding program.

3. Proof of priority respect and optimality

Suppose, for contradiction, that the returned assignment violates priorities. Then there are \(c,s,t\) such that

\(s\succ_c t,\qquad x^\star_{tc}>0,\qquad u_s=\mu_s-\sum_{d\in C}x^\star_{sd}>0.\)

Set \(\delta=\min\{x^\star_{tc},u_s\}>0\). Construct \(y\) by changing only two coordinates:

\(y_{sc}=x^\star_{sc}+\delta,\qquad y_{tc}=x^\star_{tc}-\delta.\)

We first verify that \(y\in P\).

  • Nonnegativity: the decreased coordinate remains nonnegative because \(\delta\leq x^\star_{tc}\).
  • Type capacities: type \(s\)'s assigned mass increases by at most its unassigned mass, while type \(t\)'s assigned mass decreases. All other type totals are unchanged.
  • Category capacities: the total assigned through category \(c\) is unchanged, as are all other category totals.
  • Eligibility: positivity of \(x^\star_{tc}\) implies \(t\in E_c\). Since \(E_c\) is a union of initial tiers and \(s\succ_c t\), we also have \(s\in E_c\).

The exchange preserves the first objective:

\(A(y)-A(x^\star)=0.\)

Write \(b_{vc}=1\) when \(v\in B_c\), and \(b_{vc}=0\) otherwise. Since \(B_c\) is a union of initial tiers,

\(s\succ_c t\quad\Longrightarrow\quad b_{sc}\geq b_{tc}.\)

Consequently,

\(B(y)-B(x^\star)=\delta(b_{sc}-b_{tc})\geq0.\)

If this difference were positive, \(y\) would contradict the definition of \(b^\star\), because \(y\in P\) and \(A(y)=a^\star\). Therefore the difference is zero, and \(y\) belongs to the third program's feasible region.

But its auxiliary objective is strictly larger:

\(G(y)-G(x^\star)=\delta(w_{sc}-w_{tc})>0.\)

This contradicts the optimality of \(x^\star\) in the third program. Hence \(x^\star\) respects priorities.

Finally, every priority-respecting assignment belongs to \(P\). Therefore its total assignment is at most \(a^\star\); if its total assignment equals \(a^\star\), its beneficiary assignment is at most \(b^\star\). The returned assignment respects priorities and attains both values. It is thus a lexicographic maximizer for the original problem.

This also proves that imposing priority respect does not change the optimal pair of objective values.

4. Exact rational computation and complexity

The standard polynomial-time theorem for rational linear programming computes an exact rational optimum and optimal value for a nonempty bounded rational linear program, in time polynomial in its binary encoding length. Rational data can be converted to integer data by clearing denominators with polynomial encoding growth. See the [MIT lecture notes on the ellipsoid method and linear optimization](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

Here each program has \(m\tau\) variables and \(O(m\tau+m+\tau)\) constraints. The auxiliary coefficients require \(O(\log(\tau+1))\) bits each. Thus the first program has encoding length polynomial in \(m,\tau,L\).

The exact value \(a^\star\) returned by the first program has polynomial encoding length, so adding \(A(x)=a^\star\) preserves polynomial input size. The same argument applies to \(b^\star\) and the third program. Since there are only three programs, the total running time and output encoding length are polynomial in \(m,\tau,L\).

The argument handles ties, independent category rankings, empty beneficiary or eligibility sets, and arbitrary positive supplies. It uses the listed types directly, without expanding rational masses into individual agents.
