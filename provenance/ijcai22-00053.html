The continuous mirror question, as graded

Input: a finite candidate set \(C\), a fixed integer \(k\ge3\), and a sparse rational distribution \(\mu\) over \(T=\mathcal{L}(C)\), represented by its positive-mass complete-ranking types. Question: do there exist nonnegative allocations \(x_{t,j}\) and ordered binary trees \(B_1,\ldots,B_k\) on \(C\) such that \(\sum_{j=1}^{k}x_{t,j}=\mu_t\) for every \(t\in T\), and every type \(t\) with \(x_{t,j}>0\) is \(B_j\)-consistent?

Packaged proof task (what the prover saw — nothing else)

Definitions

Fix \(k\ge 3\). The input is a finite candidate set \(C\) and a sparse rational probability distribution \(\mu\) on \(\mathcal L(C)\), given by its support \(T=\{t\in\mathcal L(C):\mu_t>0\}\).
An ordered binary tree on \(C\) has its leaves bijectively labelled by \(C\). A ranking \(t\) is \(B\)-consistent if, at every internal node of \(B\), it ranks all leaves in one child subtree above all leaves in the other child subtree.
The instance is feasible if there are \(k\) such trees \(B_1,\ldots,B_k\) and nonnegative allocations \(x_{t,j}\) with \(\sum_{j=1}^k x_{t,j}=\mu_t\) for every \(t\in T\), such that \(x_{t,j}>0\) implies that \(t\) is \(B_j\)-consistent.

Target

For every fixed \(k\ge3\), is this feasibility problem NP-hard, or does it belong to \(\mathrm P\)?

Nearest known results

For every fixed \(k\ge3\), the finite-profile problem of partitioning voters into \(k\) group-separable subprofiles is NP-complete.

Complexity classification

Theorem

For every fixed \(k\ge 3\), the feasibility problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard and can belong to \(\mathrm P\) only if \(\mathrm P=\mathrm{NP}\).

The essential observation is that fractional splitting of a ranking type does not enlarge the set of feasible instances.

Feasibility depends only on the support

For a binary tree \(B\), let \(S(B)\) denote the set of rankings that are \(B\)-consistent.

Lemma 1

An instance with support \(T\) is feasible if and only if there exist \(k\) trees \(B_1,\ldots,B_k\) such that

\[ T\subseteq \bigcup_{j=1}^k S(B_j). \]

Proof

Suppose the instance is feasible. Fix \(t\in T\). Since \(\mu_t>0\) and

\[ \sum_{j=1}^k x_{t,j}=\mu_t, \]

there is at least one \(j\) with \(x_{t,j}>0\). Feasibility then implies that \(t\in S(B_j)\). Thus every ranking in \(T\) is covered by at least one tree.

Conversely, suppose the displayed covering condition holds. For every \(t\in T\), choose an index \(j(t)\) such that \(t\in S(B_{j(t)})\), and set

\[ x_{t,j(t)}=\mu_t,\qquad x_{t,j}=0\quad\text{for }j\ne j(t). \]

These allocations satisfy all constraints. Hence the instance is feasible. \(\square\)

Consequently, neither the magnitudes of the positive probabilities nor the possibility of splitting a ranking among several trees affects feasibility.

Connection with group-separable profiles

We use the standard tree characterization:

Lemma 2

A finite profile \(P\) is group-separable if and only if there is an ordered binary tree \(B\) such that every ranking in \(P\) is \(B\)-consistent.

Proof

Under the standard definition, a profile is group-separable if every candidate subset \(A\) with \(|A|\ge2\) admits a nontrivial partition \(A=A_1\mathbin{\dot\cup}A_2\) such that every voter ranks one of \(A_1,A_2\) entirely above the other.

Suppose first that all rankings are consistent with a tree \(B\). Given \(A\), let \(v\) be the lowest common ancestor of the leaves in \(A\). By minimality, \(A\) intersects both child subtrees of \(v\). Intersecting \(A\) with those two leaf sets gives a nontrivial partition respected by every ranking.

Conversely, apply group-separability to the full candidate set \(C\), obtaining a respected partition \(C=C_1\mathbin{\dot\cup}C_2\). Each restricted profile on \(C_i\) remains group-separable because the defining condition applies to every subset of \(C_i\). Recursively construct trees for \(C_1\) and \(C_2\), and attach them below a new root. Every ranking respects the root partition and is consistent with both recursively constructed subtrees. Induction on \(|C|\) completes the proof. \(\square\)

This is also Proposition 1 in Kraiczy and Elkind’s [IJCAI 2022 paper](https://www.ijcai.org/proceedings/2022/0053.pdf).

Reduction from finite-profile partitioning

Fix \(k\ge3\). The source problem is \(\mathrm{GS\ VOTER}\ k\text{-}\mathrm{PARTITION}\): given a finite profile, decide whether its voters can be partitioned into \(k\) group-separable subprofiles. Theorem 5 of the cited paper proves this problem \(\mathrm{NP}\)-complete for every fixed \(k\ge3\).

Let the input profile be

\[ P=(t_1,\ldots,t_n). \]

For each distinct ranking \(t\), let

\[ a_t=\bigl|\{i:t_i=t\}\bigr|. \]

Construct the sparse distribution with support

\[ T=\{t:a_t>0\} \]

and probabilities

\[ \mu_t=\frac{a_t}{n}. \]

The construction is polynomial-time: there are at most \(n\) supported rankings, and each numerator and denominator has \(O(\log n)\) bits.

Forward implication

Suppose \(P\) has a partition \(P_1,\ldots,P_k\) into group-separable subprofiles. By Lemma 2, each \(P_j\) has a witnessing tree \(B_j\).

Let \(a_{t,j}\) be the number of occurrences of ranking \(t\) in \(P_j\), and define

\[ x_{t,j}=\frac{a_{t,j}}{n}. \]

Then

\[ \sum_{j=1}^k x_{t,j} =\frac{\sum_j a_{t,j}}{n} =\frac{a_t}{n} =\mu_t. \]

Moreover, if \(x_{t,j}>0\), then \(P_j\) contains \(t\), so \(t\) is \(B_j\)-consistent. Thus the distributional instance is feasible.

Reverse implication

Suppose the distributional instance is feasible. By Lemma 1, every supported ranking \(t\) is consistent with at least one tree. Choose one such index \(j(t)\), and place every occurrence of \(t\) in the finite profile into group \(P_{j(t)}\).

Every ranking in \(P_j\) is then \(B_j\)-consistent, so Lemma 2 implies that \(P_j\) is group-separable. This gives a partition into at most \(k\) nonempty group-separable subprofiles.

If the source problem requires exactly \(k\) nonempty subprofiles, this causes no gap on profiles with \(n\ge k\). Whenever fewer than \(k\) groups are nonempty, some current group contains at least two voters: otherwise the number of voters would be smaller than \(k\). Move one voter from such a group into an empty group. A singleton profile is group-separable, and a subprofile of a group-separable profile remains group-separable. Repeating yields exactly \(k\) nonempty groups. The hard instances in the cited reduction satisfy \(n\ge k\).

Therefore the finite profile is a yes-instance if and only if the constructed distributional instance is feasible. This proves \(\mathrm{NP}\)-hardness.

Membership in NP

A certificate consists only of the \(k\) ordered binary trees. A tree with \(m=|C|\) leaves has \(2m-1\) nodes and therefore has a polynomial-size encoding.

For a ranking \(t\), let \(\operatorname{pos}_t(c)\) be the position of candidate \(c\). At an internal node whose child subtrees have leaf sets \(A\) and \(D\), the ranking is consistent at that node exactly when either

\[ \max_{a\in A}\operatorname{pos}_t(a) < \min_{d\in D}\operatorname{pos}_t(d) \]

or the same inequality holds with \(A\) and \(D\) interchanged.

Thus one can check in polynomial time whether \(t\) is consistent with a given tree. The verifier accepts precisely when every \(t\in T\) is consistent with at least one of the \(k\) certificate trees. By Lemma 1, this is equivalent to feasibility. No allocation values need to appear in the certificate.

Hence the problem belongs to \(\mathrm{NP}\), completing the \(\mathrm{NP}\)-completeness proof.

Step-by-step audit

1. Support-covering characterization

Lemma 1 is correct in both directions.

  • Since \(\mu_t>0\) and \(\sum_j x_{t,j}=\mu_t\), at least one allocation \(x_{t,j}\) is positive.
  • The feasibility implication then places \(t\) in \(S(B_j)\).
  • Conversely, a covering tree can receive the entire mass \(\mu_t\), yielding valid nonnegative allocations.

This proves that feasibility depends only on \(T\), not on the positive probability values or fractional splitting.

2. Group-separable tree characterization

Lemma 2 matches Proposition 1 of the cited paper: a profile is group-separable exactly when all its rankings are consistent with a common ordered binary tree. The cited source states the same definitions of group-separability and tree consistency and the same equivalence. [Kraiczy and Elkind, IJCAI 2022](https://www.ijcai.org/proceedings/2022/0053.pdf)

The supplied proof is sound:

  • For the forward direction, the lowest common ancestor of a candidate subset yields two nonempty intersections with its child subtrees, and tree consistency ensures that every ranking separates them.
  • For the reverse direction, the separating partition of \(C\), hereditary group-separability of the two restrictions, and induction construct the required tree.
  • Singleton candidate sets supply the routine induction base.

3. Source hardness result

The cited Theorem 5 does state that \(\mathrm{GS\ VOTER}\ k\text{-}\mathrm{PARTITION}\) is \(\mathrm{NP}\)-complete for every fixed \(k\ge3\). Its source instances contain at least \(k(k+2)\) specially introduced voters, so the prover’s assertion that the hard instances satisfy \(n\ge k\) is supported by the cited construction. [Theorem 5 and its construction](https://www.ijcai.org/proceedings/2022/0053.pdf)

4. Reduction

The construction is polynomial:

  • At most \(n\) distinct rankings enter the support.
  • Each probability \(a_t/n\) has polynomial bit length.
  • Identifying and counting duplicate rankings is polynomial in the explicit profile representation.

The forward implication is correct: voter multiplicities assigned to each group produce allocations \(x_{t,j}=a_{t,j}/n\), and Lemma 2 supplies the witnessing trees.

The reverse implication is also correct:

  • Lemma 1 assigns every distinct supported ranking to a compatible tree.
  • Placing all occurrences of that ranking in the corresponding group makes every resulting group consistent with one tree.
  • Lemma 2 therefore makes every group group-separable.

The treatment of exactly \(k\) nonempty groups is valid. If fewer than \(k\) groups are nonempty while \(n\ge k\), some group contains at least two voters. Moving one voter to an empty group preserves group-separability because the remaining profile is a subprofile and the new profile is a singleton. Repetition produces exactly \(k\) nonempty groups.

Thus duplicate rankings and the loss of multiplicity in the support do not invalidate the reduction.

5. Membership in \(\mathrm{NP}\)

The certificate and verification argument are correct.

  • For fixed \(k\), the \(k\) full ordered binary trees have polynomial encoding size.
  • The displayed maximum/minimum condition is equivalent to one child subtree being ranked entirely above the other.
  • Testing this at every internal node for every supported ranking is polynomial in the sparse input size.
  • Lemma 1 shows that allocation values need not be certified.

Therefore the problem belongs to \(\mathrm{NP}\), and the hardness reduction establishes \(\mathrm{NP}\)-completeness.
