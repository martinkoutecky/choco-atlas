The continuous mirror question, as graded

Given a finite support \(T\) of types with rational masses \(\mu_t\) summing to \(1\), a bundle set \(B=\prod_{r=1}^{R}\{0,\ldots,q_r\}\), rational valuations \(V_t:B\to\mathbb{Q}\), and per-capita supplies \(b_r\), choose nonnegative masses \(x_{t,a}\) to maximize \(\sum_{t\in T}\sum_{a\in B}x_{t,a}V_t(a)\), subject to \(\sum_{a\in B}x_{t,a}=\mu_t\) for every \(t\) and \(\sum_{t\in T}\sum_{a\in B}a_r x_{t,a}\le b_r\) for every resource \(r\). Return an optimal rational assignment, with each unit of mass receiving one integral bundle.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(R\geq 1\) resources, binary-encoded integers \(q_r\geq 0\), integral bundles \(B=\prod_{r=1}^{R}\{0,\ldots,q_r\}\), and nonnegative binary-rational per-capita supplies \(b_r\).
Each valuation \(V_t:B\to\mathbb{Q}\) is supplied as a complete explicit table; values may have either sign, with no monotonicity, concavity, or zero-bundle normalization required.
An assignment consists of rational masses \(x_{t,a}\geq 0\) satisfying \(\sum_{a\in B}x_{t,a}=\mu_t\) for every \(t\) and \(\sum_{t\in T}\sum_{a\in B}a_r x_{t,a}\leq b_r\) for every \(r\). Types may split their mass among bundles; each individual receives one integral bundle, and resources may remain unused.
The computational problem is to return any assignment maximizing \(\sum_{t\in T}\sum_{a\in B}x_{t,a}V_t(a)\). Write \(m=|B|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,R,L\).

Is this exact continuous allocation problem solvable in polynomial time in \(m,\tau,R,L\), or is it NP-hard?

For finite agents, joint-valuation aggregation finds a welfare-maximizing integral allocation; its stated worst-case operation count is \(O(nm^2)\) for \(n\) agents and \(m\) bundles ([Funaro, Agmon Ben-Yehuda, and Schuster](https://arxiv.org/pdf/1905.09014)).
The sources checked establish no result for this precise distribution-over-types formulation.

  • Resource domains were unspecified; take at least one resource, nonnegative integer bundle bounds, and nonnegative rational per-capita supplies.
  • Retain the graded question's signed rational valuations and impose no zero-bundle normalization: the general discrete optimization definition states no such restrictions.
  • Interpret assignments as permitting division of each type's mass among integral bundles, and accept any optimum when there are ties.

Result

The problem is exactly solvable in polynomial time in \(m,\tau,R,L\). The permission to split type masses makes the stated problem a rational linear program. Integrality of individual bundles does not impose integrality on the assignment variables.

1. The linear program

Set \(n=\tau m\). Introduce one variable \(x_{t,a}\) for each \(t\in T\) and \(a\in B\), and solve

\( \displaystyle \max \sum_{t\in T}\sum_{a\in B}V_t(a)x_{t,a} \)

subject to

\( \displaystyle \sum_{a\in B}x_{t,a}=\mu_t \qquad(t\in T), \)

\( \displaystyle \sum_{t\in T}\sum_{a\in B}a_r x_{t,a}\leq b_r \qquad(r=1,\ldots,R), \)

\( \displaystyle x_{t,a}\geq 0 \qquad(t\in T,\ a\in B). \)

Every coefficient is explicitly available: the objective coefficients come from the valuation tables, and each resource coefficient is a bundle coordinate.

These constraints are precisely the assignment constraints in the question. Initially allowing real variables gives a real linear program; Section 2 proves that it has a rational optimum, so this relaxation also solves the problem requiring rational assignments.

The feasible region is nonempty. Indeed, the zero bundle \(\mathbf 0\) belongs to \(B\), and the assignment \(x_{t,\mathbf 0}=\mu_t\), with all other variables zero, uses no resources.

It is also compact. Each variable satisfies \(0\leq x_{t,a}\leq\mu_t\), and the constraints define a closed set. Therefore the linear objective attains its maximum. Negative valuations cause no difficulty: feasibility and boundedness do not depend on their signs.

2. Exact rational optima have polynomial encoding length

Introduce nonnegative resource slacks \(s_r\), giving

\( \displaystyle \sum_{t,a}a_r x_{t,a}+s_r=b_r. \)

Write the resulting program as

\( \displaystyle \max c^\mathsf{T}z,\qquad Az=h,\qquad z\geq 0, \)

where \(z=(x,s)\), \(h=(\mu,b)\), and

\( \displaystyle k=\tau m+R,\qquad d=\tau+R \)

are the numbers of variables and equality constraints.

The matrix \(A\) has integral entries and row rank \(d\). To see this, select the column for \(x_{t,\mathbf 0}\) for each type and the column for each slack \(s_r\). Together these columns form the identity matrix of order \(d\).

The standard-form feasible region remains compact: besides the bounds on \(x\), nonnegative resource consumption implies \(0\leq s_r\leq b_r\).

Claim. There is an optimum whose positive coordinates correspond to linearly independent columns of \(A\).

Proof. Choose an optimum \(z\) with the smallest possible number of positive coordinates. If its positive-coordinate columns were dependent, there would be a nonzero vector \(v\), supported on those coordinates, with \(Av=0\). For sufficiently small positive \(\varepsilon\), both \(z+\varepsilon v\) and \(z-\varepsilon v\) would be nonnegative and feasible. Optimality consequently forces \(c^\mathsf{T}v=0\); otherwise one of these points would improve the objective.

Reverse the sign of \(v\), if necessary, so that it has a negative coordinate. Set

\( \displaystyle \lambda=\min_{i:v_i<0}\frac{z_i}{-v_i}>0. \)

Then \(z+\lambda v\) is feasible and optimal, has no new positive coordinates, and has at least one fewer positive coordinate. This contradicts the choice of \(z\). ∎

Extend these independent columns to a set \(I\) of \(d\) independent columns. The optimum has zero coordinates outside \(I\), and its coordinates on \(I\) satisfy

\( \displaystyle z_I=A_I^{-1}h. \)

In particular, they are rational.

For an explicit encoding bound, let \(D\) be the product of the denominators of the entries of \(h\). Because these denominators are part of the input, \(D\) has \(O(L)\) bits and \(Dh\) is integral. Put

\( \displaystyle Q=\max\{1,q_1,\ldots,q_R\},\qquad W=\max\{Q,\|Dh\|_\infty\}. \)

Both \(Q\) and \(W\) have \(O(L)\) bits. Cramer’s rule expresses each coordinate as

\( \displaystyle (z_I)_j=\frac{\det(A_I[j\leftarrow Dh])}{D\det(A_I)}, \)

where the numerator matrix replaces column \(j\) by \(Dh\). The determinant expansion gives

\( \displaystyle |\det(A_I)|\leq d!Q^d,\qquad |\det(A_I[j\leftarrow Dh])|\leq d!W^d. \)

Thus each numerator and denominator has \(O(d(L+\log(d+1)))\) bits. An exact optimal assignment therefore has polynomial encoding length.

The same argument also proves that some optimum has at most \(\tau+R\) positive type–bundle masses.

3. Polynomial-time algorithm and running time

Use the standard rational linear programming theorem: given an explicitly encoded rational linear program, a deterministic algorithm can report infeasibility or unboundedness, or return an exact rational optimum, in time polynomial in its binary encoding length. This is the polynomial-time linear programming result established by Khachiyan; the guarantee concerns exact rational optimization, rather than merely numerical approximation. See [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/eng/zvmmf5239).

All its hypotheses hold here:

  • The program has \(k=\tau m+R\) variables and \(d=\tau+R\) equality constraints, besides nonnegativity.
  • Every coefficient is rational and explicitly constructible.
  • The program is feasible and bounded, as proved above.

A coarse bound on its dense binary encoding length \(H\) is

\( \displaystyle H=O\!\left((\tau m+R+1)(\tau+R+1)(L+1)\right). \)

Indeed, there are \(O((k+1)(d+1))\) coefficient positions, and each coefficient has \(O(L+1)\) bits. Enumerating the \(m\) bundles and constructing the program also takes polynomial time in these parameters.

Consequently, construction, exact optimization, and output together take

\( \displaystyle \operatorname{poly}(\tau m+R,\tau+R,L)=\operatorname{poly}(m,\tau,R,L) \)

bit operations. This is a polynomial-time guarantee including binary coefficient lengths; no strongly polynomial bound is asserted.

Moreover, because each complete valuation table contains \(m\) explicitly encoded entries, \(\tau m=O(L)\) under ordinary binary encoding. The result is therefore polynomial in the actual input length as well.

4. Why finite-agent aggregation is not needed

The cited algorithm assigns an integral bundle to each finite agent and reports a worst-case operation count of \(O(nm^2)\). Its discrete allocation variables differ from the divisible mass variables here. See [Funaro, Agmon Ben-Yehuda, and Schuster, Sections 2–3](https://arxiv.org/pdf/1905.09014).

For example, take \(\tau=R=1\), \(\mu_1=1\), \(q_1=1\), \(b_1=1/2\), and valuations \(V_1(0)=0\), \(V_1(1)=1\). The present problem has the optimum

\( \displaystyle x_{1,0}=x_{1,1}=\frac12, \)

with welfare \(1/2\). Every individual still receives an integral bundle; half the population receives each bundle.

Thus the polynomial-time conclusion follows directly from the stated distribution-over-types formulation and rational linear programming. It does not require extending the finite-agent aggregation algorithm.
