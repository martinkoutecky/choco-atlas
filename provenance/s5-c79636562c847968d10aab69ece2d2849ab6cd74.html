The continuous mirror question, as graded

Given a fixed finite type set \(T\), rational utilities, and an anonymous rule \(F(r,\mu)\) with a finite rational polyhedral description, does there exist a finite-depth public protocol implementing \(F\) for every \(\mu\in\Delta(T)\)? Each query partitions the types of agents sharing a history, the protocol observes the exact answer masses, and OSP requires truthful outcomes to be weakly preferred to deviating outcomes across all compatible continuation distributions.

Packaged proof task (what the prover saw — nothing else)

Fix a nonempty finite type set \(T\), with \(k=|T|\) constant. Outcomes lie in \(\mathbb R^m\); each type has private-value utility \(u_t(x)=a_t^\top x+b_t\), with signed binary-rational coefficients and weak preferences.
An anonymous rule \(F:T\times\Delta(T)\to\mathbb R^m\) specifies an individual's outcome from their report and the population's reported distribution. Its input description explicitly lists \(p\) disjoint cells covering \(\Delta(T)\), defined by rational weak or strict linear inequalities, and a rational affine formula for each \(F(r,\cdot)\) on each cell; boundary assignments are included.
A rational society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational, with total mass \(1\). Here \(\tau\) is support size, not the number of possible types. Implementation is required throughout the real simplex, including its boundary; no particular society is supplied to the decision problem. State running times in \(m,p,L\) and support size \(\tau\le k\), using \(\tau=k\) for the universal problem, where \(L\) is the total binary input length.
Initially every individual has possible-report set \(T\). A deterministic public protocol selects a cohort sharing an answer history and partitions its current possible-report set into at least two nonempty cells. Every individual in that cohort answers a cell; the exact mass answering each cell is publicly observed, and each resulting cohort inherits that cell as its possible-report set. Queries may depend on the public transcript.
The protocol has a uniform finite depth, although exact mass observations may give infinitely many branches. At termination, the transcript and an individual's answer history determine their outcome; truthful play must yield \(F(t,\mu)\). An individual is nonatomic: a unilateral deviation changes their own history but no observed mass. Require implementation also for hypothetical zero-mass individuals of every type, retaining their possible histories even in zero-mass cohorts.
At a pre-query history \(h\), let \(D_h\) be all distributions generating its public transcript under truthful aggregate play. A query is OSP if, for every \(t,r\) in distinct answer cells and every \(\mu,\nu\in D_h\), \(u_t(F(t,\mu))\ge u_t(F(r,\nu))\). This compares truthful continuation with a deviation consistently reporting \(r\); subsequent answers must remain in the previously reported cell. The protocol is OSP when every query satisfies this condition.

Is deciding whether the given rule admits such a finite-depth OSP public protocol in \(\mathrm P\), or is it NP-hard, for fixed \(T\)?

For discrete anonymous payoff-table inputs with fixed type-set size, OSP implementability is decidable in polynomial time; with Boolean-circuit inputs, discrete OSP implementability is co-NP-complete ([Golowich–Li](https://arxiv.org/html/2101.05149v3)).
No result settling this exact mass-protocol decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted the fixed finite type set as a constant across instances, while allowing the outcome dimension and description length to vary.
  • Specified the undefined outcome and utility domains as real outcome vectors with rational affine private-value utilities; coefficients may have either sign and preferences are weak.
  • Interpreted a finite rational polyhedral rule description as an explicit piecewise-affine description, with a complete disjoint cell partition and specified boundary behavior.
  • Normalized total population mass to one; distinguished binary-rational society encodings from the universal implementation requirement over the entire real simplex.
  • Defined the report argument as an individual's report and the distribution argument as the reported population distribution; unilateral nonatomic deviations leave that distribution unchanged.
  • Specified cohort selection, nonempty proper partitions, nested answer histories, transcript-dependent queries, terminal outcomes, and a uniform finite depth allowing infinite branching from mass observations.
  • Required implementation for hypothetical individuals of every type even at zero population mass, so outcomes following reports absent from the population remain specified.
  • Defined compatible distributions using truthful aggregate histories and imposed the cross-distribution OSP inequalities at every query, with deviations consistently mimicking a remaining possible type.
  • Defined the decision input as the rule and utilities rather than a particular society; its support-size bound is the fixed type-set size.

Result

For every fixed finite type set \(T\), the decision problem is in \(\mathrm P\).

The algorithm below handles the entire real simplex, strict inequalities, discontinuous boundary assignments, and hypothetical individuals in zero-mass cohorts. It also constructs a succinct description of an implementing protocol whenever one exists.

Throughout, a cohort means the class of individuals sharing a given answer history, including the hypothetical histories retained in zero-mass cohorts.

1. Public histories reduce to partitions and their masses

Write \(k=|T|\). At any public history, the current possible-report sets form a partition \(\mathcal P\) of \(T\). This follows inductively: initially the partition is \(\{T\}\), and a query replaces one block by a partition of that block.

For each \(B\in\mathcal P\), let \(z_B\) be its publicly observed mass. Define

\(\displaystyle E_{\mathcal P}=\left\{z\in\mathbb R^{\mathcal P}:z_B\geq 0\text{ for every }B,\ \sum_{B\in\mathcal P}z_B=1\right\},\)

and

\(\displaystyle D(\mathcal P,z)=\left\{\mu\in\Delta(T):\sum_{t\in B}\mu_t=z_B\text{ for every }B\in\mathcal P\right\}.\)

Lemma 1. At every truthfully reachable public history with current partition \(\mathcal P\) and masses \(z\), its uncertainty set is exactly \(D(\mathcal P,z)\).

Proof. Every distribution generating the transcript necessarily has the specified masses on the current blocks.

Conversely, take \(\mu\in D(\mathcal P,z)\). Every block queried earlier is a union of current blocks. Therefore its mass, and the masses of all answers to that earlier query, are determined by \(z\). They equal the corresponding observations in the given transcript.

Induct along the transcript. At each step, all preceding observations agree, so determinism makes the protocol select the same query. The answer masses then agree by the preceding union-of-blocks argument. Thus \(\mu\) generates the whole transcript. This argument also applies when some masses are zero. \(\square\)

Every query increases the number of blocks by at least one. Consequently, every public path contains at most \(k-1\) queries. Infinitely many possible mass observations do not invalidate this bound.

2. It suffices to consider protocols that reveal every report

Call a protocol fully revealing if its terminal partition consists of singletons.

Lemma 2. An implementing OSP protocol exists if and only if a fully revealing implementing OSP protocol exists.

Proof. Only the forward implication requires proof.

Suppose an implementing protocol terminates at a history with state \((\mathcal P,z)\). For each block \(B\), the terminal transcript and the answer history corresponding to \(B\) specify one outcome, say \(y_B\).

Implementation, including implementation for hypothetical zero-mass individuals, implies

\(\displaystyle F(t,\mu)=y_B\qquad\text{for every }t\in B\text{ and every }\mu\in D(\mathcal P,z).\)

Indeed, such an individual has exactly that answer history under truthful reporting, even if its type has zero population mass.

Any further partition query inside \(B\) is therefore OSP: for any separated \(t,r\in B\) and any \(\mu,\nu\in D(\mathcal P,z)\),

\(\displaystyle u_t(F(t,\mu))=u_t(y_B)=u_t(F(r,\nu)).\)

After the query, each child uncertainty set is a subset of the previous one, so the same argument permits further refinement. Extend each terminal history until all blocks are singletons.

The extended protocol still implements \(F\), and every path still has at most \(k-1\) queries, because every added query strictly refines the partition. \(\square\)

At a fully revealing terminal history, the observed singleton masses identify \(\mu\), and the individual’s history identifies its report \(r\). Assigning outcome \(F(r,\mu)\) then implements the rule, including for zero-mass types.

3. OSP admissibility is a linear projection problem

Let \(C_1,\ldots,C_p\) be the input cells. On cell \(C_i\), write

\(\displaystyle F(r,\mu)=A_{r,i}\mu+c_{r,i}.\)

For \(t,r\in T\), define the rational affine function

\(\displaystyle v_{t,r,i}(\mu)=a_t^\top A_{r,i}\mu+a_t^\top c_{r,i}+b_t.\)

It equals \(u_t(F(r,\mu))\) on \(C_i\).

A query at partition \(\mathcal P\) replaces one block \(B\) by a partition into at least two nonempty blocks. Denote the resulting partition by \(\mathcal Q\).

For every ordered pair \(t,r\in B\) separated by this query, and every pair of input cells \(i,j\), define

\(\displaystyle \operatorname{Bad}_{\mathcal P,t,r,i,j}(z)\iff \exists\mu,\nu\ \left[ \mu\in D(\mathcal P,z)\cap C_i\ \land\ \nu\in D(\mathcal P,z)\cap C_j\ \land\ v_{t,r,j}(\nu)>v_{t,t,i}(\mu) \right].\)

All constraints inside this existential formula are rational linear equalities or weak or strict inequalities.

Let \(S_{\mathcal P,\mathcal Q}(z)\) assert that none of these bad events occurs:

\(\displaystyle S_{\mathcal P,\mathcal Q}(z)= \bigwedge_{\substack{t,r\text{ separated}\\\text{by the query}}} \ \bigwedge_{i,j=1}^{p} \neg\operatorname{Bad}_{\mathcal P,t,r,i,j}(z).\)

By Lemma 1 and the stated OSP definition, this predicate is exactly the condition that the query is OSP at state \((\mathcal P,z)\).

In particular, weak preferences are treated correctly: a violation requires a strict improvement. We use the actual cell constraints, so boundary assignments are also preserved exactly.

4. Exact projection is polynomial in fixed dimension

We need an algorithm for eliminating variables from Boolean combinations of linear inequalities. The fixed-dimensional restriction is essential.

Lemma 3. Fix a nonnegative integer \(d\). Given a quantifier-free Boolean formula \(\phi(x,y)\) in rational affine equalities and weak or strict inequalities, involving at most \(d\) real variables in total, one can construct a quantifier-free formula equivalent to \(\exists y\,\phi(x,y)\) in polynomial time and polynomial output length. The polynomial depends on \(d\).

Proof.

First consider a conjunction of linear constraints. Equalities can be replaced by two weak inequalities.

To eliminate one variable \(s\), normalize every constraint involving \(s\) into a lower or upper bound. Retain the constraints not involving \(s\). For every lower–upper pair, require that the lower bound be at most the upper bound; require strict inequality if either member of the pair is strict.

These pairwise conditions are necessary. They are also sufficient. For fixed remaining variables, a finite collection of lower bounds has a largest bound value, and a finite collection of upper bounds has a smallest bound value. If these values differ, choose a point between them. If they coincide, the pairwise conditions ensure that no bound attaining that common value is strict. If one side is absent, choose \(s\) sufficiently far in the unrestricted direction.

Thus elimination preserves strictness exactly. This is the Fourier–Motzkin construction, with the strict-bound rule just justified; the standard weak-inequality construction is described in [Cheung’s notes](https://people.math.carleton.ca/~kcheung/math/notes/MATH5801/02/2_1_fourier_motzkin.html).

Starting with \(N\) constraints, one elimination produces at most \(N^2+N\) constraints. Eliminating at most \(d\) variables therefore produces polynomially many constraints for fixed \(d\). Each elimination uses rational arithmetic of bounded depth, so coefficient bit lengths also remain polynomial in the input length. Eliminating all variables gives an exact feasibility test for a conjunction.

Now consider an arbitrary Boolean formula. Let \(\ell_1,\ldots,\ell_N\) be its distinct affine expressions. Their signs partition the ambient space into nonempty sets specified by

\(\displaystyle \ell_i<0,\qquad \ell_i=0,\qquad\text{or}\qquad \ell_i>0.\)

There are only \(O_d((N+1)^d)\) such sets, including all lower-dimensional ones. This is the usual all-faces bound for hyperplane arrangements; see [Matoušek’s lecture notes](https://kam.mff.cuni.cz/~matousek/kvg1-tb.pdf). The following counting argument explains why boundaries are included.

A sign set with affine-hull codimension \(j\) has its affine hull determined by some \(j\) independent zero hyperplanes. There are at most \(\binom Nj\) choices. Inside that affine hull, the sign set is a full-dimensional region of an arrangement in dimension \(d-j\). The region count is at most \(\sum_{i=0}^{d-j}\binom Ni\): adding one hyperplane creates no more regions than the arrangement induced on that hyperplane, giving this bound by induction. Summing over \(j\) gives \(O_d((N+1)^d)\).

These sign sets can be enumerated incrementally. Insert one affine expression at a time; split each existing set according to its three possible signs and discard infeasible pieces using the conjunction feasibility test above. At every stage there are polynomially many pieces, and every feasibility test is polynomial for fixed \(d\).

The truth value of \(\phi\) is constant on each sign set. Keep the sets on which it is true, project each corresponding conjunction by Fourier–Motzkin elimination, and take their disjunction. Projection commutes with finite union, so the resulting formula is equivalent to \(\exists y\,\phi(x,y)\).

Both the enumeration and the projected output have polynomial size and bit complexity for fixed \(d\). \(\square\)

Universal quantification can consequently be eliminated using

\(\displaystyle \forall y\,\psi(x,y)\iff\neg\exists y\,\neg\psi(x,y).\)

This lemma avoids expanding an arbitrary Boolean formula into all syntactically possible conjunctions: only realizable sign sets are enumerated.

5. Backward recursion over report partitions

For each partition \(\mathcal P\), we now construct a quantifier-free predicate \(W_{\mathcal P}(z)\). Its intended meaning is:

From public state \((\mathcal P,z)\), there is a fully revealing OSP continuation for every distribution in \(D(\mathcal P,z)\).

There are only finitely many partitions and possible queries, with their numbers depending solely on \(k\).

Let \(\mathcal P_*\) be the singleton partition. Set

\(\displaystyle W_{\mathcal P_*}(z)\iff z\in E_{\mathcal P_*}.\)

For a possible query \(\mathcal P\to\mathcal Q\), let \(R_{\mathcal P,\mathcal Q}(z,w)\) describe its feasible observations:

\(\displaystyle R_{\mathcal P,\mathcal Q}(z,w)\iff w\in E_{\mathcal Q}\ \land\ \bigwedge_{B\in\mathcal P} \left(z_B=\sum_{\substack{C\in\mathcal Q\\C\subseteq B}}w_C\right).\)

These are exactly the child mass vectors that can arise. To verify sufficiency, assign each mass \(w_C\) to any one type in the nonempty block \(C\). This gives a distribution in \(D(\mathcal P,z)\) producing those observations.

Process partitions in decreasing order of their number of blocks, and define

\(\displaystyle W_{\mathcal P}(z)\iff z\in E_{\mathcal P}\ \land\ \bigvee_{\mathcal P\to\mathcal Q} \left[ S_{\mathcal P,\mathcal Q}(z)\ \land\ \neg\exists w\, \left(R_{\mathcal P,\mathcal Q}(z,w)\land\neg W_{\mathcal Q}(w)\right) \right].\)

Use Lemma 3 to eliminate the existential variables at each stage.

The order of quantifiers here matters. The protocol must select one query at the current state, and that query must admit successful continuation after every feasible mass observation.

Lemma 4. The predicates \(W_{\mathcal P}\) have their stated meaning.

Proof. Induct on \(k-|\mathcal P|\).

For the singleton partition, the distribution and each report are already known, so assigning \(F(r,\mu)\) completes implementation.

For a nonsingleton partition, suppose a fully revealing OSP continuation exists. Its first query produces some \(\mathcal Q\). That query satisfies \(S_{\mathcal P,\mathcal Q}(z)\). Every feasible observation \(w\) occurs for some distribution in the current uncertainty set. After observing it, the protocol must have a fully revealing OSP continuation from \((\mathcal Q,w)\). By induction, \(W_{\mathcal Q}(w)\) holds. Hence the corresponding disjunct in the recursion is true.

Conversely, suppose the recursion is true. Select a query witnessing a true disjunct. It is OSP, and every feasible observation \(w\) satisfies \(W_{\mathcal Q}(w)\). The inductive hypothesis provides successful continuation.

For a concrete deterministic construction, fix an ordering of all queries at each partition and always select the first true disjunct. Repeating this prescription defines the protocol on all reachable real mass observations. Each query strictly refines the partition, so termination occurs after at most \(k-|\mathcal P|\) further queries. \(\square\)

6. Decision procedure and running time

The initial partition is \(\mathcal P_0=\{T\}\), and its only mass vector is \(z_T=1\). By Lemmas 2 and 4, the rule is implementable exactly when

\(\displaystyle W_{\mathcal P_0}(1)\)

is true.

The algorithm therefore performs the following finite computations:

  • Compute the rational affine payoff functions \(v_{t,r,i}\).
  • Compute all query-admissibility predicates \(S_{\mathcal P,\mathcal Q}\).
  • Compute the predicates \(W_{\mathcal P}\) by backward recursion.
  • Evaluate the root predicate.

The payoff coefficients require \(O(k^3pm)\) rational arithmetic operations, with polynomial bit complexity in \(L\).

Each bad-event projection uses at most \(3k\) real variables: two distributions and the current block masses. Each continuation projection uses at most \(2k\) variables: current and child block masses. Thus Lemma 3 applies in fixed dimension.

The number of partitions and query choices depends only on \(k\). There are at most \(k-1\) recursion levels, and each level performs polynomial-size projections of previously constructed polynomial-size formulas. Consequently, there are computable constants \(c_k,C_k\) such that the total bit running time and the length of the resulting protocol description are bounded by

\(\displaystyle c_k(1+m+p+L)^{C_k}.\)

This is a polynomial bound for every fixed \(T\). The exponent need not be small.

For the universal decision problem, the support parameter must be taken as \(\tau=k\). No society is supplied, and the uncertainty sets include distributions throughout the simplex. A smaller support in one observed society does not justify deleting possible types or their hypothetical histories.

If the constructed protocol is subsequently executed on a supplied rational society of support size \(\tau\), its mass observations can be computed with \(O(k\tau)\) rational additions over the whole path. Including predicate evaluation and outcome computation gives a bound of the form

\(\displaystyle c'_k(1+\tau)(1+m+p+L)^{C'_k},\)

where, for this execution bound, \(L\) includes the society’s binary encoding.

7. Conclusion

The complete characterization is the root condition \(W_{\{T\}}(1)\). It is decidable in polynomial time for fixed \(T\), and a true root condition supplies a deterministic OSP protocol of depth at most \(k-1\).

The argument uses exact linear projections throughout. It requires neither continuity nor positive mass in every cohort, and it preserves all weak and strict boundary conditions.
