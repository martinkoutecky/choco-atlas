The continuous mirror question, as graded

Given a finite set of complete interaction types \(T\), positive rational masses \(\mu_a\) summing to \(1\), binary type values \(w_{ab}\), an integer \(k\ge2\), and a rational threshold \(q\ge0\), decide whether there are allocations \(x_{a\ell}\ge0\) such that \(\sum_{\ell=1}^k x_{a\ell}=\mu_a\), \(\sum_{a\in T}x_{a\ell}=1/k\), and \(\sum_{b\in T}w_{ab}x_{b\ell}\ge q\) for every type \(a\) with \(x_{a\ell}>0\) in every coalition \(\ell\). Determine the complexity in the input bit length, number of types, and number of coalitions.

Packaged proof task (what the prover saw — nothing else)

A society is an atomless population given by its support: a nonempty list \(T\) of \(\tau=|T|\) types, with positive binary rational masses \(\mu_a\) satisfying \(\sum_{a\in T}\mu_a=1\). Here \(\tau\) counts supported types, not possible types.
The input explicitly specifies \(w_{ab}\in\{0,1\}\) for every ordered pair \(a,b\in T\), a binary integer \(k\ge2\), and a binary rational threshold \(q\ge0\). Values need not be symmetric; \(w_{aa}\) describes interactions between distinct individuals of the same type and may be either binary value. An individual's own mass is zero.
Types may be split among exactly \(k\) coalitions. An allocation consists of real masses \(x_{a\ell}\ge0\) satisfying \(\sum_{\ell=1}^k x_{a\ell}=\mu_a\) for every \(a\in T\) and \(\sum_{a\in T}x_{a\ell}=1/k\) for every \(\ell\in\{1,\ldots,k\}\).
A type-\(a\) individual's utility in coalition \(\ell\) is \(u_{a\ell}=\sum_{b\in T}w_{ab}x_{b\ell}\), without division by coalition mass. An allocation is feasible if \(u_{a\ell}\ge q\) whenever \(x_{a\ell}>0\).
Let \(L\) be the total input bit length. State running times in \(\tau,k,L\); there is no separate candidate or alternative parameter \(m\).

Is deciding whether such a feasible allocation exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite agents with binary directed values, deciding whether exactly \(k\) equally sized coalitions give every agent at least a specified positive integer utility is \(\mathrm{NP}\)-complete. [Source](https://arxiv.org/pdf/2001.10772)
No result settling this exact atomless, splittable-type decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted complete interaction types as an explicitly supplied directed binary interaction matrix, with no symmetry requirement.
  • Specified an atomless population and allowed arbitrary real allocation masses.
  • Interpreted diagonal values as interactions between distinct individuals sharing a type, allowing either binary value; exclusion of the individual herself removes zero mass.
  • Specified binary encoding of k and defined L as the total input bit length; this model has no separate m parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is \(\mathrm{NP}\)-hard, even when \(\,k=4\), \(\,q=1/4\), the values are symmetric, and every diagonal entry is \(1\). All masses in the reduction are positive dyadic rationals with \(O(\log \tau)\) bits. The restriction with \(\,k=4\) and \(\,q=1/4\) is \(\mathrm{NP}\)-complete.

1. A consequence of the maximum threshold.

For any allocation satisfying the coalition mass constraints,

\(u_{a\ell}=\sum_b w_{ab}x_{b\ell}=\frac1k-\sum_{b:w_{ab}=0}x_{b\ell}.\)

Consequently, when \(\,q=1/k\), feasibility implies

\(x_{a\ell}>0,\ x_{b\ell}>0\quad\Longrightarrow\quad w_{ab}=1.\)

Indeed, if \(\,w_{ab}=0\) and both masses were positive, then \(\,u_{a\ell}\le 1/k-x_{b\ell}<q\). Conversely, if this implication holds for every coalition and every ordered pair of supported types, every type present in a coalition has utility exactly \(\,1/k\).

Thus splitting types does not allow incompatible types to share a coalition at this threshold.

2. Polynomial reduction from graph coloring.

We use the standard \(\mathrm{NP}\)-completeness of graph \(3\)-colorability on finite simple undirected graphs. See [Garey, Johnson, and Stockmeyer, *Some simplified NP-complete graph problems*](https://doi.org/10.1016/0304-3975%2876%2990059-1).

Let \(\,G=(V,E)\) be an instance, with \(\,n=|V|\ge1\). Form a graph \(\,H\) by adding a vertex \(\,z\) adjacent to every vertex of \(\,G\). Write \(\,U=V\cup\{z\}\). Then

\(G\text{ is }3\text{-colorable}\quad\Longleftrightarrow\quad H\text{ is }4\text{-colorable}.\)

The forward implication assigns \(\,z\) a fourth color. For the reverse implication, the color of \(\,z\) cannot occur on any vertex of \(\,G\), leaving at most three colors for \(\,G\).

Construct the society as follows. Introduce one type for each vertex of \(\,H\), together with a filler type \(\,f\):

\(T=U\cup\{f\},\qquad \tau=n+2,\qquad k=4,\qquad q=\frac14.\)

Let \(\,M\) be the smallest power of two satisfying \(\,M\ge n+1\), and put

\(\varepsilon=\frac1{4M},\qquad \mu_a=\varepsilon\ \text{for }a\in U,\qquad \mu_f=1-(n+1)\varepsilon.\)

These masses sum to \(1\). They are positive, because \(\,\mu_f\ge3/4\), and are dyadic rationals.

For every ordered pair \(\,a,b\in T\), set \(\,w_{ab}=0\) precisely when \(\,a,b\in U\) are distinct adjacent vertices of \(\,H\). Set every remaining entry to \(1\). In particular, the values are symmetric,

\(w_{aa}=1\quad\text{for every }a\in T,\qquad w_{af}=w_{fa}=1\quad\text{for every }a\in T.\)

The diagonal convention is exactly the permitted atomless convention: an individual’s own mass is zero, while the remaining mass of their type contributes to utility.

3. Correctness of the reduction.

Suppose first that \(\,G\) is \(3\)-colorable, and extend its coloring to a proper coloring \(\,c:U\to\{1,2,3,4\}\) of \(\,H\).

Assign all of each vertex type to its color’s coalition:

\(x_{a\ell}=\varepsilon\ \text{if }c(a)=\ell,\qquad x_{a\ell}=0\ \text{otherwise}.\)

Let \(\,N_\ell=|\{a\in U:c(a)=\ell\}|\), and assign filler mass

\(x_{f\ell}=\frac14-N_\ell\varepsilon.\)

This is nonnegative because \(\,N_\ell\le n+1\le M\). Each coalition has mass \(1/4\), and the total filler assigned is

\(\sum_{\ell=1}^4x_{f\ell}=1-(n+1)\varepsilon=\mu_f.\)

Every vertex type present in a coalition values all mass in that coalition at \(1\): the coloring excludes adjacent vertices, its diagonal entry is \(1\), and it likes the filler. The filler also values all types at \(1\). Therefore every present type has utility \(1/4\), proving feasibility.

Conversely, suppose the constructed society has a feasible allocation, allowing arbitrary splitting of every type. For each \(\,a\in U\), choose one coalition \(\,c(a)\) with \(\,x_{a,c(a)}>0\). Such a coalition exists because \(\,\mu_a=\varepsilon>0\).

If adjacent vertices \(\,a,b\) of \(\,H\) received the same chosen coalition, both corresponding masses there would be positive while \(\,w_{ab}=0\). Section 1 rules this out. Thus \(\,c\) is a proper \(4\)-coloring of \(\,H\), and hence \(\,G\) is \(3\)-colorable.

This proves both directions, including allocations in which vertex types are split.

4. Encoding size and running times.

Since \(\,n+1\le M<2(n+1)\), every constructed mass has numerator and denominator of \(O(\log \tau)\) bits. The explicitly specified value matrix has \(\,\tau^2\) entries. Hence the output length satisfies

\(L=O(\tau^2+\tau\log\tau),\)

and the construction takes \(\,O(n^2+n\log n)\) bit operations using an adjacency matrix for the source graph. It is therefore a polynomial reduction.

For completeness, there is an exact support-enumeration algorithm taking

\(2^{\tau k}\operatorname{poly}(\tau,k,L)\)

time. For each guessed set \(\,S\subseteq T\times\{1,\ldots,k\}\), solve the rational linear feasibility problem consisting of the allocation constraints, together with

\(x_{a\ell}=0\quad\text{for }(a,\ell)\notin S,\)

\(\sum_b w_{ab}x_{b\ell}\ge q\quad\text{for }(a,\ell)\in S.\)

Each linear program has \(\,\tau k\) variables, polynomially many constraints in \(\,\tau,k\), and coefficients of polynomial bit length in \(\,L\). Rational linear programming therefore takes \(\,\operatorname{poly}(\tau,k,L)\) time.

This formulation is exact: a feasible allocation supplies its positive support as \(\,S\); conversely, every positive entry of a feasible linear-program solution belongs to \(\,S\) and satisfies its utility requirement. Marked entries need not be strictly positive.

For fixed \(\,k\), guessing \(\,S\) and checking this linear program gives an \(\mathrm{NP}\) algorithm. Thus the fixed \(\,k=4,\ q=1/4\) restriction is \(\mathrm{NP}\)-complete. The support-enumeration bound does not imply polynomial time in \(\,L\) when \(\,k\) is binary encoded.

5. Hardness also holds below the maximum threshold.

The same reduction works with the strictly smaller dyadic threshold

\(q'=\frac14-\frac{\varepsilon}{8}=\frac14-\frac1{32M}>0.\)

The forward allocation still gives every present type utility \(1/4\).

For the reverse direction, choose for each \(\,a\in U\) a coalition containing its largest assigned mass. Since its total mass is \(\,\varepsilon\), that coalition contains at least \(\,\varepsilon/4\) of type \(\,a\). If adjacent vertices \(\,a,b\) chose the same coalition \(\,\ell\), feasibility for type \(\,a\) would fail because

\(u_{a\ell}\le\frac14-x_{b\ell}\le\frac14-\frac{\varepsilon}{4}<q'.\)

The chosen coalitions again give a proper \(4\)-coloring of \(\,H\). Thus \(\mathrm{NP}\)-hardness also holds with \(\,0<q<1/k\).

Step-by-step verification

1. Maximum-threshold characterization

The identity
\[ u_{a\ell}=\frac1k-\sum_{b:w_{ab}=0}x_{b\ell} \]
follows exactly from the coalition mass constraint and binary values.

At \(q=1/k\), if \(x_{a\ell}>0\), feasibility forces the displayed sum of nonnegative terms to vanish. Thus any \(b\) with \(x_{b\ell}>0\) must satisfy \(w_{ab}=1\).

The converse is also correct: if every ordered pair of types present in a coalition has value \(1\), every present type values the entire coalition mass and receives utility \(1/k\).

This condition includes \(a=b\). Consequently, the argument respects the permitted diagonal convention rather than silently discarding within-type interactions.

Finding: Correct in both directions.

2. Source problem and graph transformation

The invoked theorem is that deciding proper \(3\)-colorability of finite simple undirected graphs is \(\mathrm{NP}\)-complete. This is supported by the cited [Garey–Johnson–Stockmeyer paper](https://www.sciencedirect.com/science/article/pii/0304397576900591). The reduction uses precisely this graph class.

Adding a universal vertex \(z\) gives the claimed equivalence:

  • A proper \(3\)-coloring of \(G\) extends by assigning \(z\) a fourth color.
  • In every proper \(4\)-coloring of \(H\), the color assigned to \(z\) is unavailable to all vertices of \(G\).

The restriction \(n\ge1\) causes no hardness issue: the excluded empty graph is a trivial yes-instance.

Finding: Correct; the source theorem’s hypotheses are satisfied.

3. Validity of the constructed society

The construction produces exactly \(\tau=n+2\) supported types. Since \(M\ge n+1\),
\[ 0<(n+1)\varepsilon\le\frac14, \qquad \mu_f=1-(n+1)\varepsilon\ge\frac34. \]
Every mass is therefore positive, and the masses sum to \(1\).

The value matrix is explicitly binary and symmetric. Its zero entries correspond exactly to adjacent distinct graph vertices. Every diagonal entry and every interaction involving the filler is \(1\).

Thus the constructed instance satisfies every input restriction, including the definition of \(\tau\) as the number of supported types.

Finding: Correct.

4. Forward implication

Each vertex type is assigned its full mass to its color’s coalition. The proposed filler amount satisfies
\[ x_{f\ell}=\frac14-N_\ell\varepsilon\ge0 \]
because \(N_\ell\le n+1\le M\).

The coalition masses are exactly \(1/4\), and the sum of the filler assignments equals \(\mu_f\). Proper coloring excludes every zero-valued vertex interaction within a coalition. Diagonal and filler interactions all have value \(1\), so every present type receives utility \(1/4\).

Zero filler mass in a coalition is harmless. All four coalitions still have positive mass \(1/4\), even if some color classes are empty.

Finding: The allocation satisfies all constraints.

5. Reverse implication under arbitrary splitting

Every vertex type has positive total mass, so it has a positive entry in at least one coalition. Choosing one such coalition for each vertex is valid without any assumption about rationality or unsplit allocations.

If adjacent vertices chose the same coalition, both would have positive mass there while their interaction value is \(0\). Section 1 excludes this possibility.

The chosen coalition indices therefore form a proper \(4\)-coloring of \(H\), yielding a proper \(3\)-coloring of \(G\).

Finding: Correct. Splitting does not invalidate the reduction.

6. Encoding and construction time

The bound
\[ n+1\le M<2(n+1) \]
is correct for the smallest admissible power of two. Vertex masses have denominator \(4M\), and the filler can be represented with numerator \(4M-(n+1)\) and denominator \(4M\). Their binary lengths are \(O(\log\tau)\).

The claimed output length
\[ L=O(\tau^2+\tau\log\tau) \]
accounts for the explicit value matrix and all masses. The stated construction time \(O(n^2+n\log n)\) bit operations is a valid polynomial upper bound for an adjacency-matrix source representation.

Finding: The reduction is polynomial in the source input length.

7. Support enumeration and fixed-\(k\) membership in \(\mathrm{NP}\)

The support formulation is exact:

  • Any feasible allocation satisfies the linear program corresponding to its positive support.
  • Any feasible solution of a guessed linear program satisfies the original utility requirement at every positive entry, since entries outside the guessed support are forced to zero.

Allowing guessed support entries to equal zero introduces no false positives.

The invoked rational linear-programming result applies: the constraints are non-strict linear equalities and inequalities with rational coefficients. There are \(\tau k\) variables, polynomially many constraints in \(\tau,k\), and coefficient lengths polynomial in \(L\). In particular, binary encoding of \(k\) does not prevent representing \(1/k\) with polynomially many bits.

The resulting enumeration bound is
\[ 2^{\tau k}\operatorname{poly}(\tau,k,L). \]
For fixed \(k\), the guessed support has polynomial length and its feasibility can be checked deterministically in polynomial time. This establishes the claimed \(\mathrm{NP}\) membership and hence the restricted \(\mathrm{NP}\)-completeness.

The prover correctly refrains from claiming general \(\mathrm{NP}\) membership from this certificate when \(k\) is binary encoded.

Finding: Correct.

8. Threshold strictly below the maximum

The proposed threshold satisfies
\[ q'=\frac14-\frac1{32M}>0, \qquad q'<\frac14. \]
The forward allocation remains feasible.

For the reverse implication, the largest of four assigned masses of a vertex type is at least \(\varepsilon/4\). If adjacent vertices choose the same coalition, both are present there, and feasibility for the first vertex contradicts
\[ u_{a\ell}\le\frac14-\frac{\varepsilon}{4} < \frac14-\frac{\varepsilon}{8} =q'. \]

The strict inequality and all constants are correct. This establishes hardness for instances satisfying \(0<q<1/k\); it does not assert hardness for every prescribed threshold in that interval.

Finding: Correct as stated.
