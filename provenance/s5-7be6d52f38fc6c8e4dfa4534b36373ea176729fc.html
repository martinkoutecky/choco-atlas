The continuous mirror question, as graded

Given a finite type set \(T\), positive rational masses \(\mu_t\) summing to \(1\), and a directed relation \(E\subseteq T\times T\) describing which type classes give feedback to which others, compute a total preorder \(\succeq\) on \(T\). For each target type \(u\), let \(\rho_u(t)=\mu_t\) when \((t,u)\in E\), and \(0\) otherwise. Require that whenever there is a transport \(\pi_{y,x}\ge 0\) from \(v\)'s supporter mass to \(u\)'s supporter mass, with \(\sum_x\pi_{y,x}=\rho_v(y)\), \(\sum_y\pi_{y,x}\le \rho_u(x)\), and \(\pi_{y,x}>0\) only when \(x\succeq y\), then \(u\succ v\) if the transport leaves some of \(u\)'s supporter mass unused or sends positive mass to a strictly higher-ranked type. The computational question is whether such a ranking can be found for every instance in time polynomial in \(|T|\) and the input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Types are also the alternatives being ranked, so \(m=\tau\); let \(L\) be the total input bit length.
The input includes an explicit positive-feedback relation \(E\subseteq T\times T\) with no self-loops. Set \(\rho_u(t)=\mu_t\) if \((t,u)\in E\), and \(\rho_u(t)=0\) otherwise; supporter mass is not normalized separately for each target.
A ranking is a total preorder \(\succeq\) on \(T\), with higher meaning better and ties permitted. For \(u,v\in T\), an admissible transport is a real matrix \(\pi\in\mathbb R_{\ge0}^{T\times T}\) satisfying \(\sum_{x\in T}\pi_{y,x}=\rho_v(y)\), \(\sum_{y\in T}\pi_{y,x}\le\rho_u(x)\), and \(\pi_{y,x}>0\Rightarrow x\succeq y\).
Such a transport is strict if \(\sum_{x\in T}(\rho_u(x)-\sum_{y\in T}\pi_{y,x})>0\) or \(\sum_{y,x\in T:\,x\succ y}\pi_{y,x}>0\). A ranking is valid if, for every \(u,v\in T\), existence of a strict admissible transport implies \(u\succ v\). No weak-monotonicity condition is imposed; empty supporter sets are allowed.

Does every instance admit a valid ranking? Is finding a valid ranking, or determining that none exists, solvable in polynomial time in \(m,\tau,L\), or is this problem NP-hard?

Discrete baseline: for finite loopless positive-feedback graphs, a ranking satisfying the analogous strict supporter-injection condition always exists and can be constructed in polynomial time. [Tennenholtz (2004)](https://arxiv.org/pdf/1207.4163)
No result settling this exact rational-mass transport version was located in the literature search.

Modeling choices made when packaging the task

  • The graded question omitted the prohibition on self-loops; imposed it on the type relation, following the discrete setting.
  • Made the transport domain explicit as nonnegative real matrices, allowing supporter mass to split.
  • The graded question presupposed universal existence; retained existence as a question and specified reporting nonexistence to define the computational problem without that presupposition.
  • Identified the alternative count m with the support size tau because the types themselves are ranked, and defined L as the total encoded input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Every instance admits a valid ranking. A valid ranking can be constructed in time polynomial in \(m,\tau,L\). The proof uses successive refinement of ties, with a cumulative-mass inequality certifying every strict comparison.

1. Exact characterization of transport.

Fix a total preorder \(P\), and list its nonempty rank classes from best to worst as \(C_1,\ldots,C_k\). Define the upper segments \(H_i=C_1\cup\cdots\cup C_i\), and the cumulative supporter masses

\(D_i^P(u)=\sum_{t\in H_i}\rho_u(t)\), for \(1\le i\le k\).

Also set \(D_0^P(u)=0\) and \(M(u)=D_k^P(u)=\sum_{t\in T}\rho_u(t)\).

Lemma. An admissible transport from the supporters of \(v\) into the supporters of \(u\) exists exactly when

\(D_i^P(u)\ge D_i^P(v)\) for every \(1\le i\le k\).

A strict admissible transport exists exactly when these inequalities hold and at least one is strict.

*Proof.* Suppose \(\pi\) is admissible, and define the unused capacity at \(x\) by

\(r_x=\rho_u(x)-\sum_{y\in T}\pi_{y,x}\ge0\).

Every supporter \(y\in H_i\) must be transported into \(H_i\), because its destination must rank at least as high as \(y\). Consequently,

\(D_i^P(u)-D_i^P(v)=\sum_{x\in H_i}r_x+\sum_{y\notin H_i,\ x\in H_i}\pi_{y,x}\ge0.\)

This proves necessity.

For sufficiency, process the demand classes \(C_1,\ldots,C_k\) in that order. When processing \(C_i\), allocate its demands using residual capacity in \(H_i\). All previously allocated demand lies in \(H_i\) and has total mass \(D_{i-1}^P(v)\). Thus the residual capacity available in \(H_i\) is

\(D_i^P(u)-D_{i-1}^P(v)\ge D_i^P(v)-D_{i-1}^P(v)=\sum_{y\in C_i}\rho_v(y).\)

Because mass is divisible, this inequality permits allocating all demands in \(C_i\), respecting each individual capacity. Explicitly, repeatedly allocate the minimum of a remaining demand and a remaining capacity until all demands in the class are filled. Every destination in \(H_i\) ranks at least as high as every source in \(C_i\). The resulting matrix is admissible.

It remains to characterize strictness. If some capacity is unused, the displayed identity for \(i=k\) gives \(D_k^P(u)>D_k^P(v)\). If a positive amount moves from \(y\) to a strictly higher \(x\), some upper segment contains \(x\) and excludes \(y\); the identity gives a strict inequality at that segment.

Conversely, if an inequality is strict, the identity shows that any admissible transport has either positive unused capacity or positive transport across an upper-segment boundary. Crossing such a boundary is a strict improvement. Hence the transport is strict. \(\square\)

In particular, identical cumulative profiles preclude strict transport in either direction.

2. The refinement algorithm.

Start with the preorder \(P_0\) in which all types are tied.

Given the current preorder \(P\), with classes \(C_1,\ldots,C_k\), assign each target the signature

\(s_P(u)=\bigl(M(u),D_1^P(u),\ldots,D_{k-1}^P(u)\bigr).\)

For \(k=1\), this signature consists only of \(M(u)\).

Within each current rank class, group targets with identical signatures and order these groups by descending lexicographic order of their signatures. Preserve the order between distinct current classes. This produces a new total preorder \(P'\) refining \(P\).

Repeat until a round makes no change, then output the current preorder.

The one-sided validity condition permits these lexicographic splits. Their correctness follows from the invariant proved next.

3. An invariant protecting every strict comparison.

At every stage, the following property holds:

For every pair \(u\succ_P v\), there is an upper segment \(H\) of \(P\), possibly \(T\) itself, such that

\(\sum_{t\in H}\rho_u(t)>\sum_{t\in H}\rho_v(t).\)

*Proof by induction.* Initially there are no strict comparisons, so the property holds vacuously.

Suppose it holds for \(P\), and consider the refinement \(P'\).

If \(u\succ_P v\), its witnessing upper segment remains an upper segment of \(P'\): each old class is subdivided into consecutive classes, and their relative order is preserved. The same mass inequality therefore remains a witness.

Otherwise, a new comparison \(u\succ_{P'}v\) arises within a single old class. Descending lexicographic order means that the first differing coordinate of \(s_P(u)\) and \(s_P(v)\) is larger for \(u\). If this coordinate is \(M\), take \(H=T\). If it is \(D_i^P\), take \(H=H_i\). In either case the required strict mass inequality holds, and this old upper segment remains an upper segment after refinement. This covers every strict comparison in \(P'\). \(\square\)

By the transport lemma, this invariant has the following consequence: whenever \(u\succ_P v\), there cannot be an admissible transport from the supporters of \(u\) into the supporters of \(v\). Such a transport would require the reverse weak inequality at the witnessing upper segment.

Thus later refinements cannot create a transport requirement contradicting an established strict comparison.

4. Termination and validity.

Every round that changes the ranking splits at least one class, increasing the number of classes. There are initially one and at most \(m\) classes. Therefore there are at most \(m-1\) changing rounds and one final unchanged round.

Let \(P_*\) be the output. Consider any ordered pair \(u,v\) for which a strict admissible transport from \(v\)'s supporters into \(u\)'s supporters exists.

There are three possible relations between the targets:

  • If \(u\succ_{P_*}v\), the required conclusion already holds.
  • If \(v\succ_{P_*}u\), the invariant supplies an upper segment where \(v\)'s supporter mass exceeds \(u\)'s. The transport lemma then rules out even an admissible transport from \(v\)'s supporters into \(u\)'s.
  • If \(u\) and \(v\) are tied, termination implies \(s_{P_*}(u)=s_{P_*}(v)\). These signatures include every cumulative mass, with \(D_k^{P_*}=M\). The transport lemma therefore rules out strict transport.

Only the first case is possible. Hence \(P_*\) is valid.

This argument also covers empty supporter sets and \(m=1\).

5. Polynomial bit complexity.

Write each input mass as \(\mu_t=p_t/q_t\), with binary integers \(p_t,q_t>0\). Define

\(Q=\prod_{t\in T}q_t\), and \(w_t=p_t(Q/q_t)\).

The bit length of \(Q\) is at most the sum of the denominator bit lengths, hence is \(O(L)\). Since \(\sum_t\mu_t=1\), we have \(\sum_t w_t=Q\). Every cumulative supporter mass can therefore be represented exactly as an integer between \(0\) and \(Q\), divided by the common denominator \(Q\).

Comparing signatures requires only comparing these \(O(L)\)-bit integer numerators. No enumeration of the numerical mass units is involved.

In each round:

  • Accumulating supporter weights by rank class and computing all cumulative profiles requires \(O(m^2)\) integer additions.
  • Sorting within the current classes requires \(O(m\log(m+1))\) signature comparisons, each inspecting at most \(m\) integer coordinates.

There are at most \(m\) rounds. Using ordinary binary arithmetic, one resulting bit-operation bound is

\(O\bigl(mL^2+m^3L\log(m+1)\bigr).\)

The first term covers computing the common denominator and integer weights. Since \(m=\tau\), this is polynomial in all the requested input parameters.

Thus existence always holds, and the construction problem is polynomial-time solvable.

Conversely, a strict cumulative inequality forces either positive unused capacity within that segment or positive transport into it from outside. The former implies positive total unused capacity; the latter is necessarily transport to a strictly higher class. Thus any admissible transport is strict whenever at least one cumulative inequality is strict.

Identical cumulative profiles therefore exclude strict transport in either direction, exactly as claimed.
