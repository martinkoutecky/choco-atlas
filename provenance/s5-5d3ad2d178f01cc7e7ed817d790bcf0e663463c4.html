The continuous mirror question, as graded

Given \(n\) alternatives, \(C\) constituencies, positive weights \(\lambda_k\), and for each constituency \(k\) a finite support \(\mathcal T_k \subseteq S_n\) with positive binary-rational masses \(\mu_k(\sigma)\) summing to \(1\), return a permutation \(\pi\) satisfying \(\max_{k\in[C]} \lambda_k \sum_{\sigma\in\mathcal T_k}\mu_k(\sigma)d_\tau(\pi,\sigma) \le 2\min_{\rho\in S_n}\max_{k\in[C]} \lambda_k \sum_{\sigma\in\mathcal T_k}\mu_k(\sigma)d_\tau(\rho,\sigma)\).

Packaged proof task (what the prover saw — nothing else)

There are \(m\geq 1\) alternatives and \(C\geq 1\) constituencies, with positive binary-rational weights \(\lambda_k\). Types are strict complete rankings in \(S_m\); \(d_\tau\) denotes Kendall tau distance.
Each constituency society is given by its support: a nonempty list \(\mathcal T_k\subseteq S_m\) of types with positive binary-rational masses \(\mu_k(\sigma)\), summing to \(1\). Write \(\tau_k=|\mathcal T_k|\) and \(\tau=|\bigcup_k\mathcal T_k|\); these count supported types, not all possible rankings. Let \(L\) be the total input bit length. State running times in \(m,\tau,C,L\).
For a single output permutation \(\pi\in S_m\), define \(F(\pi)=\max_{1\leq k\leq C}\lambda_k\sum_{\sigma\in\mathcal T_k}\mu_k(\sigma)d_\tau(\pi,\sigma)\) and \(\mathrm{OPT}=\min_{\rho\in S_m}F(\rho)\).

Is there a deterministic algorithm, polynomial in \(m,\tau,C,L\), that always returns \(\pi\in S_m\) with \(F(\pi)\leq 2\mathrm{OPT}\), or is achieving this approximation guarantee NP-hard?

For finite classes with uniform masses, a deterministic polynomial-time factor \(2\) approximation is established by [Li–Milenkovic, 2017](https://arxiv.org/pdf/1701.08305v1).
No result specifically settling this guarantee for arbitrary binary-rational constituency masses was located.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

A deterministic polynomial-time factor \(2\) approximation exists for arbitrary positive binary-rational masses. The proof extends the Pick-Opt-Perm observation in [Li–Milenkovic (2017)](https://arxiv.org/pdf/1701.08305v1) using only the triangle inequality and normalization of each constituency’s masses.

For \(m=1\), every objective value is zero. The algorithm below also covers this case.

Algorithm

Write \(f_k(\pi)=\sum_{\sigma\in\mathcal T_k}\mu_k(\sigma)d_\tau(\pi,\sigma)\), so \(F(\pi)=\max_k\lambda_k f_k(\pi)\).

  • Choose \(k_0\) with \(\lambda_{k_0}=\max_k\lambda_k\), breaking ties by constituency index.
  • Evaluate \(F(\sigma)\) exactly for every \(\sigma\in\mathcal T_{k_0}\).
  • Return a candidate \(\widehat\pi\) minimizing these values, breaking ties lexicographically.

The algorithm evaluates the original rational masses directly.

Proof of the approximation guarantee

An optimal permutation \(\pi^\star\) exists because \(S_m\) is finite. Put \(\Lambda=\lambda_{k_0}>0\). By the definition of the objective,

\(\sum_{\sigma\in\mathcal T_{k_0}}\mu_{k_0}(\sigma)d_\tau(\sigma,\pi^\star)=f_{k_0}(\pi^\star)\leq\mathrm{OPT}/\Lambda\).

The masses are positive and sum to \(1\). Consequently, some \(\sigma_0\in\mathcal T_{k_0}\) satisfies \(d_\tau(\sigma_0,\pi^\star)\leq\mathrm{OPT}/\Lambda\): otherwise their weighted average would exceed that bound.

For every constituency \(k\), the triangle inequality, multiplied by each mass and summed, gives

\(f_k(\sigma_0)\leq d_\tau(\sigma_0,\pi^\star)+f_k(\pi^\star)\).

Here the first term has coefficient \(1\) because \(\sum_{\sigma\in\mathcal T_k}\mu_k(\sigma)=1\). Thus, using \(\lambda_k\leq\Lambda\),

\(\lambda_k f_k(\sigma_0)\leq\Lambda d_\tau(\sigma_0,\pi^\star)+\lambda_k f_k(\pi^\star)\leq\mathrm{OPT}+\mathrm{OPT}=2\mathrm{OPT}\).

Taking the maximum over \(k\) proves \(F(\sigma_0)\leq2\mathrm{OPT}\). Since \(\widehat\pi\) minimizes \(F\) over a candidate set containing \(\sigma_0\), it follows that \(F(\widehat\pi)\leq2\mathrm{OPT}\). This proof also applies when \(\mathrm{OPT}=0\).

Running time and exact arithmetic

There are at most \(\tau\) candidates and at most \(C\tau\) support entries overall. Each Kendall distance can be computed by checking the relative order of all alternative pairs, using \(O(m^2)\) elementary operations. Hence direct evaluation requires \(O(C\tau^2m^2)\) such distance operations and \(O(C\tau^2)\) rational arithmetic operations.

For an explicit conservative bit bound, let \(B=L+\lceil\log_2(m+C+\tau+2)\rceil\). Accumulate each \(f_k(\sigma)\) using reduced fractions, then multiply by \(\lambda_k\). Every intermediate denominator divides the product of the relevant input denominators, whose total binary length is at most \(L\). Every partial distance average lies between \(0\) and \(\binom m2\). These facts bound intermediate numerators and denominators, including weighted scores and comparison products, by \(O(B)\) bits.

Elementary integer arithmetic and fraction reduction therefore give the conservative running time \(O\!\left(L+C\tau^2m^2B^3\right)\), which is polynomial in \(m,\tau,C,L\). In particular, no expansion into a potentially exponential number of equally weighted copies is required.
