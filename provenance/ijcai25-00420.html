The continuous mirror question, as graded

Given a finite set of organization types \(\Theta\), rational masses \(\mu_\theta\), machine counts \(m_\theta\), job multiplicities \(q_{\theta,p}\), and target \(T\), let \(\ell^{\max}_\theta\) be each type's optimal private-machine makespan. Does there exist a measurable nonpreemptive schedule on pooled atomless machine mass \(M=\sum_\theta \mu_\theta m_\theta\) that schedules the complete job bundle of almost every type-\(\theta\) organization by \(\ell^{\max}_\theta\) and has essential-supremum completion time at most \(T\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(\Theta\) of \(\tau\) organization types with positive binary-rational masses \(\mu_\theta\), summing to \(1\); \(\tau\) counts supported types, not possible types.
Each type owns \(m_\theta\geq1\) identical unit-speed machines and a nonempty bundle containing \(q_{\theta,p}\in\mathbb Z_{\geq0}\) independent sequential jobs of positive integer duration \(p\). List the nonzero multiplicities; encode durations, multiplicities, machine counts, and the nonnegative integer target \(T\) in unary. Let \(p_{\max}\) be the largest listed duration, \(m=\sum_\theta m_\theta\), and \(L\) the total input bit length.
Let \(\ell^{\max}_\theta\) be the optimal nonpreemptive makespan of this finite bundle on its own \(m_\theta\) machines, with all jobs available at time \(0\); these optima are defined by the input, not supplied separately.
Represent type-\(\theta\) organizations by \([0,\mu_\theta)\) and pooled machines by \([0,M)\), where \(M=\sum_\theta\mu_\theta m_\theta\), with Lebesgue measure. Each organization has every labelled job copy in its bundle.
A schedule is a measurable family of finite job-slot lists on pooled machines, together with a measure-preserving bijection, modulo null sets, between job copies and slots; job-copy measure is organization measure times counting measure, and slot measure is machine measure times counting measure. Matched durations agree. Each slot occupies one uninterrupted interval beginning at a nonnegative real time; intervals on each machine are disjoint, with endpoint contact allowed.
The decision problem asks whether such a schedule completes the entire bundle of almost every type-\(\theta\) organization by \(\ell^{\max}_\theta\) and has essential-supremum completion time at most \(T\).
State running times in \(m,\tau,L,p_{\max},T\).

Is this continuous decision problem in \(\mathrm P\) or \(\mathrm{NP}\)-hard? If it is \(\mathrm{NP}\)-hard, is it FPT parameterized by \(p_{\max}+\tau\)?

The discrete problem is FPT parameterized by \(p_{\max}+k\), where \(k\) counts organizations; its decision version is \(\Theta_2^{\mathrm P}\)-complete, hence \(\mathrm{NP}\)-hard, and is reported \(\mathrm{W}[1]\)-hard parameterized by the total number of machines ([Chen–Durand–Hatschka](https://arxiv.org/html/2505.12377v1)).
No result settling exactly the continuous problem above was located.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, interpreting the society as a distribution over organization types.
  • Required positive integer processing times, positive integer private machine counts, and nonempty job bundles so that private makespans are well-defined.
  • Retained unary encoding for the discrete numerical data and target, while using the required binary encoding for rational masses; multiplicities explicitly specify the finite bundle.
  • Defined private makespans using finite indivisible jobs on integer private machine counts; their values are not additional input.
  • Made atomless scheduling precise through measure-preserving matching of complete labelled job copies to machine slots, preventing loss or concentration of job mass.
  • Allowed nonnegative real start times in the continuous schedule and imposed actual interval nonoverlap, following the intended scheduling condition rather than the erroneous absolute-completion-time inequality, which persists in the full version.
  • Defined m as the sum of machine counts across supported types, distinguished it from pooled machine mass M, and used support size tau in place of organization count for the combined parameter.

1. Classification

Under polynomial-time many-one reductions, the continuous decision problem is \(\mathrm{coNP}\)-complete, even for \(\tau=3\) and fixed dyadic masses. It is also FPT parameterized by \(p_{\max}\) alone, hence by \(p_{\max}+\tau\).

Thus the proposed \(\mathrm P\)-versus-\(\mathrm{NP}\)-hard dichotomy needs qualification:

  • The problem belongs to \(\mathrm P\) if and only if \(\mathrm P=\mathrm{NP}\).
  • It is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions if and only if \(\mathrm{NP}=\mathrm{coNP}\).
  • Under polynomial-time Turing reductions, it is \(\mathrm{NP}\)-hard unconditionally.

The proofs follow.

2. Pooled feasibility with supplied deadlines is polynomial-time solvable

Temporarily replace the implicit local optima by supplied nonnegative integer deadlines \(d_\theta\). Require every type-\(\theta\) job to finish by \(d_\theta\), and every job to finish by \(T\).

Write \(D\) for the number of listed pairs \((\theta,p)\). Then \(D\leq\tau p_{\max}\).

2.1 Integer-time machine patterns suffice

Take a feasible measurable schedule. Discard the null sets permitted in the definition. On each remaining machine, order its slots chronologically and remove all idle time while preserving that order.

If the ordered durations are \(p_1,\ldots,p_s\), the new completion time of slot \(j\) is \(\sum_{i=1}^j p_i\). This is no larger than its original completion time: the original schedule starts nonnegatively and contains these preceding, disjoint intervals. Consequently, compression preserves all deadlines.

All new start and completion times are integers. Compression is measurable because it acts on finite measurable slot lists using finite sums.

To justify discarding exceptional slots, each type has finitely many labelled jobs. A null set of exceptional organizations therefore produces a null set of job copies. The measure-preserving matching sends it to a null set of slots. Since slot measure uses counting measure on each machine’s list, almost every machine contains no exceptional slot.

2.2 A polynomial-size linear program

If \(T=0\), the answer is no because every supported bundle is nonempty and all durations are positive. Assume \(T\geq1\).

Construct a directed multigraph with vertices \(0,\ldots,T\):

  • For every \(t<T\), include an idle arc from \(t\) to \(t+1\).
  • For every listed \((\theta,p)\), include a job arc labelled \((\theta,p)\) from \(t\) to \(t+p\) whenever \(0\leq t\) and \(t+p\leq\min\{d_\theta,T\}\).

Parallel arcs retain their distinct labels. All arcs strictly increase time, so the graph is acyclic.

Introduce a nonnegative real variable \(f_e\) for each arc. Require:

  • Flow of value \(M=\sum_\theta\mu_\theta m_\theta\) from vertex \(0\) to vertex \(T\), with conservation at every intermediate vertex.
  • For each listed \((\theta,p)\), the demand equation

\( \sum_{e\text{ labelled }(\theta,p)} f_e=\mu_\theta q_{\theta,p}. \)

There are at most \(T(D+1)\) variables and \(T+1+D\) equality constraints.

2.3 Equivalence with the measurable model

From a schedule to a flow. Compress the schedule as above and pad each machine’s list with unit idle arcs until time \(T\). Each machine then follows a path from \(0\) to \(T\).

For every arc, define \(f_e\) as the measure of machines using that arc. Pathwise conservation gives flow conservation. The measure-preserving job matching gives the demand equations.

From a flow to a schedule. Every nonnegative flow in this finite acyclic graph decomposes into finitely many paths from \(0\) to \(T\), with nonnegative weights \(\lambda_1,\ldots,\lambda_s\) summing to \(M\).

Partition \([0,M)\) into intervals of these lengths. Every machine in interval \(i\) follows path \(i\), omitting its idle arcs from its job-slot list. Every slot is uninterrupted, and its completion time satisfies its labelled deadline.

It remains to construct the required bijection. For each \((\theta,p)\):

  • Its job-copy space is a finite disjoint union of intervals, of total measure \(\mu_\theta q_{\theta,p}\).
  • Its constructed slot space is likewise a finite disjoint union of intervals, of the same total measure.

Concatenate the intervals on each side, cut at their combined endpoints, and match corresponding pieces by translations. This gives a measure-preserving bijection modulo endpoints. Combining these maps over all classes gives the required global matching.

Every labelled copy of a type-\(\theta\) organization receives a slot meeting \(d_\theta\). Taking the finite intersection over its labels proves completion of the entire bundle for almost every organization.

This proves exact equivalence.

2.4 Running time

Define \(Q=L+m+(\tau p_{\max}+1)(T+1)\).

The graph and the rational linear program have encoding length polynomial in \(Q\). In particular, summing the binary-encoded rational quantities defining \(M\) and the demands produces only polynomially many bits. Exact rational linear programming therefore decides supplied-deadline feasibility in \(Q^{O(1)}\) bit operations.

No exponential dependence on denominators or population masses is involved.

3. The original problem belongs to \(\mathrm{coNP}\)

First, every local optimum \(\ell^{\max}_\theta\) is an integer. Indeed, for any assignment of the finite bundle to its machines, scheduling without idle time gives makespan equal to the maximum machine load. There are finitely many assignments, and all loads are integers.

A certificate for a no-instance consists of an arbitrary finite local assignment for each type. Let \(b_\theta\) be its maximum machine load. Necessarily, \(b_\theta\geq\ell^{\max}_\theta\).

The verifier:

  • Checks these assignments and computes all \(b_\theta\).
  • Runs the polynomial-time algorithm from Section 2 using deadlines \(b_\theta\).
  • Accepts the no-certificate precisely when that supplied-deadline problem is infeasible.

Soundness. A schedule meeting the true deadlines would also meet the larger deadlines \(b_\theta\). Thus infeasibility with deadlines \(b_\theta\) implies infeasibility with the true deadlines.

Completeness. For any actual no-instance, choose optimal local assignments. Then \(b_\theta=\ell^{\max}_\theta\), and the verifier finds infeasibility.

The certificates have polynomial length. Unary multiplicities imply that the total number of finite labelled jobs is at most \(L\); specifying their machine assignments uses polynomially many bits. Their loads are bounded by \(p_{\max}L\).

Hence the continuous decision problem belongs to \(\mathrm{coNP}\).

4. \(\mathrm{coNP}\)-hardness with three supported types

We reduce from the complement of unary 3-Partition, using the standard strong \(\mathrm{NP}\)-completeness theorem for the following restricted form.

The input consists of positive integers \(a_1,\ldots,a_{3r},B\), all encoded in unary, satisfying:

\( \sum_{i=1}^{3r}a_i=rB,\qquad B/4<a_i<B/2. \)

The question is whether the integers can be partitioned into \(r\) triples, each summing to \(B\).

Set \(H=B+2\) and \(T=H+B+1=2B+3\). Construct these three supported types:

| Type | Mass | Machines | Bundle |
|---|---:|---:|---|
| \(X\) | \(1/4\) | \(r\) | \(r\) jobs of duration \(H\), and jobs of durations \(a_1,\ldots,a_{3r}\) |
| \(Y\) | \(1/4\) | \(6r\) | \(r\) jobs of duration \(B+1\) |
| \(Z\) | \(1/2\) | \(1\) | \(3r+1\) jobs of duration \(H+1\) |

Equal durations among the \(a_i\) are aggregated into multiplicities, as required.

All bundles are nonempty; all masses are positive dyadic rationals summing to one. The output has \(\tau=3\), \(m=7r+1\), and \(p_{\max}=B+3\). Its unary encoding length is polynomial in the source encoding length.

4.1 The local deadline of type \(X\) detects 3-Partition

The total work in its finite bundle is \(rH+rB=r(H+B)\). On its \(r\) machines, this implies \(\ell^{\max}_X\geq H+B\).

We claim:

\( \ell^{\max}_X=H+B \quad\Longleftrightarrow\quad \text{the 3-Partition instance is a yes-instance}. \)

For the forward direction, suppose a local schedule has makespan at most \(H+B\). Since \(H>B\), two duration-\(H\) jobs cannot share a machine. There are \(r\) such jobs and \(r\) machines, so every machine receives exactly one.

The remaining jobs have total duration \(rB\), while each machine has remaining capacity at most \(B\). Thus each receives remaining load exactly \(B\). The bounds \(B/4<a_i<B/2\) imply that every such group has exactly three jobs: two have total duration less than \(B\), and four have total duration greater than \(B\). These groups give a 3-partition.

Conversely, a 3-partition yields a local schedule by placing one duration-\(H\) job and one triple on each machine.

Because the optimum is integral, a source no-instance consequently satisfies \(\ell^{\max}_X\geq H+B+1=T\).

The other local optima are explicit:

\( \ell^{\max}_Y=B+1,\qquad \ell^{\max}_Z=(3r+1)(H+1)>T. \)

For \(Y\), there are more machines than jobs, so its longest job determines the optimum. For \(Z\), there is one machine, so its total work determines the optimum.

4.2 A source yes-instance produces an infeasible continuous instance

Call the duration-\(H\) jobs of \(X\) and the duration-\(H+1\) jobs of \(Z\) long jobs.

Both durations exceed \(T/2\), since \(2H=2B+4>T\). Therefore, any machine completing by \(T\) contains at most one long job.

The total measure of long jobs is

\( r/4+(3r+1)/2=(7r+2)/4. \)

The pooled machine measure is exactly

\( M=r/4+6r/4+1/2=(7r+2)/4. \)

Thus almost every machine must contain exactly one long job. Formally, its long-job count is at most one almost everywhere, and its integral equals \(M\); hence the count equals one almost everywhere.

A type-\(Y\) job cannot share a machine with a long job of \(Z\), because their total duration is

\( (B+1)+(H+1)=T+1. \)

It must therefore share a machine with a long job of \(X\). Such a machine contains at most one type-\(Y\) job, because

\( H+2(B+1)=T+(B+1)>T. \)

The measure of type-\(Y\) jobs and the measure of machines carrying a long job of \(X\) both equal \(r/4\). Consequently, almost every machine carrying a long job of \(X\) also carries exactly one type-\(Y\) job.

A type-\(Y\) job has duration and deadline both equal to \(B+1\), so it must start at time zero. Its paired long job of \(X\) therefore completes no earlier than \(B+1+H=T\).

For a source yes-instance, however, \(\ell^{\max}_X=H+B=T-1\). A positive measure \(r/4\) of its jobs necessarily violates this deadline. The continuous instance is infeasible.

4.3 A source no-instance produces a feasible continuous instance

Now \(\ell^{\max}_X\geq T\). Partition the pooled machines into sets of measures \(r/4\) and \((3r+1)/2\).

On the first set, put one type-\(Y\) job followed by one long job of \(X\). These finish at \(B+1\) and \(T\), respectively. Their measures are exactly the required \(r/4\) each.

On the second set, put one long job of \(Z\) on every machine. Partition this set into \(3r+1\) intervals of length \(1/2\), one for each labelled job of \(Z\).

For each \(i=1,\ldots,3r\), select a subinterval of length \(1/4\) within interval \(i\). On its machines, place the duration-\(a_i\) job of \(X\) first, followed immediately by the long job of \(Z\). On all remaining machines, start the long job of \(Z\) at zero.

Every small job of \(X\) receives exactly its required measure \(1/4\). Since \(a_i<B\), each delayed long job of \(Z\) completes by

\( a_i+H+1\leq B+H+1=T. \)

The deadlines are therefore satisfied:

  • All jobs of \(X\) finish by \(T\leq\ell^{\max}_X\).
  • All jobs of \(Y\) finish by \(B+1=\ell^{\max}_Y\).
  • All jobs of \(Z\) finish by \(T<\ell^{\max}_Z\).

The finite-interval matching construction from Section 2.3 supplies a measure-preserving bijection for every labelled job copy. Hence this is a valid schedule in the stipulated model.

We have proved:

\( \text{continuous instance is feasible}\quad\Longleftrightarrow\quad\text{3-Partition instance is a no-instance}. \)

This is a polynomial-time many-one reduction from the complement of unary 3-Partition. Together with Section 3, it proves \(\mathrm{coNP}\)-completeness.

5. Fixed-parameter tractability

Use the following established theorem: finite nonpreemptive makespan minimization on identical unit-speed machines, with positive integer durations and all jobs released at zero, is solvable in time \(f(p_{\max})(n+\log(m+1))^{O(1)}\), for a computable function \(f\). This is [Mnich–Wiese, Theorem 2](https://arxiv.org/pdf/1311.4021).

Each type’s finite local problem meets every hypothesis: identical unit-speed machines, independent nonpreemptive jobs, integer durations, and release time zero. Unary multiplicities permit expansion into at most \(L\) labelled jobs overall.

Compute every \(\ell^{\max}_\theta\) using that theorem, then run the linear program of Section 2 with these deadlines. The total running time is

\( \tau f(p_{\max})(L+\log(m+1))^{O(1)}+\bigl(L+m+(\tau p_{\max}+1)(T+1)\bigr)^{O(1)}. \)

Because \(m,\tau,T\) are bounded by the unary input length, this is \(f(p_{\max})L^{O(1)}\), after adjusting \(f\). Thus \(p_{\max}\) alone suffices as an FPT parameter.

6. Interpretation of the hardness question

The distinction between \(\mathrm{NP}\)-hardness and \(\mathrm{coNP}\)-hardness is substantive here.

If this \(\mathrm{coNP}\)-complete problem were many-one \(\mathrm{NP}\)-hard, closure under polynomial-time reductions would imply \(\mathrm{NP}\subseteq\mathrm{coNP}\), and taking complements would give equality. Conversely, equality makes its \(\mathrm{coNP}\)-completeness also \(\mathrm{NP}\)-hardness.

Likewise, polynomial-time solvability would imply \(\mathrm P=\mathrm{NP}\), while that equality would make the problem polynomial-time solvable.

For Turing hardness, one oracle query to the constructed continuous instance, followed by negating its answer, decides unary 3-Partition. Hence Turing \(\mathrm{NP}\)-hardness holds unconditionally.
