The continuous mirror question, as graded

Given a finite deployment-query support \(Z\) with rational probabilities \(q_z\) and feature differences \(\alpha_z\in\mathbb{Q}^k\), and a finite type set \(T\) with rational masses \(\mu_t\) summing to \(1\), preference vectors \(\theta_t\), and welfare constraints \(\gamma_t^\top\psi\geq c_t\), find an optimal impact \(\psi\) maximizing \(\sum_{t\in T}\mu_t\theta_t^\top\psi\). The feasible impacts are \(\psi=\sum_{z\in Z}q_zs_z\alpha_z\), where \(-\tfrac12\leq s_z\leq\tfrac12\); assume the constraints are feasible. Equivalently, solve the resulting rational LP.

Deployment queries are given explicitly by a nonempty support \(Z\), with \(m=|Z|\), binary rational probabilities \(q_z>0\) summing to \(1\), and feature differences \(\alpha_z\in\mathbb Q^k\).

Type welfare is \(\theta_t^\top\psi\), measured relative to choosing each query's two options with equal probability. The objective is to find an exact optimal impact maximizing \(\sum_{t\in T}\mu_t\theta_t^\top\psi\); any maximizer is acceptable.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Computing an exact optimal impact is solvable in polynomial time in \(m,\tau,k,L\). The explicit support representation gives a polynomial-size rational linear program.

1. Exact linear-programming formulation

Define the aggregate preference vector \(w\in\mathbb Q^k\) and the query matrix \(A\in\mathbb Q^{k\times m}\) by

\(w=\sum_{t\in T}\mu_t\theta_t,\qquad A_{jz}=q_z\alpha_{z,j}.\)

For every impact \(\psi\), finite summation gives

\(\sum_{t\in T}\mu_t\theta_t^\top\psi=w^\top\psi.\)

Consider the following linear program with variables \(s\in\mathbb R^m\) and \(\psi\in\mathbb R^k\):

\(\displaystyle \text{maximize }w^\top\psi\)

subject to

\(\displaystyle \psi_j=\sum_{z\in Z}A_{jz}s_z\quad (j=1,\ldots,k),\)

\(\displaystyle \gamma_t^\top\psi\ge c_t\quad (t\in T),\)

\(\displaystyle -\tfrac12\le s_z\le\tfrac12\quad (z\in Z).\)

This formulation is exact in both directions:

  • Every feasible pair \((s,\psi)\) defines an admissible impact, because the equality constraints give precisely its required query representation and the remaining constraints impose admissibility.
  • Every admissible impact has, by definition, a witnessing vector \(s\) satisfying these same constraints.

The objective also agrees exactly with societal welfare. Consequently, the impact component of any optimal LP solution solves the stated problem. Arbitrary signs of preferences, directions, and thresholds cause no difficulty: they remain rational linear coefficients.

2. Existence and applicability of exact LP algorithms

The feasible set in the \(s\)-variables is

\(P=\{s\in[-\tfrac12,\tfrac12]^m:\gamma_t^\top As\ge c_t\text{ for every }t\in T\}.\)

It is nonempty by the feasibility promise. It is closed, since all inequalities are non-strict, and bounded, since it lies in the specified box. Thus it is compact. Its continuous linear objective \(w^\top As\) attains a finite maximum.

The extended feasible set \(\{(s,As):s\in P\}\) is likewise nonempty and compact.

We use the standard rational linear-programming theorem: an explicitly encoded rational LP can be solved in time polynomial in its numbers of variables and constraints and its total binary encoding length; when its optimum is finite, an exact rational optimal solution can be returned. See [Theorem 17.1 and the feasibility-to-optimization discussion in these University of Washington lecture notes](https://courses.cs.washington.edu/courses/cse521/22au/521-lecture-16.pdf).

All hypotheses hold here. In particular, the rational LP theorem requires neither strict feasibility nor a feasible set with nonempty interior. Equalities and boundary-only feasibility are allowed.

3. Encoding size and running time

Replacing each equality by two inequalities gives

\(n=m+k\quad\text{variables},\qquad r=\tau+2m+2k\quad\text{inequalities}.\)

Let \(B\) bound the binary length of an individual resulting coefficient. We may take

\(B=O(L+\log(\tau+1)+1).\)

To justify this bound, products \(q_z\alpha_{z,j}\) have encoding length \(O(L)\). For an aggregate coordinate, write

\(\displaystyle w_j=\sum_{t\in T}\frac{a_tu_{tj}}{b_tv_{tj}},\)

where \(\mu_t=a_t/b_t\) and \(\theta_{t,j}=u_{tj}/v_{tj}\), with positive denominators. The common denominator \(\prod_t b_tv_{tj}\) has binary length \(O(L)\), since these denominator encodings belong to the input. Each numerator term after conversion to this denominator also has length \(O(L)\); summing \(\tau\) signed terms increases this bound by at most \(O(\log(\tau+1))\). Reducing the fraction cannot increase its length.

Therefore a dense encoding of the LP has total length

\(S=O((nr+n+r)B).\)

Construction uses \(O(k(m+\tau))\) rational arithmetic operations and polynomially many bit operations in \(m,\tau,k,L\). If \(p(n,r,S)\) denotes a fixed polynomial bound for an exact rational LP algorithm, the total running time is

\(\displaystyle \operatorname{poly}(m,\tau,k,L)+p\!\left(m+k,\tau+2m+2k,O\!\left(((m+k)(\tau+2m+2k)+m+k+\tau+2m+2k)B\right)\right),\)

which is \(\operatorname{poly}(m,\tau,k,L)\) bit operations.

Exact output also has polynomial length. Indeed, a nonempty compact polytope has an optimal vertex. At a vertex, the active constraint normals span \(\mathbb R^n\): otherwise a nonzero direction orthogonal to every active normal would permit sufficiently small feasible perturbations in both directions, contradicting extremality. Choose \(n\) independent active constraints. Clearing denominators row by row produces an integer system whose entries have \(O(nB)\) bits. Hadamard’s inequality bounds the determinant lengths by \(O(n^2B+n\log n)\); Cramer’s rule gives the same polynomial bound for each vertex coordinate. In particular, an exact optimal impact has polynomial encoding length.

4. Conclusion

The finite support masses are handled by rational weighted summation, and the finite query support supplies a compact linear formulation. Solving that formulation and returning its impact coordinates completely resolves the task in polynomial time. Under standard polynomial-time reductions, NP-hardness would therefore imply \(\mathrm P=\mathrm{NP}\).
