The continuous mirror question, as graded

Given a finite bipartite graph of supplier and demander types, positive rational masses \(\mu_t\), per-capita capacities \(X_t\), and peaks \(p_t\), compute the type-level allocation maximizing \(\sum_t \mu_t(-x_t^2)\) over feasible efficient allocations with \(x_t\le p_t\). Feasibility is represented by nonnegative flows \(y_{uv}\) on compatible type edges, with each supplier type's total outflow and each demander type's total inflow equal to its mass times its per-capita assignment.

Result. The maximizing allocation is exactly computable in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\). The crucial fact is that efficient allocations below peaks are precisely the allocations implemented by maximum flows with aggregate peak capacities.

1. The network of allocations below peaks

Write \(N=S\cup D\), and define \(q_t=\mu_t p_t\). Introduce a source \(a\) and sink \(b\), with arcs:

  • \(a\to u\), of capacity \(q_u\), for each \(u\in S\);
  • \(u\to v\), of capacity \(M\), for each \(uv\in E\);
  • \(v\to b\), of capacity \(q_v\), for each \(v\in D\).

Here \(M=1+\sum_{u\in S}q_u\). This finite capacity imposes no additional restriction: each original edge carries at most the total supplier flow, which is smaller than \(M\).

A feasible allocation satisfying \(x_t\le p_t\) corresponds exactly to a flow in this network, with

\[ f_{au}=\mu_u x_u,\qquad f_{vb}=\mu_v x_v,\qquad f_{uv}=y_{uv}. \]

Indeed, conservation at each type is exactly the flow requirement in the question, and terminal arc capacities are exactly the peak bounds. Since \(p_t\le X_t\), the original capacity bounds also hold.

Let \(F\) be the maximum flow value. For any feasible allocation define its aggregate transfer by

\[ T(x)=\sum_{u\in S}\mu_u x_u =\sum_{v\in D}\mu_v x_v =\frac12\sum_{t\in N}\mu_t x_t. \]

2. Efficiency is equivalent to maximum flow

We prove the following characterization, including comparisons against allocations above peaks:

\[ x\text{ is efficient for every specified single-peaked profile and }x\le p \quad\Longleftrightarrow\quad x\text{ is feasible},\ x\le p,\ T(x)=F. \]

Here single-peakedness means strict preference for increasing assignments below the peak and decreasing assignments above it, with the peak uniquely best.

Necessity. Suppose a feasible \(x\le p\) has \(T(x)<F\), and choose an implementing flow \(f\).

Its residual network has an \(a\)-to-\(b\) path. To justify this standard fact, if no such path existed, let \(R\) be the vertices reachable from \(a\). Every original arc leaving \(R\) would be saturated, and every original arc entering \(R\) would carry zero flow. Conservation would then give a flow value equal to the capacity of this cut. Every flow is bounded by that cut capacity, contradicting \(T(x)<F\).

Choose a simple residual path and augment it by a positive amount \(\delta\) no larger than its smallest residual capacity. Because the path is simple, it visits \(a\) and \(b\) only as its endpoints. Its first arc is \(a\to u\) for some supplier \(u\), and its last arc is \(v\to b\) for some demander \(v\).

Consequently, the induced allocation changes only by

\[ x'_u=x_u+\frac{\delta}{\mu_u}, \qquad x'_v=x_v+\frac{\delta}{\mu_v}. \]

All other terminal arc flows, hence all other assignments, remain unchanged. The residual capacity bounds ensure \(x'\le p\). Both affected types strictly prefer their new assignments under every single-peaked profile with these peaks. Thus \(x\) is not efficient.

Sufficiency. Suppose instead that \(x\le p\) is feasible and \(T(x)=F\). Assume, for contradiction, that a feasible allocation \(z\) Pareto dominates \(x\) under some single-peaked profile with the specified peaks.

For every type, \(z_t\ge x_t\): an assignment smaller than \(x_t\le p_t\) is strictly worse. Furthermore, whenever \(x_t=p_t\), weak improvement requires \(z_t=x_t\). Strict Pareto improvement implies \(z\ne x\).

Let \(I=\{t:z_t>x_t\}\). This set is nonempty, and \(x_t<p_t\) for every \(t\in I\). Hence there exists \(\lambda>0\) with \(\lambda\le1\) and

\[ \lambda\le\min_{t\in I}\frac{p_t-x_t}{z_t-x_t}. \]

The allocation \(w=(1-\lambda)x+\lambda z\) is feasible: combine implementing flows with the same coefficients, and use convexity of the assignment bounds. By the choice of \(\lambda\), it also satisfies \(w\le p\).

But positivity of the masses gives

\[ T(w)-T(x) =\frac{\lambda}{2}\sum_{t\in N}\mu_t(z_t-x_t)>0. \]

This contradicts maximality of \(F\). Thus \(x\) is efficient under every such profile. This argument explicitly allows the alleged dominating allocation \(z\) to exceed peaks.

3. The objective is a quadratic minimum-cost flow

Compute \(F\), then restrict the network to flows of value exactly \(F\). Give its arcs the costs

\[ C_{au}(h)=\frac{h^2}{\mu_u}, \qquad C_{vb}(h)=\frac{h^2}{\mu_v}, \qquad C_{uv}(h)=0. \]

For the allocation induced by a flow, its total cost is

\[ \sum_{u\in S}\frac{(\mu_u x_u)^2}{\mu_u} +\sum_{v\in D}\frac{(\mu_v x_v)^2}{\mu_v} =\sum_{t\in N}\mu_t x_t^2. \]

Therefore minimizing this cost is exactly the requested maximization of \(-\sum_t\mu_t x_t^2\). Section 2 proves that fixing the flow value to \(F\) imposes precisely the required efficiency condition.

For an explicit node-balance formulation, use inflow minus outflow equal to \(-F\) at \(a\), \(F\) at \(b\), and zero at every type.

4. Exact computation and binary complexity

We apply the following established algorithmic result: minimum-cost flow with prescribed node balances, rational arc bounds, and separable costs \(C_e(h)=c_eh^2+d_eh\), where \(c_e\ge0\), admits an exact strongly polynomial algorithm. For a capacitated network with \(A\) arcs, Végh’s Theorem 20 gives \(O(A^4\log A)\) arithmetic operations; the accompanying analysis establishes polynomial encoding lengths for all intermediate rational numbers. [Végh, Theorem 20 and Section 6.1](https://personal.lse.ac.uk/veghl/papers/vegh-quadratic.pdf).

All hypotheses hold here:

  • The network has \(\tau+2\) vertices and \(A=m+\tau\) arcs.
  • All bounds, balances, and cost coefficients are rational.
  • Quadratic coefficients are either \(1/\mu_t>0\) or zero; all linear coefficients are zero.
  • A flow of value \(F\) exists, and finite arc bounds make its feasible set compact.

The constructed numbers have polynomial binary encoding length. Products \(q_t=\mu_t p_t\), reciprocals \(1/\mu_t\), and the sum defining \(M\) all require polynomially many bits in \(L\). The value \(F\) can be computed exactly in polynomial time by a rational maximum-flow algorithm. Its encoding length is polynomial as well: by the max-flow/min-cut theorem, it is a sum of capacities from a minimum cut.

Thus the quadratic-flow algorithm takes polynomial bit time in \(m,\tau,L\). Recover the answer by dividing each terminal flow by its positive mass. These divisions also take polynomial bit time.

Finally, the allocation is unique. The allocations induced by flows of value \(F\) form a nonempty compact convex set, and \(\sum_t\mu_t x_t^2\) is strictly convex because every \(\mu_t>0\). Implementing edge flows need not be unique, but their optimal allocation is.

All computations operate directly on the listed types; rational masses require no expansion into individual agents.
