The continuous mirror question, as graded

Given a planar subcubic bipartite graph \(G=(S\cup R,E)\), assign each type \(v\in S\cup R\) mass \(\mu_v=1/|V(G)|\). Does there exist a strict preference ranking for each type over opposite-side types and being unmatched such that the graph containing \(sr\) exactly when some stable mass allocation assigns \(x_{sr}>0\) is \(G\)? Allocations satisfy type-mass capacity constraints, and stability requires that for every pair \(sr\), at least one side has zero mass assigned below its partner type, including unmatched mass when that type prefers \(sr\) to being unmatched.

Packaged proof task (what the prover saw — nothing else)

Input: a nonempty finite simple planar subcubic bipartite graph \(G=(S\cup R,E)\), with its bipartition specified. Put \(\tau=|S|+|R|\) and \(m=|E|\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass encoded as a binary rational. Here \(\mu_v=1/\tau\), so total mass is \(1\); \(\tau\) is the support size, not the number of possible preference rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A preference system assigns each type \(v\) a strict total order \(\succ_v\) over all opposite-side types and the unmatched outcome \(\varnothing\). A pair is acceptable precisely when both endpoints rank each other above \(\varnothing\).
An allocation consists of real numbers \(x_{sr}\geq 0\) for all \((s,r)\in S\times R\), with \(\sum_r x_{sr}\leq\mu_s\), \(\sum_s x_{sr}\leq\mu_r\), and \(x_{sr}=0\) for unacceptable pairs. Define unmatched masses \(u_s=\mu_s-\sum_r x_{sr}\) and \(u_r=\mu_r-\sum_s x_{sr}\).
Define \(B_s(r)=\sum_{r':\,r\succ_s r'}x_{sr'}+\mathbf{1}_{\{r\succ_s\varnothing\}}u_s\) and \(B_r(s)=\sum_{s':\,s\succ_r s'}x_{s'r}+\mathbf{1}_{\{s\succ_r\varnothing\}}u_r\). The allocation is stable if, for every \((s,r)\in S\times R\), \(B_s(r)=0\) or \(B_r(s)=0\).
Recognize whether there exists one preference system such that, for every \((s,r)\in S\times R\), \(sr\in E\) if and only if some stable allocation under that system has \(x_{sr}>0\).

Is this recognition problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathsf{NP}\)-hard?

Discrete recognition with strict preferences and unacceptable partners is \(\mathsf{NP}\)-complete even for planar subcubic bipartite graphs. [Source](https://arxiv.org/pdf/2010.09230)
For prescribed preferences, the more general real-valued stable allocation problem has a strongly polynomial algorithm; this addresses finding an allocation, rather than recognizing its possible-pair graph. [Source](https://pubsonline.informs.org/doi/pdf/10.1287/moor.27.4.662.302)

Modeling choices made when packaging the task

  • Excluded the empty graph because the prescribed mass 1/|V(G)| would be undefined; retained isolated vertices and did not impose balanced or nonempty bipartition sides.
  • Made individual rationality explicit: positive mass may be allocated only to pairs that both endpoints prefer to being unmatched, as required by the discrete definition.
  • Allowed arbitrary nonnegative real allocation entries, with unmatched mass equal to unused type capacity and total society mass normalized to 1.
  • Specified strict total rankings including the unmatched outcome, encoding the discrete model's unacceptable partners below that outcome.
  • Specified that allocation variables and stability conditions range over all opposite-side pairs, and that one preference system governs every allocation used in the possible-pair graph.
  • Defined m as the graph's edge count and L as the total input bit length.

1. Result

The recognition problem is \(\mathsf{NP}\)-complete, even on the specified planar subcubic bipartite graphs.

The key fact is that, for any fixed preference system with uniform masses, its possible-pair graph for stable allocations equals its possible-pair graph for ordinary stable matchings. We prove this without assuming that the allocation entries are rational.

2. Stable allocations decompose into stable matchings

An ordinary matching uses only mutually acceptable pairs. Write \(M(v)=\varnothing\) when \(v\) is unmatched. It is stable when no pair satisfies both \(r\succ_s M(s)\) and \(s\succ_r M(r)\).

Fix a preference system and a stable allocation \(x\). Normalize its masses by setting

\(y_{sr}=\tau x_{sr},\qquad a_s=1-\sum_r y_{sr}=\tau u_s,\qquad b_r=1-\sum_s y_{sr}=\tau u_r.\)

All these quantities are nonnegative, and every row and column of \(y\) has sum at most \(1\).

Introduce copies \(\overline S\) and \(\overline R\). Construct a square matrix \(D\), with rows indexed by \(S\cup\overline R\) and columns indexed by \(R\cup\overline S\), as follows:

  • \(D_{s,r}=y_{sr}\).
  • \(D_{s,\overline s}=a_s\), with all other entries between \(S\) and \(\overline S\) zero.
  • \(D_{\overline r,r}=b_r\), with all other entries between \(\overline R\) and \(R\) zero.
  • \(D_{\overline r,\overline s}=y_{sr}\).

Every row and column sums to \(1\). For example, row \(\overline r\) sums to \(b_r+\sum_s y_{sr}=1\), and column \(\overline s\) sums to \(a_s+\sum_r y_{sr}=1\).

We next justify a finite decomposition

\(D=\sum_{i=1}^{k}\lambda_i P_i,\qquad \lambda_i>0,\qquad \sum_{i=1}^{k}\lambda_i=1,\)

where each \(P_i\) is a permutation matrix supported on positive entries of \(D\).

Suppose a nonnegative residual matrix has every row and column sum equal to \(c>0\). For any set \(U\) of rows, let \(N(U)\) be the columns containing a positive entry in those rows. Then

\(c|U|=\sum_{u\in U,\;v\in N(U)}D_{uv}\leq c|N(U)|.\)

Thus its support satisfies Hall’s condition, so it contains a perfect matching. Subtract the corresponding permutation matrix multiplied by the smallest residual entry on that matching. The residual remains nonnegative, its row and column sums remain equal, and at least one positive entry disappears. Repeating terminates after at most \(\tau^2\) steps. The resulting coefficients sum to \(1\), because the initial row sums were \(1\) and the final residual is zero. This proves the decomposition, including for real entries.

For each \(P_i\), let \(M_i\) consist of its selected entries between \(S\) and \(R\). These entries form an ordinary matching and are acceptable, since \(y_{sr}>0\) implies acceptability.

We show that every \(M_i\) is stable. Consider a mutually acceptable pair \(sr\). Stability of \(x\) gives \(B_s(r)=0\) or \(B_r(s)=0\). Suppose first that \(B_s(r)=0\). Since \(r\succ_s\varnothing\) and every summand defining \(B_s(r)\) is nonnegative, we have

\(a_s=0,\qquad y_{sr'}=0\text{ whenever }r\succ_s r'.\)

Consequently, a permutation matrix supported on \(D\) cannot leave \(s\) unmatched: its only possible entry into \(\overline S\) has value \(a_s=0\). It also cannot assign \(s\) a partner worse than \(r\). Hence \(s\) does not strictly prefer \(r\) to \(M_i(s)\).

If instead \(B_r(s)=0\), the symmetric argument shows that \(r\) does not strictly prefer \(s\) to \(M_i(r)\). Therefore \(sr\) cannot block \(M_i\).

A pair that is not mutually acceptable cannot block an acceptable matching: at least one endpoint ranks it below \(\varnothing\), whereas its current outcome is either \(\varnothing\) or an acceptable partner. Thus every \(M_i\) is stable.

Taking the \(S\times R\) entries in the decomposition yields

\(x_{sr}=\frac{1}{\tau}\sum_{i=1}^{k}\lambda_i\mathbf 1_{\{sr\in M_i\}}.\)

In particular, if \(x_{sr}>0\), then \(sr\) belongs to at least one ordinary stable matching.

3. Equality of the possible-pair graphs

Conversely, let \(M\) be an ordinary stable matching and define

\(x^M_{sr}=\frac{1}{\tau}\mathbf 1_{\{sr\in M\}}.\)

This allocation is feasible. Directly from the definitions, for every pair,

\(B_s^{x^M}(r)=\frac{1}{\tau}\mathbf 1_{\{r\succ_s M(s)\}},\qquad B_r^{x^M}(s)=\frac{1}{\tau}\mathbf 1_{\{s\succ_r M(r)\}}.\)

Ordinary stability therefore implies allocation stability.

Combining this observation with Section 2 proves, for each fixed preference system,

\(\exists\text{ stable allocation }x\text{ with }x_{sr}>0\quad\Longleftrightarrow\quad\exists\text{ ordinary stable matching }M\text{ containing }sr.\)

Strict preference lists with unacceptable partners are equivalent to the task’s total orders: place listed partners above \(\varnothing\), and all omitted partners below it. Consequently, quantifying over preference systems preserves this equivalence.

4. Hardness and encoding

Eppstein’s Theorem 5.3 states that recognizing graphs of ordinary stably matchable pairs is \(\mathsf{NP}\)-complete even for planar subcubic bipartite graphs, using strict preferences with unacceptable partners. These are precisely the graph and preference hypotheses needed here. [The Graphs of Stably Matchable Pairs, Theorem 5.3](https://arxiv.org/pdf/2010.09230)

The reduction retains the graph and assigns mass \(1/\tau\) to each vertex. Sections 2–3 prove that the discrete and allocation instances have identical answers.

Under a standard binary edge-list encoding, constructing the instance takes \(O((m+\tau)\log(\tau+1))\) bit operations. Each mass has binary numerator \(1\) and denominator \(\tau\), so the resulting total input length satisfies \(L=O((m+\tau)\log(\tau+1))\). The reduction preserves simplicity, planarity, bipartiteness, and maximum degree. Thus the problem is \(\mathsf{NP}\)-hard.

5. Polynomial certificate verification

For completeness, the problem also belongs to \(\mathsf{NP}\), with an explicit certificate that avoids real numbers.

First, any yes-instance admits a realizing preference system whose acceptable pairs are exactly \(E\). Indeed, Section 3 supplies an ordinary stable matching containing each edge. Every such matching uses only \(E\). Retain the original relative order of each vertex’s neighbors in \(E\), place them above \(\varnothing\), and place every other partner below \(\varnothing\). Each selected matching remains stable: any potentially blocking pair must belong to \(E\), where the relevant comparisons are unchanged.

A certificate therefore consists of:

  • The preference order of each vertex’s neighbors in \(E\).
  • For each edge \(e\in E\), a matching \(M_e\) containing \(e\).

The verifier checks that each \(M_e\) is a matching and that no edge in \(E\) blocks it. Nonedges are unacceptable under the certified system. If all checks pass, the allocations \(x^{M_e}\) witness every required edge, while feasibility forbids positive allocations on nonedges.

Conversely, the preceding restriction argument supplies such a certificate for every yes-instance.

Encode each matching as an \(m\)-bit incidence vector. The certificate length is \(O(m^2+m\log(\tau+1))\) bits. Verification takes \(O(L+(m+1)(m+\tau))\) elementary operations on indices of \(O(\log(\tau+1))\) bits, and hence polynomial bit time in \(m,\tau,L\). When \(m=0\), making every pair unacceptable immediately realizes the graph.

Thus the recognition problem is \(\mathsf{NP}\)-complete.
