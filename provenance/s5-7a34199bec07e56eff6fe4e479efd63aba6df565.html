The continuous mirror question, as graded

Given \(n\) features with \(q\) possible values each, a target outcome \(z\in[q]^n\), and a support-\(\tau\) distribution \(\mu\) over complete strict rankings of \([q]^n\), does there exist an objects scheme—feature subsets whose union covers all features, with overlaps allowed—under which \(z\) is a local optimum for weighted majority? Equivalently, determine whether \(\sum_{t:\,z\succ_t z^{i,a}}\mu_t>\tfrac12\) for every feature \(i\) and every \(a\ne z_i\), where \(z^{i,a}\) changes only feature \(i\); if so, construct a scheme.

Packaged proof task (what the prover saw — nothing else)

Let \(n\geq1\), \(q\geq2\), \([q]=\{1,\ldots,q\}\), \(X=[q]^n\), and \(m=|X|=q^n\). The input includes a target \(z\in X\).
A society is given by its support: a list of \(\tau\) distinct types with positive binary rational masses \(\mu_t\) summing to \(1\). Each type is a complete strict ranking of \(X\), encoded as an explicit ordered list. Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
Define \(x\succ_\mu y\) iff \(\sum_{t:x\succ_t y}\mu_t>\tfrac12\). Promise that this sum is never \(\tfrac12\) for distinct \(x,y\in X\), so social preferences are complete and strict.
An objects scheme is a finite family \(\mathcal A\) of nonempty subsets of \(\{1,\ldots,n\}\) whose union is \(\{1,\ldots,n\}\); overlaps are allowed. An object \(I\) permits replacement by any distinct outcome agreeing outside \(I\), including replacements changing only some features in \(I\).
The outcome \(z\) is a local optimum for \(\mathcal A\) if no permitted replacement \(y\) satisfies \(y\succ_\mu z\). Decide whether such a scheme exists and, on a yes instance, construct one.

Is this decision problem in \(\mathrm P\), with a witnessing scheme constructible in polynomial time, or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L,n,q\).

For finite societies with complete strict social preferences, existence of a scheme making \(z\) locally optimal is equivalent to \(z\) defeating every outcome differing in exactly one feature. Result

The decision problem is in \(\mathrm P\), and every yes instance has the polynomial-time constructible witnessing scheme \(\mathcal A_*=\{\{1\},\ldots,\{n\}\}\).

The proof applies directly to rational masses; it does not require expanding them into a population of individual agents.

1. Characterization of feasible targets

Define the set of one-feature neighbors by
\[ N_1(z)=\{y\in[q]^n:|\{i:y_i\ne z_i\}|=1\}. \]
Its cardinality is \(k=n(q-1)\).

Proposition. A scheme making \(z\) locally optimal exists if and only if \(z\succ_\mu y\) for every \(y\in N_1(z)\).

Proof. Suppose \(z\) is locally optimal for a scheme \(\mathcal A\). Take any \(y\in N_1(z)\), and let \(i\) be its unique differing coordinate. Because \(\mathcal A\) covers all coordinates, some \(I\in\mathcal A\) contains \(i\). The outcomes \(y\) and \(z\) agree outside \(I\), so \(y\) is a permitted replacement. Local optimality implies that \(y\not\succ_\mu z\).

For distinct outcomes, the masses preferring either direction sum to \(1\), since every individual ranking is complete and strict. The no-tie promise therefore implies \(z\succ_\mu y\).

Conversely, suppose \(z\succ_\mu y\) for every \(y\in N_1(z)\). Under \(\mathcal A_*\), the permitted replacements from \(z\) are exactly these neighbors. None defeats \(z\), so \(z\) is locally optimal. This proves both directions. \(\square\)

This is the supplied characterization, proved here directly for the stated replacement rule. It also agrees with the characterization restated by [Mitsui–Settepanella](https://link.springer.com/article/10.1007/s40574-022-00335-7).

2. Exact computation with rational masses

Write each input mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\) encoded in binary. Define
\[ D=\prod_{t=1}^{\tau}b_t, \qquad w_t=a_t(D/b_t). \]
Every \(w_t\) is an integer, and the normalization hypothesis gives
\[ \sum_{t=1}^{\tau}w_t=D. \]

For each neighbor \(y\), define
\[ S_y=\sum_{t:y\succ_t z}w_t. \]
Then \(y\succ_\mu z\) holds exactly when \(2S_y>D\). The promise excludes equality. Consequently, the decision criterion is
\[ 2S_y<D\quad\text{for every }y\in N_1(z). \]

These integers have polynomial bit length. Indeed, the binary length of \(D\) is at most \(1+\sum_t\log_2 b_t\), hence is \(O(L)\). Positivity and normalization imply \(w_t\le D\) and \(S_y\le D\), so all weights and accumulators also have \(O(L)\) bits.

Thus even an exponentially large numerical denominator causes no difficulty: its binary length controls the arithmetic cost.

3. Algorithm and correctness

Use one accumulator for each pair \((i,a)\) with \(i\in\{1,\ldots,n\}\) and \(a\in[q]\setminus\{z_i\}\). This pair represents the neighbor obtained by changing coordinate \(i\) to \(a\).

  • Compute \(D\) and the integer weights \(w_t\). Initialize all \(k\) accumulators to zero.
  • For each type \(t\), scan its ranking from most preferred downward until reaching \(z\). For each preceding outcome \(x\), compare its coordinates with \(z\). If exactly one coordinate differs, say coordinate \(i\) with value \(a\), add \(w_t\) to accumulator \((i,a)\).
  • If any accumulator \(S\) satisfies \(2S>D\), return no. Otherwise return yes and output \(\mathcal A_*\).

For each neighbor \(y\), its accumulator receives \(w_t\) exactly when \(y\) precedes \(z\) in type \(t\)'s ranking. It therefore equals \(S_y\). Step 3 implements the exact criterion proved above.

On a no instance, an accumulator exceeding half also identifies a certificate of impossibility: a one-feature neighbor defeating \(z\), which every covering scheme permits.

4. Running times

Let \(b=\lceil\log_2 q\rceil\). Using schoolbook integer arithmetic and a bit-cost random-access implementation:

  • Computing \(D\) and all \(w_t\) costs \(O(\tau L^2)\) bit operations.
  • Scanning the rankings and comparing coordinates costs \(O(L+\tau mnb)\).
  • There are at most \(\tau k\) accumulator additions, costing \(O(\tau kL)\).
  • The final comparisons cost \(O(kL)\).

Since \(\tau\ge1\), the total bound is
\[ O\!\left(L+\tau L^2+\tau mn\lceil\log_2 q\rceil +\tau n(q-1)L\right). \]

A sequential implementation can instead process each neighbor separately, scanning every ranking to determine whether that neighbor precedes \(z\). This gives the conservative bound
\[ O\!\left(L+\tau L^2+ \tau n(q-1)\bigl(mn\lceil\log_2 q\rceil+L\bigr)\right). \]
It avoids needing random access to the accumulators.

Both bounds are polynomial in the actual input length. To verify this explicitly, the distinct neighbors satisfy \(k\le m-1\), and the explicit rankings imply \(\tau m=O(L)\). Moreover,
\[ n\lceil\log_2 q\rceil\le2n\log_2 q=2\log_2 m. \]
The sequential bound is therefore \(O(L^3)\). The output consists of \(n\) singleton objects and takes \(O(n\log(n+1))\) bits.

Hence the rational-mass input problem is polynomial-time solvable, with a polynomial-time constructible witness.
