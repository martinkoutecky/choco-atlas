The continuous mirror question, as graded

Given candidates \(C\), a finite set \(T\subseteq S_C\) of complete ranking types, rational masses \(\mu_t\ge0\) summing to \(1\), and unit-capped utilities consistent with each type, compute a lottery \(p^\star\in\Delta(C)\) minimizing \(\max_{(u_t)}[\max_{a\in C}W(a)-\sum_{b\in C}p_bW(b)]\), where \(W(c)=\sum_{t\in T}\mu_tu_t(c)\), equivalently solving the paper's exact LP with \(q_b^a(\mu)=\sum_{t\in T}\mu_t\mathbf{1}[b\succeq_t a]/\operatorname{rk}_t(a)\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set with \(m=|C|\). A society is given by its support: a list \(T\) of \(\tau\) distinct strict complete ranking types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
For each type \(t\), the unknown utility vector belongs to \(\mathcal U_t=\{u_t\in\mathbb R_{\ge0}^{C}:\sum_{c\in C}u_t(c)\le1,\ a\succ_t b\Rightarrow u_t(a)\ge u_t(b)\}\). Thus utilities may tie despite strict rankings, and the cap applies to total utility.
For \(W_u(c)=\sum_{t\in T}\mu_tu_t(c)\), define \(R(p)=\max_{u\in\prod_{t\in T}\mathcal U_t}[\max_{a\in C}W_u(a)-\sum_{b\in C}p_bW_u(b)]\). The computational problem is to output an exact rational lottery \(p^\star\in\arg\min_{p\in\Delta(C)}R(p)\).

Is computing such an exact minimax lottery polynomial-time solvable in \(m\), \(\tau\), and \(L\), or is it NP-hard?

For an explicit finite list of voters with these utility constraints, an exact instance-optimal lottery is computable in polynomial time. That discrete guarantee measures input size using the explicit voters, whereas this question uses support size and binary rational masses.

Modeling choices made when packaging the task

  • Interpreted unit-capped utilities as nonnegative utilities whose sum over candidates is at most one, following the discrete definition.
  • Specified strict complete rankings with weak utility consistency, so equally valued candidates are permitted.
  • Treated utilities as unknown real vectors chosen adversarially, rather than additional supplied input.
  • Removed zero-mass types from the input support and defined L as the total input bit length.
  • Required a nonempty candidate set and an exact rational optimal lottery.

Result

An exact minimax lottery is computable in polynomial time in \(m\), \(\tau\), and \(L\). We construct a rational linear program with \(m+m\tau+1\) variables and \(O(m^2\tau)\) constraints whose optimal solutions yield precisely the required lotteries.

1. Decomposing the feasible utilities

For each type \(t\), write its ranking as \(c_{t,1}\succ_t\cdots\succ_t c_{t,m}\), and define the prefix \(P_{t,k}=\{c_{t,1},\ldots,c_{t,k}\}\).

Let \(v_{t,k}\) assign utility \(1/k\) to every candidate in \(P_{t,k}\) and zero elsewhere. We claim that

\(\displaystyle \mathcal U_t=\operatorname{conv}\{0,v_{t,1},\ldots,v_{t,m}\}.\)

Each listed vector satisfies the nonnegativity, ranking, and total-utility constraints. Since these constraints define a convex set, their convex hull is contained in \(\mathcal U_t\).

For the reverse containment, take any \(u_t\in\mathcal U_t\), put \(x_i=u_t(c_{t,i})\), and set \(x_{m+1}=0\). Define \(\lambda_k=k(x_k-x_{k+1})\). Ranking consistency gives \(\lambda_k\geq0\), and telescoping gives

\(\displaystyle \sum_{k=1}^m\lambda_k=\sum_{k=1}^m k(x_k-x_{k+1})=\sum_{i=1}^m x_i\leq1.\)

Moreover, for every \(i\),

\(\displaystyle \sum_{k=1}^m\lambda_kv_{t,k}(c_{t,i})=\sum_{k=i}^m(x_k-x_{k+1})=x_i.\)

Thus \(u_t=\sum_{k=1}^m\lambda_kv_{t,k}\), with the remaining convex-combination weight assigned to zero. This proves the claim.

2. An exact formula for regret

For \(p\in\Delta(C)\), define \(p(P)=\sum_{b\in P}p_b\) and

\(\displaystyle h_{a,t}(p)=\max_{u_t\in\mathcal U_t}\left[u_t(a)-\sum_{b\in C}p_bu_t(b)\right].\)

The decomposition above shows that

\(\displaystyle h_{a,t}(p)=\max\left\{0,\max_{1\leq k\leq m}\frac{\mathbf1_{\{a\in P_{t,k}\}}-p(P_{t,k})}{k}\right\}.\)

Indeed, the maximized expression is linear in \(u_t\), so its maximum over the convex hull equals its maximum over the listed vectors. At \(k=m\), the displayed fraction is zero because \(P_{t,m}=C\) and \(p(C)=1\). Consequently,

\[\displaystyle h_{a,t}(p)=\max_{1\leq k\leq m}\frac{\mathbf1_{\{a\in P_{t,k}\}}-p(P_{t,k})}{k}.\tag{1}\]

In particular, \(0\leq h_{a,t}(p)\leq1\).

Each utility set is nonempty and compact, so all maxima below are attained. Expanding the welfare expression and exchanging the two maxima gives

\(\displaystyle R(p)=\max_{a\in C}\max_{u\in\prod_t\mathcal U_t}\sum_{t\in T}\mu_t\left[u_t(a)-\sum_{b\in C}p_bu_t(b)\right].\)

For fixed \(a\), each summand depends only on \(u_t\). Choosing a maximizing utility independently for every type is permitted by the Cartesian-product feasible set. Since every \(\mu_t\) is positive, this proves

\[\displaystyle R(p)=\max_{a\in C}\sum_{t\in T}\mu_t h_{a,t}(p).\tag{2}\]

3. A polynomial-size linear program

Introduce variables \(p_b\) for candidates, \(z_{a,t}\) for candidate–type pairs, and \(r\). Minimize \(r\) subject to

\(\displaystyle \sum_{b\in C}p_b=1,\qquad p_b\geq0\quad(b\in C),\)

\(\displaystyle 0\leq z_{a,t}\leq1\quad(a\in C,\ t\in T),\qquad 0\leq r\leq1,\)

\[\displaystyle kz_{a,t}+\sum_{b\in P_{t,k}}p_b\geq\mathbf1_{\{a\in P_{t,k}\}}\quad(a\in C,\ t\in T,\ 1\leq k\leq m),\tag{3}\]

and

\[\displaystyle \sum_{t\in T}\mu_tz_{a,t}\leq r\quad(a\in C).\tag{4}\]

We verify exact equivalence.

For any feasible solution, dividing (3) by the positive integer \(k\) and taking the maximum over \(k\) yields \(z_{a,t}\geq h_{a,t}(p)\), by (1). Equations (2) and (4), together with positivity of the masses, then give \(R(p)\leq r\). Hence the linear program’s optimum is at least \(\min_{p\in\Delta(C)}R(p)\).

Conversely, for any lottery \(p\), set \(z_{a,t}=h_{a,t}(p)\) and \(r=R(p)\). Equations (1) and (2) imply (3) and (4). The bounds hold because \(0\leq h_{a,t}(p)\leq1\) and the masses sum to one, so \(0\leq R(p)\leq1\). Thus these choices form a feasible solution.

The two optimal values therefore coincide. If \((p^\star,z^\star,r^\star)\) is an optimal linear-program solution, then

\(\displaystyle \min_{p\in\Delta(C)}R(p)\leq R(p^\star)\leq r^\star=\min_{p\in\Delta(C)}R(p).\)

Accordingly, \(p^\star\) is an exact minimax lottery.

4. Exact rational output and bit complexity

The program has \(m+m\tau+1\) variables and \(O(m^2\tau)\) constraints. Its coefficients are integers of magnitude at most \(m\), together with the input rational masses. Its total binary encoding length is therefore polynomial in \(m\), \(\tau\), and \(L\), and it can be constructed within that bound.

The feasible region is nonempty: choose any lottery, set every \(z_{a,t}=1\), and set \(r=1\). It is also bounded by the explicit variable bounds and the lottery constraints.

We now apply the standard exact rational linear-programming theorem: a linear program given explicitly by binary rational coefficients, with a nonempty bounded feasible region, admits an exact rational optimal solution computable in time polynomial in its total encoding length. Exact polynomial-time LP algorithms are discussed in [Gleixner and Steffy, Section 1.3](https://arxiv.org/html/1912.12820v1#S1.SS3). All hypotheses have been checked above.

There is also no hidden exponential output requirement. An optimal vertex exists; its coordinates solve a nonsingular subsystem of the rational constraints. Clearing denominators, Cramer’s rule and Hadamard’s determinant bound give polynomial bit length for those coordinates.

Solving the displayed program exactly and outputting its \(p\)-coordinates therefore completes the task. Binary rational masses are handled directly as coefficients, without expanding them into an explicit voter population.
