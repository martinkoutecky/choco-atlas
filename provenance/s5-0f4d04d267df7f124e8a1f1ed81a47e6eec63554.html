The continuous mirror question, as graded

Given programs \(P\), applicant types \(T\) with rational masses \(\mu_t\) summing to \(1\), acceptable type-program pairs, type rankings, program priority tiers over types, and per-unit costs \(c(p)\in\{0,1\}\), find a mass assignment \(x_{t,p}\geq 0\) with \(\sum_p x_{t,p}=\mu_t\) for every type. Set capacity \(y_p=\sum_t x_{t,p}\), and minimize \(\sum_p c(p)y_p\), subject to no blocking pair: for every acceptable \((t,p)\), \(\left(\sum_{r:\,p\succ_t r}x_{t,r}\right)\left(\sum_{u:\,t\succ_p u}x_{u,p}\right)=0\).

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a nonempty set of \(m\) programs. A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length.
Mutual acceptability is specified by \(E\subseteq T\times P\), with every type having a nonempty acceptable set. Each type strictly ranks its acceptable programs; each program has ordered priority tiers over its acceptable types. Write \(t\succ_p u\) only for strictly higher priority; ties, including individuals of the same type, are not broken.
Every program has zero initial capacity and per-unit cost \(c(p)\in\{0,1\}\). An assignment consists of divisible masses \(x_{t,p}\geq0\), zero outside \(E\), with \(\sum_{p\in P}x_{t,p}=\mu_t\). Its chosen capacity is \(y_p=\sum_{t\in T}x_{t,p}\), and its cost is \(C(x)=\sum_{p\in P}c(p)y_p\).
An assignment is feasible precisely when, for every \((t,p)\in E\), \(\left(\sum_{r:\,p\succ_t r}x_{t,r}\right)\left(\sum_{u:\,t\succ_p u}x_{u,p}\right)=0\). Thus blocking requires both strictly worse assigned mass and strictly lower-priority mass at the desired program; capacities equal occupancy.

Does this minimum-cost mass assignment problem admit a polynomial-time multiplicative \(\alpha\)-approximation for some universal constant \(\alpha\geq1\), or is achieving every such constant factor NP-hard? Running times are measured in \(m,\tau,L\), and the guarantee includes instances with optimum \(0\).

For discrete applicants with strict preferences and zero initial capacities, no constant-factor approximation exists unless \(\mathrm{P}=\mathrm{NP}\), even with costs \(\{0,1\}\) and preferences obtained by restricting a common strict ordering on each side; with two distinct costs, an \(\ell_a\)-approximation exists, where \(\ell_a\) is the maximum applicant list length. Result

For every fixed \(\alpha\geq1\), achieving a multiplicative \(\alpha\)-approximation is \(\mathrm{NP}\)-hard. Consequently, no polynomial-time approximation with a universal constant factor exists unless \(\mathrm{P}=\mathrm{NP}\).

The decisive fact is that dividing a type’s mass cannot improve the optimum: every feasible mass assignment can be rounded to an assignment placing each type entirely at one program, without increasing cost.

1. A support-preserving rounding lemma

For an assignment \(x\), define its positive support by
\[ S(x)=\{(t,p)\in E:x_{t,p}>0\}. \]

Lemma. If \(x\) is feasible and \(z\) satisfies the assignment constraints with \(S(z)\subseteq S(x)\), then \(z\) is feasible.

Proof. Suppose that \(z\) were infeasible. Then some acceptable pair \((t,p)\) would have both
\[ \sum_{r:\,p\succ_t r}z_{t,r}>0 \qquad\text{and}\qquad \sum_{u:\,t\succ_p u}z_{u,p}>0. \]
Because these are finite sums of nonnegative terms, there would exist programs and types \(r,u\) such that
\[ p\succ_t r,\quad t\succ_p u,\quad z_{t,r}>0,\quad z_{u,p}>0. \]
Support inclusion implies \(x_{t,r}>0\) and \(x_{u,p}>0\). Thus both corresponding sums for \(x\) are positive, contradicting its feasibility. This proves the lemma. \(\square\)

Call an assignment pure if each type places its entire mass at one program.

Corollary. Every feasible assignment \(x\) can be converted to a feasible pure assignment \(z\) with \(C(z)\leq C(x)\).

Proof. Since \(\mu_t>0\), the set \(S_t=\{p:x_{t,p}>0\}\) is nonempty for every type. Choose \(p_t\in S_t\) minimizing \(c(p)\), and set
\[ z_{t,p_t}=\mu_t,\qquad z_{t,p}=0\quad\text{for }p\neq p_t. \]
The assignment constraints hold, and feasibility follows from the lemma. For each type,
\[ \mu_t c(p_t) = \sum_{p\in S_t}x_{t,p}c(p_t) \leq \sum_{p\in S_t}x_{t,p}c(p). \]
Summing over types proves the cost inequality. \(\square\)

In particular, the minimum over mass assignments equals the minimum over pure assignments. This minimum exists: assigning every type to its most-preferred acceptable program is feasible, and there are only finitely many pure assignments. The rounding procedure is polynomial-time for an explicitly represented rational assignment.

The lemma uses only strict comparisons, so it remains valid with the priority ties specified in the question.

2. Reduction from the discrete problem

We use the discrete hardness result given in the question: for every fixed constant factor, minimum-cost complete envy-free assignment with zero initial capacities is inapproximable unless \(\mathrm{P}=\mathrm{NP}\), even with costs \(\{0,1\}\) and strict preferences obtained by restricting master orders on both sides. This is Theorem 1.2 of the cited paper; its Section 5.1 explicitly uses costs zero and one. [Discrete hardness theorem and construction](https://arxiv.org/html/2503.23328v1#S5.SS1)

Let a discrete instance have \(n\geq1\) applicants and program set \(P_D\). Write \(D(M)=\sum_a c(M(a))\) for the cost of a complete discrete assignment \(M\).

Choose the smallest power of two \(N\) with \(N\geq n\). Construct a mass instance as follows:

  • Create one type for each original applicant, preserving acceptable programs and preferences.
  • Preserve every original program’s cost and strict priority order over the original types.
  • If \(N>n\), add \(N-n\) dummy types and one dummy program \(d\). Each dummy type accepts only \(d\); no original type accepts \(d\), and no dummy type accepts an original program. Set \(c(d)=0\), with any strict priority order over the dummy types.
  • Give every type mass \(\mu_t=1/N\).

All masses are positive dyadic rationals and sum to one. Every type has a nonempty acceptable set. There are \(\tau=N<2n\) types, at most \(|P_D|+1\) programs, and only polynomially many additional input bits. Hence the construction is polynomial-time in the original input length and produces an instance of polynomial size in \(m,\tau,L\).

If the original preferences arise from master orders, the constructed preferences do too: append \(d\) to the program master order and append the dummy types to the applicant master order. Restricting these extended orders gives all constructed lists.

Feasibility correspondence

For a pure assignment, let \(f(t)\) denote the program receiving type \(t\)’s entire mass. Its feasibility condition fails exactly when there are types \(t,u\) and a program \(p\) satisfying
\[ p\succ_t f(t),\qquad f(u)=p,\qquad t\succ_p u. \]
Indeed, the first condition makes the first factor in the blocking product positive, and the last two make the second factor positive. Conversely, a positive blocking product supplies precisely such witnesses.

This is exactly a discrete justified-envy pair. Since capacities equal occupancy, there is no additional vacancy condition. Dummy types cannot participate in blocking pairs with original types and are forced to \(d\).

Consequently, feasible pure assignments correspond to complete envy-free assignments of the original applicants, together with the forced dummy assignments. Their costs satisfy
\[ C(z)=\frac{D(M)}{N}. \]
By the rounding corollary, arbitrary divisible assignments cannot lower this minimum. Therefore,
\[ \operatorname{OPT}_{\mathrm{mass}} = \frac{\operatorname{OPT}_{\mathrm{discrete}}}{N}. \]

3. Transfer of every constant approximation factor

Fix any constant \(\alpha\geq1\), and suppose a polynomial-time algorithm returns a feasible mass assignment \(x\) satisfying
\[ C(x)\leq\alpha\,\operatorname{OPT}_{\mathrm{mass}}. \]

Apply that algorithm to the constructed instance, round its output by the corollary, and remove the dummy types. The resulting complete discrete assignment \(M\) is envy-free and satisfies
\[ D(M) = N C(z) \leq N C(x) \leq N\alpha\,\operatorname{OPT}_{\mathrm{mass}} = \alpha\,\operatorname{OPT}_{\mathrm{discrete}}. \]
All steps are polynomial-time. This would give a polynomial-time \(\alpha\)-approximation for the discrete problem, contradicting the stated hardness theorem unless \(\mathrm{P}=\mathrm{NP}\).

Since \(\alpha\) was arbitrary, the claimed hardness holds for every universal constant factor.

4. The optimum-zero case

For completeness, optimum zero itself has a simple characterization:
\[ \operatorname{OPT}=0 \quad\Longleftrightarrow\quad \text{every type accepts at least one zero-cost program}. \]

Necessity follows because a positive-mass type accepting only cost-one programs contributes exactly \(\mu_t>0\) to every assignment’s cost.

For sufficiency, assign every type entirely to its most-preferred zero-cost acceptable program. At any zero-cost program \(p\), no type has mass assigned strictly below \(p\): its chosen program is at least as preferred as \(p\). At any cost-one program, occupancy is zero. Thus every blocking product vanishes, and the assignment has zero cost.

The hardness proof therefore does not require a difficult zero-cost decision problem. Its scaling identity and rounding inequality preserve approximation guarantees, including when the optimum is zero.
