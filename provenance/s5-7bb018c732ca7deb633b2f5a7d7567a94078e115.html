2. An equivalent rational linear program

Index the support by \(T=\{1,\ldots,\tau\}\). Define the allowed, nontrivial report pairs by

\(\mathcal E=\{(t,r)\in T^2:t\ne r,\ (b_t,\delta_t)=(b_r,\delta_r)\}\).

These pairs can be enumerated using exact comparisons of the input rationals and integers, and \(|\mathcal E|\leq\tau(\tau-1)\). Reporting oneself gives an identically satisfied truthfulness constraint and can be omitted.

Set

\(a=\sum_{t\in T}\mu_t\alpha_t,\qquad d_{tj}=\mu_tc_{tj}\).

Then

\(F(x)=a+\sum_{t\in T}\sum_{j=1}^m d_{tj}x_{tj}\).

Use the \(\tau m\) allocation variables and \(\tau\) payment variables as real LP variables. Maximize

\(\sum_{t\in T}\sum_{j=1}^m d_{tj}x_{tj}\)

subject to the following inequalities:

  • Allocation bounds: \(0\leq x_{tj}\leq1\), for every \(t,j\).
  • Service limits: \(\sum_{j=1}^m x_{tj}\leq\delta_t\), for every \(t\).
  • Capacities: \(\sum_{t\in T}\mu_tx_{tj}\leq\kappa_j\), for every \(j\).
  • Sustainability: \(\sum_{t\in T}\sum_{j=1}^m d_{tj}x_{tj}-\sum_{t\in T}\mu_tp_t\leq-a\).
  • Budget caps: \(p_t\leq b_t\), for every \(t\).
  • Participation: \(p_t-\sum_{j=1}^m v_{tj}x_{tj}\leq0\), for every \(t\).
  • Truthfulness: \(p_t-p_r+\sum_{j=1}^m v_{tj}(x_{rj}-x_{tj})\leq0\), for every \((t,r)\in\mathcal E\).

Every coefficient is rational. In particular, truthfulness is linear because \(v_t\) is input data.

Each displayed inequality is exactly a rearrangement of a constraint in the question. Conversely, every required constraint appears above, apart from the tautological self-report constraints. Thus the LP and the original problem have identical feasible allocation-payment pairs. Dropping the constant \(a\) from the objective preserves all maximizers; adding it back recovers the original objective value.

The stipulated fixed population masses are used here: every capacity and sustainability constraint contains the same input masses, regardless of the individual report being compared.

3. Feasible payments are bounded, and an optimum exists

Although payments may have either sign, they cannot be arbitrarily negative in a feasible solution.

The promised nonnegativity of every \(W_t\) on the allocation box implies \(F(x)\geq0\). Sustainability therefore gives

\(\sum_{s\in T}\mu_sp_s\geq F(x)\geq0\).

Fix \(t\in T\). Using the budget caps for the other types,

\(\mu_tp_t\geq-\sum_{s\ne t}\mu_sp_s\geq-\sum_{s\ne t}\mu_sb_s\).

Since \(\mu_t>0\), division yields

\(p_t\geq-\dfrac{\sum_{s\ne t}\mu_sb_s}{\mu_t}\).

Consequently, we may append these rational lower bounds without changing the feasible set. All allocation and payment variables are then bounded above and below.

The feasible set is an intersection of finitely many closed halfspaces, so it is closed. Together with these bounds, this makes it compact. If it is nonempty, the continuous affine objective therefore attains a maximum. Thus the algorithm needs to distinguish only infeasibility from an attained finite optimum.

4. Polynomial encoding size and exact computation

There are

\(n=\tau(m+1)\)

variables. Before appending the payment lower bounds, there are

\(2\tau m+3\tau+m+1+|\mathcal E|\)

inequalities. Appending the bounds adds \(\tau\) inequalities, so the total is \(O(\tau m+\tau^2+m)\).

The coefficients introduced in the construction also have polynomial binary length:

  • Each \(d_{tj}\) is a product of two input rationals.
  • The constant \(a\) is a sum of \(\tau\) such products.
  • Each payment lower bound is a sum of at most \(\tau-1\) products, followed by division by a positive input rational.

For completeness, a common denominator for a finite rational sum can be taken as the product of its summands’ denominators. Its bit length is at most the sum of their bit lengths. The numerator is a sum of correspondingly scaled integers, requiring only an additional logarithmic number of bits in the number of summands. Products and division similarly add numerator and denominator bit lengths. Hence all these operations produce numbers of polynomial encoding length and can be performed in polynomial time.

This remains true when a mass is numerically very small: division by \(\mu_t\) uses its binary representation and does not require enumerating a population of size proportional to \(1/\mu_t\). The entire explicitly constructed LP therefore has encoding length polynomial in \(m,\tau,L\).

We now apply the standard exact rational linear programming theorem: an explicitly encoded LP with rational data can be solved in polynomial time in its binary encoding length, detecting infeasibility or returning an exact rational optimum when one exists. An equivalent ellipsoid formulation, including polynomial bit complexity and an optimal vertex output, is stated in [Yang Cai’s thesis, Section 2.6, Theorem 1](https://www.cs.yale.edu/homes/cai/publication/thesis/thesis.pdf).

All hypotheses have been checked: the program is finite and explicitly encoded, its coefficients are rational, its encoding size is polynomial, and its feasible region is bounded.

The exact output also has polynomial length. To see this directly, a linear objective on a nonempty bounded polytope has an optimal vertex. At a vertex, the active constraint normals span the ambient space: otherwise, a nonzero direction orthogonal to all active normals would permit sufficiently small feasible perturbations in both directions, contradicting extremality. Thus an optimal vertex is uniquely determined by \(n\) independent active rational equations.

Clear denominators in those equations. The resulting integer entries have polynomial bit length, say at most \(B\). By the determinant expansion, their \(n\)-dimensional determinants have absolute value at most \(n!\,2^{nB}\). Cramer’s rule therefore represents every vertex coordinate as a rational with numerator and denominator bit length \(O(nB+n\log n)\). Evaluating \(F\) at the returned solution likewise takes polynomial time and gives its exact rational value.
