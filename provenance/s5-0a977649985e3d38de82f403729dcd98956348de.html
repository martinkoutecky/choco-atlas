The continuous mirror question, as graded

Given a finite type graph \(H=(T,E,D)\), positive rational masses \(\mu_t\) summing to one, and a target type \(t\), define \(V_H(x)\) as the maximum matching worth over pair masses \(y\geq 0\): cross-type pairs use edges in \(E\), same-type pairs are allowed for types in \(D\), and each type's incident pair mass (counting a same-type pair twice) is at most its mass \(x_a\). Under the promise that the dual minimizing \(\sum_{a\in T}\mu_a z_a\), subject to \(z_a\geq 0\), \(z_a+z_b\geq 1\) for \(\{a,b\}\in E\), and \(2z_a\geq 1\) for \(a\in D\), has a unique optimum, compute its coordinate \(z_t\), equivalently the integrated marginal worth \(\int_0^1 \partial_t V_H(s\mu)\,ds\).

Packaged proof task (what the prover saw — nothing else)

Let \(H=(T,E,D)\), where \(E\subseteq\binom{T}{2}\) specifies permitted cross-type pairs and \(D\subseteq T\) specifies types permitting pairs of distinct agents of the same type. Every permitted pair has worth \(1\).
A society is given by its support: the list of \(\tau=|T|\) types with positive mass, each mass \(\mu_a\) a binary rational, with \(\sum_{a\in T}\mu_a=1\). Here \(\tau\) is the support size, not the number of possible types. Set \(m=|E|+|D|\), and let \(L\) be the total input bit length.
For \(x\in\mathbb R_{\geq0}^{T}\), define \(V_H(x)=\max\{\sum_{e\in E}y_e+\sum_{a\in D}y_{aa}:y\geq0,\ \sum_{e\in E:a\in e}y_e+2y_{aa}\leq x_a\text{ for every }a\in T\}\), taking \(y_{aa}=0\) when \(a\notin D\). Pair masses are divisible real quantities.
The input includes a target type \(t\in T\) and promises that \(\min\{\sum_{a\in T}\mu_a z_a:z\geq0,\ z_a+z_b\geq1\text{ for }\{a,b\}\in E,\ 2z_a\geq1\text{ for }a\in D\}\) has a unique optimizer \(z^*\). The requested output is the exact rational coordinate \(z_t^*\), equivalently \(\int_0^1\partial_t V_H(s\mu)\,ds\), with the endpoint derivative at \(s=0\) irrelevant.

Can this promised coordinate-computation problem be solved in time polynomial in \(m,\tau,L\), or is it NP-hard under polynomial-time Turing reductions?

For finite unweighted matching games, exact Shapley-value computation is \(\#\mathrm P\)-hard under polynomial-time Turing reductions; computing the raw Shapley value is \(\#\mathrm P\)-complete. This discrete result concerns permutation-averaged marginal contributions and does not establish the complexity of the continuous problem defined above.

  • Made maximum matching worth explicit as the total pair mass, with unit worth for every permitted pair, following the unweighted anchor.
  • Defined m as the number of permitted pair kinds and L as the total input bit length, since the continuous question supplied neither convention.
  • Specified exact rational output and polynomial-time Turing reductions for the computational hardness question, consistent with the discrete anchor's reduction model.

Result

The promised coordinate-computation problem is polynomial-time solvable in \(m,\tau,L\). A single minimum-cut computation recovers the entire vector \(z^*\). Moreover, every coordinate of \(z^*\) belongs to \(\{0,\tfrac12,1\}\).

The proof below gives an exact algorithm and verifies the stated integral identity.

1. The dual feasible region

Define

\(P=\{z\in[0,1]^T:z_a+z_b\geq1\text{ for }\{a,b\}\in E,\quad 2z_a\geq1\text{ for }a\in D\}.\)

Restricting the dual optimization to \(P\) does not change its optimum. Indeed, for any feasible nonnegative vector \(z\), set \(\bar z_a=\min\{z_a,1\}\). For a cross-type constraint, either neither coordinate changes, or one becomes \(1\), which suffices because the other remains nonnegative. For a same-type constraint, clipping preserves \(z_a\geq\tfrac12\). Thus \(\bar z\) remains feasible and has no larger objective for any nonnegative weights.

The set \(P\) is nonempty because the constant vector \(\tfrac12\) is feasible. It is compact, so every linear objective attains its minimum there. In particular, the promised unique optimizer \(z^*\) lies in \(P\).

2. An exact reduction to bipartite vertex cover

Construct a bipartite graph \(B\) with vertex classes

\(T_{\mathrm L}=\{a_{\mathrm L}:a\in T\},\qquad T_{\mathrm R}=\{a_{\mathrm R}:a\in T\}.\)

For every \(\{a,b\}\in E\), include both edges \(a_{\mathrm L}b_{\mathrm R}\) and \(b_{\mathrm L}a_{\mathrm R}\). For every \(a\in D\), include the edge \(a_{\mathrm L}a_{\mathrm R}\).

Fix arbitrary nonnegative weights \(w_a\), and assign weight \(w_a\) to each copy of type \(a\). For a vertex cover \(C\) of \(B\), define

\(z^C_a=\tfrac12\bigl(\mathbf1_{\{a_{\mathrm L}\in C\}}+\mathbf1_{\{a_{\mathrm R}\in C\}}\bigr).\)

Here a vertex cover means a set containing at least one endpoint of every edge.

First direction. Every \(z^C\) belongs to \(P\). For \(\{a,b\}\in E\), covering the two corresponding edges gives

\(\mathbf1_{\{a_{\mathrm L}\in C\}}+\mathbf1_{\{b_{\mathrm R}\in C\}}\geq1,\qquad \mathbf1_{\{b_{\mathrm L}\in C\}}+\mathbf1_{\{a_{\mathrm R}\in C\}}\geq1.\)

Adding and dividing by \(2\) gives \(z^C_a+z^C_b\geq1\). If \(a\in D\), covering \(a_{\mathrm L}a_{\mathrm R}\) gives \(2z^C_a\geq1\).

Writing \(W_w(C)\) for the cover’s weight, we also have

\(W_w(C)=2\sum_{a\in T}w_a z^C_a.\)

Consequently,

\(\min_C W_w(C)\geq2\min_{z\in P}\sum_{a\in T}w_a z_a.\)

Reverse direction. Given \(z\in P\) and \(\lambda\in(0,1)\), define

\(C_\lambda=\{a_{\mathrm L}:z_a\geq\lambda\}\cup\{a_{\mathrm R}:z_a\geq1-\lambda\}.\)

This is a vertex cover. If an edge \(a_{\mathrm L}b_{\mathrm R}\) were uncovered, then \(z_a<\lambda\) and \(z_b<1-\lambda\), contradicting \(z_a+z_b\geq1\). The same argument applies to the reversed cross-type edge. An uncovered edge \(a_{\mathrm L}a_{\mathrm R}\) would similarly imply \(2z_a<1\).

Since \(0\leq z_a\leq1\), each copy of \(a\) is selected for a set of thresholds of length \(z_a\). Therefore

\(\int_0^1 W_w(C_\lambda)\,d\lambda=2\sum_{a\in T}w_a z_a.\)

The cover weight takes only finitely many values as \(\lambda\) varies. Hence some threshold has weight at most this average. Applying this to a minimizer in \(P\) proves

\(\min_C W_w(C)=2\min_{z\in P}\sum_{a\in T}w_a z_a.\)

In particular, averaging the two copy indicators of any minimum-weight cover produces an optimal dual vector.

Taking \(w=\mu\), uniqueness forces that vector to equal \(z^*\). This also proves \(z^*_a\in\{0,\tfrac12,1\}\) for every type \(a\).

3. Computing the cover with one minimum cut

Use a directed network with source \(\sigma\), sink \(\rho\), and the vertices of \(B\). Include:

  • An arc \(\sigma\to a_{\mathrm L}\) of capacity \(\mu_a\) for each type.
  • An arc \(a_{\mathrm R}\to\rho\) of capacity \(\mu_a\) for each type.
  • An arc \(a_{\mathrm L}\to b_{\mathrm R}\) of capacity \(2\) for each edge \(a_{\mathrm L}b_{\mathrm R}\) of \(B\).

A directed cut is a partition \((S,\bar S)\) with \(\sigma\in S\) and \(\rho\in\bar S\); its capacity is the sum of capacities of arcs directed from \(S\) to \(\bar S\).

The cut \(S=\{\sigma\}\) has capacity \(\sum_a\mu_a=1\). Hence no minimum cut crosses an arc of capacity \(2\).

For a minimum cut, set

\(C=(T_{\mathrm L}\cap\bar S)\cup(T_{\mathrm R}\cap S).\)

An uncovered edge would have its left endpoint in \(S\) and its right endpoint in \(\bar S\), causing a capacity-\(2\) arc to cross the cut. Thus \(C\) is a cover. Since no middle arc crosses, the cut capacity equals \(W_\mu(C)\).

Conversely, any cover \(C\) defines a cut by placing unselected left vertices and selected right vertices in \(S\), together with \(\sigma\). No middle arc crosses, and its capacity is \(W_\mu(C)\). Therefore a minimum cut gives a minimum-weight cover.

The requested output is exactly

\(z_t^*=\tfrac12\bigl(\mathbf1_{\{t_{\mathrm L}\in C\}}+\mathbf1_{\{t_{\mathrm R}\in C\}}\bigr).\)

4. Exact bit complexity

The network has \(2\tau+2\) vertices and \(2\tau+2|E|+|D|\) arcs.

Write the input masses as \(\mu_a=p_a/q_a\), and let \(Q=\prod_a q_a\). The binary length of \(Q\) is bounded by the sum of the input denominator lengths, hence is \(O(L)\). Multiplying every capacity by \(Q\) gives integer capacities of at most \(2Q\), without changing the minimum cuts.

The Edmonds–Karp algorithm computes an exact maximum flow and minimum cut using \(O(NA^2)\) arithmetic operations for a network with \(N\) vertices and \(A\) arcs. This bound is independent of the capacity magnitudes. See [Princeton’s maximum-flow reference](https://algs4.cs.princeton.edu/64maxflow/).

Here all flow and residual-capacity arithmetic uses integers of \(O(L)\) bits. Thus the overall bit complexity is polynomial in \(m,\tau,L\). The output itself is one of \(0,\tfrac12,1\), so no approximation or rational reconstruction is needed.

5. Verification of the derivative identity

For every \(x\geq0\), the primal defining \(V_H(x)\) is feasible by taking all pair masses zero. Summing its resource constraints gives

\(2\bigl(\sum_{e\in E}y_e+\sum_{a\in D}y_{aa}\bigr)\leq\sum_{a\in T}x_a,\)

so its objective is bounded. Its dual is feasible, for example at the constant vector \(\tfrac12\). Finite-dimensional linear-programming strong duality therefore applies and yields

\(V_H(x)=\min_{z\in P}x\cdot z.\)

Define the finite set

\(\mathcal Q=P\cap\{0,\tfrac12,1\}^T.\)

Section 2 applies to every nonnegative weight vector \(x\) and produces an optimal vector in \(\mathcal Q\). Consequently,

\(V_H(x)=\min_{q\in\mathcal Q}x\cdot q\qquad\text{for every }x\geq0.\)

Fix any \(s>0\). Multiplying the objective by \(s\) preserves its unique optimizer. Thus, for every \(q\in\mathcal Q\setminus\{z^*\}\),

\((s\mu)\cdot(q-z^*)>0.\)

There are finitely many such inequalities, and each remains strict in a sufficiently small neighborhood of \(s\mu\). Because every \(\mu_a>0\), that neighborhood can also be chosen inside the positive orthant. Hence throughout this neighborhood,

\(V_H(x)=x\cdot z^*.\)

It follows that \(\partial_t V_H(s\mu)=z_t^*\) for every \(s>0\), and therefore

\(\int_0^1\partial_t V_H(s\mu)\,ds=z_t^*.\)

This completes the polynomial-time solution. The stated discrete Shapley-value hardness does not affect this computation.
