The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t \ge 0\) summing to \(1\), a standard-compatibility relation \(S \subseteq T \times T\), and a rational per-capita reserve budget \(\beta\), let \(\mathcal{C}_3\) be the feasible directed cycle patterns of lengths \(1\) through \(3\), with repeated types allowed and counted by their occurrences. For each pattern \(C\), choose a rational mass \(q_C \ge 0\). Find an optimal allocation maximizing \(\sum_{C \in \mathcal{C}_3} |C|q_C\), subject to \(\sum_C a_t(C)q_C \le \mu_t\) for each \(t \in T\) and \(\sum_C r(C)q_C \le \beta\), where \(a_t(C)\) counts occurrences of type \(t\) and \(r(C)\) counts arcs outside \(S\); return the optimum and an optimal mass allocation.

A society is given by its support: a nonempty list \(T\) of \(\tau\) recipient–donor types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains an explicitly listed directed standard-compatibility relation \(S\subseteq T\times T\) and a binary-rational reserve budget \(\beta\geq0\). Every ordered type pair outside \(S\) is an available reserve arc costing one unit per unit of transplant mass; standard arcs cost zero. Self-loops are allowed, and there are no non-directed donors or chains.
Let \(\mathcal C_3\) contain all cyclic sequences \(C=(t_1,\ldots,t_k)\) with \(1\leq k\leq3\), identifying cyclic rotations. Repeated types are allowed and represent distinct portions of the same type's mass. Put \(t_{k+1}=t_1\), \(|C|=k\), \(a_t(C)=|\{i:t_i=t\}|\), and \(r(C)=|\{i:(t_i,t_{i+1})\notin S\}|\).

Conclusion

Computing the exact optimum and an optimal rational mass allocation is polynomial-time solvable in \(\tau\) and \(L\). The fixed cycle-length bound makes the given formulation a linear program of polynomial encoding length.

1. Enumerating all cycle variables

Index the listed types by \(\{1,\ldots,\tau\}\). For each \(k\in\{1,2,3\}\), enumerate every ordered tuple in \(T^k\), retaining it precisely when it is the lexicographically smallest of its cyclic rotations.

Every rotation class has exactly one distinct smallest tuple, so this enumerates exactly \(\mathcal C_3\). It preserves repeated types and identifies rotations only; reversing a directed cycle is not an additional identification.

Writing \(N=|\mathcal C_3|\), we have

\[ N\leq \tau+\tau^2+\tau^3=O(\tau^3). \]

For each retained cycle, compute \(a_t(C)\), \(r(C)\), and \(|C|\) directly from its at most three positions. In particular, a repeated occurrence contributes separately to \(a_t(C)\), as required.

After indexing the types and constructing a table for membership in \(S\), enumeration and coefficient computation take \(O(\tau^3)\) word operations. All preprocessing takes polynomial time in \(\tau\) and \(L\).

2. The linear program has polynomial encoding length

Define a matrix \(A\) with \(\tau+1\) rows and \(N\) columns by

\[ A_{t,C}=a_t(C),\qquad A_{\tau+1,C}=r(C). \]

Set \(b=(\mu_1,\ldots,\mu_\tau,\beta)^{\mathsf T}\) and \(c_C=|C|\). The resulting linear program is

\[ \max\{c^{\mathsf T}q:Aq\leq b,\ q\geq0\}. \]

Its constraints and objective are exactly those in the task. No integrality restriction or additional compatibility restriction has been introduced: every missing standard arc remains available, with its cost counted in \(r(C)\).

Every entry of \(A\) belongs to \(\{0,1,2,3\}\), and every entry of \(c\) belongs to \(\{1,2,3\}\). Consequently, the dense matrix uses \(O((\tau+1)N)=O(\tau^4)\) bits. The right-hand side uses \(O(L)\) bits. With nonnegativity specified separately in standard LP form, the total LP encoding length \(B\) satisfies

\[ B=O(\tau^4+L). \]

3. A rational optimum exists

The zero allocation is feasible because all masses and the reserve budget are nonnegative.

For every feasible real allocation, the identity \(\sum_{t\in T}a_t(C)=|C|\) gives

\[ \sum_{C\in\mathcal C_3}|C|q_C =\sum_{t\in T}\sum_{C\in\mathcal C_3}a_t(C)q_C \leq\sum_{t\in T}\mu_t=1. \]

Since each \(|C|\geq1\) and each \(q_C\geq0\), this also implies \(q_C\leq1\) for every cycle. Thus the real feasible region is a nonempty compact polytope, and the objective attains its maximum.

A linear functional on a nonempty compact polytope has a maximizing vertex. At such a vertex, \(N\) linearly independent active constraints determine the coordinates uniquely. Their coefficients and right-hand sides are rational, so Cramer’s rule shows that all coordinates are rational.

Therefore the real LP optimum is attained by an allocation allowed by the task. Optimizing over real variables does not change the rational-allocation optimum.

4. Exact algorithm and running time

Use the following standard rational linear-programming theorem: a linear program with explicitly encoded rational data can be solved in polynomial bit time, returning an exact rational optimal solution whenever it is feasible and has a finite optimum. See [Trevisan’s Stanford lecture notes, Sections 2.4–2.5](https://lucatrevisan.github.io/cs261/lecture05.pdf).

The required hypotheses have all been verified: the data are rational and explicitly encoded, the encoding length is polynomial, and the feasible region is nonempty and bounded.

The algorithm is therefore:

  • Enumerate the cycle representatives and construct \(A,b,c\).
  • Solve the rational LP exactly.
  • Return its optimal vector \(q^\star\) and the rational value \(c^{\mathsf T}q^\star\).

For a fixed polynomial-time rational LP algorithm, its running time is \(\operatorname{poly}(B)=\operatorname{poly}(\tau^4+L)\). Including construction and exact evaluation of the objective, the overall bit running time is polynomial in \(\tau\) and \(L\). The exact rational output also has polynomial encoding length.

5. Why discrete hardness does not transfer

Vertex-disjoint packing requires indivisible selection decisions. Here the variables are divisible rational masses, and the linear program is the problem itself. No integrality theorem is needed.

The same algorithm applies when \(\beta=0\): nonnegativity then forces every cycle with \(r(C)>0\) to receive zero mass. The remaining mass-allocation problem is still a polynomial-size rational LP.
