The continuous mirror question, as graded

Given resource classes \(J\), rational per-capita supplies \(b_j\), and a support \(T\) of \(\tau\) types with rational masses \(\mu_t\) summing to \(1\), where type \(t\subseteq J\) values an integral bundle \(k\in\mathbb{Z}_{\ge 0}^{J}\) at \(u_t(k)=\sum_{j\in t}v_jk_j\), maximize \(\lambda\) over finite-support masses \(x_{t,k}\ge 0\) satisfying \(\sum_k x_{t,k}=\mu_t\), \(\sum_{t,k}k_jx_{t,k}\le b_j\), and \(x_{t,k}>0\) only if \(u_t(k)\ge\lambda\); what approximation guarantee can be achieved in time polynomial in \(|J|,\tau,L\), and the accuracy parameter?

Packaged proof task (what the prover saw — nothing else)

Let \(J\) be a nonempty set of resource classes, \(m=|J|\), with binary rational values \(v_j\geq0\) and finite per-capita supplies \(b_j\geq0\).
A society is given by its support: the list \(T\) of \(\tau\) types \(t\subseteq J\) with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau=|T|\) is the support size, not the number of possible types; \(L\) is the total input bit length.
Each individual receives an integral bundle \(k\in\mathbb Z_{\geq0}^{J}\), valued by type \(t\) at \(u_t(k)=\sum_{j\in t}v_jk_j\). Several units of a class may occur in one bundle.
An allocation consists of nonnegative masses \(x_{t,k}\) with finite support, satisfying \(\sum_kx_{t,k}=\mu_t\) and \(\sum_{t,k}k_jx_{t,k}\leq b_j\) for every \(j\in J\); unused supply is permitted.
Its guaranteed utility is \(\lambda\geq0\) if \(x_{t,k}>0\) implies \(u_t(k)\geq\lambda\). Let \(\mathrm{OPT}\) be the supremum of feasible guaranteed utilities. A factor \(\rho\geq1\) approximation computes a feasible allocation with guaranteed utility at least \(\mathrm{OPT}/\rho\).

What approximation factor can be achieved in time polynomial in \(m,\tau,L,1/\varepsilon\), for binary rational \(0<\varepsilon<1\)? In particular, can the factor \(6+2\sqrt{10}+\varepsilon\) be achieved, or is achieving it NP-hard?

For finite players and explicitly listed indivisible resources with restricted additive valuations, a combinatorial \(6+2\sqrt{10}+\varepsilon\) approximation runs in \(n^{O(\varepsilon^{-2}\log(1/\varepsilon))}\) time, where \(n\) is the discrete instance size. [Source](https://arxiv.org/html/1409.0607)
For the discrete configuration LP with bundles that are subsets of explicitly listed resources, polynomial-time approximation of its value is known; this concerns a different bundle domain. [Source](https://www.sciencedirect.com/science/article/abs/pii/S0020019020301125)

Modeling choices made when packaging the task

  • Specified the omitted value inputs as nonnegative binary rationals, following the discrete valuation domain; supplies are finite nonnegative binary rationals.
  • Interpreted resource classes as containing interchangeable units, allowing multiple units of a class in an individual's integral bundle, as stipulated by the graded question.

Result

A \(1+\varepsilon\) approximation is achievable in time \(\operatorname{poly}(m,\tau,L,1/\varepsilon)\). Consequently, the factor \(6+2\sqrt{10}+\varepsilon\) is achievable.

For bit complexity, I interpret the supplies \(b_j\) as binary rationals included in the input encoding. Without a representation of the supplies, the computational question would need an additional input model.

The proof constructs a polynomial-size linear program whose flows represent allocations of population masses to integral bundles. It rounds utility coefficients while preserving the supply constraints exactly.

1. An upper bound and attainment of the optimum

Put \(S=\sum_{j\in J}v_jb_j\). Every allocation guaranteeing \(\lambda\) satisfies

\(\displaystyle \lambda=\lambda\sum_{t\in T}\mu_t\leq\sum_{t,k}u_t(k)x_{t,k}\leq\sum_{j\in J}v_j\sum_{t,k}k_jx_{t,k}\leq S.\)

Thus \(\mathrm{OPT}\leq S\). If \(S=0\), assigning the zero bundle to every type is optimal.

Suppose \(S>0\). We first show that the supremum defining \(\mathrm{OPT}\) is attained. For each class of positive value, let \(U_j=\lceil S/v_j\rceil\). In any allocation guaranteeing \(\lambda\leq S\), remove all units that have zero value to their recipient, and replace every remaining count \(k_j\) by \(\min\{k_j,U_j\}\).

This preserves the guarantee. If no valued coordinate was reduced, utility is unchanged. If a valued coordinate \(j\) was reduced, its remaining units alone have value \(v_jU_j\geq S\geq\lambda\). Resource consumption never increases.

Consequently, every feasible threshold can be witnessed using a fixed finite collection of bundles: positive-value coordinates are bounded by \(U_j\), and zero-value coordinates are zero. Every allocation using this collection has an actual minimum utility belonging to the finite set of type–bundle utilities. The set of achievable actual minimum utilities is therefore finite and nonempty, so it has a maximum. This maximum is \(\mathrm{OPT}\).

Define \(v_{\min}=\min\{v_j:v_j>0\}\). Any positive-utility bundle contains an accepted positive-value unit and hence has utility at least \(v_{\min}\). It follows that either \(\mathrm{OPT}=0\), or

\(\displaystyle v_{\min}\leq\mathrm{OPT}\leq S.\)

In particular, if \(S<v_{\min}\), the optimum is zero.

2. Binary encoding of bundles at a proposed threshold

Fix rational numbers \(\lambda>0\) and \(0<\delta<1\). We will construct an algorithm with these two properties:

  • If \(\lambda\) is feasible in the original model, the algorithm succeeds.
  • Whenever it succeeds, it returns an allocation guaranteeing at least \((1-\delta)\lambda\).

For each positive-value class, define

\(\displaystyle B_j=\left\lceil\frac{\lambda}{v_j}\right\rceil,\qquad K_j=1+\lfloor\log_2 B_j\rfloor.\)

Every allocation guaranteeing \(\lambda\) can be modified, without increasing consumption, so that its bundles contain only accepted positive-value classes and satisfy \(k_j\leq B_j\). Indeed, delete unvalued units and clip each remaining coordinate at \(B_j\). If clipping occurs, that coordinate alone retains utility \(v_jB_j\geq\lambda\).

For class \(j\), introduce \(K_j\) chunks of sizes

\(\displaystyle 1,2,4,\ldots,2^{K_j-1}.\)

Selecting a chunk of size \(d\) means giving \(d\) units of its class. Each chunk may be selected at most once. Binary expansion represents every integer count between zero and \(B_j\), since \(B_j<2^{K_j}\).

List all chunks as \(\ell=1,\ldots,N\), where \(N=\sum_{j:v_j>0}K_j\). Write \(j_\ell\) for the class of chunk \(\ell\), \(d_\ell\) for its size, and \(w_\ell=v_{j_\ell}d_\ell\) for its value.

These chunks are a representation of bundle counts; their numbers do not represent society-wide inventories.

3. Rounding utility with a controlled loss

Set

\(\displaystyle \eta=\frac{\delta\lambda}{N},\qquad a_\ell=\left\lfloor\frac{\min\{w_\ell,\lambda\}}{\eta}\right\rfloor,\qquad Q=\left\lceil\frac{(1-\delta)\lambda}{\eta}\right\rceil=\left\lceil\frac{(1-\delta)N}{\delta}\right\rceil.\)

Two implications establish the required guarantee.

Original configurations remain representable. Consider a bounded bundle of utility at least \(\lambda\), and let \(A\) be the chunks selected by its binary representation. Then

\(\displaystyle \sum_{\ell\in A}\min\{w_\ell,\lambda\}\geq\lambda.\)

To verify this, if some selected chunk has value at least \(\lambda\), its truncated value alone is \(\lambda\). Otherwise truncation changes no selected value.

Using \(\lfloor z\rfloor\geq z-1\) and \(|A|\leq N\), we obtain

\(\displaystyle \sum_{\ell\in A}a_\ell\geq\frac{\lambda}{\eta}-N=\frac{(1-\delta)\lambda}{\eta}.\)

The left side is integral, so \(\sum_{\ell\in A}a_\ell\geq Q\).

Every accepted rounded configuration has sufficient true utility. Conversely, if selected chunks satisfy \(\sum_{\ell\in A}a_\ell\geq Q\), then

\(\displaystyle \sum_{\ell\in A}w_\ell\geq\eta\sum_{\ell\in A}a_\ell\geq\eta Q\geq(1-\delta)\lambda.\)

Thus requiring rounded utility at least \(Q\) retains every necessary original configuration and accepts only bundles meeting the weakened guarantee.

4. A polynomial-size flow LP

For each type \(t\), construct a directed acyclic graph with vertices \((\ell,q)\), where \(0\leq\ell\leq N\) and \(0\leq q\leq Q\). Its source is \((0,0)\), and its sink is \((N,Q)\).

At stage \(\ell\), from every state \((\ell-1,q)\), include:

  • A skip arc to \((\ell,q)\).
  • If \(j_\ell\in t\), a take arc to \((\ell,\min\{Q,q+a_\ell\})\), labeled with resource consumption \(d_\ell\) units of class \(j_\ell\).

Skip and take arcs remain distinct even when they have the same endpoints.

By induction over the stages, the state after any prefix equals the accumulated rounded utility capped at \(Q\). Therefore source–sink paths correspond exactly to chunk selections with rounded utility at least \(Q\). By Section 3, every such path specifies an integral bundle of true utility at least \((1-\delta)\lambda\).

Let \(f_{t,e}\geq0\) denote flow on arc \(e\) of type \(t\)'s graph. Require flow conservation with source–sink value exactly \(\mu_t\). Explicitly, outgoing flow minus incoming flow is \(\mu_t\) at the source, \(-\mu_t\) at the sink, and zero elsewhere.

For each class \(j\), impose

\(\displaystyle \sum_{t\in T}\sum_{\substack{e\text{ is a take arc}\\\text{for chunk }\ell,\ j_\ell=j}}d_\ell f_{t,e}\leq b_j.\)

These are exact resource inequalities.

If \(\lambda\) is feasible in the original model, first bound and encode its bundles as in Section 2. Section 3 shows that each encoded bundle yields a source–sink path. Sending its assigned population mass along that path gives a feasible solution of this LP.

Conversely, any feasible LP solution decomposes into source–sink paths in each type's graph. This decomposition is constructive: repeatedly choose a positive-flow path, subtract the minimum flow on it, and record that amount as the path's mass. Each iteration eliminates a positive-flow arc, so the number of recorded paths is at most the number of arcs.

Assign each recorded path's integral bundle to its recorded mass. Flow conservation gives total mass exactly \(\mu_t\) for each type. The resource consumed is exactly the resource counted by the LP inequalities. Every resulting bundle has utility at least \((1-\delta)\lambda\).

This proves both properties stated in Section 2, including production of an explicit finite-support allocation.

5. Searching for the threshold

Given \(0<\varepsilon<1\), choose

\(\displaystyle \delta=\frac{\varepsilon}{2+\varepsilon},\qquad r=1+\delta.\)

These choices satisfy

\(\displaystyle \frac{r}{1-\delta}=1+\varepsilon,\qquad \frac1\delta=\frac{2+\varepsilon}{\varepsilon}\leq\frac3\varepsilon.\)

After handling the zero cases above, test every threshold

\(\displaystyle \lambda_h=v_{\min}r^h,\qquad h=0,\ldots,H,\)

where \(H\) is the largest integer for which \(\lambda_H\leq S\). For each threshold, solve its flow LP. Among successful tests, return the allocation associated with the largest threshold. If there are no successful tests, return the zero allocation.

Suppose \(\mathrm{OPT}>0\). Let \(h^\ast\) be the largest grid index satisfying \(\lambda_{h^\ast}\leq\mathrm{OPT}\). Because the optimum is attained, this threshold is feasible, so its flow LP succeeds. Moreover,

\(\displaystyle \mathrm{OPT}<r\lambda_{h^\ast}.\)

For \(h^\ast<H\), this follows from maximality of \(h^\ast\). For \(h^\ast=H\), it follows from \(\mathrm{OPT}\leq S<r\lambda_H\).

The returned allocation therefore guarantees at least

\(\displaystyle (1-\delta)\lambda_{h^\ast}\geq\frac{1-\delta}{r}\,\mathrm{OPT}=\frac{\mathrm{OPT}}{1+\varepsilon}.\)

If \(\mathrm{OPT}=0\), any returned feasible allocation satisfies the required guarantee. Thus the algorithm is a \(1+\varepsilon\) approximation in every case.

6. Bit complexity and output size

The numerical size of binary-encoded supplies causes no expansion into individual resource units.

For every tested threshold \(\lambda\leq S\),

\(\displaystyle N=O\!\left(m\left(1+\log_2\!\left(1+\frac{S}{v_{\min}}\right)\right)\right).\)

Indeed, \(B_j\leq\lceil S/v_{\min}\rceil\), and \(K_j\) is its binary length. Since \(S\) and \(v_{\min}\) have polynomial encoding length, \(N\) is polynomial in \(m,L\). Also,

\(\displaystyle Q=O(N/\delta)=O(N/\varepsilon).\)

Each type's graph has \(O(NQ)\) vertices and arcs. The flow LP consequently has polynomially many variables and constraints. Its coefficients are rational, with polynomial bit length: chunk sizes have logarithmic encodings, and utility rounding uses exact rational arithmetic.

The number of grid points is polynomial because

\(\displaystyle H+1=O\!\left(1+\frac{\log(S/v_{\min})}{\delta}\right),\)

using \(\log(1+\delta)\geq\delta/2\). Their rational encodings also have polynomial length, since each is \(v_{\min}(1+\delta)^h\) with polynomially bounded \(h\).

We apply the standard polynomial-time feasibility theorem for rational linear programs. Its required dimensions and coefficient bit lengths have just been bounded; it returns a rational feasible solution of polynomial encoding length when one exists. Path decomposition then takes polynomial time and produces polynomially many bundles. Their counts and assigned masses have polynomial bit length.

The total running time and output size are therefore polynomial in \(m,\tau,L,1/\varepsilon\).

7. Why the discrete distinction matters

The [cited finite-player theorem](https://arxiv.org/html/1409.0607) concerns allocations to separately listed players. In the present model, configuration masses themselves constitute a legal allocation. The flow construction proves this directly for multiset bundles and preserves the original supply bounds.

Hence this mass-allocation model admits a fully polynomial-time approximation scheme, which settles the requested constant-factor question.
