The continuous mirror question, as graded

Given a finite set \(T\) of additive valuation types with rational masses \(\mu_t>0\) summing to \(1\), goods categories \(G\), rational per-capita supplies \(q_g\), and nonnegative values \(a_{t,g}\), each unit of mass must receive an integral bundle \(\mathbf{k}\in\mathbb{Z}_{\ge0}^{G}\). Let \(x_{t,\mathbf{k}}\) be the mass of type \(t\) receiving bundle \(\mathbf{k}\), with \(\sum_{\mathbf{k}}x_{t,\mathbf{k}}=\mu_t\) and \(\sum_{t,\mathbf{k}}x_{t,\mathbf{k}}k_g=q_g\). Can a polynomial-time algorithm, for fixed \(\alpha>0\), return such an allocation and nonnegative payments that give every recipient the same post-payment value and make each type weakly prefer its own bundle-and-payment to every occupied recipient class, while attaining population NSW \(W=\exp(\sum_{t,\mathbf{k}}x_{t,\mathbf{k}}\log v_t(\mathbf{k}))\ge\alpha\,\mathrm{OPT}\), where \(\mathrm{OPT}\) is unrestricted maximum NSW for the same supplies?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) additive valuation types \(T\) with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) counts supported types, not possible types. There are \(m\ge1\) goods categories \(G\), binary-rational supplies \(q_g\ge0\), and binary-rational values \(a_{t,g}\in[0,1]\), with \(v_t(\mathbf{k})=\sum_g a_{t,g}k_g\). Let \(L\) be the total input bit length.
An allocation is a finite list of occupied classes \((t,\mathbf{k})\), where \(\mathbf{k}\in\mathbb{Z}_{\ge0}^{G}\), with positive rational masses \(x_{t,\mathbf{k}}\) satisfying \(\sum_{\mathbf{k}}x_{t,\mathbf{k}}=\mu_t\) and \(\sum_{t,\mathbf{k}}x_{t,\mathbf{k}}k_g=q_g\); empty bundles are allowed and all supplies must be allocated.
Each occupied class receives a nonnegative rational subsidy \(p_{t,\mathbf{k}}\), added to its value, with no subsidy budget. Equitability and envy-freeness require a common \(c\) such that \(v_t(\mathbf{k})+p_{t,\mathbf{k}}=c\ge v_t(\mathbf{h})+p_{s,\mathbf{h}}\) for every pair of occupied classes \((t,\mathbf{k}),(s,\mathbf{h})\).
Welfare excludes subsidies: \(W(x)=\exp(\sum_{t,\mathbf{k}}x_{t,\mathbf{k}}\log v_t(\mathbf{k}))\), with \(W(x)=0\) whenever an occupied class has zero value. Define \(\mathrm{OPT}=\sup_x W(x)\) over allocations satisfying only the mass and supply constraints.

Does some fixed \(\alpha\in(0,1]\) admit an algorithm running in \(\operatorname{poly}(m,\tau,L)\) that always returns an equitable, envy-free allocation with subsidies and \(W\ge\alpha\,\mathrm{OPT}\), or is every positive constant approximation impossible?

For finite agents with additive goods valuations, no positive constant fraction of unrestricted optimal NSW is universally attainable by allocations made equitable and envy-free using the same nonnegative subsidies, regardless of computation time. [Wang–Wei](https://arxiv.org/html/2505.23251v2)

Result

Every positive constant approximation is impossible, regardless of computation time. This holds already for \(m=\tau=2\), with strictly positive values and supplies, neither type dominating the other, and an equitable, envy-free allocation of positive welfare.

We give a direct proof for the mass model. The related finite-agent obstruction appears in [Wang–Wei, Proposition 7](https://arxiv.org/html/2505.23251v2).

1. Characterizing allocations compatible with both requirements

Lemma. A feasible finite allocation admits nonnegative rational subsidies achieving equitability and envy-freeness if and only if every occupied class \((s,\mathbf h)\) satisfies
\(v_s(\mathbf h)\ge v_t(\mathbf h)\) for every supported type \(t\).

Proof. Suppose such subsidies exist, with common compensated value \(c\). For an occupied class \((s,\mathbf h)\), equitability gives
\(p_{s,\mathbf h}=c-v_s(\mathbf h)\).
Every supported type \(t\) has an occupied class because \(\mu_t>0\). Envy-freeness for that class implies

\(c\ge v_t(\mathbf h)+p_{s,\mathbf h}=v_t(\mathbf h)+c-v_s(\mathbf h)\).

Subtracting \(c\) proves the necessary inequality.

Conversely, suppose the inequalities hold. Since the occupied list is finite, choose the rational number
\(c=\max_{(s,\mathbf h)\text{ occupied}}v_s(\mathbf h)\),
and set \(p_{s,\mathbf h}=c-v_s(\mathbf h)\).
These subsidies are rational and nonnegative, and give equitability. Moreover,

\(v_t(\mathbf h)+p_{s,\mathbf h}=c+v_t(\mathbf h)-v_s(\mathbf h)\le c\),

which proves envy-freeness. \(\square\)

Thus splitting a type into arbitrarily many occupied classes does not relax the requirement that each bundle be assigned to a type maximizing its value.

2. A family with positive unrestricted and fair welfare

Let \(Q=2^n\), where \(n\ge1\). Take two types with masses
\(\mu_1=\mu_2=\tfrac12\), and two categories with supplies
\(q_1=Q\) and \(q_2=\tfrac12\). Define

\(v_1(k_1,k_2)=k_1+\tfrac12k_2,\qquad v_2(k_1,k_2)=\tfrac12k_1+k_2.\)

All input numbers are binary-rational, all coefficients and supplies are positive, and the input length is \(O(n)\). Each type uniquely maximizes the value of one category.

For unrestricted welfare, consider these two occupied classes:

| Type | Bundle | Mass |
|---|---|---|
| \(1\) | \((Q,0)\) | \(\tfrac12\) |
| \(2\) | \((Q,1)\) | \(\tfrac12\) |

Their aggregate supplies are exactly \((Q,\tfrac12)\). Hence

\(\mathrm{OPT}\ge\sqrt{Q\left(\tfrac Q2+1\right)}\ge\tfrac Q{\sqrt2}>0.\)

The optimum is finite: every bundle value is at most \(k_1+k_2\), so Jensen’s inequality bounds every positive-welfare allocation by \(Q+\tfrac12\).

There is also a fair allocation of positive welfare: assign \((2Q,0)\) to all of type \(1\), and \((0,1)\) to all of type \(2\). Each bundle maximizes its owner’s valuation, so the lemma applies. Explicitly, subsidies \(0\) and \(2Q-1\) give common compensated value \(2Q\). Its welfare is \(\sqrt{2Q}>0\).

3. Bounding every equitable, envy-free allocation

Fix any feasible allocation admitting both requirements. If its welfare is zero, the desired upper bound is immediate. Assume its welfare is positive.

By the lemma, every occupied type-\(2\) bundle satisfies

\(\tfrac12k_1+k_2\ge k_1+\tfrac12k_2,\)

and therefore \(k_2\ge k_1\). Positive welfare requires every occupied bundle to have positive value. Thus every type-\(2\) bundle is nonempty, and integrality implies \(k_2\ge1\).

The second-category supply constraint now gives

\(0=q_2-\mu_2=\sum_{\mathbf k}x_{2,\mathbf k}(k_2-1)+\sum_{\mathbf k}x_{1,\mathbf k}k_2.\)

Every summand is nonnegative. Since occupied classes have positive masses, each summand must vanish. Consequently:

  • Every occupied type-\(2\) bundle has \(k_2=1\).
  • Every occupied type-\(1\) bundle has \(k_2=0\).

For type \(2\), the inequality \(k_1\le k_2=1\) therefore implies
\(v_2(\mathbf k)\le\tfrac32\).

For type \(1\), values equal \(k_1\), and the first-category supply constraint implies

\(\sum_{\mathbf k}x_{1,\mathbf k}v_1(\mathbf k)=\sum_{\mathbf k}x_{1,\mathbf k}k_1\le Q.\)

Because type \(1\) has mass \(\tfrac12\), its average value is at most \(2Q\). Applying concavity of \(\log\) with normalized weights \(2x_{1,\mathbf k}\) gives

\(\sum_{\mathbf k}x_{1,\mathbf k}\log v_1(\mathbf k)\le\tfrac12\log(2Q).\)

The pointwise bound for type \(2\) gives

\(\sum_{\mathbf k}x_{2,\mathbf k}\log v_2(\mathbf k)\le\tfrac12\log(\tfrac32).\)

Adding and exponentiating proves that every equitable, envy-free allocation satisfies

\(W\le\sqrt{3Q}.\)

This argument permits arbitrary finite splitting and arbitrarily large integer bundles.

4. Impossibility of a constant guarantee

Combining the fair-welfare upper bound with the unrestricted feasible witness yields

\(\displaystyle\frac{W}{\mathrm{OPT}}\le\frac{\sqrt{3Q}}{Q/\sqrt2}=\sqrt{\frac6Q}.\)

For any fixed \(\alpha\in(0,1]\), choose \(Q=2^n>6/\alpha^2\). Then every equitable, envy-free allocation satisfies
\(W<\alpha\,\mathrm{OPT}\).

Thus the requested allocation need not exist, even though fair allocations with positive welfare do exist. No algorithm can provide the proposed universal guarantee.
