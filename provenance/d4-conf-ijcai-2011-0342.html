The continuous mirror question, as graded

Given a candidate set \(A\), a support \(T\) of complete rankings over \(A\) with positive rational masses \(\mu_t\) summing to \(1\), an integer \(K\le |A|\), and a rational threshold \(q\ge 0\), does there exist a slate \(\Phi\subseteq A\) with \(|\Phi|=K\) such that \(\sum_{t\in T}\mu_t\max_{a\in\Phi}(|A|-\operatorname{pos}_t(a))\ge q\)?

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(A\) with \(m=|A|\ge 1\), a society is specified by its support \(T\): a list of \(\tau\) distinct strict complete rankings over \(A\), each with positive binary-rational mass \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible rankings.
Let \(\operatorname{pos}_t(a)\in\{1,\ldots,m\}\) denote the position of \(a\) in ranking \(t\), with position \(1\) best. The remaining inputs are an integer \(1\le K\le m\) and a binary-rational threshold \(q\ge 0\). Let \(L\) be the total input bit length.
A slate is a subset \(\Phi\subseteq A\) with \(|\Phi|=K\); candidate selection is indivisible. Its welfare is \(W(\Phi)=\sum_{t\in T}\mu_t\max_{a\in\Phi}(m-\operatorname{pos}_t(a))\).

Is deciding whether some slate \(\Phi\) satisfies \(W(\Phi)\ge q\) solvable in polynomial time in \(m,\tau,K,L\), or is it NP-hard?

For an explicitly listed finite electorate, deciding whether a slate of exactly \(K\) candidates attains a given nonnegative threshold of total Borda welfare is NP-complete.

Modeling choices made when packaging the task

  • Restricted K to 1 through m, consistent with the positive slate size in the discrete model and avoiding an undefined maximum over an empty slate.
  • Specified a nonempty candidate set and strict complete rankings, with positions numbered from 1 for the best candidate.
  • Defined L as the total input bit length.
  • Made explicit that candidate selection remains indivisible when voter masses replace individual voters.

Conclusion

The decision problem is \(\mathrm{NP}\)-complete. This holds even when every mass and the threshold are dyadic rationals, meaning rationals whose denominators are powers of two.

The proof uses the explicitly listed electorate hardness result supplied in the question.

Membership in \(\mathrm{NP}\)

A certificate is a slate \(\Phi\subseteq A\) containing exactly \(K\) distinct candidates.

For each listed ranking \(t\), compute the integer
\(b_t(\Phi)=\max_{a\in\Phi}(m-\operatorname{pos}_t(a))\).
Then evaluate \(W(\Phi)=\sum_{t\in T}\mu_t b_t(\Phi)\) and compare it with \(q\).

These computations take polynomial time. In particular, exact rational arithmetic suffices: a common denominator obtained by multiplying the input denominators has bit length at most the sum of their bit lengths. Since \(0\le b_t(\Phi)\le m-1\), the resulting numerators also have polynomial bit length. Thus the problem belongs to \(\mathrm{NP}\).

A polynomial reduction establishing hardness

Consider an instance of the supplied \(\mathrm{NP}\)-complete problem with an explicitly listed electorate of \(n\ge1\) voters, rankings \(t_1,\ldots,t_n\), candidate set \(A\), slate size \(K\), and nonnegative threshold \(B\). Its total welfare is
\(S(\Phi)=\sum_{i=1}^{n}b_{t_i}(\Phi)\).

Because \(S(\Phi)\) is an integer, replace \(B\) by the integer \(Q=\lceil B\rceil\). This preserves the answer and takes polynomial time.

Simply aggregating equal rankings and assigning their relative frequencies would preserve normalized welfare exactly. To ensure that the output satisfies even the stricter dyadic interpretation of “binary-rational,” we use the following padding construction.

Choose \(N\) to be the least power of two satisfying
\(N\ge n\bigl(n(m-1)+1\bigr)\).
Write \(N=Dn+r\), where \(D=\lfloor N/n\rfloor\) and \(0\le r<n\). Then
\(D\ge n(m-1)+1>r(m-1)\).

Let \(T\) be the set of distinct rankings appearing in the source electorate, and let \(c_t\) be the multiplicity of ranking \(t\). Fix one ranking \(t_0\in T\). Assign the masses
\(\mu_{t_0}=(Dc_{t_0}+r)/N\) and
\(\mu_t=Dc_t/N\) for \(t\ne t_0\).
Set the output threshold to \(q=DQ/N\), retaining \(A\) and \(K\).

Every mass is positive, and
\(\sum_{t\in T}\mu_t=(D\sum_{t\in T}c_t+r)/N=(Dn+r)/N=1\).
All masses and \(q\) are dyadic rationals. The support contains only distinct strict complete rankings, as required.

Preservation of the answer

For every slate \(\Phi\) of size \(K\), the constructed welfare satisfies
\(NW(\Phi)=DS(\Phi)+r\,b_{t_0}(\Phi)\).

If the source instance is a yes-instance, choose \(\Phi\) with \(S(\Phi)\ge Q\). Since \(b_{t_0}(\Phi)\ge0\), we obtain
\(NW(\Phi)\ge DQ=Nq\).
Thus the constructed instance is a yes-instance.

Conversely, if the source instance is a no-instance, every size-\(K\) slate satisfies \(S(\Phi)\le Q-1\). Using \(b_{t_0}(\Phi)\le m-1\), we obtain
\(NW(\Phi)\le D(Q-1)+r(m-1)<DQ=Nq\),
where the strict inequality follows from \(r(m-1)<D\). Thus the constructed instance is a no-instance.

Polynomial encoding size

The chosen power of two satisfies
\(N<2n\bigl(n(m-1)+1\bigr)\),
so its bit length is \(O(\log n+\log m)\). There are at most \(n\) support rankings, each already present in the explicitly listed input. Their multiplicities, the output masses, and the threshold can all be computed and encoded in polynomial time.

No replicated electorate needs to be explicitly constructed: the factors \(D\) and the padding \(r\) are incorporated directly into the masses.

Consequence

The reduction proves \(\mathrm{NP}\)-hardness, and the certificate argument proves membership in \(\mathrm{NP}\). Hence polynomial-time solvability in \(m,\tau,K,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
