The continuous mirror question, as graded

Given a finite support of acyclic more-or-less CP-net types \(N_t\) with rational masses \(\mu_t\) summing to one, and outcomes \(o,o'\), compute \(D_\mu(o,o')=\sum_t \mu_t\,\mathbf{1}[N_t\models o'\succ o]\), or decide whether \(D_\mu(o,o')\ge q\). Determine the complexity when every supported type has a tree structure.

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge1\) attributes have common, explicitly listed finite domains, each containing at least two values. Outcomes \(o,o'\) are complete assignments.
A type \(N_t\) is an acyclic CP-net whose dependency graph is a rooted tree directed away from its root; different types may have different trees.
For each attribute \(X\), the type supplies a strict reference order \(\prec_{t,X}\) and a cutoff \(c_{t,X}\). Both categories \(A_{t,X}=\{x:x\preceq_{t,X}c_{t,X}\}\) and \(B_{t,X}=\{x:c_{t,X}\prec_{t,X}x\}\) are nonempty.
Every conditional preference order on \(X\) is its reference order or its reverse. For every edge \(X\to Y\), the conditional preference order on \(Y\) depends on the value of \(X\) only through its category. All conditional preferences are fully specified, without ties.
Encode each type by its tree, reference-order lists, cutoffs, and preference directions for the root and each parent category.
Write \(N_t\models o'\succ o\) when a nonempty sequence of improving flips takes \(o\) to \(o'\); each flip changes exactly one attribute to any strictly preferred value under its current parent assignment, holding all other attributes fixed.
A society is given by its support: the list of the \(\tau\) types with positive masses \(\mu_t\), each a binary rational, with \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Given also a binary rational \(q\in[0,1]\), define \(D_\mu(o,o')=\sum_{t=1}^{\tau}\mu_t\mathbf{1}[N_t\models o'\succ o]\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is deciding whether \(D_\mu(o,o')\ge q\) in \(\mathrm{P}\) or \(\mathrm{NP}\)-hard? What is the complexity of computing \(D_\mu(o,o')\) exactly?

Known discrete results: dominance testing for binary tree CP-nets takes \(O(m^2)\) time ([Boutilier et al.](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume21/boutilier04a.pdf)); tree-structured more-or-less CP-nets also admit polynomial-time dominance testing ([Yaman and desJardins](https://arxiv.org/pdf/1206.5284)).
No result addressing exactly this explicitly supported rational-mass problem was located in the search.

Modeling choices made when packaging the task

  • Use common finite attribute domains across types so that both queried outcomes have the same meaning; list domains explicitly.
  • Interpret tree structure as a rooted tree directed away from its root, rather than an arbitrary orientation of an undirected tree.
  • Supply reference orders and cutoffs as input, and encode conditional orders by their directions for each parent category.
  • Require domains of size at least two and both cutoff categories nonempty, consistent with the intended two-category representative sets.
  • Use fully specified strict local orders and ordinary ceteris paribus improving-flip semantics; equal queried outcomes do not satisfy strict dominance.
  • Restrict the threshold to a binary rational in the unit interval and define L as the total input bit length.

Result

The threshold problem is in \(\mathrm{P}\), and computing \(D_\mu(o,o')\) exactly is in \(\mathrm{FP}\).

More specifically, the dominance tests require \(O(\tau m^2)\) operations after preprocessing. Exact aggregation requires \(O(L^2)\) elementary bit operations if an unreduced fraction is acceptable, or \(O(L^3)\) with a straightforward implementation producing a reduced fraction. Including preprocessing and charging for binary indices gives the conservative bit-cost RAM bound
\(O(\tau m^2\log(L+2)+L^3)\) for reduced exact output.

The key is a dominance-preserving reduction of each type to a binary tree CP-net with at most \(2m\) variables. I prove that reduction below; it handles endpoint values lying in the same category.

1. Equal outcomes and strict dominance

An acyclic CP-net has no nonempty improving sequence returning to its starting outcome.

Indeed, suppose such a sequence existed. Choose the first variable in a topological ordering that changes anywhere in the sequence. None of its parents changes, so its conditional preference order remains fixed. Every change of this variable strictly improves its value in that fixed strict order, making a return to its initial value impossible.

Consequently, if \(o=o'\), then \(D_\mu(o,o')=0\). Henceforth assume \(o\ne o'\).

2. Reduction of one type to a binary tree

Fix a type \(N\), suppressing its type index. Write \(u_X=o(X)\) and \(v_X=o'(X)\). Let \(r_X(x)\) be the position of \(x\) in the reference-order list, increasing along that list.

Call a conditional order increasing if larger ranks are preferred, and decreasing if smaller ranks are preferred. Every conditional order has exactly one of these directions.

Category variables

For every original attribute \(X\), introduce a binary variable \(C_X\), where \(0\) represents \(A_X\) and \(1\) represents \(B_X\). Retain the original tree edges between these variables.

The initial and target values of \(C_X\) are the categories of \(u_X\) and \(v_X\), respectively. Specify its preferences as follows:

  • If the corresponding conditional order of \(X\) is increasing, prefer \(1\) to \(0\).
  • If it is decreasing, prefer \(0\) to \(1\).

For a nonroot variable, this direction depends only on its parent's category, exactly as stipulated in the input.

Because every rank in \(A_X\) is smaller than every rank in \(B_X\), a category-changing flip improves \(C_X\) precisely when every corresponding cross-category change of \(X\) is improving.

Auxiliary variables for changes within a category

Whenever \(u_X\ne v_X\) but both values belong to the same category, introduce a binary auxiliary variable \(H_X\), initially \(0\) and with target \(1\).

If \(X\) has parent \(P\), attach \(H_X\) as a leaf child of \(C_P\). In each parent-category context, prefer \(1\) to \(0\) exactly when the conditional order of \(X\) prefers \(v_X\) to \(u_X\); otherwise prefer \(0\) to \(1\).

If \(X\) is the root, attach \(H_X\) as a leaf child of \(C_X\), with identical preference rows in both contexts, determined by the fixed root order.

Call the resulting binary CP-net \(M\), with initial outcome \(a\) and target outcome \(b\). Its graph is the original rooted tree with additional leaves. It has at most \(2m\) variables, all preference rows are strict and fully specified, and \(a\ne b\): any changed original attribute changes either its category variable or its auxiliary variable.

3. Proof that the reduction preserves dominance

I claim that \(N\models o'\succ o\) if and only if \(M\models b\succ a\).

Forward implication

Suppose an improving sequence takes \(o\) to \(o'\).

Project each category-changing flip onto the corresponding variable \(C_X\), and discard flips that stay within a category. Every retained flip is improving by the construction of the category preferences.

It remains to arrange the auxiliary flips. Consider an attribute \(X\) with an auxiliary variable. Its original sequence of rank changes has total change \(r_X(v_X)-r_X(u_X)\ne0\).

If this difference is positive, at least one flip of \(X\) increases its rank. At that flip, its conditional order must be increasing and therefore prefers \(v_X\) to \(u_X\). If the difference is negative, the same argument supplies a flip under a decreasing order.

Insert the flip \(H_X:0\to1\) immediately before such a flip of \(X\) in the projected sequence. The current parent category is the required one, so this auxiliary flip is improving. For a root auxiliary, the order is constant and the same conclusion holds.

Auxiliary variables are leaves and do not affect any other preferences. After flipping each auxiliary once, leave it at \(1\). The resulting binary sequence ends at \(b\), proving \(M\models b\succ a\).

Reverse implication

Suppose an improving binary sequence takes \(a\) to \(b\). We construct an original improving sequence while following its category-variable flips.

For each attribute \(X\), distinguish two cases.

Its category variable flips at least once. Start \(X\) at \(u_X\). At every category flip except the last one for \(X\), choose any value in the new category. At its last category flip, assign \(v_X\); that flip necessarily enters the target category.

Every such change is improving: the binary flip selects the preferred category, and all values in that category are preferred to all values in the category being left.

Its category variable never flips. If \(u_X=v_X\), keep that value throughout. Otherwise, \(H_X\) exists and must undergo a flip \(0\to1\). At its first such flip, change the original \(X\) directly from \(u_X\) to \(v_X\). By the auxiliary preference definition, this change is improving in the current parent context.

Ignore all other auxiliary flips. Throughout this construction, each original variable's category matches its category bit. Thus every conditional preference used in the construction is the correct one. Moreover, changes within a category leave all children's preference rows unchanged.

The final original outcome is \(o'\). Since \(o\ne o'\), the constructed sequence is nonempty. This proves the reverse implication and completes the equivalence.

4. Applying the binary-tree dominance theorem

The established binary-tree result states that dominance testing for a fully specified binary CP-net whose graph is a rooted tree directed away from its root takes \(O(n^2)\) time. See Theorems 11–12 of [Boutilier et al.](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume21/boutilier04a.pdf).

The constructed \(M\) satisfies every hypothesis: it is binary, has strict complete preference rows, and its graph remains a rooted outward-directed tree. Since \(n\le2m\), one original dominance query takes \(O(m^2)\) operations after its reference lists have been processed.

The supplied types also satisfy Definitions 3–4 of [Yaman and desJardins](https://arxiv.org/pdf/1206.5284), namely the monotonicity and common-cutoff restrictions defining more-or-less CP-nets. The explicit reduction above supplies the needed algorithm without relying on a representative-value argument for endpoints in the same category.

Performing this construction and test separately for every supported type computes all indicators
\(d_t=\mathbf{1}[N_t\models o'\succ o]\)
in \(O(\tau m^2)\) dominance operations. Different types may have different trees; no common tree is needed.

5. Exact rational aggregation and bit complexity

Write each mass as \(\mu_t=a_t/b_t\), where \(a_t,b_t\) are positive binary integers. Initialize \(P_0=0\) and \(B_0=1\), and compute, for each \(t\),

\(P_t=P_{t-1}b_t+d_ta_tB_{t-1}\), and \(B_t=B_{t-1}b_t\).

Induction gives
\(P_t/B_t=\sum_{s=1}^t d_s\mu_s\).
Thus \(P_\tau/B_\tau\) is an exact representation of \(D_\mu(o,o')\).

The denominator satisfies \(B_\tau=\prod_{t=1}^{\tau}b_t\), so its bit length is at most \(1+\sum_t\log_2 b_t=O(L)\). Furthermore, positivity and normalization imply
\(0\le P_t/B_t\le\sum_{s=1}^t\mu_s\le1\).
Hence every stored numerator also has \(O(L)\) bits.

For completeness, let \(\ell_t\) be the combined bit length of \(a_t,b_t\), and let \(S_{t-1}=1+\sum_{s<t}\ell_s\). Schoolbook multiplication implements each update using \(O(S_{t-1}\ell_t+S_{t-1}+\ell_t)\) bit operations. Since \(\sum_t\ell_t\le L\) and \(\tau\le L\), the total is \(O(L^2)\).

If \(q=e/f\), with \(f>0\), the threshold comparison is exactly
\(fP_\tau\ge eB_\tau\).
Its two multiplications and comparison also take \(O(L^2)\) bit operations.

An unreduced fraction already gives exact output of \(O(L)\) bits. For reduced output, compute \(\gcd(P_\tau,B_\tau)\) and divide. Euclid's algorithm uses \(O(L)\) divisions on \(O(L)\)-bit integers: within every two steps the current remainder decreases by at least a factor of two. Elementary division therefore gives the conservative additional bound \(O(L^3)\).

Processing the explicit reference lists can conservatively be done in \(O(L^2)\) bit operations. Charging \(O(\log(L+2))\) bits for structural indices yields the stated overall bit-cost RAM bounds:

  • Threshold decision or unreduced exact output: \(O(\tau m^2\log(L+2)+L^2)\).
  • Reduced exact output: \(O(\tau m^2\log(L+2)+L^3)\).

Thus both tasks are polynomial in the input length. In particular, NP-hardness of the threshold problem under polynomial-time many-one reductions would imply \(\mathrm{P}=\mathrm{NP}\).
