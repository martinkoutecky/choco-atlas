The continuous mirror question, as graded

Given candidates \(C\), a target \(c^\star\), and a finite support of partial orders \(p\) with binary-rational masses \(\mu_p\) summing to one, determine whether each type’s mass can be distributed among its valid linear extensions so that \(c^\star\) is a co-winner under \((m-2)\)-approval. Equivalently, for each feasible unordered bottom pair \(\{a,b\}\) of each \(p\), choose \(x_{p,\{a,b\}}\ge 0\) with \(\sum_{\{a,b\}}x_{p,\{a,b\}}=\mu_p\), so that the total mass placing \(c^\star\) in the bottom pair is no greater than the corresponding total for any other candidate.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\geq 3\), and let \(c^\star\in C\).
A society is given by its support: a list of \(\tau\) distinct strict partial orders \(p\) on \(C\), each explicitly represented by its ordered pairs and assigned a positive binary-rational mass \(\mu_p\), with \(\sum_p\mu_p=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total binary input length.
For each type \(p\), its mass may be split arbitrarily among its valid linear extensions: choose nonnegative real masses \(y_{p,v}\) satisfying \(\sum_{v\in\operatorname{Ext}(p)}y_{p,v}=\mu_p\).
Apply \((m-2)\)-approval, aggregating scores by mass. Ties are allowed: \(c^\star\) is a co-winner exactly when its aggregate score is at least every other candidate's score.

Is deciding whether such a mass allocation makes \(c^\star\) a co-winner solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite profiles of unweighted voters, Possible Winner under \((m-2)\)-approval is NP-hard when the number of candidates is unbounded, including when ties are allowed.
No result settling this exact mass-splitting formulation was identified in a targeted literature search.

Modeling choices made when packaging the task

  • Require at least three candidates so that (m-2)-approval is a nontrivial scoring rule, consistent with the discrete setting.
  • Represent each partial order explicitly by ordered candidate pairs, using strict preferences and defining L as the total binary input length.
  • Allow arbitrary nonnegative real allocation masses; only the input masses must be binary rationals.

Result

The mass-splitting problem is solvable in time polynomial in \(\boldsymbol{m,\tau,L}\).

The key is that an extension’s approval scores depend only on its bottom two candidates. Each type therefore has at most \(\binom{m}{2}\) relevant outcomes, whose feasibility can be checked directly. Arbitrary mass splitting then yields an exact, polynomial-size linear program.

1. Characterizing feasible bottom pairs

Interpret \((a,b)\in p\) as requiring candidate \(a\) to occur before candidate \(b\).

For a type \(p\), define
\[ \]
\( \mathcal F_p=\bigl\{B\subseteq C:\ |B|=2,\ \text{there is no }(a,b)\in p\text{ with }a\in B,\ b\notin B\bigr\}. \)

Lemma. A two-element set \(B\) belongs to \(\mathcal F_p\) if and only if some linear extension of \(p\) has exactly the candidates of \(B\) in its last two positions.

Proof. Suppose such an extension exists. If \((a,b)\in p\) with \(a\in B\) and \(b\notin B\), the extension would put \(b\) before \(a\), violating this relation. Thus \(B\in\mathcal F_p\).

Conversely, suppose \(B\in\mathcal F_p\). Take a linear extension of the restriction of \(p\) to \(C\setminus B\), followed by a linear extension of its restriction to \(B\). These extensions exist because every finite strict partial order is acyclic and admits a topological ordering: repeatedly select an element with no predecessor among the remaining elements.

The concatenation respects relations within each part. Every relation between the parts points from \(C\setminus B\) to \(B\), by the defining condition of \(\mathcal F_p\), and is therefore also respected. The concatenation is the required extension. \(\square\)

Consequently, we can enumerate \(\mathcal F_p\) by checking each of the \(\binom{m}{2}\) pairs against the explicitly listed relations of \(p\). This takes polynomial time and requires no enumeration of linear extensions.

2. The linear program

For every supported type \(p\) and every \(B\in\mathcal F_p\), introduce a real variable \(z_{p,B}\). It represents the mass of type \(p\) allocated to extensions whose bottom pair is \(B\).

Impose nonnegativity and preservation of each type’s mass:

\( z_{p,B}\geq 0 \qquad(p,\ B\in\mathcal F_p), \)

\( \displaystyle\sum_{B\in\mathcal F_p}z_{p,B}=\mu_p \qquad(p). \)

For each candidate \(c\), define its total disapproved mass by

\( \displaystyle r_c=\sum_p\sum_{B\in\mathcal F_p}\mathbf 1_{\{c\in B\}}z_{p,B}. \)

Under \((m-2)\)-approval, a candidate is approved precisely when it is outside the bottom pair. Since the total mass is \(1\), candidate \(c\)’s score is therefore \(1-r_c\).

Thus \(c^\star\) is a co-winner exactly when

\( r_{c^\star}\leq r_c \qquad(c\in C\setminus\{c^\star\}). \)

Add these inequalities to the linear program. Equivalently, add

\( \displaystyle\sum_p\sum_{B\in\mathcal F_p}\bigl(\mathbf 1_{\{c\in B\}}-\mathbf 1_{\{c^\star\in B\}}\bigr)z_{p,B}\geq 0 \qquad(c\neq c^\star). \)

These are weak inequalities, so they include ties exactly as required.

3. Exact equivalence with the original problem

From an allocation to a feasible linear-program solution. Given an allowed allocation \(y_{p,v}\), let \(\operatorname{bot}(v)\) denote the unordered set of its last two candidates and set

\( \displaystyle z_{p,B}=\sum_{\substack{v\in\operatorname{Ext}(p)\\ \operatorname{bot}(v)=B}}y_{p,v}. \)

The lemma ensures that every extension’s bottom pair belongs to \(\mathcal F_p\). Grouping the allocation by bottom pair consequently preserves nonnegativity, each type’s total mass, and every candidate’s score. If the allocation makes \(c^\star\) a co-winner, all the linear-program constraints hold.

From a feasible linear-program solution to an allocation. For each \(p\) and \(B\in\mathcal F_p\), choose one witnessing extension \(v_{p,B}\) supplied by the lemma. Assign mass \(z_{p,B}\) to that extension and zero to all other extensions of \(p\). Distinct bottom pairs have distinct witnessing extensions, so this assignment is well-defined.

The type-mass equalities give total mass \(\mu_p\) for every type. The disapproved mass of every candidate is exactly \(r_c\), so the winner inequalities make \(c^\star\) a co-winner.

Therefore, the linear program is feasible if and only if the requested allocation exists.

4. Polynomial bit complexity

The number of variables is

\( \displaystyle N=\sum_p|\mathcal F_p|\leq \tau\binom{m}{2}. \)

There are \(N\) nonnegativity constraints, \(\tau\) mass equalities, and \(m-1\) winner inequalities. All matrix coefficients belong to \(\{-1,0,1\}\). The only nonzero right-hand sides are the input rational masses \(\mu_p\).

Replacing each equality by two inequalities gives an explicitly represented rational linear system whose total binary encoding length is polynomial in \(m,\tau,L\), even using a dense matrix representation.

The polynomial-time rational linear-programming feasibility theorem states that feasibility over the reals of an explicitly represented system of rational linear inequalities can be decided in time polynomial in its binary encoding length. This is the standard consequence of [Khachiyan’s polynomial algorithm for linear programming](https://www.mathnet.ru/eng/dan42319). Its hypotheses hold here: the system is finite, explicit, and has rational coefficients and right-hand sides. Exact feasibility, including solutions on the boundary, is covered.

Enumerating the feasible pairs and deciding feasibility therefore takes time polynomial in \(m,\tau,L\).

5. Why finite-profile hardness does not transfer

In a finite unweighted profile, each voter must choose one extension. The corresponding bottom-pair variables must encode indivisible voter counts. Here the masses may split arbitrarily, so continuous variables describe precisely the permitted choices.

The equivalence proved above establishes that continuous linear feasibility settles the stated mass-splitting formulation.
