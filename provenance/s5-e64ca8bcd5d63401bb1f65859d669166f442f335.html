The continuous mirror question, as graded

Given \(m+1\) candidates with preferred candidate \(p\), a positional scoring vector \(\vec{\alpha}\), rational masses \(\mu_t\) on nonmanipulator ranking types summing to \(1-\rho\), and a homogeneous manipulator bloc of mass \(\rho>0\), compute the minimum \(T_\infty^*\) and a mass allocation attaining it. Each unit of bloc mass reports a complete ranking \(r\) with \(p\) first; for \(x_r\ge 0\) with \(\sum_r x_r=\rho\), minimize \(\max_{c\ne p}\left(\sum_t\mu_t s(t,c)+\sum_{r:\,p\text{ first in }r}x_r s(r,c)\right)\). Determine whether \(p\) can win by testing \(T_\infty^*\le B_p+\rho\alpha_m\), where \(B_p=\sum_t\mu_t s(t,p)\).

All candidates with maximum aggregate score are winners.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here types are nonmanipulator rankings, \(\tau\) is the support size, not the number of possible rankings, and their masses sum to \(1-\rho\), where the input rational \(\rho\) satisfies \(0<\rho\le1\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).
The homogeneous manipulator bloc has mass \(\rho\), all preferring \(p\), and may split freely among rankings placing \(p\) first. A feasible allocation is a finite list of such rankings with nonnegative rational masses \(x_r\) satisfying \(\sum_r x_r=\rho\).
Define \(B_c=\sum_t\mu_t s(t,c)\), \(T(x)=\max_{c\ne p}(B_c+\sum_r x_r s(r,c))\), and \(T_\infty^*=\min_x T(x)\). Thus \(p\) can be a winner exactly when \(T_\infty^*\le B_p+\rho\alpha_m\).

Result

The continuous problem is exactly solvable in deterministic polynomial time. Consequently, the requested approximation exists for \(d=2\), with failure probability zero.

More precisely, an optimal feasible allocation can be computed in time \((m+\tau+L)^{O(1)}\), and it uses at most \(m^2-m+1\) rankings. The argument applies to the full stated problem, including binary rational masses and arbitrary scoring vectors satisfying the given bounds.

1. Representing the bloc by a matrix

Write \(B_i=B_{c_i}\). Since every manipulator ranking places \(p\) first, the rivals occupy the score positions indexed by \(0,\ldots,m-1\).

For a feasible allocation \(x\), define
\[ q_{ij}=\frac{1}{\rho}\sum_{\substack{r:\,c_i\text{ receives}\\\text{score }\alpha_j\text{ at index }j}}x_r, \qquad 1\le i\le m,\quad 0\le j<m. \]
Here “at index \(j\)” identifies the ranking position, even when some scoring-vector entries coincide.

Each ranking assigns each rival to exactly one index and uses each index exactly once. Therefore
\[ q_{ij}\ge0,\qquad \sum_{j=0}^{m-1}q_{ij}=1,\qquad \sum_{i=1}^{m}q_{ij}=1. \]
Thus \(Q=(q_{ij})\) is a rational doubly stochastic matrix. Rival \(c_i\)'s aggregate score is
\[ B_i+\rho\sum_{j=0}^{m-1}\alpha_jq_{ij}. \]

The following constructive converse ensures that this matrix representation loses no information relevant to the objective.

2. Rational decomposition into rankings

Lemma. Every rational doubly stochastic \(m\times m\) matrix can be decomposed into a convex combination of at most \(m^2-m+1\) permutation matrices, with rational coefficients, in polynomial time.

Proof. Initially let \(R=Q\) and \(u=1\). Maintain that \(R\) is nonnegative and every row and column sums to \(u\).

If \(u>0\), form a bipartite graph whose vertices are the rows and columns, with an edge precisely when the corresponding entry of \(R\) is positive. For a set \(S\) of rows, let \(N(S)\) be its neighboring columns. Then
\[ |S|u =\sum_{i\in S}\sum_{j\in N(S)}R_{ij} \le\sum_{j\in N(S)}\sum_{i=1}^{m}R_{ij} =|N(S)|u. \]
Since \(u>0\), this gives \(|S|\le|N(S)|\). Hall's marriage theorem therefore supplies a perfect matching.

Let \(P\) be its permutation matrix and set
\[ \lambda=\min_{\{(i,j):P_{ij}=1\}}R_{ij}. \]
All matched entries are positive, so \(\lambda>0\). Also \(\lambda\le u\), because no entry exceeds its row sum. Record \((\lambda,P)\) and replace
\[ R\leftarrow R-\lambda P,\qquad u\leftarrow u-\lambda. \]
The new matrix remains nonnegative, and all row and column sums become \(u-\lambda\). At least one positive entry becomes zero; zero entries never become positive.

Consequently the process terminates. It can terminate only with \(u=0\): whenever \(u>0\), the preceding argument supplies another matching and subtraction. A nonnegative matrix with zero row sums is the zero matrix. Hence the recorded terms satisfy
\[ Q=\sum_{\ell=1}^{N}\lambda_\ell P^\ell, \qquad \sum_{\ell=1}^{N}\lambda_\ell=1. \]

For the support bound, let \(E\le m^2\) be the initial number of positive entries. Every nonfinal iteration removes at least one positive entry. In the final iteration, the residual matrix equals \(\lambda P\), so that iteration removes exactly \(m\) positive entries. Thus
\[ N-1+m\le E,\qquad N\le m^2-m+1. \]

All coefficients are rational. For bit complexity, take a common denominator \(D_Q\) for the entries of \(Q\), for example the product of their denominators. Its bit length is at most the total bit length of \(Q\). Every subsequent residual entry and every \(\lambda_\ell\) is an integer multiple of \(1/D_Q\) between zero and one. Arithmetic therefore retains polynomial bit length.

A perfect matching can be found by a deterministic augmenting-path algorithm using \(O(m^3)\) elementary graph operations. There are at most \(m^2\) iterations, so the decomposition takes polynomial time. This proves the lemma.

For each \(P^\ell\), construct the strict ranking \(r_\ell\) placing \(p\) first and placing \(c_i\) in position \(m+1-j\) whenever \(P^\ell_{ij}=1\). Assign it mass
\[ x_{r_\ell}=\rho\lambda_\ell. \]
These masses are rational, nonnegative, and sum to \(\rho\). They reproduce exactly the rival scores represented by \(Q\).

3. An exact polynomial-size linear program

Consider the linear program minimizing \(t\), subject to
\[ q_{ij}\ge0 \quad (1\le i\le m,\ 0\le j<m), \]
\[ \sum_{j=0}^{m-1}q_{ij}=1 \quad (1\le i\le m), \]
\[ \sum_{i=1}^{m}q_{ij}=1 \quad (0\le j<m), \]
\[ B_i+\rho\sum_{j=0}^{m-1}\alpha_jq_{ij}\le t \quad (1\le i\le m), \]
and
\[ 0\le t\le\alpha_m. \]

The bounds on \(t\) are harmless. Scores are nonnegative, and the total societal mass, including manipulators, is one. Therefore every candidate's aggregate score is at most \(\alpha_m\).

The program is nonempty: take \(q_{ij}=1/m\) and \(t=\alpha_m\). Indeed,
\[ B_i\le(1-\rho)\alpha_m, \qquad \rho\sum_j\alpha_jq_{ij}\le\rho\alpha_m. \]
Its feasible region is closed and bounded, since each \(q_{ij}\) lies between zero and one. Thus it has an optimum.

We use the standard rational linear-programming theorem: a nonempty bounded linear program with rational coefficients admits an exact optimal rational solution computable in deterministic time polynomial in its binary encoding length. Optimal solutions of polynomial bit length and polynomial-time solvability are discussed in [Goemans's MIT notes on linear programming](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/6713f99d2b7c4c6adfc645c33b835059_lect9_24.pdf).

Let \((Q^*,t^*)\) be such an optimal solution.

Every feasible allocation \(x\) yields a feasible matrix for this program with \(t=T(x)\), by Section 1. Hence
\[ t^*\le T(x) \]
for every feasible allocation.

Conversely, decompose \(Q^*\) using Section 2 and construct the resulting rational allocation \(x^*\). Its rival scores satisfy the program's constraints, so
\[ T(x^*)\le t^*. \]
Applying the preceding lower bound to \(x^*\) gives the reverse inequality. Therefore
\[ T(x^*)=t^*=T_\infty^*. \]
In particular, this proves that the optimum over the stipulated finite rational allocations is attained.

4. Input and output complexity

Let \(b=L+\lceil\log_2(m+1)\rceil+1\). Since \(a\) is fixed, each scoring entry has \(O(\log(m+1))\) bits.

Computing all \(B_c\) requires scanning the \(\tau\) supplied rankings and performing \(O((\tau+1)(m+1))\) rational arithmetic operations. These computations have polynomial bit length: a common denominator can be chosen as the product of the denominators of the input masses and \(\rho\), whose bit length is \(O(L)\). Each aggregate score lies between zero and \(\alpha_m\), so its numerator over that denominator has \(O(b)\) bits.

The linear program has \(m^2+1\) variables and \(m^2+3m+2\) displayed constraints, counting nonnegativity constraints and equalities individually. Each coefficient has \(O(b)\) bits. Even a dense representation therefore has encoding length \(O(m^4b)\). Exact rational linear programming takes time polynomial in this length and returns a solution of polynomial bit length.

The decomposition then uses \(O(m^5)\) elementary graph operations and polynomial-bit rational arithmetic. It outputs at most \(m^2-m+1\) rankings with rational masses of polynomial bit length.

Thus the entire algorithm, including reading the support and explicitly writing the allocation, runs in
\[ (m+\tau+L)^{O(1)} \]
bit operations. It never expands binary rational masses into individual voters.

5. The requested approximation guarantee

Choose the absolute constant \(d=2\), with \(\beta\) defined as in the question. Monotonicity of the scoring vector implies
\[ g_\beta(\vec\alpha)\ge0. \]
The exact algorithm therefore satisfies
\[ T(x^*)=T_\infty^* \le T_\infty^*+\rho g_\beta(\vec\alpha). \]

A deterministic algorithm is also a randomized algorithm that ignores its random bits. Its failure probability is zero, which satisfies any exponentially small failure bound.

Free divisibility is the decisive hypothesis: it permits every rational doubly stochastic matrix to be implemented by rational masses on rankings. A fixed number of equal-mass discrete manipulators does not permit arbitrary such coefficients.
