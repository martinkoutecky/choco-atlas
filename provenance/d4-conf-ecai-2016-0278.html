The continuous mirror question, as graded

Given items \(P\), positive weights \(w_j\), capacity \(W\), a finite support \(T\) of types with rational masses \(\mu_t \ge 0\) summing to \(1\), and each type’s rational additive utilities \(u_j^t\) and approval threshold \(\delta_t\), does there exist \(X \subseteq P\) with \(\sum_{j \in X} w_j \le W\) such that \(\sum_{t \in T} \mu_t \mathbf{1}\{\sum_{j \in X} u_j^t \ge \delta_t\} \ge q\), for a given rational target share \(q\)?

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a nonempty set of \(m\) indivisible items, with positive binary rational weights \(w_j\) and positive integer capacity \(W\).
A society is given by its support: the list \(T\) of its \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has signed binary rational additive utilities \(u_j^t\) and a signed binary rational approval threshold \(\delta_t\); it approves \(X\subseteq P\) exactly when \(\sum_{j\in X}u_j^t\ge\delta_t\). Utilities need not be normalized.
Given a binary rational target share \(q\in(0,1]\), decide whether some \(X\subseteq P\) satisfies \(\sum_{j\in X}w_j\le W\) and \(\sum_{t\in T}\mu_t\mathbf{1}\{\sum_{j\in X}u_j^t\ge\delta_t\}\ge q\). The empty subset is allowed; items cannot be selected fractionally.
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For explicitly listed agents and a positive integer target number of approvals, discrete approval multi-agent knapsack is NP-complete (Benabbou and Perny, 2016).
With positive integer weights and fixed capacity, that discrete problem is solvable in polynomial time.

Modeling choices made when packaging the task

  • The capacity domain was unspecified; require a positive integer capacity, as in the discrete decision problem.
  • The weights' encoding was unspecified; use positive binary rationals.
  • The target share's domain was unspecified; use q in (0,1], reflecting a positive target number of approvals.
  • Utility and threshold signs were unspecified; allow signed rationals, following the discrete framework rather than its later optimization formulation.
  • Require a nonempty item set and list only positive-mass types; zero-mass entries are omitted from the support.

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when \(\tau=1\), \(q=1\), \(W=1\), and every utility equals the corresponding positive dyadic rational weight.

Consequently, a polynomial-time algorithm in \(m,\tau,L\) exists if and only if \(\mathrm{P}=\mathrm{NP}\).

Membership in \(\mathrm{NP}\)

A certificate is a selection vector \(x\in\{0,1\}^m\). We verify feasibility, determine which supported types approve, and compare their total mass with \(q\).

These operations can be performed exactly in polynomial time. Write each input rational as \(p_r/d_r\), with positive denominator \(d_r\), and let \(D=\prod_r d_r\). The binary length of \(D\) is at most the sum of the denominator lengths, hence \(O(L)\). Multiplying every rational by \(D\) produces integers of \(O(L)\) bits. The resulting sums also have \(O(L)\) bits, since there are at most \(m\) or \(\tau\) summands and both parameters are bounded by the explicit input length.

Thus all comparisons reduce to exact integer arithmetic. Using elementary multiplication and division, certificate verification takes

\(O\bigl((m\tau+m+\tau)L^2\bigr)\)

bit operations. Signed utilities and thresholds cause no difficulty. We process only the \(\tau\) listed types; no expansion of rational masses into agents is required. Therefore the problem belongs to \(\mathrm{NP}\).

Hardness with one type and fixed capacity

We reduce from SUBSET SUM: given binary-encoded positive integers \(a_1,\ldots,a_n\) and a positive integer \(B\), decide whether some \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{j\in I}a_j=B\). This version is \(\mathrm{NP}\)-complete; the standard reduction produces positive integers and a positive target. [Cornell’s SUBSET SUM proof](https://courses.cs.cornell.edu/cs4820/2018fa/lectures/subset_sum.pdf)

Let \(A=\sum_{j=1}^n a_j\), and choose a power of two \(D=2^k>A+B\). Construct \(n+1\) items, indexed by \(0,1,\ldots,n\), with

\(w_j=u_j^t=a_j/D\quad(1\le j\le n),\qquad w_0=u_0^t=(D-B)/D.\)

There is one type \(t\), with \(\mu_t=1\). Set \(\delta_t=1\), \(q=1\), and \(W=1\).

The construction satisfies every hypothesis. All weights and utilities are positive dyadic rationals because \(D>B\). The support has size \(\tau=1\), its mass sums to one, and the capacity is a positive integer. Moreover, \(k=O(S)\), where \(S\) is the SUBSET SUM input length, so the construction has polynomial size and is computable in polynomial time.

Correctness. Because \(q=\mu_t=1\), a successful subset must be approved by \(t\). Utilities equal weights, so success is equivalent to

\(\sum_{j\in X}w_j\le1\quad\text{and}\quad\sum_{j\in X}w_j\ge1,\)

hence to \(\sum_{j\in X}w_j=1\).

Every subset omitting item \(0\) has total weight at most \(A/D<1\). Therefore every successful subset contains item \(0\). Writing \(I=X\setminus\{0\}\), its total weight equals one precisely when

\(\dfrac{D-B+\sum_{j\in I}a_j}{D}=1,\)

which is equivalent to \(\sum_{j\in I}a_j=B\).

Conversely, any SUBSET SUM solution \(I\) yields the successful subset \(I\cup\{0\}\). This proves both directions of the reduction. The empty subset has utility zero and is rejected in these instances.

The problem is therefore \(\mathrm{NP}\)-hard under the stated restrictions and, by membership in \(\mathrm{NP}\), \(\mathrm{NP}\)-complete.

Why fixed integer capacity can still yield tractability

The positive integer weight restriction is essential to the stated fixed-capacity result.

If every weight is a positive integer and capacity is a fixed constant \(c\), every feasible subset contains at most \(c\) items. Enumerating all subsets of size at most \(c\), including the empty subset, examines at most

\(\sum_{r=0}^{\min(m,c)}\binom mr\le(m+1)^c\)

candidates. Using the verifier above gives running time

\(O\bigl((m+1)^c(m\tau+m+\tau)L^2\bigr),\)

which is polynomial in \(m,\tau,L\) for fixed \(c\).

Positive rational weights provide no such cardinality bound. The reduction above proves hardness even for capacity \(1\). Clearing their denominators replaces that capacity by the integer \(D\), whose numerical value can be exponential in its binary encoding length; it does not produce a fixed-capacity integer instance.
