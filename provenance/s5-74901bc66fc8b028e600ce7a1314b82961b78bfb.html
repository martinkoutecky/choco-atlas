The continuous mirror question, as graded

Given criteria with binary reference scales and a finite support \(T\) of complete user types, each with rational mass \(\mu_t\), preference data \(P_t\), and a necessary query \((x_t,y_t)\), determine for each type whether an \(E_2\) explanation exists and output one when it does. For batches in which every type is explainable, choose explanations minimizing the expected number of comparison steps, \(\sum_{t\in T}\mu_t q_t\), where \(q_t\) is the explanation length.

Packaged proof task (what the prover saw — nothing else)

There are \(m\geq2\) increasing numerical criteria, with rational interval domains \(X_i=[a_i,b_i]\) and two rational reference levels \(a_i\leq\ell_i<h_i\leq b_i\); write \(X=\prod_iX_i\) and \(V=\prod_i\{\ell_i,h_i\}\).
A society is given by its support: the list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies a finite set \(P_t\subseteq V\times V\) of weak preference statements and rational query profiles \(x_t,y_t\in X\). Its compatible models are \(U(z)=\sum_i u_i(z_i)\), where each \(u_i:X_i\to\mathbb R\) is nondecreasing, \(u_i(a_i)=0\), \(\sum_i u_i(b_i)=1\), and \(U(c)\geq U(d)\) for every \((c,d)\in P_t\).
Assume each type has a compatible model whose marginal functions are strictly increasing. Define \(z\succeq_t z'\) when \(U(z)\geq U(z')\) for every compatible model, and promise \(x_t\succeq_t y_t\).
An \(E_2\) explanation is a finite chain \(z^0=x_t,\ldots,z^{q_t}=y_t\) of rational profiles in \(X\). Each comparison is either Pareto dominance or a necessary preference \(z^{j-1}\succeq_t z^j\) between Pareto-incomparable profiles differing on exactly two criteria; dominance may change arbitrarily many criteria. Length \(q_t\) counts comparisons, including dominance comparisons, and may be zero.
Determine explainability for every supported type and output an explanation whenever one exists. When every type is explainable, choose one explanation per type minimizing \(\sum_t\mu_tq_t\), with no constraints shared across types. The associated decision problem asks whether all types admit explanations with this sum at most a supplied nonnegative binary-rational bound \(B\).
Let \(s=\sum_t|P_t|\) and let \(L\) be the total binary input length.

Is this mass-supported explanation problem, including exact minimum expected comparison length on fully explainable inputs, solvable in polynomial time in \(m,\tau,s,L\), or is its associated decision problem NP-hard?

For a single user with binary reference scales, explainability has a matching characterization, and existence testing and explanation construction are polynomial-time in the explicit preference input ([verified result](https://arxiv.org/pdf/1502.04593v1)).
The later formulation explicitly counts comparison steps as length ([published version reproduced by an author](https://wassilaouerdane.github.io/HDR_Ouerdane_2022.pdf)). No result addressing exactly the mass-supported expected-length problem was located.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, since the objective is an expectation.
  • Specified bounded rational interval attribute domains, rational reference levels, and rational query profiles; binary reference scales do not require binary attribute domains.
  • Interpreted preference data as explicitly listed weak comparisons between reference profiles, rather than a completely specified preference order.
  • Completed the utility normalization by setting each marginal value at its domain minimum to zero and the total value at the domain maxima to one.
  • Required a compatible model with strictly increasing marginals to exclude degenerate data forcing a criterion to be identically indifferent, which would undermine the intended distinction between dominance and two-criterion trade-offs.
  • Restored unrestricted Pareto-dominance comparisons alongside necessary two-criterion trade-offs, and counted every comparison as one step, following the later length convention.
  • Allowed zero comparison steps for identical query profiles and rational intermediate profiles anywhere in the attribute domain.
  • Specified one explanation per supported type with no shared constraints, and supplied a rational objective threshold to define the decision problem associated with exact optimization.

Result

The problem is polynomial-time solvable, including the exact minimum expected comparison length.

For each explainable type \(t\), define
\[ \]
\(n_t=|\{i:x_{t,i}<y_{t,i}\}|\) and \(d_t=|\{i:x_{t,i}>y_{t,i}\}|\).

Its minimum explanation length is exactly

\(q_t^*=n_t+\mathbf 1_{\{d_t>n_t\}}.\)

Consequently, on fully explainable inputs the minimum expected length is

\(\displaystyle \sum_{t\in T}\mu_t\bigl(n_t+\mathbf 1_{\{d_t>n_t\}}\bigr).\)

The cited [preprint](https://arxiv.org/pdf/1502.04593v1) establishes the binary-reference matching characterization; the [published formulation](https://wassilaouerdane.github.io/HDR_Ouerdane_2022.pdf) counts comparisons as length. Below is a self-contained proof, including optimality against arbitrary intermediate profiles and chains that reuse criteria.

1. Reference increments and their necessary ordering

Fix one type and omit its subscript. For a compatible model, write

\(w_i=u_i(h_i)-u_i(\ell_i).\)

Let \(M\) have one row for each statement \((c,d)\in P\), with entries

\(M_{(c,d),i}=\mathbf 1_{\{c_i=h_i\}}-\mathbf 1_{\{d_i=h_i\}}.\)

Because the values \(u_i(\ell_i)\) cancel in every reference-profile comparison, the preference constraints are precisely \(Mw\geq 0\). Define

\(C=\{w\in\mathbb R_{\geq 0}^{m}:Mw\geq 0\},\qquad K=\{w\in C:\sum_iw_i=1\}.\)

The strictly increasing compatible model promised in the question supplies a vector \(w^+\in C\) with every coordinate positive. Dividing by \(\sum_iw_i^+\) shows that \(K\) contains a strictly positive vector. Also, \(K\) is compact.

Every vector \(w\in K\) is realizable by a compatible model. Indeed, choose thresholds \(\ell_i<\theta_i\leq h_i\), and put

\(u_i(z)=w_i\mathbf 1_{\{z\geq\theta_i\}}.\)

These functions are nondecreasing, satisfy \(u_i(a_i)=0\), and have \(\sum_i u_i(b_i)=1\). Their reference increments equal \(w_i\), so \(Mw\geq 0\) verifies all statements in \(P\). These step functions are admissible: compatibility requires nondecreasing marginals, while strict increase is only an existence promise.

Define a relation on criteria by

\(i\trianglerighteq j\quad\Longleftrightarrow\quad w_i\geq w_j\text{ for every }w\in K.\)

This relation is reflexive and transitive. It can be tested by the rational linear program

\(\displaystyle \min_{w\in K}(w_i-w_j).\)

Moreover, \(i\trianglerighteq j\) implies \(w_i\geq w_j\) for the reference increments of every compatible model. Such an increment vector belongs to \(C\); if its coordinate sum is positive, normalize it into \(K\), and if its sum is zero, all its coordinates vanish.

2. Exact characterization of a two-criterion swap

Consider profiles \(p,p'\) differing only on two criteria, with

\(p_i>p'_i,\qquad p_j<p'_j.\)

Thus criterion \(i\) decreases and criterion \(j\) increases.

Lemma. The necessary preference \(p\succeq p'\) holds if and only if

\(p_i\geq h_i,\qquad p'_i\leq\ell_i,\qquad \ell_j\leq p_j<p'_j\leq h_j,\qquad i\trianglerighteq j.\)

Proof.

First suppose that the increase interval is not contained in \([\ell_j,h_j]\). Choose a threshold \(\theta\in(p_j,p'_j]\) with either \(\theta\leq\ell_j\) or \(\theta>h_j\). Set

\(u_j(z)=\mathbf 1_{\{z\geq\theta\}},\qquad u_k(z)=0\text{ for }k\neq j.\)

This is a normalized compatible model: its values at \(\ell_j\) and \(h_j\) agree, so every reference-profile statement holds with equality. But \(U(p)-U(p')=-1\). Therefore necessity requires

\(\ell_j\leq p_j<p'_j\leq h_j.\)

Next suppose that the decreasing interval does not cover the entire reference interval of criterion \(i\). Equivalently, \(p_i<h_i\) or \(p'_i>\ell_i\). We can then choose

\(\theta_i\in(\ell_i,h_i]\setminus(p'_i,p_i].\)

Take a strictly positive vector \(w\in K\), choose \(\theta_j\in(p_j,p'_j]\), and construct the step-function model from Section 1. Criterion \(i\) contributes zero to \(U(p)-U(p')\), while criterion \(j\) contributes \(-w_j<0\). Hence necessity requires \(p_i\geq h_i\) and \(p'_i\leq\ell_i\).

If these endpoint conditions hold but \(i\not\trianglerighteq j\), choose \(w\in K\) with \(w_i<w_j\). The same step-function construction, with \(\theta_j\in(p_j,p'_j]\), gives

\(U(p)-U(p')=w_i-w_j<0.\)

This proves necessity of every stated condition.

Conversely, assume all the conditions. In every compatible model,

\(u_i(p_i)-u_i(p'_i)\geq w_i,\qquad u_j(p'_j)-u_j(p_j)\leq w_j.\)

Therefore

\(U(p)-U(p')\geq w_i-w_j\geq 0.\)

This proves sufficiency. \(\square\)

3. Explainability is exactly a covering matching

For the query \(x\succeq y\), define

\(N=\{j:x_j<y_j\},\qquad D=\{i:x_i>y_i\},\qquad F=\{i:x_i\geq h_i,\ y_i\leq\ell_i\}.\)

Thus \(F\subseteq D\), and \(F\cap N=\varnothing\).

The necessary-preference promise implies

\(\ell_j\leq x_j<y_j\leq h_j\qquad\text{for every }j\in N.\)

Otherwise, the single-coordinate step-function countermodel used in Section 2 would violate \(x\succeq y\), regardless of changes on other criteria.

Construct a bipartite graph with vertex sets \(F\) and \(N\), placing an edge between \(i\in F\) and \(j\in N\) exactly when \(i\trianglerighteq j\).

Theorem. An \(E_2\) explanation exists if and only if this graph has a matching covering \(N\).

Sufficiency and construction

Let \(\phi:N\to F\) be an injection with \(\phi(j)\trianglerighteq j\).

Start at \(x\). For each \(j\in N\), replace the two coordinates \(\phi(j)\) and \(j\) by their values in \(y\). The pairs are disjoint, so those coordinates still have their values from \(x\) when the replacement occurs. Each comparison is a valid necessary swap by Section 2.

After these swaps, every increasing coordinate agrees with \(y\). Every remaining coordinate is at least its value in \(y\). A final Pareto-dominance comparison therefore reaches \(y\), unless the current profile already equals \(y\).

All constructed profiles are rational, and each coordinate is taken directly from \(x\) or \(y\).

Necessity for arbitrary chains

Suppose an arbitrary explanation exists. We prove the matching condition without restricting its intermediate profiles or the number of times it uses a criterion.

Choose a threshold \(\theta_i\in(\ell_i,h_i]\) for each criterion such that, with \(f_i(z)=\mathbf 1_{\{z\geq\theta_i\}}\),

\(f_i(x_i)-f_i(y_i)= \begin{cases} 1,&i\in F,\\ -1,&i\in N,\\ 0,&i\notin F\cup N. \end{cases}\)

Here are explicit valid choices:

  • For \(i\in F\), choose any threshold strictly between \(\ell_i\) and \(h_i\).
  • For \(i\in N\), choose a threshold strictly between \(x_i\) and \(y_i\).
  • Otherwise \(x_i\geq y_i\). If \(x_i<h_i\), choose \(\theta_i\in(\max\{x_i,\ell_i\},h_i]\), making both indicator values zero. If \(x_i\geq h_i\), membership outside \(F\) implies \(y_i>\ell_i\); choose \(\theta_i\in(\ell_i,\min\{y_i,h_i\}]\), making both indicator values one.

Let \(e_i\) be the \(i\)-th standard basis vector.

By Section 2, every swap decreasing criterion \(i\) and increasing criterion \(j\) decreases \(f_i\) from one to zero. It either increases \(f_j\) from zero to one or leaves \(f_j\) unchanged. Its indicator difference is therefore \(e_i-e_j\) or \(e_i\), respectively, and \(i\trianglerighteq j\).

A dominance comparison contributes a nonnegative sum of standard basis vectors. Telescoping over the chain consequently gives

\(\displaystyle \mathbf 1_F-\mathbf 1_N =\sum_{i\neq j}c_{ij}(e_i-e_j)+\sum_i r_i e_i, \)

where \(c_{ij}\) and \(r_i\) are nonnegative integers, and \(c_{ij}>0\) only if \(i\trianglerighteq j\). Here \(\mathbf 1_F\) and \(\mathbf 1_N\) denote incidence vectors.

We verify Hall’s condition. For any \(H\subseteq N\), let

\(S_H=\{i:\text{there exists }j\in H\text{ with }i\trianglerighteq j\}.\)

Reflexivity gives \(H\subseteq S_H\). Transitivity implies that no arc with \(c_{ij}>0\) enters \(S_H\) from outside: if \(j\in S_H\) and \(i\trianglerighteq j\), then \(i\in S_H\).

Summing the telescoping identity over coordinates in \(S_H\) gives

\(\displaystyle |F\cap S_H|-|N\cap S_H| =\sum_{\substack{i\in S_H\\j\notin S_H}}c_{ij} +\sum_{i\in S_H}r_i \geq 0. \)

The neighbors of \(H\) in the bipartite graph are exactly \(F\cap S_H\). Thus

\(|F\cap S_H|\geq |N\cap S_H|\geq |H|.\)

Hall’s theorem now supplies a matching covering \(N\). \(\square\)

4. Exact minimum comparison length

Assume the type is explainable, and write \(n=|N|\) and \(d=|D|\). The covering matching implies \(d\geq |F|\geq n\).

Theorem. The minimum explanation length is

\(q^*=n+\mathbf 1_{\{d>n\}}.\)

Lower bound. Every coordinate in \(N\) must increase during at least one comparison. Dominance comparisons increase no coordinates, and each two-criterion swap increases exactly one coordinate. Hence every explanation contains at least \(n\) swaps, so \(q\geq n\).

If \(q=n\), all comparisons must be swaps. Each swap decreases exactly one coordinate, so at most \(n\) distinct coordinates can decrease. Every coordinate in \(D\) must decrease somewhere in the chain. Therefore \(q=n\) requires \(d\leq n\).

Consequently, if \(d>n\), then \(q\geq n+1\).

Attainment. Use the matching construction from Section 3.

If \(d=n\), its \(n\) matched donors exhaust \(D\). Every changed coordinate reaches its final value during the swaps, so the chain has length \(n\).

If \(d>n\), some decreasing coordinates remain unmatched. After the \(n\) swaps, one strict dominance comparison changes all of them to their final values. The chain has length \(n+1\).

This also handles the boundary cases: if \(n=0<d\), use one dominance comparison; if \(n=d=0\), then \(x=y\), and the empty chain has length zero. \(\square\)

In particular, the construction uses at most \(\lceil m/2\rceil\) comparisons. When \(d=n\), we have \(2n\leq m\); when \(d>n\), we have \(2n+1\leq m\).

5. Polynomial-time algorithm and the mass-supported objective

For each supported type \(t\):

  • Compute its sets \(N_t,D_t,F_t\).
  • For every pair in \(F_t\times N_t\), test the necessary increment ordering using the linear program from Section 1.
  • Find a maximum bipartite matching. The type is explainable exactly when the matching covers \(N_t\).
  • For every explainable type, output the matching construction from Section 3. By Section 4, this explanation is shortest.

There are at most \(\tau m^2\) linear programs. Each has \(m\) variables and polynomially many constraints, with coefficients in \(\{-1,0,1\}\). Exact rational linear programming and bipartite matching both run in polynomial time. The output has polynomial size because every intermediate coordinate is an input coordinate and each chain has at most \(\lceil m/2\rceil\) comparisons.

On fully explainable inputs, every choice of explanations satisfies

\(\displaystyle \sum_t\mu_tq_t\geq\sum_t\mu_tq_t^*.\)

The separately constructed shortest explanations attain equality. There are no constraints shared across types, so this proves optimality of the expected length.

Finally, multiplying the input rational masses by the polynomially bounded integers \(q_t^*\), adding them, and comparing the result with \(B\) requires only polynomial bit complexity. The decision algorithm rejects if any supported type is unexplainable; otherwise, it accepts exactly when

\(\displaystyle \sum_t\mu_t\bigl(n_t+\mathbf 1_{\{d_t>n_t\}}\bigr)\leq B.\)

Thus explainability testing, explanation construction, exact expected-length optimization, and the associated decision problem are all polynomial-time solvable in \(m,\tau,s,L\).
