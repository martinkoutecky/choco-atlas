The continuous mirror question, as graded

Fix \(n\ge2\). Given a discounted MOMDP with finite state and action sets, transition probabilities, an initial-state distribution, discount factor \(\gamma\in(0,1)\), and positive bounded per-person rewards \(r_i\) for each type \(i\in T=\{1,\dots,n\}\), form a society with type masses \(\mu_i=1/n\). All members of a type share its reward function, and the system uses one stationary randomized policy \(\pi:S\to\Delta(A)\). Let \(v_i^\pi\) be type \(i\)'s expected discounted reward, and let \(\mathcal L_\pi(q)\) be the population Lorenz curve of these type-level per-person rewards. Compute a finite set \(Y\) of feasible policies such that for every Lorenz-optimal attainable profile \(v^\pi\), some \(\pi'\in Y\) satisfies \((1+\epsilon)\mathcal L_{\pi'}(q)\ge\mathcal L_\pi(q)\) for every \(q\in[0,1]\). At \(q=k/n\), \(\mathcal L_\pi(q)\) is the paper's \(k\)-th cumulative sorted reward divided by \(n\), with linear interpolation between these points.

Fix \(n\ge2\). A society is given by its support: the list of \(\tau=n\) types with positive binary-rational masses \(\mu_i=1/n\); \(\tau\) is the support size, not the number of possible types.
The input is a discounted MOMDP with nonempty finite state and action sets \(S,A\), \(m=|S|\), rational transition probabilities, a rational initial-state distribution, rational discount factor \(\gamma\in(0,1)\), and strictly positive rational rewards \(r_i:S\times A\to\mathbb Q_{>0}\). Let \(L\) be the total binary input length, including rational \(\epsilon>0\).
One stationary randomized policy \(\pi:S\to\Delta(A)\) governs the whole society. Each type receives its per-person expected infinite-horizon discounted reward \(v_i^\pi\), evaluated under the initial-state distribution.
Sort these rewards increasingly as \(v_{(1)}^\pi\le\cdots\le v_{(n)}^\pi\). Define the unnormalized population Lorenz curve by \(\mathcal L_\pi(0)=0\), \(\mathcal L_\pi(k/n)=n^{-1}\sum_{j=1}^k v_{(j)}^\pi\), and linear interpolation.
A profile is Lorenz-optimal if no attainable profile has a curve weakly greater everywhere and strictly greater somewhere. Seek a finite set \(Y\) of feasible policies such that every Lorenz-optimal \(v^\pi\) has some \(\pi'\in Y\) satisfying \((1+\epsilon)\mathcal L_{\pi'}(q)\ge\mathcal L_\pi(q)\) for all \(q\in[0,1]\).
Does this covering problem admit a fully polynomial approximation scheme, with runtime and output size polynomial in \(m,|A|,L,1/\epsilon\) for fixed \(\tau=n\), or can such a scheme be ruled out assuming \(\mathrm P\ne\mathrm{NP}\)?
Known results: fixed-dimensional discounted MOMDPs with stationary randomized policies admit a fully polynomial scheme for multiplicative Lorenz covering. [Primary source](https://auai.org/uai2013/prints/papers/208.pdf).
The equal-mass formulation above is exactly that covering problem: division by \(n\) preserves its inequalities, and interpolation makes the breakpoint and whole-curve conditions equivalent. Consequently, this target is already settled.

Result

The covering problem admits a fully polynomial approximation scheme for every fixed support size \(n\). This is the result stated in Proposition 3 of Perny, Weng, Goldsmith, and Hanna, [*Approximation of Lorenz-Optimal Solutions in Multiobjective Markov Decision Processes*](https://auai.org/uai2013/prints/papers/208.pdf).

Here is a direct proof that also verifies the required dependence on binary input length. Rationals are understood to be encoded in binary.

1. Feasible profiles have a rational linear representation

Write \(\alpha\) for the initial-state distribution and \(p(t\mid s,a)\) for the transition probabilities. For a stationary randomized policy \(\pi\), define its discounted occupancy numbers by

\[ x_{sa}^{\pi} = \mathbb E_{\alpha}^{\pi} \left[\sum_{t=0}^{\infty}\gamma^t \mathbf 1_{\{S_t=s,\ A_t=a\}}\right]. \]

These numbers satisfy

\[ x_{sa}\ge 0,\qquad \sum_{a\in A}x_{sa} -\gamma\sum_{t\in S}\sum_{a\in A}p(s\mid t,a)x_{ta} =\alpha_s \quad(s\in S). \]

Let \(X\) denote the polytope defined by these constraints. Summing the balance equations over states gives

\[ \sum_{s,a}x_{sa}=\frac{1}{1-\gamma}. \]

Thus \(X\) is bounded. It is nonempty because every stationary policy supplies a feasible occupancy vector. Each reward coordinate is linear:

\[ v_i(x)=\sum_{s,a}r_i(s,a)x_{sa}. \]

Conversely, every \(x\in X\) is realizable by a stationary randomized policy. Indeed, put \(d_s=\sum_a x_{sa}\) and define

\[ \pi_x(a\mid s)=\frac{x_{sa}}{d_s} \quad\text{when }d_s>0, \]

choosing any action distribution when \(d_s=0\). Then \(x_{sa}=d_s\pi_x(a\mid s)\), including at states with zero occupancy, and the balance equations become

\[ d=\alpha+\gamma P_{\pi_x}^{\mathsf T}d. \]

This equation has a unique solution: if two solutions differ by \(h\), then

\[ \|h\|_1 =\gamma\|P_{\pi_x}^{\mathsf T}h\|_1 \le\gamma\|h\|_1, \]

which implies \(h=0\), since \(\gamma<1\). The actual discounted state occupancies of \(\pi_x\) satisfy the same equation. Consequently, its state-action occupancies equal \(x\), and its reward profile equals \(v(x)\).

2. A polynomial grid and algorithm

Define

\[ r_{\min}=\min_{i,s,a}r_i(s,a),\qquad r_{\max}=\max_{i,s,a}r_i(s,a),\qquad b=\frac{r_{\min}}{1-\gamma},\qquad u=\frac{r_{\max}}{1-\gamma}. \]

Strict positivity and the occupancy sum imply

\[ 0<b\le v_i(x)\le u \quad\text{for every }x\in X\text{ and every }i. \]

Set \(\delta=\min\{\epsilon,1\}\) and \(\beta=1+\delta\). Let \(J\) be the smallest positive integer satisfying \(b\beta^J>u\), and define the rational grid

\[ G=\{b\beta^j:0\le j<J\}. \]

For each tuple \(g=(g_1,\ldots,g_n)\in G^n\), solve the rational linear feasibility problem

\[ x\in X,\qquad v_i(x)\ge g_i \quad(i=1,\ldots,n). \]

Whenever it is feasible, obtain a rational feasible point \(x^g\), recover \(\pi_{x^g}\) as above, and include that policy in \(Y\).

To verify complexity, observe that

\[ \frac{u}{b}=\frac{r_{\max}}{r_{\min}}. \]

Because all rewards have binary encoding length at most \(L\), we have \(r_{\min}\ge 2^{-L}\) and \(r_{\max}\le 2^L\). Hence \(\log(u/b)=O(L)\). Also, for \(0<\delta\le1\),

\[ \log(1+\delta)\ge\frac{\delta}{2}. \]

The minimality of \(J\) therefore gives

\[ J\le 1+\frac{\log(u/b)}{\log\beta} =O\!\left(1+L\left(1+\frac1\epsilon\right)\right). \]

There are \(J^n\) linear programs, a polynomial number for fixed \(n\). Each has \(m|A|\) variables and \(m+n\) equality or inequality constraints, apart from nonnegativity. Each grid number has encoding length \(O(L+JL)\), because it is a product of rational numbers with polynomially bounded exponents.

The standard polynomial-time theorem for rational linear programming supplies feasibility decisions and, for feasible instances, rational witnesses of polynomial encoding length. Its hypotheses hold here: all coefficients are rational and the explicitly represented programs have polynomial size. Recovering policies requires only rational sums and divisions. Thus both runtime and total output length are polynomial in \(m,|A|,L,1/\epsilon\), for fixed \(n\).

3. The algorithm covers every feasible profile

Fix any attainable profile \(v\). For each coordinate \(i\), choose the largest grid number \(g_i\le v_i\). Such a number exists because \(v_i\ge b\). Since the next grid level is larger than \(v_i\), including when that level is \(b\beta^J>u\), we have

\[ g_i\le v_i<\beta g_i. \]

The linear program indexed by \(g\) is feasible, witnessed by an occupancy vector attaining \(v\). Its returned policy has a profile \(v'\) satisfying \(v_i'\ge g_i\). Therefore,

\[ (1+\epsilon)v_i' \ge\beta v_i' \ge\beta g_i >v_i \quad(i=1,\ldots,n). \]

This establishes componentwise multiplicative covering of all attainable profiles.

For a vector \(z\in\mathbb R^n\), define its \(k\)-th cumulative sorted reward by

\[ C_k(z)=\sum_{j=1}^k z_{(j)} =\min_{\substack{I\subseteq\{1,\ldots,n\}\\|I|=k}} \sum_{i\in I}z_i. \]

The equality holds because a minimum-sum subset consists of the \(k\) smallest coordinates. For every subset \(I\) of size \(k\), componentwise covering gives

\[ (1+\epsilon)\sum_{i\in I}v_i' \ge\sum_{i\in I}v_i \ge C_k(v). \]

Taking the minimum over \(I\) yields

\[ (1+\epsilon)C_k(v')\ge C_k(v) \quad(k=1,\ldots,n). \]

4. Equal masses and whole-curve covering

By the problem’s equal-mass definition,

\[ \mathcal L_\pi(k/n)=\frac{C_k(v^\pi)}{n}. \]

Division by the positive constant \(n\) preserves the preceding inequalities. Hence the returned policy satisfies the required covering inequality at every breakpoint.

On each interval between successive breakpoints, the function

\[ q\longmapsto (1+\epsilon)\mathcal L_{\pi'}(q)-\mathcal L_\pi(q) \]

is affine. Its endpoint values are nonnegative, so every value on that interval is nonnegative. This proves covering on the whole interval \(q\in[0,1]\).

The same interpolation argument shows that breakpoint dominance and whole-curve dominance agree, including strict improvement somewhere. Thus the formulation uses exactly the cumulative-reward Lorenz order. The constructed set covers every feasible profile, and therefore every Lorenz-optimal profile, with the requested polynomial bounds.
