The continuous mirror question, as graded

Given an issue set ℐ, a DNNF integrity constraint Γ, a finite support Τ of complete ballots satisfying Γ with positive binary-rational masses μ_t summing to \(1\), and a partial ballot \(s\), is there a ballot \(y \models Γ\) agreeing with \(s\) that minimizes \(\max_{t \in Τ} d_{\mathrm H}(y,t)\) over all ballots satisfying Γ?

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal I\) be a set of \(m\) Boolean issues, and let \(\Gamma\) be an explicitly given DNNF circuit with variables contained in \(\mathcal I\). A feasible complete ballot is \(y\in\{0,1\}^{\mathcal I}\) satisfying \(\Gamma\).
A society is given by its support: a nonempty list \(T\) of \(\tau\) distinct feasible complete ballots, each with a positive binary-rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a partial ballot \(s\in\{0,1,\star\}^{\mathcal I}\); agreement means matching every coordinate where \(s\neq\star\). Define \(R(y)=\max_{t\in T}d_{\mathrm H}(y,t)\), using Hamming distance.
Decide whether some feasible ballot agreeing with \(s\) attains \(\min_{z\models\Gamma}R(z)\). All tied minimizers are eligible; the minimum is over all feasible complete ballots, without imposing \(s\).
Measure running times in \(m\), \(\tau\), the encoded circuit size \(|\Gamma|\), and the total input bit length \(L\).

Is this decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite nonempty profiles of feasible Boolean ballots, deciding whether a Max-Hamming minimizer agrees with a partial ballot is \(\Theta_2^{\mathrm P}\)-complete for DNNF integrity constraints.
The discrete problem is already \(\Theta_2^{\mathrm P}\)-hard when \(\Gamma=\top\).

Modeling choices made when packaging the task

  • Specified that the integrity circuit uses only issue variables, so satisfaction is evaluated directly on complete ballots.
  • Specified the partial-ballot domain and agreement convention from the discrete definition.
  • Made explicit that every tied global minimizer is eligible and that the partial ballot does not restrict the minimization domain.
  • Defined L as the total input bit length and included the encoded DNNF circuit size in running-time accounting.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is \(\Theta_2^{\mathrm P}\)-complete, and therefore \(\mathrm{NP}\)-hard, even when \(\Gamma=\top\). This follows from the discrete-profile hardness supplied in the question, together with a polynomial-size conversion to distinct support ballots with positive dyadic masses.

1. Multiplicity and masses do not affect the objective.

Let \(P=(b_1,\ldots,b_n)\) be a nonempty discrete profile, and let \(T\) be its set of distinct ballots. For every complete ballot \(y\),

\[ \max_{1\leq i\leq n}d_{\mathrm H}(y,b_i) = \max_{t\in T}d_{\mathrm H}(y,t). \]

Indeed, each ballot in either maximum occurs in the other; repetitions do not change a maximum. Consequently, replacing \(P\) by \(T\) preserves the objective at every feasible ballot, its optimum value, and its entire set of minimizers.

The masses \(\mu_t\) do not occur in the definition of \(R\). Thus any positive masses summing to \(1\) give the same decision answer.

2. Polynomial reduction establishing hardness.

Use the stated \(\Theta_2^{\mathrm P}\)-hardness for discrete profiles with \(\Gamma=\top\) as the source problem. Given an explicitly listed source profile \(P\), retain the issue set and partial ballot \(s\), and remove duplicate ballots to obtain \(T=\{t_1,\ldots,t_\tau\}\).

To ensure valid masses even if “binary-rational” requires dyadic rationals, set \(k=\lceil\log_2\tau\rceil\) and define

\[ \mu_{t_j}=2^{-k}\quad(1\leq j<\tau), \qquad \mu_{t_\tau}=\frac{2^k-\tau+1}{2^k}. \]

Since \(2^k\geq\tau\), all these masses are positive. Their sum is

\[ (\tau-1)2^{-k}+(2^k-\tau+1)2^{-k}=1. \]

For \(\tau=1\), the construction gives \(k=0\) and the unique mass \(1\). Each mass requires \(O(\log(\tau+1))\) bits, so their total encoding length is \(O(\tau\log(\tau+1))\).

Deduplication takes polynomial time in the explicitly listed source input, and \(\tau\leq n\). Hence the output length and construction time are polynomial in the source input length. The circuit \(\top\) is a constant-size DNNF, and every output support ballot is feasible.

By Section 1, the source and target objectives coincide on every complete ballot. Since \(s\) is unchanged, a source minimizer agrees with \(s\) exactly when a target minimizer does. This is a polynomial-time many-one reduction, proving \(\Theta_2^{\mathrm P}\)-hardness, already for \(\Gamma=\top\).

3. Membership in \(\Theta_2^{\mathrm P}\).

For an integer \(r\in\{0,\ldots,m\}\), consider the predicate

\[ Q(r)\iff \exists y\in\{0,1\}^{\mathcal I}: y\models\Gamma \ \text{and}\ d_{\mathrm H}(y,t)\leq r\text{ for every }t\in T. \]

This predicate belongs to \(\mathrm{NP}\): a certificate is the \(m\)-bit ballot \(y\). Circuit evaluation takes \(O(|\Gamma|)\) time, and all distances can be checked in \(O(m\tau)\) time.

The feasible set is nonempty because \(T\) is nonempty and consists of feasible ballots. Therefore the global optimum \(r^*=\min_{y\models\Gamma}R(y)\) exists and belongs to \(\{0,\ldots,m\}\). Moreover, \(Q(r)\) holds exactly when \(r\geq r^*\). Binary search determines \(r^*\) using \(O(\log(m+2))\) queries to an \(\mathrm{NP}\) oracle.

Finally, make one additional \(\mathrm{NP}\) query asking whether there exists a feasible ballot \(y\) agreeing with \(s\) and satisfying \(R(y)\leq r^*\). Every feasible ballot has radius at least \(r^*\), so this query accepts exactly when an eligible tied minimizer agrees with \(s\).

All query encodings and deterministic work are polynomial in \(L\). Because the partial ballot explicitly lists its \(m\) coordinates, the query count is \(O(\log(L+2))\). Thus the problem belongs to \(\mathrm P^{\mathrm{NP}[O(\log L)]}=\Theta_2^{\mathrm P}\).

Combining membership and hardness proves the claimed completeness. In particular, a polynomial-time algorithm in the stated input parameters would imply \(\mathrm P=\mathrm{NP}\).
