The continuous mirror question, as graded

Given a finite state space \(\Omega\), target events \(\mathcal E\), a finite family \(\mathcal A\) of event securities with payoffs \(x_A(\omega)=\mathbf 1[\omega\in A]\), and a rational society \(\mu\) over signal types \(t\), each described by a partition \(\Pi_t\) of \(\Omega\), find a minimum-cardinality subset \(S\subseteq\mathcal A\) whose payoff vector \(X_S=(x_A)_{A\in S}\) is informative. Here \(\Pi_\mu=\bigvee_{t:\mu_t>0}\Pi_t\); distinguishability requires that for every cell \(B\in\Pi_\mu\) and distributions \(P,P'\) supported on \(B\), \(\mathbb E_P[X_S]=\mathbb E_{P'}[X_S]\) imply \(P(E)=P'(E)\) for all \(E\in\mathcal E\). Separability uses the paper's criterion over every type with positive mass: there must be no distribution \(P\) and vector \(v\) for which all those types have conditional payoff expectation \(v\) at every \(P\)-possible state while the pooled conditional expectation differs from \(v\) at some such state.

Input consists of a nonempty finite state space \(\Omega\), explicitly listed event families \(\mathcal E,\mathcal A\subseteq 2^\Omega\), with \(m=|\mathcal A|\geq 1\), and securities \(x_A(\omega)=\mathbf 1[\omega\in A]\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; masses sum to \(1\). Each type \(t\) specifies a partition \(\Pi_t\) of \(\Omega\). Here \(\tau\) is the support size, not the number of possible types. Let \(\Pi_\mu\) be their coarsest common refinement, and let \(\Pi_t(\omega)\) and \(\Pi_\mu(\omega)\) denote the cells containing \(\omega\).
For \(S\subseteq\mathcal A\), write \(X_S=(x_A)_{A\in S}\). It distinguishes \(\mathcal E\) if, for any probability distributions \(P,P'\) each supported within a cell of \(\Pi_\mu\), possibly different cells, \(\mathbb E_P[X_S]=\mathbb E_{P'}[X_S]\) implies \(P(E)=P'(E)\) for every \(E\in\mathcal E\).
It is separable if there are no probability distribution \(P\) on \(\Omega\) and vector \(v\in\mathbb R^{|S|}\) such that \(\mathbb E_P[X_S\mid\Pi_t(\omega)]=v\) for every supported type \(t\) and every state with \(P(\omega)>0\), while \(\mathbb E_P[X_S\mid\Pi_\mu(\omega)]\neq v\) at some such state. Distributions in both definitions may have arbitrary real probabilities, including zeros.

Result

The decision problem is \(\mathrm{NP}\)-hard, even when \(\tau=1\), the sole type has mass \(1\) and is fully informed, and \(|\mathcal E|=1\). The reduction always satisfies the promise that an informative subset exists.

The cited paper establishes the corresponding finite-trader hardness. The proof below verifies the reduction directly for the mass-society definitions. [Designing Informative Securities, Theorem 7](https://arxiv.org/pdf/1210.4837)

Source problem and construction

Use the standard \(\mathrm{NP}\)-complete Set Cover decision problem. Its input is a finite universe \(U\), a family \(\mathcal C\subseteq 2^U\), and a budget \(h\); the question is whether at most \(h\) members of \(\mathcal C\) cover \(U\).

We may restrict to instances with \(U\neq\varnothing\), \(r=|\mathcal C|\geq1\), \(\bigcup_{C\in\mathcal C}C=U\), and \(0\leq h\leq r\). Indeed, an instance whose family does not cover its universe is immediately negative and can be replaced by the fixed instance \(U=\{u\}\), \(\mathcal C=\{\{u\}\}\), \(h=0\), which satisfies these restrictions and is negative. Empty-universe instances are immediately positive. Budgets exceeding the family size can be capped at that size, and duplicate sets can be removed without changing the minimum cover cardinality.

Given such an instance, introduce a new state \(b\notin U\) and construct:

  • \(\Omega=U\cup\{b\}\);
  • \(\mathcal E=\{U\}\);
  • \(\mathcal A=\mathcal C\), regarding each member as an event in \(\Omega\);
  • one supported type, of mass \(1\), with partition \(\Pi_1=\{\{\omega\}:\omega\in\Omega\}\);
  • budget \(k=h\).

Thus \(\Pi_\mu=\Pi_1\) is the singleton partition, \(m=r\), \(\tau=1\), and \(|\mathcal E|=1\).

Separability is automatic

Fix any \(S\subseteq\mathcal A\). Suppose a distribution \(P\) and vector \(v\) satisfy the consensus condition in the definition of nonseparability.

For every state \(\omega\) with \(P(\omega)>0\), conditioning on its singleton cell gives
\(\mathbb E_P[X_S\mid\Pi_1(\omega)]=X_S(\omega)=v\).

Because \(\Pi_\mu(\omega)=\Pi_1(\omega)\), we also have
\(\mathbb E_P[X_S\mid\Pi_\mu(\omega)]=v\)
at every such state. Consequently, the required disagreement with the pooled conditional expectation cannot occur. Every \(S\) is separable, including the empty selection.

Distinction is equivalent to covering

A probability distribution supported within a singleton cell must be the point mass \(\delta_\omega\). Therefore, the distinguishing condition becomes:

Whenever \(X_S(\omega)=X_S(\omega')\), the two states must have the same membership in \(U\).

Every available security pays \(0\) at \(b\). For \(u\in U\), its payoff vector equals the zero vector exactly when no selected event contains \(u\).

Necessity. Suppose \(S\) fails to cover \(U\). Choose an uncovered state \(u\). Then
\(\mathbb E_{\delta_u}[X_S]=X_S(u)=0=X_S(b)=\mathbb E_{\delta_b}[X_S]\),
but \(\delta_u(U)=1\) and \(\delta_b(U)=0\). Both point masses are admissible distributions. Hence \(S\) does not distinguish \(\mathcal E\).

Sufficiency. Suppose \(S\) covers \(U\). For every \(u\in U\), some selected security pays \(1\) at \(u\), so \(X_S(u)\neq X_S(b)\). Two states with equal payoff vectors therefore either both belong to \(U\), or both equal \(b\). Their point masses assign the same probability to \(U\). These are all admissible distributions, so \(S\) distinguishes \(\mathcal E\).

Together with automatic separability, this proves
\(S\text{ is informative}\ \Longleftrightarrow\ \bigcup_{A\in S}A=U\).

Promise, complexity, and conclusion

Since the source family covers \(U\), the full selection \(\mathcal A\) is informative. Thus every constructed instance satisfies the promise, including negative instances for the specified budget.

The equivalence above preserves cardinality, yielding
\(\exists S\subseteq\mathcal A:\ |S|\leq k,\ S\text{ informative}\ \Longleftrightarrow\ \exists\mathcal D\subseteq\mathcal C:\ |\mathcal D|\leq h,\ \bigcup_{C\in\mathcal D}C=U\).

Write \(n=|U|\) and let \(\ell\) be the source input length. With indexed states and explicit set lists, construction time and output length are bounded by
\(O\bigl(\ell+(m+1)(n+1)\log(n+m+2)\bigr)\).
In the output, \(|\Omega|=n+1\), \(\tau=1\), \(|\mathcal E|=1\), and \(k=h\). This is a polynomial-time, promise-preserving reduction.

For completeness, on these constructed instances a proposed selection is checked by testing coverage in time \(O(L+|\Omega|k)\). Enumerating all selections of size at most \(k\) gives a restricted-instance decision algorithm taking
\(O\bigl(L+|\Omega|(k+1)\sum_{j=0}^{k}\binom{m}{j}\bigr)\).

The general promised problem is therefore \(\mathrm{NP}\)-hard. In particular, it cannot have a polynomial-time algorithm unless \(\mathrm P=\mathrm{NP}\).
