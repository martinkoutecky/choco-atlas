The continuous mirror question, as graded

1. Answer and reformulation

Yes. In fact, a deterministic polynomial-time algorithm can construct a distribution with polynomial support satisfying the requested guarantee. Randomness is needed only to sample from that distribution.

This conclusion agrees with Theorem 3.1 of Becker, Kodric, and Vinci, [*Greedily Maximizing Ex-Ante Fairness*](https://ojs.aaai.org/index.php/AAAI/article/view/38428/42390). Below is a self-contained proof for the objective in the question.

Write \(\alpha=1-1/e\). For each supported type \(t\), define

\(h_t(S)=f_t(S)+\lambda\sum_{s\in T}\mu_s f_s(S).\)

These functions are nonnegative, monotone, and submodular: each is a nonnegative linear combination of functions with those properties. Moreover,

\(V(P)=\min_{t\in T}\mathbb E_{S\sim P}[h_t(S)].\)

Thus the task is to maximize the minimum expected payoff among the \(\tau\) functions \(h_t\).

Because \(\mathcal S\) is finite and \(V\) is continuous on its probability simplex, an optimal distribution \(P^\star\) exists. Choose, for each \(t\), a feasible witness \(A_t\) with \(f_t(A_t)\ge1\). The uniform mixture of these witnesses gives every type expected benefit at least \(1/\tau\). Consequently,

\(\mathrm{OPT}\ge1/\tau.\)

The algorithm will not need to find these witnesses.

2. A computable polynomial payoff bound

We first compute an integer upper bound without assuming that \(B\) is explicitly supplied. Query all singleton values and set

\(C=\left\lceil\max_{t\in T}\sum_{u\in U}f_t(\{u\})\right\rceil,\qquad M=2C.\)

For any nonempty set \(S\), telescoping its elements and applying diminishing returns gives

\(f_t(S)\le f_t(\varnothing)+\sum_{u\in S}\bigl(f_t(\{u\})-f_t(\varnothing)\bigr)\le\sum_{u\in S}f_t(\{u\}).\)

For the empty set, monotonicity and \(m\ge1\) give \(f_t(\varnothing)\le f_t(\{u\})\) for any \(u\in U\). Therefore \(f_t(S)\le C\) for every \(S\subseteq U\).

The witness assumption implies \(C\ge1\). Since singletons are feasible, the given bound implies \(C\le mB+1\). Finally,

\(0\le h_t(S)\le(1+\lambda)C\le M.\)

Hence \(M\) is computable and polynomially bounded in \(m,\tau\).

3. Greedy supplies an approximate best response

For any probability vector \(q=(q_t)_{t\in T}\), consider

\(F_q(S)=\sum_{t\in T}q_t h_t(S)=\sum_{t\in T}(q_t+\lambda\mu_t)f_t(S).\)

This is a nonnegative monotone submodular function. Its values and marginal gains can be computed using the given value oracles.

Starting at \(\varnothing\), perform \(k\) greedy steps, each adding an unused element of maximum marginal gain. Let \(A_j\) denote the set after \(j\) steps, and let \(O\) maximize \(F_q\) over \(\mathcal S\).

Monotonicity and diminishing returns imply

\(F_q(O)-F_q(A_j)\le F_q(A_j\cup O)-F_q(A_j)\le\sum_{u\in O\setminus A_j}\bigl(F_q(A_j\cup\{u\})-F_q(A_j)\bigr).\)

There are at most \(k\) summands. Thus, for \(j<k\), greedy obtains

\(F_q(A_{j+1})-F_q(A_j)\ge\bigl(F_q(O)-F_q(A_j)\bigr)/k.\)

Iterating this recurrence and using \(F_q(\varnothing)\ge0\) yields

\(F_q(A_k)\ge\bigl(1-(1-1/k)^k\bigr)F_q(O)\ge\alpha F_q(O).\)

The last inequality is immediate for \(k=1\); for \(k>1\), it follows from \(\log(1-1/k)\le-1/k\).

Furthermore,

\(\max_{S\in\mathcal S}F_q(S)\ge\mathbb E_{S\sim P^\star}[F_q(S)]=\sum_tq_t\mathbb E_{P^\star}[h_t(S)]\ge\mathrm{OPT}.\)

Therefore the greedy set \(S_q\) satisfies

\(\sum_tq_t h_t(S_q)\ge\alpha\,\mathrm{OPT}.\)

This comparison is with the optimal unrestricted distribution, not merely the optimal deterministic set.

4. Construction of the output distribution

Set

\(\eta=\varepsilon/(2M\tau),\)

and let \(N\) be the smallest power of two satisfying

\(N\ge4M^2\tau^3/\varepsilon^2.\)

Initialize \(w_{1,t}=1\) for every type. For rounds \(r=1,\ldots,N\):

  • Define \(q_{r,t}=w_{r,t}/\sum_s w_{r,s}\).
  • Use the greedy procedure above to obtain \(S_r\in\mathcal S\) for \(F_{q_r}\).
  • Compute \(\ell_{r,t}=h_t(S_r)/M\), and update

\(w_{r+1,t}=w_{r,t}(1-\eta\ell_{r,t})\).

All losses satisfy \(0\le\ell_{r,t}\le1\). Also \(0<\eta<1/2\), so every weight remains positive.

Output the distribution \(P\) that chooses a uniformly random round \(r\in\{1,\ldots,N\}\) and returns \(S_r\).

5. Complete approximation analysis

Let \(W_r=\sum_t w_{r,t}\). The update gives

\(W_{r+1}=W_r\left(1-\eta\sum_tq_{r,t}\ell_{r,t}\right).\)

Using \(\log(1-z)\le-z\), and \(W_1=\tau\), we obtain

\(\log W_{N+1}\le\log\tau-\eta\sum_{r=1}^N\sum_tq_{r,t}\ell_{r,t}.\)

For \(0\le z\le1/2\), the complementary inequality is

\(\log(1-z)\ge-z-z^2.\)

Indeed, the function \(\log(1-z)+z+z^2\) vanishes at zero and has derivative \(z(1-2z)/(1-z)\ge0\) on this interval.

Applying this inequality to the update of any fixed type \(t\), and using \(\ell_{r,t}^2\le1\), gives

\(\log w_{N+1,t}\ge-\eta\sum_{r=1}^N\ell_{r,t}-\eta^2N.\)

Since \(w_{N+1,t}\le W_{N+1}\), combining the two bounds and rearranging yields

\(\frac1N\sum_{r=1}^N\ell_{r,t}\ge\frac1N\sum_{r=1}^N\sum_sq_{r,s}\ell_{r,s}-\eta-\frac{\log\tau}{\eta N}.\)

Multiplying by \(M\) and taking the minimum over \(t\), we conclude

\(V(P)\ge\frac1N\sum_{r=1}^N\sum_tq_{r,t}h_t(S_r)-M\eta-\frac{M\log\tau}{\eta N}.\)

Section 3 bounds every round’s weighted payoff below by \(\alpha\,\mathrm{OPT}\). Moreover,

\(M\eta=\varepsilon/(2\tau),\)

and the choice of \(N\), together with \(\log\tau\le\tau\), implies

\(\frac{M\log\tau}{\eta N}=\frac{2M^2\tau\log\tau}{\varepsilon N}\le\frac{\varepsilon\log\tau}{2\tau^2}\le\frac{\varepsilon}{2\tau}.\)

Therefore

\(V(P)\ge\alpha\,\mathrm{OPT}-\varepsilon/\tau.\)

Finally, \(\mathrm{OPT}\ge1/\tau\), so

\(V(P)\ge(\alpha-\varepsilon)\mathrm{OPT}=(1-1/e-\varepsilon)\mathrm{OPT}.\)

Every step is deterministic, so the construction succeeds with probability \(1\), exceeding the required \(2/3\).

6. Running time, bit complexity, and sampling

The initial bound requires \(m\tau\) oracle queries. Each greedy call uses at most \(O(km\tau)\) queries, and evaluating its final payoffs requires at most another \(\tau\). Thus the total query count is \(O(m\tau+Nkm\tau)\), which is polynomial in the required parameters because \(M\le2(mB+1)\).

Exact rational arithmetic also has polynomial bit complexity. Each payoff \(h_t(S_r)\) is a sum of \(\tau+1\) products of input or oracle rationals, so its bit length is polynomial in \(\tau,L\). Each weight is a product of at most \(N\) rational update factors of polynomial bit length; its numerator and denominator therefore have polynomial bit length. Normalizing the weights and evaluating greedy comparisons preserve polynomial bit length and require polynomial time.

The stored list \(S_1,\ldots,S_N\) has polynomial size. Because \(N\) is a power of two, sampling a uniform round uses exactly \(\log_2N\) independent fair bits. Returning its stored feasible set takes polynomial time.

In particular, the algorithm depends on the number \(\tau\) of supported types, with no dependence on reciprocals of their masses.
