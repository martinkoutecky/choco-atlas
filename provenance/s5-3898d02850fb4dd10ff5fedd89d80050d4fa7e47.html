The continuous mirror question, as graded

Given a project set \(M\), budget \(B\), and finite support \(T\) of monotone submodular valuation types, each depending nontrivially on at most a fixed constant \(d\) items, with rational masses \(\mu_t\ge 0\) summing to \(1\), can one compute in polynomial time a \((1-1/e+\epsilon)\)-approximation to \(\max_{S\subseteq M,\ |S|\le B}\sum_{t\in T}\mu_t v_t(S)\), for fixed \(\epsilon>0\)?

Packaged proof task (what the prover saw — nothing else)

Let \(M\) be a project set with \(|M|=m\), and let the cardinality budget satisfy \(B\in\{1,\ldots,m\}\).
A society is given by its support: a nonempty list \(T\) of \(\tau\) valuation types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies \(D_t\subseteq M\), with \(|D_t|\le d\), and an explicit table of nonnegative binary-rational values for a normalized monotone submodular function \(g_t:2^{D_t}\to\mathbb{Q}_{\ge0}\); define \(v_t(S)=g_t(S\cap D_t)\) and require \(g_t(\varnothing)=0\).
The objective is \(F(S)=\sum_{t\in T}\mu_t v_t(S)\), with a common project set \(S\subseteq M\) satisfying \(|S|\le B\). Let \(L\) be the total binary input length.
Fix \(0<\epsilon<1/e\). The locality bound \(d\) is a constant that may depend on \(\epsilon\).

Does this problem admit a \((1-1/e+\epsilon)\)-approximation in time polynomial in \(m,\tau,L\), or is achieving this ratio NP-hard for some such fixed \(d\)?

For discrete combinatorial public projects, achieving this ratio is NP-hard for constant-size valuations, even for binary unit-demand valuations ([source](https://arxiv.org/pdf/1202.2792)).

  • Specified an integer cardinality budget between one and the number of projects.
  • Restricted epsilon to the meaningful approximation range and allowed the fixed locality constant to depend on epsilon; the anchor does not establish hardness for every prescribed locality bound.

Conclusion

For every fixed \(0<\epsilon<1/e\), there exists a fixed locality bound \(d=d(\epsilon)\) for which achieving a \((1-1/e+\epsilon)\)-approximation is NP-hard. This holds even when every valuation table contains only \(0\) and \(1\), and every mass is a dyadic rational. Thus a polynomial-time algorithm with this guarantee would imply \(\mathrm{P}=\mathrm{NP}\).

The support size \(\tau\) remains part of the input; it is not fixed.

1. Known hardness theorem

We use the following precise consequence of Dobzinski and Vondrák’s Theorem 1.3, proved in Section B.2:

For every fixed \(\epsilon>0\), there is a constant \(d=d(\epsilon)\) such that it is NP-hard to approximate
\(H(S)=\sum_{i=1}^{n}\min\{1,|S\cap D_i|\}\)
within a factor \(1-1/e+\epsilon\), subject to \(S\subseteq M\) and \(|S|\le B\), even when every explicitly listed domain satisfies \(|D_i|\le d\). Their proof obtains these domains from a maximum-coverage instance in which each universe element belongs to only constantly many sets. [Theorem 1.3 and Section B.2](https://arxiv.org/pdf/1202.2792)

We now give a polynomial-time, approximation-preserving conversion from this hard problem to the specified support representation.

2. Constructing the support and masses

Take such a hard instance with \(n\ge1\) valuations. Keep its project set and budget.

Set \(N=2^{\lceil\log_2 n\rceil}\). Temporarily give each valuation mass \(1/N\). If \(N>n\), add one zero valuation, with domain \(\varnothing\), of mass \((N-n)/N\). The masses are positive and sum to \(1\).

For every domain \(D\), define its local table by

\(g_D(X)=\min\{1,|X|\}\qquad(X\subseteq D).\)

Finally, merge all entries with identical domains by adding their masses. Identical domains specify identical valuation functions, so this produces a list of distinct support types. Every retained mass has the form \(c/N\), where \(c\) is a positive integer. Consequently, all masses are positive dyadic rationals and still sum to \(1\).

The resulting support satisfies \(\tau\le n+1\), and every domain has size at most \(d\).

3. Verifying the valuation hypotheses

Each table is nonnegative and normalized because \(g_D(\varnothing)=0\). It is monotone: if \(X\subseteq Y\), then \(|X|\le|Y|\), hence \(g_D(X)\le g_D(Y)\).

To verify submodularity, take \(X,Y\subseteq D\). We must prove

\(g_D(X)+g_D(Y)\ge g_D(X\cup Y)+g_D(X\cap Y).\)

If either set is empty, this is an equality. If both are nonempty, the left side equals \(2\), while each term on the right is at most \(1\). Thus the inequality always holds.

The induced valuation is exactly

\(v_D(S)=g_D(S\cap D)=\min\{1,|S\cap D|\}.\)

For \(D=\varnothing\), this function is identically zero, as required for the optional additional type.

4. Objective and encoding preservation

Before merging identical types, the constructed objective is

\(F(S)=\frac{1}{N}\sum_{i=1}^{n}\min\{1,|S\cap D_i|\}=\frac{H(S)}{N}.\)

The additional zero valuation contributes nothing. Merging identical types preserves this equality for every \(S\).

Because the feasible sets are unchanged,

\(\operatorname{OPT}_F=\operatorname{OPT}_H/N.\)

Therefore, for any approximation factor \(r\), the guarantee \(F(S)\ge r\operatorname{OPT}_F\) implies \(H(S)\ge r\operatorname{OPT}_H\).

The conversion has polynomial size. Each explicit table has at most \(2^d\) entries, all binary values. Each domain lists at most \(d\) project indices, and each mass needs \(O(\log(n+1))\) bits. Since \(d\) is fixed, the entire construction, including grouping identical domains, takes polynomial time.

An algorithm polynomial in \(m,\tau,L\) with ratio \(1-1/e+\epsilon\) would consequently give a polynomial-time algorithm with the same ratio for the hard problem in Section 1. This establishes the claimed NP-hardness for the exact input model in the question.
