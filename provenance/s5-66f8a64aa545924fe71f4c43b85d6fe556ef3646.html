The continuous mirror question, as graded

Given a finite item set \(K\), known cohort support \(T\) of size \(\tau\) with rational masses \(\mu_t\) summing to one, per-capita supplies \(s_j\), and unknown free-disposal valuation oracles \(v_t\), assign mass \(x_{t,B}\) of each type to integral bundles \(B\), subject to \(\sum_B x_{t,B}=\mu_t\) and \(\sum_{t,B:\,j\in B}x_{t,B}\le s_j\), to maximize \(\sum_{t,B}x_{t,B}v_t(B)\). Does uniformly sampling from the \(Q=\tau(2^k-1)\) type–bundle value queries, skipping answered or inferable queries, until an optimum is certified use at most \(\frac{q_{\min}}{q_{\min}+1}(Q+1)\) queries in expectation, where \(q_{\min}\) is the fewest queries any valid adaptive policy needs to certify the optimum for the same hidden valuation profile?

Let \(K\) contain \(m\ge 1\) items. A society is given by its support: a list \(T\) of \(\tau\ge 1\) types with positive binary rational masses \(\mu_t\) summing to one; \(\tau\) counts listed types, not possible valuation functions. Supplies \(s_j\) are finite nonnegative binary rationals. Let \(L\) be the public input bit length; express any running-time bounds in \(m,\tau,L\) and any additional parameters.
Each type has an unknown valuation \(v_t:2^K\to\mathbb R_{\ge 0}\), with finite values, known \(v_t(\varnothing)=0\), and free disposal. No upper bound or further valuation structure is initially known.
An allocation has real masses \(x_{t,B}\ge 0\), satisfies \(\sum_{B\subseteq K}x_{t,B}=\mu_t\) and \(\sum_{t\in T}\sum_{B\subseteq K:j\in B}x_{t,B}\le s_j\), and maximizes \(\sum_{t\in T}\sum_{B\subseteq K}x_{t,B}v_t(B)\). Any welfare tie is acceptable.
A value query reveals exactly \(v_t(B)\) for one nonempty bundle. A transcript certifies an allocation if that same allocation is optimal for every admissible valuation profile consistent with its answers; knowing its numerical welfare is unnecessary. A value is inferable if all such profiles agree on it.
A valid adaptive policy terminates with a certified allocation on every admissible profile. For a fixed hidden profile, let \(q_{\min}\) be the minimum number of queries made on that profile by any valid deterministic adaptive policy. Only queries are charged; intervening computation is unrestricted.
The random policy stops as soon as an allocation is certified; otherwise it selects uniformly among unanswered, noninferable type–bundle queries. Let \(N\) be its number of queries and \(Q=\tau(2^m-1)\).

Does \(\mathbb E[N]\le \frac{q_{\min}}{q_{\min}+1}(Q+1)\) hold for every admissible instance and fixed hidden valuation profile, or is there a counterexample?

For finite bidders receiving disjoint integral bundles, the analogous expected query bound is established. The later formulation identifies \(q_{\min}\) with the shortest certificate size. [Hudson and Sandholm](https://home.ttic.edu/~bhudson/papers/hudson04-effectiveness.pdf)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The inequality holds for every admissible instance and every fixed hidden valuation profile. A random-permutation argument proves it without requiring integral allocations. The related integral-allocation bound is stated in Proposition 1 of [Hudson and Sandholm](https://home.ttic.edu/~bhudson/papers/hudson04-effectiveness.pdf).

1. Persistence of inference and certification. Fix the public instance and a hidden valuation profile. Let \(\mathcal U\) be the set of all type–nonempty-bundle queries, so \(|\mathcal U|=Q=\tau(2^m-1)\).

For any transcript \(H\) obtained on this profile, let \(\mathcal V(H)\) be the set of admissible profiles consistent with its answers. This set is nonempty because it contains the hidden profile. Adding truthful answers can only shrink \(\mathcal V(H)\). Consequently:

  • If a query value is inferable from \(H\), it remains inferable after additional queries.
  • If an allocation is certified by \(H\), it remains certified after additional queries.

Both conclusions follow directly from the universal quantifiers in the definitions of inference and certification.

A valid deterministic policy exists: query every member of \(\mathcal U\), then choose a welfare-maximizing allocation. Indeed, the feasible allocation set is nonempty, since allocating everyone the empty bundle is feasible. It is closed and bounded in a finite-dimensional space, because each coordinate satisfies \(0\le x_{t,B}\le\mu_t\). Thus it is compact. For a fully known profile, welfare is a continuous linear function with finite coefficients, so it attains its maximum.

It follows that \(q_{\min}\) exists and satisfies \(0\le q_{\min}\le Q\).

2. A fixed certificate with at most \(q_{\min}\) queries. Choose a valid deterministic policy that makes exactly \(q_{\min}\) queries on the hidden profile. Its terminal transcript certifies some allocation \(x^\ast\).

Let \(C\subseteq\mathcal U\) consist of the distinct queries in that transcript, and write \(r=|C|\). Then \(r\le q_{\min}\). Knowing the hidden profile’s answers to every query in \(C\) certifies \(x^\ast\): removing repetitions does not change the set of consistent profiles.

If \(r=0\), the allocation \(x^\ast\) is certified before any queries. The random policy therefore has \(N=0\), and the desired inequality follows. Henceforth suppose \(r\ge1\).

3. Coupling the random policy to a random permutation. Choose a uniformly random permutation \(\pi\) of \(\mathcal U\). Scan its entries in order. Stop whenever an allocation is certified; otherwise, skip an entry if its value is inferable from the current transcript, and query it if its value is not inferable.

This procedure has exactly the query-sequence distribution of the random policy in the question.

To verify this, condition on the entire scanned prefix immediately after any actual query, or on the empty prefix initially. The remaining suffix is uniformly ordered: the decisions made so far depend only on the scanned prefix and its answers, and impose no further condition on the suffix’s ordering.

Let \(A\) be the set of unanswered, noninferable queries at this point. Every previously scanned query was either answered or inferable when skipped. Persistence of inference therefore implies that every member of \(A\) lies in the remaining suffix.

If no allocation is certified, then \(A\) is nonempty. Otherwise every valuation coordinate would already be determined, and an optimal allocation for that uniquely determined profile would be certified.

Until the next actual query, skipped entries add no information, so \(A\) stays unchanged. The next actual query is consequently the first member of \(A\) in the uniformly ordered suffix. Each member of \(A\) has probability \(1/|A|\) of being first. This is precisely the required uniform selection rule. Both procedures also use the same certification stopping rule.

4. A pathwise bound and its expectation. Let \(M\) be the largest position occupied by a member of \(C\) in \(\pi\).

If the scanning procedure has not already stopped, then after scanning the first \(M\) entries it knows every answer in \(C\). Specifically, each such query was either answered directly or skipped because its answer was inferable. In the latter case, its inferred answer equals the hidden profile’s answer, since that profile is consistent with the transcript.

Thus every profile consistent with the current transcript satisfies all the answers in \(C\). The certificate from Step 2 therefore certifies \(x^\ast\), and the procedure must stop by this point. Since each scanned entry contributes at most one actual query, the coupling gives the pointwise inequality \(N\le M\).

The positions occupied by \(C\) form a uniformly random \(r\)-element subset of \(\{1,\ldots,Q\}\). Hence, for \(0\le k\le Q\), with \(\binom{k}{r}=0\) when \(k<r\),

\(\displaystyle \Pr(M\le k)=\frac{\binom{k}{r}}{\binom{Q}{r}}.\)

Using the tail-sum formula and the identity \(\sum_{k=0}^{Q-1}\binom{k}{r}=\binom{Q}{r+1}\), we obtain

\(\displaystyle \mathbb E[M]=\sum_{k=0}^{Q-1}\Pr(M>k)=Q-\frac{\binom{Q}{r+1}}{\binom{Q}{r}}=Q-\frac{Q-r}{r+1}=\frac{r}{r+1}(Q+1).\)

The binomial identity follows by counting the \((r+1)\)-element subsets of \(\{1,\ldots,Q\}\) according to their largest element.

Finally, \(r\le q_{\min}\), and \(a/(a+1)\) is increasing for nonnegative \(a\). Therefore

\(\displaystyle \mathbb E[N]\le\mathbb E[M]=\frac{r}{r+1}(Q+1)\le\frac{q_{\min}}{q_{\min}+1}(Q+1).\)

This proves the stated bound, including the case \(q_{\min}=0\). No computational running-time bound is asserted; the proof uses the stipulated unrestricted intervening computation.
