The continuous mirror question, as graded

Given a finite premise agenda \(\Phi\), an initial distribution \(\mu\) over complete, consistent judgment types, reserve masses \(\rho_t\) by type, a rational mass budget \(\kappa\), and a consistent, complement-free target \(J\), is there a recruitment vector \(z\) with \(0\le z_t\le\rho_t\) and \(\sum_t z_t\le\kappa\) such that every formula in \(J\) is accepted by the continuous \(\mathrm{UPQR}_{1/2}\) outcome on \(\mu^z_t=(\mu_t+z_t)/(1+\sum_t z_t)\)? A literal assigned to \(\Phi_1\) is accepted when its mass share is greater than \(1/2\); a literal assigned to \(\Phi_2\) is accepted when its share is at least \(1/2\).

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge 1\) and let the premise-only agenda be \(\Phi=\{p_i,\neg p_i:1\le i\le m\}\). An input partition \(\Phi=\Phi_1\uplus\Phi_2\) places exactly one literal of each complementary pair in each part. Judgment types are complete, consistent subsets of \(\Phi\).
A society is given by its support: the list of types with positive mass, each mass a binary rational; support size counts listed types, not all possible types. The initial society has masses \(\mu_t\ge0\) with \(\sum_t\mu_t=1\); the reserve has masses \(\rho_t\ge0\) in the same units, without normalization. Let \(\tau\) be the size of their combined support, extending absent masses by zero.
The remaining inputs are a positive binary rational budget \(\kappa\) and a consistent, complement-free target \(J\subseteq\Phi\), possibly incomplete. Recruitment may split types: choose real masses \(0\le z_t\le\rho_t\) with \(\sum_t z_t\le\kappa\), yielding \(\mu^z_t=(\mu_t+z_t)/(1+\sum_t z_t)\).
The continuous \(\mathrm{UPQR}_{1/2}\) outcome accepts a literal \(\ell\in\Phi_1\) exactly when \(\sum_{t:\ell\in t}\mu^z_t>1/2\), and a literal \(\ell\in\Phi_2\) exactly when that share is \(\ge1/2\). Recruitment succeeds when every literal in \(J\) is accepted. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is deciding whether successful recruitment exists solvable in polynomial time, or is it NP-hard?

For finite profiles of indivisible judges, exact control by adding judges under \(\mathrm{UPQR}_{1/2}\) is NP-complete, even for premise-only literal agendas (Baumeister, Erdélyi, Erdélyi, and Rothe, 2012). The same result establishes NP-completeness for the variant requiring a strict improvement in Hamming distance.
These discrete results do not classify recruitment of divisible masses.

  • Made the partition determining strict versus weak thresholds part of the input, with opposite literals in opposite parts.
  • Normalized the initial mass to one, as required by the stated recruitment denominator; reserve masses use the same units and need not sum to one.
  • Defined the combined support size to include types appearing only in the reserve, with absent masses set to zero.
  • Required a positive rational budget, carrying over the discrete definition's positive budget condition.
  • Allowed arbitrary real recruitment masses, expressing divisibility without an integrality restriction.
  • Defined the target as a subset of the agenda and allowed it to be incomplete, as in exact control.

Classification

The problem is solvable in deterministic polynomial time, with running time \(\operatorname{poly}(m,\tau,L)\). Divisibility permits a linear programming formulation; a common margin variable handles the strict acceptance conditions exactly.

1. Linearizing the acceptance conditions

Index the combined support by \(t=1,\ldots,\tau\), extending absent masses by zero. For each target literal \(\ell\in J\), define
\[ a_{\ell t}= \begin{cases} 1,&\ell\in t,\\ -1,&\ell\notin t, \end{cases} \qquad d_\ell=\sum_{t=1}^{\tau}a_{\ell t}\mu_t. \]
Completeness and consistency of each judgment type ensure that it contains exactly one of \(\ell\) and its complement.

For any admissible recruitment vector \(z\), put \(s=\sum_t z_t\). Because \(\sum_t\mu_t=1\),
\[ 2\sum_{t:\ell\in t}\mu_t^z-1 = \frac{2\sum_{t:\ell\in t}(\mu_t+z_t)-(1+s)}{1+s} = \frac{d_\ell+\sum_t a_{\ell t}z_t}{1+s}. \]
The denominator is positive since \(s\ge 0\). Consequently, acceptance of \(\ell\) is equivalent to
\[ d_\ell+\sum_t a_{\ell t}z_t>0 \quad\text{if }\ell\in\Phi_1, \]
and to
\[ d_\ell+\sum_t a_{\ell t}z_t\ge 0 \quad\text{if }\ell\in\Phi_2. \]

Thus normalization introduces no nonlinear constraint.

2. Handling strict inequalities exactly

Write \(J_1=J\cap\Phi_1\) and \(J_2=J\cap\Phi_2\). Consider the following rational linear program, with variables \(z_1,\ldots,z_\tau,\delta\):
\[ \begin{array}{ll} \text{maximize}&\delta\\[2mm] \text{subject to} &0\le z_t\le\rho_t\qquad(1\le t\le\tau),\\ &\displaystyle\sum_{t=1}^{\tau}z_t\le\kappa,\\ &0\le\delta\le1,\\ &\displaystyle d_\ell+\sum_{t=1}^{\tau}a_{\ell t}z_t\ge\delta \qquad(\ell\in J_1),\\ &\displaystyle d_\ell+\sum_{t=1}^{\tau}a_{\ell t}z_t\ge0 \qquad(\ell\in J_2). \end{array} \]

Claim. Successful recruitment exists if and only if this linear program is feasible and its optimum \(\delta^\ast\) is positive.

Proof. Suppose \(z\) succeeds. If \(J_1\ne\varnothing\), every quantity
\[ d_\ell+\sum_t a_{\ell t}z_t,\qquad \ell\in J_1, \]
is positive. Since \(J_1\) is finite, their minimum \(\eta\) is positive. Taking \(\delta=\min\{1,\eta\}\) gives a feasible solution with positive objective value. If \(J_1=\varnothing\), take \(\delta=1\).

Conversely, any feasible solution with \(\delta>0\) satisfies every strict target inequality, because its left-hand side is at least \(\delta\), and satisfies every weak target inequality directly. Section 1 therefore shows that its recruitment vector succeeds.

Finally, the feasible region is closed and bounded: every \(z_t\) lies in the finite interval \([0,\rho_t]\), and \(\delta\in[0,1]\). If it is nonempty, it is compact, so the objective attains its maximum. This proves the claim. \(\square\)

The case \(J=\varnothing\) is included: \(z=0,\delta=1\) is feasible.

3. Bit complexity and algorithm

The linear program has \(\tau+1\) variables and
\[ 2\tau+|J|+3\le 2\tau+m+3 \]
inequalities.

Each \(a_{\ell t}\) belongs to \(\{-1,1\}\). Each \(d_\ell\) is a signed sum of input rationals. To bound its encoding length, use the product of their denominators as a common denominator. Its bit length is at most the sum of the input denominator bit lengths. Adding at most \(\tau\) numerators contributes at most an additional \(O(\log(\tau+1))\) bits. Hence every \(d_\ell\) has bit length \(O(L+\log(\tau+1))\), and the entire linear program has encoding length polynomial in \(m,\tau,L\). Constructing its target rows takes \(O(m\tau)\) rational arithmetic operations on numbers of polynomial bit length.

We apply the standard polynomial-time theorem for rational linear programming: feasibility and, for a feasible program with bounded objective, an exact rational optimum can be computed in time polynomial in the program’s encoding length. Its hypotheses hold here because all coefficients are rational and \(0\le\delta\le1\).

The algorithm therefore:

  • Constructs the linear program above.
  • Rejects if it is infeasible.
  • Otherwise accepts exactly when its exact optimum satisfies \(\delta^\ast>0\).

The total running time is \(\operatorname{poly}(m,\tau,L)\). In particular, the algorithm uses the listed support and never enumerates the \(2^m\) possible judgment types.

The discrete NP-completeness results do not obstruct this algorithm: indivisible recruitment requires integer choices, whereas the stated problem permits real recruitment masses and is exactly characterized by the rational linear program.
