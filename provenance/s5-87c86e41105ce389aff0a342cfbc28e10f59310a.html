The continuous mirror question, as graded

Given a finite ordered type set \(\Theta\), rational incumbent masses \(\mu_t\) summing to one, available recruit masses \(\rho_t\), self-qualification bits \(\sigma_t\), and relations \(q_{tu}\in\{0,1\}\) whose qualified types form an interval in the common order for each \(t\), let \(D\subseteq\operatorname{supp}(\mu)\) be distinguished types and \(\alpha\ge 0\) a rational budget. Is there a vector \(x\) with \(0\le x_t\le\rho_t\) and \(\sum_t x_t\le\alpha\) such that every type in \(D\) belongs to the LSR closure of the types with positive mass in the normalized society proportional to \(\mu+x\)? The closure starts at present types with \(\sigma_t=1\) and adds a present type \(u\) whenever a qualified type \(t\) has \(q_{tu}=1\).

Packaged proof task (what the prover saw — nothing else)

Input: a finite type set \(\Theta\) with a supplied linear order, nonnegative binary rational incumbent masses \(\mu_t\) with \(\sum_t\mu_t=1\), nonnegative binary rational recruit capacities \(\rho_t\), a nonempty set \(D\subseteq\operatorname{supp}(\mu)\), and a binary rational budget \(\alpha\geq0\).
Each input society is given by its support: the list of types with positive mass, each with its mass as a binary rational; support size counts listed types, not possible types. Put \(m=|\Theta|\), \(\tau=|\operatorname{supp}(\mu)\cup\operatorname{supp}(\rho)|\), and let \(L\) be the total input bit length; express running times in \(m,\tau,L\) and any additional parameters used.
A supplied matrix \(q\in\{0,1\}^{\Theta\times\Theta}\) specifies qualification: \(q_{tu}=1\) means type \(t\) qualifies type \(u\). For every \(t\), the set \(\{u:q_{tu}=1\}\) is an interval, possibly empty, in the supplied order; self-qualification bits satisfy \(\sigma_t=q_{tt}\).
Recruitment chooses arbitrary real masses \(x_t\) satisfying \(0\leq x_t\leq\rho_t\) and \(\sum_t x_t\leq\alpha\), with no minimum positive recruitment. The resulting distribution is \(p_t=(\mu_t+x_t)/(1+\sum_u x_u)\); write \(P_x=\{t:p_t>0\}\).
The liberal-start-respecting (LSR) closure starts with \(K_0=\{t\in P_x:\sigma_t=1\}\) and iterates \(K_{i+1}=K_i\cup\{u\in P_x:\exists t\in K_i,\ q_{tu}=1\}\) until unchanged. The decision problem asks whether some feasible \(x\) has \(D\subseteq K_\infty\).

Is this continuous LSR recruitment decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For discrete recruitment with a cardinality budget, the same interval restriction permits \(\mathrm{NP}\)-hardness and \(\mathrm{W}[2]\)-hardness parameterized by the number recruited; discrete LSR recruitment is also FPT parameterized by the number of distinguished individuals. [Yang and Dimitrov](https://journal.hep.com.cn/fcs/EN/10.1007/s11704-023-2700-1)
No result settling exactly the continuous decision problem above was located in the literature search.

Modeling choices made when packaging the task

  • Required the distinguished set to be nonempty, matching the discrete input domain.
  • Made recruit capacities nonnegative binary rationals without requiring their sum to be one; they are available amounts measured in incumbent-total-mass units.
  • Required self-qualification bits to equal the qualification matrix diagonal, matching the discrete LSR definition.
  • Allowed empty qualification intervals: the hardness construction explicitly includes individuals qualifying nobody, although the written interval definition uses nonempty endpoints; the published version retains this discrepancy.
  • Specified arbitrary real recruitment masses with no positive minimum, and stated the normalization explicitly.
  • Defined m as the ordered type-universe size, tau as the union of incumbent and recruit supports, and L as total input bit length; overlapping supports are permitted because distinct incumbents and recruits may share a type.

Result

The continuous LSR recruitment decision problem is in \(\mathrm{P}\). In fact, the algorithm works for arbitrary qualification matrices; the interval restriction is unnecessary.

The decisive property is that every positive budget permits activating all types with positive recruit capacity simultaneously.

1. The maximal feasible support

Write \(A=\operatorname{supp}(\mu)\), \(B=\operatorname{supp}(\rho)\), and define
\(S=A\) if \(\alpha=0\), and \(S=A\cup B\) if \(\alpha>0\).

We prove that every feasible recruitment has support contained in \(S\), and that some feasible recruitment has support exactly \(S\).

Because \(1+\sum_u x_u>0\), we have
\(p_t>0\iff \mu_t+x_t>0\).
Thus normalization does not affect support.

If \(\alpha=0\), nonnegativity and \(\sum_t x_t\leq0\) force every \(x_t=0\). Hence the support is exactly \(A=S\).

Suppose \(\alpha>0\). If \(t\notin A\cup B\), then \(\mu_t=\rho_t=0\), so feasibility forces \(x_t=0\). Consequently every feasible support is contained in \(S\).

To attain \(S\), put \(R=B\setminus A\) and \(r=|R|\). If \(r=0\), take \(x=0\). Otherwise choose

\(x_t=\min\{\rho_t,\alpha/r\}\) for \(t\in R\), and \(x_t=0\) for \(t\notin R\).

For every \(t\in R\), both quantities in the minimum are positive, so \(x_t>0\). Also \(x_t\leq\rho_t\), and

\(\sum_t x_t=\sum_{t\in R}x_t\leq r(\alpha/r)=\alpha\).

This recruitment is feasible and its support is exactly \(A\cup R=S\). All chosen masses are rational; infinitesimals or limiting arguments are unnecessary.

2. LSR closure is monotone in support

For any \(T\subseteq\Theta\), let \(G[T]\) be the directed graph with vertex set \(T\) and an edge \(t\to u\) exactly when \(q_{tu}=1\). Define its seed set by
\(Z(T)=\{t\in T:q_{tt}=1\}\).

Let \(C(T)\) denote the LSR closure computed on support \(T\). Then \(C(T)\) is exactly the set of vertices reachable in \(G[T]\) from \(Z(T)\), including paths of length zero.

To verify this, write \(K_i(T)\) for the closure after \(i\) iterations. Induction shows that \(K_i(T)\) consists exactly of vertices reachable from \(Z(T)\) by paths of length at most \(i\):

  • At \(i=0\), these are precisely the seeds.
  • At the next iteration, each newly added vertex is the endpoint of an edge from a previously reached vertex. Conversely, the penultimate vertex of any path of length \(i+1\) belongs to \(K_i(T)\).

Taking the union over all iterations proves the characterization.

It follows that \(T\subseteq T'\) implies \(C(T)\subseteq C(T')\): every seed in \(T\) remains a seed in \(T'\), and every path in \(G[T]\) remains a path in \(G[T']\).

3. Exact decision criterion

The instance is feasible if and only if \(D\subseteq C(S)\).

For necessity, suppose a feasible recruitment \(x\) succeeds. Section 1 gives \(P_x\subseteq S\). Monotonicity therefore yields
\(D\subseteq C(P_x)\subseteq C(S)\).

For sufficiency, Section 1 supplies a feasible recruitment with \(P_x=S\). If \(D\subseteq C(S)\), this recruitment succeeds.

Thus the criterion handles both zero and positive budgets completely.

4. Algorithm and encoding complexity

Index the types by their supplied order. The algorithm is:

  • Determine \(A\), \(B\), and whether \(\alpha=0\), then construct \(S\).
  • Construct \(G[S]\) from the supplied matrix.
  • Run directed reachability starting simultaneously from all vertices \(t\in S\) with \(q_{tt}=1\).
  • Accept exactly when every member of \(D\) is reached.

Put \(n=|S|\leq\tau\). The restricted graph has at most \(n^2\) edges, so graph construction and reachability take \(O(n^2)\) operations once matrix access is available. Including input reading and indexing, a direct RAM implementation takes \(O(L+m+\tau^2)\) time.

For completeness, a conservative sequential bit-operation bound is \(O((1+\tau^2)L^2)\). One can obtain each of the at most \(\tau^2\) required matrix entries by scanning the input with binary counters, costing at most \(O(L^2)\) per scan. Reachability on the resulting compact matrix can be performed by sequential scans in \(O(\tau^3\log(L+2))\) bit operations, which is dominated by the stated bound because \(\tau\leq L\). These bounds are polynomial in the supplied encoding size.

The decision algorithm uses the rational masses only to test whether they are zero. If a witness is wanted, the rational construction in Section 1 has polynomial encoding length: dividing the budget by \(r\leq\tau\) increases its denominator length by at most \(O(\log(\tau+1))\).

5. Why the discrete comparison differs

The [discrete group-control formulation of Yang and Dimitrov](https://journal.hep.com.cn/fcs/EN/10.1007/s11704-023-2700-1) limits the number of added individuals. Here, for every positive budget, all available additional types can be activated simultaneously. Since the specified LSR rule depends only on support, the support attained in Section 1 removes the combinatorial selection constraint.
