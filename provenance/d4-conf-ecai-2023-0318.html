The continuous mirror question, as graded

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge 2\) and \(\Delta^k=\{z\in\mathbb R_{\ge0}^k:\sum_{j=1}^k z_j=1\}\).
A society is given by its support: \(\tau\ge1\) distinct rational types \(s^1,\ldots,s^\tau\in\Delta^m\), each with a positive binary rational mass \(\mu_t\), where \(\sum_{t=1}^\tau\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a rational outcome \(\bar x\in\Delta^m\); let \(L\) be the total binary input bit length. State running times in \(m,\tau,L\).
For each supported type, define \(d_t(z)=\sum_{j=1}^m|s_j^t-z_j|\).
Decide whether there exists a real outcome \(y\in\Delta^m\) satisfying \(d_t(y)\le d_t(\bar x)\) for every supported type, with strict inequality for at least one supported type.

Is this decision problem in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For a finite list of agents with these ideal distributions and disutilities, checking Pareto optimality—and hence deciding whether a Pareto improvement exists—is polynomial-time solvable. No separate result for the mass-input version is supplied.

Conclusion

The decision problem is in \(\mathrm P\), with running time polynomial in \(m,\tau,L\). The masses do not enter the algorithm: the requested inequalities concern exactly the \(\tau\) supported types.

Linear programming formulation

For each \(t\in\{1,\ldots,\tau\}\), compute the rational threshold
\(D_t=d_t(\bar x)=\sum_{j=1}^m|s_j^t-\bar x_j|\), and let \(B=\sum_{t=1}^{\tau}D_t\).

Introduce outcome variables \(y_j\) and auxiliary variables \(a_{tj}\). Consider the following rational linear program:

  • Minimize \(F=\sum_{t=1}^{\tau}\sum_{j=1}^m a_{tj}\).
  • Require \(y_j\ge 0\) for every \(j\), and \(\sum_{j=1}^m y_j=1\).
  • Require \(a_{tj}\ge 0\), \(a_{tj}\ge s_j^t-y_j\), and \(a_{tj}\ge y_j-s_j^t\) for every \(t,j\).
  • Require \(\sum_{j=1}^m a_{tj}\le D_t\) for every \(t\).

The absolute-value constraints imply
\(a_{tj}\ge |s_j^t-y_j|\). Consequently, every feasible solution satisfies
\(d_t(y)\le\sum_{j=1}^m a_{tj}\le D_t\) for every supported type.

The program is feasible: take \(y=\bar x\) and \(a_{tj}=|s_j^t-\bar x_j|\). This solution has objective value \(B\).

An optimum is attained. Indeed, every feasible outcome has \(0\le y_j\le 1\). Also,
\(D_t\le\sum_{j=1}^m(s_j^t+\bar x_j)=2\), so nonnegativity and the row-sum constraints give \(0\le a_{tj}\le 2\). Thus the feasible region is nonempty, closed, and bounded. Write \(F^\star\) for its minimum objective value.

Correctness

We prove that a Pareto improvement exists if and only if \(F^\star<B\).

An improvement implies \(F^\star<B\). Suppose \(y\in\Delta^m\) satisfies \(d_t(y)\le D_t\) for every \(t\), with strict inequality for at least one \(t\). Set \(a_{tj}=|s_j^t-y_j|\). These variables satisfy every constraint, and their objective value is
\(F=\sum_{t=1}^{\tau}d_t(y)<\sum_{t=1}^{\tau}D_t=B\).
Hence \(F^\star<B\).

The inequality \(F^\star<B\) implies an improvement. Let \((y,a)\) be an optimal solution. Feasibility gives \(d_t(y)\le D_t\) for every \(t\), while
\(\sum_{t=1}^{\tau}d_t(y)\le\sum_{t=1}^{\tau}\sum_{j=1}^m a_{tj}=F^\star<B\).
If every type had \(d_t(y)=D_t\), the leftmost sum would equal \(B\), contradicting this inequality. Therefore at least one supported type strictly improves.

The algorithm therefore solves the linear program exactly and answers “yes” precisely when \(F^\star<B\). It requires no numerical tolerance for strict inequalities.

Bit complexity and running time

The program has \(m+m\tau\) variables and \(O(m\tau)\) constraints.

The thresholds \(D_t\) and \(B\) can be computed exactly in polynomial time. To check their encoding lengths, let \(Q\) be the product of the denominators of all input coordinates. Its binary length is \(O(L)\). Every coordinate difference, every \(D_t\), and \(B\) can be represented using denominator \(Q\). Since \(D_t\le 2\) and \(B\le 2\tau\), their numerators have binary length \(O(L+\log(m\tau))\). All remaining coefficients belong to \(\{-1,0,1\}\).

Thus, even with a dense matrix encoding, the linear program has total binary length
\(O((m\tau)^2(L+\log(m\tau)))\).
The polynomial-time theorem for rational linear programming applies to this explicitly represented rational program: an exact optimum can be computed in time polynomial in its binary encoding length. See the [MIT linear programming algorithm notes](https://courses.csail.mit.edu/6.854/21/Scribe/s14-lpAlgorithms/s14-lpAlgorithms.html). Comparing that rational optimum with \(B\) also takes polynomial time. The resulting running time can be stated as
\((m\tau(L+\log(m\tau)))^{O(1)}\).

No expansion into agents according to the masses is necessary. Even exponentially small positive masses leave the program’s size unchanged.
