The continuous mirror question, as graded

Given \(m\) alternatives, a committee size \(k\), and a rational distribution \(\mu\) over \(\tau\) complete rankings with encoding length \(L\), can one compute in time polynomial in \(m,\tau,L\) a size-\(k\) committee \(X\) satisfying \(D_\mu(X)=\sup_{(v_t\in P_t)_t}\frac{\max_{a\in C}\sum_t\mu_t v_t(a)}{\frac{1}{k}\sum_{b\in X}\sum_t\mu_t v_t(b)}\le C\max\{k,m^2/(k\sqrt{k})\}\) for a universal constant \(C\), where \(P_t\) is the set of unit-sum cardinal utility vectors consistent with ranking \(t\)?

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge2\) alternatives, and let \(1\le k\le m\) be an integer. A society is given by its support: \(\tau\) distinct complete strict rankings \(\sigma_t\), each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
For each type, define \(P_t=\{v\in\mathbb R_{\ge0}^{A}:\sum_{a\in A}v(a)=1,\ v(\sigma_t(1))\ge\cdots\ge v(\sigma_t(m))\}\); utility ties are permitted despite the strict reported ranking.
A committee \(X\subseteq A\) has exactly \(k\) distinct members and induces uniform selection from \(X\). Define \(D_\mu(X)=\sup_{(v_t)_t\in\prod_tP_t}\frac{\max_{a\in A}\sum_t\mu_tv_t(a)}{\frac1k\sum_{b\in X}\sum_t\mu_tv_t(b)}\), interpreting a zero denominator as infinite distortion.

Can a committee satisfying \(D_\mu(X)\le c\max\{k,m^2/(k\sqrt{k})\}\), for some universal constant \(c>0\), always be computed deterministically in time polynomial in \(m,\tau,L,k\), or is obtaining this guarantee NP-hard?

For explicitly listed finite electorates, a polynomial-time committee rule achieves \(O(\max\{k,m^2/(k\sqrt{k})\})\) distortion; every uniform committee rule has worst-case distortion \(\Omega(\max\{k,m^2/k^2\})\). [Verified discrete bounds](https://proceedings.neurips.cc/paper_files/paper/2023/file/47eb2874a790d5b1f554b9bb93b3de9d-Paper-Conference.pdf).
No result settling this guarantee for binary rational support input was identified in the literature search.

Modeling choices made when packaging the task

  • Specified at least two alternatives and an integer committee size between one and the number of alternatives.
  • Made distribution normalization and positive support masses explicit, and defined L as the total input bit length.
  • Specified nonnegative real, unit-sum utilities with weak monotonicity along complete strict rankings, allowing utility ties.
  • Defined zero-denominator distortion as infinite; unit-sum utilities ensure that the numerator is positive.
  • Required a deterministic selection of exactly k distinct alternatives, with randomness only in the uniform selection of a committee member.
  • Interpreted the unspecified universal constant existentially, independent of every input parameter.

Result

The guarantee is deterministically computable in polynomial time. A polynomial-size rounded electorate suffices; exact replication of the rational masses is unnecessary.

The proof uses the finite-electorate algorithm supplied in the question and establishes that its guarantee survives sufficiently accurate additive rounding of the masses.

1. The finite-electorate theorem

Write \(B(m,k)=\max\{k,m^2/(k\sqrt{k})\}\).

The given finite-electorate result provides a deterministic algorithm \(F\), polynomial in the explicitly listed electorate size, that returns exactly \(k\) distinct alternatives and has distortion at most \(C B(m,k)\), for a fixed universal integer \(C\ge 1\). This is Theorem 4 of [Ebadian et al., *Explainable and Efficient Randomized Voting Rules*](https://proceedings.neurips.cc/paper_files/paper/2023/file/47eb2874a790d5b1f554b9bb93b3de9d-Paper-Conference.pdf); the committee is selected deterministically, followed by uniform selection from it.

We will use the equivalent welfare inequality. For every consistent utility profile on an electorate of size \(n\), its returned committee \(X\) satisfies

\(\displaystyle \max_{a\in A}\frac1n\sum_{i=1}^{n}u_i(a)\le C B(m,k)\frac1k\sum_{b\in X}\frac1n\sum_{i=1}^{n}u_i(b).\)

This inequality also holds when utilities have ties and zeros. To verify this even if the theorem is stated for strictly consistent positive utilities, fix a ranking \(\sigma\) and define

\(\displaystyle w(\sigma(j))=\frac{2(m+1-j)}{m(m+1)},\qquad 1\le j\le m.\)

This vector is positive, strictly decreasing along \(\sigma\), and sums to one. For any weakly consistent unit-sum vector \(v\), the vector \((1-\varepsilon)v+\varepsilon w\) is strictly consistent and positive whenever \(0<\varepsilon<1\). Apply the welfare inequality to these perturbed vectors and let \(\varepsilon\) decrease to zero. Both sides are continuous, so the inequality holds for the original vectors.

2. Deterministically round the society

Set \(N=4C\tau m^3\). For each type, compute \(f_t=\lfloor N\mu_t\rfloor\), and set

\(\displaystyle r=N-\sum_{t=1}^{\tau}f_t.\)

Because \(\sum_t N\mu_t=N\), we have

\(\displaystyle r=\sum_{t=1}^{\tau}(N\mu_t-f_t).\)

Thus \(r\) is an integer satisfying \(0\le r<\tau\).

Using the input order of types, increase the first \(r\) counts by one: let \(n_t=f_t+1\) for \(t\le r\), and \(n_t=f_t\) otherwise. Define \(\nu_t=n_t/N\). Then

\(\displaystyle \sum_t\nu_t=1,\qquad |\mu_t-\nu_t|\le\frac1N.\)

Consequently, writing \(\delta=\sum_t|\mu_t-\nu_t|\), we obtain

\(\displaystyle \delta\le\frac{\tau}{N}=\frac{1}{4Cm^3}.\)

Construct an explicitly listed electorate containing \(n_t\) copies of ranking \(\sigma_t\), and run \(F\) on it. Return its committee \(X\). Types with \(n_t=0\) contribute no copies.

3. Uniform welfare estimates

Fix an arbitrary utility profile \(v=(v_t)_t\in\prod_t P_t\). For either mass vector \(\rho\in\{\mu,\nu\}\), define

\(\displaystyle W_\rho(a;v)=\sum_t\rho_t v_t(a),\qquad M_\rho(v)=\max_{a\in A}W_\rho(a;v),\)

and

\(\displaystyle Q_\rho(X;v)=\frac1k\sum_{b\in X}W_\rho(b;v).\)

Assign every copy of type \(t\) the utility vector \(v_t\). This is an admissible utility profile for the rounded electorate. The finite-electorate inequality therefore gives, with \(R=C B(m,k)\),

\(\displaystyle M_\nu(v)\le R Q_\nu(X;v).\)

Moreover, normalization implies

\(\displaystyle \sum_{a\in A}W_\nu(a;v)=\sum_t\nu_t\sum_{a\in A}v_t(a)=1.\)

Hence \(M_\nu(v)\ge 1/m\), and therefore

\(\displaystyle Q_\nu(X;v)\ge\frac{1}{mR}.\)

This lower bound holds for every admissible \(v\).

Every coordinate \(v_t(a)\) lies in \([0,1]\). Thus, for each alternative,

\(\displaystyle |W_\mu(a;v)-W_\nu(a;v)|\le\sum_t|\mu_t-\nu_t|v_t(a)\le\delta.\)

Taking maxima yields \(|M_\mu(v)-M_\nu(v)|\le\delta\). Similarly, since \(k^{-1}\sum_{b\in X}v_t(b)\in[0,1]\),

\(\displaystyle |Q_\mu(X;v)-Q_\nu(X;v)|\le\delta.\)

These estimates also cover types omitted from the rounded electorate.

4. Transfer the distortion bound

Because \(1\le k\le m\), both terms defining \(B(m,k)\) are at most \(m^2\). Consequently \(R\le Cm^2\), and

\(\displaystyle \delta\le\frac{1}{4Cm^3}\le\frac{1}{4mR}\le\frac14Q_\nu(X;v).\)

It follows that

\(\displaystyle Q_\mu(X;v)\ge Q_\nu(X;v)-\delta\ge\frac34Q_\nu(X;v)>0.\)

In particular, the original society never produces a zero denominator for this committee. Also,

\(\displaystyle M_\mu(v)\le M_\nu(v)+\delta\le RQ_\nu(X;v)+\delta.\)

Combining these inequalities gives

\(\displaystyle \frac{M_\mu(v)}{Q_\mu(X;v)} \le\frac{RQ_\nu(X;v)+\delta}{Q_\nu(X;v)-\delta} \le\frac{R+1/4}{3/4} =\frac{4R+1}{3} \le 2R,\)

where the last inequality uses \(R\ge1\).

Since \(v\) was arbitrary, taking the supremum proves

\(\displaystyle D_\mu(X)\le 2C\max\{k,m^2/(k\sqrt{k})\}.\)

Thus \(c=2C\) is a valid universal constant.

5. Bit complexity and conclusion

The rounded electorate has \(N=4C\tau m^3\) voters, a polynomial numerical size independent of the rational denominators.

If \(\mu_t=p_t/q_t\), its rounded count is computed exactly by integer division of \(Np_t\) by \(q_t\). The integers involved have bit length at most \(L+O(\log N)\), so all rounding operations take polynomial time. Explicitly writing the rounded rankings requires \(O(Nm\log m)\) bits. Running the deterministic finite-electorate algorithm on this list also takes polynomial time in \(m,\tau,L,k\).

Therefore the requested guarantee is deterministically polynomial-time solvable for binary rational support input.
