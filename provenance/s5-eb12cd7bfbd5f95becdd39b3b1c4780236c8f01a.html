The continuous mirror question, as graded

Given \(q\) ordered pipeline stations and a finite support \(T\) of \(\tau\) user types, each with station \(p(t)\), integral bundle utilities \(U_t(k)\), and a convex piecewise-linear per-capita damage function \(D_t\), let each type have positive rational mass \(\mu_t\) with \(\sum_{t\in T}\mu_t=1\). Choose \(z_{t,k}\ge 0\), with \(\sum_k z_{t,k}=\mu_t\), where \(z_{t,k}\) is the mass of type \(t\) receiving \(k\) units. Set \(F_i=\sum_{t:p(t)\ge i}\sum_k k z_{t,k}\). Find an allocation maximizing \(\sum_{t\in T}\sum_k z_{t,k}U_t(k)-\sum_{t\in T}\mu_tD_t(F_{p(t)})\), and return its allocation, flows, and welfare.

Packaged proof task (what the prover saw — nothing else)

Let \(q,m\ge1\). Stations \(1,\ldots,q\) are ordered away from a single source. A society is given by its support: a list \(T\) of \(\tau\ge1\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has a station \(p(t)\in\{1,\ldots,q\}\) and an explicit integer utility table \(U_t(0),\ldots,U_t(m)\), with \(U_t(0)=0\) and nonnegative, nonincreasing increments. Utilities are constant beyond \(m\), so larger bundles can be omitted without lowering welfare.
Each per-capita damage function \(D_t:\mathbb R_{\ge0}\to\mathbb R_{\ge0}\) is nondecreasing, convex, and piecewise linear, with \(D_t(0)=0\). Its rational breakpoints and slopes are explicitly listed, including a final ray with positive slope. Let \(b\) be the total number of pieces and \(L\) the total binary input length.
An allocation splits each type into masses \(z_{t,k}\ge0\), for \(k\in\{0,\ldots,m\}\), satisfying \(\sum_{k=0}^m z_{t,k}=\mu_t\). Flow at station \(i\) is \(F_i=\sum_{t:p(t)\ge i}\sum_{k=0}^m k z_{t,k}\).
Its welfare is \(W(z)=\sum_t\sum_{k=0}^m z_{t,k}U_t(k)-\sum_t\mu_tD_t(F_{p(t)})\). The optimization problem returns any maximizing allocation, its flows, and its exact welfare.

Is this exact welfare maximization problem solvable in polynomial time in \(m,q,\tau,b,L\), or is its decision version—whether \(\max_z W(z)\ge B\) for a binary rational threshold \(B\)—NP-hard?

For finite agents with decreasing nonnegative marginal utilities and increasing nonnegative marginal damages, the discrete anchor establishes welfare optimality of a greedy unit-allocation algorithm for every priority ordering; it does not state a binary-input polynomial running time. [Trudeau and Rosenthal](http://web2.uwindsor.ca/economics/RePEc/wis/pdf/2502.pdf).
The finite-agent model also treats real-valued consumption with differentiable concave utilities and convex damages using first-order conditions; this differs from a society of splittable masses receiving integral bundles. No result settling the exact mass problem was located.

Modeling choices made when packaging the task

  • The bundle domain and utility encoding were unspecified. Use an explicit table for all integer bundles from zero through a common bound m, with zero marginal utility thereafter; bundles larger than m can consequently be omitted.
  • Restore the discrete model's utility conditions: zero utility at zero and nonnegative, nonincreasing marginal utilities.
  • Restore zero damage at zero and nondecreasing damages. Encode piecewise-linear damages by rational breakpoints and slopes on the nonnegative real domain.
  • Require a positive final damage slope for every type. Together with the zero utility tail, this preserves the discrete assumption that marginal damage eventually strictly exceeds marginal utility.
  • Allow any welfare maximizer, since the discrete anchor permits different optimal allocations under different priority orderings.
  • Introduce an exact rational welfare threshold for the decision version and define m, b, and L so the complexity question has a finite input model.

Conclusion

The exact welfare maximization problem is polynomial-time solvable in \(m,q,\tau,b,L\). Its decision version belongs to \(\mathrm{P}\).

The key is that bundle sizes are integer labels, while the masses assigned to those labels are continuous variables. Convex piecewise-linear damages therefore yield an exact linear program.

1. Representing each damage function

For type \(t\), write its piece boundaries as \(a_{t,0}=0<a_{t,1}<\cdots<a_{t,r_t-1}\), with the last piece extending to infinity. Let \(s_{t,j}\) be the slope of piece \(j\). Convexity implies that these slopes are nondecreasing.

The functions are continuous. Continuity at positive arguments follows from finiteness and convexity. At zero, for fixed \(a>0\) and \(0<h<a\), convexity and nonnegativity give \(0\le D_t(h)\le hD_t(a)/a\), proving right continuity.

Consequently, the value at each piece boundary is

\( \displaystyle v_{t,j}:=D_t(a_{t,j})=\sum_{\ell=0}^{j-1}s_{t,\ell}(a_{t,\ell+1}-a_{t,\ell}), \)

where the empty sum is zero. Define the rational intercept \(c_{t,j}:=v_{t,j}-s_{t,j}a_{t,j}\).

Claim. For every \(x\ge0\),

\( \displaystyle D_t(x)=\max_{0\le j<r_t}\{s_{t,j}x+c_{t,j}\}. \)

To prove this, fix a piece \(j\). If \(x\ge a_{t,j}\), every slope traversed between \(a_{t,j}\) and \(x\) is at least \(s_{t,j}\), so

\(D_t(x)-D_t(a_{t,j})\ge s_{t,j}(x-a_{t,j})\).

If \(x<a_{t,j}\), every slope traversed between \(x\) and \(a_{t,j}\) is at most \(s_{t,j}\), so

\(D_t(a_{t,j})-D_t(x)\le s_{t,j}(a_{t,j}-x)\).

Thus the affine function of piece \(j\) lies below \(D_t\) everywhere. For any \(x\), the affine function of a piece containing \(x\) equals \(D_t(x)\). This proves the claim, including at breakpoints.

2. An exact linear program

For each type \(t\), define the linear expression

\( \displaystyle G_t(z):=\sum_{s:\,p(s)\ge p(t)}\sum_{k=0}^{m}kz_{s,k}. \)

This is precisely \(F_{p(t)}\).

Every feasible allocation satisfies

\( \displaystyle 0\le F_i\le\sum_s\sum_{k=0}^{m}kz_{s,k}\le m\sum_s\mu_s=m. \)

Let \(M_t:=D_t(m)\), which is rational and can be computed from the affine representation above. Introduce one auxiliary variable \(d_t\) for each type and solve the following linear program:

\( \displaystyle \max_{z,d}\left\{\sum_t\sum_{k=0}^{m}U_t(k)z_{t,k}-\sum_t\mu_td_t\right\}, \)

subject to:

  • \(z_{t,k}\ge0\), for every \(t,k\);
  • \(\sum_{k=0}^{m}z_{t,k}=\mu_t\), for every \(t\);
  • \(d_t\ge s_{t,j}G_t(z)+c_{t,j}\), for every type \(t\) and every piece \(j\);
  • \(0\le d_t\le M_t\), for every \(t\).

All these constraints are linear with rational coefficients.

Claim. This linear program has exactly the original optimal welfare, and every optimal solution yields a maximizing allocation.

For any feasible allocation \(z\), choose \(d_t=D_t(G_t(z))\). The affine representation makes every damage constraint valid. Because \(0\le G_t(z)\le m\) and \(D_t\) is nondecreasing, the bounds on \(d_t\) also hold. The resulting linear-program objective equals \(W(z)\).

Conversely, every feasible pair \((z,d)\) satisfies \(d_t\ge D_t(G_t(z))\). Its objective is therefore at most \(W(z)\), and hence at most the original optimum. Together, the two directions prove equality of optimal values.

Furthermore, in an optimal pair, each damage variable satisfies \(d_t=D_t(G_t(z))\). Otherwise, decreasing that variable to this value preserves feasibility and strictly increases the objective, because \(\mu_t>0\). Thus the extracted allocation achieves the optimal welfare exactly.

The linear program is nonempty: assign \(z_{t,0}=\mu_t\), all other allocation variables zero, and all \(d_t=0\). It is bounded because \(0\le z_{t,k}\le\mu_t\) and \(0\le d_t\le M_t\). Its optimum is therefore attained.

3. Polynomial encoding and exact computation

The linear program has \(N=\tau(m+2)\) variables, \(\tau\) equality constraints, and \(b+\tau(m+1)+2\tau\) inequality constraints. Even a dense encoding therefore has polynomially many entries.

The derived coefficients also have polynomial bit length. Each intercept is a sum of at most \(b\) products and differences of input rationals. Each summand has bit length bounded by \(O(L)\); putting these summands over a common denominator gives a polynomial bound, for example \(O(b(L+1))\). Computing \(M_t\) and coefficients such as \(ks_{t,j}\) adds only polynomially many bits. All these calculations use polynomial-time rational arithmetic.

We apply the standard exact rational linear-programming theorem: a linear program with binary rational data can be solved in time polynomial in its encoding length, returning an exact rational optimizer when its feasible set is nonempty and its optimum is finite. Exactness, rather than merely approximate optimization, is part of this theorem; see [Gleixner and Steffy, Section 1.3](https://arxiv.org/html/1912.12820#S1.SS3).

Its hypotheses have all been verified here: rational coefficients, polynomial encoding length, nonempty feasibility, and a finite attained optimum.

For completeness, there is also no obstruction from the size of an exact output. A linear objective on a nonempty bounded polyhedron has an optimal vertex. At such a vertex, \(N\) linearly independent tight constraints determine its coordinates. Let \(E\) denote the linear program’s encoding length. Clearing denominators in these constraints gives integer coefficients and right-hand sides with bit length \(O(E)\). Cramer’s rule and Hadamard’s inequality then bound the numerator and denominator bit lengths of every coordinate by \(O(N(E+\log N))\). Thus an optimal allocation has polynomial-size rational coordinates.

4. Returning flows and deciding the threshold

After obtaining an exact optimizer \(z^*\), compute each type’s consumption \(x_t:=\sum_{k=0}^{m}kz^*_{t,k}\), and return

\( \displaystyle F_i^*=\sum_{t:\,p(t)\ge i}x_t,\qquad i=1,\ldots,q. \)

These are polynomial-size rationals and can be computed in polynomial time in \(q,\tau,m,L\). The exact welfare is the rational objective value of the optimal linear-program solution.

There is a useful encoding distinction: the optimization linear program uses only the occupied station labels through comparisons of \(p(s)\) and \(p(t)\). It does not enumerate all \(q\) stations. Since the utility tables and damage pieces are explicitly listed, its encoding length is polynomial in \(L\), even when \(q\) is binary encoded. Thus the decision algorithm runs in polynomial time in the binary input length, including the encoding length of \(B\), by comparing the exact optimum with \(B\). Emitting all \(q\) flows has the additional output cost permitted by the question.

This proof uses neither a finite-agent expansion nor the greedy anchor. The allocation variables describe the stipulated splittable masses exactly, so the linear program is an exact formulation.
