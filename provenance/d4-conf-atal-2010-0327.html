The continuous mirror question, as graded

Given a candidate set \(C\), a distribution \(\mu\) with binary-rational masses over \(\tau\) complete rankings, and a candidate \(c\), decide whether \(c\) is first in some ranking minimizing \(\sum_t \mu_t\,\operatorname{Kendall}(t,\pi)\) over all rankings \(\pi\) of \(C\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) distinct rankings \(t\) with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Use the standard Kendall distance. A candidate is a winner if it is first in at least one ranking minimizing \(\sum_t\mu_t\operatorname{Kendall}(t,\pi)\) over all rankings \(\pi\) of \(C\); retain all tied minimizers.

Is this winner decision problem in \(\mathrm P\) or \(\mathrm{NP}\)-hard? If it is \(\mathrm{NP}\)-hard, is it fixed-parameter tractable with parameter \(m\), with running time \(f(m)\operatorname{poly}(\tau,L)\)?

For explicit finite electorates, Kemeny winner determination is fixed-parameter tractable in \(m\) and is \(\Theta_2^p\)-complete. [The complexity of Kemeny elections](https://www.sciencedirect.com/science/article/pii/S0304397505005785)

[High-Multiplicity Election Problems](https://www.ifaamas.org/Proceedings/aamas2018/pdfs/p1558.pdf) The normalized rational-mass formulation is an equivalent encoding, so the requested hardness-versus-polynomial-time target is already settled.

1. Result

The problem is \(\mathrm{NP}\)-hard and fixed-parameter tractable with parameter \(m\). More precisely, it is \(\Delta_2^p\)-complete under polynomial-time many-one reductions.

Here, binary-rational masses mean rational numbers whose numerators and denominators are encoded in binary. The proof below establishes the encoding equivalence and gives an exact algorithm with explicit bit-complexity bounds. When \(m=1\), the sole candidate is always a winner.

2. Encoding equivalence and hardness

For a ranking \(\pi\), write its objective value as

\(\displaystyle K_\mu(\pi)=\sum_t\mu_t\operatorname{Kendall}(t,\pi).\)

Integer multiplicities to normalized masses. Consider an election represented by distinct strict rankings \(t\) with positive binary integer multiplicities \(w_t\). Put

\(\displaystyle W=\sum_t w_t,\qquad \mu_t=\frac{w_t}{W}.\)

These masses are positive and sum to one. For every ranking \(\pi\),

\(\displaystyle K_\mu(\pi)=\frac{1}{W}\sum_t w_t\operatorname{Kendall}(t,\pi).\)

Multiplication by the positive constant \(1/W\) preserves all comparisons and equalities between objective values. Consequently, it preserves every minimizing ranking and every winner.

This transformation has polynomial running time and output length: the bit length of \(W\) is at most the largest multiplicity bit length plus \(\lceil\log_2\tau\rceil+1\), and each output mass can be represented by the pair \((w_t,W)\). Neither the candidate set nor the support size changes.

Normalized masses to integer multiplicities. Conversely, write each input mass as \(\mu_t=a_t/b_t\), with positive binary integers \(a_t,b_t\). Define

\(\displaystyle D=\prod_t b_t,\qquad w_t=a_t\frac{D}{b_t}.\)

Each \(w_t\) is a positive integer. Normalization gives

\(\displaystyle \sum_t w_t=D\sum_t\mu_t=D.\)

Moreover,

\(\displaystyle \sum_t w_t\operatorname{Kendall}(t,\pi)=D K_\mu(\pi).\)

Thus this transformation also preserves exactly the minimizing rankings and winners. The bit length of \(D\) is at most \(1+\sum_t\log_2 b_t\), hence is \(O(L)\). Since \(w_t\le D\), every multiplicity has \(O(L)\) bits, and the entire transformation is polynomial in the input length. No electorate expansion is needed.

Applying the cited theorem. Theorem 6.5 of Fitzsimmons and Hemaspaandra states that Kemeny winner determination in high-multiplicity representation is \(\Delta_2^p\)-complete. Their definition uses strict rankings and declares a candidate a winner precisely when it occurs first in some ranking minimizing total Kendall distance. Thus its hypotheses and tie convention agree with this task. [High-Multiplicity Election Problems, Section 6](https://www.ifaamas.org/Proceedings/aamas2018/pdfs/p1558.pdf)

The two polynomial-time transformations above therefore establish \(\Delta_2^p\)-completeness for the normalized rational-mass problem. In particular, it is \(\mathrm{NP}\)-hard; a polynomial-time algorithm would imply \(\mathrm P=\mathrm{NP}\).

3. An exact algorithm parameterized by \(m\)

Use the integer multiplicities obtained above. For distinct candidates \(a,b\), define

\(\displaystyle q_{a,b}=\sum_{t:\,a\text{ precedes }b\text{ in }t}w_t.\)

If \(\pi\) places \(a\) before \(b\), this pair contributes \(q_{b,a}\) to its weighted Kendall objective: exactly the rankings placing \(b\) before \(a\) disagree on that pair. Hence

\(\displaystyle K_w(\pi)=\sum_{a\text{ precedes }b\text{ in }\pi}q_{b,a}.\)

For each subset \(S\subseteq C\), let \(F(S)\) be the minimum of this pairwise sum over all strict rankings of \(S\), counting only pairs contained in \(S\). Set \(F(\varnothing)=0\).

Recurrence. For every nonempty \(S\),

\(\displaystyle F(S)=\min_{x\in S}\left(F(S\setminus\{x\})+\sum_{y\in S\setminus\{x\}}q_{y,x}\right).\)

To prove this, fix the first candidate \(x\) of a ranking of \(S\). Every pair involving \(x\) contributes \(q_{y,x}\), independently of the order of the remaining candidates. All other contributions are exactly those of the remaining ranking on \(S\setminus\{x\}\). Their minimum is \(F(S\setminus\{x\})\), which is attained because there are finitely many rankings. Taking the minimum over all possible first candidates proves the recurrence.

Compute the states in increasing order of subset size. Induction on that size, using the proved recurrence, shows that every computed value is exact.

The minimum score among rankings beginning with the designated candidate \(c\) is

\(\displaystyle F_c=F(C\setminus\{c\})+\sum_{y\in C\setminus\{c\}}q_{y,c}.\)

Therefore,

\(\displaystyle c\text{ is a winner}\quad\Longleftrightarrow\quad F_c=F(C).\)

Indeed, equality means that an attained minimum among rankings beginning with \(c\) is also a global minimum. Conversely, any globally minimizing ranking beginning with \(c\) forces this equality. This comparison retains all tied winners.

Bit complexity

Let \(B=O(L+\log(m+1))\). Because \(\sum_t w_t=D\), pairwise totals are at most \(D\), and every score computed by the recurrence is at most \(\binom m2D\). Thus all arithmetic operands have \(O(B)\) bits.

Using schoolbook integer arithmetic:

  • Clearing denominators takes \(O(\tau L^2)\) bit operations.
  • Computing all pairwise totals takes \(O(\tau m^2B)\) bit operations.
  • There are \(2^m\) subset states. Each state considers at most \(m\) first candidates and sums at most \(m-1\) pair contributions for each choice. This takes \(O(m^2 2^mB)\) bit operations.

The resulting running time is

\(\displaystyle O\!\left(\tau L^2+(\tau m^2+m^2 2^m)(L+\log(m+1))\right).\)

This has the required form \(f(m)\operatorname{poly}(\tau,L)\), proving fixed-parameter tractability in \(m\).

4. Independent verification of the upper complexity bound

The cleared-denominator score is an integer between \(0\) and \(U=\binom m2D\). The threshold question “does some ranking have score at most \(k\)?” belongs to \(\mathrm{NP}\): a ranking is a polynomial-size certificate, and its score can be checked using the pairwise totals.

Binary search over this interval determines the optimum using \(O(\log(U+1))=O(L+\log(m+1))\) oracle queries. After finding the optimum \(K^\ast\), one further \(\mathrm{NP}\) query asks whether a ranking beginning with \(c\) has score at most \(K^\ast\). Its answer is exactly the winner decision.

All preprocessing, query construction, and certificate checks take polynomial time. Thus the problem belongs to \(\mathrm P^{\mathrm{NP}}=\Delta_2^p\), independently confirming the upper bound used in the completeness statement.
