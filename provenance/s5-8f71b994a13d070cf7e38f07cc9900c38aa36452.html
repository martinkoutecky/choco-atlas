The continuous mirror question, as graded

For fixed \(n\), \(k\), and support bound \(\tau\), let \(\mu\) be a rational distribution over complete binary \(k\)-bounded acyclic CP-net types, with support size at most \(\tau\). Given an exact oracle that returns \(q_\mu(x)=\sum_t\mu_t\mathbf{1}[N_t\text{ entails }x.1\succ x.2]\) for any swap \(x\), determine the query and computational complexity, in \(n\), \(k\), \(\tau\), and the response bit length \(L\), of outputting a mixture of at most \(\tau\) such types whose aggregate response agrees with \(q_\mu\) on every swap.

Packaged proof task (what the prover saw — nothing else)

Let \(n\geq1\), \(m=2\), \(0\leq k\leq n-1\), and \(b\geq1\). A type is a complete acyclic CP-net on \(n\) variables with domain \(\{0,1\}\), at most \(k\) parents per variable, and no dummy parents; its explicit conditional preference tables specify a strict order for every parent assignment.
A society is represented by its support: a list of \(\tau\leq b\) distinct types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; \(b\) is the supplied support bound.
The support list is hidden. The learner receives \(n,k,b\) and access only to an exact, adaptive swap-query oracle. A swap \(x=(o,o')\) consists of two binary outcomes differing in exactly one variable \(v\); define \(c_N(x)=1\) precisely when the conditional preference table for \(v\), in their common parent context, ranks \(o[v]\) above \(o'[v]\).
The oracle returns \(q_\mu(x)=\sum_t\mu_t c_{N_t}(x)\). Both swap orientations are allowed. Let \(L\) be the maximum binary encoding length of a reduced rational oracle response over all swaps.
The required output is an explicit list of \(r\leq b\) admissible types and positive binary-rational weights \(w_j\) summing to \(1\), satisfying \(\sum_{j=1}^r w_jc_{N_j}(x)=q_\mu(x)\) for every swap; the original support need not be recovered. Count oracle calls separately from bit computation, including reading responses and writing the output.

For each fixed \(k\), is this exact reconstruction problem solvable with polynomially many oracle calls and polynomial bit time in \(n,b,L\), or is it NP-hard?
What are its worst-case query and computational complexities in \(n,m=2,k,\tau,b,L\)?

A single complete binary acyclic CP-net is exactly learnable with \(O(n\mathcal U_k+e\log_2 n)\) swap membership queries, where \(e\) is its edge count and \(\mathcal U_k\) is the smallest size of a set of binary contexts on \(n-1\) coordinates realizing every assignment on every \(k\)-coordinate subset; learning is polynomial-time for fixed \(k\). Probabilistic CP-net learning has been studied using observations of optimal outcomes and independent preference-table probabilities on a common graph; this concerns a different representation and information source. [Source](https://pure.uva.nl/ws/files/29462278/9781614994213.pdf#page=94)

Modeling choices made when packaging the task

  • Separated the supplied support bound b from the actual support size tau, preserving the requirement to output at most the supplied bound.
  • Treated the support list as hidden and available only through aggregate queries; providing it to the learner would make reconstruction immediate.
  • Normalized the distribution and output weights to sum to one, with strictly positive binary-rational masses.
  • Required explicit complete preference tables, strict local preferences, acyclicity, and minimal parent sets, following the discrete type definition.
  • Allowed both swap orientations, which carry complementary responses for complete types.
  • Defined L as the maximum reduced-rational response encoding length and distinguished oracle calls from bit computation and output costs.
  • Interpreted polynomial-time learning for fixed k, while retaining the question of dependence on k; explicit tables can have size exponential in k.
  • Required aggregate equivalence only, allowing an alternative support rather than identification of the hidden mixture.

Exact reconstruction is NP-hard for every fixed parent bound

The computational classification can be completed:

For every fixed $k\geq0$, exact bounded-support reconstruction is NP-hard when $b$ varies. This already holds for context-independent oracles admitting parentless representations. Polynomially many swap queries nevertheless suffice for every fixed $k$.

More precisely, polynomial bit-time reconstruction for any fixed $k$ exists if and only if $\mathrm P=\mathrm{NP}$.

I also establish sharper query bounds, including:

  • For $k=0$, the optimal worst-case query count is $n$, for every $b$.
  • For fixed $k\geq1$ and fixed $b$, it is $\Theta(n\log n)$.
  • For fixed $k\geq1$, a society with actual support size $\tau=1$ can be reconstructed in polynomial time with $\Theta(n\log n)$ worst-case queries, even when the supplied $b$ is large.
  • When $b\geq D+1$, where

$$ D=n\sum_{i=0}^{k}\binom{n-1}{i}, $$
the optimal worst-case query count is $D$. This lower bound holds on a particular oracle having $\tau=2$ and $L=O(1)$.

  • When $k=n-1$, the optimal count is $n2^{n-1}=D$, for every $b$.

Matching query bounds for intermediate, varying support bounds remain open. Thus the document is a partial resolution of the complete complexity question, although it settles the classification for every fixed $k$.

Throughout, “binary-rational” means a rational number whose numerator and denominator are encoded in binary, as in the notes. The hardness construction below uses dyadic weights.

1. Aggregate functions and a polynomial query bound

For each variable $v$, orient swaps with value $1$ first. If $y$ assigns all variables other than $v$, define
$$ f_{N,v}(y)=c_N((1,y),(0,y)), \qquad q_v(y)=\sum_t\mu_t f_{N_t,v}(y). $$

Strict binary preferences imply that the reverse swap has response $1-q_v(y)$. Consequently, reconstructing all the functions $q_v$ reconstructs every swap response.

Put
$$ d_k=\sum_{i=0}^{k}\binom{n-1}{i}, \qquad D=nd_k. $$

1.1. Multilinear representation

A Boolean function depending on a parent set $P$ has the representation
$$ f(y)=\sum_{S\subseteq P}a_S\prod_{u\in S}y_u, $$
where
$$ a_S=\sum_{T\subseteq S}(-1)^{|S|-|T|}f(\mathbf1_T). $$

Here $\mathbf1_T$ assigns $1$ exactly to the coordinates in $T$. To verify the formula, evaluate at $\mathbf1_R$. The coefficient of $f(\mathbf1_T)$ in the resulting sum is
$$ \sum_{S:T\subseteq S\subseteq R}(-1)^{|S|-|T|}, $$
which is $1$ when $T=R$ and $0$ otherwise. This also proves uniqueness.

Every local function has degree at most $k$, so every aggregate satisfies
$$ q_v(y)=\sum_{|S|\leq k}a_{v,S}\prod_{u\in S}y_u. $$

1.2. Determining queries

For each $v$, query $\mathbf1_T$ for every $T$ of size at most $k$. These are exactly $D$ queries. The coefficients follow from
$$ a_{v,S}= \sum_{T\subseteq S}(-1)^{|S|-|T|}q_v(\mathbf1_T). $$

Thus these responses determine every swap response. In particular, two admissible mixtures agree everywhere if and only if they agree on these queries.

There are at most $D2^k$ summands. A common denominator for the responses appearing in one coefficient has $O(2^kL)$ bits. Acquisition and interpolation therefore use
$$ \operatorname{poly}(n,D,2^k,L) $$
bit time, including constructing queries and reading responses. For fixed $k$, this is polynomial.

2. NP-hardness already without parents

For $k=0$, each type is a binary vector. If its $i$th entry is $1$, it prefers $1$ at variable $i$. Consequently, reconstructing probabilities $p_1,\ldots,p_n$ is exactly the following problem:

Find positive weights $w_1,\ldots,w_r$, with $r\leq b$ and sum $1$, such that each $p_i$ is a subset sum of the weights.

The difficulty is that the output may choose different weights. The construction below controls that freedom.

We reduce from two-colorability of a three-uniform hypergraph: every edge must contain both colors. This problem is NP-complete, as stated in the proof of Theorem 3.1 of [Bokal et al., *The circular chromatic number of a digraph*](https://www.sfu.ca/~mohar/Reprints/2004/BM04_JGT46_Bokal_DigraphCircular.pdf).

The construction is a normalized rational adaptation of the anchor method used for integral subset representations in [Collins et al., *Nonnegative Integral Subset Representations of Integer Sets*](https://www.david-kempe.com/publications/subset-rep.pdf). The proof below establishes the additional rigidity needed when arbitrary rational weights and normalization are allowed.

2.1. Construction

Let the hypergraph have vertices $1,\ldots,s$ and $h\geq1$ edges. Define
$$ a_i=8^i,\qquad H=1+\sum_{i=1}^{s}a_i, \qquad M=8^{s+2}. $$

We have $M>2H$.

Create one CP-net variable for each of the following targets:

  • The target $1$.
  • The $s$ targets $a_i$.
  • For each hyperedge $\{i,j,\ell\}$, the target

$$ a_i+a_j+a_\ell-1. $$

There are
$$ n=s+h+1 $$
variables. At a variable with target $z$, prescribe the context-independent response
$$ p_z=\frac zM. $$

Set
$$ b=s+2. $$

All targets lie strictly between $0$ and $H$. The responses and their complements are dyadic, with encoding length $L=O(s)$. The oracle is computable in polynomial time.

2.2. The support bound forces the anchor atoms

Suppose the prescribed probabilities have a representation with at most $s+2$ positive weights. Scale the weights by $M$ and regard them as positive masses of atoms, with total mass $M$.

Choose an event $E_0$ of mass $1$, and events $E_i$ of mass $a_i$.

For every $i\geq1$,
$$ a_i>1+\sum_{j<i}a_j. $$
The union $E_0\cup\cdots\cup E_{i-1}$ has mass at most the right-hand side. Hence $E_i$ must contain an atom outside that union.

The anchor events therefore introduce at least $s+1$ distinct atoms. Their union has mass at most $H<M$, so there is also an atom outside all anchor events. Since the support bound is $s+2$, there are exactly $s+2$ atoms:

  • One atom $t_0$ introduced by $E_0$.
  • One atom $t_i$ introduced by $E_i$, for each $i$.
  • One residual atom $t_*$ outside all anchors.

In particular,
$$ t_0=1. $$

Event $E_i$ consists of $t_i$ and some earlier atoms. Thus
$$ a_i-1-\sum_{j<i}a_j\leq t_i\leq a_i. $$

Also,
$$ t_*=M-\left(1+\sum_{i=1}^{s}t_i\right) \geq M-H>H. $$
The residual atom cannot occur in any target event.

This argument uses only positivity and cardinality, so it applies to arbitrary positive real weights, including arbitrary rational weights.

2.3. A separation lemma

Let $t=(t_1,\ldots,t_s)$. For distinct vectors
$$ u,v\in\{0,1,2,3\}^{s}, $$
we claim
$$ |(u-v)\cdot t|\geq7. $$

Let $i$ be their largest differing coordinate. The contribution at that coordinate has magnitude at least $t_i$, while the earlier contributions have total magnitude at most $3\sum_{j<i}t_j$. Hence
$$ |(u-v)\cdot t| \geq t_i-3\sum_{j<i}t_j \geq a_i-1-4\sum_{j<i}a_j. $$

Since
$$ \sum_{j<i}8^j=\frac{8^i-8}{7}, $$
the last expression is
$$ 8^i-1-\frac{4(8^i-8)}7 =\frac{3\cdot8^i+25}{7} \geq7. $$

2.4. Every reconstruction yields a coloring

Each anchor target has a representation
$$ a_i=u_i\cdot t+\varepsilon_i, \qquad u_i\in\{0,1\}^{s}, \quad \varepsilon_i\in\{0,1\}. $$
Here $\varepsilon_i$ records whether the atom $t_0=1$ is included.

Consider a hyperedge $\{i,j,\ell\}$. Its target has a representation
$$ a_i+a_j+a_\ell-1=v\cdot t+\varepsilon_c, $$
where $v\in\{0,1\}^{s}$ and $\varepsilon_c\in\{0,1\}$.

Subtracting gives
$$ (u_i+u_j+u_\ell-v)\cdot t =\varepsilon_c+1-(\varepsilon_i+\varepsilon_j+\varepsilon_\ell). $$

The right-hand side has absolute value at most $2$. The separation lemma applies to $u_i+u_j+u_\ell$ and $v$, because both belong to $\{0,1,2,3\}^{s}$. They must therefore be equal. Consequently,
$$ \varepsilon_i+\varepsilon_j+\varepsilon_\ell =\varepsilon_c+1\in\{1,2\}. $$

Thus the values $\varepsilon_i$ define a two-coloring with no monochromatic edge.

This conclusion holds for every valid reconstruction, regardless of its choice of weights.

2.5. Every coloring yields a promised society

Conversely, suppose $\varepsilon_1,\ldots,\varepsilon_s\in\{0,1\}$ form a valid coloring. Choose scaled atom masses
$$ t_0=1,\qquad t_i=a_i-\varepsilon_i, \qquad t_*=M-\left(1+\sum_i t_i\right). $$
They are positive and sum to $M$.

The anchor $a_i$ is represented by $t_i$, together with $t_0$ when $\varepsilon_i=1$.

For an edge $\{i,j,\ell\}$, put
$$ E=\varepsilon_i+\varepsilon_j+\varepsilon_\ell\in\{1,2\}. $$
Then
$$ a_i+a_j+a_\ell-1 =t_i+t_j+t_\ell+(E-1)t_0. $$
This is a subset sum.

Divide all masses by $M$. For each atom, create a parentless type whose preference at each variable records whether that atom occurs in the chosen subset representing the variable’s target.

The types are distinct: the coordinate for target $1$ distinguishes $t_0$, each anchor coordinate distinguishes its $t_i$, and the residual type has all entries zero. Therefore the constructed society has
$$ \tau=b=s+2. $$

We have proved the equivalence
$$ \text{hypergraph two-colorability} \quad\Longleftrightarrow\quad \text{existence of a reconstruction with at most }b\text{ types}. $$

3. Hardness for every fixed $k$, including the feasibility promise

3.1. Allowing parents does not help on constant oracles

Suppose every aggregate function is constant:
$$ q_v(y)=p_v. $$

From any reconstruction, replace each component’s local function at $v$ by its value at the all-zero context. This produces a parentless type. Keeping the weights gives aggregate response
$$ \sum_jw_j f_{N_j,v}(\mathbf0)=q_v(\mathbf0)=p_v. $$

Merge identical resulting types. The support size cannot increase.

Therefore a constant oracle has a representation with at most $b$ admissible types for a given parent bound if and only if it has a parentless representation with at most $b$ types. The reduction in Section 2 consequently proves hardness for every fixed $k\geq0$. Isolated source vertices can be added to ensure $k\leq n-1$.

3.2. Reconstruction is promised to be feasible

Suppose a reconstruction algorithm were correct on every promised input and had a polynomial bit-time bound in $n,b,L$.

On the oracle constructed from a hypergraph, simulate the algorithm for that polynomial bound, using the known bound $L=O(s)$. Verify any output: check its types, positive normalized weights, support bound, and agreement on the $D$ determining queries.

For fixed $k$, verification is polynomial-time.

If the hypergraph is colorable, the oracle is promised, so the algorithm returns a valid answer within the bound. If it is not colorable, Sections 2 and 3.1 show that no valid answer exists. Timeout or an invalid answer is rejected.

This decides an NP-complete problem in polynomial time. No correctness or termination assumption is made about the algorithm outside its promise.

Hence polynomial bit-time reconstruction for any fixed $k$ would imply
$$ \mathrm P=\mathrm{NP}. $$

4. Certificate size and computational upper bounds

4.1. A short rational output always exists

For each admissible type $N$, let
$$ a_N\in\{0,1\}^{D} $$
be its responses on the determining queries, and let $z\in\mathbb Q^D$ contain the oracle responses.

A valid representation satisfies
$$ z=\sum_jw_j a_{N_j}, \qquad \sum_jw_j=1. $$

Append a coordinate $1$ to each column $a_N$. If the augmented columns in a positive representation are dependent, choose a nonzero dependence $\alpha$. Its coordinates sum to zero, so it has both signs. Set
$$ \lambda=\min_{\alpha_j>0}\frac{w_j}{\alpha_j}, \qquad w'_j=w_j-\lambda\alpha_j. $$

All equations are preserved, the new weights are nonnegative, and at least one component is removed. Repetition gives independent augmented columns and
$$ r\leq \min\{\tau,b,D+1\}. $$

Select $r$ independent rows. The weights solve a nonsingular system with a zero-one matrix $A$. A common denominator $\Delta$ for its right-hand side has $O(rL)$ bits. Hadamard’s inequality gives
$$ |\det A|\leq r^{r/2}. $$
In Cramer’s rule, after clearing denominators, the numerator determinants have magnitude at most $\Delta r^{r/2}$. Each weight therefore has encoding length
$$ O\bigl(r(L+\log(r+1))\bigr). $$

An explicit type has description length at most
$$ S=O\bigl(n(2^k+(k+1)\log(n+1))\bigr). $$

Thus a valid output exists with total length
$$ O\bigl(rS+r^2(L+\log(r+1))\bigr). $$

For fixed $k$, the finite consistency problem belongs to $\mathrm{NP}$: acyclicity, essentiality of every parent, positivity, normalization, and determining-query equality are all polynomial-time checkable. Combined with Section 3, this decision problem is NP-complete for every fixed $k$.

Polynomially bounded certificates also give reconstruction in $\mathrm{FP}^{\mathrm{NP}}$ after acquiring the determining responses. In particular, if $\mathrm P=\mathrm{NP}$, fixed-$k$ reconstruction has polynomial bit time. This proves the stated “if and only if” classification.

4.2. An unconditional exhaustive bound

The number of local parent/table choices is at most
$$ C=\sum_{p=0}^{k}\binom{n-1}{p}2^{2^p}. $$
Hence there are at most $C^n$ global candidates. Discard cyclic candidates and tables with dummy parents.

After the $D$ queries, enumerate supports in increasing size. For each support with independent augmented columns, solve for its weights and check all equations and positivity.

The preceding argument guarantees success by size
$$ s=\min\{\tau,D+1\}. $$
The algorithm need not know $\tau$.

Since
$$ \log C=O\bigl(2^k+(k+1)\log(n+1)\bigr), $$
this gives the bit-time upper bound
$$ 2^{O\left(sn(2^k+(k+1)\log(n+1))\right)} \operatorname{poly}(n,D,2^k,b,L). $$

This includes reading responses and writing the output. It is an upper bound, not a claim of optimal exponential running time.

5. A sharper general query upper bound

The $D$ queries can be reduced when $b$ is small. This section counts queries separately; constructing its determining set can require exponential computation.

5.1. Nonzero low-degree functions are visible

A nonzero multilinear polynomial $g$ of degree at most $k$ is nonzero on at least a $2^{-k}$ fraction of the Boolean cube.

Proof is by induction on its degree. A nonzero constant is nonzero everywhere. Otherwise, choose a variable appearing in a highest-degree monomial and write
$$ g=x_u h+r. $$
The polynomial $h$ is nonzero and has degree one less. On every assignment where $h\neq0$, at least one of the two choices for $x_u$ makes $g\neq0$. Induction proves the bound.

5.2. Simultaneously determining all small spans

For one variable, list all local Boolean functions with at most $k$ parents; there are at most $C$ choices.

Consider every linear span generated by at most $2b$ such functions. There are at most $C^{2b}$ spans, using repetition and the zero function to pad lists.

For a span, let $j$ be its dimension minus the rank of the evaluations already selected. Define the integer potential
$$ \Phi=\sum_{\text{spans}}(2^j-1). $$

When $j>0$, its evaluation kernel contains a nonzero degree-at-most-$k$ polynomial. A uniformly random context increases the evaluation rank with probability at least $2^{-k}$. Such an increase reduces that span’s contribution by $2^{j-1}$. Therefore
$$ \mathbb E[\Phi_{\mathrm{new}}] \leq (1-2^{-k-1})\Phi. $$

Choose, by exhaustive search over contexts, a context attaining at most this expectation. Initially,
$$ \Phi\leq C^{2b}2^{2b}. $$
After
$$ O\bigl(2^k b\log(2C)\bigr) $$
contexts, the potential is below $1$, hence zero.

The resulting evaluations are injective on every span generated by at most $2b$ local functions. The difference of two mixtures with at most $b$ types belongs to one such span at each variable. Consequently these queries determine the aggregate uniquely.

Combining this with Section 1 gives
$$ Q(n,k,b) \leq n\min\left\{ d_k,\; O\bigl(2^k b\log(2C)\bigr) \right\}. $$

For fixed $k\geq1$,
$$ Q(n,k,b) = O\left(n\min\{n^k,b\log(n+1)\}\right). $$

6. Query lower bounds and tight regimes

All lower bounds below concern deterministic exact reconstruction.

6.1. Universal-set lower bound

Run the learner on the parentless all-zero type.

Fix a variable $v$, a $k$-element set $P$ of other variables, and an assignment $a$ on $P$. There is an admissible single type differing only at $v$, whose local function is the indicator of $y[P]=a$. Its graph is an acyclic star, and all its parents are essential.

Unless a query at $v$ realizes assignment $a$, this alternative gives the same transcript. Therefore the queried contexts for every variable must form a universal set, giving
$$ Q(n,k,b)\geq n\mathcal U_k. $$

For $k=0$, $\mathcal U_0=1$, so Section 1 gives the exact count $n$. For $k=n-1$, $\mathcal U_{n-1}=2^{n-1}$, giving the exact count $D$ for every $b$.

6.2. A counting lower bound with one hidden type

For $k\geq1$, order variables $1,\ldots,n$. Let variable $1$ be parentless. For each $i\geq2$, independently select one parent from $\{1,\ldots,i-1\}$, and use the local function equal to that parent’s value.

These are $(n-1)!$ distinct admissible types with distinct aggregate functions. Every response is binary. A deterministic decision tree distinguishing them therefore has depth at least
$$ \log_2((n-1)!)=\Omega(n\log n). $$

This bound applies for every supplied $b\geq1$, on inputs with $\tau=1$.

Together with Section 5, it proves that for fixed $k\geq1$ and fixed $b$,
$$ Q(n,k,b)=\Theta(n\log n). $$

6.3. One hidden type remains easy even when $b$ is large

Let
$$ d=\min\{2k,n-1\}. $$
Query, at each variable, a universal set for assignments on $d$ coordinates.

Any two local Boolean functions with at most $k$ parents that agree on this set agree everywhere: their combined dependency set has size at most $d$, and every assignment on that set appears.

Suppose all acquired responses are $0$ or $1$. Positivity forces every component to have the same local response on every queried context. Thus all components have identical local functions everywhere.

The no-dummy-parent condition makes each local function’s essential variables its unique parent set. Therefore all components are the same type. Since hidden types are distinct, this certifies $\tau=1$.

For fixed $k$, the universal set can have $O(\log(n+1))$ contexts and can be constructed in polynomial time. Here is a deterministic construction. Maintain the uncovered pairs consisting of a $d$-coordinate set and an assignment on it. A random context covers a $2^{-d}$ fraction in expectation. Choose its coordinates successively by conditional expectation, preserving that expected coverage. Each selected context removes at least a $2^{-d}$ fraction of uncovered pairs. There are at most
$$ 2^d\binom{n-1}{d} $$
pairs, so $O(2^d d\log(n+1))$ contexts suffice. For fixed $d$, enumerating these pairs and performing the conditional-expectation calculations is polynomial-time.

If the test certifies one type, enumerate the at most $C$ local candidates at each variable and find the unique matching function. Write its essential parents and table. The promise guarantees acyclicity.

If a fractional response appears, continue with a general reconstruction algorithm.

Thus, without being told $\tau$, the learner has polynomial bit time and $O(n\log n)$ queries on all $\tau=1$ inputs for fixed positive $k$. Section 6.2 supplies the matching lower bound.

6.4. Two hidden types can require all $D$ queries

Assume
$$ b\geq D+1. $$

Consider the constant oracle
$$ q_v(y)=\frac12 $$
at every variable and context. It is represented by two parentless types: the all-zero and all-one local preference vectors, each with weight $1/2$. Thus $\tau=2$ and $L=O(1)$.

Suppose the learner makes fewer than $D$ queries on this oracle. The degree-at-most-$k$ aggregate space has dimension $D$, so the queried evaluations have a nonzero rational kernel direction
$$ h=\sum_i\alpha_i e_i, $$
where $e_i$ denotes one aggregate monomial basis vector.

For each $e_i$, there is an admissible type $N_i$ having precisely that monomial as its only nonzero local function. Its complement $\overline N_i$, obtained by complementing every local Boolean function, is also admissible. Write $\mathbf1$ for the constant-one aggregate vector.

Set
$$ A=\sum_i|\alpha_i|, \qquad S=\sum_i\alpha_i, $$
and choose a positive rational $\delta$ with $\delta A<1/2$. Give:

  • $N_i$ weight $\delta\alpha_i$ when $\alpha_i>0$;
  • $\overline N_i$ weight $-\delta\alpha_i$ when $\alpha_i<0$;
  • the all-one type weight

$$ \frac{1-\delta A+\delta S}{2}; $$

  • the all-zero type weight

$$ \frac{1-\delta A-\delta S}{2}. $$

The two last weights are positive because $|S|\leq A$. The weights sum to $1$, and their aggregate is
$$ \frac12\mathbf1+\delta h. $$

By the support-reduction argument in Section 4, this aggregate has a rational representation using at most $D+1$ types. It is therefore another promised oracle for the supplied $b$.

Because $h$ vanishes on the queried swaps, the transcript is unchanged, including all adaptive query choices. Because $h\neq0$, the aggregate differs somewhere. The learner’s common output cannot be valid for both oracles.

Hence it must make at least $D$ queries on the original, two-type constant oracle. Section 1 gives equality.

The alternative oracle may have larger response encodings. This does not invalidate the argument: the learner receives $n,k,b$, not $L$, and the entire observed transcript is identical.

6.5. A lower bound involving actual support size

For another parameter-dependent bound, let
$$ h=\lfloor n/2\rfloor,\qquad \ell=n-h,\qquad M_k=\binom hk, $$
and suppose $1\leq b\leq M_k$.

Use the first $h$ variables as roots. At each remaining variable, choose $b$ distinct $k$-subsets of the roots. Construct $b$ equally weighted types, assigning one selected conjunction to each type at each remaining variable.

All graphs are acyclic, all conjunction parents are essential, and the types are distinct. Thus $\tau=b$.

The aggregate at each remaining variable is
$$ \frac1b\sum_{P\text{ selected}}\prod_{u\in P}y_u. $$
Its multilinear coefficients uniquely identify the selected subsets. There are therefore
$$ \binom{M_k}{b}^{\ell} $$
distinct oracles. Every response lies in $\{0,1/b,\ldots,1\}$, so each query has at most $b+1$ possible answers on this family.

Consequently,
$$ Q(n,k,b)\geq \frac{\ell\log_2\binom{M_k}{b}}{\log_2(b+1)}. $$

This family has actual support $\tau=b$ and $L=O(\log(b+1))$.

7. Further computational bounds and polynomial cases

7.1. Parentless reconstruction is fixed-parameter tractable in $b$

For $k=0$, acquire the $n$ probabilities.

A representation with at most $b$ weights has at most $2^b$ distinct subset sums. Hence it has at most $2^b$ distinct probabilities.

For repeated probabilities, choose the same representing subset. This preserves all marginals. Apply the column-dependence elimination from Section 4 to obtain independent augmented columns.

For each $r\leq b$, enumerate:

  • $r$ rows from the distinct probability equations and the normalization equation;
  • all zero-one $r$-by-$r$ matrices on those rows.

Each nonsingular matrix determines candidate weights. Check positivity, normalization, and whether every input probability is among their $2^r$ subset sums. Successful subsets produce the types; merge duplicate types.

There are at most $2^b+1$ available rows, so the total bound is
$$ 2^{O(b^2)}\operatorname{poly}(n,b,L). $$

This strengthens the fixed-$b$ algorithm in the notes to a fixed-parameter algorithm. It is compatible with NP-hardness when $b$ varies.

7.2. Parentless reconstruction when $b\geq n+1$

Sort the distinct values in $\{0,1,p_1,\ldots,p_n\}$:
$$ 0=a_0<a_1<\cdots<a_r=1. $$
There are at most $n+1$ intervals. Set
$$ w_j=a_j-a_{j-1}. $$
In type $j$, prefer $1$ at variable $i$ precisely when $a_j\leq p_i$. Then
$$ \sum_{j:a_j\leq p_i}w_j=p_i. $$

This is a polynomial-time reconstruction respecting the supplied bound whenever $b\geq n+1$.

7.3. Reading responses and writing tables matter

For $b\geq2$, some inputs require $\Omega(nL)$ bit time just to read responses. Take every probability to be $p=2^{-a}\neq1/2$, represented by the all-zero and all-one parentless types. Unless variable $v$ is queried, changing only its probability to $1-p$ gives an indistinguishable two-type oracle. Thus every variable must be queried, and both orientations have response length $\Theta(a)$.

When $k$ varies, explicit output can also be exponential in $k$. A single type in a fixed topological order can have parent counts $\min\{k,i-1\}$, with conjunction tables making all parents essential. Its tables contain
$$ \sum_{i=1}^{n}2^{\min\{k,i-1\}} = 2^k-1+(n-k)2^k $$
entries.

Its aggregate responses are binary. Positivity forces every component of any equivalent reconstruction to have those same local functions, and essentiality forces the same parent sets. Therefore this table-size lower bound applies even when the supplied $b$ is large.

8. Proven conclusions and remaining gap

For every fixed $k$, polynomially many oracle calls suffice, while polynomial bit-time reconstruction exists exactly when $\mathrm P=\mathrm{NP}$. The hardness includes $k=0$ and $k=1$ and respects the feasibility promise.

The general unconditional computational upper bound is
$$ 2^{O\left(sn(2^k+(k+1)\log(n+1))\right)} \operatorname{poly}(n,D,2^k,b,L), \qquad s=\min\{\tau,D+1\}. $$

The query bounds are tight for parentless types, fixed positive $k$ with fixed $b$, actual support $\tau=1$ with fixed positive $k$, sufficiently large supplied support bounds, and unrestricted parent bounds.

The remaining gap is a matching query characterization for intermediate, varying $b$, including its dependence on the actual $\tau$. The two-type lower bound shows that replacing the supplied $b$ by the hidden $\tau$ in a general query bound is not valid.
