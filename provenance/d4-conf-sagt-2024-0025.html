Theorem 2 — class: algorithmic

The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), demands \(d_t\le s\), per-capita supply \(s>0\), and an integer \(k\ge1\), find the minimum integer \(q\) and a succinct schedule of \(q\) equal-duration bins. Each household must be fully served in exactly \(k\) distinct bins, and each bin’s total demand mass must be at most \(s\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Let \(\sum_t\mu_t=1\), with binary rational demands and supply satisfying \(0<d_t\le s\) and \(s>0\), and a binary encoded integer \(k\ge1\). Let \(m\) count distinct demands and \(L\) be the total input bit length.
Represent type \(t\) by an atomless interval \([0,\mu_t)\) with Lebesgue measure. Different households of the same type may receive different schedules; a connected household receives its full demand.
A feasible schedule has an integer \(q\ge k\) of bins, each lasting \(1/q\). For each bin \(j\), choose measurable sets \(A_{tj}\subseteq[0,\mu_t)\) such that every household belongs to exactly \(k\) distinct bins and \(\sum_t d_t\lvert A_{tj}\rvert\le s\). Let \(\mathrm{OPT}_k\) be the minimum feasible \(q\).
A succinct schedule partitions each type interval into finitely many intervals with rational endpoints and assigns each interval a set of exactly \(k\) bin indices, encoded as disjoint ranges with binary integer endpoints.

Does a polynomial-time algorithm, with running time measured in \(m,\tau,L\), always produce a succinct feasible schedule satisfying \(q\le\left(\frac32+\frac{1}{5k}\right)\mathrm{OPT}_k+3k\), or is achieving this guarantee NP-hard?

For discrete households, First-Fit applied to \(k\) consecutive copies of the household list, forbidding repeated copies of a household in one bin, achieves this same bound; exact optimization is NP-hard already for \(k=1\). [Verified discrete results](https://arxiv.org/html/2311.16742v3)
No result settling this precise atomless scheduling guarantee was located.

Modeling choices made when packaging the task

  • Demands lacked a lower bound and an encoding convention; require positive binary rational demands, following the discrete positive-size domain, and binary rational supply.
  • Interpret each positive type mass as an atomless population whose households may receive different schedules, while each household receives its full demand whenever connected.
  • Normalize the scheduling horizon to one, so every bin lasts 1/q.
  • Define a succinct schedule using rational interval partitions and sets of bin indices compressed into binary encoded ranges.
  • Encode k in binary; define m as the number of distinct demands and L as the total input bit length.

2. Complete proof and polynomial-time construction

Choose \(q=k\), and set \(A_{tj}=[0,\mu_t)\) for every type \(t\) and every bin \(j\in\{1,\ldots,k\}\).

Every household belongs to exactly \(k\) distinct bins. Each bin has load \(\sum_t d_t|A_{tj}|=D\le s\), so this schedule is feasible.

Conversely, every feasible schedule must have \(q\ge k\) by definition. Therefore \(\mathrm{OPT}_k=k\).

The succinct output consists of one interval \([0,\mu_t)\) for each type, assigned the single inclusive bin range \([1,k]\). Its rational endpoints already occur in the input, and its bin endpoints require \(O(\log(k+1))\) bits. The total output length is \(O(L+\tau\log(k+1))\), and constructing it takes polynomial time in \(m,\tau,L\), even when \(k\) is exponentially large in its bit length.

Since the algorithm is exact, it satisfies the requested inequality
\[ q\le\left(\frac32+\frac{1}{5k}\right)\mathrm{OPT}_k+3k. \]

The discrete hardness result in the [referenced paper](https://arxiv.org/html/2311.16742v3) concerns indivisible households. It does not establish hardness for this atomless model.

3. Proven extension: exact atomless feasibility with scarce supply

The following result addresses the nontrivial case obtained by relaxing the assumptions that force \(D\le s\).

Proposition. Suppose there are finitely many types with positive rational masses and demands, and positive rational supply \(s\). For a given integer \(q\), an atomless schedule is feasible if and only if \(q\ge k\) and \(qs\ge kD\), where \(D=\sum_t\mu_t d_t\). Consequently,
\[ \mathrm{OPT}_k=\max\left\{k,\left\lceil\frac{kD}{s}\right\rceil\right\}. \]

Necessity. Every household belongs to exactly \(k\) bins. Integrating this identity over each type gives \(\sum_{j=1}^q|A_{tj}|=k\mu_t\). Summing the bin loads therefore yields
\[ kD=\sum_{j=1}^q\sum_t d_t|A_{tj}|\le qs. \]
The condition \(q\ge k\) is also necessary.

Sufficiency. Assume \(q\ge k\) and \(qs\ge kD\). Order the types and define \(W_0=0\) and \(W_t=\sum_{u=1}^t\mu_ud_u\). Map household \(x\in[0,\mu_t)\) to its demand coordinate \(y=W_{t-1}+d_tx\). These maps partition \([0,D)\), and demand-weighted measure \(d_t\,dx\) becomes ordinary length \(dy\).

Partition \([0,D)\) into the \(q\) half-open cells
\[ C_r=\left[\frac{rD}{q},\frac{(r+1)D}{q}\right),\qquad r\in\{0,\ldots,q-1\}. \]
For every household whose coordinate lies in \(C_r\), assign the bin set
\[ B_r=\left\{1+((r+h)\bmod q):h\in\{0,\ldots,k-1\}\right\}. \]

Because \(k\le q\), these are exactly \(k\) distinct bins. For each bin \(j\), precisely \(k\) cells have \(j\in B_r\): their indices are the distinct residues \(r\equiv j-1-h\pmod q\), with \(h\in\{0,\ldots,k-1\}\). Each cell has demand-weighted measure \(D/q\). Thus every bin has load \(kD/q\le s\), proving feasibility.

This construction also gives a finite rational schedule. Intersect the type-coordinate intervals \([W_{t-1},W_t)\) with the cells, then map those intersections back to household coordinates. All resulting endpoints are rational. Each \(B_r\) is a cyclic block of consecutive indices, so it is encoded by at most two disjoint ranges.

There are at most \(\tau+q-1\) nonempty pieces: the combined partition of \([0,D)\) has at most \(\tau-1\) internal type boundaries and \(q-1\) internal cell boundaries. This completes the proof.

4. Output size matters in the relaxed problem

The proposition does not automatically give a polynomial-size schedule when the original restrictions are removed.

For example, retain normalized mass but drop \(d_t\le s\). Take one type with \(\mu_1=1\), demand \(d_1=2^n\), supply \(s=1\), and \(k=1\). The input length is \(O(n)\).

Every interval in a succinct schedule is assigned to one bin. If its length is \(\ell\), that bin’s capacity implies \(2^n\ell\le1\), hence \(\ell\le2^{-n}\). Partitioning the unit type interval therefore requires at least \(2^n\) nonempty intervals, regardless of the number of bins used.

Thus this natural scarce-supply extension has an exponential output-size obstruction. Under the actual premises, Section 2 avoids that obstruction and completely resolves the requested guarantee.
