The continuous mirror question, as graded

Given a finite candidate set \(C\) of unit-cost projects, budget \(k\), audited committee \(W\subseteq C\), and finite approval-type support \(T\) with rational masses \(\mu_t\ge0\) summing to \(1\), where type \(t\) approves \(A_t\subseteq C\), define \(u_t(D)=|A_t\cap D|\) and \(M_\mu(D;W)=\sum_{t:u_t(D)>u_t(W)}\mu_t\). Ask for the exact value, or an \(\alpha\)-approximation, of \(\theta_c^\infty(W)=\inf_{D\subseteq C:M_\mu(D;W)>0}|D|/(kM_\mu(D;W))\); equivalently, decide or approximate whether some integral committee \(D\) satisfies \(|D|\le\theta kM_\mu(D;W)\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\ge1\) unit-cost projects, let \(k>0\) be a binary rational budget, and let the audited committee \(W\subseteq C\) satisfy \(|W|\le k\).
A society is given by its support: the list of \(\tau\) approval types with positive binary rational masses \(\mu_t\) summing to \(1\), each specified by \(A_t\subseteq C\). Empty approval sets are allowed. Here \(\tau\) is the support size, not the number of possible approval sets; \(L\) is the total input bit length.
Types have approval utilities \(u_t\). Coalitions may take any fraction of each type's mass; a coalition of mass \(s\) has entitlement \(ks\). Projects remain indivisible.
For an integral committee \(D\subseteq C\), define \(M_\mu(D;W)=\sum_{t:u_t(D)>u_t(W)}\mu_t\) and \(\theta_c^\infty(W)=\inf_{D\subseteq C:M_\mu(D;W)>0}|D|/(kM_\mu(D;W))\). No separate constraint \(|D|\le k\) is imposed, and the infimum of the empty set is \(+\infty\).
For finite optimum, a multiplicative \(\alpha\)-approximation returns an integral \(D\) with positive improving mass and ratio at most \(\alpha\theta_c^\infty(W)\); instances with infinite optimum must be identified.

For each fixed \(0<\gamma<1/e\), is approximating \(\theta_c^\infty(W)\) within \(1+1/e-\gamma\) possible in time polynomial in \(m,\tau,L\), or is this approximation problem NP-hard?

For explicitly listed discrete voters, approximation within \(1+1/e-\gamma\) is NP-hard, while a polynomial-time \(O(\min(\log m,\log n))\)-approximation is known, where \(n\) is the voter count ([Munagala, Shen and Wang](https://arxiv.org/pdf/2209.14468)). No result explicitly treating the rational-support mass formulation was located.

Modeling choices made when packaging the task

  • Specified a positive binary rational budget and required the audited committee to satisfy its budget, as in the discrete definition.
  • Discarded zero-mass entries so that the input lists exactly the positive-mass support; retained empty approval sets, which the discrete construction permits.
  • Made coalition mass divisible within each approval type while retaining integral project selection.
  • Clarified that deviating committees have no independent budget cap, since the auditing ratio allows entitlement scaling beyond one.
  • Defined the empty infimum as positive infinity and restricted multiplicative approximation guarantees to finite optima.
  • Specified approximation by a feasible deviating committee and restricted γ to the range giving an approximation factor greater than one.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed \(0<\gamma<1/e\), approximating \(\theta_c^\infty(W)\) within \(1+1/e-\gamma\) is NP-hard. The discrete-voter hardness transfers through a polynomial-time reduction that preserves every committee’s objective value exactly.

Throughout, approval utility means \(u_t(D)=|A_t\cap D|\).

1. Fractional coalitions do not change the objective

Fix an integral committee \(D\subseteq C\), and define its improving types by
\[ I(D)=\{t:u_t(D)>u_t(W)\}. \]

A coalition whose members all strictly improve with \(D\) can select masses \(x_t\) satisfying
\[ 0\le x_t\le\mu_t\quad(t\in I(D)),\qquad x_t=0\quad(t\notin I(D)). \]
Consequently, its mass \(s=\sum_t x_t\) satisfies
\[ s\le\sum_{t\in I(D)}\mu_t=M_\mu(D;W). \]
Equality is attained by taking the entire mass of every improving type.

If \(M_\mu(D;W)>0\), then \(D\ne\varnothing\), because the empty committee gives every type utility zero. Thus, for every such coalition of positive mass,
\[ \frac{|D|}{ks}\ge \frac{|D|}{kM_\mu(D;W)}. \]
The right-hand side is attained by the coalition consisting of all improving types. Hence allowing arbitrary fractions of types does not yield a smaller ratio for any fixed committee.

2. The discrete hardness theorem applies to this ratio

Consider an explicitly listed discrete election with voters \(i\in\{1,\ldots,n\}\), approval sets \(B_i\subseteq C\), budget \(k>0\), and audited committee \(|W|\le k\). Write
\[ H(D)=\{i:|B_i\cap D|>|B_i\cap W|\}. \]

The discrete core-auditing objective is
\[ \theta_{\mathrm{disc}}(W)= \min_{\substack{D\subseteq C\\H(D)\ne\varnothing}} \frac{n|D|}{k|H(D)|}, \]
with value \(+\infty\) when no committee improves any voter.

Indeed, for a fixed \(D\), the admissible discrete coalitions are the nonempty subsets of \(H(D)\); taking all of \(H(D)\) minimizes the ratio.

Section 2 of Munagala, Shen and Wang gives precisely this optimization program, without an additional constraint \(|D|\le k\). Their Theorem 3.2 states that, for every constant \(\gamma>0\), approximating its value within \(1+1/e-\gamma\) is NP-hard, already for unit-cost projects and approval utilities. These hypotheses match the discrete instances used here. [Source: *Auditing for Core Stability in Participatory Budgeting*, Section 2 and Theorem 3.2](https://arxiv.org/pdf/2209.14468).

3. An objective-preserving reduction to rational support

Given such a discrete instance, retain \(C\), \(k\), and \(W\). Group voters having identical approval sets. For each distinct approval set \(A_t\), let
\[ f_t=|\{i:B_i=A_t\}|,\qquad \mu_t=\frac{f_t}{n}. \]

This is a valid support instance: each \(f_t\) is positive, each \(\mu_t\) is a positive rational, and
\[ \sum_{t=1}^{\tau}\mu_t =\frac{\sum_{t=1}^{\tau}f_t}{n} =1. \]
Empty approval sets are retained when present. Project costs and audited-committee feasibility are unchanged.

The construction is polynomial-time. Identical approval sets can be grouped by sorting their encodings. There are at most \(n\) resulting types; each mass has numerator and denominator requiring \(O(\log n)\) bits. Copying each distinct approval set once and adding these masses therefore produces an instance of polynomial bit length in the explicitly listed input.

For every \(D\subseteq C\), all voters grouped into one type have the same improvement status. Therefore
\[ M_\mu(D;W) =\sum_{t:|A_t\cap D|>|A_t\cap W|}\frac{f_t}{n} =\frac{|H(D)|}{n}. \]
In particular, positive improving mass is equivalent to \(H(D)\ne\varnothing\). Whenever these conditions hold,
\[ \frac{|D|}{kM_\mu(D;W)} =\frac{n|D|}{k|H(D)|}. \]

Thus the feasible committees and their objective values coincide exactly:
\[ \theta_c^\infty(W)=\theta_{\mathrm{disc}}(W). \]
This also preserves infinite optimum.

4. Approximation transfer and infinite instances

Fix \(0<\gamma<1/e\), and put \(\alpha=1+1/e-\gamma\). Suppose a polynomial-time \(\alpha\)-approximation existed for the rational-support problem.

Apply the reduction above to any discrete instance and run that algorithm. On a finite instance, its returned committee \(D\) would satisfy
\[ \frac{n|D|}{k|H(D)|} =\frac{|D|}{kM_\mu(D;W)} \le\alpha\theta_c^\infty(W) =\alpha\theta_{\mathrm{disc}}(W). \]
If a discrete coalition is required, return \(H(D)\). Its members all strictly improve. On an infinite instance, the algorithm’s identification of infinity is also correct for the discrete instance. Its running time remains polynomial in the discrete input length.

This would give the approximation ruled out by Theorem 3.2. Hence the rational-support approximation problem is NP-hard.

For completeness, infinite optimum itself is easy to recognize:
\[ \theta_c^\infty(W)=+\infty \quad\Longleftrightarrow\quad A_t\subseteq W\text{ for every }t. \]
If every \(A_t\subseteq W\), then \(u_t(D)\le |A_t|=u_t(W)\) for every committee. Conversely, if some \(A_t\not\subseteq W\), then \(D=C\) strictly improves that positive-mass type, giving a finite ratio. Checking these inclusions takes polynomial time.
