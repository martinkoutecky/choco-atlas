The continuous mirror question, as graded

Given schools \(S\), a finite set of complete applicant profiles \(\Theta\), rational masses \(\mu_\theta\), school capacities \(q_s\), and reserves \(r_{s,g}\), find a mass assignment \(x_{\theta s}\geq 0\) with \(\sum_s x_{\theta s}=\mu_\theta\) and \(\sum_\theta x_{\theta s}\leq q_s\). Require that whenever \(x_{\theta d}>0\) and profile \(\theta\) prefers \(s\) to \(d\), the mass of group \(g(\theta)\) at \(s\) is at least \(r_{s,g(\theta)}\), and \(s\) is full. Each profile specifies a group, a school preference order, and a priority tier at each school; ties within a tier do not count as violations. Minimize the mass assigned to schools for which the corresponding profile prefers some school where positive mass of a lower-priority tier is admitted.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) complete types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=|S|\ge2\) schools. Each type specifies a strict complete preference ranking \(P_t\) over all schools, one diversity group \(g(t)\in G=g(T)\), and school-specific integer priority bands \(\pi_s(t)\); larger bands mean higher priority. Equal bands are tied, with no tie-breaking and no violation between tied types.
Capacities \(q_s\ge0\), reserves \(r_{s,g}\ge0\), and threshold \(B\) are binary rationals, with \(\sum_s q_s\ge1\) and \(\sum_{g\in G}r_{s,g}\le q_s\) for every school. There are no group-specific upper quotas. Let \(L\) be the total input bit length.
An assignment consists of divisible real masses \(x_{t,s}\ge0\) satisfying \(\sum_s x_{t,s}=\mu_t\) and \(\sum_t x_{t,s}\le q_s\).
Reserves-respecting, non-wastefulness, and within-group priority compatibility mean that whenever \(x_{t,s'}>0\) and \(sP_t s'\), respectively, \(\sum_{u:g(u)=g(t)}x_{u,s}\ge r_{s,g(t)}\), \(\sum_u x_{u,s}=q_s\), and \(x_{u,s}=0\) for every \(u\) with \(g(u)=g(t)\) and \(\pi_s(u)<\pi_s(t)\). Reserves are thus conditional soft lower bounds.
Define \(V(x)=\sum_{t\in T,\,s'\in S}x_{t,s'}\mathbf{1}\{\exists s\in S,\,u\in T:\ sP_t s',\ x_{u,s}>0,\ \pi_s(u)<\pi_s(t)\}\), counting each affected mass portion once regardless of how many schools or types witness a violation.

Is deciding whether such an assignment exists with \(V(x)\le B\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,|G|\), and \(L\).

For finite indivisible applicants with strict priorities, minimizing the number of applicants whose priority is violated among reserves-respecting, non-wasteful, within-group priority-compatible assignments is \(\mathrm{NP}\)-hard ([Abdulkadiroğlu–Grigoryan, 2021](https://www.nber.org/system/files/working_papers/w28689/w28689.pdf)).
No result settling this exact mass decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Restored the multiple-school and nonempty-society domains: at least two schools and at least one positive-mass support type.
  • Specified strict complete preferences over all schools and restored sufficient total capacity, normalized to total mass one.
  • Specified nonnegative capacities and reserves, restored the bound that total reserves at each school cannot exceed its capacity, and excluded group-specific upper quotas.
  • Interpreted complete types as recording preferences, one diversity group, and every school's priority band; only represented groups are included in G.
  • Retained the graded question's priority bands: larger integer bands mean higher priority, ties are allowed, and equal-band mass neither violates priority nor requires tie-breaking.
  • Specified assignment variables as divisible real masses and L as the total encoded input bit length.

1. Classification

The decision problem is \(\mathrm{NP}\)-complete, even without priority ties.

The key is a rounding lemma: with integer supplies, capacities, and reserves, every admissible fractional assignment has an admissible integer replacement whose violation objective is no larger. This permits a rigorous transfer of the finite hardness result stated in the question.

Here, admissible means feasible, reserves-respecting, non-wasteful, and within-group priority-compatible.

2. A rounding lemma

For this section, allow unnormalized integer supplies \(a_t>0\), integer capacities \(c_s\ge0\), and integer reserves \(h_{s,g}\ge0\). Define the objective by the same formula as \(V\), counting affected units of mass.

Lemma. Given an admissible real assignment \(x\), there exists an admissible integer assignment \(y\) such that

\(\operatorname{supp}(y)\subseteq\operatorname{supp}(x)\quad\text{and}\quad V(y)\le V(x).\)

Fixing the support

Write

\(H=\{(t,s'):x_{t,s'}>0\}.\)

Define the reserve-trigger indicator

\(d_{s,g}(H)=\mathbf 1\{\exists(t,s')\in H:\ g(t)=g,\ sP_t s'\},\)

and the fullness-trigger indicator

\(d_s(H)=\mathbf 1\{\exists(t,s')\in H:\ sP_t s'\}.\)

Finally, define a fixed cost for each type–school pair:

\(b_{t,s'}(H)=\mathbf 1\{\exists s,u:\ sP_t s',\ (u,s)\in H,\ \pi_s(u)<\pi_s(t)\}.\)

Because \(H\) is the actual support of \(x\),

\(V(x)=\sum_{t,s'}b_{t,s'}(H)x_{t,s'}.\)

The coefficients are indicators, so this expression counts each affected portion once.

The flow network

Construct a circulation network with a source node \(o\), a sink node \(z\), one node for each type, one node \(v_{s,g}\) for each school–group pair, and one node \(w_s\) for each school. Put \(A=\sum_t a_t\).

Use the following arcs; all costs not explicitly specified are zero.

| Arc | Lower bound | Upper bound | Cost |
|---|---:|---:|---:|
| \(o\to t\) | \(a_t\) | \(a_t\) | \(0\) |
| \(t\to v_{s,g(t)}\), only when \((t,s)\in H\) | \(0\) | \(a_t\) | \(b_{t,s}(H)\) |
| \(v_{s,g}\to w_s\) | \(d_{s,g}(H)h_{s,g}\) | \(c_s\) | \(0\) |
| \(w_s\to z\) | \(d_s(H)c_s\) | \(c_s\) | \(0\) |
| \(z\to o\) | \(A\) | \(A\) | \(0\) |

The assignment \(x\) induces a feasible circulation:

  • Type conservation follows from its prescribed supplies.
  • School upper bounds follow from feasibility.
  • Every triggered group lower bound follows from reserves-respectingness.
  • Every triggered school equality follows from non-wastefulness.

Thus the network is feasible.

All arc bounds are integers. Its feasible circulation polytope is bounded and has integral vertices. For completeness, suppose a vertex had a noninteger arc flow. At every node incident with a noninteger arc, there must be at least two such incident arcs: flow conservation cannot balance exactly one noninteger contribution against integer contributions. Consequently, the undirected graph of noninteger arcs contains a cycle. Every arc on that cycle lies strictly between its integer bounds. A sufficiently small signed perturbation around the cycle in either direction preserves conservation and all bounds, expressing the alleged vertex as the midpoint of two distinct feasible circulations—a contradiction.

A linear cost therefore attains its minimum at an integral circulation. Let \(y_{t,s}\) be the resulting type–school arc flows. Since the circulation induced by \(x\) was feasible,

\(\sum_{t,s}b_{t,s}(H)y_{t,s}\le \sum_{t,s}b_{t,s}(H)x_{t,s}=V(x).\)

Preservation of admissibility and the objective

The network ensures feasibility and \(\operatorname{supp}(y)\subseteq H\).

If a positive portion of \(y\) desires school \(s\), the same type–school pair belongs to \(H\). Therefore the relevant fullness and reserve requirements were triggered in the network, which enforces them for \(y\).

Within-group priority compatibility also survives. If a positive portion of \(y\) desired a school containing a positive lower-priority same-group portion, both positive pairs would belong to \(H\), contradicting compatibility of \(x\).

Finally, removing support pairs cannot introduce a violation witness. Hence

\(b_{t,s}(\operatorname{supp}(y))\le b_{t,s}(H)\)

for every pair, and therefore

\(V(y)\le\sum_{t,s}b_{t,s}(H)y_{t,s}\le V(x).\)

This proves the lemma. Its argument uses strictly lower priority throughout, so it also covers tied bands.

3. Reduction from the finite problem

Use the threshold form of the finite hardness result supplied in the question: for explicitly listed indivisible applicants with strict preferences and strict school priorities, deciding whether an admissible assignment violates the priorities of at most \(K\) applicants is \(\mathrm{NP}\)-hard. The cited proof gives a reduction from Complete Bipartite Subgraph. [Abdulkadiroğlu–Grigoryan, Theorem 4 and Appendix A.5](https://www.nber.org/system/files/working_papers/w28689/w28689.pdf).

Take such a finite instance with \(N\ge1\) applicants, \(M\) schools, integer capacities \(c_s\), and integer reserves \(h_{s,g}\). All applicants are assigned, preferences are complete, and \(\sum_s c_s\ge N\).

The construction below uses dyadic rationals, so it works even under that narrower interpretation of “binary rational.”

Construction

Let \(D\) be the smallest power of two strictly larger than \(N\). Thus

\(N<D\le2N.\)

Create one support type \(t_a\) for each original applicant \(a\), with:

  • mass \(\mu_{t_a}=1/D\);
  • the original diversity group;
  • the original school preferences;
  • priority bands representing the original strict priority orders.

At every original school, give the original applicants distinct bands \(1,\ldots,N\), with larger bands representing higher priority.

Add one school \(d\), one new diversity group \(g_0\), and one filler type \(f\). Set

\(\mu_f=(D-N)/D,\qquad q_d=r_{d,g_0}=(D-N)/D.\)

All other reserves at \(d\) are zero. At original schools, set

\(q_s=c_s/D,\qquad r_{s,g}=h_{s,g}/D,\qquad r_{s,g_0}=0.\)

Original types place \(d\) last. The filler ranks \(d\) first and ranks the original schools arbitrarily afterward. Give the filler band \(0\) at every school, and give original types distinct bands \(1,\ldots,N\) at \(d\). Thus there are no ties.

Set the threshold to

\(B=K/D.\)

All masses are positive and sum to one. Moreover,

\(\sum_s q_s=\bigl(\sum_{s\text{ original}}c_s+D-N\bigr)/D\ge1,\)

and reserve sums respect capacities at every school. The complete types are distinct because the original priorities are strict.

The resulting parameters are

\(\tau=N+1,\qquad m=M+1,\qquad |G|=|G_{\mathrm{original}}|+1.\)

The construction has polynomial output bit length and takes polynomial time in the finite instance’s input length.

The filler is forced

Suppose \(f\) received positive mass outside \(d\). Since it ranks \(d\) first, reserves-respectingness would require

\(x_{f,d}\ge r_{d,g_0}=\mu_f.\)

Only \(f\) belongs to \(g_0\). The displayed inequality contradicts positive assignment of some of its mass elsewhere. Hence all filler mass goes to \(d\).

It fills \(d\) completely, so original types receive no mass there. The filler has no preferred school above its assignment, and original types never prefer \(d\) to their assignments. Consequently, the added school and type contribute no violations.

Equivalence

If the finite instance has an admissible assignment with at most \(K\) affected applicants, assign each original type its corresponding mass \(1/D\) and place the filler at \(d\). Scaling all original constraints by \(1/D\) preserves admissibility, and

\(V(x)=\frac{\text{number of affected original applicants}}{D}\le B.\)

Conversely, suppose the mass instance has an admissible assignment with \(V(x)\le B\). Remove the forced filler and multiply all remaining masses by \(D\). This gives an admissible real assignment \(\widehat x\) for the original instance, with one unit supplied by each applicant and

\(V(\widehat x)=D\,V(x)\le K.\)

Apply the rounding lemma. The resulting assignment is integral, admissible, and has objective at most \(K\). Each applicant supplies exactly one unit, so integrality assigns each applicant to exactly one school. Its objective is precisely the number of applicants whose priority is violated.

Thus the finite instance is a yes-instance exactly when the constructed mass instance is a yes-instance. This proves \(\mathrm{NP}\)-hardness.

4. Membership in NP

Choose a common denominator \(D_0\) for all supplies, capacities, and reserves. For example, take the product of their encoded denominators. Under binary rational encoding,

\(\log D_0=O(L).\)

If a feasible real assignment \(x\) satisfies the threshold, multiplying it by \(D_0\) gives integer supplies, capacities, and reserves. The rounding lemma gives an admissible integer assignment \(z\) with

\(V(z)\le D_0V(x)\le D_0B.\)

Consequently, every yes-instance has a certificate

\(y_{t,s}=z_{t,s}/D_0,\qquad 0\le z_{t,s}\le D_0.\)

Its total encoding length is \(O(m\tau L)\).

Verification is polynomial. More explicitly, compute school and school–group totals, together with the minimum occupied priority band at each school and within each school–group pair; use \(+\infty\) for an empty set.

For each type, find the worst-ranked school receiving positive mass. Exactly the schools ranked above it trigger that type’s conditional requirements. These requirements can therefore be checked by scanning its complete ranking.

A second scan computes the violation indicator for every assigned portion: maintain whether an earlier school has minimum occupied band strictly below the type’s band there. Summing the flagged portions evaluates \(V\) exactly.

These scans use \(O(m\tau+m|G|)\) arithmetic and comparison operations. Including denominator construction and ordinary binary arithmetic, a conservative verification bound is

\(O\bigl((m\tau+m|G|+L)L^2\bigr).\)

Thus the problem belongs to \(\mathrm{NP}\). Together with Section 3, it is \(\mathrm{NP}\)-complete.

5. An exact running-time bound

There is also an exact algorithm with running time

\(2^{m\tau}\bigl(m\tau+m|G|+L\bigr)^{O(1)}\)

and polynomial space.

Enumerate every candidate support \(H\subseteq T\times S\). Discard \(H\) if it contains a within-group forbidden configuration: pairs \((t,s'),(u,s)\in H\) with \(sP_t s'\), \(g(u)=g(t)\), and \(\pi_s(u)<\pi_s(t)\).

For each remaining \(H\), construct the network from Section 2 after multiplying rational quantities by \(D_0\), and minimize its linear cost. Accept if some feasible network has minimum cost at most \(D_0B\).

Soundness follows because every resulting assignment uses a subset of \(H\), satisfies its triggered requirements, and has actual violation objective bounded above by the network cost. Completeness follows by choosing the actual support of any witnessing assignment.

Each network has

\(O(\tau+m|G|+m)\)

vertices and

\(O(m\tau+m|G|)\)

arcs. Its numbers have \(O(L)\) bits, so each minimum-cost circulation takes polynomial bit time. No expansion into \(D_0\) individual applicants is needed.

Therefore a running time polynomial in \(m,\tau,|G|,L\) for the general decision problem would imply \(\mathrm{P}=\mathrm{NP}\).
