Theorem 15 — class: other

The continuous mirror question, as graded

Given a finite type set \(T\) with rational masses \(\mu_t>0\), \(\sum_{t\in T}\mu_t=1\), a sector map \(\sigma:T\to\mathcal{S}\), symmetric rational link densities \(w_{tu}\in[0,1]\), and \(\alpha,\beta\geq 0\), consider dense regular simple-graph sequences realizing those type proportions and link densities. For each type \(t\), determine the limiting per-firm power \(p_t=\lim_{n\to\infty}\varphi_i^{(\alpha,\beta)}(E_n,\Pi_n)/n\) for vertices \(i\) of type \(t\), where \(D_{t,A}=\sum_{v:\sigma(v)=A}\mu_v w_{tv}\), \(D_t^{\mathrm{ext}}=\sum_{v:\sigma(v)\ne\sigma(t)}\mu_v w_{tv}\), and \(p_t=\alpha D_t^{\mathrm{ext}}+\beta\sum_{u:\sigma(u)\ne\sigma(t)}\mu_u w_{tu}\,D_u^{\mathrm{ext}}/D_{u,\sigma(t)}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau=|T|\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types.
Input also includes a surjection \(\sigma:T\to\mathcal S\), with \(m=|\mathcal S|\geq2\), symmetric binary rational densities \(w_{tu}\in[0,1]\), and binary rational coefficients \(\alpha,\beta\geq0\). Let \(L\) be the total input bit length.
A realizing sequence consists of simple undirected graphs \(G_n=(N_n,E_n)\), with \(|N_n|=n\to\infty\), type classes \(V_t^{(n)}\), and sectors \(S_A^{(n)}=\bigcup_{\sigma(t)=A}V_t^{(n)}\). Require \(|V_t^{(n)}|/n\to\mu_t\) and \(\max_{i\in V_t^{(n)}}|d_i(V_u^{(n)})/n-\mu_u w_{tu}|\to0\) for every \(t,u\); blocks with \(w_{tu}=0\) contain no edges. Here \(d_i(B)\) counts neighbors in \(B\).
For a finite realization, write \(S^i\) for the sector of \(i\) and define \(\varphi_i=\alpha d_i(N_n\setminus S^i)+\beta\sum_{j\in N(i)\setminus S^i}d_j(N_n\setminus S^i)/d_j(S^i)\), with an empty sum equal to zero.
The associated TU-game has \(\nu(C)=\sum_{A\in\mathcal S}[\alpha\sum_{i\in C\cap S_A}d_i(N_n\setminus S_A)+\beta\sum_{j\in N(C\cap S_A)\setminus S_A}d_j(N_n\setminus S_A)]\), where \(N(B)\) is the union of the neighborhoods of vertices in \(B\).

Do the limits \(p_t=\lim_{n\to\infty}\varphi_{i_n}/n\) exist and depend only on the input type data for every realizing sequence and every choice \(i_n\in V_t^{(n)}\)? If so, is deciding \(p_t\geq q\), for an input type \(t\) and binary rational threshold \(q\), in \(\mathsf P\) or \(\mathsf{NP}\)-hard? State running times in \(m,\tau,L\).

For finite graphs, the Shapley value of \(\nu\) equals \(\varphi\). [Verified source](https://arxiv.org/html/2507.13272v1).
That finite identity does not establish the realization-independent limits or the complexity of the continuous problem; no continuous result is asserted here.

Result

Yes. The limits exist for every realizing sequence, are independent of the chosen vertices, and are rational functions of the input data. Deciding \(p_t\ge q\) is in \(\mathsf P\), with an exact algorithm using \(O(\tau^2L^2)\) bit operations. Here \(L\) includes the query type and threshold. Since the sector map is surjective, \(m\le\tau\).

The supplied finite identity appears as Theorem 15 of the [cited paper](https://arxiv.org/html/2507.13272v1). The limit and complexity arguments below follow directly from the hypotheses in the question.

1. Formula for the limits

For a type \(u\) and sector \(A\), define

\[ a_{uA}:=\sum_{\sigma(v)=A}\mu_vw_{uv}, \qquad b_{uA}:=\sum_{\sigma(v)\ne A}\mu_vw_{uv}. \]

Thus these quantities describe normalized degrees into and outside \(A\), respectively.

Fix the queried type \(t\), put \(A=\sigma(t)\), and define

\[ R_t:=\{u\in T:\sigma(u)\ne A,\ w_{tu}>0\}. \]

For every \(u\in R_t\), symmetry and positive supported masses imply

\[ a_{uA}\ge\mu_tw_{ut}=\mu_tw_{tu}>0. \]

The limit is

\[ \boxed{ p_t=\alpha b_{tA} +\beta\sum_{u\in R_t}\mu_uw_{tu}\frac{b_{uA}}{a_{uA}}. } \]

In particular, every denominator used in this expression is positive.

2. Proof of realization independence

Fix any realizing sequence. Write

\[ \varepsilon_n:= \max_{u,v\in T}\ \max_{j\in V_u^{(n)}} \left|\frac{d_j(V_v^{(n)})}{n}-\mu_vw_{uv}\right|. \]

All supported classes are nonempty for sufficiently large \(n\), because their limiting masses are positive. Since there are finitely many type pairs, the assumed convergence gives \(\varepsilon_n\to0\).

Summing over the types inside and outside \(A\), for every \(j\in V_u^{(n)}\),

\[ \left|\frac{d_j(S_A^{(n)})}{n}-a_{uA}\right| \le\tau\varepsilon_n, \qquad \left|\frac{d_j(N_n\setminus S_A^{(n)})}{n}-b_{uA}\right| \le\tau\varepsilon_n. \]

Fix \(u\in R_t\), and abbreviate \(a=a_{uA}>0\), \(b=b_{uA}\), and \(\delta_n=\tau\varepsilon_n\). For sufficiently large \(n\), \(\delta_n\le a/2\). With

\[ x=\frac{d_j(N_n\setminus S_A^{(n)})}{n}, \qquad y=\frac{d_j(S_A^{(n)})}{n}, \]

we then have \(y\ge a/2\), and hence

\[ \left|\frac{x}{y}-\frac ba\right| \le \frac{|x-b|}{y}+\frac{b|a-y|}{ay} \le \frac{2\delta_n}{a}+\frac{2b\delta_n}{a^2}. \]

Consequently, uniformly over \(j\in V_u^{(n)}\),

\[ \frac{d_j(N_n\setminus S_A^{(n)})}{d_j(S_A^{(n)})} \longrightarrow \frac{b_{uA}}{a_{uA}}. \]

Now let \(i\in V_t^{(n)}\). If \(\sigma(u)\ne A\) and \(w_{tu}=0\), the exact prohibition on edges in zero-density blocks gives

\[ N(i)\cap V_u^{(n)}=\varnothing. \]

For \(u\in R_t\), uniform convergence of the ratios gives

\[ \frac1n \sum_{j\in N(i)\cap V_u^{(n)}} \frac{d_j(N_n\setminus S_A^{(n)})}{d_j(S_A^{(n)})} = \frac{d_i(V_u^{(n)})}{n}\frac{b_{uA}}{a_{uA}} +e_{i,u,n}, \]

where

\[ \sup_{i\in V_t^{(n)}}|e_{i,u,n}| \le \sup_{j\in V_u^{(n)}} \left| \frac{d_j(N_n\setminus S_A^{(n)})}{d_j(S_A^{(n)})} -\frac{b_{uA}}{a_{uA}} \right| \longrightarrow0. \]

The inequality uses \(d_i(V_u^{(n)})/n\le1\).

Finally,

\[ \frac{d_i(V_u^{(n)})}{n}\longrightarrow\mu_uw_{tu}, \qquad \frac{d_i(N_n\setminus S_A^{(n)})}{n}\longrightarrow b_{tA}, \]

uniformly over \(i\in V_t^{(n)}\). Substitution into the definition of \(\varphi_i\), followed by summation over the finite set \(R_t\), proves

\[ \max_{i\in V_t^{(n)}} \left|\frac{\varphi_i}{n}-p_t\right|\longrightarrow0. \]

This proves the claimed limit for every choice \(i_n\in V_t^{(n)}\). If \(R_t\) is empty, all external blocks incident to \(t\) are zero, so both \(\varphi_i\) and the displayed formula for \(p_t\) are zero.

3. Realizing sequences exist

The preceding conclusion is nonvacuous for every admissible input.

For each sufficiently large \(n\), choose class sizes \(n_u\) summing to \(n\), with \(|n_u-n\mu_u|\le1\). Independently include each unordered pair of distinct vertices of types \(u,v\) with probability \(w_{uv}\). This produces a simple undirected graph, and zero-density blocks are empty.

For a vertex \(i\) of type \(u\), its degree into type \(v\) has expectation

\[ \mathbb E[d_i(V_v)]=(n_v-\mathbf1_{\{u=v\}})w_{uv}. \]

Each such degree is a sum of at most \(n\) independent Bernoulli variables. If \(Z\) is its centered version, expansion of the fourth moment gives

\[ \mathbb E[Z^4] = \sum_k\mathbb E[X_k^4] +6\sum_{k<\ell}\mathbb E[X_k^2]\mathbb E[X_\ell^2] \le n+3n^2, \]

where the \(X_k\) are independent centered variables with \(|X_k|\le1\); all other terms vanish by independence and zero means.

Markov’s inequality and a union bound over at most \(n\tau\) vertex/type pairs therefore give

\[ \Pr\!\left( \max_{i,v}|d_i(V_v)-\mathbb E[d_i(V_v)]|>n^{7/8} \right) \le \frac{n\tau(n+3n^2)}{n^{7/2}} \le\frac{4\tau}{\sqrt n}. \]

For sufficiently large \(n\), this probability is less than one. Choose a graph satisfying the complementary event. Its normalized degree errors are at most \(n^{-1/8}+2/n\), which tend to zero. These choices form a realizing sequence.

4. Exact computation and bit complexity

Only one sector \(A=\sigma(t)\) is needed for a single query.

Let \(D\) be the product of all positive denominators in the rational input, including \(q\). Its binary length is \(O(L)\). Represent the input exactly as

\[ \mu_u=\frac{M_u}{D},\quad w_{uv}=\frac{W_{uv}}D,\quad \alpha=\frac cD,\quad \beta=\frac eD,\quad q=\frac hD. \]

These integers have \(O(L)\) bits. Define

\[ H_u=\sum_{\sigma(v)=A}M_vW_{uv}, \qquad J_u=\sum_{\sigma(v)\ne A}M_vW_{uv}, \qquad C_u=M_uW_{tu}. \]

Then \(a_{uA}=H_u/D^2\), \(b_{uA}=J_u/D^2\), and

\[ p_t=\frac1{D^3} \left(cJ_t+e\sum_{u\in R_t}\frac{C_uJ_u}{H_u}\right). \]

Every \(H_u\) used in the sum is positive.

Compute the sum as an unreduced fraction \(F/Q\). Start with \(F=0\), \(Q=1\), and for each \(u\in R_t\) update, simultaneously,

\[ F_{\mathrm{new}}=FH_u+C_uJ_uQ, \qquad Q_{\mathrm{new}}=QH_u. \]

These updates preserve \(F/Q=\sum C_uJ_u/H_u\). The threshold decision is the exact integer comparison

\[ \boxed{ cJ_tQ+eF\ \ge\ hD^2Q. } \]

Here \(Q>0\), so clearing denominators preserves the inequality, including when \(q\) is negative.

For the running time:

  • Constructing \(D\) and converting the input to this common denominator take \(O(\tau^2L^2)\) bit operations using schoolbook integer arithmetic.
  • Computing all \(H_u,J_u,C_u\) takes \(O(\tau^2)\) arithmetic operations on \(O(L)\)-bit integers, hence \(O(\tau^2L^2)\) bit operations.
  • Since \(\sum_uM_u=D\) and \(0\le W_{uv}\le D\), the integers \(H_u,J_u,C_u\) are at most \(D^2\). After \(r\) fraction updates, \(F,Q\) have \(O((r+1)L)\) bits. Each update multiplies such integers by \(O(L)\)-bit integers, costing \(O((r+1)L^2)\) bit operations. Summing over \(r\le\tau\) costs \(O(\tau^2L^2)\).
  • The final comparison fits within the same bound.

Thus a single query uses \(O(\tau^2L^2)\) bit operations and \(O(\tau L)\) auxiliary bits beyond the input. There is no exponential dependence on \(m\); surjectivity gives \(m\le\tau\).
