The continuous mirror question, as graded

Given a finite alternative set \(S\), supported reflexive preference types \(R_t\) with positive binary-rational masses \(\mu_t\) summing to \(1\), and \(m=|S|\), \(\tau=|\operatorname{supp}(\mu)|\), let \(P_t\) be the strict part of \(R_t\) and set \(p_\mu(x,y)=\sum_{t:xP_ty}\mu_t\). For \(1/2<\alpha\le1\), define \(xM^\mu_\alpha y\) iff \(p_\mu(x,y)\ge\alpha\), and let \(C_\mu(S)\) be the alternatives optimal in every \(\operatorname{tr}_S(M^\mu_\alpha)\). Define common components across the supported types and apply the paper’s quotient recursion for \(C^{(CC)}\), carrying and aggregating masses on quotient types. Compute the exact output \(C_\mu^{(CC)}(S)\); is this possible in time polynomial in \(m\), \(\tau\), and the input bit length \(L\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) distinct types with positive binary-rational masses \(\mu_t\) summing to \(1\). Each type is an explicitly represented arbitrary reflexive relation \(R_t\) on a finite alternative set \(S\), where \(m=|S|\ge2\). Neither completeness nor transitivity is required. Here \(\tau\) is the support size, not the number of possible types, and \(L\) is the total input bit length; state running times in \(m,\tau,L\).

Set \(P_t=R_t\setminus R_t^{\mathrm{op}}\), \(p_\mu(x,y)=\sum_{t:xP_ty}\mu_t\), and \(xM^\mu_\alpha y\iff p_\mu(x,y)\ge\alpha\) for every real \(\alpha\in(1/2,1]\). Write \(\operatorname{tr}_A\) for reflexive transitive closure on \(A\). An alternative \(x\) is \(Q\)-optimal if \(yQx\Rightarrow xQy\) for every \(y\). Define \(C_\mu(A)\) as all alternatives optimal in every \(\operatorname{tr}_A(M^\mu_\alpha)\), using the restricted types on \(A\).

A common component of the current society on \(A\) is a subset \(B\subseteq A\) with \(|B|\ge2\) such that, for every supported type and every \(x\in A\setminus B\), both truth values \(xR_tb\) and \(bR_tx\) are constant over \(b\in B\).

For a proper common component \(B\), form \(A/B=(A\setminus B)\cup\{b_B\}\), with a fresh alternative \(b_B\). Each quotient type preserves comparisons outside \(B\), is reflexive at \(b_B\), and satisfies \(x(R_t/B)b_B\iff xR_tb\) and \(b_B(R_t/B)x\iff bR_tx\) for any \(b\in B\). Carry each type's mass unchanged and sum masses of identical quotient types. Restrictions likewise preserve masses and merge identical types.

Define \(F(A,\mu)=C_\mu(A)\) if there is no proper common component. Otherwise choose any proper common component \(B\), let \(D=F(A/B,\mu/B)\), and set \(F(A,\mu)=D\) if \(b_B\notin D\), or \(F(A,\mu)=(D\setminus\{b_B\})\cup F(B,\mu|_B)\) otherwise. Apply the definitions anew at each recursive call; on a singleton, \(F(A,\mu)=A\). The requested output is \(C^{(CC)}_\mu(S)=F(S,\mu)\), retaining all chosen alternatives without tie-breaking.

Is exact computation of \(C^{(CC)}_\mu(S)\) possible in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite lists of individuals, the common-optimal rule is polynomial-time computable, and component recursion preserves polynomial-time computability for rules satisfying neutrality, anonymity, restriction independence, and the two Condorcet conditions; this rule satisfies those conditions. [Discrete results](https://arxiv.org/pdf/math/0201285v1). No result settling this exact binary-rational mass problem was located in the literature search.

Exact computation is polynomial-time solvable

There is an exact algorithm with the conservative bit-complexity bound \(O(\tau m^6L^2)\). It computes the entire set \(C^{(CC)}_\mu(S)\), without choosing among tied alternatives.

The proof requires three facts: only polynomially many thresholds matter; a proper common component can be found in polynomial time; and the recursion has only linearly many calls. Rational replication establishes that the output is independent of component choices, but is unnecessary for the algorithm.

1. Exact arithmetic and preservation of support

Write each input mass as \(\mu_t=a_t/d_t\), with positive integers represented in binary. Define

\[ Q=\prod_{t=1}^{\tau}d_t,\qquad n_t=a_t(Q/d_t). \]

Then \(\mu_t=n_t/Q\) and \(\sum_t n_t=Q\). Because the denominators are part of the input, \(Q\) and every \(n_t\) have \(O(L)\) bits. Computing them takes \(O(\tau L^2)\) bit operations using schoolbook arithmetic.

At every recursive call, we may retain the original \(\tau\) indexed types, with their fixed integer masses \(n_t\), even when some current relations coincide. This represents exactly the prescribed merged society:

  • Identical relations contribute the sum of their masses to every pairwise support value.
  • Repeating an identical relation does not change the common-component condition.

Thus merging need not be performed explicitly. Every recursive society has at most \(\tau\) stored relations, and all support calculations use integers bounded by \(Q\). Restrictions preserve the entire electorate, so there is no renormalization.

2. Computing the common-optimal rule

Consider a current alternative set \(A\), with \(k=|A|\). For each ordered pair, compute

\[ w(x,y)=\sum_{t:\,xR_ty\ \text{and}\ \neg(yR_tx)}n_t. \]

Then \(p_\mu(x,y)=w(x,y)/Q\). These weights require \(O(\tau k^2)\) additions of \(O(L)\)-bit integers.

Let

\[ W_A=\{w(x,y):x,y\in A,\ 2w(x,y)>Q\}. \]

There are at most \(k(k-1)\) such values. For each \(v\in W_A\), form the directed relation

\[ xG_vy\quad\Longleftrightarrow\quad w(x,y)\ge v. \]

Finite-threshold claim. The required choice set is

\[ C_\mu(A)= \bigcap_{v\in W_A} \operatorname{Opt}\bigl(\operatorname{tr}_A(G_v)\bigr), \]

where an empty intersection means \(A\).

To prove this, fix any real threshold \(\alpha\in(1/2,1]\). If \(M^\mu_\alpha\) has no edges, its reflexive transitive closure is the identity, so every alternative is optimal. Otherwise, let \(v\) be the minimum weight among its edges. Then \(v/Q\ge\alpha>1/2\), and

\[ w(x,y)/Q\ge\alpha \quad\Longleftrightarrow\quad w(x,y)\ge v. \]

Consequently, \(M^\mu_\alpha=G_v\). Conversely, each \(G_v\) is the threshold relation at \(\alpha=v/Q\). This proves the claim, including all threshold endpoints.

For each \(v\), compute reflexive transitive closure by the Boolean Floyd–Warshall algorithm. An alternative \(x\) is retained precisely when every reachable predecessor \(y\) is also reachable from \(x\). Intersect the resulting sets.

Constructing all these graphs takes \(O(k^4)\) integer comparisons; their closures take \(O(k^5)\) Boolean operations. Hence the common-optimal rule is exactly computable in polynomial time.

For completeness, these intersections are nonempty. Every finite preorder has an optimal element: its equivalence classes form a finite directed acyclic graph, which has a source. More generally, let \(Q_1\subseteq\cdots\subseteq Q_s\) be finite preorders. Start with \(T=\operatorname{Opt}(Q_s)\), then successively replace \(T\) by \(\operatorname{Opt}(Q_i|_T)\), descending in \(i\).

Inductively suppose \(T=\bigcap_{j>i}\operatorname{Opt}(Q_j)\). If \(x\in T\) and \(yQ_ix\), then \(y\in T\): for each \(j>i\), optimality of \(x\) gives \(xQ_jy\); and if \(zQ_jy\), transitivity and optimality give \(zQ_jx\), \(xQ_jz\), and therefore \(yQ_jz\). Thus \(y\) is \(Q_j\)-optimal. It follows that optimality in \(Q_i|_T\) is equivalent, for members of \(T\), to global \(Q_i\)-optimality. Each replacement is nonempty, proving the assertion. The threshold closures form such a nested family.

3. Finding a proper common component

For any distinct \(a,b\in A\), the following procedure finds the smallest common component containing them.

Start with \(H=\{a,b\}\). In each round, add every \(x\in A\setminus H\) for which some supported type distinguishes members of \(H\): for some \(h\in H\),

\[ (xR_th)\ne(xR_ta) \quad\text{or}\quad (hR_tx)\ne(aR_tx). \]

Repeat until no addition occurs.

Correctness. At termination, both comparisons with every outside alternative are constant over \(H\), for every type. Therefore \(H\) is a common component.

Moreover, let \(B\) be any common component containing \(a,b\). Initially \(H\subseteq B\). Whenever \(H\subseteq B\), an alternative outside \(B\) cannot distinguish two members of \(H\), by the component condition for \(B\). Every addition therefore belongs to \(B\). Induction gives \(H\subseteq B\) throughout. The final \(H\) is consequently the smallest common component containing \(a,b\).

Each round takes \(O(\tau k^2)\) relation-entry checks. There are at most \(k\) rounds, giving \(O(\tau k^3)\) checks per seed pair.

Run this procedure on all unordered pairs until a proper component is found. If a proper common component \(B\) exists, any pair of its members generates a component contained in \(B\), hence a proper one. If every generated component is \(A\), no proper common component exists. Thus detection and construction take \(O(\tau k^5)\) relation-entry checks.

This procedure does not enumerate all components.

4. Independence from component choices

We use the following finite-profile result: a nonempty choice rule satisfying neutrality, anonymity, restriction independence, and the two conditions below has a well-defined component-recursive modification, independent of the chosen proper component. This is Theorem 5 of [Heitzig’s paper](https://arxiv.org/pdf/math/0201285).

The conditions are:

  • If \(C(\{x,y\})=\{x\}\) for every \(y\ne x\), then \(C(A)=\{x\}\).
  • If \(x\in C(\{x,y\})\) for every \(y\ne x\), then \(x\in C(A)\).

Here are explicit hypothesis checks for the rule in this problem.

Neutrality and anonymity follow because relabeling alternatives or individuals preserves support values and reachability. Restriction independence follows because every graph and every closure is computed on the current alternative set. Nonemptiness was proved above.

Since each \(P_t\) is asymmetric,

\[ p_\mu(x,y)+p_\mu(y,x)\le1. \]

The two-alternative choice is therefore \(\{x\}\) exactly when \(p_\mu(x,y)>1/2\), and contains \(x\) exactly when \(p_\mu(y,x)\le1/2\).

If \(x\) belongs to every two-alternative choice, no threshold graph has an incoming edge to \(x\). Hence no other alternative has a path to \(x\), and \(x\) is optimal in every closure.

If every two-alternative choice is \(\{x\}\), define

\[ \alpha_0=\min_{y\ne x}p_\mu(x,y)>1/2. \]

At threshold \(\alpha_0\), \(x\) has an edge to every other alternative and has no incoming edge. Every other alternative is consequently nonoptimal in this closure, while \(x\) is optimal at every threshold. Thus \(C_\mu(A)=\{x\}\).

To transfer the finite-profile theorem, construct a conceptual profile with \(2n_t\) individuals of type \(t\), totaling \(2Q\) individuals. Its empirical support values equal \(p_\mu\). Because every \(n_t\) is positive, its common components are exactly the weighted society’s common components.

Restriction and quotient operations commute with this correspondence. Merging identical transformed types simply sums their corresponding individual counts. Therefore, by induction on the number of alternatives, every legal weighted recursive computation equals the corresponding finite-profile computation. The cited theorem makes all these outputs identical.

The conceptual profile may be exponentially large. It is used only to prove well-definedness.

5. Algorithm and total running time

At each call on \(A\):

  • Return \(A\) if it is a singleton.
  • Find a proper common component by the procedure in Section 3.
  • If none exists, compute \(C_\mu(A)\) using Section 2.
  • Otherwise, construct the quotient, recursively compute its choice set, and apply exactly the expansion prescribed in the question.

Correctness follows by induction on \(|A|\), since every recursive child has fewer alternatives. Section 4 establishes that the algorithm computes the requested, component-independent set.

It remains to bound the number of calls. Give a call on \(k\) alternatives the potential \(k-1\). Splitting a proper component of size \(b\) produces children of sizes \(b\) and \(k-b+1\), whose potentials sum to the parent’s:

\[ (b-1)+(k-b)=k-1. \]

Consider the full recursion tree that evaluates both children even when the internal-component result will be discarded. Starting from \(m\ge2\), every node has at least two alternatives. Each leaf therefore has potential at least \(1\); conservation of potential gives at most \(m-1\) leaves. A full binary tree with that many leaves has at most \(2m-3\) nodes. The actual computation visits no more nodes.

At a node of size \(k\), component detection uses \(O(\tau k^5)\) elementary checks. Choice computation uses \(O(\tau k^2+k^5)\) arithmetic or Boolean operations. Quotient and restriction construction are smaller costs. All integer operands have \(O(L)\) bits.

Charging conservatively \(O(L^2)\) bit operations per elementary operation, summing over at most \(2m-3\) calls, and including preprocessing gives the bound

\[ O(\tau m^6L^2). \]

Thus exact computation is polynomial in \(m,\tau,L\), including the binary encoding length of the masses.
