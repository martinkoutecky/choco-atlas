The continuous mirror question, as graded

Given an explicit decision tree \(T\) with rational chance probabilities, \(\tau\) types with rational masses \(\mu_t>0\) summing to \(1\), and for each type a rational polytope \(B_t\) of feasible coefficients for a normalized utility \(u_t(x)=\sum_{j=1}^{q} b_{tj}I_j(x)\) in a shared I-spline basis, design an adaptive elicitation algorithm. Each query asks a society-level oracle to compare lotteries by their mass-weighted expected utility \(W(\ell)=\sum_t\mu_t\sum_x p_\ell(x)u_t(x)\). The algorithm must output one contingent policy \(\pi\) whose worst-case regret, over all utility profiles consistent with the polytopes and observed answers, is at most \(\delta\); determine its query and time complexity in \(n_T,\tau,q,L,\) and \(1/\delta\).

Packaged proof task (what the prover saw — nothing else)

Given an explicit rooted decision tree \(T\) with \(n_T\) nodes, a decision-node root, nonempty action sets, and rational chance probabilities summing to \(1\) at each chance node, let \(X\subseteq[0,1]\) be its rational leaf outcomes together with \(0,1\), and let \(m=|X|\). A contingent policy deterministically selects one action at each relevant decision node and induces a lottery \(\ell_\pi\).
A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
The shared basis consists of \(q\) normalized order-three I-splines on a uniform subdivision of \([0,1]\), with \(I_j(0)=0\) and \(I_j(1)=1\). Each type has an explicitly inequality-described, nonempty rational polytope \(B_t\subseteq\{b\in\mathbb R^q:b_j\geq0,\ \sum_j b_j=1\}\), defining \(u_t(x)=\sum_j b_{tj}I_j(x)\). Thus utilities are nondecreasing and normalized at the endpoints.
An unknown fixed profile \(b^*\in\prod_t B_t\) answers queries comparing any two rational lotteries on \(X\), by their values \(W_b(\ell)=\sum_t\mu_t\sum_{x\in X}p_\ell(x)u_t(x)\). The oracle returns a weakly preferred lottery; either answer is allowed at equality. Queries need not be induced by policies. Each answer retains precisely the profiles satisfying its weak comparison inequality.
For the final consistent set \(\mathcal B\), the required output is one policy \(\pi\) satisfying \(\max_{b\in\mathcal B}\max_{\pi'}[W_b(\ell_{\pi'})-W_b(\ell_\pi)]\leq\delta\), where \(\delta\in(0,1)\) is rational. Let \(L\) be the total binary input length, including the polytopes, basis data, and tolerance; count oracle calls separately from bit computation, including query construction.

Does this adaptive elicitation problem admit polynomially many queries and polynomial bit time in \(m,n_T,\tau,q,L,1/\delta\), or is it NP-hard in this comparison-oracle model? Determine its query and time complexity in these parameters.

For one decision maker with normalized monotone utility and polyhedral utility uncertainty, interactive backward induction has polynomial time and query bounds in \(n_T,1/\delta\), with at most \(n_T\lceil\log_2(2n_T/\delta)\rceil\) queries under polynomial-time linear-programming subroutines ([published result](https://www.ijcai.org/proceedings/2017/0637.pdf)). The same source states that additive multi-agent extensions are possible, but gives no support-and-bit-complexity theorem for the mass formulation above; no separate result settling this exact formulation was located.

  • Specified the shared basis as the order-three, uniformly subdivided normalized I-spline basis used in the supplied implementation.
  • Specified rational outcomes in the unit interval and allowed endpoint outcomes in queries even when absent from the tree.
  • Specified deterministic contingent policies and regret against all deterministic policies using the same utility profile.

Result

The problem is polynomial-time solvable in the stated comparison-oracle model. In fact, there is an algorithm returning a policy with final maximum regret exactly \(0\), using at most
\(Q=\sum_{v\text{ decision node}}(\deg(v)-1)\leq n_T-1\)
oracle calls and polynomial bit computation.

This bound is independent of \(1/\delta\). The essential hypothesis is that the oracle permits comparisons between arbitrary rational lotteries on \(X\), including lotteries induced by policies within subtrees.

1. The society defines one expected-utility functional

For a profile \(b=(b_1,\ldots,b_\tau)\), define its aggregate utility by
\(U_b(x)=\sum_{t=1}^{\tau}\mu_t\sum_{j=1}^{q}b_{tj}I_j(x)\).
Then
\(W_b(\ell)=\sum_{x\in X}p_\ell(x)U_b(x)\).

Consequently, for any lotteries \(\ell_1,\ldots,\ell_k\) and nonnegative rational weights \(p_i\) summing to \(1\),
\(W_b(\sum_i p_i\ell_i)=\sum_i p_iW_b(\ell_i)\).

This identity holds for every admissible profile. It allows backward induction using the same functional at every node. We do not need to identify individual types’ utilities or explicitly construct the set of aggregate utilities.

2. Algorithm: backward induction with direct comparisons

Process every node after all its children. At each node \(v\), store a rational lottery \(\ell_v\) and deterministic choices describing a policy within its subtree.

  • Leaf: If its outcome is \(x\), let \(\ell_v\) put probability \(1\) on \(x\).
  • Chance node: If its children are \(c_1,\ldots,c_k\), with probabilities \(p_1,\ldots,p_k\), set

\(\ell_v=\sum_{i=1}^{k}p_i\ell_{c_i}\).
Retain the previously selected policies in all child subtrees.

  • Decision node: Run a sequential tournament among the child lotteries. Start with \(\ell_{c_1}\) as incumbent. For each subsequent child, query the incumbent against that child’s lottery and retain the lottery returned as weakly preferred. Select the action leading to the final incumbent, and set \(\ell_v\) equal to that lottery.

Output the policy specified by these choices, restricted to relevant decision nodes.

Every query is legal: subtree lotteries are rational probability distributions on \(X\), even when they are not induced by a policy starting at the root.

Let \(\mathcal B\) be precisely the original profile set intersected with the weak inequalities supplied by this transcript. No additional profile restrictions are imposed. The true profile \(b^*\) satisfies every answer, so \(\mathcal B\) is nonempty.

3. Proof of exact optimality over the final consistent set

Fix an arbitrary \(b\in\mathcal B\). Every answer in the transcript is a valid weak comparison under this same profile.

First, a sequential tournament returns a child lottery maximizing \(W_b\) among all children. Indeed, after processing any initial segment, the incumbent weakly dominates every lottery in that segment. For the next comparison:

  • If the incumbent wins, it also weakly dominates the new lottery.
  • If the new lottery wins, it weakly dominates the previous incumbent and therefore, by transitivity, every previously processed lottery.

This establishes the invariant by induction. It applies simultaneously to every \(b\in\mathcal B\), including profiles for which some comparisons are ties.

Now define \(V_v(b)\) as the maximum expected utility achievable by a deterministic policy within the subtree rooted at \(v\). These maxima exist because the tree is finite and action sets are nonempty. We prove, by induction from leaves toward the root, that
\(W_b(\ell_v)=V_v(b)\).

Leaf. There is only its prescribed outcome, so the assertion holds.

Chance node. Child subtrees are disjoint because the input is a tree. Thus their policies can be chosen independently. Nonnegative chance probabilities imply
\(V_v(b)=\sum_i p_iV_{c_i}(b)\):
every collection of child policies is bounded above by this sum, and choosing an optimal policy in each child attains it. Using linearity and the induction hypothesis gives
\(W_b(\ell_v)=\sum_i p_iW_b(\ell_{c_i})=\sum_i p_iV_{c_i}(b)=V_v(b)\).
Zero-probability branches cause no difficulty.

Decision node. Its optimal value is
\(V_v(b)=\max_i V_{c_i}(b)\).
By the induction hypothesis, these values equal \(W_b(\ell_{c_i})\). The tournament selects a maximizing child, proving the assertion.

At the root \(r\), therefore, the output policy \(\pi\) satisfies
\(W_b(\ell_\pi)=V_r(b)=\max_{\pi'}W_b(\ell_{\pi'})\)
for every \(b\in\mathcal B\). Hence its required regret is exactly
\(\max_{b\in\mathcal B}\max_{\pi'}[W_b(\ell_{\pi'})-W_b(\ell_\pi)]=0\),
which is at most \(\delta\).

4. Query count

A decision node with \(k\) children uses exactly \(k-1\) queries. Consequently,
\(Q=\sum_{v\text{ decision node}}(\deg(v)-1)\).

Let \(s\) be the number of leaves. Every internal node has at least one child, and a rooted tree has \(n_T-1\) edges. Thus
\(\sum_{v\text{ internal node}}(\deg(v)-1)=s-1\).
All terms are nonnegative, giving
\(Q\leq s-1\leq n_T-1\).

These are upper bounds; prior utility information can permit fewer queries.

5. Polynomial bit complexity, including query construction

It remains to establish that the stored lotteries have polynomial-length rational descriptions.

Write each chance-edge probability as \(a_e/d_e\), where \(a_e\) and \(d_e\) are integers with \(0\leq a_e\leq d_e\) and \(d_e\geq1\). For each node \(v\), let \(D_v\) be the product of all chance-edge denominators within its subtree, with empty product \(1\).

Because the denominator encodings are part of the input, every \(D_v\) has at most \(L+1\) bits.

Represent \(\ell_v\) by integer numerators \(N_{v,x}\), using the common denominator \(D_v\). We verify that this representation can be maintained exactly.

  • At a leaf, \(D_v=1\), and the numerators are its point-mass vector.
  • At a decision node selecting child \(c\), the integer \(D_c\) divides \(D_v\), and we set

\(N_{v,x}=N_{c,x}(D_v/D_c)\).

  • At a chance node, for each child \(c\), the integer \(d_{vc}D_c\) divides \(D_v\). Set

\(N_{v,x}=\sum_c a_{vc}N_{c,x}\bigl(D_v/(d_{vc}D_c)\bigr)\).

The chance-node formula is exactly the numerator of
\(\sum_c(a_{vc}/d_{vc})\ell_c\).
Thus all divisions are exact, and each stored lottery remains a probability distribution. In particular,
\(0\leq N_{v,x}\leq D_v\).

Therefore every probability in every query has an \(O(L)\)-bit representation. A dense query containing two lotteries has \(O(m(L+1))\) bits, including the probabilities and outcome descriptions.

There are \(O(mn_T)\) integer arithmetic operations for the denominator and lottery computations, on integers of \(O(L)\) bits. Sorting and indexing the rational outcomes requires \(O(n_T\log(n_T+1))\) rational comparisons. With elementary integer arithmetic, a sufficient total bit-time bound, including writing all queries and the output policy, is
\(O\bigl(L+n_T(m+\log(n_T+1))(L+1)^2\bigr)\).

No spline evaluation, linear programming, or polytope projection is required. The dependence on \(\tau\), \(q\), and the tolerance is covered by reading their input descriptions within \(L\). In particular, the algorithm is polynomial in all the requested parameters, and requires no numerical dependence on \(1/\delta\).

6. Relation to the cited result

Section 3 of the [published paper](https://www.ijcai.org/proceedings/2017/0637.pdf) explains that its algorithm uses comparisons between a sure outcome and an endpoint lottery because direct comparisons of subtree lotteries can be cognitively difficult. The oracle specified here explicitly permits those direct comparisons. This permission yields the exact tournament algorithm above.

Thus the stated elicitation problem admits polynomial bit computation with linearly many oracle calls. The proof settles the support-and-mass formulation directly.
