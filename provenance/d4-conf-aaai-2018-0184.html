The continuous mirror question, as graded

Given rational resident-type masses \(\mu_t\), room-class supplies \(\lambda_a\) with each summing to one, values \(v_{ta}\), budgets \(b_t\), per-capita rent \(R\), and rational linear objectives \(\ell_s\), decide whether there are prices \(p_a\) and assignment masses \(x_{ta}\ge 0\) such that \(\sum_a x_{ta}=\mu_t\), \(\sum_t x_{ta}=\lambda_a\), and \(\sum_a\lambda_a p_a=R\). For every \(x_{ta}>0\), require \(p_a\le b_t\) and \(v_{ta}-p_a\ge v_{tb}-p_b\) for every room class \(b\); then, if feasible, maximize \(\min_s\ell_s(u)\), where \(u_t=v_{ta}-p_a\) for any class assigned positive mass to type \(t\). Determine whether this can be done in time polynomial in the number of types, room classes, and input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) resident types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) room classes with positive binary-rational supplies \(\lambda_a\), summing to \(1\). Values \(v_{ta}\), finite budgets \(b_t\), and per-capita rent \(R\) are arbitrary signed rationals, with no valuation normalization.
The input also explicitly lists \(k\ge1\) rational linear functions \(\ell_s:\mathbb R^\tau\to\mathbb R\); let \(L\) be the total binary input length.
An allocation consists of real class prices \(p_a\) and assignment masses \(x_{ta}\ge0\), satisfying \(\sum_a x_{ta}=\mu_t\), \(\sum_t x_{ta}=\lambda_a\), and \(\sum_a\lambda_a p_a=R\); negative prices are allowed.
Whenever \(x_{ta}>0\), require \(p_a\le b_t\) and \(v_{ta}-p_a\ge v_{tc}-p_c\) for every class \(c\), including unaffordable classes. Indifference permits splitting mass; these inequalities give each type a well-defined utility \(u_t=v_{ta}-p_a\) on all positively assigned classes.
The computational problem is to decide feasibility and, when feasible, compute an allocation maximizing \(\min_{1\le s\le k}\ell_s(u)\).

Is this feasibility-and-exact-optimization problem solvable in time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For discrete bijective assignments, budget-constrained envy-free feasibility and optimization of a minimum of explicitly given linear utility functions are polynomial-time solvable ([Procaccia–Velez–Yu](https://procaccia.info/wp-content/uploads/2020/03/rent-budget.pdf)).
A different fractional model has polynomial-time feasibility with individual rationality, agent payments, and envy comparisons between entire fractional bundles ([Airiau et al.](https://www.lamsade.dauphine.fr/~lang/papers/airiau23a.pdf)); it does not impose the class-price and positive-assignment conditions above. No result settling this exact mass model was located.

Modeling choices made when packaging the task

  • Specified arbitrary signed rational values, finite budgets, and rent, and allowed negative real prices, following the unrestricted discrete domain.
  • Required positive supplies for every listed room class, matching the discrete model in which every room is assigned; zero-supply classes are omitted.
  • Specified nonempty resident and room supports and a nonempty explicitly listed family of linear objectives; running time includes the objective count and total binary input length.
  • Made explicit that envy comparisons include unaffordable classes, ties permit mass splitting, and budgets constrain every positively assigned class rather than average payment.

Result

The feasibility-and-exact-optimization problem is solvable in polynomial time in \(m,\tau,k,L\). Whenever feasible, it has a rational optimal allocation of polynomial encoding length.

The proof uses a component decomposition analogous to the discrete decomposition in [Procaccia–Velez–Yu, Section 3](https://procaccia.info/wp-content/uploads/2020/03/rent-budget.pdf), but establishes the required properties directly for the stated mass model.

1. Envy-freeness and transportation duality

Let \(\mathcal X\) be the transportation polytope consisting of all nonnegative matrices \(x\) with row sums \(\mu_t\) and column sums \(\lambda_a\). It is nonempty: \(x_{ta}=\mu_t\lambda_a\) belongs to it. It is compact because every coordinate satisfies \(0\le x_{ta}\le\mu_t\).

Consider the maximum-value transportation problem

\(\displaystyle W=\max_{x\in\mathcal X}\sum_{t,a}v_{ta}x_{ta}.\)

Its linear-programming dual is

\(\displaystyle \min_{u,p}\left(\sum_t\mu_tu_t+\sum_a\lambda_ap_a\right),\qquad u_t+p_a\ge v_{ta}\quad\text{for all }t,a,\)

where \(u,p\) are unrestricted in sign. The primal has a finite attained optimum, so strong duality gives an attained dual optimum with value \(W\).

For any primal-feasible \(x\) and dual-feasible \((u,p)\), their objective gap is

\(\displaystyle \sum_t\mu_tu_t+\sum_a\lambda_ap_a-\sum_{t,a}v_{ta}x_{ta} =\sum_{t,a}x_{ta}(u_t+p_a-v_{ta}).\)

Every summand on the right is nonnegative.

Suppose first that an allocation satisfies the problem’s envy conditions, temporarily ignoring budgets. Since \(\mu_t>0\), each type receives some class, and its utility is

\(\displaystyle u_t=\max_a(v_{ta}-p_a).\)

Consequently, \((u,p)\) is dual-feasible, and every positively assigned edge satisfies \(u_t+p_a=v_{ta}\). The gap identity therefore vanishes. Both \(x\) and \((u,p)\) are optimal.

Conversely, take any optimal transportation \(x\) and any optimal dual pair \((u,p)\). Their gap is zero, so

\(\displaystyle x_{ta}>0\ \Longrightarrow\ u_t+p_a=v_{ta}.\)

Together with all the dual inequalities, this gives exactly the required envy conditions. Because each type has positive mass, its assigned utility equals \(\max_a(v_{ta}-p_a)\).

Thus every optimal transportation is compatible with every optimal dual pair, before imposing budgets and rent.

2. The edges used by optimal transportations

Define

\(\displaystyle E^\star=\{(t,a):x_{ta}>0\text{ for some optimal transportation }x\}.\)

Every optimal transportation is supported on \(E^\star\). Moreover, every optimal dual pair satisfies

\(\displaystyle u_t+p_a=v_{ta}\qquad\text{for every }(t,a)\in E^\star.\)

Indeed, for a given edge in \(E^\star\), choose an optimal transportation positive on that edge and apply the gap identity.

Fix a rational optimal dual pair \((u^0,p^0)\), normalized so that

\(\displaystyle \sum_a\lambda_ap^0_a=0.\)

Such normalization is possible: adding a constant to all prices and subtracting it from all utilities preserves the constraints and dual objective, because both total masses equal \(1\).

Form the undirected bipartite graph with type vertices, class vertices, and edge set \(E^\star\). Let its connected components be \(\mathcal C\). For a component \(C\), denote its type vertices by \(T_C\), its class vertices by \(A_C\), and its edges by \(E_C\).

Every vertex is incident to an edge: any optimal transportation must meet all the strictly positive marginals. Each component is therefore nonempty on both sides.

A fixed optimal transportation has no positive entries between different components. Summing its row and column equations within \(C\) gives

\(\displaystyle w_C:=\sum_{t\in T_C}\mu_t=\sum_{a\in A_C}\lambda_a>0.\)

Also, \(\sum_{C\in\mathcal C}w_C=1\).

3. One price-shift variable per component

Let \((u,p)\) be any optimal dual pair. For every edge in \(E^\star\),

\(\displaystyle (u_t-u^0_t)+(p_a-p^0_a)=0.\)

Following paths in a connected component shows that there is one scalar \(d_C\) such that

\(\displaystyle p_a=p^0_a+d_C\quad(a\in A_C),\qquad u_t=u^0_t-d_C\quad(t\in T_C).\)

Write \(C(t)\) and \(C(a)\) for the components containing a type or class. Define the nonnegative reference slacks

\(\displaystyle \sigma_{ta}=u^0_t+p^0_a-v_{ta}.\)

For prices and utilities of the preceding form, dual feasibility is equivalent to

\[\displaystyle d_{C(t)}-d_{C(a)}\le\sigma_{ta}\qquad\text{for all }t,a.\tag{1}\]

Conversely, any component shifts satisfying (1) give an optimal dual pair. They give a feasible pair, and its objective equals

\(\displaystyle W+\sum_Cd_C\left(\sum_{a\in A_C}\lambda_a-\sum_{t\in T_C}\mu_t\right)=W,\)

by component balance.

The prescribed rent becomes

\[\displaystyle \sum_Cw_Cd_C=R,\tag{2}\]

using the normalization of \(p^0\).

Thus all envy-free price and utility vectors are described by the linear conditions (1) and (2). Budgets remain to be incorporated.

4. Each component’s budgets give one upper bound

For an edge \((t,a)\in E_C\), define its affordability threshold

\(\displaystyle h_{ta}=b_t-p^0_a.\)

At component shift \(d_C=d\), this edge is affordable exactly when \(d\le h_{ta}\).

For a real number \(d\), let

\(\displaystyle E_C(d)=\{(t,a)\in E_C:h_{ta}\ge d\}.\)

Call \(d\) *locally feasible* if a nonnegative transportation supported on \(E_C(d)\) has row sums \((\mu_t)_{t\in T_C}\) and column sums \((\lambda_a)_{a\in A_C}\).

These conditions concern only assignments and budgets. The full envy inequalities remain in (1).

Let

\(\displaystyle H_C=\{h_{ta}:(t,a)\in E_C\}.\)

This is a finite, nonempty set. At \(d=\min H_C\), every edge of \(E_C\) is affordable, and the restriction of any optimal transportation witnesses local feasibility. Define

\(\displaystyle B_C=\max\{h\in H_C:h\text{ is locally feasible}\}.\)

The maximum therefore exists. Retain a witnessing transportation \(y^C\) supported on \(E_C(B_C)\).

Claim. A real shift \(d\) is locally feasible if and only if \(d\le B_C\).

Proof. If \(d\le B_C\), then \(E_C(B_C)\subseteq E_C(d)\), so the fixed transportation \(y^C\) remains feasible.

Conversely, suppose \(d>B_C\) were locally feasible. Its permitted edge set cannot be empty because the component has positive mass. Hence there exists a smallest threshold \(h^\star\in H_C\) satisfying \(h^\star\ge d\). By its minimality,

\(\displaystyle E_C(d)=E_C(h^\star).\)

Thus \(h^\star\) would be a locally feasible threshold larger than \(B_C\), contradicting the definition of \(B_C\). This proves the claim.

All budgets in a component are consequently captured by the single linear inequality

\[\displaystyle d_C\le B_C.\tag{3}\]

The witness \(y^C\) works at every shift satisfying this inequality.

5. The final optimization LP

Introduce a real objective variable \(z\). Solve the following rational linear program:

\(\displaystyle \text{maximize }z,\)

subject to

\(\displaystyle d_{C(t)}-d_{C(a)}\le\sigma_{ta}\qquad\text{for all }t,a,\)

\(\displaystyle \sum_Cw_Cd_C=R,\)

\(\displaystyle d_C\le B_C\qquad\text{for all }C,\)

\[\displaystyle z\le\ell_s\!\left((u^0_t-d_{C(t)})_{t=1}^{\tau}\right) \qquad\text{for }s=1,\ldots,k.\tag{4}\]

These are linear constraints because every \(\ell_s\) is explicitly given and linear.

Necessity

Take any feasible allocation \((x,p)\), with utilities \(u\). Section 1 shows that \(x\) and \((u,p)\) are optimal for the transportation primal and dual.

Section 3 therefore supplies component shifts satisfying (1) and the rent equation (2). The assignment \(x\) is supported on \(E^\star\). Its restriction to each component is affordable at shift \(d_C\), so Section 4 gives \(d_C\le B_C\).

Hence these shifts, together with

\(\displaystyle z=\min_s\ell_s(u),\)

are feasible for (4).

Sufficiency and reconstruction

Conversely, take shifts feasible for (4). Set

\(\displaystyle p_a=p^0_a+d_{C(a)},\qquad u_t=u^0_t-d_{C(t)}.\)

Construct \(x\) by combining the retained local transportations \(y^C\), with zero entries between different components. Its row and column marginals are the required ones.

If \(x_{ta}>0\), then \((t,a)\in E_C(B_C)\), and therefore

\(\displaystyle p_a=p^0_a+d_C\le p^0_a+B_C\le b_t.\)

Also, every edge of \(E^\star\) is tight at the reference pair, and both endpoints receive the same component shift. Thus

\(\displaystyle x_{ta}>0\ \Longrightarrow\ u_t+p_a=v_{ta}.\)

The first constraints of (4) give \(u_t+p_c\ge v_{tc}\) for every class \(c\), including unaffordable classes. This verifies exactly the task’s positive-assignment and envy requirements. The rent equation also holds.

The reconstructed allocation has utility vector \(u\), and its objective is at least \(z\). Together with necessity, this proves that the LP’s optimum equals the original problem’s optimum and that reconstruction yields an optimal allocation. LP infeasibility is equivalent to allocation infeasibility.

Attainment

Every \(B_C\) is finite because all budgets and reference prices are finite. The upper bounds and rent equation imply the lower bounds

\(\displaystyle d_C\ge \frac{R-\sum_{D\ne C}w_DB_D}{w_C}.\)

Here \(w_C>0\). The feasible shift set is therefore closed and bounded. When nonempty, the continuous function

\(\displaystyle d\longmapsto\min_s\ell_s\!\left((u^0_t-d_{C(t)})_t\right)\)

attains a finite maximum.

6. Polynomial bit complexity

We use the standard rational linear-programming theorem: feasibility and finite attained optima can be computed exactly in polynomial time, with rational outputs of polynomial encoding length.

All the required computations have polynomial size:

  • Compute \(W\) and the reference dual pair. Solve the transportation LP and obtain an optimal dual pair, then normalize it as above.
  • Compute \(E^\star\). For each of the \(\tau m\) edges, solve

\(\displaystyle \max x_{ta}\quad\text{subject to }x\in\mathcal X,\quad\sum_{r,c}v_{rc}x_{rc}=W.\)
The edge belongs to \(E^\star\) exactly when this optimum is positive. These LPs optimize over a nonempty compact face, and positivity is tested exactly.

  • Compute the components and bounds. Connected components are computable in polynomial time. For each \(h\in H_C\), test the transportation feasibility defining \(E_C(h)\), retaining a witness at the largest feasible threshold. Across all components, there are at most \(|E^\star|\le\tau m\) distinct-threshold tests.
  • Solve the final LP. It has \(|\mathcal C|+1\) variables and at most \(\tau m+|\mathcal C|+k+1\) constraints.

Every auxiliary LP has polynomial dimensions. The intermediate rational numbers—including \(W,u^0,p^0,w_C,h_{ta},B_C\)—have polynomial encoding length, so the final LP does too. Its optimal shifts and the retained local transportations give rational prices and assignment masses of polynomial encoding length.

All computations use the encoded masses directly. No expansion by a common denominator is required, and no valuation normalization or sign restriction is used.
