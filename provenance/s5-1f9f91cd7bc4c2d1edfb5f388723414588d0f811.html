The continuous mirror question, as graded

Given a candidate set \(C\) and a finite list of complete ranking types with positive rational masses \(\mu_t\) summing to \(1\), decide whether there is an order \((c_1,\ldots,c_m)\) such that, for each consecutive pair \((a,b)\) among the first two candidates, both directional first-two ranking masses \(p_{ab}\) and \(p_{ba}\) are positive, and every later candidate has at least two connected predecessors.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\ge 2\). A society is given by its support: a list of \(\tau\) distinct complete strict ranking types over \(C\), each with a positive binary rational mass \(\mu_t\), with \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For distinct \(a,b\in C\), define \(p_{ab}=\sum_{t:\,t\text{ ranks }a\text{ first and }b\text{ second}}\mu_t\). Call \(a,b\) connected exactly when \(p_{ab}>0\) and \(p_{ba}>0\).
The recognition problem asks whether there is a permutation \((c_1,\ldots,c_m)\) of \(C\) such that \(c_1,c_2\) are connected and, for every \(i\ge3\), \(c_i\) is connected to at least two distinct candidates in \(\{c_1,\ldots,c_{i-1}\}\).

Is this recognition problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite multisets of strict rankings, linked-domain recognition is solvable in polynomial time ([Yang, 2017](https://arxiv.org/pdf/1712.04918)). No separate result for this exact rational-mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Restricted the candidate domain to at least two candidates so that the required first pair exists.
  • Interpreted complete ranking types as strict linear orders, following the discrete definition.
  • Defined directional first-two masses explicitly and applied the same bidirectional connectedness condition to all predecessor connections.
  • Required the two connected predecessors to be distinct candidates.
  • Defined L as the total input bit length.

Result

The recognition problem is solvable in polynomial time. Positivity of the masses makes connectedness depend only on the listed ranking types. A graph closure algorithm then decides recognition and, on a yes-instance, produces the required permutation.

This is the graph approach used in [Yang’s recognition theorem](https://arxiv.org/pdf/1712.04918). The argument below verifies its applicability to the rational-mass formulation and gives an explicit running time.

1. Reduction to a graph

For distinct candidates \(a,b\), let \(D_{ab}=1\) exactly when some listed ranking places \(a\) first and \(b\) second; otherwise let \(D_{ab}=0\).

Because every listed mass is strictly positive,

\(p_{ab}>0 \quad\Longleftrightarrow\quad D_{ab}=1.\)

Indeed, an empty sum is zero, whereas a nonempty sum of positive masses is positive. Consequently, no rational addition or comparison is needed.

Construct the simple undirected graph \(G=(C,E)\), where

\(\{a,b\}\in E \quad\Longleftrightarrow\quad D_{ab}=D_{ba}=1.\)

Write \(N(v)\) for the neighbors of \(v\). By construction, the requested permutation is precisely an ordering whose first two vertices form an edge and whose every subsequent vertex has at least two neighbors earlier in the ordering.

Equivalently, replacing each supported ranking by one unweighted vote preserves connectedness exactly. This yields a multiset with \(\tau\) votes, without expanding the rational masses.

2. Recognition algorithm

For every edge \(\{a,b\}\in E\), perform the following procedure:

  • Initialize \(S=\{a,b\}\) and the output ordering with \(a,b\).
  • While some vertex \(v\in C\setminus S\) satisfies \(|N(v)\cap S|\ge 2\), append any such vertex to the ordering and add it to \(S\).
  • If \(S=C\), accept and return the ordering.

If every edge fails to generate all vertices, reject. If \(E\) is empty, reject immediately.

For \(m=2\), this procedure accepts exactly when the two candidates are connected, as required.

3. Proof of correctness

Soundness. Every returned ordering begins with an edge. Each later vertex is appended only after it has two distinct neighbors among the previously appended vertices. Thus every returned ordering satisfies the recognition conditions.

Completeness. Suppose a valid ordering \((c_1,\ldots,c_m)\) exists. Consider the algorithm’s trial starting from the edge \(\{c_1,c_2\}\).

Assume this trial stops with \(S\ne C\). Let \(j\) be the smallest index such that \(c_j\notin S\). Since \(c_1,c_2\in S\), we have \(j\ge 3\). Minimality of \(j\) gives

\(\{c_1,\ldots,c_{j-1}\}\subseteq S.\)

Validity of the ordering says that \(c_j\) has at least two distinct neighbors in \(\{c_1,\ldots,c_{j-1}\}\). Those neighbors belong to \(S\), so \(|N(c_j)\cap S|\ge 2\). This contradicts the stopping condition.

Hence that trial reaches \(S=C\), and the algorithm accepts. This argument also proves that arbitrary choices among eligible vertices cannot cause an otherwise successful starting edge to fail.

4. Running time and binary encoding

Let \(e=|E|\). Use indexed candidates, a Boolean matrix for \(D\), and adjacency lists for \(G\). Reading the input and constructing these structures takes \(O(L+m^2)\) elementary operations.

Each trial can be implemented in \(O(m+e)\) operations. Maintain, for each unselected vertex, its number of selected neighbors and a queue of eligible vertices. Initialize the counts from the two starting vertices. Whenever a vertex is selected, scan its adjacency list and update its unselected neighbors’ counts. Enqueue a vertex when its count first reaches two. Each vertex is selected at most once, and each adjacency-list entry is scanned at most once during that trial.

There are \(e\) trials, giving total time

\(O\!\left(L+m^2+e(m+e)\right).\)

Furthermore, \(e\le \binom{m}{2}\). Also \(2e\le\tau\): every edge requires two different ordered first–second pairs, and each supported ranking witnesses only one such pair. Setting

\(q=\min\!\left\{\binom{m}{2},\left\lfloor\tau/2\right\rfloor\right\},\)

the running time is therefore

\(O\!\left(L+m^2+q(m+q)\right)\subseteq O(L+m^4)\)

on a standard word-RAM. All indices and counters use \(O(\log(m+L))\) bits. Charging that many bit operations per word operation gives the explicit bit-cost RAM bound

\(O\!\left((L+m^2+q(m+q))\log(m+L)\right).\)

Thus the binary rational encoding introduces no obstacle to polynomial-time recognition.

The equivalence
\[ p_{ab}>0 \quad\Longleftrightarrow\quad D_{ab}=1 \]
is correct. If no listed ranking has \(a,b\) in its first two positions, the defining sum is empty and equals zero. Otherwise, it contains at least one strictly positive summand and is positive. No cancellation is possible.

Consequently,
\[ \{a,b\}\in E \quad\Longleftrightarrow\quad D_{ab}=D_{ba}=1 \]
matches the task’s definition of connectedness exactly.

The graph is simple and undirected. Therefore, counting neighbors counts distinct candidates, as required. The requested permutation is precisely the graph ordering described by the prover.

Replacing each supported ranking by one unweighted vote also preserves connectedness. This replacement creates exactly \(\tau\) votes and does not require expanding any rational mass.

3. Algorithm and termination

Enumerating all edges covers every possible initial pair of a valid ordering. Considering only one orientation of each edge is sufficient: the condition on later vertices depends on the set of previously selected vertices, and the initial pair is connected in either order.

Every iteration adds a previously unselected vertex. Thus each trial terminates after at most \(m-2\) additions.

If the graph has no edges, no valid initial pair exists, so immediate rejection is correct. For \(m=2\), a trial begins with all vertices selected and accepts exactly when the sole candidate pair is connected.

4. Soundness

Every returned ordering contains each candidate exactly once, because vertices are appended only when outside the selected set and acceptance requires that all vertices have been selected.

Its first two vertices form an edge. Every later vertex has at least two distinct neighbors among the previously selected vertices when appended. Hence every returned ordering satisfies all recognition requirements.

5. Completeness and arbitrary choices

The contradiction argument is valid.

For a valid ordering \((c_1,\ldots,c_m)\), the algorithm examines its initial edge. If that trial stopped with a proper selected set \(S\), the smallest index \(j\) with \(c_j\notin S\) would exist. Since the initial two vertices belong to \(S\), necessarily \(j\ge 3\).

Minimality gives
\[ \{c_1,\ldots,c_{j-1}\}\subseteq S. \]
The valid ordering supplies two distinct neighbors of \(c_j\) in this prefix. They are therefore in \(S\), making \(c_j\) eligible and contradicting the stopping condition.

The argument does not require the algorithm’s selected order to match the valid ordering. It therefore also justifies arbitrary choices among eligible vertices.

6. Running-time verification

The construction bound \(O(L+m^2)\) is valid with indexed candidates: reading the explicit input costs \(O(L)\), and initializing and inspecting the Boolean matrix costs \(O(m^2)\). Rational arithmetic is unnecessary.

The queue implementation supports \(O(m+e)\) time per trial:

  • Initializing membership indicators and neighbor counts costs \(O(m)\), plus scanning the initial vertices’ adjacency lists.
  • Selecting a vertex requires scanning its adjacency list and updating counts for unselected neighbors.
  • Counts only increase, so each vertex can be enqueued once, when its count first reaches two.
  • Each selected vertex’s adjacency list is scanned once; the graph has \(2e\) adjacency-list entries.

There are at most \(e\) trials, so
\[ O\!\left(L+m^2+e(m+e)\right) \]
is justified.

Both edge bounds are correct:
\[ e\le \binom{m}{2}, \qquad 2e\le\tau. \]
For the second bound, every edge requires its two directed first–second pairs to be witnessed. Different directed pairs require different supporting ranking types, because a ranking witnesses only one such pair.

Thus the stated bound using
\[ q=\min\!\left\{\binom{m}{2},\left\lfloor\tau/2\right\rfloor\right\} \]
follows, as does \(O(L+m^4)\) word-RAM time.

The indices, counts, and memory addresses fit within \(O(\log(m+L))\) bits. Charging this factor per word operation yields the stated polynomial bit-cost bound.
