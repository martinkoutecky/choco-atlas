1. Result

For every fixed \(\varepsilon>0\) and every \(\sigma\in\{\mathrm{ADM},\mathrm{COM},\mathrm{PRF},\mathrm{SEM},\mathrm{STB}\}\), the promised decision problem is \(\mathrm{NP}\)-hard.

The proof establishes an exact correspondence with finite credulous acceptance. In particular, the correspondence respects pointwise semantics, literal inclusion, and measurable competitors.

2. Reduction from measurable sets to type sets

Let \(F=(T,R)\) be the finite framework on the supported types. For \(E\subseteq T\), define

\(A(E)=\{t\in T:\text{some }s\in E\text{ satisfies }(s,t)\in R\}\),

\(E^+=E\cup A(E)\),

\(D(E)=\{t\in T:\text{for every }s\text{ with }(s,t)\in R,\text{ some }r\in E\text{ satisfies }(r,s)\in R\}\),

and

\(\widehat E=\bigcup_{t\in E}I_t\).

Thus \(D(E)\) is the set of types defended by \(E\). Every \(\widehat E\) is measurable.

For a measurable \(S\subseteq U\), define its presence set

\(E(S)=\{t\in T:S\cap I_t\ne\varnothing\}\).

This definition uses nonemptiness, not positive measure: a selected occurrence of measure zero still attacks pointwise.

Lemma 1: Attacks, defence and admissibility

For every measurable \(S\), writing \(E=E(S)\), the occurrences attacked by \(S\) are exactly \(\widehat{A(E)}\), and the occurrences defended by \(S\) are exactly \(\widehat{D(E)}\). Consequently,

\(S^+=S\cup\widehat{A(E)}\),

and \(S\) is admissible if and only if \(E\) is admissible in \(F\).

Proof. An occurrence of type \(t\) is attacked by \(S\) exactly when \(S\) contains an occurrence of some type \(s\) with \((s,t)\in R\). This gives the attack identity.

Fix an occurrence of type \(t\). For every attacker type \(s\), every occurrence in \(I_s\) attacks it. Such an attacker occurrence is attacked by \(S\) exactly when some represented type \(r\in E\) attacks \(s\). Each \(I_s\) is nonempty because its mass is positive. Hence defence is precisely the condition defining \(D(E)\).

Likewise, \(S\) is conflict-free exactly when no pair of represented types attacks, including self-attacks. Equivalently, \(E\cap A(E)=\varnothing\). All selected occurrences are defended exactly when \(E\subseteq D(E)\). These are precisely finite admissibility. \(\square\)

In particular, if \(S\) is admissible, its saturation \(\widehat{E(S)}\) is an admissible measurable superset.

Lemma 2: Saturation and the other semantics

For \(\sigma\in\{\mathrm{COM},\mathrm{PRF},\mathrm{SEM},\mathrm{STB}\}\), the measurable \(\sigma\)-extensions are exactly the sets \(\widehat E\) where \(E\) is a finite \(\sigma\)-extension of \(F\).

Proof for complete semantics. If \(S\) is complete, its selected occurrences are defended. Defence is constant throughout each type interval, by Lemma 1. Completeness therefore requires every represented interval to be included in full, so \(S=\widehat E\).

For a saturated set, admissibility and inclusion of every defended occurrence are equivalent to finite admissibility and \(D(E)\subseteq E\). Thus completeness is equivalent in the two frameworks.

Proof for preferred semantics. An unsaturated admissible \(S\) has the strictly larger measurable admissible superset \(\widehat{E(S)}\), so it cannot be preferred.

If \(E\) is not finite preferred, a finite admissible strict superset \(B\supsetneq E\) yields the measurable admissible strict superset \(\widehat B\supsetneq\widehat E\).

Conversely, suppose a measurable admissible \(Q\) strictly contains \(\widehat E\). Its presence set \(B=E(Q)\) is admissible by Lemma 1. Because \(\widehat E\) already contains all occurrences of each type in \(E\), strict containment requires \(B\supsetneq E\). Therefore finite preferredness also implies measurable preferredness.

Proof for semi-stable semantics. Suppose \(S\) is admissible and unsaturated, with presence set \(E\). Conflict-freeness gives \(E\cap A(E)=\varnothing\). Every occurrence in \(\widehat E\setminus S\) is consequently outside \(S^+=S\cup\widehat{A(E)}\). Saturation therefore strictly increases the range:

\(S^+\subsetneq(\widehat E)^+=\widehat{E^+}\).

Thus every measurable semi-stable extension is saturated.

If a finite admissible \(B\) satisfies \(E^+\subsetneq B^+\), its saturation provides a strictly larger measurable range.

Conversely, suppose a measurable admissible \(Q\) satisfies

\(\widehat{E^+}\subsetneq Q^+\).

Let \(B=E(Q)\). Lemma 1 gives finite admissibility of \(B\) and

\(Q^+\subseteq\widehat{B^+}\).

Hence \(\widehat{E^+}\subsetneq\widehat{B^+}\). Since all intervals are nonempty and pairwise disjoint, this implies \(E^+\subsetneq B^+\). Finite and measurable range maximality are therefore equivalent.

Proof for stable semantics. A stable set is conflict-free. For its presence set \(E\), conflict-freeness gives \(E\cap A(E)=\varnothing\). Any omitted occurrence of a represented type is therefore neither selected nor attacked. Stability forces saturation.

For a saturated conflict-free set, \((\widehat E)^+=U\) holds exactly when \(E^+=T\), which is finite stability. \(\square\)

Corollary: Exact acceptance equivalence

For every listed semantics,

\(\exists\text{ measurable }\sigma\text{-extension }S\text{ with }\lambda(S\cap I_{t^\star})>0\)

if and only if

\(\exists\text{ finite }\sigma\text{-extension }E\text{ of }F\text{ with }t^\star\in E\).

For admissible semantics, the forward direction follows from Lemma 1: positive measure implies presence. For the reverse direction, saturate the finite admissible extension.

For the other semantics, apply Lemma 2. Whenever \(t^\star\in E\),

\(\lambda(\widehat E\cap I_{t^\star})=\mu_{t^\star}>0\).

Thus positive masses affect neither the acceptance answer nor the finite semantics governing it.

3. Padding with isolated types preserves acceptance

Let \(F=(X,R)\) be a finite framework and let \(Z\) be a disjoint set of new isolated arguments. Write \(H\) for the framework on \(X\cup Z\), retaining exactly the attacks of \(F\).

Every subset of \(H\) has the form \(E=A\cup B\), with \(A\subseteq X\) and \(B\subseteq Z\). Directly from isolation,

  • \(E\) is admissible in \(H\) exactly when \(A\) is admissible in \(F\);
  • \(D_H(E)=D_F(A)\cup Z\);
  • \(E_H^+=A_F^+\cup B\).

These identities give the following extension descriptions.

For admissible semantics, \(B\) is arbitrary. For complete semantics, completeness forces \(B=Z\), and its remaining condition is precisely completeness of \(A\).

For preferred semantics, maximality forces \(B=Z\), since any omitted isolated argument can be added admissibly. Once \(B=Z\), maximality is equivalent to preferredness of \(A\).

For semi-stable semantics, omitting any isolated argument permits a strict range increase, so again \(B=Z\). Ranges then all contain exactly the same new set \(Z\); their inclusion comparisons reduce to those in \(F\).

For stable semantics, stability forces \(B=Z\), and the remaining requirement is \(A_F^+=X\).

Consequently, adding isolated arguments preserves credulous acceptance of every original argument under every listed semantics.

4. Polynomial reduction satisfying the mass promise

The supplied hardness theorem states that finite credulous acceptance is \(\mathrm{NP}\)-hard for every listed semantics on frameworks whose minimum deletion distance to bipartiteness is exactly one. Here bipartiteness means partitionability into two conflict-free sets, exactly as required by the present promise. This is Theorem 4(1) of [Ordyniak and Szeider, *Augmenting Tractable Fragments of Abstract Argumentation*](https://www.ijcai.org/Proceedings/11/Papers/177.pdf).

Fix \(\varepsilon>0\). Choose a fixed nonnegative integer \(K\) such that \(2^{-K}\le\varepsilon\). Because \(\varepsilon\) is fixed, \(K\) is a constant of the reduction.

Take a finite hardness instance \((F,x^\star)\), with \(n=|X|\). Let

\(N=2^{\max\{K,\lceil\log_2 n\rceil\}}\).

Add \(N-n\) isolated arguments, obtaining \(H\). Construct the society with:

  • type set \(T=V(H)\), so \(\tau=N\);
  • attack relation equal to that of \(H\);
  • target \(t^\star=x^\star\);
  • uniform mass \(\mu_t=1/N\) for every type.

These masses are positive dyadic rationals, sum to one, and satisfy \(\mu_t\le\varepsilon\).

Since \(F\) has deletion distance one to bipartiteness, there exists an original argument \(b\) such that \(F-b\) has the required partition. Place all new isolated arguments into either part. This proves that \(H-b\) also has the required partition, while \(\mu_b\le\varepsilon\). The reduction does not need to identify or supply \(b\).

Moreover,

\(\tau=N\le 2\max\{n,2^K\}=O_\varepsilon(n)\).

Each mass requires \(O(\log\tau)\) bits. With an explicit adjacency matrix, the output length is \(O(\tau^2+\tau\log\tau)\), and the construction takes polynomial time in these quantities.

By Section 3, padding preserves the finite acceptance answer. By Section 2, passing from types to occurrences preserves that answer. Therefore the constructed promised society is a yes-instance exactly when the original finite instance is a yes-instance.

This proves \(\mathrm{NP}\)-hardness for every fixed \(\varepsilon\) and every listed \(\sigma\).

The correspondence also gives finite decision procedures. Parse the input and enumerate the \(2^\tau\) type subsets. In an adjacency-matrix implementation, admissibility, completeness, stability and ranges each require \(O(\tau^2)\) operations per subset.

\(O(2^\tau\tau^2+L^{O(1)})\).

For semi-stable acceptance, enumerate all admissible sets and compare their ranges pairwise. This gives the sufficient bound

\(O(4^\tau\tau^2+L^{O(1)})\).
