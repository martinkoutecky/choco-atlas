The continuous mirror question, as graded

Given a candidate set \(C\), cohort size \(k\), finite type support \(T\) with rational masses \(\mu_t>0\), candidate values \(v_{tc}\), and named groups \(G_1,\ldots,G_m\) encoded by membership indicators \(a_{tj}\), define \(U_j(S)=\frac{\sum_{t\in T}\mu_t a_{tj}\sum_{c\in S}v_{tc}}{\sum_{t\in T}\mu_t a_{tj}}\). For fixed \(0\le\epsilon<1/2\), compute a cohort \(S\subseteq C\) of size \(k\) whose minimum group utility is within additive \(\epsilon\) of the optimum; classify the problem’s complexity in \(m\), \(|T|\), input bit length, and other relevant parameters.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The input also gives a candidate set \(C\) with \(n=|C|\), an integer \(1\le k\le n\), binary rational values \(v_{tc}\in[0,1]\), and \(m\ge1\) named, possibly overlapping groups with indicators \(a_{tj}\in\{0,1\}\). Every group has positive mass \(M_j=\sum_t\mu_ta_{tj}>0\).
A feasible cohort is a deterministic subset \(S\subseteq C\) with \(|S|=k\). Define \(U_j(S)=M_j^{-1}\sum_t\mu_ta_{tj}\sum_{c\in S}v_{tc}\); candidate contributions are summed, without division by \(k\).
Fix a rational constant \(0\le\epsilon<1/2\). Let \(\mathrm{OPT}=\max_{|S|=k}\min_{1\le j\le m}U_j(S)\). The computational problem is to output a feasible \(S\) satisfying \(\min_jU_j(S)\ge\mathrm{OPT}-\epsilon\). Let \(L\) be the total binary input length.

Is this additive approximation problem solvable in polynomial time in \(n,m,\tau,k,L\), or is it NP-hard, for each fixed \(0\le\epsilon<1/2\)?

For directly specified group–candidate values, deterministic cardinality-constrained maxmin cohort selection is NP-hard even with additive error \(\epsilon<1/2\) and binary values. [Verified source](https://arxiv.org/pdf/2205.01157).
For linear group utilities, polynomial-time algorithms compute leximax marginal selection probabilities and hence optimal minimum utility in expectation; their outputs are randomized cohorts, whereas the problem above requires a deterministic cohort. [Verified source](https://arxiv.org/pdf/2205.01157).

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one; the group averages are invariant under common rescaling.
  • Specified candidate values as binary rationals in [0,1], following the linear utility model.
  • Required every named group to have positive mass so that its utility is defined; allowed overlapping groups.
  • Required at least one group and an integer cohort size between one and the number of candidates.
  • Retained summed candidate contributions without division by cohort size, following the displayed optimization problems and hardness reduction.
  • Specified epsilon as a fixed rational constant and defined approximation as a one-sided additive guarantee for the returned feasible cohort.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is \(\mathrm{NP}\)-hard for every fixed \(0\le\epsilon<1/2\), even when all values are binary, all masses are equal, and the groups are disjoint singleton types. Thus a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\). In fact, the proof works for every fixed \(0\le\epsilon<1\).

Construction. We reduce from the standard \(\mathrm{NP}\)-complete problem of deciding satisfiability of a Boolean formula in conjunctive normal form with three literals per clause.

Let the formula have variables \(x_1,\ldots,x_p\), with \(p\ge1\), and clauses \(D_1,\ldots,D_q\). Introduce two candidates \(c_i^+\) and \(c_i^-\) for each variable, representing its positive and negative literals. Set
\[ n=2p,\qquad k=p. \]

Introduce one type for each variable and one type for each clause:
\[ T=\{t_1,\ldots,t_p,s_1,\ldots,s_q\},\qquad \tau=p+q. \]
Give every type mass \(1/(p+q)\). For each type \(t\), introduce a named group containing exactly that type. Consequently,
\[ m=\tau,\qquad M_t=\mu_t=\frac1{p+q}>0. \]

Define binary candidate values as follows:

  • The variable type \(t_i\) values precisely \(c_i^+\) and \(c_i^-\) at one.
  • The clause type \(s_r\) values a candidate at one precisely when its represented literal occurs in \(D_r\).

All remaining values are zero. Because every group is a singleton, its normalization cancels its type mass:
\[ U_t(S)=\frac{\mu_t\sum_{c\in S}v_{tc}}{\mu_t} =\sum_{c\in S}v_{tc}. \]
Thus every group utility is a nonnegative integer.

The construction satisfies every input hypothesis, including \(1\le k\le n\). Its explicit value matrix has \((p+q)2p\) entries, its group-indicator matrix has \((p+q)^2\) entries, and each mass requires \(O(\log(p+q))\) bits. Hence its total encoding length is polynomial in the formula’s length.

Correctness and objective gap. Write \(F(S)=\min_t U_t(S)\).

If the formula is satisfiable, select exactly the candidate representing the true literal of each variable. This gives a feasible cohort of size \(p\). Every variable group has utility one, and every clause group has utility at least one because the assignment satisfies that clause. Therefore \(F(S)=1\).

Conversely, suppose a feasible cohort satisfies \(F(S)>0\). Integer utilities imply that every variable group has utility at least one. The \(p\) variable pairs partition the candidates, so
\[ \sum_{i=1}^p U_{t_i}(S)=|S|=p. \]
Each of these \(p\) summands is at least one; consequently each equals one. The cohort therefore selects exactly one candidate from every variable pair and defines a consistent truth assignment. Every clause group also has positive utility, so each clause contains a selected literal. This assignment satisfies the formula.

Moreover, for every feasible cohort, the displayed sum shows that some variable group has utility at most one. Hence \(F(S)\le1\). We have proved the exact gap
\[ \mathrm{OPT}= \begin{cases} 1,&\text{if the formula is satisfiable},\\ 0,&\text{if the formula is unsatisfiable}. \end{cases} \]

Consequence for approximation. Suppose a polynomial-time algorithm always outputs the required deterministic cohort. On a satisfiable instance, its output must satisfy
\[ F(S)\ge1-\epsilon>0. \]
On an unsatisfiable instance, every feasible output satisfies \(F(S)=0\). Checking whether the returned cohort has positive utility for every group therefore decides satisfiability in polynomial time. This proves the claimed hardness.

The singleton construction also explains why specifying utilities through an explicit society support does not remove the direct group–candidate hardness discussed in [Lemma 20 of the supplied paper](https://arxiv.org/pdf/2205.01157). Guarantees for expected utilities do not provide the deterministic cohort required by this reduction.
