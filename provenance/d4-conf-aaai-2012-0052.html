The continuous mirror question, as graded

Given \(C,A,p,\ell\), fixed \(k\ge 2\), and complete ranking types \(T\) over \(C\cup A\) with rational masses \(\mu_t\) summing to \(1\), compute the number of sets \(A'\subseteq A\) with \(|A'|\le\ell\) for which \(p\) is the unique \(k\)-Approval winner after restricting each type to \(C\cup A'\), where \(\operatorname{score}_{\mu,A'}(c)=\sum_{t\in T}\mu_t\mathbf{1}[c\text{ is top-}k].\)

Packaged proof task (what the prover saw — nothing else)

Let \(C\) and \(A\) be disjoint finite sets of registered and available candidates, with \(p\in C\), and let \(\ell\ge 0\) be a binary-encoded integer. Fix an integer \(k\ge 2\); put \(m=|C\cup A|\).
A society is given by its support: the list of \(\tau\) distinct unrestricted strict complete ranking types over \(C\cup A\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
For each \(A'\subseteq A\), restrict rankings to \(C\cup A'\) and apply mass-weighted \(k\)-Approval: \(s_{A'}(c)=\sum_t\mu_t\mathbf{1}[c\text{ occupies one of the first }\min\{k,|C\cup A'|\}\text{ positions}]\).
Let \(N\) be the number of sets \(A'\subseteq A\) with \(|A'|\le\ell\) such that \(s_{A'}(p)>s_{A'}(c)\) for every \(c\in(C\cup A')\setminus\{p\}\). Ties do not qualify, and each candidate set is counted once.

For each fixed \(k\ge 2\), is exact computation of \(N\) possible in polynomial time in \(m,\tau,L,\ell\), or is it \(\mathrm{NP}\)-hard?

For finite explicitly listed unweighted voters, counting these successful candidate additions is \(\#\mathrm{P}\)-complete under parsimonious reductions for every fixed \(k\ge 2\). [Wojtas et al.](https://arxiv.org/pdf/1405.6630)
No separate result for exactly the normalized rational-mass support formulation was located in the literature search.

Modeling choices made when packaging the task

  • Specified that C and A are disjoint, p belongs to C, and the addition budget is a nonnegative binary-encoded integer, following the discrete control definition.
  • Specified strict complete rankings and strict score superiority over every present rival, following the unique-winner model.
  • When fewer than k candidates are present, all present candidates receive approval; singleton elections are retained, as allowed by the discrete definition.
  • Defined m as the total candidate-universe size and L as the total input bit length; fixed k is not an input parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed \(k\ge 2\), exact computation of \(N\) is \(\#\mathrm{P}\)-complete under polynomial-time parsimonious reductions. In particular, it is \(\mathrm{NP}\)-hard.

The normalization and aggregation of identical rankings preserve the number of successful candidate sets exactly.

1. The discrete hardness theorem

We use the following established result: for every fixed \(k\ge 2\), counting the sets of at most \(\ell\) available candidates whose addition makes \(p\) the unique \(k\)-Approval winner, with unrestricted rankings and explicitly listed unweighted voters, is \(\#\mathrm{P}\)-complete under parsimonious reductions. This is Theorem 4.5 of [Wojtas et al., *Possible Winners in Noisy Elections*](https://arxiv.org/pdf/1405.6630). Their Definition 3.1 specifies the unique-winner condition and the upper bound on the number of added candidates; their complexity convention defines \(\#\mathrm{P}\)-completeness using parsimonious reductions.

Thus the source problem counts exactly the same kind of candidate sets as the present problem. The difference is the representation of the electorate.

2. A parsimonious reduction to normalized support

Fix \(k\ge 2\). Consider a source instance with candidate sets \(C,A\), designated candidate \(p\), budget \(\ell\), and \(n\ge 1\) explicitly listed voters. Each voter has a strict complete ranking over \(C\cup A\).

First replace the budget by \(\ell_0=\min\{\ell,|A|\}\). This preserves all feasible candidate sets.

Group voters having identical rankings. Let \(R_1,\ldots,R_\tau\) be the distinct rankings and let \(n_t\) be the number of voters with ranking \(R_t\). Construct the target society using these rankings with masses

\(\displaystyle \mu_t=\frac{n_t}{n}\quad(t=1,\ldots,\tau).\)

Every mass is positive, the rankings are distinct, and \(\sum_{t=1}^{\tau}\mu_t=1\). Encode each rational by its binary numerator and denominator.

Polynomial size and construction time

Identical rankings can be grouped by sorting or pairwise comparison in polynomial time. Moreover, \(\tau\le n\), and each numerator and denominator requires at most \(O(\log(n+1))\) bits. The rankings are copied from the source input, so the entire target encoding has polynomial length in the source encoding.

The construction preserves \(C,A,p\), and \(k\), and uses budget \(\ell_0\le |A|\le m\).

Preservation of every score comparison

Fix any \(A'\subseteq A\) and any \(c\in C\cup A'\). Let \(u_{A'}(c)\) be the unweighted score in the source election after restricting rankings to \(C\cup A'\). Define \(I_t(A',c)\) to equal \(1\) precisely when \(c\) occupies one of the first \(\min\{k,|C\cup A'|\}\) positions in restricted ranking \(R_t\), and \(0\) otherwise.

Grouping identical rankings gives

\(\displaystyle u_{A'}(c)=\sum_{t=1}^{\tau}n_t I_t(A',c).\)

The corresponding target score satisfies

\(\displaystyle s_{A'}(c)=\sum_{t=1}^{\tau}\frac{n_t}{n}I_t(A',c)=\frac{u_{A'}(c)}{n}.\)

Because \(n>0\), for every opponent \(c\),

\(\displaystyle s_{A'}(p)>s_{A'}(c)\quad\Longleftrightarrow\quad u_{A'}(p)>u_{A'}(c).\)

Consequently, each candidate set succeeds in the target instance exactly when it succeeds in the source instance. Ties are preserved as well. Since candidate sets themselves are unchanged, this is a parsimonious reduction.

For completeness, if zero-voter source instances are permitted, their count is \(1\) when \(C=\{p\}\), and \(0\) otherwise: all scores are zero, so only an election containing \(p\) alone qualifies. These cases map respectively to fixed target instances with \(A=\varnothing\), one ranking of mass \(1\), and registered sets \(\{p\}\) or \(\{p,q\}\). In the latter instance both candidates receive approval because \(k\ge 2\).

The cited theorem and this reduction establish \(\#\mathrm{P}\)-hardness.

3. Membership in \(\#\mathrm{P}\)

A witness is the characteristic vector of a subset \(A'\subseteq A\). This uses exactly \(|A|\) bits and represents each candidate set once.

The verifier first checks \(|A'|\le\ell\), then computes the scores and checks all required strict inequalities. We verify that these computations take polynomial bit complexity.

Write each input mass as \(\mu_t=a_t/b_t\), with positive binary integers \(a_t,b_t\). Set

\(\displaystyle D=\prod_{t=1}^{\tau}b_t,\qquad w_t=a_t(D/b_t).\)

These are integers, and normalization implies \(\sum_t w_t=D\). The bit length of \(D\) is bounded by \(\sum_t\operatorname{bitlength}(b_t)\), hence by \(O(L)\). All products and exact divisions therefore take polynomial time.

For each candidate define the integer score

\(\displaystyle S_{A'}(c)=\sum_{t=1}^{\tau}w_t I_t(A',c).\)

It satisfies \(S_{A'}(c)=D\,s_{A'}(c)\) and \(0\le S_{A'}(c)\le D\). Thus score comparisons involve integers with \(O(L)\) bits. Scanning each listed ranking determines its approved candidates after restriction in \(O(m)\) steps, giving polynomial verification time overall.

A nondeterministic machine guesses the \(|A|\)-bit characteristic vector and accepts exactly when this verifier succeeds. It has exactly \(N\) accepting branches. Hence \(N\in\#\mathrm{P}\).

4. Consequence for the requested running time

Combining hardness and membership proves \(\#\mathrm{P}\)-completeness.

The decision problem \(N>0\) is also \(\mathrm{NP}\)-complete: it has the verifier above, and a parsimonious reduction from counting satisfying assignments preserves whether the count is positive. Computing \(N\) exactly therefore decides an \(\mathrm{NP}\)-complete problem.

Finally, allowing running time polynomial in the *numerical value* of \(\ell\) does not avoid this hardness. Every instance can be replaced by an equivalent one with \(\ell\le |A|\le m\), as in the reduction. Such an exact algorithm would therefore imply \(\mathrm{P}=\mathrm{NP}\).
