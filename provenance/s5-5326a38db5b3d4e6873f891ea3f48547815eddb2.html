Theorem 7 — class: algorithmic

The continuous mirror question, as graded

Given finite types \(T\) with rational masses \(\mu_t\), item classes \(G\) with rational per-capita supplies \(q_g\), additive values \(v_t(g)\), and a uniform bundle cap \(k\), let \(\mathcal B=\{B\subseteq G:|B|\le k\}\) and define \(\mu_t^\infty=\max_{\rho}\min_{\rho_B>0}v_t(B)\), where \(\rho\) ranges over distributions on \(\mathcal B\) satisfying \(\sum_B\rho_B=1\) and \(\sum_{B\ni g}\rho_B=q_g\). Compute, in time polynomial in the compressed input size, an aggregate allocation \(x_{t,B}\ge0\) satisfying \(\sum_Bx_{t,B}=\mu_t\), \(\sum_{t,B\ni g}x_{t,B}=q_g\), and \(x_{t,B}>0\Rightarrow v_t(B)\ge(2/3)\mu_t^\infty\) for every type \(t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau=|T|\ge1\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=|G|\ge1\) item classes, binary rational supplies \(q_g\in[0,1]\), nonnegative binary rational additive values \(v_t(g)\), and an integer cap \(1\le k\le m\); assume \(\sum_gq_g\le k\). Let \(L\) be the total input bit length.
Each person receives at most one item from each class. Feasible bundles are \(\mathcal B=\{B\subseteq G:|B|\le k\}\), including the empty bundle, with \(v_t(B)=\sum_{g\in B}v_t(g)\).
Let \(\mathcal D(q)=\{\rho\ge0:\sum_{B\in\mathcal B}\rho_B=1,\ \sum_{B\ni g}\rho_B=q_g\text{ for every }g\}\), and define \(\mu_t^\infty=\max_{\rho\in\mathcal D(q)}\min_{B:\rho_B>0}v_t(B)\).
An aggregate allocation is a sparse list of nonzero binary rational entries \(x_{t,B}\ge0\), with omitted entries zero, satisfying \(\sum_Bx_{t,B}=\mu_t\) and \(\sum_t\sum_{B\ni g}x_{t,B}=q_g\).
The \(2/3\) guarantee requires \(x_{t,B}>0\Rightarrow v_t(B)\ge\frac23\mu_t^\infty\) for every \(t\) and \(B\).

Can an aggregate allocation satisfying the \(2/3\) guarantee always be computed in time polynomial in \(m,\tau,k,L\), or is achieving this guarantee NP-hard?

For finite agents with nonnegative additive valuations and a uniform bundle cap, complete \(2/3\)-MMS allocations exist and are computable in polynomial time. [Hummel–Hetland](https://link.springer.com/article/10.1007/s10458-026-09731-1)
The related AnyPrice share uses distributions over bundles with a common upper bound on item marginals; polynomial-time \(3/5\) guarantees are known for finite additive agents without bundle caps. This does not settle the specified mass allocation problem; no result settling it was identified in the search. [Babaioff–Ezra–Feige](https://arxiv.org/html/2103.04304)

Modeling choices made when packaging the task

  • Normalized total society mass to one so that per-capita supplies agree with both the benchmark marginals and aggregate supply equalities.
  • Specified nonnegative binary rational valuations, retaining zero valuations as allowed in the discrete goods model.
  • Required supplies in [0,1] and total supply at most k, carrying over feasibility while respecting the prescribed subset bundle domain.
  • Made explicit that each bundle contains at most one item per class and may be empty.
  • Took the cap to be a positive input integer at most m; larger caps are equivalent to m.
  • Specified sparse rational allocation representation so that the computational question does not require writing exponentially many zero entries.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Polynomial-time solvability

An aggregate allocation satisfying the \(2/3\) guarantee can always be computed in time polynomial in \(m,\tau,k,L\). The proof uses a polynomial-size linear program built from rounded bundle values.

In fact, the same construction gives a polynomial-time approximation scheme.

1. Types can be treated independently

Suppose that, for each type \(t\), we compute a distribution \(\rho^t\in\mathcal D(q)\) whose supported bundles satisfy

\[ v_t(B)\ge \frac23\mu_t^\infty. \]

Define \(x_{t,B}=\mu_t\rho^t_B\). Then

\[ \sum_Bx_{t,B}=\mu_t, \qquad \sum_t\sum_{B\ni g}x_{t,B} =\sum_t\mu_tq_g=q_g. \]

Thus it suffices to solve the following single-type problem: find a distribution with exactly the prescribed marginals \(q\), supported on bundles worth at least two-thirds of the maximum attainable minimum value.

First, \(\mathcal D(q)\) is nonempty. Indeed, consider

\[ P=\left\{y\in[0,1]^m:\sum_gy_g\le k\right\}. \]

Every vertex of \(P\) is integral. If a point has two fractional coordinates, sufficiently small opposite perturbations of those coordinates preserve feasibility, so it is not a vertex. If it has exactly one fractional coordinate, the sum constraint cannot be tight, because \(k\) and all other coordinates are integral; sufficiently small positive and negative perturbations again preserve feasibility. Consequently, \(P\) is the convex hull of incidence vectors of bundles of size at most \(k\). The assumptions give \(q\in P\), proving the assertion.

Moreover, the maximum defining \(\mu_t^\infty\) is attained: every distribution’s minimum supported value belongs to the finite set of bundle values, and there is at least one feasible distribution.

2. Integer scaling and rounded bundle families

Fix one type and suppress its subscript. Write each rational value as \(v(g)=p_g/d_g\), with integer \(p_g\ge0\) and \(d_g\ge1\). Set

\[ D=\prod_gd_g,\qquad a_g=Dv(g)\in\mathbb Z_{\ge0}, \qquad a(B)=\sum_{g\in B}a_g. \]

The binary lengths of \(D\), all \(a_g\), and \(U=\sum_ga_g\) are polynomial in the input length.

Let \(M=D\mu^\infty\). Since the optimal minimum is attained and every scaled bundle value is an integer, \(M\) is an integer with \(0\le M\le U\).

For an integer threshold \(s\ge1\), define

\[ H=2k,\qquad w_g(s)=\min\left\{H,\left\lfloor\frac{3ka_g}{s}\right\rfloor\right\}, \]

and let

\[ \mathcal F_s= \left\{B\subseteq G: |B|\le k,\ \sum_{g\in B}w_g(s)\ge H \right\}. \]

Also define \(\mathcal F_0=\mathcal B\).

Rounded-family lemma. For every \(s\ge1\),

\[ \{B\in\mathcal B:a(B)\ge s\} \subseteq\mathcal F_s \subseteq \{B\in\mathcal B:a(B)\ge\tfrac23s\}. \]

Proof. Suppose \(a(B)\ge s\). If some \(w_g(s)=H\) for \(g\in B\), then \(B\in\mathcal F_s\). Otherwise none of the weights in \(B\) is truncated, and

\[ \sum_{g\in B}w_g(s) \ge \frac{3ka(B)}s-|B| \ge 3k-k=2k. \]

Hence \(B\in\mathcal F_s\).

Conversely, each weight satisfies \(w_g(s)\le3ka_g/s\). Therefore, if \(B\in\mathcal F_s\),

\[ a(B)\ge\frac{s}{3k}\sum_{g\in B}w_g(s) \ge\frac{s}{3k}\,2k=\frac23s. \]

This proves both inclusions.

For increasing positive \(s\), every \(w_g(s)\) is nonincreasing. Thus the families \(\mathcal F_s\) are nested: if \(s'\ge s\), then \(\mathcal F_{s'}\subseteq\mathcal F_s\).

3. An exact polynomial-time feasibility oracle

We now decide whether a distribution with marginals \(q\) can be supported entirely on \(\mathcal F_s\).

For \(s\ge1\), construct a layered directed acyclic graph. Its states are

\[ (i,c,h), \qquad 0\le i\le m,\quad 0\le c\le k,\quad 0\le h\le H. \]

Here \(i\) is the number of classes considered, \(c\) is the number selected, and \(h\) is the rounded value accumulated, capped at \(H\).

The source is \((0,0,0)\). From a state \((i,c,h)\), with \(i<m\), include:

  • a skip arc to \((i+1,c,h)\);
  • if \(c<k\), a take arc to \((i+1,c+1,\min\{H,h+w_{i+1}(s)\})\).

Connect each state \((m,c,H)\) to a common sink. Every source-to-sink path selects exactly one bundle in \(\mathcal F_s\), and every bundle in \(\mathcal F_s\) defines such a path.

Introduce a nonnegative flow variable \(f_e\) for every arc. Require unit source-to-sink flow and flow conservation at every other vertex. For every class \(g\), additionally impose

\[ \sum_{\substack{e\text{ is a take arc}\\ e\text{ selects class }g}}f_e=q_g. \]

This is a rational linear program with \(O(mk^2)\) variables and constraints. Its coefficients are in \(\{-1,0,1\}\), and its right-hand sides are \(0,1\), and the supplied rationals \(q_g\).

Oracle equivalence. This linear program is feasible if and only if there is a distribution with marginals \(q\) supported on \(\mathcal F_s\).

Proof. Given such a distribution, route each bundle’s probability along its corresponding path. This satisfies every flow and marginal equation.

Conversely, any feasible flow decomposes into source-to-sink paths because the graph is acyclic. Explicitly, repeatedly choose a path of positive-flow arcs and subtract the minimum flow along it. Each subtraction eliminates at least one positive-flow arc. Hence at most \(O(mk^2)\) paths are needed. Their weights sum to one, and the marginal equations give exactly the required inclusion probabilities \(q_g\).

For \(s=0\), use the same construction with states \((i,c)\), omitting the rounded-value coordinate and allowing every final state to reach the sink. This represents all feasible bundles, so its linear program is feasible by Section 1.

We use the standard rational linear-programming theorem: feasibility is decidable in polynomial time, and a feasible rational solution of polynomial encoding length can be returned. Its hypotheses hold here because the linear program has polynomial size and rational coefficients of polynomial encoding length.

The subsequent path decomposition also preserves polynomial encoding length. For example, take the product of the denominators of the returned arc flows as a common denominator; its binary length is polynomial. All subtraction steps preserve that common denominator.

4. Binary search gives the required guarantee

Let \(F(s)\) denote the oracle’s feasibility answer. Since the rounded families are nested, \(F(s)\) is monotone: feasibility at a larger threshold implies feasibility at every smaller threshold.

Binary search over the integers \(0,\ldots,U\) therefore finds the largest feasible threshold \(s^*\) in \(O(1+\log(U+1))\) oracle calls.

Crucially,

\[ s^*\ge M. \]

If \(M=0\), this is immediate. If \(M>0\), an optimal distribution is supported on bundles with \(a(B)\ge M\). The rounded-family lemma places all those bundles in \(\mathcal F_M\), so \(F(M)\) is feasible.

Extract a rational distribution \(\rho\) from the feasible flow at \(s^*\). If \(s^*>0\), every supported bundle satisfies

\[ v(B)=\frac{a(B)}D \ge\frac{2s^*}{3D} \ge\frac{2M}{3D} =\frac23\mu^\infty. \]

If \(s^*=0\), then \(M=0\), and nonnegativity of the valuations gives the same guarantee.

Thus the single-type problem is solved.

5. Aggregate allocation and complexity

Apply the preceding algorithm independently to every type, obtaining distributions \(\rho^t\), and output the nonzero entries

\[ x_{t,B}=\mu_t\rho^t_B. \]

Section 1 proves the mass and supply equalities. Section 4 proves the \(2/3\) guarantee for every positive entry.

Each type contributes at most \(O(mk^2)\) supported bundles through path decomposition. All probabilities and their products with the type masses have polynomial binary encoding length.

Each threshold test uses a linear program of size \(O(mk^2)\), and the number of tests is polynomial in the binary input length. Repeating this for the explicitly listed \(\tau\) types gives total running time and output length polynomial in \(m,\tau,k,L\).

6. Stronger approximation guarantee

For any integer \(r\ge2\), replace the rounding parameters by

\[ H=(r-1)k,\qquad w_g(s)=\min\left\{H,\left\lfloor\frac{rka_g}{s}\right\rfloor\right\}. \]

The same proof gives

\[ \{B:a(B)\ge s\} \subseteq\mathcal F_s \subseteq \{B:a(B)\ge(1-\tfrac1r)s\}. \]

The graph has size \(O(mrk^2)\). Choosing \(r=\lceil1/\varepsilon\rceil\), for \(0<\varepsilon<1\), therefore yields a \((1-\varepsilon)\) guarantee in time polynomial in \(m,\tau,k,L,1/\varepsilon\).
