The continuous mirror question, as graded

Given a finite set of institutional types \(T\), rational masses \(\mu_t\) summing to \(1\), and each type’s norm net, representation function \(\rho_t\), cost function \(c_t\), and per-capita budget \(b_t\), let \(\mathcal S_t\) be its sound norm systems. Choose masses \(y_{t,\Omega}\ge 0\) with \(\sum_{\Omega\in\mathcal S_t} y_{t,\Omega}=\mu_t\) and \(\sum_{\Omega\in\mathcal S_t} y_{t,\Omega}c_t(\Omega)\le\mu_t b_t\) for each type. Maximize \(\sum_{t\in T,\Omega\in\mathcal S_t}y_{t,\Omega}\rho_t(\Omega)\), breaking ties by minimizing aggregate cost.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) institutional types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a nonempty norm set \(N_t\), with \(m=\max_t|N_t|\), and three explicitly listed, pairwise disjoint relations: symmetric irreflexive exclusivity \(R_{x,t}\), symmetric irreflexive substitutability \(R_{s,t}\), and acyclic, transitively reduced direct generalisation \(R_{g,t}\), directed from general to specific norms.
Let \(S_t\) connect distinct norms joined by a substitutability path, and let \(C_t(n)=\{n':(n,n')\in R_{g,t}\}\). A system \(\Omega\subseteq N_t\) is sound if it contains no exclusive pair, no pair in \(S_t\), and no pair connected by a directed generalisation path; additionally, \(C_t(n)\nsubseteq\Omega\) whenever \(C_t(n)\ne\varnothing\). The empty system is allowed. Let \(\mathcal S_t\) denote this implicitly specified family.
The input supplies binary-rational norm weights \(r_t(n)\in\mathbb Q\), costs \(c_t(n)\in\mathbb Q_{\ge0}\), and budgets \(b_t\in\mathbb Q_{\ge0}\). Require \(r_t(n')\le r_t(n)\) whenever a generalisation path leads from \(n\) to \(n'\). Define \(\rho_t(\Omega)=\sum_{n\in\Omega}r_t(n)\) and \(c_t(\Omega)=\sum_{n\in\Omega}c_t(n)\). Let \(L\) be the total binary input length; sound systems are not enumerated in the input.
Choose real masses \(y_{t,\Omega}\ge0\) satisfying \(\sum_{\Omega\in\mathcal S_t}y_{t,\Omega}=\mu_t\) and \(\sum_{\Omega\in\mathcal S_t}y_{t,\Omega}c_t(\Omega)\le\mu_tb_t\) for every type. Maximize \(\sum_{t\in T}\sum_{\Omega\in\mathcal S_t}y_{t,\Omega}\rho_t(\Omega)\), breaking ties by minimizing \(\sum_{t\in T}\sum_{\Omega\in\mathcal S_t}y_{t,\Omega}c_t(\Omega)\).

Is this exact lexicographic optimization problem solvable in time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

Result

The exact lexicographic optimization problem is \(\mathrm{NP}\)-hard, already when \(\tau=1\), only exclusivity is present, and all norm weights and costs equal \(1\).

The cited paper’s Lemma 1 uses independent sets to establish discrete hardness. The proof below explicitly checks that allowing fractional mass allocations preserves hardness. [Serramia et al., *Moral Values in Norm Decision Making*](https://ifaamas.org/Proceedings/aamas2018/pdfs/p1294.pdf)

Polynomial reduction

We reduce from the standard \(\mathrm{NP}\)-complete Independent Set decision problem: given a finite simple undirected graph \(G=(V,E)\) and an integer \(k\), determine whether \(G\) contains an independent set of cardinality at least \(k\). Here an independent set is a vertex subset containing no edge of \(G\).

We may restrict to instances with \(n=|V|\ge 1\) and \(1\le k\le n\), since instances outside these bounds are decided immediately.

Construct a society with one type \(t\), as follows:

  • Set \(T=\{t\}\), \(\mu_t=1\), and \(N_t=V\).
  • Set \(R_{x,t}=\{(u,v),(v,u):\{u,v\}\in E\}\).
  • Set \(R_{s,t}=R_{g,t}=\varnothing\).
  • For every \(v\in V\), set \(r_t(v)=c_t(v)=1\).
  • Set \(b_t=k\).

This satisfies every input hypothesis. Exclusivity is symmetric and irreflexive because \(G\) is simple. The three relations are pairwise disjoint. The empty generalisation relation is acyclic and transitively reduced, and the weight monotonicity requirement is vacuous. All numerical data are admissible binary rationals.

Since substitutability and generalisation are absent, \(S_t=\varnothing\) and \(C_t(v)=\varnothing\) for every norm \(v\). Consequently, a system is sound exactly when it is an independent set of \(G\).

The construction has \(m=n\), \(\tau=1\), and binary input length polynomial in the graph instance’s encoding length. It can therefore be performed in polynomial time.

Exact value of the fractional optimum

Write \(\alpha(G)\) for the maximum cardinality of an independent set of \(G\), and abbreviate \(y_{t,\Omega}\) to \(y_\Omega\).

For every sound system \(\Omega\), the unit weights and costs give
\(\rho_t(\Omega)=c_t(\Omega)=|\Omega|\).
Thus any feasible allocation satisfies
\[ \text{(equivalently, in inline notation)}\qquad \]
\(\displaystyle \sum_{\Omega\in\mathcal S_t}y_\Omega=1,\qquad \sum_{\Omega\in\mathcal S_t}y_\Omega|\Omega|\le k.\)

Define its primary objective value by
\(\displaystyle R(y)=\sum_{\Omega\in\mathcal S_t}y_\Omega|\Omega|.\)

Every sound system has cardinality at most \(\alpha(G)\). Nonnegativity and total mass \(1\) therefore imply
\(\displaystyle R(y)\le \sum_{\Omega\in\mathcal S_t}y_\Omega\alpha(G) =\alpha(G).\)
The budget also gives \(R(y)\le k\). Hence
\(\displaystyle R(y)\le\min\{\alpha(G),k\}.\)

This bound is attained in both possible cases:

  • If \(\alpha(G)\ge k\): a maximum independent set contains a subset \(I\) of exactly \(k\) vertices. Subsets of independent sets are independent, so \(I\) is sound. Assigning \(y_I=1\) and all other masses \(0\) is feasible and gives \(R(y)=k\).
  • If \(\alpha(G)<k\): take a maximum independent set \(I\). Assigning \(y_I=1\) and all other masses \(0\) is feasible because its cost is \(\alpha(G)<k\), and gives \(R(y)=\alpha(G)\).

It follows that the exact primary optimum is
\(\displaystyle R^*=\min\{\alpha(G),k\}.\)

Moreover, the total cost equals \(R(y)\) for every allocation. All primary maximizers therefore have the same total cost \(R^*\), so the secondary minimization leaves this optimum unchanged.

Complexity conclusion

The reduction establishes the equivalence
\(\displaystyle G\text{ has an independent set of size at least }k \quad\Longleftrightarrow\quad R^*=k.\)

Thus computing the exact lexicographic optimum would decide Independent Set. An algorithm polynomial in \(m,\tau,L\) would run in polynomial time on the constructed instances and imply \(\mathrm P=\mathrm{NP}\).

Fractional allocation does not invalidate the reduction: its primary objective is an average of independent-set cardinalities, and such an average cannot exceed \(\alpha(G)\). The budget caps that average at \(k\), and the proof establishes exactly when this cap is achievable.
