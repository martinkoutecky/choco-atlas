The continuous mirror question, as graded

Given a finite alternative set \(A\) and two finitely supported distributions \(\mu^{(1)},\mu^{(2)}\) over complete rankings of \(A\), with binary-rational masses summing to one in each panel, does there exist a monotonic positional scoring vector \(s\), where \(1=s_1\ge\cdots\ge s_m=0\), such that both panels induce the same strict ranking? For each panel \(j\), define \(S_j^s(a)=\sum_{\rho}\mu_\rho^{(j)}s_{\operatorname{rank}_\rho(a)}\); the condition is \((S_1^s(a)-S_1^s(b))(S_2^s(a)-S_2^s(b))>0\) for every distinct \(a,b\in A\).

Write \(\tau_j\) for panel \(j\)'s support size and \(\tau=\tau_1+\tau_2\); these count listed types, not the \(m!\) possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A common scoring vector is \(s\in\mathbb R^m\) satisfying \(1=s_1\ge\cdots\ge s_m=0\). For panel \(j\in\{1,2\}\), define \(S_j^s(a)=\sum_{\rho\in\operatorname{supp}(\mu^{(j)})}\mu^{(j)}_\rho s_{\operatorname{rank}_\rho(a)}\).
Call \(s\) feasible when \((S_1^s(a)-S_1^s(b))(S_2^s(a)-S_2^s(b))>0\) for every distinct \(a,b\in A\): both score orders must be strict and identical, with no tie-breaking.

Result

The problem is \(\mathsf{NP}\)-complete, even when every mass is dyadic, meaning its denominator is a power of two. Thus a polynomial-time algorithm in \(m,\tau,L\) exists only if \(\mathsf{P}=\mathsf{NP}\).

The proof uses the cited hardness theorem and an exact encoding reduction; it does not expand a rational support into a potentially exponentially large panel.

1. The known hardness theorem

We use the following result: given two explicitly listed panels, each containing \(n\) strict complete rankings of the same alternatives, deciding whether some normalized monotonic scoring vector produces identical strict score orders is \(\mathsf{NP}\)-complete. This is Theorem 3 in [Berker, Armstrong, Conitzer, and Shah, Section 6](https://arxiv.org/html/2508.17177v1#S6).

Its hypotheses match the required scoring-vector normalization. Moreover, the source’s definition of disagreement assigns a positive penalty to any tied pair. Consequently, zero disagreement requires identical strict score orders, with no tie-breaking.

2. Membership in \(\mathsf{NP}\)

Define the rank probabilities

\(p_j(a,r)=\sum_{\rho:\operatorname{rank}_{\rho}(a)=r}\mu^{(j)}_\rho\).

Then \(S_j^s(a)=\sum_{r=1}^{m}p_j(a,r)s_r\).

A permutation \(\pi=(a_1,\ldots,a_m)\) is the common strict score order exactly when

\(\sum_{r=1}^{m}\bigl(p_j(a_i,r)-p_j(a_{i+1},r)\bigr)s_r>0\)

for both \(j\in\{1,2\}\) and every \(i\in\{1,\ldots,m-1\}\). Adjacent inequalities suffice: summing them gives the strict inequality for any earlier and later alternatives.

We now prove that every yes-instance has a rational scoring vector of polynomial encoding length.

Write each input mass as \(u_\rho^{(j)}/d_\rho^{(j)}\), and let \(Q\) be the product of all listed denominators. Since their total binary encoding length is at most \(L\), we have \(\log_2 Q\le L\). Set

\(B_j(a,r)=Qp_j(a,r)\).

These are integers satisfying \(0\le B_j(a,r)\le Q\).

Suppose a feasible scoring vector exists, and let \(\pi\) be its common strict order. Consider the linear program with variables \(s_1,\ldots,s_m,w\):

  • maximize \(w\);
  • require \(s_1=1\), \(s_m=0\), and \(s_r\ge s_{r+1}\) for every \(r<m\);
  • require \(0\le w\le Q\);
  • require \(\sum_{r=1}^{m}\bigl(B_j(a_i,r)-B_j(a_{i+1},r)\bigr)s_r\ge w\) for both panels and every adjacent pair in \(\pi\).

The assumed feasible vector satisfies this program with positive \(w\): choose \(w\) to be the minimum of its finitely many positive, \(Q\)-scaled adjacent score gaps. Each such gap is at most \(Q\), because normalized average scores lie in \([0,1]\).

The feasible region is a nonempty compact polytope. Therefore the maximum is attained at a vertex, and its value is positive. At a vertex, \(m+1\) linearly independent active constraints determine all variables. Their coefficients and right-hand sides are integers of absolute value at most \(Q\).

By Cramer’s rule, these coordinates have a common denominator \(D\), with numerators and denominator bounded in absolute value by

\((m+1)!\,Q^{m+1}\).

Indeed, each relevant determinant has at most \((m+1)!\) terms, each of absolute value at most \(Q^{m+1}\). After choosing \(D>0\), we may therefore write \(s_r=z_r/D\), with each integer using \(O(m(L+\log m))\) bits. The resulting scoring vector remains feasible because the vertex has positive \(w\).

A certificate consists of \(D,z_1,\ldots,z_m\). Its total length is \(O(m^2(L+\log m))\). The verifier checks

\(D=z_1\ge z_2\ge\cdots\ge z_m=0\), with \(D>0\),

and computes

\(U_j(a)=\sum_{r=1}^{m}B_j(a,r)z_r\).

Since \(S_j^s(a)=U_j(a)/(QD)\), checking that all pairwise differences in the two panels are nonzero and have the same sign verifies feasibility exactly.

This is a polynomial-time verifier, establishing membership in \(\mathsf{NP}\).

3. Hardness even for dyadic masses

For arbitrary binary-encoded rationals, simply replacing each source panel by its empirical distribution would suffice. To cover the stronger interpretation of “binary-rational” as a finite binary fraction, we give a reduction whose masses are all dyadic.

Start with an instance of the known problem having \(m_0\ge2\) alternatives and \(n\) voters in each panel.

3.1 Pad the number of alternatives to a power of two

Let \(M\) be the smallest power of two satisfying \(M\ge m_0\), and put \(d=M-m_0\). Thus \(M<2m_0\).

If \(d>0\), introduce alternatives \(b_1,\ldots,b_d\). Append them, in that order, below all original alternatives in every ranking of both panels.

We claim that this padding preserves feasibility.

Forward direction. Suppose \(s\) is feasible for the original instance. If \(d=0\), use \(t=s\). Otherwise define

\(t_i=(1+s_i)/2\) for \(1\le i\le m_0\),

and

\(t_{m_0+r}=(d-r)/(2d)\) for \(1\le r\le d\).

This vector is normalized and monotonic. Every original alternative receives at least \(1/2\) from every voter; every new alternative receives less than \(1/2\). Therefore all original alternatives strictly outrank all new alternatives in both panels.

For an original alternative \(a\), its padded panel total is

\(T_j^t(a)=n/2+T_j^s(a)/2\).

Hence the strict order among original alternatives is preserved. Each new alternative \(b_r\) has total \(nt_{m_0+r}\), so the new alternatives are strictly ordered identically in both panels. Thus the padded instance is feasible.

Reverse direction. Suppose \(t\) is feasible for the padded instance. If \(d=0\), it already solves the original instance.

If \(d>0\), we must have \(t_1>t_{m_0}\). Otherwise monotonicity forces all first \(m_0\) coordinates to equal \(1\), making all original alternatives tie in each padded panel.

Define

\(s_i=(t_i-t_{m_0})/(1-t_{m_0})\), for \(1\le i\le m_0\).

This is a normalized monotonic scoring vector. Since every original alternative occupies one of the first \(m_0\) positions in every ranking,

\(T_j^t(a)=nt_{m_0}+(1-t_{m_0})T_j^s(a)\).

The coefficient \(1-t_{m_0}\) is positive. Thus all score-difference signs among original alternatives are preserved, proving feasibility of the original instance.

3.2 Encode the padded panels using dyadic masses

Let \(N\) be the smallest power of two satisfying \(N\ge Mn\). Because \(M\) is itself a power of two, \(N/M\) is an integer. Define

\(k=N/M-n\ge0\).

Choose any ranking of the \(M\) alternatives and take its \(M\) cyclic rotations. Across these rotations, each alternative occupies each rank exactly once.

For each padded panel, construct a weighted support as follows:

  • each padded voter ranking contributes mass \(M/N\);
  • each cyclic rotation contributes mass \(k/N\), omitted when \(k=0\);
  • merge identical rankings by adding their masses.

The masses sum to

\(nM/N+Mk/N=M(n+k)/N=1\).

Every listed mass is positive, and every mass has denominator \(N\), a power of two.

Let \(T_j^t(a)\) denote the total score of \(a\) in the padded, explicitly listed panel. Its score in the constructed weighted society is exactly

\(S_j^t(a)=(M/N)T_j^t(a)+(k/N)\sum_{r=1}^{M}t_r\).

The second term is independent of \(a\): the cyclic rotations place each alternative once at every position. Consequently,

\(S_j^t(a)-S_j^t(b)=(M/N)\bigl(T_j^t(a)-T_j^t(b)\bigr)\).

Since \(M/N>0\), every score-difference sign, including whether the difference is zero, is preserved. The weighted instance is therefore feasible exactly when the padded instance is feasible, which is exactly when the original source instance is feasible.

3.3 Polynomial size of the reduction

Each constructed support has at most \(n+M\) types, so \(\tau\le2(n+M)\). Each ranking has \(M\) alternatives, and each mass uses \(O(\log(nM))\) bits because \(N<2Mn\).

The output encoding length is therefore

\(O((n+M)M\log M+(n+M)\log(nM))\),

which is polynomial in the explicitly listed source input length. Constructing and merging these lists also takes polynomial time. No expansion into \(N\) voters is required.

This proves \(\mathsf{NP}\)-hardness even for dyadic masses.

4. Running times in the requested parameters

The integer rank matrices \(B_j\) can be constructed directly from the listed supports in \(O(m\tau L^2)\) bit operations using elementary integer arithmetic.

For the rational certificate above, each integer has \(O(m(L+\log m))\) bits. A conservative bound for verification is

\(O(m\tau L^2+m^4(L+\log m)^2)\)

bit operations. Thus verification is polynomial in \(m,\tau,L\).

For completeness, an exact deterministic algorithm can enumerate the \(m!\) possible common orders and solve the margin linear program for each. Each program has \(m+1\) variables, \(O(m)\) constraints, and polynomial encoding length. Its total running time is

\(O(m\tau L^2)+m!\operatorname{poly}(m,L)\).

The support parameter \(\tau\) enters through the explicitly listed types; none of these arguments enumerates the \(m!\) possible input ranking types.

Together, the polynomial certificate bound and the reduction establish the claimed \(\mathsf{NP}\)-completeness.
