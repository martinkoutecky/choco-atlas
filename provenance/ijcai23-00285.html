The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_a\) with \(\sum_a\mu_a=1\), rational compatibilities \(w_{ab}\), and \(\rho\in[0,1]\), decide whether there exist \(x_{ab}\ge0\) for two-seat offices and \(z_a\ge0\) for isolated desks satisfying \(\sum_{a\le b}x_{ab}=\rho/2\), \(\sum_a z_a=1-\rho\), and \(2x_{aa}+\sum_{b\ne a}x_{\min(a,b),\max(a,b)}+z_a=\mu_a\), such that every type occupying positive paired mass weakly prefers its assigned partner to every occupied partner type and every type with \(z_a>0\) weakly prefers isolation to every occupied partner type.

Packaged proof task (what the prover saw — nothing else)

Definitions. Let \(T\) be finite, with rational masses \(\mu_t\ge 0\) satisfying \(\sum_{t\in T}\mu_t=1\), and let \(s:T\times T\to\{0,1\}\) be symmetric. A configuration of an \(\ell\)-leaf star is \(\alpha\in T^{\ell+1}\), with center \(\alpha_0\); let \(a_t(\alpha)\) be the number of occurrences of \(t\) in \(\alpha\), and \(W(\alpha)=\sum_{i=1}^{\ell}\bigl(s(\alpha_0,\alpha_i)+s(\alpha_i,\alpha_0)\bigr)\).

For \(B\) identical stars, choose \(z_\alpha\ge0\) with \(\sum_\alpha z_\alpha=1\) and \(\sum_\alpha z_\alpha a_t(\alpha)=(\ell+1)\mu_t\) for every \(t\in T\), maximizing \(\sum_\alpha z_\alpha W(\alpha)\).

Target. Is this continuous maximum-welfare problem solvable in polynomial time, or is it NP-hard?

Known results. In the discrete maximum-welfare seat-arrangement problem, optimization is NP-hard for stars-graphs even with binary symmetric preferences and constant maximum preference degree. No continuous-side result is assumed here.

Complexity of Continuous Welfare Maximization on Stars

Claim

The continuous maximum-welfare problem is solvable in polynomial time. More precisely, it is exactly equivalent to a rational linear program with \(|T|^2\) variables and \(|T|\) equality constraints.

Throughout the proof, assume \(\ell\geq 1\). When \(\ell=0\), every configuration consists only of its center, all welfare values are zero, and the problem is trivial.

1. Leaf-count notation

For a configuration \(\alpha\), define

\[ k_v(\alpha) = \left|\left\{i\in\{1,\ldots,\ell\}:\alpha_i=v\right\}\right|. \]

Thus

\[ \sum_{v\in T}k_v(\alpha)=\ell \]

and

\[ a_t(\alpha) = \mathbf 1[\alpha_0=t]+k_t(\alpha). \]

For \(u,v\in T\), put

\[ g_{uv}=s(u,v)+s(v,u). \]

Because \(s\) is symmetric and binary, \(g_{uv}=2s(u,v)\), although the proof does not require symmetry or binarity. If \(\alpha_0=u\), then

\[ W(\alpha)=\sum_{v\in T}k_v(\alpha)g_{uv}. \]

2. Compact linear program

Consider variables \(y_{uv}\geq 0\) for \(u,v\in T\), and the linear program

\[ \begin{aligned} \max\quad& \ell\sum_{u,v\in T}g_{uv}y_{uv} \\ \text{subject to}\quad& \sum_{v\in T}y_{tv} + \ell\sum_{u\in T}y_{ut} = (\ell+1)\mu_t &&\text{for every }t\in T, \\ &y_{uv}\geq 0 &&\text{for every }u,v\in T. \end{aligned} \tag{P} \]

Summing all equality constraints gives

\[ (\ell+1)\sum_{u,v\in T}y_{uv} = (\ell+1)\sum_{t\in T}\mu_t = \ell+1. \]

Consequently, every feasible solution satisfies

\[ \sum_{u,v\in T}y_{uv}=1. \]

The program is feasible: setting

\[ y_{uv}=\mu_u\mu_v \]

gives, for every \(t\),

\[ \sum_v y_{tv}+\ell\sum_u y_{ut} = \mu_t+\ell\mu_t = (\ell+1)\mu_t. \]

Its feasible region is bounded because all variables are nonnegative and sum to one.

3. Compression of arbitrary configurations

Lemma

Every feasible configuration distribution \(z\) induces a feasible solution \(y\) of \((P)\) having exactly the same objective value.

Proof

Given \(z\), define

\[ y_{uv} = \frac{1}{\ell} \sum_{\substack{\alpha\\ \alpha_0=u}} z_\alpha k_v(\alpha). \]

First,

\[ \begin{aligned} \sum_{u,v}y_{uv} &= \frac{1}{\ell} \sum_\alpha z_\alpha \sum_v k_v(\alpha) \\ &= \frac{1}{\ell}\sum_\alpha z_\alpha\ell =1. \end{aligned} \]

For any \(t\in T\),

\[ \begin{aligned} \sum_v y_{tv} &= \frac{1}{\ell} \sum_{\alpha:\alpha_0=t} z_\alpha\sum_v k_v(\alpha) \\ &= \sum_{\alpha:\alpha_0=t}z_\alpha, \end{aligned} \]

while

\[ \ell\sum_u y_{ut} = \sum_\alpha z_\alpha k_t(\alpha). \]

Therefore,

\[ \begin{aligned} \sum_v y_{tv}+\ell\sum_u y_{ut} &= \sum_\alpha z_\alpha \left(\mathbf 1[\alpha_0=t]+k_t(\alpha)\right) \\ &= \sum_\alpha z_\alpha a_t(\alpha) \\ &= (\ell+1)\mu_t. \end{aligned} \]

Thus \(y\) is feasible for \((P)\).

Finally,

\[ \begin{aligned} \ell\sum_{u,v}g_{uv}y_{uv} &= \sum_u\sum_{\alpha:\alpha_0=u} z_\alpha\sum_v k_v(\alpha)g_{uv} \\ &= \sum_\alpha z_\alpha W(\alpha). \end{aligned} \]

Hence the objective value is preserved. \(\square\)

4. Realizing every compact solution

Lemma

Every feasible solution \(y\) of \((P)\) can be realized by a feasible configuration distribution \(z\) with the same objective value.

Proof

For each ordered pair \(u,v\in T\), let

\[ \beta^{uv}=(u,v,\ldots,v) \]

be the configuration whose center has type \(u\) and whose \(\ell\) leaves all have type \(v\). Define

\[ z_{\beta^{uv}}=y_{uv} \]

and set all other \(z_\alpha\) to zero. Because \(\ell\geq 1\), the configurations \(\beta^{uv}\) are distinct for distinct ordered pairs \((u,v)\).

We already proved that every feasible \(y\) satisfies \(\sum_{u,v}y_{uv}=1\), so \(z\) is a probability distribution. Moreover,

\[ a_t(\beta^{uv}) = \mathbf 1[u=t]+\ell\mathbf 1[v=t]. \]

Consequently,

\[ \begin{aligned} \sum_\alpha z_\alpha a_t(\alpha) &= \sum_v y_{tv}+\ell\sum_u y_{ut} \\ &= (\ell+1)\mu_t. \end{aligned} \]

Thus \(z\) satisfies every type-mass constraint. Finally,

\[ W(\beta^{uv})=\ell g_{uv}, \]

and hence

\[ \sum_\alpha z_\alpha W(\alpha) = \ell\sum_{u,v}g_{uv}y_{uv}. \]

The objective value is therefore preserved. \(\square\)

5. Polynomial-time complexity

The two lemmas show that the original configuration program and \((P)\) have exactly the same feasible objective values and therefore the same optimum.

If \(n=|T|\), then \((P)\) has

\[ n^2 \]

variables and \(n\) equality constraints. All coefficients are rational, and their binary encoding lengths are polynomial in the encoding lengths of \(\ell\), \(\mu\), and \(s\). Standard exact algorithms for rational linear programming therefore compute its optimal value in polynomial time.

An optimal configuration distribution also has a succinct polynomial-size representation: it is supported only on the at most \(n^2\) monochromatic-leaf configurations \(\beta^{uv}\). If \(\ell\) is binary encoded, each such configuration can be represented as “center \(u\), followed by \(\ell\) copies of \(v\).”

6. Why discrete hardness does not transfer

The compression replaces a configuration having several different leaf types by a fractional mixture of stars whose leaves are monochromatic. This operation preserves type masses and welfare exactly, but it need not preserve the requirement that there be an integral number of each configuration among \(B\) discrete stars.

Thus the discrete problem retains integrality constraints that are absent from the continuous formulation. Its NP-hardness does not imply hardness of this continuous relaxation.

Conclusion

The continuous maximum-welfare problem is polynomial-time solvable by an explicit compact linear program. The assumptions that preferences are binary, symmetric, or have constant degree are unnecessary for this conclusion; additivity of welfare across center-leaf edges and the aggregate type-mass constraints are sufficient.
