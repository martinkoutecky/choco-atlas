The continuous mirror question, as graded

Given rational shared production data \(A,p,c\), a finite set of firm types \(T\) with endowments \(b_t\) and rational masses \(\mu_t\) summing to \(1\), and common-pool supply \(\rho\) per unit of population, assume \(d(\mu)\le\rho\). Compute rational per-firm payoffs \(u_t\) such that \(\sum_{t\in T}\mu_tu_t=v^{\mathrm{opt}}(\mu)\) and \(\sum_{t\in T}\alpha_tu_t\ge v^{\mathrm{opt}}(\alpha)\) for every coalition mass vector \(\alpha\in\prod_{t\in T}[0,\mu_t]\), where \(v^{\mathrm{opt}}(\alpha)=\operatorname{val}(\alpha;\min\{d(\alpha),\rho\})\), and \(\operatorname{val}(\alpha;z)\) and \(d(\alpha)\) are defined by the paper's production LP with aggregate private endowment \(\sum_t\alpha_tb_t\).

Result

The required payoff vector is polynomial-time computable in \(m,q,\tau,L\). An optimal dual solution of a single rational linear program gives such a vector.

Write \(D\in\mathbb Q_{\ge0}^{q\times m}\) for the private-resource rows of \(A\), and define
\(h_j=a_{q+1,j}\) and \(r_j=p_j-ch_j\).
Thus \(h_j>0\) and \(r_j>0\). Let \(B=\sum_{t\in T}\mu_tb_t\).

1. Unrestricted common-resource purchases

For any coalition vector \(\alpha\), define its unrestricted net production value by

\(\displaystyle F(\alpha)=\max\{r^\top x:x\ge0,\ Dx\le b(\alpha)\}.\)

This maximum exists and is finite. Indeed, choose the private-resource row \(i\) whose entries are all strictly positive. Every feasible production vector satisfies

\(\displaystyle 0\le x_j\le \frac{b_i(\alpha)}{D_{ij}}\quad\text{for every }j.\)

Consequently, the feasible set is nonempty, closed, and bounded.

For fixed \(z\ge0\), the feasible set defining \(\operatorname{val}(\alpha;z)\) is also nonempty and compact. For any feasible production vector \(x\), the constraint \(h^\top x\le z\) gives

\(\displaystyle p^\top x-cz =r^\top x-c(z-h^\top x) \le r^\top x \le F(\alpha).\)

Hence

\(\displaystyle \operatorname{val}(\alpha;z)\le F(\alpha)\quad\text{for every }z\ge0.\)

Conversely, if \(x^*\) attains \(F(\alpha)\), choosing \(z=h^\top x^*\) makes \(x^*\) feasible and gives

\(\displaystyle p^\top x^*-cz=r^\top x^*=F(\alpha).\)

Therefore

\(\displaystyle \max_{z\ge0}\operatorname{val}(\alpha;z)=F(\alpha).\)

We also verify that the minimum in the definition of \(d(\alpha)\) exists. Let

\(\displaystyle X^*(\alpha)=\{x\ge0:Dx\le b(\alpha),\ r^\top x=F(\alpha)\}.\)

This set is nonempty and compact. If \(z\) maximizes \(\operatorname{val}(\alpha;z)\), choose a production vector \(x\) attaining that value. Then

\(\displaystyle 0=F(\alpha)-(p^\top x-cz) =\bigl(F(\alpha)-r^\top x\bigr)+c(z-h^\top x).\)

Both terms on the right are nonnegative. Since \(c>0\), equality implies \(x\in X^*(\alpha)\) and \(z=h^\top x\). The converse follows from the preceding construction. Thus

\(\displaystyle \operatorname*{arg\,max}_{z\ge0}\operatorname{val}(\alpha;z) =\{h^\top x:x\in X^*(\alpha)\},\)

and consequently

\(\displaystyle d(\alpha)=\min_{x\in X^*(\alpha)}h^\top x.\)

In particular,

\(\displaystyle v^{\mathrm{opt}}(\alpha)\le F(\alpha)\quad\text{for every coalition }\alpha.\)

For the grand coalition, the promise \(d(\mu)\le\rho\) implies

\(\displaystyle v^{\mathrm{opt}}(\mu) =\operatorname{val}(\mu;d(\mu)) =F(\mu).\)

These conclusions also hold at \(\alpha=0\): the strictly positive private-resource row forces \(x=0\), giving \(F(0)=d(0)=0\).

2. Constructing the payoff vector

Consider the grand coalition’s unrestricted primal and dual programs:

\(\displaystyle \max\{r^\top x:x\ge0,\ Dx\le B\},\)

\(\displaystyle \min\{B^\top y:y\ge0,\ D^\top y\ge r\}.\)

The primal is feasible and has a finite attained optimum, as proved above. The dual is feasible explicitly: for the strictly positive row \(i\), take

\(\displaystyle y_i=\max_{1\le j\le m}\frac{r_j}{D_{ij}},\qquad y_k=0\ \text{for }k\ne i.\)

Then \(D^\top y\ge r\). Linear-programming strong duality therefore supplies an optimal dual vector \(y^*\) satisfying

\(\displaystyle B^\top y^*=F(\mu).\)

Define the per-unit-mass payoff of each type by

\(\displaystyle u_t=b_t^\top y^*\quad(t\in T).\)

Efficiency. Using the definition of \(B\) and the supply promise,

\(\displaystyle \sum_{t\in T}\mu_tu_t =\left(\sum_{t\in T}\mu_tb_t\right)^\top y^* =B^\top y^* =F(\mu) =v^{\mathrm{opt}}(\mu).\)

Every real coalition inequality. Fix any \(\alpha\in\prod_{t\in T}[0,\mu_t]\). For every \(x\ge0\) with \(Dx\le b(\alpha)\), dual feasibility and nonnegativity give

\(\displaystyle r^\top x \le (D^\top y^*)^\top x =(y^*)^\top Dx \le (y^*)^\top b(\alpha).\)

Maximizing over \(x\) yields \(F(\alpha)\le(y^*)^\top b(\alpha)\). Consequently,

\(\displaystyle \sum_{t\in T}\alpha_tu_t =(y^*)^\top b(\alpha) \ge F(\alpha) \ge v^{\mathrm{opt}}(\alpha).\)

This argument applies directly to real coalition vectors, including coalitions whose unrestricted optimal demand exceeds \(\rho\).

3. Rationality and polynomial bit complexity

The algorithm is:

  • Compute \(r=p-ch\) and \(B=\sum_{t\in T}\mu_tb_t\).
  • Solve the dual program above exactly over the rationals.
  • Return \(u_t=b_t^\top y^*\) for every listed type.

The dual has \(q\) variables and \(m+q\) scalar inequalities. Computing its coefficients uses rational additions and multiplications whose resulting encoding lengths are polynomial in \(L,m,q,\tau\).

The standard rational linear-programming theorem provides an exact rational optimum in polynomial bit time whenever a rational LP is feasible and has a finite optimum. This is the polynomial-time LP result originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319). Both hypotheses have been verified here. The returned optimal vector has polynomial encoding length; the subsequent rational dot products also take polynomial time and produce polynomial-length rational payoffs.

Thus one explicit polynomial-size LP constructs the required vector. No characterization of the entire nonatomic core is needed.
