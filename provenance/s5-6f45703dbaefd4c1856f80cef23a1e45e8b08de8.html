The continuous mirror question, as graded

Given a finite alternative set \(A\), a rational positional scoring vector with fixed tie-breaking, and a binary-rational society \(\mu\) supported on ranking types \(S\subseteq\mathcal{L}(A)\), let \(a=F(\mu)\). Does there exist a target \(b\in A\) and a nonnegative mass transfer \(x_{t,r}\), from true type \(t\in S\) to report ranking \(r\in\mathcal{L}(A)\setminus\{t\}\), such that each type sends at most its mass, the resulting report distribution \(\nu\) satisfies \(F(\nu)=b\), every type sending positive mass weakly prefers \(b\) to \(a\), and a positive amount of mass comes from types that strictly prefer \(b\) to \(a\)? Here \(\nu_r=\mu_r-\sum_{q\ne r}x_{r,q}+\sum_{t\ne r}x_{t,r}\), with \(\mu_r=0\) outside \(S\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) have \(m\ge2\) alternatives, with unrestricted strict ranking domain \(\mathcal L(A)\). The input includes a positional scoring vector \(s_1\ge\cdots\ge s_m\ge0\) of binary rationals and a fixed linear priority order for breaking score ties; \(F\) denotes the resulting resolute scoring rule on report masses.
A society is given by its support: the list \(S\) of \(\tau\) ranking types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in S}\mu_t=1\). Here \(\tau=|S|\) is the support size, not the number of possible rankings; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
Put \(a=F(\mu)\). A deviation consists of a target \(b\in A\) and real transfers \(x_{t,r}\ge0\), indexed by \(t\in S\) and \(r\in\mathcal L(A)\setminus\{t\}\), with \(d_t:=\sum_{r\ne t}x_{t,r}\le\mu_t\).
Extend \(\mu\), \(d\), and transfers from unsupported source types by zero, and define \(\nu_r=\mu_r-d_r+\sum_{t\in S\setminus\{r\}}x_{t,r}\). Transfers replace sincere reports directly; received mass cannot be transferred again.
The deviation is profitable if \(F(\nu)=b\), every \(t\) with \(d_t>0\) satisfies \(b\succeq_t a\), and \(\sum_{t\in S:\,b\succ_t a}d_t>0\), where \(b\succeq_t a\) means equality or strict preference in \(t\).

Is deciding whether a profitable deviation exists in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite agents and an explicitly listed rule table, strong group strategy-proofness can be checked in \(O(n(m!)^n(1+m!)^n)\) time, polynomial in the listed table size; this checks all sincere profiles, rather than one supplied society. [Verified enumeration bound](https://arxiv.org/html/2605.12537v1).
No result settling exactly the mass-transfer decision problem above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the society's positive masses to sum to one, interpreting 'distribution over types' as a probability distribution.
  • Required at least two alternatives and unrestricted strict rankings, carrying over the discrete preference domain; weak preference means strict preference or equality.
  • Specified nonincreasing, nonnegative rational positional scores, allowing equal entries, and interpreted fixed tie-breaking as a supplied linear priority order.
  • Allowed arbitrary nonnegative real transfers and specified that transfers originate only from sincere source masses, without retransferring received mass.
  • Used L for total input bit length rather than for the number of possible rankings.

Result

The decision problem belongs to \(\mathrm P\). More precisely, it can be decided in
\(\mathcal O\!\left(m^2(\tau+\log m)L^2\right)\) bit operations using ordinary integer arithmetic.

The algorithm checks \(m-1\) sorted inequalities for each possible target. The proof accounts for strict tie-breaking inequalities and the requirement that a positive mass strictly benefits.

1. Reducing transfers to an arbitrary report distribution

Let \(\operatorname{pos}_t(c)\) denote the position of alternative \(c\) in ranking \(t\). First compute the sincere winner \(a=F(\mu)\).

A profitable deviation cannot target \(b=a\), since then no source strictly prefers the target to the original winner. Fix \(b\ne a\), and define

\[ \]
\(E_b=\{t\in S:b\succ_t a\},\qquad M_b=\sum_{t\in E_b}\mu_t.\)

Because rankings are strict and \(b\ne a\), the weak-preference condition permits transfers precisely from types in \(E_b\). If \(M_b=0\), this target is impossible.

Assume henceforth that \(M_b>0\). The reports of the original mass belonging to \(E_b\), including any retained sincere reports, form a distribution of total mass \(M_b\). All other original mass retains its sincere reports.

Conversely, any probability distribution \(p=(p_r)_{r\in\mathcal L(A)}\) can be assigned to this eligible mass. Explicitly, set

\(x_{t,r}=\mu_t p_r\quad(t\in E_b,\ r\ne t),\)

and set all other transfers to zero. Then

\(d_t=\mu_t(1-p_t)\le\mu_t\quad(t\in E_b).\)

The resulting report masses are

\(\nu_r=\mu_r\mathbf 1_{\{r\notin E_b\}}+M_b p_r.\)

This construction transfers only original source mass; it never transfers received mass again.

If this construction makes \(b\) win, some \(d_t\) must be positive: otherwise \(\nu=\mu\), whose winner is \(a\ne b\). Every such source strictly prefers \(b\) to \(a\), so the positive-benefit requirement holds automatically.

Thus a profitable deviation targeting \(b\) exists exactly when the eligible mass can be assigned a report distribution making \(b\) win.

2. The eligible reports may all rank the target first

Given any eligible report distribution making \(b\) win, move \(b\) to the first position in each report, preserving the relative order of the other alternatives.

Since \(s_1\ge\cdots\ge s_m\), this operation weakly increases \(b\)'s score and weakly decreases every rival's score. Consequently, all score differences between \(b\) and its rivals weakly increase. Both the weak inequalities and the strict inequalities required by tie-breaking remain satisfied.

It therefore suffices to consider distributions supported on rankings with \(b\) first.

For this fixed target, define the fixed scores from ineligible sources by

\(f_c=\sum_{t\in S\setminus E_b}\mu_t s_{\operatorname{pos}_t(c)}.\)

The target's resulting score is then fixed at

\(B=f_b+M_b s_1.\)

For each rival \(c\ne b\), define its available score bound

\(h_c=B-f_c.\)

Let \(H_b\) be the set of rivals preceding \(b\) in the fixed priority order. If \(y_c\) is rival \(c\)'s score contribution from eligible mass, then \(b\) wins exactly when

\(y_c\le h_c\quad(c\notin H_b),\qquad y_c<h_c\quad(c\in H_b).\)

Put \(n=m-1\), and list the remaining positional scores in increasing order:

\(v_j=M_b s_{m-j+1}\quad(1\le j\le n).\)

A ranking with \(b\) first assigns the remaining alternatives a permutation of these values. Hence the attainable rival-score vectors form precisely the permutahedron

\(P(v)=\operatorname{conv}\{(v_{\pi(1)},\ldots,v_{\pi(n)}):\pi\in\mathfrak S_n\}.\)

We have reduced target feasibility to finding a point of \(P(v)\) satisfying the specified weak and strict coordinate bounds.

3. A coordinate-bound lemma

Lemma. Let \(v_1\le\cdots\le v_n\) be real numbers, let \(h\in\mathbb R^n\), and let \(H\subseteq\{1,\ldots,n\}\). Define

\(\ell_k=\sum_{j=1}^k v_j.\)

There exists \(y\in P(v)\) satisfying \(y_i\le h_i\) for every \(i\), with \(y_i<h_i\) for \(i\in H\), if and only if every nonempty subset \(C\subseteq\{1,\ldots,n\}\) satisfies

\(\sum_{i\in C}h_i\ge\ell_{|C|},\)

with strict inequality whenever \(C\cap H\ne\varnothing\).

Proof of necessity

For every permutation of \(v\), the sum of any \(k\) coordinates is at least the sum of its \(k\) smallest entries, namely \(\ell_k\). The same inequality holds for every convex combination. Thus

\(\sum_{i\in C}y_i\ge\ell_{|C|}.\)

The coordinate bounds imply the required weak inequality. If \(C\cap H\ne\varnothing\), at least one bound is strict, so

\(\sum_{i\in C}h_i>\sum_{i\in C}y_i\ge\ell_{|C|}.\)

Proof of sufficiency for weak bounds

First suppose only weak coordinate bounds are required. Let

\(K=P(v)+\mathbb R_{\ge0}^n.\)

The desired condition \(y\le h\) is equivalent to \(h\in K\). The set \(K\) is nonempty and convex. It is closed because \(P(v)\) is compact: from any convergent sequence in \(K\), take a convergent subsequence of its \(P(v)\) components.

Suppose, for contradiction, that \(h\notin K\). Choose \(q\in K\) minimizing its Euclidean distance to \(h\); existence follows by restricting the minimization to a sufficiently large closed ball. Set \(z=q-h\ne0\).

For every \(u\in K\), convexity and the minimality of \(q\) imply

\(z\cdot(u-q)\ge0.\)

Indeed, the squared distance from \(h\) along the segment \(q+t(u-q)\) has a nonnegative right derivative at \(t=0\). Taking \(u=q+e_i\) shows that \(z_i\ge0\). Therefore,

\(z\cdot h=z\cdot q-\|z\|^2<\inf_{u\in K}z\cdot u=\min_{y\in P(v)}z\cdot y.\)

Order the coordinates as \(i_1,\ldots,i_n\) so that \(z_{i_1}\ge\cdots\ge z_{i_n}\ge0\), and put \(z_{i_{n+1}}=0\). The assumed subset inequalities give

\(z\cdot h =\sum_{k=1}^n(z_{i_k}-z_{i_{k+1}})\sum_{j=1}^k h_{i_j} \ge\sum_{k=1}^n(z_{i_k}-z_{i_{k+1}})\ell_k =\sum_{k=1}^n z_{i_k}v_k.\)

The final expression equals \(\min_{y\in P(v)}z\cdot y\). To verify this, if a permutation assigns values \(w_i>w_j\) to coordinates with \(z_i\ge z_j\), exchanging those values changes the objective by

\(-(z_i-z_j)(w_i-w_j)\le0.\)

Repeated exchanges therefore minimize the objective by pairing decreasing \(z\) with increasing \(v\). This contradicts the preceding strict inequality and proves weak feasibility.

Incorporating strict bounds

If \(H=\varnothing\), the weak result suffices. Otherwise, all quantities

\(\displaystyle \frac{\sum_{i\in C}h_i-\ell_{|C|}}{|C\cap H|} \quad(C\cap H\ne\varnothing) \)

are positive. There are finitely many such subsets, so choose a positive \(\varepsilon\) smaller than their minimum. Define \(h'_i=h_i-\varepsilon\) for \(i\in H\), and \(h'_i=h_i\) otherwise.

Every subset still satisfies the weak inequality for \(h'\). The weak result supplies \(y\in P(v)\) with \(y\le h'\), which gives the required strict bounds on \(H\). This proves the lemma.

4. Checking the lemma using sorted prefixes

Sort the rivals as \(c_1,\ldots,c_n\) so that

\(h_{c_1}\le\cdots\le h_{c_n},\)

placing members of \(H_b\) before other rivals whenever their bounds are equal. Define

\(\displaystyle \Delta_k=\sum_{i=1}^k h_{c_i} -M_b\sum_{j=m-k+1}^{m}s_j \quad(1\le k\le n). \)

The exact target-feasibility test is:

  • Require \(\Delta_k\ge0\) for every \(k\).
  • Require \(\Delta_k>0\) whenever \(\{c_1,\ldots,c_k\}\cap H_b\ne\varnothing\).

Here is why these prefix conditions suffice for every subset in the lemma.

For subsets of size \(k\), the minimum bound sum is \(\sum_{i=1}^k h_{c_i}\). Thus the weak subset conditions are equivalent to the weak prefix conditions.

Now consider a size-\(k\) subset \(C\) meeting \(H_b\). If \(\Delta_k>0\), its strict inequality follows immediately from this minimum-sum property.

If \(\Delta_k=0\), the prefix must contain no member of \(H_b\). By the prescribed ordering within equal bounds, every member of \(H_b\) then has bound strictly larger than \(h_{c_k}\). Consequently, \(C\) cannot minimize the bound sum: replacing one of its members in \(H_b\) by a missing prefix member strictly decreases that sum. Therefore,

\(\sum_{c\in C}h_c>\sum_{i=1}^k h_{c_i}=\ell_k,\)

as required.

Necessity follows by applying the lemma to the prefixes themselves. Hence the test is equivalent to target feasibility.

The complete algorithm accepts exactly when some \(b\ne a\) with \(M_b>0\) passes this test.

5. Bit complexity

Computing the sincere scores and ranking positions takes \(\mathcal O(\tau m)\) arithmetic operations.

For each target, computing eligibility, eligible mass, and all fixed scores takes \(\mathcal O(\tau m)\) operations. Sorting the rival bounds takes \(\mathcal O(m\log m)\) comparisons, and checking the prefixes takes \(\mathcal O(m)\) operations. Across all targets, this is

\(\mathcal O\!\left(\tau m^2+m^2\log m\right)\)

arithmetic operations and comparisons.

All calculations can be performed exactly with integers of \(\mathcal O(L)\) bits. To see this, write the input masses and scores as

\(\mu_t=p_t/q_t,\qquad s_j=u_j/w_j,\)

and use the common denominators

\(D_\mu=\prod_{t\in S}q_t,\qquad D_s=\prod_{j=1}^m w_j.\)

Every score, bound, and prefix expression has denominator dividing \(D_\mu D_s\). The products defining these denominators have \(\mathcal O(L)\) bits. Normalization gives \(\mu_t\le1\), and every total alternative score is at most \(s_1\); prefix sums introduce only an additional \(\mathcal O(\log m)\) bits. Thus all relevant scaled integers have \(\mathcal O(L)\) bits.

Using schoolbook integer arithmetic, each operation costs at most \(\mathcal O(L^2)\) bit operations. This yields the claimed bound

\(\mathcal O\!\left(m^2(\tau+\log m)L^2\right).\)

The transfer reduction, target-first reduction, and coordinate-bound lemma establish both directions of correctness, so this completely resolves the stated decision problem.
