The continuous mirror question, as graded

Given \(L\) tiers, rational per-capita supplies \(\bar q_1,\ldots,\bar q_L\), and \(\tau\) types \(\theta\) with rational masses \(\mu_\theta\) summing to \(1\), each type specified by a minimum acceptable tier \(\ell_\theta\) and a nonincreasing marginal-value schedule \(u_\theta(1),\ldots,u_\theta(K)\), find a welfare-maximizing allocation. Let \(y_{\theta,k}\) be the mass of type \(\theta\) receiving exactly \(k\) units, where each individual receives an integral bundle. Require \(\sum_{k=0}^{K}y_{\theta,k}=\mu_\theta\) and, for every threshold \(t\), \(\sum_{\theta:\ell_\theta\ge t}\sum_{k=0}^{K} k y_{\theta,k}\le \sum_{s=t}^{L}\bar q_s\); maximize \(\sum_\theta\sum_{k=0}^{K}y_{\theta,k}\sum_{j=1}^{k}u_\theta(j)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_\theta\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) quality tiers, ordered from lowest to highest, with nonnegative binary-rational per-capita supplies \(\bar q_1,\ldots,\bar q_m\), and an explicitly listed bundle bound \(K\ge1\).
Type \(\theta\) specifies a minimum acceptable tier \(\ell_\theta\in\{1,\ldots,m\}\) and binary-rational marginal values \(u_\theta(1)\ge\cdots\ge u_\theta(K)\ge0\). All acceptable tiers have identical value to this type.
An allocation specifies nonnegative rational masses \(y_{\theta,k}\) receiving exactly \(k\in\{0,\ldots,K\}\) acceptable units. Individuals receive integral bundles, but each type's mass may be split among bundle sizes; supply may remain unused.
Feasibility requires \(\sum_{k=0}^{K}y_{\theta,k}=\mu_\theta\) for every type and \(\sum_{\theta:\ell_\theta\ge t}\sum_{k=0}^{K}k y_{\theta,k}\le\sum_{s=t}^{m}\bar q_s\) for every \(t\in\{1,\ldots,m\}\).
Welfare is \(W(y)=\sum_\theta\sum_{k=0}^{K}y_{\theta,k}\sum_{j=1}^{k}u_\theta(j)\), with the empty sum equal to zero; any maximizing allocation is acceptable when values tie. Let \(L\) denote total input bit length, including a binary-rational threshold \(B\) when supplied.

Is computing a welfare-maximizing allocation polynomial-time in \(m,\tau,K,L\), or is deciding whether \(\max_y W(y)\ge B\) NP-hard?

For finitely many bidders with integral supplies, minimum acceptable tiers, and nonnegative decreasing marginal values, a greedy allocation algorithm is known to maximize welfare in polynomial time with explicitly listed marginal values.
No result settling exactly this continuous problem is supplied.

Result

Computing an exact welfare-maximizing allocation is polynomial-time in \(m,\tau,K,L\). Consequently, deciding whether \(\max_y W(y)\ge B\) belongs to \(\mathrm{P}\).

The allocation variables describe divisible masses receiving specified integral bundle sizes. This gives an exact linear program of polynomial size.

1. Exact linear-program formulation

Index the explicitly listed support by \(\theta\in\{1,\ldots,\tau\}\). Define the rational constants

\(\displaystyle U_{\theta,0}=0,\qquad U_{\theta,k}=\sum_{j=1}^{k}u_\theta(j)\quad(1\le k\le K),\)

and

\(\displaystyle Q_t=\sum_{s=t}^{m}\bar q_s\quad(1\le t\le m).\)

Consider the following linear program over real variables \(y_{\theta,k}\):

\(\displaystyle \text{maximize }\sum_{\theta=1}^{\tau}\sum_{k=0}^{K}U_{\theta,k}y_{\theta,k},\)

subject to

\(\displaystyle \sum_{k=0}^{K}y_{\theta,k}=\mu_\theta\quad(\theta=1,\ldots,\tau),\)

\(\displaystyle \sum_{\theta:\ell_\theta\ge t}\sum_{k=0}^{K}k\,y_{\theta,k}\le Q_t\quad(t=1,\ldots,m),\)

and

\(\displaystyle y_{\theta,k}\ge0\quad(\theta=1,\ldots,\tau;\ k=0,\ldots,K).\)

Every rational feasible point is precisely an allocation permitted by the question, and its objective value is precisely its welfare. In particular, fractional values of \(y_{\theta,k}\) represent splitting a type’s mass among bundle sizes; the bundle size \(k\) itself remains integral.

The temporary extension to real variables causes no change in the optimum, as proved below.

2. The program has polynomial encoding length

There are \(n=\tau(K+1)\) variables, \(\tau\) mass equalities, and \(m\) supply inequalities. Replacing each equality by two inequalities and explicitly including nonnegativity gives \(2\tau+m+n\) inequalities. Every constraint coefficient belongs to \(\{0,\pm1,\ldots,\pm K\}\).

For completeness, the sums defining the objective coefficients and right-hand sides also have polynomial bit length. Write each input rational scalar as an integer numerator divided by a positive integer denominator, both encoded in binary. Let \(D\) be the product of all these denominators. Since their total encoding length is at most \(L\), the bit length of \(D\) is \(O(L)\).

After multiplication by \(D\), each scalar input is an integer with \(O(L)\) bits. Consequently, \(DU_{\theta,k}\) and \(DQ_t\) have

\(\displaystyle O\!\left(L+\log(m+K+1)\right)\)

bits: each is a sum of at most \(K\) or \(m\) such integers. Their unscaled rational representations therefore have polynomial bit length as well.

All prefix and suffix sums can be computed with polynomially many operations on integers of polynomial bit length. Thus the entire linear program can be constructed in time polynomial in \(m,\tau,K,L\), and its binary encoding length is polynomial in these parameters. Only the listed support types are used.

3. A rational optimum exists and has polynomial bit length

The feasible region is nonempty: set \(y_{\theta,0}=\mu_\theta\) and all other variables to zero. This satisfies every supply inequality because supplies are nonnegative.

Moreover, nonnegativity and the mass equalities imply

\(\displaystyle 0\le y_{\theta,k}\le\mu_\theta\le1.\)

The real feasible region is therefore a nonempty compact polytope. Its linear objective attains a maximum, and the standard vertex theorem for linear programming guarantees a maximizing vertex. These hypotheses include boundedness of the feasible region, even if it has lower dimension. See [MIT’s notes on basic feasible solutions](https://courses.csail.mit.edu/6.854/16/Notes/n11-lp.html).

Here is an explicit bound on the rational size of such a vertex. At a vertex, select \(n\) linearly independent tight constraints. Their equalities form a nonsingular system \(Ay=b\). Multiplying this system by \(D\) produces an integer system whose entries have absolute value at most \(2^H\), for

\(\displaystyle H=O\!\left(L+\log(m+K+1)\right).\)

By Cramer’s rule, each coordinate is a ratio of integer determinants. Hadamard’s inequality bounds both the denominator determinant and every numerator determinant by

\(\displaystyle n^{n/2}2^{nH}.\)

Hence each coordinate has \(O(n(H+\log(n+1)))\) bits, and the entire vertex has polynomial encoding length.

In particular, a real maximizing vertex is rational and is an allocation allowed by the question. Since every permitted rational allocation is also real feasible, the rational allocation problem and this real linear program have exactly the same attained maximum.

4. Polynomial-time computation and threshold decision

We use the standard polynomial-time theorem for rational linear programming: an explicitly encoded linear program with rational coefficients can be solved in time polynomial in its binary encoding length; when it is feasible with a finite optimum, an exact rational optimal solution can be returned. This is an exact bit-complexity result, including recovery of a rational solution, rather than merely approximate optimization. See [MIT’s notes on linear-programming algorithms](https://courses.csail.mit.edu/6.854/18/Notes/n14-LP_algorithms.html).

The preceding sections verify all applicable hypotheses: the program is explicitly encoded with polynomial length, its feasible region is nonempty and bounded, and a rational optimum exists. Applying this theorem therefore returns the requested allocation in polynomial time.

Given \(B\), compute the returned allocation’s welfare using exact rational arithmetic and compare it with \(B\). The allocation and objective coefficients have polynomial bit length, so this evaluation and comparison also take polynomial time.

The decreasing-marginal assumption is compatible with the proof but is unnecessary for this formulation. No transfer of the finite-bidder greedy theorem is needed.
