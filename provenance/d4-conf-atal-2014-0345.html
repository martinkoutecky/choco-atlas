The continuous mirror question, as graded

Given a finite set of complete valuation types \(T\), rational masses \(\mu_t\) summing to \(1\), a fixed rational plot length \(\ell\), piecewise-constant rational valuation densities \(f_t\), and a piecewise-constant rational per-capita capacity profile \(b\) on \([0,1]\), determine the exact complexity of maximizing welfare over mass allocations to length-\(\ell\) intervals. Each unit of allocated mass must receive one whole interval; the mass of type \(t\) assigned to intervals is at most \(\mu_t\), and total mass assigned to intervals containing location \(z\) is at most \(b(z)\) almost everywhere. The objective is \(\sum_{t\in T}\int_{\mathcal I_\ell}(\int_I f_t(z)\,dz)\,dx_t(I)\), where \(\mathcal I_\ell=\{[a,a+\ell]:0\le a\le1-\ell\}\) and \(x_t\) is the allocation measure for type \(t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a finite list \(T\) of \(\tau\) complete valuation types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a common plot length \(\ell\in\mathbb Q\), \(0<\ell\le1\), and nonnegative piecewise-constant valuation densities \(f_t\) and per-capita capacity profile \(b\) on \([0,1]\). All breakpoints and heights are binary rationals; valuations need not be normalized. Let \(m\) be the number of cells in their common breakpoint partition and \(L\) the total input bit length. The length \(\ell\) is part of the input.
Let \(\mathcal I_\ell=\{[a,a+\ell]:0\le a\le1-\ell\}\). An allocation consists of nonnegative finite Borel measures \(x_t\) on \(\mathcal I_\ell\), identified with its start-point interval, satisfying \(x_t(\mathcal I_\ell)\le\mu_t\) and \(\sum_{t\in T}\int_{\mathcal I_\ell}\mathbf1_{\{z\in I\}}\,dx_t(I)\le b(z)\) for Lebesgue-almost every \(z\in[0,1]\).
Each allocated unit of mass receives one whole interval; a type's mass may be divided among different intervals. Unallocated mass and unused capacity are allowed. Endpoints have no effect on welfare or feasibility.
Define \(\mathrm{OPT}=\sup_x\sum_{t\in T}\int_{\mathcal I_\ell}\left(\int_I f_t(z)\,dz\right)dx_t(I)\). A binary-rational threshold \(K\) is included in the input.

Is deciding whether \(\mathrm{OPT}\ge K\) in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finitely many individual agents, welfare maximization with at most one plot per agent is \(\mathrm{NP}\)-hard even when all allocated plots have equal length; the same hardness is stated for consecutive blocks of indivisible items of a common size. 1. Result and notation

The decision problem is in \(\mathrm P\). There is an exact rational linear program of size polynomial in \(m,\tau,L\), even when \(1/\ell\) is exponentially large. Moreover, the supremum defining \(\mathrm{OPT}\) is attained.

Write the common partition as
\(0=p_0<p_1<\cdots<p_m=1\).
On cell \((p_{i-1},p_i)\), let the capacity be \(b_i\) and type \(t\)'s density be \(f_{t,i}\). Define
\(V_t(a)=\int_a^{a+\ell}f_t(z)\,dz\).

The proof has two parts. First, allocations can be rounded exactly onto a finite grid, which may be exponentially large. Second, that grid's linear program can be compressed to polynomial size.

2. Exact rounding to a finite grid

Define
\(G=\{p_i+k\ell:0\le i\le m,\ k\in\mathbb Z\}\cap[0,1]\)
and the allowed grid starts
\(S=G\cap[0,1-\ell]\).

These sets are finite. Also, \(0,1-\ell\in S\), and every start in \(S\) has its endpoint in \(G\).

Rounding lemma. Every feasible allocation can be replaced by an allocation supported on \(S\), preserving each type's allocated mass and its welfare.

Proof. A start already in \(S\) remains fixed. Otherwise, let \(u<v\) be its neighboring points in \(S\), and replace mass at start \(a\in(u,v)\) by masses at \(u\) and \(v\), with respective proportions
\(\lambda=(v-a)/(v-u)\) and \(1-\lambda=(a-u)/(v-u)\).

We verify that this preserves the integrated coverage of every cell of the finer partition \(G\).

The points \(u,v\) are consecutive in \(G\), and so are \(u+\ell,v+\ell\). Indeed, a grid point strictly between the latter two would translate back to a grid point strictly between \(u,v\). Furthermore, \(v-u\le\ell\): the grid contains all multiples of \(\ell\) lying in \([0,1]\).

Consequently, only the two finer cells \((u,v)\) and \((u+\ell,v+\ell)\) have coverage that changes as the start varies from \(u\) to \(v\). Their covered lengths for start \(a\) are respectively \(v-a\) and \(a-u\), exactly the stated convex combinations of the covered lengths for starts \(u,v\). Every other finer cell is either fully covered for all these starts or uncovered for all of them.

Thus, for every finer cell \(D\),
\(\int_D\mathbf1_{\{z\in[a,a+\ell]\}}\,dz =\lambda\int_D\mathbf1_{\{z\in[u,u+\ell]\}}\,dz +(1-\lambda)\int_D\mathbf1_{\{z\in[v,v+\ell]\}}\,dz\).

Apply this finite, measurable rounding kernel to each measure \(x_t\). Tonelli's theorem shows that each type's integrated coverage on each finer cell is preserved.

The rounded total coverage is constant on each open finer cell, since all interval endpoints belong to \(G\). Its value is therefore the average of the original coverage there, which is at most that cell's capacity. This proves feasibility. Since every \(f_t\) is constant on each finer cell, preserving integrated coverage also preserves welfare. The rounding proportions sum to one, so allocated type masses are preserved. ∎

The resulting finite-grid optimization has nonnegative variables \(X_{t,a}\), for \(t\in T,a\in S\), with the original capacity and mass constraints. Its feasible set is nonempty, closed, and bounded by the type-mass constraints. Hence it is compact and attains its maximum.

The lemma proves that this maximum equals \(\mathrm{OPT}\). In particular, \(\mathrm{OPT}\) is attained. We use this potentially large grid only to prove correctness; the algorithm will not enumerate it.

3. A flow formulation of the grid problem

Construct a directed graph with vertices \(G\), containing:

  • An idle arc between every pair of consecutive grid vertices.
  • For every \(a\in S\) and type \(t\), a plot arc from \(a\) to \(a+\ell\), carrying flow \(X_{t,a}\).

All arcs point to the right. For a grid vertex \(h\), define
\(d(h)=b_{\mathrm{right}}(h)-b_{\mathrm{left}}(h)\),
where the capacity outside \([0,1]\) is defined to be zero.

Thus \(d(h)=0\) unless \(h\) is an original partition breakpoint.

Flow lemma. Grid plot masses satisfy the capacity constraints if and only if they can be supplemented with nonnegative idle flows satisfying
\(\sum_{A:\operatorname{tail}(A)=h}F_A-\sum_{A:\operatorname{head}(A)=h}F_A=d(h)\)
at every grid vertex.

Proof. Given feasible plot masses, set the idle flow on each finer cell equal to its capacity minus its plot coverage. These flows are nonnegative.

At a grid vertex, plot coverage changes by the total plot flow starting there minus the total ending there. Therefore the change in idle flow, added to the plot-flow imbalance, equals the change in capacity. This is precisely the required balance equation, including at the boundary vertices.

Conversely, sum the balance equations over the vertices to the left of any finer cell. Since every arc points right, cancellation leaves the sum of flows crossing that cell. The right-hand side telescopes to its capacity. The crossing flows consist of its plot coverage and its nonnegative idle flow. Hence plot coverage is at most capacity. ∎

The absence of separate upper bounds on idle or plot arcs is useful: capacities are enforced by the balance equations.

4. Polynomially many boundary plots and terminals

Call a grid plot crossing if its interior contains an original internal breakpoint. Its possible starts form
\(C=\{a\in S:\text{some }p_j\text{ satisfies }a<p_j<a+\ell,\ 1\le j<m\}\).

There are only polynomially many such starts. For a fixed generating breakpoint \(p_i\) and an internal breakpoint \(p_j\), a start \(a=p_i+k\ell\) crossing \(p_j\) must satisfy
\((p_j-p_i)/\ell-1<k<(p_j-p_i)/\ell\).
This open interval has length one, so it contains at most one integer.

Therefore \(|C|\le(m+1)(m-1)\).

Crucially, \(C\) can be constructed without enumerating \(G\): for each pair \(i,j\), compute the candidate integer
\(k=\lceil(p_j-p_i)/\ell\rceil-1\)
and check the strict inequalities and the allowed start range. Remove duplicates.

Define the retained terminal set
\(Q=\{p_0,\ldots,p_m\}\cup C\cup\{a+\ell:a\in C\}\).
Then \(|Q|=O(m^2)\).

Every plot not in \(C\) lies wholly within one closed original cell. Within such a cell, its welfare for type \(t\) is simply \(\ell f_{t,i}\), independent of its start.

For each cell, put
\(Q_i=Q\cap[p_{i-1},p_i]\).
For terminals \(u<v\) in \(Q_i\), define
\(n_{i,u,v}=\lfloor(v-u)/\ell\rfloor\).

This is the maximum number of plot arcs that a rightward path from \(u\) to \(v\) can contain. The upper bound follows from their lengths. It is attained by plots starting at
\(u,u+\ell,\ldots,u+(n_{i,u,v}-1)\ell\),
followed by idle movement to \(v\). All these endpoints belong to \(G\).

5. The compressed linear program

Retain each crossing plot arc \(a\to a+\ell\), with variable \(X_{t,a}\) for every type.

For every cell \(i\) and terminal pair \(u<v\) in \(Q_i\), introduce:

  • A flow variable \(Y_{i,u,v}\) on a compressed arc \(u\to v\).
  • Variables \(Z_{t,i,u,v}\), recording the total type-\(t\) plot mass represented by that arc.

All variables are nonnegative.

Impose the slot constraint
\(\sum_{t\in T}Z_{t,i,u,v}\le n_{i,u,v}Y_{i,u,v}\)
for every compressed arc.

Impose the type-mass constraints
\(\sum_{a\in C}X_{t,a}+\sum_i\sum_{u<v,\ u,v\in Q_i}Z_{t,i,u,v}\le\mu_t\)
for every type \(t\).

Finally, impose flow balance at every terminal \(h\in Q\):
\(\sum_{A:\operatorname{tail}(A)=h}F_A-\sum_{A:\operatorname{head}(A)=h}F_A=d(h)\).

Here the flow-bearing arcs are the crossing plot arcs, with flows \(X_{t,a}\), and the compressed arcs, with flows \(Y_{i,u,v}\). The variables \(Z_{t,i,u,v}\) do not independently enter flow balance.

Maximize
\(\sum_{t\in T}\sum_{a\in C}V_t(a)X_{t,a} +\sum_i\sum_{u<v,\ u,v\in Q_i}\sum_{t\in T}\ell f_{t,i}Z_{t,i,u,v}\).

We next prove exact equivalence.

6. Proof that compression preserves the optimum

From a grid allocation to the compressed program

Supplement a feasible grid allocation with idle flows using the flow lemma. Retain the crossing plot arcs and consider the remaining graph separately inside each original cell.

Every nonterminal vertex in a cell has zero flow imbalance: the capacity is constant there, and all endpoints of crossing plot arcs belong to \(Q\).

The internal flows can therefore be decomposed into directed paths between terminals. To justify this explicitly, trace any positive-flow internal edge backward and forward through nonterminal vertices. Conservation permits continuation, and acyclicity ensures that the tracing reaches terminals. Subtract the minimum flow on the resulting path. At least one edge becomes zero. Repeating gives a finite decomposition.

Consider a path from \(u\) to \(v\) with flow amount \(w\), containing \(k_t\) plot arcs of type \(t\). Its total number of plots satisfies
\(\sum_t k_t\le\lfloor(v-u)/\ell\rfloor=n_{i,u,v}\).

Add \(w\) to \(Y_{i,u,v}\), and add \(wk_t\) to each \(Z_{t,i,u,v}\).

The slot constraint follows from the displayed inequality. Replacing a path by its compressed arc preserves its endpoint imbalances, so flow balance holds. Each plot's mass is counted once, so type-mass constraints hold.

All plots on the path lie within cell \(i\), and therefore have type-\(t\) value \(\ell f_{t,i}\). The compressed objective consequently equals the original welfare.

From the compressed program to a grid allocation

Take any feasible compressed solution. Retain its crossing plot arcs.

Fix a compressed arc \(u\to v\) in cell \(i\), and abbreviate its variables by \(Y,Z_t\), with \(n=n_{i,u,v}\).

If \(n=0\), the slot constraint forces every \(Z_t=0\); route \(Y\) entirely through idle arcs.

Otherwise, form the \(n\) consecutive slots
\([u+(j-1)\ell,u+j\ell]\), for \(1\le j\le n\).

The inequality \(\sum_tZ_t\le nY\) permits distributing the masses \(Z_t\) among these slots, with total mass at most \(Y\) in each slot. One explicit construction is to place consecutive type blocks of lengths \(Z_t\) inside \([0,nY]\), divide that interval into \(n\) bins of length \(Y\), and assign each block-bin intersection to the corresponding type and slot.

Let \(c_{t,j}\) denote the resulting masses. Then
\(\sum_{j=1}^n c_{t,j}=Z_t\)
and
\(\sum_t c_{t,j}\le Y\).

On slot \(j\), send flow \(c_{t,j}\) through the type-\(t\) plot arc, and send the remaining flow \(Y-\sum_t c_{t,j}\) through idle arcs across that slot. After the last slot, route \(Y\) through idle arcs to \(v\).

This expands the compressed arc into grid flows with exactly its endpoint imbalances and zero imbalance elsewhere. It contributes exactly \(Z_t\) allocated mass and exactly \(\ell f_{t,i}Z_t\) welfare for type \(t\).

Expand every compressed arc this way and add all contributions. The resulting full-grid flow satisfies the balance equations. By the flow lemma, its plot masses satisfy the capacity constraints. The compressed type constraints give the required bounds \(\mu_t\), and welfare is preserved.

Thus the compressed linear program has optimum exactly \(\mathrm{OPT}\). The expansion is a proof of realizability; the algorithm need not materialize its potentially enormous number of slots.

7. Size and exact decision complexity

The terminal set has size \(O(m^2)\). Each terminal belongs to at most two original cells, so
\(\sum_i|Q_i|\le2|Q|=O(m^2)\).

Consequently, the number of compressed arcs is
\(\sum_i\binom{|Q_i|}{2}=O(m^4)\).
The program has \(O(\tau m^4)\) variables and polynomially many constraints.

All coefficients have polynomial bit length:

  • Crossing starts and terminals are obtained by rational arithmetic and integer rounding on input numbers.
  • Slot counts satisfy \(n_{i,u,v}\le1/\ell\), so their binary encoding lengths are polynomial in \(L\).
  • Each crossing value is computed directly as

\(V_t(a)=\sum_{i=1}^m f_{t,i}\max\{0,\min(a+\ell,p_i)-\max(a,p_{i-1})\}\).

  • All remaining coefficients use input capacities, masses, and products \(\ell f_{t,i}\).

Thus the compressed program is constructible in time polynomial in \(m,\tau,L\). Rational linear-program feasibility is decidable in polynomial time in the dimension and binary encoding length; this standard theorem is recalled in [Adler and Beling's introduction](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf).

Add the single inequality requiring its objective to be at least \(K\), and test feasibility. Because \(\mathrm{OPT}\) is attained and the formulation is exact, this is equivalent to deciding \(\mathrm{OPT}\ge K\).

8. Relation to the individual-agent hardness

The cited [Theorem 1](https://www.ifaamas.org/Proceedings/aamas2014/aamas/p1045.pdf) concerns individual agents receiving at most one interval. Here, type mass can be split freely among starts.

That distinction is used explicitly in the reverse construction: any totals \(Z_t\) satisfying the slot constraint can be divided among the available slots. Hence the individual-agent hardness does not transfer to this mass-allocation problem.
