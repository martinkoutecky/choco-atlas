The continuous mirror question, as graded

Given a finite support \(T\) of complete HTN request types, rational masses \(\mu_t\ge 0\) with \(\sum_t\mu_t=1\), a finite implicitly represented plan set \(\Pi_t\) for each type, plan metrics \(M_t(\pi)\), resource use \(a_{t\pi r}\), and per-capita capacities \(b_r\), find an optimal rational allocation \(x_{t\pi}\ge 0\) minimizing \(\sum_{t\in T}\sum_{\pi\in\Pi_t}x_{t\pi}M_t(\pi)\), subject to \(\sum_{\pi\in\Pi_t}x_{t\pi}=\mu_t\) for every \(t\) and \(\sum_{t\in T}\sum_{\pi\in\Pi_t}x_{t\pi}a_{t\pi r}\le b_r\) for every resource \(r\). Each unit of mass receives an indivisible valid plan; allocation across a type’s population may be fractional.

Each type supplies a finite-domain HTN request: initial state, initial task network, primitive operators with preconditions and effects, decomposition methods with task-network constraints, hard constraints, preferences, and a metric expression. Preference-family violations count individual ground instances, and precondition violations count failed occurrences. Let \(m\) denote the total structural description size of the requests and expression circuits, \(R\) the number of resources, and \(L\) the total binary input length, including numerical data and a rational threshold \(K\).

Is deciding whether a feasible allocation has objective at most \(K\) solvable in polynomial time in \(m,\tau,R,L\), or is it NP-hard?

For a single discrete HTN request, exhaustive branch-and-bound search with sound pruning returns an optimal last plan when it terminates; this is an optimality guarantee, not a polynomial-time bound. [Verified source](https://www.cs.toronto.edu/kr/publications/1242050782_Sohrabi-IJCAI09.pdf)

Result

The decision problem is NP-hard, even with one supported type, one unused resource, no preferences or hard constraints, and an acyclic, totally ordered HTN. The reduction below also guarantees that every constructed instance has a feasible allocation.

Consequently, a polynomial-time algorithm in \(m,\tau,R,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The supplied [HTN complexity result](https://www.cs.umd.edu/~nau/papers/erol1996complexity.pdf) establishes NP-completeness of primitive propositional plan existence with unrestricted ordering. Here we give a direct reduction that additionally guarantees feasibility and checks the finiteness promise.

1. Constructing the request

We reduce from the standard NP-complete problem \(3\text{-}\mathrm{SAT}\). Let the input formula be \(\varphi=\bigwedge_{j=1}^{q}C_j\), with variables \(z_1,\ldots,z_n\), where every clause contains three literals. We may restrict to \(n,q\geq 1\).

Create one supported request type \(t\), with mass \(\mu_t=1\).

Its initial task network consists of compound tasks \(X_1,\ldots,X_n\), ordered as \(X_1\prec\cdots\prec X_n\). For each \(i\), give \(X_i\) exactly two unconditional alternative methods:

  • one replaces \(X_i\) by the single primitive task \(T_i\);
  • the other replaces \(X_i\) by the single primitive task \(F_i\).

Every primitive operator has empty preconditions and empty effects. There are no additional hard constraints or preferences. The state can therefore be a single fixed state.

Completing the initial network executes exactly one of \(T_i,F_i\) for each \(i\), in increasing order of \(i\). Every selection of these alternatives is valid.

Define \(c_i(\pi)\) to be the primitive-action occurrence count of \(T_i\) in plan \(\pi\). Thus \(c_i(\pi)\in\{0,1\}\), and the assignment represented by \(\pi\) is \(z_i=c_i(\pi)\). Every Boolean assignment is represented by a valid complete plan.

2. Checking the finiteness promise

The construction contains no recursive methods. Every complete decomposition makes exactly \(n\) method choices and produces exactly \(n\) primitive occurrences. There are only \(2^n\) possible selections of alternatives.

The retained decomposition contains only a bounded number of task and method instances. Their start/end annotations lie on the finite execution trace; there are no numerical scheduling variables in this construction. Consequently, only finitely many annotated complete plans exist.

In particular, \(\Pi_t\) is finite and nonempty, as required.

3. The metric counts unsatisfied clauses

For a literal \(\ell\), define its falsity indicator by \(u_{z_i}(\pi)=1-c_i(\pi)\) and \(u_{\neg z_i}(\pi)=c_i(\pi)\).

Because \(c_i(\pi)\) is Boolean, \(u_\ell(\pi)\) equals \(1\) exactly when \(\ell\) is false under the represented assignment, and equals \(0\) otherwise.

If \(C_j=\ell_{j1}\lor\ell_{j2}\lor\ell_{j3}\), define \(d_j(\pi)=u_{\ell_{j1}}(\pi)u_{\ell_{j2}}(\pi)u_{\ell_{j3}}(\pi)\). This product equals \(1\) exactly when all three literals are false, which is exactly when \(C_j\) is unsatisfied.

Set the request’s metric to \(M_t(\pi)=\sum_{j=1}^{q}d_j(\pi)\). This is an allowed rational arithmetic circuit over named primitive-action occurrence counts, using only subtraction, multiplication, addition, and the constant \(1\). It is defined on every valid plan.

We have therefore proved:

  • \(M_t(\pi)\) is the number of clauses unsatisfied by the assignment represented by \(\pi\);
  • \(M_t(\pi)\in\{0,\ldots,q\}\);
  • \(M_t(\pi)=0\) if and only if that assignment satisfies \(\varphi\).

Use one resource with constant usage \(a_{t\pi 1}=0\) and capacity \(b_1=0\). Set the threshold to \(K=0\). All masses, capacities, and thresholds have valid binary-rational encodings.

4. Correctness despite mass splitting

If \(\varphi\) is satisfiable, choose a valid plan \(\pi^\star\) representing a satisfying assignment. Set \(x_{t\pi^\star}=1\) and every other allocation mass to \(0\). These masses are rational, satisfy the type-mass equality, and satisfy the resource constraint. Their objective is \(M_t(\pi^\star)=0\), so the allocation instance is a yes-instance.

Conversely, suppose a feasible allocation has objective at most \(0\). Each term \(x_{t\pi}M_t(\pi)\) is nonnegative. Therefore, every plan receiving positive mass must have metric \(0\). Since \(\Pi_t\) is finite and \(\sum_{\pi\in\Pi_t}x_{t\pi}=1\), at least one plan receives positive mass. Its represented assignment satisfies \(\varphi\).

Equivalently, if \(\varphi\) is unsatisfiable, every valid plan has \(M_t(\pi)\geq 1\), and every feasible allocation has objective at least \(\sum_{\pi\in\Pi_t}x_{t\pi}=1\). Thus splitting mass cannot meet the threshold.

Every constructed instance is feasible: any assignment supplies a valid plan to which all mass can be allocated.

5. Encoding size and conclusion

The construction uses \(n\) compound tasks, \(2n\) methods, \(2n\) primitive operators, and an arithmetic circuit with a number of gates linear in \(n+q\). Including identifiers, its binary description length is polynomial in the formula’s input length. Moreover, \(\tau=R=1\), and all added rational constants have constant encoding length.

This is a polynomial-time many-one reduction from \(3\text{-}\mathrm{SAT}\). It proves NP-hardness of the requested decision problem under every stated promise, including on instances whose feasibility is guaranteed. No membership claim for the unrestricted problem is needed to settle the question.
