The continuous mirror question, as graded

Given \(T=\{1,\ldots,\tau\}\), known rational masses \(\mu\in\mathbb{Q}_{>0}^{\tau}\) with \(\sum_t\mu_t=1\), and an unknown partition \(\Pi\) of \(T\) such that all replicas of each type lie in one coalition block, design adaptive succinct type-symmetric normal-form queries. A query indexed by \(E\subseteq T\times T\) uses directed-prisoner's-dilemma factors with payoffs normalized so that \(b\) deviates exactly when some \((a,b)\in E\) has \(a\sim_\Pi b\), returning \(\delta_b^E=\mu_b\mathbf{1}[\exists a:(a,b)\in E,\ a\sim_\Pi b]\); recover \(\Pi\) exactly while minimizing worst-case rounds.

A society is given by its support: \(T=\{1,\ldots,\tau\}\), with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) counts supported types, and \(L\) is their total encoding length. An unknown partition \(\Pi\) has nonempty blocks; the entire mass of each type belongs to one block. Write \(a\sim_\Pi b\) for membership in the same block.
A query is specified succinctly by a list \(E\subseteq\{(a,b)\in T^2:a\ne b\}\). For each factor \((a,b)\), type \(b\) chooses \(C\) or \(D\); choosing \(C\) gives per-unit-mass payoffs \(2/\mu_a\) to type \(a\) and \(-1/\mu_b\) to type \(b\), while \(D\) gives zero. Other types have only the action \(D\). All replicas of a type use the same factor action.
Products use independent action coordinates and additive payoffs, with the all-\(D\) profile specified. Each coalition maximizes its integrated total payoff against outsiders retaining their specified actions; if the specified actions are already optimal, it retains them, and otherwise ties among best responses are adversarial.
One round returns the exact vector \(\delta^E\), where \(\delta_b^E=\mu_b\mathbf{1}[\exists a:(a,b)\in E\text{ and }a\sim_\Pi b]\). Only these product queries are permitted; successive queries may depend on previous observations.

Proposition

For every $\tau\ge1$,

$$ R_\tau\le\lfloor\log_2\tau\rfloor. $$

Construction

For $\tau=1$, there is only one partition, so no query is necessary. Assume henceforth that $\tau\ge2$, and put

$$ h=\lfloor\tau/2\rfloor. $$

Arrange the types in the cyclic order $1,\ldots,\tau$. Let $c_b(d)$ denote the type $d$ positions before $b$ in this order, for $1\le d\le h$.

For each $b$, determine

$$ d_b=\min\{d\in\{1,\ldots,h\}:c_b(d)\sim_\Pi b\}, $$

using the sentinel $h+1$ if this set is empty.

Each $d_b$ initially has $h+1$ ordered possibilities. Maintain an interval of possible values. If its size is $s>1$, query its first $\lfloor s/2\rfloor$ values by listing the corresponding factors $(c_b(d),b)$.

The queried prefix never contains the sentinel, because the sentinel is the largest possibility. Moreover, the maintained interval contains the true minimum $d_b$. Therefore the response at coordinate $b$ is positive exactly when $d_b$ belongs to the queried prefix. The surviving interval has size at most $\lceil s/2\rceil$.

All these searches run simultaneously: each search controls a different response coordinate. After

$$ k=\lceil\log_2(h+1)\rceil $$

rounds, every $d_b$ is known.

Construct an undirected graph $G$ by adding the edge $\{b,c_b(d_b)\}$ whenever $d_b\le h$.

Proof that the connected components recover the partition

Every added edge has endpoints in the same true block, so no connected component crosses blocks.

Fix a block $B$ with at least two members. List its members in cyclic order. Let $g_1,\ldots,g_q$ be the positive cyclic gaps between consecutive members, where $q=|B|$. Then

$$ \sum_{i=1}^{q}g_i=\tau. $$

For a member whose preceding block member is at distance $g_i$, that preceding member is its nearest matching predecessor. Consequently:

  • if $g_i\le h$, the construction adds the edge between these consecutive members;
  • if $g_i>h$, the search returns the sentinel and adds no edge from that member.

At most one gap can exceed $h$. Indeed, two such gaps would have sum at least $2(h+1)$, but

$$ 2(h+1)>\tau. $$

Thus $G[B]$ contains all the edges between consecutive cyclic members except possibly one. Those edges form a connected graph: a cycle, or a path after deleting one cyclic edge. For a two-member block, at least one of the two cyclic gaps supplies its connecting edge. A singleton has no matching predecessor and remains isolated.

Therefore the connected components of $G$ are exactly $\Pi$.

Finally, $k=\lfloor\log_2\tau\rfloor$. To check this without rounding ambiguity, let $j=\lfloor\log_2\tau\rfloor$. Since $\tau\ge2$,

$$ 2^j\le\tau\le2^{j+1}-1, $$

$$ 2^{j-1}+1\le h+1\le2^j. $$

3. Lower bounds, new exact cases, and finite thresholds

Monotonicity

For every $\tau\ge1$,

$$ R_\tau\le R_{\tau+1}. $$

To prove this, simulate a strategy on $\tau+1$ types while declaring the extra type a singleton. Delete all query factors involving that type. Such factors would never produce a positive response. Feed the simulated strategy the original response bits followed by a zero bit. Its final partition, restricted to the original support, recovers every partition on $\tau$ types.

Counting lower bound

Let $B_\tau$ be the number of partitions of $\tau$ labelled types. A query returns at most $2^\tau$ different bit vectors. A deterministic strategy using at most $r$ rounds therefore has at most $2^{\tau r}$ terminal transcripts.

Exact recovery requires distinct terminal transcripts for distinct partitions. Consequently,

$$ B_\tau\le2^{\tau r}, \qquad R_\tau\ge \left\lceil\frac{\log_2 B_\tau}{\tau}\right\rceil. $$

For completeness, Bell numbers can be computed from

$$ B_0=1, \qquad B_{s+1}=\sum_{j=0}^{s}\binom{s}{j}B_{s-j}. $$

Here $j$ counts the other members of the block containing the last element; the remaining elements can be partitioned in $B_{s-j}$ ways. This recurrence gives

$$ B_1=1,\quad B_2=2,\quad B_3=5,\quad B_4=15, $$

and

$$ B_5=15+4\cdot5+6\cdot2+4\cdot1+1=52>2^5. $$

Thus $R_5\ge2$. Monotonicity gives $R_6,R_7\ge2$, while the circular strategy gives an upper bound of two for all three supports. Therefore

$$ R_5=R_6=R_7=2. $$

The same upper bound gives $R_8\le3$, while monotonicity gives $R_8\ge2$. Thus the next case remains

$$ R_8\in\{2,3\}. $$

Bounds on the largest support learnable in a fixed budget

Define

$$ N_r=\max\{\tau:R_\tau\le r\}. $$

This maximum exists, as the following proof also establishes.

The circular strategy gives

$$ N_r\ge2^{r+1}-1. $$

For an upper bound, fix $r\ge0$, and set

$$ q=2^{r+1}, \qquad n=(r+1)q+1. $$

Consider partitions in which types $1,\ldots,q$ belong to distinct blocks, and every remaining type is assigned to exactly one of these $q$ blocks. There are precisely $q^{n-q}$ such partitions: each assignment is recoverable from the resulting partition by inspecting which distinguished type shares its block.

Their number satisfies

$$ q^{n-q} =2^{(r+1)(n-q)} =2^{rn+1} >2^{rn}. $$

The counting bound therefore excludes recovery of all partitions on $n$ types in $r$ rounds. Monotonicity excludes every larger support as well. Hence

$$ 2^{r+1}-1\le N_r\le(r+1)2^{r+1}. $$

In particular, $N_r$ is finite. Also, $N_0=1$, since every support of size at least two admits more than one partition.

The exact-budget question is equivalently whether $\tau\le N_r$. The displayed bounds do not determine these thresholds exactly.

4. The repaired hardness obstruction

Throughout this section, $\mathsf{NP}$-hardness means hardness under polynomial-time many-one reductions.

Let $\mathcal B$ be the language of valid society-and-budget encodings satisfying $R(\mu)\le r$. Malformed encodings are rejected. Validity, including positivity of rational masses and their exact sum being one, is checkable in polynomial time using integer arithmetic.

Put

$$ U_\tau=\lfloor\log_2\tau\rfloor. $$

Using canonical binary representations, define

$$ S=\{00\}\cup \{1^\tau0\operatorname{bin}(r): \tau\ge1,\ 0\le r<U_\tau,\ R_\tau\le r\}. $$

There is a total polynomial-time many-one reduction from $\mathcal B$ to $S$:

  • On a malformed input, output $01$, which is outside $S$.
  • On a valid input with $r\ge U_\tau$, output $00$.
  • Otherwise, output $1^\tau0\operatorname{bin}(r)$.

The second case is correct by the circular recovery bound. The third is correct by mass independence and the definition of $S$. Writing $\tau$ in unary costs polynomial time because the input explicitly lists $\tau$ positive masses.

The language $S$ is sparse. Among strings of length at most $s$, it has at most

$$ 1+\sum_{\tau=1}^{s}U_\tau =O(s\log(s+1)) $$

members.

Mahaney’s theorem states that a sparse language cannot be $\mathsf{NP}$-hard under polynomial-time many-one reductions unless $\mathsf P=\mathsf{NP}$; membership of that language in $\mathsf{NP}$ is not required. This is the form stated in [Theorem 2.1 of Grochow’s exposition](https://arxiv.org/html/1610.05825v1).

If $\mathcal B$ were $\mathsf{NP}$-hard, composition with the reduction above would make the sparse language $S$ $\mathsf{NP}$-hard. Therefore

$$ \mathcal B\text{ is }\mathsf{NP}\text{-hard} \quad\Longrightarrow\quad \mathsf P=\mathsf{NP}. $$

Conversely, suppose $\mathsf P=\mathsf{NP}$. There is a fixed valid yes-instance consisting of two masses $1/2,1/2$ and budget one, and a fixed valid no-instance with the same masses and budget zero. Every language in $\mathsf{NP}$ can then be decided in polynomial time and reduced to $\mathcal B$ by outputting the appropriate fixed instance.

Thus

$$ \mathcal B\text{ is }\mathsf{NP}\text{-hard} \quad\Longleftrightarrow\quad \mathsf P=\mathsf{NP}. $$

5. An exact decision procedure

The following procedure establishes decidability and a polynomial-space upper bound, but its running time is exponential.

For a history $H$ of queries and bit responses, let $\mathcal P(H)$ be its consistent partitions. Define $W(H,d)$ to mean that this family can be recovered using at most $d$ further rounds.

The exact recurrence is:

  • If $|\mathcal P(H)|\le1$, return true.
  • If $|\mathcal P(H)|>1$ and $d=0$, return false.
  • Otherwise, use

$$ W(H,d) \quad\Longleftrightarrow\quad \exists E\ \forall y\in\{0,1\}^{\tau}\, W(H\mathbin{\|}(E,y),d-1). $$

The existential choice is the next deterministic query. The universal choice checks every response. A response inconsistent with every candidate partition yields an empty family and is vacuously successful. Induction on $d$ proves that this recurrence exactly characterizes recoverability.

First reject malformed inputs and accept valid inputs with $r\ge U_\tau$. Otherwise the recursion depth is less than $\log_2\tau$.

Candidate partitions need not be stored as a family. Enumerate canonical block-label sequences and test their consistency with the history, stopping after finding two when checking whether the family has size at most one. There are at most $\tau^\tau$ sequences to inspect, and one partition requires $O(\tau\log(\tau+1))$ bits.

Each query has an $M$-bit mask, where $M=\tau(\tau-1)$, and each response has $\tau$ bits. Depth-first evaluation therefore uses polynomial space in $\tau,L,\log(r+1)$.

There are $2^M$ possible queries and $2^\tau$ possible responses. The resulting deterministic running-time bound is

$$ \operatorname{poly}\!\bigl(\tau,L,\log(r+1)\bigr) \,2^{O(\tau^2\log(\tau+1))}. $$

Equivalently, expressing the enumeration cost using its maximum list size $m=M$, it is

$$ \operatorname{poly}\!\bigl(m,\tau,L,\log(r+1)\bigr) \,2^{O((m+\tau)\log(\tau+1))}. $$

Every permitted query is considered; no additional factor cap is imposed.
