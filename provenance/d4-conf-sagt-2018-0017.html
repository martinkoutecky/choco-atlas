The continuous mirror question, as graded

Given four types \(T\), rational masses \(\mu_t>0\) summing to \(1\), and one normalized, additive, divisible valuation oracle \(v_t\) per type over \([0,1]\), can a Robertson–Webb protocol output bundles \(X_t\) that are finite unions of intervals, satisfy \(v_t(X_t)\ge v_t(X_s)\) for all \(t,s\), and meet \(\sum_t \mu_t \mathbf{1}_{X_t}(x)\le 1\) almost everywhere, using at most \(61\) cut queries and \(110\) evaluation queries? Theorem 1’s protocol answers this: its four output bundles partition the cake.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau=4\) types with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) counts supported types, not possible types. Let \(L\) be the total bit length of the masses. Each type has a nonnegative, normalized, additive, divisible valuation on finite unions of intervals in \([0,1]\), accessed through the Robertson–Webb model.
Output bundles \(X_t\), each a finite union of intervals, with \(\bigcup_t X_t=[0,1]\), satisfying \(v_t(X_t)\ge v_t(X_s)\) for every \(t,s\) and \(\sum_t\mu_t\mathbf{1}_{X_t}(x)\le1\) almost everywhere. Overlaps are permitted subject to this capacity constraint. Preferences are weak; equality satisfies envy-freeness. Measure oracle complexity by cut and evaluation queries, and any additional computational complexity in \(\tau,L\); there is no candidate parameter \(m\).

Can a Robertson–Webb protocol always produce such bundles using at most \(61\) cut queries and \(110\) evaluation queries, or must some instances exceed one of these budgets?

For four individual agents, a verified algorithm produces a complete envy-free partition within these query budgets ([Amanatidis et al.](https://arxiv.org/pdf/1807.00317)). Its guarantee also settles the stated mass problem, since its output satisfies the specified coverage and capacity conditions; consequently this target is already closed.

Published theorem and hypothesis checks

Theorem 1 of [Amanatidis et al., *An Improved Envy-Free Cake Cutting Protocol for Four Agents*](https://arxiv.org/pdf/1807.00317) guarantees an envy-free allocation using at most \(61\) cut queries and \(110\) evaluation queries. The protocol allocates the entire cake, and each bundle is a finite union of intervals. Its valuation assumptions are normalization, additivity, divisibility, and nonnegativity, exactly as in the task. Its query accounting includes the cost of implementing queries on disconnected residues using interval queries.

Apply this theorem to four agents indexed by the four supported types, with agent \(t\) having valuation \(v_t\). This uses one agent per supported type; the masses do not determine the number of agents. The theorem does not require distinct valuations, and its tie-breaking convention accommodates weak preferences.

Verification of the mass allocation

Let \(P_t\) be the bundle returned for agent \(t\), and output \(X_t=P_t\).

First, each \(X_t\) is a finite union of intervals, and completeness gives \(\bigcup_{t=1}^{4}X_t=[0,1]\).

Second, envy-freeness of the returned allocation gives \(v_t(X_t)\geq v_t(X_s)\) for every pair \(t,s\). These are precisely the required comparisons: the task does not impose a mass-weighted envy condition.

Third, for every point \(x\), nonnegativity of the masses and \(\mathbf{1}_{X_t}(x)\leq1\) imply
\(\sum_{t=1}^{4}\mu_t\mathbf{1}_{X_t}(x)\leq\sum_{t=1}^{4}\mu_t=1\).
Thus capacity holds pointwise, including at interval endpoints.

The reduction adds no cut or evaluation queries. It requires no mass arithmetic; reading the mass encodings takes \(O(L)\) time. With \(\tau=4\) fixed, the protocol has bounded control and exact arithmetic operations in the usual Robertson–Webb model. This is an oracle-model operation count, not a bit-complexity assertion about arbitrary real oracle answers. No candidate parameter \(m\) is needed.
