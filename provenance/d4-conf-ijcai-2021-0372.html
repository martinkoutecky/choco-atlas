The continuous mirror question, as graded

Given a finite project set \(P\) partitioned into groups \(P_1,\ldots,P_q\), integer quotas \((\ell_j,u_j)\), a scale \(N\), and a listed support \(T\) of strict rankings with rational masses \(\mu_t>0\) summing to \(1\), does there exist a selection \(y\in\{0,1\}^{P}\) and assignment masses \(x_{tr}\geq 0\) such that \(\sum_{r\in P}x_{tr}=\mu_t\), \(\sum_{t\in T}x_{tr}=y_r/N\), \(\sum_{r\in P}y_r=N\), and \(\ell_j\leq\sum_{r\in P_j}y_r\leq u_j\) for every \(j\), with \(x_{tr}>0\) implying \(r\succ_t p\) for every unselected project \(p\) (that is, every \(p\) with \(y_p=0\))?

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a set of \(m\) projects partitioned into \(q\geq1\) nonempty groups \(P_1,\ldots,P_q\). The input includes a binary-encoded integer \(1\leq N\leq m\) and integer quotas \(0\leq\ell_j\leq u_j\leq|P_j|\), with \(\sum_j\ell_j\leq N\leq\sum_j u_j\).
A society is given by its support: a list \(T\) of \(\tau\) distinct strict rankings \(\succ_t\) over all projects, each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total binary input length; state running times in \(m,\tau,q,N,L\).
A selection and mass assignment consist of \(y\in\{0,1\}^{P}\) and nonnegative real numbers \(x_{tr}\), satisfying \(\sum_{r\in P}x_{tr}=\mu_t\) for every \(t\), \(\sum_{t\in T}x_{tr}=y_r/N\) for every \(r\), \(\sum_{r\in P}y_r=N\), and \(\ell_j\leq\sum_{r\in P_j}y_r\leq u_j\) for every \(j\).
The assignment is frustration-free if \(x_{tr}>0\) implies \(r\succ_t p\) for every project \(p\) with \(y_p=0\). The decision problem asks whether such a frustration-free selection and assignment exist.

Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For a finite list of agents, each assigned one distinct project, frustration-free existence under these partition quotas is \(\mathrm{NP}\)-complete, even when rankings place each group in a contiguous block, or when every \(u_j<|P_j|\); imposing both restrictions yields a polynomial-time algorithm. [Verified discrete results](https://www.ijcai.org/proceedings/2021/0006.pdf).
No published result settling this exact mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Specified the undefined scale N as a binary-encoded positive integer with N at most m, corresponding to the discrete number of agents.
  • Restored the quota domain and feasibility assumptions: nonnegative integer quotas bounded by group sizes, with total lower quotas at most N and total upper quotas at least N.
  • Took the partition to have at least one nonempty group.
  • Specified assignment masses as nonnegative real numbers; input masses remain binary rationals without any requirement that N times each mass be integral.
  • Defined L as the total binary input length.

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness already holds when every scaled mass \(N\mu_t\) is a positive integer.

The crucial observation is that, for a fixed selection, fractional assignments with integer scaled masses can be converted into discrete assignments by flow integrality.

1. Feasibility for a fixed selection

Fix a set \(S\subseteq P\) with \(|S|=N\), satisfying all partition quotas. For each type \(t\), define its eligible projects by

\[ A_t(S)=\{r\in S:\ r\succ_t p\text{ for every }p\in P\setminus S\}. \]

If \(S=P\), the condition is vacuous, so \(A_t(S)=P\). Otherwise, \(A_t(S)\) consists precisely of the projects preceding the highest-ranked unselected project in ranking \(t\).

Construct a directed network with source \(s\), one vertex for each type, one vertex for each selected project, and sink \(v\). Its arcs and capacities are:

  • \(s\to t\), of capacity \(\mu_t\);
  • \(t\to r\), of capacity \(1\), whenever \(r\in A_t(S)\);
  • \(r\to v\), of capacity \(1/N\), for every \(r\in S\).

Claim. A frustration-free mass assignment with selected set \(S\) exists exactly when this network admits a flow of value \(1\).

Indeed, an assignment gives such a flow by placing \(x_{tr}\) on each eligible type–project arc. Unselected projects receive zero mass because their prescribed column sums are zero.

Conversely, the capacities leaving the source sum to \(1\), as do the capacities entering the sink. A flow of value \(1\) therefore saturates every source–type and project–sink arc. Flow conservation gives the required row and column sums, and the definition of the type–project arcs ensures frustration-freeness.

2. Membership in \(\mathrm{NP}\), including bit complexity

A certificate specifies only \(S\). The verifier checks its cardinality and quotas, then checks the flow condition above.

Write \(\mu_t=a_t/b_t\), with positive binary integers \(a_t,b_t\), and set

\[ D=N\prod_{t\in T}b_t. \]

Multiplying all capacities by \(D\) produces integer capacities. The target flow value becomes \(D\), and project–sink capacities become \(D/N\). Since the denominator encodings and the encoding of \(N\) are part of the input, \(D\) has \(\mathcal O(L)\) bits. Every scaled capacity is at most \(D\).

The network has at most \(m+\tau+2\) vertices and \(m\tau+m+\tau\) arcs. Eligibility can be computed in \(\mathcal O(m\tau)\) ranking-entry operations by scanning each ranking until its first unselected project.

Using schoolbook integer arithmetic and Edmonds–Karp, a conservative bound for verification is

\[ \mathcal O\!\left( \tau L^2+m\tau+q+ (m+\tau+2)(m\tau+m+\tau)^2L \right) \]

bit operations. Here the initial term covers clearing denominators and constructing integer capacities; the flow term uses the standard bound of \(\mathcal O(VE^2)\) arithmetic operations, each on \(\mathcal O(L)\)-bit integers.

Thus verification is polynomial in \(m,\tau,q,N,L\). In particular, it does not require expanding rational masses into a population of agents. The problem belongs to \(\mathrm{NP}\).

3. Reduction from the discrete problem

Use the discrete frustration-free existence problem under partition quotas as the source problem. Its input explicitly lists \(n\) agents, each of whom must receive one distinct project. Theorem 2 of the supplied paper establishes that this problem is \(\mathrm{NP}\)-complete. [Belahcene, Mousseau and Wilczynski, *Combining Fairness and Optimality when Selecting and Allocating Projects*](https://www.ijcai.org/proceedings/2021/0006.pdf).

Retain the projects, groups and quotas, and set \(N=n\). Merge agents having identical rankings. For each resulting distinct ranking \(t\), let \(k_t\) be its multiplicity and define

\[ \mu_t=\frac{k_t}{n}. \]

These masses are positive and sum to \(1\), and the resulting support contains exactly the distinct rankings, as required. Moreover, \(\tau\leq N\), and each mass has an encoding of length \(\mathcal O(\log(N+1))\). Grouping the explicitly listed rankings and constructing these masses takes polynomial time.

We prove equivalence in both directions.

Discrete feasibility implies mass feasibility

Suppose there is a discrete frustration-free allocation with selected set \(S\). Define

\[ x_{tr}=\frac{1}{n} \left|\{i:\text{agent }i\text{ has ranking }t\text{ and receives }r\}\right|. \]

Every type has row sum \(k_t/n=\mu_t\). Each selected project has column sum \(1/n=1/N\), and each unselected project has column sum zero. The selection satisfies the original quotas.

Whenever \(x_{tr}>0\), an agent with ranking \(t\) receives \(r\); discrete frustration-freeness therefore gives \(r\succ_t p\) for every unselected project \(p\). This is a feasible mass solution.

Mass feasibility implies discrete feasibility

Suppose the constructed instance has a frustration-free mass solution with selected set \(S\). Put \(z_{tr}=n x_{tr}\). Then

\[ \sum_{r\in S}z_{tr}=k_t, \qquad \sum_{t\in T}z_{tr}=1\quad(r\in S), \]

and positive entries occur only on eligible pairs.

Construct a network with source–type capacities \(k_t\), eligible type–project capacities \(1\), and selected project–sink capacities \(1\). The numbers \(z_{tr}\) define a flow of value \(n\): each \(z_{tr}\leq1\) because its project column sums to \(1\).

All capacities are integers. By the integral maximum-flow theorem, there is an integer flow of value \(n\). The total capacities leaving the source and entering the sink both equal \(n\), so all those arcs are saturated.

Consequently, each selected project is assigned to exactly one type, and type \(t\) receives exactly \(k_t\) distinct projects. Assign these projects bijectively to the \(k_t\) original agents having ranking \(t\). Every assigned pair is eligible, so the resulting allocation is frustration-free. Its selected set is \(S\), hence it satisfies every partition quota.

This completes the polynomial reduction.

4. Conclusion

The reduction proves \(\mathrm{NP}\)-hardness, and the polynomial certificate verifier proves membership in \(\mathrm{NP}\). Therefore the mass formulation is \(\mathrm{NP}\)-complete.

The reduction also preserves contiguous group blocks in rankings and strict group upper quotas. Thus the two separate hardness restrictions stated in the question transfer to the mass formulation.
