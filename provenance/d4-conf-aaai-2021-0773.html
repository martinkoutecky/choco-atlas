The continuous mirror question, as graded

Given a finite role set \(R\), colour set \(C\), irreducible rational row-stochastic matrix \(Q\), memory probabilities \(p_0,\ldots,p_m\), target colour \(c\), and rational society distribution \(\mu\) over types \((r,h)\in R\times C^{m+1}\), compute \(\lim_{N\to\infty}\Pr_N(c\text{ reaches stable consensus})\). For each valid \(N\), instantiate \(N\mu_{r,h}\) agents of each type; each role-\(r\) agent selects role \(s\) according to \(Q_{rs}\), then samples an agent uniformly from that role, and follows the stated memory protocol.

Packaged proof task (what the prover saw — nothing else)

Let \(R,C\) be nonempty finite sets, \(c\in C\), \(m\geq1\), and \(Q\) an irreducible rational row-stochastic matrix indexed by \(R\). Let \(p_0,\ldots,p_m\) be positive binary rationals summing to \(1\).
A society is given by its support: the list of the \(\tau\) types \((r,h)\in R\times C^{m+1}\) with positive mass, each mass \(\mu_{r,h}\) a binary rational; masses sum to \(1\), and every role has positive total mass. Here \(\tau\) is the support size, not the number of possible types.
For each positive integer \(N\) such that every \(N\mu_{r,h}\) is integral, instantiate that many agents of type \((r,h)\), with fixed role \(r\) and initial colours \(X_a(j)=h_j\) for \(0\leq j\leq m\).
At each round \(t\geq m\), every role-\(r\) agent independently draws a lag \(i\) with probability \(p_i\), a role \(s\) with probability \(Q_{rs}\), and an agent \(b\) uniformly from role \(s\), then sets \(X_a(t+1)=X_b(t-i)\). Updates are synchronous; draws are independent across agents and rounds, and sampling may select the updating agent itself.
Stable consensus on \(c\) means all agents have colour \(c\) throughout the current and preceding \(m\) rounds. Let \(P_N(c)\) be the probability of eventually reaching this state, and define \(F=\lim_{N\to\infty,\;N\mu\text{ integral}}P_N(c)\).

Does \(F\) exist for every such input, and is its exact computation polynomial-time solvable or NP-hard? State running times in \(m,\tau,|R|,|C|\) and the total input bit length \(L\).

For finite strongly connected weighted agent graphs with positive lag probabilities and \(m\geq1\), stable consensus occurs almost surely, and an exact stationary-distribution expression gives each colour’s winning probability. Result

The limit \(F\) exists for every input and is exactly computable in polynomial time. In fact, \(P_N(c)\) is the same for every admissible population size \(N\).

Let \(d=|R|\), and define the mass of role \(r\) and its initial colour frequencies by

\(\displaystyle \rho_r=\sum_{h:(r,h)\text{ is supported}}\mu_{r,h},\qquad f_{r,j}(c)=\frac{1}{\rho_r}\sum_{h:(r,h)\text{ is supported}}\mu_{r,h}\mathbf 1_{\{h_j=c\}}.\)

Every \(\rho_r\) is positive by hypothesis. Let \(\nu\) be the unique stationary distribution of \(Q\):

\(\displaystyle \nu Q=\nu,\qquad \sum_{r\in R}\nu_r=1.\)

Define

\(\displaystyle a_k=\sum_{i=k}^{m}p_i\quad(0\leq k\leq m),\qquad Z=\sum_{k=0}^{m}a_k=\sum_{i=0}^{m}(i+1)p_i.\)

Then the exact answer is

\(\displaystyle \boxed{F=P_N(c)=\frac{1}{Z}\sum_{r\in R}\nu_r\sum_{k=0}^{m}a_k f_{r,m-k}(c)}.\)

The index reversal matters: \(a_0/Z\) weights the most recent initial round, whose index is \(m\).

1. Almost-sure stable consensus for each admissible population

Fix an admissible \(N\), and let \(n_r=N\rho_r\). These are positive integers because they are sums of the integral type counts.

The agent-to-agent sampling matrix is

\(\displaystyle H_{ab}=\frac{Q_{rs}}{n_s},\)

where agents \(a,b\) have roles \(r,s\), respectively. It is row-stochastic, since

\(\displaystyle \sum_bH_{ab}=\sum_{s\in R}n_s\frac{Q_{rs}}{n_s}=1.\)

Its positive-edge graph is strongly connected. Indeed, any positive-probability role walk lifts to an agent walk by choosing an agent in each intermediate role. Irreducibility of \(Q\) supplies such a walk between distinct roles. It also supplies a positive-length closed walk through each role, which permits connecting two agents in the same role. For the single-role case, \(Q=(1)\), and every agent samples every other agent with positive probability.

We use the finite-population result supplied in the question: a memory consensus process on a finite strongly connected weighted agent graph reaches stable consensus almost surely when \(m\geq1\) and all lag probabilities are positive. These hypotheses have now all been verified. See Proposition 4 and Corollary 1 of [*The Influence of Memory in Multi-Agent Consensus*](https://ojs.aaai.org/index.php/AAAI/article/download/17342/17149).

Consequently, this population eventually reaches stable consensus on some colour with probability one.

2. A martingale determining the winning probability

For each role \(r\) and time \(t\), let

\(\displaystyle z_r(t)=\frac{1}{n_r}\sum_{a:\,\operatorname{role}(a)=r}\mathbf 1_{\{X_a(t)=c\}}.\)

Let \(\mathcal F_t\) contain the initial histories and all draws used through time \(t\). For \(t\geq m\), the sampling rule gives

\(\displaystyle \mathbb E[z_r(t+1)\mid\mathcal F_t]=\sum_{i=0}^{m}p_i\sum_{s\in R}Q_{rs}z_s(t-i).\)

To justify this identity, a role-\(r\) agent chooses lag \(i\) and role \(s\) with probability \(p_iQ_{rs}\). Conditional on those choices, its probability of copying colour \(c\) is precisely \(z_s(t-i)\). Averaging over agents preserves this expectation.

Set

\(\displaystyle y(t)=\sum_{r\in R}\nu_rz_r(t).\)

Using \(\nu Q=\nu\), we obtain

\(\displaystyle \mathbb E[y(t+1)\mid\mathcal F_t]=\sum_{i=0}^{m}p_i y(t-i).\)

Now define, for \(t\geq m\),

\(\displaystyle M_t=\frac{1}{Z}\sum_{k=0}^{m}a_k y(t-k).\)

The identities

\(\displaystyle a_0=1,\qquad a_i=p_i+a_{i+1}\ (0\leq i<m),\qquad a_m=p_m\)

show that \(M_t\) is a martingale. Explicitly,

\(\displaystyle \begin{aligned} Z\,\mathbb E[M_{t+1}\mid\mathcal F_t] &=\sum_{i=0}^{m}p_i y(t-i)+\sum_{k=1}^{m}a_k y(t+1-k)\\ &=\sum_{i=0}^{m-1}(p_i+a_{i+1})y(t-i)+p_m y(t-m)\\ &=\sum_{i=0}^{m}a_i y(t-i) =ZM_t. \end{aligned} \)

Moreover, \(0\leq M_t\leq1\), because \(0\leq y(t)\leq1\), all \(a_k\) are positive, and their sum is \(Z\).

Let \(W\) denote the eventual consensus colour, which exists almost surely by Section 1. Once stable consensus has occurred, all the indicators appearing in \(M_t\) equal \(\mathbf 1_{\{W=c\}}\). Thus

\(\displaystyle M_t\longrightarrow\mathbf 1_{\{W=c\}}\qquad\text{almost surely}.\)

Bounded convergence and the martingale expectation identity imply

\(\displaystyle P_N(c)=\mathbb E[\mathbf 1_{\{W=c\}}]=\lim_{t\to\infty}\mathbb E[M_t]=M_m.\)

This argument requires no estimate of the consensus time.

3. Cancellation of population size and existence of the limit

For an initial time \(j\), the number of role-\(r\) agents having colour \(c\) is

\(\displaystyle \sum_{h:(r,h)\text{ is supported}}N\mu_{r,h}\mathbf 1_{\{h_j=c\}}.\)

Therefore,

\(\displaystyle z_r(j)=\frac{\sum_hN\mu_{r,h}\mathbf 1_{\{h_j=c\}}}{N\rho_r}=f_{r,j}(c).\)

Substituting this into \(M_m\) gives the boxed formula. Every quantity in that formula is determined by the input and is independent of \(N\).

Finally, admissible population sizes are unbounded: every positive multiple of a common denominator of the masses is admissible. Since \(P_N(c)\) is constant on this set, its specified limit exists and equals that constant.

4. Exact algorithm and running time

The algorithm computes \(\nu\), the tail sums \(a_k\), and the quantities

\(\displaystyle \rho_r,\qquad T_r=\sum_{h:(r,h)\text{ is supported}}\mu_{r,h}\sum_{k=0}^{m}a_k\mathbf 1_{\{h_{m-k}=c\}}.\)

It then returns

\(\displaystyle F=\frac{1}{Z}\sum_{r\in R}\frac{\nu_rT_r}{\rho_r}.\)

Gaussian elimination and a scan of the support require

\(\displaystyle O\!\left(d^3+(m+1)\tau+m\right)\)

exact rational arithmetic operations. Here is also an explicit polynomial bound on bit complexity.

Integer representation and stationary distribution

Let \(D\) be the product of the denominators of all numerical input entries. Its bit length is \(O(L)\). Write

\(\displaystyle Q_{rs}=\frac{A_{rs}}D,\qquad p_i=\frac{P_i}D,\qquad \mu_{r,h}=\frac{U_{r,h}}D.\)

All these integer numerators lie between zero and \(D\).

To compute \(\nu\), take any \(d-1\) equations of

\(\displaystyle (A^{\mathsf T}-DI)\nu^{\mathsf T}=0\)

and append the equation \(\sum_r\nu_r=1\). The resulting integer coefficient matrix \(B\) is nonsingular. Indeed, irreducibility gives rank \(d-1\) for \(Q^{\mathsf T}-I\). Its row relations form a one-dimensional space generated by the all-ones vector, since the rows sum to zero. Hence any \(d-1\) rows are independent. Their common nullspace is the stationary line, on which normalization determines a unique vector.

Cramer’s rule gives a common-denominator representation

\(\displaystyle \nu_r=\frac{b_r}{b},\qquad b=\det B\ne0.\)

The determinants have \(O(d(L+\log(d+1)))\) bits by Hadamard’s inequality. Computing these \(d+1\) determinants by fraction-free elimination takes \(O(d^4)\) integer operations on operands of this bit length. This is a conservative implementation; it suffices for the claimed classification.

Evaluation and output size

Define integers

\(\displaystyle U_r=\sum_hU_{r,h},\qquad A_k'=\sum_{i=k}^{m}P_i,\qquad V=\sum_{i=0}^{m}(i+1)P_i, \)

and

\(\displaystyle S_r=\sum_hU_{r,h}\sum_{k=0}^{m}A_k'\mathbf 1_{\{h_{m-k}=c\}}.\)

Then

\(\displaystyle F=\sum_{r\in R}\frac{b_rS_r}{b\,U_rV}.\)

Every \(U_r\) is positive. Using the common denominator

\(\displaystyle bV\prod_{r\in R}U_r\)

allows exact evaluation without uncontrolled growth of intermediate rational denominators.

We have \(U_r\leq D\), \(V\leq(m+1)D\), and \(S_r\leq U_rV\). Consequently, all required operands and the final numerator and denominator have

\(\displaystyle O\!\left(d\bigl(L+\log(d+m+2)\bigr)\right)\)

bits.

Using schoolbook integer arithmetic, a valid overall bit-operation bound is

\(\displaystyle O\!\left( L+ \bigl[d^4+(m+1)\tau+m+1\bigr] \bigl[d(L+\log(d+m+2))\bigr]^2 \right). \)

For the specified colour \(c\), the algorithm does not iterate over \(C\); colour-label encoding and any explicit list of \(C\) are accounted for in \(L\). It scans the listed \(\tau\) histories, without enumerating \(C^{m+1}\) or instantiating agents.

Thus exact computation of \(F\) is polynomial-time solvable.
