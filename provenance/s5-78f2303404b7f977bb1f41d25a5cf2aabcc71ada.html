The continuous mirror question, as graded

Given a candidate set \(C\), explicitly listed approval types \(T\subseteq 2^C\), rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), an integer \(\bar{k}\), and \(d\in\mathbb{Q}\), decide whether there exists an integral committee \(W\subseteq C\) with \(|W|=|C|-\bar{k}\) and \(\sum_{t\in T}\mu_t\mathbf{1}[t\cap W\neq\varnothing]\ge d\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a finite candidate set and \(m=|C|\). A society is given by its support: an explicit list \(T\subseteq 2^C\) of \(\tau=|T|\) distinct approval types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval types.
Empty approval types are allowed. The remaining inputs are an integer \(0\le\bar{k}\le m\) and a binary-rational threshold \(d\in\mathbb{Q}\). Let \(L\) be the total input bit length.
A committee is an integral subset \(W\subseteq C\) with \(|W|=m-\bar{k}\). Its represented mass is \(s(W)=\sum_{t\in T:\,t\cap W\ne\varnothing}\mu_t\). The decision problem asks whether some such committee satisfies \(s(W)\ge d\); equality is accepted and no tie-breaking is imposed. State running times in \(m,\tau,L\), and \(\bar{k}\).

Is this rational-mass committee decision problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For a finite multiset of approval voters, CCAV winner determination is \(\mathrm{NP}\)-complete ([Procaccia, Rosenschein, and Zohar](https://www.microsoft.com/en-us/research/wp-content/uploads/2007/01/multi.ijcai_.pdf)) and \(\mathrm{W}[1]\)-hard parameterized by \(\bar{k}\), even when every voter approves exactly two candidates ([Yang and Wang](https://arxiv.org/html/2107.04685v5)).
No separate result for the normalized binary-rational-mass formulation was verified.

Modeling choices made when packaging the task

  • Restricted the previously unrestricted integer bar{k} to 0 through m, matching the discrete committee-size domain.
  • Removed zero-mass entries so the explicitly listed types are exactly the positive-mass support.
  • Explicitly allowed empty approval types and committee sizes zero and m, as the discrete definitions do.
  • Defined L as the total input bit length and retained arbitrary rational thresholds.

Result

The problem is \(\mathrm{NP}\)-complete. It remains \(\mathrm{NP}\)-hard when \(d=1\), every approval type contains exactly two candidates, and all masses are positive dyadic rationals.

It is also \(\mathrm{W}[1]\)-hard parameterized by \(\bar{k}\). Thus a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

1. Exact verification and membership in \(\mathrm{NP}\)

A certificate is a committee \(W\subseteq C\). Check that \(|W|=m-\bar{k}\), determine which explicitly listed types intersect \(W\), and compare their total mass with \(d\).

This comparison requires only polynomial-size integer arithmetic. Write \(\mu_t=a_t/b_t\) and \(d=a/b\), with positive denominators, and set

\(D=b\prod_{t\in T}b_t,\qquad z_t=a_t(D/b_t),\qquad z_d=a(D/b).\)

The binary length of \(D\) is at most the sum of the input denominator lengths, plus a constant, hence is \(O(L)\). All the integers above have \(O(L)\) bits. The required comparison is exactly

\(\displaystyle \sum_{t:\,t\cap W\ne\varnothing}z_t\ge z_d.\)

Using schoolbook integer arithmetic, preprocessing takes \(O(L^3)\) bit operations. After converting approval types to incidence vectors, verifying a committee takes \(O(m\tau+\tau L+m)\) operations. In particular, verification is polynomial in the input length. Equality is handled exactly.

Therefore the problem belongs to \(\mathrm{NP}\).

2. A direct hardness reduction

Use the standard \(\mathrm{NP}\)-complete Independent Set problem: given a finite simple graph \(G=(V,E)\) and an integer \(r\), determine whether there is an independent set of size at least \(r\). We may restrict to \(0\le r\le |V|\) and \(q=|E|\ge1\): the excluded instances are decidable immediately and can be mapped to fixed yes- or no-instances.

Construct

\(C=V,\qquad T=\{\{u,v\}:uv\in E\},\qquad \bar{k}=r,\qquad d=1.\)

Because the graph is simple, these are \(q\) distinct approval types, each containing exactly two candidates. Thus \(\tau=q\).

To obtain normalized dyadic masses, let \(B=2^{\lceil\log_2 q\rceil}\) and distinguish one edge type \(t_0\). Set

\(\displaystyle \mu_t=\frac1B\quad(t\ne t_0),\qquad \mu_{t_0}=\frac{B-q+1}{B}.\)

Since \(B\ge q\), every mass is positive. Their sum is

\(\displaystyle \frac{q-1}{B}+\frac{B-q+1}{B}=1.\)

Each mass uses \(O(\log(q+1))\) bits. Even with incidence-vector encoding, the output length is \(O(|V|q+(|V|+q)\log(|V|+q+2))\), so the construction is polynomial.

For any eligible committee \(W\), positivity and normalization imply

\(s(W)\ge1\quad\Longleftrightarrow\quad \text{every edge has an endpoint in }W.\)

Indeed, representing every type gives total mass one; missing any type loses a strictly positive mass.

Consequently,

\(s(W)\ge1\quad\Longleftrightarrow\quad V\setminus W\text{ is independent}.\)

Moreover, \(|V\setminus W|=\bar{k}=r\). An independent set of size at least \(r\) contains an independent subset of size exactly \(r\), whose complement is an eligible committee. Conversely, every successful committee yields an independent set of size \(r\).

This proves both directions of the reduction, and hence \(\mathrm{NP}\)-hardness. Together with Section 1, it proves \(\mathrm{NP}\)-completeness.

3. Hardness parameterized by \(\bar{k}\)

Independent Set parameterized by its target size \(r\) is \(\mathrm{W}[1]\)-hard. The construction above has \(\bar{k}=r\), so it is also a parameterized reduction.

The graph-to-approval correspondence is the one used in [Yang and Wang, Theorem 2](https://arxiv.org/html/2107.04685v5); the positive dyadic normalization above explicitly establishes its validity for this formulation.

Thus the rational-mass problem is \(\mathrm{W}[1]\)-hard parameterized by \(\bar{k}\), even under the restrictions stated in the result.

4. Explicit algorithmic bounds

Enumeration by omitted candidates. Enumerate every \(K\subseteq C\) of size \(\bar{k}\), and evaluate \(W=C\setminus K\). This gives running time

\(\displaystyle O\!\left(L^3+\binom{m}{\bar{k}}(m\tau+\tau L+m)\right).\)

Hence the problem is polynomial-time solvable for every fixed \(\bar{k}\), with an exponent depending on \(\bar{k}\). This does not establish fixed-parameter tractability.

An algorithm parameterized by support size. Index the actual types by \(\{1,\ldots,\tau\}\). For each candidate \(c\), define its representation mask

\(A_c=\{i:c\in t_i\}.\)

Process candidates successively. For each mask \(S\subseteq\{1,\ldots,\tau\}\), maintain the minimum number of processed candidates whose representation masks have union exactly \(S\). Initially, the empty mask has value zero and all other masks have value infinity. When processing \(c\), either skip it or update mask \(S\cup A_c\) with the previous value for \(S\), plus one.

These transitions are exhaustive: every subset of processed candidates either contains the latest candidate or does not. Induction therefore proves that all stored minima are correct.

Let \(h=m-\bar{k}\). Accept precisely when some mask \(S\) has stored minimum at most \(h\) and satisfies

\(\displaystyle \sum_{i\in S}\mu_{t_i}\ge d.\)

A successful committee gives such a mask. Conversely, a subset witnessing such a mask can be extended to exactly \(h\) candidates because \(h\le m\); adding candidates cannot decrease represented mass.

Using the integer weights from Section 1, a conservative running-time bound is

\(\displaystyle O\!\left(L^3+2^\tau\bigl(m(\tau+L)+\tau L\bigr)\right).\)

Thus the problem is fixed-parameter tractable in the explicit support size \(\tau\). Empty approval types are handled automatically: their indices occur in no candidate mask.
