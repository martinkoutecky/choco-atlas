The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), and each type's strict preferences over feasible coalition compositions \(x\in[0,\mu]^{|T|}\) with \(x_t>0\), encoded by rational affine lexicographic keys and a singleton option, does every instance admit a measurable partition that is internally stable against positive-mass within-coalition deviations and Pareto optimal, and can one construct such a partition from the finite input?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(T\), the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Type \(t\) occupies an atomless interval of length \(\mu_t\).
For each type \(t\), the input specifies \(K_t(x)=A_tx+b_t\), with rational coefficients, on \(D_t=\{x\in\mathbb R^\tau:0\le x\le\mu,\ x_t>0\}\), and a rational key vector for its singleton option \(s_t\). Larger keys in lexicographic order are preferred; keys distinguish every pair of distinct options in \(D_t\cup\{s_t\}\). Coefficients may have either sign.
An admissible measurable partition consists of at most countably many measurable coalitions of positive mass and singleton coalitions for everyone remaining; null sets are disregarded. A coalition's composition is the vector of its type masses, and members evaluate it using their type's preferences.
Internal stability requires that every positive-mass coalition of composition \(x\) satisfies \(x\succeq_t s_t\) for every \(t\) with \(x_t>0\), and admits no composition \(0\le y\le x\), \(y\ne x\), \(\sum_t y_t>0\), such that \(y\succ_t x\) for every \(t\) with \(y_t>0\). Singleton coalitions are internally stable.
Pareto optimality excludes any admissible partition making almost every individual weakly better off and a set of positive mass strictly better off.
For construction, a partition is represented by a finite or countable sequence of positive coalition-composition vectors whose coordinatewise sum is at most \(\mu\); residual mass lives alone. A finite program must generate this sequence, with each coordinate uniformly approximable to any requested rational accuracy; compositions are realized by consecutive intervals within each type.
Let \(m\) be the maximum key-vector length and \(L\) the total input bit length; state running times in \(m,\tau,L\), including requested output accuracy where relevant.

Does every instance admit an internally stable, Pareto-optimal admissible partition, or can existence fail?
Is deciding existence in \(\mathrm P\) or \(\mathrm{NP}\)-hard, and can such a partition, whenever one exists, be constructed effectively from the finite input?

For finite societies with strict coalition preferences, a terminating algorithm is stated to produce an internally stable, Pareto-optimal partition; no polynomial-time bound is established. [Karakaya and Özbilen (2022)](https://dergipark.org.tr/en/download/article-file/2519220).
No result settling this precise atomless, affine-lexicographic formulation was located in the literature search.

Modeling choices made when packaging the task

  • Specified the atomless society as one interval per supported type, retaining the given normalization to total mass one.
  • Specified larger lexicographic keys as better, unrestricted signs for rational coefficients, rational singleton keys, and a promise that keys distinguish distinct composition and singleton options.
  • Restricted admissible partitions to countably many positive-mass measurable coalitions plus singletons; excluded nonsingleton null coalitions, whose preferences the graded question does not define.
  • Preserved the discrete singleton departure by requiring every represented type to weakly prefer its coalition to living alone, in addition to forbidding unanimous positive-mass subcoalition departures.
  • Interpreted Pareto comparisons almost everywhere, with strict improvement required on a set of positive mass.
  • Specified effective construction through a finite program generating finite or countable composition lists with uniformly computable real coordinates, rather than requiring rational coalition masses.
  • Defined the otherwise absent parameter m as maximum key-vector length and L as total input bit length.

Partial resolution and new finite-partition results

Existence can fail, and deciding existence is $\mathrm{NP}$-hard. In addition, the following construction-related statements can be proved:

  • Pareto optimality of a finite rational partition is decidable against all admissible alternatives, including countable alternatives.
  • If an instance has a solution with finitely many positive coalitions and real compositions, it has such a solution with rational compositions.
  • A uniform search procedure therefore constructs a solution whenever a finite solution exists.

The remaining unresolved question is effective construction for arbitrary affirmative instances. In particular, the argument below does not establish that every affirmative instance has a finite solution.

1. Conventions

Write $S_t$ for the input key of the singleton option of type $t$. Its coalition key is
$$ K_t(x)=A_tx+b_t. $$
Each comparison is lexicographic. Different types may have different key lengths, all at most $m$.

An internally stable coalition must first be individually rational:
$$ K_t(x)\succeq_{\mathrm{lex}}S_t \qquad\text{whenever }x_t>0. $$

All statements about individuals and assignments are understood up to null sets. A positive amount of a type assigned to a worse option violates almost-everywhere weak improvement.

2. Existence fails with one supported type

Take $\tau=1$ and $\mu_1=1$. Give positive coalitions the scalar key
$$ K_1(x)=-x,\qquad 0<x\le1, $$
and give the singleton option key $S_1=-2$.

These keys distinguish all options, and every positive coalition is preferred to living alone. Nevertheless, every positive coalition $x$ is internally blocked by its subcoalition $y=x/2$, because
$$ 0<y<x,\qquad K_1(y)=-x/2>-x=K_1(x). $$

Thus the only internally stable partition is the all-singleton partition. The grand coalition Pareto dominates that partition, since
$$ K_1(1)=-1>-2=S_1. $$

Consequently, not every instance admits an internally stable, Pareto-optimal admissible partition.

3. Deciding existence is $\mathrm{NP}$-hard

We give a polynomial-time reduction from Clique. The source problem asks whether a finite simple graph $G$ has a clique of cardinality at least $k$. Its $\mathrm{NP}$-completeness is a standard consequence of [Karp’s theorem](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

We may restrict to $2\le k\le n$, where the vertices are $1,\ldots,n$: excluded cases are immediately decidable and can be replaced by fixed affirmative or negative instances satisfying this restriction.

3.1 The society and its preferences

Introduce types $0,1,\ldots,n$, where type $0$ is auxiliary. Set
$$ h=\lceil\log_2(n+1)\rceil,\qquad c=2^{-h},\qquad \beta=1-nc. $$
Each vertex type has mass $c$, and type $0$ has mass $\beta$. Since $2^h>n$, all masses are positive dyadic rationals, and they sum to $1$.

For a composition $x$, define
$$ V(x)=\sum_{j=1}^n x_j, $$
$$ E_i(x)= \sum_{\substack{1\le j\le n\\j\ne i,\ \{i,j\}\notin E(G)}}x_j, $$
and
$$ F(x)=(x_0,x_1,\ldots,x_n). $$
Finally, put
$$ \theta=(k-\tfrac12)c. $$

The keys, with displayed blocks concatenated, are
$$ K_i(x)=(-E_i(x),\,V(x),\,x_0,\,F(x)), \qquad S_i=(0,\,\theta,\,0,\,\mathbf0_\tau) $$
for vertex type $i$, and
$$ K_0(x)=(V(x),\,-x_0,\,0,\,F(x)), \qquad S_0=(0,\,-2\beta,\,0,\,\mathbf0_\tau). $$

Thus $\tau=n+1$ and $m=\tau+3$. All coalition-key coefficients belong to $\{-1,0,1\}$.

The final block $F(x)$ distinguishes distinct compositions. Equality with a singleton key would require $F(x)=\mathbf0_\tau$, hence $x=0$, which is outside the relevant domain. Therefore every strictness promise in the task is satisfied.

3.2 A necessary condition for individual rationality

Lemma. The vertex support of an individually rational positive coalition containing vertex mass is a clique of cardinality at least $k$.

Proof. If $x_i>0$, individual rationality for type $i$ requires $E_i(x)=0$: otherwise its first coalition-key coordinate is negative, whereas its singleton coordinate is zero.

Applying this to every present vertex type excludes all incompatible pairs, since the summands defining $E_i$ are nonnegative. Therefore
$$ C(x)=\{j\in\{1,\ldots,n\}:x_j>0\} $$
is a clique.

If $|C(x)|\le k-1$, then
$$ V(x)\le(k-1)c<\theta. $$
With first key coordinates equal to zero, this makes the coalition worse than the singleton option in the second coordinate. Hence $|C(x)|\ge k$. $\square$

The lemma applies to arbitrary real compositions; it does not assume indivisible type masses.

3.3 Negative graph instances

Suppose $G$ has no clique of cardinality at least $k$.

The lemma excludes every coalition containing vertex mass from an internally stable partition. Any remaining positive coalition contains only auxiliary mass. If its mass is $a>0$, the auxiliary-only subcoalition of mass $a/2$ strictly improves the second key coordinate:
$$ -a/2>-a. $$
Hence that coalition is internally blocked.

Only the all-singleton partition is internally stable. It is Pareto dominated by placing all auxiliary individuals together and leaving the vertex individuals alone, because
$$ -\beta>-2\beta. $$

Thus the constructed society has no required partition.

3.4 Construction for affirmative graph instances

Suppose $G$ has a clique of cardinality at least $k$.

On the remaining vertices, repeatedly choose a maximum-cardinality clique, breaking ties by the lexicographically largest incidence vector in the fixed vertex order. Remove its vertices and continue, stopping when the remaining maximum clique has cardinality below $k$.

Let the selected cliques be $C_1,\ldots,C_r$, with $q_a=|C_a|$. The hypothesis ensures $r\ge1$. Define
$$ x_i^{(a)}=c\,\mathbf1_{\{i\in C_a\}} \qquad(1\le i\le n), $$
and
$$ x_0^{(a)}=\beta\,\mathbf1_{\{a=1\}}. $$
All unselected vertex types live alone.

The cliques are disjoint, so the compositions satisfy the resource bounds.

For a vertex type in $C_a$,
$$ E_i(x^{(a)})=0,\qquad V(x^{(a)})=q_ac\ge kc>\theta. $$
It strictly prefers its coalition to being alone. Auxiliary individuals strictly prefer the first coalition because its first key coordinate is positive.

To prove internal stability, take a proper positive subcomposition $y\le x^{(a)}$.

If $y$ contains vertex mass and $V(y)<V(x^{(a)})$, every retained vertex type prefers the original coalition in the second coordinate.

If $y$ contains vertex mass and $V(y)=V(x^{(a)})$, coordinatewise domination forces every vertex coordinate to remain unchanged. Properness then means auxiliary mass was removed from the first coalition. Its retained vertex types prefer the original coalition in the third coordinate.

If $y$ contains only auxiliary mass, its first auxiliary-key coordinate is zero, below that of the first coalition.

Thus no proper positive subcomposition is unanimously preferred.

3.5 Pareto optimality against countable alternatives

Let $Q$ be an admissible partition weakly improving almost everyone.

Every vertex individual’s original first key coordinate is zero, including those originally alone. Therefore any coalition $z$ of $Q$ containing vertex type $i$ must satisfy $E_i(z)=0$. Its vertex support is consequently a clique.

We prove inductively that $Q$ contains each composition $x^{(a)}$.

Assume earlier compositions have already been forced. Their constituent type masses are exhausted, so every other coalition uses only remaining vertex types. For $a>1$, auxiliary mass is also exhausted.

Choose $i\in C_a$. Since its original coalition strictly beats its singleton option, this type cannot remain alone on positive mass in $Q$. Countability therefore supplies a coalition $z$ with $z_i>0$.

Weak improvement for this type requires
$$ V(z)\ge q_ac. $$
Its vertex support $D$ is a clique in the remaining graph. Maximal cardinality of $C_a$, together with the coordinate mass bounds, gives
$$ q_ac\le V(z)\le |D|c\le q_ac. $$
Equality follows throughout. Hence $|D|=q_a$ and $z_j=c$ for every $j\in D$.

For $a=1$, the third key coordinate additionally requires $z_0\ge\beta$, so $z_0=\beta$. For later $a$, already-forced resource exhaustion gives $z_0=0$.

The first three vertex-key coordinates now agree with those of $x^{(a)}$. Weak improvement requires
$$ F(z)\succeq_{\mathrm{lex}}F(x^{(a)}). $$
The prescribed tie-break among maximum cliques gives the reverse inequality. Thus $z=x^{(a)}$, establishing the induction.

After these compositions are forced, only unselected vertex types remain. They originally live alone, and their induced graph has no clique of cardinality at least $k$. Any positive coalition containing them would need to be individually rational, contrary to the lemma.

Therefore almost everyone retains the same option, and no positive-mass set strictly improves. The constructed partition is Pareto optimal.

3.6 Complexity of the reduction

We have proved
$$ G\text{ has a clique of cardinality at least }k \quad\Longleftrightarrow\quad \text{the constructed society has a required partition}. $$

A dense encoding has
$$ \tau=n+1,\qquad m=n+4,\qquad L=O(n^3+n\log n). $$
The reduction is polynomial-time. Hence deciding existence is $\mathrm{NP}$-hard, even for the restricted coefficients and dyadic masses above. A polynomial-time decision algorithm would imply $\mathrm P=\mathrm{NP}$. No membership in $\mathrm{NP}$ is asserted.

For affirmative instances of this family, exhaustive clique enumeration constructs the partition in
$$ 2^{O(\tau)}\operatorname{poly}(m,\tau,L) $$
time. It outputs at most $\lfloor n/k\rfloor$ positive compositions, with exact dyadic coordinates of $O(\log\tau)$ bits.

4. Local internal-stability verification

Let $x$ be a rational positive composition, and let $B$ be its bit length.

After checking individual rationality, enumerate every nonempty prospective blocker support
$$ R\subseteq\operatorname{supp}(x) $$
and, for each $t\in R$, the first key coordinate in which $K_t(y)$ exceeds $K_t(x)$.

Each choice is a rational linear system comprising
$$ 0\le y\le x,\qquad y_t>0\ (t\in R),\qquad y_t=0\ (t\notin R), $$
equalities in earlier key coordinates, and strict improvement in the selected coordinate. These strict comparisons imply $y\ne x$.

Strict feasibility is decidable by introducing $0\le\delta\le1$, replacing each strict inequality by a margin of at least $\delta$, and maximizing $\delta$. The original system is feasible exactly when the resulting linear program has positive optimum: finitely many strict margins have a positive common minimum.

There are at most
$$ (m+1)^\tau-1 $$
systems. Standard polynomial-time rational linear programming therefore gives the bound
$$ (m+1)^\tau\operatorname{poly}(m,\tau,L+B) $$
for internal-stability verification.

5. A finite-witness theorem for Pareto improvements

The next result concerns a finite baseline partition, whose compositions may initially be real.

Theorem. If a partition with finitely many positive coalitions is Pareto dominated by an admissible partition, it is dominated by a partition with finitely many positive coalitions.

An explicit bound makes this theorem algorithmic for rational baselines.

5.1 Recording individuals’ original assignments

Let the baseline positive compositions be $x^{(1)},\ldots,x^{(N)}$. Use source labels $g=0,\ldots,N$, where $g=0$ denotes original singleton assignment.

For each type-source pair, define its available mass by
$$ \alpha_{tg}=x_t^{(g)}\quad(g\ge1), \qquad \alpha_{t0}=\mu_t-\sum_{g=1}^N x_t^{(g)}. $$
Its original key is
$$ u_{tg}=K_t(x^{(g)})\quad(g\ge1), \qquad u_{t0}=S_t. $$
If $\alpha_{tg}=0$, the value of $u_{tg}$ will never affect an actual comparison; evaluating the affine expression there is harmless.

An alternative positive coalition can be described by allocation coordinates $p_{tg}\ge0$: the amount of type $t$ drawn from original source $g$. Its composition is
$$ z_t=\sum_{g=0}^N p_{tg}. $$
Weak improvement requires
$$ p_{tg}>0 \quad\Longrightarrow\quad K_t(z)\succeq_{\mathrm{lex}}u_{tg}. $$

There are
$$ d=\tau(N+1) $$
allocation coordinates. Their sum is the coalition’s mass.

Conversely, allocations satisfying the resource equations can be realized measurably by splitting each original type-source set. Atomlessness permits these splits.

5.2 Finitely many comparison cells

For each type-source pair, record one of the following states:

  • its allocation coordinate is zero;
  • its allocation coordinate is positive and its new key equals its original key;
  • its allocation coordinate is positive and the first strictly improving key coordinate is a specified coordinate.

There are at most
$$ C=(m+2)^d $$
joint states, called comparison cells.

Each cell is specified by linear equalities and strict inequalities. For example, improvement first occurring in coordinate $\ell$ requires
$$ (A_tz)_j=c_{tgj}\quad(j<\ell), \qquad (A_tz)_\ell>c_{tg\ell}, $$
where
$$ c_{tgj}=(u_{tg})_j-(b_t)_j. $$
Equality of keys requires these equalities in every coordinate.

Define
$$ H=\max\left(1,\max_{t,j,i}|(A_t)_{ji}|\right). $$
Let $\eta$ be the minimum absolute value of the nonzero constants $c_{tgj}$. If all these constants vanish, set $\eta=1$. Put
$$ \rho=\min\left(1,\frac{\eta}{2H}\right). $$

For every allocation vector $p$,
$$ |(A_tz)_j|\le H\|p\|_1. $$

5.3 Merging small coalitions within a cell

Consider finitely or countably many coalitions in the same comparison cell, with allocation vectors $p^{(a)}$, such that
$$ \left\|\sum_a p^{(a)}\right\|_1\le\rho. $$
Their combined allocation belongs to that same cell.

Indeed, every constituent has mass at most $\rho$.

An equality $(A_tz)_j=c_{tgj}$ can hold for such a constituent only if $c_{tgj}=0$: otherwise
$$ |c_{tgj}|\ge\eta>H\rho. $$
Zero-right-hand-side equalities are preserved under summation.

A strict inequality $(A_tz)_j>c_{tgj}$ cannot have a positive right-hand side. If its right-hand side is zero, summing preserves strict positivity. If its right-hand side is negative, the combined allocation satisfies it because
$$ (A_tz)_j\ge-H\rho\ge-\eta/2>c_{tgj}. $$

Coordinate zeros and strict coordinate positivity are also preserved. Countable sums cause no convergence difficulty: the total mass is finite, so every relevant linear expression is absolutely summable.

Thus combining these coalitions preserves, for every allocated type-source pair, whether its assignment is equal to or strictly better than its baseline assignment.

5.4 The bound on the number of coalitions

Retain every alternative coalition of mass greater than $\rho/2$.

For each comparison cell, group its remaining coalitions, each of mass at most $\rho/2$, into batches with total mass between $\rho/2$ and $\rho$, except for at most one final batch of mass below $\rho/2$. Such batching is possible by accumulating terms until the threshold is reached; if a remaining infinite tail never reaches it, take that entire tail as the final batch.

Combine every batch. Section 5.3 justifies each combination.

The retained large coalitions and completed batches each have mass at least $\rho/2$, so together there are at most $\lceil2/\rho\rceil$ of them. There is at most one final batch per comparison cell. Hence the resulting alternative has at most
$$ M=\left\lceil\frac2\rho\right\rceil+C $$
positive coalitions.

The original source totals are preserved. Alternative singleton assignments can be kept unchanged. Strict-improvement status is preserved on all allocated mass, so the result remains a Pareto improvement. This proves the theorem.

6. Deciding Pareto optimality of a finite rational partition

Suppose the baseline partition is rational and its total description length is $B$. Then all quantities in Section 5 are computable rationals or integers.

Use $M$ potential alternative coalition slots. For each slot, choose either a comparison cell or an unused-slot state. Introduce its allocation variables $p_{tg}^{(a)}$, together with singleton-assignment variables $w_{tg}$.

Impose resource conservation:
$$ \sum_{a=1}^M p_{tg}^{(a)}+w_{tg}=\alpha_{tg} \qquad\text{for every }t,g. $$
All variables are nonnegative. For an unused slot, all its allocation variables vanish. Other slots satisfy their selected cell conditions.

A singleton allocation is forbidden when $S_t$ is worse than $u_{tg}$. Finally, require
$$ \sum_{\substack{a,t,g\\ \text{selected cell specifies strict improvement}}} p_{tg}^{(a)} + \sum_{\substack{t,g\\S_t\succ_{\mathrm{lex}}u_{tg}}} w_{tg} >0. $$
This is exactly the requirement that a positive mass strictly improves.

For every choice of states, these are rational linear conditions. The common-slack procedure from Section 4 decides strict feasibility. A feasible system produces a rational finite Pareto improvement.

Conversely, Section 5 ensures that every countable Pareto improvement is represented by some choice of at most $M$ slots. Thus failure of every system proves Pareto optimality against all admissible alternatives.

A direct running-time bound is
$$ (C+1)^M \operatorname{poly}(M,d,m,\tau,L+B), $$
where
$$ d=\tau(N+1),\qquad C=(m+2)^d,\qquad M=\left\lceil\frac2\rho\right\rceil+C. $$

The bit lengths of $H$, $\eta$, and $\rho$ are polynomial in $m,\tau,L+B$, and $N$ is bounded by the candidate description length. Consequently, a looser bound is
$$ 2^{\,2^{\operatorname{poly}(m,\tau,L+B)}}. $$

Together with Section 4, this gives a decision procedure for whether a specified finite rational partition has both required properties.

7. Finite real solutions can be rationalized

Theorem. If an instance admits an internally stable, Pareto-optimal partition with finitely many positive coalitions, it admits one with finitely many positive coalitions and rational compositions.

7.1 An elementary fact about rational linear formulas

A first-order formula over the reals whose atomic predicates are rational affine equalities or inequalities admits effective quantifier elimination into a finite Boolean combination of predicates of the same kind.

For completeness, existential elimination can be performed after writing the formula in disjunctive normal form. In each conjunction, eliminate a variable using an equality when available. Otherwise pair its lower and upper bounds, using Fourier–Motzkin elimination. A resulting bound is strict when either participating bound is strict. One-sided bounds impose no further condition. Universal quantifiers are eliminated using negation.

Moreover, a nonempty set defined by a quantifier-free rational linear formula contains a rational point.

To verify the last assertion, take a satisfied conjunction and a real witness. Add as equalities all weak inequalities active at that witness. The resulting consistent rational equality system has a rational affine parametrization, so rational points are dense in its solution space. A sufficiently close rational point preserves all strict inequalities and all inactive weak inequalities.

7.2 Uniform compression bounds on gap-separated sets

Fix a number $N$ of positive coalitions and regard their compositions as variables.

The comparison constants from Section 5 are affine rational expressions:
$$ c_{tgj}=(A_tx^{(g)})_j\quad(g\ge1), \qquad c_{t0j}=(S_t)_j-(b_t)_j. $$

For an integer $q\ge0$, put $\delta_q=2^{-q}$ and impose, for every such expression, the condition
$$ c_{tgj}=0 \quad\text{or}\quad c_{tgj}\ge\delta_q \quad\text{or}\quad c_{tgj}\le-\delta_q. $$
Call this the gap-separation condition.

On this set, Section 5 applies uniformly with
$$ \rho_q=\min\left(1,\frac{\delta_q}{2H}\right), \qquad M_q=\left\lceil\frac2{\rho_q}\right\rceil+(m+2)^{\tau(N+1)}. $$
Every countable Pareto improvement therefore has a witness using at most $M_q$ positive coalitions.

7.3 The required properties are rational linear formulas

For fixed $N,q$, all the following conditions are expressible in first-order rational linear arithmetic:

  • Each proposed coalition has nonnegative composition and positive total mass, and their coordinatewise sum is at most $\mu$.
  • Every coalition is individually rational.
  • No coalition has an internal blocker.
  • The gap-separation condition holds.
  • There is no Pareto improvement with at most $M_q$ positive coalitions.

For condition 3, quantify over a subcomposition $y$, impose $0\le y\le x$, and express lexicographic strict improvement by a finite disjunction of first-improving-coordinate conditions.

For condition 5, use the source-allocation variables of Section 6. The original keys are now affine expressions in the candidate compositions. Comparisons between original and alternative keys remain affine linear; no multiplication of variables is needed. Singleton allocations and positive-mass strict improvement are likewise expressible using finite Boolean combinations of linear predicates.

By the uniform compression bound, condition 5 excludes countable improvements as well.

Now let a finite real solution be given. There are finitely many comparison constants, so some $q$ separates every nonzero constant from zero. Its compositions satisfy the formula just described.

That formula therefore defines a nonempty set. Section 7.1 supplies a rational point in the same set. Its compositions form an internally stable, Pareto-optimal finite rational partition, proving the theorem.

8. Effective construction within the finite-solution case

Enumerate all finite rational composition lists by increasing description length. Reject lists violating the resource or positivity conditions. For each remaining list, apply the internal-stability and Pareto-optimality procedures above. Return the first accepted list.

This is a uniform algorithm with the following precise guarantee:

It terminates whenever the instance admits a solution with finitely many positive coalitions, even if the initially known finite solution has irrational coordinates.

The guarantee follows from Section 7. Every returned partition satisfies both required properties.

If a rational solution has description length at most $B$, enumerating all descriptions through that length and verifying them takes, with a sufficiently generous polynomial,
$$ 2^{\,2^{\operatorname{poly}(m,\tau,L+B)}} $$
time. No bound on the necessary $B$ in terms of $m,\tau,L$ alone is established here.

The returned rational list is an effective representation of the required form. A finite program can store it, return each coordinate exactly, and realize the coalitions by consecutive intervals within each type. For a coordinate index and rational accuracy request $\varepsilon>0$, returning the stored rational value takes time polynomial in the stored description, the index encoding, and $\operatorname{bit}(\varepsilon)$; the error is zero.

9. What remains unresolved

The universal-existence question is answered negatively, and the existence decision problem is $\mathrm{NP}$-hard.

The new finite-witness and rationalization results substantially narrow the construction issue. They do not resolve it for arbitrary affirmative instances. Neither of the following has been proved:

  • Every instance admitting a required countable partition also admits a required finite partition.
  • Instances requiring infinitely many positive coalitions, if such instances exist, always admit a partition with the stipulated effective representation and a uniform construction algorithm.

Thus the general effective-construction part remains open in this write-up.
