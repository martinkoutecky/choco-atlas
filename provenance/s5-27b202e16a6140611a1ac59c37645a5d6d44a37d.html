The continuous mirror question, as graded

Given \(n\) objects, an unknown normalized BTL weight vector \(\tilde\pi\), a comparison graph and passive query protocol, and a society measure \(\mu\) over complete response types with Byzantine mass \(\beta\), observe the paper’s finite, unlabeled query panel sampled from that society. For \(\beta\ge1/2\), can any estimator, uniformly over \(\tilde\pi\) and allowed Byzantine strategies, output \(\pi^*\) with \(\|\pi^*-\tilde\pi\|_2/\|\tilde\pi\|_2\le f(n)\) with probability greater than \(1/2\), for some \(f(n)\to0\)?

Packaged proof task (what the prover saw — nothing else)

There are \(m=n\ge2\) objects and an unknown vector \(\tilde\pi\in\mathbb Q_{>0}^{n}\) with \(\sum_i\tilde\pi_i=1\). A complete response table specifies a binary winner for every unordered pair; it need not be a transitive ranking, and repeated queries to one voter return the same answer.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Masses sum to \(1\); \(\tau\) is the support size, not the number of possible types. A type consists of a response table and a hidden honest/Byzantine status. Byzantine mass is a known rational \(\beta\in[1/2,1]\). Conditional on honesty, distinct table entries are independent BTL responses with parameter \(\tilde\pi\).
Sample \(K\ge1\) voter slots independently from the society. Draw an independent Erdős–Rényi comparison graph \(G(n,p)\), with rational \(0<p\le1\). A passive protocol fixes all pair-to-slot assignments before seeing responses, using at most \(k\ge1\) comparisons per edge; it may reuse slots across pairs.
Byzantine voters may jointly replace their sampled tables before returning responses, knowing \(\tilde\pi\), the graph, protocol, estimator, and all queried honest responses; their returned answers must still be consistent on repeated pairs. The estimator sees the graph, assignments, and replies grouped by slot, but neither statuses nor the society’s support or masses. Any claimed running time is stated in \(m,\tau,L,K,k\), where \(L\) is the encoded instance’s bit length.

For each fixed rational \(\beta\in[1/2,1]\), can any randomized estimator and passive protocol, with arbitrarily large finite panel and query budgets, uniformly over all admissible societies, \(\tilde\pi\), and Byzantine strategies, output a probability vector \(\pi^*\) satisfying \(\Pr[\|\pi^*-\tilde\pi\|_2/\|\tilde\pi\|_2\le f(n)]>1/2\) for some nonnegative \(f(n)\to0\), or is such estimation impossible? Probability includes society sampling, graph generation, and all strategy and algorithm randomness.

For a finite population with at least half its voters Byzantine, uniformly vanishing relative Euclidean error with success probability exceeding \(1/2\) is impossible, even without a computational restriction. [Datar, Rajkumar, and Augustine](https://arxiv.org/pdf/2211.07902). No result for exactly the rational-support, independently sampled society model above was located in the search.

Result

Estimation is impossible for every fixed rational \(\beta\in[1/2,1]\), without any computational restriction.

More precisely, for every \(n\ge2\), every finite choice of panel and query budgets, every allowed protocol and estimator, and every \(0\le\varepsilon<1/\sqrt7\), there is an admissible society and Byzantine strategy for which

\(\displaystyle \Pr\!\left[\frac{\|\pi^*-\tilde\pi\|_2}{\|\tilde\pi\|_2}\le\varepsilon\right]\le\frac12.\)

The construction uses parameters whose largest-to-smallest coordinate ratio is at most \(3\).

The finite-population analogue appears in Theorem 9 of [Datar, Rajkumar, and Augustine](https://arxiv.org/pdf/2211.07902). The proof below directly addresses the rational-support, independently sampled model.

1. Honest complete-table distributions

Let \(N=\binom n2\), and let \(\mathcal T=\{0,1\}^{N}\) be the set of complete response tables. For \(i<j\), interpret \(x_{ij}=1\) as object \(i\) winning.

For any positive rational probability vector \(a\), define the probability distribution

\(\displaystyle P_a(x)=\prod_{i<j}\left(\frac{a_i}{a_i+a_j}\right)^{x_{ij}}\left(\frac{a_j}{a_i+a_j}\right)^{1-x_{ij}},\qquad x\in\mathcal T.\)

Every value \(P_a(x)\) is positive and rational. Summing over all binary entries gives

\(\displaystyle \sum_{x\in\mathcal T}P_a(x)=\prod_{i<j}\left(\frac{a_i}{a_i+a_j}+\frac{a_j}{a_i+a_j}\right)=1.\)

Thus \(P_a\) is exactly the required honest table distribution: distinct entries are independent BTL responses. Sampling a table once and retaining it also ensures consistency on repeated queries.

2. Two admissible societies with the same returned-table law

Fix two positive rational probability vectors \(u,v\), to be specified below. Write

\(\displaystyle \alpha=1-\beta,\qquad \gamma=2\beta-1.\)

Both coefficients are nonnegative, and \(\alpha+\gamma=\beta\). Let \(R\) be the uniform distribution on \(\mathcal T\), so \(R(x)=2^{-N}\).

Define society \(S_u\), with true parameter \(u\), by assigning these masses to its types:

  • Honest type with table \(x\): mass \(\alpha P_u(x)\).
  • Byzantine type with table \(x\): mass \(\alpha P_v(x)+\gamma R(x)\).

Define society \(S_v\), with true parameter \(v\), by exchanging \(u\) and \(v\):

  • Honest type with table \(x\): mass \(\alpha P_v(x)\).
  • Byzantine type with table \(x\): mass \(\alpha P_u(x)+\gamma R(x)\).

Only positive-mass types are included in each support.

All masses are rational and have finite binary encodings. In either society, honest mass is \(\alpha\), Byzantine mass is \(\alpha+\gamma=\beta\), and total mass is \(2\alpha+\gamma=1\). When \(\beta<1\), conditioning on honesty gives exactly \(P_u\) or \(P_v\), respectively, so the honest independence hypothesis holds.

For \(\beta<1\), both societies have support size \(\tau=2^{N+1}\). For \(\beta=1\), honest types are absent and both societies consist of the \(2^N\) Byzantine table types with masses \(R(x)\). At this endpoint there are no honest responses to constrain.

In both societies, choose the deterministic Byzantine strategy that keeps every sampled table unchanged. This is an allowed strategy and respects repeated-pair consistency.

The returned complete table of a sampled slot then has the same distribution in both worlds:

\(\displaystyle Q(x)=\alpha P_u(x)+\alpha P_v(x)+\gamma R(x).\)

This equality also covers the boundary \(\beta=1/2\), where \(\gamma=0\).

3. Exact indistinguishability after independent sampling

Because slots are sampled independently and no sampled table is changed, the returned complete tables \(X_1,\ldots,X_K\) have joint distribution \(Q^{\otimes K}\) in both worlds.

Consequently, even an observer given all complete returned tables, grouped by slot, would receive identically distributed data. The estimator’s actual observations contain only queried entries of these tables.

For completeness, fix a realization of the graph and the protocol’s random choices. The passive assignments are then fixed before responses. Replies, including all repeated queries, are a deterministic function of the assignments and \(X_1,\ldots,X_K\). Since these tables have the same joint law in both worlds, the replies have the same conditional law. Averaging over the graph and protocol randomness preserves equality. Applying the same randomized estimator therefore produces the same output law; denote it by \(\mu\).

This argument holds for every allowed \(p,K,k\). It does not condition on the realized panel containing a Byzantine majority. In particular, random fluctuations in the number of sampled Byzantine slots do not distinguish the worlds.

4. Rational parameters with separated error balls

Set \(h=\lfloor n/2\rfloor\) and \(s=n-2h\in\{0,1\}\). Partition the objects into two blocks of size \(h\), with one remaining object when \(s=1\).

Define \(u\) by assigning:

  • \(3/(2n)\) to every object in the first block;
  • \(1/(2n)\) to every object in the second block;
  • \(1/n\) to the remaining object, if present.

Define \(v\) by exchanging the weights of the two blocks and keeping the remaining weight unchanged.

Both vectors are strictly positive and rational. Their coordinate sums equal

\(\displaystyle h\frac{3}{2n}+h\frac{1}{2n}+\frac{s}{n}=\frac{2h+s}{n}=1.\)

Their squared norms and squared distance are

\(\displaystyle \|u\|_2^2=\|v\|_2^2=\frac{10h+4s}{4n^2},\qquad \|u-v\|_2^2=\frac{2h}{n^2}.\)

Indeed, each of the \(2h\) block coordinates changes by \(1/n\), and any remaining coordinate does not change. Hence

\(\displaystyle \frac{\|u-v\|_2}{\|u\|_2+\|v\|_2}=\sqrt{\frac{h}{5h+2s}}\ge\frac1{\sqrt7}.\)

The last inequality follows from \(h\ge1\) and \(s\le1\), which imply \(5h+2s\le7h\).

For \(0\le\varepsilon<1/\sqrt7\), define the two success sets within the probability simplex:

\(\displaystyle A_u=\{z:\|z-u\|_2\le\varepsilon\|u\|_2\},\qquad A_v=\{z:\|z-v\|_2\le\varepsilon\|v\|_2\}.\)

They are disjoint. Otherwise, a point \(z\) in their intersection would give, by the triangle inequality,

\(\displaystyle \|u-v\|_2\le\|u-z\|_2+\|z-v\|_2\le\varepsilon(\|u\|_2+\|v\|_2)<\|u-v\|_2,\)

a contradiction.

Since the output law is \(\mu\) in both worlds,

\(\displaystyle \Pr_{S_u}[\pi^*\in A_u]+\Pr_{S_v}[\pi^*\in A_v]=\mu(A_u)+\mu(A_v)\le1.\)

Thus at least one world has success probability at most \(1/2\). This proves the stated constant-error impossibility.

5. Consequence for vanishing relative error

Let \(f(n)\ge0\) tend to zero. For every sufficiently large \(n\), one has \(f(n)<1/\sqrt7\). Applying the preceding construction with \(\varepsilon=f(n)\) gives an admissible society and an allowed Byzantine strategy whose success probability is at most \(1/2\).

Therefore no estimator and passive protocol can achieve the requested uniform guarantee, regardless of finite panel size, query budget, or running time.
