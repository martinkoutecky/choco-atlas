The continuous mirror question, as graded

Given a finite set of chore templates \(E\), complete cost types \(T\) with rational masses \(\mu_t\) summing to \(1\), rational per-capita supplies \(q_e\), and costs \(v_t(B)\) for each integral bundle \(B\subseteq E\), define \(M_t^\infty\) as the least \(b\) for which there is a distribution \(y_{t,B}\) over bundles with \(\sum_B y_{t,B}=1\), \(\sum_{B:e\in B}y_{t,B}=q_e\), and positive mass only on bundles with \(v_t(B)\le b\). Find the minimum \(\alpha\) and mass allocation \(x_{t,B}\) satisfying \(\sum_Bx_{t,B}=\mu_t\), \(\sum_{t,B:e\in B}x_{t,B}=q_e\), and positive mass only where \(v_t(B)\le\alpha M_t^\infty\); each unit of mass receives an integral bundle.

Packaged proof task (what the prover saw — nothing else)

Let \(E\) be a set of \(m\ge2\) chore templates with binary-rational supplies \(0<q_e\le1\). A society is given by its support: the list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type has an explicitly listed complete table \(v_t:2^E\to\mathbb Q_{\ge0}\) of normalized, monotone, subadditive costs, with \(v_t(\varnothing)=0\). Let \(L\) be the total binary input length, including these tables.
For each \(t\), define \(M_t^\infty\) as the least \(b\ge0\) admitting nonnegative masses \(y_{t,B}\) with \(\sum_{B\subseteq E}y_{t,B}=1\), \(\sum_{B\ni e}y_{t,B}=q_e\) for every \(e\), and \(y_{t,B}>0\) only if \(v_t(B)\le b\).
An allocation consists of nonnegative masses \(x_{t,B}\) satisfying \(\sum_{B\subseteq E}x_{t,B}=\mu_t\) and \(\sum_{t\in T}\sum_{B\ni e}x_{t,B}=q_e\). Each individual receives an integral bundle \(B\subseteq E\), while type masses may split among bundles.
It is \(\alpha\)-MMS fair, for \(\alpha\ge1\), if \(x_{t,B}>0\) implies \(v_t(B)\le\alpha M_t^\infty\); this inequality also applies when \(M_t^\infty=0\).

What is the sharp universally guaranteed multiplicative MMS factor for these societies, as a function of \(m\), \(\tau\), and \(q\), and can allocations attaining that guarantee be computed in time polynomial in \(m\), \(\tau\), and \(L\)?

For discrete societies with \(n\) agents and subadditive costs, a \(\min\{n,\lceil\log_2 m\rceil\}\)-MMS allocation always exists; the construction uses MMS-defining partitions and does not establish polynomial-time computation ([Li–Wang–Zhou](https://papers.nips.cc/paper_files/paper/2023/file/aa5d22c77b380e2261332bb641b3c2e3-Paper-Conference.pdf)).
No result settling this exact continuous formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Restored the anchor's normalized, monotone, nonnegative, subadditive cost domain; costs are binary rationals supplied as complete explicit bundle tables.
  • Restricted supplies to positive values at most one, since bundles contain at most one copy of each template; omitted zero-supply templates.
  • Restricted to at least two templates because the displayed logarithmic discrete guarantee gives an invalid zero factor for one template; the published version retains this boundary slip.
  • Restricted multiplicative fairness factors to at least one, following the discrete approximation convention, and retained zero benchmarks through the undivided fairness inequality.
  • Used the supply vector directly rather than inventing a finite-agent parameter absent from the continuous formulation.
  • Interpreted the target as the sharp guaranteed approximation to MMS and its computation, rather than exact instancewise minimization, because the anchor is an approximation existence result.

Result

The sharp universally guaranteed factor is \(\alpha^\star(m,\tau,q)=1\) for every admissible \(m,\tau,q\). An allocation attaining it can be computed exactly in time polynomial in \(m,\tau,L\).

The decisive feature is that every type’s benchmark distribution has the same marginal vector \(q\), and the allocation permits splitting each type’s mass.

1. The benchmark minimum is attained

Fix a type \(t\). Define a distribution on bundles by

\(p_B=\prod_{e\in B}q_e\prod_{e\notin B}(1-q_e)\).

Expanding the products gives \(\sum_{B\subseteq E}p_B=1\) and, for every \(e\in E\), \(\sum_{B\ni e}p_B=q_e\). Thus the benchmark constraints are feasible when every bundle is allowed.

Let \(C_t=\{v_t(B):B\subseteq E\}\), the finite set of table values. For any threshold \(b\), feasibility depends only on the allowed family \(\{B:v_t(B)\le b\}\). Since costs are nonnegative, every feasible threshold can be replaced by the largest member of \(C_t\) that does not exceed it, without changing this family. Consequently,

\(M_t^\infty=\min\{c\in C_t:\text{the benchmark constraints are feasible using only bundles of cost at most }c\}\).

The set on the right is nonempty because its largest candidate allows every bundle. Hence the minimum is attained. Choose a witnessing distribution \(y_{t,B}\) for each type.

2. Combining witnesses gives exact MMS fairness

Set \(x_{t,B}=\mu_t y_{t,B}\). These masses are nonnegative and satisfy each type’s mass constraint:

\(\sum_{B\subseteq E}x_{t,B}=\mu_t\sum_{B\subseteq E}y_{t,B}=\mu_t\).

For each template \(e\), they satisfy its supply constraint:

\(\sum_{t\in T}\sum_{B\ni e}x_{t,B}=\sum_{t\in T}\mu_t q_e=q_e\),

where the last equality uses \(\sum_{t\in T}\mu_t=1\).

Because \(\mu_t>0\), positive \(x_{t,B}\) implies positive \(y_{t,B}\), and therefore \(v_t(B)\le M_t^\infty\). This is precisely \(1\)-MMS fairness. It also handles \(M_t^\infty=0\) directly, without division.

Every assigned bundle remains integral; only the masses receiving different bundles are split. This existence argument requires neither monotonicity nor subadditivity.

3. Sharpness for every admissible parameter choice

Although the question restricts factors to \(\alpha\ge1\), the following construction also rules out any universal factor below \(1\).

Fix any admissible \(m,\tau,q\), and any positive type masses summing to \(1\). Choose distinct templates \(e_1,e_2\), index the types by \(t\in\{1,\ldots,\tau\}\), and put \(a_t=2^{-t}\). Define

\(v_t(B)=\max\bigl\{\mathbf 1_{\{e_1\in B\}},\,a_t\mathbf 1_{\{e_2\in B\}}\bigr\}\).

These tables have binary-rational entries, vanish on the empty bundle, and are monotone. They also satisfy \(v_t(E)=1\). For any bundles \(A,B\),

\(v_t(A\cup B)=\max\{v_t(A),v_t(B)\}\le v_t(A)+v_t(B)\),

so they are subadditive. The types are distinct because \(v_t(\{e_2\})=a_t\).

In any benchmark witness, the positive marginal \(q_{e_1}\) requires some positive-mass bundle containing \(e_1\). Every such bundle costs \(1\), so \(M_t^\infty\ge1\). All bundles cost at most \(1\), and unrestricted feasibility was proved above; hence \(M_t^\infty=1\) for every type.

Likewise, every allocation must assign positive mass to some bundle containing \(e_1\), because its total assigned mass is \(q_{e_1}>0\). That bundle costs \(1=M_t^\infty\) for its recipient type. It therefore violates the fairness inequality for every \(\alpha<1\). This proves sharpness.

4. Exact polynomial-time computation

For each type, sort its distinct table values. For a candidate threshold \(c\), write \(S_t(c)=\{B\subseteq E:v_t(B)\le c\}\) and solve the rational linear feasibility problem

\(\sum_{B\in S_t(c)}y_B=1,\qquad \sum_{\substack{B\in S_t(c)\\e\in B}}y_B=q_e\quad(e\in E),\qquad y_B\ge0\).

Feasibility is monotone in \(c\). Binary search therefore finds the first feasible table value, which Section 1 identifies as \(M_t^\infty\), using at most \(m+1\) feasibility calls per type. Solve at that threshold to obtain an exact rational witness.

The standard rational linear-programming theorem provides feasibility decisions and, when feasible, exact rational solutions in time polynomial in the system’s binary encoding length. See Khachiyan’s papers on [polynomial linear programming](https://www.mathnet.ru/eng/dan42319) and [exact solutions](https://www.mathnet.ru/eng/zvmmf5684). Here its hypotheses hold: the systems have rational right-hand sides, coefficients in \(\{0,1\}\), at most \(2^m\) variables, and \(m+1\) equalities.

Crucially, the explicit tables already contain \(\tau2^m\) entries, so \(\tau2^m\le L\). Each constructed system thus has encoding length polynomial in \(m,\tau,L\). Sorting, all linear-programming calls, and the final rational multiplications \(x_{t,B}=\mu_t y_{t,B}\) take polynomial time and produce a polynomial-length exact output.

The stated discrete result does not obstruct this construction: in the continuous formulation, each type can realize its entire benchmark distribution through splitting its mass.
