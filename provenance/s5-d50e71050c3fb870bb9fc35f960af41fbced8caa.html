The continuous mirror question, as graded

Given candidates \(C\), a target \(x\), a finite support \(T\) of complete rankings with positive rational masses \(\mu_t\) summing to \(1\), and a rational budget \(B\), decide whether there are nonnegative masses \(p_{t,d}\) summing to \(\mu_t\) for each \(t\), where \(d\) ranges from \(0\) to the number of candidates ranked above \(x\) in \(t\), such that the average number of upward adjacent swaps is at most \(B\) and \(x\) strictly beats every other candidate pairwise in the resulting society.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set, \(m=|C|\), and \(x\in C\). A society is given by its support: a list \(T\) of \(\tau\) distinct strict complete rankings, each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Thus \(\tau\) counts positive-mass types, not all possible rankings. The budget \(B\) is a positive binary rational; let \(L\) be the total input bit length.
For each \(t\), let \(h_t\) count candidates above \(x\), and let \(t^{(d)}\) be the ranking obtained by moving \(x\) upward through exactly \(d\) adjacent swaps, preserving the relative order of other candidates, for \(d\in\{0,\ldots,h_t\}\).
The decision problem asks whether real masses \(p_{t,d}\geq0\) exist with \(\sum_{d=0}^{h_t}p_{t,d}=\mu_t\), \(\sum_{t,d}d\,p_{t,d}\leq B\), and \(\sum_{t,d:\,x\text{ above }y\text{ in }t^{(d)}}p_{t,d}>\tfrac12\) for every \(y\in C\setminus\{x\}\). Pairwise ties do not qualify. Measure running times in \(m,\tau,L\).

Is this continuous decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? If it is \(\mathrm{NP}\)-hard, is it fixed-parameter tractable parameterized by \(\tau\)?

Discrete Dodgson Score is NP-hard; parameterized by the integer swap budget \(k\), it has no polynomial kernel unless \(\mathrm{PH}=\Sigma_3^p\), and parameterized by the number of votes it is \(\mathrm{W}[1]\)-hard. [Fellows et al.](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.FSTTCS.2010.459)
The fractional Dodgson Clone score is polynomial-time computable, but permits pairwise ties; that result concerns a different condition from the strict-majority feasibility required here. [McCabe-Dansted](https://comsoc-community.org/assets/proceedings/comsoc-2008/McCabe.pdf)

  • Allowed the unspecified allocation masses p_{t,d} to be real and nonnegative.

1. Result

The continuous decision problem belongs to \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\). Consequently, it is fixed-parameter tractable parameterized by \(\tau\). Strict majorities can be handled exactly; allowing ties is unnecessary.

If \(m=1\), the answer is immediately yes: set \(p_{t,0}=\mu_t\). Henceforth assume \(m\ge2\).

2. A linear program for the common majority margin

Let \(I=\{(t,d):t\in T,\ 0\le d\le h_t\}\) and \(N=|I|\). Because \(h_t\le m-1\), we have \(N\le m\tau\).

For each opponent \(y\ne x\), define \(a_{y,t,d}=1\) if \(t^{(d)}\) ranks \(x\) above \(y\), and \(a_{y,t,d}=0\) otherwise. Thus the mass preferring \(x\) to \(y\) is \(s_y(p)=\sum_{(t,d)\in I}a_{y,t,d}p_{t,d}\). All these coefficients can be constructed in \(O(\tau m^2)\) elementary operations from the listed rankings.

Introduce one real variable \(\varepsilon\). Consider the linear program maximizing \(\varepsilon\), subject to:

  • \(p_{t,d}\ge0\) for every \((t,d)\in I\);
  • \(\sum_{d=0}^{h_t}p_{t,d}=\mu_t\) for every \(t\in T\);
  • \(\sum_{(t,d)\in I}d\,p_{t,d}\le B\);
  • \(s_y(p)-\varepsilon\ge\tfrac12\) for every \(y\in C\setminus\{x\}\);
  • \(-\tfrac12\le\varepsilon\le\tfrac12\).

Write its feasible region as \(P\). It is nonempty: take \(p_{t,0}=\mu_t\), all other masses zero, and \(\varepsilon=-\tfrac12\). The cost is zero, and every majority constraint then requires only \(s_y(p)\ge0\).

Moreover, \(P\) is closed and bounded. Indeed, the mass constraints imply \(0\le p_{t,d}\le\mu_t\le1\), and \(\varepsilon\) is bounded explicitly. Therefore the maximum \(\varepsilon^\star\) exists.

Claim. The original instance is feasible if and only if \(\varepsilon^\star>0\).

Proof. Suppose \(p\) satisfies the original constraints. Since there are finitely many opponents and every majority is strict, the number \(\eta=\min_{y\ne x}(s_y(p)-\tfrac12)\) is positive. Total mass is one, so \(s_y(p)\le1\), giving \(\eta\le\tfrac12\). Consequently, \((p,\eta)\in P\), and \(\varepsilon^\star\ge\eta>0\).

Conversely, if \(\varepsilon^\star>0\), an optimal solution satisfies \(s_y(p)\ge\tfrac12+\varepsilon^\star>\tfrac12\) for every opponent, together with the original mass and budget constraints. This proves the claim.

3. Deciding positivity exactly

To make the treatment of strict inequalities explicit, we give a positive rational threshold of polynomial encoding length.

Put \(q=N+1\), the number of variables. Write each input rational as an integer numerator divided by a positive integer denominator, and let

\(D=2\,\operatorname{den}(B)\prod_{t\in T}\operatorname{den}(\mu_t)\).

Every right-hand side defining \(P\) has denominator dividing \(D\). Also, \(\log_2D\le L+1\).

All constraint coefficients are integers with absolute value at most \(m\): the budget coefficients are \(d\le m-1\), and the remaining coefficients belong to \(\{-1,0,1\}\).

A linear functional on a nonempty compact polytope attains its maximum at a vertex. Apply this fact to \(P\), and choose an optimal vertex \(v\). At a vertex, the active constraint normals span the ambient space: otherwise, a nonzero vector orthogonal to them would permit sufficiently small displacements in both directions while preserving all constraints, contradicting extremality. We can therefore select \(q\) independent active equations \(Av=b\), where \(A\) is an invertible integer matrix.

Since \(Db\) is integral, Cramer’s rule gives each coordinate of \(v\) as an integer divided by \(D\det A\). Expanding the determinant over its \(q!\) terms yields \(|\det A|\le q!m^q\). Hence, if the \(\varepsilon\)-coordinate is positive, it satisfies

\(\varepsilon^\star\ge\delta,\qquad \delta=\dfrac{1}{Dq!m^q}>0.\)

The encoding length of \(\delta\) is \(O(L+q\log q+q\log m)\), which is polynomial in \(m,\tau,L\).

It follows that the original instance is feasible exactly when the ordinary rational linear system defining \(P\), augmented by \(\varepsilon\ge\delta\), is feasible. One direction uses the bound just proved; the other uses \(\delta>0\) and the equivalence in Section 2. Thus no numerical tolerance or limiting argument is needed.

4. Polynomial running time and parameterization

The augmented system has \(N+1\le m\tau+1\) variables and \(O(N+\tau+m)\) constraints. Its coefficient matrix and right-hand sides have total binary encoding length polynomial in \(m,\tau,L\).

The polynomial-time rational linear-programming feasibility theorem decides whether a finite system of non-strict linear inequalities with rational coefficients has a real solution, in time polynomial in its binary encoding length. Equalities can be replaced by two inequalities, so the theorem applies directly here. See [Gács and Lovász, *Khachiyan’s linear programming algorithm*](https://www.sciencedirect.com/science/article/pii/0196677480900024).

This proves membership in \(\mathrm{P}\). Because the input explicitly lists the rankings, \(m\) and \(\tau\) are bounded by its encoding length, so the running time is also \(L^{O(1)}\). In particular, it meets the fixed-parameter bound \(f(\tau)L^{O(1)}\), even with \(f(\tau)=1\). An \(\mathrm{NP}\)-hardness classification under polynomial-time reductions would therefore imply \(\mathrm{P}=\mathrm{NP}\).

5. Why the tie distinction matters

For a concrete boundary example, take \(C=\{x,y\}\), one type of mass one ranking \(y\) above \(x\), and \(B=\tfrac12\). If \(u=p_{t,1}\), both the cost and the mass preferring \(x\) to \(y\) equal \(u\).

Allowing ties permits \(u=\tfrac12\). Strict victory requires \(u>\tfrac12\), contradicting the budget. The margin program correctly returns \(\varepsilon^\star=0\), hence rejects this instance. The distinction is real, but it does not change polynomial-time solvability.
