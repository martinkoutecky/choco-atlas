The continuous mirror question, as graded

Given finite agent types \(\Theta\), mass distribution \(\mu\), entitlements \(r_\theta\) with \(\sum_\theta \mu_\theta r_\theta=1\), type-dependent chore costs \(a_{\theta j}\), and per-capita supplies \(\sigma_j\) of \(q\) indivisible chore classes, choose a configuration measure \(p_{\theta,b}\) over \(b\in\mathbb{Z}_{\ge0}^q\) satisfying \(\sum_b p_{\theta,b}=1\) and \(\sum_{\theta,b}\mu_\theta p_{\theta,b}b_j=\sigma_j\), minimizing \(\alpha\) subject to \(A_\theta(b)-a_{\theta j}\le\alpha H_\theta\) for every supported \(b\) and every \(j\) with \(b_j>0\), where \(A_\theta(b)=\sum_j a_{\theta j}b_j\) and \(H_\theta=r_\theta\min_z\max_{z_{\theta',b}>0}A_\theta(b)/r_{\theta'}\) over configuration measures \(z\) matching \(\mu\) and \(\sigma\).

There are \(m=q\ge1\) indivisible chore classes, with positive binary-rational per-capita supplies \(\sigma_j\). Entitlements \(r_\theta>0\) and additive costs \(a_{\theta j}\ge0\) are binary rationals satisfying \(\sum_\theta\mu_\theta r_\theta=1\) and \(\sum_j\sigma_j a_{\theta j}=1\) for every type.
A configuration is \(b\in\mathbb Z_{\ge0}^{q}\), with cost \(A_\theta(b)=\sum_j a_{\theta j}b_j\). A feasible configuration measure \(p\) has nonnegative entries, \(\sum_b p_{\theta,b}=1\), and \(\sum_{\theta,b}\mu_\theta p_{\theta,b}b_j=\sigma_j\) for every class; empty configurations are allowed.

Result

The optimal worst-case polynomial-time fairness factor is \(\boxed{\rho=1}\).

More strongly, a feasible allocation can be constructed such that every supported nonempty configuration satisfies \(A_\theta(b)-a_{\theta j}\le r_\theta\) for every occupied class \(j\). Since \(H_\theta\ge r_\theta\), this implies the required fairness.

The construction uses at most \(m+1\) configurations per type and runs in \(O(\tau m^3L^2)\) bit operations with elementary arithmetic. This bound is conservative. Exact benchmark evaluation is a separate computational problem: deciding whether \(H_\theta\le1\) is NP-complete already when \(\tau=1\), \(r_\theta=1\), and every cost is positive.

Here, binary-rational encoding means that numerators and denominators are written in binary.

1. A lower bound on the benchmark

Fix an evaluating type \(\theta\). For any feasible measure \(z\), put \(T_\theta(z)=\sup_{\theta',b:z_{\theta',b}>0}A_\theta(b)/r_{\theta'}\).

If this supremum is finite, every supported configuration satisfies \(A_\theta(b)\le T_\theta(z)r_{\theta'}\). Consequently,

\(\displaystyle 1=\sum_j a_{\theta j}\sigma_j =\sum_{\theta',b}\mu_{\theta'}z_{\theta',b}A_\theta(b) \le T_\theta(z)\sum_{\theta'}\mu_{\theta'}r_{\theta'} =T_\theta(z). \)

The equality follows from feasibility; exchanging the sums is valid because all summands are nonnegative. If the supremum is infinite, the same lower bound is immediate. Taking the infimum proves \(H_\theta\ge r_\theta\).

The benchmark is also finite. Indeed, let \(K_j=\lceil m\sigma_j\rceil\). Give every type configuration \(K_je_j\) with probability \(\sigma_j/K_j\), and give the empty configuration the remaining probability. Since \(\sigma_j/K_j\le1/m\), this defines a feasible finite measure. All its benchmark ratios are finite because every entitlement is positive.

Thus \(r_\theta\le H_\theta<\infty\).

2. Constructing a factor-\(1\) allocation

We construct each type’s distribution separately, prescribing its expected class quantities as \(x_{\theta j}=r_\theta\sigma_j\).

These expectations satisfy the global supply constraints because \(\sum_\theta\mu_\theta x_{\theta j}=\sigma_j\sum_\theta\mu_\theta r_\theta=\sigma_j\).

Fix a type and suppress its subscript. Write its entitlement as \(r\), its costs as \(a_j\), and its prescribed quantities as \(x_j=r\sigma_j\). Normalization gives \(\sum_j a_jx_j=r\).

Positive-cost classes

For every class with \(a_j>0\), define

\(\displaystyle k_j=\left\lfloor\frac r{a_j}\right\rfloor+1,\qquad p_{k_je_j}=\frac{x_j}{k_j}.\)

These probabilities leave strictly positive unused mass. Indeed, \(k_j>r/a_j\), so

\(\displaystyle \sum_{j:a_j>0}\frac{x_j}{k_j} < \sum_{j:a_j>0}\frac{a_jx_j}{r} =1. \)

There is at least one positive-cost class, by normalization. Define the remaining probability mass as \(\delta=1-\sum_{j:a_j>0}x_j/k_j>0\).

Every positive-cost configuration already has the desired fairness property: its only occupied class is \(j\), and

\(\displaystyle A(k_je_j)-a_j =(k_j-1)a_j =\left\lfloor\frac r{a_j}\right\rfloor a_j \le r. \)

Zero-cost classes

Let \(S_0=\sum_{j:a_j=0}x_j\). If there are zero-cost classes, then \(S_0>0\), since every supply and entitlement is positive. Set \(K=\lceil2S_0/\delta\rceil\), and assign configuration \(Ke_j\) probability \(x_j/K\) for each such class.

Their total probability is \(S_0/K\le\delta/2\). Assign the empty configuration all remaining probability, namely \(\delta-S_0/K\).

Each zero-cost configuration has total cost zero, so it satisfies the fairness inequality even when removal is from a zero-cost class. Empty configurations have no fairness constraints.

Feasibility and fairness

For every class, its sole nonempty configuration contributes expected quantity exactly \(x_j\). Probabilities are nonnegative and sum to one. Therefore the resulting society-wide measure is feasible.

Every supported nonempty configuration contains only one class. The calculations above show, for every occupied class,

\(\displaystyle A_\theta(b)-a_{\theta j}\le r_\theta\le H_\theta.\)

Hence the allocation is \(1\)-fair. The construction has at most one configuration per class, together with the empty configuration: at most \(m+1\) configurations per supported type.

3. Encoding size and running time

The algorithm does not compute any benchmark.

For a fixed type, the quantities \(x_j\), positive-class counts \(k_j\), and positive-class probabilities initially have \(O(L)\)-bit representations. Choose a common denominator \(D\) for those probabilities and the quantities \(x_j\) of zero-cost classes. Taking the product of their denominators gives \(D\) with \(O(mL)\) bits.

Write \(\delta=d/D\) and \(S_0=s/D\). The zero-class count is then computed by integer arithmetic as \(K=\lceil2s/d\rceil\). It also has \(O(mL)\) bits. All final probabilities can use the common denominator \(DK\), with the zero-class branch omitted when unnecessary.

Thus:

  • There are at most \(\tau(m+1)\) listed configurations.
  • Every configuration count and probability has \(O(mL)\) bits.
  • The total allocation encoding has size \(O(\tau m^2L)\), including dense configuration vectors.
  • There are \(O(\tau m)\) arithmetic operations on integers of \(O(mL)\) bits.

Schoolbook multiplication and division therefore give the stated bound \(O(\tau m^3L^2)\). Counts may be numerically large; the algorithm writes them in binary without expanding them into individual chores.

4. Impossibility of a uniform factor below \(1\)

Although the question restricts factors to at least \(1\), the following family establishes sharpness even if smaller factors are allowed.

Take \(\tau=m=1\), with \(\mu=r=1\), supply \(\sigma=N\), and cost \(a=1/N\), where \(N\ge2\) is an integer.

The deterministic configuration \(b=N\) is feasible and has cost \(1\). Section 1 therefore implies \(H=1\).

Suppose a factor \(c<1-1/N\) were feasible. Every supported nonempty configuration would have to satisfy \((b-1)/N\le c\). Consequently no configuration with \(b\ge N\) could be supported. The expected quantity would then be at most \(N-1\), contradicting supply \(N\).

Conversely, configuration \(N\) attains factor \(1-1/N\). Thus this instance’s minimum factor is exactly \(1-1/N\). As \(N\) increases, these minimum factors approach \(1\).

Therefore no uniform factor below \(1\) is achievable, regardless of computational power, even with \(\tau=m=1\).

5. Exact benchmark evaluation is NP-complete

This hardness concerns benchmark evaluation, not constructing the allocation above.

Consider the restricted decision problem with \(\tau=1\), \(\mu=r=1\), all costs positive, and threshold \(H\le1\).

NP-hardness

Reduce from unbounded subset sum: given positive integers \(w_1,\ldots,w_d,B\), decide whether there are nonnegative integers \(b_i\) satisfying \(\sum_iw_ib_i=B\). This is a standard NP-complete problem; its definition and integer complexity are discussed in [Wojtczak’s paper](https://arxiv.org/pdf/1802.09465).

Choose \(C=(2dB+1)\prod_iw_i\). Thus every \(w_i\) divides \(C\), and \(C>2dB\). Construct \(m=d+1\) classes, denoting the additional class by \(*\), with

\(\displaystyle a_i=\frac{w_i}{C},\quad a_*=\frac{C-B}{C},\quad \sigma_i=\frac{C+B}{2dw_i},\quad \sigma_*=\frac12. \)

All costs and supplies are positive. Normalization holds because

\(\displaystyle \sum_i\sigma_i a_i+\sigma_*a_* =\frac{C+B}{2C}+\frac{C-B}{2C} =1. \)

The construction has polynomial bit length.

If the subset-sum instance is feasible: Choose a solution \(b\), and assign probability \(1/2\) to configuration \((b,1)\), whose cost is \(1\).

Let \(y_i=\sigma_i-b_i/2\). Since \(b_i\le B/w_i\) and \(C>(d-1)B\), each \(y_i\) is nonnegative. Assign configuration \((C/w_i)e_i\) probability \(\lambda_i=y_iw_i/C\). Each such configuration has cost \(1\), and

\(\displaystyle \sum_i\lambda_i =\frac1C\left(\frac{C+B}{2}-\frac B2\right) =\frac12. \)

These probabilities complete a feasible measure with maximum cost \(1\), proving \(H=1\).

If \(H\le1\): Section 1 gives \(H=1\). Every configuration cost is an integer multiple of \(1/C\). By the definition of the infimum, there is a feasible measure with maximum cost strictly below \(1+1/C\); hence all its supported configurations have cost at most \(1\).

Since \(a_*>1/2\), such configurations contain at most one unit of class \(*\). Supply \(\sigma_*=1/2\) forces some supported configuration to contain one.

Moreover, every supported configuration has cost exactly \(1\): all costs are at most \(1\), while their expected cost is \(1\). For a configuration containing class \(*\), this implies

\(\displaystyle \sum_iw_ib_i+(C-B)=C, \)

and therefore \(\sum_iw_ib_i=B\). The original subset-sum instance is feasible.

This proves NP-hardness with \(\tau=1\).

Membership in NP

For any instance in this restricted decision problem, let \(D\) be a common denominator of the costs. Configuration costs are multiples of \(1/D\). The same infimum argument shows that \(H\le1\) is equivalent to feasibility using only configurations of cost at most \(1\).

Because every cost is positive, this set of configurations is finite: each coordinate satisfies \(b_j\le1/a_j\). Every configuration has polynomial binary encoding length.

Feasibility means that the supply vector belongs to their convex hull. By Carathéodory’s theorem in dimension \(m\), at most \(m+1\) configurations suffice. The coefficients can also be chosen with polynomial bit length: choose an affinely independent support, and solve its rational linear equations by Cramer’s rule. Determinant bounds give polynomial-size numerators and denominators.

The configurations and probabilities form a certificate whose feasibility and cost bounds can be checked in polynomial time. Thus the restricted benchmark decision problem is NP-complete.

Unless \(\mathrm P=\mathrm{NP}\), exact benchmark evaluation has no algorithm polynomial in \(m,\tau,L\). This places no computational barrier on factor-\(1\) allocation, which uses only the proved lower bound \(H_\theta\ge r_\theta\).

6. Relation to the cited discrete results

The discrete MMAX benchmark partitions the chores outside one agent’s bundle among the other agents; see [the IJCAI definition](https://www.ijcai.org/proceedings/2023/0323.pdf). Here the benchmark uses the whole society, and fractional population masses permit the class-specific lotteries constructed above.

Accordingly, substituting the number of supported types \(\tau\) for the discrete number of agents \(n\) is unnecessary. The exact configuration-measure problem admits factor \(1\) for every \(m,\tau\).
