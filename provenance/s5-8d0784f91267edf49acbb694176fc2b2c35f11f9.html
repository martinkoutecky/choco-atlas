The continuous mirror question, as graded

There are three room categories, \(\tau\) tenant types with rational masses \(\mu_t\) summing to \(1\), and rational supplies \(q_j\) summing to \(1\). Each type-category pair has a membership oracle for a convex acceptable-rent set \(A_{tj}\subseteq\Delta^2\) containing the corresponding facet \(F_j\). Given \(\varepsilon>0\) and a promise that some exact feasible rent vector and assignment exist, determine the worst-case number of binary membership queries needed to find \(p\in\Delta^2\) and masses \(x_{tj}\geq0\) with \(\sum_j x_{tj}=\mu_t\), \(\sum_t x_{tj}=q_j\), and \(x_{tj}>0\) only when \(p\in A^\varepsilon_{tj}\). In particular, is query complexity polynomial in \(\tau\) and \(\log(1/\varepsilon)\), or is there a lower bound ruling this out?

One binary membership query specifies \(t,j\) and a rational \(p\in\Delta^2\), and returns whether \(p\in A_{tj}\). Consider deterministic adaptive algorithms, counting only these queries.
For binary-rational \(0<\varepsilon<1\), define \(A_{tj}^{\varepsilon}=\{p\in\Delta^2:\inf_{a\in A_{tj}}\max_{1\leq j\leq3}|p_j-a_j|\leq\varepsilon\}\).

Result

The problem admits a query bound polynomial in \(\tau\) and \(\log(1/\varepsilon)\), uniformly over \(L\).

More precisely, put \(r=\lceil\log_2(2/\varepsilon)\rceil\). For \(m=3\), a deterministic algorithm uses at most

\(6\tau(r^2+r)\)

binary membership queries. Its computation outside the oracle takes \(\operatorname{poly}(m,\tau,L,r)\) bit operations, with \(m=3\) fixed. The algorithm returns rational rents and rational assignment masses.

The proof has two parts: obtain an explicit, conservative preference covering for each type, then solve the resulting mass-and-supply problem without additional queries.

1. Finding a point approximately accepted for every category

Set \(N=2^r\) and \(\delta=1/N\), so \(2\delta\leq\varepsilon\).

We use the stated three-tenant theorem, [Theorem 5.2 of Grebennikov et al.](https://arxiv.org/pdf/2112.13622v4). For three closed convex preference coverings containing the corresponding facets, it finds a \(\delta\)-approximate bijective assignment using at most \(6(r^2+r)\) binary queries. Its proof supplies a rational implementation: queries lie on the \(N\)-grid, and the final rent is obtained from fixed-size rational polyhedral intersections. Thus query coordinates and output coordinates have \(O(r)\) bits, and the non-oracle computation is polynomial in \(r\).

For each type \(t\), run this algorithm on three identical copies of that type. A query concerning any copy is answered by querying the original type.

Let \(c_t\) be the returned rent. Because the assignment is bijective, every category is assigned to one of these identical copies. Consequently,

\(c_t\in\bigcap_{j=1}^3 A_{tj}^{\delta}.\)

This construction uses at most \(6\tau(r^2+r)\) queries in total. All the theorem’s hypotheses hold: each copied preference set is closed and convex, contains its corresponding facet, and belongs to a covering of the simplex.

We next make these centers strictly positive. Let \(u=(1/3,1/3,1/3)\) and define

\(b_t=(1-\delta)c_t+\delta u.\)

Every coordinate of \(b_t\) is at least \(\delta/3\). Also,

\(\|b_t-c_t\|_\infty=\delta\|u-c_t\|_\infty\leq\delta.\)

The triangle inequality gives

\(b_t\in\bigcap_{j=1}^3 A_{tj}^{2\delta}\subseteq\bigcap_{j=1}^3 A_{tj}^{\varepsilon}.\)

Each \(b_t\) is rational with \(O(r)\)-bit coordinates.

2. Explicit triangles inside the enlarged preference sets

For each type and category, define

\(B_{tj}=\operatorname{conv}(F_j\cup\{b_t\}).\)

We claim that

\(B_{tj}\subseteq A_{tj}^{\varepsilon}.\)

Indeed, compactness of \(A_{tj}\) ensures that there is \(a\in A_{tj}\) with \(\|b_t-a\|_\infty\leq\varepsilon\). Any \(p\in B_{tj}\) can be written as \(p=\lambda b_t+(1-\lambda)f\), where \(f\in F_j\) and \(0\leq\lambda\leq1\). Since \(f\in A_{tj}\), convexity implies \(\lambda a+(1-\lambda)f\in A_{tj}\), and

\(\|p-[\lambda a+(1-\lambda)f]\|_\infty=\lambda\|b_t-a\|_\infty\leq\varepsilon.\)

This proves the claim.

These triangles have a useful exact description:

\(p\in B_{tj}\quad\Longleftrightarrow\quad \dfrac{p_j}{b_{tj}}\leq\dfrac{p_k}{b_{tk}}\ \text{for every }k.\)

For the forward implication, write \(p=\lambda b_t+(1-\lambda)f\) with \(f_j=0\). Then \(p_j=\lambda b_{tj}\), while \(p_k\geq\lambda b_{tk}\).

Conversely, suppose the displayed inequalities hold and put \(\lambda=p_j/b_{tj}\). They imply \(p_k\geq\lambda b_{tk}\) for every \(k\). Summing gives \(1\geq\lambda\). If \(\lambda=1\), then \(p=b_t\). Otherwise,

\(f=(p-\lambda b_t)/(1-\lambda)\)

belongs to \(F_j\), proving \(p\in B_{tj}\).

In particular, the three triangles cover the simplex: at every point, at least one of the three ratios is minimal.

3. The triangles support arbitrary masses and supplies

We now prove the main extension beyond the individual-tenant theorem.

Lemma. Suppose every \(b_{tj}\) is positive. For any nonnegative masses and supplies satisfying \(\sum_t\mu_t=\sum_jq_j=1\), there exist \(p\in\Delta^2\) and an assignment \(x\) with the prescribed margins such that \(x_{tj}>0\) implies \(p\in B_{tj}\).

Proof. Consider the transportation linear program

\(\displaystyle \max_x\sum_{t,j}x_{tj}\log b_{tj},\)

subject to

\(\displaystyle x_{tj}\geq0,\qquad \sum_jx_{tj}=\mu_t,\qquad \sum_tx_{tj}=q_j.\)

It is feasible, since \(x_{tj}=\mu_tq_j\) satisfies all constraints. Its feasible set is compact, and all objective coefficients are finite because \(b_{tj}>0\). Therefore it has an optimal solution \(x^*\).

Its dual is

\(\displaystyle \min_{\alpha,\beta}\sum_t\mu_t\alpha_t+\sum_jq_j\beta_j,\)

subject to

\(\alpha_t+\beta_j\geq\log b_{tj}.\)

The dual is feasible—for example, \(\alpha_t=\beta_j=0\) works because \(b_{tj}\leq1\). Finite-dimensional linear-programming strong duality gives an attained dual optimum \((\alpha,\beta)\) with the same objective value.

The difference of the two objective values equals

\(\displaystyle \sum_{t,j}x^*_{tj}(\alpha_t+\beta_j-\log b_{tj})=0.\)

Every summand is nonnegative. Hence \(x^*_{tj}>0\) implies

\(\alpha_t+\beta_j=\log b_{tj}.\)

For such an edge and every category \(k\), dual feasibility gives

\(\beta_j-\log b_{tj}=-\alpha_t\leq\beta_k-\log b_{tk}.\)

Define

\(\displaystyle p_j=\frac{\exp(\beta_j)}{\sum_{k=1}^3\exp(\beta_k)}.\)

Exponentiating the previous inequality shows \(p_j/b_{tj}\leq p_k/b_{tk}\) for every \(k\). By Section 2, \(p\in B_{tj}\), as required. \(\square\)

This proof includes zero supplies. It uses logarithms and exponentials only to establish existence; the algorithm below computes rational outputs using rational arithmetic.

4. Finding a rational solution without further queries

For each type and unordered pair of categories, form the line

\(H_{t,jk}=\{p\in\Delta^2:b_{tk}p_j-b_{tj}p_k=0\}.\)

Include the three facet lines \(p_j=0\). There are at most \(3\tau+3\) lines in the affine plane \(\sum_jp_j=1\).

Enumerate all unique intersections of pairs of these lines, retaining those in \(\Delta^2\). At each retained point \(v\), construct the bipartite graph whose edges are

\(E(v)=\{(t,j):v\in B_{tj}\}.\)

Membership in this graph is determined by the rational inequalities from Section 2.

Test whether this graph supports the prescribed margins using a flow network:

  • the source-to-type edge has capacity \(\mu_t\);
  • each available type-to-category edge has capacity \(1\);
  • each category-to-sink edge has capacity \(q_j\).

A flow of value \(1\) supplies the required assignment: all source and sink capacities are saturated because each collection sums to \(1\).

It remains to prove that some enumerated candidate succeeds.

Take the feasible pair \((p^*,x^*)\) provided by the lemma and let \(E^*=\{(t,j):x^*_{tj}>0\}\). Define

\(\displaystyle R=\bigcap_{(t,j)\in E^*}B_{tj}.\)

This is a nonempty compact rational polytope, since it contains \(p^*\). Choose a vertex \(v\) of \(R\).

At least two linearly independent defining constraints must be active at \(v\), relative to the two-dimensional affine plane. Otherwise, a nonzero direction preserving every active constraint would permit sufficiently small displacements in both directions while keeping all inactive inequalities satisfied, contradicting that \(v\) is a vertex.

Every defining boundary of \(R\) is one of the listed comparison lines or facet lines. Therefore \(v\) is an enumerated intersection. Moreover, \(E^*\subseteq E(v)\), so the assignment \(x^*\) certifies that the flow test at \(v\) succeeds.

The algorithm thus terminates. Its returned assignment satisfies

\(x_{tj}>0\ \Longrightarrow\ v\in B_{tj}\subseteq A_{tj}^{\varepsilon}.\)

5. Query, running-time, and output bounds

The total query count is

\(\displaystyle Q\leq6\tau(r^2+r)=O\!\left(\tau[1+\log(1/\varepsilon)]^2\right),\qquad m=3.\)

This bound is independent of \(L\). No membership queries are used after constructing the centers.

There are at most \(\binom{3\tau+3}{2}=O(\tau^2)\) candidates. Each requires \(O(m^2\tau)\) rational comparisons and one flow computation with \(O(\tau+m)\) vertices and \(O(m\tau)\) edges.

The centers have \(O(r)\)-bit coordinates. Clearing denominators in each comparison line produces coefficients with \(O(r)\) bits, and intersections of two lines have \(O(r)\)-bit coordinates by the determinant formulas in fixed dimension.

For the flow computations, multiply all capacities by the product of the denominators appearing in the masses and supplies. That product has \(O(L)\) bits. A capacity-independent polynomial-time flow algorithm therefore computes exact rational assignments in polynomial bit time. Dividing the integer flows by this common denominator yields assignment entries with \(O(L)\) bits.

Consequently, the complete algorithm has non-oracle bit running time

\(\operatorname{poly}(m,\tau,L,1+\log(1/\varepsilon)),\qquad m=3.\)

The exact-feasibility promise is unnecessary for this approximate construction: the hypotheses themselves suffice.
