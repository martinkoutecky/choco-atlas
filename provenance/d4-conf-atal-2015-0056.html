The continuous mirror question, as graded

Given candidates \(C\), a known left-to-right order \(L\), a target \(p\), a fixed rational \(\alpha\in[0,1)\), a rational mass distribution over nonmanipulator rankings that are single-peaked with respect to \(L\), and a strategic bloc of mass \(\beta\), does there exist an allocation of that bloc among \(L\)-single-peaked rankings that makes \(p\) a Copeland\(_\alpha\) co-winner?

Packaged proof task (what the prover saw — nothing else)

Given a nonempty candidate set \(C\) of size \(m\), a known axis \(A\), a target \(p\in C\), and a fixed rational \(\alpha\in[0,1)\), all rankings are strict complete orders single-peaked with respect to \(A\).
A society is given by its support: the list of its \(\tau\) ranking types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible rankings. The nonmanipulator masses \(w_1,\ldots,w_\tau\) sum to \(1\); an additional strategic bloc has binary-rational mass \(\beta\geq0\).
Let \(\mathcal R_A\) be all rankings single-peaked with respect to \(A\). An allocation assigns nonnegative real masses \(x_r\) to \(r\in\mathcal R_A\), with \(\sum_{r\in\mathcal R_A}x_r=\beta\); it may use types absent from the input support.
For distinct candidates \(a,b\), define \(N(a,b)=\sum_{i:a\succ_i b}w_i+\sum_{r:a\succ_r b}x_r\). Apply Copeland\(_\alpha\) using these pairwise masses, with exact equality giving a pairwise tie. Success means that \(p\) has maximum score, allowing other winners and also allowing \(p\) to be the unique winner; there is no tie-breaking.

For every fixed rational \(\alpha\in[0,1)\), is deciding whether such an allocation exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and the total input bit length \(L\).

Discrete weighted manipulation with strict complete single-peaked rankings on a supplied axis is polynomial-time solvable for every \(\alpha\in[0,1)\), in both winner models. [Yang (2015)](https://ifaamas.csc.liv.ac.uk/Proceedings/aamas2015/aamas/p77.pdf)
No result settling exactly the divisible-mass problem above was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the nonmanipulator distribution to total mass 1, with beta an additional mass measured in the same units.
  • Specified beta as a nonnegative binary rational, retaining the discrete model's allowance for zero strategic weight.
  • Allowed arbitrary nonnegative real allocations over all admissible rankings, including rankings absent from the supplied support.
  • Interpreted co-winner as the nonunique-winner objective, which also accepts a unique winner.
  • Used strict complete rankings, exact pairwise ties, and no winner tie-breaking.
  • Renamed the axis A so that L denotes total input bit length.

Result

For every fixed rational \(\alpha\in[0,1)\), the problem is in \(\mathrm P\).

More strongly, a successful allocation exists if and only if allocating the entire strategic mass to one of two explicit rankings succeeds. This gives an algorithm using \(O((\tau+1)m^2)\) arithmetic operations and, conservatively, \(O((\tau+1)m^2L^2)\) bit operations.

Write the axis as \(c_1<_A\cdots<_A c_m\), with \(p=c_k\). The two rankings are

\(r_L:\quad p\succ c_{k-1}\succ\cdots\succ c_1\succ c_{k+1}\succ\cdots\succ c_m,\)

\(r_R:\quad p\succ c_{k+1}\succ\cdots\succ c_m\succ c_{k-1}\succ\cdots\succ c_1.\)

Empty blocks are omitted. Both rankings are strict, complete, and single-peaked on \(A\).

The proof has two parts: transferring a known discrete normalization result to real allocations, and showing that a successful allocation normalized in this way can be replaced by one of these two rankings.

1. A successful real allocation can be rationalized exactly

For distinct candidates \(a,b\), define the pairwise margin

\(M(a,b)=N(a,b)-N(b,a).\)

Suppose that a successful real allocation \(x\) exists, and let \(S=\{r:x_r>0\}\). The set \(S\) is finite because there are finitely many complete rankings.

Consider variables \(z_r\) for \(r\in S\). Impose the following linear equations:

  • \(\sum_{r\in S}z_r=\beta\);
  • \(M_z(a,b)=0\) for every pair tied under \(x\).

Here \(M_z\) includes the fixed nonmanipulator contribution. All coefficients and right-hand sides are rational, and \(x|_S\) satisfies the equations.

Gaussian elimination therefore expresses their solution set as

\(z=z^{(0)}+\sum_{j=1}^{d}t_jv^{(j)},\)

where \(z^{(0)}\) and all \(v^{(j)}\) have rational coordinates. Approximating the real parameters representing \(x|_S\) by rational parameters gives rational solutions arbitrarily close to \(x|_S\).

Choose such a solution sufficiently close that every coordinate remains positive and every originally nonzero pairwise margin retains its sign. This is possible because there are finitely many positive coordinates and finitely many nonzero margins. Set all coordinates outside \(S\) to zero.

The resulting rational allocation has exactly the original pairwise outcomes, including every exact tie. Consequently, every Copeland score is unchanged, and \(p\) remains a winner.

2. All strategic rankings can have peak \(p\)

We use this established discrete normalization fact:

In an unweighted manipulation instance with strict complete rankings single-peaked on a supplied axis, if \(p\) can be a Copeland\(_\alpha\) winner, then a successful manipulation exists in which every manipulator ranks \(p\) first.

This is [Yang (2015), Lemma 5](https://ifaamas.csc.liv.ac.uk/Proceedings/aamas2015/aamas/p77.pdf), specialized to single-peaked width one. Each partition block is then a singleton, so putting the block containing \(p\) first means putting \(p\) first. The paper explicitly states that its results apply to the nonunique-winner model.

To verify its applicability here, take the rational successful allocation from Section 1. Choose a positive integer \(Q\) clearing the denominators of all nonmanipulator and strategic masses. Replace each ranking of mass \(w\) by \(Qw\) unweighted voters.

This produces a finite unweighted instance on the same supplied axis. Every ranking remains strict, complete, and single-peaked. Scaling multiplies all pairwise margins by \(Q\), preserving wins, losses, ties, and Copeland winners.

Apply the discrete normalization fact to this instance. Divide the resulting strategic voter counts by \(Q\). We obtain a successful allocation of total mass \(\beta\) in which every strategic ranking has peak \(p\).

The expansion is only an existence argument; the algorithm below never performs it.

3. Two score comparisons for single-peaked profiles

Consider any profile of total mass \(T>0\), and put \(H=T/2\). Define the contribution of the contest against \(b\) to \(a\)'s score by

\(F(a,b)=1\) if \(N(a,b)>H\), \(F(a,b)=\alpha\) if \(N(a,b)=H\), and \(F(a,b)=0\) if \(N(a,b)<H\).

Thus \(\operatorname{score}(a)=\sum_{b\ne a}F(a,b)\). Because \(0\leq\alpha<1\), \(F(a,b)\) is a nondecreasing function of \(N(a,b)\).

We repeatedly use the following consequence of single-peakedness: for axis positions \(a<_A b<_A c\),

\(c\succ a\ \Longrightarrow\ b\succ a,\qquad a\succ c\ \Longrightarrow\ b\succ c.\)

Indeed, either failed implication would put the middle candidate below both endpoints, contradicting single-peakedness.

Let \(U\) be the total mass whose peaks lie strictly left of \(p\), and \(V\) the total mass whose peaks lie strictly right of \(p\).

Claim 1: If \(U>H\) or \(V>H\), then \(p\) cannot win

Suppose \(U>H\), and let \(a\) be the immediate axis neighbor left of \(p\). Every voter with a peak left of \(p\) prefers \(a\) to \(p\) and to every candidate right of \(p\). Hence \(a\) strictly beats all these candidates.

For every candidate \(c<_A a\), single-peakedness gives

\(p\succ c\ \Longrightarrow\ a\succ c,\)

so \(N(a,c)\geq N(p,c)\), and therefore \(F(a,c)\geq F(p,c)\).

For every \(c>_A p\), we have \(F(a,c)=1\geq F(p,c)\). There is no candidate between \(a\) and \(p\). Finally, \(F(a,p)=1\) and \(F(p,a)=0\). Thus

\(\operatorname{score}(a)-\operatorname{score}(p)=1+\sum_{c\notin\{a,p\}}\bigl(F(a,c)-F(p,c)\bigr)\geq1.\)

Consequently, \(p\) is not a winner. The proof for \(V>H\) is symmetric.

Claim 2: If \(U<H\), then \(p\) strictly outscores every candidate left of \(p\)

The mass with peaks at or right of \(p\) is \(T-U>H\). All those voters prefer \(p\) to every candidate left of \(p\). Therefore \(p\) strictly beats every such candidate.

Fix \(a<_A p\). For every other candidate \(c<_A p\), \(F(p,c)=1\geq F(a,c)\). For every \(c>_A p\), single-peakedness gives

\(a\succ c\ \Longrightarrow\ p\succ c,\)

and hence \(F(p,c)\geq F(a,c)\). The mutual contest contributes \(1\) to \(p\) and \(0\) to \(a\). Therefore

\(\operatorname{score}(p)-\operatorname{score}(a)\geq1.\)

Symmetrically, if \(V<H\), then \(p\) strictly outscores every candidate right of \(p\).

4. A successful normalized allocation can be made unanimous

Assume \(\beta>0\), and take a successful allocation in which every strategic ranking has peak \(p\), as provided by Section 2.

Let \(Z\) be the total mass with peak \(p\). Then

\(T=1+\beta=U+V+Z,\qquad Z\geq\beta>0.\)

The values \(U,V,Z\) do not depend on how strategic rankings interleave the two sides of \(p\).

Claim 1 implies \(U\leq H\) and \(V\leq H\). Since \(Z>0\), these two inequalities cannot both be equalities.

There are exactly three cases.

Case 1: \(U<H\) and \(V<H\)

Claim 2 and its symmetric version show that \(p\) strictly outscores every other candidate in every profile having these peak masses. In particular, both unanimous allocations, to \(r_L\) and to \(r_R\), succeed.

Case 2: \(V=H\) and \(U<H\)

Replace the entire strategic allocation by mass \(\beta\) on \(r_L\).

Every strategic ranking before and after replacement puts \(p\) first. Thus all pairwise contests involving \(p\), and \(p\)'s score, remain unchanged.

A ranking with peak \(p\) necessarily orders each side from nearest to farthest. Consequently, comparisons within either side also remain unchanged.

For a left candidate \(a\) and a right candidate \(b\), the replacement ranks \(a\) above \(b\) throughout the strategic bloc. Therefore

\(N_{\mathrm{new}}(b,a)\leq N_{\mathrm{old}}(b,a).\)

All other contests of \(b\) remain unchanged, so every right candidate's score weakly decreases. Since the original allocation succeeded, no right candidate overtakes \(p\).

Left candidates may gain score, but the new profile still has \(U<H\). Claim 2 therefore guarantees that \(p\) strictly outscores every left candidate.

Thus the unanimous allocation to \(r_L\) succeeds.

Case 3: \(U=H\) and \(V<H\)

The symmetric argument shows that the unanimous allocation to \(r_R\) succeeds.

These cases prove the claimed reduction to two rankings. If \(\beta=0\), both proposed allocations simply reproduce the original society, so the equivalence remains valid. If \(m=1\), success is automatic.

5. Algorithm and running time

Compute the nonmanipulator pairwise margins. For each of \(r_L,r_R\), add the pairwise contribution of strategic mass \(\beta\), compute every Copeland score, and test whether \(p\) has maximum score. Return “yes” exactly when at least one test succeeds.

The preceding proof establishes both directions of correctness: every accepted test supplies a valid allocation, and every successful allocation implies that one of the tests succeeds.

For exact arithmetic, let \(D\) be the product of the input denominators of \(w_1,\ldots,w_\tau,\beta\). Then \(D\), every scaled mass, and every scaled pairwise margin have \(O(L)\) bits. Pairwise ties are tested by exact integer equality.

Write the fixed rational parameter as \(\alpha=a_0/b_0\). Compare scores using the integers

\(b_0\cdot(\text{number of wins})+a_0\cdot(\text{number of ties}).\)

Precomputing ranking positions and accumulating pairwise margins requires \(O(\tau m^2)\) arithmetic operations. Testing the two strategic rankings requires another \(O(m^2)\). Including denominator conversion, the total is \(O((\tau+1)m^2)\) arithmetic operations on integers of \(O(L)\) bits.

Using elementary integer arithmetic gives the conservative bit bound \(O((\tau+1)m^2L^2)\). The algorithm depends on the supplied support size \(\tau\); it never enumerates all single-peaked rankings or expands binary masses into individual voters.
