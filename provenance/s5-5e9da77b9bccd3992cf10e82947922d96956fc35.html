The continuous mirror question, as graded

Given a society described by \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\), where each type ranks its acceptable partner types and the type-level profile is acyclic, construct symmetric marks \(w_{tu}=w_{ut}\) for acceptable pairs of distinct types such that \(u\succ_t v\) if and only if \(w_{tu}<w_{tv}\); assign \(+\infty\) to unacceptable pairs.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq 1\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Acceptability is specified by a simple undirected graph \(G=(T,E)\) on the support; within-type partnerships are excluded. Each type \(t\) supplies a strict total order \(\succ_t\) on its neighbors; empty neighbor sets are allowed.
The profile is promised acyclic: there are no pairwise distinct types \(t_1,\ldots,t_k\), with \(k\geq 3\), forming a cycle in \(G\) such that \(t_{i+1}\succ_{t_i}t_{i-1}\) for every \(i\), with indices interpreted modulo \(k\).
Construct a symmetric matrix with finite nonnegative binary-rational marks \(w_{tu}=w_{ut}\) on acceptable pairs, satisfying \(u\succ_t v\iff w_{tu}<w_{tv}\) for all neighbors \(u,v\) of \(t\); all other entries, including diagonal entries, equal \(+\infty\).
Let \(m=|E|\) and let \(L\) be the total binary input length. State running times in \(m,\tau,L\).

Can this promised construction problem be solved in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite societies with strict preferences and undirected acceptability, symmetric marks representing any acyclic profile can be constructed in \(O(n^2)\) time, where \(n\) is the number of agents. [Verified source](https://opendl.ifip-tc6.org/db/conf/europar/europar2007/GaiLMMRV07.pdf)
No separate result specifically formulated for binary-rational type masses was located.

Modeling choices made when packaging the task

  • Specified mutual acceptability by a simple undirected graph, following the discrete acceptance-graph model.
  • Specified strict total rankings of acceptable neighbors, excluding ties as in the discrete model.
  • Defined acyclicity using cycles of at least three pairwise distinct types and strict successor-over-predecessor preferences.
  • Used nonnegative binary-rational output marks to give the computational construction a finite encoding, consistent with the discrete integer-valued construction.
  • Set diagonal entries to positive infinity, implementing the question's exclusion of within-type partnerships.

Result. The promised construction problem is polynomial-time solvable. Every acceptable pair can receive an integer mark in \(\{0,\ldots,m-1\}\). The construction uses \(O(m+\tau)\) operations after reading the input; producing the full matrix takes \(O(\tau^2)\) additional operations.

The vertices used below are the support types themselves. The masses do not enter any required inequality, so there is no need to expand them into a population of individual agents.

Lemma: a mutually first-choice pair exists. Let \(H=(T,F)\) be any nonempty graph obtained by deleting acceptable edges from \(G\). At each type, restrict the original preference order to its remaining neighbors. Then some edge \(\{t,u\}\in F\) joins two types that rank each other first among their remaining neighbors.

*Proof.* Deleting edges preserves acyclicity: any forbidden cycle in \(H\), together with its preference comparisons, would also be a forbidden cycle in \(G\).

For each nonisolated type \(t\), let \(f(t)\) be its first remaining choice. Starting from any nonisolated type and repeatedly applying \(f\) is always possible: every reached type has at least the preceding type as a neighbor. Since \(T\) is finite, this sequence eventually contains a directed cycle
\[ t_1,\ldots,t_k,\qquad f(t_i)=t_{i+1}, \]
with pairwise distinct types and cyclic indices.

There are no loops, so \(k\ne 1\). If \(k=2\), its two types form the required mutually first-choice pair. If \(k\geq 3\), then at each \(t_i\) the successor and predecessor are distinct remaining neighbors. Since the successor is the first choice and preferences are strict,
\[ t_{i+1}\succ_{t_i}t_{i-1}. \]
This contradicts acyclicity. Thus the mutually first-choice pair exists. \(\square\)

Construction and correctness. Initialize every matrix entry to \(+\infty\), and set a counter \(r=0\). While acceptable edges remain:

  • Choose a mutually first-choice pair \(\{t,u\}\) in the remaining graph.
  • Set \(w_{tu}=w_{ut}=r\).
  • Delete that edge from both endpoints’ preference lists and increment \(r\).

The lemma applies after every deletion. Consequently, the algorithm removes exactly \(m\) edges and assigns each acceptable pair a finite nonnegative integer mark. All other entries, including diagonal entries, remain \(+\infty\). Symmetry holds by construction.

To verify the preference representation, fix a type \(t\) and distinct original neighbors \(u,v\) with \(u\succ_t v\). If \(\{t,v\}\) were removed before \(\{t,u\}\), then \(u\) would still be an available neighbor when \(v\) was selected. This contradicts the requirement that \(v\) be \(t\)’s first remaining choice. Therefore \(\{t,u\}\) is removed earlier, and its counter value is smaller:
\[ u\succ_t v\quad\Longrightarrow\quad w_{tu}<w_{tv}. \]

Conversely, suppose \(w_{tu}<w_{tv}\). Strict totality gives either \(u\succ_t v\) or \(v\succ_t u\). The latter would imply \(w_{tv}<w_{tu}\) by the implication just proved, a contradiction. Hence
\[ u\succ_t v\quad\Longleftrightarrow\quad w_{tu}<w_{tv}. \]
For \(u=v\), both sides are false. This proves every required comparison.

If \(m=0\), the initialized matrix already satisfies all requirements.

Implementation and running time. Store each preference list in its given order and maintain a pointer to its first remaining entry. Whenever an edge is removed, it is first in both endpoint lists, so deletion consists of advancing those two pointers.

Maintain a queue of mutually first-choice pairs:

  • Initially inspect every nonisolated type’s first choice and enqueue the pair if the choice is mutual.
  • After removing \(\{t,u\}\), inspect the new first choices of \(t\) and \(u\), enqueuing any mutual pairs found.
  • When popping a record, discard it if it is stale or duplicates an already processed pair.

This queue finds every pair needed by the algorithm. Initially, every mutual pair is enqueued. After a deletion, only the first choices of its two endpoints change. Thus every newly mutual pair contains an endpoint just inspected; every other mutual pair retains its queued record.

There are at most \(\tau\) initial records and at most two new records per deleted edge. Each inspection, valid removal, and discarded record takes constant many word operations. The preference lists contain \(2m\) entries. Therefore:

  • Reading the input and constructing a sparse representation takes \(O(L+m+\tau)\) word operations.
  • Constructing and writing the explicit matrix takes \(O(L+m+\tau^2)\) word operations.

Indices, pointers, counters, and marks fit in words of \(O(\log(L+\tau+m+2))\) bits. In the standard bit-cost RAM model, a conservative total bound for the explicit matrix is
\[ O\!\left((L+m+\tau^2)\log(L+\tau+m+2)\right). \]
This is polynomial in all three requested parameters.

Each finite mark uses \(O(\log(m+2))\) bits and is a binary-rational number because it is an integer. Encoding \(+\infty\) with a distinguished constant-size token gives a full-matrix output length of \(O(\tau^2+m\log(m+2))\) bits. No arithmetic on the masses is required beyond reading their encodings.

Relation to the supplied source. This is the mutual-first-choice edge-removal construction in Algorithm 1 and Lemma 3 of [Gai et al., *Acyclic Preference Systems in P2P Networks*](https://opendl.ifip-tc6.org/db/conf/europar/europar2007/GaiLMMRV07.pdf). The proof above verifies it directly for the stated support graph and makes the dependence on the binary input and output lengths explicit. Binary-rational masses introduce no additional constraint into this construction.
