The continuous mirror question, as graded

Given finitely many types \(t=(r,o)\), rational masses \(\mu_t>0\) summing to \(1\), nomination densities \(\rho_{st}\in[0,1]\), and a cap \(\kappa\in(0,1]\), define \(d_t=\sum_s\mu_s\rho_{st}\). Compute quotas \(q_t\in[0,1]\) with \(0<\sum_t\mu_tq_t\le\kappa\) that maximize \(\min_{t:q_t>0}d_t\), subject to equal quotas for types sharing incoming class \(r\); \(o\) records outgoing nomination patterns.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types \(t=(r_t,o_t)\) with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
The input includes binary-rational nomination densities \(\rho_{st}\in[0,1]\) and a cap \(\kappa\in(0,1]\). Define the incoming profile \(r_t=(\rho_{st})_s\), the outgoing profile \(o_t=(\rho_{ts})_s\), and \(m=|\{r_t:t\in T\}|\). Individuals are nonatomic; nominations between distinct individuals of the same type are permitted, so \(\rho_{tt}\) need not vanish.
Set \(d_t=\sum_s\mu_s\rho_{st}\) and \(\Delta=\max_t d_t\). Feasible binary-rational quotas satisfy \(q_t\in[0,1]\), \(0<\sum_t\mu_tq_t\le\kappa\), and \(q_t=q_u\) whenever \(r_t=r_u\). Their quality is \(Q(q)=\min_{t:q_t>0}d_t\).
Let \(L\) denote the total input bit length; state running times in \(m,\tau,L\) and any additional approximation parameters.

What is the optimal worst-case additive guarantee \(\alpha(\kappa)\ge0\) achievable by a polynomial-time algorithm returning feasible quotas with \(Q(q)\ge\Delta-\alpha(\kappa)\) on every such society?

Discrete: for loopless directed graphs with \(n\ge2\) vertices and \(2\le k\le n\), an impartial mechanism selects a nonempty set of at most \(k\) vertices, each with indegree at least \(\Delta-\lfloor(n-2)/(k-1)\rfloor-1\); impartiality means a vertex’s selection is invariant under changes to its own outgoing edges. [Verified discrete guarantee](https://arxiv.org/abs/2301.04544v1).
The [journal version](https://link.springer.com/article/10.1007/s00355-025-01631-9) explicitly requires nonempty selections and retains this bound. No result settling this precise mass-and-quota formulation was located.

Equality of quotas for equal incoming profiles is a condition within a society; it does not impose invariance between different societies. Exact algorithm and proof

Compute every score \(d_t=\sum_s\mu_s\rho_{st}\), and let

\(H=\{t\in T:d_t=\Delta\}\).

Return

\(q_t=\kappa\) if \(t\in H\), and \(q_t=0\) otherwise.

We verify every requirement.

Quota bounds and encoding. Each quota is either zero or the input value \(\kappa\). Hence every quota is binary-rational and belongs to \([0,1]\).

Equality on incoming profiles. If \(r_t=r_u\), then \(\rho_{st}=\rho_{su}\) for every \(s\). Consequently,

\(d_t=\sum_s\mu_s\rho_{st}=\sum_s\mu_s\rho_{su}=d_u\).

Thus \(t\in H\) exactly when \(u\in H\), and the algorithm returns \(q_t=q_u\).

Positive selected mass and the cap. The finite, nonempty support has at least one score maximizer. Because every support mass is positive,

\(0<\sum_{t\in H}\mu_t\le 1\).

Therefore,

\(0<\sum_t\mu_tq_t=\kappa\sum_{t\in H}\mu_t\le\kappa\).

In particular, even an arbitrarily small positive cap permits positive selection from the maximizing types.

Quality. Since \(\kappa>0\), the types with positive quotas are exactly \(H\). Hence

\(Q(q)=\min_{t\in H}d_t=\Delta\).

This proves the zero additive guarantee.

Optimality. Every feasible quota vector selects at least one type, and every type has score at most \(\Delta\). Thus \(Q(q)\le\Delta\) for every feasible vector. The algorithm attains this upper bound on every input, so its worst-case additive loss is exactly zero.

The proof allows arbitrary diagonal densities \(\rho_{tt}\), unequal masses, and any number of incoming-profile classes.

Bit complexity

There are \(\tau^2\) score contributions. They can be evaluated exactly with polynomially bounded intermediate encodings.

For completeness, write the input masses and densities as rational numerators and positive denominators. Let \(D\) be the product of all denominators appearing in those masses and densities. Its bit length is \(O(L)\), because the sum of their encoded lengths is at most \(L\).

Each product \(\mu_s\rho_{st}\) has a denominator dividing \(D\). Thus we can compute the integer scores

\(z_t=Dd_t=\sum_s D\mu_s\rho_{st}\)

and compare these integers. Since \(0\le d_t\le1\), every partial sum is between zero and \(D\), so its bit length is \(O(L)\).

Using ordinary quadratic-time integer multiplication and division gives a conservative bound of \(O(\tau^2L^2)\) bit operations. The output has \(O(\tau L)\) bits. This bound is independent of \(m\), with \(1\le m\le\tau\), and requires no approximation parameter.

Stronger cohort impartiality: a separate, tight bound

The cited discrete model requires invariance of an agent’s selection under changes to that agent’s outgoing nominations. This is explicitly a condition comparing different inputs. [Journal definition of impartiality](https://link.springer.com/article/10.1007/s00355-025-01631-9)

One possible extension to the supplied representation is the following additional axiom: keep positive-mass cohorts and their masses fixed, and require a cohort’s quota to remain unchanged whenever only its entire outgoing row changes.

Under this stronger axiom, together with the stated feasibility conditions, the optimal guarantee is instead \(\alpha(\kappa)=1\). Here is a complete proof.

Fix any binary-rational \(\varepsilon\in(0,1/2)\). Use two cohorts \(a,b\), with masses \(\mu_a=1-\varepsilon\) and \(\mu_b=\varepsilon\), and nomination matrix

\(A=\begin{pmatrix}0&0\\1&1\end{pmatrix}\).

Their incoming profiles coincide: \(r_a=r_b=(0,1)\). Their outgoing profiles differ, so they are distinct support types. Feasibility forces \(q_a=q_b\); positive selected mass then forces both quotas to be positive.

Now change only cohort \(a\)’s outgoing row, producing

\(A'=\begin{pmatrix}0&1\\1&1\end{pmatrix}\).

The added impartiality axiom preserves \(q_a>0\). In the new society,

\(d_a=\varepsilon,\qquad d_b=(1-\varepsilon)+\varepsilon=1,\qquad\Delta=1\).

Because \(a\) must still receive a positive quota, the quality is \(Q(q)=\varepsilon\), regardless of whether \(b\) is selected. Thus the additive loss is \(1-\varepsilon\).

Taking \(\varepsilon=2^{-j}\) for arbitrarily large integers \(j\) shows that any uniform guarantee under this additional axiom must satisfy \(\alpha(\kappa)\ge1\).

Conversely, the constant rule \(q_t=\kappa\) for every type satisfies feasibility, incoming-profile equality, and the added impartiality axiom. Since \(Q(q)\ge0\) and \(\Delta\le1\), it guarantees \(Q(q)\ge\Delta-1\). Therefore the lower bound is tight.

This additional axiom concerns changes by an entire positive-mass cohort. It is stronger than an individual deviation in a nonatomic population and is not among the written quota constraints. For the formulation actually stated, the exact answer remains \(\alpha(\kappa)=0\).
