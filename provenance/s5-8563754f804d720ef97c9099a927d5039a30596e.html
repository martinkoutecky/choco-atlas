The anchor (named result in the paper)

Theorem 10 — class: algorithmic

The continuous mirror question, as graded

Given applicant type masses α_a and resource type masses β_b, each summing to one, shared rankings, nonnegative utilities \(u_{ab}\), a fairness level φ, and per-type entitlement values \(E_{a,j}\), find a mass plan \(X=(x_{ab})\) maximizing \(\sum_{a,b}u_{ab}x_{ab}\), subject to \(\sum_b x_{ab}=α_a\), \(\sum_a x_{ab}=β_b\), \(x_{ab}\ge 0\), and \(\sum_{b\in \operatorname{Top}_j(a)}x_{ab}\ge φα_a E_{a,j}\) for every type \(a\) and preference prefix \(j\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of its \(\tau\) positive-mass types, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here the applicant support \(A\) has size \(\tau\), and the resource support \(B\) has size \(m\); their positive masses satisfy \(\sum_a\alpha_a=\sum_b\beta_b=1\).
Applicants within type \(a\) share a strict total ranking \(r_a:B\to\{1,\ldots,m\}\); define \(\operatorname{Top}_j(a)=\{b:r_a(b)\le j\}\). Utilities \(u_{ab}\ge0\), fairness level \(\phi\in[0,1]\), and error tolerance \(\epsilon>0\) are binary rationals.
An entitlement table \(H\) is admissible if \(0=H_{a,0}\le\cdots\le H_{a,m}=1\) and \(\sum_a\alpha_a(H_{a,r_a(b)}-H_{a,r_a(b)-1})=\beta_b\) for every \(b\). The input supplies an admissible estimate \(\widetilde E\); the true admissible table \(E\) is unavailable, with the promise \(|\widetilde E_{a,j}-E_{a,j}|\le\epsilon/2\) everywhere.
A mass plan satisfies \(x_{ab}\ge0\), \(\sum_bx_{ab}=\alpha_a\), and \(\sum_ax_{ab}=\beta_b\). It is \(\psi\)-fair relative to \(E\) if \(\sum_{b\in\operatorname{Top}_j(a)}x_{ab}\ge\psi\alpha_aE_{a,j}\) for every \(a,j\). Let \(U(X)=\sum_{a,b}u_{ab}x_{ab}\), and let \(\operatorname{OPT}_\phi(E)\) be its maximum over \(\phi\)-fair mass plans.
Can an algorithm using only the supplied data guarantee simultaneously \(\frac{\phi(1+\epsilon/2)}{m\epsilon+1}\)-fairness and \(U(X)\ge\frac{\operatorname{OPT}_\phi(E)}{\phi m\epsilon+1}\), uniformly over all compatible true tables \(E\), in time polynomial in \(m,\tau,L\), where \(L\) is the supplied input bit length; or what computational or information-theoretic obstruction prevents these guarantees?
For finite matching markets with \(n\) applicants and resources, admissible entitlement estimates of error at most \(\epsilon/2\) yield fairness \(\frac{\phi(1+\epsilon/2)}{n\epsilon+1}\) and utility factor \(\frac{1}{\phi n\epsilon+1}\); both bounds are tight for that algorithm at \(\phi=1\). [Devic et al. (2023)](https://proceedings.mlr.press/v202/devic23a/devic23a.pdf).
No result settling this exact approximation question for arbitrary positive type masses was identified in the literature search.

Modeling choices made when packaging the task

  • Restored estimated entitlements, an unavailable true entitlement table, and an additive error tolerance because the verified anchor is an approximation result.
  • Interpreted shared rankings as rankings shared within each applicant type; different applicant types may rank resources differently.
  • Required strict total rankings over resource types, so a prefix contains whole resource types.
  • Required true and estimated entitlement tables to be cumulative probabilities whose mass-weighted increments match resource masses, carrying over the consistency properties of baseline and sampled matching marginals.
  • Used the resource support size m in place of n in the approximation factors, since preference prefixes now range over m resource types; this agrees with the finite setting when each resource is a separate type.
  • Specified binary rational numerical inputs, fairness in the interval [0,1], positive error tolerance, and running time measured in the supplied input bit length.

Conclusion

The requested guarantees are information-theoretically impossible for arbitrary positive type masses, already when \(m=\tau=2\). The supplied estimate can be compatible with two true tables whose fairness requirements cannot simultaneously be satisfied. Thus unlimited computation would not suffice.

A two-type counterexample

Let \(A=\{a_1,a_2\}\), \(B=\{b_1,b_2\}\), and let both applicant types rank \(b_1\) first and \(b_2\) second. Set

\[ \alpha_{a_1}=\alpha_{a_2}=\frac12,\qquad \beta_{b_1}=\frac18,\qquad \beta_{b_2}=\frac78,\qquad \phi=1,\qquad \epsilon=\frac14. \]

Take \(u_{ab}=1\) for every pair. Supply the estimate and consider the following two possible true tables:

| Table | First prefix for \(a_1\) | First prefix for \(a_2\) |
|---|---:|---:|
| \(\widetilde E\) | \(\frac18\) | \(\frac18\) |
| \(E^{(1)}\) | \(\frac14\) | \(0\) |
| \(E^{(2)}\) | \(0\) | \(\frac14\) |

For every table, set \(H_{a,0}=0\) and \(H_{a,2}=1\).

Admissibility. Each row is nondecreasing. Because the rankings agree, admissibility for \(b_1\) requires \(\sum_a\alpha_aH_{a,1}=\beta_{b_1}\). For the estimate this sum is \(\frac12\cdot\frac18+\frac12\cdot\frac18=\frac18\). For either true table it is \(\frac12\cdot\frac14+\frac12\cdot0=\frac18\). The sum for \(b_2\) is consequently \(\frac78\).

Compatibility. Each first-prefix entry differs from its estimate by exactly \(\frac18=\epsilon/2\). The endpoint entries agree. Both true tables therefore satisfy the promise.

The requested fairness factor is

\[ \psi=\frac{\phi(1+\epsilon/2)}{m\epsilon+1} =\frac{1+1/8}{1+1/2} =\frac34. \]

An algorithm sees identical supplied data under \(E^{(1)}\) and \(E^{(2)}\). Its output must therefore satisfy both sets of fairness constraints if the guarantee is uniform over compatible truths.

Fairness under \(E^{(1)}\) requires

\[ x_{a_1b_1}\ge\frac34\cdot\frac12\cdot\frac14=\frac{3}{32}. \]

Fairness under \(E^{(2)}\) requires \(x_{a_2b_1}\ge\frac{3}{32}\). Together these imply

\[ \sum_a x_{ab_1}\ge\frac{3}{16}>\frac18=\beta_{b_1}, \]

contradicting the resource-mass constraint. Hence no mass plan has the required uniform fairness.

The utility requirement introduces no difficulty in this example: every mass plan has \(U(X)=\sum_{a,b}x_{ab}=1\). For either true table, the entitlement-induced plan \(x_{ab}=\alpha_a(E_{a,r_a(b)}-E_{a,r_a(b)-1})\) is admissible and fully fair. Thus \(\operatorname{OPT}_1(E)=1\), and every feasible plan satisfies the requested utility bound \(U(X)\ge\frac23\). The impossibility arises entirely from fairness.

The obstruction persists for arbitrarily small error

A larger family shows that no strictly positive uniform fairness factor depending only on \(m,\phi,\epsilon\) can hold over arbitrary applicant supports.

Fix any binary rational \(0<\epsilon\le1\), put \(s=\epsilon/2\), and let \(t\ge2\) be a power of two. Use \(m=2\), \(\tau=t\), common rankings \(b_1\) before \(b_2\), and masses

\[ \alpha_a=\frac1t,\qquad \beta_{b_1}=\frac{s}{t},\qquad \beta_{b_2}=1-\frac{s}{t}. \]

Supply \(\widetilde E_{a,1}=s/t\) for every applicant type, with endpoints \(0\) and \(1\).

For each type \(i\), define a possible truth by \(E^{(i)}_{i,1}=s\) and \(E^{(i)}_{a,1}=0\) for \(a\ne i\). Its first-resource mass is \(\frac1t s=\beta_{b_1}\), so it is admissible. Its error is at most \(s=\epsilon/2\): the distinguished entry differs by \(s-s/t\), and every other entry differs by \(s/t\).

If a plan is uniformly \(\psi\)-fair, truth \(E^{(i)}\) requires

\[ x_{ib_1}\ge\psi\frac{s}{t}=\psi\beta_{b_1}. \]

Summing these necessary inequalities over all \(t\) possible distinguished types gives \(\beta_{b_1}\ge t\psi\beta_{b_1}\). Since \(\beta_{b_1}>0\), necessarily \(\psi\le1/t\).

This bound is exact for the entire compatibility set. Indeed, every compatible admissible \(E\) satisfies

\[ \frac1t\sum_a E_{a,1}=\frac{s}{t}, \]

so \(E_{a,1}\le s\) for every type. The estimate-induced plan has \(x_{ab_1}=s/t^2\), which is at least \(\frac1t\alpha_aE_{a,1}\); its full-prefix constraints also hold. Therefore the maximum uniform fairness factor for this supplied instance is exactly \(1/t\).

For any fixed \(\phi>0\), the proposed factor with \(m=2\) is positive and independent of \(t\). Choosing a power of two \(t\) larger than its reciprocal makes that factor impossible. This applies even when \(\epsilon\) is arbitrarily small.

Why the finite-market guarantee does not transfer

The finite-market proof uses uniform smoothing of assignment probabilities; equal resource capacities make the smoothed matrix feasible. [Devic et al., Theorem 10 and its proof](https://proceedings.mlr.press/v202/devic23a/devic23a.pdf).

The corresponding type-mass construction would be

\[ \widehat q_{ab} =\frac{\widetilde q_{ab}+\epsilon\alpha_a}{1+m\epsilon}, \qquad \widetilde q_{ab} =\alpha_a(\widetilde E_{a,r_a(b)}-\widetilde E_{a,r_a(b)-1}). \]

Its row sums are \(\alpha_a\), but its column sums are \((\beta_b+\epsilon)/(1+m\epsilon)\). These equal the required \(\beta_b\) precisely when \(\beta_b=1/m\).

The counterexample proves that this is more than a defect of that particular construction: arbitrary resource masses permit incompatible fairness demands from indistinguishable true tables. Randomization also cannot repair guarantees stated for expected allocations, since the expected output is a single feasible mass plan subject to the same contradiction.
