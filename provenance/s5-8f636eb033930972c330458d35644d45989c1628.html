The continuous mirror question, as graded

Given a finite metric type set \(T\), rational mass vector \(\mu\in\mathbb{Q}_{\ge 0}^{T}\) with \(\sum_{t\in T}\mu_t=1\), finite candidate set \(C\), distances \(d\), and integer \(k\), compute an integral set \(W\subseteq C\) with \(|W|\le k\) such that for every \(\ell\in\{1,\ldots,k\}\), radius \(y\ge 0\), and submass \(0\le\lambda_t\le\mu_t\) with \(\sum_t\lambda_t\ge\ell/k\), writing \(S_\lambda=\{t:\lambda_t>0\}\), if \(\left|\{c\in C:d(t,c)\le y\text{ for all }t\in S_\lambda\}\right|\ge\ell\), then \(\left|\{w\in W:\exists t\in S_\lambda,\ d(t,w)\le y\}\right|\ge\ell\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
The input also contains a finite candidate set \(C\), with \(m=|C|\), an explicit nonnegative binary rational metric distance matrix on \(T\cup C\), and a binary integer \(k\ge1\). Types and candidates may overlap; no containment assumption is imposed. Let \(L\) be the total input bit length.
For \(y\in\mathbb R_{\ge0}\), write \(A_t(y)=\{c\in C:d(t,c)\le y\}\); distance ties are included.
An integral outcome \(W\subseteq C\), with \(|W|\le k\), satisfies mass metric proportional justified representation if, for every \(\ell\in\{1,\ldots,k\}\) and every real submass vector \(0\le\lambda_t\le\mu_t\) with \(\sum_t\lambda_t\ge\ell/k\), setting \(S_\lambda=\{t:\lambda_t>0\}\), one has
\(\left|\bigcap_{t\in S_\lambda}A_t(y)\right|\ge\ell\ \Longrightarrow\ \left|W\cap\bigcup_{t\in S_\lambda}A_t(y)\right|\ge\ell\) for every \(y\ge0\).

Can an outcome satisfying this condition be computed in time polynomial in \(m,\tau,L,\log(k+1)\), or is this search problem NP-hard?

For explicitly listed agents and finite candidates, expanding approvals computes an outcome satisfying metric proportional justified representation in polynomial time. [Source](https://arxiv.org/html/2310.18162)

Result

The search problem is polynomial-time solvable, including for binary rational masses and binary-encoded \(k\).

The algorithm implements expanding approvals directly on the support types. This follows the budget approach in [Section 3.3 of the supplied source](https://arxiv.org/html/2310.18162#S3.SS3), but the proof and bit-complexity analysis below handle the stated mass model explicitly.

1. Removing the submass quantifier

For a nonempty set \(S\subseteq T\), define \(\mu(S)=\sum_{t\in S}\mu_t\), \(I_S(y)=\bigcap_{t\in S}A_t(y)\), and \(U_S(y)=\bigcup_{t\in S}A_t(y)\).

The required condition is equivalent to the following: for every nonempty \(S\subseteq T\), every \(\ell\in\{1,\ldots,k\}\), and every \(y\ge0\),

\(\displaystyle \mu(S)\ge\frac{\ell}{k}\ \text{ and }\ |I_S(y)|\ge\ell \quad\Longrightarrow\quad |W\cap U_S(y)|\ge\ell.\)

Indeed, the original condition implies this statement by taking \(\lambda_t=\mu_t\) on \(S\) and zero elsewhere. Positivity of the masses ensures that this vector has support exactly \(S\). Conversely, any admissible submass vector has nonempty support \(S_\lambda\) satisfying \(\mu(S_\lambda)\ge\sum_t\lambda_t\ge\ell/k\), so the displayed condition gives the original conclusion.

This equivalence does not require enumerating the subsets.

If \(k\ge m\), returning \(W=C\) immediately satisfies the condition: \(I_S(y)\subseteq U_S(y)\). This also handles an empty candidate set. The algorithm below handles the remaining case.

2. Algorithm

Let \(R=\{0\}\cup\{d(t,c):t\in T,\ c\in C\}\), with duplicates removed and the radii sorted increasingly. There are at most \(\tau m+1\) radii.

Initialize \(W=\varnothing\), and give each type \(t\) budget \(b_t=k\mu_t\). Each candidate costs one unit.

At each radius \(r\in R\), repeat the following operation until no eligible candidate remains:

  • Find a candidate \(c\in C\setminus W\) such that \(\sum_{t:d(t,c)\le r}b_t\ge1\).
  • Deduct exactly one unit from its supporting types, keeping every budget nonnegative.
  • Add \(c\) to \(W\).

For a deterministic deduction rule, fix an ordering of the types. Start with unpaid cost \(a=1\); for each supporting type, deduct \(\min\{b_t,a\}\) and reduce \(a\) accordingly. The eligibility inequality guarantees that the entire cost is paid. Fixing an ordering of candidates likewise makes candidate selection deterministic.

All distance ties are included before processing a radius.

3. Correctness

Committee size

Initially, the total budget is \(\sum_t k\mu_t=k\). Each selection reduces it by exactly one, and budgets remain nonnegative. Consequently, \(|W|\le k\). Since candidates are never selected twice, there are also at most \(m\) selections.

Representation at a processed radius

Fix a radius \(r\in R\). Let \(W_r\) and \(b_t^r\) denote the selected candidates and remaining budgets immediately after processing this radius.

By termination of its selection loop, every unselected candidate \(c\) satisfies

\(\displaystyle \sum_{t:d(t,c)\le r}b_t^r<1.\)

Suppose, towards a contradiction, that some nonempty \(S\subseteq T\) and \(\ell\in\{1,\ldots,k\}\) satisfy \(\mu(S)\ge\ell/k\) and \(|I_S(r)|\ge\ell\), but that \(q=|W_r\cap U_S(r)|<\ell\).

For each selected candidate \(w\in W_r\), let \(p_{t,w}\) be the amount charged to type \(t\) when selecting \(w\). Each selection costs exactly one, so \(\sum_{t\in T}p_{t,w}=1\).

If \(p_{t,w}>0\), then \(w\) was selected at some radius \(r_w\le r\), and \(d(t,w)\le r_w\le r\). Thus, if any type in \(S\) paid for \(w\), then \(w\in U_S(r)\).

It follows that the total expenditure by \(S\) up to this point is at most \(q\): only the \(q\) selected candidates in \(U_S(r)\) can have received payments from \(S\), and each received at most one unit from \(S\). Hence

\(\displaystyle \sum_{t\in S}b_t^r =k\mu(S)-\sum_{w\in W_r}\sum_{t\in S}p_{t,w} \ge\ell-q \ge1. \)

Because \(I_S(r)\subseteq U_S(r)\), at most \(q\) common candidates have been selected. Since \(|I_S(r)|\ge\ell>q\), there exists \(c\in I_S(r)\setminus W_r\).

Every type in \(S\) supports \(c\) at radius \(r\). Therefore

\(\displaystyle \sum_{t:d(t,c)\le r}b_t^r \ge\sum_{t\in S}b_t^r \ge1, \)

contradicting termination of the selection loop. This proves the representation condition at radius \(r\).

Every real radius and the final outcome

Fix any real \(y\ge0\), and let \(r\) be the largest element of \(R\) not exceeding \(y\). Such an element exists because \(0\in R\).

Every type–candidate distance belongs to \(R\). Consequently, \(A_t(y)=A_t(r)\) for every type \(t\): no approval changes between these radii.

The preceding proof establishes the required representation at \(r\) for \(W_r\). Since subsequent selections only add candidates, the final outcome \(W\supseteq W_r\) satisfies the same lower bound on representation. The equivalence in Section 1 now proves the original condition for every real submass vector.

4. Polynomial bit complexity

Write each input mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive binary integers. Define the common denominator \(D=\prod_{t\in T}q_t\).

Although its numerical value may be large, \(D\) has polynomial encoding length: \(\log_2 D=\sum_t\log_2 q_t\le L\).

Represent budgets using integer units of size \(1/D\). Initialize

\(\displaystyle B_t=k p_t(D/q_t).\)

These are integers, and their total is \(kD\). Candidate eligibility becomes \(\sum_{t:d(t,c)\le r}B_t\ge D\); each selection deducts exactly \(D\) integer units using the same greedy deduction rule.

Every budget, supporter sum, and unpaid cost lies between zero and \(kD\). Thus all budget arithmetic uses integers of \(O(L+\log(k+1))\) bits. The computation never expands a mass into individual agents.

Let \(h=|R|\le\tau m+1\). At each radius, scanning all unselected candidates either produces a selection or terminates that radius’s loop. There are at most \(m\) successful scans and \(h\) terminating scans. Each scan requires at most \(m\tau\) distance tests and budget additions; each deduction requires at most \(\tau\) updates.

Sorting the radii also takes polynomial time: rational comparisons use cross multiplication of integers of polynomial bit length. Therefore the complete algorithm runs in time polynomial in \(m,\tau,L,\log(k+1)\).

No containment relation between types and candidates is used. The proof relies only on the nested, inclusive approval sets induced by the explicit distances.
