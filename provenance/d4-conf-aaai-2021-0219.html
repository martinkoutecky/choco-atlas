The continuous mirror question, as graded

Given a finite candidate set \(C\), committee size \(k\), finite approval-type set \(T\), and rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), choose an integral committee \(W\subseteq C\) with \(\lvert W\rvert=k\) maximizing \(M_\mu(W)=\max_f\min_{c\in W}\sum_{t:c\in t}\mu_t f_{t,c}\), where \(f_{t,c}\ge0\), \(f_{t,c}=0\) when \(c\notin t\), and \(\sum_{c\in t\cap W}f_{t,c}=1\) for every positive-mass type intersecting \(W\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\) and \(1\le k\le m\). A society is given by its support: a list \(T\subseteq 2^C\) of \(\tau\) distinct approval types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible approval types. Require \(\sum_{t:c\in t}\mu_t>0\) for every \(c\in C\); empty approval types are allowed.
For an integral committee \(W\subseteq C\) with \(|W|=k\), a support assignment has real variables \(f_{t,c}\ge0\) for \((t,c)\in T\times W\), with \(f_{t,c}=0\) when \(c\notin t\) and \(\sum_{c\in t\cap W}f_{t,c}=1\) whenever \(t\cap W\ne\varnothing\). Types disjoint from \(W\) contribute nothing.
Define \(M_\mu(W)=\max_f\min_{c\in W}\sum_{t:c\in t}\mu_t f_{t,c}\). Given also a binary rational threshold \(q\ge0\), decide whether some such committee satisfies \(M_\mu(W)\ge q\). Let \(L\) be the total input bit length; state running times in \(m,\tau,k,L\).

Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite unit-weight electorates, global maximin support maximization coincides with max-Phragmén and is NP-hard. [Source](https://doi.org/10.1007/s10107-022-01805-8)
Positive real voter strengths with fractional support assignments have already been studied for this same objective, including NP-hardness; the normalized rational formulation is a specialization of that model, so the requested complexity target is already settled. [Source](https://arxiv.org/html/2004.12990v3)

  • Restored the committee-size domain 1 through the number of candidates and the requirement that every candidate have positive approving mass.
  • Removed zero-mass types from the input support; retained empty approval types, which the discrete definition permits.
  • Restricted assignment variables to committee members, with disjoint types contributing no support.
  • Introduced a nonnegative binary rational threshold to formulate the exact optimization question as a decision problem, and defined L as total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when all masses are equal and every approval type contains exactly two candidates. Consequently, it is polynomial-time solvable if and only if \(\mathrm{P}=\mathrm{NP}\).

The hardness proof below normalizes the reduction in Theorem 9 of [Cevallos and Stewart](https://arxiv.org/html/2004.12990v3#S3). It directly satisfies the requirement that the input lists distinct support types.

Polynomial-time verification of a committee

Fix a committee \(W\) with \(|W|=k\). The feasible assignments form a nonempty product of simplices: for each type intersecting \(W\), its fractions are nonnegative and sum to one. This set is compact, and the minimum candidate support is continuous. Thus the maximum defining \(M_\mu(W)\) is attained.

Construct a directed network with source \(s\), one vertex for each \(t\in T\), one vertex for each \(c\in W\), and sink \(z\). Its arcs and capacities are:

  • \(s\to t\), with capacity \(\mu_t\);
  • \(t\to c\), with capacity \(1\), whenever \(c\in t\cap W\);
  • \(c\to z\), with capacity \(q\).

We claim that
\[ M_\mu(W)\ge q \quad\Longleftrightarrow\quad \text{the network admits a flow of value }kq. \]

Forward direction. Given a qualifying assignment, initially send mass \(\mu_t f_{t,c}\) from \(t\) to \(c\). Each candidate receives at least \(q\). For each candidate separately, retain exactly \(q\) of its incoming mass and delete the excess. Send the retained row totals from \(s\) to the types and send \(q\) from every candidate to \(z\). This respects all capacities and gives flow value \(kq\).

Reverse direction. A flow of value \(kq\) saturates every candidate-to-sink arc, since their total capacity is \(kq\). Write \(x_{t,c}\) for its type-to-candidate flows. Then
\[ \sum_{c\in t\cap W}x_{t,c}\le\mu_t, \qquad \sum_{t:c\in t}x_{t,c}=q \quad(c\in W). \]
For every type intersecting \(W\), allocate its unused mass to any one candidate in that intersection. This only increases candidate supports. Dividing each resulting allocation by the positive number \(\mu_t\) gives the required fractions \(f_{t,c}\), with every active row summing to one.

This proves the claim, including the distinction between flow capacities and the problem’s requirement to allocate all active mass.

Exact running times and membership in \(\mathrm{NP}\)

For every assignment, total candidate support is at most \(1\), so \(M_\mu(W)\le 1/k\). Therefore \(q=0\) is immediately a yes-instance, and \(q>1/k\) is immediately a no-instance.

For other thresholds, the network has at most
\[ V_*=\tau+k+2, \qquad E_*=\tau k+\tau+k \]
vertices and arcs, respectively.

Multiply capacities by the product \(D\) of the input denominators. This produces integer capacities. Because the sum of the denominators’ bit lengths is at most \(L\), both \(D\) and all scaled capacities have \(O(L)\) bits. Exact integer max flow therefore avoids any numerical approximation.

Edmonds–Karp uses \(O(V_*E_*^2)\) arithmetic operations, independently of capacity magnitudes. Including network construction, denominator scaling, and elementary integer arithmetic, a conservative bit-time bound for checking one committee is
\[ O\!\left( \bigl[m\tau+(\tau+k+2)(\tau k+\tau+k)^2\bigr](L+1)^2 \right). \]

A certificate need only specify \(W\), using \(O(k\log(m+1))\) bits. The verifier checks its size and runs this exact flow test. Hence the decision problem belongs to \(\mathrm{NP}\), despite allowing real support fractions.

Enumerating all committees gives an exact deterministic algorithm with running time
\[ O\!\left( \binom{m}{k} \bigl[m\tau+(\tau+k+2)(\tau k+\tau+k)^2\bigr](L+1)^2 \right). \]

Hardness for normalized, distinct support types

Use the known \(\mathrm{NP}\)-complete problem of deciding whether a nonempty simple cubic graph \(G=(V,E)\) has an independent set of size \(k\), with \(1\le k\le |V|\).

Set \(C=V\), and write \(N=|E|\). For each edge \(e=\{u,v\}\), introduce approval type \(t_e=\{u,v\}\), with
\[ \mu_{t_e}=\frac1N, \qquad q=\frac3N. \]
Simplicity ensures distinct types. Their masses sum to \(1\), and every candidate has positive approval mass \(3/N\).

If \(W\) is independent, every type intersecting \(W\) contains exactly one selected candidate. Assign its entire mass there. Each selected candidate receives \(3/N=q\).

Conversely, if \(W\) contains adjacent vertices \(u,v\), exactly five edges are incident to at least one of them. Each corresponding type contributes at most \(1/N\) to their combined support. Thus every assignment satisfies
\[ \operatorname{supp}_f(u)+\operatorname{supp}_f(v)\le\frac5N, \qquad \min_{c\in W}\operatorname{supp}_f(c) \le\frac{5}{2N}<q. \]
Therefore a qualifying committee exists exactly when the graph has the required independent set.

Here \(m=|V|\) and \(\tau=N=3m/2\). Masses and threshold have \(O(\log m)\)-bit encodings; even a dense incidence representation has polynomial length. The construction is consequently a polynomial-time many-one reduction.

Conclusion

The reduction proves \(\mathrm{NP}\)-hardness under the stated normalization and support requirements. Exact polynomial-time committee verification proves membership in \(\mathrm{NP}\). Together they settle the target question.
