The continuous mirror question, as graded

Input a rational mass vector μ over a finite type set \(T\), with \(\sum_t μ_t=1\), positive per-member singleton worths \(a_t\), a rational polynomial coalition-worth density \(W:[0,1]^T\to\mathbb{Q}\) with \(W(0)=0\) and ∂_t W(0)=a_t\), and a rational polynomial kernel \(h:[0,1]\to\mathbb{Q}\). Set \(K=\sum_t μ_t a_t\) and \(A_h=\int_0^1 h(q)W(qμ)\,dq\). Compute the exact per-member allocation Φ_t=\frac{a_t}{K}A_h+W(μ)-A_h\) for each type, or equivalently its total mass allocation \(y_t=μ_tΦ_t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type has a binary rational per-member singleton worth \(a_t>0\). Input also includes rational-coefficient polynomials \(W:[0,1]^T\to\mathbb{R}\) and \(h:[0,1]\to\mathbb{R}\), with \(W(0)=0\) and \(\partial_tW(0)=a_t\) for every \(t\in T\). Other worths and kernel values may have either sign; no monotonicity or kernel normalization is imposed.
Both polynomials are supplied as explicit lists of monomials, with binary rational coefficients and unary nonnegative integer exponents. Let \(m\) be the maximum total degree of either polynomial and \(L\) the total input bit length.
Define \(K=\sum_{t\in T}\mu_ta_t\), \(A_h=\int_0^1h(q)W(q\mu)\,dq\), and \(\Phi_t=(a_t/K)A_h+W(\mu)-A_h\). The computational problem is to output all \(\Phi_t\) as exact binary rationals, equivalently all total allocations \(y_t=\mu_t\Phi_t\).

Can these allocations be computed exactly in time polynomial in \(m,\tau,L\), or is this computation NP-hard under polynomial-time Turing reductions?

For finite TU-games with strictly positive singleton worths, averaging the sequential procedure over uniformly random player orders yields the allocation \(\psi_i=v(\{i\})\alpha/\sum_jv(\{j\})+(v(N)-\alpha)/|N|\), where \(\alpha=\sum_{S\subseteq N}\alpha^{|N|}_{|S|}v(S)\) has arbitrary real coefficients; this is an implementation identity, not a complexity classification.

Result

The allocations can be computed exactly in time polynomial in \(m,\tau,L\). In fact, because the exponents are unary, the problem belongs to \(\mathrm{FP}\) under the stated encoding.

Here, an exact rational is represented by a numerator and a positive denominator, both written in binary.

1. Explicit evaluation and integration

Write the supplied monomial lists as

\(W(x)=\sum_{j=1}^{s}c_j\prod_{t\in T}x_t^{\alpha_{jt}},\qquad h(q)=\sum_{\ell=1}^{r}b_\ell q^{\beta_\ell}.\)

Set

\(d_j=\sum_{t\in T}\alpha_{jt},\qquad z_j=c_j\prod_{t\in T}\mu_t^{\alpha_{jt}}.\)

By the degree hypothesis, \(d_j\leq m\) and \(\beta_\ell\leq m\). Substitution gives

\(W(q\mu)=\sum_{j=1}^{s}z_jq^{d_j},\qquad W(\mu)=\sum_{j=1}^{s}z_j.\)

Multiplying the two finite polynomial sums and integrating term by term is valid. Since every exponent is a nonnegative integer,

\(A_h=\sum_{j=1}^{s}\sum_{\ell=1}^{r}\dfrac{z_jb_\ell}{d_j+\beta_\ell+1}.\)

Thus both required quantities are explicit sums of polynomially many rational terms. No coalition enumeration or implicit polynomial expansion is needed.

Finally, compute \(K=\sum_{t\in T}\mu_ta_t\). Every summand is strictly positive, so \(K>0\), and division by \(K\) is valid. The requested outputs are

\(\Phi_t=W(\mu)+\left(\dfrac{a_t}{K}-1\right)A_h.\)

It remains to prove that exact arithmetic on these expressions has polynomial bit complexity.

2. Polynomial bounds on denominators and numerators

Write \(\mu_t=u_t/v_t\) and \(a_t=p_t/s_t\), with positive integer numerators and denominators. Let \(D_W\) and \(D_h\) be the products of the positive denominators of the coefficients in the respective input lists. An empty product is \(1\).

Define

\(D_\mu=\prod_{t\in T}v_t^m,\qquad D=D_WD_hD_\mu(2m+1)!.\)

The denominator of \(\prod_t\mu_t^{\alpha_{jt}}\) divides \(D_\mu\), because each \(\alpha_{jt}\leq m\). Also,

\(1\leq d_j+\beta_\ell+1\leq 2m+1,\)

so every integration denominator divides \((2m+1)!\). Consequently, \(D\) is a common denominator for every term contributing to both \(W(\mu)\) and \(A_h\). There are integers \(V,U\) satisfying

\(W(\mu)=V/D,\qquad A_h=U/D.\)

The total bit length of input denominators is at most \(L\). Therefore,

\(\log_2D=O\!\left(mL+L+m\log(m+1)\right).\)

The numerators also have polynomial bit length. Indeed, every input coefficient has absolute value at most \(2^L\). Since \(0<\mu_t\leq1\), we have \(|z_j|\leq2^L\). Hence

\(|W(\mu)|\leq s2^L,\qquad |A_h|\leq sr2^{2L}.\)

The second inequality follows directly from the integration formula, since every integration denominator is at least \(1\). If \(h\) is zero, then \(A_h=0\). Thus \(V\) and \(U\) have bit lengths bounded by

\(O\!\left(\log_2D+L+\log(s+1)+\log(r+1)\right).\)

Next, define

\(Q=\left(\prod_{t\in T}v_t\right)\left(\prod_{t\in T}s_t\right).\)

Each denominator \(v_ts_t\) divides \(Q\), so \(K=k/Q\) for some positive integer \(k\). We have \(\log_2Q=O(L)\). Because \(K\) is a weighted average of the \(a_t\), using \(\sum_t\mu_t=1\),

\(0<K\leq\max_ta_t\leq2^L.\)

It follows that \(k\leq Q2^L\), so \(k\) also has polynomial bit length.

Substituting these representations gives the explicit output fraction

\(\Phi_t=\dfrac{p_tQU+s_tk(V-U)}{s_tkD}.\)

Its denominator is strictly positive, and both numerator and denominator have polynomial bit length. Multiplying by \(\mu_t=u_t/v_t\) gives \(y_t\) with the same polynomial bit-length guarantee.

3. Exact algorithm and running time

An exact algorithm performs the following steps:

  • Compute the degrees \(d_j\) and the products \(\prod_t\mu_t^{\alpha_{jt}}\).
  • Compute \(W(\mu)\) and \(A_h\) using the finite sums above, accumulating their numerators over the common denominator \(D\).
  • Compute \(K=k/Q\).
  • Form each displayed output fraction and reduce it using the greatest common divisor.

Integer powers can be computed by repeated squaring. Constructing the factorial uses \(O(m)\) multiplications. The evaluation and integration require polynomially many arithmetic operations: there are \(s\tau\) variable factors and \(sr\) integration terms.

All operands have polynomial bit length by the preceding bounds. Integer addition, multiplication, exact division, and greatest common divisor computation take polynomial time in their operand bit lengths. Therefore the entire algorithm runs in time polynomial in \(m,\tau,L\).

Moreover, explicit monomial lists give polynomial bounds on \(s,r,\tau\) in terms of \(L\), and unary exponents give a polynomial bound on \(m\) in terms of \(L\). Thus this is also a polynomial-time algorithm in the ordinary input-length sense.

Complexity conclusion

The exact continuous computation is in \(\mathrm{FP}\). The finite-game implementation identity is unnecessary for this conclusion: explicit polynomial input makes the required evaluation and integration directly computable.

If this problem were NP-hard under polynomial-time Turing reductions, the algorithm above would imply \(\mathrm{P}=\mathrm{NP}\).
