The continuous mirror question, as graded

Given a candidate set \(C\) and a finite support of admissible ballot types \(t\), each with positive binary-rational mass \(\mu_t\) summing to one, choose a complete ranking \(\pi\) that maximizes \(\sigma_U^\mu(\pi)\), defined from the minimum over candidate pairs of their mass-weighted agreement with \(\pi\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\geq 2\). A ballot type is an ordered list of distinct candidates, possibly empty; listed candidates strictly outrank all unlisted candidates, which are tied with one another. No other ties are allowed.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For distinct \(a,b\in C\), define \(x_t(a,b)=1\) if type \(t\) prefers \(a\) to \(b\), \(x_t(a,b)=0\) if it prefers \(b\) to \(a\), and \(x_t(a,b)=\tfrac12\) if both are unlisted. Put \(p_{ab}=\sum_t\mu_t x_t(a,b)\).
For a complete strict ranking \(\pi\), put \(M^\mu(\pi)=\min_{a\succ_\pi b}p_{ab}\), and define \(\sigma_U^\mu(\pi)=M^\mu(\pi)/(1-M^\mu(\pi))\) when \(M^\mu(\pi)<\tfrac12\), and \(\sigma_U^\mu(\pi)=1\) otherwise. Any maximizing ranking is admissible.

Is finding a complete ranking \(\pi\) maximizing \(\sigma_U^\mu(\pi)\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite profiles of equally weighted voters with these ballot conventions, exact maximization of \(\sigma_U\) is known to admit a polynomial-time algorithm. [Source](https://arxiv.org/html/2506.12961v1)
No result explicitly treating this exact optimization problem with binary-rational support masses was located in the literature search.

Modeling choices made when packaging the task

  • Resolved admissible ballot types as complete or truncated strict rankings, with listed candidates above unlisted candidates and all unlisted candidates tied.
  • Allowed the empty ballot, since no nonempty-ballot restriction is stated.
  • Restored half agreement when both candidates are unlisted and the piecewise transformation defining the unanimity score.
  • Restricted to at least two candidates and distinct candidate pairs so that the minimum is defined.
  • Allowed any maximizing complete strict ranking; no additional tie-breaking requirement is needed.
  • Defined L as total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Exact optimization is polynomial-time solvable

The problem admits an exact algorithm polynomial in \(m,\tau,L\). It operates directly on the support masses; it does not expand them into equally weighted voters.

The algorithm uses a threshold formulation of the edge-deletion approach in the cited paper’s [Section 3.3 and Appendix A](https://arxiv.org/html/2506.12961v1). The proof below establishes correctness and polynomial bit complexity independently.

1. Replace the objective by a capped minimum

For every ballot type and every pair of distinct candidates, \(x_t(a,b)+x_t(b,a)=1\). Consequently, the normalization of the masses gives \(p_{ab}+p_{ba}=1\).

Define
\(Z(\pi)=\min\{M^\mu(\pi),\tfrac12\}\).
The objective in the question satisfies
\(\sigma_U^\mu(\pi)=Z(\pi)/(1-Z(\pi))\).

This transformation is strictly increasing on \([0,\tfrac12]\): if \(0\leq u<v\leq\tfrac12\), then
\[ \frac{v}{1-v}-\frac{u}{1-u} =\frac{v-u}{(1-u)(1-v)}>0. \]
Thus maximizing \(Z\) is equivalent to maximizing \(\sigma_U^\mu\).

2. Threshold feasibility is equivalent to acyclicity

Fix \(q\in[0,\tfrac12]\). Define a directed graph \(G_q\) with vertex set \(C\), inserting the arc \(b\to a\) whenever \(a\neq b\) and \(p_{ab}<q\).

Such an arc expresses a necessary ordering: placing \(a\) above \(b\) would make the minimum agreement smaller than \(q\).

Lemma. There exists a complete strict ranking \(\pi\) satisfying \(Z(\pi)\geq q\) if and only if \(G_q\) is acyclic. Whenever it is acyclic, every topological ordering of \(G_q\) satisfies \(Z(\pi)\geq q\).

Proof. Because \(q\leq\tfrac12\), the condition \(Z(\pi)\geq q\) is equivalent to \(M^\mu(\pi)\geq q\).

Suppose first that \(M^\mu(\pi)\geq q\). For every arc \(b\to a\), we have \(p_{ab}<q\), so \(\pi\) must place \(b\) above \(a\). Therefore \(\pi\) respects every arc. A directed cycle would require positions in this strict ranking to increase around the cycle and return to their starting position, which is impossible. Hence \(G_q\) is acyclic.

Conversely, let \(\pi\) be a topological ordering of \(G_q\). If some pair \(a\succ_\pi b\) satisfied \(p_{ab}<q\), the graph would contain \(b\to a\), contradicting the topological ordering. Thus every pair oriented by \(\pi\) has agreement at least \(q\), proving \(M^\mu(\pi)\geq q\).

For completeness, a finite acyclic directed graph has a topological ordering: it contains a vertex of indegree zero, since otherwise following incoming arcs would eventually repeat a vertex and produce a directed cycle. Repeatedly removing a vertex of indegree zero constructs the ordering. ∎

There are at most \(m(m-1)\) arcs. Building the graph and testing acyclicity therefore require \(O(m^2)\) comparisons and graph operations.

3. Only polynomially many thresholds need examination

Let
\(S=\{0,\tfrac12\}\cup\{p_{ab}:a\neq b,\ p_{ab}<\tfrac12\}\).

This set has at most \(m(m-1)+2\) distinct values. Moreover, \(Z(\pi)\in S\) for every ranking \(\pi\). Indeed, either \(M^\mu(\pi)\geq\tfrac12\), giving \(Z(\pi)=\tfrac12\), or \(M^\mu(\pi)<\tfrac12\). In the latter case, the minimum defining \(M^\mu(\pi)\) is attained by some pair, because \(m\geq2\) and there are finitely many pairs.

Feasibility is monotone in the threshold. If \(q_1\leq q_2\), then every arc of \(G_{q_1}\) is an arc of \(G_{q_2}\). Thus acyclicity at \(q_2\) implies acyclicity at \(q_1\).

The algorithm is therefore:

  • Compute all pairwise probabilities and sort the distinct elements of \(S\).
  • Binary-search for the largest \(q^*\in S\) for which \(G_{q^*}\) is acyclic.
  • Return any topological ordering \(\pi^*\) of \(G_{q^*}\).

The search always has a feasible threshold, since \(G_0\) has no arcs.

Optimality proof. By the lemma, \(Z(\pi^*)\geq q^*\). For any ranking \(\pi\), its value \(Z(\pi)\) belongs to \(S\), and \(\pi\) witnesses feasibility at that threshold. The maximality of \(q^*\) therefore implies \(Z(\pi)\leq q^*\). Applying this also to \(\pi^*\) gives \(Z(\pi^*)=q^*\). Hence \(\pi^*\) maximizes both \(Z\) and \(\sigma_U^\mu\). ∎

The strict inequality in the arc definition matters: agreement exactly equal to the threshold is allowed.

4. Exact arithmetic and running time

Write each input mass as \(\mu_t=u_t/v_t\), with positive binary-encoded integers \(u_t,v_t\). This also covers dyadic masses.

Set \(D=\prod_{t=1}^{\tau}v_t\), \(Q=2D\), and \(w_t=u_t(D/v_t)\). These quantities are integers, and normalization gives \(\sum_t w_t=D\).

Every pairwise probability has the common-denominator representation
\(p_{ab}=P_{ab}/Q\), where
\(P_{ab}=\sum_{t=1}^{\tau}w_t(2x_t(a,b))\).

Each summand multiplier \(2x_t(a,b)\) belongs to \(\{0,1,2\}\). In particular, \(0\leq P_{ab}\leq Q\).

Since the sum of the denominator encoding lengths is at most \(L\), the integers \(D,Q,w_t,P_{ab}\) have \(O(L)\) bits. Their numerical magnitudes may be exponential in \(L\), but their representations remain polynomial in length.

For each ballot, assign each listed candidate its list position and every unlisted candidate the common position \(m+1\). Comparing these positions determines \(2x_t(a,b)\) exactly, including the value \(1\) when both candidates are unlisted. Computing all \(P_{ab}\) takes \(O(\tau m^2)\) elementary arithmetic and comparison operations.

Represent every threshold as \(q=s/Q\); the threshold \(\tfrac12\) has numerator \(D\). Then the graph test \(p_{ab}<q\) is simply the integer comparison \(P_{ab}<s\). Sorting thresholds takes \(O(m^2\log(m+1))\) comparisons. Binary search performs \(O(\log(m+1))\) acyclicity tests, each using \(O(m^2)\) operations.

For an explicit conservative bit bound, put
\(B=L+\lceil\log_2(m+\tau+2)\rceil\).
Using schoolbook arithmetic, all required integer operations and graph bookkeeping can be bounded by \(O(B^2)\) bit operations each. Including preprocessing, the total running time is

\(O\!\left((\tau m^2+m^2\log(m+1))\bigl(L+\log(m+\tau+2)\bigr)^2\right)\)

bit operations. This is polynomial in all three requested parameters. The optimum score can also be returned exactly as \(q^*/(1-q^*)\).

Conclusion

Finding an admissible maximizing complete ranking is polynomial-time solvable, including with binary-rational support masses.
