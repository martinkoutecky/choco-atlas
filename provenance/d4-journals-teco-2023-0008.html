The continuous mirror question, as graded

Given finite good types \(G\), complete agent types \(\Theta\), rational masses \(\mu_\theta\) with \(\sum_\theta\mu_\theta=1\), rational per-capita supplies \(\kappa_g\in[0,1]\), and additive leveled valuations \(v_\theta\), compute an exact allocation kernel \(x_{\theta,S}\ge0\) over \(S\subseteq G\) satisfying \(\sum_{S\subseteq G}x_{\theta,S}=\mu_\theta\), \(\sum_{\theta,S\ni g}x_{\theta,S}=\kappa_g\), and support-wise EFXWC: whenever \(x_{\theta,S},x_{\theta',R}>0\), every \(g\in R\setminus S\) satisfies \(v_\theta(S\setminus R)\ge v_\theta((R\setminus S)\setminus\{g\})\). Determine whether this can be done with a succinct representation in time polynomial in the type counts and input bit-length, without expanding a common denominator.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(\Theta\) of \(\tau\) complete agent types with positive binary-rational masses \(\mu_\theta\), where \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
Let \(G\) be the set of \(m\) good types, with binary-rational per-capita supplies \(\kappa_g\in[0,1]\). Each agent can receive at most one copy of each good, so bundles are subsets of \(G\).
Each type is specified by its positive binary-rational additive singleton values. Its valuation is leveled: for all \(B,C\subseteq G\), \(|B|>|C|\) implies \(v_\theta(B)>v_\theta(C)\). Equal-cardinality bundles may tie. Let \(L\) be the total input bit length.
An exact allocation kernel has rational entries \(x_{\theta,S}\geq0\), with \(\sum_{S\subseteq G}x_{\theta,S}=\mu_\theta\) and \(\sum_{\theta,S:\,g\in S}x_{\theta,S}=\kappa_g\); all supply must be allocated.
Support-wise EFXWC requires, for every ordered pair \((\theta,S),(\theta',R)\) with positive entries, including pairs of the same type, and every \(g\in R\setminus S\), that \(v_\theta(S\setminus R)\geq v_\theta((R\setminus S)\setminus\{g\})\). If \(R\setminus S=\varnothing\), the requirement is vacuous.
A succinct output is a list of the positive entries, each giving its type, bundle as an \(m\)-bit vector, and binary-rational mass; omitted entries are zero.

Can such an exact EFXWC kernel always be computed with output length and running time polynomial in \(m,\tau,L\), without expanding masses into a population using a common denominator, or is this construction problem NP-hard?

For \(n\) discrete agents with additive leveled valuations and at most \(n\) copies of each good, an exclusive EFXWC allocation can always be found in claimed time \(O(nm^2)\). [Gafni et al.](https://arxiv.org/abs/2109.08671v2)
The later full version retains this result. [Full version](https://purehost.bath.ac.uk/ws/portalfiles/portal/303539554/Goods_with_Copies_for_TEAC_R_R_v2_August_Deadline_-2.pdf) No result settling this exact support-wise mass construction problem was identified in the search.

Modeling choices made when packaging the task

  • Made valuation encoding explicit: each complete type supplies binary-rational singleton values, and L denotes total input bit length.
  • Defined leveled valuations over all exclusive bundles, using strict preference for greater cardinality; this implies positive singleton values. Equal-cardinality ties remain allowed.
  • Fixed the undefined succinct representation as a sparse list of positive rational entries with explicit bundle bit vectors.
  • Made explicit that support-wise fairness compares ordered pairs within the same type as well as across types, and that an empty comparison difference gives a vacuous condition.

Result

The construction problem is polynomial-time solvable. An exact support-wise EFXWC kernel can be computed with at most \(2\tau(m+1)\) positive entries, in time polynomial in \(m,\tau,L\), without expanding the masses into discrete agents.

The key is to maximize the aggregate value received by agents assigned the smaller of two adjacent bundle sizes. This converts the improving-swap principle used in [Theorem 8 of the full version](https://purehost.bath.ac.uk/ws/portalfiles/portal/303539554/Goods_with_Copies_for_TEAC_R_R_v2_August_Deadline_-2.pdf) into a polynomial-size marginal optimization problem.

1. Fixing two bundle sizes

Write \(w_{\theta g}>0\) for the singleton values, so that \(v_\theta(S)=\sum_{g\in S}w_{\theta g}\).

If \(m=0\), output \(x_{\theta,\varnothing}=\mu_\theta\). Henceforth assume \(m\geq1\).

Define

\(K=\sum_{g\in G}\kappa_g,\qquad q=\lfloor K\rfloor,\qquad \alpha=K-q.\)

Thus \(0\leq\alpha<1\). We will assign every agent a bundle of size \(q\) or \(q+1\). For each type, prescribe the masses in these two groups as

\(c_\theta^0=(1-\alpha)\mu_\theta,\qquad c_\theta^1=\alpha\mu_\theta.\)

Group \(0\) receives size-\(q\) bundles, and group \(1\) receives size-\((q+1)\) bundles. Groups of zero mass are omitted. Whenever group \(1\) has positive mass, \(q+1\leq m\).

We first verify that these prescriptions are feasible.

Balanced-distribution lemma. There is a rational probability distribution over subsets of \(G\) whose good marginals are \(\kappa_g\), with total probability \(1-\alpha\) on size-\(q\) bundles and \(\alpha\) on size-\((q+1)\) bundles.

Proof. Order the goods as \(g_1,\ldots,g_m\), and set

\(a_0=0,\qquad a_j=\sum_{i=1}^j\kappa_{g_i}.\)

For \(t\in[0,1)\), define

\(S(t)=\{g_j:\text{ some }z\in\mathbb Z\text{ satisfies }t+z\in[a_{j-1},a_j)\}.\)

Each interval has length at most one, so it contains at most one point of the form \(t+z\). Because these intervals partition \([0,K)\), the cardinality of \(S(t)\) equals the number of such points in \([0,K)\). Consequently,

\(|S(t)|=q+1\text{ if }t<\alpha,\qquad |S(t)|=q\text{ if }t\geq\alpha.\)

The measure of the set of \(t\) for which \(g_j\in S(t)\) is \(\kappa_{g_j}\): split \([a_{j-1},a_j)\) at integers and translate its pieces into \([0,1)\). Their interiors are disjoint and their lengths sum to \(\kappa_{g_j}\).

Finally, \(S(t)\) changes only at the fractional parts of the rational endpoints \(a_j\). Partitioning \([0,1)\) at those endpoints therefore produces a finite distribution with rational probabilities. This proves the lemma.

Giving every type this same distribution, scaled by \(\mu_\theta\), establishes feasibility of the prescribed group masses and supplies.

2. A polynomial-size marginal linear program

For \(\ell\in\{0,1\}\), let \(y_{\theta g}^{\ell}\) denote the mass of type-\(\theta\), group-\(\ell\) agents receiving good \(g\).

Solve the following linear program:

\(\displaystyle \text{maximize }\Phi(y)=\sum_{\theta\in\Theta}\sum_{g\in G}w_{\theta g}y_{\theta g}^{0},\)

subject to

\(0\leq y_{\theta g}^{\ell}\leq c_\theta^\ell\qquad\text{for every }\theta,g,\ell,\)

\(\displaystyle \sum_{g\in G}y_{\theta g}^{\ell}=(q+\ell)c_\theta^\ell\qquad\text{for every }\theta,\ell,\)

\(\displaystyle \sum_{\theta\in\Theta}\sum_{\ell=0}^1y_{\theta g}^{\ell}=\kappa_g\qquad\text{for every }g.\)

There are \(2\tau m\) variables and polynomially many constraints. All coefficients have polynomial binary encoding length. Section 1 proves feasibility, and the coordinate bounds make the feasible region bounded.

Thus the standard polynomial-time theorem for rational linear programming applies: we can compute an exact optimal solution of polynomial encoding length. We may choose an optimal vertex.

The objective counts only the value assigned to the smaller-bundle group. We next show how to recover bundles from the optimized marginals, and then prove fairness.

3. Constructively decomposing the marginals

Fixed-cardinality decomposition lemma. Suppose \(c>0\), \(r\in\{0,\ldots,m\}\), and rational numbers \(h_g\) satisfy

\(0\leq h_g\leq c,\qquad \sum_{g\in G}h_g=rc.\)

Then one can compute, using at most \(m+1\) bundles and polynomially many rational operations, a decomposition

\(\displaystyle h_g=\sum_{S:\,g\in S}p_S,\qquad \sum_Sp_S=c,\qquad p_S>0,\qquad |S|=r.\)

Proof. Maintain residual mass \(c\) and residual marginals \(h_g\) satisfying the displayed conditions.

Choose an \(r\)-element set \(S\) that includes every good with \(h_g=c\) and excludes every good with \(h_g=0\). Such a choice exists: if \(a\) coordinates equal \(c\), then \(a\leq r\); and if \(b\) coordinates are positive, then \(b\geq r\). Both inequalities follow from \(\sum_g h_g=rc\).

Define

\(\displaystyle \delta=\min\bigl(\{h_g:g\in S\}\cup\{c-h_g:g\notin S\}\bigr).\)

Every candidate is positive, and the union contains one candidate for each good. Emit bundle \(S\) with mass \(\delta\), and update

\(c'=c-\delta,\qquad h'_g=h_g-\delta\,\mathbf1_{\{g\in S\}}.\)

For goods in \(S\), the definition of \(\delta\) ensures nonnegativity, while \(h_g\leq c\) gives \(h'_g\leq c'\). For goods outside \(S\), the inequality \(\delta\leq c-h_g\) gives \(h'_g=h_g\leq c'\). Also,

\(\displaystyle \sum_g h'_g=rc-r\delta=rc'.\)

Thus all invariants persist.

If \(\delta=c\), the procedure terminates. Otherwise, a coordinate attaining the minimum becomes either zero or equal to the new residual mass. Every coordinate already at one of these two boundaries remains at a boundary. Consequently, each nonterminating iteration strictly decreases the number of coordinates lying strictly between zero and the residual mass.

There are at most \(m\) such decreases, followed by a terminating iteration. Hence at most \(m+1\) bundles are emitted. The residual identities show that their masses and marginals are exactly the required ones.

Apply this lemma separately to every positive-mass group \((\theta,\ell)\), with

\(c=c_\theta^\ell,\qquad r=q+\ell,\qquad h_g=y_{\theta g}^{\ell}.\)

Merge any repeated entries. The resulting kernel has at most \(2\tau(m+1)\) positive entries. Its type masses and supplies are exact, by the decomposition identities and the LP constraints.

4. Optimality implies support-wise EFXWC

Let \(x\) be the kernel obtained by decomposing an optimal marginal solution.

Consider any ordered pair of positive entries \((\theta,S)\), \((\theta',R)\). This includes \(\theta=\theta'\).

If \(R\setminus S=\varnothing\), the fairness condition is vacuous. Otherwise, fix \(g\in R\setminus S\).

Comparisons with \(|S|\geq|R|\)

We have

\(|S\setminus R|-|(R\setminus S)\setminus\{g\}|=|S|-|R|+1>0.\)

The leveled hypothesis therefore gives

\(v_\theta(S\setminus R)>v_\theta((R\setminus S)\setminus\{g\}).\)

Thus all such comparisons satisfy EFXWC.

Comparisons from a smaller bundle to a larger bundle

The only remaining possibility is

\(|S|=q,\qquad |R|=q+1.\)

Put

\(A=S\setminus R,\qquad D=R\setminus S,\qquad d=|A|.\)

Then \(|D|=d+1\).

If \(d=0\), the set \(D\) is a singleton. Removing its sole good leaves the empty set, so the required inequality holds with equality.

Assume \(d\geq1\). We claim that

\(w_{\theta b}\leq w_{\theta a}\qquad\text{for every }a\in A,\ b\in D.\)

Suppose instead that some \(a\in A\), \(b\in D\) satisfy \(w_{\theta b}>w_{\theta a}\). Choose a positive rational number

\(0<\varepsilon\leq\min\{x_{\theta,S},x_{\theta',R}\}.\)

Transfer mass \(\varepsilon\) from the two original bundles to

\(S'=(S\setminus\{a\})\cup\{b\},\qquad R'=(R\setminus\{b\})\cup\{a\}.\)

These are valid subsets because \(a\in S\setminus R\) and \(b\in R\setminus S\). Their cardinalities remain \(q\) and \(q+1\).

The transfer preserves every type’s mass in each group. It also preserves every good’s total supply: the two transfers exchange equal masses of \(a\) and \(b\). Therefore its marginals constitute another feasible LP solution.

Only the smaller-bundle transfer contributes to the objective change, giving

\(\Phi(y')-\Phi(y)=\varepsilon(w_{\theta b}-w_{\theta a})>0.\)

This contradicts optimality. The argument is unchanged when \(\theta=\theta'\), because the two bundles belong to different cardinality groups. The claim follows.

Now, for every \(g\in D\), additivity gives

\(\displaystyle v_\theta(D\setminus\{g\})\leq d\max_{b\in D}w_{\theta b}\leq d\min_{a\in A}w_{\theta a}\leq\sum_{a\in A}w_{\theta a}=v_\theta(A).\)

This is precisely the required EFXWC inequality.

All ordered support pairs have now been covered. Hence the constructed kernel is support-wise EFXWC.

5. Bit complexity and output length

For completeness, the LP has an especially simple denominator bound.

Its equality matrix has one row for each group and one for each good. Every variable occurs in exactly its group row and its good row. Negating the good rows turns this into a directed node-edge incidence matrix. Such a matrix is totally unimodular: in any square submatrix, a column with at most one nonzero entry permits determinant expansion; if every column has two nonzero entries, their opposite signs make the rows dependent. Induction gives determinants in \(\{0,1,-1\}\).

Appending the coordinate-bound rows preserves this property, by expansion along those unit rows.

Let \(D_0\) be the product of the denominators appearing in the input masses and supplies, and let \(Q=D_0^2\). These numbers are used here only to bound encoding length. In particular,

\(\log Q=O(L).\)

Every LP right-hand side is a multiple of \(1/Q\): this holds for the supplies, for \(c_\theta^\ell\), and for \((q+\ell)c_\theta^\ell\). At a vertex, an invertible matrix of tight constraints has determinant \(1\) or \(-1\). Cramer’s rule therefore shows that every marginal is also a multiple of \(1/Q\). The [standard basic-feasible-solution characterization](https://courses.csail.mit.edu/6.854/21/Notes/n11-lp.html) justifies this description of vertices.

The decomposition procedure uses only comparisons and subtractions. Consequently, every emitted mass remains a multiple of \(1/Q\), lies in \((0,1]\), and has binary encoding length \(O(L)\). If the input rationals are dyadic, these output masses are dyadic as well.

The total output length is therefore

\(O\bigl(\tau(m+1)(m+L+\log(\tau+1))\bigr).\)

The LP has polynomial encoding length and can be solved exactly in polynomial time. The decompositions require \(O(\tau m^2)\) rational operations on polynomial-length numbers. No step enumerates a population whose size is a common denominator.
