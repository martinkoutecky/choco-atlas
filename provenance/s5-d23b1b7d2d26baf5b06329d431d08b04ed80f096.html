The continuous mirror question, as graded

Given \(a\in\mathbb{Q}\cap(0,1)\) and a rational polynomial \(p\) in coefficient-list form, consider a society with type \(A\) of mass \(a\) and null type \(Z\) of mass \(1-a\). For coalition masses \((x_A,x_Z)\in[0,a]\times[0,1-a]\), let worth be \(V(x_A,x_Z)=x_Ap(x_A)\). Compute each type's exact Shapley payoff density, defined as the limit of its finite Shapley payoff multiplied by population size along replications with \(qa\) type-\(A\) members. Is that density \(p(a)\) for \(A\) and \(0\) for \(Z\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) denotes support size, not the number of possible types. Here the support is \(A,Z\), with masses \(a,1-a\), where \(a\in\mathbb Q\cap(0,1)\), so total mass is \(1\) and \(\tau=2\).
Input also includes \(p(t)=\sum_{j=0}^{d}c_jt^j\), given by its coefficient list with arbitrary signed binary rational coefficients. Coalition worth is \(V(x_A,x_Z)=x_Ap(x_A)\) for \((x_A,x_Z)\in[0,a]\times[0,1-a]\).
For every positive integer \(q\) with \(qa\in\mathbb Z\), form a finite game with \(qa\) members of type \(A\) and \(q(1-a)\) members of type \(Z\), each representing mass \(1/q\). Set \(v_q(S)=V(|S\cap A|/q,|S\cap Z|/q)\).
Writing \(\phi_T^{(q)}\) for the ordinary Shapley payoff of a representative member of type \(T\), define \(D_T=\lim_{q\to\infty,\,qa\in\mathbb Z}q\phi_T^{(q)}\), when this limit exists. The computational problem is to compute \((D_A,D_Z)\) exactly. Let \(L\) be the total input bit length; state running times in \(d,\tau,L\). There is no candidate parameter \(m\).

Do these limits exist for every input, and is their exact computation in polynomial time in \(d,\tau,L\), or NP-hard? Do they always satisfy \(D_A=p(a)\) and \(D_Z=0\)?

For finite games whose worth depends only on the number of participating coalition members, exact Shapley allocation takes \(O(n)\) operations, assuming unit-cost evaluation of the worth function ([Muns](https://repub.eur.nl/pub/26085/2011-1242.pdf)).
Existence of asymptotic values for polynomial nonatomic games is known ([Monderer–Neyman](https://doi.org/10.1017/CBO9780511528446.016)); the verified source does not establish the bit complexity of this coefficient-list computation.

Result

For every input, both limits exist and satisfy \(D_A=p(a)\) and \(D_Z=0\). Their exact computation is polynomial-time in \(d,\tau,L\), where \(\tau=2\). In fact, the scaled finite-game payoffs already equal these values for every admissible \(q\).

Exact finite-game payoffs

Fix a positive integer \(q\) such that \(qa\) is an integer. Let \(N_q\) be the player set, with \(k=qa\) type \(A\) players and \(q-k=q(1-a)\) type \(Z\) players. Since \(0<a<1\), both types are present.

For a permutation \(\pi\) of \(N_q\), let \(P_i^\pi\) denote the players preceding player \(i\). The ordinary Shapley payoff is

\(\displaystyle \phi_i^{(q)}=\frac{1}{q!}\sum_\pi\bigl(v_q(P_i^\pi\cup\{i\})-v_q(P_i^\pi)\bigr).\)

We establish three facts directly from this definition.

  • Type \(Z\) players receive zero. Adding a type \(Z\) player leaves the number of type \(A\) players unchanged. Every marginal contribution in the displayed formula is therefore zero, giving \(\phi_Z^{(q)}=0\).
  • All type \(A\) players receive the same payoff. Swapping two type \(A\) players preserves every coalition’s worth. This swap also gives a bijection between permutations and preserves the corresponding marginal contributions. Thus their permutation averages are equal; denote the common value by \(\phi_A^{(q)}\).
  • The payoffs sum to the grand-coalition worth. For each permutation, summing the marginal contributions over its successive players telescopes to \(v_q(N_q)-v_q(\varnothing)\). Here \(v_q(\varnothing)=0\) and \(v_q(N_q)=ap(a)\). Averaging over permutations consequently gives

\(\displaystyle qa\,\phi_A^{(q)}+q(1-a)\,\phi_Z^{(q)}=ap(a).\)

Combining these facts and dividing by \(qa>0\), we obtain

\(\displaystyle \phi_A^{(q)}=\frac{p(a)}{q},\qquad \phi_Z^{(q)}=0.\)

No sign or monotonicity assumption on \(p\) was used.

Write \(a=r/s\) with positive integers \(r<s\). Every positive multiple of \(s\) is an admissible \(q\), so the limiting sequence is unbounded. Since its scaled payoffs are constant,

\(\displaystyle D_A=p(a),\qquad D_Z=0.\)

Exact computation and bit complexity

Represent the input rationals as \(a=r/s\) and \(c_j=b_j/e_j\), where all denominators are positive and the numerators may be signed. Their total encoding length is at most \(L\).

Compute \(p(a)\) by Horner’s rule:

\(\displaystyle y_d=c_d,\qquad y_j=ay_{j+1}+c_j\quad(j=d-1,\ldots,0).\)

Then \(y_0=p(a)\). This requires \(O(d+1)\) rational arithmetic operations. To prove polynomial bit complexity, we bound the integers explicitly.

Use unreduced representations \(y_j=N_j/E_j\), initialized by \(N_d=b_d\), \(E_d=e_d\), and updated by

\(\displaystyle N_j=r e_jN_{j+1}+b_jsE_{j+1},\qquad E_j=se_jE_{j+1}.\)

These updates implement Horner’s rule exactly. Moreover,

\(\displaystyle E_j=s^{d-j}\prod_{k=j}^{d}e_k,\qquad y_j=\sum_{k=j}^{d}c_ka^{k-j}.\)

Because the input integers collectively use at most \(L\) bits,

\(\displaystyle \log_2E_j\le dL+L.\)

Also, \(0<a<1\) and \(|c_k|\le 2^L\), so

\(\displaystyle |y_j|\le(d+1)2^L.\)

Therefore the numerators, denominators, and temporary arithmetic results have at most

\(\displaystyle B=O\bigl((d+1)L\bigr)\)

bits. Using schoolbook integer arithmetic, Horner evaluation costs \(O((d+1)B^2)\) bit operations.

If a reduced fraction is required, compute \(\gcd(|N_0|,E_0)\) and divide both integers by it. Euclid’s algorithm uses \(O(B)\) divisions: within every two remainder steps, the relevant positive remainder decreases by at least a factor of two. Each division costs at most \(O(B^2)\), giving the conservative bound \(O(B^3)\) for reduction.

Thus a complete algorithm, including input reading and reduced output, has bit running time

\(\displaystyle O\bigl(L+\tau+(d+1)^3L^3\bigr),\qquad \tau=2.\)

Its output length is \(O((d+1)L)\). It constructs no finite game and introduces no additional parameter.

Relation to the cited finite-game result

The finite-game identity also fits [Muns, Proposition 1](https://repub.eur.nl/pub/26085/2011-1242.pdf): take the participating players to be type \(A\) and set \(f_q(k)=p(k/q)/q\). Then \(v_q(S)=k_Sf_q(k_S)\), so each participating player receives \(f_q(qa)=p(a)/q\).

The proof above independently establishes the finite identities and limits, while the integer-size analysis establishes polynomial bit complexity for the coefficient-list input. Consequently, the computational problem is polynomial-time solvable; NP-hardness under polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).
