Proposition 4.4 — class: algorithmic

The continuous mirror question, as graded

Given a bipartite graph of supported types with rational masses \(\mu_i\) summing to \(1\) on each side, quotas \(q_i\), and rational pair-capacity densities \(\beta_{ij}\), find a stable density vector \(y\), where \(0\le y_{ij}\le\beta_{ij}\) and the total assignment mass between types \(i,j\) is \(\mu_i\mu_j y_{ij}\). Type \(i\)'s assignment uses \(\sum_j\mu_j y_{ij}\le q_i\); its diversifying choice rule cuts offered densities at a common threshold, weighted by counterpart masses, to fill \(q_i\) when possible. A filled type’s head consists of incident pairs attaining its maximum density, while an underfilled type has an empty head; a pair blocks when it is below capacity and outside both endpoint heads. Can the unique stable density vector be computed exactly in time polynomial in the number of supported types \(\tau\), type pairs \(a\), and binary input length \(L\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. The supported types form the vertices of a simple bipartite graph \(G=(F\cup W,E)\), with \(m=\tau\) vertices and \(a=|E|\) supported pairs. Masses satisfy \(\sum_{i\in F}\mu_i=\sum_{j\in W}\mu_j=1\). Quotas \(q_i\) and capacities \(\beta_{ij}\) are arbitrary nonnegative binary rationals; \(L\) is the total binary input length.
For each incident offered density vector \(z\), with \(0\le z_{ij}\le\beta_{ij}\), type \(i\) chooses \(C_i(z)=z\) if \(\sum_{j:ij\in E}\mu_jz_{ij}\le q_i\); otherwise \(C_i(z)_{ij}=\min\{z_{ij},r\}\), where \(r\ge0\) satisfies \(\sum_{j:ij\in E}\mu_j\min\{z_{ij},r\}=q_i\). The same definition applies on both sides.
An assignment is a real density vector \(y\) satisfying \(0\le y_{ij}\le\beta_{ij}\) and \(s_i(y):=\sum_{j:ij\in E}\mu_jy_{ij}\le q_i\) for every type. Its mass on pair \(ij\) is \(\mu_i\mu_jy_{ij}\); \(q_i\) is a quota per unit mass of type \(i\).
If \(s_i(y)=q_i\), let \(H_i(y)\) contain all incident pairs attaining the maximum incident density; if \(s_i(y)<q_i\), or \(i\) is isolated, set \(H_i(y)=\varnothing\). Thus all maximum-density ties belong to the head. A pair \(ij\) blocks precisely when \(y_{ij}<\beta_{ij}\) and \(ij\notin H_i(y)\cup H_j(y)\); an assignment is stable if no pair blocks.

Is exact computation of a stable density vector possible in time polynomial in \(m=\tau\), \(a\), and \(L\), or is this search problem NP-hard?

For finite-agent diversifying assignments with unweighted incident sums and real capacities and quotas, stability is unique and an algorithm uses \(O(a^2)\) iterations of \(O(a)\) time each. [Karzanov](https://arxiv.org/abs/2308.09797v2)

Result

Exact computation is polynomial-time solvable. A progressive-filling algorithm constructs a stable density vector in at most \(a\) stages, using \(O(a(a+m))\) rational arithmetic operations. All intermediate numbers have polynomial bit length. Moreover, the stable vector is unique.

The [cited paper by Karzanov](https://arxiv.org/html/2308.09797v2) treats unweighted incident sums. The proof below handles the weighted constraints directly.

1. Algorithm

Write \(V=F\cup W\), and let \(E_v\) denote the edges incident to \(v\). For an edge \(e=vu\), its coefficient in the quota constraint at \(v\) is \(\mu_u>0\).

Maintain an active edge set \(A\). Every edge outside \(A\) already has its permanent density \(y_e\). All active edges share a current density level \(p\).

Initially, set \(A=E\) and \(p=0\). If \(E=\varnothing\), return the empty vector.

For each vertex \(v\), define

\(c_v=\sum_{vu\in E_v\setminus A}\mu_u y_{vu},\qquad d_v=\sum_{vu\in E_v\cap A}\mu_u.\)

Thus assigning density \(t\) to every active edge gives load \(c_v+d_vt\) at \(v\).

While \(A\ne\varnothing\), perform the following steps:

  • Compute the next level

\(t=\min\left(\{\beta_e:e\in A\}\cup\left\{\frac{q_v-c_v}{d_v}:v\in V,\ d_v>0\right\}\right).\)

  • Define the vertices whose quotas become tight:

\(T=\{v\in V:d_v>0,\ c_v+d_vt=q_v\}.\)

  • Freeze every active edge that reaches capacity or touches a vertex in \(T\):

\(B=\{e\in A:\beta_e=t\}\cup\bigcup_{v\in T}(E_v\cap A).\)

  • Set \(y_e=t\) permanently for every \(e\in B\), replace \(A\) by \(A\setminus B\), and set \(p=t\).

All simultaneous events are processed together.

2. Feasibility and termination

We prove the following invariant at the start of every stage:

  • Every frozen density lies between \(0\) and \(p\).
  • The vector consisting of the frozen densities and density \(p\) on every active edge is feasible.

The invariant holds initially because the zero vector is feasible.

Assume it holds at the start of a stage. For every active edge, feasibility gives \(\beta_e\ge p\). For every vertex with \(d_v>0\), feasibility gives

\(c_v+d_vp\le q_v,\)

and hence

\(\frac{q_v-c_v}{d_v}\ge p.\)

Consequently, \(t\ge p\). By the definition of \(t\), assigning density \(t\) to every active edge respects every active capacity and every quota with \(d_v>0\). For vertices with \(d_v=0\), the load remains \(c_v\), which was already feasible.

Freezing the edges in \(B\) does not change this vector. Therefore the invariant holds at the next stage.

The minimum defining \(t\) is attained, since its candidate set is finite and contains an active capacity. If a capacity attains it, its edge belongs to \(B\). Otherwise a quota candidate attains it at a vertex with \(d_v>0\); that vertex has an active incident edge because all masses are positive. Thus \(B\ne\varnothing\).

At least one edge is frozen per stage, so the algorithm terminates after at most \(a\) stages. Its final vector is feasible.

Zero quotas and zero capacities simply produce events at level \(0\). Isolated vertices require no special operation.

3. Stability

Consider an edge \(e=vu\) in the final vector.

If it was frozen at its capacity, then \(y_e=\beta_e\), so it cannot block.

Otherwise it was frozen at some level \(t\) because an endpoint, say \(v\), belonged to \(T\). At that stage:

  • Every previously frozen edge incident to \(v\) had density at most \(t\), by the invariant.
  • Every active edge incident to \(v\) was frozen at density \(t\).
  • The load at \(v\) was exactly \(q_v\).

After that stage, no incident edge of \(v\) remains active. Therefore its final load is still \(q_v\), and its maximum incident density is \(t\). In particular,

\(e\in H_v(y).\)

Every edge below capacity thus belongs to the head of at least one endpoint. By the stated blocking definition, no edge blocks. The output is stable.

4. Uniqueness

Although uniqueness is unnecessary for the complexity conclusion, it follows from the same stages.

Let \(z\) be any stable vector. We prove inductively that \(z\) agrees with the algorithm on every frozen edge. Initially this is vacuous.

Consider a stage, assuming agreement on all previously frozen edges, and let \(t\) be its next level.

First, every active edge satisfies \(z_e\ge t\). Indeed, suppose an active edge \(e=vu\) satisfied \(z_e<t\). Since \(\beta_e\ge t\), it is below capacity in \(z\). Stability therefore places it in the head of some endpoint, say \(v\). This means

\(s_v(z)=q_v\)

and every edge incident to \(v\) has density at most \(z_e\) in \(z\). Using agreement on frozen edges gives

\(s_v(z)=c_v+\sum_{vw\in E_v\cap A}\mu_w z_{vw} \le c_v+d_vz_e <c_v+d_vt \le q_v.\)

The strict inequality holds because \(e\) is active and \(\mu_u>0\), so \(d_v>0\). This contradicts \(s_v(z)=q_v\).

Now consider the edges frozen at this stage.

  • If an edge reaches capacity, then \(t\le z_e\le\beta_e=t\), so \(z_e=t\).
  • If a vertex \(v\) becomes tight, feasibility of \(z\) gives

\(c_v+\sum_{vw\in E_v\cap A}\mu_wz_{vw}\le q_v=c_v+d_vt.\)
Every active incident density is at least \(t\), and every coefficient is positive. Thus each such density must equal \(t\).

Hence \(z\) agrees on all newly frozen edges. Induction through termination proves \(z=y\).

5. Exact bit complexity

The stage count alone is insufficient for a binary-input complexity bound; we also bound intermediate rational sizes.

Let \(D\) be the product of the denominators of all input masses, quotas, and capacities, using their binary numerator–denominator representations. Then \(\log_2D=O(L)\). Define integers

\(M_u=D\mu_u,\qquad Q_v=Dq_v,\qquad K_e=D\beta_e.\)

These integers have \(O(L)\) bits. Multiplying each quota constraint by \(D\) gives

\(\sum_{vu\in E_v}M_u y_{vu}\le Q_v.\)

Maintain a common denominator \(R\) for all frozen densities, initially \(R=D\). Write a frozen density as \(y_e=N_e/R\).

For an active vertex, set

\(S_v=\sum_{vu\in E_v\cap A}M_u,\qquad A_v=\sum_{vu\in E_v\setminus A}M_uN_{vu}.\)

Its quota candidate is exactly

\(t_v=\frac{Q_vR-A_v}{RS_v}.\)

Because the graph is simple and the opposite-side masses sum to \(1\), we have \(1\le S_v\le D\) whenever \(S_v>0\).

If the selected level is a capacity candidate \(K_e/D\), it already has denominator dividing \(R\). If it is a quota candidate, replacing \(R\) by \(RS_v\) makes both all previous frozen values and the new level representable over the new common denominator. Therefore, after at most \(a\) stages,

\(R\le D^{a+1},\qquad \log_2R=O((a+1)L).\)

All output densities are bounded by the largest input capacity, whose magnitude is at most \(2^{O(L)}\). Their numerators over \(R\) consequently have \(O((a+1)L)\) bits.

For quota candidates, feasibility and nonnegativity imply

\(0\le A_v\le Q_vR.\)

Thus candidate numerators, denominators, and the integer cross-products used for comparisons also have polynomial bit length. Computing sums over a common denominator avoids any unnecessary denominator growth.

Each stage can recompute the vertex sums, compare candidates, and identify frozen edges in \(O(a+m)\) arithmetic operations. With at most \(a\) stages and polynomial-size operands, the total bit running time is polynomial in \(m\), \(a\), and \(L\).

Conclusion

The mass-weighted density problem admits an exact polynomial-time algorithm. The algorithm works directly on the supported types and pairs, and returns the unique stable density vector.
