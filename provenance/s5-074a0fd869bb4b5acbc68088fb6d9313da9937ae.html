The continuous mirror question, as graded

Given agent types \(a\) with rational masses \(\mu_a\) summing to \(1\), additive utilities \(u_a(j)\), task types \(j\) with rational per-capita supplies \(q_j\), a threshold \(\eta\), and a conflict graph that is the union of three cliques, decide whether there are nonnegative rational variables \(x_{a,B}\) for bundles \(B\) that contain at most one task from each clique and satisfy \(\sum_{B\in\mathcal B_a}x_{a,B}=\mu_a\) for every \(a\), \(\sum_a\sum_{B\in\mathcal B_a}x_{a,B}\mathbf 1[j\in B]\le q_j\) for every \(j\), and \(\sum_{j\in B}u_a(j)\ge\eta\) for every allowed bundle \(B\in\mathcal B_a\). Each unit of population receives an integral bundle.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\ge1\) agent types with positive binary-rational masses \(\mu_a\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\) task types, partitioned into three nonempty sets \(C_1,C_2,C_3\); the conflict graph has exactly the edges within these sets. Input utilities are additive, with \(u_a(j)\in\mathbb Z_{\ge0}\); supplies are \(q_j\in\mathbb Q_{\ge0}\), and the common threshold is \(\eta\in\mathbb Z_{>0}\). All numbers are binary encoded; let \(L\) be the total input bit length.
Define \(\mathcal B_a=\{B\subseteq\{1,\ldots,m\}: |B\cap C_i|\le1\text{ for every }i,\ \sum_{j\in B}u_a(j)\ge\eta\}\).
Feasibility means that rational masses \(x_{a,B}\ge0\), indexed by \(B\in\mathcal B_a\), satisfy \(\sum_{B\in\mathcal B_a}x_{a,B}=\mu_a\) for every type and \(\sum_a\sum_{B\in\mathcal B_a:j\in B}x_{a,B}\le q_j\) for every task type. Each individual receives an integral bundle containing at most one copy of each task type; a type's population may split among bundles, and supplies may remain unused.

Is this continuous feasibility problem in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

The finite-agent version with indivisible tasks and pairwise disjoint bundles is \(\mathrm{NP}\)-complete for three disjoint cliques, even with identical positive-integer utilities across agents ([source](https://arxiv.org/pdf/2309.04995v1)).
No result settling exactly this continuous formulation was identified in the literature search.

Modeling choices made when packaging the task

  • The utility and threshold domains were unspecified: utilities are nonnegative integers and the threshold is a positive integer, following the discrete input domains and interpreting natural-number utilities to allow zero.
  • The clique structure was ambiguous: task types form exactly three nonempty, vertex-disjoint cliques, with no edges between cliques.
  • Supply signs were unspecified: supplies are nonnegative binary rationals, without a normalization on their sum.
  • The allowed bundle families were undefined: each family contains every conflict-free subset meeting that type's threshold, including eligible singleton and two-task bundles.
  • Task multiplicity within an individual's bundle was implicit: each task type appears at most once, as in the discrete subset definition.
  • The encoding size was undefined: L is the total input bit length, including utilities, supplies, masses, threshold, and clique partition.

Conclusion

The stated continuous feasibility problem belongs to \(\mathrm P\), with running time polynomial in \(m,\tau,L\). The key is that three cliques allow only polynomially many distinct bundles, so the defining linear program can be constructed explicitly.

1. Enumerating all admissible bundles

Write \(n_i=|C_i|\), and introduce a symbol \(\bot\) meaning that no task is selected from a clique. Every conflict-free bundle corresponds uniquely to a tuple in

\((C_1\cup\{\bot\})\times(C_2\cup\{\bot\})\times(C_3\cup\{\bot\})\),

by deleting all occurrences of \(\bot\). This correspondence holds because a bundle contains at most one task from each clique, and there are no conflicts between different cliques.

Consequently, the number of candidate bundles is exactly

\(K=(n_1+1)(n_2+1)(n_3+1)\le(m+1)^3.\)

For each of the \(\tau\) listed agent types, enumerate these candidates and retain precisely those satisfying \(\sum_{j\in B}u_a(j)\ge\eta\). This constructs \(\mathcal B_a\) exactly.

Each candidate contains at most three tasks. Its utility can therefore be checked using at most three additions and one comparison of binary integers. The integers involved have bit length at most \(L+2\). Thus all bundle families can be constructed in time polynomial in \(m,\tau,L\).

If any \(\mathcal B_a\) is empty, return infeasible: its positive mass \(\mu_a\) cannot be assigned an acceptable bundle.

2. An explicit linear program

Otherwise, introduce one variable \(x_{a,B}\) for every listed type \(a\) and every \(B\in\mathcal B_a\). The number of variables satisfies

\(N=\sum_{a=1}^{\tau}|\mathcal B_a|\le\tau(m+1)^3.\)

Construct the following system:

  • \(x_{a,B}\ge0\) for every variable;
  • \(\sum_{B\in\mathcal B_a}x_{a,B}=\mu_a\) for every type \(a\);
  • \(\sum_{a=1}^{\tau}\sum_{B\in\mathcal B_a:\,j\in B}x_{a,B}\le q_j\) for every task type \(j\).

This system is exactly the feasibility system in the question. Enumeration includes every acceptable integral bundle and excludes every unacceptable bundle. The variables describe population masses assigned to those bundles, so allowing fractional variables preserves the required integrality of each individual's bundle.

Replace each equality by two inequalities and each nonnegativity constraint by \(-x_{a,B}\le0\). The resulting system has \(N\) variables and \(2\tau+m+N\) inequalities. Every matrix coefficient belongs to \(\{-1,0,1\}\); every right-hand side is zero or an input rational, possibly negated. Hence its complete binary encoding has length polynomial in \(m,\tau,L\), even using a dense matrix representation.

3. Exact polynomial-time feasibility

We use the standard rational linear-programming theorem: given a rational matrix \(A\) and rational vector \(b\), feasibility of \(Ax\le b\) can be decided in time polynomial in their total binary encoding length; if feasible, a rational feasible point can be produced. This is the polynomial-time solvability theorem originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here: the system is finite, explicitly constructed, has rational data, and has polynomial encoding length. Applying the theorem therefore decides the required rational feasibility in polynomial time. The preceding enumeration and construction also take polynomial time, completing the proof.

The finite-agent hardness cited in the question concerns [pairwise disjoint assignments of indivisible tasks](https://arxiv.org/pdf/2309.04995v1). In that setting, bundle-selection variables must satisfy additional discrete restrictions. In the present formulation, population masses may split among bundles, and the explicit linear program already captures all requirements.
