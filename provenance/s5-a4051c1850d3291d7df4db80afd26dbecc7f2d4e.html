The continuous mirror question, as graded

Given rational finite agent types \(T\) with masses \(\mu_t\), finite good types \(G\) with per-capita supplies \(q_g\), and additive utilities \(u_t(g)\), choose masses \(x_{t,b}\) over integral bundles \(b\in\mathbb{Z}_{\ge 0}^{G}\), satisfying \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}b_gx_{t,b}=q_g\), to maximize \(\sum_{t,b}x_{t,b}u_t(b)\), subject to every positive-mass bundle being \(\mathrm{PROP1}\): \(u_t(b)+\max_{g:q_g>0}u_t(g)\ge R_t:=\sum_g q_g u_t(g)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau=|T|\) types with positive masses \(\mu_t\) encoded as binary rationals, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m=|G|\geq1\) good types with positive binary-rational per-capita supplies \(q_g\), and nonnegative binary-rational additive utilities \(u_t(g)\); utility totals need not be equal across types. Let \(L\) be the total input bit length, including a rational welfare threshold \(K\).
An allocation assigns nonnegative real masses \(x_{t,b}\) to integral bundles \(b\in\mathbb Z_{\geq0}^{G}\), with \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}b_gx_{t,b}=q_g\) for every good type. Bundle multiplicities have no additional upper bounds.
Write \(u_t(b)=\sum_g b_gu_t(g)\), \(R_t=\sum_gq_gu_t(g)\), and \(M_t=\max_{g\in G}u_t(g)\). Every bundle with \(x_{t,b}>0\) must satisfy the mass-model PROP1 condition \(u_t(b)+M_t\geq R_t\).
Welfare is \(W(x)=\sum_{t,b}x_{t,b}u_t(b)\); the decision problem asks whether a feasible allocation has \(W(x)\geq K\).

Is this decision problem in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it NP-hard?

For discrete indivisible goods, maximizing utilitarian welfare subject to PROP1 is NP-hard even for two agents with unrestricted utility totals, and strongly NP-hard with an unrestricted number of agents. [Source](https://arxiv.org/html/2012.03979v3)
No result settling this exact distribution-over-types problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total population mass to one, so the stated per-capita reference utility is the proportional share.
  • Specified nonnegative rational utilities, allowing zero values and imposing no equality of utility totals, consistent with the discrete setting.
  • Retained only positive-supply good types and required a nonempty good-type set, making the maximum in the fairness condition defined.
  • Specified allocation masses as nonnegative reals over all integral bundles, without an additional bound on bundle multiplicities.
  • Retained the graded question's maximum over positive-supply types: in an atomless society, an individual's finite bundle does not exhaust the external supply of any such type.
  • Introduced a binary-rational welfare threshold to state the exact optimization question in decision form; infeasible instances answer no.
  • Kept the graded question's arbitrary support size rather than restricting it to two types.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Theorem. The decision problem is \(\mathrm{NP}\)-hard, even when the support consists of exactly \(\tau=2\) types and all utilities are positive integers. Consequently, a running time polynomial in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).

1. Source problem. We reduce from Unbounded Subset Sum: given positive binary-encoded integers \(a_1,\ldots,a_n,B\), decide whether

\(\displaystyle \sum_{i=1}^{n}a_i b_i=B\)

has a solution \(b_1,\ldots,b_n\in\mathbb Z_{\geq0}\). This problem is \(\mathrm{NP}\)-hard even with \(a_i<B\) for every \(i\). This precise source problem and restriction are stated in [Aggarwal, Joux, Santha, and Węgrzycki](https://arxiv.org/html/2407.05435v1).

Fix such an instance, and define

\(\displaystyle M=\max_i a_i,\qquad s=B-M>0.\)

2. Construction. Create two types \(A,C\), with masses

\(\displaystyle \mu_A=\mu=\frac{s}{2nB},\qquad \mu_C=\nu=1-\mu.\)

Since \(0<s<B\), we have \(0<\mu<1/2\), so both masses are positive.

Create \(n\) original good types and one auxiliary good type \(d\). Set their supplies and utilities as follows:

| Good type | Supply | Utility for \(A\) | Utility for \(C\) |
|---|---:|---:|---:|
| \(i\in\{1,\ldots,n\}\) | \(\displaystyle q_i=\frac{s}{na_i}\) | \(a_i\) | \(2a_i\) |
| \(d\) | \(q_d=2\) | \(M\) | \(4B\) |

All supplies are positive. For type \(A\),

\(\displaystyle M_A=M,\qquad R_A=\sum_i q_i a_i+2M=s+2M=B+M.\)

Thus its PROP1 requirement is exactly

\(\displaystyle u_A(b)\geq B.\)

For type \(C\),

\(\displaystyle M_C=4B,\qquad R_C=\sum_i q_i(2a_i)+2(4B)=2s+8B.\)

Write \(H=2s+8B\), and choose the welfare threshold

\(\displaystyle K=H-\mu B.\)

3. Welfare forces an exact subset-sum witness. For any integral bundle \(b\), define its opportunity cost relative to type \(C\) by

\(\displaystyle c(b)=u_C(b)-u_A(b)=\sum_i a_i b_i+(4B-M)b_d.\)

Equivalently,

\(\displaystyle c(b)=u_A(b)+(4B-2M)b_d.\)

Because \(M<B\), the coefficient \(4B-2M\) is strictly positive. Every occupied bundle of type \(A\) therefore satisfies

\(\displaystyle c(b)\geq B.\)

For every allocation satisfying the supply equalities, welfare has the exact identity

\(\displaystyle W(x)=\sum_g q_g u_C(g)-\sum_b x_{A,b}\bigl(u_C(b)-u_A(b)\bigr) =H-\sum_b x_{A,b}c(b). \)

Indeed, the first term values all allocated goods using type \(C\)'s utilities; the second corrects the valuation of goods allocated to type \(A\). All these sums are finite: for each type and good, its allocated quantity is bounded by the finite total supply.

Since type \(A\) has mass \(\mu\), PROP1 gives

\(\displaystyle \sum_b x_{A,b}c(b)\geq\mu B,\qquad W(x)\leq K.\)

Suppose a feasible allocation satisfies \(W(x)\geq K\). Equality must hold, so

\(\displaystyle \sum_b x_{A,b}\bigl(c(b)-B\bigr)=0.\)

Every summand is nonnegative. Consequently, every bundle with \(x_{A,b}>0\) satisfies \(c(b)=B\). But

\(\displaystyle c(b)-B=\bigl(u_A(b)-B\bigr)+(4B-2M)b_d,\)

where both terms are nonnegative. Thus every such bundle satisfies \(b_d=0\) and

\(\displaystyle \sum_i a_i b_i=B.\)

At least one such bundle exists because \(\mu>0\). It provides an Unbounded Subset Sum witness. This argument permits arbitrary real allocation masses and infinite bundle support.

4. A subset-sum witness yields a feasible allocation. Conversely, suppose \(b_1,\ldots,b_n\in\mathbb Z_{\geq0}\) satisfy \(\sum_i a_i b_i=B\).

Assign all mass \(\mu\) of type \(A\) the bundle \((b_1,\ldots,b_n,0)\). Its utility is \(B\), so it satisfies PROP1.

For each original good, \(a_i b_i\leq B\), hence

\(\displaystyle \mu b_i\leq\frac{\mu B}{a_i}=\frac{s}{2na_i}=\frac{q_i}{2}.\)

Thus the remaining supplies are nonnegative. The required conditional mean bundle for type \(C\) is

\(\displaystyle y_i=\frac{q_i-\mu b_i}{\nu},\qquad y_d=\frac{2}{\nu}.\)

We now realize this vector by a distribution over integral bundles. For each coordinate \(g\), independently choose \(\lfloor y_g\rfloor\) or \(\lfloor y_g\rfloor+1\), assigning probability \(y_g-\lfloor y_g\rfloor\) to the latter. This distribution has finite support, nonnegative integral coordinates, and mean exactly \(y\). Assign it to type \(C\), multiplied by mass \(\nu\).

The resulting allocation has the required type masses and uses every supply exactly.

Moreover, \(\nu<1\) implies \(y_d>2\). Therefore every occupied type-\(C\) bundle contains at least two copies of \(d\), giving utility at least \(8B\). Its PROP1 requirement holds because

\(\displaystyle u_C(b)+M_C\geq8B+4B=12B>2s+8B=R_C,\)

where \(s<B\).

Finally, type \(A\)'s bundle has opportunity cost \(B\), so the welfare identity gives

\(\displaystyle W(x)=H-\mu B=K.\)

5. Encoding size and conclusion. The construction uses \(m=n+1\) good types and exactly two supported types. Every numerator, denominator, utility, and threshold has binary length bounded by a polynomial in the source input length. In particular,

\(\displaystyle q_i=\frac{s}{na_i},\qquad \mu=\frac{s}{2nB},\qquad K=2s+8B-\frac{s}{2n}.\)

The entire transformation therefore takes polynomial time.

We have proved both directions:

\(\displaystyle \exists\,b\in\mathbb Z_{\geq0}^{n}\ \sum_i a_i b_i=B \quad\Longleftrightarrow\quad \exists\,x\text{ feasible with }W(x)\geq K. \)

This establishes \(\mathrm{NP}\)-hardness for the exact distribution-over-types problem.
