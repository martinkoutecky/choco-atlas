Proposition 2 — class: algorithmic

The continuous mirror question, as graded

Given rational masses \(\mu_t>0\) over \(\tau\) jurisdiction types, per-unit entitlements \(p_t\), bounds, and per-capita supply \(\bar h\), let \(\mathcal A\) be the explicitly listed feasible vectors \(q\in\mathbb Z_{\ge 0}^{\tau}\) satisfying \(\sum_t\mu_t q_t=\bar h\) and, whenever \(p_t\le p_u\), \(q_t\le q_u\) and \(q_t/p_t\ge q_u/p_u\). Compute the unions of lexicographic maxima and minima of \(\mathcal A\) over all permutations of the type coordinates, together with the remaining neutral vectors and witnesses for the extrema.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) jurisdiction types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a positive binary rational entitlement \(p_t\) and integer bounds \(0\le a_t\le b_t\); the per-capita supply \(\bar h\) is a positive binary rational.
The input explicitly lists the nonempty set \(\mathcal A\) of all vectors \(q\in\mathbb Z_{\ge0}^{\tau}\) satisfying \(a_t\le q_t\le b_t\), \(\sum_t\mu_tq_t=\bar h\), and, whenever \(p_t\le p_u\), both \(q_t\le q_u\) and \(q_t/p_t\ge q_u/p_u\). Equal entitlements therefore require equal allocations.
Let \(m=|\mathcal A|\), and let \(L\) be the total binary input length, including the listed vectors. Each vector specifies one integer allocation per type.
For each permutation \(\pi\) of the type coordinates, let \(q^+_\pi\) and \(q^-_\pi\) be the unique lexicographic maximum and minimum of \(\mathcal A\), comparing coordinates in order \(\pi\).
Compute \(F=\bigcup_\pi\{q^+_\pi\}\), \(D=\bigcup_\pi\{q^-_\pi\}\), and \(N=\mathcal A\setminus(F\cup D)\), with one witnessing permutation for each vector in each of \(F\) and \(D\).

Can these sets and witnesses be computed in time polynomial in \(m\), \(\tau\), and \(L\), or is this computation NP-hard?

For discrete allocations supplied as an explicit list, published worst-case operation bounds for computing the extrema and neutral vectors contain factorial dependence on the number of coordinates; they do not establish polynomial-time complexity. The algorithms also cover arbitrary finite vector sets. [Łyko et al.](https://doi.org/10.3390/sym13071269)
No polynomial-time or NP-hardness classification for this mass-weighted explicit-list problem was located in the search.

Result

The sets and witnesses can be computed in polynomial time. Specifically, there is an algorithm using \(O(m^2\tau^2)\) integer comparisons and \(O(m^2\tau^2L)\) bit operations.

The algorithm works for every explicitly listed finite set of distinct integer vectors. Consequently, the mass, entitlement, and feasibility restrictions in the question satisfy its hypotheses without requiring any additional argument.

1. Testing one candidate maximum

Fix \(x\in\mathcal A\). We construct a coordinate order under which \(x\) is the lexicographic maximum, or prove that no such order exists.

Maintain:

  • An ordered prefix \(P\) of selected coordinates, initially empty.
  • The set \(U\) of unused coordinates, initially \(\{1,\ldots,\tau\}\).
  • A residual set \(R\), initially \(\mathcal A\).

Call an unused coordinate \(i\) admissible when \(x_i\ge y_i\) for every \(y\in R\).

Perform the following steps:

  • If \(R=\{x\}\), append the coordinates in \(U\) in any order and return the resulting permutation.
  • If no coordinate in \(U\) is admissible, return failure.
  • Otherwise, choose any admissible coordinate \(i\), append it to \(P\), remove it from \(U\), and replace \(R\) by \(\{y\in R:y_i=x_i\}\).
  • Repeat.

There are at most \(\tau\) coordinate selections. Throughout the algorithm, \(x\in R\), and \(R\) consists exactly of those listed vectors agreeing with \(x\) on every selected coordinate. These assertions follow immediately by induction from the filtering rule.

In particular, if every coordinate has been selected, then \(R=\{x\}\), since the listed vectors are distinct.

2. Proof of correctness

Success produces a witnessing permutation

Suppose the algorithm returns a permutation \(\pi\). Consider any \(y\in\mathcal A\setminus\{x\}\).

Because the residual set eventually becomes \(\{x\}\), there is a first selected coordinate \(i\) at which \(y\) is removed. Immediately before that selection, \(y\in R\), so it agrees with \(x\) on all previously selected coordinates.

Admissibility gives \(x_i\ge y_i\). Removal means \(x_i\ne y_i\), hence \(x_i>y_i\).

Thus the first coordinate in \(\pi\) where \(x\) and \(y\) differ favors \(x\). Therefore \(x>_{\mathrm{lex},\pi}y\). This holds for every other listed vector, proving that \(x=q^+_\pi\).

Failure rules out every permutation

Suppose the algorithm fails. Let \(S\) be the set of selected coordinates, so \(U=\{1,\ldots,\tau\}\setminus S\).

The set \(U\) is nonempty: otherwise all residual vectors would agree with \(x\) everywhere, and the algorithm would have succeeded.

Since no unused coordinate is admissible, for every \(i\in U\) there is a vector \(y^{(i)}\in R\) with \(y^{(i)}_i>x_i\). Every such vector agrees with \(x\) on all coordinates in \(S\).

Now take any permutation \(\sigma\), regardless of the prefix constructed by the algorithm. Let \(i\) be the first coordinate of \(\sigma\) belonging to \(U\). Every preceding coordinate belongs to \(S\), where \(y^{(i)}\) agrees with \(x\). At coordinate \(i\), the vector \(y^{(i)}\) has the larger entry.

Consequently, \(y^{(i)}>_{\mathrm{lex},\sigma}x\). Hence \(x\) is not the maximum for \(\sigma\). Since \(\sigma\) was arbitrary, \(x\notin F\).

These two arguments establish that the test succeeds if and only if \(x\in F\), and that every returned permutation is a valid witness. In particular, arbitrary choices among admissible coordinates require no backtracking.

3. Minimum witnesses and the complete classification

For each permutation \(\pi\), negation reverses lexicographic comparisons: \(x<_{\mathrm{lex},\pi}y\) if and only if \(-x>_{\mathrm{lex},\pi}(-y)\).

Therefore, applying the maximum test to \(-x\) in the explicitly represented set \(-\mathcal A\) decides whether \(x\in D\), and returns a witnessing permutation for the minimum. Equivalently, use the same algorithm with admissibility defined by \(x_i\le y_i\) for all residual vectors.

Run both tests for every \(x\in\mathcal A\). Record successful maximum tests in \(F\), successful minimum tests in \(D\), and their respective witnessing permutations. Then compute \(N=\mathcal A\setminus(F\cup D)\).

The two tests are independent, so a vector belonging to both sets receives both witnesses. This also handles \(m=1\): the sole vector belongs to both \(F\) and \(D\), with any permutation witnessing each membership.

4. Complexity and conclusion

For one candidate and one direction, there are at most \(\tau\) rounds. Finding an admissible coordinate by scanning all unused coordinates against all residual vectors uses at most \(m\tau\) comparisons per round. Filtering costs at most another \(m\) comparisons.

Thus one test uses \(O(m\tau^2)\) comparisons, and all \(2m\) tests use \(O(m^2\tau^2)\) comparisons.

Each allocation entry has at most \(L\) bits, so each integer comparison costs \(O(L)\) bit operations. Bookkeeping and writing the at most \(2m\) witnessing permutations also fit within the stated polynomial bound.

The factorial operation bounds discussed in the cited [Łyko et al. paper](https://doi.org/10.3390/sym13071269) therefore do not prevent a polynomial algorithm for this task. The proof above settles the explicit-list problem directly, without needing the allocation constraints beyond their guarantee that the input is a finite list of feasible vectors.
