The continuous mirror question, as graded

Given a finite set \(O\) of benefit types and a rational distribution \(\mu\) over patient types, where each type \(t\) specifies a finite π-net \(\mathcal N_t\), an explicitly listed finite context \(M_t\), and benefit multisets \(A_t,B_t\subseteq M_t\) induced by the same two treatment options, determine whether \(\sum_{t:\,A_t>_{\mathcal N_t}^{M_t}B_t}\mu_t\ge q\), where \(A_t>_{\mathcal N_t}^{M_t}B_t\) means a worsening-flip sequence confined to \(M_t\).

Packaged proof task (what the prover saw — nothing else)

Let \(O\) be a finite set of benefit types, with \(m=|O|\). Represent a multiset by its vector in \(\mathbb Z_{\ge0}^{O}\); containment is coordinatewise and addition adds multiplicities.
A society is given by its support: the list of the \(\tau\) patient types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies a finite net \(\mathcal N_t\), a context multiset \(M_t\) explicitly listing every occurrence, and multisets \(A_t,B_t\subseteq M_t\) giving the benefits of the same two fixed treatment options. These benefit multisets are input data.
A net statement is \(P:U\triangleright V\), where \(P\) is a possibly empty conjunction of constraints \(x(o)\,R\,a\), with \(R\in\{\ge,\le,=\}\) and \(a\in\mathbb Z_{\ge0}\); \(U,V\) are nonzero nonnegative integer vectors with disjoint supports. All numerical data other than the occurrence lists are binary encoded.
A worsening flip \(X\to Y\) either deletes at least one occurrence, so \(Y\subsetneq X\), or has \(X=Z+U\), \(Y=Z+V\) for a statement \(P:U\triangleright V\) and a nonnegative integer vector \(Z\) satisfying \(P\).
Promise that for each type the flip graph on multisets contained in \(M_t\) has no directed cycle. Define \(A_t>_{\mathcal N_t}^{M_t}B_t\) by a finite sequence of at least one flip from \(A_t\) to \(B_t\), all states contained in \(M_t\); incomparable outcomes contribute no mass.
Given a binary rational \(q\in[0,1]\), the decision problem asks whether \(\sum_{t:\,A_t>_{\mathcal N_t}^{M_t}B_t}\mu_t\ge q\). Let \(L\) be the total input bit length, \(K=\sum_t|M_t|\) count context occurrences, and \(s=\sum_t|\mathcal N_t|\); state running times in \(m,\tau,L,K,s\).

Is this promised mass-threshold decision problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

Known discrete results: dominance in satisfiable bounded-multiset nets is preserved by translation to CI-nets on indexed copies of the objects ([dominance-preservation result](https://arxiv.org/abs/1611.02885)); dominance in satisfiable CI-nets is \(\mathrm{PSPACE}\)-complete ([CI-net complexity result](https://www.ijcai.org/Proceedings/09/Papers/022.pdf)).
No result for this exact distributional threshold problem was located in the literature search.

Result

The promised problem is \(\mathrm{PSPACE}\)-complete under polynomial-time, promise-preserving reductions. In particular, it is \(\mathrm{NP}\)-hard, even when \(\tau=1\), \(\mu_1=q=1\), every context multiplicity is one, and every net statement exchanges two single objects.

Consequently, a polynomial-time algorithm for the general problem would imply \(\mathrm P=\mathrm{PSPACE}\). The degenerate case \(q=0\) is always a yes-instance; the hardness result uses \(q=1\).

1. A precise source problem

We use the following known theorem:

CI-net dominance theorem. Given a satisfiable CI-net and two bundles, deciding whether the first strictly dominates the second is \(\mathrm{PSPACE}\)-complete. This remains true when every statement compares singletons and has only positive preconditions. This is Proposition 6, restriction (1), of [Bouveret, Endriss, and Lang](https://www.ijcai.org/Proceedings/09/Papers/022.pdf).

In this restricted source problem, a statement has the form \(C:\{u\}\triangleright\{v\}\), where \(u\ne v\) and \(C\cap\{u,v\}=\varnothing\). Its worsening flip replaces \(u\) by \(v\), provided that all objects in \(C\) are present and \(v\) is absent. Strict deletion of objects is also a worsening flip.

Satisfiability means that some strict, transitive, monotonic preference relation respects all statements. Therefore, every worsening flip follows that strict relation, and a directed cycle of worsening flips is impossible. Dominance is equivalent to the existence of a nonempty worsening-flip sequence; these are Propositions 1 and 2 of the same [paper](https://www.ijcai.org/Proceedings/09/Papers/022.pdf).

We now verify that this source problem embeds exactly into the problem in the question.

2. A promise-preserving reduction

Let the source instance have object set \(O\), satisfiable net \(\mathcal C\), and bundles \(A,B\subseteq O\). For \(o\in O\), write \(e_o\) for its unit multiplicity vector.

Construct a society with one patient type and set \(\mu_1=1\) and \(q=1\). Define its context by \(M_1(o)=1\) for every \(o\in O\), explicitly listing each occurrence once. Let \(A_1\) and \(B_1\) be the indicator vectors of \(A\) and \(B\).

For each source statement \(C:\{u\}\triangleright\{v\}\), introduce the target statement \(P_C:e_u\triangleright e_v\), where
\(P_C=\bigwedge_{c\in C}(x(c)\ge1)\).

Both compared vectors are nonzero and have disjoint supports, as required. All constants are one.

Exact correspondence of flips

Every multiset contained in \(M_1\) is the indicator vector of a unique subset of \(O\). Under this identification, deletion flips in the two problems coincide.

Consider a target statement flip \(X=Z+e_u\to Y=Z+e_v\), with \(X,Y\subseteq M_1\).

Because every coordinate of \(M_1\) is one, containment of \(X\) implies \(Z(u)=0\), and containment of \(Y\) implies \(Z(v)=0\). Thus \(u\) is present only in \(X\), \(v\) is present only in \(Y\), and all other coordinates are unchanged.

Furthermore, \(C\cap\{u,v\}=\varnothing\). Hence, for each \(c\in C\), we have \(Z(c)=X(c)=Y(c)\). The condition \(P_C\) therefore holds exactly when all objects of \(C\) are present. This is precisely the source statement’s worsening flip.

Conversely, every source statement flip gives such a target flip by taking \(Z\) to be the unchanged objects. Therefore, the two flip graphs are isomorphic, and their nonempty directed paths correspond exactly.

Verification of the promise

The source net is satisfiable. Its strict preference relation rules out a directed cycle of worsening flips: such a cycle would imply that a bundle strictly prefers itself, by transitivity.

The target flip graph is isomorphic to the source flip graph, so it is also acyclic. This verifies the target promise on every output of the reduction, independently of whether the dominance query is true.

Correctness and size

Since the society has one type of mass one, its contributing mass is one exactly when \(A_1>_{\mathcal N_1}^{M_1}B_1\), and is zero otherwise. Thus the threshold condition with \(q=1\) holds exactly when the source dominance query holds.

The construction has \(\tau=1\), \(K=m\), and \(s=|\mathcal C|\). It copies each statement once and lists each object once, so its output length and construction time are polynomial in the source input length.

This proves \(\mathrm{PSPACE}\)-hardness, and hence \(\mathrm{NP}\)-hardness. The indexed-copy translation is unnecessary here: CI-nets already occur as the multiplicity-one special case.

3. Polynomial-space upper bound

For type \(t\), put \(k_t=|M_t|\). Its number of possible states is
\(H_t=\prod_{o\in O}(M_t(o)+1)\).

For every nonnegative integer \(c\), we have \(c+1\le2^c\). Consequently,
\(H_t\le2^{k_t}\).
Also, \(M_t(o)\le k_t\), so
\(H_t\le(k_t+1)^m\).

Testing an edge

Given \(X,Y\subseteq M_t\), a deletion edge is checked by coordinatewise comparison and inequality of the two vectors.

For a statement edge, inspect each statement \(P:U\triangleright V\). Check \(U\subseteq X\), form \(Z=X-U\), test every conjunct of \(P\) on \(Z\), and check \(Y=Z+V\). Binary arithmetic and comparisons take polynomial time in \(m,L,K\). Large binary constants in a statement cause no difficulty: their encoded lengths are included in \(L\).

Thus adjacency is decidable in polynomial time and space.

Reachability

Under the acyclicity promise, if \(A_t=B_t\), strict dominance is false.

Otherwise, whenever \(B_t\) is reachable from \(A_t\), there is a simple path of length at most \(H_t-1\): repeated vertices can be removed from any directed walk. A nondeterministic algorithm can guess this path while storing only the current state, the next state, and a counter bounded by \(H_t-1\).

A state uses \(O(m\log(K+2))\) bits, and the counter uses \(O(K+1)\) bits. The resulting algorithm uses polynomial space. By the standard equality \(\mathrm{NPSPACE}=\mathrm{PSPACE}\), dominance for one type has a deterministic polynomial-space algorithm.

Run this deterministic algorithm separately for every supported type, reusing its workspace.

Exact mass comparison

Write each mass as \(\mu_t=a_t/b_t\), with \(b_t>0\), and put \(D=\prod_t b_t\). Then the contributing mass is \(W/D\), where
\(W=\sum_{t:\,A_t>_{\mathcal N_t}^{M_t}B_t}a_t(D/b_t)\).

The bit length of \(D\) is bounded by the sum of the input denominator lengths, hence by \(O(L)\). Since the masses are positive and sum to one, \(0\le W\le D\), so \(W\) also has \(O(L)\) bits.

Writing \(q=a/b\) with \(b>0\), the required comparison is exactly \(bW\ge aD\). These integer computations take polynomial time and space. Therefore, the complete threshold problem belongs to \(\mathrm{PSPACE}\).

Together with Section 2, this establishes \(\mathrm{PSPACE}\)-completeness.

4. Explicit running-time bounds

A direct deterministic algorithm explores each type’s state graph. It suffices to generate:

  • each feasible deletion of a single occurrence;
  • each feasible statement flip.

Replacing an arbitrary deletion by successive single-occurrence deletions preserves reachability, because every intermediate state remains contained in the context.

Let \(s_t=|\mathcal N_t|\). Breadth-first search, followed by exact mass comparison, takes time
\(O\!\left(\operatorname{poly}(m,L,K)\sum_{t=1}^{\tau}H_t(m+s_t+1)\right)\).

Since \(\sum_t s_t=s\) and \(k_t\le K\), this yields the bound
\(O\!\left((\tau(m+1)+s)\operatorname{poly}(m,L,K)\min\{2^K,(K+1)^m\}\right)\).

In particular, the problem is polynomial-time solvable for every fixed \(m\). The hardness result concerns variable \(m\), even with \(\tau=1\) and \(K=m\).
