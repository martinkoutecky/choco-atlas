The continuous mirror question, as graded

Given a finite chord alphabet \(A\), sequence length \(k\), support \(T\subseteq A^k\), positive binary-rational masses \(\mu_t\) summing to \(1\), and rational threshold \(q\), does there exist \(W\in A^k\) such that \(\Phi_\mu(W)\ge q\)? Here \(u_{t,j}(W)=1-d_{\mathrm{Jaccard}}(t_j,W_j)\), the values \(u_{t,j}(W)\) are sorted in nonincreasing order as \(u^\downarrow_{t,1}(W),\ldots,u^\downarrow_{t,k}(W)\), and \(\Phi_\mu(W)=\sum_{t\in T}\mu_t\sum_{r=1}^k u^\downarrow_{t,r}(W)/r\). Equivalently, find a maximizing \(W\).

Packaged proof task (what the prover saw — nothing else)

An input contains an explicitly listed chord alphabet \(A\) of size \(m\ge 1\); each chord is a four-element set of note labels from a finite input universe, and \(k\ge 1\) is the sequence length.
A society is given by its support: the list of the \(\tau\) distinct types \(t\in T\subseteq A^k\) with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number \(m^k\) of possible types.
A feasible outcome is any \(W\in A^k\), with repetitions allowed. Define \(u_{t,j}(W)=1-d_{\mathrm{Jaccard}}(t_j,W_j)\), and sort these utilities in nonincreasing order as \(u^\downarrow_{t,1}(W),\ldots,u^\downarrow_{t,k}(W)\); equal utilities may appear in any order.
Define \(\Phi_\mu(W)=\sum_{t\in T}\mu_t\sum_{r=1}^k u^\downarrow_{t,r}(W)/r\). The decision problem asks, for a binary-rational threshold \(q\in\mathbb Q\), whether some feasible \(W\) satisfies \(\Phi_\mu(W)\ge q\). Let \(L\) be the total input bit length.

Is this decision problem solvable in polynomial time in \(m,\tau,k,L\), or is it NP-hard?

Discrete proportional harmonic aggregation is [reported NP-hard](https://arxiv.org/html/2509.00120v1#S5), but the [expanded argument](https://arxiv.org/html/2509.00120v1#A1.SS1.SSS3) permits general utilities and does not establish the specified Jaccard restriction.
No result settling exactly this rational-mass Jaccard problem was verified.

  • The note universe and alphabet encoding were unspecified; both are finite input data, rather than fixing the experimental musical alphabet.
  • The sequence-length and alphabet domains were unspecified; both are positive integers.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result

The decision problem is \(\mathrm{NP}\text{-complete}\). Hardness holds even when all distinct chords are pairwise disjoint four-element sets, so every Jaccard utility belongs to \(\{0,1\}\). The masses and threshold in the reduction are dyadic rationals.

The proof below directly establishes the specified Jaccard restriction.

2. Source problem and binary Jaccard utilities

We reduce from unweighted Max-Cut: given a simple undirected graph \(G=(V,E)\) and an integer \(K\), decide whether some vertex partition has at least \(K\) crossing edges. This problem is \(\mathrm{NP}\text{-complete}\), as established by [Garey, Johnson, and Stockmeyer](https://doi.org/10.1016/0304-3975%2876%2990059-1).

Write \(s=|E|\). We may restrict to \(s\ge 1\) and \(0\le K\le s\): excluded cases are immediately decidable and can be mapped to fixed yes or no instances satisfying these restrictions.

Add isolated vertices until the number \(n\) of vertices is a power of two with \(n\ge 4\). This increases the graph size by at most a constant factor and preserves every attainable cut size. Label the vertices by \(\{1,\ldots,n\}\), and set the sequence length to \(k=n\).

Every chord introduced below receives four fresh note labels, used by no other chord. Thus distinct chords are disjoint, and for any two alphabet chords \(a,b\),

\[ 1-d_{\mathrm{Jaccard}}(a,b)= \begin{cases} 1,&a=b,\\ 0,&a\ne b. \end{cases} \]

Consequently, if \(M_t(W)=|\{j:t_j=W_j\}|\), the contribution of type \(t\) before multiplication by its mass is exactly \(H_{M_t(W)}\), where

\[ H_0=0,\qquad H_r=\sum_{\ell=1}^{r}\frac1\ell. \]

Indeed, the sorted utility vector has precisely \(M_t(W)\) initial ones, followed by zeros.

3. Alphabet, support, and masses

For each coordinate \(i\) and bit \(b\in\{0,1\}\), introduce a chord \(C_{i,b}\). Call an outcome valid when

\[ W_i\in\{C_{i,0},C_{i,1}\}\qquad\text{for every }i. \]

A valid outcome encodes the assignment \(x\in\{0,1\}^n\) defined by \(W_i=C_{i,x_i}\). Validity is only terminology; the constructed problem still permits every outcome in \(A^n\).

Guardian types

For every \(i\in\{1,\ldots,n\}\), \(b\in\{0,1\}\), and \(\ell\in\{1,2\}\), introduce a type \(g^{i,b,\ell}\) with

\[ g^{i,b,\ell}_i=C_{i,b}. \]

At each other coordinate \(j\ne i\), place a fresh dummy chord \(D_{g^{i,b,\ell},j}\).

There are \(4n\) guardian types.

Edge types

For every edge \(f=\{u,v\}\in E\) and bit \(b\in\{0,1\}\), introduce a type \(h^{f,b}\) with

\[ h^{f,b}_u=C_{u,b},\qquad h^{f,b}_v=C_{v,b}. \]

At each coordinate \(j\notin\{u,v\}\), place a fresh dummy chord \(D_{h^{f,b},j}\).

There are \(2s\) edge types.

Every dummy chord is distinct from every other dummy chord and from every \(C_{i,b}\). The alphabet consists exactly of these chords.

All listed types are distinct. Guardian types with the same designated coordinate and bit differ in their dummy chords. Guardians have one nondummy entry, whereas edge types have two. Different edge types differ either in their endpoint coordinates or in their bit. Thus

\[ \tau=4n+2s,\qquad m=2n+4n(n-1)+2s(n-2). \]

Weights and normalization

Let \(P\) be the smallest power of two strictly larger than \(s(4n^2+1)\), and define

\[ B=P-s,\qquad Z=4nP. \]

In particular,

\[ B>4sn^2. \]

Give every guardian type mass \(B/Z\), and every edge type mass \(2n/Z\). These masses are positive and sum to one because

\[ 4n\frac{B}{Z}+2s\frac{2n}{Z} =\frac{4n(B+s)}{Z}=1. \]

Since both \(n\) and \(P\) are powers of two, \(Z\) is a power of two. All masses are therefore dyadic rationals.

Set the threshold to

\[ q=\frac{2nB+n(3s+K)}{Z}. \]

This is also dyadic.

For convenience, use the unnormalized score

\[ F(W)=Z\Phi_\mu(W) =B\sum_g H_{M_g(W)}+2n\sum_h H_{M_h(W)}, \]

where the two sums range over guardian and edge types, respectively.

4. Every outcome reaching the threshold is valid

We prove a bound that covers all feasible outcomes, including repetitions and choices of dummy chords.

Let \(r(W)\) be the number of coordinates at which \(W\) is invalid. At a fixed coordinate \(j\):

  • Each chord \(C_{j,b}\) appears in exactly two guardian types at that coordinate.
  • Every other chord appears in at most one guardian type at that coordinate. A dummy chord has only its single designated occurrence, and \(C_{i,b}\) with \(i\ne j\) appears in no guardian at coordinate \(j\).

It follows, by counting matches coordinate by coordinate, that

\[ \sum_g M_g(W)\le 2(n-r(W))+r(W)=2n-r(W). \]

For every nonnegative integer \(a\), \(H_a\le a\), because each summand in \(H_a\) is at most one. Hence

\[ \sum_g H_{M_g(W)}\le 2n-r(W). \]

There are \(2s\) edge types, each having at most \(n\) matches. Using \(H_n\le n\), their total weighted contribution satisfies

\[ 2n\sum_h H_{M_h(W)} \le 2n(2s)n=4sn^2. \]

Therefore, if \(W\) is invalid, then \(r(W)\ge 1\), and

\[ F(W)\le B(2n-1)+4sn^2<2nB. \]

The last strict inequality follows from \(B>4sn^2\).

Conversely, let \(W\) be valid. A guardian \(g^{i,b,\ell}\) matches \(W\) exactly once if \(b=x_i\), and has no matches otherwise: its dummy chords cannot occur in a valid outcome. Exactly two guardians per coordinate have one match. Thus

\[ \sum_g H_{M_g(W)}=2n. \]

Since edge contributions are nonnegative, every valid outcome satisfies \(F(W)\ge 2nB\).

Finally, \(Zq=2nB+n(3s+K)\ge 2nB\). Consequently, no invalid outcome can reach the threshold.

5. Valid outcomes encode cut size exactly

Let \(W_i=C_{i,x_i}\), and let

\[ c(x)=|\{\{u,v\}\in E:x_u\ne x_v\}| \]

be the size of the encoded cut.

For an edge \(f=\{u,v\}\), consider its two types \(h^{f,0}\) and \(h^{f,1}\). Their dummy coordinates never match a valid outcome, so only the two endpoints contribute.

If \(x_u=x_v\), one type has two matches and the other has none. Their combined contribution is

\[ H_2+H_0=\frac32. \]

If \(x_u\ne x_v\), each type has one match. Their combined contribution is

\[ H_1+H_1=2. \]

Summing over edges gives

\[ \sum_h H_{M_h(W)} =\frac32(s-c(x))+2c(x) =\frac32s+\frac12c(x). \]

Including the guardian contribution and the edge weight \(2n\), we obtain

\[ F(W) =2nB+2n\left(\frac32s+\frac12c(x)\right) =2nB+n(3s+c(x)). \]

Thus, for every valid outcome,

\[ \Phi_\mu(W)\ge q \quad\Longleftrightarrow\quad c(x)\ge K. \]

Every assignment yields a feasible valid outcome, and Section 4 excludes every invalid outcome from reaching the threshold. Hence

\[ G\text{ has a cut of size at least }K \quad\Longleftrightarrow\quad \exists W\in A^n:\Phi_\mu(W)\ge q. \]

This proves the correctness of the reduction.

Polynomial size

The construction has \(k=n\), \(\tau=4n+2s\), and \(m=O(n^2+ns)\). The note universe has \(4m\) labels, each encodable with \(O(\log m)\) bits, and all support sequences are explicitly listed.

By minimality of \(P\),

\[ P\le 2s(4n^2+1). \]

Therefore \(B\), \(Z\), and the threshold numerator have polynomial magnitude and polynomial bit length. The entire construction is computable in polynomial time and establishes \(\mathrm{NP}\text{-hardness}\).

6. Membership in \(\mathrm{NP}\)

For a general input, a certificate is an outcome \(W\), represented by its \(k\) alphabet indices.

If two four-element chords intersect in \(a\) notes, their utility is \(a/(8-a)\). Thus every utility belongs to

\[ \left\{0,\frac17,\frac13,\frac35,1\right\}. \]

The verifier computes these utilities, sorts each type’s vector, and evaluates the weighted sum using exact rational arithmetic.

To verify the bit complexity, write each mass as \(\mu_t=a_t/b_t\), and write the threshold as \(q=a_q/b_q\), with positive denominators. A common denominator for all score summands and the threshold is

\[ D=105\,k!\,b_q\prod_{t\in T}b_t. \]

Utility denominators divide \(105\), and each rank denominator divides \(k!\). Moreover,

\[ \log D=O(k\log(k+1)+L). \]

The resulting integer numerators also have polynomial bit length. Exact comparison therefore takes polynomial time in \(m,\tau,k,L\). Since at least one length-\(k\) type is explicitly listed, the certificate length is polynomial in the input length.

The problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\text{-completeness}\).
