The anchor (named result in the paper)

Proposition 1 — class: other

The continuous mirror question, as graded

Given a finite type set \(T\) with positive rational masses \(\mu_t\) summing to \(1\), and a monotonic ranking with \(K\) classes whose cumulative upper sets \(W_k\) are specified by finite antichains of minimal mass vectors, compute the lexicographic preorder of types induced by \(G_{t,k}=\int_{W_k\setminus W_{k-1}} (x_t/\mu_t)\,d\nu(x)\), where \(x\in\prod_{t\in T}[0,\mu_t]\) and \(\nu\) is normalized Lebesgue measure.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq 1\) types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
Coalitions are mass vectors in \(B=\prod_{t\in T}[0,\mu_t]\), ordered coordinatewise. The input includes \(K\geq 1\) finite antichains \(A_k\subseteq B\) of binary rational vectors, defining \(W_k=\{x\in B:\exists a\in A_k,\ a\leq x\}\).
Require \(\varnothing=W_0\subsetneq W_1\subsetneq\cdots\subsetneq W_K=B\); the nonempty classes \(W_k\setminus W_{k-1}\) are ordered from best to worst. Let \(m=\sum_{k=1}^K|A_k|\) and let \(L\) be the total binary input length.
Let \(\nu\) be normalized Lebesgue measure on \(B\), so \(d\nu(x)=(\prod_{t\in T}\mu_t)^{-1}dx\), and define \(G_{t,k}=\int_{W_k\setminus W_{k-1}}(x_t/\mu_t)\,d\nu(x)\). Rank types by descending lexicographic order of \((G_{t,1},\ldots,G_{t,K})\), retaining exact ties.

Is computing this exact total preorder possible in time polynomial in \(m,\tau,K,L\), or is it NP-hard?

For discrete societies with \(n\) players, [Fritz–Moretti](https://arxiv.org/html/2608.24596v1) report a worst-case score-computation bound \(O(2^{\binom{n-1}{\lfloor n/2\rfloor-1}})\) given the inclusion-minimal coalitions obtained after adjoining the evaluated player; this is an algorithmic bound, not a hardness classification.
No complexity classification for the continuous preorder problem defined here was located in the literature search.

Modeling choices made when packaging the task

  • Minimal mass vectors are binary rational vectors within the coalition box, and their upper sets use weak coordinatewise inequalities.
  • The cumulative upper sets strictly increase from the empty set to the entire box, preserving a ranking of all coalitions with nonempty equivalence classes; positive measure of every class is not required.
  • The requested preorder uses descending lexicographic comparison with exact equality retained as indifference.
  • The parameter m counts all supplied minimal vectors across classes, and L is the total binary input length.

Result

Computing the exact total preorder is \(\mathrm{NP}\)-hard, already when \(K=2\) and every input mass and coordinate is dyadic rational. Consequently, a polynomial-time algorithm in \(m,\tau,K,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

For \(K=1\), the promise forces \(W_1=B\), so every type has score \(1/2\) and all types tie. The hardness proof concerns the first nontrivial case, \(K=2\).

1. Source problem and normalization

We reduce from Independent Set: given a finite simple graph \(H=(\{1,\ldots,n\},E)\) and an integer \(r\) with \(1\le r\le n\), decide whether \(H\) has an independent set of size at least \(r\). This problem is \(\mathrm{NP}\)-complete: Clique is \(\mathrm{NP}\)-complete, and a vertex set is a clique in a graph exactly when it is independent in its complement. Instances outside the stated bounds are trivial and can be replaced by fixed yes or no instances. [Karp’s NP-completeness theorem](https://cgi.di.uoa.gr/~sgk/teaching/grad/handouts/karp.pdf).

For any positive masses, put \(y_t=x_t/\mu_t\). This change of variables sends \(B\) to \([0,1]^\tau\), preserves coordinatewise order, and has Jacobian \(\prod_t\mu_t\). Thus normalized Lebesgue measure becomes ordinary product Lebesgue measure, and

\[ G_{t,1}=\int_{\widehat W_1}y_t\,dy, \]

where \(\widehat W_1\) denotes the image of \(W_1\). Below, we specify the construction in these normalized coordinates and then scale its generators to obtain the actual input.

2. A probability that detects a large independent set

Define

\[ \delta=2^{-(n+2)},\qquad d=\delta^{\,n-r}. \]

In particular, \(0<d\le1\).

Let \(z_1,\ldots,z_n\) be independent uniform coordinates in \([0,1]\). Call vertex \(i\) active when \(z_i\ge\delta\). Each vertex is independently active with probability \(1-\delta\).

Define the upper set

\[ U_H=\bigcup_{\{i,j\}\in E}\{z\in[0,1]^n:z_i\ge\delta,\ z_j\ge\delta\}. \]

A point lies outside \(U_H\) exactly when its active vertices form an independent set. Consequently, writing \(I_H\) for the measure of this complement,

\[ I_H=\sum_{\substack{S\subseteq\{1,\ldots,n\}\\S\text{ independent}}} (1-\delta)^{|S|}\delta^{\,n-|S|}. \]

Let \(\alpha(H)\) be the maximum independent-set size. We establish two separated bounds.

If \(\alpha(H)<r\), then \(I_H\le d/4\). Every independent set has size at most \(r-1\), so each summand is at most \(\delta^{\,n-r+1}\). There are at most \(2^n\) summands. Therefore,

\[ I_H\le2^n\delta^{\,n-r+1} =2^n\delta d =\frac d4. \]

If \(\alpha(H)\ge r\), then \(I_H\ge3d/4\). Taking a subset of a sufficiently large independent set gives an independent set \(S\) of size exactly \(r\). The event that the active set is exactly \(S\) has probability \((1-\delta)^r d\), hence

\[ I_H\ge(1-\delta)^r d. \]

The union bound gives \((1-\delta)^r\ge1-r\delta\). Since \(r\le n\) and \(n\le2^n\), we have \(r\delta\le1/4\). Thus

\[ I_H\ge\frac{3d}{4}. \]

3. Construction of the promised society

Use \(\tau=n+2\) types, labelled \(1,\ldots,n,s,t\). Let

\[ h=\lceil\log_2(n+2)\rceil,\qquad \mu_i=\mu_s=2^{-h}\quad(1\le i\le n),\qquad \mu_t=1-(n+1)2^{-h}. \]

These masses sum to \(1\). Since \(2^h\ge n+2\), we have \(\mu_t\ge2^{-h}>0\). All masses are dyadic.

Write the normalized coordinates as \((z_1,\ldots,z_n,u,v)\), where \(u=y_s\) and \(v=y_t\), and set

\[ b=\frac12+\frac d4. \]

Thus \(1/2<b\le3/4\).

The first normalized upper set is

\[ \widehat W_1 =\{v\ge b\}\ \cup\ \bigl(\{u\ge1/2\}\cap(U_H\times[0,1]^2)\bigr). \]

It has the following generators:

  • A vector \(\widehat a^0\) whose \(t\)-coordinate is \(b\), with all other coordinates zero.
  • For each edge \(\{i,j\}\in E\), a vector \(\widehat a^{ij}\) whose \(s\)-coordinate is \(1/2\), whose \(i\)- and \(j\)-coordinates are \(\delta\), and whose other coordinates are zero.

For each such generator, define its actual coordinates by \(a_q=\mu_q\widehat a_q\), for every type \(q\). Let \(A_1\) consist of these scaled generators, and set

\[ K=2,\qquad A_2=\{\mathbf0\}. \]

Verification of the input promises

Positive diagonal scaling preserves coordinatewise comparisons, so it suffices to check the normalized generators.

The vector \(\widehat a^0\) is incomparable with every edge generator: it has a larger \(t\)-coordinate and a smaller \(s\)-coordinate. Two distinct edge generators are incomparable because their distinct two-element endpoint sets each contain a vertex absent from the other. Thus \(A_1\) is an antichain; \(A_2\) is a singleton antichain.

The set \(W_1\) is nonempty because it contains its generator \(a^0\). It is proper because \(\mathbf0\notin W_1\). Finally, \(A_2=\{\mathbf0\}\) generates all of \(B\). Therefore,

\[ \varnothing=W_0\subsetneq W_1\subsetneq W_2=B. \]

Both classes even have positive measure: \(\{v\ge b\}\) lies in the first, and \(\{u<1/2,\ v<b\}\) lies in the second.

4. Exact comparison of the two distinguished types

We calculate

\[ D=G_{s,1}-G_{t,1} =\int_{\widehat W_1}(u-v)\,dz\,du\,dv. \]

The sets are finite unions of boxes and the integrand is bounded, so Fubini’s theorem applies.

For fixed \(z\notin U_H\), the winning fiber is \(\{v\ge b\}\). Its contribution is

\[ \int_b^1\int_0^1(u-v)\,du\,dv =-\frac{b(1-b)}2. \]

For fixed \(z\in U_H\), the winning fiber is \(\{u\ge1/2\}\cup\{v\ge b\}\). The integral over the full square is zero, so subtracting the integral over its complementary rectangle gives

\[ -\int_0^b\int_0^{1/2}(u-v)\,du\,dv =-\left(\frac b8-\frac{b^2}{4}\right) =\frac b4\left(b-\frac12\right). \]

The respective sets of \(z\)-coordinates have measures \(I_H\) and \(1-I_H\). Hence

\[ D=(1-I_H)\frac b4\left(b-\frac12\right) -I_H\frac{b(1-b)}2 =\frac b4\left[\left(b-\frac12\right)-\left(\frac32-b\right)I_H\right]. \]

Substituting \(b=1/2+d/4\) yields the exact identity

\[ D=\frac b{16}\bigl[d-(4-d)I_H\bigr]. \]

We now apply the bounds from Section 2.

If \(\alpha(H)<r\), then

\[ d-(4-d)I_H \ge d-(4-d)\frac d4 =\frac{d^2}{4}>0. \]

Thus \(D>0\), and type \(s\) ranks strictly above type \(t\).

If \(\alpha(H)\ge r\), then \(I_H\ge3d/4\). Since \(d\le1\), we have \(4-d\ge3\), giving

\[ d-(4-d)I_H \le d-3\frac{3d}{4} =-\frac{5d}{4}<0. \]

Thus \(D<0\), and type \(t\) ranks strictly above type \(s\).

In both cases the first score components differ, so subsequent components cannot change their lexicographic comparison. We have proved

\[ \alpha(H)\ge r \quad\Longleftrightarrow\quad t\text{ ranks strictly above }s. \]

There is no tie between these distinguished types.

5. Encoding size and conclusion

The construction has

\[ \tau=n+2,\qquad K=2,\qquad m=|E|+2. \]

Write \(M=(n+2)(n-r)\). Then \(d=2^{-M}\), so \(d\) and \(b\) have binary rational descriptions of length \(O(n^2)\). Every mass and scaled generator coordinate also has at most \(O(n^2)\) bits. There are only polynomially many explicitly listed coordinates. Therefore the total input length \(L\), and the time needed to construct the instance, are polynomial in the explicitly represented graph input length.

This is a polynomial-time many-one reduction from Independent Set to the decision problem of whether one designated type ranks strictly above another, restricted to valid instances of the stated continuous problem. Computing the entire exact total preorder determines that comparison.

Therefore the requested computation is \(\mathrm{NP}\)-hard, even with two classes and dyadic input data. The proof establishes hardness directly for the preorder, without requiring recovery of any individual score.
