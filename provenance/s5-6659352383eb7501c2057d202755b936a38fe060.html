The continuous mirror question, as graded

Given candidate sets \(C_1,\ldots,C_k\), supported approval trajectories \(\theta=(A_1^\theta,\ldots,A_k^\theta)\) with \(A_i^\theta\subseteq C_i\), positive rational masses \(\mu_\theta\) summing to \(1\), and fixed tie orders, start with \(\ell_1(\theta)=0\). At round \(i\), for each \(c\in C_i\), minimize \(\lambda_i(c)=\frac{1+\sum_\theta x_\theta\ell_i(\theta)}{\sum_\theta x_\theta}\) over \(0\leq x_\theta\leq\mu_\theta\), with \(x_\theta=0\) whenever \(c\notin A_i^\theta\) and \(\sum_\theta x_\theta>0\); set \(\lambda_i(c)=\infty\) if no mass approves \(c\). Choose a candidate with minimum \(\lambda_i(c)\), update the selected mass to that load, and leave the other mass loads unchanged. Is the resulting winner sequence and load evolution exactly computable in time polynomial in \(k\), \(m=\max_i|C_i|\), support size \(\tau\), and binary input length \(L\)? A partial selection can occur only at a boundary whose current load equals the resulting load, so it does not split a type into distinct load states.

Packaged proof task (what the prover saw — nothing else)

Given positive integers \(k,\tau\), finite nonempty candidate sets \(C_1,\ldots,C_k\), and a fixed strict tie order on each \(C_i\), consider the following continuous Perpetual Phragmén rule.
A society is given by its support: the list of \(\tau\) distinct approval trajectories \(\theta=(A_1^\theta,\ldots,A_k^\theta)\), with \(\varnothing\ne A_i^\theta\subseteq C_i\), and positive binary rational masses \(\mu_\theta\) satisfying \(\sum_\theta\mu_\theta=1\). The parameter \(\tau\) is the support size, not the number of possible trajectories.
Write \(m=\max_i|C_i|\) and let \(L\) be the total binary input length, including approvals, masses, and tie orders. Initially \(\ell_1(\theta)=0\); this is the load before round \(1\).
Each round incurs total load \(1\). For each \(c\in C_i\), define \(\lambda_i(c)=\min_x\frac{1+\sum_\theta x_\theta\ell_i(\theta)}{\sum_\theta x_\theta}\), where \(x_\theta\in\mathbb R\), \(0\le x_\theta\le\mu_\theta\), \(x_\theta=0\) if \(c\notin A_i^\theta\), and \(\sum_\theta x_\theta>0\); set \(\lambda_i(c)=\infty\) when no mass approves \(c\).
Choose \(w_i\) minimizing \(\lambda_i(c)\), resolving candidate ties by the given order. For any minimizing selection for \(w_i\), set the selected mass's load to \(\lambda_i(w_i)\) and leave all other mass unchanged, obtaining \(\ell_{i+1}\).
A partial selection \(0<x_\theta<\mu_\theta\) can occur only when \(\ell_i(\theta)=\lambda_i(w_i)\), so it creates no distinct load states within a type; minimizing-selection ties do not affect the load evolution.

Is exact computation of the winner sequence \((w_1,\ldots,w_k)\) and all rational loads \(\ell_i(\theta)\) possible in time polynomial in \(k,m,\tau,L\), or is this computation NP-hard?

Discrete Perpetual Phragmén is computable in polynomial time; this is also established in the [later treatment](https://martin.lackner.xyz/publications/AAAI-Proportional%20Decisions%20in%20Perpetual%20Voting-with-appendix.pdf).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result.

Exact computation is polynomial-time solvable in \(k,m,\tau,L\), including the binary representation of every load. The essential ingredient is a common denominator for all current loads whose bit length grows by at most \(L\) per round.

The proof below gives an explicit algorithm.

2. Computing one candidate’s score.

Fix a round, write the current loads as \(\ell(\theta)\), and let \(S\) be the nonempty set of types approving a candidate. Define

\(F(t)=\sum_{\theta\in S}\mu_\theta\max\{t-\ell(\theta),0\}\).

This function is continuous, equals zero at \(t=\min_{\theta\in S}\ell(\theta)\), is strictly increasing above that value, and tends to infinity. Consequently, there is a unique \(t_*\) satisfying \(F(t_*)=1\).

We prove that the candidate’s score is \(t_*\). For any feasible selection \(x\),

\(\sum_{\theta\in S}x_\theta(t_*-\ell(\theta))\leq\sum_{\theta\in S}\mu_\theta\max\{t_*-\ell(\theta),0\}=1\).

Indeed, for types with load below \(t_*\), this follows from \(x_\theta\leq\mu_\theta\); types with load above \(t_*\) contribute nonpositive terms. Therefore,

\(\dfrac{1+\sum_{\theta\in S}x_\theta\ell(\theta)}{\sum_{\theta\in S}x_\theta}-t_*=\dfrac{1-\sum_{\theta\in S}x_\theta(t_*-\ell(\theta))}{\sum_{\theta\in S}x_\theta}\geq0\).

Conversely, select all mass of precisely the types with \(\ell(\theta)<t_*\). This selection has positive total mass because \(F(t_*)=1\), and its objective equals \(t_*\). Thus the minimum is attained and equals \(t_*\).

Moreover, equality in the preceding inequality requires full selection below \(t_*\) and zero selection above \(t_*\). To see this explicitly, the difference between its right and left sides is

\(\sum_{\substack{\theta\in S\\\ell(\theta)<t_*}}(\mu_\theta-x_\theta)(t_*-\ell(\theta))+\sum_{\substack{\theta\in S\\\ell(\theta)>t_*}}x_\theta(\ell(\theta)-t_*)\).

Every summand is nonnegative. Equality forces each summand to vanish; mass at load \(t_*\) may be selected arbitrarily. Hence the unique resulting load evolution is

\(\ell'(\theta)=\max\{\ell(\theta),t_*\}\) for \(\theta\in S\),

with all other loads unchanged. Its increase in total weighted load is exactly \(F(t_*)=1\).

Now order the approving types as \(\theta_1,\ldots,\theta_r\) by nondecreasing load, breaking equal-load ties arbitrarily. For each nonempty prefix, define

\(R_j=\dfrac{1+\sum_{h=1}^{j}\mu_{\theta_h}\ell(\theta_h)}{\sum_{h=1}^{j}\mu_{\theta_h}}\), for \(1\leq j\leq r\).

Each prefix is a feasible selection, so \(R_j\geq t_*\). The types with load strictly below \(t_*\) form a nonempty prefix, and the preceding argument shows that its ratio equals \(t_*\). Therefore,

\(\lambda(c)=\min_{1\leq j\leq r}R_j\).

This establishes a finite prefix-scan algorithm, despite the continuous selection space.

3. Integer representation and the denominator invariant.

Write each input mass as \(\mu_\theta=u_\theta/v_\theta\), with positive integers \(u_\theta,v_\theta\), and set

\(D=\prod_\theta v_\theta,\qquad a_\theta=u_\theta(D/v_\theta)\).

Then

\(\mu_\theta=a_\theta/D,\qquad a_\theta\in\mathbb Z_{>0},\qquad\sum_\theta a_\theta=D\).

The total binary length of the input denominators is at most \(L\), so \(\log_2D\leq L\). Constructing \(D\) and the integers \(a_\theta\) takes polynomial time.

At the beginning of round \(i\), maintain integers \(Q_i>0\) and \(b_{i,\theta}\geq0\) such that

\(\ell_i(\theta)=b_{i,\theta}/Q_i\).

Initially, take \(Q_1=1\) and \(b_{1,\theta}=0\).

For a candidate prefix \(T\), let

\(s_T=\sum_{\theta\in T}a_\theta,\qquad P_T=DQ_i+\sum_{\theta\in T}a_\theta b_{i,\theta}\).

Its ratio is exactly

\(R_T=\dfrac{P_T}{Q_i s_T}\).

In particular, \(1\leq s_T\leq D\). Since \(Q_i\) is common to every prefix and candidate, two ratios can be compared by the integer comparison

\(P_Ts_U\leq P_Us_T\).

After computing the candidate scores and applying the prescribed candidate tie order, let the winning score be represented by

\(\lambda_i(w_i)=P/(Q_i s)\),

using any prefix attaining that score. Define \(Q_{i+1}=Q_i s\). For a type approving the winner, set

\(b_{i+1,\theta}=\max\{s b_{i,\theta},P\}\);

for any other type, set

\(b_{i+1,\theta}=s b_{i,\theta}\).

Dividing by \(Q_{i+1}\) gives exactly the load update proved in Section 2. Thus the integer representation remains valid.

Because \(s\leq D\) in every round,

\(Q_i\leq D^{\,i-1}\).

Consequently, every common denominator, including \(Q_{k+1}\), has at most \(1+kL\) bits. No denominator reduction is needed for this invariant.

4. Bounds on all intermediate integers.

Every load remains nonnegative. Since each round increases weighted total load by exactly one, induction gives

\(\sum_\theta\mu_\theta\ell_i(\theta)=i-1\).

For each type, positivity of its mass therefore implies

\(0\leq\ell_i(\theta)\leq\dfrac{i-1}{\mu_\theta}=\dfrac{(i-1)D}{a_\theta}\leq(i-1)D\).

For every stored state, \(1\leq i\leq k+1\), we consequently have

\(b_{i,\theta}=Q_i\ell_i(\theta)\leq kD Q_i\leq kD^{\,k+1}\).

The integers used while evaluating candidate prefixes also have polynomial bit length. In round \(i\leq k\),

\(P_T=DQ_i+\sum_{\theta\in T}a_\theta b_{i,\theta}\leq DQ_i+(i-1)D Q_i s_T\leq(k+1)D^2Q_i\).

Since \(Q_i\leq D^{i-1}\), this gives

\(P_T\leq(k+1)D^{\,k+1}\).

Thus all stored integers and prefix numerators have \(O(1+(k+1)L+\log(k+1))\) bits. Cross-products used in comparisons have the same asymptotic bit bound.

These estimates also bound the size of the complete rational output.

5. Algorithm and complexity.

In each round:

  • Sort all types by their integer load numerators \(b_{i,\theta}\).
  • For each candidate, filter this order to its approving types and scan all nonempty prefixes, computing the minimum ratio \(P_T/(Q_i s_T)\). Assign score \(\infty\) to unsupported candidates.
  • Compare candidate scores exactly and apply the given strict tie order.
  • Update \(Q_i\) and all load numerators using the formulas in Section 3, and record the resulting state.

At least one candidate has support in each round: every type has positive mass and approves a nonempty set. Hence the chosen score is always finite.

Sorting takes \(O(\tau\log\tau)\) integer comparisons per round. The prefix scans and candidate comparisons take \(O(m\tau)\) integer operations, and updating the loads takes \(O(\tau)\). The total is therefore

\(O\!\left(k(\tau\log\tau+m\tau)\right)\)

integer operations, in addition to polynomial preprocessing and output work. Section 4 bounds every operand’s bit length polynomially; standard exact integer arithmetic therefore makes this a polynomial-time algorithm in \(k,m,\tau,L\). Fractions may be reduced by greatest-common-divisor computations if reduced output is required, also in polynomial time.

The algorithm outputs the exact winner sequence and all loads from \(\ell_1\) through \(\ell_{k+1}\). This settles the stated continuous problem. The discrete prefix argument appears in Proposition 1 of the [linked treatment](https://martin.lackner.xyz/publications/AAAI-Proportional%20Decisions%20in%20Perpetual%20Voting-with-appendix.pdf); the proof here additionally establishes the continuous minimization formula and the polynomial bit-length bound for binary rational support masses.
