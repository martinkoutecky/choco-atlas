The continuous mirror question, as graded

Given a finite support \(\mathcal T\) of CDM types with positive rational masses \(\mu_t\) summing to \(1\), core options \(C\), candidate additions \(B\), a target \(x^\star\in C\), and each type’s utilities \(u_t(x)\) and context pulls \(p_t(z,x)\), choose \(Z\subseteq B\) maximizing \(\sum_{t\in\mathcal T}\mu_t\,\mathbf 1[v_t(x^\star;Z)>v_t(x;Z)\ \forall x\in C\setminus\{x^\star\}]\), where \(v_t(x;Z)=u_t(x)+\sum_{z\in Z}p_t(z,x)\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) and \(B\) be disjoint finite sets of core options and candidate additions, with \(k=|C|\ge 2\), \(m=|B|\), and target \(x^\star\in C\).
A society is given by its support: a list \(\mathcal T\) of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each context-dependent random utility model (CDM) type supplies signed binary rational utilities \(u_t(x)\) for \(x\in C\) and pulls \(p_t(z,x)\) for \(z\in B\), \(x\in C\). The utilities include all context effects from the fixed core set.
For a shared choice \(Z\subseteq B\), define \(v_t(x;Z)=u_t(x)+\sum_{z\in Z}p_t(z,x)\). A type is promoted exactly when \(v_t(x^\star;Z)>v_t(x;Z)\) for every \(x\in C\setminus\{x^\star\}\); ties do not count, and added options are not competitors in this test.
Define \(F(Z)=\sum_{t\in\mathcal T}\mu_t\mathbf 1[\forall x\in C\setminus\{x^\star\},\ v_t(x^\star;Z)>v_t(x;Z)]\). Additions have no costs or cardinality bound; the empty set is allowed.
Given a binary rational threshold \(q\in[0,1]\), is deciding whether some \(Z\subseteq B\) satisfies \(F(Z)\ge q\) solvable in polynomial time, or is it NP-hard? State running times in \(m,k,\tau,L\), where \(L\) is the total input bit length.
For a finite list of individuals, CDM promotion is NP-hard even with two individuals and two core options; it is also NP-hard with one individual and three core options. No separate result for the rational-mass formulation is supplied by these discrete results.

Modeling choices made when packaging the task

  • Utilities and pulls had no finite input encoding specified; take them to be signed binary rationals.
  • Interpret the supplied utilities as effective utilities on the fixed core set, absorbing all pulls exerted by core options.
  • Introduce a binary rational threshold q in [0,1] to state the decision version of the maximization question.
  • Specify disjoint core and addition sets and at least two core options, consistent with the anchored setting.
  • Retain unrestricted subset additions, including the empty set, with no costs or cardinality bound.
  • Define m as the number of candidate additions, k as the number of core options, and L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is \(\mathrm{NP}\)-complete. It is already \(\mathrm{NP}\)-hard with \((k,\tau)=(2,2)\), equal masses, and \(q=1\); it is also \(\mathrm{NP}\)-hard with \((k,\tau)=(3,1)\) and \(q=1\). Thus fixing the support size does not yield a polynomial-time algorithm unless \(\mathrm P=\mathrm{NP}\).

A general exact algorithm takes \(\mathcal O(2^m\tau k(m+1)L^2)\) bit operations. The case \((k,\tau)=(2,1)\) is polynomial-time solvable.

Membership in \(\mathrm{NP}\) and an exact running time. A certificate specifies \(Z\subseteq B\) using \(m\) bits. For each type and core option, compute \(v_t(x;Z)\), check all the required strict inequalities, and sum the masses of promoted types. Comparing that sum with \(q\) verifies the certificate.

These computations can use exact rational arithmetic with operands of \(\mathcal O(L)\) bits. Indeed, for any sum of input rationals, take the product of their denominators as a common denominator. Its bit length is at most the sum of the input denominator lengths. The resulting numerator has bit length bounded by the total relevant input length plus the logarithm of the number of summands, hence by \(\mathcal O(L)\). Cross-products used in comparisons also have \(\mathcal O(L)\) bits.

Using schoolbook integer arithmetic, verification therefore takes \(\mathcal O(\tau k(m+1)L^2)\) bit operations. This proves membership in \(\mathrm{NP}\). Enumerating all \(2^m\) subsets gives the stated exact running time.

Hardness with two types and two core options. We reduce from the standard \(\mathrm{NP}\)-complete problem SUBSET SUM: given positive binary integers \(a_1,\ldots,a_m\) and a positive binary integer \(T\), decide whether some \(I\subseteq\{1,\ldots,m\}\) satisfies \(\sum_{i\in I}a_i=T\).

Set \(C=\{x^\star,y\}\), \(B=\{z_1,\ldots,z_m\}\), and introduce two types, each of mass \(1/2\). Set \(q=1\). Their utilities and pulls are:

| Type | \(u_t(x^\star)\) | \(u_t(y)\) | \(p_t(z_i,x^\star)\) | \(p_t(z_i,y)\) |
|---|---:|---:|---:|---:|
| \(t_1\) | \(1-2T\) | \(0\) | \(2a_i\) | \(0\) |
| \(t_2\) | \(1+2T\) | \(0\) | \(-2a_i\) | \(0\) |

For a chosen \(Z\), write \(S(Z)=\sum_{i:z_i\in Z}a_i\). The utility differences are

\(v_{t_1}(x^\star;Z)-v_{t_1}(y;Z)=1+2(S(Z)-T)\),

\(v_{t_2}(x^\star;Z)-v_{t_2}(y;Z)=1-2(S(Z)-T)\).

Because \(S(Z)-T\) is an integer, the first difference is positive exactly when \(S(Z)\ge T\), and the second is positive exactly when \(S(Z)\le T\). Consequently, both types are promoted exactly when \(S(Z)=T\).

Both masses are positive and sum to \(1\), so \(F(Z)\ge1\) holds exactly when both types are promoted. Therefore the constructed instance is a yes-instance exactly when the SUBSET SUM instance is a yes-instance.

All constructed values are signed integers, hence permitted binary rationals. Doubling an input integer and adding or subtracting \(1\) increases its encoding length by only a constant. The construction is polynomial-time and satisfies every model requirement. It proves \(\mathrm{NP}\)-hardness with \(k=2\) and \(\tau=2\).

Hardness with one type and three core options. Using the same SUBSET SUM instance, take \(C=\{x^\star,y_1,y_2\}\), the same additions, and one type of mass \(1\). Again set \(q=1\). Define

\(u(x^\star)=0,\qquad u(y_1)=2T-1,\qquad u(y_2)=-2T-1\),

and, for every addition,

\(p(z_i,x^\star)=0,\qquad p(z_i,y_1)=-2a_i,\qquad p(z_i,y_2)=2a_i\).

The target’s utility differences against the two competitors are

\(v(x^\star;Z)-v(y_1;Z)=1+2(S(Z)-T)\),

\(v(x^\star;Z)-v(y_2;Z)=1-2(S(Z)-T)\).

By the same integer argument, both strict inequalities hold exactly when \(S(Z)=T\). The single type has mass \(1\), so this is also exactly when \(F(Z)\ge q\). The construction again has polynomial encoding length and proves the second restricted hardness claim.

These explicit constructions establish hardness for rational masses directly. They do not require assuming that the supplied discrete-population results automatically extend to this formulation.

Polynomial-time boundary: one type and two core options. Suppose \(\tau=1\) and \(C=\{x^\star,y\}\). The sole mass must be \(1\). If \(q=0\), every instance is a yes-instance. Otherwise, promotion is necessary and sufficient.

Define \(a=u(x^\star)-u(y)\) and \(b_z=p(z,x^\star)-p(z,y)\). The target is promoted exactly when

\(a+\sum_{z\in Z}b_z>0\).

With no cost or cardinality constraint, this expression is maximized by selecting every addition with \(b_z>0\). Its maximum is

\(M=a+\sum_{z\in B}\max\{0,b_z\}\).

To justify optimality, including a positive term increases the expression, including a negative term decreases it, and including a zero term leaves it unchanged. Thus a feasible subset exists exactly when \(M>0\). Computing this maximum takes \(\mathcal O((m+1)L^2)\) bit operations. Equality \(M=0\) correctly yields a no-instance because ties do not count.
