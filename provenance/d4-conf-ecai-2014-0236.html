The continuous mirror question, as graded

Given finitely many types \(a\in T\) with rational masses \(\mu_a>0\), \(\sum_a\mu_a=1\), a symmetric interaction matrix \(q_{ab}\), parameters \(b>c>0\) and \(\beta>0\), initial states \(y_a(0)\in[0,1]\), a target \(x^\star\in[0,1]\), and a controllable type \(r\) with \(\mu_r>0\), define \(d_a=\sum_b\mu_bq_{ab}\), \(F_a(y)=-cd_ay_a+b\sum_b\mu_bq_{ab}y_b\), \(p_{ab}(y)=q_{ab}\sigma(\beta(F_b(y)-F_a(y)))\), and \(g_a(y)=d_a^{-1}\sum_b\mu_bp_{ab}(y)(y_b-y_a)\), where \(\sigma(z)=(1+e^{-z})^{-1}\). With the type-interaction graph connected and every \(d_a>0\), the dynamics are \(\dot y_a=g_a(y)+\mathbf{1}_{a=r}u_r(t)\), with the same signal applied to all members of type \(r\). Construct an admissible feedback \(u_r(t)\) that ensures \(\lim_{t\to\infty}y_a(t)=x^\star\) for every type \(a\).

Define \(F_a(y)=-cd_ay_a+b\sum_{j\in T}\mu_jq_{aj}y_j\), \(\sigma(z)=(1+e^{-z})^{-1}\), \(p_{aj}(y)=q_{aj}\sigma(\beta(F_j(y)-F_a(y)))\), and \(g_a(y)=d_a^{-1}\sum_{j\in T}\mu_jp_{aj}(y)(y_j-y_a)\).

Polynomial-time synthesis

Every instance satisfying the stated hypotheses admits the feedback
\(U(t,y)=x^\star-y_r\).
Its description can be constructed in polynomial time. The proof below applies to arbitrary positive masses, positive diagonal entries, and targets at either endpoint of the state interval.

1. Closed-loop dynamics

Define
\[ \]
\(k_{aj}(y)=\dfrac{\mu_jq_{aj}}{d_a}\sigma\bigl(\beta(F_j(y)-F_a(y))\bigr).\)

Under the proposed feedback, the vector field is
\(H_a(y)=\sum_{j\in T}k_{aj}(y)(y_j-y_a)+\mathbf 1_{\{a=r\}}(x^\star-y_a).\)

The coefficients have three properties used below:

  • \(k_{aj}(y)\geq 0\) for every \(y\).
  • If \(q_{aj}>0\), then \(k_{aj}(y)>0\), because \(\mu_j>0\), \(d_a>0\), and the logistic function is strictly positive.
  • Each \(k_{aj}\), and hence \(H\), is smooth on \(\mathbb R^\tau\).

Diagonal terms contribute zero to the drift because \(y_a-y_a=0\). Their contributions to \(d_a\) and \(F_a\) are retained.

2. Admissibility and invariance

We use the following elementary fact about finitely many differentiable functions: their maximum is locally Lipschitz, and its right derivative equals the maximum of the derivatives among functions currently attaining that maximum. Indeed, functions strictly below the maximum remain below it for sufficiently small positive increments, and first-order expansions give the formula for the remaining functions. Thus, if every active derivative is nonpositive, the maximum is nonincreasing. The corresponding statement holds for minima.

Smoothness of \(H\) gives a unique local continuously differentiable solution. Along this solution, set
\(M(t)=\max\bigl(\{x^\star\}\cup\{y_a(t):a\in T\}\bigr)\)
and
\(\ell(t)=\min\bigl(\{x^\star\}\cup\{y_a(t):a\in T\}\bigr)\).

If \(y_a(t)=M(t)\), then \(y_j(t)-y_a(t)\leq 0\) for every \(j\), and \(x^\star-y_a(t)\leq 0\). Nonnegativity of the coefficients therefore gives \(H_a(y(t))\leq 0\). The constant function \(x^\star\) has derivative zero. Consequently, \(M\) is nonincreasing.

Similarly, if \(y_a(t)=\ell(t)\), every difference in its drift is nonnegative, so \(H_a(y(t))\geq 0\). Hence \(\ell\) is nondecreasing.

The supplied initial states and target belong to \([0,1]\). Therefore, throughout the maximal existence interval,
\(0\leq\ell(0)\leq\ell(t)\leq y_a(t)\leq M(t)\leq M(0)\leq 1.\)

The trajectory stays in the compact cube \([0,1]^\tau\). Since \(H\) is smooth on a neighborhood of this cube, the ODE continuation theorem extends the solution for all nonnegative times.

Finally, \(U(t,y)=x^\star-y_r\) is continuous and locally bounded, and along the trajectory \(|U(t,y(t))|\leq 1\). The unique global solution is continuously differentiable and thus absolutely continuous on every bounded time interval. The feedback is admissible.

3. Convergence to the target

Write \(z_a=y_a-x^\star\), and define the maximum target error
\(V(y)=\max_{a\in T}|z_a|.\)

We first prove that \(V(y(t))\) is nonincreasing. Express \(V\) as the maximum of the finitely many differentiable functions \(z_a\) and \(-z_a\). If a signed coordinate \(\varepsilon z_a\), with \(\varepsilon\in\{-1,1\}\), attains this maximum, then
\(\varepsilon z_a=V\) and \(\varepsilon z_j\leq V\) for every \(j\). Its derivative is
\(\varepsilon\dot z_a=\sum_{j\in T}k_{aj}(y)(\varepsilon z_j-V)-\mathbf 1_{\{a=r\}}V\leq 0.\)

The maximum rule from Section 2 proves the assertion. Since \(V\) is nonnegative, there exists a limit
\(R=\lim_{t\to\infty}V(y(t))\geq 0.\)

We show that \(R=0\).

By compactness, choose times \(t_n\to\infty\) such that \(y(t_n)\to\bar y\in[0,1]^\tau\). Let \(\bar y(s)\) be the closed-loop trajectory starting from \(\bar y\).

For every fixed \(s\geq 0\), continuous dependence on initial conditions gives
\(y(t_n+s)\to\bar y(s).\)
To check this application explicitly, both trajectories remain in the cube, where the smooth vector field has a finite Lipschitz constant \(K\). Gronwall’s inequality gives
\(\|y(t_n+s)-\bar y(s)\|_\infty\leq e^{Ks}\|y(t_n)-\bar y\|_\infty.\)

Continuity of \(V\) now yields
\(V(\bar y(s))=R\)
for every \(s\geq 0\).

Suppose, for contradiction, that \(R>0\). At time \(s=1\), choose a type \(a\) and sign \(\varepsilon\in\{-1,1\}\) satisfying
\(\varepsilon(\bar y_a(1)-x^\star)=R.\)

For every type \(j\) and every \(s\geq 0\),
\(\varepsilon(\bar y_j(s)-x^\star)\leq R.\)
Thus any coordinate attaining this signed value at time \(1\) has a differentiable local maximum there, and its derivative is zero.

In particular,
\(0=\sum_{j\in T}k_{aj}(\bar y(1))\bigl(\varepsilon(\bar y_j(1)-x^\star)-R\bigr)-\mathbf 1_{\{a=r\}}R.\)

Every summand is nonpositive. If \(a=r\), the right-hand side is strictly negative, a contradiction. Otherwise, for every neighbor \(j\) with \(q_{aj}>0\), strict positivity of \(k_{aj}\) forces
\(\varepsilon(\bar y_j(1)-x^\star)=R.\)

The same reasoning applies to every such neighbor: it also attains the global signed bound at the interior time \(1\), so its derivative is zero. Following a path in the connected off-diagonal interaction graph propagates this equality from \(a\) to \(r\).

At \(r\), the displayed derivative equation has nonpositive interaction terms and the strictly negative term \(-R\). This contradicts its derivative being zero. Therefore \(R=0\), proving
\(\lim_{t\to\infty}y_a(t)=x^\star\)
for every \(a\in T\).

4. Construction complexity

The synthesis algorithm outputs the expression
\(U(t,y)=x^\star-y_r\).

It copies the supplied rational target and identifies the controlled coordinate. The description uses one subtraction, has length \(O(L+\log\tau)\), and can be constructed in polynomial time in the input bit length. It requires no evaluation of exponentials and no simulation of the dynamics.

Thus, for the stipulated scalar setting \(m=1\), feedback synthesis is polynomial-time solvable. Every promised instance is feasible. This classification concerns constructing the feedback description; it does not assert a polynomial bound on convergence time.
