The continuous mirror question, as graded

Given a finite set of participant-argument types \(T\), an attack relation \(R\subseteq T\times T\), binary-rational masses \(\mu_t>0\) summing to \(1\), and a goal type \(g\), consider the complete extensions of the AF \((T,R)\). For a complete extension \(E\), let \(D(E)=\{t\in T:\exists u\in E,\ (u,t)\in R\}\), \(U(E)=T\setminus(E\cup D(E))\), and \(u_\mu(E)=\sum_{t\in U(E)}\mu_t\). Decide whether a supplied \(E\) minimizes \(u_\mu\) among complete extensions, whether some such minimizing extension contains \(g\), or whether every such minimizing extension contains \(g\).

Classification

All three problems are \(\mathrm{NP}\)-hard under polynomial-time Turing reductions, even when all masses are equal dyadic rationals. Thus none has a polynomial-time algorithm unless \(\mathrm{P}=\mathrm{NP}\).

For arbitrary binary-encoded rational masses, we additionally obtain:

| Problem | Proven classification |
|---|---|
| Whether a supplied set is retained | \(\mathrm{coNP}\)-complete; hence \(\mathrm{NP}\)-hard under polynomial-time Turing reductions |
| Whether some retained extension contains the goal | \(\Theta_2^{\mathrm P}\)-hard and in \(\mathrm{P}^{\mathrm{NP}}\) |
| Whether every retained extension contains the goal | \(\Theta_2^{\mathrm P}\)-hard and in \(\mathrm{P}^{\mathrm{NP}}\) |

The bounds on acceptance do not assert an exact complexity classification for arbitrary rational masses. They do settle the requested hardness question.

1. Complete extensions and exact objective evaluation

Define the set of arguments defended by a set \(E\) as

\(\operatorname{Acc}(E)=\{t\in T:\text{every }s\text{ with }(s,t)\in R\text{ belongs to }D(E)\}\).

Under ordinary Dung semantics, \(E\) is complete exactly when

\(E\cap D(E)=\varnothing\quad\text{and}\quad E=\operatorname{Acc}(E)\).

Consequently, completeness can be checked in \(O(m+\tau)\) graph operations:

  • Scan the attacks to compute \(D(E)\).
  • Check that \(E\cap D(E)=\varnothing\).
  • Initially mark every type as defended. For every attack \((s,t)\) with \(s\notin D(E)\), mark \(t\) as not defended.
  • Check that the defended types are exactly \(E\).

This procedure includes self-attacks and types with no attackers.

Every finite Dung framework has a grounded extension, which is complete. Since the explicitly listed set \(T\) is finite, there is at least one complete extension, and the minimum objective value exists.

Write each input mass as \(\mu_t=p_t/q_t\), with positive integers encoded in binary. Set

\(Q=\prod_{t\in T}q_t,\qquad w_t=p_t(Q/q_t)\).

Then every \(w_t\) is a positive integer, and normalization gives

\(\sum_{t\in T}w_t=Q\).

For any set \(E\), define

\(W(E)=\sum_{t\in U(E)}w_t\).

We have \(u_\mu(E)=W(E)/Q\). Hence minimizing \(u_\mu\) is exactly equivalent to minimizing \(W\), including all ties.

The integers \(Q\) and \(w_t\) have \(O(L)\) bits: the bit length of a product is bounded by the sum of the bit lengths of its factors. Using schoolbook integer arithmetic, they can be computed in \(O(\tau L^2)\) bit operations. Subsequently, evaluating \(W(E)\), once \(U(E)\) is known, takes \(O(\tau L)\) bit operations.

Thus large denominator values do not require expanding the society into individual units.

2. Transferring the discrete hardness results

The cited paper defines *cardinality semi-stable* extensions as complete extensions minimizing the number of undecided arguments. Its Theorem 4 states that verification is \(\mathrm{coNP}\)-complete and that both credulous and skeptical acceptance are \(\Theta_2^{\mathrm P}\)-complete for this semantics. Its definition of undecided arguments is exactly \(T\setminus(E\cup D(E))\). [Alfano et al., Definition 4 and Theorem 4](https://www.ijcai.org/proceedings/2022/0349.pdf)

Here is a polynomial-size reduction that also ensures the masses are dyadic.

Let \((A,R)\) be a discrete framework with \(n=|A|\geq 1\). Choose the least power of two \(N\) satisfying \(N\geq n\). Add a set \(I\) of \(N-n\) fresh isolated arguments, and define the society by

\(T=A\cup I,\qquad \mu_t=1/N\quad(t\in T)\),

with exactly the original attacks \(R\). We have \(n\leq N<2n\), so the construction has polynomial size. The masses are positive dyadic rationals and sum to one.

Complete-extension correspondence

The complete extensions of the padded framework are exactly

\(\{E\cup I:E\text{ is a complete extension of }(A,R)\}\).

Indeed, every isolated argument has no attackers, so every set defends it. Completeness therefore requires all of \(I\) to be accepted. Isolated arguments neither attack original arguments nor introduce new attackers, so conflict-freeness and defense on \(A\) remain exactly as in the original framework.

Furthermore,

\(D_T(E\cup I)=D_A(E),\qquad U_T(E\cup I)=U_A(E)\).

Consequently,

\(u_\mu(E\cup I)=|U_A(E)|/N\).

Multiplication by the fixed positive factor \(1/N\) preserves every objective comparison and every tie. Thus the retained extensions are exactly the padded cardinality semi-stable extensions.

Consequences for the three problems

For verification, map an original supplied set \(S\) to \(S\cup I\). The correspondence preserves both completeness and retention, so verification in the society model is \(\mathrm{coNP}\)-hard.

For either acceptance problem, keep the original goal \(g\in A\). Since \(g\in E\cup I\) exactly when \(g\in E\), credulous and skeptical acceptance both inherit \(\Theta_2^{\mathrm P}\)-hardness. In particular, they are \(\mathrm{NP}\)-hard, because \(\mathrm{NP}\subseteq\Theta_2^{\mathrm P}\).

Finally, \(\mathrm{coNP}\)-hardness implies the requested Turing \(\mathrm{NP}\)-hardness for verification. For any language \(B\in\mathrm{NP}\), its complement belongs to \(\mathrm{coNP}\), so it reduces to verification. One verification-oracle query followed by negation decides membership in \(B\).

This proves the requested hardness classification for all three problems.

3. Upper bounds for arbitrary rational masses

Verification is in \(\mathrm{coNP}\)

The complement of verification has a polynomial-time certificate procedure.

If the supplied set \(S\) is not complete, the deterministic completeness check establishes rejection. Otherwise, non-retention means that there exists a complete extension \(F\) with

\(W(F)<W(S)\).

The certificate is the \(\tau\)-bit membership vector of \(F\). Completeness and the strict integer comparison are checkable in polynomial time.

Therefore verification belongs to \(\mathrm{coNP}\). Together with Section 2, this proves \(\mathrm{coNP}\)-completeness for arbitrary rational masses.

Acceptance belongs to \(\mathrm{P}^{\mathrm{NP}}\)

Consider the threshold predicate

\(\mathcal{B}(k):\quad\text{there exists a complete extension }E\text{ with }W(E)\leq k\).

It belongs to \(\mathrm{NP}\): guess \(E\), check completeness, and evaluate its integer objective.

Let

\(W^*=\min\{W(E):E\text{ is complete}\}\).

Because \(0\leq W(E)\leq Q\), binary search using \(\mathcal{B}\) finds \(W^*\) with \(O(\log(Q+1))=O(L)\) adaptive \(\mathrm{NP}\)-oracle queries.

Once \(W^*\) is known:

  • Credulous acceptance asks whether there exists a complete \(E\) with \(W(E)=W^*\) and \(g\in E\).
  • Skeptical acceptance negates the answer to whether there exists a complete \(E\) with \(W(E)=W^*\) and \(g\notin E\).

Each existential question belongs to \(\mathrm{NP}\). Thus both acceptance problems belong to \(\mathrm{P}^{\mathrm{NP}}\), using \(O(L)\) oracle queries.

For equal masses, the objective has only \(\tau+1\) possible cardinality values, giving \(O(\log(\tau+1))\) queries instead. That shorter search does not follow for arbitrary rational masses.

4. Running times in the stated input parameters

A deterministic algorithm for all three problems enumerates the \(2^\tau\) subsets of the listed support, checks completeness, and evaluates the complete extensions.

During enumeration it maintains the minimum objective. For acceptance it also maintains whether the goal appears in some or every extension attaining the current minimum; these flags are reset whenever a smaller value is found.

With indexed graph access, a conservative bound charging logarithmic cost for graph indices is

\(O\!\left(\tau L^2+2^\tau\bigl((m+\tau)\log(\tau+1)+\tau L\bigr)\right)\).

The preprocessing term performs the exact rational-to-integer conversion. The per-subset terms perform the graph checks and integer summation. Storage is polynomial in \(m+\tau+L\), because extensions can be processed individually.

The oracle algorithms above use polynomial deterministic work in \(m,\tau,L\); their threshold and final-query witnesses can each be checked in

\(O\!\left((m+\tau)\log(\tau+1)+\tau L\right)\)

after preprocessing.

These bounds depend on the number \(\tau\) of explicitly listed types, never on an ambient space of possible types or on a numerical expansion of the masses. In particular, fixed \(\tau\) gives polynomial running time in \(L\); hardness concerns unbounded listed support.
