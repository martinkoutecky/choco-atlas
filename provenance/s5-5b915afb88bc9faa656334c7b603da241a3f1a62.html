The anchor (named result in the paper)

Theorem 3.1 (Strong NP-completeness) — class: hardness

The continuous mirror question, as graded

Given good-category values \(w_j\), rational per-capita supplies \(q_j\), and a positive rational threshold \(\theta\), decide whether there is a finite-support mass distribution \(x_{\mathbf b}\) over integral bundles \(\mathbf b\in\mathbb{N}^p\) such that \(\sum_{\mathbf b}x_{\mathbf b}=1\), \(\sum_{\mathbf b}x_{\mathbf b}b_j=q_j\) for every category \(j\), the allocation is EF1 across all positive-mass bundles, and \(\exp(\sum_{\mathbf b:x_{\mathbf b}>0}x_{\mathbf b}\ln u(\mathbf b))\geq\theta\), where \(u(\mathbf b)=\sum_jw_jb_j\).

Packaged proof task (what the prover saw — nothing else)

There are \(m=p\geq1\) good categories, with binary-encoded values \(w_j\in\mathbb Z_{\geq0}\), per-capita supplies \(q_j\in\mathbb Q_{\geq0}\), and threshold \(\theta\in\mathbb Q_{>0}\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here the society has one identical additive valuation type of mass \(1\), so \(\tau=1\).
An allocation is a finite-support distribution of rational masses \(x_{\mathbf b}>0\) over bundles \(\mathbf b\in\mathbb Z_{\geq0}^{m}\), satisfying \(\sum_{\mathbf b}x_{\mathbf b}=1\) and \(\sum_{\mathbf b}x_{\mathbf b}b_j=q_j\) for every category. Its support is chosen by the allocation, with no prescribed size bound.
Write \(u(\mathbf b)=\sum_jw_jb_j\). EF1 requires that for every ordered pair of supported bundles \(\mathbf b,\mathbf c\) with \(\mathbf c\neq\mathbf0\), some category \(j\) with \(c_j>0\) satisfies \(u(\mathbf b)\geq u(\mathbf c)-w_j\).
Define welfare as \(\exp(\sum_{\mathbf b}x_{\mathbf b}\ln u(\mathbf b))\) when every supported utility is positive, and as \(0\) otherwise. Only the final allocation must satisfy EF1.

Is deciding whether such an EF1 allocation has welfare at least \(\theta\) in \(\mathsf P\), or is it NP-hard? State running times in \(m\), \(\tau\), and the total input bit length \(L\).

For finitely many agents and explicitly listed indivisible goods, the corresponding threshold problem with identical nonnegative integer values is strongly NP-complete ([source](https://arxiv.org/html/2609.03846v4)).
No result settling this exact mass-distribution problem was identified in the literature search.

Modeling choices made when packaging the task

  • The value domain was unspecified; retained the discrete decision problem's nonnegative integer values, encoded in binary.
  • The supply domain was unspecified; used nonnegative binary rational per-capita supplies, allowing zero supplies.
  • Applied the rational-mass convention to the allocation distribution; its finite support is chosen without a prescribed size bound.
  • Distinguished valuation types from allocated bundles: the input society has one identical valuation type of mass one, while the allocation may support many bundles.
  • Made EF1 explicit as removal of one item from the compared nonempty bundle, with no condition for an empty compared bundle.

Result

The problem is \(\mathsf{NP}\)-hard under polynomial-time many-one reductions, already when \(\tau=1\), every supply equals \(\tfrac12\), every value is positive, and the threshold equals mean utility.

The proof accommodates arbitrary finite allocation support and arbitrary positive rational masses.

1. Welfare at mean utility forces equal utilities

Define mean utility by \(\mu=\sum_{j=1}^{m}w_jq_j\). Every feasible allocation satisfies

\(\displaystyle \sum_{\mathbf b}x_{\mathbf b}u(\mathbf b)=\sum_{j=1}^{m}w_j\sum_{\mathbf b}x_{\mathbf b}b_j=\mu.\)

Suppose \(\mu>0\). If a supported bundle has zero utility, welfare is zero and hence less than \(\mu\). Otherwise, strict concavity of the logarithm gives

\(\displaystyle \sum_{\mathbf b}x_{\mathbf b}\ln u(\mathbf b)\leq \ln\!\left(\sum_{\mathbf b}x_{\mathbf b}u(\mathbf b)\right)=\ln\mu.\)

Because every supported mass is positive, equality holds exactly when all supported utilities are equal. Their common value must then be \(\mu\). Consequently,

\(\displaystyle \text{welfare}\geq\mu\quad\Longleftrightarrow\quad u(\mathbf b)=\mu\text{ for every supported }\mathbf b.\)

Such an allocation satisfies EF1: for any supported nonzero bundle \(\mathbf c\), choose any category \(j\) with \(c_j>0\). Then

\(\displaystyle u(\mathbf b)=\mu\geq\mu-w_j=u(\mathbf c)-w_j.\)

We will therefore construct instances where attaining mean utility encodes a partition.

2. Reduction from PARTITION

We use the classical \(\mathsf{NP}\)-complete PARTITION problem: given positive binary integers \(a_1,\ldots,a_n\), decide whether some subset has half their total sum. Its completeness is established in [Karp’s paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

We may assume their total is an even positive integer \(2B\). This restriction preserves hardness: doubling every number in an arbitrary PARTITION instance produces an even-total instance with the same answer.

Set

\(\displaystyle r=n+1,\qquad D=2nB+1,\qquad H=Dr^n,\qquad d_i=Dr^{i-1}\quad(1\leq i\leq n).\)

Create two categories for each \(i\), with values

\(\displaystyle w_{i,+}=H+d_i+a_i,\qquad w_{i,-}=H+d_i.\)

Thus \(m=p=2n\). Give every category supply \(\tfrac12\), and use one identical valuation type of mass \(1\), so \(\tau=1\). Define

\(\displaystyle \theta=nH+\sum_{i=1}^{n}d_i+B.\)

All values and the threshold are positive integers. Moreover,

\(\displaystyle \mu=\frac12\sum_{i=1}^{n}(w_{i,+}+w_{i,-})=nH+\sum_{i=1}^{n}d_i+\frac12\sum_{i=1}^{n}a_i=\theta.\)

3. Characterization of bundles at the threshold

Lemma. A nonnegative integer bundle \(\mathbf b\) has utility \(\theta\) exactly when it selects one item from each category pair and the indices selecting the \(+\) category form a subset summing to \(B\).

Proof. Write its coordinates as \(b_{i,+},b_{i,-}\), and let

\(\displaystyle k=\sum_{i=1}^{n}(b_{i,+}+b_{i,-}),\qquad d_{\max}=Dr^{n-1}.\)

First observe that

\(\displaystyle H-n(d_{\max}+2B)=Dr^{n-1}(r-n)-2nB=Dr^{n-1}-2nB>0,\)

because \(r-n=1\), \(r^{n-1}\geq1\), and \(D=2nB+1\). Therefore

\(\displaystyle nH<\theta\leq nH+nd_{\max}+B<(n+1)H.\)

Every item has value at least \(H\). Thus \(u(\mathbf b)=\theta\) implies \(k\leq n\).

Conversely, each item has value at most \(H+d_{\max}+2B\), since \(a_i\leq2B\). If \(k\leq n-1\), then

\(\displaystyle u(\mathbf b)\leq kH+k(d_{\max}+2B)<kH+H\leq nH<\theta.\)

Hence necessarily \(k=n\).

Now define

\(\displaystyle s_i=b_{i,+}+b_{i,-},\qquad t=\sum_{i=1}^{n}a_ib_{i,+}.\)

Subtracting \(nH\) from the utility equation gives

\(\displaystyle D\sum_{i=1}^{n}s_ir^{i-1}+t=D\sum_{i=1}^{n}r^{i-1}+B.\)

Since there are exactly \(n\) items,

\(\displaystyle 0\leq t\leq2nB<D,\qquad 0<B<D.\)

Reducing the equation modulo \(D\) therefore yields \(t=B\). Dividing the remaining equation by \(D\) yields

\(\displaystyle \sum_{i=1}^{n}s_ir^{i-1}=\sum_{i=1}^{n}r^{i-1}.\)

Each \(s_i\) lies between \(0\) and \(n=r-1\). Both sides are thus base-\(r\) expansions with valid digits. Uniqueness of that expansion gives \(s_i=1\) for every \(i\).

The nonnegative integer coordinates consequently satisfy

\(\displaystyle (b_{i,+},b_{i,-})\in\{(1,0),(0,1)\}.\)

The equality \(t=B\) says precisely that the indices selecting \((1,0)\) have original values summing to \(B\).

Conversely, choosing one item from each pair according to any subset summing to \(B\) gives utility \(nH+\sum_i d_i+B=\theta\). This proves the lemma. \(\square\)

4. Correctness of the reduction

A partition gives a feasible EF1 allocation

Suppose \(S\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in S}a_i=B\).

Construct \(\mathbf b\) by choosing the \(+\) category for indices in \(S\) and the \(-\) category otherwise. Construct \(\mathbf c\) using the opposite choice in every pair.

The complementary subset also sums to \(B\), so the lemma gives

\(\displaystyle u(\mathbf b)=u(\mathbf c)=\theta.\)

Give each bundle mass \(\tfrac12\). These masses are positive rationals and sum to \(1\). Each category appears once across the two bundles, so its expected quantity is exactly \(\tfrac12\), as required.

Equal utilities imply EF1 by Section 1. Welfare is exactly

\(\displaystyle \exp\!\left(\tfrac12\ln\theta+\tfrac12\ln\theta\right)=\theta.\)

A qualifying allocation gives a partition

Conversely, suppose any feasible EF1 allocation has welfare at least \(\theta\). Its mean utility is \(\mu=\theta\), so Section 1 forces every supported bundle to have utility \(\theta\).

The support is nonempty because its masses sum to \(1\). Choose any supported bundle. The lemma extracts from it a subset of the original numbers summing to \(B\).

Thus the allocation instance is a yes-instance exactly when the PARTITION instance is a yes-instance. This direction uses no bound on support size and no restriction on the positive rational masses.

5. Bit lengths and running times

Let \(N\) be the source instance’s total bit length, and put

\(\displaystyle K=1+\left\lceil\log_2(B+1)\right\rceil+n\left\lceil\log_2(n+1)\right\rceil.\)

Every constructed value and the threshold have \(O(K)\) bits. The supplies and society description have constant bit length per entry. Hence the constructed total input length satisfies

\(\displaystyle L=O(nK),\qquad m=2n,\qquad \tau=1.\)

Repeated multiplication computes the powers of \(r\); using schoolbook integer arithmetic, the entire reduction takes \(O(nK^2)\) bit operations. Since \(n\leq N\) and \(\log_2(B+1)=O(N)\), this is polynomial in the source length \(N\). A coarser bound in the constructed parameters is \(O(mL^2)\).

Therefore, unless \(\mathsf P=\mathsf{NP}\), the target problem has no algorithm running in \(\operatorname{poly}(m,\tau,L)\). Hardness at \(\tau=1\) also excludes a running time \(f(\tau)\operatorname{poly}(m,L)\) under the same assumption.

This settles the requested hardness alternative. The reduction establishes ordinary \(\mathsf{NP}\)-hardness; it does not assert strong hardness or membership of the general threshold problem in \(\mathsf{NP}\).
