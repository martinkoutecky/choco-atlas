The continuous mirror question, as graded

Given a finite candidate set \(C\), a listed support \(T\) of strict rankings, binary rational masses \(\mu_t \ge 0\) summing to \(1\), and a rational threshold \(\kappa\), is there a strict total order \(\sigma\) on \(C\) such that \(K_\mu(\sigma)=\sum_{t\in T}\mu_t d_{\mathrm{KT}}(t,\sigma)\le\kappa\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a finite candidate set with \(m=|C|\). A society is given by its support: a list \(T\) of \(\tau\) distinct strict rankings on \(C\), each with positive binary rational mass \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
Given a nonnegative binary rational threshold \(\kappa\), ask whether there exists a strict total order \(\sigma\) on \(C\) satisfying \(K_\mu(\sigma)=\sum_{t\in T}\mu_t d_{\mathrm{KT}}(t,\sigma)\le\kappa\), where \(d_{\mathrm{KT}}\) is Kendall–tau distance. The aggregate may be any strict total order, including one outside \(T\).

Is this decision problem solvable in time polynomial in \(m\), \(\tau\), and \(L\), or is it NP-hard?

Discrete Kemeny Score is NP-complete for exactly three unweighted strict rankings, even when every candidate pair is ordered one way by exactly two rankings and the opposite way by the third.

Modeling choices made when packaging the task

  • Zero-mass entries are omitted so that the listed types are exactly the positive-mass support.
  • The threshold is restricted to nonnegative binary rationals, following the discrete threshold domain; negative thresholds would yield only trivial no-instances.
  • The aggregate ranges over all strict total orders, rather than only the listed support rankings.
  • L denotes the total input bit length, including rankings, masses, and the threshold.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is \(\mathrm{NP}\)-complete, using the hardness premise supplied in the question. Hardness already holds when \(\tau\le 3\). Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

Reduction and proof of hardness. Take an instance of the stated Discrete Kemeny Score problem: three unweighted strict rankings \(r_1,r_2,r_3\) on \(C\), and a nonnegative integer bound \(B\). Its question is whether some strict total order \(\sigma\) satisfies
\[ \sum_{i=1}^{3}d_{\mathrm{KT}}(r_i,\sigma)\le B. \]

Let \(T\) contain the distinct rankings appearing among \(r_1,r_2,r_3\). For each \(t\in T\), let \(c_t\) be its multiplicity and set
\[ \mu_t=\frac{c_t}{3}, \qquad \kappa=\frac{B}{3}. \]
Thus \(\tau\le 3\), every mass is positive, and
\[ \sum_{t\in T}\mu_t=\frac{\sum_{t\in T}c_t}{3}=1. \]
Merging repeated rankings ensures that the constructed support satisfies the distinctness requirement.

For every strict total order \(\sigma\) on \(C\),
\[ K_\mu(\sigma) =\sum_{t\in T}\frac{c_t}{3}d_{\mathrm{KT}}(t,\sigma) =\frac13\sum_{i=1}^{3}d_{\mathrm{KT}}(r_i,\sigma). \]
Consequently,
\[ K_\mu(\sigma)\le\kappa \quad\Longleftrightarrow\quad \sum_{i=1}^{3}d_{\mathrm{KT}}(r_i,\sigma)\le B. \]
The two instances therefore have the same answer. Both allow \(\sigma\) to be any strict total order, so the reduction imposes no restriction that the aggregate belong to the support.

The construction takes polynomial time: it compares three input rankings, assigns constant-size rational masses, and encodes \(B/3\) with \(O(\log(B+1))\) bits. The supplied source problem is \(\mathrm{NP}\)-complete, proving \(\mathrm{NP}\)-hardness.

Membership in \(\mathrm{NP}\). A certificate is a permutation \(\sigma\) of \(C\), whose validity can be checked in polynomial time. Each Kendall–tau distance can be computed by examining all unordered candidate pairs, taking \(O(\tau m^2)\) comparisons altogether.

Exact rational arithmetic also takes polynomial time. Write the binary-encoded rationals as
\[ \mu_t=\frac{a_t}{b_t}, \qquad \kappa=\frac{p}{q}, \]
with positive denominators, and put
\[ D=\prod_{t\in T}b_t, \qquad N=\sum_{t\in T}a_t\frac{D}{b_t}d_{\mathrm{KT}}(t,\sigma). \]
Then \(K_\mu(\sigma)=N/D\), and acceptance is equivalent to the integer comparison
\[ qN\le pD. \]
The bit length of \(D\) is at most the sum of the denominator bit lengths, hence \(O(L)\). Moreover, since the masses sum to one and every distance is at most \(\binom{m}{2}\),
\[ 0\le N\le D\binom{m}{2}. \]
Thus all integers used have polynomial bit length, and verification is polynomial in \(m,\tau,L\). This proves membership in \(\mathrm{NP}\), completing the proof.
