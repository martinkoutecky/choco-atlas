The continuous mirror question, as graded

Given \(m\) alternatives and \(\tau\) supported complete rankings \(t\), each with binary-rational mass \(\mu_t\) summing to one, compute \(Q_\mu=\{(a,b):p_\mu(a,b)>\max\{\frac12,B_\mu[b,a]\}\}\), where \(p_\mu(a,b)=\sum_{t:\,a\succ_t b}\mu_t\) and \(B_\mu[b,a]\) is the maximum, over paths from \(b\) to \(a\) in the directed graph with edges \((x,y)\) satisfying \(p_\mu(x,y)>\frac12\), of the minimum \(p_\mu\)-strength along the path; set \(B_\mu[b,a]=0\) if no such path exists.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\geq 3\) alternatives. A society is given by its support: a list of \(\tau\) distinct strict complete rankings \(t\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
For distinct \(a,b\in A\), define \(p_\mu(a,b)=\sum_{t:\,a\succ_t b}\mu_t\). Form the directed graph whose edges are the distinct pairs \((x,y)\) with \(p_\mu(x,y)>\frac12\), weighted by \(p_\mu(x,y)\).
A path has at least one edge and distinct vertices. Let \(B_\mu[b,a]\) be the maximum, over paths from \(b\) to \(a\), of the minimum edge weight on the path, and set it to zero when no such path exists.
The required output is the exact relation \(Q_\mu=\{(a,b)\in A\times A:a\neq b,\ p_\mu(a,b)>\max\{\frac12,B_\mu[b,a]\}\}\); all comparisons are strict, so equality excludes a pair.

Is exact computation of \(Q_\mu\) possible in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite electorates, the corresponding relation is characterized by the same comparison of direct support with reverse-path strength and is computable in polynomial time ([Okumura, 2025](https://arxiv.org/abs/2304.09419v5)).

Result

Exact computation of \(Q_\mu\) is possible in deterministic polynomial time in \(m,\tau,L\).

The comparison supplied in the question also appears in Proposition 10 of [Okumura (2025)](https://arxiv.org/html/2304.09419v5#S5.SS2). The proof below works directly with the weighted support and establishes polynomial bit complexity without expanding it into individual voters.

1. Compute exact integer support weights

Use the usual binary encoding of rational numbers: write each mass as \(\mu_t=u_t/v_t\), where \(u_t,v_t\) are positive integers encoded in binary. This includes explicitly encoded dyadic rationals.

Define

\(D=\prod_{t=1}^{\tau}v_t,\qquad c_t=u_t(D/v_t).\)

Then \(\mu_t=c_t/D\). The normalization hypothesis gives \(\sum_t c_t=D\).

For each distinct pair \(a,b\), compute

\(N[a,b]=\sum_{t:\,a\succ_t b}c_t.\)

Consequently,

\(p_\mu(a,b)=N[a,b]/D,\qquad 0\leq N[a,b]\leq D.\)

The majority graph therefore has an edge from \(a\) to \(b\) exactly when \(2N[a,b]>D\). Give this edge integer weight \(N[a,b]\). Dividing every edge weight by \(D\) recovers the graph in the question.

For a nonempty path \(P\), define its integer bottleneck by

\(w(P)=\min_{(x,y)\text{ an edge of }P}N[x,y].\)

Because division by a positive constant commutes with minimum and maximum, the maximum integer bottleneck from \(b\) to \(a\), with value zero when no path exists, equals \(D B_\mu[b,a]\).

2. Compute maximum bottlenecks

Enumerate the alternatives as \(a_1,\ldots,a_m\). Initialize a matrix \(F^{(0)}\) as follows:

  • Set \(F^{(0)}[a,a]=D\) for every alternative \(a\).
  • For distinct \(a,b\), set \(F^{(0)}[a,b]=N[a,b]\) if \(2N[a,b]>D\), and set it to zero otherwise.

The diagonal entries are auxiliary values; they do not represent paths permitted by the question.

For \(k=1,\ldots,m\), compute a new matrix from the previous matrix using

\(F^{(k)}[a,b]=\max\bigl\{F^{(k-1)}[a,b],\ \min\{F^{(k-1)}[a,a_k],F^{(k-1)}[a_k,b]\}\bigr\}.\)

This requires \(O(m^3)\) minimum and maximum operations.

Correctness of the recurrence

We prove by induction that, for distinct \(a,b\), \(F^{(k)}[a,b]\) is the maximum integer bottleneck among simple paths from \(a\) to \(b\) whose internal vertices belong to \(\{a_1,\ldots,a_k\}\), with value zero when no such path exists. We also maintain \(F^{(k)}[a,a]=D\).

For \(k=0\), a path without internal vertices consists of a single edge, so the initialization proves the claim. All entries lie between zero and \(D\); hence the recurrence preserves the diagonal value \(D\).

Now assume the claim holds for \(k-1\), and fix distinct endpoints \(a,b\).

If \(a_k\) equals either endpoint, allowing it as an internal vertex introduces no additional simple paths. The recurrence likewise leaves the entry unchanged, since the corresponding diagonal entry is \(D\).

Suppose instead that \(a_k\) differs from both endpoints. Every admissible simple path either avoids \(a_k\) or has \(a_k\) as an internal vertex.

If it avoids \(a_k\), its bottleneck is at most \(F^{(k-1)}[a,b]\). Otherwise, simplicity ensures that it visits \(a_k\) exactly once. Splitting there gives two paths whose internal vertices belong to \(\{a_1,\ldots,a_{k-1}\}\). Its bottleneck is therefore at most

\(\min\{F^{(k-1)}[a,a_k],F^{(k-1)}[a_k,b]\}.\)

Thus every admissible path has bottleneck at most the recurrence’s right-hand side.

Conversely, paths already admissible at stage \(k-1\) remain admissible. If both entries in the minimum are positive, their maxima are attained: there are only finitely many simple paths on a finite vertex set. Concatenating attaining paths gives a directed walk from \(a\) to \(b\) with bottleneck equal to that minimum.

Whenever this walk repeats a vertex, delete the intervening closed portion. Each deletion preserves the endpoints and uses only edges already present in the walk, so it cannot decrease the bottleneck. Repeated deletion produces a simple path. Since \(a\neq b\), this path has at least one edge; its internal vertices belong to \(\{a_1,\ldots,a_k\}\). It therefore realizes at least the candidate value. If either entry in the minimum is zero, the candidate is zero and the lower bound is automatic.

This proves the invariant. At the final stage every internal vertex is allowed, so, for all distinct \(a,b\),

\(F^{(m)}[b,a]=D B_\mu[b,a].\)

3. Output the relation and bound bit complexity

Output precisely those distinct pairs satisfying both integer inequalities

\(2N[a,b]>D\qquad\text{and}\qquad N[a,b]>F^{(m)}[b,a].\)

By the preceding identities, these conditions are equivalent to

\(p_\mu(a,b)>\max\{\tfrac12,B_\mu[b,a]\}.\)

Both tests are strict. In particular, equality with the reverse-path strength excludes the pair exactly as required.

It remains to account for the size of the integers. If \(\operatorname{bits}(v_t)\) denotes the encoded denominator length, then

\(\log_2 D=\sum_t\log_2 v_t\leq\sum_t\operatorname{bits}(v_t)\leq L.\)

Thus \(D\) has \(O(L)\) bits. Every \(c_t\), support sum, partial support sum, and matrix entry lies between zero and \(D\). All arithmetic therefore involves \(O(L)\)-bit integers.

Computing \(D\) and the \(c_t\) requires polynomially many bit operations, using ordinary integer multiplication and exact division. Processing the explicitly listed rankings requires \(O(\tau m^2)\) support additions. The path computation requires \(O(m^3)\) comparisons, and the final output requires \(O(m^2)\) strict comparisons.

Every operation has polynomial bit cost, proving the claimed polynomial-time bound. Although \(D\) may be exponentially large as a numerical value, its binary length is \(O(L)\), and the algorithm never constructs an electorate of size \(D\).
