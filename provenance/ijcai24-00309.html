The continuous mirror question, as graded

Given \(m\) candidates \(C\), a query budget \(t\), and a unit-mass society with finite-support rational distribution \(\mu\) over latent complete metric voter types, choose a fixed measurable schedule \(Q(u)\subseteq\binom{C}{2}\) with \(\lvert Q(u)\rvert\le t\) and an aggregation rule; an aggregate oracle returns exact response masses, and the objective is to minimize worst-case \(\operatorname{cost}_{\mu}(a)/\min_{c\in C}\operatorname{cost}_{\mu}(c)\) over compatible hidden metric societies.

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge2\) and \(1\le t\le\binom m2\) be integers, and let \(C\) contain \(m\) candidates. A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(w_i\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. The designer sees type labels and masses; their complete rankings and metric attributes are hidden.
A hidden society consists of a shared pseudometric \(d\) on \(C\sqcup[\tau]\) and a strict complete ranking \(\succ_i\) for each type, with \(a\succ_i b\Rightarrow d(i,a)\le d(i,b)\). Distance ties may be resolved arbitrarily, but each type's ranking is fixed across queries. Define \(\operatorname{cost}_{\mu}(c)=\sum_iw_i d(i,c)\).
Each type's mass is divisible into an atomless block. Before receiving responses, choose a deterministic schedule \(Q(u)\subseteq\binom C2\), with \(|Q(u)|\le t\), represented by finitely many rational submasses of each type block, each assigned a fixed query set. The schedule may use labels and masses but cannot use hidden rankings or distances.
For each pair \(\{a,b\}\), the oracle returns the exact total mass assigned that query that prefers each endpoint, summed across all types; it reveals neither type-specific responses nor joint response patterns. A deterministic aggregation rule selects one candidate from these totals.
Let \(D(m,t)\) be the infimum, over such schedule-and-aggregation procedures, of the supremum of \(\operatorname{cost}_{\mu}(a)/\min_{c\in C}\operatorname{cost}_{\mu}(c)\) over all finite supports, rational mass vectors, and hidden societies. Interpret \(0/0=1\) and positive cost divided by zero as \(+\infty\). Running times and schedule encoding sizes are measured in \(m,\tau,L,t\), where \(L\) is the binary input length.

What is the asymptotically optimal worst-case distortion \(D(m,t)\), and can its asymptotic order be attained by procedures running in time polynomial in \(m,\tau,L,t\)?

For finite electorates, fully nonadaptive procedures have optimal distortion \(\Theta(m^2/t)\), with the upper bound requiring \(n\ge\binom m2/t\) ([source](https://daniel-halpern.com/files/metric-distortion-with-queries.pdf)).
No result settling this exact divisible-mass, aggregate-response model was identified in the literature search.

Modeling choices made when packaging the task

  • Resolved the conflict between a supplied support distribution and latent preferences by exposing support labels and masses while hiding rankings and metric attributes.
  • Interpreted measurable schedules as permitting different query sets on different portions of the same homogeneous type's divisible mass; computational schedules use finite rational partitions.
  • Specified aggregate responses as pairwise directional totals across queried mass, without type-specific totals or joint response patterns.
  • Used a shared pseudometric and fixed strict rankings with arbitrary distance-tie resolution, following the discrete model.
  • Required at least two candidates and a positive integer query budget no larger than the number of candidate pairs; normalized total mass to one.
  • Specified deterministic procedures, zero-denominator conventions, and a worst-case guarantee uniform over support sizes and rational mass vectors.
  • Did not transfer the discrete minimum-voter-count condition to support size: divisible mass has no indivisible voter count.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Exact optimum

For every \(m\ge 2\) and \(1\le t\le \binom m2\),

\(\displaystyle D(m,t)=3.\)

Thus the asymptotically optimal distortion is \(\Theta(1)\), independently of the query budget. A deterministic procedure attaining the exact optimum runs in time polynomial in \(m,\tau,L,t\).

The crucial feature is that arbitrarily small portions of a type share its fixed ranking. Moreover, exact aggregate totals can encode individual types’ responses through distinct rational query masses.

1. Recovering every ranking with one query per person

Write \(K=\binom m2\), fix an ordering of the type labels, and define

\(\displaystyle \lambda=\min_{i\in[\tau]}w_i,\qquad h=\lceil\log_2 K\rceil,\qquad q_i=\lambda\,2^{-(h+i)}.\)

For each type \(i\), partition its block into:

  • One subblock of mass \(q_i\) for each candidate pair, assigned only that pair.
  • One remaining subblock, assigned the empty query set.

This is feasible because

\(\displaystyle Kq_i\le \lambda\,2^{-i}\le \lambda/2\le w_i/2.\)

All submasses are rational, and every person receives at most one query. The schedule depends only on labels and masses and is therefore admissible for every allowed \(t\).

For a pair \(\{a,b\}\), fix one endpoint \(a\) and let \(R_{ab}\) be the oracle’s returned mass preferring \(a\). Since every queried portion of type \(i\) has the same ranking,

\(\displaystyle R_{ab}=\sum_{i=1}^{\tau}q_i x_i^{ab},\qquad x_i^{ab}=\begin{cases}1,&a\succ_i b,\\0,&b\succ_i a.\end{cases}\)

Consequently,

\(\displaystyle Z_{ab}:=\frac{2^{h+\tau}}{\lambda}R_{ab} =\sum_{i=1}^{\tau}2^{\tau-i}x_i^{ab}.\)

The integer \(Z_{ab}\) has precisely the response vector as its binary digits, padded to length \(\tau\). Thus every type’s response to every pair can be recovered uniquely.

These comparisons determine each strict complete ranking. For example, the position of a candidate is one plus the number of candidates preferred to it.

This construction uses only the permitted scalar totals. Type-specific answers are inferred by deterministic arithmetic rather than returned separately by the oracle.

2. A weighted aggregation rule with distortion at most three

We use a weighted version of [Plurality Veto](https://www.ijcai.org/proceedings/2022/0050). The following argument proves its guarantee directly for the present model.

Let \(f_i\) be type \(i\)’s first-ranked candidate. Give each candidate initial score

\(\displaystyle p(c)=\sum_{i:f_i=c}w_i.\)

The scores sum to one.

Process types in their fixed label order. Type \(i\) has a veto budget initially equal to \(w_i\). While that budget is positive:

  • Let \(c\) be its least-preferred candidate among those with positive score.
  • Remove an amount equal to the smaller of its remaining budget and \(c\)’s remaining score.
  • Deduct that amount from both quantities.

Return the candidate \(a\) whose score is exhausted by the final removal.

Termination and conservation

Before each removal, the total remaining candidate score equals the total unspent veto budget. This holds initially and is preserved because each removal subtracts the same amount from both totals.

Hence, whenever a type has positive remaining budget, some candidate has positive score. Each removal either exhausts a candidate’s score or exhausts the current type’s budget. There are therefore at most \(m+\tau\) removals.

At termination all scores are zero. Immediately before the final removal, exactly one candidate has positive score: otherwise the final removal would leave another positive score, contradicting conservation. Thus the output is well-defined.

Let \(r_{ic}\) be the total score removed from candidate \(c\) by type \(i\). Conservation gives

\(\displaystyle \sum_c r_{ic}=w_i,\qquad \sum_i r_{ic}=p(c).\)

The winner dominates every vetoed candidate

Scores never increase. Since \(a\) is exhausted last, it has positive score at every earlier removal.

Whenever type \(i\) removes score from \(c\), it chooses its least-preferred positive-score candidate. Therefore

\(\displaystyle r_{ic}>0\quad\Longrightarrow\quad c=a\ \text{or}\ a\succ_i c.\)

By ranking consistency,

\(\displaystyle r_{ic}>0\quad\Longrightarrow\quad d(i,a)\le d(i,c).\)

Metric bound

Fix any comparison candidate \(b\in C\). Using the preceding inequality, the triangle inequality, and the conservation identities,

\(\displaystyle \operatorname{cost}_{\mu}(a) =\sum_{i,c}r_{ic}d(i,a) \le\sum_{i,c}r_{ic}d(i,c) \le\sum_{i,c}r_{ic}\bigl(d(i,b)+d(b,c)\bigr) =\operatorname{cost}_{\mu}(b)+\sum_c p(c)d(b,c). \)

The remaining term satisfies

\(\displaystyle \sum_c p(c)d(b,c) =\sum_i w_i d(b,f_i) \le\sum_i w_i\bigl(d(b,i)+d(i,f_i)\bigr) \le 2\operatorname{cost}_{\mu}(b). \)

The first inequality is the triangle inequality. The second follows because \(f_i\) is first-ranked, so \(d(i,f_i)\le d(i,b)\).

Combining these inequalities yields

\(\displaystyle \operatorname{cost}_{\mu}(a)\le 3\operatorname{cost}_{\mu}(b)\qquad\text{for every }b\in C.\)

Choosing a minimum-cost candidate proves distortion at most three when the optimum is positive. If the optimum is zero, the same inequality forces the selected candidate’s cost to be zero, and the stipulated distortion is one.

Therefore \(D(m,t)\le 3\).

3. Polynomial encoding size and running time

The schedule has \(\tau(K+1)\) pieces. Each \(q_i\) is obtained from the input rational \(\lambda\) by dividing by a power of two with exponent at most \(h+\tau\). Its binary encoding length is therefore \(O(L+\tau+\log m)\).

The remaining submasses \(w_i-Kq_i\) also have polynomial encoding length. Each aggregate answer is \(\lambda\,2^{-(h+\tau)}\) times an integer with at most \(\tau\) binary digits, so its exact encoding length is polynomial as well.

Decoding all pairs takes polynomial time. Recovering the rankings requires \(O(\tau m^2)\) comparisons or counts.

Weighted veto uses at most \(m+\tau\) removals; scanning a ranking to locate the least-preferred active candidate costs at most \(O(m)\) per removal. Its arithmetic also has polynomial bit complexity: all scores and budgets can be expressed over the product of the input denominators, whose binary length is at most \(O(L)\), and the algorithm performs only sums, comparisons, and differences.

Thus both schedule construction and aggregation run in polynomial time.

4. A matching lower bound

Fix any admissible deterministic procedure. Use two types of mass \(1/2\), with candidates \(a,b\) and, when \(m>2\), additional candidates \(z_1,\ldots,z_{m-2}\).

Fix the complete rankings

\(\displaystyle a\succ_1 b\succ_1 z_1\succ_1\cdots\succ_1 z_{m-2},\)

\(\displaystyle b\succ_2 a\succ_2 z_1\succ_2\cdots\succ_2 z_{m-2}.\)

Consider two line pseudometrics, defined by the following coordinates:

| Object | Society A | Society B |
|---|---:|---:|
| \(a\) | \(0\) | \(0\) |
| \(b\) | \(2\) | \(2\) |
| Type \(1\) | \(0\) | \(1\) |
| Type \(2\) | \(1\) | \(2\) |
| Every \(z_j\) | \(10\) | \(10\) |

Distances are absolute coordinate differences, so both societies satisfy all pseudometric axioms.

The fixed rankings are consistent in both societies. In Society A, type \(2\) is equidistant from \(a,b\); in Society B, type \(1\) is equidistant from them. The stated rankings resolve these ties as allowed. All additional candidates are farther away and mutually tied.

The costs are:

| Candidate | Society A | Society B |
|---|---:|---:|
| \(a\) | \(1/2\) | \(3/2\) |
| \(b\) | \(3/2\) | \(1/2\) |
| Every \(z_j\) | \(19/2\) | \(17/2\) |

Both societies have identical labels, masses, and complete rankings. Therefore the procedure chooses the same schedule, receives identical aggregate responses, and selects the same candidate in both.

  • If it selects \(a\), its distortion in Society B is \(3\).
  • If it selects \(b\), its distortion in Society A is \(3\).
  • If it selects an additional candidate, its distortion is at least \(17\).

Every deterministic procedure consequently has worst-case distortion at least three. Thus \(D(m,t)\ge 3\), completing the proof.

5. Why the finite-electorate bound differs

The finite-electorate result concerns a query budget on individual voters who cannot be subdivided; see [Ebadian, Halpern, and Micha](https://daniel-halpern.com/files/metric-distortion-with-queries.pdf). Here, arbitrarily small subblocks retain their type’s fixed ranking, allowing every pair to be queried within every type while asking each person only once. Exact aggregate arithmetic additionally permits the encoding in Section 1.

Under the stated assumptions, these features yield the exact polynomial-time optimum \(D(m,t)=3\).
