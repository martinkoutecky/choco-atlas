The continuous mirror question, as graded

Given supported valuation types \(T\) with rational masses \(\mu_t\), value-query access to normalized nondecreasing valuations \(v_t:\{0,\ldots,M\}\to\mathbb{Q}_{\ge 0}\), and per-capita supply \(q\), choose masses \(x_{t,s}\ge 0\) satisfying \(\sum_{s=0}^{M}x_{t,s}=\mu_t\) for each \(t\) and \(\sum_{t\in T}\sum_{s=0}^{M}s x_{t,s}\le q\), maximizing \(\sum_{t\in T}\sum_{s=0}^{M}x_{t,s}v_t(s)\). Does there exist an algorithm that returns a feasible solution with welfare at least \(\mathrm{OPT}/(1+\epsilon)\) in time polynomial in \(\tau=|T|\), \(\log M\), the input bit length \(L\), and \(1/\epsilon\)? Each unit of mass receives an integral bundle; the type-level allocation may be fractional.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) valuation types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Let \(M\geq1\) be a binary-encoded integer and let the per-capita supply be a binary rational \(q\in[0,M]\). Each type has a nondecreasing valuation \(v_t:\{0,\ldots,M\}\to\mathbb{Q}_{\geq0}\) with \(v_t(0)=0\), accessed through exact value queries. Let \(L\) comprise the explicit input bit length and a supplied bound on the bit length of every oracle answer; charge for reading and processing answers.
An allocation consists of rational masses \(x_{t,s}\geq0\) satisfying \(\sum_{s=0}^{M}x_{t,s}=\mu_t\) for every \(t\) and \(\sum_{t,s}s x_{t,s}\leq q\). Each unit of mass receives an integral bundle; a type's mass may be split among bundle sizes. Represent an allocation by its nonzero entries, with omitted entries zero.
Its welfare is \(W(x)=\sum_{t,s}x_{t,s}v_t(s)\); let \(\mathrm{OPT}\) be the maximum feasible welfare.

Does this problem admit an FPTAS that, for every rational \(0<\epsilon<1/2\), returns a feasible allocation with \(W(x)\geq\mathrm{OPT}/(1+\epsilon)\) using time and value queries polynomial in \(\tau\), \(\log(M+1)\), \(L\), and \(1/\epsilon\), or is such a guarantee impossible in this oracle model?

For finitely many bidders, a truthful-in-expectation FPTAS achieves the same welfare ratio in expectation, using value queries and time polynomial in the bidder count, the logarithm of supply, and \(1/\epsilon\). [Dobzinski–Dughmi](https://arxiv.org/pdf/0904.4193)
No result settling the stated mass-allocation problem with this oracle access and running-time bound was located.

  • Made normalization explicit as v_t(0)=0, retaining weak monotonicity and permitting zero valuations.

  • Specified sparse rational allocation output so that an exponentially large bundle domain does not itself force exponentially long output.

Result

The problem admits a deterministic FPTAS in the stated oracle model. It uses \(O\!\left(\tau\epsilon^{-1}\log(M+1)\right)\) value queries.

The key is that rounding bundle sizes upward can be compensated by reducing the mass receiving positive bundles. Monotonicity protects welfare, and splitting type mass makes this compensation feasible.

1. A small grid of bundle sizes

Set \(k=\lceil 1/\epsilon\rceil\) and \(a=1+1/k\). Thus \(a\leq 1+\epsilon\).

Construct integers \(b_0,\ldots,b_K\) by starting with \(b_0=0\) and, until reaching \(M\), setting

\[ b_{i+1}=\min\!\left\{M,\left\lfloor a(b_i+1)\right\rfloor\right\}. \]

Here and below, the displayed expressions specify exact rational or integer computations. Since \(\lfloor a(b_i+1)\rfloor\geq b_i+1\), the sequence strictly increases and terminates at \(b_K=M\). Let \(G=\{b_0,\ldots,b_K\}\).

For each integer \(s\in\{1,\ldots,M\}\), define \(\rho(s)\) as the smallest grid point at least \(s\). If \(\rho(s)=b_{i+1}\), then \(b_i<s\), hence \(b_i+1\leq s\). Consequently,

\[ s\leq \rho(s)=b_{i+1}\leq a(b_i+1)\leq as. \]

Thus every positive bundle can be rounded upward with multiplicative increase at most \(a\).

The grid is small. Before the final, possibly clipped step,

\[ b_{i+1}+1=\left\lfloor a(b_i+1)\right\rfloor+1>a(b_i+1). \]

For \(K\geq2\), iterating this inequality gives \(a^{K-1}<b_{K-1}+1\leq M\). Including the case \(K=1\), we obtain

\[ K\leq 1+\frac{\log(M+1)}{\log a}. \]

Moreover, \(\log(1+1/k)\geq 1/(k+1)\), by integrating \(1/(1+u)\geq k/(k+1)\) over \(0\leq u\leq1/k\). Therefore,

\[ K\leq 1+(k+1)\log(M+1) =O\!\left(\epsilon^{-1}\log(M+1)\right). \]

2. The algorithm

For every listed type \(t\), query \(v_t(b)\) at each positive \(b\in G\). The value \(v_t(0)=0\) is already known.

Solve the following explicit rational linear program exactly:

\[ \begin{aligned} \text{maximize}\quad& \sum_{t\in T}\sum_{b\in G} y_{t,b}v_t(b),\\ \text{subject to}\quad& \sum_{b\in G}y_{t,b}=\mu_t &&(t\in T),\\ &\sum_{t\in T}\sum_{b\in G}b\,y_{t,b}\leq q,\\ &y_{t,b}\geq0 &&(t\in T,\ b\in G). \end{aligned} \]

Return its optimal solution \(y\), listing only nonzero entries.

This program is feasible: assign every type its entire mass at bundle size zero. It is bounded because \(0\leq y_{t,b}\leq\mu_t\). Every feasible solution is an allocation permitted by the original problem.

3. Approximation proof

We prove that every feasible allocation \(x\) has a feasible counterpart supported on \(G\), with welfare at least \(W(x)/a\).

Let \(\beta=1/a=k/(k+1)\). For positive \(b\in G\), define

\[ \widehat{x}_{t,b} =\beta\sum_{\substack{1\leq s\leq M\\ \rho(s)=b}}x_{t,s}, \]

and define

\[ \widehat{x}_{t,0} =\mu_t-\beta\sum_{s=1}^{M}x_{t,s}. \]

All these masses are rational and nonnegative. Indeed, the positive-bundle mass of type \(t\) is at most \(\mu_t\), and \(\beta\leq1\). By construction, each type retains total mass exactly \(\mu_t\).

The supply used is

\[ \begin{aligned} \sum_{t\in T}\sum_{b\in G}b\,\widehat{x}_{t,b} &=\beta\sum_{t\in T}\sum_{s=1}^{M}\rho(s)x_{t,s}\\ &\leq\beta a\sum_{t\in T}\sum_{s=1}^{M}s x_{t,s}\\ &\leq q. \end{aligned} \]

The first inequality uses \(\rho(s)\leq as\), and \(\beta a=1\). Thus \(\widehat{x}\) is feasible.

Because \(\rho(s)\geq s\) and every valuation is nondecreasing,

\[ \begin{aligned} W(\widehat{x}) &=\beta\sum_{t\in T}\sum_{s=1}^{M} x_{t,s}v_t(\rho(s))\\ &\geq\beta\sum_{t\in T}\sum_{s=1}^{M} x_{t,s}v_t(s)\\ &=\beta W(x). \end{aligned} \]

The last equality uses \(v_t(0)=0\).

An optimal rational allocation \(x^*\) exists. To see this, consider the full finite linear program over all bundle sizes. Its real feasible region is nonempty and compact. A linear objective attains its maximum at a vertex, and that vertex is rational because its coordinates solve a nonsingular linear system with rational coefficients.

Apply the construction to \(x^*\). Since the algorithm optimizes over every feasible allocation supported on \(G\),

\[ W(y)\geq W(\widehat{x^*}) \geq\frac{\mathrm{OPT}}{a} \geq\frac{\mathrm{OPT}}{1+\epsilon}. \]

This proves the required guarantee, including when \(q=0\) or \(\mathrm{OPT}=0\).

4. Bit complexity and oracle access

The grid has \(O\!\left(\epsilon^{-1}\log(M+1)\right)\) points. Its construction uses integer arithmetic on numbers of bit length polynomial in \(\log(M+1)\) and the explicit input length.

There are \(\tau K\) value queries. Each answer has bit length at most \(L\), so reading and storing all answers takes polynomial time in the required parameters.

The restricted linear program has \(\tau(K+1)\) variables. Its coefficients are grid integers, explicit input rationals, and queried valuation values. Its total binary encoding length is therefore polynomial in \(\tau\), \(\log(M+1)\), \(L\), and \(1/\epsilon\).

We use the standard polynomial-time theorem for rational linear programming: an explicitly encoded rational linear program with a nonempty bounded feasible region can be optimized exactly, returning a rational optimal solution in time polynomial in its encoding length. Both hypotheses were checked above. Consequently, the returned coordinates have polynomial total encoding length, and removing zero entries gives the required allocation representation.

The encoding of the supplied rational \(\epsilon\) is included in explicit input processing. No running-time dependence on the number of possible valuation types is introduced.

5. Relation to the cited result

[Dobzinski–Dughmi](https://arxiv.org/pdf/0904.4193) establishes a truthful-in-expectation FPTAS for finite multi-unit auctions using value queries. The proof here is independent: the permitted splitting of each type’s mass directly implements the reduction in positive-bundle mass, yielding a deterministic feasible allocation.
