The continuous mirror question, as graded

Given a finite type set \(T\), a total strength order, rational masses \(\mu_t\ge0\) summing to \(1\), popularity \(p:T\to\mathbb{Q}_{\ge0}\), and threshold \(B\), choose an initial champion \(h\in T\) and a finite ordered mass word \(\mathcal{S}=((\theta_1,a_1),\ldots,(\theta_\ell,a_\ell))\) with \(a_j\ge0\) and \(\sum_{j:\theta_j=t}a_j=\mu_t\). If \(q_0=h\) and \(q_j=W(q_{j-1},\theta_j)\) is the winner type after the first challenger in block \(j\), decide whether \(\sum_{j=1}^{\ell}a_jp(q_j)\ge B\), under the vanishing normalized contribution of the first promotion match.

Packaged proof task (what the prover saw — nothing else)

Definitions

An instance has a finite type set \(T\), binary-encoded rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), a deterministic match-winner map \(W:T\times T\to T\) with \(W(a,b)\in\{a,b\}\) and \(W(t,t)=t\), popularity \(p:T\to\{0,1,2\}\), initial champion \(h_0\), and binary-encoded rational threshold \(\theta\).
A finite schedule is \(S=((t_j,x_j))_{j=1}^q\), where \(x_j\ge0\), \(\sum_{j:t_j=t}x_j=\mu_t\), and \(h_j=W(h_{j-1},t_j)\). Its value is \(\sum_{j=1}^q x_jp(h_j)\). A block with \(x_j=0\) is an explicit vanishing-carrier event: it has zero value but still performs this champion update.

Target

Is the continuous Challenge-the-Champ value-maximization decision problem above NP-hard, or solvable in polynomial time?

Nearest known results

For finite individual players, Challenge-the-Champ value maximization with a general deterministic strength graph and player popularities in \(\{0,1,2\}\) is NP-complete.
That result concerns one occurrence of each player and does not cover the mass-distribution formulation above.

Classification

Theorem

Under the definition exactly as stated, the decision problem is \(\mathrm{NP}\)-complete under the standard explicit-table encoding of \(W\). In particular, it is \(\mathrm{NP}\)-hard even when:

  • every positive mass equals \(1/m\) for some integer \(m\);
  • all other types have mass \(0\);
  • popularity takes values only in \(\{0,2\}\); and
  • the threshold is \(\theta=2\).

The reduction uses asymmetry of \(W\), which the stated definition permits. If the additional axiom \(W(a,b)=W(b,a)\) is intended, the problem instead becomes polynomial-time solvable; this is proved below.

1. A normal form for schedules

Define the champion-transition digraph \(D=(T,A)\) by putting an arc \((a,b)\in A\) precisely when \(a\ne b\) and \(W(a,b)=b\). Thus an action of type \(b\), when the current champion is \(a\), changes the champion exactly when \((a,b)\in A\).

Lemma 1

Every schedule can be transformed, without changing its value or mass totals, so that every positive-mass block preserves the champion and every champion change is performed by a zero-mass block.

Proof

Consider a block \((t,x)\) used when the current champion is \(h\), where \(x>0\) and \(W(h,t)=t\ne h\). Replace it by the two blocks \((t,0)\) and \((t,x)\).

The first block changes the champion from \(h\) to \(t\) and contributes zero value. For the second block, \(W(t,t)=t\), so it preserves champion \(t\) and contributes \(xp(t)\). This is exactly the contribution of the original block. The total assigned mass of type \(t\) remains \(0+x=x\).

Applying this replacement to every positive state-changing block proves the claim. \(\square\)

Let \(H\subseteq T\) be the set of champions visited by the resulting zero-mass walk. For a positive-mass type \(t\), define

\[ \beta_H(t)=\max\{p(h):h\in H,\ W(h,t)=h\}, \]

provided the set on the right is nonempty.

It is nonempty for every \(t\) with \(\mu_t>0\): by Lemma 1, every positive block of type \(t\) is used at some visited champion \(h\) satisfying \(W(h,t)=h\).

All mass of type \(t\) may then be moved to a single visit of a champion attaining \(\beta_H(t)\). This does not change the champion and weakly increases value. Consequently, the best value attainable with visited set \(H\) is

\[ F(H)=\sum_{t:\mu_t>0}\mu_t\beta_H(t). \]

2. Polynomial certificates and membership in \(\mathrm{NP}\)

Let the strongly connected components of \(D\) be contracted to form its condensation digraph. This condensation is a directed acyclic graph.

The component sequence visited by any champion walk is a directed path in the condensation: once the walk leaves a strongly connected component, it cannot return to it.

Conversely, suppose \(\Pi=(C_0,\ldots,C_k)\) is a directed path in the condensation, where \(C_0\) contains \(h_0\). A finite zero-mass walk can visit every vertex of every \(C_i\):

  • inside a strongly connected component, directed paths can be concatenated to visit all its vertices;
  • the condensation edge from \(C_i\) to \(C_{i+1}\) supplies a transition to the next component.

Let \(H_\Pi=\bigcup_{i=0}^k C_i\). Visiting additional vertices within an already visited component cannot decrease \(F\). Lemma 1 therefore gives the exact characterization

\[ \operatorname{OPT}=\max_{\Pi}F(H_\Pi), \]

where the maximum ranges over condensation paths starting at the component of \(h_0\), and paths for which every positive-mass type has a protecting champion in \(H_\Pi\).

A certificate consists only of such a component path. It contains at most \(|T|\) components. The verifier computes the strongly connected components, checks the path, computes every \(\beta_{H_\Pi}(t)\), and compares the resulting rational value with \(\theta\). All these operations take polynomial time. Hence the problem belongs to \(\mathrm{NP}\).

3. Reduction from \(\textsc{3-Sat}\)

Let \(\varphi\) be a \(3\)-CNF formula with variables \(z_1,\ldots,z_n\) and clauses \(C_1,\ldots,C_m\), where \(m\ge1\).

For each variable \(z_i\), introduce:

  • a decision type \(d_i\);
  • literal types \(\ell_i^0\) and \(\ell_i^1\), representing respectively \(\neg z_i\) and \(z_i\).

For each clause \(C_r\), introduce a clause type \(c_r\).

Set \(h_0=d_1\). Give the types masses

\[ \mu_{c_r}=\frac1m \]

for every clause type, and mass \(0\) to every decision and literal type. These masses sum to \(1\).

Set

\[ p(\ell_i^b)=2 \]

for every literal type, and set \(p(d_i)=p(c_r)=0\). Finally, set \(\theta=2\).

Define the transition arc set \(A\) as follows:

  • include \((d_i,\ell_i^0)\) and \((d_i,\ell_i^1)\) for every \(i\);
  • include \((\ell_i^b,d_{i+1})\) for every \(i<n\) and \(b\in\{0,1\}\);
  • include \((\ell_i^b,c_r)\) exactly when the literal represented by \(\ell_i^b\) does not occur in clause \(C_r\).

There are no other arcs. Define \(W(a,b)=b\) when \((a,b)\in A\), and define \(W(a,b)=a\) otherwise. This satisfies \(W(a,b)\in\{a,b\}\) and \(W(t,t)=t\).

The construction has polynomial size, including the explicit table for \(W\).

Lemma 2: Completeness

If \(\varphi\) is satisfiable, there is a schedule of value \(2\).

Proof

Fix a satisfying assignment. Starting from \(d_i\), use the zero-mass block \((\ell_i^{b_i},0)\), where \(\ell_i^{b_i}\) is the literal made true by the assignment. This changes the champion to \(\ell_i^{b_i}\).

Assign each clause to one of its true literals. When champion \(\ell_i^{b_i}\) is visited, schedule the entire mass \(1/m\) of every clause assigned to that literal. Because the literal occurs in that clause, \((\ell_i^{b_i},c_r)\notin A\), and hence

\[ W(\ell_i^{b_i},c_r)=\ell_i^{b_i}. \]

The clause block therefore contributes \(2/m\) and preserves the champion.

For \(i<n\), use the zero-mass block \((d_{i+1},0)\) to proceed to the next variable. Every clause is assigned exactly once, so the total value is \(m(2/m)=2\). \(\square\)

Lemma 3: Soundness

If there is a schedule of value at least \(2\), then \(\varphi\) is satisfiable.

Proof

The total scheduled positive mass is

\[ \sum_jx_j=\sum_{t\in T}\mu_t=1. \]

Because popularity is at most \(2\), every schedule has value at most \(2\). Thus a schedule of value at least \(2\) has value exactly \(2\).

In this constructed instance, popularity is either \(0\) or \(2\). Consequently, every block of positive mass must end with a literal type as champion; otherwise some positive mass would receive popularity \(0\), forcing the total value below \(2\).

Fix a clause type \(c_r\). Since \(\mu_{c_r}=1/m>0\), at least one block of type \(c_r\) has positive mass. Let its preceding champion be \(h\). Its resulting champion has popularity \(2\), so it is some literal type \(\ell_i^b\). Since \(W(h,c_r)\in\{h,c_r\}\) and \(c_r\) has popularity \(0\), necessarily \(h=\ell_i^b\) and

\[ W(\ell_i^b,c_r)=\ell_i^b. \]

By construction, this holds exactly when the literal represented by \(\ell_i^b\) occurs in \(C_r\). Hence every clause has an encountered literal champion that satisfies it.

It remains to verify that the encountered literal champions are mutually consistent. Ignoring blocks that do not change the champion, every non-clause state-changing walk starting at \(d_1\) has the form

\[ d_1,\ell_1^{b_1},d_2,\ell_2^{b_2},\ldots \]

for some choices \(b_i\in\{0,1\}\). There is no transition to the other literal of an already processed variable. Moreover, every clause type is a sink, so entering a clause type cannot make additional literal champions reachable.

Thus at most one of \(\ell_i^0,\ell_i^1\) is encountered for each variable. Assign \(z_i=b_i\) for encountered variables and assign the remaining variables arbitrarily. Every clause contains an encountered literal made true by this assignment. Therefore \(\varphi\) is satisfiable. \(\square\)

Lemmas 2 and 3 give a polynomial many-one reduction from \(\textsc{3-Sat}\). Together with membership in \(\mathrm{NP}\), this proves \(\mathrm{NP}\)-completeness.

4. If match winners are required to be symmetric

Suppose one adds the axiom \(W(a,b)=W(b,a)\). Then \(D\) is a tournament: for every two distinct types, exactly one points to the other.

The condensation of a tournament is an acyclic tournament and therefore has a total order \(C_1,\ldots,C_s\), with every arc directed from an earlier component to a later component. If \(h_0\in C_r\), a zero-mass walk can visit every vertex in \(C_r,C_{r+1},\ldots,C_s\), in that order.

Let \(R\) be this reachable set. Every schedule visits only vertices in \(R\). Moreover:

  • each \(t\in R\) is protected by itself because \(W(t,t)=t\);
  • if \(t\notin R\), every vertex in \(C_r\) beats \(t\), so symmetry implies \(W(h,t)=h\) for \(h\in C_r\).

Therefore the exact optimum is

\[ \sum_{t:\mu_t>0}\mu_t \max\{p(h):h\in R,\ W(h,t)=h\}. \]

It is computable by strongly connected components, reachability, and pairwise scanning in polynomial time. Thus asymmetry is the precise feature used by the hardness proof; with symmetric match outcomes, the explicit vanishing-carrier convention collapses the problem to polynomial time.

Overall assessment

The prover correctly establishes that, under an explicit-table encoding of the potentially asymmetric map \(W\), the decision problem is NP-complete. The reduction respects all stated restrictions, including zero-mass carrier events, rational masses summing to \(1\), and popularities in \(\{0,1,2\}\).

Step-by-step audit

1. Normal-form lemma

The replacement of a positive state-changing block \((t,x)\) by \((t,0),(t,x)\) is valid:

  • The zero-mass block performs the same transition from \(h\) to \(t\).
  • The following positive block leaves champion \(t\) unchanged because \(W(t,t)=t\).
  • Its contribution remains \(xp(t)\).
  • The total mass assigned to type \(t\) remains \(x\).

The process terminates after finitely many replacements. Thus every positive block may indeed be assumed to preserve the champion.

The definition of \(\beta_H(t)\) is well posed for every positive-mass type in a normalized schedule. Moving all mass of a type to a visit attaining this maximum does not alter champion transitions, so the formula

\[ F(H)=\sum_{t:\mu_t>0}\mu_t\beta_H(t) \]

is justified.

2. Condensation-path characterization

A champion update follows an arc of \(D\). Consequently, after contracting strongly connected components, the visited components form a directed path and cannot repeat.

Conversely, for any condensation path beginning at the component containing \(h_0\), strong connectivity permits a finite walk visiting every vertex of each component before taking the relevant exit arc. The required walk may be constructed with polynomial length, although only existence is needed for the optimization characterization.

Because enlarging the visited set can only enlarge the sets over which the maxima defining \(\beta_H(t)\) are taken, visiting every vertex of each component cannot reduce the value. The displayed characterization of \(\operatorname{OPT}\) is therefore correct.

3. Membership in NP

A component path has at most \(|T|\) components. Under explicit-table encoding, the verifier can in polynomial time:

  • construct \(D\);
  • compute its strongly connected components;
  • verify the proposed condensation path;
  • check that every positive-mass type has a protecting champion;
  • compute the rational value \(F(H_\Pi)\);
  • compare it with the binary-encoded threshold.

The bit complexity of summing polynomially many binary-encoded rationals remains polynomial. Thus membership in NP is established.

4. Reduction construction

The construction is polynomial in the size of the 3-CNF formula. The masses are nonnegative and sum to \(1\), the threshold is \(2\), and the defined map satisfies both \(W(a,b)\in\{a,b\}\) and \(W(t,t)=t\).

The explicit \(W\)-table has polynomial size because the number of constructed types is polynomial.

5. Completeness

A satisfying assignment selects exactly one literal champion per variable. Every clause can be assigned to an encountered true literal.

For such a literal \(\ell_i^{b_i}\) and assigned clause \(c_r\), the corresponding transition arc is absent, so the clause block preserves the literal champion and contributes \(2/m\). Summing over all \(m\) clauses gives exactly \(2\). The transitions between consecutive variables are all present by construction.

Completeness is correct.

6. Soundness

Since the total positive mass is \(1\) and popularity never exceeds \(2\), the value is at most \(2\). Equality forces every positive-mass block to end with popularity \(2\), hence with a literal champion.

For every clause type \(c_r\), some positive block exists. If its preceding champion is \(h\), then the resulting champion must be a literal. Because \(W(h,c_r)\in\{h,c_r\}\) and \(c_r\) has popularity \(0\), this literal must be \(h\), and \(W(h,c_r)=h\). By construction, the corresponding literal occurs in \(C_r\).

The transition graph permits at most one literal champion for each variable along any walk from \(d_1\). Entering a clause champion cannot enable later literal champions because clause types are sinks. Thus all clause-witnessing literal champions are mutually consistent and determine a satisfying assignment.

Soundness is correct.

7. Symmetric case

Under symmetry, each distinct pair has exactly one orientation in \(D\), so \(D\) is a tournament. Its strongly connected component condensation is a transitive tournament and therefore admits the asserted total order.

Starting in component \(C_r\), all and only the components from \(C_r\) onward are reachable. Every type in that suffix protects itself. For a type in an earlier component, every vertex of \(C_r\) wins against it, with the orientation interpreted according to the definition of \(D\). Hence every positive-mass type has a protecting reachable champion.

The resulting optimum formula is therefore exact and computable in polynomial time.

The prover fully resolves the target under the stated asymmetric definition and gives a correct additional classification for the symmetric variant. No major or minor defects were found.
