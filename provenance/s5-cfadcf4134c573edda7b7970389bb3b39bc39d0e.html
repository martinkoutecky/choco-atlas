The continuous mirror question, as graded

Given alternatives \(C\), a support \(T\) of \(\tau\) complete rankings, and binary-rational masses \(\mu_t>0\) summing to \(1\), compute the Schulze winner set. Define \(\gamma_\mu(x,y)=\sum_{t\in T}\mu_t\mathbf{1}[x\succ_t y]\), path strength \(s_\mu(x,y)=\max_{\pi:x\leadsto y}\min_{(u,v)\in\pi}\gamma_\mu(u,v)\) (zero if no path exists), and return all \(x\in C\) such that \(s_\mu(x,y)\ge s_\mu(y,x)\) for every \(y\in C\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty finite set of \(m\) alternatives. A society is given by its support: a list \(T\) of \(\tau\) distinct strict complete rankings of \(C\), each with a positive binary-rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For distinct \(x,y\in C\), define \(\gamma_\mu(x,y)=\sum_{t\in T}\mu_t\mathbf{1}[x\succ_t y]\). Form the directed graph on \(C\) containing exactly the arcs \((x,y)\) with \(x\ne y\) and \(\gamma_\mu(x,y)>0\), weighted by \(\gamma_\mu(x,y)\).
For distinct \(x,y\), let \(s_\mu(x,y)=\max_{\pi:x\leadsto y}\min_{(u,v)\in\pi}\gamma_\mu(u,v)\), where paths lie in this graph; set \(s_\mu(x,y)=0\) if no such path exists.
Compute the entire Schulze winner set \(W_\mu=\{x\in C:s_\mu(x,y)\ge s_\mu(y,x)\text{ for every }y\in C\setminus\{x\}\}\), retaining all tied winners.

Is computing \(W_\mu\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite electorates with strict complete rankings, successive elimination of weak pairwise relations returns exactly the Schulze winner set and admits a polynomial-time implementation. This result does not provide a bit-complexity analysis for the rational-support input specified here.

Modeling choices made when packaging the task

  • Required a nonempty alternative set and interpreted complete rankings as strict linear orders, following the discrete domain.
  • Specified that paths use only positive-support arcs between distinct alternatives, following the discrete graph definition.
  • Restricted winner comparisons to distinct alternatives, avoiding an undefined strength for an empty self-path.
  • Defined L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Computing the entire Schulze winner set is polynomial-time solvable in \(m,\tau,L\). An exact implementation using elementary integer arithmetic takes

\[ O\!\left(\tau L^2+\tau m^2L+m^3L\right) \]

bit operations. The algorithm retains every tied winner.

1. Convert the masses to integer weights

Write each input mass as \(\mu_t=p_t/q_t\), where the positive integers \(p_t,q_t\) are encoded in binary. Finite binary expansions can also be expressed this way with a power-of-two denominator whose binary encoding has length proportional to the expansion length.

Define \(D=\prod_{t\in T}q_t\) and \(a_t=p_t(D/q_t)\). These are integers satisfying \(a_t>0\) and \(\sum_{t\in T}a_t=D\).

The bit length of \(D\) is \(O(L)\): its logarithm is the sum of the logarithms of the input denominators, whose total encoding length is at most \(L\). Moreover, \(a_t\le D\), so every \(a_t\) also has \(O(L)\) bits. Computing \(D\) and all the \(a_t\), using schoolbook multiplication and exact division, costs \(O(\tau L^2)\) bit operations.

For distinct alternatives, define

\[ B(x,y)=\sum_{t\in T}a_t\mathbf{1}[x\succ_t y]. \]

Then \(0\le B(x,y)\le D\) and \(B(x,y)=D\gamma_\mu(x,y)\). In particular, the original graph contains \((x,y)\) exactly when \(B(x,y)>0\).

Store the position of each alternative in each ranking. Inspecting all ordered pairs in every ranking computes the entire matrix \(B\) with \(O(\tau m^2)\) additions of \(O(L)\)-bit integers, costing \(O(\tau m^2L)\) bit operations.

2. Compute strongest paths exactly

Enumerate the alternatives as \(c_1,\ldots,c_m\). Initialize a matrix by \(H^{(0)}(i,j)=B(c_i,c_j)\) for \(i\ne j\), and \(H^{(0)}(i,i)=D\).

For \(k=1,\ldots,m\), compute

\[ H^{(k)}(i,j)= \max\!\left\{ H^{(k-1)}(i,j), \min\!\left\{H^{(k-1)}(i,k),H^{(k-1)}(k,j)\right\} \right\}. \]

Use separate previous and current matrices, so every entry on the right comes from iteration \(k-1\).

Correctness invariant. For distinct endpoints, \(H^{(k)}(i,j)\) is the largest bottleneck of a directed path whose internal vertices belong to \(\{c_1,\ldots,c_k\}\), or zero if no such path exists. For equal endpoints, allow the empty path and assign it bottleneck \(D\).

We prove the invariant by induction.

At \(k=0\), a path between distinct endpoints with no internal vertices consists of one arc. Its weight is \(B(c_i,c_j)\), and a zero entry denotes an absent arc. The diagonal represents the empty path.

For the induction step, cycles can be deleted from any directed walk without decreasing its bottleneck: deletion retains a subset of its edges. Thus, for distinct endpoints, a maximizing path can be chosen without repeated vertices.

Such a path either avoids \(c_k\) internally, in which case its bottleneck is bounded by \(H^{(k-1)}(i,j)\), or contains \(c_k\) exactly once internally. In the latter case, splitting there gives two paths with internal vertices among \(\{c_1,\ldots,c_{k-1}\}\). Its bottleneck is therefore bounded by \(\min\{H^{(k-1)}(i,k),H^{(k-1)}(k,j)\}\).

Conversely, the first candidate is attainable whenever positive. When the second candidate is positive, concatenate paths attaining its two entries. The resulting walk has permitted internal vertices; deleting cycles produces a permitted path with at least that bottleneck. Empty paths handle cases where \(c_k\) is an endpoint. The diagonal remains \(D\), since every edge weight is at most \(D\). This proves the recurrence and the invariant.

After iteration \(m\), all internal vertices are permitted. Scaling every positive edge weight by \(D\) scales each path bottleneck, and hence its maximum, by \(D\). Therefore, for distinct endpoints,

\[ H^{(m)}(i,j)=D\,s_\mu(c_i,c_j). \]

3. Extract all winners and bound the running time

Return precisely the alternatives \(c_i\) satisfying

\[ H^{(m)}(i,j)\ge H^{(m)}(j,i) \quad\text{for every }j\ne i. \]

Because \(D>0\), these inequalities are equivalent to the defining inequalities for \(W_\mu\). Equality is accepted, so tied winners are retained. For \(m=1\), the condition is vacuous and the sole alternative is returned.

Every matrix entry stays between zero and \(D\): the recurrence only takes minima and maxima of existing entries. Consequently, entries always have \(O(L)\) bits. The \(m^3\) updates cost \(O(m^3L)\) bit operations, and winner extraction costs \(O(m^2L)\).

Combining the stages gives the claimed polynomial bound \(O(\tau L^2+\tau m^2L+m^3L)\). No explicit expansion into a finite electorate is needed.
