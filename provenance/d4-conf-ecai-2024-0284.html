The continuous mirror question, as graded

Given finitely many block types \(b\), each a graph \(H_b=(P_b,E_b)\) with strict rankings over \(K\) item classes at its positions, rational block masses \(\lambda_b\) with \(\sum_b |P_b|\lambda_b=1\), and rational per-capita item supplies \(s_k\) with \(\sum_k s_k=1\), decide whether there are nonnegative rational masses \(z_{b,a}\) such that \(\sum_{a\in\mathcal A_b} z_{b,a}=\lambda_b\) for each \(b\), and \(\sum_b\sum_{a\in\mathcal A_b} z_{b,a}|\{p\in P_b:a(p)=k\}|=s_k\) for each \(k\). Here \(\mathcal A_b\) contains the assignments giving each position one indivisible item and satisfying local envy-freeness on every edge of \(H_b\); item-class copies are interchangeable, and distinct blocks have no edges between them.

A society is given by its support: a list of \(\tau\) block types with positive masses, each encoded as a binary rational; \(\tau\) counts listed types, not possible types.
There are \(m\geq1\) interchangeable item classes. Each block type \(b\) has an explicitly given finite nonempty simple undirected graph \(H_b=(P_b,E_b)\), and each position \(p\) has a strict linear order \(\succ_{b,p}\) over the classes. Distinct blocks have no edges between them.
Block masses \(\lambda_b>0\) and nonnegative rational per-capita supplies \(s_k\) satisfy \(\sum_b|P_b|\lambda_b=1\) and \(\sum_{k=1}^{m}s_k=1\); all rationals are binary encoded.
Let \(\mathcal A_b\) consist of maps \(a:P_b\to\{1,\ldots,m\}\) satisfying \(a(p)\succ_{b,p}a(q)\) and \(a(q)\succ_{b,q}a(p)\) on every edge \(\{p,q\}\in E_b\). Each position receives one indivisible copy; classes may repeat within a block, but equal classes at adjacent positions violate this strict condition. The sets \(\mathcal A_b\) are defined implicitly, not listed in the input.
Feasibility means existence of \(z_{b,a}\in\mathbb Q_{\geq0}\) with \(\sum_{a\in\mathcal A_b}z_{b,a}=\lambda_b\) for every \(b\), and \(\sum_b\sum_{a\in\mathcal A_b}z_{b,a}|\{p\in P_b:a(p)=k\}|=s_k\) for every \(k\).
Write running times in \(m\), \(\tau\), \(B=\sum_b|P_b|\), and the total input bit length \(L\).

Is this block-mass feasibility problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finitely many agents and equally many distinct objects, locally envy-free allocation existence is equivalent to satisfiability of a polynomial-size CNF encoding ([SAT equivalence](https://ebooks.iospress.nl/pdf/doi/10.3233/FAIA240900)).
That discrete existence problem is \(\mathrm{NP}\)-complete even when the social graph is a matching ([discrete complexity](https://www.lamsade.dauphine.fr/~aharutyunyan/house.pdf)). No result settling this precise block-mass problem was located in the search.

Result

The block-mass feasibility problem is \(\mathrm{NP}\)-complete. Hardness holds even with \(\tau=1\), a connected block graph, and strictly positive supplies for every class.

The reduction explicitly handles fractional mixtures: in a no-instance, every admissible allocation consumes too few copies of one distinguished class, so averaging cannot meet its prescribed supply.

1. Reduction from Independent Set

We use the \(\mathrm{NP}\)-complete problem Independent Set: given a finite simple graph \(G=(V,E)\), with \(n=|V|\), and an integer \(1\leq K\leq n\), decide whether \(G\) has an independent set of size at least \(K\). Its hardness follows equivalently from Vertex Cover, since \(S\subseteq V\) is independent exactly when \(V\setminus S\) is a vertex cover. Vertex Cover is one of [Karp’s classical completeness results](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Classes, positions, and graph

Introduce the following \(m=n+3\) classes:

  • A private class \(t_v\) for every \(v\in V\).
  • A distinguished class \(f\).
  • Two guard classes \(g,h\).

There is exactly one block type. Its positions are:

  • A core position \(p_v\) for every \(v\in V\).
  • Filler positions \(r_1,\ldots,r_K\).
  • Guard positions \(u,w\).

Thus \(\tau=1\) and \(B=n+K+2\).

The block graph has precisely these edges:

  • \(\{p_v,p_{v'}\}\) whenever \(\{v,v'\}\in E\).
  • \(\{u,p_v\}\) for every \(v\in V\).
  • \(\{u,r_i\}\) for every \(1\leq i\leq K\).
  • \(\{u,w\}\).

In particular, \(u\) is adjacent to every other position, so the block graph is connected.

Preferences

Fix a strict order \(R\) of all classes other than \(g,h\). The guard preferences are

\(g\succ_u h\succ_u R,\qquad h\succ_w g\succ_w R.\)

The same order \(R\) appears at both guards.

For every core position, set

\(t_v\succ_{p_v} f\succ_{p_v} g\succ_{p_v}\text{all remaining classes}.\)

The remaining classes are ordered arbitrarily but strictly.

For every filler position, put every private class above \(g\), and both \(f,h\) below \(g\):

\(t_{v_1}\succ_{r_i}\cdots\succ_{r_i}t_{v_n}\succ_{r_i}g\succ_{r_i}f\succ_{r_i}h,\)

where \(v_1,\ldots,v_n\) is a fixed enumeration of \(V\). Every preference is therefore an explicitly specified strict linear order over all \(m\) classes.

Mass and supplies

Give the sole block mass

\(\lambda=1/B.\)

Set supplies

\(s_{t_v}=1/B\quad(v\in V),\qquad s_f=K/B,\qquad s_g=s_h=1/B.\)

These satisfy both required normalizations:

\(|P|\lambda=B/B=1,\qquad \sum_k s_k=(n+K+2)/B=1.\)

All supplies are positive, and every rational has binary encoding length \(O(\log(B+1))\).

2. Structure of every admissible allocation

Let \(a\) be any admissible allocation of the constructed block.

The guards are forced

We claim that \(a(u)=g\) and \(a(w)=h\).

First suppose exactly one guard receives a class outside \(\{g,h\}\). That guard ranks its neighbor’s class above its own, violating admissibility on \(\{u,w\}\).

If both guards receive classes outside \(\{g,h\}\), equal classes violate strictness. For distinct classes, the guards’ identical order \(R\) means the guard receiving the less-preferred class envies the other.

Consequently both guards receive classes in \(\{g,h\}\). They must receive different classes. The assignment \(a(u)=h,\ a(w)=g\) violates \(u\)’s strict comparison. Thus the only possibility is

\(a(u)=g,\qquad a(w)=h.\)

Core and filler domains are forced

Each core position is adjacent to \(u\), which receives \(g\). It must therefore receive a class strictly above \(g\) in its own ranking. Exactly two classes qualify:

\(a(p_v)\in\{t_v,f\}.\)

Likewise, each filler position must receive a private class:

\(a(r_i)\in\{t_v:v\in V\}.\)

The comparison in the opposite direction is automatically satisfied: \(u\) ranks \(g\) above every other class.

The distinguished class encodes an independent set

Define

\(S(a)=\{v\in V:a(p_v)=f\}.\)

If \(\{v,v'\}\in E\), both corresponding core positions cannot receive \(f\), because equal classes violate the strict edge condition. Hence \(S(a)\) is independent.

Conversely, for adjacent core positions, every other combination of their allowed classes satisfies both comparisons:

  • If they receive \(t_v,t_{v'}\), each position ranks its own private class above the other private class.
  • If they receive \(f,t_{v'}\), position \(p_v\) ranks \(f\) above \(t_{v'}\), while \(p_{v'}\) ranks \(t_{v'}\) above \(f\).
  • The remaining case is symmetric.

Therefore every independent set \(S\subseteq V\) determines admissible core assignments by giving \(f\) to its vertices and \(t_v\) to the others. Any private-class assignments to the fillers then complete an admissible allocation.

Since neither guards nor fillers can receive \(f\), the number of copies of \(f\) in any admissible allocation is exactly

\(c_f(a)=|S(a)|\leq\alpha(G),\)

where \(\alpha(G)\) is the maximum independent-set size.

3. Correctness, including fractional mixtures

An independent set gives feasibility

Suppose \(\alpha(G)\geq K\). Taking a subset if necessary, choose an independent set \(S\) of size exactly \(K\).

Assign:

  • \(a(p_v)=f\) for \(v\in S\).
  • \(a(p_v)=t_v\) for \(v\notin S\).
  • The \(K\) fillers bijectively to the \(K\) classes \(\{t_v:v\in S\}\).
  • \(a(u)=g\) and \(a(w)=h\).

Section 2 proves admissibility. This allocation uses each private class exactly once, class \(f\) exactly \(K\) times, and each guard class exactly once.

Setting \(z_a=\lambda=1/B\), with all other allocation weights zero, meets every prescribed supply.

Feasibility gives an independent set

Conversely, suppose nonnegative rational weights \(z_a\) satisfy the block-mass and supply equations. In particular,

\(\sum_a z_a=1/B,\qquad \sum_a z_a c_f(a)=K/B.\)

The bound proved in Section 2 gives

\(K/B=\sum_a z_a c_f(a)\leq\alpha(G)\sum_a z_a=\alpha(G)/B.\)

Thus \(K\leq\alpha(G)\).

This proves the exact equivalence

\(\text{constructed society is feasible}\quad\Longleftrightarrow\quad\alpha(G)\geq K.\)

The inequality applies to every fractional mixture, so the reduction does not assume integrality of the allocation weights.

Reduction size and running time

Here \(m=n+3\), \(\tau=1\), and \(B=n+K+2\leq2n+2\). The construction writes \(B\) preference lists of length \(m\), at most \(O(B^2)\) edges, and \(m+1\) rationals.

Using an explicit encoding, its bit length and construction time are \(O(n^2\log(n+1))\). Equivalently, the construction is polynomial in \(m,\tau,B,L\). Hence this is a polynomial-time many-one reduction proving \(\mathrm{NP}\)-hardness.

4. Membership in \(\mathrm{NP}\)

The implicit allocation sets require a certificate argument: listing all admissible allocations could take exponential space.

Put \(q=\tau+m\). For every admissible pair \((b,a)\), form an integer column \(v_{b,a}\in\mathbb Z^q\). Its first \(\tau\) coordinates identify the block type:

\((v_{b,a})_j=1\) if \(j=b\), and \(0\) otherwise.

Its remaining coordinates are the class counts:

\((v_{b,a})_{\tau+k}=|\{p\in P_b:a(p)=k\}|.\)

Every entry lies between \(0\) and \(B\). Feasibility is precisely

\(\sum_{b,a}z_{b,a}v_{b,a}=d,\qquad z_{b,a}\geq0,\)

where \(d=(\lambda_1,\ldots,\lambda_\tau,s_1,\ldots,s_m)\).

At most \(q\) allocations suffice

Assume feasibility, and choose a rational feasible solution with the smallest number \(r\) of positive weights. Such a choice exists because the collection of columns is finite.

Its supported columns must be linearly independent. Otherwise, their integer entries give a nonzero rational dependence

\(\sum_{i=1}^r c_i v_i=0.\)

Summing the first \(\tau\) coordinates yields \(\sum_i c_i=0\), because every column has exactly one \(1\) among those coordinates. Thus the coefficients \(c_i\) include both positive and negative values.

Set

\(t=\min_{i:c_i>0}z_i/c_i>0,\qquad z'_i=z_i-tc_i.\)

Every new weight is nonnegative, at least one becomes zero, and the represented vector remains \(d\). This contradicts minimality. Therefore \(r\leq q\).

The weights have polynomial encoding length

Choose \(r\) rows on which the supported columns form a nonsingular integer matrix \(C\).

Let \(D\) be the product of the denominators of the coordinates of \(d\). Since those rationals occur in the input, \(\log D=O(L)\). Also every coordinate of \(d\) lies in \([0,1]\), by the normalization assumptions.

The supported weights solve \(Cz=d_I\). By Cramer’s rule,

\(z_i=\det(C_i')/(D\det C),\)

where \(C_i'\) replaces column \(i\) of \(C\) by the integer vector \(Dd_I\).

The determinant expansion gives

\(|\det C|\leq r!B^r,\qquad |\det C_i'|\leq r!DB^{r-1}.\)

Consequently every weight has numerator and denominator encoding length

\(O\!\left(L+q\log(q(B+1))\right).\)

A certificate therefore lists at most \(q\) block indices, their explicit allocations, and their rational weights. Its total length is bounded by

\(O\!\left(q\left[\log(\tau+1)+B\log(m+1)+L+q\log(q(B+1))\right]\right).\)

A verifier checks all edge comparisons and all mass and supply equalities using exact rational arithmetic. There are at most \(q\) allocations to check, each on at most \(B\) positions and \(O(B^2)\) edges. The certificate bounds ensure a verification running time of \(\operatorname{poly}(m,\tau,B,L)\).

Thus the problem belongs to \(\mathrm{NP}\).

Conclusion

The reduction proves \(\mathrm{NP}\)-hardness for the precise block-mass model, and the sparse rational certificate proves membership in \(\mathrm{NP}\). Therefore the problem is \(\mathrm{NP}\)-complete, already with one connected block type and positive supplies throughout. A polynomial-time algorithm would imply \(\mathrm P=\mathrm{NP}\).
