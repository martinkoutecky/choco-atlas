The continuous mirror question, as graded

Given a finite candidate set \(C\), candidate preference orders, a tie-breaking priority, a default winner, and a distribution \(\mu\) over the supported complete voter rankings with binary rational masses summing to \(1\), decide whether there is an active set \(A \subseteq C\) that is a pure-strategy Nash equilibrium under the paper’s lazy-candidacy preferences and whose plurality winner is a designated candidate \(c^\star\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set with \(m=|C|\). Each candidate \(c\) has a strict complete preference order \(\succ_c\) over \(C\), without any self-support requirement. A strict priority order breaks ties; its highest-priority candidate is the default winner.
A society is given by its support: the list of \(\tau\) distinct complete strict voter rankings with positive binary rational masses summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).
Each candidate chooses to run or abstain, producing an active set \(A\subseteq C\). For nonempty \(A\), voters vote sincerely and plurality scores are the masses ranking each active candidate first after restriction to \(A\); let \(w(A)\) be the winner under the priority order. For \(A=\varnothing\), use the default winner.
Candidate \(c\) prefers active set \(B\) to \(A\) exactly when \(w(B)\succ_c w(A)\), or when \(w(B)=w(A)\), \(c\notin B\), and \(c\in A\). Both unilateral entry and withdrawal are available. The input also specifies \(c^\star\in C\).

Is deciding whether there exists a pure-strategy Nash equilibrium \(A\subseteq C\) with \(w(A)=c^\star\) NP-hard or solvable in polynomial time in \(m,\tau,L\)?

For finite voter lists, the designated-winner equilibrium problem is NP-complete, even when every candidate ranks herself first. It is also FPT in the number of candidates and XP in the number of voters.

Modeling choices made when packaging the task

  • The separately supplied default winner is required to be the highest-priority candidate, matching the discrete model.
  • Candidate preferences are strict complete orders over all candidates; self-supporting preferences are not required.
  • The empty active set is allowed, and deviations include both unilateral entry and withdrawal.
  • L denotes the total binary input length, including rankings, masses, candidate preferences, priority, and designated winner.

Result

The problem is \(\mathrm{NP}\)-complete, even when every candidate ranks herself first. The reduction preserves the entire game, including the empty active set and every unilateral deviation.

1. Polynomial-time equilibrium verification

Write the support as \((R_j,\mu_j)_{j=1}^{\tau}\), where \(R_j\) is a complete strict ranking and \(\mu_j=p_j/q_j>0\).

A certificate is the membership vector of an active set \(A\subseteq C\), requiring \(m\) bits. First compute \(w(A)\) and check that it equals \(c^\star\). Then compute the winner after each candidate’s unique unilateral deviation.

The exact equilibrium conditions are:

  • For each \(c\in A\), require \(w(A)\succ_c w(A\setminus\{c\})\). Indeed, withdrawal is profitable if it produces a better winner or preserves the winner. Since candidate preferences are strict and complete, the displayed condition excludes exactly those possibilities.
  • For each \(c\notin A\), require that \(w(A\cup\{c\})\not\succ_c w(A)\). Entry preserving the winner is not profitable, because abstention is preferred.

These conditions also cover \(A=\varnothing\), using the prescribed default winner.

To compute winners exactly, let \(D=\prod_{j=1}^{\tau}q_j\) and \(b_j=p_j(D/q_j)\). Then \(b_j\) are positive integers, \(\sum_j b_j=D\), and plurality scores can be computed using these integer weights. Multiplication by the common positive denominator preserves all score comparisons and ties.

The binary length of \(D\) is \(\mathcal{O}(L)\), because the denominator encodings together occupy at most \(L\) bits. Every accumulated integer score lies between zero and \(D\), so it also has \(\mathcal{O}(L)\) bits. Thus binary masses cause no exponential arithmetic cost.

Using ordinary integer arithmetic, preprocessing takes at most \(\mathcal{O}(L^3)\) bit operations. Each winner computation scans at most \(m\) positions in each of the \(\tau\) rankings and compares at most \(m\) scores. A conservative bound for the complete verifier is therefore \(T(m,\tau,L)=\mathcal{O}(L^3+m^2(\tau+1)L^2)\).

There are only \(m+1\) winner computations. Consequently, the problem belongs to \(\mathrm{NP}\).

2. Polynomial reduction from explicit voter lists

Use the finite-voter hardness result stated in the question: designated-winner equilibrium existence is \(\mathrm{NP}\)-hard for explicit voter lists, even with self-supporting candidate preferences.

The applicable theorem concerns precisely the preference for abstaining when the winner is unchanged. Its model also uses the highest-priority candidate as the empty-set winner; thus both conventions match this task. See Theorem 3 and the model definitions in [*Strategic candidacy with reluctance*](https://link.springer.com/article/10.1007/s11238-025-10113-4).

Take an instance from this hard class with \(n\geq 1\) explicitly listed voters. Leave the candidate set, candidate preferences, priority order, and designated candidate unchanged.

Group identical voter rankings. Let the distinct rankings be \(R_1,\ldots,R_\tau\), and let \(k_j\) be the number of voters with ranking \(R_j\). Output the support consisting of these rankings with masses \(\mu_j=k_j/n\).

This is a valid target instance:

  • The rankings are distinct, and each mass is positive.
  • Their total mass is \(\sum_j k_j/n=1\).
  • There are \(\tau\leq n\) support entries.
  • Each numerator and denominator requires \(\mathcal{O}(\log(n+1))\) bits.

Grouping rankings and writing these fractions takes polynomial time in the explicit source input length. More specifically, the output length is \(\mathcal{O}((m^2+\tau m)\log(m+1)+\tau\log(n+1))\), which is polynomial in that source length.

Preservation of winners and deviations

Fix any nonempty \(A\subseteq C\) and any \(a\in A\). Let \(s_{\mathrm{list}}(a,A)\) denote the number of explicit voters whose highest-ranked member of \(A\) is \(a\). The corresponding support score is exactly \(\operatorname{sc}_{\mathrm{support}}(a,A)=s_{\mathrm{list}}(a,A)/n\).

Hence every plurality score is multiplied by the same positive factor. Score inequalities and equalities are preserved, and the unchanged priority order selects the same winner.

For \(A=\varnothing\), both instances use the same default winner. Therefore the winner functions agree for every \(A\subseteq C\).

Candidate preferences and participation status are also unchanged. It follows that, for every active set and every unilateral entry or withdrawal, the deviation is profitable in the source instance if and only if it is profitable in the target instance. Thus the equilibrium active sets coincide exactly, including their winners.

This proves a polynomial many-one reduction and establishes \(\mathrm{NP}\)-hardness. Together with Section 1, it proves \(\mathrm{NP}\)-completeness.

3. Parameterized bounds using support size

The support representation also permits an \(\mathrm{XP}\) algorithm parameterized by \(\tau\).

Lemma. Every nonempty equilibrium has at most \(\tau\) active candidates.

Proof. Suppose an active candidate \(c\) has zero score. Because every support mass is positive, no support ranking selects \(c\) as its highest-ranked active candidate. Removing \(c\) therefore leaves every voter’s selected candidate unchanged.

Furthermore, \(c\) cannot be the winner: the scores sum to one, so some active candidate has positive score. Thus removing \(c\) preserves the winner. Candidate \(c\) strictly benefits from abstaining, contradicting equilibrium.

Consequently, every active candidate receives positive score. Each support ranking contributes to exactly one active candidate, so at most \(\tau\) active candidates can receive positive score. This proves the lemma. \(\square\)

Enumerating all active sets therefore gives running time \(\mathcal{O}(2^m T(m,\tau,L))\), establishing fixed-parameter tractability in \(m\).

Using the lemma, it suffices to enumerate sets of size at most \(\tau\), including the empty set. The running time is \(\mathcal{O}((\sum_{k=0}^{\min(m,\tau)}\binom{m}{k})T(m,\tau,L))\), bounded by \(\mathcal{O}((m+1)^\tau T(m,\tau,L))\). This establishes \(\mathrm{XP}\) membership in the actual support size \(\tau\), without expanding rational masses into voters.
