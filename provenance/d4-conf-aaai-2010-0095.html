The continuous mirror question, as graded

Given \(2^r\) candidates, a target \(c^\star\), a fixed tie-breaking order, and a rational distribution \(\mu\) over strict rankings, orient each candidate pair toward its majority-preferred candidate, resolving ties by the order. If every candidate that defeats \(c^\star\) has outdegree at most \(c^\star\)’s outdegree, construct a balanced single-elimination bracket in which \(c^\star\) wins.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set of size \(m=2^r\), where \(r\) is a nonnegative integer, with designated candidate \(c^\star\) and a fixed strict total tie-breaking order.
A society is given by its support: the list of \(\tau\) distinct strict rankings with positive binary-rational masses summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
For distinct candidates \(a,b\), write \(a\to b\) when the mass ranking \(a\) above \(b\) exceeds \(1/2\), or equals \(1/2\) and the tie-breaking order favors \(a\). Define \(d^+(a)=|\{b\in C\setminus\{a\}:a\to b\}|\).
Promise that \(d^+(b)\le d^+(c^\star)\) whenever \(b\to c^\star\). A bracket assigns each candidate exactly once to the leaves of a perfect binary tree of depth \(r\); each match uses \(\to\), and every candidate pair may be matched. The required output is a bracket won by \(c^\star\).

Is this promised bracket-construction problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

Known discrete result: for any tournament graph satisfying this same outdegree promise, a winning balanced bracket can be constructed in polynomial time. [Verified source](https://theory.stanford.edu/~virgi/tournament3.pdf).

  • Specified the bracket as a perfect binary tree using every candidate exactly once, with every pair eligible to play.

Result

The promised bracket-construction problem is solvable in deterministic polynomial time in \(m,\tau,L\). The support representation allows us to compute the entire majority tournament exactly in polynomial time, after which the given discrete theorem applies.

1. The society defines a tournament

Write the input rankings as \(\pi_1,\ldots,\pi_\tau\), with masses \(w_1,\ldots,w_\tau\). For distinct candidates \(a,b\), define
\(s(a,b)=\sum_{i:\,\pi_i\text{ ranks }a\text{ above }b}w_i\).

Because each ranking is strict and the masses sum to \(1\), we have \(s(a,b)+s(b,a)=1\). Consequently:

  • If \(s(a,b)>1/2\), then \(a\to b\) and \(b\not\to a\).
  • If \(s(a,b)<1/2\), then \(b\to a\) and \(a\not\to b\).
  • If \(s(a,b)=1/2\), the fixed strict total tie-breaking order selects exactly one direction.

Thus \(G=(C,E)\), where \(E=\{(a,b):a\to b\}\), is a tournament graph. Its edge directions specify exactly the match outcomes in the original problem.

2. Exact construction has polynomial bit complexity

Use the standard binary encoding of rational numbers, writing \(w_i=p_i/q_i\), with positive integers \(p_i,q_i\) given in binary. Define
\(D=\prod_{i=1}^{\tau}q_i\) and \(W_i=p_i(D/q_i)\).

These are integers, and \(\sum_i W_i=D\). Moreover,
\(\log_2 D=\sum_i\log_2 q_i\le L\).
Hence \(D\), every \(W_i\), and every partial sum of the \(W_i\) have \(O(L)\) bits. Computing them requires only polynomially many bit operations, using ordinary integer multiplication and exact division.

For each ranking, record the position of every candidate. For each unordered candidate pair \(\{a,b\}\), compute
\(S(a,b)=\sum_{i:\,\pi_i\text{ ranks }a\text{ above }b}W_i\).
Determine the edge direction by comparing \(2S(a,b)\) with \(D\), applying the tie-breaking order when they are equal.

There are \(\binom m2\) pairs, and each requires at most \(\tau\) additions of \(O(L)\)-bit integers, together with position comparisons. Thus the complete tournament can be constructed in polynomial time in \(m,\tau,L\). This procedure iterates only over the supplied support; it never enumerates all \(m!\) possible rankings.

Once the edges are known, counting outgoing edges computes every \(d^+(a)\) in polynomial time.

3. Applying the discrete construction theorem

The discrete theorem supplied in the question states: for a tournament on a power-of-two number of vertices, if a designated vertex has outdegree at least that of every vertex beating it, a balanced winning bracket can be constructed in polynomial time. This is the bracket formulation of Theorem 3 in [Vassilevska Williams, *Fixing a Tournament*](https://theory.stanford.edu/~virgi/tournament3.pdf).

All hypotheses hold here:

  • The constructed graph is a tournament.
  • Its vertex count is \(m=2^r\).
  • The designated vertex is \(c^\star\).
  • The input promise is exactly \(d^+(b)\le d^+(c^\star)\) for every \(b\to c^\star\).

Apply that construction to obtain a perfect balanced bracket won by \(c^\star\). Since its graph edges are precisely the society’s match outcomes, the same bracket is valid for the original society.

For \(m=1\), return the single leaf labeled \(c^\star\).

4. Overall complexity and conclusion

The algorithm consists of exact polynomial-time tournament construction followed by the polynomial-time discrete bracket construction. The tournament has \(m\) vertices and \(\binom m2\) edges, so the second stage also has input size polynomial in \(m\). The output bracket has \(m\) leaves and \(m-1\) internal nodes.

Therefore the required bracket always exists on promised inputs and can be produced in deterministic polynomial time in \(m,\tau,L\).
