The continuous mirror question, as graded

Given rational candidate positions \(C\), committee size \(k\), and a uniform RIV with rational segment probabilities, let \(\mu_B\) be the induced mass of each approval type \(B\subseteq C\). Find a committee \(W\subseteq C\), \(|W|=k\), such that for every \(\ell\in[k]\) and submasses \(0\le g_B\le\mu_B\) with \(\sum_B g_B\ge\ell/k\), if all types with \(g_B>0\) share a candidate outside \(W\), then \(\left|W\cap\bigcup_{B:g_B>0}B\right|\ge\ell\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\subset\mathbb Q\) contain \(m\ge2\) distinct candidate positions, and let \(1\le k\le m\). A uniform Random Interval Voter model has \(\sigma\ge1\) segments \(I_t=(t,t+1)\), with \(C\subset\bigcup_{t=1}^{\sigma}I_t\), and binary-rational probabilities \(p_t\ge0\) summing to \(1\). Choose segment \(t\) with probability \(p_t\), draw two independent uniform points \(X,Y\in I_t\), and approve \(B=C\cap[\min(X,Y),\max(X,Y)]\).
The society is given by its support: the list \(\mathcal S\) of the \(\tau\) approval types with positive induced mass, each mass \(\mu_B\) a binary rational, with \(\sum_{B\in\mathcal S}\mu_B=1\). This list is promised to agree with the supplied model; include the empty type when its mass is positive. Here \(\tau\) is support size, not the number of possible types, and \(L\) is the total input bit length.
Find an integral committee \(W\subseteq C\), \(|W|=k\), satisfying mass PJR+: for every integer \(1\le\ell\le k\) and real submasses \(0\le g_B\le\mu_B\) with \(\sum_{B\in\mathcal S}g_B\ge\ell/k\), if \((\bigcap_{B:g_B>0}B)\setminus W\ne\varnothing\), then \(|W\cap\bigcup_{B:g_B>0}B|\ge\ell\).

Is finding such a committee possible in polynomial time in \(m,\tau,\sigma,k,L\), or is it NP-hard?

For finite sampled electorates, a polynomial-time algorithm finds PJR+ committees, using \(O(\log(\sigma k))\) queries per voter in expectation and with high probability when \(n=\Omega(k^2\log m)\). [Discrete result](https://arxiv.org/html/2510.11625v1)
A later distribution-input algorithm supplies committees of at most \(k\) candidates with a strict EJR+ probability margin for arbitrary approval distributions; it does not state a binary-rational support bit-complexity bound. [Distribution result](https://arxiv.org/html/2607.01036v1#S4.SS1)

Modeling choices made when packaging the task

  • Candidates occupy distinct rational positions strictly inside their segments, resolving the conflicting open-segment definition and closed uniform-segment notation without ambiguous shared endpoints.
  • Set the feasible domain to m at least two and committee size between one and m.
  • Normalize total society mass to one, retain positive empty-ballot mass, and allow zero segment probabilities.
  • Supply the exact induced support alongside the candidate positions and RIV description, with consistency promised, to implement the required support input convention.
  • Allow real submasses and retain integral committees and the weak coalition-mass threshold.
  • Treat the finite electorate-size condition as a condition on the discrete query bound; the mass-input problem has no electorate-size parameter.

Result: polynomial-time solvable

Theorem. Given the explicit support and binary-rational masses, an integral committee of size \(k\) satisfying mass PJR+ can be found deterministically in time polynomial in \(m,\tau,\sigma,k,L\). In fact, the construction works for any explicitly supported rational approval distribution.

We use a weighted version of the Greedy Justified Candidate Rule, listed as Algorithm 4 in the [distribution paper](https://arxiv.org/html/2607.01036v1#S4.SS1). The correctness and bit-complexity arguments below are self-contained.

1. Witness masses

For a candidate set \(U\subseteq C\), a candidate \(c\notin U\), and an integer \(1\le\ell\le k\), define

\(q_{\ell,c}(U)=\sum_{\substack{B\in\mathcal S\\c\in B,\ |B\cap U|<\ell}}\mu_B.\)

We will construct a committee \(W\) satisfying the stronger condition

\(q_{\ell,c}(W)<\ell/k\qquad\text{for every }c\notin W\text{ and }1\le\ell\le k.\)

To see why this suffices, consider any submasses satisfying the premises of mass PJR+. Choose

\(c\in\left(\bigcap_{B:g_B>0}B\right)\setminus W.\)

If \(\left|W\cap\bigcup_{B:g_B>0}B\right|<\ell\), then every type with \(g_B>0\) contains \(c\) and satisfies \(|B\cap W|<\ell\). Consequently,

\(\ell/k\le\sum_{B\in\mathcal S}g_B\le q_{\ell,c}(W)<\ell/k,\)

a contradiction. This argument applies to arbitrary real submasses.

2. The algorithm

Fix any ordering of the candidates.

  • Initialize \(U=\varnothing\).
  • Process the levels \(\ell=k,k-1,\ldots,1\).
  • At each level, scan the candidates in the fixed order. For every candidate \(c\notin U\), compute \(q_{\ell,c}(U)\) using the current set \(U\). If \(q_{\ell,c}(U)\ge\ell/k\), add \(c\) to \(U\).
  • After all levels, add arbitrary remaining candidates until the committee has size \(k\).

We next prove that the greedy phase selects at most \(k\) candidates, so the final step is always possible.

3. Proof of the committee-size bound

Suppose the greedy phase makes \(R\) selections. Index them chronologically by \(j=1,\ldots,R\). Let \(c_j\) be the selected candidate, \(\ell_j\) its selection level, and \(U_{j-1}\) the set immediately before this selection. Define

\(\mathcal T_j=\{B\in\mathcal S:c_j\in B,\ |B\cap U_{j-1}|<\ell_j\},\qquad q_j=\sum_{B\in\mathcal T_j}\mu_B.\)

By the selection rule,

\(q_j\ge\ell_j/k>0.\)

For the proof only, charge type \(B\) an amount

\(\pi_j(B)=\begin{cases}\mu_B/q_j,&B\in\mathcal T_j,\\0,&B\notin\mathcal T_j.\end{cases}\)

Each selection incurs total charge exactly one:

\(\sum_{B\in\mathcal S}\pi_j(B)=1.\)

We claim that every type \(B\) receives total charge at most \(k\mu_B\).

If \(B\) is never charged, the claim is immediate. Otherwise, let \(j_*\) be its last charged selection, put \(r=\ell_{j_*}\), and let \(h\) be the number of selections at which \(B\) is charged.

Every one of the preceding \(h-1\) charged selections selected a distinct candidate belonging to \(B\). Therefore,

\(h-1\le |B\cap U_{j_*-1}|<r,\)

so \(h\le r\).

The levels are processed in decreasing order. Thus every charged selection \(j\le j_*\) has \(\ell_j\ge r\), and hence

\(\pi_j(B)=\mu_B/q_j\le k\mu_B/\ell_j\le k\mu_B/r.\)

Summing over the \(h\) charged selections gives

\(\sum_{j=1}^{R}\pi_j(B)\le h\,k\mu_B/r\le k\mu_B.\)

Finally,

\(R=\sum_{j=1}^{R}\sum_{B\in\mathcal S}\pi_j(B)=\sum_{B\in\mathcal S}\sum_{j=1}^{R}\pi_j(B)\le k\sum_{B\in\mathcal S}\mu_B=k.\)

This proves the size bound. The empty type remains included in the normalization; it simply receives no charge.

4. Proof of mass PJR+

Witness masses decrease when the committee grows. Specifically, if \(U\subseteq U'\) and \(c\notin U'\), then

\(q_{\ell,c}(U')\le q_{\ell,c}(U),\)

because \(|B\cap U'|\ge|B\cap U|\) for every type \(B\).

Let \(W\) be the committee after completion to size \(k\). Fix \(c\notin W\) and \(1\le\ell\le k\). Since \(c\) was never selected, it was considered and rejected during level \(\ell\). If \(U_{\mathrm{test}}\) denotes the committee at that moment, rejection means

\(q_{\ell,c}(U_{\mathrm{test}})<\ell/k.\)

Since \(U_{\mathrm{test}}\subseteq W\), monotonicity gives

\(q_{\ell,c}(W)\le q_{\ell,c}(U_{\mathrm{test}})<\ell/k.\)

Thus the stronger witness-mass condition from Section 1 holds for every omitted candidate and every level. Section 1 then proves mass PJR+, including groups whose mass equals \(\ell/k\).

5. Exact bit complexity

Write each supplied mass as \(\mu_B=u_B/v_B\), where the numerator and positive denominator are binary-encoded integers. Set

\(D=\prod_{B\in\mathcal S}v_B,\qquad a_B=u_B(D/v_B).\)

Then

\(\mu_B=a_B/D,\qquad \sum_{B\in\mathcal S}a_B=D.\)

The bit length of \(D\) is at most the sum of the bit lengths of the input denominators, hence is \(O(L)\). Each \(a_B\) also has \(O(L)\) bits. Computing these integers takes polynomial time.

Maintain, for each type, the integer count \(s_B=|B\cap U|\). A candidate test computes

\(A_{\ell,c}=\sum_{\substack{B\in\mathcal S\\c\in B,\ s_B<\ell}}a_B\)

and selects \(c\) exactly when

\(kA_{\ell,c}\ge\ell D.\)

Because \(0\le A_{\ell,c}\le D\), all arithmetic operands have \(O(L+\log k)\) bits. Each test scans at most \(\tau\) types. There are at most \(km\) tests, and each selected candidate requires at most \(\tau\) count updates. With a precomputed candidate–type incidence table, the greedy phase therefore uses \(O(km\tau)\) elementary integer operations on polynomial-length integers.

The charges used in Section 3 are purely analytical: the algorithm never computes them. There is consequently no denominator growth from repeated payments and no expansion into an electorate of size \(D\).

The promised interval model supplies a valid approval distribution, but no geometric property is needed by this algorithm. Its running time is polynomial in the requested parameters.
