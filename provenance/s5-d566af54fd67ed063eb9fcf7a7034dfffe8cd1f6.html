The continuous mirror question, as graded

Given worker types \(i\in B\) with rational masses \(p_i\) summing to \(1\), position types \(j\in C\) with rational masses \(q_j\) summing to \(1\), a strict order \(\succ_i\) over position types for each \(i\), and a relation \(R_j\subseteq B\times B\) for each \(j\), does there exist a nonnegative coupling \(x_{ij}\) with row sums \(p_i\) and column sums \(q_j\) such that for every \(i,j\), \(U_{ij}=0\) or \(V_{ij}=0\), where \(U_{ij}=\sum_{j':\,j\succ_i j'}x_{ij'}\) and \(V_{ij}=\sum_{k:\,(k,i)\notin R_j}x_{kj}\)?

Packaged proof task (what the prover saw — nothing else)

Let \(B\) and \(C\) be nonempty finite supports of worker and position types, respectively. Each society is given by its support list and strictly positive binary rational masses \(p_i\) and \(q_j\), with \(\sum_{i\in B}p_i=\sum_{j\in C}q_j=1\).
Set \(m=|C|\), \(\tau=|B|+|C|\), and let \(L\) be the total binary input length; \(\tau\) counts supported types, not all possible preference types. The two supports need not have equal cardinality.
Each worker type \(i\) has an explicitly listed strict total order \(\succ_i\) over all of \(C\). Each position type \(j\) has an explicitly listed arbitrary relation \(R_j\subseteq B\times B\): \((k,i)\in R_j\) means that \(j\) prefers \(k\) at least as much as \(i\). No reflexivity, completeness, transitivity, or acyclicity is required.
A feasible allocation is a real matrix \(x\geq0\) with \(\sum_jx_{ij}=p_i\) and \(\sum_ix_{ij}=q_j\). It is stable when, for every \((i,j)\in B\times C\), \(U_{ij}=0\) or \(V_{ij}=0\), where \(U_{ij}=\sum_{j':\,j\succ_i j'}x_{ij'}\) and \(V_{ij}=\sum_{k:\,(k,i)\notin R_j}x_{kj}\); this condition also applies when \(x_{ij}>0\).

Is deciding whether a stable feasible allocation exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite individual agents, deciding existence of a stable perfect matching with strict complete worker preferences and arbitrary position relations is NP-complete; it is polynomial-time solvable when the relations are asymmetric. Result

The decision problem is \(\mathrm{NP}\text{-complete}\), already when \(|B|=|C|=n\) and all masses equal \(1/n\). Thus a polynomial-time algorithm in \(m,\tau,L\) exists only if \(\mathrm{P}=\mathrm{NP}\).

The key observation is that stability is preserved when the support of an allocation shrinks. Consequently, in the equal-mass case, a stable fractional allocation yields a stable perfect matching.

1. Stability is preserved under support inclusion

For a nonnegative matrix \(x\), define \(E(x)=\{(i,j):x_{ij}>0\}\).

Lemma. If \(x\) satisfies all the stability conditions and \(y\geq 0\) satisfies \(E(y)\subseteq E(x)\), then \(y\) also satisfies all the stability conditions.

Proof. Fix \((i,j)\). All summands defining \(U_{ij}(x)\) and \(V_{ij}(x)\) are nonnegative.

If \(U_{ij}(x)=0\), then \(x_{ij'}=0\) for every \(j'\) with \(j\succ_i j'\). Support inclusion implies that all corresponding entries of \(y\) vanish, so \(U_{ij}(y)=0\).

If \(V_{ij}(x)=0\), then \(x_{kj}=0\) for every \(k\) with \((k,i)\notin R_j\). Again, support inclusion gives \(V_{ij}(y)=0\).

Stability of \(x\) guarantees at least one of these alternatives for every \((i,j)\). Hence \(y\) satisfies stability. This argument includes pairs with \(y_{ij}>0\). \(\square\)

The lemma concerns stability alone; feasibility of \(y\) must be established separately.

2. Equal masses allow extraction of a perfect matching

Suppose \(|B|=|C|=n\) and \(p_i=q_j=1/n\). Let \(x\) be feasible, and consider the bipartite graph with edge set \(E(x)\).

For any \(S\subseteq B\), let \(N(S)\subseteq C\) be its neighborhood. Since every positive entry in a row belonging to \(S\) lies in a column belonging to \(N(S)\),

\[ \text{ } \]

\( |S|/n=\sum_{i\in S}\sum_{j\in N(S)}x_{ij}\leq\sum_{j\in N(S)}\sum_{i\in B}x_{ij}=|N(S)|/n. \)

Thus \(|N(S)|\geq |S|\) for every \(S\subseteq B\). Hall’s marriage theorem therefore gives a matching covering \(B\); because the two sides have equal cardinality, it is perfect.

Write this matching as a bijection \(\mu:B\to C\), and define \(y_{i,\mu(i)}=1/n\), with all other entries zero. Then \(y\) is feasible and \(E(y)\subseteq E(x)\). By the lemma, if \(x\) is stable, so is \(y\).

For this matching allocation, the stability quantities have the following exact interpretation:

  • \(U_{ij}(y)>0\) if and only if \(j\succ_i\mu(i)\).
  • \(V_{ij}(y)>0\) if and only if \((\mu^{-1}(j),i)\notin R_j\).

Therefore \(y\) is stable exactly when there is no pair satisfying both \(j\succ_i\mu(i)\) and \((\mu^{-1}(j),i)\notin R_j\). For a matched pair \(j=\mu(i)\), the first condition is false, so applying stability also to occupied pairs causes no discrepancy.

We have proved:

Proposition. With equal cardinalities and uniform masses, a stable feasible allocation exists if and only if a stable perfect matching exists under the stated blocking-pair definition.

3. Polynomial reduction and hardness

The known discrete theorem applies to two equally sized sets, strict complete worker orders, and arbitrary position relations. Its blocking-pair criterion is exactly \(j\succ_i\mu(i)\) together with \((\mu^{-1}(j),i)\notin R_j\). Existence of a stable perfect matching under this definition is \(\mathrm{NP}\text{-complete}\). See Section 2.2 and Theorem 1 of [Farczadi, Georgiou, and Könemann](https://arxiv.org/pdf/1407.1853).

Given an instance of that discrete problem with \(n\) agents on each side, retain its support labels, worker orders, and position relations, and assign every type mass \(1/n\).

These masses are strictly positive rationals summing to one on each side. Each has binary encoding length \(O(\log n)\), so the construction has polynomial size and takes polynomial time. The proposition proves equivalence of the original and constructed instances.

Consequently, the continuous problem is \(\mathrm{NP}\text{-hard}\), even on this uniform-mass subclass. Allowing unequal support cardinalities does not affect the reduction, because the general problem includes that subclass.

4. Polynomial-size certificates for arbitrary rational masses

We now prove membership in \(\mathrm{NP}\), including instances with unequal support cardinalities.

Let \(D\) be the product of all denominators in the input masses. Then every \(Dp_i\) and \(Dq_j\) is an integer, and the binary length of \(D\) is \(O(L)\).

Suppose a stable real allocation \(x\) exists. Construct a directed network with source \(s\), sink \(t\), and the following arcs:

  • \(s\to i\), with capacity \(Dp_i\), for every worker type \(i\);
  • \(i\to j\), with capacity \(D\), for every \((i,j)\in E(x)\);
  • \(j\to t\), with capacity \(Dq_j\), for every position type \(j\).

The entries \(Dx_{ij}\), together with flows \(Dp_i\) and \(Dq_j\) on the outer arcs, give a feasible real flow of value \(D\). The middle-arc capacities suffice because \(x_{ij}\leq 1\). The total capacity leaving \(s\) is \(D\), so the maximum flow value is exactly \(D\).

The integral-flow theorem states that a finite network with nonnegative integer capacities has an integral maximum flow. All capacities here satisfy those hypotheses. Hence there is an integral flow \(f\) of value \(D\).

Every source arc and every sink arc must be saturated: their respective total capacities are \(D\), equal to the flow value. Define \(y_{ij}=f_{ij}/D\) on the middle arcs, and zero elsewhere. Flow conservation and saturation show that \(y\) has precisely the required row and column sums. Its support is contained in \(E(x)\), so the lemma proves its stability.

Thus every yes-instance has a stable allocation whose entries share denominator \(D\), with integer numerators between zero and \(D\). Its encoding length is \(O(|B||C|L)\), which is polynomial in the input length.

A verifier checks nonnegativity, all prescribed marginals, and every stability disjunction using exact rational arithmetic. The number of operations and the lengths of the numbers involved are polynomial in the input length. Therefore the problem belongs to \(\mathrm{NP}\).

Combining membership with the reduction establishes the claimed \(\mathrm{NP}\text{-completeness}\).

The lemma is valid.

The argument applies to every pair, including occupied pairs. It requires no structural properties of the position relations. The prover correctly distinguishes preservation of stability from preservation of feasibility.

The Hall inequality is correct. For every \(S\subseteq B\), the definition of \(N(S)\) ensures that all positive entries in rows indexed by \(S\) occur in columns indexed by \(N(S)\). Hence

\[ \frac{|S|}{n} = \sum_{i\in S}\sum_{j\in N(S)}x_{ij} \leq \sum_{j\in N(S)}\sum_{i\in B}x_{ij} = \frac{|N(S)|}{n}. \]

The finite bipartite graph therefore satisfies Hall’s condition. Hall’s marriage theorem supplies a matching covering \(B\), and equal cardinalities make it perfect. The empty subset satisfies the inequality as well.

The allocation defined by assigning mass \(1/n\) to every matching edge has the required marginals, and its support lies in \(E(x)\). The support lemma therefore transfers stability.
