The continuous mirror question, as graded

Given registered candidates \(R\), addable candidates \(D\), a nonempty set \(J\subseteq R\), a budget \(b\), and a list of \(\tau\) complete rankings \(t\) over \(R\cup D\) with positive rational masses \(\mu_t\) summing to \(1\), is there an \(A\subseteq D\), \(|A|\le b\), such that no candidate in \(J\) is a Maximin winner after restricting every ranking to \(R\cup A\)? Here \(M_\mu(a,c)=\sum_{t:a\succ_t c}\mu_t\), and the score of \(a\) is \(\min_{c\ne a}M_\mu(a,c)\); under random-candidates tie-breaking, the condition is that the resulting winner set is disjoint from \(J\).

Packaged proof task (what the prover saw — nothing else)

Given disjoint finite sets of registered candidates \(R\) and addable candidates \(D\), assume \(|R|\ge 2\), \(D\ne\varnothing\), a nonempty set \(J\subseteq R\), and an integer budget \(1\le b\le |D|\).
A society is given by its support: the list of \(\tau\) distinct strict complete rankings over \(R\cup D\) with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings.
For \(A\subseteq D\), restrict every ranking to \(S=R\cup A\). Define \(M_\mu(a,c)=\sum_{t:a\succ_t c}\mu_t\), the Maximin score \(s_S(a)=\min_{c\in S\setminus\{a\}}M_\mu(a,c)\), and the winner set \(W(S)=\operatorname*{arg\,max}_{a\in S}s_S(a)\).
Random-candidates tie-breaking selects uniformly from \(W(S)\); success means \(W(S)\cap J=\varnothing\). Candidate additions are indivisible, and the society remains fixed.
Let \(m=|R\cup D|\), \(k=|J|\), and \(L\) be the total binary input length; state running times in \(m,\tau,L,b,k\).

Is deciding whether there exists \(A\subseteq D\) with \(|A|\le b\) and \(W(R\cup A)\cap J=\varnothing\) solvable in polynomial time, or is it NP-hard?

For an explicitly listed finite electorate, this candidate-addition problem with random-candidates tie-breaking is NP-hard. Its discrete version also admits an \(O(2^k\operatorname{poly}(m,n))\)-time algorithm, where \(n\) is the number of voters.

Modeling choices made when packaging the task

  • The budget domain was unspecified; require an integer budget between 1 and |D|, matching the discrete candidate-addition definition and consequently requiring D to be nonempty.
  • The singleton-election score was undefined; require at least two registered candidates so every Maximin minimum has a nonempty domain.
  • Interpret complete rankings as strict linear orders, matching the discrete vote definition.
  • Define m as the total number of registered and addable candidates, k as |J|, and L as the total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is \(\mathrm{NP}\)-complete. Moreover, it admits an algorithm running in \(O(2^k\operatorname{poly}(m,\tau,L))\) time.

The hardness proof uses the finite-electorate hardness stated in the question. The algorithm below works directly with rational masses and does not expand them into voters.

1. Exact computation and membership in \(\mathrm{NP}\)

Write each input mass as \(\mu_t=p_t/q_t\), with positive binary-encoded integers \(p_t,q_t\). Let \(Q=\prod_{t=1}^{\tau}q_t\). Its binary length is \(O(L)\). Thus every pairwise support can be represented exactly as

\(M_\mu(a,c)=Q^{-1}\sum_{t:a\succ_t c}p_t(Q/q_t).\)

The numerators also have \(O(L)\) bits, because the masses sum to one.

After computing all pairwise supports, a proposed addition set \(A\) can be verified by computing the scores and winner set on \(R\cup A\). All comparisons are exact integer comparisons with the common denominator \(Q\).

Using elementary integer arithmetic, preprocessing and verification take \(O(L^3+\tau m^2L)\) time. The certificate is simply the list of candidates in \(A\), whose size is polynomial in \(L\). Hence the problem belongs to \(\mathrm{NP}\).

2. Hardness survives aggregation into support masses

Start with an instance of the explicitly listed finite-electorate problem whose hardness is given in the question. Let its electorate contain \(n\ge 1\) voters, and let \(v(a,c)\) count the voters ranking \(a\) above \(c\).

Grouping identical rankings and assigning each its frequency divided by \(n\) already preserves all winner sets. To cover even the stricter interpretation in which “binary-rational” requires dyadic masses, use the following padding construction.

Duplicate every voter. Choose the smallest power of two \(N\) satisfying \(N\ge 2n\), and put

\(h=(N-2n)/2.\)

Both \(N\) and \(2n\) are even, so \(h\) is a nonnegative integer. Fix any complete ranking \(\rho\), and add \(h\) voters with ranking \(\rho\) and \(h\) with its reverse. Every reverse pair contributes exactly one vote to each ordered pairwise comparison. Consequently, the resulting normalized support is

\(M_\mu(a,c)=(2v(a,c)+h)/N.\)

Aggregate identical rankings and give each distinct ranking its multiplicity divided by \(N\). These masses are positive dyadic rationals summing to one.

For any restricted candidate set \(S\), define the original count-based Maximin score by

\(s^{\mathrm{old}}_S(a)=\min_{c\in S\setminus\{a\}}v(a,c).\)

Since the affine map \(x\mapsto(2x+h)/N\) is strictly increasing,

\(s^\mu_S(a)=(2s^{\mathrm{old}}_S(a)+h)/N.\)

Therefore the two societies have exactly the same winner set for every \(S\). In particular, they have the same answer for every permitted addition set \(A\). The sets \(R,D,J\) and budget \(b\) remain unchanged.

The construction has polynomial size: \(N<4n\), there are at most \(n+2\) distinct rankings, and each mass requires \(O(\log(n+1))\) bits. It is therefore a polynomial-time many-one reduction from the hard problem supplied in the question.

This proves \(\mathrm{NP}\)-hardness, including for dyadic masses. Together with Section 1, it proves \(\mathrm{NP}\)-completeness.

3. A direct algorithm with a \(2^k\) factor

The following characterization also transfers the stated parameterized tractability to the support representation.

3.1 Fix a candidate and a threshold

Enumerate a candidate \(w\in(R\cup D)\setminus J\) and a threshold

\(q\in\{M_\mu(w,c):c\in(R\cup D)\setminus\{w\}\}.\)

There are at most \(m(m-1)\) such pairs.

Set \(S_0=R\cup\{w\}\), and let \(\varepsilon_w\) equal one if \(w\in D\), and zero otherwise. Discard the pair if \(\varepsilon_w>b\), or if some \(c\in S_0\setminus\{w\}\) satisfies \(M_\mu(w,c)<q\).

For every remaining pair, define the unwanted candidates still requiring a score decrease:

\(T=\{j\in J:s_{S_0}(j)\ge q\}.\)

An additional candidate is admissible precisely when it preserves the required lower bound on \(w\)'s score. Thus define

\(E=\{d\in D\setminus S_0:M_\mu(w,d)\ge q\}.\)

For each \(d\in E\), define its covered subset

\(C_d=\{j\in T:M_\mu(j,d)<q\}.\)

3.2 The resulting covering condition is exact

For any \(B\subseteq E\), put \(S=S_0\cup B\). By the admissibility tests, \(s_S(w)\ge q\).

If \(j\in J\setminus T\), then \(s_{S_0}(j)<q\). Adding candidates can only decrease its Maximin score, so \(s_S(j)<q\).

If \(j\in T\), all its comparisons against \(S_0\setminus\{j\}\) have support at least \(q\). Consequently,

\(s_S(j)<q\quad\Longleftrightarrow\quad j\in\bigcup_{d\in B}C_d.\)

It follows that, whenever

\(\bigcup_{d\in B}C_d=T\quad\text{and}\quad |B|\le b-\varepsilon_w,\)

the addition set \((\{w\}\cap D)\cup B\) succeeds: every candidate in \(J\) has score strictly below \(w\), and therefore none can be a winner.

Conversely, suppose \(A\) succeeds. Choose any winner \(w\in W(R\cup A)\). Success implies \(w\notin J\). Take \(q=s_{R\cup A}(w)\). Because the minimum defining this score is attained, this threshold occurs in the enumeration.

Now \(S_0\subseteq R\cup A\). Every comparison of \(w\) against a selected candidate has support at least \(q\), so the pair passes the initial test and \(B=A\setminus\{w\}\) is contained in \(E\).

Every \(j\in J\) has score strictly below \(q\); otherwise it would also be a winner. For \(j\in T\), its comparison witnessing this strict inequality must therefore be against a candidate in \(B\). Hence the sets \(C_d\), for \(d\in B\), cover \(T\), within the remaining budget.

Thus the original instance succeeds if and only if some enumerated pair has a cover within its remaining budget.

3.3 Dynamic programming and running time

For a fixed pair, use dynamic programming over subsets of \(T\). Process the admissible candidates one at a time. A state records the minimum number of processed candidates whose covered union is exactly \(U\subseteq T\).

Initially, only the empty union has finite cost, namely zero. When processing \(d\), each finite state \(U\) gives two transitions:

  • Skip \(d\), retaining \(U\) and its cost.
  • Select \(d\), obtaining \(U\cup C_d\) at cost one larger.

These transitions exhaust the possibilities for selecting processed candidates, which proves the state invariant by induction. Accept the pair exactly when the final cost for \(T\) is at most \(b-\varepsilon_w\). Costs can be capped at \(b+1\).

There are at most \(2^k\) states, at most \(m\) candidates per pair, and at most \(m^2\) pairs. Accounting for exact rational preprocessing, comparisons, subset operations, and budget counters, a conservative bit-operation bound is

\(O\!\left(L^3+\tau m^2L+m^3(k+1)L+2^k m^3\bigl(k+\log(b+2)\bigr)\right).\)

In particular, the running time is \(O(2^k\operatorname{poly}(m,\tau,L))\). This proves fixed-parameter tractability in \(k\), alongside general \(\mathrm{NP}\)-completeness.
