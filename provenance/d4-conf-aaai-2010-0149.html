The continuous mirror question, as graded

Given population scale \(N\), a finite report domain of single-minded bidder types \(t=(x_t,v_t)\), rational type masses \(\mu_t\), a kernel and penalty parameter \(\lambda\), and per-capita item supplies scaled to \(N\), determine the maximum unilateral incentive regret of the paper’s one-run kernel auction with price-based payments. A report from type \(t\) to \(t'\) changes the distribution by \(\mu' = \mu + \frac{1}{N}(e_{t'}-e_t)\); decide whether the maximum regret is at most \(\eta\), and return a maximizing report or a certificate.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types. The explicitly listed report domain \(D\) may also contain zero-mass types; write \(d=|D|\).
There are \(m\) item categories. Each report \(s\in D\) specifies a nonempty bundle \(x_s\in\{0,1\}^m\) and a nonnegative rational value \(v_s\); its single-minded valuation is \(V_s(y)=v_s\mathbf{1}\{y\ge x_s\}\). Input masses satisfy \(\sum_s\mu_s=1\). Input also includes a binary-encoded integer \(N\ge1\), positive rational per-capita supplies \(c\), positive rational \(\lambda\), rational \(\eta\ge0\), and a rational supply tolerance \(0<\delta<1\).
The kernel is supplied through its rational positive-semidefinite Gram matrix \(K_{su}=k(x_s,x_u)\), consistent with a centered feature map \(\phi(0)=0\). Identical bundles have identical kernel rows. Let \(X\) have columns \(x_s\).
For any report distribution \(\nu\), put \(n=N\nu\) and \(F(n)=\{b\in\mathbb{R}_{\ge0}^d:b\le n,\ Xb\le Nc\}\). Fractional mass allocations are permitted. The auction selects the lexicographically smallest optimal pair \((a,b)\) of \(\max_{0\le a\le n,\ b\in F(n)} v^\top a-\frac{1}{2\lambda}(a-b)^\top K(a-b)\), in the listed report order, and computes bundle prices \(p=K(a-b)/\lambda\).
The delivered mass is \(a\). Restrict inputs to those for which this selected allocation satisfies \(Xa\le Nc+\delta\mathbf{1}\) at the truthful distribution and every unilateral report distribution considered below; this is the explicit approximate-feasibility promise.
A tagged bidder reporting \(s\), where \(n_s\ge1\), receives \(x_s\) with probability \(z_s=a_s/n_s\) and nothing otherwise. Its expected price-based payment is \(r_s(\nu)=\max_{b'\in F(n-e_s)}p^\top b'-p^\top(a-z_se_s)\), using the prices from this run, without recomputing them after removal. Here \(e_s\) is the coordinate unit vector.
For a true type \(t\) with \(N\mu_t\ge1\), reporting \(s\in D\) produces \(\nu^{t\to s}=\mu+(e_s-e_t)/N\). Define \(U_t(s)=z_s(\nu^{t\to s})V_t(x_s)-r_s(\nu^{t\to s})\) and \(R=\max_{t:N\mu_t\ge1,\ s\in D}[U_t(s)-U_t(t)]\); assume at least one such true type exists.
Is deciding whether \(R\le\eta\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? Measure running times in \(m,\tau,d\) and the total binary input length \(L\), including the encodings of \(N,\lambda,\delta\).
For discrete bidders, the price-based auction has the conditional additive incentive-regret bound \(2(n-1)\kappa^2/\lambda\), where \(k(x,x)\le\kappa^2\), under the assumed efficient allocation and supporting-price conditions; this is not a polynomial-time computation theorem. [Source](https://ojs.aaai.org/index.php/AAAI/article/download/7642/7503).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Conclusion. The decision problem is in \(\mathrm{P}\). In fact, the exact rational value of \(R\) can be computed in time polynomial in \(m,\tau,d,L\). The proof accounts for singular Gram matrices, lexicographic tie-breaking, and binary-encoded \(N\).

1. Each auction run is an exactly solvable convex quadratic program

Extend the mass vector to all of \(D\) by assigning zero mass to unrepresented reports. Fix a nonnegative rational vector \(n\) arising from the truthful distribution or a permitted deviation. Define

\[ \]
\(P_n=\{(a,b)\in\mathbb{R}^{2d}:0\le a\le n,\ 0\le b\le n,\ Xb\le Nc\}\).

This polytope is nonempty because it contains \((0,0)\), and it is bounded because both vectors lie between \(0\) and \(n\). Write the auction objective as

\(f(a,b)=v^\top a-\dfrac{1}{2\lambda}(a-b)^\top K(a-b)\).

Minimizing \(-f\) over \(P_n\) is a rational convex quadratic program. Indeed, its quadratic form evaluated on any direction \((h_a,h_b)\) is

\(\dfrac{1}{\lambda}(h_a-h_b)^\top K(h_a-h_b)\ge0\),

using \(K\succeq0\) and \(\lambda>0\).

We use the exact polynomial-time convex quadratic programming theorem: for a rational positive-semidefinite quadratic objective and rational linear constraints, a nonempty bounded feasible polyhedron admits an exact rational optimizer computable in time polynomial in the binary input length. This theorem allows a singular quadratic matrix and does not require the feasible set to have interior. See [Kozlov, Tarasov, and Khachiyan, *The polynomial solvability of convex quadratic programming*](https://www.mathnet.ru/eng/zvmmf5189). Rational data can be converted to integer data by clearing denominators, with polynomial growth in encoding length.

Consequently, we can compute one exact optimizer \((a^0,b^0)\) of polynomial encoding length. This alone does not implement the prescribed tie-breaking; the next step does.

2. The entire optimal set has a rational polyhedral description

Set \(q^0=a^0-b^0\). We claim that the set of auction optimizers is exactly

\(\Omega_n=\{(a,b)\in P_n:K(a-b)=Kq^0,\ v^\top a=v^\top a^0\}\).

To prove necessity, let \((a,b)\) be any optimizer and put \(q=a-b\). Convexity of \(P_n\) makes the midpoint feasible. Direct expansion gives

\(f\left(\dfrac{a+a^0}{2},\dfrac{b+b^0}{2}\right)=\dfrac{f(a,b)+f(a^0,b^0)}{2}+\dfrac{1}{8\lambda}(q-q^0)^\top K(q-q^0)\).

Both endpoint objectives equal the maximum. The midpoint cannot have a larger objective, while the last term is nonnegative. Therefore

\((q-q^0)^\top K(q-q^0)=0\).

For a real symmetric positive-semidefinite matrix, \(h^\top Kh=0\) implies \(Kh=0\): diagonalizing \(K\), every component along an eigenvector with positive eigenvalue must vanish. Thus \(K(q-q^0)=0\).

It follows that the quadratic penalties agree, since

\(q^\top Kq=(q^0)^\top Kq^0+2(q^0)^\top K(q-q^0)+(q-q^0)^\top K(q-q^0)=(q^0)^\top Kq^0\).

Equality of the optimal objectives now implies \(v^\top a=v^\top a^0\). This proves necessity.

Conversely, if a feasible pair satisfies both displayed linear equalities, then \(K(q-q^0)=0\), so its quadratic penalty agrees with that of the known optimizer. Its linear objective also agrees. It is therefore optimal, proving the claim.

In particular, \(\Omega_n\) is a nonempty bounded rational polytope with a polynomial-length description. All its points produce the same price vector, although their delivered allocations may differ.

3. Lexicographic selection is polynomial-time

List the \(2d\) coordinates in the auction’s prescribed lexicographic order as \(y_1,\ldots,y_{2d}\). Starting with \(\Omega_n\), minimize \(y_1\) by exact linear programming and retain the equality fixing it to its minimum. Then minimize \(y_2\) over the retained set, and continue.

At every stage, the remaining set is a nonempty face of the preceding polytope. After all coordinates have been fixed, exactly one point remains. By construction, this is the lexicographically smallest auction optimizer.

We must also control the encoding lengths of the coordinate minima. Each retained set is a face of the original \(\Omega_n\); its vertices are therefore vertices of \(\Omega_n\). Each coordinate minimum is attained at such a vertex.

For completeness, vertices of a rational polytope have polynomial encoding length in its explicit description. Clear denominators in each constraint. If the resulting integer coefficients have at most \(B\) bits, a vertex in \(2d\) dimensions is determined by \(2d\) independent binding equations. Cramer’s rule expresses every coordinate as a ratio of determinants. Each determinant has magnitude at most

\((2d)!\,2^{2dB}\),

so its encoding length is \(O(dB+d\log d)\). This argument also covers lower-dimensional polytopes, using their binding equality constraints.

Here \(B\) is polynomial in the original input length and dimensions. Hence every coordinate minimum introduced during lexicographic selection has a uniform polynomial encoding bound. There is no repeated growth beyond this bound.

Thus one auction run, including its exact selected pair and prices, requires one convex quadratic program, at most \(2d\) linear programs, and polynomial-time rational arithmetic.

4. Each payment and utility is exactly computable

Suppose the tagged report is \(s\), with \(n_s\ge1\). From the selected allocation compute

\(z_s=\dfrac{a_s}{n_s}\), \(\qquad p=\dfrac{K(a-b)}{\lambda}\).

These are exact rational quantities of polynomial encoding length.

The removal vector \(n-e_s\) is nonnegative. Therefore the payment optimization

\(H_s(n,p)=\max\{p^\top b':0\le b'\le n-e_s,\ Xb'\le Nc\}\)

is a rational linear program with a nonempty bounded feasible set. Exact polynomial-time linear programming computes its optimal value. The required payment is then

\(r_s=H_s(n,p)-p^\top(a-z_se_s)\).

This uses the price vector from the original run, exactly as specified in the task.

For a true type \(t\), determine whether \(x_s\ge x_t\) by inspecting the \(m\) coordinates. Its utility is consequently the exactly computable rational number

\(U_t(s)=z_s v_t\mathbf{1}\{x_s\ge x_t\}-r_s\).

5. Enumerating deviations and deciding the threshold

Let

\(T=\{t\in D:N\mu_t\ge1\}\).

Membership is decidable by exact rational comparison. Every member has positive mass, so \(|T|\le\tau\). By hypothesis, \(T\) is nonempty.

First compute the selected truthful allocation at \(n^0=N\mu\), and compute \(U_t(t)\) for each \(t\in T\).

For every \((t,s)\in T\times D\), form

\(n^{t\to s}=N\mu+e_s-e_t\).

This vector is nonnegative: when \(s\ne t\), the only decreased coordinate is \(t\), whose truthful count is at least \(1\); when \(s=t\), the vector is unchanged. Moreover, its tagged coordinate satisfies \(n^{t\to s}_s\ge1\). Hence every run and payment computation above applies.

Compute \(U_t(s)\) using that run, and then take the finite maximum

\(R=\max_{t\in T,\ s\in D}\bigl(U_t(s)-U_t(t)\bigr)\).

There are at most \(\tau d\) pairs. One exact rational comparison of the resulting \(R\) with \(\eta\) decides the question, including equality.

All constructed numerical data have polynomial encoding length. In particular, forming \(N\mu\), \(Nc\), or dividing by \(\lambda\) depends polynomially on their binary encodings; the algorithm never expands the population into \(N\) individual bidders. The total number of optimization calls is polynomial: at most \(1+\tau d\) quadratic programs and \(2d(1+\tau d)+\tau+\tau d\) linear programs.

The approximate-feasibility promise is not needed by this algorithm. On promised inputs, the computed allocations satisfy it, but it does not change the optimization problems being solved. No precision parameter depending on the numerical value of \(\delta\) is required.

Thus the promised decision problem belongs to \(\mathrm{P}\). An \(\mathrm{NP}\)-hardness result under polynomial-time many-one reductions would therefore imply \(\mathrm{P}=\mathrm{NP}\).
