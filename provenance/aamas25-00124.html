The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), committee \(W\subseteq C\) with \(|W|=k\), distinct approval types \(A_1,\ldots,A_\tau\subseteq C\), and rational masses \(\mu_i\ge0\) summing to \(1\), decide whether for every integer \(\ell\ge1\), witness set \(Q\subseteq C\), and type subset \(I\subseteq\{1,\ldots,\tau\}\) satisfying \(\sum_{i\in I}\mu_i\ge|Q|/k\) and \(|A_i\cap Q|\ge\ell\) for all \(i\in I\), we have \(|W\cap\bigcup_{i\in I}A_i|\ge\ell\).

1. Interpretation and result

Literally, every instance fails: take \(I=Q=\varnothing\) and \(\ell=1\). Both premises hold, while the conclusion is false. Thus the literal problem is decidable in constant time.

For the intended, nondegenerate question, I require \(I\ne\varnothing\). Under this interpretation, verification is \(\mathrm{coNP}\)-complete, and detecting a violation is \(\mathrm{NP}\)-complete.

The proof below uses only the supplied finite-voter hardness result; it derives the complexity of the support representation.

2. Membership in \(\mathrm{coNP}\)

A violation consists of a nonempty type subset \(I\), a candidate subset \(Q\), and an integer \(\ell\) satisfying

\[ \sum_{i\in I}\mu_i\ge \frac{|Q|}{k}, \qquad |A_i\cap Q|\ge\ell\ \text{for every }i\in I, \qquad \left|W\cap\bigcup_{i\in I}A_i\right|<\ell. \]

Because \(I\ne\varnothing\), the approval condition implies \(\ell\le |Q|\). Because the total mass is \(1\), the threshold implies \(|Q|\le k\). Hence every violation satisfies \(1\le\ell\le |Q|\le k\), and has a certificate of length \(O(m+\tau+\log(k+1))\).

All conditions can be checked exactly in polynomial time. To justify the arithmetic bound, write \(\mu_i=a_i/b_i\), and set

\[ D=\prod_{i=1}^{\tau}b_i, \qquad w_i=a_i(D/b_i). \]

The integers \(D\) and \(w_i\) have \(O(L)\) bits. The mass inequality is equivalent to the integer comparison

\[ k\sum_{i\in I}w_i\ge |Q|D. \]

Using ordinary integer arithmetic and direct scans of approval sets, a conservative certificate-checking bound, including this preprocessing, is \(O(\tau(m+L)^2)\) bit operations. Therefore verification belongs to \(\mathrm{coNP}\).

3. Grouping identical voters preserves verification

Consider a finite electorate \(V\), with \(n=|V|\ge1\). Partition its voters into nonempty classes \(V_1,\ldots,V_\tau\), where all voters in \(V_i\) have approval set \(A_i\), and the sets \(A_i\) are distinct. Construct the support instance with masses

\[ \mu_i=\frac{|V_i|}{n}. \]

Keep \(C,k,W\) unchanged.

Claim. The finite electorate has a violation if and only if this support instance has a violation.

From a voter violation to a type violation. Suppose a nonempty voter coalition \(S\subseteq V\), together with \(Q,\ell\), witnesses a violation. Define

\[ I=\{i:S\cap V_i\ne\varnothing\}, \qquad S^\ast=\bigcup_{i\in I}V_i. \]

Then \(S\subseteq S^\ast\), so

\[ \sum_{i\in I}\mu_i=\frac{|S^\ast|}{n} \ge\frac{|S|}{n} \ge\frac{|Q|}{k}. \]

For each \(i\in I\), some voter in \(S\) has approval set \(A_i\). Consequently \(|A_i\cap Q|\ge\ell\). Moreover, adding the remaining voters of these types introduces no new approval sets:

\[ \bigcup_{v\in S}A_v=\bigcup_{i\in I}A_i. \]

Thus the number of approved committee members remains below \(\ell\), and \(I,Q,\ell\) witnesses a support-instance violation.

From a type violation to a voter violation. Conversely, given a support violation \(I,Q,\ell\), select the voter coalition \(S=\bigcup_{i\in I}V_i\). Its voter fraction is exactly \(\sum_{i\in I}\mu_i\); its approval union is exactly \(\bigcup_{i\in I}A_i\); and every member satisfies the same approval condition. Hence it witnesses a finite-voter violation.

This proves the claim.

The construction is polynomial: grouping explicitly listed ballots requires polynomial time, and each mass has numerator and denominator of \(O(\log(n+1))\) bits. Using incidence-vector encoding, the resulting input length is \(O(m+\tau m+\tau\log(n+1))\), with \(\tau\le n\).

The supplied theorem states that finite-voter FPJR verification is \(\mathrm{coNP}\)-complete; this result also appears in [Kalayci, Liu, and Kempe, *Full Proportional Justified Representation*](https://www.ifaamas.org/Proceedings/aamas2025/pdfs/p1070.pdf). The equivalence just proved gives a polynomial many-one reduction to support-instance verification. Thus the latter is \(\mathrm{coNP}\)-hard. Together with Section 2, it is \(\mathrm{coNP}\)-complete.

4. An explicit running-time bound

There is also a direct algorithm whose dependence on the parameters can be stated explicitly.

Enumerate every \(Q\subseteq C\) with \(1\le |Q|\le k\), and every \(S\subseteq W\) with \(|S|<|Q|\). Define

\[ E(Q,S)= \{i:A_i\cap W\subseteq S \text{ and }|A_i\cap Q|\ge |S|+1\}. \]

Report a violation precisely when some enumerated pair satisfies

\[ \sum_{i\in E(Q,S)}\mu_i\ge\frac{|Q|}{k}. \]

Soundness. The positive threshold makes \(E(Q,S)\) nonempty. Set \(I=E(Q,S)\) and \(\ell=|S|+1\). Every selected type approves at least \(\ell\) candidates in \(Q\), while their committee approval union is contained in \(S\), so its size is below \(\ell\).

Completeness. Given any violation \(I,Q,\ell\), put \(S=W\cap\bigcup_{i\in I}A_i\). Then \(|S|<\ell\le |Q|\le k\), so \((Q,S)\) is enumerated. Every \(i\in I\) belongs to \(E(Q,S)\), because \(|A_i\cap Q|\ge\ell\ge |S|+1\). Positivity of the masses therefore implies that \(E(Q,S)\) also meets the threshold.

Let \(B(m,k)=\sum_{q=1}^{k}\binom{m}{q}\). With the exact arithmetic described above, the algorithm runs in

\[ O\!\left(2^k B(m,k)\,\tau(m+L)^2\right) \]

bit operations. This is polynomial for each fixed \(k\), and is at most \(O(4^m\tau(m+L)^2)\).

5. What “\(\mathrm{NP}\)-hard” means here

For nonempty coalitions, the exact classification is \(\mathrm{coNP}\)-completeness. Consequently:

  • Verification belongs to \(\mathrm{P}\) if and only if \(\mathrm{P}=\mathrm{NP}\).
  • Violation detection is \(\mathrm{NP}\)-complete.
  • Verification is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions: query verification and negate its answer.
  • Under polynomial many-one reductions, verification is \(\mathrm{NP}\)-hard if and only if \(\mathrm{NP}=\mathrm{coNP}\). Indeed, such hardness together with membership in \(\mathrm{coNP}\) would imply \(\mathrm{NP}\subseteq\mathrm{coNP}\), and closure under taking complements then gives equality.

Thus the intended problem has a complete hardness classification, with the usual distinction between verification and finding a violation.
