1. Result

Both problems are \(\mathrm{NP}\)-hard.

More precisely:

  • The exact decision problem \(\mathrm{OPT}\geq h\) is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions.
  • Finding the requested additive approximation is \(\mathrm{NP}\)-hard: an algorithm polynomial in \(m,\tau,L,1/\varepsilon\) would imply \(\mathrm P=\mathrm{NP}\).

These conclusions already hold for a restricted family with \(m=2\), dyadic input parameters, and very weak contacts between the types whose seed masses are optimized. We prove the existence of every required mass limit for this family.

The reduction uses \(\mathcal B\)-seeding to determine which users can transmit \(\mathcal A\). Its objective approximates a graph quadratic form uniformly over all feasible allocations.

2. Construction from a graph

Start with an instance \((H,k)\) of the \(\mathrm{NP}\)-complete CLIQUE problem, where \(H\) is a simple undirected graph and \(2\leq k\leq |V(H)|\). The remaining values of \(k\) are decidable directly. CLIQUE’s \(\mathrm{NP}\)-completeness is a classical result of [Karp](https://people.seas.harvard.edu/~madhusudan/courses/Fall2020/Lectures/L19-after.pdf).

Pad \(H\) with isolated vertices until its number of vertices, denoted \(n\), is a power of two. This changes neither its clique number nor the answer for \(k\geq2\), and increases its size by less than a factor of two. Write \(A_{ij}\) for its adjacency matrix.

Construct \(n+1\) types: a source type \(s\), and one type for each vertex \(i\). Set

\(\displaystyle \mu_s=a_s=\frac12,\qquad \mu_i=\frac1{2n},\qquad a_i=0.\)

Thus every source user is an \(\mathcal A\)-seed, and no vertex user is an \(\mathcal A\)-seed. Choose

\(\displaystyle \kappa=\frac1{4n},\qquad \delta=\frac1{64n}.\)

The only nonzero contact parameters are

\(\displaystyle \lambda_{si}=2,\qquad \lambda_{ij}=\delta A_{ij}.\)

Choose the adoption probabilities

\(\displaystyle q_{\mathcal A|\emptyset}=0,\qquad q_{\mathcal A|\mathcal B}=1,\qquad q_{\mathcal B|\emptyset}=q_{\mathcal B|\mathcal A}=0.\)

All these parameters satisfy the required inequalities.

For a feasible allocation, let \(z_i=y_i\) be its \(\mathcal B\)-seed mass at vertex type \(i\), and put

\(\displaystyle b=\sum_i z_i.\)

The only other possible allocation is \(x_s\), so feasibility means

\(\displaystyle b+x_s=\kappa,\qquad 0\leq z_i\leq\frac1{2n},\qquad x_s\geq0.\)

In particular, \(b\leq\kappa\).

With probability one, an unseeded user never adopts \(\mathcal B\), since both probabilities for adopting it are zero. Consequently, a vertex user can adopt \(\mathcal A\) precisely when that user is a designated \(\mathcal B\)-seed and receives information about \(\mathcal A\). Such a user adopts \(\mathcal A\) unconditionally upon receiving that information.

Therefore the \(\mathcal A\)-cascade is exactly reachability through the live directed graph induced by the vertex \(\mathcal B\)-seeds, starting from those receiving a live channel from a source user. Allocating \(x_s\) changes neither this induced graph nor its initial information. Shared channels, reconsideration, and processing order introduce no additional effects in this construction.

Without any \(\mathcal B\)-seeds, only the source users adopt \(\mathcal A\). Hence

\(\displaystyle F_A(0,0)=\frac12.\)

3. Existence and characterization of the mass limit

We prove that the construction satisfies the limit promise for every feasible real allocation.

Define

\(\displaystyle p=1-e^{-1}.\)

For population size \(N\), let \(M_i=\lfloor Nz_i\rfloor\), \(M=\sum_iM_i\), and \(b_N=M/N\). Each vertex \(\mathcal B\)-seed independently receives direct source information with probability

\(\displaystyle p_N=1-\left(1-\frac2N\right)^{N/2}\longrightarrow p.\)

These direct-information indicators are mutually independent and independent of the internal live graph: they use distinct ordered pairs from the internal channels.

For an integer \(d\geq0\), consider activation using at most \(d\) internal edges after direct source information. Its limiting activation probabilities satisfy

\(\displaystyle u_i^{(0)}=p,\)

\[\displaystyle u_i^{(d+1)}=1-(1-p)\exp\!\left(-\delta\sum_j A_{ji}z_j u_j^{(d)}\right).\tag{1}\]

Here is a justification of this finite-depth limit.

Explore the incoming neighborhood of a uniformly chosen seed user, restricted to seed users and to depth \(d\). Before any repeated vertex appears, the number of fresh type-\(j\) predecessors of an explored type-\(i\) user is binomial with parameters \(M_j-O(R)\) and \(\delta/N\), when \(A_{ji}=1\), where \(R\) bounds the number of explored users. For fixed \(R\), these counts converge to independent Poisson variables of means \(\delta A_{ji}z_j\). At most \(R\) explored targets each have at most \(R\) previously discovered candidate predecessors, so the probability of a repeated vertex is bounded by \(\delta R^2/N\).

The restriction to fixed \(R\) can be removed. Every discovered user is the start of a simple incoming path to the root. The expected number of discovered users through depth \(d\) is therefore at most

\(\displaystyle \sum_{\ell=0}^{d}(\delta b_N)^\ell\leq\frac1{1-\delta\kappa}<2.\)

Indeed, there are at most \(M^\ell\) candidate paths of length \(\ell\), and each simple path uses distinct independent channels and has probability at most \((\delta/N)^\ell\). Markov’s inequality bounds the probability of exploring more than \(R\) users by \(2/R\), uniformly in \(N\).

Thus the finite-depth neighborhood converges to the stated Poisson tree. Its vertices have independent direct-information indicators of probability \(p\). Poisson thinning gives equation (1): the root fails to activate exactly when it lacks direct information and every incoming branch fails to activate its predecessor.

It remains to pass from bounded depth to the completed cascade. If a seed user activates but has no activation path with at most \(d\) internal edges, a shortest activation path has at least \(d+1\) internal edges. Its suffix contains a simple incoming path of length \(d+1\). The same path count bounds the expected fraction of such users by

\[\displaystyle b_N(\delta b_N)^{d+1}\leq\kappa(\delta\kappa)^{d+1}.\tag{2}\]

This tends to zero uniformly in \(N\). Finite-depth convergence and (2) prove existence of the full mass limit.

The sequence in (1) increases coordinatewise and is bounded by one. Let its limit be \(u_i\), and define \(r_i=z_i u_i\). Passing to the limit in (1) gives

\[\displaystyle r_i=z_i\left[1-\exp\!\left(-1-\delta\sum_j A_{ji}r_j\right)\right].\tag{3}\]

The map in (1) has Lipschitz constant at most \(\delta b<1\) in the maximum norm, because

\(\displaystyle |T_i(u)-T_i(v)|\leq\delta\sum_j A_{ji}z_j|u_j-v_j|\leq\delta b\|u-v\|_\infty.\)

Thus its fixed point is unique. The gain is

\[\displaystyle G(x,y)=\sum_i r_i.\tag{4}\]

The argument applies to every feasible allocation, including real masses, and to the zero allocation. It verifies the full promise required by the question.

4. A uniform quadratic approximation

Define the ordered-edge quadratic form

\(\displaystyle Q(z)=\sum_{i,j}A_{ij}z_i z_j,\)

and set

\(\displaystyle c=p(1-p),\qquad H(z)=pb+c\delta Q(z).\)

We now bound the error uniformly.

Write

\(\displaystyle S_i=\sum_j A_{ji}r_j,\qquad d_i=r_i-pz_i.\)

Equation (3) implies

\(\displaystyle d_i=(1-p)z_i(1-e^{-\delta S_i}).\)

Since \(0\leq S_i\leq b\) and \(1-e^{-t}\leq t\) for \(t\geq0\),

\[\displaystyle d_i\geq0,\qquad \sum_i d_i\leq(1-p)\delta b^2.\tag{5}\]

Also,

\(\displaystyle \sum_i z_iS_i=pQ(z)+\sum_{i,j}A_{ji}z_i d_j,\)

where the final term lies between zero and \(b\sum_jd_j\).

Using

\(\displaystyle t-\frac{t^2}{2}\leq1-e^{-t}\leq t\qquad(t\geq0),\)

we obtain

\(\displaystyle G\geq pb+c\delta Q(z)-\frac{1-p}{2}\delta^2b^3,\)

and, by (5),

\(\displaystyle G\leq pb+c\delta Q(z)+(1-p)^2\delta^2b^3.\)

Consequently, every feasible allocation satisfies

\[\displaystyle |G(x,y)-H(z)|\leq E,\qquad E:=2\delta^2\kappa^3.\tag{6}\]

This bound includes allocations spending some budget on the source type.

5. The graph quadratic form and the gap

Let \(\omega\) be the clique number of \(H\). The ordered-edge version of the [Motzkin–Straus theorem](https://doi.org/10.4153/CJM-1965-053-6) is

\[\displaystyle \max_{\substack{z_i\geq0\\\sum_i z_i=b}}Q(z)=b^2\left(1-\frac1\omega\right).\tag{7}\]

For completeness, its short proof is as follows. If two positive coordinates correspond to nonadjacent vertices, keep their sum fixed and move all their mass to whichever vertex has the larger weighted neighbor sum. Since they are nonadjacent, the objective depends linearly on this redistribution, so it does not decrease. Repeating leaves a clique-supported vector. On a clique of size \(r\leq\omega\),

\(\displaystyle Q(z)=b^2-\sum_i z_i^2\leq b^2\left(1-\frac1r\right)\leq b^2\left(1-\frac1\omega\right).\)

Equality is attained by uniform mass on a maximum clique.

Define

\(\displaystyle Y=p\kappa+c\delta\kappa^2\left(1-\frac1k\right),\)

\(\displaystyle U=p\kappa+c\delta\kappa^2\left(1-\frac1{k-1}\right).\)

If \(H\) contains a \(k\)-clique, allocate mass \(\kappa/k\) to each of its vertices and zero elsewhere. This is feasible because \(\kappa/k\leq\kappa<1/(2n)\). It has \(H(z)=Y\), and therefore

\[\displaystyle \mathrm{OPT}\geq Y-E.\tag{8}\]

If \(H\) has no \(k\)-clique, then \(\omega\leq k-1\). Equation (7), together with \(b\leq\kappa\), gives \(H(z)\leq U\) for every feasible allocation. Thus

\[\displaystyle \mathrm{OPT}\leq U+E.\tag{9}\]

The separation before diffusion error is

\(\displaystyle D:=Y-U=\frac{c\delta\kappa^2}{k(k-1)}.\)

Since \(2<e<3\), we have \(e^{-1}>1/3\) and \(1-e^{-1}>1/2\), so \(c>1/8\). Define the dyadic number

\(\displaystyle D_0=\frac{\delta\kappa^2}{8n^2}=\frac1{8192n^5}.\)

Because \(k(k-1)\leq n^2\),

\[\displaystyle D\geq D_0.\tag{10}\]

Our parameter choices also give

\[\displaystyle E=2\delta^2\kappa^3=\frac{D_0}{16}.\tag{11}\]

Thus the diffusion error is uniformly smaller than the clique gap.

6. Exact decision hardness with a rational threshold

Let

\(\displaystyle M=\frac{Y+U}{2},\qquad \eta=\frac{D_0}{16}.\)

Compute a dyadic rational \(h\) satisfying

\[\displaystyle |h-M|\leq\eta.\tag{12}\]

This computation takes polynomial time. In particular, the alternating series for \(e^{-1}\), truncated after \(T\) terms, has error at most \(1/(T+1)!\). Taking \(T\) proportional to \(\log n\) provides the required precision. The intermediate rational numbers have polynomial bit length, and subsequent dyadic rounding preserves the desired error.

For a YES instance, equations (8), (10)–(12) imply

\(\displaystyle \mathrm{OPT}-h\geq\frac D2-E-\eta\geq\frac{3D_0}{8}>0.\)

For a NO instance, equations (9)–(12) imply

\(\displaystyle h-\mathrm{OPT}\geq\frac D2-E-\eta\geq\frac{3D_0}{8}>0.\)

Therefore

\(\displaystyle H\text{ contains a clique of size at least }k\quad\Longleftrightarrow\quad\mathrm{OPT}\geq h.\)

There are \(\tau=n+1\) types. All society parameters have bit length bounded by a polynomial in the graph input length; indeed, each contact and mass parameter has bit length proportional to \(\log n\). The threshold also has polynomial bit length. Section 3 verified the limit promise throughout the constructed family.

This is a polynomial-time many-one reduction, proving exact-decision \(\mathrm{NP}\)-hardness.

7. Hardness of the requested additive approximation

Suppose an algorithm always returns a feasible rational allocation satisfying

\(\displaystyle G(x,y)\geq\mathrm{OPT}-\varepsilon,\)

in time polynomial in \(m,\tau,L,1/\varepsilon\).

Apply it to the constructed instance with

\[\displaystyle \varepsilon=\frac{D_0}{8}=\frac1{65536n^5}.\tag{13}\]

This gives polynomial running time in the original graph size, since \(m=2\), \(\tau=n+1\), \(L\) is polynomially bounded, and \(1/\varepsilon=65536n^5\).

For the returned rational vector \(z\), compute a rational approximation \(\widehat H\) to \(H(z)\) with

\(\displaystyle |\widehat H-H(z)|\leq\eta.\)

This is polynomial-time rational arithmetic plus approximation of the fixed constants \(p\) and \(c\); it does not require evaluating the cascade objective.

In a YES instance, (6), (8), and the approximation guarantee give

\(\displaystyle H(z)\geq G(x,y)-E\geq Y-2E-\varepsilon.\)

Consequently,

\(\displaystyle \widehat H-h\geq\frac D2-2E-\varepsilon-2\eta\geq\frac{D_0}{8}>0.\)

In a NO instance, every feasible allocation has \(H(z)\leq U\), so

\(\displaystyle \widehat H-h\leq-\frac D2+2\eta\leq-\frac{3D_0}{8}<0.\)

Comparing \(\widehat H\) with \(h\) therefore decides CLIQUE in polynomial time.

Hence the additive approximation task is \(\mathrm{NP}\)-hard under a polynomial-time reduction making one call to the search procedure. In particular, the proposed running-time bound is impossible unless \(\mathrm P=\mathrm{NP}\). This establishes hardness for inverse-polynomial \(\varepsilon\); constant-error hardness is not needed for the requested conclusion.
