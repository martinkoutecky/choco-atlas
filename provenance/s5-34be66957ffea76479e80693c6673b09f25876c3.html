The continuous mirror question, as graded

Given a finite support \(T\) of \(\tau\) piecewise-uniform preference types over \([0,1]\), rational masses \(\mu_t>0\) summing to \(1\), rational per-capita supply \(\rho\), and evaluation and cut oracles for each type, determine the minimum worst-case number of type-oracle queries needed to decide whether a finite-menu envy-free assignment exists and output one when it does. The assignment gives fractions \(\pi_t(B)\) of each type mass bundles \(B\), with \(\sum_B\pi_t(B)=1\); every assigned bundle must be weakly preferred by its recipients to every bundle assigned to anyone else, and the supply constraint must hold with equality, \(\sum_{t\in T}\mu_t\sum_B\pi_t(B)\mathbf{1}_{x\in B}=\rho\) almost everywhere.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has utility \(u_t(B)=|B\cap P_t|/|P_t|\), where \(P_t\subseteq[0,1]\) is a finite union of intervals with rational endpoints and \(|P_t|>0\); bars denote Lebesgue length. Utilities are accessible only through exact Robertson–Webb evaluation and cut queries; cuts return the leftmost valid endpoint, or report impossibility.
The input includes rational supply \(0<\rho\leq1\) and bounds \(m\) on the total number of preference intervals and \(L\) on the total binary description length of masses, supply, and hidden preference endpoints. The preference endpoints themselves are not disclosed. State query bounds and running times in \(m,\tau,L,\rho\).
An output consists of a finite menu \(\mathcal B\) of bundles, each a finite union of intervals with rational endpoints, and rational fractions \(\pi_t(B)\geq0\) satisfying \(\sum_{B\in\mathcal B}\pi_t(B)=1\). Menu bundles may overlap; the fractions describe subdivision of type mass.
Envy-freeness requires \(u_t(B)\geq u_t(C)\) whenever \(\pi_t(B)>0\) and \(\pi_s(C)>0\), for every pair of types \(t,s\). Full supply use requires \(\sum_t\mu_t\sum_{B\in\mathcal B}\pi_t(B)\mathbf1_B(x)=\rho\) almost everywhere.
What is the asymptotically optimal worst-case number of type-oracle queries for deterministic exact algorithms that decide existence and output such an assignment when one exists? Is this query complexity polynomially bounded in \(m,\tau,L\), or necessarily superpolynomial?
For finitely many agents, complete envy-free Robertson–Webb allocation requires \(\Omega(n^2)\) queries ([Procaccia, 2009](https://www.ijcai.org/Proceedings/09/Papers/049.pdf)); bounded piecewise complexity admits a polynomial query upper bound ([Kurokawa, Lai, and Procaccia, 2013](https://www.cs.umd.edu/~gasarch/TOPICS/cake/envyfreebounded.pdf)).
These results concern finite-agent allocations; no result settling the exact mass-assignment problem above was verified.

Modeling choices made when packaging the task

  • Normalized piecewise-uniform utility by the positive length of the valued region and required rational preference endpoints, following the discrete preference domain.
  • Restricted supply to positive rationals at most one, excluding zero supply while retaining the full domain compatible with individual bundles.
  • Defined m as a bound on the total number of preference intervals and L as a bound on the combined binary description length, including hidden preference endpoints; these bounds are supplied without revealing preferences.
  • Used deterministic exact algorithms, counted both permitted query types equally, and fixed leftmost cut responses to resolve indifference on zero-density intervals.
  • Required a finite rational representation of output bundles and mass fractions.
  • Allowed overlapping menu bundles, with feasibility governed by the stated mass-weighted supply equality.

Result

Under the stated model, the optimal worst-case number of type-oracle queries is exactly \(0\). Every admissible instance has an assignment.

The reason is that the known description-length bound permits a universal construction with exponentially many intervals. To address the computationally more informative interpretation, I also prove an \(O(m(L+1)+\tau)\)-query construction that avoids enumerating possible endpoints. Its running time depends on the output size, which can necessarily be exponential in \(L\).

Throughout, rational numbers have the usual binary numerator–denominator encoding. Write the supply in lowest terms as \(\rho=p/q\), where \(1\leq p\leq q\). Put \(Q=2^L\). Every hidden endpoint has reduced denominator at most \(Q\), and \(q\leq Q\).

1. A balanced-menu construction

First suppose a rational partition

\(\displaystyle 0=a_0<a_1<\cdots<a_K=1\)

contains every preference endpoint. Thus, up to endpoints of measure zero, every preference set \(P_t\) is a union of partition cells.

For each cell \(I_i=[a_{i-1},a_i)\), divide it into \(q\) equal subcells:

\(\displaystyle I_{i,h}=\left[a_{i-1}+\frac{h}{q}(a_i-a_{i-1}),\,a_{i-1}+\frac{h+1}{q}(a_i-a_{i-1})\right),\qquad 0\leq h<q.\)

For \(0\leq j<q\), define

\(\displaystyle B_j=\bigcup_{i=1}^{K}\ \bigcup_{\substack{0\leq h<q\\(h-j)\bmod q\in\{0,\ldots,p-1\}}}I_{i,h}.\)

Set \(\pi_t(B_j)=1/q\) for every type \(t\). Choices about including endpoints do not affect any requirement.

Equal utilities. Each \(B_j\) occupies exactly a fraction \(p/q\) of every partition cell. Since \(P_t\) is a union of these cells,

\(\displaystyle |B_j\cap P_t|=\frac pq|P_t|,\qquad u_t(B_j)=\rho.\)

Consequently, every type is indifferent between all menu bundles, proving envy-freeness.

Full supply use. Every subcell belongs to exactly \(p\) bundles: for fixed \(h\), precisely \(p\) indices \(j\) satisfy the defining modular condition. Therefore, almost everywhere,

\(\displaystyle \sum_t\mu_t\sum_{j=0}^{q-1}\pi_t(B_j)\mathbf1_{B_j}(x)=\left(\sum_t\mu_t\right)\frac pq=\rho.\)

The fractions are rational and sum to one for each type.

Within each cell, the selected subcells form a cyclic block, expressible as at most two ordinary intervals. Hence the construction needs at most \(2Kq\) interval records and \(\tau q\) fraction records.

When \(\rho=1\), simply use the single bundle \([0,1]\).

2. The optimal query bound is zero

Construct the finite set

\(\displaystyle E_Q=\left\{\frac ab:1\leq b\leq Q,\ 0\leq a\leq b\right\},\)

remove duplicates, and sort it. It contains every possible hidden preference endpoint, because each such endpoint has reduced denominator at most \(Q\).

Apply Section 1 to the partition formed by consecutive elements of \(E_Q\). This uses only the disclosed bound \(L\), supply, and type list. It makes no evaluation or cut queries.

There are \(O(Q^2)\) partition cells. Sorting the candidates and writing the assignment takes time bounded by

\(\displaystyle O\!\left((Q^2L+qQ^2+\tau q)\operatorname{poly}(L)\right)=2^{O(L)}\operatorname{poly}(\tau,L).\)

All generated endpoints have \(O(L)\) bits: they are obtained from two candidate endpoints by rational interpolation with denominator \(q\).

This proves existence and gives a deterministic exact zero-query algorithm. Since query counts are nonnegative, zero is also the matching lower bound.

Thus the query complexity is polynomially bounded—in fact, identically zero. The exponential cost of this construction lies in computation and output.

3. A polynomial-query construction using the actual endpoints

The preceding construction is deliberately large. The following reconstruction procedure uses \(O(m(L+1)+\tau)\) queries and polynomial computation before generating the menu.

Fix a type. Merge overlapping or touching preference intervals and discard intervals of zero length. Write its positive-length components as

\(\displaystyle P=\bigcup_{r=1}^{k}[a_r,b_r],\qquad b_r<a_{r+1},\qquad S=|P|.\)

All endpoints still have denominator at most \(Q\). Two distinct reduced rationals with denominators at most \(Q\) differ by at least

\(\displaystyle \delta=Q^{-2},\)

because their difference has a nonzero integer numerator over a denominator at most \(Q^2\). In particular, every component has length at least \(\delta\).

Recovering the normalization and first left endpoint

Let \(\varepsilon=\delta/4\), and ask

\(\displaystyle z_1=\operatorname{Cut}(0,\varepsilon),\qquad z_2=\operatorname{Cut}(0,2\varepsilon).\)

Both answers lie strictly inside the first component. Indeed, its normalized utility is at least \(\delta/S\geq\delta>2\varepsilon\), since \(S\leq1\).

Uniform density on that component gives

\(\displaystyle z_1=a_1+\varepsilon S,\qquad z_2=a_1+2\varepsilon S.\)

Therefore,

\(\displaystyle S=\frac{z_2-z_1}{\varepsilon},\qquad a_1=z_1-\varepsilon S.\)

These are exact rational computations.

Recovering a component’s right endpoint

Suppose its left endpoint \(a\) is known, and its right endpoint is \(b\). For \(x\in[a,1]\),

\(\displaystyle \operatorname{Eval}(a,x)=\frac{x-a}{S}\quad\Longleftrightarrow\quad x\leq b.\)

For \(x\leq b\), the entire interval is preferred. If \(b<1\) and \(x>b\), a positive-length part immediately after \(b\) is unpreferred; since density nowhere exceeds \(1/S\), the displayed equality fails.

One evaluation at \(1\) detects whether \(b=1\). Otherwise, \(2L+2\) bisection evaluations produce a closed bracket containing \(b\), of width at most

\(\displaystyle 2^{-2L-2}=\frac{1}{4Q^2}.\)

The bracket contains exactly one rational with denominator at most \(Q\): two such rationals would be separated by at least \(Q^{-2}\).

This rational can be recovered in polynomial time using continued fractions. Specifically, if \(r\) is the bracket midpoint and \(b=c/d\) in lowest terms, then

\(\displaystyle |r-b|\leq\frac{1}{8Q^2}<\frac{1}{2d^2}.\)

Legendre’s continued-fraction criterion therefore makes \(b\) a convergent of \(r\); enumerate the convergents and select the unique one in the bracket with denominator at most \(Q\). This criterion applies to real \(r\), including rational \(r\). See the [formal statement and proof in Mathlib](https://leanprover-community.github.io/mathlib4_docs/Mathlib/NumberTheory/DiophantineApproximation/ContinuedFractions.html). The Euclidean algorithm computes the convergents in polynomial bit time.

Moving to the next component

After finding \(b\), ask \(\operatorname{Cut}(b,\varepsilon)\).

If another component exists, its utility is at least \(\delta>\varepsilon\). Thus the query succeeds, skips the intervening gap, and returns

\(\displaystyle z=a_{\mathrm{next}}+\varepsilon S.\)

Recover \(a_{\mathrm{next}}=z-\varepsilon S\) and repeat. If no component remains, the query reports impossibility.

There are two initial queries and at most \(2L+4\) queries per component. Summing over types gives at most

\(\displaystyle (2L+4)m+2\tau\)

queries. All query arguments, answers, and reconstruction computations have bit length polynomial in \(m,\tau,L\), so reconstruction takes polynomial time.

Finally, sort the recovered endpoints together with \(0,1\). There are at most \(2m+1\) cells. Applying Section 1 gives total running time

\(\displaystyle \operatorname{poly}(m,\tau,L)+q(m+\tau)\operatorname{poly}(L).\)

The dependence on \(q\) is explicit; since \(q\leq2^L\), this is an exponential worst-case time bound.

4. Exponential output size can be necessary

Here is an obstruction applying to every valid assignment, regardless of its query strategy.

Discard unused menu bundles and define the global mass receiving bundle \(B\) by

\(\displaystyle w_B=\sum_t\mu_t\pi_t(B)>0.\)

Then \(\sum_Bw_B=1\).

Every used bundle has positive Lebesgue length. Suppose instead that a type \(t\) receives a null bundle with positive fraction. Its utility is zero. Envy-freeness forces \(u_t(C)=0\) for every used bundle \(C\). But integrating full supply use against \(\mathbf1_{P_t}/|P_t|\) gives

\(\displaystyle \sum_Cw_Cu_t(C)=\rho>0,\)

a contradiction.

On a positive-length used bundle \(B\), the supply equation implies \(w_B\leq\rho\), because its contribution alone is \(w_B\). Consequently,

\(\displaystyle 1=\sum_Bw_B\leq|\mathcal B|\rho,\qquad |\mathcal B|\geq\left\lceil\frac1\rho\right\rceil.\)

Take one type with \(P=[0,1]\), mass one, and supply \(\rho=2^{-k}\). Here \(m=\tau=1\) and \(L=O(k)\), yet every valid assignment has at least \(2^k\) used bundles.

Therefore, with the explicit output format in the question, no algorithm can have running time polynomial in \(m,\tau,L\) on all instances. This is an output-size obstruction, compatible with zero query complexity.

5. Scope of the conclusion

The [finite-agent lower bound of Procaccia](https://www.ijcai.org/Proceedings/09/Papers/049.pdf) concerns complete allocations to individual agents. The [bounded-complexity result of Kurokawa, Lai, and Procaccia](https://www.cs.umd.edu/~gasarch/TOPICS/cake/envyfreebounded.pdf) also concerns finite-agent allocations. Neither is needed here: subdivision of type mass permits every type to receive the same balanced distribution over overlapping bundles.

For the stated task, existence is unconditional, optimal query complexity is zero, and polynomial total running time is impossible in the worst case under explicit output.
