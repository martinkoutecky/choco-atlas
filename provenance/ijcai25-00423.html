The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) with \(\sum_t\mu_t=1\), compact scalar action intervals \(X_t\), contexts \(s^1,\ldots,s^N\), observed type-level equilibrium profiles \(\hat a^j\), and utilities \(U_t(a_t,z,s;\theta_t)=\langle\theta_t,\phi_t(a_t,z,s)\rangle\) with \(z^j=\sum_t\mu_t\hat a_t^j\), output an ε-optimal angular incenter of \(\mathcal C_\mu=\{\vartheta:\sum_t\mu_t\langle\theta_t,\partial_{a_t}\phi_t(\hat a_t^j,z^j,s^j)\rangle(a_t-\hat a_t^j)\le0\ \forall a\in\prod_tX_t,\ \forall j\}\), or minimize the corresponding regularized violation loss when \(\mathcal C_\mu\) is inconsistent.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Input consists of nonempty compact scalar intervals \(X_t=[l_t,u_t]\), \(N\ge1\) public contexts \(s^j\), observed profiles \(\hat a^j\in X:=\prod_tX_t\), and explicit feature-gradient vectors \(g_t^j=\partial_{a_t}\phi_t(\hat a_t^j,z^j,s^j)\in\mathbb Q^m\), where \(z^j=\sum_t\mu_t\hat a_t^j\); all numerical input is binary rational, of total bit length \(L\).
Utilities have the form \(U_t(a_t,z,s;\theta_t)=\langle\theta_t,\phi_t(a_t,z,s)\rangle\), with unrestricted \(\theta_t\in\mathbb R^m\); differentiation holds \(z\) fixed because individual agents are nonatomic. Equilibrium interpretation assumes continuous differentiability and pseudo-concavity in own action; consistency below is defined solely by the supplied gradients.
For \(\vartheta=(\theta_t)_{t\in T}\in\mathbb R^{m\tau}\), define \(b^j(a)=(\mu_tg_t^j(a_t-\hat a_t^j))_{t\in T}\) and \(\mathcal C_\mu=\{\vartheta:\langle\vartheta,b^j(a)\rangle\le0\text{ for every }a\in X,\ j\in\{1,\ldots,N\}\}\). Assume some \(b^j(a)\ne0\), excluding the unconstrained full-space case.
For nonzero \(v\in\mathcal C_\mu\), its angular radius is \(\rho(v)=\inf\{\arccos(\langle v,w\rangle/(\|v\|_2\|w\|_2)):0\ne w\notin\operatorname{int}(\mathcal C_\mu)\}\), using ordinary Euclidean geometry on the concatenated parameter vector.
Given binary-rational \(0<\varepsilon<1\), when \(\mathcal C_\mu\ne\{0\}\), compute a nonzero rational direction \(v\in\mathcal C_\mu\) whose angular radius is within additive \(\varepsilon\) of the supremum; this definition also covers cones with empty interior.
When \(\mathcal C_\mu=\{0\}\), instead compute an additive \(\varepsilon\)-minimizer over \(\mathbb R^{m\tau}\) of \(F(\vartheta)=N^{-1}\sum_{j=1}^N\max_{a\in X}\{\langle\vartheta,b^j(a)\rangle+\|b^j(a)\|_2\}+\alpha\|\vartheta\|_2\), where binary-rational \(\alpha>0\) is input.

For each branch of this mass-based inverse-game problem, is computation polynomial in \(m,\tau,N,L,\log(1/\varepsilon)\), or is it NP-hard?

For finitely many players, the angular incenter of the consistency cone with nonempty interior admits a minimum-Euclidean-norm convex reformulation; this is a characterization, not a polynomial-time complexity theorem. [Cui et al.](https://www.ijcai.org/proceedings/2025/0423.pdf)
Related inverse optimization establishes tractability of an incenter formulation for explicitly enumerated finite action sets. [Zattoni Scroccaro et al.](https://optimization-online.org/wp-content/uploads/2023/05/arXiv_version.pdf) No result settling this exact mass-based problem was found in the search.

| Branch | Complexity |

| \(\mathcal C_\mu=\{0\}\): compute an additive minimizer of \(F\) | \(\mathrm{NP}\)-hard, even with \(m=1\) and \(\alpha=1\) |

Determining which branch applies is itself polynomial-time solvable. The hardness proof below concerns computing a minimizer, rather than merely evaluating the inner maximization.

2. The consistency cone has a polynomial-size description

Write \(d=m\tau\). For each type \(t\), let \(E_tg\in\mathbb R^d\) denote the vector with \(g\) in block \(t\) and zero in every other block.

Construct a list of nonzero rational normals as follows:

  • Include \(E_tg_t^j\) whenever \(\hat a_t^j<u_t\) and \(g_t^j\ne0\).
  • Include \(-E_tg_t^j\) whenever \(l_t<\hat a_t^j\) and \(g_t^j\ne0\).

Denote these normals by \(h_1,\ldots,h_K\), where \(K\le2\tau N\).

Proven claim. The cone is exactly

\(\displaystyle \mathcal C_\mu=\{v\in\mathbb R^d:\langle h_i,v\rangle\le0\text{ for }i=1,\ldots,K\}.\)

For necessity, fix an observation and change only one type’s action. An upward change gives the inequality associated with \(E_tg_t^j\), and a downward change gives the inequality associated with its negative. The factors \(\mu_t\) and the absolute size of the change are positive, so they can be divided out.

Conversely, these inequalities imply, for every feasible displacement,

\(\displaystyle \mu_t\langle\theta_t,g_t^j\rangle(a_t-\hat a_t^j)\le0.\)

Summing over types proves every defining inequality of \(\mathcal C_\mu\).

The assumption that some \(b^j(a)\ne0\) guarantees \(K\ge1\). In particular, positive masses do not affect the consistency cone.

Two elementary linear-programming tests suffice for the relevant degeneracies:

  • The cone has nonempty interior exactly when the system \(\langle h_i,p\rangle\le-1\) for all \(i\) is feasible. Indeed, strict feasibility can be scaled to this system.
  • The cone contains a nonzero vector exactly when, for some coordinate \(k\) and sign \(\sigma\in\{-1,1\}\), the system

\(\langle h_i,v\rangle\le0\), \(\sigma v_k\ge1\)
is feasible.

These are polynomially many rational linear programs. Feasible instances yield rational witnesses of polynomial encoding length.

3. Polynomial-time computation in the angular branch

3.1. Empty interior and dimension one

If \(\mathcal C_\mu\ne\{0\}\) has empty interior, every nonzero \(v\in\mathcal C_\mu\) satisfies \(\rho(v)=0\): the choice \(w=v\) is allowed in the defining infimum. Thus any nonzero rational feasible witness is optimal.

There is also a one-dimensional exception to the usual incenter formula. If \(d=1\), a nonzero consistency cone is a half-line, because the full-space case is excluded. Its angular radius is \(\pi\): every nonzero vector outside its interior points in the opposite direction. A rational generator therefore solves this case exactly.

Henceforth assume \(d\ge2\) and \(\operatorname{int}(\mathcal C_\mu)\ne\varnothing\).

3.2. Angular radius equals a normalized margin

For a unit vector \(u\in\mathcal C_\mu\), define

\(\displaystyle r(u)=\min_{1\le i\le K}\frac{-\langle h_i,u\rangle}{\|h_i\|_2}.\)

Then

\(\displaystyle \rho(u)=\arcsin r(u).\)

To justify this, the complement of the interior is the union of the closed halfspaces \(\{w:\langle h_i,w\rangle\ge0\}\). For each such halfspace, its nearest nonzero direction to \(u\) lies in the corresponding orthogonal hyperplane. The angular distance is

\(\displaystyle \arcsin\!\left(\frac{-\langle h_i,u\rangle}{\|h_i\|_2}\right).\)

This remains valid when \(u\) is parallel to \(-h_i\), since \(d\ge2\) supplies a nonzero orthogonal direction. Taking the minimum proves the formula.

Let

\(\displaystyle r_*=\max_{\substack{u\in\mathcal C_\mu\\\|u\|_2=1}}r(u).\)

Compactness gives attainment, and nonempty interior gives \(r_*>0\). The optimal angular radius is therefore \(\rho_*=\arcsin r_*\).

Consider the auxiliary problem

\(\displaystyle R_*=\min\{\|x\|_2:-\langle h_i,x\rangle\ge\|h_i\|_2\text{ for every }i\}.\)

It is feasible by scaling an interior vector, and its minimum exists because the objective is coercive. Moreover,

\(\displaystyle R_*=\frac1{r_*}.\)

Indeed, a unit vector with margin \(r_*\) becomes feasible after division by \(r_*\). Conversely, normalizing any feasible \(x\) gives margin at least \(1/\|x\|_2\).

3.3. A rational quadratic program gives the required approximation

Set \(\delta=\varepsilon^2/4\). Compute positive rational numbers \(q_i\) satisfying

\(\displaystyle \|h_i\|_2\le q_i\le(1+\delta)\|h_i\|_2.\)

These upper approximations are computable in polynomial time by rational square-root approximation. Because every \(h_i\) is nonzero and rational, the magnitudes and required precision have polynomial encoding length.

Solve the rational convex quadratic program

\(\displaystyle \min_x\|x\|_2^2\quad\text{subject to}\quad-\langle h_i,x\rangle\ge q_i\quad(i=1,\ldots,K).\)

The standard rational convex quadratic-programming theorem gives an exact rational optimizer in polynomial time. Its hypotheses hold here: all data are rational, the Hessian is positive definite, the feasible set is nonempty, and the minimum is attained. See [Kozlov, Tarasov and Khachiyan, *Polynomial solvability of convex quadratic programming*](https://www.mathnet.ru/eng/dan43059).

Let \(v\) be this optimizer. It is nonzero and belongs to \(\mathcal C_\mu\). If \(x_*\) solves the auxiliary problem defining \(R_*\), then \((1+\delta)x_*\) is feasible for the rational program. Consequently,

\(\displaystyle \|v\|_2\le(1+\delta)R_*,\qquad r\!\left(\frac v{\|v\|_2}\right)\ge\frac1{\|v\|_2}\ge\frac{r_*}{1+\delta}.\)

For \(0\le b\le a\le1\),

\(\displaystyle \arcsin a-\arcsin b =\int_b^a\frac{dt}{\sqrt{1-t^2}} \le2\bigl(\sqrt{1-b}-\sqrt{1-a}\bigr) \le2\sqrt{a-b}.\)

Since \(r_*-r_*/(1+\delta)\le\delta\), this gives

\(\displaystyle 0\le\rho_*-\rho(v)\le2\sqrt{\delta}=\varepsilon.\)

The program has \(d=m\tau\) variables, at most \(2\tau N\) constraints, and encoding length polynomial in \(L+\log(1/\varepsilon)\). This proves the requested polynomial-time bound.

4. Hardness of computing a fallback minimizer

First, the fallback problem is well posed. Choosing \(a=\hat a^j\) makes each inner maximum nonnegative, so \(F(\vartheta)\ge\alpha\|\vartheta\|_2\). The function is continuous and coercive, hence attains its minimum.

We now give a polynomial-time reduction from positive-integer SUBSET SUM, a standard \(\mathrm{NP}\)-complete problem; see [Karp’s original paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf). We may restrict to instances

\(\displaystyle w_1,\ldots,w_n\in\mathbb Z_{\ge2},\qquad 0<B<W:=\sum_{i=1}^n w_i.\)

Indeed, targets outside the nontrivial range are directly decidable, and multiplying all weights and the target by two ensures \(w_i\ge2\).

The construction will use \(m=1\), \(\tau=n+1\), \(N=n+2\), and \(\alpha=1\).

4.1. A subset-sum maximum with a quantitative gap

Define

\(\displaystyle p_i=\frac{w_i-1}{2},\quad q_i=\frac{w_i+1}{2},\quad C=\sum_i p_i^2,\quad P=\sum_i p_i,\quad D=C+B.\)

The identity \(q_i^2-p_i^2=w_i\) will encode subset sums. Also,

\(\displaystyle C+W=\sum_iq_i^2\le\sum_iw_i^2\le W^2.\)

Choose a dyadic rational \(\lambda\) satisfying

\(\displaystyle \left|\lambda-\frac1{2\sqrt D}\right|\le\frac1{64W^4}.\)

It can be computed in polynomial time. Since \(D\ge2\) and \(D\le W^2\), it satisfies

\(\displaystyle \frac1{4W}\le\lambda<\frac12.\)

Let

\(\displaystyle f(s)=\sqrt{C+s}-\lambda s,\qquad t=f(B),\qquad \Delta=\frac1{16W^3},\)

and let

\(\displaystyle f_{\max}=\max_{S\subseteq\{1,\ldots,n\}}f\!\left(\sum_{i\in S}w_i\right).\)

We claim:

  • If the SUBSET SUM instance is a yes-instance, then \(f_{\max}=t\).
  • If it is a no-instance, then \(f_{\max}\le t-\Delta\).

For the proof, put \(\lambda_*=1/(2\sqrt D)\). On \(0\le s\le W\),

\(\displaystyle \frac{d^2}{ds^2}\sqrt{C+s}=-\frac1{4(C+s)^{3/2}}\le-\frac1{4W^3}.\)

Taylor’s inequality around \(B\) therefore gives

\(\displaystyle f(s)\le f(B)+(\lambda_*-\lambda)(s-B)-\frac{(s-B)^2}{8W^3}.\)

For any integer \(s\ne B\), we have \(|s-B|\ge1\) and \(|s-B|\le W\). Thus

\(\displaystyle f(s)\le t+\frac1{64W^3}-\frac1{8W^3} =t-\frac7{64W^3}\le t-\Delta.\)

An attainable sum \(B\) gives value exactly \(t\), proving both claims.

4.2. Constructing a valid inverse-game instance

Index the types by \(0,1,\ldots,n\), and denote their scalar parameters by \(x,\theta_1,\ldots,\theta_n\). Set

\(\displaystyle X_0=[0,1],\qquad X_i=[0,w_i]\quad(i=1,\ldots,n).\)

Choose positive dyadic masses

\(\displaystyle \mu_i=2^{-i}\quad(i=1,\ldots,n),\qquad \mu_0=2^{-n}.\)

Their sum is one.

For convenience, specify effective gradients \(\mu_tg_t^j\). Dividing by the chosen masses gives explicit rational gradients. Define

\(\displaystyle R=8(W+N)^2,\qquad S=8(W+N+1),\qquad K_i=\frac{Sw_i}{2}=4(W+N+1)w_i.\)

Use the following \(N=n+2\) observations:

  • One principal observation.

For type \(i\ge1\), set \(\hat a_i=p_i\) and effective gradient \(1\). For type \(0\), set \(\hat a_0=0\) and effective gradient \(R\). Its deviation vectors fill
\(\prod_i[-p_i,q_i]\times[0,R]\).

  • One observation for each \(i\ge1\).

Only type \(i\) has nonzero effective gradient, namely \(S\), and its observed action is
\(\hat a_i=(1-\lambda)w_i/2\).
Its nonzero deviation coordinate ranges over
\([-K_i(1-\lambda),K_i(1+\lambda)]\).

  • One final observation.

Only type \(0\) has nonzero effective gradient, namely \(R/2\), and its observed action is \(1\). Its deviation coordinate ranges over \([-R/2,0]\).

Inactive observed coordinates may be zero. Contexts may be any distinct rational labels. All observations belong to their prescribed intervals.

This construction has polynomial encoding length; indeed, every numerical input can be chosen dyadic.

The constructed cone is exactly \(\{0\}\). Each observation in item 2 has a nonzero gradient and an observed action strictly inside its interval. Its consistency inequalities force \(\theta_i=0\). The principal observation forces \(x\le0\), while the final observation forces \(x\ge0\). Hence all parameters vanish.

4.3. Writing the constructed loss explicitly

Let \(\theta=(\theta_1,\ldots,\theta_n)\), and define

\(\displaystyle H(\theta,x)= \max_{\substack{b_i\in[-p_i,q_i]\\0\le y\le R}} \left\{\sum_i\theta_i b_i+xy+\sqrt{\sum_i b_i^2+y^2}\right\}.\)

The individual observations contribute

\(\displaystyle H_i(\theta_i)= \max\{K_i(1-\lambda)(1-\theta_i),\,K_i(1+\lambda)(1+\theta_i)\},\)

and

\(\displaystyle H_{\mathrm{lin}}(x)=\frac R2\max\{0,1-x\}.\)

These formulas follow by maximizing a convex function over an interval at its endpoints.

Since \(\alpha=1\), multiplying the objective by \(N\) gives

\(\displaystyle G(\theta,x):=NF(\theta,x) =H(\theta,x)+\sum_iH_i(\theta_i)+H_{\mathrm{lin}}(x) +N\sqrt{\|\theta\|_2^2+x^2}.\)

4.4. The additional observations pin the weight coordinates

Set \(\bar\theta_i=-\lambda\) for every \(i\).

The two affine pieces defining \(H_i\) intersect at \(-\lambda\), with slopes \(-K_i(1-\lambda)\) and \(K_i(1+\lambda)\). Consequently,

\(\displaystyle H_i(\theta_i)-H_i(-\lambda) \ge K_i(1-\lambda)|\theta_i+\lambda| \ge2(W+N+1)w_i|\theta_i+\lambda|.\)

Furthermore, because \(|b_i|\le q_i\le w_i\),

\(\displaystyle |H(\theta,x)-H(\bar\theta,x)| \le\sum_iw_i|\theta_i+\lambda|.\)

The norm term satisfies

\(\displaystyle N\sqrt{\|\theta\|_2^2+x^2} -N\sqrt{\|\bar\theta\|_2^2+x^2} \ge-N\sum_i|\theta_i+\lambda|.\)

Combining these inequalities yields, for every \((\theta,x)\),

\(\displaystyle G(\theta,x)\ge G(\bar\theta,x)+\sum_i|\theta_i+\lambda|.\)

Here each coefficient is at least one, because

\(\displaystyle 2(W+N+1)w_i-w_i-N\ge1.\)

Thus every exact minimizer has \(\theta=\bar\theta\). The inequality also controls approximate minimizers.

4.5. The remaining minimizing coordinate reveals \(f_{\max}\)

For fixed \(\bar\theta\), convexity in \(y\) gives

\(\displaystyle H(\bar\theta,x)=\max\{H_0,H_R+Rx\},\)

where

\(\displaystyle H_0=\max_{b_i\in[-p_i,q_i]} \left\{-\lambda\sum_i b_i+\sqrt{\sum_i b_i^2}\right\},\)

and \(H_R\) is the analogous maximum with \(R^2\) added under the square root.

Both maxima occur at box vertices: every box point is a convex combination of vertices, and convexity bounds its value by the maximum vertex value.

Write a vertex as \(b_i=-p_i+w_i z_i\), where \(z_i\in\{0,1\}\), and put \(s=\sum_iw_i z_i\). Then

\(\displaystyle \sum_i b_i=-P+s,\qquad \sum_i b_i^2=C+s.\)

It follows that

\(\displaystyle H_0=\lambda P+f_{\max}.\)

For the other maximum, the scalar function

\(\displaystyle \sqrt{C+R^2+s}-\lambda s\)

is strictly decreasing on \([0,W]\), since its derivative is at most \(1/(2R)-\lambda<0\). Hence its maximum occurs at the empty subset, and

\(\displaystyle H_R=\lambda P+\sqrt{C+R^2}.\)

The two pieces of \(H(\bar\theta,x)\) intersect at

\(\displaystyle x_*=\frac{H_0-H_R}{R} =\frac{f_{\max}-\sqrt{C+R^2}}{R}.\)

This point lies in \((-1,0)\). Indeed, \(f_{\max}\le W<R\), giving \(x_*<0\). Also \(f_{\max}\ge\sqrt C\) and \(\sqrt{C+R^2}<R+\sqrt C\), giving \(x_*>-1\).

Define the unregularized scalar objective

\(\displaystyle J(x)=\max\{H_0,H_R+Rx\}+\frac R2\max\{0,1-x\}.\)

Its slopes are:

  • \(-R/2\) for \(x<x_*\);
  • \(R/2\) for \(x_*<x<1\);
  • \(R\) for \(x>1\).

Therefore, globally,

\(\displaystyle J(x)-J(x_*)\ge\frac R2|x-x_*|.\)

The remaining norm term is \(N\)-Lipschitz in \(x\). Thus

\(\displaystyle G(\bar\theta,x)-G(\bar\theta,x_*) \ge\left(\frac R2-N\right)|x-x_*|.\)

Since \(R\ge4N\), this coefficient is positive. Combining this inequality with the pinning bound proves

\(\displaystyle G(\theta,x)-G(\bar\theta,x_*) \ge\sum_i|\theta_i+\lambda| +\left(\frac R2-N\right)|x-x_*|.\)

In particular, \((\bar\theta,x_*)\) is the global minimizer.

4.6. An additive approximate minimizer decides SUBSET SUM

Choose a dyadic accuracy satisfying

\(\displaystyle 0<\varepsilon\le\frac{\Delta}{32N}.\)

Its logarithmic encoding length is \(O(\log N+\log W)\).

Suppose a fallback algorithm returns \((\theta,x)\) with \(F(\theta,x)\le\min F+\varepsilon\). The preceding bound gives

\(\displaystyle |x-x_*|\le\frac{N\varepsilon}{R/2-N}.\)

Consequently,

\(\displaystyle R|x-x_*|\le4N\varepsilon\le\frac{\Delta}{8}.\)

Using the identity

\(\displaystyle f_{\max}=Rx_*+\sqrt{C+R^2},\)

we can recover \(f_{\max}\) to error at most \(3\Delta/16\) by approximating the square root to error \(\Delta/16\). Similarly, we can compute \(t=\sqrt D-\lambda B\) to error \(\Delta/16\).

The resulting approximation to \(f_{\max}-t\) has error at most \(\Delta/4\). Comparing it with \(-\Delta/2\) therefore distinguishes:

  • yes-instances, where \(f_{\max}-t=0\);
  • no-instances, where \(f_{\max}-t\le-\Delta\).

All construction and decoding steps are polynomial-time computations. Thus one call to the requested minimizer algorithm decides SUBSET SUM.

This proves \(\mathrm{NP}\)-hardness of the fallback computation, even for scalar features and fixed \(\alpha=1\). In particular, a polynomial-time algorithm with the requested dependence on \(\log(1/\varepsilon)\) would imply \(\mathrm P=\mathrm{NP}\).
