The continuous mirror question, as graded

Given a finite support \(\mathcal T\) of worker types \(t=(a_t,h_t)\), where \(a_t\) is a truthful answer vector for a fixed task and \(h_t\) is honesty, binary-rational masses \(\mu_t\), and the task’s control answers, compute the infimum of \(\sum_{t\in\mathcal T}\mu_t R_t(\omega;\mu)\) over \(\omega\in[0,1]\) satisfying \(R_t(\omega;\mu)>R_u(\omega;\mu)\) whenever \(h_t>h_u\). Here \(R_t\) is type \(t\)’s expected total iMET reward under the paper’s report model and aggregation rule; determine whether the infimum is attained and return a minimizing weight if it is.

Packaged proof task (what the prover saw — nothing else)

A task has \(m\ge1\) non-control questions, \(c\ge1\) control questions, and \(k\ge2\) labeled options per question; every worker answers every question, and all truthful control answers equal the supplied control answers.
A society is given by its support: the list of the \(\tau\) types \(t=(a_t,h_t)\) with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Truthful answer vectors are \(a_t\in\{1,\ldots,k\}^{m+c}\), and honesty values are binary rationals \(h_t\in[0,1]\); \(L\) is the total input bit length.
Reports are independent across workers and questions: \(p_{tq}(x)=h_t\) if \(x=a_{tq}\), and \(p_{tq}(x)=(1-h_t)/(k-1)\) otherwise. Population frequencies, rather than finite samples, determine the mechanism's honesty and similarity estimates.
For non-control questions define \(\alpha_{tuq}=\sum_{x=1}^k p_{tq}(x)p_{uq}(x)\) and \(\bar\alpha_{tu}=m^{-1}\sum_{q=1}^m\alpha_{tuq}\). Set \(s_{tu}=(\bar\alpha_{tu}-1/k)(k-1)^2/((1-kh_t)(1-kh_u))+1/k\) when both denominator factors are nonzero, and \(s_{tu}=1/k\) otherwise.
Use reward scheme \(M_1\) when \((h_u\ge1/k\text{ and }s_{tu}\ge1/k)\) or \((h_u<1/k\text{ and }s_{tu}<1/k)\); otherwise use \(M_2\). Scheme \(M_1\) pays one unit for agreement and zero otherwise; \(M_2\) pays \(1/(k-1)\) for disagreement and zero otherwise.
The expected truthfulness reward is \(T_t=\sum_{q=1}^m\sum_u\mu_u g_{tu}(\alpha_{tuq})\), where \(g_{tu}(z)=z\) under \(M_1\) and \(g_{tu}(z)=(1-z)/(k-1)\) under \(M_2\). Peers are drawn from the whole society, including the focal type; a single worker has zero mass.
For each non-control question, the final answer \(b_q\) maximizes \(\sum_u\mu_u p_{uq}(x)\), breaking ties by the smallest option label. The expected consistency reward is \(C_t=\sum_{q=1}^m p_{tq}(b_q)\), and the expected total reward is \(R_t(\omega;\mu)=\omega T_t+(1-\omega)C_t\).
Let \(F=\{\omega\in[0,1]:R_t(\omega;\mu)>R_u(\omega;\mu)\text{ whenever }h_t>h_u\}\). The computational problem is to compute \(\inf_{\omega\in F}\sum_t\mu_t R_t(\omega;\mu)\), determine attainment, and return a minimizing weight when attained; an empty feasible set has infimum \(+\infty\).

Is this continuous reward-minimization problem solvable exactly in polynomial time in \(m,c,k,\tau,L\), or is it NP-hard?

The finite-worker iMET result asserts that a weight satisfying strict honesty-based reward ordering exists, with \(\omega=1\) as its witness; it supplies no hardness classification. No verified result located settles the continuous problem defined above.

Conclusion

The problem is solvable exactly in polynomial time in \(m,c,k,\tau,L\). Strict inequalities can prevent attainment, but both the infimum and its attainment status can be computed exactly.

The proof has two parts: compute the rewards as exact rationals, then optimize an affine function over an interval whose endpoints and inclusion conditions are rational.

1. Exact computation of rewards

Define
\[ j_t=\frac{kh_t-1}{k-1}. \]
Then, for every option \(x\),
\[ p_{tq}(x)=\frac1k+j_t\left(\mathbf 1_{\{x=a_{tq}\}}-\frac1k\right). \]
Indeed, when \(x=a_{tq}\), the expression equals \(h_t\); otherwise it equals \((1-h_t)/(k-1)\).

For two types \(t,u\), expanding the product and summing over options gives
\[ \alpha_{tuq} =\frac1k+j_tj_u\left(\mathbf 1_{\{a_{tq}=a_{uq}\}}-\frac1k\right). \]
Here the linear terms vanish because each centered indicator sums to zero, while
\[ \sum_{x=1}^k \left(\mathbf 1_{\{x=a_{tq}\}}-\frac1k\right) \left(\mathbf 1_{\{x=a_{uq}\}}-\frac1k\right) =\mathbf 1_{\{a_{tq}=a_{uq}\}}-\frac1k. \]

Let \(n_{tu}\) be the number of non-control questions on which \(a_t\) and \(a_u\) agree. Thus
\[ \bar\alpha_{tu}=\frac1k+j_tj_u\left(\frac{n_{tu}}m-\frac1k\right). \]

If neither honesty equals \(1/k\), then
\[ (1-kh_t)(1-kh_u)=(k-1)^2j_tj_u, \]
so substitution into the specified similarity formula yields
\[ s_{tu}=\frac{n_{tu}}m. \]
If either honesty equals \(1/k\), the stipulated value is \(s_{tu}=1/k\).

Consequently, every scheme choice is determined by exact rational comparisons. For nonneutral pairs, comparing \(s_{tu}\) with \(1/k\) amounts to comparing the integers \(kn_{tu}\) and \(m\).

Write
\[ A_{tu}=\sum_{q=1}^m\alpha_{tuq} =\frac mk+j_tj_u\left(n_{tu}-\frac mk\right). \]
Because the scheme for a pair is the same on every non-control question,
\[ T_t=\sum_u\mu_u \begin{cases} A_{tu},&\text{under }M_1,\\ (m-A_{tu})/(k-1),&\text{under }M_2. \end{cases} \]
The sum includes \(u=t\), as required.

To compute the final answers, put
\[ r_t=\frac{1-h_t}{k-1}. \]
The population frequency of option \(x\) on question \(q\) is
\[ f_q(x)=\sum_u\mu_ur_u+ \sum_{u:a_{uq}=x}\mu_uj_u. \]
The first term is independent of \(x\). Therefore, aggregate the second term by truthful option label and select its largest value, breaking ties by the smallest label.

Only labels appearing among the support need individual scores. All absent labels have score zero, so, if any label is absent, one additional candidate—the smallest absent label—suffices. Sorting the appearing labels finds that candidate in polynomial time, even when \(k\) is large.

Having obtained \(b_q\), compute
\[ C_t=\sum_{q=1}^m \left(r_t+j_t\mathbf 1_{\{a_{tq}=b_q\}}\right). \]
This accounts exactly for the prescribed tie-breaking rule.

Thus all \(T_t\) and \(C_t\) are exactly computable rationals.

2. Exact description of the feasible set

For every ordered pair with \(h_t>h_u\), define
\[ d_{tu}=C_t-C_u,\qquad e_{tu}=(T_t-C_t)-(T_u-C_u). \]
The required reward ordering is precisely
\[ d_{tu}+e_{tu}\omega>0. \]

Process each such inequality as follows:

  • If \(e_{tu}=0\) and \(d_{tu}\le0\), the feasible set is empty.
  • If \(e_{tu}=0\) and \(d_{tu}>0\), the inequality imposes no restriction.
  • If \(e_{tu}>0\), it imposes \(\omega>-d_{tu}/e_{tu}\).
  • If \(e_{tu}<0\), it imposes \(\omega<-d_{tu}/e_{tu}\).

Assume no constant inequality has already made the set empty. Let
\[ \ell=\max\left(\{0\}\cup \left\{-d_{tu}/e_{tu}:h_t>h_u,\ e_{tu}>0\right\}\right), \]
and
\[ r=\min\left(\{1\}\cup \left\{-d_{tu}/e_{tu}:h_t>h_u,\ e_{tu}<0\right\}\right). \]

There are three cases.

  • If \(\ell>r\), then \(F\) is empty: every feasible weight would have to lie between these bounds.
  • If \(\ell=r\), the only possible feasible weight is \(\ell\). Test all original strict inequalities at that point.
  • If \(\ell<r\), every point of \((\ell,r)\) is feasible. Indeed, it lies strictly above every lower bound and strictly below every upper bound. An endpoint belongs to \(F\) exactly when it satisfies all original strict inequalities.

These tests completely determine \(F\), including endpoint inclusion. In particular, no feasibility assertion from the finite-worker model is needed.

3. Infimum, attainment, and a minimizing weight

Define
\[ a=\sum_t\mu_tC_t,\qquad b=\sum_t\mu_t(T_t-C_t). \]
The objective is the affine function
\[ \sum_t\mu_tR_t(\omega;\mu)=a+b\omega. \]

If \(F\) is empty, return \(+\infty\), with no minimizing weight.

If \(F\) consists of a single feasible point, return its objective value and that point.

Otherwise \(\ell<r\), and the answer follows from the sign of \(b\):

| Condition | Exact infimum | Attainment and returned weight |
|---|---|---|
| \(b>0\) | \(a+b\ell\) | Attained exactly when \(\ell\in F\); then return \(\ell\). |
| \(b<0\) | \(a+br\) | Attained exactly when \(r\in F\); then return \(r\). |
| \(b=0\) | \(a\) | Always attained; return \((\ell+r)/2\). |

For example, if \(b>0\), every feasible weight satisfies \(\omega\ge\ell\), so its objective is at least \(a+b\ell\). Interior feasible weights approach \(\ell\), proving that this lower bound is the infimum. Strict monotonicity shows that equality occurs exactly at \(\ell\), establishing the attainment criterion. The case \(b<0\) is analogous; the constant case is immediate.

4. Polynomial bit complexity

It remains to verify that exact arithmetic does not require exponentially long numbers.

Write the input rationals as
\[ h_t=\frac{v_t}{d_t},\qquad \mu_t=\frac{w_t}{e_t}, \]
with positive denominators, and define
\[ H=\prod_t d_t,\qquad M=\prod_t e_t,\qquad Q=k(k-1)^3H^2M^2. \]
The bit lengths of \(H\) and \(M\) are bounded by the total input length \(L\), up to a constant factor.

From the formulas above:

  • Each \(j_t\) has denominator dividing \((k-1)H\).
  • Each \(A_{tu}\) has denominator dividing \(k(k-1)^2H^2\).
  • Each \(T_t\) has denominator dividing \(k(k-1)^3H^2M\).
  • Each \(C_t\) has denominator dividing \((k-1)H\).
  • The coefficients \(a,b,d_{tu},e_{tu}\) all have denominators dividing \(Q\).

Every individual reward lies in \([0,m]\): agreement probabilities lie in \([0,1]\), and disagreement payments lie in \([0,1/(k-1)]\subseteq[0,1]\). Thus the relevant reward numerators, when expressed over \(Q\), have magnitude at most a constant multiple of \(mQ\).

It follows that the rewards and affine coefficients have bit length bounded by a constant multiple of \(L+\log m+\log k\). The same bound holds for each threshold \(-d_{tu}/e_{tu}\), since it is a ratio of two integers of that bounded length. Midpoints and objective evaluations also have polynomial bit length.

Computing all agreement counts takes a number of operations proportional to \(m\tau^2\). Computing final answers uses polynomially many rational additions and label comparisons. There are at most \(\tau(\tau-1)\) ordering constraints. Rational arithmetic, comparison, and reduction on numbers of polynomial bit length take polynomial time.

Therefore the complete algorithm runs in polynomial time in \(m,c,k,\tau,L\), and returns exact answers in every feasibility and attainment case.
