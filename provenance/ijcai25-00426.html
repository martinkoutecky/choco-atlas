The continuous mirror question, as graded

Given rational machine-type masses \(\mu_t\), repeated unit-job-template supplies \(\lambda_k\), binary values \(v_t(k)\), and complete machine availability data, let \(\mathcal S_t\) be the integral feasible schedules for one type-\(t\) machine and \(a_{\sigma k}\) the number of template-\(k\) jobs used by schedule \(\sigma\). Find \(x_{t,\sigma}\ge0\) satisfying \(\sum_{\sigma\in\mathcal S_t}x_{t,\sigma}=\mu_t\) and \(\sum_{t,\sigma}a_{\sigma k}x_{t,\sigma}\le\lambda_k\), maximizing continuous Nash welfare \(\sum_{t,\sigma}x_{t,\sigma}\log U_t(\sigma)\) when utilities are positive, with zero cases handled as in the paper, such that for every positive-support \((t,\sigma)\), \((t',\rho)\), and job occurrence \(e\in\rho\), \(U_t(\sigma)\ge U_t(\rho\setminus\{e\})\), and the allocation is Pareto optimal under feasible measure-preserving reassignment.

Packaged proof task (what the prover saw — nothing else)

For each job class \(q\in Q\), a copy has release time \(r_q\), deadline \(d_q\), and processing time \(p_q\). Let \(\mathcal B\subseteq\mathbb Z_{\ge0}^{Q}\) be the set of multiplicity vectors whose corresponding job copies can be scheduled non-preemptively on one machine, with no overlaps, each wholly within its release-deadline interval. Define \(v_a(b)=\sum_{q\in Q}v_{a,q}b_q\).

A mass schedule consists of \(x_{a,b}\ge0\) for \(a\in A,b\in\mathcal B\), and charity masses \(y_q\ge0\), with \(\sum_{b\in\mathcal B}x_{a,b}=\mu_a\) and \(\sum_{a\in A,b\in\mathcal B}b_qx_{a,b}+y_q=\beta_q\). It is WIO if, whenever \(x_{a,b}>0\), \(v_a(b)\ge R_a(y)\), where \(R_a(y)=\max\{v_a(b'):b'\in\mathcal B,\ b'_q>0\Rightarrow y_q>0\}\).

Target. Is computing such a WIO mass schedule polynomial-time solvable, or NP-hard?

Nearest known results. For the discrete fair interval scheduling problem, computing a WIO schedule is NP-hard. No result for the above mass-distribution formulation is established here.

Complexity model

Use the standard high-multiplicity encoding:

  • The sets \(A\) and \(Q\) and all parameters are given explicitly in binary.
  • Processing times are positive integers.
  • The configuration set \(\mathcal B\) is represented implicitly by the release times, deadlines, and processing times.
  • A solution lists its finitely many positive rational variables \(x_{a,b}\), together with \(y\).

Under this encoding, computing an exact WIO mass schedule is \(\mathrm{NP}\)-hard.

Existence of WIO schedules

First, WIO schedules always exist when \(\mathcal B\) is finite.

Consider the linear optimization problem of maximizing total allocated value

\[ \sum_{a\in A}\sum_{b\in\mathcal B}v_a(b)x_{a,b} \]

over all mass schedules. Its feasible region is nonempty because the zero configuration belongs to \(\mathcal B\): one may set \(x_{a,0}=\mu_a\) and \(y_q=\beta_q\). It is compact because \(\mathcal B\) is finite, so an optimum exists.

Let \((x,y)\) be an optimum. Suppose it is not WIO. Then for some \(a\) and \(b\) with \(x_{a,b}>0\), there is a configuration \(b'\in\mathcal B\) such that

\[ b'_q>0\Longrightarrow y_q>0 \]

and

\[ v_a(b')>v_a(b). \]

Choose \(\varepsilon>0\) sufficiently small that \(\varepsilon\le x_{a,b}\) and

\[ \varepsilon(b'_q-b_q)\le y_q \]

for every \(q\) with \(b'_q>b_q\). Such an \(\varepsilon\) exists because every such \(q\) satisfies \(b'_q>0\), hence \(y_q>0\).

Move mass \(\varepsilon\) from \(b\) to \(b'\), and replace

\[ y_q\quad\text{by}\quad y_q+\varepsilon(b_q-b'_q). \]

All mass and supply equalities remain valid, and the choice of \(\varepsilon\) keeps every charity mass nonnegative. Total allocated value increases by

\[ \varepsilon\bigl(v_a(b')-v_a(b)\bigr)>0, \]

contradicting optimality. Thus every welfare-maximizing mass schedule is WIO.

This establishes existence, but does not provide a polynomial-time algorithm because optimizing over the implicit configuration set can be hard.

An NP-hard exact packing problem

We first give a self-contained reduction from \(\mathrm{SUBSET\ SUM}\).

Let \(a_1,\ldots,a_n\) be positive integers and let \(B\) satisfy

\[ 1\le B\le\sum_{i=1}^n a_i. \]

Set

\[ M=\max_i a_i,\qquad L=nM+1. \]

For every \(i\), define two positive integers

\[ s_{i,0}=L^i+L^{n+1}, \qquad s_{i,1}=a_i+L^i+L^{n+1}, \]

and define the target

\[ T=B+\sum_{i=1}^n L^i+nL^{n+1}. \]

We claim that

\[ \sum_{i\in S}a_i=B \]

for some subset \(S\subseteq\{1,\ldots,n\}\) if and only if there are nonnegative integers \(z_{i,0},z_{i,1}\) satisfying

\[ \sum_{i=1}^n\sum_{\epsilon\in\{0,1\}} z_{i,\epsilon}s_{i,\epsilon}=T. \]

For the forward implication, choose exactly one number for each \(i\): choose \(s_{i,1}\) when \(i\in S\), and \(s_{i,0}\) otherwise. Their sum is exactly \(T\).

Conversely, suppose such nonnegative integers \(z_{i,\epsilon}\) exist. Put

\[ N=\sum_{i,\epsilon}z_{i,\epsilon}. \]

The part of \(T\) below the \(L^{n+1}\) digit is

\[ B+\sum_{i=1}^nL^i<L^{n+1}. \]

Consequently,

\[ T<(n+1)L^{n+1}. \]

Every \(s_{i,\epsilon}\) is at least \(L^{n+1}\), so \(N\le n<L\).

Define

\[ c_i=z_{i,0}+z_{i,1}, \qquad u=\sum_{i=1}^n a_i z_{i,1}. \]

Because \(c_i\le N<L\) and

\[ u\le MN\le Mn<L, \]

the expression

\[ u+\sum_{i=1}^n c_iL^i+NL^{n+1} \]

has no carries in base \(L\). Uniqueness of base-\(L\) representation, compared with the definition of \(T\), therefore gives

\[ c_i=1\quad\text{for every }i, \qquad u=B. \]

Thus exactly one of \(z_{i,0}\) and \(z_{i,1}\) equals \(1\) for each \(i\). The set

\[ S=\{i:z_{i,1}=1\} \]

then satisfies \(\sum_{i\in S}a_i=B\).

The constructed integers have \(O(n\log L)\) bits, so this is a polynomial-time reduction. Hence exact unbounded packing—deciding whether nonnegative multiplicities of given sizes can sum exactly to a target—is \(\mathrm{NP}\)-hard.

Reduction to WIO mass scheduling

Take the exact packing instance with item sizes \(s_q\) and target \(T\). Construct a WIO instance as follows:

  • There is one agent class \(A=\{a\}\), with \(\mu_a=1\).
  • Each job class has

\[ r_q=0,\qquad d_q=T,\qquad p_q=s_q. \]

  • Set

\[ v_{a,q}=s_q=p_q. \]

  • Set every supply to

\[ \beta_q=T+1. \]

Because all jobs have the common window \([0,T]\), a multiplicity vector is feasible exactly when

\[ \mathcal B = \left\{ b\in\mathbb Z_{\ge0}^{Q}: \sum_{q\in Q}s_qb_q\le T \right\}. \]

Necessity follows because all jobs must occupy disjoint subintervals of an interval of length \(T\). Conversely, whenever the total processing time is at most \(T\), the copies can be placed consecutively starting at time \(0\).

Now consider any mass schedule for this instance. Every \(b\in\mathcal B\) satisfies \(b_q\le T\), because \(s_q\ge1\). Therefore

\[ \sum_{b\in\mathcal B}b_qx_{a,b} \le T\sum_{b\in\mathcal B}x_{a,b} =T. \]

It follows from the supply equality that

\[ y_q = T+1-\sum_{b\in\mathcal B}b_qx_{a,b} \ge1. \]

Thus every charity coordinate is strictly positive in every mass schedule. Consequently,

\[ R_a(y) = \max_{b'\in\mathcal B}v_a(b') = \max_{b'\in\mathcal B}\sum_qs_qb'_q. \]

If the schedule is WIO and \(x_{a,b}>0\), then

\[ v_a(b)\ge R_a(y). \]

The reverse inequality holds by the definition of \(R_a(y)\). Hence every positively supported configuration satisfies

\[ v_a(b)=R_a(y); \]

that is, every such configuration is an optimal unbounded packing of capacity \(T\).

A WIO schedule exists: choose any maximizing configuration \(b^\star\), set \(x_{a,b^\star}=1\), and set \(y_q=T+1-b^\star_q\).

Extracting the answer

Suppose a polynomial-time algorithm computed an exact WIO mass schedule. Since

\[ \sum_bx_{a,b}=1, \]

its output contains at least one configuration \(b\) with \(x_{a,b}>0\). By the preceding argument, its value is the optimum packing value.

The original exact packing instance is feasible if and only if

\[ v_a(b)=T. \]

Thus one call to a WIO-schedule algorithm would solve \(\mathrm{SUBSET\ SUM}\) in polynomial time.

Therefore computing a WIO mass schedule is \(\mathrm{NP}\)-hard, already with one agent class, common release time and deadline, positive integer data, and \(v_{a,q}=p_q\). The reduction establishes weak \(\mathrm{NP}\)-hardness; no claim of strong \(\mathrm{NP}\)-hardness or membership in \(\mathrm{NP}\) is needed.

Overall assessment

The prover correctly establishes weak \(\mathrm{NP}\)-hardness under the explicitly stated high-multiplicity binary encoding. The reduction is logically sound, and the extraction argument genuinely converts any exact WIO schedule into the answer to the source packing instance.

There is one minor source-problem qualification gap: the proof assumes \(1\le B\le\sum_i a_i\) without explicitly identifying this restricted version of \(\mathrm{SUBSET\ SUM}\) as NP-hard or explaining the trivial preprocessing for excluded instances.

Step-by-step audit

1. Complexity model

The prover specifies that configurations are implicit and that an exact solution explicitly lists its positive rational support. Under that model, extracting a positive-support configuration is legitimate: since \(\sum_b x_{a,b}=1\), at least one listed coefficient is positive.

The proof gives a polynomial-time oracle reduction from \(\mathrm{SUBSET\ SUM}\) to the schedule-computation problem. This is sufficient for the claimed computational \(\mathrm{NP}\)-hardness; membership in \(\mathrm{NP}\) is neither claimed nor required.

2. Existence argument

The zero configuration is feasible, and setting \(x_{a,0}=\mu_a\) and \(y_q=\beta_q\) gives a mass schedule provided, as implicit in the formulation, that the supplies \(\beta_q\) are nonnegative.

For finite \(\mathcal B\), the feasible region is bounded: each \(x_{a,b}\) lies in a finite simplex, and the supply equalities bound and determine the charity coordinates. Thus the welfare maximum exists.

The exchange argument is correct. If \(b'_q>b_q\), then \(b'_q>0\), so the eligibility condition gives \(y_q>0\). A sufficiently small common \(\varepsilon>0\) therefore preserves all nonnegativity constraints. The supply equalities are preserved because the allocation change \(\varepsilon(b'_q-b_q)\) is exactly offset in \(y_q\). The objective increases strictly, contradicting optimality.

Hence the claimed existence of WIO schedules follows.

3. Reduction to exact unbounded packing

The forward direction correctly selects one of \(s_{i,0}\) and \(s_{i,1}\) for every index.

For the reverse direction:

  • Since \(B\le\sum_i a_i\le nM<L\), the constant digit \(B\) is less than \(L\).
  • The stated bound \(B+\sum_{i=1}^nL^i<L^{n+1}\) is valid.
  • Therefore \(T<(n+1)L^{n+1}\).
  • Every selected item contributes at least \(L^{n+1}\), so the total number \(N\) of selected items satisfies \(N\le n<L\).
  • Consequently \(c_i\le N<L\), \(u\le MN\le Mn<L\), and \(N<L\).

Thus all displayed coefficients are valid base-\(L\) digits, with no carries. Uniqueness of base-\(L\) expansion then forces \(c_i=1\) for every \(i\) and \(u=B\). This correctly recovers a subset summing to \(B\).

The constructed numbers have polynomial binary length because \(L^i\) has \(O(i\log L)\) bits.

The only qualification omitted is why restricting the source instances to \(1\le B\le\sum_i a_i\) preserves \(\mathrm{NP}\)-hardness. This is routine but should be stated.

4. Scheduling construction

With common window \([0,T]\), a multiplicity vector is schedulable exactly when its total processing time is at most \(T\). Necessity follows from disjointness, and sufficiency follows by scheduling the copies consecutively.

For every feasible configuration, \(b_q\le T\), since \(s_q\ge1\). Hence, using nonnegativity and \(\sum_bx_{a,b}=1\),

\[ \sum_b b_qx_{a,b}\le T. \]

It follows that \(y_q\ge1\) for every class and every mass schedule. Therefore every feasible configuration is eligible in the definition of \(R_a(y)\), and \(R_a(y)\) equals the maximum packing value.

The WIO condition then forces every positive-support configuration to attain that maximum. The explicitly constructed schedule supported on a maximizing configuration satisfies all mass, supply, and WIO requirements.

5. Extraction

Any exact WIO output contains a positive-support configuration. Its value equals the optimum unbounded-packing value. Because every feasible packing has value at most \(T\), the exact-packing instance is feasible precisely when the extracted value equals \(T\).

All relevant integers and configurations have polynomial binary representation. Thus a polynomial-time WIO computation algorithm would decide the source problem in polynomial time.
