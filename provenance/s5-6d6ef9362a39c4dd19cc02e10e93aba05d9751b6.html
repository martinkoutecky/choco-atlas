The continuous mirror question, as graded

Given rational masses over \(K\) payoff-complete types, \(T\) probe environments, and finitely represented type-conditional mixed strategies in a specified anonymous aggregate-interaction model, decide whether there exist type-specific concave, continuous, locally non-satiated utilities under which each observed population profile maximizes mass-weighted utilitarian welfare among feasible profiles. Determine whether a finite revealed-preference certificate characterizes this consistency and its computational complexity.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau=K\) payoff-complete types with positive binary-rational masses \(w_k\), normalized by \(\sum_k w_k=1\). Support size means listed types, not the number of possible types; members of a type share one utility and the same feasible actions.
Fix \(m,K,T\geq1\). In probe \(t\), type \(k\) has action set \(A_{kt}=\{a\in\mathbb R_+^m:g_{kt}(a)\leq0\}\), where \(g_{kt}:\mathbb R^m\to\mathbb R\) is given as the minimum of finitely many rational affine functions with strictly positive coordinate slopes, and \(g_{kt}(0)<0\); thus these sets are nonempty and compact.
The probes satisfy this promised structure: for each type there is a supplied rational vector \(\beta_k\) such that, for every \(c\in\mathbb R\) and probe \(t\), \(g_{kt}(x-c\beta_k)=g_{kt}(y-c\beta_k)=0\) implies \(g_{kt}(x)=g_{kt}(y)\), for all \(x,y\in\mathbb R^m\).
Each observed type strategy \(\mu_{kt}\) is an explicitly listed finitely supported probability measure with rational atoms in \(A_{kt}\) and rational probabilities. A feasible population profile is any tuple \(\nu=(\nu_k)_{k=1}^K\) of Borel probability measures supported on the corresponding \(A_{kt}\), without a restriction on the number of atoms.
The anonymous interaction model uses the deterministic population mean \(z(\nu)=\sum_k w_k\int a\,d\nu_k(a)\). Type \(k\)'s payoff from action \(a\) is \(U_k(a,z(\nu))\), and welfare is \(W_U(\nu)=\sum_k w_k\int U_k(a,z(\nu))\,d\nu_k(a)\).
Consistency means that there exist real-valued, jointly concave, continuous utilities \(U_k:\mathbb R^{2m}\to\mathbb R\), nondecreasing and locally non-satiated in their own-action argument for every fixed aggregate, common to all probes, such that \(\mu_t\in\arg\max_{\nu_k\in\Delta(A_{kt})}W_U(\nu)\) for every \(t\). Tied maximizers are allowed; no equilibrium condition is imposed.
Let \(S\) be the total number of listed strategy atoms, \(H\) the total number of affine probe pieces, and \(L\) the total binary input length; state running times in \(m,\tau,T,S,H,L\).

Does this consistency problem admit a finite necessary-and-sufficient revealed-preference certificate, and is its decision problem in \(\mathrm P\) or \(\mathrm{NP}\)-hard?

For finitely many agents, a revealed-preference characterization equates social-optimality consistency under the stated probe structure with feasibility of finitely many linear inequalities with positive multipliers. [Snow–Krishnamurthy](https://arxiv.org/html/2404.15391v4)
For a single consumer choosing pure actions from nonlinear budget sets, a generalized Afriat theorem supplies finite rationalization inequalities. [Forges–Minelli](https://igier.unibocconi.eu/sites/default/files/media/attach/MinelliPAPER.pdf)

Modeling choices made when packaging the task

  • Normalized the positive type masses to total mass one and identified K with the support size tau.
  • Specified the otherwise undefined anonymous interaction as dependence on own action and the deterministic mass-weighted mean action; the aggregate is recomputed for every competing population profile.
  • Interpreted payoff-complete types as sharing utilities and feasible action sets, with utilities fixed across probes and allowed to take arbitrary real values.
  • Specified a finite rational encoding of the concave increasing probes using minima of affine functions with strictly positive coordinate slopes; retained the anchor's shift-invariance condition as an input promise.
  • Required negative probe values at zero to ensure nondegenerate, nonempty compact feasible action sets.
  • Specified observed strategies as rational finite atomic measures, while allowing all Borel probability measures supported on feasible action sets as competitors.
  • Used support feasibility rather than merely an expected-budget constraint, following the active discrete definition.
  • Interpreted concavity jointly in own action and aggregate, and monotonicity and local non-satiation in own action at each fixed aggregate.
  • Allowed tied welfare maximizers and omitted a Nash consistency requirement because the anchor's revealed-preference test does not technically require equilibrium observations.

2. A universal certificate and complete proof

Let \(\mathbf 1=(1,\ldots,1)\in\mathbb Q^m\). For every type \(k\), define the common-across-probes utility
\[ U_k(a,z)=\mathbf 1^\top a-\mathbf 1^\top z. \]

These utilities satisfy every stated requirement:

  • They are real-valued and continuous on \(\mathbb R^{2m}\).
  • They are jointly concave, because they are affine.
  • For every fixed aggregate \(z\), they are nondecreasing in every own-action coordinate.
  • They are locally non-satiated in their own-action argument: for every \(a\) and every \(\varepsilon>0\), choosing \(0<\delta<\varepsilon\) gives

\[ U_k(a+\delta e_1,z)-U_k(a,z)=\delta>0. \]

  • Members of each type share the same utility, as required. Identical utilities across different types are permitted.

Fix any probe \(t\) and any feasible population profile \(\nu\). Compactness of the action sets ensures that all coordinate expectations are finite. Because each \(\nu_k\) is a probability measure, the aggregate \(z(\nu)\) is constant inside each integral. Thus
\[ \begin{aligned} W_U(\nu) &=\sum_{k=1}^{\tau}w_k \left(\mathbf 1^\top\int a\,d\nu_k(a) -\mathbf 1^\top z(\nu)\right)\\ &=\mathbf 1^\top z(\nu) -\left(\sum_{k=1}^{\tau}w_k\right)\mathbf 1^\top z(\nu)\\ &=0. \end{aligned} \]

Here the second equality uses the definition of \(z(\nu)\), and the third uses the normalization \(\sum_k w_k=1\).

Every feasible profile therefore maximizes welfare. In particular, every observed \(\mu_t\) is a maximizer. Tied maximizers are explicitly allowed, so this proves consistency simultaneously for all probes. The calculation applies to arbitrary Borel probability measures; it does not impose any restriction on their number of atoms.

3. A stronger result: non-affine utilities also rationalize every dataset

Write the listed atoms as \(a_{ktr}\), and let \(z_t=z(\mu_t)\). Define the rational number
\[ M=1+\max\left(\{0\}\cup \{a_{ktr,1}-z_{t,1}:k,t,r\}\right). \]
For every type, set
\[ \widetilde U_k(a,z) =\mathbf 1^\top(a-z) -\frac12\max\{0,a_1-z_1-M\}. \]

These utilities are continuous and jointly concave: the maximum of two affine functions is convex, so its negative is concave. They are non-affine on \(\mathbb R^{2m}\).

To verify own-action monotonicity explicitly, let \(h\in\mathbb R_+^m\) and put \(r=a_1-z_1-M\). The elementary inequality
\[ 0\leq\max\{0,r+h_1\}-\max\{0,r\}\leq h_1 \]
gives
\[ \widetilde U_k(a+h,z)-\widetilde U_k(a,z) \geq\sum_{j=1}^m h_j-\frac12h_1 \geq\frac12\sum_{j=1}^m h_j. \]
Thus the utilities are nondecreasing, and increasing any coordinate by an arbitrarily small positive amount strictly increases utility. Local non-satiation holds for every fixed aggregate.

For any feasible profile, the affine terms cancel exactly as before, leaving
\[ W_{\widetilde U}(\nu) =-\frac12\sum_{k=1}^{\tau}w_k \int\max\{0,a_1-z_1(\nu)-M\}\,d\nu_k(a) \leq0. \]
At every observed atom, the definition of \(M\) makes the integrand zero. Therefore \(W_{\widetilde U}(\mu_t)=0\) for every probe, proving optimality again.

This establishes universal consistency even with non-affine rationalizing utilities.

These bounds concern the promised problem.
