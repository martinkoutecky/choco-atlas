The continuous mirror question, as graded

Given finite applicant-type and position-type sets \(I,J\), compatibility relation \(A\subseteq I\times J\), rational masses \(\mu_i>0\) summing to \(1\), and rational per-capita supplies \(\sigma_j\ge 0\) summing to less than \(1\), with every supply jointly fillable, compute a feasible flow \(x_{ij}\ge 0\) supported on \(A\), satisfying \(\sum_j x_{ij}\le\mu_i\) and \(\sum_i x_{ij}=\sigma_j\), whose rates \(p_i=\sum_j x_{ij}/\mu_i\) give a lexicographically maximal population-weighted quantile function \(Q_p(z)\). Return the exact rational flow and a sampler for measurable one-to-one matchings realizing it, in time polynomial in \(|I|,|J|\), and the input bit length.

Packaged proof task (what the prover saw — nothing else)

Let \(I\) be applicant types and \(J\) position types, with compatibility \(A\subseteq I\times J\). Applicants regard all compatible positions as equally satisfactory; satisfaction means being matched.
A society is given by its support: the list of its \(\tau=|I|\) positive-mass types, each with binary rational mass \(\mu_i>0\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types. Put \(m=|J|\), and let \(L\) be the total input bit length.
Position supplies are binary rationals \(\sigma_j>0\) with \(0<\sum_j\sigma_j<1\). Every applicant type has a compatible position type, and all supplies are jointly fillable.
A feasible flow satisfies \(x_{ij}\ge0\), \(x_{ij}=0\) outside \(A\), \(\sum_jx_{ij}\le\mu_i\), and \(\sum_ix_{ij}=\sigma_j\). Define \(p_i=\sum_jx_{ij}/\mu_i\) and \(Q_p(z)=\inf\{t\in[0,1]:\sum_{i:p_i\le t}\mu_i>z\}\) for \(z\in[0,1)\).
Compare quantile functions on the intervals of their common breakpoint partition: the larger value on the leftmost interval where they differ is lexicographically larger.
Represent each type by a disjoint half-open interval of its prescribed Lebesgue measure. A realized matching is a measurable, measure-preserving bijection from an applicant subset onto all position intervals, respecting \(A\), modulo null sets.
The output is an exact rational feasible flow maximizing \(Q_p\), together with a finite sampler description. Almost surely, each realization matches mass \(x_{ij}\) between types \(i,j\); for almost every applicant of type \(i\), the probability of assignment to type \(j\) is \(x_{ij}/\mu_i\).
The sampler uses ideal independent uniform real seeds and outputs a finite description of the matching; description construction and point evaluation use rational arithmetic and comparisons with those seeds. Count arithmetic operations in this sampling model and bit operations for the rational-flow computation.
Is this computation problem solvable in polynomial time in \(m,\tau,L\), including polynomial-size sampler descriptions and polynomial expected sampling and evaluation time, or is it NP-hard?
The discrete one-sided bipartite problem has an exact algorithm running in \(O((|V|^2+|E||V|^{2/3})(\log|V|)^2)\) expected time ([García-Soriano–Bonchi](https://arxiv.org/abs/1802.02562)).
Weighted maxmin-fair splittable routing has a polynomial-time algorithm ([Allalouf–Shavitt](https://www.eng.tau.ac.il/~shavitt/pub/ToN08maxmin.pdf)); that result does not specify the measurable matching sampler required here. No result settling this exact combined problem was identified.

Modeling choices made when packaging the task

  • Represent the otherwise unspecified nonatomic applicant and position populations by disjoint Lebesgue intervals; require measure-preserving one-to-one matchings modulo null sets.
  • Interpret realizing the flow as requiring the prescribed type-pair masses in each realization and the prescribed assignment probabilities for almost every individual applicant.

1. Result

The computation problem is solvable in polynomial time in \(m,\tau,L\). An exact rational optimal flow can be computed using polynomially many rational linear programs. From that flow, one can construct a polynomial-size sampler whose sampling and point-evaluation costs are polynomial in the stipulated arithmetic model.

The sampler uses finitely many rational circular shifts. The number of possible shifts can be exponentially large, but its binary encoding is polynomially bounded, and sampling does not enumerate them.

Progressive linear programs also appear in [Allalouf–Shavitt’s splittable-routing algorithm](https://www.eng.tau.ac.il/~shavitt/pub/ToN08maxmin.pdf). Below, we prove directly that this approach optimizes the specified weighted quantile order and construct the required measurable matching sampler.

2. The feasible polytope and progressive optimization

Write \(e=|A|\le \tau m\), and let \(P\) be the feasible-flow polytope, using only the coordinates indexed by \(A\). Thus

\( P=\left\{x\in\mathbb R_{\ge0}^{A}: \sum_{j:(i,j)\in A}x_{ij}\le\mu_i\ \text{for every }i,\quad \sum_{i:(i,j)\in A}x_{ij}=\sigma_j\ \text{for every }j \right\}. \)

The joint-fillability assumption makes \(P\) nonempty. It is compact because each coordinate is nonnegative and bounded by its row mass. Define the linear functions

\( p_i(x)=\frac{\sum_jx_{ij}}{\mu_i}. \)

These are well-defined because \(\mu_i>0\), and satisfy \(0\le p_i(x)\le1\).

We construct nested nonempty compact polytopes \(C_k\), active sets \(R_k\), and frozen sets \(B_k\). Initially,

\( C_0=P,\qquad R_0=I. \)

At stage \(k\), provided \(R_{k-1}\ne\varnothing\), solve the linear program

\( \lambda_k=\max\left\{t: x\in C_{k-1},\quad 0\le t\le1,\quad p_i(x)\ge t\ \text{for every }i\in R_{k-1}\right\}. \)

Let

\( C_k=\left\{x\in C_{k-1}:p_i(x)\ge\lambda_k \ \text{for every }i\in R_{k-1}\right\}. \)

For every \(i\in R_{k-1}\), solve another linear program to obtain

\( M_{ki}=\max_{x\in C_k}p_i(x). \)

Set

\( B_k=\{i\in R_{k-1}:M_{ki}=\lambda_k\}, \qquad R_k=R_{k-1}\setminus B_k. \)

In particular, every \(i\in B_k\) satisfies \(p_i(x)=\lambda_k\) throughout \(C_k\).

Every stage freezes at least one type

Suppose \(B_k=\varnothing\). For every active type \(i\), there would then be a flow \(x^{(i)}\in C_k\) satisfying \(p_i(x^{(i)})>\lambda_k\).

Their average belongs to \(C_k\), by convexity. Every active coordinate of every summand is at least \(\lambda_k\), and each coordinate is strictly larger in at least one summand. Consequently, the average satisfies

\( p_i\left(\frac{1}{|R_{k-1}|} \sum_{h\in R_{k-1}}x^{(h)}\right)>\lambda_k \quad\text{for every }i\in R_{k-1}. \)

Its minimum active probability exceeds \(\lambda_k\), contradicting the defining optimality of \(\lambda_k\). Therefore \(B_k\ne\varnothing\).

The same averaging argument, applied only to \(R_k\), shows that if \(R_k\ne\varnothing\), some flow in \(C_k\) satisfies \(p_i(x)>\lambda_k\) simultaneously for every \(i\in R_k\). Hence

\( \lambda_{k+1}>\lambda_k. \)

Thus the algorithm stops after \(r\le\tau\) stages. The sets \(B_1,\ldots,B_r\) partition \(I\), and every flow in \(C_r\) has the same probability vector

\( p_i^*=\lambda_k\qquad(i\in B_k). \)

Choose any rational flow \(x^*\in C_r\).

3. Proof of optimality for the weighted quantile order

The weights in the quantile definition require justification: optimizing an unweighted sorted list alone would not suffice.

For a probability vector \(v\), define

\( F_v(t)=\sum_{i:v_i\le t}\mu_i. \)

Because there are finitely many types, \(Q_v(z)\) is attained at one of the values \(v_i\), and

\( F_v(Q_v(z))>z. \)

Quantile comparison lemma

Suppose \(u,v\in[0,1]^I\), and \(B\subseteq I\) satisfies:

  • \(u_i=v_i\) for every \(i\in B\);
  • \(u_i\ge\lambda\) for every \(i\notin B\);
  • \(b=\min_{i\notin B}v_i<\lambda\).

Then \(Q_u\) is lexicographically larger than \(Q_v\).

Proof. For every \(t\le b\), none of the coordinates \(u_i\) outside \(B\) contributes to \(F_u(t)\). The coordinates in \(B\) agree, so

\( F_v(t)\ge F_u(t)\qquad(t\le b). \)

At \(t=b\), at least one additional coordinate contributes to \(F_v(b)\). Its mass is positive, hence

\( F_v(b)>F_u(b). \)

Put \(z_0=F_u(b)\). Since the complement of \(B\) has positive mass and its \(u\)-values exceed \(b\), we have \(z_0<1\).

For \(z<z_0\), the definition gives \(Q_u(z)\le b\). Therefore

\( F_v(Q_u(z))\ge F_u(Q_u(z))>z, \)

and consequently \(Q_v(z)\le Q_u(z)\).

For every \(z\in[z_0,F_v(b))\), however,

\( Q_v(z)\le b<Q_u(z). \)

This interval has positive length. Thus there is a differing interval, and every differing interval preceding this witness also favors \(u\). The leftmost differing interval therefore favors \(u\), proving the lemma. \(\square\)

Application to the algorithm

Take any feasible flow \(y\in P\) whose probability vector differs from \(p^*\).

Since all flows in \(C_r\) have probability vector \(p^*\), there is a first stage \(k\) such that

\( y\in C_{k-1}\quad\text{but}\quad y\notin C_k. \)

Let

\( B=B_1\cup\cdots\cup B_{k-1}. \)

For every \(i\in B\), both \(x^*\) and \(y\) have the frozen probability assigned at the corresponding earlier stage. Thus their probabilities agree on \(B\).

For every remaining type, \(p_i^*\ge\lambda_k\), because \(x^*\in C_k\). On the other hand, \(y\notin C_k\) means

\( \min_{i\notin B}p_i(y)<\lambda_k. \)

The comparison lemma applies and shows that \(Q_{p^*}\) is lexicographically larger than \(Q_{p(y)}\).

Therefore \(x^*\) maximizes the required weighted quantile function. Moreover, the maximizing probability vector is unique, although the maximizing flow need not be.

4. Polynomial bit complexity of the flow computation

We use the standard rational linear-programming theorem: a feasible bounded rational linear program can be solved exactly in time polynomial in its input bit length, returning a rational optimum of polynomial encoding length.

There are at most \(\tau\) stages and at most \(\tau\) coordinate tests per stage, hence \(O(\tau^2)\) linear programs. Each has polynomially many variables and constraints.

One additional issue must be checked: inserting previously computed levels into successive linear programs must not cause uncontrolled bit growth.

A uniform bound on all level encodings

Fix a stage \(k\). Consider an auxiliary polytope \(H_k\) with variables \(x\) and \(t_1,\ldots,t_k\), defined by

\( x\in P,\qquad 0\le t_1\le\cdots\le t_k\le1, \)

\( \sum_jx_{ij}=\mu_i t_h \qquad(i\in B_h,\ 1\le h<k), \)

and

\( \sum_jx_{ij}\ge\mu_i t_k \qquad(i\in R_{k-1}). \)

Crucially, its coefficients use only original input rationals and integers. Its dimension and encoding length are polynomial in \(m,\tau,L\).

We claim that lexicographically maximizing \(t_1,\ldots,t_k\), in this fixed coordinate order, gives

\( (t_1,\ldots,t_k)=(\lambda_1,\ldots,\lambda_k). \)

First, any flow in \(C_k\), paired with this vector of levels, is feasible for \(H_k\).

Conversely, suppose earlier coordinates \(t_1,\ldots,t_{h-1}\) have already been fixed to their corresponding levels. In a feasible point of \(H_k\), every type active at stage \(h\) has probability at least \(t_h\): it either belongs to some later frozen set \(B_\ell\), where its probability equals \(t_\ell\ge t_h\), or remains in \(R_{k-1}\), where its probability is at least \(t_k\ge t_h\).

The earlier frozen coordinates have their prescribed values, and the ordering of the \(t\)-coordinates ensures the previous lower bounds. Hence this flow belongs to \(C_{h-1}\), so \(t_h\le\lambda_h\). The feasible witness above attains equality. This proves the claim by induction.

Successive maximizations of linear coordinates produce nested faces of \(H_k\). Their final nonempty face contains a vertex of \(H_k\). At that vertex, the \(t\)-coordinates equal \(\lambda_1,\ldots,\lambda_k\).

By Cramer’s rule and the determinant bounds for rational-polytope vertices, every coordinate of a vertex of \(H_k\) has polynomial bit length: after clearing denominators, the defining matrix has polynomial dimension and polynomially bounded entry bit lengths. Thus all \(\lambda_h\) have a uniform polynomial bit bound in the original input.

Every actual stage and coordinate-test LP therefore has polynomial input length. Exact comparisons such as \(M_{ki}=\lambda_k\) are polynomial-time rational comparisons. Finally, an exact LP over \(C_r\) returns a rational flow \(x^*\) of polynomial encoding length.

This proves the polynomial bit complexity of the flow computation.

5. An exact sampler using rational circular shifts

The following construction works for any rational feasible flow \(x\), including \(x^*\).

Choose rational interval origins and represent applicant and position types by

\( A_i=[\alpha_i,\alpha_i+\mu_i), \qquad P_j=[\beta_j,\beta_j+\sigma_j), \)

respectively. Cumulative sums of the masses and supplies provide such disjoint intervals on each side.

Fixed partitions determined by the flow

For each applicant type \(i\), order the position types and partition a local interval \([0,\mu_i)\) into blocks

\( B_{ij}=[c_{ij},c_{ij}+x_{ij}), \qquad c_{ij}=\sum_{\ell<j}x_{i\ell}, \)

followed by an unmatched block

\( B_{i0}=\left[\sum_jx_{ij},\mu_i\right). \)

Empty blocks may be omitted.

For each position type \(j\), partition its interval into

\( T_{ij}=[\beta_j+d_{ij},\beta_j+d_{ij}+x_{ij}), \qquad d_{ij}=\sum_{h<i}x_{hj}. \)

The column equations imply that these blocks partition all of \(P_j\).

Define normalized block lengths

\( q_{ij}=\frac{x_{ij}}{\mu_i}, \qquad q_{i0}=1-\sum_jq_{ij}. \)

Let \(D_i\) be the product of the reduced denominators of these rational numbers, assigning denominator \(1\) to zero. Every normalized block endpoint is then an integer multiple of \(1/D_i\).

Sampling the shifts

Independently for each \(i\), draw an ideal uniform seed \(U_i\in[0,1)\) and choose the unique integer \(K_i\) satisfying

\( \frac{K_i}{D_i}\le U_i<\frac{K_i+1}{D_i}. \)

This makes \(K_i\) uniform on \(\{0,\ldots,D_i-1\}\). It can be found by binary search using \(O(1+\log D_i)\) comparisons of the seed with rational thresholds. No arithmetic on the real seed is needed.

Set the rational shift

\( s_i=\frac{K_i\mu_i}{D_i}. \)

For an applicant \(a\in A_i\), rotate its local coordinate:

\( r_i(a)= \begin{cases} a-\alpha_i+s_i,&a-\alpha_i+s_i<\mu_i,\\ a-\alpha_i+s_i-\mu_i,&a-\alpha_i+s_i\ge\mu_i. \end{cases} \)

If \(r_i(a)\in B_{i0}\), leave the applicant unmatched. If \(r_i(a)\in B_{ij}\), define

\( F(a)=\beta_j+d_{ij}+r_i(a)-c_{ij}. \)

Only blocks with \(x_{ij}>0\) are used; feasibility ensures that all their edges belong to \(A\).

6. Verification of the sampler

Each realization is a measure-preserving bijection

For every sampled shift, circular rotation is a measurable, measure-preserving bijection of \([0,\mu_i)\) onto itself.

Its restriction to the preimage of \(B_{ij}\), followed by the displayed translation, is therefore a measure-preserving bijection onto \(T_{ij}\). Its domain has measure \(x_{ij}\).

All target blocks are disjoint and cover all position intervals. Consequently, the union of these maps is a measurable, measure-preserving bijection from the matched applicant subset onto all position intervals. It respects compatibility and matches exactly mass \(x_{ij}\) between every pair of types.

These properties hold for every possible choice of the integers \(K_i\).

Every applicant has the prescribed assignment probabilities

Fix an applicant \(a\in A_i\), and write

\( u=\frac{a-\alpha_i}{\mu_i}\in[0,1), \qquad D_i u=h+v, \)

where \(h\in\{0,\ldots,D_i-1\}\) and \(v\in[0,1)\).

After rotation by \(K_i/D_i\), the normalized coordinate lies in cell

\( (h+K_i)\bmod D_i, \)

with the same within-cell coordinate \(v\). Because \(K_i\) is uniform, this cell index is uniform on all \(D_i\) cells.

Every normalized block is a union of whole cells. The block for position type \(j\) contains exactly \(D_iq_{ij}\) cells. Thus

\( \Pr(F(a)\in P_j) =\frac{D_iq_{ij}}{D_i} =q_{ij} =\frac{x_{ij}}{\mu_i}. \)

Half-open endpoints make this argument valid even at cell boundaries. In particular, it establishes the required assertion for almost every applicant.

Finite descriptions and evaluation

The inverse image of each block under one circular rotation is the union of at most two half-open intervals. On each such interval, \(F\) is translation by a rational constant.

A realized matching therefore has a description with at most \(2e\) pieces, each specifying rational domain endpoints, its target type, and a rational translation. This description can be constructed directly from \(x\) and the sampled \(K_i\).

Point evaluation consists of interval-membership comparisons and applying a rational translation. For rational input coordinates, these are exact rational operations; for a general coordinate, the output is specified by the corresponding rational affine expression. Inverse evaluation is also available by locating the target block and undoing its translation and circular shift.

The random seeds are used only in comparisons with rational thresholds.

7. Sampler complexity and conclusion

Let \(B\) bound the bit lengths of the computed rational flow coordinates and input masses. Section 4 shows that \(B\) is polynomial in \(m,\tau,L\).

Each normalized block length has polynomial bit length. Since \(D_i\) is a product of at most \(m+1\) denominators,

\( \log D_i=O((m+1)B). \)

Thus the integers \(D_i\), sampled integers \(K_i\), shifts, piece endpoints, and translation constants all have polynomial encoding length. Computing them requires polynomial bit time.

Sampling uses

\( O\!\left(\tau+\sum_i\log D_i\right) \)

arithmetic operations and seed comparisons. Constructing the piecewise matching description uses polynomially many rational operations. Scanning its at most \(2e\) pieces gives polynomial point-evaluation time. These are worst-case polynomial bounds, and hence also polynomial expected bounds.

Accordingly, the exact rational optimal flow and the required sampler can both be produced with the stated polynomial guarantees.
