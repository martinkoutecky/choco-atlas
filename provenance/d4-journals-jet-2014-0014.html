The continuous mirror question, as graded

Given a finite-support rational distribution \(\mu\) over consumer types \(a\), each specified by a finite history \(\{(B_{a,r},x_{a,r})\}_{r\in R_a}\) with explicit rational polyhedral-union budgets, decide whether every type with \(\mu_a>0\) has a locally non-satiated, quasi-concave utility rationalizing its history; equivalently, test Proposition 1’s linear feasibility system for each supported type.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) consumer types with positive binary-rational masses \(\mu_a\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) goods. Each type \(a\) has a nonempty finite history \(\{(B_{a,r},x_{a,r})\}_{r\in R_a}\), with rational chosen bundles \(x_{a,r}\in B_{a,r}\subseteq\mathbb R_+^m\).
Each budget is explicitly represented as \(B_{a,r}=\bigcup_{j=1}^{\ell_{a,r}}B_{a,r}^j\), where \(\ell_{a,r}\geq1\) and \(B_{a,r}^j=\{x\in\mathbb R_+^m:q_{a,r}^{j,i}\cdot x\leq1\text{ for every }i\}\), using a nonempty finite list of rational vectors \(q_{a,r}^{j,i}\in\mathbb Q_+^m\). Components are closed, downward closed, and have nonempty interior; boundedness is not required.
A type is rationalizable if there exists a locally non-satiated, quasi-concave utility \(u_a:\mathbb R_+^m\to\mathbb R\) such that \(u_a(x_{a,r})\geq u_a(x)\) for every \(r\in R_a\) and \(x\in B_{a,r}\). Utilities may differ across types; no continuity or additional monotonicity is imposed.
Let \(N\), \(J\), and \(H\) be the total numbers of observations, polyhedral components, and listed inequalities, respectively, and let \(L\) be the total binary input length. State running times in \(m,\tau,N,J,H,L\).

Is deciding whether every supported type is rationalizable solvable in polynomial time in \(m,\tau,N,J,H,L\), or is it NP-hard?

For a single finite consumer history with these budgets, Cherchye, Demuynck, and De Rock establish an equivalent linear feasibility system and an efficient linear-programming test.
The supplied result does not separately formulate the distribution-over-types decision problem.
