The continuous mirror question, as graded

Given a finite candidate set \(A\), ranking types \(T=L(A)\), and rational masses \(\mu\in\Delta(T)\), compute every \(\rho^\star\in\arg\min_{\rho\in L(A)}\sum_{t\in T}\mu_t d_{\mathrm{swap}}(t,\rho)\), together with the set of top alternatives of the minimizing rankings.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge 2\) candidates, and let \(L(A)\) denote the strict linear orders on \(A\).
A society is given by its support \(S\subseteq L(A)\): the list of its \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in S}\mu_t=1\). Here \(\tau=|S|\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
Using Kendall tau swap distance, define \(K(\mu)=\arg\min_{\rho\in L(A)}\sum_{t\in S}\mu_t d_{\mathrm{swap}}(t,\rho)\) and \(W(\mu)=\{\operatorname{top}(\rho):\rho\in K(\mu)\}\).
Compute every ranking in \(K(\mu)\) and the set \(W(\mu)\), retaining all ties. Let \(B\) be the bit length of this explicit output; state running times in \(m,\tau,L,B\).

Is this computation polynomial in \(m,\tau,L,B\), or is it NP-hard?

The discrete swap-distance minimizers have a maximum-likelihood characterization under independent pairwise errors. Computing a discrete Kemeny ranking is NP-hard even for four input rankings, and its threshold decision problem is NP-complete ([Dwork et al.](https://archives.iw3c2.org/www10/cdrom/papers/577/)).
The identical rational-mass minimizer correspondence is already defined as the Kemeny rule ([Lederer, Peters and Wąs](https://cgi.cse.unsw.edu.au/~plederer/research/sqKemeny.pdf)); the requested general complexity dichotomy is therefore not an open target.

  • Specified explicit enumeration with all ties retained and included output bit length in the polynomial running-time question, because the request to compute every minimizer leaves enumeration complexity unspecified.

Conclusion

The requested computation is NP-hard, even for societies having a unique minimizing ranking. Consequently, an algorithm polynomial in \(m,\tau,L,B\) exists if and only if \(\mathrm{P}=\mathrm{NP}\).

An unconditional algorithm that retains every tie runs in

\[ O\!\left((\tau m^2+m^2 2^m)(L+m)^2+mB\right) \]

bit operations. Below, the hardness proof explicitly handles the output length \(B\).

1. Exact formulation and ordinary hardness

Write \(x\succ_\rho y\) when ranking \(\rho\) places \(x\) before \(y\), and define

\[ F_\mu(\rho)=\sum_{t\in S}\mu_t d_{\mathrm{swap}}(t,\rho). \]

Kendall swap distance equals the number of unordered candidate pairs ordered differently. Indeed, an adjacent swap changes exactly one pair, giving the lower bound; sorting one ranking into the other by adjacent inversion swaps attains that bound.

Thus the objective is precisely the rational-weighted Kemeny objective defined by [Lederer, Peters and Wąs, Section 2](https://cgi.cse.unsw.edu.au/~plederer/research/sqKemeny.pdf).

We use the established theorem that minimizing the sum of Kendall distances to four full rankings is NP-hard, and its threshold decision problem is NP-complete. These hypotheses match our strict rankings and distance. [Dwork et al., Appendix B, Theorem 11](https://archives.iw3c2.org/www10/cdrom/papers/577/)

Given four rankings \(t_1,\ldots,t_4\), assign each occurrence mass \(1/4\), merging identical rankings. This produces support size \(\tau\leq 4\) and

\[ F_\mu(\rho)=\frac14\sum_{i=1}^4 d_{\mathrm{swap}}(t_i,\rho). \]

Hence finding one minimizing ranking is NP-hard. The rational-weighted threshold problem is NP-complete: hardness follows from this construction, while a proposed ranking is a polynomial-size certificate whose rational score can be checked exactly in polynomial time.

This alone does not settle output-sensitive enumeration: the four-ranking instance might have exponentially many minimizers. The next construction closes that gap.

2. Hardness with a unique optimum

Start with an arbitrary four-ranking instance on the same candidate set \(A\). Define

\[ N=\binom m2,\qquad C(\rho)=\sum_{i=1}^4 d_{\mathrm{swap}}(t_i,\rho). \]

The score \(C(\rho)\) is an integer.

A gadget that isolates one pair

Enumerate the unordered pairs as \(\{x_j,y_j\}\), for \(j=0,\ldots,N-1\), choosing an orientation \((x_j,y_j)\) for each. Let \(R_j\) be any ranking of the remaining candidates, and form

\[ u_j=(x_j,y_j,R_j),\qquad v_j=(R_j^{\mathrm{rev}},x_j,y_j). \]

Both rankings place \(x_j\) before \(y_j\). They disagree on every other pair: pairs within \(R_j\) are reversed, and every remaining candidate lies below \(x_j,y_j\) in \(u_j\) and above them in \(v_j\).

Define \(b_j(\rho)=1\) if \(y_j\succ_\rho x_j\), and \(b_j(\rho)=0\) otherwise. Every pair other than \(\{x_j,y_j\}\) contributes exactly one disagreement to the sum of the two distances. Therefore

\[ d_{\mathrm{swap}}(u_j,\rho)+d_{\mathrm{swap}}(v_j,\rho) =N-1+2b_j(\rho). \]

The binary code

\[ H(\rho)=\sum_{j=0}^{N-1}2^j b_j(\rho) \]

is injective on rankings. Distinct strict rankings disagree on some pair, so their binary vectors, and hence their codes, differ. Also,

\[ 0\leq H(\rho)\leq 2^N-1. \]

Positive dyadic masses

Give each original ranking occurrence integer weight

\[ M=2^{N+1}, \]

and give each of \(u_j,v_j\) integer weight \(2^j\). Their total weight is

\[ T=4M+2(2^N-1). \]

To obtain dyadic masses, set \(P=2^{N+4}\) and \(h=(P-T)/2\). Since \(P>T\) and both are even, \(h\) is a positive integer. Add an arbitrary ranking \(z\) and its reversal, each with weight \(h\). Divide every weight by \(P\), merging identical rankings.

This defines a valid society \(\nu\): all supported masses are positive, sum to one, and are dyadic rationals. Its support size satisfies

\[ \tau'\leq 2N+6. \]

Since \(z\) and its reversal disagree on every pair,

\[ d_{\mathrm{swap}}(z,\rho)+d_{\mathrm{swap}}(z^{\mathrm{rev}},\rho)=N. \]

Combining these identities gives

\[ P F_\nu(\rho) =M C(\rho)+(N-1)(2^N-1)+2H(\rho)+hN. \]

Preservation and uniqueness

Let \(C_{\min}=\min_\rho C(\rho)\). If \(C(\rho)>C_{\min}\) and \(C(\sigma)=C_{\min}\), integrality gives

\[ P\bigl(F_\nu(\rho)-F_\nu(\sigma)\bigr) \geq M-2(2^N-1)=2>0. \]

Thus every minimizer for \(\nu\) minimizes the original score \(C\). Among those original minimizers, the new objective minimizes \(H\). Injectivity of \(H\) makes that minimizer unique.

Every constructed weight has \(O(N)\) bits. Including the explicit rankings, the new input length satisfies

\[ L'=O\!\left((N+1)(N+m\log m)\right), \]

which is polynomial in \(m\). Because the optimum is unique, both the ranking list and its winner set have total output length \(B'=O(m\log m)\).

Therefore, an algorithm polynomial in \(m,\tau,L,B\), applied to this society, would return an original optimal ranking in polynomial time. Evaluating its score would solve the NP-complete four-ranking threshold problem.

This proves the claimed output-sensitive hardness.

3. An exact algorithm retaining all ties

Write each mass as \(\mu_t=a_t/b_t\), and clear denominators:

\[ D=\prod_{t\in S}b_t,\qquad q_t=a_t(D/b_t). \]

These integers have \(O(L)\) bits, and \(\sum_t q_t=D\). For distinct candidates \(x,y\), define the integer cost of placing \(x\) before \(y\):

\[ c(x,y)=\sum_{\substack{t\in S\\ y\succ_t x}}q_t. \]

Each disagreement is counted exactly once, so

\[ D F_\mu(\rho)=\sum_{x\succ_\rho y}c(x,y). \]

Subset dynamic program

For \(T\subseteq A\), let \(f(T)\) be the minimum pair cost of a ranking of \(T\). Set \(f(\varnothing)=0\). For nonempty \(T\),

\[ f(T)=\min_{x\in T} \left( f(T\setminus\{x\})+\sum_{y\in T\setminus\{x\}}c(x,y) \right). \]

To justify the recurrence, fix the first candidate \(x\). Every pair involving \(x\) contributes the displayed sum. All remaining contributions come from the suffix, whose least possible cost is \(f(T\setminus\{x\})\). Taking the minimum over all possible first candidates exhausts every ranking.

Store every minimizing choice:

\[ E(T)= \left\{ x\in T: f(T)=f(T\setminus\{x\})+ \sum_{y\in T\setminus\{x\}}c(x,y) \right\}. \]

Starting at \(A\), recursively choose any \(x\in E(T)\), append \(x\), and continue with \(T\setminus\{x\}\).

Every resulting ranking has cost \(f(A)\). Conversely, every optimal ranking must choose a minimizing first candidate and an optimal suffix at each step, so this traversal outputs every element of \(K(\mu)\). Different choice sequences give different rankings.

Moreover,

\[ W(\mu)=E(A), \]

because every minimizing first choice admits an optimal suffix.

Running time

Computing the pair costs uses \(O(\tau m^2)\) integer additions after denominator conversion. Evaluating all subset recurrences directly uses \(O(m^2 2^m)\) additions and comparisons. Scores are at most \(D\binom m2\), hence have \(O(L+\log m)\) bits.

Let \(r=|K(\mu)|\). The enumeration tree has at most \(1+mr\) nodes: every node is a prefix of an output ranking. Traversing stored choices costs \(O(m)\) bit operations per edge using subset masks; writing the output costs \(O(B)\). Since \(B\) contains \(r\) explicit rankings, this gives an enumeration bound \(O(mB)\).

A conservative total bit-operation bound is therefore

\[ O\!\left((\tau m^2+m^2 2^m)(L+m)^2+mB\right). \]

4. Why the characterization is exact

Output length can itself be enormous. With mass \(1/2\) on a ranking and mass \(1/2\) on its reversal, every ranking has score \(N/2\). Thus \(K(\mu)=L(A)\), and the explicit output contains \(m!\) rankings.

Conversely, suppose \(\mathrm{P}=\mathrm{NP}\). The predicate “some ranking extending this prefix has integer score at most \(s\)” belongs to \(\mathrm{NP}\): an extending ranking is a certificate, and its score is polynomial-time checkable.

Binary search over \(0,\ldots,DN\) then finds the optimum using \(O(L+\log m)\) polynomial-time predicate calls. Recursively testing every possible next candidate at that optimum enumerates precisely the optimal rankings. There are at most \(1+mr\) feasible prefixes and at most \(m\) tests per prefix, giving total time polynomial in \(m,\tau,L,B\).

Together with Section 2, this proves the equivalence.
