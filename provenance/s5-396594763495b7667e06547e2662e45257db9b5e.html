The continuous mirror question, as graded

Given a project set \(P\), costs \(c\), budget \(b\), and a finite-support rational distribution \(\mu\) over approval ballots with \(q_p=\sum_{t:p\in t}\mu_t>0\) for every project \(p\), decide whether there is a bundle \(\pi\subseteq P\) with \(c(\pi)\le b\) such that every type \(t\) with \(\mu_t>0\) has \(\sum_{p\in\pi\cap t}c(p)/q_p\ge\min\{b,\sum_{p\in t}c(p)/q_p\}\).

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a set of \(m\) indivisible projects, with positive integer costs \(c(p)\) and a positive integer budget \(b\), all encoded in binary; write \(c(S)=\sum_{p\in S}c(p)\).
A society is given by its support: the list of the \(\tau\) distinct approval types \(t\subseteq P\) with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Empty approval types are allowed. Here \(\tau\) is the support size, not the number of possible approval types.
Require \(q_p=\sum_{t:p\in t}\mu_t>0\) for every \(p\in P\). Define \(s_t(S)=\sum_{p\in S\cap t}c(p)/q_p\) and \(f_t=\min\{b,s_t(t)\}\).
The decision problem asks whether some bundle \(\pi\subseteq P\) satisfies \(c(\pi)\le b\) and \(s_t(\pi)\ge f_t\) for every supported type \(t\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For an explicitly listed finite electorate, feasibility of fair share is NP-complete, even with unit project costs; each voter's share divides project costs by their numbers of supporters, and their entitlement is capped at the budget divided by the electorate size. No separate complexity result for the binary-rational mass formulation is supplied.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: supported masses sum to one.
  • Specified positive integer costs and a positive integer budget, encoded in binary, following the discrete model's natural-number domain.
  • Allowed empty approval types, consistent with unrestricted approval subsets in the discrete definition.
  • Defined L as the total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when every project has unit cost. Consequently, a polynomial-time algorithm in \(m,\tau,L\) exists only if \(\mathrm{P}=\mathrm{NP}\).

The proof uses the finite-electorate hardness result supplied in the question and an explicit polynomial-time reduction.

1. Reduction from an explicitly listed electorate

Consider a finite-electorate instance with \(n\ge 1\) explicitly listed voters. Write \(t_i\) for voter \(i\)'s approval set and
\(d_p=|\{i:p\in t_i\}|\) for the number of supporters of project \(p\).

For every voter, define the finite-electorate share and entitlement by
\[ \]
\(h_i(S)=\sum_{p\in S\cap t_i}c(p)/d_p\) and
\(F_i=\min\{b/n,h_i(t_i)\}\).
The supplied hardness premise states that deciding whether a budget-feasible bundle satisfies \(h_i(S)\ge F_i\) for every voter is \(\mathrm{NP}\)-complete, even with unit costs.

Removing unsupported projects. Delete every project with \(d_p=0\). Such projects belong to no approval set, so removing them from any bundle preserves every voter's share and cannot increase its cost. Conversely, any feasible bundle in the reduced instance is feasible in the original instance. Thus this deletion preserves the answer.

If no projects remain, the instance is feasible: the empty bundle gives every voter their zero entitlement. Map this case to the fixed yes-instance consisting of one unit-cost project, budget one, and one approving type of mass one.

Otherwise, retain the remaining projects, their costs, and the budget. Group voters by identical approval sets. For each distinct approval type \(t\), let
\(a_t=|\{i:t_i=t\}|\), and assign it mass
\(\mu_t=a_t/n\).

These masses are positive, sum to one, and require \(O(\log(n+1))\) bits each for their binary-encoded numerator and denominator. The support size satisfies \(\tau\le n\). Empty approval types are retained if present.

For every retained project,
\(q_p=\sum_{t:p\in t}a_t/n=d_p/n>0\),
so the constructed instance satisfies the required positivity hypothesis.

2. Exact preservation of feasibility

Fix a voter \(i\) with approval type \(t\). For every bundle \(S\),
\(s_t(S)=\sum_{p\in S\cap t}c(p)/(d_p/n)=n\,h_i(S)\).

Its mass-formulation entitlement therefore satisfies
\(f_t=\min\{b,n\,h_i(t_i)\}=n\min\{b/n,h_i(t_i)\}=nF_i\).

Since \(n>0\), we obtain the exact equivalence
\(s_t(S)\ge f_t\) if and only if \(h_i(S)\ge F_i\).

Voters with identical approval sets have identical constraints. Consequently, replacing all their constraints by the single supported-type constraint preserves feasibility in both directions. The budget constraint is unchanged.

The construction is polynomial in the explicitly listed source input: approval sets can be grouped by sorting their incidence vectors, and multiplicities are counted without expanding any compressed electorate. Its output has length
\(L=O(\tau m+\tau\log(n+1)+m+\log(b+1))\)
for unit-cost instances. This is polynomial in the source input length.

Hence the given finite-electorate hardness result transfers to the mass formulation, already with unit costs.

3. Polynomial-time exact verification

A certificate is a bundle \(\pi\), represented by \(m\) selection bits. We show that all its constraints can be checked using polynomially many bit operations.

Write each input mass as \(\mu_t=u_t/v_t\), where \(u_t,v_t\) are positive integers. Set
\(D=\prod_t v_t\) and
\(A_p=\sum_{t:p\in t}u_t(D/v_t)\).

Then \(q_p=A_p/D\). Because \(0<q_p\le1\), we have \(1\le A_p\le D\). The bit length of \(D\), and hence of every \(A_p\), is \(O(L)\).

For \(m\ge1\), set
\(K=\prod_{p\in P}A_p\) and
\(W_p=c(p)D(K/A_p)\).
Each \(W_p\) is an integer, and
\(s_t(S)=K^{-1}\sum_{p\in S\cap t}W_p\).

Thus the constraint for type \(t\) is exactly the integer comparison
\(\sum_{p\in\pi\cap t}W_p\ge\min\{bK,\sum_{p\in t}W_p\}\).

The integers \(K,W_p,bK\), and the relevant sums all have \(O(mL)\) bits: products involve at most \(m\) factors of \(O(L)\) bits, and summing at most \(m\) terms adds only \(O(\log(m+1))\) bits.

The construction and verification use \(O(m\tau+m)\) elementary integer operations. Using elementary multiplication and division, each takes at most \(O((mL)^2)\) bit operations. Therefore a conservative verification bound is
\(O(\tau m^3L^2)\).
The budget comparison \(c(\pi)\le b\) also fits within this bound. The case \(m=0\) is immediately feasible.

This proves membership in \(\mathrm{NP}\). It also gives an exhaustive decision algorithm running in
\(O(2^m\tau m^3L^2)\)
for \(m\ge1\).

Together with the reduction, this completes the proof of \(\mathrm{NP}\)-completeness.
