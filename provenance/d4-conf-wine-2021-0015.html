The continuous mirror question, as graded

Given finite item types \(G\), valuation types \(\Theta\), rational masses \(\mu\) with \(\sum_{\theta}\mu_\theta=1\), rational per-capita supplies \(\beta_g\), and additive valuations \(v_\theta\), compute nonnegative masses \(\lambda_{\theta,B}\) for integral bundles \(B\subseteq G\) satisfying \(\sum_B\lambda_{\theta,B}=\mu_\theta\) and \(\sum_{\theta,B:g\in B}\lambda_{\theta,B}=\beta_g\), together with subsidies \(p_{\theta,B}\ge0\) satisfying \(v_\theta(B)+p_{\theta,B}\ge v_{\theta'}(B')+p_{\theta',B'}\) for all occupied pairs, minimizing \(\chi_\infty=\sum_{\theta,B}\lambda_{\theta,B}p_{\theta,B}\); in particular, determine whether one can distinguish \(\chi_\infty\le a\) from \(\chi_\infty\ge a+3\cdot10^{-4}V\), where \(V=\sum_\theta\mu_\theta v_\theta(G)\).

Packaged proof task (what the prover saw — nothing else)

Let \(G\) contain \(m\geq1\) item types. A society is given by its support: the list \(\Theta\) of \(\tau\) valuation types with positive masses \(\mu_\theta\), each a binary rational, with \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has nonnegative rational additive valuations \(v_\theta\). Supplies \(\beta_g\in[0,1]\) and a threshold \(a\geq0\) are binary rationals; \(L\) is the total input bit length. Assume \(V:=\sum_\theta\mu_\theta v_\theta(G)>0\).
An individual receives an integral bundle \(B\subseteq G\), possibly empty, containing at most one item of each type. Choose real masses \(\lambda_{\theta,B}\geq0\) satisfying \(\sum_{B\subseteq G}\lambda_{\theta,B}=\mu_\theta\) and \(\sum_{\theta,B:g\in B}\lambda_{\theta,B}=\beta_g\) for every \(g\in G\).
Each occupied pair \((\theta,B)\), meaning \(\lambda_{\theta,B}>0\), receives a real subsidy \(p_{\theta,B}\geq0\). Require \(v_\theta(B)+p_{\theta,B}\geq v_\theta(B')+p_{\theta',B'}\) for every ordered pair of occupied pairs, including pairs of the same valuation type; indifference is allowed.
Let \(\chi_\infty\) be the minimum of \(\sum_{\theta,B}\lambda_{\theta,B}p_{\theta,B}\) over these allocations and subsidies.

Can the promised cases \(\chi_\infty\leq a\) and \(\chi_\infty\geq a+3\cdot10^{-4}V\) be distinguished in time polynomial in \(m,\tau,L\), or is this promise problem NP-hard?

For finitely many agents receiving a partition of indivisible goods, minimizing total nonnegative subsidies is NP-hard to approximate within additive error \(3\cdot10^{-4}\sum_i v_i(G)\). [Source](https://cs.au.dk/~iannis/publ/C105-wine21.pdf)
For the different model of interim envy-free lotteries over matchings, polynomial-time algorithms attain optimal expected subsidy while allowing arbitrarily small violations of interim envy-freeness and payments depending on the agent and realized allocation. [Source](https://cs.au.dk/~iannis/publ/C103-ec21.pdf)

Result

The promise problem is \(\mathrm{NP}\text{-hard}\). In fact, it is \(\mathrm{NP}\text{-hard}\) to distinguish \(\chi_\infty=0\) from \(\chi_\infty>V/2\), even when all masses and supplies are dyadic rationals and \(a=0\).

The proof below is a direct reduction for the stated mass formulation.

1. Source problem and an envy-freeness observation

We reduce from proper graph \(4\)-colorability. This is \(\mathrm{NP}\text{-hard}\): adding a new vertex adjacent to every original vertex transforms graph \(3\)-colorability into graph \(4\)-colorability. Indeed, the new vertex’s color is unavailable to all original vertices, and any proper \(3\)-coloring extends by assigning the new vertex a fourth color. We use the classical \(\mathrm{NP}\)-completeness of graph \(3\)-colorability. [Garey, Johnson, and Stockmeyer](https://doi.org/10.1016/0304-3975%2876%2990059-1)

First observe that, in any feasible allocation, all occupied bundles of a given type \(\theta\) give the same utility. Applying envy-freeness in both directions between two such bundles gives equality. Denote this common utility by \(U_\theta\). Thus every occupied pair satisfies

\(p_{\theta,B}=U_\theta-v_\theta(B)\),

and every type \(\theta\) and occupied pair \((\eta,B)\) satisfy

\(U_\theta\geq v_\theta(B)+p_{\eta,B}\).

These facts hold regardless of how a type’s mass is split.

2. Construction

Let \(F=(X,E)\) be a simple undirected graph, with \(n=|X|\geq1\). Use four colors, indexed by \(\{1,2,3,4\}\).

Introduce the following item types:

  • A color item \(g_{x,c}\) for every vertex \(x\) and color \(c\).
  • One distinguished item \(A\).
  • One private marker \(b_t\) for each auxiliary valuation type \(t\) defined below.

There are \(C:=n+4|E|\) auxiliary types:

  • A vertex type \(t_x\) for each vertex \(x\).
  • An edge-color type \(t_{e,c}\) for each edge \(e=\{x,y\}\) and color \(c\).

Also introduce a zero-valued type \(z\), an anchor type \(h\), and a selector type \(s\). Their valuations and masses are:

| Type | Items with positive value | Mass |
|---|---|---|
| \(z\) | None | \(\mu_z\) |
| \(h\) | \(v_h(A)=1\) | \(\varepsilon\) |
| \(s\) | \(v_s(A)=n\); \(v_s(g_{x,c})=1\) for all \(x,c\) | \(\varepsilon\) |
| \(t_x\) | Its marker and the four items \(g_{x,c}\), each valued \(1\) | \(d\) |
| \(t_{e,c}\), where \(e=\{x,y\}\) | Its marker, \(g_{x,c}\), and \(g_{y,c}\), each valued \(1\) | \(d\) |

All unlisted item values are zero, and valuations are additive.

Let \(Q\) be the smallest power of two at least \(C\), and let \(R\) be the smallest power of two at least \(n+1\). Set

\(d=\dfrac{1}{4Q},\qquad \varepsilon=\dfrac{1}{64QR},\qquad \mu_z=1-Cd-2\varepsilon.\)

Set supplies

\(\beta_{g_{x,c}}=\varepsilon/4,\qquad \beta_A=\varepsilon,\qquad \beta_{b_t}=d,\)

and set \(a=0\).

All masses are positive and sum to one. In particular,

\(\mu_z\geq \dfrac34-\dfrac1{32}=\dfrac{23}{32}.\)

All masses and supplies are dyadic rationals.

3. Completeness: a proper coloring gives zero subsidy

Suppose \(f:X\to\{1,2,3,4\}\) is a proper coloring.

Give type \(z\) the empty bundle, type \(h\) the bundle \(\{A\}\), and every auxiliary type its own marker. For the selector, take the four cyclic permutations of the colors of \(f\). Each permutation defines a bundle containing exactly one color item per vertex. Give each of these four bundles selector mass \(\varepsilon/4\).

Every color item appears in exactly one of the four selector bundles. Consequently, all supply and type-mass constraints hold exactly.

Set every subsidy to zero. Envy-freeness follows as follows:

  • Type \(z\) values every bundle at zero.
  • Type \(h\) receives its only positively valued item.
  • Type \(s\) values every selector bundle and the anchor bundle at \(n\), and every other occupied bundle at zero.
  • Each vertex type receives value \(1\) and values every selector bundle at exactly \(1\).
  • Each edge-color type receives value \(1\). Because the coloring is proper, every selector bundle contains at most one of its two positively valued color items, so it values every such bundle at most \(1\).
  • An auxiliary type values every other auxiliary type’s marker, the anchor bundle, and the empty bundle at zero.

Thus every ordered envy inequality holds, including comparisons within a type. Nonnegativity of subsidies now gives

\(\chi_\infty=0.\)

4. Soundness: subsidy below one forces a proper coloring

Consider any feasible allocation. Since type \(z\) has zero valuations, the observation in Section 1 shows that all its occupied pairs receive the same subsidy. Write this subsidy as \(c:=U_z\).

Envy-freeness from type \(z\) to every occupied pair gives

\(p_{\theta,B}\leq c.\)

We prove that \(c<1\) implies that \(F\) has a proper \(4\)-coloring.

4.1. The anchor exhausts item \(A\)

Since \(\beta_A=\varepsilon>0\), some occupied bundle contains \(A\). Comparing type \(h\) with that pair gives \(U_h\geq1\), because its subsidy is nonnegative.

An occupied anchor bundle lacking \(A\) would have value zero and therefore require subsidy \(U_h\geq1\). This contradicts the bound \(p_{\theta,B}\leq c<1\).

Hence every anchor individual receives \(A\). Anchor mass and supply are both \(\varepsilon\), so no other type receives \(A\).

4.2. Every selector bundle contains at least \(n\) color items

Comparing type \(s\) with an occupied anchor pair gives

\(U_s\geq n+p_{h,B}\geq n.\)

A selector bundle cannot contain \(A\), and its value is therefore its integer number of color items. For every occupied selector bundle \(B\),

\(v_s(B)=U_s-p_{s,B}\geq n-c>n-1.\)

Thus every occupied selector bundle contains at least \(n\) color items.

4.3. Auxiliary types forbid all coloring violations

Fix an auxiliary type \(t\), and let \(S_t\) be its positively valued color items. For a vertex type, \(|S_t|=4\); for an edge-color type, \(|S_t|=2\).

The total population mass receiving at least one item from \(S_t\) is bounded by the sum of their supplies:

\(\displaystyle \sum_{\theta,B:\,B\cap S_t\neq\varnothing}\lambda_{\theta,B} \leq \sum_{g\in S_t}\beta_g \leq\varepsilon. \)

Since

\(\varepsilon<d=\mu_t,\)

some positive mass of type \(t\) receives bundles containing no item of \(S_t\). Choose one such occupied pair. Its bundle has value at most \(1\), since its only remaining positively valued item is its private marker. Therefore

\(U_t\leq1+c<2.\)

For any occupied pair \((\theta,B)\), envy-freeness and nonnegative subsidies give

\(v_t(B)\leq v_t(B)+p_{\theta,B}\leq U_t<2.\)

Consequently, no occupied bundle contains two items from \(S_t\).

Applying this to all auxiliary types establishes:

  • For each vertex \(x\), every occupied bundle contains at most one of its four color items.
  • For every edge \(\{x,y\}\) and color \(c\), no occupied bundle contains both \(g_{x,c}\) and \(g_{y,c}\).

Every occupied selector bundle contains at least \(n\) color items by Section 4.2, and at most one per vertex. It therefore contains exactly one per vertex. The edge-color restrictions make these choices a proper \(4\)-coloring.

The selector has positive mass, so such an occupied bundle exists. This proves the implication.

4.4. Lower bound for noncolorable graphs

If \(F\) is not \(4\)-colorable, every feasible allocation must therefore have \(c\geq1\). Its total subsidy is at least the subsidy paid to type \(z\):

\(\displaystyle \sum_{\theta,B}\lambda_{\theta,B}p_{\theta,B} \geq\mu_zc \geq\mu_z. \)

Thus

\(\chi_\infty\geq\mu_z.\)

This argument allows arbitrary real mass splitting and arbitrarily small positive occupied masses.

5. Feasibility and attainment on the constructed instances

For every graph, a feasible allocation exists with total subsidy below \(1\).

Use the anchor, marker, and empty bundles from Section 3. Give the selector four bundles \(B_c:=\{g_{x,c}:x\in X\}\), each with mass \(\varepsilon/4\). Give subsidy \(1\) to type \(z\) and every auxiliary type, and subsidy zero to the anchor and selector.

The supplies hold exactly. The zero type’s utility is \(1\), and all subsidies are at most \(1\). The anchor’s utility is \(1\), which dominates every other bundle-payment pair under its valuation. The selector’s utility is \(n\); it values the anchor bundle at \(n\), other selector bundles at \(n\), and all remaining bundle-payment pairs at most \(1\).

Each auxiliary type’s utility is \(2\). It values a selector bundle at most \(2\), its own marker with subsidy at \(2\), and every other occupied pair at most \(1\). Hence all envy inequalities hold. Total subsidy is

\(\mu_z+Cd=1-2\varepsilon<1.\)

The minimum is also attained. For any feasible solution of cost at most \(1\), the zero-type argument bounds every occupied subsidy by

\(c\leq1/\mu_z\leq32/23<2.\)

Set unoccupied subsidies to zero. We may therefore restrict all subsidies to \([0,2]\) and all masses to \([0,1]\). In this finite-dimensional compact box, the supply constraints, cost bound, and conditional envy constraints define a closed set. For the latter assertion, if two pairs have positive mass at a limit point, both have positive mass eventually along any convergent sequence, so their envy inequality passes to the limit.

The feasible set in this box is nonempty, and the objective is continuous. It attains a minimum there. Since the exhibited allocation costs less than \(1\), this is also the unrestricted minimum.

6. Gap normalization and encoding size

The normalization is exactly

\(V=d(5n+12|E|)+\varepsilon(5n+1).\)

Here each vertex type has total value \(5\), each edge-color type has total value \(3\), the selector has total value \(5n\), and the anchor has total value \(1\).

Using \(C=n+4|E|\), \(C\leq Q\), and \(n+1\leq R\),

\(d(5n+12|E|)\leq5Cd\leq5/4,\)

and

\(\varepsilon(5n+1)\leq\dfrac{5R}{64QR}\leq5/64.\)

Therefore \(0<V\leq85/64\), while

\(\mu_z\geq23/32=46/64>85/128\geq V/2.\)

The reduction consequently has the following guarantees:

  • If \(F\) is \(4\)-colorable, then \(\chi_\infty=0=a\).
  • Otherwise, \(\chi_\infty\geq\mu_z>V/2>3\cdot10^{-4}V=a+3\cdot10^{-4}V\).

Finally, \(m=4n+C+1\) and \(\tau=C+3\). All valuation entries belong to \(\{0,1,n\}\). Since \(Q<2C\) and \(R<2(n+1)\), every numerical parameter has polynomial encoding length. Thus the construction is a polynomial-time reduction whose outputs always satisfy the required promise.

A polynomial-time distinguisher for the stated promise problem would decide graph \(4\)-colorability. This establishes the claimed \(\mathrm{NP}\text{-hardness}\).
