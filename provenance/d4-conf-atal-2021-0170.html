The continuous mirror question, as graded

Given candidates \(C\), registered ranking types \(t\) with masses \(\mu_t\), eligible ranking types \(t\) with available masses \(\nu_t\), and a target \(c\), decide whether there exist admitted masses \(x_t\in[0,\nu_t]\) such that, for every \(d\ne c\), \(\sum_{t\in\mathcal B}\mu_t\bigl(s_B(t,c)-s_B(t,d)\bigr)+\sum_{t\in\mathcal A}x_t\bigl(s_B(t,c)-s_B(t,d)\bigr)\ge 0\), where \(s_B(t,d)=m-\operatorname{pos}_t(d)\).

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m=|C|\ge 2\) and a target \(c\in C\), types are strict complete rankings of \(C\). Registered types \(\mathcal B\) have fixed positive masses \(\mu_t\); eligible types \(\mathcal A\) have positive available masses \(\nu_t\). These are finite measures, with no requirement that their masses sum to one; either support may be empty, and a ranking may occur in both.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau=|\mathcal A\cup\mathcal B|\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length. State running times in \(m,\tau,L\).
Use Borda with co-winner semantics: ties for the highest score count as winning. Registered mass cannot be removed. Eligible mass is divisible, and there is no admission budget beyond its availability.
The decision problem asks whether there exist real masses \(x_t\in[0,\nu_t]\) such that, for every \(d\in C\setminus\{c\}\), \(\sum_{t\in\mathcal B}\mu_t\bigl(s_B(t,c)-s_B(t,d)\bigr)+\sum_{t\in\mathcal A}x_t\bigl(s_B(t,c)-s_B(t,d)\bigr)\ge 0\), where \(s_B\) denotes the usual Borda score.

Is this continuous Borda voter-addition decision problem in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For explicitly listed indivisible voters, constructive control by adding an unlimited number of voters under Borda is \(\mathrm{NP}\)-complete; deciding positive winning probability under independent attendance is also \(\mathrm{NP}\)-complete. [Imber and Kimelfeld](https://www.ifaamas.org/Proceedings/aamas2021/pdfs/p647.pdf).
No result settling this exact divisible-mass problem was located in the literature search.

Result

The continuous Borda voter-addition decision problem is in \(\mathrm P\), with running time polynomial in \(m,\tau,L\). It is exactly a rational linear-feasibility problem of polynomial encoding length.

1. Linear-programming formulation

Let \(n=|\mathcal A|\le\tau\), and let \(\operatorname{pos}_t(d)\) denote the position of candidate \(d\) in ranking \(t\), counting from \(1\). Under Borda,

\(s_B(t,d)=m-\operatorname{pos}_t(d)\).

For every listed type \(t\) and opponent \(d\ne c\), define

\(a_{dt}=s_B(t,c)-s_B(t,d)=\operatorname{pos}_t(d)-\operatorname{pos}_t(c)\).

These are integers satisfying \(|a_{dt}|\le m-1\). Define the fixed registered margin

\(b_d=\sum_{t\in\mathcal B}\mu_t a_{dt}\).

Consider the following linear feasibility problem, with one real variable \(x_t\) for each \(t\in\mathcal A\):

\(\sum_{t\in\mathcal A}a_{dt}x_t\ge-b_d\quad(d\in C\setminus\{c\}),\)

\(0\le x_t\le\nu_t\quad(t\in\mathcal A).\)

It has \(n\) variables and \(m-1+2n\) inequalities.

Equivalence. For any admissible admission vector \(x\), the final score difference between \(c\) and \(d\) is exactly

\(S_x(c)-S_x(d)=b_d+\sum_{t\in\mathcal A}a_{dt}x_t.\)

Thus an admissible admission vector makes \(c\) a co-winner if and only if it satisfies every displayed inequality. Both directions follow directly from this identity and the availability bounds.

If a ranking belongs to both supports, its fixed contribution appears in \(b_d\), while its additional contribution appears through \(x_t\). Consequently, overlap creates no difficulty.

2. Polynomial encoding length

We verify that constructing the linear program does not produce exponentially long coefficients.

Write each input mass as a positive integer numerator divided by a positive integer denominator. Let \(Q\) be the product of all denominators appearing in registered and eligible masses, taking \(Q=1\) when there are none. Since the sum of their binary encoding lengths is at most \(L\),

\(\log_2 Q\le L.\)

Define integers

\(U_t=Q\mu_t\quad(t\in\mathcal B),\qquad V_t=Q\nu_t\quad(t\in\mathcal A),\)

and change variables to \(y_t=Qx_t\). Because \(Q>0\), this is a bijection between real admission vectors and real scaled vectors satisfying the corresponding bounds. The equivalent system is

\(\sum_{t\in\mathcal A}a_{dt}y_t\ge-R_d,\qquad R_d=\sum_{t\in\mathcal B}U_ta_{dt},\)

\(0\le y_t\le V_t.\)

All coefficients and right-hand sides are now integers. The variables remain real; no integrality constraint is introduced.

Every input numerator has at most \(L\) bits, so \(U_t\) and \(V_t\) have \(O(L+1)\) bits. Moreover,

\(|R_d|\le|\mathcal B|(m-1)\max_{t\in\mathcal B}U_t,\)

with \(R_d=0\) when \(\mathcal B\) is empty. Hence each integer in the system has at most

\(B=O\!\left(L+\log(m+1)+\log(\tau+1)+1\right)\)

bits.

A dense encoding of the complete system therefore has length

\(S=O\!\left((m+\tau+1)(\tau+1)B\right).\)

The ranking positions can be computed by scanning the \(\tau\) listed rankings. Products, exact divisions, and sums used above involve polynomially many integers of polynomial bit length. Thus construction takes time polynomial in \(m,\tau,L\). No unlisted rankings need to be generated.

3. Exact decision and running time

The polynomial-time linear-programming theorem states that feasibility of an explicitly given system of rational linear inequalities over the reals can be decided deterministically in time polynomial in its binary encoding length. See [Aspvall and Stone, *Khachiyan’s Linear Programming Algorithm*](https://pages.cs.wisc.edu/~cs787-1/AspvallStone.pdf).

Its hypotheses hold here:

  • The system is explicitly listed.
  • It has at most \(\tau\) real variables and \(m-1+2\tau\) inequalities.
  • Its coefficients are integers, hence rational.
  • Its encoding length is bounded by \(S\) above.

Apply that exact feasibility algorithm and return its answer. The LP stage takes \(\operatorname{poly}(S)\) bit operations, so the complete running time is \(\operatorname{poly}(m,\tau,L)\).

Exact feasibility handles ties and feasible sets of lower dimension; no positive winning margin is assumed.

If \(\mathcal A\) is empty, simply test whether every registered margin \(b_d\) is nonnegative. If \(\mathcal B\) is empty, choosing every \(x_t=0\) gives all candidates score zero, so the answer is yes under co-winner semantics. These observations also cover completely empty support.

4. Relation to the indivisible problems

The hardness results in [Imber and Kimelfeld](https://www.ifaamas.org/Proceedings/aamas2021/pdfs/p647.pdf) concern selecting subsets of indivisible voters or deciding whether a winning attendance realization exists. Those choices are discrete. Here every eligible mass can range over an interval, and the constraints are linear, so rational linear feasibility settles the problem.

Therefore the stated continuous problem is polynomial-time solvable. Under polynomial-time many-one reductions, it could also be \(\mathrm{NP}\)-hard only if \(\mathrm P=\mathrm{NP}\).
