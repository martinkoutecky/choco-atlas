The continuous mirror question, as graded

Given finitely many page types \(T\), rational masses \(\mu_t>0\) summing to \(1\), and an ergodic rational transition matrix \(P\) on those types, compute each type's rank density \(r_t\). A type-\(t\) page sends probability \(P_{tt'}\) to type \(t'\), distributed uniformly across that type's pages; the aggregate type rank \(q_t=\mu_t r_t\) must satisfy \(q_{t'}=\sum_t q_tP_{tt'}\) and \(\sum_t q_t=1\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) page types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a binary rational row-stochastic matrix \(P\in\mathbb{Q}_{\geq0}^{\tau\times\tau}\), promised irreducible and aperiodic. The society is atomless; transitions from a type-\(t\) page choose destination type \(t'\) with probability \(P_{tt'}\), then sample from the society's conditional mass distribution on that type.
Compute exactly the type rank densities \(r_t\geq0\), represented as binary rationals, defined by \(q_t=\mu_t r_t\), \(q_{t'}=\sum_{t\in T}q_tP_{tt'}\), and \(\sum_{t\in T}q_t=1\). Let \(L\) be the total input bit length; there is no separate alternative-set parameter \(m\).

Is exact computation of these rank densities polynomial-time in \(\tau\) and \(L\), or is it NP-hard?

For finite ergodic Markov chains, the stationary ranking vector coincides with the normalized equilibrium prices of a Cobb–Douglas exchange market having one trader per state, each endowed with one unit of its own good and utility exponents equal to its transition probabilities. [Du](https://arxiv.org/pdf/0910.0513).
The later replacement publication also establishes the equilibrium–PageRank correspondence for finite networks. [Du, Lehrer, and Pauzner](https://www.math.tau.ac.il/~lehrer/Papers/Ranking-%20published.pdf). No result explicitly addressing this precise mass-input computation problem was located.

  • Specified exact binary rational output because the graded question did not specify precision.
  • Made ergodicity explicit as irreducibility and aperiodicity, following the supplied definition.
  • Defined L as total input bit length; no separate m parameter exists in this model.

Result

Exact computation is polynomial-time in \(\tau\) and \(L\). The output consists of rational numbers with polynomially bounded binary encoding length. Thus the computation belongs to \(\mathrm{FP}\); NP-hardness under standard polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).

Here, a binary-encoded rational is represented by an integer numerator and a positive integer denominator, both written in binary.

1. Reduction to the supported types

Label the types by \(1,\ldots,n\), where \(n=\tau\). Regard the stationary probabilities as a column vector \(q\). The required equations are

\(P^{\mathsf T}q=q,\qquad \mathbf 1^{\mathsf T}q=1,\qquad r_i=q_i/\mu_i.\)

The masses therefore enter only in the final divisions.

This reduction also follows directly from the atomless transition rule. Let \(X_i\) be the set of pages of type \(i\), and let \(\nu_i\) be the society’s conditional probability measure on \(X_i\). For any probability measure \(\rho\) on pages and any measurable set \(B\), its distribution after one transition satisfies

\(\displaystyle (\rho K)(B)=\sum_{j=1}^{n}\left(\sum_{i=1}^{n}\rho(X_i)P_{ij}\right)\nu_j(B).\)

Consequently, if \(q\) is stationary for \(P\), then \(\rho=\sum_i q_i\nu_i\) is stationary on pages. Conversely, any stationary page distribution must have this mixture form, and its type probabilities must be stationary for \(P\). Since \(\nu_i\) has density \(1/\mu_i\) relative to the society’s measure on \(X_i\), the corresponding density is exactly \(r_i=q_i/\mu_i\).

Thus no enumeration beyond the supplied support is required.

2. Existence, positivity, and uniqueness

We prove the needed stationary-distribution properties directly. Aperiodicity is unnecessary for these properties; irreducibility suffices.

Existence. Choose a probability column vector \(z\), and define

\(\displaystyle z_N=\frac1N\sum_{k=0}^{N-1}(P^{\mathsf T})^kz.\)

Because \(P\) is nonnegative and row-stochastic, every \(z_N\) lies in the probability simplex. Compactness gives a convergent subsequence with limit \(q\) in that simplex. Moreover,

\(\displaystyle P^{\mathsf T}z_N-z_N=\frac{(P^{\mathsf T})^Nz-z}{N}.\)

Both vectors in the numerator are probability vectors, so the right-hand side tends to zero coordinatewise. Passing to the limit proves \(P^{\mathsf T}q=q\).

Positivity. Some \(q_i\) is positive because its coordinates sum to one. For any \(j\), irreducibility supplies an integer \(k\geq0\) with \((P^k)_{ij}>0\). Stationarity gives

\(\displaystyle q_j=\sum_{\ell=1}^{n}q_\ell(P^k)_{\ell j}\geq q_i(P^k)_{ij}>0.\)

Hence every coordinate is positive.

Uniqueness. Suppose a real vector \(f\) satisfies \(Pf=f\), and choose \(i\) where \(f_i=M=\max_j f_j\). Then

\(\displaystyle M=f_i=\sum_jP_{ij}f_j.\)

This is a convex combination of numbers at most \(M\). Therefore \(f_j=M\) whenever \(P_{ij}>0\). Applying the same argument successively along directed paths, irreducibility implies that every coordinate equals \(M\).

Thus \(\ker(I-P)\) consists exactly of the constant vectors and has dimension one. Transposition preserves rank, so \(\ker(I-P^{\mathsf T})\) also has dimension one. Since it contains the stationary probability vector \(q\), normalization makes \(q\) unique. Positivity of the input masses then makes the densities \(r_i\) unique and positive.

3. A nonsingular rational linear system

Let \(A\) be the matrix obtained from \(I-P^{\mathsf T}\) by replacing its last row with \(\mathbf 1^{\mathsf T}\). Let \(e_n\) be the last standard basis vector. Compute \(q\) from

\(Aq=e_n.\)

We verify that this system is nonsingular and is equivalent to the stationary equations.

Row-stochasticity implies

\(\mathbf 1^{\mathsf T}(I-P^{\mathsf T})=0.\)

Therefore the coordinates of \((I-P^{\mathsf T})x\) sum to zero for every \(x\). If its first \(n-1\) coordinates vanish, its last coordinate also vanishes. This proves that \(Aq=e_n\) imposes all stationary equations together with normalization.

If \(Ax=0\), the same observation gives \((I-P^{\mathsf T})x=0\). The one-dimensional kernel proved above implies \(x=cq\). But the last equation of \(Ax=0\) gives

\(0=\mathbf 1^{\mathsf T}x=c\mathbf 1^{\mathsf T}q=c.\)

Hence \(x=0\), proving that \(A\) is nonsingular. The construction also covers \(n=1\), where \(A=(1)\).

4. Polynomial output length

Let \(D\) be the product of the positive denominators of all entries of \(P\), as supplied in the input. Their total binary encoding length is at most \(L\), so

\(\log_2D\leq L.\)

Set \(C=DA\). Then \(C\) is an integer matrix, and the system becomes

\(Cq=De_n.\)

Since every transition probability lies in \([0,1]\), every entry of \(C\) has absolute value at most \(D\). The same holds for \(De_n\).

Let \(C^{(i)}\) denote \(C\) with column \(i\) replaced by \(De_n\). By nonsingularity and Cramer’s rule,

\(\displaystyle q_i=\frac{\det C^{(i)}}{\det C},\qquad \det C\neq0.\)

For any \(n\)-by-\(n\) matrix whose entries have absolute value at most \(D\), the determinant expansion has \(n!\) terms, each of absolute value at most \(D^n\). Therefore

\(\displaystyle |\det C|,\ |\det C^{(i)}|\leq n!D^n.\)

Their binary lengths are consequently bounded by

\(O\!\left(n(L+\log(n+1))\right).\)

Write the input mass as \(\mu_i=u_i/v_i\), with positive binary-encoded integers \(u_i,v_i\). Then

\(\displaystyle r_i=\frac{v_i\det C^{(i)}}{u_i\det C}.\)

Each of \(u_i,v_i\) has at most \(L\) bits. Thus every density has numerator and denominator length

\(O\!\left(n(L+\log(n+1))+L\right).\)

Reducing a fraction cannot increase these lengths. The total output length is therefore polynomial in \(n\) and \(L\), even when some masses are very small.

5. Polynomial-time exact computation

The determinant formula above bounds output size; the algorithm need not enumerate determinant terms. We now justify polynomial-time determinant computation, including intermediate bit lengths.

Consider any integer matrix \(M\) occurring above, so its entries have absolute value at most \(D\). Apply Gaussian elimination with row pivoting, using exact rational arithmetic and reducing fractions after each operation.

After \(k\) successful pivots, partition the suitably row-permuted original matrix as

\(\displaystyle M=\begin{pmatrix}B&U\\ V&W\end{pmatrix},\)

where \(B\) is the invertible \(k\)-by-\(k\) pivot block. Elimination leaves the active block

\(S=W-VB^{-1}U.\)

For an entry \(s_{ij}=w_{ij}-v_iB^{-1}u_j\), block elimination gives

\(\displaystyle \det\begin{pmatrix}B&u_j\\v_i&w_{ij}\end{pmatrix} =\det(B)\bigl(w_{ij}-v_iB^{-1}u_j\bigr). \)

Indeed, left multiplication by the block matrix with diagonal blocks \(I_k,1\) and lower-left block \(-v_iB^{-1}\) has determinant one and makes the lower-left block zero. Hence

\(\displaystyle s_{ij}= \frac{\det\begin{pmatrix}B&u_j\\v_i&w_{ij}\end{pmatrix}}{\det B}. \)

Both determinants are minors of the original row-permuted matrix. Every minor of order \(h\leq n\) has absolute value at most

\(h!D^h\leq n!D^n.\)

Thus every reduced active entry has polynomially many bits. Pivot selection and the update

\(\displaystyle s'_{ij}=s_{ij}-\frac{s_{i\ell}s_{\ell j}}{s_{\ell\ell}}\)

use a fixed number of arithmetic operations on such rationals. The temporary numerators and denominators also have polynomially many bits, because each operation adds or multiplies only a fixed number of polynomial-length integers.

There are \(O(n^3)\) rational operations per determinant. Integer arithmetic and fraction reduction by the Euclidean algorithm take polynomial time in operand length. If no pivot exists in the current active column, elimination has produced a zero column below the previous pivots, and the determinant is zero. Otherwise, the determinant is the product of the pivots, adjusted for row-swap signs; this product also has polynomial intermediate length.

Compute \(\det C\) and all \(n\) determinants \(\det C^{(i)}\), then form and reduce the fractions for \(r_i\). This uses \(O(n^4)\) rational elimination operations and polynomial total bit time.
