The continuous mirror question, as graded

Given a finite set \(T\) of complete strict rankings over seat categories \(A\), rational type masses \(\mu_t>0\) summing to \(1\), rational per-capita supplies \(q_a\ge 0\) with \(\sum_{a\in A}q_a\ge 1\), and nonnegative rational category values \(w_a\), choose \(x_{ta}\ge 0\) with \(\sum_{a\in A}x_{ta}=\mu_t\) and \(\sum_{t\in T}x_{ta}\le q_a\). For each type \(t\), let \(a^t_1,\ldots,a^t_m\) list its categories from best to worst and define \(F_{t,k}(x)=\sum_{j=1}^{k}x_{t,a^t_j}\). Call feasible \(y\) a Pareto improvement on \(x\) if \(F_{t,k}(y)\ge F_{t,k}(x)\) for every \(t,k\), with strict inequality for some \(t,k\). Find a feasible \(x\) that admits no such improvement and maximizes \(W(x)=\sum_{t\in T}\sum_{a\in A}w_a x_{ta}\) among all such assignments.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a nonempty set of \(m\) seat categories, all acceptable to every type. A society is given by its support: the list \(T\) of \(\tau\) distinct complete strict rankings of \(A\), each with positive mass \(\mu_t\) encoded as a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
Supplies \(q_a\geq0\) and category values \(w_a\geq0\) are binary rationals, with \(\sum_{a\in A}q_a\geq1\); supplies need not be exhausted. Let \(L\) be the total input bit length, and state running times in \(m,\tau,L\).
An assignment is a real matrix \(x\geq0\) satisfying \(\sum_{a\in A}x_{ta}=\mu_t\) for every \(t\) and \(\sum_{t\in T}x_{ta}\leq q_a\) for every \(a\).
Write \(a^t_1,\ldots,a^t_m\) for type \(t\)'s ranking, best first, and set \(F_{t,k}(x)=\sum_{j=1}^{k}x_{t,a^t_j}\). A feasible \(y\) improves \(x\) if \(F_{t,k}(y)\geq F_{t,k}(x)\) for every \(t\in T\) and \(1\leq k\leq m\), strictly for at least one pair. An assignment is efficient if it admits no such improvement.
The optimization problem is to find an efficient assignment maximizing \(W(x)=\sum_{t\in T}\sum_{a\in A}w_ax_{ta}\) among efficient assignments.

Is this optimization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For indivisible objects and individually listed agents, maximizing welfare among Pareto-efficient assignments is NP-hard even with complete strict preferences, nonnegative object-based values, and enough objects to assign everyone ([Biró–Gudmundsson](https://real.mtak.hu/107918/1/CERSIEWP202016.pdf)).
For general rational polyhedra with linear scalar payoffs, the decision version of maximizing a linear objective over Pareto-optimal solutions is NP-complete ([van Rossum–Dollevoet](https://arxiv.org/html/2509.18073v1)); this does not establish complexity for the cumulative-ranking problem defined above. No result settling this exact continuous problem was located.

Result

The optimization problem is \(\mathrm{NP}\text{-hard}\). This holds even when every type and every category has the same positive mass or supply,

\(\mu_t=q_a=1/\tau\),

and every category value belongs to \(\{0,1\}\).

The essential step is to prove that, on appropriately scaled matching instances, fractional assignments cannot improve the optimum over efficient indivisible assignments.

1. Efficiency passes to components of a convex decomposition

Let \(P\) be a convex feasible set, and let \(F_1,\ldots,F_d\) be linear payoffs. Call a point efficient if no feasible point weakly increases every payoff and strictly increases at least one.

Lemma 1. Suppose an efficient point satisfies

\(x=\sum_{j=1}^{s}\lambda_jx^{(j)}\),

where \(x^{(j)}\in P\), every \(\lambda_j>0\), and \(\sum_j\lambda_j=1\). Then every \(x^{(j)}\) is efficient.

Proof. Suppose \(y\in P\) improves \(x^{(j)}\). By convexity,

\(z=\lambda_jy+\sum_{\ell\ne j}\lambda_\ell x^{(\ell)}\)

belongs to \(P\). For every payoff,

\(F_i(z)-F_i(x)=\lambda_j\bigl(F_i(y)-F_i(x^{(j)})\bigr)\).

These differences are nonnegative, and at least one is positive. Thus \(z\) improves \(x\), a contradiction. \(\square\)

This lemma applies to the cumulative-ranking payoffs because every \(F_{t,k}\) is linear.

2. Fractional matching assignments decompose into matchings

Consider \(n\) agents and \(r\ge n\) objects. Each agent receives total mass one, and each object has capacity one. The feasible polytope is

\(P_{n,r}=\{X\in\mathbb R_{\ge0}^{n\times r}:\sum_aX_{ia}=1\text{ for every }i,\ \sum_iX_{ia}\le1\text{ for every }a\}\).

A matching matrix has exactly one entry equal to one in each row and at most one in each column.

Lemma 2. Every \(X\in P_{n,r}\) is a convex combination of matching matrices.

Proof. The column slacks \(s_a=1-\sum_iX_{ia}\) satisfy

\(0\le s_a\le1,\qquad \sum_as_a=r-n\).

Add \(r-n\) rows, each of sum one, distributing these slacks among them. Such a distribution can be constructed by filling the additional rows consecutively from the available column slacks. The resulting matrix \(\widehat X\) is square, nonnegative, and has every row and column sum equal to one.

Here is the standard decomposition argument, including its matching-existence step. Form the bipartite graph of positive entries of \(\widehat X\). For any set \(S\) of rows, all its mass enters its neighboring columns \(N(S)\). Consequently,

\(|S|=\sum_{i\in S}\sum_{a\in N(S)}\widehat X_{ia}\le\sum_{a\in N(S)}\sum_i\widehat X_{ia}=|N(S)|\).

Hall’s theorem therefore gives a perfect matching consisting of positive entries. Let \(D\) be its permutation matrix and let \(\varepsilon\) be the smallest entry of \(\widehat X\) on that matching.

If \(\varepsilon=1\), then \(\widehat X=D\). Otherwise,

\(\widehat X=\varepsilon D+(1-\varepsilon)\widehat X'\),

where \(\widehat X'=(\widehat X-\varepsilon D)/(1-\varepsilon)\) is again doubly stochastic. Its positive support is strictly smaller. Repeating therefore terminates and expresses \(\widehat X\) as a convex combination of permutation matrices.

Restricting these matrices to the original \(n\) rows gives the required matching matrices. \(\square\)

3. For deterministic assignments, the two efficiency notions coincide

Give each agent a complete strict ranking of the objects. For \(X\in P_{n,r}\), use the cumulative-ranking payoffs from the question, with row mass one.

For matching matrices, ordinary Pareto efficiency means that no other matching gives every agent a weakly preferred object and some agent a strictly preferred object.

Lemma 3. A matching matrix is efficient against fractional cumulative-ranking improvements if and only if it is ordinarily Pareto efficient.

Proof.

First, an ordinary Pareto improvement is a cumulative-ranking improvement: moving an agent to a weakly preferred object weakly increases every cumulative payoff, and a strictly preferred object strictly increases at least one. Thus fractional efficiency implies ordinary Pareto efficiency.

Conversely, let \(M\) be ordinarily Pareto efficient, and suppose that \(Y\in P_{n,r}\) cumulatively improves \(M\). Write \(b_i\) for agent \(i\)’s assigned object in \(M\), and \(h_i\) for its rank.

At \(M\), the cumulative payoff at \(h_i\) equals one. Dominance and the row-sum constraint imply

\(F_{i,h_i}(Y)=1\).

Therefore \(Y_{ia}=0\) for every object \(a\) ranked below \(b_i\).

Moreover, strict improvement implies that some agent \(i\) receives positive mass of an object \(a\) ranked strictly above \(b_i\). Indeed, cumulative payoffs at ranks at least \(h_i\) already equal one at \(M\), so a strict increase must occur above that threshold.

By Lemma 2, decompose \(Y\) into matching matrices with positive coefficients. Since all entries are nonnegative, every component uses only objects weakly preferred to the original assignments. Because \(Y_{ia}>0\), some component assigns \(a\) to agent \(i\). That component is an ordinary Pareto improvement of \(M\), a contradiction. \(\square\)

4. The fractional and indivisible optima are equal

Let the welfare of a matrix in \(P_{n,r}\) be

\(\mathcal W(X)=\sum_{i,a}w_aX_{ia}\).

Let \(V_{\mathrm{disc}}\) be the maximum welfare among ordinarily Pareto-efficient matching matrices. Such matchings exist: sequentially letting each agent choose their favorite remaining object produces one.

Proposition. The maximum welfare among efficient fractional matrices in \(P_{n,r}\) equals \(V_{\mathrm{disc}}\).

Proof. Take any efficient fractional matrix \(X\), and decompose it into matching matrices:

\(X=\sum_j\lambda_jM^{(j)}\),

with every \(\lambda_j>0\).

By Lemma 1, every \(M^{(j)}\) is fractionally efficient. By Lemma 3, every \(M^{(j)}\) is ordinarily Pareto efficient. Hence

\(\mathcal W(X)=\sum_j\lambda_j\mathcal W(M^{(j)})\le V_{\mathrm{disc}}\).

Conversely, an ordinarily Pareto-efficient matching attaining \(V_{\mathrm{disc}}\) is fractionally efficient by Lemma 3. Thus the bound is attained. \(\square\)

This is the missing justification for transferring indivisible hardness: allowing fractional assignments does not increase the efficient welfare optimum on these instances.

5. Polynomial reduction with distinct support rankings

The source problem is maximizing object-based welfare among Pareto-efficient indivisible assignments with complete strict preferences and at least as many objects as agents. Biró–Gudmundsson’s Theorem 2 proves this problem \(\mathrm{NP}\text{-hard}\); its construction uses object values in \(\{0,1\}\) and supplies at least as many objects as agents. [Source: Theorem 2 and its proof](https://real.mtak.hu/107918/1/CERSIEWP202016.pdf).

Let a source instance have \(n\) agents and \(r\ge n\) objects. Every Pareto-efficient assignment assigns every agent an object: otherwise, an unassigned agent could receive an unused acceptable object.

Making all rankings distinct

Add \(n\) objects \(d_1,\ldots,d_n\), each with value zero. Every agent ranks all original objects above all added objects. In agent \(i\)’s appended ranking, put \(d_i\) first among the added objects, then list the remaining added objects in any fixed order.

The resulting complete strict rankings are pairwise distinct.

This extension preserves the efficient optimum:

  • Any full matching using an added object leaves an original object unused, because it uses at most \(n-1\) of the \(r\ge n\) original objects. Giving that unused original object to an agent holding an added object strictly improves the matching. Thus every efficient matching uses only original objects.
  • For a matching using only original objects, any Pareto improvement in the extended instance also uses only original objects, because every added object is worse than the current assignment. Its efficiency is therefore exactly its efficiency in the source instance.

Consequently, the maximum efficient welfare is unchanged.

Scaling to the society in the question

Construct a society with

\(\tau=n,\qquad m=r+n\).

Use the extended ranking of agent \(i\) as type \(i\)’s ranking, and set

\(\mu_i=1/n,\qquad q_a=1/n\)

for every type and every category. Retain the original category values and give added categories value zero.

All required hypotheses hold:

  • The support rankings are distinct, complete, and strict.
  • Every type has positive mass, and the masses sum to one.
  • Every supply is positive.
  • Total supply is \(m/n\ge1\).
  • Values belong to \(\{0,1\}\).
  • All numbers have polynomial-length binary rational encodings.

The map

\(X_{ia}=n x_{ia}\)

is a bijection between feasible society assignments and \(P_{n,m}\). It multiplies every cumulative payoff by \(n\), so it preserves efficiency. It also satisfies

\(\mathcal W(X)=nW(x)\).

By the proposition and the dummy-object argument,

\(\max_{x\text{ efficient}}W(x)=V_{\mathrm{source}}/n\).

Thus the optimal value of the continuous problem determines the source optimum exactly.

6. Running time and conclusion

The reduction writes \(\tau\) rankings of \(m\) categories and rational masses and supplies with \(O(\log(\tau+1))\)-bit denominators. Its construction time and output length are polynomial in \(m,\tau,L\).

If a solver returns an optimal fractional assignment, an optimal source matching can also be recovered in polynomial time. Scale the assignment and apply Lemma 2. The decomposition needs at most \(m^2\) matching computations on a bipartite graph with \(m\) vertices on each side. It can be implemented by subtracting matching weights from the unnormalized residual matrix, using rational arithmetic of polynomial bit length. Every resulting component is efficient by Lemma 1; choosing a component of greatest welfare yields an optimal matching. That matching uses only original objects.

Therefore, a solver running in \(\operatorname{poly}(m,\tau,L)\) time would solve the cited indivisible optimization problem in polynomial time. The continuous optimization problem is consequently \(\mathrm{NP}\text{-hard}\), even under the uniform positive masses and supplies stated above.
