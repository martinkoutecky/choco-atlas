Theorem 2.2 — class: hardness

The continuous mirror question, as graded

Given student types \(t\) with population shares \(\rho_t\), a target assignment \(a_{tp}\) to projects, and resource types \(r\) with per-package capacity \(q_r\), compatible-project set \(T_r\), and per-capita supply \(\sigma_r\), does there exist an allocation \(z_{rp}\ge 0\) such that \(z_{rp}=0\) for \(p\notin T_r\), \(\sum_{p\in T_r}z_{rp}=\sigma_r\), and \(\sum_r q_r z_{rp}\ge \sum_t a_{tp}\) for every project \(p\)?

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a set of \(m\ge 1\) projects. A society is given by its support: the list of the \(\tau\) student types with positive masses \(\rho_t\), each a binary rational, with \(\sum_t\rho_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The given target assignment consists of binary rational masses \(a_{tp}\ge 0\), with \(\sum_{p\in P}a_{tp}\le\rho_t\); the remainder is unmatched. Positive assignments are assumed mutually acceptable.
There are \(k\) resource types. Each has capacity per package \(q_r\in\mathbb N_{>0}\), an explicitly listed nonempty compatible set \(T_r\subseteq P\), and binary rational supply \(\sigma_r>0\), measured in packages per unit student population; resource supplies need not sum to one.
Resource mass is divisible. A feasible allocation is a real array \(z_{rp}\ge 0\) satisfying \(z_{rp}=0\) for \(p\notin T_r\), \(\sum_{p\in T_r}z_{rp}=\sigma_r\) for every \(r\), and \(\sum_r q_rz_{rp}\ge\sum_t a_{tp}\) for every \(p\). Thus all resources must be allocated, and excess capacity is allowed.
Let \(L\) be the total binary input length; state running times in \(m,\tau,k,L\).

Is deciding whether a feasible allocation exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite students and indivisible resources, feasibility of a given matching is \(\mathrm{NP}\)-complete, even when every resource is compatible with every project. [Source](https://arxiv.org/pdf/1808.08813v3)
No result settling this exact continuous problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized student population shares to sum to one; resource supplies are measured relative to that population and are not independently normalized.
  • Interpreted a_{tp} as assigned population mass, rather than a conditional fraction of type t; required nonnegative binary rational entries with row sum at most rho_t, allowing unmatched mass.
  • Treated the target assignment as already mutually acceptable, as the discrete input is a matching; preferences are unnecessary for this feasibility question.
  • Retained positive integer per-package capacities from the discrete definition; took resource supplies to be positive binary rationals, omitting zero-supply types.
  • Required at least one project and nonempty compatibility sets for supplied resource types, excluding resources that cannot be allocated anywhere.
  • Made resource mass divisible with real allocation variables, while retaining mandatory allocation of every resource and permitting unused capacity.

Result

The decision problem is in \(\mathrm P\). Moreover, whenever a feasible allocation exists, a rational feasible allocation can be constructed in polynomial time.

The proof uses the given support of size \(\tau\); it does not enumerate any other student types.

1. Aggregate demand and resource capacity

For each project \(p\), define its demand by
\(d_p=\sum_{t=1}^{\tau}a_{tp}\), and let \(D=\sum_{p\in P}d_p\).
The assignment assumptions imply
\(0\le D\le\sum_{t=1}^{\tau}\rho_t=1\).

For each resource type \(r\), define its total capacity by
\(c_r=q_r\sigma_r\).

Since \(q_r>0\), the change of variables \(x_{rp}=q_rz_{rp}\) is invertible. Thus feasibility is equivalent to the existence of nonnegative capacity allocations satisfying

  • \(x_{rp}=0\) whenever \(p\notin T_r\);
  • \(\sum_{p\in T_r}x_{rp}=c_r\) for every \(r\);
  • \(\sum_r x_{rp}\ge d_p\) for every \(p\).

This change of variables is valid because resource mass is divisible.

2. An exact maximum-flow formulation

Construct a directed network with source \(s\), sink \(u\), one vertex \(R_r\) for each resource type, and one vertex \(P_p\) for each project. Its arcs and capacities are:

| Arc | Condition | Capacity |
|---|---|---|
| \(s\to R_r\) | Every resource type \(r\) | \(c_r\) |
| \(R_r\to P_p\) | \(p\in T_r\) | \(c_r\) |
| \(P_p\to u\) | Every project \(p\) | \(d_p\) |

All capacities are nonnegative rationals. The total capacity entering the sink is \(D\), so every flow has value at most \(D\).

Claim. A feasible allocation exists if and only if this network admits a flow of value \(D\).

A feasible allocation gives a flow of value \(D\)

Suppose \(x\) satisfies the allocation conditions above. Write \(b_p=\sum_r x_{rp}\), so \(b_p\ge d_p\). Define
\(\lambda_p=d_p/b_p\) when \(b_p>0\), and \(\lambda_p=0\) when \(b_p=0\). In the latter case, \(d_p=0\). Consequently, \(0\le\lambda_p\le1\).

Send \(f_{rp}=\lambda_px_{rp}\) along \(R_r\to P_p\). Then

\(\sum_r f_{rp}=d_p\)

for every project, while

\(\sum_{p\in T_r}f_{rp}\le\sum_{p\in T_r}x_{rp}=c_r\)

for every resource type. Each individual \(f_{rp}\) is also at most \(c_r\).

Set the flow on \(s\to R_r\) to \(\sum_p f_{rp}\), and the flow on \(P_p\to u\) to \(d_p\). These choices satisfy every capacity constraint and flow-conservation equation. The resulting flow has value \(D\).

A flow of value \(D\) gives a feasible allocation

Suppose a flow of value \(D\) exists, and denote its resource-to-project flows by \(f_{rp}\).

Every arc \(P_p\to u\) is saturated: their capacities sum to \(D\), and their flows sum to \(D\), so their nonnegative unused capacities sum to zero. Hence
\(\sum_r f_{rp}=d_p\) for every project.

For each resource type, define its unused capacity by
\(\ell_r=c_r-\sum_{p\in T_r}f_{rp}\ge0\).
Choose any \(p_r\in T_r\), which is possible because \(T_r\) is nonempty. Define \(x\) by adding all of \(\ell_r\) to the entry \(f_{r p_r}\), leaving the other entries in row \(r\) unchanged.

This construction allocates exactly \(c_r\) capacity from each resource type, respects compatibility, and gives every project at least its demand. Finally, set \(z_{rp}=x_{rp}/q_r\). Then
\(\sum_{p\in T_r}z_{rp}=c_r/q_r=\sigma_r\), as required.

This argument also covers \(D=0\): the zero flow suffices, and each resource supply can be assigned to its chosen compatible project.

3. Running time with binary rational inputs

Let \(h=\sum_{r=1}^{k}|T_r|\). The network has
\(V=m+k+2\) vertices and \(E=m+k+h\) arcs, with \(h\le km\).

To handle rational capacities exactly, write each input assignment mass and supply as an integer numerator divided by a positive integer denominator. Let \(Q\) be the product of all these denominators. The sum of their binary encoding lengths is at most \(L\), so \(Q\) has \(O(L)\) bits.

Scale every network capacity by \(Q\). The resulting capacities are integers:

  • \(Qc_r=q_rQ\sigma_r\);
  • \(Qd_p=\sum_t Qa_{tp}\).

These integers have \(O(L)\) bits. In particular, \(Qd_p\le QD\le Q\); resource capacities also have \(O(L)\) bits because the factors \(q_r\), the supply numerators, and \(Q\) all come from the input.

Using ordinary integer multiplication and division, the scaled network can be constructed in
\(O((m\tau+k+h)L^2)\) bit operations.

The standard Edmonds–Karp bound states that maximum flow in a finite directed network with nonnegative capacities requires \(O(VE^2)\) arithmetic and graph operations, independently of capacity magnitudes. Its hypotheses hold for the scaled network. Starting from zero, its flows and residual capacities remain integral and have \(O(L)\) bits. Thus the flow computation takes
\(O(VE^2L)\) bit operations.

An explicit overall bound is therefore

\(O\!\left((m\tau+k+h)L^2+(m+k+2)(m+k+h)^2L\right)\).

Since \(h\le km\), this is polynomial in \(m,\tau,k,L\). Feasibility is decided by testing whether the maximum-flow value equals \(QD\).

The constructive proof also produces a rational allocation of polynomial encoding length: divide the integral resource-to-project flows by \(Q\), add the rational unused capacities as above, and then divide row \(r\) by \(q_r\).

4. Exact feasibility criterion and the fully compatible case

The flow formulation also gives the following characterization:

A feasible allocation exists if and only if, for every subset \(U\subseteq P\),

\(\displaystyle \sum_{p\in U}d_p\le\sum_{\{r:T_r\cap U\ne\varnothing\}}c_r.\)

Necessity follows directly: only resource types compatible with at least one project in \(U\) can contribute capacity to \(U\), and each such type contributes at most \(c_r\).

For sufficiency, consider any source–sink cut in the constructed network, and let \(U\) be the projects whose vertices lie on the sink side.

Every project outside \(U\) contributes its arc of capacity \(d_p\) to the cut. For each resource type touching \(U\), either its vertex is on the sink side, contributing the source arc of capacity \(c_r\), or it is on the source side, contributing at least one compatibility arc of capacity \(c_r\). These contributions are distinct. The cut capacity is therefore at least

\(\displaystyle \sum_{p\notin U}d_p+\sum_{\{r:T_r\cap U\ne\varnothing\}}c_r\ge D.\)

The max-flow min-cut theorem applies to this finite network with nonnegative capacities, and gives a flow of value \(D\). Section 2 then gives a feasible allocation.

In particular, when every resource type is compatible with every project, feasibility is equivalent simply to
\(\sum_r q_r\sigma_r\ge\sum_{t,p}a_{tp}\).

The [cited discrete model](https://arxiv.org/pdf/1808.08813v3) requires each indivisible resource to be allocated to a single project, as specified in Definition 1.3. Divisibility permits the splitting used in the flow construction, yielding the polynomial-time result proved here.
