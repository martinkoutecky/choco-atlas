The continuous mirror question, as graded

Given rational cohort masses \(\mu_i>0\) with \(\sum_i\mu_i=1\), a block adjacency matrix \(A\), update probabilities \(\rho_i\in(0,1)\), an initial rational belief-share vector \(x^0\in[0,1]^k\), and rational \(\varepsilon>0\), define \(q_i(x)=\frac{\sum_j A_{ij}\mu_jx_j}{\sum_j A_{ij}\mu_j}\) and update \(x_i^{t+1}=(1-\rho_i)x_i^t+\rho_i\) if \(q_i(x^t)>1/2\), \(x_i^{t+1}=(1-\rho_i)x_i^t\) if \(q_i(x^t)<1/2\), and \(x_i^{t+1}=x_i^t\) otherwise. Determine whether \(x^t\) converges to a fixed point and, if it does, return a rational \(\hat{x}\) within \(\varepsilon\) of its limit in \(\ell_\infty\) distance.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq1\) cohort types with positive binary rational masses \(\mu_i\), where \(\sum_i\mu_i=1\); \(\tau\) is the support size, not the number of possible types.
The input includes a fixed directed block adjacency matrix \(A\in\{0,1\}^{\tau\times\tau}\) with \(A_{ii}=1\); \(A_{ij}=1\) means cohort \(i\) consults cohort \(j\). Also given are binary rational \(\rho_i\in(0,1)\), \(x^0\in[0,1]^\tau\), and \(\varepsilon>0\). Here \(x_i\) is the share of cohort \(i\) believing a single binary statement.
Define \(q_i(x)=\frac{\sum_j A_{ij}\mu_jx_j}{\sum_j A_{ij}\mu_j}\) and \(F_i(x)=\begin{cases}(1-\rho_i)x_i+\rho_i,&q_i(x)>\frac12,\\(1-\rho_i)x_i,&q_i(x)<\frac12,\\x_i,&q_i(x)=\frac12.\end{cases}\)
The trajectory is deterministic: \(x^{t+1}=F(x^t)\), with all coordinates evaluated from the same current vector. Convergence to a fixed point means there exists \(x^*\) with \(\lim_{t\to\infty}x^t=x^*\) and \(F(x^*)=x^*\).
The computational problem decides whether this convergence occurs and, on yes instances, returns rational \(\hat{x}\in[0,1]^\tau\) satisfying \(\|\hat{x}-x^*\|_\infty\leq\varepsilon\). Let \(L\) be the total binary input length; the belief alphabet has size \(m=2\).

Does this problem admit an algorithm polynomial in \(m,\tau,L\), including limit approximation, or is deciding convergence to a fixed point \(\mathrm{NP}\)-hard?

For finite directed networks with self-loops, binary majority dynamics with independent, fixed update probabilities strictly between zero and one reaches an equilibrium almost surely; synchronous dynamics can cycle. These are convergence results, without a polynomial running-time claim. [Source](https://arxiv.org/pdf/1309.0659)

1. Result

Deciding convergence to a fixed point is \(\mathrm{NP}\)-hard. This holds even under the restrictions

  • all masses are equal and dyadic;
  • every update rate is \(\rho_i=15/16\);
  • every initial share belongs to \(\{0,1\}\);
  • every cohort consults at most seven cohorts, including itself;
  • the requested accuracy is fixed at \(\varepsilon=1/4\).

Consequently, an algorithm polynomial in \(m,\tau,L\) for the stated decision-and-approximation problem would imply \(\mathrm{P}=\mathrm{NP}\).

We prove this by constructing, in polynomial time from a \(\mathrm{3SAT}\) formula \(\varphi\), a society whose trajectory converges to a fixed point exactly when \(\varphi\) is satisfiable.

2. A Boolean machine that enumerates assignments and stops

Let \(\varphi\) have \(n\geq1\) variables. Its assignments are vectors \(a\in\{0,1\}^n\), interpreted as binary integers with least significant bit \(a_0\). Let \(\operatorname{inc}(a)\) denote increment modulo \(2^n\).

Use a state \(s=(h,a)\in\{0,1\}^{n+1}\), where \(h\) is a halt bit. Define a Boolean transition \(T\) by setting

\[ \text{} \]

\(u=h\lor\varphi(a)\), \(h'=u\), and

  • \(a'=0^n\) if \(u=1\);
  • \(a'=\operatorname{inc}(a)\) if \(u=0\).

Thus \(T(h,a)=(h',a')\). Start at \(s_0=(0,0^n)\).

If \(\varphi\) is satisfiable, incrementing visits a satisfying assignment, after which the state becomes \(s_*=(1,0^n)\). This state is fixed because its halt bit forces \(u=1\) and \(a'=0^n\).

If \(\varphi\) is unsatisfiable, then for every \(k\geq0\),

\(T^k(s_0)=\bigl(0,\operatorname{bin}_n(k\bmod 2^n)\bigr)\).

In particular, the least significant assignment bit alternates at every transition.

The map \(T\) has a polynomial-size Boolean circuit using two-input AND, two-input OR, and NOT gates. To verify the only potentially nonobvious component, binary increment satisfies

\(\operatorname{inc}(a)_0=\neg a_0\),

and, for \(j\geq1\),

\(\operatorname{inc}(a)_j=a_j\mathbin{\oplus}\bigwedge_{\ell<j}a_\ell\).

Each conjunction can be computed with two-input AND gates, and XOR can be expressed as

\(p\mathbin{\oplus}q=(p\land\neg q)\lor(\neg p\land q)\).

Finally, each assignment output is \((\neg u)\land\operatorname{inc}(a)_j\). These constructions use polynomially many gates.

3. Realizing the machine by a synchronous gate network

The circuit for \(T\) cannot simply be treated as computing \(T\) in one synchronous update. We explicitly account for its propagation delays.

3.1. Layering the circuit

Arrange the circuit into layers \(0,1,\ldots,D\), where layer \(0\) contains the state inputs and \(D\geq1\). Insert COPY gates so that every gate in layer \(\ell\) receives its inputs from layer \(\ell-1\), and every designated output lies in layer \(D\).

This requires only polynomially many additional gates: the original depth is at most its size, and each original wire needs at most that many COPY gates.

Write \(C_\ell\) for the Boolean map computed by layer \(\ell\), and \(P\) for the projection selecting the designated outputs from layer \(D\). Then

\(T=P\circ C_D\circ\cdots\circ C_1\).

Let \(y_\ell^t\) be the vector of Boolean nodes in layer \(\ell\) at synchronous time \(t\). Define the gate network by

\(y_0^{t+1}=P(y_D^t)\),

and, for \(1\leq\ell\leq D\),

\(y_\ell^{t+1}=C_\ell(y_{\ell-1}^t)\).

The layer-zero updates are COPY operations from the output layer. All other updates are AND, OR, NOT, or COPY operations. Every node receives its logical inputs from different nodes: there are no direct self-dependencies.

3.2. Initialization and exact timing

Define the circuit evaluations

\(E_0(s)=s\), and \(E_\ell(s)=C_\ell(E_{\ell-1}(s))\).

Initialize every layer consistently:

\(y_\ell^0=E_\ell(s_0)\).

Put \(H=D+1\). Successively substituting the synchronous update equations gives, for every \(t\geq0\),

\(y_0^{t+H}=T(y_0^t)\).

We must also check the initial states of all residue classes modulo \(H\).

For \(0\leq t\leq\ell\),

\(y_\ell^t=E_\ell(s_0)\).

Indeed, the assertion at time zero is the initialization. For \(1\leq t\leq\ell\), the previous layer at time \(t-1\) still equals \(E_{\ell-1}(s_0)\), so applying \(C_\ell\) gives the assertion.

In particular, \(y_D^t=E_D(s_0)\) for \(0\leq t\leq D\). Therefore

\(y_0^r=T(s_0)\) for \(1\leq r\leq H\).

Combining these facts yields, for every \(k\geq0\),

  • \(y_0^{kH}=T^k(s_0)\);
  • \(y_0^{kH+r}=T^{k+1}(s_0)\) for \(1\leq r\leq D\).

If \(\varphi\) is satisfiable, all these subsequences eventually equal \(s_*\). Thus layer zero eventually stays constant. Each subsequent layer then becomes constant after its propagation delay, so the entire Boolean gate network eventually reaches a fixed state.

If \(\varphi\) is unsatisfiable, the least significant assignment node at times \(kH\) equals \(k\bmod2\). Hence that node takes both Boolean values infinitely often.

4. Simulating the gate network by the cohort recurrence

We next give a robust simulation that satisfies the mandatory self-loop condition and uses an update rate strictly below one.

4.1. Complementary Boolean signals

For each Boolean node \(v\), with value \(b_v^t\), introduce two signals

\(z_v^{+,t}=b_v^t\), and \(z_v^{-,t}=1-b_v^t\).

Their updates use only AND, OR, and COPY:

| Original update | Positive signal update | Negative signal update |
|---|---|---|
| \(b_v'=b_u\) | \(z_v^{+\prime}=z_u^+\) | \(z_v^{-\prime}=z_u^-\) |
| \(b_v'=\neg b_u\) | \(z_v^{+\prime}=z_u^-\) | \(z_v^{-\prime}=z_u^+\) |
| \(b_v'=b_u\land b_w\) | \(z_v^{+\prime}=z_u^+\land z_w^+\) | \(z_v^{-\prime}=z_u^-\lor z_w^-\) |
| \(b_v'=b_u\lor b_w\) | \(z_v^{+\prime}=z_u^+\lor z_w^+\) | \(z_v^{-\prime}=z_u^-\land z_w^-\) |

The table follows from the definitions and De Morgan’s laws. Initializing the signals as complements therefore preserves their intended values at every Boolean update.

If a two-input operation has identical input signals, replace it by COPY. All remaining two-input operations have distinct input signals, and no signal depends directly on itself.

4.2. Cohorts and consultation sets

Represent each signal by two cohort copies. Add four auxiliary cohorts \(Z_1,Z_2,O_1,O_2\), initialized respectively at \(0,0,1,1\), each consulting only itself.

For each cohort copy of an output signal, prescribe these consultation sets:

| Signal operation | Cohorts consulted, besides its own self-loop | Total consulted |
|---|---|---|
| COPY of \(r\) | Both copies of \(r\) | \(3\) |
| AND of \(r,s\) | Both copies of each input, and \(Z_1,Z_2\) | \(7\) |
| OR of \(r,s\) | Both copies of each input, and \(O_1,O_2\) | \(7\) |

All listed cohorts are distinct. In particular, no input signal is the output signal itself.

If the original Boolean gate network has \(V\) nodes, this uses \(4V+4\) cohorts. Pad with additional self-consulting cohorts initialized at zero until the total number \(N\) is a power of two. Choose the smallest such power, so \(N<2(4V+4)\).

Give every cohort mass \(\mu_i=1/N\) and update rate \(\rho_i=15/16\). These are dyadic rationals satisfying all input requirements. The auxiliary and padding cohorts remain exactly at their initial values.

Because the masses are equal, a row consulting \(d\) cohorts satisfies

\(q_i(x)>\tfrac12\quad\Longleftrightarrow\quad\sum_{j:A_{ij}=1}x_j>d/2\),

with the analogous equivalence for the strict lower inequality.

4.3. Strict majority margins

Let \(c\in\{0,1\}\) be the current Boolean value of the output cohort, and \(r,s\in\{0,1\}\) the input signal values. At the corresponding Boolean corner, the consulted sum is:

| Operation | Consulted sum | Threshold |
|---|---|---|
| COPY | \(c+2r\) | \(3/2\) |
| AND | \(c+2r+2s\) | \(7/2\) |
| OR | \(c+2r+2s+2\) | \(7/2\) |

These expressions implement the desired operation regardless of the current output value \(c\):

  • For COPY, input zero gives a sum at most \(1\), and input one gives a sum at least \(2\).
  • For AND, two true inputs give a sum at least \(4\); otherwise the sum is at most \(3\).
  • For OR, two false inputs give a sum at most \(3\); otherwise the sum is at least \(4\).

Thus every intended update has a strict majority margin of at least \(1/2\) in consulted-sum units.

4.4. Exact simulation despite fractional shares

Let \(\delta=1/16\). Let \(B^t\in\{0,1\}^N\) denote the intended Boolean values of all cohort copies, auxiliary cohorts, and padding cohorts at time \(t\). Initialize \(x^0=B^0\).

We prove by induction that

\(\lvert x_i^t-B_i^t\rvert\leq\delta\)

for every coordinate and every time.

The assertion holds at time zero. Suppose it holds at time \(t\). For a gate row consulting \(d\leq7\) cohorts, the consulted sum differs from its Boolean-corner value by at most

\(d\delta\leq7/16<1/2\).

The strict margin established above therefore guarantees that the actual majority selects exactly the intended next Boolean value \(B_i^{t+1}\). No tie occurs on a gate row.

The recurrence consequently becomes

\(x_i^{t+1}=\delta x_i^t+(1-\delta)B_i^{t+1}\).

Since \(x_i^t\in[0,1]\),

\(\lvert x_i^{t+1}-B_i^{t+1}\rvert=\delta\lvert x_i^t-B_i^{t+1}\rvert\leq\delta\).

The auxiliary and padding coordinates stay exactly at their prescribed Boolean values. This completes the induction.

4.5. Consequences for convergence

Suppose the Boolean gate network eventually stays at a fixed state. Then the intended cohort vector eventually stays at some Boolean corner \(B^*\). If this starts at time \(t_0\), the update identity gives

\(x_i^{t_0+k}-B_i^*=\delta^k(x_i^{t_0}-B_i^*)\).

Hence \(x^t\to B^*\).

Moreover, \(B^*\) is a fixed point of the actual cohort map. At that corner, each gate majority selects its current bit, by the strict-margin calculation. Updating toward that same bit leaves the coordinate unchanged. The auxiliary and padding coordinates are also fixed. Thus \(F(B^*)=B^*\).

Conversely, if a Boolean node takes both values infinitely often, either positive-signal cohort copy lies in \([0,\delta]\) infinitely often and in \([1-\delta,1]\) infinitely often. These intervals are separated by \(1-2\delta=7/8\), so that coordinate cannot converge.

5. The reduction and its complexity

Given \(\varphi\), construct the layered Boolean gate network from Sections 2–3 and its cohort simulation from Section 4. Set \(\varepsilon=1/4\).

If \(\varphi\) is satisfiable, the entire Boolean network eventually reaches a fixed state. The cohort trajectory therefore converges to a Boolean corner that is a fixed point of \(F\).

If \(\varphi\) is unsatisfiable, the least significant assignment node alternates along times \(kH\). Its positive-signal cohort copy consequently does not converge. The society is a no instance.

We have proved the equivalence

\(\varphi\text{ is satisfiable}\quad\Longleftrightarrow\quad x^t\text{ converges to a fixed point of }F\).

The construction has polynomial size:

  • the transition circuit and its layered version have polynomially many nodes;
  • complementary signals, cohort copies, and padding increase this count by only a constant factor;
  • the full \(N\times N\) adjacency matrix has polynomial length;
  • each mass \(1/N\) needs \(O(\log N)\) bits;
  • update rates, initial shares, and accuracy have constant-size encodings;
  • the initial layer evaluations are computable in polynomial time.

This is a polynomial-time many-one reduction from \(\mathrm{3SAT}\), proving the stated \(\mathrm{NP}\)-hardness.

The random asynchronous convergence theorem in the supplied [paper, Theorem 4](https://arxiv.org/pdf/1309.0659) concerns stochastic updates of binary agents. The reduction above concerns the specified deterministic, simultaneous cohort recurrence and does not rely on that theorem.
