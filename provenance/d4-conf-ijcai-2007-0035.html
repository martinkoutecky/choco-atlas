The continuous mirror question, as graded

Given current finite domains \(D_1,\ldots,D_n\), a radius \(q\), and a binary-rational society \(\mu\) supported on types \(T\), each with one ideal \(v^t\), compute the subset-average lower bound \(B(D)=\max_{\emptyset\ne S\subseteq T}\left\lceil\frac{1}{|S|}\sum_{i=1}^{n}\min_{a\in D_i}\sum_{t\in S}\mathbb{1}[a\ne v_i^t]\right\rceil\), and prune each \(a\in D_i\) whose corresponding bound with \(X_i=a\) fixed exceeds \(q\). The requested output is this sound bound and the values it certifies can be removed; retained values need not have supporting completions.

Packaged proof task (what the prover saw — nothing else)

Let \(m\geq1\) be the number of coordinates. Each coordinate has a finite alphabet \(A_i\) and an explicitly listed nonempty current domain \(D_i\subseteq A_i\); ideals are complete vectors \(v^t\in\prod_{i=1}^{m}A_i\), possibly outside the current domains. The radius is an integer \(q\in\{0,\ldots,m\}\).
A society is given by its support: a list \(T\) of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\), each with one ideal. Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length and \(d=\max_i|D_i|\); state running times in \(m,\tau,d,L\).
The distance constraint requires \(\max_{t\in T}\sum_{i=1}^{m}\mathbf{1}[x_i\ne v_i^t]\leq q\) for an assignment \(x\in\prod_iD_i\). Only this constraint and the current domains are considered.
Define \(B(D)=\max_{\emptyset\ne S\subseteq T}\left\lceil\frac{1}{|S|}\sum_{i=1}^{m}\min_{a\in D_i}\sum_{t\in S}\mathbf{1}[a\ne v_i^t]\right\rceil\). Subsets consist of whole support types, and their averages are unweighted, irrespective of their masses.
For \(a\in D_i\), let \(D^{i,a}\) replace \(D_i\) by \(\{a\}\). The requested output is \(B(D)\) and exactly the pairs \((i,a)\) with \(B(D^{i,a})>q\), evaluated on the input domains; retained values need not admit supporting completions.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

Exact computation of the requested bound and removals is \(\mathrm{NP}\)-hard. More precisely:

  • Deciding whether \(B(D)>q\) is \(\mathrm{NP}\)-complete.
  • Deciding whether a specified pair satisfies \(B(D^{i,a})>q\) is \(\mathrm{NP}\)-complete. Its hardness persists on instances satisfying \(B(D)\leq q\).
  • Both hardness results hold with every input domain equal to \(\{0,1\}\), every alphabet equal to \(\{0,1,2\}\), and positive dyadic masses.

Nevertheless, the complete requested output can be computed in \(O(md\,2^\tau)\) arithmetic operations after polynomial preprocessing. Thus it is fixed-parameter tractable in the support size \(\tau\).

1. A counting identity and polynomial certificates

For a nonempty subset \(S\subseteq T\), define

\( s=|S|,\qquad c_{i,a}(S)=|\{t\in S:v_i^t=a\}|,\qquad M_i(S)=\max_{a\in D_i}c_{i,a}(S). \)

The minimum number of disagreements at coordinate \(i\) is \(s-M_i(S)\). Consequently, writing

\( F_D(S)=ms-\sum_{i=1}^m M_i(S), \)

we have

\( B(D)=\max_{\emptyset\ne S\subseteq T} \left\lceil\frac{F_D(S)}{|S|}\right\rceil. \)

Because \(q\) is an integer,

\( B(D)>q \quad\Longleftrightarrow\quad \exists\,\emptyset\ne S\subseteq T:\ F_D(S)>q|S|. \)

A subset \(S\), represented by its \(\tau\) membership bits, is therefore a polynomial-size certificate. Its counts and the displayed inequality can be checked in polynomial time. Hence this decision problem belongs to \(\mathrm{NP}\).

Fixing coordinate \(i\) to \(a\) replaces \(M_i(S)\) by \(c_{i,a}(S)\), giving

\( F_{D^{i,a}}(S)=F_D(S)+M_i(S)-c_{i,a}(S). \)

Thus the specified-pair removal decision also belongs to \(\mathrm{NP}\).

These certificates are sound for the distance constraint: if an assignment \(x\) has distance at most \(q\) from every selected type, then

\( F_D(S)\leq \sum_{t\in S}\sum_i\mathbf 1[x_i\ne v_i^t] \leq q|S|. \)

The same argument applies to assignments fixing \(x_i=a\).

2. Reduction from Exact Cover

We use the known \(\mathrm{NP}\)-completeness of Exact Cover: given an explicitly listed finite universe \(U\) and subsets \(C_1,\ldots,C_n\subseteq U\), decide whether some subfamily covers every element exactly once. This is problem 14 in [Karp’s original paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

We may restrict to a nonempty universe and nonempty, distinct sets. Empty sets and duplicates can be deleted without changing the answer; empty-universe instances are trivial and can be mapped to a fixed positive instance. Thus these restrictions preserve hardness.

Write \(u=|U|\), with \(u,n\geq1\). Create the support

\( T=\{t_0,t_1,\ldots,t_n\},\qquad \tau=n+1. \)

Type \(t_0\) is an anchor, and type \(t_j\) represents \(C_j\). Every coordinate constructed below has alphabet \(\{0,1,2\}\) and domain \(\{0,1\}\).

Coordinate construction

First construct a block of coordinates.

  • Element coordinates. For each \(e\in U\), create two identical coordinates. At either coordinate, set the anchor’s ideal to \(1\), and set type \(t_j\)’s ideal to \(0\) if \(e\in C_j\), and to \(2\) otherwise.
  • Padding coordinates. For each \(j\), create \(u-|C_j|\) coordinates. At each such coordinate, set type \(t_j\)’s ideal to \(0\), and every other type’s ideal to \(2\).

The block contains

\( h=2u+\sum_{j=1}^n(u-|C_j|) \)

coordinates. All ideals are complete; the symbol \(2\) is permitted in an ideal even though it lies outside the current domain.

Exact calculation for a selected subset

Fix a nonempty \(S\subseteq T\). Define

\( z=\mathbf 1[t_0\in S],\qquad y_j=\mathbf 1[t_j\in S],\qquad s=z+\sum_j y_j, \)

and, for each element,

\( c_e=\sum_{j:e\in C_j}y_j. \)

Define the nonnegative integer

\( E(S)=\sum_{e\in U}|c_e-z|. \)

At either coordinate belonging to element \(e\), the two domain-value matching counts are \(c_e\) and \(z\). The sum of the maximum matching counts over its two copies is

\( 2\max(c_e,z)=c_e+z+|c_e-z|. \)

Each padding coordinate for \(j\) has maximum matching count \(y_j\). Therefore the sum of maximum matching counts over the entire block is

\( \begin{aligned} \sum_{\text{block }i}M_i(S) &=\sum_{e\in U}(c_e+z+|c_e-z|) +\sum_j(u-|C_j|)y_j\\ &=\sum_j|C_j|y_j+uz+E(S) +\sum_j(u-|C_j|)y_j\\ &=us+E(S). \end{aligned} \)

The block’s minimum total disagreement is consequently

\( F_{\mathrm{block}}(S)=(h-u)s-E(S). \)

The zero-error subsets encode exact covers

We claim that a nonempty subset \(S\) satisfies \(E(S)=0\) exactly when it consists of the anchor together with an exact cover.

If \(z=0\), then \(E(S)=0\) forces every \(c_e=0\). Since every \(C_j\) is nonempty, selecting any \(t_j\) would make some \(c_e\) positive. Thus no type would be selected, contradicting \(S\ne\emptyset\).

Hence \(E(S)=0\) requires \(z=1\). It then requires \(c_e=1\) for every element, which says precisely that the selected sets cover each element exactly once. Conversely, an exact cover together with the anchor gives \(E(S)=0\).

3. Repetition makes the ceiling distinguish the cases

Repeat every coordinate of the block \(R=\tau=n+1\) times. The resulting instance has

\( m=Rh,\qquad K=R(h-u). \)

For every nonempty subset,

\( \frac{F_D(S)}{|S|} =K-\frac{R E(S)}{|S|}. \)

In particular, \(B(D)\leq K\).

If the Exact Cover instance is positive, Section 2 supplies a subset with \(E(S)=0\), so \(B(D)=K\).

If it is negative, every nonempty subset has \(E(S)\geq1\). Since \(|S|\leq\tau=R\),

\( \frac{R E(S)}{|S|}\geq1. \)

Every subset average is then at most \(K-1\), and its ceiling is also at most \(K-1\). Therefore

\( \text{Exact Cover is positive} \quad\Longleftrightarrow\quad B(D)>K-1. \)

Set the reduction’s radius to \(q=K-1\). This is admissible: \(h-u\geq u\geq1\), so \(K\geq1\), while \(m-K=Ru>0\). Hence \(0\leq q\leq m\).

Masses and input size

Let \(P=2^{\lceil\log_2\tau\rceil}\). Assign

\( \mu_{t_0}=\frac{P-n}{P}, \qquad \mu_{t_j}=\frac1P\quad(1\leq j\leq n). \)

These masses are positive dyadic rationals, sum to \(1\), and require \(O(\tau\log\tau)\) bits altogether. Their values do not affect any subset calculation.

Moreover,

\( h\leq(n+2)u,\qquad m\leq(n+1)(n+2)u. \)

The explicitly listed ideal table has \(m\tau=O((n+1)^3u)\) constant-size entries. All remaining data also have polynomial encoding length. The reduction is therefore polynomial-time.

Together with Section 1, this proves that deciding \(B(D)>q\) is \(\mathrm{NP}\)-complete. An exact algorithm for \(B(D)\) would decide this problem, proving the requested computation \(\mathrm{NP}\)-hard.

4. Certified removals are hard even when the initial bound passes

Take the constructed instance and append one coordinate \(i_\star\), with domain \(\{0,1\}\) and ideal \(0\) for every type. Let the extended domains be \(D'\).

For every subset, this coordinate contributes zero minimum disagreement. Hence

\( B(D')=B(D). \)

If this coordinate is fixed to \(1\), it contributes \(|S|\) disagreements to every selected subset. Every subset average increases by exactly \(1\), so

\( B((D')^{i_\star,1})=B(D)+1. \)

Use radius \(q'=K\), which is valid for the extended instance. The initial bound always passes, since \(B(D')\leq K=q'\). Nevertheless,

\( \begin{aligned} B((D')^{i_\star,1})>q' &\quad\Longleftrightarrow\quad B(D)+1>K\\ &\quad\Longleftrightarrow\quad B(D)=K\\ &\quad\Longleftrightarrow\quad \text{Exact Cover is positive}. \end{aligned} \)

Thus deciding this one certified removal is \(\mathrm{NP}\)-hard even under the restriction \(B(D')\leq q'\). With its polynomial certificate from Section 1, the general specified-pair decision is \(\mathrm{NP}\)-complete.

5. Exact enumeration and running time

The hardness result is compatible with enumeration over the support.

Preprocess each ideal entry to record which domain value it matches, if any. Enumerate subsets in Gray-code order, so consecutive subsets differ by one type. Maintain the subset size and all counts \(c_{i,a}(S)\).

For each nonempty subset:

  • Compute all \(M_i(S)\) and \(F_D(S)\), and update the maximum ceiling defining \(B(D)\).
  • For every input pair \((i,a)\), mark it for removal if

\( F_D(S)+M_i(S)-c_{i,a}(S)>q|S|. \)

Changing one selected type updates at most one count per coordinate. Scanning the counts and testing every pair costs \(O(md)\) arithmetic operations per subset. Thus the complete output takes

\( O(md\,2^\tau) \)

arithmetic operations after preprocessing. Every test uses the original input domains, so this produces exactly the requested pairs without iterative propagation.

For an explicit bit-time bound, straightforward domain-label comparisons take \(O((d+\tau)L)\) preprocessing time: each ideal label is compared with at most \(d\) domain labels, and each domain label with at most \(\tau\) ideal labels. All subsequent integers have \(O(\log(m\tau+2))\) bits. Using schoolbook integer arithmetic gives the conservative bound

\( O\!\left((d+\tau)L+ md\,2^\tau\log^2(m\tau+2)\right), \)

with polynomial space.

The exponential parameter is the listed support size \(\tau\). The binary masses do not require expansion into individual agents.
