The continuous mirror question, as graded

Given fixed districts, additional candidates \(A\), placement prices \(\pi(i,a)\), a budget \(B\), and for each district \(i\) a binary-rational distribution \(\mu_i\) over supported rankings of \(C_i \cup A\), is there a partition \(A_1,\ldots,A_k\) of \(A\) with total placement cost at most \(B\) such that every \(a\in A_i\) maximizes its \(R\)-score in \(C_i\cup A_i\), and every district with \(A_i\ne\varnothing\) has at most two winners?

Packaged proof task (what the prover saw — nothing else)

Fix a polynomial-time uniform nontrivial pure scoring rule \(R\), with nonincreasing integer scoring vectors \(s_q\); entries may be negative, and \(s_q\) has at least two distinct entries whenever \(q>1\).
Input consists of \(k\geq1\) fixed districts with finite incumbent sets \(C_i\), a finite additional-candidate set \(A\) satisfying \(C_i\cap A=\varnothing\), positive integer placement prices \(\pi(i,a)\), and a nonnegative integer budget \(B\), with integers encoded in binary. Incumbent sets may be empty.
Each district society is a probability distribution \(\mu_i\) over strict rankings of \(C_i\cup A\). A society is given by its support: the list of its \(\tau_i\) types with positive mass, each mass a binary rational, summing to \(1\). Write \(\tau=\sum_i\tau_i\); this counts supported district types, not all possible rankings.
For a nonempty participating set \(S\subseteq C_i\cup A\), restrict each supported ranking to \(S\) and define \(\operatorname{score}_i(c,S)=\sum_r\mu_i(r)(s_{|S|})_{\operatorname{rank}_{r|S}(c)}\). Let \(W_i(S)\) contain all score maximizers, without tie-breaking; set \(W_i(\varnothing)=\varnothing\).
The decision problem asks whether there exist pairwise disjoint, possibly empty sets \(A_1,\ldots,A_k\) whose union is \(A\), with \(\sum_i\sum_{a\in A_i}\pi(i,a)\leq B\), such that whenever \(A_i\ne\varnothing\), both \(A_i\subseteq W_i(C_i\cup A_i)\) and \(|W_i(C_i\cup A_i)|\leq2\). Candidates are assigned whole to exactly one district.
Let \(m=|A\cup\bigcup_i C_i|\) and let \(L\) be the total input bit length; express running times in \(m,\tau,L,k\).

For each fixed rule \(R\) satisfying these assumptions, is this decision problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L,k\), or is it \(\mathrm{NP}\)-hard?

For finite lists of voters, the corresponding priced and unpriced problems are \(\mathrm{NP}\)-complete for every such rule \(R\). [Chavrimootoo–Jeansonne](https://arxiv.org/html/2601.13246v3#Thmtheorem4.10)
No result for this exact probability-mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • The unspecified rule R is fixed outside the input and ranges over the nontrivial polynomial-time uniform pure scoring rules covered by the anchor.
  • Each district distribution is normalized to total mass one, so each district has nonempty support.
  • Placement prices are positive binary integers, following the discrete price domain; the budget is a nonnegative binary integer.
  • Rankings are strict and are restricted to the participating candidates before computing scores; scores are integrated against the supplied masses.
  • All tied score maximizers are winners, including incumbents when counting the two-winner limit; no tie-breaking is applied.
  • Empty incumbent sets and empty assignment parts are allowed; an empty participating election has no winners.
  • The support parameter is the sum of district support sizes, m counts distinct candidates globally, and L is the total input bit length.

Result

For every fixed rule \(R\) satisfying the assumptions, the problem is \(\mathrm{NP}\)-complete when \(k\) is part of the input. Hardness holds even when every incumbent set is empty, every placement price is \(1\), and every probability mass has a power-of-two denominator.

Here “fixed districts” means that their societies cannot be changed. If \(k\) is instead a fixed constant, the problem is polynomial-time solvable; this distinction is addressed below.

1. Capacity and two-candidate elections

Every feasible assignment satisfies
\[ |A_i|\leq 2. \]
Indeed, for a nonempty \(A_i\), the required inclusions and winner bound give \(|A_i|\leq |W_i(C_i\cup A_i)|\leq 2\). Consequently, an instance with \(|A|>2k\) is infeasible.

Write \(s_2=(\alpha,\beta)\). Nonincreasingness and nontriviality imply \(\alpha>\beta\), regardless of whether these integers are negative.

For two distinct candidates \(a,b\), let \(p=\Pr_{\mu_i}[a\text{ ranks above }b]\). Restriction to \(\{a,b\}\) gives
\[ \operatorname{score}_i(a,\{a,b\})-\operatorname{score}_i(b,\{a,b\}) =(2p-1)(\alpha-\beta). \]
Thus both candidates win exactly when \(p=1/2\). This observation uses only the nontriviality of \(s_2\).

2. A society realizing any prescribed set of tied pairs

Lemma. Let \(A\) contain \(n\geq 2\) candidates, and let \(E\) be any set of unordered pairs from \(A\). In polynomial time, one can construct a society \(\mu\) over strict rankings of \(A\) such that
\[ \Pr_\mu[a\text{ ranks above }b]=1/2 \quad\Longleftrightarrow\quad \{a,b\}\in E. \]
The society has \(O(n^2)\) supported types, with positive masses having power-of-two denominators and \(O(\log(n+2))\) bits.

Proof. Fix a linear order of \(A\). We first construct a multiset of rankings.

Begin with the fixed order and its reverse. Their combined contribution to every pairwise margin is zero. Here the margin of \(a\) against \(b\) means the number of rankings placing \(a\) above \(b\), minus the number placing \(b\) above \(a\).

For each pair \(\{u,v\}\notin E\), orient it so that \(u\) precedes \(v\) in the fixed order. List the remaining candidates as \(z_1,\ldots,z_{n-2}\), and add these two rankings:
\[ u>v>z_1>\cdots>z_{n-2}, \]
\[ z_{n-2}>\cdots>z_1>u>v. \]

These two rankings contribute margin \(2\) to \(u\) against \(v\), and zero to every other pair:

  • Both place \(u\) above \(v\).
  • Each remaining candidate lies below \(u,v\) in the first ranking and above them in the second.
  • The order of the remaining candidates is reversed between the two rankings.

Let \(t\) be the number of pairs outside \(E\). The multiset currently contains \(N_0=2+2t\) rankings. Let \(N\) be the least power of two satisfying \(N\geq N_0\). Since \(N-N_0\) is even, append \((N-N_0)/2\) copies of a ranking together with its reverse. These additions change no pairwise margin.

The resulting margin is zero precisely for pairs in \(E\); every other pair has margin \(2\) in its chosen orientation. Assign probability \(1/N\) to each ranking occurrence. If a ranking occurs \(h_r\) times, merge its occurrences into one supported type of mass \(h_r/N\). These masses are positive and sum to \(1\).

For any distinct \(a,b\),
\[ \Pr_\mu[a>b]-\Pr_\mu[b>a] =\frac{\operatorname{margin}(a,b)}{N}. \]
Because strict rankings give \(\Pr_\mu[a>b]+\Pr_\mu[b>a]=1\), the claimed equivalence follows.

Finally, \(N<2N_0\), so there are \(O(n^2)\) supported types. Their masses have power-of-two denominators and \(O(\log(n+2))\) bits. Writing and merging these rankings takes polynomial time. \(\square\)

3. Reduction from three-dimensional matching

We use the standard \(\mathrm{NP}\)-complete perfect three-dimensional matching problem: given pairwise disjoint sets \(X,Y,Z\), each of size \(h\geq 1\), and \(T\subseteq X\times Y\times Z\), decide whether \(T\) contains \(h\) triples covering every element exactly once. Its completeness is a classical result of [Karp](https://doi.org/10.1007/978-1-4684-2001-2_9).

Construct the election instance as follows.

Set \(A=X\cup Y\). Create one district for each \(z\in Z\), so \(k=h\), and set every incumbent set to the empty set.

For district \(z\), define
\[ E_z=\bigl\{\{x,y\}:x\in X,\ y\in Y,\ (x,y,z)\in T\bigr\}. \]
Apply the lemma to obtain its society \(\mu_z\). Set every placement price to \(1\), and set \(B=2h=|A|\).

All constructed rankings are over exactly \(C_z\cup A=A\). The support masses satisfy the required positivity and normalization conditions. Moreover,
\[ m=2h,\qquad k=h,\qquad \tau=O(km^2). \]
With candidates relabeled by integer indices, the output bit length is \(O(km^3\log(m+k+2))\). Construction therefore takes polynomial time in the source input length.

Forward implication. Suppose a perfect matching exists. For its unique triple \((x,y,z)\) containing each \(z\), assign \(x,y\) to district \(z\).

The matching ensures that every additional candidate is assigned exactly once. Since \(\{x,y\}\in E_z\), the lemma and Section 1 imply that both candidates win. With no incumbents, the winner set is exactly \(\{x,y\}\), so the winner bound holds. The total cost is \(2h=B\).

Reverse implication. Suppose a feasible assignment exists. There are \(2h\) additional candidates and \(h\) districts. Section 1 bounds every assigned set by two candidates. Hence every district receives exactly two candidates: otherwise the total assigned would be less than \(2h\).

Let district \(z\) receive \(\{a,b\}\). Both must win, so Section 1 gives \(\Pr_{\mu_z}[a>b]=1/2\). The lemma then implies \(\{a,b\}\in E_z\). By the definition of \(E_z\), this pair consists of some \(x\in X,y\in Y\) with \((x,y,z)\in T\).

Take this triple for each district. The assignment partitions \(X\cup Y\), so every element of \(X\) and \(Y\) appears exactly once. There is one selected triple for each \(z\), so every element of \(Z\) also appears exactly once. These triples form a perfect three-dimensional matching.

This proves \(\mathrm{NP}\)-hardness for every rule under consideration.

4. Exact verification and running time

A certificate specifies the district assigned to each additional candidate, using \(O(|A|\log(k+1))\) bits.

Fix a nondecreasing polynomial \(p_R\) bounding both the time to compute \(s_q\) and the bit length of its entries for every \(q\leq m\). Such a polynomial exists by polynomial-time uniformity.

For district \(i\), write its supported masses as \(u_{ir}/v_{ir}\), with positive denominators. Define
\[ D_i=\prod_r v_{ir}, \qquad w_{ir}=u_{ir}(D_i/v_{ir}). \]
Each \(w_{ir}\) is a positive integer, and normalization gives \(\sum_r w_{ir}=D_i\). The bit length of \(D_i\) is at most \(L+1\), because the denominator encodings contribute to the input length.

For a participating set \(S\), compare the integer quantities
\[ F_i(c,S)= \sum_r w_{ir}(s_{|S|})_{\operatorname{rank}_{r|S}(c)}. \]
The actual score is \(F_i(c,S)/D_i\), so these integer comparisons determine the winner set exactly.

Negative scoring entries cause no difficulty. If \(M_R\) bounds the absolute values of the relevant entries, then
\[ |F_i(c,S)|\leq D_iM_R. \]
Thus score numerators have \(O(L+p_R(m))\) bits. Restricted rankings can be computed by scanning the supported orders.

Set \(H=L+p_R(m)+\lceil\log_2(m+\tau+k+2)\rceil+2\). Using elementary integer arithmetic, a sufficient certificate-verification bound is
\[ V_R(m,\tau,L,k) = O\!\left( L+kp_R(m)+(\tau m+km)H^2 \right). \]
This includes checking the assignment, computing exact winners in active districts, checking the winner bound, and comparing the total price with \(B\). If \(A\) is empty, the answer is immediately yes.

The bound is polynomial in \(m,\tau,L,k\), and hence in the explicitly represented input length. Therefore the problem belongs to \(\mathrm{NP}\). Combined with Section 3, this proves \(\mathrm{NP}\)-completeness.

5. If the number of districts is a fixed constant

First reject when \(|A|>2k\). Otherwise enumerate the \(k^{|A|}\) assignments and verify each. A sufficient deterministic bound is
\[ O\!\left(L+k^{2k}V_R(m,\tau,L,k)\right). \]
For fixed constant \(k\), this is polynomial in \(m,\tau,L\). When \(k\) varies with the input, the \(\mathrm{NP}\)-completeness result applies.
