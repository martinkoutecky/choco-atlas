The continuous mirror question, as graded

Here \(h(Q_U\mid\ell)\) is the sum of the \(\ell\) highest qualities in \(Q_U\).

Result and the supplied finite-voter theorem

The search problem is \(\mathrm{NP}\)-hard. A polynomial-time algorithm in the stated binary input length would imply \(\mathrm{P}=\mathrm{NP}\).

Here, binary-rational encoding means that numerators and denominators are written in binary. The proof uses the supplied finite-voter hardness theorem: finding a value-EJR committee is \(\mathrm{NP}\)-hard even when the only qualities are \(1\) and one other positive unary-encoded rational. This is also Theorem 4.6 of [Boehmer, Dong, Kreisel, and Utke](https://arxiv.org/html/2609.08830v1#S4.SS2).

The essential point is to prove that merging identical approval types preserves exactly the valid committees.

Exact equivalence under merging identical voters

Let \(V\) be an explicitly listed electorate with \(n=|V|\ge 1\), and let \(A_i\subseteq C\) be voter \(i\)'s approval set. For a committee \(W\), define its value to an approval type by
\[ s_W(t)=\sum_{c\in t\cap W}h_c. \]
Equivalently, using the requested inline delimiters, \(s_W(t)=\sum_{c\in t\cap W}h_c\).

The finite-voter value-EJR condition says that whenever a nonempty group \(S\subseteq V\) satisfies
\(|S|\ge \ell n/k\) and \(\left|\bigcap_{i\in S}A_i\right|\ge\ell\), then
\(\max_{i\in S}s_W(A_i)\ge h\left(\bigcap_{i\in S}A_i\mid\ell\right)\).

Construct the support instance by setting
\(\mathcal T=\{A_i:i\in V\}\),
\(n_t=|\{i\in V:A_i=t\}|\), and
\(\mu_t=n_t/n\).
Each listed mass is positive, and their sum is \(1\).

Lemma. A committee satisfies finite-voter value-EJR if and only if it satisfies the requirement in the question for this support instance.

Proof, finite voters to support. Suppose \(W\) satisfies finite-voter value-EJR. Take any nonempty \(U\subseteq\mathcal T\) and any \(1\le\ell\le k\) satisfying the support antecedents. Define the voter group
\(S_U=\{i\in V:A_i\in U\}\).
Then
\(|S_U|=n\mu(U)\ge\ell n/k\), and
\(\bigcap_{i\in S_U}A_i=Q_U\).
Moreover, every type in \(U\) occurs in \(S_U\), so
\(\max_{i\in S_U}s_W(A_i)=\max_{t\in U}s_W(t)\).
Applying finite-voter value-EJR to \(S_U\) gives the required support inequality.

Proof, support to finite voters. Conversely, suppose \(W\) satisfies the support requirement. Take any finite voter group \(S\) meeting the finite-voter antecedents, and set
\(U_S=\{A_i:i\in S\}\).
The total electorate contains at least as many voters of these types as occur in \(S\). Consequently,
\(\mu(U_S)\ge |S|/n\ge\ell/k\).
Also,
\(Q_{U_S}=\bigcap_{i\in S}A_i\), and
\(\max_{t\in U_S}s_W(t)=\max_{i\in S}s_W(A_i)\).
Thus the support requirement applied to \(U_S\) gives the finite-voter inequality.

This proves both directions, including when \(S\) contains only some voters of a represented type. \(\square\)

Empty approval types and unsupported candidates cause no difficulty: the construction retains them, and the identities above remain valid.

Polynomial reduction and search hardness

Apply the construction to the hard finite-voter instances from the supplied theorem. Keep \(C\), \(k\), and every quality unchanged, converting the unary rational encoding to binary.

To check the encoding size, let \(L_{\mathrm{fin}}\) denote the source input length. There are at most \(n\) distinct types. Each mass \(n_t/n\) requires \(O(\log(n+1))\) bits. Writing approval sets as incidence vectors, the resulting input length satisfies
\(L=O(m\tau+\tau\log(n+1)+L_{\mathrm{fin}})\).
Because the voters are explicitly listed, both \(n\) and \(m\) are bounded polynomially in \(L_{\mathrm{fin}}\). Grouping their approval vectors, counting multiplicities, and encoding the masses therefore take polynomial time.

The lemma shows that the source and target instances have the same valid committees. Hence any algorithm that always outputs a valid target committee in time \(\operatorname{poly}(m,\tau,k,L)\) would yield a polynomial-time algorithm for the supplied hard finite-voter search problem: construct the support instance, run the algorithm, and return its committee unchanged.

Therefore finding the required committee is \(\mathrm{NP}\)-hard, already on instances having two quality values and masses obtained by normalizing explicitly listed voter multiplicities. This is a search-hardness statement; it does not claim that deciding whether a valid committee exists is hard.

Existence and an explicit finite running-time bound

Existence also transfers to every rational-mass instance. Write each mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\), and let
\(N=\prod_{t\in\mathcal T}b_t\).
Replace type \(t\) by \(N\mu_t=Na_t/b_t\) identical voters. These are positive integer counts summing to \(N\). By the supplied finite-voter existence theorem, this electorate has a value-EJR committee; the lemma makes it valid for the original support instance.

This expansion proves existence, but \(N\) can be exponential in \(L\), so it supplies no polynomial-time algorithm.

For completeness, exhaustive search can find a committee in
\(O\!\left(\left[m\log(m+1)+\binom{m}{k}2^\tau(m\tau+k)\right]L^2\right)\)
bit operations:

  • Sort candidates by decreasing quality.
  • Enumerate every size-\(k\) committee \(W\).
  • For each nonempty support subset \(U\), compute \(\mu(U)\), \(Q_U\), and \(\max_{t\in U}s_W(t)\).
  • Scan \(Q_U\) in the sorted order to obtain its highest-quality prefix sums, and check every applicable \(1\le\ell\le k\).

For a fixed \(U\), these checks use \(O(m\tau+k)\) arithmetic and combinatorial operations. Exact arithmetic is polynomially bounded: multiplying all input denominators gives a common denominator with \(O(L)\) bits, and all sums and comparisons involve \(O(L)\)-bit integers. Schoolbook arithmetic therefore gives the displayed conservative \(L^2\) factor. Existence guarantees that the enumeration eventually returns a valid committee.
