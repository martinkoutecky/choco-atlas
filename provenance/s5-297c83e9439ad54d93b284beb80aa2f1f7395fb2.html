The anchor (named result in the paper)

Corollary 1 — class: hardness

The continuous mirror question, as graded

Given a finite set \(J\) of item types, a monotone submodular coverage valuation \(f:2^J\to\mathbb{Q}_{\ge 0}\), and rational per-capita supplies \(b_j\in(0,1]\), let \(\lambda_C\) be the mass of a unit-mass cohort receiving integral bundle \(C\subseteq J\), with \(\sum_C\lambda_C=1\) and \(\sum_{C\ni j}\lambda_C\le b_j\). Is it NP-hard, unless \(P=NP\), to approximate \(Z_{\mathrm{mass}}=\max_{\lambda}\min_{C:\lambda_C>0}f(C)\) within \(1-1/e+\varepsilon\) for every \(\varepsilon>0\)?

Packaged proof task (what the prover saw — nothing else)

Let \(J\) be a nonempty set of \(m\) item types, with binary rational supplies \(b_j\in(0,1]\). All agents share a normalized monotone coverage valuation \(f:2^J\to\mathbb{Q}_{\geq0}\), with \(f(\emptyset)=0\), given through a value oracle.
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here the society has one valuation type of mass \(1\), so \(\tau=1\).
A feasible allocation divides this mass into cohorts receiving integral bundles \(C\subseteq J\): \(\lambda_C\geq0\), \(\sum_{C\subseteq J}\lambda_C=1\), and \(\sum_{C\ni j}\lambda_C\leq b_j\) for every \(j\). Empty bundles and unused supplies are allowed.
Define \(Z_{\mathrm{mass}}=\max_{\lambda}\min_{C:\lambda_C>0}f(C)\). An \(\alpha\)-approximation means a feasible allocation whose minimum positive-cohort value is at least \(\alpha Z_{\mathrm{mass}}\). Let \(L\) bound the input bit length and the bit length of each oracle answer; measure running time and oracle calls in \(m,\tau,L\), treating \(\varepsilon\) as fixed.

For each fixed \(0<\varepsilon<1/e\), does maximizing \(Z_{\mathrm{mass}}\) admit a polynomial-time \((1-1/e+\varepsilon)\)-approximation, or is achieving this ratio NP-hard?

Discrete identical-valuation submodular max-min allocation is NP-hard to approximate beyond \(1-1/e\), and admits a \(2/5\)-approximation ([Boehmer](https://drops.dagstuhl.de/storage/00lipics/lipics-vol370-swat2026/html/LIPIcs.SWAT.2026.8/LIPIcs.SWAT.2026.8.html)).
For equal supplies, the mass objective is the AnyPrice share. Ben Uziahu and Feige explicitly sketch hardness beyond \(1-1/e\) for computing that share with submodular valuations, without detailed proofs; the coverage restriction is not separately stated ([Ben Uziahu–Feige](https://arxiv.org/html/2303.12444v1)).

  • Retained the discrete value-oracle input model and supplied an explicit bound on rational answer lengths.
  • Imposed f(empty set)=0, as required by the discrete definition.
  • Interpreted society types as valuation types, giving support size one; bundle cohorts are allocation variables rather than input types.
  • Made cohort masses nonnegative and retained empty bundles and unused supplies.
  • Interpreted approximation as producing a feasible allocation with a multiplicative minimum-value guarantee.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Achieving a \((1-1/e+\varepsilon)\)-approximation is NP-hard, for every fixed \(0<\varepsilon<1/e\). This holds already with one supported valuation type and equal supplies.

The proof below bounds the value of every feasible fractional mass allocation in the no case. Thus it does not require converting a fractional allocation into a discrete allocation.

1. The known hardness theorem used

Write \([k]=\{1,\ldots,k\}\). We use the following form of the projection-labeling hardness construction from [Khot–Lipton–Markakis–Mehta, Section 4, Lemma 10 and Proposition 11](https://www.scribd.com/document/815094580/5).

For every fixed integer \(k\geq2\) and fixed rational \(\delta>0\), the following promise problem is NP-hard. An instance has a \(k\)-partite hypergraph with nonempty edge set \(E\), a label set \(A_v\) of the same constant cardinality \(n\) at every vertex, a constant-size alphabet \(\Gamma\), and projections \(\pi_{e,i}:A_{v_i}\to\Gamma\) for each edge \(e=(v_1,\ldots,v_k)\).

A labeling chooses \(a_v\in A_v\). An edge is strongly satisfied when all its projected labels coincide, and weakly satisfied when some pair coincide.

  • Yes: There are \(n\) labelings strongly satisfying every edge and having pairwise distinct labels at every vertex.
  • No: Every labeling weakly satisfies at most a \(\delta\) fraction of the edges.

The construction has polynomial size for fixed \(k,\delta\). In the cited construction, \(n=6^s\), the projections record shared-vertex colorings, and weak soundness is at most \(k^2 2^{-\gamma s}\); increasing the constant \(s\) gives the stated \(\delta\).

Here \(n\) is an auxiliary alphabet size. Our society will still have \(\tau=1\).

2. Constructing the coverage instance

Given such a labeling instance, create one item for each vertex-label pair:

\(\displaystyle J=\{(v,a):v\in V,\ a\in A_v\}.\)

Give every item supply \(b_{(v,a)}=1/n\).

For every edge \(e\), create a separate coverage universe

\(\displaystyle U_e=\{e\}\times[k]^\Gamma.\)

Thus an element of \(U_e\) is a function \(x:\Gamma\to[k]\), tagged by \(e\). Let \(U\) be the disjoint union of the \(U_e\).

For \(e=(v_1,\ldots,v_k)\), item \((v_i,a)\) covers precisely those elements \((e,x)\) satisfying

\(\displaystyle x\bigl(\pi_{e,i}(a)\bigr)=i.\)

An item covers no elements in universes belonging to nonincident edges. Denote its coverage set by \(S_{v,a}\), and define

\(\displaystyle f(C)=\frac{\left|\bigcup_{(v,a)\in C}S_{v,a}\right|}{|U|}.\)

This is a rational, monotone coverage valuation with \(f(\emptyset)=0\) and \(f(C)\leq1\).

Because \(k,n,|\Gamma|\) are constants, the explicit coverage representation has polynomial size. Consequently, value queries can be answered in polynomial time, with polynomially bounded answer bit lengths.

3. Completeness: the yes-case optimum equals one

Let \(\ell^1,\ldots,\ell^n\) be the disjoint strongly satisfying labelings. Define bundles

\(\displaystyle C_r=\{(v,\ell^r(v)):v\in V\},\qquad r\in[n].\)

Fix \(r\) and an edge \(e=(v_1,\ldots,v_k)\). Strong satisfaction gives a common projection \(p\in\Gamma\):

\(\displaystyle \pi_{e,1}(\ell^r(v_1))=\cdots=\pi_{e,k}(\ell^r(v_k))=p.\)

The corresponding items cover all of \(U_e\): every \(x\in[k]^\Gamma\) has \(x(p)=i\) for some \(i\in[k]\). Therefore \(f(C_r)=1\).

Assign mass \(1/n\) to each \(C_r\). At every vertex, the \(n\) labelings use \(n\) distinct labels, so every item occurs in exactly one bundle. Its allocated mass is exactly \(1/n\), satisfying its supply constraint.

This allocation has minimum value \(1\). Since every bundle has value at most \(1\),

\(\displaystyle Z_{\mathrm{mass}}=1\)

in the yes case.

4. Soundness for arbitrary fractional allocations

Assume the labeling instance is a no instance. Fix any feasible allocation \(\lambda\), and draw a random bundle \(C\) according to \(\lambda\).

For each vertex \(v\), define its selected-label list

\(\displaystyle D_v(C)=\{a\in A_v:(v,a)\in C\}.\)

For an edge \(e=(v_1,\ldots,v_k)\), set

\(\displaystyle X_e(C)=\sum_{i=1}^k|D_{v_i}(C)|.\)

Feasibility implies, for every vertex,

\(\displaystyle \mathbb E_C|D_v(C)|=\sum_{a\in A_v}\Pr_C[(v,a)\in C]\leq n\cdot\frac1n=1.\)

Hence, for every edge,

\[\displaystyle \mathbb E_C X_e(C)\leq k. \tag{1}\]

Call \((e,C)\) agreeing if two distinct vertices of \(e\) have selected labels with equal projections.

4.1. Coverage without an agreeing pair

Set \(q=1-1/k\) and \(g(x)=1-q^x\).

Suppose \((e,C)\) is not agreeing. For each \(p\in\Gamma\), all selected labels projecting to \(p\), if any, belong to a single position \(i\) of the edge. Thus the coverage condition associated with \(p\) is just \(x(p)=i\).

Let \(d\) be the number of projection symbols appearing among these labels. The coordinates of a uniformly chosen \(x\in[k]^\Gamma\) are independent, so the covered fraction of \(U_e\) is exactly \(1-q^d\). Since \(d\leq X_e(C)\), this fraction is at most \(g(X_e(C))\).

Let \(h_e(C)\) denote the covered fraction of \(U_e\). For agreeing pairs we use \(h_e(C)\leq1\). Combining the two cases gives

\[\displaystyle h_e(C)\leq g(X_e(C))+\mathbf1_{\{(e,C)\text{ agreeing}\}}. \tag{2}\]

4.2. Agreeing pairs with short lists are rare

Fix an integer \(T\geq1\) and a bundle \(C\). Decode a random labeling by independently choosing a uniform label from each nonempty \(D_v(C)\); use an arbitrary label when that list is empty.

If \((e,C)\) is agreeing and \(X_e(C)\leq T\), choose a witnessing pair of labels at vertices \(v_i,v_j\). The decoder chooses this pair with probability

\(\displaystyle \frac1{|D_{v_i}(C)|\,|D_{v_j}(C)|}\geq\frac1{T^2}.\)

That event weakly satisfies \(e\).

Every deterministic labeling weakly satisfies at most a \(\delta\) fraction of edges, so the same bound holds in expectation for the decoded labeling. Consequently, writing \(e\) for a uniformly random edge,

\(\displaystyle \Pr_e[(e,C)\text{ agreeing and }X_e(C)\leq T]\leq\delta T^2.\)

This holds for every \(C\), and therefore also after averaging over \(\lambda\).

By (1) and Markov’s inequality,

\(\displaystyle \Pr_{e,C}[X_e(C)>T]\leq\frac{k}{T}.\)

Thus

\[\displaystyle \Pr_{e,C}[(e,C)\text{ agreeing}]\leq\delta T^2+\frac{k}{T}. \tag{3}\]

4.3. Bounding the allocation’s average and minimum values

The function \(g\) is increasing and concave on the nonnegative reals: its derivatives satisfy

\(\displaystyle g'(x)=-(\log q)q^x>0,\qquad g''(x)=-(\log q)^2q^x<0.\)

All edge universes have equal size, so \(f(C)=\mathbb E_e h_e(C)\). Using (1)–(3) and Jensen’s inequality,

\[\displaystyle \mathbb E_C f(C)\leq g(\mathbb E_{e,C}X_e(C))+\delta T^2+\frac{k}{T}\leq1-\left(1-\frac1k\right)^k+\delta T^2+\frac{k}{T}. \tag{4}\]

The minimum value among positive-mass bundles is at most their weighted average. Since \(\lambda\) was arbitrary, (4) proves

\(\displaystyle Z_{\mathrm{mass}}\leq1-\left(1-\frac1k\right)^k+\delta T^2+\frac{k}{T}\)

in every no instance.

This argument permits empty bundles, unused supplies, arbitrary cohort masses, and arbitrary support size.

5. Choosing constants and obtaining hardness

Fix \(\varepsilon\), and write \(\alpha=1-1/e+\varepsilon\).

First choose a constant \(k\) sufficiently large that

\(\displaystyle 1-\left(1-\frac1k\right)^k<1-\frac1e+\frac{\varepsilon}{4}.\)

Such a choice exists because \((1-1/k)^k\) converges to \(e^{-1}\).

Next choose an integer constant \(T\) with \(k/T<\varepsilon/4\), and a positive rational constant \(\delta\) with \(\delta T^2<\varepsilon/4\). Apply the hardness theorem with these parameters.

The resulting gap is

\(\displaystyle \text{Yes: }Z_{\mathrm{mass}}=1,\qquad \text{No: }Z_{\mathrm{mass}}\leq\beta<1-\frac1e+\frac{3\varepsilon}{4}<\alpha,\)

where

\(\displaystyle \beta=1-\left(1-\frac1k\right)^k+\delta T^2+\frac{k}{T}\)

is rational.

Choose a fixed rational threshold \(r\) with \(\beta<r<\alpha\). A polynomial-time \(\alpha\)-approximation returning its positive cohorts would distinguish the promise cases: in the yes case its minimum value would exceed \(r\), whereas in the no case every feasible allocation has minimum value below \(r\). Evaluating the polynomial-length output requires only polynomially many simulated value queries.

All construction parameters depend only on the fixed \(\varepsilon\). The number of items, the supply encoding, the coverage representation, and oracle-answer bit lengths are polynomial in the source-instance size. The society has exactly one valuation type of mass \(1\).

Therefore the requested approximation ratio is NP-hard to achieve; a deterministic polynomial-time algorithm would imply \(\mathrm P=\mathrm{NP}\).

4. Feasibility-derived expectation bounds

Sampling a bundle according to \(\lambda\) is legitimate because the cohort masses are nonnegative and sum to \(1\).

Without an agreeing pair, all selected labels projecting to any one symbol belong to one edge position. Multiple such labels therefore repeat the same coverage condition.

For agreeing pairs, adding the indicator in inequality (2) is a valid upper bound, although it can exceed \(1\).

Every realization of the decoder is a deterministic labeling subject to the no-case soundness bound. Averaging therefore preserves that bound and yields the claimed estimate \(\delta T^2\).

Markov’s inequality applies because \(X_e(C)\) is nonnegative and its joint expectation over edges and bundles is at most \(k\). Splitting agreement events according to whether \(X_e(C)\leq T\) yields inequality (3).
