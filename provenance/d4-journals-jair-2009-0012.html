The continuous mirror question, as graded

Given \(\tau\) complete agent types with population distribution \(\mu\), a team-size bound \(K\), an explicit coalition welfare table \(w(z)\) for \(z\in\mathcal Z_K=\{z\in\mathbb Z_{\ge0}^{\tau}:1\le\|z\|_1\le K\}\), and a size-intensity vector \(h\) satisfying \(\sum_k kh_k=1\), find \(x_z\ge0\) maximizing \(\sum_z w(z)x_z\) subject to \(\sum_z z_t x_z=\mu_t\) for every type \(t\) and \(\sum_{\|z\|_1=k}x_z=h_k\) for every \(k\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\ge1\) complete types with positive masses \(\mu_t\), each a binary rational, with \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; agents of the same type are interchangeable.
Given an integer \(K\ge1\), define \(\mathcal Z_K=\{z\in\mathbb Z_{\ge0}^{\tau}:1\le\|z\|_1\le K\}\). Coalition welfare depends only on \(z\), is independent of other coalitions, and is supplied explicitly as a signed binary rational \(w(z)\) for every \(z\in\mathcal Z_K\).
The input also contains binary rationals \(h_k\ge0\) for \(1\le k\le K\), satisfying \(\sum_{k=1}^{K}kh_k=1\); \(h_k\) is the required intensity of size-\(k\) coalitions per unit population mass.
Find nonnegative real intensities \(x_z\) maximizing \(\sum_{z\in\mathcal Z_K}w(z)x_z\), subject to \(\sum_{z\in\mathcal Z_K}z_tx_z=\mu_t\) for every \(t\) and \(\sum_{z\in\mathcal Z_K:\|z\|_1=k}x_z=h_k\) for every \(k\), or report infeasibility.
Let \(L\) be the total binary input length, including the entire welfare table. State running times in \(\tau,K,L\); this model has no separate parameter \(m\).

Is this exact continuous welfare-maximization problem solvable in polynomial time in the explicit input length \(L\), or is it NP-hard?

For finite labelled agents with a prescribed multiset of coalition sizes, an enumeration procedure generates every admissible coalition structure exactly once; this is not a polynomial-time guarantee.
Unrestricted discrete coalition structure generation with an explicit table of all coalition values has a dynamic programming algorithm polynomial in that table's size. These discrete results do not classify the continuous problem above.

Modeling choices made when packaging the task

  • The population distribution is normalized to total mass one, with strictly positive binary rational masses on its listed support.
  • The size-intensity vector has K nonnegative binary rational entries; zero entries are allowed.
  • Coalition welfare entries are signed binary rationals, reflecting the discrete definition's unrestricted real-valued welfare while providing a finite computational encoding.
  • K is a positive integer, and coalition intensities are nonnegative real variables without integrality constraints.
  • Types are interchangeable labels whose coalition welfare is completely determined by the supplied type-count table.
  • The computational task includes reporting infeasibility, and L denotes total input length including the complete explicit welfare table; there is no separate m parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Conclusion

The problem is exactly solvable in polynomial time in the explicit input length \(L\). Moreover, every instance satisfying the stated hypotheses is feasible.

The proof uses rational linear programming, with one variable for each entry of the welfare table.

1. Number of variables and encoding length

Write \(N=|\mathcal Z_K|\). Introducing a slack coordinate \(z_{\tau+1}=K-\sum_{t=1}^{\tau}z_t\), stars and bars counts all nonnegative vectors with \(\sum_{t=1}^{\tau}z_t\le K\). Removing the zero vector gives

\[ N=\binom{\tau+K}{K}-1. \]

There are \(N\) nonnegative variables and \(\tau+K\) equality constraints. Define the matrix \(A\), right-hand side \(b\), and objective vector \(c\) by

\[ A_{t,z}=z_t \quad(1\le t\le\tau),\qquad A_{\tau+k,z}=\mathbf 1_{\{\|z\|_1=k\}}\quad(1\le k\le K), \]

\[ b=(\mu_1,\ldots,\mu_\tau,h_1,\ldots,h_K),\qquad c_z=w(z). \]

The optimization problem is therefore precisely

\[ \max\{c^{\mathsf T}x:Ax=b,\ x\ge0\}. \]

Every entry of \(A\) is an integer between zero and \(K\), requiring \(O(\log(K+1))\) bits. The entries of \(b\) and \(c\) already occur in the input. Consequently, a dense encoding of this linear program, with nonnegativity specified as variable bounds, has length

\[ B=O\!\left(L+(\tau+K)N\log(K+1)\right). \]

This encoding can be constructed within the same asymptotic bit-operation bound: enumerate the count vectors and write their columns.

Crucially, the welfare table explicitly supplies \(N\) rational values, so \(N\le L\). Also, \(N\ge\tau\), because all unit vectors occur, and \(N\ge K\), because all vectors \(ke_1\), for \(1\le k\le K\), occur. Hence \(\tau+K\le2L\) and

\[ B=O\!\left(L^2\log(L+1)\right). \]

Thus the linear program has polynomial encoding length, even when its number of variables grows rapidly with \(\tau\) and \(K\).

2. Every valid instance is feasible

For each type \(t\) and size \(k\), set

\[ x_{ke_t}=h_k\mu_t, \]

and set every other intensity to zero. These homogeneous coalition vectors are distinct, and all intensities are nonnegative.

For each type \(t\), its assigned population mass is

\[ \sum_{z\in\mathcal Z_K}z_tx_z =\sum_{k=1}^{K}kh_k\mu_t =\mu_t, \]

using the hypothesis \(\sum_{k=1}^{K}kh_k=1\).

For each size \(k\), the total coalition intensity is

\[ \sum_{\|z\|_1=k}x_z =\sum_{t=1}^{\tau}h_k\mu_t =h_k, \]

using \(\sum_{t=1}^{\tau}\mu_t=1\). This proves feasibility independently of the welfare values.

3. A finite optimum is attained

For any feasible intensity vector and any \(z\) of size \(k\), nonnegativity and the size constraint imply

\[ 0\le x_z\le\sum_{\|u\|_1=k}x_u=h_k. \]

Moreover, \(kh_k\le1\), since the nonnegative quantities \(jh_j\) sum to one. Therefore \(x_z\le1/k\le1\).

The feasible region is consequently a nonempty, closed subset of the compact box \([0,1]^N\). It is compact, and the linear welfare objective is continuous. Thus a finite maximum is attained. Signed welfare values cause no difficulty.

4. Exact optimization and running time

The standard polynomial-time theorem for rational linear programming states that an explicitly encoded rational linear program can be solved exactly in a number of bit operations polynomial in its encoding length: the algorithm detects infeasibility or unboundedness, or returns a rational optimal solution. Exact rational recovery is part of this guarantee. See [Trevisan’s linear-programming notes, Sections 5.2.4–5.2.5](https://theory.stanford.edu/~trevisan/books/cs261.pdf).

All hypotheses hold here: the coefficients are rational, the encoding is explicit, and Sections 2–3 establish feasibility and a finite attained optimum. Equalities can be replaced by pairs of inequalities, increasing the encoding length by only a constant factor.

Therefore an exact optimizer can be computed in

\[ \operatorname{poly}\!\left( L+(\tau+K)\left[\binom{\tau+K}{K}-1\right]\log(K+1) \right) =L^{O(1)} \]

bit operations. Output coordinates are represented exactly as binary-encoded integer numerators and denominators.

This settles the stated continuous problem. Its rational-threshold decision version belongs to \(\mathrm P\), so NP-hardness under polynomial-time many-one reductions would imply \(\mathrm P=\mathrm{NP}\). No discrete coalition-structure enumeration result is needed.
