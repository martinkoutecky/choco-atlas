The continuous mirror question, as graded

Given finite firm and worker type sets with rational masses, complete type-level preferences over a finite catalog of packages, and rational resource coefficients with capacities scaled by type mass, compute a feasible mass schedule \(x_a \ge 0\) with no blocking package. A package blocks if positive mass can be shifted from its participants’ worst currently used situations into that package while preserving capacities, and the firm type and every participating worker type strictly prefer it under the paper’s externality-adjusted worker order.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: disjoint firm and worker type sets \(F,W\), with \(|F|,|W|\geq2\), and positive binary rational masses \(\mu_i\) summing to \(1\). Here \(\tau=|F|+|W|\) is the support size, not the number of possible types.
An explicitly listed catalog \(A\) contains \(m\) nonempty packages. Each package \(a\) consists of contracts with one firm type \(f(a)\) and a nonempty worker type set \(W(a)\), with at most one contract per worker type; contracts specify both endpoint types and terms. Write \(a_w\) for the contract of worker type \(w\).
Each firm has a strict complete order over its catalog packages and unemployment \(\varnothing\); each worker has a strict complete order over its incident contracts and \(\varnothing\). Every catalog package is acceptable to its firm, and every contract is acceptable to its worker.
A worker's situation order ranks packages first by its own contract and, when that contract is identical, by the firm's package order; unemployment is last. A firm's situation order is its package order.
For each type \(i\), input a positive rational per-unit capacity \(r_i\). Input rational coefficients \(p_{ia}>0\) exactly for participants \(i\in\{f(a)\}\cup W(a)\), and \(p_{ia}=0\) otherwise. A mass schedule is \(x\geq0\) satisfying \(\sum_{a\in A}p_{ia}x_a\leq\mu_i r_i\) for every type.
The worst situation \(e_i(x)\) is unemployment whenever type \(i\)'s capacity is slack; otherwise it is its least preferred incident package with \(x_a>0\). Package \(a\) blocks precisely when every participant strictly prefers \(a\) to \(e_i(x)\). Existing packages may be reduced to release participants' resources, including reductions affecting outsiders; outsiders' consent is unnecessary. A schedule is stable if no package blocks. Degenerate inputs are allowed.

Does computing an exact rational stable mass schedule admit an algorithm polynomial in \(m,\tau,L\), where \(L\) is the total binary input length, or is this search problem \(\mathrm{PPAD}\)-hard under polynomial-time search reductions?

For finite agent markets with these contract preferences and positive resource schemes, Scarf's algorithm terminates with a stable generalized schedule; no polynomial running-time bound is asserted. [Huang](https://arxiv.org/pdf/2309.04181)
Computational Scarf and unrestricted fractional stable hypergraph matching are \(\mathrm{PPAD}\)-complete; those broader classifications do not themselves classify this contract-based type model. [Kintali et al.](https://arxiv.org/pdf/0904.1435)

  • Defined m as the explicitly listed package catalog size and L as the total binary input length.
  • Specified packages as nonempty contract sets involving one firm type and at most one contract per participating worker type, following the discrete assignment structure.
  • Required strict complete firm and worker contract preferences and restricted the catalog to mutually acceptable packages.
  • Specified the worker situation order by own-contract preference, with the firm's package order breaking comparisons between situations sharing the identical contract.
  • Required positive resource coefficients on every participant and zero coefficients on nonparticipants.

Classification

Computing an exact rational stable mass schedule is \(\mathrm{PPAD}\)-hard under polynomial-time search reductions. This holds even when every firm has exactly one package and every positive resource coefficient equals \(1\).

The reduction below embeds fractional stable hypergraph matching into the stated contract model.

1. The source problem

A hypergraphic preference system consists of an explicitly listed hypergraph \(H=(V,E)\) with nonempty edges and, for every vertex \(v\), a strict order \(\succ_v\) over its incident edges. Write \(h\succeq_v e\) when \(h=e\) or \(h\succ_v e\).

A fractional matching is a vector \(y\in\mathbb{R}_{\geq0}^{E}\) satisfying

\[ \sum_{h\ni v}y_h\leq1 \quad\text{for every }v\in V. \]

It is stable if every edge \(e\) contains a vertex \(v\) satisfying

\[ \sum_{\substack{h\ni v\\h\succeq_v e}}y_h=1. \]

Finding an exact fractional stable matching for such an explicitly listed system is \(\mathrm{PPAD}\)-complete. This is the source problem defined and classified in [Kintali et al., Section 5.2](https://arxiv.org/pdf/0904.1435).

We may assume \(|V|,|E|\geq2\). Indeed, adding two new vertices, each with its own singleton edge and no other incident edges, guarantees these inequalities. Stability forces each added edge to have weight \(1\), so discarding those coordinates recovers a solution of the original instance.

2. Construction of the society

Let \(n=|V|\), \(q=|E|\), and \(N=n+q\).

Create one worker type \(w_v\) for every vertex \(v\), and one firm type \(f_e\) for every edge \(e\). Thus

\[ W=\{w_v:v\in V\},\qquad F=\{f_e:e\in E\},\qquad \tau=N. \]

For each edge \(e\), create exactly one package \(a_e\), belonging to firm \(f_e\), with worker set

\[ W(a_e)=\{w_v:v\in e\}. \]

Its contract with \(w_v\) specifies endpoints \(f_e,w_v\) and a fixed term. Every package is nonempty, and it contains at most one contract per worker type.

Set

\[ \mu_i=\frac1N \quad\text{for every type }i, \qquad r_{w_v}=N,\qquad r_{f_e}=2N. \]

The masses are positive binary-encoded rationals and sum to \(1\). Worker capacities are therefore \(1\), and firm capacities are \(2\).

Set every participant coefficient to \(1\), with all other coefficients zero.

Firm \(f_e\) ranks its sole package \(a_e\) above unemployment. Worker \(w_v\) orders its incident contracts according to the source order:

\[ (a_h)_{w_v}\succ_{w_v}(a_e)_{w_v} \quad\Longleftrightarrow\quad h\succ_v e, \]

and ranks unemployment last.

These are valid strict complete preference orders. Contracts belonging to different edges have different firm endpoints, so they are distinct. Consequently, workers’ induced situation orders reproduce their source edge orders exactly; the tie-breaking rule for identical contracts never applies.

3. Feasibility and the firms’ worst situations

Identify coordinates by setting \(y_e=x_{a_e}\).

The worker constraints are exactly

\[ \sum_{e\ni v}x_{a_e}\leq1. \]

The constraint of firm \(f_e\) is \(x_{a_e}\leq2\). Since \(e\) is nonempty, choosing any \(v\in e\) gives

\[ x_{a_e}\leq\sum_{h\ni v}x_{a_h}\leq1. \]

Thus the firm constraint is redundant, and firm \(f_e\)’s capacity is strictly slack in every feasible schedule. By the task’s definition,

\[ e_{f_e}(x)=\varnothing. \]

Every firm therefore strictly prefers its package to its worst situation, for every feasible schedule.

It follows that \(x\) is feasible in the constructed society if and only if \(y\) is a fractional matching in the source instance.

4. Exact equivalence of stability

Fix an edge \(e\) and a vertex \(v\in e\). Define

\[ S_v(e,x)= \sum_{\substack{h\ni v\\h\succeq_v e}}x_{a_h}. \]

We prove the following equivalence:

\[ w_v\text{ does not strictly prefer }a_e\text{ to }e_{w_v}(x) \quad\Longleftrightarrow\quad S_v(e,x)=1. \]

Forward implication. If worker capacity were slack, its worst situation would be unemployment. Since every incident contract is acceptable, the worker would strictly prefer \(a_e\). Hence its capacity must be full.

Its worst situation is then its least preferred positive-weight incident package. Because its situation order is strict, failure to strictly prefer \(a_e\) means that this worst package is ranked at least as high as \(a_e\). Every positive-weight incident package is therefore ranked at least as high as \(a_e\). Full capacity gives \(S_v(e,x)=1\).

Reverse implication. Suppose \(S_v(e,x)=1\). Feasibility implies

\[ 1=S_v(e,x)\leq \sum_{h\ni v}x_{a_h}\leq1. \]

Thus worker capacity is full, and every incident edge ranked below \(e\) has weight zero. Its least preferred positive-weight package is consequently ranked at least as high as \(a_e\). The worker does not strictly prefer \(a_e\) to that worst situation.

Now every firm always strictly prefers its package. Therefore \(a_e\) fails to block precisely when some worker \(w_v\), with \(v\in e\), does not strictly prefer it. By the equivalence just proved, this happens precisely when some \(v\in e\) satisfies \(S_v(e,x)=1\).

Applying this to every edge proves

\[ x\text{ is stable in the society} \quad\Longleftrightarrow\quad (x_{a_e})_{e\in E}\text{ is a fractional stable matching}. \]

The argument includes zero coordinates and equality cases; it requires no nondegeneracy assumption.

5. Polynomial size and conclusion

The construction has \(m=q\) packages, \(\tau=n+q\) types, and \(\sum_{e\in E}|e|\) contracts. Preference lists are copied from the source instance. The numerical data have bit length polynomial in the source encoding length; even a dense listing of coefficients has polynomial size.

The solution transformation simply copies \(y_e=x_{a_e}\). It preserves exact rational values and maps every stable output to a valid source solution. Hence this is a polynomial-time search reduction.

Therefore the requested search problem is \(\mathrm{PPAD}\)-hard. A polynomial-time algorithm in \(m,\tau,L\) would consequently yield polynomial-time algorithms for all \(\mathrm{PPAD}\) search problems. The hardness classification does not assume an unproved separation of complexity classes.
