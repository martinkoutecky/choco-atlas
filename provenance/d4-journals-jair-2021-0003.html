The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu\) with \(\sum_t\mu_t=1\), and a rational symmetric valuation matrix \(V\), define \(\mathrm{OPT}_\infty(\mu,V)=\limsup_{N\to\infty,\;N\mu\in\mathbb{Z}^T}\mathrm{OPT}(N\mu,V)/N\), where \(\mathrm{OPT}(N\mu,V)\) is maximum FHG welfare for the corresponding clone population. Compute pair masses \(x_{\{s,t\}}\) and \(x_{tt}\), with singleton remainder, satisfying \(2x_{tt}+\sum_{s\ne t}x_{\{s,t\}}\le\mu_t\) and \(W_{\mathrm{pair}}(x)=\sum_{s<t}v_{st}x_{\{s,t\}}+\sum_t v_{tt}x_{tt}\ge\frac12\mathrm{OPT}_\infty(\mu,V)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(m=\tau\) is the valuation matrix dimension, and \(L\) is the total input bit length.
The input includes a symmetric matrix \(V=(v_{st})\in([-1,1]\cap\mathbb Q)^{T\times T}\). For an integer \(N\) with \(N\mu\in\mathbb Z^T\), create \(N\mu_t\) distinct clones of type \(t\). Distinct clones of types \(s,t\) value each other at \(v_{st}\), including when \(s=t\); every clone values itself at zero.
In this fractional hedonic game, a clone \(i\) in a nonempty coalition \(C\) has utility \(u_i(C)=|C|^{-1}\sum_{j\in C\setminus\{i\}}v_{t(i),t(j)}\). Let \(\mathrm{OPT}(N\mu,V)\) be the maximum sum of utilities over all partitions into coalitions, with no stability or incentive constraints.
Define \(\mathrm{OPT}_\infty(\mu,V)=\limsup_{N\to\infty,\;N\mu\in\mathbb Z^T}\mathrm{OPT}(N\mu,V)/N\).
A pair allocation consists of nonnegative rational pair counts per unit population \(x_{\{s,t\}}\) and \(x_{tt}\), satisfying \(2x_{tt}+\sum_{s\ne t}x_{\{s,t\}}\le\mu_t\); the remaining mass forms singletons. Its welfare is \(W_{\mathrm{pair}}(x)=\sum_{s<t}v_{st}x_{\{s,t\}}+\sum_t v_{tt}x_{tt}\), using any fixed ordering of \(T\).

Does a polynomial-time algorithm in \(m,\tau,L\) always produce a feasible pair allocation with \(W_{\mathrm{pair}}(x)\ge\tfrac12\mathrm{OPT}_\infty(\mu,V)\), or is obtaining this approximation NP-hard?

For discrete symmetric fractional hedonic games, maximum-weight matching with unmatched agents as singletons gives a polynomial-time factor-\(2\) approximation; this factor is best possible among pair-and-singleton partitions ([Flammini et al., 2021](https://jair.org/index.php/jair/article/view/12107)). No result settling this exact clone-limit approximation problem was identified in the literature search.

Modeling choices made when packaging the task

  • Restricted rational valuations to [-1,1], following the general valuation domain; larger bounded rational values can be uniformly rescaled.
  • Interpreted diagonal type values as valuations between distinct same-type clones, while retaining zero self-valuation.
  • Specified that the finite optimum ranges over all partitions, without stability or strategyproofness requirements.
  • Specified nonnegative rational pair counts normalized by population size, with all unused mass assigned to zero-welfare singletons.
  • Used m=tau for the valuation matrix dimension and L for total binary input length; the clone population size N is not an explicit input-size parameter.

Result

A polynomial-time algorithm always produces the required pair allocation. Specifically, optimize the pair-allocation linear program exactly. Its optimal value is at least \(\tfrac12\mathrm{OPT}_\infty(\mu,V)\). The factor is sharp, even with one type.

1. The algorithm and its complexity

Fix an ordering of \(T\). Let \(P(\mu,V)\) be the optimum of the linear program

\(\displaystyle \max_{x\ge 0}\left(\sum_{s<t}v_{st}x_{\{s,t\}}+\sum_t v_{tt}x_{tt}\right)\)

subject to, for every \(t\in T\),

\(\displaystyle 2x_{tt}+\sum_{s\ne t}x_{\{s,t\}}\le\mu_t.\)

Return an exact rational optimizer \(x^*\).

This program has \(\tau(\tau+1)/2\) variables and \(\tau\) capacity constraints. Its coefficients are rational, and its encoding length is polynomial in \(\tau\) and \(L\): the constraint coefficients belong to \(\{0,1,2\}\), while the objective coefficients and capacities come directly from the input.

The feasible region is nonempty because \(x=0\) is feasible. Summing its capacity constraints gives

\(\displaystyle 2\left(\sum_{s<t}x_{\{s,t\}}+\sum_t x_{tt}\right)\le\sum_t\mu_t=1.\)

Consequently, the feasible region is bounded. The standard polynomial-time theorem for rational linear programming therefore applies: an exact rational optimizer, with polynomial encoding length, can be computed in time polynomial in the program’s encoding length. See [MIT’s linear-programming notes](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html). Thus the algorithm runs in polynomial time in \(m,\tau,L\), where \(m=\tau\).

2. Converting any coalition partition into a feasible pair allocation

Fix an admissible population size \(N\), meaning \(N\mu\in\mathbb Z^T\), and an arbitrary partition \(\mathcal P\) of its clones.

For each coalition \(C\), write \(k_C=|C|\) and let \(n_t(C)\) be its number of type-\(t\) clones. Define

\(\displaystyle x^{\mathcal P}_{\{s,t\}}=\frac1N\sum_{C\in\mathcal P}\frac{n_s(C)n_t(C)}{k_C}\quad(s<t),\)

and

\(\displaystyle x^{\mathcal P}_{tt}=\frac1N\sum_{C\in\mathcal P}\frac{\binom{n_t(C)}2}{k_C}.\)

These quantities are nonnegative rational numbers. They assign weight \(1/k_C\) to each unordered pair of distinct clones within \(C\), then aggregate by type and normalize by \(N\).

Feasibility. For each type \(t\),

\(\displaystyle 2x^{\mathcal P}_{tt}+\sum_{s\ne t}x^{\mathcal P}_{\{s,t\}}=\frac1N\sum_{C\in\mathcal P}\frac{n_t(C)(n_t(C)-1)+n_t(C)\sum_{s\ne t}n_s(C)}{k_C}.\)

Since \(\sum_s n_s(C)=k_C\), this equals

\(\displaystyle \frac1N\sum_{C\in\mathcal P}n_t(C)\frac{k_C-1}{k_C}\le\frac1N\sum_{C\in\mathcal P}n_t(C)=\mu_t.\)

Hence \(x^{\mathcal P}\) is feasible. This calculation also covers singleton coalitions, whose contribution is zero.

Welfare identity. Symmetry implies that every unordered pair of distinct clones contributes twice to the sum of their coalition’s utilities. Therefore

\(\displaystyle \sum_{i\in C}u_i(C)=\frac2{k_C}\left(\sum_{s<t}v_{st}n_s(C)n_t(C)+\sum_t v_{tt}\binom{n_t(C)}2\right).\)

The diagonal term counts distinct same-type clones; it introduces no self-valuation. Summing over coalitions yields the exact identity

\(\displaystyle W_{\mathrm{pair}}(x^{\mathcal P})=\frac1{2N}\sum_{C\in\mathcal P}\sum_{i\in C}u_i(C).\)

No nonnegativity assumption on valuations was used.

Taking \(\mathcal P\) to be a welfare-maximizing partition and using optimality of \(x^*\), we obtain, for every admissible \(N\),

\(\displaystyle P(\mu,V)=W_{\mathrm{pair}}(x^*)\ge\frac{\mathrm{OPT}(N\mu,V)}{2N}.\)

3. Passing to the clone limit

Because all masses are rational, admissible population sizes include every positive multiple of a common denominator, so there are arbitrarily large admissible \(N\).

Singleton partitions have welfare zero. Moreover, each clone’s utility is at most \(1\), because all valuations are at most \(1\). Thus

\(\displaystyle 0\le\frac{\mathrm{OPT}(N\mu,V)}N\le1.\)

The limsup is consequently finite. Taking the limsup in the inequality proved above gives

\(\displaystyle W_{\mathrm{pair}}(x^*)=P(\mu,V)\ge\tfrac12\mathrm{OPT}_\infty(\mu,V).\)

The rational allocation also has an exact clone interpretation: choose \(N\) divisible by the denominators of all \(\mu_t\) and \(x^*\)-coordinates. Then the required pair counts are integers, and the capacity inequalities permit assigning distinct clones to those pairs, leaving the others as singletons. Each pair of types \(s,t\) contributes total welfare \(v_{st}\). This verifies that the output represents actual pair-and-singleton partitions along infinitely many admissible population sizes.

4. Sharpness

Take \(T=\{t\}\), \(\mu_t=1\), and \(v_{tt}=1\).

A coalition of size \(k\) has total welfare \(k-1\). Hence a partition into \(q\) coalitions has welfare \(N-q\), maximized by the grand coalition. It follows that

\(\displaystyle \mathrm{OPT}(N\mu,V)=N-1,\qquad \mathrm{OPT}_\infty(\mu,V)=1.\)

Every feasible pair allocation satisfies \(2x_{tt}\le1\), so its welfare is at most \(\tfrac12\), attained by \(x_{tt}=\tfrac12\).

Thus no pair-allocation algorithm can guarantee a fraction strictly greater than \(\tfrac12\) of the clone-limit optimum on every input.
