The continuous mirror question, as graded

1. Result and encoding convention

Exact winner-set computation is polynomial-time solvable. It also admits an exact MPC protocol with perfect simulation privacy and polynomial computation, communication, and rounds.

More precisely, the winner-set function belongs to \(\mathrm{FP}\), and deciding whether a specified candidate is a winner belongs to \(\mathrm{P}\). An \(\mathrm{NP}\)-hardness classification under polynomial-time reductions would therefore imply \(\mathrm{P}=\mathrm{NP}\).

For the MPC existence statement, the protocol can specify its public Shamir field. I choose a field whose elements have \(O(\log(D+1))\)-bit representations. If shares are instead supplied over an arbitrarily large field, its representation length must also enter a bit-complexity bound; that length is not bounded by the stated plaintext length \(L\).

The proof below handles the given explicit support of size \(\tau\). It does not enumerate possible preference types.

2. Exact pairwise comparisons with polynomial-length integers

Write each mass as \(\mu_i=n_i/d_i\), where \(n_i,d_i\) are positive integers given in binary. Reduction to lowest terms is unnecessary.

Define

\(B=\prod_{i=1}^{\tau}d_i,\qquad w_i=n_i\prod_{j\ne i}d_j.\)

These are positive integers, and

\(\displaystyle \frac{w_i}{B}=\mu_i,\qquad \sum_{i=1}^{\tau}w_i=B.\)

The second equality follows from the promised normalization \(\sum_i\mu_i=1\). Consequently, \(w_i\leq B\).

Let \(\ell_i\) be the padded binary length of \(d_i\). Since \(d_i<2^{\ell_i}\),

\(\displaystyle B<2^{\sum_i\ell_i}\leq 2^L.\)

Thus, although the numerical value of \(B\) can be exponentially large, its binary length is at most \(L\). Every \(w_i\) also has at most \(L\) bits.

For distinct candidates \(a,b\), define

\(\displaystyle P_{ab}=\sum_{i:Q^i(a,b)=1}w_i,\qquad N_{ab}=\sum_{i:Q^i(a,b)=-1}w_i.\)

Both integers lie between \(0\) and \(B\). Moreover,

\(\displaystyle A_\mu(a,b)=\frac{P_{ab}-N_{ab}}{B}.\)

Because \(B>0\), the following comparisons are exact:

  • \(A_\mu(a,b)>0\) precisely when \(P_{ab}>N_{ab}\).
  • \(A_\mu(a,b)=0\) precisely when \(P_{ab}=N_{ab}\).
  • \(A_\mu(a,b)<0\) precisely when \(P_{ab}<N_{ab}\).

Therefore, each pairwise outcome can be determined by comparing two polynomial-length binary integers. No numerical approximation is involved.

To compute the weights without division, form prefix and suffix products of the denominators. Their products give \(\prod_{j\ne i}d_j\), which is then multiplied by \(n_i\). All these integers have polynomial length. In particular, positivity and normalization imply \(\mu_i\leq1\), hence \(n_i\leq d_i\), so the intermediate products used for each weight are bounded by \(B\).

3. Exact Copeland scores and a Boolean circuit

Write the public parameter as \(\alpha=u/v\), with integers \(0\leq u\leq v\) and \(v>0\).

For each candidate \(a\), let

\(\displaystyle W_a=\bigl|\{b\ne a:P_{ab}>N_{ab}\}\bigr|,\qquad T_a=\bigl|\{b\ne a:P_{ab}=N_{ab}\}\bigr|.\)

Under Copeland with parameter \(\alpha\), the score is

\(\displaystyle s_a=W_a+\frac{u}{v}T_a.\)

Multiplying every score by the same positive integer \(v\) preserves all comparisons and ties. Hence it suffices to compute

\(Z_a=vW_a+uT_a.\)

Since \(W_a+T_a\leq M-1\) and \(u\leq v\),

\(0\leq Z_a\leq v(M-1).\)

Thus these scores also have polynomial binary length. Define the output bit for candidate \(a\) by

\(\displaystyle y_a=\bigwedge_{b=1}^{M}[Z_a\geq Z_b],\)

where brackets denote the Boolean indicator of the enclosed condition. The vector \((y_1,\ldots,y_M)\) represents exactly the entire winner set.

For \(M=1\), the score is zero and the sole output bit is one.

Circuit-size bound

Set

\(b=L+\lceil\log_2(M+1)\rceil+2.\)

All required integer quantities fit in \(b\) bits. Use fixed-length binary circuits throughout:

  • Addition and comparison of \(b\)-bit integers require \(O(b)\) Boolean gates.
  • Schoolbook multiplication requires \(O(b^2)\) Boolean gates.
  • Conditional inclusion of a weight uses its preference indicator to mask its bits.

Prefix and suffix products require \(O(\tau b^2)\) gates. Computing all pairwise sums and their comparisons requires \(O(\tau M^2b)\) gates. Computing the scaled scores and comparing every pair of scores requires \(O(Mb^2+M^2b)\) gates.

Including input decoding and output gates, a sufficient bound is

\(C_0=O(\tau M^2b^2).\)

The circuit has a public, fixed schedule determined by the public dimensions and encoding lengths. Its depth is at most its size. Evaluating it establishes polynomial-time exact winner computation.

The legality and distinctness promises need no verification for this argument.

4. Taking the existing Shamir shares as private inputs

This step makes the requested privacy conditioning explicit.

Choose a public prime \(p\) satisfying

\(D+1<p<2(D+1).\)

Such a prime exists by Bertrand’s postulate and can be found deterministically in polynomial time in \(D\). Use \(\mathbb F_p\) for the original Shamir sharing, with evaluation points \(1,\ldots,D\) and degree at most \(h\). The matrix symbols \(0,1,-1\) have distinct representations because \(p>3\).

Let \(N\) be the number of shared field elements: one for each matrix entry and one for each numerator or denominator bit. The given encoding yields \(N=O(L)\).

Each tallier’s private input to a new Boolean circuit is the binary representation of its existing shares. Fix a public set \(J\) of \(h+1\) talliers. For every original shared value, the circuit computes

\(\displaystyle s=\sum_{j\in J}\lambda_j s_j\pmod p,\qquad \lambda_j=\prod_{\substack{k\in J\\k\ne j}}\frac{-k}{j-k}\pmod p.\)

The evaluation points are distinct and nonzero, so all denominators in these public coefficients are invertible. Consistent degree-\(h\) sharing guarantees that this expression is the original secret.

Crucially, this reconstruction occurs inside the circuit. Neither the shares of honest talliers nor the reconstructed values are opened.

The circuit then decodes:

  • A shared input bit by testing whether its reconstructed value equals \(1\).
  • A strict-preference indicator by testing equality to \(1\).
  • A reverse-preference indicator by testing equality to \(p-1\).

It feeds those decoded values into the circuit from Section 3.

Put \(\ell=\lceil\log_2(2(D+1))\rceil\). Each original share has at most \(\ell\) bits. Multiplication by a public coefficient followed by reduction modulo \(p\) has a Boolean circuit of size \(O(\ell^2)\), using schoolbook multiplication and binary long division. Consequently, the combined circuit \(G\) has size

\(\displaystyle S=O\!\left(\tau M^2b^2+LD\ell^2\right).\)

Its only outputs are the \(M\) winner bits. On inconsistent or otherwise invalid inputs, the fixed circuit still defines a function; correctness is required only on the promised inputs.

5. An exact passive MPC construction

The generic passive arithmetic-circuit setting is treated in [Damgård–Nielsen, Section 3](https://www.iacr.org/archive/crypto2007/46220565/46220565.pdf). Here an elementary Shamir construction suffices, and its perfect simulation argument is given explicitly below.

Internal field and Boolean gates

For evaluating \(G\), use a separate field

\(E=\mathbb F_{2^r},\qquad r=\lceil\log_2(D+1)\rceil.\)

Then \(|E|>D\), so choose public distinct nonzero evaluation points \(\beta_1,\ldots,\beta_D\).

This field has \(r\)-bit representations. Uniform field elements can be sampled exactly using \(r\) independent fair bits. There is no rejection-sampling error or statistical approximation.

A representation of \(E\) can be constructed deterministically in polynomial time in \(D\): enumerate monic degree-\(r\) binary polynomials and test for irreducibility. There are \(2^r=O(D)\) candidates. Testing divisibility by every monic polynomial of degree at most \(\lfloor r/2\rfloor\) is sufficient, and this enumeration is polynomial in \(D\).

Represent every circuit wire by degree-at-most-\(h\) Shamir shares over \(E\). On Boolean constants, the gates are

\(x\mathbin{\mathrm{XOR}}y=x+y,\qquad \mathrm{NOT}(x)=1+x,\qquad x\mathbin{\mathrm{AND}}y=xy.\)

The additions are in characteristic two. These expressions give the correct Boolean truth tables, so induction through the circuit preserves Boolean wire constants.

Input and affine gates

For each private input bit \(x\), its owner chooses a uniformly random polynomial \(f\) of degree at most \(h\), subject to \(f(0)=x\), and privately sends \(f(\beta_j)\) to tallier \(j\).

Affine gates are evaluated locally on shares.

Multiplication and degree reduction

Suppose wires \(x,y\) have sharing polynomials \(f,g\). Tallier \(j\) computes

\(c_j=f(\beta_j)g(\beta_j).\)

These are evaluations of the polynomial \(fg\), whose degree is at most \(2h\). By the stipulated threshold,

\(2h<D.\)

Therefore there are public interpolation coefficients \(\gamma_j\) such that

\(\displaystyle f(0)g(0)=\sum_{j=1}^{D}\gamma_jc_j.\)

For example, interpolate using any fixed \(2h+1\) evaluation points and set the remaining coefficients to zero.

Tallier \(j\) chooses a fresh uniformly random degree-at-most-\(h\) polynomial \(r_j\), subject to \(r_j(0)=c_j\), and privately sends its evaluations to the other talliers. The resulting sharing polynomial is

\(\displaystyle f_{\mathrm{new}}=\sum_{j=1}^{D}\gamma_jr_j.\)

It has degree at most \(h\), and its constant term is exactly \(xy\). This proves multiplication correctness.

Refreshing and opening only outputs

After all gates have been evaluated, refresh each output sharing independently. For each output, every tallier privately distributes a fresh random degree-at-most-\(h\) polynomial with constant term zero. Add all these zero sharings to that output sharing.

Finally, broadcast the refreshed output shares and interpolate their constant terms. These constants are exactly the winner bits.

No intermediate reconstructed input, pairwise outcome, tally, or score is opened.

6. Proof of perfect simulation privacy

Fix a static coalition \(\mathcal A\) of size \(c\leq h\). Its view includes its input shares, random coins, local calculations, private messages involving coalition members, and broadcasts.

We construct a simulator given only those original input shares, the public parameters, and the winner set.

A uniformity fact

Let \(f\) be a uniformly random polynomial of degree at most \(h\), subject to a fixed constant term. Then

\(\bigl(f(\beta_j)\bigr)_{j\in\mathcal A}\)

is uniform in \(E^c\), independently of that constant term.

Indeed, evaluation at these \(c\) distinct nonzero points maps the \(h\) free coefficients onto \(E^c\). Its rank is \(c\): the first \(c\) coefficient columns form a Vandermonde matrix multiplied by invertible nonzero diagonal factors. Every evaluation vector therefore has exactly \(|E|^{h-c}\) preimages.

Simulation before output opening

For coalition-owned input bits, the simulator knows the actual bits from the coalition’s original shares. It samples the coalition’s coins and computes all its outgoing messages normally.

For each honest-owned input bit, the simulator supplies independent uniform elements as the evaluations received by coalition members. The uniformity fact proves that this distribution is exact.

Affine gates require only local calculations.

At a multiplication gate, the simulator knows the coalition’s current wire shares. It can therefore compute every coalition member’s \(c_j\), sample its resharing polynomial, and compute its messages normally.

For each honest tallier’s resharing, the evaluations received by the coalition are again independent uniform elements. This remains true conditional on the complete preceding execution: the new polynomial coefficients are fresh, and the uniformity fact applies for every possible constant \(c_j\).

The simulator then computes the coalition’s new wire shares from these messages. Induction over the gates proves that the entire view before output opening has exactly the real distribution.

The same argument simulates the messages exchanged during the final zero-sharing refresh.

Simulation of output opening

For one output, consider the vector space

\(\displaystyle U=\{q\in E[X]:\deg q\leq h,\ q(0)=0,\ q(\beta_j)=0\text{ for every }j\in\mathcal A\}.\)

The constraints are independent, so \(\dim U=h-c\).

Conditional on an honest tallier’s refresh messages to the coalition, that tallier’s zero polynomial is uniform in an affine translate of \(U\). Its remaining randomness is independent of the previous execution. Since at least one tallier is honest, adding the refresh polynomials makes the refreshed output polynomial uniform among all degree-at-most-\(h\) polynomials having:

  • Constant term equal to the actual output bit.
  • Evaluations at coalition points equal to the coalition’s refreshed shares.

This statement also holds when \(c=h\), in which case those conditions determine a unique polynomial.

The simulator knows both the output bit, from the winner set, and the coalition’s refreshed shares. It samples precisely this conditional polynomial distribution and supplies its evaluations as the honest talliers’ final broadcasts.

Each output uses independent refresh randomness, so this argument applies jointly to the entire output vector.

Thus, for every fixed valid input-share tuple, the simulator’s view and the real coalition view have identical distributions. This is perfect simulation privacy with exactly the conditioning required in the question.

and the circuit-size bound

All random coefficients are generated within these costs. Public field setup is deterministic. There is no trusted preprocessing dealer, no uncounted supply of multiplication triples, and no correctness or privacy error.

Therefore the intended formulation is fully resolved: exact rational-support Copeland winner computation is polynomial-time solvable and has the required perfectly private polynomial-resource MPC protocol.
