The continuous mirror question, as graded

Given a graph \(G\), \(p\), types \(T\) with rational masses \(\mu_t\) summing to \(1\), additive valuations \(u_t\), and rational supplies \(b_v\), decide whether there are a set \(P\subseteq V(G)\) of size \(p\) and nonnegative masses \(x_{t,S}\) over connected bundles \(S\) (including the empty bundle) such that \(\sum_S x_{t,S}=\mu_t\), each \(v\in P\) is assigned to mass \(b_v\), no other vertex is assigned, and every positively used bundle pair satisfies \(u_t(S)\ge u_t(S')\) for the type evaluating it. Determine the parameterized complexity in \(p+\tau\), where \(\tau=|T|\); in particular, does W[1]-hardness persist on stars with unary valuations?

Packaged proof task (what the prover saw — nothing else)

Given a finite simple undirected graph \(G\) with \(m\ge1\) vertices and an integer \(0\le p\le m\), a society is given by its support: a list \(T\) of \(\tau\ge1\) distinct valuation types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has additive valuations \(u_t:V(G)\to\mathbb N_{\ge0}\), encoded in binary unless unary encoding is specified; each vertex has a binary rational supply \(0<b_v\le1\). Let \(L\) be the total input bit length.
A bundle is either empty or a vertex set \(S\) whose induced graph \(G[S]\) is connected; \(u_t(\varnothing)=0\).
Feasibility means choosing \(P\subseteq V(G)\) with \(|P|=p\) and real masses \(x_{t,S}\ge0\) over bundles \(S\subseteq P\), such that \(\sum_S x_{t,S}=\mu_t\) for every type and \(\sum_t\sum_{S\ni v}x_{t,S}=b_v\) for every \(v\in P\); vertices outside \(P\) are unassigned.
Envy-freeness requires \(u_t(S)\ge u_t(S')\) whenever \(x_{t,S}>0\) and \(x_{t',S'}>0\), for all types \(t,t'\), including \(t=t'\). Bundles used by different portions of society may overlap, subject to the supply equalities.
State running times in \(m,\tau,L,p\).

Is this feasibility problem in \(\mathrm P\), or is it NP-hard?
If NP-hard, is it FPT parameterized by \(p+\tau\)? In particular, on stars with unary valuations, is it FPT or \(\mathrm{W[1]}\)-hard for that parameter?

Discrete incomplete connected envy-free allocation is \(\mathrm{W[1]}\)-hard parameterized by \(p+n\), where \(n\) is the number of agents, even on stars with unary valuations and with empty bundles allowed. [E S–Lokshtanov](https://drops.dagstuhl.de/storage/00lipics/lipics-vol360-fsttcs2025/LIPIcs.FSTTCS.2025.29/LIPIcs.FSTTCS.2025.29.pdf)
The complete discrete special case \(p=m\) is NP-complete on stars, implying NP-hardness of the incomplete problem. [Bouveret et al.](https://www.ijcai.org/proceedings/2017/0020.pdf)

Classification

The problem is \(\mathrm{NP}\)-complete. It is also \(\mathrm{W[1]}\)-hard parameterized by \(p+\tau\), even on stars with unary valuations and with every type mass and vertex supply equal to \(1/\tau\). Consequently, an FPT algorithm for this parameter would imply \(\mathrm{FPT}=\mathrm{W[1]}\).

The case \(p=0\) is always feasible: give every type the empty bundle. The hardness concerns positive \(p\).

The proof below handles arbitrary real mass splitting and overlapping bundles explicitly.

1. The source problem

Exact-Cardinality Vector Sum takes nonnegative integer vectors \(w_1,\ldots,w_N\in\mathbb N_{\ge0}^d\), a target \(a\in\mathbb N_{\ge0}^d\), and an integer \(k\). It asks whether some \(I\subseteq\{1,\ldots,N\}\) satisfies

\(\displaystyle |I|=k,\qquad \sum_{i\in I}w_i=a.\)

We may restrict to \(d\ge1\) and \(1\le k\le N\), since the excluded cases are trivial.

Two hardness facts will be used:

  • With unary numbers, this problem is \(\mathrm{W[1]}\)-hard parameterized by \(k+d\). This follows from Proposition 3.2 of [E S–Lokshtanov](https://drops.dagstuhl.de/storage/00lipics/lipics-vol360-fsttcs2025/LIPIcs.FSTTCS.2025.29/LIPIcs.FSTTCS.2025.29.pdf), whose hard instances have numbers bounded by a parameter-dependent polynomial in \(N\).
  • It is also classically \(\mathrm{NP}\)-hard with unary numbers. Indeed, take an instance of the standard \(\mathrm{NP}\)-complete Exact Cover by 3-Sets problem with universe size \(3q\). Use each triple’s incidence vector, set \(d=3q\), \(k=q\), and let every target coordinate equal \(1\). A selection sums to this target exactly when its triples form an exact cover.

2. Reduction to the mass-based problem

Fix a source instance. Define

\(\displaystyle R=\max\bigl(\{1\}\cup\{w_{i,\ell}:1\le i\le N,\ 1\le\ell\le d\}\cup\{a_\ell:1\le\ell\le d\}\bigr),\qquad B=2R+1.\)

Construct a star with center \(c\) and leaves

\(\displaystyle a_1^*,\ldots,a_d^*,\quad b_1^*,\ldots,b_d^*,\quad v_1,\ldots,v_N.\)

There are \(2d+1\) types:

\(\displaystyle A_1,\ldots,A_d,\quad D_1,\ldots,D_d,\quad C.\)

Set

\(\displaystyle m=N+2d+1,\qquad \tau=2d+1,\qquad p=2d+k+1,\qquad \alpha=\frac1{2d+1}.\)

Every type has mass \(\alpha\), and every vertex has supply \(\alpha\).

For each coordinate \(\ell\), define valuations by the following table. All entries not specified are zero.

| Vertex | \(u_{A_\ell}\) | \(u_{D_\ell}\) | \(u_C\) |
|---|---:|---:|---:|
| \(c\) | \(B\) | \(B\) | \(1\) |
| \(v_i\) | \(B+w_{i,\ell}\) | \(B-w_{i,\ell}\) | \(1\) |
| \(a_\ell^*\) | \((k+1)B+a_\ell\) | \(0\) | \(1\) |
| \(b_\ell^*\) | \(0\) | \((k+1)B-a_\ell\) | \(1\) |
| Other private leaves | \(0\) | \(0\) | \(1\) |

All valuations are nonnegative integers. In particular, \(B-w_{i,\ell}\ge B-R>0\).

Each type other than \(C\) has a unique favorite singleton: its corresponding private leaf. To check this, every candidate singleton has value at most \(B+R\), whereas even the smaller private value satisfies

\(\displaystyle (k+1)B-a_\ell\ge2B-R>B+R,\)

because \(k\ge1\), \(a_\ell\le R\), and \(B>2R\).

The types are distinct: different coordinate types have different private leaves with positive value, and \(C\) values the center at \(1\), whereas all other types value it at \(B>1\).

This construction resembles the cited discrete star reduction. The following argument supplies the additional justification needed for real masses.

3. Rigidity under arbitrary mass splitting

Assume that the constructed instance has a feasible envy-free allocation. Call a pair \((t,S)\) used when \(x_{t,S}>0\).

3.1. Type \(C\) exhausts the center’s supply

Same-type envy-freeness implies that all bundles used by a fixed type have equal value to that type: applying the envy inequality in both directions gives equality.

Since \(C\) values every vertex at \(1\), all its used bundles therefore have a common cardinality \(q\). Moreover, \(C\)’s envy-freeness implies that every used bundle, regardless of its type, has cardinality at most \(q\).

Summing the supply equalities gives

\(\displaystyle \sum_t\sum_S x_{t,S}|S| =\sum_{v\in P}b_v =p\alpha.\)

The total allocation mass is \(1\). If \(q\le1\), the left side would be at most \(1\). But

\(\displaystyle p\alpha=\frac{2d+k+1}{2d+1}>1.\)

Thus \(q\ge2\). Every connected bundle of at least two vertices in a star contains its center. Consequently, every bundle used by \(C\) contains \(c\).

Type \(C\) has total mass \(\alpha\), exactly the supply of \(c\). Hence no other type can use a bundle containing \(c\).

3.2. Every other type receives singleton bundles

A connected bundle avoiding the center is either empty or a singleton leaf.

For any type \(A_\ell\) or \(D_\ell\), every bundle used by \(C\) has value at least \(B\), since it contains \(c\). Envy-freeness therefore requires every bundle used by that type to have value at least \(B>0\). Its empty bundle is impossible.

Thus every used bundle of every type other than \(C\) is a singleton. Returning to the summed supply equation,

\(\displaystyle p\alpha=q\alpha+2d\alpha.\)

It follows that

\(\displaystyle q=p-2d=k+1.\)

3.3. Type \(C\) cannot use private leaves

Consider any private leaf belonging to a type \(t\ne C\), and let its value to \(t\) be \(H_t\).

Every bundle used by \(t\) is a singleton, so its value is at most \(H_t\), the maximum singleton value. If a bundle used by \(C\) contained that private leaf, it would also contain \(c\), and its value to \(t\) would be at least \(H_t+B>H_t\). This contradicts envy-freeness.

Hence every bundle used by \(C\) consists of the center and exactly \(k\) candidate leaves.

3.4. Every other type must use its private singleton

For any type \(t\ne C\), a bundle used by \(C\) has value at least

\(\displaystyle B+k(B-R)=(k+1)B-kR.\)

This exceeds every candidate singleton’s possible value \(B+R\), because

\(\displaystyle (k+1)B-kR-(B+R) =kB-(k+1)R =(k-1)R+k>0.\)

Other types’ private leaves have value zero to \(t\). Therefore, the only singleton that can prevent \(t\) from envying \(C\) is its own private leaf.

Thus all of type \(A_\ell\)’s mass uses \(\{a_\ell^*\}\), and all of type \(D_\ell\)’s mass uses \(\{b_\ell^*\}\).

All \(2d\) private leaves must consequently belong to \(P\). The center also belongs to \(P\). Since \(|P|=2d+k+1\), exactly \(k\) candidate leaves belong to \(P\); write their indices as \(I\).

Every bundle used by \(C\) has size \(k+1\), contains the center, and avoids private leaves. It must therefore be exactly

\(\displaystyle S_C=\{c\}\cup\{v_i:i\in I\}.\)

We have proved that every feasible envy-free mass allocation in this construction is deterministic for each type.

4. Correctness of the reduction

Forward direction

Suppose the mass-based instance is feasible. By the rigidity argument, \(|I|=k\) and \(C\) uses \(S_C\).

Type \(A_\ell\) does not envy \(C\), so

\(\displaystyle (k+1)B+a_\ell \ge u_{A_\ell}(S_C) =(k+1)B+\sum_{i\in I}w_{i,\ell}.\)

Thus \(\sum_{i\in I}w_{i,\ell}\le a_\ell\).

Likewise, type \(D_\ell\) does not envy \(C\), so

\(\displaystyle (k+1)B-a_\ell \ge u_{D_\ell}(S_C) =(k+1)B-\sum_{i\in I}w_{i,\ell}.\)

Thus \(\sum_{i\in I}w_{i,\ell}\ge a_\ell\).

Together, these inequalities yield

\(\displaystyle \sum_{i\in I}w_{i,\ell}=a_\ell\)

for every coordinate \(\ell\). Therefore \(I\) solves the source instance.

Reverse direction

Suppose \(I\) solves the source instance. Select the center, all private leaves, and the candidate leaves indexed by \(I\). Assign mass \(\alpha\):

  • of \(C\) to \(\{c\}\cup\{v_i:i\in I\}\);
  • of \(A_\ell\) to \(\{a_\ell^*\}\);
  • of \(D_\ell\) to \(\{b_\ell^*\}\).

These bundles are connected, disjoint, and together contain exactly \(p\) vertices. Every selected vertex receives exactly its supply \(\alpha\), and every type receives exactly its mass \(\alpha\).

Type \(C\) values its own bundle at \(k+1\), and every other used bundle at \(1\). Each coordinate type values \(C\)’s bundle exactly as much as its own private singleton, because the selected vectors sum to the target. It values every other private singleton at zero.

All envy inequalities hold, proving feasibility.

Encoding and parameter bounds

The output parameter is

\(\displaystyle p+\tau=k+4d+2.\)

The largest valuation is at most \((k+1)(2R+1)+R\), which is \(O((k+1)R)\). The unary valuation encoding has length

\(\displaystyle O\bigl(m\tau(k+1)R\bigr).\)

For a unary source instance, both \(R\) and \(k\le N\) are bounded by its input length, so the reduction is polynomial-time. All masses and supplies have binary encoding length \(O(\log\tau)\).

The reduction therefore proves both classical \(\mathrm{NP}\)-hardness and parameterized \(\mathrm{W[1]}\)-hardness under the claimed restrictions.

5. Membership in NP

Fix a feasible instance and its selected set \(P\). Restrict attention to the finitely many used pairs \((t,S)\). Their masses satisfy

\(\displaystyle Ax=h,\qquad x\ge0,\)

where \(A\) is a zero-one matrix with \(\tau+p\) rows: one row for each type and one for each selected vertex. The vector \(h\) contains the type masses and selected supplies.

This system has a solution with at most \(\tau+p\) positive variables. Here is a direct justification.

Choose a feasible solution with minimum support. If its active columns were linearly dependent, there would be a nonzero vector \(z\) on these columns with \(Az=0\). Every column has exactly one \(1\) among the type rows, so summing those rows gives \(\sum_i z_i=0\). Consequently, \(z\) has both positive and negative entries.

Moving from \(x\) in direction \(z\) until the first coordinate reaches zero preserves the equalities and nonnegativity, and strictly reduces the support. This contradicts minimality. Hence its active columns are independent, and there are at most \(\tau+p\).

Selecting a nonsingular square minor determines these masses uniquely. By Cramer’s rule, they are rational. Let \(r\le\tau+p\) be the support size. A common denominator for the relevant input rationals has \(O(L)\) bits, and determinants of the zero-one minors have \(O(r\log(r+1))\) bits. Thus each mass has

\(\displaystyle O\bigl(L+r\log(r+1)\bigr)\)

bits.

The new solution uses only previously used pairs. Removing used pairs cannot introduce envy, so it remains envy-free.

A certificate therefore consists of \(P\), at most \(\tau+p\) type-bundle pairs, and their rational masses. Connectivity, type totals, supplies, and every pairwise envy inequality can all be checked in \((m+\tau+L)^{O(1)}\) bit operations.

This proves membership in \(\mathrm{NP}\), and hence \(\mathrm{NP}\)-completeness.

6. An explicit running-time upper bound

There is an exact algorithm running in

\(\displaystyle \binom{m}{p}\,2^{p\tau}\bigl(\tau2^p+p+L\bigr)^{O(1)}.\)

To prove this bound, enumerate each possible selected set \(P\), and its at most \(2^p\) connected-or-empty bundles.

For every type \(t\), guess a bundle \(Q_t\subseteq P\) and set \(q_t=u_t(Q_t)\). There are at most \(2^{p\tau}\) joint guesses. These guesses cover every possible feasible allocation, because each positive-mass type has a used bundle and same-type envy-freeness makes its own utility constant.

For a fixed guess, permit variable \(x_{t,S}\) only when

\(\displaystyle u_t(S)=q_t,\qquad u_j(S)\le q_j\quad\text{for every type }j.\)

Solve the type-total and supply equalities with these permitted variables and nonnegativity. This is a rational linear program with at most \(\tau2^p\) variables and \(\tau+p\) equality constraints.

Every feasible allocation appears under one of the guesses. Conversely, any feasible solution of one of these linear programs is envy-free: type \(j\)’s own used bundles have value \(q_j\), and all used bundles have value at most \(q_j\) to it.

The bound is XP for \(p+\tau\). The hardness proof excludes a running time \(f(p+\tau)(m+\tau+L)^{O(1)}\), even for unary-valued stars, unless \(\mathrm{FPT}=\mathrm{W[1]}\).
