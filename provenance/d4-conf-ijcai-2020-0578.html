2. The finite problem used for hardness

We use the stated finite-electorate hardness theorem: given an explicitly listed, group-separable profile with \(n\geq 1\) voters, committee size \(1\leq k\leq m\), and nonnegative integer threshold \(t\), deciding whether some committee \(W\) satisfies

\[ \sum_{v=1}^{n}\min_{c\in W}\bigl(\operatorname{pos}_{v}(c)-1\bigr)\leq t \]

is \(\mathrm{NP}\)-hard.

We also use the structural fact that every group-separable profile has an exact clone decomposition consisting entirely of \(Q\)-nodes, whose children can only be reversed. Both facts are stated in [Faliszewski, Karpov, and Obraztsova, Sections 3–4](https://www.ijcai.org/proceedings/2020/0029.pdf).

Below, we give an explicit polynomial construction of the required tree, using this structural existence result.

3. Constructing a tree satisfying the exact promise

Let \(P\) be a nonempty group-separable profile, represented by its \(\tau\) distinct rankings. A common interval is a nonempty candidate set consecutive in every ranking. Let \(\mathcal I\) denote their family.

Two sets overlap if their intersection is nonempty and neither contains the other. A member of \(\mathcal I\) is strong if it overlaps no member of \(\mathcal I\).

Claim. In any exact decomposition tree containing only reversal nodes, the strong common intervals are precisely the leaf sets of its subtrees.

Proof. First consider a subtree leaf set \(S\). Every common interval is, by exactness, a subtree leaf set or a union of consecutive children at some node. Its generating node is an ancestor of, a descendant of, or incomparable with the node generating \(S\). Accordingly, that common interval contains \(S\), is contained in \(S\), or is disjoint from \(S\). Thus \(S\) is strong.

Conversely, suppose a common interval \(A\) is not a subtree leaf set. By exactness, it is the union of consecutive children indexed from \(a\) through \(b\) at some node with \(r\) children, where \(b-a+1\geq 2\) and this is a proper union.

If \(a>1\), the union of children indexed \(a-1\) and \(a\) is a common interval overlapping \(A\). If \(a=1\), properness gives \(b<r\), and the union of children indexed \(b\) and \(b+1\) overlaps \(A\). Hence \(A\) is not strong. This proves the claim.

To construct the tree, fix one supported ranking as reference and index its candidates in order. Every common interval is an interval in this reference ranking, so there are at most \(m(m+1)/2\) possibilities.

For each supported ranking \(\sigma\), a reference interval of cardinality \(s\) is consecutive in \(\sigma\) exactly when the maximum and minimum positions of its candidates differ by \(s-1\). Incrementally maintaining these extrema enumerates \(\mathcal I\) in \(O(\tau m^2)\) elementary operations.

Compare every pair of members of \(\mathcal I\) to identify the strong ones. This takes \(O(m^4)\) elementary operations. Strong intervals are laminar: two of them cannot overlap, by definition. Make each strong interval other than \(C\) a child of its smallest strict strong superset, and order siblings by their positions in the reference ranking.

The structural theorem guarantees an exact all-\(Q\) decomposition. By the claim, its subtree leaf sets are exactly the strong intervals just computed. Consequently, the constructed inclusion tree has the same hierarchy. At each node, the reference ranking orders its children either in the original order or its reversal. Choosing that order therefore preserves both the permitted rankings and the represented common intervals.

Thus the constructed tree satisfies both parts of the task’s promise. Every internal node has at least two children: singleton sets are strong, so maximal proper strong subsets cover their parent, and one proper subset alone cannot cover it.

With binary candidate indices, this construction takes

\[ O\!\left(L+(\tau m^2+m^4)\log(m+1)\right) \]

bit operations.

4. The normalization reduction

Take an instance of the finite problem from Section 2. Retain its candidate set and committee size. For every distinct ranking \(\sigma\), let \(r_\sigma\) be its multiplicity among the \(n\) voters. Output the mass

\[ \mu_\sigma=\frac{r_\sigma}{n} \]

and threshold

\[ \theta=\frac{t}{n}. \]

Every mass is positive, and their sum is one. Removing repeated copies of rankings does not change which candidate sets are consecutive in every ranking. Construct the exact tree from Section 3 and include it in the output.

For every committee \(W\), grouping identical rankings gives the identity

\[ \sum_\sigma\mu_\sigma \min_{c\in W}\bigl(\operatorname{pos}_\sigma(c)-1\bigr) = \frac{1}{n}\sum_{v=1}^{n} \min_{c\in W}\bigl(\operatorname{pos}_{v}(c)-1\bigr). \]

Because \(n>0\), the left-hand side is at most \(\theta=t/n\) exactly when the original dissatisfaction sum is at most \(t\). Committee cardinality is unchanged. This proves equivalence in both directions, without any tie-breaking assumption.

For the encoding bound, write \(S\) for the source input bit length. We have \(\tau\leq n\). Each mass requires \(O(\log(n+1))\) bits, and the threshold requires \(O(\log(t+1)+\log(n+1))\) bits. The output therefore has polynomial size in \(S\).

Sorting the explicit rankings and counting multiplicities takes polynomial time in \(S\); the tree construction takes \(O((\tau m^2+m^4)\log(m+1))\) bit operations after parsing. Hence the entire reduction is polynomial-time and always produces a promised instance. The target problem is therefore \(\mathrm{NP}\)-hard.

5. Exact verification and running times

A certificate lists \(k\) distinct candidates. Constructing the position table costs \(O(L+\tau m\log(m+1))\) bit operations. Then each ranking’s dissatisfaction

\[ d_\sigma=\min_{c\in W}\bigl(\operatorname{pos}_\sigma(c)-1\bigr) \]

can be computed by inspecting the \(k\) committee members.

Write \(\mu_\sigma=p_\sigma/q_\sigma\) and \(\theta=a/b\), with positive denominators. Set \(Q=b\prod_\sigma q_\sigma\). The threshold comparison is equivalent to the integer comparison

\[ \sum_\sigma p_\sigma d_\sigma\frac{Q}{q_\sigma} \leq a\frac{Q}{b}. \]

The product \(Q\) has at most \(O(L)\) bits. Every integer used in this computation has \(O(B)\) bits, where

\[ B=L+\left\lceil\log_2(m+1)\right\rceil +\left\lceil\log_2(\tau+1)\right\rceil+2. \]

Using schoolbook integer arithmetic, certificate verification consequently takes

\[ O\!\left( L+\tau(m+k)\log(m+1)+(\tau+1)B^2 \right) \]

bit operations. Thus the problem belongs to \(\mathrm{NP}\) on its promised domain.

For completeness, exhaustive enumeration gives a deterministic decision algorithm taking

\[ O\!\left( L+\tau m\log(m+1) +\binom{m}{k} \left[\tau k\log(m+1)+(\tau+1)B^2\right] \right) \]

bit operations. It never expands rational masses into replicated voters.

Together with the reduction, this establishes \(\mathrm{NP}\)-completeness. In particular, a polynomial-time algorithm in the unrestricted input parameters would imply \(\mathrm{P}=\mathrm{NP}\).
