The continuous mirror question, as graded

Given a finite alternative set \(X\), an explicitly listed common menu domain \(\mathcal D\), complete choice correspondences \(c_t\) for \(t=1,\ldots,\tau\), positive rational masses \(\mu_t\) summing to \(1\), and a rational budget \(B\), decide whether there are finite books \(R_t\) of complete preorders such that every menu's choice under \(c_t\) is maximal under some preorder in \(R_t\), and \(\sum_{t=1}^{\tau}\mu_t|R_t|\le B\).

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a finite set of \(m\ge 1\) alternatives and let \(\varnothing\ne\mathcal D\subseteq 2^X\setminus\{\varnothing\}\) be an explicitly listed common menu domain; write \(d=|\mathcal D|\).
A society is given by its support: the list of its \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type is a choice correspondence given explicitly on every menu, with \(\varnothing\ne c_t(A)\subseteq A\) for every \(A\in\mathcal D\). The budget is \(B\in\mathbb Q_{\ge 0}\), encoded in binary.
A book \(R_t\) is a finite nonempty set of complete preorders on \(X\). It rationalizes type \(t\) if, for every \(A\in\mathcal D\), some \(\succeq\in R_t\) has its set of maximal elements in \(A\) exactly equal to \(c_t(A)\); ties are allowed and all tied maximal alternatives are chosen.
Decide whether rationalizing books exist with \(\sum_{t=1}^{\tau}\mu_t|R_t|\le B\). Each type receives one book, and book sizes are integers. Let \(L\) be the total input bit length; state running times in \(m,\tau,d,L\).

Is this mass-weighted rationalization decision problem solvable in polynomial time, or is it NP-hard?

For one explicitly listed choice correspondence on an arbitrary nonempty menu domain, deciding whether at most \(K\) complete preorders rationalize it is NP-complete, even for single-valued choice ([Apesteguia and Ballester](https://jose-apesteguia.github.io/complexity.pdf)).
No result settling the exact mass-weighted problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted 'choice is maximal' as exact equality with the entire maximal-element set, as required by the discrete definition; mere inclusion would change the problem.
  • Required a nonempty menu domain, nonempty menus, and nonempty choices contained in their menus, following the discrete definition.
  • Made every choice correspondence explicit on every listed menu.
  • Specified a nonnegative binary-rational budget, the natural domain for a bound on nonnegative cost.
  • Specified finite nonempty books of complete preorders, with ties retained and integer cardinalities; each type receives one book as in the graded question.
  • Defined m as the number of alternatives, d as the menu-domain size, and L as total input bit length.

Result

The mass-weighted rationalization decision problem is \(\mathrm{NP}\)-complete. Hardness holds even with two distinct, single-valued types, each of mass \(\frac12\).

The proof also identifies the weighted optimum exactly in terms of the separate types’ minimum book sizes.

1. Individual minima and the weighted optimum

For each type \(t\), define
\[ \kappa_t=\min\{|R|:R\text{ is a nonempty book rationalizing }c_t\}. \]

This minimum exists, and \(1\leq\kappa_t\leq d\). To prove the upper bound, fix a menu \(A\). Define a complete preorder that ties all alternatives in \(c_t(A)\) above all alternatives outside \(c_t(A)\). Its maximal elements in \(A\) are exactly \(c_t(A)\). Taking one such preorder for each menu gives a rationalizing book containing at most \(d\) distinct preorders. The lower bound follows from the requirement that books be nonempty.

The minimum weighted cost is exactly
\[ \operatorname{OPT}=\sum_{t=1}^{\tau}\mu_t\kappa_t. \]

Indeed, every feasible family satisfies \(|R_t|\geq\kappa_t\), and positivity of the masses implies that its cost is at least this sum. Conversely, choosing a minimum book independently for every type attains the sum. There are no constraints connecting different types’ books.

Consequently, \(B<1\) always gives a no-instance, while \(B\geq d\) always gives a yes-instance. The intermediate budgets contain the computational difficulty.

2. Membership in \(\mathrm{NP}\)

Polynomial certificate size

Suppose a feasible family of books exists. For each type and each menu, retain one preorder from its book that rationalizes that menu. Delete every other preorder.

Each resulting book is nonempty, contains at most \(d\) preorders, and still rationalizes every menu. Its size has not increased, so neither has the weighted cost.

Encode a complete preorder by a rank function \(r:X\to\{1,\ldots,m\}\), with
\[ x\succeq y\quad\Longleftrightarrow\quad r(x)\geq r(y). \]
Every such function defines a complete preorder, and every complete preorder admits such an encoding by numbering its indifference classes.

Thus a certificate lists \(k_t\leq d\) rank functions for each type. Its length is
\[ O\!\left(\tau d m\log(m+1)\right) \]
bits, which is polynomial in the explicit input length \(L\).

Verification of rationalization

For each listed rank function and each menu \(A\), compute its maximum rank on \(A\). The alternatives attaining that rank are exactly the maximal elements. Compare this set with \(c_t(A)\), and verify that every menu has a matching preorder.

This takes
\[ O\!\left(\tau d^2m\log(m+1)\right) \]
bit operations using direct scans. Duplicate rank encodings may be removed first; alternatively, counting every listed entry only increases the certified cost, so accepting such a list still certifies a feasible set of preorders.

Exact verification of the budget

Write \(\mu_t=p_t/q_t\) and \(B=a/b\), with positive denominators, and form
\[ Q=b\prod_{t=1}^{\tau}q_t. \]
The budget condition is equivalent to the integer comparison
\[ \sum_{t=1}^{\tau}p_tk_t(Q/q_t)\leq a(Q/b). \]

Because all input numerators and denominators together have at most \(L\) bits, and \(k_t\leq d\), the integers involved have \(O(L+\log d)=O(L)\) bits. Ordinary integer multiplication and division therefore give a conservative arithmetic bound of \(O((\tau+1)L^2)\).

A verifier consequently runs in
\[ O\!\left(\tau d^2m\log(m+1)+(\tau+1)L^2\right) \]
bit operations. This proves membership in \(\mathrm{NP}\).

3. \(\mathrm{NP}\)-hardness

Direct reduction

The supplied single-type result is precisely applicable: the source problem has an explicitly listed arbitrary nonempty menu domain, complete preorders, and the requirement that each menu be explained exactly by some preorder. [Apesteguia and Ballester, Theorem 2 and Corollary 3](https://jose-apesteguia.github.io/complexity.pdf) establish its \(\mathrm{NP}\)-completeness, including for single-valued choice.

Given a source instance \((X,\mathcal D,c,K)\), use one type with \(c_1=c\), mass \(\mu_1=1\), and budget \(B=K\). Then
\[ \mu_1|R_1|\leq B\quad\Longleftrightarrow\quad |R_1|\leq K. \]
This is a polynomial reduction; copying the instance and adding the mass takes linear time in its bit length.

Hardness with two distinct, equally weighted types

The conclusion also holds for a society with two distinct types.

Start from a single-valued source instance. Introduce fresh alternatives \(a,b\), and set
\[ X'=X\cup\{a,b\},\qquad \mathcal D'=\mathcal D\cup\{\{a,b\}\}. \]

Define the first type by retaining all original choices and choosing \(a\) from the new menu:
\[ c_1(A)=c(A)\quad(A\in\mathcal D),\qquad c_1(\{a,b\})=\{a\}. \]

Its minimum book size equals the original minimum, denoted \(\kappa(c)\):

  • Every original rationalizing preorder extends to \(X'\) by placing \(a\) strictly above \(b\), and both above \(X\). This preserves choices on original menus and explains the new menu, so \(\kappa_1\leq\kappa(c)\).
  • Restricting every preorder in a book for \(c_1\) to \(X\) rationalizes \(c\). Removing duplicate restrictions cannot increase its size, so \(\kappa(c)\leq\kappa_1\).

Hence \(\kappa_1=\kappa(c)\).

For the second type, fix any strict total order on \(X'\) with \(b\) above \(a\), and let \(c_2\) choose its unique maximum from every menu in \(\mathcal D'\). This type has \(\kappa_2=1\). The types are distinct because their choices from \(\{a,b\}\) differ.

Give both types mass \(\frac12\), and choose budget \(B=(K+1)/2\). Section 1 then gives
\[ \operatorname{OPT}=\frac{\kappa(c)+1}{2}, \]
and therefore
\[ \operatorname{OPT}\leq B\quad\Longleftrightarrow\quad\kappa(c)\leq K. \]

All choices remain single-valued, both masses are positive binary rationals, and the domain is common and explicitly listed. Constructing the additional type by scanning the menus takes polynomial time, bounded by \(O(dm\log(m+1)+L)\) bit operations.

4. A deterministic exact running-time bound

For completeness, the problem also admits an explicit finite algorithm.

Enumerate all \(m^m\) rank functions \(X\to\{1,\ldots,m\}\). For each type and rank function, record the subset of menus it explains exactly. Computing these subsets takes
\[ O\!\left(\tau m^m d m\log(m+1)\right) \]
bit operations.

For each type, use dynamic programming over subsets \(S\) of the \(d\) menus. Initialize \(F(\varnothing)=0\). For every coverage subset \(C\), allow the transition
\[ F(S\cup C)\leftarrow\min\{F(S\cup C),F(S)+1\}. \]
Ignore transitions with \(S\cup C=S\), and process subsets in increasing binary-mask order. Every remaining transition increases the mask, so this computes shortest paths in an acyclic graph.

A path to the full menu set specifies a rationalizing book. Conversely, any rationalizing book supplies a path after omitting preorders that add no coverage. Thus the final value is exactly \(\kappa_t\).

Accounting for \(d\)-bit masks, the total deterministic running time is bounded by
\[ O\!\left(\tau m^m d\bigl(m\log(m+1)+2^d\bigr)+(\tau+1)L^2\right). \]
Finally, compare the exact weighted sum of these minima with \(B\).

Combining membership and hardness proves \(\mathrm{NP}\)-completeness. A polynomial-time algorithm for all instances exists if and only if \(\mathrm P=\mathrm{NP}\).
