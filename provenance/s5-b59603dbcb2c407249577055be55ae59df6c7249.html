The continuous mirror question, as graded

Given a type distribution \(\mu\) over \(T=\{1,2,3\}\), representative valuation oracles \(v_t\), and \(\epsilon>0\), with one normalized cake supplied per recurring unit of population, compute cuts \(0\le x\le y\le1\) and a bijection \(\pi\) assigning the intervals \(A_1=[0,x]\), \(A_2=[x,y]\), and \(A_3=[y,1]\) to types so that \(\max_{t,s\in T}(V_t(A_{\pi(s)})-V_t(A_{\pi(t)}))_+\le\epsilon\), and determine the worst-case number of type-level Robertson–Webb queries.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) denotes support size, not the number of possible types. Here \(T=\{1,2,3\}\), \(\tau=3\), \(\mu_t>0\), and \(\sum_t\mu_t=1\).
Each type has an oracle for a nonnegative integrable density \(v_t\), with \(V_t(I)=\int_I v_t(z)\,dz\) and \(V_t([0,1])=1\); no positive lower bound or finite uniform upper bound is assumed.
One normalized cake is supplied per recurring population unit. The required output assigns one interval to each type; masses do not weight the envy inequalities or impose interval-size constraints.
A deterministic Robertson–Webb protocol may ask \(\operatorname{Cut}_t(\alpha)\), returning the leftmost \(z\) with \(V_t([0,z])=\alpha\), for \(\alpha\in[0,1]\), and \(\operatorname{Eval}_t(z)\), returning \(V_t([0,z])\) at a previously returned cut point. Answers are exact; output boundaries must be returned cut points or cake endpoints.
Given a binary rational \(0<\epsilon<1\), output \(0\le x\le y\le1\) and a bijection \(\pi:T\to\{1,2,3\}\), with \(A_1=[0,x]\), \(A_2=[x,y]\), \(A_3=[y,1]\), such that \(V_t(A_{\pi(t)})\ge V_t(A_{\pi(s)})-\epsilon\) for every \(t,s\in T\). Shared endpoints have zero value.
Measure worst-case type-level query complexity separately from computation; express any computational bounds in \(m=3\) intervals, \(\tau=3\), the binary input length \(L\), and \(\epsilon\).

What is the optimal worst-case deterministic type-level Robertson–Webb query complexity of this problem as \(\epsilon\to0\)?

For three individual players, connected approximate envy-free allocation has an upper bound of \(O(\log(1/\epsilon))\) and a matching lower bound of \(\Omega(\log(1/\epsilon))\). [Source](https://arxiv.org/pdf/1705.02946)
The stated type-level problem has exactly the same oracle inputs, feasible outputs, and fairness constraints; the supplied masses enter none of them. Consequently, these bounds already settle its query complexity.

Result

The optimal worst-case deterministic type-level Robertson–Webb query complexity is \(\Theta(\log(1/\epsilon))\).

This follows from the cited three-player bounds by a query-preserving equivalence. The masses do not affect that equivalence.

Applicable theorem and hypotheses

Brânzei and Nisan’s Theorems 4.1 and 4.2 establish an upper bound of \(O(\log(1/\epsilon))\) and a deterministic lower bound of \(\Omega(\log(1/\epsilon))\) for connected approximate envy-free allocation among three players. Their model uses normalized nonnegative integrable densities, prefix Cut queries, Eval queries at previously discovered cut points, and output boundaries drawn from those points. Their cut convention explicitly permits deterministic leftmost tie-breaking. The upper bound imposes no density bounds. [Source, Sections 2 and 4](https://arxiv.org/pdf/1705.02946).

Thus the theorem’s valuation assumptions and query restrictions match those in the task. In particular, absolute continuity gives zero value to shared endpoints, so endpoint ownership has no effect on fairness.

Upper bound: regard each type as one player

Given a type-level instance, run the three-player protocol with player \(t\)’s valuation equal to \(V_t\). Implement each player query by the identical query to type \(t\). This uses exactly the same number of queries.

The protocol returns a partition into three connected pieces, one per player. Order the pieces spatially, writing them as \(A_1=[0,x]\), \(A_2=[x,y]\), and \(A_3=[y,1]\), and let \(\pi(t)\) be the position of player \(t\)’s piece.

For every pair \(t,s\), the protocol guarantees \(V_t(A_{\pi(t)})\ge V_t(A_{\pi(s)})-\epsilon\). Its boundaries satisfy the required query restriction. Consequently, it produces a valid type-level output with \(O(\log(1/\epsilon))\) queries.

No step uses the masses.

Lower bound: fix the masses

Conversely, suppose a deterministic type-level protocol solves every permitted instance. Given any three-player instance, supply its three valuation oracles as the type oracles and fix the valid binary rational masses to \(\mu_1=\mu_2=1/4\) and \(\mu_3=1/2\).

Simulate the type-level protocol, forwarding each query to the corresponding player. Every answer, including the leftmost cut point, is identical. Assign player \(t\) the output interval \(A_{\pi(t)}\). The type-level fairness inequalities are exactly the players’ approximate envy-freeness inequalities.

This constructs a deterministic three-player protocol without additional queries. Therefore the three-player lower bound applies even to this fixed-mass subclass, proving \(\Omega(\log(1/\epsilon))\) type-level queries.

Combining the two bounds proves the stated optimal complexity.

Computation versus queries

Here \(m=\tau=3\) are fixed. The cited upper-bound construction performs a constant number of valuation bisection phases, with constant work per iteration; checking assignments involves only the six bijections. Its non-oracle work is therefore \(O(1+\log(1/\epsilon))\) exact arithmetic and comparison operations. Including a scan of the binary input gives \(O(L+1+\log(1/\epsilon))\) work under unit-cost exact arithmetic. [Source, Appendix B.1](https://arxiv.org/pdf/1705.02946).

This is an arithmetic-operation bound. A Turing bit-time bound in \(m,\tau,L,\epsilon\) alone is not specified by these premises: exact oracle answers can be arbitrary real numbers, and their representation and arithmetic costs have not been defined. That distinction does not affect the proved query complexity.
