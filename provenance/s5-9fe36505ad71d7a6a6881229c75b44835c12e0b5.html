The anchor (named result in the paper)

Proposition 1 — class: hardness

The continuous mirror question, as graded

Given a consultation side with a reason vocabulary \(R\), justifications \(J\) labelled by \(\lambda(j)\subseteq R\), a rational distribution \(\mu\) over voter types \(t\) with salient reason sets \(P_t\), a slate budget \(K\), and threshold \(q\), does there exist \(S\subseteq J\), \(|S|\le K\), such that \(\sum_{\ell\in\bigcup_{j\in S}\lambda(j)}\sum_{t:\ell\in P_t}\mu_t\ge q\)?

Packaged proof task (what the prover saw — nothing else)

For one consultation side, let \(R\) be a finite reason vocabulary with \(m=|R|\), and let \(J\) be an explicitly listed finite set of \(n=|J|\) justifications, each carrying an explicitly listed nonempty label set \(\lambda(j)\subseteq R\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Each type \(t\) has an explicitly listed salient reason set \(P_t\subseteq R\); require \(\mu_t>0\) and \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a positive integer slate budget \(K\) and a nonnegative binary rational threshold \(q\). Let \(L\) be the total input bit length.
A slate is a subset \(S\subseteq J\) with \(|S|\le K\). Its value is \(V(S)=\sum_{\ell\in\bigcup_{j\in S}\lambda(j)}\sum_{t:\ell\in P_t}\mu_t\). Each covered reason contributes once; a type may contribute to several distinct reasons.

Is deciding whether a slate satisfies \(V(S)\ge q\) solvable in polynomial time, or is it \(\mathrm{NP}\)-hard? State running times in \(m,n,\tau,L,K\).

The discrete Subsuming Justification Problem—covering a specified target reason set with at most \(K\) justifications—is \(\mathrm{NP}\)-complete; its nonnegative weighted threshold variant is \(\mathrm{NP}\)-hard.
No separately verified complexity classification is available here for the distribution-over-types formulation.

Modeling choices made when packaging the task

  • Required nonempty justification label sets, following the discrete reason-labelling definition.
  • Normalized the positive rational type masses to sum to one, as required by a distribution.
  • Allowed arbitrary salient reason subsets, including the empty set, because no restriction on voter salience sets is supplied.
  • Specified a positive integer budget and a nonnegative rational threshold; the threshold is not restricted to one because the objective counts reason incidences rather than covered voters.
  • Made all finite sets explicit, defined m as the reason vocabulary size and n as the justification count, and defined L as total input bit length.

Conclusion and interpretation

The existence problem is \(\mathrm{NP}\)-complete, even when \(\tau=1\). Consequently, it has a polynomial-time algorithm only if \(\mathrm{P}=\mathrm{NP}\).

I interpret the question as asking whether there exists a slate \(S\subseteq J\) with \(|S|\le K\) and \(V(S)\ge q\). Checking a supplied slate is polynomial-time solvable.

1. The distribution induces reason weights

For each reason \(\ell\in R\), define
\[ w_\ell=\sum_{t:\ell\in P_t}\mu_t. \]
By positivity and normalization of the masses, \(0\le w_\ell\le1\). Directly from the definition,
\[ V(S)=\sum_{\ell\in\bigcup_{j\in S}\lambda(j)}w_\ell. \]

Thus the objective is a weighted coverage function. The total value can exceed \(1\), because a type contributes to every covered reason in its salient set.

This observation alone does not prove hardness: the weights obtainable from a distribution might be restricted. The following reduction establishes hardness within those restrictions.

2. Hardness with one type

Use the discrete Subsuming Justification Problem whose \(\mathrm{NP}\)-completeness is given in the question. Its input specifies a target reason set \(T\subseteq R\), justifications with label sets \(\lambda(j)\), and a positive budget \(K\). It asks whether
\[ T\subseteq\bigcup_{j\in S}\lambda(j) \qquad\text{for some }S\subseteq J,\quad |S|\le K. \]

If empty label sets are permitted in the source problem, discard those justifications: they cannot help cover any target reason.

Keep the vocabulary, remaining justifications, and budget. Construct a society consisting of exactly one type, with
\[ P_1=T,\qquad \mu_1=1, \]
and set \(q=|T|\). The mass is positive and sums to \(1\), so this is a valid instance.

For every slate \(S\), the induced weights are \(1\) on \(T\) and \(0\) elsewhere. Hence
\[ V(S)=\left|T\cap\bigcup_{j\in S}\lambda(j)\right|. \]
The right-hand side is at most \(|T|\), and equals \(|T|\) exactly when every target reason is covered. Therefore
\[ V(S)\ge q \quad\Longleftrightarrow\quad T\subseteq\bigcup_{j\in S}\lambda(j). \]

The budget is unchanged. Listing \(P_1=T\), encoding mass \(1\), and encoding the integer threshold \(|T|\) require polynomial time and output length. This is a polynomial-time many-one reduction, proving \(\mathrm{NP}\)-hardness even for \(\tau=1\).

3. Exact verification and membership in \(\mathrm{NP}\)

Write each mass as \(\mu_t=a_t/b_t\), with positive integer denominator, and write \(q=c/d\), with \(c\ge0\) and \(d>0\). Define
\[ D=\prod_{t=1}^{\tau}b_t,\qquad A_t=a_t(D/b_t),\qquad W_\ell=\sum_{t:\ell\in P_t}A_t. \]
These are integers, and \(w_\ell=W_\ell/D\).

The bit length of \(D\) is bounded by the sum of the denominator bit lengths, hence is \(O(L)\). Normalization gives \(\sum_t A_t=D\), so \(0\le W_\ell\le D\). For a supplied slate, form its covered reason set \(C\) and compute
\[ A(S)=\sum_{\ell\in C}W_\ell. \]
Because \(A(S)\le mD\), its bit length is \(O(L+\log(m+1))\). The threshold comparison is exactly
\[ V(S)\ge q \quad\Longleftrightarrow\quad dA(S)\ge cD. \]
Both products have polynomial bit length.

A certificate can specify the slate by an \(n\)-bit incidence vector. Its cardinality, union of labels, and threshold condition are therefore verifiable in polynomial time. This proves membership in \(\mathrm{NP}\), completing the classification.

4. Explicit running-time bounds

Here are conservative bounds in the bit-operation model, using ordinary quadratic-time integer multiplication and division. Put
\[ B=L+\lceil\log_2(m+1)\rceil+1, \qquad k=\min\{K,n\}. \]

Indexing the explicit reason lists, constructing label incidence arrays, and computing the integer weights above can be done in
\[ T_{\mathrm{pre}} =O\!\left((\tau+m\tau+mn+1)B^2\right). \]
Indeed, there are at most \(m\tau\) type–reason incidences and \(mn\) justification–reason incidences, and all required integers have \(O(B)\) bits.

After this preprocessing, checking any slate of size at most \(k\) takes
\[ O\!\left((mk+m+1)B^2\right). \]
This includes forming its union, summing covered weights, and making the exact threshold comparison.

Enumerating all feasible slates gives an exact decision algorithm with running time
\[ O\!\left( (\tau+m\tau+mn+1)B^2+ \left[\sum_{i=0}^{k}\binom{n}{i}\right](mk+m+1)B^2 \right). \]

For every fixed \(K\), this is polynomial time, since for \(n\ge1\) the number of enumerated slates is \(O(n^K)\). When \(K\) is part of the input, the problem is \(\mathrm{NP}\)-complete. If \(K\ge n\), nonnegative weights imply that selecting all justifications is optimal, so that case is decided by one verification.
