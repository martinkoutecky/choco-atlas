The continuous mirror question, as graded

Given a finite set of complete worker-noise types \(\Theta\), positive rational masses \(\mu_t\) summing to one, and a symmetric rational matrix \(D\) of mean report distances between distinct agents of each type pair, compute a minimizer \(\hat f\) of \(\sum_{t,u\in\Theta}\mu_t\mu_u(\hat f_t+\hat f_u-D_{tu})^2\). For \(t=u\), \(D_{tt}\) is the mean distance between distinct agents of that type.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(\Theta\) of \(\tau\) worker-noise types with positive masses \(\mu_t\in\mathbb{Q}_{>0}\), encoded in binary, satisfying \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Types identify complete report distributions; their relevant numerical information is supplied directly as an arbitrary symmetric matrix \(D\in\mathbb{Q}_{\geq0}^{\tau\times\tau}\). No report distributions need to be reconstructed.
\(D_{tu}\) represents the mean report distance between distinct agents of types \(t,u\); in particular, \(D_{tt}\) concerns two distinct agents of the same type and need not vanish.
Compute an exact minimizer over \(\hat f\in\mathbb{R}^{\Theta}\) of \(\sum_{t,u\in\Theta}\mu_t\mu_u(\hat f_t+\hat f_u-D_{tu})^2\), including all ordered type pairs. Estimates may be negative; there is no regularization.
Let \(L\) be the total binary input length and \(m\) the underlying number of report coordinates, if specified. State running times in \(m,\tau,L\); reports themselves are not input.

Is computing an exact minimizer of this mass-weighted fault-estimation problem solvable in polynomial time, or is it NP-hard?

Result

The problem is polynomial-time solvable. Its unique exact minimizer is

\[ \boxed{\hat f_t^* =\sum_{u\in\Theta}\mu_uD_{tu} -\frac12\sum_{v,u\in\Theta}\mu_v\mu_uD_{vu}.} \]

This formula applies to every nonempty support, including \(\tau=1\), and retains all diagonal entries \(D_{tt}\).

Derivation and proof of optimality

Write \(f\) for the vector of estimates, and define

\[ r_t=\sum_{u\in\Theta}\mu_uD_{tu}, \qquad A=\sum_{t\in\Theta}\mu_tr_t, \qquad s(f)=\sum_{t\in\Theta}\mu_tf_t. \]

The given objective is

\[ F(f)=\sum_{t,u\in\Theta}\mu_t\mu_u(f_t+f_u-D_{tu})^2. \]

Using symmetry of \(D\) and \(\sum_t\mu_t=1\), expansion gives

\[ F(f) =2\sum_t\mu_tf_t^2 +2s(f)^2 -4\sum_t\mu_tr_tf_t +C, \qquad C=\sum_{t,u}\mu_t\mu_uD_{tu}^2. \]

Indeed, the two squared-estimate terms each contribute \(\sum_t\mu_tf_t^2\); the cross term contributes \(2s(f)^2\); and symmetry makes the two terms linear in the estimates equal.

Consequently, for every \(t\),

\[ \frac{\partial F}{\partial f_t} =4\mu_t\bigl(f_t+s(f)-r_t\bigr). \]

Since every mass is positive, stationarity is equivalent to

\[ f_t+s(f)=r_t \quad\text{for every }t. \]

Multiplying these equations by \(\mu_t\) and summing yields \(2s(f)=A\). Thus the only stationary candidate is \(f_t^*=r_t-A/2\). Its weighted mean is \(s(f^*)=A/2\), so it satisfies every stationarity equation.

To prove global optimality and uniqueness directly, let \(h\in\mathbb R^\Theta\). Substituting \(f^*+h\) into the expanded objective gives

\[ F(f^*+h)-F(f^*) = 2\sum_t\mu_th_t^2 +2\left(\sum_t\mu_th_t\right)^2. \]

The linear terms vanish because \(f_t^*+s(f^*)-r_t=0\) for every \(t\). Both displayed terms are nonnegative. If \(h\ne0\), the first is strictly positive because every \(\mu_t>0\). Therefore \(f^*\) is the unique global minimizer.

All sums here include diagonal type pairs. In particular, for \(\tau=1\), the formula gives \(f_1^*=D_{11}/2\).

Exact computation and bit complexity

Computing the weighted row means \(r_t\), then \(A\), then the output vector requires \(O(\tau^2)\) rational arithmetic operations. We must also bound their bit complexity.

Write the input rationals as \(\mu_t=p_t/q_t\) and \(D_{tu}=c_{tu}/d_{tu}\), with positive denominators. Let \(P\) be the product of the mass denominators and \(Q\) the product of the supplied matrix-entry denominators. Define integers

\[ a_t=p_t(P/q_t), \qquad b_{tu}=c_{tu}(Q/d_{tu}). \]

Then \(\mu_t=a_t/P\) and \(D_{tu}=b_{tu}/Q\). Set

\[ R_t=\sum_u a_ub_{tu}, \qquad B=\sum_t a_tR_t. \]

The exact output can be represented as

\[ f_t^*=\frac{2PR_t-B}{2P^2Q}. \]

The products \(P,Q\) have \(O(L)\) bits because the total lengths of their input denominators are bounded by \(L\). The integers \(a_t,b_{tu},R_t,B\), and the output numerators and denominator also have \(O(L)\) bits: multiplication adds bit lengths, and the sums add at most \(O(\log\tau)\) bits.

There are \(O(\tau^2)\) integer operations. Using elementary multiplication and long division therefore gives the conservative bound \(O(\tau^2L^2)\) bit operations. Since the explicitly supplied matrix implies \(\tau^2=O(L)\), this is also \(O(L^3)\). Unreduced fractions already provide an exact output.

There is no computational dependence on the value of \(m\): report coordinates and report distributions are not processed. If \(m\) is supplied as metadata, its encoding contributes only to \(L\).
