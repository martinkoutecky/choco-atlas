The continuous mirror question, as graded

Given goods \(G\), complete valuation types \(T\), rational type masses \(\mu_t\) summing to \(1\), rational per-capita supplies \(q_g\), and explicit monotone valuation tables \(v_t(S)\), find an exact rational allocation \(x_{t,S}\) maximizing \(\sum_{t\in T}\sum_{S\subseteq G}x_{t,S}v_t(S)\), subject to \(\sum_{S\subseteq G}x_{t,S}=\mu_t\), \(\sum_{t\in T,\,S\ni g}x_{t,S}\le q_g\), and \(x_{t,S}\ge0\). Each unit of mass receives an integral bundle \(S\).

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a finite set of \(m\) goods. A society is given by its support: a list \(T\) of \(\tau\) complete valuation types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has an explicit table \(v_t:2^G\to\mathbb{Z}_{\ge0}\), with \(v_t(\varnothing)=0\) and monotone valuations. Supplies \(q_g\in\mathbb{Q}_{\ge0}\) are binary-encoded per-capita quantities; unused supply is permitted. Let \(L\) be the total input bit length, including all valuation tables.
An allocation specifies rational masses \(x_{t,S}\ge0\): mass \(x_{t,S}\) of type \(t\) receives the integral bundle \(S\subseteq G\). A type's mass may be split among bundles, including the empty bundle.
Find an allocation maximizing \(\sum_{t\in T}\sum_{S\subseteq G}x_{t,S}v_t(S)\), subject to \(\sum_{S\subseteq G}x_{t,S}=\mu_t\) for every \(t\), and \(\sum_{t\in T}\sum_{S\ni g}x_{t,S}\le q_g\) for every \(g\).

Is this exact allocation problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite bidders and indivisible goods, an ascending primal-dual auction terminates after finitely many steps with a welfare-maximizing assignment; the result supplies no polynomial-time bound. [de Vries, Schummer, and Vohra](https://www.kellogg.northwestern.edu/faculty/schummer/ftp/research/pdhetero/pdhetero.pdf)
No prior result addressing exactly this continuous problem was verified.

  • The valuation domain and empty-bundle normalization were unspecified; use nonnegative integer valuations and zero value for the empty bundle, as in the discrete definition.
  • The supply domain was unspecified; use nonnegative binary-rational supplies, allowing zero supply and unused goods.
  • Interpret complete valuation types as explicit tables for every subset of goods, and define L as the total input bit length including those tables.
  • Allow arbitrary splitting of each type's mass among integral bundles; impose no requirement that all members of one type receive the same bundle.

Result

The exact allocation problem is solvable in time polynomial in \(m,\tau,L\). The decisive assumptions are that valuation tables are explicit and type masses may be split among bundles.

Proof

1. The number of variables is bounded by the input length.

Introduce one variable \(x_{t,S}\) for each \(t\in T\) and \(S\subseteq G\). There are \(N=\tau 2^m\) such variables.

The input explicitly contains all \(N\) valuation entries. Each entry requires at least one bit, including entries equal to zero. Consequently, \(N\le L\). Thus enumerating every type–bundle pair takes time polynomial in \(m,\tau,L\), despite the exponential dependence on \(m\) alone.

2. Construct an explicit rational linear program.

For each good \(g\), introduce a nonnegative slack variable \(s_g\), representing unused supply. Solve the following linear program:

\[ \max \sum_{t\in T}\sum_{S\subseteq G}v_t(S)x_{t,S}, \]

subject to

\[ \sum_{S\subseteq G}x_{t,S}=\mu_t \qquad(t\in T), \]

\[ \sum_{t\in T}\sum_{\substack{S\subseteq G\\g\in S}}x_{t,S}+s_g=q_g \qquad(g\in G), \]

and \(x_{t,S}\ge0,\ s_g\ge0\).

There are \(N+m\) variables and \(\tau+m\) equality constraints. Every constraint-matrix coefficient belongs to \(\{0,1\}\). The objective coefficients and right-hand sides are copied from the input.

Even a dense encoding therefore has bit length

\[ B=O\bigl((\tau+m)(N+m)+L\bigr), \]

up to polynomially bounded dimension metadata. Since \(N\le L\), this is polynomial in \(m,\tau,L\). The matrix can be constructed within the same polynomial bound by inspecting bundle membership.

3. Check feasibility and boundedness.

A feasible solution assigns every type the empty bundle: set \(x_{t,\varnothing}=\mu_t\), set every other allocation variable to zero, and set \(s_g=q_g\). Nonnegative supplies ensure feasibility.

For every feasible solution, nonnegativity and the type equation imply \(0\le x_{t,S}\le\mu_t\). Likewise, the supply equation implies \(0\le s_g\le q_g\). Hence the feasible region is bounded. It is also closed, because it is defined by finitely many linear equalities and non-strict inequalities. Being nonempty and compact, it admits a maximizer of the continuous linear objective.

4. Apply exact polynomial-time rational linear programming.

The standard rational linear-programming theorem states that an explicitly encoded rational linear program can be solved in polynomial time in its binary encoding length: the algorithm detects infeasibility or unboundedness, or returns an exact rational optimal solution. This is a bit-complexity guarantee, including polynomial output length, rather than merely an approximation guarantee. Exact polynomial-time algorithms and rational reconstruction are discussed in [*Linear Programming using Limited-Precision Oracles*, Section 1.3](https://optimization-online.org/wp-content/uploads/2019/12/7507.pdf).

All hypotheses hold here: the program is explicit, every coefficient is rational, its encoding length \(B\) is polynomially bounded, and it has an attained finite optimum. Applying the theorem therefore returns an exact rational optimum in time polynomial in \(m,\tau,L\).

Finally, the correspondence with the stated allocation problem is exact. Every permissible allocation extends to a feasible linear-program solution by setting each slack to unused supply. Conversely, discarding the slack variables from any feasible solution gives a permissible allocation with the same welfare. Thus the returned optimum solves the requested problem.

Scope of the conclusion

The running time may be exponential in \(m\) alone, because the explicitly supplied tables already have that size. It is polynomial in the input length requested here. No integrality constraint is imposed on allocation masses, and the proof requires no polynomial-time bound for the ascending auction.
