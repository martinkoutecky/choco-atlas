Corollary 3 — class: algorithmic

The continuous mirror question, as graded

Given finite type and category sets \(T\) and \(J\), rational type masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), rational per-capita supplies \(q_j>0\) with \(\sum_{j\in J}q_j=1\), and a bi-valued utility vector \(u_t\) for each type, compute an exact HZ allocation and supporting prices. The allocation must satisfy \(x_{tj}\ge 0\), \(\sum_{j\in J}x_{tj}=1\), and \(\sum_{t\in T}\mu_t x_{tj}=q_j\); at prices \(p_j\ge 0\), each \(x_t\) must maximize utility over unit bundles \(z\ge 0\) with \(p\cdot z\le 1\), and be a cheapest unit bundle attaining at least \(u_t(x_t)\). Is such a solution computable in time polynomial in \(|T|\), \(|J|\), and the total input bit length \(L\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Let \(J\) be a nonempty category set, \(m=|J|\), with positive binary-rational supplies \(q_j\) satisfying \(\sum_jq_j=1\). Utilities satisfy \(u_{tj}\in\{\alpha_t,\beta_t\}\) for binary rationals \(\alpha_t>\beta_t\geq0\); both values need not occur. Every type values some category positively, and every category is valued positively by some type. Let \(L\) be the total input bit length.
Write \(u_t(z)=\sum_j u_{tj}z_j\) and \(B=\{z\in\mathbb R_{\geq0}^{m}:\sum_jz_j=1\}\). Each member of type \(t\) receives the same per-capita bundle \(x_t\).
An HZ allocation with supporting prices is a pair \((x,p)\) satisfying \(x_t\in B\), \(\sum_t\mu_tx_{tj}=q_j\), and \(p\in\mathbb R_{\geq0}^{m}\), with unit budget per member.
For every type, require \(p\cdot x_t\leq1\), \(x_t\in\arg\max\{u_t(z):z\in B,\ p\cdot z\leq1\}\), and \(p\cdot x_t=\min\{p\cdot z:z\in B,\ u_t(z)\geq u_t(x_t)\}\). Any pair meeting these conditions is admissible.

Is computing an exact HZ allocation and supporting prices, represented as binary rationals, possible in time polynomial in \(m,\tau,L\), or is this search problem NP-hard?

For an explicit finite society of \(n\) agents and \(n\) unit-supply items, bi-valued HZ allocations are computable in \(O(n^3\log n)\) time ([Aziz–Brown](https://cgi.cse.unsw.edu.au/~haziz/HZ_binary.pdf)); allocations and supporting prices also admit a strongly polynomial algorithm ([Vazirani–Yannakakis](https://ics.uci.edu/~vazirani/VY.pdf)).
No result settling the problem with binary-encoded type masses and category supplies was located in the literature search.

Modeling choices made when packaging the task

  • Specified bi-valued utilities as binary rationals with type-specific levels alpha_t > beta_t >= 0; membership in the two-value set does not require both values to occur.
  • Restored the discrete definition's assumptions that every type values some category positively and every category is valued positively by some type.
  • Required nonempty type and category sets and specified exact output as binary-rational allocations and prices.
  • Made explicit that each type receives one common per-capita bundle and each member has budget one; tied optima are resolved only by the stated minimum-cost condition.

Result

The search problem is polynomial-time solvable in \(m,\tau,L\). An exact allocation and supporting prices can be constructed directly on the support, without expanding the rational masses into individual agents.

The construction below is a weighted version of the bottleneck allocation and pricing construction discussed by [Aziz–Brown, Section 3](https://cgi.cse.unsw.edu.au/~haziz/HZ_binary.pdf). We prove its correctness and its polynomial bit complexity for the input representation in the question.

1. Reduction to binary preferences

For each type \(t\), define a nonempty set \(H_t\) of preferred categories.

If both utility values occur, let \(H_t=\{j:u_{tj}=\alpha_t\}\). If the utility is constant across categories, let \(H_t=J\). Define

\(h_t(z)=\sum_{j\in H_t}z_j.\)

For every type there are constants \(c_t\) and \(d_t>0\) such that, for every \(z\in B\),

\(u_t(z)=c_t+d_t h_t(z).\)

Indeed, for a nonconstant type take \(c_t=\beta_t\) and \(d_t=\alpha_t-\beta_t\). For a constant type with utility value \(v_t\), the assumptions imply \(v_t>0\); take \(c_t=0\) and \(d_t=v_t\), since \(h_t(z)=1\) throughout \(B\).

Consequently, maximizing utility and imposing a utility lower bound are unchanged when \(u_t\) is replaced by \(h_t\). This includes the minimum-cost requirement in the question. It therefore suffices to solve the binary-preference problem.

We work with aggregate quantities \(y_{tj}=\mu_t x_{tj}\). At the end, we recover the required per-capita bundles by \(x_{tj}=y_{tj}/\mu_t\).

For a type set \(A\), write \(\mu(A)=\sum_{t\in A}\mu_t\). For a category set \(S\), write \(q(S)=\sum_{j\in S}q_j\).

2. A weighted flow criterion

Let \(U\subseteq T\) and \(C\subseteq J\) be the currently remaining types and categories. For \(A\subseteq U\), define its remaining preferred neighborhood by

\(N_C(A)=\bigcup_{t\in A}(H_t\cap C).\)

For \(r\in[0,1]\), consider the following directed network:

  • An arc from the source to each \(t\in U\), with capacity \(r\mu_t\).
  • An arc from \(t\) to \(j\) whenever \(j\in H_t\cap C\), with capacity \(2\).
  • An arc from each \(j\in C\) to the sink, with capacity \(q_j\).

All capacities are nonnegative rationals. The total capacity leaving the source is \(r\mu(U)\leq1\), so a minimum cut cannot cross an arc of capacity \(2\).

A minimum cut whose source side contains the type set \(A\) must contain every category in \(N_C(A)\). It contains no additional categories: removing such a category from the source side strictly reduces the cut capacity because its supply is positive. Its capacity is therefore

\(r\bigl(\mu(U)-\mu(A)\bigr)+q\bigl(N_C(A)\bigr).\)

By the max-flow/min-cut theorem, all source arcs can be saturated if and only if

\(q\bigl(N_C(A)\bigr)\geq r\mu(A)\qquad\text{for every }A\subseteq U.\)

Equivalently, aggregate preferred-good demands \(r\mu_t\) can all be met if and only if these inequalities hold.

When \(U\neq\varnothing\), define the bottleneck ratio

\(r^*(U,C)=\min_{\varnothing\neq A\subseteq U}\frac{q(N_C(A))}{\mu(A)}.\)

Thus the network is feasible at \(r\in[0,1]\) exactly when \(r\leq r^*(U,C)\).

3. Computing an exact bottleneck in polynomial time

The minimum defining \(r^*(U,C)\) ranges over exponentially many subsets. Nevertheless, an exact minimizing subset can be found using polynomially many max-flow computations.

Choose a common denominator \(D\) for all masses and supplies, for example the product of their encoded denominators. Define positive integers

\(M_t=D\mu_t,\qquad Q_j=Dq_j.\)

They satisfy

\(\sum_t M_t=\sum_j Q_j=D.\)

Moreover, the binary length of \(D\) is \(O(L)\). Every neighborhood ratio is of the form

\(\frac{q(N_C(A))}{\mu(A)} =\frac{\sum_{j\in N_C(A)}Q_j}{\sum_{t\in A}M_t},\)

with numerator at most \(D\) and positive denominator at most \(D\). Any two distinct such ratios differ by at least \(1/D^2\): for distinct fractions \(a/b\) and \(a'/b'\),

\(\left|\frac ab-\frac{a'}{b'}\right| =\frac{|ab'-a'b|}{bb'}\geq\frac1{D^2}.\)

First test feasibility at \(r=1\). If it is feasible, no bottleneck needs to be removed.

Otherwise \(r^*(U,C)<1\). Maintain endpoints \(\ell,h\) such that \(\ell\) is feasible and \(h\) is infeasible, initially \(\ell=0\), \(h=1\). Exact bisection using the flow criterion produces, after \(O(\log D+1)\) iterations,

\(\ell\leq r^*(U,C)<h,\qquad h-\ell<1/D^2.\)

Compute a minimum cut at \(h\), and let \(A\) be its source-side type set. Since \(h\) is infeasible, the cut has capacity strictly less than \(h\mu(U)\). Thus \(A\neq\varnothing\) and

\(\frac{q(N_C(A))}{\mu(A)}<h.\)

By definition of \(r^*(U,C)\),

\(\ell\leq r^*(U,C) \leq\frac{q(N_C(A))}{\mu(A)}<h.\)

The two ratios in this interval must be equal, by the separation bound. Therefore \(A\) is an exact minimizing subset.

Each bisection parameter has polynomial binary length. Multiplying network capacities by \(D\) times the parameter’s denominator gives integer capacities of polynomial binary length. An exact integer max-flow algorithm, such as Edmonds–Karp, therefore performs each oracle call in polynomial bit time. This establishes a polynomial-time bottleneck procedure without rational reconstruction or population expansion.

4. Allocation and price construction

Initialize \(U=T\), \(C=J\), and all aggregate allocations to zero.

At each stage with \(U\neq\varnothing\), test the flow network at \(r=1\).

If feasible, use a saturating flow to give every remaining type \(t\in U\) aggregate quantity \(\mu_t\) entirely from \(H_t\cap C\). Assign price zero to every category in \(C\), and end the bottleneck procedure.

If infeasible, compute an exact minimizing nonempty set \(A\subseteq U\). Put

\(r=\frac{q(N_C(A))}{\mu(A)}<1,\qquad S=N_C(A).\)

Give every \(t\in A\) aggregate quantity \(r\mu_t\) of preferred goods from \(S\). Such a flow exists: for every \(A'\subseteq A\), bottleneck minimality gives

\(q(N_C(A'))\geq r\mu(A'),\)

and \(N_C(A')\subseteq S\). The flow criterion applies to the restricted network on \(A,S\).

Furthermore, this flow uses all supplies in \(S\), because

\(\sum_{t\in A}r\mu_t=r\mu(A)=q(S).\)

Set \(p_j=1/r\) for every \(j\in S\), record \(r\) for these types, and replace

\(U\leftarrow U\setminus A,\qquad C\leftarrow C\setminus S.\)

If \(U\) becomes empty, assign price zero to every remaining category in \(C\) and end the procedure.

Each removal eliminates at least one type, so there are at most \(\tau\) removal stages.

Positivity and monotonicity of the ratios

Initially every type has a nonempty preferred set, and every supply is positive. Hence every nonempty type set has positive neighborhood supply, so the first bottleneck ratio is positive.

Suppose \(A\) is removed at ratio \(r>0\). For any nonempty \(B\subseteq U\setminus A\), bottleneck minimality applied to \(A\cup B\) gives

\(q(N_C(A\cup B))\geq r\bigl(\mu(A)+\mu(B)\bigr).\)

The neighborhood is the disjoint union of \(N_C(A)\) and \(N_{C\setminus S}(B)\). Using \(q(N_C(A))=r\mu(A)\), we obtain

\(q(N_{C\setminus S}(B))\geq r\mu(B).\)

Thus every subsequent bottleneck ratio is at least \(r\), and remains positive. In particular, the assigned positive prices are nonincreasing over successive removal stages.

Filling the remaining bundle quantities

A type removed at ratio \(r_t<1\) still needs aggregate quantity

\(d_t=\mu_t(1-r_t).\)

Let \(\ell_j\) be the unallocated supply of each zero-price category after the procedure. Types handled by the final feasible flow already have their full aggregate quantities.

Every positive-price category has been exhausted. Conservation of total mass and supply therefore gives

\(W:=\sum_t d_t=\sum_{j:p_j=0}\ell_j,\)

where the first sum is over removed types.

If \(W=0\), no filling is needed. Otherwise assign each removed type the additional aggregate quantities

\(y^{\mathrm{fill}}_{tj}=\frac{d_t\ell_j}{W}\qquad\text{for every zero-price category }j.\)

These quantities give each removed type exactly its deficit and exhaust every leftover supply.

Every leftover category is outside every removed type’s preferred set. Indeed, when a type was removed, all of its then-remaining preferred categories were removed with its block. Categories surviving to the end therefore cannot be preferred by that type.

5. Verification of every HZ condition

Set \(x_{tj}=y_{tj}/\mu_t\).

The construction gives each type aggregate total \(\mu_t\), so \(x_t\in B\). It exhausts every category supply, hence

\(\sum_t\mu_t x_{tj}=q_j.\)

Prices are nonnegative. It remains to verify affordability, utility optimality, and minimum cost.

Types removed at a bottleneck

Fix a type \(t\) removed at ratio \(r_t<1\).

It receives per-capita preferred quantity \(r_t\), all at price \(1/r_t\). Its remaining quantity \(1-r_t\) consists of nonpreferred, zero-price goods. Consequently,

\(h_t(x_t)=r_t,\qquad p\cdot x_t=1.\)

Every category in \(H_t\) has price at least \(1/r_t\). To see this, a preferred category either belonged to \(t\)’s own block or was removed earlier; earlier removal ratios were no larger than \(r_t\), so their reciprocal prices were no smaller.

Therefore, for every \(z\in B\), nonnegativity of all prices implies

\(p\cdot z\geq\frac{h_t(z)}{r_t}.\)

If \(z\) is affordable, then \(p\cdot z\leq1\), and hence \(h_t(z)\leq r_t\). This proves that \(x_t\) maximizes \(h_t\), and thus maximizes \(u_t\), over the affordable bundles.

If instead \(u_t(z)\geq u_t(x_t)\), the affine representation with positive coefficient implies \(h_t(z)\geq r_t\). The same inequality gives \(p\cdot z\geq1\). Since \(x_t\) costs exactly \(1\),

\(p\cdot x_t=\min\{p\cdot z:z\in B,\ u_t(z)\geq u_t(x_t)\}.\)

This proves the specified minimum-cost condition.

Types handled by the final feasible flow

Such a type receives one per-capita unit entirely from preferred, zero-price categories. Thus

\(h_t(x_t)=1,\qquad p\cdot x_t=0.\)

For every \(z\in B\), \(h_t(z)\leq1\), so its bundle maximizes utility. Its cost is globally minimal because all prices are nonnegative. Affordability and the minimum-cost condition both follow.

All conditions in the question are therefore satisfied.

6. Exact output size and running time

The bottleneck computation already uses only polynomially many bit operations. We now verify that the allocation and price construction also has polynomial bit complexity.

Consider a removed block. Write its ratio as

\(r=\frac ab,\qquad a=\sum_{j\in S}Q_j,\quad b=\sum_{t\in A}M_t.\)

Here \(1\leq a<b\leq D\). Its prices are \(b/a\), requiring \(O(L)\) bits.

In its allocation network, multiplying capacities by \(Db\) makes them integers. By integrality of maximum flow, its aggregate allocations can be chosen as \(F_{tj}/(Db)\), with integer \(F_{tj}\). The corresponding per-capita allocation is

\(x^{\mathrm{preferred}}_{tj}=\frac{F_{tj}}{bM_t}.\)

Its numerator and denominator have \(O(L)\) bits. The final feasible flow similarly has aggregate coordinates with denominator \(D\).

Consequently, each leftover supply is \(\ell_j=R_j/D\) for some nonnegative integer \(R_j\). When filling is required, write \(W=W_0/D\), where \(1\leq W_0\leq D\). For a type in a block with ratio \(a/b\), its per-capita filler quantity is

\(x^{\mathrm{fill}}_{tj} =\frac{d_t}{\mu_t}\frac{\ell_j}{W} =\frac{(b-a)R_j}{bW_0}.\)

These coordinates also have \(O(L)\) bits. Preferred allocations and filler allocations use disjoint category sets, so these expressions directly describe the output coordinates.

Every flow network has at most \(m+\tau+2\) vertices and \(m\tau+m+\tau\) arcs. There are at most \(\tau\) removal stages, each requiring \(O(\log D+1)=O(L+1)\) max-flow computations, plus an allocation flow. All capacities and outputs have polynomial binary length.

Thus the complete construction runs in time polynomial in \(m,\tau,L\) and returns an exact rational HZ allocation with supporting rational prices.
