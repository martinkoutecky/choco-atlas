The continuous mirror question, as graded

Given finite type sets \(T_A,T_B\) with positive rational masses \(\alpha_i,\beta_j\) summing to \(1\), strict preferences over opposite-side types, and a candidate flow \(\pi_{ij}\ge 0\) with row sums \(\alpha_i\) and column sums \(\beta_j\), consider offline certification of stability and \(B\)-optimality. The \(A\)-type preferences are known to the verifier; the full \(B\)-type preferences are known to the query-set optimizer but hidden from the verifier. A query asks whether \(B\)-type \(j\) prefers \(A\)-type \(i\) to \(A\)-type \(i'\), and its answer applies to that whole type. Define \(B\)-optimality by requiring that for every stable flow \(\pi'\), each \(B\)-type receives at least as much mass in every prefix of its preference order under \(\pi\) as under \(\pi'\). Given a true stable, \(B\)-optimal flow \(\pi\) and an integer \(k\), is there a set of at most \(k\) comparisons whose true answers certify that every completion of the hidden preferences consistent with them leaves \(\pi\) stable and \(B\)-optimal?

Packaged proof task (what the prover saw — nothing else)

Each side's society is given by its support: finite nonempty disjoint type sets \(T_A,T_B\), with positive binary rational masses \(\alpha_i,\beta_j\) summing to \(1\) on each side. Set \(\tau=|T_A|+|T_B|\) and \(m=\max\{|T_A|,|T_B|\}\); \(\tau\) counts supported types, not possible preference orders. Preferences are strict complete orders over opposite-side types; write \(x\succ_t y\) when type \(t\) prefers \(x\).
A feasible flow \(x\in\mathbb R_{\ge0}^{T_A\times T_B}\) has row sums \(\alpha_i\) and column sums \(\beta_j\). A pair \((i,j)\) blocks \(x\) if both \(\sum_{j':j\succ_i j'}x_{ij'}>0\) and \(\sum_{i':i\succ_j i'}x_{i'j}>0\); stability means no blocking pair.
A stable flow \(x\) is \(B\)-optimal if, for every stable feasible flow \(y\), every \(j\in T_B\), and every prefix \(P\) of \(j\)'s order, \(\sum_{i\in P}x_{ij}\ge\sum_{i\in P}y_{ij}\).
The optimizer receives all true preferences, a binary rational feasible flow \(\pi\) promised stable and \(B\)-optimal under them, and a binary integer \(k\ge0\). The verifier knows the masses, \(\pi\), and all \(A\)-side orders, but no \(B\)-side preferences initially. Each unit-cost query compares distinct \(i,i'\in T_A\) for one \(j\in T_B\), with its true answer applying to the entire type.
A query set certifies \(\pi\) if every collection of strict complete \(B\)-side orders consistent with its answers makes \(\pi\) stable and \(B\)-optimal under those orders; the input promise supplies no additional restriction on these completions. Let \(L\) be the total input bit length.

Is deciding whether such a certificate uses at most \(k\) comparisons solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite equally sized agent sets, offline minimum-comparison certification of stability and \(B\)-optimality is NP-hard ([source](https://arxiv.org/html/2407.10170v1)). No result settling this exact mass-flow certification problem was located.

  • Flow stability was undefined; a pair blocks precisely when both types have positive mass assigned to strictly worse partners.
  • The candidate flow's encoding was unspecified; its entries are binary rationals, while competing feasible flows may have real entries.
  • Preferences and completions are strict complete orders, carrying over the discrete domain.
  • The query budget is a nonnegative binary integer, and each comparison of distinct types costs one.
  • The promise concerns the true input only; it is not information available to the verifier that restricts preference completions.
  • Both supports are nonempty; their cardinalities may differ because equal total mass replaces equal agent counts.
  • Defined m as the maximum side-support size, tau as the combined support size, and L as total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-hard, already when both sides have the same number of supported types, every mass is uniform, and the supplied flow is a scaled perfect matching. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The key point is that allowing fractional stable flows does not change whether a scaled perfect matching is \(B\)-optimal. We prove this equivalence for every complete preference profile, so it also preserves the universal quantification over preference completions.

1. Uniform masses and scaled matchings

Let \(A,B\) be disjoint sets with \(|A|=|B|=n\), and give every type mass \(1/n\). A perfect matching \(M\) is a bijection from \(A\) to \(B\); write \(M^{-1}(j)\) for the partner of \(j\in B\).

Define its scaled flow by

\( f^M_{ij}=\frac{1}{n}\mathbf{1}_{\{M(i)=j\}}. \)

This flow is feasible.

For any pair \((i,j)\), its two blocking quantities are

\( \sum_{j':\,j\succ_i j'}f^M_{ij'} =\frac{1}{n}\mathbf{1}_{\{j\succ_i M(i)\}}, \)

and

\( \sum_{i':\,i\succ_j i'}f^M_{i'j} =\frac{1}{n}\mathbf{1}_{\{i\succ_j M^{-1}(j)\}}. \)

Thus \((i,j)\) blocks \(f^M\) exactly when it blocks \(M\) in the ordinary matching model. In particular,

\( f^M\text{ is stable}\quad\Longleftrightarrow\quad M\text{ is stable}. \)

2. Every stable uniform flow decomposes into stable matchings

Lemma. Fix any strict complete preference profile. If \(y\) is a stable feasible flow with all masses \(1/n\), then there exist stable perfect matchings \(N_1,\ldots,N_s\) and positive real numbers \(\lambda_1,\ldots,\lambda_s\) such that

\( \sum_{\ell=1}^{s}\lambda_\ell=1, \qquad y=\sum_{\ell=1}^{s}\lambda_\ell f^{N_\ell}. \)

Proof. Set \(D=ny\). Every row and column of \(D\) sums to \(1\).

We first construct a decomposition into perfect matchings supported on positive entries of \(D\). Consider a nonnegative residual matrix \(R\) whose rows and columns all sum to the same number \(r>0\). Its support graph joins \(i\in A\) to \(j\in B\) precisely when \(R_{ij}>0\).

For any \(S\subseteq A\), let \(\Gamma(S)\subseteq B\) be its neighborhood. Then

\( r|S| =\sum_{i\in S}\sum_{j\in\Gamma(S)}R_{ij} \leq \sum_{j\in\Gamma(S)}\sum_{i\in A}R_{ij} =r|\Gamma(S)|. \)

Since \(r>0\), Hall’s condition holds. Hall’s marriage theorem therefore supplies a perfect matching \(N\) in the support graph.

Let

\( \varepsilon=\min_{i\in A}R_{i,N(i)}>0. \)

Subtracting \(\varepsilon\) from each matched entry preserves nonnegativity and changes every row and column sum to \(r-\varepsilon\). At least one positive entry becomes zero, and no new positive entry appears.

Starting with \(R=D\), repeat this procedure whenever \(r>0\). It terminates after at most \(n^2\) steps: each step removes a positive entry, while a residual with \(r>0\) always permits another step. At termination the residual is zero. Consequently,

\( D=\sum_{\ell=1}^{s}\lambda_\ell P^{N_\ell}, \qquad \sum_{\ell=1}^{s}\lambda_\ell=1, \)

where \(P^N\) is the incidence matrix of \(N\), and every \(N_\ell\) uses only positive entries of the original \(y\).

It remains to prove stability of these matchings. In fact, every perfect matching supported on \(y\) is stable. Suppose such a matching \(N\) had a blocking pair \((i,j)\). Then

\( j\succ_i N(i), \qquad i\succ_j N^{-1}(j). \)

Because \(N\) is supported on \(y\),

\( y_{i,N(i)}>0, \qquad y_{N^{-1}(j),j}>0. \)

These entries make both blocking quantities for \((i,j)\) in \(y\) positive, contradicting stability of \(y\). Hence every \(N_\ell\) is stable. Dividing the decomposition of \(D\) by \(n\) proves the lemma. \(\square\)

3. Exact equivalence of optimality

Proposition. For any strict complete preference profile,

\( M\text{ is stable and }B\text{-optimal among perfect matchings} \quad\Longleftrightarrow\quad f^M\text{ is stable and }B\text{-optimal among feasible flows}. \)

Here ordinary matching optimality means that, for every stable matching \(N\) and every \(j\in B\), \(j\) weakly prefers \(M^{-1}(j)\) to \(N^{-1}(j)\).

Proof, forward direction. Stability follows from Section 1. Let \(y\) be any stable feasible flow. By Section 2,

\( y=\sum_{\ell=1}^{s}\lambda_\ell f^{N_\ell}, \)

where each \(N_\ell\) is stable.

Fix \(j\in B\) and a prefix \(P\) of its preference order. Matching optimality implies that \(M^{-1}(j)\) is weakly preferred to \(N_\ell^{-1}(j)\). Since a prefix contains every alternative preferred to any of its members,

\( \mathbf{1}_{\{M^{-1}(j)\in P\}} \geq \mathbf{1}_{\{N_\ell^{-1}(j)\in P\}}. \)

Therefore,

\( \sum_{i\in P}y_{ij} =\frac{1}{n}\sum_{\ell=1}^{s}\lambda_\ell \mathbf{1}_{\{N_\ell^{-1}(j)\in P\}} \leq \frac{1}{n}\mathbf{1}_{\{M^{-1}(j)\in P\}} =\sum_{i\in P}f^M_{ij}. \)

This is precisely flow \(B\)-optimality.

Proof, reverse direction. Section 1 gives stability of \(M\). Every stable perfect matching \(N\) yields a stable feasible flow \(f^N\).

If some \(j\) strictly preferred \(N^{-1}(j)\) to \(M^{-1}(j)\), take the prefix \(P\) ending at \(N^{-1}(j)\). Then

\( \sum_{i\in P}f^N_{ij}=\frac{1}{n}, \qquad \sum_{i\in P}f^M_{ij}=0, \)

contradicting flow \(B\)-optimality. Thus \(M\) is matching \(B\)-optimal. \(\square\)

4. Polynomial reduction preserving certificates

We use the known finite-agent hardness result: offline comparison certification of a given stable, \(B\)-optimal matching, with strict complete preferences and uncertainty only on the \(B\) side, is \(\mathrm{NP}\)-hard. Theorem 11 gives a threshold reduction establishing this hardness; its constructed target matching is indeed stable and \(B\)-optimal under the true preferences. [Bampis et al., Section 3.3.3, Theorem 11](https://arxiv.org/html/2407.10170v1#S3.SS3.SSS3).

Take an instance of that decision problem, consisting of the true preferences, target matching \(M\), and comparison budget \(k\). Construct the mass-flow instance as follows:

  • Let \(T_A=A\) and \(T_B=B\), with one supported type per agent.
  • Give every type mass \(1/n\).
  • Preserve all preference orders.
  • Set \(\pi=f^M\), and preserve \(k\).

The proposition proves that this instance satisfies the required promise.

Now fix any query set \(Q\). The queries and their true answers are identical in the two instances. Hence the collections of strict complete \(B\)-side orders consistent with those answers are also identical.

For each such completion, the proposition applies without assuming that the completion preserves the input promise. It says that \(M\) is stable and matching \(B\)-optimal exactly when \(\pi\) is stable and flow \(B\)-optimal. Therefore,

\( Q\text{ certifies }M \quad\Longleftrightarrow\quad Q\text{ certifies }\pi. \)

The minimum certificate sizes are consequently equal.

Finally, the construction has \(m=n\) and \(\tau=2n\). Each mass and each nonzero flow entry is the rational \(1/n\), whose binary numerator-denominator encoding uses \(O(\log n)\) bits. Even an explicit matrix representation has polynomial length. Thus the construction is a polynomial-time, promise-preserving many-one reduction.

This proves the claimed \(\mathrm{NP}\)-hardness for the exact mass-flow certification problem.
