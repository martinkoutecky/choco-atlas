The continuous mirror question, as graded

Given \(M\), \(k\), and demand-oracle access to two monotone, subadditive MPH-\(k\) valuation types \(v_A,v_B:2^M\to\mathbb{Q}_{\ge 0}\), put mass \(1/2\) on each type and supply \(1/2\) of each item. Compute a welfare-maximizing mass assignment \(x_{i,S}\ge 0\), subject to \(\sum_{S\subseteq M}x_{i,S}=1/2\) for each \(i\in\{A,B\}\) and \(\sum_{i\in\{A,B\},\,S\ni j}x_{i,S}\le 1/2\) for each \(j\in M\), maximizing \(\sum_{i,S}x_{i,S}v_i(S)\). Determine the worst-case ratio of normalized integral two-bidder welfare, \(\mathrm{OPT}_{\mathrm{int}}/2\), to this mass optimum, where \(\mathrm{OPT}_{\mathrm{int}}=\max_{S_A\cap S_B=\varnothing}\bigl(v_A(S_A)+v_B(S_B)\bigr)\).

Packaged proof task (what the prover saw — nothing else)

Let \(M\) contain \(m\) items and let \(2\le k\le m\). A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here two labeled types have mass \(1/2\) each, and each item has supply \(1/2\).
Each type has a monotone, subadditive valuation \(v_i:2^M\to\mathbb Q_{\ge0}\), with \(v_A(M)+v_B(M)>0\). MPH-\(k\) means \(v_i(S)=\max_{a\in\mathcal F_i}\sum_{T\subseteq S,\,|T|\le k}w_{i,a}(T)\) for nonnegative weights and a finite family \(\mathcal F_i\); this representation is promised, not supplied.
A demand oracle, given nonnegative binary-rational prices \(p\), returns any maximizing bundle for \(v_i(S)-\sum_{j\in S}p_j\), together with its value. Let \(L\) bound the binary encoding length of input numbers and valuation values; state algorithmic running times and oracle counts in \(m,\tau,L,k\).
Let \(C_{\mathrm{mass}}=\max_{x\ge0}\sum_{i,S}x_{i,S}v_i(S)\), subject to \(\sum_Sx_{i,S}=1/2\) for each type and \(\sum_{i,S\ni j}x_{i,S}\le1/2\) for each item. Let \(\mathrm{OPT}_{\mathrm{int}}=\max_{S_A\cap S_B=\varnothing}(v_A(S_A)+v_B(S_B))\).

What is the asymptotically tight dependence on \(k\) of \(\inf (\mathrm{OPT}_{\mathrm{int}}/2)/C_{\mathrm{mass}}\), over all admissible societies and item sets?

Known results: the two-bidder configuration-LP integrality ratio is \(1/2+\Theta(1/\log k)\), and its optimum is computable with polynomially many demand queries. [Primary source](https://arxiv.org/pdf/1811.09871).
The stated mass problem is exactly that configuration LP scaled by \(1/2\), so its ratio has the same established bound; this target is already settled.

Modeling choices made when packaging the task

  • Exclude the all-zero instance so the welfare ratio has a positive denominator.
  • Use integer levels 2 <= k <= m; levels above m impose the same valuation restriction as level m.
  • Treat A and B as labeled types whose valuation functions may coincide, as identical bidders are permitted in the discrete anchor.
  • Require demand replies to include the attained valuation and specify a binary encoding bound L for exact oracle computation.
  • Allow nonzero empty-bundle values: the supplied discrete definitions do not impose normalization.

Result

The asymptotically tight ratio is
\(\displaystyle \boxed{\frac12+\Theta\!\left(\frac1{\log k}\right)}\).

Here the infimum ranges over admissible instances with any number \(m\ge k\) of items. The constants implicit in \(\Theta\) are absolute, and the statement concerns sufficiently large \(k\).

Exact scaling

Define the ordinary two-bidder configuration-LP optimum by
\(\displaystyle C_{\mathrm{conf}}=\max_{y\ge0}\sum_{i\in\{A,B\}}\sum_{S\subseteq M}y_{i,S}v_i(S)\),
subject to
\(\displaystyle \sum_{S\subseteq M}y_{i,S}=1\)
for each bidder and
\(\displaystyle \sum_{i\in\{A,B\}}\sum_{S\ni j}y_{i,S}\le1\)
for each item.

The substitution \(y_{i,S}=2x_{i,S}\) is a bijection between the feasible solutions of the mass LP and this configuration LP: it doubles each type’s required mass and each item’s capacity. It also doubles the objective. Consequently,
\(\displaystyle C_{\mathrm{conf}}=2C_{\mathrm{mass}}\).

The denominator is positive. Indeed, choose a type \(i\) with \(v_i(M)>0\), give its entire mass to \(M\), and give the other type’s entire mass to the empty bundle. This is mass-feasible and has positive objective.

Therefore, for every admissible instance,
\(\displaystyle \frac{\mathrm{OPT}_{\mathrm{int}}/2}{C_{\mathrm{mass}}} =\frac{\mathrm{OPT}_{\mathrm{int}}}{C_{\mathrm{conf}}}. \)

Monotonicity also identifies the integral benchmark with the usual partition benchmark: any unallocated items can be assigned to one bidder without decreasing welfare.

Applying the established bound

Proposition 6.12 of Ezra, Feldman, Neyman, Talgam-Cohen, and Weinberg states that the two-bidder configuration-LP integrality ratio for subadditive MPH-\(k\) valuations is \(\frac12+\Theta(1/\log k)\). Its lower bound follows from Theorem 6.9; the matching examples use integer-valued valuations supported on \(k\) active items. [Primary source, Sections 6.5–6.6](https://arxiv.org/pdf/1811.09871).

Precisely, there are absolute constants \(c,C>0\) and \(k_0\) such that, for every \(k\ge k_0\):

  • Every instance in this class satisfies

\(\displaystyle \mathrm{OPT}_{\mathrm{int}}/C_{\mathrm{conf}}\ge\frac12+c/\log k\).

  • Some instance in this class satisfies

\(\displaystyle \mathrm{OPT}_{\mathrm{int}}/C_{\mathrm{conf}}\le\frac12+C/\log k\).

The hypotheses apply here: there are exactly two bidders, and both valuations are monotone, subadditive, and MPH-\(k\). The representation need only exist; supplying it is not a hypothesis of the integrality theorem. The integer-valued examples satisfy the rational-value restriction. Assigning both labeled types mass \(1/2\) converts each such example into an admissible society.

The instancewise identity proved above transfers both inequalities, establishing the claimed tight dependence.

Running time and demand queries

The LP optimum can be computed exactly using polynomially many demand queries. To explain the oracle requirement, the configuration dual is
\(\displaystyle \min_{p\ge0,\;u}\left(\sum_jp_j+\sum_i u_i\right), \)
with constraints
\(\displaystyle u_i+\sum_{j\in S}p_j\ge v_i(S) \quad\text{for every }i,S. \)

At a candidate point, first reject any negative price coordinate. Otherwise, a demand query to type \(i\) returns a maximizer \(S_i\) and its value. A constraint for this type is violated exactly when
\(\displaystyle v_i(S_i)-\sum_{j\in S_i}p_j>u_i\).
Any maximizing bundle suffices, so arbitrary tie-breaking causes no difficulty.

Let \(d=m+\tau\). All dual constraint coefficients have encoding length \(O(L)\), and the dual dimension is \(d\). Rational LP optimization with separation therefore gives polynomial bit complexity and polynomial-length query prices. Optimal primal solutions can also be recovered through the separation method. This demand-oracle implementation and primal recovery are described in [Section 6.4 of the primary source](https://arxiv.org/pdf/1811.09871).

Thus exact computation of \(C_{\mathrm{mass}}=C_{\mathrm{conf}}/2\) uses \(\operatorname{poly}(m+\tau,L)\) oracle calls and \(\operatorname{poly}(m+\tau,L)\) additional bit operations, excluding the oracle’s internal cost. A separation invocation uses at most \(\tau\) demand queries; here \(\tau=2\). These bounds have no additional dependence on \(k\) or on the size of the promised MPH representation.
