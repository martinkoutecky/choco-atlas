The continuous mirror question, as graded

Given a finite set of complete agent types \(T\), rational population masses \(\mu_t\), time endowments \(w_t\), rational per-capita supplies \(\beta_a\) of activity slots, and an explicit list of feasible team templates \(j\) for each activity class \(a\), find project masses \(x_{aj}\geq 0\) maximizing \(\sum_{a,j}x_{aj}\), subject to \(\sum_{a,j}d_{ajt}x_{aj}\leq \mu_t w_t\) for every type \(t\) and \(\sum_j x_{aj}\leq\beta_a\) for every activity class \(a\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq 1\) complete types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; each type has a positive integer time endowment \(w_t\).
There are \(m\geq 1\) activity classes, with finite nonnegative binary rational supplies \(\beta_a\) of slots per unit population. Each slot can support at most one project.
For each class \(a\), an explicit finite list \(J_a\) specifies its technologically feasible team templates. A template is a nonempty finite multiset of participant roles \((t,h)\), where \(t\in T\) and \(h\in\{1,\ldots,w_t\}\); singleton teams are allowed. Define \(d_{ajt}\) as the sum of the time requirements of its roles of type \(t\).
Project masses \(x_{aj}\in\mathbb{R}_{\geq 0}\) are divisible; types supply pooled time, and templates impose no constraints beyond those stated. Maximize \(\sum_{a=1}^{m}\sum_{j\in J_a}x_{aj}\), subject to \(\sum_{a=1}^{m}\sum_{j\in J_a}d_{ajt}x_{aj}\leq\mu_tw_t\) for every \(t\), and \(\sum_{j\in J_a}x_{aj}\leq\beta_a\) for every \(a\).
Let \(K=\sum_a|J_a|\), and let \(L\) be the total binary input length, including any threshold.

Is exact maximum-project-mass optimization solvable in time polynomial in \(m,\tau,K,L\), or is its decision version, asking whether the optimum is at least an input binary rational \(q\geq 0\), \(\mathrm{NP}\)-hard?

In finite societies, when every feasible project addition strictly benefits each participant, myopic formation with independent rare project deletions, optionally also creations, has exactly the project-count maximizers as its stochastically stable states. This is a characterization, without a computational complexity bound. [Boncinelli–Muscillo–Pin](https://link.springer.com/article/10.1007/s13235-022-00438-y)
That characterization does not establish a complexity result for the divisible mass formulation above.

Modeling choices made when packaging the task

  • Normalized the positive population masses to sum to one, so project masses and activity supplies are measured per unit population.
  • Preserved positive integer individual time endowments and integer participant time requirements from the discrete definition; defined the previously undefined coefficients as aggregate time required from each type by a template.
  • Required nonempty templates to exclude projects without participants; allowed singleton teams because the anchor imposes no minimum team size of two.
  • Interpreted each activity class as a supply of interchangeable slots, each supporting at most one project, retaining the graded class-capacity constraints and the published activity exclusivity condition.
  • Made explicit that time is pooled within types and project masses are divisible, with feasibility determined solely by the stated constraints.
  • Introduced the template count, total input bit length, and rational decision threshold to specify the computational question.

Result

Exact maximum-project-mass optimization is solvable in time polynomial in \(m,\tau,K,L\). An optimal rational allocation can also be computed within this bound. The threshold decision problem belongs to \(\mathrm{P}\), and therefore can be \(\mathrm{NP}\)-hard under polynomial-time reductions only if \(\mathrm{P}=\mathrm{NP}\).

The proof uses the stated interpretation: project masses are divisible, type time is pooled, and the explicitly listed templates impose exactly the given resource constraints.

1. Constructing the linear program

Let \(I=\{(a,j):1\leq a\leq m,\ j\in J_a\}\), so \(|I|=K\). Define \(b_t=\mu_tw_t\).

Construct a matrix \(A\) with \(K\) columns and \(\tau+m\) rows. For column \((a,j)\):

  • Its entry in type row \(t\) is \(d_{ajt}\).
  • Its entry in class row \(a'\) is \(1\) if \(a'=a\), and \(0\) otherwise.

Let \(c\) be the vector whose type entries are \(b_t\) and whose class entries are \(\beta_a\). The problem is exactly the rational linear program

\(\displaystyle \max\{\mathbf{1}^{\mathsf T}x:Ax\leq c,\ x\geq0\}.\)

This equivalence follows directly from the premises: the type rows account for pooled time, the class rows account for slots, and there are no additional feasibility conditions.

If \(K=0\), the optimum is \(0\), and the threshold question is answered affirmatively exactly when \(q=0\). Henceforth assume \(K\geq1\).

2. The linear program has polynomial encoding length

The coefficients \(d_{ajt}\) can be computed by scanning the explicit role lists and adding their time requirements.

To check their binary lengths, let \(s\) be the total number of listed role occurrences. Since these occurrences are explicitly encoded, \(s\leq L\). Every encoded time requirement has value less than \(2^L\), so

\(\displaystyle 0\leq d_{ajt}<s\,2^L.\)

Thus each \(d_{ajt}\) has \(O(L+\log(L+1))\) bits. Computing these sums requires only polynomially many additions of integers of polynomial binary length.

The conclusion also holds if a multiset is represented by explicit role records with binary multiplicities: multiply each multiplicity by its time requirement and sum. Each product has \(O(L)\) bits, and there are at most \(L\) records.

Write an input mass as \(\mu_t=p_t/r_t\), where \(p_t,r_t\) are positive binary integers. Then

\(\displaystyle b_t=\frac{p_tw_t}{r_t}.\)

The product \(p_tw_t\) has at most the sum of the binary lengths of its factors, so \(b_t\) has polynomial binary length. The supplies \(\beta_a\) already have binary rational encodings in the input.

Consequently, even a dense encoding of the matrix, right-hand side, objective, and nonnegativity constraints has total length polynomial in \(m,\tau,K,L\). Denote that length by \(B\). This construction never enumerates types outside the supplied support.

3. Feasibility, attainment, and exact optimization

The zero allocation is feasible because all resource bounds are nonnegative.

For every variable \(x_{aj}\), nonnegativity and its class constraint imply

\(\displaystyle 0\leq x_{aj}\leq\sum_{j'\in J_a}x_{aj'}\leq\beta_a.\)

Every \(\beta_a\) is finite. Therefore the feasible set is bounded. It is also closed, being defined by finitely many non-strict linear inequalities. Hence it is a nonempty compact set, and the continuous objective attains a finite maximum.

We apply the polynomial-time rational linear programming theorem: a linear program with explicitly encoded rational data can be solved in time polynomial in its dimensions and total binary encoding length; when its optimum is finite and attained, an exact rational optimal solution can be returned. This is the bit-complexity result originating with [Khachiyan’s polynomial algorithm for linear programming](https://www.mathnet.ru/eng/dan42319).

All hypotheses have been checked: the data are rational and explicitly encoded, their encoding length is polynomial, and the feasible region is nonempty with an attained finite optimum. Thus exact optimization takes time polynomial in \(m,\tau,K,L\).

For completeness, exact rational output does not require exponentially many bits. A nonempty bounded polyhedron has a vertex maximizing any given linear objective. At such a vertex, \(K\) linearly independent tight constraints determine the coordinates.

Clear denominators in each constraint. Since the original program has encoding length \(B\), all resulting integer coefficients and right-hand sides have absolute value at most \(H=2^{O(B)}\). If \(M\) is the nonsingular matrix of the selected tight constraints and \(r\) their right-hand side, Cramer’s rule gives

\(\displaystyle x_i=\frac{\det M_i}{\det M},\)

where \(M_i\) replaces column \(i\) of \(M\) by \(r\). The determinant expansion yields

\(\displaystyle |\det M|,\ |\det M_i|\leq K!H^K.\)

Their binary lengths are therefore \(O(KB+K\log(K+1))\). The coordinates, and their sum, consequently have polynomial-length exact rational representations.

4. The threshold decision problem

For an input rational threshold \(q\), append the inequality

\(\displaystyle -\mathbf{1}^{\mathsf T}x\leq-q.\)

The resulting rational system is feasible if and only if the optimum is at least \(q\):

  • A feasible solution of the augmented system has project mass at least \(q\), so the optimum is at least \(q\).
  • If the optimum is at least \(q\), an attained optimal allocation satisfies the augmented system.

The added inequality has polynomial encoding length because the encoding of \(q\) is included in \(L\). Polynomial-time rational linear feasibility therefore decides the threshold question. In particular, equality with the threshold is handled exactly.

5. Relation to the finite-society characterization

[Boncinelli–Muscillo–Pin, Proposition 2](https://link.springer.com/article/10.1007/s13235-022-00438-y), characterizes the stochastically stable states of its finite team-formation model as project-count maximizers under the stated dynamics and perturbations.

The complexity proof above is independent of that characterization. It follows from the divisible variables, pooled resources, and explicit polynomial-size linear program in the present task. It establishes no running-time bound for finding finite-society stable states or for reaching them through the stochastic dynamics.
