Result. The problem is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions. Consequently, it is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions, even with one oracle query. It belongs to \(\mathrm{P}\) if and only if \(\mathrm{P}=\mathrm{NP}\).

1. Definitions and exact verification.

Let \(R\) denote the recognition problem in the question. Kendall tau distance \(d_{\mathrm{KT}}(t,Y)\) counts the unordered candidate pairs on which \(t\) and \(Y\) disagree. Thus \(0\leq d_{\mathrm{KT}}(t,Y)\leq \binom m2\).

An instance fails recognition precisely when some total order \(Y\) satisfies \(S(Y)<S(X)\). Such a \(Y\), encoded as a permutation of the candidates, is a polynomial-length certificate. We must verify the strict inequality using exact arithmetic.

Write each input mass as \(\mu_t=a_t/b_t\), where \(a_t,b_t\) are positive binary integers. Define

\(D=\prod_{t\in T}b_t,\qquad w_t=a_t(D/b_t).\)

Every \(w_t\) is an integer. Normalization gives

\(\sum_{t\in T}w_t=D.\)

For any order \(Z\), its scaled score is the integer

\(Q(Z)=\sum_{t\in T}w_t d_{\mathrm{KT}}(t,Z)=D S(Z).\)

Because \(D>0\), the certificate condition is exactly \(Q(Y)<Q(X)\). Moreover,

\(0\leq Q(Z)\leq D\binom m2.\)

The binary length of \(D\) is at most \(1+\sum_t\log_2 b_t\), hence at most \(L+1\). Therefore the weights and scaled scores have \(O(L+\log(m+1))\) bits. Clearing denominators does not require expanding the society into individual voters.

To verify a certificate, check that \(Y\) is a permutation, construct position tables for the rankings, count pair disagreements, and compare the two integer scores. Put \(B=L+\lceil\log_2(m+2)\rceil\). Using schoolbook integer arithmetic, a conservative bit-operation bound is

\(O\bigl((L+\tau(m+1)^2)B^2\bigr).\)

This includes constructing the common denominator and weights. Consequently, the complement of \(R\) belongs to \(\mathrm{NP}\), so \(R\in\mathrm{coNP}\). The strict inequality ensures that tied minimizers qualify.

2. Transfer from explicitly listed voters.

Theorem 5 of [Fitzsimmons and Hemaspaandra, *Kemeny Consensus Complexity*](https://www.ijcai.org/proceedings/2021/0028.pdf) establishes \(\mathrm{coNP}\)-completeness of Kemeny Consensus Recognition under polynomial-time many-one reductions. Their consensus definition minimizes the sum of Kendall tau distances over explicitly listed, unweighted voters and permits multiple minimizing orders. These are exactly the objective and tie convention needed here.

Take such an instance with voter rankings \(v_1,\ldots,v_n\), where \(n>0\), and proposed order \(X\). Let \(T\) contain the distinct rankings occurring in the voter list. For each \(t\in T\), let

\(k_t=|\{i:v_i=t\}|,\qquad \mu_t=k_t/n.\)

The resulting instance satisfies every support requirement:

  • The rankings in \(T\) are distinct strict total orders.
  • Each mass is a positive rational with a binary encoding.
  • Since \(\sum_t k_t=n\), the masses sum to \(1\).
  • The support size satisfies \(\tau\leq n\).

For every total order \(Y\),

\(S(Y)=\sum_{t\in T}\frac{k_t}{n}d_{\mathrm{KT}}(t,Y)=\frac1n\sum_{i=1}^{n}d_{\mathrm{KT}}(v_i,Y).\)

Multiplication by the positive constant \(1/n\) preserves every score comparison, including equality. Hence \(X\) is a consensus of the original election if and only if the constructed support instance belongs to \(R\).

The transformation is polynomial in the explicitly listed input length. More specifically, let \(N\) be that source length. After relabeling candidates by integers, the output length satisfies

\(L=O\bigl((\tau+1)(m+1)\log(m+2)+\tau\log(n+1)\bigr).\)

Each numerator and denominator uses \(O(\log(n+1))\) bits. Directly grouping identical rankings and, if required, reducing the fractions can be performed within a conservative \(O(N^3)\) bit-operation bound. Since the voters are explicitly listed, \(n\leq N\), so both the construction time and output length are polynomial in \(N\).

If the source convention permits an empty electorate, every proposed order is then minimizing; map that case to a fixed valid yes-instance with one ranking of mass \(1\).

Thus this transformation is a polynomial-time many-one reduction to \(R\). The cited hardness theorem implies that \(R\) is \(\mathrm{coNP}\)-hard. Together with Section 1, this proves \(\mathrm{coNP}\)-completeness for the precise normalized binary rational support representation.

3. Why this answers the requested Turing-hardness question.

Let \(A\) be any language in \(\mathrm{NP}\). Its complement \(\overline A\) belongs to \(\mathrm{coNP}\). By the completeness just proved, there is a polynomial-time function \(f\) such that

\(x\in\overline A\ \Longleftrightarrow\ f(x)\in R.\)

A deterministic algorithm with an oracle for \(R\) decides \(A\) by constructing \(f(x)\), making one oracle query, and accepting exactly when the oracle answers no. Therefore \(A\leq_T^p R\).

Since this holds for every \(A\in\mathrm{NP}\), recognition is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. In particular, a polynomial-time recognition algorithm would imply \(\mathrm{P}=\mathrm{NP}\). Conversely, if \(\mathrm{P}=\mathrm{NP}\), then \(\mathrm{coNP}=\mathrm{P}\), so recognition would be polynomial-time solvable.
