The continuous mirror question, as graded

Given \(C\), \(p\in C\), and a binary-rational distribution \(\mu\) over the supported complete rankings of \(C\), decide whether \(C\) has a split \(C_1\sqcup C_2\) with \(\bigl||C_1|-|C_2|\bigr|\le 1\) such that each side advances its sole weak Condorcet winner, if one exists, according to \(q_\mu(a,b)=\sum_{t:\,a\succ_t b}\mu_t\), and \(p\) is the sole weak Condorcet winner among the candidates who advance.

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m=|C|\geq 1\) and \(p\in C\), a society is given by its support: the list of the \(\tau\) distinct strict complete rankings of \(C\) with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length, and state running times in \(m,\tau,L\).
For distinct candidates define \(q_\mu(a,b)=\sum_{t:\,a\succ_t b}\mu_t\). On a candidate subset \(S\), the weak Condorcet winners are \(W_\mu(S)=\{a\in S:\ q_\mu(a,b)\geq 1/2\text{ for every }b\in S\setminus\{a\}\}\); in particular, \(W_\mu(\varnothing)=\varnothing\) and a singleton's candidate wins.
Choose a partition \(C=C_1\sqcup C_2\) satisfying \(\bigl||C_1|-|C_2|\bigr|\leq 1\). Each side advances its winner exactly when \(|W_\mu(C_i)|=1\), and otherwise advances nobody (ties eliminate). If \(A\) is the set of advancing candidates, the partition succeeds exactly when \(W_\mu(A)=\{p\}\). Every stage uses the entire unchanged society, with rankings restricted to the candidates participating in that stage.

Is deciding whether a successful partition exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For explicit finite electorates, weak Condorcet runoff candidate partition without the size constraint is in \(\mathrm{P}\) under both ties eliminate and ties promote; with equipartition, the ties-promote version is NP-complete. The ties-eliminate equipartition version was explicitly left unclassified in the [verified result](https://arxiv.org/pdf/1410.2652v1). No classification of the rational-mass formulation above was located.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: all listed masses are positive binary rationals and sum to one.
  • Retained the graded question's ties-eliminate rule, although the anchor's equipartition hardness result concerns ties promote.
  • Made explicit that every stage uses the entire unchanged society, restricting only the candidate set.
  • Allowed the single-candidate input and its necessarily empty partition side; an empty election has no winners and a singleton candidate wins.
  • Defined L as the total input bit length.

Classification

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when all masses are dyadic rationals, the support size satisfies \(\tau=O(m)\), and \(m\) is even.

The case \(m=1\) is trivially successful. The proof below concerns unbounded candidate sets.

1. Pairwise representation and membership in \(\mathrm{NP}\)

Write \(a\to b\) when \(q_\mu(a,b)>1/2\). Because every ranking is strict and complete,

\[ q_\mu(a,b)+q_\mu(b,a)=1. \]

Consequently, a candidate belongs to \(W_\mu(S)\) exactly when no candidate in \(S\) has an arc into it. Restricting rankings to a candidate subset preserves all comparisons between the remaining candidates.

A partition is a polynomial-size certificate. Its balance, preliminary winner sets, advancing candidates, and final winner set can all be checked from the pairwise comparison table.

For an explicit arithmetic bound, write each mass as \(\mu_t=a_t/b_t\), and let \(D=\prod_{t=1}^{\tau}b_t\). The bit length of \(D\) is \(O(L)\). Compute the integer weights \(w_t=a_t(D/b_t)\), and, for every ordered candidate pair, sum the weights of rankings placing the first candidate above the second. Comparing twice this sum with \(D\) determines the pairwise outcome exactly.

Using schoolbook integer arithmetic, this computation and certificate verification take

\[ O\!\left(\tau L^2+m^2\tau L\right) \]

bit operations. Thus the problem belongs to \(\mathrm{NP}\).

2. The source problem and a padding step

We reduce from Exact Cover by 3-Sets, abbreviated X3C, using its standard \(\mathrm{NP}\)-completeness theorem.

An instance consists of a universe \(U\), with \(|U|=3k\), and a family \(S_1,\ldots,S_n\) of three-element subsets of \(U\). The question is whether exactly \(k\) of these sets cover every element exactly once.

We may assume \(k\geq1\) and \(n\geq k\). Instances with \(k=0\) are trivially yes, and instances with \(n<k\) are trivially no. These can be mapped to fixed yes and no elections, respectively: a singleton election is yes, while two candidates with a unanimous ranking placing the other candidate above \(p\) give a no instance.

We first ensure that

\[ k\leq n\leq2k. \]

Given an instance with \(n\geq k\), let \(d=\max\{0,n-2k\}\). Add \(d\) mutually disjoint triples of fresh elements to the universe, and add exactly those \(d\) triples to the family. Each fresh element occurs only in its added triple, so every exact cover must select all the added triples. Therefore this padding preserves the answer.

The new parameters are \(k'=k+d\) and \(n'=n+d\). They satisfy \(k'\leq n'\leq2k'\). Indeed, if \(n>2k\), then \(n'=2(n-k)=2k'\); otherwise nothing changes. The padding is polynomial. Henceforth, rename the padded parameters \(k,n\).

3. Candidate construction and intended pairwise outcomes

Set

\[ \ell=3k+1,\qquad g=(2k-n+1)\ell. \]

Since \(n\leq2k\), we have \(g\geq\ell\geq4\).

Construct the following disjoint candidate sets:

  • the distinguished candidate \(p\);
  • one element candidate \(e_u\) for each \(u\in U\);
  • for each set \(S_i\), a block \(Z_i=\{z_{i,0},\ldots,z_{i,\ell-1}\}\);
  • a set \(G\) of \(g\) guard candidates.

Specify precisely these strict majority arcs:

  • For each \(i\), the candidates of \(Z_i\) form a directed cycle:

\[ z_{i,j}\to z_{i,j+1\bmod\ell}. \]

  • For every \(u\in S_i\), include \(z_{i,0}\to e_u\).
  • Every guard \(b\in G\) satisfies \(b\to p\).

Every other pairwise contest is tied. Section 5 constructs strict complete rankings and positive dyadic masses realizing these outcomes.

In particular, \(p\) ties every nonguard candidate, no candidate defeats a guard, and the sole candidate that defeats a cycle candidate is its predecessor in its own cycle.

The total number of candidates is

\[ m=1+3k+n\ell+g =\ell+n\ell+(2k-n+1)\ell =2(k+1)\ell. \]

Thus every permitted partition has both sides of size

\[ K=(k+1)\ell=1+k\ell+3k. \]

4. Correctness of the reduction

A successful partition yields an exact cover

Suppose a partition succeeds, and let \(P\) be its side containing \(p\). Let \(Q=C\setminus P\).

Since \(W_\mu(A)=\{p\}\), the candidate \(p\) must belong to the advancing set \(A\). Under ties eliminate, this requires

\[ W_\mu(P)=\{p\}. \]

No guard can belong to \(P\), because every guard strictly defeats \(p\). Therefore \(G\subseteq Q\).

We now determine the possible contents of \(P\).

Each cycle block is either entirely in \(P\) or entirely outside \(P\). To prove this, suppose \(z_{i,j}\in P\). If its predecessor were absent from \(P\), then \(z_{i,j}\) would have no incoming arc in \(P\), because that predecessor is its only strict defeater. It would then belong to \(W_\mu(P)\), contradicting \(W_\mu(P)=\{p\}\). Its predecessor must therefore also belong to \(P\). Repeating this argument around the cycle puts all of \(Z_i\) in \(P\).

Let \(h\) be the number of complete cycle blocks in \(P\), and let \(x\) be the number of element candidates in \(P\). There are no guards in \(P\), so balance gives

\[ 1+h\ell+x=K=1+k\ell+3k. \]

Hence

\[ (h-k)\ell=3k-x. \]

The right-hand side is an integer between \(0\) and \(3k=\ell-1\). The left-hand side is a multiple of \(\ell\). Their equality therefore forces

\[ h=k,\qquad x=3k. \]

Thus \(P\) contains exactly \(k\) cycle blocks and every element candidate.

Every element candidate \(e_u\) must have an incoming arc in \(P\), since it cannot be another weak Condorcet winner alongside \(p\). Its only possible incoming arcs are from candidates \(z_{i,0}\) with \(u\in S_i\). Consequently, the \(k\) sets corresponding to the selected cycle blocks cover all of \(U\).

These \(k\) sets have total cardinality \(3k=|U|\). Since they cover \(U\), each element must occur in exactly one selected set: otherwise the total number of element occurrences would exceed \(3k\). They therefore form an exact cover.

An exact cover yields a successful partition

Conversely, let \(I\subseteq\{1,\ldots,n\}\) index an exact cover, with \(|I|=k\). Choose

\[ P=\{p\}\cup\{e_u:u\in U\}\cup\bigcup_{i\in I}Z_i, \qquad Q=C\setminus P. \]

Then \(|P|=1+3k+k\ell=K\), and \(|Q|=K\), so the partition is balanced.

Within \(P\):

  • no candidate defeats \(p\);
  • every cycle candidate is defeated by its predecessor;
  • every element candidate is defeated by a selected representative \(z_{i,0}\), because the selected sets cover \(U\).

It follows that \(W_\mu(P)=\{p\}\), so \(p\) advances.

All guards belong to \(Q\). No candidate defeats any guard, so every guard is a weak Condorcet winner in \(Q\). Since \(g\geq4\), we have \(|W_\mu(Q)|\geq2\), and ties eliminate advances nobody from \(Q\).

Thus \(A=\{p\}\), whose unique weak Condorcet winner is \(p\). The partition succeeds.

This proves the equivalence between the X3C instance and the constructed election, provided the specified outcomes are realizable.

5. Realization by a polynomial-size rational-mass society

We give the realization explicitly.

For each specified arc \(a\to b\), choose a fixed ordering \(R\) of the other candidates and introduce the two rankings

\[ a\succ b\succ R, \qquad R^{\mathrm{rev}}\succ a\succ b. \]

Both rankings place \(a\) above \(b\), giving this pair a vote-count margin of \(2\). Every other pair receives margin \(0\) from these two rankings:

  • comparisons between two members of \(R\) reverse;
  • each of \(a,b\) is above every member of \(R\) in the first ranking and below it in the second.

Let \(r\) be the number of specified arcs. Here

\[ r=n\ell+3n+g=O(m). \]

The construction above uses \(2r\) rankings. Choose \(M\) to be the smallest power of two at least \(2r\). Thus \(2r\leq M<4r\). Add reversal pairs of arbitrary complete rankings until the electorate contains exactly \(M\) rankings. This is possible because \(M-2r\) is even, and every reversal pair contributes zero margin to every contest.

The resulting society satisfies

\[ q_\mu(a,b)= \begin{cases} \frac12+\frac1M,&a\to b,\\ \frac12-\frac1M,&b\to a,\\ \frac12,&\text{neither arc is specified}. \end{cases} \]

There are no opposite specified arcs, so these outcomes realize exactly the construction in Section 3.

Give each of the \(M\) voters mass \(1/M\), then coalesce identical rankings. A distinct ranking occurring \(c_t\) times receives mass \(\mu_t=c_t/M\). These masses are positive dyadic rationals and sum to \(1\), as required. Coalescing preserves every pairwise probability.

Since \(M=O(m)\), the resulting support size and encoding length satisfy

\[ \tau=O(m),\qquad L=O(m^2\log m). \]

Generating the rankings and coalescing duplicates by lexicographic sorting takes \(O(m^2(\log m)^2)\) bit operations. After padding, \(k\) is at most the sum of the original parameters, and \(m=2(k+1)(3k+1)\). Thus the entire reduction has polynomial size and running time in the original X3C input length.

6. Conclusion

The reduction proves \(\mathrm{NP}\)-hardness, and Section 1 proves membership in \(\mathrm{NP}\). Therefore the stated rational-mass problem is \(\mathrm{NP}\)-complete.

The construction also uses only \(O(m)\) explicit voters before coalescing. It therefore establishes the same classification for explicit finite electorates under the stated rules—the ties-eliminate case left open immediately before Theorem 4.4 in the [cited paper](https://arxiv.org/pdf/1410.2652).
