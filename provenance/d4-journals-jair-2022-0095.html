The continuous mirror question, as graded

Given candidates \(C\), a tree \(T\) on \(C\), a finite-support rational distribution \(\mu=(\mu_t)\) over complete ranking types \(\pi_t\) that are all single-peaked on \(T\), a committee size \(k\), and a rational threshold \(b\), decide whether there exists an integral committee \(W\subseteq C\) with \(|W|=k\) such that \(\sum_t \mu_t\bigl[-(\operatorname{pos}_{\pi_t}(\operatorname{top}_{\pi_t}(W))-1)\bigr]\ge b\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) distinct strict complete ranking types \(\pi_t\) over a candidate set \(C\), each with positive mass \(\mu_t\) encoded as a binary rational, with \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
Let \(m=|C|\ge1\). A tree \(T\) on \(C\) is supplied; each ranking is single-peaked on \(T\), meaning that every nonempty initial segment of the ranking induces a connected subtree.
The remaining inputs are an integer \(1\le k\le m\) and a binary rational threshold \(b\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L,k\).
For a nonempty committee \(W\subseteq C\), let \(\operatorname{top}_{\pi_t}(W)\) be its highest-ranked member, with ranking positions numbered from \(1\). Its utilitarian Chamberlin–Courant score is \(S(W)=\sum_{t=1}^{\tau}\mu_t[-(\operatorname{pos}_{\pi_t}(\operatorname{top}_{\pi_t}(W))-1)]\). Committee membership is integral; members need not represent positive mass, and there are no representation quotas.

Is deciding whether some \(W\subseteq C\) satisfies \(|W|=k\) and \(S(W)\ge b\) solvable in polynomial time, or is it NP-hard?

For finite electorates with unit-weight voters, this Borda utilitarian Chamberlin–Courant decision problem is NP-complete, even when the supplied tree has diameter \(4\) and pathwidth \(2\).
For finite electorates whose rankings are single-peaked on a star, Borda utilitarian Chamberlin–Courant winner determination is polynomial-time solvable.

Modeling choices made when packaging the task

  • Made distribution normalization explicit: positive support masses sum to one.
  • Specified the admissible committee-size domain as 1 through the number of candidates, including the one-candidate case.
  • Defined the highest-ranked committee member for every nonempty committee, including committees of size one or two.
  • Preserved the discrete rule's allowance for committee members representing no mass and its absence of representation quotas.
  • Defined L as the total binary input length and allowed any rational threshold.

Conclusion

The decision problem is NP-complete, even when the supplied tree has diameter \(4\) and pathwidth \(2\). The stated finite-electorate hardness transfers by grouping identical rankings and normalizing their multiplicities. Binary rational masses make this conversion polynomial in size.

Here \(k\) is part of the input. The boundary case \(k=m\) is immediate: the only committee has score \(0\), so the answer is yes exactly when \(b\le 0\).

Polynomial reduction from finite electorates

Use the finite-electorate NP-completeness result given in the question. Consider a source instance with \(n\ge 1\) explicitly listed unit-weight voters, candidate set \(C\), supplied tree \(T\), committee size \(k\), and threshold \(B\). Write its usual Borda utilitarian score as

\[ U(W)=\sum_{i=1}^{n}\bigl(m-\operatorname{pos}_{\pi_i}(\operatorname{top}_{\pi_i}(W))\bigr). \]

The source question is whether some committee of size exactly \(k\) satisfies \(U(W)\ge B\).

Group identical rankings. Let the resulting distinct types be \(\pi_1,\ldots,\pi_\tau\), with positive integer multiplicities \(n_1,\ldots,n_\tau\). Thus

\[ \sum_{t=1}^{\tau}n_t=n, \qquad \tau\le n. \]

Construct the target society by setting

\[ \mu_t=\frac{n_t}{n}, \qquad b=\frac{B-n(m-1)}{n}. \]

Keep \(C,T,k\) unchanged. Every mass is positive, and their sum is \(1\). Every retained ranking already occurred in the source electorate, so it remains single-peaked on the supplied tree.

For every nonempty committee \(W\),

\[ \begin{aligned} nS(W) &=\sum_{t=1}^{\tau}n_t \bigl(1-\operatorname{pos}_{\pi_t}(\operatorname{top}_{\pi_t}(W))\bigr)\\ &=U(W)-n(m-1). \end{aligned} \]

Consequently,

\[ U(W)\ge B \quad\Longleftrightarrow\quad S(W)\ge b. \]

The feasible committees are unchanged: both instances require exactly \(k\) integral members and impose no representation quotas.

If the source theorem instead uses the negative rank-offset convention directly, the same construction uses its source threshold divided by \(n\).

Encoding size and hardness

Each fraction \(n_t/n\) needs \(O(\log(n+1))\) bits. The new threshold has bit length

\[ O\bigl(\operatorname{bits}(B)+\log(n+1)+\log(m+1)\bigr). \]

After indexing candidates by integers, the target input length satisfies

\[ L=O\bigl( \tau m\log(m+1) +\tau\log(n+1) +m\log(m+1) +\operatorname{bits}(B) +\log(n+1) \bigr). \]

Because the source electorate is explicitly listed and \(\tau\le n\), this is polynomial in the source input length. Grouping rankings can be performed by sorting their explicit lists, also in polynomial time.

The reduction leaves the tree unchanged. Hence the supplied source hardness for trees of diameter \(4\) and pathwidth \(2\) holds for the target problem under those same restrictions.

This proves NP-hardness. The stated polynomial-time result for finite electorates on stars concerns a narrower tree class and does not contradict this reduction.

Membership in NP and verification time

A certificate lists \(k\) distinct candidates, requiring \(O(k\log(m+1))\) bits. Check membership in \(C\), distinctness, and cardinality exactly \(k\).

For each ranking type, determine

\[ r_t=\min_{c\in W}\operatorname{pos}_{\pi_t}(c), \qquad d_t=r_t-1. \]

Then the required comparison is

\[ -\sum_{t=1}^{\tau}\mu_t d_t\ge b. \]

This comparison can be performed exactly. Write the encoded rationals as

\[ \mu_t=\frac{p_t}{q_t}, \qquad b=\frac{a}{q_b}, \]

with positive denominators, and set

\[ D=q_b\prod_{t=1}^{\tau}q_t. \]

Since \(D>0\), the comparison is equivalent to the integer inequality

\[ -\sum_{t=1}^{\tau}p_t d_t\frac{D}{q_t} \ge a\frac{D}{q_b}. \]

The bit length of \(D\) is at most the sum of the encoded denominator lengths, hence \(O(L)\). All intermediate integers have \(O(L)\) bits: the additional factors and summation contribute only \(O(\log(m+1)+\log(\tau+1))\) bits, which are already \(O(L)\).

Using straightforward ranking scans and schoolbook integer arithmetic gives the conservative verification bound

\[ O\bigl((\tau m+k)L+(\tau+1)L^2\bigr) \]

bit operations. This is polynomial in \(m,\tau,L,k\), so the problem belongs to NP.

Together with the reduction, this establishes NP-completeness.
