The anchor (named result in the paper)

Proposition 1 — class: other

The continuous mirror question, as graded

Given a finite set of house classes \(H\), a finite type support \(T\), rational masses \(\mu_t\), and a type description \((e_t,\succ_t)\) giving each type's endowed class and strict incomplete preferences, let \(q_h=\sum_{t:e_t=h}\mu_t\). Given a feasible rational allocation \(y_{t,r}\) with \(\sum_r y_{t,r}=\mu_t\) and \(\sum_t y_{t,h}=q_h\), decide whether there is no mass transfer \(z_{t,r,h}\geq 0\) satisfying \(\sum_h z_{t,r,h}\leq y_{t,r}\), \(z_{t,r,h}=0\) unless \(h=r\) or \(h\succ_t r\), and \(\sum_{t,r}z_{t,r,h}=\sum_{t:e_t=h}\sum_{r,a}z_{t,r,a}\) for every \(h\), with \(\sum_{t,r,h:\,h\succ_t r}z_{t,r,h}>0\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Let \(H\) be a nonempty set of \(m\) house classes. Each type has an endowed class \(e_t\in H\) and a possibly incomplete strict partial order \(\succ_t\) on \(H\), given explicitly as ordered pairs; incomparability need not be transitive. Set \(q_h=\sum_{t:e_t=h}\mu_t\).
The input includes a nonnegative binary-rational allocation \(y\) satisfying \(\sum_{r\in H}y_{t,r}=\mu_t\) and \(\sum_{t\in T}y_{t,h}=q_h\). Mass represents divisible populations receiving individual house classes, not lotteries evaluated by an additional preference rule.
A blocking transfer is an array of real masses \(z_{t,r,h}\geq0\), indexed by \(t\in T\) and \(r,h\in H\), satisfying \(\sum_{h\in H}z_{t,r,h}\leq y_{t,r}\), with \(z_{t,r,h}=0\) unless \(h=r\) or \(h\succ_t r\).
It must also satisfy \(\sum_{t\in T,r\in H}z_{t,r,h}=\sum_{t:e_t=h}\sum_{r,a\in H}z_{t,r,a}\) for every \(h\in H\), and \(\sum_{t,r,h:\,h\succ_t r}z_{t,r,h}>0\). Thus participants redistribute their original endowments, may retain their current class, and must strictly improve some positive mass.
Call \(y\) core-stable when no blocking transfer exists. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is deciding whether \(y\) is core-stable in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite agents, each owning one distinct house, the core under the same equality-or-strict-improvement blocking condition equals the set of TTC outcomes over all strict linear-order extensions of agents’ preferences, and is always nonempty ([Guamán and Torres-Martínez](https://econ.uchile.cl/uploads/publicacion/2962657aaf40fe510b804d1024c0f39f2b73b79d.pdf)). This characterization supplies no polynomial-time bound for membership testing. No result settling the exact mass-transfer decision problem was verified.

  • Specified strict incomplete preferences as explicitly represented strict partial orders, carrying over transitivity and allowing complete orders.
  • Specified allocation entries as nonnegative binary rationals and transfer variables as real masses.
  • Interpreted allocation entries as masses of individuals receiving particular classes, rather than preference comparisons between lotteries.

Conclusion

Deciding whether \(y\) is core-stable is in \(\mathrm{P}\). A blocking transfer exists exactly when a directed graph constructed from the input contains a directed cycle using at least one arc that represents strict improvement.

The graph test takes \(O(L+\tau m^2)\) time in the standard word-RAM model. The proof uses the divisibility of population masses: any suitable cycle can be scaled to satisfy all participation bounds.

1. Constructing the graph

Construct a directed multigraph \(G\) whose vertices are the house classes \(H\).

For every triple \((t,r,h)\) satisfying

\(y_{t,r}>0 \quad\text{and}\quad (h=r\ \text{or}\ h\succ_t r),\)

include an arc from \(e_t\) to \(h\), labeled by \((t,r,h)\). Mark this arc precisely when \(h\succ_t r\).

The tail is the participant’s original endowment \(e_t\). The label \(r\) records the participant’s current class and hence the applicable capacity \(y_{t,r}\). Parallel arcs retain their separate labels.

There are at most \(\tau m^2\) arcs.

2. A blocking transfer implies a marked cycle

Suppose \(z\) is a blocking transfer. Whenever \(y_{t,r}=0\), nonnegativity and the participation bound imply \(z_{t,r,h}=0\) for every \(h\). The allowed-transfer restriction therefore ensures that every positive entry of \(z\) corresponds to an arc of \(G\).

Give each labeled arc \((t,r,h)\) flow \(z_{t,r,h}\). At a vertex \(v\), its total incoming and outgoing flows are respectively

\(\displaystyle \sum_{t,r}z_{t,r,v} \quad\text{and}\quad \sum_{t:e_t=v}\sum_{r,a}z_{t,r,a}.\)

The endowment-balance constraints say exactly that these quantities are equal. Thus \(z\) defines a nonnegative circulation on \(G\).

Because the total strict-improvement mass is positive, some marked arc \(u\to v\) has positive flow. We show that its head can reach its tail using positive-flow arcs.

Let \(R\) be the set of vertices reachable from \(v\) through positive-flow arcs. If \(u\notin R\), the arc \(u\to v\) supplies positive flow into \(R\). No positive-flow arc leaves \(R\), by the definition of reachability. But summing flow conservation over vertices in \(R\), with internal flows canceling, gives

\(\text{total flow entering }R=\text{total flow leaving }R.\)

This contradicts positive incoming flow and zero outgoing flow. Consequently \(u\in R\).

For \(u\ne v\), a simple directed path from \(v\) to \(u\), together with the marked arc, forms a directed cycle containing that arc. For \(u=v\), the marked arc itself is a cycle.

Hence every blocking transfer implies a directed cycle containing a marked arc.

3. A marked cycle yields a blocking transfer

Conversely, suppose a marked arc \(u\to v\) has both endpoints in the same strongly connected component of \(G\).

If \(u\ne v\), choose a simple directed path from \(v\) to \(u\). Together with the marked arc, it forms a directed cycle \(C\). If \(u=v\), take the marked self-loop as \(C\). Let \(k\) be the number of arcs in \(C\); then \(1\leq k\leq m\).

Every selected arc has a label \((t,r,h)\) with positive capacity \(y_{t,r}\). Define

\(\displaystyle B=\min\{y_{t,r}:(t,r,h)\text{ labels an arc of }C\}>0, \qquad \varepsilon=\frac{B}{k}>0.\)

Initialize every entry of \(z\) to zero, and for each selected arc labeled \((t,r,h)\), add \(\varepsilon\) to \(z_{t,r,h}\).

We verify all blocking conditions.

  • Nonnegativity and allowed transfers. Every entry is nonnegative. Every selected label satisfies \(h=r\) or \(h\succ_t r\), by construction of \(G\).
  • Participation bounds. For a fixed pair \((t,r)\), let \(n_{t,r}\) count its occurrences among the selected arc labels. If it occurs, then \(n_{t,r}\leq k\) and \(B\leq y_{t,r}\). Therefore

\(\displaystyle \sum_h z_{t,r,h} =n_{t,r}\varepsilon \leq k\varepsilon =B \leq y_{t,r}.\)

If it does not occur, the left side is zero.

  • Endowment balance. Giving every arc of a directed cycle the same flow \(\varepsilon\) yields equal incoming and outgoing flow at every vertex. Under the arc interpretation established above, this is exactly the required endowment-balance equation.
  • Strict improvement. The selected marked arc contributes \(\varepsilon>0\) to the strict-improvement sum.

Thus \(z\) is a blocking transfer. This proves the equivalence:

\(y\text{ is not core-stable} \quad\Longleftrightarrow\quad \text{some marked arc has both endpoints in the same strongly connected component of }G.\)

4. Algorithm and running time

The algorithm is:

  • Construct \(G\), recording which arcs are marked.
  • Compute its strongly connected components.
  • If any marked arc has both endpoints in the same component, return “not core-stable”; otherwise return “core-stable.”

Only positivity of allocation entries is used; their numerical magnitudes do not affect the answer. Reading their binary encodings costs \(O(L)\), graph construction costs \(O(\tau m^2)\), and strongly connected components and the final scan cost \(O(m+\tau m^2)\).

Since \(m,\tau\geq1\), the total is \(O(L+\tau m^2)\) word-RAM time. Charging bit costs for graph indices gives the conservative bound \(O((L+\tau m^2)\log(2+L+\tau m^2))\). Because the classes and types are explicitly supplied, this is polynomial in the input length.

The argument accommodates incomplete strict partial orders without imposing any condition on incomparability, and it does not require the finite-agent TTC characterization.
