Theorem 10.4 — class: algorithmic

The continuous mirror question, as graded

Input a finite set of complete ordered additive valuation types \(\Theta\), rational masses \(\mu_\theta\) with \(\sum_{\theta\in\Theta}\mu_\theta=1\), rational per-capita supplies \(q\in\mathbb{Q}_{\ge0}^m\), and \(\varepsilon\in(0,1/2]\). For an integral bundle \(b\in\mathbb{Z}_{\ge0}^m\), define \(\mathrm{MMS}^{\infty}_\theta(q)=\sup\{z:\exists\pi_b\ge0,\ \sum_b\pi_b=1,\ \sum_b\pi_b b=q,\ \pi_b>0\Rightarrow v_\theta(b)\ge z\}\). Compute a finite-support family \(\lambda_{\theta,b}\ge0\) satisfying \(\sum_b\lambda_{\theta,b}=\mu_\theta\) and \(\sum_{\theta,b}\lambda_{\theta,b}b_g=q_g\) for every good \(g\), such that every \(\theta\) with \(\mu_\theta>0\) receives only bundles with \(v_\theta(b)\ge(\frac79-\varepsilon)\mathrm{MMS}^{\infty}_\theta(q)\), in time polynomial in \(|\Theta|\), \(m\), the input encoding length, and \(1/\varepsilon\).

Packaged proof task (what the prover saw — nothing else)

A society is specified by its support: a list \(\Theta\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_\theta\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) good kinds. Each type specifies nonnegative rational additive values in a common weak order \(v_\theta(1)\ge\cdots\ge v_\theta(m)\), with ties allowed and no valuation normalization. Bundles are \(b\in\mathbb Z_{\ge0}^m\), allowing multiple copies of each kind, and \(v_\theta(b)=\sum_g v_\theta(g)b_g\).
The remaining inputs are rational per-capita supplies \(q\in\mathbb Q_{\ge0}^m\) and rational accuracy \(\varepsilon\in(0,1/2]\). Let \(L\) be the total binary input length.
Define \(\mathrm{MMS}^{\infty}_\theta(q)=\sup\{z\ge0:\exists(\pi_b)_{b\in\mathbb Z_{\ge0}^m},\ \pi_b\ge0,\ \sum_b\pi_b=1,\ \sum_b\pi_b b=q,\ \pi_b>0\Rightarrow v_\theta(b)\ge z\}\); the distribution may have countably infinite support, with finite coordinate expectations.
An allocation is an explicitly listed finite family of bundles and nonnegative binary-rational masses \(\lambda_{\theta,b}\), satisfying \(\sum_b\lambda_{\theta,b}=\mu_\theta\) and \(\sum_{\theta,b}\lambda_{\theta,b}b_g=q_g\) for every kind \(g\). Its guarantee is \(\lambda_{\theta,b}>0\Rightarrow v_\theta(b)\ge(\frac79-\varepsilon)\mathrm{MMS}^{\infty}_\theta(q)\).

Does an algorithm compute an allocation with this guarantee for every such input in time \(\operatorname{poly}(m,\tau,L,1/\varepsilon)\), or is this approximation guarantee impossible or computationally intractable with that running time?

For finite agents and individually listed indivisible goods with ordered nonnegative additive valuations, a \((\frac79-\varepsilon)\)-MMS allocation can be computed in \((1/\varepsilon)\operatorname{poly}(n,m)\) time. [Huang and Zhou](https://arxiv.org/abs/2511.13056)

Result and encoding convention

For rational masses encoded by binary numerators and denominators, the answer is yes. In fact, an algorithm computes a finite allocation with guarantee \((1-\varepsilon)\mathrm{MMS}^{\infty}_\theta(q)\) in time \(\operatorname{poly}(m,\tau,L,1/\varepsilon)\). The common ordering assumption is unnecessary.

If “binary-rational” instead means *strictly dyadic*, the literal specification is impossible: with \(m=\tau=1\), \(\mu_1=1\), and \(q_1=1/3\), a finite sum of integer bundle counts multiplied by dyadic masses cannot equal \(1/3\). Below, I settle the substantive interpretation using binary-encoded rational numbers.

1. Why types can be treated independently

Suppose that, for each type \(\theta\), we construct a finite rational probability distribution \(p_{\theta,b}\) satisfying

\(\displaystyle \sum_b p_{\theta,b}=1,\qquad \sum_b p_{\theta,b}b=q.\)

Define \(\lambda_{\theta,b}=\mu_\theta p_{\theta,b}\). Then

\(\displaystyle \sum_b\lambda_{\theta,b}=\mu_\theta,\qquad \sum_{\theta,b}\lambda_{\theta,b}b =\sum_\theta\mu_\theta q=q.\)

Thus each type may independently receive a distribution whose expectation is the entire per-capita supply vector. Mixing these distributions preserves the required aggregate supply.

It therefore suffices to solve the following single-type problem:

Given nonnegative rational values \(v_g\), rational supply \(q\), and accuracy \(\eta\in(0,1/2]\), compute a finite rational distribution of expectation \(q\), every supported bundle having value at least \((1-\eta)M\), where \(M=\mathrm{MMS}^{\infty}(q)\).

The finite-agent [Huang–Zhou theorem](https://arxiv.org/abs/2511.13056) is not needed for this construction.

2. Preliminary facts about the benchmark

Fix one type. Write \(v(b)=\sum_gv_gb_g\) and

\(\displaystyle V=\sum_gv_gq_g,\qquad G=\{g:q_g>0,\ v_g>0\},\qquad S=\sum_{g\in G}q_g.\)

For every feasible threshold \(z\), taking expectations gives \(z\le V\). Hence \(M\le V<\infty\).

Attainment

Choose a positive integer \(D\) such that every \(Dv_g\) is integral. Every bundle value belongs to \(D^{-1}\mathbb Z_{\ge0}\).

If a distribution witnesses threshold \(z\), it also witnesses threshold \(\lceil Dz\rceil/D\). All such rounded thresholds lie in the finite set

\(\displaystyle \{k/D:k\in\mathbb Z_{\ge0},\ k/D\le V\}.\)

Threshold zero is feasible: independently rounding each coordinate of \(q\) to its floor or ceiling gives a finite distribution with expectation \(q\). Consequently, the feasible lattice thresholds have a maximum. This maximum equals \(M\), so the supremum defining \(M\) is attained.

Detecting the zero case and bounding a positive benchmark

If \(S<1\), then \(M=0\). Indeed, coordinates with \(q_g=0\) vanish almost surely in any distribution of expectation \(q\). Every positive-value bundle therefore contains at least one item from \(G\). A positive feasible threshold would imply

\(\displaystyle S=\mathbb E\!\left[\sum_{g\in G}b_g\right]\ge1,\)

a contradiction.

If \(S\ge1\), set \(\ell=\min_{g\in G}v_g>0\). Assign the singleton bundle \(e_g\) probability \(q_g/S\). This distribution has expectation coordinatewise at most \(q\), and every supported bundle has value at least \(\ell\). The next lemma allows the unused supply to be added. Thus

\(\displaystyle \ell\le M\le V.\)

3. Adding unused supply exactly

Lemma. Let a finite rational distribution have expectation \(r\le q\) coordinatewise. It can be transformed into a finite rational distribution of expectation exactly \(q\), while preserving every lower bound on supported bundle values. The transformation adds at most \(m\) support entries and has polynomial bit complexity.

Proof. Choose a supported bundle \(b\) with probability \(p>0\), and put

\(\displaystyle u=(q-r)/p,\qquad k_g=\lfloor u_g\rfloor,\qquad f_g=u_g-k_g.\)

For a uniformly distributed \(t\in[0,1)\), define

\(\displaystyle A_g(t)=k_g+\mathbf 1_{\{t<f_g\}}.\)

The vector \(A(t)\) takes at most \(m+1\) distinct integer values: partition the interval at the distinct fractional parts \(f_g\). Each interval has rational length, giving an explicitly listed rational distribution, and

\(\displaystyle \mathbb E[A_g]=k_g+f_g=u_g.\)

Replace the atom \(b\) by the bundles \(b+A(t)\), multiplying their probabilities by \(p\). The new expectation is

\(\displaystyle r+p\mathbb E[A]=q.\)

All added coordinates are nonnegative, so nonnegative valuations preserve the value guarantee.

The required arithmetic consists of rational operations, floors, and sorting at most \(m\) rational numbers. The resulting counts and probabilities have polynomial encoding length in the original distribution’s encoding length. \(\square\)

In particular, this constructs a suitable distribution immediately when \(M=0\), by starting with probability one on the empty bundle.

4. Bounded configurations suffice

Fix a positive rational threshold \(z\). For \(g\in G\), define

\(\displaystyle U_g=\left\lceil z/v_g\right\rceil.\)

Let \(C(z)\) be the finite set of integer bundles satisfying

\(\displaystyle c_g=0\ \text{for }g\notin G,\qquad 0\le c_g\le U_g\ \text{for }g\in G,\qquad v(c)\ge z.\)

Lemma. Threshold \(z\) is feasible in the definition of \(M\) if and only if there is a probability distribution on \(C(z)\) whose expectation is coordinatewise at most \(q\).

Proof. For the forward direction, take a witnessing distribution, possibly with countably infinite support. Its supported bundles have zero coordinates wherever \(q_g=0\). Remove all zero-value items from each bundle, then repeatedly remove an item whenever the remaining value is still at least \(z\). This produces an inclusion-minimal subbundle \(c\le b\) with value at least \(z\).

If \(c_g>U_g\), then after deleting one item of kind \(g\), the remaining copies of that kind alone have value at least \(U_gv_g\ge z\). This contradicts minimality. Therefore \(c\in C(z)\).

Pushing the original distribution through this map gives a distribution on the finite set \(C(z)\), with expectation at most \(q\).

Conversely, apply the unused-supply lemma to a distribution on \(C(z)\). This gives expectation exactly \(q\) without decreasing any bundle’s value. \(\square\)

The remaining difficulty is that explicitly enumerating \(C(z)\) could take exponential time. We avoid that enumeration by rounding utilities inside a compact flow formulation.

5. A polynomial threshold procedure

Fix \(\delta\in(0,1/4]\). We construct a procedure with these two properties:

  • Completeness: if \(z\le M\), the procedure succeeds.
  • Soundness: whenever it succeeds, it returns a finite rational distribution of expectation \(q\), every supported bundle having value at least \((1-\delta)z\).

5.1 Binary grouping of multiplicities

For each \(g\in G\), represent the integers from zero through \(U_g\) using selectable groups of sizes

\(\displaystyle 1,2,4,\ldots,\text{a final remainder},\)

whose sizes sum to \(U_g\). More explicitly, start with remaining quantity \(U_g\); successively take the smaller of the remaining quantity and \(1,2,4,\ldots\).

Every integer from zero through \(U_g\) is a subset sum of these groups. To verify this, suppose the previous groups represent every integer from zero through \(A\). A next group of size \(d\le A+1\) extends the represented interval through \(A+d\). Every group in the construction satisfies this inequality.

List all groups as \(j=1,\ldots,K\). Group \(j\) consists of \(d_j\) copies of kind \(g(j)\), and has value

\(\displaystyle a_j=d_jv_{g(j)}.\)

Every capped bundle is represented by selecting some groups. Moreover,

\(\displaystyle K=O\!\left(\sum_{g\in G}\log(U_g+1)\right).\)

5.2 Rounded scores

Set

\(\displaystyle h=\frac{\delta z}{K},\qquad t_j=\left\lfloor\frac{\min(a_j,z)}h\right\rfloor,\qquad T=\left\lceil\frac K\delta\right\rceil-K.\)

Here \(T\) is a positive integer.

A selection whose actual value is at least \(z\) has rounded score at least \(T\). Indeed, for its selected index set \(J\),

\(\displaystyle \sum_{j\in J}\min(a_j,z)\ge z.\)

This follows because either one selected group has value at least \(z\), or truncation changes none of their values. Therefore

\(\displaystyle \sum_{j\in J}t_j \ge \frac zh-|J| \ge \frac K\delta-K.\)

The left side is integral, so it is at least \(T\).

Conversely, any selection with score at least \(T\) satisfies

\(\displaystyle \sum_{j\in J}a_j \ge h\sum_{j\in J}t_j \ge hT \ge(1-\delta)z.\)

Thus rounding includes every strong configuration and accepts only configurations meeting the weaker threshold.

5.3 The flow linear program

Construct a layered directed acyclic graph with vertices

\(\displaystyle (j,s),\qquad 0\le j\le K,\quad 0\le s\le T.\)

For group \(j\), add the following arcs from layer \(j-1\) to layer \(j\):

  • A skip arc from \((j-1,s)\) to \((j,s)\).
  • A take arc from \((j-1,s)\) to \((j,\min(T,s+t_j))\).

A source-to-sink path from \((0,0)\) to \((K,T)\) represents precisely a group selection whose total score is at least \(T\).

Introduce nonnegative arc-flow variables \(f_e\). Require one unit of flow from the source to the sink, with conservation at every other vertex. For each kind \(g\), impose

\(\displaystyle \sum_{\substack{e\text{ is a take arc}\\g(j(e))=g}}d_{j(e)}f_e\le q_g.\)

Kinds outside \(G\) have zero consumption in this program.

The graph has \(O(KT)=O(K^2/\delta)\) vertices and arcs. This is a finite rational linear feasibility problem. We use the standard polynomial-time rational linear-programming theorem: feasibility can be decided, and a rational feasible point of polynomial encoding length returned, in time polynomial in the explicit system’s encoding length. This is the classical [polynomial solvability of linear programming](https://www.mathnet.ru/eng/dan42319). Equalities can be replaced by pairs of inequalities; all flow variables are automatically bounded between zero and one.

Completeness

If \(z\le M\), attainment and the bounded-configuration lemma give a distribution on capped bundles of value at least \(z\), with expectation at most \(q\).

Choose a binary-group representation for each such bundle. The rounding calculation shows that its path reaches the sink. Mixing these paths gives a feasible unit flow satisfying every resource constraint. Thus the linear program succeeds.

Soundness and an explicit output

Any feasible rational flow decomposes into source-to-sink paths with rational weights summing to one. A constructive decomposition repeatedly follows positive-flow arcs to the sink and subtracts the minimum flow on that path. Each iteration eliminates an arc, so there are at most as many paths as arcs.

Each path yields an integer bundle worth at least \((1-\delta)z\). The resource constraints give expectation at most \(q\). Apply the unused-supply lemma to obtain expectation exactly \(q\).

This establishes both required properties of the threshold procedure.

6. Choosing a threshold without computing \(M\)

Given accuracy \(\eta\in(0,1/2]\), take \(\delta=\eta/2\).

Handle \(S<1\) as the zero case. Otherwise, test every threshold in the finite geometric sequence

\(\displaystyle z_j=\ell(1+\delta)^j,\qquad z_j\le V.\)

Keep the successful distribution with the largest tested threshold \(z_*\).

At least one test succeeds because \(\ell\le M\). Let \(z_k\) be the largest grid threshold satisfying \(z_k\le M\). Completeness ensures that this test succeeds, so \(z_*\ge z_k\). The next geometric threshold exceeds \(M\), whether or not it remains within the tested range. Hence

\(\displaystyle z_*\ge z_k\ge\frac{M}{1+\delta}.\)

Soundness gives every output bundle value at least

\(\displaystyle (1-\delta)z_* \ge\frac{1-\delta}{1+\delta}M =\left(1-\frac{\eta}{1+\eta/2}\right)M \ge(1-\eta)M.\)

No monotonicity of the rounded procedure is assumed: all grid thresholds are tested, and completeness alone guarantees a sufficiently large successful one.

7. Running time and output length

The following bounds establish polynomial complexity even when supplies and bundle multiplicities are numerically exponential.

Every positive input valuation is at least \(2^{-L}\), and every input valuation and supply is at most \(2^L\). Consequently,

\(\displaystyle V\le m2^{2L},\qquad \ell\ge2^{-L},\qquad \log(V/\ell)=O(L+\log m).\)

The number of grid thresholds is therefore

\(\displaystyle O((L+\log m)/\delta).\)

Successive rational multiplication generates them exactly. Their binary encoding lengths are polynomial in \(L,m,1/\eta\).

For every tested threshold,

\(\displaystyle U_g=\lceil z/v_g\rceil\le\lceil V/v_g\rceil\le m2^{3L}+1.\)

Thus

\(\displaystyle K=O(m(L+\log m)),\qquad T=O(K/\delta).\)

Each flow program has polynomially many variables and constraints, and every coefficient has polynomial binary encoding length. Exact rational linear programming therefore takes polynomial time.

Path decomposition uses polynomially many rational operations and returns polynomially many bundles. Its probabilities retain polynomial encoding length: all subtractions can be performed using the product of the original flow denominators as a common denominator, whose bit length is polynomial. Adding unused supply also preserves polynomial encoding length and support size.

Finally, execute this construction independently for all \(\tau\) types and multiply each probability by its input mass \(\mu_\theta\). This requires total time and output length

\(\displaystyle \operatorname{poly}(m,\tau,L,1/\eta).\)

8. Conclusion

Set \(\eta=\varepsilon\). The resulting allocation satisfies the exact type-mass and supply equations, and every positively allocated bundle satisfies

\(\displaystyle v_\theta(b)\ge(1-\varepsilon)\mathrm{MMS}^{\infty}_\theta(q) \ge\left(\frac79-\varepsilon\right)\mathrm{MMS}^{\infty}_\theta(q).\)

This completely settles the requested approximation question for binary-encoded rational masses. Neither valuation normalization nor a common weak order is required.
