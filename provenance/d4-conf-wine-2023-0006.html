The continuous mirror question, as graded

Given projects \(P\) with costs \(c_j\), PBPI groups and interaction-valid votes, budget \(B\), and a rational distribution \(\mu\) over complete vote types \(\theta=(f,s,\eta)\), output an integral bundle \(Q\subseteq P\) with \(\sum_{j\in Q}c_j\le B\) maximizing \(U_\mu(Q)=\sum_\theta\mu_\theta u_\theta(Q)\).

Packaged proof task (what the prover saw — nothing else)

Let \(P\) contain \(m\ge 1\) projects with positive integer costs \(c_j\), and let \(B\) be a positive integer budget. A supplied partition \(z_1,\ldots,z_r\) consists of nonempty groups, each marked contradictory or non-contradictory.
A complete vote type \(\theta=(f,s,\eta)\) specifies, for each group, \(f_g\in\mathbb Z_{\ge0}\), \(s_g\subseteq z_g\), and \(\eta_g\in\{0,1\}\), with \(\sum_g f_g\le B\). In contradictory groups require \(|s_g|\le1\) and \(\eta_g=0\); empty approval sets are allowed. No constraint \(f_g\le\sum_{j\in s_g}c_j\) is imposed.
A society is given by its support: the list of the \(\tau\) distinct complete vote types with positive mass, each mass \(\mu_\theta\) a binary rational, with \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
For an integral bundle \(Q\subseteq P\), define \(a_{\theta g}(Q)=\sum_{j\in Q\cap s_g}c_j\) and \(u_\theta(Q)=\sum_{g=1}^r\bigl[(1-\eta_g)+\eta_g\mathbf1\{s_g\subseteq Q\}\bigr]\min\{f_g,a_{\theta g}(Q)\}\).
Feasible bundles satisfy \(\sum_{j\in Q}c_j\le B\) and \(|Q\cap z_g|\le1\) for every contradictory group. There are no additional funding constraints. The optimization problem outputs any feasible bundle maximizing \(U_\mu(Q)=\sum_\theta\mu_\theta u_\theta(Q)\); ties may be resolved arbitrarily.
Let \(L\) be the total binary input length. State running times in \(m,\tau,L\) and any additional parameters used.

Is this integral-bundle welfare maximization problem for a society given by rational masses solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For explicitly listed voters, welfare maximization is NP-hard even with unit costs, one non-contradictory group, and only substitution votes ([Goyal–Sarmasarkar–Goel](https://arxiv.org/pdf/2305.11296v2)).
For weighted distinct votes with unit project costs, an FPT algorithm parameterized by the number of distinct votes is known; this covers a restricted mass setting, rather than unrestricted costs and support size ([Goyal–Sarmasarkar–Goel](https://arxiv.org/pdf/2305.11296v2)).

Conclusion

The optimization problem is NP-hard, even with support size \(\tau=1\), mass \(1\), one non-contradictory group, and only a substitution vote. Its rational-threshold decision version is NP-complete.

Consequently, an exact algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\). Arbitrary tie-breaking does not affect this conclusion.

1. A reduction with one supported vote

We reduce from the standard NP-complete SUBSET SUM problem: given positive integers \(a_1,\ldots,a_m\) and a positive integer target \(T\), all encoded in binary, determine whether some subset has sum exactly \(T\).

Construct the welfare instance as follows:

  • There are \(m\) projects, with costs \(c_j=a_j\).
  • The budget is \(B=T\).
  • The partition consists of the single non-contradictory group \(z_1=P\).
  • The support consists of one complete vote \(\theta\), with \(f_1=T\), \(s_1=P\), and \(\eta_1=0\).
  • Its mass is \(\mu_\theta=1\).

Every input requirement holds. Project costs and budget are positive integers; the group is nonempty; the fund allocation satisfies \(f_1=B\); and the unique positive rational mass sums to \(1\).

For any feasible bundle \(Q\), the budget constraint gives \(\sum_{j\in Q}a_j\le T\). Substituting the constructed vote into the utility definition therefore yields

\[ U_\mu(Q)=u_\theta(Q) =\min\left\{T,\sum_{j\in Q}a_j\right\} =\sum_{j\in Q}a_j. \]

Thus

\[ \max_{Q\text{ feasible}}U_\mu(Q)=T \quad\Longleftrightarrow\quad \exists Q\subseteq P:\ \sum_{j\in Q}a_j=T. \]

The forward implication holds because a feasible maximizing bundle with welfare \(T\) has total cost exactly \(T\). For the reverse implication, a subset summing to \(T\) is feasible and attains welfare \(T\), while every feasible bundle has welfare at most \(T\).

Hence, given any welfare-maximizing output bundle, computing its total cost and comparing it with \(T\) decides SUBSET SUM.

If the source input has binary length \(H\), the construction has \(\tau=1\) and length \(L=O(H+m\log(m+1))\), allowing explicit project identifiers. It can be written in time \(O(H+m\log(m+1))\). The final cost comparison takes \(O(mL)\) bit operations. A polynomial-time optimizer would therefore give a polynomial-time algorithm for SUBSET SUM. This proves NP-hardness.

2. Unit-cost hardness also survives support compression

The supplied unit-cost hardness result applies to explicitly listed voters with one non-contradictory group and substitution votes; see [Goyal–Sarmasarkar–Goel, Observation 5 and Appendix A.1](https://arxiv.org/pdf/2305.11296v2).

Here is the precise transfer to rational support. Suppose such an instance lists \(n\) voters. For each distinct complete vote type \(\theta\), let \(n_\theta\) be its multiplicity and assign mass

\[ \mu_\theta=\frac{n_\theta}{n}. \]

These masses are positive, sum to \(1\), and have binary numerator and denominator encodings of length \(O(\log(n+1))\). The resulting support has \(\tau\le n\).

For every feasible bundle,

\[ U_\mu(Q) =\sum_\theta\frac{n_\theta}{n}u_\theta(Q) =\frac1n\sum_{i=1}^{n}u_i(Q). \]

Multiplication by the positive constant \(1/n\) preserves all welfare comparisons and ties. The optimizing bundles are therefore exactly the same.

For source length \(H\) and maximum complete-vote encoding length \(h\), sorting vote encodings and counting multiplicities takes \(O(H+n\log(n+1)h)\) bit operations. The output length is \(O(H+n\log(n+1))\), hence polynomial in the explicitly listed input length.

Thus the support formulation remains NP-hard even with unit costs when \(\tau\) is unrestricted. Meanwhile, Section 1 shows why the supplied FPT result for unit costs cannot extend to arbitrary binary costs with parameter \(\tau\) alone: an algorithm taking \(F(\tau)\operatorname{poly}(m,L)\) time would solve the constructed \(\tau=1\) instances in polynomial time.

3. Exact verification and running times

Define the decision version by adding a binary rational threshold \(K\): does some feasible bundle satisfy \(U_\mu(Q)\ge K\)? Let \(L'\) be the input length including this threshold.

A certificate is the \(m\)-bit incidence vector of \(Q\). Feasibility is checked by summing costs and checking each contradictory group. Utilities are computed directly from the supplied approval sets and allocations.

For exact rational arithmetic, write \(\mu_\theta=p_\theta/d_\theta\) and set

\[ D=\prod_\theta d_\theta, \qquad w_\theta=p_\theta(D/d_\theta). \]

The integers \(D\) and \(w_\theta\) have \(O(L)\) bits. Also, \(u_\theta(Q)\) is a nonnegative integer satisfying

\[ u_\theta(Q)\le\sum_g f_g\le B. \]

Since \(\sum_\theta w_\theta=D\), the integer numerator

\[ W(Q)=\sum_\theta w_\theta u_\theta(Q) \]

satisfies \(0\le W(Q)\le BD\), and therefore has \(O(L)\) bits. Welfare equals \(W(Q)/D\); comparison with \(K\) uses exact cross multiplication.

Using schoolbook arithmetic, a conservative verification bound is \(O(m\tau(L')^2)\) bit operations. The decision problem is consequently in \(\mathrm{NP}\), and Section 1 proves it NP-hard already for threshold \(K=B\). It is therefore NP-complete.

For completeness, exhaustive enumeration gives an exact optimizer in \(O(2^m m\tau L^2)\) bit operations.
