The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), a supplied set \(D\subseteq C\), approval types \(A_1,\ldots,A_\tau\subseteq C\) with rational masses \(\mu_i\ge0\) summing to \(1\), and a threshold \(R\), where deleting \(D\) makes every \(A_i\cap(C\setminus D)\) an interval on one common axis, decide whether some \(W\subseteq C\) with \(|W|=k\) satisfies \(\sum_i\mu_i\mathbf{1}[A_i\cap W=\varnothing]\le R\).

Packaged proof task (what the prover saw — nothing else)

Definitions. Mass-Approval-CC has finite candidate set \(C\), \(k\), \(D\subseteq C\), rational \(R\), and approval types \(A_1,\ldots,A_\tau\subseteq C\) with binary-encoded masses \(\mu_i\in\mathbb{Q}_{\geq0}\) and \(\sum_i\mu_i=1\). It is promised that one order of \(C\setminus D\) makes every \(A_i\cap(C\setminus D)\) a possibly empty contiguous block.
A committee is \(W\subseteq C\) with \(|W|=k\); its unrepresented mass is \(\sum_i\mu_i\mathbf{1}[A_i\cap W=\varnothing]\). The decision question asks whether this is at most \(R\).

Target. Is Mass-Approval-CC in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? If it is \(\mathrm{NP}\)-hard, is it fixed-parameter tractable for \(d=|D|\)?

Nearest known results. Discrete Approval-CC is \(\mathrm{NP}\)-complete, even with approval ballots, and is \(\mathrm{W}[2]\)-hard parameterized by \(k\) even when \(R=0\).
With a supplied candidate-deletion set \(D\), discrete Chamberlin-Courant is solvable in \(O^*(2^{|D|})\) time; under SETH, this base cannot be improved below \(2\), even for approval ballots.

Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Classification theorem

Mass-Approval-CC is \(\mathrm{NP}\)-complete. It is fixed-parameter tractable parameterized by \(d=|D|\), with running time \(O^*(2^d)\).

The algorithm works directly with binary-encoded rational masses; it does not expand masses into individual voters.

Membership in \(\mathrm{NP}\)

A certificate is a committee \(W\subseteq C\) of size \(k\). For every type \(i\), one can test whether \(A_i\cap W=\varnothing\) and then sum the corresponding rational masses.

These rational comparisons can be performed in polynomial bit complexity. For example, multiplying all masses and \(R\) by the product of their denominators produces integers whose bit lengths are at most the total input length. Hence the unrepresented mass can be compared with \(R\) in polynomial time.

Therefore Mass-Approval-CC belongs to \(\mathrm{NP}\).

\(\mathrm{NP}\)-hardness

We reduce from Set Cover. Let \(U\) be a nonempty universe of size \(q\), let \(S_1,\ldots,S_m\subseteq U\), and let \(k\leq m\). The question is whether at most \(k\) of these sets cover \(U\).

Construct candidates \(C=\{c_1,\ldots,c_m\}\), put \(D=C\), and retain the same committee size \(k\). For every element \(u\in U\), define the approval set

\(A_u=\{c_j:u\in S_j\}\)

and give it mass \(1/q\). If identical approval sets are required to be represented by one type, group elements having the same \(A_u\); a group of \(h\) elements receives mass \(h/q\). Set \(R=0\).

Because \(C\setminus D=\varnothing\), every \(A_i\cap(C\setminus D)\) is empty and hence is a permitted contiguous block. Thus the promise is satisfied.

For a committee \(W\), the type corresponding to \(u\) is represented exactly when \(W\) contains some \(c_j\) with \(u\in S_j\). Consequently, the unrepresented mass is zero exactly when the sets corresponding to \(W\) cover \(U\).

A cover using fewer than \(k\) sets can be padded to exactly \(k\) candidates because \(k\leq m\); padding cannot destroy coverage. Hence the Set Cover instance is positive if and only if the constructed Mass-Approval-CC instance is positive.

The reduction is polynomial and uses only \(R=0\) and masses with polynomially many bits. Thus Mass-Approval-CC is \(\mathrm{NP}\)-hard, and therefore \(\mathrm{NP}\)-complete.

Recovering the interval order

Let \(O=C\setminus D\) and \(n=|O|\). Form the binary matrix whose columns are the candidates of \(O\) and whose \(i\)-th row is the characteristic vector of \(A_i\cap O\).

The standard consecutive-ones recognition theorem states that one can, in polynomial time, either find a column order in which the ones of every row are consecutive or determine that no such order exists. The promise guarantees that the former occurs.

Fix such an order and identify \(O\) with positions \(1,\ldots,n\). Every nonempty \(A_i\cap O\) is then an interval \([\ell_i,r_i]\).

Weighted interval-stabbing lemma

Consider weighted intervals \([\ell_i,r_i]\subseteq\{1,\ldots,n\}\). For an integer \(p\), one can find in polynomial time \(p\) distinct positions maximizing the total weight of intervals containing at least one selected position.

For \(0\leq a<b\leq n\), define

\(G(a,b)=\sum_{i:\,a<\ell_i\leq b\leq r_i}\mu_i\).

For \(j\geq1\) and \(b\in\{1,\ldots,n\}\), let \(M(j,b)\) be the maximum covered weight obtainable with \(j\) selected positions whose last position is \(b\). Set

\(M(1,b)=G(0,b)\),

and, for \(j\geq2\),

\(M(j,b)=\max_{j-1\leq a<b}\bigl(M(j-1,a)+G(a,b)\bigr)\).

To verify the recurrence, consider selected positions \(x_1<\cdots<x_p\) and put \(x_0=0\). An interval is first covered at \(x_j\) exactly when

\(x_{j-1}<\ell_i\leq x_j\leq r_i\).

Indeed, if \(\ell_i\leq x_{j-1}\), then the interval also contains \(x_{j-1}\), because \(r_i\geq x_j>x_{j-1}\). Conversely, if \(\ell_i>x_{j-1}\), every earlier selected position lies strictly before the interval. Thus every covered interval is counted exactly once, namely in \(G(x_{j-1},x_j)\).

It follows that the optimum for exactly \(p\) positions is

\(\max_{p\leq b\leq n}M(p,b)\).

For \(p=0\), the optimum is zero. Computing all gains naively takes \(O(\tau n^2)\) arithmetic operations and the dynamic program takes \(O(pn^2)\) operations, hence polynomial time.

Fixed-parameter algorithm

Enumerate every subset \(X\subseteq D\). Interpret \(X\) as the exact intersection of the committee with \(D\). Only subsets satisfying

\(|X|\leq k\quad\text{and}\quad k-|X|\leq n\)

need be considered. Put \(p=k-|X|\).

Types already represented by \(X\) contribute the fixed mass

\(B(X)=\sum_{i:\,A_i\cap X\neq\varnothing}\mu_i\).

For every remaining type, its only possible representation comes from its interval \(A_i\cap O\). Apply the weighted interval-stabbing dynamic program to these remaining nonempty intervals, using exactly \(p\) positions. Let its optimum be \(F(X,p)\). The maximum represented mass among committees whose intersection with \(D\) is exactly \(X\) is then

\(B(X)+F(X,p)\).

This identity follows because types represented by \(X\) are counted only in \(B(X)\), while every other represented type must be hit by a selected position in \(O\). Conversely, any \(p\)-position solution produced by the interval dynamic program, together with \(X\), forms a committee of exactly \(k\) candidates.

Therefore the overall maximum represented mass is

\(\max_X\bigl(B(X)+F(X,k-|X|)\bigr)\),

where the maximum ranges over the feasible subsets \(X\subseteq D\). Since the masses sum to \(1\), the instance is accepted exactly when this maximum is at least \(1-R\).

There are at most \(2^d\) subsets \(X\), and all work for a fixed \(X\) is polynomial in the binary input length. The running time is therefore \(O^*(2^d)\), proving fixed-parameter tractability for \(d\).

Conditional optimality of the base

The stated SETH lower bound for discrete Approval-CC transfers to this mass formulation. Given \(N\) explicit voters, group identical ballots and assign a type occurring \(h\) times mass \(h/N\); divide the discrete unrepresented-voter threshold by \(N\). This preserves \(C\), \(D\), \(d\), all committees, and their objective values up to the common factor \(1/N\).

Thus, under the supplied discrete lower bound and SETH, an \(O^*((2-\varepsilon)^d)\)-time algorithm for any fixed \(\varepsilon>0\) is impossible.

Verification report

Overall assessment

The prover correctly establishes the requested classification: Mass-Approval-CC is \(\mathrm{NP}\)-complete and admits an \(O^*(2^d)\)-time algorithm parameterized by \(d=|D|\). The reduction and dynamic program are substantively sound. There is one minor unhandled input edge case.

Step-by-step audit

Membership in \(\mathrm{NP}\)

The proposed certificate \(W\subseteq C\) has polynomial size. Testing \(A_i\cap W=\varnothing\) for every type and summing the corresponding rational masses is polynomial-time.

The denominator-product argument is valid: the bit length of the product is bounded by the sum of the denominator bit lengths, hence polynomial in the input length. The resulting integer additions and comparison with \(R\) also have polynomial bit complexity.

This part is correct.

\(\mathrm{NP}\)-hardness

The reduction from Set Cover is correct:

  • Candidates correspond to sets.
  • Types correspond to universe elements and approve precisely the candidates whose sets contain that element.
  • Equal mass \(1/q\), or grouped mass \(h/q\), gives total mass \(1\).
  • Setting \(D=C\) makes \(C\setminus D=\varnothing\), so the consecutive-ones promise holds vacuously.
  • Unrepresented mass is zero exactly when every universe element is covered.
  • Since \(k\leq m\), a cover of size below \(k\) can be padded to a committee of exactly \(k\) without losing coverage.

The construction and rational encodings have polynomial size. Thus the claimed \(\mathrm{NP}\)-hardness, including the restriction \(R=0\), follows.

Recovery of the interval order

The characteristic matrix has the consecutive-ones property for columns by the input promise. Standard polynomial-time consecutive-ones recognition therefore returns a suitable column order. Empty rows do not cause a problem.

This application is correct.

Weighted interval-stabbing dynamic program

The gain

\[ G(a,b)=\sum_{i:\,a<\ell_i\leq b\leq r_i}\mu_i \]

correctly counts intervals first hit at \(b\) when the preceding selected position is \(a\).

For selected positions \(x_1<\cdots<x_p\), an interval containing \(x_j\) but not an earlier selected point satisfies \(x_{j-1}<\ell_i\leq x_j\leq r_i\). The proof correctly uses interval convexity: if \(\ell_i\leq x_{j-1}<x_j\leq r_i\), then \(x_{j-1}\) would already hit the interval.

Consequently, the recurrence for \(M(j,b)\) counts every covered interval exactly once. The lower bound \(a\geq j-1\) ensures that \(j-1\) distinct earlier positions can exist. The stated arithmetic complexity is polynomial, and rational bit lengths remain polynomial.

This lemma is correct.

Fixed-parameter algorithm

Enumerating \(X=W\cap D\) is exhaustive. For a fixed feasible \(X\):

  • \(B(X)\) counts exactly the types represented by candidates in \(X\).
  • Removing those types prevents double counting.
  • Remaining types with nonempty outside intervals are handled exactly by interval stabbing.
  • Remaining types with empty outside intervals cannot be represented and may correctly be omitted.
  • Choosing exactly \(p=k-|X|\) outside candidates produces a committee of exactly \(k\) candidates.

Thus \(B(X)+F(X,p)\) is precisely the maximum represented mass for committees with intersection \(X\), and maximizing over all \(X\subseteq D\) is correct. Since represented and unrepresented masses sum to \(1\), comparison against \(1-R\) is also correct.

There are \(2^d\) choices of \(X\), with polynomial work per choice, establishing the claimed \(O^*(2^d)\) running time.

The only omitted case is \(k>|C|\). Then no committee exists and no subset \(X\) passes the feasibility tests, leaving the displayed maximum over an empty family undefined. The algorithm should explicitly reject this case. This is a routine edge-case repair and does not affect the substantive result.

Conditional lower bound

Grouping identical discrete ballots and assigning mass \(h/N\) preserves the objective after scaling by \(1/N\), preserves \(C\), \(D\), and \(d\), and has polynomial encoding size. Subject to the supplied discrete SETH lower bound applying to the same candidate-deletion promise, the claimed base-\(2\) lower bound transfers correctly.

Conclusion

The central classification and parameterized algorithm are correct. The write-up needs only an explicit convention or rejection rule for instances with \(k>|C|\).
