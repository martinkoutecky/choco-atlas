The continuous mirror question, as graded

Given a finite set of category rankings, rational type masses \(\mu_t\), and rational per-capita category supplies \(\kappa_h\), for each integer scale \(q\) clearing their denominators create \(q\mu_t\) named agents of type \(t\) and \(q\kappa_h\) unit-capacity slots of category \(h\), with slots in each category tied in every ranking. Let \(Z_q\) count the popular matchings under the paper’s pairwise-vote rule, identifying matchings that differ only by permutations of slots within a category. Compute or approximate to additive error \(\varepsilon\) the entropy density \(\mathcal H(\mu,\kappa)=\limsup_{q\to\infty}q^{-1}\log(1+Z_q)\), over admissible scales.

Packaged proof task (what the prover saw — nothing else)

There are \(m\) categories. A society is given by its support: the list of \(\tau\) types with positive mass, each mass encoded as a binary rational; \(\tau\) is the support size, not the number of possible rankings. Assume \(\sum_t\mu_t=1\). Each type specifies a weak order over a subset of categories; unlisted categories are unacceptable. Supplies \(\kappa_h\) are nonnegative binary rationals, with no constraint on their sum.
For every positive integer \(q\) making all \(q\mu_t\) and \(q\kappa_h\) integers, create \(q\mu_t\) distinct named agents of type \(t\) and \(q\kappa_h\) unit-capacity slots of category \(h\). All slots inherit their category's rank and are tied within that category.
A feasible matching assigns each agent at most one acceptable slot and each slot at most one agent; agents may remain unmatched. Each agent strictly prefers any acceptable assignment to being unmatched and otherwise compares category ranks, abstaining on ties. Slots do not vote. A matching is popular if no feasible matching receives strictly more agents' votes against it than it receives against that matching.
Let \(Z_q\) count popular matchings modulo permutations of slots within each category; agent names remain distinguished, including names of agents of the same type. Define \(\mathcal H(\mu,\kappa)=\limsup_{q\to\infty,\ q\text{ admissible}}q^{-1}\log(1+Z_q)\), using the natural logarithm. The input includes a binary rational \(0<\varepsilon<1\); \(L\) is the total input bit length.

Is approximating \(\mathcal H(\mu,\kappa)\) to additive error \(\varepsilon\) possible deterministically in time polynomial in \(m,\tau,L,1/\varepsilon\), or is this approximation problem NP-hard?

Discrete counting of popular matchings with ties is \(\#\mathrm P\)-hard, and indeed \(\#\mathrm P\)-complete ([Nasre](https://drops.dagstuhl.de/storage/00lipics/lipics-vol020-stacs2013/LIPIcs.STACS.2013.412/LIPIcs.STACS.2013.412.pdf)). An FPRAS is also claimed for discrete counting with ties ([Acharyya–Chakraborty–Jha](https://arxiv.org/pdf/1312.3552)); it counts individual slot assignments. No result settling the entropy problem defined here was located.

Result

The entropy admits a deterministic additive approximation in time polynomial in \(m,\tau,L,1/\varepsilon\).

The key is that popularity can be characterized by a rational polytope with at most \(\tau(m+1)\) variables, independently of the replication factor. The entropy is the maximum of a concave function over this polytope. Below, I prove this characterization and give an explicit approximation using rational linear programming.

1. A finite-instance characterization of popularity

We use the following established theorem for one-sided popular matchings with ties.

Give each agent \(a\) a private last-resort post \(\ell(a)\), ranked below every acceptable real post. Write \(f(a)\) for its first-ranked posts. Let \(G_1\) be the graph containing only first-ranked edges. Let \(E_1\) be the vertices reachable by even-length alternating paths from unmatched vertices of a maximum matching of \(G_1\). Define \(s(a)\) to be the agent’s most preferred posts belonging to \(E_1\).

Popularity characterization. An agent-complete matching \(M\) is popular if and only if:

  • \(M\cap E(G_1)\) is a maximum matching of \(G_1\).
  • Every agent \(a\) receives a post in \(f(a)\cup s(a)\).

This is Lemma 3.5 and Theorem 3.6 of [Abraham–Irving–Kavitha–Mehlhorn, *Popular Matchings*](https://people.mpi-inf.mpg.de/~mehlhorn/ftp/PopularMatchingsJournal.pdf).

The last-resort construction represents being unmatched exactly: complete an original matching by assigning every unmatched agent its private post. Votes between completed matchings agree with the original votes. Moreover, completing an incomplete competitor cannot decrease its vote margin against an agent-complete matching. Thus the characterization applies to the popularity notion in the question.

We will use an equivalent description of \(E_1\).

Lemma 1. In a bipartite graph, a vertex belongs to the even set defined above if and only if some maximum matching leaves it unmatched.

Proof. Fix a maximum matching \(M\). An even-length alternating path from an unmatched vertex to \(v\) can be toggled without changing matching size, producing a maximum matching that leaves \(v\) unmatched. A path of length zero covers vertices already unmatched.

Conversely, suppose a maximum matching \(N\) leaves \(v\) unmatched. If \(M\) also leaves it unmatched, the claim is immediate. Otherwise, the component of \(M\mathbin{\triangle}N\) containing \(v\) is an alternating path. Its two matchings must contribute equally many edges: unequal contributions would give an augmenting path for one of the maximum matchings. Consequently, this path has even length, and its other endpoint is unmatched in \(M\). Reversing the path proves that \(v\) belongs to the even set. \(\square\)

2. Computing the fallback categories without replication

Discard categories with zero supply from preference lists: they have no slots at any admissible replication factor.

For each type \(t\), let \(A_t\) be its acceptable categories of positive supply. If \(A_t\) is empty, every agent of that type is necessarily unmatched and abstains in every comparison. Such agents can therefore be omitted when applying the finite-instance theorem.

For \(A_t\ne\varnothing\), let \(F_t\) be the highest-ranked categories in \(A_t\). For \(A_t=\varnothing\), set \(F_t=\varnothing\).

Consider the first-choice flow polytope \(Q\), whose variables are \(y_{th}\) for \(h\in F_t\), with constraints

\(y_{th}\ge 0,\qquad \sum_{h\in F_t}y_{th}\le\mu_t,\qquad \sum_{t:\,h\in F_t}y_{th}\le\kappa_h.\)

Define

\(r=\max_{y\in Q}\sum_t\sum_{h\in F_t}y_{th}.\)

For each positive-supply category \(h\), define its minimum utilization among maximum first-choice flows:

\(b_h=\min\left\{ \sum_{t:\,h\in F_t}y_{th}: y\in Q,\ \sum_t\sum_{j\in F_t}y_{tj}=r \right\}.\)

Finally, set

\(\mathcal E=\{h:\kappa_h>0,\ b_h<\kappa_h\}.\)

All these quantities are obtainable by rational linear programming on polynomial-size data.

Lemma 2. For every admissible \(q\):

  • The maximum first-choice matching size is \(qr\).
  • A real slot of category \(h\) belongs to the even set of the replicated first-choice graph if and only if \(h\in\mathcal E\).

Proof. The compressed flow network has a source-to-type edge of capacity \(\mu_t\), a type-to-category edge for each \(h\in F_t\), and a category-to-sink edge of capacity \(\kappa_h\). A type-to-category capacity of \(1\) suffices, because total agent mass is \(1\).

After multiplying capacities by \(q\), all capacities are integers. Integer flows correspond exactly to first-choice matchings: partition the agents of each type according to their outgoing integer flows, and assign them distinct slots in the indicated categories. Conversely, every first-choice matching gives such a flow.

By integral maximum flow, the maximum matching size is therefore \(qr\), which is an integer.

Among flows of this fixed value, minimizing utilization of category \(h\) also has an integral optimum. Indeed, a fixed-value flow can be represented as a circulation by adding a sink-to-source edge whose lower and upper capacities both equal \(qr\); all capacities remain integral. The minimum integral utilization is consequently \(qb_h\).

Thus a maximum first-choice matching leaves some category-\(h\) slot unmatched exactly when

\(qb_h<q\kappa_h,\)

equivalently \(b_h<\kappa_h\). Permuting category-\(h\) slots preserves the graph, so if one slot can be left unmatched, every slot can be. Lemma 1 gives the claimed even-set characterization. \(\square\)

For each type with \(A_t\ne\varnothing\), its private last-resort posts are isolated in the first-choice graph and hence even. Accordingly, define the fallback set \(S_t\) as follows:

  • If \(A_t\cap\mathcal E\ne\varnothing\), let \(S_t\) consist of the most preferred categories in \(A_t\cap\mathcal E\).
  • If \(A_t\cap\mathcal E=\varnothing\), put \(S_t=\{0\}\), where \(0\) denotes being unmatched.

For types with \(A_t=\varnothing\), also put \(S_t=\{0\}\).

These sets are independent of \(q\). Importantly, \(S_t\) may overlap \(F_t\): an even category can itself be a first choice.

3. The exact aggregate polytope

Put \(B_t=F_t\cup S_t\). Introduce \(x_{th}\) for \(h\in B_t\); it represents the mass of type-\(t\) agents receiving category \(h\), or remaining unmatched when \(h=0\).

Let \(P\) be the rational polytope defined by

\(x_{th}\ge 0,\)

\(\sum_{h\in B_t}x_{th}=\mu_t\quad\text{for every }t,\)

\(\sum_{t:\,h\in B_t}x_{th}\le\kappa_h \quad\text{for every real category }h,\)

and

\(\sum_t\sum_{h\in F_t}x_{th}=r.\)

There is no supply constraint on \(0\). Let

\(d=\sum_t|B_t|\le\tau(m+1).\)

Proposition 3. For admissible \(q\), the aggregate tables of popular matchings are exactly

\(\{n\in\mathbb Z_{\ge 0}^{d}:n/q\in P\}.\)

Proof. Consider a popular matching and complete it with private last-resort posts. The finite-instance theorem and Lemma 2 imply that every agent receives a category in \(F_t\cup S_t\), and exactly \(qr\) agents receive first choices. Feasibility gives the row and supply constraints. Hence its normalized table belongs to \(P\).

Conversely, let \(n/q\in P\) be integral. Partition the named agents of every type into groups of sizes \(n_{th}\). Assign each real-category group distinct slots; the supply constraints guarantee enough slots. Complete unmatched agents with their private last-resort posts.

Every assignment belongs to \(f(a)\cup s(a)\), and the first-choice submatching has size \(qr\), the maximum possible. The finite-instance theorem proves popularity. Types with no available acceptable category remain unmatched and contribute no votes. \(\square\)

This checks all hypotheses of the imported characterization: the retained agents have nonempty finite preference lists, ties are permitted, slots have unit capacity, and only agents vote.

4. Counting after identifying slot permutations

Two feasible matchings are equivalent under permutations of slots within categories exactly when they give every named agent the same category, including unmatched status. Indeed, any two injections of the same agents into a category’s slots differ by a slot permutation.

For an integral table \(n/q\in P\), the number of these equivalence classes is therefore

\(W_q(n)= \prod_{t=1}^{\tau} \frac{(q\mu_t)!}{\prod_{h\in B_t}n_{th}!}.\)

The numerator retains the distinctions between agent names. There is no slot-assignment factor.

Proposition 3 thus gives the exact identity

\(Z_q= \sum_{\substack{n\in\mathbb Z_{\ge 0}^{d}\\n/q\in P}} W_q(n).\)

Define the continuous function

\(\Phi(x)= -\sum_t\sum_{h\in B_t} x_{th}\log\left(\frac{x_{th}}{\mu_t}\right),\)

where a term with \(x_{th}=0\) is interpreted as zero.

Each row, divided by \(\mu_t\), is a probability distribution. Thus \(\Phi(x)\) is a weighted sum of Shannon entropies and is nonnegative.

Theorem 4. The entropy in the question satisfies

\(\displaystyle \mathcal H(\mu,\kappa)= \begin{cases} 0,&P=\varnothing,\\ \max_{x\in P}\Phi(x),&P\ne\varnothing. \end{cases}\)

Proof. If \(P\) is empty, Proposition 3 gives \(Z_q=0\) for every admissible \(q\).

Suppose \(P\ne\varnothing\). It is compact, because its nonnegative coordinates satisfy fixed row sums, and \(\Phi\) is continuous. Write \(M=\max_{x\in P}\Phi(x)\).

Uniformly over integral feasible tables,

\(\log W_q(n)=q\Phi(n/q)+O((\tau+d)\log(q+1)).\)

To verify this estimate, use

\(\log(k!)=k\log k-k+O(1+\log(k+1))\)

for every nonnegative integer \(k\), with \(0\log0=0\). All factorial arguments are at most \(q\). The linear terms cancel by the row constraints; the \(q\log q\) terms cancel as well. The remaining main term is precisely \(q\Phi(n/q)\).

There are at most \((q+1)^d\) tables. Since \(M\ge 0\), the counting identity yields

\(\displaystyle \limsup_{\substack{q\to\infty\\q\text{ admissible}}} q^{-1}\log(1+Z_q)\le M.\)

For the reverse inequality, fix any rational \(x\in P\). Choose a positive integer \(D\) clearing the denominators of \(x,\mu,\kappa\). For every positive multiple \(q\) of \(D\), the replication factor is admissible and \(qx\) is an integral feasible table. Therefore

\(\log(1+Z_q)\ge\log W_q(qx) =q\Phi(x)+O((\tau+d)\log(q+1)).\)

Taking this subsequence gives \(\mathcal H(\mu,\kappa)\ge\Phi(x)\).

Rational points are dense in a nonempty bounded rational polytope: its vertices are rational, and rational convex combinations of those vertices approximate every convex combination. Continuity of \(\Phi\) now implies

\(\mathcal H(\mu,\kappa)\ge\max_{x\in P}\Phi(x)=M.\)

This proves the formula. \(\square\)

The argument uses the specified limsup; it does not assume that feasible tables exist at every replication factor.

5. A deterministic approximation by rational linear programming

It remains to approximate the maximum entropy with a certified bit complexity. We do this explicitly, avoiding any smoothness assumption near zero.

Define

\(g(u)=-u\log u\quad(0<u\le 1),\qquad g(0)=0.\)

Using the row constraints,

\(\Phi(x)=\sum_t\sum_{h\in B_t}g(x_{th})+C,\qquad C=\sum_t\mu_t\log\mu_t.\)

Every coordinate lies in \([0,1]\).

Set

\(N=\left\lceil\frac{4d}{\varepsilon}\right\rceil,\qquad \delta=\frac1N,\qquad \eta=\frac{\varepsilon}{4d}.\)

For \(i=1,\ldots,N\), put \(a_i=i/N\). The tangent to \(g\) at \(a_i\) is

\(T_i(u)=a_i-(1+\log a_i)u.\)

Concavity gives \(T_i(u)\ge g(u)\). Moreover, choose \(i=\max\{1,\lceil Nu\rceil\}\), so \(u\le a_i\) and \(a_i-u\le\delta\). For \(u>0\),

\(T_i(u)-g(u)=a_i-u+u\log(u/a_i)\le a_i-u\le\delta.\)

At \(u=0\), the tangent at \(a_1\) has gap exactly \(\delta\). Hence

\(g(u)\le\min_iT_i(u)\le g(u)+\delta \quad\text{for every }u\in[0,1].\)

Compute rational numbers \(\lambda_i\) satisfying

\(|\lambda_i-\log a_i|\le\eta,\)

and define

\(\widehat g(u)=\min_i\{a_i-(1+\lambda_i)u\}.\)

Each affine function changes by at most \(\eta\) on \([0,1]\), so

\(|\widehat g(u)-g(u)|\le\delta+\eta \le\frac{\varepsilon}{2d}.\)

Also compute a rational \(\widehat C\) satisfying

\(|\widehat C-C|\le\varepsilon/4.\)

For example, approximate every \(\log\mu_t\) to error \(\varepsilon/4\); multiplying by \(\mu_t\) and summing preserves this error bound because \(\sum_t\mu_t=1\).

Now solve the rational linear program

\(\displaystyle \text{maximize }\sum_t\sum_{h\in B_t}z_{th}+\widehat C,\)

subject to \(x\in P\) and

\(z_{th}\le a_i-(1+\lambda_i)x_{th} \quad\text{for every }(t,h)\text{ and every }i.\)

One may also impose \(-1\le z_{th}\le 2\). These bounds do not affect the optimum: the preceding estimates, together with \(0\le g(u)\le 1/e\), place \(\widehat g(u)\) strictly between these bounds.

For fixed \(x\), the optimal value of \(z_{th}\) is \(\widehat g(x_{th})\). Consequently, if \(V\) is this linear program’s optimal value,

\(\displaystyle \left|V-\max_{x\in P}\Phi(x)\right| \le d(\delta+\eta)+|\widehat C-C| \le\frac{3\varepsilon}{4}<\varepsilon.\)

Thus \(V\) is a certified additive approximation.

6. Bit complexity and conclusion

The entire algorithm is deterministic:

  • Remove zero-supply categories and compute the first-choice sets.
  • Compute \(r\) and the values \(b_h\) by rational linear programming.
  • Construct \(\mathcal E\), the fallback sets, and \(P\).
  • Test \(P\) for feasibility; return zero if it is empty.
  • Otherwise, solve the rational linear program from Section 5 and return its optimal value.

The flow polytope has at most \(\tau m\) variables. Computing the even categories requires at most \(m\) additional linear programs. Standard rational linear programming computes feasibility and finite optimal values exactly in polynomial bit complexity; its applicability here follows from the explicitly rational coefficients and bounded flow variables. The values \(r\) and \(b_h\) have polynomial encoding length.

The entropy approximation program has \(2d\) variables and \(O(dN+\tau+m)\) constraints, where

\(d\le\tau(m+1),\qquad N=O(d/\varepsilon).\)

Its coefficients also have polynomial encoding length. For completeness, logarithms of positive binary rationals can be approximated deterministically in polynomial bit complexity by writing \(b=2^k y\), with \(1\le y<2\), and using

\(\displaystyle \log y= 2\sum_{j=0}^{\infty} \frac{((y-1)/(y+1))^{2j+1}}{2j+1}.\)

The series ratio is bounded by \(1/9\); compute \(\log2\) by the same formula. The integer \(|k|\) is bounded by the encoding length, so the precision and number of terms needed remain polynomial. Rational arithmetic on these truncated series likewise has polynomial bit complexity.

No replicated graph is constructed. In particular, neither a common denominator nor the number of possible rankings appears as a running-time parameter.

Therefore the requested additive approximation is possible deterministically in time polynomial in \(m,\tau,L,1/\varepsilon\).
