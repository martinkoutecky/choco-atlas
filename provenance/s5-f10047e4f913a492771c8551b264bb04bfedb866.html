Packaged proof task (what the prover saw — nothing else)

Let \(m\geq 1\) be an integer and \(X_m=\{1,\ldots,m\}^2\). Define \(x\succsim_m y\) iff \(x_1\geq y_1\) and \(x_2\geq y_2\).
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here \(\tau=1\), the sole type is \(\succsim_m\), and its mass is \(1\). Let \(L\) be the total input bit length.
For a preorder \(R\), let \(R^{\mathrm{s}}\) be its asymmetric part and define \(M(S,R)=\{x\in S:\nexists y\in S\text{ with }yR^{\mathrm{s}}x\}\). Define the top-difference distance by \(D(R,Q)=\sum_{\varnothing\neq S\subseteq X_m}|M(S,R)\triangle M(S,Q)|\).
Choose a common total preorder \(\rho\) on \(X_m\), allowing indifference, to minimize \(F(\rho)=\int_T D(\succsim_t,\rho)\,d\mu(t)\). Represent the output by its ordered indifference classes.

Can an optimal common total preorder be computed in time polynomial in \(m\), \(\tau\), and \(L\), or is this optimization problem NP-hard?

For the discrete coordinatewise order, the unique distance-minimizing total preorder ranks alternatives by decreasing coordinate sum, with equal sums indifferent. The stated unit-mass, singleton-support problem is exactly covered by that result, so its complexity target is already settled.

Result

The stated problem is polynomial-time solvable. Its unique optimum is the total preorder \(\rho^\ast\) defined by

\(x\,\rho^\ast\,y \iff x_1+x_2\geq y_1+y_2.\)

Its ordered indifference classes can be computed explicitly in \(O(L+m^2\log(m+1))\) bit operations.

Optimality

Since the support consists of the single type \(\succsim_m\), with mass \(1\), for every feasible total preorder \(\rho\) we have

\(F(\rho)=D(\succsim_m,\rho).\)

We apply the coordinate-sum minimizer theorem stated in the task: on \(\{1,\ldots,m\}^2\), the unique total preorder minimizing the top-difference distance from the coordinatewise order compares alternatives by their coordinate sums. This is also Proposition 11 of Nishimura and Ok’s [*Best Complete Approximations of Preference Relations*](https://hirokinishimura.com/wp-content/uploads/2023/11/BestAPP.pdf).

The hypotheses match exactly: the alternative set is the same grid; the given relation is the coordinatewise order; maximal elements are defined using the asymmetric part; the distance counts symmetric differences over all nonempty menus; and the optimization permits all total preorders, including indifference. Thus the theorem gives precisely the unique minimizer of \(F\).

For \(m=1\), the same conclusion follows directly: there is one alternative and only one total preorder.

Algorithm and complexity

For each integer \(s\) with \(2\leq s\leq 2m\), define

\(C_s=\{(i,j)\in X_m:i+j=s\}.\)

Output the ordered classes

\((C_{2m},C_{2m-1},\ldots,C_2).\)

These classes partition \(X_m\), since every alternative has exactly one coordinate sum. Each class is nonempty, as is also evident from the following explicit enumeration:

For \(s=2m,2m-1,\ldots,2\), emit a class containing the pairs

\((i,s-i),\qquad \max\{1,s-m\}\leq i\leq\min\{m,s-1\}.\)

The bounds are exactly those ensuring that both coordinates lie between \(1\) and \(m\). Consequently, each alternative is emitted once, and there are \(m^2\) emitted pairs.

The output represents \(\rho^\ast\): alternatives in the same class have equal sums and are indifferent, while every earlier class has a strictly larger sum. Comparisons of sums give a reflexive, transitive, complete relation, so the output is a feasible total preorder.

There are \(O(m^2)\) iterations and output operations, each using integers of \(O(\log(m+1))\) bits. Including input reading, the bit complexity is therefore \(O(L+m^2\log(m+1))\), polynomial in the requested parameters \(m,\tau,L\), with \(\tau=1\). Optimality follows from the theorem above; enumerating the menus in the definition of \(D\) is unnecessary.
