Theorem 3.1 — class: algorithmic

The continuous mirror question, as graded

Given finite rational type support \((\mu_t,a_t,F_t)\), with \(\sum_t\mu_t a_t=1\) and each \(F_t\) a finite rational-support i.i.d. value law, fix a target type \(t^\star\) and horizon \(H\). For \(n\) agents with \(n\mu_t\) agents of type \(t\), each having fair share \(a_t/n\), run DMMF for \(\lfloor nH\rfloor\) rounds from zero allocations, with uniform tie breaking. Do the target agent’s maximin expected total utilities converge as \(n\to\infty\), when it may choose any nonanticipating request policy and the other agents may use any joint nonanticipating request policies based on public history; if so, compute the limiting value and give an \(\varepsilon\)-optimal target policy and matching adversarial strategy or upper-bound certificate.

Packaged proof task (what the prover saw — nothing else)

A society is specified by its support: \(\tau\) types of positive binary-rational mass \(\mu_t\), with \(\sum_t\mu_t=1\); \(\tau\) counts listed types, not possible types. Type \(t\) has a positive rational weight \(a_t\) and a finitely supported law \(F_t\) on nonnegative rational values, with rational probabilities and \(\sum_t\mu_ta_t=1\). Let \(m\) count all listed value atoms and \(L\) be the total input bit length.
Fix a target type \(t^\star\) and positive rational horizon \(H\). For each integer \(n\geq2\) with every \(n\mu_t\) integral, create \(n\mu_t\) agents of type \(t\), each with share \(\alpha_i=a_t/n\), and designate one agent of type \(t^\star\) as the target. Values are independent across agents and rounds, with law \(F_t\).
Run \(T_n=\lfloor nH\rfloor\) rounds from allocation counts \(A_i(0)=0\). Requests are simultaneous binary decisions; if any agent requests, DMMF allocates the item to a requester minimizing \((A_i(r-1)+1)/\alpha_i\), breaking ties uniformly with fresh independent randomness. Otherwise no allocation occurs. Only the winner's count increases, and its utility is its current value.
Public history contains past requests and winners. The target may randomize using its own values through the current round and public history; the opposing coalition may use arbitrary joint randomized policies using its members' values through the current round and public history. Neither side observes the other side's current values, requests, or private randomization before choosing requests; future values are unavailable.
Define \(G_n=\sup_\pi\inf_\sigma\mathbb E_{\pi,\sigma}[\sum_{r=1}^{T_n}V_\star(r)\mathbf1\{\star\text{ wins }r\}]\), over these policies; utility is total utility without further normalization.

Does \(G_n\) converge along all admissible \(n\to\infty\)? If so, is computing its limit to additive rational accuracy \(\varepsilon>0\), together with an asymptotically \(\varepsilon\)-optimal target policy and a matching adversarial strategy or upper-bound certificate, polynomial-time in \(m,\tau,L,1/\varepsilon\), or NP-hard? State running times in these quantities and \(H\), whose binary encoding is included in \(L\).

For finite-agent DMMF with i.i.d. values, independently requesting according to a maximizer of \(v^\star(\beta)=\max_{\rho:\operatorname{supp}(F)\to[0,1],\ \mathbb E\rho(V)\leq\beta}\mathbb E[V\rho(V)]\) guarantees at least \(\frac{\alpha}{\alpha+(1-\alpha)\beta}v^\star(\beta)T-\frac{v^\star(\beta)}{\alpha+\beta}\) expected utility for every \(\beta\in(0,1]\), against arbitrary opponents. [Source](https://arxiv.org/html/2310.08881v4)
Long-run allocation rates under fixed independent request probabilities have also been characterized for finite populations; this does not settle the adaptive maximin population limit above. [Source](https://arxiv.org/html/2501.14916) No result settling this exact limit problem was located.

  • Restricted the population limit to integers for which all type counts are integral, and designated one target agent rather than aggregating its type.
  • Used the prospective allocation count A_i+1 in the DMMF priority, as specified by the discrete mechanism.
  • Made values independent across agents as well as rounds, following the discrete model.

Partial resolution: all target laws through the second-allocation boundary

I prove convergence and give matching strategies for every finitely supported target law when $H\leq C_2$, where $C_2$ is an explicitly computable boundary defined below. This includes the previously unresolved case of general target laws in the first tied interval.

The unrestricted problem for $H>C_2$ remains open here. In particular, the results below do not establish a general polynomial-time algorithm or an NP-hardness classification.

1. Definitions and the proved limit

Write
$$ a=a_{t^\star}, \qquad v=\max\operatorname{supp}(F_{t^\star}). $$

Zero-probability listed atoms can first be discarded. If $v=0$, then $G_n=0$ for every admissible $n$ and every horizon. Henceforth assume $v>0$, and put
$$ p=\Pr(V_\star=v)>0. $$

For $k\geq1$, define
$$ b_t(k)=\left\lceil\frac{k a_t}{a}\right\rceil-1, \qquad C_k=\sum_t\mu_t b_t(k), $$
and define
$$ D=\sum_{t:\,a_t/a\in\mathbb Z_{>0}}\mu_t. $$

In particular, $D\geq\mu_{t^\star}>0$.

Define the target-law function
$$ g(u)=\mathbb E[(V_\star-u)_+], \qquad 0\leq u\leq v. $$

Let $\phi:[0,\infty)\to[0,v)$ be the unique function satisfying
$$ \phi(0)=0, \qquad \phi'(y)=g(\phi(y)). $$

Its existence and the estimates used below are proved in Section 3.

Theorem. Along all admissible population sizes, if $H\leq C_2$, then
$$ \lim_{n\to\infty}G_n= \begin{cases} 0, & H\leq C_1,\\[4pt] \displaystyle \phi\!\left(\log\frac{D}{C_1+D-H}\right), & C_1<H<C_1+D,\\[8pt] v, & C_1+D\leq H\leq C_2. \end{cases} $$

These intervals are correctly ordered:
$$ C_1+D\leq C_2. $$

In the interior interval, write
$$ q=C_1+D-H>0. $$

For every admissible $n$ for which $T_n>nC_1$, the following explicit estimate holds:
$$ \phi\!\left(\log\frac Dq\right)-\frac{2v}{nq} \leq G_n \leq \phi\!\left(\log\frac Dq\right). $$

Thus convergence in this interval has a quantitative bound against arbitrary adaptive coalitions.

2. Token counts and upper certificates

An agent of type $t$ with allocation count $A$ has next priority
$$ \frac{A+1}{a_t}, $$
after cancelling the common factor $n$ from DMMF priorities.

Call its allocation with index $j$ its $j$-th token. The priority of that token is $j/a_t$.

2.1 Strict tokens and the second-allocation boundary

A type-$t$ token has priority strictly below the target’s $k$-th priority exactly when
$$ j<\frac{k a_t}{a}. $$

There are therefore exactly $b_t(k)$ such tokens per type-$t$ agent.

Suppose every opponent requests in a round in which the target receives its $k$-th allocation. Every type-$t$ opponent must then have count at least $b_t(k)$; otherwise that opponent would have strictly smaller priority.

Excluding the target removes $b_{t^\star}(k)=k-1$ from the population’s strict-token count. Adding the target’s own previous $k-1$ allocations gives
$$ \sum_i A_i(r-1)\geq nC_k. $$

Since at most one allocation occurs per round,
$$ r\geq nC_k+1. $$

This argument requires universal opponent requesting only in the prospective target-winning round.

Consequently, against opponents who always request:

  • the target cannot win when $H\leq C_1$;
  • the target can win at most once when $H\leq C_2$.

Each allocation has value at most $v$, so these give upper certificates $0$ and $v$, respectively.

For an integer ratio $\ell=a_t/a$,
$$ b_t(2)-b_t(1)=\ell\geq1. $$

For every other ratio, this difference is nonnegative. Summing over types proves
$$ C_2-C_1\geq D. $$

2.2 A general upper bound

For completeness, define
$$ K(H)=\max\bigl(\{0\}\cup\{k\geq1:C_k<H\}\bigr). $$

The same coalition strategy proves
$$ 0\leq G_n\leq vK(H) $$
for every horizon.

The maximum is finite, since
$$ \frac{k}{a}-1\leq C_k<\frac{k}{a}. $$

Here the inequalities follow from
$$ x-1\leq\lceil x\rceil-1<x, $$
together with $\sum_t\mu_t=1$ and $\sum_t\mu_ta_t=1$. In particular,
$$ K(H)\leq\left\lceil a(H+1)\right\rceil-1. $$

Also, $C_{k+1}-C_k\geq\mu_{t^\star}>0$, because the target type’s contribution increases by $\mu_{t^\star}$ and all other contributions are nondecreasing.

3. The scalar flow and its estimates

For $0\leq u<v$,
$$ p(v-u)\leq g(u)\leq v-u. $$

The lower inequality uses the maximum-value atom. The upper inequality holds pointwise because $(V_\star-u)_+\leq v-u$.

The function $g$ is continuous, nonincreasing, and $1$-Lipschitz. Indeed,
$$ \bigl|(x-u)_+-(x-w)_+\bigr|\leq|u-w| $$
for every $x$, and taking expectations proves the Lipschitz assertion.

Define
$$ S(u)=\int_0^u\frac{dz}{g(z)}, \qquad 0\leq u<v. $$

This is continuous and strictly increasing, with $S(0)=0$. Moreover,
$$ S(u)\geq\int_0^u\frac{dz}{v-z} =\log\frac{v}{v-u}, $$
so $S(u)\to\infty$ as $u\uparrow v$.

Thus $S$ has an inverse $\phi:[0,\infty)\to[0,v)$. Since $S'(u)=1/g(u)>0$, differentiation of the inverse gives
$$ \phi'(y)=g(\phi(y)). $$

This also proves uniqueness: any solution taking values in $[0,v)$ satisfies
$$ \frac{d}{dy}S(\phi(y))=1 $$
and hence $S(\phi(y))=y$.

The bounds on $g$ give
$$ v(1-e^{-py})\leq\phi(y)\leq v(1-e^{-y}), $$
and in particular
$$ 0\leq v-\phi(y)\leq ve^{-py}. $$

Also, $\phi$ is $v$-Lipschitz because $\phi'=g(\phi)\leq v$.

3.1 Two flow inequalities

Let
$$ q(y)=g(\phi(y)). $$

Because $g$ is piecewise affine, with slopes in $[-1,0]$, the function $q$ is absolutely continuous and satisfies, almost everywhere,
$$ -q(y)\leq q'(y)\leq0. $$

Therefore, for $y_1=y_0+\Delta$ with $\Delta\geq0$,
$$ q(y_0)e^{-\Delta}\leq q(y_1)\leq q(y_0). $$

Integrating the corresponding bounds between $y_0$ and $y_1$ yields
$$ q(y_0)(1-e^{-\Delta}) \leq \phi(y_1)-\phi(y_0) \leq q(y_1)(e^\Delta-1). $$

Both inequalities will be used below.

4. A first-allocation guarantee against arbitrary coalitions

Until the target’s first allocation, its priority is $1/a$.

Count the opponents’ unconsumed tokens as follows:

  • $b$: tokens with priority strictly below $1/a$;
  • $d$: tokens with priority equal to $1/a$.

A tied token is counted even if its owner must first receive earlier strict tokens.

Initially these counts are
$$ B=nC_1, \qquad d=nD-1. $$

Both are integers for admissible $n$. Set
$$ N=d+1. $$

For a state with $h$ rounds remaining, set
$$ s=h-b. $$

If $s\leq0$, define its potential to be zero. If
$$ 0<s<N, $$
define
$$ U(b,d,h)=\phi\!\left(\log\frac{N}{N-s}\right). $$

Consider the following target policy:

  • Before its first allocation, abstain when $s\leq0$.
  • When $0<s<N$, request exactly when

$$ V_\star>U(b,d,h). $$

  • After its first allocation, abstain.

The quantities $b,d,h$ are available from the public allocation history.

Lemma. Suppose initially $0<s_0<N_0$, and put
$$ R_0=N_0-s_0\geq1. $$

The policy above guarantees expected utility at least
$$ \phi\!\left(\log\frac{N_0}{R_0}\right)-\frac{v}{R_0} $$
against every allowed coalition policy.

Proof

Before a target win, a round changes the resources in one of three ways:

  • A strict opponent token is allocated: $b$ and $h$ decrease by one.
  • A tied opponent token is allocated: $d$ and $h$ decrease by one.
  • No strict or tied token is allocated: only $h$ decreases among the counted quantities.

Thus, while $s>0$, the quantity
$$ R=N-s $$
stays constant in the first two cases and increases by one in the third. In particular, $R\geq R_0$ throughout.

Condition on the public history and on the coalition’s current private information and requester set. The target’s current value still has law $F_{t^\star}$, because current values are independent and the coalition cannot observe the target’s current value before choosing requests.

We prove a one-round inequality for earned utility plus continuation potential.

If $s\leq0$, the potential is zero and the target abstains. All possible continuation potentials are also zero, so there is no loss.

Now suppose $s>0$, and write $U=U(b,d,h)$.

Case 1: some strict opponent requests

A strict opponent wins with certainty. Both $b$ and $h$ decrease by one, so $s,N,R$ and the potential remain unchanged.

Case 2: no strict opponent requests, and $z\geq1$ tied opponents request

Here $z\leq d=N-1$. If the target does not win, one tied token is consumed. The continuation potential is
$$ U'=\phi\!\left(\log\frac{N-1}{R}\right). $$

Let $\delta=U-U'\geq0$. Conditional on the current target value, requesting wins with probability $1/(z+1)$. Therefore the expected reward plus continuation potential is
$$ U'+\frac{1}{z+1} \mathbb E[(V_\star-U')\mathbf1\{V_\star>U\}]. $$

Since $U'\leq U$,
$$ \mathbb E[(V_\star-U')\mathbf1\{V_\star>U\}] \geq g(U). $$

The displayed expectation is consequently at least
$$ U'+\frac{g(U)}{N}. $$

Apply the upper flow inequality with
$$ \Delta=\log\frac{N}{N-1}. $$

It gives
$$ \delta\leq g(U)(e^\Delta-1) =\frac{g(U)}{N-1}. $$

Hence the expected reward plus continuation potential is at least
$$ U-\frac{g(U)}{N(N-1)} \geq U-\frac{v}{N(N-1)}. $$

Case 3: no strict or tied opponent requests

Whenever the target requests, it wins. On abstention, no counted token is consumed. The continuation potential is
$$ U_0=\phi\!\left(\log\frac{N}{R+1}\right). $$

The expected reward plus continuation potential is at least
$$ U_0+g(U). $$

The upper flow inequality, now with
$$ \Delta=\log\frac{R+1}{R}, $$
gives
$$ U-U_0\leq\frac{g(U)}{R}. $$

Since $R\geq1$,
$$ U_0+g(U)\geq U. $$

Summing the losses

Only Case 2 incurs the proved loss. Every charged round has $N\geq R_0+1$.

On a failure in such a round, $N$ decreases by one. On a success, the target stops. Thus the values of $N$ in charged rounds are distinct, even if the final charged round is a target win. Pathwise, the sum of charges is at most
$$ v\sum_{j=R_0+1}^{N_0}\frac1{j(j-1)} = v\left(\frac1{R_0}-\frac1{N_0}\right) \leq\frac v{R_0}. $$

Iterating the conditional inequalities proves that final expected utility is at least initial potential minus this bound. The terminal potential is zero. This proves the lemma. $\square$

5. A matching asymptotic upper strategy

Suppose
$$ C_1<H<C_1+D. $$

Write
$$ T=\lfloor nH\rfloor, \qquad B=nC_1, \qquad N=nD, \qquad s=T-B, \qquad R=N-s. $$

For $s>0$, we have $s<N$ and $R\geq1$.

Use this coalition strategy:

  • For the first $B$ rounds, request with one opponent whose next token is strict, and with no other opponent.
  • Afterwards, until the target first wins, request with every opponent whose next token is tied.
  • After the target first wins, have every opponent request.

The first phase is feasible: whenever an unconsumed strict token remains, its owner’s next token is strict. It blocks the target and consumes one strict token.

At its end, all tied tokens are available. There are $N-1$ of them.

After the target first wins, a second target win would require round number at least $nC_2+1$ by Section 2. But
$$ T<n(C_1+D)\leq nC_2. $$

Thus the target can receive at most one allocation under this strategy.

5.1 The target’s optimal payoff against this strategy

Let $W(N,s)$ denote its optimal expected remaining payoff with $N-1$ tied opponents and $s$ rounds remaining, where $0\leq s<N$. Then
$$ W(N,0)=0 $$
and, for $1\leq s<N$,
$$ W(N,s) = W(N-1,s-1) +\frac1N g(W(N-1,s-1)). $$

To justify the recurrence, let $w=W(N-1,s-1)$. If the target requests at value $x$, it wins with probability $1/N$, earning $x$ and ending its utility opportunities. On failure, an opponent consumes a tied token and continuation value is $w$. Abstaining also consumes one tied token and gives continuation value $w$.

The improvement from requesting is therefore $(x-w)/N$, and maximizing separately for each current value gives the recurrence.

The identity of the opponent winner does not affect continuation: that opponent’s tied token is exhausted, all remaining tied tokens have equal priority, and after a target win the coalition uses universal requesting. Future target values are independent of all previous private histories. These observations justify the same bound for arbitrary randomized target policies.

There is no zero-tied-opponent transition in this recurrence: $s<N$ implies at least one tied opponent in every active round. At the excluded endpoint $s=N$, zero tied opponents can occur only in the terminal round; an abstention then consumes no opponent token. The endpoint will be treated separately below.

5.2 Bounding the recurrence by the flow

Define
$$ U(N,s)=\phi\!\left(\log\frac{N}{N-s}\right). $$

I claim
$$ W(N,s)\leq U(N,s). $$

Let
$$ \mathcal T_N(w)=w+\frac{g(w)}N. $$

This map is nondecreasing: for $x\leq y$, the Lipschitz property gives
$$ \mathcal T_N(y)-\mathcal T_N(x) \geq \left(1-\frac1N\right)(y-x)\geq0. $$

Put $R=N-s$. The lower flow inequality, with
$$ \Delta=\log\frac{N}{N-1}, $$
gives
$$ U(N,s)-U(N-1,s-1) \geq \frac1N g(U(N-1,s-1)). $$

Equivalently,
$$ \mathcal T_N(U(N-1,s-1))\leq U(N,s). $$

Induction from $s=0$, using monotonicity of $\mathcal T_N$, now proves the claim.

Combining this coalition certificate with the lower lemma yields the finite-population bounds
$$ U(N,s)-\frac vR \leq G_n\leq U(N,s). $$

The coalition strategy need not be exactly minimax at finite $n$; the argument proves its asymptotic tightness.

6. Convergence and the endpoint regions

6.1 Interior of the first tied interval

Let
$$ q=C_1+D-H>0. $$

Because $B$ and $N$ are integers,
$$ R=n(C_1+D)-\lfloor nH\rfloor =nq+\theta_n, \qquad 0\leq\theta_n<1. $$

Consequently,
$$ U(N,s)= \phi\!\left(\log\frac{D}{q+\theta_n/n}\right). $$

By continuity,
$$ U(N,s)\longrightarrow \phi\!\left(\log\frac Dq\right). $$

More quantitatively,
$$ 0\leq \log\frac Dq- \log\frac{D}{q+\theta_n/n} = \log\left(1+\frac{\theta_n}{nq}\right) \leq\frac1{nq}. $$

Since $\phi$ is $v$-Lipschitz and $R\geq nq$, Section 5 gives
$$ \phi\!\left(\log\frac Dq\right)-\frac{2v}{nq} \leq G_n \leq \phi\!\left(\log\frac Dq\right). $$

This proves both convergence and the stated quantitative estimate.

6.2 The zero region

If $H\leq C_1$, the universal-requesting certificate prevents every target allocation. Nonnegativity of values gives
$$ G_n=0. $$

6.3 The maximum-value region

Suppose
$$ C_1+D\leq H\leq C_2. $$

The upper certificate gives $G_n\leq v$.

For the lower bound, let $N=nD$, assume $N\geq4$, and choose
$$ R=\lceil\sqrt N\rceil, \qquad T'=nC_1+N-R. $$

Since $T'\leq n(C_1+D)\leq T_n$, the first $T'$ rounds are available.

Apply Section 4 to the virtual target values
$$ \widehat V=v\mathbf1\{V_\star=v\}. $$

This virtual law has
$$ \widehat g(u)=p(v-u), \qquad \widehat\phi(y)=v(1-e^{-py}). $$

The policy in Section 4 for this law is simply to request exactly at the maximum actual value, until the first allocation. Its guarantee over the first $T'$ rounds is
$$ v\left[1-\left(\frac RN\right)^p\right]-\frac vR. $$

The guarantee applies against every coalition, including coalitions planning for the longer horizon. Thus
$$ v-v\left(\frac RN\right)^p-\frac vR \leq G_n\leq v. $$

Both error terms tend to zero. This proves the maximum-value region, including the endpoint $H=C_1+D$, without making an incorrect zero-tied-token transition.

7. Examples

7.1 Bernoulli target values

For values supported on $\{0,v\}$, with maximum-value probability $p$,
$$ g(u)=p(v-u), \qquad \phi(y)=v(1-e^{-py}). $$

Hence the interior formula becomes
$$ \lim_nG_n = v\left[ 1-\left(\frac{C_1+D-H}{D}\right)^p \right]. $$

7.2 Two positive target values

Consider one type, with $\mu_1=a_1=1$, and target values $1$ and $2$, each with probability $1/2$. Here
$$ C_1=0, \qquad D=1, \qquad C_2=1. $$

The surplus function is
$$ g(u)= \begin{cases} \frac32-u,&0\leq u\leq1,\\[2pt] 1-\frac u2,&1\leq u\leq2. \end{cases} $$

Solving the two affine differential equations gives
$$ \phi(y)= \begin{cases} \frac32(1-e^{-y}),&0\leq y\leq\log3,\\[2pt] 2-e^{-(y-\log3)/2},&y\geq\log3. \end{cases} $$

Therefore
$$ \lim_nG_n= \begin{cases} \frac32H,&0<H\leq\frac23,\\[2pt] 2-\sqrt{3(1-H)},&\frac23<H<1,\\[2pt] 2,&H=1. \end{cases} $$

This illustrates why requesting only at the maximum value does not generally attain the limit inside the first tied interval.

8. Computation and asymptotically optimal policies

Let $\ell_\varepsilon$ denote the encoding length of the rational accuracy. Dependence on this length is necessary to read the accuracy input.

8.1 Rational preprocessing

Computing $v,p,C_1,C_2,D$ and identifying the proved region requires
$$ \operatorname{poly}(m,\tau,L) $$
bit operations.

No iteration through the numerical value of $H$ is required. Its contribution is through its binary encoding in $L$.

The general certificate $vK(H)$ is also polynomial-time computable. Strict monotonicity of $C_k$ and the bound
$$ K(H)\leq\left\lceil a(H+1)\right\rceil-1 $$
permit binary search with $O(L)$ evaluations of $C_k$.

8.2 Certified evaluation of the scalar flow

Here is an explicit approximation method, including error propagation through the potentially large value $v$.

Normalize values by setting
$$ X=V_\star/v, \qquad \gamma(w)=\mathbb E[(X-w)_+], \qquad \psi(y)=\phi(y)/v. $$

Then $X\in[0,1]$, $\psi'=\gamma(\psi)$, and
$$ S_0(w)=\int_0^w\frac{dz}{\gamma(z)} $$
is the inverse of $\psi$.

Between successive normalized value atoms,
$$ \gamma(z)=Q-Pz, $$
where $P$ is the probability above that interval and $Q$ is the corresponding probability-weighted value sum. Therefore each interval contributes
$$ \int_l^r\frac{dz}{Q-Pz} = \frac1P\log\frac{Q-Pl}{Q-Pr}. $$

For every interval below $1$, $P\geq p$. Thus $S_0(w)$ is a sum of at most $m$ explicitly computable logarithmic terms.

Suppose a normalized error $\delta\in(0,1)$ is desired.

  • Approximate $y$ to error at most $\delta/16$.
  • At each bisection point $w<1$, approximate $S_0(w)$ to error at most $\delta/16$. It suffices to approximate every logarithm to error

$$ \xi=\frac{\delta p}{16(m+1)}, $$
because the sum of errors after division by the tail probabilities is at most $\delta/16$.

  • If the two computed quantities differ by at most $\delta/4$, return $w$. Their true difference is then at most $3\delta/8$.
  • Otherwise their order is certified, and the appropriate half-interval is retained.

The implication
$$ |w-\psi(y)|\leq|S_0(w)-y| $$
holds because $\gamma\leq1$, so $S_0'\geq1$. Thus the stopping rule gives error below $\delta/2$. If it has not triggered, after
$$ \left\lceil\log_2\frac4\delta\right\rceil $$
bisections the bracket itself has sufficient width.

For clarity, the logarithms can be evaluated without an unproved numerical oracle. For a positive rational $r$, write
$$ r=2^k u, \qquad 1\leq u<2. $$

With $z=(u-1)/(u+1)$,
$$ \log u = 2\sum_{j=0}^{J-1}\frac{z^{2j+1}}{2j+1} +\mathcal R_J, \qquad |\mathcal R_J|\leq3\cdot3^{-2J}. $$

The same series evaluates $\log2$ using $z=1/3$. To approximate $\log r=k\log2+\log u$ to error $\xi$, approximate each component logarithm to error at most
$$ \frac{\xi}{2(|k|+1)}. $$

It suffices to take
$$ J=O\!\left(\log\frac{|k|+1}{\xi}\right). $$

All summands are rational. Exact rational arithmetic has polynomial bit cost: there are polynomially many terms, and their numerator and denominator lengths are polynomial in the input length and working precision.

The bisection points have denominator lengths $O(\log(1/\delta))$. The maximum atom has probability $p$, so at these points
$$ \gamma(w)\geq p(1-w). $$

Consequently, every positive rational entering a logarithm has polynomial encoding length. Also, $\log(1/p)=O(L)$.

To compute the limit to additive error $\varepsilon<v$, choose
$$ \delta=\varepsilon/v. $$

A normalized error at most $\delta/2$ becomes an absolute error at most $\varepsilon/2$. If $\varepsilon\geq v$, returning zero already meets the requested accuracy.

This proves a bit running time of
$$ \operatorname{poly}(m,\tau,L+\ell_\varepsilon) $$
for the limit in the proved regions.

8.3 A finite-precision target policy

The exact threshold policy from Section 4 already gives an asymptotically optimal mathematical policy. A finite-precision implementation can be made asymptotically $\varepsilon$-optimal.

In the interior interval, set
$$ \eta=\frac{\varepsilon}{2(T_n+1)}. $$

At every active state compute a certified lower threshold $\ell$ satisfying
$$ U-\eta\leq\ell\leq U, $$
and request when $V_\star>\ell$.

Such a threshold follows from an approximation to $U$ with error at most $\eta/2$, by subtracting $\eta/2$ and clipping at zero.

Relative to the exact policy, the additional requests have values in $(\ell,U]$. Every relevant continuation potential is at most $U$. Therefore an additional request can reduce the one-round expected reward plus continuation potential by at most $\eta$. It never suppresses a request of the exact policy.

Repeating the proof of Section 4 gives expected utility at least
$$ U(N,s)-\frac vR-\eta T_n \geq U(N,s)-\frac vR-\frac{\varepsilon}{2}. $$

Since $G_n\leq U(N,s)$,
$$ G_n-\mathbb E[\text{utility of this policy}] \leq \frac vR+\frac{\varepsilon}{2}. $$

For every fixed society and interior horizon, this is at most $\varepsilon$ for all sufficiently large admissible $n$.

The threshold computation per round has bit running time
$$ \operatorname{poly}(m,\tau,L+\ell_\varepsilon+\log n), $$
because $T_n$ has bit length $O(L+\log n)$.

In the zero region the target abstains. In the maximum-value region it requests exactly at value $v$ until its first allocation. Section 6 proves asymptotic optimality of that policy.

8.4 Coalition implementation and dependence on the horizon

The matching coalition strategies have succinct descriptions computable in
$$ \operatorname{poly}(m,\tau,L+\ell_\varepsilon) $$
time:

  • universal requesting in the zero and maximum-value regions;
  • strict-token exhaustion, then universal requesting among tied opponents, then universal requesting after the target wins, in the interior interval.

A direct implementation scans the population each round. Counts and priority comparisons have bit lengths polynomial in $L+\log n$. Including target threshold evaluation, executing both strategies takes
$$ O\!\left( nT_n\,\operatorname{poly}(L+\log n) + T_n\,\operatorname{poly}(m,\tau,L+\ell_\varepsilon+\log n) \right) $$
bit operations.

Thus execution depends on the numerical horizon through $T_n=\lfloor nH\rfloor$. Computing the limit and constructing the strategy descriptions depends on $H$ only through its binary encoding.

The sufficient population size need not be polynomial in the input length. For example, the interior error bound involves $v/q$, and the maximum-value endpoint estimate involves the possibly very small probability $p$. No polynomial population threshold is claimed.

9. What remains unresolved

The proof establishes the entire region $H\leq C_2$ for arbitrary finite target laws. It uses a first-allocation potential and a coalition certificate that rules out a second target allocation.

For $H>C_2$, that certificate no longer reduces the payoff to one allocation. A matching analysis must account for the target’s successive priorities and the coalition’s remaining tokens across multiple target wins. The arguments above do not provide that analysis.

For arbitrary horizons they give only bounds. In particular,
$$ \liminf_nG_n\geq v \qquad\text{when }H\geq C_1+D, $$
whereas
$$ \limsup_nG_n\leq vK(H). $$

These generally differ.

Opponent value laws do not supply additional restrictions on the coalition: it may ignore its actual values and privately generate, round by round, independent virtual values having any other desired opponent laws. Feeding those virtual values into a policy reproduces its relevant interaction distribution. Simulation in both directions shows that, with the target law fixed, changing opponent value laws does not change $G_n$. This observation does not itself settle the multiple-allocation problem.

Accordingly, neither unrestricted convergence nor the unrestricted computational classification is proved here.
