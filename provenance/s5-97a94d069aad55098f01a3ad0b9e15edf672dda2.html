The continuous mirror question, as graded

Given a population of size \(N\) with supported sensor types \(t\), type fractions \(\mu_t\), maximum precisions \(\bar{\xi}_t\), costs \(k_t\), prior precision \(\xi_x\), and target MSE \(\Sigma_t\), what is the minimum total compensation for selecting continuous masses \(q_t\in[0,N\mu_t]\) so that \(\xi_x+\sum_t q_t\bar{\xi}_t\ge\Sigma_t^{-1}\), with each selected unit intended to exert maximum effort under the paper’s incentive scheme?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types. The population is atomless with total mass \(N\), a positive integer encoded in binary.
Each type has positive binary-rational maximum precision \(\bar\xi_t\) and per-unit maximum-effort cost \(k_t\). The prior precision \(\xi_x\) and common target MSE \(\Sigma_\star\) are positive binary rationals.
Selecting mass \(q_t\in[0,N\mu_t]\) contributes precision \(q_t\bar\xi_t\). Global MSE is \((\xi_x+\sum_tq_t\bar\xi_t)^{-1}\), and expected total compensation is \(\sum_tk_tq_t\).
Take as given the incentive guarantee: selected units exert maximum effort and report measurements and local estimates truthfully in a Bayesian Nash equilibrium, receiving expected compensation equal to their maximum-effort cost; unselected units receive zero. Peer comparisons use distinct selected individuals, available whenever selected mass is positive.
Define the minimum compensation over selections satisfying \(\xi_x+\sum_tq_t\bar\xi_t\ge\Sigma_\star^{-1}\), with value \(+\infty\) if infeasible; empty selection is allowed. Let \(L\) be total input bit length and \(m=1\) the dimension of the estimated quantity.

Is this continuous minimum-compensation problem solvable exactly in polynomial time, or is its budget decision version NP-hard? State running times in \(m,\tau,L\), accounting for the binary encoding of \(N\).

For finite agents, maximum effort and truthful reporting can be incentivized at expected payment equal to effort cost; the resulting binary selection problem is NP-hard, with pseudopolynomial dynamic programming for integer numerical data. Result

The continuous problem is exactly solvable in polynomial time. Its budget decision version belongs to \(\mathrm{P}\).

For the stated dimension \(m=1\), an optimal selection and its exact compensation can be computed using \(O(\tau\log(\tau+1))\) exact arithmetic operations, with a conservative bound of

\(T(1,\tau,L)=O\!\left((\tau\log(\tau+1)+1)L^2\right)\)

bit operations using classical integer arithmetic. The algorithm processes only the supported types. The population size \(N\) enters through its binary representation; no population expansion is required.

1. Reformulation and boundary cases

Define the additional precision required by

\(R=\Sigma_\star^{-1}-\xi_x.\)

The given incentive guarantee makes the expected compensation of a selection exactly \(\sum_t k_tq_t\). Thus the optimization problem is

\(\min \sum_{t=1}^{\tau}k_tq_t,\qquad \sum_{t=1}^{\tau}\bar\xi_tq_t\ge R,\qquad 0\le q_t\le N\mu_t.\)

If \(R\le 0\), the empty selection is feasible and has compensation zero. Because costs are positive, this is optimal.

Henceforth assume \(R>0\). Introduce precision variables and capacities

\(p_t=\bar\xi_tq_t,\qquad a_t=N\mu_t\bar\xi_t,\qquad r_t=k_t/\bar\xi_t.\)

Since \(\bar\xi_t>0\), this is a bijective change of variables between the original selection box and the box \(0\le p_t\le a_t\). The problem becomes

\(\min \sum_{t=1}^{\tau}r_tp_t,\qquad \sum_{t=1}^{\tau}p_t\ge R,\qquad 0\le p_t\le a_t.\)

It is feasible exactly when

\(R\le \sum_{t=1}^{\tau}a_t=N\sum_{t=1}^{\tau}\mu_t\bar\xi_t.\)

Necessity follows from the upper bounds on \(p_t\). Sufficiency follows by selecting every type fully. If this inequality fails, the minimum compensation is \(+\infty\).

2. Exact optimal selection

Assume feasibility and relabel the supported types so that

\(r_1\le r_2\le\cdots\le r_\tau.\)

Ties may be ordered arbitrarily. Set \(S_0=0\) and \(S_i=\sum_{t=1}^{i}a_t\). Let \(j\) be the smallest index with \(S_j\ge R\). This index exists by feasibility, and

\(0<R-S_{j-1}\le a_j.\)

Construct the precision allocation as follows:

  • For \(t<j\), set \(p_t^\star=a_t\).
  • For \(t=j\), set \(p_j^\star=R-S_{j-1}\).
  • For \(t>j\), set \(p_t^\star=0\).

Every coordinate satisfies its capacity constraint, and \(\sum_t p_t^\star=R\). Translating back gives

  • \(q_t^\star=N\mu_t\) for \(t<j\);
  • \(q_j^\star=(R-S_{j-1})/\bar\xi_j\);
  • \(q_t^\star=0\) for \(t>j\).

Thus at most one supported type is selected partially. The candidate compensation is

\(C^\star=N\sum_{t<j}\mu_tk_t+\dfrac{k_j}{\bar\xi_j}(R-S_{j-1}).\)

These masses are admissible in the atomless model. When \(R>0\), the selection has positive mass because its total precision is positive. The assumed peer-comparison guarantee therefore applies. When \(R\le0\), the empty selection requires no comparisons.

3. Proof of optimality

Let \(p\) be any feasible precision allocation, including one that supplies more than the required precision. Set \(\lambda=r_j>0\). Since \(\sum_t p_t^\star=R\),

\(\sum_t r_t(p_t-p_t^\star)=\lambda\left(\sum_t p_t-R\right)+\sum_t(r_t-\lambda)(p_t-p_t^\star).\)

Every term on the right is nonnegative:

  • Feasibility gives \(\sum_t p_t-R\ge0\), and \(\lambda>0\).
  • For \(t<j\), sorting gives \(r_t-\lambda\le0\), while \(p_t-p_t^\star=p_t-a_t\le0\). Their product is nonnegative.
  • For \(t=j\), the coefficient \(r_j-\lambda\) is zero.
  • For \(t>j\), sorting gives \(r_t-\lambda\ge0\), while \(p_t-p_t^\star=p_t\ge0\). Their product is nonnegative.

Consequently,

\(\sum_t r_tp_t\ge\sum_t r_tp_t^\star=C^\star.\)

The constructed allocation is feasible and attains this lower bound. It is therefore optimal. This proves the formula for the minimum compensation in every feasible case.

4. Exact arithmetic and bit complexity

It remains to show that rational arithmetic does not conceal a dependence on the numerical value of \(N\).

Write the input rationals as

\(\mu_t=A_t/B_t,\quad \bar\xi_t=C_t/E_t,\quad k_t=F_t/G_t,\quad \xi_x=U/V,\quad \Sigma_\star=W/Z,\)

where all numerators and denominators are positive integers encoded in binary. Define the common scaling integer

\(D=WV\prod_{t=1}^{\tau}B_tE_tG_t.\)

The binary length of \(D\) is \(O(L)\), because the sum of the binary lengths of its factors is bounded by the input length.

Define scaled capacities, full-selection costs, and required precision by

\(\alpha_t=DN\mu_t\bar\xi_t,\qquad \beta_t=DN\mu_tk_t,\qquad H=D(\Sigma_\star^{-1}-\xi_x).\)

These are integers: \(B_tE_t\), \(B_tG_t\), \(W\), and \(V\) divide \(D\) in the respective expressions. They can be computed using exact integer division and multiplication.

Each integer has \(O(L)\) bits. For example,

\(\alpha_t\le DN A_tC_t,\qquad \beta_t\le DN A_tF_t,\qquad |H|\le D(Z+U),\)

and every factor on the right has at most \(O(L)\) bits. Prefix sums also have \(O(L)\) bits: summing \(\tau\) such integers adds at most \(O(\log(\tau+1))\) bits, and \(\tau\le L\) for an explicitly listed support.

The entire algorithm can now operate on integers:

  • If \(H\le0\), return the empty selection and zero compensation.
  • If \(H>\sum_t\alpha_t\), return infeasibility.
  • Sort by \(\beta_t/\alpha_t=r_t\). Compare two ratios by comparing the integers \(\beta_s\alpha_t\) and \(\beta_t\alpha_s\).
  • Find the first sorted prefix whose scaled capacity reaches \(H\).

For the resulting index \(j\), let

\(h=H-\sum_{t<j}\alpha_t,\qquad K=\sum_{t<j}\beta_t.\)

Then \(0<h\le\alpha_j\), and exact output formulas are

\(q_j^\star=\dfrac{hNA_j}{\alpha_jB_j},\qquad C^\star=\dfrac{K\alpha_j+\beta_jh}{D\alpha_j}.\)

The remaining selection coordinates are \(N A_t/B_t\) or zero. Every numerator and denominator in these output formulas has \(O(L)\) bits. Unreduced fractions already constitute exact rational output; the entire selection vector uses at most \(O(\tau L)\) output bits.

Constructing the scaled data takes \(O(\tau)\) integer arithmetic operations. Sorting takes \(O(\tau\log(\tau+1))\) comparisons, and the final scan and output construction take \(O(\tau)\) operations. All arithmetic operands and comparison products have \(O(L)\) bits. Classical multiplication and division therefore give the claimed bound

\(O\!\left((\tau\log(\tau+1)+1)L^2\right).\)

In particular, the dependence on \(N\) is through \(\log N\), already included in \(L\). No loop runs up to \(N\), a precision target, or a scaled integer capacity. These bounds concern the specified scalar problem \(m=1\); no higher-dimensional estimation model is assumed.

5. Budget decision and the discrete distinction

For a rational budget \(B\), answer yes exactly when the selection problem is feasible and \(C^\star\le B\). This comparison is performed exactly by cross multiplication. The same polynomial bound applies when \(L\) denotes the total decision-input length, including the budget.

Hence the budget decision problem is in \(\mathrm{P}\). NP-hardness under polynomial-time many-one reductions would imply \(\mathrm{P}=\mathrm{NP}\).

The cited paper’s equation (11) instead imposes binary selection of individual agents and states NP-hardness and a pseudopolynomial dynamic program for that problem. [Chen et al., *Distributed Estimation in the Presence of Strategic Data Sources*](https://arxiv.org/pdf/1908.04780)

Divisibility changes the feasible set. For example, take \(\tau=1\), \(N=1\), \(\mu_1=1\), \(\bar\xi_1=2\), \(k_1=2\), \(\xi_x=1\), and \(\Sigma_\star=1/2\). The required additional precision is \(R=1\). Continuous selection attains it with \(q_1=1/2\) at compensation \(1\); binary selection requires \(q_1=1\) at compensation \(2\). The optimality proof above relies precisely on the permitted partial selection.
