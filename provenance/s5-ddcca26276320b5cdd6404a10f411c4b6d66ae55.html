The continuous mirror question, as graded

Given a finite type set \(T\), \(K\) chore classes, rational masses \(\mu_t>0\), entitlement coefficients \(e_t>0\), per-class supplies \(s_k\ge 0\), and positive costs \(c_{tk}\), with \(\sum_{t\in T}\mu_t=1\) and \(\sum_{t\in T}\mu_t e_t=1\), let a worker of type \(t\) receiving bundle \(B\in\mathbb Z_{\ge 0}^K\) incur cost \(v_t(B)=\sum_{k=1}^K c_{tk}B_k\). A mass assignment \(y\) has finite support, satisfies \(\sum_B y_{t,B}=\mu_t\) for every \(t\), and \(\sum_{t,B}y_{t,B}B_k=s_k\) for every \(k\); write \(\mathcal Y(\mu,s)\) for these assignments and define \(W_t^\infty=\inf_{y\in\mathcal Y(\mu,s)}\max_{(u,B):\,y_{u,B}>0}(e_t/e_u)v_t(B)\). Is there an algorithm polynomial in \(K\), \(|T|\), and the input bit length \(L\) that outputs a rational finite-support mass assignment \(x\in\mathcal Y(\mu,s)\) such that \(x_{t,B}>0\) implies \(v_t(B)\le 20W_t^\infty\) for every type \(t\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau=|T|\) types with positive binary-rational masses \(\mu_t\); \(\tau\) counts supported types, not all possible types.
There are \(m=K\ge1\) chore classes. All input numbers are binary rationals: entitlement coefficients \(e_t>0\), supplies \(s_k\ge0\), and costs \(c_{tk}>0\), with \(\sum_t\mu_t=1\) and \(\sum_t\mu_te_t=1\). Let \(L\) be the total input bit length.
A worker receives an integer bundle \(B\in\mathbb Z_{\ge0}^K\), possibly empty, costing \(v_t(B)=\sum_kc_{tk}B_k\). Entitlement coefficients are densities and need not be at most one.
Let \(\mathcal Y(\mu,s)\) consist of nonnegative real arrays \(y_{t,B}\) with finite support satisfying \(\sum_B y_{t,B}=\mu_t\) and \(\sum_{t,B}y_{t,B}B_k=s_k\). Thus workers of one type may receive different bundles.
Define \(W_t^\infty=\inf_{y\in\mathcal Y(\mu,s)}\max_{(u,B):y_{u,B}>0}(e_t/e_u)v_t(B)\); every bundle in this benchmark is evaluated using type \(t\)'s costs.

Is there an algorithm running in \(\operatorname{poly}(m,\tau,L)\) that, for every such instance, outputs a rational finite-support assignment \(x\in\mathcal Y(\mu,s)\) satisfying \(x_{t,B}>0\Rightarrow v_t(B)\le20W_t^\infty\) for every \(t\)?

For finite agents with positive weights summing to one, the benchmark is \(\mathrm{WMMS}_i=\min_{(A_j)\text{ partitioning the chores}}\max_j(w_i/w_j)V_i(A_j)\); a \(20\)-WMMS assignment always exists. [Source](https://arxiv.org/html/2510.10698v1)
A separate discrete result proves existence of \(12\)-WMMS assignments and polynomial-time computation of \((24+\epsilon)\)-WMMS assignments for every fixed \(\epsilon>0\). [Source](https://arxiv.org/html/2510.06581v1)
No result settling the precise mass-assignment question above was located in the search.

Modeling choices made when packaging the task

  • Specified all entitlement coefficients, supplies, and costs as binary rationals so that the input bit length is defined.
  • Specified benchmark assignments as nonnegative real masses; the required output retains rational masses.
  • Made explicit that empty bundles and different bundles within one type are allowed, matching partitions that permit empty agent bundles.
  • Required a nonempty type support and at least one chore class; retained zero supplies.
  • Interpreted entitlement coefficients as densities under the stated mass-weighted normalization, without imposing an individual upper bound of one.
  • Set m=K because chore classes, rather than individually listed chores, constitute the resource description.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

A polynomial-time algorithm with factor below \(20\)

Yes. Using the finite-agent \(12\)-WMMS existence theorem stated in the question, there is an algorithm running in \(\operatorname{poly}(m,\tau,L)\) that outputs a rational finite-support assignment satisfying the stronger bound

\[ x_{t,B}>0\quad\Longrightarrow\quad v_t(B)\le \frac{1275}{64}W_t^\infty<20W_t^\infty. \]

The proof has two main ingredients: an exact transfer of the finite-agent existence theorem, and a polynomial-size collection of integer bundles whose convex hull contains every bundle below a prescribed threshold, with a factor \(5/4\) increase in cost.

1. Benchmark bounds and rational attainment

Write \(c_t=(c_{t1},\ldots,c_{tm})\), so \(v_t(B)=c_t\cdot B\), and extend this linear expression to real vectors.

If \(s=0\), the assignment \(x_{t,0}=\mu_t\) solves the problem: every benchmark equals zero. Henceforth assume that at least one supply is positive.

Define

\[ a_t=e_t(c_t\cdot s), \qquad U_t=\frac{e_t}{e_{\min}}\sum_k c_{tk}\lceil s_k\rceil, \qquad e_{\min}=\min_u e_u. \]

We first prove that

\[ 0<a_t\le W_t^\infty\le U_t. \]

For any feasible assignment \(y\), let its benchmark objective for evaluator \(t\) be \(D\). Every supported pair satisfies \(c_t\cdot B\le D e_u/e_t\). Therefore

\[ c_t\cdot s =\sum_{u,B}y_{u,B}(c_t\cdot B) \le \frac{D}{e_t}\sum_u e_u\mu_u =\frac{D}{e_t}. \]

Taking the infimum proves the lower bound.

For the upper bound, independently round each \(s_k\) to either \(\lfloor s_k\rfloor\) or \(\lceil s_k\rceil\), with probabilities giving expectation \(s_k\). This defines a rational, finitely supported distribution \(p_B\) on integer bundles with mean \(s\). Set \(y_{u,B}=\mu_u p_B\). Then \(y\) is feasible, and every bundle it uses has evaluator-\(t\) cost at most \(\sum_kc_{tk}\lceil s_k\rceil\). Its benchmark objective is consequently at most \(U_t\).

We also need attainment.

Lemma 1. Each \(W_t^\infty\) is attained by a rational finite-support assignment.

Proof. For fixed evaluator \(t\), any assignment with objective at most \(U_t\) uses, at recipient type \(u\), only bundles satisfying

\[ c_t\cdot B\le \frac{e_u}{e_t}U_t. \]

There are finitely many such integer bundles because every \(c_{tk}\) is positive. Thus every objective value at most \(U_t\) belongs to the finite set of values

\[ \left\{\frac{e_t}{e_u}(c_t\cdot B): u\in T,\; B\in\mathbb Z_{\ge0}^m,\; c_t\cdot B\le \frac{e_u}{e_t}U_t \right\}. \]

At least one of these values is achievable, by the upper-bound construction. Hence the least achievable value exists and equals \(W_t^\infty\).

Restricting to bundles permitted at this least value gives a nonempty finite rational linear program: its equations are precisely the type-mass and supply equations. It is bounded, since each variable lies between zero and its type’s mass. A nonempty bounded rational polyhedron has a rational vertex. This vertex gives the required rational assignment. \(\square\)

2. Transferring the finite-agent existence theorem

We use the following supplied result: every finite instance of indivisible chores with additive costs and positive agent weights summing to one admits an assignment whose cost to each agent is at most \(12\) times that agent’s WMMS. This follows from Theorems 1 and 3 of [Li–Wang–Xing, *Constant Weighted Maximin Share Approximations for Chores*](https://arxiv.org/html/2510.06581v1).

Lemma 2. The present mass model admits a rational finite-support assignment \(z\) satisfying

\[ z_{t,B}>0\quad\Longrightarrow\quad c_t\cdot B\le12W_t^\infty. \]

Proof. For every evaluator \(t\), choose a rational benchmark-attaining assignment \(y^{(t)}\), using Lemma 1.

Choose an integer \(N\ge2\) clearing all denominators of the masses, supplies, and entries of these finitely many assignments. Construct a finite instance with:

  • \(N\mu_u\) agents of type \(u\), each with weight \(e_u/N\);
  • \(Ns_k\) distinct chores of class \(k\);
  • cost \(c_{uk}\) for a class-\(k\) chore to a type-\(u\) agent.

These are integer agent and chore counts. There are \(N\) agents, and their positive weights sum to

\[ \sum_u(N\mu_u)\frac{e_u}{N} =\sum_u\mu_ue_u=1. \]

Thus all hypotheses of the finite-agent theorem hold. Since \(N\ge2\), every individual weight is also strictly below one.

Fix an evaluator of type \(t\). Give exactly \(Ny^{(t)}_{u,B}\) type-\(u\) agents bundle \(B\). The mass and supply equations ensure that this is a partition of the finite chores. Its benchmark objective equals

\[ \max_{(u,B):y^{(t)}_{u,B}>0} \frac{e_t/N}{e_u/N}(c_t\cdot B) =W_t^\infty. \]

Hence the finite WMMS of every type-\(t\) agent is at most \(W_t^\infty\).

Conversely, any finite partition induces a feasible mass assignment by giving mass \(1/N\) to each agent’s bundle. Its objective for evaluator \(t\) equals the finite partition’s WMMS objective. Therefore the finite WMMS is at least \(W_t^\infty\). The two benchmarks are exactly equal.

Apply the finite-agent \(12\)-WMMS existence theorem and aggregate the resulting agents by type and bundle, assigning mass \(1/N\) per agent. The resulting rational assignment proves the lemma. \(\square\)

This construction is used only to prove existence. The algorithm below never expands the population or supplies by \(N\).

3. A polynomial-size collection of bundles

For positive rational costs \(a=(a_1,\ldots,a_m)\) and a positive rational capacity \(C\), define

\[ \mathcal C(a,C)= \{B\in\mathbb Z_{\ge0}^m:a\cdot B\le C\}. \]

Lemma 3. One can construct, in polynomial time, a set \(\mathcal G(a,C)\) of \(O(m^4)\) integer bundles such that

\[ \operatorname{conv}\mathcal C(a,C) \subseteq\operatorname{conv}\mathcal G(a,C), \]

and every \(G\in\mathcal G(a,C)\) satisfies \(a\cdot G\le5C/4\). All generated coordinates have polynomial binary encoding length.

Construction. Call class \(k\) *large* if \(a_k>C/4\), and *small* otherwise.

Enumerate every nonnegative integer vector \(H\) supported on large classes satisfying

\[ \sum_kH_k\le3, \qquad a\cdot H\le C. \]

For each such \(H\), put \(r=C-a\cdot H\) and include \(H\) in \(\mathcal G(a,C)\). If \(r>0\), then for every small class \(k\), also include

\[ H+n_k\mathbf d^k, \qquad n_k=\left\lceil\frac{r}{a_k}\right\rceil, \]

where \(\mathbf d^k\) is the \(k\)-th coordinate unit vector.

There are \(O(m^3)\) possible vectors \(H\), since each consists of at most three class units. Each contributes at most \(m+1\) bundles.

Cost bound. The bundle \(H\) costs at most \(C\). Every additional bundle satisfies

\[ a\cdot(H+n_k\mathbf d^k) =a\cdot H+n_ka_k \le a\cdot H+r+a_k \le C+\frac C4. \]

Convex-hull inclusion. Take \(B\in\mathcal C(a,C)\). Let \(H\) be its restriction to large classes and \(Z=B-H\). There are at most three large units in \(B\): four would cost strictly more than \(C\). Thus \(H\) was enumerated.

Set \(r=C-a\cdot H\). If \(r=0\), positivity of the costs forces \(Z=0\), so \(B=H\) is generated.

Otherwise, for every small class define \(\lambda_k=Z_k/n_k\). Since \(n_k\ge r/a_k\),

\[ \sum_{k\text{ small}}\lambda_k \le \frac{\sum_{k\text{ small}}a_kZ_k}{r} \le1. \]

Consequently,

\[ B= \left(1-\sum_{k\text{ small}}\lambda_k\right)H +\sum_{k\text{ small}}\lambda_k (H+n_k\mathbf d^k). \]

This is a convex combination of generated bundles, proving the inclusion.

Finally, calculating \(n_k\) requires only division and ceiling of binary rationals. Its binary length is polynomial in the encoding lengths of \(a\) and \(C\). The enumeration and arithmetic therefore take polynomial time. \(\square\)

The inclusion preserves expected bundles exactly. Its use here is legitimate because a type’s mass may be split among different integer bundles.

4. Approximating every benchmark

Fix evaluator \(t\) and a positive rational trial value \(w\). For each recipient type \(u\), construct

\[ \mathcal G_{t,u}(w) =\mathcal G\left(c_t,\frac{e_u}{e_t}w\right). \]

Every cost vector in this construction is \(c_t\), including for recipient types different from \(t\), as required by the benchmark definition.

Test feasibility of the following explicitly given rational linear program:

\[ \lambda_{u,G}\ge0, \qquad \sum_{G\in\mathcal G_{t,u}(w)}\lambda_{u,G}=\mu_u \quad(u\in T), \]

\[ \sum_u\sum_{G\in\mathcal G_{t,u}(w)} \lambda_{u,G}G_k=s_k \quad(1\le k\le m). \]

This test has two guarantees.

  • If \(w\ge W_t^\infty\), the program is feasible.

By Lemma 1, take a benchmark-attaining assignment. Its bundles at type \(u\) belong to \(\mathcal C(c_t,(e_u/e_t)w)\). Replace each bundle by its convex combination from Lemma 3, multiplying the combination coefficients by the original mass. This preserves all type masses and supplies.

  • If the program is feasible, then \(W_t^\infty\le5w/4\).

A feasible solution is a valid mass assignment, and each of its bundles at type \(u\) satisfies

\[ \frac{e_t}{e_u}(c_t\cdot G) \le\frac54w. \]

Now test the geometric sequence

\[ w_{t,j}=a_t\left(\frac{17}{16}\right)^j, \qquad j=0,1,2,\ldots, \]

stopping at the first feasible test, with index \(j_t\). Define

\[ \widehat W_t=\frac54w_{t,j_t}. \]

The second guarantee gives \(W_t^\infty\le\widehat W_t\).

If \(j_t=0\), then \(w_{t,j_t}=a_t\le W_t^\infty\). Otherwise, the previous test was infeasible, so the first guarantee implies \(w_{t,j_t-1}<W_t^\infty\). Thus in either case,

\[ W_t^\infty \le\widehat W_t \le\frac54\frac{17}{16}W_t^\infty =\frac{85}{64}W_t^\infty. \]

No monotonicity of the generated linear programs is needed; the two guarantees suffice.

5. Computing the assignment

For every type \(t\), construct

\[ \mathcal H_t=\mathcal G(c_t,12\widehat W_t). \]

Solve the rational linear program

\[ x_{t,G}\ge0, \qquad \sum_{G\in\mathcal H_t}x_{t,G}=\mu_t \quad(t\in T), \]

\[ \sum_t\sum_{G\in\mathcal H_t}x_{t,G}G_k=s_k \quad(1\le k\le m). \]

This program is feasible. Indeed, Lemma 2 supplies an assignment whose type-\(t\) bundles cost at most \(12W_t^\infty\le12\widehat W_t\). Apply the convex-hull inclusion of Lemma 3 separately within each type to preserve its mass and expected bundle.

Return a rational feasible solution. It belongs to \(\mathcal Y(\mu,s)\), and every bundle it uses satisfies

\[ v_t(G) \le\frac54(12\widehat W_t) =15\widehat W_t \le\frac{1275}{64}W_t^\infty <20W_t^\infty. \]

6. Running time and output encoding

It remains to check that the algorithm is polynomial in the binary input length, rather than in numerical supplies or population denominators.

Let \(s_{\min}\) be the smallest positive supply. For every positive supply,

\[ \lceil s_k\rceil \le s_k\left(1+\frac1{s_{\min}}\right). \]

Zero supplies contribute zero to both benchmark bounds. Hence

\[ \frac{U_t}{a_t} \le\frac1{e_{\min}} \left(1+\frac1{s_{\min}}\right). \]

Every positive input rational is at least \(2^{-L}\), so

\[ \frac{U_t}{a_t} \le2^L(1+2^L) \le2^{2L+1}. \]

The geometric search therefore reaches \(U_t\), and must accept, after \(O(L)\) trials. Each trial value has polynomial binary length.

By Lemma 3, each benchmark test and the final assignment program have \(O(\tau m^4)\) variables and \(\tau+m\) equality constraints. Their coefficients have polynomial binary length: this applies both to rational capacities and to the possibly large integer bundle coordinates.

Standard polynomial-time algorithms for explicitly given rational linear programs decide feasibility and return rational feasible solutions of polynomial encoding length. Their hypotheses apply here because the programs are finite and explicitly constructed with rational data. The final output has at most \(O(\tau m^4)\) supported type-bundle pairs, each with a rational mass and binary-encoded integer bundle.

Thus the complete algorithm runs in \(\operatorname{poly}(m,\tau,L)\) and produces the required rational finite-support assignment.
