Conclusion and intended hypothesis

Yes. For CGS valuations, a deterministic polynomial-time algorithm suffices. Its output can be represented as a degenerate lottery.

I interpret the intended hypothesis as \(v_t\in\mathrm{CGS}\) for every type \(t\), as indicated by the two supplied references. The proof below also applies whenever every \(v_t\) is submodular; normalization and monotonicity alone do not supply this hypothesis.

1. The welfare objective is submodular

Define \(F:2^{[m]}\to\mathbb Q_{\ge0}\) by

\(F(S)=\sum_{t=1}^{\tau}\mu_t v_t(S).\)

Normalization means \(v_t(\varnothing)=0\), so \(F(\varnothing)=0\). Monotonicity of the valuations and positivity of the masses imply that \(F\) is monotone.

We use the standard theorem that gross substitutes valuations are submodular, stated in Section 2.5 of [Dughmi–Roughgarden–Yan](https://timroughgarden.org/papers/convex.pdf). In diminishing-returns form, submodularity of a function \(f\) means that, whenever \(A\subseteq B\subseteq[m]\) and \(j\notin B\),

\(f(A\cup\{j\})-f(A)\ge f(B\cup\{j\})-f(B).\)

Each CGS valuation is a finite nonnegative linear combination of gross substitutes valuations. Multiplying their diminishing-returns inequalities by the nonnegative coefficients and summing proves that each \(v_t\) is submodular. Multiplying these inequalities by \(\mu_t\) and summing proves that \(F\) is submodular.

Thus \(F\) satisfies normalization, monotonicity, and submodularity.

2. The supplied oracle gives exact set values

For any type \(t\) and set \(R\subseteq[m]\), query its bounded-lottery-value oracle with \(x=(0,\ldots,0)\) and \(b=1\).

These parameters are permitted because \(\sum_jx_j=0\le1\) and \(m\ge1\). The draw chooses nothing with probability one, so \(A=\varnothing\) almost surely. The oracle therefore returns

\(\mathbb E[v_t(R\cup A)]=v_t(R).\)

Consequently, an exact evaluation of \(F(R)\) requires \(\tau\) oracle calls and exact rational arithmetic.

3. Algorithm

If \(k=0\), output the lottery concentrated on \(\varnothing\). Its welfare and the optimum are both zero.

Otherwise, set \(S_0=\varnothing\). For each \(i=0,\ldots,k-1\), choose

\(j_i\in\operatorname*{arg\,max}_{j\in[m]\setminus S_i}\bigl(F(S_i\cup\{j\})-F(S_i)\bigr),\)

breaking ties by project index, and set \(S_{i+1}=S_i\cup\{j_i\}\).

Output \(D=\delta_{S_k}\), the lottery assigning probability one to \(S_k\). Since exactly one new project is added per iteration, \(|S_k|=k\), so the output is feasible.

4. Approximation proof

This is the classical cardinality-constrained greedy guarantee of [Nemhauser–Wolsey–Fisher](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf). Here is a direct proof.

Let \(O\) maximize \(F\) over feasible sets, and write \(\mathrm{OPT}=F(O)\). Such a set exists because the feasible family is finite.

Fix an iteration \(i<k\), and define

\(\Delta_i=\max_{j\notin S_i}\bigl(F(S_i\cup\{j\})-F(S_i)\bigr).\)

Enumerate \(O\setminus S_i=\{a_1,\ldots,a_q\}\), where \(q\le k\). Telescoping and diminishing returns give

\(F(S_i\cup O)-F(S_i)=\sum_{\ell=1}^{q}\bigl(F(S_i\cup\{a_1,\ldots,a_\ell\})-F(S_i\cup\{a_1,\ldots,a_{\ell-1}\})\bigr)\le\sum_{\ell=1}^{q}\bigl(F(S_i\cup\{a_\ell\})-F(S_i)\bigr)\le k\Delta_i.\)

The last inequality uses \(q\le k\) and \(\Delta_i\ge0\), which follows from monotonicity. Also, monotonicity gives \(F(O)\le F(S_i\cup O)\). Hence

\(\mathrm{OPT}-F(S_i)\le k\Delta_i.\)

The greedy choice satisfies \(F(S_{i+1})-F(S_i)=\Delta_i\). Therefore

\(\mathrm{OPT}-F(S_{i+1})\le\left(1-\frac1k\right)\bigl(\mathrm{OPT}-F(S_i)\bigr).\)

Iterating this inequality from \(F(S_0)=0\) yields

\(F(S_k)\ge\left[1-\left(1-\frac1k\right)^k\right]\mathrm{OPT}.\)

Since \(1-u\le e^{-u}\) for \(u\ge0\), we have \((1-1/k)^k\le e^{-1}\), including when \(k=1\). Thus

\(\mathbb E_{S\sim D}[F(S)]=F(S_k)\ge(1-1/e)\mathrm{OPT}.\)

5. Oracle and bit complexity

At iteration \(i\), evaluate \(F(S_i\cup\{j\})\) for all \(m-i\) available projects. Cache the selected value as \(F(S_{i+1})\); \(F(S_0)=0\) is known from normalization. The number of oracle calls is therefore at most

\(\tau\sum_{i=0}^{k-1}(m-i)=\tau\left(km-\frac{k(k-1)}2\right)\le\tau km.\)

Every query uses only zero probabilities, \(b=1\), and a set encoded with \(m\) bits.

The masses and returned set values have bit lengths bounded by \(L\). Each product \(\mu_t v_t(R)\) has bit length \(O(L)\). Summing \(\tau\) such products using a product of their denominators gives numerator and denominator lengths \(O(\tau L+\log\tau)\). Exact additions, subtractions, and comparisons therefore require polynomially many bit operations.

There are at most \(km\) candidate evaluations, so total bit complexity is \(\operatorname{poly}(m,\tau,k,L)\). The lottery’s sampling algorithm simply returns the stored set \(S_k\).

This proves the requested guarantee in deterministic polynomial time, and hence also in expected polynomial time.
