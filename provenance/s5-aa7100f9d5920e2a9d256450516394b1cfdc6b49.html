The anchor (named result in the paper)

Theorem 5 — class: algorithmic

The continuous mirror question, as graded

Given a finite set of types \(T\), non-atomic valuation measures \(V_t\), rational masses \(\mu_t\), and \(\epsilon\in(0,1)\), can one produce a single succinct allocation rule for every compatible population size \(N\), where \(N\mu_t\in\mathbb{Z}\)? For each type \(t\) and clone rank \(j\in\{1,\ldots,N\mu_t\}\), the rule returns a finite union of cake intervals; the bundles must be pairwise disjoint, exactly envy-free for all clones, and satisfy \(V_t(X_{t,j})\geq (1-\epsilon)/N\). Require the rule description and its shared type-level valuation-query cost to be polynomial in \(|T|\), the bit length of \(\mu\), and \(\log(1/\epsilon)\), independent of \(N\).

Packaged proof task (what the prover saw — nothing else)

The cake is \([0,1]\); free disposal is allowed. Each type \(t\) has a nonnegative, additive valuation measure \(V_t\), absolutely continuous with respect to length and normalized by \(V_t([0,1])=1\).
A society is given by its support: the list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total bit length of the masses and the binary-rational input \(\epsilon\in(0,1)\); there is one resource, so \(m=1\).
Valuations are accessible through exact Robertson–Webb queries to types. Use unit-cost exact-real arithmetic and comparisons; stored oracle answers count as individual registers in a rule description.
A construction independent of population size produces a finite program \(R\) with stored query answers. Given any integer \(N\geq2\) satisfying \(N\mu_t\in\mathbb Z\) for every type, and \(1\leq j\leq N\mu_t\), the program terminates and explicitly returns a finite union of intervals \(X_{t,j}\), without further valuation queries. Endpoint ownership must make bundles disjoint.
For each fixed compatible \(N\), all bundles are pairwise disjoint and satisfy \(V_t(X_{t,j})\geq V_t(X_{s,k})\) for every pair of clones, and \(V_t(X_{t,j})\geq(1-\epsilon)/N\). Ties are allowed. Evaluation time may depend on \(N\) and output length; express its bound in \(m,\tau,L,\log(1/\epsilon),\log N\) and output length.
Can the \((1-\epsilon)/N\) guarantee with exact envy-freeness be attained by such a uniform rule whose description size and shared construction-query cost are \(\operatorname{poly}(m,\tau,L,\log(1/\epsilon))\), independent of \(N\), or is this polynomial bound unattainable?
For a finite population of \(n\) agents, the same guarantee is achievable with \(O(4^n\log(1/\epsilon))\) cuts and \(O(n4^n\log(1/\epsilon))\) queries. [Segal-Halevi, Hassidim and Aumann](https://arxiv.org/pdf/1511.02599)
Exact envy-free proportional partial allocations for finite populations are also computable with at most \(n^3(n^2)^n\) queries. [Aziz and Mackenzie](https://arxiv.org/abs/1604.03655) Neither result supplies a single rule for all compatible population sizes; no result settling this uniform oracle formulation was located.

Modeling choices made when packaging the task

  • Strengthened non-atomicity to absolute continuity with respect to length and imposed nonnegative, additive, normalized valuations, following the discrete model.
  • Normalized the positive rational masses to sum to one and required compatible integer population sizes of at least two.
  • Specified binary-rational epsilon and included its encoding length in L.
  • Interpreted shared valuation-query cost as construction-time queries: the compiled rule stores their answers and makes no further valuation queries when evaluated.
  • Defined succinct descriptions as finite programs with exact-real registers, using unit-cost exact arithmetic and comparisons; evaluation must terminate but need not have an N-independent running time.
  • Allowed valuation ties and assigned interval endpoints consistently to ensure literal disjointness.
  • Set m=1 because the resource is a single cake rather than a candidate or item set.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result. The polynomial bound is unattainable. In fact, no finite construction using Robertson–Webb queries can produce the required uniform rule, regardless of its description size or evaluation time.

The obstruction already occurs for \(m=\tau=1\), with \(\mu_1=1\). This is a substantive obstruction: finitely many queries cannot support exact envy-free subdivision into arbitrarily many positive-valued bundles without further queries. The same obstruction also applies to larger supports.

2. What a finite transcript determines. Write \(\lambda\) for length measure. Suppose, towards a contradiction, that the required construction exists. Fix \(\epsilon=1/2\), and run the construction for the single type with valuation \(V=\lambda\).

Let \(Q\) be the finite number of construction queries. Collect \(0,1\), every endpoint appearing in an evaluation query, and every starting endpoint and returned endpoint of a cut query. List the distinct collected points as

\(0=b_0<b_1<\cdots<b_K=1.\)

Define the open cells \(I_\ell=(b_{\ell-1},b_\ell)\), for \(1\leq\ell\leq K\). Under the usual interval Robertson–Webb queries, \(K\leq 2Q+1\).

We first establish an indistinguishability property. Let \(h\) be any bounded measurable function satisfying

\(\displaystyle \int_{I_\ell}h(x)\,dx=0\qquad\text{for every }\ell.\)

For any positive \(\delta\) such that \(1+\delta h\) is strictly positive, define

\(\displaystyle W(A)=\int_A(1+\delta h(x))\,dx.\)

This is a nonnegative, absolutely continuous, normalized valuation: summing the zero-integral conditions gives \(W([0,1])=1\).

Moreover, the construction receives exactly the same transcript under \(W\) as under \(\lambda\):

  • Every queried evaluation interval has endpoints among the \(b_\ell\), so its integral of \(h\) is zero. Its answer is therefore unchanged.
  • For a cut query with starting point \(a\), target value \(\alpha\), and original answer \(c\), both \(a\) and \(c\) are collected endpoints. Consequently, \(W([a,c])=\lambda([a,c])=\alpha\). Strict positivity of the density makes the cumulative valuation strictly increasing, so \(c\) remains the unique cut answer.

For adaptive queries, these statements apply inductively: identical previous answers give the same next query, whose answer is again identical. Thus the resulting program and its stored data are identical.

In particular, because evaluation uses no further valuation queries, it returns the same bundles under all these indistinguishable valuations.

3. Exact envy-freeness forces whole-cell allocation. Fix any population size \(N\geq2\), and let \(X_1,\ldots,X_N\) be the program’s outputs. They are measurable because each is a finite union of intervals.

Under \(\lambda\), exact envy-freeness among clones of the same type implies

\(\lambda(X_j)=\lambda(X_k)\qquad\text{for all }j,k.\)

Indeed, applying envy-freeness in both directions gives both inequalities.

We claim that each indicator \(f_j=\mathbf{1}_{X_j}\) must be constant almost everywhere on every cell \(I_\ell\).

Suppose otherwise. Then, for some \(j\) and cell \(I\), both \(X_j\cap I\) and \(I\setminus X_j\) have positive length. Choose any \(k\neq j\), and put \(g=f_j-f_k\).

Disjointness implies that \(g=1\) on \(X_j\cap I\). On \(I\setminus X_j\), it takes values only in \(\{0,-1\}\). Hence \(g\) is not constant almost everywhere on \(I\).

Define its mean on that cell by

\(\displaystyle \bar g=\frac{1}{\lambda(I)}\int_I g(x)\,dx,\)

and define \(h=g-\bar g\) on \(I\), with \(h=0\) outside \(I\). Then \(h\) has integral zero on every cell. Also, \(|h|\leq2\). Taking \(\delta=1/4\) gives a density \(1+\delta h\geq1/2\), so the indistinguishability argument applies.

For the resulting valuation \(W\), compute

\(\displaystyle W(X_j)-W(X_k)=\int_0^1 g(x)\,dx+\delta\int_I g(x)(g(x)-\bar g)\,dx.\)

The first integral is zero because \(\lambda(X_j)=\lambda(X_k)\). For the second, the definition of \(\bar g\) gives

\(\displaystyle \int_I g(x)(g(x)-\bar g)\,dx=\int_I(g(x)-\bar g)^2\,dx>0.\)

The strict inequality follows because \(g\) is not constant almost everywhere on \(I\). Therefore \(W(X_j)>W(X_k)\).

The construction and program outputs are unchanged under \(W\), but clone \(k\) now envies clone \(j\). This contradicts the required correctness for every admissible valuation, and proves the claim.

Thus, up to null sets, each bundle is a union of entire transcript cells. This conclusion concerns the actual allocated sets; allowing the program to compute new endpoints by exact arithmetic does not evade it.

4. Contradiction for an unbounded population. Under the original uniform valuation, the proportionality requirement gives

\(\displaystyle \lambda(X_j)\geq\frac{1}{2N}>0\qquad\text{for every }j.\)

Because each bundle is a union of whole cells up to null sets, every clone must receive at least one cell. Pairwise disjointness prevents two clones from receiving the same cell. Consequently,

\(N\leq K.\)

But the construction was independent of population size, so its transcript and \(K\) are fixed. With \(\mu_1=1\), every integer population size is compatible. Choosing \(N=K+1\) contradicts the necessary inequality.

Endpoint ownership cannot affect this argument: all admissible valuations assign zero value to the finite set of cell endpoints.

5. Larger supports and complexity consequences. The obstruction also persists for any fixed positive binary-rational masses. Choose one type \(t\) with uniform valuation and leave all other valuations fixed. Form the cells from the endpoints of queries to type \(t\). Perturbing only that valuation as above preserves its answers; every other type’s answers remain unchanged. Induction again preserves the entire construction transcript.

For a fixed compatible population, envy-freeness between the \(N\mu_t\) clones of type \(t\) forces their bundles to be unions of those cells. Their positive proportional guarantees then imply \(N\mu_t\leq K_t\), where \(K_t\) is the number of cells for type \(t\).

Compatible populations are unbounded: a common denominator \(D\) of the masses makes every sufficiently large integer multiple of \(D\) compatible. Since \(\mu_t>0\), eventually \(N\mu_t>K_t\), giving the same contradiction.

Thus the impossibility is independent of any evaluation-time restriction. Allowing arbitrarily large finite running time or output length cannot repair the missing valuation information. There is therefore no evaluation-time bound in the requested parameters for a rule satisfying the specification.

This is consistent with the cited finite-population results: [Segal-Halevi, Hassidim and Aumann](https://arxiv.org/abs/1511.02599) obtain envy-free partial allocations approaching proportionality, while [Aziz and Mackenzie](https://arxiv.org/abs/1604.03655) obtain proportional envy-free partial allocations. Their constructions query valuations for the chosen finite population. Here the contradiction uses the requirement that one completed finite transcript support every compatible population size.
