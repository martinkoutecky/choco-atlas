The continuous mirror question, as graded

Given the fixed signal model, a focal voter’s signal \(w\), an effective peer scale \(M\), and rational masses \((\mu_0,\mu_1)\) over peers’ first-round votes with \(\mu_0+\mu_1=1\), compute the second-round posterior log-odds \(Y=x(w)+M\sum_{h\in\{0,1\}}\mu_h\log\!\left(p_1(h)/p_0(h)\right)\) and return vote \(1\) if \(Y>0\), and \(0\) otherwise. Here \(p_s(h)\) is the probability of a peer’s first-round vote \(h\) given state \(s\); integer counts \(M\mu_h\) recover the finite-panel likelihood, while rational masses define its mass-weighted extension.

The state \(S\in\{0,1\}\) has uniform prior; conditional on \(S=s\), private signals are independent with law \(Q_s\). Define \(x(w)=\log(dQ_1/dQ_0)(w)\), require finite likelihood ratios on admissible inputs, and assume the distribution of \(x(W)\) under \((Q_0+Q_1)/2\) is non-atomic.
A first-round vote is \(H=1\) exactly when \(x(W)>0\), and is \(0\) otherwise. Define \(p_s(h)=\Pr(H=h\mid S=s)\); assume \(0<p_s(h)<1\) for both states and votes.
A society is given by its support: the list of the \(\tau\) vote types with positive mass, each mass a binary rational. Here types are \(h\in\{0,1\}\), absent types have mass zero, and \(\mu_0+\mu_1=1\); \(\tau\) is the support size, not the number of possible types.

Binary input reading is charged; let \(L\) be the total input bit length and \(m=2\) the number of alternatives.

Result

The specified computation is polynomial-time solvable in the exact oracle arithmetic model. More precisely, it takes \(O(L+\tau)\) operations, including input reading. This bound covers arbitrary admissible rational masses and scales, including noninteger values of \(M\mu_h\).

Here \(m=2\) and \(1\leq\tau\leq2\), so the bound is polynomial in all the requested parameters.

Recovering the vote probabilities

Define the conditional cumulative distribution functions by

\(F_s(a)=Q_s(\{w:x(w)\leq a\})\), for \(s\in\{0,1\}\).

Since the first-round rule assigns vote \(0\) exactly when \(x(W)\leq0\), we have

\(p_s(0)=F_s(0)\), and \(p_s(1)=1-F_s(0)\).

Thus two conditional-CDF oracle calls determine all four vote probabilities exactly.

The assumed inequalities \(0<p_s(h)<1\) ensure that every ratio \(p_1(h)/p_0(h)\) is positive and finite. Consequently, every logarithm used below is defined and finite.

These identities also handle the specified first-round tie rule exactly. Non-atomicity is not needed for their validity.

Algorithm and correctness

Let \(T\subseteq\{0,1\}\) be the supplied support, so \(|T|=\tau\). Execute the following steps:

  • Read the input and decode its rational numbers exactly.
  • Evaluate \(x(w)\), \(F_0(0)\), and \(F_1(0)\).
  • Initialize \(A=0\). For every listed pair \((h,\mu_h)\), update

\(A\leftarrow A+\mu_h\log(p_1(h)/p_0(h))\).

  • Compute \(Y=x(w)+MA\).
  • Return \(1\) if \(Y>0\), and return \(0\) otherwise.

After processing any initial portion \(T'\) of the support list, the accumulator satisfies

\(A=\sum_{h\in T'}\mu_h\log(p_1(h)/p_0(h))\).

This follows by induction: initialization gives the empty sum, and each update adds exactly the next summand. At termination, absent types have mass zero, so

\(A=\sum_{h\in\{0,1\}}\mu_h\log(p_1(h)/p_0(h))\).

Step 4 therefore computes precisely the quantity required in the question. The exact comparison in step 5 implements the prescribed decision, including returning \(0\) when \(Y=0\).

No integrality assumption enters this argument. It also covers \(M=0\), when \(Y=x(w)\).

Complexity

Input reading costs \(O(L)\). Binary-encoded integers can be decoded exactly with one update \(z\leftarrow2z+b\) per bit \(b\). For numerator-and-denominator rational encodings, one additional division produces each rational value. Thus decoding takes \(O(L)\) operations under the stipulated arithmetic model.

There is one signal-likelihood evaluation and two conditional-CDF evaluations. Each support entry requires a constant number of arithmetic operations and one logarithm. Computing the final value and comparing it with zero also take constant time. Hence the total cost is

\(O(L+\tau)\).

In particular, a large binary-encoded scale \(M\) does not require iteration over \(M\) peers. Multiplication by \(M\) is one exact arithmetic operation in this model. Exact comparison also removes any need for a numerical separation bound when \(Y\) is close to zero.

Relation to finite societies

For integer peer counts \(N_h=M\mu_h\), conditional independence gives the probability of an ordered peer-vote list under state \(s\) as

\(\prod_{h\in\{0,1\}}p_s(h)^{N_h}\).

Its likelihood ratio is therefore

\(\prod_{h\in\{0,1\}}(p_1(h)/p_0(h))^{N_h}\),

whose logarithm is \(\sum_hN_h\log(p_1(h)/p_0(h))\). If only the counts are observed, the multinomial coefficient is identical under both states and cancels. This recovers the finite-peer contribution in the question.

Mossel and Tamuz’s Theorem 1.7 establishes their finite-society \(O(nt)\) algorithm under constant-time likelihood and conditional-CDF evaluation. [Making Consensus Tractable](https://tamuz.caltech.edu/papers/consensus.pdf)

For noninteger weights, the present task directly specifies the weighted log-odds formula. The algorithm above proves its tractability independently of whether those weights admit a finite-peer probabilistic interpretation.

The conclusion concerns the stated oracle model; it does not assert polynomial bit complexity for implementing the real-valued oracles. Polynomial-time membership also does not, by itself, unconditionally exclude NP-hardness under every possible reduction convention. It fully settles the requested computational upper bound.
