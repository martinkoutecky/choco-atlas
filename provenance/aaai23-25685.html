The continuous mirror question, as graded

Given candidates C, a rational distribution μ over complete rankings of C, and a designated candidate d, does there exist a sequential Baldwin elimination in which each round removes a minimum weighted-Borda-score candidate and d is the last remaining candidate?

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\), explicitly listed complete ranking types \(T\subseteq L(C)\), and binary-encoded rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), let \(S\subseteq C\) be the surviving candidates. For \(c\in S\), define its Borda score as \(\sum_{t\in T}\mu_t\bigl(|S|-\operatorname{pos}_{t|S}(c)+1\bigr)\).

A Sequential-Borda-Loser elimination is legal if, at each round, it removes any surviving candidate of minimum current Borda score, then restricts every ranking to the survivors. Given \(d\in C\), ask whether some legal elimination sequence leaves \(d\) as the sole final survivor.

Target. Is this rational-mass Sequential-Borda-Loser winner-determination problem solvable in polynomial time, or is it NP-hard?

Nearest known results. In the discrete setting, Sequential-Borda-Loser winner determination is NP-complete even when the number of voters is any fixed even \(n\ge 8\); consequently, the unrestricted discrete problem is NP-hard.

Rational-Mass Sequential-Borda-Loser Complexity

Theorem

Rational-mass Sequential-Borda-Loser winner determination is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard even when there are at most eight ranking types and every mass is an integer multiple of \(1/8\).

The hardness statement uses the given premise that discrete Sequential-Borda-Loser winner determination is \(\mathrm{NP}\)-complete for every fixed even number \(n\geq 8\) of voters.

1. Reduction from the discrete problem

Fix \(n=8\). Consider a discrete instance consisting of:

  • a candidate set \(C\);
  • eight complete rankings \(t_1,\ldots,t_8\), with repetitions allowed;
  • a distinguished candidate \(d\in C\).

For every distinct ranking \(t\) occurring among these eight ballots, let

\[ k_t=\left|\{i\in\{1,\ldots,8\}:t_i=t\}\right|. \]

Construct the rational-mass instance with the same candidate set and distinguished candidate, ranking-type set

\[ T=\{t_i:i\in\{1,\ldots,8\}\}, \]

and masses

\[ \mu_t=\frac{k_t}{8}. \]

These masses are nonnegative and satisfy

\[ \sum_{t\in T}\mu_t = \frac{1}{8}\sum_{t\in T}k_t = 1. \]

The construction is polynomial-time. Indeed, there are at most eight types, and every mass has a constant-size denominator.

2. Preservation of every elimination step

For a surviving set \(S\subseteq C\), define the positive-base discrete Borda score

\[ B^{\mathrm{disc},+}_S(c) = \sum_{i=1}^{8} \left( |S|-\operatorname{pos}_{t_i|S}(c)+1 \right). \]

The mass score in the constructed instance is

\[ \begin{aligned} B^\mu_S(c) &= \sum_{t\in T} \frac{k_t}{8} \left( |S|-\operatorname{pos}_{t|S}(c)+1 \right)\\ &= \frac{1}{8} B^{\mathrm{disc},+}_S(c). \end{aligned} \]

Consequently, for all \(c,c'\in S\),

\[ B^\mu_S(c)\leq B^\mu_S(c') \quad\Longleftrightarrow\quad B^{\mathrm{disc},+}_S(c) \leq B^{\mathrm{disc},+}_S(c'). \]

Thus the minimum-score candidates are exactly the same in both instances for every possible surviving set \(S\).

If the cited discrete theorem uses the conventional zero-based Borda score

\[ B^{\mathrm{disc},0}_S(c) = \sum_{i=1}^{8} \left( |S|-\operatorname{pos}_{t_i|S}(c) \right), \]

then

\[ B^{\mathrm{disc},+}_S(c) = B^{\mathrm{disc},0}_S(c)+8. \]

The added quantity \(8\) is independent of \(c\), so it also leaves the set of minimum-score candidates unchanged.

By induction on the number of elimination rounds, an elimination sequence is legal in the discrete instance if and only if it is legal in the constructed mass instance. Therefore,

\[ d\text{ can be the final survivor in the discrete instance} \quad\Longleftrightarrow\quad d\text{ can be the final survivor in the mass instance}. \]

This is a polynomial-time many-one reduction. Hence the rational-mass problem is \(\mathrm{NP}\)-hard.

3. Membership in \(\mathrm{NP}\)

Let \(m=|C|\). A certificate is an ordering

\[ (c_1,\ldots,c_{m-1}) \]

of \(C\setminus\{d\}\), interpreted as the proposed elimination sequence.

At round \(j\), let

\[ S_j=C\setminus\{c_1,\ldots,c_{j-1}\}. \]

The verifier checks that, for every \(x\in S_j\),

\[ B^\mu_{S_j}(c_j)\leq B^\mu_{S_j}(x). \]

Positions in every restricted ranking can be computed by scanning the explicitly listed ranking. It remains to justify that the rational comparisons are polynomial-time exact computations.

Write each input mass as

\[ \mu_t=\frac{a_t}{b_t}, \]

where \(a_t,b_t\) are binary-encoded integers and \(b_t>0\). Let

\[ D=\prod_{t\in T}b_t. \]

Its bit length satisfies

\[ \log D=\sum_{t\in T}\log b_t, \]

which is at most linear in the total encoding length of the masses. Multiplying a score comparison by \(D>0\) reduces it to comparison of binary integers:

\[ D\left(B^\mu_{S_j}(x)-B^\mu_{S_j}(c_j)\right) = \sum_{t\in T} a_t\frac{D}{b_t} \left( \operatorname{pos}_{t|S_j}(c_j) - \operatorname{pos}_{t|S_j}(x) \right). \]

Every position difference has absolute value at most \(m-1\), and all integers in this expression have polynomial bit length. Standard binary integer arithmetic therefore verifies each comparison in polynomial time. There are only polynomially many rounds and comparisons.

Thus the problem belongs to \(\mathrm{NP}\).

Conclusion

The rational-mass formulation does not make possible-winner determination polynomial-time: the fixed-eight-voter discrete instances embed exactly after normalization. Together with membership in \(\mathrm{NP}\), this proves \(\mathrm{NP}\)-completeness. Consequently, a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).
