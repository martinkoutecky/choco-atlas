The continuous mirror question, as graded

Given finitely many types \(T\) with positive rational masses \(\mu_t\) summing to \(1\), positive rational singleton-worth rates \(a_t\), and rational grand worth per capita \(g\), compute an efficient type-level payoff \(x\), with \(\sum_{t\in T}\mu_t x_t=g\), that maximizes \(\min_{0<q\le\mu}\frac{\sum_{t\in T}q_t x_t}{\sum_{t\in T}q_t a_t}\). Here \(q\) ranges over the masses of all nonzero measurable coalitions. The question is whether this continuous population allocation has the same optimizer as the paper’s optimistic satisfaction problem.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has a positive binary-rational singleton-worth rate \(a_t\); the grand worth per capita is \(g\in\mathbb Q\), with either sign allowed. Let \(L\) be the total input bit length. There is no separate parameter \(m\); running times are measured in \(\tau\) and \(L\).
Each type consists of an atomless population. A measurable coalition is represented by any \(q\in\mathbb R^T\) satisfying \(0\le q_t\le\mu_t\) for every \(t\) and \(\sum_t q_t>0\); zero coordinates and the grand coalition are allowed.
A payoff assigns a real per-capita amount \(x_t\) uniformly to each type. Feasibility requires only \(\sum_t\mu_t x_t=g\), with no nonnegativity or individual-rationality constraint.
Define \(F(x)=\min_{\substack{0\le q_t\le\mu_t\ (t\in T)\\\sum_tq_t>0}}\frac{\sum_tq_tx_t}{\sum_tq_ta_t}\). The computational problem is to output an exact maximizing feasible payoff.

Is this exact allocation problem solvable in polynomial time in \(\tau\) and \(L\), or is it NP-hard? Does its optimizer set consist exactly of the payoff \(x_t=\frac{g a_t}{\sum_s\mu_s a_s}\) for every \(t\in T\)?

For finite TU-games with positive singleton worths, the unique efficient payoff lexicographically maximizing the sorted optimistic coalition satisfactions \(\frac{\sum_{i\in S}y_i}{\sum_{i\in S}v(\{i\})}\) is \(y_i=\frac{v(N)v(\{i\})}{\sum_jv(\{j\})}\). Result

The problem is solvable exactly in polynomial time in \(\tau\) and \(L\). Its optimizer set consists of exactly the stated proportional payoff, for every sign of \(g\).

The proof uses the coalition and feasibility definitions directly; the cited finite-game theorem is not needed.

1. Evaluating the coalition minimum

Fix any payoff \(x\), and define \(r_t=x_t/a_t\). This is well-defined because \(a_t>0\).

For every admissible coalition \(q\), its denominator \(\sum_tq_ta_t\) is positive, and its satisfaction equals

\(\displaystyle \frac{\sum_tq_tx_t}{\sum_tq_ta_t}=\sum_t\lambda_t r_t,\qquad \lambda_t=\frac{q_ta_t}{\sum_sq_sa_s}.\)

Here \(\lambda_t\geq0\) and \(\sum_t\lambda_t=1\). Thus every coalition satisfaction is a weighted average of the \(r_t\), so it is at least \(\min_t r_t\). This inference holds even when some or all ratios are negative.

Conversely, choose a type \(t_0\) attaining that minimum. The coalition with \(q_{t_0}=\mu_{t_0}\) and all other coordinates zero is admissible, since \(\mu_{t_0}>0\). Its satisfaction is \(r_{t_0}\).

Consequently, the minimum is attained and

\(\displaystyle F(x)=\min_{t\in T}\frac{x_t}{a_t}.\)

2. Optimal value and uniqueness

Let \(A=\sum_t\mu_ta_t\). All summands are positive, hence \(A>0\). Define \(w_t=\mu_ta_t/A\); then every \(w_t>0\) and \(\sum_tw_t=1\).

For any feasible payoff, efficiency gives

\(\displaystyle \sum_tw_t\frac{x_t}{a_t}=\frac{\sum_t\mu_tx_t}{A}=\frac{g}{A}.\)

The minimum of finitely many real numbers cannot exceed their weighted average. Therefore

\(\displaystyle F(x)\leq\frac{g}{A}.\)

Now define \(x_t^*=ga_t/A\). It is feasible because

\(\displaystyle \sum_t\mu_tx_t^*=\frac{g}{A}\sum_t\mu_ta_t=g.\)

Every ratio \(x_t^*/a_t\) equals \(g/A\), so \(F(x^*)=g/A\). This proves optimality.

To prove uniqueness, suppose \(x\) is any optimizer. Then \(F(x)=g/A\), and the formula from Section 1 implies \(x_t/a_t\geq g/A\) for every type. Moreover,

\(\displaystyle \sum_tw_t\left(\frac{x_t}{a_t}-\frac{g}{A}\right)=0.\)

Every summand is nonnegative, and every weight is strictly positive. Therefore every difference is zero. Hence \(x_t=ga_t/A\) for all \(t\).

No step assumes \(g\geq0\), so this proves uniqueness also when \(g=0\) or \(g<0\).

3. Exact polynomial-time computation

Under the standard binary encoding of rationals, write \(\mu_t=u_t/v_t\), \(a_t=p_t/d_t\), and \(g=h/k\), with positive denominators. Set

\(\displaystyle D=\prod_t v_td_t,\qquad P=\sum_tu_tp_t\frac{D}{v_td_t}.\)

Each quotient in this sum is an integer, \(P>0\), and \(A=P/D\). The algorithm outputs the exact rational coordinates

\(\displaystyle x_t^*=\frac{hp_tD}{kd_tP}.\)

The bit length of \(D\) is bounded by the sum of the input denominator bit lengths, hence is \(O(L)\). Each summand defining \(P\) has \(O(L)\) bits; summing \(\tau\) such integers gives \(O(L+\log\tau)\) bits. Each output numerator and denominator has the same polynomial bit bound.

Computing these expressions requires polynomially many integer additions, multiplications, and exact divisions on integers of polynomial bit length. Standard integer arithmetic therefore gives polynomial running time in \(\tau\) and \(L\), including writing the entire output. Optional fraction reduction by greatest common divisors also takes polynomial time.

Thus both the computational question and the optimizer-set question are fully resolved.
