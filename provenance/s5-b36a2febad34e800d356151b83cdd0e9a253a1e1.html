The continuous mirror question, as graded

Given \(k\) Boolean base events, supported order types \(t\) with rational masses \(\mu_t>0\), and each type’s order parameters, determine whether there is a nonzero accepted-mass vector \(x\) with \(0\le x_t\le\mu_t\) such that \(\sum_t x_t a_t(\omega)\ge 0\) for every state \(\omega\in\{0,1\}^k\), where \(a_t(\omega)=-q_t\mathbf{1}_{\omega\in\psi_t}(\mathbf{1}_{\omega\in\phi_t}-p_t)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) order types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=k\) Boolean base events, with every state \(\omega\in\{0,1\}^m\) possible. Each type supplies explicitly encoded Boolean formulas \(\phi_t,\psi_t\), a binary-rational quantity \(q_t\ne0\), and a binary-rational price \(p_t\in[0,1]\); positive quantities denote purchases and negative quantities sales.
A conditional security pays one unit when both formulas hold, zero when only \(\psi_t\) holds, and cancels with a price refund when \(\psi_t\) fails. The auctioneer's surplus per unit of accepted type mass is \(a_t(\omega)=-q_t\mathbf1_{\psi_t(\omega)}(\mathbf1_{\phi_t(\omega)}-p_t)\).
Decide whether there exists \(x\in\mathbb R^\tau\) with \(0\le x_t\le\mu_t\), \(\sum_t x_t>0\), and \(\sum_t x_ta_t(\omega)\ge0\) for every state; breaking even is allowed. Let \(L\) be the total binary input length, including formulas; state running times in \(m,\tau,L\).

Is this accepted-mass decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

Indivisible-order matching is \(\mathrm{NP}\)-complete with \(m=O(\log L)\) and \(\Sigma_2^p\)-complete with unrestricted \(m\). Divisible-order matching is polynomial-time solvable in the former regime and \(\mathrm{coNP}\)-complete in the latter; the mass formulation is exactly this already classified divisible problem. [Fortnow–Kilian–Pennock–Wellman](https://lance.fortnow.com/papers/files/logicalsecurities.pdf)

Modeling choices made when packaging the task

  • Normalize masses to sum to one, following the distribution-over-types interpretation.
  • Encode events as explicit Boolean formulas and all numerical order parameters as binary rationals.
  • Exclude zero quantities, which would otherwise permit a vacuous nonzero acceptance; allow both buy and sell orders.
  • Choose prices in the natural unit-security range [0,1], since the supplied definition does not specify a price domain.
  • Allow real accepted masses and nonnegative surplus, including exact break-even.
  • Keep the graded question's unrestricted number of base events; identify m with k and define L as total input length.

Classification

For unrestricted \(m\), the accepted-mass decision problem is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions, even when \(\tau=1\). It admits a deterministic algorithm running in
\[ 2^{O(m)}\operatorname{poly}(\tau,L), \]
and therefore belongs to \(\mathrm P\) when \(m=O(\log L)\).

Consequently, “in \(\mathrm P\) or \(\mathrm{NP}\)-hard” needs a reduction convention. Under many-one reductions, the unrestricted problem is \(\mathrm{NP}\)-hard if and only if \(\mathrm{NP}=\mathrm{coNP}\). Under polynomial-time Turing reductions, it is unconditionally \(\mathrm{NP}\)-hard.

Here is a proof directly for the stated formulation.

1. Removing the positive mass caps

Write \(A_{\omega t}=a_t(\omega)\). All surplus inequalities are homogeneous in the accepted masses.

Lemma. The requested acceptance vector exists if and only if there is a vector \(y\) satisfying
\[ y_t\ge0,\qquad \sum_{t=1}^{\tau}y_t=1,\qquad \sum_{t=1}^{\tau}y_ta_t(\omega)\ge0 \quad\text{for every }\omega. \]

Proof. Given an accepted vector \(x\), let \(s=\sum_t x_t>0\) and put \(y=x/s\). Nonnegativity of every surplus is preserved by this positive scaling.

Conversely, given such a \(y\), define
\[ c=\min_{\{t:y_t>0\}}\frac{\mu_t}{y_t}. \]
The indexing set is nonempty because \(\sum_t y_t=1\). Every indexed ratio is positive because every \(\mu_t>0\); hence \(c>0\). Set \(x=cy\). Then \(0\le x_t\le\mu_t\), \(\sum_t x_t=c>0\), and every surplus remains nonnegative. \(\square\)

Thus the positive mass caps affect the permissible scale, but not existence. The normalization above also removes the strict constraint \(\sum_t x_t>0\) without imposing any positive-surplus requirement.

To identify the divisible-order formulation exactly, set
\[ \alpha_t=\frac{x_t}{\mu_t}, \qquad Q_t=\mu_tq_t. \]
Then \(0\le\alpha_t\le1\), and the surplus becomes
\[ -\sum_t\alpha_tQ_t\mathbf1_{\psi_t(\omega)} \bigl(\mathbf1_{\phi_t(\omega)}-p_t\bigr). \]
At least one \(\alpha_t\) must be positive. This is precisely the divisible matching formulation in Definition 2 of [Fortnow–Kilian–Pennock–Wellman](https://lance.fortnow.com/papers/files/logicalsecurities.pdf).

2. Deterministic algorithm and running time

Enumerate all \(2^m\) states, evaluate every supplied formula, and construct the feasibility problem from the lemma.

It has \(\tau\) variables, \(2^m\) surplus inequalities, \(\tau\) nonnegativity inequalities, and one normalization equality. Each coefficient is one of
\[ 0,\qquad q_tp_t,\qquad -q_t(1-p_t), \]
so its rational encoding length is \(O(L)\).

Exact rational linear-programming feasibility is decidable in time polynomial in the explicitly encoded program length. Formula evaluation and program construction also take time polynomial in \(2^m,\tau,L\). Therefore the total running time is
\[ \operatorname{poly}(2^m,\tau,L) =2^{O(m)}\operatorname{poly}(\tau,L). \]
For \(m=O(\log L)\), this is polynomial in \(L\), since the explicit support list implies \(\tau\le L\).

Unused events can be removed first. If only \(r\) distinct events occur in the formulas, the same argument gives the sharper bound
\[ 2^{O(r)}\operatorname{poly}(\tau,L), \qquad r\le\min(m,L). \]

3. Membership in \(\mathrm{coNP}\)

A no-instance has a certificate consisting of at most \(\tau\) states.

To prove this, work in the affine space
\[ E=\left\{y\in\mathbb R^\tau:\sum_t y_t=1\right\}, \]
whose dimension is \(\tau-1\). Define the convex sets
\[ \Delta=\{y\in E:y_t\ge0\text{ for every }t\}, \]
and, for each state,
\[ H_\omega=\left\{y\in E: \sum_t y_ta_t(\omega)\ge0\right\}. \]
By the lemma, a no-instance satisfies
\[ \Delta\cap\bigcap_\omega H_\omega=\varnothing. \]

Helly’s theorem states that a finite family of convex sets in a real affine space of dimension \(d\) with empty intersection has a subfamily of at most \(d+1\) sets with empty intersection. Its hypotheses hold here: the family is finite, all sets are convex, and \(d=\tau-1\).

Consequently, some subfamily of at most \(\tau\) sets has empty intersection. Let \(S\) consist of the states whose halfspaces occur in that subfamily. Adding \(\Delta\), if necessary, preserves emptiness, so
\[ |S|\le\tau,\qquad \Delta\cap\bigcap_{\omega\in S}H_\omega=\varnothing. \]

The verifier evaluates the formulas on the listed states and checks infeasibility of this restricted rational linear program. It has \(\tau\) variables and at most \(\tau\) surplus inequalities, so verification takes polynomial time.

For certificate size, assignments need specify only the \(r\le L\) events appearing in the formulas. Every such assignment extends to a possible full state by the problem’s assumption. Thus the certificate uses \(O(\tau r)\) assignment bits and has polynomial length in \(L\). Conversely, infeasibility for any listed states implies infeasibility for all states. This proves membership in \(\mathrm{coNP}\).

4. \(\mathrm{coNP}\)-hardness with one type

Reduce Boolean formula unsatisfiability to acceptance. Given a formula \(F\), use its variables as the base events and construct the single type
\[ \tau=1,\qquad \mu_1=1,\qquad q_1=1,\qquad p_1=\frac12,\qquad \phi_1=F,\qquad \psi_1=\top. \]
All numerical restrictions are satisfied. Its surplus is
\[ a_1(\omega)=\frac12-\mathbf1_{F(\omega)}. \]

If \(F\) is unsatisfiable, then \(a_1(\omega)=\frac12\) in every state, and \(x_1=1\) is feasible.

If \(F\) is satisfiable, choose a satisfying state \(\omega^\ast\). Every admissible nonzero acceptance has \(x_1>0\), and hence
\[ x_1a_1(\omega^\ast)=-\frac{x_1}{2}<0. \]
No feasible nonzero acceptance exists.

The construction has polynomial size and satisfies
\[ F\text{ is unsatisfiable} \quad\Longleftrightarrow\quad \text{the constructed instance admits acceptance}. \]
Since Boolean formula unsatisfiability is \(\mathrm{coNP}\)-complete, this proves the required hardness. Together with Section 3, it establishes \(\mathrm{coNP}\)-completeness.

5. Meaning of the proposed dichotomy

The unrestricted problem belongs to \(\mathrm P\) if and only if \(\mathrm P=\mathrm{NP}\): its hardness would put unsatisfiability, and therefore satisfiability by complementation, in \(\mathrm P\); the converse follows from \(\mathrm{coNP}=\mathrm P\) under that equality.

If it were many-one \(\mathrm{NP}\)-hard, its membership in \(\mathrm{coNP}\) would imply \(\mathrm{NP}\subseteq\mathrm{coNP}\), hence \(\mathrm{NP}=\mathrm{coNP}\). Conversely, that equality would make its \(\mathrm{coNP}\)-completeness also \(\mathrm{NP}\)-completeness.

For Turing hardness, one acceptance-oracle query to the construction in Section 4, followed by reversing the answer, decides satisfiability.

Thus the proved classification is \(\mathrm{coNP}\)-complete for unrestricted \(m\), and polynomial-time solvable for \(m=O(\log L)\). The parameter \(\tau\) throughout is the supplied support size.
