The continuous mirror question, as graded

Given an ordered party set \(P\), coalition \(C\), favored party \(p_F\in C\cap(P\setminus S)\), spoiler set \(S\), addition limit \(k\), rational thresholds \(\phi,\rho\), and a rational distribution \(\mu\) over the paper's symmetric single-peaked preference types, does there exist \(K\subseteq S\cap C\), \(|K|\le k\), such that for \(R(K)=(P\setminus S)\cup K\), \(q_C(K)=\sum_{t:\operatorname{top}_t(R(K))\in C}\mu_t\ge\phi\) and \(q_F(K)=\sum_{t:\operatorname{top}_t(R(K))=p_F}\mu_t\ge\rho q_C(K)\)? The type masses sum to one and are given as binary rationals.

Packaged proof task (what the prover saw — nothing else)

Let \(P=\{p_1,\ldots,p_m\}\) have distinct binary-rational positions \(0\le p_1<\cdots<p_m\le1\). A symmetric single-peaked type is a strict ranking induced by increasing distance from some peak \(h\in[0,1]\); peaks equidistant from two distinct parties are excluded. Types are encoded by their rankings, promised realizable on these positions.
A society is given by its support: the list of the \(\tau\) distinct types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also specifies a nonempty proper coalition \(C\subsetneq P\), represented by its \(q\) maximal consecutive blocks, spoilers \(S\subseteq P\), a permanent favored party \(p_F\in C\setminus S\), an integer \(1\le k\le |S|\), and binary-rational thresholds \(\phi\in(0,1]\), \(\rho\in[0,1]\).
For \(K\subseteq S\cap C\) with \(|K|\le k\), set \(R(K)=(P\setminus S)\cup K\). Under plurality, let \(\operatorname{top}_t(R)\) be the highest-ranked party in \(R\), and define \(q_C(K)=\sum_{t:\operatorname{top}_t(R(K))\in C}\mu_t\) and \(q_F(K)=\sum_{t:\operatorname{top}_t(R(K))=p_F}\mu_t\).
The decision problem asks whether such a \(K\) satisfies \(q_C(K)\ge\phi\) and \(q_F(K)\ge\rho q_C(K)\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L,k,q\).

Is this rational-mass decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For binary-encoded integer type counts, the corresponding discrete problem is \(\mathrm{NP}\)-hard and admits a pseudopolynomial algorithm; it is polynomial-time solvable for a contiguous coalition. [Source](https://arxiv.org/html/2503.04661v1).
No separate result explicitly formulated for rational type masses was verified.

Modeling choices made when packaging the task

  • The ordered party set lacked metric positions and an encoding: supplied distinct binary-rational positions in [0,1], and encoded supported types as strict rankings promised realizable on those positions.
  • Excluded peaks equidistant from distinct parties, following the explicit strict-preference convention in the appendix; no tie-breaking is needed.
  • Restored the threshold domains phi in (0,1] and rho in [0,1], and the integer addition-limit domain 1 <= k <= |S|.
  • Specified a nonempty proper coalition, represented by its maximal consecutive blocks, following the coalition-objective definition and interval convention.
  • Defined L as total binary input length and q as the number of maximal coalition blocks.

Result

The rational-mass decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when every numerical input is dyadic, \(\rho=\tfrac12\), all spoilers belong to the coalition, and the favored party’s vote share is independent of the chosen spoilers.

The cited paper uses a subset-sum reduction for the integer-count counterpart. The construction below explicitly enforces the position, strict-ranking, and rational-mass requirements of this question. [Source, Appendix H.2](https://arxiv.org/html/2503.04661v1#A8.SS2).

Membership in \(\mathrm{NP}\)

A certificate is a subset \(K\subseteq S\cap C\) with \(|K|\le k\).

Mark the parties in \(R(K)\), then scan each supported ranking to find its first remaining party. This determines which masses contribute to \(q_C(K)\) and \(q_F(K)\).

All calculations can be exact. Write \(\mu_t=a_t/b_t\) and take \(D_0=\prod_{t=1}^{\tau}b_t\). The binary length of \(D_0\) is \(O(L)\), because the denominators are part of the input. Both vote shares can therefore be represented by integer numerators over \(D_0\), with \(O(L)\) bits. Cross multiplication checks the two threshold inequalities using integers of \(O(L)\) bits.

Using ordinary quadratic-time integer arithmetic, verification takes \(O((m\tau+1)L^2)\) bit operations. Thus the problem belongs to \(\mathrm{NP}\).

Reduction from positive integer subset sum

Use the standard \(\mathrm{NP}\)-complete problem whose input consists of positive binary-encoded integers \(a_1,\ldots,a_n\) and a positive target \(T\), asking whether some \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in I}a_i=T\).

We may restrict to \(n\ge1\) and \(T\le A:=\sum_{i=1}^n a_i\). This restriction preserves hardness: instances with \(T>A\) are automatically negative and can be replaced by the fixed negative instance consisting of the integer \(2\) and target \(1\).

Parties and positions

Choose a power of two \(M>2n+2\). Introduce parties \(x_0,\ldots,x_{2n+1}\), positioned at \(x_j=j/M\).

Set

\[ S=\{x_{2i}:1\le i\le n\},\qquad C=\{x_0\}\cup S,\qquad p_F=x_0,\qquad k=n. \]

Thus all odd-indexed parties are permanent opposition parties. The favored party is permanent, the coalition is nonempty and proper, and its maximal consecutive blocks are precisely its \(n+1\) singleton parties. Consequently, \(m=2n+2\) and \(q=n+1\).

Supported types and masses

Choose a power of two \(D>A+T\). Specify the following types by their complete distance rankings:

| Type | Realizing peak | Mass |
|---|---|---|
| Favored type | \(h_F=1/(4M)\) | \(T/D\) |
| Item type \(i\), for \(1\le i\le n\) | \(h_i=(2i+\tfrac14)/M\) | \(a_i/D\) |
| Filler type | \(h_O=(2n+1+\tfrac14)/M\) | \((D-A-T)/D\) |

All masses are positive and sum to \(1\). They are dyadic.

Choose the thresholds \(\phi=2T/D\) and \(\rho=\tfrac12\). Since \(D>A+T\ge2T>0\), we have \(\phi\in(0,1)\).

Verification of the strict-ranking promise

All listed peaks lie in \([0,1]\). For two distinct parties \(x_j,x_\ell\), an equidistant peak would have to equal their midpoint, namely \((j+\ell)/(2M)\).

Every chosen peak, after multiplication by \(M\), has fractional part \(\tfrac14\). Every such midpoint, after multiplication by \(M\), is an integer or a half-integer. Therefore no chosen peak is equidistant from two distinct parties, and every induced ranking is strict.

The types are distinct: their first-ranked parties in the full party set are respectively \(x_0\), the different \(x_{2i}\), and \(x_{2n+1}\). Hence the support size is exactly \(\tau=n+2\).

Voting behavior

The favored type always votes for \(x_0\), its nearest party, which is permanent. The filler type always votes for the permanent opposition party \(x_{2n+1}\).

For item type \(i\), the distances to \(x_{2i}\), \(x_{2i+1}\), and \(x_{2i-1}\) are respectively \(1/(4M)\), \(3/(4M)\), and \(5/(4M)\). Every other party is farther away than \(x_{2i+1}\).

It follows that item type \(i\):

  • votes for \(x_{2i}\) if that spoiler is selected;
  • otherwise votes for the permanent opposition party \(x_{2i+1}\).

In particular, selections in other gadgets do not affect its vote.

Correctness and encoding size

For any selected set \(K\subseteq S\), define \(I(K)=\{i:x_{2i}\in K\}\). The voting behavior just proved gives

\[ q_F(K)=\frac{T}{D}, \qquad q_C(K)=\frac{T+\sum_{i\in I(K)}a_i}{D}. \]

The coalition inequality is equivalent to \(\sum_{i\in I(K)}a_i\ge T\). The favored-party inequality is equivalent to

\[ \frac{T}{D}\ge \frac12\frac{T+\sum_{i\in I(K)}a_i}{D}, \]

and hence to \(\sum_{i\in I(K)}a_i\le T\). Both inequalities therefore hold exactly when \(\sum_{i\in I(K)}a_i=T\).

Because \(k=n=|S|\), every subset of the source integers corresponds to an allowed selection. This proves both directions of the reduction.

Let \(B\) be the source input’s binary length. The position denominators have \(O(\log(n+2))\) bits, and \(D\) has \(O(B)\) bits. There are \(n+2\) explicitly listed rankings, each of length \(2n+2\). Thus the resulting input length is \(L=O(n^2\log(n+2)+nB)\).

The rankings can be generated by sorting integer distance numerators of \(O(\log(n+2))\) bits. All remaining construction steps use integers of polynomially bounded binary length. The reduction consequently runs in polynomial time.

Together with membership in \(\mathrm{NP}\), this proves \(\mathrm{NP}\)-completeness.

Running times and the coalition-block parameter

For completeness, the following exact algorithms give bounds in the requested parameters.

Let \(s=|S\cap C|\). Direct enumeration takes

\[ O\!\left( \left[\sum_{j=0}^{\min(k,s)}\binom{s}{j}\right] (m\tau+1)L^2 \right). \]

There is also an enumeration bound depending on \(q\), justified as follows.

Extremal-party lemma. Given any selection \(K\), retain only its leftmost and rightmost selected parties in each coalition block, obtaining \(K'\subseteq K\). Then \(q_C(K')=q_C(K)\) and \(q_F(K')\ge q_F(K)\).

To prove the equality, consider a type whose winner under \(R(K)\) is removed. This winner is an interior selected coalition party \(c\), between retained endpoints \(a<b\) in its block. Fix a realizing peak \(h\).

If \(h\le a\), party \(a\) is closer than \(c\), contradicting that \(c\) was the winner; the case \(h\ge b\) is analogous. Thus \(a<h<b\).

Every opposition party \(o\) lies outside \([a,b]\), since these endpoints belong to one consecutive coalition block. If \(o<a\), then \(|h-a|<|h-o|\); if \(o>b\), then \(|h-b|<|h-o|\). The nearer of \(a,b\) therefore beats every opposition party. This type’s new winner still belongs to the coalition.

A type whose original winner is retained keeps that winner, because only parties were removed. Consequently, every type’s coalition membership is unchanged. Finally, deleting parties cannot remove a vote from the permanent favored party, proving the inequality for \(q_F\).

Let \(s_j\) be the number of eligible spoilers in coalition block \(j\). The lemma shows that it suffices to enumerate at most two spoilers per block and reject selections exceeding \(k\). The resulting running time is

\[ O\!\left( \left[\prod_{j=1}^{q} \left(1+s_j+\binom{s_j}{2}\right)\right] (m\tau+1)L^2 \right). \]

Choosing between the two enumeration algorithms gives the simpler bound \(O((m+1)^{\min(k,2q)}(m\tau+1)L^2)\). In particular, the problem is polynomial-time solvable for each fixed \(q\); for a contiguous coalition, the bound is \(O(m^2(m\tau+1)L^2)\).

The hardness construction has unbounded \(q=n+1\), so it is consistent with this contiguous-coalition algorithm.
