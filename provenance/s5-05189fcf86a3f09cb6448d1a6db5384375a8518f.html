The continuous mirror question, as graded

Given explicit finite sets \(T,\Theta,S\), binary-rational masses \(\mu_t\) summing to \(1\), positive rational distributions \(f_t(s)\) and likelihoods \(l_t(s\mid\theta)\), and rational \(\beta,\varepsilon>0\), return \(\hat\theta\in\Theta\) whose objective is within \(\varepsilon\) of \(\min_{\theta\in\Theta}\sum_{t\in T}\mu_t[D(f_t\|l_t(\cdot\mid\theta))+\beta\mathbb E_{s\sim f_t}(\log l_t(s\mid\theta))^2]\).

Assume \(\arg\min_{\theta\in\Theta}F(\theta)\subsetneq\Theta\). The computational problem is to return any \(\hat\theta\in\Theta\) satisfying \(F(\hat\theta)\leq\min_{\theta\in\Theta}F(\theta)+\varepsilon\).
Let \(L\) be the total binary input length, including \(\beta\) and \(\varepsilon\); use the deterministic Turing model and state running times in \(m,\tau,q,L\).

Result. The problem is solvable in deterministic polynomial time in \(m,\tau,q,L\). Below is an explicit algorithm with a proved accuracy guarantee and a conservative bit-complexity bound. The promise that the minimizer set is a proper subset of \(\Theta\) is unnecessary.

1. Remove the hypothesis-independent term.

By definition,
\(D(f_t\|l_t(\cdot\mid\theta))=\sum_s f_t(s)\bigl(\log f_t(s)-\log l_t(s\mid\theta)\bigr)\).

Define
\(C=\sum_{t,s}\mu_t f_t(s)\log f_t(s)\)
and
\(G(\theta)=\sum_{t,s}\mu_t f_t(s)\bigl(-\log l_t(s\mid\theta)+\beta(\log l_t(s\mid\theta))^2\bigr)\).

Then \(F(\theta)=C+G(\theta)\). Consequently, for any two hypotheses,
\(F(\theta)-F(\theta')=G(\theta)-G(\theta')\).
It therefore suffices to approximately minimize \(G\).

Write \(w_{t,s}=\mu_t f_t(s)\). These weights are positive, and their sum is
\(\sum_{t,s}w_{t,s}=\sum_t\mu_t\sum_s f_t(s)=1\).

2. A uniform precision bound suffices.

Under the standard binary encoding of rational numerators and denominators, every positive input rational lies between \(2^{-L}\) and \(2^L\). In particular,
\(2^{-L}\leq l_t(s\mid\theta)\leq1\),
\(\beta\leq2^L\), and \(\varepsilon\geq2^{-L}\).
Thus
\(\lvert\log l_t(s\mid\theta)\rvert\leq L\log2\leq L\).

Set \(\delta=2^{-(4L+4)}\). Suppose rational approximations \(a_{t,s,\theta}\) satisfy
\(\lvert a_{t,s,\theta}-\log l_t(s\mid\theta)\rvert\leq\delta\).
Define the rational objective
\(\widetilde G(\theta)=\sum_{t,s}w_{t,s}\bigl(-a_{t,s,\theta}+\beta a_{t,s,\theta}^{\,2}\bigr)\).

For \(x=\log l_t(s\mid\theta)\) and \(a=a_{t,s,\theta}\), we have
\(\lvert a\rvert\leq L+\delta\), and hence
\(\lvert a^2-x^2\rvert=\lvert a-x\rvert\lvert a+x\rvert\leq\delta(2L+\delta)\).

Because \(\delta\leq1\) and the weights sum to one, it follows that
\(\lvert\widetilde G(\theta)-G(\theta)\rvert\leq\delta\bigl(1+2^L(2L+1)\bigr)\).

For every integer \(L\geq1\), \(2L+1\leq2^{L+1}\), so
\(1+2^L(2L+1)\leq2^{2L+2}\).
Therefore, uniformly over all hypotheses,
\(\lvert\widetilde G(\theta)-G(\theta)\rvert\leq2^{-2L-2}\leq\varepsilon/4\).

The remaining task is to compute these logarithm approximations in polynomial time.

3. Construct the logarithm approximations using rational arithmetic.

Let \(p\) be any supplied likelihood probability. Choose the least nonnegative integer \(k\) such that \(r=2^kp\geq1\). Then \(1\leq r<2\) and \(k\leq L\). Set
\(z=(r-1)/(r+1)\), so \(0\leq z<1/3\).

For a positive integer \(N\), define the rational function
\(A_N(z)=2\sum_{j=0}^{N-1}z^{2j+1}/(2j+1)\).

For \(0\leq z\leq1/3\), the identity
\(\log((1+z)/(1-z))=2\int_0^z(1-u^2)^{-1}\,du\)
and the finite geometric-series identity give the exact remainder formula
\(\log((1+z)/(1-z))-A_N(z)=2\int_0^z u^{2N}(1-u^2)^{-1}\,du\).

The remainder is nonnegative and at most
\(2z^{2N+1}/((2N+1)(1-z^2))\leq(3/4)9^{-N}\leq9^{-N}\).

Since \(r=(1+z)/(1-z)\), this approximates \(\log r\). Applying the same formula at \(z=1/3\) approximates \(\log2\). Thus the rational number
\(a(p)=A_N(z)-kA_N(1/3)\)
satisfies
\(\lvert a(p)-\log p\rvert\leq(k+1)9^{-N}\leq(L+1)9^{-N}\).

Choose \(N=4L+4\). Using \(L+1\leq2^L\) and \(9^{-N}\leq2^{-2N}\), we obtain
\(\lvert a(p)-\log p\rvert\leq2^{L-2N}=2^{-7L-8}\leq\delta\).

This construction uses only integer and rational arithmetic. In particular, it requires no exact comparison between transcendental numbers.

4. Select a hypothesis and prove its accuracy.

Compute \(a(l_t(s\mid\theta))\) for every table entry, form each \(\widetilde G(\theta)\) exactly as a rational number, and return any hypothesis \(\hat\theta\) minimizing these rational values.

A minimizer \(\theta^\star\) of \(G\) exists because \(\Theta\) is finite and nonempty. The uniform approximation bound and the definition of \(\hat\theta\) imply
\(G(\hat\theta)\leq\widetilde G(\hat\theta)+\varepsilon/4\leq\widetilde G(\theta^\star)+\varepsilon/4\leq G(\theta^\star)+\varepsilon/2\).

Adding \(C\) gives
\(F(\hat\theta)\leq\min_{\theta\in\Theta}F(\theta)+\varepsilon/2\leq\min_{\theta\in\Theta}F(\theta)+\varepsilon\),
as required.

5. Bound the deterministic Turing running time.

Here is a conservative bound using ordinary schoolbook integer arithmetic; no fast arithmetic is needed.

For each likelihood probability, the rational number \(z\) has numerator and denominator of \(O(L)\) bits. There are \(N=O(L)\) series terms, and each term has numerator and denominator of \(O(L^2)\) bits.

Computing the powers successively and adding the terms by ordinary rational cross-multiplication produces intermediate integers of at most \(O(L^3)\) bits: the denominator bit lengths add across \(O(L)\) terms, each having \(O(L^2)\) bits, and the numerator has the same order of bit length. There are \(O(L)\) arithmetic operations on integers of at most \(O(L^3)\) bits. Consequently, \(O(L^7)\) bit operations suffice for each logarithm approximation. The approximation to \(\log2\) can be computed once and reused.

Let \(M=\tau q\). Each summand of \(\widetilde G(\theta)\) has numerator and denominator of \(O(L^3)\) bits. Summing its \(M\) terms by rational cross-multiplication uses intermediate integers of \(O(ML^3)\) bits. Thus \(O(M^3L^6)\) bit operations suffice to construct one approximate objective. Comparing all \(m\) resulting rational values costs \(O(mM^2L^6)\) additional bit operations.

An overall bound is therefore
\(O\bigl(m\tau q\,L^7+m(\tau q)^3L^6\bigr)\),
which is polynomial in the requested parameters.

The explicit hypothesis table permits enumeration of all candidates, while the binary input length controls the precision needed for their comparison. This establishes the requested polynomial-time guarantee directly.
