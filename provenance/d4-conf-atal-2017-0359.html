Theorem 1 — class: hardness

The continuous mirror question, as graded

Given candidates \(C\), a common axis, a target \(p\), registered masses \(\mu_t\), eligible capacities \(a_t\), and a budget \(\rho\), where every type \(t\) is a complete ranking single-peaked on the axis, decide whether there are additions \(0 \le x_t \le a_t\) with \(\sum_t x_t \le \rho\) such that \(\sum_t (\mu_t+x_t)(s(t,p)-s(t,c)) \ge 0\) for every \(c \in C\), where \(s(t,c)\) is the Borda score of \(c\) in type \(t\).

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m=|C|\ge 2\), a common single-peaked axis, and a target \(p\in C\), each type is a strict complete ranking single-peaked on that axis. Write \(s(t,c)\) for its standard Borda score for \(c\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here the support is the combined registered and eligible pool: type \(t\) has registered mass \(\mu_t\ge 0\) and eligible capacity \(a_t\ge 0\), with \(\mu_t+a_t>0\). Thus \(\tau\) is the support size, not the number of possible rankings. Masses need not sum to one.
The budget \(\rho\ge 0\) is a binary rational; \(L\) is the total input bit length, including rankings, masses, capacities, and budget. Initially \(p\) is not a Borda co-winner.
Decide whether real additions \(0\le x_t\le a_t\), costing one unit per unit of mass and satisfying \(\sum_t x_t\le\rho\), can make \(p\) a co-winner: \(\sum_t(\mu_t+x_t)(s(t,p)-s(t,c))\ge 0\) for every \(c\in C\). Ties count as wins.

Is this continuous constructive control problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it NP-hard?

Discrete constructive control by adding unweighted votes for Borda is NP-hard even when all registered and eligible rankings share a single-peaked axis, under both co-winner and unique-winner conventions. [Yang, 2017](https://aamas.csc.liv.ac.uk/Proceedings/aamas2017/pdfs/p1178.pdf)
No result for this exact divisible-mass formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Defined the support as the union of registered and eligible types, retaining exactly types with positive combined mass and allowing either component to be zero.
  • Used nonnegative binary rational masses, capacities, and budget, with arbitrary total mass rather than normalization, preserving the discrete model's independent registered and eligible pool sizes.
  • Made additions real and divisible, with unit cost per unit of added mass; retained the co-winner convention specified by the weak inequalities.
  • Carried over the assumption that the target does not initially win; this also excludes empty registered elections and forces at least two candidates.
  • Used standard strict single-peaked rankings and standard Borda scores, resolving the inconsistent scoring-vector notation in the supplied preliminaries.

Result

The problem is in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\). In fact, the proof applies to arbitrary strict complete rankings; single-peakedness is unnecessary.

1. Exact linear-programming formulation

Index the explicitly listed support types by \(t\in\{1,\ldots,\tau\}\). If \(r_t(c)\) is the position of candidate \(c\) in type \(t\), standard Borda gives \(s(t,c)=m-r_t(c)\). Define

\(d_{t,c}=s(t,p)-s(t,c)=r_t(c)-r_t(p)\),

so \(d_{t,c}\) is an integer with \(|d_{t,c}|\le m-1\). For each rival \(c\ne p\), define the registered deficit

\(b_c=-\sum_{t=1}^{\tau}\mu_t d_{t,c}\).

Construct the following linear feasibility problem with real variables \(x_1,\ldots,x_\tau\):

  • \(x_t\ge 0\) and \(x_t\le a_t\), for every type \(t\);
  • \(\sum_{t=1}^{\tau}x_t\le\rho\);
  • \(\sum_{t=1}^{\tau}d_{t,c}x_t\ge b_c\), for every rival \(c\ne p\).

There are exactly \(\tau\) variables and \(2\tau+m\) inequalities.

Equivalence. The first two groups express precisely the permitted additions and their budget. For each rival, the last inequality is equivalent to

\(\sum_{t=1}^{\tau}(\mu_t+x_t)(s(t,p)-s(t,c))\ge 0\),

because \(b_c=-\sum_t\mu_t d_{t,c}\). This is exactly the requirement that the final Borda score of \(p\) be at least that of \(c\). The comparison with \(p\) itself is identically zero and can be omitted.

Thus, permitted additions making \(p\) a co-winner exist if and only if this linear program is feasible over the reals.

2. Polynomial encoding length

It remains to verify polynomial *bit* complexity, since the masses and budget can have large binary encodings.

Write each input rational using its binary numerator and positive denominator. Let \(Q\) be the product of all denominators appearing in the masses, capacities, and budget. Since their total encoding length is at most \(L\), the binary length of \(Q\) is \(O(L)\).

Multiply every inequality above by \(Q>0\). This preserves its solutions and produces integer coefficients and right-hand sides. In particular, writing \(\mu_t=u_t/v_t\), we obtain

\(Qb_c=-\sum_{t=1}^{\tau}(Q/v_t)u_t d_{t,c}\),

which is an integer.

Every input rational has absolute value at most \(2^{O(L)}\), and \(Q\le 2^{O(L)}\). Consequently,

\(|Qb_c|\le Q\tau(m-1)\max_t\mu_t\le\tau(m-1)2^{O(L)}\).

Hence each \(Qb_c\) has \(O(L+\log(\tau+1)+\log m)\) bits. The same bound holds for the other coefficients and right-hand sides: \(Qd_{t,c}\), \(Q\), \(Qa_t\), and \(Q\rho\).

The integer system therefore has total encoding length polynomial in \(m,\tau,L\). It can also be constructed in polynomial time: scan the rankings to compute positions, multiply the input denominators to obtain \(Q\), and compute the displayed integer sums. All these operations involve polynomially many integers of polynomial bit length.

Crucially, only the \(\tau\) explicitly supplied types are used. No enumeration of other rankings is required.

3. Exact polynomial-time decision

Apply the standard polynomial-time linear-programming feasibility theorem:

Given an explicitly encoded integer matrix \(A\) and integer vector \(b\), feasibility of \(Ax\ge b\) over real variables is decidable in time polynomial in their binary encoding length.

The ellipsoid-method theorem includes arbitrary feasible polyhedra, including those of lower dimension; see [MIT’s lecture on the ellipsoid method, Sections 3.11–3.12](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

Our constructed system satisfies the theorem’s hypotheses: it is explicit, finite, and has integer data of polynomial encoding length. Therefore its feasibility, and hence the requested control decision, is decidable in time polynomial in \(m,\tau,L\). This is an exact feasibility decision, so it correctly handles ties and zero capacities without any positive-margin assumption.

4. Relation to discrete hardness

[Yang’s discrete hardness result](https://aamas.csc.liv.ac.uk/Proceedings/aamas2017/pdfs/p1178.pdf) concerns adding whole unweighted votes. Aggregating those votes by type imposes integer constraints on the addition variables. The present problem expressly permits real additions, so its feasible set is given entirely by linear inequalities. Feasibility of that continuous relaxation does not establish feasibility under integer restrictions.

Thus the discrete hardness result is consistent with the polynomial-time algorithm proved here.
