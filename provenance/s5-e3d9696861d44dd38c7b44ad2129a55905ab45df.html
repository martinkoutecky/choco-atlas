Theorem 1 — class: other

The continuous mirror question, as graded

Given a finite set of roommate types \(T\), rational shares \(\mu_t\) summing to \(1\), and each type's preferences over acceptable roommate types, decide whether there are nonnegative matching masses \(x_{tu}\) and single masses \(s_t\) such that \(x_{tu}=x_{ut}\) for \(t\ne u\), \(\sum_u x_{tu}+s_t=\mu_t\), and no mutually acceptable type pair has positive mass on both sides who are single or strictly prefer each other to their assigned type; if so, construct such a mass assignment.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) counts supported types, not possible types. Each type \(t\) has a strict total preference order \(\succ_t\) over an explicitly listed acceptable set \(A_t\subseteq T\), possibly empty, and prefers every acceptable roommate to being single.
Distinct individuals of the same type may be roommates when \(t\in A_t\). Let \(m\) count mutually acceptable unordered type pairs, including such diagonal pairs, and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
An assignment consists of nonnegative real masses \(x_{tu},s_t\), with \(x_{tu}=0\) unless \(u\in A_t\) and \(t\in A_u\), \(x_{tu}=x_{ut}\) for \(t\ne u\), and \(\sum_{u\in T}x_{tu}+s_t=\mu_t\). Here \(x_{tt}\) counts individuals matched within type \(t\), so their pair mass is \(x_{tt}/2\); \(s_t\) counts singles.
For every mutually acceptable pair define \(D_t(u)=s_t+\sum_{v\in A_t:\,u\succ_t v}x_{tv}\). The assignment is stable precisely when \(D_t(u)D_u(t)=0\) for every such pair, including \(t=u\).

Is deciding whether a stable mass assignment exists, and constructing an exact rational assignment when one exists, solvable in polynomial time in \(m,\tau,L\), or is the existence problem NP-hard?

For finite agents with strict incomplete lists, a sound and complete ASP encoding gives a bijection between its answer sets and stable matchings ([Erdem et al.](https://eprints.gla.ac.uk/221680/7/221680.pdf)).
For loopless fractional roommates with unit vertex capacities, an ordinally stable assignment always exists and can be constructed in polynomial time ([Chen, Roy and Sorge](https://www.ijcai.org/proceedings/2021/0013.pdf)).
For the related non-bipartite stable allocation problem with vertex sizes and edge capacities, a polynomial-time algorithm is known ([Dean and Munshi](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf)).

Result

A stable mass assignment always exists, and an exact rational assignment can be constructed deterministically in polynomial time. A conservative bit-complexity bound is
\[ O\!\left((m+\tau+1)^2(\tau+1)L^2\right). \]
Moreover, writing each input mass as \(\mu_t=p_t/q_t\) and setting \(Q=\prod_{t\in T}q_t\), one can construct an assignment whose coordinates are integer multiples of \(1/(2Q)\).

The proof uses the symmetric bipartite construction of Dean and Munshi. We verify explicitly that its stability condition agrees with the product condition in the question, including diagonal pairs.

1. Remove unilateral acceptabilities

Let \(B_t=\{u\in A_t:t\in A_u\}\), with the order inherited from \(\succ_t\).

Deleting \(A_t\setminus B_t\) changes neither feasibility nor stability: every assignment coordinate involving such a partner is required to be zero, so its contribution to every \(D_t(u)\) is zero.

Henceforth all preference lists contain only mutually acceptable partners.

2. Construct a symmetric bipartite allocation instance

Introduce a dummy label \(d\), and put \(V=T\cup\{d\}\). Define sizes
\[ b_t=\mu_t\quad(t\in T),\qquad b_d=1. \]

Create a left vertex \(i_v\) and a right vertex \(j_v\), each of size \(b_v\), for every \(v\in V\). Its allocation variables \(y_{vu}\) must satisfy
\[ \sum_u y_{vu}=b_v,\qquad \sum_v y_{vu}=b_u,\qquad 0\le y_{vu}\le c_{vu}. \]

Add the following edges:

  • For each mutually acceptable distinct pair \(\{t,u\}\), add \(i_tj_u\) and \(i_uj_t\).
  • For each acceptable diagonal pair, add \(i_tj_t\).
  • For every \(t\in T\), add \(i_tj_d\) and \(i_dj_t\).
  • Add \(i_dj_d\).

On every edge set \(c_{vu}=\min\{b_v,b_u\}\).

At both copies of a real type \(t\), use its original order on \(B_t\), followed by \(d\). At both copies of \(d\), use the same arbitrary strict order on \(T\), followed by \(d\).

Thus exchanging the two sides preserves sizes, capacities, and rankings. An original diagonal pair becomes an ordinary bipartite edge between two distinct vertices.

This instance has a feasible allocation: set
\[ y_{td}=y_{dt}=\mu_t,\qquad y_{dd}=0, \]
and set every other coordinate to zero. The dummy row and column each sum to \(1\).

If \(\ell\) denotes the number of acceptable diagonal pairs, the constructed graph has
\[ N=2(\tau+1),\qquad M=2m-\ell+2\tau+1. \]

3. The allocation theorem being applied

In bipartite stable allocation, an edge blocks precisely when it is below capacity and each endpoint has positive allocation to a strictly worse partner.

Dean and Munshi prove that a symmetric bipartite instance admits a symmetric stable allocation \(y_{vu}=y_{uv}\). Their construction computes an initial stable allocation and then uses full rotations, or half of self-dual rotations. There are at most \(2M\) rotations, each represented by a cycle of length at most \(N\). Duality can be checked deterministically by explicit comparisons; randomness is used only for their faster implementation. These facts are established in Sections 3–5, especially Lemma 15 and the following algorithm discussion. [Dean and Munshi](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf)

Our construction satisfies the required symmetry and strictness hypotheses. Its dummy vertices also have exactly the standard sizes and least-preferred positions: each dummy has size equal to the total size \(1\) of the real vertices on the opposite side.

Consequently, obtain a symmetric stable allocation \(y\).

4. Exact equivalence of stability conditions

Define
\[ x_{tu}=y_{tu}\quad(t,u\in T),\qquad s_t=y_{td}. \]
Nonnegativity, acceptability, symmetry, and the mass equations follow immediately from the corresponding properties of \(y\).

For a real pair \(\{t,u\}\), the allocation at \(i_t\) to partners strictly worse than \(j_u\) is exactly
\[ y_{td}+\sum_{v\in B_t:\,u\succ_t v}y_{tv}=D_t(u). \]
By symmetry, the allocation at \(j_u\) to partners strictly worse than \(i_t\) is exactly \(D_u(t)\).

Suppose both quantities were positive. Since the first excludes \(y_{tu}\), the row equation gives
\[ y_{tu}\le \mu_t-D_t(u)<\mu_t. \]
The column equation similarly gives
\[ y_{tu}<\mu_u. \]
Therefore \(y_{tu}<\min\{\mu_t,\mu_u\}=c_{tu}\), and both endpoints have positive allocation to worse partners. This edge would block \(y\), a contradiction.

Thus \(D_t(u)D_u(t)=0\) for every real pair.

The same argument applies when \(t=u\): the two worse-partner totals are both \(D_t(t)\), so positivity would make \(i_tj_t\) block. Notice that \(y_{tt}=x_{tt}\) counts individuals, as required; its pair mass is \(x_{tt}/2\).

For completeness, the correspondence works in reverse. Given any feasible mass assignment, extend it by
\[ y_{tu}=x_{tu},\qquad y_{td}=y_{dt}=s_t,\qquad y_{dd}=1-\sum_t s_t. \]
Here \(0\le\sum_t s_t\le1\), and every row and column has the prescribed sum. All edge capacities hold because each coordinate is bounded by its endpoint sizes.

If the original assignment is stable, no real edge blocks, by the worse-partner identities above. An edge involving one real vertex and a dummy cannot block because the real endpoint ranks the dummy last. The dummy–dummy edge cannot block because both endpoints rank each other last.

Hence stable mass assignments correspond exactly to symmetric stable allocations of this instance.

5. Exact arithmetic and running time

Scale every size and capacity by \(Q=\prod_t q_t\). They become integers, and \(\log Q=O(L)\).

The initial allocation algorithm and the enumeration of full rotations use additions, subtractions, comparisons, and minima of residual capacities. Starting from integral data, these operations preserve integrality. Thus the initial allocation and every full-rotation amount are integral.

The symmetric construction selects either the full amount or zero for a non-self-dual rotation, and half the amount for a self-dual rotation. Its final scaled allocation is consequently half-integral. Dividing by \(Q\) proves the stated denominator bound \(2Q\).

For a conservative deterministic implementation, explicitly storing and comparing the \(O(M)\) cycles costs at most \(O(M^2N)\) elementary operations. Initialization and reconstruction fit within this bound. All numerical quantities have \(O(L)\) bits: scaled allocations and residual capacities are bounded by \(Q\), and the final denominator is at most \(2Q\). Using schoolbook exact arithmetic therefore gives
\[ O(M^2NL^2) = O\!\left((m+\tau+1)^2(\tau+1)L^2\right) \]
bit operations, including preprocessing and output.

Thus construction is polynomial in the supported types and input length, without expanding rational masses into individual agents. On the promised valid inputs, existence is always affirmative.
