The continuous mirror question, as graded

Given projects \(P\) with costs \(c(p)\), global budget \(B\), project groups \(\mathcal F\) with limits \(b(G)\), and a finite-support distribution \(\mu\) with binary-rational masses over approval types \(A\subseteq P\), choose a feasible bundle \(X\subseteq P\) maximizing \(U_\mu(X)=\sum_A\mu_A|A\cap X|\). For each fixed \(\epsilon>0\), is a polynomial-time \(g^{1/2-\epsilon}\)-approximation impossible unless \(P=NP\), even when \(g=|\mathcal F|\le m^2\) and \(m=|P|\)?

Packaged proof task (what the prover saw — nothing else)

Given a project set \(P\), let \(m=|P|\). Costs \(c(p)\), global budget \(B\), and group limits \(b(G)\) are binary-encoded nonnegative integers. The explicitly listed family \(\mathcal F\subseteq 2^P\) has distinct groups, with \(b(G)\le B\) and \(1\le g=|\mathcal F|\le m^2\).
A society is given by its support: the list of the \(\tau\) distinct approval types \(A\subseteq P\) with positive mass, each mass \(\mu_A\) a binary rational, with \(\sum_A\mu_A=1\). Here \(\tau\) is the support size, not the number of possible approval types. Every project belongs to some supported approval type.
A bundle \(X\subseteq P\) is feasible exactly when \(\sum_{p\in X}c(p)\le B\) and \(\sum_{p\in X\cap G}c(p)\le b(G)\) for every \(G\in\mathcal F\). Maximize \(U_\mu(X)=\sum_A\mu_A|A\cap X|\). Projects are indivisible.
Let \(\mathrm{OPT}\) be the maximum feasible utility. An approximation factor \(\alpha\ge1\) requires a feasible bundle of utility at least \(\mathrm{OPT}/\alpha\). Let \(L\) be the total input bit length; state running times in \(m,\tau,g,L\) and any dependence on \(\epsilon\).

For each fixed \(0<\epsilon<1/2\), does this problem admit a \(g^{1/2-\epsilon}\)-approximation in time polynomial in \(m,\tau,g,L\), or is achieving this factor NP-hard, excluding such an algorithm unless \(\mathsf P=\mathsf{NP}\)?

For explicitly listed finite voters, a polynomial-time \(g^{1/2-\epsilon}\)-approximation is impossible unless \(\mathsf P=\mathsf{NP}\), even when \(g\le m^2\); a polynomial-time \((g+2)\)-approximation is known. [Source](https://arxiv.org/html/2012.05213v2)
No result explicitly addressing the normalized, binary-rational support model above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one and required distinct supported approval types with strictly positive binary-rational masses.
  • Specified binary-encoded nonnegative integer costs and budgets, allowing zero because the source does not explicitly exclude it.
  • Carried over distinct groups, group limits bounded by the global budget, and positive approval mass for every project.
  • Restricted to at least one group and 0<epsilon<1/2 so the stated approximation factor is defined and at least one.
  • Specified exact budget feasibility, indivisible project selection, the approximation convention, and total input bit length L.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed \(0<\epsilon<1/2\), achieving a \(g^{1/2-\epsilon}\)-approximation is \(\mathsf{NP}\)-hard. This holds even with \(\tau=1\), mass \(1\), unit project costs, and groups of size \(2\).

Hardness theorem used

Zuckerman proved that, for every fixed \(0<\delta<1\), approximating Maximum Clique on an \(n\)-vertex graph within \(n^{1-\delta}\) is \(\mathsf{NP}\)-hard. [Zuckerman, Theorem 1.1](https://theoryofcomputing.org/articles/v003a006/v003a006.pdf).

Consequently, the same statement holds for Maximum Independent Set: a subset is independent in a graph exactly when it is a clique in its complement. Taking complements preserves the vertex count and solution cardinalities and takes polynomial time.

Reduction to the support model

Let \(H=(V,E)\) be a simple graph with \(n=|V|\). If \(E=\varnothing\), its maximum independent set is \(V\), which we can return exactly. Thus, to construct an approximation algorithm for arbitrary graphs, it suffices to handle graphs with \(E\ne\varnothing\).

For such a graph, construct the budgeting instance as follows:

  • Set \(P=V\), so \(m=n\).
  • Set \(c(p)=1\) for every project and \(B=n\).
  • For each edge \(e=\{u,v\}\), include the group \(G_e=\{u,v\}\), with \(b(G_e)=1\).
  • Use the single supported approval type \(A=P\), with \(\mu_P=1\).

All input conditions hold. The groups are distinct because the graph is simple. Furthermore, \(1\le g=|E|\le\binom n2\le m^2\), and every group limit is at most \(B\). The support consists of one distinct type with positive binary-rational mass summing to \(1\), and every project belongs to that type.

Feasibility equivalence. The global constraint holds for every \(X\subseteq P\), since its cost is \(|X|\le n\). For an edge \(e=\{u,v\}\), its group constraint is precisely \(|X\cap\{u,v\}|\le1\). Thus \(X\) is feasible if and only if it contains no two adjacent vertices, equivalently, if and only if it is an independent set of \(H\).

Objective equivalence. For every bundle, \(U_\mu(X)=\mu_P|P\cap X|=|X|\). Writing \(a(H)\) for the maximum independent-set cardinality, we therefore have \(\mathrm{OPT}=a(H)\). The correspondence preserves both feasibility and objective values exactly.

Approximation and running-time implications

Fix \(0<\epsilon<1/2\). Suppose an algorithm always returns a feasible bundle satisfying \(U_\mu(X)\ge\mathrm{OPT}/g^{1/2-\epsilon}\), in time polynomial in \(m,\tau,g,L\).

Applying it to the constructed instance gives an independent set with

\(\displaystyle |X|\ge\frac{a(H)}{g^{1/2-\epsilon}}\ge\frac{a(H)}{n^{1-2\epsilon}}.\)

The second inequality follows from \(g\le n^2\) and \(1/2-\epsilon>0\), which imply \(g^{1/2-\epsilon}\le(n^2)^{1/2-\epsilon}=n^{1-2\epsilon}\).

For completeness, using incidence vectors for the explicitly listed groups, the construction has input length \(L=O(mg+m\log m)=O(n^3)\) and can be produced within the same bit-operation bound. Here \(\tau=1\) and \(g\le n^2\). Hence any running time polynomial in \(m,\tau,g,L\) becomes polynomial in \(n\). Its constants and polynomial degree may depend arbitrarily on the fixed \(\epsilon\); the reduction itself does not depend on \(\epsilon\).

Together with the exact treatment of edgeless graphs, this would give a polynomial-time \(n^{1-2\epsilon}\)-approximation for Maximum Independent Set. Taking \(\delta=2\epsilon\in(0,1)\) contradicts the stated hardness theorem unless \(\mathsf P=\mathsf{NP}\).

Why normalization does not obstruct the transfer

There is also a direct transfer from explicitly listed voters. For \(N\) voters, let \(k_A\) count those with approval type \(A\), and retain each occurring type once with mass \(\mu_A=k_A/N\). Then

\(\displaystyle U_\mu(X)=\frac1N\sum_{v=1}^{N}|A_v\cap X|.\)

Feasibility is unchanged, and both the optimum and every bundle’s utility are scaled by \(1/N\), preserving every multiplicative approximation factor. There are at most \(N\) supported types, and each mass needs \(O(\log N)\) bits, so this conversion is polynomial in the explicit-voter input length. This transfers the supplied finite-voter hardness theorem as well. [Jain et al., Theorem 36](https://arxiv.org/html/2012.05213v2#S6).
