The continuous mirror question, as graded

Given finite type sets \(I,J\), positive rational masses \(p_i,q_j\) with \(\sum_i p_i=\sum_j q_j=\tfrac12\), and nonnegative rational surpluses \(a_{ij}\), let feasible assignment flows satisfy \(x_{ij}\ge0\), \(\sum_jx_{ij}\le p_i\), and \(\sum_ix_{ij}\le q_j\). Let \(W\) be the maximum of \(\sum_{i,j}a_{ij}x_{ij}\). A core payoff assigns rates \(u_i,v_j\ge0\) satisfying \(u_i+v_j\ge a_{ij}\) and \(\sum_i p_i u_i+\sum_jq_jv_j=W\). Compute, for every type pair, the exact rational bound \(\ell_{ij}=\min\{u_i+v_j:(u,v)\text{ is a core payoff}\}\), with a core payoff attaining each bound.

Packaged proof task (what the prover saw — nothing else)

Let \(I,J\) be disjoint nonempty finite type sets, with positive binary rational masses satisfying \(\sum_i p_i=\sum_j q_j=\tfrac12\), and nonnegative binary rational surpluses \(a_{ij}\).
A society is given by its support: the list of types with positive mass and their masses. Set \(\tau=|I|+|J|\), the support size rather than the number of possible types, \(m=\max\{|I|,|J|\}\), and let \(L\) be the total binary input length.
Feasible assignment flows satisfy \(x_{ij}\ge0\), \(\sum_jx_{ij}\le p_i\), and \(\sum_ix_{ij}\le q_j\); let \(W=\max_x\sum_{i,j}a_{ij}x_{ij}\).
A core payoff consists of real rates \(u_i,v_j\ge0\) with \(u_i+v_j\ge a_{ij}\) for every pair and \(\sum_i p_i u_i+\sum_jq_jv_j=W\).
The computational problem is to return, for every \((i,j)\in I\times J\), the exact rational value \(\ell_{ij}=\min\{u_i+v_j:(u,v)\text{ is a core payoff}\}\) and a rational core payoff attaining it; different pairs may have different attaining payoffs.

Is this exact computation problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite assignment games, exact mixed-pair core lower bounds can be computed by an algorithm using \(O(m^4)\) elementary operations, once an optimal matching is placed on the diagonal of the square matrix augmented with dummy players.
The algorithm preserves the core and terminates within \(m\) iterations. [Source](http://unipub.lib.uni-corvinus.hu/1722)

Modeling choices made when packaging the task

  • Treat the two sides as disjoint nonempty type sets.
  • Define m as the larger side's support size, tau as the combined support size, and L as the total binary input length.
  • Allow real core payoff rates, require rational output witnesses, and permit a separate attaining payoff for each pair.

Conclusion

The exact computation problem is polynomial-time solvable in \(m,\tau,L\). Each pair can be handled by a rational linear program of polynomial size, which returns both its exact lower bound and an attaining rational core payoff.

The proof below uses precisely the fractional flows and payoff rates specified in the question.

1. The core is nonempty and compact

Write \(r=|I|\), \(s=|J|\), and \(A=\max_{i,j}a_{ij}\). The assignment-flow linear program has dual

\(\displaystyle \min_{u,v}\left\{\sum_i p_i u_i+\sum_jq_jv_j:\ u_i,v_j\ge0,\ u_i+v_j\ge a_{ij}\text{ for all }i,j\right\}.\)

Indeed, \(u_i\) and \(v_j\) are the nonnegative dual variables for the row and column capacity inequalities. The dual constraint for \(x_{ij}\) is \(u_i+v_j\ge a_{ij}\).

The primal is feasible because \(x=0\) is feasible. Its feasible set is closed and bounded, since \(0\le x_{ij}\le p_i\), so its maximum is attained. Moreover,

\(\displaystyle 0\le \sum_{i,j}a_{ij}x_{ij}\le A\sum_{i,j}x_{ij}\le A\sum_i p_i=\frac A2.\)

Thus \(0\le W\le A/2\). The dual is feasible: take \(u_i=A\) and \(v_j=0\). Strong linear-programming duality therefore gives an attained dual minimum equal to \(W\). Consequently, the core defined in the question is exactly the nonempty set of dual optimal solutions.

For every core payoff, nonnegativity and the budget equality imply

\(\displaystyle 0\le u_i\le \frac{W}{p_i},\qquad 0\le v_j\le \frac{W}{q_j}.\)

All masses are strictly positive, so these bounds are finite. The core is also closed, being defined by finitely many linear inequalities and one equality. Hence it is compact, and every requested minimum is attained.

2. A linear program computing one pair

We can construct each required linear program directly from the input, without first computing \(W\).

Fix a target pair \((i_0,j_0)\). Introduce variables \(x_{ij},u_i,v_j\), and minimize \(u_{i_0}+v_{j_0}\) subject to:

  • \(x_{ij}\ge0\) for every pair.
  • \(\sum_jx_{ij}\le p_i\) for every \(i\), and \(\sum_ix_{ij}\le q_j\) for every \(j\).
  • \(u_i,v_j\ge0\), and \(u_i+v_j\ge a_{ij}\) for every pair.
  • \(\displaystyle \sum_{i,j}a_{ij}x_{ij}=\sum_i p_i u_i+\sum_jq_jv_j.\)

Call this linear program \(F_{i_0j_0}\).

Claim. The projection of its feasible set onto the payoff variables is exactly the core.

Proof. For any feasible triple, primal feasibility gives

\(\displaystyle \sum_{i,j}a_{ij}x_{ij}\le W,\)

while dual feasibility and weak duality give

\(\displaystyle W\le \sum_i p_i u_i+\sum_jq_jv_j.\)

The imposed equality forces both quantities to equal \(W\). Therefore \((u,v)\) is a core payoff.

Conversely, let \((u,v)\) be any core payoff and choose any optimal primal flow \(x^*\), whose existence was proved above. Both objectives equal \(W\), so \((x^*,u,v)\) satisfies all constraints of \(F_{i_0j_0}\). This proves the claim.

It follows that the optimal value of \(F_{i_0j_0}\) is precisely \(\ell_{i_0j_0}\). The payoff coordinates of any optimal solution constitute an attaining core payoff.

The feasible set is nonempty by the converse construction. It is compact: the flow coordinates satisfy the capacity bounds, and the payoff coordinates satisfy the bounds from Section 1. Thus this linear program has an attained optimum.

3. Polynomial time and exact rational output

We use the standard exact rational linear-programming theorem: a linear program with binary rational data can be solved in time polynomial in its encoding length, returning an exact rational optimal solution whenever it is feasible and has a finite optimum. This theorem includes lower-dimensional feasible sets. See [MIT’s notes on linear-programming algorithms](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html).

Each \(F_{i_0j_0}\) has

\(\displaystyle d=rs+r+s=rs+\tau\)

variables and \(O(rs+\tau)\) constraints. Every coefficient is an input mass, an input surplus, or one of \(0,1,-1\). Consequently, even a dense encoding has length polynomial in \(m,\tau,L\).

All hypotheses of the theorem hold: the data are rational, the constraints are explicitly listed, and feasibility and attainment were proved above. Solving one such program for each pair uses \(rs\le m^2\) calls, so the total running time is polynomial in \(m,\tau,L\).

For completeness, exact output also has polynomial encoding length. Let \(Q\) be the product of the denominators of all input masses and surpluses. Its binary length is \(O(L)\). Multiplying every constraint by \(Q\) gives integer coefficients and right-hand sides bounded in absolute value by \(H=2^{O(L)}\).

A linear objective over a nonempty compact polyhedron attains its optimum at a vertex. At such a vertex, the active constraint normals span the full variable space: otherwise, a nonzero direction orthogonal to all active normals would allow sufficiently small feasible movements in both directions, contradicting extremality. Choose \(d\) independent active constraints and write their equations as \(Bz=b\).

Cramer’s rule gives

\(\displaystyle z_k=\frac{\det B_k}{\det B},\)

where \(B_k\) replaces column \(k\) of \(B\) by \(b\). Since every entry is bounded by \(H\), the determinant expansion yields

\(\displaystyle |\det B|,\ |\det B_k|\le d!H^d.\)

Also, \(\det B\ne0\). Hence each coordinate has numerator and denominator of binary length \(O(d(L+\log d))\). The sum of the two target payoff coordinates has the same polynomial bound. Thus rational attaining payoffs and exact lower bounds exist with polynomial encoding length; exponentially small masses do not obstruct exact output.

4. Relation to the cited matching algorithm

The cited paper’s Algorithm Cover starts with a square matrix having an optimal matching on its diagonal; Proposition 6 establishes its iteration and elementary-operation bounds. [Núñez–Solymosi, Algorithm Cover and Proposition 6](https://unipub.lib.uni-corvinus.hu/1722/1/cewp_201415.pdf).

Applying that algorithm after expanding binary rational masses into individual players would not by itself establish the required complexity. For example, masses \(p_1=2^{-k}\), \(p_2=\tfrac12-2^{-k}\), and \(q_1=\tfrac12\), with \(k\ge2\), have encoding length \(O(k)\). Expansion into units of mass \(2^{-k}\) creates \(2^{k-1}\) players on each side.

The linear programs above operate directly on the support. They therefore establish the requested polynomial bit complexity without any expansion into players. No assertion of an \(O(m^4)\) bound for this weighted representation is needed.
