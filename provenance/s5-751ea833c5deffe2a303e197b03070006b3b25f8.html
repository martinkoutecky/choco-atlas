The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), rational \(\alpha\in(0,1)\), and a society \(\mu\) supported on \(\tau\) top-truncated ballot types, does there exist a committee \(W\subseteq C\) with \(|W|=k\) such that, for every \(\ell\in[k]\) and \(X\subseteq C\), \(M_\mu(X)\ge \alpha\ell/k\) implies \(|W\cap X|\ge\min(|X|,\ell)\)? Here \(M_\mu(X)\) is the total mass of types ranking every candidate in \(X\) above every candidate in \(C\setminus X\), under the paper's convention for unranked candidates.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\ge 1\) candidates, let \(1\le k\le m\) be an integer, and let \(\alpha\in(0,1)\) be rational and part of the input.
A ballot type \(t\) specifies a subset \(A_t\subseteq C\), possibly empty, and a strict ranking on it; every ranked candidate is strictly preferred to every unranked candidate, and unranked candidates are tied.
A society is given by its support: the list of the \(\tau\) distinct types with positive binary-rational masses \(\mu_t\), with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
For \(X\subseteq C\), define \(M_\mu(X)=\sum_{t:\,\forall x\in X\,\forall y\in C\setminus X,\ x\succ_t y}\mu_t\); the condition is vacuous when either quantified set is empty.
The decision problem asks whether there is a committee \(W\subseteq C\), \(|W|=k\), such that for every integer \(1\le\ell\le k\) and every \(X\subseteq C\), \(M_\mu(X)\ge\alpha\ell/k\) implies \(|W\cap X|\ge\min\{|X|,\ell\}\). Threshold equality triggers the requirement.

Is this decision problem solvable in polynomial time, or is it NP-hard, with running times measured in \(m,\tau,k,L\)?

For explicitly listed finite voters with top-truncated ballots, deciding existence of an \(\alpha\)-PSC committee for input \(0<\alpha<1\) is NP-complete; a given committee's PSC value is computable in polynomial time ([source](https://arxiv.org/html/2505.00520v1)).
No separate result for exactly the normalized rational-mass formulation was located.

Modeling choices made when packaging the task

  • Normalized the society's total mass to one, matching the discrete definition's division by the total number of voters.
  • Specified the admissible committee domain as an integer size between one and the number of candidates.
  • Retained possibly empty ranked subsets, as permitted by the ballot definition, and made the strict comparison and bottom-tie conventions explicit.
  • Interpreted alpha as part of the input and defined L as the total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete, with complexity measured in \(m,\tau,k,L\). Hardness holds even when every mass and the input \(\alpha\) are dyadic rationals.

The case \(k=m\) always has the valid committee \(C\); the hardness result concerns variable committee size.

1. Polynomial-time verification

For type \(t\), write its ranked candidates as \(a_{t,1},\ldots,a_{t,r_t}\), in decreasing preference order.

Lemma. For every nonempty proper subset \(X\subsetneq C\), type \(t\) contributes to \(M_\mu(X)\) if and only if
\[ X=\{a_{t,1},\ldots,a_{t,s}\} \]
for some \(1\le s\le r_t\).

To conform to the requested delimiters, the displayed identity above is equivalently \(X=\{a_{t,1},\ldots,a_{t,s}\}\).

Proof. Suppose \(t\) contributes. If \(X\) contained an unranked candidate \(x\), choose \(y\in C\setminus X\). Candidate \(x\) is either worse than \(y\), when \(y\) is ranked, or tied with \(y\), when \(y\) is unranked. Both contradict \(x\succ_t y\). Thus \(X\subseteq A_t\).

Moreover, no ranked candidate outside \(X\) can precede a ranked candidate inside \(X\), because that would also contradict the defining condition. Consequently, \(X\) is the set of the first \(|X|\) ranked candidates.

Conversely, every such prefix consists entirely of candidates strictly preferred to every candidate outside it. This proves the lemma.

Let \(\mathcal P\) be the family of distinct nonempty proper prefix sets occurring in the support. Its size is at most \(\tau m\). Because \(\alpha>0\) and \(\ell\ge1\), any set satisfying \(M_\mu(X)\ge\alpha\ell/k\) has positive mass. By the lemma, every nonempty proper such set belongs to \(\mathcal P\).

The two remaining sets impose no restriction:

  • For \(X=\varnothing\), the required intersection size is zero.
  • For \(X=C\), every committee of size \(k\) has intersection size \(k\ge\ell\).

A verifier therefore checks \(|W|=k\), enumerates \(\mathcal P\), computes \(M_\mu(X)\) for each \(X\in\mathcal P\), and checks the implication for every \(1\le\ell\le k\). The preceding argument proves that these checks are sufficient as well as necessary.

All arithmetic can be exact. If \(\mu_t=p_t/q_t\) and \(\alpha=a/b\), use the common denominator \(D=\prod_t q_t\). Writing \(M_\mu(X)=s_X/D\), the threshold comparison becomes

\(\displaystyle s_X b k\ge a\ell D.\)

The bit length of \(D\) is at most the sum of the denominator bit lengths, hence polynomial in \(L\). All integers in these comparisons have polynomial bit length. In particular, equality is tested exactly and triggers the requirement.

A direct implementation uses \(O(\tau^2m^2)\) elementary candidate comparisons and \(O(\tau m k)\) exact threshold checks, each with polynomial bit cost. Thus verification is polynomial in \(m,\tau,k,L\). A committee is a polynomial-size certificate, establishing membership in \(\mathrm{NP}\).

2. Hardness transfers to normalized dyadic masses

We use the following established result: for explicitly listed finite voters with top-truncated ballots, deciding existence of a committee satisfying \(\beta\)-PSC is \(\mathrm{NP}\)-hard when the rational input satisfies \(0<\beta<1\). Definitions 6–7 use the threshold \(|N'|\ge\beta\ell n/k\), including equality; Theorem 2 establishes hardness, with its construction choosing the rational parameter \(\beta=k/n\). [Bardal et al., Definitions 6–7 and Theorem 2](https://arxiv.org/html/2505.00520v1#S4.SS3).

Take such a finite-voter instance with \(n\ge1\). Preserve its candidate set and committee size. Let \(N\) be the smallest power of two satisfying \(N\ge n\), and add \(N-n\) empty ballots.

Merge identical ballots in this padded electorate. For every resulting type \(t\), let \(r_t\) be its positive multiplicity and define

\(\displaystyle \mu_t=\frac{r_t}{N},\qquad \alpha=\frac{\beta n}{N}.\)

These masses are positive dyadic rationals and sum to one. Also,

\(\displaystyle 0<\alpha=\frac{\beta n}{N}\le\beta<1.\)

The support has at most \(n+1\) types. Since \(N<2n\), each multiplicity and denominator has \(O(\log n)\) bits. The transformation therefore runs in polynomial time and produces an instance of polynomial bit length.

We now prove that it preserves every committee’s validity.

Fix a nonempty proper subset \(X\subsetneq C\), and let \(s(X)\) be the number of original voters who strictly prefer every member of \(X\) to every candidate outside \(X\). An empty ballot cannot satisfy this condition: choosing \(x\in X\) and \(y\notin X\) gives two tied candidates. Hence the added ballots contribute nothing, and

\(\displaystyle M_\mu(X)=\frac{s(X)}{N}.\)

For every \(1\le\ell\le k\),

\(\displaystyle M_\mu(X)\ge\frac{\alpha\ell}{k} \quad\Longleftrightarrow\quad \frac{s(X)}{N}\ge\frac{\beta n\ell}{Nk} \quad\Longleftrightarrow\quad s(X)\ge\frac{\beta n\ell}{k}.\)

The final inequality is exactly the finite-voter trigger. Indeed, the \(s(X)\) supporting voters themselves form a solid coalition over \(X\), and every solid coalition over \(X\) is a subset of these voters. Thus some sufficiently large solid coalition exists exactly when this inequality holds.

The demanded intersection size, \(\min\{|X|,\ell\}\), is unchanged. The sets \(\varnothing\) and \(C\) are automatically satisfied in both formulations. Consequently, a committee is valid in the original instance if and only if it is valid in the constructed rational-mass instance. The equivalence preserves threshold equality.

Finally, on the cited hardness instances where \(\beta=k/n\), the transformed parameter is \(\alpha=k/N\), which is itself dyadic. This proves the stated stronger hardness restriction.

3. Conclusion

Polynomial-time verification and the polynomial-time hardness reduction establish \(\mathrm{NP}\)-completeness for the exact normalized rational-mass formulation. A polynomial-time decision algorithm in \(m,\tau,k,L\) would therefore imply \(\mathrm P=\mathrm{NP}\).
