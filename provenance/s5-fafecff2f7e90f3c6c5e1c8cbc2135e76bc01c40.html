The continuous mirror question, as graded

Given a finite type set \(\mathcal T\) with masses \(\mu_t\), resource types \(\mathcal R\), additive utilities \(u(t,r)\), and rational per-capita supplies \(s_r\) with \(\sum_r s_r=L\), compute the maximum \(q\) and feasible mass assignment \(x_{t,b}\) such that \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b} b_r x_{t,b}=s_r\), and every bundle \(b\) with \(x_{t,b}>0\) gives its recipient utility \(\sum_r b_r u(t,r)\ge q\). Each bundle contains exactly \(L\) indivisible resources; determine the complexity as a function of the type supports and \(L\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\geq1\) types \(t\in\mathcal T\) with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types.
There are \(m\geq1\) resource types \(r\in\mathcal R\), strictly positive binary-rational additive utilities \(u(t,r)\), and nonnegative binary-rational per-capita supplies \(s_r\). A positive integer \(\ell\), encoded in binary, satisfies \(\sum_r s_r=\ell\).
A bundle is a multiset \(b\in\mathcal B_\ell:=\{b\in\mathbb Z_{\geq0}^{m}:\sum_r b_r=\ell\}\); multiple resources of the same type are allowed.
An assignment consists of nonnegative masses \(x_{t,b}\) satisfying \(\sum_bx_{t,b}=\mu_t\) and \(\sum_{t,b}b_rx_{t,b}=s_r\). It guarantees \(q\) when \(x_{t,b}>0\) implies \(\sum_rb_ru(t,r)\geq q\): the guarantee applies to every received bundle, rather than expected utility.
Compute the maximum guaranteed \(q\) and an attaining assignment, represented by its nonzero entries. Let \(L\) be the total input bit length; express running times in \(m,\tau,L,\ell\), distinguishing polynomial dependence on \(\ell\) from polynomial dependence on its encoding length.

Is this exact mass-allocation problem solvable in polynomial time, or is deciding feasibility for a binary-rational threshold \(q\) NP-hard?

Result

Threshold feasibility is \(\mathrm{NP}\)-complete, even with \(\tau=1\), strictly positive integer utilities, supplies \(s_r=1/2\), and \(\ell=m/2\). Consequently, computing the exact optimum and an attaining assignment is \(\mathrm{NP}\)-hard.

There are nevertheless exact polynomial-time algorithms when either \(\ell\) or \(m\) is fixed. For fixed \(m\), the running time is polynomial in the encoding length of \(\ell\). Every instance has an optimal assignment with at most \(m+\tau-1\) nonzero entries and polynomially encoded rational masses.

The proofs and running times follow.

1. Threshold feasibility and sparse certificates

Write \(U_t(b)=\sum_r b_ru(t,r)\), and define the admissible bundles for threshold \(q\) by

\(\displaystyle G_t(q)=\{b\in\mathbb Z_{\geq0}^{m}:\ \sum_r b_r=\ell,\ U_t(b)\geq q\}.\)

Threshold feasibility is exactly the following finite rational linear feasibility problem:

\(\displaystyle \sum_{b\in G_t(q)}x_{t,b}=\mu_t\quad(t\in\mathcal T),\)

\(\displaystyle \sum_t\sum_{b\in G_t(q)}b_rx_{t,b}=s_r\quad(r\in\mathcal R),\qquad x_{t,b}\geq0.\)

Restricting the variables to \(G_t(q)\) enforces the guarantee on every bundle receiving positive mass.

Sparse-certificate lemma

Claim. If threshold \(q\) is feasible, it has an assignment with at most \(m+\tau-1\) nonzero entries. Its bundle coordinates and rational masses have encoding length polynomial in the input length.

Proof. Let \(A\) denote the constraint matrix. Its column corresponding to \((t,b)\) is

\(\displaystyle a_{t,b}=(e_t,b)\in\mathbb Z^{\tau+m},\)

where \(e_t\) is the type indicator vector. Write the right-hand side as \(h=(\mu,s)\).

For every column, the sum of its resource coordinates is \(\ell\) times the sum of its type coordinates. Consequently,

\(\displaystyle \operatorname{rank}(A)\leq m+\tau-1.\)

Choose a feasible assignment with minimum support. Suppose its supported columns were linearly dependent. There would then be a nonzero vector \(w\), supported on those columns, satisfying \(Aw=0\). Summing the type coordinates gives \(\sum_jw_j=0\), so \(w\) has both positive and negative entries.

Set

\(\displaystyle \lambda=\min_{j:w_j>0}\frac{x_j}{w_j}.\)

Then \(x-\lambda w\) is nonnegative, satisfies the same equalities, and has strictly smaller support. This contradicts minimality. Thus the supported columns are independent, and their number \(k\) is at most \(m+\tau-1\).

Select \(k\) rows on which these columns form a nonsingular square matrix \(M\). Every entry of \(M\) is an integer of absolute value at most \(\ell\). Let \(Q_h\) be the product of the denominators of the entries of \(h\). Its encoding length is at most \(L\). Also, every entry of \(h\) is between zero and \(\ell\).

Cramer's rule gives

\(\displaystyle x_j=\frac{\det M_j}{Q_h\det M},\)

where \(M_j\) replaces column \(j\) of \(M\) by the selected coordinates of \(Q_hh\). Hadamard's inequality yields

\(\displaystyle |\det M|\leq k^{k/2}\ell^k,\qquad |\det M_j|\leq Q_hk^{k/2}\ell^k.\)

Each mass therefore needs

\(\displaystyle O\!\left(L+k\log(\ell+1)+k\log(k+1)\right)\)

bits. Each bundle needs \(O(m\log(\ell+1))\) bits. This proves the claim. \(\square\)

A verifier can check such a certificate using exact rational arithmetic: check the type masses, resource totals, bundle cardinalities, nonnegativity, and every supported bundle's utility. All these checks take polynomial time. Hence threshold feasibility belongs to \(\mathrm{NP}\), including when \(\ell\) is binary encoded.

2. Hardness with one supported type

We reduce from positive-integer \(\mathrm{PARTITION}\): given binary-encoded positive integers \(a_1,\ldots,a_n\), decide whether some \(I\subseteq\{1,\ldots,n\}\) satisfies

\(\displaystyle 2\sum_{i\in I}a_i=\sum_{i=1}^na_i.\)

This is a standard \(\mathrm{NP}\)-complete problem. [Karp, *Reducibility Among Combinatorial Problems*](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf)

Construction

Define

\(\displaystyle A_0=\sum_{i=1}^na_i,\qquad B=n+1,\qquad D_0=2nA_0+1.\)

There is one supported type, with mass one. For each \(i\), create two resource types \((i,0)\) and \((i,1)\). Set

\(\displaystyle m=2n,\qquad \ell=n,\qquad s_{i,0}=s_{i,1}=\frac12,\)

and give the single type utilities

\(\displaystyle u(i,\varepsilon)=1+D_0B^{i-1}+2\varepsilon a_i,\qquad \varepsilon\in\{0,1\}.\)

The threshold is

\(\displaystyle q_0=n+D_0\sum_{i=1}^nB^{i-1}+A_0.\)

All utilities are strictly positive integers. The supplies satisfy

\(\displaystyle \sum_{i,\varepsilon}s_{i,\varepsilon}=n=\ell.\)

The supplies force the average utility to equal the threshold

For any assignment satisfying the supplies,

\(\displaystyle \sum_bx_bU(b)=\sum_{i,\varepsilon}s_{i,\varepsilon}u(i,\varepsilon)=\frac12\sum_i\bigl(u(i,0)+u(i,1)\bigr)=q_0.\)

If this assignment guarantees \(q_0\), then

\(\displaystyle \sum_bx_b\bigl(U(b)-q_0\bigr)=0.\)

Every summand is nonnegative. Therefore every bundle receiving positive mass has utility exactly \(q_0\).

Characterization of bundles of utility exactly \(q_0\)

Consider any bundle of cardinality \(n\). Put

\(\displaystyle c_i=b_{i,0}+b_{i,1},\qquad z=\sum_i a_ib_{i,1}.\)

The equality \(U(b)=q_0\) becomes

\(\displaystyle D_0\left(\sum_i c_iB^{i-1}-\sum_iB^{i-1}\right)+(2z-A_0)=0.\)

Since \(\sum_i b_{i,1}\leq n\) and \(a_i\leq A_0\), we have \(0\leq z\leq nA_0\). In particular,

\(\displaystyle |2z-A_0|\leq2nA_0<D_0.\)

The expression in parentheses is an integer. A nonzero multiple of \(D_0\) has absolute value at least \(D_0\), so the displayed equality forces both

\(\displaystyle \sum_i c_iB^{i-1}=\sum_iB^{i-1}\qquad\text{and}\qquad 2z=A_0.\)

Moreover, \(0\leq c_i\leq n=B-1\). Reducing the first equality modulo \(B\) gives \(c_1=1\). Subtracting that digit and dividing by \(B\), then repeating, gives

\(\displaystyle c_i=1\quad\text{for every }i.\)

Thus the bundle chooses exactly one resource from each pair. If \(I=\{i:b_{i,1}=1\}\), the second equality is precisely

\(\displaystyle 2\sum_{i\in I}a_i=A_0.\)

Conversely, any such partition defines a bundle of utility \(q_0\) by choosing \((i,1)\) for \(i\in I\) and \((i,0)\) otherwise.

Equivalence and encoding length

If the allocation instance is feasible at \(q_0\), some positive-mass bundle exists. By the preceding argument, that bundle defines a partition.

If a partition \(I\) exists, its complement is also a partition. Assign mass \(1/2\) to the bundle defined by \(I\) and mass \(1/2\) to the bundle defined by its complement. Each resource appears once across these two bundles, so every resource total is \(1/2\). Both bundles have utility \(q_0\).

Therefore,

\(\displaystyle \text{allocation feasible at }q_0\quad\Longleftrightarrow\quad\text{the PARTITION instance is a yes-instance}.\)

Each constructed utility and the threshold have

\(\displaystyle O\!\left(\log(A_0+1)+n\log(n+1)\right)\)

bits. The construction consequently takes polynomial time.

Combined with membership in \(\mathrm{NP}\), this proves \(\mathrm{NP}\)-completeness. Because \(\ell=n=m/2\), the reduction also works when \(\ell\) is written in unary. Thus an algorithm polynomial jointly in \(m,\tau,L,\ell\) would imply \(\mathrm P=\mathrm{NP}\).

3. Computing the exact optimum by explicit enumeration

Existence, attainment, and the utility grid

An assignment always exists before imposing a utility threshold. For the pure bundle \(\ell e_r\), set

\(\displaystyle x_{t,\ell e_r}=\frac{\mu_ts_r}{\ell}.\)

Its type masses and resource totals satisfy the required equalities, because \(\sum_rs_r=\ell\) and \(\sum_t\mu_t=1\).

There are finitely many bundles. Every assignment's guarantee is the minimum utility among its positive-mass entries, hence belongs to the finite set

\(\displaystyle V=\{U_t(b):t\in\mathcal T,\ b\in\mathcal B_\ell\}.\)

The set of attained guarantees is a nonempty subset of \(V\), so it has a maximum \(q^\star\). Applying the sparse-certificate lemma at \(q^\star\) gives a sparse attaining assignment.

For an exact search, write each utility as a rational number and let \(D\) be the product of all utility denominators. Define

\(\displaystyle W=\max_{t,r}Du(t,r)\in\mathbb Z_{>0}.\)

Every bundle utility is an integer multiple of \(1/D\), and

\(\displaystyle q^\star=\frac{j^\star}{D}\quad\text{for some integer }0\leq j^\star\leq\ell W.\)

The numbers \(D\) and \(W\) have \(O(L)\) bits. Threshold feasibility is monotone, so binary search over these integers finds \(j^\star\) using

\(\displaystyle O\!\left(L+\log(\ell+1)\right)\)

threshold queries. A final feasible solution at \(j^\star/D\) attains the optimum.

Enumeration algorithm and its running time

The number of bundles is

\(\displaystyle H=\binom{\ell+m-1}{m-1}.\)

Enumerate these bundles, compute their utilities for every supported type, and solve the explicit threshold LP for each binary-search query. Return a basic feasible solution at the optimal threshold.

Polynomial-time rational LP algorithms give an overall bit running time of

\(\displaystyle \left(\tau H+m+L+\log(\ell+1)\right)^{O(1)}.\)

For feasibility at a separately supplied threshold, replace \(L\) by \(L+\operatorname{bits}(q)\).

The relevant parameter distinctions are:

| Regime | Running-time bound for this algorithm |
|---|---|
| General input | \(\left(\tau\binom{\ell+m-1}{m-1}+m+L+\log(\ell+1)\right)^{O(1)}\) |
| Fixed \(\ell\) | \(\left(\tau m^\ell+m+L\right)^{O(1)}\) |
| Fixed \(m\), using enumeration | \(\left(\tau(\ell+1)^{m-1}+m+L+\log(\ell+1)\right)^{O(1)}\) |

Here \(H\leq m^\ell\), because every multiset is represented by an ordered resource sequence of length \(\ell\), and \(H\leq(\ell+1)^{m-1}\), because the first \(m-1\) coordinates determine a bundle.

For fixed \(\ell\), this is polynomial in the input length. For fixed \(m\), the enumeration bound is polynomial in the numerical value of \(\ell\), which can be exponential in its binary encoding length. The next section gives a stronger fixed-\(m\) algorithm.

4. Fixed resource dimension: polynomial dependence on the encoding of \(\ell\)

We use two established algorithmic results:

  • Integer linear feasibility with a fixed number of integer variables is polynomial-time solvable and returns a feasible integer point when one exists. [Lenstra, *Integer Programming with a Fixed Number of Variables*](https://pub.math.leidenuniv.nl/~lenstrahw/PUBLICATIONS/1983i/art.pdf)
  • The constructive ellipsoid LP theorem gives exact optimization from a strong separation oracle, using polynomially many oracle calls and polynomial bit complexity when dimension, coefficient encoding bounds, and a bounding box are known. Its dual-recovery form returns optimal multipliers supported on polynomially many oracle-generated inequalities. [Grötschel–Lovász–Schrijver, *Geometric Algorithms and Combinatorial Optimization*](https://link.springer.com/book/10.1007/978-3-642-78240-4)

Here is their application, including recovery of an assignment.

A bounded dual LP

For a fixed threshold, let \(A\) contain the admissible columns \(a_{t,b}=(e_t,b)\), and retain \(h=(\mu,s)\). Introduce nonnegative slack vectors \(z^+\) and \(z^-\), and consider

\(\displaystyle \min\ \sum_{i=1}^{\tau+m}(z_i^++z_i^-)\quad\text{subject to }Ax+z^+-z^-=h,\quad x,z^+,z^-\geq0.\)

This LP is feasible: take \(x=0\), \(z^+=h\), and \(z^-=0\). Its objective is bounded below by zero. Its optimum is zero exactly when the original threshold allocation is feasible.

Its dual, with variables \(y=(\alpha,\beta)\in\mathbb R^{\tau+m}\), is

\(\displaystyle \max\ h^\mathsf Ty,\)

subject to

\(\displaystyle -1\leq y_i\leq1,\qquad \alpha_t+\sum_r\beta_rb_r\leq0\quad(t\in\mathcal T,\ b\in G_t(q)).\)

The dual is nonempty, contains zero, and lies in the known box \([-1,1]^{\tau+m}\). Strong LP duality applies because the primal is feasible with finite optimum.

Strong separation in fixed integer dimension

Check the box constraints directly. For each type \(t\), a violated bundle inequality exists exactly when there is an integer vector \(b\) satisfying

\(\displaystyle b_r\geq0,\qquad \sum_rb_r=\ell,\qquad \sum_ru(t,r)b_r\geq q,\qquad \alpha_t+\sum_r\beta_rb_r>0.\)

This has exactly \(m\) integer variables.

To handle the strict inequality, let \(E\) clear the denominators of \(\alpha_t,\beta_1,\ldots,\beta_m\). On integer vectors, it is equivalent to

\(\displaystyle E\alpha_t+\sum_rE\beta_rb_r\geq1.\)

Clearing denominators in the other inequalities also preserves polynomial encoding length. Lenstra's theorem therefore applies for fixed \(m\). A feasible integer point supplies an actual violated dual inequality; if no type supplies one, all bundle inequalities hold. This is a strong separation oracle.

All dual inequality coefficients are integers of absolute value at most \(\ell\); the dimension is \(\tau+m\); the objective has input encoding length; and the bounding box is explicit. Thus the hypotheses of the constructive ellipsoid LP theorem are satisfied.

Exact feasibility, assignment recovery, and optimization

Optimize the bounded dual exactly. A positive optimum means threshold infeasibility. A zero optimum means feasibility.

In the latter case, dual recovery provides an optimal solution of the slack primal using polynomially many admissible columns. Since its objective is zero, all slack entries vanish. Solving the allocation LP restricted to those columns gives an assignment; choosing a basic feasible solution bounds its support by \(m+\tau-1\).

For fixed \(m\), this decides feasibility and produces an assignment in time polynomial in \(\tau\), the input bit length, and \(\log(\ell+1)\). Applying the utility-grid binary search from Section 3 therefore computes the exact optimum and a sparse attaining assignment in

\(\displaystyle \left(\tau+L+\log(\ell+1)\right)^{O_m(1)}.\)

The exponent may depend on \(m\). This is polynomial in the binary encoding length of \(\ell\), unlike fixed-\(m\) bundle enumeration.
