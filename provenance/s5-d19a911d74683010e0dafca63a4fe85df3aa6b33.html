The continuous mirror question, as graded

Given a uniform prior on \(s\in\{A,B\}\), private-signal accuracy \(p\in(1/2,1)\), and a common public signal of accuracy \(q\in(p,1)\), assign ex ante mass \(\rho_r\) to each deterministic voting plan \(r:\{A,B\}^2\to\{A,B\}\). Each plan group receives private signals with the paper's conditional accuracy \(p\), and all voters observe the same public signal. Which distribution \((\rho_r)\) maximizes the probability that the mass-majority vote matches \(s\), and what accuracy does it attain?

Packaged proof task (what the prover saw — nothing else)

There are \(m=2\) alternatives, \(A\) and \(B\), and a uniform prior on the state \(s\in\{A,B\}\). Inputs are binary rationals \(1/2<p<q<1\).
A deterministic voting plan is any map \(r:\{A,B\}^2\to\{A,B\}\), with arguments private signal and public signal, respectively. Before signals arrive, choose nonnegative rational masses \(\rho_r\) over all sixteen plans, with \(\sum_r\rho_r=1\); no equilibrium constraint is imposed.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here types are voting plans and \(\tau\le16\) is the support size, not the number of possible types. State running times in \(m\), \(\tau\), and the binary input length \(L\).
Conditional on \(s\), the common public signal \(e\) equals \(s\) with probability \(q\). In every plan group, exactly a fraction \(p\) receives private signal \(s\), independently of \(e\), and the remaining fraction receives the other signal \(\bar s\).
Thus the mass voting for \(A\), conditional on \((s,e)\), is \(V_A(s,e)=\sum_r\rho_r\bigl(p\mathbf1_{r(s,e)=A}+(1-p)\mathbf1_{r(\bar s,e)=A}\bigr)\). The decision is \(A\) if \(V_A>1/2\), \(B\) if \(V_A<1/2\), and an independent fair coin at equality. Accuracy is \(\Pr[y=s]\).

Can an accuracy-maximizing mass distribution and its exact accuracy be computed in polynomial time, or is deciding whether some distribution attains accuracy at least an input binary rational \(a\in[0,1]\) NP-hard?

For odd finite committee size \(n\), the [2015 finite result](https://www.econ.ed.ac.uk/papers/id261_esedps.pdf) asserts that \(k^*=\lfloor\log(q/(1-q))/\log(p/(1-p))\rfloor\) public-signal followers, with everyone else following private signals, maximize accuracy over all strategy profiles when \(k^*<(n+1)/2\).
A [2024 finite-committee characterization](https://doi.org/10.1007/s00182-024-00886-3) also covers general majority thresholds and distinguishes integer log-odds ratios, where multiple optimal counts can occur. No result settling the exact mass-allocation problem above was located.

Modeling choices made when packaging the task

  • Signal accuracies and the decision threshold are binary rationals, making the computational input finite.
  • Total society mass is normalized to one; allocation masses are nonnegative rationals and their support is chosen by the optimizer.
  • Private-signal randomness is interpreted through exact conditional proportions within every plan group, with no aggregate sampling noise.
  • Private and public signals are independent conditional on the state; the public signal has symmetric conditional accuracy q.
  • Mass ties use an independent fair coin because odd finite committees supply no tie convention.
  • All sixteen deterministic plans are admissible, as specified by the continuous question; optimization is unrestricted by equilibrium conditions.

1. An optimal distribution and a complete proof

Define the private-signal-following plan by \(r_{\mathrm{priv}}(x,e)=x\) for every \(x,e\in\{A,B\}\). Choose \(\rho_{r_{\mathrm{priv}}}=1\), with all other masses zero. This is an admissible rational distribution, chosen before signals arrive.

For either public signal \(e\), the specified vote formula gives

\(V_A(A,e)=p\qquad\text{and}\qquad V_A(B,e)=1-p.\)

Because \(p>1/2\), in state \(A\) the decision is strictly \(A\); because \(1-p<1/2\), in state \(B\) the decision is strictly \(B\). Neither state produces a tie. Consequently, \(\Pr[y=s\mid s,e]=1\) for every state–public-signal pair, and the unconditional accuracy is \(1\).

Every accuracy is a probability and hence at most \(1\). The constructed distribution therefore attains the global maximum. This proves existence and optimality without any limiting argument or appeal to the finite-committee results.

2. Characterization of all optimal distributions

Fix a public signal \(e\). Partition the sixteen plans according to their restriction to that public signal. Let:

  • \(c_A(e)\) be the total mass whose restriction always votes \(A\);
  • \(c_B(e)\) be the total mass whose restriction always votes \(B\);
  • \(f(e)\) be the total mass whose restriction follows the private signal;
  • \(g(e)\) be the total mass whose restriction reverses the private signal.

These four classes exhaust the plans, so \(c_A(e)+c_B(e)+f(e)+g(e)=1\). Define \(C_e=c_A(e)-c_B(e)\), \(D_e=f(e)-g(e)\), and \(h=2p-1>0\).

Direct substitution yields

\(V_A(A,e)=c_A(e)+p f(e)+(1-p)g(e),\)

\(V_A(B,e)=c_A(e)+(1-p)f(e)+p g(e).\)

Using the sum-to-one identity, their majority margins are therefore

\(2V_A(A,e)-1=C_e+hD_e,\qquad 2V_A(B,e)-1=C_e-hD_e.\)

Each of the four pairs \((s,e)\) has strictly positive probability: its probability is \(q/2\) when \(e=s\), and \((1-q)/2\) otherwise. Overall accuracy equals \(1\) if and only if conditional accuracy equals \(1\) on every pair. Indeed, any conditional accuracy below \(1\) contributes a strictly positive loss.

Under the stipulated decision rule, conditional accuracy equals \(1\) precisely when the correct alternative has a strict majority; a tie gives conditional accuracy \(1/2\). Hence a distribution is optimal exactly when, for both public signals,

\(C_e+hD_e>0\qquad\text{and}\qquad C_e-hD_e<0.\)

Equivalently, the complete characterization is

\(\lvert C_e\rvert<(2p-1)D_e\qquad\text{for every }e\in\{A,B\}.\)

These inequalities also imply \(D_e>0\). They characterize optimality for arbitrary rational mixtures of all sixteen plans.

Optimality does not require small support. For example, assign mass \(17/32\) to \(r_{\mathrm{priv}}\) and mass \(1/32\) to each of the other fifteen plans. This is a half-and-half mixture of the private-following distribution and the uniform distribution over all plans. Under the uniform distribution, exactly half the plans vote \(A\) at each argument, giving \(V_A(s,e)=1/2\). Thus the proposed mixture gives

\(V_A(A,e)=\frac p2+\frac14>\frac12,\qquad V_A(B,e)=\frac{1-p}{2}+\frac14<\frac12.\)

It has support size \(\tau=16\) and accuracy \(1\).

3. Exact computation and running times

Let \(L\) denote total binary input length.

For optimization, read the input and return the single plan \(r_{\mathrm{priv}}\), mass \(1\), and exact accuracy \(1\). This takes \(O(L+m^2)=O(L)\) bit time in the stipulated model \(m=2\), and its output support size is \(\tau=1\). The threshold algorithm likewise takes \(O(L)\) time and returns “yes” for every valid \(a\in[0,1]\).

For completeness, a supplied society with support size \(\tau\) can also be evaluated exactly. Define \(H(z)=1\) for \(z>0\), \(H(0)=1/2\), and \(H(z)=0\) for \(z<0\). Its accuracy is

\(\operatorname{Acc}(\rho)=\frac q2\bigl[H(V_A(A,A)-1/2)+H(1/2-V_A(B,B))\bigr]+\frac{1-q}{2}\bigl[H(V_A(A,B)-1/2)+H(1/2-V_A(B,A))\bigr].\)

This follows by conditioning on the four pairs \((s,e)\), using the correct majority direction in each state.

There are \(m^2=4\) vote totals, each containing at most \(\tau\) contributions. A common denominator obtained from the input denominators has \(O(L)\) bits, so exact comparisons can be performed with integer arithmetic. Using schoolbook arithmetic gives a conservative bound of \(O(m^2\tau L^2)\) bit operations. This bound concerns the specified binary model; it makes no claim about a generalization to variable \(m\).

4. Why the finite-committee result does not change the conclusion

The [2015 paper](https://www.econ.ed.ac.uk/papers/id261_esedps.pdf) assumes independently distributed private signals in a finite committee. In that setting, even if everyone follows their private signal, the event that every private signal is wrong has probability \((1-p)^n>0\), and on that event the majority decision is wrong.

Here, conditional on the state, the correct private-signal fraction is exactly \(p>1/2\). Thus private followers have a correct majority on every realization permitted by the model. That exact premise settles the mass-allocation problem; finite-committee optimal follower counts need not be transferred to it.
