The continuous mirror question, as graded

Given a finite candidate set \(C\), a distribution \(\mu\) over complete rankings of \(C\) with \(\tau\) positive-mass types, and fixed \(k\ge3\), decide whether \(C\) can be partitioned into \(k\) sets such that, after restricting the rankings to each set and aggregating identical projections, the positive-mass rankings can be ordered so that each preference direction for every candidate pair occupies an interval.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\) candidates, and fix an integer \(k\ge 3\), with \(m\ge k\). Rankings are strict total orders.
A society is given by its support: a list of \(\tau\) distinct rankings with positive binary-rational masses summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
For \(S\subseteq C\), restrict every ranking to \(S\), aggregate identical restrictions by summing their masses, and retain the resulting positive-mass rankings.
Call this restricted society single-crossing if its rankings admit a linear order such that, for every distinct \(a,b\in S\), both the rankings preferring \(a\) to \(b\) and those preferring \(b\) to \(a\) form intervals; empty intervals are allowed.
The decision problem asks whether \(C\) can be partitioned into exactly \(k\) nonempty sets whose restricted societies are single-crossing. Each set may use its own ordering of rankings.

For every fixed \(k\ge 3\), is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite voter profiles, candidate partition into \(k\) single-crossing sets is NP-complete for every fixed \(k\ge 3\) (Jaeckle, Peters, and Elkind, 2018). Recognition of a single-crossing finite profile is polynomial-time.

Modeling choices made when packaging the task

  • Interpreted complete rankings as strict total orders, following the discrete preference domain.
  • Normalized the positive rational masses to sum to one, as required by a distribution.
  • Interpreted partition as exactly k nonempty parts and restricted the domain to m at least k; the supplied definition does not explicitly settle whether empty parts are permitted.
  • Made explicit that each part may have its own ranking order, as required by the discrete definition.
  • Allowed empty intervals so that unanimous pairwise preferences satisfy the single-crossing condition.
  • Defined L as the total encoded input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed \(k\ge 3\), the decision problem is \(\mathrm{NP}\)-complete. The essential point is that deleting duplicate rankings preserves single-crossingness, including duplicates created by restricting candidates.

1. Duplicate rankings do not affect single-crossingness

For a finite profile \(P\), let \(D(P)\) contain exactly one copy of each distinct ranking occurring in \(P\).

Lemma. The profile \(P\) is single-crossing if and only if \(D(P)\) is single-crossing.

Proof. For any candidate pair, record its comparison along an ordering of the voters as a binary sequence. Both comparison classes are intervals exactly when this sequence changes value at most once: two or more changes would give three positions with values \(x,1-x,x\), violating the interval condition for value \(x\).

Suppose \(P\) has a single-crossing ordering. Keep one occurrence of each distinct ranking and delete the others. Each pair’s comparison sequence becomes a subsequence, so it still changes value at most once. The induced ordering therefore witnesses single-crossingness of \(D(P)\).

Conversely, suppose \(D(P)\) has a single-crossing ordering. Replace each ranking by a consecutive block containing all its occurrences in \(P\). For every candidate pair, this merely repeats each binary value consecutively and introduces no additional change. This witnesses single-crossingness of \(P\). \(\square\)

Now let \(P|_S\) denote restriction of a finite profile to \(S\). If a society’s support consists of the distinct rankings occurring in \(P\), its aggregated restriction has support exactly \(D(P|_S)\). Indeed, both contain precisely the distinct rankings obtained by restricting rankings occurring in \(P\); positivity ensures that aggregation removes none of them.

Consequently, for every \(S\subseteq C\), the restricted society is single-crossing if and only if \(P|_S\) is single-crossing. The numerical values of the positive masses play no role.

2. Polynomial reduction from finite profiles

Fix \(k\ge 3\). Use the finite-profile candidate-partition problem stated in the question, which is \(\mathrm{NP}\)-complete for this fixed \(k\). Its single-crossing definition and allowance of a separate voter ordering for each part agree with the present problem. See [Jaeckle, Peters, and Elkind (2018), Theorem 7](https://dominik-peters.de/publications/nearlysc.pdf).

Given an explicitly listed finite profile \(P=(v_1,\ldots,v_n)\), compute its distinct rankings \(r_1,\ldots,r_\tau\). Here \(\tau\le n\), and deduplication takes polynomial time.

Assign positive dyadic masses as follows. Let \(q=\lceil\log_2\tau\rceil\), and set
\[ w_j=\frac{1}{2^q}\quad(1\le j<\tau),\qquad w_\tau=\frac{2^q-\tau+1}{2^q}. \]
All masses are positive because \(2^q\ge\tau\), and their sum is
\[ \sum_{j=1}^{\tau}w_j =\frac{\tau-1+2^q-\tau+1}{2^q}=1. \]
This also covers \(\tau=1\), giving mass \(1\). Each mass requires \(O(\log(\tau+1))\) bits, so the resulting society has polynomial encoding length. This construction works even if “binary-rational” is interpreted as requiring a finite binary expansion.

Keep the candidate set and \(k\) unchanged. For every partition \(C=S_1\mathbin{\dot\cup}\cdots\mathbin{\dot\cup}S_k\) into nonempty sets, Section 1 gives, separately for each part,
\[ P|_{S_i}\text{ is single-crossing} \quad\Longleftrightarrow\quad \text{the constructed society restricted to }S_i \text{ is single-crossing}. \]
Thus the construction preserves both yes-instances and no-instances and is a polynomial many-one reduction. The support problem is therefore \(\mathrm{NP}\)-hard.

The requirement of *exactly* \(k\) nonempty parts introduces no discrepancy if the finite-profile theorem is phrased using at most \(k\) parts. Single-crossingness is hereditary under candidate restriction: the same voter ordering works for any subset of candidates, and the lemma permits subsequent aggregation. When \(m\ge k\), any partition into fewer than \(k\) nonempty valid parts can repeatedly split a part of size at least two until exactly \(k\) parts remain. Such a part must exist whenever the current number of parts is less than \(k\).

3. Membership in \(\mathrm{NP}\)

A certificate consists of a partition into \(k\) nonempty candidate sets and, for each part, a permutation of the \(\tau\) original support indices.

For each part, the verifier restricts all support rankings to that part without aggregating duplicates. It then checks, for every candidate pair in the part, that its comparison sequence along the certified permutation changes value at most once.

By the lemma, an ordering passing these checks exists exactly when the aggregated restricted society is single-crossing. Each part has its own certified ordering, as required. The certificate has polynomial length, and all checks take polynomial time in \(m,\tau,L\). No expansion of rational masses into voters is needed.

Combining membership with the reduction proves the claimed \(\mathrm{NP}\)-completeness. In particular, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
