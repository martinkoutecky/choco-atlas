Proposition 1 — class: other

The continuous mirror question, as graded

Given a connected graph \(G=(V,E)\), a support of \(\tau\) complete edge-approval types \(B_t\subseteq E\), and binary-rational masses \(\mu_t\geq 0\) summing to \(1\), compute a spanning tree \(S\subseteq E\) maximizing \(\sum_t\mu_t|B_t\cap S|\).

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,E)\) be a finite connected simple undirected graph with \(V\ne\varnothing\), and let \(m=|E|\).
A society is given by its support: a list of \(\tau\) distinct types \(B_t\subseteq E\), each with positive binary-rational mass \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies approval or non-approval of every edge; arbitrary approval sets, including the empty set, are allowed. Non-approval contributes zero satisfaction.
Compute a spanning tree \(S\subseteq E\) maximizing \(\sum_{t=1}^{\tau}\mu_t|B_t\cap S|\). There are no edge costs, budget constraints, or additional feasibility constraints; any maximizing tree may be returned.
Let \(L\) be the total binary input length. State running times in \(m\), \(|V|\), \(\tau\), and \(L\).

Is this optimization problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For finite electorates, maximum collective spanning-tree selection is an instance of the median aggregation rule ([Boes et al.](https://arxiv.org/pdf/2112.00574)); maximizing total approval satisfaction is polynomial-time solvable ([Darmann et al.](https://comsoc-community.org/assets/proceedings/comsoc-2008/Darmann.pdf)).
No result explicitly addressing this binary-rational support representation was located in the searches performed.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is polynomial-time solvable, including with binary-rational masses given by their support. It reduces exactly to finding a maximum-weight spanning tree.

Write \(n=|V|\). If \(n=1\), the empty tree is the unique feasible solution. The argument below handles all remaining instances.

Reduction to edge weights

For every edge \(e\in E\), define its approval mass by
\(w_e=\sum_{t:e\in B_t}\mu_t\).

For any spanning tree \(S\), interchanging two finite sums gives
\(\sum_{t=1}^{\tau}\mu_t|B_t\cap S| =\sum_{t=1}^{\tau}\sum_{e\in S}\mu_t\mathbf{1}_{e\in B_t} =\sum_{e\in S}w_e\).

Consequently, the required maximizers are precisely the maximum-weight spanning trees for weights \(w_e\). Empty approval sets simply contribute nothing to these weights.

Exact arithmetic for the support representation

Use the usual binary encoding of rational numbers: write \(\mu_t=a_t/b_t\), where \(a_t,b_t\) are positive integers encoded in binary. Reduction to lowest terms is unnecessary. The argument also covers dyadic rationals given explicitly in binary.

Set \(D=\prod_{t=1}^{\tau}b_t\) and \(c_t=a_t(D/b_t)\). Every \(c_t\) is an integer, and the promised normalization gives \(\sum_{t=1}^{\tau}c_t=D\).

Define integer edge weights \(W_e=\sum_{t:e\in B_t}c_t\). Then \(W_e=Dw_e\), so maximizing \(\sum_{e\in S}W_e\) is equivalent to maximizing the original objective.

Crucially, \(D\) has only \(O(L)\) bits: its binary length is at most \(1+\sum_{t=1}^{\tau}\log_2 b_t\), and the denominators are part of the input. Moreover, \(0<c_t\le D\) and \(0\le W_e\le D\). Thus all these integers have \(O(L)\) bits. Their numerical magnitudes may be exponential in \(L\), but exact arithmetic remains polynomial in \(L\).

Algorithm and proof of optimality

Run Kruskal’s algorithm in decreasing order of \(W_e\), breaking ties arbitrarily:

  • Initialize \(F=\varnothing\).
  • Process each edge in the chosen order.
  • Add an edge to \(F\) exactly when its endpoints lie in different connected components of \((V,F)\).
  • Return \(F\).

The maintained edge set is a forest because each added edge joins distinct components. At termination it is connected: otherwise, connectedness of \(G\) supplies an edge between two final components. Its endpoints were also disconnected when it was processed, so it would have been added, a contradiction. Therefore the output is a spanning tree.

For optimality, maintain the invariant that some maximum-weight spanning tree \(T\) contains the currently selected forest \(F\). Initially this holds because a connected finite graph has at least one spanning tree, and the set of spanning trees is finite.

Suppose the next accepted edge is \(e\). If \(e\in T\), the invariant persists. Otherwise, adding \(e\) to \(T\) creates a unique cycle. The path in \(T\) between the endpoints of \(e\) contains an edge \(f\) joining different components of \((V,F)\), since the endpoints of \(e\) lie in different components. In particular, \(f\notin F\).

The edge \(f\) cannot have been processed earlier. If it had, its endpoints, which are disconnected in the current forest, would also have been disconnected in the smaller forest present then. It would therefore have been accepted and would belong to \(F\). Hence \(f\) appears after \(e\) in the processing order, giving \(W_f\le W_e\).

The set \(T'=(T\setminus\{f\})\cup\{e\}\) is a spanning tree containing \(F\cup\{e\}\), and its weight is at least that of \(T\). Since \(T\) was maximum, \(T'\) is maximum as well. This proves the invariant.

At termination, \(F\) is itself a spanning tree contained in a maximum-weight spanning tree, so it equals that tree. The returned solution therefore maximizes the original objective.

Running time

The following bounds use standard bit-cost RAM accounting, schoolbook integer arithmetic, and indexed graph vertices and edges.

Computing \(D\) and all \(c_t\) takes \(O(\tau L^2)\) bit operations. Scanning the approval information and accumulating the weights takes \(O(m\tau L)\) bit operations; for approval lists, the number of additions can instead be bounded by \(\sum_t|B_t|\).

Sorting the edges takes \(O(m\log(m+1))\) comparisons, each costing \(O(L)\) bit operations.

For cycle detection, union by size without path compression gives component trees of depth \(O(\log(n+1))\): each increase in a vertex’s depth at least doubles its component size. Thus Kruskal’s graph operations take \(O(n+m\log(n+1))\) word operations, or conservatively \(O((m+n)\log^2(n+1))\) bit operations.

Including input processing, a valid total bound is
\(O\!\left(\tau L^2+m\tau L+mL\log(m+1)+(m+|V|)\log^2(|V|+1)\right)\).

For an explicit input, \(m,\tau,|V|=O(L)\), so this is in particular \(O(L^3)\). No expansion into an electorate of size \(D\) is required.

Relation to the cited results

Darmann et al. explicitly formulate approval-tree selection as maximizing the sum of edge approval counts and solve it using maximum-spanning-tree algorithms. [Darmann et al., Section 3](https://comsoc-community.org/assets/proceedings/comsoc-2008/Darmann.pdf)

Boes et al. identify maximum collective spanning-tree selection within their aggregation framework. [Boes et al., Section 4.2](https://arxiv.org/pdf/2112.00574)

The proof above establishes directly that replacing explicit voter counts by binary-rational support masses preserves polynomial-time solvability.
