The continuous mirror question, as graded

Given a finite resource set \(M\), rational type masses \(\mu_t\) summing to \(1\), and rational piecewise-linear monotone nondecreasing utility curves \(u_t(j,z)\) for each type \(t\), resource \(j\), and population load \(z\in[0,1]\), let \(\theta_t=\max_{j\in M}u_t(j,1)\). Does there exist a mass assignment \(x_{t,j}\geq 0\) with \(\sum_j x_{t,j}=\mu_t\), loads \(y_j=\sum_t x_{t,j}\), and \(x_{t,j}>0\Rightarrow u_t(j,y_j)\geq\theta_t\) for every \(t,j\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types; assume \(\sum_{t=1}^{\tau}\mu_t=1\).
Let \(M\) be a nonempty resource set with \(m=|M|\). For every type \(t\) and resource \(j\), the input specifies a continuous monotone nondecreasing piecewise-linear function \(u_t(j,\cdot):[0,1]\to\mathbb R\) by an explicit list of rational breakpoints and rational values, with linear interpolation. Utilities may be negative. Let \(L\) be the total binary input length.
Define \(\theta_t=\max_{j\in M}u_t(j,1)\). A feasible assignment consists of real masses \(x_{t,j}\geq0\) satisfying \(\sum_{j\in M}x_{t,j}=\mu_t\), with loads \(y_j=\sum_{t=1}^{\tau}x_{t,j}\), such that \(x_{t,j}>0\Rightarrow u_t(j,y_j)\geq\theta_t\). Types may split their mass among resources; resources have no additional capacity constraints and may be empty.

Is deciding whether a feasible assignment exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite indivisible agents with monotone nondecreasing resource utilities depending on the number of users, deciding whether every agent can attain her threshold \(\max_{j\in M}v_i(j,n)\) is NP-complete; this threshold is her maximin share.
This discrete result does not classify the mass problem specified above; no result for that exact continuous problem is verified here.

Modeling choices made when packaging the task

  • Interpreted rational piecewise-linear utility curves as continuous functions represented explicitly by rational breakpoints and values with linear interpolation.
  • Allowed signed utility values, matching the discrete valuation domain of real numbers.
  • Required a nonempty resource set so that the maximum defining each threshold is defined.
  • Allowed real assignment masses and splitting of each type, with empty resources and no additional capacity constraints, as dictated by the stated mass formulation.
  • Defined L as the total binary input length, including masses and all utility-curve representations.

Result

The decision problem is \(\mathrm{NP}\)-complete, hence \(\mathrm{NP}\)-hard. Hardness holds even when all masses are dyadic rationals and all utilities take values in \([0,1]\) and have at most two linear pieces.

1. Reduction from Exact Cover

We use the classical \(\mathrm{NP}\)-complete Exact Cover problem: given an explicitly listed family \(\mathcal S=\{S_1,\ldots,S_r\}\), with universe \(U=\bigcup_{j=1}^r S_j\), decide whether some subfamily consists of pairwise disjoint sets whose union is \(U\). This is problem 14 in [Karp’s original paper](https://studylib.net/doc/27985824/karp1972).

Discard empty sets, which cannot affect the answer. We may assume \(U\) is nonempty: empty-universe instances are always yes and can be replaced by a fixed nonempty yes-instance. Write \(n=|U|\).

Construction

Let \(D\) be the smallest power of two strictly greater than \(n\). Thus \(n<D\leq 2n\).

Create one type for every element \(e\in U\), with mass

\(\mu_e=1/D.\)

Create one additional type \(\ast\), with mass

\(\mu_\ast=1-n/D.\)

All these masses are positive dyadic rationals, and their sum is \(1\).

Create a resource \(j\) for every set \(S_j\), together with one additional resource \(d\). For each set resource, put

\(a_j=|S_j|/D.\)

Since the sets are nonempty and \(D>n\), we have \(0<a_j<1\).

For an element type \(e\in S_j\), define

\(u_e(j,y)=\min\{y/a_j,1\}.\)

Its explicit breakpoint-value list is

\((0,0),\quad(a_j,1),\quad(1,1).\)

For \(e\notin S_j\), define \(u_e(j,y)=0\). Also define \(u_e(d,y)=0\) for every element type.

For the additional type, define

\(u_\ast(d,y)=1,\qquad u_\ast(j,y)=0\quad\text{for every set resource }j.\)

Every utility is continuous, monotone nondecreasing, and piecewise linear with rational data. Because each element belongs to some set, its utility at load \(1\) is \(1\) on at least one resource. Consequently,

\(\theta_e=1\quad(e\in U),\qquad\theta_\ast=1.\)

The constructed instance has \(\tau=n+1\) types and \(m=r+1\) resources. Each utility list has at most three entries, and every rational entry has binary length \(O(\log(n+1))\). Writing all lists explicitly therefore takes polynomial time and produces polynomial total input length.

Exact cover implies feasible assignment

Suppose a pairwise disjoint subfamily covers \(U\). Assign each element type’s entire mass to the resource corresponding to its covering set. Assign type \(\ast\) entirely to resource \(d\).

For every selected set resource,

\(y_j=\sum_{e\in S_j}\mu_e=|S_j|/D=a_j.\)

Thus every assigned element receives utility \(1=\theta_e\). Type \(\ast\) also receives utility \(1=\theta_\ast\). All other resources are empty, so this assignment is feasible.

Feasible assignment implies exact cover

Now suppose a feasible assignment exists.

Because every threshold is \(1\), a utility identically equal to \(0\) prohibits positive assigned mass. Hence:

  • Only element types belonging to \(S_j\) can use set resource \(j\).
  • Element types cannot use resource \(d\).
  • Type \(\ast\) must assign all its mass to resource \(d\).

Consider any nonempty set resource \(j\). Since \(y_j>0\), at least one element type has positive mass there. Its feasibility condition requires

\(1\leq u_e(j,y_j)=\min\{y_j/a_j,1\},\)

so \(y_j\geq a_j\).

On the other hand, only members of \(S_j\) can contribute, and mass conservation gives \(x_{e,j}\leq\mu_e=1/D\). Therefore,

\(y_j=\sum_{e\in S_j}x_{e,j}\leq |S_j|/D=a_j.\)

Both inequalities force equality. Moreover, equality in this sum forces

\(x_{e,j}=1/D\quad\text{for every }e\in S_j,\)

because every summand is at most \(1/D\).

Thus every nonempty set resource consumes the entire mass of every element in its set. Two nonempty set resources cannot have overlapping sets: an overlapping element would have to assign its entire positive mass to both, contradicting mass conservation.

Finally, every element has positive mass and must assign it somewhere. It cannot use resource \(d\), so it belongs to at least one nonempty set resource. The sets corresponding to the nonempty resources therefore form an exact cover.

This proves the required equivalence and establishes \(\mathrm{NP}\)-hardness. The argument applies to fully divisible masses: the constructed utility requirements themselves force the relevant assignments to be unsplit.

2. Membership in \(\mathrm{NP}\)

We next show that allowing real assignments does not prevent polynomial-size certificates.

Utility conditions become rational load thresholds

For every type-resource pair and every \(y\in[0,1]\), monotonicity gives

\(u_t(j,y)\leq u_t(j,1)\leq\theta_t.\)

If \(u_t(j,1)<\theta_t\), that pair can never carry positive mass.

Otherwise, \(u_t(j,1)=\theta_t\). Continuity and monotonicity imply that the set of acceptable loads is a closed interval

\(\{y\in[0,1]:u_t(j,y)\geq\theta_t\}=[a_{t,j},1].\)

Here \(a_{t,j}\) is the first listed breakpoint whose value equals \(\theta_t\). Indeed, a linear segment with both endpoint values strictly below \(\theta_t\) cannot attain \(\theta_t\), and after the first attainment monotonicity forces the utility to remain equal to \(\theta_t\).

Thus all eligible pairs and their rational thresholds \(a_{t,j}\) can be computed in polynomial time.

Every feasible instance has a short rational witness

Fix a set \(E\) of eligible pairs. Consider the polytope \(P_E\) defined by

\(x_{t,j}\geq0,\qquad \sum_jx_{t,j}=\mu_t,\)

\(x_{t,j}=0\quad\text{when }(t,j)\notin E,\)

and

\(\sum_sx_{s,j}\geq a_{t,j}\quad\text{when }(t,j)\in E.\)

If a feasible assignment exists, taking \(E\) to be its positive support makes \(P_E\) nonempty. Conversely, every point of \(P_E\) is feasible: each positive coordinate belongs to \(E\), and its required load inequality is enforced. Coordinates in \(E\) are allowed to be zero, so no strict inequalities are needed.

Let \(N=\tau m\). Every coordinate in \(P_E\) lies between \(0\) and its type’s mass, hence between \(0\) and \(1\). Therefore a nonempty \(P_E\) is compact.

It has an extreme point: successively minimize each coordinate over the compact set of minimizers of the preceding coordinates. The resulting point is unique and extreme, since any convex decomposition would have to preserve each successive minimum.

At an extreme point, the active constraint normals span all \(N\) dimensions. Otherwise, a nonzero direction orthogonal to all active normals would permit sufficiently small perturbations in both directions while preserving every constraint, contradicting extremality. Select \(N\) independent active constraints and write them as

\(Ax=b.\)

The entries of \(A\) belong to \(\{-1,0,1\}\), and the entries of \(b\) are input masses, input breakpoints, or zero. Let \(Q\) be the product of their denominators. Its binary length is \(O(NL)\), and \(Qb\) is integral.

Cramer’s rule expresses each coordinate as a ratio of integer determinants with denominator \(Q\det A\). Hadamard’s inequality bounds \(|\det A|\) by \(N^{N/2}\); the corresponding numerator determinants have magnitude at most \(QN^{N/2}\), since \(|b_i|\leq1\). Every coordinate therefore has a rational representation of binary length

\(O(NL+N\log(N+1)).\)

Consequently, every feasible instance admits a polynomial-size rational assignment. A verifier checks nonnegativity, mass conservation, loads, and the rational load thresholds by exact arithmetic in polynomial time. The problem belongs to \(\mathrm{NP}\).

Together with the reduction, this proves \(\mathrm{NP}\)-completeness. A polynomial-time algorithm in \(m,\tau,L\) therefore exists only if \(\mathrm{P}=\mathrm{NP}\).
