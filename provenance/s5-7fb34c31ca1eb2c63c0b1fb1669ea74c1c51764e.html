The continuous mirror question, as graded

Given a finite set of constituency types \(T\), rational masses \(\mu_t>0\) summing to \(1\), a directed graph of permitted delegation edges, total preorders over incoming edges, and per-member voting weights \(w_t\), set \(W_t=\mu_t w_t\). Assuming \(W_s+W_t>W_u\) for all \(s,t,u\in T\), decide whether there is a rooted arborescence \(A\) such that every feasible arborescence \(A'\) satisfies \(\Delta_W(A',A)\leq 0\), and find one if it exists, where \(\Delta_W\) is the preference margin weighted by \(W_t\).

Packaged proof task (what the prover saw — nothing else)

The input consists of finitely many templates \(q\), each with a nonempty finite directed graph \(G_q=(V_q,E_q)\), binary-encoded positive integer weights \(w_q(v)\), and explicitly listed total-preorder preferences over incoming edges. Require \(w_q(s)+w_q(t)>w_q(u)\) for all \(s,t,u\in V_q\), allowing repetitions.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here types are template-role pairs \((q,v)\), each of mass \(\lambda_q>0\), with \(\sum_q|V_q|\lambda_q=1\); \(\tau=\sum_q|V_q|\) is the support size, not the number of possible types. Set \(m=\sum_q|E_q|\), and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For each template, form \(D_q\) by adding a dummy root \(r\) and every edge \((r,v)\), strictly below every original incoming edge in \(v\)'s preferences. The root has no vote or mass. Feasible choices are spanning outward \(r\)-arborescences in \(D_q\); \(A(v)\) denotes the edge entering \(v\). Preference ties contribute zero, with no tie-breaking.
Copies of template \(q\) are indexed by \(x\in[0,\lambda_q]\) with Lebesgue measure; original edges connect roles only within the same copy. A feasible assignment \(B\) chooses an arborescence \(B_q(x)\) measurably for almost every copy. Call it popular if, for every measurable feasible assignment \(B'\),
\(\sum_q\int_0^{\lambda_q}\sum_{v\in V_q}w_q(v)\bigl(\mathbf{1}[B_q(x)(v)\succ_v B'_q(x)(v)]-\mathbf{1}[B'_q(x)(v)\succ_v B_q(x)(v)]\bigr)\,dx\geq0\).
For construction, a finite description consists of rational interval partitions of the copy intervals and one arborescence on each part.

Is deciding whether such a popular measurable assignment exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? In the polynomial-time case, can one also construct a popular assignment in time polynomial in \(m,\tau,L\)?

For finite vertex-weighted societies with these preferences and weight condition, existence and construction are polynomial-time solvable; the stated combinatorial running time is \(O(|E(D)|\,|V(G)|^2)\). [Natsui–Takazawa](https://arxiv.org/pdf/2110.03460)
No result settling this exact measurable-copy problem was located in the literature search.

Modeling choices made when packaging the task

  • The undefined root and feasible graph are settled by adding a dummy root and an incoming root edge to every role, strictly worse than every original incoming edge.
  • The unspecified weight condition is imposed within each template for every triple of roles, allowing repeated roles.
  • Society types are template-role pairs, each with binary-rational mass equal to its template's copy mass; the support size counts these pairs.
  • Templates have nonempty role sets, copy intervals carry Lebesgue measure, and the dummy root carries neither mass nor voting weight.
  • Preferences and weights are explicitly encoded; preference ties contribute zero without tie-breaking.
  • Construction uses a finite description by rational interval partitions labeled with arborescences; m counts original template edges and L is total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is in \(\mathrm{P}\), and a popular assignment can be constructed in time polynomial in \(m,\tau,L\). In fact, whenever one exists, there is one that uses a single arborescence throughout each template’s copy interval.

1. Finite margins and measurability.

For each template \(q\), let \(\mathcal A_q\) be the finite set of spanning outward \(r\)-arborescences in \(D_q\). This set is nonempty because it contains the arborescence consisting of all dummy edges.

For \(A,C\in\mathcal A_q\), define
\(\displaystyle \Delta_q(A,C)=\sum_{v\in V_q}w_q(v)\bigl(\mathbf 1[A(v)\succ_v C(v)]-\mathbf 1[C(v)\succ_v A(v)]\bigr).\)

Thus \(A\) is a finite popular arborescence precisely when \(\Delta_q(A,C)\geq 0\) for every \(C\in\mathcal A_q\). Write \(\mathcal P_q\) for the set of these arborescences.

We may modify any feasible assignment on its exceptional null sets to use the dummy-edge arborescence there. Such modifications preserve measurability and every comparison integral. Consequently, we may assume assignments are feasible everywhere.

Because \(\mathcal A_q\) is finite, measurability of an assignment implies measurability of every level set \(\{x:B_q(x)=A\}\). All comparison integrands are measurable and bounded: with \(W_q=\sum_{v\in V_q}w_q(v)\), we have \(|\Delta_q(A,C)|\leq W_q\). Their integrals therefore exist.

2. Proven characterization: popularity holds almost everywhere in each template.

We claim that a feasible measurable assignment \(B\) is popular if and only if, for every template \(q\),
\(\displaystyle B_q(x)\in\mathcal P_q\quad\text{for almost every }x\in[0,\lambda_q].\)

*Proof of sufficiency.* Suppose the stated condition holds, and let \(B'\) be any measurable feasible assignment. For each \(q\), finite popularity gives
\(\Delta_q(B_q(x),B'_q(x))\geq 0\)
for almost every \(x\). Integrating and summing over the finitely many templates yields
\(\displaystyle \sum_q\int_0^{\lambda_q}\Delta_q(B_q(x),B'_q(x))\,dx\geq 0.\)
This is exactly the required popularity inequality.

*Proof of necessity.* Suppose the condition fails for some template \(q\). Then the measurable set
\(\displaystyle H=\{x\in[0,\lambda_q]:B_q(x)\notin\mathcal P_q\}\)
has positive Lebesgue measure.

The set \(H\) is the finite union of level sets corresponding to arborescences in \(\mathcal A_q\setminus\mathcal P_q\). Hence some \(A\in\mathcal A_q\setminus\mathcal P_q\) has a level set
\(\displaystyle S=\{x:B_q(x)=A\}\)
of positive measure. Since \(A\) is not popular, there exists \(C\in\mathcal A_q\) with \(\Delta_q(A,C)<0\).

Define \(B'\) by replacing \(B_q(x)\) with \(C\) on \(S\), and leaving the assignment unchanged everywhere else. The set \(S\) is measurable, so \(B'\) is measurable. It is feasible because the replacement is an arborescence in the same copy.

All unchanged copies contribute zero to the comparison. Therefore, writing \(\mu\) for Lebesgue measure,
\(\displaystyle \sum_p\int_0^{\lambda_p}\Delta_p(B_p(x),B'_p(x))\,dx=\mu(S)\Delta_q(A,C)<0.\)
This contradicts popularity and proves necessity.

3. Existence and explicit construction.

The characterization implies
\(\displaystyle \text{a popular measurable assignment exists}\quad\Longleftrightarrow\quad \mathcal P_q\neq\varnothing\text{ for every }q.\)

Indeed, if \(\mathcal P_q=\varnothing\), every copy of template \(q\) uses an unpopular arborescence. Since \(\lambda_q>0\), the characterization rules out global popularity.

Conversely, choose \(A_q\in\mathcal P_q\) for each template and set \(B_q(x)=A_q\) throughout \([0,\lambda_q]\). The characterization proves that this assignment is popular.

This construction has the required finite description: for each template, use the single interval with endpoints \(0\) and \(\lambda_q\), labeled by \(A_q\). Both endpoints are rational.

4. Finite algorithm and running time.

The Natsui–Takazawa theorem supplies an algorithm that decides existence and constructs a popular arborescence for a finite instance with positive integer vertex weights, total-preorder preferences, and \(w(s)+w(t)>w(u)\) for every triple of original vertices. Its stated combinatorial running time is \(O(|E(D)|\,|V(G)|^2)\). Correctness is established by their Theorems 13 and 19. [Natsui–Takazawa, Sections 2 and 4](https://arxiv.org/pdf/2110.03460)

Apply this algorithm separately to each template. Every hypothesis holds:

  • The weights are positive integers and satisfy the required inequality within that template.
  • The preferences are total preorders, retaining all ties.
  • The augmentation adds precisely the strictly least-preferred dummy edges used in the finite theorem.
  • The dummy root has no vote or weight.

No inequality between weights from different templates is needed, because the finite algorithm is applied separately.

Let \(n_q=|V_q|\) and \(m_q=|E_q|\). Each augmented graph has \(m_q+n_q\) edges. The total combinatorial running time is therefore
\(\displaystyle O\!\left(\sum_q(m_q+n_q)n_q^2\right)\subseteq O\!\left((m+\tau)\tau^2\right),\)
using \(\sum_q n_q=\tau\), \(\sum_q m_q=m\), and \(n_q\leq\tau\).

Binary weights cause no dependence polynomial in their numerical values: Algorithm 1 uses weights through comparisons and selection of minimum-weight vertices. Weight comparisons cost \(O(L)\) bit operations; graph indices and preference ranks also have \(O(L)\) bits. Allowing \(O(L^2)\) for straightforward preprocessing of the explicitly listed preferences, a conservative bit-operation bound for decision and construction is
\(\displaystyle O\!\left(L^2+L(m+\tau)\tau^2\right).\)

If any template is rejected, report that no popular assignment exists. Otherwise output the constant assignment described above. The output contains one arborescence per template, totaling \(\tau\) selected edges, together with the input rational interval endpoints.
