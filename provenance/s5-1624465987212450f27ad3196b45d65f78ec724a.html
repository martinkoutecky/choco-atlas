The continuous mirror question, as graded

Given finitely many types \(t\in T\) with masses \(\mu_t>0\) summing to \(1\), initial opinions \(s_t^0\), stubbornness values \(\alpha_t\), a row-stochastic influence matrix \(K\), and parameters \(\beta,\rho,k,p>0\), set \(A=\operatorname{diag}(\alpha_t)\) and \(B=[I-(I-A)K]^{-1}\). Choose defender opinions \(s\) and adversarial attacker masses \(a_u\) and incidence masses \(q_{tu}\), subject to \(0\le s\le s^0\), \(\sum_t\mu_t(s_t^0-s_t)\le\beta\), \(0\le a_u\le\mu_u\), \(\sum_u a_u\le\rho\), \(q_{tu}\ge0\), \(\sum_t q_{tu}\le k a_u\), and \(\sum_u q_{tu}\le\mu_t/p\). With \(h_t=\sum_u q_{tu}/\mu_t\) and \(\Delta K(q)_{tu}=q_{tu}/\mu_t-h_tK_{tu}\), find the \(s\) minimizing the worst-case value of \(\sum_t\mu_t(BAs)_t+p\sum_t\mu_t(B(I-A)\Delta K(q)BAs)_t\), and return an optimal \(s\), a worst-case response, and the value.

Result

The task is polynomial-time solvable. In fact, an exactly optimal defender opinion vector, an exact maximizing attacker response, and the exact objective value can all be computed in time polynomial in \(\tau\) and \(L\).

The proof uses a polynomial-size rational linear program. It applies to the stated continuous mass formulation and takes the first-order expression as the objective itself.

1. The inverse and the objective coefficients

Put \(D=I-(I-A)K\). Since \(K\) is nonnegative and row-stochastic,

\[ \|(I-A)K\|_\infty=\max_t(1-\alpha_t)<1. \]

Consequently, \(D\) is invertible and \(B=D^{-1}=\sum_{j=0}^{\infty}((I-A)K)^j\) is nonnegative. Define the rational constants

\[ M=BA,\qquad w^{\mathsf T}=\mu^{\mathsf T}B(I-A),\qquad d_t=\frac{p\,w_t}{\mu_t}. \]

All \(d_t\) are well-defined and nonnegative because the masses are positive. For a defender vector \(s\), write \(z=Ms\). The perturbation satisfies

\[ \begin{aligned} (\Delta K(q)z)_t &=\frac{1}{\mu_t}\sum_u q_{tu}z_u -\frac{\sum_u q_{tu}}{\mu_t}(Kz)_t\\ &=\frac{1}{\mu_t}\sum_u q_{tu}\bigl(z_u-(Kz)_t\bigr). \end{aligned} \]

Therefore,

\[ F(s,q)=\mu^{\mathsf T}z+ \sum_{t,u}d_t\bigl(z_u-(Kz)_t\bigr)q_{tu}. \]

Thus, for fixed \(s\), the attacker has a linear objective in \(q\). Its coefficient

\[ c_{tu}(z)=d_t\bigl(z_u-(Kz)_t\bigr) \]

is itself linear in \(z\).

2. Eliminating the attacker masses

Define the flow polytope

\[ P=\left\{ q\ge0: \begin{aligned} \sum_tq_{tu}&\le k\mu_u &&\text{for every }u,\\ \sum_uq_{tu}&\le\mu_t/p &&\text{for every }t,\\ \sum_{t,u}q_{tu}&\le k\rho \end{aligned} \right\}. \]

Claim. \(P\) is exactly the projection of \(Q\) onto its \(q\)-coordinates.

If \((a,q)\in Q\), then

\[ \sum_tq_{tu}\le ka_u\le k\mu_u, \qquad \sum_{t,u}q_{tu}\le k\sum_u a_u\le k\rho. \]

The row constraints and nonnegativity also hold, so \(q\in P\).

Conversely, for any \(q\in P\), set

\[ a_u=\frac{1}{k}\sum_tq_{tu}. \]

Because \(k>0\), this gives

\[ 0\le a_u\le\mu_u,\qquad \sum_u a_u\le\rho,\qquad \sum_tq_{tu}=ka_u. \]

Together with the row constraints, these inequalities establish \((a,q)\in Q\). This proves the claim.

The polytope \(P\) is nonempty because it contains zero. It is compact: it is closed, and every coordinate satisfies \(0\le q_{tu}\le\mu_t/p\). Hence every linear objective over \(P\) has a maximizing response.

3. Dualizing the attacker

For fixed \(z\), the attacker’s objective beyond the baseline is

\[ H(z)=\max_{q\in P}\sum_{t,u}c_{tu}(z)q_{tu}. \]

Introduce nonnegative dual variables \(x_u\) for the column capacities, \(y_t\) for the row capacities, and \(\theta\) for the total capacity. The dual linear program is

\[ \begin{aligned} \text{minimize}\quad& k\sum_u\mu_u x_u+\frac1p\sum_t\mu_t y_t+k\rho\theta\\ \text{subject to}\quad& x_u+y_t+\theta\ge c_{tu}(z) &&\text{for every }(t,u)\in T^2,\\ &x,y,\theta\ge0. \end{aligned} \]

The constraint follows directly from the coefficient of \(q_{tu}\): that variable appears with coefficient one in its column, row, and total-capacity constraints.

The primal is feasible and has a finite attained optimum by compactness of \(P\). Linear programming strong duality therefore guarantees that this dual also has an attained optimum equal to \(H(z)\). In particular,

\[ g(s)=\mu^{\mathsf T}Ms+H(Ms). \]

This equality holds for every feasible real defender vector.

4. One linear program for the defender

Let

\[ S=\left\{s:0\le s\le s^0,\ \sum_t\mu_t(s_t^0-s_t)\le\beta\right\}. \]

Consider the following linear program in \(s,z,x,y,\theta\):

\[ \begin{aligned} \text{minimize}\quad& \mu^{\mathsf T}z+ k\sum_u\mu_u x_u+\frac1p\sum_t\mu_t y_t+k\rho\theta\\ \text{subject to}\quad& z=Ms,\\ &0\le s\le s^0,\\ &\sum_t\mu_t(s_t^0-s_t)\le\beta,\\ &x_u+y_t+\theta \ge d_t\left(z_u-\sum_vK_{tv}z_v\right) &&\text{for every }(t,u)\in T^2,\\ &x,y,\theta\ge0. \end{aligned} \]

Every coefficient here is constant input-derived rational data. In particular, the last family of constraints is linear.

We now verify exact equivalence and attainment.

First, \(S\) is nonempty because \(s^0\in S\), and it is compact. Moreover, write \(F(s,q)=b(q)^{\mathsf T}s\); the coefficient vector \(b(q)\) depends continuously on \(q\). Compactness of \(P\) gives a finite constant \(C=\max_{q\in P}\|b(q)\|_2\), and

\[ |g(s)-g(s')| \le\max_{q\in P}|F(s,q)-F(s',q)| \le C\|s-s'\|_2. \]

Thus \(g\) is continuous, and some \(s^\star\in S\) attains \(V\).

For any feasible point of the displayed linear program, weak duality gives an objective value at least \(g(s)\), hence at least \(V\). Conversely, choose \(s=s^\star\), \(z=Ms^\star\), and an optimal attacker-dual solution. Strong duality makes the displayed objective exactly \(g(s^\star)=V\).

Therefore the linear program has attained optimum \(V\). Furthermore, every optimal solution supplies an exactly optimal defender vector: its \(s\)-component satisfies \(V\le g(s)\le V\).

The program has \(4\tau+1\) variables and \(O(\tau^2)\) constraints.

5. Binary encoding size and the complete algorithm

Polynomial dimension alone is insufficient; the derived coefficients must also have polynomial binary encoding length.

Each entry of \(D\) has encoding length polynomial in \(L\). Choose a common positive denominator \(r\) for its entries and write \(N=rD\). Taking the product of the entry denominators shows that \(r\), and therefore every integer entry of \(N\), has encoding length polynomial in \(\tau,L\).

Suppose the entries of \(N\) have absolute value at most \(2^h\), where \(h\) is polynomial in \(\tau,L\). Expanding a determinant gives

\[ |\det N|\le\tau!\,2^{\tau h}. \]

The same argument bounds every cofactor. Their binary lengths are consequently \(O(\tau h+\tau\log\tau)\). Since \(\det N\ne0\),

\[ B=r\,\frac{\operatorname{adj}(N)}{\det N} \]

has rational entries of polynomial encoding length. Fraction-free Gaussian elimination computes this inverse in polynomial bit time: its intermediate integers are controlled by corresponding minor bounds.

The constants \(M,w,d\), and the coefficients of the defender linear program, use only polynomially many rational additions, multiplications, and divisions by the positive input masses and \(p\). Their encoding lengths remain polynomial. Expanding all constraints produces a linear program of total encoding length polynomial in \(\tau,L\).

We use the standard rational linear programming theorem: a feasible rational linear program with finite optimum admits an exact rational optimal solution computable in time polynomial in its total binary encoding length. Polynomial solvability in this bit-complexity model is recalled in [Dadush, Huiberts, Natura, and Végh](https://link.springer.com/article/10.1007/s10107-023-01956-2). All its hypotheses have been checked above.

The complete algorithm is:

  • Compute \(B,M,w,d\) exactly and solve the defender linear program, obtaining \(s^\star\).
  • Solve the attacker linear program over \(P\) with coefficients \(c_{tu}(Ms^\star)\), obtaining an exact maximizer \(q^\star\).
  • Set \(a_u^\star=k^{-1}\sum_tq_{tu}^\star\).
  • Return \(s^\star,(a^\star,q^\star)\), and the exact rational value

\[ g(s^\star)=\mu^{\mathsf T}Ms^\star+ \sum_{t,u}c_{tu}(Ms^\star)q_{tu}^\star=V. \]

The second linear program also has polynomial encoding length, because the first solver returns a rational solution of polynomial encoding length. The reconstruction proves that the returned attacker response belongs to \(Q\) and maximizes the original objective.

Hence the total running time is polynomial in \(\tau,L\). In particular, the returned solution satisfies \(g(s^\star)\le V+\varepsilon\) for every specified tolerance.

6. Relation to the cited convergence result

Its bound depends on numerical parameters including inverse minimum stubbornness; that convergence statement alone does not establish polynomial binary running time.
