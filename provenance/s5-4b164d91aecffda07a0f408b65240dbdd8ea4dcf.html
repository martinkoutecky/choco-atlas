Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(\Theta\) of \(\tau\) complete types with positive binary-rational masses \(\mu_\theta\), normalized by \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies a quota category \(g(\theta)\in\{1,\ldots,k\}\) and utilities \(u_{\theta j}\in\mathbb Q_{\ge0}\) for all item classes \(j\in J=\{1,\ldots,m\}\). Types in the same quota category may have different utilities.
Item classes have positive per-capita supplies \(\sigma_j\in\mathbb Q_{>0}\) and belong to blocks through \(b:J\to\{1,\ldots,\ell\}\); both category and block maps are surjective.
Inputs also include binary-rational quota masses \(0\le q_{pb}\le\sum_{j:b(j)=b}\sigma_j\) and a binary-rational welfare threshold \(W>0\). Utilities have no normalization; quotas are independent inputs and impose only upper bounds.
The population is atomless: each person receives at most one whole item, but each type's mass may be partitioned among item classes and unassigned persons. Aggregate assignment masses \(x_{\theta j}\) may be arbitrary nonnegative reals.
The decision problem asks whether such masses satisfy \(\sum_jx_{\theta j}\le\mu_\theta\) for every type, \(\sum_\theta x_{\theta j}\le\sigma_j\) for every item class, \(\sum_{\theta:g(\theta)=p}\sum_{j:b(j)=b}x_{\theta j}\le q_{pb}\) for every category-block pair, and \(\sum_{\theta,j}u_{\theta j}x_{\theta j}\ge W\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,k,\ell,L\).

Is this continuous assignment decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

The finite-agent version with indivisible items and category-block upper quotas is \(\mathrm{NP}\)-complete. [Source](https://people.cs.umass.edu/~yzick/papers/quotabaseddiversityTEAC.pdf)
No result settling exactly the atomless mass formulation above was identified in the literature search.

Result

The continuous assignment decision problem is in \(\mathrm P\). Its explicit support yields a polynomial-size rational linear program, and atomlessness makes every feasible mass vector an admissible assignment.

1. An exact linear formulation

Introduce one real variable \(x_{\theta j}\) for each \((\theta,j)\in\Theta\times J\). Consider the following feasibility system:

\[ \begin{aligned} x_{\theta j}&\ge 0 &&(\theta\in\Theta,\ j\in J),\\ \sum_{j\in J}x_{\theta j}&\le\mu_\theta &&(\theta\in\Theta),\\ \sum_{\theta\in\Theta}x_{\theta j}&\le\sigma_j &&(j\in J),\\ \sum_{\theta:g(\theta)=p}\sum_{j:b(j)=b}x_{\theta j}&\le q_{pb} &&\bigl(p\in\{1,\ldots,k\},\ b\in\{1,\ldots,\ell\}\bigr),\\ -\sum_{\theta\in\Theta}\sum_{j\in J}u_{\theta j}x_{\theta j}&\le-W. \end{aligned} \]

Every coefficient is rational. In particular, different utilities within a quota category cause no difficulty: the variables and welfare coefficients retain each complete type separately.

Equivalence. Any admissible assignment gives these inequalities by counting its assignment masses.

Conversely, suppose the system has a solution. For each type \(\theta\), partition its mass into parts of sizes \(x_{\theta1},\ldots,x_{\theta m}\), together with an unassigned part of size
\(\mu_\theta-\sum_jx_{\theta j}\). These sizes are nonnegative and sum to \(\mu_\theta\). Such partitioning is expressly permitted by the atomless formulation. Assign everyone in part \(j\) one whole item of class \(j\). The item and quota inequalities ensure the resulting masses obey all capacities, and the last inequality ensures welfare at least \(W\).

Thus linear feasibility is equivalent to the original decision question, including its requirement that each person receive at most one whole item.

2. Polynomial encoding size and running time

There are
\(n=\tau m\)
variables and
\(r=\tau m+\tau+m+k\ell+1\)
inequalities, counting nonnegativity.

A dense encoding of the system has length
\(S=O(nr+L)\):
apart from the supplied utilities, masses, supplies, quotas, and threshold, its entries belong to \(\{-1,0,1\}\). Each supplied numerical coefficient appears only once.

Because the maps are surjective, \(k\le\tau\) and \(\ell\le m\). Hence \(k\ell\le\tau m\). Moreover, the explicit utility table contains \(\tau m\) entries, so \(\tau m=O(L)\). Consequently, \(S=O(L^2)\), and constructing the system takes polynomial time.

Apply the standard exact rational linear feasibility theorem: feasibility of an explicitly encoded rational linear system is decidable in time polynomial in its dimensions and total binary encoding length. This follows from polynomial-time linear programming, including treatment of lower-dimensional feasible sets. See [MIT’s notes on the ellipsoid method](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

To check its applicability, rational denominators can be cleared separately in each inequality by multiplying by their positive product. This preserves feasibility, and the product’s bit length is at most the sum of the denominator bit lengths in that row. The resulting integer system therefore still has polynomial encoding length. Zero quotas and equality at the welfare threshold are allowed; no strict feasibility assumption is needed.

The resulting running time, measured in bit operations, is

\[ \bigl(\tau m+\tau+m+k\ell+L\bigr)^{O(1)} =L^{O(1)}. \]

The algorithm decides feasibility exactly, so it also handles instances whose maximum welfare equals \(W\).

3. Why finite-agent hardness does not transfer

The cited finite-agent formulation requires binary assignment variables; see its constraint (5) and Theorem 3.4 in [the source paper](https://people.cs.umass.edu/~yzick/papers/quotabaseddiversityTEAC.pdf). Here, each type’s mass can be partitioned, so arbitrary nonnegative real assignment masses are valid.

Accordingly, the linear program is an exact formulation of this problem. No integrality theorem or rounding argument is required. The classification is \(\mathrm P\); under polynomial-time many-one reductions, \(\mathrm{NP}\)-hardness would therefore imply \(\mathrm P=\mathrm{NP}\).
