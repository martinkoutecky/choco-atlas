The continuous mirror question, as graded

Given a finite resource set \(R\), complete utility types \(t\in\mathcal{T}\) with rational shares \(\mu_t\), per-capita supplies \(q_r\in\mathbb{Q}\cap[0,1]\), and utilities \(u_t:2^R\to\mathbb{Q}\), choose masses \(x_{tB}\ge 0\) for \(t\in\mathcal{T}\) and integral bundles \(B\subseteq R\), subject to \(\sum_{B\subseteq R}x_{tB}=\mu_t\) and \(\sum_{t\in\mathcal{T}}\sum_{B:r\in B}x_{tB}=q_r\) for every \(r\in R\). Find a feasible \(x\) minimizing \(\sum_{t,B}\sum_{s,C}x_{tB}x_{sC}[u_t(C)-u_t(B)]_+\), where \([z]_+=\max\{0,z\}\).

Result

I interpret the question as asking whether there exists a feasible allocation \(x\) with \(E(x)\leq K\).

This decision problem is \(\mathrm{NP}\)-complete. Hardness already holds for \(K=0\), with distinct utility values within each type, nonnegative integer utilities, and dyadic masses and supplies. The reduction uses \(m=O(\log\tau)\), so its complete utility tables have polynomial size.

A general exact algorithm runs in \(2^{\tau2^m}\operatorname{poly}(L)\) time. For \(K=0\), an algorithm runs in \(2^{2^m}\operatorname{poly}(L)\) time. The case \(m=1\) is polynomial-time solvable.

1. Zero envy forces deterministic allocation for types without ties

Call a type’s utility table *injective* if different bundles have different utility values.

Lemma 1. If every supported type has an injective utility table and \(E(x)=0\), then each type assigns its entire mass to one bundle.

Proof. Every summand defining \(E(x)\) is nonnegative. Suppose a type \(t\) assigns positive masses to distinct bundles \(B,C\). Injectivity implies that, after interchanging their names if necessary, \(u_t(C)>u_t(B)\). The same-type comparison contributes

\[ x_{tB}x_{tC}\bigl(u_t(C)-u_t(B)\bigr)>0, \]

contradicting \(E(x)=0\). Consequently, exactly one bundle has positive mass for type \(t\), and its mass is \(\mu_t\). \(\square\)

The inclusion of same-type comparisons is essential to this argument.

2. An arithmetic lemma

The reduction will encode several simultaneous constraints in the binary representations of the masses.

Lemma 2. Let \(w_0,\ldots,w_{n-1}\) be positive integers, \(W=\sum_i w_i\), and \(H=W+1\). Suppose \(a_i,b_i\in\{0,1\}\), \(c_i\in\{0,1,2\}\), and \(0\leq e\leq W\). If

\[ \sum_i\bigl((H5^i+w_i)a_i+H5^i b_i\bigr) = H\sum_i5^ic_i+e, \]

then \(a_i+b_i=c_i\) for every \(i\), and \(\sum_iw_i a_i=e\).

Proof. Rearranging gives

\[ H\sum_i5^i(a_i+b_i-c_i)+\left(\sum_iw_i a_i-e\right)=0. \]

The parenthesized expression is an integer whose absolute value is at most \(W<H\). Since it is a multiple of \(H\), it must be zero. Therefore

\[ \sum_iw_i a_i=e, \qquad \sum_i5^i(a_i+b_i-c_i)=0. \]

Each coefficient in the second equality belongs to \(\{-2,-1,0,1,2\}\). Reduction modulo \(5\) forces its first coefficient to be zero. Dividing by \(5\) and repeating forces all coefficients to be zero. \(\square\)

3. Polynomial-size reduction from SUBSET SUM

We reduce from the standard \(\mathrm{NP}\)-complete problem SUBSET SUM with positive integer weights \(w_0,\ldots,w_{n-1}\) and an integer target \(T\), where \(0\leq T\leq W=\sum_iw_i\). The question is whether some \(S\subseteq\{0,\ldots,n-1\}\) satisfies \(\sum_{i\in S}w_i=T\).

Resources and distinguished bundles

Let \(\ell=\lceil\log_2 n\rceil\), and choose distinct codes \(c_i\in\{0,1\}^{\ell}\). For \(n=1\), the sole code is empty.

There are \(\ell\) address resources \(r_1,\ldots,r_\ell\), a tag resource \(r_{\mathrm{tag}}\), and a selection resource \(r_{\mathrm{sel}}\). Thus

\[ m=\ell+2, \qquad N=2^m=4\cdot2^\ell\leq8n. \]

For each item \(i\), tag \(a\in\{0,1\}\), and selection bit \(v\in\{0,1\}\), define \(B_{i,a,v}\) as follows:

  • its address-resource incidence vector is \(c_i\);
  • it contains \(r_{\mathrm{tag}}\) exactly when \(a=1\);
  • it contains \(r_{\mathrm{sel}}\) exactly when \(v=1\).

These distinguished bundles are all different.

Types and dyadic masses

Set

\[ H=W+1,\qquad \alpha_i=H5^i+w_i,\qquad \beta_i=H5^i, \qquad D_0=\sum_i(\alpha_i+\beta_i). \]

Choose a power of two \(D>2D_0\), and set \(\gamma=D-D_0\). In particular, \(\gamma>D_0\).

For each item \(i\), create two types \((i,1)\) and \((i,0)\), with masses

\[ \mu_{i,1}=\frac{\alpha_i}{D}, \qquad \mu_{i,0}=\frac{\beta_i}{D}. \]

Create one additional type \(*\), with mass \(\mu_*=\gamma/D\). All masses are positive dyadic rationals, their sum is one, and the number of supported types is exactly \(\tau=2n+1\).

Complete utility tables

Fix a bijection \(h:2^R\to\{0,\ldots,N-1\}\), with \(h(\varnothing)=0\).

For type \((i,a)\), assign

\[ u_{i,a}(B_{i,a,0})=N, \qquad u_{i,a}(B_{i,a,1})=N+1. \]

At every other bundle \(B\), assign \(u_{i,a}(B)=h(B)\).

For the additional type, assign \(u_*(\varnothing)=N+1\), and \(u_*(B)=h(B)\) at every nonempty bundle.

Every table is injective. For each ordinary type, both distinguished bundles have higher utility than every other bundle. The tables contain only nonnegative integers at most \(N+1\).

Supplies and threshold

Set \(K=0\). For each address coordinate \(j\), set

\[ q_{r_j} = \frac{\sum_i(\alpha_i+\beta_i)c_{ij}}{D}. \]

Set the remaining supplies to

\[ q_{\mathrm{tag}}=\frac{\sum_i\alpha_i}{D} = \frac{H\sum_i5^i+W}{D}, \qquad q_{\mathrm{sel}}=\frac{H\sum_i5^i+T}{D}. \]

Every supply numerator lies between zero and \(D_0\). Hence the supplies are dyadic rationals in \([0,1]\), and, for every resource \(r\),

\[ q_r\leq\frac{D_0}{D}<\frac{\gamma}{D}=\mu_*. \]

Soundness: zero envy implies a subset sum

Suppose a feasible allocation has \(E(x)\leq0\). Nonnegativity gives \(E(x)=0\), and Lemma 1 makes every type’s allocation deterministic.

The additional type must receive the empty bundle: receiving any resource \(r\) would allocate at least \(\mu_*>q_r\) units of that resource, violating feasibility.

For an address resource \(r_j\), let \(a_i,b_i\) indicate whether the bundles assigned to types \((i,1)\) and \((i,0)\), respectively, contain that resource. Its supply equality becomes

\[ \sum_i(\alpha_i a_i+\beta_i b_i) = H\sum_i5^i(2c_{ij})+\sum_iw_ic_{ij}. \]

Lemma 2 implies \(a_i+b_i=2c_{ij}\). Since both indicators are binary, both equal \(c_{ij}\). Thus both types belonging to item \(i\) receive the correct address.

For the tag resource, Lemma 2 gives

\[ a_i+b_i=1\quad\text{for every }i, \qquad \sum_iw_i a_i=W. \]

Because every \(w_i\) is positive, the second equality forces every \(a_i=1\). Consequently, type \((i,1)\) receives the tag resource, and type \((i,0)\) does not.

For the selection resource, Lemma 2 gives

\[ a_i+b_i=1\quad\text{for every }i, \qquad \sum_iw_i a_i=T. \]

Therefore the items whose type \((i,1)\) receives the selection resource form a subset summing to \(T\).

Completeness: a subset sum gives zero envy

Conversely, suppose \(S\) satisfies \(\sum_{i\in S}w_i=T\). Let \(s_i\) be its membership indicator. Allocate:

  • the entire mass of type \((i,1)\) to \(B_{i,1,s_i}\);
  • the entire mass of type \((i,0)\) to \(B_{i,0,1-s_i}\);
  • the entire additional type to \(\varnothing\).

The address and tag supplies hold by construction. The selection-resource numerator is

\[ \sum_i\bigl(\alpha_i s_i+\beta_i(1-s_i)\bigr) = H\sum_i5^i+\sum_iw_is_i = H\sum_i5^i+T. \]

Thus every supply is fully allocated.

Each ordinary type receives one of its two distinguished bundles. Bundles assigned to other ordinary types have different addresses or tags, so their utilities are at most \(N-1\).

The additional type’s empty bundle also causes no envy. If it is a distinguished bundle of an ordinary type, it is that type’s selection-bit-zero bundle, with utility \(N\); the assigned distinguished bundle has utility \(N\) or \(N+1\). Otherwise, the empty bundle has utility at most \(N-1\). The additional type itself receives its unique favorite bundle.

Every positive utility difference in the envy objective is therefore zero. Hence \(E(x)=0\).

Size of the reduction

The construction has

\[ \tau=2n+1,\qquad m=\lceil\log_2 n\rceil+2,\qquad 2^m=O(n). \]

Consequently, all complete utility tables together have \(O(n^2)\) entries, each using \(O(\log(n+1))\) bits.

The masses and supplies use \(O(n+\log(W+1))\) bits each. The output length is polynomial in the original binary SUBSET SUM input length, and all quantities can be computed in polynomial time.

This proves \(\mathrm{NP}\)-hardness under the stated explicit-table representation, already for \(K=0\).

4. Membership in NP for arbitrary thresholds

The real allocation variables do not prevent membership in \(\mathrm{NP}\): every yes-instance has a rational witness of polynomial bit length. Here is a direct proof of that fact for this problem; general quadratic-programming membership in \(\mathrm{NP}\) was established by [Vavasis (1990)](https://doi.org/10.1016/0020-0190(90)90100-C).

Let \(d=\tau2^m\), and write the feasible set as

\[ P=\{x\in\mathbb{R}^d:Ax=b,\ x\geq0\}. \]

Here \(A\) encodes the type-mass and resource-supply equalities.

The set is nonempty: assigning each type mass according to the same product distribution of independent resource inclusions, with inclusion probabilities \(q_r\), satisfies every equality. It is compact because \(0\leq x_{tB}\leq\mu_t\).

Write \(E(x)=x^{\mathsf T}Qx\), with \(Q\) symmetric and rational. Its coefficients have polynomial encoding length. Thus \(E\) attains a minimum at some \(x^*\in P\).

Let \(S\) be the positive-coordinate support of \(x^*\). Restrict the constraint matrix and quadratic matrix to this support, writing them as \(A_S,Q_{SS}\). Choose a rational matrix \(V\) whose columns form a basis of \(\ker A_S\).

Every direction in \(\ker A_S\) permits sufficiently small perturbations of both signs around the strictly positive vector \(x^*_S\). First-order optimality therefore gives

\[ V^{\mathsf T}Q_{SS}x^*_S=0. \]

Consider the rational polytope

\[ H_S= \{z\geq0:A_Sz=b,\ V^{\mathsf T}Q_{SS}z=0\}. \]

It is nonempty and bounded. Moreover, the quadratic objective is constant on \(H_S\). Indeed, for \(z,w\in H_S\), the vector \(v=z-w\) belongs to \(\ker A_S\). The stationarity equalities imply \(v^{\mathsf T}Q_{SS}z=v^{\mathsf T}Q_{SS}w=0\). Symmetry then gives

\[ z^{\mathsf T}Q_{SS}z-w^{\mathsf T}Q_{SS}w = v^{\mathsf T}Q_{SS}(z+w)=0. \]

A rational vertex of \(H_S\) has polynomial bit length: rational nullspace computation has polynomial bit complexity, and vertex coordinates satisfy the usual determinant bounds for rational linear systems. Extending such a vertex by zeros gives a rational feasible allocation attaining the global minimum.

Thus any yes-instance has a polynomial-size rational allocation certificate. Its feasibility and objective value can be checked by exact rational arithmetic in polynomial time. The problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness.

5. Running times and the one-resource case

General exact algorithm

Enumerate all supports \(S\subseteq\{1,\ldots,d\}\). For each support, construct \(H_S\) as above and test its feasibility by rational linear programming. If feasible, evaluate the objective at any rational point of \(H_S\).

Every candidate is feasible for the original problem. The support of a global minimizer produces a candidate attaining the global minimum. Each iteration takes \(\operatorname{poly}(L)\) time, giving the bound

\[ 2^{\tau2^m}\operatorname{poly}(L). \]

Unless \(\mathrm{P}=\mathrm{NP}\), there is no general algorithm polynomial in \(L\).

A sharper bound for zero envy

For \(K=0\), enumerate nonempty sets \(S\subseteq2^R\). For each type, allow allocation only to bundles maximizing its utility over \(S\), and test the resulting linear feasibility system.

Any feasible solution has zero envy, since no assigned bundle is worse, for its recipient, than any bundle in \(S\).

Conversely, if an allocation has zero envy, take \(S\) to be its globally used bundles. Every bundle assigned to a type must maximize that type’s utility over \(S\): otherwise a positive mass of that type envies a globally used bundle, producing a positive summand.

This gives an exact running time of

\[ 2^{2^m}\operatorname{poly}(L). \]

In particular, zero-envy feasibility is polynomial-time solvable for each fixed \(m\).

The case \(m=1\)

Let \(p_t=x_{t,\{r\}}\), \(q=q_r\), and \(\delta_t=u_t(\{r\})-u_t(\varnothing)\). Write \(\delta_t^+=\max\{0,\delta_t\}\) and \(\delta_t^-=\max\{0,-\delta_t\}\).

The total masses receiving the resource and the empty bundle are fixed at \(q\) and \(1-q\), respectively. Therefore

\[ E(x) = q\sum_t\delta_t^+(\mu_t-p_t) + (1-q)\sum_t\delta_t^-p_t. \]

This is a linear objective in \(p_t\), subject to \(0\leq p_t\leq\mu_t\) and \(\sum_tp_t=q\).

Sort the coefficients \((1-q)\delta_t^- -q\delta_t^+\) and fill the available masses in increasing coefficient order. An exchange from a larger coefficient to a smaller one never increases the objective, proving optimality of this procedure.

It uses \(O(\tau\log\tau)\) rational comparisons and polynomial bit time in \(L\).
