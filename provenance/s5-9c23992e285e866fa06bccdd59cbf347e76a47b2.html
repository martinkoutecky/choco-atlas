The continuous mirror question, as graded

Given colleges \(C\), a finite set \(T\) of complete applicant types with rational masses \(\mu_t>0\) summing to \(1\), and rational per-capita upper quotas \(q_j\), compute a student-optimal H-stable assignment. Each type’s mass receives one assignment as a block, or remains unmatched; college \(j\) receives mass at most \(q_j\). H-stability is defined by college score cutoffs: each type goes to its most-preferred listed college whose cutoff it meets, and no positive cutoff can be lowered while maintaining the quotas, so tied score groups are admitted or rejected together.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq1\) colleges. A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Each type specifies a strict preference list over an acceptable subset of \(C\) and a nonnegative integer score \(s_{tj}\) at each listed college; every listed college is preferred to being unmatched. Each college has a nonnegative binary-rational upper quota \(q_j\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).
A cutoff vector \(p\in\mathbb Z_{\geq0}^{m}\) assigns the entire mass of each type to its most-preferred listed college satisfying \(s_{tj}\geq p_j\), or leaves it unmatched if none qualifies. Equal scores receive the same eligibility decision, although eligible types may attend different, more-preferred colleges. Write \(D_j(p)\) for the mass assigned to college \(j\).
The vector is feasible if \(D_j(p)\leq q_j\) for every college. It is H-stable if it is feasible and, for every \(j\) with \(p_j>0\), decreasing only \(p_j\) by \(1\) and recomputing all assignments makes \(D_j\) exceed \(q_j\). An assignment is H-stable if induced by such a vector, and student-optimal if every type weakly prefers its assignment to its assignment in every other H-stable assignment.

Can a student-optimal H-stable assignment in this rational-mass block model be computed in time polynomial in \(m,\tau,L\), or is this computational problem NP-hard?

For finite applicants, maximizing an additive objective with positive, strictly decreasing rank weights over quota-feasible cutoff-induced assignments selects the student-optimal H-stable assignment. [Discrete optimization characterization](https://www.scs-europe.net/dlib/2017/ecms2017acceptedpapers/0516-simo_ECMS2017_0066.pdf).
An extended applicant-proposing algorithm computes the discrete student-optimal H-stable assignment. [College admissions with stable score-limits](https://real.mtak.hu/33941/1/BK15cejor_last.pdf). No result settling the exact rational-mass block model was identified in the search.

Modeling choices made when packaging the task

  • Interpreted complete applicant types as specifying all preferences and relevant scores, while allowing incomplete strict lists of acceptable colleges.
  • Specified nonnegative integer scores, consistent with the supplied definitions and numerical instances, and nonnegative integer cutoffs; lowering a cutoff means decreasing it by one with all other cutoffs fixed.
  • Specified nonnegative rational quotas and allowed zero quotas; retained the stipulated total mass of one and indivisible type blocks.
  • Defined student-optimality as simultaneous weak preference dominance for every type over all other H-stable assignments, with unmatched below every acceptable college.
  • Clarified that equal treatment concerns cutoff eligibility, rather than requiring all types with equal scores to attend the same college.
  • In stating the intended discrete optimization characterization, required positive decreasing rank weights and treated unmatched applicants as contributing zero; the literal lemma omits positivity.

Result

The problem is polynomial-time solvable. In fact, one can compute a feasible cutoff vector that is componentwise below every feasible cutoff vector. Its induced assignment is \(H\)-stable and every type weakly prefers it to every other feasible cutoff-induced assignment.

Let \(E\) denote the total number of listed type–college pairs, so \(E\leq m\tau\). An implementation using exact arithmetic has bit running time

\(O\!\left((m+\tau)L^2+(m\tau+1)(m\tau+\tau+m)L\right).\)

The proof below works directly with the rational masses, without expanding them into applicants.

1. Demand monotonicity

Write \(A_j(p)\) for the set of types assigned to college \(j\) under \(p\). Thus

\(D_j(p)=\sum_{t\in A_j(p)}\mu_t.\)

For an integer \(a\geq0\), write \(p^{j\leftarrow a}\) for \(p\) with coordinate \(j\) replaced by \(a\). Vector inequalities below are componentwise.

Lemma. Suppose \(u_j=v_j\) and \(u_k\leq v_k\) for every \(k\neq j\). Then

\(A_j(u)\subseteq A_j(v)\quad\text{and consequently}\quad D_j(u)\leq D_j(v).\)

Proof. If \(t\in A_j(u)\), then \(j\) is listed, \(s_{tj}\geq u_j=v_j\), and every listed college \(k\) preferred to \(j\) satisfies \(s_{tk}<u_k\). Since \(u_k\leq v_k\), also \(s_{tk}<v_k\). Hence \(j\) remains the type’s most-preferred eligible college under \(v\). Summing the nonnegative masses proves the demand inequality. \(\square\)

In addition, increasing only \(p_j\) cannot increase \(D_j\). More precisely, for \(a\geq p_j\),

\(A_j(p^{j\leftarrow a})=\{t\in A_j(p):s_{tj}\geq a\}.\)

Indeed, increasing \(j\)’s cutoff changes no other eligibility decision. A type already assigned elsewhere cannot start choosing \(j\), and a type assigned to \(j\) stays there exactly when it remains eligible.

2. The algorithm

Initialize \(p=(0,\ldots,0)\). Repeat the following:

  • Compute all assignments and demands.
  • If every college satisfies its quota, stop and output \(p\) and its induced assignment.
  • Otherwise choose any college \(j\) with \(D_j(p)>q_j\), and replace \(p_j\) by

\(a=\min\{b\in\mathbb Z_{\geq0}:b\geq p_j,\ D_j(p^{j\leftarrow b})\leq q_j\}.\)

This minimum exists: setting \(j\)’s cutoff above every score listed at \(j\) makes its demand zero. Since the current demand exceeds its quota, the update satisfies \(a>p_j\).

The procedure resembles the applicant-oriented cutoff-raising algorithm in Section 3 of [Biró and Kiselgof, *College admissions with stable score-limits*](https://real.mtak.hu/33941/1/BK15cejor_last.pdf). The following arguments establish its correctness for the stated rational-mass model.

3. At most \(E\) updates

For each college define the finite set

\(K_j=\{0\}\cup\{s_{tj}+1:t\text{ lists }j\}.\)

Every update of coordinate \(j\) lands in \(K_j\). To prove this, let \(a\) be its new value. Since \(a>p_j\) and \(a\) is the minimum in the update rule,

\(D_j(p^{j\leftarrow a-1})>q_j\quad\text{and}\quad D_j(p^{j\leftarrow a})\leq q_j.\)

The assignments at these two vectors can differ only for types whose score at \(j\) equals \(a-1\). The demands differ, so at least one such listed type exists. Therefore \(a=s_{tj}+1\) for some type \(t\).

Each coordinate starts at zero and strictly increases whenever updated. Consequently coordinate \(j\) is updated at most \(|K_j|-1\) times. These counts sum to at most \(E\).

Thus the algorithm terminates after at most \(E\) updates, and its output \(p^\star\) is feasible.

4. The output is below every feasible vector

Proposition. At every stage of the algorithm, \(p\leq r\) for every feasible cutoff vector \(r\).

Proof. Fix any feasible \(r\). Initially \(p=0\leq r\).

Suppose \(p\leq r\) before an update at college \(j\). Consider \(u=p^{j\leftarrow r_j}\). We have \(u_j=r_j\) and \(u_k=p_k\leq r_k\) for all \(k\neq j\). The lemma gives

\(D_j(u)\leq D_j(r)\leq q_j.\)

Moreover, \(r_j\geq p_j\). Hence \(r_j\) is an admissible candidate in the minimum defining the update, so its selected value \(a\) satisfies \(a\leq r_j\). All other coordinates remain below their corresponding coordinates in \(r\).

Induction proves the assertion. Because \(r\) was arbitrary, it holds simultaneously for every feasible vector. \(\square\)

Since \(p^\star\) is itself feasible, it is therefore the componentwise least feasible cutoff vector. This also proves that the final vector does not depend on which overloaded college is selected at each step.

5. Stability and student optimality

Proposition. The vector \(p^\star\) is \(H\)-stable.

Proof. Feasibility was established above. Fix a college \(j\) with \(p^\star_j>0\), and consider the last update of its coordinate.

Let \(u\) be the vector immediately before that update and let \(a=p^\star_j\) be the selected value. Minimality of the update, together with \(a>u_j\), implies

\(D_j(u^{j\leftarrow a-1})>q_j.\)

After this update, coordinate \(j\) remains \(a\), while every other coordinate can only increase. Applying the lemma to the vectors with coordinate \(j\) fixed at \(a-1\) gives

\(D_j((p^\star)^{j\leftarrow a-1})\geq D_j(u^{j\leftarrow a-1})>q_j.\)

This is exactly the required stability condition at \(j\). It holds for every positive coordinate. \(\square\)

Proposition. The assignment induced by \(p^\star\) is student-optimal.

Proof. Let \(r\) induce any other \(H\)-stable assignment. It is feasible, so \(p^\star\leq r\).

For each type \(t\), every college eligible under \(r\) is also eligible under \(p^\star\): the inequality \(s_{tj}\geq r_j\) implies \(s_{tj}\geq p^\star_j\). Thus the type chooses its best college from a superset of its eligible colleges under \(r\). Strict preferences, with every listed college preferred to being unmatched, imply that its assignment under \(p^\star\) is weakly preferred.

This holds for every type and every \(H\)-stable assignment. Indeed, the same argument applies to every feasible cutoff-induced assignment. \(\square\)

6. Exact arithmetic and running time

Express the input rationals as fractions with integer numerators and positive denominators. Let \(Q\) be the product of all denominators appearing in the masses and quotas, and define

\(w_t=Q\mu_t,\qquad b_j=Qq_j.\)

These are integers, and feasibility comparisons become

\(\sum_{t\in A_j(p)}w_t\leq b_j.\)

The binary length of \(Q\) is at most the sum of the input denominator lengths, up to a constant. Thus \(Q\), the \(w_t\), the \(b_j\), all demand sums, and all cutoffs used by the algorithm have \(O(L)\) bits. Constructing these integers by standard multiplication and exact division costs \(O((m+\tau)L^2)\) bit operations.

For the remaining computation:

  • Sort the listed types at each college by score, grouping equal scores. This uses \(O(E\log(\tau+1))\) comparisons.
  • Compute an assignment and all demands by scanning the preference lists. This costs \(O(E+\tau+m)\) operations on \(O(L)\)-bit numbers.
  • To update an overloaded college, start with its currently assigned mass and scan its score groups in increasing order, removing the currently assigned types in each group. Stop when the remaining mass first fits the quota, and set the cutoff to one plus that group’s score.

The last operation implements the minimum exactly: raising only that college’s cutoff retains precisely its currently assigned types whose scores meet the new cutoff. Whole equal-score groups are removed together.

There are at most \(E\) updates. Including sorting and the final feasibility check, the bit running time is

\(O\!\left((m+\tau)L^2+E\log(\tau+1)L+(E+1)(E+\tau+m)L\right).\)

Since \(E\leq m\tau\) and \(\log(\tau+1)=O(\tau)\), this implies the bound stated at the start. Both large score values and small rational masses are handled through their binary representations.
