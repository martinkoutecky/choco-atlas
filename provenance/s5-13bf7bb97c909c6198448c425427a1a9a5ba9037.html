The continuous mirror question, as graded

Given a finite support of types \(T\), rational masses \(\mu_t>0\) summing to \(1\), compatible type pairs \(\Gamma\), and rational joint surpluses \(v_{tu}\ge 0\), determine and output a stable partnership allocation and payoff if one exists. Choose partnership masses \(x_{tu}\ge 0\), singleton masses \(s_t\ge 0\), and type payoffs \(p_t\ge 0\), with \(2x_{tt}+\sum_{u\ne t:\{t,u\}\in\Gamma}x_{tu}+s_t=\mu_t\), \(p_t+p_u\ge v_{tu}\) for every compatible pair, \(x_{tu}(p_t+p_u-v_{tu})=0\), and \(s_tp_t=0\); for same-type pairs require \(2p_t\ge v_{tt}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Input also specifies a set \(\Gamma\) of unordered compatible type pairs, allowing repeated types, and binary rational joint surpluses \(v_{tu}\geq0\). Write \(m=|\Gamma|\) and let \(L\) be the total input bit length. Singleton surplus is zero.
An allocation has one real partnership mass \(x_{tu}\geq0\) per compatible unordered pair and real singleton masses \(s_t\geq0\); set \(x_{tt}=0\) when \(\{t,t\}\notin\Gamma\). Same-type partnerships join two distinct individuals of that type.
Each type receives a common real payoff \(p_t\geq0\). Stability means
\(2x_{tt}+\sum_{u\ne t:\{t,u\}\in\Gamma}x_{tu}+s_t=\mu_t\quad(t\in T),\)
\(p_t+p_u\geq v_{tu},\qquad x_{tu}(p_t+p_u-v_{tu})=0\quad(\{t,u\}\in\Gamma),\qquad s_tp_t=0\quad(t\in T).\)
Thus compatible same-type pairs require \(2p_t\geq v_{tt}\) and \(x_{tt}(2p_t-v_{tt})=0\). Incompatible partnerships are forbidden.
Is deciding existence and outputting an exact rational stable allocation and payoff when one exists solvable in time polynomial in \(m,\tau,L\), or is the existence decision problem NP-hard?
For finite individual agents, equilibrium exists exactly when the fractional matching relaxation has an integral optimum, equivalently when its value equals the maximum matching weight; equilibrium may fail to exist. [Shioura](https://doi.org/10.22574/jmid.2017.12.004)
For a continuum with finitely many types and unrestricted compatibility, existence of a transferable-utility stable matching is already established; this does not state the binary-input computational complexity above. [Chiappori, Galichon and Salanié](https://www.ifo.de/DocDL/cesifo1_wp4676.pdf)

Result

Every valid instance has a stable allocation and payoff. An exact rational stable outcome can be computed in time polynomial in \(m,\tau,L\).

The key is that the given stability conditions are precisely the complementary slackness conditions for a rational linear program and its dual. Arbitrary compatibility and same-type partnerships both fit this formulation.

1. The allocation linear program

Index the coordinates of \(\mathbb R^\tau\) by \(T\), and let \(\mathbf e_t\) denote the unit vector for type \(t\). Define the incidence matrix \(A\in\{0,1,2\}^{\tau\times m}\) by assigning to each compatible pair \(e=\{t,u\}\) the column

\(A_{\cdot,e}=\mathbf e_t+\mathbf e_u.\)

Thus a same-type pair \(\{t,t\}\) has column \(2\mathbf e_t\), accounting for its two participants. Write \(v_e=v_{tu}\).

Consider the primal linear program

\(\text{(P)}\qquad \max\{v^{\mathsf T}x:Ax\leq\mu,\ x\geq0\}.\)

Its variables are exactly the partnership masses. For every feasible \(x\), define

\(s=\mu-Ax.\)

Then \(s\geq0\), and the required population accounting equations hold. Conversely, every allocation satisfying those equations yields a feasible \(x\). The objective counts each partnership’s joint surplus once.

The primal is feasible because \(x=0\) is feasible. It is bounded: summing its capacity constraints gives

\(2\sum_{e\in\Gamma}x_e\leq\sum_{t\in T}\mu_t=1.\)

In particular, its feasible set is closed and bounded, so its continuous objective attains a finite maximum.

2. The payoff dual and existence

The dual of \(\text{(P)}\) is

\(\text{(D)}\qquad \min\{\mu^{\mathsf T}p:A^{\mathsf T}p\geq v,\ p\geq0\}.\)

For a pair \(e=\{t,u\}\), its dual constraint is

\(p_t+p_u\geq v_{tu}.\)

When \(t=u\), this is exactly \(2p_t\geq v_{tt}\). Thus dual feasibility is exactly the required nonnegativity and absence of profitable pair deviations.

The dual is feasible. Indeed, let

\(V=\max\bigl(\{0\}\cup\{v_e:e\in\Gamma\}\bigr).\)

Setting \(p_t=V\) for every type satisfies every dual constraint, including same-type constraints.

We now apply linear programming strong duality: a feasible linear program with finite optimal value has an optimal dual solution, and their optimal values agree. The hypotheses were checked above. Consequently, there are optimal solutions \(x^*,p^*\) satisfying

\(v^{\mathsf T}x^*=\mu^{\mathsf T}p^*.\)

Set \(s^*=\mu-Ax^*\).

For any primal-feasible \(x\), dual-feasible \(p\), and \(s=\mu-Ax\), the following identity holds:

\(\mu^{\mathsf T}p-v^{\mathsf T}x =p^{\mathsf T}s+x^{\mathsf T}(A^{\mathsf T}p-v) =\sum_{t\in T}s_tp_t+\sum_{\{t,u\}\in\Gamma}x_{tu}(p_t+p_u-v_{tu}).\)

The identity follows by substituting \(\mu=Ax+s\) and expanding. Every summand on its right is nonnegative by primal and dual feasibility.

At \(x^*,p^*,s^*\), the left side is zero. A finite sum of nonnegative numbers is zero only when every summand is zero. Therefore,

\(s_t^*p_t^*=0\qquad(t\in T),\)

and

\(x_{tu}^*(p_t^*+p_u^*-v_{tu})=0\qquad(\{t,u\}\in\Gamma).\)

Together with feasibility, these are all the stated stability conditions. This proves existence for every valid instance.

The same identity also proves the converse: every stable outcome consists of primal and dual optimal solutions, because stability makes the objective gap zero.

3. Exact polynomial-time construction

We use the following standard theorem about rational linear programming:

Given a finite system of linear equalities and weak inequalities with binary-encoded rational coefficients, there is an algorithm that decides feasibility and, when feasible, outputs an exact rational feasible point in time polynomial in the system’s binary encoding length.

This is the exact, bit-complexity version of polynomial-time linear programming. Equalities, lower-dimensional feasible sets, and unbounded feasible sets are allowed. The polynomial feasibility algorithm and its reduction to exact solution construction are discussed in [the linear programming lecture notes hosted by Cornell, Sections 4.2.1–4.2.2](https://people.orie.cornell.edu/miketodd/Lect_EMCO.pdf).

Apply that theorem to the following single linear feasibility system, with variables \(x,s,p\):

\(Ax+s=\mu,\)

\(x\geq0,\qquad s\geq0,\qquad p\geq0,\)

\(A^{\mathsf T}p\geq v,\)

\(\mu^{\mathsf T}p-v^{\mathsf T}x=0.\)

This system is nonempty by the existence proof. Conversely, the nonnegative-gap identity proves that every feasible point satisfies all the complementary slackness conditions, hence is stable. The last equality therefore replaces all the quadratic product equations without changing the solution set.

The algorithm is:

  • Construct \(A\) from the listed compatible pairs.
  • Find an exact rational feasible point of the displayed linear system.
  • Return its coordinates \(x,s,p\), setting masses of incompatible partnerships to zero.

To check the complexity hypotheses explicitly:

  • There are \(m+2\tau\) variables.
  • There are \(\tau+1\) equalities, \(m\) pair inequalities, and \(m+2\tau\) nonnegativity inequalities.
  • Apart from the given rational coefficients \(\mu_t,v_e\), all coefficients belong to \(\{0,1,2,-1\}\).
  • Even a dense encoding of this system has length polynomial in \(m,\tau,L\).

Hence construction and exact solution take polynomial time in \(m,\tau,L\). The theorem outputs binary rational coordinates, so their total encoding length is polynomial as well. No enumeration of individuals or expansion of rational masses into individual agents is required.

4. Why finite-agent nonexistence does not obstruct this proof

For finite individuals, partnership variables must describe actual discrete matches. Optimizing the fractional relaxation may therefore produce an allocation that cannot be implemented by those individuals. Here, real partnership masses are expressly permitted, so the primal feasible region already describes the allowed allocations.

For example, take three types with \(\mu_t=1/3\), all three different-type pairs compatible, and every pair surplus equal to \(1\). Set

\(x_{12}=x_{13}=x_{23}=1/6,\qquad s_1=s_2=s_3=0,\qquad p_1=p_2=p_3=1/2.\)

Each type uses mass \(1/3\), every pair payoff constraint is tight, and every stability condition holds. The fractional triangle is a valid allocation in the stated model.

Similarly, a same-type partnership consumes \(2x_{tt}\) units of its type’s population. The requirement that its participants be distinct introduces no integer or parity restriction on continuum masses; it is already reflected in the column \(2\mathbf e_t\).

Thus the first alternative in the question holds: existence is guaranteed, and exact rational construction is polynomial-time solvable.
