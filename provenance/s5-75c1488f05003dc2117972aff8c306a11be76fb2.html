The continuous mirror question, as graded

Given \(K\) channels, a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), bids \(b_t\), demands \(d_t\), and a conflict graph \(H\) on types, choose masses \(y_{t,B}\geq 0\) for each bundle \(B\subseteq\{1,\ldots,K\}\) with \(|B|=d_t\), subject to \(\sum_B y_{t,B}\leq\mu_t\). Define \(z_{t,k}=\sum_{B\ni k}y_{t,B}\), and require \(z_{t,k}z_{u,k}=0\) for each edge \(\{t,u\}\in H\) and channel \(k\). What are the exact, approximation, and parameterized complexities of maximizing \(\sum_{t\in T} b_t\sum_B y_{t,B}\), as functions of \(K\), \(|T|\), and the input bit length?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types \(T\) with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
There are \(m=K\geq1\) identical channels, positive binary-rational bids \(b_t\) per unit of fully served mass, integer demands \(d_t\in\{1,\ldots,K\}\), and an arbitrary simple undirected conflict graph \(H=(T,E)\).
For each \(B\subseteq\{1,\ldots,K\}\) with \(|B|=d_t\), choose real mass \(y_{t,B}\geq0\), with \(\sum_B y_{t,B}\leq\mu_t\). This mass receives exactly the channels in \(B\); remaining mass is unserved.
Put \(z_{t,k}=\sum_{B\ni k}y_{t,B}\). Require \(z_{t,k}z_{u,k}=0\) for every \(\{t,u\}\in E\) and every channel \(k\). Mass of the same type may reuse a channel; there are no additional channel-capacity constraints.
Define welfare as \(W(y)=\sum_{t\in T}b_t\sum_B y_{t,B}\). Bundles are implicit, and \(L\) is the total binary input length, including a rational threshold \(q\).

Is deciding whether a feasible allocation has \(W(y)\geq q\) in \(\mathrm{P}\), or is it NP-hard? State running times in \(m=K\), \(\tau\), and \(L\).

For finite bidders with the same strict demands and conflicts, welfare maximization is NP-hard and admits no polynomial-time constant-factor approximation unless \(\mathrm{P}=\mathrm{NP}\). [Wang et al.](https://cseweb.ucsd.edu/~tixu/papers/tvt14.pdf)
No result settling exactly the mass-allocation problem above was located in the literature search.

Result

The decision problem is \(\mathrm{NP}\)-complete, even with one channel, unit demands, equal dyadic masses, and equal bids. More generally, it remains \(\mathrm{NP}\)-hard for every fixed positive channel count \(m=K\).

The essential fact is that splitting mass provides no advantage: an optimal allocation can fully serve each selected type on a single bundle.

1. Eliminating mass splitting

Write \(w_t=\mu_t b_t\), and let \([K]=\{1,\ldots,K\}\).

Lemma. Every feasible allocation can be replaced by a feasible allocation of at least the same welfare in which each type is either entirely unserved or entirely served on one bundle.

Proof. For a feasible allocation \(y\), define its served support by

\(\displaystyle S=\left\{t\in T:\sum_B y_{t,B}>0\right\}.\)

For every \(t\in S\), choose a bundle \(B_t\) with \(y_{t,B_t}>0\). Such a bundle exists because there are finitely many bundles.

If \(\{t,u\}\in E\) and \(k\in B_t\cap B_u\), then

\(\displaystyle z_{t,k}\geq y_{t,B_t}>0,\qquad z_{u,k}\geq y_{u,B_u}>0,\)

contradicting the conflict constraint. Thus adjacent selected types have disjoint chosen bundles.

Now assign all mass \(\mu_t\) to \(B_t\) for each \(t\in S\), and leave all other types unserved. This is feasible: adjacent types have disjoint bundles, and the model imposes no channel-capacity constraint. Its welfare satisfies

\(\displaystyle \sum_{t\in S}b_t\mu_t\geq \sum_{t\in T}b_t\sum_B y_{t,B}=W(y).\)

This proves the lemma.

Consequently, the optimum is exactly

\(\displaystyle \operatorname{OPT}=\max\left\{\sum_{t\in S}w_t:\ S\subseteq T,\ B_t\subseteq[K],\ |B_t|=d_t,\ B_t\cap B_u=\varnothing\text{ for every }\{t,u\}\in E\text{ with }t,u\in S\right\}.\)

This is a finite optimization problem, so its maximum is attained. The equivalence holds for arbitrary demands and arbitrary channel counts, not just the one-channel special case.

2. Hardness with dyadic masses

We reduce from Independent Set: given a nonempty graph \(G\) on \(n\) vertices and an integer \(h\), decide whether \(\alpha(G)\geq h\). This is a standard \(\mathrm{NP}\)-complete problem, equivalent to Clique in the complement graph. See [Karp’s classical completeness results](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Let \(N\) be the smallest power of two satisfying \(N\geq n\). Add \(r=N-n\) isolated vertices to \(G\), obtaining \(G'\). Then

\(\displaystyle \alpha(G')=\alpha(G)+r,\qquad N<2n.\)

Construct a society with conflict graph \(H=G'\), support size \(\tau=N\), and

\(\displaystyle K=1,\qquad d_t=1,\qquad \mu_t=\frac1N,\qquad b_t=1,\qquad q=\frac{h+r}{N}.\)

All masses are positive dyadic rationals and sum to one. The threshold is also dyadic. The construction has polynomial binary length.

With one channel, two adjacent types cannot both have positive served mass. Thus the served support of every feasible allocation is an independent set. Conversely, any independent set can be fully served on the single channel. By the lemma,

\(\displaystyle \operatorname{OPT}=\frac{\alpha(G')}{N}.\)

Therefore,

\(\displaystyle \operatorname{OPT}\geq q\quad\Longleftrightarrow\quad \alpha(G')\geq h+r\quad\Longleftrightarrow\quad \alpha(G)\geq h.\)

This proves \(\mathrm{NP}\)-hardness.

For any fixed positive \(K\), the same reduction works with \(d_t=K\) for every type. Each served type must then use every channel, so its served support must again be an independent set. Hence fixing the channel count does not remove hardness.

3. Membership in \(\mathrm{NP}\), including binary-encoded \(K\)

If \(K\) is encoded in binary, explicitly listing every assigned channel need not give a polynomial-size certificate. We instead certify multiplicities of channel patterns.

For a selected set \(S\), each channel has a pattern \(I\subseteq S\): the types assigned that channel. Every such pattern must be an independent set of \(H\).

Let \(n_I\) denote the number of channels with pattern \(I\), including the empty pattern. A canonical allocation from Section 1 gives nonnegative integer multiplicities satisfying

\(\displaystyle \sum_I n_I=K,\qquad \sum_{I\ni t}n_I=d_t\mathbf 1_{\{t\in S\}}\quad(t\in T).\)

Conversely, these equations yield a feasible canonical allocation. Partition the channels according to their patterns; each selected type receives exactly \(d_t\) channels, and adjacent types never share one.

We next prove that only polynomially many distinct patterns are needed.

Compression lemma. Whenever these equations have a nonnegative integer solution, they have one with fewer than \(4(\tau+1)^2\) positive multiplicities.

Proof. Put \(D=\tau+1\), and represent each pattern by

\(\displaystyle a_I=(1,\mathbf 1_I)\in\{0,1\}^{D}.\)

Choose a solution having the fewest positive multiplicities. Suppose its support contains at least \(R=4D^2\) patterns, and choose \(R\) of them.

These vectors have \(2^R\) subset sums. Each coordinate of a subset sum lies between zero and \(R\), so there are at most \((R+1)^D\) distinct sums. But

\(\displaystyle 2^R>(R+1)^D.\)

Indeed, \(4D^2+1<2^{4D}\) for every positive integer \(D\). One elementary verification is \(2D+1\leq3^D\), proved by induction, which implies

\(\displaystyle 4D^2+1<(2D+1)^2\leq9^D<16^D.\)

Thus two distinct subsets have equal vector sums. Cancel their intersection, leaving disjoint subsets \(A,B\) with

\(\displaystyle \sum_{I\in A}a_I=\sum_{I\in B}a_I.\)

Both are nonempty because every vector has first coordinate one. Set \(c=\min_{I\in A}n_I>0\). Subtract \(c\) from multiplicities in \(A\) and add \(c\) to those in \(B\). All equations remain true and all multiplicities remain nonnegative. At least one multiplicity becomes zero, and none outside the existing support becomes positive. This contradicts minimality. The lemma follows.

A certificate therefore consists of \(S\), fewer than \(4(\tau+1)^2\) independent-set patterns, and their positive binary multiplicities. Each multiplicity is at most \(K\), so the certificate uses

\(\displaystyle O\!\left(\tau^2\bigl(\tau+\log(K+1)\bigr)\right)\)

bits.

The verifier checks independence, the multiplicity equations, and \(\sum_{t\in S}\mu_t b_t\geq q\). Exact rational arithmetic takes polynomial time in the input length \(L\). Since \(\tau\) and \(\log(K+1)\) are bounded by \(L\), this establishes membership in \(\mathrm{NP}\).

Together with Section 2, the decision problem is \(\mathrm{NP}\)-complete.

4. Exact running times

An exact dynamic program follows directly from the channel-pattern characterization.

After processing \(j\) channels, record the reachable vectors

\(\displaystyle a=(a_t)_{t\in T},\qquad 0\leq a_t\leq d_t,\)

where \(a_t\) counts channels assigned to type \(t\). Initially only the zero vector is reachable.

For every independent set \(I\subseteq T\), including the empty set, a reachable vector \(a\) transitions to \(a+\mathbf 1_I\), provided no coordinate exceeds its demand. By induction on \(j\), these transitions enumerate exactly all assignments of the first \(j\) channels satisfying conflicts and the demand upper bounds.

After \(K\) rounds, examine states satisfying \(a_t\in\{0,d_t\}\) for every type. Their welfare is

\(\displaystyle \sum_{\{t:a_t=d_t\}}\mu_t b_t.\)

Section 1 guarantees that maximizing over these terminal states gives the original optimum.

There are \(\prod_t(d_t+1)\) states and at most \(2^\tau\) channel patterns. Including independence checks, transitions, and exact arithmetic, a valid running-time bound is

\(\displaystyle O\!\left(m\,2^\tau\tau^2\prod_{t\in T}(d_t+1)\operatorname{poly}(L)\right) \subseteq O\!\left(m\,2^\tau\tau^2(m+1)^\tau\operatorname{poly}(L)\right),\qquad m=K.\)

Two layers of states suffice, using

\(\displaystyle O\!\left(\prod_t(d_t+1)+2^\tau\right)\operatorname{poly}(L)\)

bits of storage. The dependence on \(m\) is numerical; it is not polynomial in the binary encoding length when \(m\) is large.

For the hard special case \(d_t=m\) for every type, the problem is exactly maximum-weight independent set with weights \(w_t=\mu_t b_t\). Enumerating all subsets gives running time

\(\displaystyle O\!\left(2^\tau\tau^2\operatorname{poly}(L)\right).\)

Thus no algorithm polynomial in \(m,\tau,L\) exists unless \(\mathrm{P}=\mathrm{NP}\), already because of instances with \(m=1\).
