The continuous mirror question, as graded

Given a finite project set, rational positive project costs, a rational budget, pairwise project conflicts, and a rational distribution \(\mu\) over approval types, does Modified UG have a finite worst-case approximation ratio for maximizing \(\operatorname{SW}_{\mu}(W)=\sum_t\mu_t|t\cap W|\)? Here \(W\) is an integral feasible project set, and Modified UG scans projects in descending order of \(\sum_{t:p\in t}\mu_t/\operatorname{cost}(p)\), adding each when feasible. In particular, does the ratio remain unbounded with three projects, all pairs conflicting, and support on three singleton approval types?

Packaged proof task (what the prover saw — nothing else)

Let \(P=\{1,\ldots,m\}\), with \(m\geq1\), positive binary-rational costs \(c_p\), positive binary-rational budget \(B\), and a simple undirected conflict graph \(G\) on \(P\). An integral allocation \(W\subseteq P\) is feasible if it is independent in \(G\) and \(\sum_{p\in W}c_p\leq B\).
A society is given by its support: a list \(T\subseteq2^P\) of \(\tau\geq1\) approval types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval types. Let \(L\) be the total input bit length; express any running times in \(m,\tau,L\).
Define \(\operatorname{SW}_{\mu}(W)=\sum_{t\in T}\mu_t|t\cap W|\). Modified UG starts with the empty allocation, scans every project once in nonincreasing order of \(\bigl(\sum_{t\in T:p\in t}\mu_t\bigr)/c_p\), breaks ties by increasing project index, and adds a project precisely when the resulting allocation is feasible.
Let \(W_G\) be its output and \(\operatorname{OPT}_{\mu}=\max_{W\text{ feasible}}\operatorname{SW}_{\mu}(W)\). Define its worst-case approximation ratio as \(R=\sup_{\operatorname{OPT}_{\mu}>0}\operatorname{OPT}_{\mu}/\operatorname{SW}_{\mu}(W_G)\), interpreting a zero denominator as \(+\infty\).

Is \(R\) finite, or is it unbounded? Does the same dichotomy yield a finite or unbounded ratio when \(m=\tau=3\), all project pairs conflict, and \(T=\{\{1\},\{2\},\{3\}\}\)?

For finite approval electorates, Modified UG has an unbounded approximation ratio, already with three mutually conflicting projects and singleton approvals. [Damle and Faltings](https://arxiv.org/html/2508.06060v1#A3.SS1)
No result settling this exact distributional approximation question was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one and required positive masses for listed support types.
  • Required a positive budget, as in the discrete model; retained arbitrary positive rational project costs.
  • Represented the stated pairwise conflicts by a simple undirected graph, consistent with the discrete model's intended pairwise incompatibility interpretation.
  • Fixed otherwise unspecified ties by increasing project index and required a complete scan, skipping infeasible projects.
  • Defined the approximation ratio as optimum divided by greedy welfare, restricted to positive-optimum instances, with a zero denominator interpreted as infinity.
  • Allowed arbitrary approval subsets, including the empty subset, since the approval model imposes no general nonemptiness restriction.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The worst-case ratio is \(R=+\infty\), both in general and under the stated restriction \(m=\tau=3\). The following family proves this using strictly positive dyadic rational masses and costs.

  • Construction and admissibility. Fix an integer \(k\geq2\), and write \(\varepsilon=2^{-k}\). Set

\(P=\{1,2,3\}\), \(G=K_3\), \(B=1\), and \(T=\{\{1\},\{2\},\{3\}\}\). Choose
\[ \]
\(c_1=\varepsilon,\qquad c_2=c_3=1,\)

\(\mu_{\{1\}}=\varepsilon,\qquad \mu_{\{2\}}=\frac12,\qquad \mu_{\{3\}}=\frac12-\varepsilon.\)

Since \(0<\varepsilon\leq\frac14\), all costs and masses are strictly positive binary rationals. The masses sum to \(1\), so the support size is exactly \(\tau=3\). Every singleton is affordable. Because every project pair conflicts, the feasible allocations are precisely \(\varnothing,\{1\},\{2\},\{3\}\).

  • Exact greedy output and optimum. With singleton approval types, project \(p\)'s approval mass is \(\mu_{\{p\}}\). Its density is therefore

\(\frac{\mu_{\{1\}}}{c_1}=1,\qquad \frac{\mu_{\{2\}}}{c_2}=\frac12,\qquad \frac{\mu_{\{3\}}}{c_3}=\frac12-\varepsilon.\)

These densities are strictly decreasing, so Modified UG scans projects in the order \(1,2,3\), independently of its tie-breaking rule. It accepts project \(1\), which is affordable. It then rejects both remaining projects because each conflicts with project \(1\). Thus

\(W_G=\{1\},\qquad \operatorname{SW}_{\mu}(W_G)=\varepsilon.\)

The welfare of a singleton \(\{p\}\) is exactly \(\mu_{\{p\}}\). Among the four feasible allocations, \(\{2\}\) has the largest welfare: its value is \(\frac12\), whereas the others have values \(0,\varepsilon,\frac12-\varepsilon\). Consequently,

\(\operatorname{OPT}_{\mu}=\frac12,\qquad \frac{\operatorname{OPT}_{\mu}}{\operatorname{SW}_{\mu}(W_G)}=\frac{1}{2\varepsilon}=2^{k-1}.\)

For every finite positive bound \(C\), an integer \(k\geq2\) can be chosen with \(2^{k-1}>C\). Hence the restricted class already has unbounded ratio. Since that class is contained in the general class, the general ratio is also unbounded. Throughout this family, \(m=\tau=3\); only the numerical input length grows, with \(L=\Theta(k)\) under standard binary rational encoding.

  • Connection to finite electorates. Normalizing voter counts preserves both greedy choices and approximation ratios. More precisely, for any rational mass vector, choose a positive integer \(D\) such that every \(D\mu_t\) is an integer, and create \(D\mu_t\) voters of type \(t\). Their total number is \(D\). For every allocation \(W\), total approval welfare is \(D\operatorname{SW}_{\mu}(W)\), and every project's density is multiplied by the same positive factor \(D\). Thus scan order, tie-breaking, feasibility decisions, optimal allocations, and welfare ratios are preserved.

This explains why the finite-electorate obstruction in [Damle and Faltings, Appendix C.1](https://arxiv.org/html/2508.06060v1#A3.SS1) carries over to rational distributions. The explicit construction above verifies the conclusion directly under every hypothesis of this question.
