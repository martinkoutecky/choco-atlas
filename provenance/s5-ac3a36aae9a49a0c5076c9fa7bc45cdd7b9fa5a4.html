The continuous mirror question, as graded

Given \(K\) offices with disjoint nonempty candidate sets \(A_1,\ldots,A_K\), and a finite support of approval types \(t\subseteq A\) with positive binary-rational masses \(\mu_t\) summing to \(1\), does there exist an allocation \(X=\{x_j\}_{j=1}^K\), with \(x_j\in A_j\), such that for every \(z\) with \(0\le z_t\le\mu_t\) and \(\sum_t z_t\ge 1/K\), if \(\left(\bigcap_{t:z_t>0}t\right)\cap A_j\ne\varnothing\) for some office \(j\), then \(X\cap\left(\bigcup_{t:z_t>0}t\right)\ne\varnothing\)?

Packaged proof task (what the prover saw — nothing else)

Let \(K\ge 1\) offices have finite, pairwise disjoint, nonempty candidate sets \(A_1,\ldots,A_K\); write \(A=\bigcup_{j=1}^K A_j\) and \(m=|A|\).
A society is given by its support: a list \(T\) of \(\tau\) distinct approval types \(t\subseteq A\), each with positive binary-rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Empty approval types are allowed; \(\tau\) is the support size, not the number of possible types.
An allocation is \(X=\{x_1,\ldots,x_K\}\) with \(x_j\in A_j\). A coalition is a real vector \(z\) satisfying \(0\le z_t\le\mu_t\); write \(S(z)=\{t\in T:z_t>0\}\).
Call \(X\) globally justified if, for every coalition with \(\sum_{t\in T}z_t\ge 1/K\), the condition \((\bigcap_{t\in S(z)}t)\cap A_j\ne\varnothing\) for every \(j\in\{1,\ldots,K\}\) implies \(X\cap(\bigcup_{t\in S(z)}t)\ne\varnothing\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,K,L\).

Is deciding whether a globally justified allocation exists solvable in polynomial time in \(m,\tau,K,L\), or is it \(\mathrm{NP}\)-hard?

For explicitly listed discrete voters, global justified representation with cohesion in every office is guaranteed to exist and admits a polynomial-time construction. [Page–Shapiro–Talmon](https://arxiv.org/pdf/2009.09734v4)
The same discrete condition is weak span-wise justified representation; it admits a polynomial-time construction even with general subcommittee quotas, whereas requiring cohesion in just one subcommittee yields an \(\mathrm{NP}\)-complete existence problem with general quotas. [Aziz–Lee](https://www.aies-conference.com/2018/contents/papers/main/AIES_2018_paper_54.pdf)
No result settling the exact binary-rational mass formulation above was identified in the literature search.

Result

The problem is polynomial-time solvable. Every valid instance admits a globally justified allocation, and one can construct such an allocation in time polynomial in \(m,\tau,K,L\).

The construction below handles rational masses directly. Cohesion in every office is the essential hypothesis, matching [Aziz–Lee’s weak span-wise justified representation condition](https://www.aies-conference.com/2018/contents/papers/main/AIES_2018_paper_54.pdf).

1. Reducing real coalitions to their supports

For \(S\subseteq T\), define its mass by \(\mu(S)=\sum_{t\in S}\mu_t\).

Lemma. An allocation \(X\) fails global justification if and only if there is a nonempty \(S\subseteq T\) satisfying all three conditions:

  • \(\mu(S)\ge 1/K\).
  • \((\bigcap_{t\in S}t)\cap A_j\ne\varnothing\) for every office \(j\).
  • \(X\cap(\bigcup_{t\in S}t)=\varnothing\).

Proof. If a coalition \(z\) witnesses failure, its support \(S=S(z)\) is nonempty because its mass is positive. Moreover, \(\mu(S)\ge\sum_{t\in T}z_t\ge 1/K\), while cohesion and lack of representation are exactly conditions 2 and 3.

Conversely, given such an \(S\), set \(z_t=\mu_t\) for \(t\in S\) and \(z_t=0\) otherwise. Positivity of the masses implies \(S(z)=S\), so this coalition witnesses failure. This proves the lemma.

2. Weighted greedy construction

Process the offices in the order \(1,\ldots,K\). Let \(U_0=T\). At step \(j\), the set \(U_{j-1}\) contains precisely the types approving none of the previously selected candidates.

For each \(a\in A_j\), compute its currently unrepresented support mass:

\(s_j(a)=\sum_{\substack{t\in U_{j-1}\\a\in t}}\mu_t.\)

Choose \(x_j\in A_j\) maximizing \(s_j(a)\), breaking ties arbitrarily. Define

\(R_j=\{t\in U_{j-1}:x_j\in t\},\qquad U_j=U_{j-1}\setminus R_j.\)

Return \(X=\{x_1,\ldots,x_K\}\).

Each maximum exists because \(A_j\) is finite and nonempty. The selected candidates form a valid allocation because exactly one is chosen from each office.

3. Correctness proof

Suppose, for contradiction, that the returned allocation is not globally justified. By the lemma, there is a witnessing support \(S\). Write \(M=\mu(S)\), so \(M\ge 1/K\).

Condition 3 implies that no type in \(S\) approves any selected candidate. Hence \(S\subseteq U_{j-1}\) at every step \(j\), and also \(S\subseteq U_K\).

By condition 2, for each office \(j\) there is a candidate \(c_j\in A_j\) approved by every type in \(S\). Since these types remain unrepresented at step \(j\),

\(s_j(c_j)\ge\mu(S)=M.\)

The greedy choice therefore satisfies

\(\mu(R_j)=s_j(x_j)\ge s_j(c_j)\ge M.\)

The sets \(R_1,\ldots,R_K\) are pairwise disjoint: a type is removed when it first becomes represented. They are also disjoint from \(S\), whose types remain unrepresented. Consequently,

\(1=\mu(T)\ge\mu(S)+\sum_{j=1}^{K}\mu(R_j)\ge(K+1)M\ge\frac{K+1}{K}>1.\)

This contradiction proves that \(X\) is globally justified. The proof includes the equality case \(M=1/K\) and allows empty approval types.

4. Exact arithmetic and running time

Write each binary-encoded rational mass as \(\mu_t=p_t/q_t\), with positive integer numerator and denominator. Set

\(D=\prod_{t\in T}q_t,\qquad w_t=p_t(D/q_t).\)

Because the total encoding length is \(L\), the integer \(D\) has \(O(L)\) bits. The weights satisfy \(w_t=D\mu_t\) and \(\sum_{t\in T}w_t=D\). Thus every support sum used by the algorithm has \(O(L)\) bits. Maximizing integer support sums gives exactly the same choices as maximizing rational support masses.

Using schoolbook integer arithmetic, computing \(D\) and all \(w_t\) costs \(O(\tau L^2)\) bit operations.

After building a candidate–type incidence table:

  • Computing all candidate scores over all offices uses \(O(m\tau)\) additions.
  • Finding the maxima uses \(O(m)\) comparisons.
  • Updating the unrepresented types uses \(O(K\tau)\) membership checks.

An explicit polynomial bound, including input processing, is therefore

\(O\!\left(L+\tau L^2+(m\tau+K\tau+m)L\right).\)

Since \(K\le m\) and \(\tau\ge1\), this simplifies to \(O(L+\tau L^2+m\tau L)\). No expansion into individual voters is required.

Thus existence is guaranteed on every valid input, and the construction also has polynomial bit complexity.
