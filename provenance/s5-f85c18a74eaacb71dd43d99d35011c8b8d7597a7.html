The continuous mirror question, as graded

Given projects \(A\) with costs \(c\), budget \(l\), and supported feasible approval sets \(S\) with positive rational masses \(\mu_S\) summing to \(1\), define \(r_\mu(X)=\sum_{S\supseteq X}\mu_S\). Set \(m_\mu(\emptyset)=0\), \(m_\mu(\{a\})=c(a)\), and, for \(|X|\ge 2\), set \(m_\mu(X)=\max\{(r_\mu(X)-\prod_{a\in X}r_\mu(\{a\}))c(X),\max_{a\in X}(-\sum_{Y\subsetneq X:\,a\in Y}m_\mu(Y))\}\), with \(u_{M,\mu}(X)=\sum_{Y\subseteq X}m_\mu(Y)\). Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The problem is \(\mathrm{NP}\)-hard, even when every project has unit cost and every approval set has size at most two. The proof below gives a direct reduction for the supported rational-mass formulation. The finite-electorate analogue is established in [Durand–Pascual, Proposition 7](https://arxiv.org/html/2403.19194v1#S6).

1. A useful identity

Write the expected welfare of a bundle \(B\) as \(F_\mu(B)\). Expanding the utility definition and interchanging finite sums gives

\(F_\mu(B)=\sum_{S\in\mathcal T}\mu_S\sum_{Y\subseteq S\cap B}m_\mu(Y)=\sum_{Y\subseteq B}r_\mu(Y)m_\mu(Y).\)

Consequently, if every supported approval set has size at most two, only singleton and pair terms contribute to welfare. Moreover, their recursively defined coefficients depend only on coefficients of smaller sets. Thus interactions of higher orders, although included in the definition, cannot affect welfare in these instances.

2. Construction from Clique

We use the standard \(\mathrm{NP}\)-complete Clique decision problem: given a simple undirected graph \(G=(V,E)\) and a positive integer \(k\), determine whether \(G\) contains a clique of size \(k\).

We may restrict to instances with \(n=|V|\geq k\geq2\) and \(e=|E|\geq1\). Excluded instances are directly decidable and can be mapped to fixed restricted yes- or no-instances: respectively, a single edge with \(k=2\), or a three-vertex path with \(k=3\).

For each vertex \(v\), let \(d_v\) be its degree. Define

\(D=\max_{v\in V}d_v,\qquad N=(n+1)^2,\qquad p=\frac{D}{N}.\)

Create one project for each vertex, with cost \(1\), and set the budget to \(l=k\). Define the support and masses as follows:

  • For every edge \(\{v,w\}\in E\), include the approval set \(\{v,w\}\) with mass \(1/N\).
  • For every vertex \(v\) with \(d_v<D\), include \(\{v\}\) with mass \((D-d_v)/N\).
  • Include \(\emptyset\) with mass \((N-nD+e)/N\).

All listed approval sets are distinct and feasible, since their sizes are at most \(2\leq k\). Every listed mass is strictly positive: in particular, \(D\leq n-1\) implies \(N>nD\).

By the degree-sum identity, their total mass is

\(\frac{e+\sum_{v\in V}(D-d_v)+N-nD+e}{N}=\frac{e+nD-2e+N-nD+e}{N}=1.\)

Thus the construction satisfies every input requirement.

3. Exact evaluation of welfare

Every project has the same singleton approval rate:

\(r_\mu(\{v\})=\frac{d_v}{N}+\frac{D-d_v}{N}=p,\)

where the second summand is zero when its singleton approval set is omitted.

For an edge \(\{v,w\}\), its only supported superset is its own pair approval set, so \(r_\mu(\{v,w\})=1/N\). Both monotonicity candidates in the pair recursion equal \(-1\), since singleton coefficients equal \(1\). Therefore,

\(m_\mu(\{v,w\})=\max\left\{2\left(\frac1N-p^2\right),-1\right\}=\frac{2(N-D^2)}{N^2}.\)

The last equality follows from \(D<n+1\), which gives \(N-D^2>0\).

A nonedge has pair approval rate zero, so its coefficient contributes zero in the welfare identity. Every set of size at least three also has approval rate zero.

Let \(e_G(B)\) denote the number of graph edges with both endpoints in \(B\), and define

\(w=\frac{2(N-D^2)}{N^3}>0.\)

The welfare identity now gives the exact formula

\(F_\mu(B)=p|B|+w\,e_G(B).\)

Both \(p\) and \(w\) are strictly positive, since the source graph has an edge.

4. Threshold and equivalence

Choose the rational threshold

\(Q=pk+w\binom{k}{2}=\frac{DkN^2+2(N-D^2)\binom{k}{2}}{N^3}.\)

If \(G\) contains a clique \(C\) of size \(k\), then \(C\) is a feasible bundle and

\(F_\mu(C)=pk+w\binom{k}{2}=Q.\)

Conversely, suppose a feasible bundle \(B\) satisfies \(F_\mu(B)\geq Q\), and put \(b=|B|\leq k\). A simple graph on \(b\) vertices has at most \(\binom b2\) edges, hence

\(F_\mu(B)\leq pb+w\binom b2.\)

If \(b<k\), then

\(Q-\left(pb+w\binom b2\right)=p(k-b)+w\left(\binom k2-\binom b2\right)>0,\)

because the first term is strictly positive and the second is nonnegative. Thus \(b=k\). The threshold inequality then forces \(e_G(B)\geq\binom k2\); the reverse inequality always holds. Therefore every pair of vertices in \(B\) is an edge, and \(B\) is a \(k\)-clique.

This proves a polynomial-time many-one reduction.

5. Encoding and running times

The reduction produces \(m=n\) projects and

\(\tau\leq e+n+1\leq\binom n2+n+1.\)

Every mass numerator and denominator has \(O(\log n)\) bits. The threshold numerator and denominator also have \(O(\log n)\) bits, as is explicit in its formula. The output therefore has polynomial length under either an incidence-vector or an indexed-list encoding of approval sets.

Using elementary integer arithmetic, the construction takes

\(O\!\left((m^2+\tau)\log^2(m+1)+L\right)\)

bit operations, including writing the output of length \(L\).

For completeness, the unrestricted problem has an exact exponential-time algorithm with running time

\(O\!\left((m3^m+\tau m2^m)(mL+m^2)^2\right).\)

Here is why exact arithmetic fits this bound. Let \(H\) be the product of the denominators of all input masses, so \(\log H\leq L\). Every approval rate has denominator dividing \(H\). Induction on \(|X|\) shows that every \(m_\mu(X)\) has denominator dividing \(H^{|X|}\): the product term has this property, every proper-subset coefficient has it, and taking a maximum selects one candidate.

To bound magnitudes, put \(C=c(A)\). We claim

\(|m_\mu(X)|\leq C\,2^{|X|^2}.\)

The singleton case follows from \(c(a)\leq C\). For \(t=|X|\geq2\), the statistical candidate has absolute value at most \(C\). By induction, each monotonicity candidate has absolute value at most

\(\sum_{Y\subsetneq X}|m_\mu(Y)|\leq2^tC\,2^{(t-1)^2}\leq C\,2^{t^2}.\)

The maximum consequently satisfies the claimed bound. All coefficients, utilities, and welfare comparisons therefore use \(O(mL+m^2)\) bits.

Computing all approval rates by scanning the support costs \(O(\tau m2^m)\) operations. Evaluating the recursion by explicitly summing its proper-subset terms costs \(O(m3^m)\) operations. Computing all utilities and checking all feasible bundles stays within the displayed bound when elementary arithmetic is used.

On the restricted family with approval sets of size at most two, a proposed bundle is verifiable in polynomial time: only singleton and pair coefficients are needed. A conservative bound is \(O((m+\tau)mL^2)\) bit operations. Thus this restricted family is \(\mathrm{NP}\)-complete. Membership of the unrestricted problem in \(\mathrm{NP}\) is unnecessary for the hardness conclusion.

6. Conclusion

The supported rational-mass decision problem is \(\mathrm{NP}\)-hard, already with unit costs and approval sets of size at most two. Hence a polynomial-time algorithm for it would imply \(\mathrm P=\mathrm{NP}\).
