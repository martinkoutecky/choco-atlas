The continuous mirror question, as graded

Given a finite agenda Φ, finitely many source types \(t\) carrying complete rational likelihood vectors \(a_t(\varphi)\), binary-rational masses \(\mu_t\) summing to \(1\), a mass quota \(\lambda\in(0,1]\), and crispifying thresholds \(c_\varphi\), compute \(Q^\mu_\lambda(\varphi)=\max\{a\in[0,1]:\sum_{t:a_t(\varphi)\ge a}\mu_t\ge\lambda\}\). Does crispifying \(Q^\mu_\lambda\) yield exactly the same judgments as applying quota \(\lambda\) to the typewise crispified vectors—that is, is \(\varphi\) selected exactly when \(\sum_{t:a_t(\varphi)\ge c_\varphi}\mu_t\ge\lambda\) for every \(\varphi\in\Phi^\cup\)?

Packaged proof task (what the prover saw — nothing else)

Let \(\Phi\) be a finite agenda of \(m\) propositional formulas, none a tautology or contradiction, and write \(\Phi^\cup=\Phi\cup\{\neg\varphi:\varphi\in\Phi\}\).
A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies a complete vector \(a_t\in([0,1]\cap\mathbb Q)^{\Phi^\cup}\) of lower probability bounds. Rationality is promised: the set \(\mathcal P_t\) of probability distributions over propositional valuations satisfying all these bounds is nonempty, and \(a_t(\varphi)=\min_{p\in\mathcal P_t}p(\varphi)\) for every \(\varphi\in\Phi^\cup\).
The input also supplies binary-rational \(\lambda\in(0,1]\) and thresholds \(c_\varphi\in[0,1]\), with \(c_\varphi+c_{\neg\varphi}>1\) for every \(\varphi\in\Phi\). All numerical inputs use binary encoding; \(L\) denotes the total input bit length.
Define \(Q^\mu_\lambda(\varphi)=\max\{a\in[0,1]:\sum_{t:a_t(\varphi)\ge a}\mu_t\ge\lambda\}\) and \(J_t^c=\{\varphi\in\Phi^\cup:a_t(\varphi)\ge c_\varphi\}\).
The two collective sets are \(C=\{\varphi\in\Phi^\cup:Q^\mu_\lambda(\varphi)\ge c_\varphi\}\) and \(U=\{\varphi\in\Phi^\cup:\sum_{t:\varphi\in J_t^c}\mu_t\ge\lambda\}\); these sets may be incomplete or inconsistent.

Does \(C=U\) hold for every admissible input, or is there a counterexample? Is deciding \(C=U\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L\).

For a finite list of sources and an integer quota \(1\le q\le n\), crispifying the coordinatewise quota aggregate equals applying the quota to the individually crispified judgments; this is an identity, not a complexity classification. [Source](https://arxiv.org/pdf/1907.09111)
No separate result for this exact mass formulation was located in the literature search.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every admissible input, \(C=U\). There is no counterexample. Deciding equality is therefore in \(\mathrm P\); computing the common set also takes polynomial time in \(m,\tau,L\).

Proof of the identity

Fix a coordinate \(\psi\in\Phi^\cup\). Write \(x_t=a_t(\psi)\), and define its supporting mass at level \(z\in[0,1]\) by \(S(z)=\sum_{t:x_t\ge z}\mu_t\).

First, we verify that the maximum defining \(Q^\mu_\lambda(\psi)\) exists. List the distinct coordinate values in decreasing order as \(b_1>\cdots>b_k\), and put \(W_j=\sum_{t:x_t\ge b_j}\mu_t\). Since \(W_k=1\ge\lambda\), there is a least index \(j_*\) with \(W_{j_*}\ge\lambda\).

The level \(b_{j_*}\) is feasible. If \(z>b_{j_*}\), every type counted by \(S(z)\) has its coordinate value among \(b_1,\ldots,b_{j_*-1}\). Consequently, \(S(z)\le W_{j_*-1}<\lambda\), where \(W_0=0\). Thus \(Q^\mu_\lambda(\psi)=b_{j_*}\), and this maximum is attained.

Now let \(c=c_\psi\). We prove \(Q^\mu_\lambda(\psi)\ge c\) if and only if \(S(c)\ge\lambda\).

  • If \(S(c)\ge\lambda\), then \(c\) is feasible in the defining maximum, so \(Q^\mu_\lambda(\psi)\ge c\).
  • Conversely, suppose \(Q^\mu_\lambda(\psi)\ge c\). Since the maximum is attained, \(S(Q^\mu_\lambda(\psi))\ge\lambda\). The function \(S\) is nonincreasing, because increasing its argument can only remove supporting types. Hence \(S(c)\ge S(Q^\mu_\lambda(\psi))\ge\lambda\).

By the definition of individual crispification, \(\psi\in J_t^c\) if and only if \(x_t\ge c_\psi\). Therefore

\(\psi\in C\ \Longleftrightarrow\ S(c_\psi)\ge\lambda\ \Longleftrightarrow\ \sum_{t:\psi\in J_t^c}\mu_t\ge\lambda\ \Longleftrightarrow\ \psi\in U.\)

This holds for every coordinate, proving \(C=U\). Ties and equality at either threshold are covered by the non-strict inequalities.

The proof uses only the finite support, nonnegative masses summing to \(1\), and \(0<\lambda\le1\). Rationality and the conditions on complementary thresholds impose no additional obstacle to the identity.

Running times and complexity

Deciding equality. On the promised domain, an algorithm can always return YES. This takes \(O(1)\) time without reading the input, or \(O(L)\) time if reading it is required. Checking the rationality promise is not part of this decision task.

Computing the common set. There are at most \(2m\) coordinates. For each coordinate \(\psi\), scan all \(\tau\) types, sum the masses satisfying \(a_t(\psi)\ge c_\psi\), and compare the sum with \(\lambda\).

Here is an explicit exact-arithmetic bound. Write \(\mu_t=u_t/d_t\) and \(\lambda=r/s\), with positive denominators, and choose \(D=s\prod_{t=1}^{\tau}d_t\). Precompute the integers \(w_t=u_tD/d_t\) and \(h=rD/s\). The acceptance test becomes \(\sum_{t:a_t(\psi)\ge c_\psi}w_t\ge h\).

The bit length of \(D\) is \(O(L)\), since the input contains all its denominator factors. Each \(w_t\), and every partial supporting sum, is at most \(D\). Rational coordinate comparisons use cross multiplication of integers of \(O(L)\) bits. With schoolbook integer arithmetic:

  • Preprocessing takes \(O((\tau+1)L^2)\) bit operations.
  • Scanning all coordinates takes \(O(m\tau L^2)\) bit operations.

Thus a uniform bound is \(O(L+(m+1)\tau L^2)\), simplifying to \(O(m\tau L^2)\) when \(m\ge1\). If \(m=0\), both sets are empty.

As a promise decision problem, equality has no NO-instances. It is therefore not \(\mathrm{NP}\)-hard under many-one reductions required to output admissible instances: a NO-instance of satisfiability could not map to a NO-instance here.

Relation to the cited source

Proposition 3.1 of [*Aggregating Probabilistic Judgments*](https://arxiv.org/pdf/1907.09111) proves the corresponding identity for a finite list of sources and an integer quota. Taking \(\tau=n\), \(\mu_t=1/n\), and \(\lambda=q/n\) recovers that setting. The argument above establishes the supplied mass formulation directly.
