The continuous mirror question, as graded

Given finite man-type and woman-type sets \(I,J\), rational type masses \(\mu_i,\nu_j\) summing to one on each side, integer capacities, mutually acceptable partners, and weak rankings of opposite-side types, determine whether a Pareto stable matching always exists and compute one if it does. Each type’s agents form an atomless population; each individual receives an integral set of partners, with each pair matched at most once. Stability means there is no positive-mass measurable partial matching consisting of blocking pairs under the paper’s capacity and preference conditions. Pareto efficiency means there is no feasible measurable matching that weakly improves almost every agent and strictly improves a positive mass. Give a finite rational description of the matching and characterize the complexity in the number of types \(\tau\), maximum capacity \(C\), and input bit length \(L\), including whether computation is polynomial in those parameters.

Packaged proof task (what the prover saw — nothing else)

Let \(I,J\) be nonempty finite sets of types, with mutually acceptable type pairs \(E\subseteq I\times J\), integer capacities \(c_t\geq0\), and transitive complete weak rankings of acceptable opposite-side types. All acceptable partners are strictly preferred to an empty slot; ties remain unbroken. Write \(m=|E|\) and \(C=\max_t c_t\).
A society is given by its support: the list of the \(\tau=|I|+|J|\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Masses \(\mu_i,\nu_j\) sum to one on each side; \(L\) is the total input bit length. Represent each type by a disjoint Lebesgue interval of its mass.
A feasible matching is a measurable simple bipartite relation, expressible as a countable union of graphs of measure-preserving partial bijections, using only acceptable pairs and giving each individual at most its type's capacity in distinct partners. Several distinct partners may have the same type.
For finite partner sets \(A,B\), an individual weakly prefers \(A\) to \(B\) precisely when an injection from \(B\) into \(A\) maps each partner to a weakly preferred partner. Preference is strict when this holds and the reverse comparison fails; incomparable bundles are not weak improvements.
An unmatched acceptable pair blocks when each endpoint either has unused capacity or strictly prefers the other endpoint to some current partner. A matching is stable if no measure-preserving partial bijection between positive-measure subsets pairs individuals exclusively through blocking pairs.
A matching is Pareto efficient if no feasible measurable matching weakly improves almost every individual and strictly improves a positive mass. Pareto stable means stable and Pareto efficient. A finite rational description consists of finitely many matching maps, each a translation between equal-length intervals with rational endpoints.

Does every such society admit a Pareto stable matching with a finite rational description?
Is deciding existence and computing such a description when one exists solvable in polynomial time in \(m,\tau,C,L\), or is this computational problem NP-hard?

For finite individual populations with these bundle preferences and at most one match per individual pair, Pareto stable assignments always exist and are computable in polynomial time ([Chen, 2012](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.STACS.2012.384)); a later discrete result also establishes existence and an efficient algorithm ([Chen–Li, 2019](https://doi.org/10.1016/j.jmateco.2019.03.005)).
No result settling this exact atomless formulation was located in the literature search.

Modeling choices made when packaging the task

  • The graded question omitted bundle comparisons. Used the partial order generated by acceptable additions and weakly improving replacements, expressed by injections; incomparable bundles do not count as weak improvements.
  • Made explicit that every acceptable partner is strictly preferred to an empty slot, as required by the discrete blocking and augmentation conditions.
  • Allowed nonnegative integer capacities, including zero, consistent with the discrete model's dummy agents; did not impose the finite-population bound on capacities in an atomless population.
  • Specified standard Lebesgue interval populations and measure-preserving matching maps so that bilateral matches conserve mass.
  • Interpreted a positive-mass measurable partial matching of blocking pairs as a measure-preserving partial bijection between positive-measure subsets.
  • Specified finite rational output as finitely many translations between rational intervals; general feasible matchings and Pareto comparisons remain measurable rather than restricted to rational outputs.
  • Defined m as the number of mutually acceptable type pairs, since this model has no separate candidate or object count.

Result. Every society in the question admits a Pareto stable matching with a finite rational description. Such a description can be computed in time polynomial in \(m,\tau,C,L\), using \(O(m+\tau C)\) translation maps.

The proof combines a polynomial algorithm for stable allocations with a linear program. The main points requiring proof are that atomless stability depends only on aggregate match quantities, and that rational aggregate quantities can be realized without repeated individual pairs.

1. Aggregate quantities and bundle comparisons. Work only with supported types and acceptable pairs between them. This does not increase \(m\). Write \(\alpha_t\) for the mass of type \(t\), and put \(q_t=c_t\alpha_t\). Choose half-open type intervals with rational endpoints by concatenating their rational masses.

For each type \(t\), number its acceptable preference tiers from best to worst as \(1,\ldots,r_t\). Write \(\rho_t(s)\) for the tier of opposite-side type \(s\). Types with no acceptable supported neighbors have \(r_t=0\).

For a bundle \(A\) belonging to an individual of type \(t\), define
\[ \]
\(n_{t,k}(A)=|\{a\in A:\rho_t(\operatorname{type}(a))\leq k\}|\), for \(1\leq k\leq r_t\).

We first establish the following comparison criterion:

\(A\) is weakly preferred to \(B\) if and only if \(n_{t,k}(A)\geq n_{t,k}(B)\) for every \(k\). Under this weak comparison, preference is strict if and only if at least one inequality is strict.

Indeed, an improvement injection sends every partner in the first \(k\) tiers to a partner in those tiers, proving necessity. Conversely, list each bundle in nondecreasing order of tier. The inequality at the last tier gives \(|A|\geq|B|\). For each position \(h\leq|B|\), the \(h\)-th partner of \(A\) has tier no worse than the \(h\)-th partner of \(B\): otherwise, at the latter partner’s tier, \(B\) would have at least \(h\) partners and \(A\) fewer than \(h\). Matching the lists position by position therefore gives the required injection. Applying the same criterion in reverse proves the assertion about strictness.

For a feasible measurable matching \(M\), define
\(x_{ij}(M)=\int_{X_i}|M(a)\cap Y_j|\,da\).

The same quantity equals \(\int_{Y_j}|M(b)\cap X_i|\,db\). To see this, enumerate the partial measure-preserving bijections representing \(M\), and restrict each graph to edges absent from all earlier graphs. These restrictions still preserve measure and their graphs are disjoint. Summing their domain measures and range measures gives the two degree integrals.

Consequently, the aggregate vector belongs to the transportation polytope
\(P=\{x\in\mathbb R_{\geq0}^{E}:\sum_jx_{ij}\leq q_i,\ \sum_ix_{ij}\leq q_j\}\).

For either side, define the linear prefix quantity
\(Q_{t,k}(x)=\sum_{s:\rho_t(s)\leq k}x_{ts}\),
where \(x_{ts}\) denotes the coordinate of the corresponding bipartite edge. For an actual matching,
\(Q_{t,k}(x(M))=\int_{X_t}n_{t,k}(M(a))\,da\).

Thus every measurable Pareto improvement weakly increases every \(Q_{t,k}\).

Define
\(F(x)=\sum_t\sum_{k=1}^{r_t}Q_{t,k}(x)\).

Every Pareto improvement strictly increases \(F\). Indeed, its individual prefix differences are nonnegative almost everywhere. At each strictly improving individual, at least one difference is a positive integer. There are finitely many types and prefixes, so strict improvement on positive mass makes the sum of their integrals strictly positive.

2. An exact aggregate stability criterion. For an acceptable pair \((i,j)\), let \(W_i(j)\) be the individuals of type \(i\) who have unused capacity or strictly prefer type \(j\) to some current partner.

For an individual \(a\) of type \(i\),
\(a\in W_i(j)\) if and only if \(n_{i,\rho_i(j)}(M(a))<c_i\).

If capacity is unused, this inequality holds. If capacity is full, it holds precisely when some partner lies strictly below \(j\). This also covers \(c_i=0\), when both conditions are false. Therefore
\(q_i-Q_{i,\rho_i(j)}(x(M))=\int_{X_i}(c_i-n_{i,\rho_i(j)}(M(a)))\,da\),
and hence
\(\lambda(W_i(j))=0\) if and only if \(Q_{i,\rho_i(j)}(x(M))=q_i\).

We claim that \(M\) is stable exactly when, for every acceptable \((i,j)\),
\(Q_{i,\rho_i(j)}(x(M))=q_i\) or \(Q_{j,\rho_j(i)}(x(M))=q_j\). Call this condition (S).

Suppose first that (S) holds. For each type pair, at least one endpoint’s willingness set is null. A measure-preserving partial bijection cannot pair positive mass through that type pair exclusively using blocking pairs. Since there are finitely many type pairs, no positive-mass blocking partial bijection exists.

Conversely, suppose (S) fails for \((i,j)\). Then \(A=W_i(j)\) and \(B=W_j(i)\) both have positive measure. The matching relation \(R\) has two-dimensional Lebesgue measure zero: it is measurable and each vertical section is finite.

For a real translation parameter \(s\), let \(H_s=A\cap(B-s)\). Fubini’s theorem gives
\(\int_{\mathbb R}\lambda(H_s)\,ds=\lambda(A)\lambda(B)>0\).

Also, by the change of variables \((a,s)\mapsto(a,a+s)\),
\(\lambda(\{a:(a,a+s)\in R\})=0\)
for almost every \(s\). Choose such an \(s\) with \(\lambda(H_s)>0\), and remove from \(H_s\) the null set of already matched pairs. Translation \(a\mapsto a+s\) on the remaining positive-measure domain is a measure-preserving partial bijection exclusively through blocking pairs. This contradicts stability and proves the criterion.

In particular, stability depends only on \(x(M)\).

3. Rational realization with distinct partners. We now prove that every rational \(x\in P\) has a finite rational realization with \(O(m+\tau C)\) translation maps.

For each type \(t\), form a strip \([0,c_t\alpha_t)\), divided into \(c_t\) consecutive slots of length \(\alpha_t\). Each slot is identified by translation with the individual interval of type \(t\).

Pack, consecutively in this strip, one segment of length \(x_{ts}\) for each incident acceptable edge. The capacity inequality ensures that these segments fit. Perform this construction on both sides.

For each \((i,j)\), its source and target strip segments have equal length \(x_{ij}\). Pair their coordinates in order, cutting wherever either segment crosses a slot boundary. After identifying slots with individual intervals, each resulting piece is a translation between equal-length rational intervals.

Let \(p\) be the number of pieces. There is initially one piece per positive edge; every additional cut comes from a slot boundary. Thus
\(p\leq m+\sum_tc_t\leq m+\tau C\).

With slot labels retained, each individual uses at most one partner per slot. However, folding the slots can cause different pieces to repeat the same individual pair. The following modification removes all repetitions.

Process the pieces in order. Suppose the current piece has domain \([a,a+\ell)\) and target \([b,b+\ell)\), with \(\ell>0\). Replace it by
\(a+u\mapsto b+((u+\theta)\bmod\ell)\), for \(0\leq u<\ell\).

For rational \(0<\theta<\ell\), this is two translations, with offsets
\(b-a+\theta\) and \(b-a+\theta-\ell\).

Choose
\(\theta=k\ell/(4p+1)\), with \(k\in\{1,\ldots,4p\}\),
so neither offset equals any previously produced translation offset. Before processing this piece, there are at most \(2(p-1)\) previous offsets. Each excludes at most two values of \(\theta\), leaving an available choice among the \(4p\) candidates. The two new offsets are themselves different.

All final translation offsets are therefore distinct. If two maps contain the same individual pair, their offsets must coincide; thus no pair is repeated.

Each modification preserves its entire source interval and its entire target interval. Slot occupancy and all type-pair quantities are consequently preserved. Every individual still has at most \(c_t\) partners, and these partners are distinct.

The resulting relation uses at most \(2p\) rational translation maps. Packing, cutting and selecting the rotations require polynomial time in \(m,\tau,C\) and the encoding length of \(x\). All resulting rational endpoints have polynomial encoding length. The case \(p=0\) gives the empty relation.

4. Computing a stable aggregate vector. We use the stable-allocation theorem of Baïou and Balinski. For a finite bipartite graph with strictly ranked incident edges, positive vertex quotas \(q_t\), and nonnegative edge bounds \(u_{ij}\), their strongly polynomial inductive algorithm finds a feasible allocation \(z\) such that every edge with \(z_{ij}<u_{ij}\) satisfies
\(\sum_{h\succeq_i^*j}z_{ih}=q_i\) or \(\sum_{g\succeq_j^*i}z_{gj}=q_j\).
Here \(\succeq_t^*\) is the auxiliary strict ordering, including equality. We use the corrected paper, specifically its stability definition, Theorem 2 and Corollary 1. [Baïou–Balinski, corrected version](https://pubsonline.informs.org/doi/pdf/10.1287/moor.27.4.662.302)

Apply this theorem as follows:

  • Delete zero-quota vertices for this auxiliary computation.
  • Choose strict refinements of the remaining type rankings.
  • Give every acceptable edge bound \(u_{ij}=C+1\).
  • Use vertex quotas \(q_t=c_t\alpha_t\).

The graph is finite and bipartite, the remaining quotas are positive rational numbers, and the auxiliary rankings are strict. These are precisely the theorem’s hypotheses. If there are no remaining edges, use the zero vector.

Every feasible edge quantity is at most its endpoint quota, which is at most \(C\). Hence every acceptable edge is strictly below its artificial bound \(C+1\). The theorem therefore supplies an endpoint prefix equality for every remaining edge.

A prefix under the auxiliary refinement ending at \(j\) is contained in the original weak prefix ending at \(j\). If the former fills quota \(q_i\), the latter also fills quota: it is at least \(q_i\) and cannot exceed the capacity bound. Thus the resulting vector \(x^0\) satisfies (S) under the original rankings. Edges incident to a deleted zero-quota vertex satisfy (S) at that vertex.

The inductive algorithm uses additions, subtractions, comparisons and minima, so rational inputs give rational outputs. Clearing the input denominators also shows that its quantities have polynomial encoding length.

The refinements serve only to obtain \(x^0\); all subsequent constraints and the final Pareto comparison use the original ties.

5. A linear program yielding Pareto stability. Define the nonempty rational polytope
\(P^+=\{x\in P:Q_{t,k}(x)\geq Q_{t,k}(x^0)\text{ for every }t,k\}\).

It contains \(x^0\). Every vector in \(P^+\) satisfies (S). Indeed, for each acceptable edge, choose an endpoint whose relevant prefix equals its quota in \(x^0\). For that endpoint,
\(q_t=Q_{t,k}(x^0)\leq Q_{t,k}(x)\leq q_t\),
so the equality persists.

Solve the rational linear program
\(\max\{F(x):x\in P^+\}\),
and obtain a rational optimizer \(x^\star\). The feasible region is closed and bounded, so an optimum exists. Realize \(x^\star\) by the construction in Section 3, producing \(M^\star\).

Condition (S) proves that \(M^\star\) is stable.

Suppose a feasible measurable matching \(N\) were a Pareto improvement of \(M^\star\). Section 1 gives
\(Q_{t,k}(x(N))\geq Q_{t,k}(x^\star)\geq Q_{t,k}(x^0)\)
for every type and prefix. Its aggregate vector lies in \(P\), so \(x(N)\in P^+\). The positive mass of strict improvement also gives
\(F(x(N))>F(x^\star)\),
contradicting optimality. Therefore \(M^\star\) is Pareto efficient.

This argument excludes every feasible measurable Pareto improvement, including ones without a finite description.

6. Complexity and conclusion. The aggregate linear program has \(m\) variables. Since each preference tier contains an incident edge,
\(\sum_tr_t\leq2m\).
It therefore has \(O(m+\tau)\) constraints, with polynomial encoding length. Rational linear programming computes \(x^\star\) in polynomial time.

The stable-allocation computation is polynomial in \(m,\tau,L\) and the capacity encoding length. The realization uses at most
\(2(m+\sum_tc_t)\leq2(m+\tau C)\)
maps and takes polynomial time in the parameters requested in the question.

Thus existence is always affirmative, and computing the requested finite rational description is polynomial-time solvable in \(m,\tau,C,L\).
