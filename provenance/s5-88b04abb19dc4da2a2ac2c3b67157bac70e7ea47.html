The continuous mirror question, as graded

Given a finite binary type set \(T=\{H,L\}\), a finite list of rational population states \(\mu\), and the fair-rule bundles \(x_H^\epsilon(\mu)\) and \(x_L^\epsilon(\mu)\), decide whether per-capita taxes \(p_H(\mu),p_L(\mu)\) exist such that each type prefers its truthful bundle and tax to the other report’s bundle and tax, and each type’s truthful net utility is nonnegative. Equivalently, determine whether, at every listed state, \(v_H(x_H^\epsilon(\mu))+v_L(x_L^\epsilon(\mu))-v_L(x_H^\epsilon(\mu))-v_H(x_L^\epsilon(\mu))\geq 0\).

Result

The supplied-bundle population tax-feasibility problem is in \(\mathrm P\). Feasibility holds exactly when, at every listed state \(\mu\),

\(v_H(x_H^\epsilon(\mu))+v_L(x_L^\epsilon(\mu))-v_H(x_L^\epsilon(\mu))-v_L(x_H^\epsilon(\mu))\geq 0.\)

This condition can be checked directly from the four supplied values. The proof below also constructs feasible rational taxes.

Feasibility at one state

Fix a listed state and abbreviate its supplied values by

\(a=v_H(x_H^\epsilon(\mu)),\quad b=v_H(x_L^\epsilon(\mu)),\quad c=v_L(x_H^\epsilon(\mu)),\quad d=v_L(x_L^\epsilon(\mu)).\)

Write \(p_H=p_H(\mu)\) and \(p_L=p_L(\mu)\). Because a unilateral report leaves \(\mu\) fixed, the two nontrivial incentive constraints are precisely

\(a-p_H\geq b-p_L,\qquad d-p_L\geq c-p_H.\)

Rearranging gives

\(c-d\leq p_H-p_L\leq a-b.\)

Thus incentive compatibility requires \(c-d\leq a-b\), equivalently \(a+d-b-c\geq0\). This proves necessity, even before imposing individual rationality.

Conversely, suppose \(a+d-b-c\geq0\). Define

\(q=\min\{b,d\},\qquad p_L=q,\qquad p_H=q+a-b.\)

We verify every constraint.

  • Type \(H\) incentive compatibility: truthful utility is \(a-p_H=b-q\), which equals deviation utility \(b-p_L=b-q\).
  • Type \(L\) incentive compatibility: truthful utility minus deviation utility is

\((d-p_L)-(c-p_H)=a+d-b-c\geq0\).

  • Type \(H\) individual rationality: \(a-p_H=b-q\geq0\), since \(q\leq b\).
  • Type \(L\) individual rationality: \(d-p_L=d-q\geq0\), since \(q\leq d\).

Constraints comparing a report with itself hold identically. Negative values cause no difficulty: the constructed taxes may be negative, as permitted. Equality in the cross-valuation condition is also allowed because truthful reports may tie with deviations.

Consequently, the stated inequality is both necessary and sufficient at one state.

Combining the listed states

Apply the preceding construction separately at each of the \(k\) states. This is valid because taxes have no constraints linking different states, and unilateral deviations do not change the state.

If any state violates the inequality, its two incentive constraints are inconsistent, so the whole instance is infeasible. If every state satisfies it, the constructed taxes satisfy all required constraints at every state.

The positive population masses introduce no additional condition: feasibility is defined by the individual inequalities, and there is no aggregate budget constraint.

Algorithm and bit complexity

The algorithm reads the input and checks the sign of \(a+d-b-c\) at each state, accepting exactly when all signs are nonnegative.

For the stipulated support size \(\tau=2\), this uses a constant number of exact rational operations per state, hence \(O(k)=O(k\tau^2)\) rational operations. Reading the supplied bundles involves \(k\tau m\) coordinates; all reading costs are included in \(O(L)\).

For an explicit bit bound, let \(B_j\) be the total encoding length of the four values at state \(j\). Represent each value as a signed integer numerator divided by a positive integer denominator. A common denominator obtained by multiplying the four denominators has \(O(B_j)\) bits. Computing the numerator of \(a+d-b-c\) requires only a constant number of additions and multiplications on \(O(B_j)\)-bit integers. Schoolbook arithmetic therefore checks its sign in \(O(B_j^2)\) bit operations.

Since \(\sum_{j=1}^{k}B_j\leq L\), the total running time is

\(O\!\left(L+\sum_{j=1}^{k}B_j^2\right)\subseteq O(L^2).\)

This bound holds for every \(m\geq1\) and \(k\geq1\), with \(\tau=2\). It includes reading the explicitly supplied data; valuation evaluation and allocation computation are outside the problem. The tax construction likewise uses polynomial time and yields rational taxes with polynomial encoding length.

Relation to the cited result

The same cross-valuation inequality appears in the finite-agent setting in Theorem III.1 of [Sinha and Anastasopoulos, *Mechanism Design for Fair Allocation*](https://arxiv.org/html/1504.05670v5#ThmtheoremIII.1). Here its necessity and sufficiency follow directly from the population constraints, without transferring a finite-agent theorem.

Thus the requested classification is polynomial-time solvable. Under polynomial-time many-one reductions, an \(\mathrm{NP}\)-hardness result for this problem would imply \(\mathrm P=\mathrm{NP}\).
