The continuous mirror question, as graded

Given a finite set of agent types \(T\), rational masses \(\mu_t>0\) summing to \(1\), role-based MC-net schemas with rational coefficients, a supplied maximum surplus \(p_{\max}\), and tolerance \(b\ge 0\), compute per-unit payoffs \(a_t\) with \(\sum_{t\in T}\mu_t a_t=p_{\max}\) such that \(\sup_{0\le q\le\mu,\,q\ne 0}\bigl(v_\mu(q)-\sum_{t\in T}q_ta_t\bigr)\le\epsilon^*+b\). Here \(q_t\) is coalition mass of type \(t\), \(v_\mu(q)=\sum_r\lambda_r\prod_{t\in P_r}q_t\prod_{t\in N_r}(\mu_t-q_t)\), and \(\epsilon^*\) is the minimum possible supremum over such payoff vectors. Determine the complexity as a function of the number of supported types, rule encoding size, and input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types.
There are \(m\) explicitly encoded rules \((P_r,N_r,\lambda_r)\), with \(P_r,N_r\subseteq T\), \(P_r\cap N_r=\varnothing\), and signed nonzero rational coefficients \(\lambda_r\). Define \(v_\mu(q)=\sum_{r=1}^{m}\lambda_r\prod_{t\in P_r}q_t\prod_{t\in N_r}(\mu_t-q_t)\), with empty products equal to \(1\), and require \(v_\mu(0)=0\).
The supplied rational \(p_{\max}\) is promised to equal \(\sup\{\sum_{j=1}^{k}v_\mu(q^{(j)}):k\ge1,\ q^{(j)}\ge0,\ q^{(j)}\ne0,\ \sum_jq^{(j)}=\mu\}\).
Payoffs \(a_t\) may have either sign. Set \(E(a)=\sup_{0\le q\le\mu,\ q\ne0,\ q\ne\mu}(v_\mu(q)-\sum_tq_ta_t)\) and \(\epsilon^*=\min\{E(a):a\in\mathbb R^\tau,\ \sum_t\mu_ta_t=p_{\max}\}\).
Given a binary rational tolerance \(b\ge0\), compute rational payoffs satisfying \(\sum_t\mu_ta_t=p_{\max}\) and \(E(a)\le\epsilon^*+b\). Let \(S\) be the rule encoding size and \(L\) the total input bit length.

Is this additive approximation problem solvable in polynomial time in \(m,\tau,S,L\), including the encoding length of \(b\), or is it NP-hard?

For finite MC-net games, a constraint generation algorithm guarantees the same additive bound and terminates finitely; no polynomial running time is asserted. [Source](https://da.lib.kobe-u.ac.jp/da/kernel/0100477917/0100477917.pdf)
No result settling this exact distributional formulation was located in the literature search.

Modeling choices made when packaging the task

  • Required disjoint positive and negative type sets, signed nonzero rational rule coefficients, empty products equal to one, and zero value for the empty coalition.
  • Allowed signed payoffs, as in the discrete optimization, and specified rational output payoffs and a binary rational tolerance, retaining zero tolerance.
  • Excluded the grand coalition from the excess constraints to match the discrete definition and pricing domain.
  • Defined continuous coalition structures as arbitrary finite decompositions of the total mass and interpreted supplied maximum surplus as their supremal total value, promised rational; a supremum accommodates possible nonattainment.
  • Used m for the number of rules, S for their encoding size, and L for the total input bit length.

Result

The problem is NP-hard, even when the tolerance is fixed at \(b=1/32\), all masses are uniform dyadic rationals, every rule coefficient is positive, and each rule mentions at most five types.

The reduction below supplies a provably correct \(p_{\max}\) without computing any hard optimization value. Moreover, every payoff vector satisfying the requested approximation guarantee reveals the maximum-cut value of the source graph.

1. Two reductions from continuous coalitions to whole types

For \(A\subseteq T\), define \(q^A_t=\mu_t\) when \(t\in A\), and \(q^A_t=0\) otherwise. Write

\(\displaystyle w(A)=v_\mu(q^A),\qquad x_t=\mu_t a_t,\qquad x(A)=\sum_{t\in A}x_t.\)

Thus the payoff budget becomes \(x(T)=p_{\max}\).

Lemma 1: Excess is maximized at a whole-type coalition

For every payoff vector,

\(\displaystyle E(a)=\max_{A\subseteq T}\bigl(w(A)-x(A)\bigr).\)

Proof. Because \(P_r\cap N_r=\varnothing\), each rule, and hence \(v_\mu(q)-\sum_tq_ta_t\), is affine in each coordinate separately. Holding the other coordinates fixed, replacing one coordinate by either \(0\) or \(\mu_t\) cannot decrease its value if the better endpoint is chosen. Repeating this for every coordinate proves that the maximum over the closed box occurs at a vertex \(q^A\).

The box with \(0\) and \(\mu\) removed is dense in the closed box, since every mass is positive and \(\tau\ge1\). Continuity therefore makes its supremum equal to that closed-box maximum. \(\square\)

Lemma 2: Splitting types cannot improve the partition optimum

The promised partition optimum satisfies

\(\displaystyle p_{\max}=\max_{\mathcal P\text{ a partition of }T}\sum_{A\in\mathcal P}w(A).\)

Proof. Consider any feasible finite collection \(q^{(1)},\ldots,q^{(k)}\). Independently for each type \(t\), assign the entire type to a random label \(J_t\in\{1,\ldots,k\}\), with

\(\displaystyle \Pr(J_t=j)=q^{(j)}_t/\mu_t.\)

These are valid probabilities because \(\sum_jq^{(j)}_t=\mu_t\). Let \(A_j=\{t:J_t=j\}\).

For each rule, independence across types and disjointness of its positive and negative sets give

\(\displaystyle \mathbb E\!\left[\prod_{t\in P_r}q^{A_j}_t \prod_{t\in N_r}(\mu_t-q^{A_j}_t)\right] = \prod_{t\in P_r}q^{(j)}_t \prod_{t\in N_r}(\mu_t-q^{(j)}_t). \)

Consequently,

\(\displaystyle \sum_jv_\mu(q^{(j)})=\mathbb E\!\left[\sum_jw(A_j)\right]. \)

After empty sets are removed, every realization is a partition of \(T\). Removing them preserves the value because \(w(\varnothing)=v_\mu(0)=0\). Thus every feasible split collection has value at most the maximum whole-type partition value. Conversely, every whole-type partition is feasible in the original problem. \(\square\)

2. A polynomial-size construction with known \(p_{\max}\)

We reduce from unweighted MAX-CUT: given a simple undirected graph and an integer threshold, decide whether some cut meets that threshold. This problem is NP-complete. [Garey, Johnson and Stockmeyer, *Some simplified NP-complete graph problems*](https://doi.org/10.1016/0304-3975%2876%2990059-1).

Let the source graph have \(n\) vertices and \(h\ge1\) edges. Restricting to graphs with an edge retains hardness, since edgeless instances are decidable immediately.

Add isolated vertices until the resulting vertex set \(V\) satisfies

\(\displaystyle \tau=|V|+3=2^{\lceil\log_2(n+3)\rceil}.\)

Padding does not change any cut value. Write \(F\) for the edge set and define

\(\displaystyle c(U)=|\{\{i,j\}\in F:|\{i,j\}\cap U|=1\}|,\qquad M=\max_{U\subseteq V}c(U).\)

In particular, \(c(U)=c(V\setminus U)\) and \(0\le M\le h\).

Introduce three additional supported types \(\alpha,\beta,\gamma\), and set

\(\displaystyle T=V\cup\{\alpha,\beta,\gamma\},\qquad \mu_t=1/\tau\quad(t\in T).\)

Use the following rules, displayed as triples \((P_r,N_r,\lambda_r)\):

  • \((\{\alpha,\beta\},\{\gamma\},h\tau^3)\);
  • \((\{\alpha,\gamma\},\{\beta\},h\tau^3)\);
  • \((\{\alpha,\beta,\gamma\},\varnothing,h\tau^3)\);
  • for each \(\{i,j\}\in F\), \((\{\beta,\gamma,i\},\{\alpha,j\},\tau^5)\);
  • for each \(\{i,j\}\in F\), \((\{\beta,\gamma,j\},\{\alpha,i\},\tau^5)\).

There are \(m=3+2h\) rules. Their coefficients are positive integers, their positive and negative sets are disjoint, and every positive set is nonempty. Hence \(v_\mu(0)=0\).

At a whole-type coalition, every satisfied rule contributes its coefficient times the corresponding power of \(1/\tau\). Therefore:

  • If \(\alpha\in A\) and \(A\cap\{\beta,\gamma\}\ne\varnothing\), then \(w(A)=h\).
  • If \(\alpha\notin A\) and \(\{\beta,\gamma\}\subseteq A\), then \(w(A)=c(A\cap V)\).
  • Otherwise, \(w(A)=0\).

Every positive-value coalition contains at least two of the three additional types. A partition can therefore contain at most one positive-value coalition. Every coalition has value at most \(h\), and the grand coalition has value \(h\).

By Lemma 2, the supplied value

\(\displaystyle p_{\max}=h\)

is exactly correct. The construction uses no knowledge of \(M\).

3. Exact least-core value of the constructed instance

We prove

\(\displaystyle \epsilon^*=M/3.\)

Let \(x_t=\mu_ta_t\) be arbitrary signed payoffs satisfying \(x(T)=h\), and put \(e=E(a)\). Define

\(\displaystyle R_+=\sum_{i\in V}\max(x_i,0),\qquad R_-=\sum_{i\in V}\max(-x_i,0),\qquad s=x(V)=R_+-R_-. \)

Lower bound

Let \(U_-=\{i\in V:x_i<0\}\). The coalition \(\{\alpha,\beta\}\cup U_-\) has value \(h\), so Lemma 1 and the budget give

\(\displaystyle e\ge h-x_\alpha-x_\beta+R_- =x_\gamma+s+R_- =x_\gamma+R_+. \)

Likewise, using \(\{\alpha,\gamma\}\cup U_-\),

\(\displaystyle e\ge x_\beta+R_+.\)

Choose a maximum cut \(U^*\subseteq V\). Both \(\{\beta,\gamma\}\cup U^*\) and \(\{\beta,\gamma\}\cup(V\setminus U^*)\) have value \(M\). Since \(e\) bounds both excesses, it bounds their average:

\(\displaystyle e\ge M-x_\beta-x_\gamma-s/2.\)

Adding these three inequalities yields

\(\displaystyle 3e\ge M+2R_+-s/2 =M+\frac32R_++\frac12R_-. \)

Thus every feasible payoff vector satisfies

\(\displaystyle e\ge \frac M3+\frac{R_+}{2}+\frac{R_-}{6}\ge\frac M3.\)

This bound allows all payoffs to have either sign.

Achievability

Set

\(\displaystyle x_i=0\ (i\in V),\qquad x_\beta=x_\gamma=M/3,\qquad x_\alpha=h-2M/3. \)

These payoffs sum to \(h\) and are nonnegative because \(M\le h\). Check every coalition category:

  • A value-\(h\) coalition containing exactly two additional types has excess \(M/3\); one containing all three has excess \(0\).
  • A coalition containing \(\beta,\gamma\) but not \(\alpha\) has excess \(c(A\cap V)-2M/3\le M/3\).
  • A zero-value coalition has nonpositive excess because all payoffs are nonnegative.

Lemma 1 therefore gives \(E(a)\le M/3\), where \(a_t=x_t/\mu_t\). Combined with the lower bound, this proves \(\epsilon^*=M/3\).

4. Every sufficiently accurate output reveals \(M\)

Suppose the algorithm returns any rational payoff vector with the exact budget and

\(\displaystyle e=E(a)\le M/3+b.\)

The lower bound just proved implies

\(\displaystyle \frac32R_++\frac12R_-\le3b,\)

and hence \(R_+\le2b\) and \(s\le2b\).

The two constant-value coalition inequalities give

\(\displaystyle x_\beta\le M/3+b,\qquad x_\gamma\le M/3+b.\)

The complementary-cut inequality gives

\(\displaystyle x_\beta+x_\gamma\ge M-e-s/2 \ge 2M/3-2b. \)

Subtracting the upper bound on \(x_\gamma\) yields

\(\displaystyle x_\beta\ge M/3-3b.\)

Consequently,

\(\displaystyle M-9b\le3x_\beta\le M+3b.\)

Choose the fixed dyadic tolerance \(b=1/32\). Then

\(\displaystyle M-\frac9{32}\le3x_\beta\le M+\frac3{32}.\)

Both deviations are strictly less than \(1/2\). Since \(M\) is an integer, it is the unique nearest integer to \(3x_\beta\). From the returned payoff we therefore recover

\(\displaystyle M=\operatorname{round}\!\left(\frac{3a_\beta}{\tau}\right).\)

This decoder works for every output meeting the requested guarantee.

5. Encoding and complexity conclusion

Padding gives \(\tau<2(n+3)\). There are \(3+2h\) rules, each mentioning at most five types. Every coefficient has bit length \(O(\log h+\log\tau)\), every mass is a dyadic rational of polynomial encoding length, and \(p_{\max}=h\) and \(b=1/32\) are directly computable. Thus \(m,\tau,S,L\) are polynomially bounded in the source graph’s encoding length.

A polynomial-time algorithm for the requested payoff problem would, on this construction, return rational payoffs from which exact rational arithmetic and rounding recover \(M\) in polynomial time. Comparing \(M\) with the source threshold would decide MAX-CUT.

Hence the additive approximation problem is NP-hard through a polynomial-time reduction using one call to the payoff algorithm. It is not polynomial-time solvable in the stated input parameters unless \(\mathrm P=\mathrm{NP}\).
