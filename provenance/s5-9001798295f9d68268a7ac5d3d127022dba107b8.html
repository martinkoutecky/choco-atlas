The continuous mirror question, as graded

Given belief types \(i\in[\tau]\) with rational beliefs \(b_i\) and positive rational masses \(\mu_i\) summing to \(1\), consider profiles assigning one opinion \(z_i\in\mathbb{R}\) to each type. Each agent’s neighbor is an other agent whose opinion is closest to that agent’s belief, with ties between types resolved by a fixed priority. Decide whether a type-symmetric pure Nash equilibrium exists and, if so, compute equilibria minimizing and maximizing per-capita social cost \(\sum_i\mu_i\max\{|z_i-b_i|,|z_i-q_i(z)|\}\), where \(q_i(z)\) is the selected neighbor’s opinion.

Packaged proof task (what the prover saw — nothing else)

A society is nonatomic and given by its support: \(\tau\geq 1\) distinct belief types with beliefs \(b_i\in\mathbb{Q}\), positive binary rational masses \(\mu_i\), and \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. Opinions have dimension \(m=1\).
A type-symmetric profile assigns \(z_i\in\mathbb{R}\) to every individual of type \(i\). An input total priority order resolves ties between types.
An individual's neighbor is another individual whose opinion is closest to her belief; individuals of her own type are eligible. Thus \(q_i(z)=z_{j_i}\), where \(j_i\) is the highest-priority minimizer of \(|z_j-b_i|\) over \(j\in\{1,\ldots,\tau\}\), including \(j=i\).
An individual deviation to \(x\in\mathbb{R}\) leaves the population profile and selected neighbor opinion unchanged. Define \(c_i(x;z)=\max\{|x-b_i|,|x-q_i(z)|\}\); a type-symmetric pure Nash equilibrium satisfies \(c_i(z_i;z)\leq c_i(x;z)\) for every \(i\) and every \(x\in\mathbb{R}\).
The per-capita social cost is \(C(z)=\sum_i\mu_i c_i(z_i;z)\).

Is deciding whether such an equilibrium exists, and computing equilibria minimizing and maximizing \(C\) when one exists, solvable in polynomial time, or is any of these tasks NP-hard? State running times in \(m=1\), \(\tau\), and \(L\).

For finite societies with one closest other individual as neighbor and the same maximum-distance cost, equilibrium existence and minimum- and maximum-cost equilibrium computation are polynomial-time solvable ([published result](https://link.springer.com/article/10.1007/s00453-021-00892-x)). No result settling the exact nonatomic problem above was identified in the literature search.

Modeling choices made when packaging the task

  • Interpreted each positive type mass as a nonatomic population; a unilateral deviation changes one individual's opinion, not the opinion of an entire type.
  • Excluding the individual herself does not exclude her type: other individuals of the same positive-mass type remain eligible neighbors, including after a deviation.
  • Represented belief types as distinct support points, with unrestricted signed rational beliefs and unrestricted real opinions.
  • Made the fixed tie priority an input total order on types.
  • Allowed support size one because a nonatomic population of one type still contains other individuals; set the opinion dimension to m=1 and L to the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

All three tasks are polynomial-time solvable for the exact nonatomic model stated. There is exactly one type-symmetric equilibrium:
\[ z_i=b_i \qquad (i=1,\ldots,\tau). \]
Its social cost is zero, so it both minimizes and maximizes equilibrium social cost.

The explicit eligibility of individuals of one’s own type causes this collapse. It is essential to the argument.

Proof of uniqueness

Let \(z\) be an equilibrium. Fix a type \(i\), and write
\[ d_i=|z_i-b_i|,\qquad q_i=q_i(z). \]

Because type \(i\) itself is eligible in the neighbor selection, the selected neighbor satisfies
\[ |q_i-b_i|\leq |z_i-b_i|=d_i. \]
This inequality holds regardless of the priority order.

Consider an individual deviation to
\[ x_i=\frac{b_i+q_i}{2}. \]
By the stipulated nonatomic deviation rule, the selected neighbor opinion remains \(q_i\). Consequently,
\[ c_i(x_i;z) =\max\left\{\left|\frac{q_i-b_i}{2}\right|, \left|\frac{b_i-q_i}{2}\right|\right\} =\frac{|q_i-b_i|}{2} \leq \frac{d_i}{2}. \]
On the other hand, the definition of the current cost gives
\[ c_i(z_i;z)\geq |z_i-b_i|=d_i. \]
The equilibrium condition therefore implies
\[ d_i\leq c_i(z_i;z)\leq c_i(x_i;z)\leq \frac{d_i}{2}. \]
Since \(d_i\) is nonnegative, this forces \(d_i=0\). Thus \(z_i=b_i\). Applying the argument to every type proves that any equilibrium must be the truthful profile.

Existence and social-cost extrema

Set \(z_i=b_i\) for every type. For type \(i\), its own type supplies an eligible opinion at distance zero from \(b_i\). Hence every minimizing neighbor type has opinion \(b_i\), and the priority-selected neighbor satisfies \(q_i(z)=b_i\).

It follows that
\[ c_i(z_i;z)=0, \qquad c_i(x;z)=|x-b_i|\geq 0 \]
for every deviation \(x\). The truthful profile is therefore an equilibrium. This also handles coincident beliefs, if allowed: ties between types do not change the selected opinion.

Uniqueness now gives
\[ \min_{\text{equilibria }z}C(z) = \max_{\text{equilibria }z}C(z) = \sum_{i=1}^{\tau}\mu_i\,0 = 0. \]

Algorithms and running times

For \(m=1\):

  • Existence: always return “yes” on the promised valid inputs. This requires constant time once the input promise is assumed; a full input scan takes \(O(L)\) bit time.
  • Minimum-cost equilibrium: output \(z_i=b_i\) for every type and cost zero.
  • Maximum-cost equilibrium: output the same profile and cost zero.

Both profile computations take \(O(L)\) bit time by scanning the input and copying the rational beliefs, with \(O(\tau)\) coordinate assignments. No sorting, neighbor computation, or rational arithmetic is required.

The finite-society comparison concerns a model in which the neighbor must be another individual, so that an individual’s current opinion need not remain available after deviation. The cited paper explicitly uses other individuals as neighbors. ([Published model](https://link.springer.com/article/10.1007/s00453-021-00892-x)) Here, own-type eligibility and the frozen-neighbor deviation rule yield the decisive inequality proved above.
