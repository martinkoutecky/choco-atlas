The continuous mirror question, as graded

Given finite resident types \(R\) and hospital types \(H\), complete weak-order preferences, rational resident masses \(\rho_r\) summing to \(1\), and hospital-type supplies \(\eta_h\) with integer capacity \(q_h\) per facility, choose assignment masses \(x_{rh}\ge 0\) maximizing \(\sum_{r,h}x_{rh}\). Require \(\sum_h x_{rh}\le \rho_r\), \(\sum_r x_{rh}\le q_h\eta_h\), and zero assignment on unacceptable pairs. For each acceptable pair \((r,h)\), let \(U_{rh}=\rho_r-\sum_{g\succeq_r h}x_{rg}\) and \(V_{rh}=q_h\eta_h-\sum_{s\succeq_h r}x_{sh}\); impose \(U_{rh}V_{rh}=0\), so no positive mass of residents and facility capacity can mutually form a blocking pair. Each individual receives at most one whole placement; \(x_{rh}\) records the mass receiving that placement.

Packaged proof task (what the prover saw — nothing else)

Let \(R\) and \(H\) be finite resident and hospital type sets, with \(m=|H|\). A society is given by its support: the list of the \(\tau=|R|+|H|\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Resident masses satisfy \(\rho_r>0\) and \(\sum_r\rho_r=1\); hospital supplies satisfy \(\eta_h>0\), without normalization, and each facility has capacity \(q_h\in\mathbb Z_{>0}\).
Specify mutually acceptable pairs \(A\subseteq R\times H\) and complete weak orders over each type's acceptable partners. All acceptable placements are strictly preferable to being unmatched; ties remain ties. Populations are atomless, and each resident receives at most one whole placement.
An assignment consists of real masses \(x_{rh}\ge0\), with \(x_{rh}=0\) outside \(A\), \(\sum_hx_{rh}\le\rho_r\), and \(\sum_rx_{rh}\le q_h\eta_h\). Hospital capacity is pooled within each type.
For every \((r,h)\in A\), define \(U_{rh}=\rho_r-\sum_{g\succeq_r h}x_{rg}\) and \(V_{rh}=q_h\eta_h-\sum_{s\succeq_h r}x_{sh}\), summing over acceptable partners. Require \(U_{rh}V_{rh}=0\); this is the stability condition.
Given a binary rational threshold \(K\in[0,1]\), decide whether a stable assignment has \(\sum_{r,h}x_{rh}\ge K\). Let \(L\) be the total input bit length, including preferences, masses, capacities, and threshold; state running times in \(m,\tau,L\).

Is this maximum stable assignment mass decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For discrete hospitals/residents with ties, binary assignment constraints characterize weak stability exactly, and maximum cardinality weakly stable matching is NP-hard ([Kwanashie–Manlove](https://arxiv.org/abs/1308.4064)).
For unit-bounded fractional agents, maximizing the number of fully matched agents under ordinal stability is NP-complete with ties, even in bipartite instances ([Chen–Roy–Sorge](https://www.ijcai.org/proceedings/2021/0013.pdf)); that objective differs from total assigned mass. No result settling the precise rational-mass problem above was located.

Modeling choices made when packaging the task

  • Interpreted complete weak orders as complete over acceptable partners, allowing incomplete acceptability lists as in the discrete definition.
  • Made acceptability mutual and placed every acceptable placement strictly above being unmatched; ties are preserved without tie-breaking.
  • Specified positive binary rational hospital supplies, with no hospital-side normalization, and strictly positive integer capacity per facility.
  • Made the populations atomless and retained the stated pooled hospital-type capacity and aggregate complementarity condition.
  • Defined the support size across both populations, set m to the number of hospital types, and defined L as total input bit length.
  • Expressed maximum assigned mass through its threshold decision problem, with a binary rational threshold between zero and one.

1. Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness already holds when every facility has capacity \(\,q_h=1\,\), all resident masses and hospital supplies equal the same positive dyadic rational, and ties occur only in hospital preferences.

For general inputs, an exact deterministic algorithm runs in

\(\displaystyle (\tau-m+1)^m\operatorname{poly}(L).\)

Thus the problem is polynomial-time solvable for every fixed \(\,m\,\), but a polynomial-time algorithm for unrestricted inputs would imply \(\,\mathrm P=\mathrm{NP}\,\).

The main point is that, with equal unit bounds, fractional ordinal stability permits rounding without decreasing total assigned mass.

2. A stability-preserving decomposition lemma

Let \(\,G=(B\cup C,E)\,\) be a finite bipartite acceptability graph, with complete weak orders over each vertex’s acceptable neighbors. A fractional matching is a vector \(\,y\in\mathbb R_{\geq0}^{E}\,\) satisfying

\(\displaystyle \sum_{v:uv\in E}y_{uv}\leq1\qquad\text{for every vertex }u.\)

For an acceptable pair \(\,uv\,\), define

\(\displaystyle S_u(v)=\sum_{w\succeq_u v}y_{uw}.\)

Suppose that \(\,y\,\) is ordinally stable, meaning that every acceptable pair satisfies

\(\displaystyle S_u(v)=1\quad\text{or}\quad S_v(u)=1.\)

Lemma. Such a \(\,y\,\) is a convex combination of weakly stable integral matchings. Consequently, some weakly stable integral matching \(\,M\,\) satisfies

\(\displaystyle |M|\geq\sum_{e\in E}y_e.\)

Proof. The bipartite matching polytope theorem states that every nonnegative edge vector with incident sums at most one is a convex combination of incidence vectors of matchings. Its hypotheses hold here: the graph is finite and bipartite, and \(\,y\,\) satisfies exactly those inequalities. Hence

\(\displaystyle y=\sum_{i=1}^{t}\lambda_i\mathbf1_{M_i},\qquad \lambda_i>0,\qquad\sum_{i=1}^{t}\lambda_i=1,\)

where every \(\,M_i\,\) is an integral matching using acceptable edges.

Fix an acceptable pair \(\,uv\,\). Suppose first that \(\,S_u(v)=1\,\). Then

\(\displaystyle 1=\sum_{i=1}^{t}\lambda_i \sum_{w\succeq_u v}\mathbf1_{M_i}(uw). \)

Each inner sum is either zero or one, because \(\,M_i\,\) is a matching. A convex combination with strictly positive coefficients equals one only if every inner sum equals one. Thus, in every \(\,M_i\,\), vertex \(\,u\,\) is matched to a partner weakly preferred to \(\,v\,\). Therefore \(\,uv\,\) cannot weakly block any \(\,M_i\,\): weak blocking requires both endpoints to be unmatched or to strictly prefer each other to their assigned partners.

If instead \(\,S_v(u)=1\,\), the same argument applies to \(\,v\,\). Ordinal stability supplies at least one of these alternatives for every acceptable pair. Every \(\,M_i\,\) is therefore weakly stable.

Finally,

\(\displaystyle \sum_{e\in E}y_e=\sum_{i=1}^{t}\lambda_i|M_i| \leq\max_i|M_i|. \)

This proves the lemma. \(\square\)

The stability-preservation statement also appears as Lemma 4.1 of [Chen–Roy–Sorge](https://www.ijcai.org/proceedings/2021/0013.pdf). The proof above explicitly allows ties and establishes the consequence needed for the total-mass objective.

3. Polynomial reduction from maximum stable matching

We use the following known result: given a Stable Marriage instance with Ties and Incomplete lists, deciding whether it has a weakly stable matching of cardinality at least an integer \(\,k\,\) is \(\mathrm{NP}\)-complete. This holds even when ties occur only on one side. See Lemma 2.1 and Theorem 2.2 of [Manlove–Irving–Iwama–Miyazaki–Morita, *Hard Variants of Stable Marriage*](https://www.dcs.gla.ac.uk/~davidm/pubs/TR-1999-43.pdf).

Take such an instance with \(\,n\geq1\,\) resident-side agents and \(\,b\,\) hospital-side agents. We may restrict to thresholds satisfying \(\,0\leq k\leq\min(n,b)\,\), since thresholds outside that range are trivial.

Let

\(\displaystyle D=2^{\lceil\log_2 n\rceil}.\)

Construct the society as follows:

  • Create one resident type for each original resident-side agent, and add \(\,D-n\,\) resident types with no acceptable partners.
  • Give every resident type mass \(\,\rho_r=1/D\,\).
  • Create one hospital type for each original hospital-side agent, with \(\,q_h=1\,\) and \(\,\eta_h=1/D\,\).
  • Preserve all original acceptable pairs and preferences, including ties.
  • Set \(\,K=k/D\,\).

There are exactly \(\,D\,\) supported resident types, so their masses sum to one. Every supported mass and supply is positive and dyadic. Empty acceptability lists are permitted by the stated problem.

The construction has

\(\displaystyle m=b,\qquad \tau=D+b<2n+b.\)

All these types are explicitly listed supported types. If the source input has bit length \(\,L_0\,\), the output length is

\(\displaystyle O\!\left(L_0+(n+b)\log(n+1)\right),\)

so the reduction takes polynomial time.

Forward implication

Let \(\,M\,\) be a weakly stable integral matching in the source instance. Set

\(\displaystyle x_{rh}=\frac1D\mathbf1_M(rh).\)

This is feasible. For an acceptable pair \(\,rh\,\),

\(\displaystyle U_{rh}=\frac1D\left(1-\sum_{g\succeq_r h}\mathbf1_M(rg)\right), \)

and

\(\displaystyle V_{rh}=\frac1D\left(1-\sum_{s\succeq_h r}\mathbf1_M(sh)\right). \)

Each parenthesized expression is either zero or one. Both equal one precisely when both endpoints are unmatched or strictly prefer each other to their assigned partners. That would be a weakly blocking pair. Weak stability therefore implies \(\,U_{rh}V_{rh}=0\,\).

Moreover,

\(\displaystyle \sum_{r,h}x_{rh}=\frac{|M|}{D}.\)

Thus \(\,|M|\geq k\,\) implies a stable assignment of mass at least \(\,K\,\).

Reverse implication

Let \(\,x\,\) be a stable assignment in the constructed society and put \(\,y_{rh}=Dx_{rh}\,\). Its resident and hospital incident sums are at most one. The added resident types have no incident edges and receive zero mass.

The stability equations become

\(\displaystyle \left(1-\sum_{g\succeq_r h}y_{rg}\right) \left(1-\sum_{s\succeq_h r}y_{sh}\right)=0. \)

Both factors are nonnegative, so at least one is zero for every acceptable pair. Hence \(\,y\,\), restricted to the original agents, satisfies the decomposition lemma.

If \(\,\sum_{r,h}x_{rh}\geq K\,\), that lemma gives a weakly stable integral matching \(\,M\,\) with

\(\displaystyle |M|\geq\sum_{r,h}y_{rh} =D\sum_{r,h}x_{rh} \geq DK=k. \)

The source and target instances therefore have the same answer. This proves \(\mathrm{NP}\)-hardness, including the restrictions stated above.

4. Exact cutoff algorithm for general masses

Write \(\,n=|R|=\tau-m\,\) and \(\,c_h=q_h\eta_h\,\). For each hospital \(\,h\,\), number its acceptable resident tie classes from best to worst:

\(\displaystyle 1,\ldots,d_h,\qquad d_h\leq n.\)

Let \(\,a_h(r)\,\) denote the class containing an acceptable resident type \(\,r\,\).

For each hospital, choose a mode \(\,t_h\in\{0,\ldots,d_h\}\,\). For a fixed mode vector, impose the original feasibility constraints and the threshold inequality

\(\displaystyle \sum_{r,h}x_{rh}\geq K,\)

together with the following linear constraints.

Mode \(\,t_h=0\,\):

\(\displaystyle U_{rh}=0\qquad\text{for every acceptable }r.\)

Mode \(\,t_h\geq1\,\):

\(\displaystyle \sum_r x_{rh}=c_h,\qquad x_{rh}=0\ \text{if }a_h(r)>t_h,\qquad U_{rh}=0\ \text{if }a_h(r)<t_h. \)

These are linear programs; every \(\,U_{rh}\,\) is an affine expression.

Every feasible branch gives a stable assignment

In mode zero, every incident pair has \(\,U_{rh}=0\,\).

In a positive mode, all hospital capacity is assigned to classes numbered at most \(\,t_h\,\). If \(\,a_h(r)\geq t_h\,\), all assigned residents are weakly preferred by the hospital to \(\,r\,\), so \(\,V_{rh}=0\,\). If \(\,a_h(r)<t_h\,\), the branch explicitly imposes \(\,U_{rh}=0\,\).

Thus every acceptable pair satisfies the required product equation.

Every stable assignment belongs to a branch

Fix a stable assignment.

If hospital \(\,h\,\) is not full, then for every acceptable \(\,r\,\),

\(\displaystyle V_{rh} =c_h-\sum_{s\succeq_h r}x_{sh} \geq c_h-\sum_sx_{sh}>0. \)

Stability forces \(\,U_{rh}=0\,\) for every such pair, so mode zero applies.

If hospital \(\,h\,\) is full, choose \(\,t_h\,\) to be the worst tie class receiving positive mass. Such a class exists because \(\,c_h>0\,\). No worse class receives mass. For any \(\,r\,\) with \(\,a_h(r)<t_h\,\), the positive mass in class \(\,t_h\,\) is omitted from the hospital prefix sum. Consequently \(\,V_{rh}>0\,\), and stability forces \(\,U_{rh}=0\,\). All constraints of this positive mode hold.

The branches therefore characterize stable assignments exactly.

5. Running time and membership in \(\mathrm{NP}\)

There are at most

\(\displaystyle \prod_{h\in H}(d_h+1) \leq(n+1)^m=(\tau-m+1)^m \)

mode vectors.

Each branch has at most \(\,|A|\leq m(\tau-m)\,\) variables and \(\,O(|A|+\tau)\,\) constraints. Its coefficients and right-hand sides have polynomial encoding length in \(\,L\,\): in particular, multiplying the binary integer \(\,q_h\,\) by the rational \(\,\eta_h\,\) requires only polynomially many bits. Rational linear-program feasibility is decidable in polynomial bit complexity.

Enumerating all branches therefore gives running time

\(\displaystyle \left(\prod_{h\in H}(d_h+1)\right)\operatorname{poly}(L) \leq(\tau-m+1)^m\operatorname{poly}(L). \)

For membership in \(\mathrm{NP}\), a certificate specifies one mode per hospital, using \(\,O(m\log(n+1))\,\) bits. A deterministic polynomial-time verifier constructs that branch and tests its rational linear-program feasibility. Section 4 proves that some certificate is accepted exactly when the original instance admits a stable assignment meeting the threshold.

Together with Section 3, this establishes \(\mathrm{NP}\)-completeness for the precise total-assigned-mass problem.
