The continuous mirror question, as graded

Given rational masses \(\mu_a,\mu_b\) with \(\mu_a+\mu_b=1\), two complete additive valuation types over a finite good catalogue \(G\), and \(\tfrac12\) copies of every good per unit population, compute a polynomial-size mass allocation \(\rho_{t,B}\) over integral bundles \(B\subseteq G\) satisfying \(\sum_B\rho_{t,B}=\mu_t\), \(\sum_{B\ni g}\rho_{t,B}=\mu_t/2\), and \(v_t(B)\ge v_t(B'\setminus\{g\})\) for some \(g\in B'\), for every type \(t\) and supported bundles \(B,B'\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass encoded as a binary rational. Here the types are \(a,b\), with \(\mu_a,\mu_b>0\) and \(\mu_a+\mu_b=1\); \(\tau=2\) is the support size, not the number of possible types.
Let \(G\) be a finite catalogue of \(m\) goods. Each type has a complete additive valuation specified by nonnegative binary rational values for every good; equal values are allowed. Let \(L\) be the total input bit length. Supply is \(\tfrac12\) copies of each good per unit population.
An allocation is a finite list of nonnegative rational masses \(\rho_{t,B}\), where \(B\subseteq G\) is an integral bundle and omitted entries are zero, satisfying \(\sum_{B\subseteq G}\rho_{t,B}=\mu_t\) and \(\sum_{B\ni g}\rho_{t,B}=\mu_t/2\) for every type \(t\) and good \(g\).
Require EF1 across the entire supported allocation: whenever \(\rho_{t,B}>0\) and \(\rho_{s,B'}>0\), including \(s=t\), there exists \(S\subseteq B'\) with \(|S|\leq1\) such that \(v_t(B)\geq v_t(B'\setminus S)\). Thus an empty compared bundle needs no removal.

Is computing such an allocation with total encoding size polynomial in \(m,\tau,L\), or reporting infeasibility, solvable in time polynomial in \(m,\tau,L\), or is this computational problem NP-hard?

For two discrete agents with nonnegative additive valuations, a distribution over EF1 allocations giving each agent each good with marginal probability \(\tfrac12\) can be computed in polynomial time; the resulting mechanism is truthful in expectation. [Bu and Tao](https://arxiv.org/html/2407.13634v3).

Result

The problem is solvable in polynomial time. Every valid instance is feasible, and an allocation with at most four positive entries suffices.

The key is to construct a partition \(G=X\mathbin{\dot\cup}Y\) such that, under each valuation, EF1 holds in both directions between \(X\) and \(Y\). This stronger property also appears in [Bu and Tao, Proposition 3.2](https://arxiv.org/html/2407.13634v3). We give a self-contained construction and proof.

1. Constructing the partition

Assume first that \(m>0\). If \(m\) is odd, introduce a dummy good \(d\) with \(v_a(d)=v_b(d)=0\). Denote the resulting catalogue by \(H\), so that \(|H|=2k\) for some positive integer \(k\). If \(m\) is even, take \(H=G\).

For each type \(t\in\{a,b\}\), sort the goods into an order satisfying

\(v_t(h^t_1)\geq v_t(h^t_2)\geq\cdots\geq v_t(h^t_{2k})\).

Break ties arbitrarily. Form the perfect matching

\(M_t=\bigl\{\{h^t_{2i-1},h^t_{2i}\}:1\leq i\leq k\bigr\}\).

Construct an undirected multigraph on \(H\) containing the edges of both matchings, retaining two parallel edges when a pair belongs to both matchings. Label edges by their originating type.

Each vertex has degree two, with one incident edge of each label. Consequently, every connected component is a cycle, allowing a cycle of length two consisting of parallel edges. Along each cycle the labels alternate: entering a vertex on one label leaves the other label as the only remaining edge. Thus every cycle has even length.

Color the vertices of each cycle alternately with two colors. Let \(X^*\) and \(Y^*\) be the two color classes. Every edge of either matching has one endpoint in each class. Therefore, for either type, each consecutive pair in its sorted order contributes exactly one good to each class.

Finally, set \(X=X^*\cap G\) and \(Y=Y^*\cap G\). These sets partition \(G\).

2. Proof of EF1 in both directions

Fix a type \(t\). Write its consecutive pairs as \(P^t_1,\ldots,P^t_k\), in decreasing value order.

Let \((U,V)\) be either \((X^*,Y^*)\) or \((Y^*,X^*)\). For every index \(i\), let \(u_i\) and \(w_i\) denote the unique goods of \(U\cap P^t_i\) and \(V\cap P^t_i\), respectively.

Every good in pair \(P^t_i\) has value at least that of every good in pair \(P^t_{i+1}\). Hence, for \(1\leq i<k\),

\(v_t(u_i)\geq v_t(w_{i+1})\).

By additivity and nonnegativity,

\(v_t(V\setminus\{w_1\})=\sum_{i=2}^{k}v_t(w_i)\leq\sum_{i=1}^{k-1}v_t(u_i)\leq\sum_{i=1}^{k}v_t(u_i)=v_t(U)\).

For \(k=1\), the first two sums are empty and equal zero, so the same argument applies.

Thus removing the single good \(w_1\) from the compared bundle \(V\) eliminates envy. Since the orientation \((U,V)\) was arbitrary, EF1 holds in both directions. Since \(t\) was arbitrary, it holds under both valuations.

Discarding the dummy preserves these inequalities. More explicitly, replace the removal set \(\{w_1\}\) by \(\{w_1\}\cap G\). Its cardinality is at most one, and removing zero-valued dummy goods changes neither side of the inequality. Consequently, for every \(t\in\{a,b\}\) and both orientations \((U,V)\in\{(X,Y),(Y,X)\}\), there exists \(S\subseteq V\) satisfying

\(|S|\leq1\quad\text{and}\quad v_t(U)\geq v_t(V\setminus S)\).

This also covers an empty compared bundle.

3. Constructing and verifying the allocation

For each type \(t\in\{a,b\}\), output

\(\rho_{t,X}=\mu_t/2,\qquad \rho_{t,Y}=\mu_t/2\),

with all other entries zero. Because \(m>0\), the disjoint bundles \(X\) and \(Y\) are distinct.

The total mass of type \(t\) is \(\mu_t/2+\mu_t/2=\mu_t\). Each good belongs to exactly one of \(X,Y\), so its allocated mass within type \(t\) is exactly \(\mu_t/2\). Summing over types gives total supply usage \((\mu_a+\mu_b)/2=1/2\).

For any two supported entries, their bundles are either equal or are \(X,Y\) in some orientation. Equal bundles satisfy EF1 with no removal. Distinct bundles satisfy EF1 under the receiving type’s valuation by Section 2. This verifies every required comparison, including comparisons within a type.

If \(m=0\), instead output \(\rho_{t,\varnothing}=\mu_t\) for each type. All marginal conditions are vacuous, and every bundle has value zero.

4. Running time and encoding size

The algorithm uses two sorts and a graph with \(O(m)\) vertices and edges. Sorting requires \(O(m\log m)\) exact rational comparisons. Each comparison can be performed by cross-multiplication of binary integers of bit length bounded by \(L\), so the bit running time is polynomial in \(m,\tau,L\). Constructing and coloring the cycles takes \(O(m)\) graph operations.

There are at most four positive allocation entries. Each bundle uses an \(m\)-bit incidence vector, and dividing an input rational mass by two increases its encoding length by at most a constant. The total output encoding size is therefore \(O(m+L)\).

Thus the stated two-type problem always admits a polynomial-size allocation computable in polynomial time.
