The continuous mirror question, as graded

Given \(n\) binary policy choices and a distribution \(\mu\) over the supported three-variable parity-approval types \(t=(i_1,i_2,i_3,b)\), each with binary-rational mass, maximize \(V_\mu(x)=\sum_t\mu_t\,\mathbf{1}[x_{i_1}+x_{i_2}+x_{i_3}=b\pmod 2]\). For each fixed \(\delta>0\), is it NP-hard to find an assignment with \(V_\mu(x)\ge\tfrac12+\delta\) whenever \(\max_x V_\mu(x)\ge1-\delta\)?

Packaged proof task (what the prover saw — nothing else)

There are \(m=n\ge 3\) binary policy choices. A type is \(t=(i_1,i_2,i_3,b)\), where \(1\le i_1<i_2<i_3\le m\) and \(b\in\{0,1\}\); it approves precisely assignments \(x\in\{0,1\}^m\) satisfying \(x_{i_1}+x_{i_2}+x_{i_3}\equiv b\pmod 2\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. State running times in \(m,\tau,L\), with \(\delta\) fixed.
Define \(V_\mu(x)=\sum_t\mu_t\mathbf{1}[x_{i_1}+x_{i_2}+x_{i_3}\equiv b\pmod 2]\) and \(\operatorname{OPT}(\mu)=\max_x V_\mu(x)\). An approximation algorithm must output an assignment; randomized guarantees are interpreted in expectation.
For each fixed \(0<\delta<\tfrac14\), is finding an assignment of value at least \(\tfrac12+\delta\) whenever \(\operatorname{OPT}(\mu)\ge1-\delta\) polynomial-time solvable or NP-hard?
For finite lists of equally weighted equations, this approximation guarantee is NP-hard. Håstad also explicitly establishes the corresponding gap hardness for rational probability-weighted equations, which is exactly the support-and-mass formulation above; consequently this target is already settled ([original source](https://johanhastad.se/optimalinap.pdf)).

  • Set m=n to express the number of policy choices using the required running-time convention.
  • Normalize positive masses to sum to one, as required by a distribution.
  • Use three distinct policy indices, canonically ordered, and binary right-hand sides, matching three-variable parity constraints.
  • Restrict delta to the nondegenerate approximation range 0<delta<1/4, where the requested value is strictly below the promised optimum.
  • Carry over the anchor's convention that randomized approximation guarantees hold in expectation.

Conclusion

For every fixed \(0<\delta<\tfrac14\), the requested approximation task is \(\mathrm{NP}\)-hard. A deterministic polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\). A randomized polynomial-time algorithm with the stated expectation guarantee would imply \(\mathrm{RP}=\mathrm{NP}\).

The weighted gap theorem

We use the following consequence of Håstad’s Theorem 5.4: for every fixed sufficiently small positive dyadic rational \(\eta\), there is a polynomial-time reduction from an \(\mathrm{NP}\)-complete language to rational probability-weighted equations over \(\mathbb F_2\), with exactly three variables per equation, such that:

  • YES: some assignment satisfies equations of total weight at least \(1-\eta\).
  • NO: every assignment satisfies equations of total weight at most \((1+\eta)/2\).

The proof explicitly assigns each equation its verifier-selection probability, establishes these two bounds, and states that the rational weighted instance is produced in polynomial time. See [Håstad, proof of Theorem 5.4, printed pages 27–29](https://johanhastad.se/optimalinap.pdf#page=28).

Choose a fixed dyadic rational \(\eta\) satisfying \(0<\eta<\delta/2\). This choice is possible for every fixed positive \(\delta\).

Conversion to the society representation

Write each equation as \(x_i+x_j+x_k\equiv b\pmod2\), ordering its three distinct indices increasingly. Negated literals, if present, are absorbed into \(b\), because replacing a variable by its negation adds \(1\) modulo \(2\).

For each type \(t\), let \(\mu_t\) be the sum of the weights of all equations defining that type. Retain only positive masses. Since the original weights are probabilities, \(\sum_t\mu_t=1\).

For every assignment \(x\), grouping identical equations preserves the objective exactly:

\(V_\mu(x)=\sum_e w_e\,\mathbf 1[x\text{ satisfies equation }e]\).

Consequently, it also preserves the optimum. Rational addition and grouping require polynomial time in the encoded input length; duplicating equations according to their denominators is unnecessary. Relabel the variables as policy choices, set \(n=m\), and add unused variables if needed to ensure \(m\ge3\).

Thus the resulting support-and-mass instances satisfy:

  • YES: \(\operatorname{OPT}(\mu)\ge1-\eta>1-\delta\).
  • NO: \(\operatorname{OPT}(\mu)\le\tfrac12+\tfrac{\eta}{2}\).

This checks all the representation requirements, including that \(\tau\) counts distinct positive-mass types.

Deterministic hardness

Suppose an algorithm running in \(\operatorname{poly}(m,\tau,L)\) outputs an assignment of value at least \(a=\tfrac12+\delta\) whenever \(\operatorname{OPT}(\mu)\ge1-\delta\).

Apply it to the reduced instance and accept precisely when its output has value greater than the fixed rational threshold \(q=\tfrac12+\eta\).

On YES instances, the promise holds and the output value is at least \(a>q\). On NO instances, every assignment has value at most \(\tfrac12+\tfrac{\eta}{2}<q\). Therefore this procedure decides the original \(\mathrm{NP}\)-complete language in polynomial time.

Exact evaluation is polynomial in the stated parameters. For example, form a common denominator from the binary-encoded denominators. Its bit length is \(O(L)\), so naive integer arithmetic gives a conservative evaluation-and-comparison bound of \(O((m+\tau+L)^3)\) bit operations.

Hence the approximation task is \(\mathrm{NP}\)-hard under polynomial-time reductions.

Randomized guarantees in expectation

Now suppose the algorithm is randomized and guarantees \(\mathbb E[V_\mu(X)]\ge a\) on every promised instance. On a YES instance, put \(Z=V_\mu(X)\) and \(p=\Pr[Z>q]\). Since \(0\le Z\le1\),

\(\mathbb E[Z]\le q(1-p)+p=q+(1-q)p\).

Therefore,

\(p\ge\frac{a-q}{1-q}=\frac{\delta-\eta}{\tfrac12-\eta}>\delta\),

where the last inequality follows from \(\eta<\delta/2\).

Run the algorithm independently \(k=\lceil(\ln2)/\delta\rceil\) times, accepting if any output has value greater than \(q\). On YES instances, the rejection probability is at most \((1-\delta)^k\le e^{-\delta k}\le\tfrac12\). On NO instances, acceptance is impossible, because no assignment exceeds \(q\).

This is a polynomial-time decision algorithm with one-sided error. If one approximation run takes time \(T(m,\tau,L)\), its running time is

\(O_\delta\!\left(T(m,\tau,L)+(m+\tau+L)^3\right)\).

Thus an expectation-guaranteed randomized polynomial-time algorithm would imply \(\mathrm{NP}\subseteq\mathrm{RP}\), and hence \(\mathrm{NP}=\mathrm{RP}\).
