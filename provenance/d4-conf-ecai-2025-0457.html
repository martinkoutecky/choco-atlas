The continuous mirror question, as graded

Given rational resident masses \(\mu_t\) over \(\tau\) complete preference types and rational room supplies \(\rho_q\) over \(\kappa\) room categories, with \(\sum_t\mu_t=1\) and \(\sum_q\rho_q=1/2\), find a feasible mass assignment \(x_{\{t,u\},q}\) with no positive-mass 4PS-blocking exchange. Feasibility requires \(\sum_q(2x_{\{t,t\},q}+\sum_{u\ne t}x_{\{t,u\},q})=\mu_t\) for each type \(t\), and \(\sum_{t\le u}x_{\{t,u\},q}=\rho_q\) for each category \(q\). A blocking exchange is possible if two positive-mass room cohorts \((\{t,u\},q)\) and \((\{v,w\},p)\) contain a \(t\)-resident and a \(v\)-resident whose swap would strictly improve the utilities of both movers and both roommates.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) resident types with positive masses \(\mu_t\), each a binary rational; \(\tau\) is the support size, not the number of possible types. Room categories \(q\in\{1,\ldots,\kappa\}\) have positive binary-rational supplies \(\rho_q\), with \(\sum_t\mu_t=1\) and \(\sum_q\rho_q=1/2\).
Each type has complete, nonnegative binary-rational valuations \(h_t(u)\) for every roommate type and \(v_t(q)\) for every room category; utility is \(h_t(u)+v_t(q)\). Valuations need not be symmetric, and ties are allowed. Two distinct residents of the same type may share a room, using \(h_t(t)\).
An assignment consists of nonnegative rational room-cohort masses \(x_{\{t,u\},q}\), satisfying \(\sum_q(2x_{\{t,t\},q}+\sum_{u\ne t}x_{\{t,u\},q})=\mu_t\) and \(\sum_{t\le u}x_{\{t,u\},q}=\rho_q\).
A positive-mass blocking exchange swaps the \(t\)- and \(v\)-residents in equal positive-mass portions of cohorts \((\{t,u\},q)\) and \((\{v,w\},p)\), replacing them by \((\{v,u\},q)\) and \((\{t,w\},p)\), provided all four inequalities hold: \(h_t(w)+v_t(p)>h_t(u)+v_t(q)\), \(h_v(u)+v_v(q)>h_v(w)+v_v(p)\), \(h_u(v)>h_u(t)\), and \(h_w(t)>h_w(v)\).
Check every choice of mover in each cohort. The exchanged portions occupy distinct rooms; categories and resident types may coincide, and portions taken from the same cohort must be disjoint. An assignment is four-person stable (4PS) when no such exchange exists.

Is finding a feasible 4PS mass assignment solvable in polynomial time, or is it NP-hard? State running times in \(m=\kappa\), \(\tau\), and the total input bit length \(L\).

For discrete instances with \(2n\) residents and \(n\) rooms, CTTCR produces a 4PS assignment in \(O(n^5)\) time; serial dictatorship also produces one in \(O(n^2)\) time. [Leng–Roy](https://arxiv.org/html/2508.14194v1)
No result settling this exact mass-assignment problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted complete preference types as complete nonnegative additive cardinal valuation tables, following the discrete model; used binary-rational valuations for finite computational input.
  • Allowed ties and asymmetric valuations because the anchor imposes neither strict utilities nor symmetry; blocking requires strict improvement for all four residents.
  • Defined diagonal roommate valuations for distinct residents of the same type, since same-type cohorts occur in the graded question.
  • Interpreted cohort masses as room masses and required nonnegative rational assignment entries.
  • Specified that room categories with zero supply are omitted, so listed supplies are positive.
  • Preserved the discrete requirement that a swap involves distinct rooms while allowing their categories to coincide; repeated resident types are allowed, and portions drawn from one cohort must be disjoint.
  • Identified the requested size parameter m with the number of room categories, kappa, and defined L as total input bit length.

Result

Finding a feasible 4PS mass assignment is polynomial-time solvable. A batched serial-dictatorship algorithm uses at most \(\tau+m-1\) iterations and produces an assignment with at most that many positive cohort masses.

With ordinary exact integer arithmetic, a conservative bit-complexity bound is \(O(L+(\tau+m)^2L^2)\) for sparse output, or \(O(L+(\tau+m)^2L^2+m\tau^2)\) for a dense array of all cohort masses.

The construction adapts the serial-dictatorship idea in [Leng–Roy, Section 4.1](https://arxiv.org/html/2508.14194v1#S4.SS1). The batching, stability, and bit-complexity arguments below directly address the stated mass model.

Algorithm

Let \(a_t\) be the unassigned resident mass of type \(t\), and let \(b_q\) be the unused supply of room category \(q\). Initialize \(a_t=\mu_t\), \(b_q=\rho_q\), and every assignment coordinate to zero.

Fix an order of the types. While some resident mass remains:

  • Choose the first type \(d\) with \(a_d>0\).
  • Choose a type \(u\) maximizing \(h_d(u)\) among types with \(a_u>0\). Include \(u=d\) as a candidate.
  • Choose a category \(q\) maximizing \(v_d(q)\) among categories with \(b_q>0\).
  • If \(u\ne d\), set \(\delta=\min\{a_d,a_u,b_q\}\). Increase \(x_{\{d,u\},q}\) by \(\delta\), and decrease each of \(a_d,a_u,b_q\) by \(\delta\).
  • If \(u=d\), set \(\delta=\min\{a_d/2,b_q\}\). Increase \(x_{\{d,d\},q}\) by \(\delta\), decrease \(a_d\) by \(2\delta\), and decrease \(b_q\) by \(\delta\).

Break ties arbitrarily. Call \(d\) the *dictator* of this iteration.

The independent maximizations in steps 2 and 3 are valid because utility is additive. Every available roommate type can be combined with every available category in a sufficiently small positive mass.

Feasibility and termination

Initially, and after every iteration, the following identity holds:

\(\displaystyle \sum_t a_t=2\sum_q b_q.\)

Indeed, allocating room mass \(\delta\) removes exactly \(2\delta\) resident mass, including when both residents have the same type.

Consequently, whenever resident mass remains, some room supply remains. Both maximization steps therefore have candidates. Their selected residual masses are positive, so \(\delta>0\).

The update preserves nonnegativity. It also accounts for resident and room usage exactly: a mixed-type cohort consumes mass \(\delta\) of each type, whereas a same-type cohort consumes mass \(2\delta\) of its type.

Every iteration exhausts at least one previously positive type residual or category residual, by the definition of \(\delta\). An exhausted residual never becomes positive again. There are initially \(\tau+m\) positive residuals, so termination is finite. At termination all resident residuals vanish; the displayed identity and nonnegativity imply that all category residuals vanish as well. Thus the output satisfies every required feasibility equation.

The final iteration exhausts at least one type and at least one category. Every preceding iteration exhausts at least one residual. Therefore the number of iterations is at most \(\tau+m-1\), and the number of positive output coordinates is at most the same quantity.

Proof of four-person stability

Suppose, for contradiction, that two positive output cohorts admit a blocking exchange. Write their oriented descriptions as \((\{t,u\},q)\) and \((\{v,w\},p)\), with \(t\) and \(v\) the movers.

Choose generating iterations for these cohorts. Relabel the two cohorts, if necessary, so that the iteration generating \((\{t,u\},q)\) is no later than the one generating \((\{v,w\},p)\). Let \(d\) be the dictator of the earlier iteration.

At the beginning of that iteration, all four types \(t,u,v,w\) and both categories \(q,p\) have positive residuals:

  • The types and category of the earlier cohort are positive because that cohort is being generated.
  • Those of the later cohort are positive because residuals only decrease, and they are positive when the later cohort is generated.
  • If the generating iterations coincide, both descriptions refer to the single cohort generated in that iteration, whose constituent resources are positive.

The dictator satisfies \(d=t\) or \(d=u\). There are two cases.

Case 1: \(d=t\). The dictator selected roommate type \(u\) and category \(q\). Since type \(w\) and category \(p\) were available, maximality gives \(h_t(u)\ge h_t(w)\) and \(v_t(q)\ge v_t(p)\). Adding these inequalities yields

\(\displaystyle h_t(u)+v_t(q)\ge h_t(w)+v_t(p).\)

This contradicts the strict improvement required for mover \(t\).

Case 2: \(d\ne t\). Then \(d=u\), and the dictator selected roommate type \(t\). Since type \(v\) was available, maximality gives \(h_u(t)\ge h_u(v)\). This contradicts the required strict improvement \(h_u(v)>h_u(t)\) for the nonmoving resident \(u\).

Both cases contradict blocking. Hence the output is 4PS.

This argument covers every mover orientation. It also covers repeated types, equal room categories, and exchanges between disjoint portions of the same cohort. In particular, allowing the dictator’s own type as a roommate candidate is essential to the maximality argument for repeated-type cases.

Exact arithmetic and running time

Put \(K=\tau+m\). Each iteration scans at most \(\tau\) types and \(m\) categories, then performs a constant number of mass updates. The algorithm therefore uses \(O(K^2)\) arithmetic operations and comparisons, apart from input and output handling.

To establish polynomial bit complexity, let \(D\) be the product of the denominators of all input masses and supplies, and use the fixed denominator \(H=2^K D\). Its bit length is \(O(L+K)\).

Represent each residual and allocated mass by its integer numerator over \(H\). Initially every residual numerator is divisible by \(2^K\). Inductively, after \(i\) iterations, every residual numerator is divisible by \(2^{K-i}\): a mixed-type allocation preserves the previous divisibility, and a same-type allocation can reduce it by at most one power of two. Thus every halving required by the algorithm is exact, since fewer than \(K\) iterations occur.

All residual and cohort masses lie between zero and one, so their numerators have \(O(L+K)\) bits. The explicit input includes \(\tau+m\) masses and supplies, hence \(K=O(L)\); all these integers consequently have \(O(L)\) bits.

Constructing the scale and initial numerators costs \(O(KL^2)\) bit operations using schoolbook arithmetic. Each valuation comparison uses cross multiplication of input integers and costs \(O(L^2)\). Mass comparisons and updates also fit this bound. Combining these costs gives \(O(L+K^2L^2)\) bit operations for sparse output. Writing all \(m\tau(\tau+1)/2\) coordinates adds \(O(m\tau^2)\) work.

No expansion into individual residents is needed, and the proof imposes neither symmetry nor strict preferences.
