The continuous mirror question, as graded

Given a finite set of complete utility types \(T\) with rational masses \(\mu_t\), a finite set of good types \(G\), rational per-capita supplies \(q_g\), and utility functions \(u_t\), decide whether there are assignment masses \(x_{t,B}\ge 0\) for integral bundles \(B\subseteq G\) such that \(\sum_{B\subseteq G}x_{t,B}=\mu_t\) for each \(t\), \(\sum_{t\in T,\,B\ni g}x_{t,B}=q_g\) for each \(g\), and every bundle receiving positive mass gives the same utility. The population has unit mass, and all goods are allocated.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) utility types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=|G|\) good types, with binary-rational per-capita supplies \(q_g\in[0,1]\). Each utility function \(u_t:2^G\to\mathbb{Q}_{\ge0}\) is supplied as an explicit table for all bundles; no monotonicity or normalization is assumed. Let \(L\) be the total input bit length.
An individual receives an integral bundle \(B\subseteq G\), possibly empty, containing at most one unit of each good type. A type's mass may be split among different bundles, and all supplies must be allocated.
Perfect equality means that there exist real masses \(x_{t,B}\ge0\) and a single common value \(c\ge0\) such that \(\sum_{B\subseteq G}x_{t,B}=\mu_t\) for every \(t\), \(\sum_{t\in T}\sum_{B\subseteq G:g\in B}x_{t,B}=q_g\) for every \(g\), and \(x_{t,B}>0\Rightarrow u_t(B)=c\). The common value may be zero.

Is deciding whether perfect equality exists solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite societies, perfect equality with all goods allocated is \(\mathrm{NP}\)-hard even for two agents with additive utilities encoded by singleton values ([2017 result](https://www.ifaamas.org/Proceedings/aamas2017/pdfs/p272.pdf)); with an unbounded number of agents it is strongly \(\mathrm{NP}\)-hard even for identical additive utilities ([2022 result](https://link.springer.com/content/pdf/10.1007/s10472-022-09789-z.pdf)).
No result settling this exact continuous problem with the stated encoding was located.

Modeling choices made when packaging the task

  • The utility encoding was unspecified; use explicit tables of binary-rational values for every bundle.
  • Utility signs and normalization were unspecified; retain arbitrary nonnegative utilities, without imposing monotonicity or zero utility for the empty bundle.
  • Supplies are binary rationals in [0,1], the feasible per-capita range when a bundle contains at most one unit of each good type; zero supplies are allowed.
  • Interpret equality as one common utility across all positive-mass type-bundle pairs, including the common value zero.
  • Assignment masses may be nonnegative real numbers, and empty bundles are allowed.

Result. The problem is solvable in polynomial time in \(m,\tau,L\), and indeed in \(L\) alone under the stated explicit-table encoding.

Finite candidate values. For each supported type \(t\), define
\[ V_t=\{u_t(B):B\subseteq G\}, \qquad C=\bigcap_{t\in T}V_t. \]
If perfect equality exists with common value \(c\), then \(c\in C\). To prove this, fix any \(t\in T\). Since
\[ \sum_{B\subseteq G}x_{t,B}=\mu_t>0, \]
at least one bundle \(B\) has \(x_{t,B}>0\). The equality requirement then gives \(u_t(B)=c\), so \(c\in V_t\). This holds for every supported type.

Thus every possible common value occurs in the input tables. In particular, it is rational. Zero is included whenever it belongs to \(C\).

Feasibility for a fixed value. For each \(c\in C\), define
\[ S_t(c)=\{B\subseteq G:u_t(B)=c\}. \]
Consider the following linear feasibility problem, with a real variable \(y_{t,B}\) for each \(t\in T\) and \(B\in S_t(c)\):
\[ y_{t,B}\ge 0, \]
\[ \sum_{B\in S_t(c)}y_{t,B}=\mu_t \qquad(t\in T), \]
\[ \sum_{t\in T}\ \sum_{\substack{B\in S_t(c)\\g\in B}}y_{t,B}=q_g \qquad(g\in G). \]

This system is feasible if and only if perfect equality is possible with common value \(c\).

For the forward implication, extend a feasible solution by setting \(x_{t,B}=0\) whenever \(B\notin S_t(c)\). The displayed equations give the required type masses and allocate every supply exactly. Every positive coordinate corresponds to a bundle with utility \(c\).

Conversely, suppose perfect equality holds with value \(c\). Whenever \(B\notin S_t(c)\), the implication in the definition of perfect equality forces \(x_{t,B}=0\). Restricting \(x\) to the remaining coordinates therefore satisfies the displayed system.

In particular, these constraints preserve the requirement that each individual bundle is integral: the variables split population mass among subsets of \(G\), exactly as permitted in the question.

Algorithm and bit complexity. Compute \(C\), test the displayed system for each \(c\in C\), and accept precisely when at least one test is feasible. The two preceding arguments prove correctness in both directions.

Let \(N=\tau 2^m\), the number of explicitly supplied utility entries. Because each entry requires at least one bit, \(N\le L\). Since \(T\) is nonempty, choosing any \(t_0\in T\) gives
\[ |C|\le |V_{t_0}|\le 2^m\le N. \]
Exact rational comparisons, using cross multiplication of binary integers, compute \(C\) in polynomial time in \(L\).

For each candidate, there are at most \(N\) variables and \(m+\tau\) equality constraints. All matrix coefficients belong to \(\{0,1\}\), and the right-hand sides are the input rationals \(\mu_t,q_g\). Including nonnegativity constraints, the system has encoding length
\[ O\bigl((m+\tau+1)N+L\bigr). \]
This is polynomial in \(L\), since the input also explicitly supplies all masses and supplies.

The polynomial-time rational linear-programming feasibility theorem decides whether such a system has a real solution in time polynomial in its binary encoding length. Equalities can be replaced by pairs of inequalities, so the theorem applies directly, including to feasible sets with empty interior. See [Khachiyan, *A polynomial algorithm in linear programming*](https://www.mathnet.ru/eng/dan42319).

There are at most \(N\le L\) feasibility tests, each of polynomial size. Hence the entire algorithm runs in polynomial time.

Scope of the conclusion. The proof uses both the explicit enumeration of all bundle utilities and the permission to split type masses. It requires neither monotonicity nor normalization, and handles the common value zero. An additive representation by singleton values would not provide the same input-length bound on enumerating bundles; requiring unsplittable agents would not yield the same linear feasibility problem.
