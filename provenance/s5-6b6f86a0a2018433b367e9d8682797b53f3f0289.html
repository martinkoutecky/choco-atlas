Theorem 6.3 — class: other

The continuous mirror question, as graded

Given \(\tau\) types with rational masses \(\mu_t>0\), \(\sum_t\mu_t=1\), rational coefficients \(b_t\ge 0\) with \(B=\sum_t\mu_t b_t>0\), and continuous, surjective, weakly increasing type-specific curves \(g_t:[0,1]\to[0,1]\), define the aggregate by \(F_\mu[x]=B^{-1}\sum_t\mu_t b_t\int_0^1 g_t(x(t,u))\,du\). What are each type’s total \(\varphi\)- and \(\psi\)-importance, defined as the limits of sums of individual indices in finite replications with type fractions tending to \(\mu_t\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Each type has a binary-rational coefficient \(b_t\ge0\), with \(B=\sum_t\mu_tb_t>0\), and a continuous, surjective, weakly increasing curve \(g_t:[0,1]\to[0,1]\).
For measurable states \(x(t,\cdot):[0,1]\to[0,1]\), define \(F_\mu[x]=B^{-1}\sum_t\mu_tb_t\int_0^1g_t(x(t,u))\,du\), using Lebesgue measure within each type. For the computational problem, curves are supplied as rational piecewise-linear graphs; let \(m\) be their total number of pieces and \(L\) the total binary input length.
A finite replication has \(n_t\ge1\) agents of type \(t\), \(n=\sum_tn_t\ge2\), and aggregate \(f_n(z)=(\sum_tn_tb_t)^{-1}\sum_t\sum_{i\text{ of type }t}b_tg_t(z_i)\). Consider every sequence with \(n\to\infty\) and \(n_t/n\to\mu_t\).
For any finite aggregate \(f\), put \(W_f(S,z)=f(z_S,1_{-S})-f(z_S,0_{-S})\), where the notation fixes coordinates in \(S\) to their states and all remaining coordinates to the indicated endpoint. Let \(Z_i\) be independent uniform states on \([0,1]\), and let \(P_i\) be the agents preceding \(i\) in an independent uniform random ordering.
Define \(\varphi_i(f)=\mathbb E[W_f(P_i,Z)-W_f(P_i\cup\{i\},Z)]\), \(\widetilde\psi_i(f)=\mathbb E[f(Z_{-i},1_i)-f(Z_{-i},0_i)]\), and \(\psi_i(f)=\widetilde\psi_i(f)/\sum_j\widetilde\psi_j(f)\).
The requested type totals are \(\Phi_t=\lim_{n\to\infty}\sum_{i\text{ of type }t}\varphi_i(f_n)\) and \(\Psi_t=\lim_{n\to\infty}\sum_{i\text{ of type }t}\psi_i(f_n)\).

Do these limits exist independently of the replication sequence for every admissible collection of curves? For rational piecewise-linear inputs, can all type totals be computed exactly in time polynomial in \(m,\tau,L\), or is their exact computation NP-hard?

Known finite result: for \(f(z)=\sum_iw_ih_i(z_i)\), nonnegative weights summing to one and continuous, surjective, weakly increasing curves, both individual indices equal \(w_i\). [Source](https://arxiv.org/pdf/1803.04138v2).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every admissible collection of curves, the limits exist independently of the replication sequence, and

\(\displaystyle \Phi_t=\Psi_t=\frac{\mu_t b_t}{B}\quad\text{for every type }t.\)

All these totals can be computed exactly in time polynomial in \(m,\tau,L\). In fact, their values do not depend on the curves. The proof below follows directly from the index definitions.

1. Endpoint values and finite indices

A weakly increasing, surjective curve \(g_t:[0,1]\to[0,1]\) satisfies \(g_t(0)=0\) and \(g_t(1)=1\): its minimum and maximum occur at the endpoints, and surjectivity requires these extrema to be \(0\) and \(1\).

Fix a finite replication, and write \(t(i)\) for agent \(i\)'s type. Define

\(\displaystyle C_n=\sum_{t=1}^{\tau}n_tb_t,\qquad w_i=\frac{b_{t(i)}}{C_n}.\)

Because \(B>0\), some coefficient \(b_t\) is positive. Since every \(n_t\ge1\), we have \(C_n>0\). Thus the weights are well defined, nonnegative, and satisfy \(\sum_iw_i=1\). The aggregate is

\(\displaystyle f_n(z)=\sum_iw_i g_{t(i)}(z_i).\)

For every set of agents \(S\) and every state vector \(z\), the terms indexed by \(S\) cancel in the defining difference for \(W_{f_n}\). Consequently,

\(\displaystyle W_{f_n}(S,z)=\sum_{j\notin S}w_j\bigl(g_{t(j)}(1)-g_{t(j)}(0)\bigr)=\sum_{j\notin S}w_j.\)

If \(i\notin S\), this gives

\(\displaystyle W_{f_n}(S,z)-W_{f_n}(S\cup\{i\},z)=w_i.\)

The predecessor set \(P_i\) always excludes \(i\). Hence the random variable defining \(\varphi_i(f_n)\) is identically \(w_i\), and

\(\displaystyle \varphi_i(f_n)=w_i.\)

Likewise, additivity and the endpoint values imply, for every choice of the other agents’ states,

\(\displaystyle f_n(z_{-i},1_i)-f_n(z_{-i},0_i)=w_i.\)

Therefore \(\widetilde\psi_i(f_n)=w_i\). Its normalization denominator equals \(\sum_jw_j=1\), so

\(\displaystyle \psi_i(f_n)=w_i.\)

These identities also cover agents with \(b_{t(i)}=0\).

2. Replication limits

Summing either finite index over type \(t\) yields

\(\displaystyle \sum_{i:\,t(i)=t}\varphi_i(f_n)=\sum_{i:\,t(i)=t}\psi_i(f_n)=\frac{n_tb_t}{\sum_s n_sb_s}.\)

Now consider any replication sequence from the question and put \(p_{t,n}=n_t/n\). By assumption, \(p_{t,n}\to\mu_t\) for each type. Since the support is finite,

\(\displaystyle \sum_s p_{s,n}b_s\longrightarrow\sum_s\mu_sb_s=B>0.\)

In particular, this denominator is eventually at least \(B/2\). The numerator \(p_{t,n}b_t\) converges to \(\mu_tb_t\); division by the convergent positive denominator therefore gives

\(\displaystyle \frac{n_tb_t}{\sum_s n_sb_s}=\frac{p_{t,n}b_t}{\sum_s p_{s,n}b_s}\longrightarrow\frac{\mu_tb_t}{B}.\)

This proves existence and sequence independence of both limits. It also shows that their type totals are nonnegative and sum to one.

3. Exact computation and bit complexity

Write the input rationals as

\(\displaystyle \mu_t=\frac{a_t}{q_t},\qquad b_t=\frac{c_t}{s_t},\)

where \(a_t,q_t,s_t\) are positive integers and \(c_t\) is a nonnegative integer. Define the integers

\(\displaystyle D=\prod_{t=1}^{\tau}q_ts_t,\qquad A_t=a_tc_t\frac{D}{q_ts_t},\qquad A=\sum_{t=1}^{\tau}A_t.\)

Each displayed division is exact because \(q_ts_t\) divides \(D\). Moreover,

\(\displaystyle \mu_tb_t=\frac{A_t}{D},\qquad B=\frac{A}{D}.\)

Since \(B>0\), we have \(A>0\). Thus the algorithm outputs, for every type,

\(\displaystyle \Phi_t=\Psi_t=\frac{A_t}{A}.\)

To verify polynomial complexity, the sum of the binary lengths of all input numerators and denominators is at most \(L\). Consequently, \(D\) has \(O(L)\) bits. Each \(A_t\) also has \(O(L)\) bits, because it is bounded above by \(a_tc_tD\). Summing \(\tau\) such integers gives \(A\) at most \(O(L+\log\tau)\) bits.

The algorithm uses \(O(\tau)\) integer multiplications, exact divisions, and additions on integers of these polynomially bounded lengths. Standard integer arithmetic therefore computes every output in polynomial time. If reduced fractions are required, computing \(\gcd(A_t,A)\) and reducing each fraction also takes polynomial time. The total output length is polynomially bounded.

The curve graphs need only be read as part of the input; their pieces do not enter the calculation. Thus the requested exact computation is polynomial-time solvable in \(m,\tau,L\).
