The continuous mirror question, as graded

Given a finite tree \(T\), a candidate set \(C\) with subtrees of \(T\), a committee size \(k\), and a finite support of voter types \(t\) with positive rational masses \(\mu_t\) summing to \(1\), each represented by a voter subtree that induces its approval set \(B_t \subseteq C\), is there a committee \(W \subseteq C\) with \(|W|=k\) such that \(\sum_t \mu_t \mathbf{1}[B_t \cap W \ne \varnothing] \ge q\), for a given rational threshold \(q\)? Consider both restrictions from Theorem 5: candidate subtrees are singletons, or voter-type subtrees are singletons; for Corollary 1, additionally require a singleton candidate at every tree vertex.

Classification

All three restrictions yield an \(\mathrm{NP}\)-complete problem, and hence an \(\mathrm{NP}\)-hard problem. Normalizing voter multiplicities into rational masses preserves the discrete decision problem exactly.

Let \(n=|V(T)|\). Rational arithmetic below is exact; numerators and positive denominators are encoded in binary.

1. Polynomial verification

Write
\[ \mu_t=\frac{a_t}{b_t}\quad(t=1,\ldots,\tau), \qquad q=\frac{a_0}{b_0}. \]
Define the common denominator and integer weights by
\[ D=\prod_{t=0}^{\tau}b_t, \qquad w_t=a_t(D/b_t), \qquad Q=a_0(D/b_0). \]
The bit length of \(D\) is at most \(1+\sum_{t=0}^{\tau}\log_2 b_t\), hence is \(O(L)\). Because \(\mu_t,q\in[0,1]\), every \(w_t\) and \(Q\) also has \(O(L)\) bits. Schoolbook integer arithmetic computes these quantities in \(O((\tau+1)L^2)\) bit operations.

Precompute the approval matrix
\[ A_{t,c}=\mathbf 1[R_t\cap S_c\neq\varnothing]. \]
Using vertex membership vectors, a conservative bound for this preprocessing, including reading and organizing the input, is
\[ O\bigl(m\tau nL+L^2\bigr) \]
bit operations.

A certificate is an \(m\)-bit vector specifying \(W\). Check that it contains exactly \(k\) selected candidates, then compute
\[ H(W)=\sum_{t=1}^{\tau}w_t \mathbf 1[\text{some selected }c\text{ has }A_{t,c}=1]. \]
Scanning the approval matrix and adding the relevant integer weights takes \(O(m\tau L)\) bit operations. Finally,
\[ \sum_t\mu_t\mathbf 1[B_t\cap W\neq\varnothing]\geq q \quad\Longleftrightarrow\quad H(W)\geq Q, \]
since \(D>0\).

Thus a committee can be verified in total time
\[ O\bigl(m\tau nL+(\tau+1)L^2\bigr). \]
This argument applies to all three restrictions, proving membership in \(\mathrm{NP}\).

2. Normalization preserves discrete instances

Consider a finite-voter instance with \(N\geq1\) explicitly listed voters, committee size \(k\), and integer target \(h\), where \(0\leq h\leq N\). Retain its tree, candidates, candidate subtrees, and committee size.

Group voters having the same approval set. For each resulting type \(t\), let \(N_t\) be its number of voters and retain the subtree of one representative voter as \(R_t\). Set
\[ \mu_t=\frac{N_t}{N}, \qquad q=\frac{h}{N}. \]
Each mass is positive, and \(\sum_t\mu_t=1\). The representative subtree induces the required approval set by the definition of the grouping.

For every committee \(W\),
\[ \sum_t\mu_t\mathbf 1[B_t\cap W\neq\varnothing] = \frac{1}{N} \sum_{i=1}^{N}\mathbf 1[\text{voter }i\text{ approves some member of }W]. \]
Consequently, the normalized instance meets threshold \(q\) if and only if the original committee represents at least \(h\) voters. Committee size remains exactly \(k\), and candidate identities are retained even when their subtrees coincide.

This transformation is polynomial. Indeed, if the discrete input has length \(H\), explicit listing implies \(N\leq H\). Approval sets and their equality can be computed in polynomial time. There are at most \(N\) resulting types, each numerator and denominator uses \(O(\log(N+1))\) bits, and retaining representative subtrees cannot enlarge the original geometric data. The output length is therefore
\[ O\bigl(H+N\log(N+1)\bigr). \]
In particular, this reduction never expands binary rational masses into voter copies.
