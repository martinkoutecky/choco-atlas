The continuous mirror question, as graded

Given a finite candidate set \(C\), target \(c\in C\), and binary-rational distribution \(\mu\) over a finite support of complete voter rankings, with strict pairwise majorities, let \(R_\mu^M\) be the induced majority relation. Is there a narcissistic candidate preference profile, an agenda, and a candidate entry-equilibrium strategy profile such that voters use the paper's sophisticated VSE refinement of \(R_\mu^M\) and the resulting outcome is \(c\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set, \(m=|C|\), and \(c\in C\). A society is given by its support: the list of \(\tau\) distinct strict complete voter rankings with positive binary-rational masses \(\mu_1,\ldots,\mu_\tau\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
Define \(aR_\mu^M b\) when the mass ranking \(a\) above \(b\) exceeds \(1/2\); assume no pairwise majority ties. Candidates are separate from the voter society, and all preferences are common knowledge.
An agenda \(\sigma\) is a permutation of \(C\), restricted to the running set \(B\). Voting by successive elimination first contests the first two running candidates, then contests the survivor against the next candidate, continuing to a final survivor.
Sophisticated voting is defined by backward induction at every contest: each voter type votes for the branch whose eventual winning candidate it strictly prefers, and the branch supported by a majority of mass is selected. If both branches yield the same candidate, their choice is immaterial. Let \(w_\sigma(B)\) be this outcome; a singleton wins automatically, and \(w_\sigma(\varnothing)=\bot\).
Each candidate \(a\) has a strict complete preference order \(\succ_a\) on \(C\cup\{\bot\}\), with \(a\) ranked first (narcissism); write \(\succeq_a\) for its weak extension. Candidate strategies are pure run/withdraw choices. A nonempty running set \(B\) is an entry equilibrium precisely when \(w_\sigma(B)\succeq_a w_\sigma(B\triangle\{a\})\) for every \(a\in C\), using sophisticated voting also after each deviation and keeping the agenda fixed.

Is deciding whether there exist narcissistic candidate preferences, an agenda \(\sigma\), and an entry-equilibrium running set \(B\) with \(w_\sigma(B)=c\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For an explicitly listed finite electorate of odd size, this existential outcome-membership problem is \(\mathrm{NP}\)-complete. [Brill and Conitzer, Strategic Voting and Strategic Candidacy](https://www.cs.cmu.edu/~conitzer/candidacyAAAI15.pdf). No result settling the exact rational-mass formulation was identified in the searches.

Modeling choices made when packaging the task

  • Made distribution normalization explicit: support masses are positive binary rationals summing to one, and voter rankings are strict and complete.
  • Defined sophisticated voting directly through backward induction with majority mass at every contest, including all continuation games after candidate deviations; branches with identical terminal outcomes need no tie-breaking.
  • Specified pure candidate entry strategies, unilateral deviations by both running and withdrawn candidates, and one fixed agenda restricted to each resulting running set.
  • Included singleton and empty-election outcomes. Candidate preferences extend to the empty outcome with each candidate ranked first; the position of the empty outcome relative to other candidates is unrestricted, matching the requirement that each candidate prefers itself to an empty election.
  • Explicitly separated candidates from the voter society and retained complete information and the absence of any single-peakedness restriction.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is \(\mathrm{NP}\)-complete, even when every mass is a positive dyadic rational. Thus it is \(\mathrm{NP}\)-hard; a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The proof preserves the majority tournament of an explicitly listed odd electorate. It does not expand a rational-mass society into individual voters.

1. Sophisticated outcomes depend only on the majority tournament

Let \(T=R_\mu^M\). The absence of pairwise majority ties means that, for distinct \(x,y\in C\), exactly one of \(xTy\) and \(yTx\) holds. Define \(D_T(x,y)\) to be the majority winner between distinct \(x,y\), and put \(D_T(x,x)=x\).

At any contest, let the eventual winners of its two branches be \(x\) and \(y\). If they differ, sophisticated voting selects the branch yielding \(D_T(x,y)\), by the definition of sophisticated voting. If they coincide, the eventual winner is their common value. Consequently, backward induction uses only \(T\).

Here is an explicit polynomial-time computation. Write the restricted agenda as \((b_1,\ldots,b_k)\). For \(i\in\{2,\ldots,k\}\) and \(x\in\{b_1,\ldots,b_{i-1}\}\), let \(F_i(x)\) be the eventual outcome when \(x\) is the current survivor and the next contest is against \(b_i\). Set \(F_{k+1}(x)=x\) for every \(x\in B\). Then

\(F_i(x)=D_T\bigl(F_{i+1}(x),F_{i+1}(b_i)\bigr).\)

Indeed, the two branches leave respectively \(x\) and \(b_i\) as survivor, with precisely the same remaining agenda. Their continuation outcomes are the two arguments in this recurrence. Decreasing induction on \(i\) therefore proves the recurrence and gives \(w_\sigma(B)=F_2(b_1)\).

There are \(\sum_{i=2}^k(i-1)\) nonterminal states, so the computation uses \(O(k^2)\) tournament operations. Empty and singleton running sets are handled directly.

In particular, two societies with the same majority tournament have identical sophisticated outcomes for every agenda and running set, including every set reached by a candidacy deviation.

2. Eliminating the existential candidate preferences

Fix an agenda \(\sigma\) and a nonempty running set \(B\) with \(w_\sigma(B)=c\).

Lemma. There exist narcissistic candidate preferences making \(B\) an entry equilibrium if and only if

\(w_\sigma(B\cup\{a\})\ne a\quad\text{for every }a\in C\setminus B.\)

Necessity. If an absent candidate \(a\) would win by entering, narcissism implies \(a\succ_a c\). Entering would therefore be a profitable deviation.

Sufficiency. Give \(c\) any strict complete preference order with \(c\) first. For each \(a\ne c\), put \(a\) first and \(c\) second, order the other candidates arbitrarily, and put \(\bot\) last.

Check every deviation:

  • Candidate \(c\) already obtains its first choice, so withdrawal cannot improve its outcome.
  • If \(a\in B\setminus\{c\}\), withdrawal leaves a nonempty set containing \(c\) and excluding \(a\). Its outcome cannot be \(a\). Candidate \(a\) weakly prefers \(c\) to every other possible outcome.
  • If \(a\notin B\), the hypothesis says that entry does not elect \(a\). Again, \(a\) weakly prefers \(c\) to the deviation outcome.

These are all unilateral deviations, so \(B\) is an entry equilibrium. This proves the lemma.

The proof also shows that allowing \(\bot\) anywhere below a candidate’s own name does not change existential outcome membership: the witnessing preferences can always place \(\bot\) last.

3. Membership in \(\mathrm{NP}\) and verification time

A certificate consists only of an agenda \(\sigma\) and a nonempty subset \(B\). Its length is \(O(m\log(m+1))\). By the lemma, the verifier checks \(w_\sigma(B)=c\) and, for each absent candidate \(a\), checks \(w_\sigma(B\cup\{a\})\ne a\).

There are at most \(m+1\) outcome computations, each using \(O(m^2)\) tournament operations. Thus verification after majority preprocessing uses \(O(m^3)\) tournament operations.

For completeness, the majority tournament can be computed exactly in polynomial bit time. Under the usual binary numerator-and-denominator encoding, write \(\mu_j=p_j/q_j\), and set

\(Q=\prod_{j=1}^{\tau}q_j,\qquad t_j=p_j(Q/q_j).\)

Because the denominator encodings contribute to \(L\), these integers have \(O(L)\) bits. A pairwise comparison is determined by

\(aTb\quad\Longleftrightarrow\quad 2\sum_{j:\,a\text{ precedes }b}t_j>Q.\)

Using schoolbook integer arithmetic, forming the common-denominator representation takes \(O(\tau L^2)\) bit operations. Computing all pairwise sums takes \(O(\tau m^2L)\) bit operations.

Consequently, a conservative total verifier bound, including candidate-index operations, is

\(O\bigl((\tau m^2+m^3)L^2\bigr)\)

bit operations. This establishes membership in \(\mathrm{NP}\) in the requested support representation.

4. A polynomial reduction using dyadic masses

We use the following established result: for an explicitly listed odd electorate, deciding whether a designated candidate belongs to the candidate stable set is \(\mathrm{NP}\)-complete. Section 4 defines this set using existential candidate preferences, an existential agenda, and an entry equilibrium under sophisticated successive elimination—the quantifiers required here. Candidates and voters are separate, and candidate preferences are narcissistic. See [Brill and Conitzer, Theorem 3](https://www.cs.cmu.edu/~conitzer/candidacyAAAI15.pdf).

Consider an instance of that problem with odd electorate size \(n\). Group identical rankings into distinct rankings \(\rho_1,\ldots,\rho_\tau\), with positive multiplicities \(k_1,\ldots,k_\tau\). Thus \(\tau\le n\) and \(\sum_j k_j=n\).

If arbitrary binary-encoded rationals are permitted, assigning mass \(k_j/n\) already gives an exact reduction. To cover the stricter interpretation requiring dyadic rationals, proceed as follows.

Let \(D\) be the least power of two satisfying \(D\ge 4n^2\). Define

\(f_j=\left\lfloor Dk_j/n\right\rfloor,\qquad r=D-\sum_{j=1}^{\tau}f_j.\)

Since

\(r=\sum_{j=1}^{\tau}\bigl(Dk_j/n-f_j\bigr),\)

we have \(0\le r<\tau\), and \(r\) is an integer. Increase exactly \(r\) of the integers \(f_j\) by one; call the resulting integers \(h_j\). Output ranking \(\rho_j\) with mass

\(\mu_j=h_j/D.\)

These masses satisfy all representation requirements:

  • They sum exactly to one, since \(\sum_j h_j=D\).
  • They are positive: \(k_j\ge 1\) and \(D/n\ge 4n\), so \(f_j\ge 1\).
  • They are dyadic, since \(D\) is a power of two.
  • The support rankings remain distinct.
  • Their numerators and denominator have \(O(\log(n+1))\) bits, since \(D<8n^2\).

We now prove preservation of every pairwise majority.

For each \(j\), the rounding construction gives

\(\left|\mu_j-k_j/n\right|\le 1/D.\)

Hence, for any pair \(a,b\), its supporting mass changes by at most

\(\left|\sum_{j:\,a\text{ precedes }b}\mu_j-\sum_{j:\,a\text{ precedes }b}k_j/n\right|\le \tau/D\le n/D\le 1/(4n).\)

In the original odd electorate, if \(s\) voters prefer \(a\) to \(b\), then

\(\left|s/n-1/2\right|=|2s-n|/(2n)\ge 1/(2n),\)

because \(2s-n\) is a nonzero integer. The rounding error is strictly smaller than this distance from the majority threshold. Therefore every majority comparison retains its direction, and the output has no pairwise majority ties.

The reduction is polynomial. If \(S\) denotes the explicit source input length, grouping rankings and performing the integer computations can be done in \(O(S^2)\) bit operations. The output length satisfies

\(L=O\bigl(m\log(m+1)+\tau m\log(m+1)+\tau\log(n+1)\bigr),\)

which is polynomial in \(S\), because the source lists all \(n\) voters explicitly.

5. Correctness and conclusion

Keep the candidate set and designated candidate unchanged. Section 4 proves that the source electorate and output rational-mass society have exactly the same majority tournament. Section 1 then proves equality of their sophisticated outcomes for every agenda and running set, including all unilateral deviations.

For any fixed candidate preferences, agenda, and nonempty running set, the entry-equilibrium inequalities are therefore identical in the two instances. The empty outcome causes no discrepancy: a unilateral deviation reaches the empty set only when a sole running candidate withdraws, and narcissism makes that candidate prefer winning to \(\bot\).

Thus the source instance is a yes-instance if and only if the constructed rational-mass instance is a yes-instance. This is a polynomial many-one reduction establishing \(\mathrm{NP}\)-hardness, even for dyadic masses. Together with Section 3, it proves \(\mathrm{NP}\)-completeness.
