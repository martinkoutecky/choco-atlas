The continuous mirror question, as graded

Given alternatives \(A\) and a distribution \(\mu\) over source types \(t=(A_t,\sigma_t)\), where \(A_t\subseteq A\) is the visible set and \(\sigma_t\) is its local total order, does there exist a total order \(\rho\) on \(\bigcup_{\mu_t>0} A_t\) such that \(\rho|_{A_t}=\sigma_t\) for every \(t\) with \(\mu_t>0\)?

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a finite set of \(m\geq 1\) alternatives. A source type is \(t=(A_t,\sigma_t)\), where \(\varnothing\neq A_t\subseteq A\) and \(\sigma_t\) is a strict total order on \(A_t\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
The decision problem asks whether there exists a total order \(\rho\) on \(U=\bigcup_{\mu_t>0}A_t\) such that \(\rho|_{A_t}=\sigma_t\) for every supported type. No pairwise compatibility promise is imposed.

Is this common-order existence problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite sources, common-order existence is equivalent to acyclicity of their combined precedence constraints, and is polynomial-time decidable. This finite-source result also applies to an explicitly listed positive-mass support, so the stated continuous problem is already covered.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one.
  • Required nonempty visibility sets, following the stated domain convention for local orders.
  • Interpreted local and global total orders as strict rankings without ties.
  • Defined L as the total binary input bit length.

Result

The common-order existence problem is polynomial-time solvable. The explicitly listed positive-mass support provides all relevant constraints; the numerical values of the masses do not affect feasibility.

Constraint graph

For each supported type \(t\), write its strict order as
\[ a_{t,1}\prec_{\sigma_t}a_{t,2}\prec_{\sigma_t}\cdots\prec_{\sigma_t}a_{t,k_t}, \qquad k_t=|A_t|. \]
Construct a directed graph \(G\) with vertex set \(U\). For each type, add the edges
\[ a_{t,i}\longrightarrow a_{t,i+1}, \qquad 1\leq i<k_t. \]
Only consecutive comparisons are needed: transitivity of any total order satisfying these edges forces \(a_{t,i}\) to precede \(a_{t,j}\) whenever \(i<j\).

Repeated edges may be retained, with their multiplicities counted consistently in indegrees.

Proof of equivalence

Claim. A common order exists if and only if \(G\) is acyclic.

Suppose a common order \(\rho\) exists. Every edge of \(G\) points from an earlier alternative to a later alternative in \(\rho\). A directed cycle would therefore require an alternative to precede itself, by transitivity. This contradicts strictness, so \(G\) is acyclic.

Conversely, suppose \(G\) is acyclic. Every nonempty finite acyclic directed graph has a vertex of indegree zero: otherwise, repeatedly following an incoming edge would eventually repeat a vertex, producing a directed cycle.

Repeatedly remove a vertex of indegree zero and append it to a list. Removing vertices preserves acyclicity, so the preceding argument guarantees that this procedure lists every vertex. For any edge \(x\longrightarrow y\), the algorithm cannot remove \(y\) while \(x\) remains, because that edge would give \(y\) positive indegree. Thus the resulting list defines a total order \(\rho\) respecting every edge.

For each supported type \(t\), its consecutive edges force
\[ a_{t,1}\prec_\rho a_{t,2}\prec_\rho\cdots\prec_\rho a_{t,k_t}. \]
Consequently, \(\rho|_{A_t}=\sigma_t\). This proves the claim.

No pairwise compatibility assumption is required.

Algorithm and running time

Construct \(G\), compute indegrees, and run the vertex-removal procedure above. Accept exactly when it removes all vertices. On acceptance, its output is a common order.

Let \(s=\sum_t k_t\). The graph has at most \(m\) vertices and at most \(s-\tau\) edge occurrences. With indexed alternatives and adjacency lists, construction and topological sorting take \(O(m+s)\) standard RAM operations. Including reading the input gives
\[ O(L+m+s)=O(L+m\tau), \]
because \(s\leq m\tau\) and \(\tau\geq 1\).

All graph indices and indegree counters require only \(O(\log(m\tau+m+2))\) bits, so the algorithm also has polynomial bit complexity. No arithmetic on the binary rational masses is needed under the stated input promise.

Thus the finite-source acyclicity criterion applies directly to the explicitly listed support and completely settles the stated problem.
