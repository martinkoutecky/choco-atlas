The continuous mirror question, as graded

Given project atoms \(P\), a DNNF integrity constraint \(\Gamma\), a finite support \(\mathcal{B}\subseteq 2^P\) of approval-ballot types with rational masses \(\mu_B\ge 0\) summing to \(1\), and a set of literals \(L\), determine whether some satisfying allocation \(A\subseteq P\) maximizing \(K_\mu(A)=\sum_{B\in\mathcal{B}}\mu_B\bigl(|A\cap B|+|(P\setminus A)\cap(P\setminus B)|\bigr)\) agrees with every literal in \(L\).

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a set of \(m\) project atoms. The integrity constraint \(\Gamma\) is supplied as a DNNF circuit: a rooted directed acyclic graph with literal or constant leaves and conjunction or disjunction gates, such that distinct children of each conjunction involve disjoint sets of atoms. Let \(s\) count its vertices and edges.
A society is given by its support: a list \(\mathcal B\subseteq 2^P\) of \(\tau\) distinct approval-ballot types with positive binary-rational masses \(\mu_B\), satisfying \(\sum_{B\in\mathcal B}\mu_B=1\). Here \(\tau\) is the support size, not the number of possible approval sets. Ballots need not satisfy \(\Gamma\).
Allocations remain subsets \(A\subseteq P\). Among allocations satisfying \(\Gamma\), retain every maximizer of \(K_\mu(A)=\sum_{B\in\mathcal B}\mu_B\bigl(|A\cap B|+|(P\setminus A)\cap(P\setminus B)|\bigr)\), with no tie-breaking.
Given a literal set \(\mathcal L\subseteq P\cup\{\neg p:p\in P\}\), decide whether some retained allocation includes every positively specified project and excludes every negatively specified project. If \(\Gamma\) has no satisfying allocation, the answer is no. Running times are measured in \(m,\tau,L,s,|\mathcal L|\), where \(L\) is the total binary input length.

Is this rational-mass Kemeny outcome-extension problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For societies supplied as finite lists of agents, outcome extension under Kemeny, Slater, and leximax is polynomial-time solvable when the integrity constraint is supplied as a DNNF circuit. This discrete result does not explicitly state a complexity bound for societies supplied with binary-rational masses.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is in \(\mathrm P\). Binary-rational masses can be converted into integer weights of polynomial bit length, and these weights can be optimized directly on the DNNF. Outcome extension is then decided by comparing the unrestricted optimum with the optimum subject to the specified literals.

The proof below does not require the DNNF to be deterministic or smooth.

1. Convert the objective to integer literal weights

Write each supplied mass as \(\mu_B=a_B/d_B\), where \(a_B,d_B\) are positive integers given in binary. Set
\[ D=\prod_{B\in\mathcal B}d_B, \qquad n_B=a_B(D/d_B). \]
Then each \(n_B\) is a positive integer, and normalization gives
\[ \sum_{B\in\mathcal B}n_B=D. \]

For every project \(p\in P\), define
\[ W_p=\sum_{\substack{B\in\mathcal B\\p\in B}}n_B, \qquad c_p(1)=W_p, \qquad c_p(0)=D-W_p. \]
Represent an allocation by its characteristic assignment \(x\in\{0,1\}^P\). By rearranging the sums in the definition of \(K_\mu\),
\[ \begin{aligned} D K_\mu(x) &=\sum_{B\in\mathcal B}n_B \sum_{p\in P} \bigl(x_p\mathbf 1_{p\in B}+(1-x_p)\mathbf 1_{p\notin B}\bigr)\\ &=\sum_{p\in P}\bigl(x_pW_p+(1-x_p)(D-W_p)\bigr)\\ &=\sum_{p\in P}c_p(x_p). \end{aligned} \]
Consequently, maximizing \(K_\mu\) is equivalent to maximizing the integer score
\[ S(x)=\sum_{p\in P}c_p(x_p). \]

This conversion has polynomial bit complexity. Indeed,
\[ \log_2 D=\sum_{B\in\mathcal B}\log_2 d_B\leq L, \]
so \(D\) has at most \(L+1\) bits. Moreover, \(0\leq W_p\leq D\). Products, exact divisions, and sums needed to compute all the weights therefore take polynomial time in \(m,\tau,L\).

2. Weighted optimization on a possibly nonsmooth DNNF

We give an algorithm that also permits restrictions on individual projects. For each \(p\), let \(T_p\subseteq\{0,1\}\) be its nonempty set of allowed values, and define
\[ h_p=\max_{b\in T_p}c_p(b). \]
For unrestricted optimization, use \(T_p=\{0,1\}\).

For each circuit vertex \(g\), let \(V_g\subseteq P\) be the set of atoms occurring in the subcircuit rooted at \(g\), and let \(\varphi_g\) denote its Boolean function. Define
\[ F_g= \max\left\{ \sum_{p\in V_g}c_p(x_p): x\in\prod_{p\in V_g}T_p,\ \varphi_g(x)=1 \right\}, \]
where the maximum over an empty feasible set is represented by the infeasibility marker \(-\infty\).

Also define
\[ H_g=\sum_{p\in V_g}h_p. \]

The scopes \(V_g\) are computed bottom-up by taking unions of child scopes. We now prove recurrences for \(F_g\).

Leaves

For a literal leaf \(p\),
\[ F_g= \begin{cases} c_p(1),&1\in T_p,\\ -\infty,&1\notin T_p. \end{cases} \]
For a literal leaf \(\neg p\),
\[ F_g= \begin{cases} c_p(0),&0\in T_p,\\ -\infty,&0\notin T_p. \end{cases} \]
A true constant has value \(0\), and a false constant has value \(-\infty\). These values follow directly from the definition of \(F_g\).

Conjunction gates

Suppose \(g\) is a conjunction with children \(g_1,\ldots,g_k\). Decomposability states that their scopes are pairwise disjoint. Hence
\[ F_g=\sum_{i=1}^kF_{g_i}, \]
with the result infeasible if any child is infeasible.

To justify this recurrence, every feasible assignment for \(g\) restricts to a feasible assignment for each child, so its score is at most the displayed sum. Conversely, when all children are feasible, choose an optimal assignment for each child. Their disjoint scopes allow these assignments to be combined without conflict. The combined assignment satisfies every child, and its score is exactly the displayed sum.

Disjunction gates

Suppose \(g\) is a disjunction with children \(g_1,\ldots,g_k\). Then
\[ F_g= \max_{1\leq i\leq k} \left(F_{g_i}+H_g-H_{g_i}\right), \]
where an infeasible child contributes \(-\infty\).

Here \(H_g-H_{g_i}\) supplies the optimal contribution of atoms absent from child \(g_i\). This correction is necessary because the input DNNF need not be smooth.

For the upper bound, any feasible assignment for \(g\) satisfies some child \(g_i\). Its contribution on \(V_{g_i}\) is at most \(F_{g_i}\), and its contribution on \(V_g\setminus V_{g_i}\) is at most
\[ \sum_{p\in V_g\setminus V_{g_i}}h_p=H_g-H_{g_i}. \]
For the reverse bound, take an optimal feasible assignment for child \(g_i\), and independently choose an allowed value attaining \(h_p\) for each \(p\in V_g\setminus V_{g_i}\). The added variables do not occur in that child, so the resulting assignment still satisfies it, and therefore satisfies \(g\). Its score attains the corresponding term.

Thus the recurrence is exact even when several children can be satisfied simultaneously.

Complete assignments at the root

Let \(r\) be the root and put \(H_P=\sum_{p\in P}h_p\). If \(F_r\) is infeasible, no allowed allocation satisfies \(\Gamma\). Otherwise, the optimum over complete allocations is
\[ M(T)=F_r+H_P-H_r. \]
Indeed, atoms outside \(V_r\) do not affect \(\Gamma\), so their allowed values can be chosen independently to maximize their contributions.

Together, these recurrences prove the algorithm correct by induction over a bottom-up ordering of the DAG.

3. Decide outcome extension

First, if \(\mathcal L\) contains both \(p\) and \(\neg p\) for some project, return no: no allocation can satisfy all its literals.

Otherwise, perform the optimization twice:

  • With \(T_p=\{0,1\}\) for every project, obtain the unrestricted optimum \(M_0\).
  • With

\[ T_p= \begin{cases} \{1\},&p\in\mathcal L,\\ \{0\},&\neg p\in\mathcal L,\\ \{0,1\},&\text{otherwise}, \end{cases} \]
obtain the restricted optimum \(M_{\mathcal L}\).

Return yes exactly when both optima are feasible and
\[ M_{\mathcal L}=M_0. \]

If this equality holds, an allocation attaining the restricted optimum satisfies \(\Gamma\) and every literal in \(\mathcal L\), while attaining the unrestricted optimum. It is therefore retained.

Conversely, if a retained allocation satisfies every specified literal, it is feasible for the restricted optimization and has score \(M_0\). Restricted feasible allocations form a subset of unrestricted feasible allocations, so
\[ M_{\mathcal L}\leq M_0. \]
The retained allocation supplies the reverse inequality, proving equality.

If \(\Gamma\) is unsatisfiable, the first optimization is infeasible and the algorithm returns no as required. Equality testing preserves every optimal tie.

4. Polynomial running time

Represent each scope \(V_g\) by an \(m\)-entry Boolean vector. Computing all scopes takes \(O(ms)\) elementary operations. Computing the quantities \(H_g\), and then evaluating the recurrences, requires polynomially many integer additions, subtractions, and comparisons.

Every feasible local score and every completion sum lies between \(0\) and \(mD\). Thus all finite values used by the dynamic program have
\[ O\bigl(L+\log(m+1)\bigr) \]
bits. The infeasibility marker requires no numerical encoding of an unbounded integer.

The weight preprocessing, both optimization passes, and the examination of \(\mathcal L\) consequently take polynomial time in \(m,\tau,L,s,|\mathcal L|\).

Clearing denominators does not require expanding the society into \(D\) agents: the algorithm uses only the binary representation of \(D\). This supplies the bit-complexity argument that is missing from a direct appeal to the finite-agent result.
