The continuous mirror question, as graded

Given a finite type set \(T\), rational type masses \(\mu_t\) summing to \(1\), internal opinions \(s_t\in[0,1]\), nonnegative block exposure weights \(q_{tu}\), and a rational campaign mass \(\alpha\in[0,1]\), choose \(x_t\in[0,\mu_t]\) with \(\sum_t x_t=\alpha\). Targeted mass is fixed at expressed opinion \(1\). For each type, let \(\bar z_u=(x_u+(\mu_u-x_u)z_u)/\mu_u\), where \(z_t=(s_t+\sum_u q_{tu}\bar z_u)/(1+\sum_u q_{tu})\). Find \(x\) maximizing \(\sum_t[x_t+(\mu_t-x_t)z_t]\).

A campaign chooses real masses \(0\leq x_t\leq\mu_t\) with \(\sum_t x_t=\alpha\), fixing their expressed opinions permanently to \(1\) without changing internal opinions. Remaining mass of type \(t\) has expressed opinion \(z_t\).
For each campaign, define the equilibrium by \(\bar z_u=(x_u+(\mu_u-x_u)z_u)/\mu_u\) and \(z_t=(s_t+\sum_{u\in T}q_{tu}\bar z_u)/(1+\sum_{u\in T}q_{tu})\). These equations specify the unique equilibrium; when \(x_t=\mu_t\), \(z_t\) is only an auxiliary value.
The decision problem asks whether some feasible campaign has total expressed opinion \(F(x)=\sum_{t\in T}[x_t+(\mu_t-x_t)z_t]\geq\theta\), including targeted mass.

For finite agents, selecting \(k\) agents whose expressed opinions are fixed to \(1\) to maximize total equilibrium opinion is NP-hard; its monotone submodular objective admits a greedy \((1-1/e)\)-approximation. Classification

The decision problem is \(\mathrm{NP}\)-hard, even when all masses are equal and dyadic, all exposure weights belong to \(\{0,1\}\), and exposure is symmetric with zero diagonal.

The reduction below explicitly handles arbitrary real campaign masses.

1. Deficit formulation

For each type \(t\), define the untargeted fraction \(p_t=1-x_t/\mu_t\) and the average opinion deficit \(y_t=1-\bar z_t\). Then

\[ 0\leq p_t\leq1,\qquad \sum_t\mu_t p_t=1-\alpha,\qquad F(x)=1-\sum_t\mu_t y_t. \]

Writing \(d_t=1+\sum_u q_{tu}\), \(c_t=(1-s_t)/d_t\), and \(P_{tu}=q_{tu}/d_t\), the given equilibrium equations imply

\[ 1-z_t=c_t+\sum_uP_{tu}y_u,\qquad y_t=p_t\left(c_t+\sum_uP_{tu}y_u\right). \]

These identities remain valid when \(p_t=0\): that type has \(y_t=0\), while \(z_t\) is auxiliary.

Let \(A=\operatorname{diag}(p)P\). Every row sum of \(A\) is at most

\[ \sum_uP_{tu}=\frac{\sum_uq_{tu}}{1+\sum_uq_{tu}}<1. \]

Consequently, \(I-A\) is invertible, with nonnegative inverse \(\sum_{j=0}^{\infty}A^j\). Thus the unique deficit vector is nonnegative and satisfies \(y_t\geq p_tc_t\).

Equality lemma

Suppose \(c_t=c>0\) for every type. Then every feasible campaign satisfies

\[ F(x)\leq1-c(1-\alpha). \]

Moreover, equality holds if and only if

\[ p_tp_u=0\quad\text{whenever }q_{tu}>0. \]

Proof. Summing the deficit equations with coefficients \(\mu_t\) gives

\[ \sum_t\mu_ty_t =c(1-\alpha)+\sum_{t,u}\mu_tp_tP_{tu}y_u. \]

Every term in the second sum is nonnegative, proving the bound. If equality holds, each such term is zero. Since \(\mu_t>0\), \(P_{tu}>0\) whenever \(q_{tu}>0\), and \(y_u\geq cp_u\), this forces \(p_tp_u=0\) on every positive exposure entry.

Conversely, suppose those products vanish. The vector \(y_t=cp_t\) satisfies the equilibrium deficit equations, because

\[ p_t\left(c+\sum_uP_{tu}cp_u\right) =cp_t+c\sum_uP_{tu}p_tp_u =cp_t. \]

Uniqueness therefore gives \(y_t=cp_t\), and hence equality in the bound. \(\square\)

2. Reduction from Independent Set

Use the standard \(\mathrm{NP}\)-complete Independent Set problem: given a simple undirected graph \(G\) on \(n\geq1\) vertices and an integer \(1\leq k\leq n\), decide whether it contains an independent set of size at least \(k\).

Let \(N\) be the smallest power of two satisfying \(N\geq n\). Add \(r=N-n\) isolated vertices to obtain a graph \(H\), and set \(K=k+r\). Then \(H\) has an independent set of size at least \(K\) if and only if \(G\) has one of size at least \(k\):

  • An independent set in \(G\), together with all added isolates, gives the forward implication.
  • Removing the at most \(r\) added vertices from an independent set of size at least \(K\) leaves at least \(K-r=k\) original vertices.

Construct one type for each vertex of \(H\). For a vertex \(t\) of degree \(\delta_t\), set

\[ \mu_t=\frac1N,\qquad q_{tu}= \begin{cases} 1,&\{t,u\}\in E(H),\\ 0,&\text{otherwise}, \end{cases} \qquad s_t=1-\frac{1+\delta_t}{N}. \]

Finally, choose

\[ \alpha=1-\frac KN,\qquad \theta=1-\frac K{N^2}. \]

All masses are positive and sum to one. Since \(0\leq\delta_t\leq N-1\), every \(s_t\) belongs to \([0,1]\). Also \(1\leq K\leq N\), so \(\alpha,\theta\in[0,1]\). Because \(N\) is a power of two, every numerical input is dyadic.

Crucially,

\[ c_t=\frac{1-s_t}{1+\delta_t}=\frac1N \]

for every type.

3. Correctness, including fractional campaigns

The campaign budget is equivalent to

\[ \sum_t p_t=K. \]

The equality lemma therefore gives the universal upper bound

\[ F(x)\leq1-\frac1N\left(1-\alpha\right) =1-\frac K{N^2} =\theta. \]

Independent set implies a successful campaign

Suppose \(H\) has an independent set of size at least \(K\). Choose a subset \(S\) of exactly \(K\) vertices, and set \(p_t=1\) on \(S\) and \(p_t=0\) elsewhere. Equivalently, leave \(S\) untargeted and target every other type completely.

The campaign has mass \((N-K)/N=\alpha\). Independence ensures \(p_tp_u=0\) on every positive exposure entry. The equality lemma gives \(F(x)=\theta\), so the campaign instance is a yes-instance.

Successful real campaign implies an independent set

Conversely, suppose an arbitrary feasible real campaign satisfies \(F(x)\geq\theta\). The universal upper bound forces \(F(x)=\theta\).

By the equality lemma, its positive untargeted support

\[ S=\{t:p_t>0\} \]

is an independent set in \(H\). Since each \(p_t\leq1\),

\[ K=\sum_t p_t=\sum_{t\in S}p_t\leq|S|. \]

Thus \(H\) has an independent set of size at least \(K\), and \(G\) has one of size at least \(k\).

This capacity argument is the step that excludes fractional false positives.

4. Encoding size and running time

The constructed instance has \(\tau=N<2n\) types and \(m=2|E(G)|\) positive exposure entries. Every numerical parameter and type index uses \(O(\log(2\tau))\) bits.

With sparse exposure encoding, the output length and construction time are both \(O((m+\tau)\log(2\tau))\) bits and bit operations, respectively. If all zero entries are explicitly listed, both bounds become \(O(\tau^2+(m+\tau)\log(2\tau))\). In either representation the reduction is polynomial, with construction time \(O(L+(m+\tau)\log(2\tau))\), where \(L\) is the resulting total input bit length.

The threshold strategy is related to the discrete vertex-cover reduction in Appendix A of [Gionis, Terzi, and Tsaparas](https://www.cs.uoi.gr/~tsap/publications/opinion-maximization.pdf). The equality lemma above supplies the additional argument needed for continuous targeting.

Hence the stated continuous decision problem is \(\mathrm{NP}\)-hard, and a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
