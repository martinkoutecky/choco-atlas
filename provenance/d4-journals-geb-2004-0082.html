The continuous mirror question, as graded

Given item kinds \(A\), a partition \(\pi\), rational valuation types \(v_t:2^A\to\mathbb{Q}_{\ge 0}\), masses \(\mu_t\) summing to \(1\), per-capita supplies \(\rho_a\), and threshold \(q\), optimize mass allocations \(x_{t,B}\) with \(\sum_B x_{t,B}=\mu_t\) and \(\sum_{t,B\ni a}x_{t,B}\le\rho_a\), compare unrestricted welfare \(S^\star\) with \(\Sigma_\pi\)-restricted welfare \(S^\pi\), and decide whether \(S^\star/S^\pi\ge q\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge1\) item kinds, and let \(\pi=\{A_1,\ldots,A_k\}\) partition \(A\) into nonempty parts. Define \(\Sigma_\pi=\{\bigcup_{j\in J}A_j:J\subseteq\{1,\ldots,k\}\}\).
A society is given by its support: the list of its \(\tau\ge1\) valuation types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types; \(\sum_t\mu_t=1\).
Each \(v_t:2^A\to\mathbb Q_{\ge0}\) is supplied as a complete table, satisfies free disposal, and has \(v_t(\varnothing)=0\). Supplies \(\rho_a\in\mathbb Q_{\ge0}\) and threshold \(q\in\mathbb Q_{\ge1}\) are binary encoded; \(L\) is the total input bit length, including valuation tables.
An allocation consists of real masses \(x_{t,B}\ge0\), allowing each type to be split among bundles, with \(\sum_{B\subseteq A}x_{t,B}=\mu_t\) and \(\sum_t\sum_{B\ni a}x_{t,B}\le\rho_a\) for every \(a\in A\). Unused supply is allowed.
Let \(S^\star\) maximize \(\sum_t\sum_{B\subseteq A}x_{t,B}v_t(B)\) over these allocations, and let \(S^\pi\) maximize the same objective subject additionally to \(x_{t,B}=0\) for \(B\notin\Sigma_\pi\). Promise \(S^\pi>0\).

Is deciding whether \(S^\star/S^\pi\ge q\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,k,L\).

For finite buyers receiving disjoint bundles, the worst-case unrestricted-to-restricted welfare ratio equals the largest size of a multiset of nonempty, pairwise intersecting subsets of \(\{1,\ldots,k\}\), with each index \(j\) appearing at most \(|A_j|\) times; this is a characterization, not a complexity classification. [Holzman et al.](https://holzman.technion.ac.il/files/2012/09/gebrndm.pdf)
Related fractional bundle-allocation models are studied for combinatorial Walrasian equilibrium; no classification of the precise mass-and-supply ratio decision problem above was identified. [Feldman et al.](https://www.cs.tau.ac.il/~mfeldman/papers/FGLj16.pdf)

Modeling choices made when packaging the task

  • Specified complete valuation tables and total input bit length, following the anchor's full bundle-value representation rather than introducing an unspecified succinct representation.
  • Restored normalization at the empty bundle and free disposal, as required by the discrete valuation domain.
  • Specified a nonempty item set and a partition into nonempty parts.
  • Specified nonnegative binary-rational supplies, without requiring their sum to equal one.
  • Specified nonnegative real allocation masses, divisible type masses, and permission to leave supply unused.
  • Restricted the threshold to binary rationals at least one, matching the welfare-loss ratio's natural range.
  • Promised positive restricted welfare to exclude undefined ratios; unlike the finite setting, nonzero valuations alone need not ensure this under arbitrary supplies.

Result

The decision problem is in \(\mathrm P\). Both welfare maxima can be computed exactly by rational linear programming, in total bit running time

\(\bigl[L+(m+\tau)\tau 2^m+(k+\tau)\tau 2^k\bigr]^{O(1)}=L^{O(1)}.\)

The exponent is an absolute constant. This is a polynomial bound in the binary input length; no strongly polynomial bound is asserted.

1. The unrestricted welfare program

Introduce one real variable \(x_{t,B}\) for each supported type \(t\in\{1,\ldots,\tau\}\) and bundle \(B\subseteq A\). Maximize

\(\displaystyle \sum_{t=1}^{\tau}\sum_{B\subseteq A}v_t(B)x_{t,B}\)

subject to:

  • \(\displaystyle \sum_{B\subseteq A}x_{t,B}=\mu_t\) for every type \(t\);
  • \(\displaystyle \sum_{t=1}^{\tau}\sum_{\substack{B\subseteq A\\a\in B}}x_{t,B}\le\rho_a\) for every item kind \(a\);
  • \(x_{t,B}\ge0\) for every \(t,B\).

These constraints are precisely the unrestricted allocation requirements. Consequently, the program’s optimal value is \(S^\star\).

It has \(\tau2^m\) variables, \(\tau\) equality constraints, and \(m\) supply inequalities, together with variable nonnegativity.

The feasible set is nonempty: assigning \(x_{t,\varnothing}=\mu_t\) and all other variables zero satisfies every constraint. Moreover, nonnegativity and the type equalities imply \(0\le x_{t,B}\le\mu_t\). Thus the feasible set is closed and bounded, hence compact. The linear objective therefore attains a finite maximum.

2. The restricted welfare program

For \(J\subseteq\{1,\ldots,k\}\), define

\(U_J=\bigcup_{j\in J}A_j,\qquad w_{t,J}=v_t(U_J).\)

Because the partition parts are nonempty and disjoint, the map \(J\mapsto U_J\) is injective. Its image is exactly \(\Sigma_\pi\), which therefore contains \(2^k\) bundles.

Define the effective supply of part \(j\) by

\(\displaystyle r_j=\min_{a\in A_j}\rho_a.\)

Introduce variables \(y_{t,J}\ge0\). Maximize

\(\displaystyle \sum_{t=1}^{\tau}\sum_{J\subseteq\{1,\ldots,k\}}w_{t,J}y_{t,J}\)

subject to:

  • \(\displaystyle \sum_{J\subseteq\{1,\ldots,k\}}y_{t,J}=\mu_t\) for every type \(t\);
  • \(\displaystyle \sum_{t=1}^{\tau}\sum_{\substack{J\subseteq\{1,\ldots,k\}\\j\in J}}y_{t,J}\le r_j\) for every part \(j\);
  • \(y_{t,J}\ge0\) for every \(t,J\).

To verify the supply constraints, fix a part \(A_j\). Every allowed bundle contains either all of \(A_j\) or none of it. Therefore each item kind \(a\in A_j\) has the same allocated mass,

\(\displaystyle z_j=\sum_{t=1}^{\tau}\sum_{J\ni j}y_{t,J}.\)

The original inequalities \(z_j\le\rho_a\) for all \(a\in A_j\) are equivalent to \(z_j\le r_j\). Hence this program describes exactly the restricted allocations, and its optimal value is \(S^\pi\).

It has \(\tau2^k\) variables, \(\tau\) equality constraints, and \(k\) supply inequalities. Assigning all mass to \(J=\varnothing\) proves feasibility; the type equalities again prove boundedness.

3. Exact computation and threshold comparison

We use the standard exact rational linear programming theorem: a linear program with explicitly listed binary rational data can be solved in time polynomial in its encoding length, returning an exact rational optimum when the program is feasible and bounded. Equalities and variable nonnegativity are permitted. This follows from polynomial-time linear programming over integer data by clearing denominators; the resulting integers have polynomial encoding length. See [MIT’s lecture on the ellipsoid method](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

Both programs satisfy the theorem’s hypotheses:

  • all coefficients are rational and explicitly available;
  • their feasible sets are nonempty;
  • both objectives have finite attained maxima.

Compute their exact optimal values. Write

\(S^\star=a/b,\qquad S^\pi=c/d,\qquad q=e/f,\)

with positive denominators. The promise \(S^\pi>0\) gives \(c>0\). Multiplication by the positive denominators proves

\(\displaystyle \frac{S^\star}{S^\pi}\ge q \quad\Longleftrightarrow\quad adf\ge bce.\)

The exact LP outputs have polynomial encoding length. Thus the final integer multiplications and comparison also take polynomial time, including when equality holds.

4. Encoding sizes and running times

Let \(D_\star\) and \(D_\pi\) denote the binary encoding lengths of dense representations of the two programs. Their constraint matrices contain only zeros and ones. Their remaining numerical data are copied from the input, with the restricted supplies selected by taking minima. Consequently,

\(D_\star=O\bigl(L+(m+\tau)\tau2^m\bigr),\)

\(D_\pi=O\bigl(L+(k+\tau)\tau2^k\bigr).\)

Constructing these programs, including enumerating the allowed unions and retrieving their valuations, takes polynomial time in these bounds. Exact optimization therefore takes respectively

\(\bigl[L+(m+\tau)\tau2^m\bigr]^{O(1)}\)

and

\(\bigl[L+(k+\tau)\tau2^k\bigr]^{O(1)}.\)

Finally, the complete valuation tables contain \(\tau2^m\) explicitly encoded entries. Each entry occupies at least one bit, so \(\tau2^m\le L\). Also \(k\le m\), and \(m,\tau=O(L)\). Hence both program encodings have size \(O(L^2)\), proving the claimed total bound \(L^{O(1)}\).

The conclusion concerns the stated model with splittable type masses and complete valuation tables. It requires no computation of the finite-buyer worst-case characterization. Under polynomial-time many-one reductions, NP-hardness of this decision problem would therefore imply \(\mathrm P=\mathrm{NP}\).
