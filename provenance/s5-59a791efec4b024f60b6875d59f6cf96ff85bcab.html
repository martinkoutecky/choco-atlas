The continuous mirror question, as graded

Given \(m\) goods and \(\tau\) types with rational masses \(\mu_t>0\), complete rankings \(\pi_t\), demands \(r_t>0\), per-capita supplies \(q_j\), and a feasible baseline allocation \(a_{tj}\), decide whether there is a feasible allocation \(x_{tj}\ge 0\) with \(\sum_j x_{tj}=r_t\) and \(\sum_t\mu_t x_{tj}\le q_j\), such that every type weakly lexicographically prefers \(x_t\) to \(a_t\) and at least one type strictly prefers it. By averaging allocations within each type, this decision is equivalent to asking whether a positive mass of individuals can be weakly improved, with a strict improvement for positive mass.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible rankings. Normalize \(\sum_t\mu_t=1\).
There are \(m\ge1\) divisible goods with positive per-capita supplies \(q_j\). Each type \(t\) has a strict complete ranking \(\pi_t\), a demand \(r_t>0\), and a baseline share \(a_t\). Supplies, demands, and baseline entries are binary rationals; \(L\) is the total input bit length.
A feasible allocation consists of real shares \(x_{tj}\ge0\) satisfying \(\sum_jx_{tj}=r_t\) and \(\sum_t\mu_tx_{tj}\le q_j\). The supplied baseline \(a\) is feasible. Type \(t\) compares shares by lexicographic order on \((x_{t\pi_t(1)},\ldots,x_{t\pi_t(m)})\); weak preference includes equality.
A Pareto improvement over \(a\) is a feasible allocation that every supported type weakly prefers to its baseline share and at least one supported type strictly prefers.

Is deciding whether a Pareto improvement exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and \(L\).

For finitely many agents with lexicographic preferences over divisible goods, Schulman and Vazirani establish a polynomial-time algorithm for checking Pareto efficiency, hence also for deciding whether a Pareto improvement exists.

  • Normalized the positive rational masses to sum to one, consistent with a distribution over types and per-capita supplies.
  • Required positive supplies, as in the finite-agent domain; allowed any positive number of goods and supported types.
  • Specified binary-rational supplies, demands, and baseline entries, and defined L as the total input bit length.
  • Specified strict complete rankings, real allocation shares, and equality as weak preference.

1. Result and reduction to finite agents

The decision problem is in \(\mathrm{P}\). A direct algorithm uses \(O(\tau^2m)\) arithmetic operations after preprocessing and, conservatively, \(O(\tau^2mL^2+L^3)\) bit operations.

For each supported type, define
\[ y_{tj}=\mu_tx_{tj},\qquad B_{tj}=\mu_ta_{tj},\qquad R_t=\mu_tr_t. \]
Then feasibility becomes
\[ y_{tj}\ge0,\qquad \sum_jy_{tj}=R_t,\qquad \sum_ty_{tj}\le q_j. \]
Because \(\mu_t>0\), multiplication by \(\mu_t\) preserves the position and sign of the first differing coordinate. Thus \(x_t\) weakly or strictly lexicographically dominates \(a_t\) exactly when \(y_t\) respectively dominates \(B_t\).

This is precisely a finite-agent instance with \(\tau\) agents, arbitrary positive demands \(R_t\), and the given rankings. Moreover, baseline feasibility implies
\[ \sum_tR_t=\sum_{t,j}B_{tj}\le\sum_jq_j. \]
Consequently, the finite-agent efficiency theorem applies without expanding masses into agent copies. Schulman and Vazirani state the efficiency-checking result as Corollary 15. [Source](https://drops.dagstuhl.de/storage/00lipics/lipics-vol045-fsttcs2015/LIPIcs.FSTTCS.2015.543/LIPIcs.FSTTCS.2015.543.pdf)

For an explicit running-time bound, the following gives a self-contained algorithm and proof.

2. Algorithm

Maintain a partial allocation \(z\), remaining baseline entries \(b\), remaining supplies \(c\), and remaining demands \(\rho\). Initially,
\[ z_{tj}=0,\qquad b_{tj}=B_{tj},\qquad c_j=q_j,\qquad \rho_t=R_t. \]
Throughout the algorithm,
\[ z_{tj}+b_{tj}=B_{tj},\qquad \rho_t=\sum_jb_{tj},\qquad c_j=q_j-\sum_tz_{tj}. \]
In particular, baseline feasibility gives
\[ \sum_tb_{tj}\le c_j. \]

Call type \(t\) *active* when \(\rho_t>0\). For every active type, let \(f_t\) be its most preferred good with \(c_j>0\). This good exists: some \(b_{tj}>0\), and then \(c_j\ge b_{tj}>0\).

Repeat the following:

  • If no type is active, return no Pareto improvement.
  • If some active type \(t\) satisfies \(b_{t f_t}>0\), set \(\delta=b_{t f_t}\) and update

\[ z_{t f_t}\leftarrow z_{t f_t}+\delta,\qquad b_{t f_t}\leftarrow0,\qquad c_{f_t}\leftarrow c_{f_t}-\delta,\qquad \rho_t\leftarrow\rho_t-\delta. \]

  • If active types remain but none satisfies that condition, return a Pareto improvement exists.

Every update preserves the invariants and nonnegativity because \(\delta\le c_{f_t}\). Each update eliminates one positive baseline entry permanently, so there are at most \(\tau m\) updates.

The initialization uses the full supplies \(q_j\), including unused supply.

3. Proof that stalling yields an improvement

Suppose the algorithm stalls, and let \(A\) be the nonempty set of active types. For each \(t\in A\),
\[ c_{f_t}>0,\qquad b_{t f_t}=0. \]
Every good that \(t\) ranks above \(f_t\) has zero remaining supply and therefore zero remaining baseline allocation.

For each requested good \(j\), define
\[ n_j=\bigl|\{t\in A:f_t=j\}\bigr|. \]
Choose
\[ \varepsilon= \frac12\min\left( \{\rho_t:t\in A\} \cup \{c_j/n_j:n_j>0\} \right)>0. \]
Add \(\varepsilon\) units of \(f_t\) to each active type’s partial allocation. This respects every remaining supply and leaves every active type with positive remaining demand.

There is enough total remaining supply to complete the allocation. Indeed, before these additions,
\[ \sum_jc_j =\sum_jq_j-\sum_{t,j}z_{tj} \ge\sum_tR_t-\sum_{t,j}z_{tj} =\sum_{t\in A}\rho_t. \]
The additions decrease both sides by \(|A|\varepsilon\).

Because goods are divisible and there are no further restrictions on individual entries, this aggregate inequality suffices for completion: fill the remaining demands sequentially from goods with positive remaining supply. Such a procedure cannot run out of supply while demand remains, since the same aggregate inequality is preserved after every assignment.

Let \(y\) be the completed allocation. Inactive types retain their baseline allocation. For each active type \(t\):

  • Goods above \(f_t\) were exhausted before the additions, so their final entries equal \(B_t\).
  • Since \(b_{t f_t}=0\), the partial allocation already contained \(B_{t f_t}\). Hence

\[ y_{t f_t}\ge B_{t f_t}+\varepsilon>B_{t f_t}. \]

Thus every active type strictly prefers \(y_t\) to \(B_t\), and every inactive type receives its baseline. This is a Pareto improvement.

4. Proof that completion certifies efficiency

Suppose the algorithm finishes, so \(z=B\). Number its updates consecutively.

For each good \(j\), let \(E(j)\) be the update at which its remaining supply becomes zero; set \(E(j)=+\infty\) if it never becomes zero.

For every positive baseline entry \(B_{tk}>0\), let \(s(t,k)\) be the update that allocates this entry. If \(t\) ranks \(j\) above \(k\), then \(j\) was exhausted before that update, because the algorithm allocated \(k\) only when it was \(t\)’s most preferred available good. Consequently,
\[ E(j)<s(t,k)\le E(k). \tag{1} \]

Assume, for contradiction, that a feasible allocation \(y\) Pareto improves \(B\). For each changed type \(t\), let \(g_t\) be its first differing good. Weak lexicographic preference implies
\[ y_{t g_t}>B_{t g_t}. \]
Equality of row sums implies that some lower-ranked good \(k\) satisfies
\[ y_{tk}<B_{tk}. \]
In particular, \(B_{tk}>0\), so (1) gives
\[ E(g_t)<s(t,k). \]
Therefore \(E(g_t)\) is finite for every changed type.

Choose a changed type \(t\) minimizing \(E(g_t)\), and write \(j=g_t\). Since \(E(j)\) is finite and the algorithm finished,
\[ \sum_uB_{uj}=q_j. \]
Feasibility of \(y\), together with \(y_{tj}>B_{tj}\), therefore forces some type \(u\) to satisfy
\[ y_{uj}<B_{uj}. \]
Type \(u\) is changed. Its first differing good \(g_u\) must be ranked above \(j\): its first difference is positive, whereas its difference at \(j\) is negative. Since \(B_{uj}>0\), (1) yields
\[ E(g_u)<s(u,j)\le E(j)=E(g_t). \]
This contradicts the choice of \(t\). Hence no Pareto improvement exists.

5. Running time and binary encoding

Maintain a pointer into each active type’s ranking, advancing it past exhausted goods. Each pointer advances at most \(m\) times.

A straightforward implementation scans the \(\tau\) types to find an eligible update. With at most \(\tau m\) updates and one final scan, this takes \(O(\tau^2m)\) arithmetic operations; all pointer advances together take \(O(\tau m)\) additional operations.

For exact arithmetic, let \(D\) be the product of the denominators of all input rationals. Its bit length is \(O(L)\). The denominators of
\[ B_{tj}=\mu_ta_{tj},\qquad R_t=\mu_tr_t,\qquad q_j \]
divide \(D\), since both factors’ denominators occur in the product defining \(D\). Multiply all quantities by \(D\) and execute the algorithm using integers.

These integers have \(O(L)\) bits. During the algorithm, remaining supplies, demands, and entries only decrease, so their bit lengths remain \(O(L)\). Computing \(D\) and converting the quantities takes \(O(L+\tau m)\) arithmetic operations. Charging \(O(L^2)\) bit operations per arithmetic operation gives the conservative total bound
\[ O\bigl((\tau^2m+L)L^2\bigr) =O(\tau^2mL^2+L^3). \]

The algorithm therefore runs in polynomial time in the supplied support representation, independently of the magnitudes of mass denominators or the number of possible rankings. For \(m=1\), every row is fixed by its demand, so no improvement exists; the algorithm also handles this case.
