The anchor (named result in the paper)

Theorem 4.1 — class: algorithmic

The continuous mirror question, as graded

Given a finite type set \(T\), rational society masses \(\mu\in\Delta_T\), per-capita supplies \(q_g\) of indivisible good kinds, additive values \(v_{rg}\), and non-atomic cake densities \(f_r\) in the Robertson–Webb model, compute a finite-support mass allocation \(x_{r,b}\) of integral bundles \(b\in\mathbb{Z}_{\ge0}^{\mathcal{G}}\) together with a finite cake-allocation protocol, satisfying \(\sum_b x_{r,b}=\mu_r\) and \(\sum_{r,b}x_{r,b}b_g\le q_g\), such that every type-\(r\) recipient receives at least \((1-\epsilon)\alpha' s_r\), where \(\alpha'\ge\min\left\{1,\frac12+\min_{r:\mu_r>0}\frac{h_r}{2s_r}\right\}\), \(h_r=\int f_r\), and \(s_r\) is the per-capita MMS benchmark obtained by partitioning normalized resources into unit mass of integral bundles and cake shares.

Packaged proof task (what the prover saw — nothing else)

Let \(T\) be a finite set of types with rational masses \(\mu\in\Delta_T\). Good kind \(g\) has rational per-capita supply \(q_g\); a recipient gets an integral bundle \(b\in\mathbb Z_{\ge0}^{\mathcal G}\), valued by type \(r\) at \(\sum_g v_{rg}b_g\). Type \(r\) values a cake share \(y\) at \(\int_0^1 f_r(t)y(t)\,dt\), where \(f_r\) is nonnegative and non-atomic, and \(h_r=\int_0^1 f_r(t)\,dt\) is rational.
A finite-support mass allocation assigns mass \(x_{r,b}\ge0\) and a cake share \(y_{r,b}(t)\ge0\) to each occupied type–bundle class. It requires \(\sum_b x_{r,b}=\mu_r\), \(\sum_{r,b}x_{r,b}b_g\le q_g\), and \(\sum_{r,b}x_{r,b}y_{r,b}(t)\le1\) almost everywhere. Every recipient in that class obtains value \(\sum_g v_{rg}b_g+\int_0^1 f_r(t)y_{r,b}(t)\,dt\).
Define \(s_r\) as the supremum of the least recipient value when type \(r\) partitions these normalized supplies into unit mass of integral bundles and cake shares under the same supply constraints. For fixed \(\epsilon>0\), the output consists of a finite-support mass allocation, finitely described cake shares, and \(\alpha'\ge\min\{1,\tfrac12+\min_{r:\mu_r>0,\ s_r>0}h_r/(2s_r)\}\); omit zero-benchmark types from this minimum. Each occupied class must receive at least \((1-\epsilon)\alpha's_r\). Cake densities are accessed by unit-cost Robertson–Webb evaluation and cut queries.

Is this allocation problem solvable in polynomial time in the rational input length, \(|T|\), \(|\mathcal G|\), and Robertson–Webb queries for every fixed \(\epsilon>0\), or is it NP-hard?

For finitely many agents, a polynomial-time algorithm achieves \((1-\epsilon)\alpha'\)-MMS with \(\alpha'\ge\min\{1,\tfrac12+\min_i u_i(C)/(2(n-1)\operatorname{MMS}_i)\}\). That result does not address a society specified by type masses.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The problem is polynomial-time solvable for every fixed \(\epsilon>0\). In fact, the mass model admits the stronger guarantee \(\alpha'=1\): every occupied class can receive at least \((1-\epsilon)s_r\).

Here, goods values are understood to be rational input numbers, as required by the stated rational-input complexity model. Negative goods values, if allowed, can be discarded separately for each type: supplies are upper bounds, so removing negatively valued goods never hurts feasibility or value.

1. Combining single-type allocations

Suppose that, for each positive-mass type \(r\), we construct a unit-mass allocation with:

  • class masses \(p_{r,b}\) summing to \(1\);
  • goods consumption at most \(q_g\) for each kind;
  • constant cake shares \(c_{r,b}\geq0\), satisfying \(\sum_b p_{r,b}c_{r,b}\leq1\);
  • recipient value at least \((1-\epsilon)s_r\).

Set \(x_{r,b}=\mu_rp_{r,b}\) and \(y_{r,b}(t)=c_{r,b}\). Then

\[ \sum_{r,b}x_{r,b}b_g \leq \sum_r\mu_rq_g=q_g, \qquad \sum_{r,b}x_{r,b}y_{r,b}(t) \leq\sum_r\mu_r=1. \]

Recipient values are unchanged. Thus it suffices to approximate the benchmark for one type using constant cake shares.

Fix that type, and write its positive goods values as \(v_g\), its total cake value as \(h\), and its benchmark as \(s\). Goods with nonpositive value will not be used.

For any feasible single-type partition, let \(c_b\) denote the cake value received in class \(b\). Nonnegativity and the cake supply constraint imply

\[ \sum_b p_bc_b =\int_0^1 f(t)\sum_b p_by_b(t)\,dt \leq h. \]

If \(h>0\), replacing each share by the constant function \(c_b/h\) preserves recipient values and feasibility. If \(h=0\), cake contributes no value. Consequently, only the scalar \(h\) matters for the single-type problem.

2. A rounding lemma for small goods

We need a rounding procedure whose support does not depend on the magnitudes of bundle coordinates.

Lemma. Given positive rational weights \(w_1,\ldots,w_k\) and a rational vector \(a\in\mathbb R_{\geq0}^k\), one can compute, in polynomial time, a distribution on at most \(k+1\) integral vectors \(B\) such that

\[ \mathbb E[B_i]=a_i, \qquad \sum_i w_iB_i\geq\sum_i w_ia_i-\max_iw_i \]

for every vector in its support.

Proof. Reorder coordinates so that \(w_1\geq\cdots\geq w_k\). Write \(a_i=\lfloor a_i\rfloor+r_i\), where \(0\leq r_i<1\), and set \(R_j=\sum_{i=1}^j r_i\), with \(R_0=0\).

For \(U\) uniform on \([0,1)\), define

\[ B_i(U)=\lfloor a_i\rfloor+ \lfloor R_i+U\rfloor-\lfloor R_{i-1}+U\rfloor. \]

Each added term belongs to \(\{0,1\}\). The identity
\(\mathbb E[\lfloor x+U\rfloor]=x\) gives \(\mathbb E[B_i]=a_i\).

Let

\[ E_j=\sum_{i=1}^j(B_i-a_i) =\lfloor R_j+U\rfloor-R_j. \]

Then \(-1<E_j<1\). Summation by parts gives

\[ \sum_{i=1}^k w_i(B_i-a_i) = \sum_{j=1}^{k-1}(w_j-w_{j+1})E_j+w_kE_k \geq-w_1. \]

Finally, the vector \(B(U)\) changes only at the at most \(k\) breakpoints where some \(R_j+U\) is integral. Sorting those rational breakpoints gives at most \(k+1\) intervals, whose lengths are the required probabilities. All computations and output numbers have polynomial bit complexity. \(\square\)

3. A polynomial-size feasibility relaxation

Fix a rational constant \(\delta\in(0,1)\) and a positive rational target \(z\).

Call a good *large* if \(v_g\geq\delta z\), and *small* otherwise. Put

\[ K=\lceil1/\delta\rceil, \qquad S=\sum_{g\text{ small}}v_gq_g, \qquad F=S+h. \]

Enumerate all large-good configurations \(C\) containing at most \(K\) items in total, including the empty configuration. Write

\[ V(C)=\sum_{g\text{ large}}v_gC_g, \qquad d_C=\max\{0,z-V(C)\}. \]

For fixed \(\delta\), there are at most \((|\mathcal G|+1)^K\) configurations. Solve the rational linear feasibility problem

\[ p_C\geq0,\qquad \sum_Cp_C=1, \]

\[ \sum_Cp_CC_g\leq q_g \quad\text{for every large good }g, \]

\[ \sum_Cp_Cd_C\leq F. \tag{*} \]

This LP has polynomial size for fixed \(\delta\).

We establish both properties needed for the algorithm.

Necessity. If a unit-mass partition gives every recipient value at least \(z\), then \((*)\) is feasible.

For each recipient, consider its large goods. If their total value is below \(z\), retain all of them; their number is less than \(1/\delta\). Otherwise, retain goods in any order until their total first reaches \(z\). Before the last retained item, the total is below \(z\), so fewer than \(1/\delta\) items have been retained. Including the last item gives at most \(K\) items.

Thus every retained configuration is enumerated. Its deficit \(d_C\) is at most the recipient’s original small-good value plus cake value: this is immediate when \(V(C)\geq z\), and otherwise no large goods were removed.

Aggregating configurations over the unit population gives the mass and large-good constraints. Aggregating the preceding deficit inequality gives

\[ \sum_Cp_Cd_C\leq S+h=F. \]

This proves necessity. In particular, if the LP is infeasible, then \(s\leq z\): otherwise the definition of supremum would supply a partition with minimum value greater than \(z\).

Constructive sufficiency with loss. If \((*)\) is feasible, we can construct a unit-mass allocation with minimum value at least \((1-\delta)z\).

First suppose \(F>0\). For each occupied configuration \(C\), prescribe the fractional small-good vector and constant cake share

\[ a_{Cg}=\frac{d_Cq_g}{F} \quad(g\text{ small}), \qquad y_C(t)=\frac{d_C}{F}. \]

Their combined value is exactly the deficit:

\[ \sum_{g\text{ small}}v_ga_{Cg} +h\frac{d_C}{F} =d_C. \]

Apply the rounding lemma to the small-good vector for each \(C\), splitting its mass according to the resulting distribution. Since each small-good value is below \(\delta z\), every resulting recipient obtains value at least

\[ V(C)+d_C-\delta z\geq(1-\delta)z. \]

Let \(D=\sum_Cp_Cd_C\leq F\). Expected counts are preserved exactly, so each small-good supply constraint holds:

\[ \sum_Cp_Ca_{Cg}=\frac{D}{F}q_g\leq q_g. \]

The cake constraint also holds pointwise:

\[ \sum_Cp_Cy_C(t)=\frac{D}{F}\leq1. \]

The LP already enforces the large-good constraints.

If \(F=0\), every occupied configuration has \(d_C=0\), and the large configurations alone achieve \(z\).

The construction uses at most \((|\mathcal G|+1)\) subclasses per configuration and has polynomial bit complexity. Bundle coordinates may be large, but they are written in binary.

4. Locating a sufficiently good target

It remains to choose \(z\) without knowing \(s\). We give explicit bounds and a binary-search invariant; the LP need not be an exact feasibility test.

Every feasible minimum value is at most the average value, hence

\[ s\leq B:=h+\sum_{g:v_g>0}v_gq_g. \]

We can also detect the zero-benchmark case and obtain a positive rational lower bound otherwise.

If \(h>0\), giving everyone the constant cake share \(1\) shows \(s\geq h\). Set \(L_0=h\).

Suppose \(h=0\), and put \(Q=\sum_{g:v_g>0}q_g\).

  • If \(Q<1\), then \(s=0\). Indeed, the mass of recipients getting at least one positively valued item is at most the expected number of such items, which is at most \(Q<1\). Some positive mass therefore has value at most zero.
  • If \(Q\geq1\), choose rational masses \(t_g\leq q_g\) summing to \(1\), and give mass \(t_g\) one item of kind \(g\). Thus \(s\geq L_0:=\min_{g:v_g>0}v_g>0\). Goods with zero supply may be omitted from this minimum.

In every positive-benchmark case, \(L_0\) is attained by an explicit partition, so the target-\(L_0\) LP is feasible by necessity.

Initialize \(L=L_0\), \(U=B\), retaining a feasible LP solution at \(L\). Repeatedly test the midpoint \(z=(L+U)/2\):

  • if its LP is feasible, replace \(L\) by \(z\) and retain the solution;
  • otherwise replace \(U\) by \(z\).

Throughout this procedure, \(U\geq s\), because every infeasible test implies \(s\leq z\). Also, the retained LP at \(L\) is feasible. Stop when

\[ U-L\leq\delta L_0. \]

The number of iterations is polynomial in the input bit length: \(B\) and \(L_0\) are positive rationals of polynomial encoding length, and the interval width halves at each iteration.

At termination,

\[ L\geq U-\delta L_0 \geq s-\delta L_0 \geq(1-\delta)s. \]

Applying the constructive sufficiency result to the retained LP gives minimum recipient value at least

\[ (1-\delta)L\geq(1-\delta)^2s. \]

For any fixed \(0<\epsilon<1\), choose a fixed rational \(\delta\) with \(0<\delta\leq\epsilon/3\). Then \((1-\delta)^2\geq1-\epsilon\), as required. For \(\epsilon\geq1\), the empty allocation already satisfies the requested value inequality.

5. Final allocation and complexity

Run the single-type algorithm for each positive-mass type with positive benchmark. For a zero-benchmark type, give its entire mass the empty bundle and zero cake. Combine the unit-mass allocations as in Section 1.

If subclasses of one type have the same integral bundle, merge them by summing their masses and averaging their constant cake shares with those masses as weights. Feasibility is preserved, and their common lower value bound is preserved because cake value is linear.

For fixed \(\epsilon\), the resulting algorithm has:

  • polynomial running time in the rational input length, \(|T|\), and \(|\mathcal G|\);
  • polynomial output support and polynomial-length rational descriptions;
  • constant, rationally described cake shares;
  • no Robertson–Webb queries if the rational totals \(h_r\) are supplied, and at most one evaluation query per type otherwise.

Set \(\alpha'=1\). The required lower bound on \(\alpha'\) is at most \(1\), and every occupied class receives at least \((1-\epsilon)s_r\).

The crucial feature is the ability to split type mass among integral bundles. This permits both exact preservation of expected item counts during rounding and the combination of independently constructed single-type partitions.
