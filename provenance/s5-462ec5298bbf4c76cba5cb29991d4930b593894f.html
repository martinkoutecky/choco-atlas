Hardness proof. Use the established theorem supplied in the question: computing a designated candidate’s expected plurality score under the uniform distribution on the linear extensions of one strict partial order is \(\mathrm{FP}^{\#\mathrm P}\)-complete under polynomial-time Turing reductions. The cited paper’s Theorem 11 and its proof explicitly establish hardness using a single partial-order voter. [Ping and Stoyanovich, Theorem 11](https://arxiv.org/html/2105.00082v3#S6.SS3).

Given an instance \((C,P,c)\) of that problem, construct an instance of the present problem by retaining \(C,P,c\) and setting
\( \tau=1,\qquad \mu_P=1,\qquad s_m=(1,0,\ldots,0). \)
Every promise is satisfied: the support contains one distinct strict partial order, its mass is positive and sums to one, and, since \(m\ge2\), the scoring vector is nonincreasing with \(s_m(1)>s_m(m)\). All added rational entries have constant bit length, so the construction takes polynomial time and adds \(O(m)\) bits.

The resulting answer is exactly
\( E_\mu(c) = \frac{|\{\pi\in\Omega(P):\pi^{-1}(c)=1\}|}{|\Omega(P)|}, \)
which is the expected plurality score in the source instance. Thus a single oracle call to the present problem solves each source instance. Composing this reduction with the established hardness reduction proves \(\mathrm{FP}^{\#\mathrm P}\)-hardness.

In particular, counting satisfying assignments belongs to \(\mathrm{FP}^{\#\mathrm P}\), and satisfiability is decided by testing whether that count is positive. Consequently, satisfiability has a polynomial-time Turing reduction to the present exact-computation problem, proving the requested \(\mathrm{NP}\)-hardness.

Exact computation and bit complexity. For each supplied type \(P\), define
\( N_P=|\Omega(P)|,\qquad N_{P,j}=|\{\pi\in\Omega(P):\pi^{-1}(c)=j\}|. \)
A finite strict partial order has a linear extension, so \(N_P>0\). Partitioning its extensions according to the position of \(c\) gives
\( \displaystyle E_\mu(c)= \sum_{P\in\operatorname{supp}(\mu)} \frac{\mu_P}{N_P}\sum_{j=1}^{m}s_m(j)N_{P,j}. \)

Both counts are \(\#\mathrm P\) functions. To verify this explicitly, label the candidates by integers and encode a permutation as a fixed-length sequence of those labels. There is exactly one such encoding per permutation. A polynomial-time verifier checks that all labels occur once and that every supplied preference pair is respected. For \(N_{P,j}\), it additionally checks the position of \(c\). Counting accepted witnesses therefore gives precisely the stated counts.

Hence \(\tau(m+1)\) counting-oracle calls suffice. Their descriptions have polynomial size in \(m,\tau,L\).

Exact rational arithmetic also has polynomial bit complexity. Indeed, \(N_P\le m!\), so each count has \(O(m\log m)\) bits. Write
\( s_m(j)=a_j/b_j,\qquad \mu_P=u_P/v_P, \)
with positive denominators, and let
\( D=\prod_{j=1}^{m}b_j,\qquad B=\prod_{P\in\operatorname{supp}(\mu)}v_P. \)
The total bit length of these supplied denominators is at most \(L\). A common denominator for the displayed expectation is
\( Q=BD\prod_{P\in\operatorname{supp}(\mu)}N_P, \)
whose bit length is \(O(L+\tau m\log m)\).

Furthermore, positive masses summing to one and uniform extension probabilities make \(E_\mu(c)\) a convex combination of scoring entries. Thus
\( |E_\mu(c)|\le\max_j|s_m(j)|. \)
The numerator over \(Q\) consequently also has \(O(L+\tau m\log m)\) bits. Forming the sum and reducing the resulting fraction therefore takes \(\operatorname{poly}(m,\tau,L)\) bit operations.

This proves membership in \(\mathrm{FP}^{\#\mathrm P}\), completing the stronger classification. An unconditional exact algorithm can enumerate all permutations for each supplied type, compute these counts, and evaluate the formula in \(\tau m!\operatorname{poly}(m,\tau,L)\) time. A polynomial-time exact algorithm for all inputs would imply \(\mathrm P=\mathrm{NP}\).
