The continuous mirror question, as graded

Given rational masses over finitely many complete monotone additive valuation types, integral bundle classes built from repeated indivisible item copies with rational masses, and a baseline type–bundle incidence promised to be EF1, choose a mass-preserving reassignment of bundle classes and nonnegative subsidies for occupied type–bundle pairs so that every recipient weakly prefers its subsidized bundle to every other occupied recipient's bundle, minimizing total mass-weighted subsidy or maximum subsidy, and determine whether Theorem 1-style polynomial-time bounds hold.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) valuation types with positive binary-rational masses \(a_t\), with \(\sum_t a_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) item kinds, with arbitrarily repeated indivisible copies. Type \(t\) has complete monotone additive valuations given by rational per-copy values \(v_{te}\in[0,1]\). There are \(k\geq1\) distinct bundle classes \(b_j\in\mathbb Z_{\geq0}^{m}\), encoded in binary, with positive binary-rational masses \(c_j\) summing to one; empty bundles are permitted.
An input baseline incidence \(x^0_{tj}\geq0\), encoded as binary rationals, has row sums \(a_t\) and column sums \(c_j\). It is promised EF1: for every two occupied pairs \((t,j),(u,h)\), type \(t\) weakly prefers \(b_j\) to \(b_h\) after removing at most one copy from \(b_h\).
A reassignment is a nonnegative real incidence \(x\) with the same row and column sums. Mass may split among classes, but each recipient receives one intact bundle; bundle contents cannot change. Assign a nonnegative real per-recipient subsidy \(p_{tj}\) to each occupied pair, requiring \(v_t(b_j)+p_{tj}\geq v_t(b_h)+p_{uh}\) whenever \(x_{tj}>0\) and \(x_{uh}>0\); ties are allowed.
For the chosen objective, minimize either \(\sum_{t,j:x_{tj}>0}x_{tj}p_{tj}\) or \(\max_{t,j:x_{tj}>0}p_{tj}\). Given a nonnegative binary-rational budget \(B\), the decision problem asks whether the chosen objective can be at most \(B\).

For each objective, is this decision problem in \(\mathrm P\), or is it NP-hard? State running times in \(m,\tau,k,L\), where \(L\) is the total input bit length.

For finite societies with normalized doubly monotone valuations, an EF1 allocation can be permuted in polynomial time to achieve envy-freeness with maximum subsidy at most \(n-1\) and total subsidy at most \(n(n-1)/2\); this is a guarantee, not a global subsidy-minimization theorem. [Kawase et al.](https://arxiv.org/pdf/2308.11230)

Result

Both decision problems are in \(\mathrm P\). Each reduces exactly to feasibility of a rational linear program with \(\tau k+\tau+k\) variables and \(O(\tau k+\tau+k)\) constraints.

The argument permits mass splitting and preserves every bundle intact. It also applies without the EF1 promise.

1. Envy-freeness forces one subsidy per bundle class

Write \(V_{tj}=v_t(b_j)=\sum_{e=1}^{m}v_{te}b_{je}\).

Suppose \((x,p)\) is feasible and envy-free. If \(x_{tj}>0\) and \(x_{uj}>0\), comparing these two occupied pairs in both directions gives

\(V_{tj}+p_{tj}\ge V_{tj}+p_{uj}\), and \(V_{uj}+p_{uj}\ge V_{uj}+p_{tj}\).

Consequently, \(p_{tj}=p_{uj}\). Thus every recipient of class \(j\) receives the same subsidy, denoted \(q_j\). Since \(c_j>0\), every class has a recipient, so every \(q_j\) is defined.

Similarly, all occupied pairs of a fixed type \(t\) have the same subsidized utility: applying envy-freeness in both directions to \((t,j)\) and \((t,h)\) gives

\(V_{tj}+q_j=V_{th}+q_h\).

Denote this utility by \(U_t\). It is defined because \(a_t>0\).

For every class \(h\), choose an occupied pair receiving that class. Envy-freeness then implies

\(U_t\ge V_{th}+q_h\).

For every occupied pair, equality holds:

\(x_{tj}>0\ \Longrightarrow\ U_t=V_{tj}+q_j\).

2. An exact linear formulation

Consider real variables \(x_{tj}\), \(U_t\), and \(q_j\), subject to:

  • \(x_{tj}\ge0\) for every \(t,j\).
  • \(\sum_jx_{tj}=a_t\) for every \(t\).
  • \(\sum_tx_{tj}=c_j\) for every \(j\).
  • \(q_j\ge0\) for every \(j\).
  • \(U_t-q_j\ge V_{tj}\) for every \(t,j\).
  • \(\sum_ta_tU_t-\sum_jc_jq_j=\sum_{t,j}V_{tj}x_{tj}\).

Every constraint is linear. In particular, the last equality contains no product of variables.

Claim. Feasible solutions of this system correspond exactly to envy-free reassignments with nonnegative subsidies.

Forward direction. Given an envy-free reassignment, construct \(q_j\) and \(U_t\) as in Section 1. The first five constraints hold. Because \(U_t=V_{tj}+q_j\) on occupied pairs,

\(\sum_ta_tU_t=\sum_{t,j}x_{tj}U_t=\sum_{t,j}x_{tj}(V_{tj}+q_j)=\sum_{t,j}V_{tj}x_{tj}+\sum_jc_jq_j\).

This proves the last equality.

Reverse direction. Given a feasible solution of the linear system, define the nonnegative slack

\(s_{tj}=U_t-q_j-V_{tj}\ge0\).

Using the marginal constraints and the last equality yields

\(\sum_{t,j}x_{tj}s_{tj}=\sum_ta_tU_t-\sum_jc_jq_j-\sum_{t,j}V_{tj}x_{tj}=0\).

Every summand is nonnegative. Therefore, whenever \(x_{tj}>0\), we have \(s_{tj}=0\), hence \(U_t=V_{tj}+q_j\).

Assign \(p_{tj}=q_j\) on every occupied pair. For any two occupied pairs \((t,j)\) and \((u,h)\),

\(V_{tj}+p_{tj}=U_t\ge V_{th}+q_h=V_{th}+p_{uh}\).

This is exactly the required envy-freeness condition. The marginal constraints ensure that the reassignment preserves every class’s mass. ∎

3. Both budget constraints are linear

For any envy-free solution, the total subsidy equals

\(\sum_{t,j:x_{tj}>0}x_{tj}p_{tj}=\sum_jq_j\sum_tx_{tj}=\sum_jc_jq_j\).

Thus, for the total-subsidy decision problem, append the single inequality

\(\sum_jc_jq_j\le B\).

Since every class is occupied, the maximum subsidy equals

\(\max_{t,j:x_{tj}>0}p_{tj}=\max_jq_j\).

Thus, for the maximum-subsidy decision problem, append

\(q_j\le B\) for every \(j\).

By the equivalence proved above, each resulting rational linear system is feasible if and only if the corresponding decision instance is a yes-instance. This proves the reduction for both objectives.

4. Welfare characterization and existence

The formulation also explains why it works. Consider the transportation LP

\(\max\sum_{t,j}V_{tj}x_{tj}\),

subject to nonnegativity and the prescribed row and column sums. Its dual is

\(\min\bigl(\sum_ta_tU_t-\sum_jc_jq_j\bigr)\),

subject to \(U_t-q_j\ge V_{tj}\), with \(U_t,q_j\) unrestricted.

The transportation LP is feasible because \(x^0\) has the required marginals. It is bounded because \(x_{tj}\ge0\), \(\sum_{t,j}x_{tj}=1\), and all \(V_{tj}\) are finite. Strong duality therefore gives attained primal and dual optima with equal values. This is the standard finite-dimensional LP duality theorem; see [MIT’s duality notes](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/b23096080e3d2142c3c8337bdcd9d3c7_lect9_19.pdf).

A common shift \(U_t\mapsto U_t+C\), \(q_j\mapsto q_j+C\) preserves every dual constraint and changes the dual objective by

\(C\bigl(\sum_ta_t-\sum_jc_j\bigr)=0\).

Choosing \(C=-\min_jq_j\) makes all class subsidies nonnegative. The shifted dual optimum and a primal optimum therefore satisfy the system in Section 2.

Consequently:

  • An envy-free reassignment with finite nonnegative subsidies always exists.
  • Every envy-free reassignment maximizes transportation welfare: its primal and dual feasible solutions have equal objective values.
  • Conversely, every welfare-maximizing incidence can be paired with every nonnegative dual optimum. The nonnegative-slack calculation in Section 2 proves equality on its occupied pairs.

Both subsidy minima are attained. For total subsidy, minimize \(\sum_jc_jq_j\) over the system. For maximum subsidy, add a variable \(z\), impose \(z\ge q_j\) for every \(j\), and minimize \(z\). These are nonempty rational LPs with objectives bounded below by zero.

5. Encoding and running time

Let \(N=\tau k+\tau+k\).

Each derived value \(V_{tj}\) has \(O(L)\) bits. To see this, write \(v_{te}=r_{te}/d_{te}\) and use the common denominator \(D_t=\prod_ed_{te}\). Its bit length is at most the sum of the input denominator lengths. The numerator

\(\sum_er_{te}b_{je}(D_t/d_{te})\)

also has \(O(L)\) bits: each factor comes from the input or from \(D_t\), and summation contributes only \(O(\log m)\) additional bits.

Computing all values by elementary exact rational arithmetic takes \(O(m\tau kL^2)\) bit operations. The decision LP has exactly \(N\) variables and \(O(N)\) constraints; a dense encoding has length \(O(N^2L)\).

Rational LP feasibility is decidable exactly in time polynomial in its binary encoding length; this standard bit-complexity guarantee is recalled in [Dadush et al., Section 1](https://link.springer.com/article/10.1007/s10107-023-01956-2). Hence a valid running-time bound for either objective is

\(O(m\tau kL^2)+\bigl((\tau k+\tau+k)^2L\bigr)^{O(1)}\)

bit operations.

This bound depends on the listed support size \(\tau\) and the binary descriptions of the bundles. It requires neither enumerating possible valuation types nor expanding repeated copies. Empty bundles and the cases \(m=1\), \(\tau=1\), or \(k=1\) are covered by the same proof.
