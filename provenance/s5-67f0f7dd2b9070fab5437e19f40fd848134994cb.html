The continuous mirror question, as graded

Given a finite multigraph template \(H=(R,F)\) with rational additive endpoint valuations normalized so each role values some incident edge at \(1\), consider copies indexed by \(x\in[0,1]\). Each role \(r\) has population share \(1/|R|\); each edge \((f,x)\) is indivisible and assigned to an endpoint in its copy, and agents value only goods in their own copy according to the template valuations. Can an algorithm compute measurable orientations and nonnegative payments \(p_r(x)\) that are envy-free between every pair of agents, including agents in different copies, and satisfy \(\frac{1}{|R|}\sum_{r\in R}\int_0^1 p_r(x)\,dx\le\frac12\)?

Packaged proof task (what the prover saw — nothing else)

Input is a loopless finite multigraph \(H=(R,F)\), with \(\tau=|R|\ge2\), \(m=|F|\), and binary-rational endpoint values \(w_r(f)\in[0,1]\), satisfying \(\max_{f\ni r}w_r(f)=1\) for every role \(r\).
A society is given by its support: the list of its \(\tau\) positive-mass role types, each with binary-rational mass \(1/\tau\); \(\tau\) is the support size, not the number of possible types. Copy labels are additional identities within each role type. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Agents are \((r,x)\in R\times[0,1]\), with Lebesgue population measure scaled by \(1/\tau\). Every indivisible good \((f,x)\) must be assigned to exactly one endpoint agent in copy \(x\). Orientations must be measurable in \(x\).
Write \(A_r(x)\subseteq F\) for the template edges assigned to \((r,x)\). Define \(v_{r,x}(A_s(y))=\sum_{f\in A_s(y),\,f\ni r}w_r(f)\) when \(x=y\), and \(v_{r,x}(A_s(y))=0\) otherwise.
Payments \(p_r:[0,1]\to\mathbb R_{\ge0}\) are measurable, integrable, and finite everywhere. Envy-freeness requires \(v_{r,x}(A_r(x))+p_r(x)\ge v_{r,x}(A_s(y))+p_s(y)\) for every \(r,s,x,y\), including measure-zero copies. The budget is \(\tau^{-1}\sum_{r\in R}\int_0^1p_r(x)\,dx\le\tfrac12\).

Is deciding whether such a measurable orientation and payment system exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For the finite normalized additive model, an envy-free orientation with total subsidy at most \(\lfloor n/2\rfloor\) is computable in polynomial time ([source](https://www.ijcai.org/proceedings/2026/387)).
Minimum-subsidy orientation is \(\mathrm{NP}\)-hard even for simple graphs with bi-valued additive valuations ([source](https://arxiv.org/abs/2502.13671)); this is a different objective. No result for this exact continuous model was identified in the search.

Modeling choices made when packaging the task

  • Specified loopless graphs, at least two roles, nonnegative endpoint values bounded by 1, and exact per-role maximum 1, following the discrete domain.
  • Interpreted the finite support as role templates, with copy labels treated as identities within types; literal valuations over labeled goods would otherwise give infinitely many types.
  • Specified Lebesgue measure, total population mass 1, and uniform role masses.
  • Made cross-copy bundle values zero and required envy-freeness everywhere, retaining the stated every-pair requirement rather than replacing it with an almost-everywhere condition.
  • Required payments to be finite everywhere and integrable.
  • Formulated the complexity target as measurable feasibility, avoiding an unspecified finite encoding of arbitrary measurable output functions.

Result

The decision problem is in \(\mathrm P\). In fact, every input satisfying the stated hypotheses is a YES instance. The reason is that a finite envy-free orientation can be repeated identically in every copy, including copies of measure zero.

1. Apply the finite theorem

For each role \(r\), define its finite valuation on template bundles by

\(V_r(S)=\sum_{f\in S,\,f\ni r}w_r(f)\).

These valuations are additive and nonnegative, vanish on nonincident edges, and satisfy \(\max_{f\in F}V_r(\{f\})=1\). Thus the finite instance has exactly \(\tau\) agents and satisfies the normalization required by Theorem 2 of [Li, Sun, and Xing, *Eliminating Envy in Multigraphs Through Subsidy*](https://www.ijcai.org/proceedings/2026/0387.pdf).

That theorem supplies an orientation \((B_r)_{r\in R}\) and nonnegative subsidies \((q_r)_{r\in R}\) satisfying

\(V_r(B_r)+q_r\ge V_r(B_s)+q_s\qquad\text{for every }r,s\in R,\)

and

\(\sum_{r\in R}q_r\le\lfloor\tau/2\rfloor.\)

Here the bundles partition \(F\), and every edge belongs to a bundle of one of its endpoints.

2. Lift the orientation to every copy

For every \(x\in[0,1]\), set

\(A_r(x)=B_r,\qquad p_r(x)=q_r.\)

Each good \((f,x)\) is consequently assigned to exactly one endpoint agent in copy \(x\). Every edge’s assignment is constant in \(x\), hence measurable. The payments are constant, nonnegative, finite everywhere, and integrable.

We verify envy-freeness for arbitrary \(r,s\in R\) and \(x,y\in[0,1]\).

Same copy. If \(x=y\), the finite envy-free inequalities give

\(v_{r,x}(A_r(x))+p_r(x)=V_r(B_r)+q_r\ge V_r(B_s)+q_s=v_{r,x}(A_s(y))+p_s(y).\)

Different copies. If \(x\ne y\), the compared bundle has value zero. Nonnegativity gives \(V_r(B_s)\ge0\), so the same finite inequality implies

\(v_{r,x}(A_r(x))+p_r(x)=V_r(B_r)+q_r\ge V_r(B_s)+q_s\ge q_s=v_{r,x}(A_s(y))+p_s(y).\)

These arguments hold pointwise for all copies, without any exceptional set.

3. Verify the budget

Since each payment is constant and each role has population mass \(1/\tau\),

\(\displaystyle \frac1\tau\sum_{r\in R}\int_0^1p_r(x)\,dx=\frac1\tau\sum_{r\in R}q_r\le\frac{\lfloor\tau/2\rfloor}{\tau}\le\frac12.\)

Thus the constructed system satisfies every requirement.

4. Running time and the optimization distinction

Under the promised input conditions, the decision algorithm reads the input and returns YES, taking \(O(L+m+\tau)\) time. No enumeration of possible role types or copy labels is needed.

A finite description of a witnessing system is also computable in \((m+\tau+L)^{O(1)}\) time using the cited finite algorithm: output its template orientation and interpret its subsidies as constant functions. Exact rational computation has polynomial bit complexity because the algorithm uses polynomially many additions, subtractions, comparisons, and maxima of rational values. A common denominator obtained from the input denominators has \(O(L)\) bits, and polynomially many such operations preserve polynomial bit length.

The hardness of minimizing subsidy concerns finding the optimum. Here the prescribed budget is guaranteed sufficient by the normalized finite theorem, and the pointwise lifting argument transfers that guarantee to the continuous model.
