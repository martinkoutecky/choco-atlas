The continuous mirror question, as graded

Given one activity, a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), an integer population scale \(H\) with \(H\mu_t\in\mathbb{Z}\), and rational preferences \(p_t\) and weights \(w_{tu}\), with \(w_{tt}=0\), choose active masses \(x_t\in[0,\mu_t]\); the rest of each type goes to the void activity. The per-capita welfare is \(F(x)=\sum_t x_t p_t+H\sum_{t,u}x_tx_uw_{tu}\), and the void allocation ensures \(\mathrm{OPT}\ge 0\). Does a polynomial-time algorithm in the input bit length exist for some fixed \(\alpha\ge 1\) that always returns feasible \(x\) with \(F(x)\ge \mathrm{OPT}/\alpha\) whenever \(\mathrm{OPT}>0\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq 1\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There is one activity, so \(m=1\), and a void activity giving zero utility and no interactions. The input includes a binary-encoded integer population scale \(H\geq 2\), with \(H\mu_t\in\mathbb{Z}\) for every type, arbitrary signed rational activity preferences \(p_t\), and arbitrary signed rational directed weights \(w_{tu}\), with \(w_{tt}=0\); symmetry is not required.
An allocation chooses real active masses \(0\leq x_t\leq\mu_t\); the remaining mass goes to the void. There is no integrality constraint on active masses. Define per-capita welfare by \(F(x)=\sum_{t\in T}x_tp_t+H\sum_{t,u\in T}x_tx_uw_{tu}\), where the second sum counts ordered pairs, and define \(\mathrm{OPT}=\max_{0\leq x\leq\mu}F(x)\). The all-void allocation gives \(\mathrm{OPT}\geq 0\). Let \(L\) be the total binary input length, including \(H\).

Does there exist a fixed constant \(\alpha\geq 1\) and an algorithm running in time polynomial in \(m,\tau,L\) that returns feasible rational masses \(x\) satisfying \(F(x)\geq\mathrm{OPT}/\alpha\) whenever \(\mathrm{OPT}>0\), or is achieving any fixed constant multiplicative approximation NP-hard?

For finite agents, with arbitrary signed preferences and weights, no polynomial-time algorithm guarantees a bounded multiplicative approximation of maximum utilitarian welfare, even with one activity, unless \(\mathsf{P}=\mathsf{NP}\).

Modeling choices made when packaging the task

  • Required H to be at least 2, carrying over the discrete model's minimum population of two agents.
  • Specified that preferences and weights may have either sign and that weights are directed without a symmetry requirement, following the discrete valuation domains.
  • Specified binary encoding of H and included all numerical input in L, so polynomial time does not mean polynomial in the population scale.
  • Required algorithmic outputs to be rational masses in binary representation, while retaining real masses as the feasible optimization domain.

Result

Achieving any fixed finite multiplicative approximation is \(\mathsf{NP}\)-hard. Thus the requested polynomial-time algorithm cannot exist unless \(\mathsf{P}=\mathsf{NP}\). This holds even with symmetric integer interaction weights, equal dyadic masses, and \(H=\tau\).

The proof accounts explicitly for the absence of integrality constraints.

1. Fractional allocations cannot outperform all corners

Lemma. For every feasible allocation \(x\), there is a feasible allocation \(z\) with \(z_t\in\{0,\mu_t\}\) for every type and \(F(z)\geq F(x)\). Consequently,

\(\mathrm{OPT}=\max_{z\in\prod_{t\in T}\{0,\mu_t\}}F(z).\)

Proof. Fix all coordinates except \(x_t\). Because \(w_{tt}=0\), welfare is affine in \(x_t\):

\(F(x)=C+x_t\left(p_t+H\sum_{u\neq t}x_u(w_{tu}+w_{ut})\right),\)

where \(C\) is independent of \(x_t\). If the coefficient of \(x_t\) is nonnegative, replacing \(x_t\) by \(\mu_t\) cannot decrease welfare. If it is negative, replacing \(x_t\) by zero cannot decrease welfare.

Apply this operation once to each coordinate, using its coefficient at the time of replacement. Every replacement preserves feasibility and does not decrease welfare. The final allocation is a corner. Since the corners themselves are feasible, the claimed equality follows. \(\square\)

2. A polynomial reduction from CLIQUE

We use the standard \(\mathsf{NP}\)-completeness of CLIQUE: given a simple undirected graph \(G\) and an integer \(k\), decide whether \(G\) contains a clique of size at least \(k\). See [Karp, *Reducibility among Combinatorial Problems*](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

We may restrict to instances with \(3\leq k\leq n\), where \(n\) is the number of vertices. The excluded cases are polynomial-time decidable and can be mapped to fixed yes or no instances satisfying this restriction.

Let \(N\) be the smallest power of two with \(N\geq n\). Add \(N-n\) isolated vertices to obtain a graph \(G'\). Because \(k\geq3\), this padding preserves whether a clique of size at least \(k\) exists.

Construct a society as follows:

  • There is one activity and one type for each vertex of \(G'\), so \(\tau=N\).
  • Set \(\mu_t=1/N\) for every type and \(H=N\).
  • Set \(p_t=-(k-2)\) for every type.
  • Set \(w_{tt}=0\). For distinct types, set \(w_{tu}=w_{ut}=1\) when their vertices are adjacent, and \(w_{tu}=w_{ut}=-N^2\) otherwise.

All masses are positive dyadic rationals summing to one, and \(H\mu_t=1\). The preferences and weights are integers of bit length \(O(\log N)\). Since \(N<2n\), the full construction has polynomial binary length and takes polynomial time.

3. Positive welfare exactly detects a sufficiently large clique

A corner allocation corresponds to a subset \(S\) of vertices: its active coordinates equal \(1/N\), and its other coordinates equal zero.

Write \(s=|S|\). Let \(e(S)\) be the number of unordered adjacent pairs within \(S\), and let \(q(S)\) be the number of unordered nonadjacent pairs within \(S\). The interaction sum counts both directions. Therefore,

\(F(S)=\frac{1}{N}\left(-(k-2)s+2e(S)-2N^2q(S)\right).\)

There are two cases.

If \(S\) is not a clique, then \(q(S)\geq1\). Since \(k\geq3\) and \(2e(S)\leq N(N-1)\),

\(NF(S)\leq N(N-1)-2N^2=-N^2-N<0.\)

If \(S\) is a clique, then \(q(S)=0\) and \(2e(S)=s(s-1)\). Hence,

\(F(S)=\frac{s(s-k+1)}{N}.\)

For integer \(s\geq0\), this is positive exactly when \(s\geq k\): it is zero at \(s=0\) and \(s=k-1\), and negative for \(1\leq s<k-1\).

Thus a corner has positive welfare exactly when its active vertices form a clique of size at least \(k\). By the lemma, a fractional allocation has positive welfare only if some corner does. Consequently,

\(\mathrm{OPT}>0\quad\Longleftrightarrow\quad G\text{ contains a clique of size at least }k.\)

More precisely, a yes instance has \(\mathrm{OPT}\geq k/N\), while a no instance has \(\mathrm{OPT}=0\).

4. Consequence for multiplicative approximation

Suppose that, for some fixed finite \(\alpha\geq1\), a polynomial-time algorithm returns feasible rational masses \(x\) satisfying \(F(x)\geq\mathrm{OPT}/\alpha\) whenever \(\mathrm{OPT}>0\).

Apply it to the constructed society and accept the CLIQUE instance exactly when \(F(x)>0\).

  • In a yes instance, \(F(x)\geq k/(\alpha N)>0\).
  • In a no instance, every feasible allocation has welfare at most zero, so \(F(x)\leq0\).

This sign test is exact and polynomial-time: a polynomial-time algorithm has polynomial output length, and evaluating the rational quadratic expression requires only polynomially many operations on numbers of polynomial bit length.

The assumed approximation algorithm therefore decides CLIQUE in polynomial time, implying \(\mathsf{P}=\mathsf{NP}\).

5. The hardness persists under a strictly positive optimum promise

The zero optimum in the preceding reduction is not essential.

Fix an integer \(A\geq\alpha\). Choose instead a power of two \(N\geq n+1\), keep the graph types and their coefficients as above, and add one independent bonus type with preference \(1/A\). Give every remaining padding type preference zero. All interactions involving bonus or padding types are zero, and all masses remain \(1/N\), with \(H=N\).

The bonus type contributes a maximum of \(1/(AN)\), independently of the graph types. The same corner calculation shows:

  • A no instance has \(\mathrm{OPT}=1/(AN)\).
  • A yes instance has \(\mathrm{OPT}\geq(k+1/A)/N\).

Both optima are strictly positive. In a yes instance, the approximation guarantee gives

\(F(x)\geq\frac{k+1/A}{\alpha N}>\frac{1}{AN},\)

because \(Ak+1>\alpha\). In a no instance, feasibility gives \(F(x)\leq1/(AN)\). Comparing the returned welfare with this rational threshold again decides CLIQUE.

Therefore every fixed constant multiplicative approximation is \(\mathsf{NP}\)-hard even when all instances supplied to the algorithm satisfy \(\mathrm{OPT}>0\).
