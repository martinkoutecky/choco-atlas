The continuous mirror question, as graded

Given a finite alternative set \(A\), a finite-support rational distribution \(\mu\) over complete rankings of \(A\), a target \(c\), and rational pair thresholds \(\lambda_{\{a,b\}}\in[0,1]\), choose masses \(x_{t,R}\ge 0\) assigning each ranking type \(t\)'s mass among partial orders \(R\) consistent with \(t\), with \(\sum_R x_{t,R}=\mu_t\). Let \(\nu_R=\sum_t x_{t,R}\); require at least \(\lambda_{\{a,b\}}\) total mass to report \(a\) and \(b\) as comparable for every pair. Is there such an assignment for which \(c\) uniquely minimizes maximum plurality regret, where regret is maximized over all completions that distribute each \(\nu_R\) among complete rankings extending \(R\)?

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge 2\) alternatives, with target \(c\in A\). A society is given by its support: the list of \(\tau\) distinct strict complete rankings \(t\) with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Each unordered pair has a binary-rational threshold \(\lambda_{\{a,b\}}\in[0,1]\); let \(L\) be the total input bit length.
For each type \(t\), distribute its mass using real variables \(x_{t,R}\ge0\) over all strict partial orders \(R\subseteq t\), including the empty order, with \(\sum_{R\subseteq t}x_{t,R}=\mu_t\). Set \(\nu_R=\sum_t x_{t,R}\), taking incompatible assignments as zero.
Require \(\sum_{R:\,aRb\text{ or }bRa}\nu_R\ge\lambda_{\{a,b\}}\) for every unordered pair; comparability includes all relations implied by transitivity.
A completion assigns real masses \(y_{R,r}\ge0\) to strict complete rankings \(r\) extending \(R\), with \(\sum_{r\supseteq R}y_{R,r}=\nu_R\). Completions need only respect reported orders, without preserving the original type distribution. Let \(s(a,y)\) denote the mass-weighted plurality score and define \(\operatorname{MR}(a,\nu)=\max_y\bigl(\max_{b\in A}s(b,y)-s(a,y)\bigr)\).
The decision problem asks whether an admissible assignment satisfies \(\operatorname{MR}(c,\nu)<\operatorname{MR}(a,\nu)\) for every \(a\ne c\); ties do not give a unique winner.

Is this continuous plurality manipulative-elicitation problem with pair thresholds solvable in time polynomial in \(m,\tau,L\), or is it \(\mathsf{NP}\)-hard?

For explicitly listed discrete voters and integer pair limits, the corresponding unique-winner problem is \(\mathsf{NP}\)-complete; without pair limits, discrete plurality manipulative elicitation is polynomial-time solvable. [Source](https://arxiv.org/pdf/1711.03948)
No result settling the exact divisible-mass problem above was identified in the literature search.

Modeling choices made when packaging the task

  • Made probability normalization explicit: positive support masses sum to one.
  • Used strict complete rankings and strict partial orders, allowing empty reports and counting transitive comparabilities.
  • Allowed arbitrary nonnegative real assignment and completion masses, as the natural divisible-mass interpretation.
  • Restricted the alternative domain to at least two alternatives, consistent with nonconstant plurality scoring.
  • Interpreted pair limits as constraints on reported partial orders. The discrete definition mistakenly writes the original complete profile in this constraint; the full version repeats the typo, but its reductions enforce limits on reports.
  • Made completion freedom explicit: completions preserve reported orders and their masses, rather than the original distribution over complete rankings.
  • Specified strict regret inequalities with no tie-breaking and defined L as total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The divisible-mass problem is polynomial-time solvable. It admits an exact reduction to \(m(m-1)\) rational linear programs, each of polynomial size.

1. Plurality regret depends only on possible first alternatives. For a strict partial order \(R\), define
\[ M(R)=\{a\in A:\text{there is no }b\in A\text{ with }bRa\}. \]
These are precisely the alternatives that can appear first in a completion: every first alternative must belong to \(M(R)\), and any member of \(M(R)\) can be placed first, followed by a topological ordering of the remaining alternatives.

Define the possible-first mass and forced-first mass of \(a\) by
\[ U_a=\sum_{R:\,a\in M(R)}\nu_R, \qquad F_a=\sum_{R:\,M(R)=\{a\}}\nu_R. \]

For distinct \(a,b\), the maximum contribution per unit mass of \(R\) to \(s(b,y)-s(a,y)\) is:

  • \(1\) if \(b\in M(R)\), by placing \(b\) first;
  • \(-1\) if \(M(R)=\{a\}\), since \(a\) must appear first;
  • \(0\) otherwise, by placing a member of \(M(R)\setminus\{a\}\) first.

Completion choices for different reported orders are independent. Consequently,
\[ \max_y\bigl(s(b,y)-s(a,y)\bigr)=U_b-F_a. \]
Including \(b=a\), whose score difference is zero, gives
\[ \operatorname{MR}(a,\nu) = \max\left\{0,\ \max_{b\ne a}U_b-F_a\right\}. \tag{1} \]

2. We may saturate every reported order without changing regret. Let \(o_t\) be the first alternative of type \(t\). Every order \(R\subseteq t\) has \(o_t\in M(R)\).

For any \(S\subseteq A\) containing \(o_t\), define
\[ R_t(S)=\{(a,b):a\text{ precedes }b\text{ in }t,\ b\notin S\}. \tag{2} \]
This is a strict partial order. Indeed, it is irreflexive, and if \(aR_t(S)b\) and \(bR_t(S)d\), then \(a\) precedes \(d\) in \(t\) and \(d\notin S\), so \(aR_t(S)d\).

Its maximal set is exactly \(S\): no element of \(S\) has an incoming relation, while every \(b\notin S\) has \(o_tR_t(S)b\).

Moreover, if \(S=M(R)\) and \(R\subseteq t\), then
\[ R\subseteq R_t(S). \]
For an original relation \(aRb\), the alternative \(b\) is not maximal, so that relation appears in (2).

Thus replacing each assigned order \(R\) by \(R_t(M(R))\):

  • preserves its possible first alternatives and whether its first alternative is forced;
  • hence preserves every regret by (1);
  • weakly increases comparability for every pair.

Because all pair constraints are lower bounds, this replacement preserves admissibility. Therefore, restricting attention to orders of the form \(R_t(S)\) loses no successful assignments.

3. These distributions have an exact polynomial-size description. For each type \(t\), introduce variables
\[ z_t=\text{mass assigned to }S=\{o_t\}, \]
and, for each \(a\ne o_t\),
\[ q_{t,a}=\text{mass assigned to sets }S\text{ containing }a. \]
Put \(v_t=\mu_t-z_t\). The exact constraints describing these marginals are
\[ 0\le z_t\le\mu_t, \qquad 0\le q_{t,a}\le v_t\quad(a\ne o_t), \qquad \sum_{a\ne o_t}q_{t,a}\ge v_t. \tag{3} \]

Necessity follows because the mass \(v_t\) is assigned to sets containing at least one alternative besides \(o_t\).

For sufficiency, if \(v_t=0\), assign all mass to \(\{o_t\}\). Otherwise, set \(p_a=q_{t,a}/v_t\). The conditions in (3) give
\[ p\in Q_k = \left\{p\in[0,1]^k:\sum_{i=1}^k p_i\ge1\right\}, \qquad k=m-1\ge1. \]

We claim that \(Q_k\) is the convex hull of the incidence vectors of nonempty subsets.

To prove this, consider a point with a fractional coordinate. If its coordinate sum is strictly greater than \(1\), a sufficiently small positive and negative perturbation of that coordinate stays in \(Q_k\), so the point is not a vertex. If its coordinate sum equals \(1\) and it has at least two fractional coordinates, opposite perturbations of those two coordinates preserve the sum and again show that it is not a vertex. Exactly one fractional coordinate is impossible when the sum equals \(1\), because all other coordinates are integers.

Thus every vertex of \(Q_k\) is an incidence vector of a nonempty subset. Since \(Q_k\) is a nonempty bounded polytope, it is the convex hull of its vertices. Decomposing \(p\) accordingly, assigning total mass \(v_t\) to those nonempty extra subsets, and adding mass \(z_t\) to \(\{o_t\}\) realizes all the specified marginals.

Now let \(\ell_t(a,b)\) denote the lower-ranked member of the pair \(\{a,b\}\) in \(t\). This alternative is never \(o_t\). By (2), the pair is comparable exactly when \(\ell_t(a,b)\notin S\). Its total comparable mass is therefore
\[ 1-\sum_t q_{t,\ell_t(a,b)}. \]
The pair constraints become the linear inequalities
\[ \sum_t q_{t,\ell_t(a,b)} \le 1-\lambda_{\{a,b\}} \qquad\text{for every unordered pair }\{a,b\}. \tag{4} \]

The quantities needed for regret are also linear:
\[ U_a = \sum_{t:\,o_t=a}\mu_t + \sum_{t:\,o_t\ne a}q_{t,a}, \qquad F_a=\sum_{t:\,o_t=a}z_t. \tag{5} \]

Equations (3)–(5) are an exact description: every admissible assignment can be saturated to yield such variables, and every solution yields an admissible assignment using the orders \(R_t(S)\).

4. The strict unique-winner condition reduces to polynomially many linear programs. Enumerate all ordered pairs of distinct alternatives \((p,q)\). In the linear program for \((p,q)\), impose
\[ U_p\ge U_a\quad(a\in A), \qquad U_q\ge U_a\quad(a\ne p). \tag{6} \]
Thus \(p\) has greatest possible-first mass and \(q\) has greatest possible-first mass among the remaining alternatives. Ties are permitted.

For this fixed pair, define \(\kappa(p)=q\) and \(\kappa(a)=p\) for \(a\ne p\), and set
\[ d_a=U_{\kappa(a)}-F_a. \]
By (1) and (6),
\[ \operatorname{MR}(a,\nu)=\max\{0,d_a\}. \tag{7} \]

Add variables \(h,\varepsilon\), maximize \(\varepsilon\), and impose (3)–(6) together with
\[ 0\le h\le1,\qquad 0\le\varepsilon\le1, \qquad h\ge d_c, \qquad d_a\ge h+\varepsilon\quad(a\ne c). \tag{8} \]

We prove that the original instance is a yes-instance exactly when at least one of these linear programs has optimum strictly greater than zero.

Suppose first that a feasible solution has \(\varepsilon>0\). The distribution reconstructed in Section 3 is admissible. Since \(h\ge0\) and \(h\ge d_c\), equation (7) gives
\[ \operatorname{MR}(c,\nu)\le h. \]
For every \(a\ne c\), we have \(d_a\ge h+\varepsilon>0\), so
\[ \operatorname{MR}(a,\nu)=d_a \ge h+\varepsilon >\operatorname{MR}(c,\nu). \]
Hence \(c\) is the unique winner.

Conversely, suppose an admissible assignment makes \(c\) the unique winner. Saturate it as in Section 2, preserving all regrets, and extract its variables from Section 3. Choose \(p,q\) with greatest and second-greatest values of \(U_a\), breaking ties arbitrarily. Conditions (6) hold.

Set
\[ h=\operatorname{MR}(c,\nu), \qquad \varepsilon= \min_{a\ne c} \bigl(\operatorname{MR}(a,\nu)-\operatorname{MR}(c,\nu)\bigr)>0. \]
Every regret lies in \([0,1]\), so these choices respect the bounds in (8). Every rival has strictly positive regret, and therefore (7) gives \(d_a=\operatorname{MR}(a,\nu)\) for every \(a\ne c\). Also \(d_c\le h\). Thus all inequalities in (8) hold with positive \(\varepsilon\).

This proves the equivalence, including the strict treatment of ties.

5. Bit complexity and conclusion. There are \(m(m-1)\) linear programs. Each has \(O(\tau m+m)\) variables, if \(U_a,F_a\) are introduced explicitly, and \(O(\tau m+m^2)\) constraints. All coefficients and right-hand sides are rational and have bit lengths polynomial in \(L,m,\tau\).

Each feasible program has a finite attained optimum: the mass variables are bounded, and \(h,\varepsilon\) are bounded explicitly. Standard polynomial-time algorithms for rational linear programming can determine feasibility and compare the exact optimum with zero. Accepting precisely when some optimum is positive therefore gives an algorithm polynomial in \(m,\tau,L\). No numerical tolerance or rationality assumption on the originally permitted assignments is needed.

The convex decomposition in Section 3 uses the ability to divide each type’s mass among several reported orders. An individual discrete voter cannot be divided this way, so this conclusion is consistent with the discrete hardness result in [Dey, Theorem 4.2](https://arxiv.org/pdf/1711.03948).
