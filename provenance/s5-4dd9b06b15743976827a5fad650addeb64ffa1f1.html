The anchor (named result in the paper)

Proposition 18 — class: hardness

The continuous mirror question, as graded

Given a finite set of attributes with finite domains and a support of \(\tau\) complete agent types, each specified by a GAI utility \(u_t\) on a shared cardinal scale and a binary-rational mass \(\mu_t\) summing to \(1\), find a complete assignment \(o^\star\) maximizing \(U_\mu(o)=\sum_t \mu_t u_t(o)\).

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal X=\{X_1,\ldots,X_m\}\) be attributes with explicitly listed finite domains \(D_i\), each satisfying \(|D_i|\geq 2\). Alternatives are complete assignments \(o\in\prod_{i=1}^m D_i\).
A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Type \(t\) specifies a GAI utility \(u_t(o)=\sum_{j=1}^{q_t}g_{t,j}(o[Z_{t,j}])\), where \(Z_{t,j}\subseteq\mathcal X\) are arbitrary, possibly overlapping scopes. Each local function is an explicit sparse table with entries in \(\mathbb Q\cup\{-\infty\}\); finite entries are signed binary rationals, and omitted tuples have value \(0\).
Utilities use a shared cardinal scale. Define \(U_\mu(o)=\sum_{t=1}^{\tau}\mu_tu_t(o)\), with any sum containing \(-\infty\) equal to \(-\infty\). Return any maximizing assignment; ties, including when every assignment has utility \(-\infty\), may be resolved arbitrarily. Let \(L\) be the total input bit length, including domains, scopes, tables, and masses.

Can an assignment \(o^\star\in\operatorname*{arg\,max}_{o\in\prod_iD_i}U_\mu(o)\) be found in time polynomial in \(m,\tau,L\), or is this optimization problem \(\mathrm{NP}\)-hard?

For a single GAI utility, finding a maximizing assignment is \(\mathrm{NP}\)-hard even when every local scope has at most two attributes; it is polynomial-time solvable when all local scopes are unary. No separate result for distributional societies is supplied here.

Modeling choices made when packaging the task

  • Specified sparse local utility tables with omitted tuples valued at zero, following the discrete GAI representation.
  • Replaced unspecified real-valued finite entries by signed binary rationals to obtain a finite computational input; retained the permitted value negative infinity and specified its arithmetic.
  • Required explicitly listed attribute domains of size at least two, carrying over the discrete domain condition.
  • Allowed arbitrary overlapping scopes without an arity or graphical restriction, as in the stated general GAI question.
  • Specified arbitrary resolution of maximizing ties, including the case where all assignments have utility negative infinity.
  • Defined m as the number of attributes and L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Conclusion

The optimization problem is \(\mathrm{NP}\)-hard, even when \(\tau=1\) and every local scope has at most two attributes. The hardness follows directly from the single-utility hardness supplied in the question.

Proof of hardness

Take an instance of the stated single-GAI maximization problem, with attributes \(\mathcal X\), domains \(D_i\), and utility
\[ u(o)=\sum_{j=1}^{q}g_j(o[Z_j]). \]
Construct a society on the same attributes and domains with exactly one type. Give this type utility \(u_1=u\) and mass \(\mu_1=1\).

This is a valid society: its sole mass is a positive binary rational and the masses sum to \(1\). The construction copies the original utility representation and adds only constant-size mass information, so it takes polynomial time and increases the input length by at most a constant.

For every assignment \(o\), the society’s objective satisfies \(\displaystyle U_\mu(o)=\mu_1u_1(o)=u(o)\). This equality also holds when \(u(o)=-\infty\). Consequently,
\[ \operatorname*{arg\,max}_{o}U_\mu(o) = \operatorname*{arg\,max}_{o}u(o). \]
Thus every maximizing assignment returned for the constructed society solves the original single-GAI instance, regardless of tie-breaking.

The construction preserves every local scope. Applying it to the supplied hard class in which scopes have at most two attributes proves the claimed \(\mathrm{NP}\)-hardness.

Why the distribution does not change the representation class

More generally, any society in the question can be converted into one GAI utility in polynomial time. For each type \(t\) and factor \(j\), retain the scope \(Z_{t,j}\) and define the factor \(h_{t,j}\) by \(\displaystyle h_{t,j}(z)=\mu_tg_{t,j}(z)\), with \(\mu_t(-\infty)=-\infty\).

Because all masses are strictly positive, for every assignment \(o\),
\[ U_\mu(o)=\sum_{t=1}^{\tau}\sum_{j=1}^{q_t}h_{t,j}(o[Z_{t,j}]). \]
Indeed, if any factor evaluates to \(-\infty\), both sides are \(-\infty\); otherwise the equality is ordinary distributivity over finite rational sums.

This conversion preserves sparse tables: omitted tuples remain zero, and no additional tuples need to be listed. Multiplying binary-encoded rationals produces a rational whose bit length is bounded by the sum of the operand bit lengths, up to constant overhead. Hence the converted representation has polynomial bit length and is computable in polynomial time.

Therefore society maximization and single-GAI maximization are polynomially interreducible under the stated representation. In particular, the supplied unary tractability result also transfers to societies whose scopes are all unary, but arbitrary scopes—and already scopes of size at most two—give an \(\mathrm{NP}\)-hard optimization problem.
