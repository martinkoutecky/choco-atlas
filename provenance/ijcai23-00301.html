The continuous mirror question, as graded

Given finite \(Q\), finite type set \(\mathcal T\), colour \(\chi:\mathcal T\to\{R,B\}\), accessibility sets \(S_t\subseteq Q\), rational masses \(\mu_t\ge0\) with \(\sum_t\mu_t=1\), and \(\vartheta\in[0,1]\), find \(x_{tq}\ge0\) satisfying \(x_{tq}=0\) for \(q\notin S_t\) and \(\sum_{q\in S_t}x_{tq}=\mu_t\), such that, with \(\ell_q=\sum_t x_{tq}\), \(r_q=\sum_{\chi(t)=R}x_{tq}\), and \(b_q=\sum_{\chi(t)=B}x_{tq}\), every \(x_{tq}>0\) gives its type no profitable \(q'\in S_t\): for red types \(\min\{r_q/\ell_q,\vartheta\}\ge\min\{r_{q'}/\ell_{q'},\vartheta\}\), and analogously with \(b\) for blue types, interpreting an empty target’s utility as \(\vartheta\).

Packaged proof task (what the prover saw — nothing else)

Given a finite resource set \(Q\), put \(m=|Q|\). A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Each type has a colour \(\chi(t)\in\{R,B\}\) and a nonempty accessibility set \(S_t\subseteq Q\); both colours have positive total mass. The common threshold \(\vartheta\in[0,1]\) is a binary rational. Let \(L\) be the total input bit length.
An allocation consists of divisible masses \(x_{tq}\ge0\), with \(x_{tq}=0\) for \(q\notin S_t\) and \(\sum_{q\in S_t}x_{tq}=\mu_t\). Define \(r_q=\sum_{\chi(t)=R}x_{tq}\), \(b_q=\sum_{\chi(t)=B}x_{tq}\), and \(\ell_q=r_q+b_q\).
For \(\ell_q>0\), set \(u_R(q)=\min\{r_q/\ell_q,\vartheta\}\) and \(u_B(q)=\min\{b_q/\ell_q,\vartheta\}\); for \(\ell_q=0\), set both utilities to \(\vartheta\). An impact-blind equilibrium satisfies \(x_{tq}>0\Rightarrow u_{\chi(t)}(q)\ge u_{\chi(t)}(q')\) for every \(q'\in S_t\). Deviations concern infinitesimal individuals, and ties permit no profitable deviation.

Can an exact impact-blind equilibrium be computed in time polynomial in \(m,\tau,L\), or is computing one NP-hard?

For finite individual agents, an impact-blind equilibrium always exists and can be computed in \(O(e+m\log m)\) time, where \(e\) is the number of accessibility edges ([published result](https://www.ijcai.org/proceedings/2023/0301.pdf)); the [full version](https://arxiv.org/pdf/2305.00843) states \(O((e+m)\log m)\).
No result settling this exact divisible-mass computation problem was located in the literature search.

Modeling choices made when packaging the task

  • Excluded empty accessibility sets: each positive-mass type must have an available resource, as required for the discrete model to admit strategy profiles.
  • Required positive total mass of both colours, carrying over the discrete assumption that both colours are present.
  • Made the threshold a binary rational and defined L as total input bit length, so polynomial-time computation has a finite input model.
  • Used m for the number of resources and reserved tau for the support size.
  • Specified infinitesimal individual deviations and exact computation, preserving the stated divisible-mass equilibrium condition.

Result

An exact impact-blind equilibrium can be computed in time polynomial in \(m,\tau,L\). In fact, there is always an equilibrium assigning each type’s entire mass to a single resource.

The construction is a weighted extension of Algorithm 1 in the cited [full version](https://arxiv.org/pdf/2305.00843). Below is a complete proof for the support-encoded divisible-mass model, including empty resources and bit complexity.

1. It suffices to solve the uncapped problem

For an allocation, define \(v_R(q)=r_q/\ell_q\) and \(v_B(q)=b_q/\ell_q\) when \(\ell_q>0\), and define \(v_R(q)=v_B(q)=1\) when \(\ell_q=0\).

The utilities in the question satisfy \(u_C(q)=\min\{v_C(q),\vartheta\}\) for each colour \(C\). Because truncation is nondecreasing, an allocation satisfying all equilibrium inequalities for \(v_C\) also satisfies them for \(u_C\).

We therefore construct an equilibrium for these uncapped utilities.

2. The weighted greedy algorithm

Maintain a set \(U\) of remaining resources, initially \(Q\). Types are initially unassigned. Every assignment sends the type’s whole mass to one resource and is permanent.

While \(U\) is nonempty, perform the following steps.

  • Assign every unassigned blue type \(t\) with \(|S_t\cap U|=1\) to its unique remaining accessible resource.
  • For every \(q\in U\), compute:

\(a(q)=\sum_{\substack{t\text{ unassigned}\\ \chi(t)=R,\ q\in S_t}}\mu_t\),

\(b(q)=\sum_{\substack{t\text{ assigned to }q\\ \chi(t)=B}}\mu_t\).

Define its score by \(s(q)=a(q)/(a(q)+b(q))\) if \(a(q)+b(q)>0\), and by \(s(q)=0\) otherwise.

  • Choose a resource \(q\in U\) of maximum score, breaking ties arbitrarily.
  • Assign every unassigned red type having access to \(q\) to \(q\).
  • Remove \(q\) from \(U\).

The score-zero convention for \(a(q)=b(q)=0\) is part of the algorithm; it is not a utility assigned to an empty resource.

Feasibility and termination

Every unassigned type always has at least one accessible remaining resource. This holds initially because accessibility sets are nonempty. If removing \(q\) would eliminate an unassigned red type’s last accessible resource, step 4 assigns it to \(q\). If it would eliminate an unassigned blue type’s last accessible resource, step 1 has already assigned it to \(q\).

Thus the invariant holds after every removal. Since exactly one resource is removed per iteration, the algorithm terminates after \(m\) iterations, with every type assigned to an accessible resource.

Let \(f(t)\) denote the assigned resource. Output \(x_{t,f(t)}=\mu_t\) and \(x_{tq}=0\) for all other resources. This is a feasible allocation.

3. Scores are nonincreasing along the removal order

Write \(q_1,\ldots,q_m\) for the removal order. Let \(a_i(q),b_i(q),s_i(q)\) denote the values immediately before selecting \(q_i\), and put \(p_i=s_i(q_i)\).

For a resource that survives an iteration, its available red mass can only decrease and its assigned blue mass can only increase. Hence \(a_{i+1}(q)\le a_i(q)\) and \(b_{i+1}(q)\ge b_i(q)\).

The score is nondecreasing in its first argument and nonincreasing in its second, including the specified zero convention. Explicitly, if \(a'\le a\), \(b'\ge b\), and \(a'>0\), then both denominators are positive and

\(a'b\le ab'\),

which implies \(a'/(a'+b')\le a/(a+b)\). If \(a'=0\), the new score is zero, so the same inequality holds.

Since \(q_i\) has maximum score at iteration \(i\), every surviving resource has score at most \(p_i\), both then and at the next selection. Consequently,

\(p_1\ge p_2\ge\cdots\ge p_m\).

At removal, all remaining accessible red mass is assigned to the selected resource, and its assigned blue mass is already fixed. No later assignment uses a removed resource. Therefore

\(r_{q_i}=a_i(q_i)\) and \(b_{q_i}=b_i(q_i)\).

In particular, if \(q_i\) is occupied, its final red fraction is \(p_i\). If it is empty, \(p_i=0\).

4. Equilibrium proof

Red types

Fix a red type \(t\) assigned to \(q_i\).

The resource \(q_i\) is the first resource of \(S_t\) in the removal order: otherwise, step 4 would have assigned \(t\) when an earlier accessible resource was removed.

Its assigned resource is occupied, because \(\mu_t>0\), and \(v_R(q_i)=p_i\).

Consider another accessible resource \(q_j\). Necessarily \(j>i\).

If \(q_j\) is occupied, score monotonicity gives \(v_R(q_j)=p_j\le p_i=v_R(q_i)\).

If \(q_j\) is empty, a separate argument is necessary. At iteration \(i\), type \(t\) was unassigned and had access to \(q_j\), so \(a_i(q_j)\ge\mu_t>0\). Moreover, \(b_i(q_j)=0\): any blue mass already assigned there would remain there and make its final load positive. Thus \(s_i(q_j)=1\).

The maximum-score choice then forces \(p_i=1\). Hence \(v_R(q_i)=1=v_R(q_j)\), even with the stipulated maximal utility at empty resources.

Every red type therefore satisfies every uncapped equilibrium inequality.

Blue types

Fix a blue type \(t\) assigned to \(q_j\).

The resource \(q_j\) is the last resource of \(S_t\) in the removal order. Indeed, a blue type is assigned only when exactly one accessible resource remains. All its other accessible resources have already been removed.

Its assigned resource is occupied, and \(v_B(q_j)=1-p_j\).

Consider another accessible resource \(q_i\), necessarily with \(i<j\).

If \(q_i\) is occupied, score monotonicity gives

\(v_B(q_i)=1-p_i\le 1-p_j=v_B(q_j)\).

If \(q_i\) is empty, then \(p_i=0\). Since \(0\le p_j\le p_i\), we have \(p_j=0\). Thus \(v_B(q_j)=1=v_B(q_i)\).

Every blue type also satisfies every uncapped equilibrium inequality. By Section 1, the allocation is an exact impact-blind equilibrium for the given threshold \(\vartheta\).

5. Polynomial bit complexity

Let \(e=\sum_t|S_t|\), so \(e\le m\tau\). A straightforward implementation rescans types and accessibility edges in each iteration. It uses \(O(m(e+\tau+m))\) arithmetic operations.

To implement all arithmetic exactly, write \(\mu_t=n_t/d_t\) and let \(D=\prod_t d_t\). The binary length of \(D\) is \(O(L)\), because the denominator encodings form part of the input. Compute the integer weights \(w_t=n_t(D/d_t)\). They satisfy \(\sum_t w_t=D\).

Use these weights instead of masses in the algorithm. Scaling all masses by \(D\) preserves every score. Each available-red sum \(A(q)\) and assigned-blue sum \(B(q)\) is an integer between zero and \(D\).

Represent a positive-denominator score by the pair \((A(q),A(q)+B(q))\), and represent a zero score arising from a zero denominator by \((0,1)\). Compare scores by integer cross multiplication. All operands and products have \(O(L)\) bits, so each arithmetic operation takes polynomial time in \(L\).

There are polynomially many operations, and the output entries are simply zero or original input masses. Thus the algorithm computes an exact equilibrium in polynomial time in \(m,\tau,L\), without expanding rational masses into individual agents.

The map \(z\mapsto\min\{z,\vartheta\}\) preserves weak inequalities. Consequently, every uncapped equilibrium inequality implies the corresponding capped inequality. This also covers both threshold endpoints and permits ties as required.

3. Algorithm, feasibility, and termination

Correct. The invariant that every unassigned type has an accessible remaining resource holds initially by the nonempty-accessibility hypothesis.

For each removal:

  • An unassigned red type accessing the selected resource is assigned there in step 4.
  • An unassigned blue type whose last accessible remaining resource is selected has exactly one remaining option at step 1 and is assigned there before removal.

Thus removal cannot leave an unassigned type without an accessible remaining resource. Assignments themselves do not change accessibility or the remaining-resource set, so processing all qualifying blue types in step 1 introduces no ordering ambiguity.

After exactly \(m\) removals, the invariant rules out any unassigned type. Every assignment uses an accessible resource and transfers exactly the type’s input mass. The resulting allocation satisfies all feasibility conditions.

4. Score monotonicity and final resource fractions

Correct. For surviving resources, removing and assigning red types can only decrease available red mass. Permanent blue assignments can only increase assigned blue mass.

The fraction comparison is valid. When \(a'>0\), both denominators are positive, and the assumptions imply \(a'b\le ab'\), which is precisely the cross-multiplication condition for the claimed score inequality. When \(a'=0\), the score is zero whether its denominator is positive or zero. This verifies the boundary case under the algorithm’s explicit convention.

Maximum-score selection therefore yields \(p_{i+1}\le p_i\), including arbitrary tie-breaking.

The final-load identities are also justified:

  • Red types are assigned only when their selected resource is removed. Thus no red mass is already assigned to a surviving resource.
  • Step 4 assigns exactly its available red mass.
  • Its blue mass is already assigned when its score is evaluated.
  • No subsequent assignment can use a removed resource.

Consequently, every occupied \(q_i\) has final red fraction \(p_i\), while an empty \(q_i\) has \(p_i=0\). The proof correctly avoids interpreting this artificial zero score as the utility of an empty resource.

5. Red equilibrium inequalities

Correct. A red type is assigned at the first removal of an accessible resource. Every distinct accessible alternative therefore occurs later in the removal order.

For an occupied alternative, the desired inequality follows from score monotonicity and the final-fraction identities.

The empty-alternative argument is valid and essential. At the assigning iteration, that alternative contains positive available red mass from the type under consideration. It has no assigned blue mass, since such mass would persist and contradict its final emptiness. Its score is therefore one. Maximum-score selection forces the assigned resource’s red fraction to be one as well, so the empty alternative offers no strictly greater uncapped utility.

Comparison with the assigned resource itself is equality. Thus every accessible alternative is covered.

For an occupied earlier alternative, the blue-fraction inequality follows by subtracting the nonincreasing red fractions from one.

For an empty earlier alternative, its score is zero. Monotonicity and nonnegativity force the assigned resource’s score to be zero too. Because that resource contains the type’s positive blue mass, it is occupied and its blue fraction is one. This matches the empty alternative’s uncapped utility.

Together with the red argument and truncation reduction, this establishes every equilibrium inequality in the task.
