The continuous mirror question, as graded

Given a finite type set \(T\), a compatibility graph \(H=(T,F)\), rational type masses \(\mu_t\) summing to \(1\), and nonnegative rational removal costs \(w_t\), choose removed masses \(r_t\in[0,\mu_t]\) to minimize \(\sum_{t\in T} w_t r_t\). For the remaining masses \(q_t=\mu_t-r_t\), the society is stable if there are nonnegative type payoffs \(p_t\) with \(p_t+p_u\ge1\) for each \(\{t,u\}\in F\), and \(\sum_t q_t p_t\) equals the maximum matching mass \(\max\sum_{\{t,u\}\in F}x_{tu}\), subject to \(\sum_{u:\{t,u\}\in F}x_{tu}\le q_t\) for each \(t\) and \(x_{tu}\ge0\). Find a minimum-cost stabilizing removal.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau=|T|\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The compatibility graph \(H=(T,F)\) is simple and undirected; each compatible pair produces unit value. Let \(m=|F|\). Removal costs \(w_t\) and a budget \(B\) are nonnegative binary rationals; \(L\) is the total input bit length.
Choose real removed masses \(0\le r_t\le\mu_t\), costing \(\sum_{t\in T}w_t r_t\), and put \(q_t=\mu_t-r_t\). Remaining masses are not renormalized; removing the entire society is allowed.
Define the maximum matching mass by \(M(q)=\max\{\sum_{\{t,u\}\in F}x_{tu}:x\in\mathbb R_{\ge0}^{F},\ \sum_{u:\{t,u\}\in F}x_{tu}\le q_t\text{ for every }t\in T\}\).
The remaining society is stable if there exist real payoffs \(p_t\ge0\) satisfying \(p_t+p_u\ge1\) for every \(\{t,u\}\in F\) and \(\sum_{t\in T}q_t p_t=M(q)\). Payoffs for zero-mass types are auxiliary variables and contribute nothing to this sum.
The decision problem asks whether a stable removal of cost at most \(B\) exists.

Is this continuous stabilizing-removal decision problem in P or NP-hard, with running times measured in \(m\), \(\tau\), and \(L\)?

For finite agents, minimum-cost vertex removal yielding a matching game with nonempty core is NP-hard; minimizing the number of removed vertices is polynomial-time solvable ([discrete results](https://www.ifaamas.org/Proceedings/aamas2016/pdfs/p41.pdf)).
No prior result settling this exact continuous formulation was identified in the literature search.

Proof that every remaining society is stable

Fix any vector \(q\) satisfying \(0\le q_t\le\mu_t\). Let \(A\) be the vertex-edge incidence matrix of \(H\): the column corresponding to \(\{t,u\}\) has a \(1\) in rows \(t,u\) and zeros elsewhere. Then the program defining matching mass is

\(M(q)=\max\{\mathbf{1}^{\mathsf T}x:Ax\le q,\ x\ge0\}.\)

This program is feasible because \(x=0\) is feasible. Summing its vertex constraints gives

\(2\sum_{e\in F}x_e=\sum_{t\in T}(Ax)_t\le\sum_{t\in T}q_t\le1.\)

Thus its objective is bounded. Its feasible set is also compact: every edge variable satisfies \(0\le x_{\{t,u\}}\le\min(q_t,q_u)\), and all constraints are closed. Consequently, the maximum is attained. When \(F\) is empty, the unique empty edge vector gives value \(0\).

The linear-programming dual is

\(\min\{\sum_{t\in T}q_t p_t:p_t\ge0,\ p_t+p_u\ge1\text{ for every }\{t,u\}\in F\}.\)

To verify this dual explicitly, the constraint \(Ax\le q\) supplies one nonnegative dual variable \(p_t\) per type. Each edge variable supplies the constraint \((A^{\mathsf T}p)_{\{t,u\}}=p_t+p_u\ge1\).

The dual is feasible: take \(p_t=1\) for every type. Its minimum is attained even when some \(q_t=0\). Indeed, given any dual-feasible \(p\), define \(\widehat p_t=\min(p_t,1)\). For each edge:

  • If neither endpoint is clipped, its constraint is unchanged.
  • If an endpoint is clipped, that endpoint contributes \(1\), and the other contributes a nonnegative amount.

Hence \(\widehat p\) remains feasible. Since \(q_t\ge0\), clipping cannot increase the objective. We may therefore minimize over the nonempty compact feasible subset of \([0,1]^T\), where the continuous objective attains its minimum.

Strong duality applies to these feasible, finite linear programs. Therefore an optimal dual vector \(p^*\) satisfies

\(p^*_t\ge0,\qquad p^*_t+p^*_u\ge1\text{ for every }\{t,u\}\in F,\qquad \sum_{t\in T}q_t p^*_t=M(q).\)

These are precisely the stated stability conditions. Zero-mass types cause no exception: their variables still satisfy the edge constraints and contribute zero to the objective.

Removal cost and running time

Choose \(r_t=0\) for every \(t\). Then \(q=\mu\), which is stable by the preceding proof, and the removal cost is

\(\sum_{t\in T}w_t r_t=0\le B.\)

Every permitted removal has nonnegative cost because \(w_t,r_t\ge0\). Thus the optimal removal cost is exactly \(0\).

On the promised valid input domain, the decision algorithm simply returns YES. Including reading the input, it runs in \(O(L)\) time; no graph optimization is required.

If explicit stable payoffs are requested, solve the dual at \(q=\mu\). It has \(\tau\) variables and \(m+\tau\) inequalities, with rational encoding length polynomial in \(m,\tau,L\). Polynomial-time rational linear programming therefore produces a rational payoff witness in \(\operatorname{poly}(m,\tau,L)\) bit time.

Why the discrete hardness result does not transfer

The discrete matching game uses the maximum integral matching value. Its core can be empty because the fractional matching value exceeds the integral value. The cited paper explicitly characterizes discrete stability by equality of those two values. [Ito et al., *Efficient Stabilization of Cooperative Matching Games*, Section 2](https://www.ifaamas.org/Proceedings/aamas2016/pdfs/p41.pdf).

For example, a triangle has integral matching number \(1\). Assigning \(1/2\) to each edge gives fractional value \(3/2\), which is optimal by summing the three capacity constraints.

In the present formulation, the welfare benchmark is already the fractional program. Its dual optimum therefore always provides the required payoffs. This argument applies to arbitrary compatibility graphs, including graphs with odd cycles.
