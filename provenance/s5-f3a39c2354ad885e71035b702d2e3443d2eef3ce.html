The continuous mirror question, as graded

Given a finite catalogue of local network motifs \(g\), each with single-minded users, integral channel bundles, values, and an explicit conflict graph, and a rational mass \(\mu_g\) of independent copies of each motif, let \(\mathcal A_g\) be the conflict-free integral allocations of one copy, including the empty allocation. Choose rational masses \(x_{g,A}\ge 0\) with \(\sum_{A\in\mathcal A_g}x_{g,A}=\mu_g\), maximizing \(\sum_g\sum_{A\in\mathcal A_g}x_{g,A}\,\mathrm{SW}_g(A)\). Determine the exact and approximation complexity in motif size, support, input bit length, and \(\kappa\), with each unit of motif mass receiving a whole-bundle integral allocation.

Result. The problem admits a deterministic polynomial-time \(\max\{1,\kappa\}\)-approximation. Exact optimization is NP-hard, but this does not prevent the requested approximation.

1. Independent masses separate the optimization.

For each motif \(g\), define
\(W_g^*=\max_{A\in\mathcal A_g}\mathrm{SW}_g(A)\).
This maximum exists because \(\mathcal A_g\) is finite.

Every feasible mass allocation satisfies
\[ \]
\( \sum_{A\in\mathcal A_g}x_{g,A}\mathrm{SW}_g(A) \leq W_g^*\sum_{A\in\mathcal A_g}x_{g,A} =\mu_gW_g^*. \)

Conversely, choose a maximizing allocation \(A_g^*\) and assign \(x_{g,A_g^*}=\mu_g\), with all other masses zero. These masses are rational and feasible. Because there are no constraints between motifs or copies, these choices can be made simultaneously. Therefore,

\( \mathrm{OPT}=\sum_g\mu_gW_g^*. \)

In particular, dividing a motif’s mass among several allocations cannot improve its optimum.

2. Each motif is a bounded-degree weighted independent-set instance.

Let \(U_g\) denote the users of motif \(g\). Construct a simple conflict graph \(H_g\) on \(U_g\), declaring distinct users \(i,j\) adjacent exactly when some channel \(c\in S_{g,i}\cap S_{g,j}\) satisfies \(\{i,j\}\in E(G_{g,c})\).

A user set is feasible precisely when it is independent in \(H_g\): an edge of \(H_g\) records exactly a prohibited simultaneous selection under the stated feasibility rule. Consequently, \(W_g^*\) is the maximum weight of an independent set in \(H_g\), with vertex weights \(v_{g,i}\).

For a graph \(F\), let \(N_F(i)\) denote the neighbors of vertex \(i\). By construction,

\( N_{H_g}(i)= \bigcup_{c\in S_{g,i}} \{j\in N_{G_{g,c}}(i):c\in S_{g,j}\}. \)

Taking cardinalities and using the union bound gives

\( \deg_{H_g}(i) \leq\sum_{c\in S_{g,i}}\deg_{G_{g,c}}(i) \leq |S_{g,i}|\Delta_{\max} \leq m\Delta_{\max} =\kappa. \)

Write \(D_g=\Delta(H_g)\), taking \(D_g=0\) for an empty graph. Thus \(D_g\leq\kappa\). Isolated users introduce no conflicts, regardless of shared channels.

3. Greedy selection achieves the required factor.

Fix a motif and suppress its index. Starting with all vertices remaining, repeatedly:

  • Choose a remaining vertex \(u\) of maximum weight.
  • Add \(u\) to the selected set \(B\).
  • Delete \(u\) and all its remaining neighbors.

The resulting set \(B\) is independent: when a vertex is selected, its neighbors are removed before subsequent selections.

Let \(O\) be a maximum-weight independent set. Assign each vertex \(j\in O\) to the selected vertex \(u\) whose iteration deletes \(j\). Every vertex is eventually deleted exactly once, so this assignment partitions \(O\) into sets \(C_u\), indexed by \(u\in B\).

At the iteration selecting \(u\), every vertex \(j\in C_u\) is still present. Since \(u\) has maximum weight among the remaining vertices,

\( v_j\leq v_u. \)

There are two cases.

  • If \(u\in O\), none of its neighbors belongs to \(O\), because \(O\) is independent. Therefore \(C_u=\{u\}\).
  • If \(u\notin O\), every vertex in \(C_u\) is a neighbor of \(u\). Therefore \(|C_u|\leq\deg_H(u)\leq D\), where \(D=\Delta(H)\).

Hence, in both cases,

\( \sum_{j\in C_u}v_j\leq\max\{1,D\}v_u. \)

Summing over the partition of \(O\) proves

\( \sum_{j\in O}v_j \leq\max\{1,D\}\sum_{u\in B}v_u. \)

Applying this argument to each motif gives

\( \mathrm{SW}_g(B_g) \geq \dfrac{W_g^*}{\max\{1,D_g\}} \geq \dfrac{W_g^*}{\max\{1,\kappa\}}. \)

When \(\kappa=0\), every conflict graph is edgeless, so greedy selects every user and is exact.

4. Mass allocation and running time.

Output the sparse mass allocation

\( x_{g,B_g}=\mu_g \)

for every motif, with all unspecified coordinates zero. It has at most \(\tau\) nonzero entries and satisfies every motif’s mass equality. Its welfare is at least

\( \sum_g\mu_g\mathrm{SW}_g(B_g) \geq \dfrac{\sum_g\mu_gW_g^*}{\max\{1,\kappa\}} = \dfrac{\mathrm{OPT}}{\max\{1,\kappa\}}. \)

No normalization of the masses is needed.

For completeness, the following implementation has polynomial bit complexity:

  • Store bundle membership in Boolean tables and each \(H_g\) in a Boolean adjacency matrix. Scan the explicit channel graphs, inserting an edge only when both endpoints demand its channel.
  • Sort each motif’s users by decreasing rational value. Process this order, accepting each vertex that has not been deleted, and delete its neighbors.

Across all motifs, the channel graphs contain at most \(\tau mn\Delta_{\max}/2=\tau n\kappa/2\) edges. Reading the input, constructing membership tables and conflict matrices, and processing deletions use
\(O(L+\tau(mn+n^2+n\kappa))\)
elementary operations. Sorting uses
\(O(\tau n\log(n+1))\)
rational comparisons.

If two values are encoded as \(a/b\) and \(p/q\), compare them exactly by comparing \(aq\) and \(pb\). Their numerators and denominators have at most \(L\) bits, so schoolbook multiplication gives an \(O(L^2)\) bound per comparison. A conservative total bit-time bound is therefore

\( O\!\left( \bigl[L+\tau(mn+n^2+n\kappa+n\log(n+1))\bigr]L^2 \right). \)

Since \(\kappa\leq m\max\{0,n-1\}\), this is polynomial in the stated input parameters. The algorithm copies the input masses into its output; it never enumerates \(\mathcal A_g\).

5. Exact hardness is compatible with this approximation.

Use the standard NP-completeness of Independent Set: given a simple graph \(H\) and an integer \(k\), deciding whether \(H\) has an independent set of cardinality at least \(k\) is NP-complete.

Construct one motif with one channel, mass \(1\), channel graph \(H\), every user accessible, every bundle equal to \(\{1\}\), and every value equal to \(1\). This construction is polynomial and satisfies all input requirements. Its feasible allocations are exactly the independent sets of \(H\). By the separation identity proved above, its optimal mass welfare equals the independence number of \(H\).

Thus deciding whether the optimal mass welfare is at least \(k\) is NP-hard even when \(m=\tau=1\). Exact hardness is also discussed in the supplied [AEGIS paper](https://zhengzhenzhe220.github.io/papers/ton16.pdf); the approximation for this independent-copy formulation follows from the direct proof above.
