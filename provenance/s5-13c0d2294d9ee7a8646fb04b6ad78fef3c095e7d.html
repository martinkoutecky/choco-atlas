The continuous mirror question, as graded

Given a rational interval \(I\) with uniform unit mass, output a finite partition into interval jurisdictions \(J\). Each jurisdiction chooses its median project and charges each resident \(1/\mu(J)\). Can an algorithm produce a partition that no measurable coalition \(B\) of positive mass can block, where \(B\) uses the paper's mean-of-extreme-medians rule and almost every \(x\in B\) strictly lowers cost from \(|x-m(J_x)|+1/\mu(J_x)\) to \(|x-m(B)|+1/\mu(B)\)?

Packaged proof task (what the prover saw — nothing else)

Given binary rational endpoints \(a<b\), let \(I=[a,b]\) carry the uniform probability measure \(\mu(A)=\lambda(A)/(b-a)\), where \(\lambda\) is Lebesgue measure.
The finite-support convention is: a society is supplied as its \(\tau\) positive-mass types with binary rational masses; \(\tau\) denotes support size, not the number of possible types. The present atomless society cannot use that encoding and is instead specified by \(a,b\); no finite \(\tau\) or candidate-count parameter \(m\) applies.
Output an explicit finite list of binary rational cuts \(a=t_0<t_1<\cdots<t_K=b\), defining positive-mass interval jurisdictions; assign shared endpoints arbitrarily.
For every measurable \(S\subseteq I\) with \(\mu(S)>0\), define \(M(S)=\{z\in I:\mu(S\cap[a,z])\geq\mu(S)/2,\ \mu(S\cap[z,b])\geq\mu(S)/2\}\) and \(m(S)=(\min M(S)+\max M(S))/2\).
Every jurisdiction finances a project of cost \(1\), equally shared, so a resident \(x\in S\) pays \(c(x,S)=|x-m(S)|+1/\mu(S)\).
A partition \(P\) is core stable if no measurable coalition \(B\subseteq I\) of positive mass satisfies \(c(x,B)<c(x,J_x)\) for \(\mu\)-almost every \(x\in B\), where \(J_x\) is its jurisdiction in \(P\); coalitions need not be intervals.

Is producing such a core-stable partition solvable in polynomial time in the input bit length \(L\), or is this search problem NP-hard? State any additional running-time dependence on the number \(K\) of output jurisdictions.

For finite equidistant societies, a core-stable consecutive partition always exists, with a constructive proof ([verified source](https://www.tse-fr.eu/sites/default/files/medias/doc/by/lebreton/stability_jurisdiction.pdf)).
For uniform atomless societies with these cost and median rules, core stability of equal-length interval partitions has been characterized, but the verified source does not establish binary-input complexity bounds for the explicit-output task above ([verified source](https://publications.ut-capitole.fr/1807/1/stability.pdf)).

Modeling choices made when packaging the task

  • Interpret uniform unit mass as total probability mass one, rather than unit density, and exclude degenerate intervals.
  • Define median locations throughout the project interval, including gaps in a coalition, rather than requiring a median to belong to the coalition.
  • Require positive mass for every jurisdiction and retain arbitrary measurable blocking coalitions.
  • Represent the output by an explicit list of binary rational cuts; shared endpoints are immaterial under almost-everywhere blocking.
  • Preserve the atomless uniform input through an endpoint encoding, explicitly identifying its incompatibility with the mandatory finite-support convention.

1. Conclusion

There is a deterministic construction taking \(O((K+1)L^3)\) bit operations. However, no algorithm can solve the explicit-output task in time polynomial in \(L\) alone: some inputs require exponentially many jurisdictions in every stable interval partition.

Thus the appropriate classification is output-polynomial solvability. The proposed choice between polynomial time in \(L\) and NP-hardness overlooks the possibility of necessarily exponential output size.

Write \(D=b-a>0\).

2. Normalization and the stability theorem

Apply the increasing affine transformation \(T(x)=(x-a)/D\), mapping \(I\) onto \([0,1]\). For a measurable coalition \(S\), write \(S'=T(S)\). Uniform probability becomes Lebesgue measure on \([0,1]\), so \(\mu(S)=\lambda(S')\).

The defining inequalities for the median set are preserved by \(T\). Consequently, \(T(M(S))=M(S')\), and the midpoint convention gives \(T(m(S))=m(S')\). Dividing costs by the positive number \(D\) therefore gives

\(\displaystyle \frac{c(x,S)}D=|T(x)-m(S')|+\frac{g}{\lambda(S')},\qquad g=\frac1D.\)

This transformation preserves blocking inequalities.

We use the following characterization from Proposition 4.5 of [Bogomolnaia, Le Breton, Savvateev and Weber](https://publications.ut-capitole.fr/1807/1/stability.pdf):

  • For \(g>0\), an equal partition of \([0,1]\) into \(K>1\) intervals is core stable exactly when \(\sqrt g\leq 1/K\leq(2+\sqrt2)\sqrt g\).
  • The grand jurisdiction is core stable exactly when \(\sqrt g\geq1/(2+\sqrt6)\).

The paper allows arbitrary measurable coalitions and uses the midpoint of the median interval, matching the present model.

Its pointwise blocking formulation also suffices for our almost-everywhere formulation. Indeed, if a coalition blocks almost everywhere, delete the null set where the strict inequality fails. Its measure, median set, and selected median remain unchanged, producing a coalition that blocks at every remaining point. Equal interval partitions have equal costs from both sides of each shared endpoint, so endpoint assignments cause no additional issue.

3. Exact rational construction

Use the following algorithm.

  • If \(D<4\), set \(K=1\) and output \(a,b\).
  • If \(D\geq4\), let \(q\) be the largest integer satisfying \(4^q\leq D\), and set \(K=2^q\).
  • Output every cut

\(\displaystyle t_j=a+\frac{jD}{K},\qquad j=0,\ldots,K.\)

These cuts are rational and strictly increasing. Each jurisdiction has length \(D/K>0\) and probability mass \(1/K\). Because \(K\) is a power of two, the construction also preserves dyadic rationality if that narrower meaning of “binary rational” is intended.

Proof of stability. If \(D<4\), then \(\sqrt g=1/\sqrt D>1/2>1/(2+\sqrt6)\), so the grand jurisdiction is stable.

Otherwise, maximality of \(q\) gives \(K^2\leq D<4K^2\), with \(K\geq2\). Therefore

\(\displaystyle \frac1{\sqrt D}\leq\frac1K<\frac2{\sqrt D}<\frac{2+\sqrt2}{\sqrt D}.\)

These are precisely sufficient inequalities in the equal-partition characterization, with \(g=1/D\). Hence the output is core stable against all admissible measurable coalitions.

4. Bit complexity

Assume the usual binary numerator-and-denominator encoding of rational inputs. Write \(a=A/Q\) and \(b=B/R\), where \(Q,R>0\), and put \(N=BQ-AR>0\). Then \(D=N/(QR)\), and the cuts can be represented explicitly as

\(\displaystyle t_j=\frac{ARK+jN}{QRK}.\)

All input integers have \(O(L)\) bits. Also \(D\leq2^{O(L)}\), so \(\log K=O(L)\). Every displayed numerator and denominator consequently has \(O(L)\) bits.

The integer \(q\) can be found using \(O(L)\) exact comparisons \(4^qQR\leq N\); no numerical square-root approximation is needed. Schoolbook arithmetic gives a conservative \(O(L^3)\) preprocessing bound. Each cut can be computed and, if required, reduced to lowest terms within \(O(L^3)\) bit operations.

Thus the entire explicit construction takes

\(\displaystyle O((K+1)L^3)\)

bit operations and produces \(O((K+1)L)\) output bits. In particular, it is polynomial in \(L+K\), with linear dependence on \(K\) apart from the arithmetic factor.

5. Every stable interval partition can require exponential output

The following bound applies to every core-stable interval partition, regardless of whether its intervals have equal lengths.

Lemma. Every jurisdiction in such a partition has length at most \(\sqrt{24D}\).

Proof. Suppose a jurisdiction has endpoints \(u,u+h\), with \(h^2>24D\). Its median is \(u+h/2\), and its financing charge is \(D/h\).

Consider the coalition \(B=(u,u+h/4)\). Its median is \(u+h/8\), and its financing charge is \(4D/h\). For \(x=u+y\in B\), where \(0<y<h/4\), the transportation saving is

\(\displaystyle |x-(u+h/2)|-|x-(u+h/8)|=\frac h2-y-\left|y-\frac h8\right|.\)

For \(y\leq h/8\), this equals \(3h/8\). For \(y\geq h/8\), it equals \(5h/8-2y\), which is at least \(h/8\). Consequently,

\(\displaystyle c(x,J)-c(x,B)\geq\frac h8-\frac{3D}{h}>0.\)

Thus \(B\) blocks, contradicting core stability. This proves the lemma.

If the partition has jurisdiction lengths \(h_1,\ldots,h_K\), their sum is \(D\). The lemma implies

\(\displaystyle D=\sum_{i=1}^K h_i\leq K\sqrt{24D},\qquad\text{hence}\qquad K\geq\sqrt{\frac D{24}}.\)

Now take \(a=0\) and \(b=2^{2n}\). Their ordinary binary encoding has length \(L=\Theta(n)\), whereas every stable interval partition has

\(\displaystyle K\geq\frac{2^n}{\sqrt{24}}=2^{\Omega(L)}.\)

Writing the required list alone takes \(\Omega(K)\) time. Therefore polynomial time in \(L\) alone is impossible, unconditionally.

For \(D\geq4\), our construction satisfies \(\sqrt D/2<K\leq\sqrt D\). Its jurisdiction count is consequently within a constant factor of the necessary lower bound.

The explicit-output requirement therefore explains the worst-case exponential running time. It does not constitute an NP-hardness result; the construction above establishes deterministic output-polynomial solvability.
