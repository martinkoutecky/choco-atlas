The continuous mirror question, as graded

Given finite applicant and employer type sets \(T_A,T_B\), acceptable type pairs, positive binary-rational masses \(\mu_t\) summing to \(1\), and two preference profiles ranking counterpart types, does there exist a feasible measurable matching \(M\) such that, for each profile \(\ell\in\{1,2\}\) and every feasible measurable matching \(N\), \(\Delta_\ell(M,N)\ge 0\)? Each side’s types occupy atomless populations of their specified masses; matching pairs equal masses along acceptable pairs, and unmatched mass is allowed. Each individual receives at most one integral partner, while individuals of the same type are indifferent between partners of the same counterpart type. The comparison \(\Delta_\ell\) sums each individual’s \(+1\), \(0\), or \(-1\) vote over both populations, comparing that individual’s assignment in \(M\) and \(N\) under profile \(\ell\).

Packaged proof task (what the prover saw — nothing else)

Let \(T_A,T_B\) be disjoint nonempty finite type sets and \(E\subseteq T_A\times T_B\) the acceptable pairs, common to both profiles; write \(m=|E|\). A society is given by its support: the list of \(\tau=|T_A|+|T_B|\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T_A\cup T_B}\mu_t=1\). Thus \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length.
For each profile \(\ell\in\{1,2\}\), each type has a strict order over its acceptable counterpart types, all ranked above being unmatched. Individuals are indifferent between partners of the same type.
Represent each type by a disjoint interval of Lebesgue measure \(\mu_t\). A feasible matching is a measurable, measure-preserving bijection between measurable subsets of the applicant and employer populations, pairing only acceptable types; its inverse gives employers' partners. Each matched individual has one integral partner, and the remaining individuals are unmatched. Conditions on matchings hold almost everywhere.
For matchings \(M,N\) on these same populations, let \(v_\ell(x;M,N)\) be \(+1\) if individual \(x\) prefers its assignment in \(M\), \(-1\) if it prefers its assignment in \(N\), and \(0\) if indifferent. Define \(\Delta_\ell(M,N)=\int_{A\cup B}v_\ell(x;M,N)\,dx\), where \(A,B\) are the two populations.

Is deciding whether there exists a feasible matching \(M\) satisfying \(\Delta_\ell(M,N)\geq0\) for every feasible matching \(N\) and both \(\ell\in\{1,2\}\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

Discrete existence is NP-complete for two strict profiles, even when only one side's preferences vary; independently, hardness holds when only four agents change their orders ([Robust Popular Matchings](https://aamas.csc.liv.ac.uk/Proceedings/aamas2024/pdfs/p225.pdf)).
Single-profile popular fractional matchings under bilinear comparison margins have a compact extended polyhedral formulation ([Popularity, Mixed Matchings, and Self-duality](https://www.di.ens.fr/~cchuang/work/mixed_popular.pdf)); this uses a different comparison model. No result settling the atomless problem specified here was located.

Modeling choices made when packaging the task

  • The rankings were unspecified as strict or weak: use strict orders between distinct acceptable types, preserving indifference between individuals of the same counterpart type.
  • The unmatched assignment was not ranked: place it strictly below every acceptable counterpart type in both profiles.
  • Interpret the stated normalization as total mass one across both sides; do not impose equal side masses.
  • Make measurable matching precise using disjoint Lebesgue intervals and measure-preserving partial bijections, with feasibility interpreted almost everywhere.
  • Define m as the number of acceptable type pairs and L as the total input bit length; require both type sets to be nonempty.

Result

The problem is \(\mathrm{NP}\)-complete. Hardness holds even when all types have the same dyadic mass and only four types change their preference orders.

The key fact is that, in the specified atomless model, the maximum margin of a challenger is a concave function of the incumbent’s type-pair masses. This allows a popular atomless matching with equal type masses to be rounded to a discrete popular matching, simultaneously for both profiles.

1. An exact finite-dimensional formulation

Regard \(E\) as the edge set of a bipartite graph. For each type \(t\), let \(D_t\) be its acceptable counterpart types, and introduce the label \(\bot\) for being unmatched. Write \(q_{ts}=q_{st}\) for the mass matched along the edge joining \(t\) and \(s\).

The possible type-pair mass vectors form the polytope

\[ P(\mu)=\left\{q\in\mathbb R_{\geq 0}^{E}:\ \sum_{s\in D_t}q_{ts}\leq\mu_t\text{ for every }t\right\}. \]

Every feasible measurable matching gives a vector in \(P(\mu)\). Conversely, every vector in \(P(\mu)\) is realizable: partition each type interval into pieces of the prescribed edge masses and an unmatched remainder, then pair equal-length pieces by translations.

For an incumbent with mass vector \(q\), partition each type according to its current assignment. The assignment classes are indexed by

\[ S=\{(t,s):t\in T_A\cup T_B,\ s\in D_t\cup\{\bot\}\}. \]

Their masses are

\[ h_{t,s}(q)=q_{ts}\quad(s\in D_t),\qquad h_{t,\bot}(q)=\mu_t-\sum_{s\in D_t}q_{ts}. \]

For profile \(\ell\), define \(c_t^\ell(r,s)\) as the vote for assignment \(r\) against assignment \(s\): it is \(1\) if \(r\) is preferred, \(-1\) if \(s\) is preferred, and \(0\) if \(r=s\). The order is extended by placing \(\bot\) below every acceptable type.

Construct a bipartite graph \(H\) on the assignment classes. There is an edge between \(i=(a,s)\) and \(j=(b,r)\) exactly when \((a,b)\in E\). A challenger is represented by nonnegative variables \(z_{ij}\), recording the mass paired between these two classes. Let \(d_i(z)\) denote the total incident challenger mass. The constraints are

\[ z_{ij}\geq 0,\qquad d_i(z)\leq h_i(q)\quad(i\in S). \]

For such a flow, the challenger’s margin is

\[ \Phi_\ell(q,z)= \sum_{\substack{ij\in H\\i=(a,s),\,j=(b,r)}} \bigl[c_a^\ell(b,s)+c_b^\ell(a,r)\bigr]z_{ij} + \sum_{i=(t,s)\in S} c_t^\ell(\bot,s)\bigl(h_i(q)-d_i(z)\bigr). \]

The first sum counts matched individuals’ votes; the second counts individuals left unmatched by the challenger.

This flow formulation is exact. Any measurable challenger induces a feasible flow and the displayed margin. Conversely, partition each incumbent assignment class into pieces with masses prescribed by its incident flow variables, leaving the remaining mass unmatched. Pair the corresponding applicant and employer pieces by measure-preserving bijections.

The measure-theoretic fact used here is that two measurable subsets of intervals with equal positive Lebesgue measure admit a bimeasurable, measure-preserving bijection after deleting null subsets. One obtains such a bijection through cumulative-mass coordinates and their quantile inverses. Since there are finitely many pieces, all required deletions together remain null.

Consequently, define

\[ F_\ell(q)= \max\left\{\Phi_\ell(q,z):z\geq 0,\ d_i(z)\leq h_i(q)\text{ for all }i\in S\right\}. \]

This is exactly \(\max_N\Delta_\ell(N,M)\) for every incumbent \(M\) with mass vector \(q\). In particular, it depends only on \(q\).

The flow feasible region is nonempty and compact. Choosing the incumbent itself as challenger gives \(F_\ell(q)\geq 0\). By antisymmetry of comparison margins, popularity is therefore equivalent to

\[ F_\ell(q)=0. \]

These are polynomial-size linear programs. Indeed,

\[ |S|=2m+\tau,\qquad |H|=\sum_{(a,b)\in E}(|D_a|+1)(|D_b|+1) \leq m(\tau+1)^2. \]

2. Concavity and extraction of popular vertices

Lemma. Each \(F_\ell\) is concave on \(P(\mu)\).

Proof. Suppose

\[ q=\sum_{k=1}^{r}\lambda_k q^k,\qquad \lambda_k\geq 0,\qquad \sum_k\lambda_k=1. \]

For each \(k\), choose an optimal challenger flow \(z^k\). Since every class mass is affine in \(q\),

\[ h_i(q)=\sum_k\lambda_k h_i(q^k). \]

Thus \(z=\sum_k\lambda_kz^k\) is feasible for \(q\). The margin expression is affine jointly in \(q\) and \(z\), so

\[ F_\ell(q)\geq \Phi_\ell(q,z) =\sum_k\lambda_k\Phi_\ell(q^k,z^k) =\sum_k\lambda_kF_\ell(q^k). \]

This proves concavity. \(\square\)

Corollary. If there is a mass vector popular in both profiles, then there is a vertex of \(P(\mu)\) popular in both profiles.

Proof. The polytope \(P(\mu)\) is nonempty and bounded: the zero vector is feasible, and every coordinate is bounded by the endpoint masses. Hence every point is a finite convex combination of vertices.

Write a common-popular vector as

\[ q=\sum_k\lambda_kq^k, \]

where the \(q^k\) are vertices and all \(\lambda_k>0\). For either profile,

\[ 0=F_\ell(q)\geq\sum_k\lambda_kF_\ell(q^k)\geq 0. \]

Every summand is nonnegative, so \(F_\ell(q^k)=0\) for every \(k\). Applying this separately to both profiles shows that every vertex in the decomposition is common-popular. \(\square\)

3. Equal masses recover discrete matchings

Consider the unit-capacity bipartite matching polytope

\[ P_1=\left\{x\in\mathbb R_{\geq 0}^{E}: \sum_{e\ni t}x_e\leq 1\text{ for every }t\right\}. \]

We first verify its integrality.

Suppose a feasible vector has a fractional coordinate, and form the graph consisting of edges with \(0<x_e<1\).

If this graph contains a cycle, that cycle has even length because the graph is bipartite. Alternately increasing and decreasing its edge values by a sufficiently small amount preserves every vertex’s incident sum. Both perturbation directions are feasible.

Otherwise, a component containing an edge is a tree. Choose a path between two leaves and perturb its edges alternately. Incident sums at internal path vertices remain unchanged. Each endpoint has slack: its unique fractional incident edge has value below \(1\), and it cannot also have an incident edge of value \(1\). Again, sufficiently small perturbations in both directions are feasible.

In either case, the original vector is the midpoint of two distinct feasible vectors and is therefore not a vertex. Thus every vertex of \(P_1\) is integral, and its positive edges form a discrete matching.

Now suppose every type has mass \(1/D\). Then

\[ P(\mu)=\frac{1}{D}P_1. \]

Every vertex of \(P(\mu)\) consequently has the form \(q^K=D^{-1}\chi^K\) for a discrete matching \(K\).

We also need the exact correspondence between discrete popularity and popularity of this atomless lift.

Let \(M_K\) match whole type intervals according to \(K\), and write \(K(t)=\bot\) for an unmatched type. For any challenger \(N\), let \(n_e\) be its edge masses and set \(y=Dn\in P_1\). Counting votes type by type gives

\[ D\Delta_\ell(N,M_K)=C_\ell^K(y), \]

where

\[ C_\ell^K(y)= \sum_{(a,b)\in E}y_{ab} \bigl[c_a^\ell(b,K(a))+c_b^\ell(a,K(b))\bigr] + \sum_t \left(1-\sum_{e\ni t}y_e\right)c_t^\ell(\bot,K(t)). \]

Every \(y\in P_1\) is realizable by an atomless challenger, by the interval-partition construction from Section 1. The function \(C_\ell^K\) is affine. Its maximum over \(P_1\) is attained at a vertex, which is a discrete matching indicator. At \(y=\chi^J\), its value is exactly the discrete margin of \(J\) against \(K\). Therefore,

\[ F_\ell(q^K)= \frac{1}{D}\max_J\Delta_\ell^{\mathrm{disc}}(J,K). \]

It follows that \(M_K\) is popular in profile \(\ell\) exactly when \(K\) is discretely popular in that profile.

Combining this with vertex extraction proves:

Equal-mass equivalence. A pair of equal-mass atomless profiles admits a common-popular matching if and only if the corresponding discrete profiles admit a common-popular matching.

4. Polynomial-time hardness reduction

Theorem 4.9 of [*Robust Popular Matchings*](https://aamas.csc.liv.ac.uk/Proceedings/aamas2024/pdfs/p225.pdf) establishes \(\mathrm{NP}\)-completeness of discrete common-popular matching existence for two strict profiles on the same bipartite graph, even when the second profile differs only by downshifts performed by four agents.

Take such a discrete instance with \(n\) agents. Let \(D\) be the least power of two with \(D\geq n\). Add \(D-n\) isolated agents, placing them on either side. They have empty preference lists in both profiles and are unmatched in every feasible matching, so they contribute zero to every comparison margin.

Create one type per padded agent, retain all acceptable pairs and orders, and assign each type mass \(1/D\). These masses are positive dyadic rationals and sum to \(1\).

The transformation has polynomial size: \(D<2n\), and each mass needs \(O(\log n)\) bits. It preserves the restriction that only four preference orders change.

By the equal-mass equivalence, the resulting atomless instance has a common-popular matching exactly when the padded discrete instance does. Removing the isolated agents preserves the answer. This is a polynomial-time reduction proving \(\mathrm{NP}\)-hardness.

5. Membership in \(\mathrm{NP}\)

For arbitrary input masses, the vertex-extraction corollary supplies a common-popular vertex whenever a solution exists. Such a vertex has polynomial rational encoding length.

For completeness, when \(m>0\), the polytope is full-dimensional: choosing all edge masses sufficiently small and positive makes every degree constraint strict. A vertex is therefore determined by \(m\) linearly independent tight constraints. Their coefficient matrix has entries in \(\{-1,0,1\}\), and their right-hand sides are input masses or zero.

Let \(B\) be the product of the denominators of the input masses. Its bit length is \(O(L)\). Cramer’s rule and Hadamard’s determinant bound show that each vertex coordinate has a rational representation with bit length

\[ O\bigl(L+m\log(m+1)\bigr). \]

Thus the entire vertex vector is a polynomial-size certificate. When \(m=0\), the all-unmatched matching trivially satisfies both profiles.

Given a rational certificate \(q\), a verifier checks \(q\in P(\mu)\), then solves the two exact challenger linear programs from Section 1. Their dimensions and rational coefficient lengths are polynomial in \(m,\tau,L\). Polynomial-time rational linear programming therefore verifies whether both optimal values equal zero.

The problem belongs to \(\mathrm{NP}\), and the reduction above proves that it is \(\mathrm{NP}\)-complete.
