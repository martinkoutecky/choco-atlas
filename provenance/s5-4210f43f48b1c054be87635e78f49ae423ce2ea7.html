The continuous mirror question, as graded

Given a finite agenda \(\Phi\), integrity constraint \(\Gamma\), required starting agenda \(\Phi_0\subseteq\Phi\), target conclusions \(L\subseteq\Phi\), and a finite-support distribution \(\mu\) over complete, \(\Gamma\)-consistent judgment types on \(\Phi\) with binary-rational masses summing to \(1\), is there an agenda \(A\) with \(\Phi_0\subseteq A\subseteq\Phi\) such that every complete, feasible judgment minimizing \(D_\mu^A(J)=\sum_t\mu_t d_A(J,t|_A)\) contains \(L\)?

Result

The problem is \(\Sigma_2^{\mathrm p}\)-complete under polynomial-time many-one reductions, and hence \(\mathrm{NP}\)-hard. Consequently, it is not polynomial-time solvable unless \(\mathrm P=\mathrm{NP}\).

Here rational masses are represented by binary-encoded numerators and denominators. The proof transfers the supplied finite-profile hardness result by compression and establishes membership directly using exact arithmetic.

1. The finite-profile theorem applies

Theorem 8 of the cited paper establishes \(\Sigma_2^{\mathrm p}\)-hardness of Control-by-Adding-Issues(Kemeny). Its input consists of an agenda \(\Phi\), an integrity constraint \(\Gamma\), a nonempty base agenda \(\Phi_0\), desired conclusions \(L\), and an explicitly listed profile of complete, \(\Gamma\)-consistent judgments. The question asks whether some agenda between \(\Phi_0\) and \(\Phi\) makes every Kemeny outcome contain \(L\). The constraint remains fixed when the agenda changes, and all minimizing judgments are outcomes. Thus its feasibility, control, and tie conventions agree with this task. [Source: Sections 2.1.1 and 3.4, Theorem 8](https://aamas.csc.liv.ac.uk/Proceedings/aamas2017/pdfs/p1151.pdf).

We use this theorem as the hardness premise; the representation transfer is proved next.

2. Compression preserves every outcome on every subagenda

Consider an explicitly listed profile \((J_1,\ldots,J_p)\), where \(p\) is its number of entries. Let \(t_1,\ldots,t_\tau\) be its distinct judgment types, and define

\[ c_s=\bigl|\{i:J_i=t_s\}\bigr|, \qquad \mu_s=\frac{c_s}{p}. \]

Each mass is positive, their sum is one, and every listed type remains complete and feasible. Copy \(\Phi,\Gamma,\Phi_0,L\) unchanged.

For every allowed subagenda \(A\) and every feasible complete judgment \(J\) on \(A\),

\[ D_\mu^A(J) =\sum_{s=1}^{\tau}\frac{c_s}{p}\,d_A(J,t_s|_A) =\frac1p\sum_{i=1}^{p}d_A(J,J_i|_A). \]

The second equality groups identical profile entries. Both sides use the same issue distance and the same feasible judgments, because the agenda and constraint were copied unchanged.

Multiplication by the positive constant \(1/p\) preserves strict inequalities and equalities. Therefore the mass-based and finite-profile objectives have exactly the same minimizers, including all ties, on every allowed \(A\). In particular,

\[ \exists A\; \text{every finite-profile outcome on }A\text{ contains }L \]

holds if and only if

\[ \exists A\; \text{every mass-based outcome on }A\text{ contains }L. \]

The construction is polynomial in the finite-profile input length: distinct judgment vectors can be grouped and counted in polynomial time, and each fraction \(c_s/p\) uses \(O(\log p)\) bits for its numerator and denominator. Reducing fractions, if required, is also polynomial-time.

This is a polynomial-time many-one reduction. The finite-profile theorem consequently proves \(\Sigma_2^{\mathrm p}\)-hardness of the stated rational-mass problem.

3. Exact score comparisons take polynomial time

Write each input mass as \(\mu_s=a_s/b_s\), with positive integers \(a_s,b_s\), and set

\[ Q=\prod_{s=1}^{\tau}b_s, \qquad w_s=a_s(Q/b_s). \]

Then the integer score

\[ C_A(J)=\sum_{s=1}^{\tau}w_s\,d_A(J,t_s|_A) \]

satisfies \(C_A(J)=Q D_\mu^A(J)\). Hence it preserves all score comparisons and ties.

Although the numerical value of \(Q\) can be large, its binary length is polynomially bounded:

\[ \log_2 Q=\sum_{s=1}^{\tau}\log_2 b_s\leq B. \]

Also, normalization gives \(\sum_s w_s=Q\). Since every distance is at most \(m\),

\[ 0\leq C_A(J)\leq mQ. \]

Thus scores have \(O(B+\log m)\) bits. Computing the weights uses polynomial-time integer arithmetic; computing the distances requires \(O(m\tau)\) issue comparisons. All score computations therefore take time polynomial in \(m,\tau,B\), without expanding the masses into voters.

4. Membership in \(\Sigma_2^{\mathrm p}\)

Let \(V\) be the variables occurring in \(\Phi\) or \(\Gamma\). Its size is bounded by the input length.

Consider the following nondeterministic algorithm with an \(\mathrm{NP}\) oracle.

  • Guess a subagenda \(A\), encoded by its selected complementary pairs, and check \(\Phi_0\subseteq A\subseteq\Phi\).
  • Guess a complete judgment \(J\) on \(A\) and an assignment \(v:V\to\{0,1\}\). Check that \(v\) satisfies \(\Gamma\) and every formula in \(J\), and check \(L\subseteq J\). Reject this branch if any check fails.
  • Compute \(c=C_A(J)\).
  • Ask whether there exist a complete judgment \(J'\) on \(A\) and an assignment witnessing its feasibility such that

\[ C_A(J')<c \quad\text{or}\quad \bigl(C_A(J')=c\ \text{and}\ L\nsubseteq J'\bigr). \]

Accept exactly when the oracle answers no.

The oracle question belongs to \(\mathrm{NP}\): its certificate contains \(J'\) and a satisfying assignment, and completeness, feasibility, containment, and exact score comparisons are all polynomial-time checks.

Soundness. An accepting branch supplies a feasible \(J\), and the negative oracle answer excludes every feasible judgment with lower score. Thus \(J\) is optimal. The same answer excludes every optimal judgment failing to contain \(L\). Therefore all Kemeny outcomes on the guessed \(A\) contain \(L\).

Completeness. Suppose some allowed \(A\) succeeds. Its feasible judgments form a nonempty finite set: restricting any supported full judgment to \(A\) gives a feasible judgment. Hence an optimal judgment \(J\) exists. It contains \(L\), and its feasibility has an assignment witness. Guessing these objects passes the checks. Optimality excludes the first oracle condition, and successful cautious control excludes the second, so this branch accepts.

The algorithm uses polynomial nondeterministic work and one \(\mathrm{NP}\)-oracle query. This proves membership in \(\Sigma_2^{\mathrm p}\), completing the classification.
