The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), approval sets \(A_t\subseteq T\), rational \(w_1>w_2>0\), and threshold \(\alpha\), decide whether there exist two type-level mass matchings \(x^1,x^2\) satisfying \(2x^j_{\{t,t\}}+\sum_{u\ne t}x^j_{\{t,u\}}\le\mu_t\), using only pairs approved by at least one endpoint, together with \(z_{t,S}\ge0\) for \(S\subseteq\{1,2\}\), \(\sum_S z_{t,S}=\mu_t\), and \(\sum_{S\ni j}z_{t,S}=p_{t,j}\), where \(p_{t,j}\) is the mass of type \(t\) approving its partner in round \(j\), such that \(\sum_{t\in T}\sum_{S\subseteq\{1,2\}}z_{t,S}\sum_{i=1}^{|S|}w_i\ge\alpha\).

Classification: Polynomial-Time Solvable

Theorem

The stated mass-matching decision problem belongs to \(\mathrm{P}\). More precisely, it is the feasibility problem for a rational linear program of polynomial size. Consequently, it is not \(\mathrm{NP}\)-hard unless \(\mathrm{P}=\mathrm{NP}\).

Proof

Let \(n=|T|\), and define the set of admissible unordered pairs by

\(E=\{\{t,u\}:u\in A_t\text{ or }t\in A_u\}\).

For a disallowed pair, the condition that \(x^j_{\{t,u\}}>0\) is permitted only for admissible pairs is exactly enforced by setting \(x^j_{\{t,u\}}=0\). Equivalently, variables for disallowed pairs can simply be omitted.

Introduce the following variables:

  • \(x^j_e\ge 0\) for every \(j\in\{1,2\}\) and \(e\in E\);
  • \(p_{t,j}\) for every \(t\in T\) and \(j\in\{1,2\}\);
  • \(z_{t,S}\ge 0\) for every \(t\in T\) and \(S\subseteq\{1,2\}\).

There are only four subsets \(S\subseteq\{1,2\}\).

For every \(t\in T\) and \(j\in\{1,2\}\), impose the matching-capacity constraint

\(2x^j_{\{t,t\}}+\sum_{u\ne t}x^j_{\{t,u\}}\le \mu_t\),

where omitted or disallowed variables are understood to be zero. Define approved mass using the linear equality

\(p_{t,j}=2\mathbf{1}[t\in A_t]x^j_{\{t,t\}}+\sum_{u\ne t:\,u\in A_t}x^j_{\{t,u\}}\).

The required coupling constraints are

\(\sum_{S\subseteq\{1,2\}}z_{t,S}=\mu_t\)

and

\(\sum_{S\subseteq\{1,2\}:\,j\in S}z_{t,S}=p_{t,j}\)

for every \(t\in T\) and \(j\in\{1,2\}\).

Finally, impose the threshold constraint

\(\sum_{t\in T}\bigl(w_1z_{t,\{1\}}+w_1z_{t,\{2\}}+(w_1+w_2)z_{t,\{1,2\}}\bigr)\ge\alpha\).

This is exactly the objective inequality in the question because the contribution is zero for \(S=\varnothing\), equals \(w_1\) for either singleton, and equals \(w_1+w_2\) for \(S=\{1,2\}\).

All these constraints are linear, and all their coefficients are rational.

There are at most \(n(n+1)\) matching variables over the two rounds, \(2n\) variables \(p_{t,j}\), and \(4n\) variables \(z_{t,S}\). Thus the total number of variables and constraints is polynomial in \(n\), and their encoding length is polynomial in the input encoding length. Feasibility of a rational linear program is decidable in polynomial time by standard rational linear-programming algorithms.

Therefore the decision problem belongs to \(\mathrm{P}\).

Structure of the Two-Round Coupling

The coupling variables do not conceal an integral choice. Fix a type \(t\), and write \(a=p_{t,1}\), \(b=p_{t,2}\), and \(q=z_{t,\{1,2\}}\). The coupling equalities force

\(z_{t,\{1\}}=a-q\),

\(z_{t,\{2\}}=b-q\),

and

\(z_{t,\varnothing}=\mu_t-a-b+q\).

Hence nonnegativity is equivalent to

\(\max\{0,a+b-\mu_t\}\le q\le\min\{a,b\}\).

The matching-capacity constraints imply \(0\le a,b\le\mu_t\), so this interval is always nonempty. The contribution of type \(t\) is

\(w_1(a+b)+(w_2-w_1)q\).

Because \(w_1>w_2\), an optimal coupling takes

\(q=\max\{0,a+b-\mu_t\}\).

Thus the optimized contribution is the concave piecewise-linear function

\(w_1(a+b)\) when \(a+b\le\mu_t\), and

\(w_1\mu_t+w_2(a+b-\mu_t)\) when \(a+b\ge\mu_t\).

The original \(z\)-variable formulation is precisely a linear extended formulation of this function.

Relation to the Discrete Hardness Result

The discrete \(\mathrm{NP}\)-completeness result does not transfer to this formulation. In the discrete problem, agents are indivisible and their identities across rounds create combinatorial choices. Here each type mass can be split fractionally among edges and among the four round-approval patterns. The resulting feasible region is a rational polyhedron with no integrality requirement.
