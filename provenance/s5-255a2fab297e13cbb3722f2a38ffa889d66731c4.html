The continuous mirror question, as graded

Input a finite candidate set \(M\), a finite set of location types \(T\), a rational metric \(d\) on \(T\cup M\), a rational distribution \(\mu\) over \(T\), a target \(k\), and a proposed selection \(X\subseteq M\) with \(|X|=k\). For \(S\subseteq T\), let \(\mu(S)=\sum_{t\in S}\mu_t\), \(A_r(t)=\{c\in M:d(t,c)\le r\}\), and \(A_r(S)=\bigcup_{t\in S}A_r(t)\). Does every \(\ell\in[k]\), radius \(r\), and type coalition \(S\) with \(\mu(S)\ge \ell/k\) satisfy \(|\bigcap_{t\in S}A_r(t)|\ge\ell\ \Longrightarrow\ |X\cap A_r(S)|\ge\ell\)?

Classification

Violation detection is \(\mathrm{NP}\)-complete, and verification is \(\mathrm{coNP}\)-complete, under polynomial-time many-one reductions.

The key point is that allowing only coalitions containing entire types does not obstruct a reduction from the discrete problem: any discrete violating coalition can be enlarged to include every agent at each location it touches.

1. Violation detection belongs to \(\mathrm{NP}\)

Define the finite set of relevant radii
\[ D:=\{0\}\cup\{d(t,c):t\in T,\ c\in M\}. \]
It has at most \(\tau m+1\) elements.

For any real radius \(r\ge 0\), let \(\rho\) be the largest element of \(D\) satisfying \(\rho\le r\). Such an element exists because \(0\in D\). For every \(t\in T\) and \(c\in M\),
\[ d(t,c)\le r\quad\Longleftrightarrow\quad d(t,c)\le\rho. \]
Indeed, if \(d(t,c)\le r\), that distance itself belongs to \(D\), so it cannot exceed \(\rho\). Consequently, \(A_r(t)=A_\rho(t)\) for every type. Every violation therefore has a witness radius in \(D\).

A certificate consists of:

  • an integer \(\ell\in\{1,\ldots,k\}\);
  • a nonempty coalition \(S\subseteq T\), represented by \(\tau\) bits;
  • a radius \(\rho\in D\), represented by an index into the input distances or the distinguished value \(0\).

The verifier checks
\[ k\sum_{t\in S}\mu_t\ge\ell,\qquad \left|\bigcap_{t\in S}A_\rho(t)\right|\ge\ell,\qquad \left|X\cap\bigcup_{t\in S}A_\rho(t)\right|<\ell. \]
These are precisely the conditions for a violation.

All computations use exact rational arithmetic. To check the mass inequality, write \(\mu_t=a_t/b_t\) and take the common denominator \(B=\prod_{t\in T}b_t\). Its binary length is at most the sum of the denominator lengths, hence \(O(L)\). The integer numerator
\[ \sum_{t\in S}a_t(B/b_t) \]
also has \(O(L)\) bits: it is at most \(B\), since \(\mu(S)\le1\). Thus exact mass comparison takes polynomial time.

Using elementary integer arithmetic, a conservative certificate-verification bound on valid inputs is \(O(\tau mL^2)\) bit operations. Hence violation detection belongs to \(\mathrm{NP}\).

2. Whole-type coalitions preserve discrete violations

Consider a discrete instance with a nonempty, explicitly listed population \(N\), where \(n:=|N|\). Let \(p(i)\) denote agent \(i\)'s location. Define
\[ T:=\{p(i):i\in N\},\qquad n_t:=|\{i\in N:p(i)=t\}|,\qquad \mu_t:=\frac{n_t}{n}. \]
Retain the candidate set \(M\), the integer \(k\), the selection \(X\), and the metric restricted to \(T\cup M\).

Every mass is positive, and their sum is \(1\).

Claim. The discrete instance has a metric PJR violation if and only if this rational-mass instance has a violation.

Proof, discrete to mass. Suppose a discrete coalition \(C\subseteq N\), an integer \(\ell\), and a radius \(r\) witness a violation. Let
\[ S:=\{p(i):i\in C\},\qquad \widehat C:=\{i\in N:p(i)\in S\}. \]
Thus \(\widehat C\) contains every agent at every location touched by \(C\), and \(C\subseteq\widehat C\).

Agents at the same location have identical radius-\(r\) approval sets. Adding further copies of approval sets already present changes neither their intersection nor their union. Therefore
\[ \bigcap_{i\in C}A_r(p(i)) =\bigcap_{t\in S}A_r(t),\qquad \bigcup_{i\in C}A_r(p(i)) =\bigcup_{t\in S}A_r(t). \]
Moreover,
\[ \mu(S)=\frac{|\widehat C|}{n} \ge\frac{|C|}{n} \ge\frac{\ell}{k}. \]
The intersection and insufficient-representation conditions remain unchanged, so \(S,\ell,r\) witness a mass-based violation.

Proof, mass to discrete. Conversely, suppose \(S,\ell,r\) witness a mass-based violation. Take the discrete coalition
\[ C:=\{i\in N:p(i)\in S\}. \]
Then
\[ |C|=n\mu(S)\ge\frac{\ell n}{k}. \]
Its approval intersection and union equal those of \(S\), because repeating an approval set changes neither operation. Hence \(C,\ell,r\) witness a discrete violation. This proves the claim.

3. Polynomial reduction and hardness

Use the discrete violation problem stated in the question as the \(\mathrm{NP}\)-complete source problem. Its hardness can be realized with integer metric distances, so requiring a rational, explicitly tabulated metric does not remove that hardness; see Lemma 5 and Theorem 6 of [*Check, Please: Verifiably Fair Clustering*](https://arxiv.org/html/2605.12317v2#S3.SS1).

Apply the transformation in Section 2. Counting agents at each location and restricting the metric take polynomial time in the explicit source input length. Each mass \(n_t/n\) requires \(O(\log n)\) bits. The target has support size \(\tau\le n\), and the metric table has at most \((\tau+m)^2\) entries. Thus the output length and construction time are polynomial in the source input length.

Section 2 proves equivalence of the source and target answers. This is a polynomial-time many-one reduction, establishing \(\mathrm{NP}\)-hardness. Together with Section 1, violation detection is \(\mathrm{NP}\)-complete. Taking complements gives \(\mathrm{coNP}\)-completeness of verification.

Crucially, this reduction compresses an explicitly listed discrete population. It never expands a general rational-mass instance into a population whose size might be exponential in \(L\).

4. Running times in the supplied parameters

The certificate verifier runs in \(O(\tau mL^2)\) bit operations, with \(1\le k\le m\).

An elementary deterministic algorithm enumerates all nonempty coalitions and all radii in \(D\). For each pair, compute
\[ p:=\left|\bigcap_{t\in S}A_r(t)\right|,\qquad q:=|X\cap A_r(S)|,\qquad w:=\mu(S). \]
A violating integer \(\ell\) exists exactly when
\[ q<k,\qquad p\ge q+1,\qquad kw\ge q+1. \]
Necessity follows because any violation has \(\ell\ge q+1\); sufficiency follows by choosing \(\ell=q+1\).

This gives a deterministic bound of \(O(2^\tau(\tau m+1)\tau mL^2)\) bit operations without expanding the masses. A polynomial-time algorithm for unrestricted inputs exists if and only if \(\mathrm{P}=\mathrm{NP}\).
