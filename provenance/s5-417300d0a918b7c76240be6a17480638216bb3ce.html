The continuous mirror question, as graded

Given rational \(\alpha\in(0,1)\) and \(\beta\geq0\) with \(\beta^2\alpha(1-\alpha)<1\), consider a unit-mass workforce split between two complete-bipartite types with masses \(\alpha\) and \(1-\alpha\). The finite model uses attenuation \(\delta_n=\beta/n\), and a coalition with type masses \(x,y\) has productivity per unit baseline population \(F_\beta(x,y)=\frac{x+y+2\beta xy}{1-\beta^2xy}\). Compute the LRP productivity densities \((w_K,w_M)\), equal within each type, that satisfy efficiency \(\alpha w_K+(1-\alpha)w_M=F_\beta(\alpha,1-\alpha)\), link balance \(\frac{\alpha}{1-\alpha}(w_K-1)=\frac{1-\alpha}{\alpha}(w_M-1)\), and core stability \(xw_K+yw_M\geq F_\beta(x,y)\) for all \(0\leq x\leq\alpha\), \(0\leq y\leq1-\alpha\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass encoded as a binary rational; \(\tau\) counts supported types, not possible types. Here there are \(m=2\) groups and \(\tau=2\) types, \(K,M\), with masses \(\alpha,1-\alpha\), where \(\alpha\in\mathbb{Q}\cap(0,1)\). Each unit of mass has intrinsic productivity \(1\); interactions are complete across groups and absent within groups.
The input also includes binary-rational \(\beta\geq0\), subject to \(\beta^2\alpha(1-\alpha)<1\); let \(L\) be the total input bit length. Mass is divisible: a coalition has any real masses \(0\leq x\leq\alpha\), \(0\leq y\leq1-\alpha\), and productivity \(F_\beta(x,y)=\frac{x+y+2\beta xy}{1-\beta^2xy}\).
A link ratio productivity (LRP) allocation consists of constant densities \((w_K,w_M)\in\mathbb{R}^2\) satisfying efficiency \(\alpha w_K+(1-\alpha)w_M=F_\beta(\alpha,1-\alpha)\) and link balance \(\frac{\alpha}{1-\alpha}(w_K-1)=\frac{1-\alpha}{\alpha}(w_M-1)\). It is core stable if \(xw_K+yw_M\geq F_\beta(x,y)\) for every coalition.
The computational problem is to determine whether a core-stable LRP allocation exists and, when one exists, compute its densities exactly.

Is this problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite complete bipartite workforces with both groups nonempty and \(0\leq\delta<1/\sqrt{|K||M|}\), an explicit LRP formula is known; the allocation is core stable and uniquely satisfies efficiency, equality within groups, and link balance. Result

The stated problem is polynomial-time solvable. Every admissible input has a unique LRP allocation, and that allocation is core stable for all real coalition masses.

Write \(a=\alpha\), \(b=1-\alpha\), and define

\(\displaystyle D=1-\beta^2ab>0,\qquad C=\frac{2\beta+\beta^2}{D}\geq0.\)

The exact densities are

\(\displaystyle \boxed{w_K=1+Cb^2,\qquad w_M=1+Ca^2.}\)

The cited paper establishes the finite-workforce counterpart in Proposition 5.4 and Theorems 5.5–5.6. The proof below directly handles divisible masses. [Allouch, Guardiola, and Meca](https://arxiv.org/html/2402.01910v1#S5)

1. Efficiency and link balance determine the densities uniquely

Let \(u=w_K-1\) and \(v=w_M-1\). Since \(a+b=1\), grand-coalition surplus is

\(\displaystyle F_\beta(a,b)-1 =\frac{1+2\beta ab}{1-\beta^2ab}-1 =abC.\)

Thus efficiency and link balance become

\(\displaystyle au+bv=abC,\qquad a^2u=b^2v.\)

Because \(a,b>0\), the second equality implies \(u=tb^2\) and \(v=ta^2\) for some real \(t\). Substitution into efficiency gives

\(\displaystyle abC=t(ab^2+ba^2)=tab(a+b)=tab.\)

Therefore \(t=C\). This proves both uniqueness and the displayed density formulas, including when \(\beta=0\).

2. Core stability for every real coalition

Fix arbitrary real masses \(0\leq x\leq a\) and \(0\leq y\leq b\). The promise implies

\(\displaystyle 1-\beta^2xy\geq1-\beta^2ab=D>0.\)

Subtracting intrinsic productivity gives the identity

\(\displaystyle F_\beta(x,y)-(x+y) =xy\,\frac{2\beta+\beta^2(x+y)}{1-\beta^2xy}.\)

Since \(x+y\leq a+b=1\), \(\beta\geq0\), and the denominators are positive,

\(\displaystyle 0\leq\frac{2\beta+\beta^2(x+y)}{1-\beta^2xy} \leq\frac{2\beta+\beta^2}{D}=C. \)

Consequently,

\(\displaystyle F_\beta(x,y)\leq x+y+Cxy.\)

The proposed allocation pays

\(\displaystyle xw_K+yw_M=x+y+C(b^2x+a^2y).\)

The required comparison follows from the exact identity

\(\displaystyle b^2x+a^2y-xy =b^2x\left(1-\frac{y}{b}\right) +a^2y\left(1-\frac{x}{a}\right)\geq0. \)

Indeed, expanding the right-hand side yields \(b^2x+a^2y-(a+b)xy\), which equals the left-hand side because \(a+b=1\). Both terms are nonnegative by the coalition bounds.

Since \(C\geq0\), we conclude

\(\displaystyle xw_K+yw_M\geq x+y+Cxy\geq F_\beta(x,y).\)

This proves the core inequality for every real coalition, without discretization. Together with Section 1, it proves existence and uniqueness of a core-stable LRP allocation.

3. Exact polynomial-time computation

Represent the input rationals as \(\alpha=p/q\) and \(\beta=r/s\), with positive denominators, \(0<p<q\), and \(r\geq0\). Define the integer

\(\displaystyle T=q^2s^2-r^2p(q-p).\)

The promise gives \(T>0\). Substitution into the density formulas yields

\(\displaystyle w_K=\frac{T+r(2s+r)(q-p)^2}{T}, \qquad w_M=\frac{T+r(2s+r)p^2}{T}. \)

Each input integer has \(O(L)\) bits. These expressions use a constant number of additions, subtractions, and multiplications, and every intermediate integer and output numerator or denominator also has \(O(L)\) bits. Hence ordinary integer arithmetic computes the densities in polynomial time in \(L\). If reduced fractions are required, greatest-common-divisor computation also takes polynomial time.

Thus, for the stipulated \(m=\tau=2\), the existence decision always returns yes on admissible inputs, and exact density computation is polynomial-time. This settles the specified problem.
