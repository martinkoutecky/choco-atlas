The anchor (named result in the paper)

Theorem 3 — class: hardness

The continuous mirror question, as graded

Given \(|C|=4\), a target \(c^\star\), and rational masses \(\mu_t\) summing to \(1\) over sincere types \(t=(\succ_t,q_t)\) and manipulator types \(t=(q_t,c^\star)\), does there exist an allocation \(x_{t,\pi}\geq 0\) over complete ballots \(\pi\in\mathcal L(C)\) for manipulator types, with \(\sum_{\pi}x_{t,\pi}=\mu_t\) for each such type, that makes \(c^\star\) the unique SkS winner? Compute each stage's score and sum of positions using the sincere masses and the allocated manipulator masses, weighted by \(q_t\), and use the continuous majority threshold \(W/2\), where \(W=\sum_t q_t\mu_t\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|=4\) and target \(c^\star\in C\). A society is given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Types are tagged as sincere or manipulative: sincere types specify a strict complete ranking \(\succ_t\) and weight \(q_t\); manipulator types specify \((q_t,c^\star)\). Weights are binary nonnegative integers, and \(W=\sum_t q_t\mu_t>0\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Let \(S\) and \(M\) denote the sincere and manipulator supports, and \(\mathcal L(C)\) the strict complete ballots. An allocation consists of real numbers \(x_{t,\pi}\geq0\) satisfying \(\sum_{\pi\in\mathcal L(C)}x_{t,\pi}=\mu_t\) for every \(t\in M\). Define the weighted ballot mass \(a_\pi=\sum_{t\in S:\,\succ_t=\pi}q_t\mu_t+\sum_{t\in M}q_tx_{t,\pi}\).
For each stage \(i\in\{1,\ldots,m\}\), define \(s_i(c)=\sum_{\pi:\,\operatorname{pos}_\pi(c)\leq i}a_\pi\) and \(p_i(c)=\sum_{\pi:\,\operatorname{pos}_\pi(c)\leq i}a_\pi\operatorname{pos}_\pi(c)\). Majority means strictly exceeding \(W/2\).
The continuous Skating System Single (SkS) begins at \(i^*=\min\{i:\max_{c\in C}s_i(c)>W/2\}\), with active set \(A=C\). At each stage \(i\geq i^*\), retain \(B=\arg\max_{c\in A}s_i(c)\), then \(D=\arg\min_{c\in B}p_i(c)\). If \(|D|=1\), return that candidate; if \(i=m\), return all of \(D\); otherwise set \(A=D\) and advance one stage. Ballot positions, \(m\), and \(W\) remain fixed throughout.

Is deciding whether an allocation makes \(c^\star\) the unique continuous SkS winner in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard, even with \(m=4\)?

Discrete constructive coalitional weighted manipulation for SkS, with indivisible nonnegative integer voter weights and a unique-winner objective, is \(\mathrm{NP}\)-complete even with four candidates. [Source](https://arxiv.org/pdf/2511.22384)
No result settling exactly the continuous problem above was located in the literature search.

Modeling choices made when packaging the task

  • The weight domain was unspecified; retain the discrete definition's binary nonnegative integer weights.
  • Interpret the continuous majority boundary as strict inequality above W/2, matching the discrete strict-majority condition.
  • Require positive total weighted mass W, excluding the all-zero-weight case in which the discrete definition never reaches its majority threshold.
  • Specify allocations over nonnegative real masses, with each manipulator type freely divisible among all strict complete ballots.
  • Make sincere and manipulator supports disjoint by tagging their roles; either support may be empty.

Result

The decision problem is in \(\mathrm P\) for \(\,m=4\). The proof gives an exact algorithm using at most \(\,800\) rational linear programs, each with \(\,25\) variables and a constant number of constraints.

More generally, the same argument gives a running time of \(\,f(m)\operatorname{poly}(\tau,L)\), so it establishes polynomial-time solvability for every fixed number of candidates.

1. Aggregate manipulator mass exactly

Define the fixed sincere ballot masses and total manipulator weight by

\(\displaystyle b_\pi=\sum_{t\in S:\,\succ_t=\pi}q_t\mu_t,\qquad Q=\sum_{t\in M}q_t\mu_t.\)

Then \(\,W=\sum_\pi b_\pi+Q\).

Lemma 1. The set of achievable weighted ballot profiles is exactly

\(\displaystyle a_\pi=b_\pi+y_\pi,\qquad y_\pi\geq0,\qquad \sum_{\pi\in\mathcal L(C)}y_\pi=Q.\)

Proof. Given an allocation, put \(\,y_\pi=\sum_{t\in M}q_tx_{t,\pi}\). Nonnegativity holds, and

\(\displaystyle \sum_\pi y_\pi=\sum_{t\in M}q_t\sum_\pi x_{t,\pi}=\sum_{t\in M}q_t\mu_t=Q.\)

Conversely, suppose such a vector \(\,y\) is given. If \(\,Q>0\), define, for every manipulator type,

\(\displaystyle x_{t,\pi}=\mu_t\frac{y_\pi}{Q}.\)

These allocations are nonnegative and satisfy

\(\displaystyle \sum_\pi x_{t,\pi}=\mu_t,\qquad \sum_{t\in M}q_tx_{t,\pi}=\frac{y_\pi}{Q}\sum_{t\in M}q_t\mu_t=y_\pi.\)

This construction also accommodates manipulator types with zero weight.

If \(\,Q=0\), positivity of the masses and nonnegativity of the weights imply that every manipulator weight is zero. The only possible vector \(\,y\) is then zero, and any allocation satisfying the type-mass constraints realizes it. This proves the lemma.

Consequently, we need only \(\,m!\) variables \(\,y_\pi\), irrespective of the support size. In these variables, every \(\,s_i(c)\) and \(\,p_i(c)\) is an affine function with rational coefficients.

2. Express SkS through lexicographic comparison

For a prospective first majority stage \(\,j\), define

\(\displaystyle V_j(c;y)=\bigl(s_j(c),-p_j(c),s_{j+1}(c),-p_{j+1}(c),\ldots,s_m(c),-p_m(c)\bigr).\)

For vectors of equal length, write \(\,u>_{\mathrm{lex}}v\) when their first differing coordinate is larger in \(\,u\).

Lemma 2. If the actual first majority stage is \(\,j\), the SkS winner set is exactly the set of lexicographic maximizers of \(\,V_j(c;y)\) over \(\,c\in C\). In particular, the target is the unique winner exactly when

\(\displaystyle V_j(c^\star;y)>_{\mathrm{lex}}V_j(d;y)\qquad\text{for every }d\in C\setminus\{c^\star\}.\)

Proof. At stage \(\,j\), maximizing \(\,s_j\) retains precisely the maximizers of the first coordinate. Minimizing \(\,p_j\) among those candidates retains precisely the lexicographic maximizers of the first two coordinates.

Inductively, suppose the active candidates are the lexicographic maximizers of the coordinates processed so far. All those candidates have the same processed prefix. Maximizing the next score and then minimizing the next position sum therefore retains precisely the lexicographic maximizers of the extended prefix. A candidate eliminated earlier has a strictly smaller processed prefix; later coordinates cannot reverse that comparison.

If a singleton remains, its candidate is also the unique maximizer of the full vector, so early termination causes no discrepancy. Otherwise, at stage \(\,m\), all coordinates have been processed, and the rule returns exactly the full-vector maximizers. This proves the lemma.

3. Enumerate the first differing coordinates

Fix \(\,j\in\{1,\ldots,m\}\), and let \(\,r_j=2(m-j+1)\) be the length of \(\,V_j\). Denote its coordinates by \(\,V_{j,\ell}(c;y)\).

For each rival \(\,d\neq c^\star\), choose an index

\(\displaystyle k_d\in\{1,\ldots,r_j\}.\)

The intended meaning is that \(\,k_d\) is the first coordinate at which the target and that rival differ.

For these choices, impose the following linear conditions:

  • Achievable manipulator mass:

\(\displaystyle y_\pi\geq0\quad\text{for all }\pi,\qquad \sum_\pi y_\pi=Q.\)

  • No majority before the chosen stage:

\(\displaystyle s_i(c)\leq W/2\quad\text{for every }c\in C\text{ and every }i<j.\)

  • A target majority at the chosen stage:

\(\displaystyle s_j(c^\star)>W/2.\)

  • The chosen first difference against every rival:

\(\displaystyle V_{j,\ell}(c^\star;y)=V_{j,\ell}(d;y)\quad\text{for every }\ell<k_d,\)

\(\displaystyle V_{j,k_d}(c^\star;y)>V_{j,k_d}(d;y).\)

Lemma 3. A successful allocation exists if and only if at least one of these systems is feasible.

Proof. Suppose a successful allocation exists, and let \(\,j\) be its actual first majority stage. Conditions 1 and 2 hold by definition.

The target must survive the score comparison at stage \(\,j\); otherwise it could never win. Its score therefore equals the maximum score at that stage. Since some candidate has a strict majority, the target does too, establishing condition 3.

By Lemma 2, the target’s vector is strictly lexicographically larger than each rival’s. Choosing each rival’s actual first differing coordinate establishes condition 4.

Conversely, a feasible system gives an allocation by Lemma 1. Conditions 2 and 3 make \(\,j\) its actual first majority stage. Condition 4 makes the target’s vector strictly lexicographically larger than every rival’s. Lemma 2 then proves that the target is the unique SkS winner.

4. Handle strict inequalities exactly

Each enumerated system contains both weak and strict linear inequalities. Introduce one additional variable \(\,\varepsilon\), with

\(\displaystyle 0\leq\varepsilon\leq1.\)

Replace its strict inequalities by

\(\displaystyle s_j(c^\star)-W/2\geq\varepsilon,\)

and, for each rival,

\(\displaystyle V_{j,k_d}(c^\star;y)-V_{j,k_d}(d;y)\geq\varepsilon.\)

Keep all other constraints and maximize \(\,\varepsilon\).

Lemma 4. The original system is feasible exactly when this ordinary linear program is feasible and has optimum strictly greater than zero.

Proof. At any point satisfying the original system, all its strict-inequality gaps are positive. There are finitely many such gaps. Their minimum, capped at \(\,1\), is therefore a positive feasible value of \(\,\varepsilon\).

Conversely, any feasible point with \(\,\varepsilon>0\) satisfies every original strict inequality.

Finally, the new feasible region is closed and bounded: each \(\,y_\pi\) lies between \(\,0\) and \(\,Q\), and \(\,\varepsilon\) lies between \(\,0\) and \(\,1\). Hence, if nonempty, it attains its maximum. The claimed equivalence follows.

Thus the algorithm uses an exact comparison of the rational optimum with zero. It requires no predetermined numerical tolerance.

5. Bit complexity and running time

The number of enumerated systems is

\(\displaystyle N_m=\sum_{j=1}^{m}\bigl(2(m-j+1)\bigr)^{m-1}\leq m(2m)^{m-1}.\)

Each linear program has \(\,m!+1\) variables and \(\,O(m!+m^2)\) constraints. The latter bound includes nonnegativity, the mass equation, earlier-majority constraints, prefix equalities, comparison inequalities, and bounds on \(\,\varepsilon\).

All coefficients are rational with polynomially bounded encoding length. To check this explicitly, write each input mass as \(\,\mu_t=n_t/d_t\). A common denominator is

\(\displaystyle D=\prod_t d_t.\)

Its binary length is at most the sum of the input denominator lengths, hence \(\,O(L)\). Computing \(\,b_\pi\), \(\,Q\), \(\,W\), and the sincere contributions to the scores and position sums involves rational sums with this denominator, input weights, and position factors at most \(\,m\). Their encoding lengths are polynomial in \(\,m,\tau,L\). Variable coefficients are differences of integers whose absolute values are at most \(\,m\).

We use the standard rational linear-programming theorem: feasibility and exact optimization of a rational linear program take time polynomial in its binary encoding length. This is the polynomial-time linear-programming result originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319). Its hypotheses hold here because every program has explicitly encoded rational data; moreover, each feasible program has a bounded feasible region.

The resulting bit running time is bounded by

\(\displaystyle \operatorname{poly}(m,\tau,L)+N_m\,\operatorname{poly}(m!,m,\tau,L),\)

where the polynomial degrees are independent of \(\,m,\tau,L\). Equivalently, it is \(\,f(m)\operatorname{poly}(\tau,L)\).

For \(\,m=4\), the branch count is

\(\displaystyle N_4=8^3+6^3+4^3+2^3=800.\)

Every program then has \(\,24+1=25\) variables and a constant number of constraints. The overall running time is therefore \(\,\operatorname{poly}(\tau,L)\).

6. Relation to discrete manipulation

The cited discrete hardness result concerns assigning each indivisible voter weight to one ballot: [Theorem 3 of Horn et al.](https://arxiv.org/pdf/2511.22384). In the present continuous model, Lemma 1 proves that every nonnegative distribution of total manipulator weight across ballots is attainable. This removes the discrete assignment restriction and makes the finite family of linear programs exact.

Therefore, the continuous unique-winner manipulation problem specified in the question is polynomial-time solvable for four candidates.
