Theorem 4 — class: algorithmic

The continuous mirror question, as graded

Given a distinguished root with a valuation oracle, a finite support \(\Theta\) of branch types with rational masses \(\mu_\theta\), and a specified cake-capacity measure \(\sigma\) that accounts for per-capita branch supply and the root’s bundle, compute a locally envy-free allocation. A type records its manager’s valuation and whether it has a leaf, including that leaf’s valuation. The output is a root bundle and, for each type, a finite-support distribution over deterministic manager–leaf bundle assignments; every realized assignment must satisfy the paper’s local envy inequalities, and total mass-weighted cake use plus the root’s use must respect \(\sigma\). What is the Robertson–Webb query complexity in \(\tau=|\Theta|\), the input bit length \(L\), and output size \(S\)?

Packaged proof task (what the prover saw — nothing else)

The cake is \([0,1]\). A society is given by its support: \(\tau\geq1\) branch types with positive binary-rational masses \(\mu_\theta\) summing to \(1\); \(\tau\) counts listed types, not possible types. There is also one distinguished root of mass \(1\).
Type \(\theta\) specifies a manager valuation \(v_\theta\), a flag \(b_\theta\in\{0,1\}\), and, when \(b_\theta=1\), a leaf valuation \(w_\theta\). All valuations, including the root valuation \(v_r\), are nonnegative, additive, nonatomic probability measures accessible through standard Robertson–Webb queries.
The capacity measure is \(\sigma(E)=\int_E s(x)\,dx\), where the nonnegative piecewise-constant density \(s\) is explicitly specified on \(m\) intervals by binary-rational breakpoints and heights. Let \(L\) be the total explicit input bit length.
An allocation consists of a root bundle \(A_r\) and, for each type, finitely many assignments \((M_{\theta j},F_{\theta j})\) with positive probabilities \(p_{\theta j}\) summing to \(1\). Bundles are finite unions of intervals; \(F_{\theta j}=\varnothing\) when \(b_\theta=0\), and bundles within each realized root–manager–leaf branch are pairwise disjoint, apart from endpoints.
Every assignment must satisfy \(v_r(A_r)\geq v_r(M_{\theta j})\) and \(v_\theta(M_{\theta j})\geq v_\theta(A_r)\); when a leaf is present, also require \(v_\theta(M_{\theta j})\geq v_\theta(F_{\theta j})\) and \(w_\theta(F_{\theta j})\geq w_\theta(M_{\theta j})\). Indifference is allowed.
Complete allocation means equality of measures: \(\mathbf1_{A_r}\,dx+\sum_\theta\mu_\theta\sum_jp_{\theta j}(\mathbf1_{M_{\theta j}}+\mathbf1_{F_{\theta j}})\,dx=\sigma\). Assume an allocation of this form exists. Let \(S\) count output assignments, interval endpoints, and probability entries, with exact real quantities represented in the Robertson–Webb model.

Does computing such an allocation admit a polynomial-time protocol in \(m,\tau,L,S\), using unit-cost exact arithmetic and Robertson–Webb queries, or is it NP-hard already with explicitly given rational piecewise-constant valuation densities?
What is the worst-case Robertson–Webb query complexity in \(m,\tau,L,S\)?

For a finite society on a rooted tree where each non-root vertex has degree at most \(2\), a complete locally envy-free allocation can be computed using \(O(n^2)\) cut queries and \(O(n^3)\) evaluation queries. [Source](https://arxiv.org/pdf/2211.06458)
No result settling this precise mass-weighted, finite-support allocation problem was located.

  • Required pairwise disjoint bundles within each realized root–manager–leaf branch; overlap across different assignments is governed by aggregate capacity.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The two valuation-access models have different answers.

  • Robertson–Webb access: there is no exact protocol that terminates on every promised feasible instance. This already holds with \(m=1\), \(\tau=2\), no leaves, and a constant-size feasible allocation. Consequently, there is no finite worst-case query bound in \(m,\tau,L,S\).
  • Explicit rational piecewise-constant densities: feasibility has a polynomial-size linear-programming characterization. An allocation can be constructed in time \(\operatorname{poly}(m,\tau,L,S)\), with zero Robertson–Webb queries.
  • The output parameter \(S\) is essential: even with one type and uniform valuations, an input of length \(O(B)\) can require at least \(2^B\) assignments.

Here, the output-sensitive bound means polynomial time in the size of the allocation actually produced. It does not assert that this size is polynomial in the input.

1. What completeness forces

Write \(\lambda\) for Lebesgue measure and put

\(q_{\theta j}=\mu_\theta p_{\theta j}>0.\)

These weights sum to \(1\). Away from the finitely many bundle endpoints, define

\(U_{\theta j}(x)=\mathbf 1_{M_{\theta j}\cup F_{\theta j}}(x).\)

Disjointness within each realized branch gives

\(\mathbf 1_{A_r}(x)+U_{\theta j}(x)\leq 1.\)

Completeness therefore implies

\(s(x)=\mathbf 1_{A_r}(x)+\sum_{\theta,j}q_{\theta j}U_{\theta j}(x)\leq 1\)

almost everywhere. It also implies that \(s=1\) almost everywhere on \(A_r\).

There is a stronger conclusion wherever \(s=1\) outside the root bundle: there,

\(\sum_{\theta,j}q_{\theta j}U_{\theta j}(x)=1.\)

Every summand has \(U_{\theta j}(x)\leq1\), and every weight is positive. Hence every \(U_{\theta j}(x)\) must equal \(1\).

In particular, if \(s\equiv1\) and there are no leaves, every realized manager bundle is the root’s complement, up to a Lebesgue-null set. For the absolutely continuous valuations used below, this also gives equality of their values.

2. A feasible subclass that forces exact bisection

Fix the following explicit data:

\(s\equiv1,\qquad \tau=2,\qquad \mu_1=\mu_2=\tfrac12,\qquad b_1=b_2=0.\)

The root valuation is \(v_r=\lambda\). Choose any measurable density \(f\) satisfying

\(\tfrac12\leq f(x)\leq\tfrac32,\qquad \int_0^1 f(x)\,dx=1,\)

and give the two managers densities \(f\) and \(2-f\), respectively. These are positive nonatomic probability measures.

Let

\(a=\lambda(A_r),\qquad u=\int_{A_r}f(x)\,dx.\)

By Section 1, every manager receives the complement of \(A_r\). The root’s envy inequalities imply \(a\geq1-a\), so \(a\geq\tfrac12\). The two managers’ inequalities imply

\(u\leq\tfrac12,\qquad 2a-u\leq\tfrac12.\)

Consequently,

\(1\leq2a\leq u+\tfrac12\leq1.\)

Thus every valid allocation must satisfy

\(\lambda(A_r)=\int_{A_r}f(x)\,dx=\tfrac12.\)

Conversely, any finite union satisfying these equalities gives a valid allocation by assigning its complement to both managers, with one probability-\(1\) assignment per type.

Every instance in this subclass is feasible with constant-size output. To see this, define the cumulative function

\(F(x)=\int_0^x f(t)\,dt\)

and the continuous function

\(h(t)=F(t+\tfrac12)-F(t),\qquad 0\leq t\leq\tfrac12.\)

Its endpoint values satisfy

\(h(0)=F(\tfrac12),\qquad h(\tfrac12)=1-F(\tfrac12).\)

They lie on opposite sides of \(\tfrac12\), or both equal it. The intermediate value theorem gives a \(t\) with \(h(t)=\tfrac12\). Taking

\(A_r=[t,t+\tfrac12]\)

works. Each manager’s complement has at most two intervals.

The remaining issue is whether queries can always locate *some* finite union giving this exact bisection.

3. No everywhere-terminating exact Robertson–Webb protocol

The following adversary proves impossibility even when the protocol can query all three valuations and choose arbitrary real endpoints through exact arithmetic.

3.1 The maintained invariant

Maintain a finite ordered set of recorded endpoints

\(0=x_0<x_1<\cdots<x_k=1\)

and cumulative values \(F(x_i)\), with \(F(0)=0\), \(F(1)=1\), such that

\(\tfrac12<\dfrac{F(x_{i+1})-F(x_i)}{x_{i+1}-x_i}<\tfrac32.\)

Maintain also this invariant:

No union \(B\) of the current elementary intervals has both
\(\lambda(B)=\tfrac12\) and \(F(B)=\tfrac12\).

Here, \(F(B)\) means the sum of the relevant cumulative increments. Initially there is one elementary interval, so the invariant holds.

The manager cumulative functions are \(F(x)\) and

\(G(x)=2x-F(x).\)

Their slopes satisfy the same strict bounds.

3.2 Inserting a prescribed endpoint

Suppose a new endpoint \(z\) is prescribed inside an existing elementary interval.

The strict slope constraints leave a nonempty open interval of permissible values for \(F(z)\): the old affine interpolation supplies one permissible value, with room to perturb it.

Consider any union of the refined elementary intervals.

  • If it selects both subintervals adjacent to \(z\), or neither, it represents an old union, so the invariant already excludes simultaneous bisection.
  • If it selects exactly one, its \(F\)-value has the form \(C+F(z)\) or \(C-F(z)\), where \(C\) is fixed.

For each such union having length \(\tfrac12\), at most one value of \(F(z)\) makes its value \(\tfrac12\). There are finitely many unions. Excluding these finitely many values from a nonempty open interval leaves a permissible choice.

Thus prescribed endpoints can always be inserted while preserving the invariant.

3.3 Answering queries

For an evaluation query, insert its endpoints by the preceding procedure. Then answer by cumulative differences: \(F(y)-F(x)\), \(G(y)-G(x)\), or \(y-x\), as appropriate.

For a cut query to the \(F\)-manager, first insert its starting endpoint \(x\). Let the requested cumulative level be \(F(x)+\alpha\).

If that level already occurs at a recorded endpoint, return that endpoint. Otherwise, it lies strictly between two consecutive recorded cumulative values. Under the current affine interpolation, its inverse lies strictly inside that elementary interval. A nonempty open interval of nearby endpoints \(z\) remains compatible with the strict slope bounds when assigned the prescribed cumulative value.

Choose \(z\) from this open interval. Any new union selecting exactly one subinterval adjacent to \(z\) has length \(C+z\) or \(C-z\). At most one \(z\) gives length \(\tfrac12\). Excluding these finitely many endpoints preserves the invariant.

A cut query to the \(G\)-manager is handled identically, prescribing \(G(z)\), equivalently \(F(z)=2z-G(z)\). A cut query to the uniform root prescribes an endpoint, so Section 3.2 applies.

All valid standard Robertson–Webb queries can therefore be answered consistently.

3.4 A terminating protocol cannot be correct

Suppose the protocol terminates. Insert every endpoint occurring in its finite output by Section 3.2. This does not change any previous answer.

Complete \(F\) by affine interpolation between the recorded points. The resulting density is piecewise constant and strictly between \(\tfrac12\) and \(\tfrac32\). It defines a feasible instance by Section 2 and reproduces every query answer.

The output root bundle is a union of the final elementary intervals, apart from endpoints. By the invariant, it cannot bisect both \(\lambda\) and \(F\). Section 2 shows that the output is therefore invalid.

3.5 An infinite interaction corresponds to a feasible instance

If the interaction continues forever, its recorded values remain consistent with

\(\tfrac12(y-x)\leq F(y)-F(x)\leq\tfrac32(y-x).\)

Extend \(F\) continuously to the closure of all recorded endpoints, and interpolate affinely across the remaining gaps. The extension satisfies these bounds everywhere. It is Lipschitz, hence absolutely continuous, with derivative between \(\tfrac12\) and \(\tfrac32\) almost everywhere.

Both \(F\) and \(G=2x-F\) are strictly increasing, so their cuts are unique. The resulting valuations reproduce the entire interaction. Section 2 again supplies a constant-size feasible allocation.

Thus an infinite interaction makes the protocol nonterminating on an actual promised feasible instance.

Conclusion. No deterministic exact Robertson–Webb protocol terminates correctly on every promised instance. In particular, no polynomial—or even finite—worst-case query bound exists. The obstruction persists with constant \(m,\tau,L\) and constant-size feasible witnesses.

4. Explicit rational densities: an exact linear program

Now suppose all valuation densities are explicitly given as rational piecewise-constant functions, with their descriptions included in \(L\).

Refine their breakpoints and the capacity breakpoints into common cells \(I_1,\ldots,I_K\). Let \(\ell_k=\lambda(I_k)\). On cell \(k\), write the densities as

\(s_k,\qquad d^r_k,\qquad d^\theta_k,\qquad e^\theta_k,\)

where the last is used only for types with leaves. The number \(K\) and all coefficient bit lengths are polynomially bounded by \(L\).

If any positive-length cell has \(s_k>1\), the instance is infeasible by Section 1. Otherwise introduce variables:

  • \(a_k\): root length in cell \(k\);
  • \(x_{\theta k}\): expected manager length in that cell;
  • \(y_{\theta k}\): expected leaf length in that cell.

Impose nonnegativity and the constraints

\(0\leq a_k\leq\ell_k,\qquad a_k=0\text{ if }s_k\ne1,\)

\(x_{\theta k}+y_{\theta k}\leq\ell_k-a_k,\)

\(a_k+\sum_\theta\mu_\theta(x_{\theta k}+y_{\theta k})=s_k\ell_k.\)

Set \(y_{\theta k}=0\) for leafless types. The envy inequalities are

\(\sum_k d^r_k(a_k-x_{\theta k})\geq0,\)

\(\sum_k d^\theta_k(x_{\theta k}-a_k)\geq0,\)

and, for types with leaves,

\(\sum_k d^\theta_k(x_{\theta k}-y_{\theta k})\geq0,\)

\(\sum_k e^\theta_k(y_{\theta k}-x_{\theta k})\geq0.\)

Necessity

Given an allocation, take the root lengths and the probability-weighted manager and leaf lengths in each cell.

Disjointness gives the length bounds, completeness gives the capacity equations, and Section 1 gives the restriction on root lengths. Averaging each realized envy inequality gives its displayed LP inequality.

Hence every valid allocation induces an LP solution.

Sufficiency

Take a rational feasible LP solution. Allocate a prefix of length \(a_k\) in each cell to the root. Its complement within that cell is an interval of length

\(c_k=\ell_k-a_k.\)

If \(c_k=0\), all manager and leaf lengths there are zero. For every other cell, the ratios

\(\dfrac{x_{\theta k}}{c_k},\qquad \dfrac{y_{\theta k}}{c_k}\)

are rational. Choose a positive integer \(D\) divisible by all their denominators. Put

\(h_{\theta k}=D\,\dfrac{x_{\theta k}}{c_k},\qquad g_{\theta k}=D\,\dfrac{y_{\theta k}}{c_k}.\)

These are nonnegative integers with \(h_{\theta k}+g_{\theta k}\leq D\).

Partition each nonempty cell complement into \(D\) equal consecutive blocks. For type \(\theta\), create \(D\) assignments, indexed by \(j=0,\ldots,D-1\), each with probability \(1/D\). In cell \(k\), using cyclic block indices:

  • give the manager \(h_{\theta k}\) consecutive blocks starting at \(j\);
  • give the leaf the next \(g_{\theta k}\) blocks.

Manager and leaf blocks are disjoint. Each bundle contributes at most two intervals per cell.

Every assignment has manager length \(x_{\theta k}\) and leaf length \(y_{\theta k}\) in every cell. Since densities are constant within cells, every assignment has exactly the valuation vector used in the LP. Thus all realized envy inequalities hold.

Each block belongs to the manager–leaf union in exactly \(h_{\theta k}+g_{\theta k}\) shifts. Its expected occupancy for type \(\theta\) is therefore

\(\dfrac{x_{\theta k}+y_{\theta k}}{c_k}.\)

Outside the root, total expected occupancy equals

\(\dfrac{\sum_\theta\mu_\theta(x_{\theta k}+y_{\theta k})}{c_k} =\dfrac{s_k\ell_k-a_k}{\ell_k-a_k}.\)

If \(s_k=1\), this is \(1\). If \(s_k\ne1\), then \(a_k=0\), and it is \(s_k\). Root-occupied regions have \(s_k=1\). Hence completeness holds as an equality of measures.

This proves sufficiency.

Complexity

The LP is rational, bounded, and has polynomially many variables and constraints with polynomial coefficient bit length. Polynomial-time rational linear programming therefore decides feasibility and returns a rational feasible solution of polynomial bit length.

The product of the ratio denominators is a valid \(D\), with polynomial bit length, although its numerical value can be exponential.

The construction uses \(D\tau\) assignments and \(O(K)\) work per assignment. Since the output count satisfies \(S\geq D\tau\), its running time is

\(\operatorname{poly}(L,m,\tau)+O(KS).\)

All output endpoints and probabilities are rational. No valuation queries are required.

Thus explicit-density feasibility is in \(\mathrm P\), and the stated output-sensitive search bound holds.

5. Exponential output can be unavoidable

Let \(B\geq1\), put \(c=2^{-B}\), and use one leafless type of mass \(1\). Give both root and manager the uniform valuation. Set

\(s(x)=1\text{ on }[0,c],\qquad s(x)=c\text{ on }(c,1].\)

Here \(m=2\), \(\tau=1\), and \(L=O(B)\).

In any valid allocation, the two envy inequalities force every realized manager bundle to have the same length as the root. Write this length as \(a\). Integrating completeness gives

\(2a=\int_0^1s(x)\,dx=2c-c^2,\)

so

\(a=c-\tfrac12c^2<c.\)

Because capacity is positive everywhere, the union of all manager assignments must cover the root’s complement almost everywhere. If there are \(N\) assignments, subadditivity gives

\(1-a\leq Na.\)

Therefore,

\(N\geq\dfrac{1-a}{a}>\dfrac{1-c}{c}=2^B-1.\)

As \(N\) is an integer, every allocation has at least \(2^B\) assignments.

This lower bound is attained. Let \(D=2^B\), allocate \(A_r=[0,a]\), and partition \([c,1]\) into \(D\) equal intervals \(J_1,\ldots,J_D\). Use

\(M_j=[a,c]\cup J_j,\qquad p_j=c.\)

The probabilities sum to \(1\). Every manager bundle has length

\((c-a)+c(1-c)=\tfrac12c^2+c-c^2=a,\)

so both envy inequalities hold. Every assignment covers \([a,c]\), while each \(J_j\) is covered with probability \(c\). Completeness follows.

Thus the minimum number of assignments is exactly \(2^B\). An input-only polynomial-time algorithm cannot enumerate the required output.

6. Relation to the cited finite-tree result

The cited polynomial bound is Theorem 4 for the paper’s 2-star class, which also has depth at most two. Its completeness condition partitions the cake among individual vertices. [Ghalme–Huang–Machino–Rathi, Theorem 4](https://arxiv.org/pdf/2211.06458)

Mass-weighted completeness behaves differently. In the leafless instance of Section 2, both managers must receive the entire root complement. This forces simultaneous exact bisection and creates the query obstruction, even though the underlying root–manager graph is a star.

Accordingly, the proposed alternatives are not exhaustive: the general oracle problem is not finitely solvable, whereas the explicit rational-density problem admits the requested output-polynomial construction. Its feasibility is polynomial-time decidable; exponentially large mandatory output explains why an input-only enumeration bound is unavailable.
