The continuous mirror question, as graded

Input a finite set of agent types \(T\), a compatibility graph \(H\) on \(T\), a strict preference order \(\prec_t\) over each type’s neighbors, and rational masses \(\mu_t>0\) summing to \(1\). Choose deletion amounts \(d_t\in[0,\mu_t]\) to minimize \(\sum_{t\in T}d_t\), subject to the induced preference system on \(R_d=\{t:\mu_t-d_t>0\}\) admitting a master list. What is the optimum and an optimal deletion?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau=|T|\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Input also a simple undirected compatibility graph \(H=(T,E)\) and a strict total preference order \(\prec_t\) over \(N_H(t)\) for each type. Write \(a\prec_t b\) when \(t\) prefers \(b\) to \(a\).
Choose real deletion amounts \(0\leq d_t\leq\mu_t\). The surviving system has graph \(H[R_d]\), where \(R_d=\{t\in T:\mu_t-d_t>0\}\), and each surviving type’s preferences are restricted to its surviving neighbors.
A master list is a strict total order on \(R_d\) whose restriction to each surviving neighborhood equals that type’s restricted preference order. The empty surviving system is allowed and admits the empty master list; remaining masses are not renormalized.
Minimize \(\sum_{t\in T}d_t\) subject to admitting a master list, and compute the exact optimum and an optimal deletion vector. Let \(m=|E|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this minimum-mass deletion problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathsf{NP}\)-hard?

For finite agents with unit deletion costs, Master List by Vertex Deletion is \(\mathsf{NP}\)-hard and \(\mathsf{W}[2]\)-hard parameterized by the allowed number \(k\) of deletions, even on bipartite graphs with strict preferences ([source](https://arxiv.org/pdf/2212.03521)).
No result for the exact mass formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Specified the compatibility graph as simple and undirected, following the discrete graph domain.
  • Defined the induced surviving system by restricting both the graph and each surviving type’s neighborhood preferences.
  • Specified a strict total master list for the strict-preference setting and fixed the preference-order orientation.
  • Allowed real deletion amounts, allowed the empty surviving system, and retained the original mass scale after deletion.
  • Defined m as the number of compatibility edges and L as the total binary input length.

Result

The minimum-mass deletion problem is \(\mathsf{NP}\)-hard, even when the compatibility graph is bipartite and all masses are equal dyadic rationals. Its rational-budget decision version is \(\mathsf{NP}\)-complete.

The key point is that feasibility depends only on which types have positive surviving mass. Partial deletion of a surviving type cannot help.

1. Reduction to weighted vertex deletion

Write \(I[R]\) for the preference system induced by a subset \(R\subseteq T\), with preferences restricted to surviving neighbors.

Lemma. Every optimal deletion vector satisfies \(d_t\in\{0,\mu_t\}\) for every \(t\). Moreover,
\[ \operatorname{OPT} = \min_{\substack{S\subseteq T\\ I[T\setminus S]\text{ admits a master list}}} \sum_{t\in S}\mu_t. \]

Proof. Let \(d\) be any feasible deletion vector, and define
\[ S=\{t\in T:d_t=\mu_t\}. \]
The surviving support is exactly \(T\setminus S\). Define another vector by
\[ \widehat d_t= \begin{cases} \mu_t,&t\in S,\\ 0,&t\notin S. \end{cases} \]
Because every mass is positive, \(d\) and \(\widehat d\) have the same surviving support. They therefore induce exactly the same graph and restricted preferences, so \(\widehat d\) is feasible. Also,
\[ \sum_{t\in T}\widehat d_t=\sum_{t\in S}\mu_t \leq \sum_{t\in T}d_t. \]
The inequality is strict whenever some \(t\notin S\) has \(d_t>0\).

Conversely, every subset \(S\) appearing in the displayed minimum gives a feasible vector by deleting precisely its types completely. Thus the two optimization problems have identical values. The minimum is attained because there are finitely many subsets, and \(S=T\) is feasible. The strict inequality above proves the assertion about every optimum. \(\square\)

This also resolves the potential issue caused by the strict survival condition: the optimum exists despite allowing arbitrary real deletion amounts.

2. Recognizing feasible surviving supports

For a proposed surviving support \(R\), construct a directed graph \(D_R\) with vertex set \(R\).

For each \(t\in R\), list its surviving neighbors from least to most preferred:
\[ a_1\prec_t a_2\prec_t\cdots\prec_t a_r. \]
Insert the arcs \(a_i\to a_{i+1}\) for \(1\leq i<r\). Parallel arcs may be retained.

Lemma. The system \(I[R]\) admits a master list if and only if \(D_R\) is acyclic.

Proof. If a master list exists, every inserted arc points forward in that strict total order. A directed cycle would require a vertex to precede itself, contradicting transitivity and irreflexivity. Hence \(D_R\) is acyclic.

Conversely, suppose \(D_R\) is acyclic. Take a topological order of its vertices. For every surviving type \(t\), the inserted arcs force \(a_i\) to precede \(a_{i+1}\). Transitivity then forces \(a_i\) to precede \(a_j\) whenever \(i<j\). Thus the topological order restricts to exactly \(t\)'s preference order on its surviving neighborhood. It is a master list. \(\square\)

There are at most
\[ \sum_{t\in R}\max\{\deg_{H[R]}(t)-1,0\}\leq 2m \]
inserted arcs. Filtering the original preference lists, constructing these arcs, and testing acyclicity therefore takes \(O(m+\tau)\) elementary graph operations. This construction must be performed using the surviving lists: deleting a type also removes the constraints contributed by that type.

3. Polynomial reduction proving hardness

We use the following established theorem: Master List by Vertex Deletion is \(\mathsf{NP}\)-hard on bipartite graphs with strict preferences, where the question is whether deleting at most \(k\) vertices leaves a system admitting a master list. This is Theorem 8 of [Schlotter, *Recognizing when a preference system is close to admitting a master list*](https://arxiv.org/pdf/2212.03521).

Take such an instance \(I=(G,\{\prec_v\})\), with \(n\geq 1\) vertices and deletion budget \(k\). Let
\[ N=2^{\lceil\log_2 n\rceil}. \]
Add \(N-n\) isolated vertices, retaining every original edge and preference list. Make each of the resulting \(N\) vertices a distinct supported type, and assign
\[ \mu_t=\frac1N \]
to every type. The masses are positive dyadic rationals and sum to \(1\). Set the mass budget to \(b=k/N\).

Let \(\delta(I)\) denote the minimum number of vertex deletions in the original instance. We claim that the constructed mass instance satisfies
\[ \operatorname{OPT}=\frac{\delta(I)}N. \]

First, deleting an optimal original vertex set and retaining all added isolated types gives a feasible system: a master list for the original survivors extends by inserting the isolated types anywhere. Hence
\[ \operatorname{OPT}\leq\frac{\delta(I)}N. \]

For the reverse inequality, let \(S\) be any feasible whole-type deletion set in the constructed instance. Restrict its surviving master list to the original surviving vertices. This restriction is a master list for the original instance after deleting \(S\cap V(G)\). Consequently,
\[ \delta(I)\leq |S\cap V(G)|\leq |S|, \]
and its deleted mass is \(|S|/N\). Section 1 therefore gives
\[ \operatorname{OPT}\geq\frac{\delta(I)}N. \]
This proves the claim and, in particular,
\[ \delta(I)\leq k \quad\Longleftrightarrow\quad \operatorname{OPT}\leq b. \]

The construction preserves bipartiteness and strict preferences. It has \(\tau=N<2n\), leaves \(m\) unchanged, and encodes each mass using \(O(\log(n+1))\) bits. Its output length is polynomial in the source input length.

Thus the reduction proves \(\mathsf{NP}\)-hardness. Computing either the exact optimum or an optimal deletion vector would decide the source problem in polynomial time if such an algorithm existed.

For completeness, the rational-budget decision problem belongs to \(\mathsf{NP}\): a certificate is a subset \(S\). Its total mass can be compared with the budget by exact rational arithmetic, and feasibility can be checked by Section 2. Both checks have polynomial running time in the augmented binary input length. Therefore this decision problem is \(\mathsf{NP}\)-complete.

4. Exact computation and running time

An exact algorithm enumerates all \(2^\tau\) deletion sets \(S\), checks feasibility using Section 2, and retains a feasible set of minimum mass. It returns
\[ d_t^*= \begin{cases} \mu_t,&t\in S^*,\\ 0,&t\notin S^*, \end{cases} \qquad \operatorname{OPT}=\sum_{t\in S^*}\mu_t. \]

Here is an explicit bound including rational arithmetic. Write each input mass as \(\mu_t=p_t/q_t\), with positive binary integers, and compute
\[ Q=\prod_{t\in T}q_t, \qquad w_t=p_t(Q/q_t). \]
The binary length of \(Q\) is \(O(L)\). Since \(0<\mu_t\leq 1\), each \(w_t\) has \(O(L)\) bits. Using schoolbook integer arithmetic, computing \(Q\) and all \(w_t\) takes \(O(\tau L^2)\) bit operations. Each subset weight is then computed with \(O(\tau L)\) bit operations, and exact comparison uses the common denominator \(Q\).

Charging \(O(\log(\tau+1))\) bit cost for graph indices and counters gives the total bound
\[ O\!\left( \tau L^2+ 2^\tau\bigl((m+\tau)\log(\tau+1)+\tau L\bigr) \right). \]
The unreduced fraction \(\bigl(\sum_{t\in S^*}w_t\bigr)/Q\) already represents the exact optimum.

Hence exact computation is available with exponential dependence on the support size \(\tau\); a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathsf P=\mathsf{NP}\).
