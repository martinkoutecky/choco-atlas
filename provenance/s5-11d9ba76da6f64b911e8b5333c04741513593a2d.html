The continuous mirror question, as graded

Given a finite type set \(Q\), rational population masses \(\mu\), and an explicitly represented rational polynomial \(F:[0,\mu]\to\mathbb{Q}\) with \(F(0)=0\), define the \(r\)-player game by \(v_r(S)=rF(k(S)/r)\), where \(k(S)\) counts each type in coalition \(S\) and \(r\mu_q\) is integral for every \(q\in Q\). For each \(q\in Q\), compute the limit as \(r\to\infty\) of the average solidarity payoff of type-\(q\) players.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(Q\) of \(\tau\) types with positive binary rational masses \(\mu_q\), normalized by \(\sum_q\mu_q=1\). Here \(\tau\) is the support size, not the number of possible types.
The input polynomial \(F:\prod_{q\in Q}[0,\mu_q]\to\mathbb R\) has rational coefficients of arbitrary sign and satisfies \(F(0)=0\); it is given as an explicit list of \(m\) monomials with unary nonnegative integer exponents. Let \(d\) be its total degree and \(L\) the total input bit length.
For each positive integer \(r\) with every \(r\mu_q\) integral, let \(N_r\) contain \(r\mu_q\) players of type \(q\). For \(S\subseteq N_r\), let \(k_q(S)\) count its type-\(q\) members and set \(v_r(S)=rF(k(S)/r)\).
For any finite TU game \((N,v)\), define \(a_v(S)=|S|^{-1}\sum_{j\in S}[v(S)-v(S\setminus\{j\})]\) for nonempty \(S\), and the solidarity payoff \(\operatorname{Sol}_i(N,v)=\sum_{S\subseteq N:i\in S}\frac{(|N|-|S|)!(|S|-1)!}{|N|!}a_v(S)\).
Define \(A_q(r)=(r\mu_q)^{-1}\sum_{i\in N_r:\operatorname{type}(i)=q}\operatorname{Sol}_i(N_r,v_r)\), the average payoff per type-\(q\) player.

Do all limits \(\ell_q=\lim_{r\to\infty}A_q(r)\), along the admissible integers, exist as rational numbers, and is their exact computation polynomial-time in \(m,\tau,d,L\), or NP-hard?

For finite TU games, the solidarity payoff has a dividend decomposition with coalition coefficient \(\frac{1}{|T|}\binom{|N|}{|T|}^{-1}\); this is an identity, not a polynomial-time complexity bound. [Source](https://doi.org/10.1007/s43069-026-00638-x).
A continuum NTU solidarity value has been defined, with existence and uniqueness of its asymptotic counterpart left conjectural; this does not establish the complexity of the polynomial TU limit problem above. [Source](https://mpra.ub.uni-muenchen.de/142/1/MPRA_paper_142.pdf).

Modeling choices made when packaging the task

  • Normalized the positive masses to sum to one so that the construction really has r players; excluded the empty support.
  • Interpreted the polynomial as real-valued on the real box, with rational coefficients and no sign or monotonicity restrictions, as appropriate for unrestricted TU games.
  • Specified an explicit monomial list with unary exponents; defined m as the number of listed monomials, d as total degree, and L as total input bit length.
  • Took the limit over positive integers satisfying all population integrality constraints.
  • Interpreted average solidarity payoff as payoff per player within a type, without additional rescaling.
  • Included existence and rationality of the limits in the target because exact rational computation otherwise lacks a defined output.

Result

All limits exist, are rational, and admit exact polynomial-time computation. In fact, every type has the same limit:

\(\displaystyle \ell_q=F(\mu)\qquad(q\in Q),\)

where \(\mu=(\mu_q)_{q\in Q}\).

The proof below gives an explicit bound on convergence and then establishes the bit complexity of exact evaluation. It uses only the stated finite-game definition.

1. Rewriting the solidarity payoff

Fix an admissible integer \(r\). Normalization gives \(|N_r|=\sum_q r\mu_q=r\). Write \(v=v_r\).

For a player \(i\) and an integer \(s\in\{1,\ldots,r\}\), let \(S_{i,s}\) be uniformly distributed over the size-\(s\) coalitions containing \(i\). Since

\(\displaystyle \frac{(r-s)!(s-1)!}{r!} =\frac{1}{r\binom{r-1}{s-1}}, \)

the definition becomes

\[\displaystyle \operatorname{Sol}_i(N_r,v) =\frac1r\sum_{s=1}^r\mathbb E[a_v(S_{i,s})]. \tag{1} \]

We first establish efficiency directly. Define

\(\displaystyle V_s=\binom rs^{-1}\sum_{\substack{S\subseteq N_r\\|S|=s}}v(S), \qquad 0\le s\le r. \)

Averaging \(a_v(S)\) over all size-\(s\) coalitions gives

\[\displaystyle \binom rs^{-1}\sum_{|S|=s}a_v(S)=V_s-V_{s-1}. \tag{2} \]

Indeed, the \(v(S)\) contributions give \(V_s\). Each size-\((s-1)\) coalition occurs as \(S\setminus\{j\}\) exactly \(r-s+1\) times, and

\(\displaystyle \frac{(r-s+1)\binom r{s-1}}{s\binom rs}=1. \)

Summing the defining formula over players, a size-\(s\) coalition receives total coefficient

\(\displaystyle s\frac{(r-s)!(s-1)!}{r!}=\binom rs^{-1}. \)

Consequently, (2) telescopes to

\[\displaystyle \sum_{i\in N_r}\operatorname{Sol}_i(N_r,v) =\sum_{s=1}^r(V_s-V_{s-1}) =v(N_r)-v(\varnothing) =rF(\mu), \tag{3} \]

using \(F(0)=0\). Thus the average payoff over all players is exactly \(F(\mu)\) for every admissible \(r\).

2. A uniform bound on differences between players

Let \(B=\prod_{q\in Q}[0,\mu_q]\). Define

\(\displaystyle M=\max_{p\in Q}\sup_{x\in B}|\partial_pF(x)|, \qquad K=\max_{p,q\in Q}\sup_{x\in B}|\partial_q\partial_pF(x)|. \)

These constants are finite because polynomial derivatives are continuous and \(B\) is compact. No sign restriction on the coefficients is needed.

For \(x_p\ge 1/r\), define the type-\(p\) removal marginal

\(\displaystyle D_{p,r}(x)=r\bigl(F(x)-F(x-e_p/r)\bigr), \)

where \(e_p\) is the corresponding coordinate vector. The fundamental theorem of calculus gives

\[\displaystyle D_{p,r}(x)=\int_0^1\partial_pF(x-t e_p/r)\,dt. \tag{4} \]

In particular, \(|D_{p,r}(x)|\le M\). If both removal segments lie in \(B\), the Hessian bound and convexity of \(B\) also give

\[\displaystyle |D_{p,r}(x)-D_{p,r}(y)| \le K\|x-y\|_1. \tag{5} \]

Now take distinct players \(i,j\), and a coalition \(U\subseteq N_r\setminus\{i,j\}\) of size \(s-1\). Put

\(\displaystyle x=k(U\cup\{i\})/r,\qquad y=k(U\cup\{j\})/r. \)

Then \(\|x-y\|_1\le 2/r\). For every member of \(U\), its removal marginal changes by at most \(2K/r\), by (5). The two marginals corresponding to \(i\) and \(j\) differ by at most \(2M\), by (4). Averaging these \(s\) marginals therefore yields

\[\displaystyle |a_v(U\cup\{i\})-a_v(U\cup\{j\})| \le \frac{2K(s-1)}{rs}+\frac{2M}{s} \le \frac{2K}{r}+\frac{2M}{s}. \tag{6} \]

For \(1\le s\le r-1\), the coalitions containing both \(i\) and \(j\) cancel when comparing the two expectations in (1). The remaining coalitions correspond to uniform size-\((s-1)\) subsets \(U\) of \(N_r\setminus\{i,j\}\). Their relative proportion is

\(\displaystyle \frac{\binom{r-2}{s-1}}{\binom{r-1}{s-1}} =\frac{r-s}{r-1}. \)

Hence (6) implies

\(\displaystyle \left|\mathbb E[a_v(S_{i,s})]-\mathbb E[a_v(S_{j,s})]\right| \le \frac{r-s}{r-1} \left(\frac{2K}{r}+\frac{2M}{s}\right). \)

For \(s=r\), the expectations are identical. Applying (1), and writing \(H_r=\sum_{s=1}^r 1/s\), gives

\[\displaystyle |\operatorname{Sol}_i(N_r,v)-\operatorname{Sol}_j(N_r,v)| \le \frac{2K}{r}+\frac{2M H_r}{r}. \tag{7} \]

This holds for every pair of players when \(r\ge2\).

3. Existence and identification of the limits

By (3),

\(\displaystyle \operatorname{Sol}_i(N_r,v)-F(\mu) =\frac1r\sum_{j\in N_r} \bigl(\operatorname{Sol}_i(N_r,v)-\operatorname{Sol}_j(N_r,v)\bigr). \)

Thus (7) implies

\[\displaystyle |\operatorname{Sol}_i(N_r,v)-F(\mu)| \le \frac{2K}{r}+\frac{2M H_r}{r}. \tag{8} \]

The same bound holds after averaging over any type:

\[\displaystyle |A_q(r)-F(\mu)| \le \frac{2K}{r}+\frac{2M H_r}{r}. \tag{9} \]

Since \(H_r\le1+\log r\), the right-hand side tends to zero. The admissible integers contain all positive multiples of a common denominator of the masses, so they form an unbounded sequence. Therefore (9) proves convergence along the required integers, simultaneously for all types.

If \(r=1\) is admissible, its sole player already receives \(F(\mu)\); this does not affect the limit.

Finally, \(F(\mu)\) is rational because both the coefficients and the masses are rational.

4. Exact computation and bit complexity

Write the explicit polynomial as

\(\displaystyle F(x)=\sum_{h=1}^m c_h\prod_{q\in Q}x_q^{\alpha_{hq}}, \qquad \sum_q\alpha_{hq}\le d. \)

The algorithm evaluates

\[\displaystyle F(\mu)=\sum_{h=1}^m c_h\prod_{q\in Q}\mu_q^{\alpha_{hq}} \tag{10} \]

using exact integer arithmetic and returns this rational for every type. The zero polynomial can be handled immediately.

To verify polynomial bit complexity, write \(c_h=u_h/v_h\) and \(\mu_q=a_q/b_q\), with positive denominators, and let

\(\displaystyle D_q=\max_{1\le h\le m}\alpha_{hq}, \qquad C=\left(\prod_{h=1}^m v_h\right) \left(\prod_{q\in Q}b_q^{D_q}\right). \)

For each monomial define

\(\displaystyle P_h=u_h\prod_q a_q^{\alpha_{hq}}, \qquad T_h=v_h\prod_q b_q^{\alpha_{hq}}. \)

Because \(\alpha_{hq}\le D_q\), every \(T_h\) divides \(C\). Thus (10) can be computed as

\(\displaystyle F(\mu)=\frac{Z}{C}, \qquad Z=\sum_{h=1}^m P_h(C/T_h), \)

followed by reduction using a greatest common divisor.

The input bit-length bound and \(D_q\le d\) give

\(\displaystyle \log_2 C \le \sum_h\log_2 v_h+d\sum_q\log_2 b_q \le(d+1)L. \)

Moreover, \(0<\mu_q\le1\), so each summand in \(Z\) has magnitude at most \(C|u_h|\). Consequently, \(Z\) has bit length \(O((d+2)L+\log(m+1))\). The products used to construct it also have polynomial bit length.

Repeated multiplication constructs all powers using a number of arithmetic operations polynomial in \(m,\tau,d\). Integer multiplication, exact division, addition, and greatest-common-divisor computation have polynomial bit complexity. Returning the same rational for all \(\tau\) types also requires only polynomial output length.

Therefore the requested exact computation is polynomial-time solvable in \(m,\tau,d,L\).
