Optimal Partitions in Additively Separable Hedonic Games (d4-conf-ijcai-2011-0424)

Answer: \(\mathrm{NP}\)-hard

The anchor (named result in the paper)

Theorem 2 — class: hardness

The continuous mirror question, as graded

Given rational masses \(\mu_M>0\) for an identical machine type and \(\mu_j\ge0\) for job types \(J_1,\ldots,J_r\), with processing values \(p_j>0\) and the paper’s machine/job additive valuations, partition the population so every machine unit receives an integral bundle \(k\in\mathbb{Z}_{\ge0}^r\) of job units and every job unit is assigned once; output a mass distribution \(\lambda\) over bundles satisfying \(\mathbb{E}_{\lambda}[k_j]=\mu_j/\mu_M\), maximizing \(\min\{B,\operatorname*{ess\,inf}_{k\sim\lambda}\sum_jp_jk_j\}\), where \(B\) is the fixed job-side utility.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. There is one machine type \(M\) with mass \(\mu_M>0\) and \(m\ge1\) job types \(J_j\) with masses \(\mu_j>0\), so \(\tau=m+1\). Masses are absolute quantities and need not sum to one.
Processing values \(p_j>0\) are binary rationals. Set \(B=\sum_{j=1}^m\mu_jp_j\). Additive valuations are \(v_M(J_j)=p_j\), \(v_{J_j}(M)=B\), zero between job units, and \(-(B+1)\) between distinct machine units.
Admissible coalitions contain exactly one machine unit and an integral bundle \(k\in\mathbb Z_{\ge0}^m\) of job units; empty bundles are allowed, and every job unit is assigned once. Aggregate masses may split among coalitions, but the job counts within each bundle remain integral.
A feasible allocation is a probability distribution \(\lambda\) on bundles with finite first moments satisfying \(\mathbb E_\lambda[k_j]=\mu_j/\mu_M\) for every \(j\). A machine receiving \(k\) has utility \(\sum_jp_jk_j\), and each assigned job has utility \(B\).
Compute an optimal allocation, represented by finitely many bundles and binary rational probabilities, maximizing \(W(\lambda)=\min\{B,\operatorname*{ess\,inf}_{k\sim\lambda}\sum_jp_jk_j\}\).

Is computing an allocation maximizing \(W(\lambda)\) solvable in polynomial time in \(m,\tau,L\), where \(L\) is the total input bit length, or is it NP-hard?

For finite societies, computing a maximum egalitarian partition is strongly NP-hard, including the machine/job construction above ([Aziz, Brandt, and Seedig](https://www.ijcai.org/Proceedings/11/Papers/019.pdf)).
The extended treatment retains this hardness result ([extended treatment](https://pub.dss.in.tum.de/brandt-research/ashg_journal.pdf)); no result settling the exact mass-distribution problem above was identified in the search.

Modeling choices made when packaging the task

  • Removed zero-mass job types from the support and required at least one positive-mass job type.
  • Specified positive binary rational processing values and absolute, unnormalized masses.
  • Resolved the unspecified dependence of B by using the mass analogue of total processing time: B equals the sum of job masses times processing values.
  • Used m for the number of supported job types; machine quantity is represented by its mass, and tau equals m plus one.
  • Made lambda a probability distribution over machine bundles, with finite first moments, and specified finite rational support as the output representation.
  • Preserved the stipulated integral bundle counts without imposing a per-bundle bound derived from aggregate masses.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result

Computing an exact optimal allocation is \(\mathrm{NP}\)-hard, even when \(\mu_M=1\), every job-type mass is \(1/2\), and every processing value is a positive integer. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

We prove this directly for the mass-distribution model by reduction from PARTITION.

2. Attaining the average forces exact loads

For a bundle \(k\), write its load as \(X(k)=\sum_jp_jk_j\). The prescribed first moments imply

\( \mathbb E_\lambda[X]=\sum_jp_j\frac{\mu_j}{\mu_M}=\frac{B}{\mu_M}. \)

In particular, when \(\mu_M=1\), every feasible allocation has expected load \(B\).

Suppose such an allocation satisfies \(W(\lambda)=B\). Then \(X\ge B\) almost surely. Since \(X-B\) is nonnegative and has expectation zero, it equals zero almost surely. Thus

\( W(\lambda)=B\quad\Longleftrightarrow\quad X(k)=B\text{ for every bundle }k\text{ with }\lambda(k)>0. \)

This argument applies to distributions with infinite support: the assumed finite first moments make \(X\) integrable.

3. Polynomial-size construction

PARTITION takes positive integers \(a_1,\ldots,a_n\), encoded in binary, and asks whether some subset \(S\subseteq\{1,\ldots,n\}\) satisfies

\( 2\sum_{i\in S}a_i=\sum_{i=1}^n a_i. \)

This problem is \(\mathrm{NP}\)-complete; see the [Charles University complexity exercises](https://ktiml.mff.cuni.cz/~fink/teaching/computability_2017_18/tutorial_5.pdf).

Let

\( A=\sum_{i=1}^n a_i,\qquad q=n+1,\qquad Q=2nA+1, \)

\( D=Qq^{n-1}+2A,\qquad H=nD+1,\qquad G=\sum_{i=1}^nq^{i-1}. \)

Construct one machine type of mass \(\mu_M=1\). For each index \(i\), introduce two job types \(J_{i,0}\) and \(J_{i,1}\), both of mass \(1/2\), with processing values

\( p_{i,0}=H+Qq^{i-1},\qquad p_{i,1}=H+Qq^{i-1}+2a_i. \)

These processing values are positive integers. They are distinct: values within a pair differ by \(2a_i>0\), and the increase between consecutive radix terms exceeds \(2A\), because \(Q>2A\).

There are \(m=2n\) job types and \(\tau=2n+1\) supported types. The welfare cap specified by the task is

\( B=\frac12\sum_{i=1}^n(p_{i,0}+p_{i,1})=nH+QG+A. \)

Every processing value satisfies

\( H\le p_{i,b}\le H+D. \)

Moreover,

\( 0<QG+A\le nQq^{n-1}+A\le nD<H, \)

so

\( nH<B<(n+1)H. \)

The construction has polynomial bit length. In particular, \(q^{n-1}\) requires \(O(n\log(n+1))\) bits, and each processing value requires \(O(\log A+n\log(n+1))\) bits. All quantities can therefore be computed and written in polynomial time.

4. Exact-load bundles encode PARTITION solutions

We prove that an integral bundle \(k=(k_{i,b})\) has load \(B\) if and only if it chooses exactly one job from each pair and its chosen \(J_{i,1}\) indices solve PARTITION.

Let

\( N=\sum_{i=1}^n(k_{i,0}+k_{i,1}) \)

be the total number of jobs in a bundle of load \(B\).

First, \(N=n\). Since each processing value is at least \(H\),

\( NH\le B<(n+1)H, \)

which gives \(N\le n\). If \(N\le n-1\), then

\( X(k)\le(n-1)(H+D)=nH-\bigl(H-(n-1)D\bigr)<nH<B, \)

contradicting \(X(k)=B\). Therefore \(N=n\).

Second, the selected input integers have half the total weight. Put \(c_i=k_{i,0}+k_{i,1}\). Subtracting \(nH\) from the load equation gives

\( Q\sum_{i=1}^nq^{i-1}c_i+2\sum_{i=1}^na_i k_{i,1}=QG+A. \)

Because \(N=n\),

\( 0\le 2\sum_{i=1}^na_i k_{i,1}\le 2nA<Q. \)

Also \(0<A<Q\). Reducing the displayed load equation modulo \(Q\), both residual terms lie between zero and \(Q-1\); hence

\( 2\sum_{i=1}^na_i k_{i,1}=A. \)

Third, exactly one job comes from each pair. Substituting the last equality back yields

\( \sum_{i=1}^nq^{i-1}c_i=\sum_{i=1}^nq^{i-1}. \)

Each \(c_i\) satisfies \(0\le c_i\le n=q-1\). These are therefore valid base-\(q\) digits. Uniqueness of the base-\(q\) expansion gives \(c_i=1\) for every \(i\). Explicitly, reduction modulo \(q\) gives \(c_1=1\); subtracting that digit and dividing by \(q\) repeats the argument for the remaining digits.

Thus each pair contributes either \(J_{i,0}\) or \(J_{i,1}\), and

\( S=\{i:k_{i,1}=1\} \)

satisfies \(2\sum_{i\in S}a_i=A\).

Conversely, if \(S\) satisfies that equality, the bundle defined by

\( k_{i,1}=\mathbf 1_{\{i\in S\}},\qquad k_{i,0}=1-k_{i,1} \)

has load

\( X(k)=nH+QG+2\sum_{i\in S}a_i=B. \)

This proves the claimed characterization.

5. Equivalence for distributions

If PARTITION is a yes-instance, let \(k^S\) be the bundle just constructed. Its complementary bundle, defined coordinatewise by

\( \overline{k}^{\,S}_{i,b}=1-k^S_{i,b}, \)

also has load \(B\), because the complement of \(S\) also has input weight \(A/2\).

Assign probability \(1/2\) to each of these two bundles. Every job coordinate has expectation \(1/2\), precisely its required mass divided by \(\mu_M=1\). The allocation is feasible, uses rational probabilities, and attains \(W=B\). Since the objective is capped at \(B\), it is optimal.

If an allocation attains \(W=B\), Section 2 shows that every positive-probability bundle has load exactly \(B\). At least one such bundle exists because the bundle space is countable and the probabilities sum to one. Section 4 extracts a PARTITION solution from that bundle.

We have consequently proved

\( \text{PARTITION is a yes-instance}\quad\Longleftrightarrow\quad\text{some feasible allocation has }W=B. \)

The reverse implication holds even when arbitrary real probabilities and infinite support are allowed.

For these constructed instances, all bundle loads and \(B\) are integers. The set of positive-probability loads is a nonempty subset of the nonnegative integers, so it has a minimum, which equals the essential infimum. Therefore every allocation has integer welfare. In a no-instance, every allocation satisfies \(W\le B-1\).

6. Finite rational optimal allocations exist

For completeness, the requested finite rational representation does not create an existence obstruction. Here rational probabilities are understood as fractions whose numerators and denominators are encoded in binary.

Write \(x_j=\mu_j/\mu_M\). A feasible finite rational allocation always exists: independently round each \(x_j\) to its floor or ceiling with the probabilities that preserve its expectation.

Choose a positive integer \(d\) such that every \(dp_j\) is integral. Every bundle load then belongs to \(d^{-1}\mathbb Z_{\ge0}\). Because the bundle space is countable, every allocation's essential infimum is its minimum positive-probability load. Its welfare consequently belongs to the finite set

\( \{r/d:r\in\mathbb Z_{\ge0},\ r/d\le B\}\cup\{B\}. \)

The nonempty set of attainable welfare values therefore has a maximum, say \(t\), attained by some feasible distribution.

We now replace that distribution by a finite rational one without reducing its welfare. Set

\( C_j=\lceil t/p_j\rceil,\qquad f_j(k)=\min\{k_j,C_j\}. \)

Every truncated bundle \(f(k)\) still has load at least \(t\). If no coordinate changes, its load is unchanged. If coordinate \(j\) changes, that coordinate alone contributes \(p_jC_j\ge t\).

The truncated bundles belong to a finite set \(F\), and their expected vector is coordinatewise at most \(x\). Hence the following finite rational system is feasible:

\( \sum_{f\in F}\alpha_f=1,\qquad \alpha_f\ge0,\qquad \sum_{f\in F}\alpha_f f_j\le x_j\quad\text{for every }j. \)

Its feasible set is a nonempty bounded rational polytope, so it has a rational vertex: the vertex coordinates solve a full-rank system of tight rational linear equations. Choose such rational probabilities \(\alpha_f\), and let

\( \delta_j=x_j-\sum_{f\in F}\alpha_f f_j\ge0. \)

Independently construct a finitely supported integer-valued vector \(z\) with expectation \(\delta\), again by floor-or-ceiling rounding. Its probabilities are rational. Independently sample \(f\) and \(z\), and output \(f+z\). This distribution has expectation exactly \(x\), finite support, and rational probabilities. Since \(z\) is nonnegative, every output bundle retains load at least \(t\). It therefore attains the optimum.

This establishes existence, without claiming that the finite sets used in this argument can be enumerated in polynomial time.

7. Computational consequence

Suppose a polynomial-time algorithm computed an optimal allocation in the requested representation. Apply it to the constructed society and compute the minimum load among its positive-probability bundles, capped at \(B\). Exact rational arithmetic performs this comparison in polynomial time in the output length.

By Section 5, the resulting welfare equals \(B\) exactly when the original PARTITION instance is a yes-instance. The algorithm would therefore solve PARTITION in polynomial time.

This proves the requested \(\mathrm{NP}\)-hardness classification. The reduction establishes ordinary \(\mathrm{NP}\)-hardness; it makes no claim of strong \(\mathrm{NP}\)-hardness.
