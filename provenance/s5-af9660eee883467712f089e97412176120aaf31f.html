The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), and an ordered support of \(\tau\) types with rational masses \(\mu_j>0\) summing to \(1\), approval sets \(A_j\), and rational non-increasing per-capita sequences \(w^j_1,\ldots,w^j_m\), where each candidate is approved by a consecutive block of types, compute a size-\(k\) committee \(W\subseteq C\) maximizing \(\sum_{j=1}^{\tau}\mu_j\sum_{r=1}^{|A_j\cap W|}w^j_r\) in time polynomial in \(m,\tau,L\).

Packaged proof task (what the prover saw — nothing else)

Let \(C=\{c_1,\ldots,c_m\}\), with \(m\geq1\), and let \(k\in\{1,\ldots,m\}\).
A society is given by its support: an ordered list of \(\tau\geq1\) types with positive binary-rational masses \(\mu_j\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Type \(j\) has an approval set \(A_j\subseteq C\) and binary-rational weights \(1\geq w^j_1\geq\cdots\geq w^j_m\geq0\); individual first weights need not equal \(1\).
Require \(C=\bigcup_{j=1}^{\tau}A_j\) and, for every candidate \(c\), that \(\{j:c\in A_j\}\) is a consecutive block in the supplied order. Empty approval sets are allowed.
The optimization problem is to return any committee \(W\subseteq C\) with \(|W|=k\) maximizing \(\sum_{j=1}^{\tau}\mu_j\sum_{r=1}^{|A_j\cap W|}w^j_r\), with an empty inner sum equal to \(0\). Let \(L\) be the total binary input length.

Is this optimization problem solvable in time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For a finite list of voters with individual non-increasing binary-rational scoring sequences in \([0,1]\), Generalized Thiele committee optimization on Voter Interval profiles is polynomial-time solvable.

Conclusion

The optimization problem is polynomial-time solvable, by a polynomial-size reduction to the finite-voter problem stated in the question. Each mass can be absorbed into its type’s scoring sequence.

Reduction and correctness

For every type \(j\), create exactly one voter with approval set \(A_j\) and scoring sequence
\[ \widehat w^j_r=\mu_j w^j_r,\qquad r\in\{1,\ldots,m\}. \]
Here and below, the reduction uses the given finite-voter tractability result.

We verify its hypotheses:

  • Admissible scores. Since the masses are positive and sum to \(1\), we have \(0<\mu_j\leq1\). Multiplying the original inequalities by \(\mu_j\) gives \(1\geq\widehat w^j_1\geq\cdots\geq\widehat w^j_m\geq0\). All transformed scores are binary rationals. The finite-voter result allows individual first scores below \(1\), so this scaling is admissible.
  • Voter Interval property. Order the constructed voters by their original type indices. For every candidate \(c\), its approving voters are precisely \(\{j:c\in A_j\}\), which is a consecutive block by assumption. Approval sets and their union are unchanged.
  • Identical objective. For any committee \(W\subseteq C\) with \(|W|=k\), the constructed finite-voter score satisfies

\[ \sum_{j=1}^{\tau}\sum_{r=1}^{|A_j\cap W|}\widehat w^j_r = \sum_{j=1}^{\tau}\mu_j\sum_{r=1}^{|A_j\cap W|}w^j_r. \]
This equality also holds for empty approval intersections because both corresponding sums are \(0\). The feasible committees are unchanged. Consequently, every maximizing committee for the constructed instance maximizes the original objective.

Encoding length and running time

The construction has exactly \(\tau\) voters and computes \(m\tau\) rational products.

To check bit complexity explicitly, write \(\mu_j=a_j/b_j\) and \(w^j_r=p_{jr}/q_{jr}\), with binary-encoded integer numerators and positive denominators. Their product is represented exactly as \((a_jp_{jr})/(b_jq_{jr})\). Each product’s encoding length is bounded by the sum of its factors’ encoding lengths plus a constant. Integer multiplication, and fraction reduction if required, take polynomial time in those lengths. Dyadic binary rationals satisfy the same bound.

Thus the transformed encoding length is polynomial in \(m,\tau,L\); for example, \(O(m\tau(L+1))\) is a valid bound. Applying the supplied polynomial-time finite-voter algorithm therefore takes time polynomial in \(m,\tau,k,L\), and its output is an optimal committee for the original society.

The reduction uses one voter per support type, so its running time has no dependence on a population obtained by clearing the mass denominators.
