The continuous mirror question, as graded

Given two complete utility types \(i\in\{1,2\}\) with masses \(\mu_i\), indivisible good categories \(M\) with rational per-capita supplies \(q_g\), and rational endpoint states \(x^0,x^1\), does a finite sequence of rational-mass exchanges connect them? Each state \(x_{i,B}\) assigns mass of type \(i\) to integral bundle \(B\subseteq M\), respects \(\sum_B x_{i,B}=\mu_i\) and \(\sum_{i,B:g\in B}x_{i,B}=q_g\), and is EF1 across every pair of supported type-bundle pairs. A move exchanges one good between equal positive masses of two supported bundles and must leave the state EF1.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) utility types with positive mass, each mass encoded as a binary rational; \(\tau\) counts supported types, not possible types. Here \(\tau=2\), with \(\mu_1+\mu_2=1\). Each type has explicitly given nonnegative rational additive utilities on \(M\), where \(m=|M|\ge1\); category supplies are binary rationals \(q_g\in[0,1]\).
A state consists of nonnegative rational masses \(x_{i,B}\) on integral bundles \(B\subseteq M\), including the empty bundle, satisfying \(\sum_Bx_{i,B}=\mu_i\) and \(\sum_{i,B:g\in B}x_{i,B}=q_g\). EF1 is required between every ordered pair of supported type-bundle pairs, including pairs of the same type, using the respective types' utilities.
An exchange chooses supported pairs \((i,B),(j,C)\), goods \(g\in B\setminus C\), \(h\in C\setminus B\), and rational \(0<\varepsilon\le\min\{x_{i,B},x_{j,C}\}\). Simultaneously subtract \(\varepsilon\) from each chosen pair and add it to \((i,(B\setminus\{g\})\cup\{h\})\) and \((j,(C\setminus\{h\})\cup\{g\})\); the resulting state must satisfy EF1. Exchanges between distinct subpopulations of the same type are allowed.
The input endpoints \(x^0,x^1\) are feasible EF1 states, encoded by listing only positive coordinates and their bundles. Intermediate states may use any bundles. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is deciding whether a finite sequence of these rational-mass exchanges connects \(x^0\) to \(x^1\) in \(\mathrm{P}\), or is it NP-hard?

Discrete EF1 exchange reachability is NP-hard for every fixed number of agents \(n\ge2\), even with equal bundle sizes at both endpoints ([source](https://arxiv.org/html/2609.15358v1)); with an unrestricted number of agents it is PSPACE-complete ([source](https://link.springer.com/article/10.1007/s00453-024-01271-y)).
No result settling this exact rational-mass, supportwise-EF1 reachability problem was located.

Modeling choices made when packaging the task

  • Interpreted complete utility types as explicitly given nonnegative rational additive utilities, matching the discrete utility model.
  • Normalized total society mass to one and bounded each category supply between zero and one, consistent with at most one copy of a category per bundle.
  • Encoded endpoints sparsely by positive type-bundle coordinates; intermediate states may introduce bundles absent from the endpoints.
  • Specified a simultaneous swap of two goods, with each incoming category absent from its receiving bundle, preserving bundle cardinalities and category supplies.
  • Allowed exchanges between distinct subpopulations of the same utility type, since distinct agents need not have different utilities.
  • Required feasible EF1 endpoints and retained empty bundles and same-type EF1 comparisons.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is \(\mathrm{NP}\)-hard, already for \(\tau=2\), equal type masses, integer utilities, and endpoints with only three positive coordinates.

The proof is a direct reduction from Partition. Its anchor goods are inspired by [Frank–Suksompong, Theorem 4.1](https://arxiv.org/html/2609.15358v1). The additional fixed witness type below makes the argument valid for arbitrary rational-mass exchanges, including exchanges within one type.

1. Construction

Take a Partition instance consisting of positive integers \(a_1,\ldots,a_r\), with \(\sum_{\ell=1}^r a_\ell=2t\). The question is whether some subset sums to \(t\). Partition remains \(\mathrm{NP}\)-hard with this even-total convention.

Set \(K=10t\). Introduce the disjoint sets of goods

  • \(X=\{x_1,x_2\}\);
  • \(Y=\{y_1,y_2,y_3,y_4\}\);
  • \(Z=\{z_1,z_2\}\);
  • \(G=\{g_1,\ldots,g_r\}\);
  • \(H=\{h_1,\ldots,h_{r+1}\}\).

Thus \(m=2r+9\). Write \(R=Z\cup G\cup H\).

There are exactly two supported utility types, each of mass \(\mu_1=\mu_2=1/2\). Their additive utilities are:

| Goods | Type \(1\) | Type \(2\) |
|---|---:|---:|
| \(x_1,x_2\) | \(3K\) each | \(4K\) each |
| \(y_1\) | \(2K+t\) | \(K+4t\) |
| \(y_2,y_3,y_4\) | \(2K+t\) each | \(K\) each |
| \(z_1\) | \(2t\) | \(2t\) |
| \(z_2\) | \(3t\) | \(3t\) |
| \(g_\ell\) | \(a_\ell\) | \(a_\ell\) |
| \(h_\ell\) | \(0\) | \(0\) |

The utilities coincide on \(R\). For \(S\subseteq R\), denote their common value by \(v(S)\). In particular,

\(0\le v(S)\le v(R)=7t\),

and every individual good in \(R\) has value at most \(3t\).

Set the supplies to

\(q_g=1/2\) for \(g\in X\cup Y\), and \(q_g=1/4\) for \(g\in R\).

Define the initial type-\(1\) bundles

\(A^0=X\cup\{z_1\}\cup G,\qquad B^0=X\cup\{z_2\}\cup H,\)

and the target type-\(1\) bundles

\(A^1=X\cup\{z_2,h_1,\ldots,h_r\},\qquad B^1=X\cup\{z_1,h_{r+1}\}\cup G.\)

At each endpoint, put mass \(1/4\) on each displayed type-\(1\) bundle and mass \(1/2\) on the type-\(2\) bundle \(Y\). All other coordinates are zero.

These states meet the type-mass and supply constraints: each good in \(X\) appears in both type-\(1\) bundles, each good in \(Y\) appears only in the type-\(2\) bundle, and each good in \(R\) appears in exactly one type-\(1\) bundle. Their EF1 property is proved below.

2. Proven lemma: the anchor goods cannot move

Lemma. Every state reachable from the initial state has every supported type-\(1\) bundle of the form \(X\cup S\), with \(S\subseteq R\), and has all type-\(2\) mass on \(Y\).

Proof. Suppose otherwise, and consider the first exchange involving a good in \(X\cup Y\).

Before this exchange, all supported type-\(1\) bundles contain \(X\), contain no good in \(Y\), and all type-\(2\) mass remains on \(Y\). An exchange between two type-\(1\) bundles cannot involve \(X\cup Y\), because those bundles have identical membership in these goods. Consequently, the exchange must be between a type-\(1\) bundle \(X\cup S\) and the type-\(2\) bundle \(Y\), exchanging some \(g\in X\cup S\) for some \(y\in Y\).

Both output coordinates have positive mass, whatever positive rational exchange amount is chosen. There are two cases.

Case 1: \(g\in X\). The output type-\(1\) bundle has type-\(1\) utility at most

\(3K+(2K+t)+7t=5K+8t.\)

The output type-\(2\) bundle consists of three goods from \(Y\) and one good from \(X\). Under type-\(1\) utilities, its largest good is the \(X\)-good, because \(3K>2K+t\). After removing that good, its utility is

\(3(2K+t)=6K+3t.\)

But \(5K+8t<6K+3t\), since \(K=10t\). The output type-\(1\) pair therefore violates EF1 toward the output type-\(2\) pair.

Case 2: \(g\in S\). The output type-\(2\) bundle has type-\(2\) utility at most

\(3K+4t+3t=3K+7t.\)

The output type-\(1\) bundle still contains both goods in \(X\), and additionally contains \(y\). Under type-\(2\) utilities, its largest goods are the \(X\)-goods. Removing one leaves utility at least

\(4K+u_2(y)\ge5K.\)

Since \(3K+7t<5K\), the output type-\(2\) pair violates EF1 toward the output type-\(1\) pair.

Both cases contradict legality. Hence no anchor good moves. Every exchange involving type \(2\) would move a good in \(Y\), so type \(2\) remains fixed on \(Y\). \(\square\)

3. Proven lemma: EF1 imposes a bundlewise utility interval

Lemma. For a state of the anchored form established above, supportwise EF1 holds exactly when every supported type-\(1\) bundle \(X\cup S\) satisfies

\(3t\le v(S)\le4t.\)

Proof. Type \(1\)'s utility for \(X\cup S\) is \(6K+v(S)\). Its utility for \(Y\), after removing a largest good, is \(6K+3t\). Thus EF1 from this bundle toward \(Y\) is equivalent to \(v(S)\ge3t\).

Type \(2\)'s own bundle \(Y\) has utility \(4K+4t\). Its utility for \(X\cup S\), after removing a largest good, is \(4K+v(S)\): either \(X\)-good is largest because every good in \(S\) has value at most \(3t<4K\). Thus EF1 from type \(2\) toward this bundle is equivalent to \(v(S)\le4t\).

Comparisons between type-\(1\) bundles impose no additional restriction. Indeed, for any \(S,T\subseteq R\),

\(u_1(X\cup S)\ge6K,\)

whereas the utility remaining in \(X\cup T\) after removing a largest good is

\(3K+v(T)\le3K+7t<6K.\)

The type-\(2\) bundle also satisfies EF1 toward itself. This checks every ordered pair, including pairs of the same type. \(\square\)

At the initial endpoint, the two residual values are \(4t\) and \(3t\). At the target endpoint, they are \(3t\) and \(4t\). Hence both endpoints are feasible EF1 states.

A further consequence is that every reachable type-\(1\) bundle contains exactly one good from \(Z\). With neither, its residual value is at most \(2t\); with both, its residual value is at least \(5t\). Both possibilities violate the interval.

4. Soundness: reachability implies a Partition solution

First, an exchange preserves the size of each participating bundle. It follows that, for every type \(i\) and size \(s\), the total mass on size-\(s\) bundles is invariant. This remains true for exchanges within one type.

Here,

\(|A^0|=|A^1|=r+3,\qquad |B^0|=|B^1|=r+4.\)

Consider the quantity

\(I(x)=\sum_{B:\,|B|=r+3,\ z_1\in B}x_{1,B}.\)

Initially \(I(x^0)=1/4\); at the target \(I(x^1)=0\). Any exchange that involves neither \(z_1\) nor \(z_2\) preserves bundle sizes and membership in \(z_1\), and therefore preserves \(I\). Thus a connecting sequence must include an exchange involving a good in \(Z\).

By the anchor lemma, such an exchange is between two type-\(1\) bundles. Since every supported bundle contains exactly one marker, exchanging a marker for a nonmarker would create a positively supported bundle with no marker and another with both markers. That is impossible. Consequently, the exchange swaps \(z_1\) and \(z_2\).

Let the participating bundle containing \(z_1\) have \(G\)-goods of total value \(\beta\). Before the exchange its residual value is \(2t+\beta\), so the interval lemma gives \(\beta\ge t\).

After the exchange its \(G\)-goods are unchanged, and it contains \(z_2\). Its output coordinate has positive mass, so the interval lemma applies again:

\(3t+\beta\le4t,\)

hence \(\beta\le t\). Therefore \(\beta=t\).

The \(G\)-goods in this integral bundle specify a subset of the original integers summing to \(t\). Thus the Partition instance is a yes-instance.

This argument uses only positivity of the exchange amount. It permits arbitrary rational splitting, overlapping bundles, and exchanges within type \(1\).

5. Completeness: a Partition solution gives a legal path

Suppose \(J\subseteq\{1,\ldots,r\}\) satisfies \(\sum_{\ell\in J}a_\ell=t\).

Maintain two type-\(1\) bundles of mass \(1/4\) each, with the type-\(2\) witness fixed. Every exchange below has amount \(\varepsilon=1/4\), consuming the entire mass of both participating coordinates.

First transfer the goods \(g_\ell\) with \(\ell\in J\) from the first bundle to the second, exchanging each for a distinct dummy good. Let \(\beta\) be the value of the \(G\)-goods remaining in the first bundle. During this stage, \(\beta\) decreases from \(2t\) to \(t\). The residual values of the two bundles are

\(2t+\beta,\qquad 3t+(2t-\beta)=5t-\beta.\)

Both belong to \([3t,4t]\), so every resulting state is EF1.

At \(\beta=t\), exchange \(z_1\) and \(z_2\). The residual values become \(4t\) and \(3t\), so this exchange is legal.

Then transfer the remaining \(G\)-goods from the first bundle to the second, again exchanging each for a distinct dummy. Now \(\beta\) decreases from \(t\) to \(0\), and the residual values are

\(3t+\beta,\qquad 2t+(2t-\beta)=4t-\beta.\)

Again both lie in \([3t,4t]\).

Use exactly \(h_1,\ldots,h_r\) as the exchanged dummy goods, leaving \(h_{r+1}\) in the second bundle. The resulting bundles are precisely \(A^1,B^1\).

All exchanges preserve feasibility, and the interval lemma proves supportwise EF1 throughout. The path has exactly \(r+1\) exchanges.

6. Encoding and complexity conclusion

The construction has \(\tau=2\), \(m=2r+9\), and three positive coordinates at each endpoint. Every mass and supply belongs to \(\{1/4,1/2\}\); all utilities are nonnegative integers bounded by a constant multiple of \(t\).

With bundles encoded by characteristic vectors, the constructed binary input length satisfies

\(L=O\!\left(m(1+\log(t+1)+\log(m+1))\right).\)

The construction takes polynomial time in the binary Partition input length. On yes-instances, the exhibited path has \(O(m)\) exchanges.

Sections 4 and 5 establish the equivalence:

the constructed endpoints are reachable if and only if the Partition instance has a solution.

Therefore the requested decision problem is \(\mathrm{NP}\)-hard for the fixed supported-type count \(\tau=2\). A decision algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\). This proof establishes hardness without asserting membership in \(\mathrm{NP}\).
