The continuous mirror question, as graded

Given a finite observable type set \(T\), rational masses \(\mu\), stationary context distributions \(q_t\), baseline policies \(\pi_t\), unknown shared reward laws \(\rho_t\), parameters \(\epsilon,\gamma,\lambda,\alpha,\delta\), and bandit access to rewards when a target type \(t\) is shown policy \(\pi_u\), design an adaptive audit that samples target and source types from \(\mu\), obeys \(\frac{1}{s}\sum_{i=1}^{s}v_{t,u_i}\ge(1-\alpha)v_{t,t}\) for every audited target type and prefix, where \(v_{t,u}=\sum_{x,a}q_t(x)\pi_u(a\mid x)\rho_t(a\mid x)\), and with probability at least \(1-\delta\) returns either an envy witness or certifies \(\sum_t\mu_t\mathbf{1}\!\left[\sum_u\mu_u\mathbf{1}[v_{t,u}>v_{t,t}+\epsilon]>\gamma\right]\le\lambda\), while characterizing the duration and cumulative loss trade-off.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) observable types \(T\) with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Let \(A,X\) be nonempty finite sets, with \(m=|A|\) and \(c=|X|\). Known stationary context distributions \(q_t\) and baseline policies \(\pi_t\) are rational tables. Unknown stationary reward distributions \(\nu_t(\cdot\mid x,a)\), shared by all mass of type \(t\), are supported on \([0,1]\), with means \(\rho_t(a\mid x)\). A query \((t,u)\) independently draws \(x\sim q_t\), \(a\sim\pi_u(\cdot\mid x)\), and observes a reward from \(\nu_t(\cdot\mid x,a)\); define \(v_{t,u}=\sum_{x,a}q_t(x)\pi_u(a\mid x)\rho_t(a\mid x)\).
Parameters are binary rationals \(\epsilon,\alpha\in(0,1]\), \(\gamma,\lambda\in(0,1)\), and \(\delta\in(0,1/2)\). Target types and candidate source types are drawn independently with replacement from \(\mu\); the audit adaptively queries sampled pairs or the target's baseline \((t,t)\), pooling observations of repeated types.
With probability at least \(1-\delta\), the audit must terminate, return either a witness \((t,u)\) with \(v_{t,u}>v_{t,t}\) or a valid certificate \(\sum_t\mu_t\mathbf 1[\sum_u\mu_u\mathbf 1[v_{t,u}>v_{t,t}+\epsilon]>\gamma]\le\lambda\), and satisfy \(\sum_{i=1}^{s}v_{t,u_i}\ge s(1-\alpha)v_{t,t}\) for every audited type and every prefix of its own query sequence. Either output is permitted when both statements hold.
For \(N_t\) queries to type \(t\), synchronous duration is \(D=\max_t N_t\), total reward queries are \(Q=\sum_tN_t\), and cumulative loss is \(C=\sum_t\sum_{i=1}^{N_t}(v_{t,t}-v_{t,u_i})\), which may be negative. Let \(L\) be the total explicit input bit length and \(b\) the smallest positive baseline utility, taking \(b=1\) if all baselines are zero.

Does this audit problem admit a randomized algorithm whose computation and reward-query bounds, with probability at least \(1-\delta\), are polynomial in \(m,c,\tau,L,\epsilon^{-1},\gamma^{-1},\lambda^{-1},\alpha^{-1},b^{-1},\log(1/\delta)\), or is it NP-hard? What duration–cumulative-loss trade-off is achievable?

For uniform finite populations, an audit samples \(\widetilde M=\lceil\log(3/\delta)/\lambda\rceil\) targets and \(K=\lceil\log(3\widetilde M/\delta)/\log(1/(1-\gamma))\rceil\) sources per target, with joint correctness, conservative-performance, and instance-dependent duration and loss guarantees; the sampled population sizes are independent of the total number of users.   • Normalized the positive rational masses to sum to one.

Result

Yes: the audit admits the requested randomized algorithm. In fact, the bounds below do not depend on \(b^{-1}\). They cover zero baseline utilities, rational masses, and repeated sampled types.

For any chosen safety parameter \(0<\beta\le\alpha\), the algorithm achieves, up to logarithmic factors, the instance-dependent bounds

  • duration: \(D=O\!\left(\beta^{-1}\max_t\sum_{u\in S_t}\eta_{t,u}^{-2}\right)\);
  • total queries: \(Q=O\!\left(\beta^{-1}\sum_t\sum_{u\in S_t}\eta_{t,u}^{-2}\right)\);
  • cumulative loss: \(C\le O\!\left(\sum_t\sum_{u\in S_t}(v_{t,t}-v_{t,u})_+/\eta_{t,u}^{2}\right)\),

where \(S_t\) is the set of distinct sampled sources for target \(t\), excluding \(t\), and
\(\eta_{t,u}=\max\{v_{t,u}-v_{t,t},\,\epsilon+v_{t,t}-v_{t,u}\}\).

Here \(z_+=\max\{z,0\}\). These are achievable bounds; no optimality claim is made.

The sampling scheme follows the same principle as the uniform-population audit in [Do et al., *Online certification of preference-based fairness for personalized recommender systems*](https://arxiv.org/pdf/2104.14527). The argument below proves the rational-mass guarantees directly.

1. Sampling and notation

All logarithms used to define integer parameters below have base \(2\). Set

\(R=\left\lceil \left\lceil\log_2(4/\delta)\right\rceil/\lambda\right\rceil\),

and

\(K=\left\lceil \left\lceil\log_2(4R/\delta)\right\rceil/\gamma\right\rceil\).

Draw \(R\) target types independently from \(\mu\). For each target occurrence, independently draw \(K\) source types from \(\mu\). Perform all these draws before collecting rewards.

Let \(\mathcal T\) be the set of distinct sampled targets. For each \(t\in\mathcal T\), let \(S_t\) contain all distinct sources drawn for occurrences of \(t\), excluding \(t\). This exclusion is valid because \(v_{t,t}\) cannot exceed \(v_{t,t}+\epsilon\).

Write \(s=|\mathcal T|\), \(P=\sum_{t\in\mathcal T}|S_t|\), and \(k_{\max}=\max_{t\in\mathcal T}|S_t|\). Then \(s\le\min\{\tau,R\}\), \(P\le RK\), and \(k_{\max}\le\min\{\tau-1,RK\}\).

Each distinct type has one local audit. All occurrences of a sampled pair share its observations.

Define

\(J=\left\lceil\log_2(16/\epsilon)\right\rceil\),

\(H=\left\lceil\log_2\!\left(16RK(J+1)/\delta\right)\right\rceil\),

and, for \(0\le j\le J\),

\(r_j=2^{-j}\), \(n_j=2H\,4^j\).

Thus \(r_J\le\epsilon/16\).

2. A deterministic safety schedule

Fix a target \(t\), and put \(v_0=v_{t,t}\). Let \(B_t\) count its baseline queries and \(E_t\) count its queries to sources different from \(t\).

Before making its next exploratory query, require

\(B_t\ge\left\lceil\frac{1-\beta}{\beta}(E_t+1)\right\rceil\),

adding baseline queries when necessary. Additional baseline queries for statistical estimation are also allowed.

Consequently, at every prefix,

\(B_t\ge\frac{1-\beta}{\beta}E_t\).

Every exploratory utility is nonnegative. Therefore the surplus over the required \((1-\beta)\)-baseline performance satisfies

\(\sum_{i=1}^{B_t+E_t}v_{t,u_i}-(1-\beta)(B_t+E_t)v_0 \ge \beta B_tv_0-(1-\beta)E_tv_0 \ge0\).

This proves the conservative constraint deterministically at every prefix, independently of any confidence event. Since \(\beta\le\alpha\) and \(v_0\ge0\), it also proves the required constraint with \(\alpha\).

The argument remains valid when \(v_0=0\). No positive lower bound on the baseline is needed.

3. Local tests and their confidence event

For a fixed pair, successive reward observations are independent, identically distributed, bounded in \([0,1]\), and have mean \(v_{t,u}\). This follows from the stationary distributions and independent query draws.

Only \(J+1\) binary fractional digits of each reward are needed. Let \(Z\) denote the reward truncated to that precision. Then \(Z\in[0,1]\) and \(|\mathbb E Z-v_{t,u}|\le2^{-(J+1)}=r_J/2\).

For each sampled pair and baseline, imagine its infinite independent observation stream. At stage \(j\), use the average of its first \(n_j\) truncated observations. Hoeffding’s inequality gives

\(\Pr\!\left(\left|\widehat v(n_j)-\mathbb E Z\right|>r_j/2\right) \le2\exp(-n_jr_j^2/2)=2e^{-H}\).

Since \(r_J/2\le r_j/2\), the complementary event implies
\(|\widehat v(n_j)-v|\le r_j\).

There are at most \((P+s)(J+1)\le2RK(J+1)\) averages to consider. Because \(H\ge\ln(16RK(J+1)/\delta)\), a union bound proves that the event

\(\mathcal E:\quad |\widehat v(n_j)-v|\le r_j\text{ for every relevant stream and stage}\)

has probability at least \(1-\delta/4\), conditional on any initial type samples.

This construction also justifies adaptive stopping: the confidence event covers fixed prefixes of every possible observation stream.

For each \(t\), process the sources in \(S_t\) in any fixed order. For a source \(u\), run stages \(j=0,\ldots,J\):

  • Ensure that the pooled baseline stream and the pair stream each contain at least \(n_j\) observations. Apply the safety schedule to every additional exploratory query.
  • Set \(\widehat d=\widehat v_{t,u}(n_j)-\widehat v_{t,t}(n_j)\).
  • If \(\widehat d>2r_j\), store the witness \((t,u)\) and finish this local audit.
  • Otherwise, if \(\widehat d+2r_j\le\epsilon\), discard this source and continue to the next source.

On \(\mathcal E\), the estimated difference has error at most \(2r_j\). Hence a stored witness satisfies \(v_{t,u}>v_{t,t}\), and a discarded source satisfies \(v_{t,u}\le v_{t,t}+\epsilon\).

The procedure always finishes its current comparison by stage \(J\), even if \(\mathcal E\) fails. Indeed, if the witness test fails, then \(\widehat d\le2r_J\), so

\(\widehat d+2r_J\le4r_J\le\epsilon\),

and the discard test succeeds.

Run every local audit to its local stopping point. Return any stored witness; if there is none, return the certificate in the question.

4. Why the population certificate is valid

Define

\(p_t=\sum_u\mu_u\mathbf 1[v_{t,u}>v_{t,t}+\epsilon]\),

and let \(\mathcal B=\{t:p_t>\gamma\}\). The requested certificate is exactly \(\mu(\mathcal B)\le\lambda\).

Suppose this certificate is false, so \(\mu(\mathcal B)>\lambda\). The probability that all \(R\) sampled targets miss \(\mathcal B\) is at most

\((1-\lambda)^R\le e^{-\lambda R}\le\delta/4\).

For any sampled occurrence of \(t\in\mathcal B\), its \(K\) sources miss all improvements greater than \(\epsilon\) with probability

\((1-p_t)^K\le(1-\gamma)^K\le e^{-\gamma K}\le\delta/(4R)\).

A union bound over the target occurrences makes the probability of any such miss at most \(\delta/4\).

Thus, except on events of total probability at most \(\delta/2\), a false certificate produces a sampled pair with \(v_{t,u}>v_{t,t}+\epsilon\). On \(\mathcal E\), this pair cannot be discarded. Its target’s local audit must therefore produce a witness, possibly from an earlier source.

Combining this with the confidence event, the output is correct with probability at least \(1-3\delta/4\). Deduplication preserves this argument: every sampled pair remains represented in its target’s pooled candidate set.

5. Instance-dependent duration and loss

For a sampled pair, abbreviate \(d=v_{t,u}-v_{t,t}\) and
\(\eta=\max\{d,\epsilon-d\}\). Necessarily

\(\epsilon/2\le\eta\le2\).

On \(\mathcal E\), the comparison stops whenever \(r_j\le\eta/8\):

  • If \(\eta=d\), then \(\widehat d\ge d-2r_j\ge3\eta/4>2r_j\), producing a witness.
  • If \(\eta=\epsilon-d\), then \(\widehat d+2r_j\le d+4r_j\le\epsilon-\eta/2<\epsilon\), discarding the source.

Let \(j_*\) be the first stage with \(r_{j_*}\le\eta/8\). It exists because \(r_J\le\epsilon/16\le\eta/8\). By minimality, \(r_{j_*}>\eta/16\). The pair’s total exploratory queries are consequently bounded by

\(n_{t,u}\le n_{j_*}=2H/r_{j_*}^2\le512H/\eta_{t,u}^2\).

Define \(g_\beta=\max\{2,\beta^{-1}\}\). At the end of a local audit, its baseline count is at most

\(B_t\le\max\!\left\{\max_j n_j\text{ used by that audit},\left\lceil\frac{1-\beta}{\beta}E_t\right\rceil\right\}\).

Each statistical stage finishes with at least \(n_j\) exploratory observations for its current pair, so its baseline statistical requirement is at most \(E_t\). Therefore

\(N_t=B_t+E_t\le g_\beta E_t+1\).

It follows that, on \(\mathcal E\),

\(D\le512g_\beta H\max_{t\in\mathcal T}\sum_{u\in S_t}\eta_{t,u}^{-2}+1\),

and

\(Q\le512g_\beta H\sum_{t\in\mathcal T}\sum_{u\in S_t}\eta_{t,u}^{-2}+s\).

Baseline queries incur zero loss. Discarding negative contributions when taking an upper bound gives

\(C\le512H\sum_{t\in\mathcal T}\sum_{u\in S_t}\frac{(v_{t,t}-v_{t,u})_+}{\eta_{t,u}^2}\).

For a worse source, write \(g=v_{t,t}-v_{t,u}>0\). Then \(\eta=\epsilon+g\), and

\(\frac{g}{(\epsilon+g)^2}\le\frac1{4\epsilon}\),

because \((\epsilon+g)^2-4\epsilon g=(g-\epsilon)^2\ge0\).

Thus the worst-case bounds are

\(D\le2048g_\beta Hk_{\max}/\epsilon^2+1\),

\(Q\le2048g_\beta HP/\epsilon^2+s\),

and

\(C\le128HP/\epsilon\).

The deterministic safety guarantee additionally gives

\(C\le\beta\sum_tN_tv_{t,t}\le\beta sD\).

These inequalities describe an attainable trade-off: choosing a smaller \(\beta\) enforces stronger conservative performance and increases the duration bound proportionally to \(\beta^{-1}\), while the instance-dependent cumulative-loss bound remains unchanged. Actual cumulative loss can be negative.

6. Computation and probability accounting

The reward-query bound is deterministically polynomial: every comparison ends by stage \(J\), and \(n_J<2048H/\epsilon^2\). The sharper instance-dependent bounds above hold on \(\mathcal E\).

Rational masses need no expansion into a virtual population. For exact sampling, form a common denominator \(W\) for the masses, represent them by integer weights summing to \(W\), and sample a uniform integer below \(W\) by binary rejection sampling. The product of the explicitly encoded denominators is a valid common denominator whose bit length is \(O(L)\). Each rejection attempt succeeds with probability at least \(1/2\).

For a deterministic polynomial upper bound \(S\) on the number of rational samples needed, the probability that any sampler requires more than \(\lceil\log_2(4S/\delta)\rceil\) attempts is at most \(\delta/4\). The same argument applies to context and action sampling if those draws must be implemented rather than supplied by the query oracle.

All stored reward averages use \(J+1\) fractional bits per observation. Threshold comparisons, counters, weight arithmetic, and the integer logarithm ceilings have polynomial bit complexity.

Taking \(\beta=\alpha\), computation and reward queries are therefore polynomial in the parameters specified in the question. Combining the sampling, confidence, and computation-tail events gives the required joint probability at least \(1-\delta\).

This settles the requested algorithmic alternative. The result is polynomial in the listed inverse parameters; it does not assert a bound polynomial in \(L\) alone when those inverses are exponentially large.

The parameters \(R\) and \(K\) are sufficient. Their use of base-two logarithms is conservative because \(\log_2 z\ge\ln z\) for \(z\ge1\). Consequently,

\[ \lambda R\ge\ln(4/\delta), \qquad \gamma K\ge\ln(4R/\delta). \]

The bounds \(s\le\min\{\tau,R\}\), \(P\le RK\), and \(k_{\max}\le\min\{\tau-1,RK\}\) are correct. Excluding the baseline source loses no improvement greater than \(\epsilon\).

\[ 2\exp\!\left(-n_jr_j^2/2\right)=2e^{-H}. \]
