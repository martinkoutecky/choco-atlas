The continuous mirror question, as graded

Given a finite set of types \(A\), masses \(p_a>0\) summing to \(1\), preferred actions \(s_a\in Z\), and influence shares \(q_{ab}\) summing to \(1\) for each type \(a\), find an equilibrium allocation \(x_{a,z}\geq0\) with \(\sum_{z\in Z}x_{a,z}=p_a\). Let \(\nu_b(z)=x_{b,z}/p_b\) and let \(A_a(x)\) be a weighted Fréchet median minimizing \(\sum_b q_{ab}\sum_{z\in Z}\nu_b(z)d(y,z)\) over \(y\in Z\). Require every action assigned positive mass to type \(a\) to minimize \(\alpha d(s_a,z)+(1-\alpha)d(z,A_a(x))\) over \(z\in Z\), for \(\alpha>1/2\) and an exact metric \(d\).

A society is given by its support: the list of \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Assume \(\sum_{t\in T}\mu_t=1\).
Let \(Z\) be an explicitly listed set of \(m\geq2\) strategies, with a binary-rational metric table \(d\) separating distinct strategies; each type has a preferred strategy \(s_t\in Z\), and the common confidence is a binary rational \(\alpha\in(1/2,1]\).
Influence is specified by binary-rational densities \(K_{tu}\geq0\), satisfying \(\sum_{u\in T}\mu_uK_{tu}=1\) for every \(t\); symmetry is not required, and \(K_{tt}\) is permitted.
Realize the population as \(T\times[0,1]\), with measure \(\mu_t\,dr\). A pure profile is any measurable map \(z:T\times[0,1]\to Z\), allowing agents of the same type to choose different strategies.
For \(x\in Z\), define \(p_t(z)(x)=\sum_{u\in T}\mu_uK_{tu}\lambda\{r:z(u,r)=x\}\), where \(\lambda\) is Lebesgue measure.
Fix arbitrary deterministic aggregation maps \(A_t:\Delta(Z)\to Z\), where \(\Delta(Z)\) is the probability simplex, with \(A_t(\delta_x)=x\). Aggregation depends only on \(p_t(z)\), so profiles agreeing almost everywhere under the influence measure have the same aggregate; all aggregation ties are resolved by the fixed maps.
An agent of type \(t\) choosing \(x\) incurs \(c_t(x;z)=\alpha d(s_t,x)+(1-\alpha)d(x,A_t(p_t(z)))\). A pure Nash equilibrium requires \(c_t(z(t,r);z)\leq c_t(x;z)\) for every \(x\in Z\), almost everywhere; an individual deviation leaves the influence distributions unchanged.
Does every such game have \(z(t,r)=s_t\) almost everywhere as its unique pure Nash equilibrium modulo null sets? Result

Yes. For every game satisfying the stated hypotheses, the preferred profile \(z^*(t,r)=s_t\) is the unique pure Nash equilibrium modulo population null sets.

An equilibrium can be computed uniformly over all the aggregation maps in \(O(L+\tau\lceil\log_2 m\rceil)\) bit time using the standard encoding by strategy indices. The algorithm simply outputs the preferred strategy of each supported type.

1. Influence distributions and individual deviations

Write the population measure as \(\nu(\{t\}\times B)=\mu_t\lambda(B)\). For a measurable profile \(z\), define \(q_u(x)=\lambda\{r:z(u,r)=x\}\).

Because \(Z\) is finite, the strategy sets partition each type’s interval, so \(q_u(x)\geq0\) and \(\sum_{x\in Z}q_u(x)=1\). Consequently,

\(p_t(z)(x)=\sum_{u\in T}\mu_uK_{tu}q_u(x)\geq0\),

and the normalization of the influence densities gives

\(\sum_{x\in Z}p_t(z)(x)=\sum_{u\in T}\mu_uK_{tu}\sum_{x\in Z}q_u(x)=1\).

Thus \(p_t(z)\in\Delta(Z)\), and \(a_t:=A_t(p_t(z))\) is a well-defined strategy in \(Z\).

An individual deviation changes the profile at a single point of one type’s interval. Every \(q_u(x)\), and hence every influence distribution and aggregate, remains unchanged: a singleton has Lebesgue measure zero. This also holds when \(K_{tt}>0\), since every density is a finite rational number.

Therefore an individual compares strategies against the same aggregate \(a_t\).

2. Strict dominance of the preferred strategy

Fix any type \(t\), any profile \(z\), and any strategy \(x\neq s_t\). Since \(d(s_t,s_t)=0\),

\(c_t(x;z)-c_t(s_t;z)=\alpha d(s_t,x)+(1-\alpha)\bigl(d(x,a_t)-d(s_t,a_t)\bigr)\).

The triangle inequality yields

\(d(s_t,a_t)\leq d(s_t,x)+d(x,a_t)\),

and therefore

\(d(x,a_t)-d(s_t,a_t)\geq-d(s_t,x)\).

Since \(1-\alpha\geq0\), substitution gives

\(c_t(x;z)-c_t(s_t;z)\geq(2\alpha-1)d(s_t,x)>0\).

The strict inequality follows from both hypotheses: \(\alpha>1/2\), and the metric separates distinct strategies.

Thus \(s_t\) is the unique best response for every type against every profile. This conclusion holds for every possible aggregate in \(Z\); it does not require evaluating the aggregation maps or using their unanimity property.

3. Existence and uniqueness modulo null sets

The preferred profile \(z^*(t,r)=s_t\) is measurable because it is constant on each of finitely many type intervals. By the strict dominance inequality, every agent’s prescribed action minimizes their cost. Hence \(z^*\) is a pure Nash equilibrium.

Conversely, let \(z\) be any pure Nash equilibrium, and define the measurable set

\(B_t=\{r\in[0,1]:z(t,r)\neq s_t\}\).

At every point of \(B_t\), choosing \(s_t\) strictly reduces the agent’s cost, by Section 2. Therefore the equilibrium inequalities can hold almost everywhere only if

\(\nu\left(\bigcup_{t\in T}\{t\}\times B_t\right)=\sum_{t\in T}\mu_t\lambda(B_t)=0\).

Every summand is nonnegative, and every supported type has \(\mu_t>0\). It follows that \(\lambda(B_t)=0\) for every \(t\). Thus \(z=z^*\) almost everywhere under the population measure.

Conversely, any measurable profile agreeing with \(z^*\) almost everywhere is an equilibrium: almost every agent chooses their strictly dominant strategy. This establishes uniqueness of the equilibrium equivalence class.

In particular, allowing agents of the same type to choose different strategies produces no additional equilibrium classes.

4. Uniform polynomial-time computation

Index the explicitly listed strategies as \(Z=\{z_1,\ldots,z_m\}\). For each type \(t\), let \(i_t\) be the index satisfying \(s_t=z_{i_t}\).

A finite representation of the equilibrium is the tuple \((i_t)_{t\in T}\), interpreted as the measurable rule

\(z^*(t,r)=z_{i_t}\quad\text{for every }t\in T,\ r\in[0,1]\).

The algorithm reads the finite input and copies these preferred-strategy indices into its output.

Under the standard binary-index encoding:

  • The output has \(O(\tau\lceil\log_2 m\rceil)\) bits.
  • Reading the input and writing the output takes \(O(L+\tau\lceil\log_2 m\rceil)\) bit time.
  • Since the input already contains those indices, this is \(O(L)\) under that encoding.

These bounds concern inputs promised to satisfy the stated hypotheses; checking metric and normalization validity is unnecessary for equilibrium construction.

The algorithm performs no rational arithmetic and makes no queries to any \(A_t\). It therefore works uniformly even if the fixed aggregation maps are computationally intractable or noncomputable. The equilibrium computation problem is polynomial-time solvable.

5. Scope and the confidence threshold

The proof uses the exact metric, the availability of each preferred strategy, and the fact that an individual deviation leaves the aggregate unchanged. It imposes no symmetry requirement on influence and permits influence within the same type.

The strict confidence threshold is sharp for uniqueness. If the assumptions are extended to allow \(\alpha=1/2\), consider one type with \(\mu_t=K_{tt}=1\), strategies \(Z=\{a,b\}\), distance \(d(a,b)=1\), and preference \(s_t=a\). At the unanimous profile choosing \(b\), unanimity forces the aggregate to be \(b\). Both strategies then cost \(1/2\), so this profile is an equilibrium distinct from the preferred profile.

The conclusion for \(\alpha>1/2\) agrees with the finite-population result in Theorem 2 of [Fanelli and Fotakis, *Local Aggregation in Preference Games*](https://arxiv.org/pdf/2002.01251). Sections 1–4 above give an independent proof for the specified nonatomic formulation.
