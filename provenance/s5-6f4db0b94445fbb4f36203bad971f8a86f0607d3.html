The continuous mirror question, as graded

Given rational type masses \(\mu\in\mathbb{Q}_{>0}^{\tau}\) summing to \(1\), and a rational piecewise-linear value function \(V:[0,\mu]\to\mathbb{Q}\) with \(V(\mathbf{0})=0\), promised to satisfy \(V(q)+V(r)\leq V(q\wedge r)+V(q\vee r)\) whenever \(q\wedge r\neq\mathbf{0}\) and \(q\vee r\neq\mu\), decide whether there exists a type-level payoff-rate vector \(a\in\mathbb{R}^{\tau}\) such that \(\mu\cdot a=V(\mu)\) and \(q\cdot a\geq V(q)\) for every \(q\in[0,\mu]\). Specify an explicit rational piecewise-linear encoding for \(V\), or give oracle complexity when only exact value access is available.

Result

The decision problem is solvable in polynomial time in \(\tau,K,L\). In fact, the explicit piecewise-affine encoding permits a polynomial-size linear-programming formulation without using the supermodularity promise.

1. Preparing the pieces

Write the supplied affine formula on piece \(k\) as \(c_k^\top q+d_k\), with rational coefficients.

Intersect each supplied polytope with the coalition box, obtaining

\(P_k=\{q\in\mathbb R^\tau:A_kq\leq b_k\}\),

where the inequalities include \(0\leq q_i\leq\mu_i\) for every coordinate. Test each intersection for emptiness using rational linear programming, and discard empty intersections. Let \(I\) be the retained index set.

Every retained \(P_k\) is nonempty and compact. The retained pieces still cover the box, and

\(V(q)=c_k^\top q+d_k\qquad(q\in P_k,\ k\in I)\).

Compute \(C=V(\mu)\) by finding a supplied piece containing \(\mu\) and evaluating its formula. Membership tests and evaluation use rational arithmetic. Coverage guarantees such a piece exists, and agreement on overlaps guarantees the resulting value is independent of the choice.

2. Replacing all inequalities on one piece

Fix \(k\in I\) and a rate vector \(a\in\mathbb R^\tau\). The required inequalities on this piece are equivalent to

\((c_k-a)^\top q\leq-d_k\qquad\text{for every }q\in P_k\).

Consider the linear program

\(\max\{(c_k-a)^\top q:A_kq\leq b_k,\ q\in\mathbb R^\tau\}\).

Its feasible set is nonempty and compact, so its maximum exists and is finite. Its dual is

\(\min\{b_k^\top y_k:A_k^\top y_k=c_k-a,\ y_k\geq0\}\).

Here the primal coordinates are unrestricted variables; their bounds are already included among the rows of \(A_kq\leq b_k\). Consequently the dual constraints are equalities.

The strong duality theorem for linear programming states that a feasible primal with finite optimal value has an attained dual optimum with the same value. Its hypotheses hold here, even if \(P_k\) has lower dimension. Thus all coalition inequalities on \(P_k\) hold if and only if there exists \(y_k\) satisfying

\(y_k\geq0,\qquad A_k^\top y_k=c_k-a,\qquad b_k^\top y_k\leq-d_k.\)

For completeness, the sufficient direction follows directly: for every \(q\in P_k\),

\((c_k-a)^\top q=y_k^\top A_kq\leq y_k^\top b_k\leq-d_k.\)

For the necessary direction, the coalition inequalities bound the primal optimum by \(-d_k\); an optimal dual solution therefore satisfies the displayed constraints.

3. The complete finite formulation

Construct the following rational linear feasibility problem. Its variables are the unrestricted rate vector \(a\) and one auxiliary vector \(y_k\) for each \(k\in I\):

\(\mu^\top a=C,\)

\(A_k^\top y_k+a=c_k\qquad(k\in I),\)

\(b_k^\top y_k\leq-d_k\qquad(k\in I),\)

\(y_k\geq0\qquad(k\in I).\)

All constraints are linear: in particular, no products between \(a\) and the auxiliary variables occur.

We verify both directions.

If feasible rates exist, then on every retained piece the original coalition inequalities hold. Section 2 supplies a suitable vector \(y_k\) for each piece. Together with efficiency, these vectors give a solution of the finite formulation.

If the finite formulation is feasible, take its rate component \(a\). Given any coalition \(q\), coverage supplies a retained piece \(P_k\) containing it. The constraints for \(y_k\), by Section 2, imply

\(q^\top a\geq c_k^\top q+d_k=V(q).\)

The efficiency equation also holds. Hence \(a\) is a feasible payoff-rate vector.

This proves exact equivalence.

4. Polynomial encoding size and running time

Let \(r_k\) be the number of rows of \(A_k\), and put \(R=\sum_{k\in I}r_k\). These are counts derived from the supplied input, not separate model parameters. Adding the box inequalities contributes at most \(2\tau K\) rows, so \(R\) is polynomially bounded in \(\tau,K,L\).

The final formulation has:

  • \(\tau+R\) scalar variables;
  • \(1+\tau|I|\) scalar equality constraints;
  • \(R+|I|\) scalar inequality constraints.

Its coefficients are copied from the input, apart from signs, constants, and the rational evaluation \(C\). Computing \(C\) requires summing \(\tau\) rational products, so its binary length is polynomially bounded by the input length. Therefore the entire formulation has polynomial binary encoding length, including if written as a dense matrix.

The standard polynomial-time theorem for rational linear programming decides exact feasibility in time polynomial in that encoding length; see [Karmarkar’s polynomial-time linear-programming algorithm](https://www.stat.uchicago.edu/~lekheng/courses/302/classics/karmarkar.pdf). It also handles the preliminary emptiness tests. Unrestricted rate variables can, if needed, be represented as differences of two nonnegative variables.

Thus the stated continuously divisible problem is polynomial-time solvable. The conclusion follows directly from its explicit polyhedral encoding and does not require the finite-society oracle result.
