The continuous mirror question, as graded

Given a finite set of types \(T\), rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), and a directed compatibility relation on type pairs, let \(Q_3\) be the compatible cycle patterns of lengths two and three. Repeated types in a pattern represent distinct pairs of that type. For each \(q\in Q_3\), choose cycle mass \(x_q\ge 0\); let \(a_t(q)\) count the uses of type \(t\) in \(q\). What is the maximum transplanted mass \(\max \sum_{q\in Q_3}\ell(q)x_q\), subject to \(\sum_{q\in Q_3}a_t(q)x_q\le\mu_t\) for every \(t\in T\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) donor–patient types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input includes an explicit directed relation \(R\subseteq T\times T\): \((s,t)\in R\) means a donor of type \(s\) can donate to a patient of type \(t\) in a distinct pair. Put \(m=|R|\), and let \(L\) be the total input bit length.
Let \(Q_3\) contain the directed cyclic sequences \(q=(t_1,\ldots,t_k)\), modulo cyclic rotation, with \(k\in\{2,3\}\) and \((t_i,t_{i+1})\in R\), taking \(t_{k+1}=t_1\). Repeated types represent distinct pairs; diagonal entries of \(R\) permit exchanges between distinct pairs of the same type.
Write \(\ell(q)=k\) and \(a_t(q)=|\{i:t_i=t\}|\). A feasible allocation consists of divisible cycle masses \(x_q\in\mathbb R_{\ge0}\) satisfying \(\sum_{q\in Q_3}a_t(q)x_q\le\mu_t\) for every \(t\in T\).
Its transplanted mass is \(V(x)=\sum_{q\in Q_3}\ell(q)x_q\); let \(\mathrm{OPT}=\max_x V(x)\). Unused mass is allowed; only these cycles are allowed, with no chains or one-pair exchanges.

Can this problem be approximated within a factor of \(698/697\) in time polynomial in \(m,\tau,L\), returning a feasible allocation with \(V(x)\ge(697/698)\mathrm{OPT}\), or is achieving this approximation NP-hard?

For finite societies, maximizing the number of vertices covered by vertex-disjoint directed cycles of lengths two and three is NP-hard to approximate within \(698/697\) ([Luo, Tang, Wu and Zeng](https://arxiv.org/pdf/1605.08863)).
No result for precisely the mass problem above was identified in the literature search.

  • Define m as the number of explicitly listed compatibility pairs and L as total input bit length, avoiding confusion with the cycle-length bound.

Result

The mass problem is exactly solvable in time polynomial in \(m,\tau,L\). Consequently, it admits the requested approximation factor \(698/697\).

The proof uses the stated interpretation: cycle masses are divisible, repeated types are permitted, and only cyclic sequences of lengths two and three are allowed.

1. Enumerating the allowed cycles

Index the support as \(T=\{1,\ldots,\tau\}\). Construct a Boolean table recording membership in \(R\).

For each \(k\in\{2,3\}\), enumerate every ordered tuple \((t_1,\ldots,t_k)\in T^k\), including tuples with repeated entries. Retain a tuple precisely when:

  • Every required arc \((t_i,t_{i+1})\), with \(t_{k+1}=t_1\), belongs to \(R\).
  • The tuple is lexicographically smallest among its cyclic rotations.

The arc condition is invariant under rotation. Each rotation class has exactly one smallest tuple, even when several rotations coincide. Thus this procedure produces exactly one representative of every element of \(Q_3\). Reversal is not used for identification.

Writing \(N=|Q_3|\), we have

\(N\le \tau^2+\tau^3.\)

There are only constantly many arc checks and rotation comparisons per tuple. Hence enumeration takes polynomial time in \(m,\tau,L\). In particular, diagonal arcs and repeated types require no separate assumption.

2. An exact linear-programming formulation

For each enumerated cycle \(q\), define

\(A_{tq}=a_t(q),\qquad c_q=\ell(q).\)

Then \(A_{tq}\in\{0,1,2,3\}\), \(c_q\in\{2,3\}\), and

\(\sum_{t\in T}A_{tq}=c_q.\)

Consider the rational linear program

\(\max\{c^{\mathsf T}x:Ax\le\mu,\ x\ge0\}.\)

Its variables are precisely the permitted cycle masses. Its inequalities are precisely the capacity constraints in the question, and its objective is precisely \(V(x)\). Therefore this linear program has optimum \(\mathrm{OPT}\); no relaxation or additional realizability condition is being introduced.

If \(N=0\), return the empty allocation, whose value and optimum are both zero. Suppose henceforth that \(N>0\).

The feasible set is nonempty because \(x=0\) is feasible. For any feasible \(x\), summing the capacity inequalities gives

\(c^{\mathsf T}x=\sum_{q\in Q_3}\sum_{t\in T}A_{tq}x_q=\sum_{t\in T}(Ax)_t\le\sum_{t\in T}\mu_t=1.\)

Since all variables are nonnegative, each coordinate satisfies

\(0\le x_q\le 1/c_q\le 1/2.\)

The feasible set is therefore closed and bounded, hence compact. The linear objective attains a finite maximum on it.

3. Polynomial bit complexity and the approximation guarantee

Use the standard exact rational linear-programming theorem: a linear program with binary-encoded rational coefficients can be solved in time polynomial in its total encoding length; when feasible with finite optimum, an exact rational optimal solution can be returned. Exact polynomial-time methods and rational reconstruction are discussed in [*Linear Programming using Limited-Precision Oracles*, Section 1.3](https://arxiv.org/pdf/1912.12820).

Here all hypotheses hold:

  • The constraint matrix and objective have constant-size integer entries.
  • The right-hand side consists of the given binary rational masses.
  • Feasibility and attainment of a finite optimum were proved above.
  • There are \(N\le\tau^2+\tau^3\) variables and \(\tau\) capacity constraints.

For an explicit encoding bound, introduce \(\tau\) nonnegative slack variables and write \(Ax+s=\mu\). The resulting matrix has \(\tau(N+\tau)\) constant-size entries. Including the rational masses and cycle representatives, its description length is

\(O\bigl(\tau(N+\tau)+L+N\log(\tau+1)\bigr),\)

which is polynomial in \(\tau,L\). Construction also takes polynomial time in \(m,\tau,L\).

The exact rational LP algorithm therefore returns a feasible allocation \(x^*\) in the required polynomial time, with

\(V(x^*)=\mathrm{OPT}\ge \frac{697}{698}\mathrm{OPT}.\)

This establishes the requested guarantee, including when \(\mathrm{OPT}=0\).

4. Why finite-society hardness does not transfer

The cited [Luo–Tang–Wu–Zeng result](https://arxiv.org/pdf/1605.08863) concerns vertex-disjoint cycles on indivisible vertices. Divisibility changes the optimization problem.

A concrete example demonstrates the difference. Let \(T=\{0,1,2,3,4\}\), assign \(\mu_i=1/5\), and let \(R\) contain both orientations of every edge of the undirected five-cycle, with no other arcs. Indices below are interpreted modulo five.

There are exactly five allowed two-cycles, \(q_i=(i,i+1)\). There are no allowed three-cycles: a triple with repeated types would require a diagonal arc, while a triple with distinct types would require a triangle in the underlying five-cycle.

Set \(x_{q_i}=1/10\) for every \(i\). Each type belongs to exactly two of these cycles, so its consumption is \(2/10=1/5\). Thus the allocation is feasible and has value

\(V(x)=5\cdot2\cdot(1/10)=1.\)

The general upper bound \(V(x)\le1\) proves that its mass optimum is exactly one.

By contrast, a finite society with one vertex of each type can select only disjoint edges of the five-cycle. At most two edges can be selected because three would require six distinct vertices; two disjoint edges exist. Its maximum covered fraction is therefore \(4/5\).

Thus even identical compatibility data can give different fractional and integral optima. The polynomial-time algorithm above solves exactly the divisible problem specified in the question.
