The continuous mirror question, as graded

Given a common argument vocabulary \(U\), a finite support of \(s\)-iBAF types \(IF_t\) over \(U\), binary-rational masses \(\mu_t\) summing to \(1\), a set \(S\) of arguments certain in every type, and a rational threshold \(q\), decide whether \(W \ge q\), where \(W=\sum_{t:\,\exists\text{ completion of }IF_t\text{ in which }S\text{ is an }s\text{-ad extension}}\mu_t\).

Packaged proof task (what the prover saw — nothing else)

Let \(U\) be a finite argument vocabulary, with \(m=|U|\). A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Each type is an explicitly encoded incomplete bipolar framework \(IF_t=(A_t,A_t^{?},R_{a,t},R_{a,t}^{?},R_{s,t},R_{s,t}^{?})\). The certain and uncertain argument sets are disjoint subsets of \(U\); attack relations and support relations are subsets of \((A_t\cup A_t^{?})^2\), with the certain and uncertain relations disjoint within each category. Self-loops are allowed.
A completion selects \(A_t\subseteq B\subseteq A_t\cup A_t^{?}\), retains every certain attack and support whose endpoints lie in \(B\), and independently selects any subset of the uncertain attacks and supports with endpoints in \(B\). Write the resulting framework as \((B,R_a,R_s)\).
In a completion, \(x\Rightarrow^{+}y\) means a support path of positive length. A generic attack \(x\leadsto y\) exists exactly when \((x,y)\in R_a\), or some \(z\in B\) satisfies \(x\Rightarrow^{+}z\) and \((z,y)\in R_a\). No other implicit attacks are used.
A set \(S\subseteq B\) is safe if there is no \(y\in B\) such that some member of \(S\) generically attacks \(y\) and either \(y\in S\) or some member of \(S\) transitively supports \(y\). It is an \(s\text{-ad}\) extension if it is safe and, for every \(x\in S\) and \(y\in B\) with \(y\leadsto x\), some \(z\in S\) satisfies \(z\leadsto y\).
Given \(S\subseteq\bigcap_{t=1}^{\tau}A_t\) and a binary-rational threshold \(q\in\mathbb{Q}\), define \(W=\sum_{t:\,\exists\text{ completion of }IF_t\text{ in which }S\text{ is an }s\text{-ad}\text{ extension}}\mu_t\). Completions are chosen separately for each type; the decision problem asks whether \(W\ge q\).
Is this weighted possible-extension decision problem solvable in polynomial time, or is it NP-hard?
For a single incomplete framework with these support and extension semantics, possible-extension verification is NP-complete, even when all arguments and attacks are certain and only supports may be uncertain.

Modeling choices made when packaging the task

  • The common vocabulary was interpreted as an ambient set: each type may use a subset of U.
  • The size parameters were fixed as m = |U| and L equal to the total input bit length.
  • The unspecified threshold encoding was fixed as binary rational, consistently with the mass encoding.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The weighted possible-extension decision problem is \( \mathrm{NP} \)-complete. Hardness already holds for \( \tau=1 \), with all arguments and attacks certain and only supports uncertain. Thus a polynomial-time algorithm exists if and only if \( \mathrm{P}=\mathrm{NP} \).

1. Verifying a specified completion

Fix a type and a completion \( (B,R_a,R_s) \). We first show that verifying whether the given \( S \) is an \( s\text{-ad} \) extension takes polynomial time.

Let \( P(x,y) \) mean that there is a support path of positive length from \( x \) to \( y \). Compute \( P \) by transitive closure of \( R_s \), initializing the closure with \( R_s \), without automatically adding identity pairs. Consequently, \( P(x,x) \) holds precisely when a positive-length support cycle passes through \( x \). This computation takes \( O(m^3) \) Boolean operations.

Construct the generic-attack relation \( G \) by setting, for each \( x,y\in B \),

\( G(x,y)=R_a(x,y)\lor\bigvee_{z\in B}\bigl(P(x,z)\land R_a(z,y)\bigr). \)

This is exactly the generic-attack definition in the question and takes \( O(m^3) \) Boolean operations.

For each \( y\in B \), define

\( D(y)=\bigvee_{z\in S}G(z,y) \)

and

\( H(y)=(y\in S)\lor\bigvee_{z\in S}P(z,y). \)

By the stated definition of safety, \( S \) is safe exactly when no \( y\in B \) satisfies both \( D(y) \) and \( H(y) \).

The defense condition holds exactly when, for every \( x\in S \) and \( y\in B \), \( G(y,x) \) implies \( D(y) \). Indeed, \( D(y) \) states precisely that some member of \( S \) generically attacks \( y \).

Computing these predicates and checking both conditions takes \( O(m^2) \) further Boolean operations. Therefore a specified completion can be verified in \( O(m^3) \) Boolean operations. Its validity as a completion is also checked directly against the input: certain arguments must be present, selected arguments and relations must be permitted, and all certain relations whose endpoints are present must be retained.

2. Membership in \( \mathrm{NP} \)

For an input instance, let \( T^\star \) be the set of types that admit a completion in which \( S \) is an \( s\text{-ad} \) extension. Thus \( W=\sum_{t\in T^\star}\mu_t \).

A certificate consists of:

  • A subset \( J\subseteq\{1,\ldots,\tau\} \).
  • For each \( t\in J \), a completion witnessing that \( S \) is an \( s\text{-ad} \) extension.

A completion is encoded by one selection bit for each uncertain argument, attack, and support. Certain components are determined by the input and the selected arguments. Because every uncertain component is explicitly encoded in the input, the total certificate length is \( O(L) \).

The verifier checks every supplied completion using Section 1 and accepts exactly when all checks pass and \( \sum_{t\in J}\mu_t\ge q \).

Soundness. Every verified type belongs to \( T^\star \), so \( J\subseteq T^\star \). Since all masses are positive, \( \sum_{t\in J}\mu_t\le W \). Acceptance therefore implies \( W\ge q \).

Completeness. If \( W\ge q \), choose \( J=T^\star \) and supply a witnessing completion for each of its types. This certificate passes every check and its mass sum equals \( W \).

The graph computations require \( O(\tau m^3) \) Boolean operations. Exact rational arithmetic is polynomial as well: using a product of the input denominators as a common denominator requires only \( O(L) \) bits. Schoolbook arithmetic gives an \( O(\tau L^2) \) bit-operation bound for summation and comparison. Thus verification uses \( O(\tau m^3+L) \) graph and input-processing operations, plus \( O(\tau L^2) \) arithmetic bit operations.

This proves membership in \( \mathrm{NP} \).

3. Hardness

Use the single-framework \( \mathrm{NP} \)-completeness result supplied in the question, restricted to instances with all arguments and attacks certain and only supports uncertain.

Given such an instance \( (IF,S) \), construct a society with:

  • \( \tau=1 \);
  • \( IF_1=IF \);
  • \( \mu_1=1 \);
  • threshold \( q=1 \).

Keep the same vocabulary and candidate set \( S \). Because all arguments are certain, the requirement \( S\subseteq A_1 \) is satisfied.

If the original instance admits a completion making \( S \) an \( s\text{-ad} \) extension, then \( W=1 \). Otherwise \( W=0 \). Hence \( W\ge q \) holds exactly when the original possible-extension instance is positive.

The construction copies the original instance and adds constant-size data, so it takes \( O(L) \) time. It is a polynomial-time many-one reduction, proving \( \mathrm{NP} \)-hardness under the stated restrictions.

Together with Section 2, this establishes \( \mathrm{NP} \)-completeness.
