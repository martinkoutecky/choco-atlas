The continuous mirror question, as graded

Given a finite platform set \(P\), a finite support \(T\) of item types with rational masses \(\mu_t>0\) summing to \(1\), and for each type \(t\) an allowed-platform set \(A_t\), utilities \(u_{tp}\), and group-membership set \(J_t\), along with a rational utility threshold \(\ell\) and rational convex piecewise-linear cost functions \(\Phi_p,\Psi_{pj}:[0,1]\to\mathbb{Q}\), choose masses \(y_{tp}\geq 0\) to minimize \(\sum_{p\in P}(\Phi_p(\sum_t y_{tp})+\sum_j\Psi_{pj}(\sum_{t:j\in J_t}y_{tp}))\), subject to \(\sum_{p\in A_t}y_{tp}\leq\mu_t\) for each \(t\) and \(\sum_{t,p}u_{tp}y_{tp}\geq\ell\); report infeasibility if no such assignment exists.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) platforms \(P\) and \(g\geq1\) groups. Each type has an allowed set \(A_t\subseteq P\), utilities \(u_{tp}\in\mathbb{Q}_{\geq0}\) for \(p\in A_t\), and a nonempty membership set \(J_t\subseteq\{1,\ldots,g\}\). Groups may overlap arbitrarily; every group contains at least one supported type.
The input includes \(\ell\in\mathbb{Q}_{\geq0}\) and finite continuous convex piecewise-linear functions \(\Phi_p,\Psi_{pj}:[0,1]\to\mathbb{R}\), encoded explicitly by binary-rational breakpoints and values, including both endpoints. Values and slopes may have either sign, and values at zero need not vanish.
Choose divisible masses \(y_{tp}\in\mathbb{R}_{\geq0}\), with \(y_{tp}=0\) whenever \(p\notin A_t\), subject to \(\sum_{p\in A_t}y_{tp}\leq\mu_t\) for every \(t\) and \(\sum_{t\in T}\sum_{p\in A_t}u_{tp}y_{tp}\geq\ell\). Unassigned mass is permitted.
Define \(\sigma_p=\sum_{t\in T}y_{tp}\) and \(\nu_{pj}=\sum_{t:j\in J_t}y_{tp}\). Compute an exact minimum of \(\sum_{p\in P}(\Phi_p(\sigma_p)+\sum_{j=1}^{g}\Psi_{pj}(\nu_{pj}))\), or report infeasibility. Let \(K\) be the total number of linear pieces and \(L\) the total binary input length.

Is this continuous optimization problem solvable in time polynomial in \(m,\tau,g,K,L\), or is it NP-hard?

For indivisible items with arbitrarily overlapping groups, exact optimization is NP-hard and no finite multiplicative approximation is possible; with disjoint or laminar groups and uniform utilities, exact optimization is polynomial-time. Result

The problem is solvable exactly in time polynomial in \(m,\tau,g,K,L\), including arbitrary group overlaps and arbitrary rational utilities satisfying the stated hypotheses.

The proof gives a polynomial-size rational linear program whose optimal allocations and objective value coincide with those of the original problem.

1. All cost arguments lie in their specified domains

Let \(E=\{(t,p):t\in T,\ p\in A_t\}\), and introduce allocation variables only for pairs in \(E\). All other allocations are zero.

For every allocation satisfying the mass constraints,

\(\displaystyle \sum_{(t,p)\in E}y_{tp} \leq \sum_{t\in T}\mu_t=1.\)

Consequently, for every platform and group,

\(\displaystyle 0\leq \nu_{pj}\leq \sigma_p\leq 1.\)

The first inequality between aggregates holds because the sum defining \(\nu_{pj}\) uses a subset of the nonnegative terms defining \(\sigma_p\). It holds irrespective of group overlaps. Thus every cost is evaluated within its domain.

2. Affine representation of each convex piecewise-linear cost

Consider any one of the input cost functions \(f\). Write its breakpoints and values as

\(\displaystyle 0=b_0<b_1<\cdots<b_k=1,\qquad v_i=f(b_i).\)

For each piece \(r\in\{1,\ldots,k\}\), define

\(\displaystyle a_r=\frac{v_r-v_{r-1}}{b_r-b_{r-1}},\qquad c_r=v_{r-1}-a_rb_{r-1}.\)

The function equals \(a_rx+c_r\) on \([b_{r-1},b_r]\).

Claim. For every \(x\in[0,1]\),

\(\displaystyle f(x)=\max_{1\leq r\leq k}(a_rx+c_r).\)

Proof. Convexity at any interior breakpoint gives

\(\displaystyle v_r\leq \frac{b_{r+1}-b_r}{b_{r+1}-b_{r-1}}v_{r-1} + \frac{b_r-b_{r-1}}{b_{r+1}-b_{r-1}}v_{r+1}. \)

Rearranging yields \(a_r\leq a_{r+1}\). Hence the piece slopes are nondecreasing.

Fix a piece \(r\). If \(x\geq b_r\), partition \([b_r,x]\) at its breakpoints. Every traversed piece has slope at least \(a_r\), so

\(\displaystyle f(x)-v_r\geq a_r(x-b_r).\)

Since \(v_r=a_rb_r+c_r\), this implies \(f(x)\geq a_rx+c_r\).

If \(x\leq b_{r-1}\), every piece traversed from \(x\) to \(b_{r-1}\) has slope at most \(a_r\). Therefore

\(\displaystyle v_{r-1}-f(x)\leq a_r(b_{r-1}-x),\)

again giving \(f(x)\geq a_rx+c_r\). Within the piece interval there is equality.

Thus every affine piece extension lies below \(f\) everywhere, and at every point at least one extension equals \(f\). This proves the claim. \(\square\)

No positivity assumption on slopes or values was used. The intercepts \(c_r\) retain all constants, including nonzero values at zero.

Apply this construction to write

\(\displaystyle \Phi_p(x)=\max_r(a^\Phi_{pr}x+c^\Phi_{pr}),\qquad \Psi_{pj}(x)=\max_r(a^\Psi_{pjr}x+c^\Psi_{pjr}). \)

Each maximum ranges over the pieces of its particular function.

3. Exact linear-programming formulation

Introduce the allocation variables \(y_{tp}\), aggregate variables \(\sigma_p,\nu_{pj}\), and cost variables \(z_p,w_{pj}\). The cost variables are real variables with no nonnegativity restriction.

Minimize

\(\displaystyle \sum_{p\in P}z_p+\sum_{p\in P}\sum_{j=1}^g w_{pj}\)

subject to the following linear constraints:

  • Allocation and utility constraints:

\(\displaystyle y_{tp}\geq0\quad ((t,p)\in E),\)

\(\displaystyle \sum_{p\in A_t}y_{tp}\leq\mu_t\quad(t\in T),\)

\(\displaystyle \sum_{(t,p)\in E}u_{tp}y_{tp}\geq\ell.\)

  • Aggregate definitions and domain bounds:

\(\displaystyle \sigma_p=\sum_{t:(t,p)\in E}y_{tp}\quad(p\in P),\)

\(\displaystyle \nu_{pj}=\sum_{\substack{t:(t,p)\in E\\j\in J_t}}y_{tp} \quad(p\in P,\ 1\leq j\leq g),\)

\(\displaystyle 0\leq\sigma_p\leq1,\qquad 0\leq\nu_{pj}\leq1.\)

  • Cost inequalities, one per linear piece:

\(\displaystyle z_p\geq a^\Phi_{pr}\sigma_p+c^\Phi_{pr},\)

\(\displaystyle w_{pj}\geq a^\Psi_{pjr}\nu_{pj}+c^\Psi_{pjr}.\)

Proof of equivalence

Let \(F(y)\) denote the original objective.

Every original feasible allocation can be extended to an LP-feasible point by using its prescribed aggregates and setting

\(\displaystyle z_p=\Phi_p(\sigma_p),\qquad w_{pj}=\Psi_{pj}(\nu_{pj}).\)

The affine representation proves all cost inequalities, and the LP objective then equals \(F(y)\).

Conversely, every LP-feasible point projects to an original feasible allocation. Its cost inequalities imply

\(\displaystyle z_p\geq\Phi_p(\sigma_p),\qquad w_{pj}\geq\Psi_{pj}(\nu_{pj}).\)

Therefore its LP objective is at least \(F(y)\).

These two directions establish equivalence of feasibility and equality of optimal values. Moreover, an optimal LP point projects to an optimal original allocation: otherwise lifting a strictly better original allocation would contradict LP optimality.

For completeness, whenever feasible, the original problem attains its minimum. Its feasible set is closed and bounded, since \(0\leq y_{tp}\leq\mu_t\), and its objective is continuous. Thus the equivalent LP also has an attained finite optimum.

4. Polynomial encoding length and exact computation

Let \(n=|E|\leq m\tau\). The LP has

\(\displaystyle n+2m(g+1)\)

variables and

\(\displaystyle O(n+\tau+m(g+1)+K)\)

constraints, counting equalities as pairs of inequalities if necessary.

Arbitrary overlaps only determine which allocation variables appear in each aggregate equation. These incidences can be constructed directly from the supported types and their membership sets; no enumeration of unsupported types or possible membership patterns is needed.

All coefficients are rational. Each new slope and intercept requires a constant number of rational arithmetic operations on input numbers. Their binary lengths are therefore \(O(L)\), even when a breakpoint interval is very short. The complete LP encoding has length polynomial in \(m,\tau,g,K,L\).

We now apply the standard exact rational linear-programming theorem: an explicitly encoded rational LP can be solved in polynomial time in its binary encoding length, detecting infeasibility or unboundedness, or returning an exact rational optimal solution when a finite optimum exists. This is an exact bit-complexity result, rather than merely an approximation guarantee; see [*Linear Programming using Limited-Precision Oracles*, Section 1.3](https://optimization-online.org/wp-content/uploads/2019/12/7507.pdf).

Here the LP is explicitly encoded, rational, and of polynomial encoding length. Whenever feasible, it has an attained finite optimum, as proved above. Hence the theorem returns an exact optimal allocation and value in the required polynomial time.

5. Feasibility can also be checked directly

Define

\(\displaystyle v_t=\max\bigl(\{0\}\cup\{u_{tp}:p\in A_t\}\bigr),\qquad U_{\max}=\sum_{t\in T}\mu_tv_t.\)

For every feasible allocation,

\(\displaystyle \sum_{(t,p)\in E}u_{tp}y_{tp} \leq\sum_{t\in T}v_t\sum_{p\in A_t}y_{tp} \leq U_{\max}. \)

This bound is attained by assigning each type with \(v_t>0\) entirely to an allowed platform attaining \(v_t\), and leaving types with \(v_t=0\) unassigned. This also handles empty allowed sets.

Thus the problem is feasible exactly when \(\ell\leq U_{\max}\), a condition checkable by polynomial-time rational arithmetic.

6. Relation to the discrete results

The [cited discrete results](https://ojs.aaai.org/index.php/AAAI/article/view/38768/42730) concern indivisible allocations. Here allocations are real variables, and the formulation above has no integrality constraints. Arbitrary overlap therefore poses no obstacle to solving this continuous problem by linear programming.

The classification proved here is exact polynomial-time solvability in the binary input model; no claim of strongly polynomial running time is needed.
