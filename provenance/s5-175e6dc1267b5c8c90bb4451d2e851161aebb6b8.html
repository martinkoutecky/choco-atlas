The continuous mirror question, as graded

Given three types with masses \(\mu_i=1/3\), chore categories \(M\) each supplied at mass \(1/3\), and type cost functions \(c_1,c_2,c_3\), where \(c_1,c_2\) are additive and satisfy \(\max_{b\in M}c_i(b)/\min_{b\in M}c_i(b)\le 2\), and \(c_3\) is monotone, find masses \(x_{i,S}\ge 0\) assigned to integral bundles \(S\subseteq M\) such that \(\sum_S x_{i,S}=1/3\) for each type and \(\sum_{i,S:b\in S}x_{i,S}=1/3\) for each chore category. Require that for every occupied pair \(x_{i,S}>0\), \(x_{j,R}>0\), and every \(b\in S\), \(c_i(S\setminus\{b\})\le c_i(R\cup\{b\})\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here \(\tau=3\), each type has mass \(1/3\), and each category in a nonempty set \(M\), with \(m=|M|\), has supply \(1/3\).
Costs \(c_i:2^M\to\mathbb{Q}_{\geq0}\) are normalized and monotone. The additive functions \(c_1,c_2\) are specified by positive binary rational singleton costs satisfying \(\max_{b\in M}c_i(\{b\})/\min_{b\in M}c_i(\{b\})\leq2\); \(c_3\) is specified by its complete binary rational value table. Ties are allowed. Let \(L\) be the total input bit length.
An allocation assigns nonnegative masses \(x_{i,S}\) to integral bundles \(S\subseteq M\), including the empty bundle, with \(\sum_{S\subseteq M}x_{i,S}=1/3\) for every type and \(\sum_{i=1}^3\sum_{S\ni b}x_{i,S}=1/3\) for every category \(b\).
It is tEFX if every occupied pair \(x_{i,S}>0\), \(x_{j,R}>0\) satisfies \(c_i(S\setminus\{b\})\leq c_i(R\cup\{b\})\) for every \(b\in S\). This includes comparisons within a type; bundles may overlap, and union means set union.
Is finding such a mass allocation polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?
For three discrete agents under these cost restrictions, a complete tEFX allocation exists and can be found in polynomial time, with a stated \(O(m)\) unit-cost bound ([Yin–Mehta](https://arxiv.org/pdf/2211.15836)).
Later discrete work establishes existence even when only one agent has additive \(2\)-ratio-bounded costs and the other two have general monotone costs ([Afshinmehr et al.](https://arxiv.org/html/2410.18655v1#S4)). No result for this exact mass-allocation problem was located.

  • Restore nonnegative costs and normalization c_i(empty set)=0 from the discrete model.

  • Allow cost ties: nondegeneracy is an auxiliary perturbation convention in the discrete analysis, rather than a restriction in the stated result.

Result

Finding the required mass allocation is polynomial-time solvable in \(m,\tau,L\), for the stated case \(\tau=3\). A discrete tEFX partition gives a mass allocation with exactly one occupied bundle per type. The complete value table also makes exhaustive search over discrete partitions polynomial in \(L\).

1. Discrete existence, including ties

We use the following established result: three agents admit a complete tEFX partition when two cost functions are additive with positive singleton costs and maximum-to-minimum ratio at most \(2\), and the third is normalized and monotone. This is [Yin–Mehta, Theorem 5.2](https://arxiv.org/pdf/2211.15836).

Its hypotheses match the costs in the question. To handle ties explicitly, we show that they can be removed while preserving both the ratio restriction and every strict original cost comparison.

Write \(M=\{b_1,\ldots,b_m\}\), and define the additive function

\[ p(S)=\sum_{b_k\in S}\left(1+\frac{2^{k-1}}{2^m}\right). \]

The fractional part of \(p(S)\) lies in \([0,1)\), so its integer part determines \(|S|\), and its fractional part determines \(S\) by binary expansion. Consequently, \(p(S)\neq p(T)\) whenever \(S\neq T\). Also, \(0\leq p(S)<m+1\).

Let \(\delta\) be the minimum positive value among all differences \(|c_i(S)-c_i(T)|\). This minimum exists: there are finitely many bundles, and positivity of the singleton costs of \(c_1\) ensures that some difference is positive. Choose a positive rational \(\varepsilon\) satisfying \(\varepsilon(m+1)<\delta\), and set

\[ c_i^\varepsilon(S)=c_i(S)+\varepsilon p(S). \]

These functions remain normalized and monotone, and the first two remain additive. Every strict original comparison is preserved, because \(c_i(S)>c_i(T)\) implies

\[ c_i^\varepsilon(S)-c_i^\varepsilon(T) \geq \delta-\varepsilon|p(S)-p(T)| >0. \]

Original ties are broken by injectivity of \(p\). Thus the perturbed instance is non-degenerate.

The ratio restriction is also preserved. For \(i\in\{1,2\}\) and any \(b,d\in M\), the original restriction gives \(c_i(\{b\})\leq2c_i(\{d\})\). Moreover, every singleton perturbation weight lies between \(1\) and \(3/2\), so \(p(\{b\})\leq2p(\{d\})\). Adding these inequalities gives

\[ c_i^\varepsilon(\{b\})\leq2c_i^\varepsilon(\{d\}). \]

Apply the discrete theorem to the perturbed instance. It supplies a partition \(A_1,A_2,A_3\) of \(M\) satisfying

\[ c_i^\varepsilon(A_i\setminus\{b\}) \leq c_i^\varepsilon(A_j\cup\{b\}) \quad \text{for every }i\neq j\text{ and }b\in A_i. \]

This partition is tEFX for the original costs as well. Otherwise, an original strict violation would remain a strict violation after perturbation, contradicting the displayed inequality. Therefore a suitable discrete partition exists even with ties.

2. Converting a partition into a mass allocation

Given such a partition, define

\[ x_{i,S}= \begin{cases} 1/3,&S=A_i,\\ 0,&S\neq A_i. \end{cases} \]

For each type, exactly one bundle has mass \(1/3\), so its total allocated mass is correct. Each category belongs to exactly one partition bundle, hence

\[ \sum_{i=1}^{3}\sum_{S\ni b}x_{i,S} =\frac13. \]

For distinct types, the only occupied bundles are \(A_i\) and \(A_j\), and their required comparisons are precisely the discrete tEFX inequalities.

For a comparison within type \(i\), both occupied bundles equal \(A_i\). Whenever \(b\in A_i\), monotonicity gives

\[ c_i(A_i\setminus\{b\}) \leq c_i(A_i) =c_i(A_i\cup\{b\}). \]

Thus every required occupied-pair comparison holds, including within-type comparisons. Empty partition bundles cause no difficulty: their source comparisons are vacuous.

3. A polynomial-time algorithm in the specified encoding

The following algorithm suffices without relying on the discrete theorem’s unit-cost running-time claim:

  • Enumerate every map \(f:M\to\{1,2,3\}\).
  • Form its partition \(A_i=f^{-1}(i)\).
  • Check all discrete tEFX inequalities for the original costs.
  • For the first passing partition, output the allocation from Section 2.

Section 1 guarantees that some partition passes.

There are \(3^m\) candidates. Since the input contains all \(2^m\) values of \(c_3\), its bit length satisfies \(L\geq2^m\). Therefore

\[ 3^m\leq4^m=(2^m)^2\leq L^2. \]

Each partition requires only polynomially many cost evaluations and comparisons. Additive costs are sums of at most \(m\) input rationals; the third cost is obtained from its explicit table. Exact sums and comparisons take polynomial bit time: even using products of denominators, the intermediate numbers have \(O(mL+\log m)\) bits. Table entries can be found by scanning the input if necessary, which also takes polynomial time.

Consequently, the entire search takes \(\operatorname{poly}(m,L)\) bit operations. Its output has three occupied type–bundle pairs, each with mass \(1/3\).

The partition construction satisfies the full mass-allocation requirements; allowing additional bundles or overlaps does not affect this conclusion.
