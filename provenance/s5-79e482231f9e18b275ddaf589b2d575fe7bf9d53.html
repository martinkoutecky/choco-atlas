The continuous mirror question, as graded

Given rational type masses \(\mu_t\), per-capita supplies of finitely many object categories, ordinal or benchmark-utility information for each type, and a feasible type-level random assignment \(x\), determine whether \(x\) is undominated; if it is, produce preference-compatible utilities \(v_t\) under which \(x\) maximizes aggregate ex-ante welfare, and otherwise produce a feasible assignment that dominates it.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. There are \(m\geq1\) object categories with nonnegative binary-rational per-capita supplies \(c_j\), where \(\sum_jc_j\geq1\); unused supply is permitted.
Each type has either a complete weak ordinal ranking \(\succeq_t\), or a nonempty list of signed rational benchmark vNM utility vectors \(u_t^1,\ldots,u_t^{k_t}\). Let \(K\) be the total number of benchmark vectors and \(L\) the total input bit length.
A feasible type-level random assignment \(y\) satisfies \(y_{tj}\geq0\), \(\sum_jy_{tj}=1\), and \(\sum_t\mu_ty_{tj}\leq c_j\). The input includes a rational feasible assignment \(x\).
An assignment \(y\) strictly dominates \(x\) if, for every ordinal type and every category \(j\), \(\sum_{a\succeq_t j}y_{ta}\geq\sum_{a\succeq_t j}x_{ta}\), and for every benchmark type and every \(\ell\), \(\sum_ju_t^\ell(j)y_{tj}\geq\sum_ju_t^\ell(j)x_{tj}\), with at least one of these inequalities strict. Call \(x\) undominated if no feasible \(y\) strictly dominates it.
Preference-compatible utilities satisfy \(v_t(a)\geq v_t(b)\iff a\succeq_t b\) for ordinal types, and \(v_t=\sum_{\ell=1}^{k_t}w_t^\ell u_t^\ell\), with \(w_t^\ell\geq0\), for benchmark types; impose no utility normalization.
The computational problem decides whether \(x\) is undominated and returns rational preference-compatible utilities making \(x\) maximize \(\sum_t\mu_t\sum_jv_t(j)y_{tj}\) over feasible assignments if it is, or a rational feasible assignment strictly dominating \(x\) otherwise.

Is this decision-and-construction problem solvable in time polynomial in \(m,\tau,K,L\), or is deciding undominatedness \(\mathrm{NP}\)-hard?

For finite agent lists, every undominated assignment admits a constructively obtained preference-compatible utility profile under which it maximizes aggregate ex-ante welfare ([Athanassoglou, 2011](https://www.sciencedirect.com/science/article/abs/pii/S0304406811000115)).

Result

The decision-and-construction problem is solvable in time polynomial in \(m,\tau,K,L\). A dominance linear program decides undominatedness, and its dual constructs the required rational utilities.

The proof works directly with the support and its masses.

1. Encode the preference comparisons

Let \(\mathcal F\) be the feasible-assignment polytope specified in the question.

For each ordinal type \(t\), write its indifference classes from best to worst as \(E_{t1},\ldots,E_{th_t}\). Define \(B_{tr}=E_{t1}\cup\cdots\cup E_{tr}\). Retain the comparisons

\[ \sum_{j\in B_{tr}}y_{tj}\geq\sum_{j\in B_{tr}}x_{tj}, \qquad r=1,\ldots,h_t-1. \]

Here and below, these displayed formulas denote the corresponding LaTeX mathematical expressions. Each original ordinal comparison is either one of these, a duplicate within an indifference class, or the full-row comparison, which is always an equality because both row sums are \(1\). Thus removing the duplicates and full-row comparisons preserves both weak dominance and the existence of a strict comparison.

For benchmark types, retain every benchmark comparison.

Index all retained comparisons by \(r=1,\ldots,M\), where

\[ M=\sum_{t\text{ ordinal}}(h_t-1)+K\leq\tau(m-1)+K. \]

Write comparison \(r\) as \(a_r\cdot y\geq b_r\), where \(b_r=a_r\cdot x\). Each coefficient vector \(a_r\) is supported on a single type’s row: it is a prefix indicator for an ordinal comparison, or the given utility vector for a benchmark comparison.

Consequently, a feasible assignment strictly dominates \(x\) exactly when all retained comparisons hold and at least one is strict.

If \(M=0\), every type is ordinal and indifferent among all categories. No strict dominance is possible, and setting every utility to zero supplies the required output. Assume henceforth that \(M>0\).

2. Decide dominance by linear programming

Consider the rational linear program

\[ \delta^\star= \max\left\{ \sum_{r=1}^{M}(a_r\cdot y-b_r): y\in\mathcal F,\quad a_r\cdot y\geq b_r\ \text{for every }r \right\}. \]

The supplied assignment \(x\) is feasible for this program and has objective zero. Moreover, \(\mathcal F\) is closed and contained in \([0,1]^{\tau m}\). Hence the program has a finite attained optimum, with \(\delta^\star\geq0\).

Every summand in its objective is nonnegative on its feasible region. Therefore:

  • If \(\delta^\star>0\), an optimal assignment satisfies every preference comparison and strictly satisfies at least one. It strictly dominates \(x\).
  • If a feasible assignment strictly dominates \(x\), its objective is positive, so \(\delta^\star>0\).

Thus \(x\) is undominated if and only if \(\delta^\star=0\). An exact rational LP algorithm returns a rational dominating assignment in the positive-optimum case.

3. Obtain positive supporting weights from the dual

Suppose \(\delta^\star=0\).

Introduce unrestricted dual variables \(\alpha_t\) for the row-sum equalities, nonnegative variables \(q_j\) for the supply inequalities, and nonnegative variables \(\lambda_r\) for the dominance inequalities written as \(-a_r\cdot y\leq-b_r\).

Let \(a_{r,tj}\) denote coordinate \((t,j)\) of \(a_r\), and put \(w_r=1+\lambda_r\). The dual is

\[ \min\left(\sum_t\alpha_t+\sum_jc_jq_j-\sum_rw_rb_r\right), \]

subject to

\[ \alpha_t+\mu_tq_j\geq\sum_rw_ra_{r,tj} \quad\text{for every }t,j, \qquad q_j\geq0,\quad w_r\geq1. \]

To verify the coefficients, the primal objective has coefficient \(\sum_ra_{r,tj}\) on \(y_{tj}\). The standard dual inequality is therefore

\[ \alpha_t+\mu_tq_j-\sum_r\lambda_ra_{r,tj} \geq\sum_ra_{r,tj}, \]

which gives the stated constraint. Its objective includes the primal objective’s constant term \(-\sum_rb_r\), yielding the expression above.

We use strong LP duality in its standard form: a feasible linear program with finite optimum has an attained dual optimum of the same value. The primal satisfies these hypotheses, as proved in Section 2. Thus the dual admits an optimal solution with

\[ \sum_t\alpha_t+\sum_jc_jq_j=\sum_rw_rb_r. \]

The standard duality theorem and the reduction of optimization to primal-dual feasibility are described in [MIT’s LP duality notes](https://courses.csail.mit.edu/6.854/18/Notes/n12-duality.html). All coefficients here are rational, so an exact rational LP algorithm can construct such a solution.

Define \(g_{tj}=\sum_rw_ra_{r,tj}\). For every feasible assignment \(y\in\mathcal F\), including those that fail the dominance constraints, dual feasibility gives

\[ \sum_{t,j}g_{tj}y_{tj} \leq \sum_{t,j}(\alpha_t+\mu_tq_j)y_{tj} = \sum_t\alpha_t+\sum_jq_j\sum_t\mu_ty_{tj} \leq \sum_t\alpha_t+\sum_jq_jc_j. \]

The equality uses the row sums, and the final inequality uses the supply bounds and \(q_j\geq0\). At \(x\), the last bound equals

\[ \sum_rw_rb_r=\sum_{t,j}g_{tj}x_{tj}. \]

Hence \(x\) maximizes \(\sum_{t,j}g_{tj}y_{tj}\) over all feasible assignments. Crucially, every comparison weight satisfies \(w_r\geq1\).

4. Construct and verify preference-compatible utilities

Because every mass is positive, define

\[ v_t(j)=\frac{g_{tj}}{\mu_t}. \]

Then aggregate welfare is exactly the supported objective:

\[ \sum_t\mu_t\sum_jv_t(j)y_{tj} = \sum_{t,j}g_{tj}y_{tj}. \]

Thus \(x\) maximizes aggregate welfare under these utilities.

For an ordinal type, denote its prefix weights by \(w_{t1},\ldots,w_{t,h_t-1}\). If \(j\in E_{ts}\), then

\[ v_t(j)=\frac{1}{\mu_t}\sum_{r=s}^{h_t-1}w_{tr}. \]

Utilities are therefore equal within each indifference class. If \(a\in E_{ts}\) and \(b\in E_{td}\), with \(s<d\), then

\[ v_t(a)-v_t(b) = \frac{1}{\mu_t}\sum_{r=s}^{d-1}w_{tr}>0. \]

The inequality follows from \(\mu_t>0\) and \(w_{tr}\geq1\). Consequently, \(v_t(a)\geq v_t(b)\) if and only if \(a\succeq_t b\), exactly as required. A type with a single indifference class receives constant zero utility.

For a benchmark type, denote its benchmark weights by \(w_{t\ell}\). The construction gives

\[ v_t=\sum_{\ell=1}^{k_t}\frac{w_{t\ell}}{\mu_t}u_t^\ell. \]

Every coefficient is positive, hence nonnegative. This is an admissible benchmark utility, regardless of the signs or linear dependencies of the benchmark vectors.

5. Polynomial bit complexity and algorithm

The primal has \(\tau m\) variables and \(M\) preference constraints, in addition to the assignment constraints. The dual has \(\tau+m+M\) variables and \(\tau m\) coefficient inequalities.

Both programs have polynomial encoding length. Their coefficients are input rationals, prefix indicators, or sums of polynomially many products of input rationals. Such operations produce rationals of polynomial bit length.

We use the rational LP algorithmic theorem: feasibility and optimization can be performed exactly in time polynomial in the encoded problem size, returning rational solutions when feasible and, for optimization, when the optimum is finite. See [Megiddo, *Complexity of linear programming*](https://theory.stanford.edu/~megiddo/pdf/wcongres_4.0.a.pdf). Polynomial output length also follows from the determinant bounds for basic solutions after conversion to standard form and clearing denominators.

Finally, division by \(\mu_t\) preserves polynomial bit length: for a positive rational mass, taking its reciprocal merely exchanges numerator and denominator.

The algorithm is therefore:

  • Construct and solve the dominance LP exactly.
  • If its optimum is positive, return its rational optimal assignment as a strict dominator.
  • If its optimum is zero, solve the dual and return the utilities constructed above.

All steps run in time polynomial in \(m,\tau,K,L\), completing both the decision and construction requirements.
