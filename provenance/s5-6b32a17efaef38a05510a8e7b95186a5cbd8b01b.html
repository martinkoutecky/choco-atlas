The continuous mirror question, as graded

Given firm types \(F\) and worker types \(W\), rational supplies \(\alpha_f\) and \(\beta_w\) summing to one on each side, shared strict rankings, acceptable pairs \(E\), and rational pair welfare values \(v_{fw}\), maximize \(\sum_{(f,w)\in E}v_{fw}x_{fw}\). Require \(x_{fw}\ge 0\), zero flow outside \(E\), and \(\sum_w x_{fw}\le\alpha_f\), \(\sum_f x_{fw}\le\beta_w\). For every \((f,w)\in E\), require either \(\sum_{i:\,f\succ_w i}x_{iw}=0\) or \(\alpha_f-\sum_jx_{fj}+\sum_{j:\,w\succ_f j}x_{fj}=0\), so no positive mass of employed workers and firms form a blocking pair.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here the nonempty firm and worker supports are \(F,W\), with \(m=|W|\), \(\tau=|F|+|W|\), and \(L\) the total input bit length. State running times in \(m,\tau,L\).
Each type has a strict ranking \(\succ_f\) over \(W\cup\{\emptyset\}\) or \(\succ_w\) over \(F\cup\{\emptyset\}\), shared by all its members; \(\emptyset\) means unmatched. Set \(E=\{(f,w):w\succ_f\emptyset,\ f\succ_w\emptyset\}\). Supplies satisfy \(\alpha_f,\beta_w>0\) and \(\sum_f\alpha_f=\sum_w\beta_w=1\). Pair values \(v_{fw}\in\mathbb Q\) may have either sign; unmatched mass has zero welfare.
An allocation has divisible real flows \(x_{fw}\ge0\), with \(x_{fw}=0\) outside \(E\), \(\sum_{w\in W}x_{fw}\le\alpha_f\), and \(\sum_{f\in F}x_{fw}\le\beta_w\).
Call it worker-quasi-stable when, for every \((f,w)\in E\), either \(\sum_{i\in F:\,f\succ_w i}x_{iw}=0\) or \(\alpha_f-\sum_{j\in W}x_{fj}+\sum_{j\in W:\,w\succ_f j}x_{fj}=0\). Blocking deviations involving unemployed worker mass are permitted; same-type partners are indifferent.
The objective is to maximize \(\sum_{(f,w)\in E}v_{fw}x_{fw}\). Given a binary rational threshold \(q\), the decision problem asks whether some such allocation has welfare at least \(q\).

Is this continuous worker-quasi-stable welfare decision problem in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For discrete one-to-one markets, the worker-quasi-stable matching polytope is integral, with precisely the matching incidence vectors as vertices; linear welfare optimization is consequently polynomial-time solvable ([Guiñazú et al.](https://arxiv.org/html/2609.20032v1)).
No result settling this exact continuous problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted shared rankings as rankings shared within each type, allowing different types to have different rankings; members of the same opposite-side type are indifferent.
  • Made acceptability consistent with the discrete definition: a pair is acceptable exactly when both types rank each other above being unmatched.
  • Specified arbitrary signed rational welfare values and zero welfare for unmatched mass, consistent with optimization of an arbitrary linear objective.
  • Introduced a binary rational welfare threshold to state the decision complexity question corresponding to exact maximization.
  • Defined the size parameters as the worker support size m, combined support size tau, and total input bit length L.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when all supported types have the same dyadic mass and all pair values belong to \(\{0,1\}\).

There is also an inconsistency in the supplied discrete premise: the polytope displayed in the cited preprint is not integral. An explicit counterexample appears below. The hardness proof does not rely on that preprint.

1. A useful reformulation

Write \(n=|F|=\tau-m\). For an acceptable pair, define

\(A_{fw}(x)=\sum_{i:\,f\succ_w i}x_{iw}\)

and

\(B_{fw}(x)=\alpha_f-\sum_jx_{fj}+\sum_{j:\,w\succ_f j}x_{fj}\).

Both quantities are nonnegative for every feasible allocation. Worker-quasi-stability is exactly the requirement that \(A_{fw}(x)=0\) or \(B_{fw}(x)=0\) for every \((f,w)\in E\).

Because the rankings are strict,

\(B_{fw}(x)=\alpha_f-x_{fw}-\sum_{j:\,j\succ_f w}x_{fj}\).

Moreover, its original expression is a sum of nonnegative terms. Consequently, \(B_{fw}(x)=0\) implies both that firm \(f\) is fully allocated and that \(x_{fj}=0\) whenever \(w\succ_f j\). This implication will exclude simultaneous positive flows on certain pairs.

2. Reduction from Independent Set

Let \(G=(V,H)\) be a simple undirected graph, with \(|V|=n\), and let \(k\) be the requested independent-set size. Independent Set is \(\mathrm{NP}\)-complete.

We may assume that \(n\) is a power of two. Indeed, pad the graph with isolated vertices up to the next power of two, and increase \(k\) by the number of added vertices. The independence number increases by exactly that number, so the answer is preserved. Padding increases the number of vertices by less than a factor of two.

Construction

For each \(u\in V\), introduce two firm types, \(f_u,d_u\), and two worker types, \(a_u,b_u\). Thus

\(F=\{f_u,d_u:u\in V\},\qquad W=\{a_u,b_u:u\in V\}\).

Every type has mass \(c=1/(2n)\). Both sides therefore have total mass one. Since \(n\) is a power of two, all these masses are dyadic.

The acceptable portions of the strict rankings are as follows; each indicated neighbor list is ordered arbitrarily but strictly.

| Type | Ranking above \(\emptyset\), from best to worst |
|---|---|
| \(f_u\) | \(b_u\), then all \(a_v\) with \(v\in N_G(u)\), then \(a_u\) |
| \(d_u\) | None |
| \(a_u\) | All \(f_v\) with \(v\in N_G(u)\), then \(f_u\) |
| \(b_u\) | \(f_u\) |

Place every remaining alternative strictly below \(\emptyset\), in arbitrary order. These are strict rankings over the complete supported opposite side together with \(\emptyset\).

The mutually acceptable pairs are precisely

\(E=\{(f_u,a_u),(f_u,b_u):u\in V\}\cup\{(f_u,a_v):\{u,v\}\in H\}\).

Set \(v_{f_u a_u}=1\), and set every other acceptable pair value to zero. The decision threshold is \(q=kc\).

The isolated firm types \(d_u\) serve to balance total supplies. They have positive mass and therefore count as supported types.

Positive own-pair flows identify an independent set

Let \(x\) be any worker-quasi-stable allocation in the constructed society. Define

\(S(x)=\{u\in V:x_{f_u a_u}>0\}\).

Claim. \(S(x)\) is an independent set.

Suppose instead that \(\{u,v\}\in H\) and both \(u,v\in S(x)\). Consider the acceptable pair \((f_v,a_u)\).

Worker \(a_u\) prefers neighbor firm \(f_v\) to own firm \(f_u\). Hence

\(A_{f_v a_u}(x)\ge x_{f_u a_u}>0\).

Firm \(f_v\) prefers neighbor worker \(a_u\) to own worker \(a_v\). Its nonnegative expression for \(B_{f_v a_u}\) therefore contains \(x_{f_v a_v}\), giving

\(B_{f_v a_u}(x)\ge x_{f_v a_v}>0\).

Both quantities are positive, contradicting worker-quasi-stability. This proves the claim.

Only own pairs contribute to welfare. Each such flow is at most \(c\), by either endpoint’s supply constraint. Therefore

\(\sum_{(f,w)\in E}v_{fw}x_{fw}=\sum_{u\in S(x)}x_{f_u a_u}\le c|S(x)|\le c\,\alpha(G)\),

where \(\alpha(G)\) denotes the independence number.

This argument applies to arbitrary real flows: splitting mass cannot circumvent the independent-set restriction.

Every independent set gives a quasi-stable allocation

Let \(S\subseteq V\) be independent. Define

\(x_{f_u a_u}=c\) for \(u\in S\), and \(x_{f_u b_u}=c\) for \(u\notin S\),

with every other flow zero.

Every real firm receives exactly its supply. Each worker receives either zero or exactly its supply, so the allocation is feasible.

We check every kind of acceptable pair:

  • For \((f_u,b_u)\), worker \(b_u\) receives no flow from an inferior firm, so \(A_{f_u b_u}=0\).
  • For \((f_u,a_u)\), worker \(a_u\) is either unmatched or assigned only to \(f_u\), so \(A_{f_u a_u}=0\).
  • For a neighbor pair \((f_v,a_u)\), if \(u\notin S\), then \(a_u\) is unmatched and \(A_{f_v a_u}=0\). If \(u\in S\), independence gives \(v\notin S\). Firm \(f_v\) is then fully assigned to its top worker \(b_v\), whom it prefers to \(a_u\), so \(B_{f_v a_u}=0\).

Thus the allocation is worker-quasi-stable and has welfare \(c|S|\).

Combining the two directions gives the exact identity

\(\operatorname{OPT}(G)=c\,\alpha(G)\).

In particular, the constructed society has welfare at least \(q=kc\) if and only if \(G\) has an independent set of size at least \(k\).

Size and running time

The construction has \(m=2n\) and \(\tau=4n\). Writing all strict rankings explicitly requires \(O(n^2\log(n+1))=O(m\tau\log(\tau+1))\) bits and construction time. The masses and threshold have \(O(\log(n+1))\)-bit encodings.

This is a polynomial-time many-one reduction. It proves \(\mathrm{NP}\)-hardness under the stated restricted supplies and values.

3. Membership in \(\mathrm{NP}\)

Real-valued flows do not require irrational or excessively long certificates.

Let \(P\) be the ordinary feasible transportation polytope. At any worker-quasi-stable allocation \(x\), choose one vanishing branch for every acceptable pair.

The equality \(A_{fw}=0\) fixes every flow occurring in that sum to zero. The equality \(B_{fw}=0\) fixes the unmatched slack of firm \(f\), and every indicated inferior-worker flow, to zero. These conclusions follow because all the summands are nonnegative.

Thus the selected branches define a face \(P_x\) of \(P\), containing \(x\), and every point of \(P_x\) is worker-quasi-stable. Indeed, every selected vanishing branch remains satisfied.

Let \(D\) be the product of the denominators of all supplies. Then \(\log_2 D\le L\). After scaling by \(D\), introduce nonnegative unmatched slack variables and write the capacity constraints as equalities:

\(\sum_w y_{fw}+s_f=D\alpha_f,\qquad \sum_f y_{fw}+t_w=D\beta_w\).

The right-hand sides are integers. After negating all worker equations, each flow column has one positive and one negative unit entry, and each slack column has one unit entry. This matrix is totally unimodular: in any square submatrix, a column with at most one nonzero permits determinant expansion; otherwise every column has two opposite entries and the rows sum to zero. Induction gives determinants only in \(\{0,1,-1\}\).

The standard integrality theorem for totally unimodular systems therefore applies: the nonnegative equality system has integer vertices because its right-hand side is integral. The slack variables are uniquely determined by the flows, so vertices of the scaled transportation polytope are integral as well. Every face inherits this property.

If a yes-instance has any real feasible witness \(x\), maximize welfare over its nonempty bounded face \(P_x\). A linear objective attains its maximum at a vertex of that face. Consequently, there is a witness satisfying

\(x_{fw}=y_{fw}/D,\qquad y_{fw}\in\{0,1,\ldots,D\}\).

There are at most \(mn=m(\tau-m)\) flow coordinates. Their numerators therefore require only \(O(m(\tau-m)(L+1))\) certificate bits. Exact rational arithmetic verifies capacities, every quasi-stability disjunction, and the welfare threshold in time polynomial in \(m,\tau,L\).

Hence the decision problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness.

4. An exact support-based upper bound

For completeness, there is an exact algorithm running in

\(O((\tau-m+1)^m\operatorname{poly}(m,\tau,L))\).

For each worker type \(w\), choose either an unmatched label or an acceptable firm label \(c_w\), interpreted as a cutoff for its worst assigned firm.

An unmatched label forces all flows to \(w\) to zero. A firm label forbids flows from firms worse than \(c_w\). For each acceptable firm \(f\) that \(w\) prefers to \(c_w\), impose \(B_{fw}=0\).

For any such choice, the resulting constraints define a transportation face, and every point on it is quasi-stable. A firm at or below the cutoff has \(A_{fw}=0\); a firm above it has the imposed equality \(B_{fw}=0\).

Conversely, every quasi-stable allocation belongs to one of these faces: choose its actual worst positively assigned firm for each employed worker type. Every acceptable firm above that cutoff has \(A_{fw}>0\), so quasi-stability supplies the required equality \(B_{fw}=0\).

There are at most \((n+1)^m\) choices. Each face has a rational linear-programming description of size polynomial in \(m,\tau,L\), so its welfare optimum is computable in polynomial time. This gives the stated bound, including polynomial-time solvability for each fixed \(m\).

5. Counterexample to the cited discrete integrality assertion

The [cited preprint](https://arxiv.org/html/2609.20032v1) uses unit capacities and the inequalities

\(\sum_{i:\,i\succ_w f}x_{iw}+\sum_{j:\,j\succ_f w}x_{fj}+x_{fw}\ge\sum_i x_{iw}\).

Cancelling common terms rewrites these as

\(\sum_{i:\,f\succ_w i}x_{iw}\le\sum_{j:\,j\succ_f w}x_{fj}\).

Take the construction from Section 2 for a triangle, using three real firms and six workers, now with discrete unit capacities. Isolated firms may also be included without affecting the example.

Consider the fractional point

\(x_{f_u a_u}=x_{f_u b_u}=1/2\)

for each triangle vertex \(u\), with all neighbor-pair flows zero.

Every firm has row sum one; every worker has column sum one-half. For a neighbor pair \((f_v,a_u)\), the left side of the rewritten inequality is \(1/2\), from the own-pair assignment of \(a_u\). The right side is \(1/2\), from the top-worker assignment \(x_{f_v b_v}\). For own and private pairs, the left side is zero. Thus all displayed inequalities hold.

But the own-pair objective has value \(3/2\). In every discrete worker-quasi-stable matching, vertices whose own pairs are matched form an independent set, by the same blocking argument used above. A triangle permits at most one such pair, so every matching has objective at most one.

The fractional point is therefore outside the convex hull of worker-quasi-stable matching incidence vectors. In fact, it is a vertex of the displayed polytope: nonnegativity fixes all other coordinates to zero, the binding row equations give \(s_u+t_u=1\), and the binding neighbor inequalities give \(s_u=t_v\) for distinct triangle vertices. These equations uniquely force all six remaining coordinates to equal \(1/2\).

Thus the asserted discrete integrality cannot hold for the displayed formulation. The continuous hardness result above follows directly from the task’s definitions.
