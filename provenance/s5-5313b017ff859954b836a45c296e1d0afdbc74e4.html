The continuous mirror question, as graded

Given tasks \(J\) with positive integer processing times \(p_i\), at most three complete preferred schedules \(V_t\) with positive rational masses \(\mu_t\) summing to \(1\), and a rational threshold \(B\), is there a permutation \(S\) of the tasks such that \(\sum_t \mu_t \sum_{i \in J} |C_i(S)-d_i(t)| \le B\), where \(C_i(S)\) is task \(i\)'s completion time in \(S\) and \(d_i(t)\) is its completion time in \(V_t\)?

Packaged proof task (what the prover saw — nothing else)

Given a nonempty task set \(J=\{1,\ldots,m\}\), each task \(i\) has a positive integer processing time \(p_i\), encoded in binary. A schedule is a permutation of all tasks executed on one machine from time zero, without idle time or preemption; \(C_i(S)\) is task \(i\)'s completion time.
A society is given by its support: a list of \(\tau\) distinct types with positive binary rational masses \(\mu_t\), where \(1\leq\tau\leq3\) and \(\sum_{t=1}^{\tau}\mu_t=1\). Each type specifies a complete strict preferred schedule \(V_t\), and \(d_i(t)=C_i(V_t)\). Here \(\tau\) is the support size, not the number of possible schedules.
Given a binary rational threshold \(B\in\mathbb{Q}\), decide whether some schedule \(S\) satisfies \(\sum_{t=1}^{\tau}\mu_t\sum_{i\in J}|C_i(S)-d_i(t)|\leq B\). Tasks remain indivisible, and the outcome is a single permutation. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is this decision problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For a finite electorate with an unweighted sum of deviations, the decision problem is NP-hard even with three voters; with two voters it is polynomial-time solvable. [Source](https://arxiv.org/html/2602.21332v1)
No separate result explicitly treating this rational-mass formulation was located.

  • Made the scheduling clock explicit: execution starts at zero, on one machine, without idle time or preemption, following the discrete definition.
  • Required a nonempty task set and distinct supported schedules; repeated preferred schedules represent one type with their masses combined.
  • Specified binary encoding of processing times and the threshold, and defined L as the total input bit length.
  • Allowed any rational threshold, including negative values, since the stated question imposes no sign restriction.

Conclusion

The decision problem is NP-complete, even when the support size is at most three. Normalizing voter multiplicities into rational masses preserves the decision question exactly. For support size at most two, the problem is polynomial-time solvable, including with unequal masses.

1. Transfer of the three-voter hardness result

Use the stated result that the following problem is NP-hard: given positive integer processing times, three preferred permutations \(V_1,V_2,V_3\), and an integer threshold \(Z\), decide whether a permutation \(S\) satisfies

\(H(S):=\sum_{k=1}^{3}\sum_{i\in J}|C_i(S)-C_i(V_k)|\leq Z.\)

This is the unweighted collective scheduling objective, rather than the different objective that additionally weights each task by its processing time. Its schedules have no idle time or preemption, matching the present task. The cited paper states this hardness result as Theorem 2. [Durand, *Two NP-hard Extensions of the Spearman Footrule even for a Small Constant Number of Voters*](https://arxiv.org/html/2602.21332v1)

Construct an instance of the present problem as follows:

  • Keep all tasks and processing times.
  • Group identical preferred permutations. For each distinct permutation \(W_t\), let \(r_t\) be its multiplicity among the three voters.
  • Set \(\mu_t=r_t/3\) and \(B=Z/3\).

The resulting support consists of distinct permutations and satisfies \(1\leq\tau\leq3\). Each mass is a positive rational, and \(\sum_t\mu_t=1\). All processing times retain their original binary encodings.

For every feasible schedule \(S\), the constructed objective satisfies

\(F(S):=\sum_{t=1}^{\tau}\mu_t\sum_{i\in J}|C_i(S)-C_i(W_t)|=\frac13 H(S).\)

Consequently, \(F(S)\leq B\) if and only if \(H(S)\leq Z\). The feasible schedules themselves are unchanged: each outcome remains one permutation of indivisible tasks.

Grouping three permutations takes \(O(m)\) comparisons of task identifiers, and forming the new rational threshold requires only polynomial bit work. A conservative construction bound is \(O(m\tau L^2)\), where \(L\) denotes the source input length; the output length is polynomial in that length. This is a polynomial-time many-one reduction, proving NP-hardness.

In particular, binary rational masses do not require expansion into an electorate. The reduction uses only masses from \(\{1/3,2/3,1\}\).

2. Membership in NP and bit complexity

A certificate is a permutation \(S\), encoded using \(O(m\log(m+1))\) bits. Verify that every task occurs exactly once, then compute its completion times and those of the \(\tau\) preferred schedules.

Write \(P=\sum_i p_i\). Every completion time lies between \(1\) and \(P\), and each integer deviation sum

\(D_t(S):=\sum_{i\in J}|C_i(S)-d_i(t)|\)

is at most \(mP\). These integers have \(O(L)\) bits.

For exact threshold comparison, write \(\mu_t=a_t/b_t\) and \(B=c/d\), with positive denominators, and set \(Q=d\prod_t b_t\). Then \(F(S)\leq B\) is equivalent to the integer inequality

\(\sum_{t=1}^{\tau}a_t(Q/b_t)D_t(S)\leq c(Q/d).\)

The total encoded length of the denominators is at most \(L\), so \(Q\), and all integers in this comparison, have \(O(L)\) bits. Using elementary integer arithmetic, certificate verification takes \(O(m\tau L^2)\) bit operations.

Thus the problem belongs to NP. Combined with the reduction, it is NP-complete.

3. The polynomial cases: one or two types

Define \(D(U,V)=\sum_i|C_i(U)-C_i(V)|\). Applying the scalar triangle inequality separately to every task gives

\(D(U,W)\leq D(U,V)+D(V,W).\)

For \(\tau=1\), the preferred schedule has objective zero, so the answer is yes exactly when \(B\geq0\).

For \(\tau=2\), relabel the types so that \(\mu_1\geq\mu_2\). For every schedule \(S\),

\(F(S)=(\mu_1-\mu_2)D(S,V_1)+\mu_2\bigl(D(S,V_1)+D(S,V_2)\bigr)\)

\(\phantom{F(S)}\geq(\mu_1-\mu_2)D(S,V_1)+\mu_2D(V_1,V_2)\geq\mu_2D(V_1,V_2).\)

The schedule \(S=V_1\) attains this lower bound. Therefore the exact optimum is

\(\min_S F(S)=\min\{\mu_1,\mu_2\}D(V_1,V_2).\)

Computing this value and comparing it with \(B\) takes \(O(m\tau L^2)\) bit operations. Thus unequal rational masses preserve polynomial-time solvability for two types, while allowing three types yields NP-completeness.
