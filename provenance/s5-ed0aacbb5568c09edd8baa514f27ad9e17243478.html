The continuous mirror question, as graded

Given a finite support \(T\) of types with rational masses \(\mu_t\) summing to \(1\), eligible schools \(E_t\), utilities \(u_{tj}\), group indicators \(a_{tk}\), per-capita school capacities \(c_j\), and a rational threshold \(q\), decide whether nonnegative assignment masses \(x_{tj}\) exist such that \(x_{tj}=0\) for \(j\notin E_t\), \(\sum_{j\in E_t}x_{tj}=\mu_t\) for every type, \(\sum_t x_{tj}\le c_j\) for every school, and \(\sum_t a_{tk}\sum_{j\in E_t}u_{tj}x_{tj}\ge q\) for every group. Equivalently, maximize the minimum group utility. For a cohort of \(N\) students, Theorem 2’s total-utility threshold \(1\) corresponds to normalized threshold \(q=1/N\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of its \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) schools and \(g\ge1\) demographic groups, with \(g\) part of the input. Each type specifies eligible schools \(E_t\subseteq\{1,\ldots,m\}\), nonnegative rational cardinal utilities \(u_{tj}\) for eligible schools, and membership indicators \(a_{tk}\in\{0,1\}\); groups may overlap.
The input also gives nonnegative rational per-capita capacities \(c_j\) and a rational threshold \(q\). Let \(L\) be the total binary encoding length of the input.
Assignment masses may split a type among schools. Feasibility means \(x_{tj}\in\mathbb R_{\ge0}\), \(x_{tj}=0\) for \(j\notin E_t\), \(\sum_{j\in E_t}x_{tj}=\mu_t\) for every type, and \(\sum_t x_{tj}\le c_j\) for every school.
Group utility is \(U_k(x)=\sum_t a_{tk}\sum_{j\in E_t}u_{tj}x_{tj}\), without division by the group's mass. The decision problem asks whether a feasible assignment satisfies \(U_k(x)\ge q\) for every group.
For an equally weighted cohort of \(N\) students, capacities normalize as \(c_j=C_j/N\), and total group-utility threshold \(1\) normalizes as \(q=1/N\).

Is this continuous decision problem in \(\mathrm P\), with running time polynomial in \(m,\tau,g,L\), or is it \(\mathrm{NP}\)-hard?

The discrete problem is \(\mathrm{NP}\)-complete even with two schools and total group-utility threshold \(1\), when \(g\) is part of the input. Polynomial-time solution of an individual-student fractional relaxation is also established; this is a nearest known result for the mass formulation. [Source](https://drops.dagstuhl.de/storage/00lipics/lipics-vol329-forc2025/LIPIcs.FORC.2025.20/LIPIcs.FORC.2025.20.pdf).

Conclusion

The continuous decision problem is in \(\mathrm P\), with running time polynomial in \(m,\tau,g,L\). The proof uses a rational linear program written directly over the listed support types, without expanding their masses into individual students.

1. Exact linear programming formulation

Let \(D=\{(t,j):t\in T,\ j\in E_t\}\) and \(n=|D|\). Then \(n\le \tau m\).

If some type has \(E_t=\varnothing\), reject: its positive mass cannot be assigned. Otherwise, introduce one real variable \(x_{tj}\) for each \((t,j)\in D\), and consider the following linear feasibility system:

  • Nonnegativity: \(x_{tj}\ge 0\) for every \((t,j)\in D\).
  • Type masses: \(\sum_{j\in E_t}x_{tj}=\mu_t\) for every \(t\in T\).
  • School capacities: \(\sum_{t:j\in E_t}x_{tj}\le c_j\) for every school \(j\).
  • Group thresholds: \(\sum_{t\in T}\sum_{j\in E_t}a_{tk}u_{tj}x_{tj}\ge q\) for every group \(k\).

Equivalence. Any assignment satisfying the decision problem supplies variables satisfying this system. Conversely, any solution of this system becomes an assignment by setting \(x_{tj}=0\) for ineligible pairs. Its type masses, capacities, and group utilities satisfy exactly the required conditions. Thus the system is feasible if and only if the answer is yes.

Overlapping groups cause no additional difficulty: each group contributes one linear inequality, and the same variable may occur in several such inequalities.

2. Polynomial encoding size and exact decision

Replace each type equality by two inequalities, and reverse the signs of the nonnegativity and group inequalities as needed to obtain \(Ax\le b\). The system has \(n\) variables and

\(r=n+2\tau+m+g\)

inequalities.

Every coefficient belongs to \(\{0,1,-1\}\) or is an input utility with a possible sign change. Indeed, \(a_{tk}u_{tj}\) is either zero or \(u_{tj}\), because \(a_{tk}\in\{0,1\}\). Every right-hand side is zero or an input mass, capacity, or threshold with a possible sign change. Consequently, each entry has binary encoding length \(O(L+1)\).

Even a dense encoding of the resulting system therefore has length

\(B=O\bigl(r(n+1)(L+1)\bigr)\),

which is polynomial in \(m,\tau,g,L\). The system can also be constructed within that polynomial bound.

We now apply the standard rational linear programming theorem: feasibility of an explicitly given system of non-strict linear inequalities with rational coefficients is decidable in deterministic time polynomial in its binary encoding length. This is the polynomial-time solvability theorem originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319).

All hypotheses hold here: the system is explicit, all data are rational, and all inequalities are non-strict. The theorem decides exact feasibility, including when solutions exist only on a boundary; numerical approximation is not being substituted for the threshold test.

Applying the theorem to the constructed system gives a running time polynomial in \(B\), hence polynomial in \(m,\tau,g,L\). Together with the equivalence above, this proves the conclusion.

3. Relation to the individual-student fractional relaxation

For an equally weighted cohort, suppose type \(t\) represents \(n_t=N\mu_t\) students. Let \(p_{ij}\) be the fractional assignment of student \(i\) to school \(j\), with \(\sum_{j\in E_t}p_{ij}=1\) for a student of type \(t\).

Define aggregate assignment masses by

\(x_{tj}=\frac1N\sum_{i:\,\operatorname{type}(i)=t}p_{ij}\).

Summing the individual assignment equations gives \(\sum_jx_{tj}=n_t/N=\mu_t\). School totals and group utility totals are divided by \(N\), so capacities \(C_j\) become \(c_j=C_j/N\), and total group-utility threshold one becomes \(q=1/N\).

Conversely, from a mass assignment define, for every student of type \(t\),

\(p_{ij}=x_{tj}/\mu_t\).

This division is valid because \(\mu_t>0\). Nonnegativity and the type equation imply \(\sum_jp_{ij}=1\). Moreover,

\(\sum_{i:\,\operatorname{type}(i)=t}p_{ij}=n_tx_{tj}/\mu_t=Nx_{tj}\),

so the capacity and utility totals have exactly the required scaling.

Thus the two fractional formulations are equivalent whenever such a cohort representation is given. The direct support formulation also proves polynomial running time without constructing a potentially enormous cohort.

4. Why discrete hardness does not transfer

The cited paper establishes discrete hardness in Theorem 2 and defines its fractional relaxation in Section 2.1. Its discrete variables require each student to choose a single school. [Source](https://drops.dagstuhl.de/storage/00lipics/lipics-vol329-forc2025/LIPIcs.FORC.2025.20/LIPIcs.FORC.2025.20.pdf).

The distinction already matters for two students and two schools. Give each school capacity one. Give each student utility two for the first school and zero for the second, and make each student a separate demographic group with total utility threshold one.

A discrete assignment meeting both thresholds would put both students in the first school, violating its capacity. A fractional assignment placing half of each student in each school satisfies both capacities and gives each group utility one.

Therefore, discrete infeasibility need not imply continuous infeasibility. The continuous problem is polynomial-time solvable; under polynomial-time many-one reductions, it could also be \(\mathrm{NP}\)-hard only if \(\mathrm P=\mathrm{NP}\).
