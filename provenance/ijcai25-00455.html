The continuous mirror question, as graded

Given a finite set of complete types \(T\), rational distribution \(\mu\), finite item classes \(E\), rational per-capita supplies \(\rho_e\), and additive utilities \(u_t(e)\), with a common item ordering and common good-or-chore sign for each item class, find a finite-support distribution \(\lambda_{t,b}\) over whole integer bundles \(b\in\mathbb{Z}_{\ge 0}^{E}\) and subsidy masses \(z_{t,b}\) such that \(\sum_b\lambda_{t,b}=\mu_t\), \(\sum_{t,b}b_e\lambda_{t,b}=\rho_e\), and, writing \(U_t(b)=\sum_e b_eu_t(e)\) and \(p_t=\sum_e\rho_eu_t(e)\), every used cell satisfies \(z_{t,b}\ge\lambda_{t,b}\max\{p_t-U_t(b),0\}\) and the cellwise PROP1 condition: \(U_t(b)\ge p_t\), or \(U_t(b-\mathbf{1}_e)\ge p_t\) for some \(e\) with \(b_e>0\), or \(U_t(b+\mathbf{1}_e)\ge p_t\) for some available item class \(e\). Require average subsidy \(\Sigma=\sum_{t,b}z_{t,b}\le 1/4\), or solve the optimization version minimizing \(\Sigma\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau=|T|\) complete types with positive binary-rational masses \(\mu_t\), with \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Each type specifies its additive utility vector.
There are \(m=|E|\) item classes with nonnegative binary-rational per-capita supplies \(\rho_e\) and binary-rational utilities \(u_t(e)\in[-1,1]\). A common ordering satisfies \(u_t(e_1)\ge\cdots\ge u_t(e_m)\) for every type; each class has either nonnegative utilities for every type or nonpositive utilities for every type. Zero utilities and ties are allowed.
Bundles are whole vectors \(b\in\mathbb Z_{\ge0}^{E}\). Define \(U_t(b)=\sum_e b_eu_t(e)\) and \(p_t=\sum_e\rho_eu_t(e)\); \(\mathbf1_e\) denotes one unit of class \(e\). An available class means \(\rho_e>0\): a single agent has zero population mass, so owning finitely many units does not exhaust that class.
An outcome consists of finitely supported nonnegative rational cell masses \(\lambda_{t,b}\) and subsidy masses \(z_{t,b}\), with \(z_{t,b}=0\) on unused cells, satisfying \(\sum_b\lambda_{t,b}=\mu_t\), \(\sum_{t,b}b_e\lambda_{t,b}=\rho_e\), and \(z_{t,b}\ge\lambda_{t,b}\max\{p_t-U_t(b),0\}\).
Every used cell must satisfy PROP1 without subsidy: \(U_t(b)\ge p_t\), or \(U_t(b-\mathbf1_e)\ge p_t\) for some \(e\) with \(b_e>0\), or \(U_t(b+\mathbf1_e)\ge p_t\) for some available class \(e\).
Is deciding whether such an outcome exists with \(\Sigma=\sum_{t,b}z_{t,b}\le\tfrac14\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and the total input bit length \(L\).
For finite societies with \(n\) agents and objective goods and chores, a polynomial-time algorithm computes a PROP1 allocation made proportional by total subsidy at most \(n/4\) for even \(n\), and \((n^2-1)/(4n)\) for odd \(n\). [Source](https://www.ijcai.org/proceedings/2025/0455.pdf)
No result settling this exact distributional feasibility problem was identified in the literature search.

Modeling choices made when packaging the task

Result

The problem is in \(\mathrm P\). In fact, every input satisfying the stated hypotheses admits an outcome with \(\Sigma\le \tfrac14\).

This settles the full distributional problem, including arbitrary rational supplies and mixtures of goods and chores. The key is to clear the denominators of both the population masses and the supplies, apply the finite-society theorem, and aggregate the resulting allocation.

1. The finite-society theorem

We use the following consequence of [Wu, Xue, and Zhou, Theorem 4.4](https://www.ijcai.org/proceedings/2025/0455.pdf):

For an even number \(n\) of agents and finitely many indivisible items, suppose utilities are additive, every item has utility in \([-1,1]\), and every item is either nonnegative for all agents or nonpositive for all agents. There exists a PROP1 allocation \((X_i)_{i=1}^n\) such that
\( \sum_{i=1}^n \max\{u_i(M)/n-u_i(X_i),0\}\le n/4. \)

Here \(M\) denotes the entire item set. Finite-society PROP1 permits either removing an owned item or adding an item outside the agent’s bundle.

2. Clearing denominators

Let \(D\) be a positive integer divisible by the denominators of every \(\mu_t\) and every \(\rho_e\), and set \(n=2D\). Then \(n\) is even, and
\( n_t=n\mu_t\in\mathbb Z_{>0}, \qquad N_e=n\rho_e\in\mathbb Z_{\ge0}. \)
Moreover, \(\sum_t n_t=n\).

Construct a finite instance consisting of:

  • \(n_t\) agents of type \(t\), for each \(t\in T\);
  • \(N_e\) distinct item copies of class \(e\), for each \(e\in E\).

An agent of type \(t\) values each copy of class \(e\) at \(u_t(e)\).

Every copied item has utility in \([-1,1]\) and has the required common sign across agents. Utilities remain additive. The given common ordering also extends to the copies, by placing the copies of each class consecutively.

Most importantly, the proportional share of an agent of type \(t\) is exactly
\( \frac{u_t(M)}{n} = \frac{\sum_e N_eu_t(e)}{n} = \sum_e\rho_eu_t(e) = p_t. \)

If all supplies vanish, the distributional outcome assigning bundle \(0\) to every type already satisfies all requirements with zero subsidy. Otherwise, apply the finite-society theorem to obtain a PROP1 allocation \((X_i)_{i=1}^n\).

Write \(t(i)\) for agent \(i\)’s type and \(b(i)\) for the vector counting the copies of each class in \(X_i\). Define
\( s_i=\max\{p_{t(i)}-U_{t(i)}(b(i)),0\}. \)
These numbers are rational, and the theorem gives
\( \sum_{i=1}^n s_i\le n/4. \)

3. Aggregating into a distributional outcome

For each type–bundle pair, let
\( r_{t,b} = |\{i:t(i)=t,\ b(i)=b\}|, \qquad \lambda_{t,b}=\frac{r_{t,b}}{n}. \)
Define
\( z_{t,b} = \lambda_{t,b}\max\{p_t-U_t(b),0\}. \)

All these masses are nonnegative and rational. There are at most \(n\) used cells, so the outcome has finite support. Unused cells have zero subsidy mass.

Population and supply constraints

For every type,
\( \sum_b\lambda_{t,b} = \frac{n_t}{n} = \mu_t. \)

Because the finite allocation assigns every item copy exactly once, for every class,
\( \sum_{t,b}b_e\lambda_{t,b} = \frac1n\sum_{i=1}^n b(i)_e = \frac{N_e}{n} = \rho_e. \)

The subsidy inequality holds with equality by the definition of \(z_{t,b}\).

PROP1 on every used cell

Fix a used cell \((t,b)\), and choose a finite agent of type \(t\) receiving bundle vector \(b\). Its finite allocation satisfies one of the following:

  • It already has utility at least its proportional share. Then \(U_t(b)\ge p_t\).
  • Removing an owned copy of class \(e\) achieves its proportional share. Then \(b_e>0\) and \(U_t(b-\mathbf1_e)\ge p_t\).
  • Adding a copy outside its bundle achieves its proportional share. Then \(U_t(b+\mathbf1_e)\ge p_t\). The existence of that copy implies \(N_e>0\), hence \(\rho_e>0\), so class \(e\) is available.

Thus every used cell satisfies precisely the required distributional PROP1 condition.

Total subsidy

Agents in the same type–bundle cell have the same deficit. Consequently,
\( \Sigma = \sum_{t,b}z_{t,b} = \frac1n\sum_{i=1}^n s_i \le \frac14. \)

This proves feasibility for every valid input.

4. Running time

Under the stated input promises, the decision algorithm simply returns YES.

Its running time is \(\mathrm O(1)\) if reading the input is unnecessary, or \(\mathrm O(L)\) including a complete input scan. In particular, there is no additional dependence on \(m\) or \(\tau\). Checking the numerical promises, if required, takes \(\operatorname{poly}(m,\tau,L)\) bit operations using exact rational arithmetic.

The denominator expansion is an existence proof; the decision algorithm never performs it. Explicitly constructing an outcome by this expansion can take exponential time in \(L\). For example, choosing \(D\) as the product of the input denominators yields \(\log n=\mathrm O(L)\), but \(n\) itself can be exponential. This does not affect the decision bound.

5. The threshold is tight

Consider one type of mass \(1\) and one good class with utility \(1\) and supply \(1/2\). Its proportional share is \(p=1/2\).

For any feasible outcome, write \(\lambda_k\) for the mass receiving \(k\) units. Supply conservation gives
\( \sum_{k\ge0}k\lambda_k=\frac12. \)
Since every positive integer \(k\) is at least \(1\),
\( \sum_{k\ge1}\lambda_k\le\frac12, \qquad \lambda_0\ge\frac12. \)
The zero bundle requires subsidy \(1/2\), so every outcome has
\( \Sigma\ge\frac12\lambda_0\ge\frac14. \)

Equality is attained by assigning masses \(1/2\) to each of bundles \(0\) and \(1\), with subsidy masses \(1/4\) and \(0\), respectively. Both bundles satisfy PROP1: the zero bundle can add one unit of the available good.

Hence \(1/4\) is the sharp universal bound.
