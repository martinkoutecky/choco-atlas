The anchor (named result in the paper)

Theorem 3.6 — class: hardness

The continuous mirror question, as graded

Given two role types \(V=\{a,b\}\) with positive rational masses \(\mu_v\) summing to \(1\), and a multiset of chore classes \(E\) with rational masses \(\lambda_e\geq 0\) and positive symmetric costs \(d_e\), choose assignment masses \(x_{e,v}\geq 0\) for eligible endpoint types, with \(\sum_{v\in e}x_{e,v}=\lambda_e\). For each type \(v\), its average chore burden is \(\mu_v^{-1}\sum_{e\ni v}d_e x_{e,v}\); its burden from type \(w\)'s average bundle is \(\mu_w^{-1}\sum_{e\in E(v,w)}d_e x_{e,w}\). Does a complete assignment exist such that the first burden is at most the second for each ordered pair \(v\ne w\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here \(V=\{a,b\}\), \(\tau=2\), \(\mu_a,\mu_b>0\), and \(\mu_a+\mu_b=1\).
The input also lists \(m\) chore classes \(E\). Each class \(e\) has an eligible endpoint set \(S_e\in\{\{a\},\{b\},\{a,b\}\}\), mass \(\lambda_e\in\mathbb{Q}_{\geq0}\), and cost \(d_e\in\mathbb{Q}_{>0}\). Singleton endpoint sets represent self-loops; parallel classes are allowed. Chore masses need not sum to one.
Costs are additive: each eligible type incurs cost \(d_e\) per unit of class \(e\), and every ineligible type evaluates it at zero. All rational input data are binary encoded; let \(L\) be the total input bit length.
A complete assignment consists of real masses \(x_{e,v}\geq0\), with \(x_{e,v}=0\) for \(v\notin S_e\) and \(\sum_{v\in S_e}x_{e,v}=\lambda_e\) for every class.
Write \(E(v,w)=\{e\in E:S_e=\{v,w\}\}\) for distinct types. The assignment is envy-free between average bundles if, for every ordered pair \(v\ne w\),
\(\displaystyle \frac{1}{\mu_v}\sum_{e:v\in S_e}d_ex_{e,v}\leq\frac{1}{\mu_w}\sum_{e\in E(v,w)}d_ex_{e,w}.\)

Is deciding whether such a complete assignment exists in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it NP-hard?

For indivisible chores, deciding existence of an EF1 or \(\mathrm{EFX}_0\) orientation is NP-complete even with two vertices and additive symmetric utilities, allowing self-loops. [Hsu and King](https://arxiv.org/html/2501.13481v2#S5).
No result settling this exact support-encoded continuous problem was identified in the literature search.

Modeling choices made when packaging the task

  • Specified eligible endpoint sets as either singleton role types or the pair of distinct role types, retaining self-loops and parallel classes from the discrete model.
  • Defined E(v,w) to include exactly classes joining the two distinct types, excluding singleton classes.
  • Specified positive costs as binary rationals, additive at eligible endpoints and zero at ineligible types.
  • Left chore masses unnormalized and allowed real assignment masses, as appropriate for divisible chores.
  • Defined m as the number of listed chore classes and L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is in \(\mathrm{P}\). More precisely, a complete envy-free assignment exists if and only if every singleton class has zero mass. This gives a decision algorithm that simply scans the input.

Necessity

Write \(\ p=\mu_a\) and \(\ q=\mu_b\), so \(\ p,q>0\) and \(\ p+q=1\). Define the total costs of the singleton classes by

\( A=\sum_{e:S_e=\{a\}}d_e\lambda_e, \qquad B=\sum_{e:S_e=\{b\}}d_e\lambda_e. \)

Fix any complete assignment, and let

\( T_a=\sum_{e:S_e=\{a,b\}}d_ex_{e,a}, \qquad T_b=\sum_{e:S_e=\{a,b\}}d_ex_{e,b}. \)

Completeness forces every singleton class to be assigned entirely to its sole eligible type. Consequently, the two required envy inequalities are exactly

\( \frac{A+T_a}{p}\leq\frac{T_b}{q}, \qquad \frac{B+T_b}{q}\leq\frac{T_a}{p}. \)

Multiplying each inequality by the positive number \(\ pq\) gives

\( qA+qT_a\leq pT_b, \qquad pB+pT_b\leq qT_a. \)

Adding and cancelling the shared-class terms yields

\( qA+pB\leq 0. \)

Every summand defining \(\ A\) or \(\ B\) is nonnegative. Since \(\ p,q>0\), the last inequality therefore implies \(\ A=B=0\). Moreover, every \(\ d_e>0\), so these equalities imply \(\lambda_e=0\) for every singleton class. This proves necessity.

Sufficiency and an explicit assignment

Suppose every singleton class has zero mass. For each shared class, assign

\( x_{e,a}=p\lambda_e, \qquad x_{e,b}=q\lambda_e. \)

Set all singleton-class assignment masses to zero. These masses are nonnegative, respect eligibility, and satisfy completeness because \(\ p+q=1\).

Let

\( C=\sum_{e:S_e=\{a,b\}}d_e\lambda_e. \)

Type \(\ a\)'s own average cost and its evaluation of type \(\ b\)'s average bundle are, respectively,

\( \frac{1}{p}\sum_{e:a\in S_e}d_ex_{e,a} =\frac{pC}{p}=C, \qquad \frac{1}{q}\sum_{e\in E(a,b)}d_ex_{e,b} =\frac{qC}{q}=C. \)

For type \(\ b\), the corresponding quantities are also both \(\ C\). Thus both envy inequalities hold with equality. This includes the case \(\ C=0\).

Algorithm and bit complexity

Reject precisely when a listed class has a singleton endpoint set and positive mass; otherwise accept. Under the promised input conditions, this requires only reading endpoint sets and testing whether rational numerators are zero. Its running time is \(\ O(L+m)\), hence polynomial in \(\ m,\tau,L\), with \(\tau=2\).

The displayed assignment is also computable in polynomial time: each nonzero assignment mass is a product of two input rationals, whose numerator and denominator have bit lengths bounded by the sums of the corresponding input bit lengths.

The classification follows directly from the stated continuous envy inequalities; no indivisible-orientation hardness result is needed.

Completeness and eligibility force each singleton class to be assigned entirely to its sole endpoint. Thus \(A\) and \(B\) are precisely the singleton costs assigned to \(a\) and \(b\). The quantities \(T_a\) and \(T_b\) account for all shared-class costs. Substituting these definitions into the task’s two ordered-pair inequalities gives exactly
\[ \frac{A+T_a}{p}\leq\frac{T_b}{q}, \qquad \frac{B+T_b}{q}\leq\frac{T_a}{p}. \]
There are no other ordered pairs to check because the support consists of exactly two types.

  • The necessity calculation is correct.

Since \(p,q>0\), multiplication by \(pq\) preserves both inequality directions. Adding the resulting inequalities cancels both shared-class terms and yields \(qA+pB\leq0\). Nonnegative masses and positive costs imply \(A,B\geq0\); positive coefficients \(p,q\) then force \(A=B=0\). Each is a finite sum of nonnegative terms, so every singleton term \(d_e\lambda_e\) vanishes. The assumption \(d_e>0\) therefore forces every singleton mass to vanish. No cancellation or sign assumption is missing.

For each shared class, \(x_{e,a}=p\lambda_e\) and \(x_{e,b}=q\lambda_e\) are nonnegative and sum to \(\lambda_e\). Singleton masses are zero by hypothesis. With ineligible coordinates fixed to zero as required by the task, this is a complete eligible assignment.

  • Both envy inequalities are verified.

The singleton costs vanish, and the constructed shared costs are \(pC\) and \(qC\). Consequently, each type’s own average cost and its evaluation of the other type’s average bundle equal \(C\). Both inequalities hold with equality. Division is valid because both supported types have strictly positive mass.

Empty collections of shared or singleton classes give empty sums equal to zero. Zero-mass shared classes, parallel classes, and arbitrary total chore mass introduce no additional restrictions. The proof explicitly covers \(C=0\), including an entirely zero-mass instance.

Under the promised valid input conditions, the algorithm only inspects endpoint sets and tests whether singleton masses are positive. For nonnegative rational masses, this is equivalent to checking whether their numerators are nonzero. Reading and scanning the binary encoding takes \(O(L+m)\) time. The optional explicit assignment also has polynomial output size and is computable by polynomial-time rational multiplication. The classification applies to the stated setting \(\tau=2\); the prover does not claim a characterization for larger supports.
