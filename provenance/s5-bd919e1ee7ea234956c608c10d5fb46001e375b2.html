The continuous mirror question, as graded

Given rational class masses \(\mu_1,\mu_2>0\) with \(\mu_1+\mu_2=1\), and a finite rational antichain \(\mathcal{B}\) of shift-minimal winning profiles in \([0,\mu_1]\times[0,\mu_2]\), declare \(x\) winning when \(x_1\ge b_1\) and \(x_1+x_2\ge b_1+b_2\) for some \(b\in\mathcal{B}\). Is this rule representable by weights \(w_1>w_2\ge0\) and quota \(q>0\) exactly when there are no \(b^1,b^2\in\mathcal{B}\) and losing profiles \(y^1,y^2\) with \(b^1+b^2=y^1+y^2\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here \(m=\tau=2\), with \(\mu_1,\mu_2>0\) and \(\mu_1+\mu_2=1\).
Coalition profiles range over the real rectangle \(D=[0,\mu_1]\times[0,\mu_2]\). Define \(x\succeq b\) by \(x_1\ge b_1\) and \(x_1+x_2\ge b_1+b_2\).
The input includes a nonempty finite set \(\mathcal B\subseteq D\setminus\{(0,0)\}\) of rational profiles, pairwise incomparable under \(\succeq\), with some \(b\in\mathcal B\) satisfying \(b_1>0\) and \(b_2<\mu_2\). A profile is winning precisely when it dominates some member of \(\mathcal B\); otherwise it is losing.
Weighted representability means that real numbers \(w_1>w_2\ge0\) and \(q>0\) satisfy, for every \(x\in D\), that \(x\) is winning if and only if \(w_1x_1+w_2x_2\ge q\). A forbidden trade consists of \(b^1,b^2\in\mathcal B\) and losing \(y^1,y^2\in D\) with \(b^1+b^2=y^1+y^2\); repetitions are allowed and equality is componentwise.
Write running times in \(m,\tau,r=|\mathcal B|\), and the total input bit length \(L\).

Is deciding weighted representability for these inputs in \(\mathrm P\) or \(\mathrm{NP}\)-hard? Does weighted representability hold exactly when no forbidden trade exists, or is there a counterexample?

For finite complete simple games with exactly two voter equivalence classes, weightedness is equivalent to the absence of such trades with shift-minimal winning integer profiles ([Freixas, Freixas, and Kurz](https://epub.uni-bayreuth.de/2766/1/Characterization_Threshold_Functions.pdf)). No result settling this precise continuous formulation was located in the literature search.

Modeling choices made when packaging the task

  • Profiles, including losing trade profiles, range over the entire real rectangle; only the finite input data must be rational.
  • The antichain uses partial-sum dominance rather than componentwise dominance.
  • Required a nonempty antichain excluding the zero profile, so the grand coalition wins and the empty coalition loses.
  • Required some generator with b_1>0 and b_2<mu_2, carrying over the condition distinguishing the two voter equivalence classes.
  • Weights and quota are real, threshold equality is winning, trade equality is componentwise, and repeated profiles are allowed.
  • Defined m as the number of class coordinates, fixed at two, and L as total input bit length.

Result

For the stated inputs, deciding weighted representability is in \(\mathrm P\). More precisely,

\[ \text{weighted representability} \quad\Longleftrightarrow\quad \mathcal B=\{(a,0)\}\text{ for some }0<a\le\mu_1. \]

The proposed trade characterization is false. In fact,

\[ \text{no forbidden trade exists} \quad\Longleftrightarrow\quad \mathcal B=\{(a,c)\}\text{ with }c=0\text{ or }a=\mu_1. \]

For a singleton, the input assumptions give \(a>0\) and \(0\le c<\mu_2\). Thus the nonweighted instances without a forbidden trade are exactly the singletons \(\mathcal B=\{(\mu_1,c)\}\) with \(0<c<\mu_2\).

Below is a complete proof, including the interior cases.

1. Weighted representability excludes forbidden trades

Suppose \(w_1>w_2\ge0\) and \(q>0\) represent the winning profiles. Write \(w\cdot x=w_1x_1+w_2x_2\).

Every \(b\in\mathcal B\) is winning, so \(w\cdot b\ge q\). Every losing profile \(y\) satisfies \(w\cdot y<q\).

Consequently, a forbidden trade would imply both

\(w\cdot(b^1+b^2)\ge2q\)

and

\(w\cdot(y^1+y^2)<2q\).

These contradict the componentwise equality \(b^1+b^2=y^1+y^2\). Thus a forbidden trade proves nonrepresentability.

2. Every instance with at least two profiles has a forbidden trade

Write each profile as \(b^i=(a_i,c_i)\), and put \(t_i=a_i+c_i\).

Pairwise incomparability implies that distinct profiles have distinct first coordinates: if their first coordinates were equal, the one with the greater total would dominate the other. Sort the profiles so that

\(a_1<a_2<\cdots<a_r\).

Their totals then satisfy

\(t_1>t_2>\cdots>t_r\).

Indeed, if \(a_i<a_j\) and \(t_i\le t_j\), then \(b^j\succeq b^i\), contrary to incomparability.

Assume \(r\ge2\), and choose consecutive profiles \(b^i,b^{i+1}\). The preceding inequalities give

\(c_i-c_{i+1}=(t_i-t_{i+1})+(a_{i+1}-a_i)>0\).

Hence \(c_i>0\) and \(c_{i+1}<\mu_2\). Define the positive rational number

\(\varepsilon=\frac14\min\{a_{i+1}-a_i,\ t_i-t_{i+1},\ c_i,\ \mu_2-c_{i+1}\}\),

and define

\(y^1=(a_{i+1}-\varepsilon,\ c_{i+1}+2\varepsilon)\),

\(y^2=(a_i+\varepsilon,\ c_i-2\varepsilon)\).

We verify all trade requirements.

Membership in the rectangle. Both first coordinates lie strictly between \(a_i\) and \(a_{i+1}\), hence in \([0,\mu_1]\). Furthermore,

\(0\le c_{i+1}+2\varepsilon<\mu_2\),

\(0<c_i-2\varepsilon\le\mu_2\).

Thus \(y^1,y^2\in D\).

Both profiles are losing. Their totals are

\(y^1_1+y^1_2=t_{i+1}+\varepsilon<t_i\),

\(y^2_1+y^2_2=t_i-\varepsilon<t_i\).

For every \(k\le i\), the inequality \(t_k\ge t_i\) shows that neither profile meets the total required to dominate \(b^k\).

For every \(k\ge i+1\), the inequality \(a_k\ge a_{i+1}\) shows that neither profile meets the first coordinate required to dominate \(b^k\).

They therefore dominate no member of \(\mathcal B\), so both are losing.

Conservation. Direct addition gives

\(y^1+y^2=(a_i+a_{i+1},c_i+c_{i+1})=b^i+b^{i+1}\).

This is a forbidden trade. By Section 1, every instance with \(r\ge2\) is nonweighted.

3. Complete analysis of singleton instances

Let \(\mathcal B=\{b\}\), where \(b=(a,c)\). The promised existence condition now gives \(a>0\) and \(c<\mu_2\). A profile is winning exactly when

\(x_1\ge a\quad\text{and}\quad x_1+x_2\ge a+c\).

Case A: \(c=0\)

Since \(x_2\ge0\), the winning condition reduces to \(x_1\ge a\).

The weights and quota

\(w_1=1,\qquad w_2=0,\qquad q=a\)

give an admissible representation. Section 1 also excludes forbidden trades.

Case B: \(c>0\) and \(a<\mu_1\)

Define

\(\varepsilon=\frac14\min\{a,\mu_1-a,c,\mu_2-c\}>0\),

\(y^1=(a-\varepsilon,c+2\varepsilon)\),

\(y^2=(a+\varepsilon,c-2\varepsilon)\).

The choice of \(\varepsilon\) ensures that both profiles belong to \(D\).

The first profile is losing because \(y^1_1<a\). The second is losing because

\(y^2_1+y^2_2=a+c-\varepsilon<a+c\).

Their sum is \(y^1+y^2=2b\). Thus two copies of \(b\) form the winning side of a forbidden trade. Weighted representability is impossible.

Case C: \(c>0\) and \(a=\mu_1\)

In this case the winning set is precisely

\(\{(\mu_1,x_2):c\le x_2\le\mu_2\}\).

There is no forbidden trade. Because \(\mathcal B\) is a singleton, a forbidden trade would require

\(y^1+y^2=2(\mu_1,c)\).

Each first coordinate is at most \(\mu_1\). Their sum being \(2\mu_1\) forces

\(y^1_1=y^2_1=\mu_1\).

At this first coordinate, losingness means \(y^j_2<c\). Hence

\(y^1_2+y^2_2<2c\),

contradicting conservation.

There is no weighted representation. Suppose a representation existed. Choose \(c'\) with \(c<c'<\mu_2\). For every positive integer \(n\), the profile

\(z^n=(\mu_1-\mu_1/(n+1),c')\)

lies in \(D\) and is losing, because its first coordinate is less than \(\mu_1\). Therefore

\(w_1(\mu_1-\mu_1/(n+1))+w_2c'<q\).

Taking the limit gives

\(w_1\mu_1+w_2c'\le q\).

Meanwhile, \(b=(\mu_1,c)\) is winning, so

\(q\le w_1\mu_1+w_2c\).

Combining the inequalities gives \(w_2(c'-c)\le0\). Since \(w_2\ge0\) and \(c'>c\), necessarily \(w_2=0\), and then \(q=w_1\mu_1\).

But \((\mu_1,0)\) now has weighted score exactly \(q\), so the representation declares it winning. It is actually losing because \(c>0\). This contradiction completes the case analysis and proves both classifications.

4. Explicit counterexample

Take

\(\mu_1=\mu_2=\frac12,\qquad \mathcal B=\{(\frac12,\frac14)\}\).

All input requirements hold: the masses are positive binary rationals summing to one; the profile is nonzero and belongs to \(D\); incomparability is vacuous; and \(b_1>0\), \(b_2<\mu_2\).

By Case C, this instance is nonweighted and has no forbidden trade.

The finite equivalence in [Freixas, Freixas, and Kurz, Theorem 4.9](https://epub.uni-bayreuth.de/2766/1/Characterization_Threshold_Functions.pdf) therefore does not extend to the stated continuous formulation. Here, losing profiles approach a winning boundary segment arbitrarily closely, forcing incompatible constraints on any representing weights.

5. Algorithm and running time

On the promised input class, decide weighted representability as follows:

  • If \(r\ge2\), return nonweighted.
  • If \(r=1\), return weighted exactly when the sole profile has second coordinate zero.
  • In the weighted case, output \(w_1=1\), \(w_2=0\), and \(q=b_1\).

For an explicit binary rational encoding, this takes \(O(L+mr+\tau)=O(L)\) bit operations, including reading the input, with \(m=\tau=2\). Testing whether a rational is zero requires only inspecting its numerator. This running-time claim concerns the promised inputs; it does not include validating all promises.

Thus the decision problem is in \(\mathrm P\).
