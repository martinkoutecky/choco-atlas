The continuous mirror question, as graded

Given a finite set of roommate types \(T\), rational masses \(\mu_t\) summing to one, and each type’s strict ranking of at most three acceptable types, choose a stable mass assignment \(x\) maximizing the mass \(p_1(x)\) of residents matched to their first-ranked type. Require \(2x_{tt}+\sum_{u\ne t}x_{tu}=\mu_t\); for mutually acceptable types \(t,u\), require \(d_{t,u}(x)=0\) or \(d_{u,t}(x)=0\), where \(d_{t,u}(x)=\sum_{v:\,u\succ_t v}y_{tv}\), \(y_{tu}=x_{tu}\) for \(t\ne u\), and \(y_{tt}=2x_{tt}\). Equivalently, decide whether a stable assignment exists with \(p_1(x)\ge q\) for a rational threshold \(q\).

Packaged proof task (what the prover saw — nothing else)

A society is an atomless population given by its support \(T\): the list of its \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here the partner-type universe has size \(m=\tau\); \(\tau\) counts supported types, not possible preference lists. Let \(L\) be the total input bit length.
Each type \(t\) strictly ranks an acceptable set \(A_t\subseteq T\) of size at most three, possibly empty. All acceptable types are preferred to being unmatched; residents are indifferent between partners of the same type. A ranked own type means another resident of that type.
An assignment consists of nonnegative real pair masses \(x_{tu}=x_{ut}\) and unmatched masses \(z_t\), with \(x_{tu}=0\) unless \(u\in A_t\) and \(t\in A_u\), and \(2x_{tt}+\sum_{u\ne t}x_{tu}+z_t=\mu_t\).
Set \(y_{tu}=x_{tu}\) for \(t\ne u\), \(y_{tt}=2x_{tt}\), and \(d_{t,u}=z_t+\sum_{v\in A_t:\,u\succ_t v}y_{tv}\). Stability requires \(d_{t,u}=0\) or \(d_{u,t}=0\) for every mutually acceptable pair of types, including \(t=u\).
For each nonempty list let \(f(t)\) be its first type, using the original list even if acceptance is not reciprocal. Define \(p_1(x)=\sum_{t:A_t\ne\varnothing}y_{t,f(t)}\). The input includes a binary-rational threshold \(q\in[0,1]\).

Is deciding whether a stable assignment with \(p_1(x)\ge q\) exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents with strict incomplete lists of length at most three, deciding whether a stable matching has at least a specified number of first choices is NP-complete ([Simola–Manlove](https://arxiv.org/pdf/2110.02555)).
For unit-capacity fractional roommates with strict preferences, maximizing welfare under ordinal stability is NP-hard; this uses a different objective ([Chen–Roy–Sorge](https://www.ijcai.org/proceedings/2021/0013.pdf)). No classification of the exact mass problem stated above was located.

Modeling choices made when packaging the task

  • Restored unmatched residents, which the discrete definition permits but the graded mass-balance equality excluded: introduced unmatched mass z_t and included it in every blocking deficit.
  • Specified nonnegative real assignment variables, symmetry, and zero mass on pairs without mutual acceptability.
  • Interpreted own-type matching as pairing distinct residents of that type, allowed only when the own type is listed; imposed stability for such pairs.
  • Allowed empty acceptable lists and excluded their residents from the first-choice objective; preserved first choices from original lists rather than deleting nonreciprocal entries.
  • Specified an atomless population, indifference within each partner type, and preference for every acceptable type over being unmatched.
  • Restricted the normalized threshold to [0,1], defined L as total input bit length, and identified m with the supported partner-type universe size tau.

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when all acceptance is reciprocal and no type ranks itself.

The proof uses a modification of the cycle gadget in [Simola–Manlove, Theorem 1](https://arxiv.org/pdf/2110.02555). The crucial additional argument establishes what arbitrary real pair masses can do inside the gadget.

1. Construction

We reduce from Vertex Cover on simple graphs of maximum degree at most three, which is \(\mathrm{NP}\)-complete by [Garey–Johnson–Stockmeyer, Theorem 2.6](https://www.acs.uwinnipeg.ca/ychen2/journalpapers/Garey-Johnson-2maxsat.pdf).

Let the source instance be a graph \(G=(V,E)\), with \(V=\{1,\ldots,n\}\), and an integer \(K\) satisfying \(0\le K\le n\). The question is whether some set \(C\subseteq V\), of size at most \(K\), contains an endpoint of every edge.

For each vertex \(i\), create ten supported types
\(v_i^1,\ldots,v_i^8,w_i,b_i\).
Also create one supported type \(o\) with an empty list.

Set
\(h=\lceil\log_2(10n+1)\rceil\)
and \(c=2^{-h}\).
Give each of the ten types associated with each vertex mass \(c\), and give \(o\) mass \(1-10nc\). These are positive dyadic rational masses summing to one: indeed, \(2^h\ge 10n+1\) implies \(1-10nc\ge c>0\).

Indices on the eight cycle types are interpreted cyclically. Thus the successor of \(v_i^8\) is \(v_i^1\), and the predecessor of \(v_i^1\) is \(v_i^8\).

Injectively assign the edges incident with vertex \(i\) to its three ports \(v_i^1,v_i^3,v_i^5\). For each graph edge \(\{i,j\}\), connect its assigned port at \(i\) to its assigned port at \(j\). Denote a port’s resulting external partner by \(u_i^r\), when it exists.

Specify the strict preference lists as follows, from best to worst:

| Type | Preference list |
|---|---|
| \(v_i^r\), \(r\in\{1,3,5\}\), with an external partner | \(v_i^{r+1}\succ u_i^r\succ v_i^{r-1}\) |
| \(v_i^r\), \(r\in\{1,3,5\}\), without an external partner | \(v_i^{r+1}\succ v_i^{r-1}\) |
| \(v_i^r\), \(r\in\{2,4,6,8\}\) | \(v_i^{r+1}\succ v_i^{r-1}\) |
| \(v_i^7\) | \(w_i\succ v_i^8\succ v_i^6\) |
| \(w_i\) | \(b_i\succ v_i^7\) |
| \(b_i\) | \(w_i\) |
| \(o\) | Empty |

Every listed acceptance is reciprocal. Every list has length at most three, and none contains its own type. Consequently, \(y_{tu}=x_{tu}\) on every allowable pair.

Choose the threshold
\(q=c(6n-K)\).
It lies in \([0,1]\), because \(0\le K\le n\) and \(6nc<1\).

The construction has \(m=\tau=10n+1\) supported types and total encoding length \(O(n\log n)\). In particular, it is a polynomial-time construction.

2. Structure of every stable assignment

Fix an arbitrary stable assignment for the constructed instance. No integrality assumption is made.

Lemma 1: The auxiliary pair is fully matched

For every \(i\), \(x_{w_i b_i}=c\), and \(x_{w_i v_i^7}=0\).

Proof. Since \(w_i\) and \(b_i\) rank one another first, their balance equations give
\(d_{w_i,b_i}=c-x_{w_i b_i}\)
and
\(d_{b_i,w_i}=c-x_{w_i b_i}\).
Stability therefore forces \(x_{w_i b_i}=c\). Nonnegativity and the balance equations then force both unmatched masses, and \(x_{w_i v_i^7}\), to be zero. \(\square\)

Lemma 2: Every cycle type is fully matched, and every external pair has zero mass

Proof. First consider an even-indexed cycle type \(a=v_i^r\), with \(r\in\{2,4,6,8\}\), and its predecessor \(b=v_i^{r-1}\).

Type \(a\) ranks \(b\) last, so \(d_{a,b}=z_a\). Type \(b\) ranks \(a\) first among the partners to which it can receive positive mass. For \(b=v_i^7\), this uses Lemma 1 to exclude positive mass with \(w_i\). Thus its balance equation gives \(d_{b,a}=c-x_{ab}\).

If \(z_a>0\), stability forces \(d_{b,a}=0\), hence \(x_{ab}=c\). But then \(a\)’s balance equation, together with nonnegativity, forces \(z_a=0\), a contradiction. Therefore every even-indexed cycle type has zero unmatched mass.

Write
\(e_{i,r}=x_{v_i^r v_i^{r+1}}\)
for the eight cycle-edge masses.

The even-indexed types have only cycle partners. Summing their four balance equations gives
\(\sum_{r=1}^8 e_{i,r}=4c\):
each cycle edge has exactly one even-indexed endpoint.

Let \(B_i\) be the sum of masses on external pairs incident with the ports of vertex \(i\). Summing the balance equations of the four odd-indexed cycle types, and using Lemma 1, gives
\(4c=\sum_{r=1}^8 e_{i,r}+B_i+\sum_{r\in\{1,3,5,7\}}z_{v_i^r}\).

Substituting the preceding equality yields
\(B_i+\sum_{r\in\{1,3,5,7\}}z_{v_i^r}=0\).
Every summand is nonnegative. Hence all these unmatched masses and all external pair masses vanish. \(\square\)

Lemma 3: Each cycle has one scalar parameter

For every \(i\), there exists \(a_i\in[0,1]\) such that:

  • \(e_{i,r}=ca_i\) for odd \(r\);
  • \(e_{i,r}=c(1-a_i)\) for even \(r\).

Proof. Lemmas 1 and 2 reduce every cycle type’s balance equation to
\(e_{i,r-1}+e_{i,r}=c\).
Set \(a_i=e_{i,1}/c\). Nonnegativity gives \(a_i\in[0,1]\), and successive balance equations give exactly the alternating values stated above. The final equation is consistent because the cycle has even length. \(\square\)

Lemma 4: The parameters force a vertex cover

The set \(C=\{i:a_i=1\}\) is a vertex cover of \(G\).

Proof. Consider any graph edge, represented by an external pair \(\{v_i^r,v_j^s\}\). Both ports rank their external partner between their successor and predecessor.

By Lemma 2, unmatched and external masses are zero. Therefore the only mass strictly worse than the external partner is the predecessor-edge mass. Lemma 3 gives
\(d_{v_i^r,v_j^s}=c(1-a_i)\)
and
\(d_{v_j^s,v_i^r}=c(1-a_j)\).

Stability requires at least one of these quantities to vanish. Since \(c>0\), this means \(a_i=1\) or \(a_j=1\). Hence every graph edge has an endpoint in \(C\). \(\square\)

3. Exact first-choice objective and correctness

For the ten types associated with vertex \(i\), the first-choice contributions are:

  • The three types \(v_i^1,v_i^3,v_i^5\) contribute \(3ca_i\).
  • The four even-indexed cycle types contribute \(4c(1-a_i)\).
  • Type \(v_i^7\) contributes zero, since its first choice is \(w_i\).
  • Types \(w_i,b_i\) contribute \(2c\).

The empty-list type contributes zero. Consequently, every stable assignment satisfies
\(p_1(x)=c\left(6n-\sum_{i=1}^n a_i\right)\).

From a qualifying assignment to a vertex cover

Suppose \(p_1(x)\ge q=c(6n-K)\). The objective identity implies
\(\sum_i a_i\le K\).

Lemma 4 supplies a vertex cover \(C=\{i:a_i=1\}\). Because all parameters are nonnegative,
\(|C|=\sum_{i\in C}a_i\le\sum_i a_i\le K\).
Thus the source instance is a yes-instance.

From a vertex cover to a qualifying assignment

Conversely, let \(C\) be a vertex cover with \(|C|\le K\). Set \(a_i=1\) for \(i\in C\), and \(a_i=0\) otherwise.

Assign cycle-edge masses using Lemma 3’s formulas. Set \(x_{w_i b_i}=c\), set every other non-cycle pair mass to zero, and leave only type \(o\) unmatched. All balance equations hold.

To verify stability, exhaust the possible mutually acceptable pairs:

  • Cycle pairs. Each cycle edge joins a type to its successor. The successor ranks that type as its predecessor, which is last on its list. Since the successor is fully matched, its corresponding \(d\)-value is zero.
  • Auxiliary pairs. The pair \(\{w_i,b_i\}\) is fully matched to mutual first choices. For \(\{w_i,v_i^7\}\), type \(w_i\) is fully matched to its better partner \(b_i\), so \(d_{w_i,v_i^7}=0\).
  • External pairs. The calculation in Lemma 4 applies. Since \(C\) covers every graph edge, at least one endpoint has parameter one, making its \(d\)-value zero.

There are no other mutually acceptable pairs. The assignment is therefore stable, and
\(p_1(x)=c(6n-|C|)\ge c(6n-K)=q\).

This proves a polynomial-time many-one reduction and establishes \(\mathrm{NP}\)-hardness. Fractional parameters do not invalidate the reduction: parameters equal to one already identify a vertex cover, whose size is bounded by their total sum.

4. Membership in \(\mathrm{NP}\)

We must justify a polynomial-size certificate despite allowing arbitrary real masses.

Take any yes-instance and a qualifying stable real assignment. For each mutually acceptable non-self pair, select an endpoint whose \(d\)-value is zero. For each acceptable self-pair, select its necessarily zero \(d_{t,t}\).

Consider the system consisting of:

  • nonnegativity and the balance equations;
  • those selected linear equalities \(d_{t,u}=0\);
  • the linear inequality \(p_1(x)\ge q\).

Use one variable per allowable unordered pair and one unmatched variable per type. There are \(N=O(\tau)\) variables because lists have length at most three. The system defines a nonempty bounded rational polytope: the given assignment belongs to it, and the balance equations bound every variable.

For completeness, its vertices have polynomial encoding length. Let \(D\) be the product of the input denominators, including that of \(q\). Then \(\log D=O(L)\). Scaling every mass variable by \(D\) makes all right-hand sides integers of magnitude at most \(D\); all coefficient magnitudes are at most two.

At a vertex, choose \(N\) linearly independent active constraints. Cramer’s rule and Hadamard’s determinant bound give rational coordinates with numerator and denominator bit lengths \(O(L+N\log N)\), including the rescaling by \(D\). Thus the polytope contains a polynomial-size rational assignment.

Every point of this polytope satisfies the selected stability equalities, so this rational assignment is also stable and meets the threshold. Its feasibility, stability, and first-choice value can all be checked using exact rational arithmetic in polynomial time.

Therefore the problem belongs to \(\mathrm{NP}\), and together with the reduction it is \(\mathrm{NP}\)-complete. A polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
