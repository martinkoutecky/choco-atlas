The continuous mirror question, as graded

Given a finite set of bidder types \(T\), rational masses \(\mu_t\), explicit package menus \(\mathcal B_t\subseteq 2^{[m]}\), package values \(v_{t,S}\), and per-capita supplies \(q_j\), compute an allocation \(x_{t,S}\geq 0\) maximizing \(\sum_{t\in T}\sum_{S\in\mathcal B_t}v_{t,S}x_{t,S}\), subject to \(\sum_{S\in\mathcal B_t}x_{t,S}\leq\mu_t\) for each type and \(\sum_{t,S:j\in S}x_{t,S}\leq q_j\) for each resource class. Each unit of assigned mass receives the whole package \(S\).

There are \(m\geq1\) resource classes with binary-rational per-capita supplies \(q_j\geq0\). Receiving nothing has value zero; surplus resources may be discarded.
An allocation assigns disjoint portions of each type to whole packages: \(x_{t,S}\geq0\), \(\sum_{S\in\mathcal B_t}x_{t,S}\leq\mu_t\), and \(\sum_{t\in T}\sum_{S\in\mathcal B_t:j\in S}x_{t,S}\leq q_j\). Mass may be split between packages, but each assigned individual receives one whole package.
Write \(W(x)=\sum_{t\in T}\sum_{S\in\mathcal B_t}v_{t,S}x_{t,S}\), let \(\mathrm{OPT}\) be its maximum over feasible allocations, and set \(C=\min\{1,\sum_{j=1}^m q_j\}\). Can a feasible allocation satisfying \(W(x)\geq\mathrm{OPT}-3C\varepsilon\) be computed in polynomial time in \(m,\tau,B,L\), or is achieving this additive guarantee NP-hard?

Result

The requested allocation is computable in polynomial time. In fact, an exactly optimal allocation is computable in polynomial time in \(m,\tau,B,L\).

The essential hypotheses are that menus are explicitly listed and type masses may be split between packages.

1. An exact linear-programming formulation

Let \(I=\{(t,S):t\in T,\ S\in\mathcal B_t\}\), so \(|I|=B\). Introduce one real variable \(x_{t,S}\) for each member of \(I\). Consider the linear program

\[ \max \sum_{(t,S)\in I}v_{t,S}x_{t,S} \]

subject to

\[ \sum_{S\in\mathcal B_t}x_{t,S}\leq\mu_t \qquad(t\in T), \]

\[ \sum_{\substack{(t,S)\in I\\j\in S}}x_{t,S}\leq q_j \qquad(j\in[m]), \]

and

\[ x_{t,S}\geq0 \qquad((t,S)\in I). \]

These are precisely the feasibility constraints in the question, and the objective is precisely \(W(x)\). Consequently, the linear program’s optimal value equals \(\mathrm{OPT}\).

To verify compatibility with whole-package assignments, fix a type \(t\), order its packages, and represent its mass by the interval \([0,\mu_t)\). Partition an initial portion of this interval into consecutive, disjoint intervals of lengths \(x_{t,S}\). Give every individual in the interval associated with \(S\) the entire package \(S\), and give the remaining individuals nothing. The type constraint ensures these intervals fit. Resource \(j\) is consumed in total mass exactly equal to the left-hand side of its resource constraint.

Thus every feasible vector represents an allowed allocation; no additional integrality constraint is required.

2. Existence and polynomial-time computation

If \(B=0\), the empty allocation is optimal. Assume henceforth that \(B>0\).

The zero vector is feasible because all supplies and masses are nonnegative. Moreover, every feasible coordinate satisfies

\[ 0\leq x_{t,S}\leq\mu_t\leq1. \]

The feasible region is therefore nonempty, closed, and bounded. Since the objective is continuous, it attains a finite maximum.

We use the standard polynomial-time theorem for rational linear programming: given explicitly encoded rational constraints and a rational linear objective, a nonempty feasible region with a finite optimum admits an exact rational optimal solution computable in time polynomial in the program’s binary encoding length. This is the classical polynomial-time solvability result established through the ellipsoid method. [Khachiyan, *A polynomial algorithm in linear programming*](https://www.mathnet.ru/eng/dan42319).

All its hypotheses hold here:

  • There are \(B\) variables and \(\tau+m+B\) inequalities, counting nonnegativity.
  • Every constraint coefficient belongs to \(\{-1,0,1\}\).
  • All right-hand sides and objective coefficients are rational numbers supplied explicitly in the input.
  • Nonemptiness and boundedness were proved above.

Because each menu is explicit, all package-incidence coefficients can be constructed in polynomial time. Even a dense encoding has length bounded by

\[ O\bigl((\tau+m+B)(B+1)+L\bigr). \]

Applying the rational linear-programming theorem therefore returns an exact rational optimal allocation \(x^\star\) in time polynomial in \(m,\tau,B,L\). The theorem also guarantees a polynomial-size binary representation of the output.

The monotonicity assumption on listed package values is compatible with this formulation but is not needed for the algorithm.

3. The additive guarantee

By exact optimality,

\[ W(x^\star)=\mathrm{OPT}. \]

Since \(q_j\geq0\), we have \(C=\min\{1,\sum_jq_j\}\geq0\). Together with \(\varepsilon>0\), this gives

\[ W(x^\star)=\mathrm{OPT}\geq\mathrm{OPT}-3C\varepsilon. \]

This includes \(C=0\). The algorithm need not use \(\varepsilon\); its encoding is already included in \(L\).

4. Why discrete winner-determination hardness does not transfer

Parkes and Ungar’s winner-determination problem assigns bundles to individual agents while respecting XOR bids and preventing any indivisible item from being assigned twice. Their paper reports that problem as NP-hard. [Parkes and Ungar, *Iterative Combinatorial Auctions: Theory and Practice*](https://cdn.aaai.org/AAAI/2000/AAAI00-012.pdf).

Here, arbitrary splitting of each type’s mass is expressly permitted. The linear program above consequently describes the actual allocation problem exactly. Discrete winner-determination hardness therefore does not establish hardness for this continuous model.
