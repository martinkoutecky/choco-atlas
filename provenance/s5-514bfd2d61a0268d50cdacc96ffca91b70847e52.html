The continuous mirror question, as graded

Given \(s\) item classes with rational per-capita supplies \(q_r\), integer values \(v_r\), and a rational distribution \(\mu\) over \(\tau\) types \(D_t\subseteq [s]\), assign each type’s mass to integral bundles \(b\in\mathbb Z_{\ge 0}^s\), subject to \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_r\le q_r\). Can one compute an allocation whose minimum utility among positive-mass bundles is at least \(U^*/(6+\delta)\), in time polynomial in \(\tau\) and the input bit length \(L\), for fixed \(s\), where \(U^*\) is the optimal continuous allocation value?

Packaged proof task (what the prover saw — nothing else)

There are \(m=s\geq1\) item classes, with finite supplies \(q_r\in\mathbb Q_{\geq0}\) per capita and values \(v_r\in\mathbb Z_{\geq0}\), encoded in binary. A society is given by its support: the list of \(\tau\geq1\) distinct types \(D_t\subseteq[s]\) with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
A bundle is \(b\in\mathbb Z_{\geq0}^s\); its utility for type \(t\) is \(u_t(b)=\sum_{r\in D_t}v_rb_r\). Empty desire sets and zero values or supplies are allowed.
An allocation consists of nonnegative real masses \(x_{t,b}\) with finite support satisfying \(\sum_bx_{t,b}=\mu_t\) for every type and \(\sum_{t,b}x_{t,b}b_r\leq q_r\) for every class. Unused supply is allowed. Its value is \(U(x)=\min_{(t,b):x_{t,b}>0}u_t(b)\); let \(U^*=\sup_xU(x)\) over feasible allocations. A computed allocation is represented by a finite list of bundles and binary rational masses.

For every fixed \(s\) and fixed \(\delta\in(0,1)\), can one compute a feasible allocation with \(U(x)\geq U^*/(6+\delta)\) in time polynomial in \(m,\tau,L\), or is achieving this approximation guarantee NP-hard for some fixed \(s,\delta\)?

For finite, explicitly listed players and resources, a polynomial-time \((6+\delta)\)-approximation is known ([Cheng–Mao, 2018](https://arxiv.org/abs/1804.10902)); a later polynomial-time algorithm achieves \((4+\delta)\) ([Cheng–Mao, 2019](https://drops.dagstuhl.de/storage/00lipics/lipics-vol132-icalp2019/LIPIcs.ICALP.2019.38/LIPIcs.ICALP.2019.38.pdf)).
No result settling this precise mass-allocation approximation question was identified in the literature search.

  • Defined additive utility using only classes desired by the type; undesired classes contribute zero.
  • Restricted δ to (0,1), matching the anchor's stated range.

Result

For every fixed \(s\), there is a polynomial-time algorithm producing a feasible rational allocation \(x\) with \(U(x)\geq U^*/2\). Since \(2<6+\delta\), this settles the requested approximation guarantee.

The algorithm works directly with rational masses and does not expand them into explicitly listed players.

1. Bounding bundle coordinates

Define \(V=\sum_{r=1}^s v_rq_r\) and \(B=\lfloor V\rfloor\).

For every feasible allocation \(x\), its masses sum to one. Consequently,

\(U(x)\leq\sum_{t,b}x_{t,b}u_t(b)\leq\sum_{r=1}^s v_r\sum_{t,b}x_{t,b}b_r\leq V.\)

The first inequality holds because every occupied bundle has utility at least \(U(x)\); the second holds because undesired items contribute zero utility and all values are nonnegative.

Each \(U(x)\) is a nonnegative integer: bundles and values are integral, and the allocation has finite support. The allocation assigning the zero bundle to every type is feasible. Thus the set of attainable values is a nonempty subset of \(\{0,\ldots,B\}\). It has a maximum, so \(U^*\) is attained.

If \(B=0\), outputting the zero bundle with mass \(\mu_t\) for every type is optimal. Henceforth suppose \(B\geq1\).

Bounded-bundle lemma. There is an optimal allocation using only bundles in \(\{0,\ldots,B\}^s\).

To prove this, take an optimal allocation and replace every occupied bundle \(b\) of type \(t\) by \(c\), where

\(c_r=\min\{b_r,B\}\) if \(r\in D_t\) and \(v_r>0\), and \(c_r=0\) otherwise.

This transformation decreases every resource consumption. If no contributing coordinate was truncated, utility is unchanged. Otherwise, some contributing coordinate becomes \(B\); because its positive integer value is at least one, \(u_t(c)\geq B\geq U^*\). Thus every transformed occupied bundle still has utility at least \(U^*\). Combining masses when bundles coincide preserves feasibility and finite support. This proves the lemma.

2. A polynomial-size family of rounded bundles

Let

\(G=\{0\}\cup\{2^j:0\leq j\leq\lfloor\log_2 B\rfloor\}\), and let \(\mathcal C=G^s\).

For an integer \(a\in\{0,\ldots,B\}\), define \(R(0)=0\); when \(a>0\), let \(R(a)\) be the largest power of two not exceeding \(a\). Then

\(a/2\leq R(a)\leq a.\)

Indeed, for positive \(a\), the next power of two exceeds \(a\), giving \(a<2R(a)\).

Apply \(R\) coordinatewise to each bundle in the bounded optimal allocation. For every type \(t\),

\(u_t(R(b))=\sum_{r\in D_t}v_rR(b_r)\geq\frac12\sum_{r\in D_t}v_rb_r=\frac12u_t(b).\)

Resource consumption decreases coordinatewise. Therefore there exists a feasible allocation supported on \(\mathcal C\) whose value is at least \(U^*/2\).

This allocation initially has real masses, which suffice to establish feasibility of the rational linear programs used next.

3. Computing rational masses

Enumerate the finite set of candidate utility thresholds

\(H=\{u_t(c):t\in[\tau],\ c\in\mathcal C\}.\)

For each \(h\in H\), consider the following rational linear feasibility problem. Introduce a variable \(z_{t,c}\) only for pairs satisfying \(u_t(c)\geq h\), and impose:

  • \(z_{t,c}\geq0\) for every introduced variable;
  • \(\sum_{c\in\mathcal C:\,u_t(c)\geq h}z_{t,c}=\mu_t\) for every type \(t\);
  • \(\sum_{t,c:\,u_t(c)\geq h}c_rz_{t,c}\leq q_r\) for every class \(r\).

Call this system \(P(h)\). Its feasible points are exactly the allocations supported on \(\mathcal C\) whose occupied bundles all have utility at least \(h\).

We use the standard polynomial-time theorem for rational linear programming: a finite linear system with binary rational coefficients can be tested for feasibility in time polynomial in its encoding length, and, when feasible, a rational feasible point of polynomial encoding length can be returned. The theorem applies here because all bundle coordinates and utilities are integers, and all supplies and type masses are input rationals. Feasible variables also satisfy \(z_{t,c}\leq\mu_t\), so these feasible regions are bounded.

Feasibility is monotone in the threshold: if \(h'\leq h\) and \(P(h)\) is feasible, then the same allocation makes \(P(h')\) feasible. Sort \(H\) and use binary search to find its largest feasible threshold \(h_{\max}\). Threshold zero is feasible, using the zero bundle for every type.

Return a rational feasible point of \(P(h_{\max})\), listing only its positive variables.

To verify the approximation, let \(y\) be the rounded allocation from Section 2. Its minimum occupied utility is some \(h_y\in H\), and \(h_y\geq U^*/2\). Thus \(P(h_y)\) is feasible, and maximality gives \(h_{\max}\geq h_y\). Every occupied bundle in the returned allocation has utility at least \(h_{\max}\). Hence

\(U(x)\geq h_{\max}\geq h_y\geq U^*/2\geq U^*/(6+\delta).\)

The type equalities and supply inequalities establish feasibility exactly.

4. Bit complexity and degenerate cases

The bound \(B\) is computed by exact rational arithmetic in polynomial time. Its binary length is polynomial in the input length; more explicitly, every input value and rational numerator is less than \(2^L\), so \(V<s\,2^{2L}\). Thus \(\log_2(B+1)=O(L+\log s)\).

It follows that

\(|\mathcal C|=|G|^s=O((L+\log s+1)^s).\)

For fixed \(s=m\), this is polynomial in the input parameters. There are at most \(\tau|\mathcal C|\) candidate thresholds and variables. Bundle coordinates have polynomial bit length, as do utilities, since \(u_t(c)\leq B\sum_{r=1}^s v_r\). Consequently, each linear program has polynomial encoding length, and the entire algorithm runs in polynomial time in \(m,\tau,L\) for fixed \(s\).

The output contains at most \(\tau|\mathcal C|\) bundles with polynomial-length binary rational masses, so it has the required representation.

Empty desire sets, zero values, and zero supplies require no additional assumptions. In particular, if any positive-mass type has identically zero utility, every positive threshold is infeasible, and the algorithm correctly returns value zero.
