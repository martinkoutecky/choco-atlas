Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a finite set of \(m\geq 1\) alternatives with distinguished status quo \(r\in A\), and let \(\delta\in[0,\tfrac12]\) be a binary rational. The input includes a fixed ordering of \(A\setminus\{r\}\).
A society is given by its support: the list of its \(\tau\) distinct strict complete rankings, each with positive binary-rational mass; masses sum to \(1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For distinct alternatives, define \(p(a,b)=\sum_{i:a\succ_i b}\mu_i\). Alternative \(a\) beats \(b\) by a \(\delta\)-supermajority exactly when \(p(a,b)>\tfrac12+\delta\); equality does not suffice. Define the viable set \(B=\{a\in A\setminus\{r\}:p(a,r)>\tfrac12+\delta\}\).
The conservative supermajority amendment procedure returns \(r\) if \(B\) is empty. Otherwise start with incumbent \(r\) and process \(B\) in the input ordering, replacing the incumbent by the challenger exactly when the challenger beats it by a \(\delta\)-supermajority; otherwise retain the incumbent.
Let \(w\) be the final incumbent. Return \(w\) exactly when it beats every member of \(B\setminus\{w\}\) by a \(\delta\)-supermajority, using recorded comparisons and testing any remaining pairs; otherwise return \(r\). An inconclusive comparison provides no certified victory to either side.

Is computing the outcome of this procedure polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?

For finite electorates, an efficient amendment procedure is given and proved to satisfy the conservative supermajority Condorcet criterion: elect the supermajority Condorcet winner among viable alternatives if one exists, and otherwise retain reality. [Primary source](https://www.ijcai.org/proceedings/2019/0081.pdf).
Neither that source nor its [full preprint](https://weizmann.elsevierpure.com/ws/files/112742980/1807.11105v5.pdf) states a complexity result for the binary-rational support representation specified here.

Result

Computing the outcome is polynomial-time solvable in \(m,\tau,L\). A conservative bound is \(O(L^3+m\tau L^2)\) bit operations. The algorithm uses only \(O(m)\) pairwise supermajority tests, each evaluated exactly from the listed support.

The cited paper gives the amendment procedure and its Condorcet guarantee in Algorithm 1 and Theorem 3. The proof below establishes the complexity bound for the representation in this question, using its strict threshold and explicit treatment of inconclusive comparisons. [Primary source](https://www.ijcai.org/proceedings/2019/0081.pdf).

1. Exact supermajority tests

Write the input masses as \(\mu_i=u_i/v_i\), for \(1\leq i\leq\tau\), and write \(\delta=d/e\), where all denominators are positive integers encoded in binary. Reduced fractions are unnecessary.

Define the integers
\(D=2e\prod_{i=1}^{\tau}v_i\),
\(W_i=u_i(D/v_i)\), and
\(H=(e+2d)(D/(2e))\).

Every indicated division is exact. Furthermore,
\(W_i=D\mu_i\) and \(H=D(\tfrac12+\delta)\).

For each ranking, store \(\operatorname{pos}_i(a)\), the position of alternative \(a\), with smaller positions indicating greater preference. For distinct alternatives define
\(S(a,b)=\sum_{i:\operatorname{pos}_i(a)<\operatorname{pos}_i(b)}W_i\).

Then \(S(a,b)=Dp(a,b)\). Since \(D>0\), the required test is exactly
\(p(a,b)>\tfrac12+\delta\ \Longleftrightarrow\ S(a,b)>H\).

In particular, equality fails the test. No numerical approximation is involved.

Bit lengths. The binary length of \(D\) is at most
\(2+\operatorname{bits}(e)+\sum_i\operatorname{bits}(v_i)=O(L)\).
Since the masses are positive and sum to \(1\), we have
\(\sum_iW_i=D\). Thus every partial sum used to compute \(S(a,b)\) lies between \(0\) and \(D\). Also \(0\leq H\leq D\), because \(0\leq\delta\leq\tfrac12\). Consequently all these integers have \(O(L)\) bits.

Using schoolbook integer arithmetic, preprocessing \(D\), the weights, and \(H\) costs \(O((\tau+1)L^2)\) bit operations. Given the position tables, one pairwise test requires scanning \(\tau\) rankings and adding selected \(O(L)\)-bit weights, costing \(O(\tau L)\) arithmetic bit operations.

2. Algorithm and correctness

Execute the following steps.

  • Test every alternative other than \(r\) against \(r\), thereby constructing \(B\) in the supplied ordering. If \(B\) is empty, return \(r\).
  • Initialize the incumbent to \(r\). Process \(B\) in order, replacing the incumbent precisely when \(S(\text{challenger},\text{incumbent})>H\). Let \(w\) be the final incumbent.
  • For every \(b\in B\setminus\{w\}\), verify \(S(w,b)>H\). Reuse recorded comparisons when available, and evaluate any remaining pairs. Return \(w\) if all these tests pass; otherwise return \(r\).

The equivalence proved in Section 1 shows that every test has exactly the outcome specified in the question. Induction over the ordered challengers therefore shows that Step 2 produces exactly the prescribed incumbent. Step 3 implements exactly the prescribed certification condition.

For a recorded comparison, a failed test in one direction does not certify victory in the reverse direction. One may instead record the exact sum: strict complete rankings imply \(S(b,a)=D-S(a,b)\), so either direction can subsequently be tested exactly.

If \(B\neq\varnothing\), its first challenger defeats \(r\) by the definition of viability. All subsequent incumbents belong to \(B\), so the final \(w\) belongs to \(B\).

3. Verification of the Condorcet property

For distinct \(a,b\), strict complete rankings and normalized masses imply \(p(a,b)+p(b,a)=1\). Because \(\delta\geq0\), both directions cannot satisfy the supermajority threshold: that would imply
\(1=p(a,b)+p(b,a)>1+2\delta\), a contradiction.

Suppose \(c\in B\) beats every member of \(B\setminus\{c\}\) by a \(\delta\)-supermajority. When \(c\) is processed, the incumbent is either \(r\) or an earlier member of \(B\). In the former case, \(c\) defeats it by viability; in the latter, by the assumed property of \(c\). Thus \(c\) becomes incumbent.

Every later challenger loses its supermajority test against \(c\), by the impossibility of victories in both directions. Hence \(c\) remains the final incumbent and passes every certification test.

Conversely, if no such \(c\) exists, the final incumbent \(w\in B\) fails at least one certification test, so the procedure returns \(r\). This also proves uniqueness whenever such a winner exists.

4. Running time and boundary cases

Let \(k=|B|\). Viability requires \(m-1\) pairwise tests, the amendment stage at most \(k\), and certification at most \(k-1\). Thus there are fewer than \(3m\) tests altogether. Their total arithmetic cost is \(O(m\tau L)\).

Building position tables and managing indices also takes polynomial time. With schoolbook arithmetic and a conservative allowance for input parsing and table access, the entire algorithm runs in \(O(L^3+m\tau L^2)\) bit operations. Here \(\tau\leq L\), since every support entry is explicitly listed. The algorithm neither enumerates unlisted rankings nor expands masses into individual voters.

When \(m=1\), the viable set is empty and the outcome is \(r\). When \(\delta=\tfrac12\), the threshold is \(1\), so no alternative is viable and the outcome is again \(r\). The proof covers all intermediate thresholds, including equality cases and inconclusive comparisons.

Therefore the outcome function belongs to \(\mathrm{FP}\); the associated decision problem of whether a specified alternative is returned belongs to \(\mathrm{P}\).
