The continuous mirror question, as graded

Given a finite alternative set \(X\) and a rational distribution \(\mu\) over complete ranking types \(r\in X!\), represented by its nonzero support, return all \(x\in X\) maximizing \(B_\mu(x)=\sum_r\mu_r|\{y\in X:x\succ_r y\}|\); equivalently, return the \(Winner\)-feasible judgments maximizing expected agreement under \(\mathrm{max\text{-}sum}\).

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a nonempty finite alternative set, with \(m=|X|\); types are strict complete rankings \(r\in X!\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_r\) a binary rational, with \(\sum_r\mu_r=1\). Here \(\tau\) is the support size, not \(m!\); let \(L\) be the total input bit length. State running times in \(m,\tau,L\).
Return every alternative maximizing \(B_\mu(x)=\sum_r\mu_r|\{y\in X:x\succ_r y\}|\), retaining all ties.
For the judgment formulation, the agenda is \(\Phi=\{p_{a\succeq b}:a,b\in X\}\), including diagonal items. The ranking judgment satisfies \(J_r(p_{a\succeq b})=1\) exactly when \(a=b\) or \(a\succ_r b\).
The \(\mathrm{Winner}\)-feasible judgments are exactly \(\{J_x:x\in X\}\), where \(J_x(p_{a\succeq b})=1\) exactly when \(a=x\) or \(b\ne x\): one alternative is strictly above all others, which are mutually indifferent.
The mass version of \(\mathrm{max\text{-}sum}\) returns all feasible judgments maximizing \(\sum_r\mu_r|\{p\in\Phi:J(p)=J_r(p)\}|\); return their top alternatives.

Can this winner determination problem be solved in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite profiles of strict rankings, \(\mathrm{max\text{-}sum}\) with \(\mathrm{Winner}\) feasibility selects exactly the Borda winners; discrete Borda winner determination is polynomial-time computable. [Verified source](https://www.ifaamas.org/Proceedings/aamas2018/pdfs/p946.pdf)
No separate result for the precise binary-rational mass formulation was verified.

Modeling choices made when packaging the task

  • Require a nonempty alternative set so winner determination has a nonempty output; allow a singleton because no lower bound of two is imposed.
  • Interpret complete ranking types as strict complete rankings, and distribution as positive support masses summing to one.
  • Use the intended ranking semantics with true diagonal items; the displayed antisymmetry constraint must exclude equal alternatives, as its literal unrestricted form contradicts the examples and makes Ranking unsatisfiable.
  • Retain every tied winner and define L as the total input bit length.
  • Do not impose an analogue of an odd number of voters: arbitrary rational distributions are allowed, and this objective uses no majority tie convention.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Both formulations are polynomial-time solvable in \(m,\tau,L\), with all ties retained. A sufficient bound, using elementary exact integer arithmetic, is
\[ O\!\left(L+m\tau\bigl(L+\log(m+1)\bigr)^2\right). \]

The proof below applies directly to binary-rational masses; it does not require expanding them into a finite electorate.

1. Agreement maximization equals weighted Borda maximization

Write \(s_r(x)=|\{y\in X:x\succ_r y\}|\), and define the agreement score
\[ A_\mu(x)=\sum_r\mu_r|\{p\in\Phi:J_x(p)=J_r(p)\}|. \]

Fix \(x\in X\) and a supported ranking \(r\). Partition the agenda as follows.

  • Diagonal items. Both judgments assign value \(1\) to every \(p_{a\succeq a}\), giving \(m\) agreements.
  • Comparisons between distinct alternatives other than \(x\). For each unordered pair \(\{a,b\}\subseteq X\setminus\{x\}\), the judgment \(J_x\) assigns value \(1\) to both orientations. Strictness of \(r\) means that \(J_r\) assigns value \(1\) to exactly one orientation. Thus each such pair contributes exactly one agreement, giving \((m-1)(m-2)/2\) agreements.
  • Comparisons involving \(x\). For each \(y\ne x\), the values of \(J_x\) on \((p_{x\succeq y},p_{y\succeq x})\) are \((1,0)\). The ranking judgment agrees on both items if \(x\succ_r y\), and on neither otherwise. These pairs therefore contribute \(2s_r(x)\) agreements.

Consequently,
\[ |\{p\in\Phi:J_x(p)=J_r(p)\}| =m+\frac{(m-1)(m-2)}2+2s_r(x). \]

Using \(\sum_r\mu_r=1\), we obtain
\[ A_\mu(x)=m+\frac{(m-1)(m-2)}2+2B_\mu(x). \]

The first two terms are independent of \(x\), and the coefficient of \(B_\mu(x)\) is positive. Hence the maximizing alternatives, including every tie, coincide exactly.

This extends the finite-profile equivalence established in Theorem 3 of [Endriss’s paper](https://www.ifaamas.org/Proceedings/aamas2018/pdfs/p946.pdf). Here the identity has been proved directly for the mass formulation. For \(m=1\), it also holds: the Borda score is zero and the unique alternative is returned.

2. Exact algorithm

Represent each input mass as \(\mu_r=p_r/q_r\), where \(p_r,q_r\) are positive integers written in binary. Reduced fractions are unnecessary. Set
\[ D=\prod_{r\in\operatorname{supp}(\mu)}q_r, \qquad w_r=p_r(D/q_r). \]

Every division is exact, and \(w_r=D\mu_r\). In particular,
\[ \sum_r w_r=D. \]

Initialize an integer score \(T_x=0\) for each alternative. For every supported ranking, written from best to worst as
\[ r=(x_{r,1},\ldots,x_{r,m}), \]
perform the updates
\[ T_{x_{r,j}}\leftarrow T_{x_{r,j}}+(m-j)w_r \qquad\text{for every }j\in\{1,\ldots,m\}. \]

An alternative in position \(j\) has exactly \(m-j\) alternatives below it. Therefore the resulting scores satisfy
\[ T_x=\sum_r w_rs_r(x)=D B_\mu(x). \]

Since \(D>0\), returning every alternative whose integer score equals \(\max_{y\in X}T_y\) returns precisely all required winners. Integer equality retains ties exactly.

3. Bit complexity

The total binary encoding length of the denominators is at most \(L\). Therefore
\[ \log_2 D=\sum_r\log_2 q_r\le L, \]
so \(D\) has at most \(L+1\) bits.

Positivity and normalization imply \(\mu_r\le1\), hence \(w_r\le D\). Moreover, every completed or partial score satisfies
\[ 0\le T_x\le(m-1)\sum_r w_r=(m-1)D. \]

Thus all integers used in the algorithm have
\[ O\!\left(L+\log(m+1)\right) \]
bits. This includes intermediate denominator products and individual score contributions.

Constructing \(D\) and the weights requires \(O(\tau)\) integer arithmetic operations. Processing the rankings requires \(O(m\tau)\) operations, and finding all maxima requires \(O(m)\) comparisons. Elementary multiplication and division on integers of this bit length each cost
\[ O\!\left(\bigl(L+\log(m+1)\bigr)^2\right) \]
bit operations; addition and comparison cost no more. Including input processing gives the stated bound
\[ O\!\left(L+m\tau\bigl(L+\log(m+1)\bigr)^2\right), \]
because \(m,\tau\ge1\).

The numerical value of \(D\) may be exponentially large, but its binary representation has polynomial length. The algorithm processes only the explicitly listed \(\tau\) rankings and never enumerates all \(m!\) types.
