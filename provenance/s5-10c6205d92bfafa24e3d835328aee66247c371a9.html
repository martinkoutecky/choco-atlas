The anchor (named result in the paper)

Lemma 8 — class: hardness

The continuous mirror question, as graded

Given a finite candidate set \(C\) with \(d\)-attribute vectors, committee size \(k\), a finite support \(T\) of complete attribute-approval ballots with rational masses \(\mu_t\) summing to \(1\), and a rational threshold \(q\), decide whether there is a committee \(W\subseteq C\) of size \(k\) with \(\operatorname{AV}_{\mu}(W)\ge q\) that satisfies mass-SJR. Mass-SJR requires that for every subpopulation \(\nu\) with \(0\le \nu_t\le\mu_t\) and \(\sum_t\nu_t\ge 1/k\), if all types with \(\nu_t>0\) approve a common attribute value in some dimension, then the union of those types’ approved attribute values intersects \(\{c[j]:c\in W,\ j\in[d]\}\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be an explicitly listed set of \(m\) candidates, each with a vector \((c[1],\ldots,c[d])\). Attribute values are tagged by dimension; let \(D^j=\{c[j]:c\in C\}\). Assume \(1\le k\le m\), and either \(d\ge2,k\ge2\) or \(d=1,k\ge3\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Each type specifies an approval set \(A_t^j\subseteq D^j\) for every dimension; empty approval sets are allowed. Here \(\tau\) is the support size, not the number of possible ballots. Let \(L\) be the total input bit length; state running times in \(m,\tau,L,d,k\).
For a committee \(W\subseteq C\) of size \(k\), put \(W^j=\{c[j]:c\in W\}\) and \(\operatorname{AV}_{\mu}(W)=\frac1d\sum_{t}\mu_t\sum_{c\in W}\sum_{j=1}^{d}\mathbf{1}_{\{c[j]\in A_t^j\}}\); repeated attribute values contribute once per selected candidate.
The committee satisfies mass-SJR if, for every real vector \(\nu\) with \(0\le\nu_t\le\mu_t\) and \(\sum_t\nu_t\ge1/k\), writing \(S=\{t:\nu_t>0\}\), the condition \(\exists j:\bigcap_{t\in S}A_t^j\ne\varnothing\) implies \(\exists j':(\bigcup_{t\in S}A_t^{j'})\cap W^{j'}\ne\varnothing\).

Given these data and a binary rational threshold \(q\), is deciding whether some size-\(k\) committee satisfies mass-SJR and \(\operatorname{AV}_{\mu}(W)\ge q\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite electorates, the corresponding SJR-constrained AV threshold problem is \(\mathrm{NP}\)-complete in the stated parameter regimes. [Kagita et al. (2021)](https://www.ifaamas.org/Proceedings/aamas2021/pdfs/p683.pdf)
No result for this exact mass formulation was identified in the literature search.

1. Result and interpretation

The decision problem is \(\mathrm{NP}\)-complete when \(k\) is part of the input. This holds already for \(d=1\), and for every fixed \(d\ge2\).

For every fixed \(k\), however, the problem is polynomial-time solvable by enumerating committees. Thus the parameter regimes in the question describe families with variable \(k\), rather than hardness for each fixed committee size.

We use the stated finite-electorate hardness theorem, specifically its \(d=1,\ k\ge3\) case. The contribution below is an exact reduction to the mass formulation, together with a polynomial-time verifier.

2. A finite characterization of mass-SJR

Fix a committee \(W\). Define its unrepresented types by

\[ U(W)=\{t:A_t^j\cap W^j=\varnothing\text{ for every }j\}. \]

For each tagged attribute \(a\in D^j\), define its unrepresented approving mass by

\[ r_{j,a}(W)=\sum_{\substack{t\in U(W)\\a\in A_t^j}}\mu_t. \]

Lemma. The committee \(W\) satisfies mass-SJR if and only if \(r_{j,a}(W)<1/k\) for every \(j\) and every \(a\in D^j\).

Proof. Suppose first that \(r_{j,a}(W)\ge1/k\) for some attribute. Let \(S=\{t\in U(W):a\in A_t^j\}\), and choose \(\nu_t=\mu_t\) on \(S\) and \(\nu_t=0\) elsewhere. This is admissible and has total mass at least \(1/k\). All types in its support approve \(a\), so their intersection in dimension \(j\) is nonempty. Every supported type is unrepresented in every dimension, so the representation conclusion fails. Hence mass-SJR fails.

Conversely, suppose mass-SJR fails, witnessed by an admissible vector \(\nu\) with support \(S\). Failure of the representation conclusion means that every type in \(S\) belongs to \(U(W)\). The cohesion premise supplies some dimension \(j\) and attribute \(a\in\bigcap_{t\in S}A_t^j\). Consequently,

\[ r_{j,a}(W)\ge\sum_{t\in S}\mu_t\ge\sum_{t\in S}\nu_t\ge1/k. \]

This proves the equivalence. \(\square\)

The strict inequality is essential: equality already supplies a violating group. Empty approval sets cause no exception to the argument.

3. Polynomial-time verification

Write each mass as \(\mu_t=a_t/b_t\), with positive integer denominators encoded in binary. Put \(B=\prod_t b_t\) and \(z_t=a_t(B/b_t)\). Then \(z_t=B\mu_t\) is an integer and \(\sum_t z_t=B\).

The bit length of \(B\) is at most the sum of the denominator bit lengths, hence is \(O(L)\). Thus constructing this common denominator does not require expanding the society into individual voters.

After indexing attribute labels, form the Boolean table \(I_{t,c,j}=\mathbf{1}_{\{c[j]\in A_t^j\}}\). Given \(W\):

  • A type belongs to \(U(W)\) exactly when \(I_{t,c,j}=0\) for every selected candidate and dimension.
  • For every distinct tagged attribute, sum \(z_t\) over its unrepresented approvers. If that sum is \(R_{j,a}\), the lemma requires precisely \(kR_{j,a}<B\).
  • Compute the integer \(P(W)=\sum_{c\in W}\sum_t z_t\sum_{j=1}^d I_{t,c,j}\). Then \(\operatorname{AV}_{\mu}(W)=P(W)/(dB)\), which can be compared with \(q\) by exact cross multiplication.

The score computation sums over selected candidates, so repeated attribute values contribute once per selected candidate, as required.

There are at most \(md\) distinct tagged attributes. With elementary integer arithmetic, a conservative bound for preprocessing and verifying one committee is \(O((m\tau d+kd+1)L^2)\) bit operations. All integers involved have \(O(L)\) bits: in particular, \(P(W)\le kdB\).

A certificate lists \(k\) distinct candidate indices. Its size is polynomial because \(k\le m\), and the preceding verifier is polynomial. Therefore the problem belongs to \(\mathrm{NP}\).

4. Exact transfer from finite electorates

The supplied finite-electorate theorem gives \(\mathrm{NP}\)-hardness of the SJR-constrained AV threshold problem for \(d=1\) with variable \(k\ge3\). This is the case of Lemma 5.10 that we use. [Kagita et al. (2021)](https://www.ifaamas.org/Proceedings/aamas2021/pdfs/p683.pdf)

Take such an instance with \(n\) explicitly listed voters. Keep its candidates, attributes, and committee size. Group voters with identical approval ballots into types. If type \(t\) occurs \(n_t\) times, assign \(\mu_t=n_t/n\).

Let the finite-electorate score be

\[ \operatorname{AV}_{F}(W)=\frac1d\sum_{i=1}^n\sum_{c\in W}\sum_{j=1}^d \mathbf{1}_{\{c[j]\in A_i^j\}}. \]

For every committee, grouping identical ballots gives exactly \(\operatorname{AV}_{\mu}(W)=\operatorname{AV}_{F}(W)/n\). Therefore a finite score threshold \(Q\) becomes \(q=Q/n\). If the source threshold instead counts raw approvals before division by \(d\), divide it by \(nd\).

It remains to prove that grouping preserves the representation constraint.

Finite SJR failure implies mass-SJR failure. Let \(G\) be a violating voter group. For each type, set \(\nu_t=|G\cap V_t|/n\), where \(V_t\) is its voter class. Then \(0\le\nu_t\le\mu_t\), and \(\sum_t\nu_t=|G|/n\ge1/k\). The supported types have exactly the common approvals and lack of representation exhibited by \(G\). Hence they violate mass-SJR.

Mass-SJR failure implies finite SJR failure. Let \(\nu\) witness a mass-SJR failure, with support \(S\). Take all voters whose types belong to \(S\), forming \(G=\bigcup_{t\in S}V_t\). Its size satisfies

\[ |G|=n\sum_{t\in S}\mu_t\ge n\sum_t\nu_t\ge n/k. \]

The common attribute approved by every supported type is approved by every voter in \(G\). Every such voter is unrepresented, because its ballot equals its type’s ballot. Thus \(G\) violates finite SJR.

Accordingly, every committee is feasible in the source instance exactly when it is feasible in the constructed instance, and its threshold comparison is also preserved.

The construction is polynomial: the output has \(\tau\le n\), each mass uses \(O(\log n)\) bits, and grouping explicitly listed ballots and scaling the threshold take polynomial time in the source input length. Hence the mass problem restricted to \(d=1,\ k\ge3\) is \(\mathrm{NP}\)-hard.

5. Additional dimensions and fixed committee sizes

To obtain hardness for any fixed dimension count \(d_0\ge2\), copy a hard one-dimensional mass instance into every dimension. Replace an attribute \(a\) by the tagged values \((1,a),\ldots,(d_0,a)\), give each candidate its corresponding copy in every dimension, and copy every type’s approvals.

For every type group, having a common approved attribute in any copied dimension is equivalent to having one in the original dimension. Likewise, representation in any copied dimension is equivalent to original representation. Mass-SJR is therefore unchanged.

Each candidate’s approval contribution is repeated \(d_0\) times, and the score’s factor \(1/d_0\) cancels this repetition. Thus scores and thresholds are unchanged. For fixed \(d_0\), the construction is polynomial and proves hardness within the regime \(d\ge2,\ k\ge2\), using instances with \(k\ge3\).

Combining hardness with membership proves \(\mathrm{NP}\)-completeness.

Finally, enumerating all committees gives a deterministic running time of \(O(\binom{m}{k}(m\tau d+kd+1)L^2)\). This is polynomial for every fixed \(k\), including \(k=2\), even when \(d\) varies.
