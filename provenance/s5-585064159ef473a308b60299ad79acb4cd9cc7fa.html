The continuous mirror question, as graded

Given \(r\) object categories and a rational distribution \(\mu\) over \(\tau\) types \((u_t,e_t)\), with each \(u_t(j)\) drawn from at most three common nonnegative rational values, set \(q_j=\sum_t\mu_t\mathbf{1}[j\in e_t]\). Does there exist a rational mass allocation \(x_{tB}\geq 0\) over integral bundles \(B\subseteq[r]\) satisfying \(\sum_B x_{tB}=\mu_t\), \(\sum_{t,B:j\in B}x_{tB}=q_j\), and \(x_{tB}>0\Rightarrow u_t(B)\geq u_t(e_t)\), with \(\sum_{t,B}x_{tB}(u_t(B)-u_t(e_t))>0\); can this be decided in time polynomial in \(r,\tau,L\)?

Packaged proof task (what the prover saw — nothing else)

There are \(r=m\geq1\) object categories. A society is given by its support: a list of \(\tau\geq1\) types \((u_t,e_t)\), each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length.
Each endowment is an integral bundle \(e_t\subseteq[r]\), possibly empty. Utilities are additive, with \(u_t(j)\in V\) for one common input set \(V\subseteq\mathbb{Q}_{\geq0}\), \(1\leq|V|\leq3\). Write \(u_t(B)=\sum_{j\in B}u_t(j)\) and \(q_j=\sum_t\mu_t\mathbf{1}[j\in e_t]\).
A mass allocation assigns rational masses \(x_{tB}\geq0\) to integral bundles \(B\subseteq[r]\), with \(\sum_Bx_{tB}=\mu_t\) for every type and \(\sum_{t,B:j\in B}x_{tB}=q_j\) for every category. Each individual receives at most one unit of each category; bundle sizes may change.
It is a Pareto improvement if \(x_{tB}>0\Rightarrow u_t(B)\geq u_t(e_t)\) and \(\sum_{t,B}x_{tB}(u_t(B)-u_t(e_t))>0\).

Is deciding whether such a Pareto improvement exists solvable in polynomial time in \(m=r,\tau,L\), or is it NP-hard?

For finite agents and indivisible objects, testing Pareto optimality with three common utility values is strongly coNP-complete; equivalently, deciding existence of a Pareto improvement is strongly NP-complete. With two common values, the discrete problem has a polynomial-time algorithm. [Aziz et al.](https://www.lamsade.dauphine.fr/~lang/papers/ABLLM19.pdf)
No complexity result for this exact mass-allocation problem was located in the literature search.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: positive support masses sum to one.
  • Specified additive bundle utilities and a single common input set of at most three nonnegative rational values.
  • Allowed empty endowments and empty allocated bundles, as the discrete assignment definition permits empty parts; imposed no preservation of individual bundle sizes.
  • Interpreted categories as permitting at most one unit per individual, with aggregate supply determined entirely by endowment masses.
  • Defined L as the total input bit length and identified m with r for running-time statements.

Result

The mass-allocation problem is solvable in polynomial time in \(m=r,\tau,L\). An exact linear programming formulation has \(O(\tau r^4)\) variables and constraints.

The key is to enumerate the numbers of objects received at each utility value. With at most three values, there are polynomially many such count vectors. For each vector, the possible category marginals have an exact linear description.

1. A rational decomposition lemma

Let \(C_1,\ldots,C_k\) partition \([r]\), and let \(c_i\) be integers satisfying \(0\leq c_i\leq |C_i|\). Define

\( P(c)=\{z\in[0,1]^r:\ \sum_{j\in C_i}z_j=c_i\text{ for every }i\}. \)

Lemma. Every rational point of \(P(c)\) is a rational convex combination of incidence vectors of bundles \(B\subseteq[r]\) satisfying \(|B\cap C_i|=c_i\) for every \(i\).

Proof. We induct on the number of fractional coordinates of \(z\).

If there are none, \(z\) is itself the incidence vector of a suitable bundle.

Otherwise, some class \(C_i\) contains a fractional coordinate. Because its coordinate sum is the integer \(c_i\), it cannot contain exactly one fractional coordinate. Choose two, indexed by \(p,q\in C_i\). Let \(d\) have coordinate \(1\) at \(p\), coordinate \(-1\) at \(q\), and zero elsewhere. Set

\( a=\min\{1-z_p,z_q\}>0,\qquad b=\min\{z_p,1-z_q\}>0. \)

Both \(z^+=z+ad\) and \(z^-=z-bd\) belong to \(P(c)\): the class sums remain unchanged, and all coordinates remain in \([0,1]\). Each has fewer fractional coordinates than \(z\), since at least one of the two modified coordinates reaches an endpoint. Moreover,

\( z=\frac{b}{a+b}z^++\frac{a}{a+b}z^-. \)

All quantities are rational. Applying the induction hypothesis to both points proves the lemma. \(\square\)

2. Enumerating individually acceptable count vectors

Write the common value set as \(V=\{v_1,\ldots,v_k\}\), where \(1\leq k\leq3\). For each type \(t\), define

\( C_{ti}=\{j\in[r]:u_t(j)=v_i\},\qquad n_{ti}=|C_{ti}|,\qquad b_t=u_t(e_t). \)

These classes partition \([r]\), allowing empty classes.

The count vector of a bundle \(B\) is \(c_i=|B\cap C_{ti}|\). Its utility is exactly \(\sum_i v_i c_i\). Consequently, the individually acceptable count vectors are precisely

\( H_t=\{c\in\mathbb Z_{\geq0}^k:\ c_i\leq n_{ti}\text{ for every }i,\ \sum_{i=1}^k v_i c_i\geq b_t\}. \)

There are at most \((r+1)^k\leq(r+1)^3\) candidates. We can enumerate them and check the utility inequality using exact rational arithmetic.

For \(c\in H_t\), denote its utility gain by

\( g_{tc}=\sum_{i=1}^k v_i c_i-b_t\geq0. \)

3. The polynomial-size linear program

For every \(t\) and \(c\in H_t\), introduce:

  • \(\lambda_{tc}\), the mass of type \(t\) receiving bundles with count vector \(c\);
  • \(y_{tcj}\), the mass within that group receiving category \(j\), for each \(j\in[r]\).

Maximize

\( G=\sum_{t=1}^{\tau}\sum_{c\in H_t}g_{tc}\lambda_{tc} \)

subject to the following constraints:

  • Nonnegativity and the limit of one unit of each category per individual:

\( \lambda_{tc}\geq0,\qquad 0\leq y_{tcj}\leq\lambda_{tc} \quad\text{for every }t,c,j. \)

  • Preservation of each type's total mass:

\( \sum_{c\in H_t}\lambda_{tc}=\mu_t \quad\text{for every }t. \)

  • The specified counts within every group:

\( \sum_{j\in C_{ti}}y_{tcj}=c_i\lambda_{tc} \quad\text{for every }t,c,i. \)

  • Conservation of every category:

\( \sum_{t=1}^{\tau}\sum_{c\in H_t}y_{tcj}=q_j \quad\text{for every }j. \)

We next prove that this formulation is exact.

4. Equivalence with mass allocations

From a mass allocation to the linear program

Take any mass allocation satisfying the individual utility requirement. Group its positive masses by their count vectors, setting

\( \lambda_{tc}=\sum_{B:\,|B\cap C_{ti}|=c_i\ \forall i}x_{tB} \)

and

\( y_{tcj}=\sum_{B:\,|B\cap C_{ti}|=c_i\ \forall i,\ j\in B}x_{tB}. \)

Every positive mass belongs to a group in \(H_t\), because its bundle is individually acceptable. The bounds on \(y\), type-mass equalities, and category-conservation equalities follow directly from the allocation requirements.

For the count equalities, each bundle in group \(c\) contains exactly \(c_i\) categories from \(C_{ti}\). Thus

\( \sum_{j\in C_{ti}}y_{tcj} =\sum_{B:\,\text{count vector }c}|B\cap C_{ti}|x_{tB} =c_i\lambda_{tc}. \)

Every bundle in this group has gain \(g_{tc}\), so the LP objective equals the allocation's total gain.

From the linear program to a mass allocation

Take any rational feasible LP solution. For a group with \(\lambda_{tc}>0\), define

\( z_j=\frac{y_{tcj}}{\lambda_{tc}}. \)

Its constraints imply

\( 0\leq z_j\leq1,\qquad \sum_{j\in C_{ti}}z_j=c_i. \)

Apply the decomposition lemma to the partition \(C_{t1},\ldots,C_{tk}\). There are bundles \(B_\ell\) with count vector \(c\) and nonnegative rational weights \(\alpha_\ell\), summing to one, such that

\( z=\sum_\ell\alpha_\ell\mathbf1_{B_\ell}. \)

Assign mass \(\lambda_{tc}\alpha_\ell\) to bundle \(B_\ell\). This realizes total mass \(\lambda_{tc}\) and category marginals \(y_{tcj}\). Every such bundle is individually acceptable because \(c\in H_t\).

Groups with \(\lambda_{tc}=0\) have \(y_{tcj}=0\) and require no assignment. Combining all groups, and adding masses if the same bundle occurs more than once, gives rational \(x_{tB}\) satisfying all allocation requirements. Its total utility gain is exactly \(G\).

This proves exact equivalence, including the requirement that every positive-mass bundle meets its recipient's utility threshold.

5. Polynomial-time decision

Let \(N=\sum_t|H_t|\). Then

\( N\leq\tau(r+1)^3. \)

The LP has \(N(r+1)=O(\tau r^4)\) variables and \(O(\tau r^4)\) constraints. Its coefficients are rational quantities obtained from input values, input masses, and integers bounded by \(r\). Computing \(b_t\), \(q_j\), and \(g_{tc}\) by rational arithmetic gives polynomial encoding length in \(r,\tau,L\).

The LP is nonempty: the original endowment allocation is feasible and has objective zero. It is bounded: the type-mass constraints imply \(\lambda_{tc}\leq\mu_t\), and then \(y_{tcj}\leq\mu_t\). Therefore its optimum \(G^\star\) is attained.

The standard polynomial-time theorem for rational linear programming applies: a rational LP of polynomial encoding length can be optimized exactly in polynomial time. In particular, its optimum can be compared with zero exactly.

By the equivalence proved above:

  • If a Pareto improvement exists, it gives a feasible LP solution with positive objective, so \(G^\star>0\).
  • If \(G^\star>0\), a rational optimal LP solution decomposes into a rational mass allocation with positive total gain, hence a Pareto improvement.

Thus the decision algorithm is to construct this LP and answer yes exactly when \(G^\star>0\).

6. Relation to the discrete problem

The hardness result for finite agents in [Aziz et al.](https://www.lamsade.dauphine.fr/~lang/papers/ABLLM19.pdf) concerns assigning one integral bundle to each agent. Here, a type's mass can be split among several individually acceptable bundles, and conservation is imposed on category masses. The decomposition lemma makes this permitted splitting exactly representable by linear constraints.

The proof also establishes polynomial-time solvability for any fixed bound on the number of distinct utility values per type; those values need not be common across types.
