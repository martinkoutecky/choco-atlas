The continuous mirror question, as graded

Given a finite bi-valued symmetric multigraph template \(H=(V,E)\) of multiplicity \(q\), with edge weights \(\alpha>\beta\ge0\), consider a continuum of cells indexed by \(z\in[0,1]\). Each cell has one agent per vertex and one indivisible good per edge, valued by its endpoint agents as in \(H\). Does there exist a measurable rule orienting every cell’s goods so that, for almost every \(z\), the resulting allocation in that cell is EFX?

Packaged proof task (what the prover saw — nothing else)

Let \(H=(V,E)\) be an explicitly listed finite multigraph with \(n=|V|\ge2\), \(m=|E|\ge1\), and multiplicity \(q\), the maximum number of edges sharing an unordered endpoint pair, including loops. Each edge has a binary rational weight in \(\{\alpha,\beta\}\), where \(\alpha>\beta\ge0\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here types are the labelled vertex roles, \(\tau=n\), each with mass \(1/n\); total society mass is \(1\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L,q\).
Cells are indexed by \(z\in[0,1]\) with Lebesgue measure. Every cell contains one agent of each vertex role and a separate indivisible copy of every edge. An agent's additive utility for an edge is its weight if incident to that vertex, and zero otherwise.
A rule assigns every edge copy to one of its endpoints in its own cell; loops go to their sole endpoint. For each edge and endpoint, the set of cells assigning that edge to that endpoint must be Lebesgue measurable.
Writing \(\pi_i(z)\) for agent \(i\)'s bundle, cellwise EFX means \(u_i(\pi_i(z))\ge u_i(\pi_j(z)\setminus\{e\})\) for every \(i\ne j\) and every \(e\in\pi_j(z)\), including goods with zero utility to \(i\). Comparisons are within each cell.

Is deciding whether such a measurable rule is EFX in almost every cell solvable in polynomial time, or is it NP-hard?

Discrete EFX-orientation existence is NP-complete for every fixed \(q\ge2\), even for bipartite templates with \(\alpha>q\beta\) whose heavy edges in every heavy connected component form a tree on at least two vertices after parallel edges are collapsed, with odd multiplicity for every heavy endpoint pair. [Source](https://journals.sagepub.com/doi/10.3233/FAIA251259)
No result addressing this exact measurable, cellwise continuum model was located in the literature search.

Modeling choices made when packaging the task

  • Specified binary rational edge weights and explicit edge listing to define a finite computational input and its bit length.
  • Represented the society by labelled vertex-role types of equal mass 1/n, preserving one agent per vertex in every cell and normalizing total society mass to 1.
  • Specified Lebesgue measure and measurability of each edge's endpoint-assignment sets.
  • Made allocations complete and confined to their own cells, with loops assigned to their sole endpoint.
  • Used the source's EFX convention quantifying over every removed good, including goods of zero utility to the envious agent.
  • Excluded empty templates and required at least two vertices so multiplicity and the normalized role society are nondegenerate.

Result

The decision problem is \(\mathrm{NP}\)-complete, already for every fixed multiplicity \(q\ge 2\) under the additional restrictions stated in the question. Consequently, a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The essential point is that requiring EFX within almost every cell preserves discrete EFX-orientation existence exactly.

1. Equivalence with discrete orientation existence

A discrete orientation \(o\) assigns every edge to one of its endpoints, with loops assigned to their sole endpoint. Write \(\pi_i^o\) for the resulting bundle of vertex \(i\). Call \(o\) EFX when

\[ u_i(\pi_i^o)\ge u_i(\pi_j^o\setminus\{e\}) \]

for every \(i\ne j\) and every \(e\in\pi_j^o\), including edges of zero utility to \(i\).

Proposition. A measurable rule that is EFX in almost every cell exists if and only if a discrete EFX orientation exists.

Proof. Let \(\Omega\) be the finite set of all discrete orientations. If there are \(\ell\) loops, then \(|\Omega|=2^{m-\ell}\).

Suppose first that a measurable rule is given. For each edge \(e\) and endpoint \(v\), let \(A_{e,v}\subseteq[0,1]\) be the measurable set of cells assigning \(e\) to \(v\). For each orientation \(o\), define

\[ F_o=\bigcap_{e\in E} A_{e,o(e)}. \]

This is a finite intersection of measurable sets. Because the rule assigns each edge to exactly one endpoint, the sets \(F_o\), indexed by \(\Omega\), form a partition of \([0,1]\).

Every cell has the same edges and utility functions. Therefore, on \(F_o\), cellwise EFX holds exactly when \(o\) is a discrete EFX orientation. If \(\Omega_{\mathrm{EFX}}\) denotes the set of such orientations, the set of EFX cells is precisely

\[ G=\bigcup_{o\in\Omega_{\mathrm{EFX}}}F_o. \]

If the rule is EFX almost everywhere, then \(\lambda(G)=1\). Since this is a finite disjoint union, some \(o\in\Omega_{\mathrm{EFX}}\) satisfies \(\lambda(F_o)>0\). In particular, a discrete EFX orientation exists.

Conversely, given a discrete EFX orientation \(o\), use it in every cell. Every assignment set is either \([0,1]\) or the empty set, so the rule is measurable. Its allocation is EFX in every cell. This proves the proposition. \(\square\)

The masses \(1/\tau\), where \(\tau=n\), impose no additional restriction: the specified EFX comparisons concern individual agents within a cell and contain no mass factors.

2. A polynomial certificate and verifier

By the proposition, a certificate consists of one endpoint choice for each non-loop edge, using at most \(m\) bits. It remains to verify its EFX property with exact rational arithmetic.

For a proposed orientation, define:

  • \(T_i=u_i(\pi_i)\), the utility of vertex \(i\)'s own bundle;
  • \(d_j=|\pi_j|\), counting every received edge, including loops;
  • \(h_{ij}\) and \(l_{ij}\), respectively the numbers of heavy and light edges between distinct vertices \(i,j\) assigned to \(j\);
  • \(k_{ij}=h_{ij}+l_{ij}\) and \(S_{ij}=h_{ij}\alpha+l_{ij}\beta\).

Because allocations are orientations, the only edges in \(\pi_j\) incident to \(i\ne j\) are edges between \(i\) and \(j\). Hence \(u_i(\pi_j)=S_{ij}\).

If \(k_{ij}=0\), every edge in \(\pi_j\) has zero utility to \(i\), so all EFX inequalities for this ordered pair hold by nonnegativity.

Now suppose \(k_{ij}>0\). Define \(\delta_{ij}\) as the minimum utility to \(i\) of an edge in \(\pi_j\). It is given exactly by

\[ \delta_{ij}= \begin{cases} 0, & d_j>k_{ij},\\ \beta, & d_j=k_{ij}\ \text{and}\ l_{ij}>0,\\ \alpha, & d_j=k_{ij}\ \text{and}\ l_{ij}=0. \end{cases} \]

Indeed, the first case means that \(j\) receives an edge not incident to \(i\); in the other cases every received edge lies between \(i\) and \(j\). This calculation also covers \(\beta=0\).

For this ordered pair, the strongest EFX inequality is therefore exactly

\[ T_i\ge S_{ij}-\delta_{ij}, \]

because removing an edge of minimum utility leaves the largest remaining utility. Checking these inequalities for all distinct vertices verifies the original definition, including removal of zero-valued goods.

All counts can be initialized and accumulated using \(O(m+\tau^2)\) operations. For bit complexity, write \(\alpha=a/b\) and \(\beta=c/d\), with positive denominators, and use the common denominator \(bd\). All comparisons then use integers of \(O(B)\) bits, where \(B=L+\lceil\log_2(m+1)\rceil\).

Using elementary integer arithmetic, a sufficient verifier running-time bound is

\[ O\bigl((m+\tau^2)B^2\bigr). \]

This bound is uniform in \(q\), with \(1\le q\le m\). Thus the measurable decision problem belongs to \(\mathrm{NP}\). Enumerating all certificates also gives a deterministic bound \(O\bigl(2^m(m+\tau^2)B^2\bigr)\).

3. Hardness transfers without changing the template

We apply the discrete theorem supplied in the question. For every fixed \(q\ge2\), discrete EFX-orientation existence is \(\mathrm{NP}\)-complete even for bipartite, symmetric, bi-valued multigraphs of multiplicity \(q\), with \(\alpha>q\beta\), whose heavy edges in each heavy component induce a nontrivial odd multitree. The source’s definition quantifies over every removed edge, matching the zero-utility convention here. [Hsu, *EFX Orientations of Multigraphs*, Theorem 1 and Section 2.2](https://journals.sagepub.com/doi/10.3233/FAIA251259).

The rational-weight requirement is compatible with that hardness construction: for fixed \(q\), its weights can be fixed as \(\alpha=q+1\) and \(\beta=1\), which satisfy \(\alpha>q\beta\).

Given such a discrete instance, construct the continuum instance by retaining its explicitly listed graph and weights and listing one role per vertex, each with mass \(1/n\). This adds \(O(\tau\log(\tau+1))\) bits and takes polynomial time. It preserves the multiplicity, bipartiteness, and heavy-component restrictions.

The proposition proves that the constructed instance admits an almost-everywhere EFX measurable rule exactly when the original instance admits a discrete EFX orientation. Thus this is a polynomial-time many-one reduction, establishing \(\mathrm{NP}\)-hardness for every fixed \(q\ge2\).

Together with the certificate verifier, this completes the proof of \(\mathrm{NP}\)-completeness.
