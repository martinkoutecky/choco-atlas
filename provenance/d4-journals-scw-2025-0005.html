The continuous mirror question, as graded

Given a finite set \(T\) of complete preference types, a rational distribution \(\mu\) over \(T\), and a finite rational antichain \(\Delta\) of threshold vectors \(x\in[0,1]^{\tau+1}\) with \(\sum_{i=0}^{\tau}x_i\le 1\), compute the selected alternative. Let \(p=\sum_{t\in T:\,a\succ_t b}\mu_t\), \(z_i=\mu_{W_i}\) for the \(\tau\) types \(W_i\) indifferent between \(a\) and \(b\), and \(q(\mu)=(p,z_1,\ldots,z_\tau)\). Select \(a\) exactly when some \(x\in\Delta\) satisfies \(\sum_{i=1}^{\tau}(x_i-z_i)^+\le p-x_0\); otherwise select \(b\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge2\) alternatives, with distinct designated outcomes \(a,b\). Types are complete, transitive weak preferences on \(A\), explicitly encoded as ordered indifference classes.
A society is given by its support: a list \(T\) of \(\tau\) distinct types with positive binary rational masses \(\mu_t\), satisfying \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Enumerate the types in \(T\) indifferent between \(a\) and \(b\) as \(W_1,\ldots,W_r\), allowing \(r=0\). Set \(p=\sum_{t\in T:a\succ_t b}\mu_t\), \(z_i=\mu_{W_i}\), and \(q(\mu)=(p,z_1,\ldots,z_r)\).
Let \(S_r=\{x\in\mathbb Q^{r+1}:x_i\ge0,\ \sum_{i=0}^r x_i\le1\}\), ordered by \(x\preceq y\iff\sum_{i=1}^r\max\{x_i-y_i,0\}\le y_0-x_0\).
The input also explicitly lists a finite antichain \(\Delta\subseteq S_r\) for this order; the empty antichain is allowed. Select \(a\) exactly when some \(x\in\Delta\) satisfies \(x\preceq q(\mu)\), and otherwise select \(b\); equality selects \(a\).
Let \(K=|\Delta|\) and let \(L\) be the total binary input length. State running times in \(m,\tau,r,K,L\).

Is deciding whether this rule selects \(a\) solvable in polynomial time in \(m,\tau,r,K,L\), or is it NP-hard?

For finite electorates with a common preference domain and finitely many indifferent types, antichains of attainable count vectors uniquely represent all anonymous weakly group strategy-proof rules with outcomes in \(\{a,b\}\). This is a [representation result](https://link.springer.com/article/10.1007/s00355-024-01546-x), without a stated complexity bound.
No result settling this exact rational-mass evaluation problem was identified in the literature search.

Modeling choices made when packaging the task

  • Reserved tau for positive-mass support size and renamed the number of indifferent support types r; threshold vectors consequently have r+1 coordinates.
  • Interpreted complete preference types as complete, transitive weak preferences, allowing indifference, and chose ordered indifference classes as their explicit encoding.
  • Normalized total mass to one, with every listed support mass strictly positive.
  • Specified that the threshold antichain uses the positive-part order from the discrete definition, rather than coordinatewise order, and is explicitly listed.
  • Allowed r=0 and an empty antichain, as the discrete definitions do; retained the weak threshold inequality and permitted constant outcomes.
  • Defined L as total binary input length and included the explicitly supplied threshold-list size K among the running-time parameters.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is polynomial-time solvable. A deterministic algorithm uses
\[ O\!\left(\bigl(m\tau+\tau+K(r+1)\bigr)L^2\right) \]
bit operations with elementary integer arithmetic, giving the coarser bound \(\ O(L^3)\ \) for the explicit encoding in the question.

Algorithm and correctness.

For each listed type \(t\), scan its ordered indifference classes to locate \(a\) and \(b\). Their class positions determine whether \(a\succ_t b\), \(b\succ_t a\), or \(a\sim_t b\). Sum the masses in the first category to obtain \(p\), and record the masses in the third category as \(z_1,\ldots,z_r\), using the enumeration associated with the coordinates of \(\Delta\).

These quantities satisfy
\[ p\ge0,\qquad z_i\ge0,\qquad p+\sum_{i=1}^r z_i\le1, \]
because the corresponding categories are disjoint and the total mass is \(1\). Thus the computed vector belongs to \(S_r\).

For each explicitly listed \(x=(x_0,\ldots,x_r)\in\Delta\), calculate
\[ d_x=\sum_{i=1}^r\max\{x_i-z_i,0\}. \]
Return \(a\) if any such vector satisfies
\[ d_x\le p-x_0. \]
Otherwise return \(b\).

By the definition of the order, this test is exactly \(x\preceq q(\mu)\). Consequently, the algorithm returns \(a\) exactly under the condition specified in the question. The non-strict comparison includes equality.

If \(K=0\), the existential condition is false and the algorithm returns \(b\). If \(r=0\), the sum is empty and each test reduces to \(x_0\le p\).

Exact arithmetic and running time.

Write every input rational as an integer numerator divided by a positive integer denominator. Let \(D\) be the product of all denominators appearing in the masses and the coordinates of \(\Delta\). Reduction to lowest terms is unnecessary.

The sum of the bit lengths of these denominators is at most \(L\). Therefore \(D\) has \(O(L)\) bits, even though its numerical value may be exponentially large. There are
\[ N=\tau+K(r+1) \]
input rational occurrences.

For each input rational \(u/v\), compute its scaled integer
\[ \widehat{u/v}=u(D/v). \]
This division is exact because \(v\) divides \(D\). Since every mass and coordinate lies in \([0,1]\), each scaled integer lies between \(0\) and \(D\).

Compute the integers
\[ P=Dp,\qquad Z_i=Dz_i,\qquad X_i=Dx_i. \]
The test for \(x\) becomes
\[ \sum_{i=1}^r\max\{X_i-Z_i,0\}\le P-X_0. \]
Indeed, multiplication by the positive number \(D\) preserves inequalities and satisfies
\[ D\max\{x_i-z_i,0\}=\max\{X_i-Z_i,0\}. \]

All integers used here have \(O(L)\) bits. In particular, the partial sums defining \(P\) are at most \(D\). For each candidate \(x\), its accumulated deficit is also at most \(D\), since
\[ \sum_{i=1}^r\max\{X_i-Z_i,0\} \le\sum_{i=1}^r X_i\le D, \]
where the final inequality follows from \(x\in S_r\).

Using elementary multiplication and long division:

  • Constructing \(D\) and scaling the input rationals takes \(O(NL^2)\) bit operations.
  • Computing \(P\) takes \(O(\tau L)\) bit operations.
  • Testing all candidates takes \(O(K(r+1)L)\) bit operations.

Scanning the explicit preference encodings fits within the conservative bound \(O(m\tau L^2)\). Including input parsing yields the stated total bound
\[ O\!\left(\bigl(m\tau+\tau+K(r+1)\bigr)L^2\right). \]
Because the types and antichain vectors are explicitly encoded, \(m\tau=O(L)\) and \(\tau+K(r+1)=O(L)\), so this is \(O(L^3)\).

Scope of the conclusion.

The algorithm checks only the \(\tau\) supplied types and the \(K\) supplied vectors. Its correctness does not require the antichain property; the same evaluation procedure works for any explicitly listed finite subset of \(S_r\).

The linked [representation paper](https://link.springer.com/article/10.1007/s00355-024-01546-x) concerns functional representations of the rules. The complexity conclusion here follows directly from the supplied comparison formula and explicit representation.

Thus this evaluation problem belongs to \(\mathrm{P}\). It could be NP-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).
