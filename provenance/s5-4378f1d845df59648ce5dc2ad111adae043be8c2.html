The continuous mirror question, as graded

Given a finite type set \(T\) with binary cost vectors \(a_{t,e}\in\{0,1\}\), type masses \(\mu_t\), equal entitlements, and per-capita chore supplies \(q_e\), compute a finite-support lottery over measurable allocations of integral bundle vectors \(b\in\mathbb{Z}_{\geq 0}^{E}\) that assigns all chore mass, makes every realization ex-post EFX and fPO, and satisfies ex-ante EF and fPO for every positive-mass ordered pair of agents.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. There are \(m\geq1\) chore categories \(E\), binary additive costs \(c_t(b)=\sum_{e\in E}a_{t,e}b_e\) with \(a_{t,e}\in\{0,1\}\), and nonnegative binary-rational per-capita supplies \(q_e\); \(L\) is the total input bit length.
Represent agents by disjoint intervals \(A_t\) of lengths \(\mu_t\), with Lebesgue measure and equal entitlements; write \(t(x)\) for agent \(x\)'s type. A realization is a measurable integral-bundle map \(b:A\to\mathbb Z_{\geq0}^{E}\) satisfying \(\int_A b_e(x)\,dx=q_e\) for every \(e\).
Ex-post EFX means that, for almost every ordered pair \((x,y)\), \(c_{t(x)}(b(x))-a_{t(x),e}\leq c_{t(x)}(b(y))\) for every \(e\) with \(b_e(x)>0\), including zero-cost chores; empty bundles impose no removal condition.
A feasible allocation is fPO if no measurable, integrable fractional map \(z:A\to\mathbb R_{\geq0}^{E}\) with the same supplies weakly lowers agents' costs almost everywhere and strictly lowers them on a set of positive measure.
A finite-support lottery \((\lambda_\ell,b^\ell)\) must have every realization EFX and fPO. Its expected map \(\bar b=\sum_\ell\lambda_\ell b^\ell\) must be fPO and satisfy ex-ante EF: \(c_{t(x)}(\bar b(x))\leq c_{t(x)}(\bar b(y))\) for almost every ordered pair \((x,y)\), including pairs within one type.
Encode the lottery by positive binary-rational probabilities summing to \(1\), a finite common partition of each type interval into intervals with binary-rational endpoints, and an integral bundle vector on each cell in each realization.

Is computing such a lottery, or determining that none exists, solvable in polynomial time in \(m,\tau,L\), or is this problem NP-hard?

For finitely many equally entitled agents and individually listed binary additive chores, a polynomial-time algorithm constructs a lottery with ex-ante EF and fPO and ex-post EFX and fPO, supported on at most \(n^2\) allocations. [Source](https://arxiv.org/html/2609.13970v1)
No result settling the exact atomless-agent lottery problem above was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total agent mass to one and represented each type by an atomless interval; equal entitlements mean unweighted comparisons between individual agents.
  • Took chore supplies to be nonnegative binary rationals, interpreted as category quantities per unit agent mass, with no normalization of their sum.
  • Interpreted positive-mass ordered pairs as almost-everywhere comparisons under product measure, including comparisons between agents of the same type.
  • Carried over removal of every chore in the envious agent's bundle, including zero-cost chores; removal decreases the relevant integral coordinate by one.
  • Defined continuum fPO using all feasible measurable fractional reallocations, with weak improvement almost everywhere and strict improvement on a positive-measure set; ex-ante fPO applies to the expected bundle map.
  • Specified a finite computational encoding using rational probabilities and rational interval cells carrying integral bundles.
  • Allowed an infeasibility report because existence for the continuous formulation is not supplied by the discrete guarantee.

Status and proved results

The prescribed explicit search problem cannot be solved in polynomial time in $m,\tau,L$, because some inputs require exponentially many realizations and partition cells. Nevertheless, every valid input admits a lottery, so determining existence always answers yes.

I give a direct construction proving existence, without invoking the finite-agent theorem. It also yields a polynomial-time construction whenever the total supply of universally costly chores is an integer.

A further result is that deciding whether one deterministic realization suffices is $\mathrm{NP}$-complete, even for a restricted family with dyadic inputs. This does not establish $\mathrm{NP}$-hardness of computing an unrestricted lottery. That part of the target remains unresolved.

Throughout, rationals are encoded by binary numerators and denominators. The construction also respects the narrower interpretation in which all input and output rationals must be dyadic.

1. Characterizing fractional Pareto optimality

Let
$$ E^+=\{e\in E:a_{t,e}=1\text{ for every supported type }t\}, \qquad Q=\sum_{e\in E^+}q_e. $$
Call the categories in $E^+$ universal. Write $|B|$ for the Lebesgue measure of a measurable set $B$.

Proposition. A feasible nonnegative, integrable allocation $u$, whether integral or fractional, is fPO if and only if every non-universal category is assigned exclusively to agents who incur zero cost for it, almost everywhere.

Proof. Since the total mass of agents is $1$, the integrated cost is
$$ \operatorname{SC}(u) = \int_A c_{t(x)}(u(x))\,dx = Q+\sum_{e\notin E^+}\int_A a_{t(x),e}u_e(x)\,dx. $$
In particular, every feasible fractional allocation has integrated cost at least $Q$.

Suppose, for some non-universal category $e$,
$$ \delta=\int_{\{x:a_{t(x),e}=1\}}u_e(x)\,dx>0. $$
Its zero-cost recipient set
$$ Z=\{x:a_{t(x),e}=0\} $$
has positive measure: at least one supported type has coefficient zero, and every supported type has positive mass.

Remove all category-$e$ chores from its positive-cost recipients and add $\delta/|Z|$ chores per agent on $Z$. Leave all other coordinates unchanged. This defines a feasible, measurable, integrable fractional allocation. It leaves the costs of agents in $Z$ unchanged and weakly lowers every other cost. The agents from whom a positive quantity was removed form a positive-measure set, because the removed integral is $\delta>0$. They strictly improve. Thus $u$ is not fPO.

Conversely, suppose every non-universal category is assigned at zero cost. Then $\operatorname{SC}(u)=Q$. A fractional Pareto improvement would strictly decrease integrated cost, contradicting the lower bound $Q$. Indeed, its cost reduction is an integrable function that is nonnegative almost everywhere and positive on a positive-measure set, so its integral is positive. This proves the proposition. $\square$

Consequently, the expectation of any finite lottery of feasible fPO allocations is automatically fPO: non-universal categories remain assigned only at zero cost.

2. A direct lottery construction for every input

Write
$$ Q=h+r, \qquad h=\lfloor Q\rfloor, \qquad 0\leq r<1. $$
If $r>0$, write $r=p/D$ in lowest terms. If $r=0$, set $p=0$ and $D=1$.

The construction uses $D$ equally likely realizations. Each type has the same distribution of universal chores. Non-universal chores are assigned only where the universal load is $h$, rather than $h+1$.

2.1 Integral universal bundles with the prescribed supplies

Order the universal categories as $e_1,\ldots,e_u$, where $u=|E^+|$, and define
$$ s_0=0, \qquad s_i=\sum_{j=1}^i q_{e_j}. $$
Thus $s_u=Q$.

For $s\geq0$ and $w\in[0,1)$, define
$$ F_s(w)=\lfloor s\rfloor+ \mathbf{1}_{[0,s-\lfloor s\rfloor)}(w). $$
For each universal category, put
$$ U_{e_i}(w)=F_{s_i}(w)-F_{s_{i-1}}(w). $$

These functions have three needed properties.

First, $U_{e_i}(w)$ is a nonnegative integer. To check nonnegativity, observe that $F_s(w)$ is nondecreasing in $s$. If two values of $s$ have the same integer part, their indicator intervals are nested. If their integer parts differ, the increase in the integer part compensates for any decrease in the indicator.

Second,
$$ \int_0^1 F_s(w)\,dw = \lfloor s\rfloor+(s-\lfloor s\rfloor) =s. $$
Therefore,
$$ \int_0^1 U_{e_i}(w)\,dw=q_{e_i}. $$

Third, telescoping gives
$$ \sum_{e\in E^+}U_e(w) = F_Q(w) = h+\mathbf{1}_{[0,r)}(w). $$
Thus every universal bundle contains exactly $h$ or $h+1$ chores.

If there are no universal categories, then $Q=h=r=0$, and the same statements hold with an empty sum.

2.2 Assigning non-universal chores only to low agents

For each non-universal category $e$, choose one supported type $t_e$ satisfying
$$ a_{t_e,e}=0. $$
Such a type exists by definition.

Let
$$ z_e=\frac{q_e}{\mu_{t_e}}, \qquad k_e=\left\lfloor\frac{z_e}{1-r}\right\rfloor, \qquad \delta_e=z_e-k_e(1-r). $$
Because $r<1$,
$$ 0\leq\delta_e<1-r. $$

On the normalized interval of type $t_e$, define
$$ V_e(w) = k_e\mathbf{1}_{[r,1)}(w) + \mathbf{1}_{[r,r+\delta_e)}(w). $$
Assign category $e$ to no other type.

This is a nonnegative integral bundle coordinate, supported entirely on the low region $[r,1)$. Moreover,
$$ \int_0^1 V_e(w)\,dw = k_e(1-r)+\delta_e =z_e. $$
After multiplying by the type mass, its total supply is $\mu_{t_e}z_e=q_e$.

Let $B_t(w)$ denote the resulting integral bundle for type $t$: its universal coordinates are $U_e(w)$, and its non-universal coordinates are the functions $V_e(w)$ designated for that type.

2.3 Rotating the bundles

Choose consecutive type intervals
$$ A_t=[\alpha_t,\alpha_t+\mu_t). $$
For an agent $x\in A_t$, its normalized position is
$$ w_t(x)=\frac{x-\alpha_t}{\mu_t}\in[0,1). $$

For each $j\in\{0,\ldots,D-1\}$, define a realization by
$$ b^j(x) = B_t\!\left(\left\{w_t(x)-\frac{j}{D}\right\}\right), \qquad x\in A_t, $$
where $\{v\}=v-\lfloor v\rfloor$. Give each realization probability $1/D$.

Rotation modulo $1$ preserves Lebesgue measure. Thus, for every realization and every universal category,
$$ \int_A b^j_e(x)\,dx = \sum_t\mu_t\int_0^1 U_e(w)\,dw = q_e. $$
For a non-universal category, only its designated type receives it, and
$$ \int_A b^j_e(x)\,dx = \mu_{t_e}\int_0^1 V_e(w)\,dw = q_e. $$
Every realization is therefore feasible.

2.4 Ex-post EFX and fPO

Fix a realization. Every agent has universal load $h$ or $h+1$, and every non-universal chore is assigned at zero cost.

Consider a low agent $x$, whose own cost is $h$. Removing any assigned chore leaves cost at most $h$. Every comparison bundle contains at least $h$ universal chores, so
$$ c_{t(x)}(b^j(x))-a_{t(x),e} \leq h \leq c_{t(x)}(b^j(y)). $$
This includes removal of zero-cost chores.

A high agent has $h+1$ universal chores and no non-universal chores. Every assigned chore consequently costs that agent $1$. Removing any one leaves cost $h$, and the same comparison applies.

Empty bundles impose no condition, as required. Hence every realization is EFX. The proposition in Section 1 also proves that every realization is fPO.

2.5 Ex-ante EF and fPO

For every normalized position $w$,
$$ \frac1D\sum_{j=0}^{D-1} \mathbf{1}_{[0,r)} \!\left(\left\{w-\frac{j}{D}\right\}\right) =r. $$
For $r=0$, this is immediate. Otherwise, write
$$ w=\frac{a}{D}+v, \qquad 0\leq v<\frac1D, $$
with an integer $a$. The rotated positions enumerate
$$ v,\ v+\frac1D,\ \ldots,\ v+\frac{D-1}{D} $$
in some order. Exactly $p$ lie in $[0,p/D)$, proving the identity.

It follows that every agent has expected universal load
$$ h+r=Q. $$
Agents incur zero cost for all non-universal chores they receive. Therefore,
$$ c_{t(x)}(\bar b(x))=Q $$
almost everywhere.

For any comparison agent $y$, the universal part of $\bar b(y)$ also has total quantity $Q$. Its other coordinates contribute nonnegative cost to type $t(x)$, so
$$ c_{t(x)}(\bar b(y))\geq Q=c_{t(x)}(\bar b(x)). $$
This proves ex-ante EF, including comparisons within one type. The expected map is fPO by Section 1.

Thus every valid input admits a lottery.

2.6 Encoding and running time

Each base function is constant on finitely many intervals with rational endpoints. Its possible breakpoints are:

  • fractional parts of the universal prefix sums $s_i$;
  • $0$, $r$, and $1$;
  • $r+\delta_e$ for categories designated for the type.

There are $O(m+1)$ breakpoints per type. Taking the union of their rotations by $j/D$ gives a common partition with
$$ C=O\!\left(D\tau(m+1)\right) $$
cells. Mapping normalized endpoints back to $A_t$ preserves rationality.

All numbers in this construction have bit length polynomial in $L$. For example, the denominator of $Q$ divides the product of the universal-supply denominators, giving
$$ D\leq 2^{O(L)}. $$
Also, $1-r\geq1/D$, and each positive type mass is at least $2^{-O(L)}$. Consequently, the integers $h$ and $k_e$ have $O(L)$ bits. Prefix sums, endpoints, rotations, and bundle coordinates can all be computed by exact rational arithmetic with polynomial bit length.

Listing all probabilities, partition cells, and bundle vectors therefore takes time polynomial in $m,\tau,L,D$, and in particular at most
$$ 2^{O(L)}. $$

If the inputs are dyadic, then $D$ is a power of $2$, so the probabilities are dyadic. Physical partition endpoints are dyadic as well. For the only potentially non-dyadic normalized breakpoint, observe that
$$ \mu_{t_e}(r+\delta_e) = \mu_{t_e}r+q_e-\mu_{t_e}k_e(1-r), $$
which is dyadic. Rotation adds a dyadic quantity $\mu_{t_e}j/D$ and, when wrapping occurs, subtracts an integer multiple of $\mu_{t_e}$.

Corollary. If $Q$ is an integer, then $D=1$. The construction is deterministic and runs in polynomial time in $m,\tau,L$, using $O(\tau(m+1))$ partition cells.

3. An unavoidable exponential output requirement

The following lower bound is independent of the construction above.

Fix $k\geq1$. Consider one type of mass $1$, one category costing $1$, and supply
$$ q=1+2^{-k}. $$
The input length is $L=\Theta(k)$.

Suppose a valid lottery has $K$ positive-probability realizations, with probabilities $\lambda_1,\ldots,\lambda_K$.

3.1 EFX determines every realized load

Fix a realization $\ell$. Its integer-valued load function has at least one positive-measure level set, because its countably many level sets cover a space of measure $1$. Let $d$ be the least level having positive measure. All lower levels have measure zero.

If the set of agents with load at least $d+2$ had positive measure, its Cartesian product with the positive-measure load-$d$ set would violate EFX: removing one chore would leave cost at least $d+1>d$. Thus
$$ b^\ell(x)\in\{d,d+1\} $$
almost everywhere.

Since the integral lies strictly between $1$ and $2$, necessarily $d=1$. Hence
$$ b^\ell(x)=1+\mathbf{1}_{S_\ell}(x), \qquad |S_\ell|=2^{-k}. $$

3.2 Ex-ante EF bounds every probability

Define
$$ g(x)=\sum_{\ell=1}^K\lambda_\ell b^\ell(x). $$
Identical costs and ex-ante EF imply $g(x)\leq g(y)$ for almost every ordered pair. Swapping coordinates gives equality for almost every pair. By Fubini’s theorem, $g$ is constant almost everywhere. Its integral determines that constant:
$$ g(x)=1+2^{-k} $$
almost everywhere.

Combining the finitely many exceptional null sets gives
$$ g(x)=1+\sum_{\ell=1}^K\lambda_\ell\mathbf{1}_{S_\ell}(x) $$
on a common full-measure set. On the positive-measure set $S_\ell$, this yields
$$ 1+2^{-k}=g(x)\geq1+\lambda_\ell. $$
Therefore,
$$ \lambda_\ell\leq2^{-k}. $$
Summing the probabilities,
$$ 1=\sum_{\ell=1}^K\lambda_\ell\leq K2^{-k}, \qquad K\geq2^k. $$

3.3 The common partition also requires exponentially many cells

On each positive-length common partition cell, every realized load and the expected load are constant. Since the expected load exceeds $1$, some realization assigns load $2$ throughout that cell. Its length is consequently at most $|S_\ell|=2^{-k}$.

If there are $C$ positive-length cells, their lengths sum to $1$, so
$$ C\geq2^k. $$

These two bounds are attained. Partition the unit interval into $N=2^k$ equal cells $I_1,\ldots,I_N$, and use
$$ b^j(x)=1+\mathbf{1}_{I_j}(x), \qquad \lambda_j=\frac1N. $$
Every realization has the prescribed supply and is EFX, and every expected load equals $1+1/N$. Section 1 proves fPO, since the only category is universal.

Thus the minimum numbers of realizations and common partition cells are both exactly $2^k$. Merely writing the required explicit output takes exponential time in $L$.

4. A related restriction is NP-complete

This section proves hardness for existence of a deterministic solution, not for unrestricted lottery search.

Consider the following restricted family. There are $T\geq2$ types, one universal category $u$, and one private category $e_i$ for each type $i$. Costs are
$$ a_{i,u}=1, \qquad a_{i,e_i}=0, \qquad a_{i,e_j}=1\quad(j\neq i). $$
Supplies satisfy
$$ q_{e_i}=\mu_i, \qquad q_u=\beta, \qquad 0<\beta<1. $$

Lemma. An instance in this family has a valid deterministic allocation if and only if there is a subset $H\subseteq\{1,\ldots,T\}$ such that
$$ \sum_{i\in H}\mu_i=\beta. $$

Proof of necessity. In a deterministic lottery, ex-ante EF is ordinary EF. By fPO, category $e_i$ can be assigned only to type $i$. Thus an agent’s own cost equals its universal load.

Within-type EF forces this own cost to be constant almost everywhere on each type interval. Indeed, the two directed EF inequalities imply equality for almost every pair within that interval, and Fubini gives an almost-everywhere constant. Since bundles are integral, write these constants as integers
$$ d_1,\ldots,d_T\in\mathbb Z_{\geq0}. $$
The universal supply gives
$$ \sum_i\mu_i d_i=\beta<1. $$
At least one type $j$ has $d_j=0$, since otherwise this average would be at least $1$. Also, at least one type has positive cost because $\beta>0$.

Choose a type $i$ with maximum $d_i$. Then $i\neq j$. For almost every agent $y$ of type $j$, fPO and $d_j=0$ imply
$$ c_i(b(y))=b_{e_j}(y). $$
EF from type $i$ to type $j$ therefore requires
$$ b_{e_j}(y)\geq d_i $$
almost everywhere on $A_j$. Integrating and using the private supply,
$$ \mu_j=q_{e_j} =\int_{A_j}b_{e_j}(y)\,dy \geq\mu_j d_i. $$
As $\mu_j>0$, we obtain $d_i\leq1$. Hence every $d_i$ belongs to $\{0,1\}$, and
$$ H=\{i:d_i=1\} $$
has total mass $\beta$.

Proof of sufficiency. Given such a subset $H$, assign every type-$i$ agent one private chore $e_i$ and $\mathbf{1}_H(i)$ universal chores. Supplies are correct.

An agent of type $i$ incurs own cost $\mathbf{1}_H(i)$. It evaluates a different type-$j$ agent’s bundle at
$$ 1+\mathbf{1}_H(j). $$
Thus the allocation is EF. Removing any nonnegative-cost chore cannot increase own cost, so EF implies the required EFX condition, including zero-cost removals. Private chores are assigned at zero cost, proving fPO. One cell per type encodes the allocation. $\square$

4.1 Reduction from SUBSET SUM

Use the standard $\mathrm{NP}$-hardness of SUBSET SUM for positive binary integers; this hardness is also stated in [Polak, Rohwedder, and Węgrzycki, *Knapsack and Subset Sum with Small Items*](https://arxiv.org/abs/2105.04035). Membership in $\mathrm{NP}$ follows by verifying a proposed subset.

Take positive integers $a_1,\ldots,a_n$ and a target $B$ with
$$ 0<B<S, \qquad S=\sum_{i=1}^n a_i. $$
Restricting to this range preserves hardness: the excluded cases are decidable directly and can be mapped to fixed yes- or no-instances in the restricted range.

Choose a power of two $R$ satisfying
$$ R>S+B. $$
Introduce $n+1$ types with masses
$$ \mu_i=\frac{a_i}{R}\quad(1\leq i\leq n), \qquad \mu_{n+1}=\frac{R-S}{R}, $$
and set
$$ \beta=\frac{B}{R}. $$
Use the cost matrix and private supplies specified above.

All masses and supplies are dyadic, all masses are positive, and they sum to $1$. The construction has polynomial input length. Furthermore,
$$ \mu_{n+1}>\beta, $$
so a subset with total mass $\beta$ cannot include the added type.

By the lemma, a deterministic solution exists exactly when
$$ \sum_{i\in H}a_i=B $$
for some subset of the original indices. This proves $\mathrm{NP}$-hardness.

The restricted deterministic-existence problem belongs to $\mathrm{NP}$: a subset of types is a polynomial-size certificate, and its mass sum can be checked by exact rational arithmetic. Therefore this restricted problem is $\mathrm{NP}$-complete.

4.2 Why this does not prove unrestricted search hardness

Every instance in this reduction admits a lottery by Section 2, including the no-instances of SUBSET SUM. An unrestricted search algorithm is allowed to return a randomized solution even when a deterministic one exists.

Consequently, deciding whether a deterministic solution exists cannot be recovered merely by inspecting whether an arbitrary returned lottery has one realization. The reduction establishes hardness of the stated restriction only.

5. Remaining target question

The following conclusions are fully proved:

  • Every valid input has an explicitly encodable finite lottery.
  • Existence can therefore be decided by always answering yes on valid inputs.
  • Explicit construction has an unconditional exponential worst-case output requirement.
  • A direct construction runs in time polynomial in the input length and the denominator of the fractional universal supply; integer universal supply admits polynomial-time deterministic construction.
  • Deterministic-solution existence is $\mathrm{NP}$-complete on the restricted dyadic family above.

The remaining gap is a hardness classification for unrestricted explicitly encoded lottery search under a specified search-reduction notion. Neither the exponential output requirement nor the deterministic-existence reduction supplies that classification.
