The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu\), a rational block support matrix \(\rho\), quota \(\kappa\in(0,1)\), and integer \(r\), represent each type as atomless mass, randomly partition the population into \(r\) equal-mass cells, select mass \(\kappa/r\) from each cell by cross-cell indegree, and compute the resulting selection probabilities and expected welfare relative to \(\operatorname{OPT}_\kappa\), while proving unilateral strategyproofness and an approximation guarantee.

Packaged proof task (what the prover saw — nothing else)

Definitions

Let \(T\) be a finite set of atomless types with rational masses \(\mu_t>0\), \(\sum_t\mu_t=1\), and rational support intensities \(\rho_{st}\), where \(\rho_{st}\) is support received per unit mass of type \(t\) from type \(s\).
Randomly give every individual an independent uniform label in \(\{1,\ldots,r\}\); let \(C_c\) be label-\(c\) mass. Thus each \(C_c\) has mass \(1/r\) and type-\(t\) mass \(\mu_t/r\) almost surely. Define cross-cell indegree \(d_{t,c}=\sum_s\rho_{st}\mu(P_s\setminus C_c)\).
In every cell select mass \(\kappa/r\) with greatest \(d_{t,c}\), using a fixed type order and uniform selection within a partially selected atomless type. Let \(p_t\) be a type-\(t\) individual's selection probability and \(W\) the expected welfare under full indegrees \(d_t=\sum_s\mu_s\rho_{st}\).
Set \(\operatorname{OPT}_\kappa=\max\{\sum_t x_td_t:0\le x_t\le\mu_t,\ \sum_t x_t=\kappa\}\). Unilateral strategyproofness means that changing one individual's outgoing-support report does not change that individual's selection probability.

Target

Is exact computation of \((p_t)_{t\in T}\), \(W\), and the approximation ratio \(\operatorname{OPT}_\kappa/W\) for this continuous random-\(r\)-partition mechanism solvable in polynomial time, or NP-hard?

Nearest known results

For finite directed graphs, Random \(m\)-Partition is universally strategyproof; \(2\)-RP has approximation ratio \(4\), and \(\lceil k^{1/3}\rceil\)-RP has ratio \(1+O(k^{-1/3})\).
No result is asserted here for the atomless block-support formulation above.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The selection probabilities and expected welfare are polynomial-time computable. For \(r\ge 2\), the mechanism achieves exactly \(\operatorname{OPT}_\kappa\), so the requested ratio equals \(1\) whenever it is defined. If \(W=0\), the quotient \(\operatorname{OPT}_\kappa/W\) is undefined; an algorithm can report this case exactly.

For the computational statement, assume the quota \(\kappa\) is rational with \(0\le\kappa\le1\), and \(r\) is a positive integer, both given in binary. These are the usual finite-input and feasibility requirements. The proof uses the almost-sure cell-balance property explicitly stipulated in the question.

For every pair of types \(s,t\) and every cell \(c\), that property gives
\[ \mu(P_s\setminus C_c)=\mu_s-\frac{\mu_s}{r}. \]
Consequently,
\[ d_{t,c} =\sum_s\rho_{st}\left(\mu_s-\frac{\mu_s}{r}\right) =\left(1-\frac1r\right)d_t, \qquad d_t=\sum_s\mu_s\rho_{st}. \]
When \(r\ge2\), the multiplier is strictly positive. Thus every cell ranks types by exactly the same full indegrees \(d_t\), with the prescribed type order resolving ties.

Let \(n=|T|\), and let \(\pi(1),\ldots,\pi(n)\) denote this order, so that
\[ d_{\pi(1)}\ge\cdots\ge d_{\pi(n)}. \]
Define
\[ M_j=\sum_{i<j}\mu_{\pi(i)}, \qquad x_{\pi(j)} =\min\!\left\{\mu_{\pi(j)},\max\{0,\kappa-M_j\}\right\}. \]
In each cell, types preceding \(\pi(j)\) have total mass \(M_j/r\), while type \(\pi(j)\) has mass \(\mu_{\pi(j)}/r\). Filling the quota \(\kappa/r\) therefore selects precisely \(x_{\pi(j)}/r\) of this type.

Uniform selection within a partially selected type implies that, conditional on any cell label, a type-\(t\) individual is selected with probability
\[ p_t=\frac{x_t/r}{\mu_t/r}=\frac{x_t}{\mu_t}. \]
This conditional probability is independent of the label, so it is also the unconditional probability. Expected welfare is therefore
\[ W=\sum_t\mu_t p_td_t=\sum_t x_td_t. \]

To prove optimality explicitly, let \(y\) be any feasible allocation in the definition of \(\operatorname{OPT}_\kappa\). Write
\[ X_j=\sum_{i=1}^j x_{\pi(i)}, \qquad Y_j=\sum_{i=1}^j y_{\pi(i)}. \]
The construction gives
\[ X_j=\min\!\left\{\kappa,\sum_{i=1}^j\mu_{\pi(i)}\right\}. \]
Feasibility implies that \(Y_j\) is at most each quantity inside this minimum: the capacity constraints give the second bound, and nonnegativity together with total mass \(\kappa\) gives the first. Hence \(X_j-Y_j\ge0\), and \(X_n-Y_n=0\).

Writing \(a_j=d_{\pi(j)}\), finite summation by parts gives
\[ \sum_{j=1}^n a_j\bigl(x_{\pi(j)}-y_{\pi(j)}\bigr) = \sum_{j=1}^{n-1}(a_j-a_{j+1})(X_j-Y_j) +a_n(X_n-Y_n). \]
Every summand in the first sum is nonnegative, and the final term vanishes. Thus the welfare of \(x\) is at least that of every feasible \(y\). This proves
\[ W=\operatorname{OPT}_\kappa \qquad\text{for }r\ge2. \]
No nonnegativity assumption on the intensities is needed for this argument.

If \(r=1\), all cross-cell indegrees vanish. The mechanism instead fills the quota in the fixed type order. Applying the same formula for \(x_t\) in that order computes \(p_t\) and \(W\). Separately sorting by \(d_t\) and applying the proved optimization argument computes \(\operatorname{OPT}_\kappa\). Thus this case also admits exact polynomial-time computation, although its welfare need not be optimal.

The algorithm uses \(O(n^2)\) rational arithmetic operations to compute the full indegrees, \(O(n\log n)\) rational comparisons to sort, and \(O(n)\) further operations to compute allocations, probabilities, and welfare. All intermediate rational numbers have bit lengths bounded by a polynomial in the total input length: products, sums, comparisons, and the final divisions involve only polynomially many input rationals. In particular, the algorithm never enumerates the \(r\) cells. It computes the ratio by exact division when \(W\ne0\), and detects \(W=0\) exactly.

The zero-denominator qualification is necessary. For example, setting every \(\rho_{st}=0\) gives \(W=\operatorname{OPT}_\kappa=0\). The question supplies no convention for that quotient.

Finally, under the stated atomless interpretation, unilateral strategyproofness follows directly: changing a single individual’s outgoing report changes support only on a singleton of mass zero. For finite, integrable reports, all defining support integrals remain unchanged. Therefore all scores, type allocations, and that individual’s selection probability remain unchanged.
