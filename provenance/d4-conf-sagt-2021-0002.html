The continuous mirror question, as graded

Given a finite seller set \(J\), buyer types \(T\) with rational masses \(\mu_t\geq 0\) summing to \(1\), per-type values \(v_{tj}\), fixed activation costs \(\kappa_j\), and cohort size \(N\), choose assigned masses \(x_{tj}\geq 0\) and activation variables \(y_j\in\{0,1\}\), with \(\sum_j x_{tj}\leq\mu_t\) and \(x_{tj}\leq\mu_ty_j\), to maximize \(N\sum_{t,j}v_{tj}x_{tj}-\sum_j\kappa_jy_j\).

Packaged proof task (what the prover saw — nothing else)

Let \(J\) be a set of \(m\geq1\) uncapacitated sellers. A society is given by its support: a list \(T\) of \(\tau\geq1\) buyer types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has binary-rational values \(v_{tj}\in[0,1]\). Each seller has a nonnegative binary-rational activation cost \(\kappa_j\), independent of the positive mass served; an inactive seller incurs zero cost. The cohort size \(N\geq1\) is a binary-encoded integer.
An allocation consists of divisible masses \(x_{tj}\geq0\) and activation variables \(y_j\in\{0,1\}\), satisfying \(\sum_{j\in J}x_{tj}\leq\mu_t\) and \(x_{tj}\leq\mu_ty_j\). Mass may remain unserved. Its welfare is \(W(x,y)=N\sum_{t\in T,j\in J}v_{tj}x_{tj}-\sum_{j\in J}\kappa_jy_j\).
Given a binary-rational threshold \(B\), let \(L\) denote the total input bit length, including \(N\) and \(B\).

Is deciding whether some feasible allocation has \(W(x,y)\geq B\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite unit-demand buyers, maximizing gains from trade is NP-hard even when each seller's cost is constant on nonempty buyer sets and zero on the empty set ([source](https://arxiv.org/abs/1809.02718v2)). That result concerns indivisible buyers and does not state a complexity classification for the divisible-mass formulation above.

Modeling choices made when packaging the task

  • Restricted values to binary rationals in [0,1], carrying over the discrete model's value normalization.
  • Specified activation costs as nonnegative binary rationals, the natural domain for fixed service costs.
  • Specified the cohort size as a positive binary-encoded integer, corresponding to the discrete number of buyers; normalized masses represent fractions of that cohort.
  • Omitted zero-mass types from the support and required nonempty seller and buyer-type sets.
  • Specified uncapacitated sellers, matching the hardness anchor's fixed-cost setting.
  • Introduced a binary-rational welfare threshold to state the complexity question as a decision problem and included all numerical encodings in the input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when \(N=1\), every value belongs to \(\{0,1\}\), and all activation costs are equal positive dyadic rationals.

1. Eliminating the allocation variables

For an active seller set \(S\subseteq J\), define
\[ a_t(S)=\max\bigl(\{0\}\cup\{v_{tj}:j\in S\}\bigr), \qquad F(S)=N\sum_{t\in T}\mu_ta_t(S)-\sum_{j\in S}\kappa_j. \]

For any allocation whose active set is \(S\), inactive sellers receive no mass. Consequently, for each type \(t\),
\[ \sum_{j\in J}v_{tj}x_{tj} \leq a_t(S)\sum_{j\in S}x_{tj} \leq a_t(S)\mu_t. \]
Thus its welfare is at most \(F(S)\).

This bound is attainable. Whenever \(a_t(S)>0\), assign all of type \(t\)'s mass to a seller attaining that maximum; otherwise leave the type unserved. These assignments are jointly feasible because sellers are uncapacitated. Therefore,
\[ \max_{(x,y)\text{ feasible}}W(x,y)=\max_{S\subseteq J}F(S). \]

Divisibility hence leaves a discrete optimization problem over active seller sets.

2. Membership in \(\mathrm{NP}\)

A certificate is the active set \(S\), encoded by \(m\) bits. The verifier computes \(F(S)\) and checks whether \(F(S)\geq B\).

Computing all maxima takes \(O(m\tau)\) rational comparisons. The subsequent products, sums, and threshold comparison can be performed exactly in polynomial time: multiplying denominators gives a common denominator with polynomial bit length, and the binary encoding of \(N\) contributes only its input bit length. By Section 1, the verifier accepts exactly those instances admitting a feasible allocation of welfare at least \(B\).

3. Polynomial reduction from Vertex Cover

We use the standard \(\mathrm{NP}\)-complete Vertex Cover problem: given an explicitly represented finite simple graph \(G=(V,E)\) and an integer \(k\), decide whether some \(S\subseteq V\) with \(|S|\leq k\) contains an endpoint of every edge. This is Karp’s “Node Cover” problem. [Karp, *Reducibility among Combinatorial Problems*](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Write \(m=|V|\) and \(n=|E|\). We may restrict to \(n\geq1\) and \(0\leq k\leq m\): instances outside these restrictions are immediately decidable and can be replaced by fixed yes- or no-instances satisfying them.

Choose powers of two \(q\) and \(r\) such that \(q\) is the smallest power of two at least \(n\), and \(r\) is the smallest power of two strictly greater than \(m\).

Construct the welfare instance as follows:

  • There is one seller for each vertex, so \(J=V\).
  • There is one type for each edge \(e_i\), so \(\tau=n\).
  • Set \(\mu_i=1/q\) for \(i<n\), and \(\mu_n=(q-n+1)/q\).
  • Set \(v_{ij}=1\) if vertex \(j\) is an endpoint of \(e_i\), and \(v_{ij}=0\) otherwise.
  • Set \(N=1\), \(\kappa_j=\varepsilon=1/(qr)\) for every seller, and \(B=1-k\varepsilon\).

All masses are positive dyadic rationals, each is at least \(1/q\), and their sum is
\[ \frac{n-1}{q}+\frac{q-n+1}{q}=1. \]
Every value belongs to \(\{0,1\}\). Distinct edges have distinct endpoint sets, so the constructed types are distinct even if “support” requires distinct value vectors.

The construction has polynomial size. Indeed, \(q<2n\) and \(r\leq2m\); all numerical parameters require \(O(\log(n+1)+\log(m+1))\) bits, and the value matrix has \(mn\) entries.

4. Correctness of the reduction

For \(S\subseteq V\), let \(C(S)\) be the set of edges having at least one endpoint in \(S\). Section 1 gives
\[ F(S)=\sum_{i:e_i\in C(S)}\mu_i-\varepsilon|S|. \]

If the graph has a vertex cover of size at most \(k\): activate that cover \(S\). Every type then has an active seller of value \(1\), so
\[ F(S)=1-\varepsilon|S| \geq1-\varepsilon k=B. \]
The attaining allocation from Section 1 is a feasible witness.

If the welfare instance admits welfare at least \(B\): let \(S\) be the active set of such an allocation. Section 1 implies \(F(S)\geq B\).

Suppose some edge is uncovered. Its type has mass at least \(1/q\), so nonnegative activation costs imply
\[ F(S)\leq1-\frac1q. \]
But \(k\leq m<r\), and therefore
\[ 1-\frac1q < 1-\frac{k}{qr} =B. \]
This contradicts \(F(S)\geq B\). Hence \(S\) covers every edge.

For a cover, \(F(S)=1-\varepsilon|S|\). Comparing this with \(B=1-\varepsilon k\), and using \(\varepsilon>0\), gives \(|S|\leq k\).

Thus the graph has a vertex cover of size at most \(k\) if and only if the constructed welfare instance admits welfare at least \(B\).

Conclusion

The reduction proves \(\mathrm{NP}\)-hardness, and the active-set certificate proves membership in \(\mathrm{NP}\). Therefore the divisible-mass decision problem is \(\mathrm{NP}\)-complete. A polynomial-time algorithm in \(m,\tau,L\) exists if and only if \(\mathrm{P}=\mathrm{NP}\).
