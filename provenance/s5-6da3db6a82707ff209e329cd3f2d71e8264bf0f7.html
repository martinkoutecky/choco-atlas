The continuous mirror question, as graded

Given a finite simple type graph \(H=(R,F)\), rational type masses \(\mu_r>0\) summing to \(1\), rational edge-mass supplies \(\lambda_e\), and endpoint values \(w_{r,e}\), choose \(x_{e,r},x_{e,s}\ge 0\) with \(x_{e,r}+x_{e,s}=\lambda_e\) for each \(e=\{r,s\}\), and subsidies \(p_r\ge 0\). Define \(U_r=\sum_{e\ni r}w_{r,e}x_{e,r}/\mu_r\), and let \(v_r(b_s)=w_{r,e}x_{e,s}/\mu_s\) when \(e=\{r,s\}\in F\), and \(0\) otherwise. What is the minimum \(\sum_{r\in R}\mu_r p_r\) subject to \(U_r+p_r\ge v_r(b_s)+p_s\) for every ordered pair \(r,s\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_r\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Input also includes a connected finite simple graph \(H=(R,F)\), with \(R\) this support and \(\tau\ge2\), nonnegative rational edge supplies \(\lambda_e\), and rational additive endpoint values \(0\le w_{r,e}\le1\). Nonincident goods have value zero. Let \(m=|F|\) and \(L\) be the total input bit length.
Choose real masses \(x_{e,r},x_{e,s}\ge0\) with \(x_{e,r}+x_{e,s}=\lambda_e\) for each \(e=\{r,s\}\); only endpoints may receive its supply. All individuals of a type receive identical per-capita bundles and subsidies \(p_r\ge0\).
Define \(U_r=\mu_r^{-1}\sum_{e\ni r}w_{r,e}x_{e,r}\). For distinct types, define \(v_r(b_s)=w_{r,e}x_{e,s}/\mu_s\) if \(e=\{r,s\}\in F\), and \(v_r(b_s)=0\) otherwise; set \(v_r(b_r)=U_r\).
Require \(U_r+p_r\ge v_r(b_s)+p_s\) for every ordered pair \((r,s)\in R^2\), including nonadjacent types. Minimize the total subsidy \(\sum_{r\in R}\mu_rp_r\).

Can this minimum subsidy be computed exactly in time polynomial in \(m,\tau,L\), or is the problem NP-hard?

For indivisible edges allocated to endpoints, minimum total subsidy is NP-hard even on simple graphs with additive endpoint values in \(\{1/2,1\}\); deciding whether zero subsidy suffices is NP-complete. With values in \(\{0,1\}\), discrete minimum subsidy is polynomial-time computable. [Source](https://arxiv.org/html/2502.13671v1)

Result

The minimum total subsidy is always \(\boldsymbol{0}\). An optimal rational allocation can be constructed exactly in time polynomial in \(m,\tau,L\).

This holds for every admissible instance, including unequal type masses and heterogeneous endpoint values. The key is to give both endpoints the same per-capita quantity of each edge good.

Construction and feasibility

For each edge \(e=\{r,s\}\), define

\( x_{e,r}=\lambda_e\frac{\mu_r}{\mu_r+\mu_s}, \qquad x_{e,s}=\lambda_e\frac{\mu_s}{\mu_r+\mu_s}. \)

Set \(p_r=0\) for every \(r\in R\).

Since the masses are positive and supplies are nonnegative, these allocations are well-defined and nonnegative. Moreover,

\( x_{e,r}+x_{e,s}=\lambda_e, \qquad \frac{x_{e,r}}{\mu_r} = \frac{x_{e,s}}{\mu_s} = \frac{\lambda_e}{\mu_r+\mu_s}. \)

Thus every supply is allocated entirely to its endpoints, and identical per-capita bundles within each type are obtained by distributing that type’s allocation uniformly.

Fix any ordered pair \((r,s)\). We verify its envy constraint in all three cases.

  • Distinct adjacent types. If \(e=\{r,s\}\in F\), then

\( v_r(b_s) =w_{r,e}\frac{x_{e,s}}{\mu_s} =w_{r,e}\frac{\lambda_e}{\mu_r+\mu_s} =w_{r,e}\frac{x_{e,r}}{\mu_r}. \)

The last expression is exactly the contribution of edge \(e\) to \(U_r\). Every other contribution to \(U_r\) is nonnegative, because both endpoint values and allocated quantities are nonnegative. Consequently,

\( U_r =\frac{w_{r,e}x_{e,r}}{\mu_r} +\frac{1}{\mu_r} \sum_{\substack{f\ni r\\f\ne e}}w_{r,f}x_{f,r} \ge v_r(b_s). \)

  • Distinct nonadjacent types. By the given definition, \(v_r(b_s)=0\). Nonnegativity of every summand defining \(U_r\) gives \(U_r\ge0=v_r(b_s)\).
  • The same type. By definition, \(v_r(b_r)=U_r\), so the constraint holds with equality.

Since all subsidies are zero, these inequalities establish every required constraint \(U_r+p_r\ge v_r(b_s)+p_s\).

Optimality

For every feasible solution, positivity of \(\mu_r\) and nonnegativity of \(p_r\) imply

\( \sum_{r\in R}\mu_rp_r\ge0. \)

The constructed feasible solution achieves this lower bound. Hence the minimum exists and equals \(0\).

Exact computational complexity

To verify that an optimal allocation has polynomial encoding length, write the input rationals for an edge as

\( \mu_r=\frac{a}{b}, \qquad \mu_s=\frac{c}{d}, \qquad \lambda_e=\frac{h}{k}, \)

where \(a,b,c,d,k\) are positive integers and \(h\) is nonnegative. Then the construction becomes

\( x_{e,r}=\frac{had}{k(ad+bc)}, \qquad x_{e,s}=\frac{hbc}{k(ad+bc)}. \)

Every input integer has at most \(L\) bits. Each displayed numerator and denominator therefore has \(O(L)\) bits: a product contains at most three input factors, and the addition increases bit length by at most one. These unreduced fractions already give exact rational outputs; reduction is unnecessary.

Each edge requires a constant number of integer additions and multiplications on integers of \(O(L)\) bits. Standard integer arithmetic consequently constructs all allocations and subsidies in time \(O(m\,\mathrm{poly}(L)+\tau)\), which is polynomial in the requested parameters.

Relation to the indivisible model

The cited [paper](https://arxiv.org/html/2502.13671v1) requires each indivisible edge to be assigned to one endpoint. The proportional split above is available in the continuous model and directly establishes zero subsidy without any restriction beyond the stated hypotheses.
