The continuous mirror question, as graded

Given an explicit finite item database \(D\) and a rational distribution \(\mu\) over \(\tau\) user types, each with an acyclic CP-net \(N_t\), hard filters \(D_t\), and \(\max_X |EF_X| \le k\) for fixed \(k\), construct for each type a consistent GA value function \(v_t\) and report recommendation masses \(x_{t,o} \ge 0\). Require \(\sum_{o \in D_t} x_{t,o} = \mu_t\) and \(x_{t,o} > 0\) only for \(o \in \arg\max_{a \in D_t} v_t(a)\); each person receives an integral item, while \(x\) aggregates mass across tied recommendations.

Conclusion

The construction problem is polynomial-time solvable for every fixed \(k\).

The types impose independent requirements: after constructing a consistent value function for each type, we can assign that type’s entire mass to one maximizing item in its explicitly listed filtered set. Below is a direct construction with integer factor entries of polynomial binary length.

The representation results in the cited paper also apply: its Corollary 2 gives polynomial-time construction under bounded extended families, and Theorem 3 guarantees the required decomposition for acyclic CP-nets. [Brafman, Domshlak, and Kogan](https://arxiv.org/pdf/1207.4126). The proof below is self-contained.

1. Construct local ranks

Set \(B=\max\{2,d\}\). Fix a type \(t\), and choose a topological ordering
\(X_{t,1},\ldots,X_{t,m}\)
of its acyclic dependency graph. Every parent of \(X_{t,i}\) therefore occurs before position \(i\).

For every attribute \(X\) and every assignment \(u\) to its parents \(U_{t,X}\), construct an integer rank function
\(r_{t,X,u}:A_X\longrightarrow\{0,\ldots,|A_X|-1\}\)
such that

\(\displaystyle a\succ_{t,X,u}b\quad\Longrightarrow\quad r_{t,X,u}(a)\ge r_{t,X,u}(b)+1.\)

To construct these ranks, orient each listed comparison from the less preferred value to the more preferred value and topologically sort the resulting graph. A strict partial order has no directed cycle, so such a sorting exists. Assign successive ranks starting at zero.

Any ordering introduced between incomparable values is permitted: consistency requires preservation of stated strict preferences, without requiring preservation of incomparability.

2. Construct the factor tables

For the attribute at position \(i\), define every entry of its factor table by

\(\displaystyle \phi_{t,X_{t,i}}(x,u)=B^{m-i}r_{t,X_{t,i},u}(x).\)

This is a table on exactly \(F_{t,X_{t,i}}=\{X_{t,i}\}\cup U_{t,X_{t,i}}\). Define

\(\displaystyle v_t(o)=\sum_{i=1}^{m}\phi_{t,X_{t,i}}\bigl(o(X_{t,i}),o|_{U_{t,X_{t,i}}}\bigr).\)

All entries are nonnegative integers, which are allowed by the problem’s unrestricted rational-table specification.

3. Prove consistency throughout the full assignment space

Let \(o,o'\) differ only at \(X_{t,i}\), and suppose its conditional preference table ranks \(o(X_{t,i})\) above \(o'(X_{t,i})\).

Their common parent assignment at this attribute is some \(u\). The rank construction gives

\(\displaystyle \phi_{t,X_{t,i}}(o|_{F_{t,X_{t,i}}})-\phi_{t,X_{t,i}}(o'|_{F_{t,X_{t,i}}})\ge B^{m-i}.\)

Every factor at position \(j<i\) is unchanged. Indeed, its own attribute differs from \(X_{t,i}\), and \(X_{t,i}\) cannot be its parent in a topological ordering.

For every position \(j>i\), the factor value lies between zero and \((B-1)B^{m-j}\), since every local rank is at most \(d-1\le B-1\). Consequently, the total possible decrease in all later factors is at most

\(\displaystyle (B-1)\sum_{j=i+1}^{m}B^{m-j}=B^{m-i}-1.\)

It follows that

\(\displaystyle v_t(o)-v_t(o')\ge B^{m-i}-(B^{m-i}-1)=1>0.\)

The geometric-sum identity also holds when \(i=m\), with an empty sum. Thus the constructed value function satisfies every required preference, for arbitrary assignments in the full product space.

This proof uses acyclicity to establish consistency. The family-size bound makes the explicit output tables polynomially large.

4. Construct the masses

For each type \(t\), evaluate \(v_t(o)\) for every \(o\in D_t\). Since \(D_t\) is finite and nonempty, select an item

\(\displaystyle o_t^\star\in\arg\max_{o\in D_t}v_t(o).\)

Set \(x_{t,o_t^\star}=\mu_t\), and set \(x_{t,o}=0\) for every other \(o\in D_t\).

These rational masses are nonnegative, sum to \(\mu_t\), and have positive support only on maximizers. This allocation gives every person of type \(t\) one integral item, namely \(o_t^\star\). Unlimited availability allows different types to select the same item.

No tie splitting is needed, although it is allowed.

5. Running time and binary output size

Because \(F_{t,X}\subseteq EF_{t,X}\), we have \(|F_{t,X}|\le k\) and \(|U_{t,X}|\le k-1\).

Thus each factor table contains at most \(d^k\) entries. Each attribute has at most \(d^{k-1}\) parent contexts. For each context, topological sorting of the explicitly specified local order takes \(O(d^2)\) elementary operations, allowing even a full comparison relation.

After parsing and indexing the input, the operation counts are therefore:

  • Local ranks: \(O(\tau m d^{k+1})\).
  • Weights and factor tables: \(O(\tau m d^k)\) exact arithmetic operations.
  • Database evaluation and maximizer selection: \(O(\tau m|D|)\) exact arithmetic operations.
  • Mass output: \(O(\tau|D|)\) entries.

For the binary-length bound, every factor entry and every complete score is an integer between zero and

\(\displaystyle (B-1)\sum_{i=1}^{m}B^{m-i}=B^m-1.\)

Hence these integers require \(O(1+m\log(d+1))\) bits. The numeric factor output has length

\(\displaystyle O\bigl(\tau m d^k(1+m\log(d+1))\bigr).\)

The mass output uses only zeros and copies of the input masses, so its numeric length is \(O(\tau|D|+L)\).

For example, an indexed-table implementation with schoolbook integer arithmetic has the conservative bit-time bound

\(\displaystyle \widetilde O\!\left((L+\tau m d^{k+1}+\tau m|D|)\bigl(1+L+m\log(d+1)\bigr)^2\right),\)

where \(\widetilde O\) suppresses logarithmic indexing overhead. This is polynomial in the explicitly encoded input length for fixed \(k\).

The entire construction is therefore a polynomial-time algorithm, including production of the rational output.
