The continuous mirror question, as graded

Given a finite set of decisions \(D\), goals \(G\), and a rational-mass distribution \(\mu\) over supported types \(t\), where each type is a complete pair of decision frameworks with trust scores, compute all decisions \(d\) for which no \(d' \ne d\) has \(q_\mu(d',g) \ge q_\mu(d,g)\) for every \(g \in G\), with strict inequality for at least one goal, where \(q_\mu(d,g)=\sum_t \mu_t v_{t,d,g}\) and \(v_{t,d,g}=1\) exactly when \(d\) meets \(g\) in type \(t\)'s trust-resolved joint framework.

Packaged proof task (what the prover saw — nothing else)

Let \(D\) and \(G\) be nonempty finite sets, with \(n=|D|\) and \(k=|G|\). A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational \(\mu_t\), with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type explicitly specifies two frameworks \(F_{t,i}=(D_{t,i},A_{t,i},G_{t,i},B_{t,i},C_{t,i})\), for \(i\in\{1,2\}\), with nonempty finite decision, attribute and goal sets, \(D_{t,1}\cup D_{t,2}=D\), and \(G_{t,1}\cup G_{t,2}=G\). Tables \(B_{t,i}:D_{t,i}\times A_{t,i}\to\{0,1,u\}\) and \(C_{t,i}:G_{t,i}\times A_{t,i}\to\{0,1,u\}\) respectively encode having an attribute and an attribute satisfying a goal; \(u\) means unknown.
Each type also specifies binary-encoded integer trust scores \(T_{t,1}>T_{t,2}\ge0\). Extend absent table cells by \(u\). On the union domains, form joint tables \(B_t,C_t\) by taking agent one's cell whenever it is \(0\) or \(1\), and agent two's cell otherwise.
Write \(A_t=A_{t,1}\cup A_{t,2}\). Set \(v_{t,d,g}=1\) exactly when some \(a\in A_t\) satisfies \(B_t(d,a)=C_t(g,a)=1\), and set it to \(0\) otherwise. Define \(q_\mu(d,g)=\sum_t\mu_t v_{t,d,g}\).
The required output is every \(d\in D\) for which no \(d'\in D\setminus\{d\}\) satisfies \(q_\mu(d',g)\ge q_\mu(d,g)\) for every \(g\in G\), with strict inequality for at least one goal. Include all decisions with tied undominated vectors. Let \(m=\max_t|A_t|\) and let \(L\) be the total binary input length; state running times in \(n,k,m,\tau,L\).

Can this output be computed in polynomial time in \(n,k,m,\tau,L\), or is the problem \(\mathrm{NP}\)-hard?

For two discrete agents, joint dominance—meeting every goal met by any decision—is equivalent to admissibility of the corresponding selection argument in their constructed joint ABA framework; this is a semantic equivalence, not a complexity classification. [Fan et al. (2014)](https://ifmas.csc.liv.ac.uk/Proceedings/aamas2014/aamas/p533.pdf)
That dominance condition is stronger than Pareto undominance. No result settling this exact rational-mass problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, as appropriate for a distribution.
  • Interpreted a complete pair as explicitly supplied framework data, retaining the unknown table value allowed by the discrete definitions.
  • Required each type's decision and goal unions to equal the common sets D and G, making every queried decision-goal pair defined.
  • Retained nonempty decision, attribute and goal sets for each framework, distinct nonnegative integer trust scores, and the higher-trust priority rule; absent cells are unknown.
  • Defined m as the maximum joint attribute-set size and L as the total binary input length.
  • Preserved the graded question's explicit Pareto criterion and retained all tied undominated decisions.

Conclusion

The required output is computable in polynomial time. A conservative running-time bound, including exact arithmetic, is
\[ O\!\left(\tau nkmL+\tau L^2+n^2kL\right). \]
The algorithm computes each type’s Boolean satisfaction matrix, forms exact weighted scores, and checks every ordered pair of decisions for Pareto dominance.

1. Compute each type’s satisfaction matrix

For each supported type \(t\), extend absent table cells by \(u\), as stipulated. For every \(d\in D\), \(g\in G\), and \(a\in A_t\), form
\[ B_t(d,a)= \begin{cases} B_{t,1}(d,a),&B_{t,1}(d,a)\in\{0,1\},\\ B_{t,2}(d,a),&B_{t,1}(d,a)=u, \end{cases} \]
and form \(C_t(g,a)\) by the same rule.

This implements the specified priority exactly. The numerical magnitudes of the trust scores require no further computation: the input guarantees \(T_{t,1}>T_{t,2}\).

Now compute
\[ v_{t,d,g} = \bigvee_{a\in A_t} \left(B_t(d,a)=1\ \text{and}\ C_t(g,a)=1\right). \]
Each entry takes at most \(m\) attribute checks. Thus computing all satisfaction matrices uses \(O(\tau nkm)\) checks. Constructing the joint tables uses \(O(\tau(n+k)m)\) table operations, which is also \(O(\tau nkm)\), because \(n,k\) are positive.

These computations enumerate only the \(\tau\) types explicitly supplied in the support.

2. Represent all weighted scores exactly

Write each input mass as \(\mu_t=p_t/b_t\), where \(p_t,b_t\) are positive binary-encoded integers. Reduction to lowest terms is unnecessary. Set
\[ Q=\prod_{t=1}^{\tau}b_t, \qquad w_t=p_t(Q/b_t). \]
Every \(w_t\) is an integer, and
\[ \frac{w_t}{Q}=\mu_t, \qquad \sum_{t=1}^{\tau}w_t=Q. \]

For every decision and goal, compute the integer
\[ S(d,g)=\sum_{t=1}^{\tau}w_t v_{t,d,g}. \]
By definition,
\[ q_\mu(d,g)=\frac{S(d,g)}{Q}. \]
Since \(Q>0\), comparisons of the required rational scores are exactly comparisons of these integers:
\[ q_\mu(d',g)\ge q_\mu(d,g) \quad\Longleftrightarrow\quad S(d',g)\ge S(d,g). \]
The same equivalence holds for strict inequalities.

The common denominator has polynomial bit length. Indeed,
\[ \log_2 Q=\sum_{t=1}^{\tau}\log_2 b_t, \]
and the total encoded length of the denominators is at most \(L\). Consequently, \(Q\) has \(O(L)\) bits.

Furthermore, positivity of the weights and their sum imply
\[ 0\le w_t\le Q, \qquad 0\le S(d,g)\le Q. \]
Partial sums used to compute \(S(d,g)\) also lie between zero and \(Q\). Thus all score arithmetic uses \(O(L)\)-bit integers; there is no need for approximate arithmetic.

3. Extract precisely the requested decisions

Initially mark no decision as dominated. For each ordered pair \(d,d'\) of distinct decisions, test both conditions
\[ S(d',g)\ge S(d,g)\quad\text{for every }g\in G, \]
and
\[ S(d',g)>S(d,g)\quad\text{for at least one }g\in G. \]
If both conditions hold, mark \(d\) as dominated. After checking every pair, output all unmarked decisions.

Correctness. If a decision is marked, the comparisons in Section 2 show that the decision witnessing its mark satisfies exactly the dominance condition in the question. Therefore, every output decision is undominated.

Conversely, if \(d\) is dominated according to the question, some distinct \(d'\) satisfies those inequalities. The algorithm examines that ordered pair and marks \(d\). Therefore, every undominated decision is output.

Finally, equal score vectors cannot satisfy the strict-inequality condition. Hence all decisions with tied undominated vectors are retained.

4. Running time and classification

Using elementary integer multiplication and division:

  • Computing \(Q\) and all \(w_t\) takes \(O(\tau L^2)\) bit operations.
  • Accumulating all scores takes \(O(\tau nkL)\) bit operations.
  • Checking all ordered pairs takes \(O(n^2kL)\) bit operations.

Input labels can be converted to indices in \(O(L^2)\) time. Conservatively charging \(O(L)\) for table access and index manipulation, constructing the joint tables and satisfaction matrices takes \(O(\tau nkmL)\) time. Because \(\tau,m\ge1\), these bounds together give
\[ O\!\left(\tau nkmL+\tau L^2+n^2kL\right). \]

This is polynomial in the requested parameters. It is also polynomial in total input length, since the sets, attributes, and supported types are explicitly represented.

The supplied ABA semantic equivalence is unnecessary for this algorithm: the requested output follows directly from explicit Boolean witnesses, exact rational sums, and pairwise comparisons.
