The continuous mirror question, as graded

Given a finite school set \(C\), a listed family of regions \(R\subseteq 2^C\), and rational lower-quota fractions \(p_r\), does a nonatomic unit-mass population of one feasibility-relevant type admit an assignment to schools in which each individual receives one whole school place and every region \(r\) receives at least mass \(p_r\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty school set with \(m=|C|\), and let \(R\subseteq 2^C\setminus\{\varnothing\}\) be explicitly listed, with arbitrary overlaps and binary rational lower-quota fractions \(p_r\in[0,1]\). Every school is acceptable to every individual; there are no binding upper quotas.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau=1\) and its mass is \(1\); support size means listed positive-mass types, not the number of possible types.
Represent the nonatomic population by \([0,1]\) with Lebesgue measure \(\lambda\). An assignment is a measurable map \(a:[0,1]\to C\): every individual receives exactly one school place, and individuals of the same type may attend different schools. It is feasible when \(\lambda(a^{-1}(r))\ge p_r\) for every \(r\in R\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,|R|,L\).

Is deciding whether a feasible assignment exists solvable in polynomial time in \(m,\tau,|R|,L\), or is it NP-hard?

For a finite population with all schools acceptable, feasibility with arbitrary overlapping regions is NP-complete even when only minimum quotas are imposed ([Goto et al., 2014](https://www.ifaamas.org/Proceedings/aamas2014/aamas/p1225.pdf)). No result settling exactly the continuous problem above was located in the literature search.

Modeling choices made when packaging the task

  • Required a nonempty school set and nonempty individual regions, consistent with assigning everyone and the discrete region domain.
  • Specified lower-quota fractions in [0,1], encoded as binary rationals.
  • Carried over universal acceptability and interpreted the minimum-only case as having no binding upper quotas.
  • Represented the nonatomic unit-mass society by the Lebesgue unit interval and required measurable assignments.
  • Allowed different individuals of the single type to attend different schools while requiring each individual to receive exactly one school place.
  • Defined L as total binary input length and retained |R| as an explicit running-time parameter.

Result

The continuous feasibility problem is polynomial-time solvable. The essential point is that individuals of the single type may attend different schools: every nonnegative school-mass vector summing to \(1\) can be realized by a measurable assignment.

1. An exact linear formulation

Enumerate the schools as \(C=\{c_1,\ldots,c_m\}\), and write \(k=|R|\). Consider the following rational linear feasibility problem in \(m\) real variables:

\(x_i\ge 0\quad (1\le i\le m),\)

\(\displaystyle \sum_{i=1}^{m}x_i=1,\)

\(\displaystyle \sum_{\{i:c_i\in r\}}x_i\ge p_r\quad (r\in R).\)

We prove that this system is feasible if and only if the assignment problem is feasible.

A feasible assignment gives a feasible vector

Let \(a:[0,1]\to C\) be a feasible measurable assignment, and define

\(x_i=\lambda(a^{-1}(\{c_i\})).\)

Each coordinate is nonnegative. Because every individual receives exactly one school, the measurable sets \(a^{-1}(\{c_i\})\) form a partition of \([0,1]\). Finite additivity of Lebesgue measure therefore gives

\(\displaystyle \sum_{i=1}^{m}x_i=\lambda([0,1])=1.\)

For each region \(r\), its preimage is the disjoint union of the preimages of its schools. Hence

\(\displaystyle \sum_{\{i:c_i\in r\}}x_i=\lambda(a^{-1}(r))\ge p_r.\)

Thus the vector satisfies every constraint.

A feasible vector gives a feasible assignment

Conversely, suppose \(x\) satisfies the linear system. Define cumulative sums

\(s_0=0,\qquad s_i=\sum_{j=1}^{i}x_j\quad (1\le i\le m).\)

Nonnegativity and normalization imply

\(0=s_0\le s_1\le\cdots\le s_m=1.\)

For each \(i\), assign every individual in the half-open interval \([s_{i-1},s_i)\) to \(c_i\). Assign the endpoint \(1\) to \(c_m\).

These intervals partition \([0,1)\); zero-length intervals are simply empty. Thus the rule defines an assignment on all of \([0,1]\). Every school preimage is an interval, possibly with the singleton endpoint added, so the assignment is measurable. Since a singleton has measure zero,

\(\lambda(a^{-1}(\{c_i\}))=s_i-s_{i-1}=x_i.\)

Consequently, for every region,

\(\displaystyle \lambda(a^{-1}(r))=\sum_{\{i:c_i\in r\}}x_i\ge p_r.\)

All schools are acceptable, and there are no binding upper quotas, so there are no additional assignment restrictions to check. The assignment is feasible. This proves the equivalence.

2. Polynomial running time

We use the standard rational linear-programming theorem: feasibility of an explicitly given system of rational linear inequalities can be decided exactly in time polynomial in its dimensions and total binary encoding length. This is the polynomial-time solvability established by [Khachiyan](https://www.mathnet.ru/eng/dan42319). The theorem concerns exact feasibility, including systems whose feasible set has empty interior.

To apply it, replace the normalization equality by two inequalities. The resulting system has:

  • \(m\) variables;
  • \(k+m+2\) inequalities, including nonnegativity;
  • matrix coefficients belonging to \(\{-1,0,1\}\);
  • rational right-hand sides consisting of the input quotas and constants.

Thus every coefficient is rational and explicitly available, as the theorem requires.

A dense encoding of this system has binary length

\(B=O\!\left(L+m(k+m+2)\right).\)

The bound accounts for the input quota encodings and the additional constant-size matrix entries. Constructing this encoding takes polynomial time in the same parameters.

If \(T_{\mathrm{LP}}(n,h,B)\) denotes the running time of a fixed polynomial-time rational linear-feasibility algorithm, the total running time is bounded by

\(O(B)+T_{\mathrm{LP}}(m,k+m+2,B).\)

In particular, it is

\((m+\tau+|R|+L)^{O(1)},\qquad \tau=1.\)

The type description contributes only to reading the input; feasibility uses the school masses alone. Arbitrary overlaps merely determine the zero-one coefficients of the regional constraints.

Therefore the decision problem belongs to \(\mathrm{P}\). An NP-hardness result for this exact problem, under polynomial-time reductions, would imply \(\mathrm{P}=\mathrm{NP}\).

3. Why finite-population hardness does not transfer

The cited finite-population result establishes NP-completeness even with only minimum quotas ([Goto et al., Theorem 2](https://www.ifaamas.org/Proceedings/aamas2014/aamas/p1225.pdf)). Finite students impose integrality restrictions on school counts. The continuous model imposes no such restriction, as the interval construction proves.

A concrete example demonstrates the distinction. Let

\(C=\{c_1,c_2,c_3,c_4\},\qquad R=\{r\subseteq C:|r|=2\},\qquad p_r=\tfrac12\quad(r\in R).\)

The continuous vector \(x_i=\tfrac14\) is feasible: every two-school region receives mass \(\tfrac12\).

Now consider two finite students, with minimum quota one student in every two-school region. These are exactly the same quotas after normalization by population size. Any assignment occupies at most two schools. At least two schools are therefore empty, and their pair is a listed region receiving zero students. The finite instance is infeasible.

Thus continuous feasibility is exactly rational linear feasibility, while the finite model requires integral school counts.
