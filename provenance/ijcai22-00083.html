Classification

Theorem

Under the standard explicit binary encoding of \(C\), \(f\), \(S\), the masses, and the threshold, the weighted approval-type problem is \(\mathrm{NP}\)-complete. It remains \(\mathrm{NP}\)-hard under each metric restriction inherited from the stated unweighted result: path, star, and discrete metrics.

Membership in \(\mathrm{NP}\)

A certificate is a committee \(W\subseteq C\) of size \(k\).

For every \(v\in S\) and \(c\in W\), compute \(d(v,c)=\min_{a\in v}f(a,c)\) by scanning the explicitly represented set \(v\). Then compute \(\max_{c\in W}d(v,c)\) and the rational sum

\(\sum_{v\in S}\mu_v\max_{c\in W}d(v,c)\).

The number of arithmetic operations is polynomial in the input size. Exact addition and multiplication of binary-encoded rationals also take polynomial time: throughout the computation, numerator and denominator bit lengths are bounded by the sum of the input bit lengths. The resulting rational can therefore be compared with \(\theta\) in polynomial time. Hence the problem belongs to \(\mathrm{NP}\).

Aggregation lemma

Consider an unweighted instance with explicitly listed voters \(v_1,\ldots,v_n\). For every committee \(W\), write

\(g_W(v)=\max_{c\in W}\min_{a\in v}f(a,c)\).

Let \(S\) be the set of distinct approval sets occurring among the voters. For each \(v\in S\), let

\(m_v=\left|\{i\in\{1,\ldots,n\}:v_i=v\}\right|\)

and define \(\mu_v=m_v/n\). Then every mass is positive and

\(\sum_{v\in S}\mu_v=\frac{1}{n}\sum_{v\in S}m_v=1\).

Moreover, for every committee \(W\),

\(\sum_{v\in S}\mu_v g_W(v)=\frac{1}{n}\sum_{v\in S}m_vg_W(v)=\frac{1}{n}\sum_{i=1}^{n}g_W(v_i)\).

Thus aggregation preserves the objective exactly up to the constant factor \(1/n\).

Hardness reduction

Take an instance of the stated unweighted utilitarian-max winner-determination problem, with threshold \(B\). Construct the weighted instance using the aggregation lemma and set \(\theta=B/n\). For every committee \(W\) of size \(k\),

\(\sum_{i=1}^{n}g_W(v_i)\leq B\)

holds if and only if

\(\sum_{v\in S}\mu_vg_W(v)\leq B/n=\theta\).

Consequently, the original instance is a yes-instance if and only if the constructed weighted-type instance is a yes-instance.

The construction is polynomial-time: the approval sets can be grouped by their explicit incidence vectors, and each rational mass \(m_v/n\) has \(O(\log n)\) bits. The candidate set, committee size, and metric are unchanged. Therefore every metric restriction in the stated unweighted hardness theorem is preserved.

If the unweighted formulation uses average cost rather than total cost, the same proof applies with \(\theta=B\).

Conclusion

The weighted-type representation does not remove the hardness of the explicitly listed voter formulation: every finite electorate is represented exactly by its normalized histogram of approval types. Together with membership in \(\mathrm{NP}\), this proves \(\mathrm{NP}\)-completeness. In particular, a polynomial-time algorithm exists only if \(\mathrm{P}=\mathrm{NP}\).

The aggregation also preserves \(k\), so the stated \(\mathrm{W}[2]\)-hardness parameterized by \(k\) transfers to the weighted-type formulation.

Step-by-step verification

  • Membership in \(\mathrm{NP}\).

A committee \(W\) is a polynomial-size certificate. Since every approval type \(v\) is explicitly represented, each value
\[ d(v,c)=\min_{a\in v} f(a,c) \]
can be computed by scanning \(v\). Taking the maximum over \(c\in W\) and summing over the explicitly listed types requires polynomially many rational operations.

The bit-complexity assertion is adequate: products and sums of polynomially many binary-encoded rationals have numerator and denominator lengths bounded polynomially by the total input length. Exact comparison with \(\theta\) is therefore polynomial-time.

  • Aggregation identity.

For every distinct approval type \(v\), the multiplicity \(m_v\) is positive and the masses \(\mu_v=m_v/n\) sum to \(1\). The displayed identity
\[ \sum_{v\in S}\mu_v g_W(v) = \frac{1}{n}\sum_{i=1}^n g_W(v_i) \]
is correct for every committee \(W\). No structural property of the metric is changed by this aggregation.

  • Threshold transformation.

For a total-cost threshold \(B\), setting \(\theta=B/n\) gives the exact equivalence
\[ \sum_{i=1}^n g_W(v_i)\leq B \quad\Longleftrightarrow\quad \sum_{v\in S}\mu_v g_W(v)\leq B/n. \]
Thus the existential quantifier over size-\(k\) committees is preserved.

  • Polynomial size and running time.

Grouping explicitly represented approval sets by their incidence vectors is polynomial-time. There are at most \(n\) resulting types, and each mass \(m_v/n\), as well as the scaled rational threshold \(B/n\), has polynomial encoding length.

  • Metric restrictions.

The reduction changes neither \(C\) nor \(f\). Consequently, hardness for path, star, and discrete metrics transfers exactly from the stated unweighted result.

  • Average-cost convention.

The proviso about an unweighted theorem stated using average rather than total cost is correct: if \(B\) already bounds the average, the weighted objective equals that average and the threshold remains \(B\).

  • Parameterized claim.

The reduction preserves \(k\) exactly, so the additional transfer of the stated \(\mathrm{W}[2]\)-hardness is also justified.
