The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), and a finite offer menu of products \(j\) and group sizes \(k\le K\), each type has a strict ranking of offers and a nonempty set of individually rational offers. For each group composition \(a\in\mathbb{Z}_{\ge 0}^{T}\) with \(\sum_t a_t=k\), let \(y_{a,j}\ge 0\) be its group rate per capita. Require \(\sum_{a,j}a_t y_{a,j}=\mu_t\) for every type and permit a composition only when each included type accepts offer \((j,k)\). Find a feasible group-rate vector minimizing the maximum, over all types with \(a_t y_{a,j}>0\), of \(d_t(j,k)\), the number of more-preferred individually rational offers for type \(t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge 1\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge 1\) products, an integer \(K\ge 1\), and an explicitly listed offer menu \(O\subseteq\{1,\ldots,m\}\times\{1,\ldots,K\}\) containing every singleton offer \((j,1)\). Each member buys one unit; preferences depend only on the product and group size, with no payoff transfers.
Each type supplies a strict ranking \(\succ_t\) of \(O\). Let \(b_t\) be its highest-ranked singleton offer. Its individually rational offers are \(A_t=\{o\in O:o=b_t\text{ or }o\succ_t b_t\}\), and \(d_t(o)=|\{o'\in A_t:o'\succ_t o\}|\) for \(o\in A_t\).
For every \((j,k)\in O\), all compositions \(a\in\mathbb Z_{\ge0}^{T}\) with \(\sum_t a_t=k\) are available implicitly. A composition is admissible precisely when \((j,k)\in A_t\) for every \(t\) with \(a_t>0\).
A feasible allocation assigns real group rates \(y_{a,j}\ge0\) to admissible compositions and satisfies \(\sum_{a,j}a_t y_{a,j}=\mu_t\) for every \(t\). Types may split their mass among groups, including groups containing repeated members of the same type. Minimize \(D(y)=\max\{d_t(j,\sum_s a_s):a_t y_{a,j}>0\}\).
Is deciding, for an input integer \(q\ge0\), whether a feasible allocation with \(D(y)\le q\) exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,K\) and the total input bit length \(L\).
For finite societies, a proposal protocol with exhaustive partition search attains the minimum worst distance to ideal under strict offer rankings; this is an optimality guarantee, not a polynomial-time guarantee. Its stated worst-case running time is more than polynomial. [Asselin and Chaib-draa](https://cirano.qc.ca/files/publications/2003s-40.pdf)
No result settling this exact continuous problem was identified in the literature search.

Result

The decision problem is in \(\mathrm{P}\). In fact, every valid instance has minimum objective value \(0\), so every allowed threshold \(q\ge 0\) has answer YES.

The apparent simplification is intrinsic to the stated continuous model: unrestricted repetition of a type within a group, together with real group rates, lets each type independently obtain its ideal offer. To establish that this resolves the whole model, rather than a special case, we first prove a general feasibility characterization.

A feasibility lemma

For each type \(t\), let \(B_t\subseteq O\) be any set of permitted offers. Permit a composition \(a\) at offer \((j,k)\) exactly when
\(\sum_s a_s=k\) and \((j,k)\in B_t\) for every type \(t\) with \(a_t>0\). Retain the mass constraints from the question.

Lemma. With positive masses \(\mu_t\), a feasible allocation exists if and only if every \(B_t\) is nonempty.

Proof. Suppose an allocation is feasible. For each type \(t\),
\(\sum_{a,j}a_t y_{a,j}=\mu_t>0\).
There are finitely many compositions, and all summands are nonnegative. Consequently, some positive summand has \(a_t>0\) and \(y_{a,j}>0\). Its offer must belong to \(B_t\), proving that \(B_t\) is nonempty.

Conversely, suppose every \(B_t\) is nonempty. Choose an offer
\(o_t=(j_t,k_t)\in B_t\).
Let \(e_t\) denote the vector with coordinate \(t\) equal to \(1\) and every other coordinate equal to \(0\). Use the pure composition
\(a^{(t)}=k_t e_t\), with rate
\(y_{a^{(t)},j_t}=\mu_t/k_t\),
and set every other rate to zero.

This composition is available because its coordinates sum to \(k_t\). It is permitted because its only participating type is \(t\), and \(o_t\in B_t\). The selected variables are distinct for distinct types: their composition vectors have different nonzero coordinates.

For any type \(s\), its mass contribution is therefore exactly
\(\sum_{a,j}a_s y_{a,j}=k_s(\mu_s/k_s)=\mu_s\).
All rates are nonnegative, so the allocation is feasible. This proves the lemma.

Application to the objective

For a threshold \(q\), define
\(B_t(q)=\{o\in A_t:d_t(o)\le q\}\).
An allocation satisfies \(D(y)\le q\) exactly when every positive-rate composition uses an offer in \(B_t(q)\) for every participating type. Thus the lemma applies directly.

Because \(O\) is finite and each ranking is strict, every type \(t\) has a unique highest-ranked offer \(o_t^\star=(j_t^\star,k_t^\star)\) in \(O\).

This offer belongs to \(A_t\): either it equals the highest-ranked singleton \(b_t\), or it strictly outranks \(b_t\). Moreover, no offer in \(A_t\) outranks \(o_t^\star\), so
\(d_t(o_t^\star)=0\).
Hence \(B_t(q)\) contains \(o_t^\star\) whenever \(q\ge 0\).

Explicitly, an optimal allocation is
\(y_{k_t^\star e_t,j_t^\star}=\mu_t/k_t^\star\)
for every \(t\), with all other rates zero. The lemma verifies its admissibility and mass constraints. Every participating type receives an offer of distance zero, so its objective value is \(0\).

Finally, distances are cardinalities and therefore nonnegative. Every feasible allocation has at least one participating type because all masses are positive. Its objective is consequently nonnegative. Together with the construction, this proves
\(\min_y D(y)=0\).

Running time and certificate size

Let \(n=|O|\). The menu satisfies \(m\le n\le mK\).

On the promised domain of valid inputs with \(q\ge 0\), the decision algorithm simply returns YES, taking \(\mathrm{O}(1)\) time. An implementation that reads the entire input before answering takes \(\mathrm{O}(L)\) time.

An optimal allocation can also be constructed efficiently:

  • Reading the explicit rankings involves \(\mathrm{O}(\tau n)\subseteq\mathrm{O}(\tau mK)\) offer entries and at most \(\mathrm{O}(L)\) input bits.
  • The construction uses at most \(\tau\) positive-rate compositions, each represented sparsely by its type, product, and group size.
  • If \(\mu_t=p_t/r_t\), its rate can be represented exactly as \(p_t/(r_t k_t^\star)\). Reduction to lowest terms is unnecessary.

For completeness, let \(b_t\) be the bit length of the input denominator \(r_t\), and \(c_t\) the bit length of \(k_t^\star\). Schoolbook multiplication computes \(r_t k_t^\star\) in \(\mathrm{O}(b_t c_t)\) bit operations. Since \(\sum_t b_t\le L\) and \(c_t\le 1+\log_2 K\), constructing all denominators takes
\(\mathrm{O}(L(1+\log_2 K))\) bit operations.

Including reading and sparse output, a bound is
\(\mathrm{O}\bigl(L(1+\log_2 K)+\tau\log_2(1+m+\tau+K)\bigr)\),
and hence \(\mathrm{O}(L^2)\). No enumeration of the implicit compositions is required.

Relation to finite societies

The cited work considers partitions of a finite set of consumers. [Asselin and Chaib-draa](https://cirano.qc.ca/files/publications/2003s-40.pdf) A finite partition must respect the available integer number of consumers of each type. The present model instead explicitly allows every pure composition \(k e_t\) and any real rate \(\mu_t/k\).

Those two permissions eliminate the coupling between types, as the lemma proves. Thus the result settles the exact continuous problem stated here; no additional restriction or alternative interpretation is needed.
