The continuous mirror question, as graded

Fix \(C=\{p,a,b,c\}\). An instance gives binary-rational masses \(\mu_{\succ,w}\) of sincere voter types, each with ranking \(\succ\) and positive integer weight \(w\), and masses \(\nu_w\) of manipulable types with weight \(w\); the masses together sum to \(1\), and the input has support size \(\tau\). For each weight \(w\) and reported ranking \(\pi\), choose \(x_{w,\pi}\ge 0\) with \(\sum_{\pi}x_{w,\pi}=\nu_w\). Define \(M_x(i,j)=\sum_{\succ,w}w\mu_{\succ,w}\sigma_{\succ}(i,j)+\sum_{w,\pi}w x_{w,\pi}\sigma_{\pi}(i,j)\), where \(\sigma_{\rho}(i,j)=1\) if \(\rho\) ranks \(i\) above \(j\), and \(-1\) otherwise. Decide whether a feasible \(x\) makes \(p\) a Copeland\(_1\) co-winner, or, in the unique-winner variant, the sole winner.

Classification

Both the co-winner and unique-winner problems are in \(\mathrm{P}\).

More generally, the algorithm below takes
\(3^{\binom m2}\operatorname{poly}(m!,m,\tau,L)\) bit operations. For \(m=4\), it solves at most \(3^6=729\) rational linear programs, each with \(25\) variables and a constant number of constraints. Thus its running time is \(\operatorname{poly}(\tau,L)\).

1. Aggregate the manipulable weighted mass

Let \(\Pi\) be the set of all \(m!\) strict rankings. Define the sincere margins and total manipulable weighted mass by

\(A(i,j)=\sum_{\succ,w}w\mu_{\succ,w}\sigma_\succ(i,j),\qquad W=\sum_w w\nu_w.\)

For a feasible manipulation, define

\(y_\pi=\sum_w wx_{w,\pi}\qquad(\pi\in\Pi).\)

Then

\(y_\pi\geq0,\qquad \sum_{\pi\in\Pi}y_\pi=W,\)

and the resulting margins are

\(M_y(i,j)=A(i,j)+\sum_{\pi\in\Pi}y_\pi\sigma_\pi(i,j).\)

Conversely, every vector satisfying these nonnegativity and total-weight constraints comes from a feasible manipulation.

Indeed, if \(W>0\), set, for each listed manipulable weight,

\(x_{w,\pi}=\nu_w\frac{y_\pi}{W}.\)

These masses are nonnegative and satisfy

\(\sum_\pi x_{w,\pi}=\nu_w\frac{\sum_\pi y_\pi}{W}=\nu_w.\)

Moreover,

\(\sum_w wx_{w,\pi}=\frac{y_\pi}{W}\sum_w w\nu_w=y_\pi.\)

If \(W=0\), positivity of the listed weights and masses implies that there are no manipulable types. The constraints on \(y\) force every coordinate to be zero, which represents that case correctly.

Consequently, the attainable margin vectors are exactly those generated by the simplex
\(\{y\in\mathbb R_{\geq0}^{m!}:\sum_\pi y_\pi=W\}\).
This equivalence preserves every type’s weight and mass.

2. Enumerate pairwise outcomes

Fix an arbitrary ordering of the candidates and put \(d=\binom m2\). Enumerate all \(3^d\) assignments

\(s(i,j)\in\{-1,0,1\}\qquad(i<j),\)

where a positive sign means that \(i\) defeats \(j\), zero means a pairwise tie, and a negative sign means that \(i\) loses. Extend each assignment antisymmetrically by \(s(j,i)=-s(i,j)\).

Under Copeland\(_1\), a candidate receives one point for either a victory or a tie and zero points for a defeat. Therefore the score determined by a sign assignment is

\(S_s(i)=\sum_{j\neq i}\mathbf 1\{s(i,j)\geq0\}.\)

For the co-winner problem, retain precisely those assignments satisfying

\(S_s(p)\geq S_s(c)\qquad\text{for every }c\neq p.\)

For the unique-winner problem, retain precisely those satisfying

\(S_s(p)>S_s(c)\qquad\text{for every }c\neq p.\)

These tests take \(O(m^2)\) time per assignment. What remains is to decide whether a retained assignment is attainable.

3. Test attainability, including strict margins

For a retained assignment \(s\), introduce the variables \(y_\pi\) and one additional variable \(\delta\). Solve the following rational linear program:

Maximize \(\delta\), subject to

\(y_\pi\geq0\quad(\pi\in\Pi),\qquad \sum_{\pi\in\Pi}y_\pi=W,\qquad 0\leq\delta\leq1,\)

and, for each \(i<j\), the appropriate constraint:

| Prescribed sign | Constraint |
|---|---|
| \(s(i,j)=1\) | \(A(i,j)+\sum_\pi y_\pi\sigma_\pi(i,j)\geq\delta\) |
| \(s(i,j)=0\) | \(A(i,j)+\sum_\pi y_\pi\sigma_\pi(i,j)=0\) |
| \(s(i,j)=-1\) | \(A(i,j)+\sum_\pi y_\pi\sigma_\pi(i,j)\leq-\delta\) |

Reject an infeasible program. Otherwise, accept this assignment exactly when its optimum satisfies \(\delta^*>0\).

Proof of the attainability test

Suppose first that some feasible aggregate vector \(y\) realizes the prescribed signs. If at least one prescribed sign is nonzero, define

\(\varepsilon=\min_{\substack{i<j\\s(i,j)\neq0}}|M_y(i,j)|.\)

Every quantity in this finite minimum is strictly positive, so \(\varepsilon>0\). Taking \(\delta=\min\{1,\varepsilon\}\) satisfies every constraint. Thus \(\delta^*>0\).

If all prescribed signs are zero, the same aggregate vector satisfies the program with \(\delta=1\), so again \(\delta^*>0\).

Conversely, any feasible solution with \(\delta>0\) has strictly positive margins on the prescribed positive pairs, strictly negative margins on the prescribed negative pairs, and exactly zero margins on the prescribed ties. It therefore realizes precisely \(s\). Section 1 converts its aggregate vector into a feasible manipulation.

Finally, the program’s feasible region is closed and bounded: each \(y_\pi\) belongs to \([0,W]\), and \(\delta\) belongs to \([0,1]\). Hence every feasible program attains its optimum. This proves the claimed equivalence.

4. Correctness of the decision algorithm

If a successful manipulation exists, its margins define one of the enumerated sign assignments. Its scores satisfy the applicable winner test, so that assignment is retained. Its attainability program has positive optimum by Section 3, and the algorithm accepts.

Conversely, if the algorithm accepts, an accepted program supplies an attainable sign assignment satisfying the applicable winner test. The reconstruction in Section 1 yields a feasible manipulation with exactly those margins. Thus \(p\) is a co-winner or the unique winner, respectively.

Both directions hold also when there are no manipulable types.

5. Binary encoding and running time

Computing \(A\) and \(W\) requires \(O(\tau m^2)\) rational arithmetic operations. Their encoding lengths remain polynomial in \(L\). Explicitly, a common denominator can be obtained by multiplying the denominators of all input masses; its bit length is at most their total input bit length. After clearing that denominator, multiplication by the binary weights and summation over the support produce integers of bit length \(O(L+\log\tau)\).

Each attainability program has \(m!+1\) variables and \(O(m!+m^2)\) constraints. All coefficients are rational, and its total encoding length is polynomial in \(m!,m,L\). Rational linear programming permits exact feasibility determination and exact optimization in time polynomial in the binary encoding length; see [Trevisan’s linear-programming notes, Section 5.2.5](https://theory.stanford.edu/~trevisan/books/cs261.pdf#page=44). The programs here meet these hypotheses, and feasible instances have bounded objectives. Consequently, comparing the exact rational optimum with zero is a polynomial-time operation.

Including preprocessing, enumeration, and optimization gives the bound

\(3^{\binom m2}\operatorname{poly}(m!,m,\tau,L).\)

For \(m=4\), there are at most \(729\) programs with \(25\) variables each, so both decision problems are polynomial-time solvable in the stated binary input model.
