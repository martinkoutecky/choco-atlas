The continuous mirror question, as graded

Given a finite set of interchangeable witness types \(T\), rational masses \(\mu_t\) summing to one, and indicators \(a_t\) specifying which types are selected for a reputation query, compute the normalized directed pair-query mass \(\lambda_{tu}=a_ta_u\mu_t\mu_u\) for each type pair and its total \(\Lambda=\sum_{t,u}\lambda_{tu}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) interchangeable witness types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
Each type represents an atomless population of witnesses. An input indicator \(a_t\in\{0,1\}\) specifies whether all witnesses of type \(t\) are selected for the reputation query; the selected population may be empty.
The protocol queries every ordered pair of distinct selected witnesses. Distinct witnesses may have the same type; individual self-pairs have zero product mass, so type pairs \((t,t)\) are included.
The required outputs are the exact binary rational values \(\lambda_{tu}=a_ta_u\mu_t\mu_u\) for every \((t,u)\in T\times T\), and \(\Lambda=\sum_{t,u\in T}\lambda_{tu}\). Normalization is relative to the entire society, without conditioning on selection.

Can this exact computation be performed in time polynomial in \(\tau\) and \(L\), or is it NP-hard?

For a finite selected witness set \(W\), the additional communication cost of querying witness pairs is \(O(|W|^2)\). [Bonnet (2012)](https://doi.org/10.3233/978-1-61499-098-7-187)
No result settling this exact mass-output problem was identified in the literature search.

Modeling choices made when packaging the task

  • Interpreted each type mass as an atomless population, preserving the exclusion of individual self-queries while retaining queries between distinct witnesses of the same type.
  • Specified selection indicators as binary and selection as applying to the entire type; allowed empty selection because the discrete protocol imposes no nonemptiness requirement.
  • Interpreted normalization relative to total society mass, without renormalizing the selected population.
  • Specified exact binary rational output and total input bit length L. The problem has no separate candidate parameter m or other independent parameters.

Result

The exact mass-output problem is polynomial-time solvable. Under the standard encoding of rational numbers by binary numerators and denominators, a direct algorithm takes \(O(\tau^2L^3)\) bit operations, including reduction of every output fraction to lowest terms.

1. The total queried mass

Write each input mass as \(\mu_t=p_t/q_t\), where \(p_t\) and \(q_t\) are positive integers given in binary. Define the selected mass by \(S=\sum_{t\in T}a_t\mu_t\).

By the required definition of the outputs and distributivity of finite sums,

\(\displaystyle \Lambda=\sum_{t\in T}\sum_{u\in T}a_ta_u\mu_t\mu_u=\left(\sum_{t\in T}a_t\mu_t\right)^2=S^2.\)

The sum includes the terms with \(t=u\), as required. Distinct witnesses of the same type contribute to those terms; the problem explicitly stipulates that individual self-pairs have zero product mass.

If selection is empty, then \(S=0\), every \(\lambda_{tu}=0\), and \(\Lambda=0\). No conditioning or division by the selected mass is needed.

2. An exact algorithm

First, for every ordered pair \((t,u)\in T\times T\):

  • If \(a_ta_u=0\), output \(\lambda_{tu}=0/1\).
  • Otherwise, form \(\lambda_{tu}=(p_tp_u)/(q_tq_u)\), and divide its numerator and denominator by their greatest common divisor.

To compute \(\Lambda\), form the common denominator \(Q=\prod_{t\in T}q_t\) and the integer \(P=\sum_{t\in T}a_tp_t(Q/q_t)\). Every division \(Q/q_t\) is exact because \(q_t\) is a factor of \(Q\).

Consequently, \(P/Q=S\). Output \(\Lambda=P^2/Q^2\), reduced to lowest terms, using \(0/1\) when \(P=0\).

These constructions give precisely the required pair masses and total mass.

3. Bit complexity and output size

For a positive integer \(n\), let \(b(n)=\lfloor\log_2 n\rfloor+1\) be its binary length. Because \(L\) is the total input bit length, the combined lengths of the input numerators and denominators are at most \(L\).

For each pair, multiplication produces integers satisfying \(b(p_tp_u)\leq b(p_t)+b(p_u)\leq 2L\) and \(b(q_tq_u)\leq 2L\). Reducing the fraction cannot increase these lengths.

The common denominator also has polynomial size: \(b(Q)\leq\sum_{t\in T}b(q_t)\leq L\). Moreover, the normalization assumption gives the exact integer identity

\(\displaystyle \sum_{t\in T}p_t(Q/q_t)=Q.\)

All summands are positive, and each indicator belongs to \(\{0,1\}\). Thus \(0\leq P\leq Q\). Every partial sum used to construct \(P\) is also at most \(Q\). Therefore all integers involved in constructing \(P,Q,P^2,Q^2\) have \(O(L)\) bits.

Schoolbook multiplication and division of integers with \(O(L)\) bits take \(O(L^2)\) bit operations. The Euclidean algorithm uses \(O(L)\) divisions on such integers, giving the sufficient bound \(O(L^3)\) for each greatest-common-divisor computation.

It follows that:

  • Computing and reducing the \(\tau^2\) pair outputs costs \(O(\tau^2L^3)\).
  • Constructing \(Q\) and \(P\), then computing and reducing \(\Lambda\), costs \(O(\tau L^2+L^3)\).
  • Writing all outputs costs \(O(\tau^2L)\), since each fraction has \(O(L)\) bits.

The total running time is therefore \(O(\tau^2L^3)\), polynomial in both parameters.

4. Conclusion

The prescribed computation consists entirely of exact rational arithmetic on numbers whose bit lengths remain polynomially bounded. The finite-witness communication cost does not obstruct this algorithm: the required outputs aggregate population mass by the explicitly listed witness types.

This establishes polynomial-time solvability. No literature result or complexity assumption is needed.
