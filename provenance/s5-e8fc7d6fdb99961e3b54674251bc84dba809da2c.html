The continuous mirror question, as graded

Given \(M\) schools, a finite set \(T\) of complete normalized utility types \(v^t\in[0,1]^M\), rational type masses \(\mu_t\ge 0\) summing to \(1\), and rational per-capita capacities \(\bar q_j\ge 0\) with \(\sum_j\bar q_j\ge 1\), compute an assignment maximizing \(\sum_{t\in T}\mu_t(v^t\cdot x_t)\), where each type receives a lottery \(x_t\in\Delta^M\), subject to \(\sum_t\mu_t x_{tj}\le\bar q_j\) for every school \(j\) and \(v^t\cdot x_t\ge v^t\cdot x_s\) for every pair \(t,s\in T\).

Packaged proof task (what the prover saw — nothing else)

There are \(M\ge 1\) schools. A society is given by its support: a nonempty list \(T\) of \(\tau\) distinct utility types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each complete utility vector \(v^t\in\mathbb{Q}^M\cap[0,1]^M\) either satisfies \(\min_j v^t_j=0\) and \(\max_j v^t_j=1\), or is the zero vector representing complete indifference; utility ties are allowed. Capacities \(\bar q_j\in\mathbb{Q}_{\ge0}\) satisfy \(\sum_j\bar q_j\ge1\). Let \(L\) be the total binary encoding length of the input.
An assignment gives each type a lottery \(x_t\in\Delta^M\). It must satisfy \(\sum_{t\in T}\mu_t x_{tj}\le\bar q_j\) for every school and \(v^t\cdot x_t\ge v^t\cdot x_s\) for every ordered pair \(t,s\in T\); these inequalities define exact envy-freeness.
Compute any assignment maximizing \(\sum_{t\in T}\mu_t(v^t\cdot x_t)\) subject to these conditions; no selection among tied maximizers is prescribed.

Is this exact welfare-maximization problem solvable in time polynomial in \(M,\tau,L\), or is it NP-hard?

For a finite list of students, welfare maximization over capacity-feasible, envy-free lotteries is a convex program for concave welfare: every local maximum is global, and strictly concave welfare gives a unique maximizing expected-utility vector. With linear welfare, the finite-student problem is a linear program.

Modeling choices made when packaging the task

  • Utility encoding was unspecified; require binary-rational utility coordinates and include their encoding in L.
  • Normalized utilities were unspecified beyond membership in [0,1]^M; require minimum zero and maximum one for nonconstant types, and use the zero vector for complete indifference.
  • Remove zero-mass types so the supplied list is exactly the positive-mass support.
  • Specify positive school and support counts; allow utility ties and accept any maximizing assignment without a tie-breaking rule.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is solvable exactly in time polynomial in \(M,\tau,L\). The explicitly listed support gives a linear program of polynomial size.

1. Exact linear-program formulation. Introduce a real variable \(x_{tj}\) for every \(t\in T\) and school \(j\in\{1,\ldots,M\}\). Maximize
\(\displaystyle \sum_{t\in T}\sum_{j=1}^{M}\mu_t v^t_jx_{tj}\)
subject to:

  • Nonnegativity: \(x_{tj}\ge 0\) for every \(t,j\).
  • Lottery normalization: \(\sum_{j=1}^{M}x_{tj}=1\) for every \(t\).
  • Capacity feasibility: \(\sum_{t\in T}\mu_tx_{tj}\le\bar q_j\) for every \(j\).
  • Exact envy-freeness: \(\sum_{j=1}^{M}v^t_j(x_{tj}-x_{sj})\ge0\) for every distinct \(t,s\in T\).

The first two families say exactly that \(x_t\in\Delta^M\). The third is precisely the capacity condition. The fourth is precisely the stated envy condition; pairs with \(t=s\) give identities and can be omitted. The objective is the stated welfare. Consequently, feasible solutions and maximizers of this linear program are exactly the requested assignments and welfare maximizers.

All coefficients are fixed input numbers or their products. Utility ties and zero utility vectors therefore cause no difficulty: they simply make some inequalities redundant.

2. Feasibility and attainment. Let \(Q=\sum_{j=1}^{M}\bar q_j\), so \(Q\ge1\). Give every type the same lottery,
\(x_{tj}=\bar q_j/Q\).

Its entries are nonnegative and sum to one. For each school,
\(\sum_{t\in T}\mu_tx_{tj}=(\bar q_j/Q)\sum_{t\in T}\mu_t=\bar q_j/Q\le\bar q_j\).
Because every type receives the same lottery, every envy inequality holds with equality. Thus the linear program is feasible.

Its feasible set is closed and contained in the bounded set \(\prod_{t\in T}\Delta^M\), hence compact. The linear objective is continuous, so a maximizer exists.

3. Polynomial encoding size. There are \(n=\tau M\) variables, \(\tau\) normalization equalities, \(M\) capacity inequalities, \(\tau(\tau-1)\) envy inequalities, and \(\tau M\) nonnegativity inequalities. These counts are polynomial in \(M,\tau\).

Constraint coefficients belong to the families \(0,\pm1,\mu_t,\pm v^t_j\). Objective coefficients are \(\mu_tv^t_j\). Multiplying two binary-encoded rational numbers increases numerator and denominator bit lengths by at most their respective sums, up to a constant. Every coefficient therefore has bit length \(O(L+1)\). Even a dense encoding of the entire linear program has length polynomial in \(M,\tau,L\), and exact rational arithmetic constructs it in polynomial time.

Crucially, the envy constraints range over the explicitly supplied support \(T\), whose size is \(\tau\). No enumeration of other possible utility types is required.

4. Exact polynomial-time optimization. Apply the standard rational linear-programming theorem: an explicitly encoded rational linear program can be solved in time polynomial in its binary encoding length, returning an exact rational optimizer whenever its optimum is finite and attained. This is a bit-complexity theorem, rather than merely an approximation guarantee; the ellipsoid method establishes it. See [MIT’s linear-programming lecture, Sections 3.12 and 4](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

Here the data are rational, the encoding length is polynomial, and feasibility and attainment were proved above. The theorem therefore returns an exact welfare-maximizing assignment in time polynomial in \(M,\tau,L\). If several maximizers exist, any optimizer returned by the algorithm satisfies the task.
