The continuous mirror question, as graded

Given a finite set of complete participant types \(T=P\cup A\) with positive rational masses \(\mu_t\), type-level compatibility edges and reduced costs \(r_{tu}\), and a chain cap \(K\), decide whether there is a feasible positive-mass allocation of chain templates \(Q=(a,t_1,\ldots,t_\ell)\), with \(\ell\le K\), whose total reduced cost is negative. Each template starts at an altruist type and follows compatible edges through pair types; its mass must count against the capacity of every type occurrence.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T=P\sqcup A\) of \(\tau\) complete participant types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(P\) consists of incompatible patient–donor pair types and \(A\) of altruistic donor types; \(\tau\) counts supported types, not all possible types.
Compatibility and costs depend only on types. Input includes a loopless directed graph \(E\subseteq(T\times P)\), arbitrary signed binary-rational reduced costs \(r_{tu}\), and a positive integer chain cap \(K\) encoded in binary. Put \(m=|E|\), and let \(L\) be the total input bit length.
A template is \(Q=(a,t_1,\ldots,t_\ell)\), with \(a\in A\), \(t_i\in P\), \(1\le\ell\le K\), and every consecutive edge in \(E\). Pair types may recur, representing distinct participants of the same type; \(K\) counts edges and is not bounded by \(\tau\).
Writing \(q_0=a\) and \(q_i=t_i\), define \(c(Q)=\sum_{i=1}^{\ell}r_{q_{i-1}q_i}\). Reduced costs already include the altruist's charge on the first edge; no additional endpoint charge is imposed.
An allocation assigns real masses \(x_Q\ge0\) to templates. With \(n_t(Q)\) counting all occurrences of type \(t\), including the starting altruist, feasibility means \(\sum_Q n_t(Q)x_Q\le\mu_t\) for every \(t\). Unused mass is allowed.
The decision problem asks whether such an allocation satisfies \(\sum_Qx_Q>0\) and \(\sum_Qc(Q)x_Q<0\).

Is this continuous negative-chain allocation problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L\), and \(\log(K+1)\).

For finitely many individual participants, deciding whether a negative-cost chain starts at an altruist, uses at most \(K\) edges, and visits each participant at most once is \(\mathrm{NP}\)-complete ([Plaut–Dickerson–Sandholm](https://arxiv.org/pdf/1606.00117)).
No result settling exactly the continuous problem defined here was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total mass to one to represent a distribution over types.
  • Allowed repeated pair types as distinct participants, charging mass once per occurrence; individual simplicity does not require distinct types.
  • Excluded self-type compatibility edges because complete incompatible patient–donor types cannot donate to recipients of their own type.
  • Specified arbitrary signed binary-rational reduced costs, with the altruist charge already incorporated into the first edge.
  • Specified binary encoding of the positive chain cap, counting edges without a support-size bound.
  • Specified nonnegative real allocation masses, optional unused capacity, and strict positivity and negativity thresholds.
  • Defined m as the number of compatibility edges and L as the total input bit length.

Result

The continuous negative-chain allocation problem is in \(\mathrm{P}\).

Put \(b=\lceil\log_2(K+1)\rceil\). An exact algorithm uses
\(O(m+\tau^3b)\) arithmetic operations. With elementary integer arithmetic, its bit running time is
\(O\!\left(L+mL^2+\tau^3b(L+b)\right)\),
and its space usage is
\(O\!\left(L+\tau^2(L+b)\right)\) bits.

The proof uses both stipulated features: pair types may recur, and arbitrarily small positive allocation masses are permitted.

1. Reduction to a single negative template

Let \(\mathcal Q_K\) denote the set of admissible templates. This set is finite because the supported type set and the cap \(K\) are finite.

We claim that a qualifying allocation exists if and only if some \(Q\in\mathcal Q_K\) satisfies \(c(Q)<0\).

For the forward implication, suppose an allocation satisfies
\(\sum_{Q\in\mathcal Q_K}c(Q)x_Q<0\).
Since every \(x_Q\) is nonnegative, at least one summand must be negative. Its template therefore has \(c(Q)<0\).

Conversely, suppose \(Q\) is a negative-cost template. Define
\(\mu_{\min}=\min_{t\in T}\mu_t>0\)
and assign only this template the mass
\(x_Q=\mu_{\min}/(K+1)\).
Set every other allocation variable to zero.

A template contains at most \(K+1\) type occurrences, including its starting altruist. Hence, for every \(t\in T\),
\(n_t(Q)x_Q\le (K+1)x_Q=\mu_{\min}\le\mu_t\).
The allocation is feasible, has positive total mass, and has total cost
\(c(Q)x_Q<0\).

Thus the mass constraints do not obstruct existence of a negative template. They determine how much mass can be assigned to it.

2. Exact bounded-walk computation

Write each edge cost as \(r_{tu}=p_{tu}/d_{tu}\), where \(p_{tu}\) is an integer and \(d_{tu}\) is a positive integer. Define the common positive denominator
\(D=\prod_{(t,u)\in E}d_{tu}\)
and integer edge weights
\(w_{tu}=Dr_{tu}\).
Multiplication by \(D>0\) preserves every template’s cost sign.

Index matrices by \(T\). Define the matrix \(M\) by

\(M_{tu}=\begin{cases} 0,&t=u,\\ w_{tu},&(t,u)\in E,\\ +\infty,&\text{otherwise}. \end{cases}\)

The cases are disjoint because \(E\) is loopless. The diagonal entries are artificial zero-cost waiting steps.

For matrices with entries in \(\mathbb Z\cup\{+\infty\}\), define min-plus multiplication by

\((U\otimes V)_{tu}=\min_{v\in T}(U_{tv}+V_{vu})\),

with \(+\infty+z=+\infty\). Its identity matrix \(I\) has diagonal entries zero and other entries \(+\infty\). Write \(M^{\otimes j}\) for the corresponding power, with \(M^{\otimes0}=I\).

We now prove the interpretation of these powers.

For every nonnegative integer \(j\), the entry
\((M^{\otimes j})_{tu}\)
is the minimum integer cost of an original-graph walk from \(t\) to \(u\) using at most \(j\) edges, allowing the empty walk when \(t=u\). If no such walk exists, the entry is \(+\infty\).

Indeed, first regard \(M\) as the adjacency-cost matrix of the graph augmented with the artificial waiting steps. The assertion that its \(j\)-th min-plus power gives minimum costs of augmented walks of exactly \(j\) steps follows by induction:

  • For \(j=0\), it is precisely the definition of \(I\).
  • An augmented walk of \(j+1\) steps splits into a walk of \(j\) steps ending at some \(v\), followed by one step. Minimizing over \(v\) gives the defining matrix product.

Deleting waiting steps from an augmented walk produces an original walk with at most \(j\) edges and identical cost. Conversely, any original walk with at most \(j\) edges can be padded with waiting steps to exactly \(j\) steps. This proves the claimed interpretation.

Because every original edge has its target in \(P\), an original walk starting in \(A\) has all subsequent vertices in \(P\). Repeated pair types are permitted. Consequently, original walks from \(A\) to \(P\) with at most \(K\) edges are exactly the admissible templates.

It follows that a negative template exists if and only if

\(\min_{a\in A,\;u\in P}(M^{\otimes K})_{au}<0.\)

There is no empty-walk ambiguity here: \(A\) and \(P\) are disjoint. If either set is empty, the minimum is defined as \(+\infty\), and the answer is no.

3. Binary exponentiation and bit complexity

Min-plus multiplication is associative. Explicitly, either parenthesization of a product of three matrices gives the entry

\(\min_{v,z\in T}(U_{tv}+V_{vz}+W_{zu})\).

Therefore binary exponentiation computes \(M^{\otimes K}\) using \(O(b)\) matrix products. Each dense product uses \(O(\tau^3)\) additions and comparisons. Matrix construction and denominator conversion use \(O(m+\tau^2)\) arithmetic operations, giving the stated total
\(O(m+\tau^3b)\).

It remains to bound operand lengths; counting arithmetic operations alone would not establish polynomial time.

The total encoding length of the edge numerators and denominators is at most \(L\). Thus \(D\), and every scaled weight \(w_{tu}\), have \(O(L)\) bits. Let

\(W=\max\bigl(\{1\}\cup\{|w_{tu}|:(t,u)\in E\}\bigr).\)

Every finite entry of a power representing at most \(j\) original edges lies between \(-jW\) and \(jW\). Binary exponentiation can avoid the final unused squaring, so all exponents computed are at most \(K\). Consequently, all finite entries and candidate sums have
\(O(L+b)\) bits.

Each min-plus addition or comparison therefore costs \(O(L+b)\) bit operations. Using elementary multiplication and division, constructing \(D\) and the scaled weights costs \(O(mL^2)\) bit operations. Including input reading, the total is

\(O\!\left(L+mL^2+\tau^3b(L+b)\right).\)

Only a constant number of matrices are needed, giving
\(O\!\left(L+\tau^2(L+b)\right)\) bits of space. Since the binary encoding of \(K\) is included in \(L\), we have \(b\le L\). These bounds are polynomial in the input length.

4. Why the chain cap cannot simply be truncated

Allowing repeated types does not mean a negative template always has length bounded by \(\tau\).

For example, take \(A=\{a\}\), \(P=\{u,v\}\), masses
\(\mu_a=1/2\) and \(\mu_u=\mu_v=1/4\), and only the edges

\(a\to u\) of cost \(H\), \(u\to v\) of cost \(0\), and \(v\to u\) of cost \(-1\),

where \(H\) is a positive integer.

There is exactly one template of each positive length \(\ell\), and its cost is

\(H-\left\lfloor(\ell-1)/2\right\rfloor.\)

Its cost first becomes negative at length \(2H+3\). Choosing \(H=2^h\) makes the first negative-template length exponential in \(h\), although \(\tau=3\) and the cost has only \(O(h)\) bits. Binary exponentiation handles precisely this possibility.

The cited finite-participant problem requires a chain to visit each participant at most once. That restriction is explicit in [Plaut–Dickerson–Sandholm’s definition and hardness theorem](https://arxiv.org/pdf/1606.00117). Here, repeated types are admissible and can be assigned sufficiently small mass, so the required computation is a bounded-walk computation.
