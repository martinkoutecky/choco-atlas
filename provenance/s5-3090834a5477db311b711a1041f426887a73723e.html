The continuous mirror question, as graded

Given a rational distribution \(\mu\) over patient-donor pair types \(t=X-Y\in(\{0,1\}^3)^2\), let \(D(\mu)=\sum_{Y\ge X}\mu_{X-Y}\) be the mass of left-lobe-compatible pairs, which receive direct transplants. Let \(E\) be the set of feasible unordered two-way exchange patterns between incompatible pair types, with \(X-Y\) and \(V-W\) exchangeable when \(Y\ge V\) and \(W\ge X\). For each \(e\in E\), choose exchange mass \(x_e\ge0\), subject to \(\sum_{e\in E}a_{t,e}x_e\le\mu_t\) for every type \(t\), where \(a_{t,e}\) counts the type-\(t\) pairs used by pattern \(e\). Compute a feasible \(x\) maximizing \(D(\mu)+2\sum_{e\in E}x_e\), the total mass of pairs receiving transplants.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) patient–donor pair types with positive mass, each mass a binary rational. Masses sum to \(1\); \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\), where the number of individual types is fixed at \(m=8\).
Individual types are vectors in \(\{0,1\}^3\): the first two coordinates indicate absence of the A and B antigens, and the third indicates large rather than small size. A pair type \(X-Y\) records patient type \(X\) and donor type \(Y\). Left-lobe compatibility means \(Y\ge X\) coordinatewise.
All compatible pairs receive direct transplants and cannot participate in exchange. Their total mass is \(D(\mu)=\sum_{Y\ge X}\mu_{X-Y}\). Only left-lobe donations and two-way exchanges are allowed; there are no chains or unpaired donors.
Let \(E\) contain each unordered pair of distinct incompatible support types \(X-Y,V-W\) satisfying \(Y\ge V\) and \(W\ge X\). Let \(a_{t,e}=1\) when \(t\) is an endpoint of \(e\), and \(a_{t,e}=0\) otherwise.
Mass is divisible: choose \(x_e\in\mathbb R_{\ge0}\) with \(\sum_{e\in E}a_{t,e}x_e\le\mu_t\) for every support type \(t\). The computational problem is to return an exact optimal rational vector maximizing \(D(\mu)+2\sum_{e\in E}x_e\); any maximizer is acceptable.

Is this continuous transplant-maximization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite societies with two sizes, a sequential left-lobe-only two-way exchange algorithm maximizes the number of exchanges (Ergin, Sönmez, and Ünver, 2018).
Together with direct transplantation of compatible pairs, this gives a polynomial-time algorithm for maximizing total transplants in the discrete model.

Modeling choices made when packaging the task

  • Interpreted distribution as a probability distribution: positive support masses sum to one, and omitted types have zero mass.
  • Defined m as the number of individual types, fixed at eight; L is the total input encoding length.
  • Restricted exchange patterns to support types and distinct endpoints. A two-way exchange between two incompatible pairs of the same type cannot satisfy the compatibility conditions.
  • Made divisibility explicit and required an exact optimal rational output, accepting any maximizer without an additional tie-breaker.
  • Explicitly excluded right-lobe donations, chains, and unpaired donors, preserving the scope of the anchor.

Result

The problem is polynomial-time solvable, including the requirement to return an exact optimal rational vector. An explicit maximum-flow reduction gives a bit-complexity bound of \(O((m^2+\tau^5)L+L^3)\). With \(m=8\), we have \(\tau\le 64\), so this bound becomes \(O(L^3)\).

1. Construct the exchange graph and integer capacities

Let \(I\) be the set of incompatible support types. Construct the undirected graph \(G=(I,E)\) using exactly the compatibility conditions in the question. Write \(n=|I|\) and \(r=|E|\). Then \(n\le\tau\) and \(r\le\binom{\tau}{2}\).

Compatible types contribute the fixed quantity \(D(\mu)\) and do not occur in this graph. Thus it remains to maximize \(\sum_{e\in E}x_e\) subject to the stated capacity constraints.

Write each input mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive binary-encoded integers. Define \(Q=\prod_{t\in\operatorname{supp}(\mu)}q_t\) and \(b_t=Q\mu_t\). Every \(b_t\) is an integer. Moreover, \(Q\) has \(O(L)\) bits, because the total encoding length of the denominators is at most \(L\).

2. Reduce exactly to maximum flow

Construct a directed network with source \(s\), sink \(z\), and two copies \(t_{\mathrm L},t_{\mathrm R}\) of every \(t\in I\). Its arcs are:

  • \(s\to t_{\mathrm L}\), with capacity \(b_t\);
  • \(t_{\mathrm R}\to z\), with capacity \(b_t\);
  • for each \(\{u,v\}\in E\), both \(u_{\mathrm L}\to v_{\mathrm R}\) and \(v_{\mathrm L}\to u_{\mathrm R}\), each with capacity \(Q\).

The network has \(2n+2\) vertices and \(2n+2r\) arcs. Let \(F^*\) denote its maximum flow value.

Every feasible exchange vector induces a flow. Given feasible \(x\), put flow \(Qx_{\{u,v\}}\) on each of the two middle arcs corresponding to \(\{u,v\}\). Put the incident-flow totals on the source and sink arcs.

The exchange constraints imply that these totals are at most \(b_t\), so the source and sink capacities are respected. Also, \(x_{\{u,v\}}\le\mu_u\le1\), so every middle-arc capacity is respected. Flow conservation holds by construction. The resulting flow value is \(2Q\sum_{e\in E}x_e\). Consequently, every feasible exchange vector satisfies \(2\sum_{e\in E}x_e\le F^*/Q\).

Every feasible flow induces an exchange vector. For a network flow \(f\), abbreviate \(f(u_{\mathrm L},v_{\mathrm R})\) as \(f_{uv}\), and define
\[ x_{\{u,v\}}=\frac{f_{uv}+f_{vu}}{2Q}. \]
Here and below, this formula means \(x_{\{u,v\}}=(f_{uv}+f_{vu})/(2Q)\).

For each \(t\in I\), flow conservation and the source and sink capacities give
\( \sum_{v:\{t,v\}\in E}f_{tv}\le b_t \) and
\( \sum_{v:\{t,v\}\in E}f_{vt}\le b_t \).
Therefore,
\( \sum_{e\ni t}x_e=(\sum_v f_{tv}+\sum_v f_{vt})/(2Q)\le b_t/Q=\mu_t \).
Thus \(x\) is feasible.

Every unit of source flow crosses exactly one middle arc, by flow conservation at the left copies. Hence, if \(F\) is the flow value, then
\(2Q\sum_{e\in E}x_e=\sum_{\{u,v\}\in E}(f_{uv}+f_{vu})=F\).

Applying this construction to a maximum flow attains the preceding upper bound. The exact optimal transplant mass is therefore \(D(\mu)+F^*/Q\), and the averaging formula returns an optimal exchange vector.

3. Exact computation and running time

Use Edmonds–Karp to compute the maximum flow. The standard theorem gives a maximum flow in \(O(va^2)\) elementary operations for a network with \(v\) vertices and \(a\) arcs, independently of capacity magnitudes. With integer capacities, starting from zero, every augmentation and every resulting arc flow is integral. See [Edmonds and Karp, *Theoretical Improvements in Algorithmic Efficiency for Network Flow Problems*](https://dl.acm.org/doi/10.1145/321694.321699).

The hypotheses hold here: the network is finite, and every capacity is a nonnegative integer. Since \(v=O(\tau)\) and \(a=O(\tau^2)\), the algorithm uses \(O(\tau^5)\) elementary operations. Capacities, arc flows, and residual capacities have \(O(L)\) bits, so these operations cost \(O(\tau^5L)\) bit operations.

Compatibility can be tabulated using \(O(m^2)\) tests, each comparing three coordinates. Constructing \(E\) then takes \(O(\tau^2)\) tests. Computing \(Q\) and the integer capacities by elementary binary arithmetic takes at most \(O(L^3)\) bit operations. These costs yield the claimed bound \(O((m^2+\tau^5)L+L^3)\).

Finally, each returned coordinate has numerator at most \(2Q\) and denominator \(2Q\). It therefore has \(O(L)\) bits, and the entire vector has \(O(\tau^2L)\) bits. This proves polynomial-time computation of an exact vector, not merely an approximate optimum.

4. Relation to the discrete result

The supplied discrete optimality result is unnecessary for this proof. Simply clearing denominators and explicitly creating individuals would not establish polynomial time in \(L\), because \(Q\) can be exponentially large in \(L\). The flow construction stores capacities in binary and never expands the population.

The averaging step is valid precisely because the task permits divisible mass. Thus the stated continuous problem is completely resolved.
