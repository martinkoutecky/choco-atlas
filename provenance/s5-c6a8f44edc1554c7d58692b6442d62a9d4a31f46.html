Theorem \(\mathrm{ComputabilityFPO}\) — class: algorithmic

The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), a finite complete type set \(T\), rational distribution \(\mu\), rational valuations \(v_t\in\mathbb{Q}_{\geq 0}^{C}\), and \(W\in\binom{C}{k}\), decide whether there exists \(\mathbf{p}\in[0,1]^C\) with \(\sum_{c\in C}\mathbf{p}(c)=k\), \(u_t(\mathbf{p})\geq u_t(W)\) for every \(t\in\operatorname{supp}(\mu)\), and strict inequality for some supported type; equivalently, decide whether \(W\) is not \(\mu\)-\(\mathrm{fPO}\), outputting \(\mathbf{p}\) when dominated and a positive supporting type-weight vector \(\lambda\) when it is \(\mu\)-\(\mathrm{fPO}\). The weak variant replaces the last condition by strict improvement for every supported type and permits nonnegative \(\lambda\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) have \(m\geq1\) candidates, let \(1\leq k\leq m\) be an integer, and let \(W\subseteq C\) satisfy \(|W|=k\).
A society is given by its support \(S\): the list of the \(\tau\geq1\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in S}\mu_t=1\). The parameter \(\tau\) is the support size, not the number of possible types.
Each supported type has valuations \(v_t\in\mathbb{Q}_{\geq0}^{C}\). Define \(\mathcal P=\{\mathbf p\in[0,1]^C:\sum_{c\in C}\mathbf p(c)=k\}\), \(u_t(\mathbf p)=\sum_{c\in C}v_t(c)\mathbf p(c)\), and \(u_t(W)=\sum_{c\in W}v_t(c)\).
The domination problem asks whether some \(\mathbf p\in\mathcal P\) satisfies \(u_t(\mathbf p)\geq u_t(W)\) for every \(t\in S\), with strict inequality for some \(t\in S\); absence of such a committee defines \(\mu\)-\(\mathrm{fPO}\). The weak variant requires strict improvement for every supported type; absence defines \(\mu\)-\(\mathrm{wfPO}\).
When domination exists, output a rational dominating \(\mathbf p\); otherwise output rational supporting weights \(\lambda_t>0\), normalized by \(\sum_{t\in S}\mu_t\lambda_t=1\), such that \(\sum_{t\in S}\mu_t\lambda_tu_t(W)\geq\sum_{t\in S}\mu_t\lambda_tu_t(\mathbf q)\) for every \(\mathbf q\in\mathcal P\). For the weak variant allow \(\lambda_t\geq0\). Ties in this welfare comparison are allowed.
Let \(L\) be the total binary input length; state running times in \(m,\tau,k,L\).

Are these two domination decision problems in \(\mathrm P\), with their respective witnesses computable in polynomial time in \(m,\tau,k,L\), or are they \(\mathrm{NP}\)-hard?

For finite voter lists with nonnegative rational additive valuations, both fractional Pareto-optimality variants can be verified in polynomial time, and dominating fractional committees or normalized supporting voter weights can be computed in polynomial time.
No separate result for the distribution-over-types formulation is verified here.

Modeling choices made when packaging the task

  • Normalized the rational distribution to total mass one and represented only its positive-mass support; unsupported types impose no conditions and need not be listed.
  • Specified additive utilities for both integral and fractional committees using the supplied nonnegative rational valuations.
  • Fixed a nonempty society and candidate set, with integer committee size between one and the number of candidates, inclusive.
  • Interpreted supporting type weights as welfare densities relative to the distribution, normalized by the mass-weighted sum equaling one; the weak variant therefore excludes the all-zero vector.
  • Required rational output witnesses and allowed equality in the supporting welfare comparison, consistent with arbitrary tie-breaking among welfare maximizers.
  • Defined the bit-length parameter as the total binary input length.

Result and notation

Both domination problems belong to \(\mathrm P\). Their required rational witnesses can be computed in time \((m+\tau+L+\log(k+1))^{O(1)}\). This holds directly for the explicitly listed support, without expanding rational masses into voter multiplicities.

Let \(x^W\in\{0,1\}^C\) be the incidence vector of \(W\), and define
\[ \]
\(V_{tc}=v_t(c)\), \(b_t=u_t(W)\), and \(a_c=\sum_{t\in S}v_t(c)\).

Thus \(Vx^W=b\), and \(u_t(p)=(Vp)_t\). Write \(A=a^\top x^W=\sum_{t\in S}b_t\). All vector inequalities below are componentwise.

We use two standard linear-programming facts: a feasible rational linear program with finite optimum has an optimal dual solution with the same objective value; and exact rational optimal solutions can be computed in time polynomial in the program’s binary encoding length. See the [MIT notes on duality](https://courses.csail.mit.edu/6.854/18/Notes/n12-duality.html) and [polynomial-time LP algorithms](https://courses.csail.mit.edu/6.854/18/Notes/n14-LP_algorithms.html). The hypotheses are checked below.

Ordinary domination and strictly positive supporting weights

Consider the linear program

\(\displaystyle \begin{aligned} F^*=\max\quad &a^\top p\\ \text{subject to}\quad &Vp\geq b,\\ &\mathbf1^\top p=k,\\ &0\leq p\leq\mathbf1. \end{aligned} \)

Its feasible set contains \(x^W\) and is compact, so its optimum exists and satisfies \(F^*\geq A\).

For every feasible \(p\),

\(\displaystyle a^\top p-A=\sum_{t\in S}\bigl(u_t(p)-u_t(W)\bigr).\)

Each summand is nonnegative. Their sum is positive exactly when at least one summand is positive. Consequently,

\(\displaystyle \text{ordinary domination exists}\quad\Longleftrightarrow\quad F^*>A.\)

If this inequality holds, any rational optimal \(p\) is the required dominating committee.

Suppose instead that \(F^*=A\). Introduce dual variables \(y_t\geq0\) for the constraints \(-Vp\leq-b\), \(z_c\geq0\) for \(p\leq\mathbf1\), and an unrestricted variable \(h\) for \(\mathbf1^\top p=k\). The dual is

\(\displaystyle \begin{aligned} \min\quad &kh+\sum_{c\in C}z_c-\sum_{t\in S}b_ty_t\\ \text{subject to}\quad &h+z_c\geq a_c+\sum_{t\in S}y_tv_t(c) &&\text{for every }c\in C,\\ &y\geq0,\quad z\geq0,\quad h\in\mathbb R. \end{aligned} \)

For completeness, its Lagrangian, maximized over \(p\geq0\), is

\(\displaystyle kh+\mathbf1^\top z-b^\top y+ \bigl(a+V^\top y-z-h\mathbf1\bigr)^\top p. \)

This maximum is finite precisely when the displayed dual inequalities hold, which verifies the dual formulation. The dual is feasible: take \(y=z=0\) and \(h=\max_c a_c\).

By strong duality, a rational optimal dual solution satisfies

\(\displaystyle kh+\sum_c z_c =A+\sum_t b_ty_t =\sum_t(1+y_t)b_t. \)

Set \(w_t=1+y_t\), so every \(w_t>0\). For every \(q\in\mathcal P\), dual feasibility gives

\(\displaystyle \begin{aligned} \sum_t w_tu_t(q) &=\sum_c\left(\sum_t w_tv_t(c)\right)q(c)\\ &\leq\sum_c(h+z_c)q(c)\\ &=kh+\sum_c z_cq(c)\\ &\leq kh+\sum_c z_c\\ &=\sum_t w_tu_t(W). \end{aligned} \)

The first inequality uses \(q(c)\geq0\); the second uses \(z_c\geq0\) and \(q(c)\leq1\).

Let \(D=\sum_t w_t>0\), and output

\(\displaystyle \lambda_t=\frac{w_t}{\mu_tD}.\)

Every \(\mu_t\) is strictly positive by the definition of support. Therefore these weights are rational and strictly positive, with

\(\displaystyle \sum_t\mu_t\lambda_t=1. \)

Dividing the welfare inequality by \(D\) proves exactly the required supporting inequality.

Conversely, such strictly positive supporting weights exclude ordinary domination: nonnegative utility gains, with at least one positive gain, would give a strictly positive weighted welfare gain because every \(\mu_t\lambda_t>0\).

Weak domination and nonnegative supporting weights

Consider the linear program

\(\displaystyle \begin{aligned} \Delta^*=\max\quad &\delta\\ \text{subject to}\quad &Vp-\delta\mathbf1\geq b,\\ &\mathbf1^\top p=k,\\ &0\leq p\leq\mathbf1,\qquad \delta\in\mathbb R. \end{aligned} \)

Here \(\delta\) is unrestricted in sign. The feasible point \((x^W,0)\) implies \(\Delta^*\geq0\). Moreover,

\(\displaystyle \Delta^*=\max_{p\in\mathcal P}\min_{t\in S}\bigl(u_t(p)-u_t(W)\bigr). \)

The minimum is over a finite nonempty support, so it is a continuous function of \(p\). Since \(\mathcal P\) is compact and nonempty, this maximum is finite and attained.

If a committee strictly improves every supported type, the minimum of its finitely many positive gains is positive. Conversely, any feasible pair with \(\delta>0\) strictly improves every supported type. Thus

\(\displaystyle \text{weak domination exists}\quad\Longleftrightarrow\quad\Delta^*>0.\)

When this holds, a rational optimal \(p\) is the required witness.

Suppose instead that \(\Delta^*=0\). The dual is

\(\displaystyle \begin{aligned} \min\quad &kh+\sum_c z_c-\sum_t b_ty_t\\ \text{subject to}\quad &h+z_c\geq\sum_t y_tv_t(c) &&\text{for every }c\in C,\\ &\sum_t y_t=1,\\ &y\geq0,\quad z\geq0,\quad h\in\mathbb R. \end{aligned} \)

Indeed, the Lagrangian is

\(\displaystyle kh+\mathbf1^\top z-b^\top y+ \bigl(V^\top y-z-h\mathbf1\bigr)^\top p+ \left(1-\sum_t y_t\right)\delta. \)

Maximization over unrestricted \(\delta\) forces \(\sum_t y_t=1\); maximization over \(p\geq0\) gives the remaining dual inequalities. The dual is feasible: choose any \(t_0\in S\), take \(y_{t_0}=1\) and all other \(y_t=0\), set \(z=0\), and take \(h=\max_c v_{t_0}(c)\).

Strong duality supplies a rational optimal dual solution satisfying

\(\displaystyle kh+\sum_c z_c=\sum_t y_tb_t.\)

For every \(q\in\mathcal P\), the same inequalities used above yield

\(\displaystyle \sum_t y_tu_t(q) \leq kh+\sum_c z_c =\sum_t y_tu_t(W). \)

Output

\(\displaystyle \lambda_t=\frac{y_t}{\mu_t}.\)

These weights are rational and nonnegative, and

\(\displaystyle \sum_t\mu_t\lambda_t=\sum_t y_t=1.\)

They therefore satisfy the required normalization and supporting inequality.

Conversely, any such supporting weights exclude weak domination. Normalization ensures that at least one coefficient \(\mu_t\lambda_t\) is positive. If all utility gains were strictly positive, their weighted sum would consequently be strictly positive, contradicting the supporting inequality.

Encoding length and running time

Let \(N=m+\tau+1\).

The ordinary primal has \(m\) variables; the weak primal has \(m+1\). Each has \(O(m+\tau)\) constraints when coordinate bounds are counted explicitly. Each dual has \(m+\tau+1\) variables and \(O(m+\tau)\) constraints.

The coefficients \(a_c\) and \(b_t\) are sums of input rationals. Their exact computation takes polynomial time, and their binary lengths are polynomial in \(L\): a common denominator can be obtained by multiplying the relevant input denominators, whose combined binary length is at most \(L\).

A conservative bound on the encoding length of any displayed program is

\(\displaystyle B=O\!\left(N^2\bigl(L+\log(N+1)+\log(k+1)\bigr)\right).\)

Exact rational LP algorithms therefore solve each program in \((N+B)^{O(1)}\) bit operations. Each variant requires at most one primal optimization and, when domination is absent, one dual optimization. Its total running time is consequently

\(\displaystyle (m+\tau+L+\log(k+1))^{O(1)},\)

which is polynomial in the requested parameters.

The output lengths are polynomial as well. After conversion to standard form and clearing denominators, optimal basic solutions are obtained from nonsingular integer systems of polynomial dimension and coefficient length. Cramer’s rule and determinant bounds give polynomial binary lengths for their coordinates. Forming \(1+y_t\), summing these quantities, and dividing by positive input masses preserve polynomial encoding length.

In particular, small masses cause no difficulty: their reciprocals can have large numerical values, but their binary lengths remain polynomial in \(L\).

Certificate verification and boundary cases

A proposed dominating committee is checked by exact rational evaluation of its coordinates, total size, and supported utilities.

For supporting weights, define candidate scores

\(\displaystyle s(c)=\sum_{t\in S}\mu_t\lambda_tv_t(c).\)

After checking signs and normalization, the supporting inequality is equivalent to

\(\displaystyle s(c)\geq s(d)\qquad\text{for every }c\in W,\ d\notin W.\)

Necessity follows by considering the committee obtained by replacing \(c\) with \(d\). For sufficiency, assume \(k<m\) and these inequalities hold. Set \(r=\min_{c\in W}s(c)\). For every \(q\in\mathcal P\),

\(\displaystyle \sum_{c\in W}(1-q(c))=\sum_{d\notin W}q(d).\)

Since \(s(c)\geq r\) on \(W\) and \(s(d)\leq r\) outside \(W\),

\(\displaystyle \sum_{c\in W}s(c)(1-q(c)) \geq r\sum_{c\in W}(1-q(c)) =r\sum_{d\notin W}q(d) \geq\sum_{d\notin W}s(d)q(d). \)

Rearranging proves that \(W\) maximizes the weighted welfare over \(\mathcal P\). Thus supporting certificates are also verifiable in polynomial time.

If \(k=m\), then \(\mathcal P=\{\mathbf1\}\), so neither domination variant exists. The weights \(\lambda_t=1\) satisfy both certificate requirements because \(\sum_t\mu_t=1\).

These arguments settle both variants for the distribution-over-types formulation with explicit support.
