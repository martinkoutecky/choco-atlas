The continuous mirror question, as graded

Given a finite time-extended graph, explicit route menus \(R_t\) for \(\tau\) complete request types with rational masses \(\mu_t>0\), \(\sum_t\mu_t=1\), type-specific utilities and budgets, and per-capita edge supplies \(b_e\), find an allocation and nonnegative edge prices \(p_e\). The allocation may be represented by route masses \(q_{t,s}\) and dropout masses \(q_{t,\emptyset}\), with \(\sum_{s\in R_t}q_{t,s}+q_{t,\emptyset}=\mu_t\); its per-unit average bundle for each type must be optimal for that type’s fractional individual problem at prices \(p\). Require aggregate use \(\sum_t\sum_{s\in R_t}q_{t,s}a_{s,e}\le b_e\) and price complementarity \(p_e>0\Rightarrow\sum_t\sum_{s\in R_t}q_{t,s}a_{s,e}=b_e\). Determine the complexity of finding an exact or \(\epsilon\)-approximate equilibrium in the graph and menu sizes, \(\tau\), input bit length \(L\), and \(\log(1/\epsilon)\), including whether the fixed-point route in Proposition 4.5 applies.

Packaged proof task (what the prover saw — nothing else)

A time-extended graph has arrival, occupancy, and departure vertices for every sector and time; edges join arrival to occupancy, occupancy to departure, occupancy to next-time occupancy, and departure to an adjacent sector’s next-time arrival. The last kind is unconstrained and has price zero; all other edges have rational per-capita capacities \(q_e\geq0\). Let \(m\) be the number of vertices plus edges.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type explicitly specifies a finite menu \(R_t\) of complete graph paths, a rational budget \(w_t\geq0\), and positive rational utilities \(v_{t,s}\), \(v_{t,\varnothing}\), and \(v_{t,o}\) for each route, dropout, and each unit of outside-option consumption. A common outside-option price \(p_o>0\) is a given rational; outside-option supply is unlimited.
An action \((a,z)\) selects exactly one \(a\in R_t\cup\{\varnothing\}\) and consumes \(z\geq0\) outside-option units. Set \(c_p(s)=\sum_{e\in s}p_e\) and \(c_p(\varnothing)=0\). The action is affordable iff \(c_p(a)+p_oz\leq w_t\), and its utility is \(v_{t,a}+v_{t,o}z\); dropout uses no edges.
An equilibrium consists of nonnegative edge prices and a finite distribution \(\pi_t\) over affordable actions for each type, every supported action maximizing utility among all that type’s affordable actions. Ties may be split arbitrarily. For every constrained edge, \(d_e=\sum_t\mu_t\sum_{(a,z)}\pi_t(a,z)\mathbf1\{e\in a\}\leq q_e\), with \(p_e>0\Rightarrow d_e=q_e\).
The computational problem is to decide equilibrium existence and return exact prices and distributions when they exist. Let \(K=\sum_t|R_t|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,K,L\).

Is deciding existence of this equilibrium in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? In the polynomial-time case, can an equilibrium also be constructed in polynomial time?

For a finite vehicle list, the budget-adjusted welfare problem with divisible edge allocations has feasible constraints and a convex formulation for every positive adjustment vector; this is not a complexity classification of whole-route equilibrium existence. Existence is also claimed for the divisible-allocation equilibrium, with a conditional fixed-point characterization; its individual budget constraint permits fractional routes rather than requiring each supported whole route to be affordable. [Maheshwari et al.](https://arxiv.org/abs/2411.03582)

Complexity classification

Equilibrium existence is \(\mathrm{NP}\)-complete. The hardness holds even when \(p_o=v_{t,o}=v_{t,\varnothing}=1\), every type has at most three routes, and the graph has only three sectors.

Every instance admitting an equilibrium admits one with rational prices and distributions of polynomial binary length. Decision and exact construction are possible in time \(2^{O(m+K+\tau)}\operatorname{poly}(m,\tau,K,L)\). A polynomial-time algorithm for the requested decision-and-construction problem exists if and only if \(\mathrm{P}=\mathrm{NP}\).

The proof follows.

1. Exact demand conditions

For an affordable route or dropout action \(a\), optimal outside consumption is necessarily

\[ z=\frac{w_t-c_p(a)}{p_o}, \]

because \(v_{t,o}>0\). Define the normalized route value

\[ b_{t,a}=\frac{p_o}{v_{t,o}}\bigl(v_{t,a}-v_{t,\varnothing}\bigr), \qquad b_{t,\varnothing}=0. \]

After subtracting the utility of dropout with maximal outside consumption and multiplying by \(p_o/v_{t,o}\), the score of \(a\) is \(b_{t,a}-c_p(a)\).

Thus a type chooses precisely the maximizers of \(b_{t,a}-c_p(a)\) among dropout and routes satisfying \(c_p(a)\leq w_t\). Dropout has score zero. Once the selected route is specified, its optimal outside consumption is unique.

Below, bundles denote sets of constrained resources. Section 6 realizes every such bundle as a complete path in the required graph.

2. Reduction from Set Cover

We reduce from the standard \(\mathrm{NP}\)-complete Set Cover problem: given sets \(S_1,\ldots,S_n\) covering a universe \(U=\{1,\ldots,\ell\}\), decide whether at most \(k\) sets cover \(U\). See [Karp’s original result](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

We may restrict to \(1\leq k\leq n\) and to instances in which every element belongs to some set. These restrictions preserve hardness: the usual reduction from satisfiability introduces one element for each variable and each clause, two sets per variable, and a bound equal to the number of variables. Each variable element forces selection of one of its two sets.

For each element \(j\), define \(I_j=\{i:j\in S_i\}\) and \(r_j=|I_j|\).

Resources

For each set \(i\), introduce three resources \(X_i,Y_i,Z_i\), each with capacity \(3\). Introduce resources \(H,G\), with capacities \(n+1\) and \(3k/4\), respectively. For each element \(j\), introduce a private resource \(F_j\), with capacity \(1/2\).

These are initially unnormalized capacities and masses.

Types

Set \(p_o=v_{t,o}=v_{t,\varnothing}=1\). Consequently, a normalized value \(b\) is implemented by the positive route utility \(v_{t,a}=1+b\).

The types are:

| Type | Mass | Budget | Menu: bundle and normalized value |
|---|---:|---:|---|
| \(A_i\), for each set \(i\) | \(15/2\) | \(100\) | \((\{X_i\},100)\), \((\{Y_i\},100)\), \((\{Z_i\},100)\) |
| \(B_i\), for each set \(i\) | \(1\) | \(1\) | \((\{X_i\},1)\) |
| \(C_i\), for each set \(i\) | \(1\) | \(6\) | \((\{Z_i,H\},12)\), \((\{X_i,Y_i,G\},6)\) |
| \(D\) | \(n+2\) | \(4\) | \((\{H\},4)\) |
| \(E_j\), for each element \(j\) | \(1\) | \(r_j\) | \((\{F_j\}\cup\{X_i:i\in I_j\},r_j+1)\) |

Every type also has dropout.

The total mass is \(T=21n/2+\ell+2\). Choose a power of two \(D_0>T\). Divide all listed masses and capacities by \(D_0\), and add a type with no routes, budget zero, and mass \((D_0-T)/D_0\).

The resulting society has total mass one. All masses and capacities are dyadic rationals of polynomial encoding length. Scaling masses and capacities by the same factor preserves all equilibrium conditions, so the proof uses the unnormalized units.

3. Prices forced by the construction

3.1. Element types must drop out

Only \(E_j\) uses \(F_j\). Its route, whenever affordable, has score at least \((r_j+1)-r_j=1\), so it strictly dominates dropout.

Therefore demand for \(F_j\) is either zero or one. Its capacity is \(1/2\). A positive price would require demand exactly \(1/2\), which is impossible. Hence \(p_{F_j}=0\).

At that price, capacity feasibility forces \(E_j\) to drop out, and therefore its route must be unaffordable. Thus every equilibrium satisfies

\[ \sum_{i\in I_j}p_{X_i}>r_j. \tag{1} \]

In particular, element types consume no resources in any equilibrium.

3.2. The price of \(H\) is exactly four

If \(p_H<4\), type \(D\) strictly prefers its route and demands \(n+2\) units, exceeding capacity \(n+1\).

If \(p_H>4\), type \(D\) cannot afford its route. Only the types \(C_i\) can then consume \(H\), and their total mass is \(n<n+1\). Positive-price clearing would fail.

Consequently,

\[ p_H=4. \tag{2} \]

At this price, type \(D\) is indifferent between its route and dropout.

3.3. Each triple has one common, positive price

Fix \(i\). Apart from \(A_i\), total demand on any one of \(X_i,Y_i,Z_i\) is at most two. Element types already have zero demand.

If one resource in this triple has a positive price, clearing its capacity of three requires some demand from \(A_i\). Every resource purchased by \(A_i\) must have the minimum price in the triple: a cheaper singleton would also be affordable and would have a strictly larger score.

It follows that either all three prices are zero, or all three are positive and equal.

The zero-price possibility is infeasible. At zero prices:

  • \(A_i\) consumes \(15/2\) units across the triple;
  • \(B_i\) consumes one unit of \(X_i\);
  • \(C_i\) strictly chooses \(\{Z_i,H\}\), whose score is eight, whereas the other route has score at most six.

Total demand across the triple would therefore be \(19/2>9\), exceeding total capacity.

Write the common positive price as \(p_i\). It is at most \(100\), because a positive-price resource must receive demand from \(A_i\). Equality \(p_i=100\) is also impossible: \(B_i\) and \(C_i\) would consume nothing in the triple, while \(A_i\) could supply at most \(15/2<9\).

Thus \(0<p_i<100\), and \(A_i\) strictly prefers a singleton to dropout. Its total demand across the triple is exactly \(15/2\).

Since all three resources have positive prices, total demand must equal nine. The combined demand of \(B_i,C_i\), counting their usage of these three resources, must therefore be exactly \(3/2\).

3.4. Exactly two price regimes are possible

Let \(\gamma=p_G\geq0\).

The two routes of \(C_i\) have costs \(p_i+4\) and \(2p_i+\gamma\), and scores \(8-p_i\) and \(6-2p_i-\gamma\), respectively.

If \(p_i\leq2\), the first route is affordable and has positive score. Whenever the second route is affordable, the first has strictly greater score, because their score difference is \(2+p_i+\gamma>0\). Hence \(C_i\) certainly chooses \(\{Z_i,H\}\), contributing one unit of demand to the triple.

Now consider \(B_i\):

  • If \(p_i<1\), it certainly consumes \(X_i\), giving combined demand two, which is too large.
  • If \(p_i=1\), it can split between its route and dropout; combined demand \(3/2\) forces route probability \(1/2\).
  • If \(1<p_i\leq2\), it drops out, giving combined demand one, which is too small.

Thus the only regime with \(p_i\leq2\) is \(p_i=1\).

If \(p_i>2\), the first route of \(C_i\) is unaffordable, and \(B_i\) drops out. Its second route:

  • is strictly preferred to dropout if \(2p_i+\gamma<6\);
  • ties dropout if \(2p_i+\gamma=6\);
  • is unaffordable if \(2p_i+\gamma>6\).

It uses two resources in the triple. Combined demand \(3/2\) therefore forces equality and route probability \(3/4\).

We have proved the following exhaustive characterization.

| Regime | Prices | \(B_i\) | \(C_i\) |
|---|---|---|---|
| Low | \(p_i=1\) | Route probability \(1/2\) | Chooses \(\{Z_i,H\}\) with probability one |
| High | \(p_i>2\), \(2p_i+\gamma=6\) | Drops out | Chooses \(\{X_i,Y_i,G\}\) with probability \(3/4\) |

In particular, every high price is at most three.

4. Every equilibrium yields a small set cover

Let \(J\) be the indices in the high regime.

Only high-regime types \(C_i\) consume \(G\), each with demand \(3/4\). Its capacity constraint gives

\[ \frac34|J|\leq\frac34k, \]

so \(|J|\leq k\).

For any element \(j\), if all indices in \(I_j\) were low, then \(\sum_{i\in I_j}p_{X_i}=r_j\), contradicting (1). Therefore \(I_j\cap J\neq\varnothing\).

Consequently, the sets indexed by \(J\) cover the universe, using at most \(k\) sets.

5. Every small set cover yields an exact equilibrium

Conversely, suppose \(J\) indexes a cover with \(h=|J|\leq k\). Set:

  • \(p_{X_i}=p_{Y_i}=p_{Z_i}=3\) for \(i\in J\);
  • \(p_{X_i}=p_{Y_i}=p_{Z_i}=1\) for \(i\notin J\);
  • \(p_H=4\), \(p_G=0\), and \(p_{F_j}=0\).

Use the low- and high-regime distributions proved above.

For a low triple, demand from \(B_i,C_i\) on \(X_i,Y_i,Z_i\) is \((1/2,0,1)\). Allocate type \(A_i\) masses \((5/2,3,2)\) to its three singleton routes. These sum to its mass \(15/2\), and each resource receives total demand three.

For a high triple, demand from \(B_i,C_i\) is \((3/4,3/4,0)\). Allocate type \(A_i\) masses \((9/4,9/4,3)\). Again these sum to \(15/2\), and each resource receives total demand three.

All singleton routes of \(A_i\) tie and strictly dominate dropout at the stated prices, so these distributions are optimal.

The low types \(C_i\) contribute \(n-h\) units of demand to \(H\). Give type \(D\) route mass \(1+h\), and let its remaining mass drop out. This is feasible because \(1+h\leq n+1<n+2\). Total demand on \(H\) is exactly \(n+1\), and \(D\) is indifferent at price four.

Demand on \(G\) is \(3h/4\leq3k/4\), consistent with its zero price.

Each element \(j\) belongs to a selected set. Therefore its tester route costs

\[ \sum_{i\in I_j}p_{X_i} =r_j+2|I_j\cap J|>r_j, \]

and is unaffordable. Every tester drops out, so all private-resource capacities are respected.

Finally, for every supported route or dropout action, set outside consumption to \((w_t-c_p(a))/p_o\). This gives affordable, utility-maximizing actions. Thus the specified prices and finite rational distributions form an equilibrium.

Together with Section 4, this proves the required equivalence.

6. Realization as complete time-extended paths

It remains to realize the bundle construction in the graph class from the question.

Let \(g=3n+\ell+2\) be the number of resources. Use three sectors:

  • a buffer sector \(S_0\);
  • a resource sector \(S_1\);
  • a bypass sector \(S_2\).

The sector adjacency graph has edges joining \(S_0\) to \(S_1\) and \(S_2\). Use times \(1,\ldots,2g+1\).

Enumerate the resources. At time \(2j\), assign resource \(j\) to the arrival-to-occupancy edge of \(S_1\), with its normalized capacity. Give every other constrained edge capacity two.

For any bundle, specify a complete path that:

  • visits \(S_0\) at every odd time;
  • visits \(S_1\) at time \(2j\) if resource \(j\) belongs to the bundle;
  • visits \(S_2\) otherwise.

At each visited sector-time pair, the path traverses arrival, occupancy, and departure. Successive visits are joined by the stipulated free departure-to-next-time-arrival edges. Every path has the same initial and final vertices.

Each such path uses exactly the designated resource edges in its bundle. Every other constrained edge has demand at most one, because society mass is one and a path uses an edge at most once. Its capacity is two, so it must have price zero in every equilibrium. The stipulated unconstrained edges also have price zero.

Therefore route prices, resource demands, and equilibrium conditions coincide exactly with those in the bundle construction.

The reduction has \(m=O(n+\ell)\), \(\tau=3n+\ell+2\), and \(K=6n+\ell+1\). Each explicit path has length \(O(n+\ell)\), and the total input length is polynomial in the Set Cover input length. This completes the proof of \(\mathrm{NP}\)-hardness.

7. Membership in \(\mathrm{NP}\) and exact running times

We now prove that real equilibria always have polynomial-size rational certificates.

Let \(E_c\) be the constrained-edge set. Guess:

  • A set \(J\subseteq E_c\) of positive-price edges.
  • For each type, a set \(A_t\subseteq R_t\) of affordable routes.
  • For each type, a set \(S_t\subseteq A_t\cup\{\varnothing\}\) containing all actions allowed positive probability.

Introduce prices \(p_e\), route probabilities \(x_{t,a}\), and maximal normalized scores \(u_t\). Impose the following linear conditions.

For prices and affordability:

  • \(p_e>0\) for \(e\in J\), and \(p_e=0\) otherwise;
  • \(c_p(a)\leq w_t\) for \(a\in A_t\);
  • \(c_p(a)>w_t\) for \(a\notin A_t\).

For optimality:

  • \(u_t\geq0\);
  • \(u_t\geq b_{t,a}-c_p(a)\) for every \(a\in A_t\);
  • \(u_t=b_{t,a}-c_p(a)\) for every route \(a\in S_t\);
  • \(u_t=0\) if dropout belongs to \(S_t\).

For distributions and clearing:

  • \(x_{t,a}\geq0\), \(\sum_a x_{t,a}=1\), and \(x_{t,a}=0\) outside \(S_t\);
  • \(d_e=\sum_t\mu_t\sum_a x_{t,a}\mathbf1\{e\in a\}\leq q_e\);
  • \(d_e=q_e\) for \(e\in J\).

A feasible solution is exactly an equilibrium respecting the guessed sets, after adjoining optimal outside consumption. Conversely, any equilibrium supplies such sets and a feasible solution.

These are rational linear systems with strict inequalities. Introduce a common variable \(0\leq\delta\leq1\), replace \(p_e>0\) by \(p_e\geq\delta\), and replace \(c_p(a)>w_t\) by \(c_p(a)\geq w_t+\delta\). Maximize \(\delta\).

The original strict system is feasible if and only if this linear program has optimum strictly greater than zero: a feasible strict system has finitely many positive margins, whose minimum supplies a positive \(\delta\).

Each program has \(O(m+K+\tau)\) variables and constraints, and polynomial encoding length in \(m,\tau,K,L\). Standard rational linear-programming theory gives an optimal rational solution of polynomial encoding length whenever the program is feasible. The objective is bounded by one; the usual determinant bounds on basic solutions give the stated encoding bound.

Hence every yes-instance has polynomial-length rational prices and probabilities. Its outside consumptions also have polynomial encoding length, by the formula in Section 1. Checking affordability, optimality, capacity feasibility, and positive-price clearing takes \(\operatorname{poly}(m,\tau,K,L)\) time. Thus existence belongs to \(\mathrm{NP}\).

There are at most \(2^{|E_c|+2K+\tau}\) guesses. Enumerating them and solving their linear programs decides existence and constructs an exact equilibrium in time

\[ 2^{O(m+K+\tau)}\operatorname{poly}(m,\tau,K,L). \]

If \(\mathrm{P}=\mathrm{NP}\), exact construction is also polynomial: select the guessed sets bit by bit using the \(\mathrm{NP}\) predicate “this prefix admits a feasible completion,” then solve the resulting linear program. Conversely, a polynomial-time algorithm that returns an equilibrium or correctly reports nonexistence would decide the \(\mathrm{NP}\)-complete existence problem.
