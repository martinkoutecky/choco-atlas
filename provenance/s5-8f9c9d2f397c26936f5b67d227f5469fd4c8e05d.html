The continuous mirror question, as graded

Given supported ranking types \(T\) with rational masses \(\mu_t\), school categories \(O\) with rational per-capita supplies \(q_o\), and feasible type-level shares \(p_{t,o}\) satisfying \(\sum_o p_{t,o}=1\) and \(\sum_t \mu_t p_{t,o}=q_o\), does there exist a probability distribution over feasible measurable assignments of the atomless population such that every assignment in its support is Pareto-optimal and the expected share of type \(t\) assigned to category \(o\) is \(p_{t,o}\)?

Packaged proof task (what the prover saw — nothing else)

Let \(O\) contain \(m\geq 1\) school categories. A society is given by its support: a list \(T\) of \(\tau\) distinct strict complete rankings of \(O\), each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
The input also gives positive binary rational supplies \(q_o\) with \(\sum_o q_o=1\), and binary rational shares \(p_{t,o}\in[0,1]\) satisfying \(\sum_o p_{t,o}=1\) and \(\sum_t\mu_t p_{t,o}=q_o\). Let \(L\) be the total input bit length; measure running times in \(m,\tau,L\).
Represent the population by the Lebesgue probability space \(I=[0,1]\), partitioned into type intervals \(I_t\) of measures \(\mu_t\). A feasible deterministic assignment is a measurable map \(a:I\to O\) with \(\lambda(a^{-1}(o))=q_o\) for every category; assignments are identified up to null sets.
An assignment \(a\) is Pareto-optimal if no feasible assignment \(b\) weakly improves the assigned category for almost every individual and strictly improves it for a set of positive measure, according to each individual's type ranking.
A lottery is a jointly measurable map \(A:\Omega\times I\to O\) on some probability space \((\Omega,\mathcal F,\mathbb P)\), every realization \(A_\omega\) being feasible and Pareto-optimal. It implements \(p\) when \(\mathbb E[\lambda(I_t\cap A_\omega^{-1}(o))/\mu_t]=p_{t,o}\) for every \(t,o\).

Is deciding whether such a lottery implements the given \(p\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finitely many agents with strict rankings and equally many distinct unit-supply objects, testing whether a given bistochastic assignment is a lottery over Pareto-optimal deterministic assignments is NP-complete ([Aziz et al.](https://arxiv.org/pdf/1409.6076)).
No verified complexity result for the exact atomless decision problem above was located.

Modeling choices made when packaging the task

  • Normalized total population mass and total per-capita supply to one, and required positive supplies, corresponding to the discrete setting's fully allocated positive unit supplies.
  • Specified strict complete rankings, nonempty category and type sets, and binary rational shares in the unit interval.
  • Represented the atomless population by a Lebesgue interval partitioned into type intervals; deterministic assignments give each individual exactly one category and satisfy supplies exactly.
  • Defined continuum Pareto improvement using weak improvement almost everywhere and strict improvement on a set of positive measure, with assignments identified modulo null sets.
  • Interpreted lottery support as its possible realizations, each feasible and Pareto-optimal, rather than topological support; allowed arbitrary jointly measurable lotteries.
  • Interpreted implementation as expected conditional type shares, without imposing individual marginal probabilities beyond those aggregate shares.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is \(\mathrm{NP}\text{-complete}\). Hardness holds already when \(m=\tau\) and every type mass and category supply equals \(1/m\).

The main point is that, on these uniform instances, allowing each type interval to split among categories does not enlarge the set of implementable expected assignments.

1. Pareto optimality is characterized by trading cycles.

Write \(o'\succ_t o\) when type \(t\) strictly prefers \(o'\) to \(o\). For a feasible measurable assignment \(a\), define its mass table by

\(x_{t,o}=\lambda(I_t\cap a^{-1}(o))\).

Its margins satisfy

\(\sum_o x_{t,o}=\mu_t,\qquad \sum_t x_{t,o}=q_o,\qquad x_{t,o}\geq 0.\)

Define a directed graph \(G(x)\) on the categories. It contains the edge \(o\to o'\) precisely when some type \(t\) satisfies \(x_{t,o}>0\) and \(o'\succ_t o\).

Lemma 1. A feasible assignment \(a\) is Pareto-optimal if and only if \(G(x)\) is acyclic.

Proof. Suppose first that \(G(x)\) contains a simple directed cycle

\(o_1\to o_2\to\cdots\to o_k\to o_1.\)

For each edge, choose a type \(t_j\) such that \(x_{t_j,o_j}>0\) and \(o_{j+1}\succ_{t_j}o_j\), with indices interpreted cyclically. Choose

\(0<\varepsilon<\min_j x_{t_j,o_j}.\)

By nonatomicity of Lebesgue measure, each set \(I_{t_j}\cap a^{-1}(o_j)\) has a measurable subset \(B_j\) of measure \(\varepsilon\). The sets \(B_j\) are disjoint because their currently assigned categories are distinct.

Reassign every individual in \(B_j\) to \(o_{j+1}\), leaving everyone else unchanged. Every category loses and gains exactly mass \(\varepsilon\), so the resulting assignment is feasible. All individuals in the union of the \(B_j\) strictly improve. Thus \(a\) is not Pareto-optimal.

Conversely, suppose a feasible assignment \(b\) Pareto-dominates \(a\). For distinct categories \(o,o'\), put

\(f_{o,o'}=\lambda(\{i:a(i)=o,\ b(i)=o'\}).\)

If \(f_{o,o'}>0\), then, since the type partition is finite, a positive-measure subset of these individuals has some type \(t\). Weak improvement and strict rankings imply \(o'\succ_t o\). Consequently \(o\to o'\) belongs to \(G(x)\).

Feasibility of both assignments gives, for every category \(o\),

\(\sum_{o'\ne o}f_{o,o'}=\sum_{o'\ne o}f_{o',o}.\)

The positive-measure strict improvement implies that at least one of these flows is positive. A nonzero nonnegative flow on a finite directed graph, balanced at every vertex, contains a directed cycle: after following a positive-flow edge, its destination has positive inflow and therefore positive outflow; continuing eventually repeats a vertex. Hence \(G(x)\) contains a cycle. This proves the converse. \(\square\)

In particular, Pareto optimality depends only on the mass table. Moreover, every nonnegative table with the stated margins is realized by a measurable assignment: partition each type interval into consecutive subintervals of lengths \(x_{t,o}\), assigning the corresponding categories.

For a finite matching, the analogous category graph is also acyclic exactly when the matching is Pareto-optimal. A cycle permits its distinct category owners to trade cyclically, strictly improving each owner. Conversely, a Pareto improvement produces a nonzero balanced flow, now with integer entries, and therefore a cycle.

2. Uniform atomless instances have exactly the finite implementation set.

Consider a finite problem with \(n\) agents, \(n\) objects, and pairwise distinct strict rankings. Form its atomless counterpart by using those rankings as types and setting

\(\mu_t=q_o=1/n.\)

Let \(P\) be any bistochastic target matrix. Let \(\mathcal H\) denote the convex hull of the permutation matrices representing Pareto-optimal finite matchings. Because there are finitely many matchings, \(\mathcal H\) is compact.

Lemma 2. The atomless instance implements \(P\) if and only if \(P\in\mathcal H\).

Proof. Suppose first that an atomless lottery implements \(P\). For each realization \(\omega\), define its share matrix by

\(S^\omega_{t,o}=n\,\lambda(I_t\cap A_\omega^{-1}(o)).\)

Every row sums to \(1\), and every column sums to \(nq_o=1\). Thus \(S^\omega\) is bistochastic. Joint measurability of \(A\), followed by integration over \(I_t\), makes these coordinates measurable functions of \(\omega\).

The Birkhoff–von Neumann theorem states that every nonnegative square matrix whose row and column sums are all \(1\) is a finite convex combination of permutation matrices. Apply it to \(S^\omega\). Every permutation matrix occurring with positive coefficient uses only positive entries of \(S^\omega\): a zero entry of a nonnegative convex combination cannot receive a positive contribution.

The realization \(A_\omega\) is Pareto-optimal, so Lemma 1 makes its category graph acyclic. Every matching in the Birkhoff decomposition has a category graph contained in that graph. Therefore every such matching is Pareto-optimal, and

\(S^\omega\in\mathcal H.\)

The implementation identities give \(\mathbb E[S^\omega]=P\). This expectation belongs to \(\mathcal H\). Explicitly, if it did not, separation from the compact convex set \(\mathcal H\) would give a linear functional \(c\) satisfying

\(c\cdot P>\max_{Y\in\mathcal H}c\cdot Y.\)

But \(S^\omega\in\mathcal H\) for every realization, so taking expectations contradicts this inequality. Hence \(P\in\mathcal H\).

Conversely, suppose \(P\) is a finite convex combination of Pareto-optimal matching matrices. For each matching, assign the entire interval \(I_t\) to the category allocated to its corresponding finite agent. Every category then receives mass \(1/n\). Its category graph is the matching’s acyclic graph, so Lemma 1 proves atomless Pareto optimality.

Randomizing over these assignments with the convex-combination coefficients implements \(P\). The probability space is finite, and the assignment map is jointly measurable. \(\square\)

This argument requires no measurable selection of Birkhoff decompositions: they establish membership of each realization’s matrix in the fixed compact set \(\mathcal H\).

3. A hardness reduction that respects distinct support rankings.

The finite problem of deciding whether a rational bistochastic matrix is a lottery over Pareto-optimal matchings is \(\mathrm{NP}\text{-complete}\), by Theorem 2 of [Aziz, Mackenzie, Xia, and Ye](https://arxiv.org/pdf/1409.6076). Its hardness construction uses rational entries, so it applies to binary rational input.

We must ensure pairwise distinct rankings before invoking Lemma 2. The following polynomial transformation achieves this without changing the answer.

Take an arbitrary finite instance with agents \(1,\ldots,n\), original objects \(O_0\), and target matrix \(P\). Add objects \(d_1,\ldots,d_n\) and agents \(h_1,\ldots,h_n\).

Define the extended rankings as follows:

  • Original agent \(i\) ranks all original objects first, in its original order. It then ranks \(d_i\) first among the new objects, followed by the remaining new objects in index order.
  • New agent \(h_i\) ranks \(d_i\) first, followed by every other object in any fixed strict order.

All \(2n\) rankings are distinct. Two original agents have different first objects in their appended new-object lists. Two new agents have different top objects. An original agent’s top object is original, whereas a new agent’s top object is new.

Set the extended target matrix to

\(\widehat P=\operatorname{diag}(P,I_n).\)

Thus original agents receive only original objects in expectation, and \(h_i\) receives \(d_i\) with probability \(1\).

Every matching with positive coefficient in a decomposition of \(\widehat P\) must respect its zero entries. Consequently it assigns \(d_i\) to \(h_i\) and assigns original objects to original agents.

Such a matching is Pareto-optimal in the extended problem exactly when its restriction is Pareto-optimal in the original problem:

  • A Pareto improvement of the original matching extends to the new agents by leaving them unchanged.
  • Any Pareto improvement of the extended matching must leave every \(h_i\) at its top object \(d_i\). Therefore the original agents continue to receive original objects, and the improvement restricts to one in the original problem.

It follows that \(P\) has a Pareto-optimal matching decomposition if and only if \(\widehat P\) does.

Now construct the atomless instance with these \(2n\) distinct rankings and parameters

\(m=\tau=2n,\qquad \mu_t=q_o=1/(2n),\qquad p=\widehat P.\)

All masses and supplies are positive binary rationals. The required feasibility identities hold because \(\widehat P\) is bistochastic. Lemma 2 gives

\(\widehat P\text{ is atomlessly implementable}\quad\Longleftrightarrow\quad P\text{ has a Pareto-optimal finite matching decomposition}.\)

The construction writes \(2n\) rankings of length \(2n\), a target matrix of size \(2n\) by \(2n\), and rational masses and supplies with bit length \(O(\log n)\). Its output length and running time are polynomial in the finite input length.

This is a polynomial many-one reduction to the exact atomless problem, proving \(\mathrm{NP}\text{-hardness}\).

4. Polynomial-size certificates for arbitrary rational inputs.

We now prove membership in \(\mathrm{NP}\), including nonuniform masses and supplies.

Let \(d=\tau m\), and let \(\mathcal B\) be the polytope of nonnegative mass tables with row margins \(\mu_t\) and column margins \(q_o\). Define the target mass table by

\(r_{t,o}=\mu_t p_{t,o}.\)

For each subset \(S\subseteq T\times O\), define \(G(S)\) to contain \(o\to o'\) whenever \((t,o)\in S\) for some type \(t\) with \(o'\succ_t o\). If \(G(S)\) is acyclic, define the coordinate face

\(F_S=\{x\in\mathcal B:x_{t,o}=0\text{ whenever }(t,o)\notin S\}.\)

Let \(\mathcal E\) be the set of mass tables of Pareto-optimal assignments. Lemma 1 gives the exact identity

\(\mathcal E=\bigcup_{S:\,G(S)\text{ acyclic}}F_S.\)

Indeed, an efficient table belongs to the face indexed by its support. Conversely, a table in \(F_S\) has category graph contained in the acyclic graph \(G(S)\).

Each nonempty \(F_S\) is a bounded polytope and therefore the convex hull of its finitely many vertices. Let \(V\) be the union of these vertex sets. Although \(V\) can be exponentially large, it is finite, and

\(\operatorname{conv}(\mathcal E)=\operatorname{conv}(V).\)

Every member of \(V\) is itself an efficient mass table.

Using the same separation argument as in Lemma 2, any implementing lottery has expected mass table in the compact convex set \(\operatorname{conv}(V)\). Conversely, any finite convex combination of members of \(V\) can be implemented by choosing measurable assignments realizing those tables. Hence

\(p\text{ is implementable}\quad\Longleftrightarrow\quad r\in\operatorname{conv}(V).\)

We next bound the rational encoding lengths needed for a certificate.

Vertex coordinates have polynomial bit length. Let \(D\) be the product of the positive denominators appearing in all input masses, supplies, and shares. Its binary length is \(O(L)\). In particular, \(D\mu_t\), \(Dq_o\), and \(Dr_{t,o}\) are integers.

Consider a vertex \(v\) of any nonempty \(F_S\). Form a bipartite graph with type vertices and category vertices, placing an edge \((t,o)\) whenever \(v_{t,o}>0\).

This bipartite graph is a forest. Otherwise, on an even cycle of positive entries, alternately adding and subtracting a sufficiently small positive quantity gives two distinct feasible tables in \(F_S\) whose midpoint is \(v\), contradicting that \(v\) is a vertex.

Scale the table by \(D\). Its row and column margins are integers. In each tree component, a leaf’s sole incident edge equals its remaining margin and is therefore an integer. Remove that edge and subtract its value from the other endpoint’s margin. Repeating leaf removal proves that every entry of \(Dv\) is an integer.

Since each mass entry lies between \(0\) and \(1\),

\(v_{t,o}=k_{t,o}/D,\qquad 0\leq k_{t,o}\leq D,\qquad k_{t,o}\text{ an integer}.\)

Thus every vertex coordinate has bit length \(O(L)\).

At most \(d+1\) vertices suffice. Suppose \(r\in\operatorname{conv}(V)\), and choose a representation using the smallest possible number \(k\) of positive coefficients:

\(r=\sum_{j=1}^{k}\alpha_jv^j,\qquad \sum_{j=1}^{k}\alpha_j=1,\qquad \alpha_j>0.\)

The selected vertices are affinely independent. Otherwise there are real numbers \(c_j\), not all zero, with

\(\sum_jc_jv^j=0,\qquad \sum_jc_j=0.\)

The \(c_j\) have both signs. Taking

\(s=\min_{j:\,c_j>0}\alpha_j/c_j\)

and replacing \(\alpha_j\) by \(\alpha_j-sc_j\) preserves the representation, makes all coefficients nonnegative, and makes at least one coefficient zero. This contradicts minimality. Affine independence in \(\mathbb R^d\) gives \(k\leq d+1\).

The coefficients also have polynomial bit length. The coefficient equations can be written as

\(\sum_{j=1}^{k}\alpha_j(Dv^j)=Dr,\qquad \sum_{j=1}^{k}\alpha_j=1.\)

The augmented columns \((Dv^j,1)\) are linearly independent. Choose \(k\) rows giving a nonsingular square system. Its matrix and right-hand side have integer entries of absolute value at most \(D\).

Cramer’s rule expresses each \(\alpha_j\) as a ratio of integer determinants. Expanding the determinants bounds their absolute values by \(k!D^k\). Consequently their binary lengths are

\(O(k\log k+k\log D)=O(k\log k+kL).\)

The unique solution is the original positive coefficient vector. Thus a yes-instance has a certificate consisting of at most \(d+1\) efficient rational tables and rational lottery coefficients, with total encoding length polynomial in \(m,\tau,L\).

A verifier checks nonnegativity, the row and column margins of every table, acyclicity of every category graph, nonnegative coefficients summing to \(1\), and the exact equality of their weighted average to \(r\). Graph construction takes \(O(\tau m^2)\) operations per table; the remaining checks use exact rational arithmetic on polynomial-length numbers. All verification therefore runs in polynomial time.

This proves membership in \(\mathrm{NP}\) and, together with the reduction, establishes \(\mathrm{NP}\text{-completeness}\).
