The continuous mirror question, as graded

Input schools \(S\), ranking types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), and rational per-capita capacities \(\kappa_s\ge 0\) summing to \(1\). For each type \(t\), let \(\phi_t(s)\) be the rank of school \(s\). Find an assignment flow \(x_{t,s}\ge 0\) minimizing \(\sum_{t\in T}\sum_{s\in S}x_{t,s}(\phi_t(s)-1)\), subject to \(\sum_{s\in S}x_{t,s}=\mu_t\) for each \(t\) and \(\sum_{t\in T}x_{t,s}=\kappa_s\) for each \(s\).

Let \(S\) be a nonempty set of \(m\) schools. A ranking type \(t\) is an ordered partition of \(S\) into nonempty indifference classes; \(\phi_t(s)\) is the index of the class containing \(s\), starting at \(1\).
A society is given by its support: the list \(T\) of its \(\tau\) types with positive masses \(\mu_t\), each a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
School capacities \(\kappa_s\) are nonnegative binary rationals with \(\sum_{s\in S}\kappa_s=1\). Let \(L\) be the total input bit length.
An assignment may split each type's mass among schools: choose real \(x_{t,s}\geq0\) satisfying \(\sum_{s\in S}x_{t,s}=\mu_t\) and \(\sum_{t\in T}x_{t,s}=\kappa_s\). All mass is assigned; there are no school-priority or stability constraints.

Conclusion

Finding an exact minimum-cost assignment is solvable in time polynomial in \(m,\tau,L\). The given problem is a rational linear program of polynomial encoding length.

1. Exact linear-programming formulation

For each listed type \(t\in T\) and school \(s\in S\), compute \(c_{t,s}=\phi_t(s)-1\). Because each indifference class is nonempty, there are at most \(m\) classes, so \(0\leq c_{t,s}\leq m-1\).

Consider the linear program

\(\displaystyle \min \sum_{t\in T}\sum_{s\in S}c_{t,s}x_{t,s}\)

subject to

\(\displaystyle \sum_{s\in S}x_{t,s}=\mu_t\quad(t\in T),\)

\(\displaystyle \sum_{t\in T}x_{t,s}=\kappa_s\quad(s\in S),\)

and \(x_{t,s}\geq0\) for every pair.

These are exactly the assignment constraints and objective in the question. Thus its feasible solutions are precisely the permitted assignments, and its optimizers are precisely the requested minimum-cost assignments. Only the \(\tau\) listed types appear.

2. Feasibility and attainment

Define \(x^0_{t,s}=\mu_t\kappa_s\). This assignment is nonnegative, and the normalization assumptions give

\(\displaystyle \sum_s x^0_{t,s}=\mu_t\sum_s\kappa_s=\mu_t,\qquad \sum_t x^0_{t,s}=\kappa_s\sum_t\mu_t=\kappa_s.\)

Hence the feasible set is nonempty, including when some capacities vanish.

Moreover, every feasible assignment satisfies \(0\leq x_{t,s}\leq\mu_t\leq1\). The feasible set is therefore closed and bounded in a finite-dimensional real vector space, hence compact. The objective is continuous, so a minimum is attained.

3. Polynomial encoding length and exact optimization

We use the standard polynomial-time theorem for rational linear programming: a linear program with explicitly given binary rational coefficients can be solved in time polynomial in its total encoding length; when a finite optimum exists, an exact rational optimizer can be returned. This concerns exact optimization, not merely numerical approximation. See the discussion of exact LP algorithms and polynomial-time solvability in [Dadush, Koh, Natura, Olver, and Végh, Introduction](https://homepages.cwi.nl/~dadush/papers/genflow.pdf).

Here all hypotheses hold:

  • There are \(n=m\tau\) variables.
  • There are \(m+\tau\) equalities and \(n\) nonnegativity constraints.
  • Constraint coefficients belong to \(\{0,1\}\), and right-hand sides are the given binary rationals.
  • Objective coefficients are integers requiring \(O(\log(m+1))\) bits.
  • The preceding section proves feasibility and a finite attained optimum.

Even a dense encoding has length \(O((m+\tau)m\tau+m\tau\log(m+1)+L)\), which is polynomial in the requested parameters. Constructing that encoding is also polynomial-time. Applying the theorem therefore returns an exact minimum-cost assignment in polynomial time.

4. Why an exact answer has polynomial size

For completeness, exactness introduces no hidden requirement to output arbitrarily long real numbers.

A linear objective on a nonempty compact polytope has an optimal vertex. At a vertex, \(n\) linearly independent active constraints determine the coordinates uniquely; this standard fact and its rational-size consequence are explained in [Karger’s linear-programming notes](https://courses.csail.mit.edu/6.854/21/Notes/n11-lp.html).

Let \(D\) be the product of the denominators of all input masses and capacities. Then \(\log_2 D\leq L\). At an optimal vertex \(x^*\), choose the independent active constraints and write them as \(Bx^*=b'\). The matrix \(B\) is an invertible integer matrix with entries in \(\{0,1\}\), and the entries of \(b'\) are input masses, capacities, or zero.

Set \(z=Dx^*\). Then \(Bz=Db'\) has integer right-hand side. By Cramer’s rule,

\(\displaystyle x_j^*=\frac{\det B_j}{D\det B},\)

where \(B_j\) replaces column \(j\) of \(B\) by \(Db'\). Since \(0\leq b'_i\leq1\), the determinant expansion gives \(|\det B|\leq n!\) and \(|\det B_j|\leq n!D\). Thus each coordinate has numerator and denominator of bit length \(O(L+n\log(n+1))\).

Consequently, a complete exact optimizer has polynomial encoding length. No separate theorem specific to continuous school assignments is needed.
