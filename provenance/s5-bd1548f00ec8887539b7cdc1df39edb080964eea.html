The anchor (named result in the paper)

Theorem 10 — class: hardness

The continuous mirror question, as graded

Given \(m,k\), a finite set of types with approval sets \(A_t\), positive rational masses \(\mu_t\) summing to \(1\), and proposed utilities \(\alpha_t\), does there exist a size-\(k\) committee \(W\) inducing \(\alpha_t=1\) exactly when \(A_t\cap W\ne\emptyset\), such that no coalition choosing masses \(q_t\in[0,\mu_t]\) can propose an integral committee \(W'\) with \(|W'|\le k\sum_t q_t\) and strictly improve every participating type, meaning \(s_t(W')>\alpha_t\) whenever \(q_t>0\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a set of \(m\ge 1\) candidates and \(1\le k\le m\) an integer. A society is given by its support: a list of \(\tau\ge 1\) types, each with an approval set \(A_t\subseteq C\) (possibly empty) and a positive binary rational mass \(\mu_t\), with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval sets.
The input also gives nonnegative binary rational proposed utilities \(\alpha_t\). For any integral committee \(S\subseteq C\), define the approval Chamberlin–Courant utility \(s_t(S)=\min\{|A_t\cap S|,1\}\).
A feasible committee is an integral set \(W\subseteq C\) with \(|W|=k\) and \(s_t(W)=\alpha_t\) for every type; utilities outside \(\{0,1\}\) therefore make the instance infeasible. No score maximization or tie-breaking is required.
A blocking coalition chooses real masses \(q_t\in[0,\mu_t]\) with \(\sum_tq_t>0\) and an integral committee \(W'\subseteq C\) satisfying \(|W'|\le k\sum_tq_t\) and \(s_t(W')>\alpha_t\) for every type with \(q_t>0\).
Decide whether a feasible committee exists whose induced utilities admit no blocking coalition. State running times in \(m,\tau,k\), and the total input bit length \(L\).

Is this continuous core-membership decision problem in \(\mathsf{P}\), or is it \(\mathsf{NP}\)-hard?

For explicitly listed discrete voters, the corresponding utility-vector core-membership problem is \(\mathsf{NP}\)-complete. With a witnessing committee supplied, discrete membership is polynomial-time decidable through justified representation; a discrete core utility vector can also be constructed in polynomial time.
These discrete results do not establish a classification for the support-encoded mass problem above.

Modeling choices made when packaging the task

  • Defined the omitted score s_t as binary approval Chamberlin–Courant utility.
  • Required equality between every proposed utility and its induced score, rather than only the stated condition for utility 1.
  • Encoded proposed utilities as nonnegative binary rationals; values outside {0,1} are infeasible.
  • Restricted the committee-size domain to integers 1 ≤ k ≤ m and required a nonempty society.
  • Excluded zero-mass coalitions from blocking, resolving the vacuous strict-improvement condition that would otherwise make every instance fail.
  • Allowed real coalition masses and empty approval sets; retained integral committees and the weak proportional entitlement bound.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is \(\mathsf{NP}\)-complete.

When all proposed utilities equal \(1\), blocking is impossible and feasibility is already a covering problem. The reduction below also establishes hardness with both utility values, equal positive masses, and nonempty approval sets of size at most \(3\).

1. Exact characterization of blocking

First reject any instance with some \(\alpha_t\notin\{0,1\}\), since no committee can realize that utility.

Henceforth define
\( U=\{t:\alpha_t=0\}, \qquad r_c=\sum_{\substack{t\in U\\c\in A_t}}\mu_t \)
for each candidate \(c\). Thus \(r_c\) is the approval mass of \(c\) among types assigned utility \(0\).

Lemma. The proposed utility vector admits no blocking coalition if and only if
\( r_c<1/k \)
for every candidate \(c\).

Proof. Suppose \(r_c\ge 1/k\). Choose \(W'=\{c\}\), and set \(q_t=\mu_t\) for every \(t\in U\) approving \(c\), with all other \(q_t=0\). Their total mass is \(r_c>0\), every participating type improves from \(0\) to \(1\), and
\( |W'|=1\le kr_c. \)
This is a blocking coalition.

Conversely, suppose every \(r_c<1/k\), and assume that \((q,W')\) blocks. A participating type must belong to \(U\), because utility \(1\) cannot be strictly improved. Moreover, each participating type approves a member of \(W'\). In particular, \(W'\ne\varnothing\). Consequently,
\( \displaystyle \sum_tq_t \le \sum_{\substack{t\in U\\A_t\cap W'\ne\varnothing}}\mu_t \le \sum_{c\in W'}r_c < \frac{|W'|}{k}. \)
The middle inequality counts every type on its left at least once on its right. The final strict inequality follows from the hypothesis for every member of the nonempty committee \(W'\). This contradicts the budget requirement \(|W'|\le k\sum_tq_t\). ∎

Thus stability depends only on the proposed utilities and can be checked without finding a feasible committee. Equality at the threshold permits blocking.

2. Feasibility and computational upper bounds

Let
\( P=\{t:\alpha_t=1\}, \qquad F=\bigcup_{t\in U}A_t, \qquad E=C\setminus F. \)

A committee realizes the proposed vector exactly when it has size \(k\), lies in \(E\), and intersects every \(A_t\) with \(t\in P\).

Equivalently, feasibility holds precisely when:

  • \(|E|\ge k\);
  • some \(T\subseteq E\), with \(|T|\le k\), intersects every approval set indexed by \(P\).

Indeed, a feasible committee provides such a \(T\). Conversely, any such \(T\) can be extended to size \(k\) using candidates from \(E\); extension preserves every required utility.

Membership in \(\mathsf{NP}\). When such a \(T\) exists, there is one with \(|T|\le\min(k,|P|)\): retain one selected representative for each positive-utility type. A certificate lists these candidates. One verifies their eligibility, all required intersections, and \(|E|\ge k\), then checks the lemma’s inequalities. All these checks take polynomial time in \(L\).

For completeness, the rational comparisons require no numerical approximation. Write \(\mu_t=a_t/b_t\), and take
\( D=\prod_t b_t, \qquad w_t=a_t(D/b_t). \)
The relevant inequalities become the integer comparisons
\( k\sum_{\substack{t\in U\\c\in A_t}}w_t<D. \)
The binary lengths of \(D\), the \(w_t\), and their sums are \(O(L)\). Processing the explicitly encoded approval incidences with schoolbook integer arithmetic gives a conservative polynomial bound \(O(L^3)\).

Two deterministic running-time bounds are also available:

  • Committee enumeration: after stability preprocessing, enumerate the size-\(k\) subsets of \(E\) and check their intersections. A conservative bit-operation bound is

\( O\!\left(L^3+\binom{m}{k}k\tau L\right). \)

  • Dynamic programming over types: put \(p=|P|\le\tau\). Represent each eligible candidate by the subset of \(P\) that approves it. Process candidates successively, maintaining the minimum number selected for each exact union of covered types. For a candidate with mask \(B\), each state \(R\) either remains \(R\), or moves to \(R\cup B\) at cost one. Induction on the processed candidates proves that these states give the minimum covering cardinality. Feasibility then follows from the characterization above. A conservative bound, accounting for masks and counters, is

\( O\!\left(L^3+m2^p\bigl(\tau+\log(m+1)\bigr)\right). \)

In particular, the problem is fixed-parameter tractable in the support size \(\tau\).

3. Hardness with equal masses and both utility values

We reduce from the standard \(\mathsf{NP}\)-complete problem \(3\)-SAT; its NP-completeness is stated in [CMU’s lecture on NP-completeness](https://www.cs.cmu.edu/~fp/courses/flac/lectures/lecture33.html).

Let the formula have variables \(x_1,\ldots,x_n\), where \(n\ge1\). Remove tautological clauses, repeated literals within clauses, and duplicate clauses. This preserves satisfiability. Denote the remaining clauses by \(K_1,\ldots,K_h\); each has between one and three literals.

Construct candidates
\( C=\{c_i^+,c_i^-:1\le i\le n\}\cup\{d\}, \qquad k=n. \)

There are the following types:

  • For each variable \(x_i\), a type approving \(\{c_i^+,c_i^-\}\), with proposed utility \(1\).
  • For each clause \(K_j\), a type approving the candidates corresponding to its literals, with proposed utility \(1\). A positive literal \(x_i\) corresponds to \(c_i^+\), and a negative literal corresponds to \(c_i^-\).
  • One type approving \(\{d\}\), with proposed utility \(0\).

Assign every type mass
\( \mu_t=\frac1{n+h+1}. \)

The constructed instance has
\( m=2n+1,\qquad \tau=n+h+1,\qquad k=n. \)
Its encoding length and construction time are polynomial in the formula’s encoding length. All masses are positive binary rationals and sum to \(1\). The approval sets are nonempty and have size at most \(3\). The preprocessing also ensures that these approval sets are distinct, if support types are required to have distinct approval sets.

Stability holds for every constructed instance. The only type assigned utility \(0\) approves \(d\). Hence
\( r_d=\frac1{n+h+1}<\frac1n=\frac1k, \qquad r_{c_i^+}=r_{c_i^-}=0. \)
The lemma therefore excludes every blocking coalition.

It remains to establish the feasibility equivalence.

If the formula is satisfiable, choose \(c_i^+\) when \(x_i\) is true and \(c_i^-\) when it is false. This selects exactly \(n=k\) candidates. Every variable type is covered, every clause type is covered by a true literal, and \(d\) is excluded. Thus the committee realizes all proposed utilities and is stable.

If the constructed instance has a feasible committee, its utility-\(0\) type forces \(d\) to be excluded. Each variable type requires at least one candidate from its pair. These \(n\) pairs are disjoint, and the committee has exactly \(n\) members, so it contains exactly one candidate from each pair. Define \(x_i\) to be true precisely when \(c_i^+\) is selected. Every clause type is covered, so every clause has a true literal. The formula is satisfiable.

This is a polynomial many-one reduction, proving \(\mathsf{NP}\)-hardness. Together with membership in \(\mathsf{NP}\), it proves \(\mathsf{NP}\)-completeness. Thus an unrestricted polynomial-time algorithm would imply \(\mathsf{P}=\mathsf{NP}\).
