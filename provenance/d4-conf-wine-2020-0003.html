The continuous mirror question, as graded

Given a finite good set \(G\), an explicit type set \(T\subseteq 2^G\), rational masses \(\mu_t\) with \(\sum_t\mu_t=1\), and rational per-capita supplies \(\rho_g\) satisfying \(0\le\rho_g\le\sum_{t:g\in t}\mu_t\), compute in time \(\operatorname{poly}(m,\tau,L)\) a mass assignment \(\lambda_{t,B}\ge0\) for \(B\subseteq t\), satisfying \(\sum_{B\subseteq t}\lambda_{t,B}=\mu_t\) and \(\sum_{t,B:g\in B}\lambda_{t,B}=\rho_g\), together with a polynomial-size distribution \(\mathcal D\) over integral-bundle mass assignments implementing these marginals, such that \(u_t=\mu_t^{-1}\sum_{B\subseteq t}|B|\lambda_{t,B}\) maximizes \(\sum_{t:\mu_t>0}\mu_t\log u_t\), the aggregate rule is ex ante EF, ex ante PO, and ex ante GSP, and every supported integral assignment is ex post EF1.

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a finite good set and \(T\subseteq 2^G\) an explicit set of binary-valuation types; type \(t\) values \(B\subseteq G\) by \(v_t(B)=|t\cap B|\). Type \(t\) has rational mass \(\mu_t\), with \(\sum_t\mu_t=1\), and good \(g\) has rational per-capita supply \(\rho_g\leq\sum_{t:g\in t}\mu_t\).

A type-mass allocation is \(\lambda_{t,B}\geq0\) for \(B\subseteq t\), with \(\sum_{B\subseteq t}\lambda_{t,B}=\mu_t\) and \(\sum_{t,B:g\in B}\lambda_{t,B}=\rho_g\). Its per-capita utility is \(u_t=\mu_t^{-1}\sum_{B\subseteq t}|B|\lambda_{t,B}\) for \(\mu_t>0\). An integral-bundle mass assignment gives every population member an entire bundle \(B\subseteq t\); a distribution implements \(\lambda\) when its expected type-bundle masses are \(\lambda\).

Target. Is there a polynomial-time algorithm, in \(m=|G|\), \(\tau=|T|\), and input bit-length \(L\), that returns such a \(\lambda\) maximizing \(\sum_{t:\mu_t>0}\mu_t\log u_t\), together with a polynomial-size implementing distribution that is ex ante EF, ex ante PO, ex ante GSP, and ex post EF1; or is this problem NP-hard?

Nearest known results. For finitely many individual agents with binary additive valuations, the fractional maximum-Nash-welfare rule is polynomial-time computable and is ex ante EF, ex ante PO, ex ante GSP, and ex post EF1.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

Under the standard interpretation—each realized assignment respects supply, ex ante EF compares individual population members, and a polynomial-size distribution explicitly lists its deterministic outcomes—the requested polynomial-size distribution need not exist. This is an output-size obstruction, not an NP-hardness proof. A succinct randomized implementation is a different output requirement.

Here is a precise obstruction, followed by a compact formulation of the allocation problem.

Proved obstruction. For any positive integer \(k\), take
\(G=\{g\}\), \(T=\{t\}\), \(t=\{g\}\), \(\mu_t=1\), and \(\rho_g=2^{-k}\).
These data satisfy the supply hypothesis, and their binary encoding has length \(O(k)\).

There are only two permissible bundles. Consequently, feasibility uniquely determines
\(\lambda_{t,\{g\}}=2^{-k}\) and
\(\lambda_{t,\varnothing}=1-2^{-k}\).
The unique feasible utility is \(u_t=2^{-k}>0\). Thus this allocation maximizes the stated logarithmic objective; there is no optimization difficulty in this example.

Model the population by a probability space \((X,\nu)\). A deterministic feasible assignment gives \(g\) to a measurable recipient set of mass at most \(2^{-k}\).

Suppose an implementing lottery has deterministic outcomes indexed by \(j\in\{1,\ldots,K\}\), with positive probabilities \(p_j\). Let \(A_j\subseteq X\) be the recipient set in outcome \(j\). A member \(a\in X\) receives expected utility
\(q(a)=\sum_{j=1}^{K}p_j\mathbf{1}_{A_j}(a)\).

All members have identical valuations. Individual ex ante EF therefore requires \(q(a)\geq q(b)\) for every ordered pair of members \(a,b\), so their expected utilities are equal. The same conclusion holds almost everywhere if fairness is imposed almost everywhere.

Implementation gives
\(\int_X q(a)\,d\nu(a)=2^{-k}\).
Hence \(q(a)=2^{-k}>0\) almost everywhere. Every such member belongs to at least one recipient set, and therefore
\(1=\nu(\bigcup_{j=1}^{K}A_j)\leq\sum_{j=1}^{K}\nu(A_j)\leq K2^{-k}\).
It follows that \(K\geq 2^k\).

Thus the number of explicitly listed deterministic outcomes must be exponential in the input length. This lower bound already follows from feasibility and ex ante EF, independently of the other requested properties.

The obstruction is tight in this example. Partition the population into \(2^k\) equal-mass sets and choose one uniformly to receive \(g\). Every member receives it with probability \(2^{-k}\). Every outcome is EF1: removing the sole good from any envied bundle leaves an empty bundle.

Equivalently, realize the instance using \(N=2^k\) equally weighted individuals and one physical good. Ex ante EF requires each individual to win with probability \(1/N\), while each deterministic allocation has one winner. At least \(N\) outcomes are necessary.

Why this does not contradict the finite-agent result. The finite-agent theorem uses an explicit individual-agent input and establishes polynomial-time implementation in that setting. Here the population can be exponentially larger than its type-mass encoding. The same support bound is linear in the explicit population size but exponential in the compressed input length. The cited paper also defines ex ante EF through comparisons of individual agents’ expected valuations. [Halpern, Procaccia, Psomas, and Shah, *Fair Division with Binary Valuations: One Rule to Rule Them All*](https://www.cs.toronto.edu/~nisarg/papers/binaryMNW.pdf).

A separate proved simplification. The exponentially indexed bundle variables are not themselves necessary for describing feasible marginals.

For each \(t\in T\) and \(g\in t\), define
\(x_{t,g}=\sum_{B\subseteq t:\,g\in B}\lambda_{t,B}\).
Every feasible allocation satisfies
\(0\leq x_{t,g}\leq\mu_t\) and
\(\sum_{t:\,g\in t}x_{t,g}=\rho_g\).
Moreover, \(u_t=\mu_t^{-1}\sum_{g\in t}x_{t,g}\) whenever \(\mu_t>0\).

Conversely, every vector satisfying these marginal constraints comes from a feasible bundle-mass allocation. To prove this, fix a positive-mass type and set \(z_g=x_{t,g}/\mu_t\). For a uniform parameter \(r\in[0,1]\), define
\(B_t(r)=\{g\in t:r<z_g\}\).
Then \(\Pr(g\in B_t(r))=z_g\). Assign mass
\(\lambda_{t,B}=\mu_t\Pr(B_t(r)=B)\).
These masses sum to \(\mu_t\), have the prescribed marginals, and therefore satisfy every supply equality.

The bundle changes only at the distinct thresholds \(z_g\), so this construction uses at most \(|t|+1\) positive bundle masses for type \(t\). Zero-mass types receive zero bundle masses. For rational marginals, sorting the thresholds and taking consecutive differences constructs this sparse representation in polynomial time in their encoding length.

Consequently, the welfare objective can be written using at most \(m\tau\) marginal variables. This observation does not by itself prove exact polynomial-time welfare optimization or provide a fair individual-level implementation. In particular, sparse bundle masses do not bound the support needed to randomize fairly over named population members.

Remaining interpretation issue. The question defines implementation through expected type-bundle masses, but those expectations alone do not determine individual ex ante EF. In the one-type example, always serving the same population subset implements the required masses but violates individual ex ante EF.

The exponential bound applies to an explicit lottery over feasible deterministic assignments. It does not exclude a short sampling description: “choose one of the \(2^k\) equal blocks uniformly” has a compact description despite its exponential support. Likewise, allowing supply to be respected only in expectation changes the problem.

Thus an explicit polynomial-support interpretation has a rigorous negative answer. The complexity of the variant permitting succinct randomized implementations, including its strategyproof mechanism requirement, remains unsettled here.
