The continuous mirror question, as graded

Given a finite set of goods \(G\), additive valuation types \(T\), rational masses \(\mu_t>0\) summing to \(1\), and an allocation \(x_{t,B}\ge 0\) of type mass to integral bundles \(B\subseteq G\), with \(\sum_B x_{t,B}=\mu_t\), decide whether there are common prices \(p_g\in[0,1]\) such that every bundle \(B\) with \(x_{t,B}>0\) maximizes type \(t\)'s additive utility among all integral bundles affordable at budget \(1\). The per-capita supply of good \(g\) is the amount allocated, \(q_g=\sum_{t,B:g\in B}x_{t,B}\).

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a nonempty set of \(m\) goods. A society is given by its support: a list of \(\tau\) additive valuation types with binary-rational masses \(\mu_t>0\), where \(\sum_t\mu_t=1\). Here \(\tau\) counts listed types, not possible types. Each type has binary-rational values \(v_{t,g}\ge0\); utility ties are allowed.
The given allocation is an explicit list of \(K\) positive binary-rational entries \(x_{t,B}\), with integral bundles \(B\subseteq G\); omitted entries are zero and \(\sum_Bx_{t,B}=\mu_t\). Each individual receives an integral bundle; the entries describe masses receiving those bundles.
Per-capita supplies are \(q_g=\sum_{t,B:g\in B}x_{t,B}>0\), so the given allocation exhausts every good's supply. Let \(L\) be the total binary input length; state running times in \(m,\tau,K,L\).
The CEEI-support decision problem asks whether there exist real common prices \(p_g\in[0,1]\) such that every \(B\) with \(x_{t,B}>0\) is affordable at budget \(1\) and maximizes type \(t\)'s additive utility over all integral bundles \(C\subseteq G\) satisfying \(\sum_{g\in C}p_g\le1\). Any utility-maximizing bundle is acceptable, including ties.

Is this continuous CEEI-support decision problem in \(\mathrm{P}\), or is it \(\mathrm{coNP}\)-hard?

For finite agents, CEEI supportability has an exact non-strict linear-feasibility characterization, potentially with exponentially many constraints ([Bouveret–Lemaître](https://arxiv.org/abs/1604.01734)).
Deciding whether a given discrete allocation admits supporting equilibrium prices is \(\mathrm{coNP}\)-hard even with additive valuations ([Brânzei](https://comsoc-community.org/assets/theses/phd-branzei.pdf)). No result settling exactly the continuous decision problem above was located.

Modeling choices made when packaging the task

  • Valuation encoding was unspecified: use nonnegative binary-rational item values, allowing zero values and utility ties.
  • Allocation encoding was unspecified: explicitly list positive binary-rational type–bundle masses and treat omitted entries as zero.
  • Require a nonempty goods set and positive allocated supply for every good, carrying over the discrete model's complete allocation of all goods.
  • Prices may be real; each allocated bundle must itself be affordable, and ties require no deterministic tie-breaking.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The continuous CEEI-support decision problem is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions. Hardness holds even when \(\tau=K=2\), both types have mass \(1/2\), and every good has supply \(1/2\).

Thus a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\). The proof below allows utility ties and does not assume that supported bundles exhaust their recipients’ budgets.

1. Exact supporting-price constraints

For a bundle \(D\subseteq G\), write \(p(D)=\sum_{g\in D}p_g\) and \(v_t(D)=\sum_{g\in D}v_{t,g}\).

By the definition in the question, prices support the allocation exactly when:

  • \(0\le p_g\le1\) for every good \(g\);
  • \(p(B)\le1\) for every listed positive entry \(x_{t,B}\);
  • \(p(C)>1\) whenever \(x_{t,B}>0\) and \(v_t(C)>v_t(B)\).

Indeed, the last condition excludes exactly the strictly better bundles from the affordable set. Bundles tied with \(B\) impose no exclusion constraint.

This is a finite system of linear inequalities, some strict, with at most \(2m+K+K2^m\) rows. The masses do not enter these inequalities: their positivity determines which bundles must be optimal.

2. A reduction from the complement of SUBSET-SUM

We use the standard \(\mathrm{NP}\)-complete SUBSET-SUM problem with positive binary-encoded integers \(w_1,\ldots,w_n\) and target \(T\). Assume \(n\ge1\) and \(1\le T\le W\), where \(W=\sum_{i=1}^n w_i\). This restriction preserves hardness: an instance with \(T>W\) is immediately a no-instance and can be replaced by the fixed no-instance with weight \(2\) and target \(1\).

The construction is a variant of the exchange construction in [Brânzei’s thesis, Theorem 49](https://comsoc-community.org/assets/theses/phd-branzei.pdf). We prove its correctness directly for the present definition.

Construction

Let \(I=\{g_1,\ldots,g_n\}\) and \(G=I\cup\{a,b\}\). Define two additive valuation types:

| Type | \(v_{t,g_i}\) | \(v_{t,a}\) | \(v_{t,b}\) |
|---|---:|---:|---:|
| \(1\) | \(w_i\) | \(T-\tfrac12\) | \(2W\) |
| \(2\) | \(w_i\) | \(T+\tfrac12\) | \(0\) |

Give each type mass \(1/2\), and specify exactly two positive allocation entries:

\(x_{1,\{a,b\}}=\tfrac12,\qquad x_{2,I}=\tfrac12.\)

All values are nonnegative binary rationals. Every good occurs in exactly one allocated bundle, so \(q_g=1/2>0\) for every \(g\). Consequently, this is a valid instance with \(m=n+2\) and \(\tau=K=2\).

For \(S\subseteq I\), define \(w(S)=\sum_{g_i\in S}w_i\).

A subset-sum solution prevents support

Suppose \(S\subseteq I\) satisfies \(w(S)=T\). Assume, for contradiction, that \(p\) supports the constructed allocation.

Type \(1\) strictly prefers \(\{b\}\cup S\) to its assigned bundle, because

\(v_1(\{b\}\cup S)=2W+T>2W+T-\tfrac12=v_1(\{a,b\}).\)

Optimality therefore requires \(p_b+p(S)>1\). Affordability of the assigned bundle gives \(p_a+p_b\le1\). Combining these inequalities yields

\(p(S)>1-p_b\ge p_a.\)

Now consider type \(2\)’s alternative \(D=(I\setminus S)\cup\{a\}\). Its price satisfies

\(p(D)=p(I)-p(S)+p_a<p(I)\le1,\)

so it is affordable. Its utility is

\(v_2(D)=W-T+T+\tfrac12=W+\tfrac12>W=v_2(I).\)

This contradicts type \(2\)’s optimality. Hence a subset-sum solution implies that the allocation is unsupported.

Absence of a subset-sum solution gives explicit supporting prices

Suppose no \(S\subseteq I\) satisfies \(w(S)=T\). Set

\(p_{g_i}=\dfrac{w_i}{W},\qquad p_a=\dfrac{T}{W},\qquad p_b=1-\dfrac{T}{W}.\)

Because \(0<w_i\le W\) and \(1\le T\le W\), every price belongs to \([0,1]\). Both assigned bundles have price exactly \(1\).

We verify optimality against every integral bundle.

Type \(1\). Its assigned utility is \(U_1=2W+T-\tfrac12\). Let \(C\) be affordable.

  • If \(b\notin C\), then \(v_1(C)\le W+T-\tfrac12<U_1\).
  • If both \(a,b\in C\), write \(C=\{a,b\}\cup S\). Its price is \(1+w(S)/W\). Affordability forces \(w(S)=0\), and positive weights force \(S=\varnothing\). Thus \(C\) is the assigned bundle.
  • If \(b\in C\) and \(a\notin C\), write \(C=\{b\}\cup S\). Affordability gives \(w(S)\le T\). Strict improvement would require \(w(S)>T-\tfrac12\). Since \(w(S)\) is integral, improvement and affordability together would force \(w(S)=T\), contrary to the assumption.

Thus type \(1\)’s assigned bundle maximizes utility.

Type \(2\). Its assigned utility is \(U_2=W\). Let \(C\) be affordable, and write \(S=C\cap I\).

If \(a\notin C\), then \(v_2(C)=w(S)\le W\). If \(a\in C\), nonnegative prices imply

\(p_a+p(S)\le p(C)\le1,\)

hence \(T+w(S)\le W\). Let \(R=I\setminus S\), so \(w(R)=W-w(S)\). Affordability gives \(w(R)\ge T\).

For \(C\) to improve utility strictly, we would need

\(w(S)+T+\tfrac12>W,\)

equivalently \(w(R)<T+\tfrac12\). Integrality then gives \(w(R)\le T\). Together these inequalities force \(w(R)=T\), again contradicting the assumption. The presence of \(b\) does not change type \(2\)’s utility.

Therefore these prices support both assigned bundles.

Complexity consequence

We have proved the exact equivalence:

\(\text{constructed allocation is supportable}\quad\Longleftrightarrow\quad\text{the SUBSET-SUM instance has no solution}.\)

The construction takes polynomial time in the source input length. Its output length \(L\) is polynomial in that length; it uses \(m=n+2\) goods and \(\tau=K=2\).

This proves \(\mathrm{coNP}\)-hardness.

3. Membership in \(\mathrm{coNP}\)

Consider the price inequalities from Section 1. Every row defines a convex halfspace in \(\mathbb R^m\), possibly open.

The finite form of Helly’s theorem states that if a finite family of convex sets in \(\mathbb R^m\) has empty intersection, then some subfamily of at most \(m+1\) sets already has empty intersection. Closedness is unnecessary; see [Byrne, *Continuous Optimization*, Theorem 6.15](https://faculty.uml.edu/cbyrne/optfirst.pdf#page=100). Its hypotheses hold here because the family is finite and every constraint set is convex.

The non-strict constraints alone are feasible: \(p=0\) satisfies all bounds and assigned-bundle affordability constraints. Thus, whenever support is impossible, Helly’s theorem provides at most \(m+1\) strict exclusion constraints which, together with all the non-strict constraints, are infeasible.

A certificate lists these strict constraints. Each is specified by a positive-entry index \((t,B)\) and an alternative bundle \(C\). The verifier checks \(v_t(C)>v_t(B)\) using exact rational arithmetic. The certificate has

\(O\bigl((m+1)(m+\log(K+1))\bigr)\)

bits.

It remains to check infeasibility exactly, despite strict inequalities. Introduce a common margin \(\delta\) and solve the rational linear program maximizing \(\delta\), subject to:

  • \(0\le p_g\le1\) for every \(g\);
  • \(p(B)\le1\) for every positive allocation entry;
  • \(0\le\delta\le1\);
  • \(p(C)\ge1+\delta\) for every certified exclusion.

The certified mixed system is feasible exactly when this linear program has a feasible solution with \(\delta>0\). In one direction, a positive margin satisfies every strict exclusion. In the other, finitely many satisfied strict exclusions have a positive minimum slack, which can be capped at \(1\).

The linear program has \(m+1\) variables and \(O(K+m)\) constraints, with integral coefficients of constant bit length. Exact rational linear programming and the utility checks take \(\operatorname{poly}(m,\tau,K,L)\) time.

The verifier accepts the certificate when the linear program is infeasible or its optimum is \(0\). A supportable instance cannot have such a certificate, while Helly’s theorem guarantees one for every unsupported instance. Therefore the problem belongs to \(\mathrm{coNP}\).

4. Conclusion and running times

The problem is \(\mathrm{coNP}\)-complete, even with \(\tau=K=2\) and uniform supply \(q_g=1/2\).

For arbitrary inputs, enumerating all alternative bundles and using the same margin linear program gives an exact deterministic algorithm running in \(2^{O(m)}\operatorname{poly}(m,\tau,K,L)\) time. Unsupported instances have certificates verifiable in \(\operatorname{poly}(m,\tau,K,L)\) time.
