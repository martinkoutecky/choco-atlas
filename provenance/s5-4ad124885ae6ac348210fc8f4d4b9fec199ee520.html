The continuous mirror question, as graded

Given a finite base candidate set \(C\), spoiler set \(D\), distinguished candidate \(w\in C\), budget \(q\in\mathbb{N}\), and an explicitly supported rational distribution \(\mu\) over complete score types \(r\in\{0,1,2\}^{C\cup D}\), does there exist \(D'\subseteq D\) with \(|D'|\le q\) such that \(w\) is the unique \(2\)-NRV winner on \(C\cup D'\), where each type is restricted to that set, normalized as in the paper, and aggregate scores are weighted by \(\mu\)?

Packaged proof task (what the prover saw — nothing else)

Given disjoint finite candidate sets \(C,D\), a distinguished candidate \(w\in C\), and a binary-encoded budget \(q\in\mathbb Z_{\ge0}\), let \(m=|C\cup D|\).
A society is given by its support: a list of \(\tau\) distinct complete score types \(r\in\{0,1,2\}^{C\cup D}\), each with positive binary-rational mass \(\mu(r)\), with \(\sum_r\mu(r)=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. State running times in \(m,\tau,L,q\).
For a nonempty participating set \(A\), put \(a_r=\min_{c\in A}r(c)\) and \(b_r=\max_{c\in A}r(c)\). Under \(2\)-NRV, type \(r\) contributes \(2(r(c)-a_r)/(b_r-a_r)\) to candidate \(c\in A\) if \(a_r<b_r\), and zero otherwise.
Aggregate scores are \(S_A(c)=\sum_r\mu(r)\widehat r_A(c)\), where \(\widehat r_A(c)\) is that normalized contribution. All score maximizers are winners; uniqueness requires strict superiority over every other participating candidate.
The decision problem asks whether some \(D'\subseteq D\), with \(|D'|\le q\), makes \(w\) the unique winner on \(A=C\cup D'\). Candidate additions are indivisible; the society stays fixed.

Is this decision problem solvable in polynomial time, or is it NP-hard?

For finite lists of voters, constructive control by adding at most a prescribed number of candidates under \(2\)-NRV is NP-hard. [Menton](https://arxiv.org/pdf/1005.5698)

Classification

The decision problem is \(\mathrm{NP}\)-complete. Hardness already holds when every mass is dyadic, meaning that its denominator is a power of two.

1. The finite-voter hardness theorem applies

Menton’s Theorem 5.4 establishes \(\mathrm{NP}\)-hardness of constructive control by adding at most a prescribed number of candidates under \(2\)-NRV. The paper uses the unique-winner model (§4), and its normalization rule assigns zero contribution to constant ballots (§3). These conventions match the present problem. [Menton, *Normalized Range Voting Broadly Resists Control*](https://arxiv.org/pdf/1005.5698)

We give a polynomial reduction from that finite-voter problem to the stated support representation.

Let a source instance have an explicit list of \(N\ge 1\) voters, each specified by a complete score vector in \(\{0,1,2\}^{C\cup D}\). Retain \(C,D,w\), and the candidate-addition budget \(q\).

For each distinct complete type \(r\), let \(n(r)\) be its multiplicity. Let \(r_0\) denote the complete all-zero type, and put

\[ P=2^{\lceil\log_2 N\rceil}. \]

Define modified multiplicities by adding \(P-N\) to the multiplicity of \(r_0\), introducing that type if necessary. Denote the resulting multiplicities by \(n'(r)\). List precisely those types with \(n'(r)>0\), with masses

\[ \mu(r)=\frac{n'(r)}{P}. \]

All listed masses are positive dyadic rationals, and their sum is one. The listed complete types are distinct.

2. Every possible candidate addition preserves the outcome

Fix any \(D'\subseteq D\), and let \(A=C\cup D'\). This set is nonempty because \(w\in C\).

Write the source election’s total normalized score as

\[ T_A(c)=\sum_r n(r)\widehat r_A(c). \]

Normalization depends only on the complete type and the participating set. Thus voters with the same type have identical normalized contributions.

Moreover, \(r_0\) is constant on every participating set, so \(\widehat r_{0,A}(c)=0\). Consequently, the target society satisfies

\[ S_A(c) =\sum_r\frac{n'(r)}P\widehat r_A(c) =\frac1P\sum_r n(r)\widehat r_A(c) =\frac{T_A(c)}P. \]

Since \(P>0\), for every participating competitor \(c\),

\[ S_A(w)>S_A(c) \quad\Longleftrightarrow\quad T_A(w)>T_A(c). \]

Hence \(w\) is the unique winner in the target instance exactly when it is the unique winner in the source instance, for every candidate subset \(D'\). The available candidates and budget are unchanged, so the reduction preserves both yes-instances and no-instances.

The construction has polynomial size. Its support size is at most \(N+1\), and each numerator and denominator uses \(O(\log(N+1))\) bits. Grouping complete score vectors and computing their multiplicities takes polynomial time in the explicit source input length. Padding is performed by increasing one binary-encoded multiplicity; it does not require creating additional voter records.

Therefore the stated rational-mass problem is \(\mathrm{NP}\)-hard.

3. Exact verification is polynomial

A certificate is a subset \(D'\subseteq D\), represented by a bit vector of length \(|D|\). Verify \(|D'|\le q\), and set \(A=C\cup D'\).

For each support type, compute its minimum and maximum on \(A\). Under \(2\)-NRV, every normalized contribution belongs to \(\{0,1,2\}\):

  • A constant type contributes zero.
  • If the score range is one, normalization maps its two scores to zero and two.
  • If the score range is two, normalization leaves its scores unchanged.

These computations take \(O(m\tau)\) elementary operations.

Write each mass as \(\mu(r_i)=p_i/d_i\), with positive integers \(p_i,d_i\). Set

\[ H=\prod_{i=1}^{\tau}d_i, \qquad W_i=p_i\frac{H}{d_i}. \]

The bit length of \(H\) is \(O(L)\), since the sum of the encoded denominator lengths is at most \(L\). Because the masses sum to one,

\[ \sum_{i=1}^{\tau}W_i=H. \]

Compute the integer scores

\[ U_A(c)=\sum_{i=1}^{\tau}W_i\widehat r_{i,A}(c). \]

They satisfy \(U_A(c)=H S_A(c)\) and \(0\le U_A(c)\le 2H\), so their bit lengths are \(O(L)\). Accept exactly when \(U_A(w)>U_A(c)\) for every other \(c\in A\).

Using schoolbook integer arithmetic, this verifier runs in

\[ O\!\left(L+\tau L^2+m\tau L\right) \]

bit operations. The budget is handled through its binary encoding; there is no factor proportional to its numerical value.

For completeness, exhaustive search gives a deterministic running-time bound of

\[ O\!\left( \left(\sum_{j=0}^{\min\{q,|D|\}}\binom{|D|}{j}\right) \left(L+\tau L^2+m\tau L\right) \right). \]

Thus the problem belongs to \(\mathrm{NP}\), and the hardness reduction proves \(\mathrm{NP}\)-completeness. A polynomial-time algorithm exists if and only if \(\mathrm{P}=\mathrm{NP}\).
