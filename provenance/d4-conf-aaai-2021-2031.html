The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to one, bounded type-specific contact-stub counts, rational transmission probabilities \(w_{tu}\), and rational seed intensities \(\lambda_t\), take populations with type proportions tending to \(\mu\). Pair compatible stubs uniformly, activate each type-\(t\) agent initially with probability \(\lambda_t/n\), and run the Independent Cascade Model with transmission probability \(w_{tu}\) on type-\(t\)-to-type-\(u\) contacts. Compute the exact limiting distribution of the final infected fraction \(\rho_n\), and determine the complexity in \(|T|\), the parameter bit length, and the degree bound.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), with \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type \(t\) has integer stub counts \(d_{tu}\geq0\) specifying contacts with type \(u\), with \(\sum_u d_{tu}\leq D\) and \(\mu_t d_{tu}=\mu_u d_{ut}\). Set \(m=|\{(t,u):d_{tu}>0\}|\). Transmission probabilities \(w_{tu}\in[0,1]\) and seed intensities \(\lambda_t\geq0\) are binary rationals; \(L\) is the total input bit length.
For population sizes \(n\) making all \(n\mu_t\) integral and each within-type stub pool even, use exactly \(n\mu_t\) agents of type \(t\). Match the reciprocal stub pools uniformly, conditioning on a simple undirected contact graph. Restrict to inputs for which such graphs exist for all sufficiently large admissible \(n\).
Independently seed each type-\(t\) agent with probability \(\lambda_t/n\), for sufficiently large \(n\), and run the Independent Cascade Model with independent directed transmission trials of probability \(w_{tu}\). Let \(\rho_n\) be the final infected fraction; its law averages over graph construction, seeds, and transmissions.
For exact computation, access a limiting law \(\nu\) through rational CDF cuts: given binary rationals \(x,q\in[0,1]\), decide whether \(\nu([0,x])\geq q\), including equality. Include their encoding in \(L\).

Does \(\rho_n\) have a weak limiting law for every admissible input, and is the exact limiting-distribution problem, in this CDF-cut formulation, in \(\mathrm{P}\) or \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L,D\).

For finite trees, SDP computes the exact Independent Cascade cascade-size distribution using \(O(N^2)\) arithmetic operations ([Burkholz–Quackenbush](https://ojs.aaai.org/index.php/AAAI/article/download/16844/16651)).
For bounded-degree configuration-model SIR epidemics, final-size central limit theorems cover fixed initial infective counts conditional on a large outbreak; this does not establish the exact CDF-cut complexity above ([Ball](https://arxiv.org/abs/1812.03105)).

Modeling choices made when packaging the task

  • Undefined stub compatibility is interpreted as destination-type-labelled stubs, paired with reciprocal pools; impose mass-balance equations and bound total degree by D.
  • Use exact rational type proportions along admissible population sizes, resolving rounding, reciprocal-pool balance, and within-type parity.
  • Condition uniform matching on a simple graph, following the discrete contact-graph domain, and require eventual feasibility.
  • Transmission probabilities lie in [0,1]; seed intensities are finite nonnegative rationals, with population sizes sufficiently large to make seed probabilities valid.
  • The requested distribution averages over all graph and cascade randomness; convergence means weak convergence.
  • Because exact limiting probabilities need not have finite rational encodings, formalize exact access through rational CDF comparisons, with equality included.
  • Limit existence was unstated; retain it as part of the question rather than promise convergence.
  • Define m as the number of nonzero ordered stub specifications and L as total binary input length, including CDF queries.

Status and proved results

The exact CDF-cut problem is $\mathrm{NP}$-hard already on admissible inputs with $D=3$ whose limiting laws exist.

I also prove two convergence results:

  • Every admissible input with $D\leq 2$ has a weak limiting law, described explicitly below. This includes multitype deterministic critical cases and transmission that is deterministic in only one direction.
  • For arbitrary $D$, a strict spectral-radius condition on the nonbacktracking transmission matrix implies convergence to $\delta_0$.

Universal convergence remains unresolved here. In particular, the arguments below do not establish convergence for every higher-degree input. Thus the overall resolution is partial.

Throughout, an input is fixed while $n$ tends to infinity through all its admissible population sizes.

1. A convergence-to-zero criterion for arbitrary degree

1.1. Live directed edges

Independently declare each directed contact from a type-$t$ vertex to a type-$u$ vertex live with probability $w_{tu}$. The final Independent Cascade infected set is precisely the set reachable from the seeds through live directed edges.

Indeed, one may sample every transmission trial before running the cascade. A successful transmission follows a live edge, so every infected vertex is reachable. Conversely, induction along a live directed path from a seed shows that every reachable vertex eventually becomes infected.

Write $R(v)$ for the set reachable from a vertex $v$, including $v$ itself.

1.2. The nonbacktracking matrix

Let
$$ \mathcal E=\{(u,t):d_{ut}>0\}. $$
Reciprocity and positive masses imply that $d_{ut}>0$ exactly when $d_{tu}>0$, so $|\mathcal E|=m$.

A state $(u,t)$ means that a path has arrived at a type-$t$ vertex from a type-$u$ vertex. Define the nonnegative matrix $K$, indexed by $\mathcal E$, by
$$ K_{(u,t),(a,v)} = \begin{cases} \bigl(d_{tv}-\mathbf 1_{\{v=u\}}\bigr)w_{tv},&a=t,\\ 0,&a\neq t. \end{cases} $$
The subtraction removes the contact just traversed.

For each root type $t$, define the row vector $b_t$ by
$$ (b_t)_{(a,v)} = \begin{cases} d_{tv}w_{tv},&a=t,\\ 0,&a\neq t. \end{cases} $$

Denote the spectral radius of $K$ by $r(K)$.

Proposition. If $r(K)<1$, then
$$ C_t=1+b_t(I-K)^{-1}\mathbf 1 $$
is finite and, for every sufficiently large admissible $n$,
$$ \mathbb E[\rho_n] \leq \frac1n\sum_{t\in T}\mu_t\lambda_t C_t. $$
Consequently,
$$ \rho_n\xrightarrow{\mathrm P}0, \qquad \nu=\delta_0. $$

Proof. Fix any permitted simple contact graph and a type-$t$ root $v$.

Every vertex reachable from $v$ admits a simple live directed path from $v$. For a fixed simple path, its live probability is the product of its transmission probabilities, because its directed edges are distinct.

The sum of these products over simple paths of length $\ell$ is at most the corresponding sum over all nonbacktracking walks. The latter sum equals
$$ b_tK^{\ell-1}\mathbf 1,\qquad \ell\geq 1. $$
To verify this identity, the first step has $d_{tv}$ possible contacts of each type $v$. After arrival in state $(u,t)$, there are exactly $d_{tv}-\mathbf 1_{\{v=u\}}$ allowed next contacts of type $v$. These counts hold for every permitted simple graph.

We use walk weights only as a deterministic upper bound. We do not interpret products along walks with repeated edges as probabilities.

Since $r(K)<1$, the finite-dimensional Neumann series converges and gives
$$ \mathbb E[|R(v)|] \leq 1+\sum_{\ell\geq1}b_tK^{\ell-1}\mathbf 1 = C_t. $$

The infected set is contained in the union of the reachable sets of individual seeds. Seeds are independent of the live edges. Therefore its expected size is at most
$$ \sum_t n\mu_t\frac{\lambda_t}{n}C_t = \sum_t\mu_t\lambda_t C_t. $$
This bound holds for every permitted graph, hence also after averaging over the conditioned graph construction. Division by $n$ and Markov’s inequality prove the result. $\square$

This strengthens the row-sum sufficient condition in the notes. If
$$ c=\max_t\sum_u d_{tu}w_{tu}<1, $$
then every row sum of $K$ is at most $c$, so $r(K)\leq c<1$.

1.3. Exact recognition and running time

The strict spectral condition can be checked using rational arithmetic. For a nonnegative matrix $K$,
$$ r(K)<1 $$
is equivalent to the following condition: $I-K$ is invertible and
$$ v=(I-K)^{-1}\mathbf 1 $$
is strictly positive coordinatewise.

The forward implication follows from the Neumann series. Conversely, if $v>0$, then
$$ Kv=v-\mathbf 1. $$
Nonnegativity of $K$ implies $v_i\geq1$. Conjugating $K$ by the diagonal matrix with diagonal $v$ gives row sums
$$ \frac{(Kv)_i}{v_i}=1-\frac1{v_i}<1. $$
Thus its spectral radius, and hence that of $K$, is strictly less than one.

After reading the input, the nonzero pattern of $K$ can be constructed in
$$ O\bigl(m\min\{D,\tau\}+\tau\bigr) $$
operations: every state has at most $\min\{D,\tau\}$ possible successors.

For a conservative bit bound, let
$$ H=L+\log(D+1)+\log(m+1). $$
Clear denominators using the product of the input transmission denominators, whose bit length is at most $L$. Fraction-free elimination uses $O(m^3)$ integer operations on integers of $O(mH)$ bits, by the determinant bound for minors. Schoolbook arithmetic therefore gives a bound
$$ O\bigl((m+1)^5H^2+\tau L^2\bigr) $$
for recognition and calculation of the displayed expectation constant.

On this recognized subclass, every allowed CDF cut answers YES, because
$$ \delta_0([0,x])=1 $$
for every $x\in[0,1]$.

2. A partition lemma for deterministic cycles

We first prove the probability calculation used in the degree-two classification.

2.1. Two partition models

For $\theta>0$, write
$$ (\theta)_M=\theta(\theta+1)\cdots(\theta+M-1), \qquad (\theta)_0=1. $$

Consider an exchangeable partition of $M$ labelled units whose probability for a specified partition $\pi$ is
$$ \Pr(\pi) = \frac{\theta^{|\pi|}\prod_{B\in\pi}(|B|-1)!}{(\theta)_M}. $$
We need two instances.

Uniform permutation, $\theta=1$. A specified set of $s$ labels has $(s-1)!$ cyclic permutations. Counting permutations with a specified collection of cycle blocks gives the displayed formula, since $(1)_M=M!$.

Uniform two-stub pairing, $\theta=\tfrac12$. Give every unit two labelled stubs and pair all $2M$ stubs uniformly. A specified set of $s$ units forms one connected component in
$$ 2^{s-1}(s-1)! $$
pairings.

For $s\geq3$, there are $(s-1)!/2$ undirected cyclic orders and $2^s$ stub assignments. For $s=1$, there is one loop pairing; for $s=2$, there are two double-edge pairings. Thus the same formula holds for every $s\geq1$.

Since
$$ (2M-1)!!=2^M(1/2)_M, $$
the probability of a specified component partition is exactly the displayed formula with $\theta=\tfrac12$.

2.2. The fraction covered by finitely many marks

Fix $k\geq1$ distinct marked units. Let $A_M$ be the number of units in blocks containing at least one mark.

Lemma. In either partition model,
$$ \frac{A_M}{M} \Longrightarrow \operatorname{Beta}(k,\theta). $$

Here $\operatorname{Beta}(k,\theta)$ denotes the distribution on $(0,1)$ with density proportional to
$$ z^{k-1}(1-z)^{\theta-1}. $$

Proof. Exchangeability allows us to label the marked units first.

The partition formula gives a sequential construction: after $j$ units have been assigned, the next unit joins an existing block of size $s$ with probability
$$ \frac{s}{j+\theta}, $$
and starts a new block with probability
$$ \frac{\theta}{j+\theta}. $$
These probabilities follow by taking the ratios of the partition weights after enlarging a block or adding a singleton.

Let $A_j$ count units in marked blocks at this stage. Initially $A_k=k$, and
$$ \Pr(A_{j+1}=A_j+1\mid\text{current partition}) = \frac{A_j}{j+\theta}. $$

For a specified sequence with $r$ increments and $s$ nonincrements, multiplication of these transition probabilities gives
$$ \frac{(k)_r(\theta)_s}{(k+\theta)_{r+s}}. $$
This is also the integral of $z^r(1-z)^s$ against the $\operatorname{Beta}(k,\theta)$ density. Consequently, the increment sequence has the same law as independent Bernoulli trials conditional on
$$ V\sim\operatorname{Beta}(k,\theta). $$
In particular, conditionally on $V$,
$$ A_M=k+\operatorname{Binomial}(M-k,V). $$
Its conditional variance divided by $M^2$ is at most $1/(4M)$, and its conditional mean divided by $M$ differs from $V$ by at most $k/M$. Hence $A_M/M$ converges to $V$ in mean square in this representation. $\square$

2.3. Conditioning away small blocks

For the pairing model, we also need conditioning that forbids blocks of sizes one, or sizes one and two.

Let
$$ F\in\bigl\{\varnothing,\{1\},\{1,2\}\bigr\}, $$
and let $S_M$ be the event that no block has size in $F$.

Lemma. For $\theta=\tfrac12$,
$$ \Pr(S_M)\longrightarrow \exp\left(-\theta\sum_{j\in F}\frac1j\right)>0. $$
For each fixed $k\geq1$, conditioning on $S_M$ preserves the limit
$$ \frac{A_M}{M}\Longrightarrow\operatorname{Beta}(k,\theta). $$

Proof. The partition weights give the generating-function identity
$$ \Pr(S_M) = \frac{[z^M](1-z)^{-1/2}g(z)} {[z^M](1-z)^{-1/2}}, \qquad g(z)=\exp\left(-\frac12\sum_{j\in F}\frac{z^j}{j}\right). $$
Indeed, a block of size $j$ contributes exponential-generating-function weight $\theta z^j/j$. Summing over allowed blocks gives the numerator; summing over all blocks gives the denominator.

Put
$$ c_M=[z^M](1-z)^{-1/2} =\frac{\binom{2M}{M}}{4^M}. $$
Stirling’s formula gives
$$ c_M\sim(\pi M)^{-1/2}. $$
It also supplies positive constants bounding $c_M$ above and below by constant multiples of $(M+1)^{-1/2}$. Therefore, for $0\leq j\leq M$,
$$ \frac{c_{M-j}}{c_M} \leq C\sqrt{j+1}, $$
because
$$ \frac{M+1}{M-j+1}\leq j+1. $$
For fixed $j$, this ratio tends to one.

Write $g(z)=\sum_jg_jz^j$. The function $g$ is entire, so Cauchy’s coefficient bound on any circle of radius greater than one gives geometric decay of $|g_j|$. Dominated convergence in the coefficient convolution now yields
$$ \Pr(S_M) = \sum_{j=0}^M g_j\frac{c_{M-j}}{c_M} \longrightarrow g(1). $$

Next condition on the full blocks containing the marked units. The remaining
$$ R_M=M-A_M $$
units have the same parameter-$\theta$ partition law: factoring the partition weight leaves precisely the product of block weights on the remaining labels, with its own normalization.

The beta limit from the preceding lemma has no atom at one, so $R_M$ tends to infinity in probability. Also, each fixed marked unit has a block-size fraction converging to $\operatorname{Beta}(1,\theta)$, which has no atom at zero. Thus the probability that any marked block has size in $F$ tends to zero.

The conditional probability of $S_M$, given the marked blocks, is
$$ \mathbf 1_{\{\text{marked blocks have no forbidden size}\}} \Pr(S_{R_M}). $$
It consequently tends in probability, and in mean, to $g(1)$.

For any bounded continuous function $f$, it follows that
$$ \mathbb E\left[f(A_M/M)\mathbf 1_{S_M}\right] - g(1)\mathbb E[f(A_M/M)] \longrightarrow0. $$
Division by $\Pr(S_M)\to g(1)>0$ proves preservation of the beta limit. $\square$

The two nontrivial simplicity probabilities are therefore
$$ e^{-1/2} \quad\text{for }F=\{1\}, \qquad e^{-3/4} \quad\text{for }F=\{1,2\}. $$

2.4. Rare independent marks

Suppose every unit is independently marked with probability $p_M$, where
$$ Mp_M\longrightarrow\Lambda. $$
Marking is independent of the partition, including any of the preceding small-block restrictions.

Conditional on the number of marks $K_M=k$, the marked units are a uniform $k$-subset. Moreover,
$$ K_M\Longrightarrow\operatorname{Poisson}(\Lambda). $$
Applying the preceding lemmas for each fixed $k$ gives the covered-fraction limit
$$ X_{\theta,\Lambda}\sim e^{-\Lambda}\delta_0+ e^{-\Lambda}\sum_{k=1}^{\infty} \frac{\Lambda^k}{k!}\operatorname{Beta}(k,\theta). $$

To justify the infinite mixture, observe that $\mathbb E[K_M]=Mp_M$ stays bounded. Markov’s inequality gives a uniform tail bound for $K_M$. For any bounded continuous test function, truncate the sum over $k$, pass to the limit in its finitely many terms, and then let the truncation level increase.

3. Complete convergence classification when $D\leq2$

3.1. The limiting-law formula

Form an auxiliary undirected graph on the types, joining distinct types $t,u$ when $d_{tu}>0$. Within-type contacts are recorded separately by $d_{tt}$.

For a connected component $C$ of this auxiliary graph, define
$$ \alpha_C=\sum_{t\in C}\mu_t, \qquad \Lambda_C=\sum_{t\in C}\mu_t\lambda_t. $$

Call $C$ productive in precisely the following cases.

  • Ring: $C$ is a cycle of at least three distinct types, every type has one contact to each of its two neighboring types, and one of the two cyclic directions has transmission probability one on every step. Set $\theta_C=1$.
  • Path with turning ends: every type has total degree two; the auxiliary component is a path of at least two types; and every supported directed transmission probability equals one. Set $\theta_C=\tfrac12$.
  • Single degree-two type: $C=\{t\}$, $d_{tt}=2$, and $w_{tt}=1$. Set $\theta_C=\tfrac12$.

Theorem. Every admissible input with $D\leq2$ has the weak limiting law
$$ \rho_n\Longrightarrow Y= \sum_{C\text{ productive}}\alpha_C X_{\theta_C,\Lambda_C}, $$
where the variables in the sum are independent. An empty sum means $Y=0$.

We prove both the classification and the asserted laws.

3.2. Exhaustion of the contact patterns

Every type has at most two distinct off-type neighbors. Hence every auxiliary component is a singleton, a path, or a cycle.

A cycle component must have at least three types. Each type already uses its two contacts on its two off-type neighbors, so all those counts are one and there are no within-type contacts. Reciprocity makes all masses in the ring equal.

For a path with at least two types, each interior type has one contact to each neighboring type and no within-type contact. An endpoint with total degree two has exactly one of these two forms:

  • two contacts to its single neighboring type;
  • one contact to its neighboring type and one within-type contact.

An endpoint with total degree one has one contact to its neighboring type.

Finally, a singleton has $d_{tt}\in\{0,1,2\}$.

These possibilities exhaust all inputs with $D\leq2$.

3.3. Nonproductive components contribute zero

For a degree-two type, after entering along one contact there is exactly one contact remaining. Thus the directed-state transition underlying $K$ is deterministic wherever the current type has degree two, and terminates wherever the current type has degree one.

For a ring, the states split into two directed cycles, one for each orientation. Their transmission products are
$$ a_+=\prod_{j=1}^r w_{t_jt_{j+1}}, \qquad a_-=\prod_{j=1}^r w_{t_{j+1}t_j}, $$
with cyclic indexing.

A weighted directed-cycle matrix of length $p$ and weight product $a$ satisfies
$$ K^p=aI, $$
and has spectral radius $a^{1/p}$. This follows directly by following the unique successor $p$ times; equivalently, its characteristic polynomial is $z^p-a$. Therefore a nonproductive ring has spectral radius strictly less than one in both orientation blocks.

For a path whose endpoints both have degree two, a nonbacktracking type walk traverses the path, turns at its ends, and returns. An endpoint with a within-type contact introduces one additional step before the turn. The states form one directed cycle, containing every supported ordered type pair exactly once. Its length is
$$ 2(r-1)+e, $$
where $e$ is the number of endpoints having a within-type contact. Its transmission product is less than one exactly when some supported directed probability is less than one. Hence a nonproductive such path again has spectral radius strictly less than one.

If a path has a degree-one endpoint, every directed-state walk terminates. It cannot turn at an interior type, and after any turn at the other endpoint it must reach a degree-one endpoint. Thus the directed-state graph is acyclic and its matrix is nilpotent.

For a singleton, the matrix is empty or zero when $d_{tt}\leq1$, and is the one-entry matrix $(w_{tt})$ when $d_{tt}=2$.

Applying Proposition 1 to each nonproductive component shows that its expected infected count stays bounded independently of $n$. Its contribution to $\rho_n$ therefore tends to zero in probability.

3.4. Productive rings give $\theta=1$

Let a ring have types $t_1,\ldots,t_r$. Their equal populations are
$$ N=n\mu_{t_j}. $$

Each adjacent type pair is joined by a uniform bijection between its two vertex sets. The bijections are independent. Composing them around the ring gives a uniform permutation of the $N$ vertices of type $t_1$: condition on all but one of the bijections, and the remaining uniform bijection makes the composition uniform.

A permutation cycle of length $s$ corresponds to a contact component containing exactly $s$ vertices of every ring type. All contact graphs in this construction are simple, since every adjacent type pool has one stub per vertex.

Because one complete cyclic direction transmits deterministically, every seeded contact component is fully infected.

For a component corresponding to $s$ permutation units, the probability of having no seed is
$$ h_n^s, \qquad h_n=\prod_{t\in C}\left(1-\frac{\lambda_t}{n}\right). $$
Seed statuses of different components are independent. Conditional on the component partition, this is exactly the same law as independently marking each permutation unit with probability $1-h_n$ and filling every marked block.

Furthermore,
$$ N(1-h_n) \longrightarrow \mu_{t_1}\sum_{t\in C}\lambda_t = \Lambda_C. $$
The partition lemma with $\theta=1$ proves that the infected fraction within the ring converges to $X_{1,\Lambda_C}$. Its contribution to the whole society is therefore
$$ \alpha_CX_{1,\Lambda_C}. $$

There is a particularly simple CDF in this case. Since $\operatorname{Beta}(k,1)$ has CDF $z^k$,
$$ \Pr(X_{1,\Lambda}\leq z) = e^{-\Lambda}\sum_{k=0}^{\infty}\frac{(\Lambda z)^k}{k!} = e^{-\Lambda(1-z)}, \qquad 0\leq z\leq1. $$

3.5. Productive paths give $\theta=\tfrac12$

Consider a path of $r\geq2$ types, all of total degree two.

Let $H_n$ be the number of stubs in any cross-type pool along the path. Reciprocity and the one-stub counts at interior types make this number the same along the entire path.

An endpoint with two off-type stubs has population $H_n/2$. An endpoint with one off-type stub and one within-type stub has population $H_n$; admissibility makes this population even. Thus $H_n$ is even. Put
$$ M_n=H_n/2. $$

The cross-type matchings identify $H_n$ threads running from one endpoint to the other through the interior types. At either endpoint, these threads are joined in pairs:

  • at a two-off-type-stub endpoint, the two stubs belonging to a vertex form a pair;
  • at a within-type-stub endpoint, the within-type matching pairs the endpoint vertices.

Transport both endpoint pairings to one common set of $H_n$ thread labels. Conditional on the first endpoint pairing, the second is a uniform perfect matching. To verify this, condition on the endpoint pairings in their own labels and on all but one cross-type bijection. The remaining uniform bijection transports the second fixed pairing to a uniform perfect matching relative to the first.

Contract the pairs of the first endpoint pairing into $M_n$ labelled units. The second pairing is then precisely a uniform pairing of the two stubs at every unit. Hence the component partition has parameter $\theta=\tfrac12$.

A block of $s$ units contains $b_ts$ vertices of type $t$, where
$$ b_t= \begin{cases} 1,&t\text{ is an endpoint with two off-type stubs},\\ 2,&t\text{ is an interior type or an endpoint with a within-type stub}. \end{cases} $$
Indeed, the block uses $2s$ threads. Each interior type contributes one vertex per thread; a two-stub endpoint joins two threads at one vertex; a within-type endpoint contributes one vertex per thread. Thus, for every type in the component,
$$ n\mu_t=b_tM_n. $$

The simplicity restrictions are also explicit.

  • If $r=2$ and both endpoints have two off-type stubs, a block of one unit is exactly a double edge. Simplicity forbids size-one blocks and imposes no other restriction.
  • In every other path case, each cross-type pool has an endpoint with only one stub in that pool, so parallel edges are impossible. Within-type endpoint matchings have one stub per vertex, so loops are impossible. The graph is automatically simple.

Consequently, the only required conditioning is either $F=\varnothing$ or $F=\{1\}$, covered by Section 2.3.

All supported transmissions equal one, so a contact component is fully infected exactly when it contains a seed. For a block of $s$ units its no-seed probability is
$$ h_n^s, \qquad h_n=\prod_{t\in C}\left(1-\frac{\lambda_t}{n}\right)^{b_t}. $$
As before, this is equivalent to independent unit marks with probability $1-h_n$. Since
$$ M_n(1-h_n) \longrightarrow \frac{M_n}{n}\sum_{t\in C}b_t\lambda_t = \Lambda_C, $$
the partition lemma proves a limiting infected fraction $X_{1/2,\Lambda_C}$ within this component.

3.6. A single degree-two type

For a singleton with $d_{tt}=2$, use its vertices themselves as the units. The unconditioned model is the two-stub pairing model.

Its graph is simple exactly when there are no components of sizes one or two: these are respectively loops and double edges. Thus the conditioning is $F=\{1,2\}$.

When $w_{tt}=1$, every seeded cycle is fully infected. Independent unit marking has probability $\lambda_t/n$, and
$$ n\mu_t\frac{\lambda_t}{n}=\Lambda_C. $$
Sections 2.3 and 2.4 therefore give $X_{1/2,\Lambda_C}$.

This includes, as a special case, the one-type law
$$ e^{-\lambda}\delta_0+ e^{-\lambda}\sum_{k=1}^{\infty} \frac{\lambda^k}{k!}\operatorname{Beta}\left(k,\frac12\right). $$

3.7. Combining components and running time

Different auxiliary components use disjoint stub pools. Their unconditioned matchings are independent, and simplicity is the intersection of separate events for these components. Conditioning therefore preserves their independence. Seeds and transmissions are also independent across them.

There are finitely many components for a fixed input. Each unit population tends to infinity because all supported masses are positive. The productive component fractions converge jointly to the independent limits above, while the sum of nonproductive contributions tends to zero in probability. Taking their weighted sum proves the theorem.

The classification and compact limiting-law description require
$$ O(m+\tau) $$
operations after reading the input. Calculating $\alpha_C$ and $\Lambda_C$ gives a conservative schoolbook bit bound
$$ O\bigl((m+\tau+1)L^2\bigr). $$

This is a running time for producing the analytic law description. It is not an asserted running time for deciding every exact CDF cut of sums of these mixtures.

4. Exact CDF-cut hardness at $D=3$

4.1. An admissible subclass with a proved limiting law

Take nonisolated types $1,\ldots,k$ with
$$ d_{ii}=3,\qquad d_{ij}=0\quad(i\neq j),\qquad w_{ii}=1. $$
An additional isolated type with seed intensity zero is allowed.

For each admissible $n$, let $N_i=n\mu_i$. Each $N_i$ is even. Conditioning the within-type pairing on simplicity gives a uniform labelled simple cubic graph: every such graph has exactly $(3!)^{N_i}$ stub representations. The conditioned graphs for different types remain independent.

We use the standard fixed-degree connectivity theorem: for each fixed integer $d\geq3$, a uniform labelled simple $d$-regular graph is connected with probability tending to one as its order tends to infinity through orders with even total degree. The stronger statement of asymptotic $d$-connectivity is given in [Wormald’s survey, Section 2.6](https://web.williams.edu/Mathematics/sjmiller/public_html/ntprob12/handouts/graphs/Womald_ModelsRandomGraphs.pdf).

Its hypotheses hold here: the degree is fixed at three, $N_i\to\infty$ because $\mu_i>0$, and $3N_i$ is even by admissibility.

Let $B_{i,n}$ indicate that type $i$ contains a seed. These indicators are independent and
$$ \Pr(B_{i,n}=0) = \left(1-\frac{\lambda_i}{n}\right)^{n\mu_i} \longrightarrow e^{-\mu_i\lambda_i}. $$
With probability tending to one, all $k$ type graphs are connected. On that event,
