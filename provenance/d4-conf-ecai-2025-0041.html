The continuous mirror question, as graded

Given a dimension \(d\), distinct types \(x^1,\ldots,x^\tau\in\{-1,+1\}^d\), positive rational masses \(\mu_i\) summing to \(1\), and a rational threshold \(q\in[0,1]\), place the incumbent at the origin and decide whether there is a position \(y\in\mathbb{R}^d\) for which \(\sum_{i=1}^{\tau}\mu_i\mathbf{1}[\|x^i-y\|_2<\|x^i\|_2]\ge q\); return such a position when one exists.

Packaged proof task (what the prover saw — nothing else)

Let \(d\ge1\). A society is given by its support: distinct types \(x^1,\ldots,x^\tau\in\{-1,+1\}^d\), with \(\tau\ge1\), and positive binary rational masses \(\mu_i\) satisfying \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types.
There is \(m=1\) incumbent, positioned at the origin. A newcomer may choose any \(y\in\mathbb R^d\). Each type supports the closer candidate under Euclidean distance; distance ties favor the incumbent.
Given a binary rational threshold \(q\in[0,1]\), decide whether some \(y\) satisfies \(\sum_{i=1}^{\tau}\mu_i\mathbf1[\|x^i-y\|_2<\|x^i\|_2]\ge q\), and return such a position with binary rational coordinates when one exists.
Let \(L\) be the total binary input length. State running times in \(d\), \(\tau\), \(L\), and \(m=1\), with \(d\) unrestricted.

Is this rational-mass candidate-positioning decision problem in P, or is it NP-hard?

For finite lists of unit-weight voters, the decision problem is NP-complete even with one incumbent at the origin and bipolar voter coordinates; it is polynomial-time solvable for fixed \(d\). [Source](https://arxiv.org/html/2508.13841v1).
No separate published classification of this exact rational-mass formulation was identified.

Classification

The decision problem is \(\mathsf{NP}\)-complete when \(d\) is unrestricted, already with \(m=1\). Every yes-instance has a winning position with binary rational coordinates of polynomial bit length.

Thus a polynomial-time algorithm for decision and position construction exists if and only if \(\mathsf{P}=\mathsf{NP}\). For fixed \(d\), both tasks are polynomial-time solvable.

Here, binary rationals mean rationals whose numerators and denominators are encoded in binary. The case \(q=0\) is immediate: return \(y=0\).

1. Hardness survives consolidation into distinct support types

We use the supplied unit-weight hardness result: deciding whether a newcomer can obtain at least \(k\) votes from an explicitly listed electorate is \(\mathsf{NP}\)-complete, even under Euclidean distance, with one incumbent at the origin, bipolar voter coordinates, and distance ties favoring the incumbent. These restrictions are verified in Definition 3.1, the tie convention, and Theorem 1 of [Cleveland, de Keijzer, and Polukarov](https://arxiv.org/html/2508.13841v1#S4.SS1).

Take such an instance with a nonempty voter list \(v^1,\ldots,v^n\in\{-1,+1\}^d\) and \(1\le k\le n\). Let \(x^1,\ldots,x^\tau\) be its distinct voter types, and define their multiplicities by

\[ c_i=\bigl|\{j:v^j=x^i\}\bigr|. \]

Construct the rational-mass instance with the same dimension and incumbent, and with

\[ \mu_i=\frac{c_i}{n}, \qquad q=\frac{k}{n}. \]

Every mass is positive, the types are distinct, and \(\sum_i\mu_i=1\). For every position \(y\), consolidation gives the exact identity

\[ \sum_{i=1}^{\tau}\mu_i \mathbf 1[\|x^i-y\|_2<\|x^i\|_2] = \frac1n\sum_{j=1}^{n} \mathbf 1[\|v^j-y\|_2<\|v^j\|_2]. \]

Consequently, the constructed instance reaches mass at least \(q\) if and only if the original instance obtains at least \(k\) votes.

Grouping identical vectors takes polynomial time in the explicitly listed input length. Each constructed mass and threshold uses \(O(\log(n+1))\) bits, and the constructed instance has length

\[ O\!\left(\tau d+(\tau+1)\log(n+1)+\log(d+1)\right). \]

This is a polynomial-time many-one reduction. Therefore the distinct-support rational-mass problem is \(\mathsf{NP}\)-hard. Crucially, \(\tau\) is the number of distinct types; no enumeration of all possible bipolar types occurs.

2. Winning positions admit short rational certificates

For any type \(x^i\), expanding squared distances gives

\[ \|x^i-y\|_2<\|x^i\|_2 \quad\Longleftrightarrow\quad 2x^i\cdot y>\|y\|_2^2. \]

In particular, winning type \(i\) implies \(x^i\cdot y>0\).

Suppose \(q>0\) and a real position wins a set \(S\) of types with \(\sum_{i\in S}\mu_i\ge q\). Then \(S\) is nonempty, and the strict homogeneous system

\[ x^i\cdot u>0 \qquad(i\in S) \]

is feasible.

Consider the bounded rational polytope in \(d+1\) variables

\[ P_S= \left\{ (u,t): -1\le u_j\le1\ (1\le j\le d),\ 0\le t\le d,\ x^i\cdot u\ge t\ (i\in S) \right\}. \]

A strictly feasible direction can be scaled into the cube while preserving all positive dot products. Their minimum is positive, so \(P_S\) contains a point with \(t>0\).

Maximize \(t\) over \(P_S\). The polytope is nonempty and compact, so the maximum exists and is positive. A linear objective on a nonempty bounded polytope attains its maximum at a vertex. Choose such a maximizing vertex \((u^*,t^*)\).

At this vertex, select \(d+1\) linearly independent active constraints. Their coefficient matrix \(B\) has integer entries of absolute value at most one. Writing \(D=|\det B|\), Hadamard’s inequality gives

\[ 1\le D\le(d+1)^{(d+1)/2}. \]

Cramer’s rule supplies integers \(N_j,N_t\) such that

\[ u_j^*=\frac{N_j}{D}, \qquad t^*=\frac{N_t}{D}. \]

The cube and margin bounds imply \(|N_j|\le D\) and \(0<N_t\le dD\).

Define the rational candidate position

\[ y^*=\frac{t^*}{d}u^*. \]

For every \(i\in S\), using \(x^i\cdot u^*\ge t^*\) and \(\|u^*\|_2^2\le d\), we obtain

\[ 2x^i\cdot y^*-\|y^*\|_2^2 \ge \frac{2(t^*)^2}{d} -\frac{(t^*)^2}{d^2}\|u^*\|_2^2 \ge \frac{(t^*)^2}{d} >0. \]

Hence \(y^*\) wins every type in \(S\), including under the prescribed strict tie convention.

Moreover,

\[ y_j^*=\frac{N_tN_j}{dD^2}. \]

The numerator and denominator have \(O(d\log(d+1))\) bits per coordinate. Thus the complete position uses \(O(d^2\log(d+1))\) bits.

3. Membership in \(\mathsf{NP}\)

Use the rational position from Section 2 as the certificate. A verifier computes, using exact rational arithmetic, whether

\[ 2x^i\cdot y>\sum_{j=1}^{d}y_j^2 \]

for each of the \(\tau\) types. It then sums precisely the masses of those satisfying this strict inequality and compares the sum with \(q\).

The certificate length is polynomial in \(d\), hence in the explicit input length \(L\). Arithmetic intermediates also have polynomial bit length: in particular, a common denominator for the input masses has bit length at most the sum of their denominator bit lengths. Verification therefore takes \(\operatorname{poly}(d,\tau,L)\) bit operations, with \(m=1\).

Together with Section 1, this proves \(\mathsf{NP}\)-completeness.

4. A constructive algorithm and its running time

The rational-certificate proof also yields an explicit algorithm that returns a position whenever one exists.

In variables \((u,t)\in\mathbb R^{d+1}\), form the following \(\tau+2d+2\) hyperplanes:

\[ x^i\cdot u=t\quad(1\le i\le\tau),\qquad u_j=1,\ u_j=-1\quad(1\le j\le d),\qquad t=0,\ t=d. \]

Enumerate every choice of \(d+1\) hyperplanes. For each choice:

  • Discard it if its coefficient matrix is singular.
  • Otherwise solve its rational linear system.
  • If \(-1\le u_j\le1\) for every coordinate and \(0<t\le d\), form \(y=(t/d)u\).
  • Evaluate the actual won mass exactly; return \(y\) if it is at least \(q\).

If no choice succeeds, answer no.

Every returned position passes the original voting test, so the algorithm is sound. For completeness, any yes-instance with \(q>0\) has the maximizing vertex constructed in Section 2. Its independent active constraints belong to the enumerated collection, and its associated position wins enough mass. Therefore some enumerated choice succeeds.

Each linear system and vote evaluation takes \(\operatorname{poly}(d,\tau,L)\) bit operations. The resulting bound, explicitly with \(m=1\), is

\[ \binom{\tau+2d+2}{d+1}\operatorname{poly}(d,\tau,L). \]

For fixed \(d\), this is

\[ O_d\!\left((\tau+1)^{d+1}\operatorname{poly}(L)\right), \]

and is polynomial in the support-based input length. For unrestricted \(d\), the dimension-dependent exponent does not give a polynomial-time algorithm.
