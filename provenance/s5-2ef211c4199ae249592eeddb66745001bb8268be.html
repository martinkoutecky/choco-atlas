The anchor (named result in the paper)

Theorem 3 — class: hardness

The continuous mirror question, as graded

Given a finite set of complete household types \(T\), rational masses \(\mu_t\) summing to \(1\), a coalition-size cap \(K\), and a succinct nonnegative monotone cost evaluator \(c(q)\), where \(q\in\mathbb Z_{\ge0}^{T}\) and \(1\le\lVert q\rVert_1\le K\), consider a cost-sharing rule with type utilities \(u_t(q)\). A coalition-density vector \(y_q\ge0\) is feasible when \(\sum_q q_t y_q=\mu_t\) for every \(t\); define \(\mathrm{OPT}_\mu=\min_y\sum_q c(q)y_q\) over feasible \(y\). Call \(y\) mass-stable if no pattern \(q\) can be assembled at some positive density \(\varepsilon\) from available coalitions \(r\), using only type-\(t\) mass for which \(u_t(q)>u_t(r)\), with at most \(r_t y_r\) mass drawn from each pattern \(r\). Among polynomial-time cost-sharing mechanisms that always output a mass-stable feasible \(y\), is every mechanism’s worst-case ratio \(\sum_q c(q)y_q/\mathrm{OPT}_\mu\) at least \(\Omega(\log K)\), or can some mechanism achieve \(o(\log K)\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) complete types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Let \(m\) be the maximum type-description length and \(L\) the total input bit length.
The input includes a binary integer \(K\ge2\) and a Boolean circuit evaluating binary rational costs \(c(q)\ge0\) on all patterns \(Q=\{q\in\mathbb Z_{\ge0}^{T}:1\le\lVert q\rVert_1\le K\}\), with \(c(h)\le c(q)\) whenever \(h\le q\) coordinatewise. Repeated occurrences of a type are allowed.
A cost-sharing rule assigns a possibly signed rational payment \(p_t(q)\) to each occurrence of type \(t\) in \(q\), satisfying \(\sum_{t:q_t>0}q_tp_t(q)=c(q)\). Define \(u_t(q)=c(e_t)-p_t(q)\), where \(e_t\) is the singleton pattern; thus standalone utility is \(0\).
A feasible density vector satisfies \(y_q\ge0\) and \(\sum_{q\in Q}q_ty_q=\mu_t\) for every \(t\). Write \(C(y)=\sum_{q\in Q}c(q)y_q\) and \(\mathrm{OPT}_{\mu}=\min\{C(y):y\text{ feasible}\}\); consider instances with \(\mathrm{OPT}_{\mu}>0\).
A pattern \(q\) blocks \(y\) if there are \(\varepsilon>0\) and quantities \(x_{tr}\ge0\) with \(\sum_r x_{tr}=\varepsilon q_t\), \(x_{tr}\le r_ty_r\), and \(x_{tr}=0\) unless \(q_tr_t>0\) and \(u_t(q)>u_t(r)\). Singleton deviations are included; ties do not block. Call \(y\) mass-stable if no pattern blocks it.
A mechanism chooses a succinct payment rule and outputs a feasible mass-stable \(y\) as a list of its positive rational entries on every input; both construction and payment evaluation must take time polynomial in \(m,\tau,L,\log K\). Its ratio \(R_M(K)\) is the supremum of \(C(y)/\mathrm{OPT}_{\mu}\) over inputs with cap \(K\).

Assuming \(\mathrm P\ne\mathrm{NP}\), must every such mechanism satisfy \(R_M(K)=\Omega(\log K)\), or can some mechanism achieve \(R_M(K)=o(\log K)\)?

For finite participants, a verified approximation lower bound gives \(\Omega(\log K)\) strong price of anarchy for every cost-sharing rule admitting polynomial-time computation of a stable partition, assuming \(\mathrm P\ne\mathrm{NP}\); equal-split, proportional-split and egalitarian-split rules have \(O(\log K)\) bounds under cost monotonicity ([source](https://arxiv.org/html/2009.08632v3)).
No result settling this precise mass-stable, succinct-input mechanism question was located in the search.

Modeling choices made when packaging the task

  • Undefined utilities were tied to budget-balanced payments and singleton costs, preserving standalone utility zero; signed payments remain permitted.
  • The succinct evaluator was specified as a Boolean circuit returning binary rational costs, with coordinatewise monotonicity.
  • Mechanisms choose the payment rule and return an explicitly listed rational density vector; payments are identical for occurrences of the same complete type and evaluable in polynomial time.
  • The cap is binary encoded, is at least two, and permits repeated types; polynomial time is measured in its encoding length rather than treating the cap as fixed.
  • The undefined parameter m denotes maximum type-description length; L includes the full input encoding.
  • Instances with zero optimum are excluded solely to make the approximation ratio defined.
  • Blocking was formalized using separate capacities for each type in each incumbent pattern, retaining singleton deviations and strict improvement.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

A stronger obstruction: no polynomial-time mechanism exists

Under \(\mathrm P\ne\mathrm{NP}\), no mechanism satisfies all the stated requirements. Thus the universal \(\Omega(\log K)\) assertion holds vacuously, and no qualifying mechanism achieves \(o(\log K)\).

The obstruction is exact mass stability with a binary-encoded cap. It already appears with one type and persists with two positive-mass types.

1. One type: stability forces exact optimization

Suppose \(T=\{t\}\) and \(\mu_t=1\). Identify a pattern \(k e_t\) with its size \(k\), and write

\(a(k)=c(k e_t)/k,\qquad a_*=\min_{1\le k\le K}a(k).\)

Budget balance uniquely determines the payment:

\(p_t(k e_t)=a(k).\)

Feasibility is \(\sum_{k=1}^{K}k y_k=1\).

Lemma. A feasible density \(y\) is mass-stable if and only if every occupied size minimizes \(a\).

Proof. Suppose \(y_r>0\) and \(a(r)>a_*\). Choose a minimizing size \(j\). Then

\(u_t(j e_t)=c(e_t)-a_* > c(e_t)-a(r)=u_t(r e_t).\)

Set \(\varepsilon=r y_r/(2j)>0\), set \(x_{t,r e_t}=\varepsilon j=r y_r/2\), and set all other quantities to zero. These quantities satisfy the blocking definition, so \(j e_t\) blocks.

Conversely, if every occupied size has payment \(a_*\), every proposed size has payment at least \(a_*\). No occupied mass strictly prefers any deviation. Hence no pattern blocks. \(\square\)

Moreover,

\(C(y)=\sum_{k=1}^{K}(k y_k)a(k)\ge a_*.\)

Equality is attained by \(y_j=1/j\) for any minimizing size \(j\). Therefore \(\mathrm{OPT}_{\mu}=a_*\), and every mass-stable output solves this minimization exactly.

2. Encoding satisfiability in strictly increasing costs

Let \(F\) be a Boolean formula on \(n\ge1\) variables. Set

\(K=2^n+1.\)

For \(1\le k\le K\), define

\(b_F(k)=\begin{cases}0,&k=1,\\ F(\operatorname{bin}_n(k-2)),&2\le k\le K,\end{cases}\)

where \(\operatorname{bin}_n(j)\) denotes the assignment represented by the \(n\)-bit binary expansion of \(j\). Thus sizes \(2,\ldots,K\) enumerate all assignments.

Define the cost by

\(c(k e_t)=f_F(k):=2k-b_F(k).\)

This construction satisfies every input promise:

  • Succinctness. The binary representation of \(K\) has \(O(n)\) bits. A circuit computing \(b_F(k)\), followed by the indicated arithmetic, has size polynomial in the encoding length of \(F\). Costs are integers of \(O(n)\) bits. Take one fixed type description and mass \(1\).
  • Strict monotonicity. For \(1\le h<k\le K\),

\(f_F(k)-f_F(h)=2(k-h)-b_F(k)+b_F(h)\ge2(k-h)-1\ge1.\)

  • Positive optimum. At \(k=1\), the cost per occurrence is \(2\). For \(k\ge2\),

\(f_F(k)/k=2-b_F(k)/k\ge3/2.\)

Consequently, every feasible density has cost at least \(3/2\), so \(\mathrm{OPT}_{\mu}>0\).

If \(F\) is unsatisfiable, every size has cost per occurrence \(2\). If \(F\) is satisfiable, some size has cost per occurrence strictly below \(2\). In that case, every minimizing size encodes a satisfying assignment, because \(b_F(k)=0\) gives cost per occurrence exactly \(2\).

3. A mechanism would decide satisfiability

Assume a mechanism with the required polynomial running time exists. Given \(F\), construct the preceding instance and run the mechanism.

Its output contains at least one positive entry, since feasibility requires \(\sum_k k y_k=1\). Read any occupied size \(j\). By the lemma, \(j\) minimizes \(f_F(k)/k\). Therefore,

\(F\text{ is satisfiable}\quad\Longleftrightarrow\quad b_F(j)=1.\)

Evaluate \(b_F(j)\) and return the corresponding answer.

The instance length is polynomial in the encoding length of \(F\), while \(m\) and \(\tau\) are constant and \(\log K=O(n)\). The stipulated mechanism and this final evaluation therefore decide Boolean satisfiability in deterministic polynomial time. By NP-completeness of Boolean satisfiability, this implies \(\mathrm P=\mathrm{NP}\), a contradiction.

4. The obstruction persists with two types and signed payments

To check that the argument survives beyond one type, take two distinct fixed types with masses \(\mu_1=\mu_2=1/2\). Extend \(f_F\) by \(f_F(0)=0\), and define

\(c(q)=f_F(q_1)+f_F(q_2),\qquad 1\le q_1+q_2\le K.\)

The cost circuit remains polynomial in size. Costs are positive and strictly increase under any proper coordinatewise increase. Also \(c(q)\ge(3/2)(q_1+q_2)\), so every feasible density has cost at least \(3/2\).

Write

\(a_*=\min_{1\le k\le K}f_F(k)/k,\)

and choose a minimizing size \(k_*\).

Consider any budget-balanced payment rule, allowing signed payments, and any mass-stable output \(y\). For every occupied pattern \(r\) and type \(t\) with \(r_t>0\), stability implies

\(p_t(r)\le a_*.\)

Indeed, budget balance forces the payment in the homogeneous pattern \(k_*e_t\) to equal \(a_*\). If \(p_t(r)>a_*\), a positive amount of type \(t\) from \(r\) could form that homogeneous pattern and strictly improve, exactly as in the blocking construction above.

Budget balance now gives

\(\sum_t f_F(r_t)=c(r)=\sum_{t:r_t>0}r_t p_t(r)\le a_*\sum_t r_t.\)

By the definition of \(a_*\), each summand satisfies \(f_F(r_t)\ge a_*r_t\). Hence equality must hold throughout, and every positive coordinate satisfies

\(f_F(r_t)/r_t=a_*.\)

Thus any positive coordinate of an occupied pattern again encodes a satisfying assignment whenever \(F\) is satisfiable. The same polynomial-time SAT decision follows.

Stable allocations nevertheless exist for every constructed instance. The rule

\(p_t(q)=f_F(q_t)/q_t\quad\text{for }q_t>0\)

is budget balanced and succinctly evaluable. Assigning density \(\mu_t/k_*\) to each homogeneous pattern \(k_*e_t\) is feasible and mass-stable: incumbent payments equal \(a_*\), and every proposed payment is at least \(a_*\). The difficulty is computing the required minimizing size.

5. Consequence for the stated alternatives

Under \(\mathrm P\ne\mathrm{NP}\), the class of mechanisms in the question is empty. This settles the stated alternatives through nonexistence, rather than through a nonvacuous approximation lower bound. The reduction uses precisely the permitted repeated occurrences, binary-encoded cap, succinct monotone costs, and exact mass stability.

1. One-type stability lemma

With one type, budget balance forces $p_t(k e_t)=c(k e_t)/k=a(k)$. Signed payments introduce no freedom here.

The minimum $a_*$ exists because the admissible sizes form the finite, nonempty set $\{1,\ldots,K\}$.

For an occupied size $r$ with $a(r)>a_*$, the proposed deviation to a minimizing size $j$ satisfies every blocking requirement:

  • $\varepsilon=r y_r/(2j)>0$.
  • The recruited quantity is $\varepsilon j=r y_r/2$, so it does not exceed the available quantity $r y_r$.
  • All other recruitment quantities vanish.
  • Both patterns contain the sole type.
  • The utility improvement is strict because $a(j)<a(r)$.

This argument remains valid when $j>r$: the definition permits recruiting an arbitrarily small positive density of the proposed pattern.

Conversely, if every occupied size has payment $a_*$, no admissible size offers a strictly smaller payment. Thus no recruitment from occupied mass can satisfy the strict utility condition. Unoccupied patterns supply zero mass. The treatment of ties is correct.

The objective calculation is also correct: the nonnegative weights $k y_k$ sum to $1$, so $C(y)\ge a_*$. The density $y_j=1/j$ attains equality and is feasible. Hence every stable density is optimal.

The cap, pattern coordinates, and integer costs have $O(n)$ bits. The fixed type description and mass $1$ satisfy the support requirements.
