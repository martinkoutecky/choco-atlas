The continuous mirror question, as graded

Given an explicit finite routing-role graph, rational type masses \(\mu_t\), per-unit capacities \(c_t\), symmetric demand densities \(d_{tu}\), and allowed route templates, define \(V(z)\) as the maximum routed flow for a coalition with type masses \(0\le z_t\le\mu_t\), capacities \(c_tz_t\), and pair demands \(d_{tu}z_tz_u\) for distinct types and \(d_{tt}z_t^2/2\) within a type. Compute nonnegative per-unit payoffs \(p_t\) such that \(\sum_t\mu_tp_t=V(\mu)\) and \(\sum_tz_tp_t\ge V(z)\) for every coalition vector \(z\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
The input includes an undirected routing graph on these types (loops permitted), nonnegative binary-rational per-unit capacities \(c_t\), symmetric nonnegative binary-rational demand densities \(d_{tu}\), and explicitly listed route templates. A template is a graph walk with at least two vertex occurrences, whose endpoints specify its unordered commodity; equal endpoint types represent distinct agents of that type.
Let \(\mathcal P_{tu}\) be the templates for commodity \(\{t,u\}\), and let \(a_{tP}\) count occurrences of type \(t\) in template \(P\), including endpoints. Each occurrence consumes capacity; there are no edge capacities.
For every real coalition vector \(0\le z\le\mu\), only templates whose types have positive coalition mass are available. Define \(D_{tu}(z)=d_{tu}z_tz_u\) for \(t\ne u\), and \(D_{tt}(z)=d_{tt}z_t^2/2\).
Define \(V(z)=\max\{\sum_P f_P: f_P\ge0,\ \sum_P a_{tP}f_P\le c_tz_t\ \forall t,\ \sum_{P\in\mathcal P_{tu}}f_P\le D_{tu}(z)\ \forall t\le u\}\). Each unordered commodity contributes once to the objective.
The exact core-allocation problem asks for rational per-unit payoffs \(p_t\ge0\) satisfying \(\sum_t\mu_tp_t=V(\mu)\) and \(\sum_tz_tp_t\ge V(z)\) for every real \(0\le z\le\mu\), or a determination that no such allocation exists.
Is this exact core-allocation problem solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,R,L\), where \(m\) is the graph encoding length, \(R\) is the total number of listed template vertex occurrences, and \(L\) is the total binary input length.
For the discrete transferable-payoff multicommodity flow game with node capacities, pair demands, and coalitions restricted to their induced graphs, the core is always nonempty and an allocation is computable in polynomial time ([Markakis–Saberi](https://www.sciencedirect.com/science/article/abs/pii/S0167923604001691)). No result settling this precise continuous mass model was located.

Modeling choices made when packaging the task

  • Normalized total mass to one, following the distribution-over-types convention; the graded question did not specify normalization.
  • Specified nonnegative binary-rational capacities and demand densities, matching the discrete capacity and demand domains.
  • Interpreted routing roles as support types and allowed graph loops to represent connections between distinct agents of the same type.
  • Made route templates explicit graph walks, counted every type occurrence toward its aggregate capacity, and included both endpoints. Repeated types can represent distinct agents with the same type.
  • Excluded single-occurrence routes: within-type commodities connect distinct agents and consume endpoint capacity twice.
  • Restricted coalition routing to templates entirely supported by the coalition, matching induced-subgraph routing.
  • Counted unordered commodities once, preserving the discrete maximum-flow normalization.
  • Required exact rational output and included a no-allocation outcome because continuous core existence is not supplied as a promise.
  • Defined graph size, template size, and binary input length for the running-time question.

Result

The exact core-allocation problem is polynomial-time solvable. Its core is always nonempty. One optimal solution of the grand-coalition LP dual yields a rational allocation satisfying every real coalition constraint.

The proof below applies to the stated continuous mass model, including repeated template occurrences, loops, and equal endpoint types.

1. The grand-coalition dual

Let \(\mathcal P\) be the set of listed templates, and let \(k(P)\) denote the unordered endpoint commodity of template \(P\).

The LP defining \(V(\mu)\) is feasible because the zero flow is feasible. It has a finite attained optimum: every variable \(f_P\) is bounded above by the finite demand \(D_{k(P)}(\mu)\), so its feasible region is compact.

Introduce dual variables \(y_t\ge0\) for type capacities and \(q_{tu}\ge0\) for unordered commodity demands. The dual is

\(\displaystyle \min\left\{\sum_t c_t\mu_t y_t+\sum_{t\le u}D_{tu}(\mu)q_{tu}:\ \sum_t a_{tP}y_t+q_{k(P)}\ge1\ \text{for every }P,\ y,q\ge0\right\}.\)

For example, setting every \(y_t=1\) and every \(q_{tu}=0\) is feasible, because each template has at least two occurrences. By LP strong duality, an optimal dual solution satisfies

\(\displaystyle \sum_t c_t\mu_t y_t+\sum_{t\le u}D_{tu}(\mu)q_{tu}=V(\mu).\)

Fix a rational optimal dual solution. Section 5 establishes that one can be computed exactly in polynomial time.

2. A bound valid for every real coalition

Fix any real coalition vector \(0\le z\le\mu\), and any flow feasible for that coalition. Dual feasibility and nonnegativity give

\(\displaystyle \sum_P f_P\le\sum_P\left(\sum_t a_{tP}y_t+q_{k(P)}\right)f_P.\)

Reordering the finite sums and applying the coalition’s capacity and demand constraints yields

\(\displaystyle \sum_P f_P\le\sum_t c_tz_ty_t+\sum_{t\le u}D_{tu}(z)q_{tu}.\)

Consequently,

\(\displaystyle V(z)\le\sum_t c_tz_ty_t+\sum_{t\le u}D_{tu}(z)q_{tu}.\)

This argument respects template availability. Indeed, if \(z_t=0\), the capacity constraint for type \(t\) reads \(\sum_P a_{tP}f_P\le0\). Since its summands are nonnegative, every template containing \(t\) must have zero flow. Thus unavailable templates may equivalently be retained with zero flow.

3. Linearizing the demand bounds

For distinct types \(t,u\), put \(x=z_t/\mu_t\) and \(w=z_u/\mu_u\). The positive support masses make these ratios well defined, and \(x,w\in[0,1]\). Hence

\(\displaystyle x+w-2xw=x(1-w)+w(1-x)\ge0.\)

Multiplying by the nonnegative quantity \(d_{tu}\mu_t\mu_u/2\) gives

\(\displaystyle D_{tu}(z)=d_{tu}z_tz_u\le\frac{d_{tu}}2(\mu_u z_t+\mu_t z_u).\)

For a diagonal commodity, \(z_t^2\le\mu_tz_t\), and therefore

\(\displaystyle D_{tt}(z)=\frac{d_{tt}z_t^2}{2}\le\frac{d_{tt}\mu_t}{2}z_t.\)

Both bounds are equalities when \(z=\mu\). This equality is what allows us to obtain an efficient allocation while covering every coalition.

4. Constructing and proving the allocation

Use the symmetric notation \(q_{ut}=q_{tu}\). Define

\(\displaystyle p_t=c_ty_t+\frac12\sum_{u\ne t}d_{tu}\mu_uq_{tu}+\frac12d_{tt}\mu_tq_{tt}.\)

Every term is nonnegative, so \(p_t\ge0\).

Efficiency. In the sum \(\sum_t\mu_tp_t\), each distinct-endpoint commodity receives two contributions of \(d_{tu}\mu_t\mu_uq_{tu}/2\), while each diagonal commodity receives \(d_{tt}\mu_t^2q_{tt}/2\). Thus

\(\displaystyle \sum_t\mu_tp_t=\sum_t c_t\mu_ty_t+\sum_{t<u}d_{tu}\mu_t\mu_uq_{tu}+\sum_t\frac{d_{tt}\mu_t^2}{2}q_{tt}=V(\mu).\)

The last equality is grand-coalition strong duality.

Every coalition constraint. For arbitrary real \(0\le z\le\mu\), the same regrouping gives

\(\displaystyle \sum_tz_tp_t=\sum_t c_tz_ty_t+\sum_{t<u}\frac{d_{tu}q_{tu}}2(\mu_uz_t+\mu_tz_u)+\sum_t\frac{d_{tt}\mu_tq_{tt}}2z_t.\)

By Section 3 and \(q_{tu}\ge0\), this is at least

\(\displaystyle \sum_t c_tz_ty_t+\sum_{t\le u}D_{tu}(z)q_{tu},\)

which is at least \(V(z)\) by Section 2. Therefore the constructed allocation lies in the exact core.

5. Exactness and running time

Let \(K=|\mathcal P|\), and let \(Q\) be the number of commodities having at least one template. Demand constraints for commodities without templates can be omitted, with their dual variables set to zero. Because each template has at least two occurrences,

\(\displaystyle K\le R/2,\qquad Q\le K.\)

The resulting dual has \(N=\tau+Q\) variables and \(K\) template inequalities.

For completeness, this dual can be restricted to the cube \(0\le(y,q)\le1\) without changing its optimum. To see this, clip each coordinate exceeding one to one. In any affected template inequality, that coordinate has a positive integer coefficient: either an occurrence count \(a_{tP}\ge1\), or the commodity coefficient one. Its clipped contribution alone is therefore at least one. Every unaffected inequality remains unchanged. Clipping preserves feasibility and cannot increase the objective, whose coefficients are nonnegative.

The restricted dual is consequently a nonempty compact rational polytope. It has a rational optimal vertex. Its constraint coefficients are integers of absolute value at most \(\max\{1,R\}\), and its right-hand sides are zero or one. Cramer’s rule and Hadamard’s determinant bound show that each coordinate of a vertex has binary encoding length

\(\displaystyle O\!\left(N\bigl(\log(N+1)+\log(R+1)\bigr)\right).\)

The objective coefficients \(c_t\mu_t\) and \(D_{tu}(\mu)\) have encoding length \(O(L)\) each, because they are products of at most three input rationals, with an optional factor \(1/2\).

Thus a dense encoding of the restricted dual has length at most

\(\displaystyle B=O\!\left((\tau+R)^2\log(R+2)+(\tau+R)(L+1)\right).\)

Exact rational LP optimization is polynomial in the LP encoding length; this concerns exact solutions, rather than merely approximate objective values. See [Gleixner–Steffy, Section 1.3](https://optimization-online.org/wp-content/uploads/2019/12/7507.pdf).

The algorithm therefore consists of preprocessing the listed templates, solving one rational LP, and evaluating the payoff formula. Including reading the graph encoding, its bit running time is

\(\displaystyle m+\operatorname{poly}(B+L+\tau+R)=\operatorname{poly}(m+\tau+R+L).\)

The output payoffs have polynomial binary length. If there are no templates, the algorithm simply returns \(p_t=0\) for every type.

No coalition enumeration or coalition-separation oracle is required: the proved demand inequalities certify all real coalition constraints simultaneously.
