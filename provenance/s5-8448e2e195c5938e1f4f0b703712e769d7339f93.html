The continuous mirror question, as graded

Given a finite set of firms \(F\), candidate types \(T\) with binary-rational masses \(\mu_t\) summing to \(1\), strict rankings of firms by each type and of types by each firm, and binary-rational per-capita capacities \(\kappa_f\), can one compute a stable rational assignment \(x_{tf}\) in time polynomial in \(|F|\), \(|T|\), and input bit length \(L\)? Require \(x_{tf}\geq 0\), \(\sum_f x_{tf}\leq\mu_t\), \(\sum_t x_{tf}\leq\kappa_f\), and, for each pair \((t,f)\), either no mass of type \(t\) would prefer \(f\) to its assignment or \(f\) has no capacity available after its assignments to types it ranks above \(t\).

Packaged proof task (what the prover saw — nothing else)

Let \(F\) be a nonempty set of firms, with \(m=|F|\). A society is given by its support: a nonempty list \(T\) of \(\tau=|T|\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts listed types, not possible types. Each type strictly ranks all firms, and each firm strictly ranks all types; every firm is acceptable to every type, and being unassigned is worst. Each firm has positive binary-rational capacity \(\kappa_f\); total capacity need not equal \(1\). Let \(L\) be the total input bit length.
An assignment consists of divisible binary-rational masses \(x_{tf}\geq 0\), with \(\sum_f x_{tf}\leq\mu_t\) and \(\sum_t x_{tf}\leq\kappa_f\). Write \(g\succ_t f\) and \(s\succ_f t\) for strict preference. Stability requires, for every \((t,f)\), \(x_{tf}+\sum_{g\succ_t f}x_{tg}=\mu_t\) or \(x_{tf}+\sum_{s\succ_f t}x_{sf}=\kappa_f\).

Can a stable rational assignment always be computed in time polynomial in \(m,\tau,L\), or is this computation NP-hard?

Discrete stable marriage admits a stable matching computed by Gale–Shapley in \(O(n^2)\) time; deferred acceptance also computes discrete capacitated firm–candidate stable matchings in polynomial time.
The continuous problem stated here is already covered by the strongly polynomial stable-allocation algorithm of [Baïou and Balinski (2002), corrected publication](https://pubsonline.informs.org/doi/pdf/10.1287/moor.27.4.662.302); consequently, this target is settled.

Modeling choices made when packaging the task

  • Require nonempty firm and type sets, complete strict preference lists, and positive capacities, carrying over the discrete domain; retain normalized total candidate mass without imposing equality of total capacity and mass.
  • Treat unassigned mass as worse than every firm, as dictated by the discrete blocking-pair definition.
  • Include mass already assigned to type t when testing whether firm f has room for t: only unused capacity or displacement of strictly worse types permits blocking. The graded condition counting only strictly better types omits this mass and can exclude every assignment in otherwise valid instances.
  • Allow arbitrary division of each type's mass among firms and require rational output; impose no firm-optimality requirement because the stated computational question asks for any stable assignment.

Conclusion

A stable rational assignment always exists and can be computed in time polynomial in \(m,\tau,L\). This follows from the corrected Baïou–Balinski stable-allocation algorithm. The reduction preserves exactly the stability condition in the question.

The applicable theorem

Baïou and Balinski consider two finite sets of agents with strict preferences, positive row quotas \(s_i\), positive column quotas \(d_j\), and nonnegative pair bounds \(u_{ij}\). Their inductive algorithm computes a feasible stable allocation using a strongly polynomial number of arithmetic operations. Stability means that, for every pair with \(x_{ij}<u_{ij}\), either its row preference prefix exhausts \(s_i\), or its column preference prefix exhausts \(d_j\). Neither equal total quotas nor nondegeneracy is required. See Section 1, equation (4), and Section 2 of the [corrected publication](https://pubsonline.informs.org/doi/pdf/10.1287/moor.27.4.662.302).

We apply this established theorem; the remaining argument verifies the reduction and exact bit complexity.

Exact correspondence with the given problem

Take the row agents to be the listed types \(T\), and the column agents to be the firms \(F\). Set \(s_t=\mu_t\), \(d_f=\kappa_f\), and \(u_{tf}=2\) for every pair. Copy both sides’ preference orders unchanged.

All theorem hypotheses hold: both sets are finite and nonempty, all row and column quotas are positive, and all preferences are strict.

The pair bounds impose no additional restriction. Indeed, every feasible assignment satisfies \(0\leq x_{tf}\leq\sum_{g\in F}x_{tg}\leq\mu_t\leq1<2=u_{tf}\). Consequently, feasibility in the two models is identical, and the theorem’s stability implication applies to every pair.

For a pair \((t,f)\), its row prefix, including the pair itself, has mass \(x_{tf}+\sum_{g\succ_t f}x_{tg}\). Its column prefix has mass \(x_{tf}+\sum_{s\succ_f t}x_{sf}\). Thus the theorem’s stability condition is precisely

\(x_{tf}+\sum_{g\succ_t f}x_{tg}=\mu_t\quad\text{or}\quad x_{tf}+\sum_{s\succ_f t}x_{sf}=\kappa_f.\)

This proves equivalence in both directions. In particular, the algorithm’s output satisfies the requested condition even when total firm capacity differs from \(1\).

The constructed instance has \(\tau\) row agents, \(m\) column agents, and \(m\tau\) pairs. It uses only the listed types.

Rational output and polynomial bit complexity

Write each input mass and capacity as a fraction with positive integer denominator. Let \(D\) be the product of these denominators. Because their binary encodings are part of the input, \(D\) has \(O(L)\) bits and can be computed in polynomial time.

Multiply every quota and pair bound by \(D\). The resulting data are integers: \(D\mu_t\), \(D\kappa_f\), and \(2D\), each with \(O(L)\) bits. Positive scaling preserves feasibility and stability: inequalities and prefix equalities scale by the same factor.

Run the inductive algorithm on this scaled instance. Its numerical updates use additions, subtractions, minima, and comparisons, so integer data yield integer allocations. These operations are explicit in the algorithm in [Section 2 of the corrected paper](https://pubsonline.informs.org/doi/pdf/10.1287/moor.27.4.662.302).

Let \(Q\) be its number of arithmetic operations, bounded by a polynomial in \(m,\tau\). Starting from integers of at most \(B=O(L)\) bits, an addition or subtraction increases the maximum bit length by at most one; minima and comparisons do not increase it. Hence every intermediate integer has at most \(B+Q\) bits. Exact execution therefore takes polynomial bit time.

If \(y\) is the computed integer allocation, return \(x_{tf}=y_{tf}/D\). Scaling equivalence proves feasibility and stability. Moreover, \(0\leq y_{tf}\leq D\mu_t\leq D\), so each output fraction has \(O(L)\) bits. If “binary-rational” means specifically dyadic, then \(D\) is a power of two, and the output is dyadic as well.

Thus the computation, including writing the entire assignment, takes time polynomial in \(m,\tau,L\).
