The continuous mirror question, as graded

Given four rational type masses \(\mu_r\), a finite set \(M\) of item kinds with rational per-capita supplies \(b_g\), and four rational cancelable valuations \(v_r\) specified by value tables on \(2^M\), decide whether there exists a rational allocation law \(x_{r,B} \ge 0\) satisfying \(\sum_B x_{r,B} = \mu_r\) and \(\sum_{r,B:g \in B} x_{r,B} = b_g\), such that whenever \(x_{r,B} > 0\) and \(x_{s,C} > 0\), \(v_r(B) \ge \max_{D \subseteq C, |D|=2} v_r(C \setminus D)\), with the maximum defined as \(0\) when \(|C| < 2\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau=4\) types with positive masses \(\mu_r\in\mathbb{Q}_{>0}\), encoded in binary, with \(\sum_{r=1}^{4}\mu_r=1\). Here \(\tau\) is the support size, not the number of possible types.
Let \(M\) be a finite set of \(m\) item kinds, with per-capita supplies \(b_g\in\mathbb{Q}\cap[0,1]\). A bundle \(B\subseteq M\) contains at most one item of each kind; empty bundles are allowed.
Each type has a monotone valuation \(v_r:2^M\to\mathbb{Q}_{\geq0}\), supplied as a complete binary-rational value table. Ties are allowed, and no normalization of \(v_r(\varnothing)\) is imposed.
Each valuation is cancelable: for all \(S,T\subseteq M\) and \(g\in M\setminus(S\cup T)\), \(v_r(S\cup\{g\})>v_r(T\cup\{g\})\) implies \(v_r(S)>v_r(T)\).
An allocation law consists of rational masses \(x_{r,B}\geq0\) satisfying \(\sum_{B\subseteq M}x_{r,B}=\mu_r\) and \(\sum_{r=1}^{4}\sum_{B\subseteq M:g\in B}x_{r,B}=b_g\).
Define \(w_r(C)=\max_{D\subseteq C,\,|D|=2}v_r(C\setminus D)\) when \(|C|\geq2\), and \(w_r(C)=0\) otherwise. The law is EF2X if, for every \(r,s\) and \(B,C\subseteq M\), \(x_{r,B}>0\) and \(x_{s,C}>0\) imply \(v_r(B)\geq w_r(C)\), including when \(r=s\).
Let \(L\) be the total binary input length, including all value tables; state running times in \(m,\tau,L\).

Is deciding whether such a rational EF2X allocation law exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For four discrete agents with monotone cancelable valuations, a complete EF2X allocation always exists and can be computed in pseudopolynomial time; for three agents, a polynomial-time algorithm is known. [Source](https://arxiv.org/html/2412.00254v2)
No result settling this exact distributional feasibility problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to one and required all four listed masses to be positive, so the support size is exactly four.
  • Restricted per-capita supplies to rational numbers between zero and one, consistently with bundles being subsets containing at most one item of each kind.
  • Restored monotonicity and nonnegative valuation values from the discrete domain; retained arbitrary nonnegative empty-bundle values because no zero normalization is imposed there.
  • Allowed valuation ties because the full version removes the auxiliary nondegeneracy assumption.
  • Made explicit that EF2X comparisons include different positive-mass bundles assigned to the same type.
  • Defined L as the total binary input length, including the complete valuation tables.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Polynomial-time solvability

The stated problem is polynomial-time solvable. The decisive assumptions are that the support size is fixed at \(\tau=4\) and that the complete value tables are included in the input. The algorithm below actually works for arbitrary nonnegative valuation tables; monotonicity and cancelability are unnecessary.

1. Encoding EF2X by utility thresholds

Write \(N=2^m\), the number of bundles. For each type \(r\), define the finite set of candidate thresholds
\[ \]
\(\displaystyle V_r=\{v_r(B):B\subseteq M\}.\)

Thus \(|V_r|\leq N\).

For a tuple \(a=(a_1,\ldots,a_\tau)\in V_1\times\cdots\times V_\tau\), define the bundles permitted for type \(s\) by

\(\displaystyle \mathcal A_s(a)=\{B\subseteq M:v_s(B)\geq a_s\text{ and }w_r(B)\leq a_r\text{ for every }r\}.\)

Consider the following linear feasibility problem, denoted \(\mathrm{LP}(a)\). Its variables are \(x_{s,B}\) for \(B\in\mathcal A_s(a)\), and its constraints are

\(\displaystyle x_{s,B}\geq0,\)

\(\displaystyle \sum_{B\in\mathcal A_s(a)}x_{s,B}=\mu_s\qquad(s=1,\ldots,\tau),\)

\(\displaystyle \sum_{s=1}^{\tau}\sum_{\substack{B\in\mathcal A_s(a)\\g\in B}}x_{s,B}=b_g\qquad(g\in M).\)

Variables for other bundles are understood to be zero.

Lemma. A rational EF2X allocation law exists if and only if \(\mathrm{LP}(a)\) has a rational feasible solution for at least one candidate tuple \(a\).

Proof, forward direction. Suppose \(x\) is a rational EF2X allocation law. Since \(\mu_r>0\), every type has at least one positively supported bundle. Therefore the minimum

\(\displaystyle a_r=\min\{v_r(B):x_{r,B}>0\}\)

exists and belongs to \(V_r\). Choose a positively supported bundle \(B_r\) attaining this minimum.

Let \(C\) be any bundle with \(x_{s,C}>0\), for any type \(s\). Applying EF2X to \(B_r\) and \(C\) gives

\(\displaystyle w_r(C)\leq v_r(B_r)=a_r\)

for every \(r\). Also \(v_s(C)\geq a_s\) by the definition of \(a_s\). Hence \(C\in\mathcal A_s(a)\). The original allocation law consequently satisfies \(\mathrm{LP}(a)\).

This argument includes \(r=s\), so it explicitly incorporates same-type comparisons.

Proof, reverse direction. Suppose \(x\) is a rational feasible solution of \(\mathrm{LP}(a)\). Whenever \(x_{r,B}>0\) and \(x_{s,C}>0\), membership in the permitted bundle sets gives

\(\displaystyle v_r(B)\geq a_r\geq w_r(C).\)

Thus every required EF2X inequality holds, including those with \(r=s\). The remaining constraints are precisely the type-mass and supply equations. Therefore \(x\) is a rational EF2X allocation law. This proves the lemma.

2. Exact feasibility and rationality

Each \(\mathrm{LP}(a)\) has at most \(\tau N\) variables and \(m+\tau\) equality constraints. Its constraint matrix has only zero and one entries, and its right-hand side consists of the input rationals \(\mu_s\) and \(b_g\).

We use the standard theorem that feasibility of explicitly encoded rational linear inequalities is decidable in time polynomial in their total binary encoding length. Equalities are represented by two inequalities. Thus all hypotheses of the polynomial-time linear-programming theorem are satisfied. [Khachiyan, *A polynomial algorithm in linear programming*](https://www.mathnet.ru/eng/dan42319).

Real feasibility here also implies rational feasibility. To verify this directly, observe that each variable satisfies

\(\displaystyle 0\leq x_{s,B}\leq\mu_s.\)

Consequently, a nonempty feasible region is a compact polytope and has a vertex. At a vertex, the matrix columns corresponding to positive variables must be linearly independent: otherwise, a nonzero dependence would permit sufficiently small perturbations in both directions, preserving all equations and nonnegativity, contradicting extremality.

There are therefore at most \(k\leq m+\tau\) positive variables. Selecting \(k\) independent rows gives a nonsingular square system determining them. Its matrix has integer entries and its right-hand side is rational, so Cramer’s rule gives rational coordinates.

These coordinates have polynomial binary length. Indeed, let \(D\) be the product of the input right-hand-side denominators. Its binary length is \(O(L)\), and multiplication by \(D\) makes the right-hand side integral, with entries between zero and \(D\). The determinant expansion bounds the matrix determinant by \(k!\) in absolute value and each replaced-column determinant by \(k!D\). Hence each coordinate requires \(O(L+k\log(k+1))\) bits.

3. Algorithm and running time

The algorithm proceeds as follows:

  • Compute \(w_r(C)\) for every type and bundle using the supplied definition, retaining \(w_r(C)=0\) when \(|C|<2\).
  • Enumerate all tuples in \(V_1\times\cdots\times V_\tau\).
  • For each tuple, construct the permitted bundle sets and test \(\mathrm{LP}(a)\).
  • Accept exactly when at least one of these linear programs is feasible.

The lemma and rationality argument prove correctness.

Computing all \(w_r(C)\) requires at most

\(\displaystyle O\bigl(\tau(1+m^2)2^m\bigr)\)

rational comparisons. Every comparison is exact and takes time polynomial in \(L\): each computed maximum is either zero or an existing table value.

There are at most \(N^\tau=2^{m\tau}\) threshold tuples. For each tuple, constructing the permitted sets requires \(O(\tau^2N)\) comparisons. An explicitly written linear program has encoding length

\(\displaystyle O\bigl(\tau N(m+\tau)+L\bigr).\)

Because the complete tables explicitly contain \(\tau N\) rational entries, \(L\geq\tau N\). Thus each linear program, and its feasibility test, has size and running time polynomial in \(m,\tau,L\).

The total bit running time is therefore bounded by

\(\displaystyle 2^{m\tau}\operatorname{poly}(m,\tau,L).\)

For the stipulated support size \(\tau=4\),

\(\displaystyle 2^{m\tau}=2^{4m}=N^4\leq(L/4)^4.\)

Consequently, the total running time is polynomial in \(m,\tau,L\) on the stated input class. More generally, the same proof gives polynomial time for every fixed support size; it does not establish a uniform polynomial bound when \(\tau\) is unbounded.

4. Scope of the conclusion

No assumption about ties or normalization was used. The thresholds are actual table values, and the prescribed zero value of \(w_r(C)\) for small bundles is preserved exactly.

The cited discrete four-agent theorem concerns complete allocations among four individual agents. Its existence guarantee and pseudopolynomial algorithm do not directly decide this distributional feasibility problem. [Ashuri, Gkatzelis, and Sgouritsa, *EF2X Exists For Four Agents*](https://arxiv.org/html/2412.00254v2). Here polynomial-time solvability follows instead from the threshold characterization, fixed support size, and explicit-table encoding.
