Proposition 4 — class: other

The continuous mirror question, as graded

Given a finite alternative set \(W\), supported types \(K\) with positive rational masses \(\mu_k\) summing to \(1\), an initial total-preorder preference \(\pi_k\) for each type, and a reliability order over types inducing a most-reliable successor \(f(k)\), decide whether some finite round makes all positive-mass types share the same preference, and return the earliest such round if it exists. At each round, type \(k\) adopts the current preference of type \(f(k)\).

Packaged proof task (what the prover saw — nothing else)

Let \(W\) be a finite alternative set with \(m=|W|\geq 1\). A society is given by its support: a list \(K\) of \(\tau\geq 2\) types with positive binary rational masses \(\mu_k\), where \(\sum_{k\in K}\mu_k=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type \(k\) has an initial total preorder \(\pi_k\) on \(W\), given as ordered indifference classes, and its own fixed total reliability order \(\preceq_k\) on all of \(K\), including itself. Let \(f(k)\) be the unique greatest type in this order; self-selection is allowed.
Set \(\pi_k^{(0)}=\pi_k\). At each integer round \(t\geq 0\), all types update simultaneously by \(\pi_k^{(t+1)}=\pi_{f(k)}^{(t)}\); masses and reliability orders remain fixed. Unanimity means equality of the entire preference relations for every supported type. Distinct types may initially have identical preferences.
The computational problem is to decide whether unanimity occurs and, if so, return the least such \(t\), including \(t=0\), encoded in binary. Let \(L\) be the total binary input length.

Can unanimity reachability and its earliest round be computed in time polynomial in \(m,\tau,L\), or is deciding unanimity reachability NP-hard?

For finite agent lists with pairwise distinct initial preferences, unanimity under simultaneous copying is characterized by synchronous reachability of a common agent in the most-reliable-successor relation; this characterization supplies a modal decision procedure, without a stated complexity bound. [Ghosh–Velázquez-Quesada](https://www.ifaamas.org/Proceedings/aamas2015/aamas/p1491.pdf)
No result settling the exact rational-mass problem above was located in the literature search.

Result

Both unanimity reachability and the earliest round are computable in time polynomial in \(m,\tau,L\). More precisely, if unanimity ever occurs, its earliest round satisfies \(0\leq t\leq\tau-1\).

The proof allows identical initial preferences, arbitrary positive rational masses, and self-selection. For \(m=1\), all initial preferences coincide and the answer is immediately \(t=0\); the argument below covers general \(m\).

1. Preferences at each round

Write \(f^0\) for the identity on \(K\), and \(f^{t+1}=f\circ f^t\). We first establish that, for every \(k\in K\) and \(t\geq0\),

\(\displaystyle \pi_k^{(t)}=\pi_{f^t(k)}.\)

At \(t=0\), this is the definition of the initial state. If it holds at round \(t\), the simultaneous update gives

\(\displaystyle \pi_k^{(t+1)}=\pi_{f(k)}^{(t)}=\pi_{f^t(f(k))}=\pi_{f^{t+1}(k)}.\)

Thus the claim follows by induction.

Define the set of initial preference sources at round \(t\) by

\(\displaystyle S_t=f^t(K)=\{f^t(k):k\in K\}.\)

Consequently, unanimity at round \(t\) is equivalent to

\(\displaystyle \pi_u=\pi_v\quad\text{for every }u,v\in S_t.\)

Indeed, every current preference comes from a member of \(S_t\), and every member of \(S_t\) supplies some type’s current preference. This equivalence concerns equality of preference relations, so it remains valid when distinct types have identical initial preferences.

2. The source sets stabilize within \(\tau-1\) rounds

We have \(S_0=K\) and \(S_{t+1}=f(S_t)\). These sets are nonempty because \(K\) is nonempty and \(f\) is defined everywhere.

They are also nested:

\(\displaystyle S_{t+1}\subseteq S_t\quad\text{for every }t\geq0.\)

For the base case, \(f(K)\subseteq K\). If \(S_t\subseteq S_{t-1}\), taking images under \(f\) gives \(S_{t+1}\subseteq S_t\).

Furthermore, an equality \(S_{t+1}=S_t\) forces permanent stabilization: applying \(f\) gives \(S_{t+2}=S_{t+1}\), and induction gives all subsequent equalities.

Starting with \(\tau\) elements, a nested sequence of nonempty sets can undergo at most \(\tau-1\) strict decreases. Therefore,

\(\displaystyle S_{\tau-1}=S_\tau=S_{\tau+1}=\cdots.\)

To justify the endpoint explicitly: if equality occurs before round \(\tau-1\), stabilization has already occurred; otherwise the first \(\tau-1\) decreases are strict, leaving a singleton, whose next nonempty subset must equal itself.

Since unanimity depends only on whether the initial preferences on \(S_t\) coincide, its truth value is constant after round \(\tau-1\). Hence unanimity is reachable if and only if it occurs in one of rounds \(0,\ldots,\tau-1\).

Also, once unanimity occurs, it persists: subsequent source sets are subsets of the unanimous source set.

3. Polynomial-time algorithm and earliest round

Fix an indexing of \(W\). Encode each initial preorder by its rank vector: an alternative receives the index of its indifference class in the given order. Each vector has \(m\) entries.

Two such vectors coincide exactly when their preference relations coincide. One direction follows because class ranks determine every comparison. Conversely, the relation determines its indifference classes and their order, hence determines the rank vector.

The algorithm is:

  • Extract \(f(k)\), the greatest element of each type’s reliability order.
  • Set \(S=K\).
  • For \(t=0,\ldots,\tau-1\), compare the initial rank vectors of all members of \(S\).
  • If they all coincide, return \(t\) in binary.
  • Otherwise, if another round remains, replace \(S\) by \(f(S)\), removing duplicates.
  • If no round passes the comparison, report that unanimity is unreachable.

At the start of iteration \(t\), the maintained set is \(S_t\), by induction on the update \(S\leftarrow f(S)\). Section 1 therefore proves that each comparison correctly tests unanimity at that round. Testing rounds in increasing order returns the least round. Section 2 proves that rejection after the final test rules out every later round.

There are \(\tau\) iterations. Each examines at most \(\tau\) vectors of length \(m\) and computes at most \(\tau\) successors. Thus, after parsing, the algorithm uses \(O(\tau^2m+\tau^2)\) elementary operations. Ranks and type indices require only \(O(\log(m+\tau+1))\) bits, so these operations have polynomial bit cost. Parsing the explicitly supplied preferences, reliability orders, and rational masses also takes polynomial time in \(L\).

The masses do not enter either the update rule or the equality test. Their magnitudes and denominators therefore introduce no additional dynamics or numerical computation. The returned round requires only \(O(\log\tau)\) bits.

4. Structural characterization

Let \(C\subseteq K\) be the set of vertices lying on directed cycles of the graph with edges \(k\to f(k)\). Then

\(\displaystyle S_{\tau-1}=C.\)

For the first inclusion, a cyclic vertex has a predecessor on its cycle under every iterate \(f^t\); hence \(C\subseteq S_t\) for every \(t\).

For the reverse inclusion, put \(S=S_{\tau-1}\). Stabilization gives \(f(S)=S\), so the restriction of \(f\) to the finite set \(S\) is surjective and therefore bijective. Every vertex of a finite permutation lies on a cycle. Thus \(S\subseteq C\).

It follows that unanimity is reachable exactly when all cyclic vertices, across all cycles, have the same initial preference relation.

When initial preferences are pairwise distinct, this condition says that \(C\) is a singleton, necessarily a self-loop. This recovers the common-source condition in [Ghosh–Velázquez-Quesada, Proposition 3](https://www.ifaamas.org/Proceedings/aamas2015/aamas/p1491.pdf). With repeated preferences, several cycles may exist and still permit unanimity.

5. The round bound is sharp

For any \(\tau\geq2\) and \(m\geq2\), choose distinct total preorders \(p,q\). Let \(K=\{1,\ldots,\tau\}\), with

\(\displaystyle f(i)=i+1\text{ for }i<\tau,\qquad f(\tau)=\tau.\)

Give types \(1,\ldots,\tau-1\) initial preference \(q\), and type \(\tau\) initial preference \(p\). These successors can be realized by total reliability orders placing the designated successor greatest; choose any admissible positive masses.

For every \(t<\tau-1\), type \(1\) has preference \(q\), while type \(\tau\) has preference \(p\). Unanimity therefore fails. At round \(\tau-1\), every type copies the initial preference of type \(\tau\), so unanimity occurs.

Thus the bound \(\tau-1\) cannot be improved in general. The decision problem belongs to \(\mathsf{P}\); NP-hardness under polynomial-time reductions would consequently imply \(\mathsf{P}=\mathsf{NP}\).

The identity

The equivalence between unanimity at round \(t\) and equality of all initial preferences indexed by \(S_t=f^t(K)\) is exact. 2. Nestedness and stabilization

The proof that \(S_{t+1}\subseteq S_t\) is correct: the base inclusion is \(f(K)\subseteq K\), and taking images preserves inclusion.

The permanent-stabilization claim is also correct. Since \(S_{t+1}=f(S_t)\), equality at consecutive rounds implies equality at the next pair, and induction applies.

Nonemptiness follows because \(f\) is a total function on a nonempty finite set. Consequently, there can be at most \(\tau-1\) strict decreases. Persistence of unanimity follows correctly from nestedness.

Rank vectors give a canonical representation of the supplied ordered indifference classes, using the same indexing of alternatives and class positions for every type.
