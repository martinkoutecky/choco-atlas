The continuous mirror question, as graded

Given candidates \(C\), a committee size \(q\), a finite support \(T\subseteq\{0,1\}^{C}\) of approval types with rational masses \(\mu_t\geq 0\) summing to \(1\), and a rational threshold \(B\geq 0\), does there exist a committee \(W\subseteq C\), \(|W|=q\), such that \(\sum_{t\in T}\mu_t d_H(\mathbf{1}_W,t)^2\leq B\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\geq 1\), and let the input committee size be an integer \(1\leq q\leq m\).
A society is given by its support: a list \(T\subseteq\{0,1\}^{C}\) of \(\tau\) distinct approval types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval types.
The input also contains a binary rational threshold \(B\geq0\); let \(L\) be the total input bit length. Approval sets may be empty or equal to \(C\).
A feasible outcome is a committee \(W\subseteq C\) with \(|W|=q\). Its cost is \(\sum_{t\in T}\mu_t d_H(\mathbf{1}_W,t)^2\), where \(d_H\) is Hamming distance and \(\mathbf{1}_W\) is the incidence vector of \(W\).

Is deciding whether a feasible committee has cost at most \(B\) solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,L,q\).

For a finite list of voters, minimizing the \(p\)-norm of committee Hamming distances subject to a prescribed committee size is NP-hard for every fixed rational \(p>1\), including \(p=2\). [Source](https://drops.dagstuhl.de/storage/00lipics/lipics-vol144-esa2019/LIPIcs.ESA.2019.28/LIPIcs.ESA.2019.28.pdf)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is \(\mathrm{NP}\)-complete when the committee size and support size are part of the input. Compressing repeated voters into rational masses preserves the hardness. For every fixed support size \(\tau\), however, the problem is polynomial-time solvable.

1. Exact arithmetic and membership in \(\mathrm{NP}\)

Write \(A_t=\{c\in C:t_c=1\}\). For a committee \(W\) of size \(q\),

\[ d_H(\mathbf 1_W,t)=q+|A_t|-2|W\cap A_t|. \]

A certificate is the incidence vector of \(W\). Its cardinality and all distances can be checked in \(O(m\tau)\) elementary operations.

To check the cost exactly, let \(D\) be the product of the denominators of the masses and of \(B\). Since their total encoding length is at most \(L\), the bit length of \(D\) is \(O(L)\). Set \(a_t=D\mu_t\) and \(b=DB\), both integers. The required comparison becomes

\[ \sum_{t\in T}a_t\,d_H(\mathbf 1_W,t)^2\leq b. \]

Every distance is at most \(m\), so all integers involved have \(O(L+\log m)=O(L)\) bits. Using schoolbook integer arithmetic, verification takes \(O(m\tau+\tau L^2)\) bit operations. Thus the problem belongs to \(\mathrm{NP}\).

2. A polynomial reduction establishing hardness

We use the following precise consequence of the cited result: deciding whether an explicitly listed collection of binary approval vectors admits a committee of prescribed size whose sum of squared distances is at most an integer threshold is \(\mathrm{NP}\)-hard.

The integer-threshold qualification follows directly from the paper’s construction. For a graph with \(v\) vertices and \(e\) edges, put \(h=v+e\). Specializing its Theorem 3 to \(p=2\) gives \(4h\) candidates, \(3+2v+6e\) voters, and squared threshold

\[ K=6h^2+2(v+3e)(2h)^2. \]

Corollary 7 prescribes committee size \(h\). Hence these are polynomially encoded instances with positive committee size and integer \(K\). [Chen, Hermelin and Sorge, Theorem 3 and Corollary 7](https://drops.dagstuhl.de/storage/00lipics/lipics-vol144-esa2019/LIPIcs.ESA.2019.28/LIPIcs.ESA.2019.28.pdf).

Now take such a finite-voter instance with approval vectors \(t_1,\ldots,t_N\), committee size \(q\), and squared threshold \(K\). Let \(T\) contain its distinct approval vectors, and define

\[ c_t=|\{i:t_i=t\}|,\qquad \mu_t=\frac{c_t}{N},\qquad B=\frac{K}{N}. \]

These masses are positive rationals and sum to one. For every feasible committee \(W\),

\[ \sum_{t\in T}\mu_t d_H(\mathbf 1_W,t)^2 = \frac1N\sum_{i=1}^{N}d_H(\mathbf 1_W,t_i)^2. \]

Consequently, the original instance is a yes-instance exactly when the constructed rational-mass instance is a yes-instance.

Grouping identical vectors takes polynomial time, for example by sorting them. There are \(\tau\leq N\) output types; each mass requires \(O(\log N)\) bits, and \(B\) requires \(O(\log(K+1)+\log N)\) bits. Thus the output length is polynomial in the original input length. Together with membership in \(\mathrm{NP}\), this proves \(\mathrm{NP}\)-completeness.

The reduction even works with dyadic masses if that narrower meaning of “binary rational” is intended. Choose a power of two \(R\) with \(N\leq R<2N\), and append \(R-N\) empty-approval voters before grouping. Each added voter contributes exactly \(q^2\), so use threshold

\[ B=\frac{K+(R-N)q^2}{R}. \]

All masses then have denominator \(R\), and the same equivalence holds.

3. Exact running times

The following bounds are elementary upper bounds; no optimality claim is needed.

Committee enumeration. Enumerate all committees of size \(q\), verifying each as above. A convenient conservative bit-operation bound is

\[ O\!\left(\binom{m}{q}\,m\tau L^2\right). \]

In particular, this is \(O(2^m m\tau L^2)\). If \(s=\min\{q,m-q\}\), then \(\binom{m}{q}=\binom{m}{s}\leq m^s\), so enumeration is polynomial whenever \(q\), or \(m-q\), is fixed.

Dynamic programming for fixed support size. We prove a second bound,

\[ O\!\left(m\tau(s+1)^{\tau+1}L^2\right), \qquad s=\min\{q,m-q\}. \]

First reduce to selecting \(s\) candidates. If \(q\leq m/2\), leave the instance unchanged. Otherwise replace every approval set \(A_t\) by \(C\setminus A_t\), and select the excluded committee \(U=C\setminus W\). Complementing both vectors preserves Hamming distance:

\[ d_H(\mathbf 1_W,t) = d_H(\mathbf 1_U,\mathbf 1_{C\setminus A_t}). \]

Thus this transformation preserves every cost, every mass, and distinctness of the support types.

Denote the resulting approval sets by \(A_1,\ldots,A_\tau\), and order the candidates as \(c_1,\ldots,c_m\). After processing the first \(j\) candidates, store whether each state

\[ (k,z_1,\ldots,z_\tau)\in\{0,\ldots,s\}^{\tau+1} \]

is attainable, where \(k\) is the number selected and \(z_i\) is the number selected from \(A_i\).

Initially only \((0,0,\ldots,0)\) is attainable. From any attainable state, processing candidate \(c_{j+1}\) permits:

  • skipping it, leaving the state unchanged;
  • selecting it when \(k<s\), producing

\((k+1,z_1+\mathbf 1_{c_{j+1}\in A_1},\ldots,z_\tau+\mathbf 1_{c_{j+1}\in A_\tau})\).

Induction on \(j\) proves correctness: every subset either excludes or includes the newly processed candidate, and these are exactly the two transitions.

At the last layer, consider states with \(k=s\). Such a state has distances

\[ d_i=s+|A_i|-2z_i. \]

Evaluate \(\sum_i\mu_i d_i^2\) exactly and accept if any attainable state meets the threshold. The induction ensures that this examines exactly the achievable distance vectors of feasible committees.

There are at most \((s+1)^{\tau+1}\) states per layer. Each transition updates \(\tau\) coordinates, and each final cost comparison takes polynomial bit time as established above. This yields the stated bound.

Therefore an exact algorithm can choose between the two methods and run in

\[ O\!\left( m\tau L^2 \min\left\{ \binom{m}{q},\, (s+1)^{\tau+1} \right\} \right). \]

This is polynomial for every fixed \(\tau\), while unrestricted instances are \(\mathrm{NP}\)-complete. The boundary case \(q=m\) has only one feasible committee and is also polynomial.
