The continuous mirror question, as graded

Given finite complete agent types \(T\), chore types \(E\), rational masses \(\mu_t\), per-capita supplies \(\lambda_e\), type entitlements \(r_t\), and additive costs \(v_t(e)\), define \(M_t^\infty=r_t\inf\{\rho:\exists y_{s,b}\ge0,\ \sum_b y_{s,b}=\mu_s,\ \sum_{s,b}b_e y_{s,b}=\lambda_e,\ y_{s,b}>0\Rightarrow v_t(b)\le\rho r_s\}\), where \(b\in\mathbb{Z}_{\ge0}^{E}\). Decide, or optimize, whether there exist \(x_{t,b}\ge0\) with \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}b_e x_{t,b}=\lambda_e\), and \(x_{t,b}>0\Rightarrow v_t(b)\le(2-\epsilon)M_t^\infty\).

Packaged proof task (what the prover saw — nothing else)

A society is specified by its support \(T\): the list of \(\tau=|T|\) complete agent types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Support size counts listed types, not all possible types.
There are \(m=|E|\ge1\) chore types with positive rational per-capita supplies \(\lambda_e\). Each agent type specifies rational entitlement \(r_t>0\) and nonnegative rational additive costs \(v_t(e)\); normalize \(\sum_t\mu_t r_t=1\).
An individual receives an integer bundle \(b\in\mathcal B=\mathbb Z_{\ge0}^{E}\), including the empty bundle, with \(v_t(b)=\sum_e b_e v_t(e)\). Every chore type is assignable to every agent type.
Let \(\mathcal F\) consist of nonnegative real arrays \(z_{t,b}\) satisfying \(\sum_b z_{t,b}=\mu_t\) and \(\sum_{t,b}b_e z_{t,b}=\lambda_e\) for every \(e\); these equalities require convergent sums and complete allocation.
Define \(M_t^\infty=r_t\inf\{\rho\ge0:\exists y\in\mathcal F,\ \forall s,b,\ y_{s,b}>0\Rightarrow v_t(b)\le\rho r_s\}\).
For \(\alpha\ge1\), an \(\alpha\)-WMMS allocation is \(x\in\mathcal F\) with \(x_{t,b}>0\Rightarrow v_t(b)\le\alpha M_t^\infty\) for every \(t,b\). The bound applies to each assigned bundle, rather than an average cost.
Let \(L\) be the total binary input length; express algorithmic running times in \(m,\tau,L\) and any approximation parameter.

Does there exist a constant \(0<\epsilon<1\) such that every such society admits a \((2-\epsilon)\)-WMMS allocation, or does every \(0<\epsilon<1\) admit a society with no such allocation?

For discrete indivisible chores, every \(0<\delta<1\) admits an instance with no allocation achieving a factor strictly below \(2-\delta\); a \(12\)-WMMS allocation always exists. [Li, Wang and Xing](https://arxiv.org/html/2510.06581v2)
No result settling this exact distribution-over-integer-bundles model was located in the literature search.

Modeling choices made when packaging the task

  • Normalize total society mass to one so that supplies are per capita; interpret a complete agent type as its entitlement and its full cost vector.
  • Require positive rational entitlements and normalize their mass-weighted sum to one. This fixes their otherwise unspecified scale without changing the benchmark.
  • Use nonnegative rational additive costs, allowing zero costs and imposing no valuation normalization, as in the discrete model.
  • List only chore types with positive rational supply, excluding zero-supply coordinates; require at least one chore type.
  • Allow empty integer bundles and unrestricted nonnegative integer multiplicities, retaining the graded question's bundle domain.
  • Interpret allocation variables as real masses, with convergent exact supply sums and bundlewise fairness, allowing countably many positive entries.
  • Resolve 'decide, or optimize' into the universal approximation-guarantee question dictated by the anchor's existential lower bound, rather than exact feasibility complexity.

Result

The second alternative holds: for every \(0<\epsilon<1\), there is a society admitting no \((2-\epsilon)\)-WMMS allocation.

The construction below uses strictly positive costs, dyadic masses and supplies, and only linearly many supported agent and chore types. It adapts the geometric-group idea of [Li, Wang and Xing](https://arxiv.org/html/2510.06581v2), but the proof directly handles distributions over unrestricted integer bundles.

1. Parameters and society

Fix \(0<\epsilon<1\). Choose

\(k=\lceil 8/\epsilon\rceil,\qquad a=\lceil\log_2(12/\epsilon)\rceil,\qquad \Delta=2^a.\)

Thus \(2/k\le\epsilon/4\), \(3/\Delta\le\epsilon/4\), and \(\Delta\ge16\).

For \(1\le i\le k\), define auxiliary integers and weights

\(n_i=\Delta^{i-1},\qquad w_1=1,\qquad w_i=2^{i-2}/n_i\quad(i\ge2),\qquad W_i=n_iw_i.\)

These auxiliary integers do not count as supported agent types. There will be just one supported type for each index.

The weights satisfy

\(W_1=W_2=1,\qquad W_i=2^{i-2}\quad(i\ge2),\)

and, for every \(i\ge2\),

\(\sum_{s<i}W_s=W_i.\)

Chore types and supplies

There are \(m=2k-1\) chore types:

\(E=\{H\}\cup\{A_i,B_i:2\le i\le k\}.\)

We first specify integer counts \(c_e\), which will subsequently be scaled into supplies. Set \(c_H=1\) and \(P_1=1\). Recursively, for \(i\ge2\), set

\(c_{A_i}=n_i/2-P_{i-1},\qquad c_{B_i}=n_i,\qquad P_i=P_{i-1}+c_{A_i}+c_{B_i}.\)

Consequently,

\(P_i=3n_i/2\quad(i\ge2).\)

Every count is a positive integer. Indeed,

\(c_{A_2}=\Delta/2-1>0,\)

while, for \(i\ge3\),

\(c_{A_i}=(n_i-3n_{i-1})/2=(\Delta-3)n_{i-1}/2>0.\)

Put

\(q=1/(2n_k),\qquad \lambda_e=qc_e.\)

All supplies are positive dyadic rationals.

Agent types, costs and entitlements

The support is \(T=\{0,1,\ldots,k\}\), so \(\tau=k+1\). Types \(1,\ldots,k\) have masses

\(\mu_i=qn_i.\)

The auxiliary type \(0\) has mass

\(\mu_0=1-q\sum_{i=1}^k n_i.\)

This is positive because

\(q\sum_{i=1}^k n_i<\frac{\Delta}{2(\Delta-1)}<1.\)

All masses are dyadic rationals.

For types \(1,\ldots,k\), define the costs of \(H\) by

\(v_1(H)=1,\qquad v_i(H)=2w_i\quad(i\ge2).\)

For \(2\le j\le k\), define

\(v_i(A_j)= \begin{cases} w_j,&i<j,\\ 2w_i,&i\ge j, \end{cases}\)

and

\(v_i(B_j)= \begin{cases} w_j/2,&i<j,\\ w_i,&i=j,\\ 2w_i,&i>j. \end{cases}\)

Set \(v_0=v_k\). Every cost specified above is strictly positive.

Let

\(d=w_k/4,\qquad C=q\sum_{i=1}^kW_i+\mu_0d,\)

and define entitlements

\(r_i=w_i/C\quad(1\le i\le k),\qquad r_0=d/C.\)

These are positive rationals and satisfy the required normalization:

\(\sum_{t\in T}\mu_tr_t =\bigl(q\sum_{i=1}^kW_i+\mu_0d\bigr)/C=1.\)

2. Benchmark upper bounds

We prove

\(M_i^\infty\le w_i\quad(1\le i\le k),\qquad M_0^\infty\le d.\)

Only upper bounds are needed; we do not claim equality.

For the proof, represent the mass of type \(s\ge1\) by \(n_s\) conceptual slots, each of mass \(q\). Assigning a bundle to each slot produces an allocation array by adding the masses of slots with the same type and bundle. These slots are a device for constructing a finite-support witness.

Fix an evaluating type \(i\).

Evaluator \(i=1\)

Give \(H\) to the sole slot of type \(1\).

For each \(j\ge2\):

  • Give one \(A_j\) to each of \(c_{A_j}\) slots of type \(j\).
  • Give two \(B_j\)'s to each of another \(n_j/2\) slots of type \(j\).
  • Leave the remaining slots empty.

There are enough slots because \(c_{A_j}+n_j/2\le n_j\). From evaluator \(1\)'s perspective, each nonempty type-\(j\) bundle has cost \(w_j\). The type-\(1\) bundle has cost \(w_1\).

Give every individual of type \(0\) the empty bundle. This completely allocates the prescribed supplies.

Evaluator \(i\ge2\)

The total number of copies among

\(\{H\}\cup\{A_j,B_j:2\le j<i\}\cup\{A_i\}\)

is

\(P_{i-1}+c_{A_i}=n_i/2.\)

Every one of these copies has cost \(2w_i\) to evaluator \(i\).

For each earlier type \(s<i\), give every slot exactly \(w_s/(2w_i)\) copies from this collection. These quantities are integers. For \(s=1\),

\(w_1/(2w_i)=(\Delta/2)^{i-1},\)

and, for \(2\le s<i\),

\(w_s/(2w_i)=\Delta^{i-s}/2^{i-s+1} =2^{(a-1)(i-s)-1}.\)

The number of copies consumed is exactly

\(\sum_{s<i}n_s\frac{w_s}{2w_i} =\frac{\sum_{s<i}W_s}{2w_i} =\frac{W_i}{2w_i} =n_i/2.\)

Thus all these chores can be assigned, and each type-\(s\) slot has evaluator-\(i\) cost exactly \(w_s\).

Give each type-\(i\) slot one \(B_i\), of evaluator-\(i\) cost \(w_i\).

For each \(j>i\), assign the \(A_j\) and \(B_j\) copies to type-\(j\) slots as in the previous case. Every nonempty such bundle again has evaluator-\(i\) cost \(w_j\).

Give type \(0\) empty bundles. This also completely allocates all supplies.

Applying the definition

For either witness, every bundle assigned to type \(s\ge1\) satisfies

\(v_i(b)\le w_s=Cr_s.\)

The empty bundles assigned to type \(0\) satisfy the same threshold requirement. Therefore \(\rho=C\) is feasible in the definition of evaluator \(i\)'s benchmark, giving

\(M_i^\infty\le r_iC=w_i.\)

Since \(v_0=v_k\), the witness for evaluator \(k\) also proves

\(M_0^\infty\le r_0C=d.\)

All witnesses have finite support, so their allocation sums converge.

3. Consequences of a factor below \(2\)

Suppose that an \(\alpha\)-WMMS allocation \(x\) exists for some \(1\le\alpha<2\).

By the benchmark bounds, every bundle assigned to type \(i\ge1\) has cost at most \(\alpha w_i<2w_i\).

Consequently:

  • Type \(i\ge2\) receives no \(H\).
  • Type \(i\) receives no \(A_j\) with \(j\le i\).
  • Type \(i\) receives no \(B_j\) with \(j<i\).

For example, one copy of any excluded chore already costs \(2w_i\). Because bundles have integer coordinates, its presence violates the bound irrespective of how small the mass receiving that bundle is.

Furthermore, type \(0\) receives only empty bundles. Every nonempty bundle costs at least \(w_k\) to this type, whereas

\(\alpha M_0^\infty\le\alpha d<2d=w_k/2.\)

Thus \(A_j\) can go only to types \(i<j\), and \(B_j\) only to types \(i\le j\).

4. A pricing certificate

Assign nonnegative prices to chore types:

\(p_H=1,\qquad p_{A_j}=w_j/W_{j-1},\qquad p_{B_j}=w_j/(2W_{j-1})\quad(2\le j\le k).\)

For a bundle \(b\), write \(p(b)=\sum_e p_eb_e\).

We claim that every bundle permitted by the exclusions above satisfies

\(p(b)\le v_i(b)/W_i\)

when assigned to type \(i\ge1\). It suffices to check each permitted chore.

For \(H\), the only permitted recipient is type \(1\), and \(p_H=v_1(H)/W_1=1\).

For \(A_j\), a permitted recipient has \(i<j\). Since the sequence \(W_i\) is nondecreasing,

\(p_{A_j}=\frac{w_j}{W_{j-1}} \le\frac{w_j}{W_i} =\frac{v_i(A_j)}{W_i}.\)

For \(B_j\) assigned to an earlier type \(i<j\), likewise,

\(p_{B_j}=\frac{w_j}{2W_{j-1}} \le\frac{w_j}{2W_i} =\frac{v_i(B_j)}{W_i}.\)

For \(B_j\) assigned to type \(j\), use \(W_j\le2W_{j-1}\):

\(p_{B_j}=\frac{w_j}{2W_{j-1}} \le\frac{w_j}{W_j} =\frac{v_j(B_j)}{W_j}.\)

Additivity proves the bundle inequality without any restriction on bundle multiplicities.

Now sum over the allocation. Type \(0\)'s bundles are empty. Complete allocation and the price inequality give

\(\sum_e p_e\lambda_e =\sum_{i=1}^k\sum_b p(b)x_{i,b} \le\sum_{i=1}^k\frac{1}{W_i}\sum_b v_i(b)x_{i,b}.\)

The equality is valid even for countably supported arrays: all summands are nonnegative, and the supply sums converge.

The bundlewise WMMS condition yields

\(\sum_bv_i(b)x_{i,b} \le\alpha M_i^\infty\mu_i \le\alpha w_iqn_i =\alpha qW_i.\)

Hence

\(\sum_e p_e\lambda_e\le\alpha qk.\)

We next calculate the left-hand side exactly.

For \(j=2\),

\(p_{A_2}=1/n_2,\qquad p_{B_2}=1/(2n_2),\)

so the combined contribution of \(H,A_2,B_2\), divided by \(q\), is

\(1+\frac{c_{A_2}}{n_2}+\frac12=2-\frac1\Delta.\)

For every \(j\ge3\),

\(p_{A_j}=2/n_j,\qquad p_{B_j}=1/n_j,\)

and the contribution of \(A_j,B_j\), divided by \(q\), is

\(\frac{2c_{A_j}}{n_j}+1 =\frac{n_j-3n_{j-1}}{n_j}+1 =2-\frac3\Delta.\)

Therefore

\(\frac1q\sum_e p_e\lambda_e =2-\frac1\Delta+(k-2)\left(2-\frac3\Delta\right) =2k-2-\frac{3k-5}{\Delta}.\)

Combining this with the allocation bound proves the necessary inequality

\(\alpha\ge 2-\frac2k-\frac{3k-5}{k\Delta}.\)

This certificate applies directly to real allocation masses and arbitrary integer bundles.

5. Excluding the requested factor

By our parameter choices,

\(2-\frac2k-\frac{3k-5}{k\Delta} \ge2-\frac2k-\frac3\Delta \ge2-\frac{\epsilon}{2}.\)

A \((2-\epsilon)\)-WMMS allocation would therefore imply

\(2-\epsilon\ge2-\epsilon/2,\)

a contradiction.

Thus every \(0<\epsilon<1\) admits a society with no \((2-\epsilon)\)-WMMS allocation. In particular, no fixed improvement below \(2\) works for all societies in the stated model.

6. Encoding and construction time

The construction has

\(m=2k-1=O(\epsilon^{-1}),\qquad \tau=k+1=O(\epsilon^{-1}).\)

Although the auxiliary counts are large, they are encoded in binary; no individual agents or chore copies are listed.

Each input rational has binary length \(O(ak)\). The cost table has \(O(k^2)\) entries, so the total input length satisfies

\(L=O(ak^3) =O\!\left(\epsilon^{-3}\log(1/\epsilon)\right).\)

For a rational approximation parameter \(\epsilon\), the society can be generated by elementary integer and rational arithmetic. A conservative construction bound, after selecting the parameters, is

\(O\bigl((m\tau+m+\tau)L^3\bigr)\)

bit operations. The proof's conceptual slot assignments need not be enumerated by this construction algorithm.
