Theorem 1 — class: other

The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), approval types \(T\subseteq 2^C\), rational population distribution \(\mu\in\Delta_{\mathbb Q}(T)\), margin \(\delta>0\), and conversion costs \(\gamma(A,B)\), choose \(W\in\binom{C}{k}\) and a transport plan \(y_{A,B}\ge 0\) with \(\sum_B y_{A,B}=\mu_A\), inducing \(\nu_B=\sum_A y_{A,B}\), to minimize \(\sum_{A,B}\gamma(A,B)y_{A,B}\) subject to \(\sum_{B:\,|B\cap W'|>|B\cap W|}\nu_B\le |W'|/k-\delta\) for every \(\varnothing\ne W'\subseteq C\) with \(|W'|\le k\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\) candidates and let \(1\le k<m\). A society is given by its support: a list \(T\subseteq 2^C\) of \(\tau\) approval types with positive binary rational masses \(\mu_A\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible approval sets; empty approval sets are allowed.
Conversions may send mass from any \(A\in T\) to any \(B\subseteq C\). The input explicitly lists all costs \(\gamma(A,B)\in\mathbb Q_{\ge0}\), with \(\gamma(A,A)=0\), and binary rational numbers \(\delta>0\) and \(b\ge0\). Let \(L\) be the total input bit length, including the cost table.
Choose a committee \(W\subseteq C\) with \(|W|=k\) and divisible transports \(y_{A,B}\in\mathbb R_{\ge0}\) satisfying \(\sum_{B\subseteq C}y_{A,B}=\mu_A\); write \(\nu_B=\sum_{A\in T}y_{A,B}\). Require
\(\sum_{B\subseteq C:\,|B\cap W'|>|B\cap W|}\nu_B\le |W'|/k-\delta\)
for every \(W'\subseteq C\) with \(1\le |W'|\le k\). Only strict approval-count improvements contribute; ties do not.
Decide whether such choices exist with \(\sum_{A\in T}\sum_{B\subseteq C}\gamma(A,B)y_{A,B}\le b\).

Is this decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L,k\).

Known results: For finite approval profiles, the worst-profile maximum of the minimum, over committees, of the maximum deviation support excess has an exact MILP reformulation; this also holds over rational vote distributions ([source](https://arxiv.org/html/2512.16895v1)). This equivalence supplies no complexity classification for the transport problem above; no classification of that exact problem was located in the literature search.

  • Made δ a binary rational input and retained the stated positive-margin inequalities without imposing an additional upper bound.
  • Used real nonnegative divisible transports and introduced a nonnegative binary rational budget b to state the decision version of the minimization problem.

1. Fixing the committee gives an exact linear program

Define
\(\mathcal D_k=\{W'\subseteq C:1\le |W'|\le k\}\)
and
\(D_k=|\mathcal D_k|=\sum_{j=1}^k\binom mj\).

Fix a committee \(W\subseteq C\) with \(|W|=k\). For each destination \(B\subseteq C\) and deviation \(W'\in\mathcal D_k\), compute the constant

\(a^W_{B,W'}=\begin{cases}1,&|B\cap W'|>|B\cap W|,\\0,&|B\cap W'|\le |B\cap W|.\end{cases}\)

Thus ties have coefficient zero, exactly as required.

Consider the following rational linear feasibility problem with \(N=\tau 2^m\) nonnegative variables \(y_{A,B}\):

  • For every \(A\in T\), impose \(\sum_{B\subseteq C}y_{A,B}=\mu_A\).
  • For every \(W'\in\mathcal D_k\), impose \(\sum_{A\in T}\sum_{B\subseteq C}a^W_{B,W'}y_{A,B}\le |W'|/k-\delta\).
  • Impose \(\sum_{A\in T}\sum_{B\subseteq C}\gamma(A,B)y_{A,B}\le b\).

This formulation is equivalent to the original requirements for this fixed \(W\). Indeed, defining \(\nu_B=\sum_{A\in T}y_{A,B}\) gives

\(\sum_{A\in T}\sum_{B\subseteq C}a^W_{B,W'}y_{A,B}=\sum_{B:\,|B\cap W'|>|B\cap W|}\nu_B.\)

Consequently, each deviation constraint has exactly the intended left-hand side. The conservation and budget constraints also coincide with the original ones. Empty approval sets require no special treatment: they are included among the destinations.

We use the standard theorem that feasibility of a linear program with explicitly encoded rational coefficients and nonnegative real variables is decidable in time polynomial in its binary encoding length. Its hypotheses hold here: all coefficients and right-hand sides are rational, all constraints are linear and non-strict, and every variable and constraint is explicitly listed. Divisibility of transports means that no integrality constraint is needed.

Enumerate all \(\binom mk\) committees of size \(k\), solve the corresponding linear programs, and accept precisely when at least one is feasible.

If the algorithm accepts, the feasible transport for the accepted committee satisfies every original constraint by the equivalence above. Conversely, any feasible solution of the original problem has a committee appearing in the enumeration, and its transport makes that committee’s linear program feasible. Hence the algorithm decides the problem exactly.

3. Encoding size and running time

Because the masses sum to one, \(T\) is nonempty. The explicitly listed cost table has \(N=\tau 2^m\) entries, each requiring at least one bit. Therefore

\(N\le L,\qquad 2^m\le L/\tau,\qquad \binom mk\le 2^m,\qquad D_k\le 2^m-1.\)

These inequalities use \(\tau\) as the actual support size.

For one fixed committee, the linear program has \(N\) variables and \(\tau+D_k+1\) constraints besides nonnegativity. A dense encoding has length at most

\(H=O\!\left(N(\tau+D_k+1)+(D_k+1)L\right).\)

To justify this bound, the conservation and deviation matrices contain only zero-one entries; the cost row and masses use at most their original input length; and each deviation right-hand side \(|W'|/k-\delta\) has bit length \(O(L)\). The latter follows by writing \(\delta=p/q\), giving right-hand side \((|W'|q-kp)/(kq)\).

Since \(N,\tau,D_k\le L\), we obtain \(H=O(L^2)\). Computing the comparison coefficients and assembling each program also takes polynomial time in these quantities.

Thus a running-time bound displaying all requested parameters is

\(O(L)+\binom mk\left(L+\tau 2^m+\sum_{j=1}^k\binom mj\right)^{O(1)}.\)

Using the explicit-table inequalities, this is \(L^{O(1)}\). The algorithm works for every permitted \(k\), arbitrary positive binary rational masses, and the stated arbitrary nonnegative rational costs.

The polynomial-time classification follows directly from this representation and the fixed-committee linear programs; it does not require the supplied worst-profile MILP equivalence.
