The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\), and a finite antichain \(\mathcal V\subseteq\prod_{t\in T}[0,\mu_t]\) defining a coalition profile \(q\) as losing exactly when \(q\le v\) for some \(v\in\mathcal V\), take two losing input coalitions encoded by \(\lambda_{t,\sigma}\), the mass of type \(t\) appearing in exactly \(\sigma\subseteq\{1,2\}\), with \(\sum_{\sigma}\lambda_{t,\sigma}=\mu_t\). Decide whether there are rational masses \(z_{t,\sigma,A}\ge0\), for \(A\subseteq\{1,2\}\) with \(|A|=|\sigma|\), satisfying \(\sum_{A:\,|A|=|\sigma|}z_{t,\sigma,A}=\lambda_{t,\sigma}\), such that the output profiles \(q^i_t=\sum_{\sigma,A:\,i\in A}z_{t,\sigma,A}\) are both winning.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The rule is given explicitly by a nonempty coordinatewise antichain \(\mathcal V\subseteq\prod_{t\in T}[0,\mu_t]\) of rational vectors, with \(\mu\notin\mathcal V\). A coalition profile \(q\) is losing exactly when \(q\le v\) coordinatewise for some \(v\in\mathcal V\); otherwise it is winning. Thus the zero profile loses and the full profile wins.
The input includes nonnegative binary-rational masses \(\lambda_{t,\sigma}\), for \(\sigma\subseteq\{1,2\}\), satisfying \(\sum_\sigma\lambda_{t,\sigma}=\mu_t\). These describe individuals belonging to exactly the input coalitions indexed by \(\sigma\); both profiles \(s^i_t=\sum_{\sigma:i\in\sigma}\lambda_{t,\sigma}\) are promised losing.
An exchange assigns rational masses \(z_{t,\sigma,A}\ge0\) to \(A\subseteq\{1,2\}\) with \(|A|=|\sigma|\), subject to \(\sum_{A:|A|=|\sigma|}z_{t,\sigma,A}=\lambda_{t,\sigma}\). Its outputs are \(q^i_t=\sum_{\sigma,A:i\in A}z_{t,\sigma,A}\); each individual's number of coalition memberships is preserved.
Let \(m=|\mathcal V|\) and let \(L\) be the total input bit length. State running times in \(m,\tau,L\).

Is deciding whether such an exchange makes both output profiles winning in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite indivisible players, this decision problem with an explicit list of maximal losing coalitions is \(\mathrm{NP}\)-complete and is fixed-parameter tractable in the list size. [Source](https://arxiv.org/pdf/1503.06052).
No result settling this exact continuous formulation was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total mass to one to make the society a distribution over its positive-mass support.
  • Required the antichain to be nonempty and to exclude the full mass vector, carrying over the simple-game requirements that the empty coalition loses and the full coalition wins.
  • Required all antichain coordinates and input membership masses to be binary rationals, with membership masses nonnegative.
  • Defined m as the antichain size because this problem has no candidate count, and L as the total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete, matching the classification of the [indivisible-player problem](https://arxiv.org/pdf/1503.06052).

Hardness holds even when all type masses are equal and dyadic, both input profiles equal \(\mu/2\), and every coordinate of every listed losing vector is either \(\mu_t/2\) or \(\mu_t\).

There is also a deterministic algorithm with bit running time \(O(\tau m^2 4^m L^2)\). Thus the continuous problem is fixed-parameter tractable in \(m\).

1. Profiles reachable by an exchange

For each type \(t\), define

\[ a_t=\lambda_{t,\{1,2\}},\qquad b_t=\lambda_{t,\{1\}}+\lambda_{t,\{2\}}. \]

Individuals with zero or two memberships have only one permitted destination. Individuals with one membership can be divided between the two outputs. Consequently, the reachable output pairs are exactly

\[ q^1_t=a_t+x_t,\qquad q^2_t=a_t+b_t-x_t, \qquad 0\le x_t\le b_t, \]

with rational \(x_t\).

To verify the converse explicitly, put \(r_t=\lambda_{t,\{1\}}\). Allocate to output \(1\) masses

\[ z_{t,\{1\},\{1\}}=\min(x_t,r_t),\qquad z_{t,\{2\},\{1\}}=\max(0,x_t-r_t). \]

Allocate the remaining mass of each singleton-membership class to output \(2\). These allocations are nonnegative: the second displayed mass is at most \(\lambda_{t,\{2\}}\) because \(x_t\le b_t\). Their sum is \(x_t\), so they produce the claimed profiles.

For a listed vector \(v\), the two outputs avoid its losing box precisely when

\[ \exists t:\ x_t>v_t-a_t, \qquad \exists t:\ x_t<a_t+b_t-v_t. \]

Both outputs win exactly when these two conditions hold for every \(v\in\mathcal V\).

2. A polynomial reduction from satisfiability

We use the standard NP-completeness of satisfiability for conjunctive normal form formulas with three literals per clause. Restricting to formulas with at least one variable and one clause preserves NP-completeness.

Let \(\varphi\) have variables \(X_1,\ldots,X_n\) and clauses \(C_1,\ldots,C_k\).

2.1. Encoding satisfiability by splitting sets

Introduce a distinct symbol for each positive and negative literal, together with an additional symbol \(f\). Let

\[ U=\{X_j,\neg X_j:1\le j\le n\}\cup\{f\}. \]

Form the family \(\mathcal H\) consisting of:

  • the pairs \(\{X_j,\neg X_j\}\), for every variable;
  • the sets \(\{f\}\cup\operatorname{Lit}(C_i)\), for every clause.

A two-coloring *splits* a set if the set contains both colors.

Claim. The formula \(\varphi\) is satisfiable if and only if some two-coloring splits every member of \(\mathcal H\).

Proof. Given a satisfying assignment, color \(f\) blue, true literals red, and false literals blue. Every variable pair contains one true and one false literal. Every clause set contains blue \(f\) and at least one red literal. Thus every set is split.

Conversely, suppose every set is split. Name the color of \(f\) blue and the other color red. Each variable pair is split, so its two literal symbols have opposite colors. Declare \(X_j\) true exactly when its positive literal symbol is red. A clause set contains blue \(f\); being split, it must contain a red literal. That literal is true under the assignment. Hence every clause is satisfied. \(\square\)

Remove duplicate sets and retain only the inclusion-minimal members, obtaining \(\mathcal E\).

This operation preserves splittability. Indeed, every original set contains an inclusion-minimal member of \(\mathcal H\): repeatedly choose a proper subset belonging to \(\mathcal H\), until none remains. A coloring that splits that minimal member also splits the original set. The reverse implication is immediate.

The family \(\mathcal E\) is nonempty, is an inclusion antichain, and has at most \(n+k\) members. Every member has between two and four elements. It can be computed in polynomial time.

2.2. Constructing the society

Let \(N\) be the smallest power of two satisfying \(N\ge 2n+1\). Use \(N\) types: the symbols in \(U\), together with additional dummy types if necessary. Set

\[ \tau=N,\qquad h=\frac1N,\qquad \mu_t=h \]

for every type. All masses are positive dyadic rationals, and their sum is \(1\).

For every \(E\in\mathcal E\), introduce the vector \(v^E\) defined by

\[ v^E_t= \begin{cases} h/2,&t\in E,\\ h,&t\notin E. \end{cases} \]

Let \(\mathcal V=\{v^E:E\in\mathcal E\}\).

Every vector belongs to the required coordinate box. Since \(E\) is nonempty, \(v^E\ne\mu\).

The vectors form a coordinatewise antichain. For distinct \(E,F\in\mathcal E\), incomparability of the sets provides elements \(u\in E\setminus F\) and \(w\in F\setminus E\). At these coordinates,

\[ v^E_u<h=v^F_u,\qquad v^F_w<h=v^E_w. \]

Thus neither vector dominates the other.

Finally, prescribe

\[ \lambda_{t,\{1\}}=\lambda_{t,\{2\}}=h/2,\qquad \lambda_{t,\varnothing}=\lambda_{t,\{1,2\}}=0. \]

Both input profiles equal \(h/2\) in every coordinate. They are losing because they lie below every vector in \(\mathcal V\). Hence all input promises are satisfied.

2.3. Correctness of the reduction

By Section 1, every reachable pair has the form

\[ q^1_t=x_t,\qquad q^2_t=h-x_t,\qquad 0\le x_t\le h. \]

Fix \(E\in\mathcal E\). Outside \(E\), the losing threshold is \(h\), which neither output can exceed. Therefore,

\[ q^1\not\le v^E \quad\Longleftrightarrow\quad \exists t\in E:\ x_t>h/2, \]

and

\[ q^2\not\le v^E \quad\Longleftrightarrow\quad \exists t\in E:\ x_t<h/2. \]

Suppose both outputs win. Color a symbol red when \(x_t>h/2\), and blue otherwise. Every \(E\) contains a red symbol by the first equivalence and a blue symbol by the second. Thus every member of \(\mathcal E\), and therefore every member of \(\mathcal H\), is split. Section 2.1 gives a satisfying assignment.

Conversely, suppose \(\varphi\) is satisfiable. Take the resulting splitting coloring and set \(x_t=h\) on red symbols and \(x_t=0\) on blue symbols. Set \(x_t=0\) on dummy types. Every \(E\) contains both colors, so both displayed strict inequalities have witnesses. Both outputs therefore win. These rational allocations are realizable by Section 1.

This proves equivalence between satisfiability and the existence of a successful exchange.

The construction has

\[ m\le n+k,\qquad \tau=N<2(2n+1), \]

and all numerical entries require \(O(\log(n+2))\) bits. Its total output length is \(O((n+k)(n+1)\log(n+2))\), and the construction runs in polynomial time. The continuous problem is therefore NP-hard.

3. Membership in \(\mathrm{NP}\)

Strict inequalities require justification that successful rational exchanges have certificates of polynomial length. We obtain this through a finite discretization.

For each coordinate \(t\), define the thresholds

\[ \alpha_{v,t}=v_t-a_t,\qquad \beta_{v,t}=a_t+b_t-v_t \]

for \(v\in\mathcal V\).

Let \(B_t\) contain \(0\), \(b_t\), and every distinct threshold lying in \([0,b_t]\). Sort its distinct elements. Let \(D_t\) consist of those elements and the midpoint between each consecutive pair.

There are at most \(2m+2\) distinct elements of \(B_t\), hence

\[ |D_t|\le 4m+3. \]

Discretization claim. For every \(x_t\in[0,b_t]\), some \(d_t\in D_t\) preserves all comparisons

\[ x_t>\alpha_{v,t},\qquad x_t<\beta_{v,t}. \]

Proof. If \(x_t\in B_t\), choose \(d_t=x_t\). Otherwise, \(x_t\) lies strictly between consecutive elements of \(B_t\); choose their midpoint. No threshold lies inside that interval, so all comparisons with thresholds have the same truth values throughout it. Thresholds outside \([0,b_t]\) also give constant comparisons there. This includes the degenerate case \(b_t=0\), when \(D_t=\{0\}\). \(\square\)

Applying the claim independently to every coordinate preserves every winning witness. Thus a successful exchange exists if and only if one exists with \(x_t\in D_t\) for every type.

Every candidate has \(O(L)\) bits: its construction uses only a constant number of rational additions, subtractions, and a division by two on input numbers. A certificate can specify one candidate index per coordinate, using \(O(\tau\log(m+1))\) bits. The verifier constructs the selected candidates and checks both winning conditions against every listed vector, all in polynomial time.

Therefore the problem belongs to \(\mathrm{NP}\).

4. An algorithm parameterized by the list size

The same discretization gives an explicit algorithm.

Let the requirement universe be

\[ R=\{(i,v):i\in\{1,2\},\ v\in\mathcal V\}. \]

It has \(2m\) elements. For \(d\in D_t\), define the requirements witnessed by that coordinate:

\[ M_t(d)= \{(1,v):d>\alpha_{v,t}\} \cup \{(2,v):d<\beta_{v,t}\}. \]

Process the types one at a time. Maintain the collection of requirement subsets attainable by choosing one candidate at each processed coordinate. Initialize with \(\{\varnothing\}\). At type \(t\), replace the collection by all sets

\[ S\cup M_t(d) \]

where \(S\) was previously attainable and \(d\in D_t\).

Inductively, this records exactly the requirements witnessed by some candidate selection on the processed types. After the final type, accept precisely when \(R\) is attainable. By Section 3, this is equivalent to a successful exchange.

There are \(2^{2m}=4^m\) possible requirement subsets and \(O(m)\) candidates per type. Using bit masks, each transition costs \(O(m)\) bit operations. Candidate construction and mask computation take \(O(\tau m^2L^2)\) bit operations with elementary rational arithmetic. A valid overall bound is therefore

\[ O(\tau m^2 4^m L^2). \]

This completes the classification and establishes fixed-parameter tractability in \(m\).
