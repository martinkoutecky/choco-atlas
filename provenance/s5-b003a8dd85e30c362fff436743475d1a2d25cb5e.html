The continuous mirror question, as graded

Given a matroid \(M=(E,\mathcal I)\), a supplied Hamiltonian cyclic ordering, and query access to a common monotone valuation \(v\), with \(\chi(M)\le 2\), find independent cyclic intervals \(A,B\) partitioning \(E\) such that \(\bigl||A|-|B|\bigr|\le 1\) and the two bundles satisfy EF1 for \(v\). Interpret the output as assigning mass \(1/2\) to bundle \(A\) and mass \(1/2\) to bundle \(B\).

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size. Here \(\tau=1\): the sole type has mass \(1\) and a common monotone valuation \(v:2^E\to\mathbb Q_{\ge0}\), accessed through an exact value oracle; no normalization of \(v(\varnothing)\) is imposed.
Given a matroid \(M=(E,\mathcal I)\) through an independence oracle, let \(m=|E|\). Promise that \(\chi(M)\le2\), where \(\chi(M)\) is the minimum number of independent sets partitioning \(E\), and supply a cyclic ordering in which every block of \(r(M)\) consecutive elements is a basis.
Find cyclic intervals \(A,B\in\mathcal I\) partitioning \(E\), with \(\bigl||A|-|B|\bigr|\le1\), satisfying EF1 for the common monotone valuation. Let \(L\) include the explicit input bit length and a bound on the bit length of each oracle value. State oracle counts and bit-operation running times in \(m,\tau,L\).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result and EF1 convention

The problem is polynomial-time solvable. In fact, for the common monotone valuation, an explicit algorithm uses \(O(\log(m+1))\) value-oracle queries and no independence-oracle queries.

For bundles \(X,Y\), the EF1 comparison from \(X\) toward \(Y\) means that either \(Y=\varnothing\), or there exists \(g\in Y\) such that \(v(X)\ge v(Y\setminus\{g\})\). Both directed comparisons must hold.

If \(v(X)\ge v(Y)\), monotonicity makes this comparison automatic: deleting any element from a nonempty \(Y\) cannot increase its value. No assumption on \(v(\varnothing)\) is needed.

We give a complete construction, independently of the stated known result.

2. Independence follows from the promises

Write \(r=r(M)\). Since \(\chi(M)\le2\), there is a partition of \(E\) into two independent sets. Each has cardinality at most \(r\), so \(m\le2r\), and therefore \(\lceil m/2\rceil\le r\).

Every cyclic interval of length at most \(r\) is independent: extend it along the supplied cyclic ordering to a block of exactly \(r\) elements. That block is a basis by hypothesis, and every subset of a basis is independent.

Consequently, every balanced partition into cyclic intervals consists of independent sets. The algorithm may rely on these promises without querying the independence oracle.

For \(m=0\) or \(m=1\), output \(\varnothing,E\). This partition is balanced and independent. Its EF1 comparisons follow immediately from the empty-bundle convention and, when \(m=1\), deletion of the sole element. Henceforth assume \(m\ge2\).

3. A short sequence exchanging the bundles

Let the supplied cyclic ordering be \(e_0,\ldots,e_{m-1}\). We construct partitions \((A_t,B_t)\), with \(B_t=E\setminus A_t\), whose endpoints exchange the two bundles.

If \(m=2k\), set \(N=k\) and, for \(0\le t\le k\), define
\(A_t=\{e_t,\ldots,e_{t+k-1}\}\).

Both bundles have size \(k\), and \((A_N,B_N)=(B_0,A_0)\). Consecutive partitions exchange two elements: \(e_t\) leaves \(A_t\), while \(e_{t+k}\) enters it.

If \(m=2k+1\), set \(N=m\). For \(0\le t\le m\), write \(t=2j+\varepsilon\), where \(\varepsilon\in\{0,1\}\), and define
\(A_t=\{e_j,\ldots,e_{j+k+\varepsilon-1}\}\).

The bundle sizes are \(k\) and \(k+1\). At the endpoint,
\(A_m=\{e_k,\ldots,e_{2k}\}=B_0\), so again \((A_N,B_N)=(B_0,A_0)\).

Here consecutive partitions transfer one element:

  • From \(t=2j\) to \(t+1\), element \(e_{j+k}\) moves from \(B_t\) to \(A_t\).
  • From \(t=2j+1\) to \(t+1\), element \(e_j\) moves from \(A_t\) to \(B_t\).

Every bundle in both sequences is a cyclic interval, and every partition is balanced. Section 2 therefore proves independence throughout.

4. Finding an adjacent reversal

Query \(v(A_0)\) and \(v(B_0)\). If they are equal, output this partition: it is envy-free.

Otherwise, label the sequence’s bundles \(X_t,Y_t\), swapping the names \(A_t,B_t\) throughout if necessary, so that \(v(X_0)<v(Y_0)\). The endpoint exchange gives \(v(X_N)>v(Y_N)\). Its values are already known from the initial queries.

Maintain indices \(\ell<h\) satisfying
\(v(X_\ell)<v(Y_\ell)\) and \(v(X_h)>v(Y_h)\).

While \(h-\ell>1\), query both bundle values at \(t=\lfloor(\ell+h)/2\rfloor\).

  • If the values are equal, output that envy-free partition.
  • If \(v(X_t)<v(Y_t)\), replace \(\ell\) by \(t\).
  • Otherwise, replace \(h\) by \(t\).

Each update preserves the two strict inequalities and reduces the index distance to at most its previous distance rounded up after division by two. Thus the search terminates with \(h=\ell+1\).

This search requires no monotonicity of the sequence of value comparisons. Only the maintained endpoint inequalities matter.

5. An adjacent reversal yields EF1

Suppose the search reaches consecutive partitions satisfying
\(v(X_\ell)<v(Y_\ell)\) and \(v(X_h)>v(Y_h)\).

We prove that one of them is EF1 and specify how to select it.

Even case: an exchange.

There are disjoint sets \(C,D\) and distinct elements \(x,y\) such that
\(X_\ell=C\cup\{x\}\), \(Y_\ell=D\cup\{y\}\),
\(X_h=C\cup\{y\}\), and \(Y_h=D\cup\{x\}\).

Query \(v(D)\), and put \(a=v(X_\ell)\).

If \(a\ge v(D)\), output the partition at \(\ell\). Deleting \(y\) from \(Y_\ell\) leaves \(D\), so the comparison from \(X_\ell\) is EF1. The other comparison is automatic because \(v(Y_\ell)>v(X_\ell)\).

If \(a<v(D)\), monotonicity gives
\(v(Y_h)\ge v(D)>a=v(X_\ell)\ge v(C)\).

Deleting \(y\) from \(X_h\) leaves \(C\). Thus the comparison from \(Y_h\) toward \(X_h\) is EF1. The other comparison is automatic because \(v(X_h)>v(Y_h)\). Output the partition at \(h\).

Odd case: a transfer.

The transfer must move an element from \(Y_\ell\) to \(X_\ell\). Indeed, a transfer in the opposite direction would imply, by monotonicity,
\(v(X_h)\le v(X_\ell)<v(Y_\ell)\le v(Y_h)\),
contradicting the endpoint inequality at \(h\).

Hence, for some \(y\in Y_\ell\),
\(X_h=X_\ell\cup\{y\}\) and \(Y_h=Y_\ell\setminus\{y\}\).

Put \(a=v(X_\ell)\) and \(d=v(Y_h)\); both values are already known.

If \(a\ge d\), output the partition at \(\ell\). Removing \(y\) from \(Y_\ell\) establishes its potentially envious comparison, and the reverse comparison is automatic.

If \(a<d\), output the partition at \(h\). Removing \(y\) from \(X_h\) leaves \(X_\ell\), whose value \(a\) is smaller than \(v(Y_h)=d\). The reverse comparison is automatic.

This completes the EF1 proof in all cases. Every invocation of a valuation property used only monotonicity, so arbitrary \(v(\varnothing)\) is covered.

6. Oracle counts, bit complexity, and mass assignment

For \(m\ge2\), the construction uses:

  • Two initial value queries.
  • At most \(2\lceil\log_2 N\rceil\) value queries during the search.
  • At most one additional value query in the even case.

Since \(N\le m\), a uniform bound is
\(2\lceil\log_2(m+1)\rceil+3\) value-oracle queries. There are zero independence-oracle queries. For \(m\le1\), no oracle queries are needed.

For a concrete bit-operation bound, use standard explicitly indexed subset encodings. Constructing a query takes \(O(m\log(m+1))\) bit operations. Comparing two binary rationals of bit length at most \(L\) takes \(O(L^2)\) bit operations by cross multiplication with schoolbook integer arithmetic.

Including input processing and output, a conservative bound for \(m\ge2\), excluding the oracle’s internal evaluation cost, is
\(O\!\left(L+\bigl(m\log(m+1)+L^2\bigr)\log(m+1)\right)\).
The cases \(m\le1\) take \(O(L)\) bit operations.

Finally, assign mass \(1/2\) of the sole type to each output bundle. These masses have constant-size binary rational encodings, and every good belongs wholly to one bundle. Under the specified mass interpretation, the required EF1 comparisons are exactly those proved above.

Thus, with \(\tau=1\), the search problem has polynomial bit complexity in \(m,\tau,L\) and polynomially many oracle queries.
