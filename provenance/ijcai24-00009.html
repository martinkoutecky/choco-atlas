The continuous mirror question, as graded

Given a finite type set \(T=B\mathbin{\dot\cup}P\), compatibility relation \(A_T\subseteq T\times P\), rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), caps \(\ell_p,\ell_c\), and rational target \(\beta\), decide whether feasible type-level paths and cycles admit nonnegative route masses \(x_R\) satisfying \(\sum_R a_{R,t}x_R\le\mu_t\) for every \(t\in T\) and \(\sum_R p_Rx_R\ge\beta\), where \(a_{R,t}\) counts type occurrences and \(p_R\) counts patients covered.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(T=B\mathbin{\dot\cup}P\), consisting of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Types in \(B\) represent altruistic donors; types in \(P\) represent patient–donor pairs. Compatibility depends only on types.
The input includes a loopless relation \(A_T\subseteq T\times P\), binary-encoded nonnegative integer caps \(\ell_p,\ell_c\), and a binary-rational threshold \(\beta\). Thus altruistic types have no incoming arcs, and donors cannot donate within their own type.
A path route is a type sequence \((b,t_1,\ldots,t_k)\), with \(b\in B\), \(t_i\in P\), \(1\le k\le\ell_p\), and every consecutive pair in \(A_T\). A cycle route is a cyclic sequence \((t_1,\ldots,t_k)\) in \(P\), with \(2\le k\le\ell_c\), and every consecutive pair, including \((t_k,t_1)\), in \(A_T\). Types may repeat in either route.
For a route \(R\), let \(a_{R,t}\) count occurrences of type \(t\), counting each cycle position once, and let \(p_R=\sum_{t\in P}a_{R,t}\). Decide whether nonnegative real route masses \(x_R\) satisfy \(\sum_R a_{R,t}x_R\le\mu_t\) for every \(t\in T\) and \(\sum_R p_Rx_R\ge\beta\).
Let \(m=|A_T|\) and let \(L\) be the total input bit length. The support size \(\tau\) counts listed positive-mass types, not all possible types; express running times in \(m,\tau,L,\ell_p,\ell_c\), respecting the binary encoding of the caps.

Is this continuous decision problem in \(\mathrm{P}\) or \(\mathrm{NP}\)-hard? If it is \(\mathrm{NP}\)-hard, is it nevertheless FPT parameterized by \(\tau\), with running time \(f(\tau)\operatorname{poly}(m,L)\)?

Result

The problem is in \(\mathrm{P}\), including when both caps are binary encoded. Consequently, it is also FPT parameterized by \(\tau\).

The proof uses the permitted repetition of types: dual route constraints become weighted-walk constraints, which admit a polynomial-size linear programming formulation using repeated squaring.

Define
\(H=1+\lceil\log_2(\ell_p+2)\rceil+\lceil\log_2(\ell_c+2)\rceil\).
An exact decision algorithm has running time
\((m+\tau^3H+L)^{O(1)}\).
In particular, its dependence on the numerical caps is logarithmic.

1. The route linear program and its dual

Let \(\mathcal R\) be the set of allowed routes. This set is finite because both caps are finite, even though it can be extremely large.

Consider the primal linear program
\[ \operatorname{OPT}= \max\left\{ \sum_{R\in\mathcal R}p_Rx_R: \sum_{R\in\mathcal R}a_{R,t}x_R\le\mu_t\ \text{for every }t\in T,\quad x_R\ge0 \right\}. \]

It is feasible by taking all route masses zero. Summing its patient capacity constraints gives
\(\sum_R p_Rx_R\le\sum_{t\in P}\mu_t\le1\).
Moreover, every route has \(p_R\ge1\), so each variable is bounded. Thus the feasible region is compact and the maximum is attained. If there are no routes, the optimum is zero.

Its dual is
\[ \min\left\{ \sum_{t\in T}\mu_ty_t: y_t\ge0\ \text{for every }t\in T,\quad \sum_{t\in T}a_{R,t}y_t\ge p_R\ \text{for every }R\in\mathcal R \right\}. \]

The dual is feasible: take \(y_t=1\) for patients and \(y_t=0\) for altruists. Finite-dimensional LP strong duality therefore applies, and its attained minimum equals \(\operatorname{OPT}\).

The original decision problem asks whether \(\operatorname{OPT}\ge\beta\). We will replace the dual’s route constraints by an explicit polynomial-size extended formulation.

2. Expressing dual feasibility through weighted walks

Fix \(y\ge0\), and give every original arc \((u,v)\in A_T\) weight \(1-y_v\). Its target \(v\) is always a patient.

For an original walk \(W=(v_0,\ldots,v_k)\), define its weight as
\(w_y(W)=\sum_{i=1}^{k}(1-y_{v_i})\).
A zero-length walk has weight zero.

For each nonnegative integer \(N\), let \(F_N(y)_{ij}\) be the maximum weight of an original walk from \(i\) to \(j\) using at most \(N\) arcs. If there is no such walk, the entry is \(-\infty\). Whenever there is at least one walk, the maximum exists because there are finitely many walks of bounded length.

Path constraints. Every original walk from an altruist \(b\) to a patient, using at most \(\ell_p\) arcs, is an allowed path route. Indeed, its length is positive, and no altruistic type can occur after its first position because altruists have no incoming arcs.

For such a route,
\(w_y(R)=p_R-\sum_{t\in P}a_{R,t}y_t\).
Its initial altruistic type occurs exactly once. Hence its dual constraint is equivalent to \(w_y(R)\le y_b\).

Thus all path constraints are equivalent to
\(F_{\ell_p}(y)_{bt}\le y_b\)
for every \(b\in B\) and \(t\in P\) for which this entry is finite.

Cycle constraints. An original closed walk
\((v_0,\ldots,v_k)\), with \(v_k=v_0\in P\), has
\[ w_y(W)=\sum_{i=1}^{k}(1-y_{v_i}) =\sum_{i=0}^{k-1}(1-y_{v_i}). \]
The equality holds because the terminal position repeats the initial position. Therefore this weight counts exactly the cycle positions once, with all type multiplicities preserved.

No nonempty closed walk can visit an altruist. Since the relation is loopless, every nonempty closed walk has length at least two. Consequently, nonempty closed walks of length at most \(\ell_c\) are exactly the allowed cycle routes, up to the irrelevant choice of starting position.

Their dual constraints require weight at most zero. Including the zero-length walk, whose weight is zero, does not change this condition. Hence all cycle constraints are equivalent to
\(F_{\ell_c}(y)_{tt}\le0\) for every \(t\in P\).

This also handles \(\ell_c=0\) and \(\ell_c=1\), when no cycle route exists.

3. Computing bounded-walk weights by repeated squaring

For matrices with entries in \(\mathbb R\cup\{-\infty\}\), define the max-plus product by
\[ (U\otimes V)_{ij}=\max_{h\in T}(U_{ih}+V_{hj}), \]
with the convention that \(-\infty+a=-\infty\).

For all nonnegative integers \(r,s\),
\(F_{r+s}(y)=F_r(y)\otimes F_s(y)\).

To prove this identity, concatenating walks of lengths at most \(r\) and \(s\) gives a walk of length at most \(r+s\), and its weight is the sum of their weights. This proves one inequality. Conversely, a walk of length \(k\le r+s\) can be split after \(\min\{r,k\}\) arcs. Its first part has length at most \(r\), and its second part has length at most \(s\). This proves the reverse inequality.

The matrix \(F_0(y)\) has diagonal entries zero and all other entries \(-\infty\). The matrix \(F_1(y)\) has:

  • diagonal entries zero;
  • entry \(1-y_j\) for each arc \((i,j)\in A_T\);
  • entry \(-\infty\) elsewhere.

The diagonal description uses the loopless hypothesis.

Binary exponentiation therefore computes both \(F_{\ell_p}(y)\) and \(F_{\ell_c}(y)\) from \(F_0(y)\) and \(F_1(y)\), using \(O(H)\) max-plus matrix products. This avoids iterating through the numerical caps.

4. Converting the computation into an explicit LP

Choose such an acyclic computation circuit. Its initial nodes represent \(F_0\) and \(F_1\), and each subsequent node is the product of two preceding nodes. Let the two output nodes be \(g_p\) and \(g_c\).

For every circuit node \(g\), define its support \(S_g\subseteq T\times T\) to be the pairs whose matrix entries are finite. These supports depend only on the graph and the circuit, not on \(y\).

At the initial nodes, the supports are respectively the diagonal and the diagonal together with \(A_T\). At a product node \(g=h\otimes q\), compute
\[ S_g=\{(i,j):\text{there exists }u\in T \text{ with }(i,u)\in S_h,\ (u,j)\in S_q\}. \]
These are Boolean matrix products, so all supports can be constructed without enumerating routes.

Introduce a real variable \(z_{g,ij}\) for every supported entry. These auxiliary variables are unrestricted in sign. Impose the following linear inequalities.

Initial node for \(F_0\):
\(z_{0,ii}\ge0\) for every \(i\in T\).

Initial node for \(F_1\):
\(z_{1,ii}\ge0\) for every \(i\in T\), and
\(z_{1,ij}\ge1-y_j\) for every \((i,j)\in A_T\).

Each product node \(g=h\otimes q\):
\[ z_{g,ij}\ge z_{h,iu}+z_{q,uj} \]
for every triple \((i,u,j)\) satisfying
\((i,u)\in S_h\) and \((u,j)\in S_q\).

Output constraints:
\(z_{g_p,bt}\le y_b\) for every supported pair with \(b\in B,t\in P\), and
\(z_{g_c,tt}\le0\) for every \(t\in P\).

Finally impose \(y_t\ge0\) and minimize \(\sum_t\mu_ty_t\).

5. Proof that the extended formulation is exact

We prove that the projection of this LP’s feasible region onto the \(y\)-coordinates is exactly the original dual feasible region.

Every feasible extended solution gives a dual-feasible \(y\). At each initial node, its inequalities imply that \(z\) is at least the corresponding true matrix entry.

Inductively, suppose this holds for the two inputs of a product node. Every defining inequality then gives
\[ z_{g,ij}\ge z_{h,iu}+z_{q,uj} \ge F_{a_h}(y)_{iu}+F_{a_q}(y)_{uj}, \]
where \(a_h,a_q\) are the walk-length bounds represented by those nodes. Taking the maximum over all supported intermediate types \(u\) shows that \(z_{g,ij}\) is at least the true product entry.

Thus the output inequalities imply
\(F_{\ell_p}(y)_{bt}\le y_b\) and
\(F_{\ell_c}(y)_{tt}\le0\).
By Section 2, all original route constraints hold.

Every dual-feasible \(y\) extends to a feasible solution. Assign every auxiliary variable its true matrix entry at its circuit node. All initial constraints hold. Each product constraint holds because the true output entry is the maximum of the candidate sums. Finally, dual feasibility gives the output constraints by Section 2.

The projection is therefore exact. Since the objective involves only \(y\), the extended LP has optimum exactly \(\operatorname{OPT}\).

6. Bit complexity and parameterized running time

There are \(O(H)\) circuit nodes and at most \(\tau^2\) supported entries per node. The extended LP consequently has:

  • \(O(\tau+\tau^2H)\) variables;
  • \(O(m+\tau+\tau^3H)\) constraints.

Every constraint has at most three variable occurrences. Its integer coefficients have absolute value at most two; the value two can arise when a squaring constraint uses the same input variable twice. Right-hand sides are zero or one. The objective coefficients are the given binary-rational masses.

Hence the explicit LP’s encoding length is polynomial in \(m+\tau^3H+L\). In particular, no coefficient requires writing a route or a number of bits proportional to a numerical cap.

We use the standard rational-LP theorem: an explicitly encoded rational linear program can be solved exactly in time polynomial in its encoding length. Polynomial-time linear programming originates with [Khachiyan’s theorem](https://www.mathnet.ru/eng/dan42319). Here the required hypotheses hold: the constructed LP is rational and explicitly given, is feasible, and has an attained finite optimum by its exact projection onto the dual.

Solve it and compare its exact optimum with the rational threshold \(\beta\). This yields the claimed running time
\((m+\tau^3H+L)^{O(1)}\).

Because the caps are binary encoded, \(H=O(L+1)\). Thus this is polynomial in the actual input size. It also has the form \(f(\tau)\operatorname{poly}(m,L)\), with \(f\) polynomial.

Conclusion

The stated continuous problem is polynomial-time solvable. In particular, it is FPT parameterized by the number of listed positive-mass types. It can be NP-hard under polynomial-time reductions only if \(\mathrm{P}=\mathrm{NP}\).

The argument applies to the specified model allowing repeated types in routes. That permission is what makes the weighted-walk computation represent every route constraint exactly.
