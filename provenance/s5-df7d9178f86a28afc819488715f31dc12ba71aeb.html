The continuous mirror question, as graded

Given \(m\) alternatives, a subset size \(r\) with \(2 \le r < m\), and a rational distribution \(\mu\) over \(\tau\) complete rankings, split each ranking type's mass equally among its \(\binom{m}{r}\) subsets. Each mass block ranks its assigned subset by restriction of the complete ranking and gives an alternative in position \(q\) score \(r-q\). Which alternatives maximize the resulting weighted score?

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\) alternatives, and let \(r\) be an integer with \(2\le r<m\).
A society is given by its support: \(\tau\) distinct strict complete rankings \(\pi_i\), each with positive binary rational mass \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
For each ranking \(\pi_i\) and each subset \(S\subseteq A\) of size \(r\), assign mass \(\mu_i/\binom{m}{r}\) to the restriction \(\pi_i|_S\). An alternative in position \(q\) receives score \(r-q\); alternatives outside \(S\) receive zero. Sum scores weighted by these masses, retaining all tied maximizers.

Is computing all maximizing alternatives solvable in polynomial time in \(m,\tau,r,L\), or is it NP-hard?

Known results: For finite electorates with strict complete rankings preserved under restriction, random-subset Borda scores converge almost surely to a positive multiple of average Borda scores whenever ranking frequencies converge, preserving strict score comparisons. An exact expected-score equivalence to Borda is also established for arbitrary ranking frequencies; the deterministic mass splitting above computes those same expectations. [Source](https://www.jasss.org/21/1/10.html)

  • Assign zero score to alternatives absent from an assigned subset, as specified by the discrete definition.
  • Return every tied maximizer because no tie-breaking convention is specified.
  • Define L as the total binary input length.

Computing all maximizing alternatives is polynomial-time solvable in \(m,\tau,r,L\). In fact, their set is exactly the set of weighted Borda maximizers, independently of \(r\) within the stated range. This preserves ties exactly.

Exact score identity

Let \(p_i(a)\in\{1,\ldots,m\}\) denote the position of alternative \(a\) in ranking \(\pi_i\), and define its weighted Borda score by

\(B(a)=\sum_{i=1}^{\tau}\mu_i\bigl(m-p_i(a)\bigr).\)

For a subset \(S\) of size \(r\), let \(s_i(a,S)\) be the score assigned to \(a\) by \(\pi_i|_S\), including zero when \(a\notin S\). The score specified in the question is therefore

\(F_r(a)=\dfrac{1}{\binom{m}{r}}\sum_{i=1}^{\tau}\mu_i\sum_{\substack{S\subseteq A\\|S|=r}}s_i(a,S).\)

Fix \(i\) and \(a\). Because restriction preserves the strict ranking, when \(a\in S\), its score is the number of alternatives in \(S\) ranked below it. Thus, writing \(\mathbf 1\) for an indicator,

\(s_i(a,S)=\sum_{\substack{b\in A\\p_i(b)>p_i(a)}}\mathbf 1_{\{\{a,b\}\subseteq S\}}.\)

This also holds when \(a\notin S\), since every indicator is then zero.

For each fixed alternative \(b\) below \(a\), exactly \(\binom{m-2}{r-2}\) subsets of size \(r\) contain both \(a\) and \(b\): their remaining \(r-2\) members can be chosen freely from the other \(m-2\) alternatives. There are \(m-p_i(a)\) choices of \(b\) below \(a\). Interchanging these finite sums consequently gives

\(\displaystyle \sum_{\substack{S\subseteq A\\|S|=r}}s_i(a,S)=\bigl(m-p_i(a)\bigr)\binom{m-2}{r-2}.\)

Substituting this expression into \(F_r(a)\), we obtain

\(\displaystyle F_r(a)=\frac{\binom{m-2}{r-2}}{\binom{m}{r}}B(a)=\frac{r(r-1)}{m(m-1)}B(a).\)

The last equality follows by expanding the factorials in the binomial coefficients. Since \(2\le r<m\), the multiplier is strictly positive. Hence, for every \(a,b\in A\),

\(F_r(a)>F_r(b)\iff B(a)>B(b),\qquad F_r(a)=F_r(b)\iff B(a)=B(b).\)

This proves exact equivalence, including ties. The identity agrees with Lemma 1 of the supplied [Random-Subset Voting paper](https://www.jasss.org/21/1/10.html); the counting argument above proves it directly for the given support representation.

Exact algorithm and bit complexity

Write each input mass as \(\mu_i=u_i/v_i\), with positive integers \(u_i,v_i\) encoded in binary. Define

\(D=\prod_{i=1}^{\tau}v_i,\qquad w_i=u_i(D/v_i).\)

Each division is exact, and \(w_i=D\mu_i\) is an integer. Compute the integer scores

\(T(a)=\sum_{i=1}^{\tau}w_i\bigl(m-p_i(a)\bigr)=DB(a).\)

The algorithm initializes all \(T(a)\) to zero, scans each supplied ranking, adds \(w_i(m-k)\) to the alternative at position \(k\), and returns every alternative whose integer score equals the maximum. Since \(D>0\), the preceding identity proves that this returns exactly all required maximizers.

It remains to bound the arithmetic size. The sum of the binary lengths of the denominators is at most \(L\), so \(D\) has at most \(L+1\) bits. Moreover, normalization gives

\(\sum_{i=1}^{\tau}w_i=D\sum_{i=1}^{\tau}\mu_i=D.\)

Consequently, every score and every partial score accumulated by the algorithm satisfies

\(0\le T(a)\le(m-1)D.\)

All such integers therefore have \(O(L+\log m)\) bits. The intermediate products used to compute \(D\) and the \(w_i\) also have polynomial bit length. Computing the weights requires \(O(\tau)\) integer arithmetic operations; accumulating and comparing scores requires \(O(m\tau+m)\) further operations. Standard binary integer arithmetic performs each operation in polynomial time in these bit lengths.

Thus the entire algorithm runs in polynomial time in \(m,\tau,r,L\), using exact comparisons and without enumerating subsets or rankings outside the supplied support.
