Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given a finite type graph \(H=(T,F)\), rational masses \(\mu_t>0\) summing to \(1\), and rational partnership surpluses \(w_{tu}\), let \(D\) be a common denominator of the masses. For each integer \(r\geq 1\), form the weighted matching game \(G_r\) with \(rD\mu_t\) members of each type, all compatible type-pairs connected, and within-type edges between distinct members when allowed. Let \(\eta_r\) be its nucleolus and \(p_t^{(r)}\) the allocation per member of type \(t\). Determine whether \(p_t^{(r)}\) converges for every type and, if so, compute the exact limit vector; in the promised version, compute it when convergence is guaranteed. The target running time is polynomial in \(|T|\), \(|F|\), and the rational input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list of \(\tau\) types \(T\), each with positive binary rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also specifies an undirected compatibility graph \(H=(T,F)\), allowing loops, and surpluses \(w_{tu}\in\mathbb Q_{\geq0}\) for compatible pairs. Set \(m=|F|\); let \(L\) be the total binary input length.
Let \(D\) be the least common multiple of the denominators of the reduced masses. For every integer \(r\geq1\), construct \(G_r\) with \(rD\mu_t\) distinct players of type \(t\).
Each compatible pair of distinct types induces a complete bipartite graph; a loop at \(t\) induces a clique on that type's players. These are all edges, and each has weight \(w_{tu}\).
For every coalition \(S\), its worth \(\nu_r(S)\) is the maximum weight of a matching in \(G_r[S]\), with the empty matching allowed.
Let \(\eta_r\) be the standard nucleolus over imputations \(x\geq0\) satisfying \(\sum_{i\in V(G_r)}x_i=\nu_r(V(G_r))\), using nonempty proper coalitions. By symmetry, its members of type \(t\) have a common payoff \(p_t^{(r)}\); payoffs and edge weights are not rescaled with \(r\).
The problem is to decide whether \(p^{(r)}\) converges coordinatewise as \(r\to\infty\), and compute its exact limit when it does. The promised version guarantees convergence.

Is convergence determination together with exact limit computation polynomial-time in \(m,\tau,L\), or NP-hard?
Under the convergence promise, is exact limit computation polynomial-time in \(m,\tau,L\), or NP-hard?

For explicitly listed finite players, weighted matching-game nucleoli are computable in polynomial time in the graph size and weight bit length ([Könemann–Pashkovich–Toth](https://arxiv.org/abs/1803.03249)).
No result settling this exact replica-limit problem was located in the literature search.

Modeling choices made when packaging the task

  • The surplus signs were unspecified; require nonnegative rational surpluses, following the matching-game domain.
  • Encode optional within-type compatibility by loops in the undirected type graph; loops create edges only between distinct players.
  • Replace the unspecified common denominator by the least common multiple of the reduced mass denominators, fixing the replica sequence.
  • Specify coalition worth by unrestricted maximum weight matching, allowing unmatched players and the empty matching.
  • Use the standard nucleolus over nonnegative efficient imputations and nonempty proper coalitions.
  • Interpret per-member allocation as the common individual payoff within a type, without rescaling weights or payoffs.
  • Use m for the number of compatible type pairs and L for total binary input length; replica size is not an input parameter.

Result

Both problems are polynomial-time solvable in \(m,\tau,L\). In fact, convergence holds for every input.

The limit is obtained by lexicographic max-min optimization of \(m+\tau\) explicitly given affine functions on a polytope with \(\tau\) variables. The proof uses structural results for finite matching games from Könemann–Pashkovich–Toth, rather than applying their algorithm to an exponentially large replica.

1. The type-level primal and dual LPs

For each compatible pair \(e\), define its incidence vector \(a_e\) by

  • \(a_{tu}=\mathbf e_t+\mathbf e_u\) when \(t\ne u\);
  • \(a_{tt}=2\mathbf e_t\) for a loop.

Let \(A\) have these vectors as columns. Define

\(\displaystyle \rho=\max\{w^\mathsf T y:Ay\leq\mu,\ y\geq0\}.\)

Its dual is

\(\displaystyle \rho=\min\{\mu^\mathsf T p:A^\mathsf T p\geq w,\ p\geq0\}.\)

The primal is feasible and bounded: every column of \(A\) has coordinate sum \(2\), so every feasible \(y\) satisfies \(2\sum_e y_e\leq1\). The dual is feasible, for example by choosing every coordinate sufficiently large. Thus strong LP duality applies.

Write

\(\displaystyle P=\{p\geq0:A^\mathsf T p\geq w,\ \mu^\mathsf T p=\rho\}.\)

This is a nonempty compact polytope. Compactness follows from positive masses and \(0\leq p_t\leq\rho/\mu_t\).

The relevant affine functions are

\(\displaystyle f_t(p)=p_t,\qquad f_e(p)=a_e^\mathsf T p-w_e.\)

All these functions are nonnegative on \(P\).

Define \(q\) as their lexicographic max-min point on \(P\): sort their values increasingly and lexicographically maximize the resulting list. Below we prove that \(q\) is unique, polynomial-time computable, and the replica limit.

If \(\rho=0\), every replica has worth zero, hence its unique imputation is zero. We therefore assume \(\rho>0\).

2. Replica worths and accumulation points

Put \(n=rD\), so the number of players of type \(t\) is \(n_t=n\mu_t\). Let \(v_r=\nu_r(V(G_r))\).

2.1 Integer type counts exactly represent matchings

The maximum matching worth equals

\(\displaystyle v_r=\max\{w^\mathsf T z:Az\leq n\mu,\ z\in\mathbb Z_{\geq0}^{F}\}.\)

A player matching gives these edge counts. Conversely, any feasible integer counts can be realized: assign distinct players of each type to the required incident edges, pairing two assigned players for each loop edge. The complete bipartite and clique compatibility assumptions ensure every required edge exists.

Let \(C=\sum_{e\in F}w_e\). Scaling an optimal primal solution by \(n\), then rounding every coordinate downward, gives

\[\displaystyle 0\leq n\rho-v_r\leq C. \tag{1}\]

Rounding preserves feasibility because \(A\) is nonnegative.

2.2 A uniform least-core bound

Use the satisfaction convention

\(\displaystyle s_x(S)=x(S)-\nu_r(S).\)

Thus the nucleolus lexicographically maximizes the increasingly sorted satisfaction values.

Choose \(a\in P\), and give every player of type \(t\) payoff \(a_t\). For every coalition, its payoff covers the weight of every matching, because \(a_e^\mathsf T a\geq w_e\).

Scale these payoffs by \(\alpha_r=v_r/(n\rho)\). This produces an imputation. For every coalition \(S\),

\(\displaystyle s_{\alpha_r a}(S)\geq-(1-\alpha_r)a(S)\geq-(n\rho-v_r)\geq-C.\)

Consequently, the nucleolus satisfies

\[\displaystyle s_{\eta_r}(S)\geq-C \quad\text{for every nonempty proper }S. \tag{2}\]

2.3 Every accumulation point belongs to \(P\)

Efficiency and nonnegativity imply

\(\displaystyle \mu^\mathsf T p^{(r)}=v_r/n\leq\rho,\qquad 0\leq p_t^{(r)}\leq\rho/\mu_t.\)

Hence the sequence is bounded.

Fix an edge type \(e=tu\). Choose \(k_r\) disjoint edges of this type whose endpoints form a proper coalition, with \(k_r\to\infty\). For example, for sufficiently large \(r\), take

\(\displaystyle k_r=\min(n_t,n_u)-1\quad(t\ne u),\qquad k_r=\lfloor n_t/2\rfloor-1\quad(t=u).\)

That coalition has worth at least \(k_rw_e\). Combining this with (2) gives

\(\displaystyle k_r f_e(p^{(r)})\geq-C.\)

Thus every accumulation point \(a\) satisfies \(f_e(a)\geq0\). Equation (1) and efficiency give \(\mu^\mathsf T a=\rho\). Therefore

\[\displaystyle \text{every accumulation point of }p^{(r)}\text{ belongs to }P. \tag{3}\]

3. Even replicas and the candidate limit

3.1 Half-integrality of the type-level LP

We first prove that, for integer capacities \(b\), every vertex of

\(\displaystyle \{y\geq0:Ay\leq b\}\)

is half-integral.

At a vertex, the positive columns must be linearly independent when restricted to tight capacity rows. Otherwise a sufficiently small perturbation in both directions would preserve feasibility.

Consider a connected component of the graph formed by positive edge variables. If it has \(k\) vertices and \(\ell\) edges, including loops, connectivity and this independence give

\(\displaystyle k-1\leq\ell\leq k.\)

If \(\ell=k-1\), the component is a tree, and at least \(k-1\) capacity rows are tight. Root it at the possibly nontight vertex. Successively using the tight leaf equations shows all edge values are integral.

If \(\ell=k\), the component is unicyclic and all its capacity rows are tight. Removing attached trees leaves a cycle. An even cycle would give an alternating column dependence, so the cycle is odd. Its equations have the form \(y_{i-1}+y_i=c_i\), with integral \(c_i\), and imply \(2y_i\in\mathbb Z\). A loop gives the same conclusion through \(2y_e=c_t\).

This proves half-integrality.

If all capacities are even, scaling the polytope with capacities \(b/2\) by \(2\) shows that every vertex is integral. For even \(r\), all \(n_t=rD\mu_t\) are even. Therefore

\[\displaystyle v_r=n\rho\qquad\text{whenever }r\text{ is even}. \tag{4}\]

3.2 The symmetric core is \(P\)

For \(r\geq4\), every singleton and every compatible player pair is a proper coalition, and each type has enough players to realize a loop pair.

When \(v_r=n\rho\), a symmetric imputation is in the core exactly when its type payoff vector lies in \(P\). Necessity follows from singleton and pair coalitions. Sufficiency follows by decomposing a maximum matching of any coalition into edges and unmatched players.

The nucleolus belongs to the core whenever the core is nonempty: an imputation with a negative satisfaction value cannot beat a core imputation, whose satisfaction values are all nonnegative.

More generally, if a replica with \(r\geq4\) has a nonempty core, symmetrizing a core allocation gives a feasible dual vector of value \(v_r/n\). Since \(v_r/n\leq\rho\), dual optimality forces equality. Thus its symmetric core is again \(P\).

3.3 Reducing all coalition functions to the affine functions \(f_t,f_e\)

Let \(Q\subseteq P\) be any nonempty polytope encountered during lexicographic optimization. Fix a maximum matching \(M\) in a coalition \(S\). Its satisfaction is

\[\displaystyle s_p(S)=\sum_{e\in M}f_e(p)+\sum_{i\in S\setminus V(M)}f_{t(i)}(p). \tag{5}\]

Every summand is nonnegative on \(Q\). If the left-hand side is nonconstant on \(Q\), at least one summand is nonconstant there. Hence its value is at least the minimum value among the nonconstant elementary functions.

Conversely, each elementary function is itself a singleton or compatible-pair satisfaction function. Therefore the minimum over nonconstant coalition functions equals the minimum over nonconstant elementary functions.

Functions constant throughout \(Q\) can be deleted from lexicographic comparison, since they contribute the same entries at every point. Applying the preceding argument recursively proves that coalition lexicographic optimization and elementary-function optimization have the same successive feasible sets.

The process terminates at a single point: if every singleton function is constant, every coordinate is fixed. Thus \(q\) is unique, and

\[\displaystyle p^{(r)}=q\quad\text{for every even }r\geq4. \tag{6}\]

The same equality holds for every \(r\geq4\) whose replica has a nonempty core.

One further property will be useful:

\[\displaystyle f(q)=0\ \Longrightarrow\ f\equiv0\text{ on }P \quad\text{for every elementary }f. \tag{7}\]

Indeed, each elementary function that is nonconstant on \(P\) is positive somewhere. Averaging one such witness for each nonconstant function gives a point where they are all strictly positive. The first max-min optimization, after deleting constant functions, therefore has a strictly positive optimum.

4. The finite-game structural input

For an empty-core finite matching game, let \(Q\) be its least core and let \(\varepsilon<0\) be its least-core level. Call a matching universal if its endpoint satisfaction equals \(\varepsilon\) throughout \(Q\), and let \(E^*\) be the union of universal matchings.

We use these two consequences of Könemann–Pashkovich–Toth:

  • There are disjoint odd vertex sets \(B_1,\ldots,B_k\). For any choices \(v_i\in B_i\), there is a universal matching consisting of internal matchings that saturate each \(B_i\setminus\{v_i\}\).
  • Put \(E^+=E\setminus\bigcup_i E(B_i)\). Over \(Q\), the nucleolus lexicographically maximizes the affine functions

\(\displaystyle x_v,\quad x_u+x_v-w_{uv}\ (uv\in E^+),\quad w_{uv}-x_u-x_v\ (uv\in E^*).\)

The first statement is their Lemma 4 and its construction. The second follows from Theorem 3.1: its successive thresholds are shifted by the common constant \(\varepsilon\). See [Könemann–Pashkovich–Toth, Sections 2.3 and 3](https://arxiv.org/html/1803.03249v3).

We also need the following immediate fact:

\[\displaystyle x_u+x_v-w_{uv}\leq0\qquad(uv\in E^*,\ x\in Q). \tag{8}\]

To prove it, take a universal matching containing \(uv\). Removing an edge with strictly positive satisfaction would produce a matching with satisfaction below \(\varepsilon\), contradicting least-core feasibility.

These statements apply to the present finite player graphs, which have no player loops. For an empty-core game, using proper coalitions or all matching endpoint sets gives the same least core. Empty and grand-coalition endpoint sets have nonnegative satisfaction; other coalitions decompose as in (5), with nonnegative unmatched-player payoffs.

5. Every accumulation point equals \(q\)

Suppose a subsequence satisfies

\(\displaystyle p^{(r_j)}\longrightarrow a.\)

By (3), \(a\in P\). Assume, toward a contradiction, that \(a\ne q\), and put \(d=q-a\).

By (6) and its nonempty-core extension, we may restrict to a subsequence of empty-core replicas. Let \(Q_j\) be their least cores.

5.1 Moving toward \(q\) preserves least-core feasibility

For every fixed \(0<\theta<1\), the symmetric vector

\[\displaystyle \widetilde p_j=p^{(r_j)}+\theta d \tag{9}\]

belongs to \(Q_j\) for all sufficiently large \(j\).

Efficiency is preserved because \(\mu^\mathsf T d=0\). Nonnegativity also holds eventually. If \(a_t=0\), then \(d_t=q_t\geq0\); otherwise the limiting coordinate \((1-\theta)a_t+\theta q_t\) is positive.

Consider an edge function \(f_e\). If its directional change \(a_e^\mathsf T d\) is negative, then \(f_e(a)>0\), because both \(a,q\) lie in \(P\). Its value at \(\widetilde p_j\) consequently remains positive for large \(j\).

Thus every edge with negative satisfaction at \(\widetilde p_j\) had negative satisfaction at \(p^{(r_j)}\), and its satisfaction has not decreased.

For any matching \(M\), let \(M^-\) contain its edges with negative satisfaction at \(\widetilde p_j\). If \(\varepsilon_j<0\) is the least-core level, then

\(\displaystyle \sum_{e\in M}f_e(\widetilde p_j)\geq \sum_{e\in M^-}f_e(\widetilde p_j)\geq \sum_{e\in M^-}f_e(p^{(r_j)})\geq\varepsilon_j.\)

The last inequality is a least-core matching constraint. This proves (9).

5.2 Universal edges are universally tight on \(P\)

For all sufficiently large \(j\), every edge in \(E_j^*\) has a type \(e\) satisfying

\[\displaystyle f_e\equiv0\text{ on }P. \tag{10}\]

Otherwise, by (7), \(f_e(q)>0\). If \(f_e(a)>0\), its satisfaction at \(p^{(r_j)}\) is eventually positive, contradicting (8).

If \(f_e(a)=0\), use (9) with \(\theta=1/2\). Its satisfaction tends to \(f_e(q)/2>0\), again contradicting (8). There are finitely many edge types, so these exclusions hold simultaneously.

5.3 Every payoff coordinate appearing in a block is fixed on \(P\)

Let \(h=p-p'\), where \(p,p'\in P\). Lift \(h\) to players by their types. By (10), the sum of its endpoint values is zero on every universal edge.

Fix a block \(B_i\) and a vertex \(v\in B_i\). The internal universal matching from Section 4 saturates \(B_i\setminus\{v\}\). Therefore

\(\displaystyle \sum_{u\in B_i\setminus\{v\}}h_u=0.\)

Writing \(H_i=\sum_{u\in B_i}h_u\), this says \(h_v=H_i\) for every \(v\in B_i\). Summing gives

\(\displaystyle H_i=|B_i|H_i.\)

Since \(|B_i|>1\), \(H_i=0\), and every \(h_v=0\).

Thus every type occurring in a block has a payoff coordinate constant on \(P\). In particular, every elementary edge function nonconstant on \(P\) occurs in the positive exterior-edge family \(E_j^+\).

5.4 Lexicographic optimality gives the contradiction

Restrict the structural affine functions from Section 4 to symmetric payoffs. Denote their family by \(\mathcal F_j\). It contains:

  • all singleton functions;
  • every elementary edge function nonconstant on \(P\);
  • possibly additional functions constant on \(P\).

Indeed, the negative universal-edge functions vanish on \(P\) by (10).

There are only finitely many possible distinct type-level functions. Passing to a further subsequence, their family is fixed; call it \(\mathcal F\). Repetitions do not affect the successive max-min feasible sets. Consequently, the unique lexicographic maximizer of \(\mathcal F\) on \(P\) is \(q\).

We spell out the needed strict-improvement argument. Run successive max-min optimization of \(\mathcal F\) on \(P\), deleting functions constant on the current feasible set. Since \(a\ne q\), there is a first round whose optimal feasible set excludes \(a\). Let \(c\) be the minimum remaining function value at \(a\), and let \(\lambda\) be that round’s optimum. Then \(c<\lambda\).

Functions deleted earlier take equal values at \(a\) and \(q\). Every remaining function with value \(c\) at \(a\) has value at least \(\lambda\) at \(q\), so it strictly increases in direction \(d\).

Equivalently, among the functions that change in direction \(d\), those with the smallest value at \(a\) all strictly increase. Choose a sufficiently small fixed \(0<\theta<1\). Every changing function then has value strictly greater than \(c\) at \(a+\theta d\). By convergence, for large \(j\), the minimum changing-function value at \(\widetilde p_j\) is strictly greater than at \(p^{(r_j)}\).

All unchanged-function values are exactly equal at these two points and can be cancelled from their sorted lists. Hence \(\widetilde p_j\) lexicographically improves the structural objective.

But \(\widetilde p_j\in Q_j\) by Section 5.1, while \(p^{(r_j)}\) is its lexicographic maximizer by the finite-game structural theorem. This is a contradiction.

Every accumulation point therefore equals \(q\). Boundedness now proves

\(\displaystyle \boxed{\lim_{r\to\infty}p^{(r)}=q.}\)

6. Exact polynomial-time algorithm

The algorithm uses only the type-level input:

  • Solve the primal LP for \(\rho\), and form \(P\).
  • Start with its \(m+\tau\) elementary functions.
  • On the current polytope \(Q\), identify constant functions by computing each function’s minimum and maximum.
  • Delete those functions from the objective list. For the remaining functions, solve

\(\displaystyle \max\{\delta:p\in Q,\ f(p)\geq\delta\text{ for every remaining }f\}.\)

  • Restrict \(Q\) to the optimum and repeat until it is a singleton. Output that point.

Each nonterminal round strictly decreases affine dimension. To see this, suppose no remaining function were identically equal to the optimal level on the new feasible set. For each function, choose an optimum point where it exceeds that level. Averaging these points would make every remaining function strictly exceed the level, a contradiction. The resulting new equality was nonconstant on the preceding polytope.

There are therefore at most \(\tau\) rounds, with polynomially many LP calls and constraints.

Exact bit complexity is also polynomial. One may introduce a variable for each successive optimal level and retain all corresponding inequalities. This extended LP has at most \(2\tau\) variables and polynomially many constraints, with coefficients from the input and the already polynomial-bit value \(\rho\). Sequentially maximizing its level variables ends at the unique point containing \(q\) and all optimal levels. That point is a vertex, so standard rational determinant bounds give polynomial encoding lengths for every level and every coordinate of \(q\).

Thus convergence determination always returns yes, and exact limit computation is polynomial-time, both with and without the convergence promise.
