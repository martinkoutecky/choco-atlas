The continuous mirror question, as graded

Given a finite set of complete peer-value types \(T\), rational population masses \(\mu_t\) summing to \(1\), and rational values \(a_{ts}\), define \(u_t(q)=\sum_{s\in T}a_{ts}q_s\) and \(g_t=\max\{0,u_t(\mu)\}\). Does there exist a finite family of coalition mass vectors \(q^j\ge 0\) such that \(\sum_j q_t^j\le\mu_t\), every type \(t\) with \(q_t^j>0\) satisfies \(u_t(q^j)\ge g_t\), and any unassigned mass belongs only to types with \(g_t=0\) and is assigned to singleton agents?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. The input includes the complete matrix \(a\in\mathbb{Q}^{T\times T}\) of directed peer values, with arbitrary signs and no symmetry requirement; \(a_{tt}\) values other agents of the same type. Agents are nonatomic, and singleton utility is zero.
Define \(u_t(q)=\sum_{s\in T}a_{ts}q_s\) and the grand-coalition fairness threshold \(g_t=\max\{0,u_t(\mu)\}\); preferences compare utilities weakly, so equality is acceptable.
A feasible structure consists of finitely many nonzero vectors \(q^1,\ldots,q^k\in\mathbb{R}_{\geq0}^{T}\), allowing \(k=0\), such that \(\sum_{j=1}^{k}q_t^j\leq\mu_t\) and \(q_t^j>0\) implies \(u_t(q^j)\geq g_t\). Types may split among coalitions. Residual mass \(\mu_t-\sum_jq_t^j\) must be zero whenever \(g_t>0\); all residual agents form individual singletons. There is no input bound on \(k\).
Is deciding whether such a feasible structure exists solvable in polynomial time, or is it NP-hard? State running times in \(\tau\) and total input bit length \(L\); there is no separate \(m\) or other input parameter.
For finite additively separable hedonic games, existence of a grand-coalition fair partition is NP-complete, and max-min fairness coincides with grand-coalition fairness ([Nguyen–Rothe, 2016](https://www.ifaamas.org/Proceedings/aamas2016/pdfs/p232.pdf)). The extended result strengthens existence hardness to strong NP-completeness ([Kerkmann–Nguyen–Rothe, 2021, reproduced in the author's dissertation](https://ccc.cs.uni-duesseldorf.de/~rothe/DISSERTATION/DissKerkmann.pdf)).
No complexity result for exactly this mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted the society as nonatomic: singleton agents have zero mass and zero utility, and residual mass represents separate individual singletons.
  • Allowed arbitrary signed, asymmetric rational peer values, matching the general additively separable domain of the anchor.
  • Interpreted diagonal entries as values for other agents of the same type; individual self-value normalization does not require these entries to vanish.
  • Specified real coalition masses, splitting of types among coalitions, nonzero listed coalition vectors, and an empty family when all agents may remain singletons.
  • Used support size and total input bit length as the size parameters because this problem has no separate candidate or item parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Deciding feasibility is \(\mathrm{NP}\)-hard, even when all masses are equal dyadic rationals and every diagonal entry satisfies \(a_{tt}=0\). Consequently, there is no polynomial-time algorithm in the total input bit length \(L\) unless \(\mathrm{P}=\mathrm{NP}\).

A deterministic decision algorithm runs in \(2^{2^{O(\tau)}}L^{O(1)}\) time. Both claims are proved below.

1. The finite problem used in the reduction

Consider a finite additively separable hedonic game with players \(N=\{1,\ldots,n\}\), rational values \(v_i(j)\), and \(v_i(i)=0\). Put

\(b_i=\max\{0,\sum_{j\in N}v_i(j)\}\).

Its grand-coalition fairness problem asks whether there is a partition \(\pi\) of \(N\) satisfying

\(\sum_{j\in\pi(i)}v_i(j)\geq b_i\quad\text{for every }i\in N\).

This problem is \(\mathrm{NP}\)-complete by Theorem 7 of [Nguyen–Rothe (2016)](https://www.ifaamas.org/Proceedings/aamas2016/pdfs/p232.pdf). Their normalization and fairness definition give exactly the thresholds above.

Let \(r\) be the least power of two with \(r\geq n\). Add \(r-n\) players whose incoming and outgoing values are all zero. This preserves feasibility: added players can be singleton blocks, and deleting them from any fair partition leaves all original utilities unchanged. Write \(v\) for the padded valuation matrix and \(b_i\) for its thresholds.

2. Construction of the mass instance

For each padded player \(i\in\{1,\ldots,r\}\), create an original type \(x_i\) and a guard type \(h_i\). Set

\(T=\{x_1,\ldots,x_r,h_1,\ldots,h_r\},\qquad \tau=2r,\qquad \mu_t=1/\tau\).

These masses are positive dyadic rationals and sum to one.

Define the complete matrix by

\(a_{x_i x_j}=\tau v_i(j),\qquad a_{h_i x_i}=\tau\),

with all remaining entries zero. In particular, all diagonal entries vanish.

The resulting grand-coalition thresholds are

\(g_{x_i}=\max\{0,\sum_{j=1}^{r}\tau v_i(j)\mu_{x_j}\}=b_i\),

and

\(g_{h_i}=\tau\mu_{x_i}=1\).

Because \(r<2n\), the construction has \(\tau<4n\) types. Multiplication by \(\tau\) increases the encoding length of each valuation by only \(O(\log\tau)\) bits. Thus constructing the complete matrix takes polynomial time in the finite instance’s encoding length.

3. Guards force entire types into single coalitions

Lemma. In every feasible structure of the constructed instance, each pair \(x_i,h_i\) occurs together, with both types’ entire masses, in exactly one coalition.

Proof. Since \(g_{h_i}=1>0\), no guard mass may remain in singletons. Hence some coalition \(q^\ell\) has \(q^\ell_{h_i}>0\). Its guard constraint gives

\(u_{h_i}(q^\ell)=\tau q^\ell_{x_i}\geq1\).

The mass constraint also gives \(q^\ell_{x_i}\leq\mu_{x_i}=1/\tau\). Therefore

\(q^\ell_{x_i}=1/\tau=\mu_{x_i}\).

Nonnegativity and the total mass constraint imply \(q^j_{x_i}=0\) for every \(j\neq\ell\).

Any other coalition containing positive \(h_i\)-mass would likewise require the entire \(x_i\)-mass, which is impossible. Consequently all \(h_i\)-mass belongs to \(q^\ell\). Since its residual mass must vanish,

\(q^\ell_{h_i}=\mu_{h_i}=1/\tau\).

This proves the lemma. \(\square\)

Thus splitting is permitted by the formulation, but the constructed instance prevents it. Every nonzero coalition consists of entire original–guard pairs.

4. Equivalence of the two instances

A finite fair partition gives a feasible mass structure

Suppose the padded finite game has a fair partition \(\pi\). For each block \(C\in\pi\), form a vector \(q^C\) containing mass \(1/\tau\) of both \(x_i\) and \(h_i\) for every \(i\in C\), and zero elsewhere.

Every type’s entire mass is assigned. For \(i\in C\),

\(u_{x_i}(q^C)=\sum_{j\in C}\tau v_i(j)(1/\tau)=\sum_{j\in C}v_i(j)\geq b_i=g_{x_i}\).

Also,

\(u_{h_i}(q^C)=\tau(1/\tau)=1=g_{h_i}\).

Therefore these vectors form a feasible structure.

A feasible mass structure gives a finite fair partition

Conversely, suppose the constructed mass instance is feasible. By the guard lemma, every padded player’s original–guard pair belongs entirely to one coalition. For each nonzero coalition \(q^\ell\), define

\(C_\ell=\{i:q^\ell_{x_i}>0\}\).

The sets \(C_\ell\) are nonempty and partition \(\{1,\ldots,r\}\): every original type is fully assigned to exactly one coalition, and every guard accompanies its original type.

For every \(i\in C_\ell\), feasibility gives

\(\sum_{j\in C_\ell}v_i(j)=u_{x_i}(q^\ell)\geq g_{x_i}=b_i\).

Hence the blocks \(C_\ell\) form a fair partition of the padded finite game. Deleting the added zero-valued players gives a fair partition of the original game.

The reduction is therefore a polynomial-time many-one reduction, proving \(\mathrm{NP}\)-hardness.

5. A decision algorithm for arbitrary instances

The following argument handles the absence of an input bound on the number of coalitions.

Merging coalitions with identical supports

Define \(\operatorname{supp}(q)=\{t:q_t>0\}\). Suppose several feasible coalition vectors have the same nonempty support \(S\). Replace them by their sum \(Q\).

For every \(t\in S\), linearity and nonnegativity of the thresholds give

\(u_t(Q)=\sum_j u_t(q^j)\geq\sum_j g_t\geq g_t\).

The support remains \(S\), and total assigned masses remain unchanged. Thus merging preserves feasibility.

There are \(2^\tau-1\) nonempty supports. Consequently, every feasible instance has a feasible structure with at most \(2^\tau-1\) coalitions.

Enumerating support families

Enumerate every family \(\mathcal F\subseteq 2^T\setminus\{\varnothing\}\), including the empty family. For each \(\mathcal F\), introduce vectors \(q^S\), one for each \(S\in\mathcal F\), and solve the rational linear feasibility problem

\(q_t^S\geq0\quad(t\in S),\qquad q_t^S=0\quad(t\notin S),\)

\(\sum_{S\in\mathcal F}q_t^S\leq\mu_t\quad(t\in T),\)

\(\sum_{S\in\mathcal F}q_t^S=\mu_t\quad(t\in T\text{ with }g_t>0),\)

\(\sum_{s\in T}a_{ts}q_s^S\geq g_t\quad(S\in\mathcal F,\ t\in S).\)

Strict positivity inside \(S\) is unnecessary. If this linear program is feasible, discard zero vectors. Each remaining vector has actual support contained in its indexed set \(S\), so every type present satisfies its required utility constraint. The mass and residual conditions also hold.

Conversely, merge an existing feasible structure by identical supports and choose \(\mathcal F\) to be its resulting support family. Those merged vectors satisfy the corresponding linear program.

Therefore the algorithm accepts exactly the feasible instances.

Running time

There are \(2^{2^\tau-1}\) support families. Each linear program has at most \(\tau2^{\tau-1}\) variables and \(O(\tau2^\tau)\) constraints.

The thresholds are computable in polynomial time in \(L\). Each expanded linear program has encoding length \(2^{O(\tau)}L^{O(1)}\), so polynomial-time rational linear programming gives total running time

\(2^{2^\tau-1}\,2^{O(\tau)}L^{O(1)}=2^{2^{O(\tau)}}L^{O(1)}\).

This establishes fixed-parameter tractability in the support size \(\tau\), alongside \(\mathrm{NP}\)-hardness when \(\tau\) varies. Membership of the general problem in \(\mathrm{NP}\) is not needed for the requested classification and is not asserted here.
