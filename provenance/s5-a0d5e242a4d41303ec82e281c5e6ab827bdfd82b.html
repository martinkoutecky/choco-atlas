Proposition 1 — class: algorithmic

The continuous mirror question, as graded

Given a finite object set \(O\), a support \(T\) of \(\tau\) types with rational masses \(\mu_t>0\) summing to \(1\), complete weak rankings, rational per-capita supplies \(\sigma_o\), and rational linear constraints with coefficients \(a^r_{t,o}\) and bounds \(\beta_r\), assume the feasible set is nonempty. Compute an outcome of the type-level Constrained Serial Rule: at each round maximize the minimum per-person share of the current preference prefix over a chosen subset of types, subject to \(\sum_o p_{t,o}=1\), \(\sum_t\mu_t p_{t,o}\leq\sigma_o\), \(\sum_{t,o}\mu_t a^r_{t,o}p_{t,o}\leq\beta_r\), and all prior prefix-share promises; select a minimal bottleneck subset, record its promises, and advance its prefixes until every type receives total share \(1\).

Packaged proof task (what the prover saw — nothing else)

Let \(O\) be a nonempty object set, \(m=|O|\). A society is given by its support: the list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Each type specifies a complete weak ranking and its constraint coefficients.
The input includes nonnegative rational per-capita supplies \(\sigma_o\) and \(k\) explicit linear constraints with arbitrary signed rational coefficients \(a^r_{t,o}\) and bounds \(\beta_r\). Let \(L\) be the total input bit length.
A per-person allocation \(p\) belongs to the assumed nonempty feasible set \(P\) exactly when \(p_{t,o}\geq0\), \(\sum_o p_{t,o}=1\), \(\sum_t\mu_t p_{t,o}\leq\sigma_o\), and \(\sum_{t,o}\mu_t a^r_{t,o}p_{t,o}\leq\beta_r\) for every \(r\).
Let \(E_t\) be the number of indifference classes and \(C_t(j)\) the union of the first \(j\) classes; write \(p_t(C)=\sum_{o\in C}p_{t,o}\). A promise \((t,j,\gamma)\) requires \(p_t(C_t(j))\geq\gamma\).
Initialize \(\ell_t=1\) for every type and \(F=\varnothing\). For nonempty \(S\subseteq T\), define \(v(S,F,\ell)=\max\{\lambda\geq0: p\in P,\ p\text{ satisfies }F,\ p_t(C_t(\ell_t))\geq\lambda\text{ for all }t\in S\}\).
In each round set \(\lambda=v(T,F,\ell)\). If \(\lambda=1\), return any maximizing allocation. Otherwise choose any nonempty inclusion-minimal \(B\subseteq T\) with \(v(B,F,\ell)=\lambda\), add \((t,\ell_t,\lambda)\) to \(F\) for every \(t\in B\), and then increment those \(\ell_t\). These choices define the type-level Constrained Serial Rule; any permitted bottleneck and final-allocation choices are allowed.

Is computing an exact rational outcome of this type-level Constrained Serial Rule possible in time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For a finite list of agents, the Constrained Serial Rule terminates with a feasible assignment and is computable in polynomial time ([Shende](https://arxiv.org/pdf/2011.01178)). No result settling this exact support-encoded mass version was located.

Modeling choices made when packaging the task

  • A support type specifies both a ranking and constraint coefficients, so different rankings may occur under identical constraint coefficients.
  • Allocation entries are nonnegative per-person shares; supplies are nonnegative rationals, while additional constraint coefficients and bounds may have either sign.
  • The round objective always uses the entire support; subset objectives are used to define bottlenecks.
  • Minimal means inclusion-minimal among nonempty subsets, rather than minimum cardinality; all permitted choices are allowed.
  • Promises are lower bounds on unweighted per-person prefix shares, initialized empty; thresholds start at the first indifference class.
  • Termination means that the full-support round objective equals one, rather than merely that allocation rows sum to one.
  • The computational output is an exact rational allocation; the number of explicit constraints and total input bit length are included in the running-time parameters.

Result

An exact rational outcome of the type-level Constrained Serial Rule is computable in time polynomial in \(m,\tau,k,L\).

The algorithm works directly with the \(\tau\) supported types. The proof must bound both the number of linear programs and the bit lengths of the promises generated during execution.

1. Linear programs and feasibility

For a promise set \(F\), define
\[ K_F=\{p\in P:p\text{ satisfies every promise in }F\}. \]

For nonempty \(S\subseteq T\), compute \(v(S,F,\ell)\) by the explicitly encoded linear program
\[ \max \lambda \quad\text{subject to}\quad p\in K_F,\qquad 0\leq\lambda\leq1,\qquad \lambda\leq\sum_{o\in C_t(\ell_t)}p_{t,o}\quad(t\in S). \]

The added upper bound \(\lambda\leq1\) is redundant: every cumulative allocation is at most \(1\), and \(S\) is nonempty.

Whenever \(K_F\) is nonempty, this LP has a nonempty compact feasible region. Indeed, each \(p_t\) belongs to a simplex, and \(\lambda\in[0,1]\). Consequently its maximum exists.

Initially \(K_F=P\neq\varnothing\). Suppose a round has optimum \(\lambda\) and maximizing allocation \(p^*\). For every chosen bottleneck type \(t\),
\[ p_t^*(C_t(\ell_t))\geq\lambda. \]
Thus \(p^*\) satisfies all the new promises, so the updated \(K_F\) remains nonempty. This proves feasibility throughout execution.

The LP has \(\tau m+1\) variables and
\[ O(\tau m+m+k+\tau+|F|) \]
constraints, after replacing equalities by pairs of inequalities.

2. Finding an inclusion-minimal bottleneck

Fix \(F,\ell\). For nonempty \(A\subseteq B\subseteq T\), removing threshold constraints enlarges the feasible region, so
\[ v(A,F,\ell)\geq v(B,F,\ell). \]
In particular, writing \(\lambda=v(T,F,\ell)\), every nonempty subset has value at least \(\lambda\).

Start with \(B=T\). Process the types in a fixed order. Whenever \(|B|>1\), compute \(v(B\setminus\{t\},F,\ell)\), and delete \(t\) exactly when this value equals \(\lambda\). Stop deleting if \(B\) becomes a singleton.

Every deletion preserves \(v(B,F,\ell)=\lambda\), and the final \(B\) is nonempty. To prove inclusion-minimality, suppose the final \(B\) has more than one member. For each \(t\in B\), let \(B_t\) denote the current set when its deletion was tested. Because \(t\) was retained,
\[ v(B_t\setminus\{t\},F,\ell)>\lambda. \]
Later operations only delete types, so
\[ B\setminus\{t\}\subseteq B_t\setminus\{t\}. \]
Monotonicity therefore gives
\[ v(B\setminus\{t\},F,\ell)>\lambda. \]

Now take any nonempty proper subset \(A\subsetneq B\), and choose \(t\in B\setminus A\). Since \(A\subseteq B\setminus\{t\}\),
\[ v(A,F,\ell)\geq v(B\setminus\{t\},F,\ell)>\lambda. \]
Thus \(B\) is inclusion-minimal. A singleton is inclusion-minimal automatically.

This procedure uses at most \(\tau\) additional LP calls per round. It is the same deletion principle used in [Shende’s Section 3.3](https://arxiv.org/pdf/2011.01178); the argument above applies directly to the specified type-level rule.

3. Polynomially many rounds

Suppose \(\lambda<1\), and let \(B\) be any permitted inclusion-minimal bottleneck. We claim that
\[ t\in B\implies\ell_t<E_t. \]

If \(\ell_t=E_t\), then \(C_t(\ell_t)=O\), and every feasible allocation satisfies
\[ p_t(C_t(\ell_t))=1. \]
If \(B=\{t\}\), its value is therefore \(1\), contradicting \(v(B,F,\ell)=\lambda<1\).

If \(B\) has another member, its threshold constraint for \(t\) is redundant: the constraints for the other members already imply \(\lambda\leq1\). Hence
\[ v(B\setminus\{t\},F,\ell)=v(B,F,\ell), \]
contradicting inclusion-minimality. This proves the claim.

Every nonterminal round consequently increments at least one threshold, and no threshold exceeds its corresponding \(E_t\). Let
\[ R=\sum_{t\in T}(E_t-1)\leq\tau(m-1). \]
There are at most \(R\) nonterminal rounds. When all thresholds reach their final classes, every cumulative allocation is \(1\), so the next round terminates.

Therefore there are at most \(R+1\) rounds. Moreover, each new promise corresponds to one threshold increment, giving
\[ |F|\leq R. \]
The total number of LP calls is at most
\[ (R+1)(\tau+1). \]

4. Polynomial bit lengths of all promises

Counting LP calls alone is insufficient: their promise bounds are computed rational numbers. We now bound their bit lengths.

Set \(N=\tau m+1\), the number of LP variables. Let \(Q\) be the product of the positive denominators of all rational numbers in the original input. Its bit length is \(O(L)\).

Multiply every constraint row of every LP by \(Q\). All resulting coefficient rows are integer rows:

  • Supply coefficients are \(Q\mu_t\).
  • Additional-constraint coefficients are \(Q\mu_t a^r_{t,o}\). The denominators of \(\mu_t\) and \(a^r_{t,o}\) both occur in the product defining \(Q\), so their product divides \(Q\).
  • Normalization, nonnegativity, promise, and threshold rows have coefficients in \(\{0,Q,-Q\}\).

The original right-hand sides also become integers. The only right-hand sides that may remain nonintegral are \(Q\gamma\) for previously generated promises.

Crucially, the coefficient rows do not depend on the numerical promise values. Their entries have absolute value at most some
\[ H=2^{O(L)}, \]
uniformly over all rounds and all deletion tests.

Let
\[ h=N\left\lceil\log_2(NH)\right\rceil. \]
Hadamard’s determinant inequality implies that every nonsingular \(N\)-by-\(N\) matrix \(M\) assembled from these rows satisfies
\[ 1\leq|\det M|\leq(\sqrt N\,H)^N\leq2^h. \]
Thus \(h=O(N(L+\log N))\).

Suppose, at the beginning of a round, that an integer \(D\) is a common denominator of all existing promise values. Then every scaled right-hand side becomes an integer after multiplication by \(D\).

Every LP in that round has an optimal vertex. At a vertex, there are \(N\) linearly independent active rows, even if the feasible polytope has lower dimension: otherwise a nonzero direction annihilating all active rows would permit sufficiently small feasible perturbations in both directions, contradicting extremality.

Writing these active equations as \(Mx=b\), we have
\[ Mx=\frac{u}{D} \]
for an integer vector \(u\). Cramer’s rule shows that each coordinate of \(x\), including its objective coordinate \(\lambda\), has reduced denominator dividing
\[ D|\det M|. \]

The round’s optimal value is the same at every optimum. Hence, when that value is stored as a promise, we may take
\[ D'=D|\det M| \]
as a common denominator of all old and new promises. Its logarithm satisfies
\[ \log_2D'\leq\log_2D+h. \]

Initially there are no promises, so take \(D=1\). After at most \(R\) updates,
\[ \log_2D\leq Rh. \]
Every promise lies in \([0,1]\), so its reduced numerator is no larger than its denominator. Each promise therefore has bit length \(O(1+Rh)\), polynomial in the original parameters.

The same argument bounds each deletion-test value: its reduced denominator divides \(D|\det M|\), and its value lies in \([0,1]\). These test values need not be stored as promises.

Consequently every LP encountered has polynomial total binary encoding length. Exact comparisons of its optimum with the round’s value, or with \(1\), also take polynomial time.

5. Exact implementation and conclusion

We use the standard rational linear-programming theorem: an explicitly encoded rational LP that is feasible and has finite optimum admits computation of its exact optimum and an exact rational optimal solution in time polynomial in its binary encoding length. This theorem allows equalities and lower-dimensional feasible regions; exact recovery is discussed in [Vishnoi’s linear-programming notes, page 2](https://nisheethvishnoi.wordpress.com/wp-content/uploads/2018/05/lecture71.pdf).

Every LP here meets these hypotheses:

  • feasibility follows from Section 1;
  • compactness gives a finite attained optimum;
  • all coefficients and bounds are rational;
  • Section 4 bounds its encoding length polynomially.

Execute the rule using exact LP optimization and the deletion procedure of Section 2. Section 3 bounds the number of calls polynomially, and Section 4 bounds the cost of each call polynomially.

At the terminal round, the exact LP solver returns a rational maximizing allocation with \(\lambda=1\). This is a permitted final-allocation choice, and all preceding bottleneck choices were permitted inclusion-minimal choices. The returned allocation is therefore an exact rational outcome of the specified rule.

The target problem is polynomial-time solvable.
