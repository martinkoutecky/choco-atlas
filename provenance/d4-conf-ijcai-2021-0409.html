The continuous mirror question, as graded

Given \(m\) binary issues, a current mass profile \(\mu_t\) over unconditional approval-ballot types, a target outcome \(p\), and quota \(q\), decide whether \(p\) can be made the unique Minisum optimum by adding available mass \(y_t\) with \(0\le y_t\le\nu_t\) and \(\sum_t y_t\le q\), or by deleting mass \(x_t\) with \(0\le x_t\le\mu_t\) and \(\sum_t x_t\le q\). For the resulting profile \(\lambda=\mu+y\) or \(\lambda=\mu-x\), the requirement is that \(S_\lambda(p)<S_\lambda(s)\) for every \(s\ne p\), where \(S_\lambda(s)=\sum_t\lambda_t\delta_t(s)\).

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge 1\) binary issues have outcome space \(\{0,1\}^m\). An unconditional ballot type \(t\) specifies an approval set \(A_{t,j}\subseteq\{0,1\}\) for every issue \(j\); empty sets and approval of both values are allowed. Define \(\delta_t(s)=|\{j:s_j\notin A_{t,j}\}|\) and \(S_\lambda(s)=\sum_t\lambda_t\delta_t(s)\).
A society is given by its support: the list of types with positive mass, each mass a binary rational. The parameter \(\tau\) counts supported types, not possible types; for addition, use the union of the current and available supports. Masses are finite nonnegative measures, without normalization. The current society \(\mu\) has positive total mass. Let \(L\) be the total binary input length.
The input includes a target \(p\in\{0,1\}^m\) and a nonnegative binary rational quota \(q\). Consider two separate decision problems. Addition also receives available masses \(\nu\) and permits real masses \(0\le y_t\le\nu_t\), with \(\sum_t y_t\le q\), producing \(\lambda=\mu+y\). Deletion permits real masses \(0\le x_t\le\mu_t\), with \(\sum_t x_t\le q\), producing \(\lambda=\mu-x\). Unlisted masses are zero.
In either problem, a permitted change succeeds exactly when \(S_\lambda(p)<S_\lambda(s)\) for every \(s\in\{0,1\}^m\setminus\{p\}\); ties do not count as success.

For each of these two mass-control problems, is it solvable in polynomial time or is it NP-hard? State running times in \(m\), \(\tau\), and \(L\).

For finite lists of indivisible voters, both addition and deletion control requiring a unique prescribed outcome are NP-hard even with unconditional ballots and binary issues ([Markakis–Papasotiropoulos](https://arxiv.org/pdf/2202.01660)). No result settling exactly these divisible-mass variants was located in the literature search.

Modeling choices made when packaging the task

  • Defined unconditional types by per-issue approval subsets, allowing empty subsets and approval of both binary values as the ballot definition permits.
  • Used unnormalized finite masses, preserving the discrete model's common units for registered voters, available voters, and quota.
  • Made the quota a nonnegative binary rational and allowed real-valued partial additions and deletions.
  • Treated addition and deletion as separate problems, matching the two discrete control variants.
  • Required at least one issue and positive initial total mass; retained the stated strict uniqueness condition without tie-breaking.
  • For addition, defined the joint support parameter as the number of distinct types in the union of current and available supports, with missing masses interpreted as zero.

Result

Both addition and deletion with divisible masses are polynomial-time solvable. Each reduces to an exact rational linear program with \(\tau+1\) variables and \(m+2\tau+3\) inequalities. The bit running time is \((m+\tau+L)^{O(1)}\).

The proof handles arbitrary real changes, strict uniqueness, empty approval sets, approval of both values, and deletion of the entire society.

1. Unique optimality reduces to one inequality per issue

For each supported type \(t\) and issue \(j\), define
\(d_{t,j}=\mathbf{1}\{1-p_j\notin A_{t,j}\}-\mathbf{1}\{p_j\notin A_{t,j}\}\).
Thus \(d_{t,j}\in\{-1,0,1\}\). More explicitly:

| Approval set \(A_{t,j}\) | \(d_{t,j}\) |
|---|---:|
| \(\{p_j\}\) | \(1\) |
| \(\{1-p_j\}\) | \(-1\) |
| \(\varnothing\) or \(\{0,1\}\) | \(0\) |

For a nonnegative measure \(\lambda\), define its margin on issue \(j\) by
\(g_j(\lambda)=\sum_t\lambda_t d_{t,j}\).

Lemma. The prescribed outcome \(p\) is the unique minimizer of \(S_\lambda\) if and only if \(g_j(\lambda)>0\) for every issue \(j\).

Proof. For any outcome \(s\), let \(J(s)=\{j:s_j\ne p_j\}\). Because issues are binary, \(s_j=1-p_j\) for every \(j\in J(s)\). Expanding the dissatisfaction scores and cancelling the unchanged coordinates gives
\(S_\lambda(s)-S_\lambda(p)=\sum_{j\in J(s)}\sum_t\lambda_t d_{t,j}=\sum_{j\in J(s)}g_j(\lambda)\).

If every margin is positive, this sum is positive whenever \(s\ne p\), since then \(J(s)\) is nonempty.

Conversely, for any issue \(j\), consider the outcome obtained by flipping only coordinate \(j\) of \(p\). Its score difference from \(p\) is exactly \(g_j(\lambda)\). Unique optimality therefore requires \(g_j(\lambda)>0\). This proves both directions.

2. Linear programs for addition and deletion

Let \(T\) be the union of the current and available supports for addition, and the current support for deletion. In each case \(|T|=\tau\), and unlisted masses are zero.

Define
\(b_j=\sum_{t\in T}\mu_t d_{t,j}\)
and
\(M=\sum_{t\in T}\mu_t>0\).

Since \(d_{t,j}\ge -1\) and \(\mu_t\ge0\), we have \(b_j\ge-M\).

Addition

Use real variables \(y_t\), for \(t\in T\), and a real margin variable \(\epsilon\). Maximize \(\epsilon\) subject to:

  • \(0\le y_t\le\nu_t\) for every \(t\in T\);
  • \(\sum_{t\in T}y_t\le q\);
  • \(b_j+\sum_{t\in T}d_{t,j}y_t\ge\epsilon\) for every issue \(j\);
  • \(-M\le\epsilon\le1\).

Denote its optimal value by \(\epsilon_{\mathrm{add}}^*\).

Deletion

Use real variables \(x_t\), for \(t\in T\), and a real margin variable \(\epsilon\). Maximize \(\epsilon\) subject to:

  • \(0\le x_t\le\mu_t\) for every \(t\in T\);
  • \(\sum_{t\in T}x_t\le q\);
  • \(b_j-\sum_{t\in T}d_{t,j}x_t\ge\epsilon\) for every issue \(j\);
  • \(-M\le\epsilon\le1\).

Denote its optimal value by \(\epsilon_{\mathrm{del}}^*\).

Both programs are feasible: choose zero change and \(\epsilon=-M\). Both feasible regions are closed and bounded, because all change variables have finite bounds and \(\epsilon\in[-M,1]\). Consequently, both maxima are attained.

3. Strict success is equivalent to a positive optimum

Proposition. Addition succeeds exactly when \(\epsilon_{\mathrm{add}}^*>0\), and deletion succeeds exactly when \(\epsilon_{\mathrm{del}}^*>0\).

Proof. For either operation, suppose a permitted change succeeds and produces \(\lambda\). By the lemma, all \(m\) margins are positive. Since \(m\) is finite and positive,
\(\eta=\min_{1\le j\le m}g_j(\lambda)>0\).

The change, together with \(\epsilon=\min\{1,\eta\}\), is feasible for its linear program. Thus its optimal value is positive.

Conversely, an optimal solution with \(\epsilon^*>0\) gives a permitted change whose resulting margins satisfy \(g_j(\lambda)\ge\epsilon^*>0\) for every issue. The lemma implies that \(p\) is the unique minimizer.

In particular, an optimal value of zero is rejected: ties do not count as success. Deleting all mass cannot create a false positive, since the zero measure has every margin equal to zero.

4. Exact computation and running time

We use the standard rational linear-programming theorem: a linear program with rational data can be solved exactly in time polynomial in its binary encoding length; when a finite optimum exists, an optimal rational solution and its value can be returned. This is the polynomial-time solvability theorem for linear programming originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here:

  • All coefficients and right-hand sides are rational.
  • Each program has \(\tau+1\) variables.
  • Each has \(2\tau\) variable-bound inequalities, one quota inequality, \(m\) margin inequalities, and two bounds on \(\epsilon\).
  • Feasibility and attainment of a finite optimum were proved above.

The exact rational optimum can therefore be compared with zero without a numerical tolerance.

The table \(d_{t,j}\) requires \(O(m\tau)\) ballot inspections. Computing the \(b_j\) requires \(O(m\tau)\) rational arithmetic operations, and computing \(M\) requires \(O(\tau)\).

For completeness, the constructed rational numbers have polynomial encoding length. Write the current masses as \(\mu_t=a_t/c_t\), with integer numerators and positive integer denominators. A common denominator is \(D_\mu=\prod_t c_t\). Its bit length is \(O(L)\), and
\(D_\mu b_j=\sum_t d_{t,j}a_t(D_\mu/c_t)\).
Each summand has \(O(L)\) bits, and adding at most \(\tau\) summands produces an integer with \(O(L+\log(\tau+1))\) bits. The same argument applies to \(M\).

Thus, even using a dense matrix representation, the LP encoding length is
\(B=O\bigl((m+\tau+1)(\tau+L+\log(\tau+1))\bigr)\).
Exact rational LP optimization consequently gives, for each problem, bit running time
\((m+\tau+L)^{O(1)}\).

A stronger arithmetic bound is also available. Every constraint-matrix entry belongs to \(\{-1,0,1\}\). [Tardos’s algorithm](https://pubsonline.informs.org/doi/10.1287/opre.34.2.250) therefore gives \((m+\tau)^{O(1)}\) arithmetic operations, independent of the magnitudes of the masses and quota, with polynomially bounded intermediate encoding lengths. If integer right-hand sides are required, multiply all right-hand sides and scale all variables by the product of the input denominators; this leaves the constraint matrix unchanged and preserves the sign of the optimal margin.

5. Relation to indivisible voters

The finite-voter hardness results concern indivisible choices; see Theorems 8 and 9 of [Markakis–Papasotiropoulos](https://arxiv.org/pdf/2202.01660). Here every amount within its allowed interval is permitted, so the linear programs describe the admissible changes exactly. No integrality restriction remains.
