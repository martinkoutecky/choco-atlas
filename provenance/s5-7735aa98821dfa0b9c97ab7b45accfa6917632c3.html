Proposition 1 — class: other

The continuous mirror question, as graded

Given a fixed facility set \(M\), rational costs \(c_k\ge 0\), and supported coverage types \(t\) with \(H_t\subseteq M\) and positive rational masses \(\mu_t\) summing to \(1\), where every facility has positive mass of types with \(H_t=\{k\}\), represent the full type-symmetric core. For charge rates \(q_t\ge 0\) per unit population mass, require total charge \(\sum_t\mu_tq_t=\sum_kc_k\) and, for every measurable coalition \(E\), require its charge \(\sum_t\lambda(E\cap T_t)q_t\) not to exceed the minimum cost of facilities covering every positive-mass type in \(E\); output the exact feasible set.

Packaged proof task (what the prover saw — nothing else)

Let \(M=\{1,\ldots,m\}\), with \(m\ge1\), be the given facilities, with binary rational costs \(c_k\ge0\). A society is given by its support: the list of \(\tau\) distinct nonempty coverage types \(H_t\subseteq M\), each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible coverage sets. Require \(\sum_{t:H_t=\{k\}}\mu_t>0\) for every \(k\in M\).
Realize the society as \([0,1]\) with Lebesgue measure \(\lambda\), partitioned into measurable type sets \(T_t\) of measures \(\mu_t\). For every measurable coalition \(E\), define \(C(E)=\min\{\sum_{k\in F}c_k:F\subseteq M,\ F\cap H_t\ne\varnothing\text{ whenever }\lambda(E\cap T_t)>0\}\); in particular, \(C(E)=0\) for null coalitions.
The type-symmetric core is \(K=\{q\in\mathbb R_{\ge0}^{\tau}:\sum_t\mu_tq_t=\sum_kc_k,\ \sum_t\lambda(E\cap T_t)q_t\le C(E)\text{ for every measurable }E\}\). The computational problem is to output an exact finite system of rational linear equalities and inequalities in \(q\) defining \(K\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Can this exact representation problem be solved in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite societies with every facility indispensable, the core consists exactly of nonnegative allocations charging multiply covered agents zero and assigning each facility's entire cost to agents covered only by that facility; it is always nonempty. [Source](https://mpra.ub.uni-muenchen.de/92659/1/MPRA_paper_92659.pdf).
No result settling this exact atomless representation problem was identified in the literature search.

Modeling choices made when packaging the task

  • Excluded empty coverage types, carrying over the requirement that every agent is covered.
  • Specified a Lebesgue atomless society partitioned into type sets, making measurable coalitions and their masses precise.
  • Interpreted 'represent the full feasible set' as outputting a finite rational linear description in the original charge-rate variables.
  • Treated the given facility set as part of the input, with variable size m, rather than a globally fixed constant.
  • Specified m at least one and defined L as total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The exact representation problem is polynomial-time solvable. Under the stated singleton-support assumption, the type-symmetric core contains exactly one vector.

1. Exact representation

Because the coverage types are distinct, for each facility \(k\in M\) there is a unique index \(s(k)\) such that \(H_{s(k)}=\{k\}\). The singleton-support assumption gives \(\mu_{s(k)}>0\).

The following rational linear system defines \(K\) exactly:

  • \(\mu_{s(k)}q_{s(k)}=c_k\) for every \(k\in M\).
  • \(q_t=0\) for every \(t\) with \(|H_t|\ge 2\).
  • \(q_t\ge 0\) for every \(t\in\{1,\ldots,\tau\}\).

Consequently, \(K=\{q^*\}\), where \(q^*_{s(k)}=c_k/\mu_{s(k)}\) and every multiply covered type has charge zero. This parallels the finite-society characterization in [Proposition 1 of the cited paper](https://mpra.ub.uni-muenchen.de/92659/1/MPRA_paper_92659.pdf). The proof below establishes the measurable-coalition statement directly.

2. Necessity

Write \(B=\sum_{j\in M}c_j\), and let \(q\in K\).

Fix \(k\in M\). The coalition \(T_{s(k)}\) has only coverage type \(\{k\}\). Every feasible cover therefore contains \(k\), and \(\{k\}\) itself is feasible. Since all facility costs are nonnegative,

\(C(T_{s(k)})=c_k.\)

Its core inequality yields

\(\mu_{s(k)}q_{s(k)}\le c_k.\)

Now consider the measurable coalition \(E_k=[0,1]\setminus T_{s(k)}\). For every \(j\ne k\), this coalition contains the entire positive-mass singleton type \(\{j\}\). Thus every feasible cover of \(E_k\) contains \(M\setminus\{k\}\), giving

\(C(E_k)\ge\sum_{j\ne k}c_j.\)

Conversely, \(M\setminus\{k\}\) covers \(E_k\): every active type has a nonempty coverage set different from \(\{k\}\), so it contains some facility other than \(k\). Hence

\(C(E_k)=\sum_{j\ne k}c_j=B-c_k.\)

This reasoning also covers \(m=1\): then \(E_k\) is null and its cost is zero.

Using budget balance, the core inequality for \(E_k\) becomes

\(B-\mu_{s(k)}q_{s(k)}\le B-c_k.\)

Therefore \(\mu_{s(k)}q_{s(k)}\ge c_k\). Combining both inequalities proves

\(\mu_{s(k)}q_{s(k)}=c_k\quad\text{for every }k\in M.\)

Subtracting these singleton charges from the budget equation gives

\(\sum_{t:\,|H_t|\ge 2}\mu_tq_t=0.\)

Every summand is nonnegative, and every \(\mu_t\) is strictly positive. Thus \(q_t=0\) for each multiply covered type. All equations in the proposed representation are necessary.

3. Sufficiency for every measurable coalition

Suppose \(q\) satisfies the proposed system. Its coordinates are nonnegative, and

\(\sum_t\mu_tq_t=\sum_{k\in M}\mu_{s(k)}q_{s(k)}=\sum_{k\in M}c_k.\)

Let \(E\subseteq[0,1]\) be any measurable coalition. Define

\(I(E)=\{k\in M:\lambda(E\cap T_{s(k)})>0\}.\)

Only singleton types have nonzero charges. Since \(\lambda(E\cap T_{s(k)})\le\mu_{s(k)}\), we obtain

\(\sum_t\lambda(E\cap T_t)q_t =\sum_{k\in I(E)}c_k\,\dfrac{\lambda(E\cap T_{s(k)})}{\mu_{s(k)}} \le\sum_{k\in I(E)}c_k.\)

Every feasible cover \(F\) of \(E\) must contain each \(k\in I(E)\), because \(E\) contains positive mass of coverage type \(\{k\}\). Nonnegativity of the facility costs therefore implies

\(\sum_{j\in F}c_j\ge\sum_{k\in I(E)}c_k.\)

Taking the minimum over feasible covers gives

\(C(E)\ge\sum_{k\in I(E)}c_k \ge\sum_t\lambda(E\cap T_t)q_t.\)

Thus every measurable-coalition inequality holds, including those for null coalitions. This proves sufficiency and completes the characterization.

4. Algorithm and bit complexity

Scan the support to identify the singleton indices \(s(k)\), then output the system above. There are exactly \(\tau\) equalities and \(\tau\) nonnegativity inequalities. Every coefficient is either an input rational or one of the constants zero and one; no coalition-cost optimization is required.

In a sparse encoding, the output length is \(O(L+\tau\log(\tau+1))\). A straightforward implementation, even locating singleton indices through repeated scans, has the conservative bit-time bound \(O((m+\tau)L^2)\). A dense matrix encoding adds \(O(\tau^2)\) output time and space. Both representations are polynomial in \(m,\tau,L\).
