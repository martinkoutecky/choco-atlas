The continuous mirror question, as graded

Given a society μ over finite types \(t\), each specifying a hierarchy \(h_t\) and request vector \(p_{t,r}\), per-capita supplies \(b_r\) for resource classes \(r\), and an initial rational allocation \(x\) with \(x_{t,r}\geq 0\) and \(\sum_t x_{t,r}=b_r\), output a feasible allocation \(x^*\) and a finite sequence of feasible allocations from \(x\) to \(x^*\). Each step transfers an amount \(\delta>0\) of one class \(r\) from type \(t\) to type \(u\), where either \(h_u\succeq h_t\) and \(p_{u,r}=1\), or \(h_t\succeq h_u\) and \(p_{v,r}=0\) for every type \(v\) with \(h_v\succeq h_t\). Require that in \(x^*\), each class is assigned only to highest-hierarchy requesters if any type requests it, and otherwise only to lowest-hierarchy types.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of its \(\tau\geq1\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) resource classes. Each type has a hierarchy rank \(h_t\in\{1,\ldots,\tau\}\), with larger ranks higher and ties permitted, and fixed requests \(p_{t,r}\in\{0,1\}\). Each class has positive binary rational per-capita supply \(b_r\).
An allocation \(y\) has nonnegative rational entries satisfying \(\sum_{t\in T}y_{t,r}=b_r\). Entries are aggregate quantities per unit society mass; the quantity per member of type \(t\) is \(y_{t,r}/\mu_t\), with no capacity constraints. A feasible initial allocation \(x\) is given.
A permitted step chooses distinct types \(t,u\), a class \(r\), and rational \(0<\delta\leq y_{t,r}\), subtracting \(\delta\) from \(y_{t,r}\) and adding it to \(y_{u,r}\), leaving other entries unchanged. It requires either \(h_u\geq h_t\) and \(p_{u,r}=1\), or \(h_t\geq h_u\) and \(p_{v,r}=0\) for every \(v\in T\) with \(h_v\geq h_t\).
Call an allocation good if each class with requesters is supported only on requesters of maximum hierarchy among its requesters, and each class without requesters is supported only on types of minimum hierarchy in \(T\); all tied eligible types are allowed.
The search problem asks for a good allocation \(x^*\) and a finite sequence of permitted steps from \(x\) to \(x^*\), allowing zero steps. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Can this search problem be solved in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finitely many agents and indivisible resources, every allocation reaches a good allocation through exactly \(\ell\) permitted single-resource transfers, where \(\ell\) counts its initially misplaced resources. [Verified discrete result](https://arxiv.org/pdf/1805.06864).
No published result settling the exact distribution-over-types search problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive rational type masses to sum to one, interpreting the society as a probability distribution.
  • Specified the hierarchy as a total preorder encoded by integer ranks, with larger ranks higher and ties permitted.
  • Specified requests as fixed binary values and required nonempty support and at least one resource class.
  • Required positive binary rational supplies, reflecting the presence of each resource in the discrete model.
  • Interpreted allocation entries as aggregate quantities per unit society mass, without per-member capacity constraints.
  • Required distinct source and destination types and rational transfer amounts bounded by the source's current allocation.
  • Allowed all tied highest-hierarchy requesters or tied lowest-hierarchy types as terminal recipients, without a tie-breaking rule.
  • Allowed a zero-step sequence when the initial allocation is already good and defined L as the total binary input length.

Result

The search problem is polynomial-time solvable. A good allocation and a permitted transfer sequence can be constructed in \(O(m\tau L^3)\) bit operations.

More precisely, let \(k\) be the number of initially positive entries whose types are ineligible for their resource classes. The construction uses exactly \(k\) steps, and every sequence reaching a good allocation requires at least \(k\) steps. In particular, \(k\leq m(\tau-1)\).

The proof is direct for the stated distribution-over-types model and does not require the [cited discrete result](https://arxiv.org/pdf/1805.06864).

1. Eligible types

For each class \(r\), define its requester set \(R_r=\{t\in T:p_{t,r}=1\}\).

If \(R_r\neq\varnothing\), let \(H_r=\max_{t\in R_r}h_t\) and define \(E_r=\{t\in R_r:h_t=H_r\}\).

If \(R_r=\varnothing\), let \(h_{\min}=\min_{t\in T}h_t\) and define \(E_r=\{t\in T:h_t=h_{\min}\}\).

Each \(E_r\) is nonempty because \(T\) is finite and nonempty. By the definition in the question, an allocation \(y\) is good precisely when \(y_{t,r}=0\) for every \(r\) and every \(t\notin E_r\).

Choose one representative \(s_r\in E_r\) for each class.

2. Direct-transfer lemma

Lemma. For every class \(r\), every \(t\notin E_r\), and every current allocation \(y\) with \(y_{t,r}>0\), transferring the entire quantity \(y_{t,r}\) from \(t\) to \(s_r\) is permitted.

Proof. The types are distinct because \(s_r\in E_r\) and \(t\notin E_r\). The amount \(\delta=y_{t,r}\) is rational and satisfies \(0<\delta\leq y_{t,r}\). It remains to verify a permission condition.

There are three cases.

  • There are requesters and \(h_t\leq H_r\). Since \(h_{s_r}=H_r\) and \(p_{s_r,r}=1\), we have \(h_{s_r}\geq h_t\). Thus the first permission condition holds.
  • There are requesters and \(h_t>H_r\). We have \(h_t\geq h_{s_r}\). Moreover, every \(v\in T\) with \(h_v\geq h_t\) has \(p_{v,r}=0\): otherwise such a \(v\) would be a requester with rank greater than \(H_r\), contradicting its definition. Thus the second permission condition holds.
  • There are no requesters. Since \(s_r\) has minimum rank, \(h_t\geq h_{s_r}\). Every type has \(p_{v,r}=0\), so the second permission condition again holds.

These cases exhaust all possibilities. \(\square\)

3. Construction and correctness

Start with \(y=x\). For each class \(r\), process every type \(t\notin E_r\). Whenever \(y_{t,r}>0\), append the step \((t,s_r,r,\delta)\), where \(\delta=y_{t,r}\), and execute it.

Each step is permitted by the lemma. It preserves the class total and nonnegativity: the donor entry becomes zero, while the recipient entry increases by the same amount. Hence every intermediate allocation remains feasible.

All recipients are eligible. Consequently, an ineligible entry receives no transfers and remains equal to its initial value until it is processed. Once processed, it remains zero.

After all classes have been processed, every ineligible entry is zero, so the resulting allocation \(x^*\) is good. Explicitly:

  • For \(t\notin E_r\), \(x^*_{t,r}=0\).
  • For \(t\in E_r\setminus\{s_r\}\), \(x^*_{t,r}=x_{t,r}\).
  • For the representative, \(x^*_{s_r,r}=x_{s_r,r}+\sum_{t\notin E_r}x_{t,r}\).

The masses \(\mu_t\) impose no additional restriction: allocations and transfers use aggregate quantities, and the problem specifies no capacity constraints.

4. Exact minimum number of steps

Define \(k=\left|\{(t,r):t\notin E_r,\ x_{t,r}>0\}\right|\).

The construction performs exactly one step for each such pair, hence exactly \(k\) steps.

Conversely, consider any permitted sequence ending at a good allocation. For each pair counted by \(k\), the coordinate begins positive and ends zero. It must therefore occur as a donor coordinate in at least one step. Indeed, if it never donates, its value can only stay unchanged or increase.

A single step has exactly one donor coordinate. Thus the \(k\) distinct coordinates require at least \(k\) steps. The construction is therefore optimal in sequence length.

Since each class has at least one eligible type, \(k\leq\sum_{r=1}^{m}(\tau-|E_r|)\leq m(\tau-1)\). If the initial allocation is already good, including every instance with \(\tau=1\), the construction returns zero steps.

5. Binary complexity

The eligible sets and representatives can be found using \(O(m\tau)\) rank comparisons and request inspections. The construction then uses \(O(m\tau)\) coordinate operations.

To bound exact arithmetic, write each input allocation entry as \(x_{t,r}=a_{t,r}/d_{t,r}\), with integer \(a_{t,r}\geq0\) and \(d_{t,r}\geq1\), and set \(D=\prod_{t,r}d_{t,r}\).

Because the total input length is \(L\), the binary length of \(D\) is \(O(L)\). Convert all entries to denominator \(D\). Every subsequent operation is then an integer addition or assignment to zero.

Every intermediate coordinate lies between zero and \(b_r\), by feasibility and nonnegativity. Its numerator over \(D\) is consequently at most \(Db_r\). Both \(D\) and each input supply \(b_r\) have \(O(L)\)-bit magnitude, so all these integer numerators have \(O(L)\) bits.

Using elementary integer arithmetic, forming \(D\) and converting all entries costs \(O(m\tau L^2)\) bit operations. The transfer updates cost \(O(m\tau L)\). There are \(O(m\tau)\) output rationals, each with \(O(L)\)-bit numerator and denominator. Even if reduced fractions are required, Euclidean reduction gives the conservative total bound \(O(m\tau L^3)\).

The output allocation and transfer sequence together have \(O(m\tau L)\) bits. Thus both construction time and output size are polynomial in the requested parameters.
