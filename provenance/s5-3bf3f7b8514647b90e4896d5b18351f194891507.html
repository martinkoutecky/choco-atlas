The continuous mirror question, as graded

Given a finite support \(T\) with rational masses \(\mu_t>0\), \(\sum_{t\in T}\mu_t=1\), per-unit endowments \(b_t\), valuations \(v_t\), a shared production matrix \(A\), and a feasible proposal \((x^*,u^*)\) with \(Ax^*\leq\sum_{t\in T}\mu_t b_t\) and \(u_t^*\leq v_t^\top x^*\), decide whether there exist masses \(q_t\in[0,\mu_t]\), not all zero, and a design \(y\geq0\) such that \(Ay\leq\sum_{t\in T}q_t b_t\) and \(v_t^\top y>u_t^*\) for every \(t\) with \(q_t>0\).

Deciding whether a blocking coalition exists is \(\mathrm{NP}\)-complete. Hardness holds even with \(k=1\), an all-ones production matrix, unit per-unit endowments, nonnegative valuations, and \(u_t^*=1\) for every type.

The reduction accounts for fractional participation, normalization of total mass, repeated types, and the required feasible incumbent.

2. Reduction from finite agents

We use the finite-agent hardness result stated in the question: blocking-coalition existence is \(\mathrm{NP}\)-hard for agents \(i\in N\), with \(n=|N|\), valuations \(w_i\in\mathbb Q_{\geq0}^m\), unit endowments, an all-ones production matrix, and feasible incumbent utilities equal to one. A finite coalition \(S\ne\varnothing\) blocks precisely when some \(z\in\mathbb R_{\geq0}^m\) satisfies

\(\displaystyle \sum_{j=1}^m z_j\leq |S|,\qquad w_i^\top z>1\quad(i\in S).\)

The feasibility promise and these restrictions are part of [Theorem 3.9 of the cited paper](https://arxiv.org/html/2506.05251v3#S3.SS2.SSS3).

First compute a rational feasible incumbent design \(\widehat x\) by solving the linear feasibility problem

\(\displaystyle \widehat x\geq0,\qquad \sum_{j=1}^m\widehat x_j\leq n,\qquad w_i^\top\widehat x\geq1\quad(i\in N).\)

The finite-instance promise makes this system feasible. Polynomial-time rational linear programming produces such a point with polynomial encoding length.

To ensure that the output lists actual distinct types, partition \(N\) into classes \(C_t\) of agents with identical valuation vectors. Write \(r_t=|C_t|\), and denote their common valuation by \(w_t\). Define the mass instance by

\(\displaystyle \mu_t=\frac{r_t}{n},\qquad b_t=1,\qquad v_t=nw_t,\qquad u_t^*=1,\qquad x^*=\frac{\widehat x}{n},\)

and let \(A\) be the all-ones row matrix.

Every input promise is satisfied:

  • Each mass is positive, and \(\sum_t\mu_t=\sum_t r_t/n=1\).
  • For every type, its individual feasible set is \(\{z\geq0:\sum_jz_j\leq1\}\), which is nonempty and bounded.
  • The incumbent satisfies

\(\displaystyle Ax^*=\frac{\sum_j\widehat x_j}{n}\leq1=\sum_t\mu_tb_t.\)

  • For every type,

\(\displaystyle v_t^\top x^*=w_t^\top\widehat x\geq1=u_t^*.\)

All numbers are rational with polynomial binary encoding length. The output has \(k=1\), the original number \(m\) of goods, and support size \(\tau\leq n\). Grouping identical valuations and constructing the output take polynomial time; computing \(\widehat x\) also takes polynomial time in the finite input dimensions and encoding length.

3. Proof of equivalence

Suppose first that a finite coalition \(S\) blocks using design \(z\). Set

\(\displaystyle q_t=\frac{|S\cap C_t|}{n},\qquad y=\frac zn.\)

Then \(0\leq q_t\leq r_t/n=\mu_t\), and \(\sum_tq_t=|S|/n>0\). Resource feasibility follows from

\(\displaystyle Ay=\frac{\sum_jz_j}{n}\leq\frac{|S|}{n}=\sum_tq_tb_t.\)

If \(q_t>0\), some agent \(i\in S\cap C_t\) participates. Since \(w_i=w_t\),

\(\displaystyle v_t^\top y=(nw_t)^\top(z/n)=w_i^\top z>1=u_t^*.\)

Thus the constructed mass instance has a blocking coalition.

Conversely, suppose masses \(q_t\) and design \(y\) block in the mass instance. Define

\(\displaystyle S=\bigcup_{t:q_t>0}C_t,\qquad z=ny.\)

The condition \(\sum_tq_t>0\) implies \(S\ne\varnothing\). Using resource feasibility and the upper bounds on the masses gives

\(\displaystyle \sum_jz_j=nAy\leq n\sum_tq_t\leq\sum_{t:q_t>0}r_t=|S|.\)

For every \(i\in S\), its class \(C_t\) has \(q_t>0\), and therefore

\(\displaystyle w_i^\top z=w_t^\top(ny)=v_t^\top y>1.\)

Hence \(S\) blocks in the finite instance.

This proves both directions. Fractional participation introduces no false positive: replacing each positively participating type by all finite agents of that type supplies enough resources, while every added agent has the same strictly improved utility. The reduction therefore proves \(\mathrm{NP}\)-hardness.

4. Membership in \(\mathrm{NP}\) and running times

Membership holds for the full problem, including signed endowments and valuations.

A certificate specifies a nonempty subset \(S\subseteq T\), intended to be exactly the positively participating types. The verifier solves the following rational linear program, with variables \(y\in\mathbb R^m\), \((q_t)_{t\in S}\), and \(\varepsilon\):

\(\displaystyle \text{maximize }\varepsilon,\)

subject to

\(\displaystyle y\geq0,\qquad 0\leq\varepsilon\leq1,\)

\(\displaystyle \varepsilon\leq q_t\leq\mu_t\quad(t\in S),\)

\(\displaystyle Ay\leq\sum_{t\in S}q_tb_t,\)

\(\displaystyle v_t^\top y\geq u_t^*+\varepsilon\quad(t\in S).\)

Masses outside \(S\) are set to zero. The verifier accepts exactly when the program is feasible and its optimal value is positive.

To justify this criterion, a blocking coalition with support \(S\) has finitely many positive masses and positive utility gaps. Consequently,

\(\displaystyle \varepsilon=\min\bigl(\{1\}\cup\{q_t:t\in S\}\cup\{v_t^\top y-u_t^*:t\in S\}\bigr)>0\)

makes its design and masses feasible for the program. Conversely, any feasible solution with \(\varepsilon>0\) gives positive participating masses and strict improvement for every participating type.

The program has \(m+|S|+1\) variables and \(O(m+k+|S|)\) constraints, with encoding length polynomial in \(m,\tau,k,L\). Exact rational linear programming therefore verifies the certificate in \(\operatorname{poly}(m,\tau,k,L)\) time. Since specifying \(S\) requires at most \(\tau\) bits, the problem belongs to \(\mathrm{NP}\).

Enumerating all nonempty supports also gives a deterministic algorithm running in \(O(2^\tau\operatorname{poly}(m,\tau,k,L))\). A polynomial-time algorithm in all four input parameters would imply \(\mathrm P=\mathrm{NP}\).
