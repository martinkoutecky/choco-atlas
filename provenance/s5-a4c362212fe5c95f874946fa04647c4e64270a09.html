The continuous mirror question, as graded

Given candidates \(A\) and a rational distribution \(\mu\) over a finite support \(T\) of strict-ranking types, decide whether there is a linear order \(\prec\) of \(A\) such that, for every \(t\in T\) and \(a\in A\), the upper contour set \(U_t(a)=\{b\in A:b\succeq_t a\}\) is contiguous in \(\prec\); return such an order or a forbidden subprofile.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a nonempty set of \(m\) candidates. A society is given by its support: a list \(T\) of \(\tau\) distinct strict-ranking types, each with positive binary-rational mass \(\mu(t)\), with \(\sum_{t\in T}\mu(t)=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
For each type, let \(\succ_t\) denote strict preference and define \(U_t(a)=\{a\}\cup\{b\in A:b\succ_t a\}\). An admissible axis is a linear order \(\prec\) of \(A\) in which every \(U_t(a)\) is contiguous.
A forbidden subprofile consists of restricted rankings witnessing either: three distinct types and three distinct candidates, with a different candidate ranked last by each type; or two distinct types \(s,t\) and four distinct candidates \(p,q,r,z\) satisfying \(r\succ_s q\succ_s p\), \(p\succ_t q\succ_t r\), \(z\succ_s q\), and \(z\succ_t q\).
The problem is to decide whether an admissible axis exists and return one if it does, or a forbidden subprofile otherwise.

Is this recognition problem in \(\mathrm{P}\), with the specified output computable in polynomial time in \(m,\tau,L\), or is its decision version \(\mathrm{NP}\)-hard?

For finite discrete profiles, an admissible axis exists exactly when neither forbidden pattern occurs ([Ballester–Haeringer](https://bse.eu/sites/default/files/working_paper_pdfs/273.pdf)); recognition on an axis is polynomial-time ([Escoffier–Spanjaard–Tydrichová](https://arxiv.org/abs/2004.13602)). No separate result for rational-mass societies was verified.

Modeling choices made when packaging the task

  • Specified positive rational masses summing to one, as required by a distribution over its positive-mass support.
  • Specified distinct ranking types, consistent with the discrete convention that identical preferences are consolidated.
  • Required a nonempty candidate set; allowed a single candidate because the characterization imposes no larger minimum.
  • Defined the previously unspecified forbidden-subprofile output using the two patterns in the anchor.
  • Defined L as the total input bit length and included polynomial-time construction of the requested output in the target.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The recognition problem is in \(\mathrm{P}\), and the required axis or forbidden subprofile can be computed in polynomial time in \(m,\tau,L\).

More explicitly, a consecutive-ones algorithm decides feasibility and constructs an axis in \(O(L+\tau m^2)\) word-RAM time. If no axis exists, the forbidden subprofile can be found by exhaustive search, giving an overall bound of \(O(L+\tau^2m^4)\). The rational masses require no arithmetic.

1. Reduction to a finite profile

Let \(P_T\) be the finite profile with one voter for each listed type \(t\in T\), whose preference is \(\succ_t\).

For any fixed axis \(\prec\), admissibility means precisely that \(U_t(a)\) is contiguous for every \(t\in T\) and \(a\in A\). These are exactly the same constraints for the society and for \(P_T\). Consequently, their sets of admissible axes coincide.

Likewise, a forbidden subprofile uses only rankings from the support, so it occurs in the society exactly when it occurs in \(P_T\). Every selected type has positive mass by hypothesis.

Thus the reduction simply discards the masses. It does not expand rational masses into voter multiplicities, and its profile has exactly \(\tau\) voters.

2. Matching admissibility to the finite characterization

For a strict ranking, call a triple a *valley* on an axis if \(x\prec y\prec z\), while both \(x\succ_t y\) and \(z\succ_t y\).

Lemma. All upper-contour sets of type \(t\) are contiguous if and only if its ranking has no valley.

Proof. Suppose there is a valley. Let \(a\) be the less preferred of \(x,z\). Then \(U_t(a)\) contains \(x,z\) but excludes \(y\), so it is not contiguous.

Conversely, if \(U_t(a)\) is not contiguous, there are \(x\prec y\prec z\) with \(x,z\in U_t(a)\) and \(y\notin U_t(a)\). Strictness gives \(x\succ_t y\) and \(z\succ_t y\), so this triple is a valley. \(\square\)

The absence of valleys is equivalent to the usual definition of strict single-peakedness. Indeed, let \(h\) be the unique most preferred candidate. If \(h\prec x\prec y\), then \(y\succ_t x\) would make \(h,x,y\) a valley, so \(x\succ_t y\). The same argument applies on the other side of \(h\). Conversely, preferences decreasing away from \(h\) cannot have a valley: for any \(x\prec y\prec z\), either \(y\prec h\), in which case \(y\succ_t x\), or \(h\prec y\), in which case \(y\succ_t z\), or \(y=h\).

We may therefore apply [Ballester–Haeringer, Theorem 1](https://bse.eu/sites/default/files/working_paper_pdfs/273.pdf) to \(P_T\): the candidate set and voter set are finite, and every preference is a complete strict ranking.

Their two contradictions match the requested patterns:

  • An \(\alpha\)-contradiction consists of a candidate subset having at least three different candidates that are last for some voters. Selecting three such candidates and their witnessing voters gives the requested three-candidate pattern. The voters are distinct because a strict ranking has a unique last candidate in a subset. The converse follows by taking the witnessing triple itself.
  • Their \(\beta\)-contradiction has rankings \(a\succ_s b\succ_s d\), \(d\succ_t b\succ_t a\), with \(c\succ_s b\) and \(c\succ_t b\). Setting \(a=r\), \(b=q\), \(d=p\), and \(c=z\) gives exactly the second requested pattern. Its opposing comparisons force the two types to be distinct.

Hence, if no admissible axis exists, at least one of the two specified forbidden subprofiles exists among the listed types.

3. Constructing an axis

Write each ranking as \(a_{t,1}\succ_t\cdots\succ_t a_{t,m}\). Define a binary matrix \(B\) with columns indexed by candidates and rows indexed by pairs \((t,k)\), where \(t\in T\) and \(1\leq k\leq m\), by

\(B_{(t,k),b}=1\quad\Longleftrightarrow\quad b\in\{a_{t,1},\ldots,a_{t,k}\}.\)

The support of row \((t,k)\) is exactly \(U_t(a_{t,k})\). Thus a column ordering has consecutive ones in every row if and only if it is an admissible axis. This is a direct equivalence with the definition in the question.

We use the constructive consecutive-ones theorem of [Booth–Lueker](https://www.cs.uoi.gr/~loukas/courses/grad/Algorithmic_Graph_Theory/index.files/Booth-Lueker-PQtrees.pdf): for a binary matrix with \(r\) rows, \(c\) columns, and \(f\) nonzero entries, its consecutive-ones feasibility can be tested in \(O(r+c+f)\) time. In the feasible case, the resulting PQ-tree represents the valid orderings; reading its leaves gives one such ordering. Their row/column convention can be transposed as needed.

Here the hypotheses hold with

\(r=\tau m,\qquad c=m,\qquad f=\tau\sum_{k=1}^{m}k=\tau m(m+1)/2.\)

Listing all row supports takes \(O(\tau m^2)\) time, so the algorithm decides feasibility and returns an admissible axis in \(O(L+\tau m^2)\) time, including reading the input.

4. Finding the specified forbidden output

If the consecutive-ones test rejects, construct rank tables \(\rho_t(a)\), with smaller values indicating greater preference. This takes \(O(\tau m)\) time.

Three-candidate search. For each unordered candidate triple, scan all \(\tau\) types and record one witnessing type for each candidate that occurs last in the restricted triple. If all three candidates occur last, return those three restricted rankings. The witnessing types are necessarily distinct. This search takes \(O(\tau m^3)\) time.

Four-candidate search. Enumerate every ordered pair of distinct types \((s,t)\) and every ordered quadruple of distinct candidates \((p,q,r,z)\). Test

\(\rho_s(r)<\rho_s(q)<\rho_s(p),\qquad \rho_t(p)<\rho_t(q)<\rho_t(r),\)

and

\(\rho_s(z)<\rho_s(q),\qquad \rho_t(z)<\rho_t(q).\)

Each test uses a constant number of rank comparisons. If it succeeds, return the two rankings restricted to those four candidates. This search takes \(O(\tau^2m^4)\) time.

The searches enumerate every possible requested witness. Section 2 guarantees that one succeeds whenever the consecutive-ones test rejects.

For completeness, both outputs certify impossibility directly. Admissibility is inherited by restricting candidates: a valley in the restricted axis would also be a valley in the original axis.

For the first pattern, the middle candidate of any axis on the triple is last for one witnessing type, creating a valley.

For the second pattern, \(p\) is last for \(s\) and \(r\) is last for \(t\) on the four candidates. Each must therefore be an endpoint. Up to reversing the axis, the only possibilities are \(p\prec q\prec z\prec r\) and \(p\prec z\prec q\prec r\). The first has a valley at \(q\) for \(t\), because \(p,z\succ_t q\); the second has a valley at \(q\) for \(s\), because \(z,r\succ_s q\).

5. Complexity and conclusion

Using candidate indices and standard word-RAM operations, the bounds are:

| Required computation | Running time |
|---|---:|
| Decision and axis construction | \(O(L+\tau m^2)\) |
| Forbidden subprofile after rejection | \(O(L+\tau m^3+\tau^2m^4)\) |
| Complete required output | \(O(L+\tau^2m^4)\) |

These bounds also imply polynomial bit complexity. Under the usual explicit encoding, \(m,\tau\leq L\), and all working indices occupy \(O(\log(L+2))\) bits. For example, directly simulating the indexed-memory computation by scanning its polynomially sized memory gives the conservative deterministic Turing-machine bound \(O((L+\tau^2m^4)^2\log(L+2))\).

No separate theorem for rational-mass societies is needed: the exact reduction to one voter per support type preserves both admissible axes and forbidden witnesses. The decision version is therefore in \(\mathrm{P}\); it could be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).
