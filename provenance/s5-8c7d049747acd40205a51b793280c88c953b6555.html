The continuous mirror question, as graded

Given candidates \(C\), ranking types \(T\subseteq\mathcal L(C)\), and rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), compute a linear order \(\rho\) minimizing \(D_\mu(\rho)=\sum_{t\in T}\mu_t\lvert\{\{a,b\}\subseteq C:\rho\text{ and }t\text{ disagree on }a,b\}\rvert\); equivalently, decide whether a designated candidate \(c^\star\) is first in some optimal ranking.

A society is given by its support: a list \(T\) of \(\tau\) distinct strict linear orders over \(C\), each with positive binary-rational mass \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
For a strict linear order \(\rho\), define \(D_\mu(\rho)=\sum_{t\in T}\mu_t d_{\mathrm{KT}}(\rho,t)\), using Kendall tau distance. The computational problem is to return any minimizing order; optimal ties require no prescribed tie-breaking.

Is finding an order minimizing \(D_\mu\) solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

Conclusion

Finding an order minimizing \(D_\mu\) is \(\mathrm{NP}\)-hard, already on instances with \(\tau\leq 7\). Consequently, a running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

Here, “binary-rational” means that the numerator and denominator are encoded in binary, as in the stated normalization of weighted Kemeny aggregation.

Reduction from seven-voter Kemeny aggregation

We use the given theorem that computing an optimal Kemeny ranking is \(\mathrm{NP}\)-hard for seven voters. This theorem concerns strict linear orders and the same Kendall tau objective; see the [seven-voter hardness result](https://www.dominik-peters.de/posters/kemeny.pdf).

Let such an instance consist of seven orders \(v_1,\ldots,v_7\) over \(C\). Its objective is
\[ K(\rho)=\sum_{i=1}^{7}d_{\mathrm{KT}}(\rho,v_i). \]
Kendall tau distance counts unordered candidate pairs whose relative order differs between its two arguments.

Let \(T\) contain precisely the distinct orders appearing among the seven votes. For each \(t\in T\), define
\[ k_t=\bigl|\{i:v_i=t\}\bigr|, \qquad \mu_t=\frac{k_t}{7}. \]
Then \(\tau=|T|\leq 7\), every mass is positive, and
\[ \sum_{t\in T}\mu_t=\frac{\sum_{t\in T}k_t}{7}=1. \]
Thus the construction satisfies every input requirement, including distinct support orders.

For every output order \(\rho\),
\[ D_\mu(\rho) =\sum_{t\in T}\frac{k_t}{7}d_{\mathrm{KT}}(\rho,t) =\frac{1}{7}\sum_{i=1}^{7}d_{\mathrm{KT}}(\rho,v_i) =\frac{K(\rho)}{7}. \]
Multiplication by a positive constant preserves all comparisons and ties. Hence the minimizing orders for the constructed instance are exactly the optimal rankings for the original instance.

After labeling candidates by integers, comparing and grouping seven orders takes \(O(m\log(m+1))\) bit operations. The constructed input has
\[ \tau\leq 7, \qquad L=O(m\log(m+1)), \]
because each mass has constant encoding length. An algorithm polynomial in \(m,\tau,L\) would therefore compute seven-voter Kemeny rankings in polynomial time. This proves the claimed hardness. Arbitrary optimal tie-breaking causes no difficulty: every returned minimizer solves the original instance.

Exact equivalence and arithmetic costs

The equivalence with binary-weighted Kemeny aggregation also holds for general support sizes.

For positive integer weights \(w_t\), let \(W=\sum_t w_t\) and set \(\mu_t=w_t/W\). Then
\[ D_\mu(\rho)=\frac{1}{W}\sum_t w_t d_{\mathrm{KT}}(\rho,t), \]
so normalization preserves precisely the minimizing orders. The binary length of \(W\), and the total size of the normalized instance, are polynomial in the weighted input length.

Conversely, write each input mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\), and define
\[ Q=\prod_{t\in T}b_t, \qquad w_t=a_t(Q/b_t). \]
These are positive integer weights satisfying
\[ \sum_t w_t=Q, \qquad Q D_\mu(\rho)=\sum_t w_t d_{\mathrm{KT}}(\rho,t). \]
The binary length of \(Q\) is \(O(L)\), since the denominator encodings together occupy at most \(L\) bits. Thus clearing denominators requires polynomial time and produces weights of polynomial encoding length; no voters need to be expanded.

For an explicit conservative bound, put
\[ B=L+\lceil 2\log_2(m+1)\rceil+3. \]
Using elementary integer arithmetic, denominator clearing and exact evaluation of one proposed order take
\[ O(\tau m^2 B^2) \]
bit operations: each distance can be counted by examining all candidate pairs, and every integer score is at most \(Q\binom{m}{2}\), with \(O(B)\) bits. Enumerating all orders therefore gives an exact algorithm in
\[ O(m!\,\tau m^2 B^2) \]
bit operations.

Finally, [Fitzsimmons–Hemaspaandra, Theorem 18](https://mathcs.holycross.edu/~zfitzsim/papers/Fitzsimmons-Hemaspaandra2019_Article_High-multiplicityElectionProbl.pdf) establishes \(\Delta_2^p\)-completeness of binary-weighted Kemeny winner membership. That is a separate decision problem. The direct reduction above establishes hardness of returning any minimizing order without imposing a tie-breaking rule.
