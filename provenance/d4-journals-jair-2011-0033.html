The continuous mirror question, as graded

Given candidates \(C\), rational masses \(\mu_i\) over \(\tau\) partial-order types \(O_i\), each with at most \(4\) undetermined pairs, and target \(c\), choose nonnegative masses \(x_{i,V}\) over linear extensions \(V\in E_i\) satisfying \(\sum_{V\in E_i}x_{i,V}=\mu_i\), and decide whether the maximum \(\delta\) satisfying \(\sum_{i,V}x_{i,V}\bigl(s_{\mathrm{Borda}}(V,c)-s_{\mathrm{Borda}}(V,a)\bigr)\ge\delta\) for every \(a\ne c\) is \(>0\) or \(\ge0\).

Packaged proof task (what the prover saw — nothing else)

Definitions

Let \(C\) be a candidate set, \(O_1,\ldots,O_\tau\) partial orders on \(C\), and \(\mu_1,\ldots,\mu_\tau\) nonnegative rational masses. Each \(O_i\) has at most \(4\) incomparable candidate pairs; let \(E_i\) be its linear extensions. Choose \(x_{i,V}\ge0\) for \(V\in E_i\) with \(\sum_{V\in E_i}x_{i,V}=\mu_i\). For \(a\in C\), let \(s_{\mathrm{Borda}}(V,a)=|C|-\operatorname{rank}_V(a)\), and let \(\delta^\star\) be the maximum \(\delta\) such that \(\sum_{i,V}x_{i,V}(s_{\mathrm{Borda}}(V,c)-s_{\mathrm{Borda}}(V,a))\ge\delta\) for every \(a\ne c\).

Target

Are the rational-mass Borda extension problems of deciding whether \(\delta^\star>0\), respectively whether \(\delta^\star\ge0\), solvable in polynomial time or NP-hard?

Nearest known results

For finite unweighted profiles, deciding whether a designated candidate is a possible unique winner or possible co-winner under Borda is NP-complete, even when each partial order has at most \(4\) undetermined pairs.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

Both problems are polynomial-time solvable. The rational-mass formulation permits each mass to be split among linear extensions, so it is a linear program with polynomially many variables.

1. Enumerating the linear extensions

Write \(n=|C|\), and assume \(c\in C\) and \(n\ge 2\). For each \(i\), let \(k_i\le 4\) be the number of unordered candidate pairs incomparable in \(O_i\).

A linear extension specifies an orientation of each of these \(k_i\) pairs. Its comparisons on all other pairs are already fixed by \(O_i\). Consequently, two distinct linear extensions cannot specify the same orientations, and hence \(|E_i|\le 2^{k_i}\le 16\).

This bound also gives a polynomial-time enumeration algorithm. Compute the comparisons implied by \(O_i\), and enumerate all \(2^{k_i}\) orientations of its incomparable pairs. For each choice, form the directed graph containing the fixed comparisons and the chosen orientations. It has exactly one directed edge between every pair of distinct candidates.

If this graph contains a directed cycle, the choice cannot describe a linear order. If it is acyclic, a topological ordering exists and respects every comparison. Because every pair is compared, that ordering is unique and is a linear extension of \(O_i\). Conversely, every linear extension occurs among these choices.

Thus all the sets \(E_i\) can be enumerated in polynomial time. Each is nonempty because every finite partial order admits a linear extension.

2. An explicit polynomial-size linear program

For every \(i\), \(V\in E_i\), and \(a\ne c\), compute the integer coefficient \(d_{i,V,a}=s_{\mathrm{Borda}}(V,c)-s_{\mathrm{Borda}}(V,a)\). Since Borda scores belong to \(\{0,\ldots,n-1\}\), we have \(|d_{i,V,a}|\le n-1\).

Consider the linear program with objective \(\max\delta\), subject to:

  • \(x_{i,V}\ge 0\) for every \(i\) and \(V\in E_i\);
  • \(\sum_{V\in E_i}x_{i,V}=\mu_i\) for every \(i\);
  • \(\sum_{i=1}^{\tau}\sum_{V\in E_i}d_{i,V,a}x_{i,V}\ge\delta\) for every \(a\ne c\).

These are exactly the choices and margin constraints in the question, so the optimum, if attained, equals \(\delta^\star\).

To verify feasibility and attainment, set \(M=\sum_{i=1}^{\tau}\mu_i\) and \(B=(n-1)M\). Choose one extension for each \(O_i\), assign its entire mass to that extension, and assign zero to the remaining extensions. This satisfies the mass constraints. For any mass allocation satisfying those constraints and any opponent \(a\),

\(\left|\sum_{i=1}^{\tau}\sum_{V\in E_i}d_{i,V,a}x_{i,V}\right|\le\sum_{i=1}^{\tau}\sum_{V\in E_i}(n-1)x_{i,V}=B.\)

Therefore \(\delta=-B\) is feasible. Moreover, because there is at least one opponent, every feasible solution satisfies \(\delta\le B\). We may impose \(-B\le\delta\le B\) without changing the optimum: all discarded feasible solutions have objective less than the already feasible value \(-B\).

The resulting feasible region is closed and bounded: in particular, \(0\le x_{i,V}\le\mu_i\). It is nonempty, so the continuous objective attains a maximum.

3. Exact decisions in polynomial time

The linear program has at most \(16\tau+1\) variables, \(\tau\) mass equalities, and \(n-1\) margin inequalities, in addition to variable bounds. Its margin coefficients are integers of absolute value at most \(n-1\); its remaining coefficients and right-hand sides are rational numbers of polynomial encoding length. In particular, forming \(M\) and \(B\) increases the binary encoding length by at most a polynomial in the input length.

Apply the standard polynomial-time theorem for rational linear programming: a rational linear program can be solved exactly in time polynomial in its binary encoding length, including obtaining its rational optimal value when the optimum is finite and attained. All these hypotheses have been verified above.

Compute that optimal value and compare it exactly with zero. This decides both \(\delta^\star>0\) and \(\delta^\star\ge 0\) in polynomial time. No numerical tolerance or guessed positive margin is needed.

The quoted NP-completeness result concerns indivisible, unweighted votes. Even when \(\mu_i=1\), the present formulation allows that unit mass to be distributed fractionally among different extensions. Thus the integer-choice hardness result does not establish hardness for this linear program.

4. Degenerate candidate set

If \(C=\{c\}\), there are no margin constraints, so the stated maximization is unbounded and has no finite maximum. Under the extended-value convention \(\delta^\star=+\infty\), both answers are yes. Otherwise, the definition needs the hypothesis \(n\ge 2\); the polynomial-time result above applies to every instance satisfying it.

Step-by-step verification

  • Bound on the number of linear extensions

Every pair of distinct candidates is either comparable in \(O_i\) or one of its \(k_i\) incomparable pairs. A linear extension must preserve every fixed comparison. Consequently, its orientations of the incomparable pairs determine all pairwise comparisons, and hence determine the entire linear order.

The claimed injection into the set of orientation choices is valid, yielding \(|E_i|\le 2^{k_i}\le 16\). The proof does not incorrectly assume that every orientation choice is consistent.

  • Enumeration algorithm

Computing the comparisons implied by a finite partial order is polynomial time under the ordinary explicit representation of candidates and order relations.

After orienting every incomparable pair, the graph has exactly one directed edge between each pair of distinct candidates. Here “comparisons” correctly refers to comparisons between distinct candidates, so reflexive relations are not included as graph loops.

A cyclic graph cannot represent a linear order. An acyclic graph admits a topological ordering; because every pair is compared, that ordering is unique. It respects the original partial order and is therefore a linear extension. Conversely, every linear extension supplies one of the enumerated orientation choices.

There are at most \(16\) choices per partial order, and all graph operations are polynomial time. Both completeness and running time are justified.

  • Linear-program formulation

The variables, nonnegativity constraints, mass equalities, and margin inequalities reproduce the task exactly. In particular, no integrality restriction is imposed or needed: the task expressly permits splitting mass.

The coefficient bound \(|d_{i,V,a}|\le n-1\) follows directly from the stated Borda score range. The variable \(\delta\) is unrestricted until the later explicit bounds are imposed.

  • Feasibility and margin bounds

Every finite partial order has a linear extension, so assigning each entire mass to one extension satisfies all mass constraints, including when some masses are zero.

For any feasible mass allocation, the displayed absolute-value estimate is valid by the triangle inequality, nonnegativity, and the mass equalities. Its final value is exactly \(B=(n-1)\sum_i\mu_i\).

Adding \(-B\le\delta\le B\) preserves the optimal objective value: the upper bound is already implied, and solutions removed by the lower bound have objective below an available feasible value.

Every allocation variable satisfies \(0\le x_{i,V}\le\mu_i\). The resulting region is nonempty, closed, and bounded in finite-dimensional Euclidean space, hence compact. The linear objective therefore attains its maximum. This establishes the required finite, attained optimum.
