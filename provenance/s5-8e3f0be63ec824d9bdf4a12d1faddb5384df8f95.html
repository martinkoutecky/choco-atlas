The continuous mirror question, as graded

Given a finite state set \(X\) and a distribution \(\mu\) over reflexive, acyclic preference relations \(Q_t\), form \(R_\mu=\bigcap_{t:\mu_t>0}Q_t\). Compute a reflexive, connected, acyclic relation \(R'\) extending \(R_\mu\).

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a nonempty finite state set, with \(m=|X|\). A society is given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
Each type specifies a reflexive binary relation \(Q_t\subseteq X\times X\), encoded by its Boolean matrix. Define \(P(Q)=\{(x,y)\in Q:(y,x)\notin Q\}\). A relation is acyclic when its asymmetric part has no directed cycle; every \(Q_t\) is required to be acyclic. Symmetric comparisons are permitted.
Set \(R_\mu=\bigcap_{t:\mu_t>0}Q_t\). A relation \(R'\) extends \(R_\mu\) when \(R_\mu\subseteq R'\) and \(P(R_\mu)\subseteq P(R')\); these inclusions need not be strict. Connectedness means that every distinct pair is related in at least one direction.
The problem is to compute a reflexive, connected, acyclic extension \(R'\), or report that none exists.

Can this feasibility-and-construction problem be solved in polynomial time in \(m,\tau,L\), or is deciding whether such an extension exists NP-hard?

For finite binary relations, a reflexive, connected, acyclic extension exists exactly when the original relation is acyclic. [Lahiri (2009)](https://mpra.ub.uni-muenchen.de/13687/1/Acyclic_Social_Welfare.pdf)
No separate complexity result for the specified distribution-input problem was verified.

Modeling choices made when packaging the task

  • Required the finite state set to be nonempty, as in the discrete model.
  • Normalized the positive binary rational masses to sum to one, interpreting the stated distribution as a probability distribution.
  • Specified explicit Boolean-matrix encodings of type relations and defined L as total input bit length.
  • Used acyclicity of the asymmetric part, permitting symmetric comparisons, rather than acyclicity of the entire relation.
  • Required extension to preserve both the relation and its asymmetric part, with non-strict inclusions.
  • Allowed reporting nonexistence: intersections of relations with acyclic asymmetric parts need not themselves have acyclic asymmetric parts, so the stated type assumptions do not guarantee a feasible output.

Result

The feasibility-and-construction problem is polynomial-time solvable. Compute \(R_\mu\), test whether \(P(R_\mu)\) contains a directed cycle, and, if it does not, add both directions for every incomparable pair.

The positive masses affect neither feasibility nor the construction: every listed type participates in the intersection.

1. A constructive extension criterion

Let \(R\) be any reflexive relation on the finite set \(X\). Define its incomparable pairs by

\(N(R)=\{(x,y)\in X\times X:(x,y)\notin R\text{ and }(y,x)\notin R\}\),

and set

\(\widehat R=R\cup N(R)\).

We claim that \(\widehat R\) is reflexive and connected, contains \(R\), and satisfies \(P(\widehat R)=P(R)\).

Reflexivity and containment follow from \(R\subseteq\widehat R\). For distinct \(x,y\), either at least one direction already belongs to \(R\), or both directions belong to \(N(R)\). Thus \(\widehat R\) is connected.

To verify the equality of asymmetric parts, consider each unordered pair of distinct states:

  • If neither direction belongs to \(R\), both are added, so neither becomes asymmetric.
  • If exactly one direction belongs to \(R\), neither direction belongs to \(N(R)\), so the existing asymmetric comparison is preserved.
  • If both directions belong to \(R\), both remain present and neither is asymmetric.

Diagonal pairs are never asymmetric. Therefore \(P(\widehat R)=P(R)\).

Consequently, if \(R\) is acyclic, then \(\widehat R\) is an acyclic extension satisfying both required inclusions.

Conversely, suppose an acyclic extension \(R'\) exists. Since \(P(R)\subseteq P(R')\), any directed cycle in \(P(R)\) would also be a directed cycle in \(P(R')\), contradicting acyclicity. Hence:

\(R\text{ admits a reflexive, connected, acyclic extension}\quad\Longleftrightarrow\quad P(R)\text{ is acyclic}.\)

This proves the criterion directly, including the construction. It agrees with Proposition 1 of [Lahiri (2009)](https://mpra.ub.uni-muenchen.de/13687/1/Acyclic_Social_Welfare.pdf).

2. Algorithm and correctness

Because all listed masses are positive,

\(R_\mu=\bigcap_{t=1}^{\tau}Q_t.\)

Its Boolean matrix is obtained by taking the conjunction of the corresponding entries of all input matrices. It is reflexive because every \(Q_t\) is reflexive.

Construct the directed graph \(G\) on \(X\) whose arcs are precisely

\(P(R_\mu)=\{(x,y):R_\mu(x,y)=1\text{ and }R_\mu(y,x)=0\}.\)

Test \(G\) for a directed cycle by repeatedly removing a vertex of indegree zero, updating the remaining indegrees.

This test is correct for the following reasons. A directed cycle prevents any of its vertices from being removed first, because each has an incoming arc from another vertex on that cycle. Conversely, if removal stops with vertices remaining, every remaining vertex has a remaining predecessor. Repeatedly choosing predecessors in a finite graph eventually repeats a vertex, producing a directed cycle.

The algorithm therefore has two outcomes:

  • If vertices remain, report that no extension exists. The cycle just established and the necessary direction of the criterion prove this answer.
  • If all vertices are removed, output

\(R'=R_\mu\cup N(R_\mu)\).
The sufficient direction of the criterion proves that this output is reflexive, connected, acyclic, and satisfies
\(R_\mu\subseteq R'\) and \(P(R_\mu)\subseteq P(R')\).

3. Complexity

Computing the intersection requires \(\mathcal O(\tau m^2)\) Boolean operations. Forming the asymmetric graph, testing it for cycles, and constructing the output each require \(\mathcal O(m^2)\) time using matrix scans and adjacency lists.

Including reading the input, the total running time is \(\mathcal O(L+\tau m^2)\) in the usual RAM model. The bit complexity is polynomial as well: no arithmetic on the rational masses is needed, and all indices and graph counters have \(\mathcal O(\log(L+1))\) bits.

Thus both feasibility and construction satisfy the requested polynomial bound.

4. Individual acyclicity does not guarantee feasibility

The cycle test is necessary even under the stated input promises.

Let \(X=\{a,b,c\}\), let \(\Delta=\{(x,x):x\in X\}\), and define

\(C=\{(a,b),(b,c),(c,a)\}\),

\(Q_1=\Delta\cup C\cup\{(b,a),(c,b)\}\),

\(Q_2=\Delta\cup C\cup\{(a,c)\}\).

Assign both types mass \(\frac12\). Their asymmetric parts are

\(P(Q_1)=\{(c,a)\},\qquad P(Q_2)=\{(a,b),(b,c)\}.\)

Both are acyclic. Nevertheless,

\(R_\mu=Q_1\cap Q_2=\Delta\cup C,\qquad P(R_\mu)=C,\)

which contains the directed cycle \(a\to b\to c\to a\). Hence this valid society has no required extension.

This example rules out automatic feasibility; it does not affect the polynomial-time algorithm above.
