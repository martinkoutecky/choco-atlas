The continuous mirror question, as graded

Given a finite alternative set \(X\), respondent classes \(t\) with rational masses \(\mu_t\), fixed rankings \(\succO_t,\succeqN_t,\succeqH_t\), and partial full-horizon data \(\mathcal D^F_t\), let \(P_t=\POH_t\cup R(\mathcal D^F_t)\). Given aggregate choice shares \(q_{S,x}\) for menus \(S\) in a finite set \(\mathcal Q\), decide whether there are nonnegative masses \(z_{t,R}\), indexed by \(R\in\operatorname{LE}(\operatorname{tc}(P_t))\), such that \(\sum_R z_{t,R}=\mu_t\) for each \(t\), \(\succO_t\in\operatorname{LE}(\PNH_t)\) for each \(t\), and \(\sum_t\sum_{R:\topc_R(S)=x}z_{t,R}=q_{S,x}\) for every \(S\in\mathcal Q\) and \(x\in S\).

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a finite alternative set with \(m=|X|\ge2\). A society is given by its support: a list of \(\tau\ge1\) respondent types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible rankings.
Each type supplies a strict linear ordinary ranking \(\succ_t^O\), weak consequence orders \(\succeq_t^N,\succeq_t^H\) (ties allowed), and a finite dataset \(\mathcal D_t^F\) of observations \((S,f)\) with \(\varnothing\ne S\subseteq X\) and \(f\in S\). Superscripts \(N,H\) on strict comparisons denote the strict parts of these weak orders.
Define \(xP_t^{N,H}y\) iff \(x\succeq_t^Ny\), \(x\succeq_t^Hy\), and \(x\succ_t^Ny\) or \(x\succ_t^Hy\); define \(xP_t^{O,H}y\) iff \(x\succ_t^Oy\) and \(x\succeq_t^Hy\).
Let \(R(\mathcal D_t^F)=\{(f,y):(S,f)\in\mathcal D_t^F,\ y\in S\setminus\{f\}\}\) and \(P_t=P_t^{O,H}\cup R(\mathcal D_t^F)\). Let \(\operatorname{tc}\) denote transitive closure and \(\operatorname{LE}(A)\) the strict linear orders containing all comparisons in \(A\), with no such orders when \(A\) is cyclic. Write \(\operatorname{top}_R(S)\) for the unique best element of \(S\) under \(R\).
Input also contains an explicitly listed finite family \(\mathcal Q\) of nonempty menus and binary-rational shares \(q_{S,x}\ge0\), satisfying \(\sum_{x\in S}q_{S,x}=1\) for each \(S\in\mathcal Q\). All rankings, datasets, and menus are explicitly encoded; let \(L\) be the total input bit length and \(d=\sum_t|\mathcal D_t^F|\).
The feasibility problem asks whether \(\succ_t^O\in\operatorname{LE}(P_t^{N,H})\) for every type and there exist nonnegative real masses \(z_{t,R}\), indexed by \(R\in\operatorname{LE}(\operatorname{tc}(P_t))\), satisfying \(\sum_Rz_{t,R}=\mu_t\) for every \(t\) and \(\sum_t\sum_{R:\operatorname{top}_R(S)=x}z_{t,R}=q_{S,x}\) for every \(S\in\mathcal Q\), \(x\in S\).

Is this feasibility problem solvable in polynomial time in \(m,\tau,L,|\mathcal Q|,d\), or is it NP-hard?

For deterministic individual observations, rationalizability is equivalent to ordinary dominance compatibility and acyclicity of the augmented protected relation; admissible full-horizon rankings are exactly its linear extensions. These conditions are polynomial-time checkable. [Source](https://arxiv.org/html/2608.23781v1)
For stochastic consumer demand on commodity budgets, computing the exact random-utility rationalizability test statistic is NP-hard; this concerns a different observation domain and does not classify the feasibility problem above. [Source](https://onlinelibrary.wiley.com/doi/full/10.3982/ECTA17605)

Modeling choices made when packaging the task

  • Normalized positive respondent masses to sum to one and interpreted aggregate choice shares as unconditional population shares, summing to one on each menu.
  • Carried over the alternative-set restriction of at least two alternatives and required every observed or aggregate menu to be nonempty, with observed choices belonging to their menus.
  • Specified ordinary rankings as strict linear orders and consequence rankings as weak orders permitting ties, following the deterministic definitions.
  • Interpreted each type's partial observations as restrictions applying to every full-horizon ranking receiving positive mass within that type.
  • Allowed nonnegative real allocation masses and treated cyclic augmented relations as having no admissible linear extensions.

Result

The feasibility problem is \(\mathrm{NP}\)-complete under polynomial-time many-one reductions. Hardness holds even with:

  • One respondent type, with mass \(\mu_1=1\).
  • No individual observations, so \(d=0\).
  • Empty protected and dominance relations.
  • Menus of size at most three.
  • All observed shares strictly positive and belonging to \(\{1/4,1/2,3/4\}\).

In particular, the reduction uses dyadic rationals, so it applies even if “binary-rational” is interpreted as requiring dyadic inputs.

1. Source problem and unrestricted admissible rankings

We reduce from proper graph four-colorability. A proper four-coloring of a finite simple graph \(G=(V,E)\) is a map \(\kappa:V\to\{0,1,2,3\}\) assigning different colors to adjacent vertices.

This problem is \(\mathrm{NP}\)-hard: graph three-colorability is \(\mathrm{NP}\)-complete, and adjoining one new vertex adjacent to every original vertex produces a four-colorable graph exactly when the original graph is three-colorable. Indeed, the new vertex’s color is unavailable to every original vertex. The source hardness theorem is established in [Garey, Johnson, and Stockmeyer, *Some simplified NP-complete graph problems*](https://doi.org/10.1016/0304-3975(76)90059-1).

Let \(G=(V,E)\) have \(n\ge1\) vertices. Introduce one anchor alternative \(b\) and four alternatives for each vertex:

\(X=\{b\}\cup\{a_{v,c}:v\in V,\ c\in\{0,1,2,3\}\}.\)

Thus \(m=4n+1\).

Use one respondent type of mass \(1\). Choose any strict ordinary ranking \(\succ^O\). Let \(\succ^N=\succ^O\), and let \(\succ^H\) be its reverse. Set \(\mathcal D^F=\varnothing\).

For distinct alternatives, their \(N\)- and \(H\)-comparisons point in opposite directions. Consequently, \(P^{N,H}=\varnothing\), and ordinary dominance compatibility holds. Also, whenever \(x\succ^Oy\), we have \(y\succ^Hx\), so \(P^{O,H}=\varnothing\). Therefore \(P=\varnothing\), and every strict linear order on \(X\) is admissible.

2. Construction of the observed menus

Include precisely the following menus and shares.

| Index | Menu | Required shares |
|---|---|---|
| Every \(v\in V\) and \(c\in\{0,1,2,3\}\) | \(\{b,a_{v,c}\}\) | \(q_b=3/4,\quad q_{a_{v,c}}=1/4\) |
| Every \(v\in V\) and distinct colors \(c<e\) | \(\{b,a_{v,c},a_{v,e}\}\) | \(q_b=1/2,\quad q_{a_{v,c}}=q_{a_{v,e}}=1/4\) |
| Every edge \(\{u,v\}\in E\) and color \(c\) | \(\{b,a_{u,c},a_{v,c}\}\) | \(q_b=1/2,\quad q_{a_{u,c}}=q_{a_{v,c}}=1/4\) |

Here the subscripts in the last column refer to the menu in that row.

All shares are positive dyadic rationals and sum to \(1\) on each menu. Because the graph is simple and all alternative labels are distinct, these menus are distinct. Their number is \(10n+4|E|\).

The alternatives, rankings, menus, and shares can all be explicitly encoded in polynomial time.

3. Feasibility implies a proper four-coloring

Suppose the constructed instance is feasible. Its masses define a probability distribution on strict rankings \(R\), since there is one type of mass \(1\).

For each vertex-color pair, define the event

\(A_{v,c}=\{R:a_{v,c}\succ_R b\}.\)

The binary-menu observations give \(\Pr(A_{v,c})=1/4\).

Consider any constructed triple menu \(\{b,x,y\}\). Write \(A_x=\{R:x\succ_R b\}\) and \(A_y=\{R:y\succ_R b\}\). Under a strict ranking, \(b\) wins this menu exactly when neither event occurs. Hence

\(\Pr(A_x\cup A_y)=1-\Pr(\operatorname{top}_R(\{b,x,y\})=b)=1/2.\)

Both alternatives have binary winning probabilities \(1/4\). Inclusion-exclusion therefore gives

\(\Pr(A_x\cap A_y)=\Pr(A_x)+\Pr(A_y)-\Pr(A_x\cup A_y)=1/4+1/4-1/2=0.\)

Because all ranking masses are nonnegative, no ranking with positive mass can put both \(x\) and \(y\) above \(b\).

Apply this first to the triples involving two colors of the same vertex. Every positive-mass ranking puts at most one of \(a_{v,0},a_{v,1},a_{v,2},a_{v,3}\) above \(b\).

Let

\(N_v(R)=\sum_{c=0}^{3}\mathbf 1_{A_{v,c}}(R).\)

On every positive-mass ranking, \(N_v(R)\le1\), while the binary shares imply

\(\mathbb E[N_v]=\sum_{c=0}^{3}\Pr(A_{v,c})=1.\)

Thus every positive-mass ranking has \(N_v(R)=1\). Explicitly, the expectation of the nonnegative quantity \(1-N_v\), restricted to the distribution’s support, is zero; it must vanish at every ranking with positive mass.

Choose any positive-mass ranking \(R\), which exists because the masses sum to \(1\). Define \(\kappa_R(v)\) as the unique color \(c\) for which \(a_{v,c}\succ_R b\).

For each edge \(\{u,v\}\) and color \(c\), the corresponding edge triple prohibits both \(a_{u,c}\) and \(a_{v,c}\) from lying above \(b\) in this ranking. Therefore \(\kappa_R(u)\ne\kappa_R(v)\).

So \(\kappa_R\) is a proper four-coloring of \(G\).

4. A proper four-coloring implies feasibility

Conversely, suppose \(G\) has a proper four-coloring \(\kappa:V\to\{0,1,2,3\}\).

For each \(s\in\{0,1,2,3\}\), define the shifted coloring

\(\kappa_s(v)=(\kappa(v)+s)\bmod 4.\)

Each shifted coloring remains proper. Construct a strict ranking \(R_s\) by placing:

  • All alternatives \(a_{v,\kappa_s(v)}\) above \(b\).
  • The anchor \(b\) next.
  • All remaining alternatives below \(b\).

Within the first and third groups, use any fixed ordering. Every \(R_s\) is admissible because the protected relation is empty.

Assign mass \(1/4\) to each of these four rankings, and zero elsewhere.

For each \(v,c\), exactly one shift satisfies \(\kappa_s(v)=c\). Thus \(a_{v,c}\) lies above \(b\) with probability \(1/4\), giving the required binary shares.

In a same-vertex triple \(\{b,a_{v,c},a_{v,e}\}\), the two nonanchor alternatives never lie above \(b\) together, and each individually lies above it with probability \(1/4\).

The same statements hold for an edge triple \(\{b,a_{u,c},a_{v,c}\}\): properness of every shifted coloring prevents both endpoints from having color \(c\).

For either kind of triple, each nonanchor alternative wins exactly when it lies above \(b\), so each wins with probability \(1/4\). The anchor wins the remaining probability \(1/2\).

All observed shares are therefore satisfied. This completes both directions of the reduction and proves \(\mathrm{NP}\)-hardness.

5. Membership in \(\mathrm{NP}\)

It remains to justify that feasibility has polynomial-size certificates despite the potentially factorial number of rankings.

For a general instance, put

\(K=\tau+\sum_{S\in\mathcal Q}|S|.\)

After checking ordinary dominance compatibility, write the mass constraints as \(Az=\beta,\ z\ge0\). There is one column for each admissible pair \((t,R)\). The column has:

  • A \(1\) in type \(t\)’s mass row and \(0\) in other type rows.
  • A \(1\) in menu row \((S,x)\) exactly when \(\operatorname{top}_R(S)=x\).

Thus \(A\) has \(K\) rows and entries in \(\{0,1\}\). The vector \(\beta\) consists of the input masses and shares.

Sparse feasible support

Suppose a feasible solution exists. Choose one with the fewest positive coordinates.

Its positive columns must be linearly independent. Otherwise, a nonzero dependence vector \(h\) on those columns satisfies \(Ah=0\). Reverse its sign if necessary so that some coordinate is positive, and set

\(\varepsilon=\min_{h_j>0}z_j/h_j.\)

Replacing the supported weights by \(z-\varepsilon h\) preserves all equalities and nonnegativity, and makes at least one positive coordinate zero. This contradicts minimality.

Consequently, some feasible solution uses \(r\le K\) columns.

Polynomial bit length

Select \(r\) rows on which these independent columns form an invertible integer matrix \(B\). Their weights \(w\) satisfy \(Bw=\beta'\), where \(\beta'\) contains the selected entries of \(\beta\).

Let \(D\) be the product of all denominators in \(\beta\). Its binary length is \(O(L)\). Every entry of \(D\beta'\) is an integer between \(0\) and \(D\).

By Cramer’s rule,

\(w_j=\det(B_j(D\beta'))/(D\det B),\)

where \(B_j(D\beta')\) replaces column \(j\) of \(B\) by \(D\beta'\).

Hadamard’s inequality gives

\(|\det B|\le r^{r/2},\qquad |\det(B_j(D\beta'))|\le D r^{r/2}.\)

Thus each weight has a rational representation of bit length \(O(L+r\log r)\).

A certificate therefore lists at most \(K\) type-ranking pairs and their rational weights. A verifier checks each ranking, its protected comparisons, ordinary dominance compatibility, and every mass equality using exact rational arithmetic. Checking the original protected comparisons suffices: a transitive linear order containing \(P_t\) also contains \(\operatorname{tc}(P_t)\).

Because \(K\le\tau+m|\mathcal Q|\), certificate size and verification time are polynomial in the stated parameters. Hence the problem belongs to \(\mathrm{NP}\).

Conclusion

The problem is \(\mathrm{NP}\)-complete, even in the restricted setting proved above. A polynomial-time algorithm in the stated parameters would therefore imply \(\mathrm P=\mathrm{NP}\).
