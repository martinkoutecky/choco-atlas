The continuous mirror question, as graded

Given \(s\in[1/2,1)\), \(D>0\), and a distribution \(\mu\) over finitely many types \((a_i,d_i)\) with binary-rational coordinates and masses, compute the amended pair \((s',D')\). Apply the \(h\)-rule to threshold ideals \(a_i\): raise to the maximal \(r>s\) with \(\mu(a\ge r)>r\), or lower to the minimal \(r<s\) with \(\mu(a\le r)>s\), retaining \(s\) if neither update applies; promise that any required extremum exists. For the timeout, let \(\rho=2s-1\); according to whether the weighted median of \(d_i\) lies above or below \(D\), remove mass \(\rho\) from the corresponding upper or lower tail and use the median of the remaining mass if it moves in that direction, otherwise retaining \(D\). Assume the relevant medians are unique.

All coordinates and the prevailing values \(s\in[1/2,1)\), \(D>0\) are binary rationals. Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. There is no candidate parameter \(m\); the type dimension is fixed at two.
Define \(R_+=\{r\in(s,1):\mu(a\ge r)>r\}\) and \(R_-=\{r\in[1/2,s):\mu(a\le r)>s\}\). Set \(s'=\max R_+\) if \(R_+\ne\varnothing\), otherwise \(s'=\min R_-\) if \(R_-\ne\varnothing\), and otherwise \(s'=s\). Promise that every nonempty update set has the required attained extremum.

Result

The exact amended pair \((s',D')\) is computable in deterministic polynomial time in \(\tau\) and \(L\) on the promised inputs.

The proof below uses only the stated mass-based rules. The cited [constitutional-consensus paper](https://arxiv.org/html/2505.19216v5) and [Suppress Outer paper](https://www.ijcai.org/proceedings/2019/0081.pdf) provide background; no protocol-correctness or Sybil-resilience theorem is needed for this complexity classification.

1. Computing the threshold amendment

Write the input masses as \(w_i>0\), so that \(\sum_i w_i=1\). Aggregate equal threshold coordinates and sort the resulting marginal:

\(b_1<\cdots<b_k\), with masses \(u_1,\ldots,u_k>0\).

Define prefix and suffix masses by

\(F_j=\sum_{\ell=1}^{j}u_\ell\), and \(H_j=\sum_{\ell=j}^{k}u_\ell\).

Thus \(F_j=\mu(a\le b_j)\) and \(H_j=\mu(a\ge b_j)\).

Upward amendment

Lemma. If \(R_+\) has an attained maximum, that maximum is a threshold support value.

Proof. Let \(r_*=\max R_+\), and suppose \(r_*\) is not a support value. Because the support is finite, there is an \(\varepsilon>0\) such that \(r_*+\varepsilon<1\) and there are no threshold support values in \([r_*,r_*+\varepsilon]\). Consequently,

\(\mu(a\ge r_*+\varepsilon)=\mu(a\ge r_*)\).

Since \(r_*\in R_+\), we have \(\mu(a\ge r_*)>r_*\). By decreasing \(\varepsilon\) if necessary, we can also ensure

\(r_*+\varepsilon<\mu(a\ge r_*)\).

Then \(r_*+\varepsilon\in R_+\), contradicting maximality. \(\square\)

Form the finite candidate set

\(J_+=\{j:b_j>s\text{ and }H_j>b_j\}\).

Every candidate value \(b_j\), for \(j\in J_+\), belongs to \(R_+\). Conversely, if \(R_+\) is nonempty, the attainment promise and the lemma imply that its maximum is one of these candidates. Therefore, on promised inputs:

  • \(R_+\) is nonempty exactly when \(J_+\) is nonempty.
  • If \(J_+\) is nonempty, then \(s'=\max_{j\in J_+}b_j\).

This is where the attainment promise is essential. Without it, \(R_+\) could be nonempty while \(J_+\) is empty.

Downward amendment

If \(J_+\) is empty, form

\(J_-=\{j:b_j<s\text{ and }F_j>s\}\).

Every candidate value belongs to \(R_-\). Conversely, take any \(r\in R_-\). Since \(\mu(a\le r)>s\), there is at least one support value at most \(r\). Let \(b_j\) be the largest such value. Then

\(F_j=\mu(a\le r)>s\), and \(b_j\le r<s\).

Hence \(j\in J_-\). It follows that \(R_-\) is nonempty exactly when \(J_-\) is nonempty. Moreover, when these sets are nonempty, the smallest candidate is no larger than any member of \(R_-\), and is itself a member. Thus

\(s'=\min_{j\in J_-}b_j\).

If both candidate sets are empty, return \(s'=s\). This implements the required precedence of upward amendments.

2. Weighted medians and tail removal

Aggregate equal timeout coordinates and sort the resulting marginal:

\(c_1<\cdots<c_h\), with masses \(v_1,\ldots,v_h>0\).

Let

\(C_0=0\), and \(C_j=\sum_{\ell=1}^{j}v_\ell\).

For \(0<\alpha<1\), define the quantile

\(Q(\alpha)=c_{\min\{j:C_j\ge\alpha\}}\).

We use the standard definition: a median of a measure of total mass \(M>0\) is a value \(x\) for which both the mass at or below \(x\) and the mass at or above \(x\) are at least \(M/2\). Normalizing the measure does not change its medians.

Median fact. For a finite positive measure with ordered support, the first support value whose cumulative mass reaches \(M/2\) is a median.

Indeed, the mass strictly below that value is less than \(M/2\), and the mass strictly above it is at most \(M/2\). These are exactly the two median conditions. Under the uniqueness promise, this value is therefore the required median.

In particular, the original median is

\(q=Q(1/2)\).

Set \(\rho=2s-1\). Since \(1/2\le s<1\), we have \(0\le\rho<1\), and the retained mass is

\(M=1-\rho=2(1-s)>0\).

Removing the upper tail

Suppose \(q>D\). Removing exactly the uppermost mass \(\rho\), with an atom split when necessary, retains the lowest mass \(M\).

At any original support value \(c_j\), its retained cumulative mass is

\(C_j^{\mathrm{upper}}=\min(C_j,M)\).

To verify this identity, if \(C_j\le M\), all mass at or below \(c_j\) is retained. If \(C_j\ge M\), all retained mass lies at or below \(c_j\). Splitting the cutoff atom makes the same formula valid when the cutoff lies inside an atom.

Because \(0<M/2<M\),

\(\min(C_j,M)\ge M/2\) holds exactly when \(C_j\ge M/2\).

The median fact and uniqueness promise therefore give

\(t=Q(M/2)=Q(1-s)\).

Removing the lower tail

Suppose \(q<D\). Removing exactly the lowest mass \(\rho\) leaves cumulative mass

\(C_j^{\mathrm{lower}}=\max(C_j-\rho,0)\).

Indeed, if \(C_j\le\rho\), all mass at or below \(c_j\) is removed. Otherwise, exactly mass \(\rho\) is removed from that prefix.

Since \(M/2>0\),

\(\max(C_j-\rho,0)\ge M/2\) holds exactly when \(C_j\ge\rho+M/2\).

But

\(\rho+M/2=(2s-1)+(1-s)=s\).

Consequently,

\(t=Q(s)\).

These formulas compute the trimmed median exactly, without constructing normalized rational masses.

3. Applying the timeout movement condition

The quantile function \(Q\) is nondecreasing: increasing the target cumulative mass cannot decrease the first support index that reaches it.

Since \(1-s\le 1/2\le s\), the formulas above imply:

  • If \(q>D\), then \(t=Q(1-s)\le Q(1/2)=q\).
  • If \(q<D\), then \(t=Q(s)\ge Q(1/2)=q\).

Thus the trimmed median cannot overshoot the original median in the proposed direction. The rule becomes:

  • Compute \(q=Q(1/2)\).
  • If \(q=D\), return \(D'=D\).
  • If \(q>D\), compute \(t=Q(1-s)\); return \(D'=t\) when \(t>D\), and \(D'=D\) otherwise.
  • If \(q<D\), compute \(t=Q(s)\); return \(D'=t\) when \(t<D\), and \(D'=D\) otherwise.

An accepted upward movement satisfies \(D<t\le q\); an accepted downward movement satisfies \(q\le t<D\). This verifies the stated movement condition, including reaching \(q\).

The computation uses the prevailing \(s\), as required.

4. Exact bit complexity

There are at most \(\tau\) support values in each marginal. Sorting both marginals takes \(O(\tau\log(\tau+1))\) comparisons. Aggregation, cumulative sums, candidate scans, and quantile scans require \(O(\tau)\) further arithmetic operations.

It remains to bound the cost of exact arithmetic.

Write every input rational as a numerator divided by a positive denominator, both encoded in binary. Let \(B\) be the product of all input denominators. Its bit length is \(O(L)\), because the sum of the denominators’ bit lengths is at most the total input length. Multiplying each input rational by \(B\) gives an integer of \(O(L)\) bits.

Let \(W_i=Bw_i\), \(S=Bs\), and \(A_j=Bb_j\). Then:

  • \(\sum_i W_i=B\).
  • An upward candidate test is the integer comparison \(\sum_{a_i\ge b_j}W_i>A_j\).
  • A downward candidate test is the integer comparison \(\sum_{a_i\le b_j}W_i>S\).
  • For \(Q(1/2)\), a cumulative integer mass \(T\) reaches the target exactly when \(2T\ge B\).
  • For \(Q(1-s)\), the test is \(T\ge B-S\).
  • For \(Q(s)\), the test is \(T\ge S\).

All these integers have \(O(L)\) bits. Constructing the common denominator and scaled values also takes polynomial time. Using ordinary quadratic-time integer arithmetic, a conservative bound for the entire algorithm is

\(O\!\left(\tau\log(\tau+1)L^2\right)\)

bit operations.

Finally, each returned coordinate is either its prevailing value or an original support coordinate. Hence the output has polynomial bit length as well.

This proves the polynomial-time classification for the exact promised computation. It is not necessary to infer complexity from either of the cited correctness guarantees.
