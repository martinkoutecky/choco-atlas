The continuous mirror question, as graded

Given a finite set \(U\), a support \(T\) of coherent, complete preference lists \(\Y_t\), and positive rational masses \(\mu_t\) summing to \(1\), let \(f_t(A)\) be the first bundle on \(\Y_t\) contained in menu \(A\), and define \(F_\mu(A)_x=\sum_{t:\,x\in f_t(A)}\mu_t\). Decide whether \(F_\mu(B)_x\leq F_\mu(A)_x\) for every \(A\subseteq B\subseteq U\) and \(x\in A\); if not, return a violating \(A,B,x\).

Packaged proof task (what the prover saw — nothing else)

Let \(U\) be a finite universe with \(m=|U|\). A society is given by its support: the list of \(\tau=|T|\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types.
Each type has an explicitly encoded strict ordered list \(\mathbb{Y}_t\) of distinct subsets of \(U\), ending with \(\emptyset\). Coherence means that if \(X\) precedes \(Y\), then \(X\not\subseteq Y\); completeness means every subset of every listed bundle is also listed.
Let \(N_t=|\mathbb{Y}_t|\), and let \(L\) be the total input bit length, including lists and masses. State running times in \(m,\tau,L\), and the list lengths \(N_t\).
For each menu \(A\subseteq U\), let \(f_t(A)\) be the first listed bundle contained in \(A\), and define \(F_\mu(A)_x=\sum_{t\in T:\,x\in f_t(A)}\mu_t\).
The problem is to decide whether \(F_\mu(B)_x\leq F_\mu(A)_x\) for every \(A\subseteq B\subseteq U\) and \(x\in A\), returning a violating triple \((A,B,x)\) when this fails.

Is this mass-aggregated substitutability problem solvable in polynomial time, or is it NP-hard?

For a single explicit preference list of length \(N\), substitutability can be tested in \(O(m^2N^2)\) time ([Croitoru and Mehlhorn](https://arxiv.org/pdf/1805.07642)).
No result settling this exact mass-aggregated problem was located in the literature search.

Modeling choices made when packaging the task

  • Specified explicit list encoding, with bundles encoded as subsets of the finite universe, and defined L as the total input bit length.
  • Specified strict ordering, distinct bundles, and a final empty bundle, ensuring every menu has a uniquely defined choice.
  • Interpreted completeness as closure of the listed bundles under taking subsets, rather than requiring every subset of the universe to appear.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The stated universal decision problem is \(\mathrm{coNP}\)-complete. Its complement—whether a violating triple exists—is \(\mathrm{NP}\)-complete.

This holds even when every list is coherent and complete, every list has length at most \(10\), every listed bundle has size at most \(3\), and all masses are positive dyadic rationals.

Consequently, a polynomial-time algorithm deciding the property and returning a violation when it fails would imply \(\mathrm{P}=\mathrm{NP}\). The distinction between \(\mathrm{NP}\)-hardness and \(\mathrm{coNP}\)-completeness matters because the question asks whether a universal inequality holds.

1. Local violations suffice, and verification is polynomial

For distinct elements \(y,z\in U\) and a menu \(A\) containing \(z\) but excluding \(y\), define

\(\displaystyle \Delta_{y,z}(A)=F_\mu(A\cup\{y\})_z-F_\mu(A)_z.\)

The required property holds if and only if all these quantities are nonpositive.

Indeed, necessity follows by taking \(B=A\cup\{y\}\). For sufficiency, take arbitrary \(A\subseteq B\) and \(z\in A\), and add the elements of \(B\setminus A\) one at a time. The coordinate \(z\) remains present throughout. If every local increment is nonpositive, their telescoping sum gives \(F_\mu(B)_z-F_\mu(A)_z\leq 0\).

A violating triple is therefore a polynomial-size certificate. Scanning the explicit lists computes the two chosen bundles for every type in time

\(\displaystyle O\!\left(m\sum_{t\in T}N_t\right).\)

Exact mass comparisons are also polynomial. Write each mass as \(\mu_t=a_t/d_t\), and let \(Q=\prod_t d_t\). Its bit length is \(O(L)\). Using schoolbook arithmetic, preprocessing the integer weights \(a_t(Q/d_t)\) costs \(O(\tau L^2)\), after which one coordinate comparison costs \(O(\tau L)\).

Thus violation existence belongs to \(\mathrm{NP}\), and the universal property belongs to \(\mathrm{coNP}\).

2. Reduction from unweighted Max-Cut

We use the following known theorem: for a simple unweighted graph \(G=(V,E)\) and integer \(K\), deciding whether some \(S\subseteq V\) has at least \(K\) crossing edges is \(\mathrm{NP}\)-complete. This is the Simple Max-Cut result of [Garey, Johnson, and Stockmeyer](https://doi.org/10.1016/0304-3975%2876%2990059-1).

We restrict to \(q=|E|\geq 1\) and \(1\leq K\leq q\). This restriction preserves hardness: excluded instances are immediately decidable and can be mapped to fixed instances within the restriction. A single edge with threshold \(1\) is a yes-instance; a triangle with threshold \(3\) is a no-instance.

Introduce three new, distinct elements \(x,s,c\), and set

\(\displaystyle U=V\cup\{x,s,c\},\qquad m=|V|+3.\)

We first assign positive integer weights to types, then normalize them into masses.

The oriented-edge gadget

For every edge \(\{u,v\}\in E\), introduce both orientations \((u,v)\) and \((v,u)\). For an orientation \((a,b)\), create a type of weight \(2\) with list

\(\displaystyle \mathbb Y_{a,b}= \bigl( \{b\},\, \{x,s,a\},\, \{c\},\, \{x,s\},\, \{x,a\},\, \{s,a\},\, \{x\},\, \{s\},\, \{a\},\, \emptyset \bigr). \)

This list is complete: it contains all eight subsets of \(\{x,s,a\}\), together with the singletons \(\{b\}\) and \(\{c\}\).

It is coherent. The elements \(b,c\) are outside \(\{x,s,a\}\), so neither singleton is contained in any later bundle. Within the subsets of \(\{x,s,a\}\), bundles appear in decreasing cardinality; distinct bundles of equal cardinality cannot contain one another.

For every menu \(A\) with \(x\in A\) and \(s\notin A\), this type satisfies

\[\displaystyle \mathbf 1[x\in f_{a,b}(A\cup\{s\})] -\mathbf 1[x\in f_{a,b}(A)] = \mathbf 1[c\in A,\ a\in A,\ b\notin A]. \tag{1} \]

Here \(\mathbf 1[P]\) equals \(1\) when \(P\) holds and \(0\) otherwise. To verify (1), consider all possibilities:

  • If \(b\in A\), both menus choose \(\{b\}\), giving increment \(0\).
  • If \(b\notin A\) and \(c\in A\), the smaller menu chooses \(\{c\}\). The larger menu chooses \(\{x,s,a\}\) exactly when \(a\in A\); otherwise it still chooses \(\{c\}\).
  • If \(b,c\notin A\), the smaller menu chooses \(\{x,a\}\) when \(a\in A\), and \(\{x\}\) otherwise. The larger menu chooses \(\{x,s,a\}\) when \(a\in A\), and \(\{x,s\}\) otherwise. Both choices contain \(x\), giving increment \(0\).

Consequently, the two orientations of one edge contribute total weight \(2\) to this increment exactly when \(c\in A\) and that edge crosses the cut \(A\cap V\).

Threshold type

Add a type of weight \(2K-1\) with list

\(\displaystyle (\{s\},\{x\},\emptyset).\)

Whenever \(x\in A\) and \(s\notin A\), adding \(s\) changes its choice from \(\{x\}\) to \(\{s\}\). Its weighted increment in coordinate \(x\) is therefore \(-(2K-1)\).

Types that cancel other increases

For each ordered pair of distinct elements \((y,z)\in U^2\), except \((s,x)\), add a type of weight \(4q\) with list

\(\displaystyle (\{y\},\{z\},\emptyset).\)

Every such type is coherent, complete, and individually substitutable. More explicitly, adding an element can only replace the selected singleton by the newly available, earlier singleton. Thus the selection indicator of any element already present cannot increase.

For its own ordered pair \((y,z)\), adding \(y\) to a menu containing \(z\) but excluding \(y\) changes its choice from \(\{z\}\) to \(\{y\}\). It contributes exactly \(-4q\) to that local increment.

These types contribute zero to the designated increment obtained by adding \(s\) and observing \(x\):

  • If their first singleton is \(s\), their second singleton is not \(x\), so neither choice contains \(x\).
  • If their second singleton is \(s\), their first singleton is available either in both menus or in neither; any selection of \(x\) is unchanged.
  • Otherwise, adding \(s\) does not affect their choice.

Positive dyadic masses

There are \(m(m-1)-1\) cancellation types. The total integer weight so far is

\(\displaystyle H=4q+(2K-1)+4q\bigl(m(m-1)-1\bigr) =4qm(m-1)+2K-1. \)

Choose a power of two \(D\) with \(H<D\leq 2H\). Add one type with list \((\emptyset)\) and weight \(D-H\), and give every type of weight \(w\) mass \(w/D\).

All masses are strictly positive dyadic rationals and sum to \(1\). The final type contributes zero to every coordinate.

3. Correctness of the reduction

Define the cut size

\(\displaystyle \operatorname{cut}_G(S) =\bigl|\{\{u,v\}\in E:\text{ exactly one of }u,v\text{ belongs to }S\}\bigr|. \)

For any menu \(A\) containing \(x\) and excluding \(s\), equation (1), the threshold type, and the zero contributions of the cancellation types give

\[\displaystyle D\,\Delta_{s,x}(A) = 2\,\mathbf 1[c\in A]\operatorname{cut}_G(A\cap V)-(2K-1). \tag{2} \]

If \(c\notin A\), this is negative. If \(c\in A\), integrality of the cut size implies

\[\displaystyle \Delta_{s,x}(A)>0 \quad\Longleftrightarrow\quad \operatorname{cut}_G(A\cap V)\geq K. \tag{3} \]

Now consider any other ordered pair \((y,z)\neq(s,x)\), with \(z\in A\) and \(y\notin A\). The \(2q\) oriented-edge types each have weight \(2\), and each indicator increment is at most \(1\). Their total weighted increment is therefore at most \(4q\).

The cancellation type for \((y,z)\) contributes exactly \(-4q\). Every other cancellation type and the threshold type contribute nonpositive increments, because they are individually substitutable. The empty-list type contributes zero. Hence

\[\displaystyle D\,\Delta_{y,z}(A)\leq 4q-4q=0.\tag{4}\]

Thus the designated ordered pair is the only possible source of a positive local increment.

If \(S\subseteq V\) defines a cut of size at least \(K\), take

\(\displaystyle A=S\cup\{x,c\},\qquad B=A\cup\{s\}.\)

Equation (2) gives \(F_\mu(B)_x>F_\mu(A)_x\), so \((A,B,x)\) is a violating triple.

Conversely, any violating triple yields a positive local increment by Section 1. Equation (4) forces its ordered pair to be \((s,x)\), and equation (3) then supplies a cut of size at least \(K\).

We have proved the exact equivalence

\(\displaystyle G\text{ has a cut of size at least }K \quad\Longleftrightarrow\quad \text{the constructed society violates substitutability}. \)

Therefore violation existence is \(\mathrm{NP}\)-complete, and the universal property is \(\mathrm{coNP}\)-complete.

4. Input size and constructive running times

The construction has

\(\displaystyle m=|V|+3,\qquad \tau=2q+m(m-1)+1,\qquad N_t\leq 10. \)

Every listed bundle has size at most \(3\). Each mass requires \(O(\log(qm^2))\) bits. With explicit \(m\)-bit bundle encodings, the construction takes

\(\displaystyle O\!\left(m\sum_t N_t+\tau\log(qm^2)\right)=O(m^3) \)

time and output bits, using \(q=O(m^2)\). Thus hardness uses polynomially many supported types, not an implicitly encoded collection of types.

There is also a useful exact algorithm when the support size is fixed. Any explicit-list choice function satisfies the following property:

\[\displaystyle f_t(M)\subseteq C\subseteq M \quad\Longrightarrow\quad f_t(C)=f_t(M). \tag{5} \]

Indeed, the chosen bundle remains feasible in \(C\), and any earlier bundle feasible in \(C\) would already have been feasible in \(M\).

Given a violation \((A,B,x)\), define

\(\displaystyle A'=\{x\}\cup\bigcup_t f_t(A), \qquad B'=A'\cup\bigcup_t f_t(B). \)

Then \(A'\subseteq A\), \(B'\subseteq B\), and \(A'\subseteq B'\). Applying (5) separately to every type preserves all choices at both menus, so \((A',B',x)\) remains a violation.

An algorithm can therefore enumerate an element \(x\) and two listed bundles per type, form the corresponding \(A',B'\), and directly check the inequality. It returns a violating triple if one exists. Its bit running time is

\(\displaystyle O\!\left( \tau L^2+ m\left(\prod_t N_t^2\right) \left(m\sum_t N_t+\tau L\right) \right). \)

This is polynomial for fixed \(\tau\), but the hardness result rules out polynomial time for unrestricted support size unless \(\mathrm{P}=\mathrm{NP}\).
