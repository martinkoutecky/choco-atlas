The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), a finite support of complete rankings \(\pi\) with rational masses \(\mu_\pi\) summing to \(1\), and rational thresholds \(q_1,\ldots,q_\ell\) for \(\ell\le |C|\), decide whether there is a committee \(S\subseteq C\) of size \(k\) such that \(\sum_\pi \mu_\pi\sum_{c\in S}[\operatorname{pos}_\pi(c)\le t]\ge q_t\) for every \(t\in[\ell]\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m\ge 1\), and let \(1\le k\le m\) and \(1\le\ell\le m\) be input integers. Each type is a strict complete ranking \(\pi\) of \(C\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_\pi\) a binary rational, with \(\sum_\pi\mu_\pi=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L,k,\ell\).
The input also contains nonnegative binary rational thresholds \(q_1,\ldots,q_\ell\). For a committee \(S\subseteq C\), define its mass-weighted \(t\)-Bloc score as \(B_t(S)=\sum_\pi\mu_\pi\sum_{c\in S}\mathbf{1}\{\operatorname{pos}_\pi(c)\le t\}\), where the top position is \(1\). Committees are sets of candidates of cardinality \(k\).

Is deciding whether there exists a committee \(S\) with \(B_t(S)\ge q_t\) for every \(1\le t\le\ell\) solvable in polynomial time, or is it NP-hard?

For an explicitly listed finite electorate with unweighted voters, the corresponding MULTIBLOC decision problem is NP-complete when \(\ell\) is part of the input; for fixed \(\ell\), it is in P ([Kocot et al., 2019](https://www.ijcai.org/proceedings/2019/0055.pdf)). No result for exactly the normalized rational-mass formulation was located in the search.

Modeling choices made when packaging the task

  • Restricted thresholds to nonnegative binary rationals, matching the discrete multigoal definition.
  • Specified strict complete rankings and positions numbered from 1.
  • Specified positive committee size and positive number of goals, with both at most the number of candidates.
  • Defined L as total input bit length and made the number of goals part of the input.

Result

The normalized rational-mass problem is NP-complete when \(\ell\) is part of the input. Aggregating identical rankings and normalizing voter counts gives a polynomial-time reduction from the explicitly listed, unweighted problem.

Throughout, binary rationals are represented by binary-encoded numerators and positive denominators.

1. Membership in \(\mathrm{NP}\)

A certificate is a list of \(k\) distinct candidates specifying a committee \(S\). Its length is \(O(k\log(m+1))\).

Write each input mass as \(\mu_\pi=a_\pi/b_\pi\), and define
\[ D=\prod_{\pi}b_\pi, \qquad w_\pi=a_\pi(D/b_\pi). \]
Each \(w_\pi\) is a positive integer. The normalization assumption gives
\[ \sum_\pi w_\pi=D. \]
The bit length of \(D\) is \(O(L)\), because it is at most the sum of the bit lengths of the input denominators. Consequently, these integers can be computed in polynomial time without expanding the society into individual voters.

For each supported ranking and each \(t\le\ell\), compute the integer
\[ N_{\pi,t}(S)= \bigl|\{c\in S:\operatorname{pos}_\pi(c)\le t\}\bigr|. \]
Then
\[ B_t(S)=\frac{H_t(S)}{D}, \qquad H_t(S)=\sum_\pi w_\pi N_{\pi,t}(S). \]
Since \(0\le N_{\pi,t}(S)\le k\), we have \(0\le H_t(S)\le kD\). Thus each \(H_t(S)\) has \(O(L+\log(k+1))=O(L)\) bits.

Writing \(q_t=r_t/s_t\), with \(s_t>0\), the required inequality is equivalent to the exact integer comparison
\[ s_tH_t(S)\ge r_tD. \]
All operands have \(O(L)\) bits.

Scanning the rankings, computing prefix counts, and performing these comparisons takes, conservatively,
\[ O\bigl((\tau m+\tau\ell+k+\ell)L^2\bigr) \]
bit operations using schoolbook arithmetic. Checking the certificate’s cardinality and distinctness also fits this bound. This proves membership in \(\mathrm{NP}\).

2. The source hardness theorem

Kocot et al. define \(\ell\)-MULTIBLOC using precisely the rules \(1\)-Bloc through \(\ell\)-Bloc, with separate lower thresholds and a prescribed committee size. Their Theorem 3 states that MULTIBLOC, where \(\ell\) is part of the input, is NP-complete. Their electorate consists of explicitly listed, unweighted voters with strict complete rankings. [Kocot et al., 2019, Section 4](https://www.ijcai.org/proceedings/2019/0055.pdf)

Thus the source problem asks whether some committee \(S\), of size \(k\), satisfies
\[ A_t(S):= \sum_{i=1}^{n}\sum_{c\in S} \mathbf{1}\{\operatorname{pos}_{\pi_i}(c)\le t\} \ge Q_t \quad\text{for every }1\le t\le\ell. \]

We may use nonnegative integer thresholds: these scores are integers, so rational thresholds can be replaced by their ceilings.

We may also restrict to \(n\ge1\) and \(\ell\le m\). Empty-electorate instances are immediately decidable. For \(t\ge m\), every size-\(k\) committee has score \(nk\); hence constraints beyond \(m\) are either automatically satisfied or make the instance immediately infeasible.

3. Reduction by aggregation and normalization

Take such a source instance with \(n\ge1\). Keep its candidate set, committee size \(k\), and parameter \(\ell\).

For every distinct ranking \(\pi\) occurring among the voters, let
\[ a_\pi=\bigl|\{i:\pi_i=\pi\}\bigr|. \]
Output that ranking once, with mass
\[ \mu_\pi=\frac{a_\pi}{n}. \]
Output thresholds
\[ q_t=\frac{Q_t}{n} \quad\text{for }1\le t\le\ell. \]

Every listed mass is positive, and
\[ \sum_\pi\mu_\pi =\frac{\sum_\pi a_\pi}{n} =\frac{n}{n}=1. \]
Therefore the output is a valid normalized society, with support size \(\tau\le n\).

For every size-\(k\) committee \(S\) and every \(t\le\ell\),
\[ \begin{aligned} B_t(S) &=\sum_\pi\frac{a_\pi}{n} \sum_{c\in S}\mathbf{1}\{\operatorname{pos}_\pi(c)\le t\}\\ &=\frac1n \sum_{i=1}^{n}\sum_{c\in S} \mathbf{1}\{\operatorname{pos}_{\pi_i}(c)\le t\}\\ &=\frac{A_t(S)}{n}. \end{aligned} \]
Since \(n>0\), this yields the exact equivalence
\[ B_t(S)\ge q_t \quad\Longleftrightarrow\quad A_t(S)\ge Q_t. \]
It holds simultaneously for every required value of \(t\). Consequently, the source instance is feasible if and only if the output instance is feasible.

Encoding size and construction time

The reduction never enumerates all possible rankings. It only groups the explicitly listed voters.

Each mass \(a_\pi/n\) requires \(O(\log(n+1))\) bits. Each threshold \(Q_t/n\) requires \(O(\operatorname{bits}(Q_t)+\log(n+1))\) bits. The output contains at most \(n\) rankings, all copied from the source.

Grouping can be performed by lexicographically sorting the rankings, using \(O(nm\log(n+1))\) candidate-label comparisons, and then counting repetitions. The rational constructions also take polynomial time in the source bit length. Because the voters are explicitly listed, \(n\) is bounded by that bit length. Hence this is a polynomial-time many-one reduction.

Together with membership in \(\mathrm{NP}\), this proves NP-completeness.

4. Scope of the conclusion

The hardness result concerns variable \(\ell\). For \(\ell=1\), compute each candidate’s first-position mass and choose the \(k\) candidates with largest such masses. Additivity of \(B_1\) proves that this committee maximizes the only constrained score. This gives a polynomial-time algorithm, for example within
\[ O\bigl((\tau m+m\log(m+1))L^2\bigr) \]
bit operations.

The cited fixed-\(\ell\) algorithm for explicitly listed voters does not automatically extend to binary rational masses: clearing denominators can produce an exponentially large integer score range. No extension of that algorithm is needed for the NP-completeness result proved above.
