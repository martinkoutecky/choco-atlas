The continuous mirror question, as graded

Given \(m\) candidates, a finite support \(T\) of partial rankings each with at most two undetermined pairs, rational masses \(\mu_t \geq 0\) summing to \(1\), and a target \(c^\star\), is there an allocation \(x_{t,\pi} \geq 0\) of each type's mass among its linear extensions \(\pi \in \mathrm{Ext}(t)\) such that \(\sum_{\pi \in \mathrm{Ext}(t)} x_{t,\pi} = \mu_t\) for every \(t\), and \(\sum_{t,\pi} x_{t,\pi} B(\pi,c^\star) \geq \sum_{t,\pi} x_{t,\pi} B(\pi,a)\) for every candidate \(a\), where \(B(\pi,a)=m-\mathrm{rank}_{\pi}(a)\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a set of \(m\geq2\) candidates and \(c^\star\in C\). A society is given by its support: a list \(T\) of \(\tau\) distinct partial-ranking types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Each ranking is a partial order on all of \(C\), given explicitly, with at most two incomparable unordered pairs of distinct candidates; incomparability represents missing information, not indifference.
Let \(\mathrm{Ext}(t)\) denote the strict linear orders extending \(t\). A completion may split each type's mass arbitrarily into real amounts \(x_{t,\pi}\geq0\), subject to \(\sum_{\pi\in\mathrm{Ext}(t)}x_{t,\pi}=\mu_t\).
Use Borda scores and write \(S_x(a)=\sum_{t\in T}\sum_{\pi\in\mathrm{Ext}(t)}x_{t,\pi}B(\pi,a)\). The decision problem asks whether a completion satisfies \(S_x(c^\star)\geq S_x(a)\) for every \(a\in C\); tied maximum scores count as winning.
Here \(\tau\) is the support size, not the number of possible rankings, and \(L\) is the total binary input length. State running times in \(m,\tau,L\).

Is this continuous Borda possible-co-winner problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite list of unweighted voters, Borda possible co-winner is NP-complete with at most two undetermined pairs per vote and polynomial-time solvable with at most one. [Dey and Misra](https://arxiv.org/pdf/1610.08407)
No prior result settling exactly the mass-splitting problem defined above was identified in the literature search.

Modeling choices made when packaging the task

  • Discard zero-mass entries so that the listed types are exactly the positive-mass support.
  • Interpret partial rankings as partial orders on all candidates, with undetermined pairs counted as incomparable unordered pairs of distinct candidates.
  • Use explicit partial-order input and define L as the total binary input length.
  • Require at least two candidates, consistent with a nonconstant positional scoring rule.
  • Make allocation amounts nonnegative real numbers and retain co-winner semantics, so ties at the maximum score are accepted.

Result

The continuous Borda possible-co-winner problem is solvable in polynomial time in \(m,\tau,L\).

The proof constructs an exact rational linear-feasibility problem with at most \(4\tau\) variables. Arbitrary splitting of each type’s mass is essential to this formulation.

1. Enumerating the extensions

For a type \(t\), let \(I_t\) be its set of incomparable unordered pairs and let \(k_t=|I_t|\leq2\).

Lemma. The type \(t\) has at most \(2^{k_t}\leq4\) linear extensions, and all its extensions can be enumerated in polynomial time.

Proof. Every strict linear extension chooses an orientation for each pair in \(I_t\). These choices determine its comparison on every unordered pair: comparable pairs already have their orientation fixed by \(t\). Consequently, two extensions choosing the same orientations must be identical. Thus \(|\mathrm{Ext}(t)|\leq2^{k_t}\).

To enumerate the extensions, consider each of these at most four orientation assignments. Form a directed graph containing all strict comparisons of \(t\) and the chosen orientations. Discard the assignment if this graph contains a directed cycle.

For every remaining assignment, take a topological ordering. It respects all comparisons of \(t\), so it is a linear extension. Moreover, every unordered pair has an edge in one direction, so its topological ordering is unique. Conversely, the orientations chosen by any linear extension produce an acyclic graph, and the procedure therefore finds that extension. This proves completeness of the enumeration. \(\square\)

If necessary, compute the transitive closure of the given partial-order representation first. This takes \(O(m^3)\) Boolean operations per type. Each orientation assignment then requires \(O(m^2)\) graph operations. Thus extension enumeration takes \(O(\tau m^3)\) elementary operations, apart from reading the input.

Write the resulting list as \(\mathrm{Ext}(t)=\{\pi_{t,1},\ldots,\pi_{t,r_t}\}\), where \(1\leq r_t\leq4\).

2. An exact linear-feasibility formulation

Number positions from best to worst, starting at one, and use the Borda convention \(B(\pi,a)=m-\operatorname{pos}_{\pi}(a)\).

For every listed extension introduce a real variable \(x_{t,j}\), representing the mass of type \(t\) assigned to \(\pi_{t,j}\). Define the integer score difference

\(d_{a,t,j}=B(\pi_{t,j},c^\star)-B(\pi_{t,j},a)\).

Consider the following system:

  • Nonnegativity: \(x_{t,j}\geq0\) for every \(t\in T\) and \(1\leq j\leq r_t\).
  • Mass conservation: \(\sum_{j=1}^{r_t}x_{t,j}=\mu_t\) for every \(t\in T\).
  • Co-winner conditions: \(\sum_{t\in T}\sum_{j=1}^{r_t}d_{a,t,j}x_{t,j}\geq0\) for every \(a\in C\setminus\{c^\star\}\).

Proposition. This system is feasible over the reals if and only if the given society admits a completion making \(c^\star\) a Borda co-winner.

Proof. Suppose such a completion exists. The enumeration contains every allowed extension, so assign its mass on \(\pi_{t,j}\) to \(x_{t,j}\). Nonnegativity and mass conservation follow from the definition of a completion. For each rival \(a\),

\(\sum_{t\in T}\sum_{j=1}^{r_t}d_{a,t,j}x_{t,j}=S_x(c^\star)-S_x(a)\geq0\).

Hence the system is feasible.

Conversely, suppose the system has a feasible solution. Assign mass \(x_{t,j}\) to extension \(\pi_{t,j}\). Nonnegativity and mass conservation make this a permitted completion. The same identity shows that its score for \(c^\star\) is at least every rival’s score. Thus \(c^\star\) is a co-winner. Equality is permitted throughout, as required. \(\square\)

3. Encoding size and running time

Let \(N=\sum_{t\in T}r_t\leq4\tau\). The system has \(N\) nonnegativity inequalities, \(\tau\) equalities, and \(m-1\) score inequalities. Replacing each equality by two inequalities gives at most \(6\tau+m-1\) inequalities.

Every matrix coefficient is an integer of magnitude at most \(m-1\): score differences satisfy \(|d_{a,t,j}|\leq m-1\), and the remaining coefficients are zero or unit coefficients. The only nonzero right-hand sides are the input masses and their negatives. Their combined binary encoding length is \(O(L)\).

Consequently, even a dense encoding of this rational system has length

\(B_{\mathrm{LP}}=O\!\left(L+\tau(m+\tau)\log(m+\tau)\right)\).

We use the standard polynomial-time theorem for rational linear programming: feasibility over the reals of an explicitly given rational linear system can be decided exactly in time polynomial in its binary encoding length. This theorem applies to systems with equalities and to feasible sets of lower dimension; a positive-volume feasible region is not required. See [Karger’s linear-programming algorithm notes](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html).

All hypotheses hold here: the system is explicit, its coefficients and right-hand sides are rational, and its encoding length is bounded as above. Therefore the decision algorithm has total bit running time

\((m+\tau+L)^{O(1)}\).

More specifically, preprocessing uses \(O(\tau m^3)\) elementary operations, and the remaining work is polynomial in \(B_{\mathrm{LP}}\). No expansion of rational masses into individual voters is involved. Exact feasibility also handles completions whose winning conditions hold only at equality.

4. Relation to the discrete hardness result

The [Dey–Misra result](https://arxiv.org/pdf/1610.08407) concerns discrete voters, each of whom must receive one complete ranking. Encoding those individual choices with extension variables requires integral choices.

Here, a type may distribute its mass arbitrarily among its extensions. The linear system therefore describes the permitted completions exactly. No integrality requirement remains, so the discrete NP-completeness result does not imply hardness for this mass-splitting problem.
