The continuous mirror question, as graded

Given \(m\) resources of capacity \(1\), a finite support \(T\) of Leontief or satiable Leontief types with binary-rational masses \(\mu_t>0\), per-capita demand vectors \(r_t\), and entitlements \(e_t>0\) satisfying \(\sum_{t\in T}\mu_t=1\) and \(\sum_{t\in T}\mu_t e_t=1\), compute a type-homogeneous allocation \(x_t\in\mathbb{Q}_{\ge 0}^m\). Require \(\sum_{t\in T}\mu_t x_{tj}\le 1\) for each resource \(j\), each \(x_t\) to be parsimonious, and for each type \(t\), either \(u_t(x_t)\) to be maximal or some resource \(j\) to satisfy \(\sum_{s\in T}\mu_s x_{sj}=1\) and \(x_{tj}\ge e_t\). Is this computable in time polynomial in \(m\), \(\tau=|T|\), and the total binary input length \(L\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge 1\) types with positive binary-rational masses \(\mu_t\). Here \(\tau=|T|\) is the support size, not the number of possible types; \(L\) is the total binary input length.
There are \(m\ge 1\) divisible resources, each of capacity \(1\). Each type has a binary-rational demand vector \(r_t\in\mathbb{Q}_{\ge 0}^m\setminus\{0\}\), a binary-rational per-capita entitlement \(e_t>0\), and a flag specifying ordinary or satiable Leontief utility. Require \(\sum_t\mu_t=1\) and \(\sum_t\mu_t e_t=1\).
Write \(S_t=\{j:r_{tj}>0\}\). Ordinary types have Leontief utility; satiable types have \(u_t(x)=\min\{1,\min_{j\in S_t}x_j/r_{tj}\}\), with \(r_{tj}\le 1\) for every resource. Utilities are defined on \(\mathbb{R}_{\ge 0}^m\).
A type-homogeneous allocation assigns the same per-capita bundle \(x_t\in\mathbb{Q}_{\ge 0}^m\) to every member of type \(t\). Parsimony means \(x_t=\alpha_t r_t\), where \(\alpha_t\ge 0\), and \(\alpha_t\le 1\) for satiable types.
The required allocation satisfies \(\sum_t\mu_t x_{tj}\le 1\) for every resource and, for every type \(t\), either that type is satiable with \(\alpha_t=1\), or some resource \(j\) satisfies both \(\sum_s\mu_s x_{sj}=1\) and \(x_{tj}\ge e_t\). Call this bottleneck-based fairness.

Can such an allocation be computed exactly in time polynomial in \(m,\tau,L\), or is this search problem NP-hard?

For a finite list of agents with positive entitlements summing to \(1\), bottleneck-based fair allocations for Leontief or satiable Leontief utilities can be computed in polynomial time ([Gutman–Nisan](https://www.ifaamas.org/Proceedings/aamas2012/papers/4D_5.pdf)). No result settling the exact support-encoded mass formulation above was identified in the literature search.

Modeling choices made when packaging the task

  • Required at least one resource and one supported type, and excluded all-zero demand vectors so that every Leontief minimum has a nonempty index set.
  • Specified binary-rational demands and entitlements, and an explicit ordinary/satiable flag, to complete the finite input encoding.
  • Fixed satiable utility at a cap of 1 and restricted its demand coordinates to [0,1], as in the discrete definition.
  • Interpreted maximal utility globally over nonnegative bundles: ordinary Leontief types never attain it, while satiable types attain it at their demand vector.
  • Made parsimony explicit as a scalar multiple of the demand vector, with scalar at most 1 for satiable types; zero-demand coordinates therefore receive zero.

Exact polynomial-time computation

The search problem is polynomial-time solvable, with an exact rational output. The masses can be absorbed into the demands and entitlements, using one aggregate agent per type. Below, an additional recovery argument makes exactness explicit: sufficiently accurate convex optimization determines fairness witnesses, and one rational linear program produces the required allocation.

1. Absorbing the masses

Define the aggregate demands and entitlements by

\(a_{jt}=\mu_t r_{tj},\qquad b_t=\mu_t e_t.\)

Then \(b_t>0\) and \(\sum_t b_t=1\). An aggregate bundle \(y_t=\alpha_t a_t\) corresponds to the per-capita bundle \(x_t=y_t/\mu_t=\alpha_t r_t\). Consequently,

\(\sum_t y_{tj}=\sum_t\mu_t x_{tj},\qquad y_{tj}\ge b_t\ \Longleftrightarrow\ x_{tj}\ge e_t.\)

Satiation corresponds to the same condition \(\alpha_t=1\). Moreover, for satiable types, \(a_{jt}\le1\), because \(\mu_t\le1\) and \(r_{tj}\le1\).

Thus this transformation gives precisely a finite-agent instance with \(\tau\) agents, preserving feasibility, parsimony, and bottleneck-based fairness in both directions. Its encoding length is polynomial in the original input length. It does not expand rational masses into a population.

This connects the formulation directly to the finite-agent framework of [Gutman–Nisan](https://www.ifaamas.org/Proceedings/aamas2012/papers/4D_5.pdf). We now prove exact polynomial-time computability explicitly.

2. A real fair allocation from a concave program

Let \(I\subseteq T\) be the set of satiable types. Form a matrix \(A\) whose first \(m\) rows are \(a_{jt}\), and which has one additional row for each \(t\in I\). That additional row has coefficient \(1\) in column \(t\) and zero elsewhere. Hence

\(P=\{\alpha\in\mathbb R^\tau_{\ge0}:A\alpha\le\mathbf1\}\)

is exactly the feasible set of parsimonious allocation factors, including the satiation caps.

Every column of \(A\) has a positive entry. Define

\(C_t=\max_k A_{kt}>0,\qquad U_t=1/C_t.\)

For every \(\alpha\in P\), the resource constraint attaining \(C_t\) implies \(\alpha_t\le U_t\). Therefore \(P\) is compact.

Consider the concave objective

\(F(\alpha)=\sum_t b_t\log\alpha_t\)

on the positive points of \(P\). The point \(\alpha_t=b_t/(2C_t)\) is positive and strictly feasible: for every row \(k\),

\(\sum_t A_{kt}\frac{b_t}{2C_t}\le\frac12\sum_t b_t=\frac12.\)

The objective has a positive maximizer \(\alpha^\ast\). Indeed, a maximizing sequence has a convergent subsequence by compactness. If any coordinate of its limit were zero, the corresponding logarithmic term would tend to negative infinity, while all other terms remain bounded above. This contradicts the finite objective value of the positive feasible point. Strict concavity also makes the maximizer unique.

Optimality conditions

Slater’s condition holds by the strictly feasible point above. The Karush–Kuhn–Tucker conditions therefore give multipliers \(p_k\ge0\) satisfying

\(\displaystyle \frac{b_t}{\alpha_t^\ast}=\sum_k p_kA_{kt},\qquad p_k\bigl(1-(A\alpha^\ast)_k\bigr)=0.\)

Multiplying stationarity by \(\alpha_t^\ast\), summing over types, and using complementary slackness gives

\(\displaystyle 1=\sum_t b_t=\sum_k p_k(A\alpha^\ast)_k=\sum_k p_k.\)

For each type,

\(\displaystyle b_t=\sum_k p_kA_{kt}\alpha_t^\ast.\)

This is a convex combination of its consumptions on the extended resources. Some row \(k\) with \(p_k>0\) must therefore satisfy

\(A_{kt}\alpha_t^\ast\ge b_t.\)

Such a row is exhausted, by complementary slackness.

If \(t\) is ordinary, all artificial-row coefficients in its column are zero. Since \(b_t>0\), the selected row must be a real resource.

If \(t\) is satiable and \(\alpha_t^\ast<1\), its own artificial row is slack and has multiplier zero; all other artificial-row coefficients in its column are zero. Again, the selected row must be real.

Consequently, every type is either satiated or has a real-resource witness \(j\) satisfying

\(\displaystyle \sum_s a_{js}\alpha_s^\ast=1,\qquad a_{jt}\alpha_t^\ast\ge b_t.\)

By Section 1, this is the required fairness condition.

We have proved existence over the reals. The remaining sections turn this argument into an exact rational algorithm.

3. Computing a nearby rational point

We first establish the following computational fact.

Lemma. For any positive rational \(\eta\), a rational point \(q\in P\) satisfying \(\|q-\alpha^\ast\|_\infty\le\eta\) can be computed in time polynomial in the input length and the encoding length of \(\eta\).

Bounds away from zero

Because \(\sum_kp_k=1\), stationarity implies

\(\displaystyle \frac{b_t}{\alpha_t^\ast}=\sum_kp_kA_{kt}\le C_t.\)

Thus \(\alpha_t^\ast\ge b_t/C_t\). Define

\(d_t=b_t/(2C_t),\qquad K=\{\alpha\in P:\alpha_t\ge d_t\text{ for every }t\}.\)

The maximizer belongs to \(K\). This rational polytope has a known interior ball. To see this, set

\(\displaystyle c_t=\frac{3b_t}{4C_t},\qquad M=\max\left\{1,\max_k\sum_tA_{kt}\right\},\qquad \rho=\min\left\{\min_t\frac{b_t}{4C_t},\frac1{4M}\right\}.\)

For every row, \((Ac)_k\le3/4\). Each coordinate of \(c\) lies at least \(\rho\) above \(d_t\). If \(\|z-c\|_2\le\rho\), then

\(\displaystyle (Az)_k\le(Ac)_k+\rho\sum_tA_{kt}\le1.\)

Therefore the Euclidean ball \(B(c,\rho)\) is contained in \(K\). Also, \(K\subseteq B(0,R)\) for the rational bound

\(R=\max\{1,\tau\max_tU_t\}.\)

All these numbers have polynomial encoding length.

Approximate objective optimization

On \(K\), the gradient has rational coordinates

\(\displaystyle \frac{\partial F}{\partial\alpha_t}=\frac{b_t}{\alpha_t},\)

and \(\|\nabla F(\alpha)\|_2\le2\tau\max_tC_t\). Hence a rational Lipschitz bound is

\(G=\max\{1,2\tau\max_tC_t\}.\)

The rational central-cut ellipsoid method supplies polynomial-bit query points and reduces enclosing volume geometrically, with polynomial dependence on the logarithm of the requested volume reduction. We use this standard theorem in its bounded-body form; see [Grötschel–Lovász–Schrijver, *The Ellipsoid Method*](https://link.springer.com/chapter/10.1007/978-3-642-78240-4_4).

Here is why it provides a feasible rational point with objective gap at most any prescribed positive rational \(\delta\). At a queried center \(z\):

  • If \(z\notin K\), a violated rational inequality gives a separating central cut.
  • If \(z\in K\), retain the halfspace \(\nabla F(z)\cdot(\alpha-z)\ge0\), and record \(z\).

Concavity implies that the second halfspace contains every point with objective greater than \(F(z)\).

Let

\(\displaystyle \theta=\min\left\{\frac12,\frac{\delta}{4G(2R+\rho)}\right\}.\)

By convexity of \(K\), the ball

\(B((1-\theta)\alpha^\ast+\theta c,\theta\rho)\)

lies in \(K\). Its points are within distance \(\theta(2R+\rho)\) of \(\alpha^\ast\), so their objective values are at least \(F(\alpha^\ast)-\delta/4\).

Suppose every recorded point had objective less than \(F(\alpha^\ast)-\delta/2\). Every cut would then preserve this ball. After polynomially many ellipsoid iterations, the enclosing volume becomes smaller than the ball’s volume, a contradiction. Thus some recorded feasible rational point has objective gap at most \(\delta/2\).

Evaluate the recorded objective values to additive error at most \(\delta/8\), and choose the largest estimated value. Its true objective gap is at most \(3\delta/4\), hence at most \(\delta\). Logarithms of positive rationals can be evaluated to this precision in polynomial time: range reduction to \([1,2]\), followed by the geometrically convergent series for \(\log z=2\operatorname{artanh}((z-1)/(z+1))\), suffices.

This verifies the necessary oracle and geometric hypotheses, including exact feasibility of the returned point.

Objective gap implies coordinate accuracy

For \(\alpha\in K\), the negative Hessian is diagonal, with entries

\(\displaystyle \frac{b_t}{\alpha_t^2}\ge b_tC_t^2.\)

Set \(\gamma=\min_t b_tC_t^2>0\). Thus \(F\) is \(\gamma\)-strongly concave on \(K\). First-order optimality at \(\alpha^\ast\) gives, for \(q\in K\),

\(\displaystyle F(\alpha^\ast)-F(q)\ge\frac{\gamma}{2}\|q-\alpha^\ast\|_2^2.\)

Compute the feasible rational approximation with objective gap at most

\(\delta=\min\{1,\gamma\eta^2/2\}.\)

Then \(\|q-\alpha^\ast\|_\infty\le\|q-\alpha^\ast\|_2\le\eta\). Every parameter used above has polynomial encoding length, proving the lemma.

4. A uniform gap for fairness-witness systems

A *witness choice* selects, for every type \(t\), either:

  • satiation, permitted only when \(t\in I\); or
  • a real resource \(j\in S_t\).

For a fixed choice \(w\), define an exact rational linear system. Its base constraints are \(\alpha\in P\). A satiation witness adds \(\alpha_t=1\). A resource witness \(j\) adds

\(\displaystyle \sum_s a_{js}\alpha_s=1,\qquad a_{jt}\alpha_t\ge b_t.\)

Any solution of this system is fair.

To test quantitative feasibility, introduce \(v\in[0,1]\), retain the base constraints exactly, and relax the witness constraints:

  • a satiation witness requires \(\alpha_t\ge1-v\);
  • a resource witness requires \(\sum_s a_{js}\alpha_s\ge1-v\) and \(a_{jt}\alpha_t\ge b_t-v\).

Let \(v_w\) be the minimum \(v\) in this linear program.

The program is always feasible: \(\alpha=0,v=1\) satisfies it because \(b_t\le1\). It is bounded because \(P\) is bounded. Hence its optimum occurs at a vertex.

Determinant bound

There are only polynomially many inequalities that can appear in these programs: the base inequalities, the bounds on \(v\), and the possible witness inequalities for every type-resource pair.

Clear denominators separately in every possible inequality. Let \(H\ge1\) bound the absolute values of all resulting integer coefficients and right-hand sides. This \(H\) is computable, and \(\log H\) is polynomially bounded: each row contains only polynomially many polynomial-length rational numbers.

There are \(n=\tau+1\) variables. At a vertex, select \(n\) linearly independent active inequalities. Their integer coefficient matrix \(B\) satisfies

\(0<|\det B|\le n!H^n=:D.\)

Cramer’s rule expresses the vertex coordinate \(v\) as an integer divided by \(\det B\). Therefore a positive vertex value of \(v\) is at least \(1/D\).

It follows that, uniformly over all witness choices,

\(v_w=0\quad\text{or}\quad v_w\ge1/D.\)

In particular, if a witness system admits its relaxed constraints with \(v<1/D\), its exact system is feasible. This conclusion requires no enumeration of witness choices.

5. The exact algorithm

Compute the bound \(D\) from Section 4 and set

\(\varepsilon=1/(2D),\qquad \eta=\varepsilon/M,\)

where \(M\) is the row-sum bound from Section 3. Use the lemma to compute a rational feasible point \(q\) with \(\|q-\alpha^\ast\|_\infty\le\eta\).

For each type, choose any witness passing the following rational tests:

  • satiation: \(t\in I\) and \(q_t\ge1-\varepsilon\);
  • resource \(j\in S_t\): \(\sum_s a_{js}q_s\ge1-\varepsilon\) and \(a_{jt}q_t\ge b_t-\varepsilon\).

At least one witness passes for every type. To verify this, use its witness at \(\alpha^\ast\), established in Section 2.

If it is satiation, then \(q_t\ge1-\eta\ge1-\varepsilon\). If it is a resource witness \(j\), then

\(\displaystyle \left|\sum_s a_{js}(q_s-\alpha_s^\ast)\right|\le\eta\sum_s a_{js}\le\varepsilon,\)

and

\(\displaystyle |a_{jt}(q_t-\alpha_t^\ast)|\le a_{jt}\eta\le M\eta=\varepsilon.\)

Thus its two tests pass.

Let \(w\) be the selected witness choice. The pair \((q,\varepsilon)\) is feasible for its relaxed program, so

\(v_w\le\varepsilon=1/(2D)<1/D.\)

The uniform gap implies \(v_w=0\). Therefore the exact witness system is feasible.

Solve that rational linear system using a polynomial-time linear-programming algorithm, obtaining a rational solution \(\widehat\alpha\). Output

\(x_t=\widehat\alpha_t r_t.\)

The base constraints ensure feasibility and parsimony. A selected satiation witness ensures \(\widehat\alpha_t=1\). A selected resource witness ensures exact exhaustion and

\(a_{jt}\widehat\alpha_t\ge b_t\ \Longleftrightarrow\ x_{tj}\ge e_t.\)

Hence the output satisfies every required condition exactly.

6. Running time and conclusion

The aggregate instance, convex program, and final linear program have polynomially many variables and constraints. Denominator clearing gives polynomial-length \(H\), and

\(\log D=\log((\tau+1)!)+(\tau+1)\log H\)

is polynomially bounded. Therefore the requested approximation precision also has polynomial encoding length. Section 3 computes that approximation in polynomial time, and selecting witnesses takes polynomially many rational comparisons.

Finally, exact rational linear programming returns a solution of polynomial encoding length; multiplying by the input demand vectors preserves that bound.

Thus an exact type-homogeneous, parsimonious, bottleneck-based fair allocation can be computed in time polynomial in \(m,\tau,L\).
