Conclusion

The promised computation problem is polynomial-time solvable. All limiting opinions and their mass-weighted average can be computed exactly as rational numbers in time polynomial in \(m,\tau,L\).

The proof requires both a nonsingular rational linear system and polynomial bounds on intermediate and output bit lengths. We establish these explicitly.

1. The promise gives a unique limiting equilibrium

Enumerate the support as \(T=\{1,\ldots,\tau\}\), and set \(n=m\tau\). Define

\(d_t=\sum_{s\in T}a_{ts}\mu_s.\)

By hypothesis, every \(d_t\) is positive. Consequently, \(p^\mu_{ts}=a_{ts}\mu_s/d_t\) is well-defined, nonnegative, and satisfies

\(\sum_{s\in T}p^\mu_{ts}=1.\)

Stack the opinion vectors in type order into \(X(k)\in\mathbb Q^n\), and similarly stack the prejudices into \(U\). Define

\(A=(\Lambda P^\mu)\otimes C,\qquad b=((I_\tau-\Lambda)\otimes I_m)U.\)

The stated recurrence is then exactly

\(X(k+1)=AX(k)+b.\)

For completeness, the eigenvalues of a Kronecker product are all products of eigenvalues of its factors. Indeed, triangularize both factors over \(\mathbb C\); their Kronecker product is similar to the Kronecker product of the resulting upper-triangular matrices, whose diagonal entries are precisely these products. Hence

\(\rho(A)=\rho(\Lambda P^\mu)\rho(C)<1.\)

Thus \(K=I_n-A\) is nonsingular: otherwise, \(1\) would be an eigenvalue of \(A\). Its unique equilibrium is

\(X^*=K^{-1}b.\)

Moreover, \(A^k\) tends to zero. To justify this without a diagonalizability assumption, each Jordan block with eigenvalue \(\alpha\), where \(|\alpha|<1\), has powers whose entries are finite sums of terms \(\binom{k}{r}\alpha^{k-r}\); these tend to zero. A block with \(\alpha=0\) is nilpotent. Therefore

\(X(k)-X^*=A^k(U-X^*)\longrightarrow0.\)

This also reproduces the equilibrium formula in [Parsegov et al., Theorem 2](https://arxiv.org/pdf/1505.04920v5). The argument applies to signed \(C\); it does not require nonnegative entries in that matrix.

2. Constructing an integer system of polynomial size

We use the standard explicit binary encoding of rational numbers by signed integer numerators and positive integer denominators.

Let \(Q\) be the product of the denominators of all rational input entries, including the masses. Every input rational \(z\) can then be written as

\(z=\widehat z/Q,\qquad \widehat z\in\mathbb Z.\)

Since the total input length is \(L\), the bit length of \(Q\) is \(O(L)\). Each \(\widehat z\) also has bit length \(O(L)\): forming it multiplies an input numerator by \(Q\) divided by its input denominator.

Write the corresponding integer representations as

\(\widehat\mu_t,\quad \widehat a_{ts},\quad \widehat\lambda_t,\quad \widehat C_{ij},\quad \widehat u_{ti}.\)

Define the positive integers

\(D_t=\sum_{s\in T}\widehat a_{ts}\widehat\mu_s.\)

Then \(d_t=D_t/Q^2\), and each \(D_t\) has bit length \(O(L+\log(\tau+1))\).

The equilibrium equation for coordinate \(i\) of type \(t\), multiplied by \(d_t\), is

\(d_t x_{ti}-\lambda_t\sum_{s\in T}\sum_{j=1}^m a_{ts}\mu_s C_{ij}x_{sj}=d_t(1-\lambda_t)u_{ti}.\)

Multiplying by \(Q^4\) gives the integer linear system \(HX=g\), where

\(H_{(t,i),(s,j)} =Q^2D_t\,\mathbf 1_{\{t=s,\ i=j\}} -\widehat\lambda_t\widehat a_{ts}\widehat\mu_s\widehat C_{ij},\)

and

\(g_{(t,i)} =D_t(Q-\widehat\lambda_t)\widehat u_{ti}.\)

Every coefficient has bit length at most some

\(B=O(L+\log(\tau+1)).\)

This follows because each expression uses a fixed number of products of \(O(L)\)-bit integers, together with sums of at most \(\tau\) such products.

The system is equivalent to \(KX=b\). More precisely,

\(H=\operatorname{diag}(Q^2D_1,\ldots,Q^2D_\tau)\otimes I_m\;\,K.\)

The diagonal factor is nonsingular because every \(D_t>0\), and \(K\) is nonsingular by Section 1. Thus \(H\) is nonsingular.

Constructing \(Q,D_t,H,g\) requires polynomially many operations on integers of polynomial bit length. The number of unknowns is \(m\tau\); no expansion of the masses into individual agents is needed.

3. Exact solution with polynomial bit complexity

We give an explicit, though not optimized, algorithm using determinants.

For each coordinate \(\ell\in\{1,\ldots,n\}\), let \(H^{[\ell]}\) be \(H\) with column \(\ell\) replaced by \(g\). Cramer’s rule gives

\(X^*_\ell=\frac{\det H^{[\ell]}}{\det H}.\)

We must show that these determinants can be computed in polynomial bit time.

Bounds on minors and outputs

Enlarge \(B\) if necessary so that every entry of \(H\) and every \(H^{[\ell]}\) has absolute value at most \(2^B\).

For any \(q\)-by-\(q\) submatrix \(M\), where \(1\leq q\leq n\), Hadamard’s inequality gives

\(|\det M|\leq(\sqrt q\,2^B)^q=q^{q/2}2^{qB}.\)

Therefore every such minor has bit length

\(O(n(B+\log n)).\)

In particular, the numerator and denominator in each Cramer expression have this bit length. Reducing the fraction cannot increase either length. Thus all equilibrium coordinates have polynomial-size exact representations.

Polynomial-time determinant computation

Each required determinant can be computed by Gaussian elimination over \(\mathbb Q\), reducing fractions after each arithmetic operation and using row exchanges when needed.

Here is the intermediate-size justification. At any stage with \(k\) successful pivots, consider the original integer matrix in its current row order and partition it as

\(M=\begin{pmatrix}E&F\\G&D\end{pmatrix},\)

where \(E\) is the nonsingular \(k\)-by-\(k\) pivot block. The remaining elimination matrix is the Schur complement

\(S=D-GE^{-1}F.\)

This identity follows by eliminating the first block column:

\(\begin{pmatrix}I&0\\-GE^{-1}&I\end{pmatrix} \begin{pmatrix}E&F\\G&D\end{pmatrix} = \begin{pmatrix}E&F\\0&S\end{pmatrix}.\)

For an entry of \(S\), write its corresponding column of \(F\), row of \(G\), and entry of \(D\) as \(f,c,d\). The same block elimination gives

\(\det\begin{pmatrix}E&f\\c&d\end{pmatrix} =\det(E)(d-cE^{-1}f).\)

Hence each remaining entry is a ratio of two minors of the original integer matrix. By the preceding bound, its reduced numerator and denominator have bit length \(O(n(B+\log n))\).

Each scalar elimination update consists of a fixed number of rational multiplications, divisions, and subtractions. Its temporary integers therefore also have polynomial bit length, and reduction by the Euclidean algorithm takes polynomial time. There are \(O(n^3)\) such updates per determinant. Multiplying the pivots and accounting for row-exchange signs likewise takes polynomial time.

If no nonzero pivot is available in the current column, the remaining triangularization has a zero column and the determinant is zero. Thus the procedure also handles singular matrices \(H^{[\ell]}\).

Computing the \(n+1\) determinants needed by Cramer’s rule consequently takes polynomial time. Since \(\det H\ne0\), every required coordinate is obtained exactly.

4. Computing the mass-weighted average

Let

\(\Delta=\det H,\qquad N_{ti}=\det H^{[(t,i)]}.\)

The unreduced expressions \(x^*_{ti}=N_{ti}/\Delta\) share a common denominator. Thus, for each issue \(i\),

\(\bar x_i^* =\sum_{t\in T}\mu_t x^*_{ti} =\frac{\sum_{t\in T}\widehat\mu_tN_{ti}}{Q\Delta}.\)

The numerator is a sum of \(\tau\) products of polynomial-bit-length integers; its bit length is polynomial in \(m,\tau,L\). The denominator has polynomial bit length as well. Computing and reducing these fractions therefore takes polynomial time.

5. Complexity classification

The construction and exact solution above form a deterministic algorithm whose running time and output length are polynomial in \(m,\tau,L\).

The algorithm uses the stability promise to establish convergence and nonsingularity. It does not need to compute either spectral radius or a lower bound on the distance from instability. In particular, arbitrarily slow convergence of the recurrence does not obstruct exact polynomial-time computation.

Accordingly, the promised computation problem is polynomial-time solvable. An NP-hardness classification under polynomial-time reductions that produce promised instances would imply \(\mathrm P=\mathrm{NP}\).
