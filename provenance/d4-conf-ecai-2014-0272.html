Packaged proof task (what the prover saw — nothing else)

Let \(V\) be a set of \(m\ge 1\) variables, each with an explicitly listed finite nonempty domain \(D(X)\). Outcomes are complete assignments in \(\Omega=\prod_{X\in V}D(X)\).
A society is given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Type \(t\) carries an explicitly listed finite set \(\Gamma_t\) of preference statements.
A statement \(p\ge q\parallel T\) has partial assignments \(p\) on \(P\subseteq V\) and \(q\) on \(Q\subseteq V\), with \(T\subseteq V\) and \((P\cup Q)\cap T=\varnothing\). It requires \(a\succeq b\) for every pair of outcomes extending \(p,q\), respectively, with \(a(T)=b(T)\); the three sets may be empty and \(P,Q\) may overlap.
A lexicographic model is a sequence of \(k\) distinct variables, \(1\le k\le m\), each equipped with a total order on its domain. It compares outcomes by the first selected variable on which they differ; outcomes agreeing on all selected variables are indifferent. Unselected variables are ignored.
Write \(\Gamma_t\models_{\mathrm{lex}}\alpha\ge\beta\) when every lexicographic model satisfying all statements in \(\Gamma_t\) ranks \(\alpha\) weakly above \(\beta\). If no such model exists, entailment holds vacuously.
Given outcomes \(\alpha,\beta\) and a binary rational threshold \(\rho\in[0,1]\), define \(M_\mu(\alpha,\beta)=\sum_t\mu_t\mathbf{1}[\Gamma_t\models_{\mathrm{lex}}\alpha\ge\beta]\). Let \(L\) be the total input bit length, \(d=\max_X|D(X)|\), and \(s=\sum_t|\Gamma_t|\); state running times in \(m,\tau,L,d,s\).

Is deciding whether \(M_\mu(\alpha,\beta)\ge\rho\) in polynomial time or NP-hard, and is exact computation of \(M_\mu(\alpha,\beta)\) possible in polynomial time?

The threshold decision problem is in \(\mathrm{P}\), and exact computation of \(M_\mu(\alpha,\beta)\) is in \(\mathrm{FP}\).

The essential point is that the input explicitly lists the \(\tau\) supported types. We perform one polynomial-time entailment test per type and then add the selected rational masses exactly.

Individual entailment

Use the given discrete entailment theorem: for this statement language, deciding \(\Gamma\models_{\mathrm{lex}}\alpha\ge\beta\) takes \(O(m^2|\Gamma|\bar d)\) elementary operations, where \(\bar d=m^{-1}\sum_{X\in V}|D(X)|\). The cited paper uses the same partial-assignment statement semantics and lexicographic models with distinct selected variables, total domain orders, and indifference when all selected values agree. Its universal definition of entailment also includes vacuous entailment for inconsistent premises. Thus the theorem applies to the present task. [Wilson (2014), Sections 2.1–2.2 and 4](https://pdfs.semanticscholar.org/ea8e/b22b07ae169b0895e0f1bb0deb2333d62492.pdf)

For each supported type, compute the bit \(e_t=\mathbf{1}[\Gamma_t\models_{\mathrm{lex}}\alpha\ge\beta]\).

Empty premise sets require a minor bookkeeping convention because the quoted running-time expression contains \(|\Gamma|\). If \(\Gamma_t=\varnothing\), then \(e_t=1\) precisely when \(\alpha=\beta\). Indeed, identical outcomes are indifferent in every model. Otherwise, choose a variable on which they differ and a one-variable model placing \(\beta\)'s value strictly above \(\alpha\)'s value. This model satisfies the empty premise set and refutes entailment.

Since \(\bar d\le d\), all entailment bits can therefore be computed in \(O(m^2d(s+\tau))\) elementary operations. This bound includes the empty-set cases and bookkeeping.

Exact rational aggregation

Write each input mass as \(\mu_t=a_t/b_t\), where \(a_t,b_t\) are positive binary integers. The fractions need not be reduced.

Define the positive common denominator \(Q=\prod_{t=1}^{\tau}b_t\), and the integer \(A=\sum_{t=1}^{\tau}e_ta_t(Q/b_t)\). Every division is exact because \(b_t\) divides \(Q\). Consequently,

\[ M_\mu(\alpha,\beta)=\frac{A}{Q}. \]

The large numerical value of \(Q\) does not cause an exponential output length. If \(\ell(n)\) denotes the binary length of a positive integer, then \(\ell(Q)\le 1+\sum_{t=1}^{\tau}\ell(b_t)=O(L)\).

Moreover, the promise that the masses sum to one gives \(\sum_{t=1}^{\tau}a_t(Q/b_t)=Q\). Since each \(e_t\) is either zero or one, it follows that \(0\le A\le Q\). Thus \(A\) also has \(O(L)\) bits, and the exact output fraction has polynomial length.

Using schoolbook integer arithmetic, forming \(Q\), computing the exact quotients, and accumulating \(A\) takes \(O(\tau L^2)\) bit operations. Every intermediate integer has \(O(L)\) bits. Returning \(A/Q\) is already an exact answer; reducing the fraction, if desired, also takes polynomial time.

Threshold comparison and total running time

Write the threshold as \(\rho=h/c\), with \(c>0\) and \(0\le h\le c\). Because both denominators are positive,

\[ M_\mu(\alpha,\beta)\ge\rho \quad\Longleftrightarrow\quad Ac\ge hQ. \]

Both products have \(O(L)\) bits, so this comparison takes \(O(L^2)\) bit operations. It preserves equality exactly and introduces no rounding error.

After polynomial-time indexing of the explicitly listed input, the entailment stage takes \(O(m^2d(s+\tau))\) elementary discrete operations, and rational aggregation takes \(O(\tau L^2)\) bit operations. Charging conservatively \(O(L)\) bit operations for each elementary discrete operation gives the overall bound

\[ O\!\left(m^2d(s+\tau)L+\tau L^2\right). \]

This bound covers both exact computation and threshold decision. Explicit listing ensures that \(m,\tau,d,s\) are bounded by the input length, so the bound is polynomial in \(L\).

Therefore the threshold problem is polynomial-time solvable; an NP-hardness result under polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\). Exact aggregation is likewise polynomial-time computable.
