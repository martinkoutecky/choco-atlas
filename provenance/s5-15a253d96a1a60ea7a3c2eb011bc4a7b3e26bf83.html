The continuous mirror question, as graded

Given a finite support \(T\) of workload types with positive rational workloads \(w_t\) and population masses \(\mu_t\) summing to \(1\), choose assignment masses \(x_{ti}\geq 0\) satisfying \(\sum_{i=1}^{k}x_{ti}=\mu_t\), and minimize \(\max_i L_i/\min_i L_i\), where \(L_i=\sum_{t\in T}w_t x_{ti}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) workload types, each with a positive binary rational workload \(w_t\) and positive binary rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m=k\) identical processors, where \(k\geq2\) is fixed. An assignment consists of divisible masses \(x_{ti}\in\mathbb{R}_{\geq0}\) satisfying \(\sum_{i=1}^{k}x_{ti}=\mu_t\) for every type; all mass must be assigned.
Define \(L_i=\sum_{t\in T}w_tx_{ti}\) and minimize \(R(x)=\max_iL_i/\min_iL_i\), assigning \(R(x)=+\infty\) when \(\min_iL_i=0\). Let \(\mathrm{OPT}\) denote the minimum ratio. The input also includes a binary rational \(\varepsilon\in(0,1)\); \(L\) is the total input bit length. State running times in \(m=k\), \(\tau\), \(L\), and \(1/\varepsilon\).

For each fixed \(k\geq2\), does this continuous problem admit an FPTAS producing a rational assignment with \(R(x)\leq(1+\varepsilon)\mathrm{OPT}\) in time polynomial in \(\tau\), \(L\), and \(1/\varepsilon\), or can such a scheme be ruled out assuming \(\mathsf{P}\ne\mathsf{NP}\)?

For the discrete problem of partitioning \(n\geq k\) positive integers among \(k\) subsets to minimize the same ratio, an FPTAS runs in \(O(n^{2k}/\varepsilon^{k-1})\) time for fixed \(k\) ([verified result](https://arxiv.org/html/2503.18241v3)).

Answer

For every fixed \(k\geq2\), the stated continuous problem admits an exact polynomial-time algorithm, hence an FPTAS. In fact, \(\mathrm{OPT}=1\) for every instance.

Unrestricted divisibility makes the entire stated class exactly balanceable. I use the specified assignment model, in which each type’s mass may be divided among all processors. A stronger structural result is proved below: exact balance requires splitting at most \(k-1\) types.

Exact optimum and rational assignment

Define the total workload
\(W=\sum_{t\in T}w_t\mu_t\).
Because the support is nonempty and all workloads and masses are positive, \(W>0\).

For every feasible assignment, conservation of mass gives
\[ \sum_{i=1}^{k}L_i =\sum_{t\in T}w_t\sum_{i=1}^{k}x_{ti} =\sum_{t\in T}w_t\mu_t =W. \]
If its minimum load is positive, its maximum load is at least its minimum load, so its ratio is at least \(1\). Otherwise its ratio is \(+\infty\). Thus \(\mathrm{OPT}\geq1\).

Now assign
\[ x_{ti}=\frac{\mu_t}{k} \qquad(t\in T,\ 1\leq i\leq k). \]
These numbers are nonnegative rationals, and \(\sum_{i=1}^{k}x_{ti}=\mu_t\), so the assignment is feasible. Every processor has load
\[ L_i=\sum_{t\in T}w_t\frac{\mu_t}{k}=\frac{W}{k}>0. \]
Consequently, its ratio is \(1\), proving \(\mathrm{OPT}=1\). For every input accuracy parameter \(\varepsilon\in(0,1)\), it therefore satisfies
\[ R(x)=1\leq(1+\varepsilon)\mathrm{OPT}. \]

Bit complexity and FPTAS guarantee

Write each input mass as \(\mu_t=p_t/q_t\), with positive binary integers \(p_t,q_t\). Output each entry as
\[ x_{ti}=\frac{p_t}{kq_t}. \]
Each numerator and denominator has bit length \(O(L+\log k)\). Using schoolbook integer arithmetic, a conservative bound for reading the input and producing the explicit assignment is
\[ O\!\left(m\tau(L+\log m)^2\right), \qquad m=k. \]
For fixed \(k\), this is \(O(\tau L^2)\). The output length is at most \(O(m\tau(L+\log m))\).

The algorithm’s running time is independent of \(1/\varepsilon\), apart from reading the accuracy parameter already included in \(L\). It is therefore polynomial in \(\tau\), \(L\), and \(1/\varepsilon\), as required. This conclusion holds without any assumption about \(\mathsf{P}\) and \(\mathsf{NP}\).

Stronger result: an exact assignment splitting few types

Call a type *split* if its mass is positive on at least two processors. There exists a rational optimal assignment with at most \(k-1\) split types and at most \(\tau+k-1\) positive assignment entries.

To prove this, order the types arbitrarily and define
\[ a_t=w_t\mu_t,\qquad A_0=0,\qquad A_t=\sum_{s=1}^{t}a_s,\qquad B=\frac{W}{k}. \]
The type intervals \(I_t=[A_{t-1},A_t]\) partition the workload interval \([0,W]\), up to endpoints. The processor intervals \(J_i=[(i-1)B,iB]\) do likewise.

Let \(y_{ti}\) be the length of their intersection:
\[ y_{ti} =\max\!\left\{0,\, \min\{A_t,iB\}-\max\{A_{t-1},(i-1)B\} \right\}, \qquad x_{ti}=\frac{y_{ti}}{w_t}. \]
All these quantities are rational. Since endpoints have zero length, the two interval partitions give
\[ \sum_{i=1}^{k}y_{ti}=a_t, \qquad \sum_{t=1}^{\tau}y_{ti}=B. \]
Hence each type’s assigned mass sums to \(a_t/w_t=\mu_t\), and every processor’s load equals \(B\). This assignment is optimal.

A split type must contain at least one processor boundary \(iB\), with \(1\leq i<k\), strictly inside its interval. Distinct type intervals have disjoint interiors, so distinct split types require distinct boundaries. There are only \(k-1\) such boundaries.

Finally, the combined interval partition has at most \((\tau-1)+(k-1)\) distinct interior boundaries, hence at most \(\tau+k-1\) positive-length pieces. Each positive intersection \(I_t\cap J_i\) is exactly one such piece, proving the bound on positive entries.

The cited [discrete approximation result](https://arxiv.org/html/2503.18241v3) concerns partitioning indivisible integers. Here, divisibility directly supplies exact balance, so that discrete FPTAS is unnecessary.
