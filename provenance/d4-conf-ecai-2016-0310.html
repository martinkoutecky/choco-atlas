The continuous mirror question, as graded

Given finitely many agent types \(i\) with masses \(\mu_i\), item types \(j\) with per-capita supplies \(q_j\) summing to \(1\), ordinal utilities \(u_{ij}\in L\), and a succinct coordinatewise monotone capacity ν on mass vectors, find a feasible mass plan \(x_{ij}\ge 0\) satisfying \(\sum_j x_{ij}=\mu_i\) and \(\sum_i x_{ij}=q_j\) that maximizes \(\max_{\lambda\in L}\min\{\lambda,\nu(r^\lambda)\}\), where \(r_i^\lambda=\sum_{j:u_{ij}\succeq\lambda}x_{ij}\). Each individual receives one indivisible item; atomlessness allows a type cohort to be partitioned to realize its mass flows. What is the complexity of this optimization problem as a function of the type counts, |L|, rational bit lengths, and capacity-circuit size?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) agent types with positive binary-rational masses \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\) item types with positive binary-rational supplies \(q_j\) satisfying \(\sum_jq_j=1\), and utilities \(u_{ij}\in\mathcal L\), where \(\mathcal L\) is an explicitly ordered finite ordinal scale with distinct endpoints \(\bot\) and \(\top\); ties are allowed.
A capacity is a map \(\nu:\prod_i[0,\mu_i]\to\mathcal L\), promised coordinatewise nondecreasing, with \(\nu(0)=\bot\) and \(\nu(\mu)=\top\). It is supplied by a Boolean circuit whose input predicates are rational affine comparisons \(a\cdot r\ge b\), with signed binary-rational coefficients, and whose output encodes a scale element. Let \(C\) be its size and \(L\) the total input bit length.
A feasible mass plan has real entries \(x_{ij}\ge0\), row sums \(\sum_jx_{ij}=\mu_i\), and column sums \(\sum_ix_{ij}=q_j\). Each individual receives one indivisible item; atomless type cohorts may be partitioned to realize these flows.
Define \(r_i^\lambda=\sum_{j:u_{ij}\succeq\lambda}x_{ij}\) and \(F(x)=\max_{\lambda\in\mathcal L}\min\{\lambda,\nu(r^\lambda)\}\), with minimum and maximum taken in the ordinal order.

Is finding a feasible mass plan maximizing \(F(x)\) solvable in polynomial time in \(m,\tau,|\mathcal L|,L,C\), or is it NP-hard?

Discrete one-to-one assignment maximizing the Sugeno integral is NP-hard even with two utility levels and polynomial-time capacity evaluation; capacities depending only on coalition cardinality admit polynomial-time optimization. [Drissi Oudghiri et al. (2016)](https://doi.org/10.3233/978-1-61499-672-9-1406)
No result settling this exact atomless problem with the specified capacity representation was identified in the literature search.

Result

Finding an optimal feasible mass plan is \(\mathrm{NP}\)-hard. This holds even with only two utility levels, distinct utility vectors for all supported agent types, and a capacity computed by a monotone Boolean formula whose input predicates test whether individual coordinates equal their maximum masses.

We prove this by a polynomial reduction from satisfiability of formulas in conjunctive normal form with at most three literals per clause, a standard \(\mathrm{NP}\)-complete problem. See [Karp’s original paper](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

1. Construction of the society

Let \(\varphi\) be such a formula on \(n\ge 1\) variables, with nonempty clauses. Choose a power of two \(N\) satisfying \(n\le N<2n\), and pad the variable list with unused variables. Put \(a=1/(4N)\).

Use the scale \(\mathcal L=\{\bot,\top\}\), ordered by \(\bot\prec\top\).

There are \(2N+1\) supported agent types:

  • One auxiliary type \(h\), with mass \(\mu_h=1/2\).
  • Two literal types \((i,+)\) and \((i,-)\) for every variable \(i\), each with mass \(a\).

Their masses sum to \(1/2+2Na=1\).

There are \(2N+2\) item types:

  • A common good item \(G\), with supply \(q_G=1/4\).
  • A common bad item \(B\), with supply \(q_B=1/4\).
  • A private item \(P_{i,s}\) for every literal type \((i,s)\), with supply \(q_{P_{i,s}}=a\).

Their supplies sum to \(1/4+1/4+2Na=1\). All masses and supplies are positive dyadic rationals.

Specify utilities as follows:

  • Type \(h\) has utility \(\top\) for every private item and utility \(\bot\) for \(G\) and \(B\).
  • Literal type \((i,s)\) has utility \(\top\) for \(G\) and \(P_{i,s}\), and utility \(\bot\) for every other item.

The literal types have distinct utility vectors because their private items differ. The auxiliary type is distinct from every literal type because it assigns utility \(\bot\) to \(G\).

2. Construction and validity of the capacity

For \(r\) in the capacity’s domain, define Boolean predicates

\[ H(r)=[r_h\ge 1/2], \qquad Y_{i,s}(r)=[r_{i,s}\ge a]. \]

Here brackets denote the truth value of the enclosed comparison. Because the domain bounds are \(r_h\le 1/2\) and \(r_{i,s}\le a\), these predicates test whether the corresponding coordinate has reached its full mass.

Associate each literal \(\ell\) with a predicate \(Y_\ell\): the literal \(z_i\) uses \(Y_{i,+}\), and \(\neg z_i\) uses \(Y_{i,-}\).

Define the Boolean formula

\[ A(r)= H(r) \wedge \bigwedge_{i=1}^{N}\bigl(Y_{i,+}(r)\vee Y_{i,-}(r)\bigr) \wedge \bigwedge_{D\in\varphi}\left(\bigvee_{\ell\in D}Y_\ell(r)\right). \]

Set \(\nu(r)=\top\) when \(A(r)\) is true, and \(\nu(r)=\bot\) otherwise.

This capacity satisfies every representation promise:

  • Each input predicate is a permitted rational affine comparison.
  • Each predicate is coordinatewise nondecreasing. Conjunction and disjunction preserve this property, so \(\nu\) is coordinatewise nondecreasing.
  • At \(r=0\), \(H(r)\) is false, giving \(\nu(0)=\bot\).
  • At \(r=\mu\), all predicates are true. Every clause is nonempty, so \(\nu(\mu)=\top\).

The capacity uses only full-mass thresholds and monotone Boolean gates.

3. The objective and the supply bound

For the two-element scale, the term indexed by \(\bot\) in the Sugeno objective is always \(\bot\), whereas the term indexed by \(\top\) is \(\nu(r^\top)\). Consequently,

\[ F(x)=\nu(r^\top). \]

Thus achieving objective \(\top\) is equivalent to making \(A(r^\top)\) true.

Write \(r=r^\top\). Every type assigns utility \(\bot\) to \(B\). Using nonnegativity and the column-sum constraints gives

\[ \sum_t r_t = \sum_{j\ne B}\sum_{t:u_{tj}=\top}x_{tj} \le \sum_{j\ne B}\sum_t x_{tj} = \sum_{j\ne B}q_j = \frac34. \]

The index \(t\) ranges over all supported agent types. This bound holds for every feasible real mass plan.

4. Soundness: objective \(\top\) implies satisfiability

Suppose a feasible plan satisfies \(F(x)=\top\). Then \(A(r)\) is true.

The auxiliary predicate forces \(r_h=1/2\). For each variable \(i\), at least one of \(r_{i,+}\) and \(r_{i,-}\) equals \(a\). Therefore,

\[ \sum_t r_t = r_h+\sum_{i=1}^{N}(r_{i,+}+r_{i,-}) \ge \frac12+Na = \frac34. \]

Together with the supply bound, this implies equality. More explicitly, each number \(r_{i,+}+r_{i,-}-a\) is nonnegative, and their sum is zero. Hence, for every \(i\),

\[ r_{i,+}+r_{i,-}=a. \]

At least one coordinate in this pair equals \(a\), so the other must equal zero. Thus exactly one of \(Y_{i,+}(r)\) and \(Y_{i,-}(r)\) is true.

Define a Boolean assignment by setting \(z_i\) true precisely when \(Y_{i,+}(r)\) is true. Under this assignment, \(Y_\ell(r)\) is true precisely when the literal \(\ell\) is satisfied. Every clause disjunction in \(A(r)\) is true, so this assignment satisfies \(\varphi\).

This argument allows arbitrary real entries in the plan: no integrality assumption was used.

5. Completeness: satisfiability implies objective \(\top\)

Conversely, suppose \(\varphi\) is satisfiable. Extend a satisfying assignment arbitrarily to the padded variables. For each \(i\), let \(s_i\) denote its satisfied literal sign.

Construct a plan by the following allocations, setting all other entries to zero:

  • Give type \(h\) mass \(a\) of each private item.
  • Give literal type \((i,s_i)\) mass \(a\) of \(G\).
  • Give the other literal type for variable \(i\) mass \(a\) of \(B\).

The auxiliary row receives \(2Na=1/2\), and each literal row receives \(a\). The columns for \(G\) and \(B\) each receive \(Na=1/4\), and every private column receives \(a\). Hence the plan is feasible.

Its top-utility masses are \(r_h=1/2\), \(r_{i,s_i}=a\), and zero for the opposite literal types. The auxiliary predicate, all variable-pair predicates, and all clause predicates are therefore true. Thus \(F(x)=\top\).

These rational flows can be realized by partitioning the atomless cohorts, exactly as allowed in the question.

6. Complexity conclusion

The construction has support size \(\tau=2N+1\), item count \(m=2N+2\), and scale size \(|\mathcal L|=2\). Its utility table, capacity circuit, and numerical encodings all have size polynomial in the formula’s input length. In particular, the dyadic numbers require only logarithmically many bits in \(N\).

We have proved the equivalence

\[ \varphi\text{ is satisfiable} \quad\Longleftrightarrow\quad \max_{x\text{ feasible}}F(x)=\top. \]

An exact polynomial-time optimizer would therefore decide this satisfiability problem by evaluating the returned plan’s objective. Hence finding an optimal mass plan is \(\mathrm{NP}\)-hard, and a polynomial-time algorithm for all specified inputs would imply \(\mathrm{P}=\mathrm{NP}\).

Divisibility does not eliminate the hardness: the capacity’s full-mass thresholds and the tight supply bound force exactly one full literal cohort per variable.
