The continuous mirror question, as graded

Given finite man and woman type sets \(M,W\) and a supported distribution \(\mu\) over matched pairs \((m,w)\), with binary-rational masses summing to \(1\), define \(\nu_w=\sum_m\mu_{mw}\). For a quota \(q\in(0,1]\), does there exist \(W'\subseteq W\) with \(\sum_{w\in W'}\nu_w\ge q\) such that restricting \(\mu\) to pairs incident to \(W'\) yields a rationalisable matching? Renormalise the restricted distribution to total mass \(1\); rationalisability is the paper's notion, with strict preferences for each retained type and no blocking pair.

Packaged proof task (what the prover saw — nothing else)

Let \(M,W\) be disjoint finite sets of man and woman types, and put \(m=|M|+|W|\). A society is given by its support: the list of the \(\tau\) matched-pair types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Write these masses as \(\mu_{ab}\), set unlisted masses to zero, and require \(\sum_{a\in M,b\in W}\mu_{ab}=1\).
The input also contains a binary-rational quota \(q\in(0,1]\). Define \(\nu_b=\sum_{a\in M}\mu_{ab}\), and let \(L\) be the total input bit length. State running times in \(m,\tau,L\).
A choice \(W'\subseteq W\) retains every pair incident to a selected woman type, with no partial removal or reassignment. Its retained mass is \(s=\sum_{b\in W'}\nu_b\); when \(s\ge q\), its normalized matching is \(\rho_{ab}=\mu_{ab}/s\) on \(M\times W'\).
This matching is rationalisable if there exist strict linear orders \(\succ_a\) over \(W'\) for every \(a\in M\), and \(\succ_b\) over \(M\) for every \(b\in W'\), with no blocking pair.
A pair \((a,b)\in M\times W'\), whether supported or not, blocks if some \(a'\in M,b'\in W'\) satisfy \(\rho_{a'b}>0\), \(\rho_{ab'}>0\), \(a\succ_b a'\), and \(b\succ_a b'\). There are no singles, outside options, transfers, or individual-rationality constraints.

Is deciding whether some \(W'\subseteq W\) retains mass at least \(q\) and yields a rationalisable matching solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For integer aggregate matchings, deciding whether a rationalisable woman-type restriction retains at least \(K\) woman types is \(\mathrm{NP}\)-complete; testing rationalisability of a fixed matching is polynomial-time ([Demuynck–Salman, 2022](https://onlinelibrary.wiley.com/doi/full/10.3982/TE4723)).
The same source permits nonnegative real matching quantities, but its type-removal result uses retained cardinality. No result settling exactly the retained-mass decision problem above was located.

Modeling choices made when packaging the task

  • The quota's encoding was unspecified; take it to be a binary rational and include it in total input bit length L.
  • Define m as the total number of man and woman types, and tau as the number of positive-mass matched-pair types in the supplied joint distribution.
  • Specify blocking over all retained cross-type pairs, including unsupported pairs, using positive masses for both existing partner combinations.
  • Keep the full man-type set after restriction, with preferences over all selected woman types, as in woman-type reduction.
  • Use the published NTU convention excluding singles, outside options, transfers, and individual-rationality constraints.

Result

The retained-mass decision problem is \(\mathrm{NP}\)-complete, even when every woman type has the same positive total mass. The key is that rationalisability depends only on the support, so an instance of the retained-cardinality problem can be reweighted to make cardinality and mass proportional.

The main reduction uses rationals whose numerators and denominators are encoded in binary. A refinement below proves hardness even if “binary rational” means a dyadic rational.

1. Rationalisability depends only on support

Lemma. Suppose two nonnegative matching arrays \(X\) and \(Y\), on the same type sets, satisfy
\[ X_{ab}>0\quad\Longleftrightarrow\quad Y_{ab}>0 \]
for every \((a,b)\). Then they are rationalisable under exactly the same preference profiles.

Proof. Fix a preference profile. Whether \((a,b)\) blocks depends only on the existence of \(a',b'\) for which both matching entries \(X_{a'b}\) and \(X_{ab'}\) are positive, together with the two strict preference comparisons. Replacing \(X\) by \(Y\) changes none of these conditions. Thus the blocking pairs are identical. Taking existence over preference profiles proves the claim.

In particular, dividing a retained matching by its positive total mass does not affect rationalisability.

We also use the following established characterization: form the bipartite support graph with vertices \(M\cup W\) and one edge for each positive matching entry. A matching is rationalisable precisely when every connected component has at most as many edges as vertices. This is Theorem 2(i) of [Demuynck–Salman (2022)](https://onlinelibrary.wiley.com/doi/full/10.3982/TE4723).

Its hypotheses match the task: preferences are strict linear orders, blocking is defined through positive matching entries, and singles and individual-rationality constraints are absent. For rational quantities, one may apply the theorem to the integer array having entry \(1\) on the support and \(0\) elsewhere, and then apply the lemma.

2. Reduction from retained cardinality

Use the \(\mathrm{NP}\)-complete problem stated in the question: given an integer aggregate matching \(X\) and an integer \(K\), decide whether a rationalisable woman-type restriction retains at least \(K\) woman types. This is the woman-type problem in Proposition 4 of [Demuynck–Salman (2022)](https://onlinelibrary.wiley.com/doi/full/10.3982/TE4723).

Removing zero columns

Let \(Z\) be the set of woman types whose columns in \(X\) are identically zero, and put
\[ z=|Z|,\qquad B=W\setminus Z,\qquad n=|B|,\qquad k=K-z. \]

Adding or removing zero columns preserves rationalisability. Indeed, their support vertices are isolated, so they satisfy the graph characterization and do not change any other component.

Consequently, the source instance is affirmative exactly when some \(S\subseteq B\) with \(|S|\ge k\) gives a rationalisable restriction:

  • From an affirmative restriction \(T\subseteq W\), take \(S=T\setminus Z\). Then \(|S|\ge |T|-z\ge k\).
  • Conversely, add all of \(Z\) to an affirmative \(S\). The resulting restriction retains at least \(k+z=K\) types.

If \(k\le 0\), the source answer is affirmative; if \(k>n\), it is negative. These cases can be mapped to fixed affirmative and negative target instances. Thus consider \(1\le k\le n\).

For completeness, a fixed affirmative target has one pair of mass \(1\) and quota \(1\). A fixed negative target has complete bipartite support on two man types and three woman types, masses \(1/8\) on each entry in the first two columns and \(1/4\) on each entry in the third column, and quota \(1\). Its total mass is \(1\); all columns must be retained; its connected support has six edges and five vertices.

Equalizing woman masses

For each \(b\in B\), define its support degree
\[ d_b=|\{a\in M:X_{ab}>0\}|. \]
By construction, \(d_b\ge 1\).

Construct the target society on \(M\) and \(B\) by setting
\[ \mu_{ab}= \begin{cases} 1/(n d_b),&X_{ab}>0,\\ 0,&X_{ab}=0, \end{cases} \qquad q=\frac{k}{n}. \]

Each woman type has total mass
\[ \nu_b=d_b\frac{1}{n d_b}=\frac1n. \]
Hence all masses sum to \(1\), and \(q\in(0,1]\).

For every \(S\subseteq B\), its retained mass is
\[ s=\sum_{b\in S}\nu_b=\frac{|S|}{n}. \]
Therefore,
\[ s\ge q\quad\Longleftrightarrow\quad |S|\ge k. \]

Moreover, the restriction of \(\mu\) to \(M\times S\) has exactly the support of the corresponding restriction of \(X\). By the lemma, they have identical rationalisability status, and normalization changes nothing.

This proves both directions of the reduction. In particular, reweighting occurs when constructing the target input; each subsequent choice retains whole woman columns exactly as required.

Encoding size

Let \(m_0,\tau_0,L_0\) denote the source parameters. The construction introduces no types or support entries, so the target satisfies \(m\le m_0\) and \(\tau=\tau_0\).

Since \(n,d_b\le m_0\), each denominator \(n d_b\) has \(O(\log(m_0+1))\) bits. After numbering the types, the target length is
\[ L=O((m_0+\tau_0)\log(m_0+1)). \]
Scanning the input, counting degrees, and writing the fractions takes polynomial time; using elementary integer arithmetic, a bound is
\[ O\!\left(L_0+(m_0+\tau_0)\log^2(m_0+1)\right). \]

Thus the target problem is \(\mathrm{NP}\)-hard.

3. Hardness also holds for dyadic masses

If only rationals with power-of-two denominators are allowed, modify the nontrivial construction as follows.

Let \(N\) be the least power of two satisfying \(N\ge n\), and put \(p=N-n\). Add \(p\) private man–woman pairs, each forming a separate single-edge support component. There are now \(N\) woman types. By the graph characterization, adding any of these components preserves rationalisability.

Let \(D\) be the least power of two at least as large as every woman’s support degree. For a woman of degree \(d\), enumerate her supported entries and assign:

  • mass \(1/(ND)\) to the first \(d-1\) entries;
  • mass \((D-d+1)/(ND)\) to the last entry.

All supported masses are positive dyadic rationals. Their column sum is
\[ \frac{d-1+D-d+1}{ND}=\frac1N. \]
Thus the total mass is \(1\). Set the dyadic quota
\[ q=\frac{k+p}{N}. \]

If a selection retains \(r\) original women and \(t\) added women, the quota condition is \(r+t\ge k+p\). Since \(t\le p\), this implies \(r\ge k\). Conversely, any rationalisable selection of at least \(k\) original women reaches the quota by retaining all \(p\) added women.

The original restriction is rationalisable exactly when the augmented restriction is: the added components are isolated single edges. This proves the same reduction with exclusively dyadic data. Since \(N<2n\) and \(D<2m_0\), both the number of added types and the encoding length remain polynomial.

4. Membership in \(\mathrm{NP}\) and running times

A certificate consists only of the selected set \(W'\).

The verifier first sums the listed masses incident to \(W'\) and checks \(s\ge q\) using exact rational arithmetic. It then constructs the retained support graph and checks that every connected component has at most as many edges as vertices.

The graph check takes \(O(m+\tau)\) word operations. For exact arithmetic, intermediate numerators and denominators can be kept to \(O(L)\) bits: a denominator dividing the product of the input denominators suffices, and every partial mass sum lies in \([0,1]\). With schoolbook arithmetic, the quota check takes \(O((\tau+1)L^2)\) bit operations. Thus verification is polynomial in \(m,\tau,L\).

An exhaustive decision algorithm, included to state an explicit general upper bound, uses
\[ O\!\left(2^{|W|}\bigl(m+\tau+(\tau+1)L^2\bigr)\right) \]
time under standard graph-operation accounting.

The decision problem is therefore \(\mathrm{NP}\)-complete. A polynomial-time algorithm in \(m,\tau,L\) exists only if \(\mathrm{P}=\mathrm{NP}\).
