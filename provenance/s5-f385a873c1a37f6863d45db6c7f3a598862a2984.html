The continuous mirror question, as graded

Given a finite support \(T\) of claimant types with rational masses \(\mu_t>0\), \(\sum_{t\in T}\mu_t=1\), per-person claim amounts \(a_t\geq 0\), relative strengths \(w_t>0\) normalized by \(\sum_{t\in T}\mu_t w_t=1\), and estate \(e>0\) per claimant with \(\sum_{t\in T}\mu_t a_t\geq e\), compute the per-person awards \(x_t=\min\{\lambda_* w_ta_t,a_t\}\), where \(\lambda_*\) is the least nonnegative value satisfying \(\sum_{t\in T}\mu_t\min\{\lambda_* w_ta_t,a_t\}=e\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) claimant types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a binary rational per-person claim \(a_t\geq0\) and relative strength \(w_t>0\), with \(\sum_{t\in T}\mu_tw_t=1\). The binary rational estate per claimant is \(e>0\), with \(\sum_{t\in T}\mu_ta_t\geq e\).
Define \(\lambda_*\) as the least nonnegative real satisfying \(\sum_{t\in T}\mu_t\min\{\lambda_*w_ta_t,a_t\}=e\). The required output is the exact per-person award vector \(x_t=\min\{\lambda_*w_ta_t,a_t\}\).
Let \(L\) be the total binary input length; state running times in \(\tau\) and \(L\). There is no separate alternative-count parameter \(m\).

Is computing this exact award vector solvable in polynomial time in \(\tau\) and \(L\), or is it NP-hard?

For finitely many individual claimants, the capped weighted proportional formula is equivalent to repeatedly distributing the remaining estate proportionally to strength-weighted claims and fully reimbursing and removing claimants whose proportional awards reach their claims (Wintein–Heilmann, 2024).
Continuum claim games have proportionality results for core allocations under merging and splitting, but concern a different problem ([Cetemen–Hasker–Karagözoğlu, 2015](https://hasker.bilkent.edu.tr/Research/Cetemen-Hasker-Karagozoglu-Rewards-Core-JULY-2015.pdf)); no result settling this exact computational question was located.

Modeling choices made when packaging the task

  • The graded question specifies rational masses but leaves the numerical encoding of claims, strengths, and estate unspecified; all are taken to be binary rationals.
  • The computational output is specified as the exact per-person award vector, with total binary input length L as the encoding-size parameter.
  • There is no alternative set in this model, so running times use tau and L without a separate parameter m.

Result

Computing the exact award vector is polynomial-time solvable in \(\tau\) and \(L\). A conservative bound, including reduction of output fractions, is \(O(\tau\log(\tau+1)L^3)\) bit operations.

The [cited continuum paper](https://hasker.bilkent.edu.tr/Research/Cetemen-Hasker-Karagozoglu-Rewards-Core-JULY-2015.pdf) concerns proportionality of core allocations under merging and splitting. The proof here follows directly from the formula in the task.

1. Existence and the least solution

Define
\[ F(\lambda)=\sum_{t\in T}\mu_t\min\{\lambda w_ta_t,a_t\}, \qquad A=\sum_{t\in T}\mu_ta_t. \]

Discard types with \(a_t=0\) temporarily; their awards are zero. Let \(n\leq\tau\) be the number of remaining types. Since \(A\geq e>0\), we have \(n\geq1\).

For a positive-claim type, its award reaches its cap precisely at the breakpoint \(b_t=1/w_t\). Put \(B=\max_{a_t>0}b_t\). The function \(F\) is continuous, with \(F(0)=0\) and \(F(B)=A\geq e\). Thus it attains \(e\) on \([0,B]\).

Moreover, \(F\) is strictly increasing on \([0,B]\). Indeed, choose a positive-claim type \(u\) with \(b_u=B\). For \(0\leq s<r\leq B\), its contribution increases by \(\mu_uw_ua_u(r-s)>0\), while every other contribution is nondecreasing.

Consequently, there is exactly one solution in \([0,B]\), and it is the least nonnegative solution. This also covers \(e=A\): then \(\lambda_*=B\), although every larger value satisfies the equation as well.

2. Exact algorithm

Relabel the positive-claim types so that
\[ b_1\leq b_2\leq\cdots\leq b_n, \qquad b_0=0. \]
Ties may be ordered arbitrarily.

Define \(\alpha_i=\mu_i a_i\) and \(\beta_i=\mu_iw_i a_i\). For each index \(i\), set
\[ C_i=\sum_{k<i}\alpha_k, \qquad S_i=\sum_{k\geq i}\beta_k. \]

For \(\lambda\in[b_{i-1},b_i]\), every type with index less than \(i\) is capped, and every type with index at least \(i\) is uncapped or exactly at its cap. Hence
\[ F(\lambda)=C_i+\lambda S_i. \]

Perform the following steps:

  • Sort the positive-claim types by \(b_i=1/w_i\).
  • Initialize \(C_1=0\) and \(S_1=\sum_{k=1}^n\beta_k\).
  • Scan the indices and find the first \(i\) satisfying \(C_i+b_iS_i\geq e\). After an unsuccessful test, update \(C_{i+1}=C_i+\alpha_i\) and \(S_{i+1}=S_i-\beta_i\).
  • Compute \(\lambda=(e-C_i)/S_i\).
  • Output \(x_t=\min\{\lambda w_ta_t,a_t\}\) for every original type.

The scan terminates because \(F(b_n)=A\geq e\). Also, \(S_i>0\), since it includes \(\beta_i>0\).

3. Correctness

Let \(i\) be the first successful index. If \(i=1\), then \(F(b_0)=0<e\). Otherwise, the preceding unsuccessful test gives \(F(b_{i-1})<e\). Thus
\[ C_i+b_{i-1}S_i<e\leq C_i+b_iS_i. \]

Dividing by the positive number \(S_i\) yields
\[ b_{i-1}<\frac{e-C_i}{S_i}\leq b_i. \]

Therefore the computed \(\lambda\) belongs to the interval where \(F(\lambda)=C_i+\lambda S_i\), and substitution gives \(F(\lambda)=e\). By the uniqueness proved above, \(\lambda=\lambda_*\).

The returned awards consequently equal the required vector exactly. Repeated breakpoints cause no difficulty: the interval formula is valid at its endpoints, and the displayed strict lower inequality ensures that the selected interval has positive width.

4. Bit complexity

We must bound rational sizes, rather than merely count arithmetic operations.

Represent every input rational by an integer numerator and a positive integer denominator. Let \(D\) be the product of all input denominators, including those of \(e\). Its bit length is \(O(L)\), because their total encoded length is at most \(L\).

The quantities
\[ U_i=D\mu_i a_i,\qquad V_i=D\mu_iw_i a_i,\qquad E=De \]
are integers: each corresponding denominator product divides \(D\). Each has \(O(L)\) bits. Products use only input factors, and summing at most \(\tau\) such integers adds at most \(O(\log\tau)\) bits; since the support is explicitly listed, \(\log\tau=O(L)\).

Implement the scan using the integer sums
\[ \widehat C_i=\sum_{k<i}U_k,\qquad \widehat S_i=\sum_{k\geq i}V_k. \]

Write \(w_i=p_i/q_i\), where \(p_i,q_i\) are positive integers. The scan condition is exactly
\[ p_i\widehat C_i+q_i\widehat S_i\geq p_iE. \]
Thus every scan test uses integers of \(O(L)\) bits. Sorting breakpoints likewise uses exact cross-multiplication comparisons of input integers.

At the successful index,
\[ \lambda_*=\frac{E-\widehat C_i}{\widehat S_i}. \]
Its numerator and denominator have \(O(L)\) bits. Each award, obtained by multiplication with \(w_ta_t\) and comparison with \(a_t\), also has an exact rational representation of \(O(L)\) bits.

Sorting requires \(O(\tau\log(\tau+1))\) comparisons; preparation, scanning, and output require \(O(\tau)\) further arithmetic operations. Schoolbook arithmetic on \(O(L)\)-bit integers costs \(O(L^2)\) per operation. If reduced output fractions are required, Euclid’s algorithm has the conservative bound \(O(L^3)\) per fraction: it makes \(O(L)\) divisions, each costing \(O(L^2)\).

The total therefore satisfies
\[ O\!\left(\tau\log(\tau+1)L^2+\tau L^3\right) \subseteq O\!\left(\tau\log(\tau+1)L^3\right). \]

This proves polynomial-time exact computation using only the given support; no additional alternative-count parameter is needed.
