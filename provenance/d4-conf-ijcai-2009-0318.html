The continuous mirror question, as graded

Given a finite goods set \(V\), a finite support \(\mathcal{T}\) of satisfiable CI-net types \(N_t\) over \(V\) with binary-rational masses \(\mu_t\ge 0\) summing to \(1\), bundles \(X,Y\subseteq V\), and a binary-rational threshold \(q\in[0,1]\), decide whether \(\sum_{t:\,X\succ_{N_t}Y}\mu_t\ge q\).

Packaged proof task (what the prover saw — nothing else)

A CI-net on a finite goods set \(V\), with \(m=|V|\), is an explicitly listed finite set of statements \((S^+,S^-,S_1,S_2)\) whose four components are pairwise disjoint subsets of \(V\).
A strict partial order \(\succ\) on \(2^V\) satisfies the net if it contains every comparison \(A\succ B\) with \(A\supsetneq B\), and, for each statement and every \(C\subseteq V\setminus(S^+\cup S^-\cup S_1\cup S_2)\), contains \(C\cup S^+\cup S_1\succ C\cup S^+\cup S_2\).
A net is satisfiable if such an order exists; for a satisfiable net \(N\), let \(\succ_N\) be the intersection of all orders satisfying it. Preferences may be incomplete; no completion or tie-breaking is applied.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here each type is a CI-net \(N_t\), and \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
The input promises that every \(N_t\) is satisfiable and supplies bundles \(X,Y\subseteq V\) and a binary-rational threshold \(q\in[0,1]\). Decide whether \(\sum_{t:\,X\succ_{N_t}Y}\mu_t\ge q\). Let \(L\) be the total input bit length, including all net statements, masses, bundles and the threshold; state running times in \(m,\tau,L\).

Is this mass-threshold dominance problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

Single-type dominance for satisfiable CI-nets is \(\mathrm{PSPACE}\)-complete, even with singleton compared sets and no negative preconditions, singleton compared sets and no positive preconditions, or no preconditions ([Bouveret–Endriss–Lang](https://www.lamsade.dauphine.fr/~lang/papers/bel09.pdf)).
No result for this exact distributional mass-threshold problem was identified in the literature search.

Modeling choices made when packaging the task

  • Zero-mass entries are omitted so that the supplied list is precisely the positive-mass support; normalization remains one.
  • CI-nets are represented by explicit lists of statements, and L denotes the total encoded input length.
  • Satisfiability is an input promise, rather than an additional decision requirement.
  • Dominance uses the induced strict partial order without completing incomplete preferences or applying tie-breaking.

Result

The problem is \(\mathrm{PSPACE}\)-complete, and therefore \(\mathrm{NP}\)-hard, under polynomial-time reductions that preserve the satisfiability promise. This holds even with two distinct types, equal masses, and the fixed threshold \(q=\tfrac12\).

Consequently, a polynomial-time algorithm exists only if \(\mathrm{P}=\mathrm{PSPACE}\). The boundary case \(q=0\) always answers yes; the hardness concerns positive thresholds.

1. Dominance is directed reachability

For a satisfiable net \(N\), define a directed graph \(G_N\) with vertex set \(2^V\). Include the following edges, directed from preferred to less preferred bundles:

  • \(A\longrightarrow A\setminus\{v\}\), for every \(v\in A\).
  • Every comparison generated by a CI-statement and an allowed context.

Let \(R_N\) be positive-length reachability in this graph.

Lemma. \(R_N=\succ_N\).

Proof. Every satisfying order contains all graph edges. By transitivity, it therefore contains \(R_N\).

The graph is acyclic: a directed cycle would force \(A\succ A\) in every satisfying order, contradicting irreflexivity. Thus \(R_N\) is itself an irreflexive, transitive relation. It contains all statement comparisons. It also contains every strict inclusion comparison, because deleting the goods in \(A\setminus B\) one at a time gives a path from \(A\) to \(B\) whenever \(A\supsetneq B\).

Hence \(R_N\) is a satisfying strict partial order. Since it is contained in every satisfying order and is itself one of those orders, it equals their intersection. \(\square\)

This argument uses the incomplete induced preference relation directly.

2. Hardness, preserving the promise

The given single-type theorem states that dominance for satisfiable CI-nets is \(\mathrm{PSPACE}\)-complete. Its semantics match those in the question, including strict partial orders and the least satisfying relation. See Proposition 6 of [Bouveret–Endriss–Lang](https://www.lamsade.dauphine.fr/~lang/papers/bel09.pdf).

Given a promised instance \((N,X,Y)\) of single-type dominance, construct a society with:

  • the sole type \(N\);
  • mass \(\mu_1=1\);
  • threshold \(q=\tfrac12\);
  • the same goods and queried bundles.

Its supporting mass is \(1\) if \(X\succ_N Y\), and \(0\) otherwise. Therefore the threshold is met exactly when the source dominance instance answers yes.

The construction is polynomial-time and preserves satisfiability because it leaves the net unchanged. It also preserves each syntactic restriction in the given theorem. Thus the mass-threshold problem is \(\mathrm{PSPACE}\)-hard under each of those restrictions.

Hardness with two distinct, equally weighted types

The conclusion also holds for an actual mixture of distinct types.

Introduce two fresh goods \(a,b\). On \(V'=V\cup\{a,b\}\), let \(N_0\) contain exactly the original statements, and set
\(N_1=N_0\cup\{(\varnothing,\varnothing,\{a\},\{b\})\}\).
Give each type mass \(\tfrac12\), keep the original queries \(X,Y\subseteq V\), and fix \(q=\tfrac12\).

Satisfiability. Since \(G_N\) is a finite acyclic graph, define \(h(A)\) to be the maximum length of a directed path starting at \(A\). Every original edge \(A\longrightarrow B\) satisfies \(h(A)>h(B)\).

For \(Z\subseteq V'\), define
\(H(Z)=h(Z\cap V)+2\mathbf{1}_{a\in Z}+\mathbf{1}_{b\in Z}\).
The relation \(Z\succ W\) defined by \(H(Z)>H(W)\) is a strict partial order. It satisfies monotonicity: adding original goods strictly increases \(h\), and adding either fresh good increases its positive contribution. Every original statement comparison strictly decreases \(h\) while leaving fresh goods unchanged. The added comparison replacing \(a\) by \(b\) decreases \(H\) by \(1\). Hence this order satisfies both \(N_0\) and \(N_1\).

Preservation of dominance. Starting at \(X\), which contains neither fresh good, a graph path under either net can never introduce a fresh good. Original statements preserve their presence, deletion edges only remove goods, and the added rule requires \(a\) to be present. Thus paths from \(X\) remain entirely inside \(2^V\), where their edges are exactly those of \(G_N\).

By the lemma,
\(X\succ_{N_0}Y\iff X\succ_NY\iff X\succ_{N_1}Y\).
The supporting mass is therefore again either \(0\) or \(1\), giving the required reduction.

The two nets are distinct, all masses are positive, and the added statement respects every restriction listed in the question.

3. Polynomial-space algorithm and running times

For each type \(t\), determine whether \(Y\) is reachable from \(X\) in \(G_{N_t}\), and add \(\mu_t\) exactly when it is.

Implicit adjacency and reachability

A bundle occupies \(m\) bits. Given bundles \(A,B\), adjacency can be tested in \(\operatorname{poly}(m,L)\) time and space by checking a single deletion or scanning the explicitly listed statements.

There are \(2^m\) vertices. For distinct endpoints, reachability, if present, has a simple path of length at most \(2^m-1\).

A deterministic polynomial-space procedure can be given explicitly. Let \(R_k(A,B)\) mean that there is a path of length at most \(2^k\), allowing length zero. Define:

  • \(R_0(A,B)\) by equality or adjacency;
  • for \(k\ge1\), \(R_k(A,B)\) holds precisely when some bundle \(Z\) satisfies both \(R_{k-1}(A,Z)\) and \(R_{k-1}(Z,B)\).

This recurrence is correct by splitting a path after at most \(2^{k-1}\) edges; conversely, concatenate the two paths.

Enumerating \(Z\) sequentially requires only an \(m\)-bit counter. Evaluating \(R_m(X,Y)\) has recursion depth \(m\), using \(O(m^2)\) bits for recursion frames. Handle \(X=Y\) separately: strict dominance is false.

Processing types sequentially therefore gives deterministic bounds of
\(\tau\,2^{O(m^2)}\operatorname{poly}(m,L)\) time and \(\operatorname{poly}(m,L)\) space.

Exact mass arithmetic

Write each mass as a binary-encoded fraction \(p_t/d_t\). Accumulate the selected masses using
\(n/d+p_t/d_t=(nd_t+p_td)/(dd_t)\).

The accumulated denominator has bit length bounded by the sum of the input denominator lengths, hence \(O(L)\). Every partial sum lies in \([0,1]\), so its numerator also has \(O(L)\) bits. Comparing the accumulated sum with \(q\) by cross multiplication is exact and uses polynomial time and space. Schoolbook arithmetic suffices for an \(O(L^3)\) total arithmetic bound.

Under the explicit input representation, these space bounds are polynomial in the input length. This proves membership in \(\mathrm{PSPACE}\).

Faster algorithm using exponential space

Alternatively, search each graph explicitly. From any bundle there are at most \(m\) deletion successors and one successor per applicable statement. A breadth-first search visits at most \(2^m\) bundles.

This yields deterministic time
\(\tau\,2^m\operatorname{poly}(m,L)+O(L^3)\)
and space
\(O(m2^m)+\operatorname{poly}(m,L)\),
reusing the search storage between types.

In particular, for fixed \(m\), the problem is polynomial-time solvable in \(\tau\) and \(L\). For unrestricted \(m\), the hardness and polynomial-space algorithm establish the claimed completeness.
