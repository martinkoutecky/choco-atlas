Theorem 1 — class: other

The continuous mirror question, as graded

Given \(N \ge 2\), a finite type set \(\Theta\), rational masses \(\mu_\theta\) summing to \(1\), and rational geometric discount factors \(\delta_\theta \ge (2N-3)/(2N-2)\), decide whether there are Borel probability measures \(\lambda_\theta\) over integral schedules \(S \subseteq \mathbb{N}\) such that \(\lambda_\theta\)-almost every \(S\) has \(u_\theta(S) \ge 1/N\) and, for every date \(t\), \(\sum_{\theta \in \Theta}\mu_\theta\lambda_\theta(\{S:t\in S\})=1/N\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive masses \(q_\theta\), each a binary rational; \(\tau\) is the support size, not the number of possible types.
The input includes a binary integer \(N\ge2\), with \(\sum_\theta q_\theta=N\), and binary rational discount factors \(\frac{2N-3}{2N-2}\le\delta_\theta<1\). Let \(L\) be the total input bit length.
Dates are \(T=\{1,2,\ldots\}\), and type \(\theta\) values a whole schedule \(S\subseteq T\) by \(u_\theta(S)=(1-\delta_\theta)\sum_{t\in S}\delta_\theta^{t-1}\).
Represent the atomless population as the disjoint union \(A=\bigsqcup_\theta A_\theta\), where \(A_\theta=\{\theta\}\times[0,q_\theta)\), with Lebesgue measure \(\mu\).
An assignment gives each \(a\in A\) a schedule \(S_a\subseteq T\), with \(\{a:t\in S_a\}\) measurable for every date \(t\). It is feasible if \(u_\theta(S_a)\ge1/N\) for every \(a\in A_\theta\), and \(\mu(\{a:t\in S_a\})=1\) for every \(t\in T\).
Is deciding whether a feasible assignment exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(\tau\), \(L\), and \(N\); the date universe is infinite, so there is no finite item-count parameter \(m\).
For \(N\) discrete agents, the stated discount bound guarantees a proportional partition of all dates, with a constructive existence proof but no polynomial bit-complexity bound ([source](https://brandlf.com/docs/patience_ensures_fairness.pdf)).
No result settling this exact atomless-population feasibility problem was identified in the literature search.

Modeling choices made when packaging the task

  • The missing upper bound on discount factors is settled as delta strictly below one, preserving normalized geometric utilities.
  • The unspecified atomless population is represented by disjoint Lebesgue intervals of the given type masses; total mass remains N rather than one.
  • Measurability means that each date's recipient set is measurable; proportionality is required for every member, as stated in the continuous question.
  • The computational target concerns existence, avoiding an unspecified finite representation of an infinite measurable assignment.
  • There is no finite item-count parameter m because the date universe is countably infinite; running times use support size, input bit length, and N.

Result

Every instance satisfying the stated promises is feasible. Thus the decision problem is in \(\mathrm{P}\). In fact, the weaker discount bound \(\delta_\theta\ge (N-1)/N\) suffices.

The key is that each type can use its own partition of the dates. Splitting that type’s population equally among its schedules then gives exactly the required mass at every date.

1. Equal-value partitions for one discount factor

Lemma. Let \(N\ge 2\) be an integer and let \((N-1)/N\le\delta<1\). There is a partition \(T=S_1\sqcup\cdots\sqcup S_N\) such that, for every \(i\in\{1,\ldots,N\}\),

\[ (1-\delta)\sum_{t\in S_i}\delta^{t-1}=\frac1N. \]

Proof. Write \(e_i\) for the \(i\)-th coordinate vector. Starting with \(r^{(0)}=(1/N,\ldots,1/N)\), recursively choose an index \(j_t\) whose coordinate in \(r^{(t-1)}\) is largest, breaking ties by the smallest index, and define

\[ r^{(t)}=\frac{r^{(t-1)}-(1-\delta)e_{j_t}}{\delta}. \]

We first prove inductively that every \(r^{(t)}\) has nonnegative coordinates summing to one. This holds at \(t=0\). If it holds at \(t-1\), then the largest coordinate satisfies

\[ r^{(t-1)}_{j_t}\ge\frac1N\ge 1-\delta. \]

Consequently, every coordinate of \(r^{(t)}\) is nonnegative. Their sum is \((1-(1-\delta))/\delta=1\), completing the induction. In particular, every coordinate belongs to \([0,1]\).

Rearranging the recurrence and substituting it repeatedly gives, for every positive integer \(h\),

\[ r^{(0)}=(1-\delta)\sum_{t=1}^{h}\delta^{t-1}e_{j_t}+\delta^h r^{(h)}. \]

Define \(S_i=\{t\in T:j_t=i\}\). Exactly one index is chosen at each date, so these schedules partition \(T\). Taking coordinate \(i\) in the preceding identity yields

\[ \frac1N=(1-\delta)\sum_{\substack{1\le t\le h\\t\in S_i}}\delta^{t-1}+\delta^h r_i^{(h)}. \]

The remainder lies between zero and \(\delta^h\), which tends to zero because \(\delta<1\). Letting \(h\) tend to infinity proves the lemma. \(\square\)

2. Construction for the atomless population

The input’s discount bound implies the lemma’s hypothesis, because

\[ \frac{2N-3}{2N-2}-\frac{N-1}{N} =\frac{N-2}{2N(N-1)}\ge 0. \]

Apply the lemma separately to every supported type \(\theta\). Obtain a partition \(T=S_{\theta,1}\sqcup\cdots\sqcup S_{\theta,N}\) satisfying \(u_\theta(S_{\theta,i})=1/N\) for every index \(i\).

Partition the interval representing type \(\theta\) into the half-open intervals

\[ I_{\theta,i}=\left[\frac{(i-1)q_\theta}{N},\frac{i q_\theta}{N}\right), \qquad i\in\{1,\ldots,N\}. \]

For every \(x\in I_{\theta,i}\), assign the agent \((\theta,x)\) the schedule \(S_{\theta,i}\). These intervals partition \([0,q_\theta)\), so the assignment is defined for every agent. Every agent of type \(\theta\) receives utility exactly \(1/N\).

Fix any date \(t\). For each type \(\theta\), exactly one of its schedules contains \(t\); denote its index by \(i_\theta(t)\). The set receiving that date is therefore

\[ \{a:t\in S_a\} =\bigsqcup_\theta\bigl(\{\theta\}\times I_{\theta,i_\theta(t)}\bigr). \]

This is a finite union of measurable intervals in the disjoint population components. Its measure is

\[ \mu(\{a:t\in S_a\}) =\sum_\theta\frac{q_\theta}{N} =\frac{N}{N}=1. \]

Thus all individual utility requirements, measurability requirements, and date-capacity equalities hold. The assignment is feasible.

3. Decision complexity

On the promised input domain, the algorithm simply returns YES. Its decision running time is constant; reading the complete input takes \(O(L)\) time.

If validity of the numerical promises must also be checked, this can be done in \(O((\tau+1)L^2)\subseteq O(L^3)\) bit operations using schoolbook arithmetic:

  • Check \(N\ge 2\) and positivity of each mass.
  • Sum the rational masses and compare their sum with \(N\).
  • Check each discount bound by cross multiplication with positive denominators.

For the mass sum, unreduced rational addition produces denominators whose bit lengths are bounded by the sum of the input denominator lengths. The intermediate numerators also have \(O(L)\) bits. Thus there are \(O(\tau)\) arithmetic operations on \(O(L)\)-bit integers, giving the stated bound.

The decision running time has no dependence on the numerical magnitude of \(N\) beyond its encoding in \(L\). The infinite schedule construction proves existence; a finite representation of all schedules is unnecessary for deciding feasibility.
