The continuous mirror question, as graded

Given item classes \(J\) with rational capacities \(q_j\) summing to \(1\), and rational masses \(\mu_r\) of types \(r=(\succ_r,b_r)\), where \(\succ_r\) is a complete ranking and \(b_r\) is the benchmark item with \(\sum_{r:b_r=j}\mu_r=q_j\), run fluid probabilistic serial and compute its marginal allocation \(p_{rj}\). Decide whether the expected ordinal welfare \(\sum_r\mu_r\sum_{j:\,j\succcurlyeq_r b_r}p_{rj}\) is at least a given rational threshold \(\alpha\).

Packaged proof task (what the prover saw — nothing else)

Let \(J\) contain \(m\geq1\) item classes with positive rational capacities \(q_j\) satisfying \(\sum_jq_j=1\). A society is given by its support: the list of \(\tau\) types with positive binary rational masses \(\mu_r\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state any running times in \(m,\tau,L\).
Each type is \(r=(\succ_r,b_r)\), where \(\succ_r\) is a strict complete ranking of \(J\) and \(b_r\in J\). Require \(\sum_{r:b_r=j}\mu_r=q_j\), so \(\sum_r\mu_r=1\); the benchmark assigns every member of type \(r\) item class \(b_r\).
Fluid probabilistic serial runs over \(t\in[0,1]\): every individual consumes its highest-ranked class with remaining capacity at unit speed, so type \(r\) consumes aggregate mass at rate \(\mu_r\). Remove all simultaneously exhausted classes together. Let \(p_{rj}\) be the total time type \(r\) consumes class \(j\), its marginal allocation per individual.
Define ordinal welfare by \(W=\sum_r\mu_r\sum_{j:\,j\succcurlyeq_r b_r}p_{rj}\), where \(\succcurlyeq_r\) includes equality.

Does fluid probabilistic serial guarantee \(W\geq\tfrac12\) for every such society and feasible benchmark, or does a counterexample exist?

For finite unit-demand agents and equally many distinct items, PS guarantees expected ordinal welfare at least \(\tfrac12\) against every perfect benchmark matching ([Bhalgat–Chakrabarty–Khanna](https://www.cis.upenn.edu/~sanjeev/papers/approx11_matching.pdf)). Generalized simultaneous eating with good quotas has been studied for ordinal efficiency ([Sano–Zhan](https://link.springer.com/article/10.1007/s10878-023-01063-0)); no result settling the stated mass benchmark guarantee was located.

Modeling choices made when packaging the task

  • Interpreted complete rankings as strict complete orders, consistent with the discrete mechanism's unique best available item.
  • Required positive capacities and a nonempty item set; zero-capacity classes can be omitted.
  • Specified unit consumption speed per individual, aggregate speed equal to type mass, and marginal allocation as consumption time per individual.
  • Specified simultaneous removal of exhausted classes and defined weak comparison to include the benchmark class itself.

Result

Fluid probabilistic serial always guarantees \(W\geq\tfrac12\). In fact, the following stronger bound is sharp for every prescribed capacity vector:

\(W\geq \dfrac{1+\sum_{j\in J}q_j^2}{2}.\)

Thus, for fixed \(m\), the sharp universal guarantee is \(\dfrac{m+1}{2m}\).

The proof extends the exhaustion-time argument in Section 2.3 of [Bhalgat–Chakrabarty–Khanna](https://www.cis.upenn.edu/~sanjeev/papers/approx11_matching.pdf), replacing item counts by capacities. The argument below is self-contained.

Proof of the capacity-dependent bound

Let \(T_j\) denote the time at which class \(j\) is exhausted.

First, total consumption proceeds at aggregate rate \(\sum_r\mu_r=1\) whenever any capacity remains: every type has a complete ranking and therefore consumes some available class. Each phase exhausts at least one class, so there are at most \(m\) phases. Since initial total capacity is \(1\), all capacity is exhausted at time \(1\). Consequently, total consumption by time \(t\in[0,1]\) equals \(t\).

Step 1: Each type consumes acceptable classes until its benchmark class is exhausted.

Fix a type \(r\). At every time \(t<T_{b_r}\), class \(b_r\) remains available. Because type \(r\) consumes its highest-ranked available class, its choice is at least as good as \(b_r\). Isolated switching instants do not affect consumption durations. Therefore,

\(\displaystyle \sum_{j:\,j\succcurlyeq_r b_r}p_{rj}\geq T_{b_r}.\)

Multiplying by \(\mu_r\), summing over the listed types, and using benchmark feasibility gives

\(\displaystyle W\geq\sum_r\mu_rT_{b_r} =\sum_{j\in J}T_j\sum_{r:\,b_r=j}\mu_r =\sum_{j\in J}q_jT_j.\)

This is a lower bound; acceptable consumption can continue after the benchmark class is exhausted.

Step 2: Bound the capacity-weighted exhaustion times.

Order the classes as \(j_1,\ldots,j_m\) so that

\(T_{j_1}\leq T_{j_2}\leq\cdots\leq T_{j_m},\)

breaking ties arbitrarily. Define \(C_k=\sum_{\ell=1}^kq_{j_\ell}\).

At time \(T_{j_k}\), all of the first \(k\) classes have been completely consumed. Their total capacity is \(C_k\), whereas total consumption across all classes is \(T_{j_k}\). Hence

\(T_{j_k}\geq C_k.\)

This remains valid when several classes exhaust simultaneously. Thus,

\(\displaystyle W\geq\sum_{k=1}^mq_{j_k}T_{j_k} \geq\sum_{k=1}^mq_{j_k}C_k.\)

Expanding the last sum yields

\(\displaystyle \sum_{k=1}^mq_{j_k}C_k =\sum_{k=1}^mq_{j_k}^2+\sum_{\ell<k}q_{j_\ell}q_{j_k} =\frac{\left(\sum_jq_j\right)^2+\sum_jq_j^2}{2} =\frac{1+\sum_jq_j^2}{2}.\)

This proves the claimed bound, and in particular \(W>\tfrac12\) for every individual instance.

Sharpness

Fix any positive rational capacities \(q_1,\ldots,q_m\). Construct exactly \(\tau=m\) types. All share the strict ranking \(1\succ2\succ\cdots\succ m\); type \(k\) has mass \(\mu_k=q_k\) and benchmark \(b_k=k\). Benchmark feasibility holds because the mass assigned class \(k\) is precisely \(q_k\).

All types consume class \(1\) together, then class \(2\), and so forth. Since aggregate speed is \(1\), class \(j\) is consumed for duration \(q_j\), giving \(p_{kj}=q_j\) for every type \(k\).

Type \(k\)'s acceptable classes are exactly \(1,\ldots,k\). Therefore,

\(\displaystyle W=\sum_{k=1}^mq_k\sum_{j=1}^kq_j =\frac{1+\sum_jq_j^2}{2}.\)

The capacity-dependent bound is therefore attained.

Finally, \(\sum_j(q_j-\tfrac1m)^2\geq0\) implies \(\sum_jq_j^2\geq\tfrac1m\). Equal capacities attain equality, so the sharp guarantee for fixed \(m\) is \(\dfrac{m+1}{2m}\). These examples approach \(\tfrac12\) as \(m\) grows, making \(\tfrac12\) the best constant independent of \(m\).

Encoding and computation

The proof uses the actual support of size \(\tau\); no population replication is needed. If desired, the sharp capacity bound can be computed exactly in \(O(L+mL^2)\) bit operations using schoolbook arithmetic: use the product of the capacity denominators as a common denominator, whose bit length is \(O(L)\), and compute the sum of squared numerators. Reading the entire listed input is covered by \(O(L)\).
