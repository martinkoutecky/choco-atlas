The continuous mirror question, as graded

Given rational masses \(\mu_t\) over finitely many valuation types \(t\), rational per-capita supplies \(q_g\) for good types \(g\), and additive valuations \(v_t:2^G\to\mathbb{R}_+\), choose \(\lambda_{t,S}\ge 0\) for \(S\subseteq G\) satisfying \(\sum_S\lambda_{t,S}=\mu_t\) and \(\sum_{t,S:g\in S}\lambda_{t,S}=q_g\), and compute an allocation maximizing \(W_p(\lambda)=\left(\sum_{t,S}\lambda_{t,S}v_t(S)^p\right)^{1/p}\) for fixed \(p\in(0,1)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\geq1\) valuation types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Let \(G\) contain \(m\geq1\) good types, with binary-rational per-capita supplies \(q_g\in[0,1]\) and explicitly given additive valuations with nonnegative binary-rational singleton values. Fix a rational \(p\in(0,1)\); zero valuations and empty bundles are allowed.
An input population scale \(n\geq1\) is a binary-encoded integer; define the total goods scale \(M=n\sum_{g\in G}q_g\), required to be an integer with \(M\geq n\). Neither scale is a support size.
An allocation assigns mass \(\lambda_{t,S}\geq0\) to each \(t\) and \(S\subseteq G\), with \(\sum_{S\subseteq G}\lambda_{t,S}=\mu_t\) and \(\sum_{t,S:g\in S}\lambda_{t,S}=q_g\). Each recipient receives at most one copy of each good type, and all supplies must be allocated.
Set \(W_p(\lambda)=\left(\sum_{t,S}\lambda_{t,S}v_t(S)^p\right)^{1/p}\), and let \(\mathrm{OPT}_p\) be its maximum over feasible allocations. Allocations are represented by lists of their nonzero rational masses; \(L\) is the total binary input length.

For each fixed rational \(p\in(0,1)\), can an allocation satisfying \(W_p(\lambda)\geq\mathrm{OPT}_p/(M-n+1)\) be computed in time polynomial in \(m,\tau,L\), or is obtaining this guarantee NP-hard?

For discrete allocations of \(M\geq n\) indivisible goods among \(n\) agents with additive valuations, obtaining this same guarantee for every instance is NP-hard for every fixed \(p\in(0,1)\). [Barman et al.](https://arxiv.org/html/2005.07370v2)
No result settling this precise continuous formulation was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the society's masses to one so that the stated objective is a population mean.
  • Specified explicitly encoded nonnegative rational singleton values and a fixed rational exponent to give a finite binary input model.
  • Restricted per-capita supplies to the interval from zero to one, as required by bundles containing at most one copy of each good type.
  • Added a binary-encoded population scale n and defined the total goods scale M as n times total per-capita supply; required M to be an integer at least n so that the inherited approximation factor is defined and at least one.
  • Allowed empty bundles, zero singleton values, and identically zero valuation types, consistent with the discrete hardness construction.
  • Specified a sparse rational representation of allocations to avoid requiring an exponentially long table.

Result

For every fixed rational \(p\in(0,1)\), obtaining the stated guarantee is NP-hard, even with support size \(\tau=2\) and dyadic masses and supplies.

The permitted boundary \(M=n\) makes the required factor equal to \(1\). The substantive point is that computing an exact optimum remains NP-hard despite arbitrary splitting of type masses.

1. Reduction from PARTITION

PARTITION asks whether positive integers \(a_1,\ldots,a_r\), encoded in binary, admit a subset whose sum is half their total. This is the NP-complete problem used in the cited paper’s discrete hardness proof; below we verify a reduction directly for the continuous formulation. [Barman et al., Appendix A.3](https://arxiv.org/html/2005.07370v2)

Let \(m\) be the smallest power of two satisfying \(m\geq\max\{r,4\}\). Pad the sequence with \(a_{r+1}=\cdots=a_m=0\), and write \(z=\sum_{i=1}^{m}a_i>0\).

Construct the following society:

  • There are \(m\) good types \(G=\{g_1,\ldots,g_m\}\), each with supply \(q_{g_i}=1/m\).
  • Type \(+\) has mass \(\mu_+=2/m\) and singleton values \(v_+(\{g_i\})=a_i\).
  • Type \(0\) has mass \(\mu_0=1-2/m\) and zero valuation.
  • Set the population scale to \(n=m\).

Both masses are positive, and the two valuation types are distinct. Thus the support size is exactly \(\tau=2\). All masses and supplies are dyadic rationals, and the valuations are nonnegative integers.

Moreover, \(\sum_{g\in G}q_g=1\), so \(M=n=m\) and \(M-n+1=1\). Consequently, an algorithm providing the requested guarantee must return an optimal allocation on these instances.

The construction has polynomial encoding length: \(m<2\max\{r,4\}\), and padding introduces only zero values.

2. A universal welfare bound

For any feasible allocation \(\lambda\), define the mass of type \(+\) receiving good \(g_i\) by \(x_i=\sum_{S:g_i\in S}\lambda_{+,S}\). The supply constraints imply \(0\leq x_i\leq1/m\).

Normalize the bundle masses within type \(+\) by setting \(\pi_S=(m/2)\lambda_{+,S}\). These numbers are nonnegative and sum to \(1\). Their mean bundle value is

\(\displaystyle A=\sum_{S\subseteq G}\pi_Sv_+(S)=\frac m2\sum_{i=1}^{m}a_ix_i\leq\frac z2.\)

The equality uses additivity; the inequality uses \(a_i\geq0\) and \(x_i\leq1/m\).

Since type \(0\) contributes no welfare, Jensen’s inequality gives

\(\displaystyle W_p(\lambda)^p=\frac2m\sum_{S\subseteq G}\pi_Sv_+(S)^p\leq\frac2m A^p\leq\frac2m\left(\frac z2\right)^p.\)

Here \(u\mapsto u^p\) is strictly concave on the nonnegative reals and strictly increasing. Define

\(\displaystyle U=\left(\frac2m\right)^{1/p}\frac z2.\)

Thus every feasible allocation satisfies \(W_p(\lambda)\leq U\).

Crucially, equality \(W_p(\lambda)=U\) forces equality in both preceding inequalities. Therefore \(A=z/2\), and the equality condition for strict Jensen implies

\(\displaystyle \lambda_{+,S}>0\quad\Longrightarrow\quad v_+(S)=z/2.\)

Hence every bundle occurring with positive mass for the valued type must itself encode a partition.

3. The bound is attained exactly on YES instances

Suppose the PARTITION instance is a YES instance. Choose \(T\subseteq G\) with \(v_+(T)=z/2\). Additivity gives \(v_+(G\setminus T)=z/2\).

Set \(\lambda_{+,T}=1/m\), \(\lambda_{+,G\setminus T}=1/m\), and \(\lambda_{0,\emptyset}=1-2/m\), with all other masses zero.

The type masses are correct. Each good belongs to exactly one of the two complementary bundles, so its allocated mass is exactly \(1/m=q_g\). This is therefore a feasible rational allocation, and its welfare equals \(U\). The universal bound proves \(\mathrm{OPT}_p=U\).

Conversely, suppose a feasible allocation attains \(U\). Since \(\mu_+>0\), some bundle \(S\) has \(\lambda_{+,S}>0\). Section 2 gives \(v_+(S)=z/2\). Removing the padded zero-valued goods yields a solution to the original PARTITION instance.

For completeness, an optimum exists: the feasible set is a nonempty, closed, bounded polytope in finitely many coordinates, and the objective is continuous. Nonemptiness follows, for example, by assigning mass \(1/m\) of type \(+\) the bundle \(G\), mass \(1/m\) of that type the empty bundle, and all of type \(0\) the empty bundle.

Therefore \(\mathrm{OPT}_p=U\) precisely on YES instances; on NO instances, \(\mathrm{OPT}_p<U\).

4. Extracting a witness without irrational comparisons

Assume an algorithm computes the requested allocation in time polynomial in \(m,\tau,L\). Run it on the constructed society.

Because \(M-n+1=1\), its output must be optimal. Select any listed bundle \(S\) with positive mass for type \(+\), which exists because that type has positive total mass. Accept the PARTITION instance exactly when

\(\displaystyle 2\sum_{\substack{i\leq r\\g_i\in S}}a_i=z.\)

On a YES instance, optimality forces welfare \(U\), so Section 2 ensures that the selected bundle passes this check. On a NO instance, no subset can pass it.

This procedure uses only the explicit output list and integer arithmetic. It never evaluates or compares irrational welfare values. A polynomial-time allocation algorithm has polynomial output length, so witness extraction also takes polynomial time.

5. Conclusion

Such an allocation algorithm would decide PARTITION in polynomial time. Thus obtaining the stated all-instance guarantee is NP-hard for every fixed rational \(p\in(0,1)\), even when \(\tau=2\).

Continuous mass splitting does not defeat this reduction: attaining the concavity bound requires actual equal-value bundles in the output support.
