Theorem 3 — class: other

The continuous mirror question, as graded

Given item classes \(G\), roles \(U\), binary-rational supplies \(q_g\), and a finite support \(T\) of team types with rational masses \(\mu_t\) and additive values \(v_t(g)\), where each class \(g\) has an eligibility set in \(U\), promise that \(q\) can be realized by a distribution over feasible integral bundles. A bundle \(b\in\mathbb{Z}_{\ge 0}^{G}\) is feasible if its item copies can be matched injectively to roles. Does there exist an algorithm polynomial in \(|G|, |U|, |T|\), and input bit length \(L\) that outputs a polynomial-size sparse rational list \(x_{t,b}>0\), with \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_g=q_g\), such that every pair of bundles \(b,b'\) used with positive mass satisfies EF1 for the recipient of \(b\): either \(b'\) is empty or some \(g\) with \(b'_g>0\) has \(\sum_h v_t(h)b_h\ge\sum_h v_t(h)(b'_h-\mathbf{1}_{h=g})\)?

Packaged proof task (what the prover saw — nothing else)

Given finite item classes \(G\), roles \(U\), and explicitly listed eligibility sets \(E_g\subseteq U\), put \(m=|G|\).
A society is given by its support: the list \(T\) of its \(\tau=|T|\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Supplies \(q_g\geq0\) and additive values \(v_t(g)\geq0\) are binary rationals; \(L\) is the total input bit length.
A bundle \(b\in\mathbb Z_{\geq0}^{G}\) is feasible if its copies can be matched injectively to roles, each copy of class \(g\) using a role in \(E_g\). Roles are available separately for each recipient; bundles need not fill every role.
Promise that \(q=\sum_b y_b b\) for some distribution \(y_b\geq0\), \(\sum_b y_b=1\), over feasible bundles; this distribution is not supplied.
An allocation is a finite rational list of positive entries \(x_{t,b}\) on feasible bundles satisfying \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_g=q_g\).
Require EF1 across every pair \((t,b),(s,b')\) with positive entries, including pairs of the same type: either \(b'=0\), or some \(g\) with \(b'_g>0\) satisfies \(\sum_h v_t(h)b_h\geq\sum_h v_t(h)b'_h-v_t(g)\).

Does every promised instance admit such an EF1 allocation with encoding length polynomial in \(m,|U|,\tau,L\)?
Can such a list always be computed in time polynomial in \(m,|U|,\tau,L\), or is the corresponding search problem NP-hard?

For finitely many agents with nonnegative additive values and a common transversal matroid constraint, a complete feasible EF1 allocation exists whenever a complete feasible allocation exists ([source](https://arxiv.org/html/2608.31121v1)).
No result settling this exact continuous formulation was located in the literature search.

Modeling choices made when packaging the task

  • Normalized society masses to sum to one and interpreted supplies as aggregate quantities per unit society mass.
  • Restricted additive values to nonnegative binary rationals, following the discrete goods model and making the input encoding explicit; supplies are nonnegative binary rationals.
  • Interpreted the feasibility promise as membership in the convex hull of feasible integral bundles, without a supplied decomposition.
  • Required matching only within each recipient's bundle, with no requirement to fill all roles, following transversal independence rather than the informal full-team example.
  • Made pairwise EF1 apply to all positive allocation entries, including different bundles assigned to the same type.
  • Interpreted polynomial-size sparse output as polynomial total binary encoding length.

Result

Every promised instance admits an EF1 allocation with at most \(m+\tau\) positive entries. Such an allocation can be computed in time polynomial in \(m,|U|,\tau,L\), with polynomial encoding length.

The proof below works directly with rational population masses. The finite-agent existence result cited in the question is [Theorem 3 of the supplied source](https://arxiv.org/html/2608.31121v1).

Write \(r=|U|\), and define \(V_t(b)=\sum_g v_t(g)b_g\). Also define

\(M_t(b)=\max\{v_t(g):b_g>0\}\)

when \(b\ne 0\), and \(M_t(0)=0\). Because values are nonnegative, the required EF1 condition is equivalent to

\(V_t(b)\ge V_t(c)-M_t(c)\)

for every pair of positive entries \((t,b),(s,c)\), including pairs with \(t=s\).

The construction uses two lemmas: one adds the goods assigned to a single role; the other preserves EF1 while removing envy cycles and reducing support.

1. Splitting the supplies among roles

We first compute nonnegative rational numbers \(z_{g,u}\), defined only when \(u\in E_g\), satisfying

\(\sum_{u\in E_g}z_{g,u}=q_g\quad\text{for every }g,\qquad \sum_g z_{g,u}\le 1\quad\text{for every }u.\)

The promise guarantees their existence. Indeed, every feasible bundle has a matching of its copies to roles. Choose one such matching for each bundle in the promised distribution, and average the resulting class-to-role incidences. The class totals are \(q_g\), and each role is used at most once per bundle.

These numbers can be computed by a rational maximum-flow problem:

  • The source-to-class arc has capacity \(q_g\).
  • There is a class-to-role arc whenever \(u\in E_g\).
  • Each role-to-sink arc has capacity \(1\).

Class-to-role capacities can be set to \(r\), since the promise implies \(\sum_g q_g\le r\). A flow saturating all source-to-class arcs supplies the desired \(z_{g,u}\).

Fix an ordering \(u_1,\ldots,u_r\). Let

\(p^{(k)}_g=\sum_{j=1}^{k}z_{g,u_j},\qquad p^{(0)}_g=0.\)

At stage \(k\), we will allocate exactly \(p^{(k)}\), using bundles matchable to the first \(k\) roles.

2. An EF1-preserving linear program

Lemma 1. Suppose a finite rational EF1 allocation has type masses \(\mu_t\), class totals \(p_g\), and global bundle support \(B\). There is another allocation using only bundles in \(B\) that:

  • has the same type masses and class totals;
  • is EF1;
  • has no directed cycle of strict envy among its positive entries;
  • has at most \(m+\tau\) positive entries.

If \(B\) has polynomial size and its bundles have polynomial encoding length, this allocation can be computed by rational linear programming in polynomial time.

Proof. Each type has positive total mass, so define its minimum supported utility

\(a_t=\min\{V_t(b):x_{t,b}>0\}.\)

For every type \(t\) and every global bundle \(c\in B\), the original EF1 allocation implies

\(a_t\ge V_t(c)-M_t(c).\)

To justify this, choose a positive entry of type \(t\) attaining \(a_t\), and a positive entry carrying \(c\), and apply EF1 to that pair.

Allow a pair \((t,b)\) precisely when \(b\in B\) and \(V_t(b)\ge a_t\). Consider the linear program

\(\displaystyle \max \sum_{(t,b)\text{ allowed}} w_{t,b}V_t(b)\)

subject to

\(\sum_{b:(t,b)\text{ allowed}}w_{t,b}=\mu_t\quad\text{for every }t,\)

\(\sum_{(t,b)\text{ allowed}}w_{t,b}b_g=p_g\quad\text{for every }g,\)

and \(w_{t,b}\ge 0\).

The original allocation is feasible. The feasible polytope is compact, because every variable is bounded by its type’s mass. Choose an optimal vertex.

Every feasible solution of this LP is EF1. For any of its positive entries \((t,b),(s,c)\),

\(V_t(b)\ge a_t\ge V_t(c)-M_t(c).\)

We next prove that an optimal solution has no strict-envy cycle. Suppose such a cycle consists of positive entries

\((t_1,b_1),\ldots,(t_\ell,b_\ell),\)

with cyclic indices and

\(V_{t_i}(b_{i+1})>V_{t_i}(b_i)\quad\text{for every }i.\)

For sufficiently small rational \(\delta>0\), decrease each \(w_{t_i,b_i}\) by \(\delta\), and increase each \(w_{t_i,b_{i+1}}\) by \(\delta\). All increased pairs are allowed, since

\(V_{t_i}(b_{i+1})>V_{t_i}(b_i)\ge a_{t_i}.\)

Taking \(\delta\) no larger than the smallest mass on the cycle ensures nonnegativity, even if some increased pairs coincide. Type masses are preserved. Class totals are preserved because

\(\sum_{i=1}^{\ell}(b_{i+1}-b_i)=0.\)

The objective increases by

\(\displaystyle \delta\sum_{i=1}^{\ell}\bigl(V_{t_i}(b_{i+1})-V_{t_i}(b_i)\bigr)>0,\)

contradicting optimality.

Finally, the equality-constraint matrix has \(m+\tau\) rows. At a vertex, columns corresponding to positive variables must be linearly independent: otherwise a nonzero dependence permits sufficiently small perturbations in both directions, contradicting extremality. Therefore the vertex has at most \(m+\tau\) positive entries. This proves the lemma. \(\square\)

For later use, direct an envy edge from \((t,b)\) to \((s,c)\) when \(V_t(c)>V_t(b)\). A topological ordering of the acyclic graph has the following property:

A later entry does not envy an earlier entry.

All entries, including different entries of the same type, are vertices of this graph.

3. Adding one role

Lemma 2. Suppose an EF1 allocation has an acyclic strict-envy graph, and every supported bundle is matchable to a processed set of roles. Let \(u\) be an unprocessed role, and let \(z_g\ge 0\) satisfy

\(\sum_g z_g\le 1,\qquad z_g=0\text{ whenever }u\notin E_g.\)

One can extend the allocation by exactly these class supplies, preserving EF1 and matching feasibility. If the original allocation has \(K\) positive entries, the extension has at most \(K+m+1\) entries before merging duplicates.

Construction. Put the positive entries in a topological envy order. Regard an entry \((t,b)\) of mass \(x_{t,b}\) as a population block of that size.

Process the blocks in this order. Within each block, assign recipients one copy of their type’s most valuable class among those with remaining supply. Split the block whenever either its remaining mass or the chosen class’s supply is exhausted. Once all supplies are exhausted, give the remaining recipients no additional item.

Thus every resulting segment carries a bundle \(b+w\), where \(w\) is either \(0\) or a unit vector \(e_g\). Items remain indivisible; only population blocks are split.

All supplies are consumed. Otherwise supplies would remain throughout the procedure, so the procedure would assign one item to the entire population of mass \(1\), despite having strictly more than one unit of initial supply. This contradicts \(\sum_g z_g\le 1\).

Every segment ends at a block boundary, exhausts a class supply, or belongs to the final suffix receiving no item. Consequently there are at most \(K+m+1\) segments.

Feasibility. An old bundle is matchable to the processed roles. Any added item is eligible for the new role \(u\), which is distinct from those roles. Hence the extended bundle is matchable to the enlarged processed set.

EF1 proof. Keep the chronological order of the resulting segments. Write two segments as \((t,b+w)\) and \((s,c+w')\).

Suppose first that the segment of type \(t\) is earlier. Greedy selection gives

\(V_t(w)\ge V_t(w').\)

Indeed, if the later segment receives class \(h\), that class was available when the earlier segment made its choice. If the earlier segment receives nothing, all subsequent segments also receive nothing.

The original allocation was EF1, so

\(V_t(b)\ge V_t(c)-M_t(c).\)

Adding these inequalities gives

\(V_t(b+w)\ge V_t(c+w')-M_t(c).\)

Since \(M_t(c+w')\ge M_t(c)\), the required EF1 inequality follows.

Now suppose that the segment of type \(t\) is later. If the segments came from different original blocks, the topological ordering gives \(V_t(b)\ge V_t(c)\). If they came from the same block, their old bundles are identical, so the same inequality holds.

If the earlier segment received an item, removing that item leaves \(c\), and

\(V_t(b+w)\ge V_t(b)\ge V_t(c).\)

If it received no item, its entire bundle is \(c\), and this inequality already gives no envy.

These arguments apply to every ordered pair of segments, including pairs of the same type. Merging identical type-bundle entries preserves the property. \(\square\)

4. The algorithm and its correctness

Start with \(x_{t,0}=\mu_t\) for every type. This allocation is EF1, has no strict-envy edges, and has class totals \(p^{(0)}=0\).

For \(k=1,\ldots,r\):

  • Topologically order the current positive entries.
  • Apply Lemma 2 to role \(u_k\), using supplies \(z_g=z_{g,u_k}\).
  • Apply Lemma 1 to the resulting allocation.

By induction, after stage \(k\):

  • type masses are exactly \(\mu_t\);
  • class totals are exactly \(p^{(k)}\);
  • every supported bundle is matchable to the first \(k\) roles;
  • the allocation is EF1 and has an acyclic strict-envy graph;
  • there are at most \(m+\tau\) positive entries.

The linear program only reassigns bundles already present, so their matching feasibility is preserved. It need not preserve the particular role matchings used to construct them.

After the last stage, \(p^{(r)}=q\). Hence the output satisfies every requirement in the question.

If \(r=0\), the promise forces \(q=0\), and the initial allocation is already the desired output.

5. Encoding length and polynomial running time

It remains to control rational arithmetic independently of population denominators.

Put \(d=m+\tau\) and \(R=\max\{1,r\}\). Let \(D\) be the product of the denominators of the input masses and supplies. Then \(\log_2 D\le L\).

Scale the flow network by \(D\). Its capacities are integers. An integral maximum flow therefore yields each \(z_{g,u}\), and each processed supply \(p^{(k)}_g\), with denominator dividing \(D\). Maximum flow is computable in polynomial time with binary capacities.

At every application of Lemma 1, the equality matrix has columns of the form

\((e_t,b)\in\mathbb Z^{\tau+m},\)

where \(e_t\) denotes the unit vector for type \(t\). Every coordinate of \(b\) is at most \(r\), because its bundle is matchable to at most \(r\) roles.

Consider a vertex with \(k\le d\) positive variables. Select \(k\) independent equality rows on those variables, giving an invertible integer matrix \(C\). Its entries have absolute value at most \(R\). The selected right-hand side has the form \(h/D\), where \(h\) is integral and its entries have absolute value at most \(DR\).

Hadamard’s inequality gives

\(|\det C|\le (\sqrt{k}R)^k.\)

If \(C_j\) replaces one column of \(C\) by \(h\), the same inequality gives

\(|\det C_j|\le D(\sqrt{k}R)^k.\)

By Cramer’s rule, every positive mass has the form

\(\displaystyle \frac{\det C_j}{D\det C}.\)

Thus its numerator and denominator require

\(B=O\bigl(L+d\log(dR+1)\bigr)\)

bits. This bound holds at every stage: the right-hand sides are always the original type masses and the processed supplies, rather than previously computed allocation masses.

The greedy step also uses polynomial-size rationals. Its input masses have at most \(B\) bits each, and its supplies have denominator dividing \(D\). A common denominator for them has bit length at most \(L+dB\). Every split is obtained by subtraction and taking a minimum, so all resulting masses retain polynomial bit length.

After a greedy step there are at most \(d+m+1\) candidate bundles. The next LP therefore has at most \(\tau(d+m+1)\) variables. Its coefficients, objective values, and allowed-pair comparisons have polynomial encoding length. Rational linear programming can compute an optimal vertex in polynomial time.

There are \(r\) stages. Hence the total running time is polynomial in \(m,r,\tau,L\).

Finally, the output contains at most \(d\) entries. Each entry stores a type, an integer bundle, and a rational mass. Its total encoding length is bounded by

\(O\bigl(d[B+m\log(R+1)+\log(\tau+1)]\bigr),\)

which is polynomial in the requested parameters. This completes the proof of both existence and polynomial-time computability.
