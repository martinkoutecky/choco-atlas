The continuous mirror question, as graded

Given a finite set \(T\) of complete valuation types with rational monotone submodular valuations \(v_t\) over \(m\) good types, rational population masses \(\mu_t\) summing to \(1\), and rational per-capita supplies \(q_g\), does there exist a rational assignment \(x_{t,S}\ge 0\) of type mass to integral bundles \(S\subseteq [m]\), with \(\sum_S x_{t,S}=\mu_t\) and \(\sum_{t,S:g\in S}x_{t,S}=q_g\), such that for every \(t,u\in T\) and bundles \(A,B\) with \(x_{t,A}>0\) and \(x_{u,B}>0\), \(v_t(B\setminus\{g\})\le v_t(A)\) for every \(g\in B\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge 1\) valuation types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\ge 1\) good types, indexed by \([m]=\{1,\ldots,m\}\), with binary-rational per-capita supplies \(q_g\in[0,1]\). Each person receives an integral bundle \(S\subseteq[m]\), containing at most one good of each type.
Each valuation \(v_t:2^{[m]}\to\mathbb{Q}_{\ge 0}\) is given by its complete table, is weakly monotone and submodular, and satisfies \(v_t(\emptyset)=0\). Ties and empty bundles are allowed. Let \(L\) be the total binary input length, including all valuation tables.
A mass assignment consists of rational numbers \(x_{t,S}\ge 0\) satisfying \(\sum_{S\subseteq[m]}x_{t,S}=\mu_t\) for every \(t\), and \(\sum_{t\in T}\sum_{S\ni g}x_{t,S}=q_g\) for every \(g\).
It is EFX if, for every \(t,u\in T\), including \(t=u\), and every \(A,B\subseteq[m]\) with \(x_{t,A}>0\) and \(x_{u,B}>0\), one has \(v_t(B\setminus\{g\})\le v_t(A)\) for every \(g\in B\).

Is deciding whether such an EFX mass assignment exists solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

Discrete complete EFX allocations can fail to exist with submodular valuations for every \(n\ge 3\) and \(m\ge n+5\) (Akrami et al.). [Mackenzie and Suzuki](https://arxiv.org/abs/2605.06451) also establish a three-agent, eight-good counterexample with weighted-coverage valuations.
No result settling this exact supportwise mass-assignment decision problem was located.

Modeling choices made when packaging the task

  • Settled valuation representation as an explicit table of binary-rational values for every bundle; L includes these tables and all other input data.
  • Required nonnegative valuations normalized by v_t(emptyset)=0, and used weak monotonicity with ties allowed, consistent with the formal valuation definition and the counterexample extensions allowing zero-valued goods.
  • Restricted per-capita supplies to binary rationals in [0,1], as bundles contain at most one good of each type.
  • Allowed empty bundles and retained comparisons between different positive-mass bundles assigned to the same valuation type; neither nondegeneracy nor nonempty bundles are assumptions of the general EFX existence problem.

Result

The decision problem is \(\mathrm{NP}\)-complete. This holds even when all masses, supplies, and valuation-table entries are dyadic rationals, and every valuation has strictly positive marginal value for every good.

The reduction below uses only \(\mathit{O}(\log \tau)\) goods. Thus its complete valuation tables have polynomial size.

1. Source problem and goods

We reduce from the standard \(\mathrm{NP}\)-complete SUBSET SUM problem: given positive binary-encoded integers \(a_1,\ldots,a_n\) and an integer \(b\), decide whether some \(I\subseteq[n]\) satisfies \(\sum_{i\in I}a_i=b\). We may assume \(0\le b\le A:=\sum_i a_i\), since targets outside this range are immediately infeasible. This is the equality form of the knapsack problem in [Karp’s NP-completeness theorem](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Set \(k=1+\lceil\log_2(n+1)\rceil\). There are:

  • code goods \(C=\{c_1,\ldots,c_{2k}\}\);
  • a selection good \(c\);
  • a mandatory good \(d\).

Write \(P=C\cup\{c\}\), \(p=|P|=2k+1\), and \(m=p+1=2k+2\). Define the anchor bundle and a designated code good by

\(D=\{c_{k+1},\ldots,c_{2k}\}\), and \(e=c_{2k}\).

Choose distinct binary strings \((\beta_{i1},\ldots,\beta_{i,k-1})\), one for each \(i\in[n]\). This is possible because \(2^{k-1}\ge n\). Define

\(B_i=\{c\}\cup\{c_{2j-1+\beta_{ij}}:j\in[k-1]\}\).

Consequently, the \(B_i\) are distinct bundles of cardinality \(k\), each containing \(c\), whereas \(D\) has cardinality \(k\) and excludes \(c\).

We first define valuations on the active goods \(P\), then extend them to include \(d\).

2. Valuations and their properties

There are \(n+2\) types: an anchor type \(\alpha\), item types \(1,\ldots,n\), and a slack type \(\sigma\).

Let \(F(s)=(2p+1)s-s^2\), for \(0\le s\le p\). For every type \(t\), define an active-good valuation

\(w_t(U)=F(|U|)+\rho_t(U)\), for \(U\subseteq P\).

The perturbations are as follows.

For the anchor type, set \(\rho_\alpha(U)=0\) when \(|U|\ne k\), and otherwise set

\(\rho_\alpha(U)=2^{-p}\left(\mathbf 1_{\{c\in U\}}+\sum_{j:c_j\in U}2^j\right)\).

Binary uniqueness implies that the anchor’s values are distinct on all bundles of cardinality \(k\). Moreover, \(D\) uniquely maximizes its value among those bundles: \(D\) contains the goods with the \(k\) largest binary weights.

For item type \(i\), set

\(\rho_i(B_i)=1\), \(\rho_i(D)=1/2\), and \(\rho_i(U)=0\) for every other \(U\).

For the slack type, set \(\rho_\sigma(U)=1\) if \(|U|=k\) and \(c\notin U\), and set \(\rho_\sigma(U)=0\) otherwise.

All perturbations lie in \([0,1]\), vanish at the empty bundle, and are integer multiples of \(2^{-p}\).

Monotonicity and submodularity

For \(0\le s<p\),

\(F(s+1)-F(s)=2(p-s)\ge2\).

Because perturbations lie in \([0,1]\), adding any active good increases \(w_t\) by at least \(1\). More generally, for any \(U,W\subseteq P\),

\(|W|>|U|\ \Longrightarrow\ w_t(W)>w_t(U)\).

Indeed, \(F(|W|)-F(|U|)\ge2\), while \(\rho_t(W)-\rho_t(U)\ge-1\).

For submodularity, let \(U\subseteq P\) and let \(g,h\) be distinct goods outside \(U\). Writing \(s=|U|\), we have

\(2F(s+1)-F(s)-F(s+2)=2\).

Therefore,

\(w_t(U\cup\{g\})+w_t(U\cup\{h\})-w_t(U)-w_t(U\cup\{g,h\})\ge2-2=0\).

Here the perturbation contribution is at least \(-2\), since each perturbation lies in \([0,1]\). These local inequalities imply submodularity: they say that a good’s marginal value cannot increase when another good is added; iterating gives diminishing marginal values for arbitrary nested sets, and summing those inequalities gives the usual submodular inequality.

Thus every \(w_t\) is normalized, nonnegative, strictly monotone, and submodular.

Now set \(\delta=2^{-(p+1)}\) and define the actual valuation table by

\(v_t(S)=w_t(S\cap P)+\delta\,\mathbf 1_{\{d\in S\}}\).

The added term is modular. Hence every \(v_t\) is normalized and submodular, with strictly positive marginal value for every good, including \(d\).

3. Masses and supplies

Let \(M\) be the smallest power of two satisfying \(M\ge32A\). Define

\(\mu_i=a_i/M\), \(V=A/M\), \(H=1/4-V\), and \(r=b/M\).

Assign masses \(\mu_\alpha=3/4\) and \(\mu_\sigma=H\). All masses are positive and sum to \(1\). Also,

\(0<V\le1/32\), \(H\ge7/32\), and \(0\le r\le V\).

Set the supplies to

\(q_d=1\), and \(q_c=r\),

and, for every \(g\in C\), set

\(q_g=(3/4+V)\mathbf 1_{\{g\in D\}}+H/2-r\mathbf 1_{\{g=e\}}\).

These supplies lie in \([0,1]\). For \(g\notin D\), \(q_g=H/2\le1/8\). For \(g\in D\),

\(3/4+H/2\le q_g\le3/4+V+H/2=7/8+V/2\le57/64\).

The active-good supplies sum to exactly \(k\):

\(\sum_{g\in P}q_g=r+(3/4+V)k+Hk-r=k\).

Every mass and supply is dyadic.

4. The mandatory good makes EFX enforce exact comparisons

Since \(q_d=1\) and total population mass is \(1\), every positively assigned bundle contains \(d\). Indeed, the total mass receiving a bundle without \(d\) is \(1-q_d=0\).

Consider supported bundles \(U\cup\{d\}\) and \(W\cup\{d\}\), with the first assigned to type \(t\). The EFX inequality obtained by deleting \(d\) from the second bundle is

\(w_t(W)\le w_t(U)+\delta\).

Both active values are integer multiples of \(2^{-p}=2\delta\). A strictly positive difference between them is therefore at least \(2\delta\). Consequently, the displayed inequality implies

\(w_t(W)\le w_t(U)\).

Conversely, if this exact comparison holds for every supported pair, then EFX holds. Deleting \(d\) gives \(w_t(W)\le w_t(U)+\delta\). Deleting an active good \(g\in W\) gives, by monotonicity,

\(w_t(W\setminus\{g\})+\delta\le w_t(W)+\delta\le w_t(U)+\delta\).

Thus, in the constructed instance, EFX is equivalent to exact supportwise envy-freeness for the active valuations \(w_t\).

5. Every EFX assignment yields a subset-sum solution

Assume an EFX mass assignment exists.

All active bundles have cardinality \(k\)

Suppose supported active bundles \(U,W\) satisfy \(|U|<|W|\). For the type \(t\) receiving \(U\), the cardinality property from Section 2 gives \(w_t(W)>w_t(U)\), contradicting Section 4.

Hence all supported active bundles have a common cardinality \(h\). Since total population mass is \(1\), their average cardinality equals \(h\). On the other hand, that average is \(\sum_{g\in P}q_g=k\). Therefore \(h=k\).

The anchor receives exactly \(D\)

Exact supportwise envy-freeness within the anchor type forces all its supported bundles to have equal anchor value. Its values on bundles of cardinality \(k\) are distinct, so its entire mass \(3/4\) receives one active bundle \(U\).

Every good outside \(D\) has supply less than \(3/4\): code goods outside \(D\) have supply at most \(1/8\), and \(c\) has supply at most \(1/32\). Therefore \(U\) cannot contain any good outside \(D\). Since \(|U|=|D|=k\), it follows that \(U=D\).

Each item type makes a whole-mass choice

Because \(D\) is supported, every bundle \(U\) assigned to item type \(i\) must satisfy

\(w_i(U)\ge w_i(D)=F(k)+1/2\).

Among bundles of cardinality \(k\), only \(D\) and \(B_i\) satisfy this inequality. Moreover, type \(i\) cannot support both: the person receiving \(D\) would strictly envy \(B_i\) under the exact comparison.

Thus each item type assigns its entire mass either to \(D\) or to \(B_i\). Let \(I\subseteq[n]\) be the types choosing \(B_i\).

The slack type receives no selection good

The supported bundle \(D\) has slack value \(F(k)+1\). Therefore every slack bundle must also have perturbation \(1\), which requires that it exclude \(c\).

The anchor also excludes \(c\). Consequently, precisely the selected item types receive \(c\), and supply balance gives

\(b/M=q_c=\sum_{i\in I}\mu_i=\sum_{i\in I}a_i/M\).

Multiplying by \(M\) yields \(\sum_{i\in I}a_i=b\).

6. Every subset-sum solution yields an EFX assignment

Now suppose \(I\subseteq[n]\) satisfies \(\sum_{i\in I}a_i=b\), equivalently \(\sum_{i\in I}\mu_i=r\).

Give the anchor its entire mass on \(D\). Give item type \(i\) its entire mass on \(B_i\) if \(i\in I\), and on \(D\) otherwise. Append \(d\) to every bundle.

It remains to allocate the slack mass \(H\). For each code good \(g\), its required slack marginal is

\(y_g=H/2-r\mathbf 1_{\{g=e\}}+\sum_{i\in I}\mu_i\left(\mathbf 1_{\{g\in D\}}-\mathbf 1_{\{g\in B_i\}}\right)\).

Since \(D\) contains \(k\) code goods and each \(B_i\) contains \(k-1\) code goods,

\(\sum_{g\in C}y_g=Hk-r+\sum_{i\in I}\mu_i=Hk\).

Also,

\(H/2-V\le y_g\le H/2+V\).

To check the lower bound, if \(g\notin D\), the summation is at least \(-V\), and the correction involving \(e\) vanishes. If \(g\in D\), the summation is nonnegative, and the correction is at least \(-r\ge-V\). The upper bound follows because the summation is at most \(V\) and the correction is nonpositive.

Because \(V\le1/32<H/2\), these bounds imply \(0<y_g<H\).

Rational realization of the slack marginals

We use the following elementary fact: if a rational vector \(z\in[0,1]^C\) satisfies \(\sum_g z_g=k\), then \(z\) is a rational convex combination of incidence vectors of bundles containing exactly \(k\) code goods.

Here is a proof. Induct on the number of fractional coordinates. If there are none, the assertion is immediate. There cannot be exactly one fractional coordinate, because the coordinate sum is an integer.

Otherwise choose two fractional coordinates \(a,b\). Let

\(\lambda=\min(1-z_a,z_b)>0\), and \(\eta=\min(z_a,1-z_b)>0\).

Define

\(z^+=z+\lambda(\mathbf e_a-\mathbf e_b)\), and \(z^-=z-\eta(\mathbf e_a-\mathbf e_b)\),

where \(\mathbf e_a,\mathbf e_b\) are unit coordinate vectors. Both vectors remain in \([0,1]^C\), retain coordinate sum \(k\), and have fewer fractional coordinates. Furthermore,

\(z=\dfrac{\eta}{\lambda+\eta}z^++\dfrac{\lambda}{\lambda+\eta}z^-\).

All vectors and coefficients are rational, so induction proves the fact.

Apply it to \(z_g=y_g/H\). Allocate slack mass according to the resulting rational distribution over bundles containing exactly \(k\) code goods, appending \(d\). This realizes the required marginals and assigns no selection good to the slack type.

The formula for \(y_g\) exactly compensates for the item types’ deviations from \(D\), so every code supply is satisfied. The selection supply is \(r\), the mandatory supply is \(1\), and all type-mass constraints hold.

Verification of EFX

We verify the exact active comparisons from Section 4.

  • The anchor receives \(D\), its highest-valued bundle of cardinality \(k\).
  • A selected item type \(i\) receives \(B_i\), whose perturbation \(1\) is maximal.
  • An unselected item type \(i\) receives \(D\), with perturbation \(1/2\). Its bundle \(B_i\) is absent from the entire support: other selected bundles \(B_j\) are distinct, and all anchor and slack bundles exclude \(c\). Every supported bundle therefore has item-\(i\) perturbation at most \(1/2\).
  • Every slack bundle excludes \(c\) and has perturbation \(1\), which is maximal.

All supported active bundles have cardinality \(k\). Thus these perturbation comparisons establish every required active envy-free inequality. Section 4 then establishes EFX.

This proves both directions of the reduction.

7. Polynomial size of the complete-table construction

The number of types is \(\tau=n+2\), and

\(2^m=2^{\,2k+2}\le64(n+1)^2\).

Hence explicitly listing every entry of every valuation table requires only polynomially many entries.

The masses and supplies have encoding length \(\mathit{O}(\log A)\) each. Valuation entries have encoding length polynomial in \(p=\mathit{O}(\log n)\). All tables, masses, and supplies can therefore be constructed in time polynomial in the binary length of the SUBSET SUM instance.

The reduction proves \(\mathrm{NP}\)-hardness for the stated complete-table representation.

8. Membership in \(\mathrm{NP}\)

Suppose an EFX assignment exists, and fix its support. Restrict the feasibility system to that support. It has the form

\(Ex=b,\quad x\ge0\),

where \(E\) is a zero-one matrix with \(\tau+m\) rows: one row for each type mass and each good supply.

This feasible polytope is bounded, because each coordinate is at most its type’s mass. It therefore has an extreme point. An extreme point has at most \(\tau+m\) positive coordinates: otherwise the corresponding columns of \(E\) are linearly dependent, permitting a sufficiently small nonzero perturbation in both directions while preserving feasibility, contrary to extremality.

Its positive coordinates have polynomial encoding length. Indeed, they are uniquely determined by a nonsingular square zero-one submatrix. After clearing the input denominators, Cramer’s rule bounds their encoding lengths by \(\mathit{O}(L+(\tau+m)\log(\tau+m))\).

The extreme point uses a subset of the original support, so it remains EFX: removing supported bundles cannot introduce a violated comparison.

A certificate can consequently list at most \(\tau+m\) bundles with polynomial-length rational masses. A verifier checks all mass and supply equalities, then all EFX comparisons between listed bundles using the supplied tables, in polynomial time.

Combining membership with the reduction proves \(\mathrm{NP}\)-completeness. A polynomial-time algorithm in \(m,\tau,L\) would therefore imply \(\mathrm P=\mathrm{NP}\).
