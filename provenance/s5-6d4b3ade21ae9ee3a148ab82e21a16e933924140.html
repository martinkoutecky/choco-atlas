The continuous mirror question, as graded

Given finite type and item-class sets \(T\) and \(G\), rational masses \(\mu_t\) and per-capita supplies \(q_g\) summing to \(1\), rankings \(\succ_t\), parameters \(h_t\in[0,1)\), requirements \(r_t\in\{1,2\}\), and target \(\kappa\), does there exist \(X\ge0\) with \(\sum_gX_{tg}=\mu_t\) and \(\sum_tX_{tg}=q_g\) such that \(\sum_{t:\operatorname{rank}_t(\operatorname{rep}(p_t,\succ_t,h_t))\le r_t}\mu_t\ge\kappa\), where \(p_t(g)=X_{tg}/\mu_t\) for every \(\mu_t>0\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of the \(\tau\) types with positive masses \(\mu_t\), each encoded as a binary rational; \(\tau\) is the support size, not the number of possible types. Let \(G\) be a nonempty set of \(m\) item classes, with nonnegative binary-rational supplies \(q_g\), and require \(\sum_t\mu_t=\sum_gq_g=1\).
Each type has a strict total ranking \(\succ_t\) of \(G\), a binary-rational quantile parameter \(h_t\in[0,1)\), and a requirement \(r_t\in\{1,2\}\cap\{1,\ldots,m\}\); the target mass is a binary rational \(\kappa\in[0,1]\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For a lottery \(p\), its representative \(\operatorname{rep}(p,\succ_t,h_t)\) is the unique class \(g\) satisfying \(\sum_{g':g\succ_t g'}p(g')\le h_t<\sum_{g':g\succeq_t g'}p(g')\). Write \(\operatorname{rank}_t(g)\) for its position, starting at \(1\).
A feasible allocation is a real matrix \(X\ge0\) with \(\sum_gX_{tg}=\mu_t\) and \(\sum_tX_{tg}=q_g\). Every member of type \(t\) receives the same lottery \(p_t(g)=X_{tg}/\mu_t\); the entire mass of that type counts as satisfied precisely when \(\operatorname{rank}_t(\operatorname{rep}(p_t,\succ_t,h_t))\le r_t\).

Is deciding whether a feasible allocation satisfies \(\sum_{t:\operatorname{rank}_t(\operatorname{rep}(p_t,\succ_t,h_t))\le r_t}\mu_t\ge\kappa\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finitely many agents and equally many distinct unit-supply items, the corresponding decision problem with requirements \(r_i\in\{1,2\}\) is \(\mathrm{NP}\)-hard; maximizing the satisfied count when all \(r_i=1\) is polynomial-time solvable. [Source](https://arxiv.org/html/2502.13772v2).
No result settling this exact mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Specified strict total rankings and the exact representative boundary convention from the discrete definition.
  • Required binary-rational quantile parameters and target mass, and defined L as the total input bit length.
  • Specified positive support masses, nonnegative supplies, and separate normalization of total agent mass and total supply to 1.
  • Restricted the target mass to [0,1]; larger nonnegative targets are automatically infeasible.
  • Required a nonempty item-class set and rank requirements within the available ranks, so a single-class instance permits only requirement 1.
  • Made explicit that each type receives one common lottery and contributes its whole mass or zero to the satisfied mass, as prescribed by the graded formula.

Result

The problem is \(\mathrm{NP}\)-complete. It is already \(\mathrm{NP}\)-hard with \(m=2\), strictly positive supplies, identical rankings, and \(r_t=1\) for every type. The reduction uses only dyadic rationals and genuinely distinct types.

1. Satisfaction is a non-strict linear condition

Let \(A_t=\{g\in G:\operatorname{rank}_t(g)\le r_t\}\), and let \(b_t=\sum_{g\notin A_t}p_t(g)\).

The representative belongs to \(A_t\) exactly when \(b_t\le h_t\). Indeed, the quantile intervals of the classes outside \(A_t\), read from worst to best, partition \([0,b_t)\); those of the classes in \(A_t\) partition \([b_t,1)\). Classes of probability zero have empty intervals.

Consequently,

\(\displaystyle \operatorname{rank}_t(\operatorname{rep}(p_t,\succ_t,h_t))\le r_t \quad\Longleftrightarrow\quad \sum_{g\in A_t}X_{tg}\ge\mu_t(1-h_t).\)

In particular, if \(r_t=1\) and the top class is \(a\), satisfaction requires \(X_{ta}\ge\mu_t(1-h_t)\). Equality suffices.

2. A reduction from SUBSET SUM

We use the standard \(\mathrm{NP}\)-complete SUBSET SUM problem: given positive binary-encoded integers \(a_1,\ldots,a_n\) and an integer \(B\), decide whether some subset sums to \(B\). This is the problem called KNAPSACK in [Karp’s original completeness theorem](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Write \(A=\sum_{i=1}^n a_i\). We may restrict to \(0<B<A\): the other cases are immediately decidable and can be mapped to fixed yes or no instances satisfying this restriction.

Choose powers of two \(D,H\) such that

\(\displaystyle A+B<D\le 2(A+B),\qquad nA<H\le 2nA.\)

These are obtained by taking the smallest powers of two strictly exceeding \(A+B\) and \(nA\), respectively.

Construct two classes \(G=\{a,b\}\), with supplies and target

\(\displaystyle q_a=\frac{B}{D},\qquad q_b=1-\frac{B}{D},\qquad \kappa=\frac{B}{D}.\)

There are \(\tau=n+1\) types. For each \(i\in\{1,\ldots,n\}\), set

\(\displaystyle \mu_i=\frac{a_i}{D},\qquad h_i=\frac{i}{H},\qquad r_i=1,\qquad a\succ_i b.\)

Add a type \(f\) with

\(\displaystyle \mu_f=\frac{D-A}{D},\qquad h_f=0,\qquad r_f=1,\qquad a\succ_f b.\)

Validity and encoding

All masses and both supplies are strictly positive, and

\(\displaystyle \sum_{t\in T}\mu_t=\frac{A+D-A}{D}=1=q_a+q_b.\)

Since \(H>nA\ge n\), every \(h_i\) lies in \((0,1)\). The quantile parameters \(0,1/H,\ldots,n/H\) are distinct, so these are genuinely distinct types even though their rankings and requirements coincide.

All numerical inputs are dyadic rationals. The binary lengths of \(D\) and \(H\) are \(O(\log A+\log n)\), and the constructed total input length satisfies

\(\displaystyle L=O\bigl(n(\log A+\log n)\bigr).\)

Thus the construction takes polynomial time in the source input length and explicitly produces a support list of size \(\tau=n+1\).

3. Correctness of the reduction

A subset summing to the target gives a feasible allocation

Suppose \(S\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in S}a_i=B\).

Allocate every type in \(S\) entirely to \(a\), and every other type, including \(f\), entirely to \(b\). The column sums are

\(\displaystyle \sum_tX_{ta}=\frac{B}{D}=q_a,\qquad \sum_tX_{tb}=1-\frac{B}{D}=q_b.\)

Every type in \(S\) has representative \(a\), and their satisfied mass is exactly \(\kappa=B/D\). Hence the constructed instance is a yes instance.

A feasible allocation reaching the target gives a subset summing to it

First, type \(f\) cannot be satisfied. Because \(h_f=0\), satisfaction would require \(X_{fa}=\mu_f\). But

\(\displaystyle \mu_f=\frac{D-A}{D}>\frac{B}{D}=q_a,\)

using \(D>A+B\). This exceeds the entire supply of \(a\).

Now let \(S\subseteq\{1,\ldots,n\}\) be the satisfied types in an allocation reaching the target. Define the integer \(W=\sum_{i\in S}a_i\). The satisfied-mass requirement gives

\(\displaystyle \frac{W}{D}\ge\frac{B}{D},\qquad\text{so }W\ge B.\)

By the satisfaction inequality and the supply constraint,

\(\displaystyle \frac{B}{D} =\sum_tX_{ta} \ge\sum_{i\in S}X_{ia} \ge\frac1D\sum_{i\in S}a_i\left(1-\frac{i}{H}\right).\)

Multiplying by \(D\) yields

\(\displaystyle W\le B+\sum_{i\in S}\frac{ia_i}{H}.\)

The correction term satisfies

\(\displaystyle 0\le\sum_{i\in S}\frac{ia_i}{H} \le\frac{nA}{H}<1.\)

Therefore \(B\le W<B+1\). Since \(W\) and \(B\) are integers, \(W=B\). Thus \(S\) solves the SUBSET SUM instance.

Both implications are proved, establishing \(\mathrm{NP}\)-hardness under the stated restrictions.

4. Membership in \(\mathrm{NP}\) and running times

A certificate is a subset \(S\subseteq T\) of types intended to be satisfied.

The verifier first checks \(\sum_{t\in S}\mu_t\ge\kappa\). It then checks feasibility of the rational linear system consisting of

\(\displaystyle X_{tg}\ge0,\qquad \sum_gX_{tg}=\mu_t,\qquad \sum_tX_{tg}=q_g,\)

and, for every \(t\in S\),

\(\displaystyle \sum_{g\in A_t}X_{tg}\ge\mu_t(1-h_t).\)

By Section 1, this system is feasible precisely when an allocation satisfies every type in \(S\). Additional satisfied types only increase the objective. Conversely, any allocation meeting the target supplies an accepting certificate by choosing its satisfied types.

Rational linear-program feasibility is decidable in polynomial bit time. Here there are \(m\tau\) variables and \(O(m\tau+m+\tau)\) constraints; all coefficients have encoding length polynomial in \(m,\tau,L\). In particular, computing \(\mu_t(1-h_t)\) increases bit length only polynomially. Thus verification takes \(\operatorname{poly}(m,\tau,L)\) time, proving membership in \(\mathrm{NP}\).

Enumerating all certificates also gives an exact deterministic algorithm running in \(2^\tau\operatorname{poly}(m,\tau,L)\) time.

5. Why the finite-agent result does not contradict this

The polynomial algorithm for maximizing the satisfied count with all requirements equal to one uses equal rewards: each satisfied agent contributes one. [Theorem 10 of the supplied paper](https://arxiv.org/html/2502.13772v2) exploits this by selecting agents in order of their required probability.

Here the reward is the type mass \(\mu_t\). The reduction makes that reward \(a_i/D\), while its consumption of class \(a\) is at least \(a_i(1-i/H)/D\). The total difference is less than one scaled integer unit, forcing an exact subset sum. Thus varying masses already cause hardness when every requirement equals one.
