The continuous mirror question, as graded

Given ordered finite strength tiers \(T\), rational masses \(\mu_t\) summing to one, bracket height \(h\), two popularity values \(q_t\) in \(\{a,b\}\), and target \(B\), let \(N=2^h\) and use normalized mass-flow variables \(y_{t,r}\) and \(a_{i,r}\) for type mass assigned to \(r\)-round subtournaments and open-subtournament counts divided by \(N\). Require \(a_{0,h}=1/N\), \(a_{0,r}=0\) for \(r<h\), \(\sum_r y_{t,r}=\mu_t\), \(a_{i,r}=a_{i-1,r}-y_{i,r}+\sum_{s>r}y_{i,s}\), \(0\le y_{i,r}\le a_{i-1,r}\), and \(a_{\tau,r}=0\). Decide whether there is a feasible trajectory with \(\sum_{t,r} r q_t y_{t,r}\) at least \(B\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) strength types \(T=(1,\ldots,\tau)\), ordered strictly from strongest to weakest, with positive binary-rational masses \(\mu_i\) summing to \(1\). Here \(m=|T|=\tau\) is the support size, not the number of possible types.
Each type has popularity \(q_i\in\{a,b\}\), where \(a>b\geq0\) are binary-encoded integers and both values occur. A match contributes its winner's popularity. The input also contains a unary-encoded height \(h\geq1\) and binary-rational threshold \(B\); set \(N=2^h\). Let \(L\) be the total input bit length.
For \(0\leq r\leq h\), an open subtournament has \(2^r\) positions; assigning its winner closes it and opens one subtournament of each height \(0,\ldots,r-1\). Height \(0\) means a single position and contributes no wins.
A continuous trajectory consists of nonnegative real variables \(y_{i,r}\), the mass of type \(i\) assigned as winners of height-\(r\) subtournaments, and \(a_{i,r}\), the open-subtournament counts divided by \(N\) after processing types \(1,\ldots,i\).
Require \(a_{0,h}=1/N\), \(a_{0,r}=0\) for \(r<h\), and \(\sum_{r=0}^{h}y_{i,r}=\mu_i\) for every \(1\leq i\leq\tau\).
For every \(1\leq i\leq\tau\) and \(0\leq r\leq h\), require \(0\leq y_{i,r}\leq a_{i-1,r}\), \(a_{i,r}=a_{i-1,r}-y_{i,r}+\sum_{s=r+1}^{h}y_{i,s}\), and \(a_{\tau,r}=0\). Newly opened subtournaments become available only to later types.
The decision problem asks whether such a trajectory exists with normalized value \(\sum_{i=1}^{\tau}\sum_{r=0}^{h}r q_i y_{i,r}\geq B\).

Is this continuous decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,h,L\).

For explicitly listed discrete players with a strict strength order and two winner-popularity values, tournament value maximization has a linear-time algorithm. [Source](https://arxiv.org/html/2309.09967v2#S4.SS3)
No result settling this exact continuous trajectory problem was located in the literature search.

Modeling choices made when packaging the task

  • Specified the type order as strongest to weakest and all round indices as ranging from zero through h, including degenerate single-position subtournaments.
  • Specified popularity values as nonnegative binary-encoded integers with a greater than b, following the discrete popularity domain, and required both values to occur.
  • Specified h as a positive unary-encoded integer because the model explicitly indexes every bracket height; specified B as a binary rational and L as total input bit length.
  • Specified trajectory variables as nonnegative reals without integrality or mass-quantization requirements, and the objective as tournament value divided by N.
  • Made explicit that the stated availability bound processes each tier simultaneously: subtournaments opened by a tier are available only to later tiers.
  • Identified m with the number of supported strength types, so m equals tau.

Classification

The stated continuous decision problem is in \(\mathrm{P}\). It is exactly feasibility of a rational linear program of polynomial encoding length. This settles the specified trajectory model, including the restriction that newly opened subtournaments are available only to later types.

1. Exact linear formulation

Write \(H=h+1\). Use the \(2\tau H\) real variables \(y_{i,r}\) and \(a_{i,r}\), for \(1\leq i\leq\tau\) and \(0\leq r\leq h\). Treat \(a_{0,r}\) as the specified constants.

Impose the following constraints:

  • Nonnegativity: \(y_{i,r}\geq0\) and \(a_{i,r}\geq0\).
  • Availability: \(y_{i,r}\leq a_{i-1,r}\).
  • Type mass: \(\sum_{r=0}^{h}y_{i,r}=\mu_i\).
  • State update: \(a_{i,r}-a_{i-1,r}+y_{i,r}-\sum_{s=r+1}^{h}y_{i,s}=0\).
  • Terminal state: \(a_{\tau,r}=0\).
  • Value threshold: \(\sum_{i=1}^{\tau}\sum_{r=0}^{h}r q_i y_{i,r}\geq B\).

Every expression is affine in the variables; the popularities, masses, and threshold are input constants.

Equivalence. A trajectory answering the original question positively satisfies every constraint above. Conversely, a feasible point supplies nonnegative trajectory variables satisfying every defining condition and the required value threshold. In particular, availability uses \(a_{i-1,r}\), so openings produced while processing type \(i\) cannot be used by that same type.

Thus the reduction is exact. It introduces neither an integrality condition nor a relaxation of the stated model.

2. Polynomial encoding size

Let \(d=2\tau H\) be the number of variables. There are:

  • \(2\tau H\) nonnegativity inequalities;
  • \(\tau H\) availability inequalities;
  • \(\tau+\tau H+H\) equalities;
  • one threshold inequality.

Replacing each equality by two inequalities yields \(p=5\tau H+2\tau+2H+1\) inequalities. Hence \(d,p=O(\tau H)\).

All matrix coefficients outside the threshold row belong to \(\{-1,0,1\}\). A threshold coefficient \(r q_i\) has bit length \(O(L+\log H)\), because \(r\leq h\) and \(q_i\) is a binary-encoded input integer.

The initial constant \(1/N=2^{-h}\) has an ordinary numerator–denominator encoding of length \(O(h)\): its denominator is a binary one followed by \(h\) zeros. Consequently, the magnitude of \(N\) does not force an exponentially long formulation.

Set \(D=\tau(h+1)\). A dense encoding of the inequality system has total bit length bounded by

\(S=O\!\left(D^2+D(L+\log(h+1))+L+h\right).\)

Since the height is unary encoded, \(h\leq L\). Therefore this simplifies to

\(S=O(D^2+DL).\)

The formulation can be constructed in polynomial time in this bound.

3. Exact feasibility and running time

Use the standard rational linear-programming theorem: feasibility of an explicitly encoded system of rational linear equalities and non-strict inequalities is decidable in time polynomial in its total binary encoding length. This theorem applies to arbitrary rational polyhedra, including those of lower dimension; it does not require a strictly feasible point. See [MIT’s ellipsoid-method lecture, Section 3.12](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

All its hypotheses hold here: the formulation is explicit, all coefficients are rational, and its encoding length is polynomial in the original input length. Applying that theorem gives a deterministic bit running time of

\(\left((\tau(h+1))^2+\tau(h+1)L\right)^{O(1)}.\)

Because \(m=\tau\), this is also

\(\left((m(h+1))^2+m(h+1)L\right)^{O(1)}=\operatorname{poly}(m,h,L).\)

Finally, explicit support listing implies \(\tau\leq L\), and unary height implies \(h\leq L\). The running time is therefore \(L^{O(1)}\), proving membership in \(\mathrm{P}\).

The threshold is included directly as a non-strict inequality. Accordingly, the algorithm decides exact feasibility even when the optimum equals \(B\); no numerical tolerance or approximation assumption is needed.

4. Scope of the conclusion

This proof does not require the discrete-player algorithm or the restriction to two popularity values. It also establishes polynomial-time solvability of the same trajectory problem with arbitrary explicitly listed binary-rational popularities.

The established running time is polynomial in numerical encoding length; no strongly polynomial or linear-time claim is made. Under polynomial-time many-one reductions, NP-hardness of this problem would imply \(\mathrm{P}=\mathrm{NP}\).
