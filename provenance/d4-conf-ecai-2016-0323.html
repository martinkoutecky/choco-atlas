Conclusion

The continuous problem is solvable exactly in polynomial time in \(m,\tau,L\). It is an explicitly given rational linear program. The cited discrete hardness result concerns an additional integrality requirement.

1. Exact linear programming formulation

Index the listed types by \(t\in\{1,\ldots,\tau\}\). Define the incidence matrix \(C\in\{0,1\}^{m\times\tau}\) by \(C_{jt}=1\) if \(j\in S_t\), and \(C_{jt}=0\) otherwise. Each column has two or three nonzero entries.

Consider the linear program

\(\displaystyle \max\{\mathbf 1^\top x:Cx\le q,\ x\le\mu,\ -x\le0\}.\)

This formulation is exactly equivalent to the allocation problem:

  • The inequalities \(0\le x_t\le\mu_t\) express the permitted served mass of each type.
  • For category \(j\), the quantity \((Cx)_j=\sum_{t:j\in S_t}x_t\) is its consumption.
  • Because revenue per unit of served mass is one, revenue equals \(\mathbf 1^\top x\).

There are \(\tau\) variables and \(m+2\tau\) inequalities. Variables are needed only for the listed support types.

The feasible set is nonempty because \(x=0\) is feasible, using \(q_j\ge0\). It is closed and bounded because it lies in \(\prod_{t=1}^{\tau}[0,\mu_t]\). Thus the objective attains a maximum. Moreover, every feasible allocation satisfies \(\mathbf 1^\top x\le\sum_t\mu_t=1\).

2. Polynomial-time computation of an exact maximizer

We use the following standard rational linear programming theorem:

Theorem. Given an explicitly encoded linear program with rational coefficients, a deterministic algorithm can determine feasibility and boundedness and, when a finite optimum exists, return an exact rational optimal solution in a number of bit operations polynomial in the total encoding length.

The classical polynomial-time algorithms for rational linear programming are discussed by [Adler and Beling](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf); exact solution computation is also treated by [Gleixner and Steffy](https://arxiv.org/abs/1912.12820).

All hypotheses hold here: the constraint matrix has entries in \(\{-1,0,1\}\), the right-hand sides are the input rationals and zeros, and the objective coefficients are ones. Section 1 establishes feasibility and a finite, attained optimum. Consequently, the theorem returns an exact maximizing allocation, including when some supplies are zero.

A dense encoding of this linear program has length

\(\displaystyle N=O\bigl(L+\tau(m+\tau)\bigr).\)

Indeed, the constraint matrix has \((m+2\tau)\tau\) constant-size entries, while the nonconstant numerical data are already included in \(L\). Constructing this encoding takes \(O\bigl(L+\tau(m+\tau)\bigr)\) bit operations.

Therefore, for some fixed polynomial \(p\), the complete algorithm has running time

\(\displaystyle T(m,\tau,L)\le p\bigl(L+\tau(m+\tau)\bigr).\)

This is a polynomial bound in all three requested parameters.

3. Why exact output has polynomial length

For completeness, we verify directly that an optimal allocation can have a polynomial-size rational encoding.

First replace each supply by \(q'_j=\min\{q_j,1\}\). This preserves feasibility: nonnegativity and \(\sum_t x_t\le1\) imply \((Cx)_j\le1\).

A linear objective on a nonempty bounded polytope has an optimal vertex. Let \(x^*\) be such a vertex. Its active constraint normals span \(\mathbb R^\tau\): otherwise, a nonzero vector orthogonal to all active normals would permit sufficiently small feasible perturbations in both directions, contradicting extremality. Select \(\tau\) independent active constraints and write them as \(Wx^*=d\).

Here \(W\) is a nonsingular integer matrix with entries in \(\{-1,0,1\}\), and every entry of \(d\) lies in \([0,1]\). Let \(D\) be the product of the denominators of the original input masses and supplies. Its binary length is \(O(L)\), and \(Dd\) is integral.

For coordinate \(k\), let \(W^{(k)}\) be obtained from \(W\) by replacing column \(k\) with \(Dd\). Cramer’s rule gives

\(\displaystyle x^*_k=\frac{\det W^{(k)}}{D\det W}.\)

Each column of \(W\) has Euclidean norm at most \(\sqrt{\tau}\); the replacement column has norm at most \(D\sqrt{\tau}\). Hadamard’s determinant inequality therefore gives

\(\displaystyle |\det W|\le\tau^{\tau/2},\qquad |\det W^{(k)}|\le D\tau^{\tau/2}.\)

Since \(\det W\) is a nonzero integer, this represents each coordinate using \(O\bigl(L+\tau\log(\tau+1)\bigr)\) bits. Thus exact output does not require exponentially many bits.

4. Why discrete hardness does not transfer

Accepting or rejecting an indivisible bid requires a binary variable. The continuous problem instead permits every \(x_t\in[0,\mu_t]\), so integrality is not among its constraints.

This distinction changes optimal revenue even on a small admissible instance. Take \(m=3\), with support bundles \(S_1=\{1,2\}\), \(S_2=\{1,3\}\), \(S_3=\{2,3\}\), masses \(\mu_1=1/2\), \(\mu_2=\mu_3=1/4\), and supplies \(q_1=q_2=q_3=1/4\).

The allocation \(x_1=x_2=x_3=1/8\) is feasible and earns \(3/8\). Summing the three supply inequalities gives \(2(x_1+x_2+x_3)\le3/4\), proving optimality.

If each type must instead be served entirely or not at all, type one is infeasible, and types two and three cannot both be served because they share category three. The optimum is then \(1/4\).

Thus the continuous formulation is not an exact encoding of discrete bid acceptance. Its polynomial-time solvability follows from rational linear programming, regardless of the discrete hardness result. In particular, NP-hardness under standard polynomial-time reductions would imply \(\mathrm P=\mathrm{NP}\).
