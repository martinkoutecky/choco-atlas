The continuous mirror question, as graded

Given a finite-support rational distribution \(\mu\) over installation types with entitlements \(\ell_t\) and a common cap \(M>\max_t\ell_t\), determine a dominant claim for each type and the resulting per-installation payoffs in the atomless slack-allocation game.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\ge1\) installation types with positive masses \(\mu_t\) encoded as binary rationals, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Entitlements \(\ell_t>0\) and the common cap \(M>\max_t\ell_t\) are binary rationals; \(L\) is the total input bit length. There is one resource, so \(m=1\); state running times in \(m,\tau,L\).
Represent installations by an atomless probability space \((A,\nu)\), partitioned into measurable sets \(A_t\) of mass \(\mu_t\). Each installation independently chooses a real claim in \([0,M]\); profiles \(c:A\to[0,M]\) are measurable. Utility is the settlement payoff, and claims are costless.
Write \(\ell(a)=\ell_t\) for \(a\in A_t\), \(v(a)=(c(a)-\ell(a))_+\), \(s(a)=(\ell(a)-c(a))_+\), \(X=\int_Av\,d\nu\), and \(I=\int_As\,d\nu\).
Define \(q(X,I)=1\) when \(X\le I\), including \(X=I=0\), and \(q(X,I)=I/X\) when \(X>I\). An installation of type \(t\) claiming \(z\) receives \(p_t(z;X,I)=z\) if \(z\le\ell_t\), and \(p_t(z;X,I)=\ell_t+q(X,I)(z-\ell_t)\) otherwise. Unused slack is discarded.
A claim \(d_t\in[0,M]\) is weakly dominant if \(p_t(d_t;X,I)\ge p_t(z;X,I)\) for every alternative \(z\in[0,M]\) and every measurable profile of other installations. A unilateral deviation changes no aggregate; a type is not a single player controlling its entire mass. The induced outcome assigns \(d_t\) to every installation in \(A_t\).

Is finding a weakly dominant claim for every type and computing the induced per-installation payoffs solvable in polynomial time in \(m,\tau,L\), or is this computational problem NP-hard?

For finite societies with the same costless linear clearing rule and cap, own payoff is nondecreasing in own claim, so maximal claiming is weakly dominant. [Lengyel (2025)](https://arxiv.org/html/2509.07145v3)
No result settling this exact atomless computational problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one and represented each positive-mass type by an atomless set of independently acting installations.
  • Specified measurable profiles and individual null-mass deviations; dominance is against arbitrary installation profiles, including profiles with different claims within a type.
  • Carried over positive entitlements, costless claims, real actions in the closed bounded interval, and the linear overage-proportional rule; entitlements and the cap are binary rational inputs.
  • Used full overage coverage at the equality boundary, including zero aggregates, and discarded unused slack.
  • Interpreted resulting payoffs as those induced when every installation uses the selected dominant claim for its type; dominance is weak and no uniqueness is required.
  • Set the resource count to one and defined the total input bit length.

Result

The problem is polynomial-time solvable. For every type \(t\), the unique weakly dominant claim is \(d_t=M\). The induced per-installation payoff is exactly \(\ell_t\).

The finite-society dominance result appears in [Lengyel (2025), Proposition 3](https://arxiv.org/html/2509.07145v3). The following proof establishes the stated atomless problem directly.

1. Maximal claiming is weakly dominant

Fix a type \(t\), and fix any measurable profile of other installations. By the stipulated atomless unilateral-deviation convention, changing one installation’s claim leaves the aggregates \(X\) and \(I\) unchanged.

Both aggregates are finite and nonnegative: pointwise, \(0\le v\le M\) and \(0\le s\le\max_t\ell_t\). Consequently, the clearing factor always satisfies \(0\le q(X,I)\le1\). Indeed, it equals \(1\) when \(X\le I\), and equals \(I/X\in[0,1)\) when \(X>I\).

Write \(q=q(X,I)\). Since \(M>\ell_t\), maximal claiming yields \(p_t(M;X,I)=\ell_t+q(M-\ell_t)\). Compare this with an arbitrary alternative \(z\in[0,M]\).

  • If \(z\le\ell_t\), then

\(p_t(M;X,I)-p_t(z;X,I)=(\ell_t-z)+q(M-\ell_t)\ge0\).

  • If \(z>\ell_t\), then

\(p_t(M;X,I)-p_t(z;X,I)=q(M-z)\ge0\).

These cases cover every alternative. Because the opponents’ profile was arbitrary, \(M\) is weakly dominant for every type.

2. No smaller claim is weakly dominant

Fix a type \(t\) and a candidate \(d<M\). Let every other installation claim zero. This is a measurable profile, and the individual installation under consideration has no effect on the aggregates.

Under this opponents’ profile, \(X=0\) and \(I=\sum_{u=1}^{\tau}\mu_u\ell_u>0\). The strict positivity follows from the positive masses and entitlements. Thus \(q(X,I)=1\), regardless of the individual’s claim.

When \(q=1\), the settlement payoff equals the claim throughout \([0,M]\): below the entitlement this follows from the first payoff branch, and above it from \(\ell_t+(z-\ell_t)=z\). Therefore \(p_t(M;X,I)=M>d=p_t(d;X,I)\).

This opponents’ profile disproves weak dominance of \(d\). Hence \(M\) is the unique weakly dominant claim for every type, including when \(\tau=1\): one type still consists of atomless individual players.

3. Payoffs at the induced profile

Assign \(c^*(a)=M\) to every installation. This profile is measurable. For each \(a\in A_t\), the strict cap inequality gives \(v(a)=M-\ell_t>0\) and \(s(a)=0\).

It follows that

\(X^*=\sum_{t=1}^{\tau}\mu_t(M-\ell_t)>0,\qquad I^*=0.\)

Every summand defining \(X^*\) is positive. Therefore the clearing rule uses its \(X>I\) branch and gives \(q(X^*,I^*)=0\). Each installation of type \(t\) consequently receives

\(p_t(M;X^*,I^*)=\ell_t+0\cdot(M-\ell_t)=\ell_t.\)

Thus both the dominant claims and the induced payoffs have exact rational representations already present in the input.

4. Algorithm and bit complexity

Return, in the input’s type order, the pair \((d_t,p_t)=(M,\ell_t)\) for each \(t\).

Let \(b_M\le L\) be the bit length of the encoded cap. Reading the input takes \(O(L)\) bit operations. Writing \(\tau\) copies of \(M\) takes \(O(\tau b_M)\), and copying all entitlement encodings takes \(O(L)\). The total running time is therefore

\(O(L+\tau b_M)\subseteq O(\tau L).\)

No rational summation or division is needed by the algorithm: the preceding proof establishes the payoffs symbolically. Since the stipulated domain has \(m=1\), this is also an \(O(m\tau L)\) bound on that domain; no extension to multiple resources is asserted.
