The continuous mirror question, as graded

Given a candidate set \(C\), committee size \(k\), and a finite support \(\mathcal T\subseteq 2^C\) with positive rational masses \(\mu_B\) summing to \(1\), define \(\operatorname{PAV}_{\mu}(W)=\sum_{B\in\mathcal T}\mu_B H_{|B\cap W|}\) for each \(W\subseteq C\) of size \(k\). Is there exactly one committee maximizing \(\operatorname{PAV}_{\mu}\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\ge1\) distinct candidates, and let the input committee size satisfy \(1\le k\le m\).
A society is given by its support: a nonempty list \(\mathcal T\subseteq 2^C\) of \(\tau\) distinct approval types with positive binary rational masses \(\mu_B\) summing to \(1\). Empty approval sets are allowed. Here \(\tau\) is the support size, not the number of possible approval types.
For each committee \(W\subseteq C\) with \(|W|=k\), define \(\operatorname{PAV}_{\mu}(W)=\sum_{B\in\mathcal T}\mu_B H_{|B\cap W|}\), where \(H_j\) is the harmonic number and \(H_0=0\). Retain all maximizing committees without tie-breaking.
The decision problem asks whether exactly one committee maximizes this score. Let \(L\) be the total binary input length; state running times in \(m,\tau,L,k\).

Is this rational-mass PAV uniqueness problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard under polynomial-time many-one reductions?

For explicitly listed finite electorates, PAV uniqueness is \(\Delta_2^{\mathrm P}\)-complete under polynomial-time many-one reductions, even when there are at most two optimal committees.

Result

The problem is NP-hard under polynomial-time many-one reductions. More precisely, using the finite-electorate completeness result supplied in the question, it is \(\Delta_2^{\mathrm P}\)-complete, even when there are at most two optimal committees.

The key is that aggregating identical voters into rational masses preserves every score comparison and requires only polynomial space and time.

1. Reduction from explicitly listed electorates

Consider an explicitly listed electorate with \(N\ge 1\) voters, approval sets \(A_1,\ldots,A_N\), candidate set \(C\), and committee size \(k\). Its unnormalized PAV score is
\[ \operatorname{PAV}_{\mathrm{fin}}(W)=\sum_{i=1}^{N}H_{|A_i\cap W|}. \]

For each distinct approval set \(B\) occurring in the electorate, let \(n_B\) be its multiplicity. Construct the rational-mass instance with support
\[ \mathcal T=\{B:n_B>0\} \]
and masses
\[ \mu_B=\frac{n_B}{N}. \]

These masses are positive rationals summing to \(1\), and the support contains \(\tau\le N\) distinct types. Empty approval sets cause no difficulty.

For every size-\(k\) committee \(W\),
\[ \operatorname{PAV}_{\mu}(W) =\sum_{B\in\mathcal T}\frac{n_B}{N}H_{|B\cap W|} =\frac{1}{N}\operatorname{PAV}_{\mathrm{fin}}(W). \]
Multiplication by the positive constant \(1/N\) preserves all strict comparisons and all ties. Thus the two instances have exactly the same maximizing committees. In particular, uniqueness is preserved, as is the promise of at most two optimal committees.

For completeness, a zero-voter electorate, if permitted, can be mapped to the support \(\{\varnothing\}\) with mass \(1\); both instances give every committee score zero.

To bound the reduction, represent approval sets by length-\(m\) bit vectors, sort them, and count repetitions. For \(N\ge1\), this takes \(O(Nm\log(N+1))\) bit operations, apart from polynomial encoding overhead. Each mass requires \(O(\log(N+1))\) bits, so the output length is
\[ O\bigl(m+\log(k+1)+\tau(m+\log(N+1))\bigr). \]
Consequently the reduction is polynomial in the explicitly listed input length. It enumerates only occurring types.

By the stated finite-electorate theorem, this proves \(\Delta_2^{\mathrm P}\)-hardness, hence NP-hardness, under polynomial-time many-one reductions.

2. Exact arithmetic with polynomial bit length

We next prove membership in \(\Delta_2^{\mathrm P}\), without expanding rational masses into voters.

Write each mass as \(\mu_B=a_B/b_B\), with positive binary integers \(a_B,b_B\). Define
\[ Q=\prod_{B\in\mathcal T}b_B,\qquad F=k!,\qquad D=QF. \]
For \(0\le j\le k\), define
\[ h_0=0,\qquad h_j=\sum_{i=1}^{j}\frac{F}{i}, \]
and put \(c_B=a_BQ/b_B\). All these quantities are integers: each denominator \(b_B\) divides \(Q\), and each \(i\le k\) divides \(k!\).

The scaled score
\[ S(W)=\sum_{B\in\mathcal T}c_Bh_{|B\cap W|} \]
therefore satisfies \(S(W)=D\operatorname{PAV}_{\mu}(W)\). Since \(\sum_Bc_B=Q\) and \(H_j\le k\),
\[ 0\le S(W)\le kD. \]

Let
\[ \beta=L+k\lceil\log_2(k+1)\rceil+\lceil\log_2(k+1)\rceil+2. \]
The inequalities \(\log_2 Q\le L\) and \(\log_2(k!)\le k\log_2(k+1)\) imply that \(kD\), all scaled scores, and all intermediate nonnegative sums fit in \(O(\beta)\) bits.

Using schoolbook integer arithmetic, the coefficients and harmonic table can be computed in \(O((\tau+k)\beta^2)\) bit operations. After this preprocessing, evaluating a committee costs
\[ O(m\tau+\tau\beta^2) \]
bit operations: intersect it with every support type, multiply the corresponding integers, and add.

3. An NP-oracle algorithm

For an integer threshold \(z\), consider the predicate
\[ \exists W\subseteq C:\quad |W|=k\ \text{and}\ S(W)\ge z. \]
This predicate is in NP. A certificate is the length-\(m\) incidence vector of \(W\); its cardinality and score can be checked in polynomial time using the preceding arithmetic.

Binary search over the integer interval from \(0\) through \(kD\) finds the maximum scaled score \(M\) using \(O(\beta)\) NP-oracle queries.

One additional NP query asks whether there exist two distinct size-\(k\) committees \(W_1,W_2\) with
\[ S(W_1)=S(W_2)=M. \]
Two incidence vectors provide a polynomially verifiable certificate.

At least one size-\(k\) committee exists because \(1\le k\le m\). Hence the optimum is unique exactly when this final query answers no. This establishes membership in \(\mathrm P^{\mathrm{NP}}=\Delta_2^{\mathrm P}\), completing the classification.

4. Running times and boundary cases

The oracle algorithm uses \(O(L+k\log(k+1))\) NP-oracle calls and polynomial deterministic overhead in \(m,\tau,L,k\).

A deterministic exhaustive algorithm, with no oracle, evaluates all \(\binom{m}{k}\) committees and counts how many attain the maximum. Its bit-operation bound is
\[ O\!\left((\tau+k)\beta^2+ \binom{m}{k}(m\tau+\tau\beta^2)\right). \]
Thus fixed \(k\) gives a polynomial-time algorithm; the hardness concerns unrestricted input \(k\).

When \(k=m\), there is only one feasible committee, so the answer is always yes. When \(k=1\), singleton scores are the total masses approving each candidate, and uniqueness can be checked in polynomial time by counting candidates attaining the largest such total.

For general input \(k\), polynomial-time solvability is equivalent to \(\mathrm P=\mathrm{NP}\): hardness gives one implication, and the NP-oracle upper bound gives the other.
