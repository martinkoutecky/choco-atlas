How Hard Is It for a Party to Nominate an Election Winner? (d4-conf-ijcai-2016-0419)

Answer: \(\mathrm{NP}\text{-complete}\)

Theorem 3 — class: hardness

The continuous mirror question, as graded

Given candidates \(C\) partitioned into parties \(P_1,\ldots,P_t\), target party \(P_w\), a societal axis \(B\), and rational masses \(\mu_\rho\) over complete rankings \(\rho\) that are single-peaked with respect to \(B\), decide whether there exists \(q\in P_1\times\cdots\times P_t\) such that some \(q_w\) maximizes \(\operatorname{score}_{\mu,q}(c)=\sum_{\rho\in T:\,c\text{ is top-ranked among }q\text{ under }\rho}\mu_\rho\), with ties accepted.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq 1\) candidates, partitioned into \(t\geq 1\) nonempty parties \(P_1,\ldots,P_t\), with target index \(1\leq w\leq t\). A supplied societal axis \(B\) is a linear order on \(C\); party members need not be consecutive on it.
A society is given by its support \(T\): a list of \(\tau\geq 1\) distinct strict complete rankings of \(C\), each single-peaked with respect to \(B\), with positive binary rational masses \(\mu_\rho\) satisfying \(\sum_{\rho\in T}\mu_\rho=1\). Here \(\tau=|T|\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L,t\).
Each party nominates exactly one candidate: \(q=(q_1,\ldots,q_t)\in\prod_{i=1}^{t}P_i\). Writing \(Q=\{q_1,\ldots,q_t\}\), define \(s_{\mu,q}(c)=\sum_{\rho\in T:\,c\text{ is highest in }Q\text{ under }\rho}\mu_\rho\) for \(c\in Q\). The decision problem asks whether some nomination satisfies \(s_{\mu,q}(q_w)\geq s_{\mu,q}(q_i)\) for every \(1\leq i\leq t\); ties count as wins.

Is this decision problem solvable in polynomial time in \(m,\tau,L,t\), or is it NP-hard?

For explicit finite electorates, the same nomination problem is NP-complete with single-peaked rankings, and is in \(\mathrm{P}\) when every party is consecutive on the supplied axis. [Source](https://www.lamsade.dauphine.fr/~lang/papers/FGLLM16.pdf)
No published result specifically treating the stated rational-mass support representation was located.

Modeling choices made when packaging the task

  • The mass normalization was unspecified; use positive support masses summing to one, as a distribution over types.
  • Make the implicit ranking domain explicit: strict complete rankings, consistent with the discrete preference orders.
  • Require nonempty parties and a valid target index, so each party can nominate exactly one candidate.
  • Define L as the total input bit length and tau as the number of distinct positive-mass ranking types.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The decision problem is \(\mathrm{NP}\)-complete. Consequently, it has a polynomial-time algorithm in \(m,\tau,L,t\) only if \(\mathrm{P}=\mathrm{NP}\).

For \(t=1\), the answer is always yes. The hardness result concerns the general case where \(t\) is part of the input.

Polynomial reduction from explicit electorates

We use the following established result: for an explicitly listed finite electorate with strict single-peaked rankings, deciding whether some nomination makes the target party’s nominee a plurality winner is \(\mathrm{NP}\)-complete. This is Theorem 3 of [Faliszewski et al., *How Hard Is It for a Party to Nominate an Election Winner?*](https://www.lamsade.dauphine.fr/~lang/papers/FGLLM16.pdf). Their model counts ties as wins, and their hardness construction explicitly supplies a societal axis. Thus its axis can be included in the source instance.

Let a source instance have \(n\geq 1\) explicitly listed voters, with rankings \(\rho_1,\ldots,\rho_n\). Keep its candidates, parties, target index, and axis unchanged.

Let \(T\) be the set of distinct rankings occurring in this list. For each \(\rho\in T\), define

\[ k_\rho=\left|\{j:\rho_j=\rho\}\right|, \qquad \mu_\rho=\frac{k_\rho}{n}. \]

The resulting instance satisfies all required hypotheses:

  • Its support consists of distinct strict complete rankings.
  • Every supported ranking is single-peaked on the unchanged supplied axis.
  • Each mass is a positive rational.
  • Since the multiplicities partition the voter list, \(\sum_{\rho\in T}\mu_\rho=1\).
  • Its support size satisfies \(1\leq\tau\leq n\).

This transformation is polynomial in the source input length. Identical rankings can be grouped by sorting their explicitly supplied encodings. Each numerator and denominator needs \(O(\log(n+1))\) bits; reducing fractions, if required by the encoding, also takes polynomial time. No unlisted rankings are generated.

For any nomination \(q\) and any \(c\in Q\), let \(v_q(c)\) be the number of source voters whose highest-ranked nominee is \(c\). Grouping these voters by ranking gives

\[ s_{\mu,q}(c) = \sum_{\rho\in T:\,c\text{ is highest in }Q\text{ under }\rho} \frac{k_\rho}{n} = \frac{v_q(c)}{n}. \]

Because \(n>0\), for every party index \(i\),

\[ s_{\mu,q}(q_w)\geq s_{\mu,q}(q_i) \quad\Longleftrightarrow\quad v_q(q_w)\geq v_q(q_i). \]

Thus the transformation preserves the winning nominations exactly, including ties. It is a polynomial many-one reduction from the established \(\mathrm{NP}\)-hard problem, proving \(\mathrm{NP}\)-hardness of the rational-mass support problem.

Membership in \(\mathrm{NP}\) and verification time

A certificate specifies one candidate \(q_i\in P_i\) for each party. Its encoding has \(O(t\log(m+1))\) bits.

Write each input mass as \(\mu_\rho=a_\rho/b_\rho\), with positive binary integers \(a_\rho,b_\rho\). Define

\[ D=\prod_{\rho\in T}b_\rho, \qquad A_\rho=a_\rho\frac{D}{b_\rho}. \]

Each \(A_\rho\) is a positive integer, and normalization implies

\[ \sum_{\rho\in T}A_\rho = D\sum_{\rho\in T}\mu_\rho = D. \]

The bit length of \(D\) is at most \(1+\sum_{\rho\in T}\log_2 b_\rho\), hence \(O(L)\). Every \(A_\rho\), and every partial sum of these integers, is at most \(D\), so all score computations use \(O(L)\)-bit integers.

After checking that each certificate candidate belongs to its designated party, scan each supported ranking from highest to lowest until encountering a nominee. Add \(A_\rho\) to that nominee’s integer score. The resulting score is

\[ S_q(c)=D\,s_{\mu,q}(c). \]

Accept precisely when \(S_q(q_w)\geq S_q(q_i)\) for every \(i\). Since \(D>0\), this is exactly the required condition.

Using schoolbook integer multiplication and division, a conservative bound for verification on the stated valid inputs is \(O((\tau m+\tau+t+1)L^2)\) bit operations. This includes scanning the rankings, forming the integer weights, accumulating scores, and comparing them. It is polynomial in \(m,\tau,L,t\), proving membership in \(\mathrm{NP}\).

Conclusion

The polynomial reduction and polynomial certificate verification together prove \(\mathrm{NP}\)-completeness. A separate published hardness theorem for rational-mass supports is unnecessary: grouping an explicit electorate preserves every nomination outcome and produces a polynomial-size instance of the stated representation.
