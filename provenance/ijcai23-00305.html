The continuous mirror question, as graded

Given finite item categories \(M\), rational type masses \(\mu_t\), rational per-capita copy supplies \(\lambda_o\), and separable lexicographic types each having a terrible chore, does there exist a bundle census \(x_{t,B}\ge0\) satisfying \(\sum_B x_{t,B}=\mu_t\) and \(\sum_{t,B:o\in B}x_{t,B}=\lambda_o\), such that every pair of positive-mass configurations satisfies EFX for the first type and no feasible census admits a typewise Pareto improvement? If so, compute \(x\); otherwise report nonexistence.

Definitions

An instance has finite \(O,T\), rational \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), rational \(\rho_o\in[0,1]\), and for each \(t\), a linear importance order \(\triangleright_t\) and a partition \(O=G_t\mathbin{\dot\cup}C_t\). For distinct bundles \(B,D\subseteq O\), \(B\succ_tD\) iff the highest-ranked item of \(B\triangle D\) lies in \((B\cap G_t)\cup(D\cap C_t)\); write \(B\succeq_tD\) if \(B\succ_tD\) or \(B=D\).
A distributional allocation is \(x_{t,B}\ge0\) with \(\sum_{B\subseteq O}x_{t,B}=\mu_t\) and \(\sum_{t\in T}\sum_{B\ni o}x_{t,B}=\rho_o\) for every \(t,o\). It is EFX if, whenever \(x_{t,B},x_{u,D}>0\) and \(D\succ_tB\), then \(B\succeq_tD\setminus\{g\}\) for every \(g\in G_t\cap D\), and \(B\setminus\{c\}\succeq_tD\) for every \(c\in C_t\cap B\).

Complexity of Distributional EFX Feasibility

Theorem

The stated distributional EFX-feasibility problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard, even when:

  • three distinguished types regard every item as a good;
  • every remaining type has only three goods and regards all other items as chores; and
  • all supplies belong to \(\{1,2/7\}\).

Thus a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

Membership in \(\mathrm{NP}\)

Let \(m=|O|\) and \(n=|T|\), and suppose a feasible distributional allocation \(x\) exists. Let

\[ \mathcal S=\{(t,B):x_{t,B}>0\}. \]

Keeping only variables indexed by \(\mathcal S\), the mass and supply constraints form a rational linear system

\[ Ax=b,\qquad x\geq 0, \]

with \(n+m\) equality rows. Its feasible region is bounded because, for every type \(t\), the sum of the variables belonging to \(t\) equals \(\mu_t\).

Choose an extreme point \(x'\) of this feasible region. Every extreme point has at most \(\operatorname{rank}(A)\leq n+m\) positive coordinates. Moreover,

\[ \operatorname{supp}(x')\subseteq\mathcal S. \]

Deleting supported bundles cannot create a new EFX violation, because EFX is imposed only on pairs of bundles having positive mass. Consequently, \(x'\) is still EFX.

The matrix \(A\) is a \(0\)-\(1\) matrix. By Cramer's rule and the standard determinant bound, the rational coordinates of a basic feasible solution have encoding length polynomial in the input length and in \(n+m\). A certificate can therefore list at most \(n+m\) triples \((t,B,x'_{t,B})\).

Given such a certificate, one can verify in polynomial time:

  • nonnegativity and all mass and supply equalities;
  • the highest-ranked item of every relevant symmetric difference;
  • every required item-removal comparison for every ordered pair of supported bundles.

Hence the problem belongs to \(\mathrm{NP}\).

Reduction from \(3\)-COLORABILITY

We reduce from \(3\)-COLORABILITY on a simple graph \(H=(V,E)\). We may assume \(k=|E|\geq 1\): if necessary, add a disjoint edge, which does not change \(3\)-colorability.

Items

Introduce:

  • a universal item \(q\);
  • three private items \(p_1,p_2,p_3\);
  • one vertex item \(a_v\) for every \(v\in V\).

Thus

\[ O=\{q,p_1,p_2,p_3\}\mathbin{\dot\cup}\{a_v:v\in V\}. \]

Set the supplies to

\[ \rho_q=1,\qquad \rho_{p_i}=\frac27,\qquad \rho_{a_v}=\frac27. \]

Types and masses

There are three color types \(c_1,c_2,c_3\), each of mass

\[ \mu_{c_i}=\frac27. \]

For every edge \(e\in E\), introduce an edge-guard type \(h_e\) of mass

\[ \mu_{h_e}=\frac{1}{7k}. \]

The masses sum to

\[ 3\cdot\frac27+k\cdot\frac{1}{7k}=1. \]

The total mass of all guards is \(1/7\), strictly smaller than the mass \(2/7\) of one color type.

Preferences of the color types

For color type \(c_i\), every item is a good:

\[ G_{c_i}=O,\qquad C_{c_i}=\varnothing. \]

Its importance order places \(p_i\) first and \(q\) last. All remaining items may be ordered arbitrarily between them.

Preferences of an edge guard

Let \(e=\{v,w\}\). For \(h_e\), define

\[ G_{h_e}=\{q,a_v,a_w\},\qquad C_{h_e}=O\setminus G_{h_e}. \]

Its importance order begins

\[ q\mathrel{\triangleright_{h_e}}a_v \mathrel{\triangleright_{h_e}}a_w, \]

followed by all remaining items in arbitrary order. In particular, both endpoint items precede every chore.

The construction has polynomial encoding length.

Structural Properties of Every Feasible Allocation

Lemma 1: Every supported bundle contains \(q\)

The total population mass is \(1\), while \(\rho_q=1\). Therefore

\[ \sum_{t\in T}\sum_{B\not\ni q}x_{t,B}=0. \]

Thus every bundle with positive mass contains \(q\).

Lemma 2: Every \(c_i\)-bundle contains \(p_i\)

Suppose a supported bundle \(B\) of type \(c_i\) omitted \(p_i\). Since \(\rho_{p_i}=2/7>0\), some supported bundle \(D\) contains \(p_i\).

Under \(c_i\)'s order, \(p_i\) is the highest-ranked item. Hence \(D\succ_{c_i}B\). Both bundles contain \(q\), and \(q\) is a good for \(c_i\). EFX would therefore require

\[ B\succeq_{c_i}D\setminus\{q\}. \]

But \(D\setminus\{q\}\) still contains \(p_i\), whereas \(B\) does not. Since \(p_i\) is top-ranked,

\[ D\setminus\{q\}\succ_{c_i}B, \]

a contradiction.

Thus every supported \(c_i\)-bundle contains \(p_i\). Since \(\mu_{c_i}=\rho_{p_i}=2/7\), color type \(c_i\) exhausts the entire supply of \(p_i\). No other supported bundle contains \(p_i\).

Lemma 3: Each color type has a single supported bundle

Suppose distinct bundles \(B,D\) both occur in the support of \(c_i\). By strictness of the lexicographic order, assume \(D\succ_{c_i}B\).

Both bundles contain \(p_i\) and \(q\). Their first difference is therefore an item ranked above \(q\). Because every item is a good for \(c_i\), EFX applied to the common good \(q\in D\) requires

\[ B\succeq_{c_i}D\setminus\{q\}. \]

Removing the lowest-ranked item \(q\) does not change the earlier first difference between \(B\) and \(D\). Consequently,

\[ D\setminus\{q\}\succ_{c_i}B, \]

contradicting EFX.

Denote the unique bundle of \(c_i\) by \(D_i\).

Lemma 4: Every vertex item belongs to exactly one color bundle

Fix \(v\in V\), and let \(r\) be the number of color bundles among \(D_1,D_2,D_3\) that contain \(a_v\).

Their total contribution to the supply of \(a_v\) is \(2r/7\). The total mass of all guards is only \(1/7\). Since \(\rho_{a_v}=2/7\):

  • \(r=0\) is impossible, because the guards cannot supply mass \(2/7\);
  • \(r\geq 2\) is impossible, because the color types alone would contribute at least \(4/7\);
  • hence \(r=1\).

When \(r=1\), the unique color type already contributes exactly \(2/7\), so no guard bundle contains \(a_v\).

Together with Lemmas 1 and 2, this shows that every guard has the unique bundle \(\{q\}\).

The Edge-Guard Gadget

Fix \(e=\{v,w\}\), let \(B=\{q\}\) be the bundle of \(h_e\), and let \(D_i\) be a color bundle.

We claim that \(B\) and \(D_i\) satisfy EFX from the perspective of \(h_e\) if and only if \(D_i\) does not contain both \(a_v\) and \(a_w\).

Neither endpoint is in \(D_i\)

Every item of \(D_i\setminus\{q\}\) is then a chore for \(h_e\). Therefore \(B\succ_{h_e}D_i\), so the guard does not envy \(D_i\).

Exactly one endpoint is in \(D_i\)

Suppose \(a_v\in D_i\) and \(a_w\notin D_i\). Since \(a_v\) precedes every chore,

\[ D_i\succ_{h_e}B. \]

The goods of \(h_e\) contained in \(D_i\) are exactly \(q\) and \(a_v\).

After removing \(q\), the guard's bundle contains the top-ranked good \(q\), while \(D_i\setminus\{q\}\) does not. Hence

\[ B\succ_{h_e}D_i\setminus\{q\}. \]

After removing \(a_v\), the remaining items of \(D_i\setminus\{a_v\}\), apart from the common item \(q\), are chores. Thus

\[ B\succeq_{h_e}D_i\setminus\{a_v\}. \]

Finally, \(B\) contains no \(h_e\)-chore. All EFX conditions therefore hold.

The case in which only \(a_w\) is present is identical.

Both endpoints are in \(D_i\)

Because \(a_v\) is ranked above \(a_w\),

\[ D_i\setminus\{a_w\}\succ_{h_e}B, \]

as \(D_i\setminus\{a_w\}\) still contains the higher-ranked good \(a_v\). The EFX condition for removing the good \(a_w\) would require the reverse weak comparison. Hence EFX fails.

This proves the claim.

Correctness of the Reduction

If \(H\) is \(3\)-colorable

Let \(\chi:V\to\{1,2,3\}\) be a proper coloring. Give color type \(c_i\) the bundle

\[ D_i=\{q,p_i\}\cup\{a_v:\chi(v)=i\} \]

with mass \(2/7\). Give every guard \(h_e\) the bundle \(\{q\}\) with mass \(1/(7k)\).

All mass and supply constraints hold.

A color type never envies another supported bundle, because its own private item \(p_i\) is its highest-ranked good and occurs in no other bundle. Guards have identical bundles among themselves. Finally, properness of \(\chi\) ensures that no color bundle contains both endpoints of an edge. The edge-gadget analysis therefore proves EFX between every guard and every color bundle.

Hence the constructed distributional instance is feasible.

If the distributional instance is feasible

By Lemma 4, every vertex item \(a_v\) lies in exactly one of \(D_1,D_2,D_3\). Define

\[ \chi(v)=i\quad\text{if and only if}\quad a_v\in D_i. \]

For any edge \(e=\{v,w\}\), its guard has bundle \(\{q\}\). The edge-gadget analysis shows that EFX would fail if both \(a_v\) and \(a_w\) belonged to the same \(D_i\). Therefore

\[ \chi(v)\neq\chi(w) \]

for every edge. Thus \(\chi\) is a proper \(3\)-coloring of \(H\).

Conclusion

The reduction is polynomial and proves \(\mathrm{NP}\)-hardness. Together with membership in \(\mathrm{NP}\), the distributional EFX-feasibility problem is \(\mathrm{NP}\)-complete.

The argument is valid.

  • All feasibility equalities and all ordered EFX comparisons among the polynomially many supported bundles can be checked in polynomial time.

The fact that the original bundle space is exponential does not invalidate the certificate argument.

The construction contains \( |V|+4 \) items and \( |E|+3 \) types. All masses, supplies, partitions, and importance orders have polynomial encoding length.

The masses satisfy \( 3(2/7)+|E|(1/(7|E|))=1 \). Adding a disjoint edge when necessary preserves \( 3 \)-colorability and ensures that \( 1/(7|E|) \) is well-defined.

3. Structural lemmas

Lemma 1

Since the total population mass and the supply of \( q \) are both \( 1 \), every unit of allocated mass must contain \( q \). The nonnegativity of all variables justifies the conclusion that every supported bundle contains \( q \).

Lemma 2

If a supported \( c_i \)-bundle omitted \( p_i \), positive supply of \( p_i \) would provide another supported bundle containing it. Since \( p_i \) is top-ranked for \( c_i \), the latter bundle is strictly preferred. Applying EFX to the common good \( q \) requires the comparison contradicted by the continued presence of \( p_i \) after removing \( q \).

Consequently, every \( c_i \)-bundle contains \( p_i \). Its total contribution is exactly \( \mu_{c_i}=2/7=\rho_{p_i} \), so no bundle of another type can contain \( p_i \).

Lemma 3

Two distinct supported bundles of \( c_i \) share both \( p_i \) and \( q \). Their highest-ranked difference therefore occurs above \( q \). Removing the common, lowest-ranked good \( q \) from the preferred bundle does not alter that decisive difference. This contradicts the EFX requirement associated with removing \( q \). Hence each color type has one supported bundle.

Lemma 4

If \( r \) color bundles contain a fixed vertex item, their supply contribution is \( 2r/7 \).

  • If \( r=0 \), the guards can contribute at most their total mass \( 1/7<2/7 \).
  • If \( r\geq2 \), the color bundles already contribute at least \( 4/7>2/7 \).
  • Therefore \( r=1 \), and that color bundle exhausts the item’s supply.

Together with the exhaustion of every private item and the mandatory presence of \( q \), this correctly implies that every supported guard bundle is exactly \( \{q\} \).

4. Edge-guard gadget

For a guard associated with \( e=\{v,w\} \), its only bundle is \( B=\{q\} \).

  • If a color bundle contains neither endpoint, all its non-\( q \) items are chores, so the guard does not envy it.
  • If it contains exactly one endpoint, it is preferred to \( B \), but removing either guard-good in that color bundle—\( q \) or the endpoint—leaves a bundle weakly below \( B \). There are no guard-chores in \( B \), so no additional removal condition applies.
  • If it contains both endpoints, removing the lower-ranked endpoint leaves the higher-ranked endpoint. The resulting bundle remains strictly preferred to \( B \), directly violating the required EFX comparison.

Thus the gadget characterization is correct.

5. Correctness in both directions

Given a proper \( 3 \)-coloring, the proposed allocation meets every supply and mass equality. Color types do not envy any other supported bundle because their private top item occurs only in their own bundle. Guards have equal bundles among themselves, and properness ensures that the edge-gadget condition holds against every color bundle.

Conversely, structural Lemma 4 assigns every vertex to exactly one color bundle. The guard for each edge excludes both endpoints from occurring in the same color bundle. The resulting map is therefore a proper \( 3 \)-coloring.

Conclusion

The reduction is sound, and the membership argument is sufficient. The prover’s claimed \( \mathrm{NP} \)-completeness result is fully established.
