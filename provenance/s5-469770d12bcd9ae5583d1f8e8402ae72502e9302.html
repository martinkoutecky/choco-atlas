The continuous mirror question, as graded

Given seeker types \(A\), vacancy types \(B\), rational masses \(\mu\) summing to \(1\), an explicit compatibility relation \(E\subseteq A\times B\), a group color \(c(a,b)\) for each compatible pair, and fairness bounds \(0\leq\alpha\leq\beta\leq1\), choose matched masses \(x_{ab}\geq0\). Require \(\sum_{b:(a,b)\in E}x_{ab}\leq\mu_a\) and \(\sum_{a:(a,b)\in E}x_{ab}\leq\mu_b\); for \(z=\sum_{(a,b)\in E}x_{ab}\), require \(\alpha z\leq\sum_{(a,b)\in E:c(a,b)=c}x_{ab}\leq\beta z\) for every group \(c\). What is the maximum feasible \(z\)?

Packaged proof task (what the prover saw — nothing else)

Let \(A,B\) be disjoint nonempty sets of seeker and vacancy types. The society is given by its support: the \(\tau=|A|+|B|\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in A\cup B}\mu_t=1\); \(\tau\) counts listed types, not possible types.
Input also includes an explicit compatibility relation \(E\subseteq A\times B\), an explicit group set \(C=\{1,\ldots,\ell\}\) with \(\ell\ge1\), one color \(c(a,b)\in C\) per compatible pair, and binary rational bounds \(0\le\alpha\le\beta\le1\). Groups may have no compatible pairs.
Choose divisible matched masses \(x_{ab}\in\mathbb R_{\ge0}\), subject to \(\sum_{b:(a,b)\in E}x_{ab}\le\mu_a\) for every \(a\) and \(\sum_{a:(a,b)\in E}x_{ab}\le\mu_b\) for every \(b\).
Writing \(z=\sum_{(a,b)\in E}x_{ab}\), require \(\alpha z\le\sum_{(a,b)\in E:c(a,b)=g}x_{ab}\le\beta z\) for every \(g\in C\). Let \(\mathrm{OPT}\) be the maximum feasible \(z\), with value zero when no positive allocation exists.
For a fixed \(\gamma>1\), a \(\gamma\)-approximation returns a feasible allocation with \(z\ge\mathrm{OPT}/\gamma\), without violating fairness. Put \(m=|E|\) and let \(L\) be the total binary input length.

For each fixed \(\gamma>1\), does this continuous problem admit a \(\gamma\)-approximation in time polynomial in \(m,\tau,\ell,L\), or does ETH rule out every \(2^{o(\ell)}(m+\tau+L)^{O(1)}\)-time \(\gamma\)-approximation, even when the compatibility graph is a path?

For discrete matchings, ETH rules out every \(2^{o(\ell)}n^{O(1)}\)-time constant-factor approximation preserving fairness, even on paths, where \(n\) counts vertices ([source](https://arxiv.org/html/2301.03862)).
A fractional formulation with unit vertex capacities and these global color bounds is used in subsequent work; it does not address arbitrary rational type masses ([source](https://ojs.aaai.org/index.php/AAAI/article/download/33805/35960)).

  • Interpreted the normalization as total mass one across both sides together, without requiring equal side masses.
  • Made the group set explicit, allowing groups without compatible pairs, as the discrete coloring definition permits.
  • Specified binary rational fairness bounds, real divisible allocations, total input bit length L, and m as the number of compatible pairs.
  • Allowed the zero allocation as the fallback when no positive fair allocation exists; a finite approximation factor forces positive output whenever the optimum is positive.

Result

The continuous problem is exactly solvable in time polynomial in \(m,\tau,\ell,L\). Consequently, for every fixed \(\gamma>1\), it admits a \(\gamma\)-approximation preserving fairness exactly, including when the compatibility graph is a path.

The argument applies to arbitrary rational type masses as given in the task.

1. An exact linear programming formulation

For each group \(g\in C\), define \(E_g=\{(a,b)\in E:c(a,b)=g\}\). Introduce one variable \(x_{ab}\) for each compatible pair and one variable \(z\). Consider the following linear program:

  • Maximize \(z\).
  • Require \(x_{ab}\ge 0\) for every \((a,b)\in E\), and \(z\ge 0\).
  • Require \(z-\sum_{(a,b)\in E}x_{ab}=0\).
  • For each \(a\in A\), require \(\sum_{b:(a,b)\in E}x_{ab}\le\mu_a\).
  • For each \(b\in B\), require \(\sum_{a:(a,b)\in E}x_{ab}\le\mu_b\).
  • For each \(g\in C\), require both \(\alpha z-\sum_{(a,b)\in E_g}x_{ab}\le 0\) and \(\sum_{(a,b)\in E_g}x_{ab}-\beta z\le 0\).

All these constraints are linear: \(\alpha\) and \(\beta\) are input constants, so multiplying either by \(z\) does not introduce a product of variables.

Every feasible allocation in the task extends to a feasible point of this program by setting \(z=\sum_{(a,b)\in E}x_{ab}\). Conversely, every feasible point gives an allocation satisfying precisely the capacity and fairness constraints in the task. The objectives coincide. Thus the linear program’s optimal value is exactly \(\mathrm{OPT}\).

This equivalence includes empty groups. If \(E_g=\varnothing\), its lower fairness constraint is \(\alpha z\le 0\). In particular, when \(\alpha>0\), such a group correctly forces \(z=0\).

2. Feasibility, boundedness, and attainment

The zero allocation with \(z=0\) satisfies every constraint. Hence the program is always feasible, even when \(E=\varnothing\).

For any feasible point, summing the seeker constraints gives

\(z=\sum_{a\in A}\sum_{b:(a,b)\in E}x_{ab}\le\sum_{a\in A}\mu_a.\)

Summing the vacancy constraints similarly gives \(z\le\sum_{b\in B}\mu_b\). Since the two total masses sum to one,

\(0\le z\le\min\{\sum_{a\in A}\mu_a,\sum_{b\in B}\mu_b\}\le\tfrac12.\)

Moreover, nonnegativity and the capacity constraints imply \(0\le x_{ab}\le\min\{\mu_a,\mu_b\}\) for every compatible pair. Therefore the feasible set is closed and bounded in a finite-dimensional space. It is nonempty, so it is compact, and the continuous objective \(z\) attains its maximum.

Thus, when no positive allocation exists, the program returns optimum zero exactly as required.

3. Polynomial bit complexity and exact fairness

We use the standard polynomial-time theorem for rational linear programming: a linear program with rational coefficients can be solved in time polynomial in its total binary encoding length; when feasible with finite optimum, an exact rational optimal solution can be returned.

Here its hypotheses hold:

  • There are \(m+1\) variables.
  • Apart from nonnegativity, there are \(\tau+2\ell\) inequalities and one equality. The equality can be replaced by two inequalities.
  • All coefficients and right-hand sides belong to \(\{0,1,-1,\alpha,-\beta\}\) or are input masses. Their binary lengths are bounded by \(O(L+1)\).
  • Feasibility and boundedness were established above.

Even a dense encoding of this program therefore has length at most

\(O\bigl((m+\tau+\ell+1)(m+1)(L+1)\bigr),\)

which is polynomial in the requested parameters. Constructing it also takes polynomial time. In particular, no expansion of a type into individual agents is needed.

For completeness, an exact optimum has a polynomial-length rational representation. A nonempty bounded polyhedron has an optimal vertex. At a vertex, \(d=m+1\) linearly independent tight constraints determine the coordinates. Clearing denominators in these constraints produces an integer system whose entries have \(O(L+1)\) bits. By Cramer’s rule and Hadamard’s determinant bound, the coordinate numerators and denominators have \(O(d(L+\log(d+1)))\) bits.

The algorithm therefore returns rational coordinates satisfying the original inequalities exactly. This matters when, for example, \(\alpha=\beta\): numerical feasibility within a tolerance would not establish the required fairness guarantee.

If the returned allocation has total mass \(z^\star\), then \(z^\star=\mathrm{OPT}\). Since \(\mathrm{OPT}\ge 0\) and \(\gamma>1\), it follows that \(z^\star\ge\mathrm{OPT}/\gamma\).

4. Why the discrete hardness does not transfer

The cited discrete hardness theorem concerns selecting actual matching edges. It establishes the stated ETH obstruction even on paths. [Bandyapadhyay et al., Theorem 5](https://arxiv.org/html/2301.03862)

Divisible allocations have a different feasible set. For a concrete example, take the path \(a_1-b-a_2\), with its two edges colored differently. Set

\(\mu_{a_1}=\tfrac14,\quad\mu_b=\tfrac14,\quad\mu_{a_2}=\tfrac12,\quad\ell=2,\quad\alpha=\beta=\tfrac12.\)

The allocation \(x_{a_1b}=x_{a_2b}=\tfrac18\) is feasible and has \(z=\tfrac14\). Each color receives exactly half the total. It is optimal because the capacity of \(b\) bounds every allocation by \(\tfrac14\).

In contrast, every nonempty discrete matching on this graph contains exactly one edge. Its color proportions are one and zero, so no nonempty discrete matching satisfies these fairness bounds.

The subsequent paper’s LP-FAIR uses the same linear color constraints with unit vertex capacities. Our formulation directly replaces those capacity right-hand sides by the input masses; this remains a rational linear program of polynomial encoding length. [Duppala et al., Section 3, LP-FAIR](https://ojs.aaai.org/index.php/AAAI/article/download/33805/35960)

Finally, a polynomial running time in \(m,\tau,\ell,L\) is of the form \(2^{o(\ell)}(m+\tau+L)^{O(1)}\), since a polynomial factor in \(\ell\) is \(2^{O(\log(\ell+1))}\). The proposed ETH exclusion therefore does not hold for this continuous problem.
