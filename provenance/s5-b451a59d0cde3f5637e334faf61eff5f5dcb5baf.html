The continuous mirror question, as graded

Given a finite set \(X\) of alternatives, a distribution \(\mu\) over \(\tau\) complete rankings of \(X\), an edge budget \(k\), and a threshold \(q\), does there exist an undirected graph \(H\) on \(X\) with at most \(k\) edges such that \(\sum_{\sigma:\,\sigma\text{ is a DFS-ordering of }H}\mu_\sigma\ge q\)?

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a nonempty set of \(m\) alternatives. A society is given by its support: a list of \(\tau\) distinct strict complete rankings \(\sigma\) of \(X\), each with positive binary-rational mass \(\mu_\sigma\), with \(\sum_\sigma\mu_\sigma=1\). Here \(\tau\) is the support size, not the number of possible rankings.
A feasible support is a simple connected undirected graph \(H\) on \(X\). A ranking is a DFS-ordering of \(H\) if some standard DFS traversal produces it as the order of first visits; the starting vertex and all neighbor choices are unrestricted and may differ between rankings.
The input also contains a nonnegative binary integer \(k\) and a binary rational \(q\in[0,1]\). Decide whether there exists such an \(H\) with \(|E(H)|\leq k\) and \(\sum_{\sigma:\,\sigma\text{ is a DFS-ordering of }H}\mu_\sigma\geq q\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\), and \(k\).

Is this rational-mass DFS-support decision problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For a finite set of rankings, requiring every ranking to be a DFS-ordering of a support with at most \(k\) edges is \(\mathrm{NP}\)-hard; requiring a tree support is polynomial-time solvable. [Source](https://arxiv.org/html/2605.04701v2)
No separate result for the rational-mass threshold variant was located in the literature search.

Modeling choices made when packaging the task

  • Required the graph support to be connected: allowing disconnected DFS forests makes the empty graph admit every ranking, contradicting the intended discrete hardness result. The latest available version still leaves this restriction implicit.
  • Made the graph simple and undirected, with no loops or parallel edges.
  • Specified a nonempty alternative set and distinct strict complete rankings with positive rational masses summing to one.
  • Specified a nonnegative binary-integer edge budget, a binary-rational threshold in the closed unit interval, and total input bit length L.
  • Specified that DFS records first visits, with independently chosen starting vertices and unrestricted neighbor choices for each ranking.

Result

The rational-mass DFS-support decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when every mass is dyadic and \(0<q<1\), with \(q\) supplied as part of the input.

The endpoint \(q=1\) immediately encodes the requirement that every ranking be supported. The proof below also establishes hardness away from that endpoint.

1. The hardness premise and connectedness

We use the given hardness result: deciding whether a finite set of rankings has a DFS-support with at most \(k\) edges is \(\mathrm{NP}\)-hard.

The connectedness requirement is compatible with this result. In the Vertex Cover reduction in [Theorem 3.5 of the cited paper](https://arxiv.org/html/2605.04701v2), a yes-witness consists of a clique, one pendant attached to each clique vertex, and an additional vertex adjacent to the vertices of a vertex cover. For a nonempty cubic source graph, every vertex cover is nonempty, so this witness is connected. Conversely, a connected support is also a support allowed by that theorem. Thus the same reduction establishes hardness with connected supports.

We therefore reduce from the following problem: given a nonempty set of distinct rankings \(\Pi=\{\sigma_1,\ldots,\sigma_\tau\}\) on \(X\) and an edge budget \(k\), determine whether a simple connected graph on \(X\), with at most \(k\) edges, admits every ranking in \(\Pi\).

2. Reduction to positive rational masses

Retain \(X\), the rankings, and \(k\). Set \(s=\lceil\log_2\tau\rceil\), and assign

\(\displaystyle \mu_{\sigma_i}=2^{-s}\quad\text{for }1\leq i<\tau,\qquad \mu_{\sigma_\tau}=1-(\tau-1)2^{-s}.\)

Since \(\tau\leq 2^s\), the last mass is at least \(2^{-s}\). Consequently, all masses are positive dyadic rationals, their sum is \(1\), and their minimum is at least \(2^{-s}\).

Choose

\(\displaystyle q=1-2^{-(s+1)}.\)

This satisfies \(0<q<1\), including when \(\tau=1\).

For any feasible graph \(H\):

  • If every listed ranking is a DFS-ordering of \(H\), its supported mass is \(1\), which exceeds \(q\).
  • If at least one listed ranking is unsupported, its supported mass is at most \(1-2^{-s}<1-2^{-(s+1)}=q\).

Therefore,

\(\displaystyle \sum_{\sigma:\,\sigma\text{ is a DFS-ordering of }H}\mu_\sigma\geq q \quad\Longleftrightarrow\quad \text{every ranking in }\Pi\text{ is a DFS-ordering of }H.\)

The graph constraints are unchanged, so this is a many-one reduction.

Each newly introduced rational requires \(O(\log(\tau+1))\) bits. If the source input has bit length \(L_0\), the reduction takes \(O(L_0+\tau\log(\tau+1))\) bit operations and produces an instance of that size. This proves \(\mathrm{NP}\)-hardness.

3. Recognizing a DFS-ordering of a fixed graph

Let \(H\) be connected, with \(e\) edges, and let \(\sigma=(v_1,\ldots,v_m)\).

For each vertex, order its adjacency list by increasing position in \(\sigma\). Run standard DFS from \(v_1\), inspecting neighbors in these orders, and accept precisely when its first-visit order is \(\sigma\).

Correctness. Acceptance directly exhibits a DFS traversal producing \(\sigma\).

Conversely, suppose some DFS traversal produces \(\sigma\). Compare it with the prescribed traversal, inductively over first visits. Initially their roots and recursion stacks agree. After any common prefix, both traversals must backtrack through exactly those stack vertices that have no unvisited neighbors. At the resulting top vertex, the successful traversal chooses the next vertex of \(\sigma\). That vertex has the smallest position in \(\sigma\) among *all* unvisited vertices, hence also among the top vertex’s unvisited neighbors. The prescribed traversal therefore chooses the same vertex. Their stacks and visited sets agree again, completing the induction.

The ordered adjacency lists can be built in \(O(m+e)\) operations: process vertices in the order \(\sigma\), appending each processed vertex to the lists of its neighbors. DFS also takes \(O(m+e)\) operations. Thus recognition takes \(O(m+e)\) graph operations per ranking.

4. Exact verification and membership in \(\mathrm{NP}\)

A certificate is the adjacency matrix of \(H\), containing \(O(m^2)\) bits. Check simplicity, connectedness, and the edge budget, then apply the recognition algorithm to all \(\tau\) rankings.

The mass comparison uses exact integer arithmetic. Write the input masses as \(\mu_{\sigma_i}=a_i/b_i\) and the threshold as \(q=c/d\). Define

\(\displaystyle D=d\prod_{i=1}^{\tau}b_i,\qquad A_i=a_i(D/b_i),\qquad Q=c(D/d).\)

The bit length of \(D\) is \(O(L)\), because the denominator encodings are part of the input. Moreover, \(0<A_i\leq D\), \(0\leq Q\leq D\), and every supported subtotal is at most \(D\). Thus all relevant integers have \(O(L)\) bits.

Using schoolbook arithmetic, these scaled integers can be precomputed in \(O((\tau+1)L^2)\) bit operations. Given the recognition results, summing the accepted \(A_i\) and comparing their sum with \(Q\) takes \(O(\tau L)\) bit operations.

Put \(K=\min\{k,\binom m2\}\). A conservative total verifier bound is

\(\displaystyle O\!\left( [m^2+\tau(m+K)]\log(m+1)+(\tau+1)L^2 \right).\)

Here the logarithmic factor accounts for graph indices in a bit-operation model. This bound is polynomial in the explicit input length, and the certificate has polynomial size. Hence the problem belongs to \(\mathrm{NP}\).

Together with Section 2, this proves \(\mathrm{NP}\)-completeness.

5. An explicit deterministic running-time bound

For completeness, exhaustive search supplies an exact algorithm with explicit dependence on \(k\).

If \(k<m-1\), reject, because every connected graph on \(m\) vertices has at least \(m-1\) edges. Otherwise define

\(\displaystyle N=\binom m2,\qquad K=\min\{k,N\},\qquad B(m,k)=\sum_{j=m-1}^{K}\binom Nj.\)

Enumerate these \(B(m,k)\) edge sets, discard disconnected graphs, and verify each remaining graph. Precompute the scaled masses once. The resulting bit-operation bound is

\(\displaystyle O\!\left( (\tau+1)L^2+ B(m,k)\left( [m^2+\tau(m+K)]\log(m+1)+\tau L \right) \right).\)

Two easy cases avoid enumeration: when \(q=0\), the answer is yes exactly when \(k\geq m-1\); when \(k\geq N\), the complete graph supports every ranking, so the answer is yes.

The classification is therefore complete: a polynomial-time algorithm for the general problem would imply \(\mathrm{P}=\mathrm{NP}\).
