The continuous mirror question, as graded

Given finite worker-type and position-type sets \(A,B\), rational masses \(\mu\in\mathbb{Q}_{\ge 0}^{A}\), \(\nu\in\mathbb{Q}_{\ge 0}^{B}\), and rational pair surpluses \(w_{ab}\ge 0\), find an exact finite description of a piecewise-linear path \((\alpha(s),\beta(s),u(s),v(s))\), \(s\in[0,1]\). Require \(\alpha(0)=\beta(0)=0\), \(\alpha(1)=\mu\), \(\beta(1)=\nu\), nondecreasing masses and per-type payoffs, and a core allocation at every \(s>0\): \(u_a(s),v_b(s)\ge 0\), \(u_a(s)+v_b(s)\ge w_{ab}\), and \(\sum_a\alpha_a(s)u_a(s)+\sum_b\beta_b(s)v_b(s)=W(\alpha(s),\beta(s))\), where \(W(\alpha,\beta)=\max\{\sum_{a,b}w_{ab}z_{ab}: z\ge 0,\ \sum_b z_{ab}\le\alpha_a,\ \sum_a z_{ab}\le\beta_b\}\).

Packaged proof task (what the prover saw — nothing else)

Given disjoint finite worker-type and position-type supports \(A,B\), a society is specified by listing its \(\tau=|A|+|B|\) positive-mass types and their binary rational masses \(\mu_a,\nu_b>0\). Here \(\tau\) is the support size, not the number of possible types; let \(m=|A||B|\) and let \(L\) be the total input bit length. Mass totals need neither equal each other nor sum to one. Pair surpluses \(w_{ab}\) are nonnegative binary rationals.
For nonnegative mass vectors, define \(W(\alpha,\beta)=\max\{\sum_{a,b}w_{ab}z_{ab}:z\ge0,\ \sum_bz_{ab}\le\alpha_a,\ \sum_az_{ab}\le\beta_b\}\); unmatched mass is allowed and contributes zero surplus.
The construction problem is to find a continuous piecewise-linear path \((\alpha,\beta,u,v):[0,1]\to\mathbb R_{\ge0}^{2\tau}\), described by finitely many rational breakpoints and rational vertex coordinates, or determine that none exists.
Require \(\alpha(0)=\beta(0)=0\), \(\alpha(1)=\mu\), \(\beta(1)=\nu\), and every mass and per-unit payoff coordinate to be nondecreasing. Initial payoffs are unrestricted apart from nonnegativity; several mass coordinates may increase simultaneously.
At every \(s\in(0,1]\), require \(u_a(s)+v_b(s)\ge w_{ab}\) for every \((a,b)\in A\times B\), including types currently having zero mass, and \(\sum_a\alpha_a(s)u_a(s)+\sum_b\beta_b(s)v_b(s)=W(\alpha(s),\beta(s))\).

Is this exact path-construction problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite assignment games, some order adding players one at a time always admits core allocations with nondecreasing incumbent payoffs ([Abe–Liu](https://link.springer.com/article/10.1007/s00355-019-01197-3)); this is an existence result, not a stated complexity classification.
No published result settling this exact mass-path construction problem was located.

Modeling choices made when packaging the task

  • Zero terminal-mass types are omitted so that the input lists only positive-mass support types; either support may be empty.
  • Masses are quantities rather than normalized probabilities, with no equality imposed between the two side totals, matching the discrete allowance of unequal populations.
  • An exact finite path description means rational breakpoints and rational vertex coordinates, with affine interpolation and continuity.
  • Initial per-unit payoffs need not be zero: the specified zero initial condition applies only to masses.
  • The graded question's inequalities apply to all terminal-support pairs even before their masses become positive, and payoff monotonicity applies on the entire parameter interval.
  • The construction problem permits reporting nonexistence, since continuous-path existence is not supplied as a promise.
  • The size parameter m denotes the number of supplied pair-surplus entries, and L denotes total input bit length.

Result

The exact problem stated is polynomial-time solvable. Every instance admits a path with only the two breakpoints \(0\) and \(1\).

The key is that initial payoffs are unrestricted and all mass coordinates may increase simultaneously. One optimal payoff vector for the final society remains optimal throughout proportional growth of its masses.

1. Compute optimal final payoffs

The linear program defining \(W(\mu,\nu)\) has dual
\[ \min\left\{\sum_{a\in A}\mu_a u_a+\sum_{b\in B}\nu_b v_b: u_a,v_b\ge 0,\quad u_a+v_b\ge w_{ab}\ \text{for every }(a,b)\right\}. \]

The primal is feasible: take \(z=0\). Its feasible set is compact, since each variable satisfies \(0\le z_{ab}\le\min\{\mu_a,\nu_b\}\). Thus its optimum is finite and attained.

The dual is feasible as well. Set \(M=\max_{a,b}w_{ab}\), with \(M=0\) if there are no pairs, and take \(u_a=M\), \(v_b=0\). Linear-programming strong duality therefore gives an optimal dual vector \((u^*,v^*)\) satisfying
\[ \sum_a\mu_a u_a^*+\sum_b\nu_b v_b^*=W(\mu,\nu). \]

These payoffs can be computed exactly in polynomial time. To make boundedness explicit, add \(u_a\le M\) and \(v_b\le M\). These restrictions preserve the optimum: clipping any feasible coordinate to \(M\) preserves every pair inequality, because a clipped coordinate alone is at least \(w_{ab}\); clipping cannot increase the nonnegative objective.

The resulting feasible rational linear program is bounded, has \(\tau\) variables and \(m+2\tau\) inequalities, and has encoding length polynomial in \(m,\tau,L\). The standard polynomial-time theorem for rational linear programming returns an exact rational optimum of polynomial encoding length. All its hypotheses are satisfied here.

2. Prove homogeneity of surplus

For every \(s>0\),
\[ W(s\mu,s\nu)=sW(\mu,\nu). \]

Indeed, multiplying a feasible assignment for \((\mu,\nu)\) by \(s\) produces a feasible assignment for \((s\mu,s\nu)\), with objective multiplied by \(s\). Hence \(W(s\mu,s\nu)\ge sW(\mu,\nu)\).

Conversely, dividing any feasible assignment for \((s\mu,s\nu)\) by \(s\) produces a feasible assignment for \((\mu,\nu)\). This proves the reverse inequality. At \(s=0\), all assignment variables must vanish, so \(W(0,0)=0\).

3. Construct and verify the path

Define, for \(s\in[0,1]\),
\[ \alpha_a(s)=s\mu_a,\qquad \beta_b(s)=s\nu_b,\qquad u_a(s)=u_a^*,\qquad v_b(s)=v_b^*. \]

This is a continuous affine path. Its rational vertex coordinates are
\[ (0,0,u^*,v^*)\quad\text{and}\quad(\mu,\nu,u^*,v^*). \]

Every required property follows:

  • Endpoints: the mass vectors start at zero and end at \((\mu,\nu)\).
  • Nonnegativity and monotonicity: each mass coordinate increases linearly, and every payoff coordinate is constant and nonnegative.
  • All pair inequalities: \(u_a(s)+v_b(s)=u_a^*+v_b^*\ge w_{ab}\), including inequalities involving zero-mass types.
  • Surplus equality: for every \(s\in(0,1]\),

\[ \sum_a\alpha_a(s)u_a(s)+\sum_b\beta_b(s)v_b(s) =sW(\mu,\nu) =W(\alpha(s),\beta(s)). \]

Thus the path satisfies the exact specification.

4. Complexity conclusion

The algorithm solves one rational linear program and outputs two rational vertices. Both its running time and output length are polynomial in \(m,\tau,L\). It never needs to report nonexistence.

The construction relies on the permissions expressly given in the task; no player-by-player ordering theorem or additional existence assumption is needed.
