The continuous mirror question, as graded

Given supported complete utility types \(t\) with masses \(\mu_t\), item classes \(j\in[K]\), integer per-household bundle caps \(b_j\), rational per-capita supplies \(q_j\le b_j\), and additive values \(v_{tj}\) satisfying \(\sum_j b_jv_{tj}=c\) for every type, does there exist a mass assignment \(x_{t,y}\ge0\) over integral bundles \(y\in\prod_j\{0,\ldots,b_j\}\) such that \(\sum_y x_{t,y}=\mu_t\), \(\sum_{t,y}x_{t,y}y_j=q_j\), and every ordered pair of positive-mass outcomes \((t,y),(s,z)\) satisfies the paper’s JF1 test? Writing \(U_t(y)=\sum_jv_{tj}y_j\), whenever \(U_t(y)<U_s(z)\), require either some \(j\) with \(y_j>0\), \(v_{tj}<0\), and \(U_t(y)\ge U_s(z+e_j)\), or some \(j\) with \(z_j>0\), \(v_{sj}>0\), and \(U_t(y)\ge U_s(z-e_j)\), where \(e_j\) is one unit of class \(j\) and the comparison uses the additive utility of the hypothetically changed bundle.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) complete utility types with positive masses \(\mu_t\) encoded as binary rationals, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; each type specifies its value for every item class.
There are \(K\ge1\) item classes, binary-encoded integer household caps \(b_j\ge1\), and binary-rational per-capita supplies \(0\le q_j\le b_j\), with \(\sum_jq_j>0\). Write \(m=\sum_jb_j\).
Values \(v_{tj}\in\mathbb Q\) are binary encoded and may be negative, zero, or positive; normalization requires \(\sum_jb_jv_{tj}=c\) for every type, with common \(c\in\mathbb Q\) of unrestricted sign.
Let \(Y=\prod_{j=1}^K\{0,\ldots,b_j\}\) and \(U_t(y)=\sum_jv_{tj}y_j\). An assignment consists of real masses \(x_{t,y}\ge0\) satisfying \(\sum_{y\in Y}x_{t,y}=\mu_t\) and \(\sum_{t,y\in Y}x_{t,y}y_j=q_j\) for every class.
The assignment is JF1 if every ordered pair \((t,y),(s,z)\) with \(x_{t,y}>0\) and \(x_{s,z}>0\), including pairs of outcomes of the same type, satisfies the following: whenever \(U_t(y)<U_s(z)\), either some \(j\) has \(y_j>0\), \(v_{tj}<0\), and \(U_t(y)\ge U_s(z+e_j)\), or some \(j\) has \(z_j>0\), \(v_{sj}>0\), and \(U_t(y)\ge U_s(z-e_j)\).
Here \(e_j\) is the unit vector for class \(j\); hypothetical comparisons use the same additive formula even beyond household caps, and retain the jealous household's original utility. Equal utilities require no modification.

Is deciding whether such a JF1 mass assignment exists in \(\mathrm P\), or is it NP-hard? State running times in \(m,\tau,L,K\), where \(L\) is the total binary input length.

For finitely many agents and indivisible items, existence of a complete JF1 allocation is NP-hard even with normalized additive utilities allowing mixed items. [Verified source](https://arxiv.org/pdf/2004.11469v3).

Result

The decision problem is \(\mathrm{NP}\text{-complete}\), already with \(\tau=2\), unit caps \(b_j=1\), integer valuations, and positive normalization \(c=1\).

The reduction below applies directly to real mass assignments.

1. Reduction from \(\mathrm{PARTITION}\)

We use the standard \(\mathrm{NP}\)-complete problem \(\mathrm{PARTITION}\): given binary-encoded positive integers \(a_1,\ldots,a_n\), decide whether some subset has half their total sum. See [Karp’s original paper](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9). We may restrict to even total sum: doubling every input integer preserves the answer and ensures this restriction.

Write \(\sum_{i=1}^n a_i=2B\), where \(B\ge1\). Construct two types, \(A\) and \(R\), with masses \(\mu_A=\mu_R=1/2\).

There are \(n+2\) classes: ordinary classes indexed by \(i\), a compulsory class \(h\), and an unavailable class \(d\). Every cap is one.

| Class | Value for \(A\) | Value for \(R\) | Supply |
|---|---:|---:|---:|
| \(i\in\{1,\ldots,n\}\) | \(a_i\) | \(0\) | \(1/4\) |
| \(h\) | \(-B\) | \(1\) | \(1\) |
| \(d\) | \(1-B\) | \(0\) | \(0\) |

Both types satisfy the required normalization:

\(\sum_j b_jv_{Aj}=2B-B+(1-B)=1\), and \(\sum_j b_jv_{Rj}=1\).

Thus \(c=1\). The supplies satisfy every input promise, including strictly positive total supply. The construction has \(\tau=2\) and \(m=K=n+2\), and its binary length is polynomial in the source input length.

2. Necessity: every feasible JF1 assignment yields a partition

Suppose the constructed instance has a JF1 assignment.

Forced coordinates

Every supported outcome contains class \(h\). Indeed, total household mass is one, \(y_h\in\{0,1\}\), and its supply is one. Hence

\(\sum_{t,y}x_{t,y}(1-y_h)=0\).

Every summand is nonnegative, so \(x_{t,y}>0\) implies \(y_h=1\).

Likewise, supply zero for class \(d\) implies \(y_d=0\) in every supported outcome.

Consequently, every supported outcome of type \(R\) has utility \(1\).

JF1 forces nonnegative utility for type \(A\)

Consider a supported type-\(A\) outcome \(y\) with \(U_A(y)<0\). Since \(\mu_R>0\), there exists a supported type-\(R\) outcome \(z\), whose utility is \(U_R(z)=1\).

Neither JF1 modification can resolve this comparison:

  • The only received class with negative value for \(A\) is \(h\). Transferring it hypothetically to \(R\) gives \(U_R(z+e_h)=2\), so the required inequality \(U_A(y)\ge2\) fails. This calculation uses the stipulated additive comparison beyond caps.
  • The only received class with positive value for \(R\) is \(h\). Removing it gives \(U_R(z-e_h)=0\), so the required inequality \(U_A(y)\ge0\) also fails.

This contradicts JF1. Therefore every supported type-\(A\) outcome has nonnegative utility.

The supplies force all those utilities to equal zero

For each ordinary class, let

\(p_i=\sum_y x_{A,y}y_i\)

be its total consumption by type \(A\). Type \(R\)'s consumption is nonnegative, so \(p_i\le q_i=1/4\).

Using the forced coordinates and \(\mu_A=1/2\), the total utility carried by type-\(A\) mass is

\(\sum_y x_{A,y}U_A(y)=\sum_{i=1}^n a_ip_i-B/2\le\frac14\sum_{i=1}^n a_i-B/2=0\).

Every supported summand on the left is nonnegative. Thus every supported type-\(A\) outcome has utility exactly zero.

At least one such outcome exists because \(\mu_A>0\). For any such outcome, define \(S=\{i:y_i=1\}\). Its zero utility gives

\(0=U_A(y)=\sum_{i\in S}a_i-B\).

Hence \(S\) solves the source \(\mathrm{PARTITION}\) instance.

3. Sufficiency: a partition gives a JF1 mass assignment

Conversely, suppose \(S\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in S}a_i=B\). Its complement also has sum \(B\).

Assign:

  • mass \(1/4\) of type \(A\) the ordinary classes in \(S\), together with \(h\);
  • mass \(1/4\) of type \(A\) the ordinary classes outside \(S\), together with \(h\);
  • all mass \(1/2\) of type \(R\) class \(h\) alone.

No outcome receives class \(d\).

Each ordinary class appears in exactly one of the two type-\(A\) outcomes, so its consumption is \(1/4\). Every household receives \(h\), giving consumption one. All type masses and supplies are therefore correct.

Both type-\(A\) outcomes have utility zero; the type-\(R\) outcome has utility one. The only ordered pairs with strict utility inequality have a type-\(A\) outcome as the lower-utility household and the type-\(R\) outcome as the higher-utility household. Removing \(h\) from the latter reduces its utility to zero, satisfying the second JF1 alternative.

All same-type outcome pairs have equal utilities. Thus every required ordered pair satisfies JF1.

The constructed instance is feasible exactly when the source instance has a partition. This proves \(\mathrm{NP}\)-hardness.

4. Membership in \(\mathrm{NP}\), despite real masses

We prove that every feasible instance has a polynomial-size rational certificate.

Let \(d=\tau+K\). Associate with each outcome \((t,y)\) the integer column

\(\alpha_{t,y}=(e_t,y)\in\mathbb Z^d\),

where \(e_t\) is the type indicator vector. The assignment equations become

\(\sum_{t,y}x_{t,y}\alpha_{t,y}=\beta\), where \(\beta=(\mu_1,\ldots,\mu_\tau,q_1,\ldots,q_K)\).

A feasible JF1 support can be reduced to at most \(d\) outcomes

Start with any feasible JF1 assignment. If its positive-support columns are linearly dependent, choose a nonzero dependence vector \(h\) satisfying

\(\sum_{t,y}h_{t,y}\alpha_{t,y}=0\).

Summing the first \(\tau\) coordinates gives \(\sum_{t,y}h_{t,y}=0\). Therefore \(h\) has both positive and negative entries.

Set

\(\lambda=\min_{h_{t,y}>0}x_{t,y}/h_{t,y}\), and \(x'_{t,y}=x_{t,y}-\lambda h_{t,y}\)

on the current support. All new masses are nonnegative, the assignment equations are preserved, and at least one previously positive mass becomes zero.

JF1 is preserved because the new positive support is a subset of the previous support. Repeating this finite elimination process leaves linearly independent columns, hence at most \(d\) outcomes.

The remaining masses have polynomial binary length

Suppose \(r\le d\) independent columns remain. Select \(r\) rows yielding a nonsingular integer matrix \(C\). The masses are the unique solution of this subsystem, so they are rational.

Let \(D\) be the product of the denominators of the selected entries of \(\beta\). Its binary length is \(O(L)\). Entries of \(C\) have absolute value at most \(m\), and entries of \(D\beta\) have absolute value at most \(Dm\).

Cramer’s rule therefore expresses every mass using numerator and denominator bounded in absolute value by \(D\,r!\,m^r\). Each mass consequently needs

\(O\!\left(L+r\log(r(m+1))\right)\)

bits. This is polynomial in \(L\), since \(r\le\tau+K=O(L)\) and \(\log(m+1)=O(L)\).

A certificate lists these outcomes and rational masses. A verifier checks the coordinates, masses, assignment equations, and every ordered pair of positive outcomes against the exact JF1 definition. With at most \(d\) outcomes, the pair checks require \(O(d^2K)\) rational arithmetic operations, on numbers of polynomial binary length.

Thus the problem belongs to \(\mathrm{NP}\). Together with the reduction, it is \(\mathrm{NP}\text{-complete}\).

5. Running times in the requested parameters

The reduction is polynomial in its source binary input length and produces \(\tau=2\) and \(m=K=n+2\). Consequently, an algorithm polynomial in \(m,\tau,K,L\) would imply \(\mathrm P=\mathrm{NP}\).

An explicit general deterministic upper bound follows from the sparse-support proof. Define

\(N=|Y|=\prod_{j=1}^K(b_j+1)\).

Enumerate all supports of at most \(\tau+K\) among the \(\tau N\) type-outcome columns. For each support, check independence and pairwise JF1, solve its assignment equations by exact Gaussian elimination, and accept if the solution satisfies all equations with positive masses.

The sparse-support proof establishes completeness of this search. Each candidate takes polynomial time in \(L\), giving total time

\(O\!\left((\tau N)^{\tau+K}\operatorname{poly}(L)\right)\).

For bounds expressed directly through \(m\) and \(K\),

\(N\le2^m\), and \(N\le(1+m/K)^K\).

The first follows from \(b_j+1\le2^{b_j}\); the second follows from the arithmetic–geometric mean inequality. Hence, for example, a valid running-time bound is

\(O\!\left(\tau^{\tau+K}(1+m/K)^{K(\tau+K)}\operatorname{poly}(L)\right)\).
