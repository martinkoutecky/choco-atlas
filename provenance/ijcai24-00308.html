Complexity Classification

Theorem

The continuous individual-rationality feasibility problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard even under all of the following restrictions:

  • \(G\) consists of three isolated vertices;
  • every capacity equals \(1\);
  • every type has the same mass;
  • \(a_{tt'}\in\{0,-1\}\);
  • the distance-factor table is fixed independently of the input.

Thus fractional splitting of type mass does not make the problem polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).

Membership in \(\mathrm{NP}\)

For an assignment \(x\), define the utility expression

\[ U_{t,v}(x)=\sum_{w\in V,\ t'\in T}a_{tt'}K_{vw}x_{t',w}. \]

For a set \(S\subseteq T\times V\), consider the following rational linear system:

\[ x_{t,v}\geq 0, \qquad \sum_{v\in V}x_{t,v}=\mu_t, \qquad \sum_{t\in T}x_{t,v}\leq u_v, \]

together with

\[ x_{t,v}=0\quad\text{for every }(t,v)\notin S \]

and

\[ U_{t,v}(x)\geq 0\quad\text{for every }(t,v)\in S. \]

We claim that the original instance is feasible if and only if this linear system is feasible for at least one \(S\).

Suppose first that \(x\) is feasible for the original problem. Let

\[ S=\{(t,v):x_{t,v}>0\}. \]

Every pair outside \(S\) has zero mass, and individual rationality gives \(U_{t,v}(x)\geq0\) for every pair in \(S\). Hence \(x\) satisfies the linear system for \(S\).

Conversely, suppose \(x\) satisfies the linear system for some \(S\). If \(x_{t,v}>0\), then \(x_{t,v}=0\) outside \(S\) implies \((t,v)\in S\). Consequently \(U_{t,v}(x)\geq0\). Thus \(x\) satisfies the original support-dependent individual-rationality condition.

A certificate can therefore consist solely of the incidence vector of \(S\), which has length \(|T||V|\). After guessing \(S\), feasibility of the associated rational linear system can be decided in polynomial time by rational linear programming. The coefficients \(K_{vw}\) can be computed in polynomial time from all-pairs graph distances and the rational table \(f\). Therefore the problem belongs to \(\mathrm{NP}\).

Reduction from \(3\)-Colorability

Let \(H=(Q,F)\) be a nonempty simple graph with \(n=|Q|\). Deciding whether \(H\) is \(3\)-colorable is \(\mathrm{NP}\)-complete.

Construct an instance of the continuous problem as follows.

Host graph and capacities

Let the host graph \(G\) have three isolated vertices

\[ V=\{c_1,c_2,c_3\}. \]

Set

\[ u_{c_1}=u_{c_2}=u_{c_3}=1. \]

Use the fixed strictly decreasing rational table

\[ f(1)=1,\qquad f(2)=\frac12,\qquad f(\infty)=0. \]

The value \(f(2)\) is unused but ensures strict decrease on the finite table. Since the vertices of \(G\) are pairwise disconnected,

\[ K_{c_i c_i}=1 \quad\text{and}\quad K_{c_i c_j}=0\ \text{for }i\neq j. \]

Types and masses

For every vertex \(q\in Q\), introduce one type, so \(T=Q\). Give every type mass

\[ \mu_q=\frac1n. \]

Thus all masses are positive and sum to \(1\).

Symmetric utility matrix

Define

\[ a_{qr}= \begin{cases} -1,&\text{if }\{q,r\}\in F,\\ 0,&\text{otherwise}. \end{cases} \]

In particular, \(a_{qq}=0\). Because \(H\) is undirected, \(a\) is symmetric. Its only values are \(0\) and \(-1\).

The construction has polynomial size; explicitly writing \(a\) requires \(O(n^2)\) entries.

Correctness of the Reduction

A \(3\)-coloring gives a feasible assignment

Suppose \(\gamma:Q\to\{1,2,3\}\) is a proper coloring of \(H\). Define

\[ x_{q,c_i}= \begin{cases} \frac1n,&\text{if }\gamma(q)=i,\\ 0,&\text{otherwise}. \end{cases} \]

Every type receives total mass \(1/n\). Moreover, at every host vertex \(c_i\),

\[ \sum_{q\in Q}x_{q,c_i}\leq\sum_{q\in Q}\frac1n=1=u_{c_i}. \]

Consider a supported pair \((q,c_i)\). Because distinct host vertices have zero interaction,

\[ U_{q,c_i}(x) = \sum_{r\in Q}a_{qr}x_{r,c_i} = -\sum_{r\in N_H(q)}x_{r,c_i}. \]

No neighbor of \(q\) has color \(i\), so every term in the last sum is zero. Hence \(U_{q,c_i}(x)=0\), and the assignment is individually rational.

A feasible assignment gives a \(3\)-coloring

Conversely, suppose \(x\) is feasible. For every \(q\in Q\),

\[ \sum_{i=1}^{3}x_{q,c_i}=\frac1n>0. \]

Therefore the support set

\[ C(q)=\{i\in\{1,2,3\}:x_{q,c_i}>0\} \]

is nonempty.

We first prove that adjacent vertices have disjoint support sets. Let \(\{q,r\}\in F\). If some \(i\) belonged to both \(C(q)\) and \(C(r)\), then \(x_{q,c_i}>0\) and \(x_{r,c_i}>0\). Individual rationality of type \(q\) at \(c_i\) would require \(U_{q,c_i}(x)\geq0\). But

\[ U_{q,c_i}(x) = -\sum_{s\in N_H(q)}x_{s,c_i} \leq -x_{r,c_i}<0, \]

a contradiction. Hence \(C(q)\cap C(r)=\varnothing\) whenever \(\{q,r\}\in F\).

For each \(q\), choose any \(\gamma(q)\in C(q)\). If \(\{q,r\}\in F\), disjointness of \(C(q)\) and \(C(r)\) implies \(\gamma(q)\neq\gamma(r)\). Thus \(\gamma\) is a proper \(3\)-coloring of \(H\).

This argument explicitly handles fractional splitting: a type may occupy several host vertices, but adjacent types can never occupy the same one. Selecting any occupied vertex for each type therefore recovers an integral coloring.

Conclusion

The reduction proves \(\mathrm{NP}\)-hardness, while the support-guess linear-program argument proves membership in \(\mathrm{NP}\). Therefore the continuous individual-rationality problem is \(\mathrm{NP}\)-complete, already for a fixed three-vertex edgeless host graph and a symmetric matrix using only two rational values.

Step-by-step verification

1. Membership in \(\mathrm{NP}\)

For a guessed set \(S\subseteq T\times V\), the prover constructs a rational linear system containing:

  • the nonnegativity, mass, and capacity constraints;
  • \(x_{t,v}=0\) for \((t,v)\notin S\);
  • \(U_{t,v}(x)\geq 0\) for \((t,v)\in S\).

The claimed equivalence is correct.

  • Given an original feasible assignment, choosing its exact positive support produces a feasible system.
  • Conversely, if the system for \(S\) is feasible, every positive variable must correspond to a pair in \(S\), where the required utility inequality is imposed.
  • Variables indexed by \(S\) are not required to be positive, but this causes no problem: imposing utility constraints on additional zero variables only strengthens that particular system, and the exact support is available in the forward direction.

The certificate \(S\) has polynomial length. Exact feasibility of a rational linear program is decidable in polynomial time. Graph distances and the corresponding rational coefficients \(K_{vw}\) are also polynomial-time computable. Thus membership in \(\mathrm{NP}\) is established.

2. Polynomial size of the reduction

The reduction creates:

  • three host vertices;
  • one type per vertex of \(H\);
  • masses \(1/n\);
  • a symmetric \(n\times n\) matrix with entries in \(\{0,-1\}\).

The dense matrix representation has \(O(n^2)\) entries, and \(1/n\) has polynomial encoding length. The construction is polynomial.

Restricting the source problem to nonempty simple graphs does not affect the standard \(\mathrm{NP}\)-hardness of \(3\)-Colorability.

3. Distance coefficients

Because the host graph consists of three isolated vertices,

\[ K_{c_i c_i}=f(1)=1 \]

by the special diagonal definition, while

\[ K_{c_i c_j}=f(\infty)=0 \]

for \(i\neq j\). Consequently, utility at \(c_i\) depends only on mass placed at \(c_i\), exactly as used later.

The fixed table specifies all distances relevant to a three-vertex graph: \(1\), \(2\), and \(\infty\). Its stated values satisfy the required monotonicity.

4. Forward implication

Given a proper \(3\)-coloring, placing the entire mass \(1/n\) of each type at its color vertex satisfies:

  • every type’s mass equality;
  • each capacity constraint, since the total mass of all types is \(1\);
  • individual rationality, because no neighbor of \(q\) is placed at the same host vertex.

For a supported pair \((q,c_i)\), the utility calculation

\[ U_{q,c_i}(x) = -\sum_{r\in N_H(q)}x_{r,c_i} \]

is correct. The diagonal term contributes zero because \(a_{qq}=0\), and other host vertices contribute zero because their \(K\)-coefficients vanish.

5. Reverse implication

Every type has mass \(1/n>0\), so its support set \(C(q)\) is nonempty.

If adjacent vertices \(q,r\) both placed positive mass at \(c_i\), then

\[ U_{q,c_i}(x) = -\sum_{s\in N_H(q)}x_{s,c_i} \leq -x_{r,c_i}<0. \]

This contradicts individual rationality because \(x_{q,c_i}>0\). Hence adjacent vertices have disjoint support sets.

Choosing one element from each nonempty \(C(q)\) produces a proper \(3\)-coloring. This correctly handles arbitrary fractional splitting and does not assume that each type is integrally assigned.

6. Final classification

The reduction proves \(\mathrm{NP}\)-hardness under the stated restrictions, while the support certificate proves membership in \(\mathrm{NP}\). Therefore the claimed \(\mathrm{NP}\)-completeness conclusion follows.
