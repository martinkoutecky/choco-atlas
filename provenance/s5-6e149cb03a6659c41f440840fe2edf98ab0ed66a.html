Conclusion and encoding convention

Exact computation of the stable opinion vector is solvable in deterministic time polynomial in \(\tau\) and \(L\). The proof below establishes convergence, bounds the output length, and gives an exact algorithm with polynomial bit complexity.

Here, a binary rational is represented by an integer numerator and a positive integer denominator, both written in binary. In particular, the output need not have a terminating binary expansion.

1. Convergence and uniqueness

Write \(n=\tau\), \(W=W_\mu\), \(\Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_n)\), and \(T=\Lambda W\). Let \(\mathbf 1\) denote the all-ones column vector.

Every normalization denominator is positive by assumption. Thus \(W\) is nonnegative and \(W\mathbf 1=\mathbf 1\). Moreover, positivity of every mass gives

\[ W(t,s)>0 \quad\Longleftrightarrow\quad a_{ts}>0. \]

Consequently, the graph of \(W\), using the arc convention in the question, is strongly connected.

The matrix \(T\) is substochastic: it is nonnegative and \(T\mathbf 1\leq\mathbf 1\). Define the deficit vector

\[ d=\mathbf 1-T\mathbf 1, \qquad d_t=1-\lambda_t, \]

and the nonempty set \(S=\{t:\lambda_t<1\}\).

For each type \(t\), choose a shortest directed path in the graph of \(W\) from \(t\) to \(S\), say \(t=t_0,t_1,\ldots,t_j\). Such a path exists by strong connectivity and has \(j\leq n-1\). Its internal vertices are outside \(S\), since otherwise the path could terminate earlier. Therefore, for \(i<j\),

\[ T(t_i,t_{i+1})=\lambda_{t_i}W(t_i,t_{i+1}) =W(t_i,t_{i+1})>0. \]

As \(d_{t_j}>0\), the path contributes a positive term to \((T^j d)_t\). This also holds for \(j=0\), when \(t\in S\).

The telescoping identity

\[ \mathbf 1-T^n\mathbf 1 =\sum_{h=0}^{n-1}T^h(\mathbf 1-T\mathbf 1) =\sum_{h=0}^{n-1}T^h d \]

therefore has every component strictly positive. For the maximum absolute row-sum norm, this implies \(c:=\|T^n\|_\infty<1\). Also, \(\|T^r\|_\infty\leq1\) for every nonnegative integer \(r\). Submultiplicativity gives

\[ \|T^{qn+r}\|_\infty\leq c^q \qquad(q\geq0,\;0\leq r<n). \]

Hence \(T^k\to0\), and \(\sum_{k=0}^{\infty}T^k\) converges. Multiplying its partial sums by \(I-T\) shows that

\[ (I-T)^{-1}=\sum_{k=0}^{\infty}T^k. \]

Thus \(I-T\) is nonsingular. With \(b=(I-\Lambda)u\), the unique fixed point is \(z=(I-T)^{-1}b\). Since \(x(k+1)=Tx(k)+b\), subtraction of the fixed-point equation gives \(x(k)-z=T^k(u-z)\to0\).

This proves the convergence premise directly, including cases with \(\lambda_t=0\). It agrees with the stability criterion in [Proskurnikov and Tempo, Section 6.1](https://arxiv.org/html/1701.06307).

2. Constructing an integer system of polynomial size

We can avoid explicitly computing the normalized entries of \(W\). Put

\[ h_t=\sum_s\mu_s a_{ts}>0. \]

Multiplying each fixed-point equation by \(h_t\) gives

\[ \sum_s\bigl(h_t\delta_{ts}-\lambda_t\mu_s a_{ts}\bigr)z_s =h_t(1-\lambda_t)u_t, \]

where \(\delta_{ts}\) is the Kronecker delta. The coefficient matrix is \(\operatorname{diag}(h_1,\ldots,h_n)(I-T)\), so it is nonsingular.

Let \(Q\) be the product of all positive denominators appearing in the input. Because their binary lengths are included in \(L\), the binary length of \(Q\) is \(O(L)\). Define integers

\[ p_t=Q\mu_t,\qquad r_{ts}=Qa_{ts},\qquad \ell_t=Q\lambda_t,\qquad v_t=Qu_t, \qquad R_t=\sum_s p_s r_{ts}. \]

Then \(h_t=R_t/Q^2\). Multiplying the preceding equations by \(Q^4\) produces the integer system \(Hz=g\), with

\[ H_{ts}=Q^2R_t\delta_{ts}-Q\ell_t p_s r_{ts}, \qquad g_t=R_t(Q-\ell_t)v_t. \]

The matrix \(H\) is nonsingular because it is a positive scalar multiple of the nonsingular coefficient matrix above.

Each of \(Q,p_t,r_{ts},\ell_t,v_t\) has \(O(L)\) bits. Each \(R_t\) is a sum of \(n\) products of such integers, so it has \(O(L+\log(n+1))\) bits. The same bound holds for every entry of \(H\) and \(g\).

Choose \(B=O(L+\log(n+1))\) such that all these entries have absolute value at most \(2^B\). Their construction uses polynomially many operations on integers of polynomial length.

3. Polynomial output length

For each \(t\), let \(H^{(t)}\) be \(H\) with column \(t\) replaced by \(g\). Since \(H\) is nonsingular, Cramer’s rule gives

\[ z_t=\frac{\det H^{(t)}}{\det H}. \]

For any \(n\)-by-\(n\) integer matrix \(M\) whose entries have absolute value at most \(2^B\), the determinant expansion gives

\[ |\det M| \leq\sum_{\pi}\prod_{i=1}^{n}|M_{i,\pi(i)}| \leq n!\,2^{nB}. \]

Thus each determinant above has \(O(n(B+\log(n+1)))\) bits. Reducing the fraction by its greatest common divisor cannot increase its numerator or denominator.

Every output coordinate consequently has \(O(n(L+\log(n+1)))\) bits, and the entire vector has polynomial output length.

4. Computing the determinants in polynomial bit time

For completeness, the determinant bound also controls the intermediate rational numbers in Gaussian elimination.

Consider an integer matrix \(M\) with the entry bound above. Perform exact Gaussian elimination with row pivoting, reducing each rational after every operation. After \(k\) successful pivots, let \(P_k\) be the nonsingular leading \(k\)-by-\(k\) block of the row-permuted original matrix.

Each remaining Schur-complement entry has the form

\[ \alpha-cP_k^{-1}b = \frac{ \det\begin{pmatrix}P_k&b\\c&\alpha\end{pmatrix} }{ \det P_k }. \]

This identity follows by multiplying the bordered matrix on the left by the block triangular matrix with diagonal blocks \(I\) and \(1\), and lower-left block \(-cP_k^{-1}\). That multiplier has determinant \(1\), and the resulting matrix has determinant \(\det(P_k)(\alpha-cP_k^{-1}b)\).

Both determinants in the ratio are minors of the row-permuted original matrix. A minor of order \(r\leq n\) has absolute value at most \(r!2^{rB}\). Thus every reduced Schur-complement entry and pivot has \(O(n(B+\log(n+1)))\) bits. The temporary products and differences in an elimination update also have polynomial length.

If no nonzero pivot exists in the current column, the remaining Schur complement has a zero column, so the determinant is zero. Otherwise, elimination finishes, and the determinant is the product of the pivots, adjusted for row swaps. Even multiplying all pivot fractions directly requires only polynomially many bits: there are \(n\) factors, each of polynomial length.

Gaussian elimination uses \(O(n^3)\) rational operations. Integer arithmetic and greatest-common-divisor computation on polynomial-length integers take polynomial bit time. Therefore each determinant can be computed in polynomial time.

Compute \(\det H\) and the \(n\) determinants \(\det H^{(t)}\), then reduce the resulting fractions. This yields every stable opinion exactly in time polynomial in \(n=\tau\) and \(L\).

5. Complexity classification

The exact-output function belongs to \(\mathrm{FP}\). Its computation uses the support size directly; no expansion into individual agents is needed.

This settles the requested classification as polynomial-time solvable. As usual, a claim of \(\mathrm{NP}\)-hardness under reductions allowing decision problems to be solved with this exact-output algorithm would imply \(\mathrm{P}=\mathrm{NP}\).
