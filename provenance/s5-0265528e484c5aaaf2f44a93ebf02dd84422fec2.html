The continuous mirror question, as graded

Given candidates \(C\), a committee \(W\), and a distribution \(\mu\) over supported approval types \(T\), compute the exact threshold \(\theta_\mu(W)=\max_{c\notin W,\ \emptyset\ne S\subseteq T_c,\ r_W(S)<k} k\mu(S)/(r_W(S)+1)\), where \(T_c=\{t\in T:c\in t\}\), \(\mu(S)=\sum_{t\in S}\mu_t\), and \(r_W(S)=|\bigcup_{t\in S}(t\cap W)|\); return a maximizing \(c,S\) and the boundary level \(\ell=r_W(S)+1\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\) candidates and let \(W\subseteq C\) be a committee of size \(k\), with \(1<k<m\).
A society is given by its support: a list \(T\subseteq 2^C\) of \(\tau\) approval types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
For \(c\in C\setminus W\), define \(T_c=\{t\in T:c\in t\}\). For \(S\subseteq T\), define \(\mu(S)=\sum_{t\in S}\mu_t\) and \(r_W(S)=\left|\bigcup_{t\in S}(t\cap W)\right|\); selecting a type includes its entire mass.
Compute exactly \(\theta_\mu(W)=\max_{c\in C\setminus W,\ \emptyset\ne S\subseteq T_c,\ r_W(S)<k}\frac{k\mu(S)}{r_W(S)+1}\). The maximum of an empty family is \(0\). When positive, also return any maximizing pair \((c,S)\) and the boundary level \(\ell=r_W(S)+1\); otherwise return no witness.

Is this exact computation problem solvable in polynomial time in \(m,\tau,k,L\), or is it NP-hard?

For a finite society of \(n\) unweighted voters, the corresponding exact threshold and a boundary witness are computable by parametric flow in \(\mathcal O(mnk^2\min\{n,k\}\log(\min\{n,k\}))\) time.

Modeling choices made when packaging the task

  • Normalize the masses to sum to one, following the stated distribution model and the discrete threshold's normalization by the number of voters.
  • Require the committee size to satisfy 1<k<m, as in the discrete election definition.
  • Set the maximum over an empty feasible family to zero and return no witness in that case, following the discrete threshold convention.
  • Allow any maximizing witness when several pairs attain the threshold.

Result

The exact computation problem is polynomial-time solvable in \(m,\tau,k,L\), including recovery of a maximizing pair and its boundary level.

The key is to enforce \(r_W(S)<k\) by fixing one committee member that the selected types do not approve. The resulting threshold decision problem reduces to minimum cut, with each type selected together with its entire mass.

1. Integer scaling and separation of possible values

Write each input mass as \(\mu_t=p_t/d_t\), where \(p_t,d_t\) are positive integers. Define

\(D=\prod_{t\in T}d_t,\qquad a_t=p_t(D/d_t).\)

Then every \(a_t\) is a positive integer, \(\mu_t=a_t/D\), and \(\sum_{t\in T}a_t=D\). Moreover, the binary length of \(D\) is at most the sum of the binary lengths of the input denominators, hence is \(O(L)\). These integers can therefore be computed in polynomial time.

For \(S\subseteq T\), let \(a(S)=\sum_{t\in S}a_t\). It suffices to compute the scaled optimum

\(\Phi=D\theta_\mu(W)=\max_{c\in C\setminus W,\ \emptyset\ne S\subseteq T_c,\ r_W(S)<k}\frac{k\,a(S)}{r_W(S)+1},\)

with the same empty-family convention.

Every feasible value has the form \(kA/\ell\), where \(A\) is an integer satisfying \(1\le A\le D\), and \(1\le\ell\le k\). Consequently, two distinct feasible values satisfy

\(\left|\frac{kA}{\ell}-\frac{kA'}{\ell'}\right|=\frac{k|A\ell'-A'\ell|}{\ell\ell'}\ge\frac{k}{k^2}=\frac1k.\)

Also, \(0\le\Phi\le kD\). This separation bound will permit exact recovery using polynomially many threshold queries.

2. A minimum-cut oracle for strict threshold comparison

Fix a rational threshold \(q\ge0\). We construct an oracle deciding whether \(\Phi>q\), returning a feasible pair whose scaled value exceeds \(q\) whenever the answer is yes.

For each \(c\in C\setminus W\) and \(w\in W\), define

\(U_{c,w}=\{t\in T:c\in t,\ w\notin t\}.\)

Every subset of \(U_{c,w}\) omits \(w\) from its committee approvals and therefore has \(r_W(S)<k\). Conversely, every feasible pair \((c,S)\) belongs to one of these cases: because \(r_W(S)<k\), some \(w\in W\) is absent from \(\bigcup_{t\in S}(t\cap W)\), so \(S\subseteq U_{c,w}\).

For this fixed pair \((c,w)\), build a directed network with:

  • a source \(s\) and sink \(z\);
  • one vertex for each type \(t\in U_{c,w}\);
  • one vertex for each candidate \(v\in W\setminus\{w\}\);
  • an arc \(s\to t\) of capacity \(k a_t\);
  • an arc \(v\to z\) of capacity \(q\);
  • an arc \(t\to v\) of capacity \(B=kD+1\) whenever \(v\in t\cap W\).

Let \(K_{c,w}=\sum_{t\in U_{c,w}}k a_t\), and let \(\lambda_{c,w}(q)\) be the minimum-cut capacity.

The cut whose source side contains only \(s\) has capacity \(K_{c,w}\le kD<B\). Thus no minimum cut cuts an arc of capacity \(B\).

Let \(S\) be the type vertices and \(R\) the candidate vertices on the source side of a minimum cut. Since no dependency arc is cut,

\(\bigcup_{t\in S}(t\cap W)\subseteq R.\)

Its capacity is therefore

\(K_{c,w}-k a(S)+q|R|.\)

Conversely, for every \(S\subseteq U_{c,w}\), choosing exactly its committee-approval union as \(R\) yields a cut of capacity

\(K_{c,w}-k a(S)+q r_W(S).\)

Because \(q\ge0\), adding candidate vertices beyond that union cannot improve the cut. Hence

\(K_{c,w}-\lambda_{c,w}(q)=\max_{S\subseteq U_{c,w}}\bigl(k a(S)-q r_W(S)\bigr).\)

Here the empty subset is included. It follows that

\(K_{c,w}-\lambda_{c,w}(q)>q\)

holds exactly when some nonempty \(S\subseteq U_{c,w}\) satisfies

\(\frac{k a(S)}{r_W(S)+1}>q.\)

Indeed, this is just the inequality \(k a(S)-q r_W(S)>q\), and the empty subset cannot satisfy it.

A minimum cut also supplies a witness. If its source-side type set is \(S\), then \(r_W(S)\le|R|\), so

\(k a(S)-q r_W(S)\ge k a(S)-q|R|=K_{c,w}-\lambda_{c,w}(q)>q.\)

Thus its type set is nonempty and has scaled value exceeding \(q\).

Running these networks for all \((c,w)\) gives the required oracle, using at most \((m-k)k\) minimum-cut computations per query.

3. Exact recovery of an optimal witness

First query the oracle at \(q=0\). If it answers no, then \(\Phi=0\); return threshold \(0\) and no witness.

Otherwise, initialize \(b_-=0\) and \(b_+=kD\). Maintain

\(b_-<\Phi\le b_+.\)

At each step, query \(q=(b_-+b_+)/2\). If \(\Phi>q\), replace \(b_-\) by \(q\); otherwise replace \(b_+\) by \(q\). The invariant is preserved.

Choose an integer \(N\) satisfying \(2^N>Dk^2\), and perform \(N\) steps. Then

\(b_+-b_-=\frac{kD}{2^N}<\frac1k.\)

Query the oracle once more at \(b_-\), obtaining a feasible pair \((c,S)\). Write its scaled value as

\(v=\frac{k a(S)}{r_W(S)+1}.\)

The oracle and the interval invariant give

\(b_-<v\le\Phi\le b_+.\)

If \(v<\Phi\), the separation bound from Section 1 would imply \(\Phi-v\ge1/k\). But the displayed inequalities imply

\(\Phi-v<b_+-b_-<1/k,\)

a contradiction. Therefore \(v=\Phi\), and \((c,S)\) is a maximizing pair.

Return, using exact rational arithmetic,

\(\ell=r_W(S)+1,\qquad \theta_\mu(W)=\frac{k a(S)}{D\ell}.\)

4. Polynomial bit complexity

Each network has at most \(\tau+k+2\) vertices and \(O(\tau k+\tau+k)\) arcs.

The number of bisection steps is \(N=O(\log D+\log k)=O(L+\log k)\). Every queried threshold is dyadic and has numerator and denominator of binary length \(O(L+\log k)\). Multiplying all capacities in a queried network by the threshold’s denominator produces integer capacities of polynomial bit length and preserves its minimum cuts.

For example, the Edmonds–Karp algorithm computes a maximum flow, and hence a minimum cut, using a number of arithmetic operations polynomial in the numbers of vertices and arcs, independently of capacity magnitudes. All these operations involve integers of polynomial bit length. Each oracle query therefore takes polynomial time.

There are at most \((m-k)k(N+2)\) minimum-cut computations in total. All preprocessing and witness recovery also take polynomial time. Thus the algorithm computes the exact threshold and a maximizing boundary witness in polynomial time in \(m,\tau,k,L\), without expanding rational masses into individual voters.

Verification report

The prover resolves the assigned problem correctly. The reduction, exact recovery procedure, and polynomial bit complexity are valid. No major or minor issues were found.

1. Integer scaling and value separation

The definition \(D=\prod_{t\in T}d_t\) makes each \(a_t=p_t(D/d_t)\) a positive integer. The identities \(\mu_t=a_t/D\) and \(\sum_{t\in T}a_t=D\) follow from the input normalization.

The bit length bound for \(D\) is valid: multiplying denominators adds their logarithms, so its binary representation has length \(O(L)\). Computing these quantities does not require time polynomial in the numerical value of \(D\).

Scaling the objective by \(D\) preserves its maximizing pairs. For any nonempty feasible set, \(1\le a(S)\le D\), and \(r_W(S)<k\) gives \(1\le r_W(S)+1\le k\).

The separation calculation is correct. For distinct values, \(A\ell'-A'\ell\) is a nonzero integer, so its absolute value is at least \(1\). Consequently, distinct feasible scaled values differ by at least \(1/k\). The upper bound \(\Phi\le kD\) also holds.

2. Enforcement of the feasibility restriction

The enumeration over \((c,w)\) is exact.

  • Every subset of \(U_{c,w}\) consists of types approving \(c\) and omitting \(w\), hence has \(r_W(S)\le k-1\).
  • Every feasible pair has a committee member absent from its approval union, and therefore appears in at least one enumerated case.

There is no relaxation of the indivisibility requirement: selecting a type vertex selects its entire mass.

3. Minimum-cut oracle

All capacities are nonnegative for the stated domain \(q\ge0\). The source-only cut has capacity \(K_{c,w}\le kD<B\). Thus a minimum cut cannot cross a dependency arc of capacity \(B\).

The resulting containment of the selected types’ approval union in \(R\) is correct, as is the cut-capacity expression
\[ K_{c,w}-k a(S)+q|R|. \]

For each type subset, taking precisely its approval union as the candidate vertices produces the stated cut. Since \(q\ge0\), extra candidate vertices cannot reduce its capacity. This proves the claimed identity between the cut value and the maximization objective. At \(q=0\), extra candidate vertices may occur without changing capacity; the argument remains valid.

The strict comparison is also exact:
\[ k a(S)-q r_W(S)>q \]
is equivalent to the scaled ratio exceeding \(q\). The empty set has objective value \(0\), so it cannot satisfy this comparison for any permitted threshold.

Witness extraction works even if the returned minimum cut contains extra candidate vertices. The inequality \(r_W(S)\le|R|\), together with \(q\ge0\), gives the asserted witness bound. A successful comparison therefore returns a nonempty feasible set.

These statements also cover \(U_{c,w}=\emptyset\): its network cannot yield a positive strict comparison.

4. Exact recovery

The initial query correctly distinguishes \(\Phi=0\) from \(\Phi>0\). Every feasible nonempty set has positive value, so a negative answer at zero requires returning no witness.

For the positive case, the bisection invariant \(b_-<\Phi\le b_+\) is valid initially and after either update, including when the queried threshold equals \(\Phi\).

The choice \(2^N>Dk^2\) gives an interval of width strictly less than \(1/k\). The final oracle query succeeds because its threshold remains strictly below \(\Phi\).

The returned value lies above \(b_-\) and at most \(\Phi\). If it were suboptimal, the proved separation bound would contradict the interval width. Hence the extracted pair maximizes the original objective after dividing by \(D\).

The reported boundary level is exactly \(r_W(S)+1\), as required.

5. Polynomial bit complexity

The network size bounds are correct. The number of bisection steps is \(O(L+\log k)\), and all queried dyadic thresholds have polynomial binary length.

Multiplying capacities by the positive threshold denominator preserves minimum cuts and produces nonnegative integer capacities of polynomial bit length. The cited Edmonds–Karp polynomial arithmetic-operation guarantee applies to these directed networks. Intermediate flow and residual-capacity integers also have polynomial bit length, so this yields polynomial bit complexity.

The count of at most \((m-k)k(N+2)\) cut computations includes the initial query, all bisection queries, and final witness query. Preprocessing and computing the witness’s approval union are polynomial as well.

The proof establishes the requested polynomial-time classification and both required outputs. It need not reproduce the finite unweighted society’s particular runtime bound.
