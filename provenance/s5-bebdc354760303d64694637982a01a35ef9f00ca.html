The continuous mirror question, as graded

Given a finite task set \(S\), exact worker types \(T\), rational type masses \(\mu_t\geq 0\) summing to \(1\), and rational task data with workload and reward scaled per reference population, choose masses \(x_{ts}\geq 0\) assigned from type \(t\) to task \(s\), subject to \(\sum_s x_{ts}\leq\mu_t\) and reachability constraints. For each assigned task let \(y_s=\sum_t x_{ts}>0\) and \(q_s=a_s+(\sum_t \Delta_{ts}x_{ts}+\bar w_s)/y_s\); require completion by the deadline and positive work contribution \(q_s-a_s-\Delta_{ts}>0\) for every assigned type. Keep tasks indivisible: an assigned task earns the paper’s reward-pricing-model reward at \(q_s\), and an unassigned task earns zero. Maximize total task reward, or decide whether a feasible assignment achieves at least a given rational threshold \(K\).

Here \(\tau\) is the support size, not the number of possible types. Let \(m=|S|\), and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
All tasks are assigned at one given time \(a\geq0\). Task \(s\) has rational publication time \(p_s\), expected completion time \(e_s\), deadline \(d_s\), workload \(\bar w_s>0\), maximum reward \(B_s>0\), and penalty rate \(c_s\geq0\), with \(0\leq p_s\leq e_s\leq d_s\), \(p_s\leq a<d_s\), and \(c_s(d_s-e_s)\leq B_s\). Workloads, rewards, and penalty rates are expressed per unit reference population.
Each type has a given rational travel time \(\Delta_{ts}\geq0\) to each task and a given range-membership indicator. A pair \((t,s)\) is eligible exactly when the task lies within the type's reachable range and \(a+\Delta_{ts}<d_s\).
Choose real masses \(x_{ts}\geq0\), with \(\sum_s x_{ts}\leq\mu_t\) and \(x_{ts}=0\) for ineligible pairs. A task is assigned exactly when \(y_s=\sum_t x_{ts}>0\); its completion time is \(q_s=a+(\sum_t\Delta_{ts}x_{ts}+\bar w_s)/y_s\). Require \(q_s\leq d_s\) and \(q_s-a-\Delta_{ts}>0\) whenever \(x_{ts}>0\).
An assigned task earns \(R_s(q_s)=B_s-c_s\max\{0,q_s-e_s\}\); an unassigned task earns zero. Tasks remain indivisible: reward is paid once per completed task, without multiplication by assigned mass.
Each assigned task's mass vector must be minimal: no distinct componentwise smaller vector earns the same reward while either satisfying that task's eligibility, completion, and positive-contribution conditions or being the zero vector, which earns zero.
Given a binary-rational threshold \(K\geq0\), decide whether such an assignment has total reward at least \(K\).

Result

The decision problem is \(\mathrm{NP}\)-hard, even when the support size is \(\tau=1\), every task is reachable, all travel times are zero, all deadlines coincide, and all penalty rates are zero.

The reduction below respects the exact mass formulation, including its minimality and positive-contribution requirements.

Reduction from Subset Sum

Use the standard \(\mathrm{NP}\)-hard Subset Sum problem: given binary-encoded positive integers \(v_1,\ldots,v_n\) and a positive integer \(H\), decide whether some subset \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in I}v_i=H\). Subset Sum’s hardness is a standard result; see, for example, [Polak, Rohwedder, and Węgrzycki](https://arxiv.org/abs/2105.04035).

Construct a society with one worker type \(t\), of mass \(\mu_t=1\), and set the assignment time to \(a=0\). Create \(m=n\) tasks. For task \(i\), set

\(p_i=e_i=0,\qquad d_i=H,\qquad \bar w_i=v_i,\qquad B_i=v_i,\qquad c_i=0.\)

Every task lies within the type’s reachable range, and \(\Delta_{ti}=0\). Set the reward threshold to \(K=H\).

All numerical input values are integers, hence binary-rational. The support mass is positive and sums to one. Because \(H>0\), every task satisfies

\(0\leq p_i\leq e_i\leq d_i,\qquad p_i\leq a<d_i.\)

Also, \(c_i(d_i-e_i)=0\leq B_i\), and every pair is eligible because \(a+\Delta_{ti}=0<H=d_i\). Thus the construction satisfies every input hypothesis.

Exact characterization of minimal task masses

Write \(x_i=x_{ti}\). With one type, an assigned task has \(y_i=x_i>0\), and its completion time is

\(q_i=\dfrac{v_i}{x_i}.\)

Consequently, its deadline condition is equivalent to

\(q_i\leq H\quad\Longleftrightarrow\quad x_i\geq\dfrac{v_i}{H}.\)

Its positive-contribution condition holds automatically: \(q_i-a-\Delta_{ti}=v_i/x_i>0\). Since \(c_i=0\), every feasible positive assignment earns the same reward \(v_i>0\).

Claim. An assigned task’s mass vector is minimal exactly when \(x_i=v_i/H\).

Proof. If \(x_i>v_i/H\), replace it by \(x'_i=v_i/H\). This is a distinct componentwise smaller vector. It completes the task at time \(H\), satisfies eligibility and positive contribution, and earns the same reward \(v_i\). Hence the original vector is not minimal.

Conversely, suppose \(x_i=v_i/H\). Any smaller positive mass \(z_i<x_i\) gives \(v_i/z_i>H\), violating the deadline. The zero vector earns zero, strictly less than \(v_i\). Thus no distinct componentwise smaller vector permitted by the minimality definition earns the same reward. This proves the claim.

In particular, minimality is fully enforced in the constructed instance.

Correctness of the reduction

Forward direction. Suppose a subset \(I\) satisfies \(\sum_{i\in I}v_i=H\). Assign \(x_i=v_i/H\) for \(i\in I\), and assign zero to every other task.

The total assigned mass is

\(\sum_{i=1}^{n}x_i=\dfrac{\sum_{i\in I}v_i}{H}=1=\mu_t.\)

Every selected task completes at its deadline, satisfies positive contribution, and has a minimal mass vector by the claim. The total reward is \(\sum_{i\in I}v_i=H=K\). Thus the task-assignment instance is a yes-instance.

Reverse direction. Suppose an admissible assignment earns at least \(K=H\). Let \(I=\{i:x_i>0\}\) be its selected tasks. Minimality implies \(x_i=v_i/H\) for each \(i\in I\). The population constraint therefore yields

\(\dfrac{\sum_{i\in I}v_i}{H}=\sum_{i\in I}x_i\leq1,\)

so \(\sum_{i\in I}v_i\leq H\). Since rewards are paid once per selected task, the threshold condition gives \(\sum_{i\in I}v_i\geq H\). Together these inequalities imply \(\sum_{i\in I}v_i=H\). Hence the Subset Sum instance is a yes-instance.

Encoding size and complexity

Let \(\ell\) be the source instance’s bit length. The construction has \(m=n\), \(\tau=1\), and total output length \(L=O(m\ell)\): each task copies its integer \(v_i\) and the common deadline \(H\). It can be written in \(O(L)\) bit operations, so this is a polynomial-time many-one reduction.

For this restricted family, a certificate is simply the selected subset. Checking its integer sum takes \(O(mL)\) bit operations. Thus the restricted family is also in \(\mathrm{NP}\), although membership of the unrestricted continuous problem is unnecessary for the requested hardness conclusion.

Therefore, an algorithm for the general problem running in \(\operatorname{poly}(m,\tau,L)\) time would imply \(\mathrm{P}=\mathrm{NP}\). The continuous availability of worker masses does not eliminate the combinatorial choice of which indivisible task rewards to obtain.
