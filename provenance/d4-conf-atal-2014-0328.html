The continuous mirror question, as graded

Given a fixed weighted network whose edge roles \(a\) have endpoints and weights \(w_a\), and a population distribution \(\mu\) over those roles, maximize total team value over simple source-to-target paths \(r\). For each path let \(q(r)=\min_{a\in r}w_a\), and let \(x_r\ge 0\) be the mass of teams assigned to \(r\). Find an optimal \(x\) for \(\max \sum_r q(r)x_r\), subject to \(\sum_{r\ni a}x_r\le \mu_a\) for every role \(a\).

Packaged proof task (what the prover saw — nothing else)

Let the input network be a finite undirected graph \(G=(V,E)\), with distinct terminals \(s,t\), \(m=|E|\) edge roles, and positive binary-rational weights \(w_a\). Parallel edges are distinct roles; the network is part of the input.
A society is given by its support: the list of the \(\tau\) roles with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types. Set omitted masses to zero and require \(\sum_{a\in E}\mu_a=1\).
Let \(R\) contain all simple \(s\)-to-\(t\) paths and define \(q(r)=\min_{a\in r}w_a\). An assignment gives each path a real team mass \(x_r\geq0\), consuming \(x_r\) mass of every role on that path; unused population mass contributes zero value.
Define \(\operatorname{OPT}=\max\{\sum_{r\in R}q(r)x_r:\sum_{r\ni a}x_r\leq\mu_a\text{ for every }a\in E,\ x_r\geq0\}\), with value zero when \(R\) is empty. Let \(L\) be the total binary input length, including an input threshold \(K\in\mathbb{Q}_{\geq0}\).

Is deciding whether \(\operatorname{OPT}>K\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), \(|V|\), and \(L\).

For indivisible edge agents, maximizing the sum of coalition values—each coalition worth its strongest contained path, or zero—is \(\mathrm{NP}\)-hard, and admits a polynomial-time \(O(\log m)\)-approximation ([source](https://www.ifaamas.org/Proceedings/aamas2014/aamas/p589.pdf)).
No result settling this exact continuous formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Interpreted the network as an input instance rather than a constant fixed independently of the input.
  • Used undirected edges, following the discrete hardness construction; parallel edges remain distinct roles.
  • Required distinct source and target vertices so every admissible path has a defined bottleneck.
  • Specified positive binary-rational weights, matching the positive rational weight domain of the discrete model.
  • Normalized the population distribution to total mass one and assigned zero mass to roles omitted from its support.
  • Allowed unused mass to contribute zero value, preserving the stated capacity inequalities and the discrete convention for coalitions without a source-to-target path.
  • Introduced a nonnegative binary-rational threshold for the decision complexity question and defined the total input bit length.

Result

Deciding whether \(\operatorname{OPT}>K\) is in \(\mathrm{P}\). In fact, the exact optimum can be computed by a polynomial-size rational linear program.

The proof below uses continuous flows with shared edge capacities. It does not assume an integral optimum.

1. Restricting to the support

Let \(S=\{a\in E:\mu_a>0\}\), so \(|S|=\tau\).

If a path \(r\) contains an edge \(a\notin S\), its capacity constraint implies

\(\displaystyle 0\le x_r\le\sum_{r'\ni a}x_{r'}\le\mu_a=0.\)

Consequently, deleting all edges outside \(S\) preserves the optimum. If loops are allowed, they can also be deleted because a simple path cannot use them. No renormalization of the remaining masses is needed.

Retain only the endpoints of remaining edges together with \(s,t\). Write \(H\) for this graph and \(h\) for its number of vertices. Then

\(\displaystyle h\le\min\{|V|,2\tau+2\}.\)

Parallel edges remain distinct roles throughout.

If \(H\) contains no \(s\)-to-\(t\) path, then \(\operatorname{OPT}=0\), and the answer is negative because \(K\ge0\). Henceforth suppose such a path exists.

Let

\(\displaystyle \lambda_1<\lambda_2<\cdots<\lambda_d\)

be the distinct weights of the remaining edges. Thus \(d\le\tau\). For each \(k\), define the threshold graph

\(\displaystyle H_k=(V(H),E_k),\qquad E_k=\{a\in E(H):w_a\ge\lambda_k\}.\)

Every path in \(H_k\) has quality at least \(\lambda_k\).

2. A polynomial-size linear program

For each threshold \(k\), replace every edge \(a=\{u,v\}\in E_k\) by two directed arcs, retaining the identity of \(a\). Let \(A_k\) be this directed arc set.

Introduce nonnegative variables \(f_{k,a,u\to v}\) and \(f_{k,a,v\to u}\) for these arcs, and a nonnegative variable \(z_k\) for the flow value in layer \(k\).

Define \(b(s)=1\), \(b(t)=-1\), and \(b(v)=0\) at every other vertex. Impose flow conservation:

\(\displaystyle \sum_{\alpha\in\delta_k^+(v)}f_{k,\alpha} -\sum_{\alpha\in\delta_k^-(v)}f_{k,\alpha} =b(v)z_k \qquad(k=1,\ldots,d,\ v\in V(H)). \)

Here \(\delta_k^+(v)\) and \(\delta_k^-(v)\) denote the outgoing and incoming arcs at \(v\) in \(A_k\).

All layers share each role’s capacity:

\(\displaystyle \sum_{k:\,a\in E_k} \bigl(f_{k,a,u\to v}+f_{k,a,v\to u}\bigr) \le\mu_a \qquad(a=\{u,v\}\in E(H)). \)

Maximize

\(\displaystyle \sum_{k=1}^{d}\lambda_k z_k.\)

Call this linear program \(P\).

It is feasible: all variables can be zero. Every arc variable is at most its role’s mass, hence at most \(1\). Conservation at \(s\) also gives

\(\displaystyle 0\le z_k \le\sum_{\alpha\in\delta_k^+(s)}f_{k,\alpha} \le\sum_{a\in E(H)}\mu_a \le1. \)

Thus its feasible region is bounded and closed, and its optimum is attained.

3. Proof that the formulation is exact

From a path assignment to layered flows

Take any feasible assignment \((x_r)\). Its positive-mass paths lie in \(H\).

Every such path has quality equal to one of the thresholds. Assign \(r\) to the unique layer \(k\) satisfying \(q(r)=\lambda_k\), and send \(x_r\) units along its directed orientation from \(s\) to \(t\).

These flows satisfy conservation. Their aggregate consumption of role \(a\) is exactly

\(\displaystyle \sum_{r\ni a}x_r\le\mu_a,\)

so they satisfy the shared capacities. Moreover,

\(\displaystyle \sum_k\lambda_k z_k =\sum_r q(r)x_r. \)

Therefore

\(\displaystyle \operatorname{OPT}\le\operatorname{OPT}(P).\)

From layered flows to simple paths

Take any feasible solution of \(P\). We first justify the required decomposition for one layer \(k\).

Add a distinguished artificial arc \(t\to s\) carrying \(z_k\) units. Conservation now holds at every vertex, including \(s,t\), so the augmented flow is a nonnegative circulation.

Circulation decomposition. Every nonzero nonnegative circulation on a finite directed multigraph decomposes into finitely many simple directed cycles with nonnegative masses.

To prove this, start from a positive-flow arc and continue following positive-flow arcs. Whenever a vertex is reached along a positive-flow arc, conservation guarantees a positive-flow outgoing arc. Finiteness forces a repeated vertex; the segment between the first repetition is a simple directed cycle. Subtract the minimum flow on its arcs. The remainder is a nonnegative circulation, and at least one positive-flow arc disappears. Repetition terminates after at most the initial number of positive-flow arcs.

Apply this decomposition to the augmented layer:

  • A simple cycle containing the distinguished artificial arc becomes a simple directed \(s\)-to-\(t\) path when that arc is removed.
  • Discard every cycle not containing the artificial arc.

The masses of the retained paths sum to \(z_k\), because the cycle decomposition accounts for all \(z_k\) units on the artificial arc. Their consumption of each original directed arc is at most its original flow.

After forgetting orientations, each retained path is a simple path in \(H_k\), with its edge-role identities preserved. Hence its quality is at least \(\lambda_k\).

Perform this construction in every layer and aggregate masses assigned to identical paths. For each role \(a=\{u,v\}\), the resulting assignment satisfies

\(\displaystyle \sum_{r\ni a}x_r \le \sum_{k:\,a\in E_k} \bigl(f_{k,a,u\to v}+f_{k,a,v\to u}\bigr) \le\mu_a. \)

It is therefore feasible for the original problem. Its value is at least the layered objective:

\(\displaystyle \sum_r q(r)x_r \ge\sum_k\lambda_k z_k. \)

Taking an optimal solution of \(P\) gives

\(\displaystyle \operatorname{OPT}\ge\operatorname{OPT}(P).\)

Combining both directions proves

\(\displaystyle \boxed{\operatorname{OPT}=\operatorname{OPT}(P)}.\)

The inequality in the second direction is intentional: a path extracted from layer \(k\) may have quality strictly greater than its credited threshold \(\lambda_k\). This only improves the original assignment.

4. Exact decision and running time

The formulation has

\(\displaystyle N=2\sum_{k=1}^{d}|E_k|+d \le2d\tau+d \)

variables, at most \(\tau\) shared-capacity inequalities, and \(dh\) conservation equations. Nonnegativity contributes another \(N\) inequalities. Therefore

\(\displaystyle N=O(d\tau),\qquad C=O(d\tau+dh+\tau). \)

Before removing isolated vertices, these bounds are \(O(\tau^2)\) variables and \(O(\tau^2+\tau|V|)\) constraints. After the support restriction and vertex removal, both are \(O(\tau^2)\), since \(h\le2\tau+2\).

All constraint-matrix coefficients belong to \(\{-1,0,1\}\). The nonzero right-hand sides are input masses, and the nonzero objective coefficients are distinct input weights. Consequently, even a dense encoding of \(P\) has total binary length

\(\displaystyle B=O(\tau^4+L).\)

The rational linear-programming theorem provides an algorithm that returns an exact rational optimal solution in time polynomial in the LP’s binary encoding length. This applies here because \(P\) is explicitly represented, has rational coefficients, is feasible, and is bounded. Exact rational optimization, including recovery of an optimal rational solution, is discussed in [Trevisan’s linear-programming notes, Sections 2.4–2.5](https://lucatrevisan.github.io/cs261/lecture05.pdf).

Compute its rational objective value \(v^*\), then compare it exactly with the rational input \(K\), using integer cross multiplication with positive denominators. The optimal solution and objective have polynomial encoding length, so this comparison also takes polynomial bit time. In particular, equality with \(K\) is handled exactly.

A valid total bit-time bound, including preprocessing, is

\(\displaystyle (\tau^4+L)^{O(1)}. \)

Since \(\tau\le m\), this also gives the requested bound

\(\displaystyle (m+\tau+|V|+L)^{O(1)}. \)

The graph preprocessing uses \(O(m+|V|)\) graph operations if the full graph is scanned, followed by \(O(\tau\log\tau)\) rational weight comparisons. The optimization stage depends on unsupported edges and discarded vertices only through the input-reading cost.

Finally, the cited hardness result concerns partitions of indivisible edge agents, as stated in [*Cooperative Weakest Link Games*](https://www.ifaamas.org/Proceedings/aamas2014/aamas/p589.pdf). Such a partition restricts role sharing. The continuous formulation permits fractional sharing, and the proof above establishes polynomial-time exact optimization for that formulation.
