The continuous mirror question, as graded

Given finite applicant and position type sets \(I,J\), rational applicant masses \(\mu_i\) summing to \(1\), rational per-applicant position supplies \(q_j\), and acceptable pairs \(E\) with ranks \(r_{ij}\), define feasible flows by \(\sum_j x_{ij}\le\mu_i\) and \(\sum_i x_{ij}\le q_j\). Lexicographically maximize the rank totals \(z_\ell(x)=\sum_{(i,j)\in E:\,r_{ij}=\ell}x_{ij}\). Output every pair \((i,j)\in E\) for which some lexicographically optimal flow has \(x_{ij}>0\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) applicant types \(I\) with positive masses \(\mu_i\), each a binary rational, with \(\sum_{i\in I}\mu_i=1\). Here \(\tau=|I|\) is the support size, not the number of possible preference types.
There are \(m=|J|\) position types, with binary rational supplies \(q_j\geq0\) measured per unit applicant mass; their sum need not equal \(1\). Acceptable pairs \(E\subseteq I\times J\) and positive integer ranks \(r_{ij}\), encoded in binary, are explicitly listed. Lower ranks are preferred; equal ranks represent indifference, with no tie-breaking.
A feasible flow has real entries \(x_{ij}\geq0\) on \(E\), with \(\sum_{j:(i,j)\in E}x_{ij}\leq\mu_i\) and \(\sum_{i:(i,j)\in E}x_{ij}\leq q_j\). Unassigned mass is allowed; unacceptable pairs carry no flow.
Set \(r=\max(\{1\}\cup\{r_{ij}:(i,j)\in E\})\) and \(z_\ell(x)=\sum_{(i,j)\in E:r_{ij}=\ell}x_{ij}\). A flow is rank-maximal if it lexicographically maximizes \((z_1(x),\ldots,z_r(x))\).
The required output is \(S=\{(i,j)\in E:\text{some rank-maximal flow }x\text{ has }x_{ij}>0\}\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\), and any additional parameters used.

Is computing \(S\) solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite applicants and unit-capacity posts, computing every pair occurring in some rank-maximal matching is polynomial-time solvable, including with tied preferences. [Ghosal, Nasre, and Nimbhorkar](https://arxiv.org/pdf/1409.4977).
The search identified no result settling this exact problem with rational masses and supplies given by support.

Modeling choices made when packaging the task

  • Interpreted applicant types as the positive-mass support, with support size tau, and used m for the number of position types.
  • Specified nonnegative rational position supplies in the same units as applicant mass, without normalizing their sum.
  • Specified nonnegative real flows restricted to acceptable pairs and allowed unassigned applicant mass, as discrete matchings may leave applicants unmatched.
  • Specified positive integer ranks encoded in binary, allowing ties and rank gaps, without tie-breaking.
  • Defined the maximum rank as 1 when the acceptable-pair set is empty.
  • Defined L as the total input bit length so that rational data and rank encodings are included.

Result

Computing \(S\) is polynomial-time solvable in \(m,\tau,L\). An exact algorithm uses at most \(2|E|\) rational linear-programming optimizations. Binary rank labels, tied preferences, and arbitrary nonnegative rational supplies are all covered.

1. Compress the rank labels

Write \(n=|E|\). If \(n=0\), return \(S=\varnothing\). Assume henceforth that \(n>0\).

Let \(a_1<\cdots<a_k\) be the distinct ranks occurring on acceptable pairs, so \(k\leq n\). Define

\(c_t(x)=\sum_{(i,j)\in E:\,r_{ij}=a_t}x_{ij}\), for \(1\leq t\leq k\).

Every omitted rank has identically zero assigned mass. Consequently, lexicographically maximizing the original rank vector is equivalent to lexicographically maximizing \((c_1(x),\ldots,c_k(x))\).

Sorting the explicitly listed binary rank labels takes polynomial time in \(n,L\). The algorithm therefore need not iterate up to the numerical value of \(r\).

2. Identify exactly the rank-maximal flows

Let \(P\subseteq\mathbb{R}^{E}\) be the feasible-flow polytope defined in the question. It is nonempty because the zero flow is feasible. Moreover, every \(x\in P\) satisfies

\(\sum_{(i,j)\in E}x_{ij}\leq\sum_{i\in I}\mu_i=1\).

Thus \(P\subseteq[0,1]^n\), and \(P\) is compact.

Starting with \(P_0=P\), perform the following operations for \(t=1,\ldots,k\):

\(\alpha_t=\max\{c_t(x):x\in P_{t-1}\}\),

\(P_t=\{x\in P_{t-1}:c_t(x)=\alpha_t\}\).

Each maximum exists, and each \(P_t\) is nonempty and compact. Its explicit LP description consists of the original feasibility constraints and the equalities \(c_h(x)=\alpha_h\) for \(1\leq h\leq t\).

Claim. \(P_k\) is exactly the set of rank-maximal flows.

Proof. Every point of \(P_k\) has compressed rank vector \((\alpha_1,\ldots,\alpha_k)\). If \(y\in P\setminus P_k\), let \(t\) be the first index for which \(y\notin P_t\). Then \(y\in P_{t-1}\), so

\(c_h(y)=\alpha_h\) for \(h<t\), and \(c_t(y)<\alpha_t\).

Hence every point of \(P_k\) has a lexicographically larger rank vector than \(y\). Points of \(P_k\) all have the same rank vector, so they are precisely the lexicographic maximizers. \(\square\)

3. Recover every pair that can occur

For each \(e=(i,j)\in E\), solve the LP

\(\beta_e=\max\{x_{ij}:x\in P_k\}\).

Return

\(S=\{e\in E:\beta_e>0\}\).

This criterion is exact. If a rank-maximal flow has \(x_{ij}>0\), then \(\beta_e>0\). Conversely, if \(\beta_e>0\), compactness guarantees an attaining flow in \(P_k\), and that rank-maximal flow has positive flow on \(e\).

It remains to prove that the intermediate LP descriptions have polynomial bit length.

4. Polynomial bit length of the optimal values

We first justify why it suffices to bound vertices of the original polytope \(P\).

A face of a convex set has the following property: if an interior point of a segment between two points of the set belongs to the face, both endpoints belong to the face. Maximizers of a linear function satisfy this property: both endpoint objective values are at most the maximum, so their strict convex combination equals the maximum only if both equal it.

Therefore \(P_t\) is a face of \(P_{t-1}\). The segment property also proves transitivity of faces, so every \(P_t\) is a face of \(P\). A vertex of a face is a vertex of the original polytope: any nontrivial segment decomposition in the original polytope would, by the face property, be a decomposition inside the face.

A linear function on a nonempty compact polytope attains its maximum at a vertex, because the polytope is the convex hull of its vertices. Consequently, every \(\alpha_t\) and every \(\beta_e\) is attained at a vertex of \(P\).

Let \(D\) be the product of the denominators of all input masses and supplies. Its binary length is \(O(L)\), and multiplying any original constraint right-hand side by \(D\) gives an integer.

At a vertex \(v\) of \(P\), there are \(n\) linearly independent active constraints. Indeed, otherwise there would be a nonzero direction annihilated by every active constraint; sufficiently small displacements in both directions would preserve the inactive inequalities as well, contradicting extremality.

Those active constraints give a nonsingular system

\(Mv=b\),

where \(M\) is an integer matrix with entries in \(\{-1,0,1\}\), and \(Db\) is integral. Cramer’s rule implies that every coordinate of \(v\), and every integer-coefficient sum of its coordinates, has a representation with denominator \(D|\det M|\).

By Hadamard’s determinant inequality,

\(1\leq|\det M|\leq n^{n/2}\).

Each coordinate of \(v\), and each rank sum \(c_t(v)\), belongs to \([0,1]\). In a representation with positive denominator \(D|\det M|\), the numerator therefore lies between zero and that denominator. Thus their rational encoding lengths are bounded by

\(H=O\!\left(L+n\log(n+1)\right)\).

Since all intermediate optima are attained at original vertices, this bound applies uniformly to every \(\alpha_t\) and \(\beta_e\). In particular, adding successive optimal-value equalities does not cause uncontrolled growth in bit length.

5. Running time

We use the standard rational LP theorem: a linear program with rational data can be solved exactly in time polynomial in its total binary encoding length, including on a feasible set of lower dimension. For a nonempty bounded feasible set, this yields an exact rational optimum and an attaining solution. Polynomial-time rational LP follows from [Khachiyan’s polynomial algorithms for linear programming](https://www.mathnet.ru/eng/zvmmf5239).

Let \(T_{\mathrm{LP}}(N,C,B)\) denote such a polynomial bit-time bound for \(N\) variables, at most \(C\) inequalities, and total encoding length at most \(B\).

Every LP above has \(n\) variables. Counting nonnegativity constraints and replacing equalities by two inequalities, we may take

\(C=\tau+m+n+2k\).

A conservative dense-encoding bound is

\(B=O\!\left(L+nC+k\bigl(L+n\log(n+1)\bigr)\right)\).

Here the original right-hand sides contribute \(O(L)\) bits, the constraint matrix contributes \(O(nC)\), and the added optimal-value right-hand sides contribute \(O(kH)\).

The algorithm makes \(k+n\leq2n\) LP calls. Its running time is therefore

\(O\!\left((k+n)\,T_{\mathrm{LP}}(n,C,B)+\operatorname{poly}(m,\tau,L)\right)\).

Since \(k\leq n\leq\tau m\), this is polynomial in \(m,\tau,L\). All positivity comparisons use exact rational values.

The construction keeps applicant types aggregated throughout. It handles ties by optimizing the total mass at each distinct rank, and it imposes no condition on the sum of the position supplies.
