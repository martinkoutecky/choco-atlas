The continuous mirror question, as graded

Given \(\tau\) complete binary CP-nets \(N_1,\ldots,N_\tau\), each with a chain or tree dependency graph, a rational mass vector \(\mu\in\mathbb{Q}_{\ge 0}^{\tau}\) with \(\sum_t\mu_t=1\), outcomes \(x,y\in\{0,1\}^n\), and \(q\in[0,1]\), compute \(D_\mu(x,y)=\sum_{t:x\succ_{N_t}y}\mu_t\), where \(x\succ_{N_t}y\) means that \(N_t\) entails an improving flipping sequence from \(y\) to \(x\), and decide whether \(D_\mu(x,y)\ge q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) distinct types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type is a complete binary CP-net \(N_t\) on the same \(m\ge1\) variables: its graph is a rooted tree directed from parent to child (a directed chain is allowed), and its explicitly listed conditional preference tables specify a strict order on \(\{0,1\}\) for every assignment to each variable's parents. Different types may have different graphs.
An improving flip changes exactly one variable to its strictly preferred value under its current parent assignment, leaving all other variables fixed. Write \(x\succ_{N_t}y\) when a nonempty sequence of improving flips leads from \(y\) to \(x\); in particular, \(x\not\succ_{N_t}x\).
Given outcomes \(x,y\in\{0,1\}^m\) and a binary-rational threshold \(q\in[0,1]\), define \(D_\mu(x,y)=\sum_{t:x\succ_{N_t}y}\mu_t\). Let \(L\) be the total binary input length.

Is deciding whether \(D_\mu(x,y)\ge q\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? What is the complexity of computing \(D_\mu(x,y)\) exactly? State running times in \(m,\tau,L\).

For a single binary chain or tree CP-net, rightmost search with suffix fixing and extension is complete and backtrack-free; later work establishes quadratic-time dominance testing ([Boutilier et al., 2004](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume21/boutilier04a.pdf)).
[Bigot et al., 2013](https://www.auai.org/uai2013/prints/papers/225.pdf) establish linear-time deterministic tree dominance and an FPT algorithm for dominance probability under independently sampled conditional preference rules; that distribution representation differs from the explicit support used here.

Modeling choices made when packaging the task

  • Made the threshold q a binary rational so the decision input has a finite encoding.
  • Removed zero-mass entries and merged identical types to follow the positive-support convention.
  • Specified strict conditional preferences, following the anchor's algorithms, which omit indifference.
  • Interpreted tree structure as a rooted outward-directed tree with at most one parent per variable, rather than a polytree.
  • Specified a nonempty improving sequence for strict dominance, including when the queried outcomes coincide.

Result

The threshold problem is in \(\mathrm{P}\), and exact computation of \(D_\mu(x,y)\) is in \(\mathrm{FP}\).

For explicitly listed support, the dominance tests require \(O(\tau m)\) operations using the linear-time deterministic tree algorithm. Including input processing and exact rational arithmetic, a conservative bound is \(O(L+\tau m\log(L+2)+L^2)\) bit operations, hence \(O(L^2)\) under the ordinary explicit binary encoding.

Consequently, the threshold problem can be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).

1. Applicable deterministic dominance theorem

We use the following established result: dominance between two outcomes in a deterministic binary tree CP-net with \(m\) variables can be decided in \(O(m)\) time. This is Theorem 2 of [Bigot et al. (2013), Section 4.3](https://www.auai.org/uai2013/prints/papers/225.pdf).

Its hypotheses hold separately for every listed type:

  • Every variable has the binary domain \(\{0,1\}\).
  • The dependency graph is a rooted tree directed from parent to child.
  • Every conditional preference table is complete and deterministic, specifying a strict order for each parent assignment.

In particular, each nonroot variable has exactly one parent and two table rows. The root has one row, so each type has \(O(m)\) table entries. A directed chain is a special case of the required tree structure.

The theorem’s dominance relation agrees with the question’s improving-flip reachability: reversing a worsening sequence from \(x\) to \(y\) gives an improving sequence from \(y\) to \(x\). We handle \(x=y\) explicitly by returning false, as required by the question’s strict convention.

The linear bound concerns deciding existence of a sequence, without constructing it. Alternatively, the earlier TreeDT algorithm gives an \(O(m^2)\) bound per type. [Boutilier et al. (2004), Theorem 12](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume21/boutilier04a.pdf).

2. Algorithm and correctness

If \(x=y\), output \(D_\mu(x,y)=0\). Otherwise, for each \(t\in\{1,\ldots,\tau\}\), compute

\(b_t=\mathbf{1}[x\succ_{N_t}y]\)

using the deterministic tree dominance algorithm. Then compute the rational number

\(S=\sum_{t=1}^{\tau}b_t\mu_t\)

exactly. For the threshold problem, return whether \(S\ge q\).

Correctness. Each dominance test establishes exactly whether its type belongs to the set \(\{t:x\succ_{N_t}y\}\). Thus the summands selected by the algorithm are precisely those in the definition of \(D_\mu(x,y)\), and \(S=D_\mu(x,y)\). Exact rational comparison therefore answers the threshold question correctly.

The graphs may differ between types: each test uses its own graph, and aggregation uses only the resulting indicators and masses.

3. Exact arithmetic and output length

We give bounds allowing general fractions whose numerators and denominators are written in binary; they also apply to explicitly written finite binary fractions.

Write \(\mu_t=a_t/d_t\), where \(a_t,d_t\) are positive integers. Maintain an unreduced fraction \(A/B\), initially \(0/1\). Whenever \(b_t=1\), update

\(A\leftarrow A d_t+a_tB,\qquad B\leftarrow B d_t,\)

with both right-hand sides evaluated using the old values.

These updates preserve the exact partial sum. Moreover,

\(B=\prod_{t\text{ included so far}}d_t.\)

The sum of the binary lengths of all input denominators is at most \(L\). Hence \(B\) has \(O(L)\) bits. Since the masses are positive and sum to one, every selected partial sum lies in \([0,1]\); consequently \(0\le A\le B\), so \(A\) also has \(O(L)\) bits. The exact output therefore has polynomial length.

For completeness, schoolbook arithmetic suffices for an \(O(L^2)\) aggregation bound. If \(a_t,d_t\) have bit lengths \(\alpha_t,\delta_t\), the multiplications at that update cost \(O(L(\alpha_t+\delta_t))\), and addition costs \(O(L)\). Summing over selected types gives

\(O\!\left(L\sum_t(\alpha_t+\delta_t)+\tau L\right)=O(L^2),\)

because \(\sum_t(\alpha_t+\delta_t)\le L\) and \(\tau\le L\). If a reduced fraction is desired, a final greatest-common-divisor computation and exact divisions also fit within \(O(L^2)\) using classical integer algorithms.

Finally, write \(q=c/d\), with \(d>0\). Compare \(Ad\) and \(cB\). This exact comparison costs \(O(L^2)\) bit operations.

4. Running times and representation

Using the linear-time dominance theorem, all dominance tests together take \(O(\tau m)\) elementary operations on the usual word RAM. Input processing costs \(O(L)\), and the rational arithmetic above costs \(O(L^2)\) bit operations.

Charging conservatively \(O(\log(L+2))\) bit operations per structural word operation yields the overall bound

\(O(L+\tau m\log(L+2)+L^2).\)

The explicit support contains \(\Omega(\tau m)\) table information, so \(\tau m=O(L)\), and this bound is \(O(L^2)\). Using quadratic TreeDT instead gives the conservative bound \(O(L+\tau m^2\log(L+2)+L^2)\), which also proves polynomial-time solvability.

These bounds apply to both exact computation and threshold decision. The probabilistic algorithm for independently sampled preference rules is unnecessary here: every supported deterministic type is explicitly available, and the required probability is exactly its weighted indicator sum.

1. Deterministic dominance theorem

The citation is correct. Theorem 2 in Section 4.3 of [Bigot et al. (2013)](https://www.auai.org/uai2013/prints/papers/225.pdf) establishes linear-time deterministic tree dominance. The paper’s relevant setting is binary variables with an acyclic graph assigning at most one parent to each variable.

Every supported type satisfies these hypotheses:

  • Its domain is binary.
  • Its rooted tree is acyclic and has at most one parent per variable.
  • Its tables specify complete, deterministic, strict local preferences.

The claimed table size is correct: there is one root row and two rows for each nonroot variable, giving \(2m-1\) rows per type. Chains and the single-variable case are included.

The reversal of worsening sequences into improving sequences preserves validity: a flip changes only its own variable, so its parent assignment is unchanged across that flip. The explicit exclusion of equal outcomes respects the task’s strict dominance convention.

The alternative citation is also correct. Theorem 12 of [Boutilier et al. (2004)](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume21/boutilier04a.pdf) gives quadratic-time flipping-sequence search for binary tree CP-nets. Neither citation introduces an unverified hypothesis.

The fraction update is correct, provided both right-hand sides use the old values as expressly stated. It preserves the selected partial sum.

The denominator product satisfies
\[ \log_2 B=\sum_{t\text{ included}}\log_2 d_t\le L. \]
Thus \(B\) has \(O(L)\) bits. Positivity and normalization of the masses ensure that every selected partial sum lies in \([0,1]\), so \(0\le A\le B\). The numerator therefore also has \(O(L)\) bits. No intermediate or output size becomes exponential.

The schoolbook multiplication accounting is valid. Multiplying an \(O(L)\)-bit accumulator by an input integer of bit length \(\alpha_t\) or \(\delta_t\) costs respectively \(O(L\alpha_t)\) or \(O(L\delta_t)\). Summing these costs and the additions gives
\[ O\!\left(L\sum_t(\alpha_t+\delta_t)+\tau L\right)=O(L^2). \]
Both inequalities used here, \(\sum_t(\alpha_t+\delta_t)\le L\) and \(\tau\le L\), follow from explicit input encoding.

The asserted optional reduction by classical greatest-common-divisor computation and exact division fits the quadratic bound. Cross-multiplication for comparison with \(q=c/d\) also fits \(O(L^2)\), with the comparison direction preserved because both denominators are positive.

The argument explicitly covers binary-encoded numerator–denominator fractions and explicitly written finite binary fractions. It does not rely on a succinct representation of exponentially long denominators.
