The continuous mirror question, as graded

Given a finite argument set \(A\), a fixed irreflexive master attack relation \(\alpha\), a bound \(k\ge 3\), and a rational distribution \(\mu\) over report types \(t=(A_t,D_t)\), does there exist a value set \(V\) with \(|V|\le k\), a common map \(\mathrm{val}:A\to V\), and a preorder \(\succeq_t\) for each \(t\) with \(\mu_t>0\), such that for every \(a,b\in A_t\), \((a,b)\in D_t\) if and only if \((a,b)\in\alpha\) and \(\mathrm{val}(b)\not\succ_t\mathrm{val}(a)\)?

Packaged proof task (what the prover saw — nothing else)

Given a finite argument set \(A\), let \(m=|A|\). The input includes an irreflexive master attack relation \(\alpha\subseteq A\times A\) and a binary-encoded integer \(k\ge 3\).
A society is given by its support: a list of \(\tau\) distinct report types \(t=(A_t,D_t)\), each with a positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
Each \(A_t\subseteq A\), with \(A=\bigcup_t A_t\), and each \(D_t\subseteq A_t\times A_t\) is irreflexive. Reports may use different argument sets.
A rationalisation consists of a finite value set \(V\) with \(|V|\le k\), a common map \(\mathrm{val}:A\to V\), and a preorder \(\succeq_t\) on \(V\) for every supported type. Preorders may allow indifference and incomparability; \(\succ_t\) denotes their strict part.
It must satisfy, for every supported \(t\) and every \(a,b\in A_t\), \((a,b)\in D_t\iff (a,b)\in\alpha\ \land\ \neg(\mathrm{val}(b)\succ_t\mathrm{val}(a))\).

Is deciding whether such a rationalisation exists solvable in polynomial time in \(m,\tau,L\), including the binary encoding of \(k\), or is it \(\mathrm{NP}\)-hard?

For a finite list of agents, this decision problem with a fixed master attack relation and a value bound of at least three is \(\mathrm{NP}\)-complete. With both the master attack relation and the value-labelling fixed, discrete rationalisability is decidable in polynomial time.

Modeling choices made when packaging the task

  • Normalized the rational masses to sum to one, as required by a distribution, and retained only positive-mass types.
  • Required the argument set to equal the union of the supported report argument sets, following the discrete definition.
  • Specified that report defeat relations are irreflexive relations on their respective argument sets.
  • Allowed incomplete preorders, including indifference and incomparability, following the discrete preference domain.
  • Encoded the value bound in binary and defined L as the total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete, already for the fixed bound \(k=3\), equal masses, empty defeat relations, and reports containing at most two arguments. Consequently, a polynomial-time algorithm in \(m,\tau,L\) exists only if \(\mathrm{P}=\mathrm{NP}\).

Here the master relation is part of the input, as specified in the question, and is common to all reports.

1. Membership in \(\mathrm{NP}\)

A preorder is a reflexive, transitive relation. Its strict part satisfies \(x\succ_t y\) precisely when \(x\succeq_t y\) and \(y\not\succeq_t x\).

If \(m=0\), every valid instance is feasible. Assume henceforth that \(m\ge1\).

Suppose a rationalisation exists. Restrict its value set to the image \(V'=\mathrm{val}(A)\), and restrict every preorder to \(V'\times V'\). These restrictions remain reflexive and transitive. Moreover, for any two used values, both directions of the preorder are unchanged, so their strict comparison is unchanged. Thus the restricted rationalisation remains valid and uses \(q=|V'|\le\min(k,m)\) values.

After renaming those values, a certificate consists of:

  • An integer \(q\) satisfying \(1\le q\le\min(k,m)\).
  • A map \(f:A\to\{1,\ldots,q\}\).
  • For each supported type \(t\), a Boolean matrix \(S_t\) representing its preorder.

The verifier checks reflexivity and transitivity of each matrix. It then checks, for every \(a,b\in A_t\), the equivalence
\((a,b)\in D_t\iff (a,b)\in\alpha\land\neg\bigl(S_t[f(b),f(a)]\land\neg S_t[f(a),f(b)]\bigr)\).

The certificate uses \(O(m\log(m+1)+\tau m^2)\) bits. Transitivity checks take \(O(\tau m^3)\) Boolean operations, and the report checks take \(O(\tau m^2)\).

Crucially, the verifier compares \(q\) with the binary-encoded \(k\); it never allocates a structure of size \(k\). Input validity, including positivity and exact normalization of rational masses, can also be checked in polynomial time using exact integer arithmetic. The product of all input denominators has bit length bounded by their total input bit length.

Therefore the problem belongs to \(\mathrm{NP}\).

2. A polynomial reduction from graph three-colourability

We use the standard theorem that deciding whether a finite simple undirected graph admits a proper colouring with at most three colours is \(\mathrm{NP}\)-complete. See [Garey, Johnson, and Stockmeyer, *Some simplified NP-complete graph problems*](https://doi.org/10.1016/0304-3975%2876%2990059-1).

Let \(G=(U,E)\) be such a graph. We may assume \(U\ne\varnothing\): adding an isolated vertex preserves three-colourability. Fix an ordering of \(U\).

Construct the instance as follows:

  • Set \(A=U\) and \(k=3\).
  • Orient each edge according to the ordering, defining \(\alpha=\{(u,v):\{u,v\}\in E,\ u<v\}\).
  • For every edge \(\{u,v\}\in E\), create the report type \(t_{\{u,v\}}=(\{u,v\},\varnothing)\).
  • For every vertex \(u\in U\), create the singleton report type \(s_u=(\{u\},\varnothing)\).
  • Give every type mass \(1/\tau\), where \(\tau=|E|+|U|\).

These types are distinct: different edges have different endpoint sets, different singleton types have different vertices, and singleton sets differ from two-element sets. Their argument sets cover \(A\), their masses are positive and sum to one, and both the master relation and every report relation are irreflexive.

The construction has polynomial size. In particular, each mass has a binary representation of length \(O(\log(\tau+1))\).

Rationalisation implies a proper three-colouring

Suppose the constructed instance has a rationalisation.

Consider an edge \(\{u,v\}\in E\), with \(u<v\). In its report, \((u,v)\in\alpha\) but \((u,v)\notin D_{t_{\{u,v\}}}\). The required equivalence therefore forces
\(\mathrm{val}(v)\succ_{t_{\{u,v\}}}\mathrm{val}(u)\).

The strict part of any preorder is irreflexive: \(x\succ_t x\) would require both \(x\succeq_t x\) and its negation. Hence \(\mathrm{val}(u)\ne\mathrm{val}(v)\).

This holds for every graph edge. The value map therefore gives a proper colouring using at most three colours.

A proper three-colouring implies rationalisation

Conversely, suppose \(c:U\to\{1,2,3\}\) is a proper colouring. Set \(V=\{1,2,3\}\) and \(\mathrm{val}=c\).

For the report corresponding to an edge \(\{u,v\}\), with \(u<v\), define
\(\succeq_{t_{\{u,v\}}}=\{(x,x):x\in V\}\cup\{(c(v),c(u))\}\).

Because the colouring is proper, \(c(v)\ne c(u)\). This relation is reflexive and transitive. To verify transitivity, compositions involving an identity pair preserve the other pair; two nonidentity pairs cannot compose, because that would require \(c(u)=c(v)\). Also, the reverse pair \((c(u),c(v))\) is absent. Thus \(c(v)\succ_{t_{\{u,v\}}}c(u)\).

Within this report’s argument set, the only master attack is \((u,v)\). That attack is suppressed by the strict comparison just established. Every other ordered pair is absent from \(\alpha\), so the required equivalence makes it absent from the defeat relation as well. The resulting defeat relation is exactly \(\varnothing\), as required.

For each singleton report, use the identity preorder on \(V\). Its only argument pair is diagonal, and the master relation is irreflexive, so its defeat relation is likewise empty.

These choices rationalise every supported type.

3. Consequence for the support representation

We have proved that \(G\) is three-colourable if and only if the constructed support instance is rationalisable with \(k=3\). This establishes \(\mathrm{NP}\)-hardness; membership proved above establishes \(\mathrm{NP}\)-completeness.

The masses do not change this conclusion. Feasibility requires a suitable preorder for each supported report, independently of its positive mass. The reduction uses only \(\tau=|E|+|U|\) explicitly listed types and equal masses of polynomial bit length. It requires neither expansion into individual agents nor enumeration of possible report types.
