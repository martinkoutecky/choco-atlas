The continuous mirror question, as graded

Given a planar role graph \(H=(T,F)\), positive rational masses \(\mu_t\) summing to \(1\), rational interaction densities \(a_{tu}\) on edges, and a rational threshold \(K\), decide whether the population mass can be partitioned into coalitions with total value at least \(K\). A coalition \(q\) has mass vector \(x^q\), where \(x_t^q\ge 0\) and \(\sum_q x_t^q=\mu_t\); its total value is \(\sum_q\sum_{\{t,u\}\in F}a_{tu}x_t^q x_u^q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq 1\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a connected simple undirected planar role graph \(H=(T,F)\), signed binary rational interaction densities \(a_{tu}\) for \(\{t,u\}\in F\), and a binary rational threshold \(K\). Write \(m=|F|\) and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A feasible partition is any finite family of nonzero vectors \(x^1,\ldots,x^Q\in\mathbb{R}_{\geq 0}^{T}\), with \(Q\) unrestricted, such that \(\sum_{q=1}^{Q}x_t^q=\mu_t\) for every type. Each coalition's positive support \(\{t:x_t^q>0\}\) must induce a connected subgraph of \(H\); singleton supports are allowed.
Its total value is \(V=\sum_{q=1}^{Q}\sum_{\{t,u\}\in F}a_{tu}x_t^qx_u^q\). There are no within-type interactions or additional terms. The decision problem asks whether a feasible partition has \(V\geq K\).

Is this continuous decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

The discrete decision problem, partitioning planar graph vertices into connected coalitions and summing weights of edges internal to coalitions, is NP-complete ([Voice, Polukarov and Jennings](https://doi.org/10.1613/jair.3715)). No complexity result for this exact continuous mass model was located in the literature search.

  • Interaction densities may be positive, negative or zero, following the discrete edge-weight domain; the threshold may have either sign.
  • Restored connectedness of every coalition's positive type support, with singleton supports allowed, following the intended discrete coalition constraint.
  • Specified a finite but unrestricted number of nonempty coalitions, following finite discrete coalition structures; coalition masses are real and divisible.

Result

The continuous decision problem is \(\mathrm{NP}\)-complete.

The key fact is that splitting a type’s mass cannot improve the optimum: every feasible continuous partition is dominated by a feasible partition in which each type places its entire mass in one coalition. This holds for arbitrary signed interaction densities.

1. Rounding without decreasing value

Call a feasible partition unsplit if, for each type \(t\), exactly one coalition contains its entire mass \(\mu_t\).

Lemma. Every feasible continuous partition has an unsplit feasible partition of at least the same value.

Proof. Fix any feasible family \(x^1,\ldots,x^Q\). Since \(\mu_t>0\), define

\(p_t^q=x_t^q/\mu_t\).

For each \(t\), these numbers are nonnegative and satisfy \(\sum_{q=1}^Q p_t^q=1\). Independently for each type, choose a random label \(Z_t\) with \(\Pr(Z_t=q)=p_t^q\). Assign the entire mass \(\mu_t\) to that label.

Temporarily disregard connectedness. The resulting value is

\(W(Z)=\sum_{\{t,u\}\in F}a_{tu}\mu_t\mu_u\,\mathbf{1}_{\{Z_t=Z_u\}}\).

Every edge has distinct endpoints because the graph is simple. Independence therefore gives

\(\Pr(Z_t=Z_u)=\sum_{q=1}^Q p_t^q p_u^q\).

Consequently,

\(\mathbb{E}[W(Z)] =\sum_{\{t,u\}\in F}a_{tu}\mu_t\mu_u\sum_{q=1}^Q p_t^q p_u^q =\sum_{q=1}^Q\sum_{\{t,u\}\in F}a_{tu}x_t^q x_u^q =V.\)

This is an equality, so negative densities cause no difficulty. The random experiment has finitely many outcomes; hence some outcome satisfies \(W(Z)\geq V\).

Fix such an outcome. For each nonempty label class \(S_q=\{t:Z_t=q\}\), split \(S_q\) into the connected components of \(H[S_q]\). Give every resulting component its own coalition, containing the full masses of its types.

This operation preserves the value. Indeed, if the endpoints of an edge had the same label, that edge itself connects them within the corresponding induced subgraph, so they remain in the same component. Endpoints with different labels remain separated. Thus every edge’s contribution is unchanged.

The resulting partition is feasible and unsplit, and has at most \(\tau\) coalitions. Its value is at least \(V\). \(\square\)

2. Exact equivalence with a discrete problem

Define the effective edge weights

\(b_{tu}=a_{tu}\mu_t\mu_u.\)

For a partition \(\mathcal{P}\) of \(T\) into nonempty connected blocks, define

\(D(\mathcal{P}) =\sum_{C\in\mathcal{P}}\sum_{\{t,u\}\in F:\,t,u\in C}b_{tu}.\)

Every such partition gives a feasible continuous partition: for each block \(C\), use the vector whose coordinate at \(t\) is \(\mu_t\) when \(t\in C\), and zero otherwise. Its continuous value is exactly \(D(\mathcal{P})\).

Conversely, the lemma shows that every feasible continuous value is bounded above by the value of some such discrete partition. Therefore

\(\max_{\text{feasible continuous partitions}}V =\max_{\text{connected vertex partitions }\mathcal{P}}D(\mathcal{P}).\)

The maximum on the right exists because there are finitely many vertex partitions. Thus the continuous maximum is attained, despite unrestricted \(Q\) and real-valued coalition masses.

In particular,

\(\exists\text{ feasible continuous partition with }V\geq K \quad\Longleftrightarrow\quad \exists\text{ connected vertex partition }\mathcal{P}\text{ with }D(\mathcal{P})\geq K.\)

3. Polynomial reduction proving hardness

The discrete source problem has a connected simple planar graph \(G=(N,E)\), signed rational edge weights \(w_{tu}\), and threshold \(B\). It asks whether a connected vertex partition has internal-edge weight at least \(B\). This is the edge-sum problem proved \(\mathrm{NP}\)-complete by Voice, Polukarov and Jennings, Theorem 2; their graph model is connected and simple. [Source](https://jair.org/index.php/jair/article/download/10781/25742/20089).

Write \(n=|N|\) and \(e=|E|\). The following construction uses dyadic masses, so it also works if “binary rational” requires terminating binary expansions.

Let \(p\) be the smallest power of two satisfying \(p\geq n\). Add \(p-n\) new pendant vertices to an arbitrary original vertex, giving every new edge weight zero. Call the resulting graph \(H=(T,F)\), and write \(\widehat w\) for its edge weights.

The graph remains connected, simple, and planar. Moreover, padding preserves the discrete optimum:

  • Any original connected partition extends by making the new vertices singleton coalitions, preserving its value.
  • Given a padded connected partition, remove the new vertices and split each remaining block into connected components in \(G\). Every original edge whose endpoints shared a block still connects those endpoints within the remaining block, so its contribution is preserved. All removed edges had weight zero.

Now construct the continuous instance by setting

\(\mu_t=1/p\quad(t\in T),\qquad a_{tu}=p^2\widehat w_{tu}\quad(\{t,u\}\in F),\qquad K=B.\)

All masses are positive dyadic rationals, and their sum is one. Its effective edge weights are

\(a_{tu}\mu_t\mu_u =p^2\widehat w_{tu}\cdot p^{-1}\cdot p^{-1} =\widehat w_{tu}.\)

By Section 2, this continuous instance is a yes-instance exactly when the padded discrete instance is, and therefore exactly when the original discrete instance is.

For the output parameters,

\(\tau=p<2n,\qquad m=e+p-n.\)

If the source encoding length is \(L_{\mathrm d}\), the output satisfies

\(L=O\!\left(L_{\mathrm d}+(e+n)\log(n+1)\right).\)

Multiplying weights by \(p^2\) adds only \(O(\log(n+1))\) bits per weight. Hence the construction runs in polynomial time and proves \(\mathrm{NP}\)-hardness.

4. Certificates and running times

A certificate assigns each type a coalition label in \(\{1,\ldots,\tau\}\), using \(O(\tau\log(\tau+1))\) bits. The verifier checks that each nonempty label class induces a connected subgraph and computes its exact value using \(b_{tu}=a_{tu}\mu_t\mu_u\).

Here is an explicit polynomial bit bound. Write the input rationals as

\(\mu_t=r_t/s_t,\qquad a_{tu}=c_{tu}/d_{tu},\qquad K=k/d_K,\)

with positive denominators. Choose the common denominator

\(D=d_K\left(\prod_{\{t,u\}\in F}d_{tu}\right)\left(\prod_{t\in T}s_t^2\right).\)

Its bit length is \(O(L)\). For every edge,

\(B_{tu}=c_{tu}r_tr_u\,\frac{D}{d_{tu}s_ts_u}\)

is an integer equal to \(Db_{tu}\). Compare the sum of \(B_{tu}\) over internal edges with \(kD/d_K\). All these integers and sums have \(O(L)\) bits. Using ordinary integer arithmetic, certificate verification takes

\(O((m+\tau)L^2)\)

bit operations. The rounding lemma guarantees such a certificate for every continuous yes-instance, proving membership in \(\mathrm{NP}\).

For completeness, an exact exhaustive algorithm runs in

\(O(2^m(m+\tau)L^2)\)

bit operations: enumerate all edge subsets, take their connected-component partitions, and evaluate each partition. This covers every connected vertex partition because choosing a spanning tree inside each block realizes that partition as the components of an edge subset.

Thus the requested problem is \(\mathrm{NP}\)-complete, and a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
