The continuous mirror question, as graded

Given rational criterion profiles \(x_t\in\mathbb{Q}^m\) with masses \(\mu_t>0\), rational labeled submasses \(\lambda_{t,h}\ge 0\) satisfying \(\sum_h\lambda_{t,h}\le\mu_t\), rational utility knots, ordered categories, and fixed rational \(\alpha\in(0,1)\), find the piecewise-linear marginal utilities and category thresholds. For each labeled profile-category mass, impose the paper’s category-fit constraints with nonnegative inconsistency slacks; first maximize \(\alpha\epsilon-(1-\alpha)r^{-1}\sum_{t,h}\lambda_{t,h}(\delta^+_{t,h}+\delta^-_{t,h})\), where \(r=\sum_{t,h}\lambda_{t,h}>0\), then, among optimal fits, minimize the total absolute change between adjacent utility slopes. Return the threshold-rule category for each profile and the resulting category mass shares.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) distinct types \(x_t\in\mathbb Q^m\) with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Input includes \(m\ge1\), ordered categories \(C_1\prec\cdots\prec C_q\) with \(q\ge2\), fixed rational \(\alpha\in(0,1)\), and binary-rational labeled submasses \(\lambda_{t,h}\ge0\) satisfying \(\sum_h\lambda_{t,h}\le\mu_t\) and \(r=\sum_{t,h}\lambda_{t,h}>0\).
For each criterion \(j\), input \(s_j+1\) equally spaced rational knots \(\beta_j^1<\cdots<\beta_j^{s_j+1}\), with \(s_j\ge1\), spanning \([\min_t x_{t,j},\max_t x_{t,j}]\); assume each such interval has positive length. Let \(K=\sum_j(s_j+1)\) and let \(L\) be the total binary input length.
Unknown knot utilities \(v_{j,l}\in[0,1]\) define \(u_j\) by linear interpolation, without monotonicity or endpoint normalization; set \(U_t=\sum_j u_j(x_{t,j})\). Unknown internal thresholds \(b_1,\ldots,b_{q-1}\in\mathbb R\) satisfy \(b_h-b_{h-1}\ge\epsilon\) for \(2\le h\le q-1\), where \(0<\epsilon\le m/(q-1)\).
For every \(\lambda_{t,h}>0\), introduce \(\delta^+_{t,h},\delta^-_{t,h}\ge0\): impose \(b_{h-1}-\delta^+_{t,h}\le U_t\le b_h-\epsilon+\delta^-_{t,h}\) when \(1<h<q\), only \(U_t\le b_1-\epsilon+\delta^-_{t,1}\) when \(h=1\), and only \(U_t\ge b_{q-1}-\delta^+_{t,q}\) when \(h=q\).
First maximize \(J=\alpha\epsilon-(1-\alpha)r^{-1}\sum_{t,h:\lambda_{t,h}>0}\lambda_{t,h}(\delta^+_{t,h}+\delta^-_{t,h})\); among its maximizers minimize \(\sum_{j=1}^m\sum_{l=2}^{s_j}\left|\frac{v_{j,l+1}-v_{j,l}}{\beta_j^{l+1}-\beta_j^l}-\frac{v_{j,l}-v_{j,l-1}}{\beta_j^l-\beta_j^{l-1}}\right|\).
Find any exact optimum of these two successive stages, or determine that a required optimum is not attained. For an optimum, return the utilities, internal thresholds, categories \(c(t)=1+\left|\{h\in\{1,\ldots,q-1\}:b_h\le U_t\}\right|\), and shares \(p_h=\sum_{t:c(t)=h}\mu_t\).
Is this exact mass-weighted fitting and sorting problem solvable in polynomial time in \(m,\tau,q,K,L\), or is it \(\mathrm{NP}\)-hard?
For finite lists, the absolute adjacent-slope complexity objective has an exact linear-programming reformulation while preserving the first-stage optimum and constraints. [Source](https://arxiv.org/html/2409.02760v1).
No result settling this exact mass-weighted formulation was identified in the literature search.

Result

The problem is solvable in polynomial time in \(m,\tau,q,K,L\), including exact detection of nonattainment at either stage. At most four rational linear programs are required.

The strict constraint \(\epsilon>0\) needs explicit treatment: merely solving the two closed LP relaxations would not establish attainment.

1. Rational linear representation

Let \(\mathcal A=\{(t,h):\lambda_{t,h}>0\}\), and put \(n=|\mathcal A|\le\tau q\). Treat \(\epsilon\) as an optimization variable, as prescribed by the first-stage objective.

For every pair \((t,j)\), choose an index \(\ell(t,j)\) such that

\(\beta_j^{\ell(t,j)}\le x_{t,j}\le\beta_j^{\ell(t,j)+1}\).

Such an index exists because the knots span the observed interval. Define the rational number

\(\displaystyle a_{t,j}=\frac{x_{t,j}-\beta_j^{\ell(t,j)}}{\beta_j^{\ell(t,j)+1}-\beta_j^{\ell(t,j)}}\in[0,1].\)

Then

\(\displaystyle U_t(v)=\sum_{j=1}^{m}\bigl((1-a_{t,j})v_{j,\ell(t,j)}+a_{t,j}v_{j,\ell(t,j)+1}\bigr).\)

If an observation coincides with a knot, either adjacent interval gives the same value. Consequently, every fitting constraint is a rational linear inequality in the knot utilities, thresholds, margin, and deviation variables.

Write

\(\displaystyle E=\frac{m}{q-1},\qquad J(y)=\alpha\epsilon-\frac{1-\alpha}{r}\sum_{(t,h)\in\mathcal A}\lambda_{t,h}(\delta^+_{t,h}+\delta^-_{t,h}),\)

where \(y=(v,b,\epsilon,\delta)\). Since \(r>0\), every coefficient is defined and rational.

2. The closed relaxation has the correct first-stage supremum

Let \(P\) be the rational polyhedron consisting of all given constraints, except that \(0<\epsilon\le E\) is replaced by \(0\le\epsilon\le E\). The original feasible set is

\(P^+=\{y\in P:\epsilon>0\}.\)

First, \(P^+\) is nonempty. Set

\(v_{j,l}=0,\qquad \epsilon=E,\qquad b_h=hE,\qquad \delta^+_{t,h}=m,\qquad\delta^-_{t,h}=0.\)

All utilities are zero. The threshold gaps equal \(E\). Every upper fitting bound is satisfied because \(b_h-E=(h-1)E\ge0\); every lower fitting bound is satisfied because each internal threshold is at most \(m\), so subtracting \(m\) makes its lower bound nonpositive.

Fix this feasible point \(y^\circ\in P^+\). For any \(y\in P\) and any \(0<\theta\le1\), convexity gives

\(y_\theta=(1-\theta)y+\theta y^\circ\in P.\)

Its margin satisfies \(\epsilon(y_\theta)\ge\theta E>0\). Thus \(y_\theta\in P^+\), and \(y_\theta\to y\) as \(\theta\to0\). Hence \(P^+\) is dense in \(P\).

Moreover, nonnegative deviations imply

\(J(y)\le\alpha\epsilon\le\alpha E.\)

We use the standard rational-LP theorem: an explicitly represented rational LP can be solved exactly in polynomial bit complexity; a nonempty feasible polyhedron with a finite optimal value has a rational optimizer of polynomial encoding length. This theorem does not require the feasible polyhedron to be bounded. See the [MIT linear-programming notes](https://courses.csail.mit.edu/6.854/21/Notes/n11-lp.html).

Therefore the first LP,

\(\displaystyle J^*=\max_{y\in P}J(y),\)

has an attained finite optimum. Density and continuity of \(J\) imply

\(\displaystyle \sup_{y\in P^+}J(y)=J^*.\)

Indeed, the supremum over \(P^+\) cannot exceed the maximum over \(P\), and mixing any optimizer in \(P\) with \(y^\circ\) produces original feasible points whose objective values approach \(J^*\).

3. Exact detection of first-stage attainment

Define the nonempty rational optimal face

\(F_1=\{y\in P:J(y)=J^*\}.\)

Solve the second LP:

\(\displaystyle e_1=\max_{y\in F_1}\epsilon.\)

Its objective lies in \([0,E]\), so its optimum is attained.

  • If \(e_1=0\), every point of \(F_1\) has zero margin. Since the original supremum is \(J^*\), the first-stage optimum is not attained.
  • If \(e_1>0\), an optimizer of this LP belongs to \(P^+\) and has objective \(J^*\). Thus the first-stage optimum is attained, and its complete optimizer set is

\(F_1^+=\{y\in F_1:\epsilon>0\}.\)

In the second case, fix a point \(y^1\in F_1^+\). Mixing any point of \(F_1\) with \(y^1\) preserves every constraint and the equality \(J=J^*\), while making the margin positive. Therefore \(F_1^+\) is dense in \(F_1\).

The remaining steps apply only when \(e_1>0\).

4. Exact second-stage reformulation and attainment test

For every \(j\) and \(2\le l\le s_j\), define the rational linear form

\(\displaystyle D_{j,l}(v)= \frac{v_{j,l+1}-v_{j,l}}{\beta_j^{l+1}-\beta_j^l} -\frac{v_{j,l}-v_{j,l-1}}{\beta_j^l-\beta_j^{l-1}}.\)

The desired complexity is

\(\displaystyle C(v)=\sum_{j=1}^{m}\sum_{l=2}^{s_j}|D_{j,l}(v)|.\)

Introduce variables \(z_{j,l}\) and impose

\(z_{j,l}\ge D_{j,l}(v),\qquad z_{j,l}\ge-D_{j,l}(v).\)

These inequalities imply \(z_{j,l}\ge|D_{j,l}(v)|\). Conversely, choosing \(z_{j,l}=|D_{j,l}(v)|\) satisfies them. This is the epigraph reformulation appearing in [Theorem 1 of the supplied source](https://arxiv.org/html/2409.02760v1#S4.SS4).

Let

\(Q=\{(y,z):y\in F_1,\ z_{j,l}\ge D_{j,l}(v),\ z_{j,l}\ge-D_{j,l}(v)\},\)

and define

\(\displaystyle S(z)=\sum_{j=1}^{m}\sum_{l=2}^{s_j}z_{j,l}.\)

The third LP is

\(\displaystyle C^*=\min_{(y,z)\in Q}S(z).\)

The set \(Q\) is nonempty: any point of \(F_1\) admits the choice \(z_{j,l}=|D_{j,l}(v)|\). Its objective is nonnegative, so the LP has an attained finite optimum.

For every fixed \(y\in F_1\), the least possible value of \(S(z)\) is exactly \(C(v)\). It follows that

\(\displaystyle C^*=\min_{y\in F_1}C(v).\)

We must still justify that this is the second-stage infimum under the strict margin constraint. Let

\(Q^+=\{(y,z)\in Q:\epsilon>0\}.\)

Lift the previously chosen \(y^1\in F_1^+\) to a point of \(Q^+\) by setting \(z^1_{j,l}=|D_{j,l}(v^1)|\). Mixing this lift with any point of \(Q\) remains in \(Q\), has positive margin, and approaches the original point. Thus \(Q^+\) is dense in \(Q\). Since \(S\) is continuous,

\(\displaystyle \inf_{y\in F_1^+}C(v) =\inf_{(y,z)\in Q^+}S(z) =\min_{(y,z)\in Q}S(z) =C^*.\)

Define the nonempty rational optimal face

\(F_2=\{(y,z)\in Q:S(z)=C^*\}.\)

The fourth LP is

\(\displaystyle e_2=\max_{(y,z)\in F_2}\epsilon.\)

Again, its optimum is attained and lies in \([0,E]\).

  • If \(e_2=0\), the second-stage infimum is not attained among first-stage maximizers with positive margin. If such a minimizer existed, lifting it with \(z_{j,l}=|D_{j,l}(v)|\) would give a point of \(F_2\) with positive margin, a contradiction.
  • If \(e_2>0\), return an optimizer \((y^*,z^*)\) of this LP.

For the latter case, \(J(y^*)=J^*\) and \(\epsilon^*>0\). Furthermore,

\(C^*\le C(v^*)\le S(z^*)=C^*.\)

The first inequality follows from \(y^*\in F_1\), and the second from the epigraph inequalities. Hence \(C(v^*)=C^*\). This proves that \(y^*\) is an exact optimum of both successive stages.

Empty complexity sums, occurring when every \(s_j=1\), are handled by taking \(S=C=0\).

5. Exact categories and shares

The returned knot values specify the full utility functions by interpolation. Compute every \(U_t(v^*)\) exactly.

Because \(\epsilon^*>0\), the gap constraints make the internal thresholds strictly increasing. For each support type, perform the prescribed exact rational comparisons and set

\(\displaystyle c(t)=1+\bigl|\{h\in\{1,\ldots,q-1\}:b_h^*\le U_t(v^*)\}\bigr|.\)

Equality is included exactly as required. Then compute

\(\displaystyle p_h=\sum_{t:c(t)=h}\mu_t.\)

These computations require at most \(\tau(q-1)\) threshold comparisons and rational summation over the support. Each type contributes to exactly one category, so the returned shares satisfy \(p_h\ge0\) and \(\sum_h p_h=1\).

6. Polynomial bit complexity

The first two LPs have \(K+(q-1)+1+2n=K+q+2n\) variables and \(O(K+q+n)\) constraints after substituting the interpolation formulas.

The complexity reformulation adds

\(\displaystyle \sum_j(s_j-1)=K-2m\)

variables and twice that many inequalities. Thus all four LPs have polynomially many variables and constraints.

Their coefficients also have polynomial total encoding length:

  • Interpolation coefficients and reciprocal knot spacings are formed by a bounded number of rational arithmetic operations on input numbers; positive knot spacings ensure all divisions are defined.
  • The value \(r\) and the coefficients \(\lambda_{t,h}/r\) have polynomial encoding length. Adding polynomially many encoded rationals increases numerator and denominator bit lengths by at most a polynomial amount.
  • Exact rational-LP optimization returns \(J^*\) and \(C^*\) with polynomial encoding length. Adding their defining equalities therefore preserves polynomial LP size.
  • The attainment tests compare exact rational numbers \(e_1,e_2\) with zero. They require no numerical tolerance.
  • The final utilities, thresholds, comparisons, and mass sums likewise have polynomial encoding length and can be computed in polynomial time.

Unbounded threshold or deviation variables cause no difficulty: each LP is nonempty, and its particular objective has the finite bound proved above.

Consequently, the algorithm either returns the requested exact optimum and sorting output, or correctly identifies the stage at which a required optimum is not attained, in polynomial time in \(m,\tau,q,K,L\).
