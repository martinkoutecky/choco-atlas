The continuous mirror question, as graded

Given a finite graph \(G=(V,E)\), rational capacities \(q_v\ge 0\), rational total masses \(R,B\), and a rational threshold \(s\), does there exist a real allocation \(x_{v,c}\ge 0\) with \(x_{v,R}+x_{v,B}\le q_v\), \(\sum_v x_{v,R}=R\), and \(\sum_v x_{v,B}=B\), such that \(W(x)\ge s\)? For each \(v\) and \(c\in\{R,B\}\), define \(u_{v,c}(x)=\frac{\sum_{w\in N(v)}x_{w,c}}{\sum_{w\in N(v)}(x_{w,R}+x_{w,B})}\), with value \(0\) when the denominator is \(0\), and let \(W(x)=\sum_{v,c}x_{v,c}u_{v,c}(x)\).

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,E)\) be a finite simple connected undirected graph with \(m=|V|\ge2\), and let \(N(v)\) be its open neighborhood. Input capacities are \(q_v\in\mathbb Q_{\ge0}\), and the threshold is \(s\in\mathbb Q\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here the possible types are red and blue, with masses \(R,B\in\mathbb Q_{\ge0}\), absent types having mass zero; \(\tau\) is the support size, not the number of possible types. Assume \(0<R+B\le\sum_v q_v\); masses are not normalized to sum to one.
An allocation consists of real \(x_{v,c}\ge0\) for \(c\in\{R,B\}\), satisfying \(x_{v,R}+x_{v,B}\le q_v\), \(\sum_v x_{v,R}=R\), and \(\sum_v x_{v,B}=B\). Both types may occupy the same vertex, and capacity may remain unused.
Define \(u_{v,c}(x)=\frac{\sum_{w\in N(v)}x_{w,c}}{\sum_{w\in N(v)}(x_{w,R}+x_{w,B})}\) when the denominator is positive, and \(u_{v,c}(x)=0\) otherwise. Set \(W(x)=\sum_{v\in V}\sum_{c\in\{R,B\}}x_{v,c}u_{v,c}(x)\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is deciding whether there exists a feasible real allocation \(x\) with \(W(x)\ge s\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For indivisible agents occupying distinct vertices, this welfare-threshold problem is NP-complete even on regular graphs with every vertex occupied ([source](https://arxiv.org/pdf/2012.02086)). Computing maximum welfare is also NP-hard on cubic graphs ([source](https://arxiv.org/abs/2201.06904)).
No complexity result for exactly the real mass-allocation problem defined above was located in the literature search.

Modeling choices made when packaging the task

  • Specified that the topology is simple, connected, and undirected, with at least two vertices, following the discrete model.
  • Specified nonnegative masses with positive total mass, permitting an absent color because the discrete model permits one-type instances.
  • Kept masses unnormalized, matching the discrete use of total rather than average welfare.
  • Required total mass not to exceed total capacity, the mass analogue of having enough vertices for all agents.
  • Made explicit that neighborhoods exclude the vertex itself, so colocated mass contributes neither to the numerator nor to the denominator of utility.
  • Defined m as the vertex count and L as total binary input length.

Result

The decision problem is \(\mathrm{NP}\)-hard, even when \(\tau=2\), the graph is a tree, every capacity is a strictly positive integer, and \(R+B=\sum_v q_v\).

The reduction below controls all feasible real allocations; it does not assume that vertices are monochromatic.

1. Reduction from PARTITION

Use the standard NP-complete problem PARTITION: given positive integers \(a_1,\ldots,a_n\), encoded in binary, decide whether some \(S\subseteq\{1,\ldots,n\}\) satisfies

\(\displaystyle 2\sum_{i\in S}a_i=\sum_{i=1}^n a_i.\)

This is one of the classical problems in [Karp’s NP-completeness theorem](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Set

\(\displaystyle A=\sum_{i=1}^n a_i,\qquad D=4(n+1),\qquad c_i=Da_i.\)

Construct a tree with vertices \(h,u_1,v_1,\ldots,u_n,v_n\) and edges \(hu_i,u_iv_i\) for every \(i\). Thus \(m=2n+1\). Assign capacities

\(\displaystyle q_h=1,\qquad q_{u_i}=q_{v_i}=c_i.\)

Choose the two positive masses and threshold as follows:

\(\displaystyle R=B=DA+\frac12,\qquad T=R+B=2DA+1,\qquad s=T-(n+1).\)

All capacities are strictly positive integers. Also, \(T=\sum_vq_v\), so every feasible allocation saturates every vertex: the nonnegative quantities \(q_v-x_{v,R}-x_{v,B}\) sum to zero.

Write \(r_v=x_{v,R}\) and \(b_v=x_{v,B}=q_v-r_v\). Define the welfare loss by \(\mathcal L(x)=T-W(x)\). The threshold condition is precisely \(\mathcal L(x)\le n+1\).

2. An exact expression for welfare loss

For a saturated allocation, let \(d_v=\sum_{w\in N(v)}q_w\). Every \(d_v\) is positive in the constructed tree.

The loss at vertex \(v\) is

\(\displaystyle q_v-\frac{r_v\sum_{w\in N(v)}r_w+b_v\sum_{w\in N(v)}b_w}{d_v} =\frac{r_v\sum_{w\in N(v)}b_w+b_v\sum_{w\in N(v)}r_w}{d_v}.\)

Here the equality follows by expanding \(q_vd_v=(r_v+b_v)\sum_{w\in N(v)}(r_w+b_w)\).

Summing and collecting the two contributions of each undirected edge gives

\(\displaystyle \mathcal L(x)=\sum_{\{v,w\}\in E}\left(\frac1{d_v}+\frac1{d_w}\right)(r_vb_w+b_vr_w).\)

Every summand is nonnegative.

For branch \(i\), define

\(\displaystyle y_i=r_{u_i}+r_{v_i},\qquad z_i=\frac{y_i}{2c_i},\qquad \delta_i=\min\{y_i,2c_i-y_i\}.\)

Thus \(\delta_i\) measures the distance of the branch’s red mass from either zero or its full capacity.

We have \(d_{u_i}=c_i+1\) and \(d_{v_i}=c_i\). Moreover,

\(\displaystyle r_{u_i}b_{v_i}+b_{u_i}r_{v_i} =c_i y_i-2r_{u_i}r_{v_i} \ge c_i y_i-\frac{y_i^2}{2} =2c_i^2z_i(1-z_i),\)

where the inequality uses \(r_{u_i}r_{v_i}\le y_i^2/4\).

Consequently, the loss contributed by edge \(u_iv_i\) is at least

\(\displaystyle \frac1{c_i}\,2c_i^2z_i(1-z_i) \ge c_i\min\{z_i,1-z_i\} =\frac{\delta_i}{2}.\)

The second inequality holds because \(2z(1-z)\ge\min\{z,1-z\}\) for \(0\le z\le1\). Discarding the other nonnegative edge contributions proves the key bound

\(\displaystyle \sum_{i=1}^n\delta_i\le2\mathcal L(x).\)

3. A partition gives a qualifying allocation

Suppose \(S\) is a partition witness. Fill both vertices of branch \(i\) entirely with red when \(i\in S\), and entirely with blue otherwise. At \(h\), place red and blue mass \(1/2\) each.

The branch red mass is \(2D\sum_{i\in S}a_i=DA\), so both prescribed type totals are satisfied.

Each leaf \(v_i\) has utility one for its occupying type and contributes zero loss. At \(u_i\), the same-type neighboring mass is \(c_i+1/2\), while total neighboring mass is \(c_i+1\). Its loss is therefore \(c_i/[2(c_i+1)]\).

The neighbors of \(h\) contain red and blue mass \(DA/2\) each. Both utilities at \(h\) equal \(1/2\), giving hub loss \(1/2\). Hence

\(\displaystyle \mathcal L(x)=\frac12+\sum_{i=1}^n\frac{c_i}{2(c_i+1)} \le\frac{n+1}{2}<n+1.\)

Thus \(W(x)\ge s\).

4. Every qualifying real allocation gives a partition

Conversely, consider any feasible real allocation. Round its branches by defining

\(\displaystyle S=\{i:y_i\ge c_i\}.\)

By the definition of \(\delta_i\),

\(\displaystyle \left|y_i-2c_i\mathbf1_{\{i\in S\}}\right|=\delta_i.\)

The total red-mass constraint gives

\(\displaystyle \sum_i y_i=DA+\frac12-r_h,\qquad 0\le r_h\le1.\)

The triangle inequality and the key bound therefore imply

\(\displaystyle \left|DA-2D\sum_{i\in S}a_i\right| \le\left|r_h-\frac12\right|+\sum_i\delta_i \le\frac12+2\mathcal L(x). \)

If the PARTITION instance is a no-instance, the integer \(A-2\sum_{i\in S}a_i\) is nonzero, so its absolute value is at least one. It follows that

\(\displaystyle \mathcal L(x)\ge\frac D2-\frac14 =2(n+1)-\frac14>n+1. \)

Thus no feasible real allocation meets the welfare threshold in a no-instance. Together with the preceding section, this proves the required equivalence.

5. Input length and the support parameter

Let \(\ell\) denote the binary length of the PARTITION instance. The reduction produces \(m=2n+1\), \(\tau=2\), and output length \(L=O(\ell+n\log(n+1))\). It can be computed in \(O(\ell^2)\) bit operations using elementary integer arithmetic.

Therefore, an algorithm polynomial in \(m,\tau,L\) for the stated problem would imply \(\mathrm P=\mathrm{NP}\). The reduction establishes NP-hardness, without asserting strong NP-hardness.

For comparison, the case \(\tau=1\) is polynomial-time solvable. Let \(M\) be the sole positive mass and define

\(\displaystyle U=\{v:q_v>0\text{ and some }w\in N(v)\text{ has }q_w>0\},\qquad C=\sum_{v\in U}q_v.\)

Vertices outside \(U\) always contribute zero welfare, so \(W\le\min\{M,C\}\). This bound is attained:

  • If \(0<M\le C\), assign \(x_v=Mq_v/C\) on \(U\) and zero elsewhere. Every vertex of \(U\) has an occupied neighbor in \(U\), so its utility is one.
  • If \(M>C\), fill \(U\) and distribute the remaining mass outside \(U\). Feasibility follows from \(M\le\sum_vq_v\).
  • If \(C=0\), every allocation has welfare zero.

Thus the one-type answer is yes exactly when \(s\le\min\{M,C\}\). Scanning the graph and performing exact rational additions and comparisons takes, conservatively, \(O(m^2+mL^2)\) bit operations.
