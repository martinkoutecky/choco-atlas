Proposition 2 — class: hardness

The continuous mirror question, as graded

Given a finite graph \(H=(T,E)\) and positive rational role masses \(\mu_t\) summing to \(1\), compute exactly \(\alpha_\infty(H,\mu)=\min_{p\in\mathbb{R}_{\ge 0}^{T},\ p_u+p_v\ge 1\ \forall uv\in E}\ \max_{I\subseteq T,\ I\text{ independent in }H}\sum_{t\in I}\mu_t p_t\), and output an optimal vector \(p\).

Packaged proof task (what the prover saw — nothing else)

Let \(H=(T,E)\) be a finite simple undirected graph with \(E\ne\varnothing\). A society is given by its support: the list of \(\tau=|T|\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) counts supported types, not all possible types. Set \(m=|E|\), and let \(L\) be the total input bit length.
A payoff vector assigns a nonnegative real \(p_t\) to each type and must satisfy \(p_u+p_v\ge1\) for every \(uv\in E\). Define
\(\alpha_\infty(H,\mu)=\min_{p\in\mathbb R_{\ge0}^{T}:\ p_u+p_v\ge1\ \forall uv\in E}\ \max_{I\subseteq T\text{ independent in }H}\sum_{t\in I}\mu_t p_t\).
The computational problem is to compute this value exactly and return an optimal vector, with rational outputs represented in binary.

Is this exact computation problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For the discrete objective obtained by replacing \(\mu_t p_t\) with \(p_t\), exact computation is \(\mathrm{NP}\)-hard on arbitrary graphs and polynomial-time solvable on bipartite graphs. [Source](https://arxiv.org/html/1810.08841#S4).
No published result for this precise mass-weighted formulation was located in the search.

Modeling choices made when packaging the task

  • Specified that the graph is simple and undirected, as its edges represent two-player coalitions.
  • Required a nonempty edge set to preserve the discrete simple-game condition that the grand coalition is winning; isolated vertices remain allowed.
  • Defined m as the edge count and L as the total input bit length.
  • Specified binary-rational encoding of exact outputs; any optimal vector is acceptable.

Conclusion

The exact computation problem is \(\mathrm{NP}\)-hard, even when every supported type has the same positive dyadic mass. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. The unweighted problem

For a finite simple graph \(G=(V,F)\), define
\[ \beta(G)= \min_{\substack{q\in\mathbb R_{\ge 0}^{V}\\ q_u+q_v\ge 1\;\forall uv\in F}} \max_{\substack{J\subseteq V\\J\text{ independent in }G}} \sum_{v\in J}q_v. \]

Here and below, the displayed formula means \(\beta(G)=\min\{\max_{J\text{ independent}}\sum_{v\in J}q_v:q\ge 0,\ q_u+q_v\ge 1\text{ for every }uv\in F\}\).

The known hardness result applies to precisely this quantity: Proposition 2 of the supplied paper states that computing \(\beta(G)\) on arbitrary graphs is \(\mathrm{NP}\)-hard. Its feasible vectors are nonnegative real vectors with the same edge constraints used here. [Hof et al., Section 4](https://arxiv.org/html/1810.08841#S4).

We may restrict the source problem to graphs with \(F\ne\varnothing\): on an edgeless graph, the zero vector proves \(\beta(G)=0\), so those instances can be handled directly.

2. A polynomial reduction with dyadic masses

Let \(G=(V,F)\) be a source instance with \(n=|V|\) and \(F\ne\varnothing\). Let \(N\) be the smallest power of two satisfying \(N\ge n\). Thus \(n\le N<2n\).

Construct \(H=(T,E)\) by adjoining a set \(Z\) of \(N-n\) isolated vertices to \(G\). Thus \(T=V\cup Z\), \(E=F\), and \(\tau=N\). Assign every type the mass \(\mu_t=1/N\).

These masses are positive, sum to one, and are dyadic because \(N\) is a power of two. Each has binary representation length \(O(\log n)\). The graph and the explicit list of all supported types therefore have polynomial size; in particular, the construction adds fewer than \(n\) supported types.

For a feasible payoff vector \(p\) on \(H\), write
\[ M_G(p|_V)= \max_{\substack{J\subseteq V\\J\text{ independent in }G}} \sum_{v\in J}p_v. \]

Every independent set of \(H\) consists of an independent set of \(G\) together with a subset of \(Z\). Since \(p\ge 0\), including all of \(Z\) maximizes the contribution from the isolated vertices. Consequently,
\[ \max_{\substack{I\subseteq T\\I\text{ independent in }H}} \sum_{t\in I}\mu_t p_t = \frac{1}{N}\left(M_G(p|_V)+\sum_{z\in Z}p_z\right). \]

The restriction \(p|_V\) is feasible for the unweighted problem on \(G\), so \(M_G(p|_V)\ge\beta(G)\). Hence every feasible vector on \(H\) has weighted objective at least \(\beta(G)/N\).

Conversely, extend any optimal vector for \(G\) by setting \(p_z=0\) for every \(z\in Z\). This extension is feasible on \(H\) and has weighted objective \(\beta(G)/N\). Therefore,
\[ \alpha_\infty(H,\mu)=\frac{\beta(G)}{N}. \]

Thus one exact computation of the weighted value recovers \(\beta(G)\) by multiplication by \(N\). This multiplication is polynomial-time binary rational arithmetic.

The optimal vector also transfers: if \(p\) is optimal on \(H\), then
\[ M_G(p|_V)+\sum_{z\in Z}p_z=\beta(G). \]
Because \(M_G(p|_V)\ge\beta(G)\) and every \(p_z\ge 0\), the restriction \(p|_V\) is optimal on \(G\).

3. Rational optimal outputs exist

For completeness, the real-variable formulation admits optimal rational vectors of polynomial binary length.

Given any feasible vector \(p\), replace each coordinate by \(\min\{p_t,1\}\). An edge constraint remains satisfied: if either endpoint was clipped, that endpoint now contributes one; otherwise neither coordinate changed. Every independent-set sum weakly decreases because all masses are positive.

It therefore suffices to optimize over \(0\le p_t\le 1\). Introduce a variable \(a\) and impose, for every independent set \(I\), the inequality \(\sum_{t\in I}\mu_t p_t\le a\), together with the edge constraints and \(0\le a\le 1\). This is a nonempty compact rational polytope: \(p_t=1\) for all \(t\), with \(a=1\), is feasible. Its minimum of \(a\) occurs at a vertex.

A vertex is determined by \(\tau+1\) linearly independent active constraints. Clearing denominators produces integer coefficients with bit length polynomial in \(L\). Cramer’s rule and determinant bounds then give polynomial binary lengths for the vertex coordinates. The exponentially many possible independent-set constraints do not change this bound, since only \(\tau+1\) active constraints are needed.

4. Complexity consequence

The reduction preserves \(E\ne\varnothing\), uses only positive dyadic masses, and has polynomial \(m,\tau,L\). A polynomial-time algorithm for the requested value-and-vector problem would therefore compute the known \(\mathrm{NP}\)-hard unweighted value in polynomial time. The target problem is consequently \(\mathrm{NP}\)-hard; hardness already holds for computing its value alone.
