The continuous mirror question, as graded

Given a finite catalogue \(T\) of normalized valuation densities, a population distribution \(\mu\in\Delta(T)\), an integer population scale \(N\), and \(\eta>0\), construct a succinct randomized Robertson–Webb protocol that implicitly partitions the cake into \(N\) pieces \(A_1,\ldots,A_N\), assigns them by a valuation-independent uniform random permutation, preserves individual truthfulness in expectation, and guarantees \(V_t(A_j)\in[(1-\eta)/N,(1+\eta)/N]\) for every \(t\in T\) and every \(j\), using complexity polynomial in \(|T|\), the input length, \(1/\eta\), and \(\log N\), rather than \(N\).

Packaged proof task (what the prover saw — nothing else)

The cake is \([0,1]\). Each type \(t\) has an arbitrary integrable nonnegative density \(v_t\), with \(V_t(X)=\int_X v_t(x)\,dx\) and \(V_t([0,1])=1\); strict positivity is not required.
A society is given by its support: the list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu(t)\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Densities are accessible through Robertson–Webb oracles, rather than finite function descriptions. Also given are a binary integer \(N\ge2\) and a binary rational \(\eta>0\); \(L\) is the bit length of this finite input. There is one resource, so \(m=1\).
The query \(\operatorname{Cut}(t;\alpha)\), for \(\alpha\in[0,1]\), returns a point \(y\) satisfying \(V_t([0,y])=\alpha\); any such point is admissible. The query \(\operatorname{Eval}(t;y)\) returns \(V_t([0,y])\), only at previously generated cut points. Interior allocation endpoints must have been returned by Cut queries. Reports must remain consistent with a normalized nonnegative valuation.
An allocation partitions the entire cake into \(N\) finite unions of intervals \(A_1,\ldots,A_N\), allowing shared endpoints. A succinct output is a program specifying the recipient-piece label of each interval between consecutive queried cut points; it cannot introduce additional endpoints or defer uncharged queries. Count all queries and computation, using unit-cost exact oracle answers and real arithmetic, together with ordinary bit operations on the finite input.
The \(N\) recipient labels are virtual slots: no integrality condition is imposed on \(N\mu(t)\). Assign pieces through an independent uniform permutation \(\pi\) of these labels, drawn after reporting finishes and represented implicitly as a chance operation. Individual truthfulness in expectation means that, for every recipient's true type and every strategy of the other reporting individuals, changing its own consistent query replies cannot increase its expected value \(V_t(A_{\pi(i)})\).
Can such a randomized protocol guarantee \(V_t(A_j)\in[(1-\eta)/N,(1+\eta)/N]\) for every \(t\in T\) and \(j\in\{1,\ldots,N\}\) on every truthful execution, while preserving individual truthfulness in expectation and using total complexity and output size \(\operatorname{poly}(m,\tau,L,1/\eta,\log N)\), or is this approximation guarantee impossible within that bound?
For finite lists of \(n\) agents, a truthful-in-expectation Robertson–Webb construction guarantees \(V_i(A_j)\in[1/n-\varepsilon,1/n+\varepsilon]\); its stated query bound is \(O(n^2/\varepsilon)\), but its construction uses exhaustive enumeration. [Brânzei–Miltersen](https://www.ijcai.org/Proceedings/15/Papers/074.pdf)
An exact perfect-partition mechanism with uniform random assignment is known for nonatomic valuations, but is existential and uses direct revelation. Neither result establishes the stated support-input succinct complexity bound. [Mossel–Tamuz](https://www.tamuz.caltech.edu/papers/1003.5480.pdf)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Conclusion

The approximation guarantee is impossible within the stated complexity bound. For every \(0<\eta<1\), any successful execution requires at least \(N-1\) Cut queries. This holds already for one type with uniform density, regardless of randomization or succinct output.

1. The endpoint restriction forces many queries

Consider a completed execution making \(q\) Cut queries. Let \(c\) be the number of distinct interior points returned by those queries. Since each query returns one point, \(c\le q\).

Write these points in increasing order as \(x_1,\ldots,x_c\), and set \(x_0=0\) and \(x_{c+1}=1\). They determine \(c+1\) elementary intervals
\(I_r=(x_r,x_{r+1})\), indexed by \(0\le r\le c\).

By the output restriction, each elementary interval receives a single recipient-piece label. Consequently, every \(A_j\), apart from endpoints, is a union of elementary intervals carrying label \(j\). Every endpoint has value zero under every type, because valuations have integrable densities.

Suppose \(0<\eta<1\), and fix any \(t\in T\). The required lower bound gives
\(V_t(A_j)\ge (1-\eta)/N>0\)
for every \(j\). Thus each label must occur on at least one elementary interval of positive \(t\)-value: otherwise its piece would have value zero.

Different labels require different elementary intervals. Hence
\(N\le c+1\le q+1\),
and therefore
\(q\ge N-1\).

This argument allows disconnected pieces, repeated cut points, zero-density regions, and compressed programs. Compression cannot create additional elementary intervals.

There is also a lower bound using only the upper guarantee. Each elementary interval lies in one piece, so
\(V_t(I_r)\le (1+\eta)/N\).
The intervals cover the cake except for finitely many zero-value endpoints. Therefore
\(1=\sum_{r=0}^{c}V_t(I_r)\le (c+1)(1+\eta)/N\),
which implies
\(q\ge \lceil N/(1+\eta)\rceil-1\).
Thus any fixed positive \(\eta\), including \(\eta\ge1\), still forces a number of queries linear in \(N\).

2. Contradiction with the proposed polynomial bound

Take the admissible family of inputs with:

  • \(m=1\) and \(T=\{t\}\), so \(\tau=1\);
  • \(\mu(t)=1\);
  • \(v_t(x)=1\) throughout the cake;
  • \(\eta=1/2\);
  • \(N=2^k\), encoded in binary.

All finite input data other than \(N\) have constant length, so \(L=\Theta(k)\). The proposed bound
\(\operatorname{poly}(m,\tau,L,1/\eta,\log N)\)
is therefore polynomial in \(k\).

But every successful truthful execution requires at least
\(N-1=2^k-1\)
Cut queries. Each query contributes to total complexity, and this exponential lower bound eventually exceeds every polynomial in \(k\).

The contradiction applies to randomized protocols as well: the counting argument holds separately for every successful realization of their randomness. Under the stipulated guarantee on every truthful execution, every such execution incurs the lower bound.

3. Uniform assignment does preserve truthfulness in expectation

The incentive requirement itself poses no additional obstruction.

Fix a recipient’s normalized true valuation \(V\), any reporting strategies, and any completed partition \(A_1,\ldots,A_N\). Conditional on everything determined before the independent uniform permutation \(\pi\), the recipient receives each piece with probability \(1/N\). Its conditional expected value is consequently
\(\mathbb E[V(A_{\pi(i)})\mid A_1,\ldots,A_N] =\frac1N\sum_{j=1}^{N}V(A_j)=1/N\).

The last equality follows from complete allocation and the zero value of shared endpoints. Taking expectation over the preceding execution preserves this value.

Thus changing consistent replies cannot increase expected utility, provided the protocol always terminates with a complete partition. This is also the expectation argument in [Mossel–Tamuz, Proposition 2.2](https://www.tamuz.caltech.edu/papers/1003.5480.pdf).

4. The query obstruction is sharp for one type

For a single type, exact equal-value partitioning requires only the matching \(N-1\) Cut queries: ask
\(\operatorname{Cut}(t;r/N)\)
for each \(r\in\{1,\ldots,N-1\}\).

Let the returned points be \(y_r\), with \(y_0=0\) and \(y_N=1\). The cumulative valuation is nondecreasing, and its values at successive points strictly increase, so \(y_0<y_1<\cdots<y_N\). Each consecutive interval has value
\(V_t([y_{r-1},y_r])=r/N-(r-1)/N=1/N\).

This works even when the density vanishes on intervals and Cut answers are nonunique. Uniform assignment then gives truthfulness in expectation.

Accordingly, the negative result concerns the required dependence on binary-encoded \(N\). Neither succinct labels nor uniform random assignment removes the \(N-1\) charged endpoints necessary when \(0<\eta<1\).
