Theorem 1 — class: other

The continuous mirror question, as graded

Given a finite set of peer-effect types \(T\), rational population masses \(\mu_t>0\) summing to one, and finite rational distributions \(\nu_t\) over observed influence-outcome pairs \((I,Y)\), choose a trigger \(r_t\) for each type to maximize \(\sum_{t\in T}\mu_t\bigl(\mathbb{E}_{\nu_t}[Y\mid I\ge r_t]-\mathbb{E}_{\nu_t}[Y\mid I<r_t]\bigr)\), with both conditional sets nonempty.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq 1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types.
For each type \(t\), the input explicitly lists a finite probability distribution \(\nu_t\) with positive binary-rational probabilities on pairs \((I,Y)\), where \(I\in\mathbb{Q}\cap[0,1]\) is normalized activation influence and \(Y\in\{0,1\}\) indicates activation. Each distribution has at least two distinct influence values; no deterministic threshold relation is promised.
Choose one trigger \(r_t\in[0,1]\) per type, requiring \(\nu_t(I<r_t)>0\) and \(\nu_t(I\geq r_t)>0\). Conditional expectations use the probabilities in \(\nu_t\); equal influence values remain together, with equality assigned above the trigger. Any maximizing choice is acceptable.
The objective is \(F(r)=\sum_{t\in T}\mu_t\bigl(\mathbb{E}_{\nu_t}[Y\mid I\geq r_t]-\mathbb{E}_{\nu_t}[Y\mid I<r_t]\bigr)\). Let \(m=\sum_t|\operatorname{supp}(\nu_t)|\), and let \(L\) be the total binary input length, including a rational target value \(q\).

Is deciding whether there exist feasible triggers with \(F(r)\geq q\) in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite deterministic linear-threshold potential outcomes with both activation classes present, the true threshold maximizes the difference of conditional means; this is presented as a threshold-estimation result, without a complexity classification ([Tran and Zheleva, 2022](https://arxiv.org/pdf/2201.11242)).
No result settling this exact explicitly encoded mass problem was located in the literature search.

Modeling choices made when packaging the task

  • Restricted influence values and triggers to [0,1], following normalized activation influence, and outcomes to {0,1}, following the activation indicator.
  • Made each outcome distribution an explicit list of positive binary-rational atom probabilities summing to one.
  • Required at least two distinct influence values per type so that the stipulated two positive-probability conditional groups are feasible.
  • Retained arbitrary observed distributions rather than adding the anchor proof's deterministic threshold promise, which the graded question does not impose.
  • Allowed any maximizing trigger and kept tied influence values together; finite influence support does not justify a unique numerical trigger.
  • Defined m as the total number of listed outcome-distribution atoms and L as total input bit length, and introduced a binary-rational target q to state the decision complexity question.

Result

The decision problem is in \(\mathrm{P}\). An exact maximizing trigger vector can also be computed in time polynomial in \(m,\tau,L\).

The proof uses two properties of the stated input: each distribution is explicitly listed, and triggers for different types are unconstrained by one another. No deterministic threshold relation is needed.

1. Each type has finitely many relevant cuts

Fix a type \(t\). Let its distinct influence values, in increasing order, be
\(x_{t,1}<\cdots<x_{t,s_t}\).
By hypothesis, \(s_t\geq 2\).

For each influence value define
\[ \text{} \]
The following quantities aggregate all outcomes at that influence:
\(w_{t,j}=\nu_t(I=x_{t,j})\) and
\(a_{t,j}=\nu_t(I=x_{t,j},Y=1)\).

Thus \(w_{t,j}>0\), \(0\leq a_{t,j}\leq w_{t,j}\), and
\(\sum_{j=1}^{s_t}w_{t,j}=1\). This aggregation keeps equal influence values together, as required.

A trigger \(r_t\) is feasible precisely when, for some
\(k\in\{1,\ldots,s_t-1\}\), it satisfies
\(x_{t,k}<r_t\leq x_{t,k+1}\).
Indeed, positivity of the probabilities on both sides requires at least one influence value below the trigger and at least one at or above it. Sorting then identifies exactly such a cut.

Conversely, every such cut is feasible and has the representative trigger
\(r_t=x_{t,k+1}\in[0,1]\).
Equality belongs above the trigger, so this representative puts exactly the first \(k\) influence groups below it.

Define the prefix quantities
\(W_{t,k}=\sum_{j=1}^{k}w_{t,j}\),
\(A_{t,k}=\sum_{j=1}^{k}a_{t,j}\), and the total activation probability
\(B_t=\sum_{j=1}^{s_t}a_{t,j}\).

For every feasible cut, \(0<W_{t,k}<1\). Since \(Y\) is binary, its two conditional means are
\(\mathbb{E}[Y\mid I<r_t]=A_{t,k}/W_{t,k}\) and
\(\mathbb{E}[Y\mid I\geq r_t]=(B_t-A_{t,k})/(1-W_{t,k})\).

Consequently, the score of cut \(k\) is exactly
\(d_{t,k}=(B_t-A_{t,k})/(1-W_{t,k})-A_{t,k}/W_{t,k}\).
Every feasible trigger has one of these scores, and every listed score is attained.

2. The global maximum separates by type

Let
\(d_t^*=\max_{1\leq k<s_t}d_{t,k}\),
and choose any maximizing index \(k_t^*\). These maxima exist because their candidate sets are finite and nonempty.

For every feasible trigger vector \(r\), the score of type \(t\) is at most \(d_t^*\). Since \(\mu_t>0\), summing these inequalities gives
\(F(r)\leq\sum_{t\in T}\mu_t d_t^*\).

Now choose \(r_t^*=x_{t,k_t^*+1}\) independently for every type. Section 1 proves that each choice is feasible and attains its local maximum. Therefore
\(F(r^*)=\sum_{t\in T}\mu_t d_t^*\).

Hence the attained global maximum is exactly
\(F^*=\sum_{t\in T}\mu_t d_t^*\).
The decision answer is yes if and only if \(F^*\geq q\).

This requires evaluating at most
\(\sum_t(s_t-1)\leq m-\tau\) candidate scores, rather than enumerating combinations of cuts.

3. Exact arithmetic has polynomial bit complexity

It remains to verify that the rational computations above do not require exponentially many bits. All bit lengths below refer to the ordinary explicit binary encoding in the question.

For type \(t\), write each listed probability as
\(p_{t,\ell}=c_{t,\ell}/b_{t,\ell}\), where numerator and denominator are positive integers. Put
\(D_t=\prod_{\ell}b_{t,\ell}\) and
\(z_{t,\ell}=c_{t,\ell}(D_t/b_{t,\ell})\).

These are integers, and normalization gives
\(\sum_{\ell}z_{t,\ell}=D_t\).
Computing them requires only integer multiplication and exact integer division.

For cut \(k\), let \(U_{t,k}\) be the sum of the integer weights below the cut, \(V_{t,k}\) the sum below the cut with \(Y=1\), and \(C_t\) the total integer weight with \(Y=1\). Then
\(1\leq U_{t,k}\leq D_t-1\), and the score becomes
\(d_{t,k}=(U_{t,k}C_t-D_tV_{t,k})/[U_{t,k}(D_t-U_{t,k})]\).

The denominator is strictly positive. Thus two candidates can be compared exactly by cross multiplication, including when their numerators are negative.

Because the denominator encodings form part of the input,
\(\sum_t\log_2 D_t=\sum_{t,\ell}\log_2 b_{t,\ell}\leq L\).
Every integer weight and prefix sum is at most \(D_t\). Each candidate numerator has absolute value at most \(D_t^2\), and each candidate denominator is at most \(D_t^2\). All these integers, and the products needed to compare them, therefore have \(O(L)\) bits.

For each selected score write
\(d_t^*=N_t/H_t\), using the integer expression above, with \(H_t>0\). Write the input mass as
\(\mu_t=u_t/v_t\), with \(v_t>0\).
A common denominator for the weighted sum is
\(Q=\prod_{t\in T}v_tH_t\).

Since \(H_t\leq D_t^2\), we have
\(\log_2 Q\leq\sum_t\log_2 v_t+2\sum_t\log_2 D_t=O(L)\).
Thus even this unreduced common denominator has only \(O(L)\) bits.

The corresponding numerator also has \(O(L)\) bits. To see this explicitly, each score belongs to \([-1,1]\), because it is a difference of two conditional means in \([0,1]\). For any subset of processed types, the absolute value of its weighted sum is therefore at most the sum of its masses, which is at most \(1\). When sequential rational addition uses the product of the processed denominators, its numerator consequently has absolute value at most that denominator.

Finally, write \(q=c/e\), with \(e>0\). If \(F^*=P/Q\), the answer is determined exactly by comparing the integers \(Pe\) and \(cQ\). Both have \(O(L)\) bits.

4. Algorithm and running time

The algorithm is:

  • Sort each type’s support by influence, comparing rational influences exactly.
  • Aggregate equal influences and compute the integer prefix sums described above.
  • Evaluate every feasible cut and retain a maximum by exact cross multiplication.
  • Sum the selected scores with their masses and compare the result with \(q\).
  • If requested, return the maximizing triggers \(r_t^*=x_{t,k_t^*+1}\).

Sorting requires \(O(m\log(m+1))\) rational comparisons. The remaining work requires \(O(m+\tau)\) integer arithmetic operations. Every operation uses integers of \(O(L)\) bits. Using elementary quadratic-time integer arithmetic gives the polynomial bit-operation bound
\(O((m\log(m+1)+m+\tau)L^2)\).

The deterministic threshold-estimation setting discussed by [Tran and Zheleva (2022)](https://arxiv.org/pdf/2201.11242) is not needed for this argument. The algorithm applies to every explicitly supplied distribution satisfying the question’s hypotheses, including those with no deterministic threshold relation.

Thus the stated problem is polynomial-time solvable. Under polynomial-time many-one reductions, it could be \(\mathrm{NP}\)-hard only if \(\mathrm{P}=\mathrm{NP}\).
