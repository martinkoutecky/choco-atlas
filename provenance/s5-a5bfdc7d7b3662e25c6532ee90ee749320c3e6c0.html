The continuous mirror question, as graded

Given a candidate set \(C\), an explicitly listed support \(T\) of complete rankings with rational masses \(\mu_t\) summing to \(1\), a target \(c^\star\), and a budget \(k\), does there exist \(D \subseteq C \setminus \{c^\star\}\) with \(|D| \le k\) such that \(c^\star\) is the unique Llull winner after deleting \(D\) and restricting each ranking to \(C \setminus D\)? For each remaining pair \(a,b\), \(a\) defeats \(b\) when the mass ranking \(a\) above \(b\) exceeds \(1/2\); a tie awards both candidates a point.

Packaged proof task (what the prover saw — nothing else)

Given a nonempty candidate set \(C\), let \(m=|C|\), let \(c^\star\in C\), and let the deletion budget \(k\geq1\) be a binary integer.
A society is given by its support: an explicit list \(T\) of \(\tau\) distinct strict complete rankings, each with positive binary rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
Deleting \(D\subseteq C\setminus\{c^\star\}\) restricts every ranking to \(C\setminus D\), preserving its mass. In each remaining pairwise contest, a candidate receives one point for a strict majority win, zero for a loss, and one for a tie at mass \(1/2\). Its Llull score is the sum of these points; a unique winner has strictly greater score than every other remaining candidate, with no tie-breaking.
The decision problem asks whether some \(D\) with \(|D|\leq k\) makes \(c^\star\) the unique Llull winner.
Let \(G\) be the directed graph on \(C\) with arc \(a\to b\) exactly when \(a\) defeats \(b\). Let \(s_v\) and \(s_a\) be its minimum directed feedback vertex set size and minimum feedback arc set size. State running times in \(m,\tau,L,k\) and any structural parameter used.

Is this rational-mass candidate-deletion problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?
If it is \(\mathrm{NP}\)-hard, is it fixed-parameter tractable with respect to \(s_v\), or with respect to \(s_a\)?

For finite electorates, Minimum Indegree Deletion, the corresponding graph problem, is \(\mathrm{W}[2]\)-hard separately for \(s_v\) and \(s_a\) ([Bredereck](https://arxiv.org/abs/1108.2191)).
Finite-electorate unique-winner Llull candidate deletion is \(\mathrm{NP}\)-complete even with ten voters ([Betzler–Uhlmann](https://fpt.akt.tu-berlin.de/publications/cocoa08-stamped.pdf)). No result explicitly treating this precise rational-mass support encoding was verified.

Classification

The problem is \(\mathrm{NP}\)-complete, even when \(\tau\leq 10\). It is also \(\mathrm{W}[2]\)-hard separately for \(s_v\) and \(s_a\). Thus, an algorithm fixed-parameter tractable in either structural parameter would imply \(\mathrm{FPT}=\mathrm{W}[2]\).

These conclusions apply to the precise rational-mass support encoding in the question. The essential point is that arbitrary oriented graphs can be realized with polynomially many explicitly listed rankings, while preserving the strict-majority graph exactly.

The cases \(m=1\) and \(k\geq m-1\) are immediately yes-instances: retain only \(c^\star\). The classification concerns the general case.

1. Exact correspondence with Minimum Indegree Deletion

An oriented graph is a directed graph without loops or opposing arcs. The strict-majority graph \(G\) is oriented: both candidates cannot receive mass strictly greater than \(1/2\) against each other.

Let \(S\subseteq C\) contain \(c^\star\). Restricting rankings to \(S\) preserves the relative order of every pair in \(S\), so the resulting strict-majority graph is exactly \(G[S]\).

Write \(d^-_{G[S]}(a)\) for the indegree of \(a\) in \(G[S]\). Against each other remaining candidate, \(a\) receives one point unless it loses. Its losses are exactly its incoming arcs. Consequently,

\(\displaystyle \operatorname{Llull}_S(a)=|S|-1-d^-_{G[S]}(a).\)

Therefore,

\(\displaystyle c^\star\text{ is the unique Llull winner on }S \quad\Longleftrightarrow\quad d^-_{G[S]}(c^\star)<d^-_{G[S]}(a) \text{ for every }a\in S\setminus\{c^\star\}.\)

This includes pairwise ties correctly: a tied pair contributes a point to each endpoint and contributes no arc.

Thus the election problem is exactly Minimum Indegree Deletion on its strict-majority graph, with the same distinguished vertex and deletion budget.

2. Polynomial-time arithmetic and membership in NP

Write each input mass as \(\mu_t=p_t/q_t\), with positive integers \(p_t,q_t\). Define

\(\displaystyle Q=\prod_{t\in T}q_t,\qquad w_t=p_t(Q/q_t).\)

The bit length of \(Q\) is at most the sum of the denominator bit lengths, hence is \(O(L)\). Since the masses sum to one,

\(\displaystyle \sum_{t\in T}w_t=Q.\)

For each pair \(a,b\), compute the integer

\(\displaystyle W_{ab}=\sum_{\substack{t\in T\\a\text{ precedes }b\text{ in }t}}w_t.\)

Comparing \(2W_{ab}\) with \(Q\) determines whether \(a\) wins, ties, or loses. All these integers have \(O(L)\) bits. In particular, no expansion into an electorate of size \(Q\) is needed.

Using elementary integer arithmetic, a conservative bound for constructing \(G\), including reading the input, is

\(\displaystyle P(m,\tau,L)=O\!\left(L+\tau m^2L^2\right).\)

A certificate is a subset \(D\subseteq C\setminus\{c^\star\}\), represented by an \(m\)-bit incidence vector. Verify its size against the binary budget and compute the remaining indegrees. This takes

\(\displaystyle O\!\left(P(m,\tau,L)+m^2L\right)\)

bit operations. The certificate has polynomial length, so the problem belongs to \(\mathrm{NP}\).

3. Realizing an arbitrary oriented graph

We now prove the reduction needed to transfer structural hardness.

Let \(H=(C,A)\) be any oriented graph, and put \(q=|A|\).

Construction when there is an arc

Suppose \(q>0\). For every arc \(a\to b\), choose an ordering \(r_1,\ldots,r_{m-2}\) of the other candidates and create two rankings:

\(\displaystyle a\succ b\succ r_1\succ\cdots\succ r_{m-2},\)

\(\displaystyle r_{m-2}\succ\cdots\succ r_1\succ a\succ b.\)

Initially give each of the \(2q\) ranking occurrences mass \(1/(2q)\).

For the pair \(a,b\), these two rankings both place \(a\) ahead of \(b\). For every other pair, the rankings disagree:

  • A pair entirely among the \(r_i\) appears in opposite orders.
  • A pair involving one of \(a,b\) and one \(r_i\) also appears in opposite orders.

Thus this gadget contributes an unnormalized pairwise margin of \(2\) only to its designated arc and contributes zero to every other pair.

Since \(H\) has no opposing arcs, summing all gadgets gives

\(\displaystyle \Pr[a\succ b]= \begin{cases} \frac12+\frac{1}{2q},&a\to b\in A,\\ \frac12-\frac{1}{2q},&b\to a\in A,\\ \frac12,&\text{neither arc is present}. \end{cases}\)

The strict-majority graph is therefore exactly \(H\).

If a ranking occurs more than once, merge its occurrences. A ranking with multiplicity \(h\) receives mass \(h/(2q)\). This makes the support rankings distinct, preserves every pairwise mass, and gives positive rational masses summing to one.

Construction when there are no arcs

If \(q=0\), use any ranking and its reverse, each with mass \(1/2\). Every pair ties. For \(m=1\), merge the identical rankings into the single ranking of mass one.

Encoding and parameter preservation

The construction has

\(\displaystyle \tau\leq 2\max\{1,q\}=O(m^2).\)

After numbering candidates, its total output length, including the unchanged binary budget, is

\(\displaystyle L'=O\!\left(m^3\log(m+1)+\log(k+1)\right).\)

Constructing and sorting the ranking occurrences to merge duplicates takes, conservatively,

\(\displaystyle O\!\left(m^3\log^2(m+1)+\log(k+1)\right)\)

bit operations.

Because the resulting majority graph is exactly \(H\), the construction preserves both minimum feedback parameters exactly:

\(\displaystyle s_v(G)=s_v(H),\qquad s_a(G)=s_a(H).\)

Section 1 shows that it also preserves the answer and the deletion budget.

4. Classical hardness, even with small support

Betzler–Uhlmann’s Theorem 3 states that constructive candidate deletion for Llull is \(\mathrm{NP}\)-complete with ten votes. Their paper explicitly uses the unique-winner convention and awards one point for a pairwise tie. [Betzler–Uhlmann](https://fpt.akt.tu-berlin.de/publications/cocoa08-stamped.pdf)

Convert such an instance into the required encoding as follows. For each distinct ranking \(t\), let \(n_t\) be its multiplicity among the ten votes, and set

\(\displaystyle \mu_t=\frac{n_t}{10}.\)

The resulting support has \(\tau\leq 10\), positive binary rational masses, and total mass one. For every candidate pair, its support mass is precisely its finite-electorate vote fraction. The same remains true after any candidate deletion.

Therefore the conversion preserves every feasible deletion set and the unique-winner condition. Aggregating ten rankings takes \(O(m\log(m+1))\) bit operations after candidate numbering.

This proves \(\mathrm{NP}\)-hardness for the support encoding, even with \(\tau\leq 10\). Together with Section 2, it proves \(\mathrm{NP}\)-completeness.

5. Hardness for both feedback parameters

The known result used here is:

Bredereck’s Theorem 1, Section 4.2. Minimum Indegree Deletion is \(\mathrm{W}[2]\)-hard separately for the directed feedback vertex set parameter and the feedback arc set parameter. Its reduction from Dominating Set with solution-size parameter \(h\) produces graphs satisfying \(s_v\leq h+1\) and \(s_a\leq(h+1)^2\). [Bredereck](https://arxiv.org/pdf/1108.2191)

The relevant graph-class hypothesis can be checked directly in that construction. Its blocks have arcs

\(\displaystyle X\to Y,\quad Y\to Z,\quad Z\to X,\)

together with arcs from these blocks to later blocks, from the dominating-vertex block to the dominated-vertex block and distinguished vertex, and from dominated vertices to auxiliary vertices. No pair receives arcs in both directions. Hence its hard instances are oriented graphs, which Section 3 can realize.

Compose Bredereck’s reduction with the rational-support construction. The latter is polynomial-time, preserves the answer by Section 1, and preserves the graph itself. Consequently, the output parameters still satisfy

\(\displaystyle s_v\leq h+1,\qquad s_a\leq(h+1)^2.\)

These are valid parameterized reductions for each parameter separately. Thus the rational-support election problem is \(\mathrm{W}[2]\)-hard for \(s_v\), and separately for \(s_a\).

In particular, an algorithm with running time

\(\displaystyle f(s_v)L^{O(1)}\quad\text{or}\quad f(s_a)L^{O(1)}\)

would yield an FPT algorithm for Dominating Set parameterized by \(h\). Therefore neither structural parameter alone gives fixed-parameter tractability unless \(\mathrm{FPT}=\mathrm{W}[2]\). This is a conditional exclusion, not a claimed separation of complexity classes.

6. Explicit algorithmic bounds

The hardness conclusions coexist with the following upper bounds.

Enumeration by deletion budget

Put \(k'=\min\{k,m-1\}\). Enumerate every eligible deletion subset of size at most \(k'\), then check remaining indegrees. The running time is

\(\displaystyle O\!\left( P(m,\tau,L)+ m^2L\sum_{i=0}^{k'}\binom{m-1}{i} \right).\)

This gives an FPT algorithm in \(m\), with time

\(\displaystyle O\!\left(P(m,\tau,L)+2^{m-1}m^2L\right),\)

and an XP bound in \(k\).

An XP algorithm for the feedback parameters

We give the argument explicitly, so this bound does not require a supplied feedback set.

Let \(s=s_v(G)\). Every nonempty induced subgraph \(H\) of \(G\) has a vertex of indegree at most \(s\). To prove this, take a feedback vertex set \(F\) of size \(s\):

  • If \(V(H)\setminus F\) is nonempty, its induced graph is acyclic. A source there has incoming neighbors in \(H\) only from \(F\), hence indegree at most \(s\).
  • Otherwise, every vertex of \(H\) has indegree at most \(|V(H)|-1\leq s-1\).

It follows that in any successful remaining graph, \(c^\star\) has indegree at most \(s\).

Let \(I\) be the original set of incoming neighbors of \(c^\star\). Enumerate all \(N\subseteq I\) with \(|N|\leq s\), interpreting \(N\) as its surviving incoming neighbors. For each choice:

  • Delete \(I\setminus N\), and put \(r=|N|\).
  • Repeatedly delete any vertex other than \(c^\star\) whose current indegree is at most \(r\).
  • Reject this choice if the process deletes a member of \(N\) or exceeds the budget.

For a choice not rejected, \(c^\star\) retains indegree \(r\). At termination, every other remaining vertex has indegree greater than \(r\), so the result is valid.

For completeness, suppose \(D^\star\) is a successful deletion set and choose \(N=I\setminus D^\star\). Then \(|N|\leq s\). Initially all deletions belong to \(D^\star\). Inductively, if a vertex has current indegree at most \(r\), it cannot survive in the successful graph: further deletions cannot increase its indegree, whereas every surviving rival there has indegree greater than \(r\). Thus every forced deletion also belongs to \(D^\star\). The process neither deletes \(N\) nor exceeds the budget.

Each closure computation takes \(O(m^2L)\) bit operations. Determine \(s\) first by enumerating vertex subsets in increasing size and testing acyclicity. For \(m\geq2\), the combined running time is

\(\displaystyle O\!\left(P(m,\tau,L)+(s_v+1)m^{s_v+2}L\right).\)

Finally, \(s_v\leq s_a\): choosing one endpoint of each arc in a feedback arc set produces a feedback vertex set, because every directed cycle contains an arc of that set. Hence the same algorithm also has the bound

\(\displaystyle O\!\left(P(m,\tau,L)+(s_a+1)m^{s_a+2}L\right).\)

These are XP bounds for the individual structural parameters, consistent with their \(\mathrm{W}[2]\)-hardness.
