The continuous mirror question, as graded

Given candidates \(C\), an integer \(k\), and an ordered list of rankings \((\pi_i)_{i=1}^{\tau}\) occupying consecutive intervals of rational masses \((\lambda_i)_{i=1}^{\tau}\) on \([0,1]\), with each \(\lambda_i>0\) and \(\sum_i \lambda_i=1\), is there a subset \(X\subseteq C\) with \(|C\setminus X|\le k\) such that, for every pair in \(X\), its relative order along the population axis switches at most once, up to measure-zero points?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) distinct ranking types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible rankings.
Let \(C\) be a finite nonempty candidate set, \(m=|C|\), and let each type \(\pi_j\) be a strict linear order on \(C\), with mass \(\lambda_j>0\) and \(\sum_{j=1}^{\tau}\lambda_j=1\).
The fixed population axis \([0,1]\) is specified by an ordered list of \(q\) consecutive intervals with positive binary rational lengths \(\mu_r\) and type labels \(j_r\), satisfying \(\sum_{r:j_r=j}\mu_r=\lambda_j\). Types may occur in several intervals; interval endpoints may be ignored.
Given an integer \(k\geq1\), ask whether there exists \(X\subseteq C\) with \(|C\setminus X|\leq k\) such that, for every distinct \(a,b\in X\), their relative order along the axis changes at most once outside a set of Lebesgue measure zero. Restricting to \(X\) preserves every surviving pair's order, and the population axis cannot be reordered. Empty and singleton \(X\) satisfy the condition.
Let \(L\) be the total binary input length; state running times in \(m,\tau,q,k,L\).

Is this continuous candidate-deletion decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite ordered lists of voters with strict rankings, candidate deletion to obtain single-crossing preferences is \(\mathrm{NP}\)-complete. It is solvable in polynomial time when there are at most three voters.

Modeling choices made when packaging the task

  • The ordered ranking list may repeat a ranking. To preserve those repetitions while making tau the actual support size, distinguish tau distinct ranking types from q ordered intervals and require interval lengths to aggregate to each type's mass.
  • Require strict linear orders and a fixed, non-reorderable population axis, as in the discrete definition.
  • Require k to be an integer at least one, as in the discrete candidate-deletion definition.
  • Take the candidate set to be nonempty; allow empty and singleton retained sets, which the discrete subset definition permits.
  • Define L as the total binary input length, including the ordered interval representation.

Result

The problem is \(\mathrm{NP}\)-complete, using the finite ordered-voter hardness result supplied in the question. Hardness holds even when every interval length and every type mass is a dyadic rational.

The key is that each interval has positive length: the continuous condition is exactly the single-crossing condition for the finite sequence of rankings in the specified axis order.

1. Equivalence of the continuous and finite conditions

For distinct candidates \(a,b\), define \(\sigma_r(a,b)=1\) if ranking \(\pi_{j_r}\) places \(a\) above \(b\), and \(\sigma_r(a,b)=0\) otherwise. Let

\(\displaystyle d(a,b)=\bigl|\{r\in\{1,\ldots,q-1\}:\sigma_r(a,b)\ne\sigma_{r+1}(a,b)\}\bigr|.\)

Lemma. The relative order of \(a,b\) changes at most once along the population axis outside a null set if and only if \(d(a,b)\leq1\).

Proof. If \(d(a,b)\leq1\), the relative order is constant throughout all interval interiors, or changes at a single interval boundary. The finitely many endpoints form a null set.

Conversely, suppose \(d(a,b)\geq2\). The binary sequence then contains three intervals in increasing axis order whose signs alternate: either \(1,0,1\) or \(0,1,0\). For any null set \(N\), each of these intervals contains a point outside \(N\), because its length is positive. Those three points witness two changes of relative order. Thus removing a null set cannot make the pair change at most once. \(\square\)

Restricting rankings to \(X\) preserves every surviving pair’s comparison. Consequently, \(X\) is feasible precisely when \(d(a,b)\leq1\) for every distinct \(a,b\in X\).

This equivalence uses the full ordered interval sequence, including repeated types.

2. Polynomial reduction from the finite problem

Take an instance of the supplied \(\mathrm{NP}\)-complete finite problem: a candidate set \(C\), an ordered list of \(n\geq1\) strict rankings \(\rho_1,\ldots,\rho_n\), and deletion budget \(k\).

Set \(\displaystyle h=\lceil\log_2 n\rceil\) and \(D=2^h\). Construct \(q=n\) consecutive intervals, with lengths

\(\displaystyle \mu_i=\frac1D\quad(1\leq i<n),\qquad \mu_n=\frac{D-n+1}{D}.\)

These lengths are positive because \(D\geq n\), and their sum is

\(\displaystyle \frac{n-1+D-n+1}{D}=1.\)

List the distinct rankings among the \(\rho_i\) as \(\pi_1,\ldots,\pi_\tau\), and label interval \(i\) with the type representing \(\rho_i\). Define each support mass by

\(\displaystyle \lambda_j=\sum_{i:j_i=j}\mu_i.\)

Every listed type occurs, so every \(\lambda_j\) is positive. All masses and interval lengths have denominator \(D\), hence are dyadic rationals with binary descriptions of length \(O(\log(n+1))\). The required consistency equations hold by construction.

By the lemma, for every candidate subset \(X\),

  • the restricted finite ordered profile is single-crossing;
  • the constructed continuous society satisfies the required condition on \(X\);

are equivalent. The candidate set and deletion budget are unchanged.

If the finite input has binary length \(L_{\mathrm{fin}}\), the constructed input has length \(O(L_{\mathrm{fin}}+n\log(n+1))\), and construction takes polynomial time. Here \(\tau\leq n\) and \(q=n\). Thus this is a polynomial many-one reduction, proving \(\mathrm{NP}\)-hardness.

If the supplied finite theorem allows budget \(k=0\), that does not obstruct the restriction \(k\geq1\). A zero-budget instance can be decided by checking all pairs. Map its answer to a fixed instance with budget \(1\): a singleton candidate set gives a yes-instance, while three candidates with axis rankings \(abc,cba,abc\) give a no-instance. In the latter, every pair changes twice, so at least two candidates must be deleted.

3. Membership in \(\mathrm{NP}\) and explicit running times

Precompute the position of every candidate in every support ranking. This takes \(O(\tau m)\) operations. For each unordered candidate pair, scan the \(q\) interval labels and count changes, stopping once two have been found. This takes \(O(qm^2)\) operations.

Define the forbidden-pair graph \(G\) on vertex set \(C\), placing an edge between \(a,b\) precisely when \(d(a,b)\geq2\).

By the lemma, a deletion set \(S\subseteq C\) is feasible exactly when it meets every edge of \(G\): it is a vertex cover. Indeed, an uncovered edge is a surviving pair that violates the condition, and covering all edges leaves no violating pair.

A certificate consists of the deleted candidates. Checking its size and verifying that it covers every edge establishes membership in \(\mathrm{NP}\).

Using a standard RAM model with words of \(O(\log(L+2))\) bits, graph construction and certificate verification take

\(\displaystyle O(L+\tau m+qm^2)\)

time and \(O(L+\tau m+m^2)\) space. A conservative bit-operation bound is

\(\displaystyle O\bigl((L+\tau m+qm^2)\log(L+2)\bigr).\)

There is also a direct parameterized decision algorithm. Choose an uncovered edge \(\{a,b\}\). Every vertex cover must contain \(a\) or \(b\), so branch on deleting either endpoint and decrease the remaining budget by one. The search tree has \(O(2^k)\) nodes; spending \(O(m^2)\) operations per node gives total time

\(\displaystyle O(L+\tau m+qm^2+2^k m^2).\)

The corresponding conservative bit bound has an additional factor \(O(\log(L+2))\). If \(k\geq m-1\), answer yes immediately, since a singleton can be retained.

4. Why support size does not replace axis length

The ordered interval list contains essential information beyond the support and its masses.

For example, let the two types be \(A=abc\) and \(B=cba\), each with mass \(1/2\). The axis \(A,B\), with lengths \(1/2,1/2\), satisfies the condition without deletions. The axis \(A,B,A\), with lengths \(1/4,1/2,1/4\), has the same support and masses, but every pair changes twice. It therefore requires at least two deletions.

The supplied polynomial result for at most three voters applies directly when \(q\leq3\), through the lemma. General hardness follows when the axis length is unbounded, even though repeated rankings are stored only once in the support.
