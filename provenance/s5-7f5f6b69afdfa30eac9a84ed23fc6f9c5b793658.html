The continuous mirror question, as graded

Given rational masses μ_t over complete applicant-profile types, per-capita university capacities κ_u, and type assignment fractions \(q_{t,u}\in[0,1]\) satisfying \(\sum_u q_{t,u}\leq 1\) and \(\sum_t μ_t q_{t,u}\leq κ_u\), what pairwise-fairness guarantees does a mass-scaled version of the paper’s nomination heuristic satisfy? In particular, do the type-level priority implications corresponding to Proposition 3 hold, and can the weak- and strong-fairness violations of Proposition 4 persist?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) applicant-profile types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible profiles. There are \(m\geq1\) universities with positive binary-rational per-capita capacities \(\kappa_u\). Let \(L\) be the total input bit length.
Each type \(t\) specifies a nonempty application set \(A_t\), a strict ranking with ranks \(r_{t,u}\in\{1,\ldots,|A_t|\}\), binary-rational aptitude scores \(a_{t,u}\in[0,1]\), a nonnegative binary-rational GPA score \(g_t\), and an integer \(e_t\geq0\) counting previous exchange semesters; lower scores are better.
Assignments have \(q_{t,u}\in[0,1]\), with \(q_{t,u}=0\) outside \(A_t\), \(\sum_u q_{t,u}\leq1\), and \(\sum_t\mu_tq_{t,u}\leq\kappa_u\). Write \(N_t=\sum_u q_{t,u}\) and \(H_t(u)=\sum_{v\in A_t:r_{t,v}\leq r_{t,u}}q_{t,v}\).
The mass nomination heuristic starts with zero assignments and residual capacities \(C_u=\kappa_u\). Process semester counts increasingly, then ranks increasingly, then universities in a supplied fixed order; at each step process eligible types in ascending lexicographic order of \((a_{t,u},g_t,t)\). Transfer \(\delta=\min\{\mu_t(1-N_t),C_u\}\) mass to \(u\), increasing \(q_{t,u}\) by \(\delta/\mu_t\) and decreasing \(C_u\) by \(\delta\). Eligibility means \(u\in A_t\), the current semester count and rank match, and \(N_t<1\).
For distinct types \(s,k\) applying to \(u\), semester fairness requires \(q_{k,u}\leq N_s\) whenever \(e_s<e_k\).
When \(e_s=e_k\), dominance fairness requires \(q_{k,u}\leq H_s(u)\) if \(r_{s,u}\leq r_{k,u}\) and \(a_{s,u}\leq a_{k,u}\), with at least one strict inequality, or if both are equal and \(g_s<g_k\).
For conflict pairs with \(e_s=e_k\), \(r_{s,u}>r_{k,u}\), and \(a_{s,u}<a_{k,u}\), weak fairness additionally requires \(q_{k,u}\leq N_s\), while strong fairness instead requires \(q_{k,u}\leq H_s(u)\); both include semester and dominance fairness.
For each of semester, dominance, weak, and strong fairness, does the mass nomination heuristic always satisfy it, or can it violate it?
Is deciding whether its output satisfies each fairness condition in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is any such decision problem \(\mathrm{NP}\)-hard?
In the discrete setting, the nomination heuristic guarantees dominance fairness but can violate weak and strong fairness. [Verified discrete results](https://orca.cardiff.ac.uk/id/eprint/136292/1/Manuscript_AcceptedForPublication.pdf).
No result settling this precisely specified mass version was located.

2. A saturation lemma

Call the scheduled consideration of an application \((t,u)\) its event, including when it is skipped because \(N_t=1\). Every application has exactly one event.

Every transfer preserves \(0\leq N_t\leq1\), nonnegative assignments, and nonnegative residual capacities: its mass is at most both the type’s remaining mass and the university’s residual capacity. Residual capacities never increase.

Lemma. Suppose distinct types \(s,k\) apply to \(u\), and the event for \((s,u)\) precedes the event for \((k,u)\). If the final output has \(q_{k,u}>0\), then the final output has \(H_s(u)=1\).

Proof. Since assignments start at zero and \((k,u)\) has only one event, \(q_{k,u}>0\) means that event transfers positive mass. Thus \(C_u>0\) immediately before that event.

Residual capacities never increase, so \(C_u>0\) immediately after the earlier event for \((s,u)\).

If \(N_s=1\) before its event, it remains fully assigned. Otherwise, write its remaining mass and the residual capacity immediately before its event as

\(\displaystyle B=\mu_s(1-N_s)>0,\qquad C=C_u.\)

The transfer is \(\delta=\min\{B,C\}\). Because the residual capacity afterward is positive, \(C-\delta>0\), hence \(\delta<C\). Therefore \(\delta=B\), and \(N_s=1\) immediately after its event.

All assignments of type \(s\) made before this event have rank strictly less than \(r_{s,u}\): semester count is fixed for a type, ranks are processed increasingly, and the ranking is strict. Any assignment made at this event is to \(u\). Consequently, immediately afterward,

\(\displaystyle H_s(u)=N_s=1.\)

The type is now fully assigned and receives no subsequent transfers, so its final value of \(H_s(u)\) is also \(1\). \(\square\)

The strict ranking hypothesis matters here: a type has only one application at each rank.

3. Semester and dominance fairness always hold

Semester fairness

Consider distinct types \(s,k\) applying to \(u\), with \(e_s<e_k\).

If \(q_{k,u}=0\), the required inequality \(q_{k,u}\leq N_s\) follows from \(N_s\geq0\).

If \(q_{k,u}>0\), the event for \((s,u)\) precedes that for \((k,u)\), since semester counts are processed first. The lemma gives \(H_s(u)=1\), and therefore \(N_s=1\). Since \(q_{k,u}\leq1\),

\(\displaystyle q_{k,u}\leq N_s.\)

Thus semester fairness always holds. In fact, the proof establishes the stronger inequality \(q_{k,u}\leq H_s(u)\) for these pairs.

Dominance fairness

Consider a pair to which dominance fairness applies, so \(e_s=e_k\). Its hypotheses imply that \((s,u)\) precedes \((k,u)\):

  • If \(r_{s,u}<r_{k,u}\), rank order puts \((s,u)\) first.
  • If ranks are equal and \(a_{s,u}<a_{k,u}\), aptitude order puts \(s\) first at their common university.
  • If ranks and aptitudes are equal and \(g_s<g_k\), GPA order puts \(s\) first.

These cases exhaust the dominance hypotheses. The type-index tie breaker is irrelevant because one of the preceding comparisons is strict.

If \(q_{k,u}=0\), the required inequality is immediate. Otherwise, the lemma gives \(H_s(u)=1\), so

\(\displaystyle q_{k,u}\leq H_s(u).\)

Thus dominance fairness always holds.

4. Counterexamples for weak and strong fairness

A two-type example violating both

Take two universities \(u,v\), in that fixed processing order, with capacities

\(\displaystyle \kappa_u=\frac12,\qquad \kappa_v=\frac14.\)

There are two types \(s,k\), each of mass \(1/2\), with \(e_s=e_k=0\) and \(g_s=g_k=0\).

| Type | Application ranking | Aptitudes |
|---|---|---|
| \(s\) | \(v\succ u\) | \(a_{s,v}=0,\ a_{s,u}=0\) |
| \(k\) | \(u\) only | \(a_{k,u}=1\) |

All input quantities satisfy the stated hypotheses, including positive capacities and masses summing to \(1\).

At rank \(1\):

  • University \(u\) receives all \(1/2\) mass of type \(k\), giving \(q_{k,u}=1\) and exhausting its capacity.
  • University \(v\) receives \(1/4\) mass of type \(s\), giving \(q_{s,v}=1/2\).

At rank \(2\), type \(s\) receives nothing at \(u\), whose capacity is exhausted. Hence

\(\displaystyle q_{k,u}=1,\qquad N_s=\frac12,\qquad H_s(u)=\frac12.\)

The pair is a conflict pair because

\(\displaystyle e_s=e_k,\qquad r_{s,u}=2>1=r_{k,u},\qquad a_{s,u}=0<1=a_{k,u}.\)

Weak fairness requires \(1\leq1/2\), and strong fairness requires the same false inequality. Thus both can be violated, even with \(\tau=2\) and \(m=2\).

For \(m=1\), conflict pairs cannot occur because every application has rank \(1\); consequently weak and strong fairness always hold in that special case.

Weak fairness can hold while strong fairness fails

To distinguish the two conditions on heuristic outputs, modify the example by adding a third university \(w\). Set

\(\displaystyle \kappa_u=\frac12,\qquad \kappa_v=\frac18,\qquad \kappa_w=\frac12.\)

Keep both masses equal to \(1/2\), both semester counts and GPAs equal to zero, and use:

  • Type \(s\): ranking \(v\succ u\succ w\), with aptitude \(0\) at each university.
  • Type \(k\): application to \(u\) only, with aptitude \(1\).

Use university order \(u,v,w\). The heuristic produces

\(\displaystyle q_{k,u}=1,\qquad q_{s,v}=\frac14,\qquad q_{s,u}=0,\qquad q_{s,w}=\frac34.\)

Indeed, \(k\) exhausts \(u\) at rank \(1\); \(s\) receives mass \(1/8\) at \(v\), nothing at \(u\), and its remaining mass \(3/8\) at \(w\).

Thus

\(\displaystyle N_s=1,\qquad H_s(u)=\frac14.\)

The only shared university is \(u\), and its only conflict orientation is \(s,k\). Its weak inequality holds:

\(\displaystyle q_{k,u}=1\leq N_s=1.\)

Semester and dominance fairness hold by the preceding proofs. Therefore this output is weakly fair. Its strong conflict inequality fails:

\(\displaystyle q_{k,u}=1>\frac14=H_s(u).\)

5. Exact simulation and verification take polynomial time

Let

\(\displaystyle E=\sum_{t=1}^{\tau}|A_t|\leq m\tau\)

be the number of explicitly listed applications.

Scheduling without iterating through large semester counts

Let \(\pi(u)\) denote a university’s position in the supplied order. Sort all application events lexicographically by

\(\displaystyle \bigl(e_t,r_{t,u},\pi(u),a_{t,u},g_t,t\bigr).\)

Then process this sorted list, skipping fully assigned types.

This exactly reproduces the heuristic: the first three components specify its outer processing order, and the final three specify its within-step order. There are only \(E\) events. In particular, an integer semester count with large numerical value does not require iterating through all smaller integers.

Integer mass arithmetic

Write the masses and capacities as binary-encoded rational numbers, and let \(D\) be the product of their denominators. The binary length of \(D\) is \(O(L)\), because the sum of the denominator bit lengths is at most \(L\).

Define integers

\(\displaystyle M_t=D\mu_t,\qquad K_u=D\kappa_u.\)

Maintain:

  • \(B_t\), the scaled remaining mass of type \(t\), initially \(M_t\);
  • \(Y_u\), the scaled residual capacity of \(u\), initially \(K_u\);
  • \(X_{t,u}\), the scaled assigned mass, initially zero.

At an event \((t,u)\), transfer

\(\displaystyle d=\min\{B_t,Y_u\}\)

and update

\(\displaystyle B_t\leftarrow B_t-d,\qquad Y_u\leftarrow Y_u-d,\qquad X_{t,u}\leftarrow X_{t,u}+d.\)

This is exactly the specified mass transfer multiplied by \(D\). The resulting fractions are

\(\displaystyle q_{t,u}=\frac{X_{t,u}}{M_t}.\)

All maintained integers have \(O(L)\) bits. Specifically, remaining and assigned type masses are bounded by \(M_t\leq D\), while residual capacities are bounded by their initial \(K_u\), whose bit lengths are \(O(L)\). Thus the simulation avoids uncontrolled denominator growth.

Checking every required inequality

Compute rank-prefix sums

\(\displaystyle T_{s,u}=\sum_{\substack{v\in A_s\\r_{s,v}\leq r_{s,u}}}X_{s,v}.\)

Then

\(\displaystyle N_s=\frac{M_s-B_s}{M_s},\qquad H_s(u)=\frac{T_{s,u}}{M_s}.\)

Since every mass is positive, \(M_s,M_k>0\). Therefore the semester and weak inequalities can be checked by the equivalent integer comparison

\(\displaystyle X_{k,u}M_s\leq(M_s-B_s)M_k,\)

and the dominance and strong inequalities by

\(\displaystyle X_{k,u}M_s\leq T_{s,u}M_k.\)

Enumerate all ordered pairs of distinct types applying to each university, test the relevant fairness hypotheses, and perform these comparisons. There are at most \(m\tau(\tau-1)\) such triples. Aptitude and GPA comparisons also take polynomial time by exact rational cross multiplication.

For example, using ordinary integer arithmetic, a conservative bit-operation bound is

\(\displaystyle O\!\left(\bigl(L+E\log(E+1)+m\tau^2\bigr)L^2\right).\)

This accounts for denominator scaling, sorting, transfers, prefix sums, and pairwise checks. Since \(E\leq m\tau\), it is polynomial in \(m,\tau,L\).

Consequently, all four output-verification problems lie in \(\mathrm{P}\). On valid inputs, semester and dominance verification can simply return yes by the proved guarantees; weak and strong verification use the exact simulation and checks above.
