The continuous mirror question, as graded

Given a finite set of types \(T\), blocs \(G\), and item categories \(J\), let each type \(t\) belong to a bloc \(g(t)\), have rational mass \(\mu_t\), and have utility \(u_{tj}\) for category \(j\), with \(\sum_t\mu_t=1\). Category \(j\) has rational per-branch supply \(q_j\), represented by \(Nq_j\) indivisible copies for a population of \(N\) branches. Choose positive-bid masses \(x_{tj}\in[0,\mu_t]\), setting \(x_{tj}=0\) when \(u_{tj}=0\). With \(P_j=\sum_t x_{tj}\), bloc \(g\)’s normalized expected utility is \(U_g(x)=\sum_{j:P_j>0}q_j\frac{\sum_{t:g(t)=g}u_{tj}x_{tj}}{P_j}\), with a zero term when \(P_j=0\). Find a feasible profile \(x\) such that \(U_g(x)\ge U_g(x'_g,x_{-g})\) for every bloc \(g\) and every feasible unilateral change \(x'_g\) to its bid masses.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. A surjection \(g:T\to G\) partitions types into nonempty blocs. There are \(m=|J|\ge1\) item categories, with positive rational supplies \(q_j\) per unit population and nonnegative rational utilities \(u_{tj}\). Let \(L\) be the total input bit length.
Each bloc simultaneously chooses real positive-bid masses \(x_{tj}\in[0,\mu_t]\) for its types, with \(x_{tj}=0\) whenever \(u_{tj}=0\). These choices are independent across categories; there are no bidding costs or budgets. Fractional masses describe deterministic participation by portions of a type, not randomized bloc strategies.
LIKE allocates each category proportionally to positive-bid mass. Write \(P_j=\sum_t x_{tj}\). Bloc \(g\) maximizes its aggregate normalized expected utility \(U_g(x)=\sum_{j:P_j>0}q_j\frac{\sum_{t:g(t)=g}u_{tj}x_{tj}}{P_j}\); an unbid category contributes zero and remains unallocated.
An equilibrium is a feasible profile satisfying \(U_g(x)\ge U_g(x'_g,x_{-g})\) for every bloc \(g\) and every feasible joint change \(x'_g\) of all its types across all categories. Indifference is allowed.

Is computing an exact equilibrium, or determining that none exists, polynomial-time solvable in \(m,\tau,|G|,L\), or is it NP-hard?

For finite agents with general utilities, computing a group pure Nash equilibrium under LIKE is polynomial-time solvable; a bound of \(O(n^3m)\) is reported ([Aleksandrov–Walsh](https://www.ijcai.org/proceedings/2017/0007.pdf)). No result settling this exact continuous bloc model was located.

Modeling choices made when packaging the task

  • Utilities are nonnegative binary rationals; zero utility denotes a disliked category and prohibits positive bids, consistently with monotone bidding.
  • Supplies are positive binary rationals; categories with zero supply can be omitted.
  • Blocs are nonempty and partition the support, as specified by the single-valued bloc assignment in the continuous question.
  • Bid masses may be real and have no population-size lattice restriction; the finite population parameter is only an interpretation of normalized supplies.
  • Participation choices have no costs, budgets, or constraints linking categories, matching independent item bids under LIKE.
  • An unbid category is unallocated and contributes zero utility, including when evaluating deviations.
  • The search problem includes determining nonexistence because equilibrium existence for the continuous model is not assumed.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Exact equilibrium computation is polynomial-time solvable

Every instance satisfying the stated assumptions admits an exact equilibrium. Moreover, an equilibrium can be computed in polynomial time in the binary input size, and every coordinate of the computed equilibrium satisfies \(x_{tj}\in\{0,\mu_t\}\).

Thus fractional participation is allowed but is not needed for existence or efficient computation.

1. Categories can be solved independently

For each category \(j\), define its contribution to bloc \(g\)’s payoff by

\(U_{gj}(x_{\cdot j})=q_j\frac{\sum_{t:g(t)=g}u_{tj}x_{tj}}{\sum_t x_{tj}}\)

when its denominator is positive, and by zero otherwise.

The feasible strategy set is a Cartesian product across categories, and \(U_g=\sum_j U_{gj}\). Consequently, if a profile admits no profitable unilateral deviation in any individual category, then it admits no profitable joint deviation: each summand under a joint deviation is at most its original value.

It therefore suffices to construct an equilibrium for one category. Fix that category and suppress its index. Since \(q>0\), maximizing its payoff is equivalent to maximizing the ratio without the factor \(q\).

Write

\(B_g=\sum_{t:g(t)=g}x_t,\qquad N_g=\sum_{t:g(t)=g}u_tx_t,\qquad P=\sum_t x_t.\)

When \(P>0\), define the threshold \(\theta_g=N_g/P\). The bloc’s category payoff is \(q\theta_g\).

2. A sufficient condition for global best responses

Lemma. Suppose \(P>0\), every coordinate satisfies \(x_t\in\{0,\mu_t\}\), and, for every type with \(u_t>0\),

  • if \(x_t=\mu_t\), then \(u_t\ge\theta_{g(t)}\);
  • if \(x_t=0\), then \(u_t\le\theta_{g(t)}\).

Then the profile is an equilibrium for this category, including against arbitrary feasible real-valued joint changes within a bloc.

Proof. Fix a bloc \(g\), and let \(y_t\in[0,\mu_t]\) be any feasible replacement for its coordinates. Let \(R=P-B_g\) be the unchanged bid mass outside the bloc. Set

\(N_g(y)=\sum_{t:g(t)=g}u_ty_t,\qquad B_g(y)=\sum_{t:g(t)=g}y_t.\)

Because \(N_g=\theta_gP\), we have the identity

\(N_g(y)-\theta_g\bigl(R+B_g(y)\bigr)=\sum_{t:g(t)=g}(u_t-\theta_g)(y_t-x_t).\)

Every summand on the right is nonpositive:

  • For a fully participating type, \(u_t-\theta_g\ge0\) and \(y_t-x_t\le0\).
  • For an excluded positive-utility type, \(u_t-\theta_g\le0\) and \(y_t-x_t\ge0\).
  • For a zero-utility type, feasibility forces \(y_t=x_t=0\).

If \(R+B_g(y)>0\), division by this positive denominator gives

\(\frac{N_g(y)}{R+B_g(y)}\le\theta_g.\)

If \(R+B_g(y)=0\), the deviating payoff is zero by definition, whereas the current payoff \(q\theta_g\) is nonnegative. Thus no feasible deviation improves the bloc’s payoff. This holds for every bloc. \(\square\)

3. The deletion algorithm

If every utility in the category is zero, feasibility forces every bid mass to be zero, and this profile is an equilibrium.

Otherwise, use the following algorithm.

  • Initialize \(x_t=\mu_t\) whenever \(u_t>0\), and \(x_t=0\) otherwise.
  • Compute \(P\) and each \(N_g\).
  • While there is a participating type \(t\) satisfying \(u_tP<N_{g(t)}\), set \(x_t=0\) and update \(P\) and \(N_{g(t)}\).
  • Return the resulting profile.

Any violating type may be selected at each iteration. Each type is removed at most once, so there are at most \(\tau\) deletions.

The remaining points are to show that the denominator stays positive and that previously removed types satisfy the lemma’s inequality at termination.

4. Positivity and monotonicity of the thresholds

Positive-utility blocs retain their maximum-utility types

Call a bloc interested if it contains a type with positive utility. For an interested bloc \(g\), let

\(M_g=\max_{t:g(t)=g}u_t>0.\)

At every feasible profile with \(P>0\),

\(N_g\le M_gB_g\le M_gP,\)

so \(\theta_g\le M_g\). Hence a participating type with utility \(M_g\) never satisfies the deletion condition \(u_t<\theta_g\).

All such types participate initially and remain throughout the algorithm. Therefore every interested bloc retains positive bid mass, and \(P\) remains positive after every deletion.

Every deletion weakly increases every threshold

Suppose type \(t\) is removed from bloc \(h\). Write \(a=\mu_t\) and \(u=u_t\). The deletion condition is \(u<\theta_h\). Before deletion, let the total mass be \(P\); afterward it is \(P'=P-a>0\).

For the deleting bloc,

\(\theta'_h-\theta_h=\frac{N_h-ua}{P-a}-\frac{N_h}{P}=\frac{a(\theta_h-u)}{P-a}>0.\)

For any other bloc \(g\), its numerator is unchanged, so

\(\theta'_g-\theta_g=\frac{N_g}{P-a}-\frac{N_g}{P}=\frac{aN_g}{P(P-a)}\ge0.\)

Thus every bloc’s threshold is nondecreasing throughout the algorithm.

5. Correctness

At termination, every participating type satisfies \(u_tP\ge N_{g(t)}\), equivalently \(u_t\ge\theta_{g(t)}\).

Now consider a positive-utility type \(t\) that was removed. At its deletion, it satisfied

\(u_t<\theta_{g(t)}.\)

Its bloc’s threshold can only increase afterward. Therefore, at termination, it still satisfies \(u_t<\theta_{g(t)}\).

All coordinates remain either zero or their full input mass, and the final denominator is positive. The sufficient-condition lemma therefore applies and proves that the returned profile is a category equilibrium against every feasible real-valued deviation.

Applying this algorithm independently to each category and using Section 1 gives an equilibrium of the full game. This proves existence for every valid input, including categories with no interested bloc and categories with exactly one interested bloc.

6. Exact computation and bit complexity

A direct implementation scans at most \(\tau\) types to find a deletion, performs at most \(\tau\) deletions per category, and maintains the numerators and total mass. This requires \(O(m\tau^2)\) arithmetic operations. The comparisons and updates can be implemented using integers of polynomial bit length, as follows.

Write the input masses as \(\mu_t=a_t/b_t\), and take

\(D=\prod_t b_t,\qquad M_t=D\mu_t.\)

Then every \(M_t\) is an integer and \(\sum_tM_t=D\).

For a fixed category, write its utilities as \(u_t=c_t/d_t\), and take

\(E=\prod_t d_t,\qquad V_t=Eu_t.\)

Every \(V_t\) is a nonnegative integer. If \(A\) denotes the currently participating types, maintain

\(S=\sum_{t\in A}M_t,\qquad W_g=\sum_{\substack{t\in A\\g(t)=g}}M_tV_t.\)

These represent the original quantities exactly:

\(P=S/D,\qquad N_g=W_g/(DE).\)

The deletion test is precisely the integer comparison

\(V_tS<W_{g(t)}.\)

Deleting type \(t\) updates

\(S\leftarrow S-M_t,\qquad W_{g(t)}\leftarrow W_{g(t)}-M_tV_t.\)

The products defining \(D\) and \(E\) have \(O(L)\) bits because the input denominators have total bit length at most \(L\). Also \(S\le D\), and

\(W_g\le D\max_tV_t.\)

The input numerators and the integers \(V_t\) have \(O(L)\) bits, so all maintained integers and comparison products have \(O(L)\) bits. Using schoolbook integer multiplication and division gives, for example, a coarse bound of \(O(m\tau^2L^2)\) bit operations, including preprocessing.

Finally, each output coordinate is either zero or its original rational mass. Thus the output itself has polynomial length and requires no algebraic-number representation.

The cited finite-agent tractability statement appears in [Aleksandrov–Walsh, Theorem 3](https://www.ijcai.org/proceedings/2017/0007.pdf). The proof above establishes existence and polynomial bit complexity directly for the specified continuous support model.
