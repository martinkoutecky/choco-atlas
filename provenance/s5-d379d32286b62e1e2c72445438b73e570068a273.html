The continuous mirror question, as graded

Given an explicit outcome set \(X=\prod_{i=1}^{n}\{0,\ldots,m_i-1\}\), a target \(z\in X\), and a binary-rational distribution \(\mu\) with support \(\tau\) over strict rankings of \(X\), with pairwise majority ties excluded, compute the set of all \(x\in X\) from which some objects scheme admits a maximal sequence of best-neighbor moves ending at \(z\) under the majority rule induced by \(\mu\).

Packaged proof task (what the prover saw — nothing else)

Let \(n\geq1\), \(m_i\geq2\), and \(X=\prod_{i=1}^{n}\{0,\ldots,m_i-1\}\) be explicitly listed; write \(m=|X|\). A target \(z\in X\) is given.
A society is given by its support: a list of \(\tau\) strict rankings of \(X\), each explicitly listed with positive binary-rational mass; masses sum to \(1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length.
Write \(y\succ x\) when the mass ranking \(y\) above \(x\) exceeds \(1/2\); exclude pairwise majority ties.
An object is a nonempty coordinate set \(I\subseteq\{1,\ldots,n\}\). An objects scheme \(\mathcal A\) is a family of objects whose union is all coordinates; overlaps are allowed.
Define \(\Phi_I(x)=\{y\in X:y\succ x,\ y_j=x_j\text{ for every }j\notin I\}\). A best neighbor for \(I\) is a member \(y\in\Phi_I(x)\) satisfying \(y\succ w\) for every \(w\in\Phi_I(x)\setminus\{y\}\); it need not exist.
A sequence uses one fixed scheme \(\mathcal A\), with each move selecting a best neighbor for some \(I\in\mathcal A\). It ends maximally at \(z\) only when \(\Phi_I(z)=\varnothing\) for every \(I\in\mathcal A\); being unable to select a best neighbor alone does not suffice. Allow a sequence of length zero.
Let \(\Psi_\mu(z)\) contain exactly those \(x\in X\) admitting such a finite sequence to \(z\) for some scheme, which may depend on \(x\).

Can \(\Psi_\mu(z)\) be computed in polynomial time, or is its computation \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L,n\).

For an explicitly given strict social rule on the finite product space, the universal basin is computable in \(O(m^3\log m)\) time. [Source](https://arxiv.org/pdf/1004.3385)
No separate result for exactly the rational-mass input problem was identified in the search.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: positive support masses sum to one, and each strict ranking is explicitly listed.
  • Used m for the number of outcomes and L for the total input bit length.
  • Restricted to nonconstant features, with n at least one and each m_i at least two, matching the nondegenerate feature convention implicit in the anchor's logarithmic coordinate bound.
  • Specified that objects cover all coordinates and may overlap, and that one scheme remains fixed throughout each sequence.
  • Interpreted best neighbor as defeating every other preferred neighbor, excluding comparison with itself; a cyclic preferred-neighbor set may have no best neighbor.
  • Required termination at a local optimum, meaning no preferred neighbor under any object, rather than merely no available best-neighbor move.
  • Allowed a zero-length sequence, so z belongs to its basin whenever a scheme makes it a local optimum.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The set \(\Psi_\mu(z)\) is computable in polynomial time. A sufficient exact-arithmetic running-time bound is
\[ \]
\(O\!\left(L+\tau L^2+\tau m^2L+(m^2n+m^3)\log m\right).\)

Since \(m=\prod_i m_i\geq 2^n\), this simplifies to
\(O\!\left(L+\tau L^2+\tau m^2L+m^3\log m\right).\)

The proof below handles the fixed scheme, missing best neighbors, maximality at \(z\), and zero-length sequences directly. The combinatorial bound agrees with [Theorem 5.1 of the cited paper](https://arxiv.org/pdf/1004.3385), but the argument does not require applying that theorem.

1. Compute the majority relation exactly

Write the masses as \(p_r=a_r/b_r\), for \(1\leq r\leq\tau\), with positive integers encoded in binary. Define
\(Q=\prod_{r=1}^{\tau}b_r\) and \(c_r=a_r(Q/b_r)\).

Then \(p_r=c_r/Q\), and the promised normalization gives
\(\sum_{r=1}^{\tau}c_r=Q\).

The bit length of \(Q\) is \(O(L)\). Each \(c_r\), and every partial sum of these nonnegative integers, also has \(O(L)\) bits.

Invert each explicitly listed ranking into a table of positions. For every unordered pair of distinct outcomes \(x,y\), compute
\(S(y,x)=\sum_{\{r:\,r\text{ ranks }y\text{ above }x\}}c_r\).

The exact majority test is
\(y\succ x\Longleftrightarrow 2S(y,x)>Q\).

Thus all pairwise comparisons can be stored in a Boolean table. Using schoolbook integer arithmetic, constructing the common-denominator weights costs \(O(\tau L^2)\) bit operations; computing all majority comparisons costs \(O(\tau m^2L)\) bit operations. Input parsing and ranking-table construction are covered by these terms together with \(O(L)\).

2. Objects compatible with maximality at the target

For \(u,v\in X\), define their difference set by
\(D(u,v)=\{i:u_i\neq v_i\}\).

Then
\(v\in\Phi_I(u)\Longleftrightarrow v\succ u\text{ and }D(u,v)\subseteq I\).

Call an object \(I\) safe at \(z\) if \(\Phi_I(z)=\varnothing\). Every object in a scheme admitting a maximal sequence ending at \(z\) must be safe.

Lemma 1: Safety is inherited by smaller objects

If \(\varnothing\neq J\subseteq I\), then \(\Phi_J(u)\subseteq\Phi_I(u)\) for every \(u\).

Indeed, agreement outside \(J\) implies agreement outside \(I\). Consequently, if \(I\) is safe at \(z\), then \(J\) is safe at \(z\).

Lemma 2: A safe covering scheme exists exactly when every singleton is safe

Suppose a safe scheme covers all coordinates. For each coordinate \(i\), some object \(I\) in that scheme contains \(i\). Lemma 1 implies that \(\{i\}\) is safe.

Conversely, if every singleton is safe, then the scheme
\(\mathcal S=\{\{1\},\ldots,\{n\}\}\)
covers all coordinates and is safe.

Therefore, if some singleton is unsafe, then \(\Psi_\mu(z)=\varnothing\). If every singleton is safe, the zero-length sequence witnesses \(z\in\Psi_\mu(z)\).

Lemma 3: A move can use precisely its changed coordinates

Suppose \(y\) is a best neighbor of \(x\) for an object \(I\), and put \(J=D(x,y)\).

Since \(y\succ x\), we have \(x\neq y\), so \(J\) is nonempty. Membership in \(\Phi_I(x)\) gives \(J\subseteq I\), while \(y\in\Phi_J(x)\). Every other member \(w\) of \(\Phi_J(x)\) belongs to \(\Phi_I(x)\), so \(y\succ w\). Hence \(y\) is also a best neighbor for \(J\).

If \(I\) is safe at \(z\), Lemma 1 shows that \(J\) is safe too.

3. A graph that exactly describes the basin

Assume henceforth that every singleton is safe. Construct a directed graph \(G_z\) on vertex set \(X\). Insert an arc \(x\to y\) exactly when all three conditions hold:

  • \(y\succ x\).
  • \(D(x,y)\) is safe at \(z\).
  • \(y\) is a best neighbor of \(x\) for \(D(x,y)\).

These conditions can be checked without enumerating schemes. For \(J=D(x,y)\), condition 2 is
\(\nexists w\in X:\ w\succ z\text{ and }D(z,w)\subseteq J\).

Given condition 1, condition 3 is
\(\forall w\in X\setminus\{y\},\quad [w\succ x\text{ and }D(x,w)\subseteq J]\Longrightarrow y\succ w\).

In particular, this test never substitutes “some improving neighbor” for “a best neighbor.”

Proposition: The basin is reverse reachability from the target

We have
\(\Psi_\mu(z)=\{x\in X:\text{there is a directed path in }G_z\text{ from }x\text{ to }z\}\).

Proof, forward direction. Let an admissible sequence be
\(x=x_0,x_1,\ldots,x_k=z\),
using one fixed scheme \(\mathcal A\).

Maximality at \(z\) makes every object in \(\mathcal A\) safe. For each move, Lemma 3 shows that \(x_{t+1}\) is a best neighbor for the safe object \(D(x_t,x_{t+1})\). Thus every move is an arc of \(G_z\). When \(k=0\), the corresponding path has length zero.

Proof, reverse direction. Let
\(x=x_0,x_1,\ldots,x_k=z\)
be a directed path in \(G_z\). Use the single fixed scheme
\(\mathcal A=\mathcal S\cup\{D(x_t,x_{t+1}):0\leq t<k\}\).

The singleton objects ensure coverage. Every object in this scheme is safe: the singletons by assumption, and the other objects by the arc conditions. Every path move selects a best neighbor for an object belonging to this fixed scheme. At its endpoint, \(\Phi_I(z)=\varnothing\) for every \(I\in\mathcal A\), so the sequence ends maximally at \(z\).

For \(k=0\), take \(\mathcal A=\mathcal S\). This proves the proposition.

4. Algorithm and running time

After computing the majority table:

  • Precompute all difference sets \(D(u,v)\).
  • If any singleton is unsafe at \(z\), output \(\varnothing\).
  • Otherwise construct \(G_z\) using the three explicit arc tests.
  • Search from \(z\) in the graph with all arcs reversed, and output the visited vertices.

Because \(n\leq\log_2m\), each difference set fits in an \(O(\log m)\)-bit mask. Precomputing the masks costs \(O(m^2n)\) word operations. Each ordered pair \(x,y\) requires at most two scans of \(X\), using constant-time mask-inclusion and majority-table tests. Graph construction therefore costs \(O(m^3)\) word operations. Reverse reachability costs \(O(m^2)\).

Consequently, the combinatorial phase takes \(O(m^2n+m^3)\) operations on \(O(\log m)\)-bit words. Charging \(O(\log m)\) bit operations per such operation gives the stated total bound
\(O\!\left(L+\tau L^2+\tau m^2L+(m^2n+m^3)\log m\right)\).

All parameters in this bound are polynomially bounded by the explicit input length. Hence the full basin, and membership in it, are polynomial-time computable.

As an additional check, exhaustive enumeration of every tournament, target, and covering scheme on the binary two-coordinate product agreed with the graph characterization in all \(256\) tournament–target cases.

  • Exact majority computation.

The common-denominator construction is valid. Every denominator divides \(Q=\prod_{r=1}^{\tau}b_r\), so \(c_r=a_r(Q/b_r)\) is an integer and \(p_r=c_r/Q\). The promised normalization implies \(\sum_r c_r=Q\).

The claimed bit-length bounds follow from the encoding and positivity: the bit length of \(Q\) is bounded by the sum of the denominator bit lengths, hence is \(O(L)\); each \(c_r\) and every partial sum is at most \(Q\).

Thus \(2S(y,x)>Q\) is exactly the required strict-majority test. Pairwise ties are excluded by the task. The stated \(O(\tau L^2)\) bound for constructing the weights using schoolbook multiplication and division is sufficient, and \(O(\tau m^2L)\) covers the pairwise sums and comparisons. Ranking inversion and parsing fit within the stated overall bound.

  • Difference sets correctly characterize allowable neighbors.

The equivalence
\(v\in\Phi_I(u)\Longleftrightarrow v\succ u\text{ and }D(u,v)\subseteq I\)
follows directly from agreement on every coordinate outside \(I\). There is no omitted restriction: \(v\succ u\) already ensures \(v\neq u\).

  • Safety and covering schemes.

Lemma 1 has the correct inclusion direction. If \(J\subseteq I\), agreement outside \(J\) imposes at least all the agreement requirements outside \(I\). Therefore \(\Phi_J(u)\subseteq\Phi_I(u)\), and safety passes to nonempty subsets.

Both directions of Lemma 2 are valid. Coverage places each coordinate in some safe object, making its singleton safe by Lemma 1. Conversely, the singleton family is a valid covering scheme when every singleton is safe.

Consequently, an unsafe singleton rules out every scheme under which a sequence could end maximally at \(z\). Returning the empty basin in that case is correct. When all singletons are safe, the singleton scheme validates the zero-length sequence at \(z\).

  • Shrinking a move to its changed coordinates.

Lemma 3 preserves every required property. For a best-neighbor move \(x\to y\), the set \(J=D(x,y)\) is nonempty and contained in the original object \(I\). The outcome \(y\) remains an improving neighbor under \(J\), while every competing improving neighbor under \(J\) was already a competitor under \(I\). The existing best-neighbor condition therefore supplies all required comparisons.

Safety of \(J\) follows from Lemma 1 when \(I\) is safe. This lemma does not assume that best neighbors always exist.

  • The arc tests match the definitions.

Condition 2 excludes exactly the outcomes that would make \(D(x,y)\) unsafe at \(z\).

Given \(y\succ x\), condition 3 tests every other member of \(\Phi_{D(x,y)}(x)\) and requires \(y\) to beat it. This is exactly the stated best-neighbor definition, including the case where the competitor set is empty.

In particular, the construction does not confuse the existence of an improving neighbor with the existence of a best neighbor.

  • The graph characterization handles one fixed scheme.

In the forward direction, maximality at \(z\) makes every object of the original scheme safe. Lemma 3 then validates every sequence move as a graph arc. This establishes reachability even if the original sequence revisits vertices. The zero-length case is also included.

In the reverse direction, the proposed family contains all singleton objects and all changed-coordinate objects used by the selected path. It is one fixed scheme for the entire sequence, covers every coordinate, and contains only nonempty safe objects.

Each move is valid for its corresponding object by the arc conditions. Safety of every scheme object gives the required endpoint condition \(\Phi_I(z)=\varnothing\), rather than merely an inability to choose a best neighbor.

The scheme may depend on the starting outcome and chosen path, as the task permits. No stronger uniformity assumption is introduced.

Since every \(m_i\geq2\), the inequality \(m\geq2^n\) holds, including \(n=1\). Thus \(n\leq\log_2m\), and coordinate values and difference masks fit in words of \(O(\log m)\) bits.

Computing all difference sets takes \(O(m^2n)\) word operations. For each of \(O(m^2)\) candidate arcs, the safety and best-neighbor tests each scan at most \(m\) outcomes. Mask inclusion and stored majority lookup take constant word time, giving \(O(m^3)\) word operations for graph construction. Reverse reachability takes \(O(m^2)\).

Under the stated word-operation accounting, the combinatorial bit-cost bound is therefore \(O((m^2n+m^3)\log m)\). The total bound
\(O(L+\tau L^2+\tau m^2L+(m^2n+m^3)\log m)\)
