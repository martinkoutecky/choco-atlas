Theorem 1 — class: other

The continuous mirror question, as graded

Given a finite type set \(T\), positive rational masses \(\mu_t\) summing to \(1\), and a symmetric link-cost table \(w_{tu}\in\{c_1,c_2\}\) with \(c_1<c_2\), suppose every type has direct source cost \(c_2\) and the graph of \(c_1\)-links on supported types is connected. For each denominator-compatible replication with \(q\mu_t\) agents of type \(t\), compute the limit, as \(q\) grows, of the finite Folk charge to an agent of each type.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) counts supported types, not possible types.
Input also includes binary rational costs \(0\le c_1<c_2\) and a symmetric table \(w:T\times T\to\{c_1,c_2\}\), including its diagonal. The graph with edges \(\{t,u\}\) for distinct types satisfying \(w_{tu}=c_1\) is connected.
For every positive integer \(q\) with \(q\mu_t\in\mathbb Z\) for all \(t\), form \(N_q\) with \(q\mu_t\) agents of type \(t\). Distinct agents of types \(t,u\) have link cost \(w_{tu}\), including when \(t=u\); every agent has source-link cost \(c_2\).
On the complete graph \(N_q\cup\{\omega\}\), define irreducible edge costs \(d_{ab}=\min_{P:a\leadsto b}\max_{e\in P}c(e)\), allowing paths through any agents and the source.
Define the coalition cost \(v_q(S)\) as the minimum spanning-tree cost on \(S\cup\{\omega\}\) using the restricted irreducible costs, with \(v_q(\varnothing)=0\). The finite Folk charge is the Shapley value of \(v_q\); write \(F_t(q)\) for the charge of any agent of type \(t\).

Do the limits \(f_t=\lim_{q\to\infty,\ q\mu_u\in\mathbb Z\ \forall u}F_t(q)\) exist for every admissible input, and is computing them exactly polynomial-time in \(\tau\) and total input bit length \(L\), or NP-hard? There is no independent \(m\) parameter in this model.

Discrete two-cost networks whose grand coalition admits no nonempty proper partition with additive optimal connection costs have a closed-form Folk allocation ([discrete result](https://web.ua.es/es/dmcte/documentos/qmetwp1507.pdf)).
No result settling this exact support-encoded replication-limit problem was located in the literature search.

Modeling choices made when packaging the task

  • Specified nonnegative binary rational link costs, allowing zero low cost as in the discrete elementary-cost domain.
  • Interpreted diagonal table entries as costs between distinct agents of the same type, separately from source-link costs.
  • Defined compatible replications using positive integer population sizes and retained unscaled per-agent charges.
  • Specified that irreducible costs are computed on the entire replicated graph before restricting to a coalition.
  • Allowed singleton support, using the usual convention that a one-vertex graph is connected.
  • Used support size and total input bit length as the complexity parameters because this model has no independent m parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

All limits exist, and computing them exactly is polynomial-time solvable. More precisely, for every supported type \(t\),

\(f_t=\begin{cases}c_2,&\tau=1\text{ and }w_{tt}=c_2,\\ c_1,&\text{otherwise}.\end{cases}\)

The crucial premise is that irreducible costs are computed using the entire replicated network before being restricted to a coalition. The supplied [paper](https://web.ua.es/es/dmcte/documentos/qmetwp1507.pdf) likewise defines the Folk solution through the game associated with irreducible costs. We prove the result directly from the task’s definitions.

1. Admissible replications contain every supported type.

Write each mass in lowest terms as \(\mu_t=a_t/b_t\), and let \(D\) be the least common multiple of the denominators \(b_t\). The admissible positive integers \(q\) are exactly the positive multiples of \(D\), so they form an unbounded sequence.

Fix any admissible \(q\). Since \(q\mu_t\) is a positive integer, every supported type has at least one agent. Moreover,

\(|N_q|=\sum_{t\in T}q\mu_t=q.\)

2. Irreducible costs when \(\tau\geq2\).

We first prove that any two distinct agents are connected by a path whose edges all cost \(c_1\).

For agents of different types \(t,u\), choose a simple path from \(t\) to \(u\) in the connected low-cost type graph. Choose one agent of each intermediate type. Together with the specified endpoint agents, these agents give the required path.

For two distinct agents of the same type \(t\), connectivity and \(\tau\geq2\) imply that \(t\) has a neighbor \(u\) in the low-cost type graph. Any agent of type \(u\) gives a two-edge path between the specified agents, with both edges costing \(c_1\). This works regardless of \(w_{tt}\).

Every original edge costs at least \(c_1\). The preceding paths therefore show that, for distinct agents \(a,b\),

\(d_{ab}=c_1.\)

Every path from an agent to the source contains an edge incident to the source, costing \(c_2\). The direct source edge also costs \(c_2\). Thus

\(d_{a\omega}=c_2.\)

3. Coalition costs and finite Shapley charges.

Under these irreducible costs, let \(S\) be a nonempty coalition of size \(k\). Every spanning tree on \(S\cup\{\omega\}\) has \(k\) edges and at least one source edge. Consequently its cost is at least

\(c_2+(k-1)c_1.\)

This bound is attained by taking a tree on \(S\), whose edges all cost \(c_1\), and adding one source edge. Hence

\(v_q(S)=c_1|S|+(c_2-c_1)\mathbf{1}_{\{S\ne\varnothing\}}.\)

For a fixed agent, its marginal contribution in a uniformly random ordering of the agents is \(c_2\) if it comes first, and \(c_1\) otherwise. Its probability of coming first is \(1/q\). By the permutation definition of the Shapley value,

\(F_t(q)=\frac{c_2}{q}+\left(1-\frac1q\right)c_1=c_1+\frac{c_2-c_1}{q}.\)

This proves, for every type when \(\tau\geq2\),

\(\displaystyle\lim_{\substack{q\to\infty\\q\mu_u\in\mathbb Z\ \forall u}}F_t(q)=c_1.\)

4. The one-type cases.

If \(\tau=1\), normalization gives \(\mu_t=1\), so every positive integer \(q\) is admissible.

If \(w_{tt}=c_1\), all edges between distinct agents cost \(c_1\). The coalition-cost and Shapley calculations above apply, including \(q=1\), and give

\(F_t(q)=c_1+\frac{c_2-c_1}{q},\qquad f_t=c_1.\)

If \(w_{tt}=c_2\), every original edge costs \(c_2\), so every irreducible cost between distinct vertices is \(c_2\). A coalition of size \(k\) requires exactly \(k\) tree edges, yielding

\(v_q(S)=c_2|S|.\)

Every agent’s marginal contribution is therefore \(c_2\), and

\(F_t(q)=f_t=c_2.\)

These cases exhaust all admissible inputs.

5. Exact computation and bit complexity.

The algorithm outputs \(c_2\) precisely when there is one supported type and its diagonal entry equals \(c_2\); otherwise it outputs \(c_1\) for every supported type.

It does not construct any replicated population or compute any admissible denominator. Each output is an input rational, so its representation has at most \(L\) bits. Reading the input and writing all \(\tau\) outputs takes at most \(O(L+\tau L)\) bit operations. Thus exact computation is polynomial-time in \(\tau\) and \(L\).
