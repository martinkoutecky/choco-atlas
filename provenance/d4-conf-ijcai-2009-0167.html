The continuous mirror question, as graded

Given Boolean variables \(V\), fixed \(k\ge 2\), and a support of report types \(q=(o_q^+,o_q^-)\) with positive rational masses \(\mu_q\) summing to \(1\), does there exist an acyclic \(N\in\mathcal N_k\) such that \(N\models o_q^+\succ o_q^-\) for every support type \(q\)?

Packaged proof task (what the prover saw — nothing else)

Let \(V\) contain \(m\) Boolean variables, with outcomes in \(\{0,1\}^{V}\), and fix a constant integer \(k\ge2\).
A society is given by its support: a list of \(\tau\) distinct report types \(q=(o_q^+,o_q^-)\), each consisting of two distinct outcomes and having positive binary rational mass \(\mu_q\), with \(\sum_q\mu_q=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
A CP-net specifies a directed graph on \(V\) and, for every variable and every assignment to its parents, a strict total order on its Boolean values. Let \(\mathcal N_k\) consist of such CP-nets whose graphs are acyclic and have maximum in-degree at most \(k\).
A total preorder on outcomes satisfies a CP-net when it strictly prefers the locally preferred value in every parent context, holding all other variables fixed. Write \(N\models o\succ o'\) when every total preorder satisfying \(N\) strictly prefers \(o\) to \(o'\).
The decision problem asks whether one \(N\in\mathcal N_k\) entails \(o_q^+\succ o_q^-\) for every support type; inputs are not promised to admit such a network.

For each fixed \(k\ge2\), is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite comparison sets, this existence problem is NP-hard for every fixed \(k\ge2\), even for Boolean outcomes differing on at most two variables and with a promise that every feasible instance has an in-degree-two solution ([original result](https://www.ijcai.org/Proceedings/09/Papers/313.pdf)).
No result explicitly treating the specified rational-mass support problem was located.

  • Specified entailment using all satisfying total preorders, retaining strict local preferences and allowing global indifference as in the supplied definitions.
  • Required distinct outcomes within each strict report and distinct support types.
  • Made explicit that feasibility is not promised; the decision problem includes inconsistent comparison supports.
  • Defined m as the number of Boolean variables and L as the total binary input length.

Result

For every fixed \(k\ge 2\), the decision problem is NP-hard, even when all masses are dyadic rationals and every reported pair differs on at most two variables. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).

The proof transfers the stated comparison-set hardness theorem to the support representation. No new hardness construction is needed.

The existing theorem applies to the specified semantics

Theorem 1 of Dimopoulos, Michael, and Athienitou states that, for each fixed \(k\ge 2\), deciding whether a finite comparison set \(P\) is entailed by an acyclic CP-net of maximum in-degree at most \(k\) is NP-hard. Its hard instances use Boolean variables, comparisons differing on at most two variables, and have the additional property that whenever they are feasible, an in-degree-two solution exists. [Original paper, Theorem 1](https://www.ijcai.org/Proceedings/09/Papers/313.pdf).

The paper’s Definitions 1–3 use strict local orders and define entailment by quantifying over every total preorder satisfying the local ceteris paribus preferences. Its class \(\mathcal N_k\) is the class of acyclic CP-nets with maximum in-degree at most \(k\). Thus the theorem uses exactly the network class and entailment semantics in the question. [Original paper, Section 2](https://www.ijcai.org/Proceedings/09/Papers/313.pdf).

We apply this theorem separately for each fixed \(k\); hardness for a smaller network class alone would not justify hardness for a larger one.

Polynomial-time reduction to rational-mass supports

Fix \(k\ge 2\). Let \((V,P)\) be an instance of the comparison-set problem, with nonempty comparison set

\(P=\{o_i^+\succ o_i^-:1\le i\le s\}\).

Repeated identical comparisons, if present in an input list, can be removed in polynomial time: repetition does not change which networks entail all comparisons. The comparisons in the cited hard instances have distinct outcomes within each pair.

Retain the variable set \(V\), and create one support type \(q_i=(o_i^+,o_i^-)\) per comparison. Hence \(\tau=s\), and the report types are distinct.

To ensure that the masses qualify even under a restriction to terminating binary fractions, put

\(r=\lceil\log_2 s\rceil\),

and assign

\(\mu_{q_i}=2^{-r}\) for \(1\le i<s\), and
\(\mu_{q_s}=(2^r-s+1)2^{-r}\).

These masses satisfy every required condition:

  • Positivity. Since \(s\le 2^r\), the last numerator satisfies \(2^r-s+1\ge 1\). Every other mass is also positive.
  • Normalization. Their sum is

\(\sum_{i=1}^{s}\mu_{q_i}=(s-1)2^{-r}+(2^r-s+1)2^{-r}=1\).

  • Polynomial encoding length. Each numerator and denominator has \(O(1+\log s)\) binary digits. The outcomes contribute \(O(sm)\) bits, so the resulting input has length \(O(sm+s(1+\log s))\), apart from ordinary encoding overhead. The construction therefore takes polynomial time.

For \(s=1\), this construction gives the single mass \(1\).

If the source comparison set is empty, map it to the fixed feasible support consisting of one Boolean variable \(x\), the comparison \(1\succ 0\), and mass \(1\). This preserves the affirmative answer for an empty comparison set.

Correctness and inherited restrictions

For a nonempty source instance, every candidate \(N\in\mathcal N_k\) satisfies

\(N\models o_q^+\succ o_q^-\) for every support type \(q\)

if and only if

\(N\models o_i^+\succ o_i^-\) for every comparison in \(P\).

This equivalence holds because the support contains exactly those ordered pairs. The decision predicate imposes no further condition involving their masses. Taking the existential quantifier over \(N\in\mathcal N_k\) therefore preserves both affirmative and negative answers.

The reduction preserves the outcomes, so it preserves the bound of two differing variables per comparison. It also preserves the set of feasible networks, and hence the cited property that every feasible hard instance has an in-degree-two solution.

We have thus given a polynomial-time many-one reduction from the cited NP-hard problem to the specified rational-mass support problem. This proves the requested NP-hardness classification. It does not assert membership in \(\mathrm{NP}\), which is unnecessary for the question.
