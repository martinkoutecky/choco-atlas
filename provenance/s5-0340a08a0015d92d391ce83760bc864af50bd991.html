The continuous mirror question, as graded

Given a binary combinatorial domain (C(A)), a language (L\in\{\mathrm{PF},\mathrm{PT},\mathrm{RPT}\}) with DNF formulas, a finite set (T) of response-profile types with positive rational masses (\mu_t) summing to (1), and for each type a record (\varepsilon_t) of (q) comparison examples, plus a rational threshold (\theta), does there exist one model (M\in L) that satisfies at least a (\theta) fraction of every type's examples, that is, (\min_{t\in T}|\{e\in\varepsilon_t:M\text{ satisfies }e\}|/q\ge\theta)?

Packaged proof task (what the prover saw — nothing else)

Let \(A=\{X_1,\ldots,X_m\}\), with \(m\ge1\), and \(C(A)=\{0,1\}^m\); alternatives are truth assignments to these attributes.
A society is given by its support: a nonempty list \(T\) of \(\tau\) response-profile types, each with positive binary-rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies an explicit set \(\varepsilon_t\) of exactly \(q\ge1\) examples \((\alpha,\beta,R)\), with distinct alternatives and \(R\in\{\succ,\succeq,\approx,\prec,\preceq,\bowtie\}\); \(\bowtie\) denotes incomparability. Each set is promised consistent with some preorder, which may differ across types. An example is satisfied when its stated relation holds; weak comparisons include indifference.
A preference formula (PF) is a finite nonempty tuple \(\varphi=(\varphi_1,\ldots,\varphi_h)\) of DNF formulas over \(A\). Set \(s_\varphi(\alpha)=\min\{i:\alpha\models\varphi_i\}\), or \(h+1\) if none holds; define \(\alpha\succeq_\varphi\beta\) iff \(s_\varphi(\alpha)\le s_\varphi(\beta)\).
A preference theory (PT) is a finite set of PFs, with \(\alpha\succeq_P\beta\) iff every constituent PF weakly prefers \(\alpha\) to \(\beta\). A ranked preference theory (RPT) assigns positive integer ranks to its PFs: compare rank groups in increasing order using the PT relation, stopping at the first group where the alternatives are not indifferent, including incomparability; if all groups give indifference, the alternatives are indifferent.
All other comparison relations are the standard relations derived from the induced preorder. Models have no prescribed size bound or fixed formula shape beyond DNF; the output sought is one deterministic model.
Given \(\mathcal L\in\{\mathrm{PF},\mathrm{PT},\mathrm{RPT}\}\) and binary-rational \(\theta\in[0,1]\), feasibility means that some \(M\in\mathcal L\) satisfies \(\min_{t\in T}|\{e\in\varepsilon_t:M\text{ satisfies }e\}|/q\ge\theta\).

For each \(\mathcal L\in\{\mathrm{PF},\mathrm{PT},\mathrm{RPT}\}\), is this feasibility problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,q,L\), where \(L\) is the total binary input length.

Discrete maximin rank-aggregation model learning is reported \(\mathrm{NP}\)-complete for all three languages, even with DNF formulas ([Huelsman and Truszczynski, 2021](https://doi.org/10.32473/flairs.v34i1.128489)).
No separate published complexity classification for the specified distribution-over-types problem was located.

  • Included strict, weak, indifferent, inverse, and incomparable comparison labels; weak labels are satisfied by the corresponding weak relation, including ties.
  • Resolved the abbreviated RPT semantics using the later author article Relating Preference Languages By Their Expressive Power (https://doi.org/10.32473/flairs.v35i.130651): the first non-indifferent rank group decides, including incomparability.

1. Classification

For each of \(\mathrm{PF}\), \(\mathrm{PT}\), and \(\mathrm{RPT}\), the stated feasibility problem is \(\mathrm{NP}\)-complete. Hardness holds even with fixed \(q=3\), fixed \(\theta=1/4\), and examples using only strict preference.

The masses \(\mu_t\) do not occur in the feasibility condition. Their positivity determines which types belong to the support; their numerical values do not affect the answer. Thus the relevant number of constraints is the explicitly supplied support size \(\tau\).

Some special cases are polynomial-time solvable: in particular, \(q=1\), or more generally any threshold requiring every example to be satisfied. The hardness concerns the general problem.

2. Finite representability and polynomial witnesses

Let \(S\) be the set of alternatives occurring in the examples, and put \(n=|S|\). Then \(n\le 2\tau q\). Only comparisons within \(S\) affect feasibility.

Write \(aRb\) for “\(a\) is weakly preferred to \(b\).” A preorder is a reflexive, transitive relation; it is total if \(aRb\) or \(bRa\) for every pair.

For \(a=(a_1,\ldots,a_m)\), define its identifying conjunction by

\(\delta_a=\bigwedge_{j=1}^{m}\ell_{a,j}\), where \(\ell_{a,j}=X_j\) when \(a_j=1\), and \(\ell_{a,j}=\neg X_j\) otherwise.

This conjunction is satisfied by exactly \(a\).

PFs represent exactly the total preorders on \(S\). Every PF induces a total preorder because it compares integer scores. Conversely, let a total preorder have indifference classes \(B_1,\ldots,B_h\), ordered from best to worst. Define

\(\varphi_i=\bigvee_{a\in B_i}\delta_a\).

The PF \((\varphi_1,\ldots,\varphi_h)\) represents the given relation on \(S\), using \(O(mn)\) literals. Alternatives outside \(S\) receive score \(h+1\).

PTs represent every preorder on \(S\). Let \(R\) be any preorder. For each \(b\in S\), define

\(U_b=\{a\in S:aRb\}\), \(\psi_b=\bigvee_{a\in U_b}\delta_a\), and the one-formula PF \(\Phi_b=(\psi_b)\).

The set \(U_b\) is nonempty by reflexivity. Put \(P=\{\Phi_b:b\in S\}\), removing duplicate PFs if necessary.

If \(aRc\), then transitivity gives \(c\in U_b\Rightarrow a\in U_b\) for every \(b\). Therefore every \(\Phi_b\) weakly prefers \(a\) to \(c\).

Conversely, if \(a\not Rc\), then \(c\in U_c\) but \(a\notin U_c\). Consequently \(\Phi_c\) strictly prefers \(c\) to \(a\), so \(P\) does not weakly prefer \(a\) to \(c\).

Thus \(a\succeq_P c\) exactly when \(aRc\). This construction uses at most \(n\) PFs and \(O(mn^2)\) literals.

RPTs also represent exactly the preorders on \(S\). Every PT is an RPT with all ranks equal to \(1\), so the preceding construction supplies every preorder.

For completeness, the specified ranked comparison is itself a preorder. Each rank group induces a preorder. Suppose \(a\succeq_M b\) and \(b\succeq_M c\), and let \(r,s\) be their respective first nonindifference ranks, taking the value infinity when all ranks give indifference.

Before \(\min(r,s)\), all three alternatives are indifferent. If \(r<s\), then at rank \(r\), \(a\) strictly precedes \(b\), while \(b\) and \(c\) are indifferent; hence \(a\) strictly precedes \(c\). The case \(s<r\) is symmetric. If \(r=s\) is finite, transitivity of the strict part of that group’s preorder gives the same conclusion. If both are infinite, all three remain indifferent. These implications follow directly from transitivity of a preorder and the definition of its strict and indifferent parts. Therefore the ranked relation is transitive; reflexivity is immediate.

In particular, on the observed alternatives, \(\mathrm{PT}\) and \(\mathrm{RPT}\) have identical expressive power.

3. Membership in \(\mathrm{NP}\)

Set \(k=\lceil q\theta\rceil\). Feasibility means satisfying at least \(k\) examples of each type.

A certificate is an \(n\times n\) Boolean matrix representing the weak relation on \(S\). Check:

  • reflexivity and transitivity;
  • totality when the language is \(\mathrm{PF}\);
  • satisfaction of at least \(k\) examples in each \(\varepsilon_t\).

For example, a strict example \((a,b,\succ)\) requires \(aRb\) and \(b\not Ra\); an indifference example requires both directions; an incomparability example requires neither direction. Weak examples require the stated direction alone.

Transitivity takes \(O(n^3)\) Boolean checks, and evaluating all examples takes \(O(\tau q)\) relation lookups. Computing \(k\) uses polynomial-time exact binary arithmetic, bounded by \(O(L^2)\) with elementary arithmetic.

The certificate has \(O(n^2)\) bits. Section 2 proves that every accepted certificate has a corresponding DNF model in the requested language, of polynomial size. Conversely, restricting any feasible model to \(S\) supplies an accepted certificate. Hence all three problems belong to \(\mathrm{NP}\).

4. A common hardness reduction

Use the \(\mathrm{NP}\)-complete restriction of \(3\)-SAT in which every clause contains three distinct variables and clauses are unique. These restrictions remain \(\mathrm{NP}\)-complete even for monotone clauses, by [Döcker’s theorem](https://arxiv.org/abs/1912.08032).

Let the source formula have variables \(z_1,\ldots,z_v\) and clauses \(D_1,\ldots,D_\tau\). Remove unused variables, so \(v\le 3\tau\).

Choose \(m=\lceil\log_2(2v)\rceil\) and assign distinct alternatives \(a_i,b_i\in\{0,1\}^m\) to every variable \(z_i\). Encode literals by

\(e(z_i)=(a_i,b_i,\succ)\), and \(e(\neg z_i)=(b_i,a_i,\succ)\).

For a clause \(D_t=\ell_{t,1}\vee\ell_{t,2}\vee\ell_{t,3}\), set

\(\varepsilon_t=\{e(\ell_{t,1}),e(\ell_{t,2}),e(\ell_{t,3})\}\).

Thus \(q=3\). Set \(\theta=1/4\), so \(k=\lceil3/4\rceil=1\).

To ensure valid masses even under the finite-binary interpretation of “binary-rational,” put \(d=\lceil\log_2\tau\rceil\) and use

\(\mu_t=2^{-d}\) for \(t<\tau\), and \(\mu_\tau=(2^d-\tau+1)2^{-d}\).

These masses are positive dyadic rationals and sum to \(1\).

The consistency promise holds. Within each clause, its three variables are distinct. Therefore its three examples constrain three disjoint pairs of alternatives. Place each requested winner in a better class and each requested loser in a worse class. This gives a total preorder satisfying all three examples, and Section 2 realizes it by a PF.

A satisfying assignment gives a feasible model. Given a satisfying truth assignment \(\sigma\), define

\(B_\sigma=\{a_i:\sigma(z_i)=1\}\cup\{b_i:\sigma(z_i)=0\}\),

and take the one-formula PF

\(\Phi_\sigma=\left(\bigvee_{c\in B_\sigma}\delta_c\right)\).

Its selected alternatives have score \(1\), and their opposite partners have score \(2\). Consequently it satisfies \(e(\ell)\) exactly when \(\sigma\) satisfies \(\ell\). Every clause therefore contributes at least one satisfied example. The PF is feasible, as are its singleton-PT and rank-\(1\) RPT versions.

A feasible model gives a satisfying assignment. Let \(M\) be feasible in any of the three languages. Define \(\sigma(z_i)=1\) exactly when \(a_i\succ_M b_i\).

Every type has a satisfied strict example. A satisfied positive example makes its variable true. A satisfied negative example gives \(b_i\succ_M a_i\); asymmetry of strict preference then implies that \(a_i\succ_M b_i\) is false, making its variable false. Thus each clause has a literal satisfied by \(\sigma\).

This proves equivalence of the source and target instances for all three languages.

The construction is polynomial: \(m=O(\log(\tau+1))\), the example data use \(O(\tau m)\) bits, and the masses use \(O(\tau\log(\tau+1))\) bits. Therefore all three problems are \(\mathrm{NP}\)-hard, even under the stated fixed constants and consistency promise.

5. Explicit deterministic running times

An exact algorithm can enumerate which \(k\) examples of each type will be satisfied. There are

\(B=\binom{q}{k}^{\tau}\le 2^{\tau q}\)

such selections. The following polynomial-time consistency test handles each selection.

Translate selected examples into required directed edges and forbidden directed edges:

| Example | Required edges | Forbidden edges |
|---|---|---|
| \(a\succeq b\) | \(aRb\) | none |
| \(a\succ b\) | \(aRb\) | \(bRa\) |
| \(a\approx b\) | \(aRb,bRa\) | none |
| \(a\bowtie b\) | none | \(aRb,bRa\) |

Reverse the arguments for \(\preceq\) and \(\prec\).

Compute the reflexive transitive closure \(F\) of the required edges.

For \(\mathrm{PT}\) and \(\mathrm{RPT}\), the selection is consistent exactly when \(F\) contains no forbidden edge. Necessity follows because every satisfying preorder contains that closure. Sufficiency follows because \(F\) itself is a satisfying preorder.

For \(\mathrm{PF}\), reject any selected incomparability example. Otherwise, consistency holds exactly when \(F\) contains no forbidden edge. For sufficiency, collapse the strongly connected components of the required-edge graph and topologically order its acyclic quotient, with required preference edges pointing from earlier to later components. Tie alternatives within each component. No strict example has endpoints in one component, since that would put its forbidden reverse edge in \(F\). The resulting total preorder satisfies every selected example.

If a selection passes, construct its DNF witness using Section 2. If none passes, no feasible model exists: any feasible model would supply a passing selection of \(k\) satisfied examples per type.

Including preprocessing, this gives, for each language, the deterministic bound

\(\widetilde O\!\left(L^2+\binom{q}{k}^{\tau}(n^3+\tau q)+mn^2\right)\),

and hence

\(\widetilde O\!\left(L^2+2^{\tau q}((\tau q)^3+\tau q)+m(\tau q)^2\right)\).

Here the tilde hides logarithmic factors for indexing and writing literal identifiers. PF witness construction needs only \(O(mn)\) literals; the common bound accommodates PT and RPT witnesses.

If \(k=0\), any model is feasible. If \(k=q\), there is only one selection, giving a polynomial-time algorithm. In particular, \(q=1\) is polynomial-time solvable for every threshold.

Thus the general feasibility problem is \(\mathrm{NP}\)-complete for every requested language, with polynomial-size deterministic witnesses despite the absence of an imposed model-size bound.
