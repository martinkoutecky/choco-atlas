The continuous mirror question, as graded

Given depth \(n\), a unit-mass nonatomic electorate initially opposing a proposal, and a regular hierarchy with finite odd branching factors \(k_1,\ldots,k_n\), partition the mass equally among terminal constituencies. Convert opponent mass to supporter mass within constituencies at unit cost; each constituency and each internal node adopts the strict majority outcome. Choose the branching factors and constituency-level transfers to minimize total converted mass. What is the infimum, and is it attained?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here there are \(m=2\) positions, and initially one opponent type of mass \(1\), so \(\tau=1\); the electorate is nonatomic and everyone votes.
Given a positive depth \(n\), encoded in unary, choose finite positive odd integers \(k_1,\ldots,k_n\). A rooted tree has \(k_i\) children per node at distance \(i-1\) from its root; its \(K=\prod_{i=1}^n k_i\) leaves are terminal constituencies, each of mass \(1/K\). There is no bound on \(K\).
In constituency \(j\), choose a real converted mass \(x_j\in[0,1/K]\), at cost \(x_j\). That constituency supports the proposal exactly when \(x_j>1/(2K)\); otherwise it opposes. Each internal node supports exactly when a strict majority of its children support, with one vote per child. A feasible conversion makes the root support.
Let \(I(n)\) be the infimum of \(\sum_{j=1}^K x_j\) over all feasible choices of branching factors and conversions. For a binary rational budget \(b\in[0,1]\), budget feasibility means that some feasible conversion costs at most \(b\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L,n\).

What is \(I(n)\), and is this infimum attained? Is budget feasibility in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For a discrete electorate of fixed size \(N\) and \(d\) majority aggregation stages, the minimum winning coalition is smallest at equal branching factors \(N^{1/d}\), whenever these are admissible odd integers. [Böttcher–Kernell](https://journals.sagepub.com/doi/full/10.1177/26339137221133401).
No result settling this exact nonatomic problem was located in the literature search.

Modeling choices made when packaging the task

  • Depth counts the branching levels above the terminal constituencies; constituency voting is an additional aggregation stage, making the graded question's tree convention explicit.
  • A tied terminal constituency opposes the proposal, as required by strict majority acceptance.
  • Depth is positive and encoded in unary; the added decision budget is a binary rational in the unit interval.
  • Branching factors are positive odd integers, including one, with no uniform upper bound; the unit-mass normalization imposes no fixed discrete electorate-size constraint.
  • Converted masses may be real, and budget feasibility asks for an actual conversion costing at most the budget, rather than merely comparing the budget with the infimum.
  • Feasibility requires proposal acceptance at the root; all voters participate and every child outcome has equal weight.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The answer is \(I(n)=2^{-(n+1)}\), and this infimum is not attained. Budget feasibility holds exactly when \(b>2^{-(n+1)}\), so the specified problem is in \(\mathrm{P}\).

  • Minimum number of supporting leaves.

Fix finite positive odd branching factors \(k_1,\ldots,k_n\). Define \(r_i=(k_i+1)/2\), the number of supporting children required at level \(i\), and \(K=\prod_{i=1}^n k_i\).

The minimum number of supporting leaves needed for the root to support is
\[ \]
\(W=\prod_{i=1}^n r_i\).

To prove this, let \(w_i\) be the minimum number of supporting leaves required to make a node at distance \(i-1\) from the root support. Set \(w_{n+1}=1\): a supporting leaf requires one supporting leaf.

A supporting node at level \(i\) must have at least \(r_i\) supporting children. Their subtrees are disjoint, and each requires at least \(w_{i+1}\) supporting leaves. Thus \(w_i\ge r_iw_{i+1}\).

Equality is achievable: select exactly \(r_i\) children, make each selected child support using a minimum leaf configuration, and leave every leaf in the other child subtrees opposing. Induction gives \(w_i=r_iw_{i+1}\), hence the stated formula for \(W=w_1\).

  • The cost infimum for a fixed tree.

Suppose a feasible conversion has \(S\) supporting leaves and total cost \(C\). Each supporting leaf costs strictly more than \(1/(2K)\), and all other costs are nonnegative. Since \(S\ge W\ge1\),

\(C>\dfrac{S}{2K}\ge\dfrac{W}{2K}\).

Conversely, take a configuration with exactly \(W\) supporting leaves. For any real \(\varepsilon\) satisfying \(0<\varepsilon\le1/(2K)\), convert mass \(1/(2K)+\varepsilon\) in each selected leaf and zero elsewhere. This respects the constituency capacity, makes exactly the selected leaves support, and costs \(W/(2K)+W\varepsilon\).

Letting \(\varepsilon\) decrease to zero proves that the fixed-tree cost infimum is

\(A(k_1,\ldots,k_n)=\dfrac{W}{2K} =2^{-(n+1)}\prod_{i=1}^n\left(1+\dfrac1{k_i}\right)\).

It is not attained, because every feasible cost is strictly greater than \(A(k_1,\ldots,k_n)\).

  • Optimization over all finite trees.

Write \(c=2^{-(n+1)}\). Every factor \(1+1/k_i\) is strictly greater than one. Consequently, every feasible conversion satisfies

\(C>A(k_1,\ldots,k_n)>c\).

This proves \(I(n)\ge c\) and shows that no feasible conversion can attain \(c\).

For the matching upper bound, choose any positive odd integer \(q\) and set every branching factor equal to \(q\). Then \(K=q^n\) and \(W=((q+1)/2)^n\). Select a minimum supporting-leaf configuration and convert mass

\(x_q=\dfrac{1+1/q}{2K}\)

in each selected leaf. This is feasible: \(1/(2K)<x_q\le1/K\). The resulting cost is

\(C_q=W x_q=c\left(1+\dfrac1q\right)^{n+1}\).

For fixed \(n\), these costs converge to \(c\) as \(q\) tends to infinity through odd integers. Therefore \(I(n)\le c\). Together with the lower bound, this proves \(I(n)=c\), with no attainment.

The fixed-electorate result in [Böttcher–Kernell, Theorem 3 and Appendix 3](https://journals.sagepub.com/doi/full/10.1177/26339137221133401) concerns optimization with electorate size fixed. Here the number of constituencies is unrestricted, which permits the approaching sequence above.

  • Exact budget feasibility and running time.

If \(b\le c\), the strict lower bound \(C>c\) rules out feasibility.

If \(b>c\), convergence of the explicit feasible costs \(C_q\) to \(c\) guarantees a finite odd \(q\) with \(C_q<b\). Thus a feasible conversion exists with cost at most \(b\). We have proved the exact criterion

\(\text{budget feasible}\ \Longleftrightarrow\ b>2^{-(n+1)}\).

For an exact binary rational representation \(b=p/s\), with nonnegative integer \(p\) and positive integer \(s\), this is equivalent to the integer comparison

\(2^{n+1}p>s\).

Multiplication by \(2^{n+1}\) is a binary shift. The shifted integer has at most \(O(L+n)\) bits, so the comparison takes \(O(L+n)\) bit operations. A finite binary expansion of the budget admits the same bound by direct digit comparison.

In the stipulated family, \(m=2\) and \(\tau=1\). The decision algorithm therefore runs in \(O(L+n)=O(L)\) time, since unary encoding of \(n\) implies \(n\le L\). It does not enumerate the tree or its leaves. Budget feasibility is in \(\mathrm{P}\); it can be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).
