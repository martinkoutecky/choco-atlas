The continuous mirror question, as graded

Given a finite support of voter types \(T\), type masses \(\mu_t\), weights \(w_t\), and corruption budget \(\rho<1/3\), decide whether there exist corrupted masses \(b_t\) and guaranteed included correct masses \(x_t\) such that \(0\le b_t,\ 0\le x_t,\ b_t+x_t\le\mu_t,\ \sum_t b_t\le\rho,\ \sum_t x_t\ge1-2\rho\), and \(\sum_t b_tw_t\ge\sum_t x_tw_t\). Equivalently, maximize \(\sum_t b_tw_t-\sum_t x_tw_t\) subject to those constraints and determine whether the maximum reaches zero.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational; \(\tau\) is the support size, not the number of possible types. Require \(\sum_{t\in T}\mu_t=1\).
Each type has a nonnegative binary rational voting weight \(w_t\), with \(\sum_{t\in T}\mu_tw_t>0\). The corruption budget \(\rho\) is a binary rational satisfying \(0\le\rho<1/3\). There are \(m=2\) ballot values: approval and rejection; a tie meets the approval threshold.
All correct voters reject and corrupted voters approve. Real variables \(b_t\) and \(x_t\) represent corrupted mass and included correct mass, respectively; remaining mass is omitted. The decision problem asks whether
\(\exists (b_t,x_t)_{t\in T}:\quad b_t\ge0,\quad x_t\ge0,\quad b_t+x_t\le\mu_t,\quad\sum_{t\in T}b_t\le\rho,\quad\sum_{t\in T}x_t\ge1-2\rho,\quad\sum_{t\in T}b_tw_t\ge\sum_{t\in T}x_tw_t.\)
These constraints define the problem; no protocol execution witness is required. Let \(L\) be the total binary input length.

Is this continuous decision problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For a discrete society of \(n\) voters and an integer corruption bound \(0\le f<n/3\), adversarial weight strictly below the weight of every subset of \(n-2f\) correct voters prevents adversarial approval when all correct voters reject ([discrete safety guarantee](https://arxiv.org/pdf/2602.01341)). This is a sufficient safety condition, not a computational complexity classification.
No published result settling this exact mass decision problem was located in the search.

Result

The continuous decision problem is in \(\mathrm{P}\). In fact, sorting the supported types gives an exact decision algorithm using \(O(\tau\log\tau)\) comparisons and \(O(\tau)\) additional arithmetic operations, each on numbers of polynomial binary length.

The proof uses exactly the stated mass constraints.

1. Constructing the extremal allocations

Relabel the supported types so that \(w_1\le\cdots\le w_\tau\). Define \(S_0=0\) and \(S_i=\sum_{j=1}^i\mu_j\), so \(S_\tau=1\). Represent type \(i\) by the interval \(I_i=[S_{i-1},S_i]\), whose length is \(\mu_i\). Endpoints have zero length.

Set \(q=1-2\rho\). Define the included correct mass and corrupted mass by

\[ x_i^*=\operatorname{length}\bigl(I_i\cap[0,q]\bigr), \qquad b_i^*=\operatorname{length}\bigl(I_i\cap[1-\rho,1]\bigr). \]

Thus, \(x^*\) fills the lowest-weight types first, while \(b^*\) fills the highest-weight types first. Explicitly,

\[ x_i^*=\min\{\mu_i,\max\{0,q-S_{i-1}\}\}, \qquad b_i^*=\min\{\mu_i,\max\{0,S_i-(1-\rho)\}\}. \]

Their total masses are \(\sum_i x_i^*=q\) and \(\sum_i b_i^*=\rho\).

Since \(q=1-2\rho\le1-\rho\), the two allocation intervals have disjoint interiors. Consequently, \(b_i^*+x_i^*\le\mu_i\) for every type \(i\). This remains true when both allocations use part of the same type.

Define their weighted totals by \(C=\sum_iw_ix_i^*\) and \(B=\sum_iw_ib_i^*\).

2. Proof of extremality

We first prove that, among allocations \(y\) satisfying \(0\le y_i\le\mu_i\) and \(\sum_i y_i=h\), filling the lowest-weight types minimizes \(\sum_iw_iy_i\), while filling the highest-weight types maximizes it.

For \(h=0\), the only allocation is zero. Suppose \(0<h\le1\).

For the lowest-weight allocation \(y^{\mathrm{low}}\), choose the cutoff type \(k\) with \(S_{k-1}<h\le S_k\), and let \(\lambda=w_k\). Every type below \(k\) is filled completely, and every type above \(k\) is empty. Since \(y\) and \(y^{\mathrm{low}}\) have equal total mass,

\[ \sum_iw_i(y_i-y_i^{\mathrm{low}}) = \sum_i(w_i-\lambda)(y_i-y_i^{\mathrm{low}}). \]

For \(i<k\), both factors on the right are nonpositive. For \(i>k\), both are nonnegative. For \(i=k\), the first factor is zero. Every summand is therefore nonnegative, proving the minimum claim.

For the highest-weight allocation \(y^{\mathrm{high}}\), choose the cutoff type \(j\) with \(S_{j-1}\le1-h<S_j\), and let \(\lambda=w_j\). Types below \(j\) are empty and types above \(j\) are filled completely. In the analogous identity, each product \((w_i-\lambda)(y_i-y_i^{\mathrm{high}})\) is nonpositive: below \(j\), its factors are nonpositive and nonnegative; above \(j\), they are nonnegative and nonpositive. This proves the maximum claim.

Now consider any allocation satisfying the task’s constraints.

For its correct mass \(x\), write \(s=\sum_i x_i\ge q>0\). The allocation \(\widehat{x}=(q/s)x\) has total mass \(q\) and satisfies \(0\le\widehat{x}_i\le x_i\le\mu_i\). Nonnegative weights and the minimum claim give

\[ \sum_iw_ix_i\ge\sum_iw_i\widehat{x}_i\ge C. \]

For its corrupted mass \(b\), write \(r=\sum_i b_i\le\rho<1\). Extend it to

\[ \widehat{b}_i = b_i+\frac{\rho-r}{1-r}(\mu_i-b_i). \]

The multiplier lies in \([0,1]\), so \(b_i\le\widehat{b}_i\le\mu_i\); also, \(\sum_i\widehat{b}_i=\rho\). Nonnegative weights and the maximum claim give

\[ \sum_iw_ib_i\le\sum_iw_i\widehat{b}_i\le B. \]

These auxiliary allocations establish bounds; they need not themselves satisfy the joint capacity constraints.

3. Exact decision criterion

The answer is yes if and only if \(B\ge C\).

If a feasible pair satisfies the approval inequality, the preceding bounds imply

\[ B\ge\sum_iw_ib_i\ge\sum_iw_ix_i\ge C. \]

Conversely, if \(B\ge C\), the constructed pair \((b^*,x^*)\) satisfies nonnegativity, every per-type capacity constraint, both total-mass requirements, and the approval inequality. Thus it is a witness for a yes-instance. Equality is accepted, as required by the tie rule.

4. Binary running time

The algorithm sorts the weights, computes the prefix masses, constructs \(b^*\) and \(x^*\), and compares \(B\) with \(C\).

To verify the bit complexity, let \(D\) be the product of the positive denominators of all input rationals. Its binary length is \(O(L)\), and every input rational can be expressed with denominator \(D\). All prefix masses and constructed allocation masses also have denominator \(D\); weighted products have denominator \(D^2\). Their numerators have polynomial binary length. Therefore, exact comparisons and arithmetic take polynomial time in \(L\).

The complete running time is polynomial in \(\tau,L\), hence in \(m,\tau,L\) with \(m=2\).

There is also an immediate alternative proof: the stated constraints form a rational linear feasibility problem with \(2\tau\) variables, \(3\tau+3\) inequalities, and polynomial encoding length. Exact rational linear feasibility is polynomial-time solvable by [Khachiyan’s theorem](https://www.mathnet.ru/eng/dan42319). The sorting proof above additionally supplies an explicit criterion and witness.

Thus the problem is in \(\mathrm{P}\); under polynomial-time many-one reductions, it could be \(\mathrm{NP}\)-hard only if \(\mathrm{P}=\mathrm{NP}\).
