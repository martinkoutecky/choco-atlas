The continuous mirror question, as graded

Given a finite type set \(T\), positive rational masses \(\mu_t\) summing to \(1\), positive rational module requests \(d_t\le k\), and rational capacity \(1<\kappa<k\) per unit of population mass, find rational assignment masses \(x_{tj}\ge0\) for \(j\in\{0,\ldots,k\}\). Require \(\sum_j x_{tj}=\mu_t\) for each type and \(\sum_{t,j}j x_{tj}\le\kappa\). With \(u_t(j)=\min(j/d_t,1)\) and \(u_t(z)=0\) for \(z<0\), require support-wise EF1: whenever \(x_{tj}>0\) and \(x_{s\ell}>0\), \(u_t(j)\ge u_t(\ell-1)\). Require Pareto efficiency against feasible reassignments that weakly improve almost every individual and strictly improve a positive mass, and require every bundle used by type \(t\) to satisfy \(u_t(j)\ge u_t(\lfloor\kappa\rfloor)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau=|T|\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types. Each type represents an atomless population.
Let \(k\ge2\) be an integer, given in unary, with positive rational requests \(0<d_t\le k\) and rational capacity \(1<\kappa<k\) per unit population mass. Write \(m=k+1\) for the number of bundle sizes and \(L\) for the total binary encoding length of the rational data.
For \(j\in\{0,\ldots,k\}\), set \(u_t(j)=\min\{j/d_t,1\}\), with \(u_t(z)=0\) for \(z<0\). An assignment consists of rational masses \(x_{tj}\ge0\) satisfying \(\sum_jx_{tj}=\mu_t\) and \(\sum_{t,j}jx_{tj}\le\kappa\).
Require support-wise EF1: \(x_{tj}>0\) and \(x_{s\ell}>0\) imply \(u_t(j)\ge u_t(\ell-1)\). Also require \(x_{tj}>0\Rightarrow u_t(j)\ge u_t(\lfloor\kappa\rfloor)\).
Pareto efficiency means there is no real nonnegative reassignment \(y_{tj\ell}\) with \(\sum_\ell y_{tj\ell}=x_{tj}\), \(\sum_{t,j,\ell}\ell y_{tj\ell}\le\kappa\), and \(y_{tj\ell}>0\Rightarrow u_t(\ell)\ge u_t(j)\), for which \(\sum_{t,j,\ell:\,u_t(\ell)>u_t(j)}y_{tj\ell}>0\). Comparisons impose only feasibility, not fairness.

Is finding such an assignment, or deciding that none exists, solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For discrete connected agents with port limit \(k\), total capacity \(C\), and \(N\) ports, FAIR-OPAP-M guarantees EF1, Pareto efficiency, and \(u_i(a_i)\ge u_i(C)/n\) whenever \(n\le N\) and \(k+N-1\le C<Nk\); its reported operation bound is \(O(C\log n)\). Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is solvable in polynomial time in \(m,\tau,L\). In fact, every instance satisfying the stated hypotheses admits such an assignment. The construction uses at most two bundle sizes per supported type.

1. Integer satisfaction thresholds. Define
\(q_t=\lceil d_t\rceil\) and \(b=\lfloor\kappa\rfloor\).
Then \(1\le q_t\le k\), and \(q_t\) is the smallest integer bundle giving type \(t\) utility \(1\).

We first establish a sufficient condition for Pareto efficiency:

If an assignment uses only bundles \(j\le q_t\) for each type \(t\), and its total consumption equals \(\kappa\), then it is Pareto efficient under the stated real reassignment definition.

To prove this, consider any supported source bundle \(j\le q_t\). For every integer \(\ell<j\), we have \(\ell<d_t\) and
\(u_t(\ell)<u_t(j)\).
Indeed, if \(j<q_t\), both utilities are on the strictly increasing part; if \(j=q_t\), the source utility is \(1\), whereas \(\ell<d_t\).

Consequently, every permitted reassignment from a supported source satisfies \(\ell\ge j\). Moreover, a strict utility improvement requires \(\ell>j\), hence \(\ell-j\ge1\).

For a reassignment \(y\), let
\(S=\sum_{t,j,\ell:\,u_t(\ell)>u_t(j)}y_{tj\ell}\)
be its strictly improved mass. The source-mass equations imply
\[ \]
\( \displaystyle \sum_{t,j,\ell}\ell y_{tj\ell} -\sum_{t,j}jx_{tj} =\sum_{t,j,\ell}(\ell-j)y_{tj\ell} \ge S. \)

Thus \(S>0\) would increase consumption strictly above \(\kappa\), contradicting feasibility. This proves the sufficient condition, including comparisons with real-valued reassignment masses.

Separately, an assignment in which everyone receives utility \(1\) is Pareto efficient, since no strict utility improvement is possible.

2. Construction. For integers \(a\in\{0,\ldots,k\}\), define
\(G(a)=\sum_{t\in T}\mu_t\min\{q_t,a\}\).
This is the consumption needed to give each type its satisfaction threshold or the common level \(a\), whichever is smaller.

There are two cases.

*If \(G(k)\le\kappa\):* assign
\(x_{tq_t}=\mu_t\), with all other entries zero.
This is feasible and gives everyone utility \(1\). Both fairness conditions hold because all utilities lie in \([0,1]\), and Pareto efficiency follows immediately.

*If \(G(k)>\kappa\):* choose
\(r=\max\{a\in\{0,\ldots,k\}:G(a)\le\kappa\}\).
Since \(G(0)=0\) and \(G(k)>\kappa\), this is well-defined and satisfies
\(0\le r\le k-1\) and \(G(r)\le\kappa<G(r+1)\).

Furthermore,
\(G(b)\le\sum_t\mu_t b=b\le\kappa\),
so \(r\ge b\).

Set
\(A=\sum_{t:q_t>r}\mu_t\).
For integer thresholds,
\(G(r+1)-G(r)=A\).
Therefore \(A>0\), and the rational number
\(\alpha=(\kappa-G(r))/A\)
satisfies \(0\le\alpha<1\).

Assign:

  • For \(q_t\le r\), set \(x_{tq_t}=\mu_t\).
  • For \(q_t>r\), set \(x_{tr}=(1-\alpha)\mu_t\) and \(x_{t,r+1}=\alpha\mu_t\).

All unspecified entries are zero. Zero entries when \(\alpha=0\) can simply be omitted.

3. Verification in the second case. Each type receives exactly its prescribed mass, and all entries are nonnegative rational numbers. Since \(r+1\le k\), every assigned bundle is allowed.

Consumption is exactly
\( \displaystyle \sum_{t,j}jx_{tj} =G(r)+\alpha A =\kappa. \)

For support-wise EF1, take any supported recipient bundle \(j\) of type \(t\) and any supported bundle \(\ell\).

If \(q_t\le r\), the recipient has \(j=q_t\) and utility \(1\), so \(u_t(j)\ge u_t(\ell-1)\).

If \(q_t>r\), the recipient has \(j\ge r\). Every supported bundle in the entire society is at most \(r+1\), so \(\ell-1\le r\le j\). Monotonicity of \(u_t\), including its stipulated values at negative arguments, gives
\(u_t(j)\ge u_t(\ell-1)\).
Thus EF1 holds for every required pair of supported bundles.

For the utility floor, types with \(q_t\le r\) again have utility \(1\). All other supported recipients have \(j\ge r\ge b\), and hence
\(u_t(j)\ge u_t(b)=u_t(\lfloor\kappa\rfloor)\).

Finally, every assigned bundle satisfies \(j\le q_t\): this is immediate for the fully satisfied types, and follows from \(q_t>r\Rightarrow q_t\ge r+1\) for the others. Consumption equals \(\kappa\), so the Pareto-efficiency condition proved in Section 1 applies.

4. Polynomial running time and output length. Compute the thresholds \(q_t\), evaluate \(G(a)\) for all \(m=k+1\) levels, and construct the assignment above. Direct evaluation requires \(O(m\tau)\) exact rational arithmetic operations.

To check bit complexity, let \(D\) be the product of the denominators of the masses and of \(\kappa\). Its binary length is \(O(L)\). Each \(G(a)\), \(A\), and \(\kappa-G(r)\) can be represented over denominator \(D\), with numerators of magnitude at most \(kD\). Their encoding lengths are therefore \(O(L+\log k)\). Computing \(\alpha\) and multiplying it by the input masses preserves polynomial encoding length. Computing the ceilings of the rational requests also takes polynomial time.

Thus the algorithm has polynomial bit complexity in \(m,\tau,L\). Its output has at most \(2\tau\) nonzero entries and processes only the listed supported types.

Adversarial review (gpt-6.1-sol / medium, Bolzano verifier prompt)

The prover’s claim is correct and fully established. The construction satisfies all requirements, including Pareto efficiency against real-valued reassignment masses, and has polynomial bit complexity. No substantive gaps or errors were found.

1. Satisfaction thresholds.

The definition \(q_t=\lceil d_t\rceil\) gives \(1\le q_t\le k\). For integer bundle sizes, \(q_t\) is indeed the smallest size with utility \(1\).

The strict-utility assertion used in the efficiency argument is valid: if \(0\le\ell<j\le q_t\), then \(\ell\le q_t-1<d_t\). When \(j<q_t\), both utilities lie on the strictly increasing part of the utility function; when \(j=q_t\), the source utility equals \(1\), while the destination utility is strictly smaller.

2. Sufficient condition for Pareto efficiency.

The stated condition is correct. For a supported source bundle \(j\le q_t\), a utility-preserving reassignment cannot send positive mass to \(\ell<j\). A strict improvement necessarily uses \(\ell>j\), increasing consumption by at least one unit per unit of improved mass.

Unsupported sources contribute nothing: nonnegativity and the source-mass equations force all their reassignment entries to be zero. Consequently, the displayed consumption identity and its lower bound by \(S\) apply to the entire reassignment.

If initial consumption equals \(\kappa\), any \(S>0\) violates capacity. This argument uses no integrality assumption on reassignment masses and therefore establishes efficiency under precisely the task’s real reassignment definition.

The separate assertion that universal utility \(1\) implies Pareto efficiency is also correct, since strict improvement is impossible.

3. The fully satisfied case.

When \(G(k)\le\kappa\), assigning mass \(\mu_t\) to bundle \(q_t\) is feasible and rational. Every recipient obtains utility \(1\), which dominates every EF1 comparison and the required utility floor. Pareto efficiency follows from the preceding universal-satisfaction observation.

Equality \(G(k)=\kappa\) is correctly included in this case.

4. The mixed construction.

When \(G(k)>\kappa\), the maximum defining \(r\) exists because \(G(0)=0\). Monotonicity of \(G\) and maximality give
\(G(r)\le\kappa<G(r+1)\), with \(r\le k-1\).

The bound \(G(b)\le b\le\kappa\) correctly establishes \(r\ge b\). The increment identity
\(G(r+1)-G(r)=A\) holds because each integer threshold above \(r\) contributes exactly its mass to that increment, while all other thresholds contribute zero.

Thus \(A>0\), and the stated \(\alpha\) is rational with \(0\le\alpha<1\). The construction preserves each type’s mass, uses allowed bundle sizes, and consumes exactly \(\kappa\). The boundary case \(\alpha=0\) is handled correctly by omitting zero entries.

5. Fairness and efficiency of the mixed construction.

For types with \(q_t\le r\), utility \(1\) establishes both fairness conditions.

For other types, every supported recipient bundle has \(j\ge r\), and every supported bundle anywhere has \(\ell\le r+1\). Therefore \(\ell-1\le j\), which establishes EF1 by monotonicity, including the stipulated negative-argument convention.

The utility floor follows from \(j\ge r\ge b\). Every assigned bundle also satisfies \(j\le q_t\). Together with exact consumption \(\kappa\), this meets all hypotheses of the proved efficiency condition.

6. Running time and output encoding.

Evaluating all \(m\) levels takes \(O(m\tau)\) rational arithmetic operations. The denominator product \(D\) has binary length \(O(L)\), and the claimed common-denominator representations and numerator bounds are valid. Consequently, the intermediate numbers have polynomial encoding length. Division to obtain \(\alpha\), multiplication by input masses, comparisons, and ceiling computations all retain polynomial bit complexity.

The assignment has at most \(2\tau\) nonzero entries and operates only on supported types. A dense representation would also have polynomial size.
