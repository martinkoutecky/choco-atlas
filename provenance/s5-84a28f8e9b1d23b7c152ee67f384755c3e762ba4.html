The continuous mirror question, as graded

Given a finite agenda \(X\), its minimal inconsistent subsets, and rational quota shares \(q_p\), decide whether every rational distribution \(\mu\) with finite support over complete, consistent judgment types yields a consistent collective set \(Q_q(\mu)=\{p:\sum_{t:\,p\in t}\mu_t\ge q_p\}\). If not, return a rational distribution that yields an inconsistent set.

Packaged proof task (what the prover saw — nothing else)

An instance specifies a nonempty agenda \(X\), with \(m=|X|\), consisting of proposition–negation pairs, with double negations cancelled and no tautologies or contradictions. Its representation is a list of proposition labels, their negation pairing, and the exhaustive list \(\mathcal Z\) of minimal inconsistent subsets; this representation is promised to arise from an agenda in classical propositional logic.
A set \(A\subseteq X\) is consistent exactly when it contains no member of \(\mathcal Z\). An admissible judgment type is a consistent subset containing exactly one proposition from each negation pair.
The instance also supplies binary rational quotas \(q_p\in(0,1]\) for every \(p\in X\). A society is given by its support: the list of its \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Define \(Q_q(\mu)=\{p\in X:\sum_{t:p\in t}\mu_t\ge q_p\}\); equality meets the quota. Decide whether this set is consistent for every admissible rational society, and otherwise return a rational society yielding an inconsistent set. No society or list of all admissible types is supplied as input.
State running times in \(m\), \(r=|\mathcal Z|\), and the input bit length \(L\), and for counterexample generation additionally in the returned support size \(\tau\) and mass encoding length \(B\).

Is this universal-consistency decision problem in \(\mathrm P\) or \(\mathrm{NP}\)-hard?

For \(n\ge2\) discrete agents and integer quotas \(a_p\in\{1,\ldots,n\}\), universal consistency holds exactly when \(\sum_{p\in Z}a_p>n(|Z|-1)\) for every minimal inconsistent set \(Z\). [Dietrich–List](https://doi.org/10.1177/0951629807080775)
No result settling the exact distribution-based problem with this explicit input representation was located in the literature search.

Modeling choices made when packaging the task

  • Specified a nonempty agenda closed under negation, with double negations cancelled and no tautologies or contradictions, following the discrete model.
  • Specified an exhaustive, explicitly supplied minimal-inconsistency list and negation pairing, promised to represent a classical propositional agenda; no formula-satisfiability oracle is required.
  • Restricted quota shares to positive binary rationals at most one, corresponding to the discrete thresholds divided by population size.
  • Normalized society masses to one and required positive binary rational masses on the listed support.
  • Clarified that societies are universally quantified rather than supplied as input; support size and mass encoding length describe a returned counterexample.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Polynomial-time solvability

The promised problem is in \(\mathrm P\). More precisely, universal consistency holds exactly when

\(\displaystyle \sum_{p\in Z}q_p>|Z|-1\qquad\text{for every }Z\in\mathcal Z.\)

If this condition fails, a rational counterexample can be constructed in polynomial time, with support size \(\tau\le |Z|\le m\) and total mass encoding length \(B=O(\tau L)\).

The strict inequality is essential: equality admits a counterexample.

1. Completing consistent sets

Write \(\bar p\) for the negation paired with \(p\).

Lemma. Every consistent set \(A\subseteq X\) extends to an admissible judgment type. Such an extension can be constructed using only the supplied pairing and \(\mathcal Z\).

Proof. By the classical-logic promise, a consistent set \(A\) has a satisfying valuation. For every negation pair \(\{p,\bar p\}\), that valuation satisfies exactly one member. Consequently, at least one of \(A\cup\{p\}\) and \(A\cup\{\bar p\}\) is consistent.

Process all pairs. If a pair is already represented in the current set, leave it alone. Otherwise, test whether adding \(p\) preserves consistency. Add \(p\) if it does; otherwise add \(\bar p\), which the preceding argument guarantees is consistent. Each consistency test uses the promised equivalence

\(\displaystyle A\text{ is consistent}\quad\Longleftrightarrow\quad Z\nsubseteq A\text{ for every }Z\in\mathcal Z.\)

The resulting set remains consistent and contains exactly one member of every pair, so it is admissible. \(\square\)

This lemma uses the logical promise but requires neither the underlying formulas nor an enumeration of all admissible types.

2. Proof of the characterization

For a society \(\mu\), let

\(\displaystyle s_p(\mu)=\sum_{t:p\in t}\mu_t.\)

Sufficiency

Fix \(Z\in\mathcal Z\), and write \(k=|Z|\). Every admissible type is consistent, so it cannot contain all of \(Z\). Thus

\(\displaystyle |t\cap Z|\le k-1.\)

Because the society has total mass \(1\),

\(\displaystyle \sum_{p\in Z}s_p(\mu) =\sum_t\mu_t|t\cap Z| \le k-1.\)

If \(Z\subseteq Q_q(\mu)\), every proposition in \(Z\) meets its quota, giving

\(\displaystyle \sum_{p\in Z}q_p \le\sum_{p\in Z}s_p(\mu) \le k-1.\)

Therefore, when \(\sum_{p\in Z}q_p>|Z|-1\) for every listed \(Z\), the aggregate contains no member of \(\mathcal Z\). By the promised consistency characterization, it is consistent.

Necessity and a rational counterexample

Suppose some \(Z=\{p_1,\ldots,p_k\}\in\mathcal Z\) satisfies

\(\displaystyle \sum_{i=1}^k q_{p_i}\le k-1.\)

Define the rational capacities

\(\displaystyle c_i=1-q_{p_i}.\)

Then each \(c_i\) is nonnegative and

\(\displaystyle \sum_{i=1}^k c_i =k-\sum_{i=1}^k q_{p_i}\ge1.\)

Choose rational weights satisfying

\(\displaystyle 0\le w_i\le c_i,\qquad \sum_{i=1}^k w_i=1.\)

For completeness, these can be obtained greedily: set \(R_0=1\), and successively set

\(\displaystyle w_i=\min\{c_i,R_{i-1}\},\qquad R_i=R_{i-1}-w_i.\)

Inductively,

\(\displaystyle R_i=\max\left\{0,1-\sum_{j=1}^i c_j\right\},\)

so \(R_k=0\), proving the required weight properties.

Minimal inconsistency of \(Z\) implies that every \(Z\setminus\{p_i\}\) is consistent. By the lemma, extend it to an admissible type \(T_i\). This extension cannot contain \(p_i\), since it would then contain the inconsistent set \(Z\). Hence

\(\displaystyle T_i\cap Z=Z\setminus\{p_i\}.\)

Give \(T_i\) mass \(w_i\), omitting all zero weights. The retained types are distinct: their intersections with \(Z\) omit different propositions. They therefore form a society with positive rational masses and support size at most \(k\).

For every \(j\),

\(\displaystyle s_{p_j}(\mu) =\sum_{i\ne j}w_i =1-w_j \ge1-c_j =q_{p_j}.\)

Thus \(Z\subseteq Q_q(\mu)\), making the aggregate inconsistent. This proves necessity and completes the characterization. \(\square\)

3. Exact arithmetic and encoding bounds

Write each input quota as \(q_p=b_p/d_p\), where \(b_p,d_p\) are positive binary integers. Set

\(\displaystyle D=\prod_{p\in X}d_p,\qquad H_p=D-b_p(D/d_p).\)

Each \(H_p\) is an integer satisfying

\(\displaystyle H_p=D(1-q_p).\)

The criterion can therefore be checked entirely with integers:

\(\displaystyle \sum_{p\in Z}q_p>|Z|-1 \quad\Longleftrightarrow\quad \sum_{p\in Z}H_p<D.\)

For a failing set, construct integer weights by starting with remainder \(R=D\) and, for its propositions in order, assigning

\(\displaystyle W_i=\min\{H_{p_i},R\},\qquad R\leftarrow R-W_i.\)

The failure condition guarantees that the final remainder is zero. Return the positive masses \(W_i/D\), together with the types constructed above.

The binary length of \(D\) is \(O(L)\), because the sum of the denominator encoding lengths is at most \(L\). Moreover, \(0<W_i\le D\) for every retained weight. Thus each returned mass uses \(O(L)\) bits, and

\(\displaystyle B=O(\tau L),\qquad \tau\le |Z|\le m.\)

No expansion into individual agents is needed.

4. Running times

Let

\(\displaystyle s=\sum_{Z\in\mathcal Z}|Z|\le mr.\)

The following bounds use schoolbook integer arithmetic and logarithmic costs for operations on structural indices and counters. Returned types are represented by indices into the input proposition list.

Decision

Computing \(D\) and all \(H_p\) takes \(O(mL^2)\) bit operations. Scanning the listed sets and summing their capacities takes \(O(sL)\): all intermediate sums have \(O(L+\log m)=O(L)\) bits.

Consequently,

\(\displaystyle T_{\mathrm{decision}} =O(mL^2+sL) \subseteq O(mL^2+mrL).\)

Counterexample generation

The completion lemma has an efficient implementation. Precompute the incidence lists

\(\displaystyle \operatorname{Inc}(p)=\{Z\in\mathcal Z:p\in Z\}.\)

For a current consistent set \(A\), maintain the missing-member counters

\(\displaystyle h_Z=|Z\setminus A|.\)

When \(p\notin A\), adding \(p\) is consistent exactly when \(h_Z\ge2\) for every \(Z\in\operatorname{Inc}(p)\). Indeed, only those sets have their missing-member count decreased, and inconsistency occurs exactly when a count reaches zero.

Initialize the counters by scanning all incidences. During completion, each candidate literal is tested at most once, and each selected literal is added at most once. Testing and updating therefore scan only \(O(s)\) incidences in total. One completion costs

\(\displaystyle O((m+r+s)\log(m+r)).\)

Only the \(\tau\) positive-weight types need completion. Including arithmetic and output, the total bound is

\(\displaystyle T_{\mathrm{counterexample}} =O\!\left(mL^2+sL+\tau(m+r+s)\log(m+r)+B\right).\)

Every negation pair is itself minimally inconsistent: its two singletons are consistent because tautologies and contradictions are excluded. Hence \(r\ge m/2\) and \(s\ge2r\). The bound simplifies to

\(\displaystyle T_{\mathrm{counterexample}} =O\!\left(mL^2+mrL+\tau mr\log(m+r)+B\right).\)

These bounds are polynomial in the explicit input size; the returned witness also has polynomial size.

5. Relation to the finite-agent criterion

For quotas \(q_p=a_p/n\), the characterization becomes precisely

\(\displaystyle \sum_{p\in Z}a_p>n(|Z|-1).\)

In this case, the construction may use the common denominator \(D=n\). Its integer weights sum to \(n\); repeating each constructed type according to its weight yields an \(n\)-agent counterexample whenever the condition fails. This recovers the finite-agent criterion quoted from [Dietrich and List](https://doi.org/10.1177/0951629807080775).
