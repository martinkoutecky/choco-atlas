The continuous mirror question, as graded

Given a finite rational distribution μ over tree-community templates \(H_j\) and a rational pair-sampling rule π_j for candidate nonlinks in each template, compute the exact population-average Myerson distance \(̅d=∑_j μ_j∑_{(u,v)} π_j(u,v)(1/2-q_{uv}(H_j))\) for a continuum of repeated independent communities.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) community types with positive binary-rational masses \(\mu_j\), where \(\sum_j\mu_j=1\); \(\tau\) is the support size, not the number of possible types.
Each type is an explicitly listed finite simple undirected tree \(H_j=(V_j,E_j)\), together with a nonempty set \(C_j\) of unordered pairs of distinct nonadjacent vertices and explicitly listed binary-rational probabilities \(\pi_j(e)\geq0\) satisfying \(\sum_{e\in C_j}\pi_j(e)=1\).
Let \(m=\max_j|V_j|\) and let \(L\) be the total input bit length, including graph descriptions and all rational numbers.
For \(\{u,v\}\in C_j\), choose a uniformly random permutation of \(V_j\). Define \(q_{uv}(H_j)\) as the probability that \(u\) and \(v\) are connected in the subgraph induced by the vertices arriving no later than \(u\); this probability is symmetric in the endpoints. Their Myerson distance is \(\frac12-q_{uv}(H_j)\).
The continuum consists of separate copies of these communities, with community-type masses \(\mu_j\). Its community-weighted population average is \(\bar d=\sum_{j=1}^{\tau}\mu_j\sum_{e\in C_j}\pi_j(e)(\frac12-q_e(H_j))\).

Can \(\bar d\) be computed exactly in time polynomial in \(m,\tau,L\), or is this computation NP-hard?

For finite trees, an incoming-link-deletion procedure computes exact pairwise Myerson distances in polynomial time ([source](https://www.nber.org/papers/w20669)).
No result explicitly addressing this distribution-input computation was identified in the sources checked.

Modeling choices made when packaging the task

  • Normalized the community masses to sum to one and interpreted them as community shares, so the stated average does not introduce additional weighting by community size.
  • Made each template an explicitly encoded connected simple undirected tree, with an explicitly encoded nonempty candidate set of unordered nonlinks; consequently each template has at least three vertices.
  • Made each pair-sampling rule an explicitly listed nonnegative rational probability distribution on its candidate set.
  • Resolved the conflicting descriptions of q using the arrival-order definition and inclusion–exclusion formula: q is connection probability upon one specified endpoint's arrival.
  • Defined m as the maximum template size and L as the total input bit length; exact computation returns a rational value.

Conclusion

The average \(\bar d\) is exactly computable in time polynomial in \(m,\tau,L\). On a tree, each pair’s probability depends only on its path length. The explicitly listed distribution can then be averaged using rational arithmetic with polynomially bounded bit lengths.

1. Exact pair probability on a tree

Fix a listed tree \(H=(V,E)\) and a pair \(\{u,v\}\in C\). Let \(k=\operatorname{dist}_H(u,v)\), where distance counts edges. The unique path from \(u\) to \(v\) has \(k+1\) vertices.

For a permutation \(\sigma\) of \(V\), let \(A_u(\sigma)\) be the set of vertices arriving no later than \(u\). We claim that \(u\) and \(v\) are connected in \(H[A_u(\sigma)]\) exactly when every vertex of their unique path belongs to \(A_u(\sigma)\).

Indeed, if all path vertices belong to this set, the entire path remains in the induced subgraph. Conversely, any connection in the induced subgraph contains a simple path in \(H\). Since \(H\) is a tree, that path must be the unique path from \(u\) to \(v\), so all its vertices must belong to the induced subgraph.

Thus the event defining \(q_{uv}(H)\) is precisely that \(u\) arrives last among the \(k+1\) path vertices.

The relative order of these vertices is uniform: relabeling the path vertices gives bijections between full permutations realizing any two prescribed relative orders. Consequently, each path vertex has probability \(1/(k+1)\) of being last. Hence

\[ q_{uv}(H)=\frac{1}{k+1}, \qquad \frac12-q_{uv}(H)=\frac{k-1}{2(k+1)}. \]

The same calculation with \(v\) as the arrival threshold proves the stated endpoint symmetry. Nonadjacency ensures \(k\geq 2\).

2. Formula and graph computation

For each listed pair \(e=\{u,v\}\in C_j\), write \(k_{j,e}=\operatorname{dist}_{H_j}(u,v)\). The preceding calculation gives

\[ \bar d = \sum_{j=1}^{\tau} \sum_{e\in C_j} \mu_j\pi_j(e)\frac{k_{j,e}-1}{2(k_{j,e}+1)}. \]

All quantities in this expression are computable from the input.

Specifically, perform breadth-first search from every vertex of each tree. A search in \(H_j\) takes \(O(|V_j|)\) graph operations because a tree has \(|V_j|-1\) edges. Therefore all pair distances can be computed in

\[ O\!\left(\sum_{j=1}^{\tau}|V_j|^2\right) \subseteq O(\tau m^2) \]

graph operations. Each listed pair then requires one distance lookup.

Let \(N=\sum_j|C_j|\). Since the pairs are explicitly listed, \(N=O(L)\); also \(N\leq \tau\binom{m}{2}\). Thus the averaging step has only polynomially many terms.

3. Exact arithmetic has polynomial bit complexity

It remains to control intermediate and output lengths; counting rational operations alone would not suffice.

Write the input rationals as

\[ \mu_j=\frac{a_j}{b_j}, \qquad \pi_j(e)=\frac{c_{j,e}}{d_{j,e}}, \]

with positive integer denominators and nonnegative integer numerators. They need not be reduced. Their aggregate binary representation length is \(O(L)\). This also covers explicitly represented dyadic rationals.

Define the integer

\[ D=2m!\left(\prod_{j=1}^{\tau}b_j\right) \left(\prod_{j=1}^{\tau}\prod_{e\in C_j}d_{j,e}\right). \]

For every listed pair, \(k_{j,e}+1\leq |V_j|\leq m\). Thus \(k_{j,e}+1\) divides \(m!\), and

\[ \frac{D}{2b_jd_{j,e}(k_{j,e}+1)} \]

is an integer. We can therefore compute

\[ S= \sum_{j=1}^{\tau}\sum_{e\in C_j} a_jc_{j,e}(k_{j,e}-1) \frac{D}{2b_jd_{j,e}(k_{j,e}+1)} \]

using integer arithmetic, obtaining exactly \(\bar d=S/D\).

The denominator has bit length bounded by

\[ \log_2 D = 1+\log_2(m!) +\sum_j\log_2 b_j +\sum_{j,e}\log_2 d_{j,e} = O(L+m\log m). \]

Here \(m!\leq m^m\), and the denominator logarithms are bounded by their input bit lengths.

Moreover, the weights are nonnegative and satisfy

\[ \sum_{j,e}\mu_j\pi_j(e) = \sum_j\mu_j=1. \]

Every pair distance lies between \(0\) and \(1/2\). Hence \(0\leq S<D/2\), so \(S\) also has \(O(L+m\log m)\) bits. Individual products during its computation have the same asymptotic bit bound: each input factor has \(O(L)\) bits, and \(k_{j,e}-1\) has \(O(\log m)\) bits.

Constructing \(D\) and \(S\) requires \(O(m+\tau+N)\) integer arithmetic operations on polynomially bounded operands. Standard integer multiplication, exact division, and addition take polynomial time in operand bit length. If a reduced output is required, compute \(\gcd(S,D)\) and divide both integers by it; this also takes polynomial time.

4. Complexity conclusion

The graph searches, evaluation of all explicitly listed terms, and exact rational arithmetic all take time polynomial in \(m,\tau,L\). The output itself has polynomial bit length.

Therefore the stated distribution-input computation is polynomial-time exactly solvable. This proof uses only the given permutation definition and the unique-path property of trees; it does not require the cited incoming-link-deletion procedure.
