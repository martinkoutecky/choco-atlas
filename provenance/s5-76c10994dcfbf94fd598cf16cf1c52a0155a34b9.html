The continuous mirror question, as graded

Given finite agent types \(T\) with rational masses \(\mu_t\), item classes \(J\) with rational per-capita supplies \(\rho_j\) satisfying \(1\le\sum_j\rho_j\le2\), and additive values \(u_t(j)\), find nonnegative mass variables \(x_{t,b}\) over integral bundles \(b\in\mathbb Z_{\ge0}^{J}\) with \(1\le\sum_j b_j\le2\), such that \(\sum_bx_{t,b}=\mu_t\), \(\sum_{t,b}b_jx_{t,b}\le\rho_j\), and \(x_{t,b}>0\Rightarrow\sum_jb_ju_t(j)\ge U_t:=\sum_j\rho_ju_t(j)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq1\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) item classes \(J\), with binary rational supplies \(\rho_j\geq0\) per unit of population satisfying \(1\leq\sum_j\rho_j\leq2\), and binary rational additive values \(u_t(j)\in[0,1]\). Let \(L\) be the total input bit length.
An individual receives an integral bundle from \(B=\{b\in\mathbb Z_{\geq0}^{J}:1\leq\sum_jb_j\leq2\}\); two items of the same class are permitted. Supplies may remain unused.
An allocation consists of real masses \(x_{t,b}\geq0\) satisfying \(\sum_{b\in B}x_{t,b}=\mu_t\) for every \(t\), and \(\sum_{t\in T,b\in B}b_jx_{t,b}\leq\rho_j\) for every \(j\).
It is proportional if every positively assigned bundle satisfies \(x_{t,b}>0\Rightarrow\sum_jb_ju_t(j)\geq U_t\), where \(U_t=\sum_j\rho_ju_t(j)\). Decide whether such an allocation exists and find one when it does; inputs are arbitrary subject to these conditions.

Is this proportional mass-allocation feasibility problem in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it NP-hard?

For discrete societies with \(n\) agents and \(k\) items, \(n\leq k\leq2n\), a polynomial-time algorithm outputs a proportional allocation with probability tending to one as \(n\to\infty\), when all individual item values are sampled independently from a fixed non-atomic distribution on \([0,1]\) whose density is bounded above and bounded below by positive constants and whose mean is at most \(1/2\).
That discrete guarantee allows partial allocations and does not classify the arbitrary-input mass feasibility problem defined above.

Modeling choices made when packaging the task

  • Normalized the positive type masses to sum to one, so the per-capita supplies and the stated proportional threshold use the same population normalization.
  • Specified binary rational utilities in [0,1], carrying over the discrete nonnegative utility domain and normalization while giving the computational input a finite encoding.
  • Specified nonnegative supplies, allowing zero-supply classes, and required nonempty type and item-class sets.
  • Interpreted repeated coordinates in an integral bundle as distinct items of the same class, as permitted by the graded question.
  • Retained unused supplies and weak proportionality inequalities, consistent with the discrete allowance for partial proportional allocations.
  • Treated the continuous question as an arbitrary-input feasibility problem; the anchor's random sampling and distributional mean assumptions describe its discrete guarantee rather than restrictions on the given rational society.

Result

The problem is in \(\mathrm P\). A deterministic algorithm can decide feasibility and, when feasible, output an exact rational allocation in time polynomial in \(m,\tau,L\).

The key is that bundles contain at most two items, so all possible bundles can be explicitly enumerated in polynomial time. The allocation masses may be fractional, exactly as allowed in the question.

1. Enumerate the proportional bundles

Let \(e_j\) denote the unit vector for item class \(j\). The complete bundle set is

\(B=\{e_j:j\in J\}\cup\{e_j+e_k:j,k\in J,\ j\leq k\}\).

The case \(j=k\) represents two items of the same class. Thus

\(|B|=m+\frac{m(m+1)}2=\frac{m(m+3)}2\).

For each type \(t\), compute its threshold \(U_t=\sum_{j\in J}\rho_j u_t(j)\) and define its eligible bundle set

\(E_t=\{b\in B:\sum_{j\in J}b_j u_t(j)\geq U_t\}\).

These sets can be computed exactly using rational arithmetic. There are \(\tau|B|\) eligibility comparisons. Computing each threshold involves \(m\) rational products and their sum. The denominators can be represented using products of input denominators, whose bit lengths are bounded by the sum of their input bit lengths. Consequently, all intermediate numbers have bit length polynomial in \(L\), and eligibility testing takes time polynomial in \(m,\tau,L\).

Equality with the threshold is included, as required by the definition.

2. Construct a linear program

Introduce a real variable \(x_{t,b}\) for every \(t\in T\) and \(b\in E_t\). Consider the following feasibility system:

  • Nonnegativity: \(x_{t,b}\geq0\) for every introduced variable.
  • Type conservation: \(\sum_{b\in E_t}x_{t,b}=\mu_t\) for every \(t\in T\).
  • Supply constraints: \(\sum_{t\in T}\sum_{b\in E_t}b_jx_{t,b}\leq\rho_j\) for every \(j\in J\).

If some \(E_t\) is empty, its conservation equation reads \(0=\mu_t\), so the system is infeasible because \(\mu_t>0\).

There are at most \(\tau m(m+3)/2\) variables, \(\tau\) conservation equations, and \(m\) supply inequalities. Every matrix coefficient belongs to \(\{0,1,2\}\). The right-hand sides are the input rationals \(\mu_t,\rho_j\). Therefore, the entire linear program has encoding length polynomial in \(m,\tau,L\), even with a dense matrix representation.

3. Prove equivalence

A proportional allocation gives a feasible solution of the linear program.
Suppose an allocation satisfies all conditions in the question. If \(b\notin E_t\), then its value to type \(t\) is strictly below \(U_t\). Proportionality therefore forces \(x_{t,b}=0\). Removing these zero coordinates leaves precisely the variables introduced above. The original conservation and supply constraints become the corresponding linear-program constraints.

A feasible solution gives a proportional allocation.
Conversely, suppose the linear program has a feasible solution. Extend it to all \(t\in T,b\in B\) by setting \(x_{t,b}=0\) whenever \(b\notin E_t\). Conservation and supply feasibility hold by the linear-program constraints. Every positively assigned bundle belongs to \(E_t\), so its value is at least \(U_t\). Hence the extended allocation is proportional.

Thus the two feasibility questions are equivalent. In particular, unused supplies require no additional conditions: they are already permitted by the supply inequalities.

4. Polynomial-time decision and construction

Use the standard exact rational linear-programming theorem: given a linear system with rational coefficients and total binary encoding length \(S\), a deterministic algorithm running in time polynomial in \(S\) decides feasibility over the reals and, when feasible, returns a rational feasible point of total encoding length polynomial in \(S\). Equalities can be represented by two inequalities.

Its hypotheses hold here: all coefficients and right-hand sides are rational, and the system’s encoding length is polynomial in \(m,\tau,L\). Applying the theorem therefore decides feasibility within the requested running time.

When feasible, return the resulting rational masses for eligible bundles and assign zero mass to all other bundles. Section 3 proves that this is the requested allocation. Its encoding length is polynomial, and its validity can be checked by exact rational arithmetic.

Feasibility is not automatic. For example, take \(m=\tau=1\), \(\mu_1=1\), \(\rho_1=3/2\), and \(u_1(1)=1\). The threshold is \(3/2\), so only the two-item bundle is eligible. Giving that bundle to the entire population requires supply \(2>3/2\), making this instance infeasible.

The classification is therefore a polynomial-time feasibility algorithm for arbitrary inputs. It does not depend on the stated probabilistic guarantee for discrete societies.
