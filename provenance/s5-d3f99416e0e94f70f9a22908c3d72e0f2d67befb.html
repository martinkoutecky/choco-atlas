Theorem 3 — class: algorithmic

The continuous mirror question, as graded

Given agent types \(K=[\tau]\) with rational masses \(\mu_k\), item classes \(J=[t]\) with rational per-capita supplies \(q_j\), and valuation oracles \(\nu_k:2^J\to\{0,-1\}\), find a finite-support rational allocation \(x_{k,\mathbf b}\ge 0\) over integral bundles \(\mathbf b\in\mathbb N^t\). Require \(\sum_{\mathbf b}x_{k,\mathbf b}=\mu_k\), \(\sum_{k,\mathbf b}x_{k,\mathbf b}b_j=q_j\), and EF1 for every pair of positive-mass type-bundle cells, using \(\bar\nu_k(\mathbf b)=\nu_k(\{j:b_j>0\})\); ask whether such an allocation can be found in time and output length polynomial in \(t,\tau,L\), counting valuation-oracle queries.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(K=[\tau]\), the list of types with positive binary-rational masses \(\mu_k\), with \(\sum_k\mu_k=1\). Here \(\tau\) is the support size, not the number of possible valuation types.
There are \(J=[t]\) item classes (write \(m=t\)), with binary-rational per-capita supplies \(q_j\ge0\). Each type has a value oracle \(\nu_k:2^J\to\{0,-1\}\), with \(\nu_k(\emptyset)=0\); no monotonicity or identity across types is assumed. Let \(L\) be the bit length of the finite input outside the oracles.
An integral bundle is \(\mathbf b\in\mathbb Z_{\ge0}^t\), including the empty bundle, and \(\bar\nu_k(\mathbf b)=\nu_k(\{j:b_j>0\})\). An allocation is a finite list of cells with binary-rational masses \(x_{k,\mathbf b}>0\) and binary-encoded bundle coordinates, satisfying \(\sum_{\mathbf b}x_{k,\mathbf b}=\mu_k\) and \(\sum_{k,\mathbf b}x_{k,\mathbf b}b_j=q_j\).
Require EF1 for every ordered pair of positive-mass cells \((k,\mathbf b),(\ell,\mathbf c)\), including cells of the same type: if \(\bar\nu_k(\mathbf b)<\bar\nu_k(\mathbf c)\), then either some \(j\) with \(b_j>0\) satisfies \(\bar\nu_k(\mathbf b-\mathbf e_j)\ge\bar\nu_k(\mathbf c)\), or some \(j\) with \(c_j>0\) satisfies \(\bar\nu_k(\mathbf b)\ge\bar\nu_k(\mathbf c-\mathbf e_j)\), where \(\mathbf e_j\) is the unit vector. Removal affects exactly one copy in exactly one bundle.

Is finding such an allocation polynomial-time solvable in \(m,t,\tau,L\), with polynomial output length and counting value-oracle queries, or is this search problem NP-hard?

For finitely many agents and explicitly listed indivisible items, arbitrary nonidentical negative Boolean valuations admit a complete EF1 allocation computable in polynomial time and polynomially many value queries ([Bhaskar et al.](https://arxiv.org/html/2411.19881v1)).
No result settling this precise continuous problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalize total society mass to one, so supplies are per capita; require strictly positive support masses and nonnegative supplies.
  • Require zero value for the empty set, as implicitly used by the discrete algorithm and its proof.
  • Interpret integral bundles as nonnegative integer vectors, allowing empty bundles, with binary-encoded coordinates and no additional bundle-size bound.
  • Specify EF1 as removal of one copy from either the envying or the envied bundle, affecting only the chosen bundle, including comparisons between distinct cells of the same type.
  • Identify m with t, the number of item classes, and define L as the finite input bit length outside the valuation oracles.

Result

The search problem is polynomial-time solvable, with polynomially many value-oracle queries and polynomial output length. In fact, an allocation with \(O(\tau+t)\) positive-mass cells can always be constructed.

The construction adapts the greedy idea underlying [Bhaskar et al., Algorithm NegBooleanEF1](https://arxiv.org/html/2411.19881v1). An additional stopping rule bounds the number of steps independently of the magnitudes and denominators of the supplies. The proof below is self-contained.

1. A compression lemma

For a bundle \(\mathbf b\), write \(\operatorname{supp}(\mathbf b)=\{j:b_j>0\}\).

Lemma. Suppose a population of total rational mass \(a>0\), partitioned into \(s\) types with specified positive rational masses, must receive supplies \(r_j\). Assume every positive \(r_j\) satisfies \(r_j\ge a\). Then these supplies can be allocated using at most \(s+t\) cells, with every bundle having support \(R=\{j:r_j>0\}\).

Moreover, the cell masses are obtained from the given masses and supplies using only addition, subtraction, and multiplication by integers.

Proof. For each class, define

\(n_j=\lfloor r_j/a\rfloor\) and \(\rho_j=r_j-a n_j\).

Thus \(0\le\rho_j<a\). Represent the population by the interval \([0,a)\), partitioned into consecutive intervals of the specified type masses. Add a cut at every \(\rho_j\). On each resulting interval, assign the constant bundle whose coordinate at a point \(u\) is

\(b_j(u)=n_j+\mathbf 1_{\{u<\rho_j\}}\).

Its total supply in coordinate \(j\) is \(a n_j+\rho_j=r_j\). If \(r_j>0\), then \(n_j\ge1\); if \(r_j=0\), then \(n_j=\rho_j=0\). Hence every bundle has support exactly \(R\).

There are at most \(s-1\) internal type boundaries and \(t\) additional cuts, giving at most \(s+t\) positive-length intervals. Their lengths have the asserted arithmetic form. \(\square\)

2. State and terminal constructions

Maintain unallocated type masses \(a_k\) and remaining supplies \(r_j\), initially \(a_k=\mu_k\) and \(r_j=q_j\). Define

\(A=\{k:a_k>0\}\), \(R=\{j:r_j>0\}\), and \(M=\sum_{k\in A}a_k\).

Previously allocated cells remain unchanged. Apply the following cases in order.

Case I: No remaining supplies

If \(R=\emptyset\), give every remaining type its remaining mass of empty bundles and stop.

Case II: A remaining type values the remaining support at zero

If some \(k\in A\) satisfies \(\nu_k(R)=0\), let

\(\alpha=\min\bigl(\{a_k\}\cup\{r_j:j\in R\}\bigr)>0\).

Apply the compression lemma to mass \(\alpha\) of type \(k\), using all remaining supplies. Every resulting bundle has support \(R\), so its owner values it at zero.

Give all other remaining population, including any remaining mass of type \(k\), empty bundles and stop. All cells created in this terminal case have value zero for their owners.

Case III: Every remaining class can cover the remaining population

Suppose every \(k\in A\) satisfies \(\nu_k(R)=-1\), and every \(j\in R\) satisfies \(r_j\ge M\).

Apply the compression lemma to the entire remaining population, respecting its remaining type masses. Every resulting bundle has support \(R\). Consequently, every active type values every bundle created in this terminal case at \(-1\). Stop.

It remains to specify the nonterminal step.

3. The greedy step

Assume none of the terminal cases applies. Thus all active types value \(R\) at \(-1\), and the set of scarce classes

\(B=\{j\in R:r_j<M\}\)

is nonempty.

Starting from \(S=R\), repeatedly delete a class \(j\in S\) whenever

\(\nu_\ell(S\setminus\{j\})=-1\) for every \(\ell\in A\).

Stop when no such deletion is possible. The resulting set satisfies:

  • \(\nu_\ell(S)=-1\) for every \(\ell\in A\).
  • For every \(j\in S\), some \(k\in A\) satisfies \(\nu_k(S\setminus\{j\})=0\).

These properties follow directly from the deletion rule and its stopping condition. Also, \(S\ne\emptyset\), because every valuation assigns zero to the empty set. Only this local stopping condition is needed; no assumption about monotonicity is used.

Choose \(j_*\in S\) and a witnessing type \(k\in A\) with \(\nu_k(S\setminus\{j_*\})=0\). Allocate the bundle \(\mathbf 1_S\), consisting of exactly one copy of each class in \(S\), to mass

\(\lambda=\min\bigl(\{a_k\}\cup\{r_j:j\in S\}\cup\{M-r_j:j\in B\setminus S\}\bigr)\)

of type \(k\).

Every candidate in this minimum is positive. Update

\(a_k\leftarrow a_k-\lambda\), and \(r_j\leftarrow r_j-\lambda\) for every \(j\in S\).

All other masses and supplies remain unchanged.

This step has two essential properties:

  • Its owner values the allocated bundle at \(-1\), but removing the single copy of \(j_*\) raises that value to zero.
  • Every type active when the step is performed values this allocated bundle at \(-1\).

The extra candidates \(M-r_j\), for scarce classes outside \(S\), provide the polynomial step bound.

4. Termination after polynomially many steps

First, every greedy step leaves positive unallocated population.

Choose any \(j\in B\). If \(j\in S\), then \(\lambda\le r_j<M\). If \(j\notin S\), then \(\lambda\le M-r_j<M\), since \(r_j>0\). Thus \(\lambda<M\), and the new total mass is \(M'=M-\lambda>0\).

Each greedy step causes at least one of these events:

  • A type is exhausted, if \(\lambda=a_k\).
  • A class supply is exhausted, if \(\lambda=r_j\) for some \(j\in S\).
  • A scarce class becomes abundant, if \(\lambda=M-r_j\) for some \(j\in B\setminus S\). Indeed, its supply is unchanged and now equals \(M'\).

The first two events can occur at most \(\tau\) and \(t\) times, respectively. The third can occur at most \(t\) times, because abundance never reverses. To verify this, for every class surviving a step,

\(r'_j-M'=r_j-M\) if \(j\in S\),

and

\(r'_j-M'=r_j-M+\lambda\) if \(j\notin S\).

Hence \(r_j-M\) never decreases. Once a positive class supply is at least the remaining population mass, it remains so while present.

Therefore there are at most \(\tau+2t\) greedy steps. If no terminal case held afterward, another greedy step would produce another event, contradicting these bounds. Thus the algorithm terminates.

5. Proof of EF1

Conservation follows from the updates: each greedy step records precisely the population mass and supplies it subtracts, and every terminal construction allocates all remaining masses and supplies exactly.

Now consider any positive-mass cell as the potentially envious cell.

Greedy cells

A greedy cell of type \(k\) receives \(\mathbf 1_S\), with

\(\bar\nu_k(\mathbf 1_S)=-1\) and \(\bar\nu_k(\mathbf 1_S-\mathbf e_{j_*})=0\).

If it envies any cell, the target has value zero under \(\nu_k\), since the valuation range is \(\{0,-1\}\). Removing the single copy of \(j_*\) from its own bundle therefore eliminates the envy.

This argument applies to every target, including cells of the same type.

Terminal cells from Cases I and II

Every such cell has value zero for its owner. Zero is the maximum possible value, so none of these cells envies any cell.

Terminal cells from Case III

Let \(k\) be the type of such a cell. Its own value is \(-1\).

Every other terminal bundle has support \(R\), and \(\nu_k(R)=-1\). Every earlier greedy bundle also has value \(-1\) under \(\nu_k\): type \(k\) was active when that bundle was allocated, because it still has positive unallocated mass at termination.

There are no earlier terminal cells, since a terminal construction ends the algorithm. Thus type \(k\) values every allocated bundle at \(-1\), and this cell envies none.

These cases exhaust all cells. Therefore the allocation satisfies the required EF1 condition for every ordered pair.

6. Oracle complexity and output length

Value queries

One greedy step uses at most \(t\) successful deletions. Each deletion search tests at most \(t\) candidate classes, using at most \(\tau\) value queries per candidate. Terminal-case detection and witness selection fit within the same \(O(\tau(t+1)^2)\) bound.

With at most \(\tau+2t\) greedy steps, the total query count is

\(O((\tau+t)\tau(t+1)^2)\).

All queried objects are subsets of the \(t\) classes.

Number of cells

Each greedy step creates one cell. Cases I and II create at most \(\tau+t+1\) terminal cells, and Case III creates at most \(\tau+t\). The total number of cells is therefore \(O(\tau+t)\).

Repeated cells with the same type and bundle may be merged by adding their masses; this preserves conservation and EF1.

Bit lengths

Let \(D\) be the product of the denominators of the input masses and supplies. Its bit length is \(O(L)\). Initially every mass and supply is an integer multiple of \(1/D\).

Every greedy update preserves this property: its mass \(\lambda\) is chosen from existing masses, supplies, and differences of such quantities. The compression lemma also preserves it, since all cut points and type boundaries are formed using integer multiples, additions, and subtractions of these quantities. Hence every positive output mass is at least \(1/D\), and its numerator and denominator have \(O(L+1)\) bits.

For a compression step with population mass \(a>0\), we have \(a\ge1/D\). Its bundle coordinates satisfy

\(b_j\le r_j/a+1\le Dq_j+1\).

Thus every coordinate has \(O(L+1)\) bits. Greedy coordinates are simply zero or one.

All arithmetic consequently has polynomial bit complexity, and the complete output has polynomial length. The construction also preserves dyadic masses when the inputs are dyadic.

Conclusion

The stated continuous search problem admits a polynomial-time algorithm, using polynomially many oracle queries and producing \(O(\tau+t)\) cells of polynomial encoding length. The proof allows arbitrary nonidentical, nonmonotone valuations and uses exactly the stipulated one-copy removal operation.

The type boundaries and additional cuts produce at most \(s+t\) positive-length intervals. Coincident cuts and cuts at zero do not increase this bound. Each interval lies within one type interval, so type masses are preserved.
