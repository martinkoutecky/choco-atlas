The continuous mirror question, as graded

Given a finite set \(T\) of complete agent types, a symmetric valuation table \(v:T\times T\to\{0,\ldots,6\}\), and positive rational masses \(\mu_t\) summing to \(1\), decide whether there are nonnegative masses \(z_M\) for multisets \(M\) of three types such that \(\sum_M a_t(M)z_M=\mu_t\) for every \(t\in T\), and no justified envy occurs between any two occupied team compositions. Specifically, for every \(M,R\) with \(z_M,z_R>0\), every slot type \(t\in M\), and every slot type \(u\in R\), it must not be the case that \(\sum_{s\in R\setminus\{u\}}v_t(s)>\sum_{s\in M\setminus\{t\}}v_t(s)\) and \(v_s(t)>v_s(u)\) for both slots \(s\in R\setminus\{u\}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) complete types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length and the fixed team size is \(m=3\).
The input includes a symmetric table \(v:T\times T\to\{0,\ldots,6\}\) specifying all interpersonal valuations. The entry \(v(t,t)\) values a distinct agent of the same type and need not be zero; no agent values itself in its utility.
Let \(\mathcal M\) be all multisets of exactly three types, allowing repetitions, and let \(a_t(M)\) count occurrences of \(t\) in \(M\). An allocation consists of real masses \(z_M\geq0\) satisfying \(\sum_{M\in\mathcal M}a_t(M)z_M=\mu_t\) for every \(t\in T\).
A type \(t\) slot in \(M\) has utility \(U_t(M)=\sum_{s\in M\setminus\{t\}}v(t,s)\); removal deletes one occurrence and sums count multiplicities. Equal utilities mean indifference.
The allocation is justified-envy-free if, for every ordered pair \(M,R\) with \(z_M,z_R>0\), including \(M=R\), and every choice of slots \(t\in M\), \(u\in R\), the conditions \(\sum_{s\in R\setminus\{u\}}v(t,s)>U_t(M)\) and \(v(s,t)>v(s,u)\) for both remaining slots \(s\) do not hold simultaneously. Comparisons concern distinct agents in distinct teams, which may have identical compositions.

Is deciding whether such an allocation exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite societies whose positive number of agents is divisible by three, existence of a justified-envy-free partition into triples is NP-complete even with symmetric integer valuations in \(\{0,\ldots,6\}\). [Source](https://eprints.gla.ac.uk/319085/3/319085.pdf)
No result settling this exact continuous allocation problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted diagonal type valuations as valuations of distinct agents of the same type, retaining the graded question's unrestricted diagonal; the discrete zero self-valuation convention applies only to an agent's own identity.
  • Specified allocation masses as nonnegative real numbers, with the society's input masses remaining binary rationals.
  • Specified that multiset removal deletes one occurrence and that utilities and justification tests count both remaining slots, including repeated types.
  • Interpreted comparisons with identical compositions as comparisons between distinct teams carrying those compositions.
  • Required nonempty support and defined m as the fixed team size three and L as total input bit length.

Result

Every valid input admits a justified-envy-free allocation. Consequently, the existence decision problem is polynomial-time solvable: on the promised input domain, the algorithm always returns “yes.”

The proof uses Scarf’s lemma. Repeated-type triples ensure that its fractional solution allocates every type’s entire mass.

1. The version of Scarf’s lemma used

Let \(A\in\mathbb R_{\geq 0}^{n\times d}\) have no zero column, and let \(b\in\mathbb R_{>0}^{n}\). For each row \(i\), prescribe a strict total order \(\succ_i\) on the columns \(j\) with \(A_{ij}>0\).

Scarf’s lemma guarantees a point \(x\geq 0\) with \(Ax\leq b\) such that every column \(j\) is dominated in some row \(i\). Here domination means:

  • \(A_{ij}>0\);
  • \((Ax)_i=b_i\);
  • every column \(k\) satisfying \(A_{ik}x_k>0\) is either \(j\) itself or ranked above \(j\) in \(\succ_i\).

This is the formulation stated in [Lemma 1 of *Stable Hypergraph Matching in Unimodular Hypergraphs*](https://drops.dagstuhl.de/storage/00lipics/lipics-vol334-icalp2025/html/LIPIcs.ICALP.2025.31/LIPIcs.ICALP.2025.31.html).

The lemma applies to arbitrary nonnegative matrices; its entries need not be binary. Thus it accommodates repeated types.

2. Applying the lemma to team compositions

Index rows by types \(t\in T\) and columns by triples \(M\in\mathcal M\). Define \(A_{tM}=a_t(M)\) and \(b_t=\mu_t\).

Every column is nonzero because its entries sum to three. Every coordinate of \(b\) is positive by hypothesis. The feasible set \(P=\{z\geq 0:Az\leq\mu\}\) is nonempty because it contains zero. It is also bounded: summing its row inequalities gives \(3\sum_{M\in\mathcal M}z_M\leq 1\).

For each type \(t\), order the columns containing \(t\) by decreasing utility \(U_t(M)\), breaking ties arbitrarily. This gives the strict orders required by Scarf’s lemma. Because the orders refine utility comparisons, a column ranked at least as highly as another has at least as much utility.

Apply the lemma to obtain \(z\in P\) dominating every column.

All mass constraints are tight. To see this, fix \(t\) and consider the homogeneous triple \(H_t=\{t,t,t\}\). Its column has a positive entry only in row \(t\). Since this column must be dominated somewhere, it must be dominated in row \(t\). Domination therefore gives \((Az)_t=\mu_t\).

This holds for every \(t\), so \(z\) is an allocation satisfying exactly the required mass constraints.

3. A utility property of this allocation

Because \(\mu_t>0\) and \((Az)_t=\mu_t\), every type occurs in at least one positive-mass composition. Define its minimum assigned utility by

\(\ell_t=\min\{U_t(M):z_M>0,\ a_t(M)>0\}\).

For every possible triple \(C\in\mathcal M\), domination of its column provides a type \(r\in C\) such that every positive-mass composition containing \(r\) ranks at least as highly as \(C\). Consequently,

\(\ell_r\geq U_r(C)\).

We have therefore established the following property:

For every possible triple \(C\), at least one type occurring in \(C\) receives utility at least \(U_r(C)\) in every occupied composition containing that type.

4. Justified envy would contradict this property

Suppose, for a contradiction, that justified envy occurs between occupied compositions \(M\) and \(R\).

Let \(t\) be the envying slot in \(M\), and let \(u\) be the slot it would replace in \(R\). Write the two remaining slots of \(R\) as \(a,b\), allowing their types to coincide with each other or with \(t,u\).

The assumed justified envy gives

\(v(t,a)+v(t,b)>U_t(M)\),

\(v(a,t)>v(a,u)\), and \(v(b,t)>v(b,u)\).

Consider the possible triple \(C=\{t,a,b\}\). The incoming slot satisfies

\(U_t(C)=v(t,a)+v(t,b)>U_t(M)\geq\ell_t\).

For the retained slot of type \(a\), its utilities before and after replacement are

\(U_a(R)=v(a,u)+v(a,b)\)

and

\(U_a(C)=v(a,t)+v(a,b)\).

The strict justification inequality therefore implies

\(U_a(C)>U_a(R)\geq\ell_a\).

Likewise,

\(U_b(C)=v(b,t)+v(b,a)>v(b,u)+v(b,a)=U_b(R)\geq\ell_b\).

Thus every type occurring in \(C\) has utility in \(C\) strictly greater than its minimum assigned utility. This contradicts the property proved in Section 3.

These calculations remain valid with repeated types: each formula removes the relevant slot occurrence and counts the remaining occurrences. They also remain valid when \(M=R\), since they compare the slots’ original utilities with those in \(C\). Hence the contradiction covers every comparison required by the question.

The allocation \(z\) is justified-envy-free.

5. Complexity and the finite result

Universal existence settles the decision problem. Returning “yes” on every valid input takes constant time under the promise; reading and validating the input can be done in polynomial time in \(L\).

This proof does not establish a polynomial-time algorithm for *constructing* an allocation. Such an algorithm is unnecessary for the existence decision question.

There is no contradiction with the supplied finite hardness result. Scarf’s lemma supplies fractional team masses rather than integer numbers of teams. Moreover, the present model allows homogeneous triples of every type, which force every row constraint to be tight in the argument above. A finite instance with one agent of each type cannot use those triples.
