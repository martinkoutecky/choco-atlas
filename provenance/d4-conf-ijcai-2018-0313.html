Exact minimization is polynomial-time solvable

The stipulated problem admits an exact deterministic polynomial-time algorithm. It returns both a rational minimizing fraction \(q^\star\) and the rational minimum value. The algorithm examines at most three candidate points, regardless of the numerical size of \(B\).

1. Reduction to a single rational function

Set \(n=Bq\). Since \(B>0\), this substitution is a bijection between \(q\in[0,1]\) and \(n\in[0,B]\). Define
\(c=a-b+2d\). The objective becomes

\(G(n)=F_x(n)=\dfrac{bn^2+cn+v}{(n+1)^2}.\)

The denominator is positive throughout \([0,B]\). Thus \(G\) is continuous on this compact interval and differentiable on its interior. In particular, a global minimum exists.

This is the objective in Equation (1) of the [original source](https://www.ijcai.org/proceedings/2018/0064.pdf), whose Propositions 1 and 2 analyze real-valued recruitment. The following argument establishes the bounded-interval optimization and its bit complexity directly.

2. A complete candidate set

Define
\(\alpha=2b-c=3b-a-2d\) and
\(\beta=c-2v=a-b+2d-2v\).

Differentiating and simplifying gives

\(G'(n)=\dfrac{(2bn+c)(n+1)-2(bn^2+cn+v)}{(n+1)^3} =\dfrac{\alpha n+\beta}{(n+1)^3}.\)

Consider the following cases.

  • If \(\alpha\ne0\): the derivative has exactly one possible zero,

\(r=-\beta/\alpha\). Every global minimizer in \((0,B)\) must have derivative zero, by Fermat’s theorem. Consequently, some global minimizer belongs to the set consisting of \(0\), \(B\), and \(r\) if \(r\in[0,B]\).

  • If \(\alpha=0\) and \(\beta\ne0\): the derivative has the fixed nonzero sign of \(\beta\), because its denominator is positive. By the mean value theorem, \(G\) is strictly monotone. Its minimum is therefore attained at an endpoint.
  • If \(\alpha=\beta=0\): the equations imply \(c=2b\) and \(v=b\). Hence

\(G(n)=b(n+1)^2/(n+1)^2=b\).
Every feasible point minimizes \(G\), including \(0\).

Thus the following algorithm is correct in every case:

  • Start with the candidate set \(\mathcal C=\{0,B\}\).
  • If \(\alpha\ne0\), compute \(r=-\beta/\alpha\), adding it when \(0\le r\le B\).
  • Evaluate \(G\) exactly at every candidate and select one with the smallest value.
  • Return \(q^\star=n^\star/B\) and \(G(n^\star)\).

The set contains at most three points. Including a stationary point that happens to be a maximum is harmless: the algorithm compares its value with both endpoints.

3. Exact arithmetic and bit complexity

Represent each input rational as an integer numerator divided by a positive integer denominator. Let \(T\) be the product of the four moment denominators, and write

\(v=V/T,\qquad a=A/T,\qquad b=K/T,\qquad d=D/T,\)

where \(V,A,K,D\) are integers, possibly signed where permitted.

Define the integers

\(P=3K-A-2D,\qquad Q=A-K+2D-2V.\)

Then \(\alpha=P/T\), \(\beta=Q/T\), and, when \(P\ne0\), the stationary candidate is \(r=-Q/P\). Represent it with a positive denominator by setting

\(u=-Q\,\operatorname{sgn}(P),\qquad w=|P|.\)

The feasibility test is exactly \(0\le u\le Bw\), using integer comparisons.

For any feasible candidate \(n=u/w\), with \(w>0\), substitution yields the exact evaluation formula

\(G(u/w)= \dfrac{Ku^2+(A-K+2D)uw+Vw^2}{T(u+w)^2}.\)

Its denominator is positive. Thus two candidate values \(N_1/H_1\) and \(N_2/H_2\), with \(H_1,H_2>0\), can be compared exactly by comparing the signed integers \(N_1H_2\) and \(N_2H_1\). The returned recruitment fraction is \(q^\star=u/(Bw)\).

Let \(L\) denote the total input bit length, including the binary encoding of \(B\). Every integer constructed above has \(O(L)\) bits:

  • The bit length of \(T\) is bounded by the sum of the four denominator bit lengths, up to a constant.
  • Forming the common-denominator numerators and the fixed linear combinations \(P,Q\) preserves an \(O(L)\) bound.
  • Multiplication by \(B\), squaring, evaluating the fixed-degree expressions, and cross multiplication involve only a fixed number of factors of \(O(L)\) bits.

There are only constantly many integer arithmetic operations and comparisons. With ordinary schoolbook arithmetic, the algorithm uses \(O(L^2)\) bit operations and returns fractions with \(O(L)\)-bit numerators and denominators, allowing unreduced fractions. If reduced fractions are required, greatest-common-divisor computations also take polynomial time.

In particular, the algorithm never enumerates the \(B\) humans. Its dependence on \(B\) is through the encoding length \(\ell_B=\lfloor\log_2 B\rfloor+1\), which is already included in \(L\).

4. Classification and scope

Exact minimization is therefore polynomial-time solvable, with \(\tau=1\), including all signs of the covariances and all degenerate derivative cases. A rational-threshold decision version is also in \(\mathrm P\), since the exact minimum can be compared with the threshold in polynomial time.

The realizability promise requires no additional algorithmic work: the proof applies to every rational coefficient tuple for the stipulated interpolation, and therefore applies to every promised input. No additional parameter or discrete selection problem is introduced.
