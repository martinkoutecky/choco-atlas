The problem is \(\mathrm{EXPTIME}\)-complete under polynomial-time many-one reductions, and therefore \(\mathrm{NP}\)-hard. Hardness already holds with \(\tau=1\) and mass \(1\).

I first give a direct, self-contained proof of \(\mathrm{NP}\)-hardness. I then prove the stronger classification using the standard combined-complexity theorem for positive Datalog.

1. Direct reduction from satisfiability.

Let \(\varphi(x_1,\ldots,x_n)\) be a propositional formula, with \(n\geq1\). Construct an instance with

\(m=n+2,\qquad \mathcal O=\{0,1\}^{m},\qquad s=(0,0,0^n),\qquad t=(0,1,0^n).\)

For each assignment \(a\in\{0,1\}^{n}\), write \(w_a=(1,0,a)\). These outcomes are distinct from both \(s\) and \(t\).

Use one type of mass \(1\), whose theory consists of the following two flat clauses:

\(d(s,(1,0,X_1,\ldots,X_n))\leftarrow C_\varphi(X_1,\ldots,X_n),\)

\(d((1,0,X_1,\ldots,X_n),t)\leftarrow \top.\)

Here \(C_\varphi\) replaces each propositional variable \(x_i\) in \(\varphi\) by the equality \(X_i=1\). It is an allowed propositional combination of Boolean-coordinate equalities, and its size is linear in the size of \(\varphi\).

The derived \(d\)-edges are exactly

\(s\longrightarrow w_a\quad\text{when }\varphi(a)\text{ is true},\)

and

\(w_a\longrightarrow t\quad\text{for every }a.\)

Because every outcome is feasible, the two runtime clauses define precisely reachability by a path of positive length in this graph. To verify this assertion, the base clause derives every one-edge path; the recursive clause prepends one edge to an already derived path. Conversely, induction on path length derives every positive-length path.

There is a path from \(s\) to \(t\) exactly when some \(a\) satisfies \(\varphi\). Consequently,

\(\varphi\text{ is satisfiable}\quad\Longleftrightarrow\quad L(P)\vdash\operatorname{dom}(s,t).\)

With one type of mass \(1\), the supporting mass is \(1\) when dominance holds and \(0\) otherwise. Thus the strict majority test has exactly the same answer.

The construction has polynomial size, uses a nonempty common feasible set, and supplies feasible, distinct query outcomes. This proves \(\mathrm{NP}\)-hardness even for one type with two flat clauses.

2. Stronger lower bound: encoding positive Datalog.

Use the following standard theorem: deciding whether a ground atom belongs to the least model of an explicitly supplied finite, function-free positive Datalog program and database is \(\mathrm{EXPTIME}\)-complete under combined complexity. Here predicate arities and the program are part of the input. This is the Datalog complexity result stated in [Section 2.3 of the supplied source](https://arxiv.org/pdf/1504.06374).

We encode an arbitrary instance of that problem into the syntax specified in the question.

Let \(Q\) include both the Datalog rules and the database facts, let \(q\) be its ground query, and let its finite constant domain be \(D\), of size \(k\geq1\). Set

\(b=\max\{1,\lceil\log_2 k\rceil\},\)

and choose an injective encoding \(e:D\longrightarrow\{0,1\}^{b}\).

Introduce an auxiliary predicate \(\operatorname{valid}\) of arity \(b\), with exactly the facts

\(\operatorname{valid}(e(c))\qquad(c\in D).\)

Translate every original predicate \(p\) of arity \(r\) into a fresh auxiliary predicate \(\widehat p\) of arity \(rb\). Replace every constant by its code and every variable \(X\) by a block of fresh Boolean variables \(\mathbf X=(X_1,\ldots,X_b)\), using the same block at all occurrences of \(X\).

For each translated rule, add \(\operatorname{valid}(\mathbf X)\) to its body for every original variable \(X\) occurring in that rule. Denote the resulting positive Boolean program by \(\widehat Q\).

This translation preserves least-model derivability:

\(Q\vdash p(c_1,\ldots,c_r)\quad\Longleftrightarrow\quad \widehat Q\vdash\widehat p(e(c_1),\ldots,e(c_r)).\)

Here is the justification. A ground substitution over \(D\) gives a Boolean substitution satisfying every added validity atom, and therefore turns each applicable original rule into an applicable translated rule. Conversely, any applicable translated rule assigns a valid code to every original variable. Injectivity of \(e\) supplies a unique corresponding substitution over \(D\). Every derived translated predicate atom consequently has valid coded arguments. Induction on finite derivation trees proves both directions. Positive finite programs have least models consisting exactly of atoms with such finite derivations.

Now choose

\(m=1,\qquad\mathcal O=\{0,1\},\qquad s=(0),\qquad t=(1).\)

Use one type of mass \(1\). Its theory contains the auxiliary clauses of \(\widehat Q\) and the single preference clause

\(d(s,t)\leftarrow\widehat q.\)

No auxiliary clause mentions \(d\) or \(\operatorname{dom}\). Therefore the auxiliary least model is unaffected by the preference clause and runtime clauses. Moreover, the only possible \(d\)-edge is \(s\longrightarrow t\), which is present exactly when \(\widehat q\) is derived. Since both endpoints are feasible,

\(Q\vdash q\quad\Longleftrightarrow\quad L(P)\vdash\operatorname{dom}(s,t) \quad\Longleftrightarrow\quad \text{supporting mass}>1/2.\)

The translation is polynomial: \(b\) is logarithmic in \(k\); each argument is replaced by \(b\) explicit coordinates; and the validity facts and guards have polynomial total size.

All generated clauses are positive and function-free. The auxiliary predicates have explicitly written, possibly large arities, which the task permits. This verifies the hypotheses needed for the reduction and proves \(\mathrm{EXPTIME}\)-hardness, even with \(m=\tau=1\).

3. Upper bound and running time.

For each type separately, expand each outcome variable into \(m\) Boolean-coordinate variables. This is a finite relational representation because tuple notation introduces no nested function terms.

Let \(v\) be the largest number of distinct Boolean variables in an expanded rule, including runtime rules, and let \(a\) be the largest expanded predicate arity. Explicit input syntax implies

\(v=O(mL),\qquad a=O(mL).\)

There are \(O(L)\) predicate symbols and rules. Hence there are at most \(O(L2^a)\) ground atoms and \(O(L2^v)\) ground rule instances, apart from polynomial factors for their written lengths.

Enumerate all \(2^m\) outcomes and evaluate the feasible-set formula to produce the \(\operatorname{outcome}\) facts. Ground each rule over the Boolean domain, evaluate its propositional constraint, and discard ground instances whose constraints are false.

Compute the least model by repeatedly applying ground rules whose body atoms have already been derived. Positivity makes this process monotone. Each nonterminal round adds a new atom, so the number of rounds is bounded by the number of ground atoms. The final fixed point is the least model: induction shows that every added atom belongs to every model, and termination leaves a set closed under every rule.

Even this elementary implementation takes

\(\operatorname{poly}(m,L)\,2^{O(mL)}\)

time per type. Processing the explicitly listed support therefore takes

\(T(m,\tau,L)\leq \tau\,\operatorname{poly}(m,L)\,2^{O(mL)}+\operatorname{poly}(L).\)

The final polynomial term suffices for exact mass arithmetic. Specifically, write each mass as \(\mu_i=a_i/b_i\), with positive integer denominator, and let \(I\) be the set of supporting types. Set

\(B=\prod_{i=1}^{\tau}b_i,\qquad A=\sum_{i\in I}a_i(B/b_i).\)

Then the answer is positive exactly when \(2A>B\). The total denominator bit length is at most \(L\), so \(B\), the summands, and \(A\) have polynomial bit length. Exact computation and comparison consequently take polynomial time in \(L\), and equality correctly produces a negative answer.

Since the explicit query tuples give \(m\leq L\), and the explicit support gives \(\tau\leq L\), this running time is \(2^{\operatorname{poly}(L)}\). The problem belongs to \(\mathrm{EXPTIME}\).

4. Final classification.

The lower and upper bounds establish \(\mathrm{EXPTIME}\)-completeness for the exact explicit-support problem. In particular, it is \(\mathrm{NP}\)-hard. The deterministic time hierarchy gives \(\mathrm P\subsetneq\mathrm{EXPTIME}\), so there is no polynomial-time algorithm in the total input length for the unrestricted problem.
