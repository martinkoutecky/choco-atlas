The continuous mirror question, as graded

Given a finite set of terminal types \(T\), rational type masses \(\mu_t\), positive fairness weights \(w_t\), and a succinct source model providing the fractional coalition-cost function \(b_\mu(y)\) for \(0\le y_t\le\mu_t\), find the unique \(q\) minimizing \(\sum_{t\in T}\mu_t q_t^2/w_t\), subject to \(\sum_t\mu_t q_t=b_\mu(\mu)\) and \(\sum_t y_tq_t\le b_\mu(y)\) for every fractional coalition mass vector \(y\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge2\) terminal types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Each type has a positive binary-rational fairness weight \(w_t\).
The succinct source-cost model is a circuit with \(m\) gates, using rational constants, addition, rational scalar multiplication, minimum, and maximum, that evaluates \(b_\mu:[0,\mu]\to\mathbb R_{\ge0}\). Let \(L\) be the total binary input length.
Promise that \(b_\mu(0)=0\), that \(b_\mu\) is coordinatewise nondecreasing, and that \(b_\mu(x)+b_\mu(y)\ge b_\mu(x\wedge y)+b_\mu(x\vee y)\), where meet and join are coordinatewise minimum and maximum.
A type receives a uniform nonnegative rate density \(q_t\). Define \(C_\mu=\{q\in\mathbb R_{\ge0}^{T}:\sum_t\mu_tq_t=b_\mu(\mu),\ \sum_t y_tq_t\le b_\mu(y)\text{ for every real }y\in[0,\mu]\}\), and promise \(C_\mu\ne\varnothing\). There is no packet-splitting grid restriction.

Is computing the unique minimizer of \(\sum_t\mu_tq_t^2/w_t\) over \(C_\mu\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finitely many terminals, steepest descent reaches a weighted quadratic minimizer on the prescribed packet-splitting grid; its runtime bound depends on the grid denominator and core diameter ([Ding et al.](https://arxiv.org/html/1902.03706v1)).
Weighted quadratic minimization over finite-set submodular base polyhedra also has polynomial-time algorithms ([Nagano–Kawahara](https://arxiv.org/pdf/1309.6850)); these results do not address the fractional-coalition circuit model specified here.

Modeling choices made when packaging the task

  • Normalized total mass to one because the continuous society is a distribution; retained at least two represented terminal types to mirror the discrete nondegeneracy condition.
  • Required fairness weights to be binary rational so that the computational input is finite.
  • The paper gives no fractional-coalition source model. Interpreted the supplied cost function through a rational piecewise-linear circuit, with normalization, monotonicity, and lattice submodularity carrying over the discrete cost function's rank properties.
  • Promised a nonempty core, preserving the feasibility guaranteed in the discrete model.
  • Interpreted q as a nonnegative rate density uniform within each type, and allowed every real fractional coalition.
  • Removed the discrete packet-splitting grid restriction, as required by the stated continuous optimization question.
  • Defined m as circuit gate count and L as total binary input length; requested exact minimization.

Result

Computing the unique minimizer is \(\mathrm{NP}\text{-hard}\), even when \(\tau=2\), both masses are \(1/2\), and both fairness weights are \(1\).

We give a polynomial-time reduction from Boolean satisfiability in conjunctive normal form, using its standard \(\mathrm{NP}\)-completeness theorem. [Cook’s paper](https://www.cs.toronto.edu/~sacook/homepage/1971.pdf). Every constructed instance satisfies all the promises. Its minimizer is \((4,2)\) if the formula is satisfiable and \((3,3)\) otherwise.

1. Encoding assignments in one real variable

Let \(\varphi\) be a conjunctive-normal-form formula with variables indexed by \(1,\ldots,n\), where \(n\ge1\), and with at least one clause, every clause nonempty. These restrictions preserve \(\mathrm{NP}\)-hardness.

On \([0,1]\), define
\[ \]
\(F(u)=\min\{3u,\,3-3u,\,1\}\), and
\(\beta(u)=\max\{0,\min\{1,\,3u-1\}\}\).

Both functions take values in \([0,1]\). For each variable, define
\(\beta_i(z)=\beta(F^{i-1}(z))\), where \(F^0(z)=z\).

For a positive literal indexed by \(i\), its real-valued evaluation is \(\beta_i(z)\); for a negative literal, it is \(1-\beta_i(z)\). Write this evaluation as \(\ell(z)\). Define
\[ \]
\(V_\varphi(z)=\min_{C\text{ a clause of }\varphi}\ \max_{\ell\in C}\ell(z)\).

Thus \(V_\varphi(z)\in[0,1]\).

Every Boolean assignment is represented at an interior point. Given an assignment \(\alpha\in\{0,1\}^n\), set \(u_{n+1}=1/2\). Recursively, for \(i=n,\ldots,1\), set \(u_i=u_{i+1}/3\) if \(\alpha_i=0\), and \(u_i=1-u_{i+1}/3\) if \(\alpha_i=1\).

Inductively, every \(u_i\) belongs to \((0,1)\). In the first case, \(u_i\in(0,1/3)\), so \(F(u_i)=u_{i+1}\) and \(\beta(u_i)=0\). In the second case, \(u_i\in(2/3,1)\), so \(F(u_i)=u_{i+1}\) and \(\beta(u_i)=1\).

Consequently, taking \(z=u_1\) gives \(\beta_i(z)=\alpha_i\) for every \(i\). If \(\alpha\) satisfies \(\varphi\), then \(V_\varphi(z)=1\).

Unsatisfiable formulas satisfy \(V_\varphi(z)\le1/2\) everywhere. Fix any \(z\). Round the real evaluations to a Boolean assignment by setting \(\alpha_i=1\) precisely when \(\beta_i(z)>1/2\). If \(\varphi\) is unsatisfiable, some clause is false under this assignment. Every positive literal in that clause has evaluation at most \(1/2\), and every negative literal has evaluation strictly below \(1/2\). The clause maximum is therefore at most \(1/2\), proving the assertion.

2. A monotone circuit that detects satisfiability

Define
\[ \]
\(H(z)=4^{-n}\min\{z,\,1-z,\,\max\{V_\varphi(z)-1/2,\,0\}\}\),
and \(g(z)=z+H(z)\).

All quantities inside the outer minimum defining \(H\) are nonnegative. Hence \(H\ge0\), and \(H(0)=H(1)=0\).

The preceding encoding proves:

  • If \(\varphi\) is unsatisfiable, then \(H\equiv0\), so \(g(z)=z\) everywhere.
  • If \(\varphi\) is satisfiable, some interior \(z\) has \(V_\varphi(z)=1\). At that point, \(H(z)>0\), so \(g(z)>z\).

We also need monotonicity and a Lipschitz bound.

Both \(F\) and \(\beta\) are \(3\)-Lipschitz: they are continuous piecewise-affine functions whose slopes have absolute value at most \(3\). Thus \(\beta_i\) is \(3^i\)-Lipschitz, and every literal evaluation is \(3^n\)-Lipschitz.

Finite minima and maxima of functions with a common Lipschitz bound retain that bound. Indeed, if every function changes by at most \(K|z-z'|\), applying the same inequality to their minimum or maximum gives the claim. Therefore \(V_\varphi\), and then the unscaled minimum defining \(H\), are \(3^n\)-Lipschitz.

It follows that \(H\) is \(\rho\)-Lipschitz, where \(\rho=(3/4)^n<1\). For \(z'\ge z\),
\[ \]
\((1-\rho)(z'-z)\le g(z')-g(z)\le(1+\rho)(z'-z)\).

Thus \(g\) is nondecreasing and \(2\)-Lipschitz. Since \(g(0)=0\) and \(g(1)=1\), it maps \([0,1]\) into \([0,1]\).

3. Constructing the society and verifying the promises

Take \(T=\{1,2\}\), with \(\mu_1=\mu_2=1/2\) and \(w_1=w_2=1\).

For \(y\in[0,\mu]\), write \(z=2y_1\) and \(r=2y_2\). Define
\[ \]
\(b_\mu(y)=B(z,r)\), where \(B(z,r)=2z+2r-\min\{g(z),r\}\).

This uses only rational constants, addition, rational scalar multiplication, minimum, and maximum.

Normalization, monotonicity, and nonnegativity

We have \(B(0,0)=0\) and \(B(1,1)=3\).

For \(z'\ge z\), monotonicity and the Lipschitz bound for \(g\) give
\[ \]
\(0\le\min\{g(z'),r\}-\min\{g(z),r\}\le2(z'-z)\).

Consequently, \(B(z',r)-B(z,r)\ge0\). Likewise, for \(r'\ge r\), the corresponding minimum increases by at most \(r'-r\), so
\[ \]
\(B(z,r')-B(z,r)\ge r'-r\ge0\).

Thus \(B\), and therefore \(b_\mu\), is coordinatewise nondecreasing. Its nonnegativity follows from this monotonicity and its value zero at the origin.

Lattice submodularity

Let \(K(z,r)=\min\{g(z),r\}\). We prove that \(K\) is supermodular.

Fix \(r\le r'\). The function
\[ \]
\(D(u)=\min\{u,r'\}-\min\{u,r\}\)

equals \(0\) for \(u\le r\), equals \(u-r\) for \(r\le u\le r'\), and equals \(r'-r\) for \(u\ge r'\). Hence it is nondecreasing. Since \(g\) is nondecreasing, for \(z\le z'\) this yields
\[ \]
\(K(z',r')-K(z',r)\ge K(z,r')-K(z,r)\).

Rearranging gives the supermodular rectangle inequality. For arbitrary two points in a two-dimensional box, comparable points give equality in the lattice inequality; incomparable points give exactly this rectangle inequality. Therefore \(K\) is lattice-supermodular.

The function \(2z+2r\) is modular. Subtracting \(K\) proves that \(B\) is lattice-submodular. Positive coordinate scaling preserves meet and join, so \(b_\mu\) satisfies the required lattice-submodularity promise.

Nonempty core

The rate vector \((4,2)\) is feasible in every constructed instance. Its total cost is \(3=b_\mu(\mu)\), and for every coalition,
\[ \]
\(4y_1+2y_2=2z+r\le2z+2r-\min\{g(z),r\}=b_\mu(y)\),

because \(\min\{g(z),r\}\le r\). Thus the nonemptiness promise always holds.

4. Exact characterization of the core

The full-coalition equality implies \(q_1+q_2=6\). The two axis coalitions give \(q_1\le4\) and \(q_2\le4\), since \(B(1,0)=B(0,1)=2\).

Hence every feasible vector has the form
\[ \]
\(q(a)=(4-2a,\,2+2a)\), with \(0\le a\le1\).

Substituting this vector into the fractional-coalition inequality shows that feasibility is equivalent to
\[ \]
\(az+(1-a)r\ge\min\{g(z),r\}\quad\text{for every }z,r\in[0,1]\).

Unsatisfiable case. Here \(g(z)=z\). Every convex combination \(az+(1-a)r\) is at least \(\min\{z,r\}\). Therefore every \(a\in[0,1]\) is feasible, and
\[ \]
\(C_\mu=\{(4-2a,\,2+2a):0\le a\le1\}\).

Satisfiable case. Choose \(z\) with \(g(z)>z\), and set \(r=g(z)\). This is an allowed coalition coordinate because \(g(z)\in[0,1]\). Feasibility requires
\[ \]
\(az+(1-a)g(z)\ge g(z)\),

or \(a(z-g(z))\ge0\). Since \(a\ge0\) and \(z-g(z)<0\), this forces \(a=0\). The vector corresponding to \(a=0\) was already proved feasible. Therefore \(C_\mu=\{(4,2)\}\).

5. Minimizers and reduction size

The prescribed objective is \((q_1^2+q_2^2)/2\). On the segment above, it equals
\[ \]
\(\bigl((4-2a)^2+(2+2a)^2\bigr)/2=9+4(a-1/2)^2\).

Thus the unique minimizer is \((3,3)\) in the unsatisfiable case and \((4,2)\) in the satisfiable case. The respective minimum objective values are \(9\) and \(10\).

If the formula has \(s\) literal occurrences, the circuit uses \(O(n+s)\) gates: the iterates of \(F\) are computed once and shared. The only constant whose encoding length grows with \(n\) is \(4^{-n}=2^{-2n}\), which has \(O(n)\) binary encoding length. Consequently, the construction has polynomial total input length and is computable in polynomial time.

An algorithm computing the minimizer would decide satisfiability by testing whether its first coordinate exceeds \(7/2\). This proves the claimed \(\mathrm{NP}\)-hardness. In particular, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

6. Why finite-set algorithms do not resolve this model

Every instance in this reduction has the same four corner values: \(0,2,2,3\). Retaining only whole-type coalitions therefore gives the same segment in both cases. Fractional coalitions can shrink that segment to a singleton.

This explains why algorithms for [finite-set submodular base polyhedra](https://arxiv.org/pdf/1309.6850) do not directly solve the stated circuit model. Likewise, the grid-dependent bound in [Ding et al.](https://arxiv.org/html/1902.03706v1) concerns a prescribed packet-splitting grid; the reduction above uses constraints over every real fractional coalition.
