Theorem 5.1 — class: algorithmic

The continuous mirror question, as graded

Given a rational distribution μ over recipient types \(t\), additive values \(v_{tj}\) for indivisible good classes \(j\), and per-recipient supplies \(b_j\) with \(\sum_j b_j \geq 1\), choose assignment masses \(x_{tj} \geq 0\) satisfying \(\sum_j x_{tj}=μ_t\) and \(\sum_t x_{tj}\leq b_j\). What is the maximum \(\lambda\) such that \(x_{tj}>0\) only when \(v_{tj}\geq\lambda\), and what assignment attains it?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq1\) recipient types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). The parameter \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) good classes, with binary-rational supplies \(b_j\geq0\) per recipient and \(\sum_j b_j\geq1\). Each individual receives exactly one indivisible good; mass of a type may be split among classes.
Values \(v_{tj}\geq0\) are binary rationals and additive, normalized by \(\sum_j b_jv_{tj}=1\) for each type. This fixes the value of the entire inventory per unit of recipient mass.
An assignment consists of masses \(x_{tj}\geq0\) satisfying \(\sum_jx_{tj}=\mu_t\) and \(\sum_tx_{tj}\leq b_j\); surplus supply may remain unused.
Its bottleneck value is \(\min\{v_{tj}:x_{tj}>0\}\). Let \(L\) be the total binary encoding length of the input.

Is computing the maximum bottleneck value \(\lambda^*\) and an assignment attaining it polynomial-time solvable in \(m,\tau,L\), or is the threshold decision problem, given a binary-rational \(q\), asking whether \(\lambda^*\geq q\), NP-hard?

For finite agents, assigning one distinct good to each agent to maximize the minimum received value is polynomial-time solvable; if goods are insufficient, zero-valued dummy goods are added.
No result for exactly the mass-assignment problem above is asserted here.

Modeling choices made when packaging the task

  • Made the distribution a probability distribution with positive masses on its listed support.
  • Specified binary-rational nonnegative values and supplies, and defined L as the total input encoding length.
  • Extended inventory normalization to per-recipient supply units by requiring the supply-weighted value sum to equal one for each type.
  • Interpreted splitting as assigning different individuals of the same type to different indivisible good classes; the objective concerns received values, not type-average utility.
  • Retained the stated sufficient-supply restriction and allowed surplus supply to remain unused; zero-valued dummy supply is therefore unnecessary.
  • Allowed any optimal assignment when ties occur and made the threshold decision formulation explicit.

Conclusion

Computing both the maximum bottleneck value \(\lambda^*\) and an assignment attaining it is polynomial-time solvable in \(m,\tau,L\). For a fixed threshold, feasibility is a capacitated bipartite maximum-flow problem. Exact optimization requires searching only the finitely many input values.

1. Threshold feasibility as maximum flow

Fix a rational threshold \(q\). An assignment has bottleneck at least \(q\) exactly when it uses only pairs in
\(A_q=\{(t,j):v_{tj}\geq q\}\).

Construct a directed network with source \(s\), one vertex \(T_t\) for each recipient type, one vertex \(G_j\) for each good class, and sink \(z\). Its arcs and capacities are:

  • \(s\to T_t\), of capacity \(\mu_t\);
  • \(T_t\to G_j\), of capacity \(1\), for every \((t,j)\in A_q\);
  • \(G_j\to z\), of capacity \(b_j\).

The capacity \(1\) on a type-to-class arc imposes no additional restriction: every assignment satisfies \(x_{tj}\leq\mu_t\leq1\).

Claim. An assignment with bottleneck at least \(q\) exists if and only if this network admits a flow of value \(1\).

Proof. Given such an assignment, send \(\mu_t\) along \(s\to T_t\), send \(x_{tj}\) along \(T_t\to G_j\), and send \(\sum_t x_{tj}\) along \(G_j\to z\). Every positive \(x_{tj}\) corresponds to an allowed arc. The assignment constraints give capacity feasibility and flow conservation. The resulting flow has value \(\sum_t\mu_t=1\).

Conversely, suppose a feasible flow has value \(1\). The capacities of all arcs leaving \(s\) sum to \(1\), so every such arc is saturated. Set \(x_{tj}\) equal to the flow on \(T_t\to G_j\), and set \(x_{tj}=0\) when that arc is absent. Conservation at \(T_t\) gives \(\sum_jx_{tj}=\mu_t\). Conservation and the outgoing capacity at \(G_j\) give \(\sum_tx_{tj}\leq b_j\). Every positive entry satisfies \(v_{tj}\geq q\), as required. \(\square\)

Thus the threshold answer is affirmative precisely when the maximum flow value is \(1\). Unused supply is permitted because the good-to-sink arcs need not be saturated.

2. Exact arithmetic and polynomial complexity

We verify that rational capacities cause no encoding difficulty.

Write the masses and supplies as fractions with positive integer denominators, and let \(D\) be the product of these denominators. Multiplying all network capacities by \(D\) gives nonnegative integer capacities:
\(D\mu_t\), \(D\), and \(Db_j\).

The binary length of \(D\) is at most one plus the sum of the binary lengths of the denominators, hence is \(O(L)\). Each scaled capacity also has binary length \(O(L)\). Computing these integers therefore takes polynomial time.

The network has \(V=m+\tau+2\) vertices and at most \(E=m\tau+m+\tau\) arcs. We use the standard Edmonds–Karp maximum-flow theorem: for a finite directed network with nonnegative integer capacities, the algorithm computes a maximum flow using \(O(VE^2)\) arithmetic and comparison operations. All its hypotheses hold here. During its execution, flow and residual-capacity integers have \(O(L)\) bits, so the bit complexity is polynomial in \(m,\tau,L\).

The threshold is feasible exactly when the scaled maximum flow has value \(D\). Dividing its type-to-class flows by \(D\) yields an exact rational assignment. Each entry has a representation of \(O(L)\) bits, giving a polynomial-size output.

Determining which arcs to include requires only exact rational comparisons \(v_{tj}\geq q\), performed by cross multiplication. Consequently, threshold decision is polynomial in \(m,\tau,L\) and the encoding length of \(q\).

3. A feasible assignment always exists

Let \(B=\sum_jb_j\). By hypothesis, \(B\geq1\). Define \(x_{tj}=\mu_tb_j/B\). Then
\(\sum_jx_{tj}=\mu_t\), while \(\sum_tx_{tj}=b_j/B\leq b_j\).

Thus the unrestricted assignment problem is feasible. Since all values are nonnegative, threshold \(0\) is feasible as well.

The normalization \(\sum_jb_jv_{tj}=1\) is consistent with the algorithm but is not needed for this feasibility argument or for the flow reduction.

4. Computing and attaining the optimum

Let the distinct input values, sorted increasingly, be \(a_1<a_2<\cdots<a_K\), where \(1\leq K\leq m\tau\).

Every feasible assignment has at least one positive entry because its total assigned mass is \(1\). Its bottleneck is the minimum of the values on its nonempty, finite support, and therefore belongs to \(\{a_1,\ldots,a_K\}\).

Threshold \(a_1\) is feasible: it allows every type-to-class pair, and Section 3 supplies a feasible assignment. Moreover, threshold feasibility is monotone: if a threshold is feasible, every smaller threshold is feasible.

Sort the candidate values using exact rational comparisons, then binary-search for the largest feasible candidate \(a_r\). This requires \(O(\log(K+1))\) maximum-flow computations. Recover an assignment from a flow of value \(D\) at threshold \(a_r\).

Its bottleneck is at least \(a_r\). If its bottleneck were strictly larger, that bottleneck would be a larger input value and a feasible threshold, contradicting the choice of \(a_r\). Hence the recovered assignment has bottleneck exactly \(a_r\).

Every other feasible assignment also has its bottleneck among the candidate values, and that candidate must pass the threshold test. Its bottleneck is therefore at most \(a_r\). This proves \(\lambda^*=a_r\) and proves attainment.

The sorting, flow computations, and output construction all have polynomial bit complexity. The stated mass-assignment problem is therefore completely resolved.

Step-by-step verification

1. Threshold characterization

The equivalence between bottleneck at least \(q\) and using only pairs with \(v_{tj}\geq q\) is exact. Every feasible assignment has nonempty support because its total assigned mass is \(1\), so its bottleneck is well-defined.

This characterization also covers negative thresholds and thresholds exceeding every input value.

2. Flow reduction

All capacities correctly represent the assignment constraints:

  • The source-to-type capacities impose the prescribed masses.
  • The type-to-class capacity \(1\) adds no restriction, since \(x_{tj}\leq\mu_t\leq1\).
  • The class-to-sink capacities impose the supply upper bounds and permit unused inventory.

Both directions of the claimed equivalence are justified. In particular, a flow of value \(1\) saturates every source-to-type arc because their capacities sum to \(1\). Conservation therefore yields the required equalities \(\sum_jx_{tj}=\mu_t\), rather than merely upper bounds.

Classes with zero supply cause no difficulty: their outgoing capacities force zero assigned mass.

3. Exact arithmetic and complexity

The denominator-product scaling is valid. Its numerical magnitude can be large, but its binary encoding length is \(O(L)\). The scaled capacities likewise have \(O(L)\) bits, and their construction requires polynomial-time integer arithmetic.

The stated Edmonds–Karp theorem applies to this finite network with nonnegative integer capacities. Its operation bound is independent of capacity magnitude. Flow and residual-capacity arithmetic uses integers of polynomially bounded bit length, so the stated polynomial bit-complexity conclusion follows.

Dividing the resulting integral flows by \(D\) gives exact rational assignment entries with polynomial encoding length. Thus the proof establishes a polynomial-size output as well as polynomial-time decision.

The threshold-input accounting is also correct: comparisons with \(q\) take polynomial time in \(L\) and the encoding length of \(q\).

4. Unrestricted feasibility

The proposed assignment \(x_{tj}=\mu_tb_j/B\) is well-defined because \(B\geq1\). Both computations are correct:

\[ \sum_jx_{tj}=\mu_t,\qquad \sum_tx_{tj}=\frac{b_j}{B}\leq b_j. \]

This establishes unrestricted feasibility and feasibility at threshold \(0\).

The normalization of values is unnecessary for the reduction; proving the result under weaker assumptions is consistent with the task.

5. Candidate values and optimization

Every feasible assignment has finite, nonempty support, so its bottleneck equals an input value. This remains true for assignments whose masses are arbitrary real numbers.

The least candidate \(a_1\) permits every pair and is feasible by the preceding construction. Threshold feasibility is monotone, so binary search correctly identifies the largest feasible candidate. The stated bound of \(O(\log(K+1))\) flow computations also covers \(K=1\).

Sorting and comparing the rational candidates have polynomial bit complexity.

6. Optimality and attainment

The recovered assignment has bottleneck at least \(a_r\). If its bottleneck were larger, that bottleneck would itself be a larger feasible candidate, contradicting maximality of \(a_r\).

Every other feasible assignment likewise has a candidate bottleneck that passes the threshold test, hence cannot exceed \(a_r\). These arguments establish both optimality and attainment without assuming beforehand that a continuous maximum exists.
