The continuous mirror question, as graded

Given a finite set \(T\) of complete ADCOP types with rational masses \(\mu_t>0\), \(\sum_{t\in T}\mu_t=1\), finite domains \(D_t\), nonnegative rational interaction intensities \(\rho_{tu}\), asymmetric rational costs \(c_{t\leftarrow u}(a,b)\), and a rational threshold \(B\), decide whether \(\min_q F(q)\le B\), where \(q_{ta}\ge0\), \(\sum_{a\in D_t}q_{ta}=1\), and \(F(q)=\sum_{t,u\in T}\mu_t\mu_u\rho_{tu}\sum_{a\in D_t,\,b\in D_u}q_{ta}q_{ub}c_{t\leftarrow u}(a,b)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), satisfying \(\sum_t\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
Each type controls one decision with an explicitly listed nonempty finite domain \(D_t\). The input supplies nonnegative binary rational intensities \(\rho_{tu}\), explicit cost tables \(c_{t\leftarrow u}:D_t\times D_u\to\mathbb Q_{\ge0}\), and a threshold \(B\in\mathbb Q\). Neither intensities nor costs must be symmetric.
A feasible allocation has real fractions \(q_{ta}\ge0\) with \(\sum_{a\in D_t}q_{ta}=1\); the mass assigned action \(a\) is \(\mu_tq_{ta}\). Interacting actions are independently drawn from these fractions, including between distinct individuals of the same type.
Define \(F(q)=\sum_{t,u\in T}\mu_t\mu_u\rho_{tu}\sum_{a\in D_t,\,b\in D_u}q_{ta}q_{ub}c_{t\leftarrow u}(a,b)\). The ordered sum includes \(t=u\) and aggregates both directed costs without a factor of one half. All input tables are available to the algorithm.
Let \(m=\max_t|D_t|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is deciding whether \(\min_q F(q)\le B\) solvable in polynomial time, or is it NP-hard?

For finite ADCOPs, AsymDPOP has utility-message size exponential in the counts of separator ancestors (ancestors adjacent to the current subtree) and interface descendants (descendants adjacent to those ancestors). [AsymDPOP](https://www.ijcai.org/proceedings/2019/0032.pdf)
Discrete ADCOP optimization is NP-hard. [Scheduling operations in a large hospital by multiple agents](https://tzin.bgu.ac.il/~zivanr/files/operationsEAAI.pdf) No classification of exactly the mass-allocation problem above was located in the literature search.

Modeling choices made when packaging the task

  • Restricted the unspecified signs of rational costs to nonnegative values, as required by the discrete ADCOP definition.
  • Required nonempty finite domains so that every type has a feasible decision.
  • Made allocation fractions real and cost tables explicit; interpreted complete input as available centrally, without an additional privacy constraint.
  • Retained same-type interaction terms as interactions between distinct individuals of the same type with independently drawn actions.
  • Defined the otherwise unspecified size parameter m as the maximum domain size and L as the total binary input length.

Classification

The decision problem is \(\mathrm{NP}\)-complete, under polynomial-time many-one reductions. Thus it has a polynomial-time algorithm exactly if \(\mathrm{P}=\mathrm{NP}\).

Hardness holds even under either of these restrictions:

  • \(m=2\), equal masses, and no self-interactions.
  • \(\tau=1\), with a symmetric cost table whose entries belong to \(\{0,1\}\).

Below, all running times are bit-complexity bounds.

1. Without self-interactions, fractions do not improve the optimum

Call an allocation pure if each type assigns fraction \(1\) to one action. For a pure action vector \(a=(a_t)_{t\in T}\), write its cost as \(F(a)\).

Lemma. If \(\rho_{tt}=0\) for every \(t\), then

\(\displaystyle \min_q F(q)=\min_{a\in\prod_{t\in T}D_t}F(a).\)

Proof. Given a feasible allocation \(q\), draw one random action \(A_t\) for each type, independently across types, with probability \(\Pr(A_t=a)=q_{ta}\). For distinct types \(t,u\), independence gives

\(\displaystyle \mathbb E[c_{t\leftarrow u}(A_t,A_u)]=\sum_{a\in D_t,\ b\in D_u}q_{ta}q_{ub}c_{t\leftarrow u}(a,b).\)

Because all self-interaction terms vanish, summing this identity yields \(\mathbb E[F(A)]=F(q)\). An average of pure-allocation costs is at least their minimum. Consequently, every feasible \(q\) satisfies \(F(q)\ge\min_a F(a)\). Pure allocations are themselves feasible, proving equality. \(\square\)

The hypothesis matters: with self-interactions, the model draws two actions independently from the same type, whereas a pure action vector supplies only one action for that type.

2. Hardness with two actions per type

We reduce from weighted MAX-CUT: given a simple undirected graph \(G=(V,E)\), positive binary integer edge weights \(w_e\), and an integer threshold \(K\), decide whether some cut has weight at least \(K\). This problem is \(\mathrm{NP}\)-complete; weighted MAX-CUT and CLIQUE are among the problems treated in [Karp’s original paper](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Let \(n=|V|\), taking the nonempty-graph restriction, which retains hardness. Construct the society as follows:

  • \(T=V\), so \(\tau=n\), and \(\mu_i=1/n\) for every vertex.
  • \(D_i=\{0,1\}\), so \(m=2\).
  • Order the vertices. For each edge \(\{i,j\}\) with \(i<j\), set \(\rho_{ij}=w_{\{i,j\}}\). Set every other intensity, including every \(\rho_{ii}\), to zero.
  • Supply every cost table explicitly, with \(c_{i\leftarrow j}(a,b)=1\) when \(a=b\), and \(c_{i\leftarrow j}(a,b)=0\) otherwise.
  • Let \(W=\sum_{e\in E}w_e\) and set \(B=(W-K)/n^2\).

All masses are positive and sum to \(1\); intensities and costs are nonnegative. Each undirected edge contributes through exactly one ordered pair, so there is no factor-of-two ambiguity.

For a pure allocation \(a\), let \(\operatorname{cut}_w(a)\) denote the weight of edges whose endpoint actions differ. Then

\(\displaystyle F(a)=\frac{1}{n^2}\sum_{\{i,j\}\in E}w_{\{i,j\}}\mathbf 1_{\{a_i=a_j\}}=\frac{W-\operatorname{cut}_w(a)}{n^2}.\)

The lemma therefore gives

\(\displaystyle \min_qF(q)=\frac{W-\operatorname{MaxCut}_w(G)}{n^2}.\)

Consequently,

\(\displaystyle \min_qF(q)\le B\quad\Longleftrightarrow\quad\operatorname{MaxCut}_w(G)\ge K.\)

The construction writes only quadratically many constant-size cost tables. The masses, intensities, and threshold have polynomial encoding length, so this is a polynomial-time reduction. It proves \(\mathrm{NP}\)-hardness even when \(m=2\) and every self-interaction vanishes.

3. Hardness with a single type

This second reduction shows that fixing the support size \(\tau\) does not make the unrestricted problem polynomial-time solvable.

Given a nonempty simple graph \(G=(V,E)\), take one type \(t\), with \(\mu_t=\rho_{tt}=1\), and domain \(D_t=V\). Define

\(\displaystyle c_{t\leftarrow t}(v,w)=\begin{cases}0,&\{v,w\}\in E,\\1,&\text{otherwise}.\end{cases}\)

In particular, every diagonal entry is \(1\). For a probability vector \(q\) on \(V\), the ordered-sum convention gives

\(\displaystyle F(q)=1-2H(q),\qquad H(q)=\sum_{\{v,w\}\in E}q_vq_w.\)

Let \(\omega(G)\) be the maximum clique size. We prove directly that

\(\displaystyle \min_qF(q)=\frac1{\omega(G)}.\)

The simplex is compact and \(H\) is continuous, so a maximizer exists. Choose a maximizer with the smallest possible number of positive coordinates.

Suppose two positive coordinates \(q_i,q_j\) correspond to nonadjacent vertices. Holding every other coordinate fixed, define

\(\displaystyle A_i=\sum_{v:\{i,v\}\in E}q_v,\qquad A_j=\sum_{v:\{j,v\}\in E}q_v.\)

Neither sum depends on \(q_i\) or \(q_j\), because the graph has no loops and \(i,j\) are nonadjacent. The terms involving these coordinates are exactly \(q_iA_i+q_jA_j\).

If \(A_i\ge A_j\), replace \((q_i,q_j)\) by \((q_i+q_j,0)\). This changes \(H\) by \(q_j(A_i-A_j)\ge0\). If \(A_j>A_i\), merge both coordinates into \(j\) instead. In either case the resulting vector must remain a maximizer, because the original value was globally maximal, but its positive support is smaller. This is a contradiction.

Thus the chosen maximizer is supported on a clique of size \(r\le\omega(G)\). On that support,

\(\displaystyle H(q)=\frac12\left(1-\sum_vq_v^2\right).\)

Cauchy–Schwarz gives \(\sum_vq_v^2\ge1/r\), hence

\(\displaystyle H(q)\le\frac12\left(1-\frac1r\right)\le\frac12\left(1-\frac1{\omega(G)}\right).\)

The uniform distribution on a maximum clique attains the last bound. The asserted formula for \(\min_qF(q)\) follows.

For a CLIQUE instance with threshold \(1\le k\le|V|\), set \(B=1/k\). Then

\(\displaystyle \min_qF(q)\le B\quad\Longleftrightarrow\quad\omega(G)\ge k.\)

The construction has polynomial size. Hence the problem remains \(\mathrm{NP}\)-hard when \(\tau=1\), even with symmetric costs in \(\{0,1\}\).

4. Polynomial-length rational certificates

Real-valued feasibility does not by itself establish membership in \(\mathrm{NP}\). We now prove the needed certificate bound.

Let \(N=\sum_t|D_t|\le m\tau\), and index coordinates by pairs \(i=(t,a)\). Define the rational matrix

\(\displaystyle Q_{(t,a),(u,b)}=\mu_t\mu_u\rho_{tu}c_{t\leftarrow u}(a,b),\qquad M=\frac{Q+Q^{\mathsf T}}2.\)

Then \(M\) is symmetric and \(F(q)=q^{\mathsf T}Mq\). This symmetrization preserves the given ordered sum exactly.

The feasible product of simplexes is nonempty and compact, so let \(q^*\) be a global minimizer. Define its positive support in each type by \(S_t=\{a:q^*_{ta}>0\}\).

For any \(a,b\in S_t\), sufficiently small transfers of mass between these coordinates are feasible in either direction. Differentiating along that direction at a minimum gives

\(\displaystyle (Mq^*)_{ta}=(Mq^*)_{tb}.\)

Choose one reference action \(a_t\in S_t\) for each type. Consider the following rational linear system with nonnegativity constraints:

\(\displaystyle z_{ta}=0\ \text{for }a\notin S_t,\qquad z_{ta}\ge0,\qquad \sum_{a\in S_t}z_{ta}=1,\)

\(\displaystyle (Mz)_{ta}=(Mz)_{t a_t}\quad\text{for every }a\in S_t.\)

Its feasible set is nonempty because it contains \(q^*\).

Every feasible point of this system has the same objective value. To see this, let \(x,y\) be feasible and put \(h=x-y\). For every type, \(\sum_a h_{ta}=0\); moreover, \(h\) vanishes outside the selected supports. Both \(Mx\) and \(My\) are constant within each selected type support. Symmetry of \(M\) therefore gives

\(\displaystyle F(x)-F(y)=h^{\mathsf T}M(x+y)=0.\)

In particular, every feasible point has value \(F(q^*)\).

It remains to bound the encoding length of a rational feasible point. After deleting coordinates outside the selected supports, write the equalities as \(Cz=b\), with \(z\ge0\). Choose a feasible point \(z\) having the fewest positive coordinates.

The columns of \(C\) indexed by those positive coordinates are linearly independent. Otherwise, there would be a nonzero vector \(h\) supported on them with \(Ch=0\). The type-sum equations imply that \(h\) has both positive and negative entries. Moving from \(z\) in direction \(h\) until the first positive coordinate becomes zero preserves feasibility and reduces the positive support, a contradiction.

Let the positive support have size \(r\). Select \(r\) rows forming an invertible square submatrix on these columns. Cramer’s rule expresses every positive coordinate of \(z\) as a ratio of determinants of rational matrices.

Here the entries of \(C\) have \(O(L)\) bits: each coefficient involves only a fixed number of products, sums, and differences of input rationals. Clearing denominators separately in each row produces integer entries with \(O(NL)\) bits. For an \(r\)-by-\(r\) integer matrix whose entries have at most \(R\) bits, the determinant has \(O(rR+r\log r)\) bits, since its absolute value is at most \(r!2^{rR}\).

Thus all coordinates of \(z\), and their total encoding, have polynomial length in \(L\), using \(N\le L\) up to the encoding convention. We have proved that a polynomial-length rational global minimizer exists.

A certificate consists simply of that rational allocation. Exact arithmetic verifies nonnegativity, type sums, and \(F(z)\le B\) in \(\operatorname{poly}(m,\tau,L)\) time. Therefore the decision problem belongs to \(\mathrm{NP}\). Together with Section 2, this proves \(\mathrm{NP}\)-completeness.

5. Exact running-time bounds

When all self-interactions vanish, Section 1 gives an exact algorithm by enumerating pure allocations. Its running time is

\(\displaystyle m^\tau\,\operatorname{poly}(m,\tau,L).\)

For the general problem, enumerate every tuple of nonempty supports \(S_t\subseteq D_t\). For each tuple, solve the rational linear feasibility problem from Section 4 and evaluate any feasible point. Rational linear-programming feasibility and witness construction take polynomial time in the system’s binary encoding length.

Every candidate is a feasible allocation, so its cost is at least the global minimum. The support tuple of a global minimizer produces a candidate with exactly the global minimum, by the constant-value argument above. Taking the least candidate value is therefore exact.

There are \(\prod_t(2^{|D_t|}-1)\) support tuples, giving the bound

\(\displaystyle \left(\prod_t(2^{|D_t|}-1)\right)\operatorname{poly}(m,\tau,L)\le2^{m\tau}\operatorname{poly}(m,\tau,L).\)

For \(m=1\), the allocation is unique and direct evaluation takes polynomial time. For fixed \(m\) and fixed \(\tau\), the general algorithm is polynomial in \(L\). Fixing either parameter alone does not suffice, by Sections 2 and 3.
