The continuous mirror question, as graded

Given \(m\) candidates on a common axis, a committee size \(k\), and \(\tau\) interval-approval types with positive rational masses \(\mu_t\) summing to \(1\), find a size-\(k\) committee \(W\) maximizing \(\sum_{t=1}^{\tau}\mu_t H_{|W\cap I_t|}\), where \(I_t\) is type \(t\)'s approved interval and \(H_q=\sum_{\ell=1}^{q}1/\ell\).

Packaged proof task (what the prover saw — nothing else)

Let \(C=\{c_1,\ldots,c_m\}\), with \(m\geq 1\), have the supplied axis \(c_1\triangleleft\cdots\triangleleft c_m\), and let \(1\leq k\leq m\) be an integer. Each approval type is an interval \(I_t\subseteq C\); empty and full intervals are allowed.
A society is given by its support: the list of the \(\tau\) distinct types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Intervals are encoded by endpoints, with a separate empty-set marker; \(L\) is the total input bit length.
Find a committee \(W\subseteq C\) with \(|W|=k\) maximizing \(\sum_{t=1}^{\tau}\mu_t H_{|W\cap I_t|}\), where \(H_0=0\) and \(H_q=\sum_{\ell=1}^{q}\frac{1}{\ell}\) for \(1\leq q\leq k\). Any maximizing committee is acceptable.

Is this optimization problem solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,k,L\).

For an explicitly listed finite electorate with interval approvals, optimal PAV committees are computable in polynomial time; this also holds for nonnegative, non-increasing scoring vectors ([Peters, 2018](https://www.dominik-peters.de/publications/tum.pdf)). No result explicitly addressing the binary-rational support representation above was located in the search.

Modeling choices made when packaging the task

  • Specified the feasible domain as integers m >= 1 and 1 <= k <= m.
  • Defined H_0 = 0, so types approving no committee members contribute zero.
  • Allowed empty and full approval intervals, consistent with the approval-set definition permitting arbitrary subsets.
  • Specified a supplied axis, endpoint encoding, distinct support types, and total input bit length L.
  • Resolved ties by allowing any maximizing committee.

Result

The problem is polynomial-time solvable in \(m,\tau,k,L\). Binary-rational masses can be used directly as objective coefficients; expanding the society into individual voters is unnecessary.

The relevant mechanism is the total-unimodularity formulation in [Peters (2018), Section 3](https://www.dominik-peters.de/publications/tum.pdf). Below is a complete proof for the support representation, including bit complexity. Compressing interchangeable candidates gives the stronger running-time bound \((\tau k+L)^{O(1)}\), with explicit committee output.

1. Compressing the axis

For every nonempty interval, write \(I_t=\{c_{a_t},\ldots,c_{b_t}\}\). Sort the distinct cut positions
\(1,m+1\), together with all \(a_t\) and \(b_t+1\).

Consecutive cuts partition the axis into nonempty blocks \(B_1,\ldots,B_s\), where \(s\leq 2\tau+1\). Let \(d_j=|B_j|\). Every interval is a union of consecutive blocks. In particular, all candidates within one block belong to precisely the same approval types.

Define \(A_{tj}=1\) if \(B_j\subseteq I_t\), and \(A_{tj}=0\) otherwise. Empty intervals give zero rows; full intervals give all-one rows.

A committee is therefore described, for purposes of its score, by integers \(y_j=|W\cap B_j|\) satisfying
\(0\leq y_j\leq d_j\) and \(\sum_{j=1}^{s}y_j=k\).
Conversely, every such integer vector can be realized by choosing \(y_j\) candidates from each block.

2. A linear programming formulation

Introduce variables \(x_{t,\ell}\) for each type \(t\) and each \(\ell\in\{1,\ldots,k\}\). Consider the LP

\[ \begin{aligned} \text{maximize}\quad& \sum_{t=1}^{\tau}\sum_{\ell=1}^{k} \frac{\mu_t}{\ell}x_{t,\ell}\\ \text{subject to}\quad& \sum_{j=1}^{s}y_j=k,\\ & \sum_{\ell=1}^{k}x_{t,\ell} \leq \sum_{j=1}^{s}A_{tj}y_j \quad(t=1,\ldots,\tau),\\ & 0\leq y_j\leq d_j \quad(j=1,\ldots,s),\\ & 0\leq x_{t,\ell}\leq1 \quad(t=1,\ldots,\tau,\ \ell=1,\ldots,k). \end{aligned} \]

For a fixed integral vector \(y\), put \(q_t=\sum_j A_{tj}y_j\). This is an integer between \(0\) and \(k\). The best choice for type \(t\) is
\(x_{t,\ell}=1\) for \(\ell\leq q_t\), and zero otherwise, giving value \(\mu_tH_{q_t}\).

This remains optimal even among fractional choices of \(x\). Indeed, write \(q=q_t\). If \(q=0\), feasibility forces all its \(x\)-variables to zero. If \(q=k\), their upper bounds give the result. For \(1\leq q<k\), monotonicity of \(1/\ell\) gives

\[ \begin{aligned} \sum_{\ell=1}^{k}\frac{x_{t,\ell}}{\ell}-H_q &= -\sum_{\ell=1}^{q}\frac{1-x_{t,\ell}}{\ell} +\sum_{\ell=q+1}^{k}\frac{x_{t,\ell}}{\ell}\\ &\leq -\frac1q\sum_{\ell=1}^{q}(1-x_{t,\ell}) +\frac1q\sum_{\ell=q+1}^{k}x_{t,\ell}\\ &=\frac1q\left(\sum_{\ell=1}^{k}x_{t,\ell}-q\right) \leq0. \end{aligned} \]

Thus, for integral \(y\), optimizing the auxiliary variables gives exactly the required committee score.

3. Total unimodularity and integrality

A matrix is *totally unimodular* if every square submatrix has determinant in \(\{-1,0,1\}\).

First, any zero-one matrix whose ones are consecutive in each row is totally unimodular. Here is a direct proof. Take any square submatrix \(Q\). Its rows retain consecutive ones. Hence the columns of \(Q^{\mathsf T}\) have consecutive ones.

Let \(D\) have diagonal entries \(1\), subdiagonal entries \(-1\), and all other entries zero. Then \(\det D=1\). Each column of \(DQ^{\mathsf T}\) has at most one \(1\) and at most one \(-1\). Every square matrix with this property has determinant in \(\{-1,0,1\}\):

  • A zero column gives determinant zero.
  • A column with one nonzero entry permits determinant expansion and induction.
  • Otherwise every column has exactly two opposite nonzero entries, so the sum of the rows is zero and the determinant vanishes.

Consequently, \(\det Q=\det(DQ^{\mathsf T})\in\{-1,0,1\}\), proving the claim.

Now consider the LP constraints before adding variable bounds. Orient each type constraint as
\(\sum_j A_{tj}y_j-\sum_\ell x_{t,\ell}\geq0\).
The columns for \(y\) form \(A\) with an additional all-one cardinality row. Every row has consecutive ones, so this matrix is totally unimodular.

Each auxiliary column has just one nonzero entry, namely \(-1\) in its type row. Appending such columns preserves total unimodularity, by determinant expansion. Appending signed unit rows for variable bounds preserves it for the same reason. Finally, expressing the cardinality equality as two opposite inequalities also preserves total unimodularity: a square submatrix containing both opposite rows is singular; otherwise its determinant differs only by a row sign from an existing determinant.

Therefore the complete inequality matrix is totally unimodular. Its right-hand sides are integers: they consist of \(k,d_j,0,1\) and their negatives.

Every vertex of the feasible polytope is integral. To verify this, select a nonsingular square system of active constraints determining a vertex. Its determinant is \(1\) or \(-1\), so its inverse is integral by the adjugate formula. An integral right-hand side therefore gives integral coordinates.

The polytope is nonempty because \(\sum_jd_j=m\geq k\), and it is bounded by the variable bounds. Hence its linear objective attains a maximum at an integral vertex. Section 2 shows that the resulting committee maximizes precisely the requested objective.

The masses affect only the objective, so their denominators do not affect integrality.

4. Exact extraction and running time

There are \(N=s+\tau k\) variables and \(2N+\tau+2\) inequalities. A dense binary encoding of the LP has length

\[ S=O\!\left( N^2+kL+\tau k\log(k+1)+s\log(m+1) \right). \]

Here \(kL\) accounts for repeating each mass in its \(k\) objective coefficients. Multiplication of a denominator by \(\ell\) adds only \(O(\log(k+1))\) bits.

Exact rational linear programming runs in time polynomial in its encoding length. One can also extract an integral committee without assuming that a solver returns a vertex:

  • Compute the exact optimum \(F\), and restrict to the optimal face.
  • Successively minimize \(y_1,\ldots,y_s\), fixing each coordinate to its minimum before continuing.

Every resulting set is a nonempty face of the original integral polytope. Its vertices are therefore integral, so every coordinate minimum fixed in this procedure is an integer. After these \(s\) additional LPs, all block counts are integral. By Section 2, the committee realizing them has score \(F\).

These LPs retain polynomial encoding length. Explicitly, if \(\mu_t=p_t/b_t\), every integral committee score has denominator dividing
\(D=(\prod_t b_t)k!\), whose bit length is \(O(L+k\log(k+1))\).
Since \(0\leq F\leq H_k\leq k\), the exact value \(F\) also has polynomial bit length.

Let \(P\) be a polynomial bound for an exact rational LP algorithm. Including preprocessing and output, the running time is

\[ O\!\left(L+\tau\log(\tau+1)\log(m+1)\right) +(s+1)P(S) +O\!\left(k\log(m+1)\right). \]

Because \(s\leq2\tau+1\), this is \((\tau k+L)^{O(1)}\), and in particular \((m+\tau k+L)^{O(1)}\). With the supplied axis explicitly listed, it is polynomial in total input length as well. If candidates are instead represented succinctly by their indices, the stated bound remains polynomial in the requested parameters; explicitly listing a committee necessarily takes at least \(k\) output steps.

  • Otherwise every column has two opposite entries, so the rows sum to zero and the determinant vanishes.

All subsequent matrix operations are justified:

  • The cardinality row is all ones and preserves the row consecutive-ones property.
  • Each auxiliary column has one nonzero entry.
  • Bound rows are signed unit rows.
  • Duplicating the cardinality row with opposite sign creates either a singular selected submatrix or merely changes a determinant’s sign.

Converting the oriented constraints into a common inequality direction only changes row signs, which also preserves total unimodularity.

The cited mechanism agrees with the PAV formulation in [Peters (2018), Section 3](https://www.dominik-peters.de/publications/tum.pdf). The submitted proof supplies its own integrality argument, so it does not rely on extending the finite-electorate theorem without justification.
