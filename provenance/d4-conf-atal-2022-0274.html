The continuous mirror question, as graded

Given binary-rational type masses μ_t>0 summing to \(1\), target influence densities \(c_t\), and threshold η, choose nonnegative weights \(a_t\) satisfying \(∑_t μ_t a_t^2=1\) to minimize \(√{∑_t μ_t(Φ_t(μ,a,η)-c_t)^2}\), where \(Z_t\sim\mathcal{N}(0,μ_t)\) independently and \(Φ_t=(1/μ_t)ℕ[Z_t\,\operatorname{sign}(\sum_s a_s Z_s-η)]\).

Result

The problem is polynomial-time solvable, in the stronger sense that an exactly optimal weight representation \(b\in\mathbb Q_{\geq0}^{\tau}\setminus\{0\}\) can be computed in time \(\operatorname{poly}(\tau,L)\). No realizability promise is needed.

The algorithm is:

  • If some \(c_t>0\), output \(b_t=\max\{c_t,0\}\) for every \(t\).
  • Otherwise, choose \(j\) minimizing \(\mu_jc_j^2\), and output the coordinate vector \(b=e_j\).

We prove both optimality and the complexity bound.

1. The Gaussian influence formula

Fix any feasible \(a\), and set \(S=\sum_s a_sZ_s\). Independence and feasibility give

\(S\sim\mathcal N(0,1)\), since \(\operatorname{Var}(S)=\sum_s\mu_sa_s^2=1\).

For each \(t\), define \(R_t=Z_t-\mu_ta_tS\). The pair \((R_t,S)\) is jointly Gaussian, possibly degenerate, and

\(\operatorname{Cov}(R_t,S)=\operatorname{Cov}(Z_t,S)-\mu_ta_t\operatorname{Var}(S)=\mu_ta_t-\mu_ta_t=0\).

Uncorrelated jointly Gaussian variables are independent. Since \(\mathbb E[R_t]=0\), it follows that

\(\mathbb E[Z_t\operatorname{sign}(S-\eta)]=\mu_ta_t\,\mathbb E[S\operatorname{sign}(S-\eta)]\).

Let \(\varphi(s)=(2\pi)^{-1/2}\exp(-s^2/2)\). Because \(S\) has a continuous distribution, the convention at zero does not affect this expectation. Using \(\mathbb E[S]=0\) and \(\varphi'(s)=-s\varphi(s)\), we obtain

\(\mathbb E[S\operatorname{sign}(S-\eta)]=2\int_\eta^\infty s\varphi(s)\,ds=2\varphi(\eta)\).

Consequently, with the strictly positive constant \(\kappa=2\varphi(\eta)=\sqrt{2/\pi}\exp(-\eta^2/2)\), we have the exact identity

\(\Phi_t(\mu,a,\eta)=\kappa a_t\).

This holds for every feasible \(a\) and every input threshold \(\eta\).

2. Reduction to linear optimization

Write \(C^2=\sum_t\mu_tc_t^2\). Expanding the squared objective and using feasibility gives

\(D(a)^2=\sum_t\mu_t(\kappa a_t-c_t)^2=\kappa^2+C^2-2\kappa\sum_t\mu_ta_tc_t\).

Since \(\kappa>0\), minimizing \(D(a)^2\), and hence \(D(a)\), is equivalent to maximizing \(\sum_t\mu_ta_tc_t\).

Introduce \(x_t=\sqrt{\mu_t}\,a_t\) and \(d_t=\sqrt{\mu_t}\,c_t\). Because every mass is positive, this is a bijection between feasible weights and vectors satisfying \(x_t\geq0\) and \(\sum_tx_t^2=1\). The quantity to maximize becomes \(d\cdot x\).

We now solve this maximization in all cases.

3. Optimality when some target is positive

Suppose some \(c_t>0\). Define \(d_t^+=\max\{d_t,0\}\) and \(r=\|d^+\|_2>0\).

For every feasible \(x\), nonnegativity and the Cauchy–Schwarz inequality give

\(d\cdot x\leq d^+\cdot x\leq\|d^+\|_2\|x\|_2=r\).

The vector \(x^*=d^+/r\) is feasible. Its coordinates vanish wherever \(d_t\leq0\), so

\(d\cdot x^*=\sum_{t:d_t>0}d_t^2/r=r\).

Thus \(x^*\) is globally optimal. Translating back to weights gives

\(a_t^*=\max\{c_t,0\}/\bigl(\sum_s\mu_s\max\{c_s,0\}^2\bigr)^{1/2}\).

This is exactly the weight vector denoted by the rational representation \(b_t=\max\{c_t,0\}\). The representation is nonzero because at least one target is positive.

4. Optimality when all targets are nonpositive

Suppose \(c_t\leq0\) for every \(t\), so also \(d_t\leq0\). Let \(M=\max_td_t\leq0\).

For every feasible \(x\), we have \(\sum_tx_t\geq1\): indeed,

\(\bigl(\sum_tx_t\bigr)^2=\sum_tx_t^2+2\sum_{s<t}x_sx_t\geq1\).

Therefore,

\(d\cdot x\leq M\sum_tx_t\leq M\),

where the last inequality uses \(M\leq0\). If \(j\) satisfies \(d_j=M\), then \(x=e_j\) attains this bound.

Such a coordinate can be found using rational comparisons alone. Since all targets are nonpositive,

\(d_t=\sqrt{\mu_t}\,c_t=-\sqrt{\mu_tc_t^2}\).

Hence maximizing \(d_t\) is equivalent to minimizing the rational number \(\mu_tc_t^2\). Choose any minimizing index \(j\), and output \(b=e_j\). Its represented weights satisfy \(a_j=1/\sqrt{\mu_j}\) and \(a_t=0\) for \(t\neq j\), giving precisely \(x=e_j\).

This also covers zero targets and ties.

5. Bit complexity and approximation guarantee

Testing the signs of the rational targets and copying their positive parts takes polynomial time in the input length.

In the second case, each product \(\mu_tc_t^2\) has binary encoding length \(O(L)\). Exact comparisons use cross multiplication of positive denominators, involving integers of \(O(L)\) bits. Finding a minimum among \(\tau\) such products therefore takes \(\operatorname{poly}(\tau,L)\) bit operations.

The output has polynomial encoding length: it consists either of the input targets with negative entries replaced by zero, or of a coordinate vector. Neither square roots nor the transcendental constant \(\kappa\) need to be evaluated.

In both cases the represented weights attain \(D(a)=\mathrm{OPT}\). Thus they satisfy \(D(a)\leq\mathrm{OPT}+\varepsilon\) for every allowed \(\varepsilon\), with running time \(\operatorname{poly}(\tau,L)\), and therefore also \(\operatorname{poly}(\tau,L,1/\varepsilon)\).
