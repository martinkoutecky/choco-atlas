The continuous mirror question, as graded

Given finite posts \(P\), finite applicant types \(T\), rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), rational normalized capacities \(q_p\), strict preference and eligibility data assigning each eligible pair \((t,p)\) a rank \(r_t(p)\in\{1,\ldots,r\}\), and a target signature \(\rho=(\rho_1,\ldots,\rho_{r+1})\), decide whether there exist masses \(x_{t,p}\ge0\) and unmatched masses \(u_t\ge0\) such that \(\sum_p x_{t,p}+u_t=\mu_t\), \(\sum_t x_{t,p}\le q_p\), \(z_j=\sum_{t,p:r_t(p)=j}x_{t,p}\), \(z_{r+1}=\sum_tu_t\), and \(\sum_{j=1}^{\ell}z_j\ge\sum_{j=1}^{\ell}\rho_j\) for every \(\ell\); output such an allocation if one exists.

Packaged proof task (what the prover saw — nothing else)

Given finite sets of posts \(P\) and applicant types \(T\), rational type masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), rational post capacities \(q_p\), and eligible type--post pairs with strict ranks \(r_t(p)\in\{1,\ldots,r\}\), an allocation consists of \(x_{t,p}\ge0\) and \(u_t\ge0\). It is feasible when \(\sum_p x_{t,p}+u_t=\mu_t\) for every \(t\) and \(\sum_t x_{t,p}\le q_p\) for every \(p\).

Its signature is \(z=(z_1,\ldots,z_{r+1})\), where \(z_j=\sum_{t,p:r_t(p)=j}x_{t,p}\) for \(j\le r\), and \(z_{r+1}=\sum_tu_t\). For a rational target signature \( ho\), \(z\) is cumulatively at least \( ho\) if \(\sum_{j=1}^{\ell}z_j\ge\sum_{j=1}^{\ell} ho_j\) for every \(\ell\in\{1,\ldots,r+1\}\).

Is deciding whether such a feasible allocation exists, and producing one when it does, NP-hard or in \(P\)?

Result

The distributional cumulative-signature problem is polynomial-time solvable. Moreover, whenever a feasible allocation exists, an exact rational allocation can be produced in polynomial time.

Linear-program formulation

Let \(E\subseteq T\times P\) be the set of eligible type–post pairs, and define the cumulative targets

\[ R_\ell=\sum_{j=1}^{\ell}\rho_j \]

for every \(\ell\in\{1,\ldots,r+1\}\).

Use one variable \(x_{t,p}\) for every \((t,p)\in E\), and one variable \(u_t\) for every \(t\in T\). Consider the following rational linear system.

For every type \(t\),

\[ \sum_{p:(t,p)\in E}x_{t,p}+u_t=\mu_t. \]

For every post \(p\),

\[ \sum_{t:(t,p)\in E}x_{t,p}\le q_p. \]

For every \(\ell\in\{1,\ldots,r\}\),

\[ \sum_{\substack{(t,p)\in E\\r_t(p)\le\ell}}x_{t,p}\ge R_\ell. \]

Finally,

\[ x_{t,p}\ge0,\qquad u_t\ge0. \]

The cumulative constraint for \(\ell=r+1\) can be checked separately as

\[ 1\ge R_{r+1}. \]

Indeed, summing all type-mass equalities gives

\[ \sum_{(t,p)\in E}x_{t,p}+\sum_{t\in T}u_t =\sum_{t\in T}\mu_t=1. \]

Thus every feasible allocation has total signature mass exactly \(1\).

Equivalence proof

For \(\ell\le r\), the definition of the signature gives

\[ \sum_{j=1}^{\ell}z_j = \sum_{j=1}^{\ell} \sum_{\substack{(t,p)\in E\\r_t(p)=j}}x_{t,p} = \sum_{\substack{(t,p)\in E\\r_t(p)\le\ell}}x_{t,p}. \]

Consequently, the linear inequality indexed by \(\ell\) is exactly the cumulative-signature requirement

\[ \sum_{j=1}^{\ell}z_j\ge\sum_{j=1}^{\ell}\rho_j. \]

For \(\ell=r+1\),

\[ \sum_{j=1}^{r+1}z_j=1, \]

so the last cumulative condition is exactly \(1\ge R_{r+1}\).

Therefore:

  • Every allocation satisfying the displayed linear system and \(1\ge R_{r+1}\) is feasible and has signature cumulatively at least \(\rho\).
  • Conversely, every feasible allocation whose signature is cumulatively at least \(\rho\) satisfies that linear system.

Hence the original problem is precisely rational linear feasibility.

Polynomial-time complexity

The linear system has

\[ |E|+|T| \]

variables and \(O(|T|+|P|+r+|E|)\) constraints, counting nonnegativity constraints. Its coefficients are \(0\), \(1\), or \(-1\), while its right-hand sides are rational numbers obtained from the input by polynomially many rational additions.

Under the standard binary encoding of rational numbers, rational linear-program feasibility is decidable in time polynomial in the number of variables, the number of constraints, and the total coefficient bit length. The applicable theorem also returns an exact rational feasible point when one exists.

There is no output-size obstruction here. Every feasible variable satisfies

\[ 0\le x_{t,p}\le\mu_t,\qquad 0\le u_t\le\mu_t, \]

so the feasible region is bounded. If it is nonempty, it has a vertex. A vertex is determined by a nonsingular square subsystem of rational equalities. Cramer’s rule together with the determinant bit-size bound shows that its coordinates have bit length polynomial in the input length. Thus an exact rational allocation of polynomial encoding length exists and can be produced by an exact rational LP algorithm.

Because \(\rho\) explicitly contains \(r+1\) coordinates, constructing all \(r\) cumulative inequalities is polynomial in the stated input size.

Conclusion

The indivisible hardness result does not transfer: indivisibility imposes implicit integrality constraints, whereas the distributional formulation permits arbitrary splitting of each type mass and all its requirements are linear.

Thus the exact distributional feasibility-and-construction problem is in \(P\). In particular, it is not an NP-hardness analogue of the indivisible problem unless \(P=NP\).
