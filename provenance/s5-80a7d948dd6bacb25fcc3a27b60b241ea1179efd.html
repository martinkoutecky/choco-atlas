The continuous mirror question, as graded

Given a finite type set \(T\), distribution \(\mu\), rational per-capita supplies \(q_g\) of item kinds \(g\in G\), additive valuations \(v_\theta(b)=\sum_g w_{\theta,g}b_g\), and a target type \(\theta\), compute the largest \(z\) such that for every \(0\le\kappa<1\) and every removable mass distribution over integral configurations \(b\in\mathbb{Z}_{\ge0}^{G}\) of total mass \(\kappa\), supported on configurations with \(v_\theta(b)<z\), the residual supply can be assigned to mass \(1-\kappa\) using only integral configurations with value at least \(z\). In the bounded-catalogue regime, output \(z\) or a certificate allocation.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=|G|\) item kinds, binary-rational supplies \(q_g\geq0\), nonnegative binary-rational weights \(w_{t,g\!}\), and a designated type \(\theta\in T\); write \(v_\theta(b)=\sum_g w_{\theta,g}b_g\).
The bounded catalogue is explicitly listed as \(C=\prod_{g\in G}\{0,\ldots,B_g\}\), with integer bounds \(B_g\geq0\) and \(q_g\leq B_g\); put \(s=|C|\). Empty configurations are allowed.
For \(z\geq0\), a removable distribution is any real vector \(x\in\mathbb R_{\geq0}^{C}\) with \(\kappa=\sum_bx_b<1\), \(\sum_bx_bb_g\leq q_g\) for every \(g\), and \(x_b=0\) whenever \(v_\theta(b)\geq z\).
Call \(z\) residually feasible if every such \(x\), including \(x=0\), admits \(y\in\mathbb R_{\geq0}^{C}\) satisfying \(\sum_by_b=1-\kappa\), \(\sum_by_bb_g=q_g-\sum_bx_bb_g\) for every \(g\), and \(y_b=0\) whenever \(v_\theta(b)<z\).
All configurations are evaluated using \(v_\theta\), regardless of recipient type; masses may split among configurations, and all residual supply must be allocated. Define \(z^\star\) as the largest residually feasible threshold.

Is exact computation of \(z^\star\) polynomial-time in \(m,\tau,s,L\), where \(L\) is the total binary input length, or is it NP-hard?

For finite agents with additive valuations, computing RMMS and finding an RMMS-feasible partition are weakly NP-hard, already for two agents, where RMMS equals MMS. [Source](https://arxiv.org/html/2602.11732v2#S3.SS2)
No result settling this exact continuous bounded-catalogue problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized society mass to one and required supplies and additive weights to be nonnegative binary rationals.
  • Interpreted the undefined bounded-catalogue regime as an explicitly enumerated complete box of integral configurations with supplied integer coordinate bounds; required each per-capita supply to lie within its bound.
  • Defined removability by coordinatewise supply feasibility, the continuous counterpart of disjoint removed bundles.
  • Required exact exhaustion of residual supply, matching complete partitions, and included empty configurations and zero removed mass.
  • Allowed arbitrary real configuration masses and splitting of each type's mass; evaluated every configuration using the designated type's valuation, as residual self-feasibility does.
  • Selected exact threshold computation as the target; an allocation for a single residual instance alone does not specify the universally quantified threshold.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result for the stated problem

Exact computation is polynomial-time: every valid instance has \(z^\star=0\).

The bounded catalogue and arbitrarily large empty removals force this conclusion, even when all supplies and weights are positive. I first prove the stated result, then examine a nontrivial modification that preserves residual capacity.

Proof that \(0\) is residually feasible

Every configuration has nonnegative value. Consequently, at threshold \(z=0\), the removal condition forces \(x=0\).

It remains to allocate the original supplies using population mass \(1\). For each coordinate with \(B_g>0\), independently choose bundle coordinate \(B_g\) with probability \(q_g/B_g\), and coordinate \(0\) otherwise. When \(B_g=0\), choose coordinate \(0\); the assumption \(q_g\leq B_g\) implies \(q_g=0\).

Let \(y_b\) be the probability of configuration \(b\). Every resulting configuration belongs to \(C\), and

\(\sum_b y_b=1,\qquad \sum_b y_b b_g=q_g\quad\text{for every }g.\)

All configurations have value at least \(0\), so this is a valid residual allocation. Thus \(0\) is residually feasible.

Proof that every positive threshold fails

Fix any \(z>0\). Write \(\mathbf 0\) for the empty configuration, whose value is \(0<z\).

At least one supply is positive

Choose \(g\) with \(q_g>0\). Then \(B_g>0\). Set

\(\varepsilon=\frac{q_g}{2B_g},\qquad x_{\mathbf 0}=1-\varepsilon,\)

and set all other removal coordinates to zero. Because \(0<q_g\leq B_g\), we have \(0<\varepsilon\leq 1/2\). This removal has mass strictly less than \(1\), consumes no supply, and uses only a configuration of value below \(z\). It is therefore removable.

Any residual allocation would have total mass \(\varepsilon\). Since every catalogue configuration satisfies \(b_g\leq B_g\), it would necessarily satisfy

\(\sum_b y_b b_g\leq B_g\sum_b y_b=B_g\varepsilon=q_g/2.\)

But the required residual supply in coordinate \(g\) is still \(q_g>0\). This contradicts the supply equality.

All supplies are zero

Use the permitted removal \(x=0\). Any residual allocation must have mass \(1\) and satisfy

\(\sum_b y_b v_\theta(b)=\sum_g w_{\theta,g}\sum_b y_b b_g=\sum_g w_{\theta,g}q_g=0.\)

If every configuration receiving positive mass had value at least \(z\), the same quantity would be at least \(z\sum_b y_b=z>0\), a contradiction.

These cases exhaust all inputs. Hence no positive threshold is residually feasible, proving \(z^\star=0\).

A nontrivial capacity-preserving modification

To address the intended residual-allocation phenomenon beyond this obstruction, consider the different definition that additionally requires every removable distribution to satisfy

\(q_g-\sum_b x_b b_g\leq (1-\kappa)B_g\quad\text{for every }g.\)

This says that the remaining population has enough capacity to absorb each residual supply. The original problem does not impose this condition.

Even under this modification, an initial allocation above a threshold does not establish residual feasibility. The following instance demonstrates this and has an exactly computable modified threshold.

Take one type, four item kinds, and

\(B=(1,1,1,1),\qquad w_\theta=(7,8,13,1),\qquad q=(1/4,1/2,1/2,1/4).\)

The initial distribution assigning masses \(1/2,1/4,1/4\), respectively, to

\((0,0,1,0),\qquad (1,1,0,0),\qquad (0,1,0,1)\)

allocates exactly \(q\). Their values are \(13,15,9\), so everyone initially receives value at least \(9\).

Every threshold above \(8\) fails

Remove mass \(1/8\) on configuration \(b=(1,0,0,1)\), whose value is \(8\). For every \(z>8\), this configuration is below threshold.

The residual mass is \(7/8\), and the residual supply is

\(r=(1/8,1/2,1/2,1/8).\)

Each residual supply lies between \(0\) and \(7/8\), so the added capacity condition holds.

Every configuration of value greater than \(8\) satisfies \(b_1+b_3+b_4\geq1\): if these three coordinates vanish, its value is \(8b_2\leq8\). Therefore any allocation using only configurations of value at least \(z>8\) would satisfy

\(\sum_b y_b(b_1+b_3+b_4)\geq\sum_b y_b=7/8.\)

The required supply equalities instead give that sum as \(1/8+1/2+1/8=3/4\), a contradiction.

Threshold \(8\) is feasible under the modification

Consider any permitted removal at threshold \(8\), and write \(M=1-\kappa>0\). Every removed configuration has \(b_2=b_3=0\), since either coordinate alone gives value at least \(8\). Hence both residual supplies \(r_2,r_3\) equal \(1/2\).

The capacity condition implies \(M\geq1/2\). Assign the following masses to the pair \((b_2,b_3)\):

| Pair | Mass |
|---|---:|
| \((1,1)\) | \(1-M\) |
| \((1,0)\) | \(M-1/2\) |
| \((0,1)\) | \(M-1/2\) |

These masses are nonnegative, sum to \(M\), and give supply \(1/2\) in each coordinate. Every supported pair has at least one coordinate equal to \(1\).

For coordinates \(1\) and \(4\), independently attach binary coordinates with probabilities \(r_1/M\) and \(r_4/M\). These probabilities belong to \([0,1]\) by nonnegative residual supplies and the added capacity condition. The resulting catalogue distribution allocates every residual supply exactly. Every supported configuration has value at least \(8\).

Thus the modified threshold for this instance is exactly \(8\). This establishes a nontrivial case of the repaired formulation, without asserting its general computational complexity.

Complexity conclusion

For the problem actually stated, an algorithm simply returns \(0\). Its correctness follows from the complete proof above; reading or validating the input also takes polynomial time in \(m,\tau,s,L\).

The cited finite-agent hardness result concerns discrete partitions and does not contradict this conclusion. [Proposition 3.13](https://arxiv.org/html/2602.11732v2#S3.SS2) establishes weak NP-hardness for that finite model; the unrestricted empty-mass removals used here are a different feature.
