The continuous mirror question, as graded

Given \(m\) and an explicit rational distribution \(\mu\) over ballot types \(t\in\{0,1\}^m\), decide whether there is a partition \(P\) of \([m]\) into nonempty bundles such that every \(C\in P\) satisfies \(q_\mu(C)\ge \tfrac12\), where \(q_\mu(C)=\sum_{t:\,2\sum_{i\in C}t_i\ge |C|}\mu_t\).

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge 1\) be the number of independent, equally weighted binary issues, indexed by \([m]=\{1,\ldots,m\}\).
A society is given by its support: a list \(T\subseteq\{0,1\}^m\) of \(\tau\) distinct types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
Type \(t\) supports issue \(i\) exactly when \(t_i=1\). It approves a nonempty bundle \(C\subseteq[m]\) exactly when \(2\sum_{i\in C}t_i\ge |C|\).
Define \(q_\mu(C)=\sum_{t\in T:\,2\sum_{i\in C}t_i\ge |C|}\mu_t\). A bundle approves all its issues exactly when \(q_\mu(C)\ge\tfrac12\); ties at both voting stages favor approval.
A perfect bundling is a partition \(P\) of \([m]\) into nonempty bundles with \(q_\mu(C)\ge\tfrac12\) for every \(C\in P\). The number and sizes of bundles are unrestricted, and the society is fixed.

Is deciding whether a perfect bundling exists in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For an explicitly listed finite electorate with equal voter weights and these same tie conventions, deciding whether a perfect bundling exists is \(\mathrm{NP}\)-complete. [Source](https://www.cs.tau.ac.il/~nogaa/PDFS/bundlingaaai2.pdf)
No separate result for this exact rational-mass formulation was identified in the search.

Modeling choices made when packaging the task

  • Made distribution normalization explicit: all listed masses are positive binary rationals summing to one, and zero-mass types are omitted.
  • Specified a nonempty issue domain with m at least one and defined L as the total input bit length.
  • Made explicit that issues have equal weight, both voting stages favor approval on ties, and partitions have unrestricted numbers and sizes of nonempty bundles.

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when every mass is a dyadic rational, meaning a rational with a finite binary expansion.

Membership in \(\mathrm{NP}\)

A certificate assigns each issue a bundle label in \([m]\). The nonempty label classes form a partition, and the certificate uses \(O(m\log(m+1))\) bits.

Write each input mass as \(\mu_t=a_t/b_t\), with positive integers encoded in binary. Define
\(D=\prod_{t\in T}b_t\) and \(w_t=a_t(D/b_t)\).
These are integers, and normalization gives \(\sum_{t\in T}w_t=D\). The bit length of \(D\) is at most the sum of the denominator bit lengths, hence \(O(L)\); also \(0<w_t\le D\).

For each bundle \(C\), compute \(\sum_{i\in C}t_i\) for every type and check the exact integer inequality
\[ 2\sum_{\substack{t\in T\\2\sum_{i\in C}t_i\ge |C|}}w_t\ge D. \]
This is equivalent to \(q_\mu(C)\ge\tfrac12\). There are at most \(m\) bundles, and all arithmetic involves integers of polynomial bit length. Thus verification takes time polynomial in \(m,\tau,L\), proving membership in \(\mathrm{NP}\).

Polynomial reduction establishing hardness

We use the given equal-weight electorate hardness theorem. Its hypotheses match this task: the source defines approval by nested majority votes, breaks ties toward approval, and allows arbitrary partitions. Its Proposition 2 states that deciding whether a perfect bundling exists is \(\mathrm{NP}\)-complete. [Alon, Falik, Meir, and Tennenholtz, *Bundling Attacks in Judgment Aggregation*](https://www.cs.tau.ac.il/~nogaa/PDFS/bundlingaaai2.pdf)

Let an instance of that problem consist of \(n\ge1\) explicitly listed voters, whose rows are \(v^{(1)},\ldots,v^{(n)}\in\{0,1\}^m\). Repeated rows are permitted.

We first pad the electorate to make its size a power of two while preserving the decision on every nonempty bundle.

Let \(N\) be the smallest power of two satisfying \(N\ge\max\{2,n\}\). Then \(N\le2n\). Add

\[ a=\frac N2-\left\lceil\frac n2\right\rceil \]

voters supporting every issue, and

\[ b=\frac N2-\left\lfloor\frac n2\right\rfloor \]

voters supporting no issue. Both counts are nonnegative integers, and \(a+b=N-n\).

For a nonempty bundle \(C\), let \(r(C)\) be the number of original voters approving it. Every added all-supporting voter approves \(C\), and every added zero-supporting voter rejects it. Consequently, the padded electorate approves \(C\) exactly when

\[ r(C)+a\ge\frac N2 \quad\Longleftrightarrow\quad r(C)\ge\left\lceil\frac n2\right\rceil. \]

The last condition is exactly the original electorate’s approval rule, including its approval-favoring tie convention.

Now merge identical rows in the padded electorate. Let \(T\) be the set of distinct rows, and let \(k_t\) be the multiplicity of \(t\in T\). Set \(\mu_t=k_t/N\). These masses are positive, sum to one, and are dyadic because \(N\) is a power of two.

For every nonempty bundle \(C\),

\[ q_\mu(C)=\frac{r(C)+a}{N}. \]

Thus \(C\) passes in the constructed society if and only if it passes in the original electorate. Since the issues are unchanged, every partition succeeds in one instance if and only if it succeeds in the other. In particular, existence of a perfect bundling is preserved in both directions.

Finally, the construction has polynomial size. There are at most \(n+2\) distinct types; each type requires \(m\) bits, and each mass requires \(O(\log(n+1))\) bits. Hence the output length is

\[ O\bigl((n+2)(m+\log(n+1))\bigr), \]

which is polynomial in the explicitly listed electorate’s input length. Padding, grouping rows, and computing their multiplicities also take polynomial time.

This is a polynomial many-one reduction, proving \(\mathrm{NP}\)-hardness. Together with membership in \(\mathrm{NP}\), it settles the question.
