The continuous mirror question, as graded

Given \(m\) alternatives and an explicitly listed finite-support rational distribution \(\mu\) over complete rankings \(\pi\in S_m\), output an integral ranking \(\rho\in S_m\) minimizing \(F_\mu(\rho)=\sum_{\pi\in S_m}\mu_\pi d_{\mathrm{KT}}(\pi,\rho)\); equivalently, decide whether \(\min_{\rho\in S_m}F_\mu(\rho)\le B\).

Packaged proof task (what the prover saw — nothing else)

Let \(m\geq 1\) alternatives be given, and let \(S_m\) denote their strict complete rankings. A society is given by its support: a list of \(\tau\geq 1\) distinct rankings \(\pi_i\in S_m\), each with positive binary rational mass \(\mu_i\), where \(\sum_{i=1}^{\tau}\mu_i=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length, including a binary rational threshold \(B\geq 0\).
Use the standard, unnormalized Kendall–tau distance \(d_{\mathrm{KT}}\). The output ranking must belong to \(S_m\); any minimizer is acceptable. Define \(F_\mu(\rho)=\sum_{i=1}^{\tau}\mu_i d_{\mathrm{KT}}(\pi_i,\rho)\).

Is deciding whether \(\min_{\rho\in S_m}F_\mu(\rho)\leq B\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite electorates, minimizing total Kendall–tau distance is Kemeny aggregation and is NP-hard, even with four complete rankings ([Dwork et al., Rank Aggregation Revisited](https://cs.brown.edu/courses/csci2531/papers/rank2.pdf)). No separate result specifically formulated with binary rational probability masses was verified.

Modeling choices made when packaging the task

  • Specified a nonempty support and positive masses summing to one, as required by a probability distribution.
  • Specified that rankings are strict complete orders and Kendall–tau distance is unnormalized.
  • Specified a nonnegative binary rational decision threshold and defined L as total input bit length.
  • Allowed any minimizing ranking, since tie-breaking does not affect the decision question.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when the support size satisfies \(\tau\leq 4\) and every mass is an integer multiple of \(\frac14\). Thus a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

Reduction from finite-electorate Kemeny aggregation

We use the following known result: given four strict complete rankings \(\sigma_1,\ldots,\sigma_4\) of the same alternatives and a nonnegative integer threshold \(K\), deciding whether there exists \(\rho\in S_m\) with
\(\sum_{j=1}^{4}d_{\mathrm{KT}}(\sigma_j,\rho)\leq K\)
is \(\mathrm{NP}\)-complete. This is the four-list case of Theorem 14 in Appendix A of [Dwork et al., *Rank Aggregation Revisited*](https://cs.brown.edu/courses/csci2531/papers/rank2.pdf). Their distance on complete rankings is the unnormalized Kendall–tau distance used here.

Take an instance of this problem. Let \(\pi_1,\ldots,\pi_\tau\) be the distinct rankings occurring among \(\sigma_1,\ldots,\sigma_4\), and define their multiplicities by
\[ n_i=\bigl|\{j\in\{1,2,3,4\}:\sigma_j=\pi_i\}\bigr|. \]
Set \(\mu_i=n_i/4\) and \(B=K/4\).

These data satisfy every requirement of the target problem:

  • The support rankings are distinct, and \(1\leq\tau\leq4\).
  • Every \(\mu_i\) is positive, and \(\sum_i\mu_i=\frac14\sum_i n_i=1\).
  • The masses and threshold are binary-encodable rationals. Indeed, they are dyadic rationals, so the reduction also works if “binary rational” requires a terminating binary expansion.

For every admissible output ranking \(\rho\in S_m\), grouping equal input rankings gives
\[ F_\mu(\rho) =\sum_{i=1}^{\tau}\frac{n_i}{4}d_{\mathrm{KT}}(\pi_i,\rho) =\frac14\sum_{j=1}^{4}d_{\mathrm{KT}}(\sigma_j,\rho). \]
Consequently,
\[ \min_{\rho\in S_m}F_\mu(\rho)\leq B \quad\Longleftrightarrow\quad \min_{\rho\in S_m}\sum_{j=1}^{4}d_{\mathrm{KT}}(\sigma_j,\rho)\leq K. \]

The construction takes polynomial time: comparing and grouping four rankings is polynomial in their explicit encoding length, each mass has constant encoding length, and encoding \(K/4\) adds only a constant number of bits to the encoding of \(K\). This is therefore a polynomial-time many-one reduction, proving \(\mathrm{NP}\)-hardness.

Membership in \(\mathrm{NP}\)

A certificate is a ranking \(\rho\), encoded as a permutation of the alternatives using \(O(m\log(m+1))\) bits. A verifier first checks that every alternative occurs exactly once.

For each support ranking, compute
\(D_i=d_{\mathrm{KT}}(\pi_i,\rho)\)
by counting unordered pairs whose relative orders disagree. This takes \(O(\tau m^2)\) pair checks, and \(0\leq D_i\leq\binom m2\).

Write the input rationals as \(\mu_i=a_i/b_i\) and \(B=c/d\), where the denominators are positive integers. Define
\[ Q=d\prod_{i=1}^{\tau}b_i. \]
Since \(Q\) is positive and divisible by every denominator, the required comparison is exactly the integer comparison
\[ \sum_{i=1}^{\tau}a_iD_i\frac{Q}{b_i} \leq c\frac{Q}{d}. \]

The bit length of \(Q\) is bounded by the sum of the input denominator bit lengths, hence is \(O(L)\). The products and sums in this comparison have bit lengths polynomial in \(L,\log(m+1),\log(\tau+1)\). Standard exact integer arithmetic therefore performs the verification in polynomial time.

Thus the problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness. No separate hardness theorem for rational probability masses is needed: normalization and merging duplicate rankings preserve the objective exactly up to the factor \(\frac14\).
