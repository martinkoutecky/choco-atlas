The continuous mirror question, as graded

For an integer \(M\geq 3\), a finite set \(T\) of valuation types with rational masses \(\mu_t\geq 0\) summing to \(1\), and rational piecewise-constant densities on three layers \([0,M]\) whose total value for each type is \(M\), find a finite piecewise-affine description of maps \(\Phi_t:[0,\mu_t]\to\) bundles of three intervals. Require each bundle to have type-\(t\) value at least \(1\), its intervals to have pairwise disjoint interiors, and, for almost every point \(x\) on each layer \(\ell\), require \(\sum_{t\in T}\lambda\{u\in[0,\mu_t]:x\in I_{t\ell}(u)\}=1/M\). Is such an allocation computable with description size and running time polynomial in \(\tau=|T|\), the input bit length \(L\), and \(\log M\)?

The requested universal polynomial bound is false: even with one type and strictly positive constant densities, every permitted explicit description can require at least $M$ affine cells, while the input length is $\Theta(\log M)$.

There is also a further positive result:

Every input admits a finite rational description with at most $M$ constant cells per type.

Thus finite-description existence can be established. The remaining classification question is NP-hardness; the output-size lower bound does not establish it.

Throughout, a description explicitly lists its parameter cells and their affine endpoint data, as required in the task.

2. Rational finite-agent allocations

We first establish the rationality needed for the new existence result.

Lemma. Suppose there are $M$ identical agents with one of the given valuation types. There is a complete allocation into feasible bundles, each containing at most one interval per layer, such that every endpoint is rational and every bundle has value exactly $1$.

Existence over the real numbers

We use the finite-agent theorem supplied in the question: for three layers and any number $n\geq3$ of agents with nonnegative integrable additive valuations, a complete, feasible, contiguous proportional allocation exists. This is [Sanpui’s Theorem 5](https://arxiv.org/html/2208.00726v2#Thmtheorem5).

Its hypotheses hold here. To check the normalization explicitly, rescale $x=My$ and put
$$ w_\ell(y)=v_\ell(My),\qquad 0\leq y\leq1. $$
Then
$$ \sum_{\ell=1}^3\int_0^1w_\ell(y)\,dy = \frac1M\sum_{\ell=1}^3\int_0^Mv_\ell(x)\,dx =1. $$
Apply the theorem to $n=M\geq3$ identical agents. Each receives normalized value at least $1/M$, hence original value at least $1$. Rescaling preserves contiguity and disjointness of interval interiors.

Let $B_1,\ldots,B_M$ be the resulting bundles. Because they partition every layer up to endpoints and all agents have the same valuation,
$$ \sum_{i=1}^M V(B_i) = \sum_{\ell=1}^3\int_0^Mv_\ell(x)\,dx =M. $$
Each summand is at least $1$, so every summand equals $1$.

Rationalizing the endpoints

For each layer define its primitive
$$ F_\ell(z)=\int_0^zv_\ell(x)\,dx. $$
Since the density has rational breakpoints and heights, $F_\ell$ is continuous and piecewise affine with rational coefficients.

Start with the real allocation just obtained, and delete all zero-length intervals. Fix the following finite data from that allocation:

  • which agent-layer intervals remain;
  • the order of those intervals on each layer;
  • the left-to-right order of each agent’s intervals across layers;
  • a closed density segment containing each endpoint.

Introduce variables $s_{i\ell},e_{i\ell}$ for every retained interval. Impose the following constraints:

  • Its endpoints lie in their chosen density segments and satisfy

$$ 0\leq s_{i\ell}\leq e_{i\ell}\leq M. $$

  • On each layer, the first interval starts at $0$, the last ends at $M$, and consecutive intervals satisfy

$$ e_{i\ell}=s_{j\ell}. $$

  • For consecutive intervals in an agent’s chosen cross-layer order, impose

$$ e_{i\ell}\leq s_{i\ell'}. $$

  • For every agent, impose

$$ \sum_{\ell:\,(i,\ell)\text{ retained}} \bigl(F_\ell(e_{i\ell})-F_\ell(s_{i\ell})\bigr)=1. $$

The second set of equalities holds in the original allocation: a positive gap would contradict completeness, and a positive overlap would contradict its being a partition. The third set holds because positive-length intervals with disjoint interiors are ordered from left to right.

On the chosen endpoint segments, each occurrence of $F_\ell$ is a rational affine expression. Consequently, all these constraints define a rational polytope $P$. It is nonempty because it contains the original endpoints, and it is bounded because all coordinates lie in $[0,M]$.

A nonempty bounded polytope has an extreme point. For example, successively minimizing its coordinates yields a singleton face, hence an extreme point. At an extreme point, the active constraint normals span the ambient coordinate space: otherwise a nonzero vector orthogonal to them would allow sufficiently small perturbations in both directions while preserving all constraints, contradicting extremality. Selecting a full-rank set of active equations therefore determines the point by a nonsingular rational linear system. Its solution is rational.

Take such a rational point of $P$. Delete any intervals that have collapsed to zero length. The layer-chain equalities still give completeness almost everywhere, the cross-layer inequalities give disjoint interiors, and every bundle still has value $1$. This proves the lemma.

3. Every society has a finite rational description

Apply the lemma separately to each type $t$. Write its $M$ rational bundles as
$$ B_{t,1},\ldots,B_{t,M}. $$
Each bundle has value $1$ for type $t$, and together these bundles partition every layer almost everywhere.

Partition the type’s parameter interval at
$$ 0,\frac{\mu_t}{M},\frac{2\mu_t}{M},\ldots,\mu_t. $$
On the open cell
$$ \left(\frac{(i-1)\mu_t}{M},\frac{i\mu_t}{M}\right), $$
assign the constant bundle $B_{t,i}$. At every parameter breakpoint, assign $B_{t,1}$.

All parameter breakpoints and interval endpoints are rational. Constant endpoints are rational affine functions with slope $0$, so this is an allowed description. Every parameter value receives a feasible bundle of value exactly $1$.

To verify completeness, fix a layer $\ell$. Outside the finitely many endpoints of its finite-agent allocations, exactly one bundle $B_{t,i}$ contains any given $x$, for each type $t$. Hence
$$ \lambda\{u\in[0,\mu_t]:x\in I_{t\ell}(u)\} = \frac{\mu_t}{M}. $$
Summing over types gives
$$ \sum_{t\in T} \lambda\{u:x\in I_{t\ell}(u)\} = \frac1M\sum_{t\in T}\mu_t = \frac1M. $$
Parameter breakpoints have measure zero and do not change this calculation.

This proves finite rational-description existence on every input, with at most $\tau M$ open cells in total.

A bound on encoded bits

A coarse bound also follows from the rational-polytope proof. Each primitive coefficient has $O(L^2)$ bits: it is obtained by summing at most $L$ products and differences of input rationals. Each constraint row has only constantly many nonzero coefficients.

There are at most $d=6M$ endpoint variables. Clearing denominators row by row gives integer coefficients with $O(L^2)$ bits. For a nonsingular active system, the determinant expansion bounds both Cramer-rule determinants by
$$ d!\,2^{O(dL^2)}. $$
Thus every chosen endpoint has
$$ O\bigl(M(L^2+\log M)\bigr) $$
bits. The resulting description has, conservatively,
$$ O\bigl(\tau M^2(L^2+\log M)\bigr) $$
encoded bits.

This is polynomial in the numerical value of $M$. It is not polynomial in its binary encoding length.

The proof is also effective without knowing the original real allocation: enumerate the finite choices of empty intervals, interval orders and endpoint segments, then enumerate candidate rational vertices of their bounded constraint systems. The existence argument guarantees that a valid candidate is eventually found. No polynomial running-time bound is claimed for that enumeration.

4. A strictly positive family requiring at least $M$ cells

We now give a self-contained proof of the output-size obstruction from the notes.

Fix an integer $M\geq3$. Take one type of mass $1$, and put
$$ \varepsilon=\frac{1}{100M^2}, \qquad v_1(x)=1-2\varepsilon, \qquad v_2(x)=v_3(x)=\varepsilon. $$
These densities are strictly positive and satisfy
$$ \sum_{\ell=1}^3\int_0^Mv_\ell(x)\,dx = M\bigl((1-2\varepsilon)+2\varepsilon\bigr) =M. $$
All input rationals have $O(\log M)$ bits. Including the encoding of $M$ gives
$$ L=\Theta(\log M). $$

Consider any valid finite affine description. Let $d_\ell(u)$ be the length of its layer-$\ell$ interval, with length $0$ for an empty interval.

4.1. The first-layer length is close to $1$

The endpoint functions are measurable because they are piecewise affine with finitely many separately specified breakpoint values. Tonelli’s theorem and completeness give, for each layer,
$$ \int_0^1d_\ell(u)\,du = \int_0^M\lambda\{u:x\in I_\ell(u)\}\,dx =1. $$
Write the allocated value as
$$ W(u) = (1-2\varepsilon)d_1(u) + \varepsilon\bigl(d_2(u)+d_3(u)\bigr). $$
Therefore
$$ \int_0^1W(u)\,du=1. $$
Since feasibility requires $W(u)\geq1$ everywhere, it follows that
$$ W(u)=1 \quad\text{for almost every }u. $$

Pairwise disjoint interiors imply
$$ d_1(u)+d_2(u)+d_3(u)\leq M. $$
Consequently, almost everywhere,
$$ d_1(u)\leq\frac{1}{1-2\varepsilon} $$
and
$$ 1=W(u) \leq (1-3\varepsilon)d_1(u)+\varepsilon M. $$
Thus
$$ \frac{1-\varepsilon M}{1-3\varepsilon} \leq d_1(u) \leq \frac{1}{1-2\varepsilon}. $$

Set
$$ \eta=\frac{1}{10M}, \qquad a=1-\eta, \qquad b=1+\eta. $$
The denominators below exceed $1/2$, so
$$ 1-\frac{1-\varepsilon M}{1-3\varepsilon} = \frac{\varepsilon(M-3)}{1-3\varepsilon} \leq 2\varepsilon M = \frac{1}{50M} <\eta, $$
and
$$ \frac{1}{1-2\varepsilon}-1 = \frac{2\varepsilon}{1-2\varepsilon} \leq 4\varepsilon = \frac{1}{25M^2} <\eta. $$
Hence
$$ a\leq d_1(u)\leq b \quad\text{almost everywhere}. $$

In fact, the first interval has positive length for every $u$. Otherwise the other two intervals could give value at most
$$ \varepsilon M<1, $$
contradicting feasibility. Let its endpoints be $s(u)$ and $e(u)$.

4.2. Completeness gives an endpoint-measure identity

Let $S$ and $E$ be the distributions of $s(u)$ and $e(u)$ when $u$ is uniform on $[0,1]$, and let $\xi$ be their joint distribution.

The almost-everywhere length bound places the support of $\xi$ in the compact set
$$ K= \{(s,e):0\leq s\leq e\leq M,\ a\leq e-s\leq b\}. $$
In particular,
$$ \operatorname{supp}S\subseteq[0,M-a], \qquad \operatorname{supp}E\subseteq[a,M]. $$

Define
$$ C(x)=\lambda\{u:x\in I_1(u)\}. $$
For every continuously differentiable function $f$ on $[0,M]$, Fubini’s theorem gives
$$ \int f\,dE-\int f\,dS = \int_0^1\bigl(f(e(u))-f(s(u))\bigr)\,du = \int_0^Mf'(x)C(x)\,dx. $$
Completeness therefore yields
$$ \int f\,dE-\int f\,dS = \frac{f(M)-f(0)}{M}. $$
Polynomials, and hence continuously differentiable functions, are uniformly dense in the continuous functions on $[0,M]$. Finite Borel measures are determined by their integrals against continuous functions. We obtain
$$ S-E=\frac{\delta_0-\delta_M}{M}. $$
In particular, $S$ and $E$ agree on $(0,M)$.

4.3. Left endpoints lie in separated bands

Define
$$ A_k=[ka,kb], \qquad 0\leq k\leq M. $$
We claim that
$$ \operatorname{supp}S \subseteq \bigcup_{k=0}^{M-1}A_k. $$

Take a positive point $s\in\operatorname{supp}S$. Since $s\leq M-a<M$, equality of $S$ and $E$ on $(0,M)$ implies $s\in\operatorname{supp}E$.

For a compactly supported joint measure, projecting its support onto a coordinate gives the support of that marginal. Indeed, the projection is compact; a marginal-support point outside it would have a neighborhood of marginal measure zero. Conversely, a projected joint-support point has positive marginal measure in every neighborhood.

Thus there is some $s'\in\operatorname{supp}S$ with
$$ (s',s)\in\operatorname{supp}\xi, \qquad a\leq s-s'\leq b. $$
Every positive support point therefore has a predecessor at least $a$ smaller.

Repeatedly taking predecessors must reach $0$: otherwise it would produce arbitrarily long sequences of nonnegative numbers decreasing by at least $a>0$. Consequently, $s$ is the sum of $k$ increments in $[a,b]$, and
$$ ka\leq s\leq kb. $$
Also,
$$ ka\leq M-a, \qquad k\leq\frac{M-a}{a}<M. $$
The last inequality holds because
$$ a=1-\frac{1}{10M}>\frac{M}{M+1}. $$
Hence $k\leq M-1$, proving the claim.

For $0\leq k\leq M$,
$$ A_k\subseteq \left[k-\frac{1}{10},\,k+\frac{1}{10}\right]. $$
The bands are therefore pairwise separated.

4.4. Every band has mass $1/M$

Fix $k\in\{0,\ldots,M-1\}$ and choose
$$ x\in \left(k+\frac{1}{10},\,k+\frac{9}{10}\right). $$
On a common full-measure set of parameters, $s(u)$ lies in exactly one band $A_j$ and
$$ e(u)\in A_{j+1}, $$
because $e(u)-s(u)\in[a,b]$.

There are three cases:

  • If $j=k$, then

$$ s(u)\leq k+\frac{1}{10}<x <k+\frac{9}{10}\leq e(u). $$
Thus the interval contains $x$.

  • If $j<k$, then

$$ e(u)\leq j+1+\frac{1}{10} \leq k+\frac{1}{10}<x. $$

  • If $j>k$, then

$$ s(u)\geq j-\frac{1}{10} \geq k+\frac{9}{10}>x. $$

Exceptional parameters have measure zero. Consequently,
$$ C(x)=S(A_k) $$
throughout the displayed open spatial interval. That interval has positive length, so almost-everywhere completeness forces
$$ S(A_k)=\frac1M \qquad \text{for every }k=0,\ldots,M-1. $$

4.5. Each affine cell serves only one band

Let
$$ B=\bigcup_{k=0}^{M-1}A_k. $$
On any open parameter cell, the endpoint $s(u)$ is affine and therefore continuous. We know that $s(u)\in B$ almost everywhere.

Because $B$ is closed, continuity strengthens this to membership everywhere on that cell. Otherwise, the inverse image of its open complement would contain a nonempty open parameter interval, contradicting almost-everywhere membership.

The continuous image of a connected parameter cell is connected. Since the bands are separated, that image lies in one band.

Each of the $M$ bands has parameter mass $1/M$. Finitely many parameter breakpoints have measure zero, so each band must be served by an open cell. A cell serves only one band. Therefore every valid description has at least
$$ M $$
open affine cells.

Explicitly encoding them requires $\Omega(M)$ bits. Taking $M=2^n$ gives input length $\Theta(n)$ and required output size $\Omega(2^n)$. This disproves the proposed polynomial description bound and any polynomial running-time bound for writing such a description.

5. The lower-bound family has valid descriptions

The obstruction is compatible with existence, and its cell count is attained.

For $r=0,\ldots,M-1$, put
$$ J_r=[r,r+1]. $$
On parameter cell
$$ \left(\frac{j}{M},\frac{j+1}{M}\right), \qquad j=0,\ldots,M-1, $$
assign
$$ I_1=J_j, \qquad I_2=J_{(j+1)\bmod M}, \qquad I_3=J_{(j+2)\bmod M}. $$
Because $M\geq3$, these intervals have pairwise disjoint interiors. Every bundle has value
$$ (1-2\varepsilon)+\varepsilon+\varepsilon=1. $$
On each layer, every unit interval occurs on exactly one parameter cell of measure $1/M$. Completeness follows away from the finitely many integer spatial endpoints.

At parameter breakpoints, assign any one of these feasible bundles. This gives exactly $M$ constant cells and $O(M\log M)$ encoded bits.

6. Verification and the unresolved complexity question

For descriptions with rational breakpoint bundles, validity can be checked in polynomial time in the combined input and description lengths.

For feasibility, split each open parameter cell wherever an affine endpoint crosses a density breakpoint. Value is affine on every resulting subcell, so checking its limiting endpoint values checks the inequality everywhere. Endpoint range and ordering constraints are linear. For two positive-length intervals, disjoint interiors are equivalent to
$$ e_\ell\leq s_{\ell'} \quad\text{or}\quad e_{\ell'}\leq s_\ell. $$
Splitting at the roots of these affine differences checks this condition exactly. Zero-length intervals have empty interiors. Separately specified breakpoint bundles are checked directly.

Completeness also has a finite exact check. For each layer, let $S_\ell$ and $E_\ell$ be the aggregate endpoint measures, summing over all nonempty intervals on all parameter cells. An endpoint map
$$ u\longmapsto \alpha u+\beta $$
pushes the cell’s Lebesgue measure to an atom of mass equal to the cell length when $\alpha=0$, or to constant density $1/|\alpha|$ on its image interval otherwise.

The same Fubini calculation used above shows that completeness is equivalent to
$$ S_\ell-E_\ell = \frac{\delta_0-\delta_M}{M}. $$
For sufficiency, this identity gives
$$ \int_0^M f'(x) \left(C_\ell(x)-\frac1M\right)\,dx=0 $$
for every continuously differentiable $f$. Every continuous function is such a derivative, so the integrable function $C_\ell-1/M$ defines the zero signed measure and vanishes almost everywhere. The endpoint measures have finitely many rational atoms and piecewise-constant rational densities; sorting their breakpoints and comparing their masses and densities performs the check.

These verification results do not provide polynomial-size outputs. The established conclusions are finite rational-description existence and an exponential worst-case output-size lower bound. No NP-hardness reduction is established here.
