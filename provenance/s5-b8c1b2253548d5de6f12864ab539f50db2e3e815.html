The continuous mirror question, as graded

Given finitely many cohort templates \(q\), each a weighted graph \(H_q=(R_q,E_q)\) with a supplied proper \(\kappa\)-coloring, rational cohort masses \(p_q\) summing to \(1\), and \(k\ge\max\{\kappa/\varepsilon,2\Delta\}\), distribute each template's mass over its integral proper \(k\)-colorings: choose \(x_{q,\sigma}\ge0\) with \(\sum_\sigma x_{q,\sigma}=1\). For role weights \(a_{qr}\), define \(L_i=\sum_q p_q\sum_\sigma x_{q,\sigma}\sum_{r:\sigma(r)=i}a_{qr}\). Find a distribution minimizing \(\max_i L_i/\min_i L_i\), equivalently decide whether all color loads can be made equal in the atomless limit of repeated cohort copies.

Conclusion

The decision problem is in \(\mathrm{P}\). Every instance satisfying the stated promises admits an exactly equal feasible mass assignment.

The key is that the assignment may distribute copies of a cohort among different integral proper colorings. Averaging over cyclic relabelings balances every role while preserving all conflicts within every cohort.

Exact balancing construction

Since \(\varepsilon\le 1/10\) and \(k\ge\kappa/\varepsilon\), we have \(k\ge\kappa\). Thus the supplied proper coloring of each graph can be viewed as a proper coloring \(c_q:R_q\to\{1,\ldots,k\}\).

For each \(j\in\{0,\ldots,k-1\}\), define
\(\sigma_{q,j}(r)=1+((c_q(r)-1+j)\bmod k)\).

Each map \(\sigma_{q,j}\) is proper: cyclic relabeling is a bijection on the color set, so distinct colors at adjacent roles remain distinct.

Define the mass assignment by
\(x_{q,\sigma}=\frac{1}{k}\left|\{j\in\{0,\ldots,k-1\}:\sigma_{q,j}=\sigma\}\right|\).

This definition also handles coincident colorings, including those of an empty graph. Every coefficient is nonnegative, and
\(\sum_{\sigma\in\Sigma_q}x_{q,\sigma}=\frac{1}{k}\sum_{j=0}^{k-1}1=1\).
Consequently, these coefficients constitute a feasible mass assignment.

Fix a role \(r\in R_q\) and a color \(i\in\{1,\ldots,k\}\). As \(j\) ranges over its \(k\) possible values, \(\sigma_{q,j}(r)\) takes each color exactly once. Therefore
\(\sum_{\sigma\in\Sigma_q}x_{q,\sigma}\mathbf{1}_{\{\sigma(r)=i\}}=1/k\).

Substituting this identity into the load definition and rearranging finite sums gives
\(L_i=\sum_q p_q\sum_{r\in R_q}a_{qr}\sum_{\sigma\in\Sigma_q}x_{q,\sigma}\mathbf{1}_{\{\sigma(r)=i\}}=\frac{1}{k}\sum_qp_q\sum_{r\in R_q}a_{qr}=W/k\).

This proves exact equality for every color.

Compatibility with the atomless interpretation

The construction can also be realized exactly by finite collections of cohort copies along an appropriate sequence.

Choose a positive integer \(D\) such that \(b_q=Dp_q\) is a positive integer for every \(q\). For any positive integer \(t\), set \(N=kDt\). Then type \(q\) has \(Np_q=ktb_q\) copies. Assign exactly \(tb_q\) of them to each coloring \(\sigma_{q,j}\).

For any fixed role and color, exactly one cyclic shift assigns that role to that color. Its contribution to that color’s load is therefore
\((tb_q)a_{qr}/N=p_qa_{qr}/k\).
Summing proves that all loads equal \(W/k\) at each such replication size.

Let \(A=\max_{q,r}a_{qr}\), which exists and is positive because \(W>0\). The maximum individual-copy weight is \(A/N\), tending to zero as \(t\) increases. In particular, whenever \(N\ge kA/(\varepsilon W)\), it satisfies the stated low maximum weight condition.

Thus exact balancing respects both the integral coloring requirement for each copy and the individual-copy weight interpretation.

Decision and representation complexity

On the promised input domain, the decision algorithm always returns yes. It requires constant time after accepting the promises, or polynomial time in \(L\) if the input and promises are validated. There is no numerical dependence on \(k\), \(\kappa\), or \(1/\varepsilon\) beyond their binary encodings.

The construction has a succinct description of size \(O(L)\): retain the supplied colorings and specify uniform cyclic shifting. An explicit enumeration uses at most \(k\tau\) coloring entries and can be produced using \(O(k(m+\tau))\) arithmetic operations on integers of \(O(L)\) bits.

Because \(k\) is binary encoded, explicit enumeration need not have polynomial size in \(L\). This distinction is unavoidable: with one positive-weight role, exact balancing forces each of its \(k\) possible colorings to have mass \(1/k\), so every explicitly listed assignment has \(k\) nonzero entries. The decision problem remains polynomial-time solvable.

The discrete approximate-equitability theorem is unnecessary here. Exact equality follows directly from the permitted mixtures and symmetry under color relabeling.
