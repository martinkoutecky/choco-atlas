The continuous mirror question, as graded

Given a finite object set \(V\), a finite support \(T\subseteq\Omega\) of non-strict incomplete rankings \(a^t\), each ranking at least two objects, and positive rational masses \(\mu_t\) summing to \(1\), find a complete ranking \(r\in\Omega_C\) maximizing \(\sum_{t\in T}\mu_t\hat{\tau}_x(r,a^t)\).

Packaged proof task (what the prover saw — nothing else)

Let \(V=\{v_1,\ldots,v_m\}\), with \(m\geq2\). A type \(t\) specifies a weak order \(a^t\) on a subset \(S_t\subseteq V\), with \(k_t=|S_t|\geq2\); ties are allowed, and unranked objects convey no comparisons.
A society is given by its support: a list \(T\) of \(\tau\) distinct types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types, and \(L\) is the total input bit length.
Represent each ranking by ordinal labels, with smaller labels preferred and equal labels tied. For any ranking \(b\), define \(B_{ij}=0\) if \(i=j\) or either object is unranked; otherwise define \(B_{ij}=1\) if \(b_i\leq b_j\), and \(B_{ij}=-1\) if \(b_i>b_j\).
A feasible output \(r\) is a weak order on all of \(V\), with ties allowed. Define \(\hat{\tau}_x(r,a^t)=\frac{\sum_{i=1}^{m}\sum_{j=1}^{m}R_{ij}A^t_{ij}}{k_t(k_t-1)}\), and \(F(r)=\sum_{t\in T}\mu_t\hat{\tau}_x(r,a^t)\). Any maximizing ranking is acceptable.

Is computing a complete ranking maximizing \(F(r)\) solvable in time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For a finite unweighted list of non-strict, possibly incomplete rankings, maximizing the sum of these scaled correlations over complete rankings with ties allowed is \(\mathrm{NP}\)-hard.

Modeling choices made when packaging the task

  • Made explicit that the complete output may contain ties, as required by the discrete feasible domain.
  • Interpreted ranking types as weak orders, identifying ordinal representations that encode the same comparisons.
  • Resolved multiple optimal outputs by allowing any maximizing ranking.
  • Defined L as the total input bit length.

Conclusion

Computing a complete weak order maximizing \(F(r)\) is \(\mathrm{NP}\)-hard. This follows from the unweighted hardness result supplied in the question by merging repeated types and assigning their relative frequencies as masses.

Reduction

Use the stated \(\mathrm{NP}\)-hard problem as the source problem. Its input is an explicitly listed collection of rankings \(a^1,\ldots,a^n\) on \(V\), and its objective is
\[ G(r)=\sum_{\ell=1}^{n}\hat{\tau}_x(r,a^\ell), \]
over complete weak orders \(r\), with ties allowed. Here the scaled correlation is the one defined in the question.

Represent each input ranking canonically: retain its ranked subset and replace its ordinal labels by consecutive labels for its ordered tie classes. This preserves every comparison and therefore preserves its comparison matrix.

Group identical canonical rankings. Let \(T\) be the resulting set of distinct types, and let \(c_t\) be the number of occurrences of type \(t\). Construct the support instance using the same object set \(V\), the types in \(T\), and masses
\[ \mu_t=\frac{c_t}{n}. \]
Every mass is positive, and
\[ \sum_{t\in T}\mu_t=\frac{\sum_{t\in T}c_t}{n}=1. \]
Thus the constructed instance satisfies the required support and mass conditions.

Preservation of optimal rankings

Fix any feasible complete weak order \(r\). All occurrences grouped into type \(t\) have the same ranked subset, the same comparison matrix, and the same denominator \(k_t(k_t-1)\). Consequently,
\[ G(r) =\sum_{t\in T}c_t\hat{\tau}_x(r,a^t) =n\sum_{t\in T}\mu_t\hat{\tau}_x(r,a^t) =nF(r). \]

The feasible rankings are identical in the two instances. Since \(n\) is positive, multiplying an objective by \(n\) preserves its entire set of maximizers. Therefore every maximizing ranking returned for the support instance also maximizes the source objective. This includes rankings with ties; no tie-breaking assumption is needed.

Polynomial size and running time

Canonicalization, comparison, and grouping of the explicitly listed rankings take polynomial time in the source input length. The constructed support has \(\tau\leq n\) types, and their ranking descriptions can be taken directly from the canonicalized input.

Each mass \(c_t/n\), represented by a numerator and denominator in binary, requires \(O(\log(n+1))\) bits. Hence the additional mass descriptions require \(O(n\log(n+1))\) bits, and the complete constructed instance has polynomial length.

An algorithm running in time polynomial in \(m,\tau,L\) would therefore solve the stated unweighted problem in polynomial time: construct this support instance and return its maximizing ranking. By the supplied hardness result, this proves \(\mathrm{NP}\)-hardness.
