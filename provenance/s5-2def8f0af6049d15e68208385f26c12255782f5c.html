The continuous mirror question, as graded

Given finite firm and worker type sets \(P,Q\), rational type masses \(\alpha_p,\beta_q\) in compatible market units, integer capacities \(r_p\), nonnegative surpluses \(a_{pq}\), and a rational linear objective on type payoffs \((\pi,w)\), compute an optimal payoff in the type-anonymous continuous core and a supporting aggregate assignment of firm mass to integral worker bundles.

Packaged proof task (what the prover saw — nothing else)

Let \(P,Q\) be nonempty finite sets of firm and worker types. A society is given by its support: the list of its \(\tau=|P|+|Q|\) types with positive binary rational masses \(\alpha_p,\beta_q\); \(\tau\) counts supported types, not possible types. Put \(m=|Q|\). Masses use common market units, need not sum to one, and satisfy \(\sum_p r_p\alpha_p=\sum_q\beta_q\), where capacities \(r_p\in\mathbb Z_{\ge0}\) are binary encoded. Surpluses \(a_{pq}\in\mathbb Q_{\ge0}\) are additive and net of reservation values; outside payoffs are zero.
A firm's integral worker bundle is \(b\in B_p:=\{b\in\mathbb Z_{\ge0}^{Q}:\sum_q b_q\le r_p\}\), including the empty bundle. Repeated worker types represent distinct workers. An aggregate assignment has nonnegative masses \(z_{pb}\), with \(\sum_{b\in B_p}z_{pb}=\alpha_p\) and \(\sum_{p,b}b_qz_{pb}\le\beta_q\); its surplus is \(\sum_{p,b}z_{pb}\sum_q a_{pq}b_q\).
For any coalition submasses \(0\le u\le\alpha\), \(0\le v\le\beta\), let \(V(u,v)\) be the maximum assignment surplus with these masses replacing \(\alpha,\beta\). Coalition submasses may be real and need not be capacity-balanced.
The type-anonymous continuous core consists of nonnegative per-unit payoffs \((\pi,w)\) satisfying \(\sum_p\alpha_p\pi_p+\sum_q\beta_qw_q=V(\alpha,\beta)\) and \(\sum_pu_p\pi_p+\sum_qv_qw_q\ge V(u,v)\) for every coalition submass pair.
A supporting assignment attains \(V(\alpha,\beta)\), satisfies \(\pi_p+\sum_qb_qw_q=\sum_qb_qa_{pq}\) whenever \(z_{pb}>0\), and leaves worker mass unused only at types with \(w_q=0\). Its representation lists the nonzero bundle masses and their bundles.
Given rational coefficients \(c_p,d_q\), optimize \(\sum_pc_p\pi_p+\sum_qd_qw_q\) over this core and compute a supporting assignment. Let \(L\) be the total binary input length.

Is this exact optimization and supporting-assignment problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite capacity-balanced markets, an optimal matching yields a quadratic-size description of the core by salary bounds and differences, with firm payoffs uniquely determined ([Atay–Núñez–Solymosi](https://ataatay.github.io/webpage/ANS_2024_WP.pdf)).
For nonatomic one-to-one assignment markets, existence and equivalence of optimal assignments, core allocations, and Walrasian equilibria are established ([Gretsky–Ostroy–Zame](https://link.springer.com/article/10.1007/BF01213255)); no complexity result for the precise integral-bundle problem above was located.

Modeling choices made when packaging the task

  • Carried over the anchor's capacity-balance condition as equality between total firm-capacity mass and total worker mass; masses share common units and are not separately normalized.
  • Made both supported type sets nonempty, allowed zero integer capacities as in the discrete model, and specified binary encoding of capacities and rational surpluses.
  • Defined integral bundles as worker-type multiplicity vectors, allowing several distinct workers of the same type and including empty and partially filled bundles.
  • Defined the continuous core using all real coalition submasses and the maximum surplus attainable by aggregate integral-bundle assignments within each coalition.
  • Interpreted type payoffs as per-unit payoffs with zero outside options and defined support through bundle payoff exhaustion and zero payoffs for unused worker mass.
  • Interpreted optimization as maximization of an arbitrary rational linear objective and specified a sparse bundle representation for the aggregate assignment.
  • Defined the requested running-time variables by taking m to be the worker support size, tau the combined support size, and L the total binary input length.

The problem is solvable exactly in time polynomial in \(m,\tau,L\). A supporting assignment can be returned with at most \(|P|(m+1)\) nonzero bundle masses. The proof below uses precisely the stated model, including repeated worker types within integral bundles.

Lemma 1 (Exact aggregate formulation).

For any coalition masses \((u,v)\), define the aggregate hiring variables \(x_{pq}\) as the worker mass of type \(q\) assigned to firm type \(p\). Then
\[ \]
\( \displaystyle V(u,v)= \max\left\{ \sum_{p,q}a_{pq}x_{pq}: x_{pq}\ge0,\quad \sum_qx_{pq}\le r_pu_p,\quad \sum_px_{pq}\le v_q \right\}. \)

To prove this equality, first take any feasible bundle assignment and set
\(x_{pq}=\sum_{b\in B_p}b_qz_{pb}\).
Its firm-capacity constraints imply
\( \displaystyle \sum_qx_{pq} =\sum_{b\in B_p}\left(\sum_qb_q\right)z_{pb} \le r_p\sum_{b\in B_p}z_{pb} =r_pu_p. \)
The worker constraints and surplus agree with those of the displayed linear program.

Conversely, take any feasible \(x\). Write \(e_q\) for the unit vector at worker type \(q\). For each \(p\) with \(r_p>0\), define
\( \displaystyle z_{p,r_pe_q}=\frac{x_{pq}}{r_p}, \qquad z_{p,0}=u_p-\frac{\sum_qx_{pq}}{r_p}, \)
and set every other bundle mass to zero. These masses are nonnegative, sum to \(u_p\), and assign exactly \(x_{pq}\) workers of each type. Every listed bundle is integral and belongs to \(B_p\). When \(r_p=0\), feasibility forces \(x_{pq}=0\) for all \(q\); assign mass \(u_p\) to the empty bundle.

Thus both formulations have the same feasible aggregate hiring patterns and the same surplus. This argument applies to real coalition masses, including coalitions that are not capacity-balanced.

Lemma 2 (Polynomial-size description of the core).

Put \(V^*=V(\alpha,\beta)\). The core is exactly the set of payoffs satisfying
\( \displaystyle \begin{aligned} \pi_p&\ge0 &&(p\in P),\\ w_q&\ge0 &&(q\in Q),\\ \pi_p+r_pw_q&\ge r_pa_{pq} &&(p\in P,\ q\in Q),\\ \sum_p\alpha_p\pi_p+\sum_q\beta_qw_q&=V^*. \end{aligned} \)

*Necessity.* Nonnegativity and the final equality are part of the core definition. Fix \(p,q\) with \(r_p>0\), and choose
\( \displaystyle \varepsilon=\min\{\alpha_p,\beta_q/r_p\}>0. \)
Consider the coalition containing firm mass \(\varepsilon\) of type \(p\) and worker mass \(r_p\varepsilon\) of type \(q\), with all other masses zero. It can assign every participating firm the integral bundle \(r_pe_q\), obtaining surplus \(\varepsilon r_pa_{pq}\). Its core constraint therefore gives
\( \displaystyle \varepsilon\pi_p+r_p\varepsilon w_q \ge V(u,v) \ge\varepsilon r_pa_{pq}. \)
Division by \(\varepsilon\) proves the required inequality. For \(r_p=0\), that inequality is simply \(\pi_p\ge0\).

*Sufficiency.* Suppose all displayed conditions hold. For \(r_p>0\), the pairwise inequalities imply
\(a_{pq}-w_q\le\pi_p/r_p\).
Hence, for every \(b\in B_p\),
\( \displaystyle \sum_qb_q(a_{pq}-w_q) \le \frac{\pi_p}{r_p}\sum_qb_q \le\pi_p, \)
where the last step uses \(\pi_p\ge0\). Consequently,
\[ \displaystyle \pi_p+\sum_qb_qw_q\ge\sum_qb_qa_{pq}. \tag{1} \]
For \(r_p=0\), the only bundle is empty, and the same inequality follows from \(\pi_p\ge0\).

Now take any coalition \((u,v)\) and any feasible assignment for it. Multiplying (1) by its bundle masses and summing gives
\( \displaystyle \begin{aligned} \sum_{p,b}z_{pb}\sum_qb_qa_{pq} &\le \sum_pu_p\pi_p+ \sum_qw_q\sum_{p,b}b_qz_{pb}\\ &\le \sum_pu_p\pi_p+\sum_qv_qw_q. \end{aligned} \)
The second inequality uses nonnegative wages and the coalition’s worker constraints. Maximizing the left side over assignments proves every coalition inequality. Efficiency then establishes core membership.

Lemma 3 (Nonemptiness and attainment).

By Lemma 1, the grand-coalition problem is the finite linear program
\[ \displaystyle \begin{aligned} \text{maximize}\quad &\sum_{p,q}a_{pq}x_{pq}\\ \text{subject to}\quad &x_{pq}\ge0,\\ &\sum_qx_{pq}\le r_p\alpha_p &&(p\in P),\\ &\sum_px_{pq}\le\beta_q &&(q\in Q). \end{aligned} \tag{P} \]
It is feasible because \(x=0\) is feasible. Its feasible set is compact: every coordinate satisfies \(0\le x_{pq}\le\beta_q\). Thus its finite optimum \(V^*\) is attained.

Its dual is
\[ \displaystyle \begin{aligned} \text{minimize}\quad &\sum_pr_p\alpha_ps_p+\sum_q\beta_qw_q\\ \text{subject to}\quad &s_p\ge0,\quad w_q\ge0,\\ &s_p+w_q\ge a_{pq} &&(p\in P,\ q\in Q). \end{aligned} \tag{D} \]
The dual is feasible, for example with \(s_p=0\) and \(w_q=\max_pa_{pq}\). Finite-dimensional linear-programming strong duality therefore supplies an optimal dual solution with objective \(V^*\).

Set \(\pi_p=r_ps_p\). These payoffs satisfy all the conditions in Lemma 2, so the core is nonempty. This also handles zero-capacity types, whose constructed firm payoffs are zero.

Finally, the core is closed and bounded. Indeed, positivity of all supported masses, nonnegative payoffs, and efficiency imply
\( \displaystyle 0\le\pi_p\le\frac{V^*}{\alpha_p}, \qquad 0\le w_q\le\frac{V^*}{\beta_q}. \)
It follows that every linear payoff objective attains an optimum over the core.

Proposition 4 (Exact optimization and a supporting assignment).

For definiteness, consider maximization; minimization follows by negating the objective coefficients.

First solve (P), obtaining an exact optimal solution \(x^*\) and value \(V^*\). Next solve
\[ \displaystyle \begin{aligned} \text{maximize}\quad &\sum_pc_p\pi_p+\sum_qd_qw_q\\ \text{subject to}\quad &\pi_p\ge0,\quad w_q\ge0,\\ &\pi_p+r_pw_q\ge r_pa_{pq} &&(p\in P,\ q\in Q),\\ &\sum_p\alpha_p\pi_p+\sum_q\beta_qw_q=V^*. \end{aligned} \tag{C} \]
By Lemmas 2 and 3, this program optimizes exactly over the nonempty, compact core.

Construct \(z^*\) from \(x^*\) using Lemma 1:
\( \displaystyle z^*_{p,r_pe_q}=\frac{x^*_{pq}}{r_p}, \qquad z^*_{p,0}=\alpha_p-\frac{\sum_qx^*_{pq}}{r_p} \quad(r_p>0), \)
and \(z^*_{p,0}=\alpha_p\) when \(r_p=0\). Omit zero masses from the output. This assignment attains \(V^*\).

It remains to verify that it supports the payoff vector returned by (C). Define unused worker mass
\( \displaystyle \ell_q=\beta_q-\sum_{p,b}b_qz^*_{pb}\ge0. \)
Efficiency and assignment optimality give the identity
\( \displaystyle \begin{aligned} 0 &=\sum_p\alpha_p\pi_p+\sum_q\beta_qw_q -\sum_{p,b}z^*_{pb}\sum_qb_qa_{pq}\\ &=\sum_{p,b}z^*_{pb} \left(\pi_p+\sum_qb_qw_q-\sum_qb_qa_{pq}\right) +\sum_qw_q\ell_q. \end{aligned} \)
Every summand is nonnegative: the bundle slacks are nonnegative by (1), and all masses and wages are nonnegative. Therefore each summand vanishes. In particular,
\( \displaystyle z^*_{pb}>0 \quad\Longrightarrow\quad \pi_p+\sum_qb_qw_q=\sum_qb_qa_{pq}, \)
and
\( \displaystyle \ell_q>0\quad\Longrightarrow\quad w_q=0. \)
These are exactly the required supporting-assignment conditions.

Proposition 5 (Binary complexity and output size).

The algorithm uses the standard rational linear-programming theorem: a feasible rational linear program with finite optimum admits an exact rational optimal solution computable in time polynomial in its dimensions and total binary encoding length. The solution’s encoding length is also polynomial. Polynomial solvability in this binary model is discussed explicitly by [Adler and Beling](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf).

All hypotheses have been verified above. Program (P) has \(|P|m\) variables and \(|P|+m\) capacity inequalities, besides nonnegativity. Program (C) has \(\tau\) variables, \(|P|m\) pairwise inequalities, and one efficiency equality, besides nonnegativity. Their dimensions are polynomial in \(m,\tau\).

Their coefficients have polynomial encoding length:

  • Products such as \(r_p\alpha_p\) and \(r_pa_{pq}\) have bit lengths bounded by the sum of the operand lengths, up to a constant.
  • The exact optimal solution \(x^*\), and hence the rational value \(V^*\), have polynomial encoding length.
  • Division by the binary-encoded positive integer \(r_p\), and the sums used to construct bundle masses, preserve polynomial encoding length.

For each positive-capacity firm type, the output contains at most \(m\) bundles \(r_pe_q\) and one empty bundle. A zero-capacity type contributes one empty bundle. Thus there are at most \(|P|(m+1)\) listed entries. Each bundle is an \(m\)-dimensional integer vector whose only potentially nonzero coordinate is the input integer \(r_p\), so even a dense bundle representation has polynomial length.

Consequently, both exact payoff optimization and construction of the specified supporting assignment run in time polynomial in \(m,\tau,L\). The proof does not enumerate bundles, workers, or capacity slots.
