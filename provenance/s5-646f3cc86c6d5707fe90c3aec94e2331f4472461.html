The continuous mirror question, as graded

Given a resource set \(R\), a population scale \(N\), rational type masses \(\mu_t\) summing to \(1\), and each type’s feasible allocation family \(\mathcal S_t\subseteq 2^R\), choose masses \(x_{t,S}\ge 0\) with \(\sum_{S\in\mathcal S_t}x_{t,S}=\mu_t\). For linear resource costs \(c_r(y)=a_ry+b_r\), where \(a_r,b_r\ge 0\), set \(y_r=N\sum_{t,S:r\in S}x_{t,S}\) and minimize \(\sum_{r\in R}y_rc_r(y_r)\). Determine the complexity of computing a feasible allocation with cost at most \((1+\epsilon)\) times optimum, as a function of the encoded instance, \(\tau\), the input bit length, \(\log N\), \(1/\epsilon\), and the complexity of optimizing over implicitly represented \(\mathcal S_t\).

Packaged proof task (what the prover saw — nothing else)

Let \(R\) be a finite resource set, \(m=|R|\), and let \(N\ge1\) be a binary-encoded integer population scale. A society is given by its support: the list of its \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type has a nonempty feasible family \(\mathcal S_t\subseteq2^R\), listed explicitly or represented implicitly. Empty allocations are permitted when included in the family. For implicit families, access consists of an oracle returning a minimizer of \(\sum_{r\in S}w_r\) over \(S\in\mathcal S_t\) for any nonnegative binary-rational vector \(w\); account for its running time and query bit lengths.
Resource costs are \(c_r(y)=a_ry+b_r\), with binary-rational \(a_r,b_r\ge0\). A feasible allocation consists of divisible masses \(x_{t,S}\ge0\) satisfying \(\sum_{S\in\mathcal S_t}x_{t,S}=\mu_t\), encoded by its nonzero rational masses and corresponding sets.
Define \(y_r=N\sum_{t,S:r\in S}x_{t,S}\), \(C(x)=\sum_{r\in R}y_rc_r(y_r)\), and \(\mathrm{OPT}=\min_x C(x)\). The approximation input is binary-rational \(0<\epsilon<1\); the required allocation satisfies \(C(x)\le(1+\epsilon)\mathrm{OPT}\), including when \(\mathrm{OPT}=0\). Let \(L\) be the total encoded input length.

Does this problem admit a \((1+\epsilon)\)-approximation in time polynomial in \(m,\tau,L,\log N,1/\epsilon\) and the allocation-oracle running time, or is achieving such an approximation NP-hard even when allocation-oracle calls take polynomial time?

For discrete unit commodities choosing one allocation each, no polynomial-time \(\alpha\)-approximation exists for \(1\le\alpha<52/51\) unless \(\mathrm P=\mathrm{NP}\). [Bjelde (2018)](https://d-nb.info/1159631778/34).
For related continuous problems, Grigoriadis and Khachiyan give relative-accuracy approximation schemes for convex block resource sharing using block optimization subproblems; this is a neighboring formulation, rather than a verified classification of the allocation problem stated here. [Grigoriadis–Khachiyan (1994)](https://epubs.siam.org/doi/10.1137/0804004).

Modeling choices made when packaging the task

  • Specified N as a positive binary-encoded integer, matching its role as the scale corresponding to a discrete population count.
  • Required every feasible allocation family to be nonempty; retained empty resource subsets when explicitly feasible, as the discrete definition permits.
  • Specified rational cost coefficients and a binary-rational approximation parameter between zero and one.
  • Made implicit-family access precise through nonnegative linear minimization, with oracle time and query bit lengths included in the complexity accounting.
  • Specified the computational representation of an allocation as its nonzero rational masses and corresponding feasible sets.
  • Retained the multiplicative guarantee at zero optimum, without imposing an unsupported positive-cost promise.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The problem admits the requested approximation scheme. This holds with the stated nonnegative-weight allocation oracles. The algorithm returns an exactly feasible rational allocation and handles \(\mathrm{OPT}=0\) exactly.

Here is a proof, including oracle access, allocation recovery, and bit complexity.

  • Zero optimum and a positive lower bound.

Write \(\chi(S)\in\{0,1\}^m\) for the incidence vector of \(S\), and let \(f_r(y)=a_ry^2+b_ry\). Each \(f_r\) is nonnegative and nondecreasing on nonnegative arguments.

If \(m=0\), every feasible family consists of the empty set, and assigning mass \(\mu_t\) to it solves the problem. Henceforth assume \(m\ge1\).

Define \(Z=\{r:a_r>0\text{ or }b_r>0\}\). For each type, query its oracle with \(w_r=1\) on \(Z\) and \(w_r=0\) elsewhere. This minimizes \(|S\cap Z|\).

If every returned minimum is zero, assign each type’s entire mass to its returned set. All loads on \(Z\) vanish, so the allocation has cost zero.

Otherwise, some type \(t_0\) must use at least one resource of \(Z\) in every feasible allocation. Consequently, every allocation satisfies
\(\sum_{r\in Z}y_r\ge N\mu_{t_0}\).
In particular, zero cost is impossible.

In this latter case, define
\(\mu_{\min}=\min_t\mu_t\),
\(d=\min\bigl(\{a_r:a_r>0\}\cup\{b_r:b_r>0\}\bigr)\), and
\(\beta=d(\mu_{\min}/m)^2\).

Some \(r\in Z\) has
\(y_r\ge N\mu_{t_0}/|Z|\ge\mu_{\min}/m\).
Put \(q=\mu_{\min}/m\), so \(0<q\le1\). If \(a_r>0\), then \(f_r(y_r)\ge dq^2\). If \(a_r=0\), then \(b_r>0\), and \(f_r(y_r)\ge dq\ge dq^2\). Thus every feasible allocation satisfies
\(\displaystyle C(x)\ge\beta>0\).

The rational number \(\beta\) has polynomial encoding length. We now work only in this positive-optimum case.

  • Converting nonnegative oracle access into signed linear optimization.

For each type, form its upward closure
\(\mathcal U_t=\{T\subseteq R:\text{some }S\in\mathcal S_t\text{ satisfies }S\subseteq T\}\),
and the polytope
\(Q_t=\operatorname{conv}\{\chi(T):T\in\mathcal U_t\}\).

Although \(\mathcal U_t\) need not be enumerated, linear optimization over \(Q_t\) with arbitrary signed rational weights is available using one permitted oracle query.

Indeed, given signed weights \(w\), put
\(B=\{r:w_r<0\}\) and \(w_r^+=\max\{w_r,0\}\).
Query the original oracle with \(w^+\), obtaining \(S^\star\), and return
\(T^\star=S^\star\cup B\).

To verify optimality, take any \(T\in\mathcal U_t\) and choose \(S\in\mathcal S_t\) contained in \(T\). Then
\(\displaystyle w\cdot\chi(T) \ge \sum_{r\in B}w_r+\sum_{r\in S}w_r^+ \ge \sum_{r\in B}w_r+\sum_{r\in S^\star}w_r^+. \)
The returned \(T^\star\) attains the last expression. Linear optimization over a convex hull has the same minimum as over its generating points, proving the assertion.

Passing to these upward closures preserves the minimum social cost. Define
\(\displaystyle F(u)=\sum_r f_r\!\left(N\sum_t\mu_tu_{t,r}\right)\)
on \(\prod_tQ_t\).

Every original allocation gives a point in this product by taking its conditional incidence marginals. Conversely, decompose each \(u_t\in Q_t\) into incidence vectors of sets in \(\mathcal U_t\), and replace each such set by a contained member of \(\mathcal S_t\). This produces an original allocation whose resource loads are no larger. Monotonicity of the functions \(f_r\) therefore gives
\(\displaystyle \min_{u\in\prod_tQ_t}F(u)=\mathrm{OPT}\).

  • The precise polyhedral algorithmic results used.

We use the standard rational-polyhedron oracle theorems: given dimension and a bound on the encoding length of individual defining inequalities, strong linear optimization and strong separation are polynomial-time equivalent; strong separation permits exact rational linear programming. For a bounded rational polytope, a rational point can also be decomposed in oracle-polynomial time into a convex combination of at most one more than its ambient dimension vertices. These statements include lower-dimensional polytopes, with polynomial query and output bit lengths. See Grötschel–Lovász–Schrijver, [*Rational Polyhedra*](https://link.springer.com/chapter/10.1007/978-3-642-97881-4_7), particularly Sections 6.4–6.5 and Theorem 6.5.11.

Their hypotheses hold here. Each \(Q_t\) is nonempty, bounded, and has only vertices in \(\{0,1\}^m\). The standard vertex-to-facet encoding bound, obtained from rational linear algebra and determinant bounds, gives a polynomial bound in \(m\) on its individual defining inequalities and affine-hull equations. This bound requires no enumeration of vertices or facets.

Step 2 therefore supplies polynomial-time strong separation for every \(Q_t\), relative to the allocation oracle.

  • A polynomial-size piecewise-linear upper approximation.

Let \(A=\sum_ra_r\), and choose
\(\displaystyle h=\min\left\{1,\frac{\epsilon\beta}{A+1}\right\}\).

Construct knots starting at \(0,h\), then repeatedly multiply the positive knot by \(1+\epsilon\), clipping the last knot to \(N\). This is possible because \(h\le1\le N\). Write them as
\(0=t_0<t_1<\cdots<t_K=N\).

Let \(g_r\) interpolate \(f_r\) linearly between consecutive knots. On an interval \([u,v]\), its chord is
\(\displaystyle \ell_{r,u,v}(y)=\bigl(a_r(u+v)+b_r\bigr)y-a_ruv\),
and direct subtraction gives
\(\displaystyle \ell_{r,u,v}(y)-f_r(y)=a_r(y-u)(v-y)\ge0\).

On the first interval,
\(g_r(y)-f_r(y)\le a_rh^2/4\).

On every other interval, \(v-u\le\epsilon u\) and \(y\ge u\). Hence
\(\displaystyle g_r(y)-f_r(y) \le\frac{a_r\epsilon^2u^2}{4} \le\frac{\epsilon}{4}f_r(y), \)
using \(\epsilon<1\).

Summing these estimates, for any \(y\in[0,N]^m\),
\(\displaystyle \sum_rf_r(y_r) \le\sum_rg_r(y_r) \le\left(1+\frac{\epsilon}{4}\right)\sum_rf_r(y_r) +\frac{\epsilon\beta}{4}. \)
The additive term follows from
\(Ah^2/4\le Ah/4\le\epsilon\beta/4\).

The chord slopes are nonnegative and nondecreasing. Thus \(g_r\) is convex and nondecreasing, and on \([0,N]\) it equals the maximum of its chord lines.

  • Solving the surrogate and recovering an allocation.

Solve the following rational linear program. Its variables are \(u_t\in\mathbb R^m\) and \(z_r\in\mathbb R\), and its objective is \(\min\sum_rz_r\). Its constraints are
\(u_t\in Q_t\) for every type,
\(0\le z_r\le f_r(N)+1\), and
\(\displaystyle z_r\ge\ell_{r,t_j,t_{j+1}}\!\left(N\sum_t\mu_tu_{t,r}\right) \)
for every resource and knot interval.

This polytope is nonempty and bounded. Since \(u_{t,r}\in[0,1]\), all represented loads lie in \([0,N]\). Also \(g_r(y)\le f_r(N)\) on this interval, so the upper bounds on \(z_r\) do not exclude an optimal epigraph solution.

Its separation oracle checks the explicit inequalities and uses Step 3 to check membership in each \(Q_t\). Exact oracle linear programming therefore returns a rational optimum \(\widehat u\) minimizing
\(\displaystyle G(u)=\sum_rg_r\!\left(N\sum_t\mu_tu_{t,r}\right)\).

For each type, use the constructive decomposition theorem to obtain
\(\displaystyle \widehat u_t=\sum_{j=1}^{k_t}\lambda_{t,j}\chi(T_{t,j}), \qquad k_t\le m+1,\quad \lambda_{t,j}\ge0,\quad \sum_j\lambda_{t,j}=1, \)
with rational coefficients and \(T_{t,j}\in\mathcal U_t\).

Recover an original feasible set contained in each \(T_{t,j}\) by querying the allocation oracle with weight zero inside \(T_{t,j}\) and weight one outside it. Because \(T_{t,j}\in\mathcal U_t\), the minimum is zero; the returned \(S_{t,j}\) therefore satisfies \(S_{t,j}\subseteq T_{t,j}\).

Assign mass \(\mu_t\lambda_{t,j}\) to \(S_{t,j}\), merging duplicates and discarding zero masses. This is exactly feasible, uses at most \(\tau(m+1)\) nonzero masses, and satisfies
\(C(x)\le F(\widehat u)\).

Let \(u^\star\) minimize \(F\) over the product polytope. Such a minimizer exists by compactness and continuity. Combining the preceding results,
\(\displaystyle C(x) \le F(\widehat u) \le G(\widehat u) \le G(u^\star) \le\left(1+\frac{\epsilon}{4}\right)\mathrm{OPT} +\frac{\epsilon\beta}{4} \le\left(1+\frac{\epsilon}{2}\right)\mathrm{OPT} \le(1+\epsilon)\mathrm{OPT}. \)

  • Running time and query bit lengths.

The knot count satisfies
\(\displaystyle K=O\!\left(1+\frac{\log(N/h)}{\epsilon}\right)\),
because \(\log(1+\epsilon)\ge\epsilon/2\). The encoding length of \(h\), and therefore \(\log(1/h)\), is polynomial in the input length and \(\log(m+1)\).

Each knot is obtained by at most \(K\) rational multiplications. Thus all knots, chord coefficients, and linear-program coefficients have encoding lengths polynomial in \(m,\tau,L,\log N,1/\epsilon\). The linear program has \(m\tau+m\) variables and \(O(mK)\) explicit inequalities.

The rational-polyhedral algorithms make polynomially many allocation-oracle calls, each with polynomial query bit length. If oracle inputs are required to be dyadic rationals, multiply each queried nonnegative rational vector by the product of its denominators. This produces integer weights of polynomial bit length and preserves its minimizers.

More precisely, for some polynomial \(p\) in the stated parameters, the total time is bounded by
\(p\bigl(1+T_{\mathrm{oracle}}(p)\bigr)\),
where \(T_{\mathrm{oracle}}(b)\) bounds allocation-oracle time on queries of bit length at most \(b\). The output masses also have polynomial encoding length.

The divisible allocation model therefore admits an oracle-polynomial-time \((1+\epsilon)\)-approximation scheme. The discrete inapproximability premise does not transfer to this convexified feasible domain.
