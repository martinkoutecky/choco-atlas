The continuous mirror question, as graded

Given a finite set of agent types \(T\) with mass distribution \(\mu\), finite item types \(E\) with per-capita supplies \(q_e\), additive values \(v_t(e)\) satisfying \(\sum_e q_e v_t(e)=1\), and an adversarial online stream of batches of identical copies, irrevocably assign each copy to an individual agent while every bundle remains integral; determine the supremum worst-case \(r\) such that almost every type-\(t\) agent receives \(v_t(B)\ge r\,\MMS^\infty_t\), where \(\MMS^\infty_t\) is the high-multiplicity MMS obtained from distributions of integral bundles \(B\in\mathbb{Z}_{\ge 0}^{E}\) with expectation \(q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) agent types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Realize each type as an atomless interval of length \(\mu_t\), with total population measure \(\lambda\).
An instance has \(m=|E|\) good types, positive binary-rational per-capita supplies \(q_e\), and nonnegative binary-rational additive values satisfying \(\sum_e q_e v_t(e)=1\) for every \(t\).
Initially the algorithm knows the society and this normalization. It does not know \(E\), \(q\), future values, or the number of batches. An adaptive adversary supplies a finite stream of batches \((e,b)\), with positive rational copy mass \(b\), revealing \((v_t(e))_{t\in T}\) when \(e\) first appears; batch masses for \(e\) sum to \(q_e\).
Every agent starts with the empty integral bundle. On receiving \((e,b)\), a deterministic algorithm immediately chooses a measurable integer increment \(k(x)\geq0\) with \(\int k(x)\,d\lambda(x)=b\), adding \(k(x)\) whole copies of \(e\) to agent \(x\). All copies must be assigned, and previous assignments cannot change.
Define \(\mathsf{MMS}^{\infty}_t=\sup_{D:\,\mathbb E_D B=q}\operatorname*{ess\,inf}_{B\sim D}v_t(B)\), where \(D\) ranges over probability distributions on \(\mathbb Z_{\geq0}^{E}\). An algorithm guarantees \(r\in[0,1]\) if every admissible stream ends with \(v_t(B(x))\geq r\mathsf{MMS}^{\infty}_t\) for almost every type-\(t\) agent, for every \(t\); zero benchmarks impose no additional requirement.
Let \(r^*\) be the supremum of guarantees achievable by deterministic online algorithms uniformly over all such instances. State any running times in \(m\), \(\tau\), total binary input length \(L\), and the number of batches \(s\).
What is \(r^*\)? In particular, is \(r^*=0\), or can a deterministic online algorithm guarantee a uniform \(r>0\)?
For finite societies with normalized additive goods values and only arrival-time information, no deterministic online algorithm guarantees a positive MMS competitive ratio, even with three agents; with two agents the optimal ratio is \(1/2\). [Verified source](https://proceedings.mlr.press/v202/zhou23a/zhou23a.pdf)
No result settling this exact atomless-society problem with integral individual bundles was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total population mass to one and represented each positive-mass type by an atomless interval, making individual integral bundles and almost-everywhere guarantees precise.
  • Specified nonnegative rational goods values and positive rational supplies; omitted zero-supply item types.
  • Interpreted supplies and valuations as instance data revealed through the stream, rather than advance information, following the discrete online information model.
  • Specified deterministic algorithms and adaptive adversaries, with finite streams of positive rational batch masses.
  • Interpreted a batch as copy mass allocated through measurable integer increments, allowing multiple whole copies per individual while conserving the entire batch.
  • Defined the high-multiplicity benchmark using the supremum of essential minimum bundle values over distributions with exact expectation q.
  • Interpreted the requested worst-case supremum as a uniform guarantee over all admissible support sizes and instances, without a running-time restriction.

Result

The optimal uniform guarantee is \(r^*=0\). Every positive ratio fails even with \(\tau=1\), \(m=3\), and \(s=3\), using only dyadic supplies and values.

1. A counting lemma

Let the population have measure \(1\), and let \(k(x)\) be a measurable nonnegative integer function satisfying \(\int k\,d\lambda=1\).

Fix \(r>0\) and an integer \(K>4/r\). Then some \(j\in\{1,\ldots,K\}\) satisfies

\[ \lambda\{x:k(x)\ge r2^j\}<2^{-j-1}. \]

Indeed, the sets \(H_j=\{x:k(x)\ge r2^j\}\) are nested. Pointwise,

\[ r\sum_{j=1}^{K}2^{j-1}\mathbf 1_{H_j}(x)\le k(x). \]

To verify this inequality, if the largest satisfied index is \(J\), the sum is \(r(2^J-1)\le k(x)\); if no index is satisfied, it is zero. Integrating gives

\[ 1\ge r\sum_{j=1}^{K}2^{j-1}\lambda(H_j). \]

If every \(\lambda(H_j)\) were at least \(2^{-j-1}\), the right-hand side would be at least \(rK/4>1\), a contradiction.

2. The adversarial stream

Fix any deterministic online algorithm and any proposed guarantee \(r>0\). Choose an integer \(K>4/r\), and set \(\varepsilon=2^{-(K+1)}\).

There is one agent type of mass \(1\). The first batch consists of copy mass \(1\) of good \(e_1\), whose value is \(\varepsilon\). Let \(k(x)\) denote the algorithm’s allocation of this batch. Feasibility implies \(\int k\,d\lambda=1\).

Apply the lemma and choose an index \(j\) for which

\[ \lambda\{x:k(x)\ge r2^j\}<2^{-j-1}. \]

Write \(\delta=2^{-j}\). Complete the stream with the following two batches:

| Good | Copy mass, hence supply | Value |
|---|---:|---:|
| \(e_1\) | \(1\) | \(\varepsilon\) |
| \(e_2\) | \(1-\delta\) | \(1\) |
| \(e_3\) | \((\delta-\varepsilon)/2\) | \(2\) |

These data are admissible. All supplies are positive because \(j\le K\) gives \(\delta>\varepsilon\). Every supply and value is dyadic, and normalization holds exactly:

\[ \sum_e q_e v(e) =\varepsilon+(1-\delta)+2\frac{\delta-\varepsilon}{2} =1. \]

The stream contains exactly three batches, each introducing a different good.

3. A positive benchmark certificate

Define \(a_j=\varepsilon2^j\). Since \(j\le K\), we have \(0<a_j\le 1/2\).

We exhibit a distribution \(D\) feasible for the benchmark. First choose a pair of integer counts as follows:

\[ (B_{e_1},B_{e_2})= \begin{cases} (2^j,0),&\text{with probability }\delta,\\ (0,1),&\text{with probability }1-\delta. \end{cases} \]

Independently, let \(B_{e_3}\) be a Bernoulli random variable with success probability \(q_{e_3}=(\delta-\varepsilon)/2\). This probability lies strictly between \(0\) and \(1\).

The expected counts are exactly the supplies:

\[ \mathbb E_D B_{e_1}=\delta2^j=1,\qquad \mathbb E_D B_{e_2}=1-\delta,\qquad \mathbb E_D B_{e_3}=q_{e_3}. \]

Every bundle in the first branch has value at least \(\varepsilon2^j=a_j\). Every bundle in the second branch has value at least \(1\ge a_j\). Therefore

\[ \mathsf{MMS}^{\infty}\ge a_j>0. \]

This is a lower bound on the benchmark, which suffices for the impossibility proof.

4. A positive mass of agents fails

Let \(h(x)\) be the total number of copies of \(e_2\) and \(e_3\) assigned to agent \(x\). Since these are integer copies, every agent receiving any later good contributes at least one to \(h(x)\). Consequently,

\[ \lambda\{x:h(x)\ge1\} \le\int h\,d\lambda =(1-\delta)+\frac{\delta-\varepsilon}{2} =1-\frac{\delta+\varepsilon}{2}. \]

Thus the set \(U=\{x:h(x)=0\}\) of agents receiving no later goods has measure at least \((\delta+\varepsilon)/2\).

On the other hand, the selected index satisfies

\[ \lambda(H_j)<\frac{\delta}{2}, \qquad H_j=\{x:k(x)\ge r2^j\}. \]

It follows that

\[ \lambda(U\setminus H_j) \ge\lambda(U)-\lambda(H_j) >\frac{\varepsilon}{2}>0. \]

Every agent in \(U\setminus H_j\) finishes with only copies of \(e_1\), and has utility

\[ v(B(x))=\varepsilon k(x) <r\varepsilon2^j =ra_j \le r\mathsf{MMS}^{\infty}. \]

Hence the required guarantee fails on a set of positive population measure. Since the algorithm and \(r>0\) were arbitrary, no deterministic online algorithm guarantees a positive uniform ratio.

5. Achievability of zero and input size

For every type, normalization gives \(\mathbb E_D v_t(B)=1\) for every benchmark-feasible distribution. Hence \(0\le\mathsf{MMS}^{\infty}_t\le1\). Nonnegative utilities therefore always satisfy the guarantee for \(r=0\).

A feasible deterministic allocator exists: identify the population with \([0,1)\), and, for each arriving copy mass \(b\), write \(b=n+f\), where \(n=\lfloor b\rfloor\) and \(0\le f<1\). Assign the increment

\[ k(x)=n+\mathbf 1_{[0,f)}(x). \]

This is integer-valued, measurable, and integrates to \(b\).

The adversarial instance has \(\tau=1\), \(m=s=3\), and total binary input length \(L=O(K)\). The impossibility applies without any running-time restriction. With a global interval representation, the zero-guarantee allocator uses \(O(\tau+s)\) rational arithmetic operations; a conservative bit-complexity bound is \(O((\tau+s)L^2+L)\).

Therefore \(r^*=0\).
