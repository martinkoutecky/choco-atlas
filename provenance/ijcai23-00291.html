The continuous mirror question, as graded

Given \(m\ge2\) issues \(I\), ranking types \(\mathcal T\subseteq L(I)\), rational masses \(\mu_t\ge0\) summing to \(1\), and an issue \(a\), choose \(\nu\) with \(0\le\nu_t\le\mu_t\) to maximize \(D(\nu)\), where \(D(\nu)=0\) if \(\nu=0\) or \(\nu=\mu\), and otherwise \(D(\nu)=|B(a,\nu)-B(a,\mu-\nu)|\), with \(B(a,z)=\frac{\sum_t z_t(m-\operatorname{rank}_t(a))}{(m-1)\sum_t z_t}\). Return an optimal mass vector \(\nu\) and the optimum value.

Packaged proof task (what the prover saw — nothing else)

Given a set \(I\) of \(m\ge2\) issues and a designated issue \(a\in I\), a society is given by its support: a list \(\mathcal T\) of \(\tau\) distinct strict rankings with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number \(m!\) of possible rankings; \(L\) is the total input bit length.
A subpopulation is any real mass vector \(\nu\) satisfying \(0\le\nu_t\le\mu_t\); types may be split arbitrarily. For nonzero nonnegative \(z\), define the normalized Borda average \(B(a,z)=\frac{\sum_t z_t(m-\operatorname{rank}_t(a))}{(m-1)\sum_t z_t}\), with rank \(1\) best.
Set \(D(\nu)=0\) when \(\nu=0\) or \(\nu=\mu\), and otherwise \(D(\nu)=|B(a,\nu)-B(a,\mu-\nu)|\). The optimization problem returns an optimal mass vector and its exact value; any maximizer is acceptable.

Is this continuous optimization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For an explicitly listed finite population, maximizing the absolute difference of the two subpopulations’ normalized Borda averages is polynomial-time solvable ([Colley et al., 2023](https://www.ijcai.org/proceedings/2023/0291.pdf)).
No result settling exactly the divisible-mass problem above was identified in the literature search.

  • Removed zero-mass types from the input list so that the representation lists exactly the positive-mass support.
  • Made the feasible mass vectors real-valued, expressing arbitrary divisibility of each type’s mass.
  • Specified exact optimization and allowed any maximizer, since no output precision or tie-breaking convention was given.
  • Defined L as the total input bit length.

Result

The problem is polynomial-time solvable in \(m,\tau,L\). More strongly, an optimal mass vector can be chosen by a threshold on the designated issue’s Borda score: every type above the threshold is included in full, and every type below it is excluded.

The explicitly listed finite-population case appears in Proposition 4 of [Colley et al. (2023)](https://www.ijcai.org/proceedings/2023/0291.pdf). We prove the divisible-mass result directly, including attainment and exact bit complexity.

1. Reduce to score levels

For each type, define its normalized score
\(x_t=(m-\operatorname{rank}_t(a))/(m-1)\).
Let \(b=\sum_t\mu_t x_t\) be the society’s average.

For a feasible vector \(\nu\), put \(p=\sum_t\nu_t\) and \(s=\sum_t\nu_t x_t\). When \(0<p<1\),

\(B(a,\nu)-B(a,\mu-\nu)=\dfrac{s}{p}-\dfrac{b-s}{1-p}=\dfrac{s-bp}{p(1-p)}.\)

Replacing \(\nu\) by its complement \(\mu-\nu\) reverses this signed difference and preserves its absolute value. Consequently, to bound every feasible objective value, it suffices to consider vectors with \(s-bp\ge0\).

Let the distinct scores occurring in the support be
\(c_1>c_2>\cdots>c_k\).
Define their total masses and cumulative masses by

\(w_i=\sum_{t:x_t=c_i}\mu_t,\qquad Q_j=\sum_{i=1}^{j}w_i,\qquad Q_0=0.\)

Every \(w_i\) is positive, \(Q_k=1\), and \(k\le\min(m,\tau)\).

If \(k=1\), both nonempty subpopulations always have the same score. Thus every feasible vector has objective value zero, and returning \(\nu=0\) solves the problem. Assume henceforth that \(k\ge2\).

2. At fixed mass, select the highest scores first

Write \(y_i=\sum_{t:x_t=c_i}\nu_t\). Then
\(0\le y_i\le w_i\), \(p=\sum_i y_i\), and \(s=\sum_i c_i y_i\).

Conversely, every vector satisfying these group-mass constraints is realizable: for types with score \(c_i\), set
\(\nu_t=(y_i/w_i)\mu_t\).

Fix \(p\in(0,1)\), and choose \(j\) such that \(Q_{j-1}\le p\le Q_j\). Define

\(y_i^*=\begin{cases} w_i,&i<j,\\ p-Q_{j-1},&i=j,\\ 0,&i>j. \end{cases}\)

This feasible allocation maximizes the score sum at mass \(p\). Indeed, any other feasible allocation \(y\) of the same mass satisfies

\(\sum_i c_i(y_i^*-y_i)=\sum_i(c_i-c_j)(y_i^*-y_i)\ge0.\)

The equality follows from \(\sum_i(y_i^*-y_i)=0\). For \(i<j\), both factors in the corresponding term are nonnegative. For \(i>j\), both factors are nonpositive. The term with \(i=j\) vanishes.

Therefore the largest score sum at mass \(p\) is

\(U(p)=\sum_{i<j}w_i c_i+c_j(p-Q_{j-1}).\)

After orienting a subpopulation so that its signed difference is nonnegative, its objective value is bounded by

\(D(\nu)\le F(p):=\dfrac{U(p)-bp}{p(1-p)}.\)

3. Splitting a score level cannot improve the optimum

On the interval \(Q_{j-1}\le p\le Q_j\), define

\(d_j=\sum_{i<j}w_i(c_i-c_j),\qquad e_j=\sum_{i>j}w_i(c_j-c_i).\)

Both quantities are nonnegative. Moreover,
\(U(p)=c_jp+d_j\).
Using \(b=\sum_iw_ic_i\) and \(\sum_iw_i=1\), we obtain
\(e_j=c_j-b+d_j\).
Hence

\(F(p)=\dfrac{(c_j-b)p+d_j}{p(1-p)} =\dfrac{d_j}{p}+\dfrac{e_j}{1-p}.\)

We examine all intervals, including those adjacent to the excluded denominator endpoints.

Interior intervals. For \(2\le j\le k-1\), the entire interval lies inside \((0,1)\), and

\(F''(p)=\dfrac{2d_j}{p^3}+\dfrac{2e_j}{(1-p)^3}\ge0.\)

Thus \(F\) is convex there. A convex function on a closed interval is bounded above by the larger endpoint value: its value at any intermediate point is at most the corresponding convex combination of its endpoint values. Therefore,

\(F(p)\le\max\{F(Q_{j-1}),F(Q_j)\}.\)

First interval. Here \(d_1=0\) and
\(e_1=c_1-b>0\), because some positive mass has a strictly smaller score. Consequently,

\(F(p)=\dfrac{e_1}{1-p}\le F(Q_1) \quad\text{for }0<p\le Q_1.\)

Last interval. Here \(e_k=0\) and
\(d_k=b-c_k>0\). Consequently,

\(F(p)=\dfrac{d_k}{p}\le F(Q_{k-1}) \quad\text{for }Q_{k-1}\le p<1.\)

Together these inequalities prove that

\(F(p)\le\max_{1\le j<k}F(Q_j)\quad\text{for every }p\in(0,1).\)

4. A finite family attains the global optimum

For each \(j\in\{1,\ldots,k-1\}\), define the threshold vector

\(\nu_t^{(j)}=\begin{cases} \mu_t,&x_t\ge c_j,\\ 0,&x_t<c_j. \end{cases}\)

Its mass is \(Q_j\), and its score sum is \(U(Q_j)\). Every selected score is strictly larger than every complementary score, so its signed difference is positive. Therefore,

\(D(\nu^{(j)})=F(Q_j).\)

Every nontrivial feasible vector is bounded by the largest of these candidate values, by Sections 2–3. The two special vectors \(\nu=0\) and \(\nu=\mu\) have value zero, whereas every threshold candidate has positive value.

It follows that the maximum exists and is exactly

\(\max_\nu D(\nu)= \max_{1\le j<k} \left( \dfrac{\sum_{i\le j}w_i c_i}{Q_j} - \dfrac{\sum_{i>j}w_i c_i}{1-Q_j} \right).\)

In particular, arbitrary real splitting offers no improvement over this family of at most \(\min(m,\tau)-1\) candidates.

5. Exact algorithm and bit complexity

The algorithm computes the designated issue’s score in each listed ranking, sorts and groups the types by score, and evaluates every threshold between consecutive distinct score levels. It returns a maximizing threshold vector and its exact value.

To verify polynomial bit complexity, write each input mass as
\(\mu_t=u_t/v_t\), with positive integers \(u_t,v_t\), and let

\(H=\prod_t v_t,\qquad M_t=H\mu_t,\qquad r_t=m-\operatorname{rank}_t(a).\)

Each \(M_t\) is an integer, and \(\sum_tM_t=H\). The bit length of \(H\) is at most a constant plus the sum of the input denominator bit lengths, hence is \(O(L)\).

For a threshold’s selected type set \(J\), define

\(A=\sum_{t\in J}M_t,\qquad C=\sum_{t\in J}M_t r_t,\qquad C_{\mathrm{tot}}=\sum_tM_t r_t.\)

Its exact objective value is

\(\dfrac{HC-A C_{\mathrm{tot}}}{(m-1)A(H-A)}.\)

The denominator is positive because \(0<A<H\). Since
\(A\le H\) and \(C,C_{\mathrm{tot}}\le(m-1)H\), all integers in this expression have bit length \(O(L+\log m)\). Candidate values can be compared exactly by cross multiplication; the final fraction can be reduced by the Euclidean algorithm. These operations take polynomial time.

Computing scores requires scanning the listed rankings; sorting requires \(O(\tau\log\tau)\) score comparisons; prefix sums evaluate all candidates using \(O(\tau)\) additional arithmetic operations. The output vector consists solely of zeros and original input masses, so it also has polynomial encoding length.

Thus both an optimal mass vector and the exact optimum are computable in polynomial time in \(m,\tau,L\).
