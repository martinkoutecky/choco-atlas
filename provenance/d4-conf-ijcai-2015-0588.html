The continuous mirror question, as graded

Given a finite variable set \(V\), a feasible-outcome constraint \(\Gamma\), complete goalbases \(G_1,\ldots,G_\tau\) with positive rational masses \(\mu_1,\ldots,\mu_\tau\) summing to \(1\), and a rational threshold \(\gamma\), is there an interpretation \(\sigma\models\Gamma\) such that \(\sum_{t=1}^{\tau}\mu_tG_t(\sigma)\ge\gamma\)?

Packaged proof task (what the prover saw — nothing else)

Let \(V\) be a finite set of Boolean variables, with \(m=|V|\). A goalbase \(G\) is an explicitly listed finite set of pairs \(\langle\varphi,w\rangle\), where \(\varphi\) is a propositional formula over \(V\) and \(w\in\mathbb{Q}\) may have either sign or be zero; define \(G(\sigma)=\sum_{\langle\varphi,w\rangle\in G:\,\sigma\models\varphi}w\).
A society is given by its support: the list of \(\tau\geq1\) distinct goalbase types \(G_1,\ldots,G_\tau\) with positive binary rational masses \(\mu_1,\ldots,\mu_\tau\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; each goalbase is supplied in full.
The input also contains a satisfiable propositional constraint \(\Gamma\) over \(V\) and a binary rational threshold \(\gamma\in\mathbb{Q}\). Outcomes are Boolean interpretations \(\sigma:V\to\{\top,\bot\}\) satisfying \(\Gamma\).
Let \(L\) be the total input bit length, including formulas, weights, masses, and threshold; state running times in \(m,\tau,L\).

Is deciding whether there exists a feasible interpretation \(\sigma\) with \(\sum_{t=1}^{\tau}\mu_tG_t(\sigma)\geq\gamma\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite list of agents with unweighted utilitarian aggregation, the corresponding threshold decision problem is NP-complete, even with one agent and \(\Gamma=\top\), both when all formula weights are positive and when all are negative.
No separate result for the distribution-over-types formulation is supplied.

Modeling choices made when packaging the task

  • Interpreted undefined 'complete goalbases' as goalbases supplied in full as explicit finite sets of weighted formulas; imposed no additional semantic completeness condition.
  • Required the feasible-outcome constraint to be satisfiable, as in the discrete scenario definition.
  • Allowed arbitrary signed rational formula weights, including zero, and an unrestricted rational threshold.
  • Took interpretations over all of V, with every goalbase formula and the constraint using only variables in V, so constraint-only variables are assigned.
  • Represented support types as distinct goalbases with positive mass, and defined L as the total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The decision problem is NP-complete, even when the support size is \(\tau=1\), the constraint is \(\Gamma=\top\), and all formula weights are strictly positive. It remains NP-complete when all formula weights are strictly negative.

Thus a polynomial-time algorithm in \(m,\tau,L\) exists if and only if \(\mathrm{P}=\mathrm{NP}\).

Membership in NP and running time

A certificate is an interpretation \(\sigma\), represented by \(m\) Boolean values. We verify that \(\sigma\models\Gamma\), evaluate the explicitly listed goal formulas, and compare the resulting utility with \(\gamma\).

The rational comparison can be performed exactly with polynomial bit complexity. Write the weights, masses, and threshold as

\(w_{t,j}=a_{t,j}/b_{t,j}\), \(\mu_t=c_t/d_t\), and \(\gamma=e/f\),

where all denominators are positive. Let \(N\) be the total number of listed goal pairs and define

\(D=f\left(\prod_{t=1}^{\tau}d_t\right)\left(\prod_{t,j}b_{t,j}\right)\).

For every pair \((t,j)\), the integer \(d_tb_{t,j}\) divides \(D\). Consequently, the required comparison is equivalent to the integer comparison

\(\displaystyle \sum_{t,j:\,\sigma\models\varphi_{t,j}} a_{t,j}c_t\,\frac{D}{d_tb_{t,j}}\ \geq\ e\,\frac{D}{f}.\)

The total bit length of all input denominators is at most \(L\), so \(D\) has \(O(L)\) bits. Each summand also has \(O(L)\) bits: its numerator factors and \(D\) each have bit length bounded by the input length. Summing at most \(N\leq L\) terms adds only \(O(\log L)\) bits. Thus every integer used in this calculation has \(O(L)\) bits.

There are \(O(L)\) arithmetic operations. Using elementary integer arithmetic, they take \(O(L^3)\) bit operations. Formula evaluation is polynomial as well. A conservative total verifier bound is \(O((m+\tau+L)^3)\).

This proves membership in NP. Exhaustively checking all interpretations also gives a deterministic upper bound of \(O(2^m(m+\tau+L)^3)\).

NP-hardness with positive weights

We give a polynomial-time reduction from propositional satisfiability.

Given a propositional formula \(F\), use its variables as \(V\), and construct the instance

\(\tau=1,\qquad \mu_1=1,\qquad G_1=\{\langle F,1\rangle\},\qquad \Gamma=\top,\qquad \gamma=1.\)

This is a valid society: its sole mass is positive and sums to \(1\). The constraint is satisfiable, and the sole formula weight is strictly positive.

For any interpretation \(\sigma\), the aggregate utility is \(1\) if \(\sigma\models F\), and \(0\) otherwise. Therefore,

\(\displaystyle \exists\sigma\models\Gamma:\ \sum_{t=1}^{\tau}\mu_tG_t(\sigma)\geq\gamma \quad\Longleftrightarrow\quad F\text{ is satisfiable}.\)

The construction has size \(O(|F|)\). Since propositional satisfiability is NP-complete, this establishes NP-hardness.

NP-hardness with negative weights

For the strictly negative restriction, instead construct

\(\tau=1,\qquad \mu_1=1,\qquad G_1=\{\langle\neg F,-1\rangle\},\qquad \Gamma=\top,\qquad \gamma=0.\)

If \(\sigma\models F\), the sole goal formula is false, so the utility is \(0\). If \(\sigma\not\models F\), the sole goal formula is true, so the utility is \(-1\). Hence a feasible interpretation has utility at least \(0\) exactly when it satisfies \(F\).

This is again a polynomial-time reduction satisfying every input requirement.

Why the support representation does not change hardness

The support representation permits a society containing exactly one type with mass \(1\). On such an instance, \(\sum_t\mu_tG_t(\sigma)=G_1(\sigma)\). It therefore contains the one-agent problem as a special case, without any encoding expansion. No separate hardness theorem for distributions over types is needed.
