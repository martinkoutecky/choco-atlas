The continuous mirror question, as graded

Given finitely many advertiser classes \(r\), rational class masses \(\mu_r\), finite rational type distributions \(h_r\), finite state spaces \(\Theta_r\), finite full-information experiments \(\tau_r\), and values \(v_r(t;\theta)\), with agents’ states independent, consider a unit-mass population with supply \(q\) indivisible items per unit mass and unit demand per agent. Compute an exact revenue-maximizing symmetric direct mechanism whose allocation probability and payment depend on an agent’s class, report, signal, and the aggregate measure of reports and signals. Require feasibility \(\int x\,d\nu\le q\) for every aggregate input measure \(\nu\), individual rationality under truthful full revelation, and ex-post IIC against truthful, fully revealing others for every type misreport and every garbling \(\lambda_r\) with \(\tau_r\succeq_{\mathrm{MPS}}\lambda_r\); maximize expected revenue per unit population mass. What is the complexity in the number of classes, support size, and input bit length?

Packaged proof task (what the prover saw — nothing else)

There are \(k\) publicly observable classes with positive binary-rational masses \(\mu_r\) summing to \(1\). Class \(r\) has a nonempty finite type set \(T_r\), a positive rational type distribution \(h_r\), a finite state set \(\Theta_r\), rational values \(v_r:T_r\times\Theta_r\to\mathbb Q\), and a finite rational experiment \(E_r\) over posterior beliefs \(\sigma\in\Delta(\Theta_r)\). Full revelation means revealing the observed posterior, not the underlying state; each class has at least one nondegenerate posterior of positive probability. Types are independent of information, and agents’ states and experiments are independent.

A society is given by its support: the list of its \(\tau\) positive-mass types \((r,t,\sigma)\), each with its mass \(\mu_r h_r(t)E_r(\sigma)\) as a binary rational. Here \(\tau\) is the support size, not the number of possible types or posterior reports. Set \(m=\sum_r|\Theta_r|\), and let \(L\) be the total input bit length.

Retain these promises. State rankings by value, including ties, are independent of type within each class. For each state, let \(a_1<\cdots<a_d\) be its distinct values under \(h_r\), with probabilities \(f_j\); define \(\phi_r(t;\theta)=a_j-(a_{j+1}-a_j)\sum_{\ell>j}f_\ell/f_j\) when \(v_r(t;\theta)=a_j\) and \(j<d\), and \(\phi_r(t;\theta)=a_d\) at the largest value. Require \(v_r(t;\theta)\ge v_r(t';\theta')\iff\phi_r(t;\theta)\ge\phi_r(t';\theta')\). Information sufficiency means that, for every fixed competing value and prior profile, the state-conditioned Myerson allocation probability is constant as the agent’s state ranges over the support of any observed posterior. Use uniform tie-breaking among positive maximal virtual values and no allocation when all virtual values are nonpositive.

A unit-mass nonatomic population has unit demand for identical indivisible items and rational supply \(q>0\) per unit mass. A symmetric direct mechanism specifies measurable allocation probabilities \(x_r(b,s;\nu)\in[0,1]\) and nonnegative payments \(p_r(b,s;\nu)\), depending only on class, type report \(b\in T_r\), posterior report \(s\in\Delta(\Theta_r)\), and the aggregate report measure \(\nu\). Require \(\int x_r(b,s;\nu)\,d\nu(r,b,s)\le q\) for every probability measure \(\nu\) with class marginal \(\mu\). An individual deviation leaves \(\nu\) unchanged.

An agent commits before observing information to any garbling with posterior output \(s\) satisfying \(\mathbb E[\sigma\mid s]=s\); its output law is \(\lambda\), denoted \(E_r\succeq_{\mathrm{MPS}}\lambda\). Type reports are fixed across signal realizations. Define \(V_r(t,s)=\sum_\theta s(\theta)v_r(t;\theta)\) and \(u_r(t;b,s,\nu)=x_r(b,s;\nu)V_r(t,s)-p_r(b,s;\nu)\).

For every nonnegative array \(\alpha\) with \(\sum_t\alpha_{rt}=\mu_r\), define the truthful aggregate \(\nu_\alpha(r,t,d\sigma)=\alpha_{rt}E_r(d\sigma)\); independent information is represented by these exact population frequencies. Ex-post IIC requires \(\mathbb E_{\sigma\sim E_r}u_r(t;t,\sigma,\nu_\alpha)\ge\mathbb E_{s\sim\lambda}u_r(t;b,s,\nu_\alpha)\) for every \(r,t,b,\alpha\) and every garbling. Truthful ex-post IR requires \(u_r(t;t,\sigma,\nu_\alpha)\ge0\) for every supported \(\sigma\). Maximize \(\int p_r(t,\sigma;\nu_0)\,d\nu_0\), where \(\nu_0(r,t,d\sigma)=\mu_r h_r(t)E_r(d\sigma)\). Computing a mechanism means producing a finite algorithmic description of its allocation and payment functions.

Is exact revenue maximization under these promises and constraints solvable in polynomial time in \(k,m,\tau,L\), or is it NP-hard?

For finitely many bidders, posterior averaging of state-conditioned Myerson outcomes is asserted to achieve optimal revenue and truthful ex-post equilibrium under information sufficiency, regular values, and regular virtual values; no computational complexity bound is asserted. [Wu, Badanidiyuru, and Xu](https://arxiv.org/pdf/2109.04888v2). No result settling this precise nonatomic problem was located in the literature search.

Result

Exact revenue maximization is polynomial-time solvable in \(k,m,\tau,L\).

The proof gives a polynomial-size rational linear program and an explicit extension of its optimal solution to every posterior report and aggregate measure. It uses the stated IR requirement: nonnegative payments at posterior reports outside the experiment’s support are permitted.

The construction works without the ranking, virtual-value, or information-sufficiency promises. It does not require the [finite-bidder Simulated-Myerson result](https://arxiv.org/pdf/2109.04888v2).

1. Notation

For each class \(r\), write its experiment as
\[ \]
\(E_r=\sum_{i=1}^{n_r}e_{ri}\delta_{\sigma_{ri}}\),
where the supported posteriors are distinct, \(e_{ri}>0\), and \(\sum_i e_{ri}=1\).

Let \(a_r=|T_r|\), and define

\(W_{rti}=V_r(t,\sigma_{ri})=\sum_{\theta\in\Theta_r}\sigma_{ri}(\theta)v_r(t;\theta)\),

and

\(w_{rti}=\mu_r h_r(t)e_{ri}\).

All these numbers are rational. Positivity of the type probabilities implies

\(\tau=\sum_r a_r n_r\).

We first optimize allocation and payment tables \(X_{rti},P_{rti}\) for reports whose posteriors belong to the experiment’s support. For a true type \(t\) and fixed reported type \(b\), define

\(D_{rtb,j}=W_{rtj}X_{rbj}-P_{rbj}\),

and define truthful expected utility by

\(F_{rt}=\sum_i e_{ri}\bigl(W_{rti}X_{rti}-P_{rti}\bigr)\).

These are linear expressions in the table variables.

2. Supported-output garblings and their dual

Fix a class \(r\). A garbling whose outputs belong to the finite set \(\{\sigma_{r1},\ldots,\sigma_{rn_r}\}\) is characterized by joint probabilities

\(z_{ij}=\Pr(\sigma=\sigma_{ri},\,s=\sigma_{rj})\).

The necessary and sufficient constraints are

\(z_{ij}\ge 0,\qquad \sum_j z_{ij}=e_{ri}\),

and, for every output index \(j\),

\(\sum_i z_{ij}(\sigma_{ri}-\sigma_{rj})=0\).

Necessity follows from the input law and the condition \(\mathbb E[\sigma\mid s]=s\). For sufficiency, given such a matrix, use the kernel that outputs \(\sigma_{rj}\) with probability \(z_{ij}/e_{ri}\) after input \(\sigma_{ri}\). The displayed vector equality verifies its posterior-averaging condition whenever that output has positive probability.

Consequently, the greatest deviation utility obtainable with fixed report \(b\) and supported outputs is the optimum of the linear program

\(\displaystyle \max_z\sum_{i,j}z_{ij}D_{rtb,j}\)

subject to those constraints.

This program is feasible: take \(z_{ii}=e_{ri}\) and all other entries zero. Its feasible set is compact, because its nonnegative entries have fixed row sums.

Introduce unrestricted dual variables \(Y_i^{rtb}\in\mathbb R\) and \(B_j^{rtb}\in\mathbb R^{\Theta_r}\). Its dual is

\(\displaystyle \min_{Y,B}\sum_i e_{ri}Y_i^{rtb}\),

subject to

\(Y_i^{rtb}+B_j^{rtb}\cdot(\sigma_{ri}-\sigma_{rj})\ge D_{rtb,j}\qquad\text{for every }i,j.\)

The primal is feasible and has a finite optimum, so finite-dimensional linear-programming strong duality applies, and the dual optimum is attained.

Therefore, compatibility against every supported-output garbling is equivalent to the existence of these dual variables satisfying the displayed inequalities and

\(F_{rt}\ge\sum_i e_{ri}Y_i^{rtb}\).

The reported type is fixed across signal realizations, so we need one such system for each ordered pair \((t,b)\).

3. The revenue linear program

Use table variables \(X_{rti},P_{rti}\) and the dual variables above for every class and ordered type pair. Maximize

\(\displaystyle \sum_{r,t,i}w_{rti}P_{rti}\),

subject to:

  • Allocation bounds and nonnegative payments:

\(0\le X_{rti}\le 1,\qquad P_{rti}\ge 0.\)

  • Truthful IR at each supported posterior:

\(W_{rti}X_{rti}-P_{rti}\ge 0.\)

  • Supply feasibility at the target aggregate:

\(\displaystyle \sum_{r,t,i}w_{rti}X_{rti}\le q.\)

  • For every \(r,t,b,i,j\), the dual inequalities:

\(Y_i^{rtb}+B_j^{rtb}\cdot(\sigma_{ri}-\sigma_{rj})\ge W_{rtj}X_{rbj}-P_{rbj}.\)

  • For every \(r,t,b\), the dual objective bound:

\(\displaystyle F_{rt}\ge\sum_i e_{ri}Y_i^{rtb}.\)

Every constraint is linear with rational coefficients.

This program upper-bounds every admissible mechanism

Take any mechanism satisfying the question’s constraints, and evaluate its allocations and payments at \(\nu_0\) and the supported reports. These values give tables \(X,P\).

Feasibility at \(\nu_0\) gives the supply constraint. Truthful ex-post IR gives the pointwise IR inequalities. Ex-post IIC at \(\nu_0\), restricted to supported-output garblings, gives every incentive inequality characterized in Section 2. Strong duality therefore supplies suitable dual variables.

Thus every admissible mechanism induces a feasible point of this linear program with the same target revenue. Its optimum is an upper bound on achievable revenue.

4. Extending the solution to arbitrary posterior reports

Take a feasible solution of the linear program. For each class, set

\(\displaystyle M_r=\max\left(\{0\}\cup\{-Y_i^{rtb}:t,b\in T_r,\ 1\le i\le n_r\}\right).\)

Define base allocation and payment functions by

\(\bar x_r(b,\sigma_{rj})=X_{rbj},\qquad \bar p_r(b,\sigma_{rj})=P_{rbj}\)

at supported posteriors, and by

\(\bar x_r(b,s)=0,\qquad \bar p_r(b,s)=M_r\)

at every other posterior.

The base functions have nonnegative payments and satisfy truthful IR. We now prove compatibility against every garbling, including those with infinitely many possible outputs.

Fix \(r,t,b\), and any allowed joint law of \((\sigma,s)\). Define

\(z_{ij}=\Pr(\sigma=\sigma_{ri},\,s=\sigma_{rj})\),

and

\(\rho_i=\Pr(\sigma=\sigma_{ri},\,s\notin\operatorname{supp}(E_r))\).

Then

\(\sum_jz_{ij}+\rho_i=e_{ri}\),

and the posterior-averaging condition gives

\(\sum_i z_{ij}(\sigma_{ri}-\sigma_{rj})=0\)

for each supported output \(j\).

The expected deviation utility under the base functions equals

\(\displaystyle \sum_{i,j}z_{ij}D_{rtb,j}-M_r\sum_i\rho_i.\)

Multiplying the dual inequalities by \(z_{ij}\), summing, and using the posterior equalities yields

\(\displaystyle \sum_{i,j}z_{ij}D_{rtb,j}\le\sum_i(e_{ri}-\rho_i)Y_i^{rtb}.\)

Hence the deviation utility is at most

\(\displaystyle \sum_i e_{ri}Y_i^{rtb}-\sum_i\rho_i(Y_i^{rtb}+M_r).\)

By construction, \(Y_i^{rtb}+M_r\ge 0\). The last expression is therefore at most

\(\displaystyle \sum_i e_{ri}Y_i^{rtb}\le F_{rt}.\)

This proves the required incentive inequality for arbitrary garblings. The proof uses only the finitely many supported-output masses and the remaining mass; it imposes no finiteness assumption on the garbling’s output law.

5. Supply feasibility at every aggregate

For any report measure \(\nu\), define its demand under the base allocation by

\(\displaystyle D(\nu)=\int\bar x_r(b,s)\,d\nu(r,b,s)=\sum_{r,b,j}X_{rbj}\nu(\{(r,b,\sigma_{rj})\}).\)

Define a common scaling factor

\(c(\nu)=1\) if \(D(\nu)\le q\), and

\(c(\nu)=q/D(\nu)\) if \(D(\nu)>q\).

Set the final mechanism to be

\(x_r(b,s;\nu)=c(\nu)\bar x_r(b,s),\qquad p_r(b,s;\nu)=c(\nu)\bar p_r(b,s).\)

These functions satisfy all the required conditions:

  • Allocation bounds and payments. Since \(0<c(\nu)\le 1\), allocations remain in \([0,1]\) and payments remain nonnegative.
  • Feasibility. For every allowed report measure,

\(\displaystyle \int x_r(b,s;\nu)\,d\nu=c(\nu)D(\nu)=\min\{D(\nu),q\}\le q.\)

  • Truthful ex-post IR. At every \(\nu_\alpha\), supported truthful utilities are the base truthful utilities multiplied by the nonnegative factor \(c(\nu_\alpha)\).
  • Ex-post IIC. Fix any \(\nu_\alpha\). An individual deviation leaves this aggregate unchanged, so truthful and deviation utilities are multiplied by the same factor \(c(\nu_\alpha)\). The inequality proved in Section 4 therefore applies for every class, true type, fixed type report, and garbling.

At the target aggregate,

\(\displaystyle D(\nu_0)=\sum_{r,t,i}w_{rti}X_{rti}\le q.\)

Thus \(c(\nu_0)=1\), and the mechanism achieves exactly the linear program’s objective value.

Combined with the upper bound in Section 3, this proves that the linear program’s optimum equals the original problem’s maximum revenue.

The functions are measurable. Their dependence on posterior reports uses finitely many singleton tests, and their dependence on \(\nu\) uses finitely many atom masses and a piecewise continuous scalar formula. Atom-evaluation maps are Borel measurable on the probability measures over the finite union of posterior simplices.

6. Polynomial complexity and finite output description

The allocation and payment tables contain \(2\tau\) variables. Writing \(m_r=|\Theta_r|\), the number of auxiliary dual variables is

\(\displaystyle \sum_r a_r^2 n_r(1+m_r)\le(1+m)\tau^2.\)

The number of dual inequalities is

\(\displaystyle \sum_r a_r^2n_r^2=\sum_r(a_rn_r)^2\le\tau^2.\)

All remaining constraints also number polynomially many. Their rational coefficients have bit lengths polynomial in the input length: they use only the input probabilities, posterior coordinates, masses, supply, and finite rational sums defining \(W_{rti}\).

The linear program is feasible by setting all its variables to zero. Its objective is bounded, because IR implies

\(0\le P_{rti}\le X_{rti}W_{rti}\le\max\{0,W_{rti}\}.\)

The standard polynomial-time theorem for explicitly represented rational linear programs therefore returns an exact rational optimal solution of polynomial bit length. Computing the constants \(M_r\) requires only polynomially many rational comparisons.

A finite description of the optimal mechanism consists of the rational tables \(X,P\), the constants \(M_r\), and the formulas in Sections 4–5. Evaluation uses finitely many posterior comparisons and finitely many atom masses of the supplied aggregate measure.

Thus both the exact optimal revenue and a finite description of an optimal mechanism can be produced in polynomial time.
