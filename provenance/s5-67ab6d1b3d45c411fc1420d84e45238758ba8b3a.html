The continuous mirror question, as graded

Given a finite shared agenda of temporal preference rules over binary attributes and a binary-rational distribution \(\mu\) over user types, where each type is a theory on that agenda, form \(\Phi_\mu=\{\phi:\sum_{t:\phi\in\Phi_t}\mu_t>1/2\}\). If \(\Phi_\mu\) is acyclic and every rule lies in \(TPref^*\), decide whether \(\Phi_\mu\) is consistent over all finite sequences; a no-instance has a finite improvement cycle as a witness. The sequences remain discrete; the population of users is continuous.

Packaged proof task (what the prover saw — nothing else)

Let \(V\) consist of \(m\) binary attributes, with objects in \(\{0,1\}^m\); sequences are nonempty finite words of objects, with repetitions allowed and no length bound.
A pure present formula is a Boolean formula over attribute equalities. Pure past formulas are Boolean combinations of \(F\mathbin{\mathrm{Since}}G\), where both operands are pure present or both are recursively pure past; constants are allowed. Use strict past semantics: \((s,i)\models F\mathbin{\mathrm{Since}}G\) iff some \(1\le j<i\) satisfies \((s,j)\models G\) and every \(j<k<i\) satisfies \((s,k)\models F\).
The explicitly encoded shared agenda \(A\) contains \(\operatorname{TPref}^{*}\) rules \(\phi:(H_\phi\land C_\phi)\to(X_\phi=a_\phi>X_\phi=b_\phi)\), where \(H_\phi\) is pure past, \(C_\phi\) is pure present, \(a_\phi,b_\phi\in\{0,1\}\) are distinct, and \(X_\phi\) does not occur in \(C_\phi\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Each type is an explicitly listed theory \(\Phi_t\subseteq A\), and \(\sum_t\mu_t=1\). Thus \(\tau\) is the support size, not the number of possible theories.
Form \(\Phi_\mu=\{\phi\in A:\sum_{t:\phi\in\Phi_t}\mu_t>1/2\}\); ties exclude the rule. Promise that the graph with edges \(Y\to X_\phi\) for attributes \(Y\) occurring in \(C_\phi\), over retained rules, is acyclic.
An improvement applies a retained rule at one position, changing only \(X_\phi\) from \(b_\phi\) to \(a_\phi\); its condition must hold at that position in both sequences. Consistency means that the transitive closure of these moves is irreflexive for every finite sequence length; inconsistency means a finite nonempty improvement cycle exists.

Classification

Under the stated promises, deciding consistency is \(\mathrm{PSPACE}\)-complete, and therefore \(\mathrm{NP}\)-hard, under polynomial-time many-one reductions.

Hardness already holds with \(\tau=1\), \(q=2\), mass \(1\), and an empty present-dependency graph. Thus a polynomial-time algorithm for the promised problem exists if and only if \(\mathrm P=\mathrm{PSPACE}\).

The proof below uses exactly the strict-past semantics in the question.

1. Aggregation takes polynomial time

Write each mass as \(\mu_t=n_t/d_t\), with numerator and denominator encoded in binary. Define

\(D=\prod_{t=1}^{\tau}d_t\), \(\qquad w_t=n_t(D/d_t)\).

The bit length of \(D\) is at most the sum of the denominator bit lengths, hence \(O(L)\). Because the masses sum to \(1\), we have \(\sum_t w_t=D\).

For each agenda rule, compute

\(W_\phi=\sum_{t:\phi\in\Phi_t}w_t\).

The rule is retained exactly when \(2W_\phi>D\). This implements strict majority and excludes ties without numerical approximation.

Using schoolbook integer arithmetic and the explicitly listed theories, this preprocessing takes

\(O((\tau+1)L^2+q\tau L)\)

bit operations. In particular, aggregation introduces no exponential dependence on the support size.

Henceforth let \(\Phi=\Phi_\mu\).

2. Under acyclicity, every cycle implies a two-move cycle

Call two retained rules *opposite* if they have the same target attribute and prefer opposite binary values.

First observe that a pure past formula evaluated at position \(i\) depends only on positions strictly before \(i\). This follows inductively from the syntax: a strict Since formula tests its operands only at positions less than \(i\), and Boolean combinations preserve that property.

Consequently, changing only the target attribute at position \(i\) preserves the rule’s past condition. It also preserves its present condition because the target does not occur there. Thus an enabled flip satisfies the condition in both sequences, as required.

Lemma. The theory \(\Phi\) is inconsistent if and only if there are opposite rules \(\phi,\psi\), a finite history \(h\), and a current object \(o\), such that

\((ho,|h|+1)\models H_\phi\land H_\psi\), \(\qquad o\models C_\phi\land C_\psi\).

The history may be empty.

Proof.

Suppose first that such rules, history, and object exist. Their present conditions do not mention their common target \(X\), and their past conditions are independent of the current object. Therefore both conditions remain true for either current value of \(X\). One rule flips \(X\) from \(0\) to \(1\), and the other flips it back. This gives a two-move improvement cycle.

Conversely, suppose there is a cycle

\(s^0\longrightarrow s^1\longrightarrow\cdots\longrightarrow s^r=s^0\),

with \(r>0\). All its sequences have the same length.

Let \(i\) be the earliest position changed by any move. The prefix before \(i\) is therefore fixed throughout the cycle.

Fix a topological order of the promised acyclic present-dependency graph. Among attributes changed at position \(i\), choose the earliest one in that order, denoted \(X\).

For every rule targeting \(X\), every attribute occurring in its present condition precedes \(X\). By the choice of \(X\), these attributes are fixed at position \(i\) throughout the cycle. Its past condition is also fixed, because the prefix before \(i\) is fixed.

Since \(X\) changes and returns to its initial binary value, the cycle contains both a flip from \(0\) to \(1\) and a flip from \(1\) to \(0\) at position \(i\). Let \(\phi,\psi\) be rules used for those flips. Their conditions, true when the corresponding flips occur, are true throughout the cycle. The fixed prefix and any current object at position \(i\) therefore supply the required witness. \(\square\)

Because histories and current objects can be chosen independently, the lemma also gives the following criterion:

\(\Phi\text{ is inconsistent}\)

if and only if some opposite pair satisfies both:

  • \(H_\phi\land H_\psi\) is satisfiable at some position of a finite sequence.
  • \(C_\phi\land C_\psi\) is propositionally satisfiable.

The independence matters: there is no additional restriction on which objects may occur in the witnessing history.

3. Finite-state monitoring and running time

Let \(k\) be the number of occurrences of Since subformulas in the retained past conditions. Then \(k\le L\).

At position \(i\), store one bit for each such occurrence \(T=F\mathbin{\mathrm{Since}}G\):

\(t_T(i)=1\quad\Longleftrightarrow\quad(s,i)\models T\).

All these bits are initially false at position \(1\).

Under the stated strict semantics, the update equation is

\(t_T(i+1)=G(i)\lor\bigl(F(i)\land t_T(i)\bigr)\).

Indeed, a witness for position \(i+1\) either is position \(i\), requiring \(G(i)\), or lies strictly before \(i\), requiring both a witness for \(T\) at \(i\) and \(F(i)\).

Given the stored vector and object \(s[i]\), all operand values can be evaluated bottom-up. Present formulas use the object; temporal occurrences use their stored bits. All updates are then performed simultaneously. This takes \(O(L)\) time after indexing the attributes.

Thus there is a deterministic monitor with at most \(2^k\) states. Its initial state represents the empty history. Reading an object extends that history by one position.

For every opposite pair, precompute

\(M_{\phi,\psi}=1\quad\Longleftrightarrow\quad C_\phi\land C_\psi\text{ is satisfiable}\).

A monitor state is *bad* if, for some pair with \(M_{\phi,\psi}=1\), both past conditions are true there. By the lemma, inconsistency is exactly reachability of a bad state.

Explicit time bound

Let \(m_0\) be the number of attributes occurring anywhere in the retained rules. Then \(m_0\le m\) and \(m_0\le L\). Unused attributes can be discarded: every word over the remaining attributes extends to a word over all attributes, and all relevant rule conditions and moves are preserved.

Enumerating the \(2^{m_0}\) current assignments computes the compatibility matrix in

\(O(2^{m_0}(L+q^2))\)

time. Breadth-first search explores at most \(2^k\) monitor states, with at most \(2^{m_0}\) transitions per state.

Including aggregation and preprocessing, a deterministic running-time bound is

\(O\!\left((\tau+1)L^2+q\tau L+m+2^{m_0+k}(m_0+L+q^2)\right)\).

In particular, expressed only through the requested parameters, this is at most

\(O\!\left((\tau+1)L^2+q\tau L+m+2^{m+L}(m+L+q^2)\right)\).

The breadth-first implementation uses

\(O\!\left(L+m_0+q^2+(k+1)2^k\right)\)

space.

A bounded-history theorem

If a bad state is reachable, it is reachable along a simple path containing at most \(2^k-1\) transitions. Each transition reads one history object. Appending a current object witnessing the present conditions gives a two-move cycle on sequences of length at most \(2^k\).

This bound is proved for the full syntax in the question, including arbitrary Boolean combinations and recursive past nesting.

Polynomial-space membership

Exponential storage is unnecessary.

For monitor states \(u,v\), let \(R(u,v,r)\) mean that there is a path of length at most \(2^r\) from \(u\) to \(v\). For \(r=0\), test equality or a single transition. A transition can be tested by enumerating objects with \(O(m_0+L)\) working space.

For \(r>0\), use

\(R(u,v,r)\quad\Longleftrightarrow\quad \exists w\bigl(R(u,w,r-1)\land R(w,v,r-1)\bigr)\).

The equivalence follows by splitting a path after at most \(2^{r-1}\) edges; conversely, concatenate the two paths.

Enumerate candidate intermediate states \(w\) sequentially. With \(r=k\), recursion depth is at most \(k\), and each level stores \(O(k)\) bits. Enumerating bad target states and evaluating their predicates also uses polynomial space.

Therefore reachability, and its negation, can be decided deterministically in

\(O(L+m_0+q^2+k^2)\)

space. This proves that consistency belongs to \(\mathrm{PSPACE}\).

4. Hardness within the permitted past syntax

We now prove hardness directly, avoiding any assumption about the complexity of a different temporal language.

4.1 Encoding configurations

Let \(K\) be any language in \(\mathrm{PSPACE}\). Fix a deterministic polynomial-space machine \(M\) deciding the complement of \(K\). Such a machine exists by swapping the accepting and rejecting outcomes of a polynomial-space decider for \(K\).

We may use a one-tape machine: the usual encoding of finitely many tapes by tracks and head markers preserves polynomial space. Let \(N\) be a polynomial tape bound for input \(x\).

Encode a configuration by Boolean variables recording:

  • its control state, using one variable per state;
  • its head position, using one variable per tape cell;
  • its tape symbols, using one variable per cell and symbol.

The machine’s state set and alphabet are fixed, so the number \(d\) of configuration variables is \(O(N)\).

There are polynomial-size Boolean formulas:

\(\operatorname{Valid}(\mathbf z)\), \(\quad \operatorname{Init}_x(\mathbf z)\), \(\quad \operatorname{Accept}(\mathbf z)\), \(\quad \operatorname{Step}(\mathbf u,\mathbf v)\),

with the following meanings:

  • \(\operatorname{Valid}\) requires exactly one state, one head position, and one symbol per cell.
  • \(\operatorname{Init}_x\) specifies the initial configuration on input \(x\).
  • \(\operatorname{Accept}\) tests an accepting state.
  • On valid configurations, \(\operatorname{Step}\) holds exactly for a legal machine transition.

For completeness, “exactly one” is expressed by

\(\operatorname{One}(v_1,\ldots,v_a)= (\bigvee_j v_j)\land\bigwedge_{j<\ell}\neg(v_j\land v_\ell)\).

The transition formula is a disjunction over the head position, old state, and scanned symbol. Each disjunct requires the corresponding old values, the new state, head position and written symbol, and equality of every unchanged tape cell. There are \(O(N)\) disjuncts, each of size \(O(N)\). Therefore the formula has polynomial size. Boundary-crossing and halting transitions are omitted.

4.2 Expressing a computation with pure past formulas

For a formula \(Q\) that is either pure present or pure past, define

\(\mathsf P Q=\bot\mathbin{\mathrm{Since}}Q\).

Use the constant \(\bot\) in the same syntactic class as \(Q\). Under strict semantics,

\((s,i)\models\mathsf P Q \quad\Longleftrightarrow\quad i>1\text{ and }(s,i-1)\models Q\).

A witness earlier than \(i-1\) would require \(\bot\) at an intervening position; the witness \(i-1\) has no intervening positions.

For each configuration attribute \(z_j\), put

\(U_j=\mathsf P(z_j=1)\), \(\qquad B=\mathsf P\top\), \(\qquad E=B\land\neg\mathsf P B\).

All these are pure past formulas. The formula \(B\) holds exactly at positions at least \(2\), and \(E\) holds exactly at position \(2\).

At position \(i\ge2\), the vector \(\mathbf U\) describes the object at position \(i-1\). At position \(i\ge3\), the vector \(\mathsf P\mathbf U\) describes the object at position \(i-2\).

Define the pure past formula

\(D= (B\to\operatorname{Valid}(\mathbf U)) \land (E\to\operatorname{Init}_x(\mathbf U)) \land ((B\land\mathsf P B)\to \operatorname{Step}(\mathsf P\mathbf U,\mathbf U))\),

and then define

\(H_{M,x}= B\land\operatorname{Accept}(\mathbf U)\land D \land\neg(\top\mathbin{\mathrm{Since}}\neg D)\).

Implications and equivalences here are Boolean abbreviations. Expand them, and expand the named subformulas, to obtain an explicitly encoded formula of polynomial size.

Every temporal occurrence respects the required grammar:

  • \(\mathsf P(z_j=1)\) has two pure present operands.
  • \(\mathsf P U_j\) and \(\mathsf P B\) have two pure past operands.
  • The final Since occurrence has two pure past operands.

Claim. The formula \(H_{M,x}\) is satisfiable at a position of a finite sequence if and only if \(M\) accepts \(x\).

Proof.

The last conjunct says that \(D\) holds at every strictly earlier position. Together with the separate conjunct \(D\), it requires \(D\) at every position through the evaluation position \(i\).

At position \(1\), all antecedents in \(D\) are false.

At position \(2\), \(D\) requires the first object to encode a valid initial configuration.

At every position from \(3\) through \(i\), it requires the preceding object to encode a valid configuration and the preceding two objects to encode a legal transition.

Finally, \(B\land\operatorname{Accept}(\mathbf U)\) requires \(i\ge2\) and makes the configuration encoded at position \(i-1\) accepting.

Thus a satisfying prefix encodes an accepting computation of \(M\).

Conversely, encode any accepting computation as successive objects and append an arbitrary final object. At that final position, each displayed requirement holds. \(\square\)

4.3 Turning acceptance into inconsistency

Add a fresh binary attribute \(X\). Let the agenda contain exactly these two rules:

\(\phi_+:(\top\land\top)\to(X=1>X=0)\),

\(\phi_-:(H_{M,x}\land\top)\to(X=0>X=1)\).

Give the single type \(\{\phi_+,\phi_-\}\) mass \(1\). Both rules are retained. Both present conditions are constant, so the dependency graph is empty and hence acyclic.

If \(H_{M,x}\) is satisfiable, the witnessing history permits both flips at the following position, giving a two-move cycle.

If \(H_{M,x}\) is unsatisfiable, the reverse rule is never applicable. Every improvement then changes an \(X\)-value from \(0\) to \(1\). For a fixed sequence length, the number of positions with \(X=1\) strictly increases at every move, so no cycle exists.

Therefore,

\(\Phi_\mu\text{ is consistent} \quad\Longleftrightarrow\quad M\text{ does not accept }x \quad\Longleftrightarrow\quad x\in K\).

The construction is polynomial-time and always satisfies the promises. Since \(K\) was arbitrary in \(\mathrm{PSPACE}\), this proves \(\mathrm{PSPACE}\)-hardness of consistency itself.
