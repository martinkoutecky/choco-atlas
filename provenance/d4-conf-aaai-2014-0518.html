The continuous mirror question, as graded

Given candidates \(X\), a known-available set \(Y\subseteq X\), a target \(x^\star\in Y\), and a distribution \(\mu\) over a support of complete rankings, does \(x^\star\) win under the paper’s plurality tie-breaking rule for every available set \(A\) with \(Y\subseteq A\subseteq X\), when each candidate’s score is the total mass of rankings that place it first in \(A\)?

Packaged proof task (what the prover saw — nothing else)

Given a finite candidate set \(X\), let \(m=|X|\), and let \(x^\star\in Y\subseteq X\) be a target and a known-available set.
A society is given by its support: a list of \(\tau\) distinct complete, strict rankings of \(X\), each with positive binary rational mass; the masses sum to \(1\). Here \(\tau\) is the support size, not the number of possible rankings.
An additional input is a strict priority order on \(X\). For each available set \(Y\subseteq A\subseteq X\), use plurality with mass-weighted scores and select the highest-priority candidate among those with maximum score, restricting the same priority order to \(A\).
Call \(x^\star\) robust if it wins for every such \(A\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is deciding whether \(x^\star\) is robust in \(\mathrm{P}\), or is it \(\mathrm{coNP}\)-hard?

For finite electorates, robustness is equivalent to the absence of destructive control by adding any subset of the unknown candidates; plurality robustness is reported as \(\mathrm{coNP}\)-complete ([Boutilier et al.](https://ojs.aaai.org/index.php/AAAI/article/download/8893/8752)).
Destructive plurality control by adding candidates is \(\mathrm{NP}\)-complete in the unique-winner model ([Hemaspaandra et al.](https://arxiv.org/pdf/cs/0507027)). No result settling the exact rational-mass formulation with the specified priority order was located.

Modeling choices made when packaging the task

  • The plurality tie-breaking rule was unspecified. Chose an input strict priority order, used consistently across all available sets.
  • Made the distribution normalization explicit: positive rational support masses sum to one.
  • Complete rankings are strict, as in the discrete model; the target's membership in the known-available set ensures every considered election is nonempty.
  • Used a coNP-hardness-versus-P target because the anchor is a complement equivalence and the decision question universally quantifies over available sets.

Result

Deciding robustness is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions. This holds even when the target has lowest priority.

Here “binary rational” means a rational number whose numerator and denominator are encoded in binary.

1. Robustness belongs to \(\mathrm{coNP}\)

Write the support as distinct rankings \(R_1,\ldots,R_\tau\), with masses \(\mu_i=p_i/q_i>0\). For a nonempty available set \(A\), let \(\operatorname{top}_i(A)\) be its highest-ranked candidate in \(R_i\). Define

\(\displaystyle s_A(x)=\sum_{\{i:\operatorname{top}_i(A)=x\}}\mu_i.\)

A certificate of nonrobustness is a subset \(S\subseteq X\setminus Y\), encoded by at most \(m\) bits. The verifier computes the winner on \(A=Y\cup S\) and accepts exactly when that winner differs from \(x^\star\).

All score comparisons can be performed exactly in polynomial time. Set

\(\displaystyle Q=\prod_{i=1}^{\tau}q_i,\qquad w_i=p_i(Q/q_i).\)

The bit length of \(Q\) is at most the sum of the denominator bit lengths, hence is \(\mathrm{O}(L)\). Each \(w_i\) is an integer, and the normalization hypothesis gives

\(\displaystyle \sum_{i=1}^{\tau}w_i=Q.\)

Consequently, every integer score

\(\displaystyle W_A(x)=\sum_{\{i:\operatorname{top}_i(A)=x\}}w_i\)

has \(\mathrm{O}(L)\) bits. Moreover, \(W_A(x)=Qs_A(x)\), so these integer scores preserve every comparison and tie.

Using elementary integer multiplication and division, computing all weights takes \(\mathrm{O}(\tau L^2)\) bit operations. With candidates indexed by binary identifiers, scanning all rankings, accumulating scores, and applying the priority order takes

\(\displaystyle \mathrm{O}\!\left(\tau m\log(m+1)+(\tau+m)L\right)\)

bit operations. Including input reading, certificate verification therefore takes

\(\displaystyle \mathrm{O}\!\left(L+\tau L^2+\tau m\log(m+1)+(\tau+m)L\right).\)

Thus nonrobustness belongs to \(\mathrm{NP}\), and robustness belongs to \(\mathrm{coNP}\).

2. The known hardness theorem applies without an addition budget

We use the following established result: given disjoint qualified and additional candidate sets \(C,D\), a distinguished candidate \(c\in C\), and an explicitly listed finite electorate with complete strict rankings of \(C\cup D\), it is \(\mathrm{NP}\)-complete to decide whether some \(S\subseteq D\) makes \(c\) fail to be the unique plurality winner on \(C\cup S\).

This is the destructive plurality control problem in Section 3 of [Hemaspaandra, Hemaspaandra, and Rothe](https://arxiv.org/pdf/cs/0507027), established by Theorem 3.2 and Corollary 4.32. Their definition permits any subset of additional candidates; it imposes no cardinality budget. Their hardness construction has a nonempty electorate.

These hypotheses match the reduction below.

3. Reduction to rational-mass nonrobustness

Take an instance of that problem with \(n>0\) voters. Construct

\(\displaystyle X=C\cup D,\qquad Y=C,\qquad x^\star=c.\)

Choose a strict priority order putting every candidate other than \(c\) ahead of \(c\). Fix this same order for every available set.

Aggregate identical complete rankings. If the resulting distinct rankings are \(R_1,\ldots,R_\tau\), with positive multiplicities \(n_1,\ldots,n_\tau\), assign

\(\displaystyle \mu_i=\frac{n_i}{n}.\)

This satisfies every support requirement:

  • Each listed ranking is complete and strict, and the rankings are distinct.
  • Each mass is positive and has a binary encoding of length \(\mathrm{O}(\log(n+1))\).
  • The masses sum to \(1\), because \(\sum_i n_i=n\).
  • The support size satisfies \(\tau\le n\).

For every \(S\subseteq D\), put \(A=C\cup S\). Let \(v_A(x)\) denote the original number of plurality votes for \(x\). Aggregation preserves the contribution of every ballot, so

\(\displaystyle s_A(x)=\frac{v_A(x)}{n}\qquad(x\in A).\)

Therefore the two elections have exactly the same score comparisons and ties.

Because \(c\) has lowest priority, it is selected on \(A\) if and only if it is the unique score maximizer:

  • If \(c\) is the unique maximizer, the priority rule selects it.
  • If another candidate has greater score, the rule cannot select \(c\).
  • If \(c\) ties for maximum with another candidate, that candidate has higher priority, so the rule does not select \(c\).

Consequently,

\(\displaystyle \exists S\subseteq D:\ c\text{ is not the unique original plurality winner on }C\cup S\)

is equivalent to

\(\displaystyle \exists A,\ Y\subseteq A\subseteq X:\ x^\star\text{ is not selected on }A.\)

This is precisely nonrobustness.

The transformation is polynomial in the original input length. For example, sorting the explicit ballots lexicographically and counting equal ballots takes polynomial time. Its output length is

\(\displaystyle \mathrm{O}\!\left(\tau m\log(m+1)+\tau\log(n+1)+m\log(m+1)\right).\)

In particular, the reduction never enumerates all possible rankings.

4. Conclusion and deterministic running time

Section 3 gives a polynomial-time many-one reduction from an \(\mathrm{NP}\)-complete problem to nonrobustness. Section 1 proves nonrobustness is in \(\mathrm{NP}\). Hence nonrobustness is \(\mathrm{NP}\)-complete, and taking complements proves that robustness is \(\mathrm{coNP}\)-complete.

An explicit deterministic algorithm precomputes the integer weights and checks every subset of \(X\setminus Y\). Its running time is

\(\displaystyle \mathrm{O}\!\left(L+\tau L^2+2^{m-|Y|}\bigl[\tau m\log(m+1)+(\tau+m)L\bigr]\right).\)

A polynomial-time algorithm for the general problem would imply \(\mathrm{P}=\mathrm{NP}\).
