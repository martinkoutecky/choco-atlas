The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), and a finite list of approval types \(A\subseteq C\) with positive rational masses \(\mu_A\) summing to \(1\), find a committee \(W\subseteq C\) of size \(k\) such that for every \(\ell\in\{1,\ldots,k\}\) and every choice of coalition masses \(x_A\in[0,\mu_A]\), if \(\sum_A x_A\ge \ell/k\) and \(\left|\bigcap_{A:x_A>0}A\right|\ge\ell\), then \(\sum_{A:|A\cap W|\ge\ell}x_A>0\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set of size \(m\), and let \(k\) be an integer with \(1\leq k\leq m\). A society is given by its support: a list \(\mathcal S\) of \(\tau\) distinct approval types \(A\subseteq C\), each with positive binary rational mass \(\mu_A\), where \(\sum_{A\in\mathcal S}\mu_A=1\). Empty approval types are allowed. Here \(\tau\) is the support size, not the number of possible approval types; \(L\) is the total input bit length.
A coalition is a vector of real masses \(x_A\in[0,\mu_A]\). A committee \(W\subseteq C\), \(|W|=k\), provides mass EJR if, for every integer \(\ell\in\{1,\ldots,k\}\) and every coalition, \(\sum_A x_A\geq\ell/k\) and \(\left|\bigcap_{A:x_A>0}A\right|\geq\ell\) imply \(\sum_{A:|A\cap W|\geq\ell}x_A>0\). The mass threshold ensures that the intersection has a nonempty index set. The computational problem is to find such a committee.

Is finding a committee providing mass EJR solvable in polynomial time in \(m,\tau,k,L\), or is this search problem NP-hard?

For an explicit list of \(n\) voters, EJR requires every \(\ell\)-cohesive coalition to contain a voter approving at least \(\ell\) winners; such a committee can be computed in \(O(nmk)\) arithmetic operations. [Sánchez-Fernández, Elkind, and Lackner](https://arxiv.org/html/1704.00356v3).
No result settling the exact rational-mass search problem above was identified in the literature search.

Modeling choices made when packaging the task

  • The graded question omitted the domain of committee size; impose the discrete domain of integer k with 1 ≤ k ≤ m.
  • The graded question did not explicitly specify the domain of coalition masses; allow real masses throughout each interval [0, μ_A].
  • Allow empty approval types, as the discrete approval-ballot domain permits every subset of C.
  • Define L as the total binary input length and represent each positive-mass approval type once.

Result

Finding a committee providing mass EJR is solvable in deterministic polynomial time in \(m,\tau,k,L\).

The algorithm is a weighted version of Simple EJR, described in [Sánchez-Fernández, Elkind, and Lackner, Section 5.1.1](https://arxiv.org/html/1704.00356v3#S5.SS1.SSS1). Below is a self-contained correctness proof and a bound on exact arithmetic. No expansion into individual voters is required.

1. Replacing real coalitions by finite inequalities

For a committee \(W\), an integer \(\ell\in\{1,\ldots,k\}\), and a set \(T\subseteq C\) of size \(\ell\), define

\(B_{\ell,T}(W)=\{A\in\mathcal S:T\subseteq A,\ |A\cap W|<\ell\}\).

Lemma 1. A committee \(W\) provides mass EJR if and only if, for every such \(\ell,T\),

\(\displaystyle \sum_{A\in B_{\ell,T}(W)}\mu_A<\frac{\ell}{k}.\)

Proof. Suppose a coalition violates mass EJR at level \(\ell\). Its mass is positive, so its active types have a well-defined intersection containing some set \(T\) of size \(\ell\). The violation requires

\(\displaystyle \sum_{A:|A\cap W|\geq\ell}x_A=0.\)

All summands are nonnegative. Consequently, every active type belongs to \(B_{\ell,T}(W)\), and

\(\displaystyle \sum_{A\in B_{\ell,T}(W)}\mu_A\geq\sum_Ax_A\geq\frac{\ell}{k}.\)

Conversely, if this inequality holds for some \(\ell,T\), take \(x_A=\mu_A\) on \(B_{\ell,T}(W)\) and \(x_A=0\) elsewhere. This coalition has the required mass, its active types all contain \(T\), and none approves \(\ell\) winners. Thus it violates mass EJR. \(\square\)

This equivalence includes arbitrary real coalitions and treats equality at the threshold as a violation.

2. Candidate levels and the algorithm

For any partial committee \(W\subseteq C\), write \(s_A(W)=|A\cap W|\). For an unelected candidate \(c\), define its level by

\(\displaystyle d_W(c)=\max\left(\{0\}\cup\left\{\ell\in\{1,\ldots,k\}:k\sum_{\substack{A\in\mathcal S\\c\in A,\ s_A(W)<\ell}}\mu_A\geq\ell\right\}\right).\)

These levels need only single-candidate support sums.

Two properties follow directly.

  • Monotonicity. If \(W\subseteq V\) and \(c\notin V\), then \(d_V(c)\leq d_W(c)\). Indeed, for each fixed \(\ell\), the types counted in its defining sum can only disappear as winners are added.
  • Zero levels suffice. If \(|W|=k\) and every unelected candidate has level zero, then \(W\) provides mass EJR.

To prove the second property, suppose Lemma 1 gives a violation \(\ell,T\). Its set of types has positive mass. Because those types contain \(T\) but approve fewer than \(\ell\) winners, \(T\) cannot be contained in \(W\). Choose \(c\in T\setminus W\). Then

\(\displaystyle k\sum_{\substack{A\in\mathcal S\\c\in A,\ s_A(W)<\ell}}\mu_A \geq k\sum_{A\in B_{\ell,T}(W)}\mu_A \geq\ell,\)

so \(d_W(c)\geq\ell>0\), a contradiction.

The algorithm is:

  • Start with \(W=\varnothing\).
  • While \(|W|<k\) and some unelected candidate has positive level, elect an unelected candidate of maximum level.
  • If fewer than \(k\) candidates were elected, add arbitrary distinct candidates until \(|W|=k\).

All ties may be resolved arbitrarily.

3. A charging lemma

Consider the positive-level selections. Let \(w_j\) be the candidate selected in round \(j\), let \(W_j=\{w_1,\ldots,w_j\}\), and put

\(\displaystyle d_j=d_{W_{j-1}}(w_j)>0.\)

Because levels decrease when winners are added, and each selection maximizes the current level,

\(\displaystyle d_1\geq d_2\geq\cdots.\)

For the proof only, assign type \(A\) the charge

\(\displaystyle \gamma_{A,j}= \begin{cases} \mu_A/d_j,&w_j\in A\text{ and }s_A(W_{j-1})<d_j,\\ 0,&\text{otherwise}. \end{cases}\)

Lemma 2. Every positive-level round charges total mass at least \(1/k\), while every type receives cumulative charge at most its mass.

Proof. Since \(d_j\) is a positive level of \(w_j\),

\(\displaystyle \sum_A\gamma_{A,j} =\frac{1}{d_j} \sum_{\substack{A\in\mathcal S\\w_j\in A,\ s_A(W_{j-1})<d_j}}\mu_A \geq\frac{1}{k}. \)

Now fix a type \(A\). If it is never charged, its cumulative charge is zero. Otherwise, let \(r_A\) be the number of rounds in which it is charged, and let \(j_A\) be its last charged round.

Each previous charged round elected a distinct candidate approved by \(A\). Therefore

\(\displaystyle r_A-1\leq s_A(W_{j_A-1}).\)

The condition for charging \(A\) in round \(j_A\), together with integrality, gives

\(\displaystyle d_{j_A}\geq s_A(W_{j_A-1})+1\geq r_A.\)

Every earlier selection level is at least \(d_{j_A}\). Hence

\(\displaystyle \sum_j\gamma_{A,j} \leq\frac{r_A\mu_A}{d_{j_A}} \leq\mu_A. \)

This proves both assertions. \(\square\)

4. Correctness

If the positive-level phase stops before selecting \(k\) candidates, all remaining candidates have level zero. Arbitrary additions preserve this property by monotonicity. The resulting committee therefore provides mass EJR.

It remains to consider the case of \(k\) positive-level selections.

Suppose, towards a contradiction, that an unelected candidate \(c\) has positive level \(\ell=d_{W_k}(c)\). Define

\(\displaystyle B=\{A\in\mathcal S:c\in A,\ s_A(W_k)<\ell\},\qquad M_B=\sum_{A\in B}\mu_A.\)

By the definition of its level,

\(\displaystyle M_B\geq\frac{\ell}{k}>0.\)

Candidate \(c\) remains available in every selection round. Monotonicity implies \(d_{W_{j-1}}(c)\geq\ell\), so the maximum-level selection satisfies \(d_j\geq\ell\) in every round.

For each \(A\in B\), a charged round must elect a candidate approved by \(A\). Thus \(A\) is charged at most \(s_A(W_k)\leq\ell-1\) times. Each charge is at most \(\mu_A/\ell\), giving

\(\displaystyle \sum_{j=1}^{k}\gamma_{A,j}\leq\frac{\ell-1}{\ell}\mu_A.\)

For types outside \(B\), Lemma 2 bounds cumulative charge by their mass. Consequently,

\(\displaystyle \sum_A\sum_{j=1}^{k}\gamma_{A,j} \leq \sum_{A\notin B}\mu_A+ \frac{\ell-1}{\ell}\sum_{A\in B}\mu_A = 1-\frac{M_B}{\ell} <1. \)

But Lemma 2 also gives

\(\displaystyle \sum_{j=1}^{k}\sum_A\gamma_{A,j} \geq k\cdot\frac1k=1, \)

a contradiction.

Therefore every unelected candidate has level zero after \(k\) positive-level selections. The zero-level property proves mass EJR. This completes the correctness proof.

5. Exact implementation and bit complexity

Write each input mass as \(\mu_A=p_A/q_A\), with positive integers \(p_A,q_A\). Form

\(\displaystyle D=\prod_{A\in\mathcal S}q_A,\qquad a_A=p_A(D/q_A).\)

Then \(\mu_A=a_A/D\), and normalization gives \(\sum_Aa_A=D\).

Although the *value* of \(D\) may be large, its binary length is at most the sum of the denominator lengths, hence \(O(L)\). Every \(a_A\) also has \(O(L)\) bits, because \(0<a_A\leq D\).

Every level test becomes the exact integer comparison

\(\displaystyle k\sum_{\substack{A\in\mathcal S\\c\in A,\ s_A(W)<\ell}}a_A \geq\ell D. \)

Its operands have \(O(L+\log(k+1))\) bits.

Initially, all representation counts are zero, so

\(\displaystyle d_{\varnothing}(c)= \left\lfloor\frac{k\sum_{A:c\in A}a_A}{D}\right\rfloor.\)

After electing a candidate, update the representation counts and each remaining candidate’s stored level. Starting from its previous level \(d\), decrement \(d\) while \(d>0\) and

\(\displaystyle k\sum_{\substack{A\in\mathcal S\\c\in A,\ s_A(W)<d}}a_A<dD. \)

This procedure computes the new maximum feasible level: all levels above the previous maximum were already infeasible and remain infeasible by monotonicity; scanning downward finds the largest remaining feasible level, or zero. No assumption that feasible levels form an interval is needed.

Each candidate’s stored level starts at most \(k\) and only decreases. Across the entire algorithm, it undergoes at most \(k\) decrements and at most \(k\) additional terminating tests. Each test scans at most \(\tau\) types. Thus the algorithm uses \(O(\tau m k)\) arithmetic operations, apart from polynomial-time preprocessing.

All these operations involve integers of polynomial bit length. Therefore the complete algorithm runs in polynomial time in \(m,\tau,k,L\). Empty approval types cause no difficulty: they contribute to normalization but to no candidate-support sum.

Verdict: proved. The output settles the stated search problem by giving a deterministic polynomial-time algorithm for exact rational masses. The correctness proof covers arbitrary real coalitions, including equality at the mass threshold. I found no major or minor mathematical issues.

1. Scope and external reference

The algorithm operates directly on the \(\tau\) listed approval types and their rational masses. It does not expand the input into individual voters.

The cited [Section 5.1.1 on Simple EJR](https://arxiv.org/html/1704.00356v3#S5.SS1.SSS1) describes selection by maximum dissatisfaction level, downward level updates, and completion once levels vanish. The attribution is appropriate. The prover supplies its own correctness argument for rational masses; it does not rely on applying an unstated discrete-voter theorem to the continuous setting.

2. Lemma 1: equivalence with finite inequalities

Both directions are correct.

For a violating coalition, the positive threshold \(\ell/k\) ensures that at least one type is active. Consequently, the intersection used to choose \(T\) is defined.

The failure of the EJR conclusion means that
\(\sum_{A:|A\cap W|\geq\ell}x_A=0\).
Nonnegativity implies that every active type approves fewer than \(\ell\) winners. Every active type also contains \(T\). The capacity constraints \(x_A\leq\mu_A\) therefore justify the displayed mass bound on \(B_{\ell,T}(W)\).

Conversely, assigning full mass to every type in \(B_{\ell,T}(W)\) produces a permitted coalition. Its mass is at least \(\ell/k>0\), every active type contains \(T\), and no active type approves \(\ell\) winners.

The strict inequality in the lemma is necessary and correctly stated: equality at the threshold produces a violation. No rationality restriction is imposed on the coalitions in either direction.

3. Candidate levels and algorithm

The level is well-defined because its defining maximum is over a finite, nonempty set containing zero.

Monotonicity is valid. For every fixed level \(\ell\), enlarging the committee can only remove types from the support sum. Thus no previously infeasible level becomes feasible.

The zero-level condition is sufficient. In the stated contradiction argument, \(B_{\ell,T}(W)\) has positive mass. If \(T\subseteq W\), every type in that set would approve at least \(\ell\) winners, contradicting its definition. Thus an unelected candidate \(c\in T\setminus W\) exists. Its support sum contains the entire violating set, establishing a positive level.

The selection phase terminates after at most \(k\) selections. Whenever \(|W|<k\), an unelected candidate exists because \(k\leq m\). Completion by distinct arbitrary candidates is therefore possible.

Arbitrary tie resolution does not affect the proof. A fixed ordering of candidates supplies deterministic tie resolution.

4. Lemma 2: charging argument

The selected levels are nonincreasing. Every candidate available at the next round was available at the preceding round, its level cannot increase, and its preceding level was bounded by the preceding selected maximum.

The lower bound on each round’s total charge follows directly from feasibility of \(d_j\) and division by the positive integer \(d_j\).

For the cumulative charge bound, all stated inequalities are justified:

  • The previous \(r_A-1\) charged rounds elected distinct candidates approved by \(A\), so \(r_A-1\leq s_A(W_{j_A-1})\).
  • The charging condition and integrality give \(d_{j_A}\geq s_A(W_{j_A-1})+1\geq r_A\).
  • Every earlier charged round has selection level at least \(d_{j_A}\), so each such charge is at most \(\mu_A/d_{j_A}\).

Consequently, cumulative charge is at most \(\mu_A\). Uncharged types are explicitly covered. The charges are analytical quantities only; their denominators do not enter the implementation’s arithmetic bound.

5. Correctness after termination

Both termination cases are handled correctly.

If the positive-level phase ends early, every remaining candidate has level zero. Monotonicity preserves zero levels during completion, so the sufficient condition applies to the final committee.

If there are \(k\) positive-level selections, the contradiction argument is valid. A candidate with final positive level \(\ell\) remained available in every round. Monotonicity and maximum-level selection imply \(d_j\geq\ell\) throughout.

For each \(A\in B\), there are at most \(s_A(W_k)\leq\ell-1\) charged rounds, each charging at most \(\mu_A/\ell\). Combining this with Lemma 2 for types outside \(B\) gives the stated upper bound \(1-M_B/\ell<1\). The \(k\) roundwise lower bounds give total charge at least one. These contradict each other.

All sums are finite, so exchanging their order requires no additional justification. The argument also covers \(\ell=1\).

6. Exact arithmetic and running time

The common-denominator construction is correct. The product \(D\) has binary length bounded by the sum of the denominator lengths, hence \(O(L)\). Normalization gives \(\sum_Aa_A=D\), and positivity implies \(0<a_A\leq D\).

Every support sum is at most \(D\). Thus both operands in a level comparison have \(O(L+\log(k+1))\) bits.

The initialization formula is correct because every representation count initially equals zero and candidate support mass is at most one.

The downward update computes the new maximum feasible level. Levels above the old maximum remain infeasible; the scan checks every intervening integer until finding a feasible level or reaching zero. The argument correctly avoids assuming that feasible levels form an interval.

Each candidate has at most \(k\) decrements and at most \(k\) terminating tests during updates. Scanning at most \(\tau\) types per test gives the claimed \(O(\tau m k)\) arithmetic bound. Representation-count updates and maximum selection fit within that bound. Common-denominator preprocessing and all integer operations take polynomial bit time.

The exponentially large possible numerical value of \(D\) therefore causes no pseudopolynomial dependence.

7. Boundary cases and repair feedback

Empty approval types contribute to normalization but cannot enter positive-level candidate-support sums or a violating set containing a nonempty \(T\). Unsupported candidates have level zero. The cases \(k=1\), \(k=m\), and exact threshold equality are covered by the written argument.

Required repairs: none. No missing lemma, unverified theorem application, or unsupported computational step prevents acceptance.
