The continuous mirror question, as graded

Given a shared argumentation framework \(\Lambda=\langle A,R\rangle\), an argument \(g\in A\), a rational threshold \(q\in(0,1]\), and a finite support of valid ePCAF profiles \(\Delta_j=\langle A,R,C_j,\succ_j\rangle\) with positive rational masses \(\mu_j\) summing to \(1\), decide whether at least a \(q\)-fraction of the society has \(g\) credulously accepted under complete semantics and the paper's KTV comparison. Equivalently, set \(z_j=1\) iff some \(E\in\mathrm{co}_k(\Delta_j)\) contains \(g\), and decide whether \(\sum_{j=1}^{\tau}\mu_j z_j\ge q\).

Packaged proof task (what the prover saw — nothing else)

Given a finite argumentation framework \(\Lambda=\langle A,R\rangle\), let \(m=|A|\ge1\), and let \(g\in A\). A society is given by its support: a list of \(\tau\ge1\) distinct types \(\Delta_j=\langle A,R,C_j,\succ_j\rangle\) with positive binary rational masses \(\mu_j\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each \(C_j\) is an explicitly listed set of constraints \(\varphi\Rightarrow v\) or \(v\Rightarrow\varphi\), where \(v\in\{f,u,t\}\) and \(\varphi\) is a propositional formula over \(A\) using \(\wedge,\vee,\neg,\Rightarrow\); \(C_j\) is promised satisfiable by some three-valued assignment. Evaluate formulas in three-valued Łukasiewicz logic; a constraint is satisfied exactly when its value is \(t\).
Each \(\succ_j\) is an explicitly listed strict partial order on \(A\times\{f,u,t\}\), with \(a^v\) denoting \((a,v)\). For a Dung complete extension \(E\), put \(t(E)=E\), \(f(E)=\{a\in A:\exists b\in E\ (b,a)\in R\}\), and \(u(E)=A\setminus(E\cup f(E))\); these sets assign the arguments their truth values.
Let \(\mathcal F_j\) be the complete extensions satisfying \(C_j\). For distinct \(E,F\in\mathcal F_j\), define \(E\succeq_j F\) iff there is no \(a^v\succ_j b^w\) with \(a\in v(F)\setminus v(E)\) and \(b\in w(E)\setminus w(F)\). Define \(E\triangleright_j F\) iff \(E\succeq_j F\) and \(F\not\succeq_j E\).
The KTV-best complete extensions are \(\mathcal B_j=\{E\in\mathcal F_j:\nexists F\in\mathcal F_j\text{ with }F\triangleright_j E\}\). Set \(z_j=1\) iff some \(E\in\mathcal B_j\) contains \(g\), and \(z_j=0\) otherwise, including when \(\mathcal B_j\) is empty. Given a binary rational \(q\in(0,1]\), decide whether \(\sum_{j=1}^{\tau}\mu_jz_j\ge q\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is this mass-threshold credulous-acceptance problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite, fixed number of agents, both existential and universal agentwise credulous acceptance under complete semantics and KTV comparison are \(\Sigma_2^p\)-complete; single-type acceptance is also \(\Sigma_2^p\)-complete. [Source](https://www.ijcai.org/proceedings/2023/0345.pdf)
No result for exactly the rational-mass threshold problem was identified in the literature search.

Modeling choices made when packaging the task

  • Expanded 'valid ePCAF profiles' to require satisfiable constraint sets and strict partial orders over argument–truth-value pairs, as in the discrete definitions.
  • Specified explicit formula and preference-relation encodings and defined L as the total input bit length.
  • Constraint satisfiability is a promise about arbitrary three-valued assignments, not a guarantee of a feasible complete extension; types with no best extension contribute zero.
  • Applied constraints before comparing extensions, and retained all undominated extensions without tie-breaking.
  • Allowed the support size to vary with the input, as stipulated by the support convention, although the discrete multi-agent result assumes a fixed number of agents.

Result

The problem is \(\Sigma_2^p\)-complete under polynomial-time many-one reductions, and therefore \(\mathrm{NP}\)-hard. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The permitted case \(\tau=1\) already establishes hardness. The rational-mass aggregation also admits a \(\Sigma_2^p\) upper bound, even when the support size varies with the input.

1. Polynomial-time checks and exact arithmetic

For a subset \(E\subseteq A\), define its defeated set and defended set by

\(f(E)=\{a\in A:\exists b\in E,\ (b,a)\in R\}\),

\(D(E)=\{a\in A:\text{every attacker of }a\text{ belongs to }f(E)\}\).

By the definition of Dung complete semantics, \(E\) is complete exactly when \(E\cap f(E)=\varnothing\) and \(E=D(E)\). These conditions, and the resulting truth-value assignment, can be computed in \(O(m^2)\) time using an attack matrix.

Each explicitly represented constraint can then be evaluated by traversing its formula. Every connective has a fixed three-valued truth table, so the time is linear in the formula representation. Thus membership in \(\mathcal F_j\) is decidable in polynomial time.

For distinct feasible extensions \(E,F\), the test \(E\succeq_j F\) scans the explicitly listed preference pairs and checks the two required set differences. Testing both directions decides \(E\triangleright_j F\) in polynomial time. Identical extensions never strictly dominate one another.

The threshold comparison also uses polynomial-time exact arithmetic. Write \(\mu_j=a_j/b_j\) and \(q=c/d\), with positive integer denominators, and set

\(H=d\prod_{j=1}^{\tau}b_j,\qquad W_j=a_j(H/b_j),\qquad Q=c(H/d)\).

Then, for any subset \(S\subseteq\{1,\ldots,\tau\}\),

\(\sum_{j\in S}\mu_j\ge q\quad\Longleftrightarrow\quad\sum_{j\in S}W_j\ge Q\).

The integers involved have \(O(L)\) bits: the bit length of the product is bounded by the total denominator bit length, and \(\mu_j,q\le1\). Ordinary integer arithmetic therefore performs this comparison in polynomial time; \(O(L^3)\) is a sufficient bound.

2. Membership in \(\Sigma_2^p\)

We use the characterization of \(\Sigma_2^p\) by an existentially quantified polynomial-length string followed by a universally quantified polynomial-length string, with a polynomial-time predicate.

Existentially choose a subset \(S\subseteq\{1,\ldots,\tau\}\) and an extension \(E_j\subseteq A\) for every \(j\in S\). Require:

  • \(\sum_{j\in S}\mu_j\ge q\).
  • For every \(j\in S\), \(E_j\in\mathcal F_j\) and \(g\in E_j\).
  • For every \(j\in S\) and every \(F\subseteq A\), if \(F\in\mathcal F_j\), then \(F\not\triangleright_j E_j\).

The existential data use \(O(\tau(m+1))\) bits. The third condition can be checked by universally quantifying a single pair \((j,F)\), using \(O(\log(\tau+1)+m)\) bits. Invalid indices and indices outside \(S\) impose no condition. Section 1 shows that the resulting predicate is polynomial-time computable.

To prove equivalence with the target decision:

  • If the actual accepting mass reaches \(q\), choose \(S=\{j:z_j=1\}\). For each selected type, the definition of \(z_j\) supplies a best feasible extension containing \(g\). All three conditions hold.
  • Conversely, the second and third conditions imply \(E_j\in\mathcal B_j\) and \(g\in E_j\), hence \(z_j=1\), for every \(j\in S\). Positivity of the masses gives \(\sum_{j=1}^{\tau}\mu_jz_j\ge\sum_{j\in S}\mu_j\ge q\).

This argument also covers empty feasible or best-extension sets: such a type cannot supply a selected witness.

Therefore the problem belongs to \(\Sigma_2^p\).

3. A direct \(\mathrm{NP}\)-hardness proof respecting the promise

Here is a reduction from Boolean satisfiability that does not depend on the cited argumentation hardness theorem.

Let \(\phi\) be a Boolean formula over variables \(x_1,\ldots,x_n\). Construct

\(A=\{g\}\cup\{x_i,y_i:1\le i\le n\}\),

\(R=\{(x_i,y_i),(y_i,x_i):1\le i\le n\}\).

Thus \(g\) is unattacked, and the remaining arguments form disjoint mutually attacking pairs. Use one type, with empty preference order, mass \(\mu_1=1\), and threshold \(q=1\). Its constraints are

\(C_1=\{t\Rightarrow(x_i\vee\neg x_i):1\le i\le n\}\cup\{t\Rightarrow(\neg g\vee\phi)\}\).

Verification of the satisfiability promise

Assign \(g=f\), every \(x_i=f\), and every \(y_i=f\). Each \(x_i\vee\neg x_i\) has value \(t\), and \(\neg g\vee\phi\) has value \(t\) because \(\neg g=t\).

In Łukasiewicz logic, \(t\Rightarrow\psi\) has the same value as \(\psi\). Hence this assignment satisfies every constraint, regardless of whether \(\phi\) is Boolean-satisfiable.

The empty preference relation is a strict partial order. With one type, the distinctness requirement is automatic.

Characterization of complete extensions

Every complete extension contains the unattacked argument \(g\): it is defended by every set, and a complete extension contains every argument it defends.

For each pair \(\{x_i,y_i\}\), a complete extension contains exactly one of the following local choices:

\(\varnothing,\qquad\{x_i\},\qquad\{y_i\}\).

Indeed, selecting both violates conflict-freeness. Selecting neither leaves neither argument defended. Selecting one defends that argument against its sole attacker and does not defend the other. Since there are no attacks between components, arbitrary combinations of these local choices, together with \(g\), are complete.

Their values for \(x_i\) are respectively \(u,t,f\). Moreover,

\(x_i\vee\neg x_i=t\quad\Longleftrightarrow\quad x_i\in\{f,t\}\).

Therefore the first group of constraints eliminates the empty local choices. The surviving extensions correspond bijectively to Boolean assignments: select \(x_i\) when the variable is true and \(y_i\) when it is false.

Because every complete extension assigns \(g=t\), the final constraint is satisfied exactly when \(\phi\) evaluates to \(t\). On Boolean assignments, the specified three-valued connectives agree with their Boolean counterparts. Consequently,

\(\mathcal F_1\ne\varnothing\quad\Longleftrightarrow\quad\phi\text{ is Boolean-satisfiable}\).

Finally, the empty preference order makes both comparison directions hold for every pair of distinct feasible extensions. There is therefore no strict domination, so \(\mathcal B_1=\mathcal F_1\). Every such extension contains \(g\), giving

\(\sum_{j=1}^{\tau}\mu_jz_j\ge q\quad\Longleftrightarrow\quad z_1=1\quad\Longleftrightarrow\quad\phi\text{ is satisfiable}\).

The construction has \(m=2n+1\), \(\tau=1\), and polynomial output bit length. This proves \(\mathrm{NP}\)-hardness while satisfying every input promise.

4. The stronger lower bound from the supplied source

Theorem 1 of [Alfano, Greco, Parisi, and Trubitsyna, *Preferences and Constraints in Abstract Argumentation*](https://www.ijcai.org/proceedings/2023/0345.pdf) states that credulous acceptance among KTV-best complete extensions of an extended preference-based argumentation framework is \(\Sigma_2^p\)-complete.

Its hypotheses match a restricted instance here: the preference relation is a strict partial order on argument–truth-value pairs, and Definition 9 gives exactly the comparison in the question. Under complete semantics, the source’s defended set equals the extension, so the truth-value assignments also agree.

Map such an instance to one type with \(C_1=\varnothing\), \(\mu_1=1\), and \(q=1\). The empty constraint set satisfies the promise, and the threshold answer equals the source’s single-type credulous-acceptance answer. This is a polynomial-time many-one reduction.

Thus the threshold problem is \(\Sigma_2^p\)-hard. Together with Section 2, it is \(\Sigma_2^p\)-complete.

5. Explicit deterministic running time

An exhaustive exact algorithm gives a bound in the requested parameters:

  • Enumerate all \(2^m\) subsets, retaining complete extensions and their truth-value assignments.
  • Evaluate each type’s constraints on these extensions.
  • For each type, test all ordered pairs of feasible extensions for strict domination, and determine whether an undominated extension contains \(g\).
  • Compare the resulting mass with \(q\) exactly.

Let \(c_j\) be the formula-representation length for type \(j\), and \(p_j\) its number of listed preference pairs. Feasibility filtering costs \(O(2^m\sum_j c_j)\). A comparison costs \(O(m+p_j)\), and there are at most \(4^m\) ordered pairs per type. Since \(\sum_j c_j=O(L)\) and \(\sum_j p_j=O(L)\), a sufficient deterministic time bound is

\(O\!\left(L^3+2^m(m^2+L)+4^m(\tau m+L)\right)\).

This algorithm uses the supplied support directly; it does not enumerate other possible types.
