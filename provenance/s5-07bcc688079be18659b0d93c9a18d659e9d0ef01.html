The continuous mirror question, as graded

Given two colleges \(c_1,c_2\), a finite type set \(T\), rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), rational values \(p_t\ge0\), capacities \(\beta_j\ge1/2\), and scale \(N\), find a complete mass assignment \(x_{tj}\ge0\) satisfying \(x_{t1}+x_{t2}=\mu_t\) and \(\sum_t x_{tj}\le\beta_j\), with each individual assigned integrally and no type–college blocking pair, that lexicographically maximizes the sorted pair \((W_{(1)},W_{(2)})\), where \(W_j=N\sum_t p_tx_{tj}\) and \(W_{(1)}\le W_{(2)}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Each type represents an atomless population.
There are \(m=2\) colleges. Input values \(p_t\geq0\) and normalized capacities \(\beta_j\in[1/2,1]\) are binary rationals; the scale \(N\geq2\) is a binary integer. A type-\(t\) student values either college at \(p_t\), and either college values such a student at \(p_t\), additively.
An assignment is represented by rational masses \(x_{tj}\geq0\), with \(x_{t1}+x_{t2}=\mu_t\) and \(0<\sum_t x_{tj}\leq\beta_j\) for each college. Every individual is assigned wholly to one college; different individuals of the same type may attend different colleges, with no integrality grid imposed on masses.
A type–college pair \((t,c_j)\) blocks precisely when there exist \(k\ne j\) and a type \(s\) with \(x_{tk}>0\), \(x_{sj}>0\), \(u_t(c_j)>u_t(c_k)\), and \(p_t>p_s\), where \(u_t(c_j)=p_t\). Stability excludes such pairs; vacancies alone do not create blocking pairs, and indifferences are not broken.
Define \(W_j=N\sum_t p_tx_{tj}\), and sort these into \(W_{(1)}\leq W_{(2)}\). Optimize the sorted pair lexicographically over complete stable assignments; any maximizer is acceptable.

Is computing an exact leximin optimal complete stable assignment polynomial-time solvable in \(m\), \(\tau\), and the total input bit length \(L\) (including \(N\)), or is it NP-hard?

For finite societies, computing a leximin optimal stable matching is NP-hard with two colleges, isometric valuations, and weak rankings, even when each student has equal value at both colleges; it is strongly NP-hard when \(n=3m\). [Narang, Biswas, and Narahari](https://arxiv.org/html/2009.05823v4)
No result settling exactly the atomless, support-encoded problem above was identified in the literature search.

  • Specified the omitted student and college valuations as p_t on both sides at either college, matching the anchor's two-college construction.
  • Interpreted individual integrality over an atomless population: types may split across colleges, but individuals are assigned wholly, without a discrete mass grid.
  • Restored completeness on the college side by requiring positive assigned mass at each college.
  • Specified blocking through strict improvement on both sides and replacement of an assigned student; vacant capacity does not itself create a blocking pair.
  • Specified N as a binary integer at least two, following the discrete requirement that the student count is at least the college count; N imposes no divisibility constraints on masses.

Result

The stated problem is polynomial-time solvable. An exact optimal assignment is
\(x_{t1}=x_{t2}=\mu_t/2\) for every supported type \(t\).

Equal student values make stability automatic. The optimization still requires a proof: the assignment above is feasible and attains a universal upper bound on the smaller college welfare.

1. Every feasible assignment is stable

A blocking pair requires, among its other conditions, a strict student preference
\(u_t(c_j)>u_t(c_k)\).

For every type \(t\), the premises give
\(u_t(c_1)=u_t(c_2)=p_t\).
Consequently, this strict inequality never holds. No type–college pair blocks, so every feasible complete assignment is stable.

This conclusion uses exactly the specified blocking rule, including its treatment of indifference and vacancies.

2. Constructing a feasible complete assignment

For every supported type \(t\), define
\(x^*_{t1}=x^*_{t2}=\mu_t/2\).

These masses are rational and nonnegative, and
\(x^*_{t1}+x^*_{t2}=\mu_t\).
Thus the assignment is complete.

For each college \(j\), its assigned mass is
\(\sum_t x^*_{tj}=\frac12\sum_t\mu_t=\frac12\).
Because \(\beta_j\in[1/2,1]\), this satisfies
\(0<\sum_t x^*_{tj}\leq\beta_j\).
Hence the assignment is feasible and, by Section 1, stable.

This construction respects the requirement that each individual attend one college. The standard divisibility property of a finite atomless measure states that a measurable subset exists with any prescribed mass between zero and the total mass. Each type population is atomless and has finite mass \(\mu_t\), so it can be partitioned into two disjoint populations of mass \(\mu_t/2\). Assign these populations wholly to the two colleges.

3. Proof of exact leximin optimality

Define the total welfare
\(T=N\sum_t p_t\mu_t\).

For any complete assignment \(x\), completeness implies
\(W_1(x)+W_2(x)=N\sum_t p_t(x_{t1}+x_{t2})=N\sum_t p_t\mu_t=T\).

Therefore every feasible assignment satisfies
\(W_{(1)}(x)=\min\{W_1(x),W_2(x)\}\leq T/2\).

For the constructed assignment,
\(W_j(x^*)=N\sum_t p_t(\mu_t/2)=T/2\)
for both colleges. Thus its sorted welfare pair is
\((W_{(1)}(x^*),W_{(2)}(x^*))=(T/2,T/2)\),
and it attains the largest possible first coordinate.

To verify the second lexicographic coordinate, any assignment attaining first coordinate \(T/2\) must have second coordinate
\(T-T/2=T/2\), because total welfare is fixed. Thus no assignment can improve either coordinate lexicographically over \(x^*\).

The argument also covers \(T=0\); no positivity assumption on welfare is needed.

4. Exact computation and bit complexity

The algorithm reads each supported mass and outputs two copies of its half. If an input mass is represented as \(a_t/b_t\), its half can be represented exactly as \(a_t/(2b_t)\). This increases the denominator’s binary length by at most one bit. If reduced fractions are required, reduction by the greatest common divisor takes polynomial time.

There are exactly \(2\tau\) output masses, and their total encoding length is \(O(L+\tau)\). Constructing them takes polynomial time in \(\tau\) and \(L\). The algorithm neither enumerates possible types outside the support nor expands the binary integer \(N\) into individuals; indeed, it need not perform arithmetic with \(N\).

Therefore, for the stipulated \(m=2\), computing an exact leximin optimal complete stable assignment is polynomial-time solvable in the stated parameters.

5. Why finite-society hardness does not transfer

The cited paper studies finite sets of students and colleges and establishes hardness results for that setting. [Narang, Biswas, and Narahari](https://arxiv.org/html/2009.05823v4)

In the present model, each type population can be divided into two equal masses while keeping every individual wholly assigned. Finite indivisible students need not permit such a division. Here, atomlessness and both capacity bounds being at least \(1/2\) make exact welfare equalization feasible, which settles the optimization directly.
