The continuous mirror question, as graded

Given locations \(L\), rational type masses \(\mu_t\) summing to \(1\), per-capita capacities \(\kappa_l\), and for each type its features \(x_t\), default location \(d_t\), observed default outcome \(y_t\), and predicted scores \(p_{tl}=g_l(x_t)\), find the infimum of \(\sum_{t,l}\mu_t|\breve p_{tl}-p_{tl}|\) over shared type-level scores \(\breve p_{tl}\ge 0\), subject to every maximizer of \(\sum_{t,l}\breve p_{tl}q_{tl}\) over \(q_{tl}\ge 0\), \(\sum_lq_{tl}\le\mu_t\), and \(\sum_tq_{tl}\le\kappa_l\) satisfying \(q_{t,d_t}=\mu_t\) for every type with \(y_t=1\). Specify an attaining or arbitrarily close score table, including tie handling.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) counts listed types, not possible types. There are \(m\geq1\) locations \(\mathcal L\), with binary-rational capacities \(\kappa_l\geq0\).
Each type has a default location \(d_t\in\mathcal L\), an observed outcome \(y_t\in\{0,1\}\), and explicitly supplied binary-rational predicted employment scores \(p_{tl}\in[0,1]\). Default placements are feasible: \(\sum_{t:d_t=l}\mu_t\leq\kappa_l\) for every location. Features merely label types; no classifier oracle is required.
Let \(Q=\{q\in\mathbb R_{\geq0}^{\tau\times m}:\sum_lq_{tl}\leq\mu_t\ \forall t,\ \sum_tq_{tl}\leq\kappa_l\ \forall l\}\); mass may be split or left unassigned.
A shared type-level score table \(\breve p\in\mathbb R_{\geq0}^{\tau\times m}\), with no upper bound, is admissible if every maximizer of \(\sum_{t,l}\breve p_{tl}q_{tl}\) over \(Q\) satisfies \(q_{t,d_t}=\mu_t\) whenever \(y_t=1\). Thus all tied maximizers must satisfy the condition.
Define \(C^*=\inf_{\breve p\text{ admissible}}\sum_{t,l}\mu_t|\breve p_{tl}-p_{tl}|\). The computational problem is to compute \(C^*\) exactly and, given a positive binary-rational \(\eta\), produce an admissible rational table attaining it or having cost at most \(C^*+\eta\).

Is this continuous inverse-assignment problem solvable in polynomial time in \(m\), \(\tau\), and the total input bit length \(L\), including the encoding of \(\eta\), or is it NP-hard?

For finite agents, Lee et al. give a polynomial-time procedure for minimum total absolute score modification enforcing preservation of successful default placements under every optimal matching, using infinitesimal tie perturbations. [Lee et al.](https://raw.githubusercontent.com/mlresearch/v275/main/assets/lee25a/lee25a.pdf)
Unbounded partial inverse assignment under the unweighted \(\ell_1\) norm is strongly polynomial-time solvable when a prescribed partial assignment must belong to some optimal assignment. [Yang and Zhang](https://doi.org/10.1016/j.orl.2005.12.003)
No result settling the exact shared-score, divisible-mass problem above was located in the literature search.

Modeling choices made when packaging the task

  • Specified nonempty support and location sets, binary-rational nonnegative capacities, binary observed outcomes, and original predicted scores in [0,1].
  • Required the entire default placement to satisfy capacities, reflecting retrospective data generated by a feasible default matching policy.
  • Used the explicitly supplied prediction table as numerical input; features are labels rather than an unevaluated classifier representation.
  • Retained unrestricted nonnegative modified scores, including scores above 1, as explicitly allowed by the discrete framework.
  • Made arbitrarily close output precise using a positive binary-rational additive tolerance eta, whose encoding contributes to the input bit length.
  • Retained partial fractional assignments and universal treatment of tied maximizers; no favorable tie-breaking convention is introduced.

Result

The problem is \(\mathrm{NP}\)-hard. In fact, producing the requested admissible table within the given additive tolerance is already \(\mathrm{NP}\)-hard, even without computing \(C^*\).

The reduction below uses only one successful type, identical default locations, predicted scores in \(\{0,1\}\), and dyadic masses and capacities.

1. Reduction from \(3\)-PARTITION

Use the standard strongly \(\mathrm{NP}\)-complete \(3\)-PARTITION problem: given positive integers \(a_1,\ldots,a_{3k},B\) satisfying
\(\sum_i a_i=kB\) and \(B/4<a_i<B/2\), decide whether the indices can be partitioned into \(k\) triples, each having sum \(B\). [A precise statement of this standard hardness result appears in *Diverse collections in matroids and graphs*.](https://pmc.ncbi.nlm.nih.gov/articles/PMC10869459/)

Let \(R\) be the smallest power of two satisfying \(R\geq4kB\). Define
\(M=kB/R\), \(s=1-M\), and \(\rho=\min_i a_i/R\).
Consequently,
\(0<\rho\leq M\leq1/4\) and \(s\geq3/4\).

Construct the society as follows.

  • There are locations \(0,1,\ldots,k\), with capacities \(\kappa_0=1\) and \(\kappa_j=B/R\) for \(1\leq j\leq k\).
  • There is one successful type, denoted \(\star\), with mass \(\mu_\star=s\).
  • For each index \(i\), there is an unsuccessful type of mass \(\mu_i=a_i/R\).
  • Every type has default location \(0\).
  • The successful type has scores \(p_{\star0}=0\) and \(p_{\star j}=1\) for \(1\leq j\leq k\).
  • Every unsuccessful type has score \(0\) at every location.

All masses are positive and sum to \(s+M=1\). All defaults are feasible because location \(0\) has capacity \(1\). All numerical inputs are dyadic, and the construction has polynomial encoding length.

We will prove the following gap:

\(\text{YES instance of }3\text{-PARTITION}\ \Longrightarrow\ C^*=M,\)

\(\text{NO instance of }3\text{-PARTITION}\ \Longrightarrow\ C^*\geq M+\rho.\)

2. A lower bound for every admissible table

Write \(c=\breve p\) for an arbitrary admissible table. Define its modification on the successful row by

\(\Delta=c_{\star0}+\sum_{j=1}^{k}|c_{\star j}-1|.\)

Because all original unsuccessful scores are zero and \(c\) is nonnegative, its total cost is exactly

\(\operatorname{cost}(c)=s\Delta+\sum_{i=1}^{3k}\mu_i\sum_{l=0}^{k}c_{il}.\)

The feasible set \(Q\) is nonempty and compact, so an optimizer \(q\) exists. Admissibility gives \(q_{\star0}=s\); the successful row constraint therefore gives \(q_{\star j}=0\) for every \(j\geq1\).

If \(\Delta\geq1\), then

\(\operatorname{cost}(c)\geq s\geq3/4>M+\rho,\)

because \(M+\rho\leq2M\leq1/2\).

Hence consider \(\Delta<1\). For each \(j\geq1\),

\(c_{\star j}-c_{\star0}\geq1-|c_{\star j}-1|-c_{\star0}\geq1-\Delta>0.\)

Every nondefault location is full

Suppose location \(j\geq1\) had positive unused capacity in \(q\). Moving a sufficiently small positive amount of successful mass from location \(0\) to \(j\) would remain feasible and increase the objective by that amount times \(c_{\star j}-c_{\star0}>0\). This contradicts optimality.

Thus each location \(j\geq1\) is saturated. Its occupants are all unsuccessful, and the sum of these locations’ capacities is

\(\sum_{j=1}^{k}\kappa_j=kB/R=M.\)

Since the total unsuccessful mass is also \(M\), every unsuccessful type is fully assigned among locations \(1,\ldots,k\). In particular,

\(\sum_{j=1}^{k}q_{ij}=\mu_i\quad\text{and}\quad q_{i0}=0\)

for every unsuccessful type \(i\).

Each used score costs at least \(1-\Delta\)

Fix \(i,j\) with \(q_{ij}>0\). Choose \(0<\varepsilon\leq\min\{q_{ij},s\}\). Exchange \(\varepsilon\) units of successful mass at location \(0\) with \(\varepsilon\) units of type \(i\) at location \(j\).

This exchange preserves both row totals and both location totals, hence is feasible. Optimality implies

\(\varepsilon(c_{\star j}+c_{i0}-c_{\star0}-c_{ij})\leq0.\)

Using \(c_{i0}\geq0\), we obtain

\(c_{ij}\geq c_{\star j}-c_{\star0}+c_{i0}\geq1-\Delta.\)

Let \(r_i\) be the number of nondefault locations receiving positive mass from type \(i\). Every \(r_i\geq1\), so

\(\sum_i\mu_i\sum_l c_{il}\geq(1-\Delta)\sum_i\mu_i r_i\geq M(1-\Delta).\)

Consequently,

\(\operatorname{cost}(c)\geq s\Delta+M(1-\Delta)=M+(s-M)\Delta\geq M.\)

Together with the case \(\Delta\geq1\), this proves \(C^*\geq M\) for every constructed instance.

3. NO instances have a positive cost gap

Suppose the \(3\)-PARTITION instance is a NO instance.

Continue with an admissible table satisfying \(\Delta<1\) and an optimizer \(q\) as above. At least one unsuccessful type must have \(r_i\geq2\).

Indeed, otherwise every type would place its entire mass at exactly one nondefault location. Saturation would then partition the indices into sets \(I_j\) satisfying

\(\sum_{i\in I_j}a_i=R\kappa_j=B.\)

Each such set would contain exactly three indices: two indices have sum strictly below \(B\), whereas four indices have sum strictly above \(B\). This would be a valid \(3\)-partition, contradicting the NO assumption.

Therefore,

\(\sum_i\mu_i r_i\geq M+\rho.\)

The preceding score bound now yields

\(\operatorname{cost}(c)\geq s\Delta+(M+\rho)(1-\Delta)\)

\(=M+\rho+(s-M-\rho)\Delta\geq M+\rho,\)

where the final inequality follows from

\(s-M-\rho=1-2M-\rho\geq1-3M\geq1/4.\)

The case \(\Delta\geq1\) already gives an even larger bound. Hence every admissible table costs at least \(M+\rho\), and taking the infimum proves

\(C^*\geq M+\rho\)

on NO instances.

4. YES instances have infimum exactly \(M\)

Suppose a valid partition \(I_1,\ldots,I_k\) exists. For any positive rational \(\varepsilon\), define a shared table by

\(c_{\star0}=\varepsilon,\qquad c_{\star j}=1\quad(1\leq j\leq k),\)

and, for unsuccessful types,

\(c_{ij}=1\ \text{if }i\in I_j,\)

with every other unsuccessful score equal to zero.

Its modification cost is

\(\operatorname{cost}(c)=s\varepsilon+\sum_i\mu_i=M+s\varepsilon.\)

We must verify admissibility under every maximizing assignment.

For any feasible \(q\),

\(\sum_{t,l}c_{tl}q_{tl}=\varepsilon q_{\star0}+\sum_{j=1}^{k}\left(q_{\star j}+\sum_{i\in I_j}q_{ij}\right)\)

\(\leq\varepsilon q_{\star0}+\sum_{j=1}^{k}\kappa_j\leq\varepsilon s+M.\)

This bound is attained by assigning the successful type entirely to location \(0\) and each unsuccessful type \(i\in I_j\) entirely to location \(j\). The assignment is feasible because each partition set has total mass \(B/R=\kappa_j\).

Every maximizer must therefore attain \(\varepsilon s+M\). The displayed upper bound, together with \(\varepsilon>0\), forces \(q_{\star0}=s\). Thus the table is admissible.

Taking positive rational \(\varepsilon\) tending to zero gives \(C^*\leq M\). The lower bound from Section 2 proves

\(C^*=M.\)

This argument uses an infimum and does not assume that the infimum is attained.

5. Computational consequences

The gap proves that exact computation of \(C^*\) is \(\mathrm{NP}\)-hard: comparison with \(M\) decides the original \(3\)-PARTITION instance.

It also proves hardness of the requested near-optimal output alone. Supply the positive dyadic tolerance

\(\eta=\rho/4.\)

If a polynomial-time algorithm produced an admissible rational table of cost at most \(C^*+\eta\), its output would satisfy:

  • On YES instances, its cost would be at most \(M+\rho/4\).
  • On NO instances, its cost would be at least \(M+\rho\).

Comparing its rational cost with \(M+\rho/2\) would therefore decide \(3\)-PARTITION in polynomial time. The tolerance has polynomial encoding length.

The shared-score constraint is essential to this reduction. When a type splits between two locations, both corresponding score entries must be raised, and each entry incurs the full weight \(\mu_i\), regardless of how little mass uses it. Allowing separate modifications for individual agents would remove this specific cost mechanism.

Thus the stated continuous shared-score problem is \(\mathrm{NP}\)-hard; a polynomial-time algorithm meeting the requested guarantees would imply \(\mathrm{P}=\mathrm{NP}\).
