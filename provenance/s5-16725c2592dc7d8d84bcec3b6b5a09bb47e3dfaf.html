The continuous mirror question, as graded

Given a finite set \(G\) of \(q\) standardized indivisible item classes with rational per-capita supplies \(b_g\), and a finite set \(T\) of \(\tau\) complete agent types with rational masses \(\mu_t\) summing to \(1\), output variables \(x_{t,S}\ge0\) for \(S\subseteq G\) satisfying \(\sum_S x_{t,S}=\mu_t\) and \(\sum_{t,S:g\in S}x_{t,S}=b_g\), such that \(\mathrm{NSW}_\infty(x)=\exp(\sum_{t,S}x_{t,S}\log v_t(S))\ge \mathrm{OPT}_\infty/(4+\varepsilon)\) in time polynomial in \(\tau\), \(q\), input length, and \(1/\varepsilon\), independently of the common denominator \(N\) after clearing rational masses and supplies. Welfare is zero if positive mass receives a zero-valued bundle.

Packaged proof task (what the prover saw — nothing else)

Let \(G\) contain \(q\) standardized indivisible item classes. Each agent can receive a subset \(S\subseteq G\). There are \(\tau\) types; type \(t\) has rational mass \(\mu_t\), with \(\sum_t\mu_t=1\), and a nonnegative, monotone submodular valuation \(v_t\) given by a value oracle. Class \(g\) has rational per-capita supply \(b_g\).
A mass allocation is a finitely supported family \(x_{t,S}\geq0\) satisfying \(\sum_S x_{t,S}=\mu_t\) and \(\sum_{t,S:g\in S}x_{t,S}=b_g\). Define \(\mathrm{NSW}_\infty(x)=\exp(\sum_{t,S}x_{t,S}\log v_t(S))\), taking it to be zero if positive mass receives a zero-valued bundle; let \(\mathrm{OPT}_\infty\) be its maximum over feasible allocations.
Is finding an allocation with \(\mathrm{NSW}_\infty(x)\geq\mathrm{OPT}_\infty/(4+\varepsilon)\) solvable in time polynomial in \(\tau\), \(q\), the input length, and \(1/\varepsilon\), independently of the common denominator \(N\) of the masses and supplies; or is it NP-hard?
For finitely many individual agents, a deterministic polynomial-time \((4+\varepsilon)\)-approximation is known for symmetric Nash social welfare with submodular valuations. Configuration-LP work also concerns finite-agent allocations and does not establish a result for the type-mass problem above.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

Result. The requested approximation is solvable in deterministic polynomial time in the value-oracle model, independently of the numerical value of \(N\). In fact, the argument below gives an approximation factor strictly smaller than \(4\).

As usual, the bit-complexity statement uses the standard convention that value-oracle answers have polynomial-length rational encodings. Equivalently, the algorithm makes polynomially many value queries, with additional computation polynomial in the encoding lengths of the data and oracle answers. Logarithms need only be approximated by rationals.

1. Feasibility and positive welfare

Discard types of zero mass. Feasibility requires \(0\leq b_g\leq1\) for every class. These conditions are also sufficient: let \(u\) range uniformly over \([0,1]\), and give an agent the bundle

\(S(u)=\{g:u\leq b_g\}.\)

Partitioning \([0,1]\) at the supply values gives a rational allocation with at most \(\tau(q+1)\) supported type-bundle pairs. Thus infeasible inputs can be recognized immediately. Assume henceforth that the instance is feasible. The case \(q=0\) is immediate, so assume \(q\geq1\).

We first determine whether positive welfare is possible.

For a type with \(v_t(\varnothing)=0\), submodularity and nonnegativity imply

\(v_t(S)\leq\sum_{g\in S}v_t(\{g\}).\)

Indeed, each marginal contribution in an ordering of \(S\) is at most its marginal contribution to the empty set. Consequently,

\(v_t(S)>0\quad\Longleftrightarrow\quad S\text{ contains some }g\text{ with }v_t(\{g\})>0.\)

Construct a flow network. Each type with \(v_t(\varnothing)=0\) has demand \(\mu_t\); it can send flow to precisely the classes whose singleton values are positive. Class \(g\) has capacity \(b_g\).

A positive-welfare allocation induces a flow satisfying all these demands: from each positive bundle, designate one positive singleton and charge its mass to that class. Therefore, failure to saturate the type demands proves \(\mathrm{OPT}_\infty=0\), in which case any feasible allocation answers the question.

Conversely, a saturating flow constructs a positive-welfare allocation using at most singleton bundles initially. Types with positive empty-set value initially receive the empty bundle. Every class is initially used with mass at most its supply.

Complete the supply equalities one class at a time. If class \(g\) currently occurs with mass \(a_g<b_g\), add it to mass \(b_g-a_g\) of bundles lacking it. This is possible because

\(1-a_g\geq b_g-a_g.\)

Monotonicity preserves positive values. Each class requires at most one split of a supported mass after whole supported masses have been processed. Hence this construction has polynomial support and rational encoding length.

We have therefore either finished the zero-optimum case or obtained a polynomial-support feasible allocation \(x^0\) consisting entirely of positive-valued bundles.

2. An elementary submodular knapsack guarantee

We will use the following deterministic algorithmic fact, with its proof included.

Lemma 1. For a nonnegative monotone submodular function \(f\), nonnegative rational item costs, and one budget constraint, a polynomial-time value-oracle algorithm returns a feasible set of value at least

\(\beta\max\{f(T):T\text{ satisfies the budget}\},\qquad \beta=\frac{3}{10}.\)

Proof. Include all zero-cost items, discard items whose individual cost exceeds the budget, and subtract the value of the included zero-cost set. This reduces the problem to a normalized monotone submodular function \(h\), positive costs, and budget \(B>0\). A multiplicative guarantee for \(h\) also holds after restoring the nonnegative subtracted value.

Starting with the empty set, repeatedly select a remaining item of maximum marginal-value-to-cost ratio. Stop immediately before the first selected item that would exceed the budget. Return the better of the feasible greedy prefix and the best singleton.

Let \(O\) be an optimal feasible set. At any greedy prefix \(P\), submodularity gives

\(h(O)-h(P)\leq\sum_{i\in O\setminus P}\bigl(h(P\cup\{i\})-h(P)\bigr).\)

Since the total cost of \(O\) is at most \(B\), the maximum available marginal density is at least \((h(O)-h(P))/B\).

For analysis, take a fraction of the first overflowing greedy step so that the total cost becomes exactly \(B\). If the successive full or fractional costs are \(\ell_1,\ldots,\ell_k\), the preceding density inequality gives the recurrence

\(F_j\geq F_{j-1}+\frac{\ell_j}{B}\bigl(h(O)-F_{j-1}\bigr),\)

where \(F_j\) is the corresponding interpolated greedy value. Consequently,

\(F_k\geq\left(1-\prod_{j=1}^k(1-\ell_j/B)\right)h(O)\geq(1-e^{-1})h(O).\)

The last inequality uses \(\sum_j\ell_j=B\) and \(1-z\leq e^{-z}\).

If \(P\) is the feasible prefix and \(i\) the overflowing item, submodularity implies

\(F_k\leq h(P)+h(\{i\}).\)

Thus one of the two candidates returned has value at least \((1-e^{-1})h(O)/2\). If all items fit, the algorithm instead obtains an optimum directly. Finally, \(e>5/2\) implies \((1-e^{-1})/2>3/10\). The algorithm uses polynomially many value queries. \(\square\)

3. Additive approximation for logarithmic demand

For a single valuation \(v\), arbitrary rational prices \(p_g\), and positive-valued bundles, define

\(F_p(S)=\log v(S)-p(S),\qquad p(S)=\sum_{g\in S}p_g.\)

The prices may be negative.

Lemma 2. For every rational \(\eta>0\), logarithmic demand can be approximated additively:

\(F_p(S)\geq\max_{T:v(T)>0}F_p(T)-\log(10/3)-\eta,\)

using time polynomial in \(q\), \(1/\eta\), and the relevant encoding lengths, apart from the numerical precision needed to compare logarithms.

Proof. Let \(Z=\{g:p_g<0\}\). Every maximizing bundle contains \(Z\): adding a missing negative-price item strictly improves \(F_p\).

Fix a maximizing bundle \(S^*\). There is a set \(A\subseteq S^*\) of one of the forms

\(A=Z\quad\text{or}\quad A=Z\cup\{g\}\)

such that

\(v(A)>0,\qquad v(S^*)\leq qv(A).\)

To verify this, if \(S^*=Z\), use \(A=Z\). Otherwise, put \(k=|S^*\setminus Z|\). Submodularity gives

\(v(S^*)\leq v(Z)+\sum_{g\in S^*\setminus Z}\bigl(v(Z\cup\{g\})-v(Z)\bigr)\leq\sum_{g\in S^*\setminus Z}v(Z\cup\{g\}).\)

The largest term is therefore at least \(v(S^*)/k\), and \(k\leq q\).

Optimality of \(S^*\), compared with the positive-valued bundle \(A\), now gives

\(0\leq p(S^*\setminus A)\leq\log\frac{v(S^*)}{v(A)}\leq\log q.\)

This is the crucial bound: although individual prices can have large numerical magnitudes, the additional cost after fixing a suitable seed is at most \(\log q\).

Enumerate every positive-valued seed \(Z\) or \(Z\cup\{g\}\). For each seed, enumerate budgets

\(B=j\eta,\qquad 0\leq j\leq\lceil q/\eta\rceil.\)

On the remaining items, costs are nonnegative. Apply Lemma 1 to the nonnegative monotone submodular function \(T\mapsto v(A\cup T)\) with budget \(B\).

For the seed identified above, one enumerated budget satisfies

\(p(S^*\setminus A)\leq B<p(S^*\setminus A)+\eta.\)

The corresponding returned bundle \(S\) satisfies

\(v(S)\geq\frac{3}{10}v(S^*),\qquad p(S)\leq p(S^*)+\eta.\)

Hence

\(F_p(S)\geq F_p(S^*)-\log(10/3)-\eta.\)

Choosing the best enumerated candidate proves the claim. \(\square\)

For bit complexity, we use a rational version of this conclusion. Fix

\(\eta=\frac{1}{100}.\)

For every positive-valued bundle define a deterministically computed rational coefficient \(c_t(S)\) satisfying

\(|c_t(S)-\log v_t(S)|\leq\eta.\)

Run the preceding candidate enumeration and select the candidate maximizing \(c_t(S)-p(S)\), using exact rational comparisons. Comparing the rational coefficients with the true logarithms shows that this returns \(S_t\) satisfying

\(c_t(S_t)-p(S_t)\geq\max_{S:v_t(S)>0}\bigl(c_t(S)-p(S)\bigr)-C,\)

where

\(C=\log(10/3)+3\eta.\)

The three error terms are the budget-grid loss and the two coefficient-approximation errors.

4. The configuration LP and exact marginal constraints

Let \(\mathcal P_t=\{S:v_t(S)>0\}\). Consider the finite, potentially exponentially large, rational LP

\(V=\max\left\{\sum_t\sum_{S\in\mathcal P_t}c_t(S)x_{t,S}:\ \sum_{S\in\mathcal P_t}x_{t,S}=\mu_t,\ \sum_t\sum_{\substack{S\in\mathcal P_t\\g\in S}}x_{t,S}=b_g,\ x\geq0\right\}.\)

It is feasible because it contains \(x^0\). Every feasible solution has total mass one, so its objective is bounded.

Its dual is

\(\min\left\{\sum_t\mu_t\alpha_t+\sum_g b_gp_g:\ \alpha_t+p(S)\geq c_t(S)\text{ for all }t,\ S\in\mathcal P_t\right\},\)

where both \(\alpha\) and \(p\) are unrestricted in sign.

The demand oracle from Section 3 has the following exact implication. If, for every type, its returned bundle satisfies

\(\alpha_t+p(S_t)\geq c_t(S_t),\)

then \((\alpha+C\mathbf 1,p)\) is feasible for the full dual. Since \(\sum_t\mu_t=1\), its objective is only \(C\) larger.

An approximate demand oracle alone is not yet a primal allocation. We next prove the required recovery statement.

Lemma 3. Polynomially many calls to this demand oracle suffice to produce a feasible rational allocation with coefficient objective at least \(V-C-2\eta\).

Proof. Write \(d=\tau+q\), \(r=(\mu,b)\), and \(y=(\alpha,p)\). Each configuration constraint has the form

\(a_{t,S}^{\mathsf T}y\geq c_t(S),\)

where \(a_{t,S}\) has its type indicator and bundle incidence vector as coordinates. In particular,

\(\|a_{t,S}\|_2\leq\sqrt d,\qquad \|r\|_2\leq\sqrt d.\)

Choose a rational integer \(H\geq1\) bounding the absolute values of all coefficient values. Such a bound is computable from polynomially many queries. Indeed, positive bundle values are at most \(v_t(G)\). If \(v_t(\varnothing)>0\), they are at least \(v_t(\varnothing)\); otherwise, every positive bundle contains a positive singleton and is at least the smallest positive singleton value. These queried values bound every relevant logarithm.

Maintain a collection \(J\) of configuration columns, initially containing the support of \(x^0\). Every restricted primal LP on such a collection is feasible and has optimum \(V_J\in[-H,H]\).

There is a computable radius \(R_0=2^{\operatorname{poly}(d,L)}\), uniform over all such collections, within which each restricted dual has an optimal solution. Here \(L\) bounds the encoding lengths of the rational data and coefficients.

For completeness, this is the usual rational-polyhedron bound, applicable even when the dual has lineality. A restricted primal has an optimal basic solution with at most \(d\) positive variables, so Cramer's rule bounds the encoding length of \(V_J\) polynomially in \(d,L\). In its dual optimal face, choose the point of minimum Euclidean norm. That point lies in the span of independent active constraint normals: otherwise a sufficiently small displacement along their common nullspace would preserve feasibility and decrease its norm. It is therefore obtained by solving a system involving at most \(d\) independent active rows and their Gram matrix. Cramer's rule again gives the asserted bound. The number of available configurations does not enter this bound.

Fix a rational threshold \(z\). Start an ellipsoid procedure in a ball of radius

\(R=2(R_0+d+1).\)

At a queried center \(y\):

  • If \(r^{\mathsf T}y>z\), cut with \(r^{\mathsf T}y\leq z\).
  • Otherwise, run the demand oracle for each type. If a returned bundle violates its configuration inequality, add that column to \(J\) and cut with its inequality.
  • If none violates its inequality, accept.

Acceptance certifies

\(V\leq z+C,\)

by the shifted-dual observation above.

Suppose no center has been accepted. Run sufficiently many iterations that the enclosing ellipsoid has volume smaller than a ball of radius

\(\rho=\frac{\eta}{4d}.\)

This takes polynomially many iterations: the rational central-cut ellipsoid method preserves the retained intersection and decreases volume by a factor \(\exp(-\Omega(1/d))\) per iteration, with polynomial bit complexity in the dimension, coefficient lengths, and \(\log(R/\rho)\). These are the standard ellipsoid guarantees; see [Grötschel–Lovász–Schrijver, Chapter 3](https://www.mpi-inf.mpg.de/fileadmin/inf/d1/ellipsoid-lovasz.pdf).

We claim that the collected columns then satisfy

\(V_J>z-\eta.\)

Otherwise, take a restricted-dual optimum \(y^*\) of norm at most \(R_0\), with objective at most \(z-\eta\). Add \(\eta/2\) to every type coordinate, leaving item prices unchanged, and call the result \(y'\).

Every collected configuration inequality now has slack at least \(\eta/2\), while

\(r^{\mathsf T}y'\leq z-\eta/2.\)

The norm bounds on the inequality normals imply that the entire ball of radius \(\rho\) around \(y'\) satisfies every collected inequality and the objective inequality. This ball also lies inside the initial radius-\(R\) ball. Consequently, it survives every cut and must lie in the final ellipsoid, contradicting the final volume bound. This proves the claim.

Finally, bisect an interval initially equal to \([-H,H]\). At an accepted midpoint replace the upper endpoint by that midpoint; at a nonaccepted midpoint replace the lower endpoint by that midpoint. Retain all collected columns.

Throughout, with endpoints \(L_0,U_0\), the established certificates give

\(V\leq U_0+C,\qquad V_J\geq L_0-\eta.\)

Initially these hold because all objectives lie in \([-H,H]\). Each update preserves them by the two conclusions just proved.

When \(U_0-L_0\leq\eta\),

\(V_J\geq V-C-2\eta.\)

Solve the polynomial-size restricted primal LP exactly. Its solution satisfies every original type and supply equality. An optimal basic solution has at most \(d\) positive entries and polynomial rational encoding length. \(\square\)

5. Approximation guarantee

Let

\(L^*=\log\mathrm{OPT}_\infty.\)

We are in the positive-optimum case, so this is the optimum of the configuration LP with the true logarithmic coefficients.

Because every feasible allocation has total mass one, replacing its logarithmic coefficients by \(c_t(S)\) changes its objective by at most \(\eta\). Thus

\(|V-L^*|\leq\eta.\)

For the allocation returned by Lemma 3,

\(\log\mathrm{NSW}_\infty(x)\geq V-C-3\eta\geq L^*-C-4\eta.\)

Substituting \(C=\log(10/3)+3\eta\) yields

\(\log\mathrm{NSW}_\infty(x)\geq L^*-\log(10/3)-7\eta.\)

Therefore,

\(\mathrm{NSW}_\infty(x)\geq\frac{\mathrm{OPT}_\infty}{(10/3)e^{7/100}}.\)

This denominator is strictly smaller than \(4\). Explicitly, \(7/100<1/8\), and the power series for the exponential gives \(e^u\leq1/(1-u)\) for \(0\leq u<1\). Hence

\(\frac{10}{3}e^{7/100}<\frac{10}{3}e^{1/8}\leq\frac{80}{21}<4.\)

The returned allocation consequently satisfies the requested guarantee for every \(\varepsilon>0\).

6. Running time and denominator independence

All flow computations, budget enumerations, ellipsoid iterations, value queries, and the final rational LP have polynomial size. The accuracy parameter used above is the fixed constant \(\eta=1/100\), so the algorithm is also polynomial in \(1/\varepsilon\).

Masses and supplies enter through their binary rational encodings. No step creates \(N\) individual agents or \(Nb_g\) item copies. The output has polynomial encoding length and, in the positive-optimum case, at most \(\tau+q\) supported type-bundle pairs.

Thus the proof establishes the approximation directly for the type-mass problem; it does not require transferring the finite-agent approximation theorem.
