The continuous mirror question, as graded

Given finite-support producer and consumer type distributions μ and ν with rational masses summing to one, producer types carrying capacity and cost parameters \((\bar{x}_t,\gamma_t)\), consumer types carrying valuation parameters θ_s, a positive population ratio ρ, and explicitly encoded population production, valuation, and cost functions \(Y(\mu,a)\), \(w\), and \(c\), find a type-level per-producer contribution vector \(a\), with \(0\le a_t\le\bar{x}_t\), maximizing \(\rho\sum_s\nu_s w(Y(\mu,a),\theta_s)-\sum_t\mu_t c(a_t,\gamma_t)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: its positive-mass types and their binary rational masses. Producer and consumer distributions \(\mu,\nu\) each have total mass \(1\); \(\tau=|\operatorname{supp}\mu|+|\operatorname{supp}\nu|\) counts listed types, not possible types.
Producer type \(t\) has capacity \(\bar x_t\in\mathbb Q_{\ge0}^{m}\) and cost parameter \(\gamma_t\in\mathbb Q_{\ge0}\); consumer type \(s\) has valuation parameter \(\theta_s\in\mathbb Q_{\ge0}\). The consumer-to-producer population ratio is \(\rho\in\mathbb Q_{>0}\).
Production \(Y(\mu,a)\), valuation \(w(y,\theta)\), and cost \(c(a,\gamma)\) are explicitly encoded, single-valued semialgebraic functions, specified by quantifier-free graph formulas using rational polynomials in sparse representation with binary exponents. Their domains are supplied semialgebraic sets containing all relevant arguments; \(Y\) is scalar and nonnegative.
Promise that \(v_\mu(a,\theta)=w(Y(\mu,a),\theta)\) and \(c(a_t,\gamma)\) are nonnegative, smooth on neighborhoods of their relevant domains, and coordinatewise nondecreasing in contributions and their respective type parameters. Also \(c(0,\gamma)=0\) and \(w(y,0)=0\); zero is an admissible consumer type but need not have positive mass.
A zero-contributing producer type can be deleted without changing any valuation, retaining the remaining masses without renormalization; production functions are defined on these subprobability supports as well.
Each producer type receives one common real contribution vector \(a_t\), with \(0\le a_t\le\bar x_t\) coordinatewise. Define surplus per unit producer mass by \(F(a)=\rho\sum_s\nu_s w(Y(\mu,a),\theta_s)-\sum_t\mu_t c(a_t,\gamma_t)\).
For a binary rational threshold \(B\), the exact decision problem asks whether \(\max_{0\le a_t\le\bar x_t}F(a)\ge B\). Let \(L\) be the total input bit length, including function descriptions, domains, and \(B\).

Is this continuous surplus decision problem in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite agent lists with divisible contributions, truthful implementation of a capacity-constrained surplus maximizer is known to attain ex-post allocative efficiency; this establishes no polynomial-time algorithm or hardness classification. Result

The decision problem is \(\mathrm{NP}\)-hard, even with one producer type, one positive-mass consumer type, quadratic production in contributions, and linear cost at the listed producer parameter. Consequently, an algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).

The reduction below satisfies all the stated promises, including smoothness, monotonicity, and deletion of zero-contributing types.

1. Source problem and construction

We reduce from Independent Set: given a simple undirected graph \(G=(V,E)\) and an integer \(k\), decide whether its independence number \(\alpha(G)\) satisfies \(\alpha(G)\ge k\). This problem is \(\mathrm{NP}\)-hard: a graph has a clique of size \(k\) exactly when its complement has an independent set of size \(k\), and Clique is one of [Karp’s classical complete problems](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Label \(V=\{1,\ldots,n\}\), with \(n\ge1\). Construct a society with:

  • \(m=n\) contribution coordinates;
  • one producer type \(t\), with \(\mu_t=1\), \(\gamma_t=1\), and \(\bar x_t=(1,\ldots,1)\);
  • one positive-mass consumer type \(s\), with \(\nu_s=1\) and \(\theta_s=1\);
  • \(\rho=1\) and threshold \(B=k\).

Thus \(\tau=2\), and the feasible contribution vector is \(a\in[0,1]^n\).

Define
\[ Y(\mu,a)=2n\sum_{i=1}^n a_i-2\sum_{\{i,j\}\in E}a_i a_j, \]
\[ w(y,\theta)=\theta y, \qquad c(a,\gamma)=(2n-1)\gamma\sum_{i=1}^n a_i. \]

The resulting surplus is
\[ F(a) =Y(\mu,a)-c(a,1) =\sum_{i=1}^n a_i-2\sum_{\{i,j\}\in E}a_i a_j. \]

We will prove that
\[ \max_{a\in[0,1]^n}F(a)=\alpha(G). \]

2. Verification of the promises

Production and deletion

To specify production on subprobability supports as well, let \(p\in[0,1]\) be the retained mass of the single possible producer type. Define
\[ Y_p(a)=2np\sum_{i=1}^n a_i -2p^2\sum_{\{i,j\}\in E}a_i a_j. \]

At \(p=1\), this is the production function above. The empty producer support is represented by \(p=0\), for which \(Y_0=0\). This representation does not add a zero-mass type to the listed support.

Writing \(N(i)\) for the neighbors of vertex \(i\), we have
\[ \frac{\partial Y_p}{\partial a_i} =p\left(2n-2p\sum_{j\in N(i)}a_j\right). \]
For \(p\in[0,1]\) and \(a\in[0,1]^n\), simplicity of the graph gives
\[ \sum_{j\in N(i)}a_j\le |N(i)|\le n-1. \]
Therefore
\[ \frac{\partial Y_p}{\partial a_i} \ge p\bigl(2n-2(n-1)\bigr) =2p\ge0. \]

Hence production is coordinatewise nondecreasing in contributions. Since \(Y_p(0)=0\), it is also nonnegative throughout its supplied domain.

If the producer contributes zero, then \(Y_p(0)=0=Y_0\). Deleting that type therefore changes no consumer valuation. There are no remaining producer masses to renormalize.

Valuation and cost

For \(y,\theta\ge0\), the valuation \(w(y,\theta)=\theta y\) is nonnegative and satisfies \(w(y,0)=0\). Its composition with production obeys
\[ \frac{\partial v_p}{\partial a_i} =\theta\frac{\partial Y_p}{\partial a_i}\ge0, \qquad \frac{\partial v_p}{\partial\theta}=Y_p(a)\ge0. \]

For \(a\in[0,1]^n\) and \(\gamma\ge0\), cost is nonnegative, and
\[ c(0,\gamma)=0, \]
\[ \frac{\partial c}{\partial a_i}=(2n-1)\gamma\ge0, \qquad \frac{\partial c}{\partial\gamma} =(2n-1)\sum_{i=1}^n a_i\ge0. \]

All these functions are polynomials, so they extend smoothly to neighborhoods of their domains. Their supplied domains can be
\[ [0,1]\times[0,1]^n \quad\text{for production}, \]
\[ [0,\infty)\times[0,\infty) \quad\text{for valuation}, \]
and
\[ [0,1]^n\times[0,\infty) \quad\text{for cost}. \]
These domains contain every relevant argument, including consumer parameter zero.

Each graph is specified by its domain inequalities together with the displayed polynomial equality defining its output. Thus the functions are single-valued and have the required quantifier-free semialgebraic descriptions.

3. Fractional contributions cannot improve the optimum

The surplus polynomial is multiaffine, meaning that it is affine in each coordinate when the other coordinates are fixed.

Indeed, fixing all coordinates except \(a_i\), its dependence on \(a_i\) is
\[ F(a)=C_i+ a_i\left(1-2\sum_{j\in N(i)}a_j\right), \]
where \(C_i\) is independent of \(a_i\).

An affine function on \([0,1]\) has an endpoint whose value is at least its value at any specified point. Starting from any feasible \(a\), replace \(a_1\) by such an endpoint, then replace \(a_2\), and continue through \(a_n\). Every replacement preserves feasibility and does not decrease surplus.

The final vector \(b\in\{0,1\}^n\) therefore satisfies \(F(b)\ge F(a)\). Since every binary vector is also feasible,
\[ \max_{a\in[0,1]^n}F(a) = \max_{b\in\{0,1\}^n}F(b). \]
The continuous maximum exists because \(F\) is continuous on the compact box.

4. The binary optimum equals the independence number

For \(b\in\{0,1\}^n\), let
\[ S=\{i:b_i=1\}, \]
and let \(e(S)\) denote the number of edges with both endpoints in \(S\). Then
\[ F(b)=|S|-2e(S). \]

If \(S\) is independent, \(e(S)=0\), so its surplus is \(|S|\). A maximum independent set therefore gives surplus \(\alpha(G)\).

Conversely, suppose \(S\) is not independent. Choose a vertex \(i\in S\) incident to an edge within \(S\), and let \(d_S(i)\ge1\) be its degree in the induced graph. Removing \(i\) changes surplus by
\[ \begin{aligned} \bigl(|S\setminus\{i\}|-2e(S\setminus\{i\})\bigr) -\bigl(|S|-2e(S)\bigr) &=-1+2d_S(i)\\ &\ge1. \end{aligned} \]

Repeated removal terminates at an independent set \(I\), while strictly increasing surplus whenever a removal occurs. Thus every set \(S\) satisfies
\[ |S|-2e(S)\le |I|\le\alpha(G). \]

Combining both directions gives
\[ \max_{a\in[0,1]^n}F(a)=\alpha(G). \]

5. Encoding size and conclusion

The production description has \(n+|E|\) monomials. Its coefficients have bit length \(O(\log n)\), and all exponents are bounded by a constant, including in the subprobability extension. The domain inequalities, capacities, masses, cost, valuation, and threshold also have polynomial encoding length. Even an encoding storing full exponent vectors has polynomial size.

The construction is therefore a polynomial-time many-one reduction, and
\[ \max_{0\le a_t\le\bar x_t}F(a)\ge B \quad\Longleftrightarrow\quad \alpha(G)\ge k. \]

This proves \(\mathrm{NP}\)-hardness for the specified distributional problem. It does not assert membership of the full semialgebraic problem in \(\mathrm{NP}\).

The cited mechanism-design paper leaves computational issues concerning optimal surplus for future research; its efficiency theorem does not supply a polynomial-time optimization algorithm. [Cong et al.](https://arxiv.org/pdf/2007.14780)
