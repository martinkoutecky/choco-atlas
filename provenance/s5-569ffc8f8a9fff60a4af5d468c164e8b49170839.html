Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Each type has a binary rational weight \(a_t>0\); the input also specifies a supported target type \(t^\star\) and a binary rational threshold \(\theta\in[0,1]\). Let \(L\) be the total input bit length; the policy space is one-dimensional, so \(m=1\).
For every positive integer \(N\) with \(N\mu_t\in\mathbb Z\) for all types, create \(N\mu_t\) voters of type \(t\), each of weight \(a_t\). Types specify weights, not fixed policy votes.
For votes \(x\in[0,1]^N\), order voters by nondecreasing votes using any fixed ordering of equal votes. Write \(W=\sum_i a_{t(i)}\), let \(\ell\) be the first position whose prefix weight is at least \(W/2\), and let \(r\) be the last position whose suffix weight is at least \(W/2\). Define the aggregation rule \(v_N(x)=(x_{(\ell)}+x_{(r)})/2\), including exact half-weight ties.
Choose independently a uniform random voter permutation \(\pi\) and independent uniform votes \(X_i\in[0,1]\). For a voter set \(A\), let \(X^{A,b}\) retain the votes in \(A\) and set every other vote to \(b\in\{0,1\}\); let \(A_i\) be the voters preceding \(i\) in \(\pi\).
Define \(\operatorname{SSI}_i(v_N)=\mathbb E[v_N(X^{A_i,1})-v_N(X^{A_i\cup\{i\},1})+v_N(X^{A_i\cup\{i\},0})-v_N(X^{A_i,0})]\) and \(P_{t^\star}^{(N)}=\sum_{i:t(i)=t^\star}\operatorname{SSI}_i(v_N)\).

Does \(\lim_{N\to\infty}P_{t^\star}^{(N)}\) exist along all denominator-compatible integers for every input, and is deciding whether this limit is at least \(\theta\) in \(\mathrm P\) or \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L\).

For finitely many voters with no coalition of weight exactly \(W/2\), the weighted-median index above equals the binary Shapley–Shubik index of the game in which a coalition wins precisely when its weight is at least \(W/2\); this identity asserts no complexity bound. Result

The limit exists for every input, along all denominator-compatible integers, and equals
\[ \lim_{N\to\infty}P_{t^\star}^{(N)} = \frac{\mu_{t^\star}a_{t^\star}}{\sum_{t=1}^{\tau}\mu_ta_t}. \]

Consequently, the threshold problem is in \(\mathrm P\). For the stipulated dimension \(m=1\), an exact algorithm uses \(O(\tau L^2)\) bit operations and \(O(L)\) space.

The proof below handles exact half-weight ties explicitly.

1. Representing the midpoint median by coalition values

Fix a compatible population size \(N\). Let \(V\) be its voter set, write \(w_i=a_{t(i)}>0\), and define \(w(C)=\sum_{i\in C}w_i\) and \(W=w(V)\).

Define the coalition function
\[ g(C)=\mathbf 1_{\{w(C)>W/2\}} +\frac12\mathbf 1_{\{w(C)=W/2\}}. \]

Thus a coalition has value zero below half the weight, one half at an exact tie, and one above half.

For \(x\in[0,1]^N\), define
\[ F_g(x)=\int_0^1 g(\{i:x_i\ge z\})\,dz. \]

Claim. \(F_g(x)=v_N(x)\) for every vote vector \(x\).

To prove this, use the ordering specified in the question and write \(c_k=\sum_{j=1}^k w_{(j)}\), with \(c_0=0\). Positivity of the weights makes these prefix sums strictly increasing. There are two cases.

  • If \(c_\ell>W/2\), then \(c_{\ell-1}<W/2\). The suffix beginning at \(\ell\) has weight above half, while the suffix beginning at \(\ell+1\) has weight below half. Hence \(r=\ell\). For \(z<x_{(\ell)}\), the coalition \(\{i:x_i\ge z\}\) has weight above half; for \(z>x_{(\ell)}\), it has weight below half. Therefore \(F_g(x)=x_{(\ell)}=v_N(x)\).
  • If \(c_\ell=W/2\), then \(r=\ell+1\). For \(z<x_{(\ell)}\), the coalition has weight above half; for \(x_{(\ell)}<z<x_{(\ell+1)}\), it has weight exactly half; and for \(z>x_{(\ell+1)}\), it has weight below half. Consequently,

\[ F_g(x) = x_{(\ell)}+\frac{x_{(\ell+1)}-x_{(\ell)}}2 = v_N(x). \]

These statements remain valid when some votes coincide: the interval between equal adjacent votes has length zero. Values at the finitely many vote thresholds do not affect the integral. This proves the claim.

2. An exact identity with the Shapley value

For a coalition function \(h:2^V\to[0,1]\), define its Shapley value by
\[ \phi_i(h) = \mathbb E_\pi[h(A_i\cup\{i\})-h(A_i)], \]
where \(\pi\) is a uniform random permutation.

We prove the following identity for any monotone \(h\) with \(h(\varnothing)=0\) and \(h(V)=1\):
\[ \operatorname{SSI}_i(F_h)=\phi_i(h), \qquad F_h(x)=\int_0^1h(\{j:x_j\ge z\})\,dz. \]

For \(p\in[0,1]\), let \(B_p\subseteq V\setminus\{i\}\) include each voter independently with probability \(p\), and set
\[ M_i(p)= \mathbb E[h(B_p\cup\{i\})-h(B_p)]. \]

Generate the random permutation by independent uniform priorities \(U_j\), independently of all votes. Conditional on \(U_i=s\), every other voter precedes \(i\) independently with probability \(s\).

Fix a vote threshold \(z\in(0,1)\).

For the term with unrevealed votes set to zero, revealing \(i\) changes the threshold coalition only if \(X_i\ge z\), an event of probability \(1-z\). Each other voter belongs to that coalition precisely when it precedes \(i\) and its vote is at least \(z\), independently with probability \(s(1-z)\). Its conditional expected contribution is therefore
\[ (1-z)M_i(s(1-z)). \]

For the term with unrevealed votes set to one, revealing \(i\) changes the threshold coalition only if \(X_i<z\), an event of probability \(z\). Each other voter belongs to that coalition unless it both precedes \(i\) and has vote below \(z\), independently with probability \(1-sz\). Its conditional expected contribution is
\[ zM_i(1-sz). \]

All integrands are bounded, so exchanging expectation and integration is justified. We obtain
\[ \operatorname{SSI}_i(F_h) = \int_0^1\int_0^1 \bigl((1-z)M_i(s(1-z))+zM_i(1-sz)\bigr)\,ds\,dz. \]

For the first integral, substituting \(q=1-z\) and then \(p=sq\) gives
\[ \int_0^1\int_0^1(1-z)M_i(s(1-z))\,ds\,dz = \int_0^1\int_0^qM_i(p)\,dp\,dq = \int_0^1(1-p)M_i(p)\,dp. \]

For the second integral, substituting \(p=1-sz\) gives
\[ \int_0^1\int_0^1zM_i(1-sz)\,ds\,dz = \int_0^1\int_{1-z}^1M_i(p)\,dp\,dz = \int_0^1pM_i(p)\,dp. \]

Their sum is \(\int_0^1M_i(p)\,dp\). Conditional on \(U_i=p\), the predecessor coalition has exactly the distribution of \(B_p\). Hence this integral is \(\phi_i(h)\), proving the identity.

Applying it to Section 1 gives the exact finite-population equality
\[ \operatorname{SSI}_i(v_N)=\phi_i(g). \]

3. Exact ties give the same Shapley value as strict majority

Define the two binary games
\[ h_>(C)=\mathbf 1_{\{w(C)>W/2\}}, \qquad h_{\ge}(C)=\mathbf 1_{\{w(C)\ge W/2\}}. \]

Then \(g=(h_>+h_{\ge})/2\).

For any normalized coalition function \(h\), its dual is \(h^d(C)=1-h(V\setminus C)\). Shapley values are invariant under duality. Here is a direct justification.

If \(A\) precedes \(i\) in a permutation, put \(D=V\setminus(A\cup\{i\})\). Then
\[ h^d(A\cup\{i\})-h^d(A) = h(D\cup\{i\})-h(D). \]
The set \(D\) precedes \(i\) in the reversed permutation. Reversal preserves the uniform permutation distribution, so \(\phi_i(h^d)=\phi_i(h)\).

Since \(w(V\setminus C)=W-w(C)\), we have
\[ h_{\ge}(C)=1-h_>(V\setminus C). \]
Thus \(h_{\ge}=h_>^d\). Linearity of the Shapley value now yields
\[ \phi_i(g) = \frac{\phi_i(h_>)+\phi_i(h_{\ge})}{2} = \phi_i(h_>). \]

Therefore, even when exact half-weight coalitions exist,
\[ \boxed{\operatorname{SSI}_i(v_N)=\phi_i(h_>)=\phi_i(h_{\ge}).} \]

This equality concerns the indices; the three coalition functions themselves need not coincide.

4. Convergence along every compatible population size

We use the following precise form of Neyman’s renewal theorem. For a finite nonnegative weight vector \(\lambda\) summing to one, let \(Q_i(\lambda,q)\) be the probability that voter \(i\) first makes the accumulated weight strictly exceed \(q\) in a uniform random ordering. Given \(\varepsilon>0\), constants \(\delta>0\) and \(K>0\) exist such that, writing \(\rho=\max_i\lambda_i\),
\[ \rho<\delta \quad\text{and}\quad K\rho<q<1-K\rho \quad\Longrightarrow\quad \sum_i|Q_i(\lambda,q)-\lambda_i|<\varepsilon. \]
This is the main theorem of [Neyman, *Renewal Theory for Sampling Without Replacement* (1982), author-uploaded paper](https://www.researchgate.net/publication/38361781_Renewal_Theory_for_Sampling_Without_Replacement).

Set
\[ \bar a=\sum_{t=1}^{\tau}\mu_ta_t>0. \]
For every compatible \(N\), the total voter weight is exactly \(W_N=N\bar a\). Normalize each individual weight as
\[ \lambda_i^{(N)}=\frac{a_{t(i)}}{N\bar a}. \]

These weights are positive and sum to one. Furthermore,
\[ \rho_N=\max_i\lambda_i^{(N)} = \frac{\max_t a_t}{N\bar a} \longrightarrow0. \]

Take \(q=1/2\). For every fixed \(\varepsilon>0\), all sufficiently large compatible \(N\) satisfy both hypotheses of Neyman’s theorem. In the strict-majority game, the marginal contribution equals one exactly for the voter first making the prefix weight exceed half. Section 3 therefore identifies
\[ Q_i(\lambda^{(N)},1/2)=\operatorname{SSI}_i(v_N). \]

Consequently,
\[ \sum_{i\in V_N} \left|\operatorname{SSI}_i(v_N)-\lambda_i^{(N)}\right| \longrightarrow0. \]

There are \(N\mu_{t^\star}\) target-type voters, whose total normalized weight is
\[ \sum_{i:t(i)=t^\star}\lambda_i^{(N)} = \frac{\mu_{t^\star}a_{t^\star}}{\bar a}. \]
Hence
\[ \left| P_{t^\star}^{(N)} - \frac{\mu_{t^\star}a_{t^\star}}{\bar a} \right| \le \sum_{i\in V_N} \left|\operatorname{SSI}_i(v_N)-\lambda_i^{(N)}\right| \longrightarrow0. \]

The theorem’s hypotheses hold for every sufficiently large compatible integer, so this proves convergence along all such integers, without choosing a particular subsequence. Compatible integers are unbounded because every multiple of a common denominator of the masses is compatible.

5. Exact threshold decision and running time

The requested decision is equivalent to
\[ \mu_{t^\star}a_{t^\star} \ge \theta\sum_{t=1}^{\tau}\mu_ta_t. \]

This comparison can be performed exactly, including equality.

For an explicit bit bound, write the input rationals as
\[ \mu_t=\frac{p_t}{q_t}, \qquad a_t=\frac{r_t}{s_t}, \qquad \theta=\frac{h}{k}, \]
with positive denominators. Define
\[ D=\prod_{t=1}^{\tau}q_ts_t, \qquad b_t=p_tr_t\,\frac{D}{q_ts_t}, \qquad B=\sum_{t=1}^{\tau}b_t. \]
These are integers, and the answer is yes precisely when
\[ k b_{t^\star}\ge h B. \]

The total encoding length bounds the sum of the bit lengths of all input numerators and denominators by \(O(L)\). Thus \(D\), every \(b_t\), \(B\), and both comparison products have \(O(L)\) bits. Using ordinary schoolbook integer arithmetic, the construction and comparison require \(O(\tau)\) operations costing at most \(O(L^2)\) each.

Accordingly, for \(m=1\), the running time is \(O(\tau L^2)\), with \(O(L)\) space when the terms are processed sequentially. Since \(\tau=O(L)\), this is also an \(O(L^3)\) bound. The algorithm never constructs a finite voter population.
