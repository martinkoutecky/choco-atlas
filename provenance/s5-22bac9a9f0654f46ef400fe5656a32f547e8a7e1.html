The continuous mirror question, as graded

Given a finite alternative set \(X\) and \(\tau\) supported antisymmetric acyclic preference types \(\succsim_t\) with positive rational masses \(p_t\) summing to \(1\), choose for each type a preorder \(R_t\) extending \(\succsim_t\) to minimize \(\sum_t p_t D(\succsim_t,R_t)\); output the minimizing tuple and its value.

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a finite alternative set with \(m=|X|\geq 2\). A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(p_t\) a binary rational, with \(\sum_{t=1}^{\tau}p_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
Each type is a reflexive, antisymmetric relation \(\succsim_t\), given explicitly as a Boolean matrix, whose asymmetric part is acyclic. For any relation \(Q\), write \(Q^{>}=\{(x,y):xQy\text{ and }\neg(yQx)\}\).
A feasible choice for type \(t\) is any preorder \(R_t\) satisfying \(\succsim_t^{>}\subseteq R_t^{>}\); completeness is not required, and indifferences are permitted only when consistent with this condition.
Define \(M(S,Q)=\{x\in S:\nexists y\in S\text{ with }yQ^{>}x\}\) and the top-difference semimetric \(D(Q,R)=\sum_{S\subseteq X}|M(S,Q)\triangle M(S,R)|\).
Output a feasible tuple minimizing \(\sum_{t=1}^{\tau}p_tD(\succsim_t,R_t)\), together with its exact rational value; any minimizing tuple is acceptable.

Is this exact optimization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a single antisymmetric acyclic preference, its transitive closure is a minimizing preorder extension under \(D\); evaluating \(D\) on explicitly given relations takes polynomial time. These facts are established by [Nishimura and Ok](https://hirokinishimura.com/wp-content/uploads/2023/10/PrefMetric.pdf). No separate complexity result for the distribution formulation was verified.

Modeling choices made when packaging the task

  • Specified at least two alternatives and reflexive input relations, as required by the discrete preference domain.
  • Interpreted extension as preservation of the asymmetric part, rather than mere inclusion of the input relation.
  • Specified explicit Boolean-matrix encoding of relations and total input bit length L.
  • Allowed incomplete preorders and any minimizing tuple, without imposing tie-breaking.

1. Result. The exact optimization problem is polynomial-time solvable in \(m,\tau,L\). An optimal tuple consists of the transitive closures of the given relations.

Here each support type has its own feasible preorder, exactly as specified in the task. The proof below establishes optimality and polynomial bit complexity, including computation of the exact rational objective value.

2. A minimizing extension for each type. Fix a type and write \(Q=\succsim_t\) and \(A=Q^{>}\). Let \(C\) be the positive-length reachability relation of the directed graph \(A\), and define \(T=\Delta_X\cup C\), where \(\Delta_X=\{(x,x):x\in X\}\).

Reachability is transitive. Moreover, \(C\) is irreflexive: a positive-length path from a vertex to itself would contain a directed cycle, contrary to acyclicity of \(A\). Similarly, \(C\) cannot contain both \((x,y)\) and \((y,x)\), because concatenating their witnessing paths would give a closed directed walk and hence a directed cycle. Consequently, \(T\) is a partial order with \(T^{>}=C\). Since \(A\subseteq C\), it is feasible. Reflexivity and antisymmetry of \(Q\) give \(Q=\Delta_X\cup A\), so \(T\) is precisely its transitive closure.

We next show that every feasible preorder \(R\) satisfies \(C\subseteq R^{>}\).

First, the asymmetric part of any preorder is transitive. Indeed, suppose \(xR^{>}y\) and \(yR^{>}z\). Transitivity gives \(xRz\). If \(zRx\), transitivity applied to \(zRxRy\) gives \(zRy\), contradicting \(yR^{>}z\). Therefore \(xR^{>}z\). Applying this fact successively along any directed \(A\)-path, using feasibility \(A\subseteq R^{>}\), proves \(C\subseteq R^{>}\).

Thus, for every feasible \(R\),

\( Q^{>}\subseteq T^{>}\subseteq R^{>}. \)

By the definition of maximal elements, enlarging the strict relation can only remove maximal elements. Hence, for every \(S\subseteq X\),

\( M(S,R)\subseteq M(S,T)\subseteq M(S,Q). \)

For nested finite sets, the symmetric difference consists exactly of the elements removed. Therefore,

\( |M(S,Q)\triangle M(S,R)| =|M(S,Q)|-|M(S,R)| \geq |M(S,Q)|-|M(S,T)| =|M(S,Q)\triangle M(S,T)|. \)

Summing over all menus proves \(D(Q,R)\geq D(Q,T)\). This establishes the needed single-type minimizing property directly; it also agrees with the transitive-closure result in [Nishimura and Ok, Section 5](https://hirokinishimura.com/wp-content/uploads/2023/10/PrefMetric.pdf).

For each type, let \(T_t\) be the closure just constructed. Every feasible tuple then satisfies

\( \sum_{t=1}^{\tau}p_tD(\succsim_t,R_t) \geq \sum_{t=1}^{\tau}p_tD(\succsim_t,T_t), \)

because each individual inequality holds and each \(p_t\) is positive. The tuple \((T_1,\ldots,T_\tau)\) is feasible, so it attains the minimum.

3. Exact value without enumerating menus. For a relation \(Q\), define the strict predecessor set \(P_Q(x)=\{y\in X:yQ^{>}x\}\).

An alternative \(x\) belongs to \(M(S,Q)\) exactly when \(x\in S\) and \(S\cap P_Q(x)=\varnothing\). Since \(x\notin P_Q(x)\), the remaining \(m-1-|P_Q(x)|\) elements can be included independently. Thus,

\( |\{S\subseteq X:x\in M(S,Q)\}|=2^{m-1-|P_Q(x)|}. \)

For the closure \(T\), we already proved \(M(S,T)\subseteq M(S,Q)\). Interchanging two finite sums therefore gives

\( D(Q,T) =\sum_{S\subseteq X}\bigl(|M(S,Q)|-|M(S,T)|\bigr) =\sum_{x\in X}\left(2^{m-1-|P_Q(x)|}-2^{m-1-|P_T(x)|}\right). \)

Consequently, set \(a_t(x)=|P_{\succsim_t}(x)|\) and \(c_t(x)=|P_{T_t}(x)|\). The exact minimum is

\( V=\sum_{t=1}^{\tau}p_t \sum_{x\in X} \left(2^{m-1-a_t(x)}-2^{m-1-c_t(x)}\right). \)

All exponents are nonnegative, since predecessor sets exclude the alternative itself.

4. Algorithm and bit complexity. Compute each \(T_t\) by Boolean transitive closure, count its strict predecessors and those of \(\succsim_t\), and evaluate the formula above. Output the closure matrices together with \(V\).

Transitive closure requires \(O(\tau m^3)\) Boolean operations. Counting predecessors requires \(O(\tau m^2)\) operations. Write \(d_t=D(\succsim_t,T_t)\). The formula shows

\( 0\leq d_t\leq m\,2^{m-1}, \)

so each distance has \(O(m+\log m)\) bits. The exponentially large numerical values therefore require only polynomially many bits.

For exact rational arithmetic, write the input masses as \(p_t=u_t/v_t\), with positive integer denominators. Let \(B=\prod_{t=1}^{\tau}v_t\). Its bit length is at most the sum of the input denominator bit lengths, hence \(O(L)\). Compute

\( N=\sum_{t=1}^{\tau}u_t d_t(B/v_t), \qquad V=N/B. \)

Every division \(B/v_t\) is exact. Because the masses sum to one, \(0\leq V\leq m2^{m-1}\), and thus \(0\leq N\leq Bm2^{m-1}\). The integers used here have \(O(L+m+\log m)\) bits. Standard integer multiplication, division, addition, and optional reduction by a greatest common divisor all take polynomial time at these lengths.

The output matrices occupy \(\tau m^2\) bits, and the exact rational value has polynomial bit length. This completes the polynomial-time algorithm and its proof.
