Theorem 1 (Binary Action Model) — class: hardness

The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), a directed type-observation graph, binary signal probabilities \(p_{t,\theta}\), a prior, and type-specific utilities and tie-breaking rules, consider populations at scales \(N\) with \(N\mu_t\in\mathbb{N}\). Agents within each type are identical and receive independent signals conditional on \(\theta\); they observe the fractions of action-\(1\) reports in adjacent cohorts and update by Bayes’ rule. For an uninformative target at time \(2\) and an observed share vector \(h\), let \(\mathcal{X}(h)\subseteq[0,1]^T\) be the signal-share vectors inducing \(h\), and define \(I_\theta(h)=\inf_{x\in\mathcal{X}(h)}\sum_{t\in T}\mu_tD_{\mathrm{KL}}(x_t\Vert p_{t,\theta})\), where \(D_{\mathrm{KL}}\) is binary relative entropy. Given \(\epsilon>0\), determine the MAP state under the promise \(I_0(h)-I_1(h)\ge\epsilon\) or \(I_0(h)-I_1(h)\le-\epsilon\).

Inputs also specify a directed observation graph, rational probabilities \(0<p_{t,\theta}<1\), a common rational prior \(0<\nu(1)<1\), rational utilities \(u_t(a,\theta)\) of either sign, and a fixed preferred action for ties. All these data are common knowledge.
For each integer scale \(N\) with \(N\mu_t\in\mathbb N\), type \(t\) contains \(N\mu_t\) agents whose signals are independent conditional on \(\theta\), with probability \(p_{t,\theta}\) of signal \(1\). An edge \(t\to u\) means every type-\(t\) agent observes the action-\(1\) fraction in cohort \(u\), separately for each observed cohort. Each agent also remembers her own signal and actions; information is counted only once.
At round \(0\), agents condition on their private signals. At round \(1\), they additionally condition on all observed round-\(0\) fractions. They use Bayes’ rule and choose actions myopically to maximize expected utility, applying their specified tie rule.

1. Result

The continuous rate-based MAP promise problem is \(\mathrm{NP}\)-hard, already for \(m=2\). Consequently, an algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The reduction below preserves the finite-scale Bayesian dynamics exactly. Its essential feature is that hidden cohort counts can differ by one while their fractions converge to the same limit. Those count differences encode a vertex cover and impose different entropy costs on other cohorts.

2. Bayesian threshold rules

Use the uniform prior and prefer action \(0\) at ties. For any positive rational \(\rho\), define utilities by

\[ \text{} \]

\(\displaystyle u(1,1)=1,\qquad u(0,0)=\rho,\qquad u(1,0)=u(0,1)=0.\)

If the posterior odds of state \(1\) are \(O\), this agent chooses action \(1\) exactly when \(O>\rho\): the expected utility difference, after multiplication by the positive posterior normalizing factor, is \(O-\rho\).

A source cohort will have

\(\displaystyle p_0=\frac13,\qquad p_1=\frac23,\qquad \rho=1,\)

and observe no other cohort. Its agents choose their private signals at both rounds. If its size is \(n\) and its signal-\(1\) count is \(k\), observing its round-\(0\) fraction gives likelihood ratio

\(\displaystyle \frac{\binom nk(2/3)^k(1/3)^{n-k}} {\binom nk(1/3)^k(2/3)^{n-k}} =2^{\,2k-n}. \)

Write \(y=2k-n\). For observations of several distinct source cohorts, these likelihood ratios multiply, because their signals are independent conditional on the state.

All agents constructed below observe other cohorts only. Thus their own signals are counted once, separately from those cohort observations; remembering their own round-\(0\) actions adds no information.

3. Construction from vertex cover

Use the standard \(\mathrm{NP}\)-complete problem: given a finite simple graph \(G=(V,E)\) and an integer \(K\), determine whether a vertex cover of size at most \(K\) exists. We restrict to \(r=|V|\ge1\) and \(0\le K\le r\); excluded cases are trivial, so this restriction preserves hardness. Let \(e=|E|\) and let \(\kappa(G)\) denote the minimum vertex-cover size.

Create the following types:

  • One source \(S_v\) for each \(v\in V\), and one reference source \(S_*\).
  • Two bounding types \(U_v,L_v\) for each vertex, and two reference bounding types \(U_*,L_*\).
  • One edge type \(A_{uv}\) for every edge \(\{u,v\}\).
  • One penalty type \(P_v\) for every vertex.
  • One bias type \(B\), and the target type \(q\).

There are \(\tau_0=4r+e+5\) types. Pad with isolated, uninformative types having constant action \(0\) until the support size \(\tau\) is a power of two. Padding types can be given distinct constant-action utilities if distinct numerical type descriptions are required. Assign every type mass \(1/\tau\).

Thus every admissible scale is \(N=\tau n\) for an integer \(n\), and every cohort has size \(n\). The masses are positive dyadic rationals.

Bounding and edge types

These types have uninformative signals, \(p_0=p_1=1/2\), and threshold utilities as above. The target observes all of them. Specify their observation sets and the target’s desired fractions as follows:

| Type | Cohorts it observes | Threshold \(\rho\) | Desired round-\(0\) fraction | Desired round-\(1\) fraction |
|---|---|---:|---:|---:|
| \(U_v\) | \(S_v\) | \(3\) | \(0\) | \(0\) |
| \(L_v\) | \(S_v\) | \(1/3\) | \(1\) | \(1\) |
| \(U_*\) | \(S_*\) | \(3\) | \(0\) | \(0\) |
| \(L_*\) | \(S_*\) | \(3/2\) | \(0\) | \(1\) |
| \(A_{uv}\) | \(S_u,S_v,S_*\) | \(3/2\) | \(0\) | \(1\) |

The round-\(0\) entries follow immediately from their uninformative signals and prior odds \(1\).

Penalty types

Each \(P_v\) observes \(S_v\), has threshold \(\rho=3\), and has signal probabilities

\(\displaystyle p_{P_v,0}=\frac14,\qquad p_{P_v,1}=\frac12.\)

Its private-signal likelihood ratios are \(2/3\) for signal \(0\) and \(2\) for signal \(1\). Consequently, its round-\(0\) action is always \(0\).

The target observes every \(P_v\), with desired fractions \(0\) at both rounds.

Bias type

The bias type observes nobody, uses threshold \(\rho=1\), and has

\(\displaystyle p_{B,0}=1-\frac25\left(\frac23\right)^K, \qquad p_{B,1}=\frac12. \)

These probabilities lie strictly between \(0\) and \(1\), with \(p_{B,0}>p_{B,1}\). Therefore its action at both rounds is \(1-s\), where \(s\) is its private signal.

The target observes \(B\), with desired fraction \(1\) at both rounds.

Target and remaining data

The target has \(p_{q,0}=p_{q,1}=1/2\) and utilities making action \(0\) strictly optimal in both states. It observes precisely the bounding, edge, penalty, and bias cohorts. Nobody observes the target. There are no additional edges.

Let \(h\) be the history specified above, and set

\(\displaystyle \epsilon=\frac1{8\tau}.\)

All input data are rational; the masses and \(\epsilon\) are dyadic. All utilities are nonnegative.

4. Exact characterization of continuous feasibility

For a source \(S_v\), write \(y_v=2k_v-n\), and similarly write \(y_*=2k_*-n\).

Every bounding or edge cohort takes a common round-\(1\) action: its own signal is uninformative, and every agent observes the same source fractions. Its round-\(1\) fraction therefore belongs to \(\{0,1\}\).

Hence, along any sequence whose history converges to \(h\), all these fractions must eventually equal their specified values exactly.

The hidden count choices form a vertex cover

The conditions for \(U_v\) and \(L_v\) are

\(\displaystyle 2^{y_v}\le3,\qquad 2^{y_v}>\frac13.\)

Since \(y_v\) is an integer, these are equivalent to

\(\displaystyle -1\le y_v\le1.\)

The reference conditions are

\(\displaystyle 2^{y_*}\le3,\qquad 2^{y_*}>\frac32,\)

which force \(y_*=1\). Because \(y_*=2k_*-n\), the cohort size \(n\) must be odd. Every \(y_v\) has the same parity as \(n\), so necessarily

\(\displaystyle y_v\in\{-1,1\}.\)

For an edge type, the desired action \(1\) is equivalent to

\(\displaystyle 2^{y_u+y_v+y_*}>\frac32.\)

Substituting \(y_*=1\) and \(y_u,y_v\in\{-1,1\}\), this fails exactly when \(y_u=y_v=-1\). Thus

\(\displaystyle C=\{v\in V:y_v=1\}\)

is a vertex cover.

These conditions also force all source fractions to converge to \(1/2\), since

\(\displaystyle x_{S_v}=\frac12+\frac{y_v}{2n}, \qquad x_{S_*}=\frac12+\frac1{2n}.\)

Penalty coordinates record the cover

For \(P_v\), the round-\(1\) posterior odds are:

| Source deviation | Own signal \(0\) | Own signal \(1\) | Round-\(1\) action |
|---|---:|---:|---|
| \(y_v=-1\) | \(1/3\) | \(1\) | Always \(0\) |
| \(y_v=1\) | \(4/3\) | \(4\) | Equals its own signal |

Its threshold is \(3\). Therefore its round-\(1\) fraction is \(0\) when \(v\notin C\), and equals \(x_{P_v}\) when \(v\in C\).

Convergence to the desired fraction \(0\) consequently forces \(x_{P_v}=0\) for selected vertices. Also, the bias observation forces \(x_B=0\).

For each vertex cover \(C\), define

\(\displaystyle \mathcal P_C= \left\{ x\in[0,1]^T: x_{S_*}=x_{S_v}=\frac12\ \text{for every }v,\quad x_B=0,\quad x_{P_v}=0\ \text{for every }v\in C \right\}. \)

There are no other coordinate restrictions. We claim the exact equality

\(\displaystyle \mathcal X(h)=\bigcup_{C\text{ a vertex cover of }G}\mathcal P_C. \)

First inclusion. Given any witnessing sequence for a point of \(\mathcal X(h)\), the bounding and edge observations eventually produce vertex covers as proved above. There are finitely many covers, so a subsequence has a fixed cover \(C\). On that subsequence, the source coordinates converge to \(1/2\), the selected penalty coordinates converge to \(0\), and the bias coordinate converges to \(0\). The limiting point belongs to \(\mathcal P_C\).

Reverse inclusion. Fix \(x\in\mathcal P_C\). Take odd integers \(n\) tending to infinity and scales \(N=\tau n\). Choose source counts

\(\displaystyle k_*=\frac{n+1}{2}, \qquad k_v= \begin{cases} (n+1)/2,&v\in C,\\ (n-1)/2,&v\notin C. \end{cases} \)

Set the bias count and every selected penalty count to zero. Approximate every unrestricted coordinate by a count divided by \(n\).

Every bounding and edge observation then has its prescribed value. Every penalty observation is zero, and both bias observations equal one. Thus \(H_N=h\) exactly, while the signal shares converge to \(x\). This proves the reverse inclusion.

In particular, \(\mathcal X(h)\ne\varnothing\), since \(V\) itself is a vertex cover. The feasibility promise is satisfied for every source instance.

5. Computing the two rate infima

Use the binary relative entropy with the convention \(0\log0=0\). Define

\(\displaystyle d=D_{\mathrm{KL}}\!\left(\frac12\middle\Vert\frac13\right) =D_{\mathrm{KL}}\!\left(\frac12\middle\Vert\frac23\right) =\frac12\log\frac98, \)

\(\displaystyle b_\theta=D_{\mathrm{KL}}(0\Vert p_{B,\theta}), \qquad c_\theta=D_{\mathrm{KL}}(0\Vert p_{P_v,\theta}). \)

For a fixed cover \(C\), minimization over \(\mathcal P_C\) is separable:

  • The \(r+1\) source coordinates contribute \((r+1)d\).
  • The bias coordinate contributes \(b_\theta\).
  • Selected penalty coordinates contribute \(|C|c_\theta\).
  • Every remaining coordinate is unrestricted and contributes minimum zero, attained at its state-\(\theta\) signal probability.

Since all masses equal \(1/\tau\),

\(\displaystyle \min_{x\in\mathcal P_C} \sum_t\mu_tD_{\mathrm{KL}}(x_t\Vert p_{t,\theta}) = \frac{(r+1)d+b_\theta+|C|c_\theta}{\tau}. \)

Both \(c_0\) and \(c_1\) are positive. Minimizing over covers therefore gives

\(\displaystyle I_\theta(h)= \frac{(r+1)d+b_\theta+\kappa(G)c_\theta}{\tau}. \)

The penalty terms satisfy

\(\displaystyle c_0=\log\frac43,\qquad c_1=\log2,\qquad c_0-c_1=-\log\frac32. \)

For the bias,

\(\displaystyle b_0-b_1 = \log\frac{1-p_{B,1}}{1-p_{B,0}} = K\log\frac32+\log\frac54. \)

Consequently,

\(\displaystyle I_0(h)-I_1(h) = \frac{(K-\kappa(G))\log(3/2)+\log(5/4)}{\tau}. \)

6. Promise gap and reduction complexity

If \(\kappa(G)\le K\), then

\(\displaystyle I_0(h)-I_1(h)\ge\frac{\log(5/4)}{\tau}>\frac1{8\tau}=\epsilon, \)

so the required MAP answer is state \(1\).

If \(\kappa(G)\ge K+1\), then

\(\displaystyle I_0(h)-I_1(h) \le-\frac{\log(6/5)}{\tau} <-\frac1{8\tau}=-\epsilon, \)

so the required answer is state \(0\).

For completeness, the strict bounds follow from

\(\displaystyle \log(1+t)=\int_0^t\frac{ds}{1+s}\ge\frac{t}{1+t} \quad(t>0), \)

which gives \(\log(5/4)\ge1/5>1/8\) and \(\log(6/5)\ge1/6>1/8\).

The construction has \(m=2\) and \(\tau=O(r+e)\). All probabilities except the bias probabilities have constant bit length. The bias probability can be written as

\(\displaystyle p_{B,0}=1-\frac{2^{K+1}}{5\cdot3^K},\)

so its encoding has \(O(K+1)\) bits. Because \(K\le r\), the total output length \(L\) and the construction time are polynomial in the vertex-cover input length. No logarithms need to be computed by the reduction.

Thus this is a polynomial-time reduction mapping every vertex-cover instance to an instance satisfying both promises, with the answer state \(1\) exactly for YES instances. The continuous rate-based MAP problem is therefore \(\mathrm{NP}\)-hard. The proof establishes hardness, without asserting membership in \(\mathrm{NP}\).
