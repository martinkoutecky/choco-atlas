The continuous mirror question, as graded

Given a finite list of types \(t\), binary rational masses \(\mu_t\) summing to \(1\), a shared argument set \(A\), a goal \(g\in A\), a semantics \(\sigma\), and for each type a CPBAF \(\Delta_t\) with world probabilities \(I_t\) and a fixed extension-selection distribution \(\rho_t(E\mid w)\), compute \(M^\sigma(g)=\sum_t\mu_t\sum_{w\in pw(\Delta_t)}I_t(w)\sum_{\substack{E\in\sigma(w)\g\in E}}\rho_t(E\mid w)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) counts listed types, not possible types. Let \(A\) be a shared argument set, \(m=|A|\geq1\), \(g\in A\), and \(\sigma\in\{\mathrm{gr},\mathrm{co},\mathrm{pr},\mathrm{st}\}\).
Each type has a conditional probabilistic bipolar argumentation framework \(\Delta_t=(A,R_t,S_t,P_t)\), with disjoint attack and necessary-support relations \(R_t,S_t\subseteq A\times A\). Each argument or edge \(x\) has one propositional condition \(C_{t,x}\) and a binary rational probability \(p_{t,x}\in(0,1]\); edge conditions include both endpoints. The dependency graph, with an edge from each atom in \(C_{t,x}\) to \(x\), is acyclic.
Generate a world in dependency order: if \(C_{t,x}\) is false, omit \(x\); otherwise include it with probability \(p_{t,x}\). These conditional draws define \(pw(\Delta_t)\) and its world distribution \(I_t\); neither worlds nor their probabilities are explicitly enumerated.
For a world \(w=(B,R,S)\) and \(E\subseteq B\), let \(D_w(E)\) be the least set containing all arguments attacked by \(E\) and all arguments on support cycles, and closed under outgoing supports. Let \(C_w(E)\) be the least fixed point of \(X\mapsto\{a\in B:(\forall b\,((b,a)\in R\Rightarrow b\in D_w(E)))\land(\forall c\,((c,a)\in S\Rightarrow c\in X))\}\).
Complete extensions satisfy \(E\cap D_w(E)=\varnothing\) and \(E=C_w(E)\); preferred extensions are inclusion-maximal complete extensions; stable extensions are preferred extensions satisfying \(E\cup D_w(E)=B\); the grounded extension is the inclusion-least complete extension. Write \(\sigma(w)\) for the corresponding extension set.
Each type supplies a Boolean circuit taking the incidence vectors of \(w,E\) and outputting a binary numerator and positive denominator for \(\rho_t(E\mid w)\). On every positive-probability world, these values are promised nonnegative, zero outside \(\sigma(w)\), and to sum to one over \(\sigma(w)\); thus such worlds must have an extension, including when \(\sigma=\mathrm{st}\). Let \(L\) be the total input bit length, including formulas and circuits.
Define \(M^\sigma(g)=\sum_{t=1}^{\tau}\mu_t\sum_{w\in pw(\Delta_t)}I_t(w)\sum_{E\in\sigma(w):\,g\in E}\rho_t(E\mid w)\).

Is exact computation of \(M^\sigma(g)\) polynomial-time in \(m,\tau,L\), or is it NP-hard, for each fixed \(\sigma\in\{\mathrm{gr},\mathrm{co},\mathrm{pr},\mathrm{st}\}\)?

Single-framework probabilistic acceptance is \(\mathrm{FP}^{\#\mathrm P}\)-hard for all four semantics, even for acyclic frameworks and any fixed extension-selection distribution. [Verified hardness result](https://ojs.aaai.org/index.php/AAAI/article/download/38961/42923).
No separate classification for this support-encoded mass formulation was located.

Modeling choices made when packaging the task

  • The representation of world probabilities was unspecified: they are induced succinctly by the framework's acyclic conditional dependency graph, rather than supplied as an explicit world table.
  • Conditional probabilities are binary rationals in (0,1]; a false conditioning formula forces absence, and edge conditions include endpoint presence, following the discrete definition.
  • The extension-selection distribution had no finite encoding: each type supplies a Boolean circuit returning binary rational values, with distribution validity promised.
  • A distribution on an empty extension set is impossible: every positive-probability world is promised to have a selected-semantics extension, particularly for stable semantics.
  • The recursive defeat and acceptability operators are interpreted as least fixed points, implementing the stipulated defeat of support cycles and exclusion of self-supported acceptance.
  • Set m to the number of shared arguments and L to the total encoding length; ask the complexity question separately for each fixed semantics.

Classification

Exact computation of \(M^\sigma(g)\) is NP-hard for every fixed \(\sigma\in\{\mathrm{gr},\mathrm{co},\mathrm{pr},\mathrm{st}\}\). Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).

This holds even with one listed type, no attacks or supports, and a unique extension in every world. The following direct reduction verifies all the promises in the question; it does not require transferring the representation assumptions of the cited [single-framework hardness result](https://ojs.aaai.org/index.php/AAAI/article/download/38961/42923).

1. Construction from a Boolean formula

Let \(\varphi(z_1,\ldots,z_n)\) be a CNF formula, with \(n\geq1\). Satisfiability remains NP-complete under this restriction.

Construct a society with \(\tau=1\) and \(\mu_1=1\). Its argument set and relations are

\(A=\{a_1,\ldots,a_n,g\},\qquad R_1=S_1=\varnothing.\)

Assign the following conditions and probabilities:

  • For each \(a_i\), set \(C_{1,a_i}=\top\) and \(p_{1,a_i}=\tfrac12\).
  • Set \(C_{1,g}=\varphi(a_1,\ldots,a_n)\) and \(p_{1,g}=1\), replacing each variable \(z_i\) by the atom recording the presence of \(a_i\).

Here \(\top\) denotes the constant true condition. All probabilities satisfy the required bounds. The only possible dependency edges are from arguments \(a_i\) to \(g\), so the dependency graph is acyclic. The conditions on edges are vacuous because there are no edges.

For an assignment \(u=(u_1,\ldots,u_n)\in\{0,1\}^n\), define

\(B_u=\{a_i:u_i=1\}\cup G_u,\)

where \(G_u=\{g\}\) if \(\varphi(u)=1\), and \(G_u=\varnothing\) otherwise. The corresponding world is \(w_u=(B_u,\varnothing,\varnothing)\).

The arguments \(a_i\) are included by independent unconditional draws, each with probability \(\tfrac12\). After those draws, the presence of \(g\) is deterministic. Thus

\(I_1(w_u)=2^{-n}.\)

Different assignments give different worlds because their incidence vectors on \(a_1,\ldots,a_n\) differ. These are exactly all positive-probability worlds.

2. Every world has the same unique extension under all four semantics

Consider any world \(w=(B,\varnothing,\varnothing)\), and any \(E\subseteq B\).

There are no attacked arguments, support cycles, or outgoing supports. Hence

\(D_w(E)=\varnothing.\)

In the operator defining \(C_w(E)\), both universal conditions are vacuously true for every \(a\in B\). Consequently, that operator maps every \(X\subseteq B\) to \(B\), and its least fixed point is

\(C_w(E)=B.\)

The complete-extension requirements therefore hold precisely when \(E=B\): the condition \(E=C_w(E)\) forces this equality, and \(B\cap D_w(B)=\varnothing\) verifies conflict-freeness.

It follows explicitly that:

  • \(B\) is the unique complete extension.
  • \(B\) is the grounded extension because it is the least complete extension.
  • \(B\) is the unique preferred extension because it is the only complete extension.
  • \(B\) is stable because it is preferred and \(B\cup D_w(B)=B\).

Thus, for every chosen semantics,

\(\sigma(w)=\{B\}.\)

This also covers the case \(B=\varnothing\).

3. A valid polynomial-size selection circuit

Supply a circuit whose denominator is always \(1\), and whose numerator is \(1\) exactly when the incidence vector of \(E\) equals the argument-incidence vector of \(w\); otherwise its numerator is \(0\).

Equality of these \(m=n+1\) bits is computable by a circuit of size \(O(m)\). On every positive-probability world \(w=(B,\varnothing,\varnothing)\), it therefore defines

\(\rho_1(E\mid w)=1\) if \(E=B\), and \(\rho_1(E\mid w)=0\) otherwise.

By Section 2, this circuit is nonnegative, vanishes outside \(\sigma(w)\), and sums to one over \(\sigma(w)\). In particular, the stable-extension existence promise is satisfied.

The entire constructed instance has bit length polynomial in the encoding length of \(\varphi\).

4. Exact acceptance computes the satisfying-assignment count

Write \(\#\mathrm{SAT}(\varphi)\) for the number of assignments satisfying \(\varphi\). Since the unique extension of \(w_u\) is \(B_u\), and \(g\in B_u\) precisely when \(\varphi(u)=1\), the definition of societal acceptance gives

\(M^\sigma(g)=\sum_{u\in\{0,1\}^n}2^{-n}\mathbf{1}[\varphi(u)=1]=\dfrac{\#\mathrm{SAT}(\varphi)}{2^n}.\)

In particular,

\(\varphi\text{ is satisfiable}\quad\Longleftrightarrow\quad M^\sigma(g)>0.\)

Therefore, an exact-computation algorithm yields a satisfiability decision procedure by constructing this instance, making one call, and testing whether the returned rational is positive. This proves NP-hardness under a polynomial-time, one-call reduction for each fixed semantics. More strongly, multiplying the result by \(2^n\) recovers \(\#\mathrm{SAT}(\varphi)\), establishing \(\#\mathrm P\)-hardness under polynomial-time oracle reductions.

The reduced fraction has numerator and denominator of \(O(n)\) bits, so this hardness already occurs on instances with polynomial-size exact outputs.

$$ M^\sigma(g)=2^{-n}\#\mathrm{SAT}(\varphi). $$
