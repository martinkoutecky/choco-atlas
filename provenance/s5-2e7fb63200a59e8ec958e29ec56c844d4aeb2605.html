The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), a symmetric utility table \(\sigma:T\times T\to\{-\infty,1\}\), and a coalition cap \(\kappa\in(0,1]\), can one construct a finite rational partition with component masses \(x^j_t\) summing to \(\mu_t\) that is stable against every measurable coalition of mass at most \(\kappa\)? A deviation selects type mass from components, forms links among the selected members, and may retain links to source components, which then join the resulting component in full; it succeeds only if every participating type slice strictly improves its component utility. If no such partition exists, establish that fact.

Packaged proof task (what the prover saw — nothing else)

A society is atomless and given by its support: the list of the \(\tau\) types \(T\) with positive masses \(\mu_t\), each a binary rational, with \(\sum_t\mu_t=1\). The support size is not the number of possible types; here \(m=|T|=\tau\). The input also contains a symmetric table \(\sigma:T\times T\to\{-\infty,1\}\) and a binary rational cap \(0<\kappa\leq1\); \(L\) is the total input bit length.
For a component mass vector \(x\), a type's per-person utility is \(U_t(x)=-\infty\) if some \(s\) with \(x_s>0\) satisfies \(\sigma(t,s)=-\infty\), and otherwise \(U_t(x)=\sum_s x_s\). Diagonal entries describe relations between distinct members of the same type.
An outcome is a finite list of nonzero rational vectors \(x^j\geq0\) with \(\sum_jx_t^j=\mu_t\), representing disjoint complete information-sharing components. Require individual rationality: \(U_t(x^j)\geq0\) whenever \(x_t^j>0\), since any individual can delete all links and obtain singleton utility \(0\).
A coalition selects arbitrary real masses \(0\leq y_t^j\leq x_t^j\) with \(0<\sum_{j,t}y_t^j\leq\kappa\). All selected members link to one another and may delete their existing links.
It may retain links to any set \(R\subseteq\{j:\sum_t y_t^j>0\}\) of source components; the resulting component has vector \(z=\sum_j y^j+\sum_{j\in R}(x^j-y^j)\). Thus each retained source joins in full, without requiring nonparticipants' consent; only selected mass counts toward the cap.
The deviation succeeds exactly when \(U_t(z)>U_t(x^j)\) for every \((j,t)\) with \(y_t^j>0\). An outcome is stable if no such deviation succeeds.

Is constructing such a stable finite rational outcome, or reporting that none exists, solvable in polynomial time in \(m,\tau,L\), with \(\kappa\) part of the input, or is this computational problem NP-hard?

For finite agents with symmetric utilities in \(\{-\infty,1\}\), stable networks exist for every integer coalition cap \(k\geq2\), but constructing one is NP-hard when \(k\) is part of the input. [Verified discrete results](https://arxiv.org/pdf/1003.0469v1).
No result settling this exact atomless construction problem was located in the literature search.

Modeling choices made when packaging the task

  • Specified atomless type populations, additive utility integrated against component mass, and negative infinite utility only upon exposure to positive enemy mass.
  • Interpreted diagonal utility entries as relationships between distinct members of the same type, preserving the supplied table's full domain.
  • Restored unilateral deletion of all links with singleton utility zero through individual rationality, including individual exits of zero population mass.
  • Represented each output component as a complete information-sharing component; required positive component mass and binary rational output entries.
  • Made the coalition cap a binary rational input and allowed real selected masses, so stability covers measurable deviations rather than only rational ones.
  • Required all selected members to connect, allowed retention only of touched source components, counted retained residual mass once, and required strict improvement only from selected participants.
  • Used m=τ because this model has no separate alternative or object parameter; L includes the utility table, masses, and coalition cap.

Result

The construction problem is \(\mathsf{NP}\text{-hard}\), even when the cap is fixed at \(\kappa=\tfrac12\) and all masses are dyadic rationals. A polynomial-time constructor would imply \(\mathsf P=\mathsf{NP}\).

Existence itself has a simple characterization: a stable finite rational outcome exists exactly when every diagonal entry is \(1\). The proof below handles the stated retention rule, including possible harm to nonparticipants.

1. Structure of individually rational and stable outcomes

For a component \(x^j\), write \(C_j=\{t:x_t^j>0\}\) and \(q_j=\sum_t x_t^j\).

Individual rationality implies \(\sigma(t,s)=1\) for every \(t,s\in C_j\), including \(t=s\). Consequently, every member of that component has utility \(q_j\).

If \(\sigma(t,t)=-\infty\) for some supported type \(t\), its positive mass must appear in some component, where its utility would be \(-\infty\). Thus no individually rational finite outcome exists.

Henceforth suppose every diagonal entry is \(1\). Define the compatibility graph on \(T\) by putting an edge between distinct \(t,s\) exactly when \(\sigma(t,s)=1\). Individually rational component supports are cliques. For any \(C\subseteq T\), define \(w(C)=\sum_{t\in C}\mu_t\).

Lemma 1. A stable outcome cannot split a type between components.

Proof. Suppose \(x_t^a>0\) and \(x_t^b>0\) for distinct components, labeled so that \(q_a\ge q_b\). Choose a positive rational \(\delta\) satisfying \(\delta\le x_t^a\), \(\delta\le x_t^b\), and \(2\delta\le\kappa\).

Select mass \(\delta\) of type \(t\) from each component and retain only component \(a\). The resulting vector is \(z=x^a+\delta e_t\), where \(e_t\) is the unit vector of coordinate \(t\).

Type \(t\) is compatible with every type in \(C_a\), by individual rationality. Both selected groups therefore obtain utility \(q_a+\delta\), strictly exceeding their previous utilities \(q_a\) and \(q_b\). This contradicts stability. \(\square\)

Thus every stable outcome assigns each type’s entire mass to one component and has at most \(m\) components.

2. Stable finite rational outcomes exist

Proposition 2. If every diagonal entry is \(1\), a stable finite rational outcome exists for every permitted cap.

Proof. Repeatedly choose a maximum-weight clique among the remaining types and remove its types. Let the resulting cliques, in selection order, be \(C_1,\ldots,C_p\). Assign each type’s entire mass to its clique, so \(x_t^j=\mu_t\) for \(t\in C_j\) and \(x_t^j=0\) otherwise.

This produces an individually rational rational outcome with \(p\le m\). Suppose, for contradiction, that a successful deviation exists.

Every selected type must be compatible with every type having positive mass in the resulting vector \(z\): otherwise its new utility would be \(-\infty\).

First, the deviation cannot retain two or more source components. Suppose it did, and let \(r\) be the earliest retained component. Choose another retained component \(s>r\). Because a retained component must be touched, some type \(t\in C_s\) has positive selected mass. The entire vector \(x^r\) occurs in \(z\), so success requires \(t\) to be compatible with every type in \(C_r\).

Therefore \(C_r\cup\{t\}\) is a clique. All its types were available when \(C_r\) was chosen, and its weight is \(w(C_r)+\mu_t>w(C_r)\), contradicting maximality of the chosen weight.

Hence at most one component is retained. In this case the support of \(z\) is a clique. Every positive-mass type in \(z\) either is selected or belongs to the single retained component. Pairs involving a selected type are compatible by success; pairs wholly within the retained component are compatible by individual rationality.

Let \(h\) be the earliest touched component and let \(Q=\{t:z_t>0\}\). Every type in \(Q\) was still available when \(C_h\) was chosen. Also \(z_t\le\mu_t\), since the deviation includes each portion of the original population at most once. Thus

\(\displaystyle \sum_t z_t\le w(Q)\le w(C_h)=q_h.\)

But a positive selected mass from component \(h\) previously obtained utility \(q_h\), and its new utility is \(\sum_t z_t\). It cannot strictly improve. This contradiction proves stability. \(\square\)

This is an existence proof, not a polynomial-time construction: finding the maximum-weight cliques can be hard. Together with the diagonal obstruction, it proves the stated existence characterization.

3. A forcing lemma for an isolated sector

The following lemma makes every possible stable output reveal a maximum-weight clique.

Lemma 3. Let \(S\subseteq T\) be nonempty and satisfy:

  • \(\sigma(t,s)=-\infty\) whenever \(t\in S\) and \(s\notin S\);
  • \(w(S)\le\kappa\).

Then every stable outcome contains a component whose support is a maximum-weight clique in the compatibility graph induced by \(S\), and that component contains the entire mass of every type in its support.

Proof. Individual rationality prevents any component from mixing a type in \(S\) with a type outside \(S\).

Let \(M\) be the maximum clique weight within \(S\), and let \(q_{\max}\) be the largest mass of a component supported in \(S\). Such components exist because \(S\) has positive total mass.

Every such component has clique support and satisfies \(x_t^j\le\mu_t\), so \(q_j\le w(C_j)\le M\). In particular, \(q_{\max}\le M\).

Suppose \(q_{\max}<M\). Choose a maximum-weight clique \(C\subseteq S\). Select the entire population of every type in \(C\), from all their source components, and retain no source component. Explicitly, set \(y_t^j=x_t^j\) for \(t\in C\), and \(y_t^j=0\) otherwise.

The selected mass is \(M\le w(S)\le\kappa\). Its resulting component is compatible and gives every participant utility \(M\). Every participant previously belonged to a component supported in \(S\), with utility at most \(q_{\max}<M\). This is a successful deviation, a contradiction.

Therefore \(q_{\max}=M\). For a component attaining this mass,

\(\displaystyle M=q_j=\sum_{t\in C_j}x_t^j\le\sum_{t\in C_j}\mu_t=w(C_j)\le M.\)

All inequalities are equalities. Since every difference \(\mu_t-x_t^j\) is nonnegative, their sum being zero implies \(x_t^j=\mu_t\) for every \(t\in C_j\). Its support is consequently a maximum-weight clique. \(\square\)

For \(\kappa=1\), this lemma applies directly with \(S=T\). The next reduction establishes hardness at the fixed smaller cap \(\tfrac12\).

4. Polynomial reduction at the fixed cap

We reduce from the classical \(\mathsf{NP}\)-complete decision problem CLIQUE: given a finite simple graph \(G\) and an integer \(r\), decide whether its maximum clique size \(\omega(G)\) satisfies \(\omega(G)\ge r\). Its completeness is a standard result of [Karp (1972)](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Take an instance with \(n=|V(G)|\ge1\). Let \(N\) be the smallest power of two satisfying \(N\ge n\). Add \(N-n\) isolated vertices to obtain a graph \(H\). Since \(G\) is nonempty and an added isolated vertex belongs only to singleton cliques, \(\omega(H)=\omega(G)\).

Construct the society as follows:

  • Its types are \(T=V(H)\cup\{b\}\), where \(b\) is one additional type.
  • Every vertex type has mass \(\mu_v=1/(2N)\), and \(\mu_b=1/2\).
  • Every diagonal entry is \(1\).
  • Distinct vertex types are compatible exactly when adjacent in \(H\).
  • Type \(b\) is incompatible with every vertex type.
  • The cap is fixed at \(\kappa=1/2\).

The masses sum to \(N/(2N)+1/2=1\), and every mass is dyadic. Moreover, \(m=\tau=N+1\), with \(N<2n\). The explicit table and masses have total encoding length \(O(n^2+n\log n)\), so the transformation is polynomial.

By Proposition 2, this society has a stable finite rational outcome. Therefore a correct constructor must return an outcome rather than report nonexistence.

Apply Lemma 3 to \(S=V(H)\). This sector is incompatible with its complement and has total mass \(1/2=\kappa\). Every stable output therefore contains a maximum-weight clique component within \(S\).

All vertex types have the same mass. Consequently, a maximum-weight clique in this sector is a maximum-cardinality clique of \(H\). Every component supported in \(S\) has clique support, and at least one has support size \(\omega(H)\). Hence

\(\displaystyle \max_{j:\,x_b^j=0}\bigl|\{v\in V(H):x_v^j>0\}\bigr|=\omega(H)=\omega(G).\)

Read this maximum from the returned outcome and compare it with \(r\). This decides the original CLIQUE instance.

The argument works for every stable output; it does not depend on which outcome the constructor chooses. Thus one call to any polynomial-time constructor would decide CLIQUE in polynomial time.

5. Conclusion

Constructing a stable finite rational outcome, or correctly reporting nonexistence, is \(\mathsf{NP}\text{-hard}\) under a polynomial-time reduction using one constructor call, already for fixed \(\kappa=\tfrac12\), explicit support, and dyadic masses.

The nonexistence branch is easy: it occurs exactly when some diagonal entry is \(-\infty\). The hardness lies in constructing a stable outcome on instances where existence is guaranteed.
