The continuous mirror question, as graded

Given candidates, a target ranking \(X\), and a finite support \(T\) of ranking-and-price types \((r_t,p_t)\) with rational masses \(\mu_t\) summing to \(1\), let \(d_t=\kt(X,r_t)\). Given a per-capita budget \(B\) and normalized distance threshold \(K\), does there exist a mass allocation \(x_{t,q}\geq 0\), for integer \(q\in\{0,\ldots,d_t\}\), such that \(\sum_q x_{t,q}=\mu_t\), \(\sum_{t,q}p_t q x_{t,q}\leq B\), and \(\sum_{t,q}(d_t-q)x_{t,q}\leq K\), where every unit of mass assigned \(q\) receives a sequence of \(q\) admissible swaps?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq 1\) candidates, and let \(X\) be a strict complete ranking of \(C\). A society is given by its support: a list \(T\) of \(\tau\) types \((r_t,p_t)\), each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(r_t\) is a strict complete ranking of \(C\), and \(p_t\) is a nonnegative integer encoded in binary.
The support size \(\tau\) counts listed ranking-and-price types, not all possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
An admissible swap exchanges consecutive candidates in the current ranking. Every swap applied to mass originating from type \(t\) costs \(p_t\) per unit mass, independently of the exchanged pair and intermediate ranking; costs add.
Write \(d_t=\operatorname{KT}(X,r_t)\), using Kendall tau distance. Given nonnegative binary rational inputs \(B,K\), ask whether there are real masses \(x_{t,q}\geq0\), for integers \(0\leq q\leq d_t\), satisfying \(\sum_{q=0}^{d_t}x_{t,q}=\mu_t\), \(\sum_{t,q}p_tq x_{t,q}\leq B\), and \(\sum_{t,q}(d_t-q)x_{t,q}\leq K\).
Every positive allocation \(x_{t,q}\) must admit a sequence of exactly \(q\) admissible swaps starting from \(r_t\) and ending at distance \(d_t-q\) from \(X\). Mass may be split arbitrarily between allocations. Both budget and distance are measured per unit total society mass; distance is not divided by the number of candidate pairs.

Is this continuous swap-bribery decision problem in \(\mathsf{P}\), or is it \(\mathsf{NP}\)-hard?

For an explicitly listed finite society with a fixed target ranking and a constant integer price per swap for each original ranking, swap bribery to meet a total Kendall tau distance threshold is polynomial-time solvable ([Jain and Thakur](https://arxiv.org/html/2603.28574v1)). No published result settling exactly the continuous formulation above was identified in the search.

Modeling choices made when packaging the task

  • Specified strict complete rankings on a common nonempty candidate set.
  • Specified binary-encoded nonnegative integer swap prices, retaining the discrete integer cost domain and allowing zero cost.
  • Specified nonnegative binary rational budget and distance threshold.
  • Specified that the original type's swap price remains constant through all intermediate rankings.
  • Required a sequence assigned to q to end at Kendall tau distance d_t-q, making the graded question's residual-distance expression explicit.
  • Interpreted normalized distance as average distance per unit society mass, without normalization by the number of candidate pairs; allocation masses are arbitrary nonnegative reals.

Result

The continuous swap-bribery decision problem is in \(\mathsf{P}\). An exact algorithm computes each type’s available distance reduction, sorts the types by price, and buys reduction in that order.

The proof below includes the required swap realizability and polynomial bit complexity.

1. Every permitted swap count is realizable

Label each candidate by its position in \(X\). A ranking \(r\) then becomes a permutation \((a_1,\ldots,a_m)\), and \(\operatorname{KT}(X,r)\) equals its number of inversions.

If this permutation has a positive number of inversions, it has an adjacent descent: otherwise \(a_i<a_{i+1}\) for every consecutive pair, so the permutation would be increasing and have no inversions.

Swap the candidates at an adjacent descent. Because they are consecutive, their relative order with every other candidate remains unchanged. Only their mutual order changes, removing exactly one inversion. Thus this admissible swap decreases the distance from \(X\) by exactly one.

Repeating this argument produces a sequence of exactly \(\operatorname{KT}(X,r)\) admissible swaps ending at \(X\). Its prefix of length \(q\) ends at distance \(\operatorname{KT}(X,r)-q\).

Consequently, for every listed type \(t\) and every integer \(q\) satisfying \(0\leq q\leq d_t\), the required sequence exists.

2. Exact reduction to divisible distance reduction

Define the initial mean distance and each type’s reduction capacity by

\(\displaystyle D=\sum_{t=1}^{\tau}\mu_t d_t,\qquad a_t=\mu_t d_t.\)

For any allocation satisfying the mass constraints, define

\(\displaystyle y_t=\sum_{q=0}^{d_t}q\,x_{t,q}.\)

Since \(0\leq q\leq d_t\), we have \(0\leq y_t\leq a_t\). Moreover, its cost and final distance are exactly

\(\displaystyle \sum_t p_t y_t,\qquad \sum_{t,q}(d_t-q)x_{t,q}=D-\sum_t y_t.\)

Conversely, every real vector satisfying \(0\leq y_t\leq a_t\) can be realized by admissible allocations. For a type with \(d_t>0\), set

\(\displaystyle x_{t,d_t}=\frac{y_t}{d_t},\qquad x_{t,0}=\mu_t-\frac{y_t}{d_t},\)

and set all other allocations to zero. These masses are nonnegative and sum to \(\mu_t\). Their reduction is \(y_t\), and their cost is \(p_t y_t\). Section 1 supplies the required sequences for both allocations.

If \(d_t=0\), then \(a_t=y_t=0\), and we set \(x_{t,0}=\mu_t\).

Therefore, writing

\(\displaystyle R=\max\{0,D-K\},\)

the original instance is feasible exactly when there is a vector satisfying

\(\displaystyle 0\leq y_t\leq a_t,\qquad \sum_t y_t\geq R,\qquad \sum_t p_t y_t\leq B.\)

Because \(K\geq0\), we have \(0\leq R\leq D=\sum_t a_t\).

3. Greedy optimality

Relabel the listed types so that

\(\displaystyle p_1\leq p_2\leq\cdots\leq p_\tau.\)

If \(R=0\), the zero vector is feasible and has minimum cost zero. Hence the answer is yes.

Suppose \(R>0\). Let \(j\) be the smallest index satisfying

\(\displaystyle \sum_{i=1}^{j}a_i\geq R.\)

Such an index exists because \(\sum_i a_i=D\geq R\). Define the greedy vector by

\(\displaystyle z_i=\begin{cases}a_i,&i<j,\\ R-\sum_{h<j}a_h,&i=j,\\0,&i>j.\end{cases}\)

The definition of \(j\) gives \(0<z_j\leq a_j\). Thus the greedy vector obeys all capacity constraints and has total reduction exactly \(R\).

To prove optimality, take any vector \(y\) satisfying the capacity constraints and \(\sum_i y_i\geq R\). Its cost difference from the greedy vector is

\(\displaystyle \sum_i p_i(y_i-z_i)=\sum_i(p_i-p_j)(y_i-z_i)+p_j\left(\sum_i y_i-R\right).\)

Every contribution on the right is nonnegative:

  • For \(i<j\), both \(p_i-p_j\leq0\) and \(y_i-z_i=y_i-a_i\leq0\).
  • For \(i=j\), the coefficient \(p_i-p_j\) is zero.
  • For \(i>j\), both \(p_i-p_j\geq0\) and \(y_i-z_i=y_i\geq0\).
  • The final term is nonnegative because \(p_j\geq0\) and \(\sum_i y_i\geq R\).

Hence \(\sum_i p_i y_i\geq\sum_i p_i z_i\). This proof permits equal prices and zero prices.

The minimum cost is therefore

\(\displaystyle C_{\min}=\sum_{i<j}p_i a_i+p_j\left(R-\sum_{i<j}a_i\right),\)

and the decision algorithm returns yes exactly when \(C_{\min}\leq B\).

The allocation constructed in Section 2 realizes this optimum. At most one listed type needs to split its mass between its original ranking and \(X\).

4. Exact implementation and running time

Compute each \(d_t\) by counting disagreements over candidate pairs. This takes \(\mathcal O(\tau m^2)\) comparisons. Sorting the listed types takes \(\mathcal O(\tau\log(\tau+1))\) price comparisons.

To implement all numerical steps exactly, let \(V\) be the product of the denominators of all masses, \(B\), and \(K\), as encoded in the input. Reduction to lowest terms is unnecessary. Define integers

\(\displaystyle A_t=V\mu_t,\qquad J=VB,\qquad E=VK,\qquad h_t=A_t d_t.\)

Then the required scaled reduction is the integer

\(\displaystyle \rho=\max\left\{0,\sum_t h_t-E\right\}.\)

After sorting by price, start with remaining reduction \(s=\rho\). For each type in order, set \(w_t=\min\{h_t,s\}\) and replace \(s\) by \(s-w_t\). Since \(\rho\leq\sum_t h_t\), the remaining reduction eventually becomes zero. Return yes exactly when

\(\displaystyle \sum_t p_t w_t\leq J.\)

This is precisely the greedy algorithm with all reductions multiplied by \(V\). It uses no rounding and never expands rational masses into individual voters.

For the bit bound, put

\(\displaystyle H=L+\left\lceil\log_2(m+1)\right\rceil+\left\lceil\log_2(\tau+1)\right\rceil.\)

The sum of the encoded denominator lengths is at most \(L\), so \(V\) has \(\mathcal O(L)\) bits. Also:

  • \(A_t\leq V\), because \(0<\mu_t\leq1\).
  • \(d_t\leq\binom m2\).
  • \(\sum_t h_t=V D\leq V\binom m2\).
  • \(\sum_t p_t w_t\leq(\max_t p_t)V\binom m2\).
  • The scaled inputs \(J\) and \(E\) have \(\mathcal O(L)\) bits.

Thus all numerical intermediates have \(\mathcal O(H)\) bits. Using elementary integer arithmetic, multiplication and exact division take \(\mathcal O(H^2)\) bit operations. A conservative total bit-operation bound is

\(\displaystyle \mathcal O\!\left(\bigl(L+\tau m^2+\tau\log(\tau+1)\bigr)H^2\right).\)

This is polynomial in \(m,\tau,L\), and therefore polynomial in the explicit input length. In particular, the running time depends on the listed support size, not on the number of possible rankings or on the numerical values of rational denominators.

The cases \(m=1\) and \(D\leq K\) are included: they have \(R=0\) and require no swaps.

5. Conclusion

The stated continuous formulation is polynomial-time solvable by an exact greedy algorithm. The discrete finite-society result appears as Theorem 12 of [Jain and Thakur](https://arxiv.org/html/2603.28574v1); the proof above independently establishes the continuous formulation, including binary rational masses and thresholds.
