The continuous mirror question, as graded

Given a finite item set \(M\), rational per-capita supplies \(\rho\), a finite set of weakly lexicographic preference types \(\mathcal T\), and rational type masses \(\mu\), does there exist a finite-support mass allocation \(x_{t,B}\) over integral bundles \(B\subseteq M\) satisfying \(\sum_B x_{t,B}=\mu_t\), \(\sum_{t,B:g\in B}x_{t,B}=\rho_g\), \(\mathrm{EF}_\infty\), and individual \(\mathrm{PO}_\infty\)?

Packaged proof task (what the prover saw — nothing else)

Let \(M\) be a nonempty set of \(m\) goods. Each type \(t\) specifies an ordered partition \((C_{t,1},\ldots,C_{t,k_t})\) of \(M\) into nonempty indifference classes; define \(s_t(B)=(|B\cap C_{t,1}|,\ldots,|B\cap C_{t,k_t}|)\), with bundles compared lexicographically and equal vectors indifferent.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Supplies \(\rho_g\in[0,1]\) are binary rationals; let \(L\) be the total input bit length.
A mass allocation assigns real masses \(x_{t,B}\geq0\) to integral bundles \(B\subseteq M\), including the empty bundle, satisfying \(\sum_Bx_{t,B}=\mu_t\) and \(\sum_{t,B:g\in B}x_{t,B}=\rho_g\) for every good. Positive cells describe actual recipients, and masses may be split arbitrarily.
It satisfies \(\mathrm{EF}_\infty\) if \(s_t(B)\geq_{\mathrm{lex}}s_t(D)\) whenever \(x_{t,B}>0\) and \(x_{u,D}>0\), including \(t=u\).
It satisfies individual \(\mathrm{PO}_\infty\) if there is no nonnegative real reassignment \(z_{t,B,D}\) with \(\sum_Dz_{t,B,D}=x_{t,B}\), \(\sum_{t,B,D:g\in D}z_{t,B,D}=\rho_g\), and \(z_{t,B,D}>0\) only when \(s_t(D)\geq_{\mathrm{lex}}s_t(B)\), such that \(\sum_{t,B,D:s_t(D)>_{\mathrm{lex}}s_t(B)}z_{t,B,D}>0\).

Is deciding whether a mass allocation satisfying \(\mathrm{EF}_\infty\) and individual \(\mathrm{PO}_\infty\) exists solvable in time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite agents and one copy of each good, existence of a complete envy-free and Pareto-optimal allocation under weakly lexicographic preferences is \(\mathrm{NP}\)-complete. [Source](https://arxiv.org/html/2404.19740v1)
No result settling this exact mass-allocation problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to one and restricted per-capita supplies to binary rationals in [0,1], consistent with bundles containing at most one copy of each good.
  • Made the goods-only domain explicit, with nonempty indifference classes covering all goods and lexicographic comparison of class counts; ties remain indifferences.
  • Defined EF_infinity by comparisons between all positive-mass recipient cells, including recipients of the same type.
  • Defined individual PO_infinity through arbitrary mass-splitting reassignments preserving supplies, weakly improving every recipient almost everywhere and strictly improving a positive mass.
  • Allowed real allocation and reassignment masses, empty bundles, and unrestricted finite support over the finite bundle universe.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result

The decision problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions, even when every type has exactly two indifference classes and all type masses are equal.

We prove this by reducing graph three-colorability. The edge-type preference pattern is adapted from [Appendix A of the cited paper](https://arxiv.org/html/2404.19740v1); the supply ratios below make the argument work with arbitrarily split masses.

2. Encoding a coloring in one bundle

Let \(G=(V,E)\) be a simple graph, with \(n=|V|\). Adding isolated vertices if necessary, assume \(n\geq 3\), which preserves three-colorability.

Construct a graph \(H=(W,F)\), where \(W=V\times\{1,2,3\}\). Its edges are:

  • All three edges among \((v,1),(v,2),(v,3)\), for each \(v\in V\).
  • The edge \(\{(u,c),(v,c)\}\), for each \(\{u,v\}\in E\) and \(c\in\{1,2,3\}\).

Write \(q=|F|=3n+3|E|\). In particular, \(q\geq 3n\), and every vertex of \(H\) has an incident edge.

An independent set of size \(n\) in \(H\) contains exactly one vertex from each triangle \(\{v\}\times\{1,2,3\}\). Its selected labels therefore define a proper three-coloring of \(G\). Conversely, a proper three-coloring gives such an independent set.

Moreover, if \(G\) is three-colorable, cyclically permuting its color labels gives three independent sets \(S_1,S_2,S_3\), each of size \(n\), that partition \(W\).

3. The mass-allocation instance

For every \(e\in F\), introduce two padding goods \(p_e^0,p_e^1\). Let \(P\) be the set of these \(2q\) goods, and set \(M=W\cup P\).

There is one distinguished type \(t_*\), with partition
\((W,P)\).

For every edge \(e=\{a,b\}\in F\), introduce an edge type \(t_e\), with partition
\((P\cup\{a,b\},\,W\setminus\{a,b\})\).

Both classes of every type are nonempty. Distinct edges give distinct types, and the distinguished type is different from every edge type. Thus the support size is \(\tau=q+1\).

Put \(\lambda=1/(q+1)\). Every type has mass \(\lambda\). Supplies are

\(\rho_p=\lambda\) for \(p\in P\), and \(\rho_w=\lambda/3\) for \(w\in W\).

These are positive binary-encoded rationals in \([0,1]\). The construction has \(m=2q+3n\) goods and polynomial total input length.

4. A coloring yields an envy-free, individually Pareto-optimal allocation

Suppose \(G\) has a proper three-coloring, and let \(S_1,S_2,S_3\) be the independent sets described above.

Give every recipient of type \(t_e\) the bundle \(\{p_e^0,p_e^1\}\), using mass \(\lambda\). Give type \(t_*\) each bundle \(S_i\) with mass \(\lambda/3\).

This meets every type mass and every supply: each padding good occurs in its edge type’s bundle, while each vertex good occurs in exactly one \(S_i\).

Every edge recipient has own score \((2,0)\). An edge type evaluates every padding pair as \((2,0)\), and evaluates each \(S_i\) with first coordinate at most \(1\), because \(S_i\) is independent. Hence edge recipients envy nobody.

Every distinguished recipient has score \((n,0)\), while the distinguished type evaluates padding pairs as \((0,2)\). Thus the allocation satisfies \(\mathrm{EF}_\infty\), including comparisons within types.

To prove individual \(\mathrm{PO}_\infty\), put \(d_{t_e}=2\) and \(d_{t_*}=n\). Every original recipient of type \(t\) receives score \((d_t,0)\), consisting entirely of first-class goods.

Any weakly preferred replacement bundle \(D\) must have at least \(d_t\) first-class goods, and therefore \(|D|\geq d_t\). If it is strictly preferred, then either it has more first-class goods, or it has exactly \(d_t\) first-class goods and at least one second-class good. In either case, \(|D|>d_t\).

For any admissible reassignment \(z\), preservation of supplies and original recipient masses gives

\(\sum_{t,B,D}z_{t,B,D}|D|=\sum_{g\in M}\rho_g=\sum_{t,B,D}z_{t,B,D}d_t\).

Consequently, \(\sum_{t,B,D}z_{t,B,D}(|D|-d_t)=0\). Every positive term is nonnegative, and every strictly improved recipient would contribute positively. Hence no positive mass can strictly improve.

5. Any envy-free mass allocation yields a coloring

Suppose the constructed instance admits an allocation satisfying \(\mathrm{EF}_\infty\). Pareto optimality is not needed in this direction.

For accounting, divide all allocation masses by \(\lambda\), writing \(y_{t,B}=x_{t,B}/\lambda\). Each type now has total mass \(1\); each padding good has supply \(1\), and each vertex good has supply \(1/3\). Thus

\(\sum_{t,B}y_{t,B}|B|=2q+n\).

Call a bundle *used* if some \(y_{t,B}>0\), and write \(h(B)=|B\cap P|\) and \(v(B)=|B\cap W|\).

Envy-freeness within a type implies that all its used bundles have the same own score: applying envy-freeness in both directions gives equality of score vectors. In particular, they have the same cardinality.

Write the distinguished type’s score as \((r,s)\). Every distinguished recipient therefore receives \(r\) vertex goods and \(s\) padding goods. Since vertex supplies are positive, some used bundle contains a vertex good. Envy-freeness of the distinguished type then forces \(r\geq 1\).

We repeatedly use the following budget observation: it is impossible for every edge recipient to receive at least three goods. Such recipients would consume at least \(3q\) goods in total, while distinguished recipients consume at least \(1\). This would contradict

\(3q+1>2q+n\),

which holds because \(q\geq 3n\).

5.1. Every used bundle has at most two padding goods

If a used bundle contained at least three padding goods, every edge type would evaluate its first coordinate as at least \(3\). Envy-freeness would force every edge recipient to receive at least three goods, contradicting the budget observation.

Thus \(h(B)\leq 2\) for every used bundle.

5.2. Two padding goods cannot accompany any vertex good

Suppose a used bundle \(B\) had \(h(B)=2\) and \(v(B)>0\).

For an edge \(e=\{a,b\}\), put \(\delta=|B\cap\{a,b\}|\). Its evaluation is \((2+\delta,v(B)-\delta)\). If \(\delta=0\), this is strictly above \((2,0)\) because its second coordinate is positive. If \(\delta>0\), its first coordinate exceeds \(2\).

Therefore every edge type strictly prefers \(B\) to score \((2,0)\). Envy-freeness forces every edge recipient to have score strictly above \((2,0)\), which requires at least three goods. This again contradicts the budget observation.

Because \(r\geq 1\), distinguished recipients consequently have \(s\leq 1\).

5.3. Every edge recipient has score exactly \((2,0)\)

Some used edge bundle must contain two padding goods. Otherwise, edge recipients consume at most \(q\) padding goods in total, and distinguished recipients at most \(1\). This cannot meet padding supply \(2q\), since \(q>1\).

By the preceding claim, such a bundle consists of exactly two padding goods. Every edge type evaluates it as \((2,0)\), so envy-freeness forces every edge type’s own score to be at least \((2,0)\).

Suppose some edge type \(t_e\), with \(e=\{a,b\}\), had own score strictly above \((2,0)\). Every one of its recipients would then receive at least three goods. Its bundles cannot contain two padding goods, because those bundles contain no vertex goods and have cardinality two. Hence each contains at most one padding good.

Its first-class count is at least \(2\). Since its first class is \(P\cup\{a,b\}\), every recipient must therefore receive at least one of \(a,b\). Type \(t_e\) has rescaled mass \(1\), so

\(\sum_B y_{t_e,B}|B\cap\{a,b\}|\geq 1\).

But the combined global supply of \(a,b\) is only \(2/3\), a contradiction.

Thus every edge recipient has score \((2,0)\), and cardinality two.

5.4. Every distinguished bundle contains exactly \(n\) vertex goods

Edge recipients consume exactly \(2q\) goods. The total supply identity therefore gives \(r+s=n\).

If \(s=1\), then \(r=n-1\geq 2\). Choose a used distinguished bundle \(B\), a vertex \(w\in B\cap W\), and an incident edge \(e=\{w,w'\}\).

If \(w'\in B\), type \(t_e\) evaluates \(B\) with first coordinate \(3\). Otherwise, it evaluates \(B\) as \((2,r-1)\), whose second coordinate is positive. Either way, this exceeds its own score \((2,0)\), contradicting envy-freeness.

Hence \(s=0\) and \(r=n\).

5.5. Every distinguished bundle encodes a proper coloring

A used distinguished bundle \(B\) is a subset of \(W\) of size \(n\). If it contained both endpoints of an edge \(e\in F\), type \(t_e\) would evaluate it as \((2,n-2)\). Since \(n\geq 3\), this is strictly above \((2,0)\), contradicting envy-freeness.

Thus \(B\) is independent in \(H\). Distinguished mass is positive, so at least one such bundle exists. By Section 2, it determines a proper three-coloring of \(G\).

6. Complexity conclusion

We have proved that \(G\) is three-colorable if and only if the constructed mass instance admits an allocation satisfying both \(\mathrm{EF}_\infty\) and individual \(\mathrm{PO}_\infty\).

The construction is polynomial, so the requested decision problem is \(\mathrm{NP}\)-hard. A polynomial-time algorithm in \(m,\tau,L\) would therefore imply \(\mathrm{P}=\mathrm{NP}\).
