The continuous mirror question, as graded

Given a finite \(\mathrm{MCSP}(\Gamma_X^{\mathrm{cons}})\) instance with variables \(V\), sort assignment \(\delta\), and constraints \(\mathcal{C}\), take a continuum of identical modules indexed by \(u\in[0,1]\), with one role type \(v\) of mass \(\mu_v=1/|V|\) for each \(v\in V\). Does there exist a measurable assignment \(a_v(u)\in A_{\delta(v)}\) such that, for every constraint \(((v_1,\ldots,v_k),R)\in\mathcal{C}\), \((a_{v_1}(u),\ldots,a_{v_k}(u))\in R\) for almost every \(u\)?

Packaged proof task (what the prover saw — nothing else)

Fix \(m\geq1\), finite sort domains \(A_1,\ldots,A_m\), and a nonempty relation \(X\subseteq\prod_{j=1}^m A_j\), whose coordinate projections \(X_j\) each have at least two elements. These constitute a fixed template, not instance input.
Let \(\Gamma_X^{\mathrm{cons}}\) consist of \(X\), with signature \((1,\ldots,m)\), and every unary relation \(B\subseteq A_j\), including the empty subset, with signature \((j)\).
An instance gives a nonempty finite variable set \(V\), a sort map \(\delta:V\to\{1,\ldots,m\}\), and a finite constraint list \(\mathcal C\). Each constraint \(((v_1,\ldots,v_k),R)\) uses \(R\in\Gamma_X^{\mathrm{cons}}\) with matching sort signature; scopes may repeat variables.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here the types are the roles \(v\in V\), \(\tau=|V|\), and \(\mu_v=1/\tau\), so total mass is one; \(\tau\) denotes support size, not the number of possible types.
Each module \(u\in[0,1]\) contains all roles. Feasibility means that there exist Lebesgue-measurable functions \(a_v:[0,1]\to A_{\delta(v)}\), with discrete codomains, such that every constraint satisfies \((a_{v_1}(u),\ldots,a_{v_k}(u))\in R\) for Lebesgue-almost every \(u\).
Let \(L\) be the total binary input length, including constraints and masses; state running times in \(m,\tau,|\mathcal C|,L\), allowing dependence on the fixed template.
For the discrete comparison, a uniformly non-dictatorial aggregator is a tuple \((f_1,\ldots,f_m)\), of a common arity \(n\geq2\), with \(f_j:A_j^n\to A_j\) always returning an input value, preserving \(X\) coordinatewise, and restricting to no projection on \(B^n\) for every two-element \(B\subseteq X_j\).

For each fixed template \(X\), is this continuum feasibility problem in \(\mathrm P\) or \(\mathrm{NP}\)-hard, and what condition on \(X\) determines its complexity?

The discrete problem is in \(\mathrm P\) when \(X\) admits a uniformly non-dictatorial aggregator, and is \(\mathrm{NP}\)-complete otherwise. [Verified discrete dichotomy](https://arxiv.org/html/1505.07737v2).

Result

For every fixed template \(X\), the continuum problem has the following dichotomy:

  • If \(X\) admits a uniformly non-dictatorial aggregator as defined in the question, continuum feasibility is in \(\mathrm P\).
  • Otherwise, continuum feasibility is \(\mathrm{NP}\)-complete, and hence \(\mathrm{NP}\)-hard.

The key fact is an exact equivalence with the discrete constraint satisfaction problem.

1. Equivalence of continuum and discrete feasibility

Fix an instance \(I=(V,\delta,\mathcal C)\). A discrete satisfying assignment is a map \(b\) such that \(b(v)\in A_{\delta(v)}\) for every \(v\in V\), and \((b(v_1),\ldots,b(v_k))\in R\) for every constraint \(((v_1,\ldots,v_k),R)\in\mathcal C\).

Lemma. The continuum instance is feasible if and only if \(I\) has a discrete satisfying assignment.

Proof. Suppose first that measurable functions \(a_v\) establish continuum feasibility. For a constraint \(C=((v_1,\ldots,v_k),R)\), define its failure set by
\(N_C=\{u\in[0,1]:(a_{v_1}(u),\ldots,a_{v_k}(u))\notin R\}\).

This set is measurable: the domains are finite, so it is a finite union of intersections of measurable fibers \(a_{v_i}^{-1}(\{t_i\})\). By feasibility, its Lebesgue measure is zero.

Because \(\mathcal C\) is finite, the set \(N=\bigcup_{C\in\mathcal C}N_C\) also has measure zero. Consequently, \([0,1]\setminus N\) has measure one and is nonempty. Choose \(u_0\) in that complement and set \(b(v)=a_v(u_0)\) for every \(v\in V\).

Every constraint holds at \(u_0\), so \(b\) is a discrete satisfying assignment. Repeated variables in a scope cause no difficulty: each occurrence receives the same value \(b(v)\).

Conversely, suppose that \(b\) is a discrete satisfying assignment. Define \(a_v(u)=b(v)\) for every \(u\in[0,1]\). These constant functions are measurable, and every constraint holds at every module. Thus they establish continuum feasibility. This proves the lemma.

The proof also covers an empty constraint list. An empty unary relation makes both formulations infeasible.

In particular, whenever the continuum instance is feasible, it has a feasible realization by constant functions. The masses impose no additional restriction, because the stated feasibility conditions involve only the functions and constraints.

2. Applying the discrete dichotomy

The cited discrete theorem concerns exactly the multi-sorted language consisting of \(X\), with signature \((1,\ldots,m)\), together with every unary subset of each \(A_j\). It states that this discrete problem is polynomial-time solvable when \(X\) admits a uniformly non-dictatorial aggregator, and is \(\mathrm{NP}\)-complete otherwise. Its hypotheses match ours: the domains are finite, \(X\) is nonempty, and every projection \(X_j\) has at least two elements. See [Kirousis, Kolaitis and Livieratos, Theorem 5](https://arxiv.org/html/1505.07737v2).

To obtain a continuum decision algorithm, discard the mass fields and run the discrete algorithm on \((V,\delta,\mathcal C)\). The lemma proves that its answer is correct.

For hardness, take a discrete instance and retain its variables, sorts and constraints. Give each variable a role of mass \(1/\tau\), where \(\tau=|V|\). Encode this rational by its binary numerator and denominator. The lemma again proves preservation of the answer.

If the discrete instance has no variables, first add one unconstrained variable of sort \(1\). This preserves satisfiability because \(A_1\) is nonempty, and ensures that the resulting society has nonempty support.

The added support list has length \(O(\tau\log(\tau+1))\) using indexed role names. It can therefore be constructed in polynomial time. This proves \(\mathrm{NP}\)-hardness in the second case.

Finally, continuum feasibility belongs to \(\mathrm{NP}\): a certificate is simply a discrete satisfying assignment. The lemma establishes its sufficiency and necessity, and all constraints can be checked in polynomial time. Thus the hard case is \(\mathrm{NP}\)-complete.

3. Running times and encoding

Let \(D_X=\max_j|A_j|\) and \(S=L+m+\tau+m|\mathcal C|\). Dependence on the entire fixed template is allowed in the following bounds.

A discrete assignment has \(O_X(\tau)\) bits. A direct implementation verifies it in \(O_X(S^2)\) bit operations: read the input, check each assigned value’s sort, and check every constraint by looking up its scope values and testing membership in the fixed relation. Every scope has length at most \(m\).

In the tractable case, the cited theorem supplies a constant \(c_X\), depending only on the fixed template, such that continuum feasibility can be decided in \(O_X(S^{c_X})\) time, including input processing. Since the variable set, constraints and masses are explicitly listed, and \(m\) is fixed, this is also \(O_X(L^{c_X})\) after increasing the constant or exponent if necessary.

For every template, exhaustive enumeration gives a decision algorithm with running time \(O_X(D_X^\tau S^2)\). This bound enumerates role assignments; the continuum module set contributes no enumeration factor.

The complexity condition is therefore precisely the existence of the specified uniformly non-dictatorial aggregator. No additional continuum assumption or theorem is needed.
