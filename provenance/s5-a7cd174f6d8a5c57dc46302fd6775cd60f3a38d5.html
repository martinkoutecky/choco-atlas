The anchor (named result in the paper)

Theorem C.1 — class: hardness

The continuous mirror question, as graded

Given a finite rational metric space \((T,d)\) and a rational distribution \(\mu\) with positive mass on each type, suppose each type can supply at least \(k\) distinct candidates. A committee is an integer vector \(y\in\mathbb{Z}_{\ge 0}^{T}\) with \(\sum_{t\in T}y_t=k\), and its normalized cost is \(C_\mu(y)=\sum_{t,u\in T}\mu_t y_u d(t,u)\); let \(C_\mu^\star\) be the minimum over such committees. For \(U\subseteq T\), let \(\mu(U)=\sum_{t\in U}\mu_t\), \(D(U)=\max_{t,t'\in U}d(t,t')\), and \(N_r(U)=\{u\in T:\min_{t\in U}d(t,u)\le r\}\). Given rational \(\rho>1\), decide whether there is a committee \(y\) such that, for every \(\ell\in\{1,\ldots,k\}\) and every \(U\subseteq T\) with \(\mu(U)\ge\ell/k\), \(\sum_{u\in N_{D(U)}(U)}y_u\ge\ell\), and \(C_\mu(y)<\rho C_\mu^\star\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input includes a rational metric \(d\) on \(T\), a binary integer \(k\ge1\), and a binary rational \(\rho>1\). Candidate locations are exactly \(T\); each supplies at least \(k\) distinct candidates, so committees are integer vectors \(y\in\mathbb Z_{\ge0}^{T}\) with \(\sum_t y_t=k\).
Define \(C_\mu(y)=\sum_{t,u\in T}\mu_t y_u d(t,u)\) and \(C_\mu^\star=\min_{z\in\mathbb Z_{\ge0}^{T},\,\sum_tz_t=k}C_\mu(z)\), without fairness constraints.
For nonempty \(U\subseteq T\), define \(\mu(U)=\sum_{t\in U}\mu_t\), \(D(U)=\max_{t,t'\in U}d(t,t')\), and \(N_r(U)=\{u\in T:\min_{t\in U}d(t,u)\le r\}\); singleton diameter is zero.
A committee satisfies proportional representative fairness (PRF) if every \(\ell\in\{1,\ldots,k\}\) and nonempty \(U\subseteq T\) with \(\mu(U)\ge\ell/k\) satisfy \(\sum_{u\in N_{D(U)}(U)}y_u\ge\ell\).
The decision problem asks whether a PRF committee exists with \(C_\mu(y)<\rho C_\mu^\star\). Let \(m=\tau\) count candidate locations and \(L\) be the total binary input length; state running times in \(m,\tau,L,k\), distinguishing polynomial dependence on \(k\) from its encoding length.

Is this decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite lists of \(n\) agents, existence of a PRF committee better than a \(1+\gamma-O(n^{-1/2})\) approximation to the unrestricted optimum is co-NP-hard for each constant \(\gamma\in(0,1)\). [Jerrett–Anshelevich](https://arxiv.org/html/2510.21039#A3)
No result settling this exact rational-mass decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: positive masses sum to one.
  • Specified a nonempty support and a positive integer committee size, with binary encoding for the committee size and approximation threshold.
  • Defined m as the number of candidate locations, equal to the support size, because individual candidate identities and capacities above k do not affect this model.
  • Restricted diameter and neighborhood definitions to nonempty coalitions and explicitly assigned singleton diameter zero.
  • Retained the strict cost inequality even when the unrestricted optimum is zero; no positive-optimum promise was added.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The decision problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions. This holds even when every nonzero distance belongs to \(\{1,2\}\), when \(1<\rho<2\), and when \(k=O(\tau^2)\).

Consequently, an algorithm polynomial in \(m,\tau,L,k\) would imply \(\mathrm P=\mathrm{NP}\). The proof below concerns exactly the rational-mass model in the question.

The degenerate case \(\tau=1\) always answers no: both costs are zero, so the required strict inequality fails.

1. Preliminary identities

For each location \(u\), define its cost per representative by

\[ a_u=\sum_{t\in T}\mu_t d(t,u). \]

Because representatives have no capacity restriction,

\[ C_\mu(y)=\sum_{u\in T}a_u y_u, \qquad C_\mu^\star=k\min_{u\in T}a_u. \]

Also, PRF is equivalent to the following single inequality for each nonempty \(U\subseteq T\):

\[ \sum_{u\in N_{D(U)}(U)}y_u\ge \lfloor k\mu(U)\rfloor. \]

Indeed, the positive integers \(\ell\) satisfying \(\mu(U)\ge\ell/k\) are precisely those at most \(\lfloor k\mu(U)\rfloor\). If that floor is zero, the constraint is vacuous.

2. Source problem

We reduce from Set Cover: given a universe \(E\), sets \(S_1,\ldots,S_s\subseteq E\), and an integer \(b\), decide whether at most \(b\) sets cover \(E\). Its NP-completeness is a classical result of [Karp](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

We use instances satisfying

\[ e:=|E|\ge1,\qquad s\ge1,\qquad \bigcup_{j=1}^s S_j=E,\qquad 1\le b\le e. \]

These restrictions preserve NP-hardness. To verify this directly, use the usual reduction from \(3\)-SAT: introduce one universe element for each variable and each clause. For each variable, create two sets, corresponding to its two truth values; each contains its variable element and the clauses satisfied by that literal. Set the budget equal to the number of variables. Covering all variable elements with that budget forces exactly one truth value per variable, and covering the clause elements is equivalent to satisfying the formula. Every universe element belongs to some set, and the budget is at most the universe size.

3. Construction

Set

\[ k=8(e+1)^2,\qquad \delta=\frac{1}{4ks}. \]

The support consists of a central type \(c\), two witness types \(p_i,q_i\) for each element \(i\in E\), and one set type \(v_j\) for each set \(S_j\). Thus,

\[ m=\tau=1+2e+s. \]

Assign masses

\[ \mu_{p_i}=\mu_{q_i}=\frac{1}{2k}, \qquad \mu_{v_j}=\delta, \qquad \mu_c=1-\frac{e}{k}-\frac{1}{4k}. \]

All masses are positive, and their sum is one.

Distances between distinct types are initially two. Change exactly the following distances to one:

  • \(d(c,v_j)=1\) for every \(j\);
  • \(d(p_i,q_i)=1\) for every \(i\);
  • \(d(p_i,v_j)=d(q_i,v_j)=1\) whenever \(i\in S_j\).

Keep symmetry and zero diagonal. This is a metric: for three distinct points, each distance is at most two, while the sum of any two distances is at least two.

Finally, choose

\[ \rho=1+\frac{b+\tfrac12}{2e+\tfrac14}. \]

Since \(1\le b\le e\) and \(e\ge1\), this satisfies \(1<\rho<2\).

4. The cost threshold bounds noncentral representatives

The central cost per representative is

\[ a_c=\frac{2e}{k}+s\delta =\frac{2e+\tfrac14}{k}. \]

For a set type \(v_j\), write \(h_j=|S_j|\). Its distances to the witnesses contribute \((2e-h_j)/k\), so

\[ a_{v_j} =\mu_c+\frac{2e-h_j}{k}+2(s-1)\delta. \]

Subtracting \(a_c\) gives the exact identity

\[ a_{v_j}-a_c =1-\frac{e+h_j}{k}-2\delta. \]

In particular, \(a_{v_j}-a_c\le1\).

Define

\[ \beta=1-\frac{4e+1}{k}. \]

This number is positive. Since \(h_j\le e\) and \(\delta\le1/(4k)\),

\[ a_{v_j}-a_c \ge1-\frac{2e+\tfrac12}{k} \ge\beta. \]

For any witness \(w\in\{p_i,q_i\}\), its distance to \(c\) is two. All other cost contributions are nonnegative; hence

\[ a_w-a_c \ge2\mu_c-a_c =2-\frac{4e+\tfrac34}{k} >\beta. \]

Thus every noncentral location has cost per representative at least \(a_c+\beta\). In particular, \(c\) is the unique cheapest location, and

\[ C_\mu^\star=ka_c=2e+\frac14, \qquad \rho C_\mu^\star =ka_c+b+\frac12. \]

For any committee, let

\[ H=\sum_{u\ne c}y_u \]

be its number of noncentral representatives. Then

\[ C_\mu(y) =ka_c+\sum_{u\ne c}(a_u-a_c)y_u \ge ka_c+H\beta. \]

Moreover,

\[ \frac{(b+1)(4e+1)}{k} \le\frac{(e+1)(4e+1)}{8(e+1)^2} =\frac{4e+1}{8(e+1)} <\frac12. \]

Consequently,

\[ (b+1)\beta>b+\frac12. \]

It follows that every committee satisfying the strict cost threshold has \(H\le b\).

Conversely, a committee with \(r\le b\) representatives at set types and all remaining representatives at \(c\) satisfies

\[ C_\mu(y)\le ka_c+r \le ka_c+b <\rho C_\mu^\star. \]

5. A cheap PRF committee yields a set cover

Suppose \(y\) is PRF and satisfies the cost threshold. Section 4 gives \(H\le b\).

For each element \(i\), consider

\[ U_i=\{p_i,q_i\}. \]

Its mass is \(1/k\), its diameter is one, and its diameter-neighborhood is exactly

\[ N_1(U_i) =\{p_i,q_i\}\cup\{v_j:i\in S_j\}. \]

Therefore PRF requires

\[ y_{p_i}+y_{q_i} +\sum_{j:\,i\in S_j}y_{v_j}\ge1. \]

Map every occupied noncentral location to an original set: map \(v_j\) to \(S_j\), and map an occupied witness for element \(i\) to any set containing \(i\). Such a set exists by the source-instance restriction.

There are at most \(H\le b\) resulting distinct sets. They cover every element: the displayed fairness inequality ensures that each element has either an occupied witness of its own or an occupied set type containing it. Thus the original Set Cover instance answers yes.

6. A set cover yields a cheap PRF committee

Suppose \(S_{j_1},\ldots,S_{j_r}\) cover \(E\), where \(r\le b\). Choose one representative at each corresponding set type and put the remaining \(k-r\) representatives at \(c\).

Its cost satisfies the strict threshold by Section 4. We now verify PRF for every nonempty coalition \(U\).

Coalitions of diameter two

All distances are at most two, so \(N_2(U)=T\). This neighborhood contains all \(k\) representatives, which is at least \(\lfloor k\mu(U)\rfloor\).

Coalitions containing \(c\), of diameter at most one

Such a coalition contains no witness because every witness has distance two from \(c\). Therefore

\[ \mu(U)\le\mu_c+\sum_j\mu_{v_j} =1-\frac{e}{k}. \]

Its neighborhood contains \(c\), where there are

\[ k-r\ge k-b\ge k-e \]

representatives. This is at least \(\lfloor k\mu(U)\rfloor\).

Singleton coalitions other than \(c\)

Every noncentral singleton has mass at most \(1/(2k)\). Its required number of representatives is consequently zero.

Coalitions of diameter one that exclude \(c\)

Witnesses belonging to different elements have distance two, and distinct set types also have distance two. Hence such a coalition contains witnesses from at most one element and at most one set type.

If it contains at most one witness, then

\[ \mu(U)\le\frac{1}{2k}+\delta \le\frac{3}{4k}<\frac1k, \]

so its fairness constraint is vacuous.

Otherwise, it contains both \(p_i,q_i\) for some element \(i\), with possibly one set type. Its mass satisfies

\[ \frac1k\le\mu(U)\le\frac1k+\delta<\frac2k, \]

so it requires exactly one representative. Because the chosen sets cover \(i\), some selected \(v_j\) satisfies \(i\in S_j\). That representative lies in \(N_1(\{p_i,q_i\})\), and therefore in \(N_1(U)\).

These cases exhaust all coalitions. Thus the committee is PRF.

7. Reduction size and running times

We have proved the exact equivalence:

\[ \text{a set cover of size at most }b\text{ exists} \quad\Longleftrightarrow\quad \text{a PRF committee with }C_\mu(y)<\rho C_\mu^\star\text{ exists}. \]

The construction has \(m=\tau=1+2e+s\), \(k=8(e+1)^2=O(\tau^2)\), and rational numerators and denominators bounded by polynomials in \(e+s\). Writing the complete output takes

\[ O\bigl(\tau^2+\tau\log(es+2)\bigr) \]

bits and polynomial time in the source input length. Hence this is a polynomial-time many-one reduction.

In particular, hardness is not caused merely by binary encoding of a huge \(k\): it persists when \(k\) is polynomial in the support size. Any running time polynomial in \(m,\tau,L,k\), as well as any running time polynomial in \(L\), would imply \(\mathrm P=\mathrm{NP}\).

For comparison, a general exhaustive algorithm enumerates

\[ \binom{k+m-1}{m-1} \]

committees and checks every coalition using the floor formulation. Its running time is bounded by

\[ \binom{k+m-1}{m-1}\,2^\tau \operatorname{poly}(m,\tau,L). \]

For fixed \(m=\tau\), this is polynomial in the numerical value of \(k\), not necessarily in its encoding length.

Finally, the general problem belongs to \(\Sigma_2^p\): existentially specify the binary committee vector, then universally quantify over coalition bit vectors. The cost and individual coalition inequalities are computable in polynomial time. This upper bound does not establish membership in \(\mathrm{NP}\); no such membership claim is needed for the proved hardness result.
