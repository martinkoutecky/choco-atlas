The anchor (named result in the paper)

Theorem 2 — class: hardness

The continuous mirror question, as graded

Given a finite candidate set \(C\), candidate preferences, a fixed tie-breaking order, voter ranking types \(T\) with positive rational masses \(\mu_t\) summing to \(1\), an initial state, and a designated candidate \(c^\star\), does there exist a finite sequence of single-candidate improving moves that reaches an equilibrium where \(c^\star\) wins? For WINNER1, when a candidate withdraws, every type blocks that candidate; each type votes for its highest-ranked running candidate not blocked, or its highest-ranked running candidate if all running candidates are blocked. For WINNER0, no candidates are blocked. Initial refusal histories can be represented by splitting types that share a ranking but have different histories.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set, with \(m=|C|\); every candidate has a strict linear order over \(C\), with no requirement to rank itself first. Fix a strict tie-breaking order over \(C\), restricted to the running candidates in every election.
A society is given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Each type specifies a strict ranking of \(C\) and an initial blocked set \(B_t^0\subseteq C\); identical rankings with different histories are distinct types. Thus \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A state is \(S=(A,(B_t)_t)\), with \(\varnothing\ne A\subseteq C\). Each type votes with its entire mass for its highest-ranked candidate in \(A\setminus B_t\), or its highest-ranked candidate in \(A\) if \(A\setminus B_t=\varnothing\). The winner \(w(S)\) is selected by mass-weighted Plurality and the fixed tie-breaking order.
A move toggles one candidate's membership in \(A\), keeping \(A\) nonempty. In WINNER1, withdrawal of \(c\) replaces every \(B_t\) by \(B_t\cup\{c\}\); entry leaves all blocked sets unchanged, and blocks are never removed. In WINNER0, all blocked sets are always empty.
A move by \(c\) from \(S\) to \(S'\) is improving precisely when \(c\) strictly prefers \(w(S')\) to \(w(S)\), after the prescribed block update. An equilibrium has no improving move, including entry moves.
Given an initial state \(S_0\) and \(c^\star\in C\), each variant asks whether a finite improvement sequence, possibly of length zero, reaches an equilibrium won by \(c^\star\).

For each of WINNER1 and WINNER0 with this rational-mass society, is the reachability decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite electorates, WINNER1 is \(\mathrm{NP}\)-complete and WINNER0 is \(\mathrm{NP}\)-hard, even starting with all candidates running and no blocks ([Polukarov et al., 2015](https://www.ijcai.org/Proceedings/15/Papers/094.pdf)).
No result settling this exact rational-mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Specified strict linear orders for voters and candidates; self-supporting candidate preferences are not required by the discrete model.
  • Required a nonempty candidate set and nonempty running sets throughout; excluded withdrawal of the last running candidate because the election outcome would be undefined.
  • Specified mass-weighted Plurality and restriction of the fixed global tie-breaking order to each running set.
  • Represented arbitrary initial refusal histories by ranking-and-blocked-set types, counted separately in the support size.
  • Made blocks permanent, with no block update upon entry, following the formal state-based ballot definition and the graded question's fallback rule.
  • Included both entry and withdrawal among possible moves, evaluated improvement after the prescribed state update, and defined equilibrium using those same moves.
  • Allowed a zero-length sequence when the initial state already meets the requested condition, and defined L as total input bit length.

Conclusion

Both \(\mathrm{WINNER1}\) and \(\mathrm{WINNER0}\) are \(\mathrm{NP}\)-hard for the rational-mass formulation. Hardness holds even when initially all candidates run and every blocked set is empty.

The proof is a polynomial reduction from the finite-electorate hardness results supplied in the question. It preserves the entire improvement dynamics, including entry moves and the fallback voting rule.

1. The finite-electorate premise

We use the following given result: for a nonempty finite electorate represented explicitly by its voters, both variants are \(\mathrm{NP}\)-hard, even with all candidates initially running and no initial blocks. These are the hardness conclusions of Theorems 2 and 3 of [Polukarov et al. (2015)](https://www.ijcai.org/Proceedings/15/Papers/094.pdf).

Their model uses fixed tie-breaking priorities and, when a voter has blocked every running candidate, selects that voter’s highest-ranked running candidate while retaining the blocks. Thus the voting and block-update rules agree with those in the question. No assumption that candidates rank themselves first is needed.

2. Constructing the rational-mass society

Let a finite-electorate instance have \(\mathrm{n}\) voters, where \(\mathrm{n}>0\). Keep its candidates, candidate preferences, tie-breaking order, initial running set, and designated candidate.

Partition the voters according to their ranking and initial blocked set. For each nonempty class indexed by \(\mathrm{t}\), let \(\mathrm{k}_t\) be its cardinality. Create one type with that class’s ranking and initial blocked set, and assign mass \(\mu_t=k_t/n\).

These masses satisfy \(\mu_t>0\) and \(\sum_{t=1}^{\tau}\mu_t=1\). Each numerator and denominator requires at most \(O(\log(n+1))\) bits, and \(\tau\leq n\). Fractions may be reduced without increasing their encoding lengths.

The construction is polynomial in the explicit finite-electorate input length: partitioning explicitly listed records and computing their multiplicities takes polynomial time, and each resulting type record has polynomial length. In particular, compression introduces no enumeration of possible rankings.

3. Exact preservation of dynamics

Fix any finite sequence of candidate toggles that keeps the running set nonempty. Apply the sequence in both instances, without yet requiring the moves to improve the outcome.

We prove inductively that, after every prefix:

  • The running sets agree.
  • Every original voter in class \(\mathrm{t}\) has the same blocked set as rational type \(\mathrm{t}\).
  • The winners agree.

The first two statements hold initially by construction. A toggle changes the same candidate’s running status in both instances. In \(\mathrm{WINNER0}\), blocks remain empty. In \(\mathrm{WINNER1}\), entry preserves every block, and withdrawal of \(\mathrm{c}\) adds \(\mathrm{c}\) to every block. Hence the first two statements persist.

Consequently, all original voters in class \(\mathrm{t}\) choose the same candidate as type \(\mathrm{t}\). This also holds in the fallback case, because their rankings, running sets, and blocked sets agree.

For each running candidate \(\mathrm{x}\), write \(\mathrm{N}_x\) for its finite-electorate vote count and \(\mathrm{M}_x\) for its rational-mass score. Then \(\mathrm{M}_x=N_x/n\). Multiplication by the positive constant \(\mathrm{1}/n\) preserves all score comparisons and equalities. The common tie-breaking order therefore selects the same winner.

Now consider any legal next move by candidate \(\mathrm{c}\). Both its current and resulting winners agree across the instances. Since candidate preferences are unchanged, the move is improving in one instance exactly when it is improving in the other.

It follows that the same candidate sequences are improvement sequences in both instances. At corresponding reachable states, every legal withdrawal and entry has the same improvement status. Thus equilibrium status and the equilibrium winner agree, including for a sequence of length zero.

We have proved that the finite instance is a yes-instance if and only if its rational-mass image is a yes-instance. Together with the polynomial construction, this establishes both hardness claims.

If the tie-breaking order is fixed externally rather than supplied as input, relabel candidates in priority order and apply the same relabeling to all rankings and the designated candidate. This preserves the argument.

4. Exact computation and running times

For completeness, the following bounds use precisely \(\mathrm{m},\tau,L\) from the question. They also give finite decision algorithms without claiming polynomial running time.

Write each input mass as \(\mu_t=p_t/q_t\), with positive integers encoded in binary. Set \(\mathrm{Q}=\prod_t q_t\) and \(\mathrm{a}_t=p_t(Q/q_t)\). The total bit length of the denominators is at most \(\mathrm{L}\), so \(\mathrm{Q}\) has \(O(L)\) bits. Moreover, \(\sum_t a_t=Q\). Plurality comparisons can therefore use exact integer scores with \(O(L)\) bits.

Using elementary integer arithmetic gives these conservative bounds:

  • Computing a winner, including scanning rankings and handling fallback, takes \(O((\tau m+m)L^2)\) bit operations.
  • Testing equilibrium by checking every legal toggle takes \(O(m^2(\tau+1)L^2)\) bit operations.

For \(\mathrm{WINNER0}\), a state is determined by its nonempty running set, so there are at most \(\mathrm{2}^m\) states. Exploring the reachable improvement graph and accepting precisely when a reachable equilibrium has the designated winner takes \(O(2^m m^2(\tau+1)L^2)\) time.

For \(\mathrm{WINNER1}\), let \(\mathrm{H}\) be the set of candidates withdrawn at least once since the initial state. Every reachable blocked set satisfies \(\mathrm{B}_t=B_t^0\cup H\), by induction on the moves. Thus a reachable state can be represented by \(\mathrm{(A,H)}\), giving at most \(\mathrm{4}^m\) representations. The same exploration takes \(O(4^m m^2(\tau+1)L^2)\) time.

The requested classification is therefore settled: both problems are \(\mathrm{NP}\)-hard. The argument does not assert membership in \(\mathrm{NP}\) for the full rational-mass formulation.
