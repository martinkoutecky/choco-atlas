The anchor (named result in the paper)

Theorem 2.8 — class: other

The continuous mirror question, as graded

Given a unit-mass society of one interchangeable type, a measurable coalition \(C\) of mass \(q\in(0,1]\), common singleton value \(u\), and transferable coalition value \(V\ge qu\), find a measurable payoff \(x:C\to\mathbb R\) with \(x(a)\ge u\) and \(\int_C x(a)\,da=V\) that maximizes \(\frac1q\int_C\log(x(a)-u)\,da\) when \(V>qu\); when \(V=qu\), return \(x(a)=u\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here \(\tau=1\), its mass is \(1\), and there is no additional combinatorial dimension (set \(m=1\)).
Represent the atomless society by \([0,1]\) with Lebesgue measure. The input consists of binary rationals \(q\in(0,1]\), \(u\ge0\), and \(V\ge qu\); \(L\) is their total encoding length. Since all individuals are interchangeable, represent the given coalition by \(C=[0,q]\).
A feasible payoff is an integrable measurable function \(x:C\to\mathbb R\) satisfying \(x\ge u\) almost everywhere and \(\int_C x(a)\,da=V\). For \(V>qu\), maximize \(q^{-1}\int_C\log(x(a)-u)\,da\), with \(\log 0=-\infty\) and the integral interpreted in the extended sense. For \(V=qu\), return \(x=u\) almost everywhere.
Represent an output by a finite interval partition of \(C\) with rational endpoints and rational payoff values, identifying payoffs that agree almost everywhere; optimization is over all feasible measurable payoffs.

Is exact computation of an optimal payoff for this problem possible in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite transferable-utility coalitions, equal division of surplus maximizes the product of individual surpluses; the stated negotiation result identifies this division with the outcome of product-based concessions that decrease the conceding agent’s payoff. [Guéneron–Bonnet](https://roia.centre-mersenne.org/item/10.5802/roia.63.pdf)
A different continuum bargaining model establishes convergence and regularity for resource allocations with distance-dependent utilities; it does not classify this support-encoded computational problem. No exact complexity classification for the problem stated here was located. [Warren](https://pages.uoregon.edu/micahw/papers/NBSMarch9.pdf)

Modeling choices made when packaging the task

  • Restricted the common singleton value to a nonnegative binary rational, consistent with nonnegative payoffs and the zero-surplus case in the discrete model.
  • Made coalition mass and transferable value binary rational inputs and defined their total encoding length L.
  • Used an atomless Lebesgue society and represented the interchangeable coalition by an interval of its given mass, eliminating the unspecified encoding of an arbitrary measurable set.
  • Interpreted feasibility and payoff equality almost everywhere, required integrability, and defined the logarithmic objective at zero surplus through an extended integral.
  • Specified finite rational interval step functions as the computational output representation while retaining optimization over all measurable feasible payoffs.
  • Set m=1 because the model has no additional combinatorial objects; the fixed support size is tau=1.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Exact computation is polynomial-time solvable. The unique optimal payoff, up to equality almost everywhere, is

\(x^*(a)=V/q\quad\text{for all }a\in[0,q].\)

It has a valid representation consisting of one interval with a rational payoff value. The proof below covers optimization over all feasible measurable payoffs.

Optimality when the surplus is positive

Suppose \(V>qu\). Define the total surplus \(S=V-qu>0\) and its average \(s=S/q>0\).

For any feasible payoff \(x\), let \(y=x-u\). After changing values on a null set if necessary, \(y\) is nonnegative everywhere, integrable, and satisfies

\(\int_C y(a)\,da=S=qs.\)

First, the logarithmic integral is well defined in the stated extended sense. Indeed, its positive part satisfies \((\log y)^+\le y\), interpreting the positive part as zero when \(y=0\). Thus its positive part is integrable, and \(\int_C\log y\) is either finite or equals \(-\infty\).

For every \(t>0\),

\(\log t\le \log s+(t-s)/s,\)

with equality exactly when \(t=s\). To verify this, set \(r=t/s\). The function \(r-1-\log r\) has derivative \(1-1/r\), so it decreases up to \(r=1\), increases thereafter, and has minimum zero. The inequality also holds at \(t=0\) under the convention \(\log 0=-\infty\).

If \(\int_C\log y=-\infty\), the payoff cannot improve upon a constant positive surplus. Otherwise, both parts of \(\log y\) are integrable, so integrating the inequality gives

\(\int_C\log y(a)\,da\le q\log s+\frac{1}{s}\left(\int_C y(a)\,da-qs\right)=q\log s.\)

Consequently, every feasible payoff satisfies

\(q^{-1}\int_C\log(x(a)-u)\,da\le\log s.\)

The constant payoff \(x^*=u+s=V/q\) is feasible: it exceeds \(u\), and its integral is \(q(V/q)=V\). Its surplus is constantly \(s\), so it attains the bound.

For uniqueness, any maximizing payoff has finite logarithmic integral. The nonnegative, integrable gap

\(h(a)=\log s+(y(a)-s)/s-\log y(a)\)

then has integral zero. A nonnegative measurable function with zero integral is zero almost everywhere. The equality condition in the pointwise inequality therefore gives \(y=s\) almost everywhere, hence \(x=V/q\) almost everywhere.

The zero-surplus case

Suppose \(V=qu\). For any feasible payoff, \(y=x-u\) is nonnegative almost everywhere and satisfies

\(\int_C y(a)\,da=V-qu=0.\)

Therefore \(y=0\) almost everywhere, and \(x=u\) almost everywhere. Since \(V/q=u\), the same constant-output formula handles this case.

Exact representation and running time

The algorithm outputs the single interval \(C=[0,q]\), assigned payoff \(V/q\).

Under the usual explicit binary encoding of rational numbers, write \(q=A/B\) and \(V=D/E\), where \(A,B,E\) are positive integers and \(D\) is nonnegative. Then

\(V/q=DB/(EA).\)

The numerator and denominator each have bit length bounded by the sum of the bit lengths of their factors, hence by \(O(L)\). Integer multiplication takes polynomial time; reducing the fraction, if required, also takes polynomial time using the Euclidean algorithm. The endpoints \(0,q\) already have polynomial-size encodings.

Thus the algorithm produces an exact optimizer of size \(O(L)\) in polynomial time in \(L\), and therefore in \(m,\tau,L\) for the stipulated \(m=\tau=1\). Computing the potentially irrational optimum objective value \(\log s\) is unnecessary because the requested output is the payoff.

This settles the stated problem as polynomial-time solvable. NP-hardness under standard polynomial-time reductions would consequently imply \(\mathrm{P}=\mathrm{NP}\).
