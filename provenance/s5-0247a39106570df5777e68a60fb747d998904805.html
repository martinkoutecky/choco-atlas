The continuous mirror question, as graded

Given a finite outcome set \(X\) and a rational distribution \(\mu\) over supported weak-order preference types, is every lottery supported on the Pareto-optimal outcomes ex-ante efficient under stochastic-dominance preferences of all supported types?

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a nonempty finite outcome set, with \(m=|X|\). A society is given by its support: a list \(T\) of \(\tau\) distinct weak-order preference types over \(X\), each with positive binary rational mass \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Types are encoded as ordered indifference classes; \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Let \(X^*\) consist of outcomes \(x\) for which no \(y\in X\) satisfies \(y\succeq_t x\) for every \(t\in T\) and \(y\succ_t x\) for some \(t\in T\).
Lotteries may have arbitrary real probabilities. A lottery \(p\in\Delta(X)\) is ex-ante efficient if no \(q\in\Delta(X)\) weakly stochastically dominates \(p\) for every supported type and strictly stochastically dominates it for at least one supported type. Indifferences are retained without tie-breaking; dominance compares each type separately.

Is deciding whether every lottery \(p\in\Delta(X^*)\) is ex-ante efficient solvable in polynomial time in \(m,\tau,L\), or is this decision problem NP-hard?

For a finite list of agents with weak-order preferences, deciding whether every lottery supported on Pareto-optimal outcomes is ex-ante efficient is polynomial-time solvable. [Echenique, Root, and Sandomirskiy](https://arxiv.org/pdf/2203.06353v3).

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: all listed masses are positive binary rationals summing to one.
  • Required a nonempty outcome set and encoded each weak order by ordered indifference classes.
  • Interpreted Pareto improvement and lottery improvement typewise: weak improvement for every supported type and strict improvement for at least one supported type.
  • Allowed arbitrary real lottery probabilities, including for dominating alternatives over the full outcome set, as in the discrete definition.
  • Defined L as total input bit length and retained preference indifferences without tie-breaking.

Result

The decision problem is polynomial-time solvable in \(m,\tau,L\).

The masses \(\mu_t\) do not affect the answer: both Pareto dominance and stochastic dominance are tested separately for every supported type. Replacing the society by one agent of each listed type preserves both definitions exactly. Thus the cited finite-agent theorem applies with \(\tau\) agents, without expanding the binary rational masses. This agrees with Corollary 3 of [Echenique, Root, and Sandomirskiy](https://arxiv.org/pdf/2203.06353v3).

Here is a direct, self-contained linear-programming proof.

1. Compute the Pareto set

Write each type’s indifference classes, from best to worst, as
\(C_{t,1},\ldots,C_{t,k_t}\), and let \(r_t(x)\) be the class index containing \(x\).

An outcome \(y\) Pareto-dominates \(x\) precisely when
\(r_t(y)\leq r_t(x)\) for every \(t\), with strict inequality for at least one \(t\).
Checking all ordered outcome pairs computes \(S=X^*\) using
\(O(\tau m^2)\) rank comparisons.

Moreover, \(S\) is nonempty. Indeed, choose an outcome minimizing
\(\sum_{t\in T}r_t(x)\). A Pareto dominator would have a strictly smaller sum, contradicting minimality.

2. Encode stochastic dominance without breaking ties

For each \(t\) and \(1\leq j<k_t\), define the upper contour set
\(U_{t,j}=\bigcup_{\ell=1}^{j}C_{t,\ell}\).
For a lottery \(a\), write
\(a(U)=\sum_{x\in U}a_x\).

These sets are exactly the distinct nontrivial upper contour sets of the weak order. The remaining upper contour set is \(X\), on which every lottery has probability one. Consequently, \(q\) weakly stochastically dominates \(p\) for type \(t\) exactly when
\(q(U_{t,j})\geq p(U_{t,j})\) for every \(j<k_t\).
It strictly stochastically dominates \(p\) exactly when these inequalities hold and at least one is strict.

The total number of cutoffs is
\(K=\sum_{t\in T}(k_t-1)\leq\tau(m-1)\).

3. One linear program decides the question

Use variables \(p_x\) for \(x\in S\) and \(q_x\) for \(x\in X\). Extend \(p\) by zero outside \(S\). Solve the linear program maximizing
\[ \text{not used} \]
\( \displaystyle D(p,q)= \sum_{t\in T}\sum_{j=1}^{k_t-1} \left( \sum_{x\in U_{t,j}}q_x - \sum_{x\in U_{t,j}\cap S}p_x \right) \)
subject to
\( \displaystyle p_x\geq0\quad(x\in S),\qquad \sum_{x\in S}p_x=1, \)
\( \displaystyle q_x\geq0\quad(x\in X),\qquad \sum_{x\in X}q_x=1, \)
and, for every cutoff,
\( \displaystyle \sum_{x\in U_{t,j}}q_x - \sum_{x\in U_{t,j}\cap S}p_x \geq0. \)

The feasible region is nonempty: choose \(p=q\) to be a point mass at any outcome in \(S\). It is also compact, being a closed subset of the product of two finite-dimensional simplices. Hence the maximum \(v\) exists, and \(v\geq0\).

Every summand of \(D\) is nonnegative on the feasible region. Therefore \(D(p,q)>0\) holds exactly when \(q\) weakly stochastically dominates \(p\) for every supported type and strictly stochastically dominates it for at least one type.

It follows in both directions that:

  • If some \(p\in\Delta(S)\) is inefficient, its dominating lottery \(q\) gives a feasible pair with \(D(p,q)>0\), so \(v>0\).
  • If \(v>0\), a maximizing feasible pair supplies an inefficient \(p\in\Delta(S)\).

Thus the algorithm answers yes exactly when \(v=0\).

4. Bit complexity and arbitrary real probabilities

The linear program has at most \(2m\) variables and \(K+O(m)\) constraints. Constraint coefficients and right-hand sides belong to \(\{-1,0,1\}\). After collecting terms, objective coefficients are integers of absolute value at most \(K\). A dense encoding therefore has bit length
\(B=O((K+m+1)m+m\log(K+2))\).

The standard polynomial-time theorem for rational linear programming applies: the program has rational input and a nonempty bounded feasible region, so its exact optimum can be computed in time polynomial in its dimensions and encoding length. In particular, the comparison \(v=0\) is exact.

This also handles arbitrary real lottery probabilities. Any real dominating pair yields positive objective value; a positive optimum of this rational program has a rational optimal solution. No discretization of lotteries is assumed.

Including input reading and rank computations, a bit-complexity bound is
\(O(L+\tau m^2\log(m+1))+\operatorname{poly}(m,\tau m,B)\),
which is \((m+\tau+L)^{O(1)}\). The masses require no denominator expansion.
