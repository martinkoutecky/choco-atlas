The continuous mirror question, as graded

Given a connected graph G and a rational distribution over complete weak edge-ranking types, find a minimum-cardinality H subset of E such that every positive-mass type has an MST of G contained in H.

Packaged proof task (what the prover saw — nothing else)

A type \(t\) is a complete weak order on \(E\), represented by ordered tie classes from cheapest to most expensive. A \(t\)-MST is a spanning tree returned by Kruskal's algorithm under this order, with ties broken arbitrarily.
The input explicitly lists a finite set \(T\) of types with rational masses \(\mu_t\ge 0\) satisfying \(\sum_{t\in T}\mu_t=1\), and an integer \(B\). Write \(T_+=\{t\in T:\mu_t>0\}\). The instance is feasible if some \(H\subseteq E\) with \(|H|\le B\) contains a \(t\)-MST for every \(t\in T_+\).

Is this distributional MMCP decision problem solvable in polynomial time, or is it NP-hard?

For a finite list of agents, the corresponding MMCP problem is NP-hard even when every agent has binary edge weights in \(\{0,1\}\). No result for the explicitly represented distribution-over-types formulation above was verified.

Complexity classification

Theorem

The explicitly represented distributional MMCP decision problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard even when every positive-mass type has binary edge weights and all positive masses are equal.

Support-compression lemma

For a graph \(G=(V,E)\), budget \(B\), and edge-order type \(t\), define \(P_H(t)\) to mean that \(H\subseteq E\) contains a \(t\)-MST.

Let \(t_1,\ldots,t_n\) be a finite list of agent types, and let \(U=\{t_i:i\in\{1,\ldots,n\}\}\) be the set of distinct types occurring in the list. Then, for every \(H\subseteq E\),

\[ \bigl(\forall i\in\{1,\ldots,n\},\ P_H(t_i)\bigr) \quad\Longleftrightarrow\quad \bigl(\forall t\in U,\ P_H(t)\bigr). \]

Indeed, the forward implication follows because every \(t\in U\) equals \(t_i\) for some \(i\). Conversely, every \(t_i\) belongs to \(U\), so the right-hand condition implies \(P_H(t_i)\) for every \(i\).

Thus duplicate agents impose no additional feasibility constraints. More generally, in the distributional formulation the numerical values of the positive masses are irrelevant: feasibility depends only on \(T_+\).

Polynomial reduction from finite-agent MMCP

Use the given premise that finite-agent MMCP is \(\mathrm{NP}\)-hard even when every agent assigns each edge a weight in \(\{0,1\}\).

Consider such a finite-agent instance consisting of:

  • a graph \(G=(V,E)\);
  • binary edge-weight functions \(w_1,\ldots,w_n:E\to\{0,1\}\);
  • a budget \(B\).

Each \(w_i\) induces a complete weak order \(t_i\): all edges of weight \(0\) form the cheapest tie class, followed by all edges of weight \(1\). Empty tie classes may simply be omitted.

Compute the set \(U=\{t_i:i\in\{1,\ldots,n\}\}\) of distinct induced types, and write \(k=|U|\). Restricting to the nonempty finite-agent instances used in the hardness result gives \(k\geq 1\).

Construct a distributional instance by setting

\[ T=U \qquad\text{and}\qquad \mu_t=\frac{1}{k} \quad\text{for every }t\in T. \]

Then every mass is positive and

\[ \sum_{t\in T}\mu_t = k\cdot\frac{1}{k} = 1. \]

Hence \(T_+=T=U\).

This construction is polynomial-time. Binary types can be represented by bit vectors of length \(|E|\), so duplicates can be removed in polynomial time. Moreover, the rational number \(1/k\) has encoding length \(O(\log k)\).

For every \(H\subseteq E\), the support-compression lemma gives

\[ H\text{ contains a }t_i\text{-MST for every agent }i \quad\Longleftrightarrow\quad H\text{ contains a }t\text{-MST for every }t\in T_+. \]

The budget is unchanged. Consequently, the finite-agent instance has a feasible cover of size at most \(B\) if and only if the constructed distributional instance does. This is a polynomial many-one reduction, proving \(\mathrm{NP}\)-hardness.

Membership in \(\mathrm{NP}\)

A certificate consists of:

  • a set \(H\subseteq E\) with \(|H|\leq B\);
  • for every \(t\in T_+\), a permutation \(\pi_t\) of \(E\) specifying the tie-breaking order within each tie class of \(t\).

The verifier checks that each \(\pi_t\) respects the ordered tie classes of \(t\), runs Kruskal’s algorithm in the order \(\pi_t\), and verifies that the resulting spanning tree is contained in \(H\).

These operations take polynomial time using, for example, a disjoint-set data structure. The certificate contains \(O(|T_+||E|)\) edge entries and therefore has polynomial size because all types are explicitly represented.

Thus the problem belongs to \(\mathrm{NP}\).

Conclusion

The distributional formulation does not become easier through aggregation into rational masses. Universal satisfaction depends only on which types have positive mass, so the known finite-agent hardness transfers after identical types are merged. The problem is therefore \(\mathrm{NP}\)-complete, and hence it is not polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).

Verification report

Overall assessment

The reduction and NP-membership argument are mathematically sound in substance. The only gap is a routine edge case concerning finite-agent instances with no agents. No major issue undermines the claimed NP-completeness result.

Step-by-step audit

  • Support compression. The equivalence between satisfying every occurrence \(t_i\) and satisfying every distinct type in \(U\) is correct. Duplicate agents impose identical existential MST-containment conditions, so multiplicity is irrelevant.
  • Irrelevance of positive masses. Feasibility quantifies universally over \(T_+\) and never otherwise uses \(\mu_t\). Therefore changing positive masses while preserving their support does not change feasibility. This claim is correct.
  • Conversion of binary weights to types. Each binary weight function induces the stated weak order, with weight-\(0\) edges preceding weight-\(1\) edges. Omitting an empty tie class does not change the order. This step is correct.
  • Construction of the distribution. After duplicate types are removed, assigning mass \(1/k\) to each of the \(k\) distinct types produces valid rational masses summing to \(1\). The encoding-length claim \(O(\log k)\) is correct.
  • Polynomial running time. Comparing the binary type vectors and removing duplicates can be done in polynomial time. The constructed instance has polynomial size.
  • Preservation of feasibility. For every candidate \(H\), the support-compression lemma gives exactly the required equivalence between the finite-agent and distributional feasibility conditions. The unchanged budget therefore preserves yes-instances and no-instances.
  • Empty-agent edge case. The construction uses \(1/k\), so it requires \(k\geq 1\). The prover asserts that one may restrict to “the nonempty finite-agent instances used in the hardness result,” but the supplied premise only states NP-hardness for a finite list of agents and does not explicitly state that the source hardness theorem is restricted to nonempty lists. The write-up must either cite that restriction as part of the given hardness result or explicitly address source instances with zero agents. This is a minor gap because it is an isolated, elementary boundary case, but the reduction as written is not literally defined on every stated source instance.
  • Membership in NP. A tie-respecting permutation for each positive-mass type specifies a valid total refinement of its weak order. Running Kruskal under that refinement and checking that the resulting spanning tree lies in \(H\) correctly verifies the existential condition that \(H\) contains some \(t\)-MST. The certificate size and verification time are polynomial because the types are explicitly represented. The verifier should, as part of its routine validation, check that every supplied sequence is genuinely a permutation of \(E\); this is implicit in the description of the certificate and does not constitute a substantive gap.
  • Conclusion. Subject to the minor empty-agent clarification, NP-hardness and membership in NP establish NP-completeness. The stronger claim that hardness holds with binary types and equal positive masses is supported by the construction.

Actionable feedback

State explicitly why the invoked finite-agent NP-hardness remains valid when there is at least one agent, or add a separate treatment of zero-agent source instances. No new structural lemma is needed.
