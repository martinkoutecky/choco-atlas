The continuous mirror question, as graded

Given schools \(S\), a finite support \(T\) of strict student rankings with rational masses \(\mu_t\) summing to \(1\), per-capita school capacities \(\kappa_s\) with \(\sum_s \kappa_s \ge 1\), and a common strictly increasing nonnegative rational cost \(f\) on ranks, compute a rational assignment \(x_{ts}\) minimizing \(\sum_{t\in T,s\in S} x_{ts} f(\operatorname{rank}_t(s))\), subject to \(x_{ts}\ge 0\), \(\sum_s x_{ts}=\mu_t\), and \(\sum_t x_{ts}\le\kappa_s\). Establish whether every minimum-cost assignment is Pareto efficient when atomless type mass can be partitioned among schools and each individual receives one school.

Packaged proof task (what the prover saw — nothing else)

Let \(S\) be a nonempty set of \(m\) schools. A society is given by its support: a list \(T\) of \(\tau\) distinct strict rankings of all schools, each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
Capacities \(\kappa_s\) are nonnegative binary rationals with \(\sum_s\kappa_s\ge1\). The common cost function \(f:\{1,\ldots,m\}\to\mathbb Q_{\ge0}\) is strictly increasing and given by its values. Let \(L\) be the total input bit length; express running times in \(m,\tau,L\).
A feasible assignment satisfies \(x_{ts}\ge0\), \(\sum_s x_{ts}=\mu_t\), and \(\sum_t x_{ts}\le\kappa_s\); its cost is \(C(x)=\sum_{t,s}x_{ts}f(\operatorname{rank}_t(s))\). All students receive one school, and school priorities impose no constraints.
Interpret each type as an atomless measurable population of mass \(\mu_t\), partitioned among schools according to \(x\). A realization is Pareto efficient if no feasible measurable reassignment makes almost every individual weakly better off and a set of positive mass strictly better off. Call \(x\) Pareto efficient if every realization is efficient; competing reassignments may have real masses.

Is computing a rational minimum-cost assignment polynomial-time solvable in \(m,\tau,L\), or is the threshold decision problem \(C(x)\le B\), for binary rational input \(B\), NP-hard? Does every minimum-cost assignment satisfy the stated Pareto efficiency condition, or can it fail?

For finite students and integer capacities, minimum-cost assignments under a common strictly increasing rank cost are Pareto efficient and can be computed by the Hungarian algorithm. [Discrete result](https://arxiv.org/pdf/1304.7413v2).

Result

Computing a rational minimum-cost assignment is polynomial-time solvable in \(m,\tau,L\). The threshold decision problem belongs to \(\mathrm P\). Moreover, every minimum-cost assignment satisfies the stated Pareto efficiency condition, including against measurable reassignments with real masses.

1. Feasibility and existence of an optimum

Let \(P\subseteq\mathbb R^{\tau m}\) be the feasible set defined in the question.

First, \(P\) is nonempty. Put \(K=\sum_{s\in S}\kappa_s\), so \(K\ge1\), and define

\(x_{ts}=\mu_t\kappa_s/K.\)

These entries are nonnegative. For every type \(t\),

\(\sum_s x_{ts}=\mu_t,\)

and for every school \(s\),

\(\sum_t x_{ts}=\kappa_s/K\le\kappa_s.\)

Thus this assignment is feasible.

The set \(P\) is closed because it is defined by finitely many linear equalities and inequalities. Every feasible assignment satisfies \(0\le x_{ts}\le\mu_t\le1\), so \(P\) is bounded. Consequently, \(P\) is compact, and the continuous linear objective \(C\) attains its minimum over \(P\).

Throughout, this minimum is taken over real-valued feasible assignments.

2. Polynomial-time computation and rational output

Set \(N=m\tau\), and define the rational coefficients

\(c_{ts}=f(\operatorname{rank}_t(s)).\)

The optimization problem is exactly the rational linear program

\(\min\left\{\sum_{t,s}c_{ts}x_{ts}:x_{ts}\ge0,\ \sum_sx_{ts}=\mu_t\text{ for every }t,\ \sum_tx_{ts}\le\kappa_s\text{ for every }s\right\}.\)

It has \(N\) variables, \(\tau\) equality constraints, and \(m+N\) inequality constraints. Its constraint coefficients belong to \(\{-1,0,1\}\). Each objective coefficient is copied from the supplied list of values of \(f\).

The standard polynomial-time theorem for rational linear programming gives an exact rational optimum, when a finite optimum exists, in time polynomial in the explicit binary encoding length of the linear program. This theorem includes problems with equality constraints and feasible sets of lower dimension. See [David Karger’s notes on linear programming algorithms](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html).

Here all hypotheses hold: the coefficients are rational, the feasible set is nonempty, and the optimum is finite by Section 1. Even a dense encoding of this linear program has length

\(O\!\left(N(N+m+\tau)+NL+L\right).\)

Therefore an exact rational minimum-cost assignment can be computed in

\((m\tau+m+\tau+L)^{O(1)}\)

bit operations. In particular, this uses only the listed \(\tau\) types; it does not enumerate all possible rankings.

For completeness, the existence of an optimum with polynomial output length also follows directly from a determinant bound. Replace each capacity by \(\widehat\kappa_s=\min\{\kappa_s,1\}\). This preserves the feasible set because every school’s assigned mass is at most the total population mass, which is \(1\).

A linear function on a nonempty compact polytope has an optimal vertex. At such a vertex, select \(N\) linearly independent active constraints, obtaining

\(Hx=b,\)

where \(H\) is an invertible integer matrix with entries in \(\{-1,0,1\}\), and every entry of \(b\) lies in \([0,1]\).

Let \(D\) be the product of the denominators of all masses and truncated capacities. Its binary length is \(O(L)\), and \(Db\) is integral. Let \(H_i\) denote \(H\) with column \(i\) replaced by \(Db\). Cramer’s rule gives

\(x_i=\dfrac{\det(H_i)}{D\det(H)}.\)

Each column of \(H\) has Euclidean norm at most \(\sqrt N\), and the replacement column has norm at most \(D\sqrt N\). Hadamard’s inequality therefore yields

\(|\det(H)|\le N^{N/2},\qquad |\det(H_i)|\le D N^{N/2}.\)

Thus each coordinate has a rational representation using \(O(L+N\log(N+1))\) bits.

Finally, for the threshold problem, compute an exact optimum \(x^*\) and compare the rational numbers \(C(x^*)\) and \(B\). Rational arithmetic and comparison take polynomial time in their encoding lengths. Hence the threshold problem is in \(\mathrm P\), with the same polynomial bound when \(L\) includes the encoding of \(B\).

3. Every minimum-cost assignment is Pareto efficient

Let \(x\) be any minimum-cost assignment, and fix any realization of it.

Represent the population as a disjoint union \(\Omega=\bigsqcup_{t\in T}\Omega_t\), with measure \(\lambda\) satisfying \(\lambda(\Omega_t)=\mu_t\). The realization is a measurable map \(a:\Omega\to S\) such that

\(\lambda(\{\omega\in\Omega_t:a(\omega)=s\})=x_{ts}.\)

For an individual \(\omega\in\Omega_t\), define the assigned rank by

\(r_a(\omega)=\operatorname{rank}_t(a(\omega)).\)

Since these functions have finitely many values, they are measurable and integrable, and

\(\int_\Omega f(r_a(\omega))\,d\lambda(\omega)=C(x).\)

Suppose, for contradiction, that a feasible measurable reassignment \(b:\Omega\to S\) makes almost every individual weakly better off and a set of positive mass strictly better off. Define

\(y_{ts}=\lambda(\{\omega\in\Omega_t:b(\omega)=s\}).\)

These entries may be irrational. Nevertheless, they are nonnegative, each type’s row sums to \(\mu_t\), and feasibility of \(b\) gives each school’s capacity inequality. Thus \(y\in P\).

Because rankings are strict, weak improvement means

\(r_b(\omega)\le r_a(\omega)\)

almost everywhere. Strict improvement means \(r_b(\omega)<r_a(\omega)\). Let \(I\) be the measurable set of strictly improved individuals; by assumption, \(\lambda(I)>0\).

If \(m=1\), strict improvement is impossible. Assume therefore that \(m\ge2\), and put

\(\delta=\min_{1\le j<m}\bigl(f(j+1)-f(j)\bigr)>0.\)

The positivity follows from strict increase of \(f\) and finiteness of its domain. Almost everywhere,

\(f(r_a(\omega))-f(r_b(\omega))\ge0.\)

On \(I\), the rank decreases by at least one position, so

\(f(r_a(\omega))-f(r_b(\omega))\ge\delta.\)

Integrating gives

\(C(x)-C(y)=\int_\Omega\bigl(f(r_a(\omega))-f(r_b(\omega))\bigr)\,d\lambda(\omega)\ge\delta\lambda(I)>0.\)

This contradicts the minimum-cost property of \(x\), which holds over the real feasible set \(P\).

The chosen realization was arbitrary. Therefore every realization of every minimum-cost assignment is Pareto efficient, exactly as required.
