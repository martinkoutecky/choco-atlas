The continuous mirror question, as graded

Given issues \(I_1,\ldots,I_m\) with finite domains \(D_1,\ldots,D_m\), a finite support \(T\) of complete conditional-ballot types with rational masses \(\mu_t>0\) summing to \(1\), and a rational threshold \(q\), decide whether \(\min_{r\in\prod_j D_j}\sum_{t\in T}\mu_t\delta_t(r)\le q\). For the Theorem 2 restriction, each conditional type has an in-star dependency graph on three vertices.

Packaged proof task (what the prover saw — nothing else)

Issues \(I_1,\ldots,I_m\) have explicitly listed, nonempty finite domains \(D_j\); write \(d=\max_j|D_j|\).
A society is given by its support: a list \(T\) of \(\tau\) distinct complete conditional-ballot types with positive binary rational masses \(\mu_t\) satisfying \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Type \(t\) specifies a dependency graph \(G_t\) on all issues and, for every issue \(I_j\), an explicit list \(C_{tj}\) of statements \((p,A)\), where \(p\in\prod_{I_k\in N_t^-(I_j)}D_k\), \(N_t^-(I_j)\) is its set of incoming neighbors, and \(A\subseteq D_j\) may be empty.
For an outcome \(r\in\prod_jD_j\), type \(t\) is satisfied on \(I_j\) exactly when some \((p,A)\in C_{tj}\) has \(p=r|_{N_t^-(I_j)}\) and \(r_j\in A\). Missing premises give dissatisfaction; an issue with no incoming neighbors uses the empty premise. Let \(\delta_t(r)\) count dissatisfied issues.
Each \(G_t\) is either edgeless or consists of exactly two edges \(I_a\to I_c\) and \(I_b\to I_c\) on three distinct issues, with all other vertices isolated. The undirected union of these graphs has no isolated vertices.
The threshold \(q\in\mathbb Q\) is binary encoded. Let \(L\) be the total input bit length; state running times in \(m,\tau,d,L\).

Is deciding whether \(\min_{r\in\prod_jD_j}\sum_{t\in T}\mu_t\delta_t(r)\le q\) polynomial-time solvable or NP-hard under these restrictions?

Discrete conditional minisum with these dependency restrictions admits no \(f(m)d^{o(m)}|P|^{O(1)}\)-time algorithm under ETH, for any computable \(f\), where \(|P|\) is the discrete profile's encoding length. [Source](https://arxiv.org/html/2412.09005v2)

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when \(d=2\), \(q=0\), and all types have the same mass. The reduction below also uses nonempty approval sets and lists every possible premise.

Membership in \(\mathrm{NP}\) and running time

An outcome \(r\) is a polynomial-size certificate: each coordinate identifies an element of an explicitly listed domain. For each type and issue, scan its statements to determine satisfaction according to the definition in the question. This determines every \(\delta_t(r)\) in polynomial time.

Exact rational comparison also takes polynomial time. Write \(\mu_t=a_t/b_t\), with positive integer denominators, and \(q=u/v\), with \(v>0\). Define

\(B=\prod_{t\in T}b_t,\qquad w_t=a_t(B/b_t),\qquad S(r)=\sum_{t\in T}w_t\delta_t(r).\)

Then the threshold condition is exactly

\(vS(r)\le uB.\)

The bit length of \(B\) is at most the sum of the denominator bit lengths, hence is \(O(L)\). Moreover, the mass normalization gives \(\sum_t w_t=B\), so \(0\le S(r)\le mB\). All integers used in the comparison therefore have \(O(L+\log m)=O(L)\) bits.

Using elementary integer arithmetic and straightforward list scanning, a conservative verification bound is \(O(\tau m+(\tau+1)L^2)\), which is \(O(L^3)\). Thus the problem belongs to \(\mathrm{NP}\). Enumerating all outcomes gives the bound

\(O\!\left(d^m\bigl(\tau m+(\tau+1)L^2\bigr)\right)\subseteq O(d^mL^3).\)

A suitable satisfiability source problem

We reduce from \(\mathrm{3SAT}\), restricted to formulas whose clauses contain exactly three distinct underlying variables, whose clauses are distinct, and whose variables all occur.

For completeness, these restrictions preserve \(\mathrm{NP}\)-hardness. Start with the standard \(\mathrm{NP}\)-complete version having at most three literals per clause. Delete tautological clauses and remove repeated literals. A two-literal clause \((\ell_1\lor\ell_2)\) can be replaced, using a fresh variable \(z\), by

\((\ell_1\lor\ell_2\lor z)\land(\ell_1\lor\ell_2\lor\neg z).\)

If either original literal is true, both new clauses hold; otherwise they require both \(z\) and \(\neg z\).

A unit clause \((\ell)\) can be replaced, using fresh variables \(y,z\), by the four clauses

\((\ell\lor y\lor z),\quad(\ell\lor y\lor\neg z),\quad(\ell\lor\neg y\lor z),\quad(\ell\lor\neg y\lor\neg z).\)

If \(\ell\) is true, all four hold. If \(\ell\) is false, every assignment to \(y,z\) falsifies one of them. Each replacement therefore preserves satisfiability.

Finally, delete duplicate clauses and unused variables. A formula with no remaining clauses can be replaced by one fixed satisfiable three-variable clause. An input containing an empty clause can be replaced by the fixed unsatisfiable conjunction of all eight sign patterns on three variables: every assignment falsifies one of those clauses. These operations take polynomial time.

Consequently, we may start with a formula \(\Phi\) on \(n\) variables and \(s\ge1\) distinct clauses satisfying all the stated restrictions.

Construction of the rational-mass instance

Create one issue \(I_i\) for each variable \(x_i\), with \(D_i=\{0,1\}\). Interpret \(r_i=1\) as \(x_i\) being true.

For each clause \(C\), create one complete type \(t_C\). Order its variable indices as \(a<b<c\), and write its literals as \(\ell_a,\ell_b,\ell_c\). Give this type precisely the edges

\(I_a\to I_c,\qquad I_b\to I_c.\)

For every issue \(I_j\ne I_c\), give the unconditional statement \(((),\{0,1\})\). Thus this type is always satisfied on those issues.

For the child issue \(I_c\), list one statement for each premise \((\alpha,\beta)\in\{0,1\}^2\). Its approval set is

\(A_{\alpha,\beta}=\{0,1\}\)

if \(\ell_a\) is true under \(x_a=\alpha\) or \(\ell_b\) is true under \(x_b=\beta\). Otherwise, let

\(A_{\alpha,\beta}=\{\gamma\in\{0,1\}:\ell_c\text{ is true under }x_c=\gamma\}.\)

In the latter case this is a singleton. Hence all four premises are explicitly present, and every approval set is nonempty.

Assign \(\mu_{t_C}=1/s\) and set \(q=0\).

Verification of the input restrictions

Every type has exactly the required two-edge graph on three distinct issues.

Every variable occurs in a clause. In that clause’s graph, its issue is either a parent or the child, and therefore has an incident edge. The undirected union consequently has no isolated vertices.

The types are distinct. Clauses on different variable triples give different graphs. Clauses on the same triple but with different signs have different unique falsifying assignments. Their conditional satisfaction relations—and hence their explicitly constructed tables—are therefore different.

The masses are positive binary rationals and sum to \(s(1/s)=1\). Thus \(m=n\), \(\tau=s\), and \(d=2\).

Each type has \(m-1\) unconditional statements and four conditional statements. The construction has \(O(\tau m)\) statements and can be encoded in

\(O\!\left(\tau m\log(m+1)+\tau\log(\tau+1)+m\log(m+1)\right)\)

bits. It is therefore a polynomial-time reduction.

Correctness of the reduction

Fix any outcome \(r\), and let its Boolean assignment be \(x_i=r_i\).

For type \(t_C\), every issue other than \(I_c\) is satisfied unconditionally. Its child issue is satisfied exactly when clause \(C\) is true:

  • If either parent literal is true, the matching approval set is \(\{0,1\}\), so the child is satisfied.
  • If both parent literals are false, the matching approval set contains exactly the value making the child literal true.

These two cases exhaust all assignments. Therefore

\(\delta_{t_C}(r)=0\) if \(C\) is true, and \(\delta_{t_C}(r)=1\) if \(C\) is false.

It follows that

\(\displaystyle\sum_{t\in T}\mu_t\delta_t(r)=\frac{\#\{\text{clauses of }\Phi\text{ falsified by }r\}}{s}.\)

This nonnegative quantity is at most \(q=0\) exactly when every clause is satisfied. Hence

\(\displaystyle\Phi\text{ is satisfiable}\quad\Longleftrightarrow\quad\min_r\sum_{t\in T}\mu_t\delta_t(r)\le0.\)

This proves \(\mathrm{NP}\)-hardness. Together with membership in \(\mathrm{NP}\), it proves the claimed classification.

Relation to the cited discrete result

There is also a direct transfer from explicit discrete profiles to rational supports. Group identical ballots among \(N\) listed voters. If type \(t\) occurs \(k_t\) times, assign mass \(k_t/N\) and replace a discrete threshold \(s\) by \(s/N\). For every outcome,

\(\displaystyle\sum_t\frac{k_t}{N}\delta_t(r)=\frac1N\sum_{i=1}^{N}\delta_i(r).\)

This transformation is polynomial in the discrete encoding length and preserves \(m\), \(d\), and the dependency graphs. Accordingly, the [cited paper’s Theorem 2](https://arxiv.org/html/2412.09005v2) also transfers its stated ETH lower bound to the rational-support formulation. The complete classification above follows independently from the explicit reduction.
