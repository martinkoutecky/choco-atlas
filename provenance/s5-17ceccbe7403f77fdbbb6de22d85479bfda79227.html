The continuous mirror question, as graded

Given local electoral cohort types \(t\) with population masses \(\mu_t\), per-resident Republican-minus-Democratic margins \(a_t\), and a target population share \(q\), does there exist a selection \(x_t \in [0,\mu_t]\) such that \(\sum_t x_t \ge q\) and \(\sum_t a_t x_t > 0\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) local electoral cohort types with positive masses \(\mu_t\), each encoded as a binary rational. Here \(\tau\) is the support size, not the number of possible types, and \(\sum_t\mu_t=1\).
There are \(m=2\) parties, Republican and Democratic. Each type has a binary-rational per-resident vote margin \(a_t\in[-1,1]\), meaning Republican votes minus Democratic votes divided by resident population; turnout may vary across types.
The input also contains a binary-rational target population share \(q\in(0,1]\). Let \(L\) be the total input bit length.
A selection takes a real mass \(x_t\in[0,\mu_t]\) from each type, contributing margin \(a_tx_t\). It is feasible when \(\sum_t x_t\ge q\) and \(\sum_t a_tx_t>0\); a tied vote is not a Republican majority. There are no spatial constraints or requirements to partition the selection into districts.

Is deciding whether a feasible selection exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For indivisible population units, a polynomial-time sorting procedure provides sufficient feasibility and infeasibility certificates, but can leave the exact decision unresolved ([source](https://journals.sagepub.com/doi/10.1089/elj.2018.0537)).
No result settling this exact continuous decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total population mass to 1 so that q is a population share.
  • Specified binary-rational margins and threshold, with total input bit length L.
  • Restricted q to (0,1], matching the positive population threshold and the meaning of a population share.
  • Restricted per-resident margins to [-1,1], using nonnegative two-party vote totals with at most one vote per resident; allowed varying turnout.
  • Specified real divisible selections that preserve each cohort's per-resident margin, with strict majority and no spatial or district-partition constraints.
  • Defined m as the fixed number of parties, 2; the varying society size is tau.

Result

The continuous decision problem is polynomial-time solvable. Sort the supported types by decreasing per-resident vote margin, take population exactly \(q\) from the beginning of that order, and test whether its total margin is strictly positive.

The proof below establishes both optimality and polynomial bit complexity.

1. Reducing to population exactly \(q\)

Suppose \(x=(x_t)_{t=1}^{\tau}\) is feasible, and write \(s=\sum_t x_t\). By feasibility, \(s\ge q>0\). Define \(y_t=(q/s)x_t\).

Because \(0<q/s\le 1\), we have \(0\le y_t\le x_t\le\mu_t\). Moreover,

\[ \sum_t y_t=q,\qquad \sum_t a_ty_t=\frac{q}{s}\sum_t a_tx_t>0. \]

Conversely, a selection of population exactly \(q\) and positive margin satisfies the original constraints. Thus:

A feasible selection exists if and only if a selection of population exactly \(q\) has strictly positive margin.

This reduction uses the permission to select arbitrary real masses.

2. Constructing an optimal selection

Relabel the supported types so that \(a_1\ge a_2\ge\cdots\ge a_\tau\), breaking ties arbitrarily. Define \(C_0=0\) and \(C_j=\sum_{i=1}^{j}\mu_i\).

Since \(C_\tau=1\ge q\), there is a smallest index \(k\) with \(C_k\ge q\). Consequently, \(C_{k-1}<q\le C_k\).

Define the greedy selection by

\[ g_i= \begin{cases} \mu_i,&i<k,\\ q-C_{k-1},&i=k,\\ 0,&i>k. \end{cases} \]

The cutoff condition gives \(0<g_k\le\mu_k\), so every coordinate respects its capacity and \(\sum_i g_i=q\). Its margin is

\[ F(q)=\sum_{i<k}a_i\mu_i+a_k(q-C_{k-1}). \]

Claim. Every selection \(y\) satisfying \(0\le y_i\le\mu_i\) and \(\sum_i y_i=q\) has margin at most \(F(q)\).

Proof. Set \(\lambda=a_k\). Since \(y\) and \(g\) have equal population,

\[ \sum_i a_i(y_i-g_i) = \sum_i(a_i-\lambda)(y_i-g_i). \]

Each term on the right is nonpositive:

  • If \(i<k\), then \(a_i-\lambda\ge0\), while \(y_i-g_i=y_i-\mu_i\le0\).
  • If \(i=k\), then \(a_i-\lambda=0\).
  • If \(i>k\), then \(a_i-\lambda\le0\), while \(y_i-g_i=y_i\ge0\).

Therefore \(\sum_i a_i y_i\le\sum_i a_i g_i=F(q)\), proving the claim. Equal margins cause no difficulty because their corresponding coefficients vanish. \(\square\)

Combining this claim with the scaling argument gives the exact criterion:

\[ \boxed{\text{A feasible selection exists if and only if }F(q)>0.} \]

If \(F(q)>0\), the greedy selection is a witness. If \(F(q)\le0\), a feasible selection would scale to population \(q\) with positive margin, contradicting optimality. In particular, \(F(q)=0\) correctly yields no.

3. Exact arithmetic and polynomial running time

It remains to justify that this criterion can be evaluated in polynomial time in the input bit length.

Write the input rationals as integer numerators over positive integer denominators, as in the stated binary encoding. Let \(D\) be the product of all denominators appearing in \(q\), the masses, and the margins. The bit length of \(D\) is at most the sum of those denominator bit lengths plus one, hence is \(O(L)\).

Convert the inputs to this common denominator:

\[ a_i=\frac{A_i}{D},\qquad \mu_i=\frac{M_i}{D},\qquad q=\frac{Q}{D}. \]

Here the integers satisfy \(|A_i|\le D\), \(0<M_i\le D\), \(0<Q\le D\), and \(\sum_i M_i=D\).

The algorithm now uses only integer arithmetic:

  • Sort the types by decreasing \(A_i\).
  • Find the first \(k\) with \(\sum_{i\le k}M_i\ge Q\).
  • Compute

\[ N=\sum_{i<k}A_iM_i+ A_k\left(Q-\sum_{i<k}M_i\right). \]

  • Answer yes exactly when \(N>0\).

Indeed, \(F(q)=N/D^2\), so this integer comparison handles strict positivity exactly.

All these integers have \(O(L)\) bits. For the margin computation, the sum of the absolute values of its terms is at most \(DQ\le D^2\), because \(|A_i|\le D\) and the selected population numerators sum to \(Q\). Constructing the common denominator and converting the inputs also require only polynomially many operations on integers of \(O(L)\) bits.

Sorting requires \(O(\tau\log(\tau+1))\) integer comparisons; the remaining calculations require \(O(\tau)\) integer arithmetic operations. Standard integer arithmetic therefore gives polynomial bit complexity in \(\tau\) and \(L\). Since \(m=2\) is fixed, this is polynomial in \(m,\tau,L\).

4. Relation to indivisible units

The cited study uses whole towns or precincts as indivisible building blocks in its numerical feasibility analysis. [Duchin et al., *Locating the Representational Baseline*](https://journals.sagepub.com/doi/10.1089/elj.2018.0537)

For the continuous problem here, the cutoff type can be taken partially, and a feasible selection can be scaled to population exactly \(q\). These operations make the sorting criterion exact.
