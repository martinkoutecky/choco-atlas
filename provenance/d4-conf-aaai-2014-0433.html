The continuous mirror question, as graded

Given candidates \(C\), a rational distribution \(\mu\) over finitely many complete ranking types \(T\subseteq S_m\), and an order of its positive-mass type blocks, decide whether finitely many added ranking blocks with rational masses \(\eta_j>0\) can be inserted without reordering the original blocks so that the resulting measure \(\nu=\mu+\eta\) is single-crossing and minimally rich, meaning \(\sum_{t:\operatorname{top}(t)=c}\nu_t>0\) for every \(c\); if so, construct the blocks, masses, and a witnessing candidate axis.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a fixed candidate set with \(|C|=m\geq 1\). A society is given by its support: a list of \(\tau\geq 1\) distinct strict complete ranking types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. The input also orders these types as indivisible blocks; let \(L\) be the total input bit length.
An extension inserts finitely many blocks with arbitrary strict complete rankings \(r_j\) over \(C\) and binary-rational masses \(\eta_j>0\), including before or after all original blocks, preserving every original block and its relative order. Zero insertions are allowed; repeated rankings are allowed; there is no bound on added mass or number of blocks.
The resulting finite measure is \(\nu_t=\mu_t+\sum_{j:r_j=t}\eta_j\), taking \(\mu_t=0\) outside the original support; it is not renormalized. Single-crossing is required in the resulting block order: every candidate pair changes relative preference at most once. Minimal richness means \(\sum_{t:\operatorname{top}(t)=c}\nu_t>0\) for every \(c\in C\).
A witnessing candidate axis is a linear order of \(C\) with respect to which all original and added rankings are single-peaked.

Is deciding whether such an extension exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? In the polynomial-time case, can the inserted blocks, their masses, and a witnessing candidate axis also be constructed in polynomial time? State running times in \(m,\tau,L\).

For finite voter lists, deciding whether an order-preserving minimally rich single-crossing extension exists and constructing one takes \(O(nm^2)\) time, where \(n\) is the number of voters ([Elkind, Faliszewski, and Skowron](https://d-nb.info/1203435991/34)).
No result explicitly treating this rational-mass extension problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the input distribution to total mass one; the extended object is an unnormalized finite measure because additions preserve original masses.
  • Interpreted the requested candidate axis as witnessing single-peakedness of every ranking in the extended society; single-crossing uses the block order.
  • Made original blocks indivisible and permitted insertion at either endpoint or between blocks, without changing their masses or relative order.
  • Allowed zero additions and repeated added rankings, with no insertion budget, matching unrestricted voter addition.
  • Used a nonempty candidate set and nonempty support with strict complete rankings, and defined L as total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is in \(\mathrm{P}\). Both a valid extension and a witnessing candidate axis can be constructed in \(O(L+\tau m^2)\) time under the usual word-RAM accounting.

If \(q\) candidates occur at the top of an original ranking, a successful construction needs only \(m-q\) inserted blocks. Every inserted block can have mass \(1\).

For \(m=1\), zero insertions already suffice. The argument below handles arbitrary \(m\).

1. Finite-profile results used

For an ordered list \(V\) of strict complete rankings, call \(V\) extendible if it is an order-preserving sublist of a finite, minimally rich, single-crossing list.

We use two results from [Elkind, Faliszewski, and Skowron, *A characterization of the single-peaked single-crossing domain*](https://d-nb.info/1203435991/34):

  • Theorem 10: Extendibility of an ordered list of \(n\) rankings can be decided, and an extension constructed, in \(O(nm^2)\) time. Its construction inserts one ranking for each candidate absent from the original top positions.
  • Proposition 3: Every minimally rich single-crossing list is single-peaked with respect to the candidate axis given by its first ranking, read from most preferred to least preferred.

The ordering in these statements is the supplied voter ordering; it is preserved by the extension.

2. Erasing masses preserves feasibility

Write the original blocks, in their supplied order, as \((r_1,\mu_1),\ldots,(r_\tau,\mu_\tau)\). Define the finite ranking list \(V=(r_1,\ldots,r_\tau)\), containing exactly one ranking per original block.

Claim. The rational-mass instance admits the requested extension if and only if \(V\) is extendible.

Proof, forward direction. Suppose a rational-mass extension exists. Erase the masses from every original and inserted block, retaining all rankings and their order. This produces a finite list \(W\) containing \(V\) as an order-preserving sublist.

For any distinct candidates \(a,b\), the relative-preference sequence along \(W\) is exactly the sequence along the extended block order. Consequently, it changes at most once, and \(W\) is single-crossing.

Moreover, all block masses are positive. For each candidate \(c\),

\(\sum_{t:\operatorname{top}(t)=c}\nu_t>0\)

holds exactly when at least one block has a ranking whose top candidate is \(c\). Indeed, the sum is the total mass of those blocks: it is zero when there are none and positive when there is at least one. Thus \(W\) is minimally rich, proving that \(V\) is extendible.

Proof, reverse direction. Suppose \(V\) is extendible, and let \(W\) be a finite minimally rich single-crossing extension. Identify the occurrences in \(W\) corresponding to the original rankings.

Replace each such occurrence of \(r_i\) by the original indivisible block \((r_i,\mu_i)\). Replace every other occurrence by an inserted block with the same ranking and mass \(1\).

This preserves every original block and its relative order. It does not split any block. The number of insertions is finite, and \(1\) is an admissible positive binary-rational mass.

The resulting ranking sequence remains \(W\), so single-crossing holds. Every candidate tops a block of positive mass, so minimal richness holds. Proposition 3 applies because \(W\) is finite, minimally rich, and single-crossing; its first ranking therefore supplies a witnessing single-peaked candidate axis. This proves the claim.

In particular, the numerical values of the positive original masses do not affect feasibility. No denominator clearing or replication of voters is required.

3. Construction algorithm and correctness

Apply the following procedure:

  • Form \(V=(r_1,\ldots,r_\tau)\), retaining each original block’s identity.
  • Run the order-preserving algorithm of Theorem 10 on \(V\).
  • If it rejects, report that no extension exists.
  • Otherwise, retain the original masses and assign mass \(1\) to each inserted ranking.
  • Output the first ranking of the constructed extended list as the candidate axis.

All hypotheses of Theorem 10 hold: \(V\) is a finite ordered list of strict complete rankings over the same candidate set \(C\). Its list length is \(\tau\), regardless of the masses.

If the algorithm rejects, Section 2 shows that a rational-mass extension would contradict its rejection. If it accepts, Section 2 proves that the constructed blocks satisfy every requested condition, including the existence of the output axis.

The finite construction inserts one ranking for each candidate without an original top-ranked occurrence. Hence it inserts exactly \(m-q\) blocks and produces at most \(\tau+m-q\) blocks in total. Since \(\tau\geq1\), we have \(q\geq1\), so at most \(m-1\) insertions suffice.

4. Running time and encoding size

Use candidate indices from \(\{1,\ldots,m\}\).

Reading the input costs \(O(L)\). The finite-profile algorithm costs \(O(\tau m^2)\). Writing at most \(m-q\) inserted rankings and the axis costs \(O(m^2)\), which is absorbed by \(O(\tau m^2)\). Each inserted mass has constant encoding length.

Thus both decision and construction take \(O(L+\tau m^2)\) word-RAM time.

Under bit-cost RAM accounting, charging \(O(\log(m+\tau+2))\) for operations on candidate and position indices gives the conservative bound \(O(L+\tau m^2\log(m+\tau+2))\) bit operations. The algorithm performs no arithmetic on the original masses.

With insertion locations encoded as original-list gaps and their order within each gap, the additional witness has bit length \(O(m^2\log(m+1)+m\log(\tau+1))\). An explicit complete extended list, including the original masses, has bit length \(O(L+m^2\log(m+1)+m\log(\tau+1))\).

These bounds are polynomial in the given binary input length and depend on the support size \(\tau\), rather than any population size obtained by expanding the masses.
