A society is given by its support: a nonempty list \(T\) of \(\tau\) distinct complete cost-vector types, each with positive mass \(\mu_t\) encoded as a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Proven conclusion. For every fixed weight family satisfying the stated assumptions, a deterministic polynomial-time multiplicative approximation with any finite computable ratio \(\alpha(m,\tau,k,L)\) would imply \(\mathsf P=\mathsf{NP}\). This holds already for binary costs.

The family assumptions are understood on the admissible committee sizes: when \(\lfloor\lambda k\rfloor=0\), positivity of the first weight and the truncation condition would be incompatible.

1. Zero cost and the known discrete hardness.

For an admissible size \(k\), define
\[ p(k)=\max\{i:w_i^{(k)}>0\}. \]
Then \(1\le p(k)\le\lfloor\lambda k\rfloor\). Nonnegativity and monotonicity imply that precisely the first \(p(k)\) weights are positive.

For binary costs, let \(z_t(W)\) be the number of selected candidates having cost zero for type \(t\). Sorting places these zeros first, so
\[ \sum_{\ell=1}^{k}w_\ell^{(k)}c_\ell^\uparrow(W,t) = \begin{cases} \sum_{\ell=z_t(W)+1}^{p(k)}w_\ell^{(k)},&z_t(W)<p(k),\\ 0,&z_t(W)\ge p(k). \end{cases} \]
Consequently, because every mass is positive,
\[ L_\mu(W)=0 \quad\Longleftrightarrow\quad z_t(W)\ge p(k)\text{ for every }t\in T. \]

We use the following established discrete result: for each fixed nonzero weight family with the specified truncation, deciding whether a binary-cost discrete-client instance admits a zero-cost committee is \(\mathsf{NP}\)-hard. This is the zero-versus-positive reduction underlying [Theorem 21 of Byrka, Skowron, and Sornat](https://arxiv.org/html/1704.02183v3#A5).

Its hypotheses match the present family. In that reduction, committee size grows linearly with the source instance size, and the last positive weight can be found in polynomial time under the present computability assumption. Restricting to admissible sizes therefore preserves hardness. More generally, the finitely many excluded sizes can be solved by enumerating committees in polynomial time, since each such size is bounded by a constant depending only on \(\lambda\).

2. Polynomial reduction to distinct types with rational masses.

Take a discrete instance with \(n\ge1\) explicitly listed clients, the same candidate set, and the prescribed vector \(w^{(k)}\). Partition its clients according to equality of their complete cost vectors.

Let \(T\) contain one representative of each class, and let \(a_t\) be the number of clients in class \(t\). Set
\[ \mu_t=\frac{a_t}{n}. \]
The resulting support satisfies every requirement:

  • Its complete cost vectors are distinct, and \(1\le\tau\le n\).
  • Each mass is a positive binary rational.
  • The masses sum to one.
  • Each mass requires \(O(\log(n+1))\) bits.

Write \(D(W)\) for the original discrete objective. For every committee \(W\), grouping identical summands gives the exact identity
\[ \begin{aligned} D(W) &=\sum_{t\in T}a_t\sum_{\ell=1}^{k} w_\ell^{(k)}c_\ell^\uparrow(W,t)\\ &=nL_\mu(W). \end{aligned} \]
Thus the feasible committees are unchanged, and
\[ \operatorname{OPT}_{D}=0 \quad\Longleftrightarrow\quad \operatorname{OPT}_{\mu}=0. \]

Let \(L_D\) denote the discrete input length, including the weight vector. Grouping the binary rows by lexicographic sorting takes \(O(nm\log(n+1))\) elementary comparisons. The mass instance has length
\[ L=O\!\left(L_D+n\log(n+1)\right), \]
which is polynomial in \(L_D\). This is a polynomial reduction using the actual support size \(\tau\); it never enumerates possible types.

Combining this reduction with the discrete result proves that zero-optimum recognition for the rational-mass problem is \(\mathsf{NP}\)-hard.

3. Every finite multiplicative guarantee recognizes zero optimum.

Suppose an algorithm returns a feasible committee \(W_A\) in time polynomial in \(m,\tau,k,L\), with
\[ L_\mu(W_A)\le \alpha(m,\tau,k,L)\operatorname{OPT}_{\mu}. \]

If \(\operatorname{OPT}_{\mu}=0\), finiteness of the ratio and nonnegativity force \(L_\mu(W_A)=0\).

If \(\operatorname{OPT}_{\mu}>0\), every feasible committee has positive cost, so \(L_\mu(W_A)>0\).

Therefore, running the algorithm and testing its output for zero cost decides the hard recognition problem. No evaluation of \(\alpha\), and no bound on its growth, is needed.

For binary costs, this test takes \(O(k+\tau k)\) elementary operations after reading the input: find \(p(k)\), then count the selected zero-cost candidates for each type. Hence the resulting decision algorithm is polynomial, implying \(\mathsf P=\mathsf{NP}\).

4. Running times for exact evaluation and enumeration.

For arbitrary rational costs, one committee can be evaluated exactly in
\[ O\!\left(\tau k\log(k+1)\operatorname{poly}(L)\right) \]
bit operations, by sorting its selected costs separately for each type and performing rational arithmetic. Arithmetic lengths remain polynomial: the product of all input denominators has \(O(L)\) bits and is a common denominator for all objective terms.

Enumerating all committees consequently gives an exact algorithm in
\[ O\!\left( \binom{m}{k}\tau k\log(k+1)\operatorname{poly}(L) \right) \]
bit operations. This is polynomial for each fixed \(k\); the hardness concerns the uniform problem with unbounded input committee size.
