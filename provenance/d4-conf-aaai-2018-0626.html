The continuous mirror question, as graded

Given a finite item set \(X\), candidate set \(Z\), recommendation limit \(k\), nonnegative rational item affinities \(W_{ij}\), and supported user types \(T\) with rational masses \(\mu_t\) summing to \(1\), each type has observed items \(I_t\), nonnegative ratings \(r_i(t)\), and nonnegative rational pair affinities \(A(t,t')\). For \(f(x)=\min\{x,1\}\), define \(F_\mu(S)=\sum_{t\in T}\mu_t\bigl(\sum_{t'\in T}\mu_{t'}A(t,t')\bigr)\sum_{i\in I_t}r_i(t)f(\sum_{j\in S}W_{ij})\). Compute \(\hat S\subseteq Z\), \(|\hat S|\le k\), such that \(F_\mu(\hat S)\ge\bigl(1-(1-1/k)^k\bigr)\max_{S\subseteq Z,\ |S|\le k}F_\mu(S)\).

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a finite item set, \(m=|X|\). A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type has observed items \(I_t\subseteq X\) and nonnegative binary rational ratings \(r_i(t)\). Set \(I=\bigcup_{t\in T}I_t\) and \(Z=X\setminus I\), and assume an integer recommendation limit \(1\le k\le |Z|\).
Input affinities \(W_{ij}\), for \(i,j\in X\), and \(A(t,t')\), for \(t,t'\in T\), are nonnegative binary rationals, with no symmetry or transitivity requirements. Types describe an atomless population: distinct individuals of the same type interact, so \(A(t,t)\) is included.
With identity user saturation and item saturation \(f(x)=\min\{x,1\}\), define \(F_\mu(S)=\sum_{t\in T}\mu_t\bigl(\sum_{t'\in T}\mu_{t'}A(t,t')\bigr)\sum_{i\in I_t}r_i(t)f\bigl(\sum_{j\in S}W_{ij}\bigr)\) for \(S\subseteq Z\). Let \(L\) be the total binary input length.

Is there an algorithm, polynomial in \(m,\tau,k,L\), that always returns \(\hat S\subseteq Z\), \(|\hat S|\le k\), satisfying \(F_\mu(\hat S)\ge\bigl(1-(1-1/k)^k\bigr)\max_{S\subseteq Z,\ |S|\le k}F_\mu(S)\)?

For finite user lists, the corresponding group recommendation objective has the greedy approximation guarantee \(1-(1-1/k)^k\). [Source](https://cdn.aaai.org/ojs/11650/11650-13-15178-1-2-20201228.pdf)
The same bound is established for arbitrary normalized nondecreasing submodular set functions under a cardinality constraint. [Original result](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf) No separate treatment of the exact distributional formulation above was located.

Modeling choices made when packaging the task

  • The candidate domain was unspecified; set the candidate set to the complement of the union of observed items, as in the discrete recommendation definition.
  • The recommendation limit lacked a domain; require an integer between one and the candidate-set size, ensuring the ratio is defined and the recommendation procedure is feasible.
  • Ratings lacked a finite encoding; require nonnegative binary rational ratings, retaining the graded question's nonnegative domain.
  • Interpret masses as an atomless population. Excluding an individual's interaction with itself removes zero mass, while interactions between distinct individuals of the same type remain; consequently include diagonal type affinities.
  • Define m as the item-set size and L as the total binary input length.
  • The displayed objective implicitly fixes user saturation to the identity; make this explicit.

Conclusion

Yes. Exact greedy selection runs in time polynomial in \(m,\tau,k,L\) and achieves the requested factor
\(1-(1-1/k)^k\).

The proof below establishes both the approximation guarantee and the bit complexity directly for the given distributional formulation.

1. Aggregate the type contributions

For each \(t\in T\), define
\(b_t=\sum_{t'\in T}\mu_{t'}A(t,t')\).
For each \(i\in I\), define
\(c_i=\sum_{t:\,i\in I_t}\mu_t b_t r_i(t)\).

All these coefficients are nonnegative rational numbers. Rearranging the finite sums in the given objective yields
\[ \]
\(F_\mu(S)=\sum_{i\in I}c_i\min\{\sum_{j\in S}W_{ij},1\}\)
for every \(S\subseteq Z\).

The sum defining \(b_t\) includes \(t'=t\), exactly as required by the atomless-population interpretation. Thus this rearrangement preserves the stated objective, including all diagonal interactions.

Write \(F=F_\mu\) and \(h_i(S)=\sum_{j\in S}W_{ij}\).

2. Normalization, monotonicity, and submodularity

Normalization follows from \(h_i(\varnothing)=0\):
\(F(\varnothing)=0\).

If \(S\subseteq R\), nonnegativity of the affinities gives \(h_i(S)\le h_i(R)\). Since \(x\mapsto\min\{x,1\}\) is nondecreasing and \(c_i\ge0\), we obtain \(F(S)\le F(R)\).

For \(e\in Z\setminus S\), define its marginal gain by
\(\Delta(e\mid S)=F(S\cup\{e\})-F(S)\).
For any \(x,w\ge0\),
\(\min\{x+w,1\}-\min\{x,1\}=\min\{w,\max\{1-x,0\}\}\):
when \(x\ge1\), both sides are zero; when \(x<1\), both sides equal \(\min\{w,1-x\}\).
Consequently,
\[ \]
\(\Delta(e\mid S)=\sum_{i\in I}c_i\min\{W_{ie},\max\{1-h_i(S),0\}\}\).

If \(S\subseteq R\subseteq Z\) and \(e\notin R\), then \(h_i(S)\le h_i(R)\). Hence each summand in this formula is at least as large for \(S\) as for \(R\), giving
\(\Delta(e\mid S)\ge\Delta(e\mid R)\).

This is the diminishing-returns definition of submodularity. Therefore \(F\) is normalized, nondecreasing, and submodular on the finite ground set \(Z\). No symmetry or transitivity assumption was used.

3. Greedy algorithm and approximation guarantee

Start with \(S_0=\varnothing\). For each \(\ell=0,\ldots,k-1\), choose an item \(e_{\ell+1}\in Z\setminus S_\ell\) maximizing \(\Delta(e\mid S_\ell)\), using exact rational comparisons, and set
\(S_{\ell+1}=S_\ell\cup\{e_{\ell+1}\}\).
Break ties arbitrarily and return \(\hat S=S_k\).

Because \(k\le|Z|\), every iteration has an available item, and \(|\hat S|=k\).

Let \(O\subseteq Z\), \(|O|\le k\), maximize \(F\), and write \(\mathrm{OPT}=F(O)\). Such an \(O\) exists because the feasible family is finite.

Fix \(\ell<k\). Monotonicity gives
\(\mathrm{OPT}-F(S_\ell)\le F(S_\ell\cup O)-F(S_\ell)\).

Enumerate \(O\setminus S_\ell\) as \(o_1,\ldots,o_q\). Telescoping the gain from adding these items, then applying diminishing returns to each addition, gives
\[ \]
\(F(S_\ell\cup O)-F(S_\ell) =\sum_{a=1}^{q}\Delta(o_a\mid S_\ell\cup\{o_1,\ldots,o_{a-1}\}) \le\sum_{a=1}^{q}\Delta(o_a\mid S_\ell)\).

Every marginal in the last sum is at most the greedy marginal. Since \(q\le k\) and all marginals are nonnegative,
\[ \]
\(\mathrm{OPT}-F(S_\ell) \le k\bigl(F(S_{\ell+1})-F(S_\ell)\bigr)\).

Define \(R_\ell=\mathrm{OPT}-F(S_\ell)\). Each \(S_\ell\) is feasible, so \(R_\ell\ge0\). Rearranging the preceding inequality gives
\(R_{\ell+1}\le(1-1/k)R_\ell\).
Since \(R_0=\mathrm{OPT}\), applying this recurrence over the \(k\) iterations yields
\(R_k\le(1-1/k)^k\mathrm{OPT}\).
Therefore
\[ \]
\(F_\mu(\hat S)\ge\bigl(1-(1-1/k)^k\bigr)\mathrm{OPT}\).

This argument also covers \(\mathrm{OPT}=0\) and \(k=1\); it never divides by the optimum.

The recurrence is the classical cardinality-constrained greedy argument of [Nemhauser, Wolsey, and Fisher](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf). Here its hypotheses and its conclusion have been proved explicitly for the supplied objective.

4. Polynomial bit complexity

It remains to justify exact greedy comparisons in the binary-input model.

Represent each input rational as an integer numerator divided by a positive integer denominator. Let \(D\) be the product of all input denominators. The binary length of \(D\) is at most \(O(L)\), because the sum of their binary lengths is at most \(L\). Each input rational can therefore be represented with denominator \(D\) and an integer numerator of \(O(L)\) bits.

Using these representations:

  • Each \(b_t\) has denominator \(D^2\).
  • Each \(c_i\) has denominator \(D^4\).
  • Each load \(h_i(S)\) has denominator \(D\).
  • Each marginal \(\Delta(e\mid S)\) has denominator \(D^5\).

For the last assertion, the capped increment
\(\min\{W_{ie},\max\{1-h_i(S),0\}\}\)
has denominator \(D\), and multiplying by \(c_i\) gives denominator \(D^5\).

All numerator lengths remain polynomially bounded. Indeed, each input value is at most \(2^{O(L)}\); a coefficient \(c_i\) is a sum of at most \(\tau^2\) products of four input values; a load sums at most \(k\) affinities; and a marginal sums at most \(m\) coefficient-weighted increments. Thus the integers involved have
\(O(L+\log m+\log\tau+\log k)\) bits, with absolute constant factors. Exact comparison of marginal gains reduces to comparison of their integer numerators over the common denominator \(D^5\).

Computing all \(b_t\) requires \(O(\tau^2)\) arithmetic operations, and computing all \(c_i\) requires \(O(\tau m)\). Maintain the loads \(h_i(S_\ell)\). Each greedy iteration evaluates at most \(m\) candidates, each using at most \(m\) summands, and updates at most \(m\) loads. The greedy phase therefore uses \(O(km^2)\) arithmetic operations.

Integer addition, multiplication, comparison, and exact division on polynomial-length integers take polynomial time. Consequently the entire algorithm runs in time polynomial in \(m,\tau,k,L\). It operates directly on the support list and never expands rational masses into individual users.
