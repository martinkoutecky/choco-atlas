The continuous mirror question, as graded

For two types \(i\in\{1,2\}\), rational masses \(\mu_i\) with \(\sum_i\mu_i=1\), finite good profiles \(G\), rational per-capita supplies \(s_g\), and additive values \(v_i(g)\), define \(\beta_i(s)\) as the supremum \(\beta\) for which finite-support masses \(\lambda_B\ge0\) over integral bundles \(B\in\mathbb{Z}_{\ge0}^{G}\) satisfy \(\sum_B\lambda_B=1\), \(\sum_B B_g\lambda_B\le s_g\), and \(v_i(B)\ge\beta\) whenever \(\lambda_B>0\). Decide whether finite-support masses \(\lambda_{i,B}\ge0\) exist with \(\sum_B\lambda_{i,B}=\mu_i\), \(\sum_{i,B}B_g\lambda_{i,B}\le s_g\), and \(\lambda_{i,B}>0\Rightarrow v_i(B)\ge\frac{4}{5}\beta_i(s)\) for each type.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here \(\tau=2\), the additive valuation vectors are distinct, and \(\mu_1+\mu_2=1\). Support size means the number of listed types, not the number of possible types.
Let \(G\) be a finite set of \(m\) good profiles, with nonnegative binary-rational supplies \(s_g\) and values \(v_i(g)\). A bundle is \(B\in\mathbb Z_{\ge0}^{G}\), allowing repeated copies of each profile, with additive value \(v_i(B)\). Let \(L\) be the total input bit length.
For each type define \(\beta_i(s)=\sup\{\beta\ge0:\exists\text{ finitely supported }(\lambda_B)_{B\in\mathbb Z_{\ge0}^{G}},\ \lambda_B\ge0,\ \sum_B\lambda_B=1,\ \sum_B B_g\lambda_B\le s_g\ \forall g,\ \lambda_B>0\Rightarrow v_i(B)\ge\beta\}\).
A \(\frac45\)-allocation consists of finitely supported nonnegative real masses \(\lambda_{i,B}\) satisfying \(\sum_B\lambda_{i,B}=\mu_i\), \(\sum_{i,B}B_g\lambda_{i,B}\le s_g\) for every profile, and \(\lambda_{i,B}>0\Rightarrow v_i(B)\ge\frac45\beta_i(s)\). Unused supply is allowed; the benchmarks are defined from the input, not supplied separately.
Is deciding whether a \(\frac45\)-allocation exists solvable in time polynomial in \(m,\tau,L\), or is achieving this fixed approximation threshold \(\mathrm{NP}\)-hard?
Discrete two-type additive-goods instances always admit \(\frac45\)-MMS allocations; the constructive algorithms are stated to run in polynomial time apart from MMS computations ([Shahkar–Garg](https://www.ijcai.org/proceedings/2025/0452.pdf)).

Result

The stated existence decision problem is polynomial-time solvable: every valid instance admits a \(\frac45\)-allocation.

The substantive point is that rational benchmark distributions can be replicated into a finite discrete instance whose MMS values equal the mass-model benchmarks. The discrete two-type existence theorem then applies exactly.

1. Each benchmark is attained

Fix a type \(i\), and write \(V_i=\sum_{g\in G}s_gv_i(g)\).

For any feasible finitely supported probability distribution \(p=(p_B)\), define its guaranteed value by
\(q_i(p)=\min\{v_i(B):p_B>0\}\).
By additivity, nonnegative values, and the supply constraints,

\[ q_i(p) \le \sum_Bp_Bv_i(B) =\sum_{g\in G}v_i(g)\sum_BB_gp_B \le V_i. \]

Because all values are rational, choose a positive integer \(D_i\) such that \(D_iv_i(g)\) is an integer for every profile \(g\). Every integer bundle then has value in \(\frac1{D_i}\mathbb Z_{\ge0}\). Consequently, every feasible guaranteed value belongs to the finite set
\(\frac1{D_i}\mathbb Z_{\ge0}\cap[0,V_i]\).

The set of feasible guaranteed values is nonempty: the distribution concentrated on the empty bundle guarantees zero. It therefore has a maximum, attained by a finitely supported distribution. A threshold is feasible precisely when some such distribution guarantees at least that threshold. Thus this maximum equals \(\beta_i(s)\).

In particular, \(\beta_i(s)\) is finite, rational, and attained.

2. Each benchmark has a rational witnessing distribution

Take an attaining distribution for type \(i\), and let \(K_i\) be its finite support. Consider the polytope of weights \(x=(x_B)_{B\in K_i}\) satisfying

\[ x_B\ge0,\qquad \sum_{B\in K_i}x_B=1,\qquad \sum_{B\in K_i}B_gx_B\le s_g \quad(g\in G). \]

This polytope is nonempty, since it contains the original distribution. It is bounded, since it lies in the probability simplex. Its defining coefficients and right-hand sides are rational.

It therefore has a rational vertex. Explicitly, at a vertex, the active constraint normals span the full coordinate space: otherwise a nonzero direction orthogonal to those normals would allow sufficiently small perturbations in both directions while preserving feasibility, contradicting extremality. Selecting linearly independent active constraints gives a nonsingular rational linear system, whose unique solution is rational.

Choose such a vertex and denote its weights by \(p_{i,B}\). Every bundle in \(K_i\) already satisfies \(v_i(B)\ge\beta_i(s)\). Hence these rational weights still witness the benchmark:

\[ \sum_{B\in K_i}p_{i,B}=1,\qquad \sum_{B\in K_i}B_gp_{i,B}\le s_g,\qquad p_{i,B}>0\Longrightarrow v_i(B)\ge\beta_i(s). \]

Apply this argument independently to both types.

3. A finite replication preserves both benchmarks exactly

Choose a positive integer \(N\) clearing the denominators of all supplies, both type masses, and all weights in the two rational witnessing distributions. Thus
\(Ns_g\), \(N\mu_i\), and \(Np_{i,B}\) are nonnegative integers.

Construct a discrete instance with:

  • \(N\) agents, of whom \(N\mu_i\) have valuation \(v_i\);
  • exactly \(Ns_g\) individually labeled copies of profile \(g\).

Both agent types have positive counts because \(\mu_i>0\). Each item copy has the original profile’s value.

Let \(M_i^{(N)}\) denote the ordinary MMS value for valuation \(v_i\), using partitions of this item set into \(N\) bundles. We prove
\(M_i^{(N)}=\beta_i(s)\) for each type.

Lower bound. For every \(B\in K_i\), take \(Np_{i,B}\) copies of bundle \(B\). Their total number is \(N\), and their total demand for each profile is

\[ \sum_{B\in K_i}Np_{i,B}B_g\le Ns_g. \]

These bundles can therefore be formed from disjoint labeled items. Every bundle has value at least \(\beta_i(s)\). Distribute any remaining items among the bundles; nonnegative values ensure that no bundle’s value decreases. This produces a partition into \(N\) bundles and proves \(M_i^{(N)}\ge\beta_i(s)\).

These are separate benchmark partitions for the two types, as required by the MMS definition.

Upper bound. Conversely, any partition into \(N\) bundles defines a mass-model distribution by choosing a partition bundle uniformly and recording its profile multiplicities. Its expected consumption of profile \(g\) is exactly \(Ns_g/N=s_g\). It is therefore feasible in the definition of \(\beta_i(s)\), and guarantees the partition’s minimum value. That minimum cannot exceed \(\beta_i(s)\). Maximizing over partitions proves \(M_i^{(N)}\le\beta_i(s)\).

Thus both equalities hold simultaneously for this \(N\).

4. Transfer the discrete allocation back to masses

The discrete theorem needed here states that every finite indivisible-goods instance with nonnegative additive valuations and two agent types admits an allocation giving each agent at least \(\frac45\) of its ordinary MMS. This is [Shahkar–Garg, Corollary 2](https://www.ijcai.org/proceedings/2025/0452.pdf).

Our replicated instance satisfies these hypotheses: its agent and item sets are finite, its valuations are nonnegative and additive, and it has at most two valuation types. If the valuations coincide on the available items, the one-type case follows directly by assigning an MMS partition to the agents.

Apply the theorem. For each discrete agent \(a\), let \(C_a\in\mathbb Z_{\ge0}^{G}\) record its allocated profile counts. Every type-\(i\) agent receives

\[ v_i(C_a)\ge\frac45M_i^{(N)} =\frac45\beta_i(s). \]

Define mass-allocation weights by
\(\lambda_{i,B}=N^{-1}|\{a:a\text{ has type }i,\ C_a=B\}|\).
Their support is finite, and

\[ \sum_B\lambda_{i,B}=\frac{N\mu_i}{N}=\mu_i. \]

For every profile \(g\), discrete feasibility gives

\[ \sum_{i,B}B_g\lambda_{i,B} =\frac1N\sum_a(C_a)_g \le\frac{Ns_g}{N}=s_g. \]

Finally, positive \(\lambda_{i,B}\) means that some type-\(i\) agent received bundle \(B\), so \(v_i(B)\ge\frac45\beta_i(s)\). These are exactly the required allocation conditions.

5. Complexity conclusion and scope

The existence decision algorithm returns YES on every valid input. Under the stated input promise this takes constant time; checking input validity, if required, takes polynomial time in the input bit length.

This proof does not establish a polynomial-time algorithm for outputting an allocation in the compressed input representation. The replication parameter and the expanded instance size need not be polynomially bounded. That limitation concerns construction, not the existence decision problem, which is completely settled.
