The continuous mirror question, as graded

Given \(l>0\) and a finite-support rational society \(\mu\) over types \(t=(x,p)\in[0,l]\times\{0,1\}\), set \(z_t=x\) when \(p=0\), \(z_t=l-x\) when \(p=1\), and \(a=\sum_{t:z_t<l/2}\mu_t\). Let \(F(\mu)=0\) if \(a\le 1/2\), and \(F(\mu)=l\) otherwise, extending this rule to reported finite-support real-mass distributions so deviations are defined. Prove or refute that \(F\) is group-strategyproof against every positive-mass coalition whose members may reassign their reports and that \(U(F(\mu);\mu)\ge \frac13\max_{y\in[0,l]}U(y;\mu)\) for every rational input; give the exact algorithm and its bit complexity.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types \(t=(x,p)\in[0,l]\times\{0,1\}\) with positive binary-rational masses \(\mu_t\), summing to \(1\); locations are binary rational. Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. There is one facility, so \(m=1\).
For \(y\in[0,l]\), define \(u((x,0),y)=|x-y|\), \(u((x,1),y)=l-|x-y|\), and \(U(y;\mu)=\sum_t\mu_tu(t,y)\). Both location and preference may be misreported.
Set \(z_{(x,0)}=x\), \(z_{(x,1)}=l-x\), and \(a=\sum_{t:z_t<l/2}\mu_t\). Define \(F(\mu)=0\) when \(a\le1/2\), and \(F(\mu)=l\) otherwise; use the same rule for finite-support distributions with real locations and real masses.
A coalition is a submass \(0\le\gamma_t\le\mu_t\) with \(\sum_t\gamma_t>0\). It may split its mass among arbitrary finitely many reports in \([0,l]\times\{0,1\}\), preserving total mass; the resulting distribution is \(\mu'=\mu-\gamma+\nu\). Result

Both properties hold: \(F\) is group strategyproof in the stated mass-splitting model, and its worst-case social-utility approximation ratio is exactly \(1/3\).

For \(m=1\), an exact implementation uses \(O(\tau)\) arithmetic operations and, with schoolbook integer arithmetic, \(O(L^2)\) bit operations and \(O(L)\) working space.

The finite-agent counterpart is Mechanism 2 in [Zou and Li, Theorems 3 and 6](https://www.ifaamas.org/Proceedings/aamas2015/aamas/p615.pdf). The proofs below establish the claims directly for the stated model, including deviations with real masses and real report locations.

1. Endpoint preferences

For every type \(t=(x,p)\), the definition of \(z_t\) gives

\(\displaystyle u(t,0)=z_t,\qquad u(t,l)=l-z_t.\)

Consequently,

\(\displaystyle u(t,l)>u(t,0)\iff z_t<l/2,\)

\(\displaystyle u(t,0)>u(t,l)\iff z_t>l/2.\)

Types with \(z_t=l/2\) are indifferent between the endpoints.

Let \(A\) be the set of all report types satisfying \(z_t<l/2\). For any finite-support mass distribution \(\rho\), write \(\rho(A)\) for its total mass on \(A\). Thus \(a=\mu(A)\).

2. Group strategyproofness under mass splitting

Consider any admissible coalition \(\gamma\) and report distribution \(\nu\). Set

\(\displaystyle c=\sum_t\gamma_t>0.\)

Mass preservation means \(\nu\) has total mass \(c\). For the resulting society \(\mu'=\mu-\gamma+\nu\),

\(\displaystyle a'=\mu'(A)=a-\gamma(A)+\nu(A),\qquad 0\le \nu(A)\le c.\)

If \(F(\mu')=F(\mu)\), no coalition member strictly improves. It therefore suffices to exclude a change of endpoint that strictly benefits every participating type.

Case \(F(\mu)=0\). Here \(a\le 1/2\). If every participating type strictly benefited from switching to \(l\), Section 1 would imply that every such type lies in \(A\). Hence \(\gamma(A)=c\), and

\(\displaystyle a'=a-c+\nu(A)\le a\le 1/2.\)

The rule therefore still outputs \(0\), a contradiction.

Case \(F(\mu)=l\). Here \(a>1/2\). If every participating type strictly benefited from switching to \(0\), each would satisfy \(z_t>l/2\). Thus \(\gamma(A)=0\), and

\(\displaystyle a'=a+\nu(A)\ge a>1/2.\)

The rule therefore still outputs \(l\), again a contradiction.

These cases exhaust all possible changes of output. The argument uses only nonnegativity and mass preservation, so it applies to arbitrary finite splitting among real reports with real masses. This proves group strategyproofness under the definition in the question.

3. A direct weighted utility bound

We first prove an endpoint estimate valid for either preference.

Fix an endpoint \(e\in\{0,l\}\), a location \(y\in[0,l]\), and a type \(t\). Define

\(\displaystyle c_t=u(t,e),\qquad d=|y-e|.\)

Then

\[\displaystyle u(t,y)\le c_t+d,\qquad u(t,y)\le 2l-c_t-d. \tag{1}\]

To verify both inequalities, first take \(e=0\), so \(d=y\).

For \(p=0\), we have \(c_t=x\). The first inequality follows from \(|x-y|\le x+y\). For the second,

\(\displaystyle |x-y|+x+y=2\max\{x,y\}\le 2l.\)

For \(p=1\), we have \(c_t=l-x\). Using respectively \(|x-y|\ge x-y\) and \(|x-y|\ge y-x\) gives

\(\displaystyle l-|x-y|\le l-x+y=c_t+d,\)

\(\displaystyle l-|x-y|\le l+x-y=2l-c_t-d.\)

For \(e=l\), reflect both \(x\) and \(y\) about \(l/2\). This preserves their distance and either preference’s utility, and converts the chosen endpoint to \(0\). Thus the same inequalities hold.

Now take \(e=F(\mu)\), and put

\(\displaystyle S=U(e;\mu),\qquad H=\{t:c_t\ge l/2\},\qquad b=\sum_{t\in H}\mu_t.\)

The mechanism guarantees \(b\ge 1/2\):

  • If \(e=0\), then \(H=\{t:z_t\ge l/2\}\), so \(b=1-a\ge 1/2\).
  • If \(e=l\), then \(H=\{t:z_t\le l/2\}\), so \(b\ge a>1/2\).

Since all utilities are nonnegative,

\[\displaystyle S\ge b\,l/2. \tag{2}\]

For types outside \(H\), the first inequality in (1) gives

\(\displaystyle u(t,y)\le c_t+d.\)

For types in \(H\), the second inequality in (1), together with \(2c_t\ge l\), gives

\(\displaystyle u(t,y)\le 2l-c_t-d\le c_t+l-d.\)

Multiplying these inequalities by the masses and summing yields

\(\displaystyle U(y;\mu)\le S+(1-b)d+b(l-d)=S+bl+(1-2b)d.\)

Because \(b\ge 1/2\) and \(d\ge 0\), the last term is nonpositive. Equation (2) gives \(bl\le 2S\). Therefore, for every \(y\in[0,l]\),

\(\displaystyle U(y;\mu)\le S+bl\le 3S.\)

The function \(U\) is continuous, being a finite sum of continuous utilities, so it attains its maximum on \([0,l]\). Consequently,

\(\displaystyle U(F(\mu);\mu)\ge \frac13\max_{y\in[0,l]}U(y;\mu).\)

This proof also applies to finite-support societies with real locations and masses.

4. The ratio is attained by a rational society

Give each of the two types \((0,0)\) and \((l/2,0)\) mass \(1/2\). These are admissible rational data whenever \(l\) is rational.

Only the first type belongs to \(A\), so \(a=1/2\) and \(F(\mu)=0\). The resulting utility is

\(\displaystyle U(0;\mu)=\frac12\cdot 0+\frac12\cdot\frac l2=\frac l4.\)

For an arbitrary facility location,

\(\displaystyle U(y;\mu)=\frac12y+\frac12|l/2-y|.\)

This equals \(l/4\) when \(y\le l/2\), and equals \(y-l/4\) when \(y\ge l/2\). Its maximum is therefore \(3l/4\), attained at \(y=l\). Hence

\(\displaystyle \frac{U(F(\mu);\mu)}{\max_y U(y;\mu)}=\frac13.\)

Thus \(1/3\) is the exact worst-case ratio of this rule.

5. Exact algorithm and bit complexity

Use the standard binary encoding of rationals by a binary numerator and positive binary denominator. Write

\(\displaystyle l=r/s,\qquad x_t=c_t/d_t,\qquad \mu_t=h_t/k_t.\)

Here the symbols \(c_t\) are location numerators, independently of their use in Section 3.

Scan the support once. Membership in \(A\) can be determined without computing transformed locations:

\(\displaystyle t\in A\iff \begin{cases} 2c_ts<rd_t,&p_t=0,\\ 2c_ts>rd_t,&p_t=1. \end{cases}\)

Equality is excluded in both cases, as required by the strict midpoint test.

Maintain an unreduced rational accumulator \(N/D\), initially \(0/1\). For each type belonging to \(A\), update simultaneously

\(\displaystyle (N,D)\leftarrow (Nk_t+h_tD,\;Dk_t).\)

This preserves the invariant that \(N/D\) is the total mass of the selected types processed so far. At termination, output \(0\) if \(2N\le D\), and output \(l\) otherwise. The invariant proves that this algorithm computes \(F\) exactly, including the tie case.

There are \(O(\tau)\) arithmetic operations. Their bit complexity is polynomial despite the unreduced fractions:

Location comparisons. Let \(b_l\) be the encoding length of \(l\), and \(b_{x_t}\) that of \(x_t\). Schoolbook multiplication and integer comparison cost \(O(b_l b_{x_t})\) per type, including linear overhead. Summing over the support gives

\(\displaystyle O\!\left(b_l\sum_t b_{x_t}\right)=O(L^2).\)

Mass accumulation. The denominator is a product of processed mass denominators, so its bit length is \(O(L)\). Every partial selected mass lies in \([0,1]\); hence \(0\le N\le D\), and the numerator also has \(O(L)\) bits.

More precisely, if the selected mass encodings have lengths \(b_1,\ldots,b_q\), an update costs

\(\displaystyle O\!\left(\left(1+\sum_{j<i}b_j\right)b_i\right).\)

Summing these costs gives \(O(L^2)\), since \(\sum_i b_i\le L\). The final comparison costs \(O(L)\).

Thus, for \(m=1\), the specified exact algorithm takes \(O(\tau)\) arithmetic operations, \(O(L^2)\) bit operations, and \(O(L)\) working space. It operates on support masses directly; expanding rational masses into individual agents is unnecessary.
