The continuous mirror question, as graded

Given finite type sets \(T_U,T_W\), rational masses \(\mu_t\), allowed type pairs, strict rankings over opposite-side types, and a fixed link template \(H\), what is the maximum total matching mass among feasible type-level matchings for which there is no positive-measure set of mutually improving agent pairs at distance at most two in the graph of links and matching edges?

Packaged proof task (what the prover saw — nothing else)

Let \(T_U,T_W\) be disjoint, nonempty finite type sets, with \(\tau=|T_U|+|T_W|\) and \(m=\max\{|T_U|,|T_W|\}\). A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational; \(\tau\) counts supported types, not possible types. Normalize \(\sum_t\mu_t=1\).
The input also gives acceptable pairs \(E\subseteq T_U\times T_W\), strict rankings \(\succ_t\) of acceptable partner types, and a symmetric binary link template \(H\) on all supported types. Every acceptable partner is preferred to being unmatched, denoted \(\bot\); agents of the same partner type are indifferent. The template is part of the input and remains fixed: \(H_{ts}=1\) links every distinct pair of agents of types \(t,s\), including within a type when \(H_{tt}=1\).
A feasible type-level matching consists of real masses \(x_{uw}\geq0\), zero outside \(E\), satisfying \(\sum_wx_{uw}\leq\mu_u\) and \(\sum_ux_{uw}\leq\mu_w\). Each matched agent has one partner; masses may split among partner types. Write \(q_{uw}=q_{wu}=x_{uw}\) and \(q_{t\bot}=\mu_t-\sum_sq_{ts}\).
For \((u,w)\in E\), agents in partner-status classes \((u,a)\) and \((w,b)\) mutually improve exactly when \(w\succ_u a\) and \(u\succ_w b\). Such a pair is accessible exactly when \(H_{uw}=1\), or \(H_{ur}H_{rw}=1\) for some supported type \(r\), or \(a\neq\bot\) and \(H_{aw}=1\), or \(b\neq\bot\) and \(H_{ub}=1\).
Call \(x\) locally stable if no accessible, mutually improving status pair has \(q_{ua}q_{wb}>0\). This means blocking pairs have zero product measure in the graph of fixed links and individual matching edges. Maximize total matching mass \(\sum_{(u,w)\in E}x_{uw}\).

For each fixed \(\varepsilon\in(0,1/2)\), does this maximization problem admit a polynomial-time \((3/2-\varepsilon)\)-approximation, or is achieving that ratio hard under the Unique Games Conjecture? State running times in \(m,\tau,L\), and \(\varepsilon\), where \(L\) is the total input bit length.

For finite agents with strict preferences, a \((3/2-\varepsilon)\)-approximation is impossible under the Unique Games Conjecture for every fixed \(\varepsilon>0\), even with links only within one side; a polynomial-time \(2\)-approximation exists. [Source](https://arxiv.org/pdf/1207.1265)
No approximation result for this precise mass model was located in the literature search.

  • Interpret positive measure using the product measure on agent pairs, with accessibility determined by individual partner-status classes and paths containing fixed links and actual individual matching edges.

  • Allow incomplete acceptable-pair sets as specified in the continuous question, and allow links independently of acceptability and across or within either side.

Result

For every fixed \(\varepsilon\in(0,1/2)\), achieving a \((3/2-\varepsilon)\)-approximation is hard under the Unique Games Conjecture. This holds even when all supported types have equal mass and the fixed links occur only within one side.

The essential point is that, on equal-mass instances, divisibility does not improve the optimum: a locally stable fractional allocation can be rounded without decreasing its scaled matching mass.

Here, an \(\alpha\)-approximation means a locally stable allocation of value at least \(\mathrm{OPT}/\alpha\).

1. Local stability is preserved when status support shrinks

For a feasible allocation \(x\), define its positive status support by

\(\mathcal S(x)=\{(t,a):q_{ta}(x)>0\}\),

where \(a\) ranges over acceptable partner types and \(\bot\).

Lemma 1. If \(x\) is locally stable and \(y\) is feasible for the same instance, with \(\mathcal S(y)\subseteq\mathcal S(x)\), then \(y\) is locally stable.

Proof. Suppose \(y\) has an accessible, mutually improving status pair \((u,a),(w,b)\) with both status masses positive. The support inclusion makes both corresponding status masses positive under \(x\).

Mutual improvement depends only on the fixed rankings and the labels \(u,a,w,b\). Accessibility depends only on these labels and the fixed template \(H\), including the fixed set of supported types. Thus the same status pair is accessible and mutually improving under \(x\), contradicting its local stability. \(\square\)

This lemma requires preserving zero unmatched mass as well as zero matching coordinates. Preserving only the positive matching edges would be insufficient.

2. Equal-mass allocations admit integral rounding

Lemma 2. Suppose every supported type has mass \(1/\tau\). For every locally stable allocation \(x\), there is a matching \(M\) on the type vertices such that:

  • its normalized allocation \(y_{uw}=\mathbf 1_{\{(u,w)\in M\}}/\tau\) is locally stable;
  • \(|M|\geq \tau\sum_{(u,w)\in E}x_{uw}\).

Given an explicitly encoded rational allocation \(x\), such a matching can be computed in polynomial time.

Proof. Scale the allocation by setting \(z_{uw}=\tau x_{uw}\). Let

\(C=\{(u,w)\in E:x_{uw}>0\}\)

and let

\(R=\{t:q_{t\bot}(x)=0\}\)

be the types that are fully matched under \(x\).

Consider the polytope \(F\) specified by

\[ v_{uw}\geq 0,\qquad v_{uw}=0\ \text{for }(u,w)\notin C, \]

\[ \sum_{s:(t,s)\in E}v_{ts}\leq 1\quad\text{for every }t, \qquad \sum_{s:(t,s)\in E}v_{ts}=1\quad\text{for }t\in R. \]

The scaled allocation \(z\) belongs to \(F\), so \(F\) is nonempty. It is bounded because every coordinate is at most \(1\).

We verify integrality. The vertex-edge incidence matrix of a bipartite graph becomes a directed incidence matrix after multiplying the rows indexed by \(T_W\) by \(-1\). This matrix is totally unimodular: in any square submatrix, a column with at most one nonzero permits determinant expansion; if every column has two nonzeros, they have opposite signs, so the rows sum to zero and the determinant vanishes. Induction therefore gives determinants in \(\{0,1,-1\}\). Adding coordinate rows preserves this property.

Consequently, every nonsingular active-constraint matrix defining a vertex of \(F\) has determinant \(1\) or \(-1\). Its right-hand side is integral, so Cramer’s rule makes that vertex integral. Every integral feasible coordinate belongs to \(\{0,1\}\), and its positive edges form a matching.

Maximize \(\sum_{(u,w)\in E}v_{uw}\) over \(F\), and choose an optimal vertex \(v^\ast\). Its matching \(M\) satisfies

\[ |M| =\sum_{(u,w)\in E}v^\ast_{uw} \geq \sum_{(u,w)\in E}z_{uw} =\tau\sum_{(u,w)\in E}x_{uw}. \]

For the normalized allocation \(y=v^\ast/\tau\), every positive matching status was already positive under \(x\), because edges outside \(C\) were forbidden. Also, every type with zero unmatched mass under \(x\) remains fully matched, because its degree was constrained to equal \(1\). Hence \(\mathcal S(y)\subseteq\mathcal S(x)\), and Lemma 1 proves local stability.

For computation, use a bipartite flow network with unit capacities on source-to-\(T_U\) arcs and \(T_W\)-to-sink arcs, retaining only the edges in \(C\). Give the corresponding boundary arc lower bound \(1\) for every type in \(R\). Maximizing feasible flow with these lower bounds produces an integral optimum in polynomial time. \(\square\)

3. Reduction from the finite-agent problem

We use the finite-agent hardness theorem supplied in the question: for every fixed \(\varepsilon\in(0,1/2)\), under the Unique Games Conjecture there is no polynomial-time \((3/2-\varepsilon)\)-approximation for maximum locally stable matching with strict preferences, even when links occur only within one side. The stated restriction appears in Corollary 4 and its following remark in [Hoefer and Wagner, *Locally Stable Marriage with Strict Preferences*](https://arxiv.org/pdf/1207.1265).

Take such a finite instance with \(N\) agents. Create one supported type for each agent, retaining its side, acceptable partners, and strict ranking. Set \(H\) equal to the finite link adjacency matrix, with diagonal zero.

For completeness, equal masses can even be chosen dyadic. Let \(\tau\) be the smallest power of two at least \(N\), add \(\tau-N\) dummy types with no acceptable partners and no links, and assign every type mass \(1/\tau\). Then \(N\leq\tau<2N\), unless \(N=\tau\). Dummy types can be placed on either side and cannot participate in any matching or blocking pair.

Accessibility agrees on normalized finite matchings

Consider a mutually improving pair of original agents \(u,w\), whose current partners are \(a,b\), respectively.

A path of length at most two in the finite graph of fixed links and matching edges can consist of:

  • one fixed link;
  • two fixed links;
  • the matching edge from \(u\) to \(a\), followed by a fixed link to \(w\);
  • a fixed link from \(u\) to \(b\), followed by its matching edge to \(w\).

These are precisely the four accessibility conditions in the mass model. A direct matching edge between \(u,w\) cannot be mutually improving. A two-edge path consisting of two matching edges cannot occur because matching edges are disjoint.

Thus a finite matching is locally stable exactly when its normalized type allocation is locally stable.

The optimum is preserved exactly

Let \(\mathrm{OPT}_{\mathrm{fin}}\) denote the original maximum cardinality, and let \(\mathrm{OPT}_{\mathrm{mass}}\) denote the constructed mass optimum.

Normalizing an optimal finite matching gives

\[ \mathrm{OPT}_{\mathrm{mass}} \geq \frac{\mathrm{OPT}_{\mathrm{fin}}}{\tau}. \]

Conversely, Lemma 2 rounds every locally stable mass allocation \(x\) to a finite matching of cardinality at least \(\tau\sum x_{uw}\). Dummy types have no acceptable edges, so deleting them changes nothing. Therefore

\[ \sum x_{uw}\leq \frac{\mathrm{OPT}_{\mathrm{fin}}}{\tau}. \]

Together, these inequalities establish

\[ \mathrm{OPT}_{\mathrm{mass}} =\frac{\mathrm{OPT}_{\mathrm{fin}}}{\tau}. \]

Now suppose a mass-model algorithm returned a locally stable allocation \(x\) with approximation ratio \(\alpha\). Rounding would give

\[ |M| \geq \tau\sum x_{uw} \geq \frac{\tau\,\mathrm{OPT}_{\mathrm{mass}}}{\alpha} =\frac{\mathrm{OPT}_{\mathrm{fin}}}{\alpha}. \]

Taking \(\alpha=3/2-\varepsilon\) contradicts the cited finite-agent theorem under the Unique Games Conjecture.

4. Running times and dependence on supported types

The reduction creates fewer than \(2N\) supported types. Its output length satisfies

\(L=O(\tau^2+|E|\log\tau+\tau\log\tau)=O(\tau^2\log\tau)\).

Both construction and rounding take polynomial time. In particular, the rounding flow network has \(O(\tau)\) vertices and \(O(|E|+\tau)\) arcs. A standard implementation using the lower-bound reduction and Edmonds–Karp uses \(O(\tau(|E|+\tau)^2)\) arithmetic operations; here its integral capacities require \(O(\log\tau)\) bits. Reading and testing a rational candidate allocation additionally takes polynomial time in its encoding length.

Consequently, under the Unique Games Conjecture, the requested approximation cannot run in \(\operatorname{poly}(m,\tau,L)\) time for any fixed positive \(\varepsilon\). This also excludes a running time \(f(\varepsilon)\operatorname{poly}(m,\tau,L)\), with a polynomial exponent independent of \(\varepsilon\).

There is nevertheless an exact algorithm with running time

\[ 2^{|E|+\tau}\operatorname{poly}(m,\tau,L) \leq 2^{m^2+\tau}\operatorname{poly}(m,\tau,L). \]

To prove this bound, enumerate an allowed positive-edge set \(C\subseteq E\) and an allowed unmatched-type set \(B\subseteq T_U\cup T_W\). These choices specify allowed statuses: the endpoints of edges in \(C\), together with \((t,\bot)\) for \(t\in B\).

Reject a pattern if two allowed statuses form an accessible, mutually improving pair. Otherwise maximize matching mass subject to feasibility and

\[ x_{uw}=0\quad\text{for }(u,w)\notin C, \qquad \sum_s x_{ts}=\mu_t\quad\text{for }t\notin B. \]

This is a rational linear program, equivalently a bipartite flow problem with lower bounds. Every feasible solution has status support contained in the allowed pattern and is therefore locally stable. Conversely, the exact positive status support of every locally stable allocation appears among the enumerated patterns and passes the test. Thus optimizing all retained patterns gives the exact optimum.

There are \(2^{|E|+\tau}\) patterns. Accessibility through fixed links can be precomputed in \(O(\tau^3)\) operations, and each pattern can be checked in \(O(|E|(m+1)^2)\) operations. The remaining flow computation is polynomial in \(m,\tau,L\), using rational arithmetic without expanding masses into individual agents.

Since \(\tau\leq 2m\), this is also a \(2^{O(m^2)}\operatorname{poly}(L)\) exact algorithm. Its running time has no dependence on \(\varepsilon\). It does not contradict the hardness result, because the reduction has an unbounded number of supported types.

1. Support monotonicity

Lemma 1 is correct.

For an accessible, mutually improving status pair, both improvement and accessibility depend only on the status labels, rankings, fixed template, and fixed set of supported types. They do not depend on the positive magnitudes of the status masses.

Consequently, if both statuses are positive under \(y\), support inclusion makes both positive under \(x\), yielding the same forbidden pair under \(x\).

The write-up correctly includes unmatched statuses in the support. This matters: eliminating matching edges alone could introduce previously absent unmatched statuses, so preserving only matching-edge support would not justify the lemma.

2. Equal-mass rounding

Feasibility and boundedness

With \(\mu_t=1/\tau\), scaling by \(\tau\) gives vertex capacities \(1\). Therefore the scaled allocation \(z\) satisfies every constraint defining \(F\):

  • Edges outside \(C\) have zero allocation.
  • Every vertex has degree at most \(1\).
  • Every vertex in \(R\) has degree exactly \(1\).

Thus \(F\) is nonempty. Every edge coordinate is bounded above by an endpoint’s capacity, so \(F\) is bounded.

Integrality

The total-unimodularity argument is valid.

After negating the rows for \(T_W\), each edge column has one positive and one negative entry. In a square submatrix:

  • A column with no nonzero entry gives determinant zero.
  • A column with one nonzero entry permits induction by determinant expansion.
  • If every column has two nonzero entries, its entries have opposite signs, so the rows are linearly dependent.

This establishes the claimed determinant restriction. Coordinate constraints preserve total unimodularity by the same expansion argument. Row sign changes and the degree equalities do not invalidate it.

At any vertex of \(F\), a nonsingular set of active constraints therefore has determinant \(1\) or \(-1\). Its right-hand side is integral, so the vertex is integral. Nonnegativity and unit degree capacities then force every edge coordinate to belong to \(\{0,1\}\). Its positive edges form a matching.

Nonemptiness and boundedness justify choosing an optimal vertex of the linear objective.

Objective and status preservation

Since \(z\in F\), optimization gives \(|M|\geq\tau\sum_{(u,w)\in E}x_{uw}\).

The normalized matching allocation preserves the required support restrictions:

  • A positive matching coordinate can occur only on an edge already in \(C\).
  • Every type with zero unmatched mass under \(x\) belongs to \(R\) and remains fully matched.

Other unmatched statuses may disappear, which is permitted by support inclusion. Lemma 1 therefore applies exactly as claimed.

Computation

The lower-bound flow formulation correctly enforces saturation of every type in \(R\). All bounds and capacities can be integral, and the scaled allocation witnesses feasibility. Integral maximum-flow computation therefore supplies the required integral optimum.

The computational statement is appropriately restricted to explicitly encoded rational allocations, whose positive coordinates and zero unmatched masses can be determined exactly.

  • The number of types satisfies \(N\leq\tau<2N\).

  • Dummy types have neither acceptable edges nor links, so they cannot match, block, or create accessibility paths.

Setting the template diagonal to zero correctly reflects the original loopless fixed-link graph. The original two sides remain nonempty.

Accessibility equivalence

The path classification is exhaustive for a mutually improving pair.

A path of length one can be a fixed link. A direct matching edge cannot connect a mutually improving pair, since those agents are already partners.

A path of length two can contain:

  • Two fixed links.
  • A matching edge incident to the first endpoint followed by a fixed link.
  • A fixed link followed by a matching edge incident to the second endpoint.

Two distinct matching edges cannot form a path of length two because a matching has degree at most one at every vertex.

These cases coincide with the four accessibility conditions in the task. Rankings and unmatched preferences are preserved, so finite local stability and local stability of the normalized matching allocation are equivalent.

This equivalence is asserted only for normalized finite matchings, which is sufficient: Lemma 2 handles fractional allocations separately.

Optimum and approximation preservation

Removing isolated dummy types leaves a matching in the original finite instance. Hence \(\sum x_{uw}\leq\mathrm{OPT}_{\mathrm{fin}}/\tau\) for every locally stable allocation.

The claimed equality of optima follows.

Applying rounding to an \(\alpha\)-approximate mass allocation gives \(|M|\geq\mathrm{OPT}_{\mathrm{fin}}/\alpha\). Thus a polynomial-time mass approximation with \(\alpha=3/2-\varepsilon\) would contradict the supplied finite-agent hardness theorem.
