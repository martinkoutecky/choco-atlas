The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to one, panel size \(k\), and integer quotas \(\ell_{f,v},u_{f,v}\), produce an exact sampler for \(k\) independent draws from \(\mu\), conditioned on the resulting panel satisfying every quota, or report that no feasible panel exists.

Packaged proof task (what the prover saw — nothing else)

Let \(F\) be a nonempty finite feature set, with nonempty finite value sets \(V_f\), and put \(m=\sum_{f\in F}|V_f|\). A type specifies exactly one value \(f(t)\in V_f\) for each feature.
A society is given by its support: a list \(T\) of \(\tau\) distinct types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The input also contains a unary panel size \(k\geq1\) and binary-integer quotas \(0\leq\ell_{f,v}\leq u_{f,v}\leq k\). Let \(L\) be the total input bit length.
A panel is an ordered tuple \(x\in T^k\), with repeated types allowed. It is feasible exactly when \(\ell_{f,v}\leq|\{j:f(x_j)=v\}|\leq u_{f,v}\) for every feature-value pair; write \(A\) for the feasible tuples.
The computational problem is to report infeasibility when \(A=\varnothing\), and otherwise provide an exact sampler with \(\Pr[X=x]=\prod_{j=1}^k\mu_{x_j}/\sum_{y\in A}\prod_{j=1}^k\mu_{y_j}\) for \(x\in A\). Use independent fair random bits and count preprocessing and generation of one sample in the running time.

Does this conditional sampling problem admit an exact algorithm with expected running time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For finite pools, exact uniform sampling from feasible subsets is known, without a general polynomial-time guarantee ([source](https://arxiv.org/html/2604.02712v1)); deciding whether such a subset exists is NP-hard ([source](https://procaccia.info/wp-content/uploads/2021/08/assemblies.pdf)).
No verified complexity classification for the mass-input conditional sampler above was located.

Modeling choices made when packaging the task

  • Defined types as complete categorical feature vectors, with exactly one value per feature, and defined m as the number of feature-value pairs.
  • Carried over the quota domain: integer lower and upper bounds between zero and the panel size.
  • Required nonempty feature and value sets and a positive panel size.
  • Represented the independent draws as an ordered tuple permitting repeated types; quotas count occurrences, not distinct types.
  • Encoded the panel size in unary so polynomial time includes the explicit sample's length; quotas remain binary encoded.
  • Specified fair-bit randomness and expected running time, including preprocessing and one exact sample.
  • Retained infeasibility reporting as requested, although the discrete sampling correctness guarantee assumes feasibility.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The conditional sampling problem is \(\mathsf{NP}\)-hard. Its feasibility problem is \(\mathsf{NP}\)-complete, even with binary-valued features, exact quotas, and positive dyadic masses. Consequently, an exact algorithm with the required polynomial expected running time would imply \(\mathsf{NP}=\mathsf{ZPP}\).

The reduction below addresses repetitions explicitly. The expected-time conclusion is conditional on a complexity-class separation; hardness alone does not establish an unconditional impossibility.

  • Feasibility belongs to \(\mathsf{NP}\).

Define the decision problem \(\mathrm{FEAS}\) to ask whether \(A\neq\varnothing\).

A certificate is an ordered tuple of \(k\) support indices. Its encoding has length \(O(k\log(\tau+1))\), which is polynomial in the input length because \(k\) is unary and the support is explicitly listed.

Given this tuple, compute every feature-value count and compare it with the corresponding quotas. These operations take polynomial time. Thus \(\mathrm{FEAS}\in\mathsf{NP}\).

  • A polynomial reduction from exact cover.

We use Exact Cover by 3-Sets, abbreviated X3C: given a universe \(U\) of size \(3q\) and a collection \(\mathcal C\) of three-element subsets of \(U\), determine whether some subcollection covers every element exactly once. This is a standard \(\mathsf{NP}\)-complete problem, also used in the [cited panel-feasibility proof](https://procaccia.info/wp-content/uploads/2021/08/assemblies.pdf).

We may assume \(q\geq1\) and \(\mathcal C\neq\varnothing\). The excluded cases are directly decidable and can be mapped to fixed feasible or infeasible instances. Remove duplicate sets, which does not change whether an exact cover exists, and write \(\mathcal C=\{C_1,\ldots,C_n\}\).

Construct the mass-input instance as follows:

  • For each \(a\in U\), introduce a feature \(f_a\) with value set \(\{0,1\}\).
  • For each \(C_i\), introduce a type \(t_i\), defined by \(f_a(t_i)=1\) if \(a\in C_i\), and \(f_a(t_i)=0\) otherwise.
  • Set \(k=q\).
  • For every \(a\in U\), impose exact quotas

\(\ell_{f_a,1}=u_{f_a,1}=1\) and
\(\ell_{f_a,0}=u_{f_a,0}=q-1\).

The types are distinct because the sets \(C_i\) are distinct. All quotas satisfy the required bounds.

To obtain valid masses even under the restrictive interpretation that “binary-rational” means dyadic, let \(b=\lceil\log_2 n\rceil\), and set
\(\mu_{t_i}=2^{-b}\) for \(1\leq i<n\), and
\(\mu_{t_n}=(2^b-n+1)/2^b\).

Every mass is positive, since \(n\leq2^b\), and their sum is
\((n-1+2^b-n+1)/2^b=1\).
For \(n=1\), this assigns mass \(1\) to the sole type.

Here \(m=6q\), \(\tau=n\), and \(k=q\). The incidence table has \(3qn\) binary entries, each mass has \(O(\log(n+1))\) bits, and each quota has \(O(\log(q+1))\) bits. Thus the construction, including the unary encoding of \(k\), has polynomial size and takes polynomial time.

  • Correctness, including repeated types.

Suppose first that \(\mathcal C'\subseteq\mathcal C\) is an exact cover. Since its sets have size three and partition a universe of size \(3q\), it contains exactly \(q\) sets.

Order their corresponding types arbitrarily to form a tuple of length \(q\). For every \(a\in U\), exactly one selected type has \(f_a\)-value \(1\), and the other \(q-1\) types have value \(0\). Hence the tuple satisfies every quota.

Conversely, let \(x=(x_1,\ldots,x_q)\) be feasible. For every \(a\in U\), the quota for \((f_a,1)\) says that exactly one selected set contains \(a\).

No type can occur twice: if \(t_i\) occurred at least twice, choose any \(a\in C_i\), which exists because \(|C_i|=3\). The count for \((f_a,1)\) would then be at least two, contradicting its upper quota of one.

Consequently, the tuple selects \(q\) distinct sets, and each universe element belongs to exactly one of them. Those sets form an exact cover.

We have therefore proved
\(A\neq\varnothing\) if and only if the X3C instance has an exact cover.
Together with membership in \(\mathsf{NP}\), this proves that \(\mathrm{FEAS}\) is \(\mathsf{NP}\)-complete.

  • Implication for exact expected-time sampling.

Assume there is an algorithm satisfying the task, with expected total running time bounded by a polynomial in \(m,\tau,k,L\), including preprocessing and generation of one sample.

Run it on the constructed instance. If it reports infeasibility, reject the X3C instance. Otherwise, generate its sample and accept. This decision procedure is correct because:

  • When \(A=\varnothing\), the specification requires an infeasibility report.
  • When \(A\neq\varnothing\), all masses are positive, so the conditional distribution is defined, and the algorithm must produce a tuple in \(A\).

The reduction has polynomial size, so the resulting decision procedure has polynomial expected running time. Finite expectation also implies termination with probability one. It is therefore a zero-error randomized polynomial expected-time algorithm for X3C, placing X3C in \(\mathsf{ZPP}\).

By \(\mathsf{NP}\)-completeness and closure under deterministic polynomial reductions, this gives \(\mathsf{NP}\subseteq\mathsf{ZPP}\). For completeness, \(\mathsf{ZPP}\subseteq\mathsf{NP}\): truncate a zero-error algorithm after twice its polynomial expected-time bound. Markov’s inequality gives completion probability at least one half. On a yes-instance, some polynomial-length random-bit string therefore produces acceptance; on a no-instance, none can. Such strings are \(\mathsf{NP}\) certificates. Hence the assumed sampler would imply \(\mathsf{NP}=\mathsf{ZPP}\).

The hardness classification is thus established. In particular, unless \(\mathsf{NP}=\mathsf{ZPP}\), the requested exact polynomial expected-time algorithm does not exist.
