The continuous mirror question, as graded

Given a finite norm net \(\langle N,R\rangle\), value set \(V\), support map, and rational-mass distribution \(\mu\) over \(\tau\) complete weak rankings \(\succeq_t\) of \(V\), define \(M_\mu(v,w)=\sum_{t:v\succeq_t w}\mu_t\) and \(v\succeq_\mu w\) iff \(M_\mu(v,w)\ge \tfrac12\). For inputs where \(\succeq_\mu\) is transitive, find a sound \(\Omega\subseteq N\) maximizing the norm-system ranking induced from \(\succeq_\mu\) by preference induction, lex-cel grounding, and anti-lex-cel lifting.

Packaged proof task (what the prover saw — nothing else)

Let \(N\) be a nonempty finite set of candidate norms, \(V\) a nonempty finite value set, \(q=|N|\), and \(m=|V|\). The explicitly listed norm relations are symmetric irreflexive exclusivity \(R_x\), symmetric irreflexive substitutability \(R_s\), and acyclic directed generalisation \(R_g\), with \((n,n')\in R_g\) meaning that \(n\) directly generalises \(n'\).
Write \(A(n)\) for the ancestors of \(n\) under \(R_g\), and \(D(n)=\{n':(n,n')\in R_g\}\). A system \(\Omega\subseteq N\) is sound if it contains no exclusive or substitutable pair, no norm together with an ancestor, and never contains all of \(D(n)\) when \(|D(n)|>1\).
The explicit promotion map \(\sigma_v:N\to 2^V\) has nonempty images, and every value is promoted. Require \(\sigma_v(n)\cap\sigma_v(n')=\varnothing\) for exclusive norms and \(\sigma_v(n')\subseteq\sigma_v(n)\) whenever \((n,n')\in R_g\). Put \(S_v=\{n:v\in\sigma_v(n)\}\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Each type is a complete weak ranking \(\succeq_t\) of \(V\); \(\tau\) is the support size, not the number of possible rankings. Require \(\sum_t\mu_t=1\), and define \(M_\mu(v,w)=\sum_{t:v\succeq_t w}\mu_t\) and \(v\succeq_\mu w\iff M_\mu(v,w)\ge\tfrac12\).
Promise that \(\succeq_\mu\) is transitive and that \(S_v=S_w\) implies \(v\sim_\mu w\). Preference induction ranks the distinct sets \(S_v\) by \(S_v\succeq S_w\iff v\succeq_\mu w\); all other subsets of \(N\) form one strictly last indifference class.
For these subset classes \(\Sigma_1,\ldots,\Sigma_k\), ordered best first, lex-cel ranks norms by lexicographically comparing \(c(n)=(|\{S\in\Sigma_i:n\in S\}|)_{i=1}^k\). Let \(\Xi_1,\ldots,\Xi_r\) be the resulting norm indifference classes, best first. Anti-lex-cel ranks systems by lexicographically comparing \(\eta(\Omega)=(|\Omega\cap\Xi_i|)_{i=1}^r\), with equal vectors tied.
Find a sound \(\Omega\subseteq N\) maximizing this ranking; any tied optimum is acceptable. Norm selection remains integral. State running times in \(m,\tau,q,L\), where \(L\) is the total binary input length.

Is this rational-mass norm-system optimization problem solvable in polynomial time, or is it NP-hard?

For a supplied value ranking, qualitative optima coincide with maximum additive value-alignment optima ([2020 equivalence result](https://www.ifaamas.org/Proceedings/aamas2020/pdfs/p1233.pdf)).
A later generalization provides an equivalent binary integer program ([2021 result](https://link.springer.com/article/10.1007/s10458-021-09519-5)); no result for this exact rational-mass problem was located.

Conclusion

The optimization problem is NP-hard, even when \(m=\tau=1\), all masses are integral, and \(R_x=R_g=\varnothing\). In this restricted case, it is exactly maximum independent set.

The rational society and the induced rankings can be processed in polynomial time. The hardness remains in selecting an integral sound system.

1. Computing the ranking in polynomial time

Write each positive mass as \(\mu_t=a_t/b_t\), where \(a_t,b_t\) are positive integers represented in binary. Set

\[ Q=\prod_{t=1}^{\tau}b_t,\qquad p_t=a_t(Q/b_t). \]

These integers have \(O(L)\) bits. Every majority comparison can be computed exactly using

\[ v\succeq_\mu w \iff 2\sum_{t:v\succeq_t w}p_t\ge Q. \]

Thus all comparisons require \(O(\tau m^2L^2)\) bit operations using elementary integer arithmetic.

For each type, completeness of its weak ranking gives

\[ \mathbf 1[v\succeq_t w]+\mathbf 1[w\succeq_t v]\ge 1. \]

Consequently, \(M_\mu(v,w)+M_\mu(w,v)\ge 1\), so the majority relation is complete. It is reflexive because \(M_\mu(v,v)=1\), and transitive by promise. Hence it is a total preorder.

The promise concerning equal promotion sets makes the induced ranking well-defined. Indeed, in any transitive relation, if \(v\sim_\mu v'\), then \(v\succeq_\mu w\) holds exactly when \(v'\succeq_\mu w\), by applying transitivity in both directions. The same argument applies to the second argument of the comparison.

There are at most \(m\) distinct promotion sets. Let their indifference classes, ordered best first, be \(C_1,\ldots,C_h\), where \(h\le m\). These classes contain distinct sets, so repeated values with the same promotion set are counted only once.

For a norm \(n\), define

\[ a_i(n)=|\{S\in C_i:n\in S\}|. \]

Every value is promoted, so every distinguished set \(S_v\) is nonempty. Therefore the class containing all other subsets is nonempty: it contains \(\varnothing\).

Exactly \(2^{q-1}\) subsets of \(N\) contain any fixed norm. It follows that the full lex-cel vector is

\[ c(n)=\left(a_1(n),\ldots,a_h(n), 2^{q-1}-\sum_{i=1}^{h}a_i(n)\right). \]

The last coordinate cannot distinguish norms whose preceding coordinates agree. Thus comparing the shorter vectors \((a_1(n),\ldots,a_h(n))\) gives exactly the required norm ranking. No enumeration of \(2^N\) is necessary.

Using direct pairwise comparisons to deduplicate promotion sets and rank norms, and a transitive-closure computation for \(R_g\), a conservative polynomial preprocessing bound is

\[ P(m,\tau,q,L) = O\!\left( (\tau m^2+m^3+m^2q+q^2m+q^3)L^2 \right). \]

This bound also allows checking the stated promises: majority transitivity takes \(O(m^3)\) comparisons, and the remaining structural and promotion conditions can be checked within the other terms.

2. A promise-preserving hardness reduction

We use the standard NP-complete problem Independent Set: given a nonempty simple undirected graph \(G=(U,E)\) and an integer \(K\), determine whether some subset of at least \(K\) vertices contains no edge.

Construct the norm instance as follows:

  • \(N=\{n_u:u\in U\}\).
  • \(V=\{v\}\), with \(\sigma_v(n_u)=\{v\}\) for every \(u\).
  • \(R_x=R_g=\varnothing\).
  • \(R_s=\{(n_u,n_w),(n_w,n_u):\{u,w\}\in E\}\).
  • The society has one type, of mass \(1\), ranking its sole value \(v\).

The construction has polynomial size and satisfies every hypothesis:

  • \(R_s\) is symmetric and irreflexive because the graph is simple.
  • \(R_g\) is acyclic because it is empty.
  • Every promotion image is nonempty, and the sole value is promoted.
  • The promotion conditions on exclusivity and generalisation are vacuous.
  • The masses sum to \(1\).
  • The majority ranking on a singleton is transitive.
  • The equal-promotion-set promise holds automatically.

Since \(R_x\) and \(R_g\) are empty, soundness requires precisely that no two selected norms form a pair in \(R_s\). Therefore

\[ \Omega\text{ is sound} \iff \{u:n_u\in\Omega\}\text{ is independent in }G. \]

It remains to verify the objective. The sole distinguished promotion set is \(S_v=N\). Every norm therefore has the same vector

\[ c(n)=(1,2^{q-1}-1). \]

There is exactly one norm indifference class, \(\Xi_1=N\), and consequently

\[ \eta(\Omega)=(|\Omega|). \]

Thus the required optimum is exactly a maximum independent set. Given any tied optimum, its cardinality decides whether \(G\) has an independent set of size at least \(K\).

The reduction has \(m=\tau=1\), uses only the mass \(1\), and has output length polynomial in the graph’s explicit input length. Therefore an algorithm polynomial in \(m,\tau,q,L\) would solve Independent Set in polynomial time. This proves NP-hardness.

This hardness also holds with \(R_s=R_g=\varnothing\). To see this, instead use \(R_x\) for the graph edges, give each norm its own distinct value, and let the sole society type tie all values. Exclusive norms then promote disjoint values. The distinguished sets are tied singletons, every norm again has vector \((1,2^{q-1}-1)\), and the same independent-set argument applies.

3. Integral encoding and exact running time

For completeness, the objective has a polynomial-size additive encoding. Let \(\Xi_1,\ldots,\Xi_r\) be the computed norm classes and set \(B=q+1\). Assign each norm in \(\Xi_i\) weight \(B^{r-i}\). Define

\[ F(\Omega)=\sum_{i=1}^{r}|\Omega\cap\Xi_i|B^{r-i}. \]

This objective induces exactly the specified lexicographic ranking. If two vectors first differ at coordinate \(i\), a positive difference there contributes at least \(B^{r-i}\). The absolute contribution from all later coordinates is at most

\[ q\sum_{j=i+1}^{r}B^{r-j} = B^{r-i}-1. \]

Hence later coordinates cannot reverse the first strict comparison. Equal vectors give equal objectives. Since \(r\le q\), the weights and objective have \(O(q\log(q+1))\) bits.

Introduce binary variables \(x_n\), indicating membership in \(\Omega\). Soundness is exactly expressed by

\[ x_n+x_{n'}\le 1 \quad\text{for every exclusive or substitutable pair}, \]

\[ x_n+x_a\le 1 \quad\text{for every }a\in A(n), \]

\[ \sum_{n'\in D(n)}x_{n'}\le |D(n)|-1 \quad\text{whenever }|D(n)|>1, \qquad x_n\in\{0,1\}. \]

Maximizing the corresponding weighted sum is therefore an exact binary integer formulation.

The natural threshold decision problem—whether some sound system has \(F(\Omega)\ge K\)—is in NP: a proposed system can be checked for soundness and its objective computed in polynomial time. Together with the reduction, this decision problem is NP-complete.

An unconditional exact algorithm computes the ranking, enumerates all \(2^q\) systems, and retains a sound system with the best vector. Its conservative bit-operation bound is

\[ O\!\left( (\tau m^2+m^3+m^2q+q^2m+q^3+2^q q^2)L^2 \right), \]

with polynomial space.

4. Why additive equivalence does not imply polynomial time

The [2020 encoding](https://www.ifaamas.org/Proceedings/aamas2020/pdfs/p1233.pdf) explicitly uses binary selection variables, and the [2021 generalization](https://link.springer.com/article/10.1007/s10458-021-09519-5) gives a binary integer program. Equivalence to an additive objective does not remove the integrality requirement.

For example, take the one-value construction above on a triangle. Its integral optimum has cardinality \(1\). If the binary restrictions are relaxed to \(0\le x_n\le 1\), assigning \(1/2\) to each of the three norms satisfies every pair constraint and gives objective \(3/2\). Thus the continuous relaxation does not, in general, recover a sound integral optimum.

The classification is therefore complete: the specified rational-mass optimization problem is NP-hard, including the constant-\(m\), constant-\(\tau\) restriction proved above.
