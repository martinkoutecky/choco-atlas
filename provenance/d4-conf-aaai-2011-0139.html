The continuous mirror question, as graded

Given goals \(G\), resources \(R\), and a distribution \(\mu\) over \(\tau\) types, where each type \(t\) has an acceptable-goal set \(A_t\subseteq G\) and per-agent endowments \(e_{t,r}\), and each goal \(g\) has population-normalized requirements \(q_{g,r}\), determine whether there is a nonempty goal set \(S\subseteq G\) such that \(A_t\cap S\neq\emptyset\) for every type with \(\mu_t>0\), and \(\sum_{g\in S}q_{g,r}\leq\sum_t\mu_t e_{t,r}\) for every resource \(r\in R\).

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a finite goal set with \(m=|G|\), and let \(R\) be a finite nonempty resource set. The entire society is the coalition under consideration.
A society is given by its support: the list of the \(\tau\geq1\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types; \(\sum_t\mu_t=1\).
Each type has an acceptable-goal set \(A_t\subseteq G\), possibly empty, and per-agent endowments \(e_{t,r}\in\mathbb{Q}_{\geq0}\). Each goal has population-normalized requirements \(q_{g,r}\in\mathbb{Q}_{\geq0}\); all numerical inputs are binary encoded.
Goals are indivisible and selected once. A successful selection is a nonempty set \(S\subseteq G\) satisfying \(A_t\cap S\neq\emptyset\) for every support type and \(\sum_{g\in S}q_{g,r}\leq\sum_t\mu_t e_{t,r}\) for every \(r\in R\).
Let \(L\) be the total input bit length; state running times in \(m,\tau,|R|,L\).

Is deciding whether a successful selection exists in \(\mathrm{P}\), or is it NP-hard? If NP-hard, is it FPT parameterized by \(\tau\)?

For finite agent lists, Successful Coalition is strongly NP-complete, even with endowments and requirements in \(\{0,1\}\) ([Wooldridge–Dunne](https://www.cs.ox.ac.uk/people/michael.wooldridge/pubs/aij2006a.pdf)), and is \(\mathrm{W[1]}\)-hard parameterized by coalition size ([Chitnis–Hajiaghayi–Liaghat](https://arxiv.org/pdf/1105.0707)).
No result settling this exact mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one and treated its entire support as the fixed coalition.
  • Specified endowments and normalized requirements as nonnegative binary rationals, retaining zero values allowed by the discrete model.
  • Used support size tau as the continuous counterpart of coalition size for the conditional FPT question.
  • Retained possibly empty acceptable-goal sets and a possibly empty goal set; required a nonempty resource set, as in the original CRG model.
  • Made explicit that goals remain indivisible and selected once, and defined L as total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

The problem is \(\mathrm{NP}\)-complete, even when every endowment equals \(1\), every requirement belongs to \(\{0,1\}\), and all support types have equal mass.

Parameterized by the support size \(\tau\), it is \(\mathrm{W[1]}\)-hard. Thus it is not FPT unless \(\mathrm{FPT}=\mathrm{W[1]}\). It does admit an XP algorithm with running time
\(O\!\left(m^\tau\tau(\tau+|R|)L^2\right)\) for \(m\geq1\).

These are complexity classifications with the usual qualifications: polynomial-time solvability would imply \(\mathrm{P}=\mathrm{NP}\), and fixed-parameter tractability would imply \(\mathrm{FPT}=\mathrm{W[1]}\).

1. Exact verification and membership in \(\mathrm{NP}\)

Define the aggregate budget for resource \(r\) by
\(B_r=\sum_{t=1}^{\tau}\mu_t e_{t,r}\).

A certificate is the \(m\)-bit indicator vector of a selected set \(S\). Verification checks that:

  • \(S\neq\emptyset\);
  • \(A_t\cap S\neq\emptyset\) for every support type \(t\);
  • \(\sum_{g\in S}q_{g,r}\leq B_r\) for every resource \(r\).

All arithmetic can be performed exactly. For each resource, the products and sums have intermediate numerator and denominator lengths \(O(L)\): their denominators can be taken as products of the relevant input denominators, whose total bit lengths are bounded by \(O(L)\). Numerator lengths satisfy the same bound, including the additional logarithmic cost of summation.

Using elementary integer arithmetic, verification therefore takes
\(O\!\left(((m+\tau)|R|+m\tau+1)L^2\right)\)
bit operations. Hence the problem belongs to \(\mathrm{NP}\).

If \(m=0\), or some \(A_t\) is empty, the instance is immediately unsuccessful. The hardness construction below avoids both cases.

2. A reduction from Independent Set

We use the standard facts that Independent Set is \(\mathrm{NP}\)-complete and is \(\mathrm{W[1]}\)-complete when parameterized by the requested set size \(k\). Independent Set is also the parameterized source problem used in [Chitnis–Hajiaghayi–Liaghat, Theorem 5.1](https://arxiv.org/pdf/1105.0707). We give the reduction for the mass formulation explicitly.

Let \(H=(V,E)\) be a finite simple undirected graph, with \(n=|V|\), and let \(1\leq k\leq n\). The excluded cases are decidable immediately, so this restriction preserves both hardness statements.

Construction

Create exactly \(k\) support types, indexed by \(i\in\{1,\ldots,k\}\), each with mass \(\mu_i=1/k\).

For every index \(i\) and vertex \(v\), create a goal \(g_{i,v}\). Define
\(A_i=\{g_{i,v}:v\in V\}\).

These acceptable-goal sets are nonempty and pairwise disjoint. Consequently the listed types are distinct and the support size is exactly \(\tau=k\).

Create one resource \(r_v\) for every vertex \(v\), and one resource \(r_e\) for every edge \(e\). Thus
\(m=kn\) and \(|R|=n+|E|\).
In particular, \(R\neq\emptyset\).

Give every type one unit of every resource:
\(e_{i,r}=1\).
Since the masses sum to one, every aggregate budget is
\(B_r=\sum_{i=1}^{k}(1/k)\cdot1=1\).

Set the requirements as follows:

  • For a vertex resource \(r_w\), let \(q_{g_{i,v},r_w}=1\) if \(v=w\), and \(0\) otherwise.
  • For an edge resource \(r_{\{u,w\}}\), let \(q_{g_{i,v},r_{\{u,w\}}}=1\) if \(v\in\{u,w\}\), and \(0\) otherwise.

Every requirement belongs to \(\{0,1\}\). All masses are positive binary-encoded rationals, with total mass one.

Forward implication

Suppose \(H\) has an independent set \(\{v_1,\ldots,v_k\}\). Select
\(S=\{g_{1,v_1},\ldots,g_{k,v_k}\}\).

This nonempty set intersects every \(A_i\).

For each vertex resource \(r_v\), its total requirement is at most \(1\), because the chosen vertices are distinct. For an edge resource \(r_{\{u,w\}}\), its total requirement is the number of selected vertices among \(u,w\). Independence makes this number at most \(1\).

All requirements therefore satisfy their budgets, so \(S\) is successful.

Reverse implication

Suppose a successful selection \(S\) exists. Since \(S\cap A_i\neq\emptyset\), choose one representative \(g_{i,v_i}\in S\cap A_i\) for each \(i\).

The vertices \(v_i\) are distinct. Indeed, if \(v_i=v_j=v\) for distinct indices, the two distinct selected goals would together require \(2\) units of \(r_v\), exceeding its budget \(1\).

They are also pairwise nonadjacent. If \(\{v_i,v_j\}\in E\), those two selected goals would together require \(2\) units of \(r_{\{v_i,v_j\}}\), again exceeding budget \(1\).

Thus \(\{v_1,\ldots,v_k\}\) is an independent set of size \(k\).

Reduction size and consequences

The construction lists \(kn\) goals, \(k\) types, and \(n+|E|\) resources. Its requirement table has \(kn(n+|E|)\) entries, each equal to \(0\) or \(1\). The only nonintegral values are the masses \(1/k\), whose numerator and denominator require \(O(\log(k+1))\) bits.

Because \(k\leq n\), the construction has polynomial size and can be produced in polynomial time. Together with membership in \(\mathrm{NP}\), the equivalence proves \(\mathrm{NP}\)-completeness.

Moreover, the output parameter is exactly \(\tau=k\). The same construction is therefore a parameterized reduction proving \(\mathrm{W[1]}\)-hardness with respect to \(\tau\).

3. A witness bound and an XP algorithm

Lemma. If a successful selection exists, one exists containing at most \(\tau\) goals.

Proof. Let \(S\) be successful. For every support type \(t\), choose a goal \(g_t\in A_t\cap S\), and let \(S'=\{g_t:1\leq t\leq\tau\}\).

Since \(\tau\geq1\), the set \(S'\) is nonempty. It satisfies every type, and \(|S'|\leq\tau\). Furthermore, \(S'\subseteq S\), so nonnegativity of every requirement gives
\(\sum_{g\in S'}q_{g,r}\leq\sum_{g\in S}q_{g,r}\leq B_r\)
for every \(r\). Hence \(S'\) is successful. \(\square\)

This yields an exact algorithm:

  • Reject if \(m=0\) or any \(A_t\) is empty.
  • Compute every aggregate budget \(B_r\).
  • Enumerate all tuples \((g_1,\ldots,g_\tau)\) with \(g_t\in A_t\).
  • For each tuple, form its set of distinct goals and check every resource inequality.

Every tuple automatically satisfies all types. The lemma proves that a successful instance is accepted by some tuple.

There are at most \(m^\tau\) tuples. Pairwise comparison removes duplicates in \(O(\tau^2)\) comparisons, and resource checking uses \(O(\tau|R|)\) rational additions and comparisons. Including preprocessing, a valid bit-operation bound is
\(O\!\left(m^\tau\tau(\tau+|R|)L^2\right)\)
for \(m\geq1\).

Thus every fixed value of \(\tau\) gives a polynomial-time algorithm. This is an XP bound: its polynomial exponent depends on \(\tau\). The parameter-preserving hardness reduction rules out an FPT bound \(f(\tau)L^c\), with constant \(c\), unless \(\mathrm{FPT}=\mathrm{W[1]}\).
