The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), candidate groups with diversity bounds, reference committees \(W_P\) with representation bounds, and a finite support \(T^+\) of voter types with rational masses \(\mu_t>0\) summing to \(1\), where each type specifies a complete ranking and its voter-population memberships, decide whether there is a size-\(k\) committee \(W'\) satisfying all bounds and \(U_P(W')=U_Q(W')\) for every pair of populations \(P,Q\). For each nonempty population \(P\subseteq T^+\), define \(\bar b_P(c)=\sum_{t\in P}\mu_t b_t(c)/\sum_{t\in P}\mu_t\), where \(b_t(c)\) is candidate \(c\)’s Borda score in type \(t\), and \(U_P(W')=\sum_{c\in W'}\bar b_P(c)\).

A society is given by its support \(T^+\): the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Each type specifies a strict complete ranking of \(C\) and its population memberships; \(\tau\) counts supported types, not possible types.
Candidate attributes partition \(C\) into nonempty groups; voter attributes partition \(T^+\) into nonempty populations. Let \(\mathcal G\) and \(\mathcal P\) collect these groups and populations; overlap across attributes is allowed. Only the listed populations are compared.
For every \(G\in\mathcal G\), input an integer lower bound \(0\leq\ell_G^D\leq\min(k,|G|)\). For every \(P\in\mathcal P\), input a reference committee \(W_P\subseteq C\) of size \(k\) and an integer lower bound \(0\leq\ell_P^R\leq k\); reference committees are supplied data.

Writing \(b_t(c)\) for the standard Borda score, define \(\bar b_P(c)=\frac{\sum_{t\in P}\mu_t b_t(c)}{\sum_{t\in P}\mu_t}\) and \(U_P(S)=\sum_{c\in S}\bar b_P(c)\). The decision problem asks whether a feasible committee \(W'\) satisfies \(U_P(W')=U_Q(W')\) for every \(P,Q\in\mathcal P\).

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when:

  • there are exactly two populations, forming one partition of the supported types;
  • there is one candidate group, namely \(C\);
  • every lower bound is zero;
  • every mass is a positive dyadic rational;
  • \(\tau\leq 2m+2\);
  • a feasible committee is supplied.

The proof below constructs the mass-weighted Borda utilities directly. It does not require transferring the hardness result for population-level rankings in the [cited paper](https://arxiv.org/pdf/2211.12820).

1. Realizing prescribed utility differences

Write \(b(R)\) for the Borda-score vector of a strict ranking \(R\), with scores \(m-1,\ldots,0\). Let \(R^{\mathrm{rev}}\) denote its reverse. Coordinatewise,

\(b(R)+b(R^{\mathrm{rev}})=(m-1)\mathbf 1\).

Set \(h=(m-1)/2\).

Lemma. Suppose \(m\geq2\), and let \(d=(d_1,\ldots,d_m)\in\mathbb Z^m\) satisfy \(\sum_{i=1}^m d_i=0\). One can construct two disjoint populations \(P,Q\), each of mass \(1/2\), such that

\(\bar b_Q(c_i)=h,\qquad \bar b_P(c_i)=h+\dfrac{d_i}{2D}\),

where \(D\) is a positive power of two. The construction uses at most \(2m+2\) supported types and positive dyadic masses. Its encoding length is polynomial in the encoding length of \(d\) and in \(m\).

Proof. Put \(H=\sum_{i=1}^{m-1}|d_i|\), and choose a power of two \(D>H\).

For each \(i<m\) with \(d_i\neq0\), construct two rankings \(A_i,B_i\) satisfying

\(b(A_i)-b(B_i)=\operatorname{sgn}(d_i)(e_i-e_m)\),

where \(e_i\) is the \(i\)-th coordinate vector. Explicitly, first take rankings beginning respectively with \(c_i,c_m\) and \(c_m,c_i\), followed by all remaining candidates in the same fixed order. Their Borda-score difference is \(e_i-e_m\), since only two adjacent candidates have been exchanged. When \(d_i<0\), interchange the two rankings.

Fix any ranking \(R\). In population \(P\), assign the following global society masses:

  • mass \((D-H)/(4D)\) to each of \(R,R^{\mathrm{rev}}\);
  • for every \(i<m\) with \(d_i\neq0\), mass \(|d_i|/(4D)\) to each of \(A_i,B_i^{\mathrm{rev}}\).

All these masses are positive. Their sum is

\(\dfrac{D-H}{2D}+\sum_{i=1}^{m-1}\dfrac{|d_i|}{2D}=\dfrac12\).

In population \(Q\), assign mass \(1/4\) to each of \(R,R^{\mathrm{rev}}\). Thus the entire society has mass \(1\), and its populations form a partition.

Population \(Q\) has average score vector \(h\mathbf1\). For each gadget in \(P\),

\(b(A_i)+b(B_i^{\mathrm{rev}})=(m-1)\mathbf1+\operatorname{sgn}(d_i)(e_i-e_m)\).

Consequently, the unnormalized score vector of \(P\) is

\(\dfrac12h\mathbf1+\dfrac1{4D}\sum_{i=1}^{m-1}d_i(e_i-e_m)\).

The zero-sum hypothesis gives

\(\sum_{i=1}^{m-1}d_i(e_i-e_m)=d\).

Dividing by the population mass \(1/2\) proves

\(\bar b_P=h\mathbf1+d/(2D)\).

There are at most \(2(m-1)+2\) types in \(P\) and two in \(Q\). If identical ranking-and-membership pairs occur, merge them by adding their masses; this preserves all utilities, positivity, and dyadic encoding.

Finally, if each \(d_i\) has at most \(b\) bits, then \(H\) and \(D\) have \(O(b+\log(m+1))\) bits. There are \(O(m)\) rankings, each containing \(m\) candidate identifiers. Hence the construction has polynomial encoding length. \(\square\)

2. Reduction from PARTITION

We use the standard \(\mathrm{NP}\)-complete problem PARTITION: given positive binary-encoded integers \(a_1,\ldots,a_n\), decide whether some index set \(I\subseteq\{1,\ldots,n\}\) satisfies

\(2\sum_{i\in I}a_i=\sum_{i=1}^n a_i\).

Its \(\mathrm{NP}\)-completeness is a classical result of [Karp](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Let \(A=\sum_{i=1}^n a_i\). Create \(m=2n\) candidates and require committee size \(k=n\). Define

\(v_i=a_i\quad(1\leq i\leq n),\qquad v_i=0\quad(n<i\leq2n)\),

and set

\(d_i=2n\,v_i-A\quad(1\leq i\leq2n)\).

These integers have zero sum:

\(\sum_{i=1}^{2n}d_i=2n\sum_{i=1}^{2n}v_i-2nA=0\).

Apply the lemma to obtain the two populations \(P,Q\).

Use one candidate attribute with its sole group \(C\), and put \(\ell_C^D=0\). Set \(\ell_P^R=\ell_Q^R=0\). Supply

\(W=W_P=W_Q=\{c_1,\ldots,c_n\}\).

Every size-\(n\) committee is feasible, so the supplied committee satisfies the required feasibility promise.

For any size-\(n\) committee \(S\),

\(U_P(S)-U_Q(S)=\dfrac1{2D}\sum_{c_i\in S}d_i =\dfrac1{2D}\left(2n\sum_{c_i\in S}v_i-nA\right)\).

Thus

\(U_P(S)=U_Q(S)\quad\Longleftrightarrow\quad 2\sum_{c_i\in S}v_i=A\).

We verify both directions.

If the PARTITION instance is a yes-instance, choose \(I\subseteq\{1,\ldots,n\}\) with \(2\sum_{i\in I}a_i=A\). Select the corresponding candidates and add \(n-|I|\) candidates from the \(n\) zero-valued candidates. The resulting size-\(n\) committee is feasible and has equal population utilities.

Conversely, suppose a feasible committee \(S\) has equal population utilities. Let \(I=\{i\leq n:c_i\in S\}\). Since all other \(v_i\) are zero, the displayed equivalence gives

\(2\sum_{i\in I}a_i=A\).

Hence the PARTITION instance is a yes-instance.

Encoding size

Let \(N\) be the PARTITION input bit length. Each \(d_i\) has \(O(N+\log(n+1))\) bits. The lemma therefore produces an instance of bit length

\(O\!\left(n^2\log(n+1)+n(N+\log(n+1))\right)\),

constructible in polynomial time. Moreover,

\(m=2n,\qquad k=n,\qquad |\mathcal G|=1,\qquad |\mathcal P|=2,\qquad \tau\leq4n+2\).

This is a polynomial-time many-one reduction whose outputs always contain a feasible supplied committee. It proves the claimed restricted \(\mathrm{NP}\)-hardness.

3. Exact verification and membership in NP

Let \(g=|\mathcal G|\) and \(p=|\mathcal P|\). A certificate is a list of \(k\) distinct candidate identifiers, requiring \(O(k\log(m+1))\) bits.

Exact equality testing is polynomial-time; no numerical approximation is needed. Write each mass as \(\mu_t=u_t/q_t\), with positive integers \(u_t,q_t\), and define

\(Z=\prod_{t\in T^+}q_t,\qquad a_t=u_t(Z/q_t)\).

Then \(\mu_t=a_t/Z\). For every listed population \(P\), precompute

\(M_P=\sum_{t\in P}a_t,\qquad H_{P,c}=\sum_{t\in P}a_t b_t(c)\).

Because \(P\) is nonempty and every supported mass is positive, \(M_P>0\). For any committee \(S\),

\(U_P(S)=\dfrac{\sum_{c\in S}H_{P,c}}{M_P}\).

If \(p\geq1\), fix a listed population \(P_0\). Equality of all population utilities is equivalent to checking, for every \(P\),

\(\left(\sum_{c\in S}H_{P,c}\right)M_{P_0} =\left(\sum_{c\in S}H_{P_0,c}\right)M_P\).

Checking against one population suffices by transitivity of equality.

The total denominator bit length is at most \(L\), so \(Z\) has \(O(L)\) bits. Since the masses sum to \(1\),

\(\sum_t a_t=Z,\qquad M_P\leq Z,\qquad H_{P,c}\leq(m-1)Z\).

All committee sums and cross-products therefore have
\(O(L+\log(mk+1))\) bits. Cardinality and all lower bounds can also be checked by counting intersections. This establishes membership in \(\mathrm{NP}\).

Combined with Section 2, the problem is \(\mathrm{NP}\)-complete.

4. Explicit running-time bounds

The following are conservative bit-operation bounds, using schoolbook integer arithmetic. Define

\(B=L+\left\lceil\log_2(m\tau k+2)\right\rceil\),

\(A_0=L+m\tau(p+1)+m(g+p)\),

and

\(A_1=k(g+p+1)+p\).

Preprocessing the Borda scores, group and reference-committee membership tables, and the integers from Section 3 takes

\(O(A_0B^2)\).

After preprocessing, a size-\(k\) committee can be checked in

\(O(A_1B^2)\).

Indeed, intersection counts require \(O(k(g+p))\) table accesses and additions; utility sums require \(O(kp)\) additions; and equality testing requires \(O(p)\) integer multiplications and comparisons.

Thus a certificate can be verified in

\(O\!\left((A_0+A_1)B^2\right)\),

which is polynomial in the total input length.

Enumerating all size-\(k\) committees gives a deterministic decision algorithm with running time

\(O\!\left(\left[A_0+\binom{m}{k}A_1\right]B^2\right)\).

In particular, this is polynomial for fixed \(k\), or for fixed \(m-k\). The unrestricted problem is \(\mathrm{NP}\)-hard, so a polynomial-time algorithm for all instances would imply \(\mathrm P=\mathrm{NP}\).

5. Easy boundary cases

The hardness statement concerns variable committee size and at least two populations. Several cases are immediate:

  • If \(p\leq1\), utility equality is vacuous, and the supplied feasible committee proves a yes-instance.
  • If \(k=m\), the unique committee is \(C\), which is feasible by the supplied-committee promise. Every ranking has total Borda score \(m(m-1)/2\), so every population assigns \(C\) that same utility.
  • If \(k=1\), checking all \(m\) singleton committees gives a polynomial-time algorithm, as covered by the bound above.

These cases do not affect the reduction, which uses \(k=m/2\).
