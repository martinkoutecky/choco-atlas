The continuous mirror question, as graded

Given a finite hypothesis set \(\Theta\), a nonatomic unit-mass society with finitely many types \(t\) of masses \(\mu_t\), type-specific signal likelihoods \(L_t(\cdot\mid\theta)\), and a strongly connected type-interaction kernel, determine conditions under which the partial-sharing update (2)–(4), extended using type-level interaction averages, makes almost every agent's belief converge to the transmitted hypothesis \(\theta_{\mathrm{TX}}\), or instead yields the theorem's alternative collapse regime.

Packaged proof task (what the prover saw — nothing else)

A nonatomic unit-mass society is given by its support: \(\tau\) types with positive binary-rational masses \(\mu_t\), with \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types. Let \(m=|\Theta|\geq2\), and fix the true hypothesis \(\theta_0\in\Theta\) and transmitted hypothesis \(\theta_{\mathrm{TX}}\in\Theta\). Let \(L\) denote the bit length of the rational input data; any running-time bounds must also account for the likelihood representation.
Each type has likelihood pmfs or densities \(L_t(\cdot\mid\theta)\) on a common type-specific signal space, with all pairwise log-likelihood ratios integrable under \(L_t(\cdot\mid\theta_0)\). Signals are identically distributed and independent over time. Initially, all agents of type \(t\) have the same strictly positive probability vector \(b_{t,0}\).
The fixed interaction kernel has nonnegative binary-rational entries \(K_{st}\), where \(s\) sends to \(t\), and satisfies \(\sum_s\mu_sK_{st}=1\). Its positive-entry graph is strongly connected and \(K_{tt}>0\) for at least one type.
Define \(\psi_{t,i}(\theta;x)\) by the Bayesian update from \(b_{t,i-1}\) using \(L_t(x\mid\theta)\), and set \(\widehat\psi_{t,i}(\theta_{\mathrm{TX}};x)=\psi_{t,i}(\theta_{\mathrm{TX}};x)\) and \(\widehat\psi_{t,i}(\theta;x)=(1-\psi_{t,i}(\theta_{\mathrm{TX}};x))/(m-1)\) otherwise.
Specify the within-type population average exactly by expectation: \(q_{t,i}(\theta)=\sum_s\mu_sK_{st}\mathbb E_{X\sim L_s(\cdot\mid\theta_0)}[\log\widehat\psi_{s,i}(\theta;X)]\), and \(b_{t,i}(\theta)=\exp(q_{t,i}(\theta))/\sum_{\eta\in\Theta}\exp(q_{t,i}(\eta))\). Every type member adopts this vector, including when combining information from its own type.

Under what conditions does population-almost-every agent satisfy \(b_{t,i}(\theta_{\mathrm{TX}})\to1\), and under what conditions does it instead satisfy \(b_{t,i}(\theta_{\mathrm{TX}})\to0\) and \(b_{t,i}(\theta)\to1/(m-1)\) for every \(\theta\neq\theta_{\mathrm{TX}}\)?

For finite networks with identical likelihoods, strict KL comparisons between the transmitted likelihood and the uniform mixture of the other likelihoods establish the two collapse regimes, including truth learning when the transmitted hypothesis is true and the mixture differs from it. [Source](https://arxiv.org/abs/1910.13889).
Heterogeneous finite networks have corresponding Perron-weighted KL criteria. [Source](https://arxiv.org/pdf/2006.13659). No result for the specified nonatomic expectation-averaged model was located.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Criterion and complete result. The two collapse regimes are characterized exactly by a Perron-weighted KL comparison. Equality produces a third regime: every type converges to strictly interior beliefs.

For each supported type \(s\), define the true likelihood, transmitted likelihood, and uniform mixture of the remaining likelihoods by

\[ P_s=L_s(\cdot\mid\theta_0),\qquad T_s=L_s(\cdot\mid\theta_{\mathrm{TX}}),\qquad M_s=\frac{1}{m-1}\sum_{\theta\neq\theta_{\mathrm{TX}}}L_s(\cdot\mid\theta). \]

Define the matrix \(B\) by \(B_{ts}=\mu_sK_{st}\). Thus \(B\) is row-stochastic. Let \(\pi\) be its stationary probability vector:

\[ \pi^\top B=\pi^\top,\qquad \sum_s\pi_s=1,\qquad \pi_s>0. \]

The graph assumptions guarantee that this vector exists and is unique, as verified below. Set

\[ \delta_s=\mathbb E_{P_s}\!\left[\log\frac{T_s(X)}{M_s(X)}\right] =D(P_s\Vert M_s)-D(P_s\Vert T_s), \qquad \Delta=\sum_s\pi_s\delta_s. \]

All these expectations and divergences are finite under the stated integrability assumption.

The complete characterization is:

  • Population-almost-every agent satisfies \(b_{t,i}(\theta_{\mathrm{TX}})\to1\) if and only if \(\Delta>0\).
  • Population-almost-every agent satisfies \(b_{t,i}(\theta_{\mathrm{TX}})\to0\) and \(b_{t,i}(\theta)\to1/(m-1)\) for every \(\theta\neq\theta_{\mathrm{TX}}\) if and only if \(\Delta<0\).
  • If \(\Delta=0\), every type’s belief vector converges, and every limiting coordinate is strictly positive. Neither collapse occurs.

The weights are \(\pi_s\), generally different from the population masses \(\mu_s\). Equivalently, they satisfy \(\pi_s=\mu_s\sum_t\pi_tK_{st}\).

The strict comparisons agree with the finite-network criterion without self-awareness in Theorem 3 of [Bordignon, Matta, and Sayed](https://arxiv.org/pdf/2006.13659). The following proof applies directly to the specified expectation-averaged model and also settles equality.

Well-definedness of the updates. Fix a type \(s\), and take any strictly positive prior vector \(b\). On a set of full \(P_s\)-measure, define

\[ R_\theta(X)=\log\frac{L_s(X\mid\theta)}{P_s(X)}. \]

Each \(R_\theta\) is finite and integrable by hypothesis. Since there are finitely many hypotheses, \(H(X)=\max_\theta|R_\theta(X)|\) is integrable.

For any probability weights \(w_\theta\),

\[ e^{-H(X)}\leq\sum_\theta w_\theta e^{R_\theta(X)} \leq e^{H(X)}. \]

Consequently, the logarithm of this sum is integrable. The Bayesian posterior satisfies

\[ \log\psi_s(\theta;X) =\log b(\theta)+R_\theta(X) -\log\sum_\eta b(\eta)e^{R_\eta(X)}, \]

so every log-posterior coordinate is integrable.

Writing \(a=b(\theta_{\mathrm{TX}})\) and \(w_\theta=b(\theta)/(1-a)\) for the non-transmitted hypotheses gives

\[ \log(1-\psi_s(\theta_{\mathrm{TX}};X)) =\log(1-a) +\log\sum_{\theta\neq\theta_{\mathrm{TX}}}w_\theta e^{R_\theta(X)} -\log\sum_\eta b(\eta)e^{R_\eta(X)}. \]

This is integrable as well. Hence every expected log-message in the question is finite. Exponentiation and normalization therefore produce a strictly positive belief vector. Induction proves that every update is well-defined.

The same bound, using uniform weights on the non-transmitted hypotheses, shows that \(\log(M_s/P_s)\) is integrable. Thus both KL divergences defining \(\delta_s\) are finite, and their difference equals the displayed expectation.

Exact reduction to a linear recursion. For every signal, all non-transmitted coordinates of \(\widehat\psi_{s,i}\) are equal. Their expected logarithms, their combined values \(q_{t,i}\), and their normalized beliefs are therefore equal. In particular, for every \(i\geq1\),

\[ b_{t,i}(\theta)=\frac{1-b_{t,i}(\theta_{\mathrm{TX}})}{m-1} \qquad(\theta\neq\theta_{\mathrm{TX}}). \]

Define the log-belief ratio \(r_{t,i}=\log\!\bigl(b_{t,i}(\theta_{\mathrm{TX}})/b_{t,i}(\theta)\bigr)\) for \(i\geq1\), using any non-transmitted \(\theta\). This is independent of that choice.

For \(i\geq2\), put \(p=b_{s,i-1}(\theta_{\mathrm{TX}})\). The total Bayesian numerator for the non-transmitted hypotheses is

\[ \sum_{\eta\neq\theta_{\mathrm{TX}}} b_{s,i-1}(\eta)L_s(X\mid\eta) =(1-p)M_s(X). \]

It follows exactly that

\[ \frac{\widehat\psi_{s,i}(\theta_{\mathrm{TX}};X)} {\widehat\psi_{s,i}(\theta;X)} =\frac{(m-1)p}{1-p}\frac{T_s(X)}{M_s(X)} =e^{r_{s,i-1}}\frac{T_s(X)}{M_s(X)}. \]

The final normalization cancels in a ratio of beliefs. Taking the prescribed expectations therefore gives

\[ r_{t,i}=\sum_s B_{ts}(r_{s,i-1}+\delta_s), \qquad\text{or}\qquad r_i=Br_{i-1}+B\delta. \]

The possibly unequal initial non-transmitted beliefs affect only the first update. Explicitly, define the finite vector \(u\) by

\[ u_s=\mathbb E_{P_s}\!\left[ \log\frac{(m-1)b_{s,0}(\theta_{\mathrm{TX}})T_s(X)} {\sum_{\eta\neq\theta_{\mathrm{TX}}}b_{s,0}(\eta)L_s(X\mid\eta)} \right]. \]

Then \(r_1=Bu\). Iterating the recursion yields, for every \(i\geq1\),

\[ r_i=B^{i-1}r_1+\sum_{k=1}^{i-1}B^k\delta. \]

Perron analysis, including equality. Because all masses are positive, \(B_{ts}>0\) exactly when \(K_{st}>0\). Thus \(B\) is irreducible, and the stipulated positive diagonal entry gives a self-loop. An irreducible finite graph with a self-loop is aperiodic, so \(B\) is primitive.

The Perron–Frobenius theorem for primitive stochastic matrices now applies: the stationary vector \(\pi\) is unique and strictly positive, and, writing \(\Pi=\mathbf1\pi^\top\), there are constants \(C<\infty\) and \(\rho\in(0,1)\) such that \(\|B^k-\Pi\|\leq C\rho^k\). The geometric bound follows from the simplicity of eigenvalue \(1\) and the fact that all remaining eigenvalues have modulus strictly less than \(1\).

In particular, the vector

\[ h=\sum_{k=1}^{\infty}(B^k-\Pi)\delta \]

is finite. Substitution into the exact recursion gives

\[ r_i=(i-1)\Delta\mathbf1 +\mathbf1(\pi^\top r_1)+h+o(1). \]

Indeed, the error is precisely

\[ (B^{i-1}-\Pi)r_1 -\sum_{k=i}^{\infty}(B^k-\Pi)\delta, \]

and both terms tend to zero by the geometric bound.

Recovering beliefs from the log ratio gives

\[ b_{t,i}(\theta_{\mathrm{TX}}) =\frac{e^{r_{t,i}}}{e^{r_{t,i}}+m-1}, \qquad b_{t,i}(\theta) =\frac{1}{e^{r_{t,i}}+m-1} \quad(\theta\neq\theta_{\mathrm{TX}}). \]

If \(\Delta>0\), every \(r_{t,i}\to+\infty\), proving transmitted collapse. If \(\Delta<0\), every \(r_{t,i}\to-\infty\), proving uniform collapse onto the other hypotheses.

If \(\Delta=0\), every \(r_{t,i}\) converges to the finite number \(c_t=\pi^\top r_1+h_t\). Hence

\[ \lim_i b_{t,i}(\theta_{\mathrm{TX}}) =\frac{e^{c_t}}{e^{c_t}+m-1}\in(0,1), \qquad \lim_i b_{t,i}(\theta) =\frac{1}{e^{c_t}+m-1}>0. \]

This also proves necessity of both strict inequalities. At equality, the limiting values can differ across types.

Finally, every supported type has positive mass, and all its members adopt the same deterministic vector. Consequently, each population-almost-everywhere statement is equivalent to the corresponding statement for every supported type. No probabilistic limit theorem for a continuum of signals is needed.

Truth transmission and a sharp obstruction. Suppose \(\theta_{\mathrm{TX}}=\theta_0\). Then \(T_s=P_s\), so \(\delta_s=D(P_s\Vert M_s)\geq0\). Gibbs’ inequality applies because these are probability laws and the divergences are finite; equality holds exactly when the two laws agree.

Since every \(\pi_s>0\), truth learning therefore occurs if and only if at least one supported type satisfies \(M_s\neq P_s\) as probability laws. If all uniform mixtures equal their respective true laws, then \(\Delta=0\), and the interior-limit result applies.

Individual distinguishability of every false hypothesis is insufficient. For example, take one type, mass \(1\), kernel entry \(K_{11}=1\), three hypotheses, and transmit the true hypothesis. On a two-point signal space, let

\[ P=(1/2,1/2),\qquad L(\cdot\mid\theta_1)=(1/4,3/4),\qquad L(\cdot\mid\theta_2)=(3/4,1/4). \]

Both false likelihoods differ from the truth, but their uniform mixture is \(P\). All likelihoods are strictly positive binary-rational pmfs, so the integrability assumptions hold. With uniform initial beliefs, the transmitted posterior is always \(1/3\), and the reconstructed message has all three coordinates equal to \(1/3\). Thus the belief vector remains uniform forever.

For \(m=2\), the mixture contains only the other likelihood. Accordingly, transmitting the truth produces collapse to it exactly when some type distinguishes the two likelihoods; transmitting the false hypothesis produces rejection under exactly the same condition.

Likelihood representation. The criterion is mathematically exact. Evaluating it requires the likelihood-dependent expectations defining \(\delta_s\). No running-time bound depending only on the rational kernel input is asserted for arbitrary pmfs or densities without a specified likelihood representation.
