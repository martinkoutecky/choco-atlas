Theorem 5.1 — class: algorithmic

The continuous mirror question, as graded

Given \(m\) binary public issues, \(\tau\) complete types \(t\) with preferred sides \(a_{tj}\), rational CES weights and budgets \(b_t\), rational masses \(\mu_t>0\) summing to one, and rational tolerance \(\varepsilon>0\), compute an \(\varepsilon\)-approximate pairwise-pricing market equilibrium in time polynomial in \(m,\tau,L,1/\varepsilon\). The output is a common randomized decision \(z\), per-type bundles \(y_t\), and symmetric nonnegative prices \(P_{tu,j}\) for disagreeing type pairs; with \(q_{tj}=\sum_{u:a_{uj}\ne a_{tj}}\mu_uP_{tu,j}\), each \(y_t\) maximizes its CES utility subject to \(\sum_jq_{tj}y_{tj}\le b_t\), each disagreeing pair satisfies \(y_{tj}+y_{uj}\le1+\varepsilon\) and \(P_{tu,j}>\varepsilon\Rightarrow y_{tj}+y_{uj}\ge1-\varepsilon\), and \(z^{j,0}+z^{j,1}\le1+\varepsilon\), \(y_{tj}\le z^{j,a_{tj}}+\varepsilon\), and \(q_{tj}>\varepsilon\Rightarrow y_{tj}\ge z^{j,a_{tj}}-3\varepsilon\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) complete types with positive masses \(\mu_t\), each a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) binary issues; type \(t\) prefers \(a_{tj}\in\{0,1\}\), and both sides of every issue occur in the support. Each type has a positive rational budget \(b_t\) per individual and nonnegative rational weights \(w_{tj}\), not all zero.
Fix a rational CES parameter \(\rho\in(-\infty,0)\cup(0,1)\). Use \(u_t(y)=(\sum_{j:w_{tj}>0}(w_{tj}y_j)^\rho)^{1/\rho}\) on \(\mathbb R_{\ge0}^m\), extended continuously to the boundary. Let \(L\) be the total binary input length and let \(0<\varepsilon<1\) be rational.
An \(\varepsilon\)-approximate pairwise-pricing equilibrium consists of \(z\in[0,1]^{m\times2}\), bundles \(y_t\in\mathbb R_{\ge0}^m\), and symmetric prices \(P_{tu,j}=P_{ut,j}\ge0\) for pairs with \(a_{tj}\ne a_{uj}\). Define \(q_{tj}=\sum_{u:a_{uj}\ne a_{tj}}\mu_uP_{tu,j}\).
Require \(y_t\in\arg\max\{u_t(v):v\in\mathbb R_{\ge0}^m,\ \sum_jq_{tj}v_j\le b_t\}\), with exact utility maximization.
For every disagreeing pair require \(y_{tj}+y_{uj}\le1+\varepsilon\) and \(P_{tu,j}>\varepsilon\Rightarrow y_{tj}+y_{uj}\ge1-\varepsilon\).
For every issue and type require \(z^{j,0}+z^{j,1}\le1+\varepsilon\), \(y_{tj}\le z^{j,a_{tj}}+\varepsilon\), and \(q_{tj}>\varepsilon\Rightarrow y_{tj}\ge z^{j,a_{tj}}-3\varepsilon\). Output numbers may be represented by finite arithmetic circuits with rational constants and rational-power gates on their real domains.

Is computing such an equilibrium possible in time polynomial in \(m,\tau,L,1/\varepsilon\), for each fixed \(\rho\), or is this search problem NP-hard?

For finite societies, tâtonnement convergence in \(O(\kappa(m,n,\delta))\) steps for nested utilities lifts to public decisions with error \(3\delta\) in \(O(\kappa(n^2m,n,\delta))\) steps; the CES application claims polynomial convergence. [Garg–Goel–Plaut](https://arxiv.org/pdf/1807.10836v4)
Efficient tâtonnement convergence is known for finite Fisher markets with nested CES–Leontief utilities. [Avigdor-Elgrabli–Rabani–Yadgar](https://arxiv.org/pdf/1401.6637) No result settling the exact mass-weighted problem specified above was located.

Modeling choices made when packaging the task

  • The CES parameter was unspecified; fixed a common rational parameter in the nonlinear range used by the polynomial-convergence application, with polynomial bounds allowed to depend on that fixed parameter.
  • Specified nonnegative rational weights, at least one positive weight per type, the powered-weight CES convention, omission of zero-weight coordinates, and continuous boundary extension.
  • Specified positive per-individual budgets; no additional budget normalization is imposed.
  • Excluded unanimous issues because pairwise expansion otherwise has empty disagreement sets and can assign zero prices to valued, unbounded demand coordinates; the latest full version retains this omission.
  • Retained demand optimization over the entire nonnegative orthant and placed the common decision coordinates in the unit interval.
  • Restricted the tolerance to the nondegenerate range between zero and one and defined the total binary input length.
  • Allowed exact symbolic output using arithmetic circuits with rational-power gates, since exact CES demands need not be rational.

Result

For every fixed rational \(\rho\in(-\infty,0)\cup(0,1)\), the specified search problem is polynomial-time solvable.

The algorithm computes rational pair prices and represents the bundles by rational-power circuits. The bundles maximize utility exactly. The proof uses a regularized convex dual whose dimension is polynomial in the support size, without expanding types into individual agents.

1. Exact CES demand at positive prices

Fix a type, suppress its index, and write \(J=\{j:w_j>0\}\). Define

\(\displaystyle \sigma=\frac1{1-\rho}>0,\qquad c_j=w_j^{\rho/(1-\rho)}\quad(j\in J).\)

For a positive price vector \(r\) and a positive budget \(B\), let

\(\displaystyle D(r)=\sum_{k\in J}c_k r_k^{1-\sigma},\qquad d_j(r)=\frac{B c_j r_j^{-\sigma}}{D(r)}\quad(j\in J),\)

and set \(d_j(r)=0\) for \(j\notin J\). Then

\(\displaystyle \sum_jr_jd_j(r)=B.\)

We first justify that this is exact utility demand.

On the positive supported coordinates, put \(\ell(y)=\log u(y)\). For a direction \(v\), define

\(\displaystyle s_j=\frac{(w_jy_j)^\rho}{\sum_{k\in J}(w_ky_k)^\rho},\qquad h_j=\frac{v_j}{y_j}.\)

Direct differentiation gives

\(\displaystyle v^{\mathsf T}\nabla^2\ell(y)v=(\rho-1)\sum_{j\in J}s_jh_j^2-\rho\left(\sum_{j\in J}s_jh_j\right)^2.\)

For \(0<\rho<1\), this is negative for every nonzero supported direction. For \(\rho<0\), the inequality

\(\displaystyle \left(\sum_js_jh_j\right)^2\le\sum_js_jh_j^2\)

bounds the displayed expression above by \(-\sum_js_jh_j^2\). Thus \(\ell\) is strictly concave on the positive supported coordinates. Its concavity extends to the boundary, with the convention \(\log 0=-\infty\), by taking limits.

Also,

\(\displaystyle \frac{\partial\ell}{\partial y_j}=\frac{w_j^\rho y_j^{\rho-1}}{\sum_{k\in J}(w_ky_k)^\rho}.\)

Substitution of \(d(r)\) shows that

\(\displaystyle B\nabla\ell(d(r))=r\)

on the supported coordinates. Concavity therefore proves that \(d(r)\), with zero unsupported coordinates, maximizes

\(\displaystyle B\log u(y)-r\cdot y\)

over all nonnegative bundles. Unsupported coordinates have positive prices and are optimally zero.

If \(r\cdot v\le B=r\cdot d(r)\), this maximizing property implies

\(\displaystyle B\log u(v)\le B\log u(d(r))+r\cdot v-B\le B\log u(d(r)).\)

Bundles with zero utility satisfy the desired comparison automatically. Consequently,

\(\displaystyle d(r)\in\arg\max\{u(v):v\ge0,\ r\cdot v\le B\}.\)

These formulas use only arithmetic and fixed rational powers.

2. A convex dual on the support

Let \(E\) contain one unordered triple \(e=\{t,u,j\}\) for each disagreeing pair on each issue, and let \(N=|E|\). Both sides occur on every issue, so \(N\ge1\), and \(N\le m\tau^2\).

Define the aggregate type budgets and their sum by

\(\displaystyle B_t=\mu_tb_t,\qquad B=\sum_tB_t>0.\)

For strictly positive multipliers \(\lambda=(\lambda_e)_{e\in E}\), define

\(\displaystyle r_{tj}(\lambda)=\sum_{u:a_{uj}\ne a_{tj}}\lambda_{\{t,u,j\}}.\)

Every \(r_{tj}\) is positive. Let \(y_t(\lambda)\) be the exact CES demand from Section 1 at prices \(r_t(\lambda)\) and budget \(B_t\).

For positive \(r\), define

\(\displaystyle f_t(r)=\max_{v\ge0}\{B_t\log u_t(v)-r\cdot v\}.\)

This function is convex because it is a supremum of affine functions of \(r\). The demand formula yields the explicit expression

\(\displaystyle f_t(r)=B_t\log B_t+\frac{B_t}{\sigma-1}\log D_t(r)-B_t.\)

Here \(\sigma-1\ne0\), and \(D_t\) uses the supported weights of type \(t\). Differentiating gives

\(\displaystyle \frac{\partial f_t}{\partial r_j}=-y_{tj}.\)

Hence the convex function

\(\displaystyle F(\lambda)=\sum_{e\in E}\lambda_e+\sum_tf_t(r_t(\lambda))\)

satisfies

\(\displaystyle \frac{\partial F}{\partial\lambda_{\{t,u,j\}}}=1-y_{tj}(\lambda)-y_{uj}(\lambda).\)

The conversion to the required prices will be

\(\displaystyle P_{tu,j}=\frac{\lambda_{\{t,u,j\}}}{\mu_t\mu_u}.\)

Indeed, these prices are symmetric and satisfy

\(\displaystyle q_{tj}=\sum_{u:a_{uj}\ne a_{tj}}\mu_uP_{tu,j}=\frac{r_{tj}}{\mu_t}.\)

Therefore \(r_t\cdot v\le B_t\) is equivalent to \(q_t\cdot v\le b_t\). Thus every demand \(y_t(\lambda)\) already satisfies the task’s exact utility-maximization requirement.

3. Regularization and bounds on its minimizer

Put

\(\displaystyle \nu=\min_t\mu_t>0,\qquad h=\frac{\nu^2\varepsilon^2}{64},\)

and consider

\(\displaystyle \Phi(\lambda)=F(\lambda)-h\sum_{e\in E}\log\lambda_e,\qquad \lambda>0.\)

We establish that \(\Phi\) has a unique minimizer and bound its coordinates explicitly.

Let \(S=\sum_e\lambda_e\). For every type, \(\sum_jr_{tj}\le S\). Testing the bundle whose every coordinate equals \(B_t/S\) gives

\(\displaystyle f_t(r_t)\ge B_t\log u_t(\mathbf1)+B_t\log B_t-B_t\log S-B_t.\)

Since \(\lambda_e\le S\), there is a finite constant \(C\), independent of \(\lambda\), such that

\(\displaystyle \Phi(\lambda)\ge S-(B+Nh)\log S+C.\)

The right-hand side tends to infinity both as \(S\) tends to zero and as \(S\) tends to infinity. Moreover, with \(S\) bounded above and bounded away from zero, any coordinate tending to zero makes its barrier term tend to infinity; the other terms have uniform lower bounds. Thus every sublevel set is contained in a compact subset of the positive orthant. Continuity gives a minimizer \(\lambda^*\). The strictly convex barrier makes that minimizer unique.

Stationarity gives, for every \(e=\{t,u,j\}\),

\[\displaystyle 1-y_{tj}(\lambda^*)-y_{uj}(\lambda^*)=\frac h{\lambda_e^*}.\tag{1}\]

Because the demands are nonnegative, this implies \(\lambda_e^*\ge h\).

Multiplying all stationarity equations by their respective multipliers and summing gives

\(\displaystyle 0=\sum_e\lambda_e^*-\sum_t\sum_jr_{tj}(\lambda^*)y_{tj}(\lambda^*)-Nh.\)

Every type spends exactly \(B_t\), so

\(\displaystyle \sum_e\lambda_e^*=B+Nh.\)

Consequently,

\[\displaystyle h\le\lambda_e^*\le B+Nh\quad(e\in E).\tag{2}\]

4. Computing a sufficiently accurate rational multiplier

Define

\(\displaystyle H=2(B+Nh),\qquad K_0=[h/2,H]^N.\)

By (2), \(\lambda^*\) lies in the interior of this rational box. We now give quantitative bounds sufficient for polynomial-time convex optimization.

Throughout \(K_0\),

\(\displaystyle r_{tj}\ge h/2,\qquad 0\le y_{tj}\le\frac{B_t}{r_{tj}}\le\frac{2B}{h}.\)

For a supported coordinate, write

\(\displaystyle s_{tk}=\frac{c_{tk}r_{tk}^{1-\sigma}}{D_t(r_t)}.\)

Differentiating demand gives, for supported \(j,k\),

\(\displaystyle \frac{\partial y_{tj}}{\partial r_{tk}}=y_{tj}\left(-\frac{\sigma\,\mathbf1_{j=k}}{r_{tj}}-\frac{(1-\sigma)s_{tk}}{r_{tk}}\right).\)

Derivatives involving an unsupported demand coordinate or an unsupported price coordinate are zero. Since \(0\le s_{tk}\le1\), all these derivatives have absolute value at most

\(\displaystyle A=\frac{4B\bigl(\sigma+|1-\sigma|\bigr)}{h^2}.\)

A multiplier affects at most one price coordinate of any given type. Therefore each entry of \(\nabla^2F\) has absolute value at most \(2A\). The barrier contributes a diagonal Hessian whose entries are at most \(4/h\). Thus

\[\displaystyle \|\nabla^2\Phi(\lambda)\|_2\le K:=1+2NA+\frac4h\quad(\lambda\in K_0).\tag{3}\]

On the other hand, convexity of \(F\) and the barrier Hessian imply

\[\displaystyle \nabla^2\Phi(\lambda)\succeq aI,\qquad a:=\frac h{H^2}>0.\tag{4}\]

An objective Lipschitz bound is also explicit: each gradient coordinate has absolute value at most \(3+4B/h\), so we may use

\(\displaystyle G=N(3+4B/h).\)

We use the standard approximate-oracle ellipsoid theorem: minimizing a differentiable convex function on a rational box to additive accuracy \(\xi\) takes time polynomial in the dimension, the box’s encoding and logarithmic geometric bounds, the logarithmic Lipschitz bound, and \(\log(1/\xi)\), provided function values and gradients can be approximated to requested precision in polynomial time. Strong convexity converts objective accuracy into distance accuracy. An approximate-oracle formulation is given in [Appendix A, Corollary 14, of Coester–Cosson](https://drops.dagstuhl.de/storage/00lipics/lipics-vol374-icalp2026/html/LIPIcs.ICALP.2026.65/LIPIcs.ICALP.2026.65.html).

All oracle hypotheses hold here:

  • The box has rational bounds and known positive inner radius and finite outer radius.
  • The formulas above compute values and gradients using arithmetic, fixed rational powers of positive numbers, and logarithms.
  • On the box, every positive argument in these formulas is between \(2^{-p}\) and \(2^p\) for a polynomial \(p\) in the input length, because \(\rho\) is fixed.
  • Fixed rational powers can be approximated by root bisection. Logarithms can be approximated by range reduction and a geometrically convergent series. Polynomially many guard bits suffice for all compositions.

In particular, the oracle running time is polynomial in the input length and the requested number of precision bits.

Set

\(\displaystyle d=\frac{\varepsilon}{16K},\qquad \xi=\frac a2d^2.\)

Compute a rational \(\widehat\lambda\in K_0\) such that

\(\displaystyle \Phi(\widehat\lambda)-\Phi(\lambda^*)\le\xi.\)

By (4),

\(\displaystyle \|\widehat\lambda-\lambda^*\|_2\le\sqrt{2\xi/a}=d.\)

By (3) and \(\nabla\Phi(\lambda^*)=0\),

\[\displaystyle \|\nabla\Phi(\widehat\lambda)\|_\infty\le Kd=\varepsilon/16.\tag{5}\]

The rational parameters \(h,H,A,K,a,d,\xi\) have polynomial encoding length. Thus exponentially small masses require polynomially many precision bits. They do not cause an exponential iteration count.

5. Pairwise conditions

Output

\(\displaystyle P_{tu,j}=\frac{\widehat\lambda_{\{t,u,j\}}}{\mu_t\mu_u},\qquad y_t=y_t(\widehat\lambda).\)

Exact demand optimality follows from Sections 1–2.

For \(e=\{t,u,j\}\), equation (5) gives

\[\displaystyle 1-y_{tj}-y_{uj}=\frac h{\widehat\lambda_e}+g_e,\qquad |g_e|\le\varepsilon/16.\tag{6}\]

Since \(h/\widehat\lambda_e>0\),

\[\displaystyle y_{tj}+y_{uj}\le1+\varepsilon/16.\tag{7}\]

If \(P_{tu,j}>\varepsilon\), then

\(\displaystyle \widehat\lambda_e>\mu_t\mu_u\varepsilon\ge\nu^2\varepsilon,\)

so \(h/\widehat\lambda_e<\varepsilon/64\). Equation (6) therefore gives

\[\displaystyle y_{tj}+y_{uj}\ge1-\frac{5\varepsilon}{64}.\tag{8}\]

Both required pairwise conditions follow.

6. Public decisions and consistency

For each issue and side, define

\(\displaystyle X_{j,a}=\max_{t:a_{tj}=a}y_{tj},\qquad z^{j,a}=\min\{1,X_{j,a}\}.\)

The maxima are over nonempty sets. Applying (7) to types attaining the two maxima yields

\(\displaystyle X_{j,0}+X_{j,1}\le1+\varepsilon/16.\)

Thus \(z\in[0,1]^{m\times2}\) and

\(\displaystyle z^{j,0}+z^{j,1}\le1+\varepsilon/16\le1+\varepsilon.\)

Each \(X_{j,a}\le1+\varepsilon/16\). Consequently, every type satisfies

\(\displaystyle y_{tj}\le z^{j,a_{tj}}+\varepsilon/16\le z^{j,a_{tj}}+\varepsilon.\)

Finally, suppose \(q_{tj}>\varepsilon\). If every disagreeing pair price were at most \(\varepsilon\), then

\(\displaystyle q_{tj}\le\varepsilon\sum_{u:a_{uj}\ne a_{tj}}\mu_u\le\varepsilon,\)

a contradiction. Hence some opposing type \(u\) has \(P_{tu,j}>\varepsilon\).

For any type \(s\) agreeing with \(t\) on issue \(j\), equations (7) and (8) give

\(\displaystyle y_{sj}+y_{uj}\le1+\varepsilon/16,\qquad y_{tj}+y_{uj}\ge1-5\varepsilon/64.\)

Subtracting yields \(y_{sj}-y_{tj}\le9\varepsilon/64\). Taking the maximum over such \(s\),

\(\displaystyle y_{tj}\ge X_{j,a_{tj}}-\frac{9\varepsilon}{64}\ge z^{j,a_{tj}}-3\varepsilon.\)

This proves the last required implication.

7. Output representation and running time

The prices are rational. Each supported demand coordinate has the exact circuit representation

\(\displaystyle y_{tj}=\frac{B_t\,w_{tj}^{\rho/(1-\rho)}\,r_{tj}^{-1/(1-\rho)}}{\sum_{k:w_{tk}>0}w_{tk}^{\rho/(1-\rho)}r_{tk}^{-\rho/(1-\rho)}}.\)

All powered arguments are positive. Unsupported demand coordinates are zero.

The public decisions also have permitted circuit representations, because

\(\displaystyle \max\{x,y\}=\frac{x+y+\bigl((x-y)^2\bigr)^{1/2}}2,\qquad \min\{x,y\}=\frac{x+y-\bigl((x-y)^2\bigr)^{1/2}}2.\)

The square-root arguments are nonnegative. Iterating these formulas computes the required maxima and clipping operations with polynomially many gates.

There are at most \(m\tau^2\) multiplier variables. All optimization parameters, oracle precisions, rational output constants, and circuit sizes are polynomially bounded in the input length for fixed \(\rho\). The running time is polynomial in \(m,\tau,L,\log(1/\varepsilon)\), with the rational encoding of \(\varepsilon\) included in the input length, and therefore satisfies the requested polynomial bound in \(m,\tau,L,1/\varepsilon\).
