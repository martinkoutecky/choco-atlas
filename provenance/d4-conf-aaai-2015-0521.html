Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given finitely many types \(T\) with rational masses \(\mu_t\), a local ASP program for each type with feasible integral packages \(\mathcal S_t\), package resource vectors \(h_{t,S}\), weighted scores \(u_t(S)\), and rational per-capita resource bounds \(b\), compute a feasible allocation \(x_{t,S}\ge 0\) minimizing \(\sum_{t\in T}\sum_{S\in\mathcal S_t}x_{t,S}u_t(S)\), subject to \(\sum_{S\in\mathcal S_t}x_{t,S}=\mu_t\) and \(\sum_{t,S}x_{t,S}h_{t,S}\le b\), or report infeasibility.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
For each type, the input contains a finite ground normal or disjunctive ASP program \(P_t\) over an atom set \(A_t\); its integral packages are \(\mathcal S_t=\operatorname{SM}(P_t)\), represented implicitly by \(P_t\). No satisfiability promise is imposed.
The score is \(u_t(S)=\sum_{(w,\ell)\in E_t,\ S\models\ell}w\), where \(E_t\) is an input list of weighted literals and \(w\in\mathbb Q\); smaller scores are preferred, with equal scores tied.
There are \(r\ge1\) resources. Polynomial-size input Boolean circuits, evaluated on the characteristic vector of \(S\), output binary-rational vectors \(h_{t,S}\in\mathbb Q_{\ge0}^r\); bounds \(b\in\mathbb Q_{\ge0}^r\) are per capita.
An allocation assigns real masses \(x_{t,S}\ge0\), satisfying \(\sum_{S\in\mathcal S_t}x_{t,S}=\mu_t\) and \(\sum_{t,S}x_{t,S}h_{t,S}\le b\) componentwise. Compute one minimizing \(\sum_{t,S}x_{t,S}u_t(S)\), or report infeasibility; represent the answer by its positive-mass packages and rational masses.
Let \(m=|\bigcup_t A_t|\) and let \(L\) be the total binary input length, including programs, circuits, weights, masses, and bounds.

Is this exact allocation problem solvable in time polynomial in \(m,\tau,r,L\), or is deciding whether a feasible allocation has objective at most an input binary rational \(q\) NP-hard?

Discrete: successive ASP solves compute a preferred stable model for any strict partial-order preference, or detect unsatisfiability; this is a correctness guarantee, not a polynomial-time bound ([source](https://ojs.aaai.org/index.php/AAAI/article/download/9398/9257)).

Conclusion

The decision problem is \(\mathrm{NP}\)-hard, even with one type, one resource, a satisfiable normal program, and an allocation instance that is always feasible. All numerical data in the reduction are constants.

Consequently, computing an exact optimal allocation in time polynomial in \(m,\tau,r,L\) would imply \(\mathrm{P}=\mathrm{NP}\). For normal programs, the decision problem is also in \(\mathrm{NP}\), hence is \(\mathrm{NP}\)-complete.

The absence of a satisfiability promise already permits hardness through stable-model existence. The proof below establishes the stronger result with both program satisfiability and allocation feasibility guaranteed.

1. A reduction with guaranteed feasibility

Let \(F=C_1\land\cdots\land C_k\) be an instance of Boolean \(3\)-satisfiability over variables \(z_1,\ldots,z_n\). We construct an allocation instance in polynomial time.

There is one type of mass \(\mu_1=1\). Its atom set is

\[ \]
\(A=\{p_i,n_i:1\leq i\leq n\}\cup\{d,e,v\}.\)

Here \(p_i\) and \(n_i\) are distinct atoms representing the two truth values of \(z_i\). The atoms \(d\) and \(e\) distinguish a fallback package from an assignment package.

The ground normal program contains the rules

\(p_i\leftarrow\operatorname{not} n_i,\qquad n_i\leftarrow\operatorname{not} p_i\qquad(1\leq i\leq n),\)

and

\(d\leftarrow\operatorname{not} e,\qquad e\leftarrow\operatorname{not} d.\)

For a Boolean literal \(\ell\), define its falsity atom by

\(f(z_i)=n_i,\qquad f(\neg z_i)=p_i.\)

For each clause \(C_j=\ell_{j1}\lor\ell_{j2}\lor\ell_{j3}\), add

\(v\leftarrow e,f(\ell_{j1}),f(\ell_{j2}),f(\ell_{j3}).\)

Thus \(v\) records that an assignment package falsifies at least one clause.

Stable models of the constructed program

We use the usual reduct definition: a stable model is the least model of its positive normal reduct.

Every stable model contains exactly one of \(p_i,n_i\), for each \(i\), and exactly one of \(d,e\). To verify this, consider any such pair. If neither atom belongs to a candidate model, both corresponding rules become facts in the reduct. If both belong to it, both rules are removed, and neither atom has another defining rule. In either case, the candidate differs from the reduct’s least model.

Now fix a truth assignment \(\alpha\) and select either \(d\) or \(e\). The reduct contains the selected atoms as facts. Its only possible additional consequence is \(v\). By the clause rules, \(v\) is derived exactly when \(e\) was selected and \(\alpha\) falsifies a clause of \(F\).

It follows that the stable models are exactly:

  • \(S_{\alpha,d}\): the assignment atoms for \(\alpha\), together with \(d\);
  • \(S_{\alpha,e}\): the assignment atoms for \(\alpha\), together with \(e\), and additionally \(v\) precisely when \(\alpha\not\models F\).

This proves both directions of the characterization: every stable model has this form, and each listed set equals the least model of its reduct. In particular, the program always has stable models.

Scores and resources

Set the weighted-literal list to \(E=\{(1,d)\}\). Thus

\(u(S)=\mathbf{1}_{d\in S}.\)

Use one resource, with consumption

\(h(S)=1+\mathbf{1}_{v\in S},\)

and bound \(b=1\). A constant-size Boolean circuit implements this function by reading the characteristic-vector bit for \(v\). The threshold is \(q=0\).

The packages therefore have the following values:

| Package | Score | Resource consumption |
|---|---:|---:|
| \(S_{\alpha,d}\) | \(1\) | \(1\) |
| \(S_{\alpha,e}\), where \(\alpha\models F\) | \(0\) | \(1\) |
| \(S_{\alpha,e}\), where \(\alpha\not\models F\) | \(0\) | \(2\) |

The allocation instance is always feasible: assigning mass \(1\) to any fallback package \(S_{\alpha,d}\) satisfies the resource bound.

2. Why fractional mixing cannot defeat the reduction

Let \(x_S\) be any feasible allocation. Since its total mass is \(1\),

\(\sum_S x_Sh(S)=\sum_Sx_S+\sum_{S:v\in S}x_S=1+\sum_{S:v\in S}x_S.\)

The resource bound requires this quantity to be at most \(1\). Nonnegativity therefore implies

\(\sum_{S:v\in S}x_S=0.\)

Consequently, every assignment package corresponding to an unsatisfying assignment receives zero mass.

The objective is

\(\sum_Sx_Su(S)=\sum_{S:d\in S}x_S.\)

It is nonnegative, and it is at most \(q=0\) exactly when fallback packages also receive zero mass.

If \(F\) is satisfiable, choose a satisfying assignment \(\alpha\) and allocate mass \(1\) to \(S_{\alpha,e}\). This allocation has resource consumption \(1\) and objective \(0\).

Conversely, suppose a feasible allocation has objective at most \(0\). It gives zero mass to fallback packages and to unsatisfying assignment packages. Because its total mass is \(1\), some satisfying assignment package must exist. Hence \(F\) is satisfiable.

We have proved

\(F\text{ is satisfiable}\quad\Longleftrightarrow\quad\text{the constructed instance has a feasible allocation of objective at most }0.\)

Indeed, its optimum is exactly \(0\) when \(F\) is satisfiable and exactly \(1\) otherwise.

The construction has \(m=2n+3\), \(\tau=r=1\), and input length polynomial in the formula length. Its masses, bounds, weights, resource values, and threshold are constants. This is a polynomial-time many-one reduction from \(3\)-satisfiability, proving \(\mathrm{NP}\)-hardness for normal programs and therefore also for the permitted normal-or-disjunctive input class.

3. Optimal allocations have polynomial-size rational representations

The implicit package representation creates computational hardness, but it does not force exponentially large optimal answers.

Claim. Every feasible instance has an optimal allocation with at most \(\tau+r\) positive package masses, all rational with polynomial encoding length.

Proof. Each atom set is finite, so each stable-model set is finite. Introduce one variable for each type-package pair. The feasible allocations form a finite-dimensional rational polytope \(K\).

For every variable, nonnegativity and its type’s mass equation imply

\(0\leq x_{t,S}\leq\mu_t.\)

Thus \(K\) is bounded. It is closed because it is defined by finitely many linear equalities and weak inequalities. If nonempty, it is compact, so the linear objective attains its minimum. A bounded nonempty polytope has an optimal vertex for every linear objective.

Let \(x\) be such a vertex, and suppose it has \(s>\tau+r\) positive coordinates. For each positive coordinate, form its column consisting of its \(\tau\) type-incidence entries followed by its \(r\) resource entries. These columns lie in a vector space of dimension \(\tau+r\), so they are linearly dependent.

There is therefore a nonzero vector \(d\), supported on the positive coordinates, that preserves all type totals and all resource totals. For sufficiently small \(\varepsilon>0\), both \(x+\varepsilon d\) and \(x-\varepsilon d\) remain nonnegative and feasible. They are distinct, and their midpoint is \(x\), contradicting that \(x\) is a vertex. Hence \(s\leq\tau+r\).

It remains to bound the encoding length of the masses. Let \(B\) bound the binary lengths of all resource coefficients, type masses, and resource bounds. Since the circuits output explicitly encoded binary rationals, \(B\) is polynomially bounded by \(L\).

Restrict the type equations and tight resource inequalities to the \(s\) positive coordinates. Their coefficient matrix has column rank \(s\). Otherwise a nonzero null direction would preserve these active constraints; sufficiently small perturbations in both directions would also preserve nonnegativity and the finitely many resource inequalities with positive slack, again contradicting extremality.

Select \(s\) independent rows, obtaining a nonsingular rational system

\(Dx=a.\)

In each row, clear the denominators of its \(s\) coefficients and its right-hand side. The resulting integer entries have binary length \(O(sB)\). By the determinant expansion, their determinants, including the determinants used in Cramer’s rule, have binary length \(O(s^2B+s\log s)\). Cramer’s rule therefore gives rational coordinates of polynomial encoding length.

Together with \(s\leq\tau+r\), this proves the claim. \(\square\)

4. Membership in \(\mathrm{NP}\) for normal programs

Suppose all input programs are normal and the threshold answer is yes. An optimal vertex supplied by the preceding claim has objective at most \(q\). It provides a certificate containing at most \(\tau+r\) typed packages and their polynomial-size positive rational masses.

A verifier performs the following polynomial-time checks:

  • Stable-model membership. For each listed package, form the normal reduct, compute the least model of its headed positive rules, compare it with the package, and check any integrity constraints.
  • Coefficients. Evaluate its resource circuits and weighted literals.
  • Allocation conditions. Check nonnegativity, every type-mass equality, every resource inequality, and the objective threshold using exact rational arithmetic.

For completeness, the stable-model check remains valid with integrity constraints. The least model of the headed positive rules is contained in every model of those rules. If a larger model satisfies a positive integrity constraint, its least submodel also satisfies that constraint. Thus a candidate is a minimal model of the reduct precisely when it equals this least model and satisfies the constraints.

All certificate lengths and arithmetic lengths are polynomial in the input parameters. The decision problem for normal programs therefore belongs to \(\mathrm{NP}\). Combined with the reduction, it is \(\mathrm{NP}\)-complete. This membership argument is not asserted for disjunctive programs.

5. Consequence for exact optimization

A polynomial-time exact allocation algorithm could be run on the constructed instances, which are always feasible. Computing the returned allocation’s objective and comparing it with \(0\) would decide \(3\)-satisfiability in polynomial time. Therefore such an algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The stated discrete correctness guarantee is compatible with this hardness result. The cited [asprin paper](https://ojs.aaai.org/index.php/AAAI/article/download/9398/9257) describes repeated solver calls and explicitly makes algorithmic complexity dependent on dominance tests; that guarantee supplies no polynomial-time bound for the present allocation problem.
