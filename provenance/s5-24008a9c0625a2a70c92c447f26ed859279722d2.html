Theorem 6.3 — class: hardness

The continuous mirror question, as graded

Given a rational distribution \(\mu\) over finitely many roommate types, each with a ranking of acceptable partner types, and a rational profile threshold \(\sigma\), does there exist a stable mass-pair assignment whose profile \(p(x)\) is lexicographically at least \(\sigma\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of the \(\tau\) types with positive binary rational masses \(\mu_i\), with \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(m\) be the total preference-list length and \(L\) the total input bit length.
Each type strictly ranks a possibly empty subset of acceptable partner types; every acceptable partner is preferred to being unmatched. A type may list itself, meaning partnership between distinct individuals of that type. Write \(r_i(j)\) for the listed rank of \(j\).
A mass assignment is a symmetric matrix \(x\in\mathbb R_{\geq0}^{\tau\times\tau}\), with \(x_{ij}=0\) unless acceptability is mutual and \(\sum_jx_{ij}\leq\mu_i\). Off the diagonal, \(x_{ij}\) is the mass of type \(i\) paired with type \(j\); \(x_{ii}\) is the mass of individuals in within-type pairs, whose pair mass is \(x_{ii}/2\).
Set \(u_i=\mu_i-\sum_jx_{ij}\) and, for acceptable \(j\), \(D_i(j)=u_i+\sum_{k:r_i(k)>r_i(j)}x_{ik}\), summing over listed partners. Stability means \(D_i(j)D_j(i)=0\) for every mutually acceptable pair of types, including \(i=j\): positive masses cannot both strictly prefer pairing together.
The profile is \(p(x)=(p_1(x),\ldots,p_\tau(x))\), where \(p_\ell(x)=\sum_i\sum_{j:r_i(j)=\ell}x_{ij}\); unmatched mass contributes nothing. The input threshold is \(\sigma\in\mathbb Q^\tau\), encoded in binary.

Is deciding whether a stable mass assignment \(x\) exists with \(p(x)\geq_{\mathrm{lex}}\sigma\) solvable in time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

The discrete profile threshold problem is \(\mathrm{NP}\)-complete, even with complete strict lists ([Cooper–Manlove](https://arxiv.org/pdf/1905.06626)); maximizing first choices is also \(\mathrm{W}[1]\)-hard parameterized by the requested number ([Simola–Manlove](https://arxiv.org/pdf/2110.02555)).
For fractional roommates with strict preferences and unit capacities, ordinally stable welfare threshold feasibility is \(\mathrm{NP}\)-complete, while maximizing the number of fully matched agents is polynomial-time solvable ([Chen–Roy–Sorge](https://www.ijcai.org/proceedings/2021/0013.pdf)). These objectives differ from the profile threshold above; no result settling exactly this mass problem was located.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one, with every listed support mass strictly positive.
  • Used strict, possibly incomplete preference lists, preserving listed ranks; assignments and blocking deviations require mutual acceptability.
  • Allowed partnership between distinct individuals of the same type when that type lists itself; this does not allow an individual to partner with themselves.
  • Defined assignment variables as endpoint masses, with diagonal entries counting individuals rather than pairs, and allowed arbitrary nonnegative real assignments.
  • Allowed unmatched mass, following the operative at-most-once matching definition and the explicit treatment of unassigned agents; acceptable partners are preferred to being unmatched.
  • Defined stability by the absence of positive masses on both sides that strictly prefer a deviation, including within-type deviations.
  • Fixed profile and threshold length at the support size, using zero entries for unattained ranks; threshold coordinates may be signed binary rationals, consistent with the unrestricted profile threshold.
  • Defined the running-time parameters as total preference-list length, support size, and total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The problem is \(\mathrm{NP}\)-complete

This holds even when all masses are equal dyadic rationals, acceptability is mutual, no type lists itself, and the threshold has the form \(\sigma=(c,0,\ldots,0)\).

The reduction uses the preference gadget in [Simola–Manlove, Section 4.1](https://arxiv.org/pdf/2110.02555). The essential additional argument below characterizes all fractional stable assignments of that gadget.

1. A consequence of stability

Lemma. Suppose two distinct mutually acceptable types \(q,r\) both have mass \(\delta>0\). Let \(x\) be stable, and suppose \(x_{qk}=0\) for every partner \(k\) that \(q\) ranks above \(r\). Then \(r\) is fully matched and assigns zero mass to every partner it ranks below \(q\).

Proof. The hypothesis and the definition of \(D\) give

\[ D_q(r)=\delta-x_{qr}. \]

If \(x_{qr}<\delta\), stability implies \(D_r(q)=0\). Since \(D_r(q)\) is the sum of unmatched mass and masses assigned to partners below \(q\), all these nonnegative terms vanish.

If \(x_{qr}=\delta\), symmetry and the capacity of \(r\) imply that \(r\) assigns its entire mass to \(q\). The same conclusion follows. \(\square\)

2. Construction from Independent Set

Let \(G=(V,E)\) be a simple graph, with \(V=\{1,\ldots,n\}\), and let \(k\) be the requested independent-set size. We may restrict to \(n\geq1\) and \(1\leq k\leq n\); Independent Set remains \(\mathrm{NP}\)-complete under these restrictions.

For each vertex \(i\), introduce six types

\[ v_i,\quad w_i,\quad s_i,\quad t_i,\quad a_i,\quad b_i. \]

Their strict preference lists, from best to worst, are:

| Type | Preference list |
|---|---|
| \(v_i\) | \(a_i\succ w_i\succ [v_j:\{i,j\}\in E]\succ t_i\) |
| \(w_i\) | \(s_i\succ v_i\succ a_i\succ b_i\) |
| \(s_i\) | \(a_i\succ t_i\succ w_i\) |
| \(t_i\) | \(a_i\succ v_i\succ s_i\) |
| \(a_i\) | \(w_i\succ b_i\succ v_i\succ s_i\succ t_i\) |
| \(b_i\) | \(w_i\succ a_i\) |

Order the neighbors in the bracket arbitrarily but strictly. These lists make acceptability mutual.

Let \(N\) be the smallest power of two satisfying \(N\geq6n\), and put \(\delta=1/N\). Add \(N-6n\) types with empty lists, and give every type mass \(\delta\). Thus the support size is \(\tau=N\), all masses are positive dyadic rationals, and their sum is one.

Set

\[ \sigma=(k\delta,0,\ldots,0)\in\mathbb Q^\tau. \]

The total preference-list length is \(m=20n+2|E|\). Since \(N<12n\), and \(\delta\) and \(k\delta\) have bit lengths bounded by a constant multiple of \(\log(n+1)\), this construction has polynomial size.

3. Every stable assignment has a forced local form

Fix any stable mass assignment \(x\). We first apply the lemma repeatedly within each vertex gadget.

  • Apply it to \((a_i,w_i)\). Since \(w_i\) is \(a_i\)'s first choice, \(w_i\) is fully matched and \(x_{w_i b_i}=0\).
  • Apply it to \((b_i,a_i)\). The only partner \(b_i\) ranks above \(a_i\) is \(w_i\), whose assigned mass is now zero. Consequently \(a_i\) is fully matched and

\[ x_{a_i v_i}=x_{a_i s_i}=x_{a_i t_i}=0. \]

  • Apply it to \((v_i,w_i)\). The only partner above \(w_i\) is \(a_i\), with zero assigned mass. Consequently

\[ x_{w_i a_i}=x_{w_i b_i}=0. \]
Since \(a_i\) is fully matched, its only remaining partner is \(b_i\), so \(x_{a_i b_i}=\delta\).

  • Apply it to \((s_i,t_i)\). The partner \(a_i\), which \(s_i\) ranks above \(t_i\), has zero assigned mass. Thus \(t_i\) is fully matched.

Define

\[ \lambda_i=\frac{x_{w_i s_i}}{\delta}, \qquad \beta_i=\frac{x_{v_i t_i}}{\delta}, \qquad C_i=\sum_{j:\{i,j\}\in E}x_{v_i v_j}. \]

Because \(w_i\) and \(t_i\) are fully matched and the eliminated edges have zero mass,

\[ x_{v_i w_i}=\delta(1-\lambda_i), \qquad x_{s_i t_i}=\delta(1-\beta_i). \]

The capacity constraint at \(s_i\) gives

\[ \delta\lambda_i+\delta(1-\beta_i)\leq\delta, \qquad\text{hence}\qquad \lambda_i\leq\beta_i. \]

The capacity constraint at \(v_i\) gives

\[ \delta(1-\lambda_i)+\delta\beta_i+C_i\leq\delta, \qquad\text{hence}\qquad \beta_i+\frac{C_i}{\delta}\leq\lambda_i. \]

Since \(C_i\geq0\), these two inequalities force

\[ \beta_i=\lambda_i,\qquad C_i=0. \]

Every summand defining \(C_i\) is nonnegative. Therefore every edge between different vertex gadgets has zero assigned mass.

We have proved that every stable assignment has, for some \(\lambda_i\in[0,1]\), exactly the following potentially nonzero entries in gadget \(i\):

| Pair | Assigned mass |
|---|---|
| \(a_i,b_i\) | \(\delta\) |
| \(v_i,w_i\) | \(\delta(1-\lambda_i)\) |
| \(s_i,t_i\) | \(\delta(1-\lambda_i)\) |
| \(w_i,s_i\) | \(\delta\lambda_i\) |
| \(v_i,t_i\) | \(\delta\lambda_i\) |

All six types are fully matched.

4. Stability is equivalent to independent positive support

For a graph edge \(\{i,j\}\in E\), every neighboring \(v\)-type lies between \(w_i\) and \(t_i\) in \(v_i\)'s list. The forced form therefore gives

\[ D_{v_i}(v_j)=\delta\lambda_i, \qquad D_{v_j}(v_i)=\delta\lambda_j. \]

Stability implies

\[ \lambda_i\lambda_j=0 \quad\text{for every }\{i,j\}\in E. \]

Consequently the set \(S=\{i:\lambda_i>0\}\) is independent.

Conversely, choose any parameters \(\lambda_i\in[0,1]\) whose positive support is independent, and assign masses according to the preceding table, with all other entries zero. This assignment is symmetric, nonnegative, and fully matches every gadget type.

To verify local stability exhaustively, the following quantities vanish:

| Type \(q\) | Partners \(r\) for which \(D_q(r)=0\) |
|---|---|
| \(w_i\) | \(a_i,b_i,v_i\) |
| \(a_i\) | \(b_i,v_i,s_i,t_i\) |
| \(s_i\) | \(w_i\) |
| \(t_i\) | \(s_i\) |
| \(v_i\) | \(t_i\) |

Indeed, each row type is fully matched entirely to partners weakly preferred to every indicated partner. Every mutually acceptable pair within a gadget is covered by this table, so every local stability product is zero.

For a pair \(v_i,v_j\) corresponding to a graph edge, the stability product is \(\delta^2\lambda_i\lambda_j=0\), by independence of the positive support. Padding types have no acceptable partners.

Thus this assignment is stable. We have completely characterized the stable assignments of the constructed society.

5. First-choice mass encodes the independence number

In the original lists, \(v_i,s_i,t_i\) have first choice \(a_i\), while \(a_i,b_i\) have first choice \(w_i\). All these first-choice edges receive zero mass in every stable assignment.

Only \(w_i\)'s first-choice edge, to \(s_i\), contributes. Hence

\[ p_1(x)=\delta\sum_{i=1}^n\lambda_i. \]

Let \(\alpha(G)\) denote the maximum size of an independent set. Since the positive support \(S\) is independent and \(\lambda_i\leq1\),

\[ p_1(x)\leq\delta|S|\leq\delta\alpha(G). \]

Conversely, take a maximum independent set \(S\), set \(\lambda_i=1\) for \(i\in S\), and set all other parameters to zero. Section 4 proves stability, and this assignment satisfies \(p_1(x)=\delta\alpha(G)\). Therefore

\[ \max_{x\text{ stable}}p_1(x)=\delta\alpha(G). \]

Every profile coordinate is nonnegative. With our chosen threshold, this means

\[ p(x)\geq_{\mathrm{lex}}(k\delta,0,\ldots,0) \quad\Longleftrightarrow\quad p_1(x)\geq k\delta. \]

Indeed, a smaller first coordinate fails immediately; a larger one succeeds immediately; and equality succeeds because the remaining profile coordinates are nonnegative.

Combining these statements,

\[ G\text{ has an independent set of size at least }k \quad\Longleftrightarrow\quad \exists x\text{ stable with }p(x)\geq_{\mathrm{lex}}\sigma. \]

This proves \(\mathrm{NP}\)-hardness.

6. Membership in \(\mathrm{NP}\)

This argument applies to the full input model, including unequal masses and self-acceptable types.

For any feasible mass assignment, every \(D_i(j)\) is a nonnegative affine function of the assignment variables. Therefore an off-diagonal stability constraint is equivalent to the disjunction

\[ D_i(j)=0\quad\text{or}\quad D_j(i)=0. \]

A nondeterministic algorithm guesses one endpoint for every mutually acceptable off-diagonal pair and imposes the corresponding equality. For a self-acceptable type it directly imposes \(D_i(i)=0\).

It also guesses which lexicographic alternative holds:

  • equality \(p(x)=\sigma\); or
  • an index \(h\) such that \(p_\ell(x)=\sigma_\ell\) for all \(\ell<h\), and \(p_h(x)>\sigma_h\).

After these guesses, all constraints are rational linear constraints except for the single possible strict inequality. To check that inequality exactly, introduce a variable \(z\), impose

\[ 0\leq z\leq1,\qquad p_h(x)-\sigma_h\geq z, \]

and maximize \(z\). The strict branch is feasible exactly when this linear program is feasible and has strictly positive optimum. The feasible region is bounded: assignment variables are bounded by the masses, and \(z\) is bounded by one.

These linear programs have polynomially many variables and constraints, and rational coefficients of polynomial bit length in the original input. The polynomial-time theorem for rational linear programming therefore supplies exact feasibility and optimum comparisons. The guesses also have polynomial length.

Every accepting branch produces a stable assignment satisfying the threshold, and every qualifying stable assignment satisfies some guessed branch. Hence the problem belongs to \(\mathrm{NP}\).

The decision problem is therefore \(\mathrm{NP}\)-complete, and a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
