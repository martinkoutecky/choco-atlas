The continuous mirror question, as graded

Given rational type masses \(\mu_t\), task truths \(y_j\), response masses \(x_{tjh}\ge 0\) satisfying \(\sum_h x_{tjh}=\mu_t\), fixed score tables \(f_t(k,h)\), offsets \(b_k\), and a fixed tie rule, compute \(G_{jk}=\sum_t\sum_h x_{tjh}f_t(k,h)+b_k\), the predicted labels \(\hat y_j\in\arg\max_k G_{jk}\), and their error rate against the supplied truths.

Packaged proof task (what the prover saw — nothing else)

Let \(m\geq2\) be the number of labels, \(C=\{1,\ldots,m\}\), and let \(N\geq1\) tasks have supplied truths \(y_j\in C\). Response \(0\) denotes a missing label.
A society is given by its support: the list of the \(\tau\geq1\) types with positive mass, each with its mass \(\mu_t\) as a binary rational; \(\tau\) is the support size, not the number of possible types. Require \(\sum_t\mu_t=1\).
The input explicitly supplies binary rational response masses \(x_{tjh}\geq0\) for \(h\in C\cup\{0\}\), with \(\sum_h x_{tjh}=\mu_t\) for every type and task. Each type has an explicitly supplied score table \(f_t:C\times(C\cup\{0\})\to\mathbb Q\); scores and offsets \(b_k\in\mathbb Q\) may have either sign, and \(f_t(k,0)\) is independent of \(k\).
Use the fixed tie rule that chooses the smallest maximizing label. The required quantities are \(G_{jk}=\sum_{t=1}^{\tau}\sum_{h=0}^{m}x_{tjh}f_t(k,h)+b_k\), \(\hat y_j=\min\operatorname*{arg\,max}_{k\in C}G_{jk}\), and the empirical error rate \(E=N^{-1}\sum_{j=1}^{N}\mathbf1\{\hat y_j\neq y_j\}\). Let \(L\) be the total binary input length; state running times in \(m,\tau,N,L\).

Is exact computation of all \(G_{jk}\), all \(\hat y_j\), and \(E\) polynomial-time solvable in \(m,\tau,N,L\), or is it NP-hard?

For finite worker lists, finite-sample exponential upper and lower probability bounds on empirical error are established for fixed decomposable score rules under the Dawid–Skene model; this is a statistical result, not a computational classification. [Li and Yu](https://arxiv.org/pdf/1411.4086).
That result does not classify exact evaluation from supplied rational response masses.

Modeling choices made when packaging the task

  • Normalized positive type masses to sum to one, as the natural distribution-over-types convention; the discrete definition supplies no mass normalization.
  • Included missing responses as label zero and required their score contribution to be independent of the potential label, following the discrete rule.
  • Restricted supplied scores, offsets, and response masses to explicitly encoded binary rationals so exact computation has a finite input model; scores and offsets may be negative.
  • Instantiated the unspecified fixed tie rule as choosing the smallest maximizing label, and used labels numbered from one even in the binary case.
  • Required at least two labels, a nonempty society, and at least one task; defined error as the unweighted empirical fraction of incorrectly predicted tasks.
  • Interpreted fixed score tables as supplied input held constant during evaluation, and defined L as total binary input length.

Conclusion

Exact computation of all \(G_{jk}\), all \(\hat y_j\), and \(E\) is polynomial-time solvable. With ordinary binary encodings of rational numerators and denominators, a direct algorithm uses \(O(N\tau m^2L^2)\) bit operations.

The key point is that both the support and the response masses are explicitly supplied. Every required score is a sum of explicitly listed rational products.

1. Exact arithmetic with polynomial bit length

Write every rational input as \(p_i/q_i\), where \(p_i\) is an integer and \(q_i\) is a positive integer. Reduced fractions are not required. Let \(Q\) be the number of rational entries, and define the positive integer

\(D=\prod_{i=1}^{Q}q_i.\)

Because the total binary input length is \(L\), the sum of the bit lengths of these denominators is at most \(L\). Consequently, \(D\) has \(O(L)\) bits.

For each rational input, define its scaled integer

\(Z_i=p_i(D/q_i).\)

This is an integer because \(q_i\) divides \(D\). Its bit length is also \(O(L)\): its magnitude is bounded by the product of \(|p_i|\) and all denominators other than \(q_i\), whose total encoding length is at most \(L\). In particular, we may use the uniform bound \(|Z_i|\leq 2^L\).

Using schoolbook integer multiplication and division, operations on \(O(L)\)-bit integers cost \(O(L^2)\) bit operations. Constructing \(D\) and all scaled integers therefore costs \(O(QL^2)\).

2. Computing every score

Use the scaled integers

\(X_{tjh}=Dx_{tjh},\qquad F_{tkh}=Df_t(k,h),\qquad B_k=Db_k.\)

For each task \(j\) and label \(k\), compute the integer

\(A_{jk}=\sum_{t=1}^{\tau}\sum_{h=0}^{m}X_{tjh}F_{tkh}+DB_k.\)

Substituting the definitions gives, exactly,

\(A_{jk}=D^2\left(\sum_{t=1}^{\tau}\sum_{h=0}^{m}x_{tjh}f_t(k,h)+b_k\right)=D^2G_{jk}.\)

Thus outputting \(A_{jk}/D^2\) computes \(G_{jk}\) exactly. An unreduced fraction is an exact rational representation.

Set \(R=\tau(m+1)\), the number of products in one score. Each product, including \(DB_k\), has magnitude at most \(2^{2L}\). Every partial sum therefore has magnitude at most \((R+1)2^{2L}\), and hence bit length at most \(2L+O(\log(R+1))\).

The input explicitly supplies at least \(R\) response masses, so \(R=O(L)\). All intermediate integers consequently have \(O(L)\) bits, even when scores or offsets are negative.

There are \(NmR\) products in the score computations. Their total cost, including additions, is \(O(NmRL^2)=O(N\tau m(m+1)L^2)\).

3. Computing predictions and empirical error

Since the common denominator \(D^2\) is positive,

\(G_{jk}>G_{j\ell}\quad\Longleftrightarrow\quad A_{jk}>A_{j\ell},\)

and equality is likewise preserved.

For each task, initialize the selected label to \(1\). Scan labels \(2,\ldots,m\) in increasing order, replacing the selected label only when the new numerator is strictly larger.

After processing any initial segment of labels, the selected label is the smallest label attaining the maximum numerator in that segment. This follows by induction: a strictly larger numerator replaces every earlier maximizer, while an equal numerator leaves the earlier, smaller label selected. After the full scan, the algorithm therefore returns exactly

\(\hat y_j=\min\operatorname*{arg\,max}_{k\in C}G_{jk}.\)

The scans require \(O(Nm)\) comparisons of \(O(L)\)-bit integers, costing \(O(NmL)\) bit operations.

Finally, count

\(e=\sum_{j=1}^{N}\mathbf1\{\hat y_j\neq y_j\}\)

and output the exact rational \(E=e/N\). The count uses \(O(\log(N+1))\) bits and takes \(O(N\log(N+1))\) bit operations.

4. Total running time and interpretation

The number of rational inputs is

\(Q=\tau+\tau N(m+1)+\tau m(m+1)+m.\)

Under the hypotheses \(N\geq1\), \(\tau\geq1\), and \(m\geq2\), this is \(O(N\tau m(m+1))\). Combining preprocessing, score computation, comparisons, counting, and output gives

\(O(N\tau m(m+1)L^2)=O(N\tau m^2L^2)\)

bit operations. Each output score has an \(O(L)\)-bit numerator and denominator, so output size also remains polynomial. No enumeration of types outside the supplied support is needed.

The normalization constraints and the independence of \(f_t(k,0)\) from \(k\) are compatible with this algorithm; the proof does not require additional restrictions on the signs of scores or offsets.

Li and Yu’s finite-sample bounds concern statistical error under the Dawid–Skene model. They are separate from the exact arithmetic evaluation proved here. [Li and Yu](https://arxiv.org/pdf/1411.4086).
