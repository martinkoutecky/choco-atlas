The continuous mirror question, as graded

Given \(T\) rounds of labeled indivisible slot types \(r\), common additive values \(v_r\), and rational per-capita supplies \(q_{tr}\in[0,1]\), decide whether a measurable irrevocable allocation of unit population mass exists such that each microscopic agent receives \(b_r\in\{0,1\}\) for every slot, aggregate slot usage equals the supplies, and almost every agent meets the continuum MMS benchmark after every round. For goods, the benchmark is \(\sup_{\lambda:\mathbb{E}_{\lambda}[b_r]=q_r}\operatorname{ess\,inf}_{b\sim\lambda}\sum_r v_rb_r\); for chores, use the corresponding \(\inf\operatorname{ess\,sup}\) cost benchmark.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Masses sum to \(1\). Here all agents have identical additive valuations, so \(\tau=1\).
There are \(T\ge1\) rounds and \(m\) distinct labeled slots, partitioned into arrival sets \(R_1,\ldots,R_T\). Each slot \(r\in R_t\) has binary-rational supply \(q_r=q_{tr}\in[0,1]\) and common binary-rational value \(v_r\ge0\) for goods, or cost \(d_r\ge0\) for chores. Repeated labels in different rounds denote distinct slots.
Represent agents by \([0,1]\) with Lebesgue measure. An allocation consists of measurable maps \(b_r:[0,1]\to\{0,1\}\) satisfying \(\int_0^1 b_r(x)\,dx=q_r\). Each slot is assigned in its arrival round and its assignment never changes; the full instance is known beforehand. Empty bundles are allowed.
For \(S_t=\bigcup_{s\le t}R_s\), let \(\Lambda_t\) be all probability distributions on \(\{0,1\}^{S_t}\) with \(\mathbb E_\lambda[b_r]=q_r\) for every \(r\in S_t\). Define \(G_t=\sup_{\lambda\in\Lambda_t}\operatorname{ess\,inf}_{b\sim\lambda}\sum_{r\in S_t}v_rb_r\) and \(C_t=\inf_{\lambda\in\Lambda_t}\operatorname{ess\,sup}_{b\sim\lambda}\sum_{r\in S_t}d_rb_r\).
Exact continuum TMMS requires, for almost every agent \(x\) and every round \(t\), \(\sum_{r\in S_t}v_rb_r(x)\ge G_t\) for goods, or \(\sum_{r\in S_t}d_rb_r(x)\le C_t\) for chores. The benchmarks are defined from the input, not supplied separately.
For each of goods and chores, is deciding whether an exact continuum TMMS allocation exists solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,T,L\), where \(L\) is the total binary input length.
For finite societies, exact TMMS existence is NP-hard for both goods and chores, even with identical valuations, two agents, and two rounds; the Partition reduction establishes hardness, not strong NP-hardness. This discrete result does not establish the complexity of the continuum problem defined above.

Modeling choices made when packaging the task

  • Interpreted slot occurrences in different rounds as distinct labeled slots, matching the disjoint arrival sets; each occurrence has its own supply and binary receipt indicator.
  • Normalized the atomless population to mass one and represented it by the unit interval with Lebesgue measure.
  • Used one supported valuation type of mass one because valuations are common.
  • Specified binary-rational nonnegative goods values and chore costs to make computational input length well-defined; zero values and zero supplies remain allowed.
  • Computed each benchmark using all slots available through that round and their fixed marginal supplies, with arbitrary probability distributions over binary bundles.
  • Allowed knowledge of the full arrival sequence, imposed irrevocability, and required fairness only at round ends, as in the discrete temporal model.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Exact continuum TMMS existence is NP-hard for both goods and chores, even with \(\tau=1\), \(T=2\), integer values or costs, and \(q_r=1/2\) for every slot.

An exact algorithm runs in \(2^{O(m)}\operatorname{poly}(m,\tau,T,L)\) time on the specified class, where \(\tau=1\). A polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\). The reduction below establishes NP-hardness, without establishing strong NP-hardness.

For \(T=1\), existence is automatic: the finite bundle space ensures that the optimal benchmark is attained.

1. Continuum allocations and their benchmarks

For a prefix \(S_t\), write \(\mathcal B_t=\{0,1\}^{S_t}\). Every measurable allocation induces a distribution on \(\mathcal B_t\): the probability of a bundle is the Lebesgue measure of agents receiving it. Its coordinate expectations are exactly the prescribed supplies.

Conversely, every distribution on a finite bundle space can be realized measurably. Partition \([0,1]\) into intervals whose lengths are the bundle probabilities, and assign each interval its corresponding bundle. For a distribution on full bundles, each coordinate is assigned in its arrival round; thus this realization respects irrevocability.

For goods, every feasible prefix distribution has the same expected value,

\(\displaystyle M_t=\sum_{r\in S_t}v_rq_r.\)

Consequently, \(G_t\le M_t\). For chores, the analogous argument gives \(C_t\ge\sum_{r\in S_t}d_rq_r\).

Both optimal benchmarks are attained. Indeed, for any candidate threshold \(h\), goods feasibility is equivalent to

\(\displaystyle q|_{S_t}\in\operatorname{conv}\left\{b\in\mathcal B_t:\sum_{r\in S_t}v_rb_r\ge h\right\}.\)

There are only finitely many bundle values. The largest feasible candidate value is therefore attained and equals \(G_t\). The corresponding argument, with the inequality reversed and the smallest feasible candidate selected, proves attainment of \(C_t\).

We will also use the following elementary fact: if an integrable random variable satisfies \(X\ge a\) almost surely and \(\mathbb E[X]=a\), then \(X=a\) almost surely. This follows because the nonnegative variable \(X-a\) has integral zero.

2. NP-hardness for goods

We reduce from Partition. Let \(a_1,\ldots,a_k\) be positive integers, with \(k\ge2\), and put \(W=\sum_{j=1}^k a_j\). The question is whether some \(P\subseteq\{1,\ldots,k\}\) satisfies

\(\displaystyle \sum_{j\in P}a_j=W/2.\)

Restricting to \(k\ge2\) preserves NP-hardness, since instances with fewer entries are directly decidable.

Construct one valuation type of mass \(1\) and two rounds:

| Arrival round | Slots | Common values | Supplies |
|---|---|---|---|
| \(1\) | \(g_1,\ldots,g_k\) | \(v_{g_j}=2a_j\) | \(1/2\) each |
| \(2\) | \(h_1,h_2\) | \(v_{h_1}=v_{h_2}=W\) | \(1/2\) each |

This uses the numerical gadget from [Appendix F.2 of Choi, Li, and Teh](https://arxiv.org/html/2608.20033v1#A6.SS2). The proof below verifies its validity for arbitrary continuum allocations.

The necessary benchmark properties

The expected first-round value is \(W\), so \(G_1\le W\). Moreover,

\(\displaystyle G_1\ge\min\{2a_1,\,2(W-a_1)\}>0.\)

To verify this lower bound, give probability \(1/2\) to the bundle \(\{g_1\}\) and probability \(1/2\) to its complement within round \(1\). Every first-round coordinate then has expectation \(1/2\). Both bundle values are positive because all inputs are positive and \(k\ge2\).

The expected final value is \(2W\). Consider the distribution placing probability \(1/2\) on all first-round slots and probability \(1/2\) on both second-round slots. Every coordinate again has expectation \(1/2\), and both bundles have value \(2W\). Together with the expectation upper bound, this proves

\(\displaystyle G_2=2W.\)

These arguments use benchmarks defined from the instance; no benchmark is supplied to the decision problem.

Any continuum TMMS allocation yields a partition

Suppose an exact continuum TMMS allocation exists. Let \(X(x)\) and \(Y(x)\) denote the values agent \(x\) receives from rounds \(1\) and \(2\), respectively.

The supply constraints imply

\(\displaystyle \int_0^1X(x)\,dx=W,\qquad \int_0^1(X(x)+Y(x))\,dx=2W.\)

Final fairness requires \(X(x)+Y(x)\ge G_2=2W\) almost everywhere. The elementary integral fact above therefore gives

\(\displaystyle X(x)+Y(x)=2W\quad\text{almost everywhere}.\)

Since round \(2\) consists of two binary slots of value \(W\),

\(\displaystyle Y(x)\in\{0,W,2W\},\qquad X(x)\in\{0,W,2W\}\)

almost everywhere. First-round fairness and \(G_1>0\) exclude \(X(x)=0\). Hence \(X(x)\ge W\) almost everywhere. Its integral is \(W\), so the same integral fact implies

\(\displaystyle X(x)=W\quad\text{almost everywhere}.\)

Choose an agent from this measure-one set and define \(P=\{j:b_{g_j}(x)=1\}\). Then

\(\displaystyle 2\sum_{j\in P}a_j=X(x)=W,\)

which solves Partition.

Crucially, this argument permits arbitrary measurable allocations and arbitrary mixtures of bundles.

A partition yields a continuum TMMS allocation

Conversely, suppose \(P\) solves Partition. On the first half of \([0,1]\), assign the first-round bundle indexed by \(P\); on the second half, assign its complement. Every first-round supply is \(1/2\), and every agent receives value \(W\).

In round \(2\), assign \(h_1\) to the first half and \(h_2\) to the second half. Every agent then has final value \(2W\).

The inequalities \(G_1\le W\) and \(G_2=2W\) prove exact TMMS at both rounds.

The reduction has \(m=k+2\), \(\tau=1\), and \(T=2\). Computing \(W\) and writing the instance takes polynomial time in the Partition input length; all numbers have polynomial binary encoding length. Thus goods existence is NP-hard.

3. Goods and chores are polynomially equivalent

Take any goods instance and construct a chores instance with

\(\displaystyle d_r=v_r,\qquad q'_r=1-q_r.\)

For each prefix, put \(D_t=\sum_{r\in S_t}v_r\). Complementing bundles, \(c_r=1-b_r\), gives a bijection between distributions with marginals \(q_r\) and distributions with marginals \(q'_r\). Pointwise,

\(\displaystyle \sum_{r\in S_t}d_rc_r=D_t-\sum_{r\in S_t}v_rb_r.\)

Therefore,

\(\displaystyle C_t(d,q')=D_t-G_t(v,q).\)

Indeed, essential supremum under complementation equals \(D_t\) minus essential infimum, and taking the infimum over distributions gives the stated identity.

For a measurable allocation, complementing every coordinate preserves arrival times and irrevocability. The identity shows that, almost everywhere,

\(\displaystyle \sum_{r\in S_t}v_rb_r\ge G_t(v,q) \quad\Longleftrightarrow\quad \sum_{r\in S_t}d_rc_r\le C_t(d,q').\)

Because there are finitely many rounds, these equivalences hold simultaneously outside one null set.

The transformation is polynomial-time and is its own inverse. In the reduction above, every supply is \(1/2\), so complementation leaves the supplies unchanged. The same constructed numbers, interpreted as costs, therefore establish NP-hardness for chores.

4. Exact running-time upper bound

Here is an exact algorithm that also computes the benchmarks.

For each round \(t\):

  • Enumerate all \(2^{|S_t|}\) bundles and sort their distinct prefix values or costs.
  • Test a candidate goods threshold \(h\) using the rational linear program

\(\displaystyle \sum_b p_b=1,\qquad \sum_b p_bb_r=q_r\quad(r\in S_t),\qquad p_b\ge0,\)

with variables only for bundles of value at least \(h\). For chores, retain bundles of cost at most \(h\).

  • Binary-search the ordered candidates to obtain the exact optimum. Feasibility is monotone, and at most \(O(m+1)\) feasibility tests suffice per round.

After obtaining every benchmark, enumerate full bundles satisfying all prefix fairness inequalities. Solve the same marginal linear program over these retained bundles.

This final program is feasible exactly when an exact continuum TMMS allocation exists, by the distribution–allocation equivalence proved in Section 1.

Each program has at most \(2^m\) variables and \(m+1\) equalities. Its matrix entries are binary, and its right-hand side consists of the input supplies. Bundle sums and benchmark comparisons have polynomial bit length in \(m\) and \(L\).

The standard polynomial-time theorem for rational linear-program feasibility therefore applies: every program has a finite, explicitly encoded rational description. Including enumeration, sorting, and all rounds, the total bit running time is

\(\displaystyle 2^{O(m)}\operatorname{poly}(m,\tau,T,L),\qquad \tau=1.\)

Thus fixing the society’s support size and the number of rounds does not make either problem polynomial-time unless \(\mathrm{P}=\mathrm{NP}\).
