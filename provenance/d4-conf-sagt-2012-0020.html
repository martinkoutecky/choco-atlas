The continuous mirror question, as graded

Given a finite \(\omega\)-sparse template \(H=(U,F)\), with \(\tau=|U|\) and maximum matching size \(\nu(H)\), consider a continuum of copies indexed by \(r\in[0,1]\), with one agent of each role \(u\in U\) in each copy and bargaining edges between roles in \(F\) within each copy. Find measurable payoffs \(x_u(r)\ge 0\) and measurable edge-deletion sets \(B_{uv}\subseteq[0,1]\) such that \(\frac{1}{\tau}\sum_{u\in U}\int_0^1 x_u(r)\,dr\le \frac{\nu(H)}{\tau}\) and \(x_u(r)+x_v(r)\ge 1\) for almost every \(r\notin B_{uv}\), while minimizing \(\frac{1}{\tau}\sum_{uv\in F}\operatorname{Leb}(B_{uv})\). Give an algorithm whose objective is at most \(8\omega+2\) times the optimum.

Agents are indexed by \((u,r)\), with \(r\in[0,1]\); an edge \(uv\in F\) connects only \((u,r)\) and \((v,r)\), and has unit value.
A feasible solution consists of nonnegative Lebesgue-measurable payoffs \(x_u(r)\) and measurable deletion sets \(B_{uv}\subseteq[0,1]\), satisfying \(\frac1\tau\sum_{u\in U}\int_0^1x_u(r)\,dr\le\frac{\nu(H)}\tau\) and \(x_u(r)+x_v(r)\ge1\) for almost every \(r\notin B_{uv}\), for every \(uv\in F\). The budget is imposed only on the integral across copies.
Its cost is \(C(B)=\frac1\tau\sum_{uv\in F}\operatorname{Leb}(B_{uv})\); define \(\mathrm{OPT}\) as the infimum over all measurable feasible solutions. Computational solutions are represented by a finite common interval partition with rational endpoints, rational constant payoffs, and constant deletion membership on each interval.

Does this problem admit an algorithm, polynomial in \(m,\tau,L\), that returns a feasible solution with \(C(B)\le(8\omega+2)\mathrm{OPT}\), or is achieving this approximation guarantee NP-hard?

For the discrete problem, a blocking set \(B\subseteq F\) permits nonnegative payoffs with \(\sum_u x_u\le\nu(H)\) and \(x_u+x_v\ge1\) on every undeleted edge; a polynomial-time \((8\omega+2)\)-approximation is known on \(\omega\)-sparse graphs ([source](https://cs.uwaterloo.ca/~klarson/papers/nwbg-sagt.pdf)).

1. Result

The problem admits a polynomial-time \((8\omega+2)\)-approximation. A solution constant across all copies suffices. The key is that the cited discrete algorithm has a guarantee relative to a linear relaxation, whose optimum also lower-bounds the continuum optimum.

2. A lower bound for every measurable solution

Write \(k=\nu(H)\). Define the following finite linear program, with optimum \(\lambda(H,k)\):

\[ \begin{aligned} \text{minimize}\quad & \sum_{uv\in F}z_{uv}\\ \text{subject to}\quad & y_u+y_v+z_{uv}\ge 1 &&(uv\in F),\\ & \sum_{u\in U}y_u\le k,\\ & y_u\ge 0,\quad z_{uv}\ge 0. \end{aligned} \]

Consider any feasible measurable solution \((x,B)\). Set
\(y_u=\int_0^1x_u(r)\,dr\) and
\(z_{uv}=\operatorname{Leb}(B_{uv})\).
Each integral is finite because the payoffs are nonnegative and their total integral is at most \(k\).

For each edge \(uv\), feasibility and nonnegativity imply
\(x_u(r)+x_v(r)+\mathbf{1}_{B_{uv}}(r)\ge 1\)
almost everywhere: outside the deletion set this is the required constraint, and inside it the indicator already equals one. Integrating gives
\(y_u+y_v+z_{uv}\ge 1\).
The integral budget gives \(\sum_u y_u\le k\).

Thus \((y,z)\) is feasible for the linear program, and
\(\lambda(H,k)\le\sum_{uv}z_{uv}=\tau C(B)\).
Since this holds for every feasible measurable solution, taking the infimum yields

\[ \frac{\lambda(H,k)}{\tau}\le\mathrm{OPT}. \]

This argument uses only the integral budget; it imposes no budget on individual copies.

3. The precise discrete guarantee used

The stronger guarantee established by the cited paper is:

For an \(\omega\)-sparse graph \(G=(V,E)\), with \(\omega\ge 1\), and a positive integer budget \(k\), its polynomial-time algorithm returns a set \(D\subseteq E\) and nonnegative payoffs \(a\) satisfying \(\sum_v a_v\le k\), \(a_u+a_v\ge 1\) for every \(uv\in E\setminus D\), and
\(|D|\le(8\omega+2)\lambda(G,k)\).

Here \(\lambda(G,k)\) is exactly the relaxation defined above. This is the LP-relative bound from Lemma 6 and the paper’s concluding double-cover argument: the bipartite rounding factor is \(2\omega'+1\), while the construction uses \(\omega'=2\omega\) and increases the LP optimum by at most a factor of two. [Könemann–Larson–Steiner, *Network Bargaining: Using Approximate Blocking Sets to Stabilize Unstable Instances*](https://cs.uwaterloo.ca/~klarson/papers/nwbg-sagt.pdf).

All hypotheses hold for our instance when \(m>0\): the promised sparsity condition is the paper’s definition, \(\omega\ge 1\), and \(k=\nu(H)\) is a positive integer. Importantly, we use the LP-relative guarantee stated above, which is stronger than a comparison with the discrete optimum alone.

4. Algorithm and approximation proof

If \(m=0\), return zero payoffs and no deletions. This is feasible and optimal.

Otherwise, compute \(k=\nu(H)\) and apply the discrete algorithm from Section 3 to obtain \(D\) and feasible payoffs \(a\). Define the continuum solution by
\(x_u(r)=a_u\) for every \(r\in[0,1]\), and set \(B_{uv}=[0,1]\) when \(uv\in D\), and \(B_{uv}=\varnothing\) otherwise.

Its total integral payoff is \(\sum_u a_u\le k\). Every undeleted edge satisfies its payoff constraint everywhere. Therefore the solution is feasible, and

\[ C(B)=\frac{|D|}{\tau} \le(8\omega+2)\frac{\lambda(H,k)}{\tau} \le(8\omega+2)\mathrm{OPT}. \]

5. Polynomial time and the required representation

Maximum matching and the cited rounding algorithm run in polynomial time. To obtain explicitly rational payoffs after computing \(D\), solve the finite feasibility linear program with constraints
\(0\le a_u\le 1\),
\(\sum_u a_u\le k\), and
\(a_u+a_v\ge 1\) for \(uv\in F\setminus D\).

This program is feasible: truncating any feasible nonnegative payoff at one preserves every edge constraint and cannot increase the budget. Its rational coefficients and dimensions have polynomial encoding length, so rational linear programming returns a feasible solution of polynomial bit length.

The output uses the single interval \([0,1]\), rational constant payoffs, and constant deletion membership. Its size and construction time are polynomial in \(m,\tau,L\). This completes the requested approximation guarantee.
