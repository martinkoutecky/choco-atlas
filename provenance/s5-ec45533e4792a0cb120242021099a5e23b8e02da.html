The continuous mirror question, as graded

Given a finite variable set \(X\), a finite support \(S\) of QCL preference types represented by formulas over \(X\), positive binary-rational masses \(\mu_\psi\) summing to \(1\), and a classical query \(\chi\), consider shared assignments \(I\subseteq X\) with finite satisfaction degree for every \(\psi\in S\). Define \(D_\mu(I)=\max_{\psi\in S}\deg(I,\psi)\). Decide whether \(\chi\) holds in every admissible assignment minimizing \(D_\mu\), taking the universal condition as true if there is no admissible assignment.

Conclusion

The problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions, even when \(\tau=1\) and the sole mass is \(1\). More precisely, it is \(\Theta_2^{\mathrm P}\)-complete. Consequently, it belongs to \(\mathrm P\) if and only if \(\mathrm P=\mathrm{NP}\).

1. Masses do not affect the decision

For a support \(S\), define its admissible assignments by
\(\mathcal A(S)=\{I\subseteq X:d_I(\psi)<\infty\text{ for every }\psi\in S\}\).

Neither \(\mathcal A(S)\) nor the objective
\(D_\mu(I)=\max_{\psi\in S}d_I(\psi)\)
depends on the numerical masses. Thus changing the masses while preserving the support preserves every admissible assignment, every minimizing assignment, and the entailment answer.

In particular, a singleton support with mass \(1\) satisfies all mass requirements.

2. A direct many-one reduction from satisfiability

Let \(\varphi\) be an instance of classical propositional satisfiability, with variable set \(V\). Introduce a fresh variable \(q\), and construct

\(X=V\cup\{q\}\),
\(S=\{\psi\}\), where \(\psi=(\varphi\wedge q)\overrightarrow{\times}\neg q\),
\(\mu_\psi=1\), and \(\chi=q\).

A classical formula has degree \(1\) exactly when it is true, and degree \(\infty\) otherwise. This follows by structural induction from the given rules: negation interchanges these two values, conjunction is finite exactly when both operands are finite, and disjunction is finite exactly when at least one operand is finite.

Both operands of the ordered disjunction are classical, so
\(o(\varphi\wedge q)=o(\neg q)=1\).
Consequently, the degree of \(\psi\) has exactly these cases:

  • If \(I\models\varphi\wedge q\), then \(d_I(\psi)=1\).
  • If \(I\models\neg q\), then the left operand has degree \(\infty\), while the right operand has degree \(1\). Hence \(d_I(\psi)=1+1=2\).
  • If \(I\models q\wedge\neg\varphi\), both operands have degree \(\infty\), so \(d_I(\psi)=\infty\).

These cases exhaust all assignments. In particular, assignments making \(q\) false are always admissible.

If \(\varphi\) is satisfiable, extending a satisfying assignment by making \(q\) true gives degree \(1\). Since every finite degree is positive, the optimum is \(1\). Every assignment attaining it satisfies \(q\), so the constructed instance answers true.

If \(\varphi\) is unsatisfiable, no assignment has degree \(1\). The admissible assignments are exactly those making \(q\) false, all with degree \(2\). They therefore violate \(\chi=q\), so the constructed instance answers false.

We have proved the equivalence
\(\varphi\text{ is satisfiable}\iff\text{the constructed instance answers true}\).

The construction adds only a constant number of syntax-tree nodes and one variable; its bit length and construction time are polynomial in the source input length. Since propositional satisfiability is \(\mathrm{NP}\)-complete, this proves the requested \(\mathrm{NP}\)-hardness.

3. Degree bounds and running times

Let \(\ell(A)\) denote the number of atom occurrences in the syntax tree of \(A\). For every QCL formula \(A\),

\(o(A)\leq\ell(A)\),

and every finite degree satisfies

\(1\leq d_I(A)\leq o(A)\).

Here are the induction steps establishing these bounds:

  • Atoms have optionality \(1\) and finite degree \(1\).
  • Negations have optionality \(1\), and their only finite degree is \(1\).
  • For conjunction and disjunction, optionality is the maximum of the operand optionalities, bounded by the sum of their atom counts. A finite conjunction degree is the maximum of two finite operand degrees; a finite disjunction degree is the minimum of the finite operand degrees. Both are bounded by that optionality.
  • Ordered disjunction adds operand optionalities. Its finite degree is either the left operand’s finite degree or \(o(A)+d_I(B)\), bounded respectively by \(o(A)\) or \(o(A)+o(B)\).

Set \(B=\max_{\psi\in S}o(\psi)\). Because formulas are explicit syntax trees, \(B\leq L\). Hence every admissible objective value lies between \(1\) and \(B\).

Write \(N=m+\tau+L\). Bottom-up evaluation computes all support degrees and the truth of \(\chi\) in \(O(N^2)\) bit operations, a conservative bound allowing variable indexing and arithmetic on integers of \(O(\log(L+2))\) bits.

A deterministic algorithm enumerates all \(2^m\) assignments, records the smallest admissible objective value, and checks \(\chi\) on all assignments attaining it. If none is admissible, it returns true. Its running time is

\(O\!\left(2^m(m+\tau+L)^2\right)\)

bit operations.

For a sharper complexity upper bound, use the following \(\mathrm{NP}\) predicate:

\(Q(k)\iff\exists I\subseteq X\,[I\in\mathcal A(S)\text{ and }D_\mu(I)\leq k]\).

An assignment is a polynomial-length witness, verifiable by the evaluation procedure above. First query \(Q(B)\); if false, return true. Otherwise, binary search the monotone predicate \(Q\) to find the minimum feasible value \(k^\ast\).

Finally, make one \(\mathrm{NP}\)-oracle query asking whether there exists an admissible \(I\) with \(D_\mu(I)\leq k^\ast\) and \(I\not\models\chi\). By minimality of \(k^\ast\), every such assignment is a minimizer. Return true exactly when this query answers no.

This uses \(O(\log(L+2))\) oracle calls and polynomial deterministic work, conservatively
\(O(N^2\log(L+2))\)
outside the oracle. Therefore the problem belongs to
\(\Theta_2^{\mathrm P}=\mathrm P^{\mathrm{NP}[O(\log L)]}\).

4. Transfer of the known completeness result

Proposition 31 of Bernreiter, Maly, and Woltran states that discrete QCL minmax entailment is \(\Theta_2^{\mathrm P}\)-complete. Its degree semantics, finite-model requirement, and minmax preference relation are precisely those used here. [Source, Definitions 2–5 and 20, Proposition 31](https://repositum.tuwien.at/bitstream/20.500.12708/142161/1/Bernreiter-2022-Artificial%20Intelligence-vor.pdf).

To transfer hardness without introducing any rational-encoding issue, take a nonempty discrete theory \(T=\{A_1,\ldots,A_t\}\) and form the explicit conjunction \(F_T=A_1\wedge\cdots\wedge A_t\). Repeated application of the conjunction rule gives
\(d_I(F_T)=\max_{1\leq j\leq t}d_I(A_j)\).

Thus \(F_T\) has finite degree exactly on the models of \(T\), and its minimum-degree models are exactly the minmax preferred models of \(T\). Replace \(T\) by the singleton support \(\{F_T\}\) with mass \(1\), retaining the query. This preserves all ties and vacuous entailment and takes polynomial time. The cited hardness proof already uses singleton theories, so restricting to nonempty theories loses no hardness.

Together with Section 3, this proves \(\Theta_2^{\mathrm P}\)-completeness.
