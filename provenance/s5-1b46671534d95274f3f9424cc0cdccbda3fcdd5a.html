The continuous mirror question, as graded

Given a rational society distribution \(\mu\) over communication-equivalent user types and a population scale \(N\), choose a cluster count \(k\) and mass assignments \(x_{tc}\ge 0\) with \(\sum_c x_{tc}=\mu_t\). Let \(q_c=\sum_t x_{tc}\). Find the choices minimizing per-resource communication workload \(C_N(k,x)=N+N^2\sum_{c=1}^k q_c^2+k+Nk\), and determine the resulting ratio to the QPQ baseline \(B_N=N+N^2\).

A society is given by its support: a list of \(\tau\) types with positive masses \(\mu_t\), each a binary rational, with \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; types are labels with no additional constraints.
The input also contains a binary integer population scale \(N\ge2\). Choose an integer \(k\ge2\) and divisible real masses \(x_{tj}\ge0\) satisfying \(\sum_{j=1}^{k}x_{tj}=\mu_t\); every cluster must have positive mass \(q_j=\sum_{t=1}^{\tau}x_{tj}>0\).
There is no minimum cluster mass or upper bound on \(k\). The communication cost is \(C=N+N^2\sum_{j=1}^{k}q_j^2+k+Nk\). Let \(L\) be the total input bit length, including a binary rational threshold \(B\) when supplied; there is no separate \(m\) parameter.

Exact minimum

The problem is polynomial-time solvable in the binary input length. Define

\( \displaystyle K=\max\left\{2,\left\lceil\frac{\sqrt{4N+1}-1}{2}\right\rceil\right\}. \)

Then the exact minimum is

\( \displaystyle \boxed{C_{\min}=N+\frac{N^2}{K}+(N+1)K}. \)

The optimal cluster count is uniquely \(K\). An optimal allocation is \(x_{tj}=\mu_t/K\) for every type \(t\) and cluster \(j\). Thus the minimum is independent of the support size and masses.

1. Reduction to the cluster count

Fix an integer \(k\ge2\). Every feasible allocation satisfies

\( \displaystyle \sum_{j=1}^{k}q_j=\sum_{t=1}^{\tau}\sum_{j=1}^{k}x_{tj}=\sum_{t=1}^{\tau}\mu_t=1. \)

Consequently,

\( \displaystyle 0\le\sum_{j=1}^{k}\left(q_j-\frac1k\right)^2=\sum_{j=1}^{k}q_j^2-\frac1k. \)

Equality holds exactly when every cluster has mass \(1/k\).

This lower bound is attainable under the stated hypotheses: set \(x_{tj}=\mu_t/k\). These entries are positive rational numbers, each row sums to \(\mu_t\), and each column sums to \(1/k>0\). There is no restriction on splitting a type across clusters.

Therefore, for every integer \(k\ge2\), the minimum cost at that cluster count is exactly

\( \displaystyle f(k)=N+\frac{N^2}{k}+(N+1)k. \)

It remains to minimize this explicit function over the integers.

2. Exact integer minimization

For every positive integer \(k\),

\( \displaystyle f(k+1)-f(k)=(N+1)-\frac{N^2}{k(k+1)}. \)

The division identity

\( \displaystyle \frac{N^2}{N+1}=N-1+\frac1{N+1} \)

places this ratio strictly between the consecutive integers \(N-1\) and \(N\). Since \(k(k+1)\) is an integer, it follows that

  • \(f(k+1)<f(k)\) exactly when \(k(k+1)\le N-1\);
  • \(f(k+1)>f(k)\) exactly when \(k(k+1)\ge N\).

In particular, adjacent costs never tie.

Let \(h\) be the smallest positive integer satisfying \(h(h+1)\ge N\). The product \(k(k+1)\) strictly increases with \(k\), so \(f\) strictly decreases up to \(h\) and strictly increases afterward. Restricting to \(k\ge2\) therefore gives the unique minimizer \(K=\max\{2,h\}\).

Solving the quadratic inequality over positive integers gives

\( \displaystyle h=\left\lceil\frac{\sqrt{4N+1}-1}{2}\right\rceil, \)

which proves the stated formula. No limiting argument over unbounded cluster counts is needed: the minimum is attained at this finite \(K\).

For example, \(K=2\) for \(2\le N\le6\), \(K=3\) for \(7\le N\le12\), and \(K=4\) for \(13\le N\le20\).

Every optimal allocation has exactly \(K\) clusters and column masses \(q_j=1/K\). The allocation matrix itself need not be unique.

3. Exact decision algorithm and bit complexity

Write \(b=\lceil\log_2(N+1)\rceil\). We use elementary binary arithmetic: multiplication of two integers having at most \(s\) bits takes \(O(s^2)\) bit operations.

Computing the minimum. Binary-search for the smallest positive integer \(h\) satisfying \(h(h+1)\ge N\), using the interval from \(1\) to \(N\). This interval contains \(h\), since \(N(N+1)\ge N\). The predicate is monotone, so the search takes \(O(b)\) iterations. Each iteration uses integers of \(O(b)\) bits and costs \(O(b^2)\) bit operations. Thus computing \(K\) costs \(O(b^3)\).

Set

\( \displaystyle A=NK+N^2+(N+1)K^2. \)

Then \(C_{\min}=A/K\), an exact rational representation whose numerator and denominator have \(O(b)\) bits. Computing this representation costs another \(O(b^2)\) bit operations.

Including reading the supplied valid input, computing the optimal count and value therefore takes

\( \displaystyle O\!\left(L+(\log N)^3\right) \)

bit operations.

Deciding the threshold question. Write the supplied rational threshold as \(B=a/d\), with \(d>0\). The answer is yes exactly when

\( \displaystyle dA\le aK. \)

This comparison uses exact integer arithmetic, including when \(a\) is negative. Its cost is \(O(L^2)\), because all operands have \(O(L)\) bits. Hence the decision running time is

\( \displaystyle O\!\left(L^2+(\log N)^3\right)\subseteq O(L^3). \)

These bounds assume the input satisfies the stated premises. If input validity must also be checked, positivity and normalization can be checked in polynomial time: accumulating rational sums keeps numerator and denominator lengths \(O(L)\), since the total encoded denominator length is at most \(L\).

Thus the decision problem is in \(\mathrm{P}\). NP-hardness under polynomial-time many-one reductions would imply \(\mathrm{P}=\mathrm{NP}\).

4. Dependence on support size and output format

Since the support is explicitly listed, \(\tau\le L\). After reading it, neither the optimal-value computation nor the threshold comparison requires any further calculation involving the masses. Their running times are polynomial in \(L\) and \(\log N\), rather than merely polynomial in the numerical value of \(N\).

An optimal allocation has the compact description

\( \displaystyle k=K,\qquad x_{tj}=\mu_t/K\quad\text{for all }t,j. \)

This description has polynomial size in \(L\).

If the full matrix must be written explicitly, the output contains \(\tau K\) rational entries. Each entry can be represented with \(O(L)\) bits. A conservative running-time bound for constructing and writing this matrix is

\( \displaystyle O\!\left(L+b^3+\tau K L^2\right). \)

The formula for \(K\) gives \(K=\sqrt N+O(1)\), so this is

\( \displaystyle O\!\left(L+(\log N)^3+\tau\sqrt N\,L^2\right). \)

This bound is polynomial in \(\tau,L,N\), but need not be polynomial in \(\log N\). Indeed, even with one type, an explicitly listed optimal matrix has \(\Omega(\sqrt N)\) entries. This output-size issue does not affect the polynomial-time value or decision algorithms.

5. Relation to the discrete comparison
