The continuous mirror question, as graded

Given a simple graph \(G=(V,E)\) and integer \(K\ge2\), with \(|V|\ge K\), does there exist a mass vector \(\mu\) such that \(\sum_{v\in V}\mu_v=1\), \(0\le\mu_v\le1/K\), and \(K^2\sum_{v\in V}\mu_v\sum_{w\in N(v)}\mu_w\ge K(K-1)\)?

Packaged proof task (what the prover saw — nothing else)

Given an explicitly encoded simple undirected graph \(G=(V,E)\), write \(m=|V|\) and \(N(v)=\{w\in V:\{v,w\}\in E\}\). The integer \(K\) is binary encoded and satisfies \(2\le K\le m\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; \(\tau\) is the support size, not the number of possible types. Here the society has one homogeneous type of total mass \(1\), so \(\tau=1\); vertex masses are allocation variables, not types.
A feasible allocation is a real vector \(\mu\in\mathbb R^V\) with \(\sum_{v\in V}\mu_v=1\) and \(0\le\mu_v\le 1/K\). Its welfare is \(W(\mu)=K^2\sum_{v\in V}\mu_v\sum_{w\in N(v)}\mu_w\).
The decision problem asks whether a feasible allocation satisfies \(W(\mu)\ge K(K-1)\), with exact comparison. Let \(L\) be the total binary input length; state running times in \(m,\tau,L,K\).

Is this continuous allocation decision problem solvable in polynomial time, or is it NP-hard?

For the discrete version, placing \(K\) identical agents injectively on vertices, each receiving utility equal to her occupied-neighbor count, deciding whether total welfare reaches \(K(K-1)\) is NP-complete and \(\mathrm{W}[1]\)-complete parameterized by \(K\). [Source](https://arxiv.org/html/2607.23248v1#S5)

Result

The problem is \(\mathrm{NP}\)-complete, even with \(\tau=1\). In fact, its answer is yes if and only if \(G\) contains a clique of size \(K\). It is also \(\mathrm{W}[1]\)-complete parameterized by \(K\).

1. An upper bound for fractional allocations

Define the simplex \(\Delta=\{x\in\mathbb R^V:x_v\ge 0,\ \sum_{v\in V}x_v=1\}\) and the quadratic function
\( F(x)=\sum_{v\in V}x_v\sum_{w\in N(v)}x_w. \)
Thus \(W(\mu)=K^2F(\mu)\). Let \(\omega(G)\) denote the maximum size of a clique in \(G\).

We prove that every \(x\in\Delta\) satisfies
\( F(x)\le 1-\frac1{\omega(G)}. \)

Suppose two nonadjacent vertices \(a,b\) have positive coordinates. Set
\( d_a=\sum_{w\in N(a)}x_w,\qquad d_b=\sum_{w\in N(b)}x_w. \)
Exchange the names of \(a,b\), if necessary, so that \(d_a\ge d_b\). Define \(x'\) by
\( x'_a=x_a+x_b,\qquad x'_b=0, \)
leaving every other coordinate unchanged.

The vector \(x'\) belongs to \(\Delta\). Because the graph is undirected, each edge contributes twice to \(F\). Because \(a,b\) are nonadjacent and there are no loops, there is no quadratic term involving only their coordinates. Consequently,
\( F(x')-F(x)=2x_b(d_a-d_b)\ge 0. \)

This operation decreases the number of positive coordinates by one. Repeating it therefore terminates at a vector \(y\in\Delta\) whose positive support \(C\) is a clique and for which \(F(y)\ge F(x)\).

Write \(r=|C|\). Since \(C\) is a clique,
\( F(y)=\sum_{v\in C}y_v(1-y_v)=1-\sum_{v\in C}y_v^2. \)
Furthermore,
\( 0\le\sum_{v\in C}\left(y_v-\frac1r\right)^2 =\sum_{v\in C}y_v^2-\frac1r. \)
Hence
\( F(x)\le F(y)\le 1-\frac1r\le 1-\frac1{\omega(G)}, \)
where the last inequality uses \(r\le\omega(G)\). This proves the bound.

The merging operation may violate the coordinate cap \(1/K\). That is harmless: we use it to establish an upper bound on the larger simplex \(\Delta\), which also bounds every capped feasible allocation.

2. Exact equivalence with clique existence

Suppose \(G\) contains a clique \(C\) of size \(K\). Allocate mass \(1/K\) to each vertex of \(C\) and zero elsewhere. This allocation is feasible, and
\( F(\mu)=K(K-1)\frac1{K^2}, \qquad W(\mu)=K(K-1). \)
Thus the continuous instance is a yes-instance.

Conversely, suppose a feasible allocation satisfies \(W(\mu)\ge K(K-1)\). Since \(\mu\in\Delta\), the proved bound gives
\( 1-\frac1K \le F(\mu) \le 1-\frac1{\omega(G)}. \)
Rearranging yields \(\omega(G)\ge K\), so \(G\) contains a clique of size \(K\).

This establishes both directions. Moreover, if no such clique exists, then \(\omega(G)\le K-1\), and every feasible allocation satisfies the strict separation bound
\( W(\mu)\le K^2\left(1-\frac1{K-1}\right) =K(K-1)-\frac K{K-1}. \)

3. Complexity and running times

For hardness, take an instance \((G,K)\) of \(K\)-Clique and retain the same graph and integer, adding the constant-size description of one homogeneous type of mass \(1\). The construction takes \(O(L)\) bit time and preserves \(K\). Its correctness follows from Section 2.

The standard \(\mathrm{NP}\)-completeness and parameterized \(\mathrm{W}[1]\)-completeness of Clique are also the hardness premises used in [Theorem 9 of the supplied source](https://arxiv.org/html/2607.23248v1#S5). The restriction \(2\le K\le m\) discards only trivially decidable Clique instances and does not affect hardness.

For membership in \(\mathrm{NP}\), a certificate consists of \(K\) distinct vertex identifiers. Checking all their pairs verifies that they form a clique. Section 2 proves that such a certificate exists for every continuous yes-instance; there is no need to certify arbitrary real coordinates. The certificate has \(O(K\log(m+1))\) bits, and verification takes polynomial bit time in \(m,\tau,L,K\), with \(\tau=1\).

The reverse map to \(K\)-Clique also preserves \(K\), establishing \(\mathrm{W}[1]\)-membership and hence completeness.

For an explicit deterministic algorithm, build an adjacency matrix and enumerate all \(K\)-vertex subsets. Its running time is
\( O\!\left(L+m^2+\binom mK K^2\right) \)
operations on words of \(O(\log(m+2))\) bits. Equivalently, its bit running time is
\( \left(L+m^2+\binom mK K^2\right)\operatorname{poly}(\log(m+2)). \)
This is an XP bound in \(K\), not a uniform polynomial bound. Since \(K\le m\) and \(\tau=1\), a uniform polynomial-time algorithm in \(m,\tau,L,K\) would imply \(\mathrm{P}=\mathrm{NP}\).
