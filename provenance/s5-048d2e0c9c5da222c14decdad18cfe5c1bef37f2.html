The continuous mirror question, as graded

Given a rational distribution \(\mu\) over finitely many types \(t=(x,j)\), with \(x\in[0,1]\), masses summing to one, and \(N\mu_t\) integral, let \(p_j\) be group \(j\)'s mass and \(N_j=Np_j\). For \(N_j\ge2\), set the public congestion parameter \(\alpha_j=\beta_j/(N_j-1)\) for \(\beta_j\in[0,1]\); singleton groups have \(\beta_j=0\). Find an exact deterministic rule \(f(\mu)\in[0,1]\) minimizing \(F_\mu(y)=\sum_j p_j\bigl[\beta_j+(1-\beta_j)\int |y-x|\,d\nu_j(x)\bigr]\), where \(\nu_j\) is group \(j\)'s conditional location distribution, and truthful for an individual location deviation that transfers mass \(1/N\) within their group under the paper's individual cost. Res-M gives a lower weighted median of weights \(\mu_t(1-\beta_j)\), with the smallest supported location as tie-break; if all weights vanish, choose the smallest supported location.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types \(t=(x,j)\) with positive binary-rational masses \(\mu_t\), where \(x\in[0,1]\cap\mathbb Q\), \(j\in\{1,\ldots,m\}\), and \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
A positive integer \(N\) is supplied in binary, with \(N\mu_t\) integral. Every group is nonempty; write \(p_j=\sum_x\mu_{(x,j)}\), \(N_j=Np_j\), and \(\nu_j(x)=\mu_{(x,j)}/p_j\).
Group memberships and binary-rational parameters \(\beta_j\in[0,1]\) are public. For \(N_j\ge2\), set \(\alpha_j=\beta_j/(N_j-1)\); for \(N_j=1\), require \(\beta_j=0\) and set \(\alpha_j=0\).
An individual of true type \((x,j)\) has cost \(C_{x,j}(y;\mu)=|y-x|+\alpha_j\left[N\sum_u\mu_{(u,j)}(1-|y-u|)-(1-|y-x|)\right]\).
The objective is \(F_\mu(y)=\sum_jp_j\left[\beta_j+(1-\beta_j)\int|y-x|\,d\nu_j(x)\right]\), minimized over \(y\in[0,1]\).
A deterministic rule, with \(N\) and the public parameters fixed, must output an exact minimizer on every admissible reported society and be strategyproof for location reports.
Precisely, for every true society \(\mu\), supported type \((x,j)\), rational report \(z\in[0,1]\), and arbitrary reports \(\eta\) of the other individuals, require \(C_{x,j}(f(\eta+N^{-1}\delta_{(x,j)});\mu)\le C_{x,j}(f(\eta+N^{-1}\delta_{(z,j)});\mu)\). Here \(N\eta_t\) is integral and its group masses are \(p_k-N^{-1}\mathbf1_{k=j}\).
Let \(L\) be the total binary input length, including locations, masses, \(N\), and public parameters; state running times in \(m,\tau,L\).

Can such an exact deterministic strategyproof rule be computed in time polynomial in \(m,\tau,L\), or is computing such a rule NP-hard?

For an explicitly listed finite society with public groups and private locations, Res-M is strategyproof and exactly minimizes social cost, and its stated rule is computable in polynomial time. This result does not state a running-time guarantee for the binary support representation above.

Modeling choices made when packaging the task

  • Specified rational locations, reports, and congestion parameters so that the computational input has a finite binary encoding.
  • Made N an explicitly supplied positive binary integer and included it in the total input length.
  • Retained only nonempty groups and set the singleton externality coefficient to zero, since a singleton has no competitors.
  • Expanded the individual cost with the individual's own contribution removed from the group sum.

Result

Such a rule is computable in polynomial time. Choose the leftmost weighted median, assigning each reported type \((x,j)\) weight \(\mu_{(x,j)}(1-\beta_j)\). If every weight is zero, output \(0\).

This rule exactly minimizes the stated objective and satisfies strategyproofness with arbitrary reports by the other individuals. It can be computed in
\(O\bigl((m+\tau+\tau\log(2+\tau))L^2\bigr)\)
bit operations using schoolbook arithmetic.

1. Individual costs are monotone away from the true location

Fix a true society \(\mu\) and a supported type \((x,j)\). Because the multiplicities \(N\mu_t\) are integral, we may regard the society as a finite population for the proof, without expanding it computationally.

Let \(u_1,\ldots,u_{N_j-1}\) be the true locations of this individual’s other group members, counted with multiplicity. Define
\(D(y)=\sum_{k=1}^{N_j-1}|y-u_k|\).

The given cost is exactly
\(C_{x,j}(y;\mu)=|y-x|+\alpha_j\bigl((N_j-1)-D(y)\bigr)\).
For a singleton group, the sum is empty and \(\alpha_j=0\).

The triangle inequality gives, for any \(a,b\in[0,1]\),
\(|D(b)-D(a)|\le (N_j-1)|b-a|\).

Moreover, under the singleton convention as well as for larger groups,
\(\alpha_j(N_j-1)=\beta_j\).

Consequently, if \(x\le a<b\), then
\[ C_{x,j}(b;\mu)-C_{x,j}(a;\mu) =(b-a)-\alpha_j(D(b)-D(a)) \ge (1-\beta_j)(b-a)\ge0. \]

If \(b<a\le x\), the same calculation gives
\[ C_{x,j}(b;\mu)-C_{x,j}(a;\mu) =(a-b)-\alpha_j(D(b)-D(a)) \ge (1-\beta_j)(a-b)\ge0. \]

Thus moving the facility farther away on either side of the individual’s true location cannot reduce their cost. This property concerns the true society and places no restriction on anyone’s reports.

2. Definition and exact optimality of the rule

For an admissible reported society \(\rho\), define the nonnegative measure
\[ \lambda_\rho=\sum_{(r,k)\in\operatorname{supp}(\rho)} \rho_{(r,k)}(1-\beta_k)\delta_r. \]

Its total weight is
\[ W=\lambda_\rho([0,1])=\sum_k p_k(1-\beta_k). \]
The public group memberships fix the group masses, so \(W\) is independent of location reports.

If \(W=0\), define \(f(\rho)=0\). Otherwise, define \(f(\rho)\) to be the smallest reported location \(a\) such that
\[ \lambda_\rho([0,a])\ge W/2. \]
Such a location exists because the measure has finite support and total weight \(W>0\).

Expanding the objective yields
\[ F_\rho(y)=\sum_k p_k\beta_k+ \sum_{(r,k)}\rho_{(r,k)}(1-\beta_k)|y-r|. \]
Its first term is constant. Write the second term as \(G_\rho(y)\).

If \(W=0\), every coefficient in \(G_\rho\) is zero, so every location is optimal.

Suppose \(W>0\), and put \(a=f(\rho)\). At every point \(y\) outside the support of \(\lambda_\rho\),
\[ G_\rho'(y)=2\lambda_\rho([0,y])-W. \]

For \(y<a\), the definition of \(a\) gives
\(\lambda_\rho([0,y])<W/2\), hence this derivative is negative. For \(y>a\), we have
\(\lambda_\rho([0,y])\ge\lambda_\rho([0,a])\ge W/2\), hence the derivative is nonnegative.

The function \(G_\rho\) is continuous and piecewise linear. Therefore it strictly decreases up to \(a\), when that interval is nonempty, and is nondecreasing after \(a\). Thus \(a\) is its leftmost minimizer, and \(f(\rho)\) exactly minimizes \(F_\rho\).

3. Strategyproofness with arbitrary other reports

Fix any true society \(\mu\), supported type \((x,j)\), rational alternative report \(z\), and arbitrary admissible reports \(\eta\) of the other individuals.

If \(W=0\), both outputs are \(0\), so the required inequality holds.

Suppose \(W>0\). Let \(A\) be the weighted measure contributed by \(\eta\), and let
\[ v=\frac{1-\beta_j}{N},\qquad H=W/2. \]
The weighted measures under the truthful and alternative reports are respectively
\(A+v\delta_x\) and \(A+v\delta_z\).

Denote their outputs by
\[ a=f(\eta+N^{-1}\delta_{(x,j)}),\qquad b=f(\eta+N^{-1}\delta_{(z,j)}). \]

For either measure, its cumulative weight is at least \(H\) at its selected location and is strictly below \(H\) at every smaller location.

We now prove that any change in the output moves it away from \(x\).

If \(b>a\), then \(x\le a\). Indeed, suppose \(x>a\). The truthful individual contributes no weight to \([0,a]\), so
\(A([0,a])\ge H\).
The alternative measure has cumulative weight at least \(A([0,a])\) there. Its selected location must therefore satisfy \(b\le a\), a contradiction.

If \(b<a\), then \(x\ge a\). Suppose instead that \(x<a\), and set \(q=\max\{b,x\}<a\). Because \(b\) is the alternative output,
\[ H\le A([0,b])+v\mathbf1_{\{z\le b\}} \le A([0,b])+v \le A([0,q])+v. \]
Since \(x\le q\), the rightmost expression is the truthful measure’s cumulative weight at \(q\). This contradicts its being strictly below \(H\) at every location smaller than \(a\).

There are now three exhaustive cases:

  • If \(b=a\), the individual’s cost is unchanged.
  • If \(b>a\), then \(x\le a<b\), so Section 1 gives \(C_{x,j}(a;\mu)\le C_{x,j}(b;\mu)\).
  • If \(b<a\), then \(b<a\le x\), so Section 1 gives the same inequality.

This proves exactly the strategyproofness requirement in the question, including its quantification over arbitrary reports \(\eta\).

4. Computation from the binary support

The algorithm processes only the listed support:

  • Compute each weight \(h_t=\mu_t(1-\beta_{j(t)})\) and their sum \(W\).
  • If \(W=0\), return \(0\).
  • Otherwise, sort the \(\tau\) entries by location and return the first location whose cumulative weight is at least \(W/2\).

Repeated locations may be processed consecutively; all such entries represent the same possible output.

For an explicit bit bound, write
\(\mu_t=a_t/b_t\) and \(\beta_j=c_j/d_j\), using positive denominators, and choose
\[ D=\left(\prod_t b_t\right)\left(\prod_j d_j\right). \]
The binary length of \(D\) is \(O(L)\), because the sum of the input denominator lengths is at most \(L\). Each weight can be represented by the integer
\[ I_t=Dh_t =\frac{D}{b_td_{j(t)}}a_t(d_{j(t)}-c_{j(t)}). \]
The division is exact. Also, \(0\le h_t\le\mu_t\) and \(\sum_t\mu_t=1\), so all cumulative integer weights are at most \(D\).

Thus weight computation uses \(O(m+\tau)\) arithmetic operations on integers of \(O(L)\) bits. Sorting takes \(O(\tau\log(2+\tau))\) rational comparisons, each implementable by cross multiplication on \(O(L)\)-bit integers. The final scan uses \(O(\tau)\) integer additions and comparisons.

With schoolbook arithmetic, the total bound is
\[ O\bigl((m+\tau+\tau\log(2+\tau))L^2\bigr) \]
bit operations. The output is \(0\) or an input location, so its encoding has length \(O(L)\). No population expansion is needed.
