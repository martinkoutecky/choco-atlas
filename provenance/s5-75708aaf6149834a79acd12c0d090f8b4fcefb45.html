The continuous mirror question, as graded

Given a rational distribution \(\mu\) over supported valuation types \(T\), rational per-capita supplies \(s\in\mathbb{Q}_{\ge 0}^q\), and valuations \(v_t\in[0,1]^q\) sharing a common weak order over the \(q\) categories, compute integral bundle vectors \(b^1,\ldots,b^r\in\mathbb{Z}_{\ge 0}^q\) and rational masses \(\lambda_1,\ldots,\lambda_r\ge 0\) such that \(\sum_\ell\lambda_\ell=1\), \(\sum_\ell\lambda_\ell b^\ell=s\), and \(\sum_jv_{tj}b^\ell_j\ge p_t-1\) for every supported type \(t\) and every bundle with \(\lambda_\ell>0\), where \(p_t=\sum_jv_{tj}s_j\). Can this be done in time polynomial in \(q,\tau,L\), with bundles remaining integral for each individual?

A society is given by its support: the list of the \(\tau\ge1\) valuation types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(q\ge1\) item categories (write \(m=q\)), with unlimited identical copies within each category and binary-rational per-capita supplies \(s\in\mathbb Q_{\ge0}^q\). Each type has additive binary-rational values \(v_t\in[0,1]^q\). A common category permutation \(\pi\) satisfies \(v_{t,\pi(1)}\ge\cdots\ge v_{t,\pi(q)}\) for every type; ties need not coincide across types.
Let \(L\) be the total input bit length and \(p_t=\sum_{j=1}^q v_{tj}s_j\). A feasible bundle distribution consists of finitely many individual bundles \(b^\ell\in\mathbb Z_{\ge0}^q\) and binary-rational masses \(\lambda_\ell>0\), with \(\sum_{\ell=1}^r\lambda_\ell=1\), \(\sum_{\ell=1}^r\lambda_\ell b^\ell=s\), and \(\sum_{j=1}^q v_{tj}b_j^\ell\ge p_t-1\) for every \(t\) and \(\ell\). Empty bundles and zero supplies are allowed.

Can a feasible bundle distribution always be computed in time polynomial in \(m=q,\tau,L\), or is this computation problem NP-hard?

For finitely many agents and explicitly listed indivisible items with a common non-increasing order and values in \([0,1]\), a polynomial-time algorithm constructs a partition whose every part has value at least each agent’s proportional share minus \(1\). Result

The computation problem is polynomial-time solvable. A feasible distribution with at most \(q+1\) bundles can always be constructed in time polynomial in \(q,\tau,L\).

The construction rounds cumulative supplies using a common offset. It applies directly to binary-encoded supplies, without expanding them into individual copies.

1. Put categories in their common order

Relabel categories so that, for every type \(t\),

\(v_{t1}\ge v_{t2}\ge\cdots\ge v_{tq}\ge0.\)

If the common permutation is not supplied, it can be found in polynomial time. For each category \(j\), compute \(w_j=\sum_{t=1}^{\tau}v_{tj}\), and sort categories by decreasing \(w_j\).

To justify this, consider any common permutation whose existence is promised. If category \(i\) precedes category \(j\), then \(v_{ti}-v_{tj}\ge0\) for every \(t\), hence \(w_i\ge w_j\). Moreover, equality \(w_i=w_j\) forces every nonnegative difference \(v_{ti}-v_{tj}\) to be zero. Thus sorting by \(w_j\), with arbitrary tie breaking, gives a valid common order.

Define cumulative supplies

\(C_0=0,\qquad C_j=\sum_{i=1}^{j}s_i\quad (1\le j\le q).\)

2. Construct bundles by rounding cumulative supplies

For an offset \(u\in[0,1)\), define

\(F_j(u)=\lfloor C_j+u\rfloor\quad (0\le j\le q),\)

and the bundle

\(b_j(u)=F_j(u)-F_{j-1}(u)\quad (1\le j\le q).\)

Because \(C_j\ge C_{j-1}\), monotonicity of the floor function gives \(b_j(u)\ge0\). Thus \(b(u)\) is an integer, nonnegative bundle. Also \(F_0(u)=0\), so its prefix counts satisfy

\(\sum_{i=1}^{j}b_i(u)=F_j(u).\)

We now describe a finite distribution over these bundles.

Write \(C_j=n_j+f_j\), where \(n_j=\lfloor C_j\rfloor\) and \(f_j\in[0,1)\). If \(f_j=0\), then \(F_j(u)=n_j\) throughout \([0,1)\). If \(f_j>0\), then

\(F_j(u)=n_j\) for \(0\le u<1-f_j\), and \(F_j(u)=n_j+1\) for \(1-f_j\le u<1\).

Consequently, all bundle coordinates are constant between consecutive points of

\(\mathcal A=\{0,1\}\cup\{1-f_j:1\le j\le q,\ f_j>0\}.\)

Sort the distinct points as

\(0=a_0<a_1<\cdots<a_r=1.\)

There are at most \(q\) interior points, so \(r\le q+1\). Output, for each \(\ell\in\{1,\ldots,r\}\),

\(\lambda_\ell=a_\ell-a_{\ell-1},\qquad b^\ell=b(a_{\ell-1}).\)

Every mass is positive, and their sum is \(1\). The use of the left endpoint is valid because each \(F_j\) is constant on the corresponding half-open interval \([a_{\ell-1},a_\ell)\).

3. The distribution uses exactly the supplies

For any nonnegative real number \(C=n+f\), with integer \(n\) and \(f\in[0,1)\),

\(\int_0^1\lfloor C+u\rfloor\,du=n(1-f)+(n+1)f=C.\)

For \(f=0\), the same identity follows because the integrand is constantly \(n\).

Since our finite distribution records exactly the interval lengths on which \(b(u)\) is constant, for every category \(j\),

\(\sum_{\ell=1}^{r}\lambda_\ell b_j^\ell =\int_0^1 b_j(u)\,du =\int_0^1F_j(u)\,du-\int_0^1F_{j-1}(u)\,du =C_j-C_{j-1} =s_j.\)

Thus the supply equalities hold exactly.

4. Every bundle satisfies every type’s guarantee

Fix a type \(t\) and an offset \(u\in[0,1)\). Define prefix errors

\(e_j=F_j(u)-C_j\quad (0\le j\le q).\)

Here \(e_0=0\). From \(\lfloor x\rfloor>x-1\), we obtain, for every \(j\ge1\),

\(e_j>u-1\ge-1.\)

Moreover,

\(b_j(u)-s_j=e_j-e_{j-1}.\)

Set \(v_{t,q+1}=0\). Expanding and regrouping the finite sum gives the summation-by-parts identity

\(\sum_{j=1}^{q}v_{tj}\bigl(b_j(u)-s_j\bigr) =\sum_{j=1}^{q}v_{tj}(e_j-e_{j-1}) =\sum_{j=1}^{q}(v_{tj}-v_{t,j+1})e_j.\)

The common ordering makes every coefficient \(v_{tj}-v_{t,j+1}\) nonnegative. Using \(e_j\ge-1\), we therefore obtain

\(\sum_{j=1}^{q}(v_{tj}-v_{t,j+1})e_j \ge-\sum_{j=1}^{q}(v_{tj}-v_{t,j+1}) =-v_{t1} \ge-1.\)

Since \(p_t=\sum_jv_{tj}s_j\), this proves

\(\sum_{j=1}^{q}v_{tj}b_j(u)\ge p_t-1.\)

The argument holds for every type and every offset, so every output bundle satisfies every required inequality. In fact, it proves the stronger bound with loss \(v_{t1}\).

5. Exact encoding and polynomial running time

All operations are exact rational arithmetic: summation, floor computation, subtraction, comparison, and sorting.

For completeness, let \(D\) be the product of the denominators of the input supplies. Its bit length is at most the sum of those denominator bit lengths, hence is bounded by \(L\). Every \(C_j\), breakpoint, and output mass can be represented with denominator \(D\). Their numerators have bit length polynomial in \(L+\log q\). If “binary-rational” specifically means dyadic rational, these quantities remain dyadic.

Bundle coordinates also have polynomial bit length. Indeed, writing \(C_{j-1}+u=k+\theta\), with \(\theta\in[0,1)\), gives

\(b_j(u)=\lfloor s_j+\theta\rfloor\in\{\lfloor s_j\rfloor,\lceil s_j\rceil\}.\)

The algorithm outputs at most \(q+1\) bundles, each with \(q\) coordinates, and performs polynomially many arithmetic operations on numbers of polynomial bit length. Recovering the common order likewise uses polynomial-time rational arithmetic.

Zero supplies and the all-zero supply vector require no exceptions: the formulas yield zero coordinates and, when appropriate, a single empty bundle. The type masses \(\mu_t\) do not enter the construction because the stipulated guarantees must hold for every listed type on every output bundle.

Thus the algorithm meets all feasibility and encoding requirements and runs in time polynomial in \(q,\tau,L\).

The proposed sorting rule is valid under the promised existence of a common permutation.

For any two categories \(i,j\), their relative order in a promised common permutation implies either \(v_{ti}\ge v_{tj}\) for every \(t\), or the reverse inequality for every \(t\). Consequently, their sums \(w_i,w_j\) have the corresponding order.

This argument uses the support as explicitly listed and does not require the type masses.

2. Integer bundles and finite positive masses

Since supplies are nonnegative, \(C_j\ge C_{j-1}\). Hence
\[ b_j(u)=\lfloor C_j+u\rfloor-\lfloor C_{j-1}+u\rfloor\ge0. \]
Each coordinate is an integer. Also, \(F_0(u)=\lfloor u\rfloor=0\) throughout the specified domain \(u\in[0,1)\), so the prefix-count identity is correct.

The breakpoint analysis is exact:

Removing duplicate breakpoints ensures every interval length is strictly positive. There are at most \(q\) interior breakpoints, hence at most \(q+1\) output bundles. Their masses telescope to \(1\). Repeated bundles, if any, are permitted by the task.
