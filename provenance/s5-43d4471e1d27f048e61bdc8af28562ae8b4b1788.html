The anchor (named result in the paper)

Theorem B.1 — class: hardness

The continuous mirror question, as graded

Given goods \(G\), a finite set of types \(T\) with rational masses \(p_t\ge 0\) summing to \(1\), and for each type a fixed reference MMS menu \(M_t=(M_{t1},\ldots,M_{tn})\) that partitions \(G\) into \(n\) whole bundles, decide whether there are nonnegative masses \(x_{tj}\) such that \(\sum_{j=1}^{n}x_{tj}=p_t\) for each \(t\), and \(\sum_{t\in T}\sum_{j:g\in M_{tj}}x_{tj}\le 1/n\) for every \(g\in G\). Each unit of mass receives a whole bundle; only the mass of a type choosing each bundle is split.

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a set of \(m\ge 1\) goods and let \(n\ge 1\) be an input integer specifying the common menu length.
A society is given by its support: the list \(T\) of its \(\tau\) types with positive mass, each mass \(p_t\) a binary rational, with \(\sum_{t\in T}p_t=1\). Here \(\tau\) is the support size, not the number of possible types.
For each type, the input explicitly gives a fixed reference MMS menu \(M_t=(M_{t1},\ldots,M_{tn})\): pairwise disjoint subsets whose union is \(G\); empty bundles are allowed. The menus are supplied, not computed, and valuations are not part of the input.
An assignment splits each type's mass among its listed bundles; each recipient receives one whole listed bundle, with no repeated copy of a good within that bundle. Each good has capacity \(1/n\).
Feasibility means that there exist \(x_{tj}\in\mathbb R_{\ge 0}\) satisfying \(\sum_{j=1}^{n}x_{tj}=p_t\) for every \(t\in T\), and \(\sum_{t\in T}\sum_{j:g\in M_{tj}}x_{tj}\le 1/n\) for every \(g\in G\). Let \(L\) be the total binary input length; state running times in \(m,\tau,n,L\).

Is this continuous menu-assignment feasibility problem solvable in polynomial time in \(m,\tau,n,L\), or is it NP-hard?

For a discrete society of \(n\) agents, each supplied with an \(n\)-bundle partition, selecting one listed bundle per agent with pairwise disjoint selections is NP-hard ([Barman, Rammohan, and Sethia](https://arxiv.org/html/2502.03789v2#A2)). No prior result settling the exact continuous formulation was identified in the search.

Modeling choices made when packaging the task

  • Omit zero-mass types from the support, so every listed mass is positive.
  • Treat n as an input menu-length and capacity-normalization parameter, independent of the support size.
  • Allow empty bundles, as in the discrete definition of partitions into subsets.
  • Use explicitly supplied partitions without valuation input or MMS verification, matching the anchor's computational input.
  • Take m and n to be positive integers and L to be the total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The continuous problem is polynomial-time solvable. In fact, every instance satisfying the stated hypotheses is feasible. This holds for arbitrary supplied partitions; their MMS interpretation is unnecessary.

Explicit feasible assignment

For every type \(t\in T\) and every bundle index \(j\in\{1,\ldots,n\}\), set
\(x_{tj}=p_t/n\).

These numbers are nonnegative. For each type \(t\),
\(\sum_{j=1}^{n}x_{tj}=n(p_t/n)=p_t\),
so its entire mass is assigned.

Now fix a good \(g\in G\). Because \(M_t\) is a partition of \(G\), there is exactly one index \(j_t(g)\) such that \(g\in M_{t,j_t(g)}\). Consequently its total load is
\(\sum_{t\in T}\sum_{j:g\in M_{tj}}x_{tj} =\sum_{t\in T}x_{t,j_t(g)} =\sum_{t\in T}p_t/n =1/n\).

Thus every good satisfies its capacity constraint with equality. Empty bundles cause no difficulty: they receive their assigned mass and consume no goods. Each recipient still receives one whole listed bundle; only the population mass is split.

This proves feasibility for all permitted \(m,\tau,n\).

Running time and bit complexity

On inputs promised to satisfy the hypotheses, the decision algorithm simply returns YES. Reading the input and returning this answer takes \(O(L)\) time.

An explicit rational witness also has polynomial size and can be constructed in polynomial time. Write the input mass as \(p_t=a_t/b_t\), with binary integers \(a_t,b_t\) and \(b_t>0\). Output
\(x_{tj}=a_t/(nb_t)\);
reduction to lowest terms is unnecessary.

Each numerator and denominator has \(O(L)\) bits, since both \(b_t\) and \(n\) are encoded in the input. Using elementary binary multiplication, compute \(nb_t\) once per type in \(O(L^2)\) bit operations, then output its \(n\) copies. A valid overall bound is
\(O(L+\tau L^2+\tau nL)\)
bit operations, with witness length \(O(\tau nL)\). These bounds are polynomial in \(m,\tau,n,L\).

Why the discrete hardness does not transfer

The cited discrete result requires choosing a single bundle for each indivisible agent. [Barman, Rammohan, and Sethia, Theorem B.1](https://arxiv.org/html/2502.03789v2#A2.Thmtheorem1), establish hardness under that requirement. The continuous formulation permits the uniform mass split proved above.

For a concrete distinction, take \(n=\tau=2\), masses \(p_1=p_2=1/2\), and goods \(G=\{a,b,c,d\}\), with menus
\(M_1=(\{a,b\},\{c,d\})\) and
\(M_2=(\{a,c\},\{b,d\})\).

Every bundle in the first menu intersects every bundle in the second, so selecting one bundle per agent cannot yield disjoint selections. Nevertheless, assigning mass \(1/4\) to each of the four listed bundles gives every good load \(1/2\), exactly its continuous capacity.

The continuous feasibility question is therefore completely settled by the explicit construction.
