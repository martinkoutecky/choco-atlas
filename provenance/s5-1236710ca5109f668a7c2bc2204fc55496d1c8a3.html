Theorem (Section 3.2 proxy-manipulation characterization) — class: other

The continuous mirror question, as graded

Given a rational finite-support distribution \(\mu\) over follower ideal positions, with unique median \(a\), and finitely many proxies with rational peaks \(q_1,\ldots,q_K\), let each proxy report a position in \(\mathbb{R}\), let each follower type delegate its mass to the nearest reported proxy, and let \(W(s)\) be the reported position of the proxy nearest \(a\), with fixed tie-breaking. Starting from truthful reports \(s=q\), decide whether there are a proxy \(j\) and a report \(r\in\mathbb{R}\) such that \(\lvert W(q_{-j},r)-q_j\rvert < \lvert W(q)-q_j\rvert\), and return a witnessing pair if one exists.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\geq1\) distinct follower ideal positions \(x_i\in\mathbb{Q}\), each with positive binary-rational mass \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types. Assume this distribution has a unique median \(a\).
There are \(m=K\geq1\) proxies with binary-rational peaks \(q_1,\ldots,q_m\); coincident peaks are allowed. Proxies have zero population mass and strictly prefer outcomes closer to their own peaks.
A report profile is \(s\in\mathbb{R}^m\). Each follower type delegates its entire mass to a nearest reported proxy, breaking ties by smallest proxy index. Define \(h(s)=\min\operatorname*{argmin}_{j\in\{1,\ldots,m\}}|s_j-a|\) and \(W(s)=s_{h(s)}\).
Starting from truthful reports \(s=q\), decide whether some proxy \(j\) can report \(r\in\mathbb{R}\) with \(|W(q_{-j},r)-q_j|<|W(q)-q_j|\), where \((q_{-j},r)\) replaces only coordinate \(j\); return a rational witnessing pair when one exists. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this manipulation decision problem in \(\mathrm{P}\), with a polynomial-time procedure returning a witnessing pair, or is its decision version \(\mathrm{NP}\)-hard?

For finite electorates in which each proxy also casts one self-vote, truthful manipulation exists exactly when no proxy peak equals the median of all voters and proxy peaks occur strictly on both sides of that median. [Bielous–Meir](https://link.springer.com/article/10.1007/s42979-025-04084-0)
The same work discusses weightless proxies, whose reports leave the population median fixed; the search located no complexity classification for the exact finite-support problem defined above. [Source](https://link.springer.com/article/10.1007/s42979-025-04084-0)

Modeling choices made when packaging the task

  • Normalized follower masses to sum to one and required rational support positions, making the rational distribution input explicit.
  • Resolved unspecified fixed tie-breaking by choosing the smallest proxy index for both delegation and outcome selection.
  • Made proxies weightless to preserve the graded question's explicitly fixed follower median and outcome rule; adding discrete self-votes would change that question.
  • Allowed coincident proxy peaks and required a nonempty proxy set and support.
  • Required returned witnesses to use rational reports while retaining the existential report domain over the real line, so the requested output has a finite binary representation.
  • Defined the graded proxy count K as m and L as total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is in \(\mathrm{P}\), and a rational witnessing pair can be returned in polynomial time.

More precisely, truthful manipulation exists if and only if

  • no proxy peak equals \(a\); and
  • proxy peaks occur strictly on both sides of \(a\).

An implementation uses \(O(\tau\log(\tau+1)+m)\) exact rational arithmetic operations and \(O((\tau\log(\tau+1)+m)L^2)\) bit operations under standard binary encoding and schoolbook arithmetic.

1. Computing the follower median

For a distribution of total mass \(1\), a median is a point \(y\) such that the mass strictly below \(y\) and the mass strictly above \(y\) are each at most \(1/2\).

Sort the support positions as \(y_1<\cdots<y_\tau\), retaining their masses \(\nu_1,\ldots,\nu_\tau\). Define \(C_0=0\) and \(C_k=\sum_{i=1}^k\nu_i\).

Let \(k\) be the first index for which \(C_k\geq 1/2\). If \(C_k=1/2\), then \(k<\tau\), and every point in \([y_k,y_{k+1}]\) is a median: its mass strictly below and strictly above are each at most \(1/2\). This contradicts uniqueness. Consequently, \(C_{k-1}<1/2<C_k\).

It follows that \(a=y_k\). Indeed, the masses strictly below and above \(y_k\) are \(C_{k-1}<1/2\) and \(1-C_k<1/2\). For any \(z<y_k\), the mass strictly above \(z\) is at least \(1-C_{k-1}>1/2\). For any \(z>y_k\), the mass strictly below \(z\) is at least \(C_k>1/2\).

Thus sorting and scanning compute \(a\) exactly. The subsequent proof uses the stipulated outcome rule \(W(s)=s_{h(s)}\); follower delegation creates no additional computational requirement for that rule.

2. Outcomes available to a deviating proxy

Write \(t=h(q)\), \(w=q_t=W(q)\), and \(d=|w-a|\). By definition, every truthful report satisfies \(|q_i-a|\geq d\).

Any proxy with \(q_j=w\) already receives its ideal outcome, so it cannot strictly improve.

Now consider a proxy with \(q_j\neq w\). Necessarily \(j\neq t\), so proxy \(t\) remains at \(w\) when \(j\) changes its report.

Among the unchanged proxies, \(t\) still has the smallest distance to \(a\), with the smallest index among those attaining that distance. Therefore, after any report \(r\) by \(j\):

  • if the selected proxy is unchanged, the outcome is \(w\);
  • if \(j\) is selected, the outcome is \(r\), and necessarily \(|r-a|\leq d\).

Conversely, every report satisfying \(|r-a|<d\) makes \(j\) the unique closest proxy to \(a\), hence produces outcome \(r\). Reports at distance exactly \(d\) are subject to the stated index tie rule; neither proof below requires winning such a tie.

3. Necessity of the characterization

First suppose some proxy peak equals \(a\). Then \(d=0\) and \(w=a\).

A proxy whose peak equals \(a\) has zero initial loss and cannot strictly improve. For any other proxy, a different proxy reporting \(a\) remains unchanged. Every selected report must consequently have distance zero from \(a\), so the outcome remains \(a\). Thus manipulation is impossible.

Now suppose no peak equals \(a\), but peaks do not occur on both sides. All peaks then lie strictly on one side.

If every peak lies to the right of \(a\), then \(w=a+d\) and \(q_j\geq w\) for every \(j\). Proxies with \(q_j=w\) cannot improve. For any other proxy \(j\), Section 2 shows that a deviation either leaves outcome \(w\), or produces a selected report \(r\) satisfying \(r\leq a+d=w\). In the latter case,
\(|r-q_j|=q_j-r\geq q_j-w=|w-q_j|\).
No strict improvement is possible.

If every peak lies to the left of \(a\), then \(w=a-d\) and \(q_j\leq w\). Any selected deviating report satisfies \(r\geq a-d=w\), giving
\(|r-q_j|=r-q_j\geq w-q_j=|w-q_j|\).
Again no proxy strictly improves.

This proves necessity, including coincident peaks and all index ties.

4. Sufficiency and a rational witness

Suppose no proxy peak equals \(a\), and peaks occur on both sides. Then \(d>0\).

Choose a proxy \(j\) on the side of \(a\) opposite to \(w\), so that \((q_j-a)(w-a)<0\). Such a proxy exists by hypothesis. Set

\(r=a-\dfrac{w-a}{2}=\dfrac{3a-w}{2}\).

This report lies on the same side of \(a\) as \(q_j\), at distance \(|r-a|=d/2\). Every unchanged proxy has distance at least \(d\) from \(a\). Therefore \(j\) becomes the unique selected proxy, and \(W(q_{-j},r)=r\).

Let \(e=|q_j-a|\). Since \(w\) is a closest truthful report, \(e\geq d\). Because \(q_j\) and \(w\) lie on opposite sides of \(a\), the initial loss is \(|w-q_j|=e+d\). Because \(r\) lies between \(a\) and \(q_j\), the new loss is \(|r-q_j|=e-d/2\).

Hence the loss decreases by \(3d/2>0\). The pair \((j,r)\) is a valid witness. Both \(a\) and \(w\) are rational, so \(r\) is rational.

5. Algorithm and bit complexity

The algorithm is:

  • Sort the follower support and compute \(a\) by cumulative mass.
  • Scan proxies in increasing index order to compute \(t=h(q)\) and \(w=q_t\), updating the selected index only when a strictly smaller distance is found.
  • If any peak equals \(a\), return no.
  • Find a proxy \(j\) satisfying \((q_j-a)(w-a)<0\). If none exists, return no.
  • Otherwise return yes, with witness \((j,(3a-w)/2)\).

Sections 3 and 4 prove correctness.

Sorting costs \(O(\tau\log(\tau+1))\) rational comparisons. Computing cumulative masses and scanning proxies require \(O(\tau+m)\) further arithmetic operations and comparisons.

All intermediate integers can be kept to \(O(L)\) bits. For cumulative masses, an unreduced denominator can be taken as the product of the denominators encountered so far. Its bit length is bounded by the total input denominator length, hence \(O(L)\). Since every partial mass sum lies in \([0,1]\), its numerator has the same bound. Coordinate differences, cross-products for comparisons, and the witness formula involve only a constant number of input rationals and also have \(O(L)\)-bit representations.

Schoolbook integer arithmetic therefore gives the stated bound of \(O((\tau\log(\tau+1)+m)L^2)\) bit operations. The witness has \(O(L)\) bits.

Thus the decision problem and witness construction are polynomial-time solvable. An additional claim of \(\mathrm{NP}\)-hardness under polynomial-time many-one reductions would imply \(\mathrm{P}=\mathrm{NP}\).
