The continuous mirror question, as graded

Given finitely many agent types \(T\) with rational masses \(\mu_t\), resource classes \(j\in[q]\) with rational per-capita supplies \(\rho_j\), a conflict graph \(H\), utilities \(u_t(j)\), threshold \(\eta\), and bundle cap \(s\), does there exist a feasible mass assignment \(x_{t,b}\)? Each bundle \(b\in\mathbb Z_{\ge0}^q\) must satisfy \(\sum_j b_j\le s\), have support independent in \(H\), and meet \(\sum_j u_t(j)b_j\ge\eta\) for its recipient type \(t\). Require \(\sum_b x_{t,b}=\mu_t\) for each type; in complete mode require \(\sum_{t,b}x_{t,b}b_j=\rho_j\) for each class, and in partial mode require \(\sum_{t,b}x_{t,b}b_j\le\rho_j\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\ge1\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m=q\ge1\) resource classes, binary-rational per-capita supplies \(\rho_j\ge0\), a simple undirected conflict graph \(H\) on the classes, utilities \(u_t(j)\in\mathbb Z_{\ge0}\), and positive integers \(\eta,s\). All numerical inputs use binary encoding; \(L\) is the total input bit length.
For type \(t\), an admissible bundle is \(b\in\mathbb Z_{\ge0}^{m}\) with \(\sum_j b_j\le s\), independent support \(\{j:b_j>0\}\) in \(H\), and \(\sum_j u_t(j)b_j\ge\eta\). Multiple units of one class are mutually compatible.
An assignment consists of real masses \(x_{t,b}\ge0\) on admissible bundles, satisfying \(\sum_bx_{t,b}=\mu_t\) for every type. Types may split their mass among bundles; every assigned bundle must meet the threshold.
In complete mode require \(\sum_{t,b}x_{t,b}b_j=\rho_j\) for every class; in partial mode require \(\sum_{t,b}x_{t,b}b_j\le\rho_j\). Bundles are specified implicitly by these conditions.

For each mode, is deciding existence of such an assignment in \(\mathsf P\), or is it \(\mathsf{NP}\)-hard? State running times in \(m,\tau,L,s,\eta\).

For finitely many agents and distinct indivisible jobs, both size-bounded modes are \(\mathsf{NP}\)-hard, already with an edgeless conflict graph and \(s=\eta=2\); both admit polynomial-time algorithms for \(s=1\) or for constant agent count and bundle cap ([source](https://arxiv.org/html/2403.04265v1)).
No result settling the exact mass-assignment problem above was located.

Modeling choices made when packaging the task

  • Normalize total society mass to one so that the stated supplies are per capita.
  • Use nonnegative integer utilities and a positive integer threshold, matching the discrete definition; take the bundle cap to be a positive integer.
  • Allow nonnegative rational supplies, including zero, and require a nonempty society and at least one resource class.
  • Interpret the conflict graph as a simple graph on classes: different units of the same class do not conflict, as prescribed by the graded question's independent-support condition.
  • Interpret assignment variables as nonnegative real masses and allow a type's mass to split among admissible bundles.
  • Identify m with the number q of resource classes and define L as the total binary input length; retain unrestricted s because classes can contribute repeated units.
  • Treat admissible bundles as implicit rather than explicitly listed input.

1. Classification

Both complete and partial modes are \(\mathsf{NP}\)-complete, even with one supported type, an edgeless conflict graph, and supplies equal to \(\tfrac12\).

There is also a polynomial-time algorithm whenever either the bundle cap or the threshold is fixed. More precisely, put \(k=\min\{s,\eta\}\). Both modes admit a deterministic algorithm running in

\(\displaystyle \left[L+\tau(m+1)\binom{m+k}{k}\right]^{O(1)},\)

with an absolute constant in the exponent. In particular, this is \((m+1)^{O(k)}\operatorname{poly}(\tau,L)\).

Thus both mass-assignment modes are polynomial-time solvable at \(s=\eta=2\), regardless of the support size. The finite-agent hardness in the question does not transfer to that case.

2. A finite generating set for admissible bundles

For a bundle \(b\), write \(|b|=\sum_j b_j\), and let \(e_j\) denote the \(j\)-th coordinate vector. Fix a type \(t\), and let \(\mathcal A_t\) be its set of admissible bundles.

Enumerate every vector \(c\in\mathbb Z_{\ge0}^m\) satisfying

\(\displaystyle |c|\le k,\qquad \operatorname{supp}(c)\text{ is independent in }H,\qquad u_t\cdot c\ge\eta.\)

For each such \(c\), include in a set \(\mathcal G_t\):

  • the bundle \(c\);
  • the bundle \(c+(s-|c|)e_j\), for every class \(j\) having no neighbor in \(\operatorname{supp}(c)\).

Classes already in \(\operatorname{supp}(c)\) are allowed in the second construction: repeated units of one class are compatible. Every generated bundle is admissible, because utilities are nonnegative.

Lemma. \(\operatorname{conv}(\mathcal A_t)=\operatorname{conv}(\mathcal G_t)\).

Proof. Take \(b\in\mathcal A_t\). Among the integer vectors \(c\) satisfying \(0\le c\le b\) coordinatewise and \(u_t\cdot c\ge\eta\), choose one minimal under coordinatewise order.

No retained unit has zero utility, since removing it would preserve the threshold. Consequently, every retained unit contributes at least one unit of utility.

Suppose \(|c|>\eta\). Removing any retained unit would leave at least \(|c|-1\ge\eta\) units, each contributing at least one. The remaining bundle would still meet the threshold, contradicting minimality. Hence \(|c|\le\eta\); also \(|c|\le s\). Therefore \(c\) is among the enumerated vectors.

Set \(r=b-c\) and \(h=s-|c|\). If \(h=0\), then \(r=0\), so \(b=c\in\mathcal G_t\).

If \(h>0\), then \(|r|\le h\), and

\(\displaystyle b=\left(1-\frac{|r|}{h}\right)c+\sum_{j:r_j>0}\frac{r_j}{h}\bigl(c+h e_j\bigr).\)

The coefficients are nonnegative and sum to one. Whenever \(r_j>0\), class \(j\) has no neighbor in \(\operatorname{supp}(c)\), because both supports lie within the independent support of \(b\). Thus every bundle appearing in this convex combination belongs to \(\mathcal G_t\).

This proves \(\mathcal A_t\subseteq\operatorname{conv}(\mathcal G_t)\). The reverse convex-hull inclusion follows from \(\mathcal G_t\subseteq\mathcal A_t\). \(\square\)

3. Algorithm and running time

There are exactly \(\binom{m+k}{k}\) nonnegative integer vectors with coordinate sum at most \(k\). Hence

\(\displaystyle |\mathcal G_t|\le(m+1)\binom{m+k}{k}.\)

Use one nonnegative variable \(x_{t,g}\) for each \(g\in\mathcal G_t\). Impose the original type-mass equations and resource equations or inequalities.

This explicit rational linear program is feasible exactly when the original problem is feasible. Indeed, the lemma allows every assigned admissible bundle to be replaced by a distribution over generated bundles with the same mean resource vector. This replacement preserves both the assigned type mass and all resource constraints.

Generating the bundles takes their number times a polynomial in \(L\). Every generated coordinate is at most \(s\), so its binary length is bounded by the input length. Polynomial-time rational linear programming therefore gives the stated bound

\(\displaystyle \left[L+\tau(m+1)\binom{m+\min\{s,\eta\}}{\min\{s,\eta\}}\right]^{O(1)}.\)

Since \(\binom{m+k}{k}\le(m+1)^k\), this is \((m+1)^{O(k)}\operatorname{poly}(\tau,L)\). In particular:

  • fixed \(s\): polynomial time, with arbitrary binary-encoded \(\eta\);
  • fixed \(\eta\): polynomial time, with arbitrary binary-encoded \(s\);
  • \(s=1\), or \(s=\eta=2\): polynomial time, with arbitrary \(\tau\).

The dependence is on the supplied support size \(\tau\); no enumeration of possible types is needed.

4. Hardness with one type and no conflicts

We reduce from PARTITION on positive integers: given \(a_1,\ldots,a_n\), decide whether some subset has half their total sum. This is a standard \(\mathsf{NP}\)-complete problem; see [Karp’s original paper](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

We may assume the total is even, since doubling every input integer preserves the answer and ensures an even total. Write

\(\displaystyle A=\sum_{i=1}^n a_i=2B,\qquad R=n+1,\qquad D=nA+1.\)

Construct an instance with one type of mass \(1\), and two resource classes \((i,0),(i,1)\) for every \(i\). Thus \(m=2n\). Let the conflict graph be edgeless, and set

\(\displaystyle s=n,\qquad \rho_{i,0}=\rho_{i,1}=\frac12,\)

\(\displaystyle u(i,0)=D R^{i-1},\qquad u(i,1)=D R^{i-1}+a_i,\)

\(\displaystyle \eta=D\sum_{i=1}^n R^{i-1}+B.\)

All utilities are positive integers, and all supplies and masses are dyadic rationals.

4.1 Every assigned bundle must attain the threshold exactly

The utility contained in the supply vector is

\(\displaystyle u\cdot\rho=\frac12\sum_{i=1}^n\bigl(u(i,0)+u(i,1)\bigr)=D\sum_{i=1}^nR^{i-1}+\frac A2=\eta.\)

Suppose either mode has a feasible assignment, and let \(z=\sum_bx_b b\) be its mean consumption vector.

In complete mode, \(z=\rho\). In partial mode, \(z\le\rho\) coordinatewise, and nonnegative utilities imply \(u\cdot z\le u\cdot\rho=\eta\).

On the other hand, every assigned bundle satisfies \(u\cdot b\ge\eta\), and \(\sum_bx_b=1\). Thus

\(\displaystyle \eta\le\sum_bx_b(u\cdot b)=u\cdot z\le\eta.\)

Consequently, every bundle with positive assigned mass satisfies \(u\cdot b=\eta\). Indeed, the nonnegative sum \(\sum_bx_b(u\cdot b-\eta)\) is zero.

4.2 Exact-threshold bundles encode partitions

Let \(b\) have size at most \(n\) and utility exactly \(\eta\). Define

\(\displaystyle d_i=b_{i,0}+b_{i,1},\qquad T=\sum_{i=1}^n a_i b_{i,1}.\)

The utility equation becomes

\(\displaystyle D\left(\sum_{i=1}^n d_iR^{i-1}-\sum_{i=1}^nR^{i-1}\right)=B-T.\)

Because \(|b|\le n\), we have \(0\le T\le nA<D\). Also \(0\le B<D\). Hence \(-D<B-T<D\).

The left side is an integer multiple of \(D\). It follows that both sides are zero:

\(\displaystyle T=B,\qquad \sum_{i=1}^n d_iR^{i-1}=\sum_{i=1}^nR^{i-1}.\)

Furthermore, \(0\le d_i\le n<R\). Uniqueness of base-\(R\) representation therefore gives \(d_i=1\) for every \(i\). Thus exactly one class from each pair is used, with one unit, and

\(\displaystyle \sum_{i:b_{i,1}=1}a_i=B.\)

So a feasible mass assignment in either mode implies a yes-instance of PARTITION.

4.3 A partition supplies a feasible assignment

Conversely, suppose \(S\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in S}a_i=B\).

Construct a bundle \(b^S\) using one unit of \((i,1)\) when \(i\in S\), and one unit of \((i,0)\) otherwise. Define \(b^{\overline S}\) analogously for the complementary subset.

Both bundles have size \(n\), independent support, and utility exactly \(\eta\). Assign mass \(\tfrac12\) to each. Each resource class is consumed with mean \(\tfrac12\), giving a complete assignment and therefore also a partial assignment.

4.4 Encoding length

Each constructed utility and the threshold have binary length

\(\displaystyle O\bigl(\log(nA+1)+n\log(n+1)\bigr).\)

The construction is therefore polynomial in the PARTITION input length. It proves \(\mathsf{NP}\)-hardness of both modes under the claimed restrictions.

5. Polynomial-size certificates

It remains to justify membership in \(\mathsf{NP}\), despite allowing real assignment masses.

For complete mode, write the finite bundle-variable system as \(My=r,\ y\ge0\). For partial mode, add one nonnegative slack variable per resource to obtain the same form. There are \(d=\tau+m\) rows. All matrix entries are integers of magnitude at most \(s\).

If the system is feasible, choose a feasible vector having minimum support. Its positive-variable columns are linearly independent. Otherwise, a nonzero dependence \(Mv=0\), supported on those columns, would allow a perturbation \(y-\varepsilon v\) that remains nonnegative and makes at least one positive coordinate zero, contradicting minimality. Explicitly, choose the sign of \(v\) so some entry is positive and take \(\varepsilon=\min_{v_i>0}y_i/v_i\).

Thus at most \(d\) variables are positive. Selecting an invertible square submatrix on those columns and applying Cramer’s rule shows that these values are rational. Clearing the input denominators and bounding determinants gives numerator and denominator bit lengths

\(\displaystyle O\bigl(L+d\log d+d\log(s+1)\bigr).\)

Therefore a yes-instance has a polynomial-size certificate listing at most \(\tau+m\) type-bundle pairs and their rational masses. Bundle admissibility, type-mass equations, and resource constraints can all be checked exactly in polynomial time.

Both modes belong to \(\mathsf{NP}\); combined with the reduction, both are \(\mathsf{NP}\)-complete.
