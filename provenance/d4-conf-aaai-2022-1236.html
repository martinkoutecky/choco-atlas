The continuous mirror question, as graded

Fix \(C \in \{\text{ODDFREE},\text{EVENFREE-4}\}\). Given a finite support of types \((F_i,a_i)\), each with \(\operatorname{btw}_C(F_i)=0\), and positive binary-rational masses \(\mu_i\) summing to \(1\), compute exactly \(Q=\sum_i \mu_i\,\mathbf{1}[a_i\text{ belongs to every preferred extension of }F_i]\).

Packaged proof task (what the prover saw — nothing else)

Fix \(C\in\{\mathrm{ODDFREE},\mathrm{EVENFREE}\text{-}4\}\). An argumentation framework is \(F=(A,R)\), with \(A\) finite and nonempty and \(R\subseteq A\times A\); self-attacks are allowed. Use standard Dung preferred semantics, denoted \(\operatorname{pref}(F)\).
The class \(\mathrm{ODDFREE}\) excludes directed simple cycles of odd length, including self-loops; \(\mathrm{EVENFREE}\text{-}4\) excludes directed simple cycles of even length at least \(4\).
A \(C\)-backdoor is a set \(S\subseteq A\) such that the induced framework \(F-S\) lies in \(C\). Let \(U_F\) be the underlying simple undirected graph. The torso \(G_F^S\) has vertex set \(S\), with distinct vertices adjacent if adjacent in \(U_F\) or both adjacent to the same connected component of \(U_F-S\).
Define \(\operatorname{btw}_C(F)=\min_{S:\,F-S\in C}\operatorname{tw}(G_F^S)\), using \(\operatorname{tw}(\varnothing)=-1\).
A society is given by its support: a list of \(\tau\) distinct types \((F_i,a_i)\), with \(a_i\in A_i\), each having positive binary-rational mass \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types.
Frameworks are explicitly encoded, and every type is promised to satisfy \(\operatorname{btw}_C(F_i)=0\); no backdoor is supplied. Set \(m=\max_i|A_i|\), and let \(L\) be the total input bit length. State running times in \(m,\tau,L\).
Compute exactly the rational \(Q=\sum_{i=1}^{\tau}\mu_i\mathbf{1}[\forall E\in\operatorname{pref}(F_i),\ a_i\in E]\).

Is exact computation of \(Q\) polynomial-time solvable in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard under polynomial-time Turing reductions, for each fixed choice of \(C\)?

For a single framework satisfying \(\operatorname{btw}_C(F)=0\), skeptical preferred acceptance is \(\Pi_2^{\mathrm P}\)-hard for both choices of \(C\). [Source](https://cdn.aaai.org/ojs/20501/20501-13-24514-1-2-20220628.pdf)
No result specifically addressing this explicitly supported, mass-weighted computation was located.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For each fixed \(C\in\{\mathrm{ODDFREE},\mathrm{EVENFREE}\text{-}4\}\), exact computation of \(Q\) is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. Hardness already holds for \(\tau=1\), and also holds for \(\tau=2\) with two distinct types of mass \(1/2\).

Consequently, a running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. The single-framework hardness theorem applies

Write \(b(F,a)=1\) when every preferred extension of \(F\) contains \(a\), and write \(b(F,a)=0\) otherwise.

Recall that \(E\subseteq A\) is admissible if it is conflict-free and defends every member: for every \(x\in E\) and every attacker \(y\) of \(x\), some member of \(E\) attacks \(y\). A preferred extension is an inclusion-maximal admissible set. Because \(A\) is finite and the empty set is admissible, preferred extensions exist.

Proposition 4 of the cited paper states that deciding \(b(F,a)\) is \(\Pi_2^{\mathrm P}\)-hard even when \(\operatorname{btw}_C(F)=0\), for each of the two classes in the question. Its torso and backdoor definitions agree with those here. Its proof uses frameworks outside \(C\) having a one-argument \(C\)-backdoor; that backdoor has a singleton torso of treewidth \(0\). Thus the convention \(\operatorname{tw}(\varnothing)=-1\) does not invalidate the exact-zero promise. [Proposition 4, *Tractable Abstract Argumentation via Backdoor-Treewidth*](https://cdn.aaai.org/ojs/20501/20501-13-24514-1-2-20220628.pdf)

We use this supplied hardness theorem; the transfer to weighted computation is proved below.

2. A one-call reduction to exact computation

Fix either class \(C\). Given a promised single-framework instance \((F,a)\), construct the society consisting solely of type \((F,a)\), with mass \(\mu_1=1\).

This is a valid input:

  • The support contains one distinct type.
  • Its mass is a positive binary rational, and the masses sum to \(1\).
  • Its framework satisfies the required exact-zero promise.
  • No backdoor needs to be supplied.

The resulting value is exactly \(Q=b(F,a)\). Therefore, one call to an exact-\(Q\) oracle decides skeptical preferred acceptance by testing whether its output equals \(1\).

The transformation takes time linear in the input encoding length. It has \(\tau=1\), \(m=|A|\), and total length \(L\) linear in the single-framework input length.

For completeness, the given \(\Pi_2^{\mathrm P}\)-hardness implies the requested \(\mathrm{NP}\)-hardness: \(\mathrm{NP}\subseteq\Pi_2^{\mathrm P}\), since an existential polynomial-time certificate condition can be preceded by an unused universal quantifier. Composing the single-framework hardness reduction with the construction above gives a polynomial-time Turing reduction from every language in \(\mathrm{NP}\) to exact computation of \(Q\).

This settles the classification. The singleton support is an allowed restriction of the intended problem, rather than a change to its interpretation.

3. Hardness also holds for two distinct supported types

To show that the conclusion survives a non-singleton support, let \(F^+\) be obtained from \(F\) by adding one fresh, unattacked argument \(z\), with no incident attacks.

First, \(\operatorname{pref}(F^+)=\{E\cup\{z\}:E\in\operatorname{pref}(F)\}\). Indeed, adjoining \(z\) preserves admissibility, so every maximal admissible set of \(F^+\) contains \(z\). Removing \(z\) preserves admissibility as well. A proper admissible enlargement on either side would give a proper admissible enlargement on the other side, establishing the claimed correspondence. Hence \(b(F^+,a)=b(F,a)\).

Second, \(\operatorname{btw}_C(F^+)=0\). Choose a \(C\)-backdoor \(S\) of \(F\) whose torso has treewidth \(0\). Adding an isolated argument creates no directed cycles, so \(F^+-S\in C\), and the torso on \(S\) is unchanged. Thus \(\operatorname{btw}_C(F^+)\leq0\).

To obtain equality, the original promise implies \(F\notin C\): otherwise the empty backdoor would give value \(-1\). The forbidden cycle in \(F\) remains in \(F^+\), so \(F^+\notin C\). Its backdoors are therefore nonempty, and their torsos have nonnegative treewidth. This proves equality.

Now use the two types \((F,a)\) and \((F^+,a)\), each of mass \(1/2\). They are distinct because their frameworks have different numbers of arguments. Their weighted value is \(Q=(b(F,a)+b(F^+,a))/2=b(F,a)\).

This again gives a one-call reduction, now with \(\tau=2\), \(m=|A|+1\), and \(L\) polynomial in the original input length.

4. General-support computation and running time

An exact algorithm can compute each bit \(b_i=b(F_i,a_i)\) and then sum the corresponding masses. The arithmetic introduces only polynomial overhead.

Specifically, write each input mass as \(\mu_i=p_i/d_i\), with positive integers encoded in binary. Let \(D=\prod_i d_i\). Then \(Q=N/D\), where \(N=\sum_i b_i p_i(D/d_i)\).

The bit length of \(D\) is at most the sum of the denominator bit lengths, hence is \(O(L)\). Moreover, \(0\leq N\leq D\), because the masses sum to \(1\). Products, exact divisions, summation, and reduction by a greatest common divisor therefore take polynomial time in \(\tau,L\); a conservative bound is \(O(\tau L^3)\) bit operations. The exact output has \(O(L)\) bits.

A direct algorithm for the acceptance bits is also available. For a framework with \(n\leq m\) arguments:

  • Enumerate all \(2^n\) subsets and record which are admissible.
  • Enumerate all pairs \(E\subsetneq T\). There are fewer than \(3^n\) such pairs, since each argument lies in \(E\), in \(T\setminus E\), or outside \(T\).
  • Mark an admissible \(E\) as nonmaximal whenever an admissible proper superset \(T\) occurs.
  • Test whether every remaining admissible set contains the queried argument.

Each admissibility test uses polynomial time in \(n\). Thus this gives exact computation in time \(O(\tau\,3^m\operatorname{poly}(m)+\tau L^3)\), without finding or verifying backdoors.

The polynomial arithmetic overhead cannot remove the hardness: even at constant support size, exact \(Q\) reveals the hard acceptance bit.
