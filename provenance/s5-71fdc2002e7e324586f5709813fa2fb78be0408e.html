The continuous mirror question, as graded

Given a finite item-type catalogue \(O\), a finite set \(T\) of complete utility types, rational population mass \(\mu\) on \(T\), rational per-capita supplies \(s_j\), item magnitudes \(w_j\), and a finite catalogue \(\mathcal B\subseteq\mathbb Z_{\ge0}^{O}\) of integral bundles satisfying \(u_\theta(j)\in\{-w_j,+w_j\}\) with zero-valued dummies allowed, find \(\pi_{\theta,b}\ge0\) such that \(\sum_b\pi_{\theta,b}=\mu_\theta\) and \(\sum_{\theta,b}b_j\pi_{\theta,b}=s_j\). Require the paper's EFX inequalities for every pair of positive-mass classes \((\theta,b)\) and \((\eta,d)\), evaluated using the first type's utilities, and require Pareto-optimality against all measurable allocations with the same population masses and item supplies; item units remain integral and only type mass is splittable.

Packaged proof task (what the prover saw — nothing else)

A society is an atomless probability space partitioned into types \(T\), given by its support: the list of \(\tau=|T|\) types with positive binary-rational masses \(\mu_\theta\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible utility types.
Input also includes an item-type catalogue \(O\), with \(m=|O|\ge1\), nonnegative rational per-capita supplies \(s_j\) with \(\sum_j s_j>0\), rational magnitudes \(w_j\ge0\), and each type's complete additive utility vector satisfying \(u_\theta(j)\in\{-w_j,+w_j\}\). An item with \(w_j=0\) is a dummy for every type; write \(u_\theta(b)=\sum_j b_j u_\theta(j)\).
A nonempty finite catalogue \(\mathcal B\subseteq\mathbb Z_{\ge0}^{O}\) is explicitly listed, with binary-encoded coordinates. An allocation is a matrix \(\pi_{\theta,b}\ge0\) satisfying \(\sum_b\pi_{\theta,b}=\mu_\theta\) and \(\sum_{\theta,b}b_j\pi_{\theta,b}=s_j\); individuals receive integral bundles, while type mass may be split.
EFX requires, for every ordered pair with \(\pi_{\theta,b}>0\) and \(\pi_{\eta,d}>0\), both \(u_\theta(b)-u_\theta(j)\ge u_\theta(d)\) whenever \(b_j>0\) and \(u_\theta(j)<0\), and \(u_\theta(b)\ge u_\theta(d)-u_\theta(j)\) whenever \(d_j>0\) and \(u_\theta(j)>0\). Each removal deletes one unit; zero-valued units impose no condition.
Pareto-optimality excludes any measurable reassignment of integral bundles from \(\mathbb Z_{\ge0}^{O}\), preserving types and total supplies, that weakly improves individual utility almost everywhere and strictly improves it on a set of positive measure. Competitors need not use \(\mathcal B\) or satisfy EFX.

Is deciding whether an EFX and Pareto-optimal allocation exists solvable in polynomial time, or is it NP-hard? State running times in \(m\), \(\tau\), \(|\mathcal B|\), and the total input bit length \(L\).

For finite societies with absolute identical additive utilities and unrestricted bundles, an EFX and Pareto-optimal allocation always exists and is computable in \(O(\max\{M\log M,Mn\})\) arithmetic operations, for \(M\) individual items and \(n\ge2\) agents ([Aleksandrov–Walsh](https://cgi.cse.unsw.edu.au/~tw/awki2020.pdf)).
No result settling this exact atomless, integral-bundle, catalogue-constrained existence problem was identified in the literature search.

Result

The problem is \(\mathrm{NP}\text{-complete}\), even when every magnitude is \(1\), all supplies and type masses are positive dyadic rationals, and all catalogue coordinates are polynomially bounded in the reduction size.

Writing \(B=|\mathcal B|\), a deterministic algorithm runs in

\(\bigl(B(B+1)\bigr)^\tau\operatorname{poly}(m,\tau,B,L)\)

bit operations. Thus the problem is polynomial-time solvable for every fixed support size \(\tau\), but not in general unless \(\mathrm P=\mathrm{NP}\).

1. Exact characterization of Pareto-optimality

For each item type \(j\), define \(v_j=\max_{\theta\in T}u_\theta(j)\), where the maximum is over the given positive-mass support.

Lemma. A feasible catalogue allocation is Pareto-optimal against unrestricted measurable integral-bundle reassignments if and only if

\(\pi_{\theta,b}>0,\ b_j>0\ \Longrightarrow\ u_\theta(j)=v_j.\)

Necessity. Suppose the condition fails. Since utilities have identical absolute magnitudes, there are supported types \(\theta,\eta\) with \(u_\theta(j)=-w_j<0<w_j=u_\eta(j)\), and a positive-mass set of type \(\theta\) individuals holding a unit of \(j\).

Atomlessness permits choosing measurable subsets of equal positive measure: one from those holders and one from type \(\eta\). Remove one unit of \(j\) from each individual in the first subset and add one unit to each individual in the second subset. Supplies are preserved. Every affected individual gains \(w_j>0\), and everyone else is unchanged. The resulting bundles are integral and measurable, so this is an admissible Pareto improvement.

Sufficiency. An allocation satisfying the condition has aggregate utility \(\sum_j v_js_j\). Every unrestricted competitor has aggregate utility at most this quantity, because each unit contributes at most \(v_j\).

These aggregate utilities are well-defined: finite supplies imply integrability of every nonnegative bundle coordinate, and hence of additive utility. A weak improvement almost everywhere that is strict on a positive-measure set would strictly increase aggregate utility, which is impossible. This proves the lemma.

Call a type–bundle pair satisfying the lemma admissible. Admissibility can be checked directly from the input.

2. Reduction from Independent Set

We reduce from Independent Set: given a simple graph \(G\) on vertices \(\{1,\ldots,n\}\) and \(1\le k\le n\), decide whether it has an independent set of size at least \(k\). This is the standard NP-complete problem obtained from Clique by graph complementation. [Karp, *Reducibility among Combinatorial Problems*](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Types and parameters

Let \(N\) be the smallest power of two at least \(n\). Introduce vertex types \(1,\ldots,n\) and an auxiliary type \(0\), with masses

\(\mu_i=\mu=\frac1{2N}\quad(1\le i\le n),\qquad \mu_0=1-n\mu.\)

All masses are positive dyadic rationals.

Define

\(U_i=4i,\qquad C=4n+4,\qquad K_i=U_i+C,\qquad H=2K_n+2=16n+10.\)

Items and utilities

Introduce item types \(p_i,q_i,r_i\) for each vertex \(i\), and one item type \(h\). Every magnitude is \(1\). The types that like each item are exactly:

| Item | Types assigning utility \(+1\) |
|---|---|
| \(p_i\) | Type \(i\) |
| \(q_i\) | Types \(0,i\), and every type \(a<i\) with \(\{a,i\}\in E(G)\) |
| \(r_i\) | Types \(0,i\) |
| \(h\) | Type \(0\) |

Every other utility is \(-1\).

Catalogue

Let \(e_j\) denote the unit bundle of item type \(j\). List the following bundles:

\(A_i=e_{p_i}+U_i e_{q_i},\qquad I_i=e_{p_i}+K_i e_{r_i},\)

\(Q_i=(H-U_i)e_h+U_i e_{q_i},\qquad R_i=(H-K_i)e_h+K_i e_{r_i},\)

and \(Z=He_h\).

There are \(B=4n+1\) distinct bundles. Every displayed coordinate is a nonnegative integer; in particular, \(H>K_i\) for every \(i\).

Supplies and encoding size

Set

\(s_{p_i}=\mu,\qquad s_{q_i}=U_i\mu,\qquad s_{r_i}=K_i\mu,\)

and

\(s_h=H\mu_0-\mu\sum_{i=1}^n U_i-Ck\mu.\)

These supplies are dyadic rationals. They are all positive: using \(n\mu\le\frac12\), \(U_i\le4n\), and \(k\le n\),

\(s_h\ge\frac H2-\frac{4n}{2}-\frac C2=4n+3>0.\)

The constructed parameters satisfy

\(m=3n+1,\qquad \tau=n+1,\qquad B=4n+1.\)

All catalogue coordinates are \(O(n)\), and the rational numerators and denominators have \(O(\log n)\) bits. The construction takes \(O(n^2\log n)\) bit operations and has total encoding length \(O(n^2\log n)\).

3. Necessity: every valid allocation yields an independent set

Suppose the constructed instance admits an EFX and Pareto-optimal allocation.

Pareto-optimality fixes which types can receive which bundles

Each \(A_i\) and \(I_i\) contains \(p_i\), which only type \(i\) likes. By the lemma, these bundles can be assigned only to type \(i\).

Each \(Q_i,R_i,Z\) contains \(h\), which only type \(0\) likes. These bundles can be assigned only to type \(0\).

Conversely, every bundle assigned to its indicated type contains only positively valued items, so all these indicated pairs are admissible.

Write \(x_i=\pi_{i,A_i}\). The type-mass equation gives \(\pi_{i,I_i}=\mu-x_i\), with \(0\le x_i\le\mu\).

The supply equations for \(q_i\) and \(r_i\), respectively, give

\(\pi_{0,Q_i}=\mu-x_i,\qquad \pi_{0,R_i}=x_i.\)

Consequently,

\(\pi_{0,Z}=\mu_0-n\mu=1-\frac nN\ge0.\)

The resulting consumption of \(h\) is

\(H\mu_0-\sum_i U_i(\mu-x_i)-\sum_i K_i x_i =H\mu_0-\mu\sum_i U_i-C\sum_i x_i.\)

Comparison with the prescribed supply \(s_h\) yields \(\sum_i x_i=k\mu\).

EFX prevents a vertex type from splitting between its choices

Type \(i\) values its two bundles at

\(u_i(A_i)=U_i+1,\qquad u_i(I_i)=K_i+1.\)

If both had positive mass, applying EFX from \(A_i\) toward \(I_i\), and removing one positively valued unit from \(I_i\), would require

\(U_i+1\ge K_i=U_i+C.\)

This is false because \(C>1\). Therefore \(x_i\in\{0,\mu\}\).

Let \(S=\{i:x_i=\mu\}\). The equation \(\sum_i x_i=k\mu\) now implies \(|S|=k\).

Adjacent vertices cannot both be selected

Suppose \(i<j\), \(\{i,j\}\in E(G)\), and \(i,j\in S\). Type \(i\) likes \(q_j\) and dislikes \(p_j\), so

\(u_i(A_i)=U_i+1,\qquad u_i(A_j)=U_j-1.\)

EFX after removing one \(q_j\) unit from \(A_j\) requires \(U_i+1\ge U_j-2\). But \(U_j-U_i=4(j-i)\ge4\), so \(U_j-2>U_i+1\).

This contradiction proves that \(S\) is an independent set of size \(k\).

4. Sufficiency: every independent set yields a valid allocation

Suppose \(G\) has an independent set \(S\) of size \(k\); any larger independent set can be reduced to this size.

Assign all mass \(\mu\) of vertex type \(i\) to \(A_i\) when \(i\in S\), and to \(I_i\) otherwise.

For type \(0\), assign mass \(\mu\) to \(R_i\) when \(i\in S\), and to \(Q_i\) otherwise. Assign its remaining mass \(1-n/N\) to \(Z\).

The supply identities established above show that this allocation is feasible. Atomlessness permits the required finite partition of type \(0\). Every recipient likes every item in its assigned bundle, so the Pareto lemma proves unrestricted Pareto-optimality.

It remains to verify EFX.

Every assigned bundle contains only goods for its recipient. Thus all conditions involving removal of an own negatively valued unit are vacuous. Since every magnitude is \(1\), the other EFX conditions require

\(u_\theta(b)\ge u_\theta(d)-1\)

whenever the observed bundle \(d\) contains an item liked by type \(\theta\).

Comparisons between vertex types

For distinct vertex types \(i,j\), type \(i\) dislikes every item in \(I_j\), so observing \(I_j\) imposes no condition.

Type \(i\) likewise dislikes every item in \(A_j\), unless \(i<j\) and \(\{i,j\}\in E(G)\). In that exceptional case, \(u_i(A_j)=U_j-1\). If \(A_j\) is assigned, then \(j\in S\), and independence implies \(i\notin S\). Type \(i\) therefore receives \(I_i\), and

\(u_i(I_i)=K_i+1>C>U_j-2.\)

Hence the required EFX inequality holds.

Each vertex type receives just one bundle, so comparisons within that type also satisfy EFX.

Vertex types observing auxiliary bundles

For any vertex type \(i\),

\(u_i(Q_j)\le-H+2U_j<0,\qquad u_i(R_j)\le-H+2K_j\le-2,\qquad u_i(Z)=-H<0.\)

Its own utility is positive. Removing any positively valued unit from an observed auxiliary bundle lowers that bundle’s evaluated utility further, so every required inequality holds.

Auxiliary type comparisons

Type \(0\) values every \(Q_i,R_i,Z\) at exactly \(H\). It evaluates vertex bundles as

\(u_0(A_i)=U_i-1<H,\qquad u_0(I_i)=K_i-1<H.\)

Thus every comparison involving type \(0\) as observer satisfies EFX.

This completes both directions of the reduction and proves NP-hardness.

5. Polynomial certificates

We next prove membership in \(\mathrm{NP}\), including the possibility that a solution initially uses real masses.

Suppose a valid allocation exists, and let \(S\) be its positive support. Restrict the feasibility equations to variables indexed by \(S\):

\(\sum_{b:(\theta,b)\in S}x_{\theta,b}=\mu_\theta,\qquad \sum_{(\theta,b)\in S}b_jx_{\theta,b}=s_j,\qquad x_{\theta,b}\ge0.\)

This is a nonempty bounded rational polytope: each variable is bounded above by its type mass. Choose an extreme point.

There are \(r=m+\tau\) equality rows. An extreme point has at most \(r\) positive variables. Indeed, if its positive columns were linearly dependent, a nonzero dependence would permit sufficiently small perturbations in both directions while retaining nonnegativity and all equalities, contradicting extremality.

The extreme point has polynomially bounded rational encoding length. To see this explicitly, choose a nonsingular square minor determining its positive variables, clear the right-hand-side denominators, and apply Cramer’s rule. The common denominator has \(O(L)\) bits, and determinant bounds give \(O(r(L+\log r))\) bits per coordinate.

Its support is contained in \(S\). Admissibility and EFX are both preserved when support pairs are removed, so this extreme point is another valid allocation.

A certificate therefore consists of at most \(m+\tau\) type–bundle pairs and polynomial-bit rational masses. Supply equations, admissibility, and every ordered EFX comparison can be checked in polynomial time. More specifically, after reading the input, verification needs \(O(m((m+\tau)^2+\tau))\) exact rational arithmetic operations on polynomial-bit numbers.

Together with the reduction, this proves NP-completeness.

6. Running time for fixed support size

The following algorithm provides the stated dependence on \(\tau\).

For every type \(\theta\) and catalogue bundle \(b\), precompute:

  • \(v_\theta(b)=u_\theta(b)\);
  • \(c_\theta(b)=u_\theta(b)+\min_{j:b_j>0,\ u_\theta(j)<0}|u_\theta(j)|\), or \(+\infty\) if there is no such item;
  • \(g_\theta(b)=\min_{j:b_j>0,\ u_\theta(j)>0}u_\theta(j)\), when this set is nonempty.

For an allocation, define

\(\beta_\theta=\min_{b:\pi_{\theta,b}>0}v_\theta(b),\qquad \alpha_\theta=\min_{b:\pi_{\theta,b}>0}c_\theta(b).\)

The first minimum exists because \(\mu_\theta>0\). The second can equal \(+\infty\).

There are at most \(B\) candidates for each \(\beta_\theta\), and at most \(B+1\) candidates for each \(\alpha_\theta\). Enumerate these threshold choices.

For each choice, allow a variable \(x_{\eta,d}\) only if:

  • \((\eta,d)\) is admissible.
  • \(v_\eta(d)\ge\beta_\eta\).
  • If \(d\) contains an item negatively valued by \(\eta\), then \(c_\eta(d)\ge\alpha_\eta\); this is impossible when \(\alpha_\eta=+\infty\).
  • For every \(\theta\) with finite \(\alpha_\theta\), \(v_\theta(d)\le\alpha_\theta\).
  • For every \(\theta\) for which \(g_\theta(d)\) is defined, \(v_\theta(d)-g_\theta(d)\le\beta_\theta\).

Solve the supply and type-mass equations over these allowed variables by rational linear programming.

Soundness. Consider any resulting positive cells \((\theta,b)\) and \((\eta,d)\). For an own negative item, conditions 3 and 4 give

\(u_\theta(b)-u_\theta(j)\ge c_\theta(b)\ge\alpha_\theta\ge u_\theta(d).\)

For a positively valued item in \(d\), conditions 2 and 5 give

\(u_\theta(b)\ge\beta_\theta\ge u_\theta(d)-g_\theta(d)\ge u_\theta(d)-u_\theta(j).\)

Hence the allocation is EFX, and admissibility makes it Pareto-optimal.

Completeness. Given any valid allocation, choose its actual minima \(\alpha_\theta,\beta_\theta\). Its positive cells satisfy conditions 1–3 by definition. EFX implies conditions 4–5: minimize over own negative-item removals for condition 4, and use an own bundle attaining \(\beta_\theta\) for condition 5. Thus one enumerated linear program is feasible.

Precomputation requires \(O(m\tau B)\) rational arithmetic operations. There are at most \(\bigl(B(B+1)\bigr)^\tau\) linear programs, each with at most \(\tau B\) variables and \(m+\tau\) equality rows. Rational linear programming is polynomial in its encoding length. [Khachiyan, *A polynomial algorithm in linear programming*](https://www.mathnet.ru/eng/dan42319).

The total bit running time is therefore

\(\bigl(B(B+1)\bigr)^\tau\operatorname{poly}(m,\tau,B,L).\)

The [Aleksandrov–Walsh finite-society theorem](https://cgi.cse.unsw.edu.au/~tw/awki2020.pdf) is consistent with this classification: its allocation algorithm does not enforce an explicitly listed bundle catalogue.
