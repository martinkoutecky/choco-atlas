Packaged proof task (what the prover saw — nothing else)

Let \(V\) be a nonempty set of \(m\) Boolean context variables. The shared ontology \(O\) consists of annotated \(\mathcal{EL}\) axioms \(\langle\lambda:\varphi\rangle\), where \(\varphi\) is a propositional formula over \(V\); for a valuation \(W\), put \(O_W=\{\lambda:\langle\lambda:\varphi\rangle\in O,\ W\models\varphi\}\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types; require \(\sum_t\mu_t=1\).
Each type supplies a total numerical ranking \(r_t:\{0,1\}^{m}\to[0,1]\cap\mathbb Q\), represented by a Boolean circuit outputting a binary numerator and positive denominator. Rankings may have ties and need not attain \(1\).
Given a CQ \(q(x)\), let \(N\) be the individual names occurring in \(O\) or \(q\), and let \(B\) contain all substitutions \(\theta:x\to N\), including substitutions of rank zero. Define \(s_t(\theta)=\max\{r_t(W):O_W\models q(x\theta)\}\), with the empty maximum equal to \(0\).
Fix a positive integer \(k\). The proposed answer is an ordered tuple \(A=(\theta_1,\ldots,\theta_\ell)\) of distinct members of \(B\), with \(0\le\ell\le k\). It is top-\(k\) for type \(t\) if either its entries exhaust \(B\), or \(\ell=k\), \(s_t(\theta_1)\ge\cdots\ge s_t(\theta_k)\), and \(s_t(\theta)\le s_t(\theta_k)\) for every \(\theta\in B\setminus\{\theta_1,\ldots,\theta_k\}\). Ties require no further tie-breaking.
Given a binary rational \(\eta\in[0,1]\), the decision problem asks whether \(\sum_{t:A\text{ is top-}k\text{ for }t}\mu_t\ge\eta\).
Is this decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard, in combined complexity? State running times in \(m\), \(\tau\), the total input bit length \(L\), \(|O|\), \(|q|\), and \(|N|\), with \(k\) fixed.
For one ranking, top-\(k\) verification over \(\mathcal{EL}\) is \(\Delta_2^{\mathrm P}\)-complete in ranking and combined complexity, and polynomial in data and KB complexity when the ranking and query are fixed ([source](https://www.ijcai.org/proceedings/2017/0131.pdf)).
No result settling this exact support-distribution threshold problem was identified in the literature search.

Result and interpretation

For every fixed positive \(k\), the problem is \(\Delta_2^{\mathrm P}\)-complete under polynomial-time many-one reductions, where \(\Delta_2^{\mathrm P}=\mathrm P^{\mathrm{NP}}\). In particular, it is \(\mathrm{NP}\)-hard and therefore has no polynomial-time algorithm unless \(\mathrm P=\mathrm{NP}\).

Here the proposed tuple \(A\) is part of the input: the question asks whether this particular tuple receives sufficient support.

The hardness holds even with \(\tau=1\), mass \(1\), threshold \(\eta=1\), a fixed atomic query, and a fixed ontology containing just \(k+1\) annotated assertions. Thus the explicit support representation does not remove the difficulty.

1. Preliminary cases

Let \(d\) be the number of answer variables and \(n=|N|\). Then \(|B|=n^d\), with the usual convention that there is exactly one substitution when \(d=0\).

Assume the input satisfies the stated validity requirements, including distinct entries of \(A\) belonging to \(B\).

If \(A\) exhausts \(B\), it is top-\(k\) for every type under the definition in the question, so the answer is yes. This includes \(B=\varnothing\) and \(A=()\).

If \(A\) does not exhaust \(B\) and \(\ell<k\), it is top-\(k\) for no type. The answer is then yes exactly when \(\eta=0\).

It remains to consider \(\ell=k<|B|\).

2. Membership in \(\Delta_2^{\mathrm P}\)

We use the standard fact that Boolean CQ entailment over \(\mathcal{EL}\) is in \(\mathrm{NP}\) in combined complexity. This is recalled in Section 6 of the [cited paper](https://www.ijcai.org/proceedings/2017/0131.pdf). It applies here because, after choosing \(W\) and a substitution, \(O_W\) is an ordinary \(\mathcal{EL}\) ontology and the instantiated query is a Boolean CQ.

Fix a type \(t\). Let \(b\ge1\) bound the number of output bits of its denominator circuit. Every denominator is consequently smaller than \(2^b\).

If two attainable rational scores \(a/u\) and \(c/v\) differ, then

\(\left|a/u-c/v\right|=|av-cu|/(uv)\ge1/(uv)>2^{-2b}\).

This also applies when one score is \(0\), represented as \(0/1\). Every answer score is either \(0\) or an attained ranking value, since there are finitely many valuations.

Put \(D=2^{2b+1}\). It follows that the map \(s\mapsto\lfloor Ds\rfloor\) preserves both equality and strict ordering among all answer scores: distinct scores become numbers differing by more than \(2\) before rounding.

For each proposed entry define

\(h_{t,i}=\lfloor D s_t(\theta_i)\rfloor\).

Also define the largest outsider score, including a zero baseline:

\(u_t=\max\bigl(\{0\}\cup\{s_t(\theta):\theta\in B\setminus A\}\bigr)\),

and put \(h_{t,\mathrm{out}}=\lfloor Du_t\rfloor\).

For an integer \(j>0\), the predicate \(s_t(\theta_i)\ge j/D\) is in \(\mathrm{NP}\). A certificate consists of:

  • a valuation \(W\);
  • an \(\mathcal{EL}\) CQ-entailment certificate for \(O_W\models q(x\theta_i)\).

Evaluating annotations and the ranking circuit, and comparing the resulting rational with \(j/D\), all take polynomial time. The existential characterization is correct because \(j/D>0\), so the empty-maximum convention cannot create a false witness.

Similarly, \(u_t\ge j/D\) is in \(\mathrm{NP}\): additionally guess a substitution \(\theta\in B\setminus A\). Its representation requires \(O(d\log(n+1))\) bits.

For \(j=0\), both predicates are automatically true. Binary search over \(j\in\{0,\ldots,D\}\) therefore computes each integer \(h_{t,i}\) and \(h_{t,\mathrm{out}}\) using \(O(b+1)\) NP-oracle calls.

By the order-preservation property, \(A\) is top-\(k\) for this type exactly when

\(h_{t,1}\ge\cdots\ge h_{t,k}\quad\text{and}\quad h_{t,\mathrm{out}}\le h_{t,k}\).

Thus ties, zero scores, and rankings that never attain \(1\) are all handled correctly.

Repeat this computation for every listed type. Finally, add exactly the masses of the accepting types and compare the sum with \(\eta\). Binary rational arithmetic is polynomial-time here: a common denominator obtained by multiplying the input denominators has bit length at most their total input bit length, hence \(O(L)\).

Taking \(b\) to be the largest denominator-output width across all circuits, the algorithm uses

\(O\bigl(\tau(k+1)(b+1)\bigr)\)

NP-oracle calls and polynomial work per call. Since \(b\le L\) and \(k\) is fixed, this proves membership in \(\Delta_2^{\mathrm P}\).

3. Hardness: encoding an oracle computation

We prove \(\Delta_2^{\mathrm P}\)-hardness directly, without assuming that the cited single-ranking hardness reduction transfers to the present definitions.

Let \(H\) be any language in \(\mathrm P^{\mathrm{NP}}\). By the NP-completeness of SAT, there is a deterministic polynomial-time SAT-oracle machine \(M\) deciding \(H\).

Fix an input \(u\). Choose a polynomial bound \(T=T(|u|)\ge1\) on the machine’s running time, query lengths, and number of queries, for every sequence of oracle answers. Set \(t=T\).

A purported oracle transcript is a bit string \(y=(y_1,\ldots,y_t)\). Simulate \(M\) on \(u\), answering its successive queries with these bits. Any positions after the final query are padding positions and must contain \(0\).

For every position, supply a certificate block of \(T\) bits. A SAT query of length at most \(T\) needs at most \(T\) assignment bits. Call a transcript together with its certificate blocks *valid* when:

  • every query answered \(1\) has a satisfying assignment in its certificate block;
  • every padding bit is \(0\).

Queries answered \(0\) require no certificate.

Let \(C(y,c)\) be this validity predicate, and let \(\alpha(y)\in\{0,1\}\) indicate whether the simulated machine accepts.

Both functions have polynomial-size Boolean circuits constructible in polynomial time from \(u\). Indeed, the bounded machine simulation and all certificate checks run in polynomial time; unrolling those bounded computations produces polynomial-size circuits.

Let \(e\) be the genuine SAT-oracle transcript, padded with zeros.

Lemma. The transcript \(e\) is the lexicographically greatest transcript admitting certificates \(c\) with \(C(e,c)=1\).

Proof. It admits certificates because every genuine yes-answer has a satisfying assignment.

Suppose a valid transcript \(y\) were lexicographically larger. At the first differing position \(i\), we would have \(e_i=0\) and \(y_i=1\). All earlier answers agree, so the deterministic simulations reach the same next query, or both have already finished making queries.

In the first case, the genuine answer \(e_i=0\) means that query is unsatisfiable, contradicting the certificate required by \(y_i=1\). In the second case, validity requires the padding bit to be \(0\), again a contradiction. \(\square\)

Define

\(\operatorname{val}(y)=\sum_{i=1}^{t}y_i2^{t-i}\), and \(R(y)=(\operatorname{val}(y)+1)/2^t\).

The function \(R\) strictly increases with lexicographic order, and \(0<R(y)\le1\). Consequently, \(R(e)\) is strictly greater than \(R(y)\) for every other valid transcript.

4. Turning the transcript into a top-\(k\) instance

Use individuals \(a_1,\ldots,a_k,b\), a concept name \(P\), and the fixed query \(q(x)=P(x)\).

The context variables comprise a selector bit \(z\), the transcript bits, and all certificate bits. In particular, \(m=1+T+T^2\), so \(V\) is nonempty.

The shared ontology is

\(O=\{\langle P(a_i):z\rangle:1\le i\le k\}\cup\{\langle P(b):\neg z\rangle\}\).

Use one type, of mass \(1\), with ranking

\(r(z,y,c)=R(y)\) when \(C(y,c)=1\) and \(z=\alpha(y)\), and \(r(z,y,c)=0\) otherwise.

This has the required circuit representation: output denominator \(2^t\), and numerator \(\operatorname{val}(y)+1\) when the condition holds, or \(0\) otherwise. Both outputs have polynomial bit length. The ranking is total and takes values in \([0,1]\cap\mathbb Q\).

Set \(A=(x\mapsto a_1,\ldots,x\mapsto a_k)\) and \(\eta=1\).

There are exactly \(k+1\) substitutions in \(B\), so \(A\) does not exhaust \(B\). Moreover,

  • \(O_W\models P(a_i)\) exactly when \(z=1\);
  • \(O_W\models P(b)\) exactly when \(z=0\).

For the reverse implications, when an assertion is absent, interpret all names as distinct elements and interpret \(P\) as containing exactly the asserted elements. This is a countermodel to the absent assertion.

Thus every proposed entry has the same score: the maximum rank of a valid accepting transcript, or \(0\) if none exists. The outsider’s score is the maximum rank of a valid rejecting transcript, or \(0\).

If \(M\) genuinely accepts \(u\), then \(\alpha(e)=1\). Every proposed entry has score \(R(e)\), while the outsider has strictly smaller score. Hence \(A\) is top-\(k\).

If \(M\) genuinely rejects \(u\), the outsider has score \(R(e)\), strictly greater than every proposed entry’s score. Hence \(A\) is not top-\(k\).

Because the sole type has mass \(1\) and \(\eta=1\), the threshold instance accepts exactly when \(u\in H\).

The construction has polynomial size and is computable in polynomial time. Since \(H\) was arbitrary, this proves \(\Delta_2^{\mathrm P}\)-hardness for every fixed positive \(k\), completing the classification.

5. Explicit running-time bounds

Here \(|O|\) and \(|q|\) denote encoding lengths; annotation and circuit lengths are included in \(L\).

The oracle algorithm above has polynomial running time with an NP oracle, using \(O(\tau(k+1)(L+1))\) calls. It avoids enumerating either the \(2^m\) valuations or the \(n^d\) substitutions.

For an ordinary deterministic bound, let \(E(o,h,n)\) bound the time for one Boolean CQ-entailment test over an \(\mathcal{EL}\) ontology of length at most \(o\), with query-pattern length at most \(h\) and \(n\) available names.

Enumerate all valuations and all substitutions. For each valuation:

  • construct \(O_W\);
  • evaluate the listed ranking circuits;
  • test each instantiated query;
  • update its score for every type when entailment holds.

The entailment result is shared across all types. Exact comparisons and the final mass calculation take polynomial time in \(L\). This gives

\(O\!\left(2^m\left[\operatorname{poly}(L)+n^d\left(E(|O|,|q|,n)+\tau\operatorname{poly}(L)\right)\right]+\operatorname{poly}(L)\right)\).

NP membership of \(\mathcal{EL}\) CQ entailment supplies a fixed polynomial \(p\) such that one may take

\(E(|O|,|q|,n)\le2^{p(|O|+|q|(1+\lceil\log_2(n+1)\rceil)+n+1)}\),

after consistently relabeling individual names. This yields an explicit unconditional exponential upper bound in the requested parameters.

When the query is fixed, ordinary \(\mathcal{EL}\) CQ entailment is polynomial in ontology size, as recalled in the [source](https://www.ijcai.org/proceedings/2017/0131.pdf). Since \(d\) is then fixed, the enumeration bound simplifies, for nonempty \(B\), to

\(O\!\left(\tau\,2^m\,|N|^d\,\operatorname{poly}(L)\right)\).

In particular, fixing both \(m\) and the query gives polynomial time. Fixing the query and ontology alone does not: the hardness construction varies only the context variables and ranking circuit.
