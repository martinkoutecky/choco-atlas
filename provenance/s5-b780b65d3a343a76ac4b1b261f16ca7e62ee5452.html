The continuous mirror question, as graded

Fix a finite set of publicly known bundles \(\mathcal R\), rational cohort masses \(\lambda_R\), positive binary values \(0<L<H\), and per-capita item supplies \(q_j\). At replica scale \(N\), use cohorts whose sizes divided by \(N\) converge to \(\lambda_R\), and supplies divided by \(N\) converge to \(q_j\). Does there exist a family of deterministic, individually rational, obviously strategyproof mechanisms, each querying individuals and giving each served individual the whole desired bundle, whose worst-case welfare approximation ratio has limit superior strictly below \(2\)?

Result

Yes. Every finite replica admits a deterministic, ex-post IR, OSP mechanism satisfying
\[ \rho_N\leq 2-\frac{\ell}{h}<2. \]
Thus the first alternative holds for every fixed public instance and every replica sequence.

The construction uses the rejection protocol underlying the IS mechanism in [de Keijzer, Kyropoulou, and Ventre](https://drops.dagstuhl.de/storage/00lipics/lipics-vol168-icalp2020/LIPIcs.ICALP.2020.71/LIPIcs.ICALP.2020.71.pdf). The key is a sharper welfare analysis that keeps track of the fixed ratio \(\ell/h\). We prove the construction and bound directly below.

Finite-instance setup

Fix one replica, and let \(P\) be its set of individuals, with \(T=|P|\). Write \(R_i\) for individual \(i\)'s publicly known bundle.

Let \(\mathcal F\) be the family of feasible served sets:
\[ \mathcal F = \left\{ S\subseteq P: \sum_{\substack{i\in S\\j\in R_i}}1\leq s_j \text{ for every }j \right\}. \]
This family contains the empty set and is downward closed: every subset of a feasible set is feasible.

Define the public maximum feasible cardinality
\[ K=\max_{S\in\mathcal F}|S|. \]
Fix deterministic orders for resolving all ties.

The mechanism

Maintain an active set \(A\), a queried set \(Q\), and provisional weights \(w_i\) for active individuals. Initially,
\[ A=P,\qquad Q=\varnothing,\qquad w_i=\ell. \]

Repeat the following steps:

  • Compute a feasible set \(I\subseteq A\) maximizing \(\sum_{i\in I}w_i\).
  • If every unqueried active individual belongs to \(I\), terminate and serve exactly \(I\).
  • Otherwise, choose an unqueried individual \(i\in A\setminus I\) and ask whether their value is \(\ell\) or \(h\).
  • Add \(i\) to \(Q\). If they report \(\ell\), remove them permanently from \(A\). If they report \(h\), set \(w_i=h\).

Charge each served individual \(\ell\), and charge every other individual zero.

Each query concerns a previously unqueried individual, so there are at most \(T\) queries. Consequently the protocol is finite and deterministic.

Individual rationality and obvious strategyproofness

Payments are nonnegative. Under truthful play, a served individual has utility \(v_i-\ell\geq0\), and an unserved individual has utility zero. Thus the mechanism is ex-post individually rational.

Consider any query node.

If the queried individual's true value is \(\ell\), truthful reporting removes them permanently and gives utility zero. Reporting \(h\) also gives utility zero under every continuation: they either receive nothing and pay zero, or receive their bundle and pay \(\ell\).

If their true value is \(h\), truthful reporting gives utility either zero or \(h-\ell\), so its worst possible utility is at least zero. Reporting \(\ell\) removes them permanently, giving utility zero under every continuation.

These comparisons hold regardless of subsequent actions by other individuals. Moreover, the queried individual is never queried again. Therefore, at every truthful decision node, the worst utility from truthful continuation is at least the best utility from any alternative action and continuation. The mechanism is OSP.

Welfare analysis

Fix an arbitrary truthful value profile \(v\), and write
\[ W=\sum_{i\in I}v_i \]
for the mechanism's final welfare.

Claim 1: \(W\geq\ell K\)

Initially, the maximum provisional welfare is exactly \(\ell K\).

At each query, the queried individual lies outside the currently maximizing set. Removing that individual therefore leaves the current maximizing set feasible with the same provisional welfare. Increasing their provisional weight also leaves that set's welfare unchanged. Hence the maximum provisional welfare never decreases.

At termination, every active individual's provisional weight is at most their true value. Thus
\[ W\geq\sum_{i\in I}w_i\geq\ell K. \]

Claim 2: \(I\) maximizes true welfare among feasible subsets of the final active set

Let \(A\) denote the final active set and \(U=A\setminus Q\) its unqueried individuals. The stopping condition gives \(U\subseteq I\).

Every queried active individual reported \(h\), so their provisional and true values coincide. For each \(i\in U\), define
\[ \delta_i=v_i-\ell\geq0. \]
Let \(B=\sum_{i\in I}w_i\). For any feasible \(S\subseteq A\), provisional optimality and nonnegativity of the \(\delta_i\) give
\[ \sum_{i\in S}v_i = \sum_{i\in S}w_i+\sum_{i\in S\cap U}\delta_i \leq B+\sum_{i\in U}\delta_i = W. \]
The final equality uses \(U\subseteq I\). This proves the claim.

Claim 3: \(\operatorname{OPT}\leq(2-\ell/h)W\)

Let \(O\in\mathcal F\) maximize true welfare. Put
\[ a=\sum_{i\in O\cap A}v_i,\qquad k=|O\cap A|,\qquad d=|O\setminus A|. \]

Every removed individual truthfully reported \(\ell\), so
\[ \operatorname{OPT}=a+\ell d. \]
Downward closure makes \(O\cap A\) feasible. Claim 2 therefore gives \(a\leq W\).

Every value is at most \(h\), so \(a\leq hk\). Also, feasibility of \(O\) gives \(k+d\leq K\). Consequently,
\[ d\leq K-k\leq K-\frac{a}{h}. \]
Combining these inequalities with Claim 1 yields
\[ \begin{aligned} \operatorname{OPT} &=a+\ell d\\ &\leq \ell K+\left(1-\frac{\ell}{h}\right)a\\ &\leq W+\left(1-\frac{\ell}{h}\right)W\\ &=\left(2-\frac{\ell}{h}\right)W. \end{aligned} \]

If \(K>0\), Claim 1 ensures \(W>0\), so division is valid. If \(K=0\), both welfare quantities are zero and the stipulated ratio is \(1\). Thus the asserted approximation bound holds for every profile.

Implementation and replica conclusion

Exact optimization requires no computational assumption. It can also exploit the public cohorts.

For each type \(R\), partition active individuals into queried individuals who reported \(h\) and unqueried individuals. A candidate allocation is specified by the number selected from each of these two groups. There are at most
\[ \prod_{R\in\mathcal R}(n_R+1)^2 \]
candidate count vectors. For each vector, feasibility and provisional welfare can be checked using the public bundles, supplies, and rational values. Fixed identity orders determine which individuals are selected.

With at most \(T+1\) optimization calls, a valid bit-time bound is
\[ O\!\left( (T+1)\prod_{R\in\mathcal R}(n_R+1)^2 \operatorname{poly}(m,\tau,L,T) \right). \]
This is polynomial in the population size for fixed \(\tau\); dependence on \(N\) enters through the replica counts and supplies.

Apply this mechanism separately to every replica. Since \(\ell/h\) is fixed independently of \(N\),
\[ \limsup_{N\to\infty}\rho_N \leq 2-\frac{\ell}{h} <2. \]
The convergence assumptions are unnecessary for this bound: it already holds replica by replica. It is consistent with the stated uniform discrete lower bound because the improvement \(\ell/h\) can approach zero across different value pairs.
