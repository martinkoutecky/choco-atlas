Theorem 27 — class: hardness

The continuous mirror question, as graded

Given a graph template \(H=(V,E)\) in the blow-up-of-subdivided-stars class, a common binary valuation \(w:V\to\{0,1\}\), and rational per-capita supplies \(\lambda_v\in[0,1]\), does there exist a distribution \(x_B\geq 0\) over connected bundles \(B\subseteq V\), including the empty bundle, such that \(\sum_B x_B=1\), \(\sum_{B\ni v}x_B=\lambda_v\) for each \(v\in V\), and every pair \(B,B'\) with \(x_B,x_{B'}>0\) satisfies the paper’s \(EF1_{\text{outer}}\) condition: either \(B'=\emptyset\), or some outer vertex \(u\in B'\) has \(w(B)\geq w(B'\setminus\{u\})\)?

Packaged proof task (what the prover saw — nothing else)

Input: an explicitly represented graph \(H=(V,E)\), with \(m=|V|\), obtained from a star with at least three leaves by subdividing its edges arbitrarily and replacing its center by a nonempty clique; every former neighbor of the center is adjacent to every vertex of that clique, and there are no other added edges. Also given are a common binary additive valuation \(w:V\to\{0,1\}\) and binary rational supplies \(\lambda_v\in[0,1]\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; \(\tau\) is the support size, not the number of possible types. Here the society has total mass \(1\), consists of the single valuation type \(w\), and hence has \(\tau=1\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Let \(\mathcal C\) contain the empty bundle and all subsets \(B\subseteq V\) for which \(H[B]\) is connected. An outer vertex of a nonempty bundle \(B\) is a vertex \(u\in B\) such that \(B\setminus\{u\}\in\mathcal C\); in particular, a singleton's vertex is outer. Write \(w(B)=\sum_{v\in B}w(v)\).
Feasibility means that there exist real masses \(x_B\geq0\), indexed by \(B\in\mathcal C\), satisfying \(\sum_{B\in\mathcal C}x_B=1\) and \(\sum_{B\in\mathcal C:v\in B}x_B=\lambda_v\) for every \(v\in V\).
For every ordered pair \(B,B'\in\mathcal C\) with \(x_B,x_{B'}>0\), require \(\mathrm{EF1}_{\mathrm{outer}}\): either \(B'=\emptyset\), or there exists an outer vertex \(u\in B'\) with \(w(B)\geq w(B'\setminus\{u\})\).

Is this mass-feasibility decision problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finitely many agents with common binary additive valuations, deciding whether the vertices can be partitioned into connected bundles satisfying \(\mathrm{EF1}_{\mathrm{outer}}\) is stated to be \(\mathrm{NP}\)-complete on this graph class ([source](https://arxiv.org/html/2608.29902#S6)).
No result settling this exact mass-feasibility problem was located.

Modeling choices made when packaging the task

  • Expanded the graph-class name using the center-clique blow-up definition, retaining the convention that the underlying star has at least three leaves and that the clique is nonempty.
  • Made induced connectivity explicit and treated the empty set as an admissible remainder after deletion, so singleton vertices are outer.
  • Specified the common valuation as additive and the normalized society as one valuation type of mass one, giving support size tau = 1.
  • Specified that allocation masses may be real, while the supplies and input society masses are binary rationals; L denotes total input bit length.

Polynomial-time solvability

The mass-feasibility problem is solvable in polynomial time in \(m,\tau,L\), with \(\tau=1\) as specified. The proof uses a polynomial-size flow formulation for each of at most \(m+1\) possible fairness thresholds.

1. Reducing fairness to a bundle family

Call a nonempty connected bundle *good* if it has an outer vertex of value \(1\).

Every nonempty connected bundle has an outer vertex. For a singleton this follows from the definition. Otherwise, deleting a leaf of a spanning tree leaves a connected spanning tree on the remaining vertices.

Let \(W=w(V)\), so \(W\leq m\). For each integer \(k\in\{0,\ldots,W\}\), define

\( \mathcal F_k = \{B\in\mathcal C:w(B)=k\} \;\cup\; \{B\in\mathcal C:w(B)=k+1,\ B\text{ is good}\}. \)

In particular, \(\emptyset\in\mathcal F_0\).

Lemma 1. A nonempty collection of bundles satisfies all ordered-pair \(\mathrm{EF1}_{\mathrm{outer}}\) conditions if and only if it is contained in some \(\mathcal F_k\).

Proof. Suppose the collection is fair, and let \(k\) be its minimum bundle value. Choose a bundle \(A\) with \(w(A)=k\). For every nonempty bundle \(B\) in the collection, fairness gives an outer vertex \(u\) such that

\( k\geq w(B\setminus\{u\})=w(B)-w(u). \)

Since \(w(u)\in\{0,1\}\) and \(w(B)\geq k\), we have \(w(B)\in\{k,k+1\}\). If \(w(B)=k+1\), the displayed inequality forces \(w(u)=1\). Thus the collection lies in \(\mathcal F_k\).

Conversely, suppose the collection lies in \(\mathcal F_k\). Every bundle \(A\) in it has \(w(A)\geq k\). For a nonempty bundle \(B\) of value \(k\), deleting any outer vertex gives value at most \(k\). For a bundle \(B\) of value \(k+1\), deleting a valued outer vertex gives value exactly \(k\). Hence every required comparison holds. Empty envied bundles impose no condition. \(\square\)

Consequently, writing \(\mathbf1_B\) for the incidence vector of \(B\), the decision problem is equivalent to testing whether

\( \lambda\in\operatorname{conv}\{\mathbf1_B:B\in\mathcal F_k\} \)

for at least one \(k\in\{0,\ldots,W\}\). We now give an explicit polynomial-size linear program for each test.

2. Connected bundles and their outer vertices

Write the central clique as \(Q\). Write the arms, ordered outward from the clique, as

\( P_i=(p_{i,1},\ldots,p_{i,\ell_i}),\qquad i=1,\ldots,d, \)

where \(d\geq3\). Only \(p_{i,1}\) is adjacent to \(Q\), and it is adjacent to every vertex of \(Q\).

This decomposition can be recovered in polynomial time from the explicit graph. All vertices of \(Q\) have the same closed neighborhood. No vertex outside \(Q\) shares that neighborhood: it misses the first vertex of an arm other than its own. Thus \(Q\) is one equivalence class under equality of closed neighborhoods. Testing the at most \(m\) classes for the required clique-and-arms structure takes \(O(m^3)\) time using an adjacency matrix.

Lemma 2. Every nonempty connected bundle has exactly one of the following forms:

  • An interval in one arm, containing no vertex of \(Q\).
  • A nonempty subset \(S\subseteq Q\), together with a prefix of each arm.

Proof. Deleting \(Q\) separates the graph into the paths \(P_i\). A connected bundle avoiding \(Q\) therefore lies in one path and is an interval.

If a connected bundle intersects \(Q\) and contains \(p_{i,j}\), it must contain \(p_{i,1},\ldots,p_{i,j-1}\): these vertices are the only route from \(p_{i,j}\) to \(Q\). Hence its intersection with each arm is a prefix. Conversely, every described set is connected because \(S\) is a nonempty clique and every nonempty prefix attaches to it. \(\square\)

For a bundle of the second form, let \(r\) be the number of nonempty selected prefixes. Its outer vertices are precisely:

  • The last vertex of every nonempty prefix.
  • Every vertex of \(S\), if \(|S|\geq2\).
  • The sole vertex of \(S\), if \(|S|=1\) and \(r\leq1\).

To justify completeness, deleting a prefix vertex other than its last vertex separates the remaining tail from \(S\). Deleting a clique vertex leaves the bundle connected when another clique vertex remains. If \(S\) is a singleton, deleting it leaves either the empty bundle, one connected prefix, or at least two disconnected prefixes, according to whether \(r=0\), \(r=1\), or \(r\geq2\).

Thus, define the following capped counts and Boolean flags:

\( c=\min\{2,|S|\},\qquad a=\min\{2,r\}, \)

\( h=\mathbf1[\text{some selected clique vertex has value }1], \)

\( f=\mathbf1[\text{some selected prefix ends at a vertex of value }1]. \)

The bundle is good exactly when

\( f=1 \quad\text{or}\quad \bigl(h=1\text{ and }(c=2\text{ or }a\leq1)\bigr). \)

For an interval avoiding \(Q\), its outer vertices are its endpoints, with the usual singleton convention. Such an interval is good exactly when at least one endpoint has value \(1\).

3. A polynomial-size network encoding \(\mathcal F_k\)

Fix \(k\). Construct a directed acyclic multigraph \(D_k\), with source \(s\) and sink \(t\). Each arc \(e\) carries a label \(A_e\subseteq V\). We arrange that the label unions of source-to-sink paths are exactly the bundles in \(\mathcal F_k\), and that labels along any such path are pairwise disjoint.

Bundles intersecting the clique

Process the vertices of \(Q\) individually, followed by the arms individually. At every processing layer, a state records

\( (z,c,h,a,f), \)

where \(z\in\{0,\ldots,W\}\) is the accumulated value and the remaining coordinates have the meanings above. Initially all coordinates are zero.

For a clique vertex \(q\), provide two transitions:

  • Skip \(q\), with empty label and no state change.
  • Select \(q\), with label \(\{q\}\), adding \(w(q)\) to \(z\), replacing \(c\) by \(\min\{2,c+1\}\), and replacing \(h\) by \(\max\{h,w(q)\}\).

For arm \(P_i\), provide one transition for each prefix length \(j\in\{0,\ldots,\ell_i\}\). Its label is

\( A_{i,j}=\{p_{i,1},\ldots,p_{i,j}\}. \)

Add \(w(A_{i,j})\) to \(z\). If \(j>0\), replace \(a\) by \(\min\{2,a+1\}\), and replace \(f\) by \(\max\{f,w(p_{i,j})\}\). Other coordinates remain unchanged.

Connect the source to the initial state with an empty-label arc. After all choices have been processed, connect a state to the sink with an empty-label arc exactly when \(c\geq1\) and either

\( z=k, \)

or

\( z=k+1 \quad\text{and}\quad \bigl(f=1\text{ or }(h=1\text{ and }(c=2\text{ or }a\leq1))\bigr). \)

By Lemma 2 and the outer-vertex characterization, these paths encode exactly the members of \(\mathcal F_k\) intersecting \(Q\).

Bundles avoiding the clique

Enumerate every nonempty interval in every arm. For each interval belonging to \(\mathcal F_k\), add a direct source-to-sink arc labeled by that interval.

When \(k=0\), also add a direct arc labeled by \(\emptyset\).

Together, the two constructions encode exactly \(\mathcal F_k\). Pairwise disjointness of labels along a path follows because each clique vertex and each arm is processed only once.

Network size

There are constantly many possibilities for \((c,h,a,f)\). Each layer therefore has \(O(W+1)\) states, and there are \(O(m)\) layers. The number of states is \(O(m(W+1))\).

Clique transitions number \(O(m(W+1))\). Arm transitions number at most a constant times

\( (W+1)\sum_{i=1}^{d}(\ell_i+1)=O(m(W+1)). \)

The direct interval arcs number at most

\( \sum_{i=1}^{d}\frac{\ell_i(\ell_i+1)}2=O(m^2). \)

Since \(W\leq m\), both the number of nodes and the number of arcs are \(O(m^2)\).

4. The exact linear program

Introduce a nonnegative flow variable \(y_e\) for every arc \(e\) of \(D_k\). Require unit source-to-sink flow:

\( \sum_{e\in\delta^+(u)}y_e-\sum_{e\in\delta^-(u)}y_e = \begin{cases} 1,&u=s,\\ -1,&u=t,\\ 0,&\text{otherwise}. \end{cases} \)

For every graph vertex \(v\), impose the marginal equation

\( \sum_{e:\,v\in A_e}y_e=\lambda_v. \)

Lemma 3. This linear program is feasible if and only if there exist bundle masses supported on \(\mathcal F_k\) with total mass \(1\) and marginals \(\lambda\).

Proof. Given such bundle masses, choose an encoding path for each bundle and send its mass along that path. This gives unit flow. Since the path labels are disjoint and their union is its bundle, the marginal equations hold.

Conversely, every nonnegative unit flow on this finite acyclic network decomposes into source-to-sink path flows. For completeness, follow positive-flow arcs from the source; conservation prevents termination before reaching the sink. Acyclicity guarantees termination. Subtract the minimum flow on this path and repeat. Each subtraction removes at least one positive arc, so the process is finite. Any residual positive flow would also yield a source-to-sink path by tracing backward and forward using conservation; therefore no residual remains.

The resulting path masses sum to \(1\). Assign each path’s mass to its encoded bundle, aggregating paths encoding the same bundle. All resulting bundles belong to \(\mathcal F_k\). Disjointness of labels along paths gives, for every \(v\),

\( \sum_{B:\,v\in B}x_B = \sum_{e:\,v\in A_e}y_e = \lambda_v. \)

Thus the required bundle masses exist. \(\square\)

Combining Lemmas 1 and 3, the algorithm accepts exactly when at least one of these linear programs is feasible.

5. Bit complexity and conclusion

We use the standard rational linear programming theorem: feasibility of a linear system with rational coefficients, including equalities and nonnegativity constraints, can be decided exactly in time polynomial in its dimensions and total binary encoding length.

Its hypotheses hold here:

  • Each linear program has \(O(m^2)\) variables and \(O(m^2)\) constraints.
  • Every matrix coefficient belongs to \(\{-1,0,1\}\).
  • The only nonconstant rational right-hand sides are the input supplies.
  • A dense encoding has length \(O(L+m^4)\).
  • There are \(W+1\leq m+1\) programs.

If \(\mathsf{LP}(n,r,b)\) denotes the polynomial bit-running time of a fixed exact rational LP algorithm, the total running time is bounded by

\( O(m^3) + (m+1)\bigl[ O(m^4) + \mathsf{LP}(O(m^2),O(m^2),O(L+m^4)) \bigr]. \)

This is polynomial in \(m,\tau,L\), since \(\tau=1\). Binary rational supplies are handled directly; their denominators do not cause enumeration. Likewise, the value coordinate is bounded by \(m\) because the valuation is binary.

The cited finite-agent NP-completeness statement concerns partitions into connected bundles ([Section 6](https://arxiv.org/html/2608.29902#S6)). Here, masses impose weighted incidence equations and allow overlapping bundles. The flow formulation establishes polynomial-time solvability of this exact mass problem.
