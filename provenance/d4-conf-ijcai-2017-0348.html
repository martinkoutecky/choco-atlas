The continuous mirror question, as graded

Given a finite rational catalogue \(A\subseteq\mathbb{Q}^d\) and a rational-mass distribution \(\mu\) over consistent comparison-profile types \(t\), each described by \(\Lambda_t\subseteq\mathbb{Q}^d\), compute for every \(a\in A\) the mass \(M(a)=\sum_{t:\,a\in P_t(A)}\mu_t\), and return a maximizer, where \(P_t(A)=\{a\in A:\exists u\in SI(\Lambda_t),\ u\cdot a\ge u\cdot b\ \forall b\in A\}\) and \(SI(\Lambda_t)=\operatorname{cone}(\Lambda_t)\cap\{u:u\cdot\lambda\ge1\ \forall\lambda\in\Lambda_t\}\).

Packaged proof task (what the prover saw — nothing else)

Let \(d\ge1\) and let \(A\subseteq\mathbb Q^d\) be an explicitly listed nonempty catalogue, with \(m=|A|\). Coordinates may have either sign.
A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type explicitly lists a finite set \(\Lambda_t\subseteq\mathbb Q^d\) of strict comparison differences: \(\lambda=x-y\) represents preferring \(x\) to \(y\). Consistency means that some \(w\in\mathbb R^d\) satisfies \(w\cdot\lambda>0\) for every \(\lambda\in\Lambda_t\). Empty comparison sets are allowed.
Define \(SI(\Lambda_t)=\operatorname{cone}(\Lambda_t)\cap\{u\in\mathbb R^d:u\cdot\lambda\ge1\text{ for all }\lambda\in\Lambda_t\}\), using the usual nonnegative generated cone and \(\operatorname{cone}(\varnothing)=\{0\}\). Utility vectors have no additional sign or normalization restriction.
Define \(P_t(A)=\{a\in A:\exists u\in SI(\Lambda_t),\ u\cdot a\ge u\cdot b\text{ for every }b\in A\}\); utility ties count as optimal.
The problem is to compute exactly every \(M(a)=\sum_{t:a\in P_t(A)}\mu_t\) and return any maximizer. Let \(K=\sum_t|\Lambda_t|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,d,K,L\).

Is this exact mass-aggregation problem solvable in polynomial time, or is it NP-hard?

For a single finite comparison profile, the known characterization is \(u\in SI(\Lambda)\) exactly when \(u=\sum_{\lambda\in\Lambda}r_\lambda\lambda\), \(r_\lambda\ge0\), and \(u\cdot\lambda\ge1\) for every \(\lambda\in\Lambda\). [Montazery and Wilson, 2017](https://www.ijcai.org/proceedings/2017/0168.pdf).
The same characterization and the single-profile possible-optimality notion appear in the [2021 extended treatment](https://cora.ucc.ie/bitstreams/c21e04e3-c9fd-4bdf-bbf3-bb903ed2c572/download); no result settling this exact distribution-over-types aggregation problem was located.

Modeling choices made when packaging the task

  • Made the catalogue nonempty so that returning a maximizer is defined, consistent with the extended treatment's optimality results.
  • Specified explicit finite comparison sets and defined consistency using simultaneous strict linear comparisons; comparison endpoints need not belong to the catalogue.
  • Normalized the positive rational masses to sum to one, following the stated distribution interpretation.
  • Preserved unrestricted signed feature coordinates and real utility vectors, with no added positivity or utility normalization.
  • Allowed empty comparison sets with the standard cone convention, since the definitions supply no exclusion and the maximum-margin utility is then zero.
  • Counted utility ties as possible optimality and allowed any maximizer of aggregate mass.
  • Defined m as catalogue size, K as total comparison-set size, and L as total binary input length.

Result

The exact mass-aggregation problem is deterministically polynomial-time solvable, with both the dimension and support size included in the input. The proof is a reduction to at most \(m\tau\) rational linear feasibility problems, followed by exact rational arithmetic.

1. A linear program for each membership test

Write \(k_t=|\Lambda_t|\), and enumerate \(\Lambda_t=\{\lambda_{t,1},\ldots,\lambda_{t,k_t}\}\).

Fix a type \(t\) and an alternative \(a\in A\). Introduce unrestricted real variables \(u_1,\ldots,u_d\) and nonnegative real variables \(r_1,\ldots,r_{k_t}\). Consider the following feasibility system:

  • \(r_i\ge 0\) for every \(i\in\{1,\ldots,k_t\}\).
  • \(u_j=\sum_{i=1}^{k_t}r_i\lambda_{t,i,j}\) for every \(j\in\{1,\ldots,d\}\).
  • \(\sum_{j=1}^d u_j\lambda_{t,i,j}\ge 1\) for every \(i\in\{1,\ldots,k_t\}\).
  • \(\sum_{j=1}^d u_j(a_j-b_j)\ge 0\) for every \(b\in A\setminus\{a\}\).

Every coefficient is rational and known from the input. In particular, the last constraints are linear because \(a\) and \(b\) are fixed vectors.

Claim. This system is feasible if and only if \(a\in P_t(A)\).

Proof. Suppose the system is feasible. Constraints 1 and 2 imply \(u\in\operatorname{cone}(\Lambda_t)\). Constraint 3 gives all the inequalities required for \(u\in SI(\Lambda_t)\). Constraint 4 gives \(u\cdot a\ge u\cdot b\) for every other catalogue alternative; the inequality for \(b=a\) holds automatically. Thus \(u\) witnesses \(a\in P_t(A)\).

Conversely, suppose \(a\in P_t(A)\), and choose its witnessing vector \(u\in SI(\Lambda_t)\). Cone membership supplies coefficients \(r_i\ge 0\) satisfying constraint 2. The definition of \(SI(\Lambda_t)\) supplies constraint 3, and the witnessing optimality inequalities supply constraint 4. Hence the system is feasible. \(\square\)

The cone representation used here is also the characterization in Corollary 10 of [Montazery and Wilson (2017)](https://www.ijcai.org/proceedings/2017/0168.pdf). Under the task’s stated definition of \(SI\), however, the equivalence above follows directly from the definition of a finitely generated cone.

2. Boundary cases and hypotheses

If \(\Lambda_t=\varnothing\), constraint 2 becomes \(u_j=0\) for every coordinate. Constraints 1 and 3 disappear, and constraint 4 holds with equality. Consequently, \(P_t(A)=A\), exactly as required by \(\operatorname{cone}(\varnothing)=\{0\}\).

Negative coordinates cause no difficulty: the variables \(u_j\) are unrestricted, and rational linear feasibility allows coefficients of either sign. Weak inequalities in constraint 4 include utility ties exactly.

The algorithm works whether consistency is promised or not. If a type is inconsistent, constraint 3 cannot hold: any vector satisfying it would itself satisfy \(u\cdot\lambda>0\) for every listed comparison. Thus its possible-optimality set is empty under the stated definition.

3. Exact aggregation and correctness

For every pair \((t,a)\), solve the feasibility system and record \(I_{t,a}=1\) if it is feasible and \(I_{t,a}=0\) otherwise. Then compute \(M(a)=\sum_{t=1}^{\tau}I_{t,a}\mu_t\) exactly.

The membership claim proves that each indicator is correct. Therefore every computed mass equals the specified \(M(a)\). Since \(A\) is finite and nonempty, comparing these exact masses and returning any alternative with largest mass produces a maximizer.

Different membership tests may use different witnessing utility vectors. This is precisely what the separate existential quantifier in the definition of each \(P_t(A)\) permits. No joint choice of utility vectors across alternatives is required.

4. Polynomial bit complexity

Use the standard binary encoding of rational numbers by integer numerators and positive integer denominators.

The relevant standard theorem is: feasibility of a finite system of rational linear equalities and weak inequalities over real variables is decidable deterministically in time polynomial in its binary encoding length. This theorem permits unrestricted variables and unbounded feasible regions; neither boundedness nor strict feasibility is required.

For type \(t\), our system has:

  • \(n_t=d+k_t\) real variables;
  • \(d\) equalities;
  • \(2k_t+m-1\) inequalities, including nonnegativity.

Replacing each equality by two inequalities gives \(h_t=2d+2k_t+m-1\) inequalities. All coefficients are input coordinates, their negatives, differences of two input coordinates, or constants. Subtracting two input rationals produces a rational with \(O(L+1)\) bits. Hence a dense encoding of this system has length \(B_t=O(n_t h_t(L+1))\).

Let \(q(n,h,B)\) be a fixed nondecreasing polynomial bounding rational linear feasibility, enlarged to include construction of the system. The total feasibility work is bounded by

\(O\!\left(m\sum_{t=1}^{\tau}q\!\left(d+k_t,\;2d+2k_t+m-1,\;(d+k_t)(2d+2k_t+m-1)(L+1)\right)\right)\).

Since every \(k_t\le K\), this is \(O\!\left(m\tau\,\operatorname{poly}(d+K+m,L)\right)\).

Exact aggregation also has polynomial bit complexity. Write \(\mu_t=p_t/q_t\), with positive integer denominators, and set \(D=\prod_{t=1}^{\tau}q_t\). The binary length of \(D\) is \(O(L)\), because the sum of the input denominator lengths is at most \(L\). For each alternative define the integer

\(N_a=\sum_{t=1}^{\tau}I_{t,a}p_t(D/q_t)\).

Then \(M(a)=N_a/D\). Positivity and \(\sum_t\mu_t=1\) imply \(0\le N_a\le D\), so every output numerator also has \(O(L)\) bits. All these numerators can be computed with elementary integer arithmetic in \(O(m\tau(L+1)^2)\) bit operations. Comparing numerators suffices to find a maximizer, since their denominators are identical.

Thus the complete running time is

\(O\!\left(m\tau\,\operatorname{poly}(d+K+m,L)+m\tau(L+1)^2\right)\),

which is polynomial in the explicitly listed input. The explicit support is essential to this bound: the algorithm processes its \(\tau\) listed types directly.

Conclusion

Computing every exact mass and returning a maximizer belongs to \(\mathrm{FP}\). An NP-hardness result under standard polynomial-time reductions would therefore imply \(\mathrm{P}=\mathrm{NP}\).
