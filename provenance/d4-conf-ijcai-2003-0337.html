The continuous mirror question, as graded

Given a candidate set \(C\), target \(p\), protocol \(P\in\{\mathrm{Plurality},\mathrm{Borda},\mathrm{Maximin},\mathrm{STV}\}\), fixed announced pairing \(\mathcal M\), rational finite-support distribution \(\nu\) over complete rankings with \(\sum_t\nu_t=1-\alpha\), and a controlled \(p\)-top type of mass \(0<\alpha<1\), does some common bloc report \(r\) make \(p\) win under DPRE + \(P\) on \(\mu^r=\nu+\alpha e_r\)?

Packaged proof task (what the prover saw — nothing else)

Given candidates \(C\) with \(m=|C|\geq2\), a target \(p\in C\), and a fixed protocol \(P\in\{\mathrm{Plurality},\mathrm{Borda},\mathrm{Maximin},\mathrm{STV}\}\), all ranking types are strict total orders of \(C\).
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) denotes support size, not the number of possible rankings. Here \(\tau=|\operatorname{supp}(\nu)|\) describes the fixed, uncontrolled society.
The input includes these known masses \(\nu_t>0\), a binary rational \(0<\alpha<1\) with \(\sum_t\nu_t=1-\alpha\), and a controlled bloc of mass \(\alpha\) whose true ranking places \(p\) first. The entire bloc must submit one common strict ranking \(r\), unrestricted by its true ranking; its mass cannot be split among reports. The reported society is \(\mu^r=\nu+\alpha e_r\), where \(e_r\) is unit mass on \(r\).
An announced pairing \(\mathcal M\) partitions \(C\) into pairs, with exactly one bye when \(m\) is odd. In DPRE, each pair retains the candidate preferred by greater total reported mass, and a bye survives automatically.
Delete all eliminated candidates from every reported ranking, retaining every type's mass, and apply \(P\) to the survivors using mass in place of voter counts. Borda uses the number of survivors; STV is the single-winner elimination rule. A sole survivor wins automatically.
Use a fixed public priority order on candidate labels: the highest-priority tied candidate wins a pairwise or final-score tie, and the lowest-priority tied candidate is eliminated in STV. Winning means being the resulting unique winner. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

For each fixed \(P\in\{\mathrm{Plurality},\mathrm{Borda},\mathrm{Maximin},\mathrm{STV}\}\), is deciding whether some common report \(r\) makes \(p\) win under \(\mathrm{DPRE}+P\) on \(\mu^r\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

Discrete constructive manipulation is \(\mathrm{NP}\)-complete for each of these four preround protocols, even with one unweighted manipulator and all other votes known ([Conitzer–Sandholm](https://www.cs.cmu.edu/~sandholm/voting_tweaks.ijcai03.pdf)).
No separate result for exactly the rational-mass, common-report formulation was verified.

Modeling choices made when packaging the task

  • Complete rankings are strict total orders, and the common report may be any such order; a true p-top ranking does not restrict the report.
  • The announced pairing covers every candidate, with exactly one bye for an odd candidate count.
  • Resolve all ties by a fixed public candidate priority order, eliminating the lowest-priority tied candidate in STV.
  • Extend voting rules by replacing voter counts with masses, retain masses after restriction, and compute Borda scores using the survivor count.
  • A sole survivor wins automatically, including when Maximin would otherwise have no opponent.
  • Use tau for the supplied uncontrolled support; a reported society has at most tau plus one support types. Alpha is part of the binary input, and total reported mass is one.

1. The discrete hardness theorem applies

Theorem 6 of [Conitzer–Sandholm, *Universal Voting Protocol Tweaks to Make Manipulation Hard*](https://www.cs.cmu.edu/~sandholm/voting_tweaks.ijcai03.pdf) establishes \(\mathrm{NP}\)-completeness of constructive manipulation for each of the four deterministic-preround protocols.

The source’s definitions and conventions supply the required hypotheses:

  • Every vote is a strict total order.
  • There is one unweighted manipulator, and all other votes are known.
  • The pairing is announced before the manipulator reports.
  • Eliminated candidates are deleted from every ranking before applying the underlying protocol.
  • The results hold for any tie-breaking rule.

Thus we may use its hardness theorem with exactly the public priority convention in the question, including elimination of the lowest-priority tied candidate in STV.

2. A polynomial normalization reduction

Fix one of the four protocols \(P\). Consider a discrete instance with candidate set \(C\), target \(p\), announced pairing \(\mathcal M\), and \(N\) explicitly listed uncontrolled votes.

We first treat \(N\geq1\) and \(m\geq2\). Let \(t_1,\ldots,t_\tau\) be the distinct uncontrolled rankings, and let \(k_i\) be the number of occurrences of \(t_i\). Hence

\[ k_i\geq1,\qquad \sum_{i=1}^{\tau}k_i=N. \]

Construct the rational-mass instance by keeping \(C,p,\mathcal M\) and setting

\[ \alpha=\frac{1}{N+1}, \qquad \nu_{t_i}=\frac{k_i}{N+1}. \]

Here and below, the displayed formulas are:
\(k_i\geq1,\ \sum_{i=1}^{\tau}k_i=N\), and
\(\alpha=1/(N+1),\ \nu_{t_i}=k_i/(N+1)\).

These masses satisfy all input requirements:

\[ 0<\alpha<1,\qquad \nu_{t_i}>0,\qquad \sum_{i=1}^{\tau}\nu_{t_i} =\frac{N}{N+1}=1-\alpha. \]

Equivalently,
\(0<\alpha<1\), \(\nu_{t_i}>0\), and
\(\sum_{i=1}^{\tau}\nu_{t_i}=N/(N+1)=1-\alpha\).

Choose any true ranking of the controlled bloc with \(p\) first. Its true ranking imposes no restriction on its report, so the permitted reports are exactly the discrete manipulator’s possible votes.

Grouping identical votes takes polynomial time in the explicitly listed discrete input. Each numerator and denominator has \(O(\log(N+1))\) bits. The output contains \(\tau\leq N\) rankings, so its length is polynomial in the source input length.

For completeness, instances with \(N=0\) or \(m=1\) are always yes-instances: a sole manipulator can put \(p\) first, making it survive the preround and win under each of the four protocols. Map these cases to the fixed valid yes-instance with two candidates, pairing them together, uncontrolled mass \(1/2\) on \(p\) above its opponent, and controlled mass \(\alpha=1/2\).

3. Outcome preservation for every report

Fix an arbitrary common report \(r\). Compare the discrete election consisting of the \(N\) uncontrolled votes and the manipulator’s vote \(r\) with the constructed rational society \(\mu^r\).

For every candidate pair \(a,b\), the mass preferring \(a\) to \(b\) is exactly the corresponding discrete voter count divided by \(N+1\). Consequently, every preround comparison has the same direction and the same equality status. Because priorities are unchanged, pairwise ties are resolved identically. Both elections therefore produce exactly the same survivor set \(S\).

Deleting candidates outside \(S\) also preserves this relationship: the mass of each restricted ranking equals its discrete multiplicity divided by \(N+1\), including the contribution of \(r\). We now verify each final protocol.

Plurality. Each candidate’s first-place mass is its discrete first-place count divided by \(N+1\). Scores and ties therefore agree.

Borda. Both elections have the same number \(|S|\) of survivors and use the same Borda coefficients. Each candidate’s total mass-based Borda score is its discrete Borda score divided by \(N+1\). Scores and ties agree.

Maximin. Every pairwise support is divided by \(N+1\). Since this factor is positive, taking the minimum over opponents commutes with scaling. Thus every maximin score is its discrete counterpart divided by \(N+1\), with identical ties. If there is only one survivor, both elections declare it the winner automatically.

STV. Induct on elimination rounds. Initially the remaining sets agree. If they agree at the start of a round, each candidate’s first-place mass among the remaining candidates equals its discrete first-place count divided by \(N+1\). The candidates of minimum score are therefore identical. The same priority rule eliminates the same candidate, proving that the remaining sets agree in the next round. Hence the eventual winners agree.

We have proved, for every strict report \(r\),

\[ r\text{ makes }p\text{ win in the discrete instance} \quad\Longleftrightarrow\quad r\text{ makes }p\text{ win in the rational instance}. \]

That is, \(r\) makes \(p\) win in the discrete instance if and only if it makes \(p\) win in the rational instance.

Taking existence over all \(r\) proves correctness of the many-one reduction. The discrete hardness theorem therefore gives \(\mathrm{NP}\)-hardness for every fixed \(P\).

4. Exact verification and running times

A certificate is one strict ranking \(r\), encoded using \(O(m\log m)\) bits. It remains to show that its outcome can be verified in polynomial bit complexity.

Let \(D\) be the product of the input denominators of \(\alpha\) and the \(\tau\) uncontrolled masses. The binary length of \(D\) is \(O(L)\), because the denominator lengths together are bounded by the input length. Multiplying every mass by \(D\) gives integer weights and preserves all outcomes by the same scaling argument used above.

Computing \(D\) and these integer weights takes \(O((\tau+1)L^2)\) bit operations using schoolbook arithmetic. Individual weights, accumulated supports, and Borda scores have \(O(L+\log m)=O(L)\) bits.

After preprocessing ranking positions:

  • The preround and final plurality or Borda computation require \(O((\tau+1)m)\) arithmetic operations.
  • Computing all pairwise supports for maximin requires \(O((\tau+1)m^2)\) operations.
  • STV can be simulated by rescanning every ranking in each elimination round, using \(O((\tau+1)m^2)\) operations.

Thus a uniform, conservative verification bound for all four protocols is

\[ O\bigl((\tau+1)m^2L^2\bigr). \]

In inline notation, this bound is \(O((\tau+1)m^2L^2)\) bit operations. This proves membership in \(\mathrm{NP}\). Exhaustive enumeration also gives a deterministic decision algorithm taking \(O(m!(\tau+1)m^2L^2)\) bit operations, which is polynomial when \(m\) is fixed.

All four problems are \(\mathrm{NP}\)-complete, already on the restricted family with
\(\alpha=1/(N+1)\) and \(\nu_{t_i}=k_i/(N+1)\).
The controlled bloc submits precisely one common report throughout the reduction; its mass is never split.
