The continuous mirror question, as graded

Given a finite creator set \(N\) and a finite support \(T\) of user types, where type \(t\) has rational mass \(\mu_t>0\), an integral stream vector \(v^t\in\mathbb{Z}_{\ge 0}^{N}\), and reservation price \(r_t>0\), with \(\sum_{t\in T}\mu_t=1\), define \(p_N=\min_{t\in T} r_t\sum_{i\in N}v_i^t\) and \(R(S)=\max_{p>0}p\sum_{t:\,r_t\sum_{i\in S}v_i^t\ge p}\mu_t\). Assume every nonempty proper coalition \(S\subsetneq N\) has an optimal price at which all user mass subscribes. Compute a per-capita core allocation \(x\in\mathbb{R}_{\ge0}^{N}\) satisfying \(\sum_{i\in N}x_i=p_N\) and \(\sum_{i\in S}x_i\ge R(S)\) for every nonempty proper \(S\subsetneq N\).

Packaged proof task (what the prover saw — nothing else)

Let \(N\) be a nonempty finite creator set, with \(m=|N|\). A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) counts supported types, not possible types.
Each type has a binary-encoded vector \(v^t\in\mathbb Z_{\ge0}^{N}\) and a positive binary rational reservation price \(r_t\). Require \(\sum_{i\in N}v_i^t>0\) for every type and \(\sum_{t\in T}\mu_t v_i^t>0\) for every creator. Let \(L\) be the total input bit length.
For \(S\subseteq N\), write \(w_t(S)=r_t\sum_{i\in S}v_i^t\). At price \(p>0\), precisely the types with \(w_t(S)\ge p\) subscribe, including those indifferent at that price.
Define \(p_N=\min_{t\in T}w_t(N)\) and, for nonempty proper coalitions, \(R(S)=\max_{p>0}p\sum_{t:w_t(S)\ge p}\mu_t\). The grand coalition's revenue is fixed at \(p_N\).
Inputs are promised inclusive: for every \(\varnothing\ne S\subsetneq N\), some revenue-maximizing positive price makes every supported type subscribe; other maximizing prices may exist.
A per-capita core allocation satisfies \(x\in\mathbb R_{\ge0}^{N}\), \(\sum_{i\in N}x_i=p_N\), and \(\sum_{i\in S}x_i\ge R(S)\) for every \(\varnothing\ne S\subsetneq N\).

Can an exact rational per-capita core allocation be computed on promised inputs in time polynomial in \(m,\tau,L\), or is this search problem NP-hard?

For finite lists of users, inclusive markets have nonempty cores ([published result](https://pure.tue.nl/ws/files/316907454/1-s2.0-S0305048323001846-main.pdf)).
A later core characterization concerns fixed subscription fees and coalitions receiving fees from exclusive streamers, a different coalition-value model ([source](https://link.springer.com/article/10.1007/s10479-026-07385-6)). No result settling this exact mass-based search problem was located.

Modeling choices made when packaging the task

  • Reservation prices lacked a finite encoding; restrict them to positive binary rationals.
  • Restore the discrete model's nonempty creator set, positive total streams for each user type, and positive streaming mass for each creator; retain the permitted single-creator case.
  • Treat inclusivity as an input promise rather than an additional recognition problem.
  • Specify exact rational output to give the allocation search problem a finite computational representation.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

An exact rational per-capita core allocation can be computed in polynomial time on promised inputs.

Choose any supported type \(t^\ast\) minimizing \(r_t\sum_{i\in N}v_i^t\), and output

\[ x_i=r_{t^\ast}v_i^{t^\ast}\qquad(i\in N). \]

This is the mass-normalized version of the explicit construction in the proof of Proposition 2 of [*Stable streaming platforms*](https://pure.tue.nl/ws/files/316907454/1-s2.0-S0305048323001846-main.pdf). The proof and encoding analysis follow.

Coalition revenues under the promise

Fix a nonempty proper coalition \(S\), and define \(a(S)=\min_{t\in T}w_t(S)\).

By inclusivity, some maximizing price \(q>0\) makes every supported type subscribe. Consequently, \(q\le a(S)\), so \(a(S)>0\). Since total mass equals one, revenue at \(q\) equals \(q\); hence \(R(S)=q\).

At price \(a(S)\), every type also subscribes, including types indifferent at that price. Revenue therefore equals \(a(S)\). Optimality of \(q\) gives \(q\ge a(S)\). Combining these inequalities proves

\[ R(S)=a(S)=\min_{t\in T}r_t\sum_{i\in S}v_i^t. \]

The existence of other maximizing prices does not affect this identity.

Correctness of the allocation

The finite, nonempty support contains a minimizer \(t^\ast\). Every coordinate \(x_i=r_{t^\ast}v_i^{t^\ast}\) is nonnegative, and

\[ \sum_{i\in N}x_i =r_{t^\ast}\sum_{i\in N}v_i^{t^\ast} =p_N. \]

For every nonempty proper coalition \(S\),

\[ \sum_{i\in S}x_i =r_{t^\ast}\sum_{i\in S}v_i^{t^\ast} \ge \min_{t\in T}r_t\sum_{i\in S}v_i^t =R(S). \]

Thus the output satisfies every defining core condition. When \(m=1\), the coalition constraints are absent, and the same construction satisfies nonnegativity and efficiency.

Exact polynomial-time computation

Write each input reservation price as \(r_t=A_t/B_t\), with positive binary integers \(A_t,B_t\).

  • Compute \(V_t=\sum_{i\in N}v_i^t\) for every supported type.
  • Select a minimizer of \(A_tV_t/B_t\), comparing fractions by exact cross multiplication.
  • Output \(x_i=A_{t^\ast}v_i^{t^\ast}/B_{t^\ast}\) for every creator. Reduce fractions using greatest common divisors if desired.

Each \(V_t\) has at most \(L+\lceil\log_2 m\rceil+1\) bits. All products, comparison operands, and output numerators and denominators consequently have bit lengths bounded by \(O(L+\log m)\). Binary addition, multiplication, comparison, and greatest-common-divisor computation take polynomial time in these lengths.

The algorithm uses \(O(m\tau)\) arithmetic operations and has polynomial total running time and output length in \(m,\tau,L\). Its correctness uses the supplied promise; it requires neither enumerating coalitions nor expanding rational masses into individual users.
