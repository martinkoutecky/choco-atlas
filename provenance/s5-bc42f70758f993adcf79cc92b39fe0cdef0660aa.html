Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given a finite support \(T\) with rational masses \(\mu_t>0\) summing to \(1\), where each type \(t\) specifies an eligibility set \(E_t\subseteq C\), a priority \(\alpha_t\), and a complete availability vector \(v_t\in\{0,1\}^{|D|}\), together with \(\delta\in(0,1)\) and per-capita daily supplies \(\bar{s}_d\) and category-day quotas \(\bar{q}_{cd}\), find nonnegative assignment masses \(x_{tcd}\) maximizing \(\sum_{t\in T}\sum_{d\in D}\sum_{c\in E_t}\alpha_t\delta^{d-1}x_{tcd}\), subject to \(\sum_{c\in E_t,\,d:v_{td}=1}x_{tcd}\leq\mu_t\), \(\sum_{t,c}x_{tcd}\leq\bar{s}_d\) for every day \(d\), and \(\sum_t x_{tcd}\leq\bar{q}_{cd}\) for every category-day pair \((c,d)\).

Conclusion

Exact utility maximization is solvable in time polynomial in \(m,\tau,h,L\). Both an optimal allocation and its exact rational utility can be computed. The proof uses a polynomial-size rational linear program; it does not expand the masses into individual agents.

1. Exact linear programming formulation

Define the set of permitted allocation entries by

\( I=\{(t,c,d):1\leq t\leq\tau,\ c\in E_t,\ d\in D,\ v_{td}=1\}, \)

and write \(n=|I|\). Then \(n\leq\tau mh\). If \(n=0\), the zero allocation is optimal with utility \(0\). Henceforth suppose \(n>0\).

Introduce one real variable \(x_{tcd}\) for each \((t,c,d)\in I\). Consider the linear program with objective

\( \max\ \sum_{(t,c,d)\in I}w_{td}x_{tcd}, \qquad w_{td}=\alpha_t\delta^{d-1}, \)

and constraints

  • \(x_{tcd}\geq0\) for every \((t,c,d)\in I\);
  • \(\sum_{(c,d):(t,c,d)\in I}x_{tcd}\leq\mu_t\) for every type \(t\);
  • \(\sum_{(t,c):(t,c,d)\in I}x_{tcd}\leq\bar s_d\) for every day \(d\);
  • \(\sum_{t:(t,c,d)\in I}x_{tcd}\leq\bar q_{cd}\) for every category-day pair \((c,d)\).

Empty sums mean \(0\).

Every allocation allowed in the question gives a feasible point of this program by retaining its permitted entries. Conversely, every feasible point gives an allowed allocation by setting all other entries to zero. The inequalities and objective agree exactly in both directions. Thus this is an exact formulation of the given problem.

The feasible region is nonempty because it contains the zero allocation. Furthermore, nonnegativity and the type constraints imply

\( 0\leq x_{tcd}\leq\mu_t\leq1 \)

for every variable. The feasible region is therefore closed and bounded, hence compact. The linear objective attains a maximum on it. This also covers instances with zero supplies or quotas.

2. Polynomial encoding length

There are \(n\leq\tau mh\) variables and at most

\( n+\tau+h+mh \)

inequalities, including nonnegativity. Every constraint-matrix entry belongs to \(\{-1,0,1\}\). The right-hand sides are input rationals.

The objective coefficients require a separate bit-length check because discount powers are computed from the input. Write

\( \delta=\frac{a}{b}, \qquad \alpha_t=\frac{p_t}{q_t}, \)

with positive integers in binary. Then

\( w_{td}=\frac{p_ta^{d-1}}{q_tb^{d-1}}. \)

Each of \(a,b,p_t,q_t\) has at most \(L\) bits. Consequently, the numerator and denominator in this representation each have at most \(dL+O(1)\) bits, and hence \(O(hL)\) bits. Reducing the fraction cannot increase those lengths.

All powers can be computed by successive integer multiplications. There are polynomially many such operations, all on integers of \(O(hL)\) bits, so constructing the objective takes polynomial time.

Even storing the entire constraint matrix densely takes polynomial space in \(m,\tau,h,L\): both its row count and column count are polynomial, and its entries have constant bit length. Including the right-hand sides and objective, the full linear-program encoding length is therefore polynomial in these parameters.

3. Exact polynomial-time optimization

We apply the standard rational linear programming theorem: a linear program with explicitly encoded rational coefficients, a nonempty feasible region, and a finite attained optimum admits an algorithm computing an exact rational optimal solution in time polynomial in its total binary encoding length. This is an exact optimization result, including recovery of an optimal rational point; see the discussion following Theorem 1 in [Vishnoi’s linear programming notes](https://nisheethvishnoi.wordpress.com/wp-content/uploads/2018/05/lecture71.pdf).

The hypotheses have all been checked: the coefficients are rational, the feasible region is nonempty and compact, and the encoding length is polynomial. The theorem therefore computes an exact optimal allocation in time polynomial in \(m,\tau,h,L\). Its rational output has polynomial encoding length, and evaluating the objective on that output using exact rational arithmetic also takes polynomial time.

4. Why the support encoding causes no hardness here

The finite-agent guarantee alone would not justify expanding rational masses into agents: clearing denominators could produce an exponentially large population.

The formulation above avoids that expansion. It uses only the \(\tau\) listed types and at most \(\tau mh\) allocation variables. Because masses are divisible, all requirements are linear inequalities in those variables. Thus the compact rational support remains a polynomial-size exact optimization problem.
