The continuous mirror question, as graded

Given finite applicant and position type sets \(A\) and \(B\), binary-rational masses \(\mu_a,\nu_b\) summing to \(1\) on each side, and integer scores \(p_a(b),q_b(a)\), let \(\ell_{ab}=p_a(b)+q_b(a)\). Assume the \(\ell_{ab}\) values are distinct across \(b\) for each \(a\), and across \(a\) for each \(b\). Find, in time polynomial in \(\tau=|A|+|B|\) and input bit length \(L\), a flow \(x_{ab}\ge0\) with row sums \(\mu_a\) and column sums \(\nu_b\), maximizing \(\sum_{a,b}\ell_{ab}x_{ab}\), subject to every \((a,b)\) satisfying \(\bigl(\sum_{b':\,\ell_{ab'}<\ell_{ab}}x_{ab'}=0\bigr)\lor\bigl(\sum_{a':\,\ell_{a'b}<\ell_{ab}}x_{a'b}=0\bigr)\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) and \(B\) be nonempty finite applicant and position type sets. A society is given by its support: the list of its \(\tau=|A|+|B|\) types with positive binary-rational masses \(\mu_a,\nu_b\), with \(\sum_a\mu_a=\sum_b\nu_b=1\). Support size counts listed types, not possible types. Write \(m=|B|\) and let \(L\) be the total input bit length.
Every pair is admissible. Scores \(p_a(b),q_b(a)\) are nonnegative integers encoded in binary; define \(\ell_{ab}=p_a(b)+q_b(a)\). These link values are pairwise distinct within each row and each column, and larger links are strictly preferred by both endpoints.
A feasible flow has \(x_{ab}\geq0\), \(\sum_bx_{ab}=\mu_a\), and \(\sum_ax_{ab}=\nu_b\). It is link-additive-stable when, for every \((a,b)\in A\times B\),
\(\bigl(\sum_{b':\,\ell_{ab'}<\ell_{ab}}x_{ab'}=0\bigr)\lor\bigl(\sum_{a':\,\ell_{a'b}<\ell_{ab}}x_{a'b}=0\bigr)\).
The optimization problem is to find such a stable flow maximizing \(\sum_{a,b}\ell_{ab}x_{ab}\).

Is this optimization problem solvable in time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite societies with equally many individuals on each side and no link ties, Gale–Shapley using link rankings returns a link-additive-stable marriage of maximum total link [Pini et al.](https://arxiv.org/pdf/1007.5120).
For the related capacitated stable-allocation model, Cseh and Skutella establish uniqueness under globally ranked pairs and expected polynomial convergence to stability; that result concerns finding stable allocations rather than the objective and exact marginal constraints stated here [Cseh–Skutella](https://arxiv.org/pdf/1211.2169).

  • Restricted the unspecified sign of integer scores to nonnegative integers, following the discrete definition's natural-number scores.
  • Made support masses strictly positive and both type sets nonempty, as required by the support convention and normalization.
  • Made all applicant–position pairs admissible, following the discrete model's complete preference lists.
  • Defined m as the number of position types and L as the total binary input length.

Result

The optimization problem is solvable in time polynomial in \(m,\tau,L\). In fact, there is exactly one feasible link-additive-stable flow. A deterministic greedy algorithm computes it, so it necessarily maximizes the stated objective among stable flows.

The proof below works directly with the listed types and rational masses.

1. Algorithm

Let \(n=|A|=\tau-m\) and \(N=nm\). Order all pairs as \(e_1,\ldots,e_N\) by nonincreasing link value, breaking equal-value ties arbitrarily.

The distinctness assumption implies the following crucial property: among pairs incident to any fixed type, this order is strictly decreasing in link value. Equal-value pairs cannot share an endpoint.

Initialize residual masses \(r_a=\mu_a\), \(s_b=\nu_b\), and all flow entries to zero. For each pair \(e_i=(a,b)\), in order, assign

\(x_{ab}=\min\{r_a,s_b\},\)

and update

\(r_a\leftarrow r_a-x_{ab},\qquad s_b\leftarrow s_b-x_{ab}.\)

Each pair is processed exactly once.

2. The algorithm fills every marginal

Residual masses remain nonnegative because every assignment is at most each endpoint’s residual. At every stage,

\(\displaystyle \sum_a r_a=\sum_b s_b=1-\sum_{\text{processed }(a,b)}x_{ab}.\)

Suppose the common final residual total were positive. There would then be types \(a,b\) with final residuals \(r_a>0\) and \(s_b>0\).

All pairs are admissible, so \((a,b)\) was processed. Residuals only decrease; consequently both endpoint residuals were positive at that step. Assigning their minimum made at least one endpoint’s residual zero. That residual stayed zero thereafter, contradicting the choice of \(a,b\).

Thus the final residual total is zero. Nonnegativity implies every final residual is zero, proving

\(\displaystyle \sum_bx_{ab}=\mu_a,\qquad \sum_ax_{ab}=\nu_b.\)

Hence the output is feasible.

3. The output is stable

Fix a pair \((a,b)\). When it is processed, assigning the minimum residual makes at least one of its endpoint residuals zero.

If the applicant residual becomes zero, every subsequently processed pair incident to \(a\) receives zero flow. Every pair \((a,b')\) with \(\ell_{ab'}<\ell_{ab}\) is processed subsequently. Therefore,

\(\displaystyle \sum_{b':\,\ell_{ab'}<\ell_{ab}}x_{ab'}=0.\)

If instead the position residual becomes zero, the same argument gives

\(\displaystyle \sum_{a':\,\ell_{a'b}<\ell_{ab}}x_{a'b}=0.\)

This reasoning also covers steps where an endpoint residual was already zero. Thus at least one required equality holds for every pair, proving link-additive stability.

4. Every stable feasible flow equals the output

Let \(y\) be any feasible link-additive-stable flow. We prove by induction over the ordered pairs that \(y_{e_i}=x_{e_i}\).

Assume equality on all earlier pairs, with the assumption vacuous for the first pair. Let \(e_i=(a,b)\), and let \(r_a,s_b\) denote the greedy residuals immediately before processing it.

Because all earlier entries agree, feasibility of \(y\) gives

\(\displaystyle r_a=y_{ab}+\sum_{b':\,\ell_{ab'}<\ell_{ab}}y_{ab'},\)

and

\(\displaystyle s_b=y_{ab}+\sum_{a':\,\ell_{a'b}<\ell_{ab}}y_{a'b}.\)

To justify these identities, every other pair incident to either endpoint has a different link value. The earlier incident pairs are precisely those with larger links, and the later incident pairs are precisely those with smaller links.

Nonnegativity therefore implies

\(y_{ab}\leq\min\{r_a,s_b\}.\)

Stability of \(y\) at \((a,b)\) says that at least one of the two sums displayed above is zero. Consequently,

\(y_{ab}=r_a\quad\text{or}\quad y_{ab}=s_b.\)

Together with the upper bound, either equality forces

\(y_{ab}=\min\{r_a,s_b\}=x_{ab}.\)

This completes the induction. The greedy output is therefore the unique stable feasible flow, including among flows with arbitrary real entries.

It follows immediately that this flow maximizes \(\sum_{a,b}\ell_{ab}x_{ab}\) over all stable feasible flows.

5. Exact arithmetic and polynomial running time

It remains to ensure that binary-encoded masses do not cause exponential running time.

Write the input masses as rational fractions, and let \(D\) be the product of their positive denominators. The sum of the denominators’ encoding lengths is at most \(L\), so \(D\) has \(O(L)\) bits.

Scale all masses by \(D\). Each scaled mass is an integer between zero and \(D\). The algorithm then uses only integer comparisons and subtractions, and every residual and assigned amount remains between zero and \(D\). Thus all these quantities have \(O(L)\) bits. Dividing the resulting assignments by \(D\) gives the exact output flow.

Each link value also has \(O(L)\) bits. Computing and sorting the \(N\) links requires \(O(N\log(N+1))\) comparisons; the greedy scan requires \(O(N)\) arithmetic operations. Computing the common denominator and scaled masses takes polynomial time using ordinary integer arithmetic. Hence the overall bit complexity is polynomial in \(N,\tau,L\), and therefore in \(m,\tau,L\), since

\(N=m(\tau-m)\leq m\tau.\)

The objective value is also exactly computable in polynomial time. If \(z_{ab}=Dx_{ab}\) and \(U=\max_{a,b}\ell_{ab}\), then

\(\displaystyle \sum_{a,b}\ell_{ab}x_{ab}=\frac{\sum_{a,b}\ell_{ab}z_{ab}}{D},\qquad 0\leq\sum_{a,b}\ell_{ab}z_{ab}\leq UD,\)

because \(\sum_{a,b}z_{ab}=D\). Its numerator therefore has \(O(L)\) bits.

The forced-edge argument parallels the uniqueness argument in the proof of Theorem 1 of [Cseh–Skutella](https://arxiv.org/pdf/1211.2169). Here, Sections 2–5 explicitly establish exact marginal feasibility, uniqueness for the stated stability condition, objective optimality, and polynomial bit complexity.
