The continuous mirror question, as graded

Given finitely many block templates \(B\), each with residents \(I_B\), empty houses \(U_B\), bounds \(ub_B\), and legal integral housings \(\mathcal P_B=\{P\subseteq U_B: |N_B(i)\cap P|\le ub_B(i)\text{ for every }i\in I_B\}\), along with rational template masses \(\mu_B\) summing to \(1\) and a target refugee load \(\rho\), do there exist \(x_{B,P}\ge 0\) such that \(\sum_{P\in\mathcal P_B}x_{B,P}=\mu_B\) for every \(B\) and \(\sum_B\sum_{P\in\mathcal P_B}|P|x_{B,P}=\rho\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) block types with positive binary-rational masses \(\mu_B\), where \(\sum_B\mu_B=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type is an explicitly encoded finite simple bipartite graph \(G_B=(I_B\mathbin{\dot\cup}U_B,E_B)\): resident vertices \(I_B\) are already occupied, and \(U_B\) consists of empty houses, each accommodating at most one refugee. Write \(N_B(i)\) for the neighbours of resident \(i\), and give each resident an integer bound \(1\le ub_B(i)\le\deg_{G_B}(i)\).
The legal integral configurations are \(\mathcal P_B=\{P\subseteq U_B: |N_B(i)\cap P|\le ub_B(i)\text{ for all }i\in I_B\}\). This family is defined implicitly by the graph and bounds, not supplied as an enumerated list.
The input also specifies a binary-rational load \(0<\rho\le\sum_B\mu_B|U_B|\). Feasibility means that there exist real masses \(x_{B,P}\ge0\) satisfying \(\sum_{P\in\mathcal P_B}x_{B,P}=\mu_B\) for every \(B\) and \(\sum_B\sum_{P\in\mathcal P_B}|P|x_{B,P}=\rho\). Every configuration receiving mass must individually obey every resident's bound.
Let \(m=\max_B(|I_B|+|U_B|)\), and let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this distributional housing feasibility problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite city and a positive integer refugee count, deciding whether an inhabitants-respecting housing of exactly that size exists is NP-complete, even on planar topologies of maximum degree three ([source](https://arxiv.org/abs/2308.09501v2)).
That discrete result does not establish a complexity classification for the distributional problem defined here.

Modeling choices made when packaging the task

  • Specified block templates as explicitly encoded simple bipartite graphs, identifying residents with their occupied vertices; edges between vertices of the same occupancy class can be omitted as in the discrete model.
  • Restricted resident bounds to positive integers at most their degrees, carrying over the assumption that intolerant residents have been removed.
  • Specified that configuration families are implicit rather than enumerated in the input.
  • Specified a positive binary-rational load at most the mass-weighted number of empty houses, mirroring the discrete positive refugee count and available-house condition.
  • Specified real allocation masses and required bounds to hold within each integral configuration, preserving the graded question's configuration-based interpretation.
  • Defined m as the maximum number of vertices in a supported template and L as the total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The problem is \(\mathrm{NP}\)-complete, even when \(\tau=1\), the single mass is \(1\), and every resident has degree \(2\) and upper bound \(1\). Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. Exact characterization of feasible loads

For each block type \(B\), define its maximum legal occupancy by
\[ a_B=\max\{|P|:P\in\mathcal P_B\}, \qquad M=\sum_B\mu_Ba_B. \]
These maxima exist because each \(\mathcal P_B\) is finite and contains the empty configuration.

Claim. The instance is feasible if and only if \(\rho\le M\).

For necessity, suppose feasible masses \(x_{B,P}\) exist. Every legal configuration satisfies \(|P|\le a_B\), so
\[ \rho =\sum_B\sum_{P\in\mathcal P_B}|P|x_{B,P} \le\sum_Ba_B\sum_{P\in\mathcal P_B}x_{B,P} =\sum_B\mu_Ba_B=M. \]

For sufficiency, suppose \(0<\rho\le M\). Choose a maximizing legal configuration \(Q_B\) for each block and set \(\lambda=\rho/M\). Thus \(0<\lambda\le1\). In each block, assign mass \(\lambda\mu_B\) to \(Q_B\) and mass \((1-\lambda)\mu_B\) to the empty configuration. If these configurations coincide, add their contributions.

Both configurations are individually legal. Their masses sum to \(\mu_B\), and their total load is
\[ \sum_B\lambda\mu_B|Q_B|=\lambda M=\rho. \]
This proves the claim.

Thus allowing distributions fills the interval between zero and the maximum weighted occupancy, but computing that endpoint still requires optimizing over legal integral configurations.

2. Membership in \(\mathrm{NP}\)

A certificate consists of one subset \(Q_B\subseteq U_B\) per block. The verifier checks that every \(Q_B\) is legal and that
\[ S:=\sum_B\mu_B|Q_B|\ge\rho. \]

If the verifier accepts, then \(S>0\). Mixing \(Q_B\) with the empty configuration in every block, using the common proportion \(\rho/S\), gives a feasible distribution by the same construction as above. Conversely, every feasible instance has an accepting certificate: choose maximizing configurations and apply Section 1.

The certificate uses at most \(\tau m\) bits when subsets are encoded by incidence vectors. Legality is checked by counting selected neighbours of every resident.

The weighted inequality can also be checked exactly in polynomial time. Under the usual binary encoding of rationals, a common denominator obtained by multiplying all input denominators has bit length at most their total input bit length. Multiplication by configuration sizes and summation therefore involve only polynomially many bits.

Hence certificate verification runs in \(\operatorname{poly}(m,\tau,L)\) time, proving membership in \(\mathrm{NP}\).

3. Polynomial reduction from Independent Set

We use the standard \(\mathrm{NP}\)-complete Independent Set problem: given a finite simple graph \(H=(V,F)\) and an integer \(1\le k\le |V|\), decide whether \(H\) has an independent set of size at least \(k\).

Construct a society with one block \(B\):

  • For every \(v\in V\), create an empty house \(u_v\).
  • For every edge \(e=\{v,w\}\in F\), create a resident \(i_e\) whose neighbours are exactly \(u_v,u_w\).
  • Set \(ub_B(i_e)=1\) for every resident.
  • Set \(\mu_B=1\) and \(\rho=k\).

The resulting graph is finite, simple, and bipartite, with residents on one side and houses on the other. Every resident has degree \(2\), so its bound satisfies the required condition \(1\le ub_B(i_e)\le\deg(i_e)\). The load promise holds because \(0<k\le |U_B|=|V|\).

For a subset \(P\subseteq U_B\), let \(S_P=\{v:u_v\in P\}\). The resident corresponding to an edge \(\{v,w\}\) imposes precisely
\[ |\{u_v,u_w\}\cap P|\le1. \]
Consequently, \(P\) is legal if and only if \(S_P\) is an independent set of \(H\). Therefore \(a_B=\alpha(H)\), where \(\alpha(H)\) denotes the maximum independent-set size.

By Section 1,
\[ \text{the constructed society is feasible} \quad\Longleftrightarrow\quad k\le\alpha(H). \]
This is exactly the Independent Set decision question.

Writing \(n=|V|\) and \(h=|F|\), the construction has \(\tau=1\), \(m=n+h\), and \(2h\) graph edges. Its binary encoding length and construction time are polynomial in the source input length. This proves \(\mathrm{NP}\)-hardness under polynomial-time many-one reductions. Together with Section 2, it proves \(\mathrm{NP}\)-completeness directly for the distributional problem.

4. Running time and the implicit configuration families

An exact deterministic algorithm enumerates all subsets of \(U_B\), checks their legality, and computes \(a_B\) for each block. It then compares \(\rho\) with \(\sum_B\mu_Ba_B\) using exact rational arithmetic.

There are at most \(2^m\) subsets per block, and each legality check takes polynomial time in \(m,L\). Thus this algorithm runs in
\[ O\!\left(\tau\,2^m\operatorname{poly}(m,L)\right). \]

This is polynomial for fixed \(m\), but the unrestricted problem is \(\mathrm{NP}\)-complete. The hardness already occurs at support size \(\tau=1\); it comes from the implicitly specified legal configurations.
