The continuous mirror question, as graded

Given rational type masses \(\mu_i\), a rational strongly connected contact matrix \(P\), initial pro and opposing zealot masses \(\alpha_i,\beta_i\), and a feasible budget \(B\), choose rational targeting masses \(x_i\) with \(0\le x_i\le \mu_i-\alpha_i-\beta_i\) and \(\sum_i x_i=B\). For each choice, let \(v_i(x)\) be the probability that an unconverted type-\(i\) agent eventually reaches a pro zealot before an opposing zealot under the stated type-mixing process, and maximize \(J(x)=\sum_i[\alpha_i+x_i+(\mu_i-\alpha_i-\beta_i-x_i)v_i(x)]\). For fixed \(\varepsilon>0\), determine whether a feasible \(x\) with \(J(x)\ge(1-\varepsilon)\max_x J(x)\) can be found in time polynomial in the number of types \(\tau\) and input bit length \(L\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive masses \(\mu_i\), each a binary rational, with \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types; there are \(m=2\) grouped opinions, pro and opposing.
Input also includes a nonnegative rational row-stochastic matrix \(P\) whose positive-entry directed graph is strongly connected, and rational zealot masses \(\alpha_i,\beta_i\geq0\) with \(\alpha_i+\beta_i\leq\mu_i\) and \(\sum_i\beta_i>0\). Zealots permanently hold their respective opinions.
A rational budget satisfies \(0<B\leq\sum_i(\mu_i-\alpha_i-\beta_i)\). Targeting converts non-zealot mass to pro zealots at unit cost: feasible allocations satisfy \(0\leq x_i\leq\mu_i-\alpha_i-\beta_i\) and \(\sum_i x_i=B\).
From an unconverted agent of type \(i\), each step chooses type \(j\) with probability \(P_{ij}\), then independently samples an agent according to the mass proportions within type \(j\). The walk stops at its first zealot; otherwise it continues from the sampled type.
Write \(r_i(x)=\mu_i-\alpha_i-\beta_i-x_i\). The pro-before-opponent hitting probabilities are the unique solution of \(v_i(x)=\sum_j P_{ij}(\alpha_j+x_j+r_j(x)v_j(x))/\mu_j\). This equation also defines \(v_i\) when \(r_i(x)=0\).
Define \(J(x)=\sum_i[\alpha_i+x_i+r_i(x)v_i(x)]\) and \(\mathrm{OPT}=\max_{x\in\mathbb R^\tau\text{ feasible}}J(x)\); the requested allocation must be rational.

Does this problem admit, for every fixed \(\varepsilon\in(0,1)\), an algorithm polynomial in \(m,\tau,L\) that returns feasible rational \(x\) with \(J(x)\geq(1-\varepsilon)\mathrm{OPT}\), or is obtaining such an allocation NP-hard for some fixed \(\varepsilon\in(0,1)\)? Here \(L\) is the total binary input length, and the polynomial may depend on \(\varepsilon\).

For discrete vertex targeting with a fixed cardinality budget, obtaining a \((1-\varepsilon_0)\)-approximation is NP-hard for some constant \(\varepsilon_0>0\); greedy targeting achieves \(1-1/e\). [Source](https://arxiv.org/html/2407.00213v1).
A distinct continuous relaxation allocates nonnegative soft pinning strengths on graph vertices and has a concavity result. [Source](https://arxiv.org/html/2407.00213v1). No result settling the approximation target for the mass-conversion model above was located.

Modeling choices made when packaging the task

  • Normalized total society mass to one, matching the discrete objective's population-average normalization.
  • Specified P as a nonnegative row-stochastic contact kernel, directed from the contacting type to the sampled type.
  • Defined the missing type-mixing process by independent sampling within each destination type according to its current mass proportions.
  • Required nonnegative disjoint zealot masses, positive opposing zealot mass, and a positive feasible budget; initial pro zealot mass may be zero.
  • Retained unit conversion costs, permanent zealotry, and the prohibition on converting existing zealots.
  • Defined continuation values for types with no remaining non-zealot mass using the same hitting-probability equations.
  • Defined OPT over real feasible allocations while requiring a rational output, avoiding an unsupported assumption that a rational maximizer exists.
  • Interpreted the approximation target as a scheme for every fixed accuracy versus NP-hardness at some fixed accuracy, and fixed the grouped opinion count at two.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result

Obtaining the requested allocation is \(\mathrm{NP}\)-hard for some fixed \(\varepsilon_0\in(0,1)\). This holds even when all initial pro-zealot masses vanish, there is exactly one fully opposing type, and all convertible types have equal dyadic masses.

The key is an upper bound valid for every fractional allocation, together with a rounding lemma for the quadratic expression appearing in that bound.

2. External hardness premise

We use the following standard cubic-vertex-cover gap theorem, stated explicitly in the proof of Theorem 3.2 of [Boyd et al., *Targeting influence in a harmonic opinion model*](https://arxiv.org/html/2407.00213v1).

There is a fixed rational constant \(\delta\in(0,1)\) such that the following promise problem is \(\mathrm{NP}\)-hard. Given a simple undirected cubic graph \(G=(V,E)\), with \(n=|V|\), and an integer \(1\leq k\leq n\), distinguish:

  • YES: \(G\) has a vertex cover of size at most \(k\).
  • NO: Every set of \(k\) vertices leaves at least \(\delta|E|\) edges uncovered.

An edge is uncovered by a set if neither endpoint belongs to that set. Since \(G\) is cubic, \(|E|=3n/2\). A positive gap constant may be decreased to a positive rational constant without weakening the hardness premise.

Everything below is proved directly for the mass-conversion model.

3. A rounding lemma

For a simple undirected graph \(G=(V,E)\), define

\(\displaystyle H(w)=\sum_{\{i,j\}\in E}w_iw_j.\)

Lemma. If \(w\in[0,1]^n\) and \(\sum_iw_i=\ell\) is an integer, there exists \(\widehat w\in\{0,1\}^n\) satisfying

\(\displaystyle \sum_i\widehat w_i=\ell,\qquad H(\widehat w)\leq H(w).\)

Proof. If \(w\) is not integral, at least two coordinates are fractional: exactly one fractional coordinate would contradict the integrality of their sum.

Choose fractional coordinates \(i,j\), and vary them as \(w_i+t,w_j-t\). The feasible values of \(t\) form the interval

\(\displaystyle \left[-\min\{w_i,1-w_j\},\ \min\{1-w_i,w_j\}\right].\)

Both endpoints make at least one of these coordinates integral. Along this interval,

\(\displaystyle H\bigl(w+t(e_i-e_j)\bigr)=H(w)+a t-\mathbf 1_{\{\{i,j\}\in E\}}t^2\)

for some real constant \(a\). Indeed, edges incident to exactly one of \(i,j\) contribute affine terms; their mutual edge, when present, contributes \((w_i+t)(w_j-t)\).

Consequently this function is concave. Its value at some endpoint is no greater than its value at \(t=0\). Move to such an endpoint. This preserves the coordinate sum, does not increase \(H\), and reduces the number of fractional coordinates.

Repeating terminates at the required integral vector. \(\square\)

In a NO instance of the gap theorem, this implies that every \(w\in[0,1]^n\) with \(\sum_iw_i=n-k\) satisfies

\[\displaystyle H(w)\geq\delta|E|=\frac{3\delta n}{2}.\tag{1}\]

To see this, apply the lemma and put \(A=\{i:\widehat w_i=0\}\). Then \(|A|=k\), and \(H(\widehat w)\) counts precisely the edges uncovered by \(A\).

4. Constructing the society

Given a promised instance \((G,k)\), introduce one type for each vertex and one additional opposing type \(o\). Thus \(\tau=n+1\) and \(m=2\).

Choose

\(\displaystyle h=\lceil\log_2(n+1)\rceil,\qquad c=2^{-h}.\)

For every vertex type \(i\in V\), set

\(\displaystyle \mu_i=c,\qquad \alpha_i=\beta_i=0.\)

For the opposing type, set

\(\displaystyle \mu_o=1-nc,\qquad \alpha_o=0,\qquad \beta_o=\mu_o.\)

Since \(2^h\geq n+1>n\), the opposing mass is strictly positive. All masses are dyadic and sum to one.

Set the budget to

\(\displaystyle B=kc.\)

Every vertex type has convertible capacity \(c\), while the opposing type has zero capacity. Hence \(0<B\leq nc\), as required.

Define the transition matrix by

\(\displaystyle P_{ij}=\begin{cases}\frac14,&\{i,j\}\in E,\\0,&\text{otherwise},\end{cases}\qquad P_{io}=\frac14\quad(i\in V),\)

and

\(\displaystyle P_{oj}=\frac1n\quad(j\in V),\qquad P_{oo}=0.\)

Each vertex row sums to one because its vertex has three neighbors; the opposing row also sums to one. All entries are nonnegative rationals.

The positive-entry directed graph is strongly connected: every vertex type reaches \(o\), and \(o\) reaches every vertex type. This remains true even if \(G\) is disconnected.

The construction has polynomial binary input length.

5. Bounding every fractional allocation

Take any feasible allocation, including an arbitrary real allocation. Necessarily \(x_o=0\). For \(i\in V\), define

\(\displaystyle y_i=\frac{x_i}{c},\qquad w_i=1-y_i.\)

Then

\(\displaystyle 0\leq y_i,w_i\leq1,\qquad \sum_i y_i=k,\qquad \sum_iw_i=n-k.\)

Let \(u_i\) denote the average pro probability within vertex type \(i\):

\(\displaystyle u_i=\frac{x_i+r_i(x)v_i(x)}{c}=y_i+w_iv_i(x).\)

The opposing type has average pro probability \(u_o=0\). Substituting the constructed transition matrix into the given equations yields

\(\displaystyle v_i(x)=\frac14\sum_{j:\{i,j\}\in E}u_j,\)

and therefore

\[\displaystyle u_i=y_i+\frac{w_i}{4}\sum_{j:\{i,j\}\in E}u_j.\tag{2}\]

For completeness, the affine map on the right of (2) maps \([0,1]^n\) into itself and has maximum row sum at most \(3/4\) in its linear part. It is therefore a contraction in the maximum norm, with a unique fixed point \(u\in[0,1]^n\). Recovering \(v_i\) by the displayed formula, and setting \(v_o=n^{-1}\sum_i u_i\), satisfies every original equation, including the equation for the fully opposing type.

Since \(u_j\leq1\), equation (2) gives

\[\displaystyle u_i\leq y_i+\frac34w_i,\qquad 1-u_i\geq\frac14w_i.\tag{3}\]

Rewriting (2) and applying (3) at its neighboring coordinates gives

\(\displaystyle u_i =y_i+\frac34w_i-\frac{w_i}{4}\sum_{j:\{i,j\}\in E}(1-u_j) \leq y_i+\frac34w_i-\frac{w_i}{16}\sum_{j:\{i,j\}\in E}w_j. \)

Summing over all vertices counts each undirected edge twice. Thus

\(\displaystyle \sum_i u_i\leq k+\frac34(n-k)-\frac18H(w).\)

Because \(J(x)=c\sum_i u_i\), we obtain the central bound

\[\displaystyle J(x)\leq c\left[k+\frac34(n-k)-\frac18H(w)\right].\tag{4}\]

This bound holds throughout the real feasible region.

6. The YES and NO values

Define

\(\displaystyle T=c\left[k+\frac34(n-k)\right].\)

YES case. Enlarge a vertex cover of size at most \(k\) to a vertex cover \(A\) of size exactly \(k\). Convert precisely those types: take \(x_i=c\) on \(A\) and \(x_i=0\) elsewhere.

For \(i\in A\), equation (2) gives \(u_i=1\). Every vertex outside \(A\) has all three neighbors in \(A\), so its value is \(u_i=3/4\). Therefore this rational feasible allocation achieves \(J(x)=T\).

Equation (4), together with \(H(w)\geq0\), bounds every feasible allocation by \(T\). Hence

\[\displaystyle \mathrm{OPT}_{\mathrm{YES}}=T.\tag{5}\]

NO case. For every real feasible allocation, inequality (1) applies. Substituting it into (4) yields

\[\displaystyle \mathrm{OPT}_{\mathrm{NO}}\leq T-\frac{3\delta}{16}cn.\tag{6}\]

Thus fractional conversion preserves a constant gap.

7. Approximation hardness and rational output

Put

\(\displaystyle \Delta=\frac{3\delta}{16}cn,\qquad \varepsilon_0=\frac{3\delta}{32}.\)

This is a fixed constant in \((0,1)\). Since \(k\leq n\), we have \(T\leq cn\), and consequently

\(\displaystyle \varepsilon_0T\leq\frac{\Delta}{2}.\)

Suppose a polynomial-time algorithm returned a feasible rational allocation satisfying \(J(x)\geq(1-\varepsilon_0)\mathrm{OPT}\). On the constructed instances:

  • In the YES case, its output would satisfy \(J(x)\geq T-\Delta/2\).
  • In the NO case, every output would satisfy \(J(x)\leq T-\Delta\).

These cases can be distinguished by comparing the output value with the rational threshold \(T-3\Delta/4\).

This comparison is polynomial-time computable. The output has polynomial length because the algorithm runs in polynomial time. Equation (2) is a nonsingular rational linear system, so exact rational linear algebra computes \(u\), and hence \(J(x)\), in time polynomial in the input and output lengths.

The alleged approximation algorithm would therefore solve the stated \(\mathrm{NP}\)-hard promise problem. This proves the requested fixed-constant approximation hardness and rules out the proposed approximation scheme unless \(\mathrm{P}=\mathrm{NP}\).
