The continuous mirror question, as graded

Given candidates \(C\), target \(c^\star\), a rule \(\mathcal R\) from Corollary 2, finitely many complete voter types \(\Theta\), type data \((\rho_\theta,\sigma_\theta,a_\theta)\) where applicable, and a rational distribution \(\mu\) with \(\sum_{\theta\in\Theta}\mu_\theta=1\), choose \(x_{\theta,\rho}\ge 0\) with \(\sum_{\rho}x_{\theta,\rho}=\mu_\theta\) to minimize \(\sum_{\theta,\rho}\kappa_\theta(\rho)x_{\theta,\rho}\), where \(\kappa_\theta(\rho)\) is the admissible-swap cost from \(\rho_\theta\) to \(\rho\), subject to \(c^\star\) winning under \(\mathcal R\) in the resulting weighted profile, with approval states retained for SP-AV and fallback.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq2\) candidates and let \(c^\star\in C\). Fix a natural scoring protocol, a computable C1 rule, maximin, Bucklin, SP-AV, fallback, or Kemeny; the rule is not part of the input. Natural scoring vectors satisfy \(m\geq s_1\geq\cdots\geq s_m\geq0\) with integer entries; C1 means a Condorcet-consistent rule determined solely by pairwise majority victories and ties.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types; \(\sum_\theta\mu_\theta=1\).
Each type specifies a strict complete ranking \(\rho_\theta\), binary-encoded signed integer pair-swap costs \(\sigma_\theta(c,d)\), and, for SP-AV or fallback, an approval count \(a_\theta\in\{0,\ldots,m\}\).
For any destination ranking \(\rho\), define \(\kappa_\theta(\rho)=\sum_{c\succ_{\rho_\theta}d,\ d\succ_\rho c}\sigma_\theta(c,d)\): each inverted pair is exchanged once through adjacent swaps; repeated exchanges are excluded.
Choose real masses \(x_{\theta,\rho}\geq0\), over all strict complete destination rankings, with \(\sum_\rho x_{\theta,\rho}=\mu_\theta\). Their cost is \(\sum_{\theta,\rho}\kappa_\theta(\rho)x_{\theta,\rho}\); approval counts remain fixed, approving the first \(a_\theta\) candidates of each destination ranking.
Evaluate rules by replacing voter counts with mass, retaining all tied winners. Bucklin uses the first round with score strictly greater than \(1/2\); SP-AV maximizes approved mass; fallback applies Bucklin to approved prefixes and, if no round exceeds \(1/2\), maximizes approved mass.
Given a binary rational budget \(B\), ask whether such a redistribution makes \(c^\star\) a winner at cost at most \(B\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\) and any rule parameters.

For each fixed rule in this family, is this continuous budget problem in \(\mathsf P\) or \(\mathsf{NP}\)-hard?
In the hard cases, is it fixed-parameter tractable parameterized by \(m\), with time \(f(m)\operatorname{poly}(\tau,L)\)?

Discrete swap bribery is FPT parameterized by \(m\) throughout this family ([source](https://arxiv.org/pdf/1812.01852)), but Borda swap bribery is NP-complete ([source](https://www.math.auckland.ac.nz/~slinko/Research/swap.pdf)). Discrete approval variants are W[1]-hard for the approval parameter or budget, rather than for \(m\) ([source](https://arxiv.org/pdf/1011.1338)).
In the continuum, general-cost Borda swap bribery already has a hardness result, including finite costs; nonnegative-cost approval swap bribery is polynomial for each fixed approval parameter. General-cost Bucklin swap bribery remains listed as open ([source](https://arxiv.org/html/2608.25444v1)); the target is a rule-by-rule classification, with these existing results retained.

1. A signed-cost ordering lemma

Let \(T\) be a tournament on a vertex set \(D\). For a linear order \(\pi\) of \(D\), let \(b_T(\pi)\) count the tournament arcs pointing backward in \(\pi\).

Deciding whether some \(\pi\) satisfies \(b_T(\pi)\leq k\) is \(\mathsf{NP}\)-complete. To connect the standard feedback-arc formulation with this ordering formulation: backward arcs of any order form a feedback arc set; conversely, a topological ordering after deleting a feedback arc set has all its backward arcs among the deleted arcs. The required deterministic hardness theorem is proved by [Charbit, Thomassé, and Yeo](https://perso.ens-lyon.fr/stephan.thomasse/liste/feedback.pdf).

Fix an arbitrary reference order \(\pi_0\), and put \(K=b_T(\pi_0)\). For every pair \(u\succ_{\pi_0}v\), define its inversion cost by

\(\sigma(u,v)=1\) if \(u\to v\) is an arc of \(T\), and \(\sigma(u,v)=-1\) if \(v\to u\) is an arc of \(T\).

Then the inversion cost of every destination order is exactly

\[ \kappa(\pi)=b_T(\pi)-K. \]

Indeed, an uninverted pair contributes zero to both sides. Inverting a forward arc increases the backward-arc count by one; inverting a backward arc decreases it by one. Summing these pairwise changes proves the identity.

Consequently, if \(F=\min_\pi b_T(\pi)\), then

\[ \min_\pi\kappa(\pi)=F-K. \]

This uses exactly the prescribed inversion-cost definition. No pair is exchanged repeatedly.

2. Hardness for every listed rule

Given an instance \((T,k)\), introduce \(p=c^\star\) and use one supported type of mass one, initially ranked

\(p\succ \pi_0\).

Use the costs from Section 1 among candidates in \(D\), and set every cost involving \(p\) to zero. For SP-AV and fallback, set the approval count to one. Set the budget to \(B=k-K\).

For every destination ranking \(\rho\),

\[ \kappa(\rho)=b_T(\rho|_D)-K. \]

Suppose a redistribution has cost at most \(B\). Mass conservation gives

\[ \sum_\rho x_\rho b_T(\rho|_D)\leq k, \qquad \sum_\rho x_\rho=1. \]

Thus at least one destination order used with positive mass has at most \(k\) backward arcs. Otherwise their weighted average would exceed \(k\). Therefore every successful redistribution implies a YES instance of the tournament problem.

Conversely, suppose \(b_T(\pi)\leq k\). Move all mass to \(p\succ\pi\). Its cost is at most \(B\), and \(p\) wins under every listed rule:

  • Under any scoring protocol, \(p\) receives the maximum score \(s_1\).
  • Under any C1 rule, \(p\) is the unanimous Condorcet winner.
  • Under maximin, \(p\)'s score is one, while every opponent's score is zero.
  • Under Bucklin, \(p\) has first-round mass one.
  • Under SP-AV and fallback with approval count one, only \(p\) is approved.
  • Under Kemeny, the unanimous destination ranking is uniquely optimal.

The construction has polynomial encoding length and \(\tau=1\). Hence every listed problem is \(\mathsf{NP}\)-hard under polynomial-time many-one reductions.

Constant scoring vectors are included: with arbitrary rational budgets, cost feasibility itself is hard. If one additionally required \(B\geq0\), a constant scoring protocol would instead always answer YES. The next result addresses nontrivial rules without relying on negative budgets.

3. Hardness with zero budget

Proven strengthening. With signed costs and \(B=0\), the problem is \(\mathsf{NP}\)-hard for every C1 rule, maximin, Bucklin, SP-AV, fallback, Kemeny, and plurality. It remains hard with \(\tau=1\).

Here Condorcet consistency has its conventional meaning: when a strict Condorcet winner exists, that candidate is the sole winner.

Construction

Use the tournament instance and notation from Section 1. If \(K\leq k\), the reference order already certifies YES; output a fixed YES election.

Otherwise \(K>k\). Introduce two candidates \(q,p\), where \(p=c^\star\), and use one type of mass one with initial ranking

\(q\succ p\succ\pi_0\).

Retain the signed costs among \(D\). Set

\[ H=2(K-k)-1, \qquad M=2K+1. \]

The inversion cost of the pair \(q,p\) is \(H\). For every \(d\in D\), each of the pairs \(q,d\) and \(p,d\) has inversion cost \(M\). Set \(B=0\), and use approval count one where applicable.

These are finite integers, with \(M>H\geq1\).

Lower bound for every successful redistribution

For an arbitrary redistribution, define:

  • \(t\): the mass of rankings placing \(p\) above \(q\);
  • \(e\): the mass of rankings in which some candidate in \(D\) precedes \(q\) or \(p\).

Write \(\delta=F-K\). Each destination ranking incurs internal cost at least \(\delta\) on \(D\). Every ranking counted in \(e\) incurs at least one \(M\)-cost inversion. Therefore its total expected cost is at least

\[ \delta+Ht+Me. \]

If \(t+e<1/2\), then \(q\)'s first-place mass is greater than \(1/2\): outside the union of those two events, the ranking begins \(q\succ p\).

In that situation \(p\) cannot win:

  • Plurality, Bucklin, SP-AV, and fallback select \(q\) alone because its first-place, or approved, mass exceeds \(1/2\).
  • Under maximin, every pairwise support for \(q\) exceeds \(1/2\), whereas \(p\)'s support against \(q\) is below \(1/2\).
  • Under a C1 rule, \(q\) is the strict Condorcet winner.
  • Under Kemeny, every optimal ranking starts with \(q\). Moving \(q\) to the front of a ranking that does not start with it strictly increases agreement: each crossed candidate contributes \(P_{qd}-P_{dq}>0\).

Thus every successful redistribution satisfies \(t+e\geq1/2\). Since \(M\geq H\), its cost is at least

\[ \delta+H(t+e)\geq\delta+\frac H2 =F-k-\frac12. \]

If \(F\geq k+1\), this lower bound is at least \(1/2\), contradicting budget zero.

A successful redistribution in every YES instance

Suppose \(F\leq k\), and choose an order \(\pi\) attaining \(F\). Set

\[ t=\frac12+\frac{1}{4H}. \]

Assign mass \(t\) to \(p\succ q\succ\pi\) and mass \(1-t\) to \(q\succ p\succ\pi\).

Then \(p\) has a strict majority of first-place mass and is the strict Condorcet winner. It therefore wins under every rule covered by this strengthening. The cost is

\[ \delta+Ht =F-K+\frac H2+\frac14 =F-k-\frac14<0. \]

Hence the zero-budget instance is feasible exactly when the tournament instance is YES.

4. Exact LP framework

Let \(\mathcal R\) be the set of all \(m!\) complete rankings. Enumerate them and introduce the \(\tau m!\) variables \(x_{\theta,\rho}\).

Every LP includes

\[ x_{\theta,\rho}\geq0, \qquad \sum_{\rho\in\mathcal R}x_{\theta,\rho}=\mu_\theta, \qquad \sum_{\theta,\rho}\kappa_\theta(\rho)x_{\theta,\rho}\leq B. \]

Every cost coefficient is computable by inspecting at most \(\binom m2\) pairs. Its bit length is \(O(L+\log m)\). Negative coefficients cause no difficulty: the mass-conservation constraints bound every variable between zero and one.

Define the following linear functions:

\[ P_{cd}=\sum_{\theta,\rho:\ c\succ_\rho d}x_{\theta,\rho}, \]

\[ S_c=\sum_{\theta,\rho} s_{\operatorname{rank}_\rho(c)}x_{\theta,\rho}, \]

\[ U_{c,r}=\sum_{\theta,\rho:\ \operatorname{rank}_\rho(c)\leq r} x_{\theta,\rho}, \]

and, for approval rules,

\[ V_{c,r}= \sum_{\theta,\rho:\ \operatorname{rank}_\rho(c)\leq\min(r,a_\theta)} x_{\theta,\rho}, \qquad A_c=V_{c,m}. \]

Set \(U_{c,0}=V_{c,0}=0\).

Strict inequalities

A finite system containing strict inequalities can be decided exactly by adding a common slack variable \(\varepsilon\).

Replace every strict inequality \(h_i(x)>0\) by \(h_i(x)\geq\varepsilon\), impose \(0\leq\varepsilon\leq1\), and maximize \(\varepsilon\), retaining the budget constraint.

The original system is feasible exactly when this bounded rational LP is feasible and its optimum is positive. One direction follows immediately. For the other, at any feasible point of the original system, the minimum of its finitely many positive strict slacks is positive.

This procedure tests actual feasibility at the budget; it does not confuse an unattained infimum with an achievable cost.

5. Winner conditions for each rule

Scoring protocols and SP-AV

For a scoring protocol, impose \(S_p\geq S_c\) for every \(c\neq p\).

For SP-AV, impose \(A_p\geq A_c\) for every \(c\neq p\).

Each rule needs one LP.

C1 rules

Enumerate all \(3^{\binom m2}\) pairwise patterns: victory, defeat, or tie for each unordered pair.

Evaluate the fixed rule on each pattern. Discard patterns in which \(p\) is not a winner. For each remaining pattern, impose the corresponding conditions \(P_{cd}>1/2\), \(P_{cd}<1/2\), or \(P_{cd}=1/2\).

These conditions characterize the pattern exactly because rankings are complete and total mass is one. Handle strict conditions by the common-slack construction.

Computability suffices: for fixed \(m\), there are only finitely many patterns, so their maximum evaluation time \(T_R(m)\) is a computable function of \(m\).

Maximin

For every candidate \(c\), guess an opponent \(d(c)\neq c\) attaining its minimum pairwise support. There are \((m-1)^m\) guesses.

For each guess, impose

\[ P_{c,d(c)}\leq P_{c,d} \quad\text{for every }d\neq c, \]

and

\[ P_{p,d(p)}\geq P_{c,d(c)} \quad\text{for every }c\neq p. \]

The first inequalities make the guessed opponents genuine minimizers; the second make \(p\)'s maximin score maximal. Every profile admits such a guess, including profiles with tied minimizers.

Bucklin

Guess the winning round \(r\in\{1,\ldots,m\}\). Impose

\[ U_{c,r-1}\leq\frac12\quad\text{for every }c, \]

\[ U_{p,r}>\frac12, \qquad U_{p,r}\geq U_{c,r}\quad\text{for every }c. \]

Prefix scores are nondecreasing in the round. Thus the first inequalities exclude every earlier majority round; the remaining inequalities say that \(r\) is the first majority round and \(p\) has maximal score there.

Conversely, every Bucklin-winning profile satisfies the system for its winning round.

Fallback

For each guessed majority round \(r\), use the Bucklin system with \(V\) replacing \(U\).

Add one branch for the absence of an approved-prefix majority:

\[ A_c\leq\frac12\quad\text{for every }c, \qquad A_p\geq A_c\quad\text{for every }c. \]

Because approved-prefix scores are nondecreasing and their final values are \(A_c\), this last branch excludes a majority at every round and implements the specified approval fallback.

Kemeny

For an aggregate ranking \(\pi\), define its agreement score

\[ G_\pi(x)= \sum_{\theta,\rho}x_{\theta,\rho} \left|\{(c,d):c\succ_\pi d\text{ and }c\succ_\rho d\}\right|. \]

This is a linear function with integer coefficients between zero and \(\binom m2\).

Enumerate the \((m-1)!\) rankings \(\pi\) starting with \(p\). For each one, impose

\[ G_\pi(x)\geq G_\lambda(x) \quad\text{for every }\lambda\in\mathcal R. \]

These inequalities make \(\pi\) an optimal Kemeny ranking. Therefore some branch is feasible exactly when \(p\) is a Kemeny winner. Each branch has at most \(m!\) agreement comparisons.

6. Running-time justification

Every branch has \(\tau m!\) redistribution variables, at most one additional slack variable, and at most

\[ O(\tau+m^2+m!) \]

explicit constraints besides nonnegativity. All rational coefficients have bit length \(O(L+\log m)\).

Constructing and solving a branch therefore takes

\[ 2^{O(m\log m)}\operatorname{poly}(\tau,L) \]

time by polynomial-time rational linear programming.

The branch counts are one for scoring and SP-AV, \((m-1)^m\) for maximin, \(m\) for Bucklin, \(m+1\) for fallback, and \((m-1)!\) for Kemeny. These factors preserve the stated \(2^{O(m\log m)}\) bound.

For C1, multiplying by \(3^{\binom m2}\) and including pattern evaluation gives

\[ 3^{\binom m2}T_R(m) +2^{O(m^2)}\operatorname{poly}(\tau,L). \]

The construction keeps a separate block for each supported type. It neither assumes that \(\tau\) counts all possible types nor expands binary rational masses into individual voters.
