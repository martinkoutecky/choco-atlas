The continuous mirror question, as graded

Given finite \(T\) and \(J\), rational type masses \(\mu_t\) and item supplies \(q_j\) with \(\sum_t\mu_t=\sum_jq_j=1\), known rankings \(\succ_t\), and oracle access to each type's common valuation vector \(v_t\), design a deterministic algorithm that makes at most \(1+\lambda+\lambda\lceil\log_2|J|\rceil\) queries per positive-mass type and returns \(x=(x_{tj})\) satisfying \(x_{tj}\ge0\), \(\sum_jx_{tj}=\mu_t\), and \(\sum_tx_{tj}=q_j\); determine its worst-case distortion \(\sup_v \frac{\max_{x'\in\mathcal X(\mu,q)}W(x';v)}{W(x;v)}\), where \(W(x;v)=\sum_{t,j}x_{tj}v_t(j)\), and whether \(2\eta^{-1/(\lambda+1)}\) is achievable for \(\eta=\min(\{\mu_t:\mu_t>0\}\cup\{q_j:q_j>0\})\).

Packaged proof task (what the prover saw — nothing else)

Let \(T\) and \(J\) be finite, with rational masses \(\mu_t\ge 0\) and supplies \(q_j\ge 0\), each summing to \(1\). Each type \(t\) has a known ranking \(\succ_t\) consistent with an unknown, unrestricted nonnegative valuation \(v_t:J\to\mathbb R_{\ge0}\); a value query for \((t,j)\) returns \(v_t(j)\).
A feasible mass allocation \(x\) satisfies \(x_{tj}\ge0\), \(\sum_jx_{tj}=\mu_t\), and \(\sum_tx_{tj}=q_j\). Write \(\mathcal X(\mu,q)\) for these allocations and \(W(x;v)=\sum_{t,j}x_{tj}v_t(j)\). Distortion is the worst-case ratio \(\max_{x'\in\mathcal X(\mu,q)}W(x';v)/W(x;v)\) over valuations consistent with the rankings.
For an integer \(\lambda\ge0\), let \(\eta=\min(\{\mu_t:\mu_t>0\}\cup\{q_j:q_j>0\})\).
Target. Is there a polynomial-time deterministic algorithm using at most \(1+\lambda+\lambda\lceil\log_2|J|\rceil\) queries per positive-mass type and achieving distortion at most \(2\eta^{-1/(\lambda+1)}\), or is achieving this guarantee NP-hard? What is the optimal worst-case distortion under this query budget?
Nearest known results. With \(n\) individual agents and \(n\) indivisible items, a polynomial-time deterministic algorithm uses \(1+\lambda+\lambda\log_2 n\) queries per agent and achieves distortion at most \(2n^{1/(\lambda+1)}\). No result for the exact mass-allocation model was verified.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The requested guarantee is achievable in polynomial time. In fact, the algorithm below uses at most \(1+\lambda\lceil\log_2|J|\rceil\) queries per positive-mass type. This settles the algorithmic existence question. I do not establish the optimal worst-case distortion under the query budget.

The computational model is exact arithmetic and comparisons on query answers. For rational answers, the algorithm also has polynomial bit complexity in the input and answer lengths.

Proven claim. There is a deterministic algorithm producing an allocation \(x\) such that, for every consistent valuation profile \(v\),
\[ \max_{y\in\mathcal X(\mu,q)}W(y;v) \le \min\!\left\{\eta^{-1},\,2\eta^{-1/(\lambda+1)}\right\}W(x;v). \]
This inequality also covers profiles whose optimal welfare is zero.

Delete zero-mass types and zero-supply items. These rows and columns must be zero in every feasible allocation, so deletion preserves all attainable welfare values. Let \(m\) be the remaining number of items. Each remaining supply is at least \(\eta\).

If the allowed query budget is at least \(m\), query every remaining value and compute an optimal transportation allocation. This gives distortion \(1\). Otherwise use the construction below. In particular, we may assume \(\lambda<m\), which bounds the exponents used in the computations.

For each type, list the remaining items in ranking order as \(j_{t,1},\ldots,j_{t,m}\). Consistency implies
\[ v_t(j_{t,1})\ge\cdots\ge v_t(j_{t,m}). \]
The argument permits ties and therefore also applies when consistency requires strict inequalities.

  • Query threshold boundaries and construct lower estimates.

Set
\[ \rho=\eta^{-1/(\lambda+1)}\ge1. \]
Query \(M_t=v_t(j_{t,1})\). If \(M_t=0\), every remaining value of this type is zero; no further queries are needed.

For each \(k\in\{1,\ldots,\lambda\}\), find the last position
\[ b_{t,k}=\max\{i:v_t(j_{t,i})\ge M_t\rho^{-k}\} \]
by binary search.

Here position \(1\) is a known true position, and position \(m+1\) is an artificial false sentinel. The initial interval has length \(m\), so at most \(\lceil\log_2m\rceil\) queries identify the boundary. Moreover, the boundary's value is known: every true endpoint is either position \(1\) or a position that was queried.

Let \(Q_t\) be the set of queried positions, including position \(1\). Define
\[ \widehat v_t(j_{t,i}) = \max\bigl(\{v_t(j_{t,h}):h\in Q_t,\ h\ge i\}\cup\{0\}\bigr). \]
Ranking consistency gives
\[ 0\le\widehat v_t(j)\le v_t(j), \qquad \widehat v_t(j_{t,1})=M_t. \]

This uses at most
\[ 1+\lambda\lceil\log_2m\rceil \le1+\lambda\lceil\log_2|J|\rceil \]
queries per positive-mass type.

  • Verify the approximation supplied by the queries.

I claim that, for every remaining type and item,
\[ v_t(j)\le \rho\,\widehat v_t(j)+M_t\rho^{-\lambda}. \tag{1} \]

When \(\lambda=0\), this follows from \(v_t(j)\le M_t\). When \(M_t=0\), it is immediate.

Otherwise, if \(v_t(j)<M_t\rho^{-\lambda}\), the additive term alone proves (1). For the remaining case, let \(k\) be the smallest integer in \(\{1,\ldots,\lambda\}\) satisfying
\[ v_t(j)\ge M_t\rho^{-k}. \]
The position of \(j\) is at most \(b_{t,k}\). Because this boundary was queried,
\[ \widehat v_t(j)\ge v_t(j_{t,b_{t,k}})\ge M_t\rho^{-k}. \]
If \(k=1\), then \(v_t(j)\le M_t=\rho M_t\rho^{-1}\). If \(k>1\), minimality gives
\[ v_t(j)<M_t\rho^{-(k-1)}=\rho M_t\rho^{-k}. \]
Thus in either case \(v_t(j)\le\rho\widehat v_t(j)\), proving (1).

  • Optimize the lower estimates.

Return a deterministically chosen maximizer
\[ x\in\operatorname*{arg\,max}_{y\in\mathcal X(\mu,q)} \sum_{t,j}y_{tj}\widehat v_t(j). \]
Write its surrogate welfare as \(\widehat W\), and set
\[ S=\sum_t\mu_tM_t. \]
Since the surrogate values are lower estimates,
\[ W(x;v)\ge\widehat W. \tag{2} \]

The essential capacity bound is
\[ \widehat W\ge\eta S. \tag{3} \]

To prove it, initially assign mass \(\eta\mu_t\) of each type to its first-ranked remaining item. The load on any item \(j\) is
\[ \ell_j=\eta\sum_{t:j_{t,1}=j}\mu_t\le\eta\le q_j. \]
Each row also stays within its required mass.

If \(\eta<1\), complete this partial allocation by assigning residual mass
\[ r_{tj}=\frac{(1-\eta)\mu_t(q_j-\ell_j)}{1-\eta}. \]
Indeed, the residual row requirements are \((1-\eta)\mu_t\), the residual column requirements are \(q_j-\ell_j\), and both sum to \(1-\eta\). The displayed product construction has exactly these marginals. If \(\eta=1\), the initial allocation is already complete.

Its surrogate welfare is at least \(\eta S\), because all remaining contributions are nonnegative. Optimality of \(x\) proves (3).

  • Bound the true optimum.

Let \(x^\star\) maximize true welfare. Summing (1) against \(x^\star\), using its row sums and then surrogate optimality, gives
\[ \begin{aligned} W(x^\star;v) &\le \rho W(x^\star;\widehat v)+\rho^{-\lambda}S\\ &\le \rho\widehat W+\rho^{-\lambda}S\\ &\le\left(\rho+\eta^{-1}\rho^{-\lambda}\right)\widehat W. \end{aligned} \]
By the definition of \(\rho\),
\[ \eta^{-1}\rho^{-\lambda}=\rho. \]
Applying (2) therefore yields
\[ W(x^\star;v)\le2\eta^{-1/(\lambda+1)}W(x;v). \]

Also, \(W(x^\star;v)\le S\), since every value of type \(t\) is at most \(M_t\). Equations (2) and (3) consequently give
\[ W(x^\star;v)\le\eta^{-1}W(x;v), \]
proving the claimed minimum of the two bounds.

The optimization step is a minimum-cost transportation problem: use type supplies \(\mu_t\), item demands \(q_j\), and arc costs \(-\widehat v_t(j)\). It is feasible, since \(y_{tj}=\mu_tq_j\) is feasible, and bounded, since total transported mass is \(1\). Strongly polynomial minimum-cost-flow algorithms apply. [Orlin, *A Faster Strongly Polynomial Minimum Cost Flow Algorithm*](https://pubsonline.informs.org/doi/pdf/10.1287/opre.41.2.338).

No irrational coefficients are needed in this optimization: every surrogate value is either zero or a query answer. Threshold comparisons can also avoid extracting roots, because for nonnegative values
\[ v_t(j)\ge M_t\rho^{-k} \quad\Longleftrightarrow\quad v_t(j)^{\lambda+1}\ge M_t^{\lambda+1}\eta^k. \]
For rational answers these are exact rational comparisons of polynomial bit length, using \(\lambda<m\).

What remains open in this argument. The construction proves an upper bound, not a matching lower bound for arbitrary adaptive deterministic query algorithms. The optimal distortion is exactly \(1\) when the budget permits querying all positive-supply items. Outside that regime, neither the exact optimum nor a matching asymptotic lower bound is established here.
