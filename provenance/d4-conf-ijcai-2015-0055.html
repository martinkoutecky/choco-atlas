The continuous mirror question, as graded

Given a finite HCLP structure, a query \(\alpha\le\beta\), a rational threshold \(q\), a support bound \(\tau\), and strata \(j\) with rational masses \(w_j\) summing to one and input statements \(\Gamma_j\), consider allocations \(x_{j,H}\ge0\) of each stratum’s mass to HCLP types \(H\in\mathcal C(2)\) satisfying \(\Gamma_j\), with at most \(\tau\) distinct types used overall. Is the minimum, over all such compatible allocations, of \(\sum_{j,H:\,H\models^\oplus\alpha\le\beta}x_{j,H}\) at least \(q\)?

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a finite set of alternatives and \(C\) a finite set of criteria, with \(m=|C|\ge2\), given by tables \(c:A\to\mathbb Q_{\ge0}\). Fix an associative, commutative, monotone operation \(\oplus\) on nonnegative rationals, with identity \(0\), computable in linear bit time.
An HCLP type \(H=(C_1,\ldots,C_k)\in\mathcal C(2)\) is an ordered partition of any subset of \(C\), with nonempty levels of size at most two; the empty sequence is allowed. Compare alternatives lexicographically by the level costs \(\bigoplus_{c\in C_i}c(a)\), preferring smaller costs. Write \(H\models^\oplus a\le b\) for weak preference and \(H\models^\oplus a<b\) for strict preference; complete ties satisfy only the weak comparison.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here input types are strata described by finite sets \(\Gamma_j\) of strict or non-strict comparisons; \(\tau\) is the support size, not the number of possible HCLP types. Masses \(w_j>0\) satisfy \(\sum_jw_j=1\).
The remaining inputs are \(\alpha,\beta\in A\), a binary rational \(q\in[0,1]\), and a binary integer \(K\ge1\) bounding the number of distinct HCLP types used overall. Let \(L\) be the total input bit length.
A compatible allocation has nonnegative rational entries \(x_{j,H}\), satisfies \(\sum_Hx_{j,H}=w_j\), and has \(x_{j,H}=0\) unless \(H\models^\oplus\Gamma_j\); moreover \(\left|\{H:\sum_jx_{j,H}>0\}\right|\le K\). Define \(V=\min_x\sum_{j,H:\,H\models^\oplus\alpha\le\beta}x_{j,H}\), with \(V=+\infty\) if no compatible allocation exists.

Is deciding whether \(V\ge q\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard under polynomial-time Turing reductions? State running times in \(m,\tau,L,K,|A|\), and \(\sum_j|\Gamma_j|\).

Discrete HCLP deduction with levels of size at most two is \(\mathrm{coNP}\)-complete even with only non-strict statements; singleton levels give polynomial-time deduction ([source](https://arxiv.org/html/2409.11044v1)).

Classification

For every fixed operation \(\oplus\) satisfying the stated assumptions, deciding whether \(V\ge q\) is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions. Consequently, it is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions, and a polynomial-time algorithm would imply \(\mathrm P=\mathrm{NP}\).

Hardness holds even when \(\tau=K=1\), \(q=1\), and all input statements are non-strict. These restricted instances are always feasible.

Write \(S=\sum_{j=1}^{\tau}|\Gamma_j|\).

1. Splitting a stratum’s mass is unnecessary

For each type \(H\), define \(d(H)=1\) if \(H\models^\oplus\alpha\le\beta\), and \(d(H)=0\) otherwise.

Lemma. Every compatible allocation can be replaced by a compatible allocation assigning each stratum’s entire mass to one type, without increasing its objective or its number of distinct types.

Proof. Let \(x\) be compatible. For each stratum \(j\), its positive mass \(w_j\) implies that some \(x_{j,H}\) is positive. Among those types, choose \(H_j\) minimizing \(d(H)\). Assign all \(w_j\) to \(H_j\).

Compatibility holds because \(x_{j,H_j}>0\) implies \(H_j\models^\oplus\Gamma_j\). Every selected type belonged to the original support, so the number of types cannot increase. Moreover,

\(w_jd(H_j)=\sum_Hx_{j,H}d(H_j)\le\sum_Hx_{j,H}d(H).\)

Summing over \(j\) proves the claim. \(\square\)

There are finitely many HCLP types. Therefore, if an allocation exists, the minimum is attained by such an unsplit allocation, and

\(V=\min\left\{\sum_{j=1}^{\tau}w_jd(H_j): H_j\models^\oplus\Gamma_j,\ \left|\{H_1,\ldots,H_\tau\}\right|\le K\right\}.\)

The minimum of an empty feasible family is understood as \(+\infty\). In particular, any feasible optimum uses at most \(\min\{K,\tau\}\) types. No linear programming is needed.

2. Membership in \(\mathrm{coNP}\)

The complement of the decision problem asks whether \(V<q\).

By the lemma, a certificate consists of one type \(H_j\) for each stratum, satisfying:

  • \(H_j\models^\oplus\Gamma_j\) for every \(j\);
  • at most \(K\) distinct types occur;
  • \(\sum_jw_jd(H_j)<q\).

Equivalently, the certificate can list at most \(\min\{K,\tau\}\) types and specify which listed type each stratum uses. Duplicate entries in this list cause no difficulty: its length already bounds the number of distinct types.

A type contains at most \(m\) criterion occurrences and has an encoding of length \(O(m\log(m+1))\). Thus the certificate length is polynomial in \(L\), even though \(K\) is binary encoded.

To verify satisfaction, compute the costs at successive levels and inspect the first unequal pair. Each level has at most two criteria. The linear bit-time assumption on \(\oplus\) implies that every level cost has \(O(L)\) bits. Rational comparisons and the final weighted sum can therefore be checked in polynomial bit time. For the weighted sum, a common denominator obtained by multiplying the input denominators has \(O(L)\) bits.

For example, a conservative verification bound is

\(O\!\left(L^2\left[m^2(|A|+S+1)+m(S+\tau)+\tau\right]\right).\)

Here one may first compute costs for every singleton and pair, and comparison signs for all statements appearing in the input or query.

If no allocation exists, then \(V=+\infty\), so the instance is correctly outside the complement. Hence the original problem belongs to \(\mathrm{coNP}\).

3. Hardness with one stratum

The cited deduction theorem states that deciding \(\Gamma\models_{\mathcal C(2)}^\oplus\alpha\le\beta\) is \(\mathrm{coNP}\)-complete even when \(\Gamma\) contains only non-strict statements. Its HCLP structures use precisely the assumptions here: nonnegative rational criterion tables, an associative, commutative, monotone operation with identity \(0\), linear-time computation of that operation, and ordered partitions of possibly empty criterion subsets. Thus it applies to the fixed operation in this question. [Wilson, George, and O’Sullivan, Theorem 1](https://arxiv.org/html/2409.11044v1#S2).

Given such a deduction instance, retain its alternatives, criteria, tables, and query, and construct the allocation instance with

\(\tau=1,\quad \Gamma_1=\Gamma,\quad w_1=1,\quad K=1,\quad q=1.\)

This transformation has polynomial running time and output length. Since all statements in \(\Gamma\) are non-strict, the empty type satisfies them, so the allocation instance is feasible.

With one stratum and \(K=1\), all mass must be assigned to a single compatible type. Consequently:

  • If some \(H\models^\oplus\Gamma\) violates \(\alpha\le\beta\), assigning the entire mass to \(H\) gives \(V=0\).
  • If every \(H\models^\oplus\Gamma\) satisfies \(\alpha\le\beta\), every compatible allocation has objective \(1\), so \(V=1\).

Therefore,

\(V\ge1\quad\Longleftrightarrow\quad\Gamma\models_{\mathcal C(2)}^\oplus\alpha\le\beta.\)

This proves \(\mathrm{coNP}\)-hardness, and together with Section 2 proves \(\mathrm{coNP}\)-completeness.

For the requested Turing hardness, take a polynomial-time reduction from \(3\)-UNSAT to this problem. On a \(3\)-SAT instance, make the resulting oracle query and negate its answer. This decides \(3\)-SAT using one oracle call, proving \(\mathrm{NP}\)-hardness under polynomial-time Turing reductions.

4. Explicit deterministic running times

Let \(N=N_m=|\mathcal C(2)|\). An upper bound sufficient for the algorithm is

\(N\le\sum_{n=0}^{m}\frac{m!}{(m-n)!}\,2^n\le(m+1)2^m m!=2^{O(m\log m)}.\)

Indeed, a type using \(n\) criteria can be represented by an ordered list of those criteria and cuts into blocks of size one or two. There are \(m!/(m-n)!\) possible lists and at most \(2^n\) cut patterns. Multiple representations only enlarge this upper bound.

Set

\(k=\min\{K,\tau,N\},\qquad F(N,k)=\sum_{r=1}^{k}\binom Nr.\)

Enumerate all types and record their compatibility with each stratum and their query indicators \(d(H)\). Then enumerate all nonempty type sets \(T\) with \(|T|\le k\).

For a fixed \(T\), define \(I_j(T)=\{H\in T:H\models^\oplus\Gamma_j\}\). The set \(T\) permits an allocation exactly when every \(I_j(T)\) is nonempty. When it does, its minimum objective is

\(f(T)=\sum_{\{j:\ d(H)=1\text{ for every }H\in I_j(T)\}}w_j.\)

To justify this formula, a stratum contributes zero whenever it has a compatible type with indicator zero; otherwise every compatible type contributes its entire mass. These choices use only types from \(T\). Taking the minimum of \(f(T)\) over feasible enumerated sets gives \(V\), by Section 1.

Using ordinary rational arithmetic, a conservative bit-time bound for this exact algorithm is

\(O\!\left(L^2\left[m^2(|A|+S+1)+Nm(S+\tau)+\tau(k+1)F(N,k)\right]\right).\)

The terms account respectively for preprocessing level comparisons, screening all types, and evaluating all candidate type sets. This bound explicitly handles binary encoded \(K\): only its capped value \(k\) controls enumeration.

Since \(F(N,k)\le(N+1)^k\), the bound is also

\(2^{O(km\log m)}\operatorname{poly}(L,m,\tau,|A|,S).\)

Alternatively, \(F(N,k)\le2^N\) yields

\(2^{\,2^{O(m\log m)}}\operatorname{poly}(L,m,\tau,|A|,S),\)

so the problem is fixed-parameter tractable in \(m\). If \(q=0\), the answer is always yes, including infeasible instances.
