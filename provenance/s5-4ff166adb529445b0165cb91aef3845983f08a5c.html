The continuous mirror question, as graded

Given a finite type set \(T\) with positive rational masses \(\mu_t\) summing to one, an explicitly listed Markov chain \(Q\) over graphs \(H\) on \(T\), component values \(w(S,H)\), and rational \(0<\delta<1\) for which the operator in Theorem 4.1 is invertible, compute the unique per-capita allocation table \(y_t(H)\) satisfying \(\sum_{t\in S}\mu_t y_t(H)=w(S,H)\) for every component and \(X_t(y,H)-X_t(y,H\setminus e)=X_u(y,H)-X_u(y,H\setminus e)\) for each edge \(e=\{t,u\}\), where \(X_t\) is the discounted expected per-capita payoff under \(Q\).

Result

The promised allocation is exactly computable in polynomial time in \(m,\tau,K,L\). The proof gives a rational linear system of polynomial size, proves that the promise makes it uniquely solvable, and bounds the bit lengths needed for exact computation.

Throughout, graphs have vertex set \(T\), so subgraph inclusion refers to inclusion of edge sets.

1. Static existence and uniqueness with positive masses

We first justify the static operator \(M_\mu\) directly, including arbitrary component externalities.

For a component \(S\), write \(\mu(S)=\sum_{t\in S}\mu_t\). Every such quantity is positive.

Lemma. For every real component-value table \(v\), there is exactly one table \(z\) satisfying static component efficiency and edge fairness. Its dependence on \(v\) is linear.

Proof. Process graphs in increasing order of their number of edges. We construct auxiliary tables \(a_t(H)\) that are constant on each connected component of \(H\).

Once these tables have been defined for all proper subgraphs of \(H\), set

\(\displaystyle g_t(H)=\sum_{F\subsetneq H}a_t(F).\)

For each component \(S\) of \(H\), define, for every \(t\in S\),

\(\displaystyle a_t(H)=\frac{v(S,H)-\sum_{u\in S}\mu_u g_u(H)}{\mu(S)}.\)

Finally, set

\(\displaystyle z_t(H)=g_t(H)+a_t(H)=\sum_{F\subseteq H}a_t(F).\)

These definitions also cover the empty graph: its proper-subgraph sum is zero. The definition of \(a_t(H)\) immediately gives component efficiency.

For an edge \(e=\{t,u\}\in H\), subtraction gives

\(\displaystyle z_t(H)-z_t(H\setminus e)=\sum_{\substack{F\subseteq H\\ e\in F}}a_t(F).\)

Every graph \(F\) in this sum contains \(e\). Its endpoints therefore belong to the same component of \(F\), and \(a_t(F)=a_u(F)\). This proves edge fairness.

For uniqueness, proceed by induction on the number of edges. Suppose the solution and its auxiliary tables have already been determined on all proper subgraphs of \(H\). For any candidate solution, put \(b_t(H)=z_t(H)-g_t(H)\). For \(e=\{t,u\}\in H\),

\(\displaystyle z_t(H)-z_t(H\setminus e)=b_t(H)+\sum_{\substack{F\subsetneq H\\ e\in F}}a_t(F).\)

The sum on the right has equal values for \(t\) and \(u\). Edge fairness thus implies \(b_t(H)=b_u(H)\). Consequently, \(b_t(H)\) is constant on each component \(S\), and component efficiency uniquely determines that constant as the displayed formula for \(a_t(H)\).

Every step of the construction is linear in \(v\), proving linearity. \(\square\)

Let \(B\) denote the component-sum operator:

\(\displaystyle (Bz)(S,H)=\sum_{t\in S}\mu_t z_t(H).\)

The lemma gives \(BM_\mu v=v\). It also shows that a table \(x\) satisfies static edge fairness exactly when

\(\displaystyle x=M_\mu(Bx).\)

2. The dynamic promise gives a unique solution

Let \(n=mK\), the number of entries in a per-capita table. Regard \(Q\) as an operator on these \(n\) coordinates.

Because its transition probabilities are nonnegative and each row sums to one,

\(\displaystyle \|Qz\|_\infty\leq\|z\|_\infty.\)

Hence, since \(0<\delta<1\), the operator series \(\sum_{k=0}^{\infty}\delta^kQ^k\) converges. Multiplying its finite partial sums by \(I-\delta Q\) gives \(I-\delta^{j+1}Q^{j+1}\), which converges to \(I\). Thus

\(\displaystyle D:=I-\delta Q\quad\text{is invertible},\qquad X(y)=D^{-1}y.\)

Put \(x=X(y)\). The requested conditions become

  • \(y=Dx\);
  • \(By=w\);
  • \(x\) satisfies static edge fairness.

By the static lemma, these conditions imply

\(\displaystyle x=M_\mu(Bx)=M_\mu(w+\delta BQx).\)

Since \(W_{Q,\mu}=BQ\), define

\(\displaystyle A=I-\delta M_\mu W_{Q,\mu}.\)

Every requested allocation must therefore satisfy \(Ax=M_\mu w\). The promise says that \(A\) is invertible.

Conversely, take \(x=A^{-1}M_\mu w\) and \(y=Dx\). The defining equation for \(x\) gives

\(\displaystyle x=M_\mu(w+\delta W_{Q,\mu}x).\)

Therefore \(x\) satisfies static edge fairness, and applying \(B\) gives \(Bx=w+\delta W_{Q,\mu}x\). Consequently,

\(\displaystyle By=Bx-\delta BQx=w.\)

Also \(X(y)=D^{-1}y=x\), so the required dynamic fairness holds. This proves existence and uniqueness, with operator formula

\(\displaystyle y=(I-\delta Q)(I-\delta M_\mu W_{Q,\mu})^{-1}M_\mu w.\)

3. A polynomial-size rational linear system

The algorithm can use the original constraints directly, without constructing the operators in that formula.

Introduce the \(2n\) unknowns \(x_t(H)\) and \(y_t(H)\), and impose:

  • For every \(t,H\),

\(\displaystyle x_t(H)-\delta\sum_{H'}Q(H'\mid H)x_t(H')-y_t(H)=0.\)

  • For every component \(S\) of every \(H\),

\(\displaystyle \sum_{t\in S}\mu_t y_t(H)=w(S,H).\)

  • For every edge \(e=\{t,u\}\in H\),

\(\displaystyle x_t(H)-x_t(H\setminus e)-x_u(H)+x_u(H\setminus e)=0.\)

The preceding section proves that this rational system has exactly one solution on every promised input.

There are \(n\) equations of the first kind. The number \(c\) of component equations satisfies \(c\leq mK\), and the number \(r\) of fairness equations satisfies \(r\leq K\binom{m}{2}\). Thus the total number of rows obeys

\(\displaystyle R=n+c+r\leq 2mK+K\binom{m}{2}.\)

Components and edge-deleted graphs can be identified in polynomial time from the explicitly listed graphs. The whole matrix therefore has polynomial size and can be constructed in polynomial time.

4. Exact bit complexity and output size

It remains to justify polynomial bit complexity.

Let \(d\) be the product of the positive denominators of all rational numbers in the input, including \(\delta\). Since their encodings contribute to the total input length, \(\log_2 d=O(L)\).

Every coefficient of the system is among \(0,\pm1,\mu_t,-\delta Q(H'\mid H)\), and \(1-\delta Q(H\mid H)\). Multiplying the entire system by \(d^2\) therefore produces an integer system, including its right-hand side. Every resulting entry has \(O(L)\) bits: the coefficients have absolute value at most one before scaling, and the input values \(w(S,H)\) have at most \(L\) bits.

Write \(N=2n\), and let \(U=2^{O(L)}\) bound all absolute integer entries. Uniqueness and consistency imply that the coefficient matrix has column rank \(N\). Hence it contains \(N\) independent rows forming an invertible integer matrix \(C\).

For any \(s\) by \(s\) submatrix of the augmented integer matrix, the determinant expansion gives

\(\displaystyle |\det|\leq s!U^s.\)

In particular, every determinant of order at most \(N\) has \(O(N(L+\log N))\) bits.

For completeness, this also bounds the arithmetic needed to find independent rows and compute determinants. In exact Gaussian elimination with row and column pivoting, each remaining entry after \(k\) pivots is a Schur-complement entry. If \(P\) is the selected invertible pivot submatrix, the identity

\(\displaystyle d_0-cP^{-1}b=\frac{\det\begin{pmatrix}P&b\\c&d_0\end{pmatrix}}{\det P}\)

expresses that entry as a ratio of minors of the original matrix. The same identity applies to the right-hand-side column. Thus reduced fractions occurring during elimination have polynomial bit length. There are polynomially many arithmetic operations, and integer arithmetic and fraction reduction take polynomial time at these lengths.

After selecting \(C\), Cramer’s rule gives each coordinate of the unique solution as

\(\displaystyle u_i=\frac{\det C_i}{\det C},\)

where \(C_i\) replaces one column of \(C\) by the selected right-hand side. These determinants can be computed by the same exact elimination procedure. Both numerator and denominator have \(O(N(L+\log N))\) bits.

This proves polynomial-time exact computation and polynomial total output length. Returning the \(y\)-coordinates supplies the requested rational allocation.

Conclusion

The target problem is polynomial-time computable under the stated invertibility promise. Although \(K=2^{\binom{m}{2}}\), all graphs and their transition data are explicitly present in the input; the algorithm is polynomial in that explicit input size.
