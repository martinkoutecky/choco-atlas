The continuous mirror question, as graded

Given a known agenda \((p_j,q_j)_{j=1}^m\) with rational coordinates and a finite support of complete ballot-record types \(t\), each with positive rational mass \(\mu_t\), compute \(\rho(\mu)=\sum_t \mu_t\,\mathbf{1}[\text{Theorem 1’s conditions hold for }V_t]\) exactly and decide, for a rational threshold \(\alpha\), whether \(\rho(\mu)\ge\alpha\).

Packaged proof task (what the prover saw — nothing else)

Given integers \(m,d\ge1\), a known agenda consists of pairs \((p_j,q_j)\in\mathbb{Q}^d\times\mathbb{Q}^d\), with \(p_j\ne q_j\), for \(j=1,\ldots,m\). Alternatives may recur across items.
A society is given by its support: the list of \(\tau\) distinct complete ballot types \(t\in\{\mathrm{yes},\mathrm{no}\}^m\) with positive masses \(\mu_t\) encoded as binary rationals, satisfying \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
For type \(t\), define \(V_t=\{(y_j,z_j):j=1,\ldots,m\}\), where \((y_j,z_j)=(p_j,q_j)\) for a yes ballot and \((y_j,z_j)=(q_j,p_j)\) for a no ballot.
Call \(V_t\) admissible if there exists a concave utility function \(u_t:\mathbb{R}^d\to\mathbb{R}\) satisfying \(u_t(y)>u_t(z)\) for every \((y,z)\in V_t\). Utilities are unrestricted in sign; no monotonicity or ideal-point condition is imposed.
Define \(\rho(\mu)=\sum_t\mu_t\mathbf{1}[V_t\text{ is admissible}]\). The input also includes a binary rational threshold \(\alpha\in[0,1]\). Let \(L\) be the total input bit length; state running times in \(m,\tau,d,L\).

Can \(\rho(\mu)\) be computed exactly in polynomial time in \(m,\tau,d,L\), or is deciding whether \(\rho(\mu)\ge\alpha\) NP-hard?

For a single finite voting record, admissibility is decidable in polynomial time using linear programming. Existence of a concave, strictly concave, quasiconcave, or strictly quasiconcave utility that strictly rationalizes that record is equivalent.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The statistic \(\rho(\mu)\) can be computed exactly in polynomial time. The essential hypothesis is that the support is explicitly listed: only the \(\tau\) supplied ballot types need to be tested.

Admissibility as a rational linear program. Let \(\{x_1,\ldots,x_n\}\) be the distinct alternatives occurring in the agenda, so \(n\le 2m\). For each item \(j\) and ballot type \(t\), let \(a_t(j)\) and \(b_t(j)\) index its preferred and rejected alternatives, respectively.

For a fixed type \(t\), introduce variables \(U_i\in\mathbb R\) and \(g_i\in\mathbb R^d\), for \(i=1,\ldots,n\). Consider the feasibility problem

\[ U_k\le U_i+g_i\cdot(x_k-x_i) \qquad(i,k=1,\ldots,n), \]

\[ U_{a_t(j)}-U_{b_t(j)}\ge 1 \qquad(j=1,\ldots,m). \]

All variables are unrestricted in sign. We prove that this system is feasible exactly when \(V_t\) is admissible.

First, suppose a finite-valued concave function \(u:\mathbb R^d\to\mathbb R\) strictly rationalizes \(V_t\). Define

\[ \delta=\min_{1\le j\le m} \bigl(u(x_{a_t(j)})-u(x_{b_t(j)})\bigr)>0. \]

The minimum is positive because it is taken over finitely many strictly positive quantities. Thus \(v=u/\delta\) is concave and its required utility differences are at least \(1\).

We use the standard supergradient theorem: a finite-valued concave function on an open convex domain has, at every point \(x\), a vector \(g\) satisfying \(v(z)\le v(x)+g\cdot(z-x)\) throughout that domain. Here the domain is all of \(\mathbb R^d\), so every \(x_i\) satisfies its hypotheses. Choose such a supergradient \(g_i\) at each \(x_i\), and set \(U_i=v(x_i)\). These choices satisfy the displayed system.

Conversely, suppose the system is feasible. Define

\[ u(x)=\min_{1\le i\le n} \bigl(U_i+g_i\cdot(x-x_i)\bigr). \]

This is a finite-valued concave function on \(\mathbb R^d\). Indeed, each affine function at a convex combination equals the corresponding convex combination of its values, which is at least the same convex combination of the two minima.

For every \(k\), the first family of constraints says that every affine term evaluated at \(x_k\) is at least \(U_k\); the term indexed by \(k\) equals \(U_k\). Consequently \(u(x_k)=U_k\). The second family therefore gives

\[ u(x_{a_t(j)})-u(x_{b_t(j)})\ge 1>0, \]

so \(u\) strictly rationalizes \(V_t\). This proves the equivalence, including when alternatives recur across agenda items.

Algorithm and running time. Solve this rational linear feasibility problem independently for every listed type, obtaining indicators \(I_t\in\{0,1\}\). Then return

\[ \rho(\mu)=\sum_{t:I_t=1}\mu_t. \]

Each linear program has \(n(d+1)=O(m(d+1))\) variables and \(n^2+m=O(m^2)\) inequalities. Its coefficients are rational coordinate differences or integers. Each coefficient has bit length \(O(L+1)\), so even a dense encoding has total length \(O(m^3(d+1)(L+1))\). Exact rational linear-programming feasibility is polynomial-time decidable. Hence all \(\tau\) tests take \(\tau\,\operatorname{poly}(m,d,L)\) bit operations.

The final sum also has polynomial bit complexity. Write each input mass as \(\mu_t=A_t/B_t\), with positive integer denominator \(B_t\), and use the common denominator

\[ D=\prod_{t\in\operatorname{supp}(\mu)}B_t. \]

Its bit length is \(O(L)\), because the sum of the input denominators’ bit lengths is at most \(L\). The numerator

\[ N=\sum_{t:I_t=1}A_t(D/B_t) \]

satisfies \(0\le N\le D\), since the masses are positive and sum to \(1\). Thus the exact output \(N/D\) has \(O(L)\) bits. Computing these integers takes \(O(\tau L^2)\) bit operations using ordinary integer arithmetic; reducing the fraction, if desired, is also polynomial-time.

The complete running time is therefore \(\tau\,\operatorname{poly}(m,d,L)\). There is no enumeration of the \(2^m\) possible ballot types.

Threshold decision. If \(\alpha=C/E\) with \(E>0\), decide \(\rho(\mu)\ge\alpha\) by the exact integer comparison \(NE\ge CD\). This is polynomial-time as well. Consequently the decision problem belongs to \(\mathrm P\); NP-hardness under polynomial-time many-one reductions would imply \(\mathrm P=\mathrm{NP}\).
