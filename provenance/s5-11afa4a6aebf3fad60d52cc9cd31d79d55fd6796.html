The continuous mirror question, as graded

Let \(T_s\) and \(T_c\) be finite supports of single and couple types, with masses \(\alpha_t\) and \(\beta_u\), where couple types specify both partners' complete descriptions. Given target shares \(p_{t,h}\) and \(r_{u,h}\) over hospitals \(h\in H\), with each share vector summing to \(1\), and per-capita hospital capacities \(q_h\), where \(\sum_{t\in T_s}\alpha_t+2\sum_{u\in T_c}\beta_u=1\), does there exist a measurable assignment of the society realizing those shares and capacities? Each point of single-type mass must be assigned to one hospital; each couple household must be assigned wholly to one hospital, with both partners together. Hospital \(h\) must receive intern mass \(\sum_{t\in T_s}\alpha_t p_{t,h}+2\sum_{u\in T_c}\beta_u r_{u,h}=q_h\).

Packaged proof task (what the prover saw — nothing else)

Let \(H\) be a nonempty set of \(m\) hospitals. A society is given by its support: lists \(T_s\) of single types and \(T_c\) of couple types, each with positive binary rational mass \(\alpha_t\) or \(\beta_u\). Couple types describe both partners; \(\beta_u\) measures households. Set \(\tau=|T_s|+|T_c|\), the support size, not the number of possible types, and require \(\sum_t\alpha_t+2\sum_u\beta_u=1\).
Represent each single type by a separate interval of length \(\alpha_t\), and each couple type by a separate interval of households of length \(\beta_u\), all with Lebesgue measure \(\mu\). Each household point represents two partners who must receive the same hospital.
The input includes nonnegative binary rational shares \(p_{t,h},r_{u,h}\), with \(\sum_h p_{t,h}=\sum_h r_{u,h}=1\), and nonnegative binary rational capacities \(q_h\), with \(\sum_h q_h=1\). Let \(L\) be the total input bit length.
A feasible assignment consists of measurable maps \(a_t:[0,\alpha_t)\to H\) and \(b_u:[0,\beta_u)\to H\), satisfying \(\mu(a_t^{-1}(h))=\alpha_t p_{t,h}\), \(\mu(b_u^{-1}(h))=\beta_u r_{u,h}\), and \(\sum_t\mu(a_t^{-1}(h))+2\sum_u\mu(b_u^{-1}(h))=q_h\) for every hospital. Every single and every household receives exactly one hospital.

Is deciding whether such a feasible assignment exists in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finitely many individual interns with inseparable couples, deciding whether prescribed hospital marginals are a convex combination of deterministic assignments filling every hospital's integer capacity is NP-complete ([Bronfman](https://arxiv.org/pdf/1506.07046v2)). No result settling the exact atomless problem stated here was identified in the literature search.

Modeling choices made when packaging the task

  • Made the continuous society explicitly atomless by representing each type on a separate Lebesgue interval; couple mass counts households, each contributing twice its mass in interns.
  • Specified shares and capacities as nonnegative binary rationals and defined L as the total input bit length.
  • Treated capacities as independently supplied inputs whose equality to assigned intern mass must be satisfied, rather than assuming the displayed capacity equalities as an input promise.
  • Required total capacity to equal normalized intern mass, carrying over full assignment and exact capacity filling.
  • Allowed either type category to be empty and allowed zero hospital capacities; the general hardness domain imposes no singles-dominance or positive-capacity restriction.

Result

The stated atomless problem is in \(\mathrm{P}\). A feasible assignment exists if and only if, for every \(h\in H\),
\(\displaystyle \sum_{t\in T_s}\alpha_t p_{t,h}+2\sum_{u\in T_c}\beta_u r_{u,h}=q_h.\)

These equalities can be checked in time polynomial in \(m,\tau,L\). When they hold, interval partitions give an explicit feasible assignment.

Proof of the feasibility criterion

Necessity. Suppose a feasible assignment exists. The prescribed measures and the capacity equation imply, for each \(h\in H\),
\(\displaystyle q_h=\sum_{t\in T_s}\mu(a_t^{-1}(h))+2\sum_{u\in T_c}\mu(b_u^{-1}(h))=\sum_{t\in T_s}\alpha_t p_{t,h}+2\sum_{u\in T_c}\beta_u r_{u,h}.\)

Thus every stated equality is necessary.

Sufficiency. Suppose all these equalities hold. Enumerate the hospitals as \(H=\{h_1,\ldots,h_m\}\).

For each single type \(t\), define
\(\displaystyle A_{t,0}=0,\qquad A_{t,j}=\alpha_t\sum_{i=1}^{j}p_{t,h_i}\quad(1\leq j\leq m).\)

Nonnegativity of the shares makes these endpoints nondecreasing, and their normalization gives \(A_{t,m}=\alpha_t\). Consequently, the half-open intervals
\(\displaystyle I_{t,j}=[A_{t,j-1},A_{t,j})\)
partition \([0,\alpha_t)\), allowing empty intervals. Define \(a_t(x)=h_j\) for \(x\in I_{t,j}\). This map is measurable because each hospital’s preimage is an interval, and
\(\displaystyle \mu(a_t^{-1}(h_j))=A_{t,j}-A_{t,j-1}=\alpha_t p_{t,h_j}.\)

For each couple type \(u\), similarly define
\(\displaystyle B_{u,0}=0,\qquad B_{u,j}=\beta_u\sum_{i=1}^{j}r_{u,h_i}\quad(1\leq j\leq m),\)
and set \(b_u(x)=h_j\) on \([B_{u,j-1},B_{u,j})\).

These intervals partition \([0,\beta_u)\), so every household receives exactly one hospital. Assigning both partners the value \(b_u(x)\) preserves their inseparability. Moreover,
\(\displaystyle \mu(b_u^{-1}(h_j))=B_{u,j}-B_{u,j-1}=\beta_u r_{u,h_j}.\)

The resulting occupancy of hospital \(h_j\) is therefore
\(\displaystyle \sum_t\mu(a_t^{-1}(h_j))+2\sum_u\mu(b_u^{-1}(h_j))=\sum_t\alpha_t p_{t,h_j}+2\sum_u\beta_u r_{u,h_j}=q_{h_j}.\)

All feasibility conditions hold. This proves sufficiency and completes the characterization.

Polynomial bit complexity

The algorithm computes each hospital’s prescribed occupancy and compares it with its capacity using exact rational arithmetic.

Here is an explicit bound. Fix a hospital \(h\). Each summand is a rational product of two input rationals, with an additional numerator factor \(2\) for couples. There are \(\tau\) summands.

Accumulate these fractions without cancellation. If the current sum is \(A/B\) and the next term is \(n/d\), update it to
\(\displaystyle \frac{Ad+nB}{Bd}.\)

For this fixed hospital, the denominator \(B\) is a product containing each relevant input mass denominator and share denominator at most once. Their total binary encoding length is at most \(L\), so \(B\) has \(O(L)\) bits.

Every partial occupancy sum lies between \(0\) and \(1\): all terms are nonnegative, the shares are at most \(1\), and
\(\displaystyle \sum_t\alpha_t+2\sum_u\beta_u=1.\)
Hence \(0\leq A\leq B\), and the accumulated numerator also has \(O(L)\) bits. The intermediate products in each update have \(O(L)\) bits as well.

Using schoolbook integer arithmetic, each update takes \(O(L^2)\) bit operations. Comparing the final sum with \(q_h\) by cross multiplication has the same bound. Across all hospitals, the decision algorithm therefore takes \(O(m\tau L^2)\) bit operations, which is polynomial in the required parameters.

Why the finite hardness result does not transfer

[Bronfman’s finite formulation](https://arxiv.org/pdf/1506.07046v2), Section 5.3, requires a convex decomposition into deterministic assignments, each of which fills the finite hospital capacities.

In the present formulation, the shares specify measures of subsets of type intervals. A positive household mass can be partitioned among hospitals while every individual household remains intact. The construction above realizes the prescribed shares in a single deterministic measurable assignment and satisfies every aggregate capacity exactly. Thus no finite decomposition theorem is needed.
