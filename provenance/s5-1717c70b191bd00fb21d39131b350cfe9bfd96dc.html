The continuous mirror question, as graded

Given finite seller and buyer value supports \(S\) and \(B\), rational type-mass vectors \(\alpha\) and \(\beta\), and a threshold \(\rho\), compute the seller- and buyer-offering price schedules that maximize their respective expected profits under these masses, using the paper’s tie-breaking convention. With market-type mass \(\alpha_s\beta_b\) for each pair \((s,b)\), compute first-best gains \(\mathrm{OPT}=\sum_{s\in S,b\in B}\alpha_s\beta_b(b-s)^+\) and random-offerer gains \(\mathrm{GFT}_{RO}=(\mathrm{GFT}_{SO}+\mathrm{GFT}_{BO})/2\), then decide whether \(\mathrm{GFT}_{RO}<\rho\,\mathrm{OPT}\).

Packaged proof task (what the prover saw — nothing else)

Consider bilateral trade of one indivisible item, with independent seller and buyer values. The input consists of nonempty finite supports \(S,B\subseteq\mathbb{Q}_{\geq0}\), positive binary-rational masses \(\alpha_s,\beta_b\) satisfying \(\sum_s\alpha_s=\sum_b\beta_b=1\), and a binary-rational threshold \(\rho\in\mathbb{Q}\).
A society is given by its support: the list of its \(\tau\) types with positive mass, each with its mass as a binary rational; \(\tau\) counts supported types, not possible types. Here types include their seller or buyer role, \(\tau=|S|+|B|\), \(m=|S\cup B|\), and \(L\) is the total input bit length. State running times in \(m,\tau,L\).
For each \(s\), the seller-offering price \(p_s\) maximizes \((p-s)\sum_{b\geq p}\beta_b\) over real \(p\geq s\); for each \(b\), the buyer-offering price \(q_b\) maximizes \((b-q)\sum_{s\leq q}\alpha_s\) over real \(0\leq q\leq b\).
Among positive-profit maximizers, choose the largest seller price and the smallest buyer price. If maximum profit is zero, choose no trade. Recipients accept offers at equality.
Let \(T_{SO}(s,b)\) indicate that \(p_s\) is a trade offer and \(b\geq p_s\); let \(T_{BO}(s,b)\) indicate that \(q_b\) is a trade offer and \(s\leq q_b\).
Define \(\mathrm{GFT}_{SO}=\sum_{s,b}\alpha_s\beta_b(b-s)T_{SO}(s,b)\), \(\mathrm{GFT}_{BO}=\sum_{s,b}\alpha_s\beta_b(b-s)T_{BO}(s,b)\), \(\mathrm{GFT}_{RO}=(\mathrm{GFT}_{SO}+\mathrm{GFT}_{BO})/2\), and \(\mathrm{OPT}=\sum_{s,b}\alpha_s\beta_b\max\{b-s,0\}\).

Is deciding whether \(\mathrm{GFT}_{RO}<\rho\,\mathrm{OPT}\), with the offering schedules defined above, in \(\mathrm{P}\) or \(\mathrm{NP}\)-hard?

Finite discrete distributions are known for which \(\mathrm{GFT}_{RO}<0.495\,\mathrm{OPT}\); this is a performance counterexample, not a computational hardness result. [Babaioff–Dobzinski–Kupfer](https://arxiv.org/pdf/2111.07790)
An extension of that counterexample to continuous value distributions is stated, but no complexity classification of this rational-support threshold problem is supplied there. [Babaioff–Dobzinski–Kupfer](https://arxiv.org/pdf/2111.07790)

Classification

The decision problem is in \(\mathrm{P}\). An exact algorithm runs in \(O(\tau m L^2)\) bit operations using elementary integer arithmetic.

The proof accounts for optimization over real prices, the specified tie rules, and strict comparison at the threshold.

1. Positive-profit optimal prices belong to the opposing support

Write \(n=|S|\) and \(k=|B|\), so \(\tau=n+k\). Sort the supports as \(s_1<\cdots<s_n\) and \(b_1<\cdots<b_k\).

Seller offers. Fix a seller value \(s\), and consider any feasible real price \(p\geq s\) with positive profit. Its acceptance probability is positive, so there exists a smallest supported buyer value \(b_j\geq p\). By its definition,

\(\displaystyle \sum_{b\geq p}\beta_b=\sum_{b\geq b_j}\beta_b.\)

Consequently,

\(\displaystyle (b_j-s)\sum_{b\geq b_j}\beta_b\geq(p-s)\sum_{b\geq p}\beta_b,\)

with strict inequality if \(b_j>p\). Thus every positive-profit maximizer belongs to \(B\), and the maximum can be found by examining the finite set \(B\cap[s,\infty)\).

If no candidate has positive profit, no real price has positive profit either. The maximum is then zero, since \(p=s\) yields zero profit, and the rule prescribes no trade.

Buyer offers. Fix a buyer value \(b\), and consider any feasible real price \(q\in[0,b]\) with positive profit. There exists a largest supported seller value \(s_i\leq q\), and

\(\displaystyle \sum_{s\leq q}\alpha_s=\sum_{s\leq s_i}\alpha_s.\)

Therefore,

\(\displaystyle (b-s_i)\sum_{s\leq s_i}\alpha_s\geq(b-q)\sum_{s\leq q}\alpha_s,\)

with strict inequality if \(s_i<q\). Every positive-profit maximizer therefore belongs to \(S\), and it suffices to examine \(S\cap[0,b]\).

Again, if no candidate has positive profit, the maximum over all feasible real prices is zero: \(q=b\) yields zero profit. The prescribed outcome is no trade.

These arguments establish both the existence of the required maxima and the finite candidate sets.

2. Exact computation of the offering schedules

Precompute the buyer suffix masses and seller prefix masses:

\(\displaystyle H_j=\sum_{\ell=j}^{k}\beta_{b_\ell},\qquad F_i=\sum_{\ell=1}^{i}\alpha_{s_\ell}.\)

For each seller \(s\), evaluate \((b_j-s)H_j\) for every \(b_j\geq s\). Initialize the best profit to zero and the offer to “no trade.” Scan candidates in decreasing price order and update only upon a strict improvement. This selects the largest positive-profit maximizing seller price.

For each buyer \(b\), evaluate \((b-s_i)F_i\) for every \(s_i\leq b\). Use the same initialization, scan candidates in increasing price order, and update only upon a strict improvement. This selects the smallest positive-profit maximizing buyer price.

Equality is tested exactly. Thus the procedure implements all specified tie and no-trade rules.

Computing the prefix and suffix masses takes \(O(\tau)\) arithmetic operations. Computing both schedules takes \(O(nk)\) arithmetic operations.

3. Exact gains and threshold comparison

Once the schedules are known, iterate over all \(nk\) supported pairs. For each pair, determine the two acceptance indicators using the non-strict comparisons specified in the question. Accumulate the three gains expressions from their definitions.

To prove that this computation has polynomial bit complexity, clear denominators explicitly.

Write every input rational as an integer numerator divided by a positive integer denominator, both encoded in binary. This argument also covers the special case of dyadic rational inputs.

Let:

  • \(D\) be the product of all support-value denominators;
  • \(A\) be the product of all seller-mass denominators;
  • \(C\) be the product of all buyer-mass denominators.

Define the nonnegative integers \(x_s=Ds\), \(x_b=Db\), \(a_s=A\alpha_s\), and \(c_b=C\beta_b\). Normalization gives

\(\displaystyle \sum_s a_s=A,\qquad \sum_b c_b=C.\)

The seller candidate profits have the common positive denominator \(DC\), so they can be compared using the integer numerators

\(\displaystyle (x_{b_j}-x_s)\sum_{\ell=j}^{k}c_{b_\ell}.\)

Similarly, buyer candidate profits have common denominator \(DA\), and their integer numerators are

\(\displaystyle (x_b-x_{s_i})\sum_{\ell=1}^{i}a_{s_\ell}.\)

Thus every schedule comparison, including every tie, reduces to an integer comparison.

Define

\(\displaystyle N_{\mathrm{SO}}=\sum_{s,b}a_sc_b(x_b-x_s)T_{\mathrm{SO}}(s,b),\)

\(\displaystyle N_{\mathrm{BO}}=\sum_{s,b}a_sc_b(x_b-x_s)T_{\mathrm{BO}}(s,b),\)

\(\displaystyle N_{\mathrm{OPT}}=\sum_{s,b}a_sc_b\max\{x_b-x_s,0\}.\)

Every seller trade satisfies \(b\geq p_s>s\), and every buyer trade satisfies \(s\leq q_b<b\), because the selected offers have positive profit. Hence all summands in these three numerators are nonnegative.

Their relation to the requested gains is

\(\displaystyle \mathrm{GFT}_{\mathrm{SO}}=\frac{N_{\mathrm{SO}}}{DAC},\qquad \mathrm{GFT}_{\mathrm{BO}}=\frac{N_{\mathrm{BO}}}{DAC},\qquad \mathrm{OPT}=\frac{N_{\mathrm{OPT}}}{DAC}.\)

Write the threshold as \(\rho=r/t\), where \(r\) is an integer and \(t\) is a positive integer. The required decision is exactly the integer comparison

\(\displaystyle t(N_{\mathrm{SO}}+N_{\mathrm{BO}})<2rN_{\mathrm{OPT}}.\)

No division or numerical approximation is needed. This remains valid for negative thresholds. If \(\mathrm{OPT}=0\), there is no supported pair with \(b>s\); both mechanisms prescribe no trade, and the strict inequality is false.

4. Bit complexity

Because \(L\) is the total binary input length, each product \(D,A,C\) has \(O(L)\) bits: the logarithm of a product is the sum of the logarithms of its factors. The scaled values \(x_s,x_b\) and masses \(a_s,c_b\) likewise have \(O(L)\) bits.

Let \(X=\max\{x_v:v\in S\cup B\}\). Each nonnegative gains numerator is at most

\(\displaystyle \sum_{s,b}a_sc_bX=ACX.\)

Thus the gains numerators, their running partial sums, the candidate-profit numerators, and both sides of the final threshold comparison all have \(O(L)\) bits.

Elementary integer addition, comparison, multiplication, and division on integers of this size take at most \(O(L^2)\) bit operations. Constructing the common denominators and scaled integers takes \(O(\tau L^2)\) bit operations. Sorting, computing the schedules, and accumulating the gains therefore give the total bound

\(\displaystyle O\bigl((\tau\log\tau+nk+\tau)L^2\bigr).\)

Both supports are subsets of their union, so \(n,k\leq m\), and hence \(nk\leq\tau m\). Also \(m\leq\tau\leq2m\), which implies \(\log\tau=O(m)\). The bound consequently simplifies to

\(\displaystyle O(\tau m L^2).\)

Since the input explicitly lists all supported types, \(\tau\) and \(m\) are bounded by the input length. This is polynomial time.

5. Consequence

The rational-support threshold problem is therefore in \(\mathrm{P}\); it could be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).

The cited paper’s finite-distribution \(0.495\) counterexample concerns the mechanism’s performance ratio. It does not obstruct exact polynomial-time evaluation on explicitly listed finite supports. [Babaioff–Dobzinski–Kupfer, Theorem 1.1](https://arxiv.org/pdf/2111.07790)
