Packaged proof task (what the prover saw — nothing else)

Let \(A,B\) be nonempty finite sets of firm and worker types. A society is given by its support: the list of its \(\tau=|A|+|B|\) types with positive masses \(r_a,s_b\), each a binary rational; \(\tau\) counts supported types, not possible types. Masses need not sum to one or have equal totals. Match surpluses \(\alpha_{ab}\) are nonnegative binary rationals.
A mass matching has rational entries \(x_{ab}\geq0\), with \(\sum_bx_{ab}\leq r_a\), \(\sum_ax_{ab}\leq s_b\), and \(x_{ab}=0\) whenever \(\alpha_{ab}=0\). Its surplus is \(\sum_{a,b}\alpha_{ab}x_{ab}\).
Supporting core payoffs are nonnegative rational payoffs per unit of type mass, \(u_a,v_b\), satisfying \(u_a+v_b\geq\alpha_{ab}\) for every pair, with equality whenever \(x_{ab}>0\). Unmatched mass receives zero: \(u_a(r_a-\sum_bx_{ab})=0\) and \(v_b(s_b-\sum_ax_{ab})=0\).
Can a maximum-surplus mass matching and supporting core payoffs be computed in polynomial time in \(|A|,|B|,\tau,L\), where \(L\) is the total input bit length, or is this computation NP-hard?
For finite agents, the unperturbed aspiration-adjustment process reaches a core outcome almost surely in finite time; its absorbing states have zero aspirations for unmatched agents, and every absorbing state is reachable from zero aspirations. This gives no polynomial-time bound.
For balanced mass markets requiring everyone to match, [Galichon](https://alfredgalichon.com/wp-content/uploads/2020/08/2020-08-17_Galichon_WorldCongress.pdf) presents an optimal-transport characterization of transferable-utility equilibrium; this is a neighboring formulation with equality capacities.

Result

A maximum-surplus mass matching and supporting core payoffs can be computed exactly in polynomial time in \(|A|,|B|,\tau,L\). The proof uses a rational linear program and its dual. Neither equal total masses nor normalization is needed.

1. The matching linear program

Define the set of permitted pairs by \(E=\{(a,b)\in A\times B:\alpha_{ab}>0\}\). Introduce a variable \(x_{ab}\) only for pairs in \(E\), and set all other matching entries to zero.

Consider the linear program with objective

\(\displaystyle \operatorname{maximize}\quad P(x)=\sum_{(a,b)\in E}\alpha_{ab}x_{ab},\)

subject to

\(\displaystyle \sum_{b:(a,b)\in E}x_{ab}\leq r_a\quad(a\in A),\)

\(\displaystyle \sum_{a:(a,b)\in E}x_{ab}\leq s_b\quad(b\in B),\)

and \(x_{ab}\geq0\) for every \((a,b)\in E\). Empty sums are zero.

These are exactly the matching constraints in the question. The feasible set is nonempty because the zero matching is feasible. It is closed and bounded: every variable satisfies \(0\leq x_{ab}\leq\min(r_a,s_b)\). Consequently, its continuous linear objective attains a finite maximum.

If \(E\) is empty, the zero matching and zero payoffs solve the problem. Henceforth assume \(E\) is nonempty.

2. The dual linear program

The dual has one variable \(u_a\) for each firm capacity constraint and one variable \(v_b\) for each worker capacity constraint. It is

\(\displaystyle \operatorname{minimize}\quad D(u,v)=\sum_{a\in A}r_au_a+\sum_{b\in B}s_bv_b,\)

subject to \(u_a,v_b\geq0\) and

\(\displaystyle u_a+v_b\geq\alpha_{ab}\quad((a,b)\in E).\)

To verify the dual, each primal variable \(x_{ab}\) has coefficient one in precisely the capacity rows indexed by \(a\) and \(b\). Its dual constraint is therefore \(u_a+v_b\geq\alpha_{ab}\). Because the primal is a maximization problem with upper capacity inequalities, its dual variables are nonnegative.

For pairs outside \(E\), the required inequality is also satisfied: \(\alpha_{ab}=0\) and both payoffs are nonnegative.

The dual is feasible. Indeed, let \(M=\max_{a,b}\alpha_{ab}\); setting \(u_a=M\) for every firm type and \(v_b=0\) for every worker type satisfies every constraint.

We use linear-programming strong duality: a feasible linear program with a finite optimal value has an optimal dual solution, and their optimal values coincide. The preceding section verifies feasibility and finiteness for the primal. Thus optimal solutions \(x^*\) and \((u^*,v^*)\) exist and satisfy \(P(x^*)=D(u^*,v^*)\).

3. Optimal dual solutions are supporting core payoffs

For any primal-feasible \(x\) and dual-feasible \((u,v)\), define the unmatched masses and payoff slacks by

\(\displaystyle \rho_a=r_a-\sum_{b:(a,b)\in E}x_{ab},\qquad \sigma_b=s_b-\sum_{a:(a,b)\in E}x_{ab},\qquad \gamma_{ab}=u_a+v_b-\alpha_{ab}.\)

All these quantities are nonnegative. Substituting the definitions of unmatched masses into the dual objective gives

\(\displaystyle D(u,v)=\sum_a u_a\rho_a+\sum_b v_b\sigma_b+\sum_{(a,b)\in E}(u_a+v_b)x_{ab}.\)

Subtracting the primal objective yields the exact identity

\(\displaystyle D(u,v)-P(x)=\sum_a u_a\rho_a+\sum_b v_b\sigma_b+\sum_{(a,b)\in E}\gamma_{ab}x_{ab}.\)

Every summand on the right is nonnegative. For optimal primal and dual solutions, strong duality makes the left side zero. A finite sum of nonnegative terms equals zero only if every term equals zero. Therefore:

  • \(u_a^*\rho_a^*=0\) for every firm type;
  • \(v_b^*\sigma_b^*=0\) for every worker type;
  • if \(x_{ab}^*>0\), then \(\gamma_{ab}^*=0\), so \(u_a^*+v_b^*=\alpha_{ab}\).

Together with dual feasibility and nonnegativity, these are precisely all the supporting-core conditions in the question. In particular, a type with any positive unmatched mass receives zero payoff per unit.

The identity also proves the converse. If a feasible matching has supporting core payoffs, every term on its right vanishes. Hence its surplus equals a feasible dual objective. Weak duality bounds every feasible matching’s surplus by that dual objective, so the supported matching is maximum-surplus.

4. Exact polynomial-time computation

We use the standard polynomial-time theorem for rational linear programming: given explicitly encoded rational coefficients, feasibility and boundedness can be decided and, when a finite optimum exists, an exact rational optimal solution can be computed in time polynomial in the dimensions and total binary encoding length. This is a bit-complexity result, not merely a bound on arithmetic operations. See [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/php/archive.phtml?jrnid=zvmmf&option_lang=eng&paperid=5239&wshow=paper).

Its hypotheses hold here:

  • The primal has \(|E|\leq|A||B|\) variables and \(\tau=|A|+|B|\) capacity inequalities, besides nonnegativity.
  • The dual has \(\tau\) variables and \(|E|\) pair inequalities, besides nonnegativity.
  • Every coefficient is an input rational or one of \(0,1\). Even writing the constraint matrices densely requires only polynomial encoding length in \(|A|,|B|,\tau,L\).
  • Both programs are feasible and have finite, attained optimal values, as proved above.

Solve both programs exactly, then fill in zero matching entries outside \(E\). Section 3 proves that these independently computed optimal solutions form the requested matching and supporting core payoffs. The rational outputs have polynomial encoding length as part of the rational linear-programming theorem.

Crucially, this computation uses one capacity per supported type. It does not expand rational masses into individual agents or perform a number of iterations proportional to their numerical magnitudes.

5. Relation to the supplied formulations

[Galichon’s presentation, slides 6 and 10](https://alfredgalichon.com/wp-content/uploads/2020/08/2020-08-17_Galichon_WorldCongress.pdf), gives the primal–dual optimal-transport characterization with equality marginals. Here, upper capacity inequalities produce nonnegative dual payoffs, while complementary slackness forces zero payoffs for unmatched mass. The argument above proves this directly for the stated unequal-mass setting.

The aspiration-adjustment process’s convergence properties are not needed for this algorithm. This proof establishes polynomial-time computation by linear programming; it establishes no polynomial convergence bound for that process.
