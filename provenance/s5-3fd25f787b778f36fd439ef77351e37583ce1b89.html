The continuous mirror question, as graded

Given finite left and right type sets with rational masses, compatible type pairs, strict rankings of opposite-side types, and type-pair costs, represent each type by an atomless population and unmatched status as its last choice. Find a minimum-cost measurable matching \(\pi\) such that every measurable challenger \(\sigma\) on the same agents satisfies \(\Phi(\sigma,\pi) \le 2\Phi(\pi,\sigma)\), where \(\Phi\) counts the mass on both sides that prefers the first matching and ties abstain; report infeasibility if none exists.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) and \(B\) be disjoint, nonempty finite type sets, with compatible pairs \(E\subseteq A\times B\), and put \(m=|E|\). Each type strictly ranks its compatible opposite-side types; all agents of a type share this ranking and are indifferent between partners of the same type. Unmatched status is strictly last.
A society is given by its support: the list of the \(\tau=|A|+|B|\) types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types. Masses sum to \(1\) across both sides; the sides need not have equal mass. Let \(L\) be the total input bit length.
Represent each type \(t\) by a disjoint interval of Lebesgue measure \(\mu_t\). A matching \(\pi\) is a measurable, measure-preserving bijection between measurable subsets of the left and right populations, using only compatible type pairs; agents outside these subsets are unmatched. Matchings are identified up to null sets.
For binary rational costs \(c_{ab}\in\mathbb{Q}\), let \(x_{ab}(\pi)\) be the mass paired between types \(a\) and \(b\), and define \(C(\pi)=\sum_{(a,b)\in E}c_{ab}x_{ab}(\pi)\); unmatched agents incur zero cost and each pair is counted once.
Let \(\Phi(\sigma,\pi)\) be the total mass on both sides strictly preferring its assignment in \(\sigma\) to its assignment in \(\pi\), with ties abstaining. Call \(\pi\) quasi-popular if \(\Phi(\sigma,\pi)\leq 2\Phi(\pi,\sigma)\) for every measurable matching \(\sigma\) on the same agents.

Is computing a minimum-cost quasi-popular matching, with infeasibility reported when none exists, solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents with strict preferences, minimum-cost quasi-popular matching is NP-hard, even with costs in \(\{0,1\}\), and admits no polynomial-time approximation within any multiplicative factor unless \(\mathrm{P}=\mathrm{NP}\). A polynomial-time algorithm does produce a quasi-popular matching costing at most a minimum-cost popular fractional matching. [Faenza–Kavitha](https://arxiv.org/pdf/1904.05974)
No result settling this exact atomless, same-agent challenger problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total mass across both sides to one, without requiring equal side masses.
  • Made measurable matching precise as a partial measure-preserving bijection between disjoint type intervals, modulo null sets.
  • Interpreted strict rankings as rankings of compatible types only, with indifference among individual partners of the same type.
  • Used signed binary rational costs, reflecting the general real-valued cost domain of the discrete optimization problem.
  • Defined cost by paired mass, counted once per pair, with zero cost for unmatched agents.
  • Defined m as the number of compatible type pairs and L as the total input bit length.

Result

The problem is \(\mathrm{NP}\text{-hard}\), already when all positive type masses are equal dyadic rationals and all costs belong to \(\{0,1\}\).

The essential point is that an atomless quasi-popular matching cannot gain an advantage by splitting types: every finite matching appearing with positive weight in its type-pair decomposition must itself be quasi-popular. This follows by constructing a challenger on the same agents that changes only one component.

1. Finite matchings and their decomposition

For a bipartite graph \(G=(A\cup B,E)\), define

\( P(G)=\left\{y\in\mathbb R_{\geq 0}^{E}: \sum_{e\ni t}y_e\leq 1\text{ for every }t\in A\cup B\right\}. \)

Every element of \(P(G)\) is a convex combination of incidence vectors of ordinary matchings. Here is a proof of the integrality needed for this statement.

Suppose a vertex \(y\) has fractional coordinates, and consider the graph consisting of edges satisfying \(0<y_e<1\).

If this graph contains a cycle, the cycle has even length because \(G\) is bipartite. Alternately adding and subtracting a sufficiently small positive quantity around the cycle preserves all vertex sums and nonnegativity. Both signs of the perturbation are feasible, contradicting extremality.

Otherwise, a component containing an edge is a tree. Choose a path between two leaves of that component and perturb its edges with alternating signs. Internal vertex sums remain unchanged. Each endpoint has precisely one incident fractional edge and cannot have an incident edge of value \(1\), because its total incident value is at most \(1\). Consequently, its constraint has positive slack. A sufficiently small perturbation is feasible in both directions, again contradicting extremality.

Thus every vertex of \(P(G)\) is integral and represents a matching. Since \(P(G)\) is a bounded polytope, every \(y\in P(G)\) admits a finite decomposition

\( y=\sum_{i=1}^{k}\lambda_i\chi^{M_i}, \qquad \lambda_i>0,\qquad \sum_{i=1}^{k}\lambda_i=1, \)

where each \(M_i\) is an ordinary matching.

2. Votes and equal-mass societies

Write \(\bot\) for unmatched status. For type \(t\), define the score of a new assignment \(r\) relative to an old assignment \(s\) by

\( v_t(r,s)= \begin{cases} 1,&r\succ_t s,\\ -2,&s\succ_t r,\\ 0,&r=s. \end{cases} \)

The arguments are compatible partner types or \(\bot\). Thus agents assigned to different partners of the same type receive score \(0\), as required.

For ordinary finite matchings \(N,M\), put

\( D_F(N,M)=\sum_{t\in A\cup B}v_t(N(t),M(t)). \)

Then \(M\) is quasi-popular precisely when \(D_F(N,M)\leq 0\) for every finite matching \(N\).

For measurable matchings, put

\( D_C(\sigma,\pi)=\Phi(\sigma,\pi)-2\Phi(\pi,\sigma). \)

This is the integral of the corresponding agent scores, so \(\pi\) is quasi-popular precisely when every challenger has nonpositive score.

Now suppose there are \(n\) types, each of mass \(h=1/n\). For any measurable matching \(\pi\), define

\( y_e=\frac{x_e(\pi)}{h}. \)

The mass constraints imply \(y\in P(G)\). Fix a decomposition

\( y=\sum_{i=1}^{k}\lambda_i\chi^{M_i}. \)

We will show that quasi-popularity of \(\pi\) forces quasi-popularity of every \(M_i\).

3. A challenger can isolate one decomposition component

Lemma. If \(\pi\) is quasi-popular in the equal-mass society, then every \(M_i\) in the decomposition above is quasi-popular in the finite instance.

Proof. We first partition the actual agents into components indexed by \(i\), retaining every incumbent pair within its component.

For an edge \(e=(a,b)\), let \(P_e\) be the measurable set of left agents that \(\pi\) pairs along \(e\). Its measure is

\( x_e(\pi)=h\sum_{i:e\in M_i}\lambda_i. \)

Partition \(P_e\) into measurable sets \(P_{e,i}\), one for each \(i\) with \(e\in M_i\), of measures \(h\lambda_i\). Label the corresponding right agents \(\pi(P_{e,i})\) with the same index.

These partitions exist by atomlessness. Images under \(\pi\) have the same measures because \(\pi\) is measure-preserving; all statements are understood modulo null sets.

For each type \(t\), its unmatched mass under \(\pi\) is

\( h-\sum_{e\ni t}x_e(\pi) = h\sum_{i:M_i(t)=\bot}\lambda_i. \)

Partition those unmatched agents into pieces of measure \(h\lambda_i\), indexed by components in which \(t\) is unmatched.

Let \(S_{t,i}\) denote the agents of type \(t\) labelled \(i\). The construction has three properties:

  • Each \(S_{t,i}\) has measure \(h\lambda_i\).
  • Every agent in \(S_{t,i}\) has incumbent assignment type \(M_i(t)\), including \(\bot\).
  • Every incumbent pair joins agents with the same index \(i\).

The required measurable partitions and pairings use elementary properties of Lebesgue spaces. In particular, measurable sets of equal positive measure admit measure-preserving bijections modulo null sets: the cumulative-measure map identifies each such set with an interval of that measure, and its generalized inverse supplies the inverse identification.

Suppose \(M_i\) were not quasi-popular. There would be a finite matching \(N\) with

\( D_F(N,M_i)>0. \)

Construct \(\sigma\) as follows. On the agents labelled \(i\), implement \(N\): for each \((a,b)\in N\), match \(S_{a,i}\) bijectively and measure-preservingly to \(S_{b,i}\). Leave \(S_{t,i}\) unmatched whenever \(N(t)=\bot\). On all other agents retain \(\pi\).

This is a valid matching on the same agents. Equal measures permit all the new pairings, compatibility follows from \(N\), and property 3 ensures that retaining \(\pi\) outside component \(i\) creates no conflicts.

Outside component \(i\), all agents abstain. Inside it, the agents of each type have mass \(h\lambda_i\) and compare exactly \(N(t)\) with \(M_i(t)\). Hence

\( D_C(\sigma,\pi) = h\lambda_iD_F(N,M_i)>0, \)

contradicting quasi-popularity of \(\pi\). Therefore every \(M_i\) is quasi-popular. \(\square\)

4. Finite quasi-popular matchings remain quasi-popular after lifting

The reverse direction requires checking all measurable challengers, including those that split types.

Let \(M\) be a finite quasi-popular matching. Lift it to a measurable matching \(\pi_M\) by pairing the entire type intervals along the edges of \(M\). Every agent of type \(t\) then has incumbent assignment type \(M(t)\).

For an arbitrary measurable challenger \(\sigma\), put

\( z_e=\frac{x_e(\sigma)}{h}. \)

Again \(z\in P(G)\). Define the affine function

\( Q_M(z)= \sum_{(a,b)\in E}z_{ab} \bigl[v_a(b,M(a))+v_b(a,M(b))\bigr] + \sum_{t\in A\cup B} \left(1-\sum_{e\ni t}z_e\right)v_t(\bot,M(t)). \)

The edge terms count the scores of matched agents, and the remaining terms count unmatched agents. Since the incumbent assignment is constant within each type,

\( D_C(\sigma,\pi_M)=hQ_M(z). \)

For any finite matching \(N\),

\( Q_M(\chi^N)=D_F(N,M). \)

Decompose \(z=\sum_j\beta_j\chi^{N_j}\). Affineness and \(\sum_j\beta_j=1\) give

\( D_C(\sigma,\pi_M) = h\sum_j\beta_jD_F(N_j,M) \leq 0, \)

because \(M\) is finite quasi-popular. Thus \(\pi_M\) is quasi-popular against every measurable same-agent challenger.

5. Equality of optimal costs

Write

\( c(M)=\sum_{e\in M}c_e \)

for finite matching cost. For an arbitrary atomless quasi-popular matching \(\pi\), Section 3 shows that every component of its decomposition is finite quasi-popular. Moreover,

\( C(\pi) = h\sum_i\lambda_i c(M_i). \)

Consequently, if \(\operatorname{OPT}_F\) is the minimum finite quasi-popular cost,

\( C(\pi)\geq h\operatorname{OPT}_F. \)

Conversely, Section 4 lifts any finite optimal quasi-popular matching to an atomless quasi-popular matching of cost \(h\operatorname{OPT}_F\). Therefore

\( \boxed{\operatorname{OPT}_C=h\operatorname{OPT}_F.} \)

Existence is equivalent as well: a finite quasi-popular matching lifts to an atomless one, while an atomless one supplies a finite quasi-popular component. Whenever feasible, the atomless minimum is attained by a lifted finite matching.

6. Polynomial reduction and hardness

The finite hardness result supplies strict bipartite instances with costs in \(\{0,1\}\) for which deciding whether a zero-cost quasi-popular matching exists is \(\mathrm{NP}\text{-hard}\). This zero-cost formulation follows explicitly from Theorem 13 and Lemma 8 in Section 5 of [Faenza–Kavitha](https://arxiv.org/pdf/1904.05974).

Take such an instance with \(n\) vertices. Let

\( N=2^{\lceil\log_2 n\rceil}. \)

Add \(N-n\) isolated vertices, placing them on either side. Isolated vertices remain unmatched in every matching and never vote, so this padding preserves quasi-popularity and cost.

Make each of the resulting \(N\) vertices a distinct positive-mass type, with mass

\( \mu_t=\frac1N. \)

Copy the compatibility graph, strict preferences, and costs.

This construction satisfies all input requirements:

  • The total mass is \(N/N=1\).
  • Every mass is a positive dyadic rational.
  • The support size is \(\tau=N<2n\).
  • The number of compatible pairs is unchanged.
  • Each mass needs only \(O(\log n)\) bits, so the construction has polynomial total encoding length.

By Section 5, its optimal atomless cost is exactly \(1/N\) times the padded finite optimum. In particular,

\( \operatorname{OPT}_C=0 \quad\Longleftrightarrow\quad \operatorname{OPT}_F=0. \)

Thus even deciding whether an atomless zero-cost quasi-popular matching exists is \(\mathrm{NP}\text{-hard}\). Computing a minimum-cost quasi-popular matching, with infeasibility reporting, is therefore \(\mathrm{NP}\text{-hard}\) and cannot be polynomial-time solvable in \(m,\tau,L\) unless \(\mathrm P=\mathrm{NP}\).

The same zero-cost reduction also excludes a polynomial-time approximation with any finite multiplicative guarantee unless \(\mathrm P=\mathrm{NP}\): on a zero-optimum instance such a guarantee requires returning cost exactly zero.

1. Integrality and decomposition

The polytope in Section 1 is the appropriate bipartite matching polytope, including matchings that leave vertices unmatched.

The extremality argument is correct:

  • On an even cycle of fractional edges, alternating perturbations preserve every incident sum. A sufficiently small perturbation preserves nonnegativity in both directions.
  • If the fractional-edge graph is acyclic, a component containing an edge has two leaves. Along their connecting path, alternating perturbations preserve internal incident sums.
  • At either endpoint, the unique fractional edge has value strictly below \(1\). Every other incident coordinate is either \(0\) or \(1\), and a coordinate equal to \(1\) would violate the capacity constraint. Thus the endpoint constraint has strictly positive slack, permitting both perturbation directions.

Consequently, no vertex has fractional coordinates. Integral feasible points are precisely matching incidence vectors. The polytope is bounded because every edge coordinate lies between \(0\) and \(1\), so the stated finite convex decomposition follows.

The argument also covers an edgeless graph: its unique feasible vector represents the empty matching.

2. Vote scores and normalization

The score definition correctly represents the required inequality. A strict improvement contributes \(1\), a strict deterioration contributes \(-2\), and indifference contributes \(0\). Hence

\[ D_C(\sigma,\pi)=\Phi(\sigma,\pi)-2\Phi(\pi,\sigma). \]

Here and below, the displayed identities are understood using the task’s mathematical notation; equivalently, \(D_C(\sigma,\pi)=\Phi(\sigma,\pi)-2\Phi(\pi,\sigma)\).

The finite score uses one voter per vertex, exactly as required by the finite source problem. Assignment symbols denote partner types, so changing partners within the same type correctly produces abstention.

For equal type mass \(h\), the normalization \(y_e=x_e(\pi)/h\) satisfies each type’s capacity constraint. This does not require the two sides to have equal total mass.

\(x_e(\pi)=h\sum_{i:e\in M_i}\lambda_i\).

The unmatched-mass identity is also correct:

\(h-\sum_{e\ni t}x_e(\pi)=h\sum_{i:M_i(t)=\bot}\lambda_i\).

For each component and type, precisely one of two cases applies: the finite matching assigns that type one incident edge, or leaves it unmatched. Consequently, the construction gives each \(S_{t,i}\) mass \(h\lambda_i\) and constant incumbent assignment type \(M_i(t)\).

The measure-theoretic operations are legitimate on Lebesgue spaces modulo null sets. Atomlessness supplies the finite partitions. Equal-measure measurable subsets admit measure-preserving measurable bijections modulo null sets; the cumulative-measure identification cited in the proof supplies this standard fact.

  • Both endpoint scores for each matched mass.
  • The unmatched score for each type’s remaining mass.

There is no double counting: an edge contributes one score for each side, as required by \(\Phi\). In particular, \(D_C(\sigma,\pi_M)=hQ_M(z)\).

For a matching incidence vector, \(Q_M(\chi^N)=D_F(N,M)\). Its affine constant is handled correctly because the decomposition weights sum to \(1\). Every summand is nonpositive by finite quasi-popularity, so every measurable challenger has nonpositive score.

This establishes quasi-popularity against challengers that split types as well as those that do not.
