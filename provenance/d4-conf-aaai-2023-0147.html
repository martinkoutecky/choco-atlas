Packaged proof task (what the prover saw — nothing else)

Given a finite argumentation framework \(\Lambda=(A,\Omega)\), put \(m=|A|\), and let \(\operatorname{pr}(\Lambda)\) denote its Dung preferred extensions. The proposed set is \(S\subseteq A\).
A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Each type explicitly supplies a finite conditional-preference base \(\Gamma_t\); let \(L\) be the total input bit length. State running times in \(m,\tau,L\).
A rule is \(a>b\leftarrow\bigwedge_{p\in P}p\wedge\bigwedge_{n\in N}\neg n\), where all arguments appearing in the rule are distinct and belong to \(A\); either body set may be empty. Each \(\Gamma_t\) is well-formed: some \(\phi_t:A\to\mathbb N\) assigns equal values to the two head arguments of every rule and a different value to every argument in its body. Empty bases are allowed.
For an extension \(E\), define \(E^+=\{b\in A:\exists a\in E\;(a,b)\in\Omega\}\). A rule body is satisfied by \(E\) precisely when \(P\subseteq E\) and \(N\subseteq E^+\).
For distinct preferred extensions \(E,F\), define \(E\succeq_{k,t}F\) iff no rule \(a>b\leftarrow\mathrm{body}\) in \(\Gamma_t\) has \(a\in F\setminus E\), \(b\in E\setminus F\), and its body satisfied by both extensions. Define \(E\succ_{k,t}F\) iff \(E\succeq_{k,t}F\) and \(F\not\succeq_{k,t}E\); no transitive closure of rules is taken.
Put \(w_\mu(E,F)=\sum_{t:E\succ_{k,t}F}\mu_t\) and \(E\succ_\mu F\) iff \(w_\mu(E,F)>w_\mu(F,E)\). Ties and incomparisons abstain; identical extensions never strictly beat themselves.
The decision problem asks whether \(S\in\operatorname{pr}(\Lambda)\) and there is no \(F\in\operatorname{pr}(\Lambda)\) with \(F\succ_\mu S\).

Is this decision problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For a single conditional-preference base, verification of an unbeaten preferred extension under flat KTV is \(\Pi_2^p\)-complete; comparison of two extensions is polynomial-time ([source](https://ceur-ws.org/Vol-3464/short1.pdf)).
No result for exactly the support-encoded rational-mass majority problem was located in the literature search.

Result

The decision problem is \(\Pi_2^p\)-complete under polynomial-time many-one reductions, already when \(\tau=1\) and the unique mass is \(1\). Consequently, it is \(\mathrm{NP}\)-hard and cannot be solved in polynomial time unless \(\mathrm{P}=\mathrm{NP}\).

The hardness proof uses the single-base completeness theorem supplied in the question. The upper bound is proved below directly for the support-encoded rational-mass problem.

1. Polynomial-time comparison

For a type \(t\) and distinct sets \(E,F\), define \(H_t(E,F)\) to mean that some rule in \(\Gamma_t\) has its preferred head argument in \(E\setminus F\), its other head argument in \(F\setminus E\), and its body satisfied by both sets.

The definitions give

\(E\succeq_{k,t}F\iff\neg H_t(F,E)\),

and therefore

\(E\succ_{k,t}F\iff H_t(E,F)\wedge\neg H_t(F,E)\).

Compute \(E^+\) and \(F^+\) by scanning the attack relation, taking \(O(m^2)\) time. Then scan every explicitly supplied rule, checking its head memberships and all body literals. The total rule-scanning time is \(O(L)\).

The masses can also be compared exactly in polynomial time. Write \(\mu_t=p_t/q_t\), and set \(D=\prod_{t\in T}q_t\). Its binary length is \(O(L)\). Define the integer weight \(c_t=p_t(D/q_t)\). Then

\(w_\mu(E,F)>w_\mu(F,E)\iff \sum_{t:E\succ_{k,t}F}c_t> \sum_{t:F\succ_{k,t}E}c_t\).

Using elementary integer arithmetic, all \(c_t\) can be computed in \(O(\tau L^2)\) time. Thereafter, a comparison takes \(O(m^2+L+\tau L)\) time. Thus a conservative bound including preprocessing is \(O(m^2+L+\tau L^2)\).

For the upper-bound argument, extend this polynomial comparison procedure to arbitrary subsets, and define \(B(E,F)\) to be its strict-majority outcome, with \(B(E,E)\) false. On distinct preferred extensions, \(B\) agrees exactly with \(\succ_\mu\).

2. Membership in \(\Pi_2^p\)

A set \(X\subseteq A\) is admissible if it is conflict-free and defends each of its members: for every \(x\in X\) and every attacker \(y\) of \(x\), some \(z\in X\) attacks \(y\). Write \(\operatorname{Adm}(X)\) for this predicate. It is decidable in \(O(m^2)\) time by computing \(X^+\) and scanning the attacks.

By definition, preferred extensions are precisely the inclusion-maximal admissible sets. Hence

\(X\in\operatorname{pr}(\Lambda)\iff \operatorname{Adm}(X)\wedge \forall Y\subseteq A\, \bigl(X\subsetneq Y\Rightarrow\neg\operatorname{Adm}(Y)\bigr)\).

For subsets \(U,F,V\subseteq A\), let \(R(U,F,V)\) be the conjunction of:

  • \(\operatorname{Adm}(S)\);
  • \(\neg\bigl(S\subsetneq U\wedge\operatorname{Adm}(U)\bigr)\);
  • \(\neg\operatorname{Adm}(F)\vee\neg B(F,S)\vee \bigl(F\subsetneq V\wedge\operatorname{Adm}(V)\bigr)\).

The required decision condition is equivalent to

\(\forall U\subseteq A\;\forall F\subseteq A\;\exists V\subseteq A\;R(U,F,V)\).

To verify this equivalence, suppose first that \(S\) is preferred and unbeaten. Conditions 1 and 2 hold for every \(U\). For each \(F\), condition 3 holds immediately if \(F\) is inadmissible or does not beat \(S\). Otherwise, \(F\) must be admissible but nonpreferred, so it has an admissible proper superset \(V\).

Conversely, suppose the quantified formula holds. Conditions 1 and 2 imply that \(S\) is preferred. If a preferred extension \(F\) beat \(S\), the first two disjuncts of condition 3 would be false. The last disjunct would require an admissible proper superset of \(F\), contradicting its preferredness.

Each quantified set uses \(m\) bits, and \(R\) is computable in polynomial time, with the conservative bound \(O(m^2+L+\tau L^2)\). The universal sets can be combined into one block, so this is a \(\forall\exists\) characterization with a polynomial-time predicate. The problem therefore belongs to \(\Pi_2^p\).

3. Hardness through a singleton support

We use the supplied theorem that verifying an unbeaten preferred extension for one well-formed conditional-preference base under flat KTV is \(\Pi_2^p\)-complete. The cited paper’s body satisfaction, well-formedness, flat KTV comparison, and best-extension definitions coincide with those in the question; Table 1 lists \(\Pi_2^p\)-completeness for preferred-extension verification under KTV. [Alfano et al., definitions and Table 1](https://ceur-ws.org/Vol-3464/short1.pdf).

Given a single-base instance \((\Lambda,\Gamma,S)\), construct the society

\(T=\{t\},\qquad\Gamma_t=\Gamma,\qquad\mu_t=1\).

This construction preserves the framework, proposed set, rules, and their well-formedness witness. The mass is a positive binary rational, its encoding has constant length, and the masses sum to \(1\). The reduction takes linear time in the source input length.

Strict KTV preference is asymmetric: \(E\succ_{k,t}F\) requires both \(E\succeq_{k,t}F\) and \(F\not\succeq_{k,t}E\), which excludes \(F\succ_{k,t}E\). Consequently, in this singleton society,

\(E\succ_\mu F\iff E\succ_{k,t}F\).

Indeed, a strict KTV preference produces weights \(1\) and \(0\); if neither direction is strict, both weights are \(0\). Thus the constructed instance accepts exactly when the original single-base instance accepts. This proves \(\Pi_2^p\)-hardness.

Finally, \(\mathrm{NP}\subseteq\Pi_2^p\): an existential polynomial-time certificate characterization can be preceded by a universal quantifier whose value the verifier ignores. Therefore \(\Pi_2^p\)-hardness under polynomial-time many-one reductions implies \(\mathrm{NP}\)-hardness.

4. An explicit deterministic running-time bound

An exhaustive algorithm provides the bound

\(O\bigl(\tau L^2+2^m(m^2+L+\tau L)\bigr)\).

To obtain it, first compute admissibility for all \(2^m\) subsets in \(O(2^m m^2)\) time. Let \(C(X)\) indicate whether some admissible superset of \(X\), possibly \(X\) itself, exists. Compute it in decreasing order of set size using

\(C(X)=\operatorname{Adm}(X)\vee \bigvee_{a\in A\setminus X}C(X\cup\{a\})\).

This takes \(O(m2^m)\) time. A set \(X\) is preferred exactly when it is admissible and every \(C(X\cup\{a\})\) is false. Finally, check \(S\)’s preferredness and compare every preferred extension against \(S\), using the preprocessed integer masses.

The lower and upper complexity bounds establish the claimed completeness.
