Theorem 12 — class: hardness

The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), a capacity \(K\), and a positive monotone cost table \(C(q)\) for each integer composition \(q\in\mathbb{Z}_{\ge0}^{T}\) with \(1\le\sum_t q_t\le K\), choose intensities \(x_q\ge0\) minimizing \(\sum_q C(q)x_q\), subject to \(\sum_q q_t x_q=\mu_t\) for every \(t\in T\). Here \(x_q\) is the number of coalitions of composition \(q\) per unit population; determine an optimal intensity vector.

Let \(K\ge3\) be an integer capacity, encoded in binary, and let \(Q=\{q\in\mathbb Z_{\ge0}^{T}:1\le\sum_{t\in T}q_t\le K\}\). Every composition in \(Q\) is allowed, including repeated occurrences of a type.
The input explicitly lists a positive binary-rational cost \(C(q)\) for every \(q\in Q\). Monotonicity means \(C(q)\le C(q')\) whenever \(q_t\le q'_t\) for every \(t\); set \(C(0)=0\).
An intensity \(x_q\in\mathbb R_{\ge0}\) represents the number of coalitions of composition \(q\) per unit population. Determine an optimal intensity vector minimizing \(\sum_{q\in Q}C(q)x_q\), subject to \(\sum_{q\in Q}q_tx_q=\mu_t\) for every \(t\in T\).
Let \(L\) be the total binary input length, including the entire cost table. State running times in \(\tau\), \(K\), and \(L\); there is no separate ground-set parameter \(m\).

Is this continuous optimization problem solvable in polynomial time, or is it NP-hard?

For finitely many individual participants, minimizing the total positive monotone cost of a partition into coalitions of size at most \(K\) is NP-hard for every fixed \(K\ge3\); for \(K=2\), it is polynomial-time solvable by general graph matching. Conclusion

The continuous optimization problem is solvable exactly in polynomial time in \(L\). This holds for variable capacity \(K\) encoded in binary. The decisive assumption is that the input explicitly contains the entire cost table.

1. Number of variables

Write \(N=|Q|\). Introducing the slack coordinate \(q_0=K-\sum_{t\in T}q_t\) gives a bijection between compositions of total size at most \(K\) and nonnegative integer vectors with \(\tau+1\) coordinates summing to \(K\). By stars and bars, and then excluding the zero composition,

\[ N=\binom{\tau+K}{K}-1. \]

Here and below, the displayed equations denote the same mathematics as inline formulas.

Because the input explicitly lists \(N\) costs, each using at least one bit, \(N\le L\). Moreover, the singleton compositions give \(\tau\le N\), and the compositions \(e_t,2e_t,\ldots,Ke_t\) for any fixed \(t\in T\) give \(K\le N\). Thus both \(\tau\) and the numerical value of \(K\) are bounded by \(L\).

2. An explicit rational linear program

Index the columns of a matrix \(A\) by \(Q\), and define \(A_{tq}=q_t\). Let \(c_q=C(q)\). The requested problem is exactly

\[ \min\{c^{\mathsf T}x:Ax=\mu,\ x\ge0\}. \]

It has \(N\) variables and \(\tau\) equality constraints. Every coefficient is rational, and every entry of \(A\) is an integer between zero and \(K\).

The feasible set is nonempty: set \(x_{e_t}=\mu_t\) for every \(t\), and set all other coordinates to zero.

It is also bounded. Summing the mass constraints gives, for every feasible \(x\),

\[ 1=\sum_{q\in Q}\left(\sum_{t\in T}q_t\right)x_q. \]

Every composition has total size at least one, so \(\sum_qx_q\le1\). In particular, every coordinate belongs to \([0,1]\). The feasible set is closed, since it is defined by finitely many linear equalities and inequalities. It is therefore compact. The linear objective is continuous, so an optimum exists.

3. Exact polynomial-time solution

We use the standard polynomial-time theorem for rational linear programming: a linear program with explicitly encoded rational coefficients can be solved exactly, or classified as infeasible or unbounded, in a number of bit operations polynomial in its binary encoding length. This includes recovering an optimal rational vector, rather than merely approximating the optimal value. The ellipsoid method provides such an algorithm; see [MIT’s notes on polynomial-time linear programming](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html).

Let \(S\) be the binary encoding length of the standard-form linear program above. Constructing its dense coefficient matrix gives

\[ S=O\!\left(L+\tau N\log(K+1)\right). \]

Indeed, the masses and costs already occur in the input, and the matrix has \(\tau N\) integer entries, each requiring \(O(\log(K+1))\) bits.

The theorem applies because all coefficients are rational and explicitly available. The preceding section establishes feasibility and existence of a finite optimum. Consequently, the running time can be bounded by

\[ \left( L+\tau\left[\binom{\tau+K}{K}-1\right]\log(K+1) \right)^{O(1)}. \]

Since \(N,\tau,K\le L\), we have \(S=O(L^2\log(L+1))\). Hence the running time is \(L^{O(1)}\).

This is a polynomial bound in the full input length; it does not assert a polynomial bound in \(\tau+\log K\) without accounting for the cost table.

4. An optimal vector has a small exact representation

There is an optimal vector with at most \(\tau\) positive coordinates. Here is a direct proof.

Choose an optimal vector \(x\) whose support \(J=\{q:x_q>0\}\) has minimum cardinality. Suppose the columns \(A_{\cdot q}\), \(q\in J\), are linearly dependent. Then there is a nonzero vector \(d\), supported on \(J\), with \(Ad=0\).

For sufficiently small positive \(\varepsilon\), both \(x+\varepsilon d\) and \(x-\varepsilon d\) are nonnegative and satisfy the mass constraints. Optimality therefore forces \(c^{\mathsf T}d=0\): otherwise one of these two vectors would have strictly smaller cost.

After changing the sign of \(d\) if necessary, it has a positive coordinate. Set

\[ \alpha=\min_{q:d_q>0}\frac{x_q}{d_q}. \]

Then \(x-\alpha d\) is feasible and optimal, has no positive coordinates outside \(J\), and has at least one fewer positive coordinate. This contradicts the choice of \(x\). Thus its supported columns are independent, and \(|J|\le\tau\).

To check the encoding size, put \(r=|J|\). Choose \(r\) rows on which these columns form an invertible integer matrix \(M\). Let \(D\) be the product of the denominators of the input masses, written in the usual binary rational encoding. Then \(\log D=O(L)\), and \(D\mu\) is integral.

Cramer’s rule expresses each supported coordinate as

\[ x_j=\frac{\det M_j}{D\det M}, \]

where \(M_j\) replaces column \(j\) of \(M\) by the corresponding coordinates of \(D\mu\). Since all masses are at most one, Hadamard’s determinant inequality gives

\[ |\det M|\le r^{r/2}K^r, \qquad |\det M_j|\le r^{r/2}DK^{r-1}. \]

Thus each supported coordinate has binary numerator and denominator lengths bounded by \(O(L+r\log(K+1)+r\log(r+1))\). An exact optimal vector therefore admits a polynomial-size representation.

5. Relation to the discrete problem

The finite-participant partition problem requires integer coalition counts. The mass problem permits arbitrary nonnegative real intensities and is precisely the rational linear program analyzed above. The stated NP-hardness of the discrete problem therefore does not transfer to this formulation.

Monotonicity is not needed for the polynomial-time argument. Under the stated explicit-table encoding, the continuous problem is polynomial-time solvable, and hence cannot be NP-hard under polynomial-time reductions unless \(\mathrm P=\mathrm{NP}\).
