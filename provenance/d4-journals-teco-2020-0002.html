The anchor (named result in the paper)

Theorem 2(iv) — class: hardness

The continuous mirror question, as graded

Given a finite outcome set \(A\), supported nonempty like-sets \(\mathcal T\subseteq 2^A\setminus\{\emptyset\}\), and binary-rational masses \(\mu_S>0\) summing to one, compute the exact expected RP share of each distinct outcome signature. Draw a type order sequentially, choosing each remaining \(S\) with probability proportional to \(\mu_S\); for each order, select its lexicographically maximal like-set signature, then average the resulting shares over orders.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a nonempty finite outcome set, with \(m=|A|\). A society is given by its support: a list \(\mathcal T\subseteq 2^A\setminus\{\emptyset\}\) of \(\tau\) distinct types with positive binary-rational masses \(\mu_S\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
Type \(S\) likes precisely the outcomes in \(S\), with indifference within likes and within dislikes. The signature of outcome \(a\) is \(v(a)=(\mathbf 1_{a\in S})_{S\in\mathcal T}\); let \(V\) be the set of distinct signatures, identifying outcomes with identical signatures.
Draw a strict order \(\sigma=(S_1,\ldots,S_\tau)\) without replacement, choosing each next type \(S\) from the remaining set \(R\) with probability \(\mu_S/\sum_{T\in R}\mu_T\). For this order, select the unique signature \(v^\sigma\in V\) lexicographically maximizing \((v_{S_1},\ldots,v_{S_\tau})\), with \(1\) preferred to \(0\).
The required output is every signature share \(p_v=\Pr(v^\sigma=v)\), represented as an exact binary rational; each order assigns its entire share to its selected signature.

Is computing all shares \((p_v)_{v\in V}\) possible in time polynomial in \(m,\tau,L\), or is this computation \(\mathrm{NP}\)-hard under polynomial-time Turing reductions?

For finite lists of agents, exact RP computation is \(\#\mathrm P\)-complete even with dichotomous preferences; determining its support is polynomial-time. [Aziz, Brandt, and Brill](https://arxiv.org/pdf/1304.3169).
No result settling the exact mass-weighted signature-share problem stated here was located.

Modeling choices made when packaging the task

  • Defined an outcome signature as its binary approval vector over supported types and identified outcomes with identical signatures.
  • Interpreted a signature's share as its selection probability: every order assigns unit share to its unique maximal signature, without requiring a split among outcome clones.
  • Required a nonempty outcome set and specified exact rational output in binary.
  • Specified polynomial-time Turing reductions for hardness because the requested computation is a function problem and the verified discrete hardness uses this reduction notion.

Result

Computing all signature shares is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. In fact, it is \(\#\mathrm P\)-hard under such reductions, even when every input mass is dyadic.

Here “exact binary rational” means a rational represented by binary integers for its numerator and denominator. If it instead means a terminating binary expansion, the requested output need not exist: on outcomes \(\{a,b\}\), masses \(\mu_{\{a\}}=1/2\), \(\mu_{\{b\}}=1/4\), and \(\mu_{\{a,b\}}=1/4\) give \(p_{v(a)}=2/3\). The proof below addresses the intended exact-rational computation.

1. Repeated types have no further effect

For a nonempty candidate set \(B\subseteq A\), define the filtering operation of type \(S\) by

\(F_S(B)=B\cap S\) if \(B\cap S\ne\emptyset\), and \(F_S(B)=B\) otherwise.

Applying these operations in a given order retains precisely the outcomes whose signatures are lexicographically maximal in that order. Indeed, at each coordinate, the operation retains the outcomes with value \(1\) if any remain, and otherwise retains all current outcomes.

Lemma 1. In a sequence of filtering operations, deleting every occurrence of a type after its first occurrence leaves the final candidate set unchanged.

Proof. Immediately after the first operation of type \(S\), the candidate set is contained either in \(S\) or in \(A\setminus S\). Every subsequent operation only shrinks the candidate set, so this containment persists. Consequently, every later application of \(F_S\) acts as the identity. Deleting these identity operations preserves all subsequent candidate sets. \(\square\)

After every distinct type has been processed, all surviving outcomes have the same signature: each processed coordinate is constant on the surviving set. Thus this procedure selects exactly one signature, as required in the question.

2. First appearances follow the mass-weighted order

Lemma 2. Suppose an explicitly listed population contains \(c_S\) agents of each distinct type \(S\), where every \(c_S\) is a positive integer. In a uniformly random permutation of these agents, the order of first appearances of distinct types has the distribution specified in the question with masses

\(\mu_S=c_S/\sum_T c_T\).

Proof. Give every individual agent an independent exponential clock of rate \(1\), and order agents by increasing clock times. These clocks are identically distributed and continuous, so every permutation is equally likely.

For each type \(S\), let \(T_S\) be the minimum clock among its \(c_S\) agents. The variables \(T_S\) are independent, because different types use disjoint collections of independent clocks. Moreover,

\(\Pr(T_S>t)=e^{-c_St}\),

so \(T_S\) is exponential of rate \(c_S\). The first-appearance order is precisely the increasing order of these minima.

For any remaining type set \(R\), independent exponential clocks of rates \((c_T)_{T\in R}\) satisfy

\(\Pr(T_S=\min_{T\in R}T_T)=\int_0^\infty c_Se^{-c_St}\prod_{T\in R\setminus\{S\}}e^{-c_Tt}\,dt =c_S/\sum_{T\in R}c_T.\)

Conditional on the winning type and its clock time, the remaining clocks, after subtracting that time, are again independent exponentials with their original rates, by the memoryless property. Hence the same calculation applies recursively at every position.

Finally,

\(c_S/\sum_{T\in R}c_T=\mu_S/\sum_{T\in R}\mu_T\),

which is exactly the required sampling rule. \(\square\)

Together, the two lemmas show that aggregating identical agents into distinct types with masses proportional to their multiplicities preserves the distribution over selected signatures.

3. Reduction from dichotomous random serial dictatorship

We use the following known result: computing the exact random serial dictatorship probability of a designated alternative in an explicitly listed dichotomous voting profile is \(\#\mathrm P\)-hard under polynomial-time Turing reductions. The profiles satisfy the assumption that no two alternatives are indifferent for every agent. This is [Aziz, Brandt, and Brill, Theorem 2 and their standing assumption in Section 2](https://arxiv.org/pdf/1304.3169).

Take such a profile with \(n\) agents and outcome set \(A\). Represent each agent by its nonempty liked set \(S\); for a completely indifferent agent, use \(S=A\). Let \(d_S\) be the multiplicity of each distinct liked set.

We construct a valid instance of the question, with dyadic masses.

  • Let \(M=2^{\lceil\log_2 n\rceil}\).
  • Add \(M-n\) completely indifferent agents, all of type \(A\).
  • Let \(c_S\) be the resulting multiplicities.
  • Include exactly the types with positive multiplicity, assigning each mass \(\mu_S=c_S/M\).

The masses are positive, dyadic, and sum to \(1\). The types are distinct and nonempty.

Adding completely indifferent agents does not change any deterministic selection: their filtering operation is \(F_A(B)=B\). Furthermore, the relative order of the original agents in a uniformly random permutation of the padded population is uniform. Therefore padding preserves the original random serial dictatorship probabilities.

By Lemma 2, the padded population induces exactly the mass-weighted first-appearance order in the constructed instance. By Lemma 1, filtering in this first-appearance order produces the same result as filtering in the full agent permutation.

Finally, distinct outcomes in the source profile remain distinct signatures after aggregation. If two outcomes were indifferent for every distinct type, they would be indifferent for every original agent, contradicting the source assumption. Thus, for every source alternative \(a\),

\(p_{v(a)}=\Pr(\text{the source random serial dictatorship selects }a).\)

An oracle computing all target shares therefore computes the exact source probability of any designated alternative.

4. Polynomial size and exact arithmetic

The construction has the same number \(m\) of outcomes and at most \(n+1\) distinct types. Because \(M<2n\), each mass requires only \(O(\log(n+1))\) bits. Grouping agents by their liked sets and writing the resulting incidence table takes polynomial time.

The oracle answers on these constructed instances also have polynomial length. Every signature share equals the fraction of the \(M!\) padded agent permutations selecting that signature. Consequently, its reduced denominator divides \(M!\), and its numerator and denominator each require at most \(O(M\log(M+1))\) bits. There are at most \(m\) shares.

Thus the reduction can construct its queries, read their answers, and recover the designated source probabilities in polynomial time. Composing it with the cited hardness reduction proves \(\#\mathrm P\)-hardness, and therefore \(\mathrm{NP}\)-hardness, under polynomial-time Turing reductions.

Accordingly, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).
