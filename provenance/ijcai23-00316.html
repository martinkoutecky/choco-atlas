The continuous mirror question, as graded

Fix \(\alpha=1\), \(\beta\), and a graph \(H\) of treewidth at most \(w\). Given complete additive agent types \(a\in[\tau]\), rational per-building masses \(\mu_a\), valuations \(u_a(v)\), \(\rho=\sum_a\mu_a\), and \(U_a=\sum_{v\in V(H)}u_a(v)\), a local configuration is an integral allocation in one copy of \(H\) to a finite multiset of type-labelled agents, with pairwise disjoint \((1,\beta)\)-compact bundles and every type-\(a\) bundle worth at least \(U_a/\rho\). Decide whether finite-support masses \(\lambda_\sigma\ge0\) exist with \(\sum_\sigma\lambda_\sigma=1\) and \(\sum_\sigma\lambda_\sigma q_a(\sigma)=\mu_a\) for every type \(a\), where \(q_a(\sigma)\) counts type-\(a\) agents in configuration \(\sigma\).

Packaged proof task (what the prover saw — nothing else)

Definitions. Fix an integer \(\alpha\ge 3\). An instance has a finite set \(Z\), a distribution of rational type masses \((\mu_t)_{t\in T}\), rational supplies \((\rho_z)_{z\in Z}\), and additive valuations \(v_t\). Let \(p_t=\sum_{z\in Z}\rho_zv_t(z)\). It is feasible if nonnegative masses \(x_{t,B}\), for \(B\subseteq Z\) with \(|B|\le\alpha\), satisfy \(\sum_Bx_{t,B}=\mu_t\), \(\sum_{t,B:z\in B}x_{t,B}\le\rho_z\), and \(x_{t,B}>0\Rightarrow v_t(B)\ge p_t\).

Target. Is deciding feasibility of this continuous proportional allocation problem in \(P\), or is it NP-hard?

Nearest known results. The discrete counterpart is strongly NP-hard for every fixed \(\alpha\ge3\), even with additive valuations and an edgeless item graph; there, compactness is exactly the requirement that every bundle contain at most \(\alpha\) items. Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Result

Under the standard explicit binary encoding of \(Z\), \(T\), the rational numbers \(\mu_t,\rho_z,v_t(z)\), the feasibility problem is polynomial-time solvable for every fixed \(\alpha\).

1. Admissible bundles

Let \(n=|Z|\). For each type \(t\), compute

\[ p_t=\sum_{z\in Z}\rho_zv_t(z). \]

Define the admissible bundle family

\[ \mathcal A_t= \left\{ B\subseteq Z: |B|\leq\alpha \text{ and } \sum_{z\in B}v_t(z)\geq p_t \right\}. \]

Because \(\alpha\) is fixed, the number of candidate bundles is bounded by

\[ \sum_{k=0}^{\alpha}\binom{n}{k}=O(n^\alpha). \]

Thus all candidate bundles can be enumerated in polynomial time. Additivity permits \(v_t(B)\) to be computed using at most \(\alpha\) rational additions.

All comparisons with \(p_t\) can be performed exactly using rational arithmetic. Products, sums, and comparisons of polynomially many binary-encoded rational numbers have polynomial bit complexity.

2. Explicit linear program

Introduce one nonnegative variable \(x_{t,B}\) for every \(t\in T\) and \(B\in\mathcal A_t\). Consider the rational linear system

\[ \sum_{B\in\mathcal A_t}x_{t,B}=\mu_t \qquad\text{for every }t\in T, \]

\[ \sum_{t\in T}\sum_{\substack{B\in\mathcal A_t\\z\in B}}x_{t,B} \leq \rho_z \qquad\text{for every }z\in Z, \]

and

\[ x_{t,B}\geq0 \qquad\text{for every }t\in T,\ B\in\mathcal A_t. \]

3. Equivalence with the original formulation

Lemma

The original allocation instance is feasible if and only if the displayed linear system is feasible.

Proof

Suppose first that the original instance has a feasible solution \(x_{t,B}\). If \(B\notin\mathcal A_t\), then either \(B\) violates the cardinality bound or \(v_t(B)<p_t\). Variables for bundles violating the cardinality bound do not occur in the original formulation. For every remaining \(B\notin\mathcal A_t\), the implication

\[ x_{t,B}>0\Longrightarrow v_t(B)\geq p_t \]

and nonnegativity imply \(x_{t,B}=0\). Deleting these zero coordinates leaves a solution of the displayed linear system.

Conversely, suppose the displayed system is feasible. Extend its solution to every \(B\subseteq Z\) with \(|B|\leq\alpha\) by setting \(x_{t,B}=0\) whenever \(B\notin\mathcal A_t\). The type-mass and supply constraints remain valid. Moreover, whenever \(x_{t,B}>0\), the variable belongs to the displayed system, so \(B\in\mathcal A_t\) and therefore \(v_t(B)\geq p_t\). Hence the extended solution is feasible for the original instance. This proves the equivalence. \(\square\)

4. Polynomial running time

The number of variables is at most

\[ |T|\sum_{k=0}^{\alpha}\binom{|Z|}{k} =O\!\left(|T||Z|^\alpha\right). \]

There are \(|T|\) mass equalities, \(|Z|\) supply inequalities, and one nonnegativity constraint per variable. Since \(\alpha\) is fixed, both the number of variables and the encoding length of the entire rational linear system are polynomial in the input length.

Feasibility of an explicitly given rational linear program is decidable in polynomial time in its binary encoding length. Applying any polynomial-time rational linear-programming feasibility algorithm therefore decides the allocation problem in polynomial time.

5. Conclusion

For every fixed \(\alpha\geq3\), the continuous proportional allocation feasibility problem belongs to \(P\).

The discrete hardness result does not transfer: after enumerating the polynomially many bounded-cardinality bundles, the discrete problem retains integrality restrictions, whereas the mass-distribution formulation has unrestricted nonnegative rational variables and is exactly a linear program. Consequently, the continuous problem can be NP-hard under standard polynomial-time reductions only if \(P=NP\).
