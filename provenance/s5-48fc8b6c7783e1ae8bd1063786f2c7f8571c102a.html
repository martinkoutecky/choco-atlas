The continuous mirror question, as graded

Given finitely many complete tenant types \(T\) with rational masses \(\mu_t\), each type’s request DAGs with edge utilities, and shared resource classes \(K\) with per-unit-mass capacities \(b_k\), choose masses \(x_{t,q}\ge 0\) over each type’s tuples of paths \(q\). Require \(\sum_q x_{t,q}=\mu_t\) for every \(t\) and \(\sum_{t,q}x_{t,q}a_{t,q,k}\le b_k\) for every \(k\), where \(a_{t,q,k}\) is the additive resource use of tuple \(q\); compute an allocation maximizing \(\sum_{t,q}x_{t,q}U_t(q)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) complete tenant types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies a nonempty finite family \(G_t\) of explicitly represented single-source single-sink DAGs. Each arc has a nonnegative binary-rational utility; each DAG includes a direct source-to-sink arc of utility zero representing an empty bundle.
There is an explicitly listed set \(K\) of resource classes with nonnegative binary-rational capacities \(b_k\), measured per unit of total society mass. Each vertex \(v\) has explicitly given nonnegative binary-rational consumption \(c_{v,k}\); sources and sinks consume zero.
Let \(Q_t\) contain all tuples choosing one source-to-sink path in every DAG in \(G_t\). For \(q\in Q_t\), define \(U_t(q)=\sum_{g\in G_t}\sum_{e\in q_g}u_g(e)\) and \(a_{t,q,k}=\sum_{g\in G_t}\sum_{v\in q_g}c_{v,k}\).
Choose divisible masses \(x_{t,q}\ge0\) satisfying \(\sum_{q\in Q_t}x_{t,q}=\mu_t\) and \(\sum_{t\in T}\sum_{q\in Q_t}x_{t,q}a_{t,q,k}\le b_k\), maximizing \(\sum_{t\in T}\sum_{q\in Q_t}x_{t,q}U_t(q)\). These are the only compatibility constraints; tuples are specified implicitly by the DAGs.
Let \(m\) be the total number of request DAGs, \(N\) and \(E\) their total vertex and arc counts, and \(L\) the total input bit length.

Is this mass-allocation optimization problem solvable in polynomial time in \(m,\tau,N,E,|K|,L\), or is its decision version asking whether utility at least a given binary-rational threshold \(h\) is attainable NP-hard?

Discrete allocation of one path per request, with forbidden vertex sets whose vertices belong to distinct DAGs, has an NP-complete utility-threshold decision problem. [Roussel et al., 2023](https://doi.org/10.3390/systems11060297)
No result settling exactly the mass-allocation problem defined above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive masses to sum to one, interpreting capacities as aggregate capacities per unit of total society mass.
  • Required explicitly represented nonempty families of single-source single-sink request DAGs, nonnegative binary-rational arc utilities, and a zero-utility direct source-to-sink option, following the discrete definitions.
  • Specified the undefined additive resource use through explicit nonnegative binary-rational vertex consumptions, summed across the paths in a tuple; sources and sinks consume zero.
  • Allowed nonnegative binary-rational capacities, including zero, since the graded capacity model supplies no positivity restriction.
  • Interpreted each type's tuples as all combinations of its request paths, with exactly the graded aggregate capacity constraints and no additional tuple compatibility restrictions.
  • Defined the input-size parameters and a binary-rational utility threshold for the decision version.

Result

The mass-allocation optimization problem is solvable in polynomial time. Its utility-threshold decision version belongs to \(\mathrm{P}\).

The proof gives an exact linear program with \(E\) variables and a polynomial-time procedure that converts an optimal solution into an allocation supported on at most \(E\) path tuples. It uses precisely the stated assumption that every combination of paths within a type is allowed.

1. A polynomial-size flow formulation

Index each request DAG by its type and its occurrence within that type. Write \(V_{t,g}\) and \(A_{t,g}\) for its vertex and arc sets, and \(s_{t,g}\) and \(z_{t,g}\) for its source and sink. Let \(\delta^+(v)\) and \(\delta^-(v)\) denote the outgoing and incoming arcs in that DAG.

Introduce a nonnegative variable \(f_{t,g,e}\) for each arc. It represents the mass of type \(t\) whose path in request \(g\) uses arc \(e\). Each request of type \(t\) carries total flow \(\mu_t\): every member of that type chooses a path in every request.

Define \(d_{t,g,v}\) to equal \(\mu_t\) at the source, \(-\mu_t\) at the sink, and zero elsewhere. Impose the flow equations

\[ \sum_{e\in\delta^+(v)}f_{t,g,e} - \sum_{e\in\delta^-(v)}f_{t,g,e} = d_{t,g,v} \qquad (t\in T,\ g\in G_t,\ v\in V_{t,g}). \]

The resource constraints are

\[ \sum_{t\in T}\sum_{g\in G_t} \sum_{e=(v,w)\in A_{t,g}} c_{w,k}f_{t,g,e} \le b_k \qquad(k\in K). \]

The objective is

\[ \max\; \sum_{t\in T}\sum_{g\in G_t} \sum_{e\in A_{t,g}} u_g(e)f_{t,g,e}. \]

This charges each arc for consumption at its head. On a DAG path, every vertex other than the source is entered exactly once. Because sources and sinks consume zero, this arc-based expression equals the vertex consumption specified in the question.

Call this linear program the flow LP.

2. Every allocation induces a feasible flow with the same utility

Let \(x\) be any feasible allocation in the original problem. Define

\[ f_{t,g,e} = \sum_{q\in Q_t}x_{t,q}\, \mathbf{1}_{\{e\in q_g\}}. \]

Each source-to-sink path has net outflow one at the source, net outflow minus one at the sink, and zero net outflow at every other vertex. Summing these identities with weights \(x_{t,q}\) proves the flow equations, because \(\sum_{q\in Q_t}x_{t,q}=\mu_t\).

For each resource \(k\), rearranging finite sums gives

\[ \sum_{t,g}\sum_{e=(v,w)\in A_{t,g}} c_{w,k}f_{t,g,e} = \sum_{t\in T}\sum_{q\in Q_t} x_{t,q}a_{t,q,k}. \]

Thus the flow satisfies every resource constraint. Similarly,

\[ \sum_{t,g}\sum_{e\in A_{t,g}} u_g(e)f_{t,g,e} = \sum_{t\in T}\sum_{q\in Q_t} x_{t,q}U_t(q). \]

Consequently, the flow LP optimum is at least the original optimum.

3. Simultaneous path decomposition

The reverse direction must ensure that the separate request flows can be realized by one distribution over complete path tuples.

Lemma. Fix a type \(t\). Suppose every DAG in \(G_t\) carries a nonnegative source-to-sink flow of the same value \(r>0\). These flows can be represented by nonnegative masses on at most \(\sum_{g\in G_t}|A_{t,g}|\) path tuples, with total mass \(r\).

Proof. Maintain residual flows, initially the given flows, and their common residual value \(\rho\), initially \(r\).

Whenever \(\rho>0\), each residual DAG flow contains a source-to-sink path using only positive-flow arcs. Indeed, the source has positive outgoing flow. After entering an internal vertex on a positive-flow arc, conservation guarantees a positive outgoing arc. Since the graph is finite and acyclic, this process terminates, and conservation implies that its terminal vertex must be the sink.

Choose such a path \(P_g\) in every DAG. Their tuple \(q=(P_g)_{g\in G_t}\) belongs to \(Q_t\), since every combination is allowed. Set

\[ \alpha = \min\{f_{t,g,e}:g\in G_t,\ e\in P_g\} >0. \]

Assign mass \(\alpha\) to \(q\), and subtract \(\alpha\) from every arc on every selected path.

The residual flows remain nonnegative. Subtracting a path flow preserves conservation at internal vertices and reduces the flow value by \(\alpha\). Hence every DAG now has the same residual value \(\rho-\alpha\). Also, \(\alpha\le\rho\), because each selected path starts with an arc whose flow is at most the source’s total outgoing flow \(\rho\).

At least one positive arc becomes zero in each iteration. Zero arcs never become positive again. Therefore there are at most \(\sum_{g\in G_t}|A_{t,g}|\) iterations.

The process must reach residual value zero: otherwise another iteration would be possible, contradicting that iteration bound. A nonnegative flow of value zero on a DAG is identically zero. To verify this, if a positive arc existed, choose the earliest vertex in a topological ordering having a positive outgoing arc. It has no positive incoming arc, contradicting zero divergence.

Thus the extracted tuple masses reproduce every original arc flow. Their sum is \(r\), since each extraction reduces the common flow value by its assigned mass. This proves the lemma. \(\square\)

4. Every feasible flow induces a feasible allocation

Apply the lemma separately to each type, with \(r=\mu_t\). Let \(x_{t,q}\) be the resulting tuple masses, aggregating any repeated tuples and setting all other entries to zero.

For every type and request, the construction guarantees

\[ \sum_{q\in Q_t}x_{t,q}=\mu_t, \qquad f_{t,g,e} = \sum_{q\in Q_t}x_{t,q} \mathbf{1}_{\{e\in q_g\}}. \]

The resource and objective identities proved in Section 2 therefore apply again. The reconstructed allocation has exactly the same resource consumption and utility as the flow.

It follows that the original problem and the flow LP have equal optimal values. Moreover, the reconstruction uses at most \(E\) tuples across all types.

5. Polynomial-time solvability and output size

The flow LP has \(E\) variables, \(N\) flow equations, and \(|K|\) resource inequalities, together with nonnegativity constraints.

Every coefficient is an input rational, zero, or a signed unit coefficient. Repeating consumption coefficients across incoming arcs increases the representation size only polynomially; even a dense matrix representation has size polynomial in \(N,E,|K|,m,\tau,L\). Thus the LP can be constructed in polynomial time.

The standard rational linear-programming theorem states that feasibility and optimization are solvable in time polynomial in the dimensions and binary encoding length, and a finite optimum admits an exactly computable rational optimal solution of polynomial encoding length. This is the polynomial-time solvability theorem originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here:

  • All coefficients and right-hand sides are rational.
  • The LP is feasible: send mass \(\mu_t\) along the zero-utility direct arc in every request. This consumes zero resources.
  • Its feasible region is bounded. Section 3 decomposes each request flow into paths with total mass \(\mu_t\), so every arc satisfies \(0\le f_{t,g,e}\le\mu_t\).

Hence an exact optimal flow can be computed in polynomial time.

The reconstruction also takes polynomial bit time. It has at most \(E\) iterations, each requiring only path searches, comparisons, and subtractions. For an explicit bit bound, let \(D\) be the product of the denominators of all optimal flow coordinates and the masses \(\mu_t\). Its bit length is polynomial. Every residual flow and extracted mass remains an integer multiple of \(1/D\), lies between zero and one, and therefore has polynomial bit length. Each output tuple contains explicitly listed DAG paths, so the total output size is polynomial.

For the threshold decision problem, append the inequality

\[ \sum_{t,g}\sum_{e\in A_{t,g}} u_g(e)f_{t,g,e} \ge h. \]

By the equivalence already proved, this rational system is feasible exactly when the requested utility is attainable. Its feasibility is decidable in polynomial time, including the encoding length of \(h\).

6. Why the discrete hardness premise does not transfer

The simultaneous decomposition relies on two stated premises: masses are divisible, and every path combination within a type is admissible. Forbidden combinations would invalidate the step that combines arbitrarily selected positive-flow paths into an allowed tuple.

Thus the discrete hardness premise concerns constraints absent from this problem. For the problem defined here, the exact flow formulation proves polynomial-time solvability; NP-hardness under polynomial-time many-one reductions would imply \(\mathrm{P}=\mathrm{NP}\).
