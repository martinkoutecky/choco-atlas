The continuous mirror question, as graded

Given a finite set of programs \(P\), rational masses \(\mu_t\) for single-resident types \(t\in T\), rational masses \(\nu_u\) for couple-household types \(u\in U\), type rankings, program priorities, and rational quota rates \(q_p\), decide whether a stable assignment exists and, if so, return one with rational assigned masses \(x_{t,p}\) and \(y_{u,p,r}\). Each type's mass must be fully assigned to acceptable outcomes, quotas must hold, and stability requires that no positive mass of a single type can move to a preferred program, or of a couple type can move jointly to a preferred ordered program pair, where the programs would accept the movers after applying priority choice to the updated mass assignment.

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a set of \(m\geq1\) programs and \(P^+=P\cup\{\bot\}\), where \(\bot\) means unmatched. A society is given by its support: lists of single types \(T\) and ordered couple-household types \(U\) with positive binary-rational masses \(\mu_t,\nu_u\). Set \(\tau=|T|+|U|\); this is the support size, not the number of possible types. Normalize \(\sum_t\mu_t+\sum_u\nu_u=1\); program quotas \(q_p>0\) are binary rationals in resident-mass units. Let \(L\) be the total input bit length.
Each single type strictly ranks an explicit acceptable subset of \(P^+\), ending in \(\bot\); each couple type strictly ranks an explicit acceptable subset of \((P^+)^2\), ending in \((\bot,\bot)\). Partially unmatched pairs and pairs using the same program are permitted. Each program strictly ranks an acceptable subset of the resident categories \(T\cup(U\times\{1,2\})\); unlisted categories are unacceptable.
An assignment consists of nonnegative rational masses \(x_{t,p}\) and \(y_{u,p,r}\), supported on acceptable outcomes whose non-null coordinates accept the corresponding resident categories, with \(\sum_{p\in P^+}x_{t,p}=\mu_t\) and \(\sum_{p,r\in P^+}y_{u,p,r}=\nu_u\). For every \(p\in P\), require \(\sum_t x_{t,p}+\sum_u\sum_{r\in P^+}(y_{u,p,r}+y_{u,r,p})\leq q_p\).
Priority choice retains acceptable resident mass in priority order up to the quota, splitting a category at the cutoff if necessary; within a category, incumbents precede incoming movers. The null program accepts everything.
A block takes some real mass \(\varepsilon>0\) from one occupied outcome of one type to a strictly preferred acceptable outcome. Singles move to one program; both members of couple mass move to the ordered destination pair, and both must be accepted in full. Test each destination against its original roster augmented by the movers, counting members already there only once; do not first remove departing partner mass. For a common destination, test both members jointly, using resident mass \(2\varepsilon\). An assignment is stable if it has no block.

Is stable-assignment existence for this mass model in \(\mathrm{P}\), with a rational stable assignment constructible in polynomial time in \(m,\tau,L\) whenever one exists, or is its existence decision problem \(\mathrm{NP}\)-hard?

Discrete stable matchings correspond exactly to satisfying assignments of a SAT encoding ([Perrault, Drummond and Bacchus](https://arxiv.org/pdf/1505.03463)); discrete existence is NP-complete even without preference ties ([Ronn](https://www.sciencedirect.com/science/article/pii/0196677490900072)).
For related fractional models, stable allocations and schedules exist via Scarf’s lemma, with applications to couples; the general same-program construction has only a one-directional correspondence with discrete stability ([Biró and Fleiner](https://real.mtak.hu/26264/7/BF16do_last.pdf)). No complexity classification for the precise mass model above was located.

Modeling choices made when packaging the task

  • Unmatched outcomes were omitted from the graded formulation; included the null program, partially unmatched couple pairs when listed, and the always-acceptable fully unmatched outcome.
  • Normalization was unspecified; normalized total household mass to one and measured quotas in resident mass, so a couple contributes twice its household mass.
  • Preference and quota domains were unspecified; used explicit strict incomplete rankings, positive rational quotas, and program acceptability for each single category and each ordered couple-member category.
  • Priority choice within a positive-mass category was unspecified; allowed splitting at a quota cutoff and gave incumbents precedence over incoming movers of the same category.
  • The scope of a positive-mass deviation was unspecified; allowed any positive real submass from one occupied outcome, requiring full acceptance of every moving member.
  • The updated-roster wording was ambiguous about departures and members already at a destination; preserved the discrete union-based acceptance test against original destination rosters, counting existing members once and testing same-program couple arrivals jointly.

Proven progress: easy existence, a $\mathrm{PPAD}$ barrier to construction

Every valid instance has a rational stable assignment of polynomial encoding length. Thus the existence decision problem is in $\mathrm{P}$: on valid inputs, its answer is always yes.

The construction question has a different complexity. I prove polynomial search reductions in both directions between the construction task and $\mathrm{SCARF}$, a $\mathrm{PPAD}$-complete search problem. Consequently,

$$ \text{polynomial-time stable-assignment construction} \quad\Longleftrightarrow\quad \mathrm{PPAD}\subseteq\mathrm{FP}, $$

where the right side means that every $\mathrm{PPAD}$ search problem has a polynomial-time algorithm.

I also give an algorithm running in

$$ (K+1)^m\operatorname{poly}(m,\tau,L), $$

where $K$ is the number of mutually acceptable, non-null outcomes in the explicit lists. This establishes polynomial-time construction for every fixed number of programs.

These results do not establish an unconditional polynomial-time construction. They show why existence decision and construction should be distinguished in the question.

1. Outcomes and auxiliary priorities

Let

$$ \mathcal H=T\sqcup U $$

be the household types, and write $b_h$ for the mass of household type $h$. Let $o_h$ denote its completely unmatched outcome.

Delete every listed outcome whose non-null destination rejects the corresponding resident category. Such an outcome cannot occur in an assignment or receive all its members in a block. Let $\mathcal E$ be the remaining non-null outcomes, and put

$$ K=|\mathcal E|, \qquad n=m+\tau. $$

For an outcome $e$, write $h(e)$ for its household type and $a_p(e)\in\{0,1,2\}$ for the number of its members assigned to program $p$.

Choose household scores satisfying

$$ v_h(o_h)=0, \qquad 1\leq v_h(e)\leq K, $$

with larger scores representing strictly preferred outcomes.

For each program $p$, let $\rho_p(c)$ be the position of acceptable resident category $c$ in its priority list; smaller positions mean higher priority. For an outcome using $p$, define

$$ \ell_p(e)= \max\{\rho_p(c):c\text{ is a member of }e\text{ assigned to }p\}. $$

Order the outcomes using $p$ lexicographically by

$$ \bigl(-\ell_p(e),v_{h(e)}(e)\bigr), $$

with larger tuples preferred. Give them consecutive increasing scores $s_p(e)$.

This ordering is strict. Equal values of $\ell_p$ identify the same lowest-priority resident category, which identifies its household type. Distinct outcomes of that household have distinct household scores.

Two consequences will be used.

Priority consequence. If $s_p(g)\geq s_p(e)$, then

$$ \ell_p(g)\leq\ell_p(e). $$

Thus every member of $g$ at $p$ has priority at least that of the lowest-priority member of $e$ at $p$.

Stationary-member consequence. Suppose $e$ is strictly preferred to $f$, and the lowest-priority member of $e$ at $p$ is already at $p$ in $f$. Then

$$ s_p(f)<s_p(e). $$

Indeed, the presence of that member gives $\ell_p(f)\geq\ell_p(e)$. Strict inequality decides the auxiliary comparison through its first component. Equality decides it through the household preference component. This also covers a source outcome placing both members at $p$.

2. A sufficient stability certificate

Construct a matrix $A$ with $n$ rows, indexed by households and programs.

Its first $n$ columns form the identity matrix. A household identity column represents its unmatched outcome; a program identity column represents unused quota.

For each $e\in\mathcal E$, add a column with entries

$$ A_{h(e),e}=1, \qquad A_{p,e}=a_p(e), $$

and zero elsewhere. Let the right-hand side $b$ contain the household masses and program quotas.

Then

$$ Az=b,\qquad z\geq0 $$

expresses exactly assignment feasibility, including explicit nonnegative quota slack.

Assume first that $K>0$, and put $M=K+1$. Define $C$ on identity columns by

$$ C_{ii}=0, \qquad C_{ij}=2M\quad(i\neq j). $$

On a nonidentity column $e$, set

$$ C_{h(e),e}=v_{h(e)}(e), $$

$$ C_{p,e}=s_p(e)\quad\text{when }a_p(e)>0, $$

and set every other entry to $M$.

Call a feasible vector $z$ dominating if every column $e$ has a row $i$ satisfying

$$ C_{ie}\leq C_{ig} \qquad \text{for every }g\in\operatorname{supp}(z). $$

Lemma: every dominating feasible vector gives a stable assignment

Suppose positive mass from an occupied outcome $f$ blocks by moving to a strictly preferred outcome $e$.

The destination must be mutually acceptable and cannot be completely unmatched. Hence $e\in\mathcal E$.

A dominating row for $e$ must be its household row or a destination program row. To see this, suppose row $i$ does not participate in $e$. Then $C_{ie}=M$. Since $b_i>0$, feasibility supplies an occupied column $g$ with $A_{ig}>0$. That column is either row $i$’s identity column or a participating outcome, so

$$ C_{ig}<M, $$

contradicting domination.

The household row cannot dominate $e$: the occupied source $f$ has household score strictly smaller than $e$. Therefore some destination program $p$ dominates $e$.

Its domination has three implications.

  • The original roster at $p$ fills its quota. Otherwise its slack identity column would be occupied and have score zero, contradicting $s_p(e)>0$.
  • Every incumbent at $p$ has priority at least that of the lowest-priority destination member. Every occupied outcome $g$ using $p$ satisfies $s_p(g)\geq s_p(e)$, so the priority consequence applies.
  • That lowest-priority destination member is genuinely incoming. If already at $p$ in $f$, the stationary-member consequence would give $s_p(f)<s_p(e)$, contradicting domination.

Let $c$ be this genuinely incoming member’s category. The original roster contains exactly $q_p$ mass, all with priority at least $c$. Every bit of that original mass precedes incoming category-$c$ mass: strictly higher categories precede it by priority, and incumbent category-$c$ mass precedes it by the incumbent rule.

The blocking test retains the original roster, including departing partner mass. Consequently, no positive incoming category-$c$ mass can be accepted in full.

This contradicts the alleged block. For a common destination, failure to accept this member also defeats joint acceptance of both members. The argument therefore covers stationary partners, partially unmatched outcomes, and same-program destinations. $\square$

3. Universal rational existence and polynomial witness size

The matrix form of Scarf’s lemma used here requires a nonnegative right-hand side, identity initial columns, a bounded feasible set, and

$$ C_{ii}<C_{ik}<C_{ij} $$

for every nonidentity column $k$ and every other identity column $j\neq i$. It supplies a feasible vector with dominating support. This is the version stated in [Biró and Fleiner, Theorem 5](https://real.mtak.hu/26264/7/BF16do_last.pdf).

All hypotheses hold:

  • Every entry of $b$ is strictly positive.
  • The initial columns of $A$ form the identity.
  • Assigning every household entirely unmatched and leaving all quotas unused is feasible.
  • The feasible set is bounded: $A$ is nonnegative, and every column has a positive entry, so each coordinate is bounded by some right-hand-side entry.
  • Every nonidentity entry of $C$ lies strictly between $0$ and $2M$.

Scarf’s lemma therefore supplies a dominating feasible vector. Section 2 proves that its assignment is stable.

If $K=0$, the entirely unmatched assignment is directly stable, because no mutually acceptable non-null destination remains.

Rationality and sparsity

Starting with a dominating vector, suppose its positive-support columns are linearly dependent. Choose a nonzero vector $d$, supported there, with

$$ Ad=0. $$

The vector $d$ has both positive and negative coordinates. Otherwise nonnegativity of $A$, together with its nonzero columns, would make $Ad=0$ impossible.

Set

$$ \lambda=\min_{d_j>0}\frac{z_j}{d_j}, \qquad z'=z-\lambda d. $$

Then $z'\geq0$, $Az'=b$, and the support strictly decreases. Domination persists because every required comparison is now over a subset of the old support.

Repeating gives at most $n$ linearly independent positive-support columns. Choose an invertible square row submatrix $B$ of these columns. Their positive coordinates are uniquely determined by

$$ Bz_B=b_R, $$

so they are rational.

Let $k\leq n$ be their number, and let $D$ be the product of the denominators appearing in $b$. Then

$$ \log D=O(L). $$

Every entry of $B$ belongs to $\{0,1,2\}$. Hadamard’s inequality gives

$$ |\det B|\leq(2\sqrt{k})^k. $$

If $B^{(j)}$ replaces column $j$ by $Db_R$, Cramer’s rule gives

$$ z_j=\frac{\det B^{(j)}}{D\det B}. $$

The replacement column has norm at most $2^{O(L)}\sqrt{k}$, hence

$$ |\det B^{(j)}| \leq 2^{O(L)}\sqrt{k}(2\sqrt{k})^{k-1}. $$

Every coordinate therefore has encoding length

$$ O(L+n\log n). $$

There are at most $n=m+\tau$ occupied coordinates, counting quota slack. In particular, a rational stable assignment has polynomial total encoding length.

Computational consequence

The construction of $A,C,b$ has polynomial size. Finding a dominating solution is the computational problem $\mathrm{SCARF}$, which belongs to $\mathrm{PPAD}$. Its standard computational formulation returns a feasible dominating basis, from which rational coordinates can be recovered by polynomial-time rational linear algebra. See [Kintali et al., Section 5.1](https://arxiv.org/pdf/0904.1435).

Thus the stable-assignment construction task has a polynomial search reduction to a $\mathrm{PPAD}$ problem. This upper reduction does not establish a polynomial-time algorithm.

4. Construction is $\mathrm{PPAD}$-hard under the exact blocking rule

The lower reduction uses instances where every non-null couple outcome has two distinct programs and distinct outcomes of the same couple share no program. Consequently, all members of an improving move are genuinely incoming.

4.1 The source problem

Consider a three-partite, three-uniform hypergraph

$$ V=X\sqcup A\sqcup B, \qquad e=(x,a,b). $$

Vertices strictly rank their incident edges. Capacities satisfy

$$ k_x=1\quad(x\in X), \qquad k_v\in\mathbb Z_{>0}\quad(v\in A\cup B). $$

A feasible fractional matching consists of $z_e\geq0$ with

$$ \sum_{e\ni v}z_e\leq k_v. $$

An edge blocks if each of its vertices is either undersaturated or has positive weight on a strictly less preferred incident edge. Stability means absence of such an edge.

We use the following restricted hardness consequence of Csáji’s reduction: finding a stable fractional matching remains $\mathrm{PPAD}$-hard when, additionally,

$$ \text{each pair }(x,a)\text{ and each pair }(x,b) \text{ belongs to at most one edge}. $$

The intermediate hypergraph in [Csáji, Section 4, proofs of Lemmas 4.4 and 4.6](https://egres.elte.hu/tr/egres-21-11.pdf) has precisely these restrictions, before the step that copies vertices to make all capacities unit. Its $X$ vertices are arc rows and added rows: an arc row together with either endpoint row determines the remaining endpoint, and each added row has degree one. The reduction produces positive integral capacities on $A\cup B$ and unit capacities on $X$.

The unit edge bound is automatic here, because every edge contains an $X$ vertex of capacity one.

4.2 Constructing a normalized society

Let $N=|X|$, and choose

$$ \alpha=2^{-\lceil\log_2N\rceil}. $$

Make one couple type $u_x$ of mass $\alpha$ for each $x\in X$.

Its acceptable non-null outcomes are exactly the pairs $(a,b)$ for edges $(x,a,b)$, ranked according to $x$’s edge preferences. Append $(\bot,\bot)$ last.

Use $A\sqcup B$ as the programs, with quotas

$$ q_p=\alpha k_p. $$

A program $a\in A$ accepts category $(u_x,1)$ exactly when some edge contains $x,a$. A program $b\in B$ similarly accepts $(u_x,2)$.

The pair-uniqueness restriction makes every accepted category correspond to a unique incident edge. Programs rank these categories according to their edge preferences.

If $N\alpha<1$, add one single type of mass $1-N\alpha$ whose only outcome is $\bot$. Thus household masses sum to one. All masses and quotas are positive dyadic rationals with polynomial encoding length.

This transformation has polynomial size.

4.3 Feasible assignments correspond

Given a feasible mass assignment, define

$$ z_{(x,a,b)}=\frac{y_{u_x,a,b}}{\alpha}. $$

Household conservation gives

$$ \sum_{e\ni x}z_e\leq1, $$

and program quota constraints give

$$ \sum_{e\ni p}z_e\leq k_p. $$

Conversely, from a feasible hypergraph matching, set

$$ y_{u_x,a,b}=\alpha z_{(x,a,b)}, $$

$$ y_{u_x,\bot,\bot} = \alpha\left(1-\sum_{e\ni x}z_e\right). $$

These operations preserve rationality and are polynomial-time computations.

4.4 Exact correspondence of blocks

Fix an edge $e=(x,a,b)$ and its corresponding couple destination.

At a destination program $p$, let $c$ be the incoming member’s category. Define

$$ W_p(c)= \sum_{\substack{c'\text{ incumbent at }p\\c'\text{ has priority at least }c}} \text{mass of category }c'. $$

There is one incoming member at each destination. By priority order and incumbent precedence, incoming mass $\varepsilon$ is accepted in full exactly when

$$ W_p(c)+\varepsilon\leq q_p. $$

Therefore some positive incoming mass is acceptable exactly when

$$ W_p(c)<q_p. $$

Since the original load is at most $q_p$, this is equivalent to either:

  • $p$ is undersaturated; or
  • $p$ has positive incumbent mass in a category strictly below $c$.

By pair uniqueness, the latter condition is exactly positive hyperedge weight on an incident edge strictly less preferred than $e$.

Now suppose $e$ blocks the hypergraph matching. At $x$, either unmatched couple mass is positive or a strictly less preferred outcome has positive mass. Choose that outcome as the source $f$.

The source and destination share no program: distinct edges containing $x$ cannot share their $A$ or $B$ endpoint. Thus both members are incoming.

Both destination margins are positive. If the source mass is $z_f^{\mathrm{mass}}>0$, choose

$$ \varepsilon = \frac12\min \left\{ z_f^{\mathrm{mass}}, q_a-W_a((u_x,1)), q_b-W_b((u_x,2)) \right\}. $$

This positive mass is accepted at both destinations and strictly improves the couple’s outcome. Hence it is a block in the task’s model.

Conversely, suppose a mass block moves household $u_x$ to $(a,b)$. Its occupied source is strictly worse, so the $X$ vertex wants edge $e$. Both members are incoming, and their full acceptance implies

$$ W_a((u_x,1))<q_a, \qquad W_b((u_x,2))<q_b. $$

The corresponding program vertices therefore satisfy the hypergraph blocking conditions. Thus $e$ blocks the hypergraph matching.

We have proved exact equivalence:

$$ \text{mass assignment stable} \quad\Longleftrightarrow\quad \text{decoded hypergraph matching stable}. $$

In particular, every stable assignment returned for the constructed society decodes to a solution of the $\mathrm{PPAD}$-hard source problem.

This establishes $\mathrm{PPAD}$-hardness of construction for the precise mass model, already on the restricted instances described above.

5. Polynomial construction for fixed $m$

The sufficient domination certificate also yields a smaller enumeration than the basis enumeration in the notes.

For each program $p$, choose either:

  • an inactive state $a_p=0$; or
  • a score $a_p$ occurring among its incident outcomes.

There are at most

$$ \prod_{p\in P}(K_p+1)\leq(K+1)^m $$

states, where $K_p$ is the number of outcomes using $p$.

For a chosen state $a$, define

$$ D(a)= \left\{ e\in\mathcal E: \text{some }p\text{ using }e \text{ has }a_p>0 \text{ and }s_p(e)\leq a_p \right\}. $$

For household $h$, put

$$ H_h(a)= \max\left( \{v_h(e):h(e)=h,\ e\notin D(a)\}\cup\{0\} \right). $$

Solve a rational linear feasibility problem with assignment variables, ordinary household conservation and quota constraints, and these additional requirements:

  • Every active program is full.
  • An outcome $g$ using an active program $p$ is forbidden if $s_p(g)<a_p$.
  • A household outcome $g$, including its unmatched outcome, is forbidden if

$$ v_{h(g)}(g)<H_{h(g)}(a). $$

Each such linear program has polynomial size.

Soundness

Let an LP be feasible.

For $e\in D(a)$, its witnessing active program is full and every occupied incident outcome has score at least $a_p\geq s_p(e)$. That program dominates $e$ in the matrix certificate.

For $e\notin D(a)$, every occupied outcome of its household has score at least

$$ H_{h(e)}(a)\geq v_{h(e)}(e). $$

Its household row dominates $e$. Columns unrelated to that household have $C$ entries $M$ or $2M$, which are larger than its household score.

Identity columns are always dominated by their own rows, whose identity entry is zero.

Thus every feasible LP solution gives a dominating assignment and is stable by Section 2.

Completeness

Take a dominating assignment supplied by Scarf’s lemma.

Declare exactly its full programs active. For each active $p$, choose

$$ a_p= \min\{s_p(g):g\text{ is occupied and uses }p\}. $$

This minimum exists because $q_p>0$.

The assignment satisfies requirements 1 and 2. If $e\notin D(a)$, no program row dominates $e$: an underfilled program has positive slack, and a full program could dominate only if $s_p(e)\leq a_p$.

As proved in Section 2, a dominating row must participate in $e$. Hence its household row dominates $e$. Every occupied outcome of that household therefore has score at least $v_{h(e)}(e)$. Taking the maximum over all such $e$ proves requirement 3.

So at least one enumerated LP is feasible.

Polynomial-time rational linear programming now yields a rational stable assignment within

$$ (K+1)^m\operatorname{poly}(m,\tau,L) $$

time. Since the outcomes are explicitly listed, $K$ is polynomially bounded by input length. Therefore construction is polynomial-time for every fixed $m$, with unrestricted support size $\tau$.
