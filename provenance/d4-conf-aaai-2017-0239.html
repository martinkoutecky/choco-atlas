The continuous mirror question, as graded

Given a population scale \(N\), a finite support \(T\) of piecewise-constant valuation types on \([0,1]\), and rational masses \(\mu_t\) summing to \(1\), with the types satisfying the intersection property, choose finite-support distributions \(q_t\) over bundles that are finite unions of intervals. Require that every mass unit receives a whole bundle, that \(\sum_{t\in T}\mu_t q_t(\{P:x\in P\})=1/N\) almost everywhere, and that every type weakly prefers every bundle in its distribution’s support to every bundle in any type’s support. Find distributions minimizing \(K=\sum_{t\in T}\mu_t\sum_P q_t(P)k(P)\), where \(k(P)\) is the number of intervals in \(P\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Input also includes a binary-encoded integer population scale \(N\geq2\) and a binary-rational threshold \(B\geq0\). No integrality condition is imposed on \(N\mu_t\).
Each type has a nonnegative piecewise-constant density \(\nu_t\), specified by at most \(m\) positive-length valuation intervals with disjoint interiors, positive rational heights and rational endpoints; it is zero elsewhere and satisfies \(\int_0^1\nu_t(x)\,dx=1\). At almost every point, some type has positive density. Write \(V_t(P)=\int_P\nu_t(x)\,dx\).
The intersection property requires that each specified valuation interval of type \(t\) overlaps in positive length exactly one specified valuation interval of every other type \(s\).
A bundle \(P\) is a nonempty finite union of positive-length intervals in \([0,1]\), considered modulo null sets; \(k(P)\) counts its interval components after merging adjacent intervals.
Choose a finite-support probability distribution \(q_t\) over bundles for each type, allowing real probabilities and endpoints. A fraction \(q_t(P)\) of type \(t\) receives the whole bundle \(P\).
Feasibility requires \(\sum_{t\in T}\mu_t\sum_{P\in\operatorname{supp}(q_t)}q_t(P)\mathbf{1}_P(x)=1/N\) almost everywhere and \(V_t(P)\geq V_t(Q)\) for every \(t,s\in T\), \(P\in\operatorname{supp}(q_t)\), and \(Q\in\operatorname{supp}(q_s)\).
Define \(K=\sum_{t\in T}\mu_t\sum_{P\in\operatorname{supp}(q_t)}q_t(P)k(P)\); let \(L\) be the total binary input length.
Is deciding whether feasible distributions with \(K\leq B\) exist solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,L,N\).
For a finite society of \(n\) agents satisfying the intersection property, an algorithm polynomial in \(m,n\) constructs an envy-free complete allocation using \(O(nm)\) cuts ([source](https://ojs.aaai.org/index.php/AAAI/article/view/10584)); this does not establish exact cut minimization.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The decision problem is polynomial-time solvable: the answer is yes exactly when \(B\geq 1\). In fact, every permitted instance admits feasible distributions with \(K=1\).

The substantive point is that a partition into \(N\) connected intervals can always be paired with fractional assignments of types to their most preferred intervals, giving each interval total recipient mass \(1/N\). This uses the stated permission to assign the same bundle to fractions of several types. It holds without the intersection property.

1. The universal lower bound

Every allowed bundle is nonempty and has at least one interval component. Therefore every choice of distributions satisfies

\(K=\sum_{t\in T}\mu_t\sum_{P\in\operatorname{supp}(q_t)}q_t(P)k(P)\geq\sum_{t\in T}\mu_t\sum_{P\in\operatorname{supp}(q_t)}q_t(P)=1.\)

Consequently, \(B<1\) is impossible. It remains to prove that \(K=1\) is always achievable.

2. Partitions and preferred intervals

Let

\(\Delta_N=\{\ell\in\mathbb{R}_{\geq0}^{N}:\sum_{i=1}^{N}\ell_i=1\}.\)

For \(\ell\in\Delta_N\), define \(c_0=0\), \(c_i=\sum_{j=1}^{i}\ell_j\), and \(P_i(\ell)=[c_{i-1},c_i]\). These intervals partition the cake modulo endpoints. During the existence argument, we allow zero-length intervals; we will prove that the final partition has none.

For each type \(t\), write

\(v_{ti}(\ell)=V_t(P_i(\ell)).\)

Each function \(v_{ti}\) is continuous. Indeed, the cumulative valuation \(F_t(a)=\int_0^a\nu_t(x)\,dx\) is continuous, and

\(v_{ti}(\ell)=F_t(c_i)-F_t(c_{i-1}).\)

Nonnegativity and normalization give

\(v_{ti}(\ell)\geq0,\qquad \sum_{i=1}^{N}v_{ti}(\ell)=1.\)

In particular, the largest interval value for every type is at least \(1/N\). Thus a zero-length interval is never most preferred.

Define the set of most preferred indices by

\(A_t(\ell)=\{i:v_{ti}(\ell)=\max_{1\leq j\leq N}v_{tj}(\ell)\},\)

and the allowed probability vectors for type \(t\) by

\(C_t(\ell)=\{z\in\Delta_N:z_i=0\text{ whenever }i\notin A_t(\ell)\}.\)

This is a nonempty compact convex face of \(\Delta_N\). Its vectors assign positive probability only to most preferred intervals.

Define the possible aggregate recipient-mass vectors by

\(D(\ell)=\{\sum_{t\in T}\mu_t z_t:z_t\in C_t(\ell)\text{ for every }t\}.\)

Every vector in \(D(\ell)\) belongs to \(\Delta_N\), because the masses and each probability vector sum to \(1\).

3. A balanced partition exists

We use the following finite-dimensional form of Kakutani’s fixed-point theorem: if \(S\) is a nonempty compact convex subset of a Euclidean space, and a correspondence \(\Phi:S\rightrightarrows S\) has a closed graph and nonempty compact convex values, then some \(s\in S\) satisfies \(s\in\Phi(s)\). This is Theorem 1 and its corollary in [Kakutani’s original paper](https://www.math.ucdavis.edu/~deloera/TEACHING/READINGSEMINAR/PAPERS/kakutanioriginal.pdf).

We first verify the required properties.

The correspondence \(C_t\) has a closed graph. Suppose \(\ell^{(r)}\to\ell\), \(z^{(r)}\to z\), and \(z^{(r)}\in C_t(\ell^{(r)})\). If \(z_i>0\), then \(z_i^{(r)}>0\) for all sufficiently large \(r\). Hence

\(v_{ti}(\ell^{(r)})\geq v_{tj}(\ell^{(r)})\)

for every \(j\). Continuity gives the same inequalities at \(\ell\), so \(i\in A_t(\ell)\). This proves \(z\in C_t(\ell)\).

The correspondence \(D\) has nonempty compact convex values and a closed graph. Nonemptiness follows from that of each \(C_t\). Compactness follows because \(D(\ell)\) is the continuous image of the finite product of the compact sets \(C_t(\ell)\). Convexity follows by taking convex combinations of the corresponding vectors for every type.

For closedness of the graph, suppose \(\ell^{(r)}\to\ell\), \(d^{(r)}\to d\), and \(d^{(r)}\in D(\ell^{(r)})\). Choose representations

\(d^{(r)}=\sum_t\mu_t z_t^{(r)},\qquad z_t^{(r)}\in C_t(\ell^{(r)}).\)

Compactness of the finite product \((\Delta_N)^\tau\) gives a subsequence along which every \(z_t^{(r)}\) converges to some \(z_t\). Closedness of the graphs of \(C_t\) gives \(z_t\in C_t(\ell)\). Taking limits yields \(d=\sum_t\mu_t z_t\), hence \(d\in D(\ell)\).

For \(d\in\Delta_N\), define

\(R(d)=\{\ell\in\Delta_N:\ell_i=0\text{ whenever }d_i>\min_j d_j\}.\)

Thus \(R(d)\) consists of length vectors supported on indices with minimum aggregate recipient mass. It is a nonempty compact convex face. Equivalently,

\(R(d)=\{\ell\in\Delta_N:\sum_i\ell_i d_i=\min_jd_j\}.\)

This equality also proves that \(R\) has a closed graph, since both sides depend continuously on \((\ell,d)\).

Now take \(S=\Delta_N\times\Delta_N\) and define

\(\Phi(\ell,d)=R(d)\times D(\ell).\)

The domain \(S\) is nonempty, compact, and convex. The preceding checks show that \(\Phi\) has nonempty compact convex values and a closed graph. Kakutani’s theorem therefore supplies \((\ell^*,d^*)\) with

\(\ell^*\in R(d^*),\qquad d^*\in D(\ell^*).\)

We next prove that every coordinate of \(\ell^*\) is positive. Suppose \(\ell_i^*=0\) for some \(i\). That interval has zero value for every type, whereas every type has a most preferred interval of positive value. Thus every vector in \(C_t(\ell^*)\) has coordinate \(i\) equal to zero, and consequently \(d_i^*=0\). Since \(d^*\) is nonnegative, its minimum coordinate is zero.

Membership \(\ell^*\in R(d^*)\) now implies that \(d_j^*=0\) whenever \(\ell_j^*>0\). For indices with \(\ell_j^*=0\), the preceding zero-length argument also gives \(d_j^*=0\). All coordinates of \(d^*\) would therefore vanish, contradicting \(d^*\in\Delta_N\).

Hence \(\ell_i^*>0\) for every \(i\). Membership in \(R(d^*)\) then forces every coordinate of \(d^*\) to equal its minimum. Since their sum is \(1\),

\(d_i^*=1/N\qquad\text{for every }i.\)

4. Feasible distributions attaining the lower bound

Because \(d^*\in D(\ell^*)\), choose vectors \(z_t\in C_t(\ell^*)\) such that

\(\sum_t\mu_t z_{ti}=1/N\qquad\text{for every }i.\)

Use the positive-length bundles \(P_i=P_i(\ell^*)\), and set \(q_t(P_i)=z_{ti}\), omitting zero-probability entries. Each distribution has finite support of size at most \(N\).

For almost every \(x\), exactly one interval \(P_i\) contains \(x\). Therefore

\(\sum_t\mu_t\sum_jq_t(P_j)\mathbf{1}_{P_j}(x)=\sum_t\mu_t z_{ti}=1/N.\)

This proves the required pointwise feasibility.

If \(P_i\) belongs to the support of \(q_t\), then \(z_t\in C_t(\ell^*)\) implies

\(V_t(P_i)=\max_jV_t(P_j).\)

Every bundle allocated to any type is one of the \(P_j\). Thus \(V_t(P_i)\geq V_t(Q)\) for every allocated bundle \(Q\), proving all the required envy inequalities, including those within a type.

Finally, each \(P_i\) has exactly one component. Hence

\(K=\sum_t\mu_t\sum_i z_{ti}=1.\)

Together with the lower bound, this proves that the optimum is exactly \(1\).

5. Decision algorithm and running time

For the promised input class, accept exactly when \(B\geq1\). Comparing the binary-encoded numerator and denominator of \(B\), including reading the input, takes \(O(L)\) bit operations.

Thus the decision running time is \(O(L)\), with no additional dependence on \(m\), \(\tau\), or the numerical value of \(N\). In particular, expanding the population into \(N\) agents is unnecessary.

The fixed-point proof establishes existence; it does not assert an efficient algorithm for explicitly listing the distributions. That distinction does not affect this decision problem, whose answer is determined entirely by the threshold comparison.
