The continuous mirror question, as graded

Given finite house classes \(H\) with rational per-capita supplies \(q_h\), a finite set of complete utility types \(T\) with rational utilities \(u_t(h)\), and rational type masses \(\mu_t\) summing to one, compute the minimum subsidy per capita for an envy-free allocation. Each individual receives one whole house, while type mass may be split across house classes: choose \(x_{t,h}\ge 0\) with \(\sum_h x_{t,h}=\mu_t\) and \(\sum_t x_{t,h}\le q_h\). For each active type-house pair choose a common subsidy \(z_{t,h}\ge0\), require \(u_t(h)+z_{t,h}\ge u_t(h')+z_{t',h'}\) for every two active pairs \((t,h),(t',h')\), and minimize \(\sum_{t,h}x_{t,h}z_{t,h}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of \(\tau\geq1\) complete utility types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) house classes \(H\), with binary rational supplies \(q_h\geq0\) satisfying \(\sum_h q_h\geq1\), and binary rational utilities \(u_t(h)\geq0\) for every type and class. Utilities may tie.
Each individual receives one whole house; type mass may be split among classes. Choose real masses \(x_{t,h}\geq0\) with \(\sum_h x_{t,h}=\mu_t\) and \(\sum_t x_{t,h}\leq q_h\); unused supply is permitted.
A pair \((t,h)\) is active exactly when \(x_{t,h}>0\). Each active pair receives a common real subsidy \(z_{t,h}\geq0\) per individual.
An outcome is envy-free when \(u_t(h)+z_{t,h}\geq u_t(h')+z_{t',h'}\) for every ordered pair of active pairs \((t,h),(t',h')\). Unallocated houses impose no envy constraints; indifference is allowed without tie-breaking.
The subsidy per capita is \(C(x,z)=\sum_{(t,h):x_{t,h}>0}x_{t,h}z_{t,h}\). Given a binary rational threshold \(B\geq0\), the decision problem asks whether an envy-free outcome with \(C(x,z)\leq B\) exists. Let \(L\) be the total binary input length, including \(B\).

Is this continuous subsidy-threshold problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For a finite list of agents and distinct houses, minimum total subsidy and its threshold decision problem are NP-hard; optimization is polynomial-time solvable when the number of houses exceeds the number of agents by a fixed constant, or when utilities are identical. [Choo et al.](https://arxiv.org/html/2403.01162v1)
No result settling the exact continuous model above was located in the literature search.

Modeling choices made when packaging the task

  • Restricted utilities to nonnegative rationals, matching the discrete utility domain.
  • Required nonnegative supplies with total supply at least one, carrying over the requirement that there be at least as many houses as agents; zero-supply classes are harmless and permitted.
  • Made the society and house-class set nonempty and explicitly represented only positive-mass types.
  • Specified real allocation masses and subsidies, with activity defined by strictly positive mass.
  • Made explicit that unused supply generates no envy constraints and that weak envy inequalities permit ties without tie-breaking.
  • Introduced a nonnegative binary rational subsidy threshold and total input bit length to express the exact optimization question as a complexity decision problem.

The continuous subsidy-threshold problem is \(\mathrm{NP}\)-hard

1. Claim and reduction source

Theorem. The stated decision problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions, even when all input rationals are dyadic. Therefore, an algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

We reduce from Vertex Cover. The construction adapts the vertex gadgets of [Choo et al., Theorem 3.1](https://arxiv.org/html/2403.01162v1). The essential additional argument consists of subsidy lower bounds valid for arbitrary real mass allocations.

Let \(G=(V,E)\) be a simple undirected graph, and let \(k\) be the cover-size threshold. Write \(n=|V|\) and \(e=|E|\). We may restrict to instances satisfying:

  • \(n\) is a power of two and \(n\geq4\);
  • \(1\leq k\leq n-2\).

These restrictions preserve hardness. Starting from Vertex Cover instances with \(1\leq k\leq |V|\), add isolated vertices until the vertex count is a power of two at least \(|V|+2\). This preserves the answer and increases the vertex count by only a constant factor. The excluded threshold cases are immediately decidable.

Set \(N=2n^3\), \(P=n^3-e\), and \(\varepsilon=1/n^3\). Since the graph is simple, \(e\leq n(n-1)/2\), so \(P>0\).

2. The continuous instance

There are \(2n+1\) house classes:

  • one special class \(S\), with supply \(q_S=P/N\);
  • for each vertex \(v\), a good class \(G_v\), with supply \(q_{G_v}=n/N\);
  • for each vertex \(v\), a bad class \(D_v\), with supply \(q_{D_v}=n^2/N\).

There are \(1+n+e\) utility types:

  • one special type \(s\), with mass \(\mu_s=P/N\);
  • for each vertex \(v\), a vertex type \(t_v\), with mass \(\mu_{t_v}=n^2/N\);
  • for each edge \(f\), an edge type \(t_f\), with mass \(\mu_{t_f}=1/N\).

Their complete utilities are:

| Type | Special class \(S\) | Good class \(G_v\) | Bad class \(D_v\) |
|---|---|---|---|
| \(s\) | \(1\) | \(0\) | \(0\) |
| \(t_w\) | \(0\) | \(1+\varepsilon\) if \(v=w\), otherwise \(0\) | \(1\) if \(v=w\), otherwise \(0\) |
| \(t_f\), where \(f=\{a,b\}\) | \(1\) | \(1\) if \(v\in\{a,b\}\), otherwise \(0\) | \(0\) |

The subsidy threshold is \(B=k/(nN)\).

The masses sum to one because

\(\displaystyle P+n\cdot n^2+e=(n^3-e)+n^3+e=N.\)

Total supply satisfies

\(\displaystyle \sum_h q_h=\frac{P+n^2+n^3}{N}=1+\frac{n^2-e}{N}>1.\)

All masses are positive. The listed utility rows are distinct, so the support size is exactly \(\tau=1+n+e\).

For the proof, rescale allocation masses by defining \(X_{t,h}=Nx_{t,h}\). In these units, the special-type mass and special-class capacity are both \(P\); each vertex-type mass is \(n^2\); each edge-type mass is \(1\); and good and bad class capacities are \(n\) and \(n^2\).

Define the rescaled cost

\(\displaystyle W=\sum_{(t,h):X_{t,h}>0}X_{t,h}z_{t,h}=NC(x,z).\)

Activity and envy-freeness are unchanged by this rescaling. The budget condition becomes \(W\leq k/n\).

3. A vertex cover yields a feasible outcome

Suppose \(K\subseteq V\) is a vertex cover with \(|K|\leq k\).

Use the following rescaled allocation:

  • assign all special-type mass \(P\) to \(S\);
  • assign all vertex-type mass \(n^2\) of \(t_v\) to \(D_v\);
  • for every edge \(f\), choose an endpoint \(v_f\in K\cap f\) and assign its edge-type mass \(1\) to \(G_{v_f}\).

Each good class receives at most \(\deg(v)\leq n-1<n\) mass, so all supply constraints hold.

Give subsidy \(\varepsilon\) to the active pair \((t_v,D_v)\) when \(v\in K\), and subsidy zero to every other active pair.

We check all types’ envy constraints.

  • Special and edge types. Their assigned utility, including subsidy, is \(1\). They value every allocated special or good bundle at at most \(1\), since these bundles receive zero subsidy. They value every bad bundle at at most \(\varepsilon<1\).
  • Vertex types \(t_v\) with \(v\in K\). Their assigned utility is \(1+\varepsilon\). Their own good class, when active, has value \(1+\varepsilon\) and zero subsidy. Their own bad bundle also has value \(1+\varepsilon\). Every other active bundle has value at most \(\varepsilon\).
  • Vertex types \(t_v\) with \(v\notin K\). Their assigned utility is \(1\). Their own good class is unused, because edge mass is assigned only to good classes indexed by \(K\). Their own bad bundle has value \(1\); every other active bundle has value at most \(\varepsilon\).

Thus the outcome is envy-free. Its rescaled cost is

\(\displaystyle W=|K|n^2\varepsilon=\frac{|K|}{n}\leq\frac{k}{n}.\)

Consequently \(C(x,z)\leq B\).

4. A feasible outcome yields a vertex cover

Conversely, suppose an arbitrary envy-free outcome satisfies \(W\leq k/n\). The allocation masses may be arbitrary real numbers.

4.1. Some special-class mass must be allocated

The total capacity of all nonspecial classes, in rescaled units, is

\(\displaystyle \sum_{v\in V}(n+n^2)=n^2+n^3<2n^3=N.\)

Since all population mass \(N\) must be allocated, at least one active pair receives class \(S\).

Its subsidy is nonnegative. Therefore, every special or edge type values that active bundle at at least \(1\).

4.2. Active good classes form a vertex cover

Define

\(\displaystyle A=\left\{v\in V:\sum_t X_{t,G_v}>0\right\}.\)

We prove that \(A\) covers every edge.

Suppose, for contradiction, that \(f=\{a,b\}\) has neither endpoint in \(A\). Then \(G_a\) and \(G_b\) are unused.

Let

\(\displaystyle d=\sum_{h\neq S}X_{s,h}\)

be the special-type mass assigned outside \(S\). Each such active pair has intrinsic utility zero and must not envy the active special-class bundle from Section 4.1. Its subsidy is therefore at least \(1\). These pairs contribute at least \(d\) to \(W\).

The special type occupies \(P-d\) mass of \(S\). Since the capacity of \(S\) is \(P\),

\(\displaystyle \sum_{t\neq s}X_{t,S}\leq d.\)

In particular, writing \(\beta=X_{t_f,S}\), we have \(\beta\leq d\).

The remaining edge-type mass is \(1-\beta\). Because \(G_a\) and \(G_b\) are unused, this mass receives nonspecial classes of utility zero. Each active pair carrying this mass needs subsidy at least \(1\), again by comparison with the active special-class bundle.

The special-type and edge-type contributions are disjoint. Hence

\(\displaystyle W\geq d+(1-\beta)\geq1.\)

But \(W\leq k/n<1\), because \(k\leq n-2\). This contradiction proves that \(A\) is a vertex cover.

This argument allows arbitrary splitting: assigning some uncovered-edge mass to \(S\) requires displacing at least as much special-type mass, which itself incurs subsidy.

4.3. Each active good class forces a fixed subsidy lower bound

Fix \(v\in A\). Some active pair receives \(G_v\). Vertex type \(t_v\) values that bundle, including its nonnegative subsidy, at at least \(1+\varepsilon\).

Every class other than \(G_v\) has intrinsic utility at most \(1\) for \(t_v\). Thus every active pair \((t_v,h)\) with \(h\neq G_v\) must receive subsidy at least \(\varepsilon\).

Consequently, the subsidy contribution of type \(t_v\) is at least

\(\displaystyle \varepsilon\bigl(n^2-X_{t_v,G_v}\bigr)\geq\varepsilon(n^2-n),\)

where the final inequality uses the good-class capacity \(X_{t_v,G_v}\leq n\).

Summing over the distinct vertex types indexed by \(A\), and using nonnegativity of all other contributions, gives

\(\displaystyle W\geq |A|\varepsilon(n^2-n)=|A|\frac{n-1}{n^2}.\)

If \(|A|\geq k+1\), then

\(\displaystyle W\geq\frac{(k+1)(n-1)}{n^2}=\frac{k}{n}+\frac{n-k-1}{n^2}>\frac{k}{n},\)

because \(k\leq n-2\). This contradicts the budget. Therefore \(|A|\leq k\).

We have extracted a vertex cover of size at most \(k\) from every feasible continuous outcome.

5. Encoding and conclusion

The construction has \(m=2n+1\) classes and \(\tau=1+n+e\) supported types. Its complete utility table has polynomial size, and every numerical entry has \(O(\log n)\) bits.

Moreover, \(n\) is a power of two. The denominators \(N=2n^3\), \(n^3\), and \(nN\) are therefore powers of two, so all constructed masses, supplies, utilities, and the threshold are dyadic rationals.

Sections 3 and 4 prove the exact equivalence:

\(G\) has a vertex cover of size at most \(k\) if and only if the constructed continuous instance has an envy-free outcome with \(C(x,z)\leq B\).

Thus the reduction is polynomial and establishes the claimed \(\mathrm{NP}\)-hardness.
