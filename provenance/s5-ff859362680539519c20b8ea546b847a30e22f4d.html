Result

For every fixed \(\epsilon\in(0,1)\), achieving a \(1/\ell^{1-\epsilon}\)-approximation is \(\mathrm{NP}\)-hard for the precise mass-allocation model in the question. Consequently, such a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The decisive property is that fractional allocations can be rounded without losing any exactly optimal dimension. Below, I prove this property and give a direct approximation-preserving reduction from Maximum Clique.

1. The feasible marginal region

Write \(v_{igk}=v_{t_i gk}\), and define the normalized marginal
\[ \]
\(x_g=2\sum_B\lambda_{t_1,B}B_g.\)

Because the total mass of type \(t_1\) is \(1/2\), we have \(0\leq x_g\leq1\). The supply constraint gives
\(2\sum_B\lambda_{t_2,B}B_g=1-x_g.\)
Therefore welfare depends only on \(x\):
\(W_k(x)=\frac12\sum_{g\in G}\bigl(v_{1gk}x_g+v_{2gk}(1-x_g)\bigr).\)

Every point \(x\in[0,1]^G\) is feasible. To prove this, let \(u\) range uniformly over \([0,1]\), and define
\(B(u)=\{g\in G:u<x_g\}.\)
Give type \(t_1\) the distribution of \(B(u)\), scaled by \(1/2\), and type \(t_2\) the distribution of its complement, also scaled by \(1/2\). These are finite bundle distributions: the bundle changes only at the coordinate values \(x_g\), so each type uses at most \(m+1\) bundles.

Each type has total mass \(1/2\). Moreover,
\(\sum_B\lambda_{t_1,B}B_g=\frac12\Pr(u<x_g)=x_g/2,\)
and the corresponding type-\(t_2\) marginal is \((1-x_g)/2\). Their sum is the required supply \(1/2\).

For rational \(x\), the masses are half the lengths of intervals between successive coordinate values and endpoints. Thus this construction gives a rational, polynomial-size allocation. It uses precisely the permitted bundle domain, including the empty bundle.

2. Exact optimality forces endpoint marginals

Since the marginal region is the entire cube and welfare separates over categories,
\(U_k^*=\frac12\sum_{g\in G}\max\{v_{1gk},v_{2gk}\}.\)

Define
\(P_k=\{g:v_{1gk}=1,\ v_{2gk}=0\}\)
and
\(N_k=\{g:v_{1gk}=0,\ v_{2gk}=1\}.\)
Categories with equal valuations contribute the same welfare regardless of their marginal.

Subtracting welfare from its optimum gives
\(U_k^*-W_k(x)=\frac12\left(\sum_{g\in P_k}(1-x_g)+\sum_{g\in N_k}x_g\right).\)

Every summand is nonnegative. Consequently,
\(W_k(x)=U_k^*\)
holds if and only if
\(x_g=1\) for every \(g\in P_k\), and
\(x_g=0\) for every \(g\in N_k\).

This equivalence uses exact equality, as required by the task.

Rounding lemma. For any feasible marginal vector \(x\), define \(y_g=1\) when \(x_g\geq1/2\), and \(y_g=0\) otherwise. Every dimension optimal at \(x\) remains optimal at \(y\).

Indeed, rounding preserves every coordinate already equal to \(0\) or \(1\), and these are precisely the requirements of an optimal dimension. Hence \(F(y)\geq F(x)\).

The rounded allocation has just one bundle per type: give mass \(1/2\) of type \(t_1\) bundle \(\{g:y_g=1\}\), and mass \(1/2\) of type \(t_2\) its complement. Every category then has consumption \(1/2\).

Thus the continuous optimum equals the optimum over these two-bundle allocations. In particular, copying the valuations of any two-agent discrete instance preserves its optimum number of optimal dimensions; discrete welfare and its dimensionwise optimum are both scaled by \(1/2\). This rigorously transfers the stated discrete hardness result, whose two-agent binary restriction is verified in [Theorem 6 of the cited paper](https://arxiv.org/html/2606.21346v1).

3. A direct reduction from Maximum Clique

The following reduction independently establishes the claimed hardness.

Let \(H\) be a simple graph with vertex set \([n]\), where \(n\geq1\). Write \(\omega(H)\) for its maximum clique size.

Construct a society as follows:

  • Set \(\ell=n\), with one dimension per vertex.
  • Introduce one category \(g_{ab}\) for every nonedge \(\{a,b\}\), oriented with \(a<b\).
  • Add one dummy category so that \(m\geq1\).
  • Keep exactly the two specified types, each of mass \(1/2\), and supply \(1/2\) for every category.
  • Set every dummy-category valuation to zero.
  • For category \(g_{ab}\), set

\((v_{1,g_{ab},a},v_{2,g_{ab},a})=(1,0)\)
and
\((v_{1,g_{ab},b},v_{2,g_{ab},b})=(0,1)\).
Set both valuations to zero in every other dimension.

All valuations are binary.

3.1 Every allocation yields a clique

For a feasible allocation with marginals \(x\), let
\(S(x)=\{k:W_k(x)=U_k^*\}.\)

For a nonedge \(\{a,b\}\) with \(a<b\), optimality of dimension \(a\) requires \(x_{g_{ab}}=1\), whereas optimality of dimension \(b\) requires \(x_{g_{ab}}=0\). Both cannot hold.

Therefore no nonedge has both endpoints in \(S(x)\). Hence \(S(x)\) is a clique, and
\(F(x)=|S(x)|\leq\omega(H).\)

This argument applies to arbitrary real allocations.

3.2 Every clique yields an allocation

Let \(C\) be any clique of \(H\). For each nonedge \(\{a,b\}\), with \(a<b\), choose:

  • \(x_{g_{ab}}=1\) if \(a\in C\);
  • \(x_{g_{ab}}=0\) if \(b\in C\);
  • \(x_{g_{ab}}=0\) if neither endpoint belongs to \(C\).

These rules are consistent because a clique cannot contain both endpoints of a nonedge. Set the dummy marginal to zero.

Every dimension in \(C\) now satisfies all its endpoint requirements. The corresponding complementary-bundle allocation is feasible and has \(F(x)\geq|C|\).

Applying this construction to a maximum clique and combining it with the preceding upper bound proves
\(\operatorname{OPT}(I(H))=\omega(H).\)

3.3 The approximation factor is preserved

Fix \(\epsilon\in(0,1)\). Suppose a polynomial-time algorithm always returned a feasible allocation satisfying
\(F(x)\geq\operatorname{OPT}(I)/\ell^{1-\epsilon}.\)

On the constructed instance, its optimal dimensions form a clique of size
\(|S(x)|=F(x)\geq\omega(H)/n^{1-\epsilon}.\)

Extracting this clique requires only evaluating the endpoint requirements. Thus the algorithm would approximate Maximum Clique within the same factor. This is \(\mathrm{NP}\)-hard by [Zuckerman’s Theorem 1.1](https://theoryofcomputing.org/articles/v003a006/v003a006.pdf), which applies to unrestricted simple graphs on \(n\) vertices for every fixed positive \(\epsilon\).

The parameter needed by that theorem is preserved exactly: \(\ell=n\).

4. Encoding, running times, and the elementary approximation

The reduction has
\(\tau=2,\quad \ell=n,\quad m=1+|\{\text{nonedges of }H\}|\leq1+\binom n2.\)
Its explicit valuation table contains \(m\tau\ell\) binary entries. All mass and supply encodings have constant bit length. The instance has \(L=O(n^3\log(n+2))\) under a conventional explicit encoding and can be constructed in polynomial time in that bound.

In the standard bit model, an algorithm outputs an exact finite representation, such as a list of nonzero rational masses and their bundles, or rational marginals. Computing marginals and checking endpoint requirements takes polynomial time in the input and output lengths. A polynomial-time algorithm necessarily has polynomial-length output. Conversely, rational marginals admit the polynomial-size bundle realization proved above, so the implicit bundle domain creates no representation obstruction.

For completeness, the continuous problem also admits the elementary \(c/\ell\) guarantee for every fixed positive integer \(c\), when \(\ell\geq c\).

A subset \(S\) of dimensions can be optimized simultaneously exactly when no category is required to have marginal both \(0\) and \(1\). Necessity follows from the endpoint characterization. For sufficiency, choose the required endpoint at every constrained category, choose either endpoint elsewhere, and use the complementary-bundle allocation.

Enumerate all subsets of dimensions of size at most \(\min\{c,\ell\}\), test this condition, and realize a largest feasible subset. If the optimum is \(r\), this finds at least \(\min\{c,r\}\) optimal dimensions: take that many dimensions from an optimal solution.

The guarantee is therefore \(\min\{1,c/\ell\}\). The number of subsets tested is at most \((\ell+1)^c\), and each test uses at most \(mc\) endpoint checks after reading the valuation table. A conservative bit-time bound is
\(O\!\left((L+m\tau\ell+mc(\ell+1)^c)^2\right),\)
which is polynomial for fixed \(c\). The returned allocation uses one bundle per type.
