The anchor (named result in the paper)

Theorem 2.1 — class: other

The continuous mirror question, as graded

Given a finite anonymous typed TU game with type set \(T=\operatorname{supp}(\mu)\), rational masses \(\mu_t>0\) summing to \(1\), normalized grand worth \(W\), and per-unit grand-marginal contributions \(b_t\), find \(x\in\mathbb R^T\) minimizing \(\sum_{t\in T}\mu_t(b_t-x_t)^2\) subject to \(\sum_{t\in T}\mu_t x_t=W\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\geq 1\) types \(T\) with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input additionally supplies signed binary rationals \(W\) and \(b_t\): the grand worth per unit of total mass and the grand-marginal contribution per unit of type \(t\), respectively. These are supplied data, with no coalition-worth oracle or derivative computation required.
An allocation \(x\in\mathbb R^T\) specifies a common payoff per unit of each type. Feasibility requires only \(\sum_{t\in T}\mu_t x_t=W\); there are no sign, individual-rationality, or coalitional constraints.
Find an exact minimizer of \(\sum_{t\in T}\mu_t(b_t-x_t)^2\) over feasible allocations. Let \(L\) be the total input bit length; running times are measured in \(\tau\) and \(L\). There is no separate \(m\) parameter.

Is this exact minimization problem solvable in polynomial time in \(\tau\) and \(L\), or is it \(\mathrm{NP}\)-hard?

For finite TU games, minimizing the unweighted sum of squared deviations from individual grand-marginal contributions over efficient allocations has a unique minimizer, the ENSC value ([Sun, 2019](https://doi.org/10.3990/1.9789036547192)).
No result addressing exactly the support-encoded continuous formulation above was identified in the literature search.

Modeling choices made when packaging the task

  • The encoding and signs of W and b_t were unspecified; they are explicitly supplied signed binary rationals, consistent with unrestricted TU worths.
  • Per-unit grand-marginal contributions have no specified continuous game representation; b_t are treated as supplied numerical data rather than quantities to derive from an unspecified worth function.
  • Normalization is by total mass: W is grand worth per unit of total mass, not necessarily equal to one.
  • The feasible domain retains only efficiency and unrestricted real payoffs, as in the discrete anchor.
  • The computational model is exact binary computation with total input bit length L; this formulation has no separate m parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Exact minimizer

The problem is solvable exactly in polynomial time in \(\tau\) and \(L\).

Define the mass-weighted mean of the supplied contributions by
\[ B=\sum_{t\in T}\mu_t b_t. \]
The unique minimizer is
\[ x_t^*=b_t+W-B \qquad(t\in T), \]
and the minimum objective value is \((W-B)^2\).

Proof of existence and uniqueness

Write \(c=W-B\). Since \(\sum_{t\in T}\mu_t=1\), the proposed allocation is feasible:
\[ \sum_{t\in T}\mu_t x_t^* =\sum_{t\in T}\mu_t(b_t+c) =B+c=W. \]

Now let \(x\) be any feasible allocation, and define \(z_t=x_t-x_t^*\). Feasibility of both allocations implies
\[ \sum_{t\in T}\mu_t z_t=0. \]
Also, \(b_t-x_t=-c-z_t\). Expanding the objective therefore gives
\[ \begin{aligned} \sum_{t\in T}\mu_t(b_t-x_t)^2 &=\sum_{t\in T}\mu_t(c+z_t)^2\\ &=c^2\sum_{t\in T}\mu_t +2c\sum_{t\in T}\mu_t z_t +\sum_{t\in T}\mu_t z_t^2\\ &=c^2+\sum_{t\in T}\mu_t z_t^2. \end{aligned} \]
The final sum is nonnegative. Because every supported type has strictly positive mass, it equals zero precisely when every \(z_t=0\). Thus \(x^*\) is the unique minimizer, with objective value \(c^2\). This argument covers every \(\tau\geq 1\) and all signed values of \(W\) and \(b_t\).

Exact computation and bit complexity

For completeness, the algorithm works even for general binary-encoded rationals, not only dyadic rationals. Write the input as \(\mu_t=p_t/q_t\), \(b_t=r_t/s_t\), and \(W=u/v\), with positive integer denominators and signed integer numerators where appropriate.

Choose the common denominator
\[ D=v\prod_{t\in T}q_t s_t. \]
Every \(q_t s_t\), every \(s_t\), and \(v\) divides \(D\). Hence the following computations use integer arithmetic:
\[ N=\sum_{t\in T}p_t r_t\frac{D}{q_t s_t}, \qquad A_t=r_t\frac{D}{s_t}+u\frac{D}{v}-N. \]
They satisfy \(B=N/D\) and \(x_t^*=A_t/D\), so the output is exact.

The bit length of \(D\) is \(O(L)\), because it is a product of denominators whose total encoding length is at most \(L\). Each summand defining \(N\) has \(O(L)\) bits; summing \(\tau\) such integers produces \(O(L+\log\tau)\) bits. The same bound holds for every \(A_t\) and all intermediate integers.

Computing \(D\), \(N\), and all \(A_t\) requires \(O(\tau)\) integer arithmetic operations on numbers of polynomially bounded bit length. Standard integer multiplication and division therefore give polynomial running time in \(\tau\) and \(L\). Fractions may be output unreduced, or reduced using polynomial-time greatest-common-divisor computations.

Thus the supplied-data, support-encoded formulation has an explicit rational solution computable in polynomial time; no coalition-worth information is required.
