The continuous mirror question, as graded

Given rational type data \(T\) with \(|T|=\tau\), masses \(\mu_t\), repeated-agent columns \(a_t\), objective coefficients \(v_t\), and population-scaled resources \(b\), define \(Z^\ast=\arg\max\{\sum_{t\in T}v_tz_t:\sum_{t\in T}a_tz_t\le b,\ 0\le z_t\le\mu_t\}\). Compute \(Y_\infty=\{t:z_t=\mu_t\ \forall z\in Z^\ast\}\), \(N_\infty=\{t:z_t=0\ \forall z\in Z^\ast\}\), and \(M_\infty=T\setminus(Y_\infty\cup N_\infty)\), with an exact complexity bound.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
For \(m\ge1\), each type has a column \(a_t\in\mathbb Q^m\) and objective coefficient \(v_t\in\mathbb Q\); the resource vector \(b\in\mathbb Q^m\) is expressed per unit population. These coefficients may have either sign. Let \(L\) be the total binary encoding length.
A selection assigns a divisible mass \(z_t\in[0,\mu_t]\) to each type, subject to \(\sum_{t\in T}a_tz_t\le b\), componentwise. Assume this feasible region is nonempty; there are no auxiliary decision variables.
Define \(Z^\ast=\operatorname*{arg\,max}\{\sum_{t\in T}v_tz_t:\sum_{t\in T}a_tz_t\le b,\ 0\le z_t\le\mu_t\}\), retaining all maximizers.
Define \(Y_\infty=\{t\in T:\forall z\in Z^\ast,\ z_t=\mu_t\}\), \(N_\infty=\{t\in T:\forall z\in Z^\ast,\ z_t=0\}\), and \(M_\infty=T\setminus(Y_\infty\cup N_\infty)\). A type whose selected mass is fixed strictly between its bounds belongs to \(M_\infty\).

Is exact computation of \((Y_\infty,N_\infty,M_\infty)\) polynomial-time solvable, or is it NP-hard? State the running-time bound in \(m,\tau,L\).

For discrete binary-agent integer programs with an attained optimum, the always-selected, never-selected, and sometimes-selected partition can be computed using at most \(n+1\) integer-program solves, each adding at most one constraint; this is an oracle bound, not a polynomial-time guarantee ([source](https://doi.org/10.1016/j.ejor.2024.08.023)).
No result specifically addressing this mass-based partition problem was located in the literature search.

  • Defined m as the number of resource constraints and L as the total binary encoding length; allowed arbitrary signed rational columns, objective coefficients, and resource bounds, matching the unrestricted discrete coefficient domains.
  • Promised a nonempty feasible region, excluding vacuous classifications when there are no optimal solutions.
  • Retained the graded formulation's absence of auxiliary decision variables rather than importing auxiliary integer variables from the broader discrete model.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Exact computation of \((Y_\infty,N_\infty,M_\infty)\) is polynomial-time solvable. An algorithm uses at most \(\tau+1\) exact rational linear-programming solves, each with \(\tau\) variables and at most \(m+2\tau+1\) inequalities. Its running time is

\[ (\tau+1)\operatorname{poly}(m+\tau,\tau L+\tau^2) =\operatorname{poly}(m,\tau,L) \]

bit operations. This is a polynomial bound in the binary encoding length; no strongly polynomial bound is asserted.

Algorithm and correctness

Write \(A\) for the matrix whose columns are \(a_t\), and define the feasible polytope

\(P=\{z\in\mathbb R^\tau:Az\le b,\ 0\le z_t\le\mu_t\text{ for every }t\in T\}\).

By hypothesis, \(P\) is nonempty. It is closed and bounded, so it is compact. Consequently, the objective attains its maximum, and every coordinate minimum or maximum over the optimal set also exists.

First solve the original LP exactly, obtaining an optimal solution \(z^0\) and its objective value \(q=v^\top z^0\). Define

\(F=\{z\in P:v^\top z\ge q\}\).

Every point of \(P\) satisfies \(v^\top z\le q\), by the definition of \(q\). Thus \(F=Z^\ast\). In particular, the optimal set can be specified by adding one inequality to the original constraints.

Process each type \(t\) as follows.

  • If \(0<z_t^0<\mu_t\), assign \(t\) to \(M_\infty\).

The solution \(z^0\) itself disproves both “every optimum selects the full mass” and “every optimum selects zero.”

  • If \(z_t^0=\mu_t\), solve

\(\ell_t=\min\{z_t:z\in F\}\).

If \(\ell_t=\mu_t\), assign \(t\) to \(Y_\infty\); otherwise assign it to \(M_\infty\). Indeed, all feasible coordinates satisfy \(z_t\le\mu_t\), so \(\ell_t=\mu_t\) holds exactly when every optimum has \(z_t=\mu_t\). If \(\ell_t<\mu_t\), an optimum attaining this minimum disproves membership in \(Y_\infty\), while \(z_t^0=\mu_t>0\) disproves membership in \(N_\infty\).

  • If \(z_t^0=0\), solve

\(u_t=\max\{z_t:z\in F\}\).

If \(u_t=0\), assign \(t\) to \(N_\infty\); otherwise assign it to \(M_\infty\). Since every feasible coordinate is nonnegative, \(u_t=0\) holds exactly when every optimum has \(z_t=0\). If \(u_t>0\), an optimum attaining this maximum disproves membership in \(N_\infty\), while \(z_t^0=0<\mu_t\) disproves membership in \(Y_\infty\).

Because \(\mu_t>0\), these three cases are disjoint and exhaustive. This proves correctness, including the case of a coordinate fixed strictly between its bounds.

There is one initial solve and at most one additional solve per supported type, giving at most \(\tau+1\) solves. No auxiliary variables are needed.

Exactness and encoding length

The standard exact rational LP theorem supplies a deterministic algorithm that returns an exact rational optimum in time polynomial in the number of variables, number of constraints, and total binary encoding length. It applies to arbitrary rational coefficients and does not require a full-dimensional feasible region. Exact polynomial-time rational LP methods are described in [Gleixner and Steffy, Section 1.3](https://optimization-online.org/wp-content/uploads/2019/12/7507.pdf).

We must also check that encoding \(q\) does not make the auxiliary LPs exponentially large.

Let \(D\) be the product of the positive denominators of all input coefficients. Since their total encoding length is \(L\), both \(D\) and every input coefficient multiplied by \(D\) have \(O(L)\) bits.

A linear objective on a nonempty compact polytope has an optimal vertex \(z^\ast\). This remains true when the polytope has lower dimension: its nonempty optimal face has an extreme point, and an extreme point of that face is an extreme point of \(P\).

At a vertex, the active constraint normals span \(\mathbb R^\tau\). Otherwise, a nonzero vector orthogonal to every active normal would permit sufficiently small feasible perturbations in both directions, contradicting extremality. Select \(\tau\) independent active constraints and multiply them by \(D\). They give

\(Hz^\ast=h\),

where \(H\) is a nonsingular integer matrix and all entries of \(H\) and \(h\) have \(O(L)\) bits. By Cramer’s rule,

\(z_t^\ast=\det(H_t)/\det(H)\),

where \(H_t\) replaces the corresponding column of \(H\) by \(h\). Hadamard’s inequality bounds the bit length of each determinant by

\(O\bigl(\tau(L+\log(\tau+1))\bigr)\).

Writing \(v_t=c_t/D\), we therefore have

\(q=v^\top z^\ast=\dfrac{\sum_{t\in T}c_t\det(H_t)}{D\det(H)}\).

Its numerator and denominator also have \(O\bigl(\tau(L+\log(\tau+1))\bigr)\) bits. Hence \(q\) has polynomial encoding length.

Each auxiliary LP has \(\tau\) variables, \(m+2\tau+1\) inequalities, and total encoding length \(O(\tau L+\tau^2)\); the latter bound allows dense encoding of the box constraints. All required equalities and inequalities between rational outputs can be tested exactly in polynomial time. Applying the exact LP theorem to these polynomially sized instances proves the stated running-time bound.

Conclusion

The mass-based partition is polynomial-time computable because divisibility makes both the original optimization and every partition test rational linear programs. The argument requires no sign restrictions on \(A\), \(b\), or \(v\).
