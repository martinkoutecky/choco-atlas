The continuous mirror question, as graded

Given a project set \(P\), \(d\) resource costs \(c_k(p)\), budgets \(b_k\), and an explicitly listed support of \(\tau\) approval types \(A_t\subseteq P\) with binary rational masses \(\mu_t\ge0\) summing to \(1\), find a feasible indivisible project set \(S\subseteq P\) maximizing \(\sum_t \mu_t |A_t\cap S|\), subject to \(\sum_{p\in S}c_k(p)\le b_k\) for every resource \(k\). In particular, classify the complexity of its threshold decision version when \(d\) is part of the input.

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a set of \(m\ge1\) indivisible projects and let \(d\ge1\) be the number of resources, supplied as part of the input. Costs \(c_k(p)\) are nonnegative integers and budgets \(b_k\) are positive integers, all encoded in binary; every project has positive cost for at least one resource.
A society is given by its support: the list of its \(\tau\) distinct approval types \(A_t\subseteq P\) with positive binary rational masses \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval sets.
A set \(S\subseteq P\), possibly empty, is feasible if \(\sum_{p\in S}c_k(p)\le b_k\) for every resource \(k\). Its approval score is \(u(S)=\sum_{t=1}^{\tau}\mu_t|A_t\cap S|\).
Given also a nonnegative binary rational threshold \(q\), decide whether some feasible \(S\) satisfies \(u(S)\ge q\). Let \(L\) be the total input bit length; state running times in \(m,\tau,d,L\).

Is this threshold decision problem solvable in polynomial time, or is it NP-hard, when \(d\) is part of the input?

For finite, explicitly listed voters, the corresponding approval-score threshold problem is strongly NP-hard when the number of resources is part of the input. For each fixed number of resources, maximum approval score can be computed in pseudopolynomial time.

Modeling choices made when packaging the task

  • Specified binary-encoded nonnegative integer costs, positive integer budgets, and a positive cost in at least one resource for every project, following the discrete scenario definition.
  • Removed zero-mass entries and merged duplicate approval sets so that the listed types constitute the positive-mass support.
  • Specified a nonnegative binary rational threshold, matching the rational normalized approval scores.
  • Allowed the empty selected set, following the discrete threshold problem's feasibility definition rather than the inconsistent nonempty-output requirement for mechanisms.
  • Specified positive numbers of projects and resources and defined L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is NP-complete, and is strongly NP-hard even when \(\tau=1\), every project is approved, every cost belongs to \(\{0,1\}\), and every budget equals \(1\). Thus it has no polynomial-time algorithm unless \(\mathrm{P}=\mathrm{NP}\).

Membership in \(\mathrm{NP}\). A certificate is a subset \(S\subseteq P\), represented by \(m\) bits. Its feasibility can be checked by summing its costs for each of the \(d\) resources.

To verify the score exactly, write \(\mu_t=a_t/h_t\) and \(q=a_q/h_q\), with positive integer denominators. Let
\[ D=h_q\prod_{t=1}^{\tau}h_t, \qquad n_t=|A_t\cap S|. \]
Then the score condition is equivalent to the integer inequality
\[ \sum_{t=1}^{\tau}n_ta_t(D/h_t)\ge a_q(D/h_q). \]
The bit length of \(D\) is at most the sum of the input denominators’ bit lengths, hence is \(O(L)\). All integers in this calculation have \(O(L)\) bits: multiplication adds bit lengths, while summing \(\tau\) terms adds at most \(O(\log\tau)\) bits.

Using ordinary binary arithmetic, certificate verification therefore takes
\[ O\bigl((md+m\tau)L+(\tau+1)L^2\bigr) \]
bit operations. This is polynomial in the input length, proving membership in \(\mathrm{NP}\).

Hardness with one approval type. We reduce from the standard NP-complete problem \(3\)-SAT, restricted to formulas with exactly three literal occurrences per clause and at least one clause.

Let the formula have clauses \(C_1,\ldots,C_r\). Construct a graph \(G=(V,E)\) as follows:

  • Each literal occurrence is a separate vertex, so \(|V|=3r\).
  • Join every pair of distinct vertices belonging to the same clause.
  • Join every pair of vertices whose literals are complementary, meaning \(x\) and \(\neg x\) for the same variable.

Duplicate edges are retained only once. Now construct the project instance:

  • There is one project \(p_v\) for each vertex \(v\), so \(m=3r\).
  • There is one resource for each edge \(e\), so \(d=|E|\).
  • For resource \(e\), set \(b_e=1\), and set \(c_e(p_v)=1\) when \(v\) is an endpoint of \(e\), and \(c_e(p_v)=0\) otherwise.
  • Set \(\tau=1\), \(A_1=P\), \(\mu_1=1\), and \(q=r\).

Every vertex has the other two vertices of its clause as neighbors. Consequently, every project has positive cost for at least one resource, as required. Moreover, \(d\ge1\), all budgets are positive, and the single approval mass is positive and sums to \(1\).

For any subset \(S\subseteq P\), the resource corresponding to an edge \(e=\{v,w\}\) imposes
\[ \mathbf{1}_{p_v\in S}+\mathbf{1}_{p_w\in S}\le1. \]
Thus \(S\) is feasible exactly when its corresponding vertices form an independent set in \(G\). Since every project is approved, \(u(S)=|S|\).

We now prove the equivalence with satisfiability.

If the formula is satisfiable, choose one true literal occurrence from each clause. No two chosen occurrences belong to the same clause. Also, two literals that are simultaneously true cannot be complementary. The chosen vertices therefore form an independent set of size \(r\), yielding a feasible set with score \(r\).

Conversely, suppose a feasible set has score at least \(r\). The three vertices of each clause form a clique, so an independent set contains at most one vertex from each clause. Since there are \(r\) clauses, the selected set must contain exactly one occurrence from every clause. No two selected literals are complementary. Assign each variable appearing among these selected literals the value that makes its selected literal true; the absence of complementary selected literals makes this assignment consistent. Assign the remaining variables arbitrarily. Every clause contains its selected true literal, so the formula is satisfied.

The construction is polynomial: \(m=3r\), \(d\le\binom{3r}{2}\), and the explicitly written cost matrix has \(md=O(r^3)\) entries. This proves NP-hardness, and together with membership proves NP-completeness.

Strength of the result. In the reduction, costs are \(0\) or \(1\), budgets and the mass equal \(1\), and the threshold is \(r=m/3\). Encoding all numerical values in unary would still leave a polynomial-size reduction. Hence the hardness is strong and already holds for support size \(\tau=1\). The explicit-support representation therefore does not remove the hardness caused by allowing the number of resources to vary.
