The continuous mirror question, as graded

Given a candidate set \(C\) and a rational distribution \(\mu\) over weak orders on \(C\), listed by its \(\tau\) positive-mass types, does there exist an axis \(A\) such that every type \(v\) with \(\mu_v>0\) is existentially single-peaked with respect to \(A\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set with \(m=|C|\). Each type is a weak order on \(C\), represented by its ordered indifference classes.
A society is given by its support: the list of the \(\tau\) distinct types with positive mass, each with its mass as a binary rational. Require \(\sum_v\mu_v=1\); \(\tau\) is the support size, not the number of possible weak orders. Let \(L\) be the total input bit length.
An axis \(A\) is a total order on \(C\). A type \(v\) is existentially single-peaked on \(A\) if some strict total preference order obtained by breaking its ties, preserving every strict comparison, is single-peaked on \(A\). Tie-breaking may differ between types.
The decision problem asks whether one axis \(A\) makes every supported type existentially single-peaked.

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite explicitly listed profiles, existential single-peaked consistency for weak orders is in \(\mathrm{P}\), without requiring a guiding total order.
Single-peaked consistency for finite profiles of strict total orders is also in \(\mathrm{P}\).

Modeling choices made when packaging the task

  • Require a nonempty candidate set so that ordinary single-peaked preferences have a peak; allow a single candidate.
  • Make the distribution normalization explicit: all listed masses are positive binary rationals and sum to one.
  • Specify weak orders by ordered indifference classes and define L as the total input bit length.
  • Clarify that an extension breaks ties while preserving strict comparisons, and that each type may choose its own extension on the common axis.

Result

The decision problem is solvable in polynomial time in \(m,\tau,L\). The support is already an explicitly listed finite profile; the masses do not affect which axes are feasible.

Reduction and correctness

Write the input society as \(S=((v_1,\mu_1),\ldots,(v_\tau,\mu_\tau))\), with every \(\mu_i>0\). Construct the unweighted profile \(P=(v_1,\ldots,v_\tau)\), containing exactly one occurrence of each supported type.

For a weak order \(v\), define \(\mathcal A(v)\) to be the set of axes on which some strict refinement of \(v\), preserving every strict comparison, is single-peaked. By the definition in the question, the feasible axes for \(S\) are exactly \(\bigcap_{i=1}^{\tau}\mathcal A(v_i)\).

The feasible axes for \(P\) are the same intersection. Consequently, \(S\) is a yes-instance if and only if \(P\) is existentially single-peaked consistent. This equivalence preserves the freedom to break ties differently for different types: both problems ask for one common axis and a separately chosen strict refinement of each \(v_i\).

Now apply the polynomial-time algorithm for explicitly listed weak-order profiles supplied in the premises. Its hypotheses hold: \(P\) is finite, each preference is a weak order on the same candidate set, and the required notion is existential single-peakedness. No guiding total order is needed. This is also the result established by Fitzsimmons, Corollary 15. [Single-Peaked Consistency for Weak Orders Is Easy](https://mathcs.holycross.edu/~zfitzsim/papers/single-peaked-tark15.pdf).

Encoding and running time

Constructing \(P\) requires only copying the preference portion of the input. Its encoding length is at most \(L\), up to ordinary encoding overhead. Thus the reduction and the finite-profile recognition algorithm together take polynomial time in \(m,\tau,L\).

If input validity must also be checked, the rational masses cause no difficulty. Write \(\mu_i=a_i/b_i\), with positive integer denominators, and let \(D=\prod_{i=1}^{\tau}b_i\). The bit length of \(D\) is at most the sum of the denominator bit lengths, hence is \(O(L)\). Positivity and normalization can therefore be checked using polynomial-time integer arithmetic, with normalization equivalent to \(\sum_{i=1}^{\tau}a_i(D/b_i)=D\).

No voter expansion according to the masses is required. Even if a common denominator is numerically enormous, each supported weak order contributes exactly one feasibility constraint. This proves polynomial-time solvability for the stated support representation.
