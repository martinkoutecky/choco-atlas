The continuous mirror question, as graded

Given finite type supports \(T_L,T_R\), positive rational masses \(\mu_t\) summing to one on each side, satisfaction values \(s_t(u)\), and a welfare threshold \(\Gamma\), is there a nonnegative flow \(x_{tu}\) with \(\sum_u x_{tu}\le\mu_t\) and \(\sum_t x_{tu}\le\mu_u\), such that each type receives a common per-capita mix, \(U_t=\sum_u s_t(u)x_{tu}/\mu_t\), and for every acceptable pair \(t,u\), \(U_t\ge s_t(u)\) or \(U_u\ge s_u(t)\), while \(\sum_{t\in T_L\cup T_R}\mu_tU_t\ge\Gamma\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: disjoint nonempty lists \(T_L,T_R\) of types with positive binary rational masses \(\mu_v\), summing to \(1\) on each side. Let \(\tau=|T_L|+|T_R|\) be the support size, not the number of possible types.
Satisfactions \(s_v(w)\) are nonnegative binary rationals for opposite-side types. Define \(E=\{(t,u)\in T_L\times T_R:s_t(u)>0\text{ or }s_u(t)>0\}\); every type has an acceptable neighbor. For each type, satisfaction values on its acceptable neighbors are pairwise distinct (strict preferences).
The input also includes \(\Gamma\in\mathbb Q_{\ge0}\). Set \(m=|E|\), and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
An allocation is a real flow \(x_{tu}\ge0\) supported on \(E\), with \(\sum_u x_{tu}\le\mu_t\) and \(\sum_t x_{tu}\le\mu_u\). Every individual of a type receives the same per-capita mix; unmatched mass contributes zero utility.
Define \(U_t=\mu_t^{-1}\sum_u s_t(u)x_{tu}\) and \(U_u=\mu_u^{-1}\sum_t s_u(t)x_{tu}\). Cardinal stability means \(U_t\ge s_t(u)\) or \(U_u\ge s_u(t)\) for every \((t,u)\in E\); equality prevents blocking.
The decision problem asks whether such a stable allocation satisfies \(\sum_{v\in T_L\cup T_R}\mu_vU_v\ge\Gamma\).

Is this continuous welfare-threshold decision problem in \(\mathsf P\), or is it \(\mathsf{NP}\)-hard?

For finite lists of unit-capacity agents, the corresponding cardinally stable fractional-matching welfare decision problem is NP-complete even in bipartite markets with strict preferences ([Chen, Roy, and Sorge](https://www.ijcai.org/proceedings/2021/0013.pdf)).
No result settling the exact mass formulation above was identified in the literature search.

Modeling choices made when packaging the task

  • Specified nonnegative binary rational satisfactions and a nonnegative binary rational welfare threshold.
  • Defined acceptability by positivity of at least one endpoint's satisfaction, excluded isolated types, and restricted flow to acceptable pairs.
  • Carried over the anchor's strict-preference restriction: each type has distinct satisfaction values on its acceptable neighbors.
  • Specified real-valued flows and zero utility from unmatched mass.
  • Defined m as the number of acceptable type pairs and L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is \(\mathsf{NP}\)-complete. Hardness holds even when every type has the same mass and that mass is a reciprocal power of two.

1. The source problem.

We use Chen, Roy, and Sorge’s Theorem 5.7: deciding whether a bipartite instance with strict preferences admits a cardinally stable fractional matching of welfare at least a given threshold is \(\mathsf{NP}\)-complete. Their hardness construction uses integer satisfactions and an integer threshold. Their definitions also require no isolated vertices and define acceptability by positivity of at least one directed satisfaction, exactly as in the present task. [Chen, Roy, and Sorge, Sections 2 and 5](https://www.ijcai.org/proceedings/2021/0013.pdf).

Write a source instance as follows:

  • Its disjoint agent sets are \(A,B\), and its acceptable edge set is \(F\).
  • Its satisfaction function is \(s\), and its welfare threshold is \(\gamma\).
  • A fractional matching \(y\) satisfies \(y_e\ge 0\) and \(\sum_{e\ni v}y_e\le 1\).
  • Its utilities and welfare are \(V_v(y)=\sum_{w:\{v,w\}\in F}s_v(w)y_{vw}\) and \(W(y)=\sum_v V_v(y)\).
  • Cardinal stability requires \(V_a(y)\ge s_a(b)\) or \(V_b(y)\ge s_b(a)\) for each acceptable pair.

Let \(N=|A|+|B|\) and \(r=|F|\).

2. Construction of a normalized society.

First take two disjoint copies of the source instance, exchanging the sides in the second copy. Thus the first copy has sides \(A,B\), while the second has sides \(B',A'\). Every directed satisfaction is copied without changing its value. Together, these copies have exactly \(N\) types on each side.

Let \(q=2^{\lceil\log_2 N\rceil}\) and \(h=q-N\). Add \(h\) disjoint dummy pairs, each consisting of one new left type and one new right type. Each dummy type has satisfaction \(1\) toward its partner. All satisfactions between different components are zero.

There are now exactly \(q\) types on each side. Set

\(\mu_v=1/q\)

for every type, and set the target threshold to

\(\Gamma=(2\gamma+2h)/q.\)

This is a valid instance:

  • Every mass is positive, dyadic, and the masses sum to \(1\) on each side.
  • Every type has an acceptable neighbor.
  • Original types retain exactly their original acceptable neighbors and strict preferences.
  • Dummy types have one acceptable neighbor, so their preferences are strict.
  • The threshold is a nonnegative binary rational.

The output parameters satisfy

\(\tau=2q<4N,\qquad m=2r+h.\)

The construction has polynomial output bit length and takes polynomial time. In particular, adding the dummy pairs does not require expanding any population represented by a mass.

3. Exact correspondence of allocations and fractional matchings.

For an allocation \(x\) in the constructed society, define \(y_e=qx_e\). The capacity constraints become

\(\sum_{e\ni v}y_e=q\sum_{e\ni v}x_e\le q\mu_v=1.\)

Conversely, any unit-capacity fractional matching \(y\) on the constructed graph gives a feasible allocation \(x_e=y_e/q\). These maps are inverse.

For every type, the per-capita utility is

\(U_v(x)=\mu_v^{-1}\sum_w s_v(w)x_{vw}=q\sum_w s_v(w)(y_{vw}/q)=V_v(y).\)

Consequently, every cardinal-stability inequality is preserved exactly, including equality.

For a dummy pair with edge \(d\), both endpoints have utility \(y_d\). Stability therefore requires \(y_d\ge 1\), while feasibility requires \(y_d\le 1\). Thus every stable solution has \(y_d=1\), and each dummy pair contributes exactly \(2\) to unit-capacity welfare.

Let \(y^{(1)},y^{(2)}\) denote the restrictions to the two source copies. Because no acceptable edges join different components, stability of the complete allocation implies stability in each copy. Its welfare is

\(\sum_v\mu_vU_v(x)=\bigl(W(y^{(1)})+W(y^{(2)})+2h\bigr)/q.\)

We can now prove both directions of the reduction.

If the source instance has a stable matching \(z\) with \(W(z)\ge\gamma\), use \(z\) in both copies and give every dummy edge weight \(1\). Scaling by \(1/q\) gives a stable allocation with welfare at least \(\Gamma\).

Conversely, suppose the constructed society has a stable allocation with welfare at least \(\Gamma\). The preceding identity implies

\(W(y^{(1)})+W(y^{(2)})\ge 2\gamma.\)

At least one of these two welfare values is at least \(\gamma\): otherwise their sum would be strictly less than \(2\gamma\). That copy, after undoing the relabeling if necessary, is a stable fractional matching satisfying the source threshold.

Thus the construction is a polynomial-time many-one reduction, proving \(\mathsf{NP}\)-hardness.

4. Membership in \(\mathsf{NP}\) and running times.

The use of real allocations does not prevent membership in \(\mathsf{NP}\). A certificate consists of one chosen endpoint for each acceptable edge: the endpoint whose stability inequality is to hold.

For a fixed choice, solve the following rational linear feasibility problem in the \(m\) variables \(x_e\):

  • Nonnegativity: \(x_e\ge 0\).
  • Capacities: \(\sum_{e\ni v}x_e\le\mu_v\).
  • For every edge \((t,u)\), impose the chosen inequality, either

\(\sum_w s_t(w)x_{tw}\ge\mu_t s_t(u)\), or
\(\sum_w s_u(w)x_{wu}\ge\mu_u s_u(t)\).

  • Welfare: \(\sum_{(t,u)\in E}(s_t(u)+s_u(t))x_{tu}\ge\Gamma\).

Multiplying the original utility inequalities by the positive masses justifies the third group. Expanding the definition of welfare justifies the fourth.

This system has \(m\) variables, \(O(m+\tau)\) constraints, and encoding length polynomial in \(m,\tau,L\). Exact feasibility of rational linear inequalities is decidable in polynomial bit time; its hypotheses apply because all displayed coefficients are rational and have polynomial encoding length.

If a stable allocation exists, choose a satisfied endpoint inequality on every edge. The resulting linear system is feasible. Conversely, any feasible system obtained from such choices supplies a stable allocation satisfying the welfare threshold.

Hence an \(m\)-bit certificate can be verified in \(\operatorname{poly}(m,\tau,L)\) time, proving membership in \(\mathsf{NP}\). Enumerating all choices also gives a deterministic algorithm with running time \(2^m\operatorname{poly}(m,\tau,L)\).

Together with the reduction, this establishes \(\mathsf{NP}\)-completeness for the exact continuous mass formulation.
