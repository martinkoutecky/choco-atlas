The continuous mirror question, as graded

Given a finite provider-type set \(A\) with masses \(\mu_a>0\), online contexts \(q_t\), features \(x(q_t,a)\), packet masses \(\ell_t\), an unknown utility function \(f\) with a stated contextual-bandit confidence model, and initial states \(u_{0,a}\), choose online type allocations using only past feedback \(y_t=f(x(q_t,a_t))+\epsilon_t\), where \(u_{t,a}=u_{0,a}+\mu_a^{-1}\sum_{s<t}z_{s,a}\ell_s y_s\), to minimize cumulative regret against the type maximizing \(G_{\mu,w}(u)=\int_0^1w(r)u^\uparrow_{\mu}(r)\,dr\), with sublinear regret per unit request mass.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(A\) of \(\tau\) provider types with positive binary-rational masses \(\mu_a\), normalized by \(\sum_a\mu_a=1\). Here \(\tau\) is the support size, not the number of possible types.
Contexts \(q_t\) arrive independently from an unknown distribution on \(m\) context types. Before acting, the learner sees all features \(x(q_t,a)\in\mathbb R^d\) and the packet mass \(\ell_t\), where fixed known constants satisfy \(0<c\le\ell_t\le C<\infty\); future arrivals are unknown.
Each packet is allocated irrevocably to one type \(a_t\): \(z_{t,a}=\mathbf1\{a=a_t\}\). Only \(y_t=f(x(q_t,a_t))+\epsilon_t\) is observed, where \(f:\mathbb R^d\to(0,\infty)\) is unknown and \(\epsilon_t\) is conditionally mean-zero, \(R\)-sub-Gaussian noise.
Initial states \(u_{0,a}\ge0\) are given, and the state before round \(t\) is \(u_{t,a}=u_{0,a}+\mu_a^{-1}\sum_{s<t}z_{s,a}\ell_s y_s\). States may become negative through noise.
The confidence model supplies a routine using only past observations that computes \(\widehat f_t(x(q_t,a))\) and \(h_t(a)\ge0\). For every adaptive allocation policy and every \(\delta\in(0,1)\), with probability at least \(1-\delta\), simultaneously for all \(t,a\), \(|\widehat f_t(x(q_t,a))-f(x(q_t,a))|\le h_t(a)\) and \(\sum_{t=1}^T h_t(a_t)^2\le B(T,\delta)=o(T)\) for fixed model parameters.
The routine and its updates take polynomial time in the accumulated input length and their stated model parameters. Numerical inputs, routine outputs, and observed feedback are binary rationals; \(L\) denotes their accumulated encoding length.
A given nonincreasing step function \(w:[0,1]\to[0,1]\) has \(k\) pieces with binary-rational breakpoints and values. Define \(G_{\mu,w}(u)=\int_0^1w(r)u^\uparrow_\mu(r)\,dr\), where \(u^\uparrow_\mu\) lists the state values in increasing order, each occupying an interval of length \(\mu_a\).
Let \(e_a\) be the coordinate vector and \(v_t(a)=u_t+\ell_t f(x(q_t,a))e_a/\mu_a\). Define \(\mathcal R_T=\sum_{t=1}^T[\max_{a\in A}G_{\mu,w}(v_t(a))-G_{\mu,w}(v_t(a_t))]\) and \(M_T=\sum_{t=1}^T\ell_t\). The benchmark uses the learner's current state and expected next utility; ties may be broken uniformly.
Is attaining \(\mathcal R_T=o(M_T)\) with probability at least \(1-\delta\) achievable by a policy with polynomial per-round running time in \(m,\tau,L,t,d,k\) and the confidence-model parameters, or is this continuous online allocation problem NP-hard?
For finitely many individual agents, a conditional algorithmic guarantee is \(\mathcal R_T\le2c_{\max}\sqrt{T\sum_{t=1}^T h_t(a_t)^2}\) for coordinatewise nondecreasing goodness functions with coordinate Lipschitz constants bounded by \(c_{\max}\). Weighted Gini evaluation is covered. [Verified source](https://arxiv.org/html/2408.12845v3).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Under the stated confidence-model assumptions, a policy with polynomial per-round running time achieves the required sublinear regret. With probability at least \(1-\delta\), its regret satisfies
\(\mathcal R_T\le 2C\sqrt{T B(T,\delta)}=o(M_T)\).

The essential fact is that the coordinate Lipschitz constant for type \(a\) is \(\mu_a\). This cancels the factor \(\mu_a^{-1}\) in its state update.

1. Monotonicity and the mass-dependent Lipschitz bound

For \(u\in\mathbb R^\tau\), define its weighted distribution function by
\(F_u(b)=\sum_{a\in A}\mu_a\mathbf1\{u_a\le b\}\).
For \(r\in(0,1)\), its increasing quantile is
\(Q_u(r)=\inf\{b\in\mathbb R:F_u(b)\ge r\}\).
This agrees almost everywhere with \(u^\uparrow_\mu\).

Lemma. For every \(u\in\mathbb R^\tau\), \(a\in A\), and \(s\ge0\),
\(0\le G_{\mu,w}(u+s e_a)-G_{\mu,w}(u)\le\mu_a s\).

Proof. Put \(v=u+s e_a\). Increasing one coordinate implies \(F_v(b)\le F_u(b)\) for every \(b\). Consequently,
\(\{b:F_v(b)\ge r\}\subseteq\{b:F_u(b)\ge r\}\),
and hence \(Q_v(r)\ge Q_u(r)\) for every \(r\in(0,1)\).

Because each coordinate occupies an interval of length \(\mu_a\),
\(\int_0^1 Q_u(r)\,dr=\sum_{a\in A}\mu_a u_a\).
Therefore,
\(\int_0^1[Q_v(r)-Q_u(r)]\,dr=\mu_a s\).

Using \(0\le w(r)\le1\) and the nonnegative quantile difference gives
\(0\le\int_0^1w(r)[Q_v(r)-Q_u(r)]\,dr\le\mu_a s\),
which proves the lemma.

In particular, for every \(\alpha,\beta\in\mathbb R\),
\(\lvert G_{\mu,w}(u+\alpha e_a)-G_{\mu,w}(u+\beta e_a)\rvert\le\mu_a\lvert\alpha-\beta\rvert\).
Apply the lemma to the smaller of the two coordinate values to obtain this inequality.

These statements hold on all of \(\mathbb R^\tau\), so negative states caused by noise present no difficulty.

2. The optimistic policy

Fix \(\delta\in(0,1)\) and use the supplied confidence routine at that confidence level. At round \(t\), write
\(f_t(a)=f(x(q_t,a))\), and compute
\(U_t(a)=\widehat f_t(x(q_t,a))+h_t(a)\).

For each \(a\in A\), form the optimistic state
\(\widetilde v_t(a)=u_t+\ell_t U_t(a)e_a/\mu_a\).
Choose
\(a_t\in\operatorname*{arg\,max}_{a\in A}G_{\mu,w}(\widetilde v_t(a))\),
using any fixed deterministic rule for ties.

After observing \(y_t\), update
\(u_{t+1}=u_t+\ell_t y_t e_{a_t}/\mu_{a_t}\),
and update the confidence routine.

Every operation uses only the current packet information and past observations. The policy is therefore causal and allocates each packet irrevocably to one type.

3. Regret analysis

Let \(\mathcal E_\delta\) be the simultaneous confidence event supplied in the question. Its probability is at least \(1-\delta\). The guarantee applies to this policy because it is assumed to hold for every adaptive allocation policy.

On \(\mathcal E_\delta\), for every \(t,a\),
\(0\le U_t(a)-f_t(a)\le2h_t(a)\).
The lower bound follows from \(\widehat f_t(x(q_t,a))\ge f_t(a)-h_t(a)\); the upper bound follows from the other side of the confidence interval.

Choose a true maximizing action \(a_t^\star\). Monotonicity and the policy’s maximizing property give
\(G_{\mu,w}(v_t(a_t^\star))\le G_{\mu,w}(\widetilde v_t(a_t^\star))\le G_{\mu,w}(\widetilde v_t(a_t))\).

Thus the instantaneous regret \(r_t\) satisfies
\(0\le r_t\le G_{\mu,w}(\widetilde v_t(a_t))-G_{\mu,w}(v_t(a_t))\).

The two states on the right differ only in coordinate \(a_t\), by the nonnegative amount
\(\ell_t[U_t(a_t)-f_t(a_t)]/\mu_{a_t}\).
The lemma therefore yields
\(r_t\le\mu_{a_t}\ell_t[U_t(a_t)-f_t(a_t)]/\mu_{a_t}\le2\ell_t h_t(a_t)\).

Summing and applying Cauchy–Schwarz,
\(\mathcal R_T\le2\sum_{t=1}^T\ell_t h_t(a_t)\le2\sqrt{\bigl(\sum_{t=1}^T\ell_t^2\bigr)\bigl(\sum_{t=1}^T h_t(a_t)^2\bigr)}\le2C\sqrt{T B(T,\delta)}\).

Since \(M_T\ge cT\),
\(0\le\mathcal R_T/M_T\le(2C/c)\sqrt{B(T,\delta)/T}\longrightarrow0\).

This proves \(\mathcal R_T=o(M_T)\) on the supplied confidence event. No knowledge or estimation of the arrival distribution is needed.

The optimistic comparison is consistent with the finite-agent argument in [Theorem 3 of the cited paper](https://arxiv.org/html/2408.12845v3). The proof above independently establishes the mass-dependent bound needed here.

4. Exact evaluation and polynomial running time

Represent the step function using breakpoints
\(0=b_0<b_1<\cdots<b_k=1\)
and values \(\omega_j\) on \((b_{j-1},b_j)\). Values at endpoints do not affect the integral.

To evaluate \(G_{\mu,w}(v)\), sort the support types so that
\(v_{a_1}\le\cdots\le v_{a_\tau}\).
Define \(p_0=0\) and
\(p_i=\sum_{h=1}^i\mu_{a_h}\).
Then the exact evaluation formula is
\(G_{\mu,w}(v)=\sum_{i=1}^{\tau}\sum_{j=1}^{k}v_{a_i}\omega_j\max\{0,\min(p_i,b_j)-\max(p_{i-1},b_{j-1})\}\).

Indeed, the last factor is the length of the intersection between the state interval \((p_{i-1},p_i)\) and the weight interval \((b_{j-1},b_j)\). Arbitrarily ordering tied coordinates leaves the value unchanged.

Sorting takes \(O(\tau\log(\tau+1))\) rational comparisons. A simultaneous scan of the two interval partitions evaluates the integral in \(O(\tau+k)\) rational operations. Evaluating all \(\tau\) candidates therefore takes
\(O\bigl(\tau[\tau\log(\tau+1)+\tau+k]\bigr)\)
rational operations, followed by exact score comparisons.

All quantities used by the policy are rational. Exact arithmetic has polynomial bit complexity:

  • Each state can be maintained as

\(u_{t,a}=u_{0,a}+S_{t,a}/\mu_a\), where
\(S_{t,a}=\sum_{s<t:a_s=a}\ell_s y_s\).
The bit lengths of these sums are polynomial in the accumulated encoding length \(L\) and \(t\): a common denominator has bit length at most the sum of the relevant input-denominator bit lengths.

  • Candidate states use a bounded number of rational operations on these states and the routine outputs.
  • Prefix masses, interval intersections, and scores require polynomially many rational operations, with polynomial intermediate bit lengths when fractions are reduced.

In particular, a very small \(\mu_a\) does not require expanding the population into individual agents. The reciprocal \(1/\mu_a\) has encoding length comparable to that of \(\mu_a\), even when its numerical value is large.

Combining this evaluation procedure with the assumed polynomial confidence routine proves polynomial per-round running time in the parameters requested. This settles the stated regret question, conditional precisely on the confidence-model assumptions.
