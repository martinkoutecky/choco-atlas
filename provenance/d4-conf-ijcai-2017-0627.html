The continuous mirror question, as graded

Given \(m\) indivisible items, two additive utility types \(v_1,v_2\), and rational masses \(\mu_1=\mu_2=1/2\), decide whether there exists \(A\subseteq S\) with \(|A|=m/2\) such that \(v_j(A)\ge v_j(S\setminus A)\) for each \(j\in\{1,2\}\).

Packaged proof task (what the prover saw — nothing else)

Let \(S\) contain \(m\geq 2\) indivisible items, where \(m\) is even. There are two additive utility types with nonnegative binary-rational item values \(v_j(x)\), without utility normalization.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here \(\tau=2\) and \(\mu_1=\mu_2=1/2\); \(\tau\) denotes support size, not the number of possible types.
A single subset \(A\subseteq S\) is agreeable if \(v_j(A)\geq v_j(S\setminus A)\) for every \(j\in\{1,2\}\); indifference is allowed. Require \(|A|=m/2\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is deciding whether such an agreeable subset exists solvable in polynomial time, or is it NP-hard?

For two discrete agents with nonnegative additive utilities, this exact-half decision problem is weakly NP-hard. For a fixed number of agents and integer utilities, minimum-size agreeability admits a pseudo-polynomial-time algorithm.

Modeling choices made when packaging the task

  • Restrict m to positive even values with m at least two, so the exact-half cardinality requirement is integral.
  • Specify nonnegative binary-rational item utilities, following the additive model's nonnegativity and giving a finite computational input; impose no utility normalization.
  • Define L as the total binary input length, including utilities and masses.
  • Retain unanimity across positive-mass types, weak agreeability, indivisible items, and one common subset.

Result

The decision problem is \(\mathrm{NP}\)-complete, with hardness already holding for nonnegative integer utilities, support size \(\tau=2\), and masses \(\mu_1=\mu_2=1/2\). Thus a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The hardness is witnessed by a reduction from the weakly \(\mathrm{NP}\)-complete Partition problem. The integer-utility restriction also admits a pseudo-polynomial algorithm, as shown below.

Membership in \(\mathrm{NP}\)

A certificate specifies a subset \(A\subseteq S\) by its \(m\) membership bits. Verify that \(|A|=m/2\) and, for every supported type, that

\(2v_j(A)\geq v_j(S).\)

These are exactly the required agreeability inequalities, because additivity gives \(v_j(S\setminus A)=v_j(S)-v_j(A)\).

For exact rational arithmetic, write each value as \(p_{jx}/q_{jx}\), with \(q_{jx}>0\), and multiply all utilities of type \(j\) by \(D_j=\prod_{x\in S}q_{jx}\). This positive scaling preserves every comparison. The resulting integer values and their sums have \(O(L)\) bits: the bit lengths of all input numerators and denominators together are bounded by \(L\).

Using elementary integer arithmetic, denominator clearing and certificate verification take \(O(m\tau L^2)\) bit operations. Hence the problem belongs to \(\mathrm{NP}\).

Explicit hardness reduction

We reduce from Partition: given positive binary-encoded integers \(a_1,\ldots,a_n\), decide whether some \(I\subseteq\{1,\ldots,n\}\) satisfies

\(\sum_{i\in I}a_i=\frac12\sum_{i=1}^{n}a_i.\)

The classical \(\mathrm{NP}\)-completeness of this problem is established, for example, in these [Cornell lecture notes](https://www.cs.cornell.edu/courses/cs6820/2022fa/Handouts/NPC4.pdf).

Put \(T=\sum_{i=1}^{n}a_i\) and \(C=\max_i a_i\). Construct \(m=2n\) distinct items: original items \(x_1,\ldots,x_n\) and padding items \(d_1,\ldots,d_n\). Define the two additive utility types by the following item values:

| Item | Type \(1\) | Type \(2\) |
|---|---:|---:|
| \(x_i\) | \(a_i\) | \(C-a_i\) |
| \(d_i\) | \(0\) | \(C\) |

Give each type mass \(1/2\).

All values are nonnegative integers. The two types are distinct because \(C>0\) and their values on every padding item differ. Thus the support has exactly two types. Moreover,

\(v_1(x)+v_2(x)=C\quad\text{for every }x\in S,\)

and therefore

\(v_1(S)=T,\qquad v_2(S)=2nC-T.\)

Consider any subset \(A\) satisfying the required cardinality \(|A|=n=m/2\). Write \(s=v_1(A)\). The constant itemwise sum gives

\(v_2(A)=nC-s.\)

Consequently, agreeability for type \(1\) is equivalent to

\(2s\geq T,\)

while agreeability for type \(2\) is equivalent to

\(2(nC-s)\geq 2nC-T,\)

which simplifies to \(2s\leq T\). Hence

\(A\text{ is agreeable for both types}\quad\Longleftrightarrow\quad s=T/2.\)

We now verify both directions of the reduction.

  • Partition implies agreeability. Suppose \(I\subseteq\{1,\ldots,n\}\) has sum \(T/2\). Select the original items indexed by \(I\), together with any \(n-|I|\) padding items. There are enough padding items, and the resulting subset has cardinality \(n\) and type-\(1\) utility \(T/2\). It is therefore agreeable for both types.
  • Agreeability implies Partition. Suppose an agreeable subset \(A\) has cardinality \(n\). The preceding calculation forces \(v_1(A)=T/2\). Padding items contribute zero to this utility, so the original items selected by \(A\) give a solution to Partition.

If \(T\) is odd, the forced equality is impossible for integer utilities, correctly preserving a negative instance.

The construction has \(2n\) items, and every value is at most \(C\). Its output length is \(O(n\log(C+1))\), polynomial in the source encoding length. Computing the values requires only comparisons and subtractions of binary integers. This proves polynomial-time many-one hardness.

Together with membership in \(\mathrm{NP}\), the reduction proves \(\mathrm{NP}\)-completeness.

Pseudo-polynomial running time

For completeness, suppose the utilities are integers. Label the items \(x_1,\ldots,x_m\), and put \(h=m/2\) and \(W_j=v_j(S)\).

Define \(F_i(k,s)\) as the maximum type-\(2\) utility of a \(k\)-item subset of \(\{x_1,\ldots,x_i\}\) whose type-\(1\) utility is exactly \(s\). Use \(-\infty\) when no such subset exists. Initialize \(F_0(0,0)=0\), with all other entries infeasible.

The recurrence is

\(F_i(k,s)=\max\{F_{i-1}(k,s),\,F_{i-1}(k-1,s-v_1(x_i))+v_2(x_i)\},\)

omitting infeasible or out-of-range terms. It is correct because every feasible subset either excludes \(x_i\) or includes it; removing an included item gives precisely the second predecessor state. Induction on \(i\) therefore proves the stated meaning of every entry.

An agreeable exact-half subset exists precisely when some integer \(s\geq\lceil W_1/2\rceil\) satisfies

\(F_m(h,s)\geq\lceil W_2/2\rceil.\)

There are \(O(m^2(W_1+1))\) entries, each requiring \(O(L)\) bit operations. For \(\tau=2\), this gives time \(O(m^2(W_1+1)L)\). Interchanging the two types replaces \(W_1\) by \(\min\{W_1,W_2\}\).

For rational utilities, denominator clearing takes \(O(m\tau L^2)\) time, after which the same algorithm applies to the scaled integer totals. Those totals can be exponential in \(L\), so this is not a polynomial-time bound in the binary input length.

Finally, the positive masses do not change feasibility: the definition requires both supported types to agree with the same subset.
