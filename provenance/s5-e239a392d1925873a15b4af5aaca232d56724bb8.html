The continuous mirror question, as graded

Given a finite candidate set \(C\) and a society \(\mu\) with finite support over weak-order types, decide whether every triple \(S\subseteq C\) has an alternative \(a\in S\) and a rank position \(r\in\{1,2,3\}\) such that \(\sum_{t\in\operatorname{supp}(\mu)\cap V_S}\mu_t\,mPM_t^S(a,r)=0\), where \(V_S\) is the set of types concerned over \(S\), and \(mPM_t^S(a,r)\) indicates whether type \(t\) permits \(a\) at position \(r\) within \(S\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq 3\) candidates. A society is given by its support: a list of \(\tau\) distinct weak-order types on \(C\), each encoded as an ordered partition into indifference classes, with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
For each triple \(S\subseteq C\), let \(V_S\) consist of the supported types whose restriction to \(S\) does not tie all three candidates. Assume \(\sum_{t\in V_S}\mu_t>0\) for every triple.
For \(a\in S\), let \(b_t^S(a)\) count candidates in \(S\) strictly preferred to \(a\), and let \(e_t^S(a)\) count candidates in \(S\) indifferent to \(a\), including \(a\). Define \(mPM_t^S(a,r)=1\) exactly when \(b_t^S(a)+1\leq r\leq b_t^S(a)+e_t^S(a)\), and \(0\) otherwise. Thus ties occupy all positions in their consecutive block; no tie-breaking is applied.
Decide whether every triple \(S\) admits \(a\in S\) and \(r\in\{1,2,3\}\) such that \(\sum_{t\in V_S}\mu_t mPM_t^S(a,r)=0\). No parity condition is imposed on rational masses.

Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite electorates with at least three voters, the corresponding zero-entry condition expresses value restriction; together with an odd number of concerned voters on every triple, it suffices for transitive majority preferences. This is a structural sufficiency result, not a complexity classification. [Hou, 2022](https://arxiv.org/pdf/2204.05105v1)
No result settling exactly this rational-mass recognition problem was located in the literature search.

Modeling choices made when packaging the task

  • Required at least three candidates, matching the anchor's domain.
  • Normalized the positive rational masses to sum to one and encoded weak orders as ordered indifference classes.
  • Defined concerned types using their restriction to the triple, excluding exactly those tying all three candidates.
  • Specified permitted positions using the consecutive block occupied by each indifference class, without tie-breaking.
  • Retained the nonemptiness implied by the discrete oddness condition as positive concerned mass on every triple; imposed no parity condition on rational masses because the requested problem tests value restriction rather than a majority-transitivity guarantee.
  • Did not translate the discrete requirement of at least three voters into a lower bound on support size, since distinct types do not count individuals.

Classification

The problem is in \(\mathrm{P}\). With explicitly listed support, it can be decided in \(O(L+\tau m^3)\) time on a standard word RAM. A conservative bound for a sequential bit implementation is \(O(m^3L\log(m+1))\).

1. Positivity reduces the condition to a support test

Fix a triple \(S\), a candidate \(a\in S\), and a position \(r\in\{1,2,3\}\). Every summand \(\mu_t mPM_t^S(a,r)\) is nonnegative, and \(\mu_t>0\). Consequently,

\(\displaystyle \sum_{t\in V_S}\mu_t mPM_t^S(a,r)=0 \quad\Longleftrightarrow\quad mPM_t^S(a,r)=0\text{ for every }t\in V_S.\)

Indeed, if all indicators vanish, the sum vanishes. Conversely, any indicator equal to \(1\) contributes the strictly positive quantity \(\mu_t\), making the sum positive.

Thus the answer depends only on which types are supported. No rational arithmetic or expansion into a finite electorate is necessary.

2. Algorithm

Index the candidates by \(\{1,\ldots,m\}\). For every supported type \(t\), construct an array \(q_t\), where \(q_t(a)\) is the index of the indifference class containing \(a\), with smaller indices denoting better classes. These arrays are obtained directly from the ordered partitions.

For each of the \(\binom{m}{3}\) triples \(S\):

  • Initialize nine Boolean entries \(B_S(a,r)\), indexed by \(a\in S\) and \(r\in\{1,2,3\}\), to false.
  • Inspect every supported type \(t\).
  • If all three values \(q_t(a)\), \(a\in S\), are equal, skip this type: it does not belong to \(V_S\).
  • Otherwise, for each \(a\in S\), compute

\(\displaystyle b_t^S(a)=|\{c\in S:q_t(c)<q_t(a)\}|\) and
\(\displaystyle e_t^S(a)=|\{c\in S:q_t(c)=q_t(a)\}|.\)

  • Set \(B_S(a,r)\) to true for every position satisfying

\(b_t^S(a)+1\leq r\leq b_t^S(a)+e_t^S(a)\).

  • If all nine entries are true, reject.

Accept if no triple causes rejection.

The updates use the entire consecutive block occupied by a tie, exactly as required in the question.

3. Correctness proof

Fix a triple \(S\). After processing any initial segment of supported types, \(B_S(a,r)\) is true exactly when that segment contains some \(t\in V_S\) with \(mPM_t^S(a,r)=1\).

This invariant holds initially because no type has been processed and every entry is false. A skipped type is outside \(V_S\), so it cannot change the stated existence condition. For a type in \(V_S\), the algorithm marks precisely the positions specified by the definition of \(mPM_t^S\). Thus each update preserves the invariant.

After all types have been processed,

\(\displaystyle B_S(a,r)=\text{false}\quad\Longleftrightarrow\quad mPM_t^S(a,r)=0\text{ for every }t\in V_S.\)

By the positivity argument, this is equivalent to the required weighted sum being zero. Hence \(S\) satisfies the condition exactly when at least one of its nine entries remains false.

The algorithm rejects exactly when some triple fails the condition, and therefore accepts exactly the societies specified in the question. The assumed positive concerned mass on every triple is respected by the input promise.

4. Running time and encoding

Reading the input costs \(O(L)\). Constructing the class-index arrays takes \(O(m\tau)\) word operations and \(O(m\tau)\) words of auxiliary space.

For a fixed triple and type, the algorithm performs only a constant number of array accesses, comparisons, and Boolean updates: there are three candidates and nine possible entries. The total word-RAM running time is therefore

\(\displaystyle O\!\left(L+m\tau+\tau\binom{m}{3}\right)=O(L+\tau m^3).\)

Here a word has \(O(\log(L+2))\) bits, sufficient for the indices in the explicitly encoded input.

Polynomial bit complexity also follows without random-access tables. For each triple, rescan the ordered partitions and retain only its three candidates, preserving their class boundaries. This produces each restricted order and its nine indicators. With binary candidate indices, a conservative bound for one complete scan is \(O(L\log(m+1))\) bit operations, giving \(O(m^3L\log(m+1))\) overall.

Because every type explicitly lists all \(m\) candidates, both \(m\) and \(\tau\) are bounded by the input length. These bounds are polynomial in \(L\).

[Hou’s transitivity theorem](https://arxiv.org/pdf/2204.05105v1) concerns a sufficiency condition with an additional oddness hypothesis. The recognition proof here follows directly from the stated zero-entry condition and requires no parity assumption.
