The continuous mirror question, as graded

Given \(\theta_L < B < \theta_H\), a discount factor \(\delta\), and a finite rationally encoded distribution \(P\) over issue states \(x \in [0,1]\), where each state has society \(\mu_x=(x,1-x)\) over low-cost and high-cost jurisdictions, choose a quota \(q \in [0,1]\). If \(x \ge q\), all jurisdictions are instructed to participate, and any refusal makes the collective action ineffective. Maximize \(U(q)=\mathbb{E}_{x\sim P}[\mathbf{1}[x\ge q](x(B-\theta_L)+(1-x)(B-\theta_H))]\), subject to \(\theta_H-B \le \frac{\delta}{1-\delta}U(q)\) whenever the quota passes an issue with \(x<1\); quotas that pass only at \(x=1\) are the unanimity outcome.

Issues are drawn independently over time. A single stationary quota \(q\in[0,1]\) passes precisely when \(x_j\ge q\), including equality. Result

The exact quota optimization is solvable in time polynomial in \(m,\tau,K,L\). In fact, it suffices to compare two explicitly computable quotas: the welfare cutoff and unanimity.

1. The welfare-maximizing cutoff

Define \(h=\theta_H-B>0\), \(d=\theta_H-\theta_L>0\), and \(a=h/d\). By hypothesis, \(\frac12<a<1\).

The welfare contribution conditional on passage at state \(x\) is
\(w(x)=x(B-\theta_L)+(1-x)(B-\theta_H)=dx-h=d(x-a)\).

Consequently, \(w(x)\) is negative for \(x<a\), zero for \(x=a\), and positive for \(x>a\).

Set \(U^\star=U(a)=\sum_{j:x_j\ge a}p_jw(x_j)\). This is the maximum welfare over all quotas, without imposing feasibility. Indeed, for any quota \(q\),
\(U(q)=\sum_jp_jw(x_j)\mathbf{1}_{\{x_j\ge q\}}\le\sum_jp_j\max\{w(x_j),0\}=U^\star\).

The inequality holds term by term: excluding a positive contribution or including a negative contribution cannot increase the sum. Quota \(a\) includes every positive contribution and excludes every negative contribution, attaining the bound. Inclusion of states with \(x_j=a\), as required by the equality convention, contributes zero. In particular, \(U^\star\ge0\).

2. Enforcement reduces to one comparison

Because \(1-\delta>0\), the supplied feasibility condition for any quota subject to enforcement is equivalent to
\((1-\delta)h\le\delta U(q)\).

This formulation also handles \(\delta=0\) without division.

There are two exhaustive cases.

Case 1: \((1-\delta)h\le\delta U^\star\).
Quota \(a\) is feasible: if enforcement applies, the displayed inequality verifies its constraint; otherwise it is feasible without a constraint. Its welfare is \(U^\star\), the global upper bound proved above. Thus \(a\) is an optimal feasible quota.

Case 2: \((1-\delta)h>\delta U^\star\).
For every quota subject to enforcement, the bound \(U(q)\le U^\star\) and the hypothesis \(\delta\ge0\) imply
\(\delta U(q)\le\delta U^\star<(1-\delta)h\).
Hence every such quota is infeasible.

It remains to optimize among unconstrained quotas. A quota is unconstrained precisely when it passes no supported state with \(x_j<1\). Since every allowed quota satisfies \(q\le1\), it always passes a supported state with \(x_j=1\), if one exists. Therefore all unconstrained quotas have the same passage outcome and welfare:
\(U_{\mathrm{un}}=\sum_{j:x_j=1}p_j(B-\theta_L)\).

Quota \(1\) realizes this outcome and is always unconstrained. If no state has \(x_j=1\), it passes nothing and has welfare zero. Thus quota \(1\) is optimal in Case 2.

3. Exact algorithm

The algorithm is:

  • Compute \(h=\theta_H-B\), \(d=\theta_H-\theta_L\), and \(a=h/d\).
  • Compute \(U^\star=\sum_{j:x_j\ge a}p_j[dx_j-h]\) using exact rational arithmetic.
  • If \((1-\delta)h\le\delta U^\star\), return \(q=a\).
  • Otherwise, return \(q=1\).

The preceding case analysis proves feasibility and optimality of the returned quota in every instance. No sorting or search over subsets is required.

4. Bit complexity

All calculations have polynomial bit complexity, including the exact comparisons.

To verify this explicitly, let \(D\) be the product of the denominators in the supplied rational encodings. Its binary length is \(O(L)\), because the sum of those denominator lengths is at most the total input length. Represent each input rational as an integer divided by \(D\); every resulting integer has \(O(L)\) bits.

Each term \(p_j[dx_j-h]\) then has denominator \(D^3\). Thus \(U^\star\) can be accumulated over this common denominator. Its numerator has \(O(L)\) bits: the selected terms are nonnegative, their probabilities sum to at most \(1\), and their welfare magnitudes are bounded by the input cost and benefit magnitudes. The latter have \(O(L)\)-bit encodings.

Membership in the sum can be tested as \(dx_j\ge h\), without computing an approximate cutoff. The final enforcement comparison can likewise be performed by integer cross-multiplication. All operands and products have \(O(L)\) bits.

The algorithm uses \(O(K+1)\) arithmetic operations on integers of polynomially bounded length, so its running time is \(O((K+1)\operatorname{poly}(L))\), plus input reading. The output \(a=h/d\), or \(1\), also has \(O(L)\) bits. Since this problem has \(m=2\) and \(\tau\le2\), this is polynomial in \(m,\tau,K,L\).

5. Critical discount factor

The comparison can equivalently be written as
\(\delta\ge\delta_c\), where \(\delta_c=h/(h+U^\star)\).

Thus the algorithm returns the unconstrained welfare optimum for \(\delta\ge\delta_c\), and unanimity for \(\delta<\delta_c\). When \(U^\star=0\), the critical value is \(1\), so unanimity is optimal throughout the permitted range \(\delta<1\). Ties can make unanimity optimal above the critical value as well.

This directly establishes, for the specified finite-support mass model, the cutoff/unanimity pattern discussed in the [supplied Maggi–Morelli paper](https://economics.yale.edu/sites/default/files/2022-10/voting41g.pdf). The computational conclusion follows from the explicit algorithm above.
