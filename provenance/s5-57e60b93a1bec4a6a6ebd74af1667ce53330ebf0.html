The continuous mirror question, as graded

Given a path with positions \(1,\ldots,m\), a finite type set \(T\), binary additive valuation vectors \(u_t\in\{0,1\}^m\), a rational mass vector \(\mu\) with \(\sum_t\mu_t=1\), and rational per-capita capacities \(b_j\), decide whether there are masses \(\lambda_{t,I}\ge0\) for types \(t\in T\) and intervals \(I\subseteq\{1,\ldots,m\}\), including \(\varnothing\), such that \(\sum_I\lambda_{t,I}=\mu_t\), \(\sum_{t,I:j\in I}\lambda_{t,I}=b_j\), \(\sum_{t,I:j\in I}u_t(j)\lambda_{t,I}=b_j\), and for every positive-mass classes \((t,I)\), \((t',J)\) with \(J\ne\varnothing\), some \(j\in J\) satisfies \(u_t(I)\ge u_{t'}(J\setminus\{j\})\), where \(u_t(I)=\sum_{j\in I}u_t(j)\).

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge1\) positions form a path. A society is given by its support: the list \(T\) of \(\tau\ge1\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has binary additive valuations \(u_t\in\{0,1\}^m\); every position is valued by some supported type. Input capacities are binary rationals \(b_j\in[0,1]\), with no normalization of \(\sum_j b_j\). Let \(L\) be the total input bit length.
Let \(\mathcal I\) contain all nonempty intervals and \(\varnothing\), and define \(u_t(S)=\sum_{j\in S}u_t(j)\) for every subset \(S\).
An allocation consists of real masses \(\lambda_{t,I}\ge0\), allowing each type to split among intervals, subject to \(\sum_{I\in\mathcal I}\lambda_{t,I}=\mu_t\) for every \(t\).
Complete use of capacities and non-wastefulness require, for every position \(j\), \(\sum_{t,I:j\in I}\lambda_{t,I}=b_j\) and \(\sum_{t,I:j\in I}u_t(j)\lambda_{t,I}=b_j\).
Equitability up to one good (EQ1) requires that for every ordered pair of classes with \(\lambda_{t,I}>0\), \(\lambda_{t',J}>0\), and \(J\ne\varnothing\), some \(j\in J\) satisfies \(u_t(I)\ge u_{t'}(J\setminus\{j\})\); the residual set need not be connected.

Is deciding whether such an allocation exists solvable in time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finitely many agents and indivisible goods, existence of a connected EQ1 and non-wasteful allocation is \(\mathrm{NP}\)-complete even when each agent values at most four goods and each good is valued by at most four agents. [Source](https://arxiv.org/pdf/2101.09794v2)
No result settling this exact mass-and-capacity formulation was identified in the literature search.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Polynomial-time solvability

The decision problem is solvable in time polynomial in \(m,\tau,L\). The algorithm tests feasibility of \(m+1\) rational linear programs.

1. Non-wastefulness restricts occupied intervals

Call a class \((t,I)\) occupied if \(\lambda_{t,I}>0\), and call an interval \(I\) approved by \(t\) if \(u_t(j)=1\) for every \(j\in I\). The empty interval is approved vacuously.

Subtracting the non-wastefulness equality from the capacity equality at position \(j\) gives
\[ \sum_{t,I:j\in I}(1-u_t(j))\lambda_{t,I}=0. \]
Every summand is nonnegative because valuations are binary and masses are nonnegative. Therefore, whenever \(\lambda_{t,I}>0\) and \(j\in I\), necessarily \(u_t(j)=1\).

Thus every occupied interval is approved by its receiving type, and consequently
\[ u_t(I)=|I| \]
for every occupied class, including an empty one.

Conversely, if variables are restricted to approved intervals, then complete use of capacities automatically implies non-wastefulness: every contribution to a position’s capacity also contributes the same amount to its valued-use equality.

2. EQ1 is equivalent to a common length band

Consider any allocation satisfying the mass, capacity, and non-wastefulness constraints. There is at least one occupied class because total mass is \(1\). Define
\[ a=\min_{\lambda_{t,I}>0}|I|, \qquad c=\max_{\lambda_{t,I}>0}|I|. \]

We claim that EQ1 holds exactly when \(c-a\le1\).

Necessity. If \(c=0\), every occupied interval is empty and the inequality holds. Otherwise, choose occupied classes \((t,I)\) and \((t',J)\) with lengths \(a\) and \(c\), respectively. Since \(J\ne\varnothing\), EQ1 requires some \(j\in J\) satisfying
\[ u_t(I)\ge u_{t'}(J\setminus\{j\}). \]
Both intervals are approved by their receiving types. Binary additivity therefore makes this inequality \(a\ge c-1\), proving \(c-a\le1\).

Sufficiency. Suppose \(c-a\le1\). For any ordered pair of occupied classes \((t,I),(t',J)\) with \(J\ne\varnothing\), choose any \(j\in J\). Then
\[ u_t(I)=|I|\ge a\ge c-1\ge |J|-1 =u_{t'}(J\setminus\{j\}). \]
This is exactly EQ1. Additivity justifies the last equality even when the residual set is disconnected.

Since interval lengths are integers, the equivalence says that all occupied intervals have lengths in \(\{k,k+1\}\) for some \(k\in\{0,\ldots,m\}\). The choice \(k=0\) allows empty intervals and singletons.

3. Linear program for a fixed band

For each \(k\in\{0,\ldots,m\}\) and supported type \(t\), define
\[ \mathcal A_{t,k} = \{I\in\mathcal I: |I|\in\{k,k+1\} \text{ and }u_t(j)=1\text{ for every }j\in I\}. \]
Lengths exceeding \(m\) simply yield no intervals.

Introduce a real variable \(x_{t,I}\ge0\) for each \(I\in\mathcal A_{t,k}\). Test feasibility of the following linear program:
\[ \sum_{I\in\mathcal A_{t,k}}x_{t,I}=\mu_t \qquad(t\in T), \]
\[ \sum_{t\in T} \sum_{\substack{I\in\mathcal A_{t,k}\\j\in I}} x_{t,I}=b_j \qquad(j\in\{1,\ldots,m\}). \]

The algorithm accepts if and only if at least one of these linear programs is feasible.

Correctness

If an original feasible allocation exists, Section 1 shows that every occupied interval is approved. Section 2 shows that its occupied lengths lie in some band \(\{k,k+1\}\). Its masses therefore give a feasible solution to the corresponding linear program.

Conversely, suppose the linear program for \(k\) is feasible. Set \(\lambda_{t,I}=x_{t,I}\) for its variables and set all other allocation variables to zero. The linear program enforces the required type masses and complete capacity use. Approval of every permitted interval implies non-wastefulness by Section 1. All occupied lengths lie in \(\{k,k+1\}\), so Section 2 implies EQ1.

This proves both directions.

4. Polynomial running time and exact feasibility

For a positive length \(r\le m\), the path has exactly \(m-r+1\) intervals of length \(r\). It has one empty interval. Consequently, each fixed-band linear program has at most \(\tau(2m+1)\) variables and exactly \(\tau+m\) equality constraints, besides nonnegativity constraints.

The permitted intervals can be constructed in polynomial time. For example, prefix sums of each type’s binary valuation identify whether an interval is approved by checking whether its valuation sum equals its length.

All constraint coefficients are \(0\) or \(1\). The right-hand sides are the input binary rationals \(\mu_t,b_j\). Thus each linear program has an encoding length polynomial in \(m,\tau,L\). The polynomial-time theorem for rational linear-programming feasibility applies: the system is finite, all coefficients are rational, and the full coefficient encoding has polynomial length. Testing \(m+1\) such programs remains polynomial.

Allowing real masses causes no additional issue. Each variable is bounded by its type’s mass, so any feasible system defines a bounded rational polytope. A nonempty bounded rational polytope has a rational vertex: at a vertex, a full-rank collection of active rational constraints determines the coordinates, which are rational by linear algebra. Hence exact rational feasibility testing decides the stipulated real feasibility problem.

No assumption about normalization of the total capacities was used.

5. Relation to the indivisible-agent result

The cited paper establishes hardness for connected EQ1 and non-wasteful allocations of indivisible goods to finitely many agents. [Misra et al., *Equitable Division of a Path*](https://arxiv.org/pdf/2101.09794v2)

In the present formulation, type mass may split across several intervals. Once the common length band is fixed, all remaining requirements are linear constraints on those masses. This establishes polynomial-time solvability for the exact formulation in the question.
