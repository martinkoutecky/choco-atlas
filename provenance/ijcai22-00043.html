Complexity Status of the Stated Uniform-Mechanism Problem

Conclusion

The target problem is not a well-defined decision problem as stated. In particular, “uniform mechanism” is undefined, no welfare requirement is imposed on the mechanism, and no finite representation of candidate mechanisms is specified.

Under the literal existence-only interpretation, the problem is trivial: every society admits a deterministic strategyproof mechanism, so the promised decision problem is an all-YES problem and belongs to \(\mathrm{P}\).

A nontrivial polynomial-time result can nevertheless be proved: for every specified replica, an optimal-welfare outcome can be computed by one minimum-cut computation on a graph with \(|\Theta|\) vertices. This optimization result does not make the resulting report-dependent rule strategyproof.

1. Literal Mechanism Existence Is Trivial

Let \(\mathcal N(\mu)\) be the set of positive integers \(N\) for which every \(N\mu_\theta\) is integral.

For every \(N\in\mathcal N(\mu)\), define \(M_N\) as follows: independently of all reports, put every agent into one group labeled \(a_1\).

Fix an agent \(i\), her true values and outgoing weights, arbitrary reports of the other agents, and two possible reports \(r_i,r'_i\) by agent \(i\). Since \(M_N\) ignores every report, the outcome under \((r_i,r_{-i})\) is identical to the outcome under \((r'_i,r_{-i})\). Hence agent \(i\)'s true utility is identical under the two reports. In particular, truthful reporting is weakly optimal against every \(r_{-i}\).

Thus \(M_N\) is strategyproof for every valid replica size \(N\). The same finite rule describes all the \(M_N\), so it is uniform in the ordinary algorithmic sense of “one rule for every replica.”

Consequently, if the intended language is

\(\{\text{valid society encodings admitting a deterministic strategyproof mechanism}\}\),

then every promised input is accepted. This problem is solvable in constant time after syntactic validation, and therefore belongs to \(\mathrm{P}\).

This conclusion uses no welfare property. Any nontrivial existence problem must add one.

2. Polynomial-Time Welfare Optimization for a Specified Replica

Although it does not settle the intended mechanism-design question, the welfare optimization problem itself has a compact polynomial-time solution.

Fix a valid replica size \(N\), and write \(n_\theta=N\mu_\theta\).

Lemma 2.1: At most one group per activity is needed

Suppose two groups \(G\) and \(H\) are both labeled by the same activity \(a\). Merging them leaves all activity-value terms unchanged. It adds the interaction contribution

\(\sum_{i\in G}\sum_{j\in H}\bigl(\omega_{\operatorname{type}(i),\operatorname{type}(j)}+\omega_{\operatorname{type}(j),\operatorname{type}(i)}\bigr)\),

which is nonnegative by hypothesis.

Therefore merging same-activity groups cannot decrease welfare. Repeating this operation shows that some optimal outcome has at most one group labeled \(a_1\) and at most one group labeled \(a_2\).

Hence an optimal outcome may be represented simply by assigning every agent to one of the two activities.

Lemma 2.2: Some optimum assigns every type uniformly

Fix a type \(\theta\), and hold fixed the activity assignments of all other types. Let \(x\) of the \(n_\theta\) agents of type \(\theta\) be assigned to \(a_1\), and let \(z_\phi\) of the \(n_\phi\) agents of type \(\phi\ne\theta\) be assigned to \(a_1\).

Up to terms independent of \(x\), welfare equals

\(F_\theta(x)=x p_\theta(a_1)+(n_\theta-x)p_\theta(a_2)+\omega_{\theta,\theta}\bigl(x(x-1)+(n_\theta-x)(n_\theta-x-1)\bigr)+\sum_{\phi\ne\theta}(\omega_{\theta,\phi}+\omega_{\phi,\theta})\bigl(xz_\phi+(n_\theta-x)(n_\phi-z_\phi)\bigr)\).

All terms except the self-interaction term are affine in \(x\). The coefficient of \(x^2\) is \(2\omega_{\theta,\theta}\ge 0\). Therefore \(F_\theta\) is convex on \([0,n_\theta]\).

For every \(x\in[0,n_\theta]\), convexity gives \(F_\theta(x)\le\max\{F_\theta(0),F_\theta(n_\theta)\}\). Thus all agents of type \(\theta\) can be moved to one activity without decreasing welfare.

Applying this argument successively to every type yields an optimal outcome in which each type is assigned wholly to one activity.

Theorem 2.3: The optimum is a minimum cut

Let \(y_\theta\in\{1,2\}\) denote the activity assigned to type \(\theta\). For distinct types define

\(c_{\theta\phi}=n_\theta n_\phi(\omega_{\theta,\phi}+\omega_{\phi,\theta})\ge 0\).

The welfare of a type-uniform outcome is

\(\sum_\theta n_\theta p_\theta(a_{y_\theta})+\sum_\theta n_\theta(n_\theta-1)\omega_{\theta,\theta}+\sum_{\{\theta,\phi\}}c_{\theta\phi}\mathbf 1[y_\theta=y_\phi]\).

The middle sum is independent of \(y\). Put \(b_{\theta r}=n_\theta p_\theta(a_r)\), \(B_\theta=\max\{b_{\theta1},b_{\theta2}\}\), and \(D_\theta(r)=B_\theta-b_{\theta r}\ge0\).

Maximizing welfare is equivalent to minimizing

\(E(y)=\sum_\theta D_\theta(y_\theta)+\sum_{\{\theta,\phi\}}c_{\theta\phi}\mathbf 1[y_\theta\ne y_\phi]\).

Construct an \(s\)-\(t\) cut instance with one vertex for every \(\theta\):

  • Add an arc from \(s\) to \(\theta\) of capacity \(D_\theta(2)\).
  • Add an arc from \(\theta\) to \(t\) of capacity \(D_\theta(1)\).
  • For every unordered pair \(\{\theta,\phi\}\), add an undirected edge of capacity \(c_{\theta\phi}\), equivalently two opposite directed arcs of that capacity.

Interpret the source side as activity \(a_1\) and the sink side as activity \(a_2\). The cut capacity is exactly \(E(y)\). Thus a minimum cut produces an optimal outcome.

The graph has \(|\Theta|+2\) vertices and \(O(|\Theta|^2)\) edges. All capacities are nonnegative rationals of polynomial encoding length. Clearing denominators increases the bit length only polynomially, so standard minimum-cut algorithms run in time polynomial in \(|\Theta|\), the rational input length, and \(\log N\). The answer is a compressed type-level outcome; explicitly listing all agents may require \(\Omega(N)\) output time.

3. Welfare Maximization Is Not Automatically Strategyproof

Consider two types \(\alpha,\beta\), each of mass \(1/2\), and the replica \(N=2\). Set all unspecified weights to zero, and let

\(p_\alpha(a_1)=0,\quad p_\alpha(a_2)=10,\quad p_\beta(a_1)=100,\quad p_\beta(a_2)=0,\quad \omega_{\beta,\alpha}=20,\quad \omega_{\alpha,\beta}=0\).

Under truthful reports, putting both agents together at \(a_1\) has welfare \(120\). Putting \(\alpha\) alone at \(a_2\) and \(\beta\) alone at \(a_1\) has welfare \(110\), while putting both together at \(a_2\) has welfare \(30\). The remaining singleton outcomes have welfare at most \(100\). Hence together at \(a_1\) is the unique optimum.

Suppose \(\alpha\) reports \(p_\alpha(a_2)=21\), leaving everything else unchanged. The separated outcome now has reported welfare \(121\), whereas together at \(a_1\) still has welfare \(120\), and every other outcome is worse. Thus separation is the unique optimum for the reported profile.

Agent \(\alpha\)'s true utility changes from \(0\) to \(10\). Therefore every rule required to select an optimum at every reported profile is manipulable on this instance.

Consequently, the minimum-cut optimizer is not a strategyproof mechanism merely because it is computationally efficient.

4. Why the Known Impossibility Does Not Establish \(\mathrm{NP}\)-Hardness

The cited discrete result states that no deterministic strategyproof mechanism has a bounded approximation ratio with two activities, even when activities are copyable and all values and weights are nonnegative; see [Flammini and Varricchio, Theorem 1](https://www.ijcai.org/proceedings/2022/0043.pdf).

This is a universal nonexistence theorem, not a reduction from an \(\mathrm{NP}\)-hard language. If the intended question asks for one bounded-approximation mechanism over the entire unrestricted domain, that theorem points to the constant answer “no,” subject to a precise correspondence between the two report models. A constant negative answer is not an \(\mathrm{NP}\)-hardness classification.

Moreover, the typed formulation assigns two incompatible roles to \(p_\theta\) and \(\omega_{\theta,\theta'}\): they appear both as data in the input society and as private information agents must report. Whether the mechanism may use the society's stated values independently of reports materially changes the problem.

5. Missing Specifications

A complexity classification requires a finite language such as

\(L=\{\langle S,\rho,\mathcal D,\mathcal C\rangle:\text{there exists a mechanism in }\mathcal C\text{ that is strategyproof on }\mathcal D\text{ and has ratio at most }\rho\}\).

The current statement does not define:

  • what “uniform” requires;
  • whether welfare optimality or an approximation threshold is required;
  • whether the mechanism is tailored to one society or must work over a domain of societies;
  • which data are public and which are privately reported;
  • whether the guarantee must hold for every report profile or only at the one encoded profile;
  • how a mechanism is finitely represented or bounded in size;
  • whether the approximation factor must be independent of \(N\).

Until these choices are fixed, the intended existence problem has no well-defined membership or hardness classification.

Step-by-step verification

1. Report-independent strategyproof mechanism

The proposed mechanism puts every agent into one group labeled \(a_1\), independently of all reports.

This is strategyproof under the definition in the task: changing an agent’s report cannot change the outcome, so it cannot change that agent’s true utility. Truthful reporting is therefore weakly dominant.

This argument covers every valid replica size \(N\), including types of zero mass. Since the same description applies to every \(N\), it supports the prover’s stated ordinary algorithmic interpretation of uniformity.

The conclusion that the literal existence language is all-YES is correct. It is, however, conditional on that interpretation of “uniform,” which the task itself does not define.

2. Merging groups with the same activity

When two groups carrying the same activity are merged:

  • Every activity-value contribution remains unchanged.
  • For each cross-group pair, the merger introduces both directed interaction terms.
  • These terms are nonnegative by hypothesis.

Thus welfare cannot decrease. Iterating the merger proves that some optimum has at most one group for each activity. This lemma is correct.

3. Uniform assignment within each type

For a fixed type \(\theta\), the displayed function \(F_\theta(x)\) correctly counts:

  • activity values;
  • ordered interactions among agents of type \(\theta\);
  • both directed interactions between type \(\theta\) and each distinct type \(\phi\).

The coefficient of \(x^2\) is indeed \(2\omega_{\theta,\theta}\ge 0\), so \(F_\theta\) is convex. A convex function on the interval \([0,n_\theta]\) is bounded above by the larger endpoint value. Hence replacing the current split of type \(\theta\) by either \(x=0\) or \(x=n_\theta\) cannot decrease welfare.

The successive application is substantively correct, but the write-up should explicitly state that it starts from an optimal outcome furnished by Lemma 2.1. Every nondecreasing replacement then remains optimal and does not undo the uniformity of previously processed types. This is a minor expositional omission.

The case \(n_\theta=0\) is harmless, although not mentioned.

4. Minimum-cut reduction

For type-uniform assignments, the welfare formula is correct:

  • \(n_\theta p_\theta(a_{y_\theta})\) counts activity values;
  • \(n_\theta(n_\theta-1)\omega_{\theta,\theta}\) counts ordered same-type interactions;
  • \(c_{\theta\phi}\) counts both directed cross-type contributions when the two types select the same activity.

With \(D_\theta(r)=B_\theta-b_{\theta r}\), maximizing welfare is equivalent to minimizing the displayed energy \(E(y)\), up to an assignment-independent constant.

Under the source-side/\(a_1\) convention:

  • \(s\to\theta\) contributes \(D_\theta(2)\) exactly when \(\theta\) is assigned \(a_2\);
  • \(\theta\to t\) contributes \(D_\theta(1)\) exactly when \(\theta\) is assigned \(a_1\);
  • two opposite arcs of capacity \(c_{\theta\phi}\) contribute exactly \(c_{\theta\phi}\) when the endpoints lie on opposite sides.

Therefore the cut capacity equals \(E(y)\). The reduction is correct.

The conclusion section says the graph has \(|\Theta|\) vertices, while the construction has \(|\Theta|+2\) vertices. This is a minor counting error with no complexity consequence.

The bit-complexity claim is reasonable for binary-encoded \(N\), rational data, and a compressed type-level output. The prover appropriately notes that explicitly outputting all agents may require \(\Omega(N)\) time. Because the task never specifies how \(N\) or outcomes are represented, this remains a conditional complexity statement rather than a fully formal classification.
