The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\), and ordinal rankings of types promised to be induced by at least one metric \(d\) on \(T\), compute a mass-pairing plan \(x\) from \((T,\mu,\succ)\). Require \(2x_{tt}+\sum_{u\ne t}x_{tu}=\mu_t\) for each \(t\), and require \(V_d(x)\ge \frac{5}{8}\mathrm{OPT}_d(\mu)\) for every compatible \(d\), where \(V_d(x)=\sum_{t<u}x_{tu}d(t,u)\) and \(\mathrm{OPT}_d(\mu)\) is the maximum value over feasible mass-pairing plans.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T=\{1,\ldots,\tau\}\): the types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; set \(m=|T|=\tau\), and let \(L\) be the total input bit length.
Each type \(t\) supplies a strict ranking \(\succ_t\) of \(T\setminus\{t\}\). A compatible metric \(d:T\times T\to\mathbb R_{\ge0}\) satisfies \(u\succ_t v\Rightarrow d(t,u)\ge d(t,v)\); thus larger distances are preferred, and rankings may break distance ties arbitrarily. At least one compatible metric is promised, but none is supplied.
A feasible mass-pairing plan consists of nonnegative real quantities \(x_{tu}=x_{ut}\) satisfying \(2x_{tt}+\sum_{u\ne t}x_{tu}=\mu_t\) for every \(t\). Pairing within a type is allowed and has value zero.
Define \(V_d(x)=\sum_{t<u}x_{tu}d(t,u)\) and \(\mathrm{OPT}_d(\mu)=\max\{V_d(y):y\text{ is feasible}\}\).

Can an ordinal algorithm, using only \((T,\mu,\succ)\), return a rational feasible plan \(x\) in time polynomial in \(m,\tau,L\) such that \(V_d(x)\ge\frac58\mathrm{OPT}_d(\mu)\) for every compatible metric \(d\), or is this approximation guarantee impossible in polynomial time?

For finite agents, a polynomial-time randomized ordinal algorithm achieves expected value at least \(\frac58\) of the maximum-weight perfect matching when the agent count is divisible by six; the stated extension to arbitrary counts incurs a vanishing multiplicative error. [Source](https://sekarshre.github.io/publication/ordinal_journal/ordinal_journal.pdf)
No result settling the exact support-encoded mass-pairing question above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, interpreting the society as a distribution.
  • Specified strict rankings over other types, with weak distance inequalities and arbitrary ordering of equal distances, following the discrete preference convention.
  • Specified nonnegative real feasible pairing quantities, symmetric off-diagonal entries, and rational algorithm outputs.
  • Interpreted diagonal quantities as pairing distinct members of the same type, with zero metric value and consumption of twice the pairing mass.
  • Used ordinary real-valued metrics on the type set, as requested by the continuous question.
  • There is no separate alternative universe in this problem, so defined m to equal the support size tau and L to be the total input bit length.
  • Kept the continuous guarantee on the returned plan itself; the discrete anchor's guarantee is in expectation.

1. Result

The exact guarantee is achievable in polynomial time. A deterministic ordinal algorithm can return a rational feasible plan \(x\) satisfying

\(\displaystyle V_d(x)\ge \frac58\mathrm{OPT}_d(\mu)\)

simultaneously for every compatible metric \(d\).

The construction compresses the greedy/random idea in [Anshelevich–Sekar, Section 3.1](https://sekarshre.github.io/publication/ordinal_journal/ordinal_journal.pdf). The proof below is self-contained. Population expansion is used only as a proof device.

2. Constructing a partial greedy plan

Initialize residual masses \(r_t=\mu_t\), a symmetric partial plan \(g=0\), and total paired mass \(s=0\). Continue until \(s=\frac13\).

Suppose first that the active support \(A=\{t:r_t>0\}\) contains at least two types. For each \(t\in A\), let \(f(t)\) be its highest-ranked type in \(A\setminus\{t\}\). Find a directed cycle of \(f\), and select an edge \(\{t,u\}\) from that cycle.

This edge is undominated for every compatible metric: its distance is at least every distance incident to either endpoint within \(A\). Indeed, writing the cycle as \(t_0,\ldots,t_{\ell-1}\), compatibility and symmetry give

\(\displaystyle d(t_i,t_{i+1})\ge d(t_i,t_{i-1})=d(t_{i-1},t_i).\)

Indices are interpreted cyclically. Consequently, all cycle-edge distances are equal. Each equals the maximum distance from its respective endpoint to an active type.

Set

\(\displaystyle \delta=\min\left\{r_t,r_u,\frac13-s\right\}.\)

Increase \(g_{tu}=g_{ut}\) by \(\delta\), decrease both residual masses by \(\delta\), and increase \(s\) by \(\delta\).

If only one active type \(t\) remains, instead increase \(g_{tt}\) by \(\delta=\frac13-s\) and decrease \(r_t\) by \(2\delta\). This is possible because the remaining total mass is \(1-2s\), and

\(\displaystyle 2\left(\frac13-s\right)\le 1-2s.\)

Every iteration either finishes the construction or removes at least one active type. Thus there are at most \(m\) iterations.

Define the consumed and residual masses by

\(\displaystyle a_t=2g_{tt}+\sum_{u\ne t}g_{tu},\qquad b_t=\mu_t-a_t.\)

They satisfy

\(\displaystyle a_t,b_t\ge0,\qquad \sum_t a_t=\frac23,\qquad \sum_t b_t=\frac13.\)

3. The greedy prefix achieves half the optimum

We first prove a finite counting lemma, allowing zero distances between distinct vertices.

Lemma. Let \(N\) be divisible by six. On a complete graph with nonnegative symmetric weights satisfying the triangle inequality, select \(k=N/3\) matching edges successively, each undominated among the currently unmatched vertices. If their total weight is \(G_N\), then every perfect matching \(M\) has weight at most \(2G_N\).

Proof. Write the selected edges as \(e_1,\ldots,e_k\), with weights \(w_1,\ldots,w_k\), and put \(W=\min_i w_i\).

Let \(B\) be the \(N/3\) vertices left unmatched. Suppose \(M\) has \(h\) edges entirely inside \(B\). Then \(h\le N/6\).

Assign every other edge of \(M\) to the first selected edge intersecting it. At that selection step, both endpoints of the assigned edge are still unmatched. Undomination therefore implies that its weight is at most the weight of the selected edge.

Let \(c_i\) be the number of edges assigned to \(e_i\). Since \(M\) is a matching,

\(\displaystyle 0\le c_i\le2,\qquad \sum_i c_i=N/2-h.\)

Now consider any edge \(\{p,q\}\) of \(M\) inside \(B\), and any selected edge \(e_i=\{v,z\}\). Both \(p,q\) were unmatched when \(e_i\) was selected. Hence

\(\displaystyle w(p,q)\le w(p,v)+w(v,q)\le2w_i.\)

Thus the total weight of the \(h\) edges inside \(B\) is at most \(2hW\). Meanwhile,

\(\displaystyle 2G_N-\sum_i c_iw_i =\sum_i(2-c_i)w_i \ge\left(2k-\sum_i c_i\right)W =\left(\frac N6+h\right)W \ge2hW. \)

Combining the bounds for the assigned edges and the edges inside \(B\) proves \(w(M)\le2G_N\). \(\square\)

Application to mass plans. Fix a compatible metric \(d\) and a rational feasible plan \(y\). Choose \(N\), divisible by six, so that all masses, all greedy batch quantities, and all entries of \(y\), multiplied by \(N\), are integers.

Create \(N\mu_t\) labeled copies of type \(t\). Give two copies of types \(t,u\) distance \(d(t,u)\); copies of the same type have distance zero. These weights are nonnegative, symmetric, and satisfy the triangle inequality.

The plan \(y\) is realizable as a perfect matching of these copies: use \(Ny_{tu}\) edges between distinct types and \(Ny_{tt}\) edges within type \(t\). Its weight is \(NV_d(y)\).

Likewise, realize each greedy batch by repeatedly selecting copy pairs of its designated types. Every selected edge is undominated: the cycle argument establishes domination over all active types, and within-type distances are zero. The within-type batch occurs only when all remaining copies have the same type. The resulting greedy prefix has exactly \(N/3\) edges and weight \(NV_d(g)\).

The lemma yields

\(\displaystyle V_d(g)\ge\frac12V_d(y).\)

To extend this to real feasible plans, for each positive integer \(q\) round every off-diagonal entry of \(y\) down:

\(\displaystyle y^{(q)}_{tu}=\frac{\lfloor qy_{tu}\rfloor}{q}\quad(t<u),\qquad y^{(q)}_{tt}=\frac12\left(\mu_t-\sum_{u\ne t}y^{(q)}_{tu}\right).\)

These plans are rational, nonnegative, feasible, and converge coordinatewise to \(y\). Their values therefore converge to \(V_d(y)\).

The feasible set is nonempty and compact, so the optimum is attained. Consequently,

\(\displaystyle \boxed{V_d(g)\ge\frac12\mathrm{OPT}_d(\mu).}\)

4. The output plan and its guarantee

Return the symmetric rational plan defined by

\(\displaystyle x_{tu}=\frac34\left(g_{tu}+\mu_tb_u+\mu_ub_t\right) \quad(t\ne u), \)

and

\(\displaystyle x_{tt}=\frac34\left(g_{tt}+\mu_tb_t\right).\)

All entries are nonnegative.

Feasibility

Using \(\sum_u b_u=\frac13\), \(\sum_u\mu_u=1\), and \(a_t+b_t=\mu_t\), we obtain

\(\displaystyle 2x_{tt}+\sum_{u\ne t}x_{tu} =\frac34\left(a_t+\mu_t\sum_u b_u+b_t\sum_u\mu_u\right) =\frac34\left(\mu_t+\frac{\mu_t}{3}\right) =\mu_t. \)

Thus \(x\) is feasible.

Approximation

Fix any compatible metric \(d\), and write

\(\displaystyle H_d=\sum_{t,u}\mu_tb_ud(t,u).\)

Since \(d(t,t)=0\), the output formula gives

\(\displaystyle V_d(x)=\frac34\left(V_d(g)+H_d\right).\)

For any feasible plan \(y\) and any type \(v\), the triangle inequality implies

\(\displaystyle V_d(y) \le\sum_{t\le u}y_{tu}\bigl(d(t,v)+d(u,v)\bigr) =\sum_t\mu_td(t,v). \)

Here the sum includes within-type entries; the equality follows from the feasibility constraints.

Multiply this inequality by \(3b_v\) and sum over \(v\). These coefficients sum to one, so

\(\displaystyle V_d(y)\le3H_d,\qquad\text{and hence}\qquad H_d\ge\frac13\mathrm{OPT}_d(\mu).\)

Together with the greedy-prefix bound, this proves

\(\displaystyle V_d(x) \ge\frac34\left(\frac12+\frac13\right)\mathrm{OPT}_d(\mu) =\frac58\mathrm{OPT}_d(\mu). \)

The algorithm uses only masses and rankings. Therefore the same output \(x\) satisfies this inequality for every compatible metric.

5. Polynomial running time and output size

Let \(D\) be the product of the denominators of the input masses. Its binary length is \(O(L)\). Every greedy batch quantity, residual mass, and entry of \(g\) has denominator dividing \(3D\): this follows inductively from the updates, which use subtraction and a minimum with \(\frac13-s\).

The output entries consequently have denominators dividing \(4D^2\), so each has polynomial bit length.

There are at most \(m\) greedy iterations. Finding all active top choices and a directed cycle takes \(O(m^2)\) elementary ranking operations per iteration. Computing the output requires \(O(m^2)\) rational arithmetic operations. All arithmetic involves polynomially many bits.

Hence the running time and output size are polynomial in \(m,\tau,L\), with \(m=\tau\).
