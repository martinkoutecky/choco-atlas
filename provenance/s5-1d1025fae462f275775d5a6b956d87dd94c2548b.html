The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), and a finitely supported distribution \(\mu\) with positive binary-rational masses over approval types \(A_t\subseteq C\), find a committee \(W\subseteq C\) of size \(k\) satisfying continuous JUQ. A violation consists of \(c\in W\), \(d\notin W\), and a positive-mass subpopulation \(S\) of supporters of \(d\), such that every type supporting \(c\) has \(|A_t\cap W|>\lceil k\mu(c)\rceil\), while every type represented in \(S\) has \(|A_t\cap((W\cup\{d\})\setminus\{c\})|\le\lceil k\mu(S)\rceil\).

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m=|C|>0\) and an integer \(1\le k\le m\), a society is given by its support: distinct approval types \(A_t\subseteq C\), each with positive binary-rational mass \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval types; empty approval sets are allowed. Let \(L\) be the total input bit length.
Define \(\mu(c)=\sum_{t:c\in A_t}\mu_t\), and require \(\mu(c)>0\) for every \(c\in C\).
A subpopulation \(S\) is a vector of divisible masses \(s_t\in[0,\mu_t]\), with \(\mu(S)=\sum_t s_t>0\); it consists of supporters of \(d\) when \(s_t=0\) whenever \(d\notin A_t\).
A committee \(W\subseteq C\) with \(|W|=k\) satisfies continuous justified upper quota (JUQ) if there are no \(c\in W\), \(d\in C\setminus W\), and such a subpopulation \(S\) of supporters of \(d\) for which both conditions hold:
\(\lvert A_t\cap W\rvert>\lceil k\mu(c)\rceil\) for every \(t\) with \(c\in A_t\), and \(\lvert A_t\cap((W\cup\{d\})\setminus\{c\})\rvert\le\lceil k\mu(S)\rceil\) for every \(t\) with \(s_t>0\).

Can a size-\(k\) committee satisfying continuous JUQ be found in time polynomial in \(m,\tau,k,L\), or is this search problem NP-hard?

For explicitly listed finite voters, finding a size-\(k\) JUQ committee is polynomial-time solvable by the Upper Quota Elimination Rule. [Source](https://arxiv.org/html/2606.19968v1)
No published result settling this exact divisible-mass formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass 1, matching the discrete quota's normalization by the total electorate.
  • Required a nonempty candidate set, an integer committee size between 1 and the number of candidates, and positive supporter mass for every candidate, carrying over the discrete domain conditions.
  • Specified subpopulations as arbitrary divisible real masses within each type, with positive total mass; the graded question did not specify whether a type could be partially included.
  • Allowed empty approval sets, as in the discrete approval-profile domain, and defined L as the total input bit length.

Result

A size-\(k\) committee satisfying continuous JUQ can be found in time polynomial in \(m,\tau,k,L\).

The algorithm is the mass-weighted version of the [Upper Quota Elimination Rule, Section 3.4](https://arxiv.org/html/2606.19968v1). Below is a self-contained proof that it works for divisible subpopulations and binary-encoded rational masses, without expanding the population into individual voters.

1. Definitions and algorithm

For each candidate \(c\), define its upper quota by \(q_c=\lceil k\mu(c)\rceil\). For a candidate set \(X\subseteq C\), write \(r_t(X)=|A_t\cap X|\).

Call \(c\in X\) eligible for deletion if \(r_t(X)>q_c\) for every type \(t\) approving \(c\). Let \(E(X)\) be the set of eligible candidates.

Run the following algorithm:

  • Initialize \(X=C\).
  • While \(|X|>k\) and \(E(X)\ne\varnothing\), choose a candidate \(d\in E(X)\) minimizing \(\mu(d)\), breaking ties arbitrarily, and delete \(d\).
  • If \(|X|=k\), output \(X\). Otherwise, output any size-\(k\) subset of \(X\).

Every deletion reduces the set size by one, and deletions occur only when its size exceeds \(k\). Thus the algorithm always outputs exactly \(k\) candidates.

We prove correctness next.

2. Eligibility and deletion priority

Lemma 1. If \(Y\subseteq X\), then \(E(Y)\subseteq E(X)\).

Proof. If \(c\in E(Y)\), then \(c\in X\). For every type approving \(c\), we have \(r_t(X)\ge r_t(Y)>q_c\). Hence \(c\in E(X)\). \(\square\)

Consequently, deletions cannot make a previously ineligible candidate eligible.

Lemma 2. Suppose candidate \(d\) is deleted. Any candidate \(e\) deleted later, and any candidate \(c\) eligible at a later stage, satisfies \(\mu(e)\ge\mu(d)\) and \(\mu(c)\ge\mu(d)\), respectively.

Proof. Let \(X^{-}\) be the set immediately before deleting \(d\). A candidate eligible at any later stage belongs to \(X^{-}\) and, by Lemma 1, was eligible in \(X^{-}\). Since \(d\) minimized support mass among \(E(X^{-})\), that candidate has support mass at least \(\mu(d)\).

Apply this argument to \(e\) immediately before its deletion, and to \(c\) at the specified later stage. \(\square\)

In particular, their upper quotas satisfy \(q_e\ge q_d\) and \(q_c\ge q_d\), because multiplication by positive \(k\) and taking ceilings preserve weak inequalities.

3. The supporter invariant

Lemma 3. Once \(d\) has been deleted, every subsequent set \(X\) produced by the elimination loop satisfies \(r_t(X)\ge q_d\) for every type \(t\) approving \(d\).

Proof. Immediately before deleting \(d\), eligibility gives \(r_t(X^{-})>q_d\). Since both sides are integers, deleting \(d\) leaves \(r_t(X^{-}\setminus\{d\})\ge q_d\).

Now consider a later deletion of a candidate \(e\). Fix a type \(t\) approving \(d\).

If \(e\notin A_t\), this deletion leaves its satisfaction unchanged. If \(e\in A_t\), eligibility of \(e\) gives \(r_t(Y)>q_e\), where \(Y\) is the set immediately before deleting \(e\). Thus \(r_t(Y\setminus\{e\})\ge q_e\ge q_d\), using integrality and Lemma 2.

Induction over the subsequent deletions proves the invariant. \(\square\)

4. Correctness for divisible subpopulations

Proposition. Every set \(X\) produced by the elimination loop satisfies the continuous JUQ condition, using the given target size \(k\).

Proof. Suppose otherwise. Let \(c\in X\), \(d\in C\setminus X\), and a positive-mass subpopulation \(S=(s_t)\) witness a violation.

The first condition of the violation says exactly that \(c\in E(X)\). Since the algorithm started with \(C\), candidate \(d\) was deleted earlier. Lemma 2 therefore gives \(q_c\ge q_d\).

Consider the swapped set \(X'=(X\cup\{d\})\setminus\{c\}\). We show that every type approving \(d\) has satisfaction strictly greater than \(q_d\) in \(X'\).

Fix such a type \(t\).

  • If \(c\notin A_t\), Lemma 3 gives \(r_t(X)\ge q_d\). Adding \(d\) increases its satisfaction by one, so \(r_t(X')=r_t(X)+1>q_d\).
  • If \(c\in A_t\), exchanging \(c\) for \(d\) leaves its satisfaction unchanged. Eligibility of \(c\) gives \(r_t(X')=r_t(X)>q_c\ge q_d\).

Because \(S\) consists of supporters of \(d\), its total mass satisfies \(\mu(S)=\sum_{t:d\in A_t}s_t\le\sum_{t:d\in A_t}\mu_t=\mu(d)\). Hence \(\lceil k\mu(S)\rceil\le q_d\).

The mass of \(S\) is positive, so some type \(t\) has \(s_t>0\). That type approves \(d\), and the preceding inequalities give \(r_t(X')>q_d\ge\lceil k\mu(S)\rceil\). This contradicts the second condition of a JUQ violation. \(\square\)

It remains to check the algorithm’s possible final truncation.

If the loop stops at size \(k\), the proposition proves correctness directly. Otherwise, it stops with \(|X|>k\) and \(E(X)=\varnothing\). For any size-\(k\) subset \(W\subseteq X\), Lemma 1 gives \(E(W)\subseteq E(X)=\varnothing\). The first condition of any JUQ violation would require a candidate in \(E(W)\), so \(W\) satisfies continuous JUQ as well.

Thus every output of the algorithm satisfies the required axiom.

5. Polynomial bit complexity

Write each input mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\). Set \(D=\prod_{t=1}^{\tau}b_t\) and \(w_t=a_t(D/b_t)\).

Then \(\mu_t=w_t/D\), and normalization gives \(\sum_t w_t=D\). The bit length of \(D\) is at most the sum of the denominator bit lengths, hence \(O(L)\). Moreover, each \(w_t\le D\).

For each candidate, compute \(P_c=\sum_{t:c\in A_t}w_t\). Its mass is \(P_c/D\), its quota is \(q_c=\lceil kP_c/D\rceil\), and comparing support masses amounts to comparing the integers \(P_c\). These calculations use integers with \(O(L+\log k)\) bits.

There are at most \(m-k\) deletions. At each iteration, scanning all candidate–type pairs determines eligibility in \(O(m\tau)\) elementary operations. Finding a minimum-mass eligible candidate and updating the satisfaction counts also take polynomial time. Thus the algorithm uses \(O(m^2\tau)\) elementary operations after polynomial-time preprocessing, with polynomial bit complexity throughout.

The search problem is therefore polynomial-time solvable.
