The continuous mirror question, as graded

Given a cycle \(C_n\) and a partition \(V_1,\ldots,V_m\), find rational weights \(\lambda_I\geq 0\) over independent sets \(I\) of \(C_n\) such that \(\sum_I\lambda_I=1\) and \(\sum_I\lambda_I|I\cap V_i|\geq |V_i|/2-1\) for every \(i\).

Packaged proof task (what the prover saw — nothing else)

Input: an explicitly listed simple cycle \(C_n\), with \(n\geq 3\), and a partition \(V_1,\ldots,V_m\) of its vertices into nonempty sets, with \(1\leq m\leq n\). Let \(L\) be the input bit length; no parity restriction is imposed.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here this convention represents the sought distribution, whose types are independent sets of \(C_n\).
Find such a distribution with \(\lambda_I\in\mathbb{Q}_{\geq 0}\), \(\sum_I\lambda_I=1\), and \(\sum_I\lambda_I|I\cap V_i|\geq |V_i|/2-1\) for every \(i\in\{1,\ldots,m\}\); unlisted independent sets have zero mass. Fairness is required only in expectation.
State running times in \(n,m,L,\tau\); polynomial time means polynomial in the input length, including the time to write the support and its masses.

Is this distribution search problem solvable in polynomial time, or is it \(\mathsf{NP}\)-hard under polynomial-time search reductions?

Finding a single independent set satisfying the same fairness inequalities is \(\mathsf{PPA}\)-complete, and every input has such a set. [Haviv](https://arxiv.org/abs/2011.01770)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The distribution search problem is solvable in polynomial time. Two independent sets, each assigned mass \(1/2\), always suffice.

Construction. Write the cycle vertices in cyclic order as \(v_0,v_1,\ldots,v_{n-1}\). Delete \(v_0\). The remaining induced graph is the path with consecutive vertices \(v_1,\ldots,v_{n-1}\). Define its two color classes by
\[ A=\{v_j:1\leq j\leq n-1,\ j\text{ odd}\}, \qquad B=\{v_j:1\leq j\leq n-1,\ j\text{ even}\}. \]
Both are independent sets of the original cycle: every edge whose endpoints remain joins consecutive indices, which have opposite parity. Since \(n\geq3\), both sets are nonempty and distinct.

Output the support \(A,B\), with
\[ \lambda_A=\lambda_B=\frac12. \]
All other independent sets have mass zero. These masses are nonnegative, sum to one, and have constant-length binary representations.

Verification of fairness. The sets \(A,B\) partition all vertices except \(v_0\). Thus every remaining vertex has inclusion probability \(1/2\), while \(v_0\) has inclusion probability zero.

For each partition class \(V_i\), let \(\delta_i=1\) if \(v_0\in V_i\), and let \(\delta_i=0\) otherwise. By linearity of expectation,
\[ \sum_I\lambda_I|I\cap V_i| =\frac{|A\cap V_i|+|B\cap V_i|}{2} =\frac{|V_i|-\delta_i}{2} \geq\frac{|V_i|}{2}-\frac12 \geq\frac{|V_i|}{2}-1. \]
This proves every required inequality, without any parity assumption. Indeed, the construction gives the stronger error bound \(1/2\) simultaneously for every subset of vertices.

Running time and output size. The support size is exactly \(\tau=2\), and the support lists contain \(n-1\) vertices in total. With vertex indices encoded in binary, the output has \(O(n\log(n+1))\) bits; the masses contribute only constant size.

If the cycle is supplied in cyclic order, reading the input and writing the construction takes \(O(L+n\log(n+1))\) bit operations. For an explicit edge-list representation, cyclic order can conservatively be recovered by scanning the input for the next edge at each traversal step, giving the polynomial bound
\[ O\!\left(nL+m+\tau n\log(n+1)\right), \qquad \tau=2. \]
The partition requires no further processing.

Individual support sets may violate fairness constraints; their average satisfies every constraint. Consequently, the stated hardness of finding a single fair independent set does not obstruct this construction.

Step-by-step verification

  • Deleting one vertex produces the stated path.

In a simple cycle \(C_n\), deleting \(v_0\) leaves exactly the edges between \(v_j\) and \(v_{j+1}\) for \(1\leq j\leq n-2\). This holds for every \(n\geq3\), including \(n=3\).

  • Both support sets are independent in the original cycle.

Every edge with both endpoints among the remaining vertices joins consecutive indices, hence opposite parity classes. Edges incident to \(v_0\) cannot have both endpoints in either support set because \(v_0\) is excluded. Thus both \(A\) and \(B\) are independent. Since \(v_1\in A\) and \(v_2\in B\), both sets are nonempty and distinct, establishing that the support size is exactly \(\tau=2\).

  • The masses define a valid distribution.

The assigned masses \(1/2\) are positive binary rationals and sum to one. Giving every unlisted independent set zero mass matches the required support representation.

  • The fairness calculation is exact.

Because \(A\) and \(B\) partition \(V(C_n)\setminus\{v_0\}\), for every partition class \(V_i\),
\[ |A\cap V_i|+|B\cap V_i|=|V_i|-\delta_i, \qquad \delta_i\in\{0,1\}. \]
Therefore its expected intersection size is exactly
\[ \frac{|V_i|-\delta_i}{2} \geq \frac{|V_i|}{2}-\frac12 \geq \frac{|V_i|}{2}-1. \]
Both inequalities have the correct direction and constants. The argument applies to singleton classes, to \(m=1\), and to both parities of \(n\). No assumption about class sizes is missing.

  • The stronger subset claim is justified.

The same identity applies to any subset of vertices, with its indicator for containing \(v_0\). Thus the claimed simultaneous error bound of \(1/2\) follows directly from the written calculation.

  • Running time includes output costs.

The support contains \(n-1\) vertex occurrences altogether. Binary vertex indices therefore require \(O(n\log(n+1))\) output bits, and the masses require constant space. The stated cyclic-order bound includes reading the input and writing this output. For an explicit edge list, repeated scans to identify successive cycle neighbors give the stated conservative polynomial bound \(O(nL+m+\tau n\log(n+1))\), with \(\tau=2\). The partition need not be processed because the fairness argument applies to every subset.

  • The distinction from finding one fair independent set is valid.

The task imposes fairness on expectations. It does not require either listed independent set to satisfy the inequalities individually. Accordingly, the supplied single-set hardness statement does not invalidate this construction.
