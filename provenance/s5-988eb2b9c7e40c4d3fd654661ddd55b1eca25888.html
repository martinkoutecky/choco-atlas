The continuous mirror question, as graded

Input: a finite set of types \(T\), positive rational masses \(\mu_t\) with \(\sum_{t\in T}\mu_t=1\), a fixed initial bundle \(B_t\) and additive binary valuation \(u_t\) for each type, and two indivisible added item types \(r,q\) with positive finite rational supplies \(S_r,S_q\) per unit of population. Let \(x_{t,z}\geq 0\) be the mass of type \(t\) receiving the integral bundle \(z=(z_r,z_q)\in\mathbb{Z}_{\geq 0}^2\), with \(\sum_z x_{t,z}=\mu_t\) and \(\sum_{t,z}x_{t,z}z_j\leq S_j\) for \(j\in\{r,q\}\). Decide whether such an assignment exists in which, for every \(t,t'\) and every \(z,z'\) with \(x_{t,z},x_{t',z'}>0\), \(u_t(B_t)+u_t(r)z_r+u_t(q)z_q\geq u_t(B_{t'})+u_t(r)z'_r+u_t(q)z'_q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
The input includes a finite set \(P\) of initial good labels, pairwise disjoint bundle templates \(B_t\subseteq P\), and additive valuations specified by \(u_t(p)\in\{0,1\}\) for every \(t\in T\) and \(p\in P\cup\{r,q\}\). Each recipient of type \(t\) retains a copy of the template \(B_t\).
There are exactly two additional indivisible item types \(r,q\), with positive finite binary-rational supplies \(S_r,S_q\) per unit of population. Initial bundles cannot be changed; unused additional supply is allowed, and there is no separate budget.
An assignment consists of real masses \(x_{t,z}\geq0\), indexed by \(t\in T\) and \(z=(z_r,z_q)\in\mathbb Z_{\geq0}^2\), satisfying \(\sum_z x_{t,z}=\mu_t\) and \(\sum_{t,z}x_{t,z}z_j\leq S_j\) for \(j\in\{r,q\}\); countably many bundles may have positive mass.
It is envy-free exactly when \(u_t(B_t)+u_t(r)z_r+u_t(q)z_q\geq u_t(B_{t'})+u_t(r)z'_r+u_t(q)z'_q\) whenever \(x_{t,z}>0\) and \(x_{t',z'}>0\), including \(t=t'\). Equality is permitted.
Write running times in \(m=|P|+2\), \(\tau\), and the total binary input length \(L\).

Is deciding whether an envy-free assignment exists solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite societies, the corresponding problem is \(\mathrm{NP}\)-complete with binary additive valuations, two positive finite supplies, and no separate budget, even with nested approval sets and polynomially bounded numerical quantities; with one additional item type it is polynomial-time solvable. [Source](https://arxiv.org/html/2608.10326v1)
No result settling this exact distribution-over-types problem was located.

Modeling choices made when packaging the task

  • Made the initial-goods encoding explicit using disjoint labeled bundle templates and binary per-good valuations, following the discrete initial-allocation definition; each population recipient holds its own copy of its type's template.
  • Specified assignment masses as real numbers and allowed countably many positive-mass integral bundles, preserving the graded question's unrestricted indexing.
  • Defined m as the number of initial good labels plus the two additional item types, and L as total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is \(\mathrm{NP}\)-complete, and hence \(\mathrm{NP}\)-hard. The hardness proof applies to dyadic masses and supplies. Its essential feature is that envy is tested against every bundle occurring with positive mass.

I first prove membership in \(\mathrm{NP}\), then give a reduction whose soundness explicitly allows arbitrary splitting of types.

1. Polynomial-size certificates. Write \(a_t=(u_t(r),u_t(q))\). Within-type envy-freeness implies that
\(a_t\cdot z=a_t\cdot z'\)
whenever both bundles have positive mass for type \(t\): apply the envy inequality in both directions.

We may delete from every recipient’s added bundle all items that their type does not approve. This preserves their own utility, weakly decreases every other type’s valuation of their bundle, and weakly decreases supply consumption. Consequently, any feasible assignment can be replaced by one with the following form:

  • If \(a_t=(0,0)\), everyone of type \(t\) receives \((0,0)\).
  • If \(a_t=(1,0)\), everyone receives \((k_t,0)\), for an integer \(k_t\).
  • If \(a_t=(0,1)\), everyone receives \((0,k_t)\), for an integer \(k_t\).
  • If \(a_t=(1,1)\), every supported bundle satisfies \(z_r+z_q=k_t\), for an integer \(k_t\).

For every approving type, the supply inequalities give
\(\mu_t k_t\leq S_r+S_q\).
Thus \(k_t\leq (S_r+S_q)/\mu_t\), and every remaining bundle coordinate has binary length polynomial in \(L\).

For a type approving both items, let \(y_t\) be its mean number of \(r\)-items. Replace its distribution by the two adjacent bundles
\((\lfloor y_t\rfloor,k_t-\lfloor y_t\rfloor)\) and
\((\lceil y_t\rceil,k_t-\lceil y_t\rceil)\),
using weights that preserve the mean; if \(y_t\) is integral, use one bundle.

Here is why this replacement preserves pointwise envy-freeness. Let \(l_t,h_t\) be the minimum and maximum \(r\)-coordinates in the original support after deletion. They exist because that support is contained in the finite set of bundles with total \(k_t\). Both replacement coordinates lie in \([l_t,h_t]\). An observer approving only \(r\) values them no more than the original bundle at \(h_t\); an observer approving only \(q\) values them no more than the original bundle at \(l_t\). An observer approving both items sees the unchanged total \(k_t\), and an observer approving neither sees zero. Every recipient’s own utility is unchanged. Hence all envy inequalities continue to hold, even if both replacement bundles are made available for every type simultaneously.

It remains to obtain rational weights of polynomial binary length. For each type with two distinct replacement bundles, call the bundle with fewer \(r\)-items its lower bundle. Put all its mass on that bundle initially, and let \(A_r,A_q\) be the resulting total consumption. Moving mass \(\lambda_t\) to its upper bundle changes consumption by \((\lambda_t,-\lambda_t)\), where \(0\leq\lambda_t\leq\mu_t\).

If \(J\) is the set of such types, the supply conditions therefore become
\[ \]
\(\max\{0,A_q-S_q\}\leq\sum_{t\in J}\lambda_t\leq \min\{\sum_{t\in J}\mu_t,S_r-A_r\}\).

This interval is nonempty because the mean-preserving replacement satisfies the supplies. Choose its rational lower endpoint and distribute that amount greedily among the capacities \(\mu_t\). All resulting weights are rational, and at most one type has a weight strictly between zero and its capacity. Their binary lengths are polynomial: they are obtained by sums, products with the bounded integer coordinates, and differences of input rationals.

Thus every yes-instance has a rational certificate using at most \(\tau+1\) positive-mass bundles in total. A verifier checks type masses, both supplies, and every ordered pair of supported bundles. Computing initial-bundle values takes \(O(\tau^2m)\) additions, and all subsequent arithmetic has polynomial bit length. Verification is polynomial in \(m,\tau,L\). This proves membership in \(\mathrm{NP}\).

2. Reduction from \(\mathrm{CLIQUE}\). The initial-good gadget below is adapted from the cited [finite-society reduction, Theorem 5](https://arxiv.org/html/2608.10326v1). The soundness argument here establishes its validity for distributions over types.

Start with a simple graph \(G=(V,E)\) and target clique size \(3\leq\ell\leq |V|\). This restriction of \(\mathrm{CLIQUE}\) remains \(\mathrm{NP}\)-hard: excluded cases are decidable directly and can be mapped to fixed yes- or no-instances satisfying the restriction.

Put \(M=\binom{\ell}{2}\). If necessary, add disjoint two-vertex components until \(|E|\geq M+1\). Since \(\ell\geq3\), these components cannot create an \(\ell\)-clique. The padding is polynomial, and afterwards
\(|E|\geq M+1=\ell+(\ell-1)(\ell-2)/2>\ell\).

Create a vertex type \(t_v\) for each vertex, an edge type \(t_e\) for each edge, and a distinguished type \(b\). Let \(n=|V|+|E|+1\), and let \(N\) be the smallest power of two with \(N\geq n\). Give each constructed type mass \(1/N\). If \(N>n\), add a dummy type of mass \((N-n)/N\), with zero valuations and an empty template.

The initial goods, templates, and approvals are:

| Good | Owner’s template | Types approving it |
|---|---|---|
| \(p_b\) | \(B_b=\{p_b\}\) | \(b\) and every edge type |
| \(p_v\), for \(v\in V\) | \(B_{t_v}=\{p_v\}\) | Only \(t_v\) |
| \(p_e\), for \(e=\{v,w\}\) | \(B_{t_e}=\{p_e\}\) | Only \(t_v,t_w\) |

All unlisted initial-good valuations are zero. Vertex types approve \(r\) only; edge types approve both \(r,q\); \(b\) and the dummy approve neither. Set
\(S_r=(M+\ell)/N\) and \(S_q=(|E|-M)/N\).

Both supplies are positive. All masses and supplies are dyadic rationals, and the templates are pairwise disjoint. The construction has \(m=n+2\), \(\tau\leq n+1\), and \(L=O(n^2\log(n+1))\), so it is polynomial.

3. A clique gives an envy-free assignment. Suppose \(K\subseteq V\) is an \(\ell\)-clique. Give every recipient:

  • one \(r\)-item if their edge type corresponds to an edge inside \(K\);
  • one \(q\)-item if their edge type corresponds to any other edge;
  • one \(r\)-item if their vertex type belongs to \(K\);
  • no added items otherwise.

Exactly \(M\) edge types receive \(r\). Consumption is therefore precisely \(S_r,S_q\).

Every edge type has own utility one. It values \(b\)’s bundle at one, every edge bundle at one, and every vertex bundle at at most one.

A vertex type in \(K\) has own utility two, and values every bundle at at most two. A vertex type outside \(K\) has own utility one. An incident edge cannot lie inside \(K\), so its bundle has value one; nonincident edge bundles and other vertex bundles also have value at most one.

Type \(b\) values only its own initial good, and the dummy values nothing. These checks cover every observer type and prove envy-freeness.

4. Any envy-free distribution gives a clique. Now assume an arbitrary feasible envy-free assignment, allowing countably many supported bundles and real masses.

Every edge type values its own initial template at zero. Within-type envy-freeness therefore forces its added-item total to be a fixed integer. Every edge type also values every other edge template at zero and approves both added items. The envy inequalities between edge types, in both directions, force these integers to coincide. Denote their common value by \(h\).

Every edge type values \(b\)’s initial good at one, so \(h\geq1\). The edge population alone consumes \(h|E|/N\) added items. Consequently,
\(h|E|/N\leq S_r+S_q=(|E|+\ell)/N\).

Since \(|E|>\ell\), this implies \(h<2\). Integrality gives \(h=1\). Thus every edge recipient receives exactly one of \((1,0)\) and \((0,1)\), regardless of how its type is split.

Let \(\alpha_e\in[0,1]\) be the fraction of edge type \(t_e\) receiving \((1,0)\). The edge population’s \(q\)-consumption is
\((|E|-\sum_e\alpha_e)/N\).
The \(q\)-supply bound implies
\(\sum_e\alpha_e\geq M\).

Define
\(E^+=\{e\in E:\alpha_e>0\}\),
and let \(W\) be the set of endpoints of these edges.

Within-type envy-freeness forces every vertex type \(t_v\) to have a fixed integer \(r\)-count \(k_v\), because its own utility is \(1+z_r\). If \(v\in W\), an incident edge type has positive mass receiving \((1,0)\). Type \(t_v\) values that recipient’s initial good and its \(r\)-item at one each. Pointwise envy-freeness therefore requires
\(1+k_v\geq2\), hence \(k_v\geq1\).

The \(r\)-consumption of edge recipients and vertex types in \(W\) is consequently at least
\((\sum_e\alpha_e+|W|)/N\).
Applying the \(r\)-supply bound gives
\(\sum_e\alpha_e+|W|\leq M+\ell\).
Together with \(\sum_e\alpha_e\geq M\), this yields \(|W|\leq\ell\).

Finally, each \(\alpha_e\leq1\), and every edge in \(E^+\) has both endpoints in \(W\). Since the graph is simple,
\(M\leq\sum_e\alpha_e\leq|E^+|\leq\binom{|W|}{2}\leq\binom{\ell}{2}=M\).

All inequalities are equalities. Because \(\ell\geq3\), equality of the binomial coefficients with \(|W|\leq\ell\) implies \(|W|=\ell\). Moreover, \(E^+\) contains every possible edge on \(W\). Hence \(W\) is an \(\ell\)-clique.

The reduction proves \(\mathrm{NP}\)-hardness for the exact distribution-over-types model, and the certificate argument proves membership in \(\mathrm{NP}\). Therefore the decision problem is \(\mathrm{NP}\)-complete; a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
