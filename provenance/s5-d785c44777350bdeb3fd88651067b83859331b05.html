The continuous mirror question, as graded

Given a finite type set \(T\), rational population shares \(\mu_t\), principal values \(x_t\), agent values \(v_t>0\), penalty fraction \(c\), and per-capita supply \(\rho\in(0,1]\) of individually indivisible awards, find allocation probabilities \(q_t\in[0,1]\) maximizing \(\sum_{t\in T}\mu_t x_tq_t\), subject to \(\sum_{t\in T}\mu_tq_t\le\rho\) and \(q_t\ge(1-c)q_s\) for every \(t,s\in T\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There is one kind of individually indivisible award, so \(m=1\). Inputs also include binary rational principal values \(x_t\in\mathbb Q\), with \(\max_t x_t>0\), agent values \(v_t\in\mathbb Q_{>0}\), a penalty fraction \(c\in\mathbb Q\cap(0,1)\), and per-capita supply \(\rho\in\mathbb Q\cap(0,1]\). Retaining an award gives the principal zero payoff.
Each individual receives at most one award. An individual may report any type in \(T\); a verified false report destroys fraction \(c\) of that individual's award utility, while truthful reports are unpenalized. There are no transfers.
Choose allocation probabilities \(q_t\in[0,1]\) maximizing \(\sum_{t\in T}\mu_t x_tq_t\), subject to \(\sum_{t\in T}\mu_tq_t\le\rho\) and \(q_t\ge(1-c)q_s\) for every \(t,s\in T\). Supply constrains allocated mass; unused supply is permitted.
For a binary rational threshold \(K\), the decision problem asks whether a feasible allocation has principal payoff at least \(K\). Let \(L\) be the total input bit length, including \(K\); state running times in \(m,\tau,L\).
Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?
Known for the finite-agent model: optimal incentive-compatible allocation rules and optimal reduced forms are equivalent when reduced-form feasibility includes the Matthews–Border constraints. This is an implementation equivalence, not a computational complexity classification; it does not classify the mass-allocation problem stated here.

Result

The decision problem is in \(\mathrm{P}\). For \(m=1\), an exact algorithm runs in \(O(\tau\log(\tau+1)L^3)\) bit operations.

Below is a direct proof, including an explicit algorithm. It uses only the mass-allocation constraints in the question.

1. An equivalent formulation

Write \(\alpha=1-c\), so \(0<\alpha<1\). Introduce an auxiliary variable \(u\) and impose

\(\displaystyle 0\le u\le1,\qquad \alpha u\le q_t\le u\quad(t\in T),\qquad \sum_t\mu_tq_t\le\rho.\)

This formulation has exactly the same feasible allocations as the original problem:

  • Given an originally feasible allocation, take \(u=\max_s q_s\). The incentive constraints give \(q_t\ge\alpha u\) for every \(t\).
  • Conversely, these bounds imply \(q_t\ge\alpha u\ge\alpha q_s\) for every pair \(t,s\).

Because the masses sum to one, every feasible pair satisfies \(\sum_t\mu_tq_t\ge\alpha u\). Thus the possible values of \(u\) are exactly the interval \([0,U]\), where

\(\displaystyle U=\min\{1,\rho/\alpha\}.\)

Indeed, for any \(u\) in this interval, the allocation \(q_t=\alpha u\) is feasible.

Let \(F(u)\) be the largest payoff attainable with this fixed value of \(u\). The original optimum is therefore \(\max_{0\le u\le U}F(u)\).

2. Solving the problem for fixed \(u\)

Define \(X=\sum_t\mu_tx_t\). List the types with positive principal value as \(1,\ldots,p\), in nonincreasing order:

\(\displaystyle x_1\ge x_2\ge\cdots\ge x_p>0.\)

The hypothesis \(\max_t x_t>0\) ensures \(p\ge1\). Define prefix sums

\(\displaystyle A_j=\sum_{i=1}^j\mu_i,\qquad B_j=\sum_{i=1}^j\mu_ix_i,\qquad A_0=B_0=0.\)

For \(u>0\), express allocations as \(q_t=\alpha u+cu\,y_t\), where \(0\le y_t\le1\). The supply constraint becomes

\(\displaystyle \sum_t\mu_ty_t\le h(u),\qquad h(u)=\frac{\rho-\alpha u}{cu}.\)

The objective becomes

\(\displaystyle \alpha uX+cu\sum_t\mu_tx_ty_t.\)

For any type with \(x_t\le0\), setting \(y_t=0\) weakly improves the objective and preserves feasibility. Consequently, define

\(\displaystyle G(h)=\max\left\{\sum_{i=1}^p x_ir_i:\ 0\le r_i\le\mu_i,\ \sum_{i=1}^p r_i\le h\right\},\)

where \(r_i=\mu_i y_i\). Then \(F(u)=\alpha uX+cuG(h(u))\).

We now prove the needed fractional-knapsack formula. If \(h\ge A_p\), positivity of all \(x_i\) gives \(G(h)=B_p\). Otherwise choose \(j\) with \(A_{j-1}\le h\le A_j\). Every feasible vector satisfies

\(\displaystyle \sum_{i=1}^p x_ir_i=x_j\sum_{i=1}^p r_i+\sum_{i=1}^p(x_i-x_j)r_i \le x_jh+\sum_{i<j}(x_i-x_j)\mu_i =B_{j-1}+x_j(h-A_{j-1}).\)

The inequality follows because \(x_j>0\), the coefficients for \(i<j\) are nonnegative, and those for \(i>j\) are nonpositive.

Equality is attained by taking \(r_i=\mu_i\) for \(i<j\), \(r_j=h-A_{j-1}\), and \(r_i=0\) for \(i>j\). Hence

\(\displaystyle G(h)=B_{j-1}+x_j(h-A_{j-1})\quad\text{when }A_{j-1}\le h\le A_j.\)

This proves the fixed-\(u\) optimum completely.

3. Only linearly many candidates are needed

For \(0\le j\le p\), define

\(\displaystyle u_j=\frac{\rho}{\alpha+cA_j}.\)

All denominators are positive. Moreover, \(h(u_j)=A_j\), so these are precisely the breakpoints of the fixed-\(u\) optimization.

For \(0<u\le u_p\), all positive types receive their full increment, giving

\(\displaystyle F(u)=u(\alpha X+cB_p).\)

For \(u_j\le u\le u_{j-1}\), substituting the proved formula for \(G\) gives

\(\displaystyle F(u)=\rho x_j+u\left[\alpha X+cB_{j-1}-x_j(\alpha+cA_{j-1})\right].\)

Thus \(F\) is affine on every interval between consecutive breakpoints. Also, \(F(0)=0\), and the first formula shows continuity at zero.

An affine function attains its maximum on a closed interval at an endpoint. Applying this fact to each piece of \([0,U]\), the global optimum occurs in the finite set

\(\displaystyle \mathcal C=\{0,U\}\cup\{u_j:\ 0\le j\le p,\ u_j\le U\}.\)

At a breakpoint, evaluation is particularly simple:

\(\displaystyle F(u_j)=u_j(\alpha X+cB_j).\)

For \(F(U)\), compute \(h(U)\). Use the full-allocation formula if \(h(U)\ge A_p\); otherwise find a prefix containing \(h(U)\) and use the corresponding affine formula.

Therefore the algorithm is:

  • Sort the positive types by \(x_t\).
  • Compute \(X\) and the prefix sums \(A_j,B_j\).
  • Evaluate \(F\) at all candidates in \(\mathcal C\).
  • Answer yes exactly when their maximum is at least \(K\).

The candidate \(0\) accounts for the possibility that every positive allocation has negative payoff because incentive compatibility forces allocations to sufficiently unfavorable types.

The algorithm can also recover an optimal allocation. At \(u_j\), assign \(q_i=u_j\) to the first \(j\) positive types and \(q_t=\alpha u_j\) to every other type. Its allocated mass is \(u_j(\alpha+cA_j)=\rho\). At \(U\), use the fractional-knapsack allocation proved above.

4. Exact running time

Sorting requires \(O(\tau\log(\tau+1))\) rational comparisons. Prefix construction, breakpoint evaluation, and evaluation at \(U\) require \(O(\tau)\) additional rational operations.

All intermediate rational numbers, stored in reduced form, have \(O(L)\) bits:

  • A common denominator for the prefix sums divides a product of input denominators, whose total bit length is at most \(L\).
  • The masses sum to one, so the magnitudes of \(X\) and \(B_j\) are bounded by \(\max_t|x_t|\).
  • Each subsequent formula uses only a constant number of arithmetic operations on these prefix sums and input rationals.

Using elementary integer arithmetic and the Euclidean algorithm, each rational operation or comparison takes at most \(O(L^3)\) bit operations. This yields the stated bound \(O(\tau\log(\tau+1)L^3)\) for \(m=1\).

The positive agent values introduce no additional computational dependence: dividing \(v_tq_t\ge(1-c)v_tq_s\) by \(v_t>0\) gives exactly the supplied incentive constraints. No finite-agent implementation theorem is needed for this classification.

Thus maximizing \(F(u)\) over this interval correctly recovers the original optimum.

2. Fixed-\(u\) optimization

The substitution \(q_t=\alpha u+cu\,y_t\) is valid for \(u>0\), because \(c>0\). The resulting supply and objective formulas are algebraically correct.

On the feasible domain, \(\rho-\alpha u\ge0\), so \(h(u)\ge0\). Removing increments assigned to types with \(x_t\le0\) preserves feasibility and weakly increases payoff. This step does not remove their required baseline allocations.

The fractional-knapsack argument is complete:

  • For \(h\ge A_p\), assigning every positive type its full increment is feasible and optimal.
  • For \(A_{j-1}\le h\le A_j\), the displayed upper bound correctly uses \(x_j>0\), the capacity constraint, and the signs of \(x_i-x_j\).

Equal principal values cause no problem: the relevant coefficients may vanish, and the same inequality and attaining allocation remain valid. At shared interval endpoints, the formulas agree.

The denominators \(\alpha+cA_j\) are positive. Since every mass is positive, the prefix masses strictly increase, and the \(u_j\) strictly decrease. Substituting \(u_j\) into \(h\) correctly gives \(h(u_j)=A_j\).

Both displayed formulas for \(F\) follow correctly from the fixed-\(u\) formula, on their intersections with the feasible domain \([0,U]\). The saturated formula also verifies continuity at zero, where the only feasible allocation is zero.

The endpoint argument is valid. These subdivision points partition \([0,U]\) into finitely many intervals on which \(F\) is affine. Their endpoints are exactly covered by the candidate set after excluding points outside the feasible domain.

The breakpoint evaluation \(F(u_j)=u_j(\alpha X+cB_j)\) is correct whenever \(u_j\) is feasible. The procedure for evaluating \(F(U)\) covers both saturation and partial allocation. Because \(U>0\), its use of \(h(U)\) involves no division by zero.

Including zero handles negative-payoff alternatives and arbitrary thresholds \(K\). Comparing the exact maximum against \(K\) therefore answers the stated decision question.

The allocation-recovery formulas are also correct for feasible breakpoint candidates. Their allocated mass is \(\rho\), as claimed.

The arithmetic count is correct: sorting uses \(O(\tau\log(\tau+1))\) comparisons, and the remaining computations require \(O(\tau)\) rational operations, including locating the interval containing \(h(U)\).

The intermediate-size argument is sufficient:

  • Prefix denominators can be bounded using products of the relevant input denominators, including both mass and value denominators for weighted sums.
  • Positivity and normalization of the masses justify the stated magnitude bounds for \(X\) and \(B_j\), even when some principal values are negative.
  • Subsequent expressions use a constant number of operations on numbers with \(O(L)\) bits, so their numerators and denominators retain \(O(L)\) bits.

The conservative \(O(L^3)\) bound per exact rational operation, including reduction by the Euclidean algorithm, is valid. Hence the claimed total bound follows.

Issue and minimum clarification

The \(u_j\) are valid subdivision points, but some may not be actual changes of slope.

For example, take two types with masses \(1/2\), principal values both equal to \(1\), and \(c=\rho=1/2\). The prover’s formulas give \(U=1\), \(u_1=2/3\), and \(u_2=1/2\). They give \(F(u)=u\) up to \(1/2\) and \(F(u)=1/2\) thereafter. Thus \(u_1\) is not a slope-change breakpoint.
