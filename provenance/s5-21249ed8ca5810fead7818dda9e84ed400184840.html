The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), a common axis, a finite support \(T\) of single-peaked ranking types \(\rho_t\) with positive rational masses \(\mu_t\) summing to \(1\), a nonincreasing score vector \(w\), and a nonincreasing OWA vector \(\alpha\), find a size-\(k\) committee \(W\) maximizing \(\sum_{t\in T}\mu_t\,\operatorname{OWA}_{\alpha}\bigl((w_{\operatorname{rank}_{\rho_t}(c)})_{c\in W}\bigr)\).

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m=|C|\geq 1\), an integer \(1\leq k\leq m\), and a common linear axis, a society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types, and \(\sum_t\mu_t=1\).
Each type \(\rho_t\) is a weak order; \(\operatorname{rank}_{\rho_t}(c)\) is the index of the indifference class containing \(c\), starting at \(1\) for the best class. Single-peakedness means that every set \(\{c:\operatorname{rank}_{\rho_t}(c)\leq r\}\) is an interval of the supplied axis.
The input includes binary rational vectors \(w\in\mathbb{Q}_{\geq0}^{m}\) and \(\alpha\in\mathbb{Q}_{\geq0}^{k}\), with \(w_1\geq\cdots\geq w_m\) and \(\alpha_1\geq\cdots\geq\alpha_k\); neither vector must sum to one. For \(W\subseteq C\) with \(|W|=k\), let \(s_{t,1}(W)\geq\cdots\geq s_{t,k}(W)\) be its members' scores \(w_{\operatorname{rank}_{\rho_t}(c)}\), sorted in decreasing order, and define \(F(W)=\sum_t\mu_t\sum_{j=1}^{k}\alpha_j s_{t,j}(W)\). Equal scores may be ordered arbitrarily, and any maximizing committee is acceptable. Let \(L\) be the total binary input length.

Is finding a size-\(k\) committee maximizing \(F(W)\) solvable in polynomial time in \(m,\tau,k,L\), or is it \(\mathrm{NP}\)-hard?

For explicitly listed voters, OWA winner determination with nonincreasing weights is polynomial-time solvable on single-peaked profiles ([Peters, 2018](https://www.dominik-peters.de/publications/tum.pdf)); this also holds on profiles single-peaked on a circle ([Peters and Lackner, 2020](https://martin.lackner.xyz/publications/jair-spoc.pdf)). No result explicitly treating the normalized binary-rational support representation above was located.

Modeling choices made when packaging the task

  • Interpreted ranking types as weak orders, as in the discrete model, with ranks indexing indifference classes rather than occupied positions.
  • Used best-rank prefixes to define single-peakedness, correcting the reversed rank inequality in the supplied text.
  • Specified nonnegative binary-rational scores and OWA weights, including zero entries; rational scores extend the original integer score domain to a finite encoding consistent with the later real-valued definition.
  • Specified that both weight vectors are input, have lengths m and k, and require no normalization.
  • Restricted committee size to 1 through m and permitted any maximizing committee, with arbitrary ordering of equal scores.
  • Defined L as total binary input length, including masses and weight vectors.

Result

Finding an optimal committee is polynomial-time solvable in \(m,\tau,k,L\).

The binary-rational masses can be placed directly in the objective of a polynomial-size linear program. Its constraint matrix is totally unimodular, independently of the masses. Thus there is no need to expand a type into individual voters.

This extends the interval-based formulation in [Peters (2018), Section 5](https://www.dominik-peters.de/publications/tum.pdf). Below is a complete proof, including the binary encoding and extraction of an optimal committee.

1. Decomposing the objective into interval counts

Index the candidates as \(c_1,\ldots,c_m\) along the supplied axis. For each type \(t\) and \(r\in\{1,\ldots,m\}\), define

\(\displaystyle I_{t,r}=\{c\in C:\operatorname{rank}_{\rho_t}(c)\leq r\}.\)

By the single-peakedness hypothesis, each \(I_{t,r}\) is an interval. If \(r\) exceeds the number of indifference classes, then \(I_{t,r}=C\).

Set \(w_{m+1}=0\) and define

\(\displaystyle \Delta_r=w_r-w_{r+1}\quad(r=1,\ldots,m).\)

Every \(\Delta_r\) is nonnegative. Telescoping gives

\(\displaystyle w_h=\sum_{r=h}^{m}\Delta_r\quad(h=1,\ldots,m).\)

Also define \(A(0)=0\) and

\(\displaystyle A(n)=\sum_{j=1}^{n}\alpha_j\quad(n=1,\ldots,k).\)

For a committee \(W\), put \(n_{t,r}(W)=|W\cap I_{t,r}|\). We claim that

\[\displaystyle F(W)=\sum_{t=1}^{\tau}\sum_{r=1}^{m}\mu_t\Delta_r A(n_{t,r}(W)).\tag{1}\]

To prove this, fix \(t\) and order the members of \(W\) by nondecreasing rank. Write their ranks as \(h_1\leq\cdots\leq h_k\). Since \(w\) is nonincreasing, their scores in this order are nonincreasing, so this order is valid for computing the OWA value. Consequently,

\(\displaystyle \sum_{j=1}^{k}\alpha_j s_{t,j}(W) =\sum_{j=1}^{k}\alpha_j w_{h_j} =\sum_{r=1}^{m}\Delta_r\sum_{\{j:h_j\leq r\}}\alpha_j =\sum_{r=1}^{m}\Delta_r A(n_{t,r}(W)). \)

The last equality holds because exactly the first \(n_{t,r}(W)\) ranks are at most \(r\). Multiplying by \(\mu_t\) and summing proves (1). This argument handles both rank ties and equal entries of \(w\).

2. A polynomial-size linear program

Introduce variables \(y_c\) for candidates and \(x_{t,r,j}\) for \(t\in\{1,\ldots,\tau\}\), \(r\in\{1,\ldots,m\}\), and \(j\in\{1,\ldots,k\}\).

Consider the following linear program:

\[\displaystyle \text{maximize }\quad \sum_{t=1}^{\tau}\sum_{r=1}^{m}\sum_{j=1}^{k} \mu_t\Delta_r\alpha_j x_{t,r,j}, \tag{2} \]

subject to

\[\displaystyle \sum_{c\in C}y_c=k,\tag{3}\]

\[\displaystyle \sum_{j=1}^{k}x_{t,r,j} \leq \sum_{c\in I_{t,r}}y_c \quad\text{for every }t,r, \tag{4} \]

and

\[\displaystyle 0\leq y_c\leq1,\qquad 0\leq x_{t,r,j}\leq1. \tag{5} \]

The variables are continuous.

Claim. For a fixed binary vector \(y\) representing a committee \(W\), the maximum of (2) over the remaining variables is exactly \(F(W)\).

Indeed, fix a block \((t,r)\) and write \(n=n_{t,r}(W)\). Its constraints are precisely

\(\displaystyle 0\leq x_j\leq1,\qquad \sum_{j=1}^{k}x_j\leq n.\)

If \(n=0\), all its variables are zero. If \(n\geq1\), monotonicity and nonnegativity of \(\alpha\) give

\(\displaystyle \begin{aligned} \sum_{j=1}^{k}\alpha_jx_j &\leq \sum_{j=1}^{n}\alpha_jx_j +\alpha_n\sum_{j=n+1}^{k}x_j\\ &\leq \sum_{j=1}^{n}(\alpha_j-\alpha_n)x_j+\alpha_n n\\ &\leq \sum_{j=1}^{n}(\alpha_j-\alpha_n)+\alpha_n n\\ &=A(n). \end{aligned} \)

Equality is attained by setting \(x_j=1\) for \(j\leq n\) and \(x_j=0\) otherwise.

The blocks have no further constraints coupling their \(x\)-variables. Their coefficients \(\mu_t\Delta_r\) are nonnegative, so their maximum contributions sum to the expression in (1). This proves the claim, including cases with zero objective coefficients.

3. Total unimodularity

A matrix is *totally unimodular* if every square submatrix has determinant in \(\{-1,0,1\}\).

We first prove the interval-matrix fact needed here.

Lemma. A binary matrix whose ones are consecutive in each row is totally unimodular.

Proof. Let \(B\) be any square submatrix. Its rows still have consecutive ones in the inherited column order.

Replace its columns by

\(\displaystyle D_1=B_1,\qquad D_j=B_j-B_{j-1}\quad(j\geq2).\)

This is multiplication by a triangular matrix with diagonal entries all equal to \(1\), so \(\det D=\det B\). Each row of \(D\) has at most two nonzero entries; when it has two, they are \(1\) and \(-1\).

Every square matrix with this latter property has determinant in \(\{-1,0,1\}\), by induction on its dimension. A zero row gives determinant zero. A row with exactly one nonzero entry permits cofactor expansion, reducing to a smaller matrix with the same property. If every row has two nonzero entries, every row sums to zero, so the matrix is singular.

Therefore \(\det B\in\{-1,0,1\}\), proving the lemma.

Now write (3) as two inequalities and write (4) as

\(\displaystyle \sum_{j=1}^{k}x_{t,r,j}-\sum_{c\in I_{t,r}}y_c\leq0. \)

Initially omit the bounds (5).

In the columns belonging to the \(y\)-variables, each constraint row is either an interval incidence vector or its negative. The two cardinality rows correspond to the full interval \(C\). Multiplying rows by \(-1\) does not change the absolute values of subdeterminants. Hence this submatrix is totally unimodular by the lemma.

Each \(x_{t,r,j}\)-column has exactly one nonzero entry, equal to \(1\). Appending such columns preserves total unimodularity: a square minor containing one can be expanded along that column, or has determinant zero if the column vanishes within the minor.

Finally, the bounds (5) append rows having a single nonzero entry, equal to \(1\) or \(-1\). The analogous cofactor-expansion argument shows that these rows also preserve total unimodularity.

Thus the full constraint matrix of (3)–(5) is totally unimodular.

4. Integrality and correctness

All right-hand sides in (3)–(5) are integers. It follows that every vertex of the feasible polytope is integral. For completeness, here is the direct argument.

Let \(N\) be the number of variables. At a vertex, there are \(N\) linearly independent tight constraint rows. Their coefficient matrix \(B\) is a nonsingular square submatrix of the full constraint matrix. Total unimodularity implies \(\det B\in\{-1,1\}\). Its right-hand side \(b\) is integral, and the adjugate formula shows that \(B^{-1}\) has integer entries. Hence the vertex \(B^{-1}b\) is integral.

The polytope is nonempty: select any \(k\) candidates and set all \(x\)-variables to zero. It is bounded by (5), so the linear objective attains its maximum at a vertex. Every coordinate of an integral vertex lies in \(\{0,1\}\).

Let \(V^\star\) be the optimal LP value.

For every committee \(W\), Section 2 constructs a feasible solution of value \(F(W)\), so

\(\displaystyle V^\star\geq\max_{\{|W|=k\}}F(W).\)

Conversely, choose an optimal integral vertex and let \(W^\star=\{c:y_c=1\}\). Constraint (3) gives \(|W^\star|=k\). Section 2 gives

\(\displaystyle V^\star\leq F(W^\star)\leq\max_{\{|W|=k\}}F(W).\)

Therefore equality holds throughout, and \(W^\star\) is an optimal committee.

5. Binary encoding and committee extraction

The LP has

\(\displaystyle N=m+\tau mk\)

variables and \(2+\tau m+2N\) inequalities. Its constraint coefficients belong to \(\{-1,0,1\}\), and its right-hand sides belong to \(\{-k,0,1,k\}\).

Every objective coefficient is the rational number

\(\displaystyle \mu_t\alpha_j(w_r-w_{r+1}).\)

A subtraction and two multiplications of input rationals produce a rational with bit length bounded by a constant multiple of \(L\). Thus the complete LP has encoding length polynomial in \(m,\tau,k,L\). It can be constructed and optimized exactly in polynomial time by the standard polynomial-time algorithms for rational linear programming.

One must extract a binary committee even if an LP algorithm returns a fractional point on the optimal face. This can also be done in polynomial time:

  • Compute \(V^\star\) and restrict to the face where objective (2) equals \(V^\star\).
  • Successively maximize \(y_{c_1},\ldots,y_{c_m}\), fixing each coordinate to its attained maximum before continuing.

At each step, the remaining feasible set is a nonempty face of the original polytope. Every vertex of such a face is an original vertex and is therefore binary. Consequently, each coordinate maximum belongs to \(\{0,1\}\). After these \(m\) additional LP optimizations, all candidate coordinates are fixed to binary values, and they specify an optimal committee.

These LPs retain polynomial encoding length: \(V^\star\) has polynomial bit length because it is the sum of a subset of the \(N\) rational objective coefficients at an optimal binary vertex.

The algorithm therefore runs in polynomial time in \(m,\tau,k,L\). Neither normalization of the masses nor normalization of either weight vector is needed for the proof; their nonnegativity and the stated monotonicity assumptions suffice.
