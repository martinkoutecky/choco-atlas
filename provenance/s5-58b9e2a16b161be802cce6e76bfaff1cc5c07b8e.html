The continuous mirror question, as graded

Given item classes \(J\), rational per-capita supplies \(b\in\mathbb{Q}_{\ge 0}^{J}\), and a common additive valuation vector \(u\in\mathbb{Q}^{J}\) that is all nonnegative (goods) or all nonpositive (chores), a unit-mass population receives integral bundles \(z\in\mathbb{Z}_{\ge 0}^{J}\). Choose a finite-support distribution \(p_z\ge 0\) with \(\sum_z p_z=1\) and \(\sum_z p_z z=b\); compute the maximum \(q^*\) such that every bundle with \(p_z>0\) has utility \(u\cdot z\ge q^*\), and return a distribution attaining it.

Packaged proof task (what the prover saw — nothing else)

Let \(J\) be a finite set of item classes, \(m=|J|\), with per-capita supplies \(b\in\mathbb{Q}_{\ge0}^{J}\) and common additive valuations \(u\in\mathbb{Q}^{J}\), either all nonnegative (goods) or all nonpositive (chores).
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here the society has one valuation type of mass \(1\), so \(\tau=1\).
An allocation is a finite-support distribution on integral bundles \(z\in\mathbb{Z}_{\ge0}^{J}\), with \(p_z\ge0\), \(\sum_zp_z=1\), and \(\sum_zp_zz=b\). Empty bundles and zero utilities are allowed; bundles have no additional size bound.
Define \(q^*=\max_p\min_{z:p_z>0}u\cdot z\). The computational problem is to compute \(q^*\) exactly and return an attaining distribution, listing its bundles and binary rational masses. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

For each of the goods and chores domains, is this exact optimization problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For finitely many agents with identical valuations, finding an allocation maximizing the minimum utility is strongly \(\mathrm{NP}\)-hard for both goods and chores, and weakly \(\mathrm{NP}\)-hard even for two agents ([source](https://arxiv.org/html/1604.01435)).
No result settling exactly the distributional problem above was identified in the literature search.

Modeling choices made when packaging the task

  • The common valuation is represented as one supported society type of mass 1, hence tau=1; allocation support is a separate object.
  • The output distribution is represented explicitly by integral bundle vectors and binary rational masses.
  • Empty bundles and zero utilities remain allowed, consistent with the discrete allocation definitions.
  • Per-capita supplies constrain expected bundle counts only; no finite-population inventory bound is imposed on individual bundles.
  • L denotes total input bit length, including supplies, valuations, and society masses.

Result

Both goods and chores are \(\mathrm{NP}\)-hard, already with \(\tau=1\), every supply equal to \(\frac12\), and strictly positive integer valuations for goods or strictly negative integer valuations for chores.

Consequently, neither exact optimization problem admits running time \(\operatorname{poly}(m,\tau,L)\) unless \(\mathrm{P}=\mathrm{NP}\). The proof below handles unrestricted bundle sizes and arbitrary rational probabilities.

1. The average bound and existence of an optimum

For a feasible finite-support distribution \(p\), write \(q(p)=\min_{z:p_z>0}u\cdot z\). Its expected utility is

\(\displaystyle \sum_zp_z(u\cdot z)=u\cdot\sum_zp_zz=u\cdot b.\)

Therefore \(q(p)\le u\cdot b\). Moreover,

\(\displaystyle q(p)=u\cdot b\quad\Longleftrightarrow\quad u\cdot z=u\cdot b\text{ for every }z\text{ with }p_z>0.\)

Indeed, when the minimum equals the average, all differences \(u\cdot z-q(p)\) are nonnegative and have weighted sum zero. Every supported bundle has positive probability, so every difference is zero.

The maximum defining \(q^*\) exists. To see this, first construct a feasible rational distribution by rounding each coordinate \(b_j\) independently to its floor or ceiling with probabilities giving expectation \(b_j\). This has finite support; denote its minimum utility by \(q_0\).

Choose a positive integer \(D\) clearing the denominators of \(u\). Every integral bundle, and hence every finite-support minimum, has utility in \(D^{-1}\mathbb Z\). There are only finitely many such values between \(q_0\) and \(u\cdot b\). The achievable values in this interval form a nonempty finite set, whose largest element is an attained global optimum.

An attaining distribution can also be chosen rational. Starting with its finite support, consider the columns \((1,z)\). If these are linearly dependent, perturb the positive masses along a dependence until one becomes zero, preserving both total mass and coordinate means. Repeat until the remaining columns are linearly independent. There are then at most \(m+1\) columns, and their masses solve a rational linear system uniquely, so they are rational. Removing bundles cannot decrease the minimum utility.

2. Reduction from \(\mathrm{PARTITION}\)

We use the standard \(\mathrm{NP}\)-complete problem \(\mathrm{PARTITION}\): given positive integers \(a_1,\ldots,a_n\) with total \(2A\), determine whether some subset sums to \(A\). The standard hardness result is proved, for example, in these [University of Basel notes](https://ai.dmi.unibas.ch/_files/teaching/fs22/theo/slides/theory-d05-handout.pdf).

Restricting to even totals preserves hardness: multiplying every integer of an arbitrary instance by two makes the total even and preserves whether a partition exists. Zero entries, if present, can be deleted.

Create two item classes \((i,+)\) and \((i,-)\) for each \(i\in\{1,\ldots,n\}\). Thus \(m=2n\). Set

\(\displaystyle b_{i,+}=b_{i,-}=\frac12.\)

Define positive integer weights

\(\displaystyle w_{i,+}=2^n a_i+2^{i-1},\qquad w_{i,-}=2^{i-1}.\)

Their per-capita average is

\(\displaystyle T:=w\cdot b=\frac12\sum_{i=1}^n\left(2^na_i+2^i\right)=2^nA+2^n-1.\)

Use \(u=w\) for the goods instance and \(u=-w\) for the chores instance. Each society has one supported valuation type of mass \(1\).

The key statement is:

There exists a feasible distribution supported entirely on bundles of weight \(T\) if and only if the partition instance is a yes-instance.

3. Equal-weight distributions force binary choices

Suppose a feasible distribution is supported entirely on bundles satisfying \(w\cdot z=T\).

For a supported bundle, write

\(\displaystyle x_i=z_{i,+},\qquad y_i=z_{i,-},\qquad c_i=x_i+y_i.\)

The weight equation is

\(\displaystyle 2^n\sum_{i=1}^na_ix_i+\sum_{i=1}^n2^{i-1}c_i=2^nA+2^n-1.\)

The prescribed means give, for every \(i\),

\(\displaystyle \mathbb E[c_i]=\mathbb E[x_i]+\mathbb E[y_i]=\frac12+\frac12=1.\)

We prove inductively that \(c_i=1\) in every supported bundle.

For \(i=1\), reducing the weight equation modulo \(2\) gives \(c_1\equiv1\pmod2\). Since \(c_1\) is a nonnegative integer, \(c_1\ge1\). Its expectation is exactly \(1\), so every supported bundle has \(c_1=1\).

Now suppose \(c_h=1\) in every supported bundle for all \(h<i\). Their contribution to the weight equation is

\(\displaystyle \sum_{h<i}2^{h-1}=2^{i-1}-1.\)

Subtract this contribution and reduce modulo \(2^i\). The high term and all terms indexed above \(i\) vanish modulo \(2^i\), leaving

\(\displaystyle 2^{i-1}c_i\equiv2^{i-1}\pmod{2^i}.\)

Thus \(c_i\) is odd. Again \(c_i\ge1\), and \(\mathbb E[c_i]=1\) forces \(c_i=1\) in every supported bundle. This completes the induction.

Consequently, each supported bundle satisfies

\(\displaystyle x_i+y_i=1,\qquad x_i,y_i\in\{0,1\}.\)

Substituting these equalities into the weight equation and cancelling \(\sum_i2^{i-1}=2^n-1\) yields

\(\displaystyle \sum_{i=1}^na_ix_i=A.\)

Therefore any supported bundle identifies a partition subset \(S=\{i:x_i=1\}\).

This argument imposes no a priori bound on bundle coordinates. The modular equations and prescribed expectations themselves exclude repeated copies.

4. A partition gives an attaining distribution

Conversely, suppose \(S\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in S}a_i=A\).

Define a bundle \(z^S\) by selecting class \((i,+)\) when \(i\in S\) and class \((i,-)\) otherwise, exactly once for each \(i\). Define \(z^{\overline S}\) by reversing every choice.

Give these two bundles probability \(\frac12\) each. Every item class then has mean supply \(\frac12\). Since both \(S\) and its complement sum to \(A\),

\(\displaystyle w\cdot z^S=w\cdot z^{\overline S}=2^nA+\sum_{i=1}^n2^{i-1}=T.\)

This proves the key equivalence, using a distribution with two bundles and binary rational masses.

5. Applying the equivalence to both domains

For goods, \(u=w\), so the average bound gives \(q^*_{\mathrm{goods}}\le T\). Sections 3–4 and the equality condition from Section 1 imply

\(\displaystyle q^*_{\mathrm{goods}}=T\quad\Longleftrightarrow\quad\text{the partition instance is a yes-instance}.\)

For chores, \(u=-w\), so the average bound gives \(q^*_{\mathrm{chores}}\le-T\). Equality is possible precisely when every supported bundle has utility \(-T\), equivalently weight \(T\). Hence

\(\displaystyle q^*_{\mathrm{chores}}=-T\quad\Longleftrightarrow\quad\text{the partition instance is a yes-instance}.\)

Thus computing the exact optimum alone decides \(\mathrm{PARTITION}\) in either domain. Requiring an attaining distribution cannot make the problem easier.

6. Encoding and running-time consequence

Let \(N\) be the source instance’s total binary encoding length. Each constructed weight has \(O(n+\log(a_i+1))\) bits. The resulting allocation instance therefore has

\(\displaystyle m=2n,\qquad\tau=1,\qquad L=O(n^2+N)=O(N^2).\)

The instance and comparison threshold can be constructed in \(O(N^2)\) bit operations using elementary binary arithmetic.

A \(\operatorname{poly}(m,\tau,L)\)-time exact optimizer in either domain would consequently yield a polynomial-time algorithm for \(\mathrm{PARTITION}\). This establishes the requested \(\mathrm{NP}\)-hardness classification. The reduction uses large binary-encoded valuations and does not establish strong \(\mathrm{NP}\)-hardness.
