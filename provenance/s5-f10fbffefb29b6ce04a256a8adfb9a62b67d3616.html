The continuous mirror question, as graded

Given a finite support of \(\tau\) complete valuation types \(\nu_t\) on \([0,1]\), with positive rational masses \(\mu_t\) summing to one and binary encoding length \(L\), determine the worst-case Robertson–Webb query complexity of producing a finite partition and nonnegative, piecewise-constant per-capita bundle densities \(x_t\) satisfying \(\sum_t \mu_t x_t(z)=1\) almost everywhere and \(\int x_t\,d\nu_t \ge \int x_u\,d\nu_t\) for every pair of types \(t,u\). In particular, is there a deterministic protocol using \(\mathrm{poly}(\tau,L)\) queries, independent of the masses’ denominators and the population size?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\ge1\) valuation types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types, and \(L\) is the total mass-encoding bit length.
Each type has a finite, nonnegative, additive, nonatomic valuation \(\nu_t\) on \([0,1]\), accessed only through Robertson–Webb queries; valuations need not be normalized and may be zero.
An evaluation query returns \(\nu_t([a,b])\); a cut query, given \(a\) and \(0\le v\le\nu_t([a,1])\), returns any \(b\ge a\) with \(\nu_t([a,b])=v\). Exact arithmetic and finite computation between queries are free.
The output is a common finite interval partition and finite nonnegative constants defining per-capita densities \(x_t\) on its cells, with \(\sum_t\mu_t x_t(z)=1\) on every cell and \(\int_{[0,1]}x_t\,d\nu_t\ge\int_{[0,1]}x_u\,d\nu_t\) for all \(t,u\). Cut endpoints are ignored.

What is the worst-case deterministic Robertson–Webb query complexity of this problem: does a protocol using \(\operatorname{poly}(\tau,L)\) queries exist, or is a superpolynomial number necessary?
The bound may depend on denominator bit lengths through \(L\), but not on denominator magnitudes or a population obtained by replicating types.

For finite societies of \(n\) agents receiving disjoint finite unions of intervals, a deterministic complete envy-free protocol uses \(n^{O(1)}2^n\) queries ([Ye–Bai](https://arxiv.org/abs/2609.05191)); an \(\Omega(n^2)\) lower bound is known ([Procaccia](https://www.ijcai.org/Abstract/09/049)).
The search identified no query-complexity result for exactly the mass-and-density formulation above.

Modeling choices made when packaging the task

  • Interpreted complete valuation types as finite, nonnegative, additive, nonatomic valuations, allowing zero valuations and imposing no normalization, as in the discrete definition.
  • Assigned L to the binary encoding of masses only; arbitrary valuations are supplied by oracles rather than finite binary descriptions.
  • Specified a common partition into intervals and finite real density constants; conservation holds on every cell, with endpoints ignored because every valuation is nonatomic.
  • Retained the Robertson–Webb convention that exact arithmetic and finite computation on oracle answers are free, and correctness must hold for any valid cut answer.
  • Interpreted independence from denominators as independence from their numerical magnitudes beyond their encoding length L.
  • Used tau and L as the input parameters; this cake model has no finite-alternative parameter m.

Exact query complexity

The optimal worst-case deterministic Robertson–Webb query complexity is \(0\). The formulation permits the constant densities \(x_t\equiv 1\). This works for arbitrary support size and arbitrary valuations, including nonzero, pairwise distinct valuations; it is not confined to a degenerate instance.

Complete proof

Fix any admissible input. Make no valuation queries. Output the one-cell partition consisting of \([0,1]\), and assign the constant density

\(x_t(z)=1\qquad\text{for every }t\in\{1,\ldots,\tau\}\text{ and every }z\in[0,1].\)

We verify every output requirement.

  • Representation and nonnegativity. The partition is finite, and each density is specified by the finite, nonnegative constant \(1\).
  • Feasibility. For every point of the cell, the assumed mass identity gives

\(\sum_{t=1}^{\tau}\mu_t x_t(z)=\sum_{t=1}^{\tau}\mu_t=1.\)

  • Envy-freeness. For any two types \(t,u\), both densities are identically \(1\), so

\(\int_{[0,1]}x_t\,d\nu_t=\nu_t([0,1])=\int_{[0,1]}x_u\,d\nu_t.\)
These integrals are finite because \(\nu_t\) is finite. Thus every required envy inequality holds with equality. The same calculation covers zero valuations and valuations that are not normalized.

The protocol therefore succeeds on every admissible input using \(0\) queries. Since query counts are nonnegative, this upper bound is optimal. It has no dependence on \(\tau\), \(L\), denominator magnitudes, or replicated population size.

A structural result beyond the constant witness

The constant construction is also forced for any universally correct deterministic protocol making no queries.

Proposition. Fix the masses and support size. Any deterministic zero-query protocol satisfying the stated requirements on every valuation profile must output \(x_t=1\) on every cell of positive length.

Proof. With no queries, the output depends only on the supplied masses and support size. Fix one of its cells \(I\) of positive length, and write \(a_t\) for the constant assigned to type \(t\) there.

Choose an interval \(J\) of positive length strictly inside \(I\). Let \(\lambda\) denote Lebesgue measure, and define the admissible valuation profile by

\(\nu_t(A)=c_t\lambda(A\cap J),\)

where the constants \(c_t>0\) are pairwise distinct. These valuations are finite, nonnegative, additive, nonatomic, nonzero, and pairwise distinct.

Because the protocol makes no queries, it returns the same output for this profile. Envy-freeness requires, for every \(t,u\),

\(c_t\lambda(J)a_t\ge c_t\lambda(J)a_u.\)

Dividing by the positive factor \(c_t\lambda(J)\) gives \(a_t\ge a_u\). Applying this to all ordered pairs shows that all \(a_t\) equal some constant \(a\). Feasibility on \(I\) then implies

\(1=\sum_t\mu_t a_t=a\sum_t\mu_t=a.\)

Thus \(a_t=1\) for every type. The argument applies to every positive-length cell. Endpoint values are irrelevant by the task’s convention. This proves the proposition.

Why the disjoint-allocation bounds do not transfer

The [Ye–Bai upper bound](https://arxiv.org/abs/2609.05191) and [Procaccia lower bound](https://www.ijcai.org/Abstract/09/049) concern standard envy-free cake cutting. The task supplies them for disjoint allocations.

Here, the aggregate density assigned to type \(t\) is \(y_t=\mu_t x_t\). Our construction gives \(y_t\equiv\mu_t\): every type receives its mass fraction at every location. When \(\tau>1\), these aggregate densities are fractional, whereas a disjoint allocation assigns each location entirely to one recipient.

Consequently, the stated density model admits an output unavailable in the disjoint model. A requirement such as disjoint aggregate holdings or an additional efficiency objective would define a different problem. Neither is among the given constraints, and the result above does not settle those variants.
