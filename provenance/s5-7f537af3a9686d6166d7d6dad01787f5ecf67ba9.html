The continuous mirror question, as graded

Given a finite preference DAG \(G=(V,A)\), rational per-capita supplies \(q_v\in[0,1]\) for each interchangeable item class \(v\in V\), and a rational threshold \(D\), decide whether there are real masses \(x_B\ge 0\) over integral bundles \(B\subseteq V\) such that \(\sum_B x_B=1\), \(\sum_{B\ni v}x_B\le q_v\) for every \(v\), and \(\sum_B x_B\delta_G(B)\le D\), where \(\delta_G(B)=|\{v\in V:B\cap\operatorname{pred}[v]=\varnothing\}|\).

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,A)\) be a finite preference DAG with \(m=|V|\ge 1\). An arc points from a more preferred item class to a less preferred one; preferences include transitive reachability, and unreachable pairs are incomparable. Define \(\operatorname{pred}[v]=\{v\}\cup\{u\in V:\text{there is a directed path from }u\text{ to }v\}\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here there is one common preference type, represented by \(G\), with mass \(1\), so \(\tau=1\); support size counts present types, not possible types.
The remaining inputs are binary rational supplies \(q_v\in[0,1]\) and a binary rational threshold \(D\in\mathbb Q\). Supplies need not sum to any prescribed value. Let \(L\) be the total input bit length; running times are measured in \(m,\tau,L\).
Each agent receives an integral bundle \(B\subseteq V\), containing at most one item from each class; the empty bundle is allowed, and supplies may remain unused. Its dissatisfaction is \(\delta_G(B)=|\{v\in V:B\cap\operatorname{pred}[v]=\varnothing\}|\), counting classes without weighting them by supply.
Decide whether real masses \(x_B\ge 0\), indexed by all \(B\subseteq V\), satisfy \(\sum_{B\subseteq V}x_B=1\), \(\sum_{B\ni v}x_B\le q_v\) for every \(v\in V\), and \(\sum_{B\subseteq V}x_B\delta_G(B)\le D\). The bundle masses are decision variables, not an explicitly listed input.

Is this continuous decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

The discrete counterpart assigns pairwise disjoint bundles of individual items to agents and bounds their summed dissatisfaction. It is NP-complete for every fixed \(k\ge 3\), even when every arc goes from one side of a bipartition to the other and maximum in-degree is \(2\); for \(k=2\), it has a linear-time algorithm. [Verified source](https://onlinelibrary.wiley.com/doi/full/10.1002/net.70040).
No result settling this exact continuous decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Defined pred[v] using all directed predecessors and v itself, rather than only immediate in-neighbors.
  • Represented the homogeneous society by one supported preference type of mass one; bundle masses describe allocations rather than input types.
  • Made explicit that empty bundles and unused supplies are allowed, as in the discrete allocation definition; the discrete nonempty-antichain restriction is a without-loss-of-generality result, not a feasibility condition.
  • Treated dissatisfaction as an unweighted count of item classes and supplies as arbitrary per-capita upper bounds, without introducing a finite-agent parameter or a common reciprocal supply.
  • Specified a nonempty item-class set, total input bit length, and implicit indexing of bundle variables.

Result

The continuous decision problem is \(\mathrm{NP}\)-complete, even with one preference type, supplies in \(\{0,\tfrac12\}\), and a preference DAG whose arcs all go from sources to sinks and whose maximum in-degree is \(3\).

Thus a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\). The proof below is a direct reduction for the continuous problem.

1. A satisfiability problem with complement symmetry

A not-all-equal clause \(\operatorname{NAE}(a,b,c)\) is satisfied when its three literal truth values contain both \(0\) and \(1\). A formula consisting of such clauses is invariant under complementing every variable: this complements every literal value and preserves every clause.

We first establish the hardness needed for the reduction, starting from the standard \(\mathrm{NP}\)-completeness of \(3\)-SAT. [Schaefer, *The Complexity of Satisfiability Problems*](https://doi.org/10.1145/800133.804350).

Given a \(3\)-SAT formula, introduce one common fresh variable \(z\). Replace each clause \(a\lor b\lor c\) by the four-literal constraint \(\operatorname{NAE}(a,b,c,z)\). If the original formula is satisfiable, setting \(z=0\) satisfies all these constraints. Conversely, any satisfying assignment to the constraints can be complemented, if necessary, so that \(z=0\). Each constraint then requires at least one of \(a,b,c\) to be true.

To obtain three-literal constraints, introduce a fresh variable \(w\) for each clause and use the equivalence

\(\operatorname{NAE}(a,b,c,z)\ \Longleftrightarrow\ \exists w\,[\operatorname{NAE}(a,b,w)\land\operatorname{NAE}(\neg w,c,z)]\).

Here is a verification for all cases:

  • If \(a=b=t\), the first constraint forces \(w=1-t\). The second then becomes \(\operatorname{NAE}(t,c,z)\), which holds exactly when \(c,z\) are not both \(t\). This is precisely the original four-literal constraint.
  • If \(a\ne b\), the first constraint holds for either value of \(w\), and the four-literal constraint already holds. If \(c\ne z\), the second constraint also holds for either value of \(w\). If \(c=z=t\), choose \(w=t\), so that \(\neg w=1-t\).

The construction has polynomial size. Therefore satisfiability of three-literal not-all-equal formulas is \(\mathrm{NP}\)-hard.

2. Construction of the continuous instance

Let \(\Phi\) be a not-all-equal formula with variables \(y_1,\ldots,y_n\) and clauses \(C_1,\ldots,C_r\), where \(n\ge 1\).

Create two source vertices \(t_i,f_i\) for each variable. For a literal \(\ell\), define its corresponding source by

\(s(y_i)=t_i,\qquad s(\neg y_i)=f_i\).

Give every source supply \(\tfrac12\). All other vertices constructed below are sinks with supply \(0\).

For each variable, create a sink \(p_i\) and arcs \(t_i\to p_i\) and \(f_i\to p_i\).

For each clause \(C_j=\operatorname{NAE}(\ell_{j1},\ell_{j2},\ell_{j3})\), create two sinks \(c_j^+,c_j^-\). Add arcs from each \(s(\ell_{jh})\) to \(c_j^+\), and from each \(s(\neg\ell_{jh})\) to \(c_j^-\), for \(h\in\{1,2,3\}\). Repeated arcs, if any, are included only once.

Set the dissatisfaction threshold to \(D=n\). There is one common preference type, with mass \(1\).

This graph has \(m=3n+2r\) vertices. Every arc goes from a source to a sink, so it is acyclic and has no directed path of length two. Every sink has in-degree at most \(3\). The graph, supplies, and threshold all have polynomial encoding length.

Because a sink has zero supply, feasibility forces every positive-mass bundle to omit that sink. Consequently, covering a sink requires selecting at least one of its source predecessors. Although these sinks have zero supply, they still count toward dissatisfaction under the definition in the question.

3. A lower bound and its equality conditions

Let any feasible bundle distribution be given, and regard its bundle as a random variable \(B\). For each source \(u\), write \(p_u=\Pr(u\in B)\).

A source has no strict predecessors, so its dissatisfaction indicator is exactly \(\mathbf{1}_{u\notin B}\). The expected contribution of all sources is therefore

\(2n-\sum_{i=1}^{n}(p_{t_i}+p_{f_i})\).

The supply constraints give \(p_{t_i},p_{f_i}\le\tfrac12\). Hence this contribution is at least \(n\). Every sink contributes a nonnegative amount, so

\(\mathbb{E}[\delta_G(B)]\ge n\).

Suppose now that the distribution meets the threshold \(D=n\). Equality must hold throughout the preceding bound. It follows that:

  • Every source marginal is exactly \(\tfrac12\).
  • Every sink has expected dissatisfaction \(0\).

Since the distribution is over finitely many bundles and dissatisfaction indicators are nonnegative, every sink is covered in every positive-mass bundle.

In particular, covering \(p_i\) requires each positive-mass bundle to contain at least one of \(t_i,f_i\). But

\(\mathbb{E}[|B\cap\{t_i,f_i\}|]=p_{t_i}+p_{f_i}=1\).

An integer-valued random variable that is at least \(1\) on every positive-mass outcome and has expectation \(1\) must equal \(1\) on every such outcome. Thus every positive-mass bundle contains exactly one of \(t_i,f_i\), for every variable \(i\).

4. Correctness of the reduction

A satisfying formula gives a feasible distribution

Suppose \(\alpha\) satisfies \(\Phi\). Form a bundle \(B_\alpha\) containing \(t_i\) when \(\alpha(y_i)=1\), and \(f_i\) when \(\alpha(y_i)=0\). Let \(B_{\bar\alpha}\) be the bundle for the complementary assignment.

Give these two bundles mass \(\tfrac12\) each.

Each source appears in exactly one bundle, so its marginal is \(\tfrac12\). No sink is allocated. Every variable sink is covered in both bundles.

Each clause has at least one true literal and at least one false literal under \(\alpha\). Therefore \(B_\alpha\) contains a predecessor of both \(c_j^+\) and \(c_j^-\). The complementary assignment also satisfies every not-all-equal clause, so the same holds for \(B_{\bar\alpha}\).

Each bundle consequently has dissatisfaction exactly \(n\): precisely its \(n\) omitted source vertices contribute. The distribution meets all constraints.

A feasible distribution gives a satisfying formula

Conversely, suppose the constructed instance has a feasible distribution with expected dissatisfaction at most \(n\). Choose any positive-mass bundle, which exists because the masses sum to \(1\).

By Section 3, this bundle contains exactly one of \(t_i,f_i\) for every variable. Define an assignment by setting \(y_i=1\) exactly when \(t_i\) is in the bundle.

Coverage of \(c_j^+\) means that at least one literal of \(C_j\) is true. Coverage of \(c_j^-\) means that at least one complementary literal is true, so at least one literal of \(C_j\) is false. Every clause is therefore not-all-equal satisfied.

This proves the equivalence

\(\Phi\text{ is satisfiable}\ \Longleftrightarrow\ \text{the constructed continuous instance is feasible}\).

Hence the continuous problem is \(\mathrm{NP}\)-hard.

5. Polynomial-size certificates for arbitrary instances

It remains to justify membership in \(\mathrm{NP}\), despite allowing real masses and exponentially many possible bundles.

For a general instance, introduce nonnegative slack variables \(s_v\) and \(s_D\). Feasibility is equivalent to the nonnegative linear system

\(\sum_Bx_B=1,\qquad \sum_{B\ni v}x_B+s_v=q_v,\qquad \sum_B\delta_G(B)x_B+s_D=D\).

Write this as \(My=b\), where \(y\) comprises the bundle masses and slack variables. There are \(m+2\) rows, and every entry of \(M\) is an integer between \(0\) and \(m\).

If the system is feasible, choose a feasible vector with minimum support cardinality. Its supported columns are linearly independent. Indeed, otherwise there is a nonzero vector \(h\), supported on those columns, with \(Mh=0\). Reverse its sign if necessary so that some coordinate is positive, and set

\(\varepsilon=\min_{j:h_j>0}y_j/h_j\).

Then \(y-\varepsilon h\) is nonnegative, satisfies the same equations, and has strictly smaller support, a contradiction. Thus at most \(m+2\) coordinates are positive.

Let their number be \(k\). Select \(k\) rows on which these \(k\) columns form a nonsingular integer matrix \(C\). Let \(Q\) be the product of the denominators of the entries of \(b\). Its bit length is \(O(L)\). Cramer’s rule expresses each supported coordinate as an integer determinant divided by \(Q\det C\).

The determinant bounds

\(|\det C|\le k!m^k\)

and the corresponding bound for a determinant with one column replaced by \(Qb\) show that every coordinate has bit length \(O(L+m\log(m+2))\). The solution on these rows equals the original supported solution by uniqueness, so it also satisfies all remaining rows.

Consequently, every yes-instance has a certificate listing at most \(m+2\) bundles with nonnegative rational masses of polynomial bit length. A verifier computes reachability, evaluates each listed bundle’s dissatisfaction, and checks all constraints by exact rational arithmetic in polynomial time.

The problem belongs to \(\mathrm{NP}\), and together with the reduction is \(\mathrm{NP}\)-complete.

The subsequent replacement by two three-literal constraints is also correct. The two cases \(a=b\) and \(a\ne b\) are exhaustive.
