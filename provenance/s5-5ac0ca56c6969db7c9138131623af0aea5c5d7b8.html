The continuous mirror question, as graded

Given a candidate set \(C\) with \(|C|=m\) and a finite support \(T\) of strict rankings with rational masses \(\mu_t>0\), where \(\sum_{t\in T}\mu_t=1\), find a candidate \(c\in C\) and masses \(x_{t,d}\ge0\) such that \(\sum_{d\in C}x_{t,d}=\mu_t\) for every \(t\), \(\sum_{t\in T}x_{t,d}=1/m\) for every \(d\), and \(x_{t,d}=0\) unless type \(t\) ranks \(c\) at least as high as \(d\).

Let \(C\) be a nonempty candidate set with \(|C|=m\). A society is given by its support: a list \(T\) of \(\tau\) distinct strict complete rankings of \(C\), each with positive mass \(\mu_t\) encoded as a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Write \(c\succeq_t d\) when \(c=d\) or type \(t\) ranks \(c\) above \(d\). The search problem asks for \(c\in C\) and nonnegative rational masses \(x_{t,d}\) satisfying \(\sum_{d\in C}x_{t,d}=\mu_t\) for every \(t\), \(\sum_{t\in T}x_{t,d}=1/m\) for every \(d\), and \(x_{t,d}=0\) whenever \(c\not\succeq_t d\).

Is this rational-mass search problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite equally weighted voters, a candidate admitting the required fractional matching always exists and can be found in polynomial time.

Result

The search problem is solvable in polynomial time in \(m,\tau,L\).

The weighted Ranking-Matching Lemma of Gkatzelis, Halpern, and Shah applies directly: take the voter set to be \(T\), with weights \(p(t)=\mu_t\), and candidate weights \(q(d)=1/m\). Both weight vectors are nonnegative and sum to one; their domination edges are exactly the permitted pairs \(c\succeq_t d\). [Lemma 2](https://daniel-halpern.com/files/optimal-metric-distortion.pdf).

Here is an explicit exact construction, using [FractionalVeto, Algorithm 2](https://www.ijcai.org/proceedings/2022/0050.pdf).

Algorithm and correctness

Initialize residual masses \(r_t=\mu_t\), residual capacities \(s_d=1/m\), and allocations \(x_{t,d}=0\).

While some \(r_t>0\):

  • Choose such a type \(t\).
  • Let \(A=\{d\in C:s_d>0\}\), and choose the candidate \(d\) ranked last by \(t\) within \(A\).
  • Set \(\delta=\min\{r_t,s_d\}\). Increase \(x_{t,d}\) by \(\delta\), and decrease both \(r_t\) and \(s_d\) by \(\delta\).

Return the last chosen candidate \(c\), together with \(x\).

Throughout, residuals remain nonnegative and \(\sum_t r_t=\sum_d s_d\). Thus \(A\) is nonempty whenever a step is needed. Each step permanently exhausts at least one residual; the final step exhausts both a type and a candidate. Consequently there are at most \(\tau+m-1\) steps.

At termination all residuals vanish, giving \(\sum_d x_{t,d}=\mu_t\) and \(\sum_t x_{t,d}=1/m\).

The returned candidate \(c\) had positive residual capacity at the start of every step: once exhausted, a candidate can never be chosen again. Whenever mass was allocated to \(d\) by type \(t\), both \(c\) and \(d\) were active, and \(d\) was ranked last among active candidates. Hence \(c\succeq_t d\). Every positive allocation therefore satisfies the required restriction.

Exact arithmetic and running time

Write each input mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\), and define the common denominator
\(Q=m\prod_{t\in T}b_t\).

Run the algorithm after multiplying all masses and capacities by \(Q\). Its initial values are the integers \(Q\mu_t=a_t(Q/b_t)\) and \(Q/m\). Every subsequent mass operation is an integer comparison, addition, or subtraction. If the resulting integer allocation is \(y_{t,d}\), output \(x_{t,d}=y_{t,d}/Q\).

The bit length of \(Q\) is
\(B=O(L+\log(m+1))\):
the sum of the input denominators’ bit lengths is at most \(L\). All residuals and allocations lie between zero and \(Q\), so every mass manipulated by the algorithm has \(O(B)\) bits. The dense output has \(O(m\tau B)\) bits.

To implement candidate selection, maintain a pointer starting at the bottom of each type’s ranking. Advance it past exhausted candidates. Because capacities never increase, each pointer advances at most \(m\) times, giving \(O(m\tau)\) total ranking operations. Process types in a fixed order, moving to the next type when its residual vanishes.

Computing the scaled initial integers takes \(O(\tau B^2)\) bit operations using schoolbook multiplication and division. The allocation steps, ranking scans, and output take \(O((m\tau+m+\tau)B)\) additional bit operations. Including input reading, a conservative bound is therefore
\(O\!\left(L+m\tau(L+\log(m+1))^2\right)\).

This constructs the candidate and every required rational mass directly from the support representation, proving polynomial-time solvability.
