The continuous mirror question, as graded

Given a finite set of types \(T\), rational masses \(\mu_t\), a polynomial worth function \(V\) on \([0,\mu]\), and an efficient allocation rule for coalition compositions, does there exist a measurable partition with no positive-mass group that can reorganize among existing or new coalitions so that almost every deviator strictly improves? Theorem 1’s continuous promised subclass assumes \(\sum_t y_t\phi_t(\mu)\ge V(y)\) for every \(y\le\mu\), where \(\phi_t(\mu)\) is the grand-coalition per-capita payoff.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\). Here \(\tau\) is the support size, not the number of possible types; masses need not sum to one.
Represent type \(t\) by an atomless interval of measure \(\mu_t\). A coalition has composition \(y\in[0,\mu]\setminus\{0\}\), and every type-\(t\) member receives the per-capita payoff \(\phi_t(y)\).
The input gives a rational-coefficient polynomial worth function \(V\), with \(V(0)=0\), and rational-function allocation expressions \(\phi_t\), finite wherever \(y_t>0\). Worths and payoffs may be negative. Efficiency means \(\sum_{t:y_t>0}y_t\phi_t(y)=V(y)\) for every nonzero composition.
Encode these functions by arithmetic circuits; let \(m\) be their total number of gates and \(L\) the total binary input length. State running times in \(m,\tau,L\).
A partition consists of finitely or countably many measurable positive-mass coalitions covering the society up to a null set. Preferences compare per-capita payoffs, with equal payoffs giving indifference.
A deviation uses any measurable positive-mass group \(H\), possibly the entire society. Its members may split among new coalitions, join existing coalitions, or remain with nondeviators, without permission; nondeviators retain exactly their previous grouping, modulo null sets.
A partition is FX-FE strongly Nash stable if no such deviation produces another admissible partition in which almost every member of \(H\) strictly improves.
Restrict inputs to the promised subclass satisfying \(\sum_t y_t\phi_t(\mu)\ge V(y)\) for every \(y\in[0,\mu]\); the promise need not be checked.

Is deciding whether an FX-FE strongly Nash stable measurable partition exists on this promised subclass in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

In the finite-agent setting, efficiency on every coalition and core membership of the grand-coalition allocation guarantee that the grand-coalition partition is FX-FE strongly Nash stable. [Source](https://www.ijcai.org/proceedings/2026/60)

Result

The promised decision problem is in \(\mathrm{P}\). Every promised instance admits an FX-FE strongly Nash stable partition: the grand-coalition partition.

We use the efficiency identity stated in the task. The argument establishes the continuous analogue of the finite result in [Theorem 1 of the cited paper](https://www.ijcai.org/proceedings/2026/0060.pdf), including countable partitions and deviations by the entire society.

Setup

Let \(X_t\) be the interval representing type \(t\), let \(X=\bigsqcup_{t\in T}X_t\), and let \(\lambda\) denote measure. Thus \(\lambda(X_t)=\mu_t\). Consider the admissible partition \(\pi_0=\{X\}\).

Define \(a_t=\phi_t(\mu)\). These numbers are finite because every \(\mu_t\) is positive. Every type-\(t\) member receives \(a_t\) under \(\pi_0\).

The promise states that, for every \(y\in[0,\mu]\),

\(\displaystyle V(y)\leq\sum_{t\in T}y_ta_t.\)

Proof of stability

Suppose, for contradiction, that a measurable group \(H\subseteq X\) of positive measure deviates to an admissible partition \(\pi'\), with almost every member of \(H\) strictly improving.

First, no coalition in \(\pi'\) can consist almost entirely of deviators. Indeed, suppose \(C\in\pi'\) satisfies \(\lambda(C\setminus H)=0\). Write \(y_t=\lambda(C\cap X_t)\). Since \(C\) has positive measure, \(y\neq0\).

For each type with \(y_t>0\), almost every member of \(C\cap X_t\) belongs to \(H\) and strictly improves. All these members receive the same new payoff \(\phi_t(y)\), so necessarily \(\phi_t(y)>a_t\). Efficiency therefore gives

\(\displaystyle V(y)=\sum_{t:y_t>0}y_t\phi_t(y)>\sum_{t:y_t>0}y_ta_t=\sum_{t\in T}y_ta_t.\)

The strict inequality follows because the sum is finite, its index set is nonempty, and every summand \(y_t(\phi_t(y)-a_t)\) is positive. This contradicts the promise.

Now put \(N=X\setminus H\), the set of nondeviators. There are two cases.

  • If \(\lambda(N)=0\), every coalition in \(\pi'\) consists almost entirely of deviators. Since the positive-mass society is covered up to a null set, \(\pi'\) contains a positive-mass coalition, contradicting the preceding conclusion.
  • If \(\lambda(N)>0\), preservation of the nondeviators’ previous grouping means that some coalition \(C_*\in\pi'\) contains all of \(N\), modulo a null set: all nondeviators were grouped together in \(\pi_0\).

Any other coalition \(C\in\pi'\) has \(\lambda(C\cap N)=0\), and hence \(\lambda(C\setminus H)=0\). The preceding conclusion excludes every such positive-mass coalition. Consequently, \(C_*\) is the only coalition in \(\pi'\).

Because \(\pi'\) covers \(X\) up to a null set, \(C_*\) has composition \(\mu\). Almost every type-\(t\) deviator therefore still receives \(\phi_t(\mu)=a_t\). No positive-mass group can strictly improve almost everywhere, again a contradiction.

These cases exhaust all deviations. Thus \(\pi_0\) is FX-FE strongly Nash stable.

The argument works for finite or countable admissible partitions and does not assume nonnegative worths or payoffs.

Algorithm and running time

On every promised input, return YES. No circuit evaluation or promise verification is necessary.

The decision takes \(\mathrm{O}(1)\) time, independently of \(m,\tau,L\), when input reading is not required; including a full input scan gives \(\mathrm{O}(L)\) time. A stable partition is specified simply as the single coalition containing the whole society.

2. Excluding coalitions consisting almost entirely of deviators

Fix the hypothesized deviation \(H\) and resulting partition \(\pi'\). The assumption of strict improvement almost everywhere means that the exceptional set of deviators who fail to improve has measure zero.

For a positive-mass coalition \(C\) satisfying \(\lambda(C\setminus H)=0\), its composition satisfies \(y\in[0,\mu]\setminus\{0\}\).

\[ V(y)-\sum_{t\in T}y_ta_t = \sum_{t:y_t>0}y_t\bigl(\phi_t(y)-a_t\bigr)>0 \]

No uniform positive improvement margin is needed. Negative worths or initial payoffs do not affect this calculation.

The conclusion follows.
