The continuous mirror question, as graded

Given finite item kinds \(G\), finite complete binary valuation types \(T\) with value-oracle access, rational masses \(\mu_t\) satisfying \(\sum_{t\in T}\mu_t=1\), and rational per-capita supplies \(0\le \rho_g\le1\), compute a finite-support histogram \(x_{t,A}\ge0\) over \(t\in T\) and integral bundles \(A\subseteq G\) satisfying \(\sum_A x_{t,A}=\mu_t\), \(\sum_{t,A:g\in A}x_{t,A}=\rho_g\), and \(v_t(A)\ge v_t(B\setminus\{g\})\) whenever \(x_{t,A}x_{t',B}>0\), for all \(t,t'\) and \(g\in B\); alternatively minimize unallocated item mass and decide whether the optimum is zero.

Packaged proof task (what the prover saw — nothing else)

Let \(G\) contain \(m\) item kinds. A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has an exact value oracle for \(v_t:2^G\to\mathbb Z_{\ge0}\), with \(v_t(\emptyset)=0\) and \(v_t(S\cup\{g\})-v_t(S)\in\{0,1\}\) for every \(S\subseteq G\) and \(g\notin S\); additivity and submodularity are not assumed.
Supplies are binary rationals \(\rho_g\in[0,1]\). Each individual receives an integral bundle \(A\subseteq G\), with at most one item of each kind; types may split their mass among bundles, including \(\emptyset\).
A feasible histogram has finitely many positive rational entries \(x_{t,A}\), with \(\sum_{A\subseteq G}x_{t,A}=\mu_t\) and \(\sum_{t,A:g\in A}x_{t,A}=\rho_g\).
It must satisfy \(v_t(A)\ge v_t(B\setminus\{g\})\) whenever \(x_{t,A}>0\) and \(x_{t',B}>0\), for every \(t,t'\in T\), \(A,B\subseteq G\), and \(g\in B\), including comparisons within a type and removal of zero-marginal items.
Let \(L\) be the total bit length of the masses and supplies; count bit operations and exact value-oracle calls separately.

Does deciding feasibility and constructing a feasible EFX histogram admit an algorithm using \(\operatorname{poly}(m,\tau,L)\) bit operations and oracle calls, or is feasibility \(\mathrm{NP}\)-hard even for polynomial-time evaluable valuations?

For finitely many agents and distinct indivisible items, a complete EFX allocation always exists for these binary-marginal valuations and is computable in polynomial time ([source](https://arxiv.org/pdf/2308.05503)).
No result settling this exact mass-histogram problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted binary valuations as normalized functions with marginal gains in {0,1}, without assuming additivity or submodularity.
  • Made the item-kind interpretation explicit: each individual receives at most one item of each kind, while a type's mass may split among integral bundles, including the empty bundle.
  • Specified rational histogram entries to give the construction problem an exact finite representation.
  • Selected complete-allocation feasibility and construction from the stated alternatives, without introducing the optional unallocated-mass objective.
  • Specified L as the bit length of masses and supplies, counted oracle calls separately from bit operations, and formulated NP-hardness for polynomial-time evaluable valuations.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Feasibility is \(\mathrm{NP}\)-hard, even with one supported type, dyadic supplies, and a polynomial-time evaluable valuation taking values only in \(\{0,1\}\). Consequently, the requested algorithm cannot exist unless \(\mathrm{P}=\mathrm{NP}\).

The proof uses the requirement to remove every item, including items of zero marginal value.

1. A universally supplied zero-value item forces equal values

Suppose there is one type of mass \(1\), and an item \(d\) satisfies \(\rho_d=1\) and \(v(S)=v(S\setminus\{d\})\) for every bundle \(S\).

Every positive-support bundle contains \(d\): otherwise, the mass receiving \(d\) would be strictly less than \(1\).

For any two positive-support bundles \(A,B\), the EFX comparison obtained by removing \(d\) from \(B\) gives
\[ v(A)\ge v(B\setminus\{d\})=v(B). \]
Reversing the bundles gives the opposite inequality. Thus all positive-support bundles have the same value.

2. Reduction from graph coloring

We use the classical theorem that deciding whether a finite simple graph is \(3\)-colorable is \(\mathrm{NP}\)-complete. See [Garey, Johnson, and Stockmeyer](https://doi.org/10.1016/0304-3975%2876%2990059-1).

Let \(R\) be an input graph. Add a new vertex adjacent to every vertex of \(R\), obtaining a graph \(Q=(U,F)\). We may assume \(n=|U|\ge2\).

Then \(Q\) is \(4\)-colorable exactly when \(R\) is \(3\)-colorable. Indeed, a \(3\)-coloring extends by giving the new vertex a fourth color. Conversely, in any \(4\)-coloring, the color of the new vertex is unavailable to every original vertex.

Item kinds and conflict graph

For each \(u\in U\) and \(c\in\{0,1,2,3\}\), introduce an item \(p_{u,c}\). Write
\[ P=\{p_{u,c}:u\in U,\ c\in\{0,1,2,3\}\}. \]

Construct a conflict graph \(H\) on \(P\) with these edges:

  • For each \(u\), its four items form a clique.
  • For each \(\{u,w\}\in F\) and each color \(c\), connect \(p_{u,c}\) to \(p_{w,c}\).

Every independent set in \(H\) has size at most \(n\), because it contains at most one item for each vertex \(u\). An independent set of size \(n\) contains exactly one item \(p_{u,c(u)}\) for each \(u\); the second family of edges ensures that \(c\) is a proper \(4\)-coloring of \(Q\).

Introduce two additional items \(z,d\). Extend \(H\) to a graph \(H^+\) by making \(z\) adjacent to every item in \(P\). The item \(d\) is outside this conflict graph.

The complete item set is \(G=P\cup\{z,d\}\), so \(m=4n+2\).

Type, valuation, and supplies

There is exactly one type, with mass \(1\). Define
\[ v(A)= \begin{cases} 1,&\text{if }A\cap(P\cup\{z\})\text{ contains an edge of }H^+,\\ 0,&\text{otherwise}. \end{cases} \]

This valuation is normalized and monotone. Since its values belong to \(\{0,1\}\), every marginal belongs to \(\{0,1\}\). It ignores \(d\), and evaluation requires only checking the explicitly listed conflict edges.

Set \(q=\lceil\log_2 n\rceil\) and \(\varepsilon=2^{-q}\). Thus \(0<\varepsilon<1\) and \(n\varepsilon\le1\). Specify
\[ \rho_d=1,\qquad \rho_z=1-\varepsilon,\qquad \rho_{p_{u,c}}=\frac{\varepsilon}{4}. \]

All supplies are dyadic and lie in \([0,1]\). Their total encoding length is \(O(n\log n)\), and the graph describing the valuation has polynomial size.

3. Every feasible histogram yields a coloring

Suppose a feasible EFX histogram exists. Suppress the sole type index and write its positive entries as \(x_A\).

By Section 1, every supported bundle contains \(d\), and all supported bundles have a common value in \(\{0,1\}\).

The common value must be zero

If every supported bundle had value \(1\), each would contain an edge of \(H^+\), hence at least two items from \(P\cup\{z\}\). Consequently,
\[ \sum_A x_A\,|A\cap(P\cup\{z\})|\ge2\sum_Ax_A=2. \]

However, the supply equations give
\[ \sum_A x_A\,|A\cap(P\cup\{z\})| =\rho_z+\sum_{p\in P}\rho_p =1-\varepsilon+n\varepsilon \le2-\varepsilon<2. \]
This is a contradiction. Therefore every supported bundle has value zero.

Bundles without \(z\) must encode complete colorings

A value-zero bundle containing \(z\) contains no item in \(P\), because \(z\) conflicts with every such item.

The total mass of bundles without \(z\) is exactly \(\varepsilon\). All supplies of items in \(P\) must be carried by these bundles, so
\[ \sum_{A:z\notin A}x_A\,|A\cap P| =\sum_{p\in P}\rho_p =n\varepsilon. \]

For every supported bundle without \(z\), the set \(A\cap P\) is independent in \(H\), and therefore has size at most \(n\). It follows that
\[ \sum_{A:z\notin A}x_A\bigl(n-|A\cap P|\bigr)=0. \]

Each summand is nonnegative. Since every listed mass is positive, every supported bundle without \(z\) has \(|A\cap P|=n\). Such a bundle exists because their total mass is \(\varepsilon>0\).

Its independent set of size \(n\) encodes a proper \(4\)-coloring of \(Q\). Thus \(R\) is \(3\)-colorable.

4. Every coloring yields a feasible histogram

Conversely, suppose \(Q\) has a proper coloring \(c:U\to\{0,1,2,3\}\).

For each \(j\in\{0,1,2,3\}\), define
\[ I_j=\{p_{u,(c(u)+j)\bmod4}:u\in U\}. \]

Each \(I_j\) is independent in \(H\): it selects one color per vertex, and applying the same cyclic permutation to every color preserves properness.

Use the following five histogram entries:

  • Bundle \(\{d,z\}\), with mass \(1-\varepsilon\).
  • For each \(j\in\{0,1,2,3\}\), bundle \(\{d\}\cup I_j\), with mass \(\varepsilon/4\).

Their masses sum to \(1\). Every bundle contains \(d\), and only the first contains \(z\). For each fixed \(u,c'\), exactly one of the four sets \(I_j\) contains \(p_{u,c'}\). Hence every supply equation holds exactly.

All five bundles have value zero. Removing any item leaves a value-zero bundle, since removing items cannot create a conflict edge. Thus every required EFX inequality is satisfied.

This constructs a feasible rational histogram whenever \(R\) is \(3\)-colorable, completing both directions of the reduction.

5. Polynomial-size certificates

For completeness, the explicitly represented valuation family above has an \(\mathrm{NP}\)-complete feasibility problem. The required certificate bound holds more generally.

Claim. Every feasible instance has a feasible histogram with at most \(m+\tau\) positive entries, each having polynomial encoding length.

Proof. Start with any feasible histogram. For a type–bundle pair \((t,A)\), form a column with:

  • A \(1\) in the row for type \(t\), and zeros in other type rows.
  • The incidence vector of \(A\) in the \(m\) supply rows.

These columns form a matrix \(M\) with \(m+\tau\) rows. The mass and supply equations are \(Mx=b\).

If the active columns are dependent, there is a nonzero rational vector \(h\) with \(Mh=0\). The type rows imply that the entries of \(h\) sum to zero, so \(h\) has both positive and negative entries. Setting
\[ \lambda=\min_{j:h_j>0}\frac{x_j}{h_j} \]
and replacing \(x\) by \(x-\lambda h\) preserves all equations and nonnegativity, while eliminating at least one positive entry. EFX is preserved because the support only shrinks.

Repeat until the active columns are independent. Their number \(r\) is at most \(m+\tau\).

Choose \(r\) rows giving an invertible square matrix \(C\). Let \(D\) be the product of the denominators in \(b\); its binary length is \(O(L)\). Cramer’s rule expresses every surviving mass as an integer determinant divided by \(D\det C\).

The entries of \(C\) are in \(\{0,1\}\), and the entries of \(Db\) are integers between \(0\) and \(D\). Hadamard’s inequality bounds the relevant determinants by \(r^{r/2}\) and \(Dr^{r/2}\), respectively. Thus each mass has encoding length \(O(L+r\log(r+1))\). This proves the claim.

A verifier checks the rational equations and all support-pair EFX comparisons using polynomially many bit operations and \(O(r^2m)\) exact oracle calls. For the graph valuations in the reduction, each call is computable in polynomial time. Therefore this restricted problem belongs to \(\mathrm{NP}\) and is \(\mathrm{NP}\)-complete.

6. Consequence for the requested algorithm

The reduction has \(\tau=1\), \(m=4n+2\), and \(L=O(n\log n)\), with polynomial-time exact value evaluation. An algorithm using \(\operatorname{poly}(m,\tau,L)\) bit operations and oracle calls would therefore decide graph \(3\)-colorability in polynomial time.

The finite-agent existence theorem concerns partitions of distinct items; it does not impose these exact item-kind marginals across a mass histogram. [Bu, Song, and Yu, Theorem 3.1](https://arxiv.org/pdf/2308.05503). The reduction proves hardness for the formulation stated here.
