The continuous mirror question, as graded

Given a finite alternative set \(X\), a support \(\Pi\) of complete rankings with rational masses \(\mu_\pi>0\) summing to \(1\), no pairwise majority ties, and a designated triple \(R\subseteq X\), decide whether \(R\) is a minimal \(\tau\)-retentive set in the induced majority tournament \(T_\mu\), where \(x\to y\) exactly when \(\sum_{\pi:\,x\succ_\pi y}\mu_\pi>1/2\).

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a finite alternative set with \(m=|X|\geq 3\), and let \(R\subseteq X\) contain exactly three alternatives.
A society is given by its support: a list \(\Pi\) of \(\tau\) distinct strict complete rankings, each with positive binary rational mass \(\mu_\pi\), with \(\sum_{\pi\in\Pi}\mu_\pi=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Assume no pairwise majority ties. Define the tournament \(T_\mu\) by \(x\to y\) exactly when \(\sum_{\pi:\,x\succ_\pi y}\mu_\pi>1/2\).
Write \(\operatorname{TEQ}\) for the tournament equilibrium set. For a nonempty tournament \(H\), let \(N_H^-(v)=\{u:u\to v\}\), and let \(H[B]\) denote the induced subtournament on \(B\).
A nonempty set \(A\subseteq V(H)\) is retentive if every \(v\in A\) with \(N_H^-(v)\neq\varnothing\) satisfies \(\operatorname{TEQ}(H[N_H^-(v)])\subseteq A\). It is minimal if no nonempty proper subset is retentive. Recursively, \(\operatorname{TEQ}(H)\) is the union of all minimal retentive sets; on a singleton it is that singleton.

Is deciding whether \(R\) is a minimal retentive set of \(T_\mu\) solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For explicitly given finite tournaments, recognition of a designated triple as a minimal retentive set is known to be polynomial-time solvable.

Result

The problem is polynomial-time solvable in \(m,\tau,L\). The essential point is that the explicitly listed support permits exact polynomial-time construction of the majority tournament, even when the masses have large binary denominators.

Exact construction of the tournament

Index the support as \(\Pi=\{\pi_1,\ldots,\pi_\tau\}\), and write each supplied mass as
\(\mu_{\pi_i}=a_i/b_i\), with positive binary integers \(a_i,b_i\). Define
\[ D=\prod_{i=1}^{\tau}b_i, \qquad w_i=a_i(D/b_i). \]
All divisions here are exact. Since the masses sum to one,
\[ \sum_{i=1}^{\tau}w_i=D. \]

The binary length of \(D\) is at most one plus the sum of the binary lengths of the denominators, hence is \(O(L)\). Moreover, positivity and normalization imply \(w_i\leq D\). Thus every \(w_i\), and every partial sum of the \(w_i\), has \(O(L)\) bits.

For each unordered pair of distinct alternatives \(x,y\), compute
\[ S_{xy}=\sum_{i:\,x\succ_{\pi_i}y}w_i. \]
Then the exact majority comparison is
\[ x\to y \quad\Longleftrightarrow\quad 2S_{xy}>D. \]
Indeed, the supporting mass is exactly \(S_{xy}/D\). Strict completeness of each ranking gives \(S_{xy}+S_{yx}=D\); the no-ties hypothesis therefore guarantees exactly one orientation for every pair. The resulting adjacency matrix represents precisely \(T_\mu\).

Using elementary integer arithmetic, constructing \(D\) and the weights costs \(O(\tau L^2)\) bit operations. Store each alternative’s position in each ranking, then compute all pairwise sums using \(O(m^2\tau)\) additions of \(O(L)\)-bit integers. Including input processing and ranking comparisons, a conservative bound for this entire construction is
\[ O(m^2\tau L^2). \]
There is no expansion of rational masses into individual voters and no enumeration of rankings outside the supplied support.

Recognition and correctness

Use the recognition theorem supplied in the question:

For an explicitly represented finite tournament \(H\) and a designated set \(A\) of exactly three vertices, deciding whether \(A\) is a minimal \(\operatorname{TEQ}\)-retentive set is possible in polynomial time.

The designated-triple recognition result also follows from the characterization in Lemma 7 of [Yang, *A Further Step Towards an Understanding of the Tournament Equilibrium Set*](https://arxiv.org/pdf/1611.03991).

Let \(p(m)\) be a polynomial upper bound on the theorem’s recognition algorithm for an \(m\)-vertex tournament. Apply that algorithm to the constructed adjacency matrix and the original designated triple \(R\).

Its hypotheses hold: the matrix explicitly represents a finite tournament on \(m\) vertices, and \(|R|=3\). Its answer is correct for the original instance because the constructed tournament equals \(T_\mu\), and retentiveness and minimality are defined entirely from that tournament.

The total running time is therefore bounded by
\[ O(m^2\tau L^2+p(m)), \]
which is polynomial in \(m,\tau,L\).

Thus the decision problem belongs to \(\mathrm{P}\). In particular, it cannot be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions unless \(\mathrm{P}=\mathrm{NP}\).
