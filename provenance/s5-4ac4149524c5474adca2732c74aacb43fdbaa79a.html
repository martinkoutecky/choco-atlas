Theorem 3 — class: other

The continuous mirror question, as graded

Given a finite type set \(T\), goods categories \(G\), rational type masses \(\mu_t\) summing to \(1\), rational per-capita supplies \(q_g\), and nonnegative rational values \(v_{gt}\), does there exist a finite-support mass plan \(\pi_{t,b}\ge 0\) over integral bundles \(b\in\mathbb{Z}_{\ge 0}^{G}\) such that \(\sum_b\pi_{t,b}=\mu_t\), \(\sum_{t,b}\pi_{t,b}b_g=q_g\) for each \(g\), and every positively assigned bundle \(b\) of type \(t\) satisfies \(v_t(b)\ge v_t(c)-\min_{g:c_g>0}v_{gt}\) for every positively assigned bundle \(c\) of any type, with comparison to an empty bundle vacuous?

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a nonempty set of \(m\) goods categories. A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts listed types, not all possible types.
Inputs also include binary-rational supplies \(q_g\geq 0\) and values \(v_{gt}\geq 0\). Write \(v_t(b)=\sum_{g\in G}v_{gt}b_g\) for an integral bundle \(b\in\mathbb Z_{\geq 0}^{G}\).
A mass plan consists of nonnegative real numbers \(\pi_{t,b}\), only finitely many positive, satisfying \(\sum_b\pi_{t,b}=\mu_t\) and \(\sum_{t,b}\pi_{t,b}b_g=q_g\) for every \(g\in G\).
The plan is EFX if, whenever \(\pi_{t,b}>0\) and \(\pi_{s,c}>0\) with \(c\neq 0\), one has \(v_t(b)\geq v_t(c)-\min_{g:c_g>0}v_{gt}\). Comparisons include bundles assigned to the same type and removal of zero-valued goods; comparisons to empty bundles are vacuous.
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is deciding whether an EFX mass plan exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents with nonnegative additive valuations and complete allocation of indivisible goods, EFX existence is equivalent to an unconstrained piecewise-linear difference-of-convex objective having nonpositive infimum, without a complexity classification ([Etesami](https://arxiv.org/html/2510.04915v1)).
No result settling this exact mass-plan decision problem was located in the literature search.

Modeling choices made when packaging the task

  • The supply sign was unspecified; supplies are nonnegative rational numbers, allowing zero.
  • The bundle valuation was undefined; it is the additive sum of category values with multiplicities.
  • The domain of plan masses was unspecified; plan masses are nonnegative reals, while input masses remain binary rationals.
  • The encoding parameters were unspecified; m counts goods categories, tau counts positive-mass support types, and L is the total binary input length.

Result

Every valid instance admits an EFX mass plan. Consequently, the decision problem is polynomial-time solvable: an algorithm can read the input and return YES, taking \(O(L)\) time, hence polynomial time in \(m,\tau,L\).

The proof uses a finite-agent approximate-EFX theorem, a uniform bound on bundles, and a separate argument for categories valued at zero by every type.

1. The finite-agent theorem used

We use the following established result.

Approximate EFX with sublinear charity. For any finite instance with \(n\) agents, finitely many indivisible goods, and nonnegative additive valuations, and any \(\varepsilon\in(0,1/2]\), there exists a partial allocation \((X_i)_{i=1}^{n}\) with unallocated set \(P\) satisfying

\(u_i(X_i)\geq(1-\varepsilon)u_i(X_j\setminus\{a\})\)

for every pair of agents \(i,j\) and every individual good \(a\in X_j\), and

\(|P|\leq64(n/\varepsilon)^{4/5}\).

This is Theorem 1 of Chaudhury, Garg, Mehlhorn, Mehta, and Misra, [*Improving EFX Guarantees through Rainbow Cycle Number*](https://arxiv.org/html/2103.01628v1). Their definition compares removal of every good, including goods valued at zero.

For category-count bundles, the all-removals formulation of EFX is

\(v_t(b)\geq v_t(c-e_g)\qquad\text{for every }g\text{ with }c_g>0,\)

where \(e_g\) is the unit vector for category \(g\). This is equivalent to the question’s minimum-value formulation because

\(\max_{g:c_g>0}v_t(c-e_g)=v_t(c)-\min_{g:c_g>0}v_{gt}.\)

2. Separate the globally zero-valued categories

Define

\(H=\{g\in G:\text{there exists }t\in T\text{ with }v_{gt}>0\},\qquad Z=G\setminus H.\)

Thus every category in \(H\) is positively valued by at least one listed type, while every category in \(Z\) is valued at zero by every type.

We first construct an EFX mass plan for the supplies restricted to \(H\). We will subsequently restore all supplies in \(Z\).

If \(H=\varnothing\), the restricted plan assigning the empty bundle to every type already suffices. Otherwise, proceed as follows.

3. Uniformly bounded approximate plans on \(H\)

Choose a positive integer \(D\) clearing the denominators of all masses \(\mu_t\) and supplies \(q_g\) for \(g\in H\).

For each integer \(k\geq2\), let

\(n_k=Dk^9,\qquad\varepsilon_k=1/k,\qquad\alpha_k=1-\varepsilon_k.\)

Construct a finite instance with exactly \(n_k\mu_t\) agents of type \(t\) and \(n_kq_g\) individually labeled copies of category \(g\in H\). These are integers by the choice of \(D\). Each copy of category \(g\) has value \(v_{gt}\) to every agent of type \(t\).

This instance satisfies the theorem’s hypotheses: it has finitely many agents and goods, with nonnegative additive valuations. Apply the theorem and normalize agent counts by \(n_k\). Specifically, define

\(\pi^{(k)}_{t,b}=\frac{\#\{\text{type }t\text{ agents receiving category-count bundle }b\}}{n_k}.\)

The resulting finitely supported plan has type masses exactly \(\mu_t\), is \(\alpha_k\)-EFX, and allocates some supplies \(q_g^{(k)}\) satisfying

\(0\leq q_g-q_g^{(k)}\leq\frac{|P_k|}{n_k}\leq64D^{-1/5}k^{-1}.\)

Indeed, substituting \(n_k=Dk^9\) and \(\varepsilon_k=1/k\) into the charity bound gives the final expression. In particular,

\(q_g^{(k)}\longrightarrow q_g\qquad(g\in H).\)

We next prove that all bundles appearing in these plans belong to one fixed finite set.

For each type \(t\), put

\(A_t=\sum_{g\in H}v_{gt}q_g,\qquad M_t=\max_{g\in H}v_{gt}.\)

Nonnegativity and \(q_g^{(k)}\leq q_g\) imply

\(\sum_b\pi^{(k)}_{t,b}v_t(b)\leq\sum_{s,b}\pi^{(k)}_{s,b}v_t(b)=\sum_{g\in H}v_{gt}q_g^{(k)}\leq A_t.\)

Since type \(t\) has positive mass \(\mu_t\), some bundle \(b_{t,k}\) in its support satisfies

\(v_t(b_{t,k})\leq A_t/\mu_t.\)

For every nonempty bundle \(c\) in the entire plan’s support, approximate EFX therefore gives

\(\alpha_k\bigl(v_t(c)-\min_{g:c_g>0}v_{gt}\bigr)\leq v_t(b_{t,k})\leq A_t/\mu_t.\)

As \(\alpha_k\geq1/2\), it follows that

\(v_t(c)\leq2A_t/\mu_t+M_t.\)

For each \(g\in H\), choose a listed type \(t(g)\) with \(v_{g,t(g)}>0\). Additivity and nonnegativity give

\(v_{g,t(g)}c_g\leq v_{t(g)}(c).\)

Consequently, every supported bundle satisfies

\(c_g\leq K_g:=\left\lfloor\frac{2A_{t(g)}/\mu_{t(g)}+M_{t(g)}}{v_{g,t(g)}}\right\rfloor.\)

The bounds \(K_g\) depend only on the original instance. Thus all approximate plans are supported on the fixed finite set

\(\mathcal B=\{b\in\mathbb Z_{\geq0}^{H}:b_g\leq K_g\text{ for every }g\in H\}.\)

4. Taking the limit gives exact EFX

View each \(\pi^{(k)}\) as a vector indexed by \(T\times\mathcal B\). Every coordinate lies in \([0,1]\). Since this is a fixed finite-dimensional space, some subsequence converges coordinatewise to a vector \(\pi^*\).

Passing to the limit in the finite sums gives

\(\sum_{b\in\mathcal B}\pi^*_{t,b}=\mu_t,\qquad \sum_{t,b\in\mathcal B}\pi^*_{t,b}b_g=q_g\quad(g\in H).\)

Hence \(\pi^*\) is a finitely supported mass plan allocating all supplies on \(H\).

To verify exact EFX, fix \((t,b)\) and \((s,c)\) with positive limiting masses, and fix \(g\in H\) with \(c_g>0\). Both masses are positive along all sufficiently late terms of the convergent subsequence. Therefore,

\(v_t(b)\geq\alpha_kv_t(c-e_g)\)

along those terms. Letting \(k\) tend to infinity gives

\(v_t(b)\geq v_t(c-e_g).\)

This proves EFX, including removal of zero-valued goods and comparisons between bundles assigned to the same type.

The uniform bundle bound is essential here: it ensures that the limiting plan has finite support and retains all category supplies.

5. The restricted plan can have rational weights

We need rational weights to restore the categories in \(Z\) through a finite replication argument.

Let \(S\) be the positive support of \(\pi^*\). On this fixed support, consider the feasibility equations

\(Ax=y,\qquad x\geq0,\)

where the column corresponding to \((t,b)\in S\) consists of the type-incidence vector \(e_t\) followed by the bundle vector \(b\), and

\(y=((\mu_t)_{t\in T},(q_g)_{g\in H}).\)

The matrix \(A\) is integral, the vector \(y\) is rational, and the system is feasible.

Choose a feasible vector \(x\) with the fewest positive coordinates. Its active columns are linearly independent. Otherwise, there would be a nonzero vector \(d\) supported on those columns with \(Ad=0\). Summing the type rows yields \(\sum_jd_j=0\), so \(d\) has both positive and negative coordinates. Setting

\(\lambda=\min_{j:d_j<0}x_j/(-d_j)\)

would make \(x+\lambda d\) feasible and nonnegative, with strictly smaller positive support—a contradiction.

Select an invertible square minor of the active columns. The active weights solve the corresponding square system with rational coefficients and right-hand side, and therefore are rational.

This produces a rational mass plan whose support is contained in \(S\). It remains EFX because deleting supported bundles cannot introduce an EFX violation. Denote this rational plan by \(\widehat\pi\).

When \(H=\varnothing\), simply use \(\widehat\pi_{t,0}=\mu_t\), which is already rational.

6. Restore every globally zero-valued category

Choose a positive integer \(R\) clearing the denominators of all weights in \(\widehat\pi\), all masses, and all supplies \(q_g\), including those in \(Z\).

Realize \(\widehat\pi\) as a finite allocation to \(R\) agents: there are \(R\mu_t\) agents of each type \(t\), and exactly \(R\widehat\pi_{t,b}\) receive bundle \(b\). This allocates \(Rq_g\) copies of every category \(g\in H\) and is EFX.

We now produce an unenvied bundle without changing the supplies or losing EFX.

For a finite allocation \((X_i)\), define its envy graph by an edge \(i\to j\) whenever

\(u_i(X_i)<u_i(X_j).\)

If the graph has a directed cycle, give each agent on that cycle the bundle of its successor. Every participating agent strictly increases her own utility, and other agents retain their utilities. The multiset of bundles is unchanged.

Such a rotation preserves EFX: every agent’s own utility weakly increases, while every bundle against which she must compare remains among the same multiset of bundles. Repeated rotations terminate because there are only finitely many assignments of that multiset, and each rotation strictly increases \(\sum_i u_i(X_i)\).

The resulting envy graph is acyclic. It therefore has a vertex \(j\) with no incoming edge. Its bundle is unenvied:

\(u_i(X_i)\geq u_i(X_j)\qquad\text{for every agent }i.\)

Give agent \(j\) all \(Rq_g\) copies of every category \(g\in Z\), leaving other bundles unchanged. These counts are integral by the choice of \(R\).

All agents’ own utilities remain unchanged, and every agent values the enlarged bundle of \(j\) exactly as she valued \(X_j\). Thus the enlarged bundle remains unenvied. By nonnegativity, removing any good from it cannot increase its value, so all EFX comparisons to that bundle hold. Comparisons to other bundles retain their previous EFX inequalities.

The resulting finite allocation is complete and EFX. Normalizing its agent counts by \(R\) yields a finitely supported EFX mass plan with precisely the prescribed type masses and supplies on all of \(G\).

7. Complexity conclusion

The preceding argument proves universal existence under exactly the stated assumptions, including arbitrary nonnegative values, positive listed-type masses, same-type comparisons, and removal of zero-valued goods.

Therefore, on the specified valid inputs, the decision algorithm reads the input and returns YES in \(O(L)\) time. The finite replications and limiting argument establish existence; the decision algorithm need not construct them.
