The continuous mirror question, as graded

Given integer type weights \(w_t\ge2\), rational masses \(\mu_t\) summing to \(1\), and a population scale \(N\), define \(V(x)=\prod_t w_t^{Nx_t}-1\) for \(0\le x_t\le\mu_t\). Compute a type-anonymous payoff vector \(p\) satisfying \(\sum_t\mu_t p_t=V(\mu)\) and \(\sum_t x_t p_t\ge V(x)\) for every feasible mass vector \(x\).

A society is given by its support: \(\tau\ge1\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types. Each type has a binary integer weight \(w_t\ge2\); the population scale \(N\ge1\) is a binary integer, with no integrality requirement on \(N\mu_t\).
Coalitions are all real mass vectors \(x\) with \(0\le x_t\le\mu_t\), and their worth is \(V(x)=\prod_{t=1}^{\tau}w_t^{Nx_t}-1\), including \(V(0)=0\).
A type-anonymous allocation assigns a real payoff density \(p_t\) to each type. Compute one satisfying \(\sum_t\mu_t p_t=V(\mu)\) and \(\sum_t x_t p_t\ge V(x)\) for every coalition \(x\).
Exact payoffs are represented by finite arithmetic circuits with binary rational constants, addition, subtraction, multiplication, division by nonzero quantities, and rational-power gates with positive bases and binary rational exponents. Let \(L\) be the total input bit length; state running times in \(\tau\), \(L\), and any additional dependence on \(N\). There is no separate candidate parameter \(m\).

Is this exact core-allocation problem solvable in polynomial time in \(\tau\) and \(L\), or is it NP-hard?

For finite product games with integer weights at least \(2\), zero empty-coalition worth and unshifted product worth otherwise, a core allocation can be computed using linearly many arithmetic operations. [Rosales](https://arxiv.org/pdf/1401.8144).
Finite games with normalized worth \(\prod_{i\in S}a_i-1\), for \(a_i\ge1\), are also convex and have nonempty cores. [Dehez](https://perso.uclouvain.be/pierre.dehez/Publications/CORE-DP-2023-10.pdf). No result settling the exact mass-allocation problem above was located.

  • Do not require N times a type's mass to be integral; coalitions may select arbitrary real fractions of every supported type.

Result

The exact core-allocation problem is polynomial-time solvable in \(\tau\) and \(L\), under the stipulated arithmetic-circuit output representation. The construction needs no additional dependence on the numerical value of \(N\).

The proof below covers every real-mass coalition, without requiring \(N\mu_t\) to be integral.

1. Construction

Use the input order of the supported types. Define

\(\displaystyle a_t=w_t^{N\mu_t},\qquad P_0=1,\qquad P_t=\prod_{s=1}^{t}a_s.\)

Because \(w_t\ge2\), \(N\ge1\), and \(\mu_t>0\), each \(a_t>1\). Assign payoff density

\(\displaystyle p_t=\frac{P_{t-1}(a_t-1)}{\mu_t},\qquad t=1,\ldots,\tau.\)

Every division is valid because the supported masses are positive. The powers have positive bases and binary rational exponents, so these expressions use precisely the permitted circuit operations.

2. Efficiency

For every type,

\(\displaystyle \mu_t p_t=P_{t-1}(a_t-1)=P_t-P_{t-1}.\)

Summing and telescoping gives

\(\displaystyle \sum_{t=1}^{\tau}\mu_t p_t=P_\tau-P_0=\prod_{t=1}^{\tau}w_t^{N\mu_t}-1=V(\mu).\)

Thus the allocation distributes exactly the grand-coalition worth.

3. Every real-mass coalition receives at least its worth

Fix an arbitrary coalition \(x\), where \(0\le x_t\le\mu_t\). Define its participation fractions by

\(\displaystyle y_t=\frac{x_t}{\mu_t}\in[0,1].\)

Its worth and payment are therefore

\(\displaystyle V(x)=\prod_{t=1}^{\tau}a_t^{y_t}-1,\qquad \sum_{t=1}^{\tau}x_t p_t=\sum_{t=1}^{\tau}y_tP_{t-1}(a_t-1).\)

We prove that the first expression is at most the second.

Convexity bound. For any \(a\ge1\), the function \(f(y)=a^y\) has second derivative

\(\displaystyle f''(y)=(\log a)^2a^y\ge0.\)

Consequently, its value at \(y\in[0,1]\) is at most the chord joining its endpoint values:

\(\displaystyle a^y\le(1-y)a^0+ya^1=1+y(a-1).\)

These logarithms are used only in the proof; the algorithm does not compute them.

Set

\(\displaystyle b_t=1+y_t(a_t-1).\)

Then \(1\le b_t\le a_t\) and \(a_t^{y_t}\le b_t\). Since all factors are positive,

\(\displaystyle V(x)\le\prod_{t=1}^{\tau}b_t-1.\)

Telescoping bound. Set \(B_0=1\) and \(B_t=\prod_{s=1}^{t}b_s\). For each \(t\),

\(\displaystyle B_t-B_{t-1}=B_{t-1}(b_t-1)=B_{t-1}y_t(a_t-1).\)

Moreover, \(b_s\le a_s\) for every \(s\), so \(B_{t-1}\le P_{t-1}\). Because \(y_t(a_t-1)\ge0\), summing these identities yields

\(\displaystyle \prod_{t=1}^{\tau}b_t-1=\sum_{t=1}^{\tau}B_{t-1}y_t(a_t-1)\le\sum_{t=1}^{\tau}P_{t-1}y_t(a_t-1)=\sum_{t=1}^{\tau}x_t p_t.\)

Combining the two bounds proves

\(\displaystyle V(x)\le\sum_{t=1}^{\tau}x_t p_t.\)

The coalition \(x\) was arbitrary, including \(x=0\). Together with efficiency, this proves that the constructed allocation lies in the core.

4. Exact representation and running time

Write each input mass as \(\mu_t=u_t/v_t\), with positive binary integers \(u_t,v_t\). The rational-power exponent is

\(\displaystyle N\mu_t=\frac{Nu_t}{v_t}.\)

Its numerator and denominator each have \(O(L)\) bits. In particular, forming this exponent does not require expanding the population into \(N\) individuals.

The algorithm constructs the following gates successively:

  • \(a_t=w_t^{Nu_t/v_t}\);
  • \(p_t=P_{t-1}(a_t-1)/\mu_t\);
  • \(P_t=P_{t-1}a_t\).

With shared subexpressions, this uses \(O(\tau)\) gates, including exactly \(\tau\) rational-power gates. The total circuit encoding length is

\(\displaystyle O\!\left(L+\tau\log(N+1)+\tau\log(\tau+1)\right).\)

Indeed, the original constants occupy \(O(L)\) bits, multiplying each exponent numerator by \(N\) adds at most \(O(\log(N+1))\) bits per type, and gate references require \(O(\log(\tau+1))\) bits each.

Using schoolbook integer arithmetic to form the exponent numerators gives a conservative construction-time bound of \(O(\tau L^2)\) bit operations. If each payoff must be delivered as a separate circuit without sharing between outputs, copying the needed prefixes gives \(O(\tau^2)\) total gates and \(O(\tau^2L)\) output bits. This also fits the stated polynomial-time bound, since \(\tau\le L\).

Thus the algorithm constructs exact circuit representations in polynomial time. It need not numerically evaluate the potentially enormous or irrational payoffs.

5. Relation to the finite-game results

The construction follows the marginal-contribution principle discussed in [Rosales’s finite product-game analysis](https://arxiv.org/pdf/1401.8144). Normalized finite product games are also studied by [Dehez](https://perso.uclouvain.be/pierre.dehez/Publications/CORE-DP-2023-10.pdf). The convexity and telescoping argument above independently establishes the required inequalities for arbitrary fractional participation, completing the passage to the stated mass model.
