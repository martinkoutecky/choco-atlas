The continuous mirror question, as graded

Given a rational type-mass vector \(\mu\in\mathbb{Q}_{>0}^{\tau}\) with \(\sum_a\mu_a=1\), and a rational-coefficient polynomial comparison kernel \(f(x,y)\) of fixed degree on \(P_\mu\times P_\mu\), where \(P_\mu=\prod_a[0,\mu_a]\), compute for each type \(a\) the value \(b_a=\left.\frac{d}{d\epsilon}\big[f(z+\epsilon e_a,z)-f(z,z+\epsilon e_a)\big]\right|_{\epsilon=0}\), with \(z=\mu/2\), and return the weak ranking induced by \((b_a)_a\).

Conclusion

The exact scores and their weak ranking are computable in deterministic polynomial time in \(\tau\) and \(L\), for every fixed \(d\). The explicit monomial representation permits direct differentiation and exact rational evaluation.

Exact formula for the scores

Write the input polynomial as

\(f(x,y)=\sum_{r=1}^{M}c_r\prod_{j=1}^{\tau}x_j^{\alpha_{rj}}y_j^{\gamma_{rj}},\)

where \(c_r\) is rational, the exponents are nonnegative integers, and \(\sum_j(\alpha_{rj}+\gamma_{rj})\leq d\).

Because every \(\mu_a\) is positive, both \(z+\epsilon e_a\) and \(z\) lie in \(P_\mu\) whenever \(|\epsilon|<\mu_a/2\). Thus the derivative in the question is well-defined, and polynomial differentiation gives

\(b_a=\partial_{x_a}f(z,z)-\partial_{y_a}f(z,z).\)

For each monomial, put \(k_{rj}=\alpha_{rj}+\gamma_{rj}\) and \(A_r=\{j:k_{rj}>0\}\). Its contribution to \(b_a\) is zero if \(a\notin A_r\). If \(a\in A_r\), its contribution is

\(u_{r,a}=c_r(\alpha_{ra}-\gamma_{ra})\prod_{j\in A_r}z_j^{\,k_{rj}-\mathbf{1}_{j=a}}.\)

Indeed, differentiating with respect to \(x_a\) contributes the multiplier \(\alpha_{ra}\), while differentiating with respect to \(y_a\) contributes \(\gamma_{ra}\). At \((z,z)\), both derivative products have exactly the exponents displayed above. When either multiplier is zero, its derivative term is zero, so the same formula still applies.

Consequently,

\(b_a=\sum_{r:\,a\in A_r}u_{r,a}.\)

Every exponent in this formula is nonnegative. Each product has total degree at most \(d-1\), and \(|A_r|\leq d\). Constant monomials contribute nothing. In particular, if \(d=0\), all scores are zero.

Algorithm and exact arithmetic complexity

Initialize every score to zero. For each monomial \(r\), compute \(u_{r,a}\) for each \(a\in A_r\) and add it to the corresponding score. This gives precisely the scores proved above.

Here is a bit complexity bound, including the cost of exact rational arithmetic. Represent each rational as an integer numerator and a positive integer denominator. The argument applies to both dyadic rationals and general rationals encoded in binary.

Each input numerator and denominator has bit length at most \(L\). Forming \(z_j=\mu_j/2\) increases its denominator bit length by at most one. A contribution \(u_{r,a}\) uses:

  • one input coefficient;
  • an integer multiplier of absolute value at most \(d\);
  • at most \(d-1\) factors \(z_j\), counting repetitions.

Therefore, for fixed \(d\), each contribution admits an exact numerator–denominator representation whose two integers have bit length at most \(B=O_d(L+1)\).

We must also bound the size of the accumulated scores. Suppose one score receives \(t\leq M\) contributions \(p_s/q_s\), with \(|p_s|<2^B\) and \(1\leq q_s<2^B\). A common-denominator representation is

\(D=\prod_{s=1}^{t}q_s,\qquad N=\sum_{s=1}^{t}p_s\prod_{\ell\neq s}q_\ell.\)

These integers satisfy \(D<2^{tB}\) and \(|N|<t\,2^{tB}\). Hence their bit lengths are \(O(tB+\log(t+1)+1)\). The same bound applies to every intermediate sum obtained by successive rational additions; reducing fractions is unnecessary.

Since an explicit input list has \(M=O(L)\), all intermediate integers have bit length \(O_d((L+1)^2)\).

For each monomial there are at most \(d\) contributions, each requiring \(O(d)\) arithmetic operations. Thus the score computation uses \(O(Md^2+\tau)\) arithmetic operations, in addition to reading the input. For fixed \(d\), this is polynomial in \(\tau\) and \(L\). Integer addition and multiplication on the polynomially bounded integers above also take polynomial time, proving polynomial bit complexity, rather than merely a polynomial arithmetic-operation count.

Computing the weak ranking

Write the resulting scores as \(b_a=N_a/D_a\), with \(D_a>0\). Exact comparison uses

\(b_a\geq b_b\quad\Longleftrightarrow\quad N_aD_b\geq N_bD_a.\)

The cross-products have polynomial bit length. Sorting the \(\tau\) scores therefore takes polynomial time. Group adjacent scores whenever \(N_aD_b=N_bD_a\); these groups retain precisely the requested ties.

This completes the algorithm and its correctness and complexity proofs. Neither antisymmetry nor diagonal normalization is needed, and the finite-player Banzhaf identity is not required.
