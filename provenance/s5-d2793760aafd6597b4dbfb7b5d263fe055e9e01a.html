The continuous mirror question, as graded

Given firms \(F\), a finite support \(T\) of complete productivity types with rational masses \(\mu_t\), rational values \(a_{it}\), and a fixed assignment \(x_{it}\ge 0\) satisfying \(\sum_i x_{it}=\mu_t\), compute the largest core factor and a supporting wage schedule and firm-profit vector. With \(B_i=\sum_t x_{it}a_{it}\), cohort wages \(z_{ht}\), and \(s_{iht}\ge 0\), the equivalent question is to minimize \(\rho\) subject to \(\sum_t x_{it}z_{it}+\sum_{h,t}x_{ht}s_{iht}\le \rho B_i\) for each \(i\), and \(s_{iht}\ge a_{it}-z_{ht}\); the factor is \(\alpha=1/\rho\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) complete productivity types with positive binary-rational masses \(\mu_t\), where \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_t\mu_t=1\).
There are \(m\ge1\) firms, nonnegative rational additive productivities \(a_{it}\), and a fixed rational assignment \(x_{ht}\ge0\) satisfying \(\sum_hx_{ht}=\mu_t\). Assume \(\sum_t\mu_t\max_i a_{it}>0\); allow zero-output firms. Set \(B_i=\sum_t x_{it}a_{it}\).
Cohort \((h,t)\) consists of type \(t\) mass currently assigned to firm \(h\). A wage schedule pays each unit of this cohort \(y_{ht}\ge0\); firm profits \(p_i\ge0\) satisfy local financing \(p_i+\sum_t x_{it}y_{it}=B_i\).
For any nonempty firm coalition \(I\) and selected cohort masses \(0\le u_{ht}\le x_{ht}\), its deviation value is \(\sum_{h,t}u_{ht}\max_{i\in I}a_{it}\). Selection may include its current workers; firms have no capacity constraints.
An outcome supports factor \(\alpha\ge0\) if \(\sum_{i\in I}p_i+\sum_{h,t}u_{ht}y_{ht}\ge\alpha\sum_{h,t}u_{ht}\max_{i\in I}a_{it}\) for every such coalition and selection. Let \(\alpha^*(x)\) be the largest supportable factor.

Is computing \(\alpha^*(x)\) and supporting wages and profits possible in polynomial time in \(m,\tau,L\), or is deciding whether \(\alpha^*(x)\ge q\) NP-hard, for an input nonnegative binary-rational threshold \(q\), where \(L\) is the total input bit length?

For a finite list of indivisible workers and a fixed complete assignment, the largest supportable core factor and supporting payments are exactly computable in polynomial time by linear programming. No result establishing the complexity of this continuous formulation has been verified here.

Modeling choices made when packaging the task

  • Normalized total mass to one; the graded question did not specify a normalization.
  • Required nonnegative rational productivities and a rational fixed assignment, following the discrete valuation domain and ensuring a finite binary input.
  • Defined wages as nonnegative payments per unit of each employer–type cohort, with nonnegative firm profits and separate local financing for each firm.
  • Defined deviations to select arbitrary divisible portions of every cohort, including current workers, without capacity constraints.
  • Excluded the all-zero productivity market, where the unrestricted core factor is unbounded; retained zero-output firms and assignments whose optimal factor is zero.

Result

Computing \(\alpha^*(x)\), together with supporting wages and profits, is possible in polynomial time in \(m,\tau,L\). The threshold problem is therefore also polynomial-time solvable.

The key is that single-firm deviation constraints imply every coalition deviation constraint, even with divisible cohort masses.

1. Reduction to single-firm deviations

Fix a factor \(\alpha\ge0\), wages \(y_{ht}\ge0\), and profits \(p_i\ge0\).

Suppose the support inequality holds for every singleton firm coalition and every permitted selection of cohort masses. Consider any nonempty coalition \(I\) and any selection \(u_{ht}\in[0,x_{ht}]\).

For each type \(t\), choose a firm \(i(t)\in I\) attaining \(\max_{i\in I}a_{it}\). For each \(i\in I\), define
\[ u^i_{ht}= \begin{cases} u_{ht},&i=i(t),\\ 0,&i\ne i(t). \end{cases} \]
Each \(u^i\) is a permitted selection. Applying the singleton constraint to firm \(i\) gives
\[ p_i+\sum_{h,t}u^i_{ht}y_{ht} \ge \alpha\sum_{h,t}u^i_{ht}a_{it}. \]
Summing these inequalities over \(i\in I\), and using the fact that each selected cohort mass appears exactly once, yields
\[ \sum_{i\in I}p_i+\sum_{h,t}u_{ht}y_{ht} \ge \alpha\sum_{h,t}u_{ht}\max_{i\in I}a_{it}. \]
This is precisely the required coalition constraint. The converse is immediate because singleton coalitions are allowed.

Thus it suffices to impose the singleton constraints.

For a fixed firm \(i\), these constraints are
\[ p_i\ge \sum_{h,t}u_{ht}(\alpha a_{it}-y_{ht}) \qquad \text{for every }0\le u_{ht}\le x_{ht}. \]
The coordinates \(u_{ht}\) vary independently. Writing \(r_+=\max\{r,0\}\), maximizing the right-hand side therefore gives the equivalent condition
\[ p_i\ge \sum_{h,t}x_{ht}(\alpha a_{it}-y_{ht})_+. \tag{1} \]
Indeed, each summand is maximized by taking \(u_{ht}=x_{ht}\) when its coefficient is positive and \(u_{ht}=0\) when its coefficient is negative; either endpoint works when the coefficient is zero.

2. A polynomial-size linear program

Let
\[ C=\{(h,t):x_{ht}>0\}, \qquad c=|C|\le m\tau. \]
Cohorts outside \(C\) can never contribute selected mass, so their wages may be set to zero.

For each \((h,t)\in C\), introduce its total wage payment
\[ w_{ht}=x_{ht}y_{ht}. \]
Because \(x_{ht}>0\), condition (1) becomes
\[ p_i\ge \sum_{(h,t)\in C} (\alpha x_{ht}a_{it}-w_{ht})_+. \tag{2} \]

Define
\[ B=\sum_{i=1}^m B_i, \qquad S=\sum_t\mu_t\max_i a_{it}. \]
The hypothesis ensures \(S>0\). Any supporting outcome must satisfy
\[ \alpha S\le B. \tag{3} \]
To see this, take the coalition of all firms and select every cohort completely. Its total payment is
\[ \sum_i p_i+\sum_{h,t}x_{ht}y_{ht} =\sum_i B_i=B \]
by local financing, while its deviation value is \(S\).

Consider the following linear program, with variables \(\alpha,p_i,w_{ht},z_{iht}\):
\[ \begin{aligned} \text{maximize}\quad &\alpha\\ \text{subject to}\quad &p_h+\sum_{t:(h,t)\in C}w_{ht}=B_h &&\text{for every }h,\\ &z_{iht}\ge \alpha x_{ht}a_{it}-w_{ht} &&\text{for every }i,\ (h,t)\in C,\\ &\sum_{(h,t)\in C}z_{iht}\le p_i &&\text{for every }i,\\ &S\alpha\le B,\\ &\alpha,\ p_i,\ w_{ht},\ z_{iht}\ge0. \end{aligned} \tag{LP} \]

We prove that its feasible solutions correspond exactly to supporting outcomes.

From a supporting outcome to a feasible solution. Set \(w_{ht}=x_{ht}y_{ht}\) and
\[ z_{iht}=(\alpha x_{ht}a_{it}-w_{ht})_+. \]
Local financing gives the first constraints, condition (2) gives the profit constraints, and (3) gives the factor bound. All remaining constraints follow from the definitions.

From a feasible solution to a supporting outcome. Define
\[ y_{ht}= \begin{cases} w_{ht}/x_{ht},&(h,t)\in C,\\ 0,&(h,t)\notin C. \end{cases} \]
Local financing holds. Moreover, the nonnegativity and lower bounds on \(z_{iht}\) imply
\[ z_{iht}\ge(\alpha x_{ht}a_{it}-w_{ht})_+. \]
Consequently,
\[ p_i\ge\sum_{(h,t)\in C}z_{iht} \ge\sum_{(h,t)\in C} (\alpha x_{ht}a_{it}-w_{ht})_+. \]
Thus every singleton constraint holds, and Section 1 proves that every coalition constraint holds.

Therefore the optimal value of (LP) is exactly \(\alpha^*(x)\).

3. Attainment, exactness, and complexity

The linear program is nonempty: take
\[ \alpha=0,\qquad p_i=B_i,\qquad w_{ht}=z_{iht}=0. \]

Its feasible region is bounded. Specifically,
\[ 0\le\alpha\le B/S,\qquad 0\le p_i\le B_i,\qquad 0\le w_{ht}\le B_h, \]
where the last two bounds follow from local financing and nonnegativity. Also,
\[ 0\le z_{iht}\le p_i\le B_i \]
because the nonnegative \(z_{iht}\) sum to at most \(p_i\). The feasible region is closed, so the maximum is attained. This includes the case \(B=0\), in which the optimum is zero.

There are
\[ 1+m+c+mc=O(m^2\tau) \]
variables and \(O(m^2\tau)\) constraints. All coefficients are rational numbers computed from the input using products, sums, and comparisons. Their total binary encoding length is polynomial in \(m,\tau,L\). In particular, the formulation enumerates only the supplied support types.

Apply the standard rational linear programming theorem: a rational linear program can be solved exactly in time polynomial in its binary encoding length, returning an optimal rational solution when a finite optimum exists. Here rationality, nonemptiness, and boundedness have all been verified. The resulting wages are recovered by rational division \(w_{ht}/x_{ht}\); both their encoding lengths and the computation time remain polynomial.

Finally, for a given rational threshold \(q\ge0\), add the equality \(\alpha=q\) to (LP) and test feasibility. This is equivalent to \(\alpha^*(x)\ge q\): the optimum is attained, and an outcome supporting any factor also supports every smaller nonnegative factor because all deviation values are nonnegative.

Hence both exact optimization with supporting payments and threshold decision admit polynomial-time algorithms.
