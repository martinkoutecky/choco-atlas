Packaged proof task (what the prover saw — nothing else)

Definitions

For \(N\ge4\), set \(n=\lceil(N+4)/2\rceil\) and \(t=n^2(n-2)^2+n\). There are two additive types \(R,C\), of masses \(\mu_R=\lfloor N/2\rfloor/N\) and \(\mu_C=1-\mu_R\), and every item class has supply \(1/N\).
The core classes are the seven indicated groups of positions \(g_{ij}\), for \(2\le j\le n-1\), with base values \(b_{1j}=n(n-2)\), \(b_{1n}=1\), \(b_{j1}=(n-2)(n-1)\), \(b_{jj}=(n-2)(n^2-4n+2)\), \(b_{jn}=(n-2)(n-1)+1\), \(b_{n1}=b_{nj}=(n-2)^2+1\), and \(b_{nn}=(n-2)(n-3)\). Add \(N-n\) auxiliary classes, each valued \(t\) by both types.
For a core class \(g\), let \(v_R(g)=nb_g-\mathbf 1[g=g_{nj}\text{ for some }j<n]+(n-1)\mathbf 1[g=g_{nn}]\), and let \(v_C(g)=nb_g-\mathbf 1[g=g_{jn}\text{ for some }j<n]+(n-1)\mathbf 1[g=g_{nn}]\). An integral bundle is a subset of the item classes.
For \(\theta\in\{R,C\}\), define \(W_\theta\) as the largest \(w\) for which supplies can be assigned as masses \(y_B\ge0\) of integral bundles with \(\sum_B y_B=1\), \(\sum_{B\ni g}y_B=1/N\) for every class \(g\), and \(v_\theta(B)\ge w\) whenever \(y_B>0\).
The decision problem asks whether there are masses \(x_{\theta,B}\ge0\) with \(\sum_Bx_{\theta,B}=\mu_\theta\), \(\sum_{\theta,B\ni g}x_{\theta,B}=1/N\), and \(v_\theta(B)\ge W_\theta\) whenever \(x_{\theta,B}>0\).

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The problem is polynomial-time solvable: every instance in the question is feasible. The key is that each type’s benchmark already permits a distribution over bundles. Those distributions can be scaled by the type masses and combined.

Here is the general argument. Let \(\mathcal G\) be a finite set of classes with supplies \(s_g\), and let the type masses satisfy \(\mu_\theta\ge 0\) and \(\sum_\theta\mu_\theta=1\). Suppose that, for every type \(\theta\), a distribution \(y^\theta_B\) attains its benchmark \(W_\theta\), so that

\( \displaystyle \sum_B y^\theta_B=1,\qquad \sum_{B\ni g}y^\theta_B=s_g,\qquad y^\theta_B>0\Longrightarrow v_\theta(B)\ge W_\theta. \)

Set \(x_{\theta,B}=\mu_\theta y^\theta_B\). Then the required type masses are

\( \displaystyle \sum_Bx_{\theta,B}=\mu_\theta\sum_By^\theta_B=\mu_\theta. \)

For every class \(g\), the combined consumption is

\( \displaystyle \sum_{\theta,B\ni g}x_{\theta,B}=\sum_\theta\mu_\theta\sum_{B\ni g}y^\theta_B=\sum_\theta\mu_\theta s_g=s_g. \)

Finally, \(x_{\theta,B}>0\) implies \(y^\theta_B>0\), hence \(v_\theta(B)\ge W_\theta\). This proves feasibility whenever the benchmark distributions exist.

For completeness, the benchmarks in the stated instance are attained and equal to \(t\), and an explicit feasible allocation follows.

Write \(A=n(n-2)^2+1\), so \(t=nA\). Let \(P_i\) consist of all core classes in row \(i\), and let \(Q_j\) consist of all core classes in column \(j\). Each row and column has total base value \(A\). Indeed, the three possible row sums are

  • \( \displaystyle \sum_{g\in P_1}b_g=n(n-2)^2+1=A. \)
  • For \(2\le i\le n-1\),

\( \displaystyle \sum_{g\in P_i}b_g=(n-2)\bigl(2(n-1)+n^2-4n+2\bigr)+1=A. \)

  • \( \displaystyle \sum_{g\in P_n}b_g=(n-1)\bigl((n-2)^2+1\bigr)+(n-2)(n-3)=A. \)

The three possible column sums are

  • \( \displaystyle \sum_{g\in Q_1}b_g=(n-2)^2(n-1)+(n-2)^2+1=A. \)
  • For \(2\le j\le n-1\),

\( \displaystyle \sum_{g\in Q_j}b_g=(n-2)\bigl(n+n^2-4n+2+n-2\bigr)+1=A. \)

  • \( \displaystyle \sum_{g\in Q_n}b_g=1+(n-2)\bigl((n-2)(n-1)+1\bigr)+(n-2)(n-3)=A. \)

For type \(R\), the perturbations vanish on every row other than the last. On the last row, the \(n-1\) negative perturbations cancel the positive perturbation \(n-1\). Thus \(v_R(P_i)=t\) for every \(i\). The corresponding column argument gives \(v_C(Q_j)=t\) for every \(j\).

Since \(n\le N\), adjoining the \(N-n\) auxiliary singleton bundles gives a partition into exactly \(N\) bundles of value \(t\) for each respective type. Giving every bundle in either partition mass \(1/N\) proves \(W_R\ge t\) and \(W_C\ge t\).

Conversely, either partition shows that the total value of all classes is \(Nt\) for its type. For any distribution satisfying the benchmark supply constraints, additivity therefore gives

\( \displaystyle \sum_B y_Bv_\theta(B)=\sum_{g\in\mathcal G}v_\theta(g)\sum_{B\ni g}y_B=\frac1N\sum_{g\in\mathcal G}v_\theta(g)=t. \)

If every positive-mass bundle has value at least \(w\), this expectation is at least \(w\), because \(\sum_By_B=1\). Consequently \(W_\theta\le t\), proving \(W_R=W_C=t\).

An explicit allocation now assigns mass \(\mu_R/N\) to each row bundle for type \(R\), mass \(\mu_C/N\) to each column bundle for type \(C\), and mass \(\mu_\theta/N\) to each auxiliary singleton for each type \(\theta\). Each type receives its prescribed total mass. Every class is consumed with total mass \((\mu_R+\mu_C)/N=1/N\), and every used bundle has value \(t\) for its recipient type.

Thus the decision algorithm returns YES on every valid input. The discrete impossibility does not obstruct this construction: continuous masses permit combining the two types’ different benchmark partitions.
