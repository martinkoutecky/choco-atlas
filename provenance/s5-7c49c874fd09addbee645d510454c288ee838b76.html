Proposition — class: other

The continuous mirror question, as graded

Given a finite set \(T\) of voter types, rational type masses \(\mu_u>0\), and rational delegation-flow masses \(z_{tu}\) from source type \(t\) to target type \(u\), estimate nonnegative weights \(\varphi_{tu}\) maximizing \(\sum_{t,u} z_{tu}\log\!\left(\frac{\mu_u\varphi_{tu}}{\sum_v\mu_v\varphi_{tv}}\right)\), with \(\sum_u\mu_u\varphi_{tu}=1\) for each source type. For rows with positive delegation mass, the MLE is \(\hat\varphi_{tu}=z_{tu}/(\mu_u\sum_v z_{tv})\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) voter types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; the underlying issue has \(m=2\) alternatives.
The input also contains binary-rational masses \(z_{tu}\geq0\) of observed direct delegations, with \(\sum_u z_{tu}\leq\mu_t\). Delegations within a type are permitted: the society is atomless, so excluding the source individual removes zero mass.
Conditional on delegating, a source of type \(t\) chooses target type \(u\) with probability \(P_{tu}=\mu_u\varphi_{tu}/\sum_v\mu_v\varphi_{tv}\). The unknown weights \(\varphi_{tu}\geq0\) are unrestricted apart from \(\sum_u\mu_u\varphi_{tu}=1\) for every \(t\).
The estimation problem is to compute an exact maximizer of \(\ell(\varphi)=\sum_{t,u}z_{tu}\log P_{tu}\). A zero observation contributes zero even when \(P_{tu}=0\); a positive observation with \(P_{tu}=0\) contributes \(-\infty\). Rows with no observed delegations retain their normalization constraint.
Let \(L\) be the total binary input length. State running times in \(m,\tau,L\).

Can an exact maximizer of this continuous delegation likelihood be computed in polynomial time in \(m,\tau,L\), or is this computation \(\mathrm{NP}\)-hard?

For finite populations partitioned into types, an explicit maximum-likelihood estimator is known up to row scaling, with target availability corrected to exclude the source voter.

Modeling choices made when packaging the task

  • Normalized society masses to sum to one, interpreting them as a distribution over an atomless population.
  • Specified nonnegative delegation-flow masses and bounded each outgoing row total by its source mass, corresponding to at most one direct delegation per voter.
  • Retained delegation within a type; excluding an individual source removes zero mass in the atomless society.
  • Specified the logarithm conventions at zero and retained normalized, unconstrained estimation rows when their observation totals are zero.
  • Interpreted estimation as computing an exact maximizing weight matrix rather than evaluating the potentially irrational optimal log-likelihood.
  • Fixed m=2 for the underlying binary issue; no alternative-dependent parameter enters the estimation objective.

Conclusion

An exact maximizer is computable in polynomial time. The normalization makes each row an independent probability distribution, and its maximum-likelihood estimate is given by its observed relative frequencies. An exact rational maximizer can be computed in \(O(\tau^2 L^3)\) bit operations, independently of \(m\); in the stated problem, \(m=2\).

1. Feasible weights correspond exactly to probability distributions

For every source type \(t\), the prescribed normalization gives
\[ P_{tu}=\frac{\mu_u\varphi_{tu}}{\sum_v\mu_v\varphi_{tv}} =\mu_u\varphi_{tu}. \]
Thus a feasible weight row determines a probability row:
\[ P_{tu}\geq 0,\qquad \sum_uP_{tu}=1. \]

Conversely, because every \(\mu_u\) is strictly positive, any probability row \(p_{tu}\) determines feasible weights by
\[ \varphi_{tu}=\frac{p_{tu}}{\mu_u}. \]
Indeed,
\[ \sum_u\mu_u\varphi_{tu}=\sum_up_{tu}=1. \]

Consequently, the original optimization is equivalent to maximizing
\[ \sum_t\sum_u z_{tu}\log p_{tu} \]
over one independent probability simplex for each row \(t\). Within-type delegation creates no additional restriction under the atomless assumptions in the question.

2. Exact maximizer and proof of optimality

Define the total observed delegation mass in row \(t\) by
\[ r_t=\sum_u z_{tu}. \]
Choose
\[ \varphi^*_{tu}= \begin{cases} \displaystyle\frac{z_{tu}}{\mu_u r_t},&r_t>0,\\[6pt] 1,&r_t=0. \end{cases} \]

These weights are feasible. For \(r_t>0\),
\[ \sum_u\mu_u\varphi^*_{tu} =\frac{\sum_u z_{tu}}{r_t}=1. \]
For \(r_t=0\), feasibility follows from \(\sum_u\mu_u=1\).

We now prove optimality separately for each row.

Rows with positive observed mass

Fix \(t\) with \(r_t>0\), and write
\[ y_u=\frac{z_{tu}}{r_t},\qquad S=\{u:y_u>0\}. \]
The proposed probability row is \(p^*_{tu}=y_u\). Its likelihood is finite because every positive observation receives positive probability.

Let \(q\) be any competing probability row. If \(q_u=0\) for some \(u\in S\), its row likelihood is \(-\infty\), so it cannot improve on \(y\). Otherwise,
\[ \sum_u z_{tu}\log q_u-\sum_u z_{tu}\log y_u =r_t\sum_{u\in S}y_u\log\frac{q_u}{y_u}, \]
where terms with zero observations are omitted according to the stipulated convention.

For \(x>0\), the inequality \(\log x\leq x-1\) holds, with equality exactly when \(x=1\). To verify it, the derivative of \(x-1-\log x\) is \(1-1/x\), which is negative below \(1\) and positive above \(1\); its minimum is therefore its value \(0\) at \(1\).

Applying this inequality gives
\[ \begin{aligned} r_t\sum_{u\in S}y_u\log\frac{q_u}{y_u} &\leq r_t\sum_{u\in S}y_u\left(\frac{q_u}{y_u}-1\right)\\ &=r_t\left(\sum_{u\in S}q_u-1\right)\\ &\leq 0. \end{aligned} \]
The last inequality uses nonnegativity and \(\sum_uq_u=1\). Hence \(y\) is optimal.

Moreover, equality requires \(q_u=y_u\) for every \(u\in S\). These coordinates already sum to \(1\), so all remaining coordinates must be zero. Thus the maximizing probability row, and therefore the maximizing weight row, is unique whenever \(r_t>0\).

Rows with no observed mass

If \(r_t=0\), nonnegativity of the observations implies \(z_{tu}=0\) for every \(u\). The row contributes zero to the likelihood for every feasible row.

Our choice \(\varphi^*_{tu}=1\) satisfies the retained normalization constraint and induces \(P^*_{tu}=\mu_u\).

Since the objective is the sum of independent row objectives, these rowwise choices form a global exact maximizer.

3. Exact representation and running time

All entries of \(\varphi^*\) are rational. Represent the output by binary-encoded integer numerators and positive denominators. Although the inputs may be dyadic rationals, the unrestricted real weights permit rational outputs whose denominators are not powers of two.

The algorithm performs the following operations:

  • Compute the \(\tau\) row sums \(r_t\).
  • For each positive row, output \(z_{tu}/(\mu_u r_t)\).
  • For each zero row, output \(1\) in every coordinate.

Every intermediate rational can be represented with \(O(L)\) bits. To see this for a row sum, use the product of its input denominators as a common denominator. That product has bit length bounded by the sum of their encoded bit lengths, hence \(O(L)\). Each partial sum lies between \(0\) and \(\mu_t\leq1\), so its numerator has the same bound. The output formula involves only a constant number of products of such integers, preserving the \(O(L)\) bound.

There are \(O(\tau^2)\) rational arithmetic operations. Schoolbook integer arithmetic and classical fraction reduction give a conservative bound of
\[ O(\tau^2L^3) \]
bit operations. The output occupies \(O(\tau^2L)\) bits. No logarithm needs to be evaluated to compute the maximizing weights.

Therefore, the distribution-input estimation problem as defined is polynomial-time solvable. This conclusion follows directly from its unrestricted row weights and does not require the finite-population estimator.
