The continuous mirror question, as graded

Given ordered types \(T=\{t_1<\cdots<t_\tau\}\) with positive rational masses \(\mu_i\) summing to \(1\), and a finite sample size \(k\), choose counts \(z_i\in\mathbb{Z}_{\ge 0}\) with \(\sum_i z_i=k\). Each positive-mass type contains enough interchangeable individuals to supply any finite \(z_i\). Let \(F_i=\sum_{j\le i}\mu_j\) and \(G_i(z)=\frac{1}{k}\sum_{j\le i}z_j\). For a specified objective, find a minimizing \(z\) and its value for \(D_{\mathrm{KS}}(z)=\max_i|F_i-G_i(z)|\), \(D_1(z)=\sum_i\mu_i|F_i-G_i(z)|\), or \(D_{\mathrm{CvM}}(z)=\sum_i\mu_i(F_i-G_i(z))^2\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a strictly ordered list \(T=\{t_1<\cdots<t_\tau\}\) of types with positive binary rational masses \(\mu_i\), where \(\sum_i\mu_i=1\). The support size \(\tau\) counts listed types, not possible types; only their order matters.
The input also specifies a binary integer \(k\ge1\) and one objective. Each type supplies arbitrarily many interchangeable individuals; feasible samples are count vectors \(z\in\mathbb Z_{\ge0}^{\tau}\) with \(\sum_i z_i=k\).
Define \(F_i=\sum_{j\le i}\mu_j\) and \(G_i(z)=k^{-1}\sum_{j\le i}z_j\).
The objectives are \(D_{\mathrm{KS}}(z)=\max_i|F_i-G_i(z)|\), \(D_1(z)=\sum_i\mu_i|F_i-G_i(z)|\), and \(D_{\mathrm{CvM}}(z)=\sum_i\mu_i(F_i-G_i(z))^2\).
Find a minimizing count vector and its exact value; any minimizer is acceptable. The threshold decision problem asks whether a feasible vector has objective at most an input binary rational \(b\).
Let \(L\) be the total input bit length, including \(k\) and, for decision, \(b\); counts are output in binary. State running times in \(\tau,k,L\); there is no separate dimension parameter \(m\).

For each of the three objectives, is exact minimization solvable in polynomial time in \(\tau,L\), or is its threshold decision problem NP-hard?

For a strictly ranked finite population of \(n=(2r+1)k\) distinct individuals, selecting the appropriate quantile ranks minimizes all three objectives and takes \(O(n\log n)\) time including sorting. [Source](https://arxiv.org/html/2603.24727v1)
Analytical optima are known for CvM approximation of distributions possessing a density, allowing approximation locations and probabilities to vary; this differs from the finite support and integer counts specified here. [Source](https://link.springer.com/article/10.1007/s00362-022-01356-2)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

All three objectives admit exact minimization in polynomial time in \(\tau,L\). In fact, the same count vector minimizes all three. With ordinary integer arithmetic, it can be computed, together with all three exact objective values, in \(O(\tau L^2)\) bit operations. The dependence on the numerical value of \(k\) is only through its binary encoding.

  • Cumulative counts and the proposed minimizer.

Set \(F_0=0\). For a feasible count vector \(z\), define \(s_0=0\) and \(s_i=\sum_{j\le i}z_j\). Feasibility is equivalent to the conditions
\[ 0=s_0\le s_1\le\cdots\le s_\tau=k, \qquad s_i\in\mathbb Z. \]
Indeed, feasible counts give these inequalities; conversely, such cumulative counts give feasible counts by \(z_i=s_i-s_{i-1}\).

Define the rounding function \(R(x)=\lfloor x+\tfrac12\rfloor\), which rounds half-integers upward. Our proposed cumulative counts and counts are
\[ s_i^*=R(kF_i)\quad(0\le i\le\tau), \qquad z_i^*=s_i^*-s_{i-1}^*. \]

The function \(R\) is nondecreasing: if \(x\le y\), then \(x+\tfrac12\le y+\tfrac12\), and taking floors preserves this inequality. Since the cumulative masses are increasing, the \(s_i^*\) are nondecreasing. Moreover, \(s_0^*=R(0)=0\) and \(s_\tau^*=R(k)=k\). Thus \(z^*\) is feasible. The availability of arbitrarily many individuals of each type ensures that no additional capacity constraint needs checking.

  • Proof of simultaneous optimality.

For every real \(x\), \(R(x)\) is a nearest integer to \(x\). To verify this, write \(q=R(x)\). Then \(q-\tfrac12\le x<q+\tfrac12\), so \(|x-q|\le\tfrac12\). Every integer \(m\le q-1\) satisfies \(x-m\ge\tfrac12\), and every integer \(m\ge q+1\) satisfies \(m-x>\tfrac12\). Hence \(|x-q|\le |x-m|\) for every integer \(m\).

Apply this fact to \(x=kF_i\). For any feasible vector \(z\), its cumulative count \(s_i\) is an integer. Therefore, at every support point,
\[ \left|F_i-\frac{s_i^*}{k}\right| =\frac{|kF_i-R(kF_i)|}{k} \le\frac{|kF_i-s_i|}{k} =\left|F_i-\frac{s_i}{k}\right|. \]

Taking the maximum over \(i\) proves \(D_{\mathrm{KS}}(z^*)\le D_{\mathrm{KS}}(z)\).

Multiplying each inequality by the positive weight \(\mu_i\) and summing proves \(D_1(z^*)\le D_1(z)\).

Finally, the quantities being compared are nonnegative, so squaring preserves their inequalities. Multiplying by \(\mu_i\) and summing proves \(D_{\mathrm{CvM}}(z^*)\le D_{\mathrm{CvM}}(z)\).

These comparisons hold for every feasible \(z\), completing the optimality proof. Equivalently, if
\[ \delta_i=\min_{m\in\mathbb Z}|kF_i-m|, \]
the exact minimum values are
\[ D_{\mathrm{KS}}^*=\frac{\max_i\delta_i}{k}, \qquad D_1^*=\frac{\sum_i\mu_i\delta_i}{k}, \qquad D_{\mathrm{CvM}}^*=\frac{\sum_i\mu_i\delta_i^2}{k^2}. \]

  • Exact arithmetic and running time.

Write each input mass as \(\mu_i=a_i/d_i\), with positive binary integers \(a_i,d_i\). Reduction to lowest terms is unnecessary. Define
\[ Q=\prod_{i=1}^{\tau}d_i,\qquad w_i=a_i(Q/d_i),\qquad M_i=\sum_{j\le i}w_j. \]
Then \(\mu_i=w_i/Q\), \(F_i=M_i/Q\), and \(M_\tau=Q\).

Compute the cumulative counts using integer division:
\[ s_i^*=\left\lfloor\frac{2kM_i+Q}{2Q}\right\rfloor. \]
Taking successive differences outputs \(z^*\) in binary. Next compute the nonnegative integers
\[ e_i=|kM_i-Qs_i^*|. \]
Since \(|F_i-s_i^*/k|=e_i/(kQ)\), the exact optimum values, as possibly unreduced rational numbers, are
\[ D_{\mathrm{KS}}^*=\frac{\max_i e_i}{kQ}, \qquad D_1^*=\frac{\sum_i w_i e_i}{kQ^2}, \qquad D_{\mathrm{CvM}}^*=\frac{\sum_i w_i e_i^2}{k^2Q^3}. \]

To check the bit complexity, the sum of the input denominator bit lengths is at most \(L\); consequently \(Q\) has \(O(L)\) bits. Also \(0\le w_i,M_i\le Q\), \(0\le s_i^*\le k\), and \(0\le e_i\le Q/2\). In particular,
\[ \sum_i w_i e_i\le Q^2/2, \qquad \sum_i w_i e_i^2\le Q^3/4, \]
because \(\sum_i w_i=Q\). All intermediate integers and output fractions therefore have \(O(L)\) bits, including the factors involving \(k\).

Constructing these quantities requires \(O(\tau)\) additions, multiplications, comparisons, and integer divisions. Schoolbook multiplication and long division on \(O(L)\)-bit integers take \(O(L^2)\) bit operations each. Thus the total running time is \(O(\tau L^2)\), including binary count output. There is no loop of length \(k\).

  • Threshold decisions and the finite-population connection.

For any of the three objectives, compute its minimum as \(N/D\), with \(D>0\). If the threshold is \(b=u/v\), with \(v>0\), answer yes exactly when \(Nv\le uD\). This comparison is exact and uses \(O(L)\)-bit integers. Hence all three threshold decision problems belong to \(\mathrm P\); under polynomial-time many-one reductions, NP-hardness would imply \(\mathrm P=\mathrm{NP}\).

The construction also recovers the quantile ranks in the stated uniform finite-population case. Suppose \(\tau=n=(2r+1)k\) and \(\mu_i=1/n\). The cumulative count becomes \(s_i^*=\lfloor ki/n+\tfrac12\rfloor\). Its \(j\)-th increment occurs at rank
\[ i_j=\left\lceil\frac{n(j-\tfrac12)}{k}\right\rceil =(2r+1)j-r,\qquad 1\le j\le k. \]
These ranks are distinct, so the resulting counts are zero or one and specify a feasible selection of distinct individuals. Thus this proof recovers the quantile selection described in [Adversarial Selection](https://arxiv.org/html/2603.24727v1), while also covering the arbitrary rational masses and unrestricted multiplicities in the present task.
