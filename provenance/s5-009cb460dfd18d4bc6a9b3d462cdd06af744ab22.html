The continuous mirror question, as graded

Given a finite type set \(T\), rational population masses \(\mu_t\), and symmetric rational link costs \(c_{tu}\) and \(c_{tr}\), define \(F(x)=\sum_{t:x_t>0}x_t\min\bigl(\{c_{tr}\}\cup\{c_{tu}:x_u>0\}\bigr)\) for coalition masses \(x\in[0,\mu]^T\). Decide whether \(F\) has diminishing returns: for every \(x\le y\), type \(i\in T\), and \(\delta\ge0\) with \(y+\delta e_i\le\mu\), does \(F(x+\delta e_i)-F(x)\ge F(y+\delta e_i)-F(y)\) hold?

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\); \(\tau\) is the support size, not the number of possible types. Masses need not sum to one.
A distinguished source \(r\notin T\) is always available. Input costs \(c_{tu}=c_{ut}\) and \(c_{tr}\) are finite nonnegative binary rationals. The diagonal \(c_{tt}\) is an input cost for linking distinct individuals of the same type, with no requirement that it vanish.
For real coalition masses \(x\in\prod_{t\in T}[0,\mu_t]\), define \(F(0)=0\) and \(F(x)=\sum_{t:x_t>0}x_t\min\bigl(\{c_{tr}\}\cup\{c_{tu}:u\in T,\ x_u>0\}\bigr)\). The minimum includes \(u=t\); ties require no selection rule.
Say that \(F\) has diminishing returns if, for every real \(x\le y\), \(i\in T\), and real \(\delta\ge0\) with \(y+\delta e_i\le\mu\), one has \(F(x+\delta e_i)-F(x)\ge F(y+\delta e_i)-F(y)\), where inequalities are coordinatewise and \(e_i\) is the coordinate unit vector.
Let \(L\) be the total binary input length; state running times in \(\tau\) and \(L\). There is no separate parameter \(m\) in this model.

Exact characterization

The recognition problem is in \(\mathrm{P}\). In fact, diminishing returns holds precisely when the function is additive.

For each \(t\in T\), define
\(b_t:=\min\{c_{tr},c_{tt}\}\).

Theorem. The following statements are equivalent:

  • \(F\) has diminishing returns as defined in the question.
  • For every pair of distinct types \(t,u\in T\),

\(c_{tu}\ge \max\{b_t,b_u\}\).

  • For every feasible \(x\),

\(F(x)=\sum_{t\in T}b_t x_t\).

This characterization applies to arbitrary positive masses and arbitrary nonnegative input diagonals.

Proof of necessity

Suppose condition 2 fails. By symmetry of the costs, we can label a failing pair \(t,u\) so that
\(c_{tu}<b_t\).

Set
\(h:=\mu_u/2>0\), \(a:=\min\{b_u,c_{tu}\}\), and choose
\(x:=\mu_t e_t\), \(y:=x+h e_u\), and \(\delta:=h\).

These choices satisfy \(x\le y\) and \(y+\delta e_u\le\mu\): the mass of type \(t\) is \(\mu_t\), and the mass of type \(u\) after the second increment is \(2h=\mu_u\).

The support of \(x\) is \(\{t\}\), so
\(F(x)=\mu_t b_t\).

Both \(y=x+\delta e_u\) and \(y+\delta e_u\) have support \(\{t,u\}\). On this support, type \(t\)'s minimum cost is
\(\min\{c_{tr},c_{tt},c_{tu}\}=c_{tu}\),
because \(c_{tu}<b_t\). Type \(u\)'s minimum cost is
\(\min\{c_{ur},c_{uu},c_{ut}\}=a\).
Consequently,

\(F(x+\delta e_u)=F(y)=\mu_t c_{tu}+ha\),

\(F(y+\delta e_u)=\mu_t c_{tu}+2ha\).

Thus the two increments are

\(F(x+\delta e_u)-F(x)=ha-\mu_t(b_t-c_{tu})\),

\(F(y+\delta e_u)-F(y)=ha\).

Since \(\mu_t>0\) and \(b_t-c_{tu}>0\), the first increment is strictly smaller than the second. This violates diminishing returns.

Therefore condition 1 implies condition 2. The violation uses only two types and rational coalition masses; no limiting argument is needed.

Proof of sufficiency

Assume condition 2. Fix a feasible \(x\) and an active type \(t\), meaning \(x_t>0\).

The source cost and diagonal cost are both at least \(b_t\), and their minimum equals \(b_t\). Every other active type \(u\ne t\) satisfies
\(c_{tu}\ge\max\{b_t,b_u\}\ge b_t\).
Hence

\(\min\bigl(\{c_{tr}\}\cup\{c_{tu}:x_u>0\}\bigr)=b_t\).

Substitution into the definition of \(F\) gives
\(F(x)=\sum_{t:x_t>0}x_t b_t=\sum_{t\in T}x_t b_t\).
This also holds at \(x=0\), by the specified convention. Thus condition 2 implies condition 3.

Finally, under condition 3, every feasible coordinate increment satisfies

\(F(x+\delta e_i)-F(x)=\delta b_i=F(y+\delta e_i)-F(y)\).

Diminishing returns therefore holds with equality, proving condition 3 implies condition 1.

Recognition algorithm and running time

Compute each \(b_t=\min\{c_{tr},c_{tt}\}\). Then examine every unordered pair of distinct types and reject if
\(c_{tu}<\max\{b_t,b_u\}\).
Accept if no pair fails.

The theorem proves correctness. For \(\tau=1\), there are no pairs to examine, and acceptance is correct.

The algorithm uses \(O(\tau^2)\) exact rational comparisons. With binary numerator–denominator encoding, a comparison uses integer cross-multiplication on integers of at most \(L\) bits. Schoolbook multiplication gives the conservative total bound
\(O(\tau^2L^2)\) bit operations.

The essential feature is the quantification over every \(x\le y\), including \(x_i=0<y_i\). Activating a type can lower the cost of existing mass; the next equal increment has no such saving. The necessity proof shows that any such saving contradicts the stated diminishing-returns condition.
