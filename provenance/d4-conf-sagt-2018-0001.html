The continuous mirror question, as graded

Given a finite type set \(T\), masses \(\mu_t\) with \(\sum_t\mu_t=1\), aggregate demands \(w_t\in\mathbb{Z}_{>0}\), atomless valuation oracles \(v_t\) on a cake \(X\) with \(v_t(X)=D=\sum_t w_t\), and type-level cut/evaluation access, compute measurable allocation densities \(a_t:X\to[0,1]\) satisfying \(\sum_t a_t(x)=1\) and \(\int_X a_t\,dv_t\ge w_t\) for every \(t\), while determining the worst-case number of type queries; in particular, whether \(2(\tau-1)\lceil\log_2D\rceil\) queries suffice and whether \(\Omega(\tau\log D)\) are necessary.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of its \(\tau\ge2\) types with positive masses \(\mu_t\), each a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a binary-encoded aggregate demand \(w_t\in\mathbb Z_{>0}\); set \(D=\sum_t w_t>\tau\). These are total type demands, so they are not multiplied by \(\mu_t\).
The cake is a known Lebesgue-measurable \(X\subseteq\mathbb R^m\), with \(m\ge1\) and \(0<\lambda(X)<\infty\). Each unknown valuation \(v_t\) is a nonnegative finite measure absolutely continuous with respect to \(\lambda\), with \(v_t(X)=D\).
For a measurable piece \(I\subseteq X\), an evaluation query returns \(v_t(I)\). A moving knife is a measurable-set-valued mapping \(f:[0,\lambda(I)]\to2^I\) with \(f(s)\subseteq f(u)\) for \(s\le u\) and \(\lambda(f(s))=s\).
An absolute cut query returns any \(s\) satisfying \(v_t(f(s))=\alpha\), for \(\alpha\ge0\), or reports impossibility. A proportional cut query returns any \(s\) satisfying \(v_t(f(s))=r v_t(I)\), for rational \(r\in[0,1]\). Each evaluation, absolute cut, or proportional cut counts as one type query; arbitrary valid cut answers must be tolerated.
Compute a finite symbolic description of measurable densities \(a_t:X\to[0,1]\) satisfying \(\sum_t a_t(x)=1\) throughout \(X\) and \(\int_X a_t\,dv_t\ge w_t\) for every \(t\). Fractional densities are permitted, and no connectedness condition is imposed.
Use deterministic protocols with exact oracle answers; oracle calls, arithmetic, comparisons, and symbolic set operations have unit cost. Let \(L\) be the bit length of the finite numerical input; state bounds in \(m,\tau,L,D\). Hardness reductions must provide polynomial-time simulable type oracles.
Is this density-allocation search problem solvable in polynomial time in \(m,\tau,L\) in this oracle model, or is it NP-hard?
What is its worst-case type-query complexity: do \(2(\tau-1)\lceil\log_2D\rceil\) queries suffice, and are \(\Omega(\tau\log D)\) queries necessary?
For finitely many players receiving disjoint measurable pieces, the verified [algorithmic bound](https://hpi.de/friedrich/docs/publications/2020/TALG.pdf) is \(2(n-1)\lceil\log_2D\rceil\) under the proportional-cut convention, for \(2\le n<D\); the same source proves a deterministic worst-case lower bound of \(\Omega(n\log D)\), even with generalized queries.
Those results require disjoint pieces rather than fractional allocation densities; no result settling this exact density-output problem was identified in the search.

  • Specified the cake domain and generalized moving-knife access using the measurable finite-dimensional cake model.
  • Strengthened unspecified atomless valuations to nonnegative finite valuations absolutely continuous with respect to Lebesgue measure, following the discrete definitions; strict positivity is not required.
  • Carried over the anchor's conditions of at least two participants and total integer demand strictly exceeding their number, with support size replacing participant count.
  • Interpreted w_t as the supplied aggregate type demand, independent of the society mass; no additional mass factor enters feasibility.
  • Counted proportional cuts as single queries to make the anchor's exact numerical bound comparable; also specified evaluation and absolute-cut queries.
  • Allowed arbitrary valid generalized cut answers and required deterministic protocols, matching the lower-bound setting.
  • Required finite symbolic output descriptions while retaining genuinely fractional measurable densities.
  • Specified exact unit-cost oracle computation and polynomial-time simulable oracles for hardness reductions, because arbitrary valuation oracles do not supply an ordinary finite Turing input.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Resolution

The problem is polynomial-time solvable, with exactly zero type queries in the worst case.

Fractional densities permit a valuation-independent solution for every instance. This applies throughout the stated parameter range, rather than only to a degenerate case.

Construction and proof

Compute \(D=\sum_{t\in T}w_t\), and output the constant functions

\(a_t(x)=w_t/D\quad\text{for every }t\in T\text{ and }x\in X.\)

These formulas are finite symbolic descriptions of measurable functions.

Because all demands are positive and \(\tau\ge2\), we have \(0<w_t<D\). Thus each \(a_t\) takes values in \([0,1]\). At every point \(x\in X\),

\(\sum_{t\in T}a_t(x)=D^{-1}\sum_{t\in T}w_t=1.\)

For every admissible valuation \(v_t\), integration of a constant gives

\(\int_X a_t\,dv_t=(w_t/D)v_t(X)=(w_t/D)D=w_t.\)

Hence every demand is satisfied exactly. The construction uses the aggregate demands as given; the masses \(\mu_t\) do not enter the allocation.

No oracle is queried, so arbitrary valid cut answers have no effect on correctness.

Computational and query complexity

Computing \(D\) takes \(\tau-1\) additions. Recording the \(\tau\) rational constants takes \(O(\tau)\) further operations. The symbolic output can share the denominator \(D\).

Thus the protocol uses \(O(\tau)\) arithmetic and output operations, independently of \(m\) and the numerical magnitude of \(D\). Including input reading gives a polynomial bound in \(m,\tau,L\).

For an explicit encoding bound, let \(b\) be the maximum bit length of a demand. Since \(D<\tau\,2^b\), its bit length is at most \(b+\lceil\log_2\tau\rceil+1\). Even writing each numerator-denominator pair separately therefore uses \(O(L+\tau\log D)\) bits, which is polynomial in the input parameters.

Consequently:

  • \(2(\tau-1)\lceil\log_2D\rceil\) queries suffice, because zero queries suffice.
  • An \(\Omega(\tau\log D)\) query lower bound is false for this density-output problem.
  • Its optimal worst-case type-query complexity is exactly zero, since query counts are nonnegative.

The polynomial-time construction settles the computational alternative. Any NP-hardness reduction with polynomial-time simulable oracles and polynomial-time solution decoding would, when composed with this construction, imply \(\mathrm{P}=\mathrm{NP}\).

A structural explanation

Proven claim. Any fixed feasible density tuple that succeeds for every admissible valuation tuple must satisfy \(a_t=w_t/D\) almost everywhere for each type.

To prove this, put \(p_t=w_t/D\). Suppose \(E=\{x\in X:a_t(x)<p_t\}\) has positive Lebesgue measure. Since

\(E=\bigcup_{k\ge1}\{x\in X:a_t(x)\le p_t-1/k\},\)

some measurable set \(E_k=\{x\in X:a_t(x)\le p_t-1/k\}\) has positive measure. Define, for measurable \(B\),

\(v_t(B)=D\,\lambda(B\cap E_k)/\lambda(E_k).\)

This is a nonnegative finite measure, absolutely continuous with respect to \(\lambda\), with \(v_t(X)=D\). However,

\(\int_X a_t\,dv_t\le D(p_t-1/k)<w_t,\)

contradicting universal success. Thus \(a_t\ge p_t\) almost everywhere.

There are finitely many types, so these inequalities hold simultaneously outside one null set. There, \(\sum_t a_t=\sum_t p_t=1\); the nonnegative differences \(a_t-p_t\) must therefore all vanish. This proves the claim.

The constant allocation is consequently the unique universal allocation up to null sets.

Why the disjoint-piece lower bound does not transfer

The cited [Cseh–Fleiner result](https://hpi.de/friedrich/docs/publications/2020/TALG.pdf) concerns allocations by disjoint measurable pieces. Such an allocation has indicator densities \(a_t=\mathbf{1}_{I_t}\).

Here the successful constants satisfy \(0<a_t<1\) everywhere, so they are not indicator densities. Allowing fractional output changes the admissible solutions and removes the need to learn the valuations. The disjoint-piece lower bound therefore does not establish a lower bound for the stated task.
