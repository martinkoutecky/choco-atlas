The continuous mirror question, as graded

Given a finite set \(T\) of ranking types over candidates \(C\) and rational societies \(\mu,\nu\in\Delta(T)\), decide whether the set \(\{\lambda\in\Delta(T):D(\lambda,\mu)=D(\lambda,\nu)\}\) has nonempty relative interior in \(\Delta(T)\), where \(D(\lambda,\mu)=\frac12\sum_{t\in T}|\lambda_t-\mu_t|\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq 1\) candidates, and let \(T\) be an explicitly listed nonempty set of distinct strict complete rankings of \(C\); put \(k=|T|\).
A society is given by its support: the list of types with positive mass, each mass a binary rational. Let \(\tau\) be the larger support size of the two input societies, not the number of possible rankings.
The inputs are \(\mu,\nu\in\Delta(T)\cap\mathbb{Q}^{T}\), where \(\Delta(T)=\{\lambda\in\mathbb{R}_{\geq 0}^{T}:\sum_{t\in T}\lambda_t=1\}\). Unlisted masses are zero; types in \(T\) may have zero mass in both inputs, and \(\mu=\nu\) is allowed.
Define \(D(\lambda,\eta)=\frac12\sum_{t\in T}|\lambda_t-\eta_t|\) and \(B(\mu,\nu)=\{\lambda\in\Delta(T):D(\lambda,\mu)=D(\lambda,\nu)\}\).
Here nonempty relative interior means that \(B(\mu,\nu)\) contains a nonempty open subset of \(\Delta(T)\) in its inherited topology. Let \(L\) be the total input bit length; state running times in \(m,\tau,k,L\).

Is deciding whether \(B(\mu,\nu)\) has nonempty relative interior solvable in polynomial time, or is it NP-hard?

The ambient analogue, asking whether the \(\ell^1\) bisector of two nonnegative rational vectors contains an open ball in \(\mathbb{R}^{k}\), is NP-complete ([revised source](https://arxiv.org/pdf/1610.01900v2)).
An [earlier manuscript](https://www.cs.auckland.ac.nz/~mcw/Research/Outputs/HaWi2016b.pdf) also claimed hardness for a simplex analogue, but its displayed reduction does not establish this restricted-interior problem; the revised statement omits that claim. No verified classification of the exact problem above was located.

Modeling choices made when packaging the task

  • Interpreted relative interior in Delta(T) as interior in the topology of the ambient simplex, rather than interior relative to the bisector's own affine hull.
  • Allowed real distributions as queried points lambda, while retaining binary rational input societies.
  • Kept T as an explicitly supplied ambient type set, including types absent from both supports; introduced k=|T| separately from the support parameter tau.
  • Used strict complete rankings and a nonempty candidate and type domain; retained identical input societies because the anchor imposes no distinctness condition.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is \(\mathrm{NP}\)-complete. Hardness holds even when both societies have full support, every coordinate differs between them, and all masses are dyadic rationals.

If \(\mu=\nu\), the answer is trivially yes. The proof below handles the nontrivial case \(\mu\ne\nu\) and uses interior in precisely the topology specified in the question.

1. An exact criterion for simplex interior

Index the explicitly listed types by \(\{1,\ldots,k\}\). Define

\( d_i=\nu_i-\mu_i,\qquad a_i=\min(\mu_i,\nu_i),\qquad b_i=\max(\mu_i,\nu_i). \)

Let \( I=\{i:d_i\ne0\},\quad E=\{i:d_i=0\},\quad Z=\{i\in I:a_i=0\}. \)

Since both societies have total mass one, \(\sum_i d_i=0\).

Lemma. Suppose \(\mu\ne\nu\). Then \(B(\mu,\nu)\) contains a nonempty relatively open subset of the simplex if and only if there exists \(H\subseteq I\) satisfying all four conditions:

  • \(Z\subseteq H\);
  • \(\sum_{i\in H}d_i=0\);
  • \(\sum_{i\in H}b_i<1\);
  • \(H\cup E\ne\varnothing\).

Necessity

Put \( F(x)=\sum_{i=1}^k\bigl(|x_i-\mu_i|-|x_i-\nu_i|\bigr). \)
Thus \(B(\mu,\nu)=\{x\in\Delta(T):F(x)=0\}\).

Suppose this set contains a nonempty relatively open subset \(U\). Because \(\mu\ne\nu\), necessarily \(k\ge2\). Write \( A=\{x\in\mathbb R^k:\sum_i x_i=1\}. \)

The subset of the simplex with every coordinate positive is dense in the simplex: for any simplex point, taking a sufficiently small convex combination with \((1/k,\ldots,1/k)\) gives such a point. Consequently, \(U\) contains a nonempty open subset of \(A\) consisting of positive points.

For each \(i\in I\), the equations \(x_i=\mu_i\) and \(x_i=\nu_i\) define proper hyperplanes in \(A\). A finite union of proper hyperplanes cannot contain an open subset of \(A\). We can therefore choose \(x\in U\) with positive coordinates that avoids all these hyperplanes.

On a sufficiently small neighborhood of \(x\) in \(A\), the function \(F\) is affine and identically zero. Let \(g_i\) be its coefficient on coordinate \(i\). Varying in each direction \(e_i-e_j\) shows that \(g_i=g_j\) for all \(i,j\).

The coefficients have the following possibilities:

  • If \(d_i>0\), then \(g_i=2\) when \(a_i<x_i<b_i\), and \(g_i=0\) otherwise.
  • If \(d_i<0\), then \(g_i=-2\) when \(a_i<x_i<b_i\), and \(g_i=0\) otherwise.
  • If \(i\in E\), the corresponding summand is identically zero, so \(g_i=0\).

Because \(\sum_i d_i=0\) and \(d\ne0\), there are both positive and negative entries of \(d\). Thus the common coefficient belongs to both \(\{0,2\}\) and \(\{0,-2\}\), forcing it to be zero.

It follows that, for every \(i\in I\), either \(x_i<a_i\) or \(x_i>b_i\). Define \( H=\{i\in I:x_i>b_i\}. \)

If \(a_i=0\), positivity prevents \(x_i<a_i\), proving \(Z\subseteq H\).

For \(i\in I\), direct calculation gives

\( |x_i-\mu_i|-|x_i-\nu_i| = \begin{cases} -d_i,&x_i<a_i,\\ d_i,&x_i>b_i. \end{cases} \)

Hence \( 0=F(x)=\sum_{i\in H}d_i-\sum_{i\in I\setminus H}d_i =2\sum_{i\in H}d_i, \)
which proves condition 2.

If \(H\ne\varnothing\), strict inequalities imply \( \sum_{i\in H}b_i<\sum_{i\in H}x_i\le1. \)
If \(H=\varnothing\), condition 3 holds because the empty sum is zero.

Finally, suppose \(H=E=\varnothing\). Then every coordinate satisfies \(x_i<a_i\), so \( 1=\sum_i x_i<\sum_i a_i=1-D(\mu,\nu)<1, \)
a contradiction. Here the identity follows from \( a_i=(\mu_i+\nu_i-|\mu_i-\nu_i|)/2 \),
and \(D(\mu,\nu)>0\) because the societies differ. This proves condition 4.

Sufficiency

Suppose \(H\) satisfies the four conditions. Choose \(\varepsilon>0\) sufficiently small that

\( k\varepsilon<1-\sum_{i\in H}b_i \)

and \(\varepsilon<a_i\) for every \(i\in I\setminus H\). Such a choice exists because condition 1 ensures all those \(a_i\) are positive.

Define \( y_i= \begin{cases} b_i+\varepsilon,&i\in H,\\ \varepsilon,&i\notin H. \end{cases} \)
Then \(\sum_i y_i<1\).

Choose \(j\in H\cup E\), which exists by condition 4, and set \( x=y+\bigl(1-\sum_i y_i\bigr)e_j. \)

This point belongs to the simplex, has positive coordinates, and satisfies \(x_i>b_i\) on \(H\) and \(x_i<a_i\) on \(I\setminus H\). Adding the remaining mass at \(j\) preserves these inequalities.

They define a nonempty relatively open subset of the simplex. Throughout that subset, \( F(x)=2\sum_{i\in H}d_i=0. \)
Thus the subset lies in \(B(\mu,\nu)\), completing the lemma.

2. Membership in \(\mathrm{NP}\)

For \(\mu\ne\nu\), a certificate is the subset \(H\subseteq I\). The lemma reduces verification to set inclusion, one rational equality, one rational inequality, and a nonemptiness check.

Every coordinate in \(I\) lies in the union of the input supports. Consequently, \( |I|\le\min(k,2\tau). \)
Types absent from both supports belong to \(E\); they are fully accounted for by condition 4.

Exact rational arithmetic has polynomial bit complexity here. For example, using the product of all input denominators as a common denominator produces integers with \(O(L)\) bits. There are \(O(L)\) arithmetic operations to verify the conditions, each implementable in \(O(L^2)\) bit operations. Thus a conservative verification bound, including preprocessing, is \( O\bigl(km\log(m+1)+L^3\bigr). \)

The case \(\mu=\nu\) is accepted directly. Therefore the problem belongs to \(\mathrm{NP}\).

3. A reduction from PARTITION

Use the standard \(\mathrm{NP}\)-completeness of PARTITION: given positive binary integers \(a_1,\ldots,a_n\), decide whether some subset has half their total sum. This is one of the classical problems covered by [Karp’s NP-completeness theorem](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9). Restricting to positive integers preserves hardness: zero entries can be discarded, and an all-zero instance can be replaced by the fixed yes-instance \((1,1)\).

Let \( A=\sum_{i=1}^n a_i,\qquad k=n+2. \)

Define the nonzero integer vector \( (w_1,\ldots,w_k)=(2a_1,\ldots,2a_n,-A,-A). \)
Its entries sum to zero.

Let \(q\) be the least power of two satisfying \(q\ge k\), and let \(R\) be the least power of two satisfying \(R>4A\). Define

\( \mu_i= \begin{cases} 1/q,&1\le i<k,\\ (q-k+1)/q,&i=k, \end{cases} \qquad \nu_i=\mu_i+\frac{w_i}{qR}. \)

Both vectors sum to one. Every coordinate of \(\mu\) is at least \(1/q\), and \(w_i\ge-A\), so \( \nu_i\ge\frac1q-\frac{A}{qR}>\frac{3}{4q}>0. \)

Thus both societies have full support, and \(\tau=k\). Every coordinate differs because every \(w_i\) is nonzero. All masses are dyadic rationals.

Every proper upper set satisfies the mass bound

For these societies, \( D(\mu,\nu)=\frac12\sum_i\frac{|w_i|}{qR} =\frac{2A}{qR}<\frac1{2q}. \)

The identity \(\sum_i b_i=1+D(\mu,\nu)\) follows directly from the definition of \(b_i\). Also, every \(b_i\ge\mu_i\ge1/q\). Therefore, for every proper subset \(H\subsetneq\{1,\ldots,k\}\), \( \sum_{i\in H}b_i \le1+D(\mu,\nu)-\frac1q <1-\frac1{2q}<1. \)

For the full set, however, \(\sum_i b_i=1+D(\mu,\nu)>1\).

Here \(I=\{1,\ldots,k\}\) and \(E=Z=\varnothing\). The lemma consequently says that the constructed bisector has nonempty relative interior exactly when there exists a nonempty proper subset \(H\) with \( \sum_{i\in H}w_i=0. \)

Zero-sum subsets encode partitions

Given \(H\), put \(S=H\cap\{1,\ldots,n\}\), and let \(r\in\{0,1,2\}\) count how many of the two final coordinates belong to \(H\). Its zero-sum equation is \( 2\sum_{i\in S}a_i=rA. \)

There are three cases:

  • If \(r=0\), positivity of the \(a_i\) forces \(S=\varnothing\), so \(H=\varnothing\).
  • If \(r=2\), then \(\sum_{i\in S}a_i=A\). Positivity forces \(S=\{1,\ldots,n\}\), so \(H\) is the full set.
  • If \(r=1\), then \(\sum_{i\in S}a_i=A/2\), exactly a solution to PARTITION.

Conversely, any subset solving PARTITION, together with exactly one final coordinate, gives a nonempty proper zero-sum subset \(H\).

The constructed simplex-interior instance is therefore a yes-instance if and only if the original PARTITION instance is a yes-instance.

4. Rankings, encoding size, and running times

To realize the construction with strict complete rankings, take \(m=k\) candidates. For each \(i\), let type \(i\) rank candidate \(i\) first and the remaining candidates in increasing order. These are \(k\) distinct rankings, explicitly listed.

Since \(q<2k\) and \(R\le8A\), every mass uses \(O(\log k+\log A)\) bits. The constructed input length satisfies \( L=O\bigl(km\log(m+1)+k(\log k+\log A)\bigr), \)
with \(m=\tau=k=n+2\). Construction therefore takes polynomial time in the original binary input length.

For general inputs, enumerating the certificates from the lemma gives the deterministic bound \( O\bigl(km\log(m+1)+2^{\min(k,2\tau)}L^3\bigr). \)
In particular, the problem is polynomial-time solvable for fixed support bound \(\tau\), without enumerating all possible rankings.

The polynomial reduction and membership proof establish \(\mathrm{NP}\)-completeness for the exact restricted-interior problem posed.
