The anchor (named result in the paper)

Theorem 14 — class: hardness

The continuous mirror question, as graded

Continuous-EJR-Verification: given candidates \(C\), committee size \(k\), an explicit finite support \(T\subseteq 2^C\) with rational masses \(\mu_A\) summing to \(1\), and an integral committee \(W\subseteq C\) of size \(k\), decide whether for every \(1\le \ell\le k\) and every \(S\subseteq C\) with \(|S|=\ell\), \(\sum_{A\in T:S\subseteq A,\ |A\cap W|<\ell}\mu_A<\ell/k\).

Packaged proof task (what the prover saw — nothing else)

A Continuous-EJR-Verification instance consists of a candidate set \(C\), a committee size \(k\), an explicitly listed finite set \(T\subseteq 2^C\) of approval types with rational masses \((\mu_A)_{A\in T}\) summing to \(1\), and a size-\(k\) committee \(W\subseteq C\). It is a yes-instance if, for every \(1\le \ell\le k\) and every \(S\subseteq C\) with \(|S|=\ell\),
\[ \sum_{A\in T: S\subseteq A,\ |A\cap W|<\ell}\mu_A<\ell/k. \]

Target. Is Continuous-EJR-Verification solvable in polynomial time, or is it NP-hard?

For finite approval profiles, deciding whether a given committee provides extended justified representation is coNP-complete. No result for the rational-mass type-distribution formulation is assumed here.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The rational-mass formulation is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions. Thus it is polynomial-time solvable if and only if \(\mathrm{P}=\mathrm{NP}\). It is also \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. Under many-one reductions, calling it \(\mathrm{NP}\)-hard would require \(\mathrm{NP}=\mathrm{coNP}\).

Here is a complete proof, using the finite-profile hardness result supplied in the question.

Membership in \(\mathrm{coNP}\). Assume \(k\geq 1\), as required for the defining fractions. A certificate that the instance is a no-instance consists of an integer \(\ell\) and a candidate subset \(S\) satisfying
\[ 1\leq \ell\leq k,\qquad |S|=\ell,\qquad \sum_{\substack{A\in T:\ S\subseteq A\\ |A\cap W|<\ell}}\mu_A\geq \frac{\ell}{k}. \]
This certificate has polynomial length because \(k\leq |C|\).

The verifier scans all explicitly listed approval types, tests the two conditions selecting terms, and compares the resulting rational sum with \(\ell/k\). This comparison can be performed exactly in polynomial time. Specifically, write each mass as \(\mu_A=p_A/q_A\), with \(q_A>0\), and let \(D=\prod_{A\in T}q_A\). The binary length of \(D\) is at most the sum of the binary lengths of the denominators. The required comparison is equivalent to the integer comparison
\[ k\sum_{\substack{A\in T:\ S\subseteq A\\ |A\cap W|<\ell}} p_A(D/q_A)\geq \ell D. \]
All integers involved have polynomial binary length, and there are polynomially many arithmetic operations. Consequently, the complement belongs to \(\mathrm{NP}\), so Continuous-EJR-Verification belongs to \(\mathrm{coNP}\).

Reduction from finite-profile verification. Consider a finite approval profile with voters \(N=\{1,\ldots,n\}\), where \(n\geq 1\), approval sets \(A_i\subseteq C\), and a size-\(k\) committee \(W\). For each distinct approval set \(A\), define
\[ n_A=|\{i\in N:A_i=A\}|,\qquad T=\{A_i:i\in N\},\qquad \mu_A=\frac{n_A}{n}. \]
These masses are nonnegative and sum to \(1\). There are at most \(n\) distinct types, and each mass has an encoding of length \(O(\log n)\). Thus the constructed instance has polynomial size and is computable in polynomial time.

We verify that the reduction preserves the answer. In a finite profile, a violation of EJR consists of an integer \(\ell\in\{1,\ldots,k\}\) and a group \(X\subseteq N\) such that
\[ |X|\geq \frac{\ell n}{k},\qquad \left|\bigcap_{i\in X}A_i\right|\geq \ell,\qquad |A_i\cap W|<\ell\quad\text{for every }i\in X. \]

Suppose first that such a group exists. Choose an \(\ell\)-element subset \(S\) of its common intersection. Every voter in \(X\) belongs to
\[ B_{\ell,S}=\{i\in N:S\subseteq A_i,\ |A_i\cap W|<\ell\}. \]
By construction of the masses,
\[ \sum_{\substack{A\in T:\ S\subseteq A\\ |A\cap W|<\ell}}\mu_A =\frac{|B_{\ell,S}|}{n} \geq\frac{|X|}{n} \geq\frac{\ell}{k}. \]
Hence the constructed continuous instance is a no-instance.

Conversely, suppose the continuous instance is a no-instance, witnessed by \(\ell\) and \(S\). Set \(X=B_{\ell,S}\). The same counting identity gives
\[ |X| =n\sum_{\substack{A\in T:\ S\subseteq A\\ |A\cap W|<\ell}}\mu_A \geq\frac{\ell n}{k}. \]
Every voter in \(X\) approves all of \(S\), so their common intersection has size at least \(\ell\). Every voter in \(X\) also satisfies \(|A_i\cap W|<\ell\). Thus \(X\) witnesses a finite-profile EJR violation.

Therefore the finite committee satisfies EJR if and only if the constructed rational-mass instance is a yes-instance. Notice that the reverse implication simply takes all eligible voters; no assumption about indivisibility of approval types is needed.

By the supplied \(\mathrm{coNP}\)-completeness of finite-profile EJR verification, this polynomial-time many-one reduction proves \(\mathrm{coNP}\)-hardness. Together with membership, it proves the asserted classification.

Meaning of the requested dichotomy. The distinction between \(\mathrm{NP}\)-hardness and \(\mathrm{coNP}\)-hardness matters for a verification problem.

If this problem were polynomial-time solvable, its \(\mathrm{coNP}\)-hardness would imply \(\mathrm{coNP}\subseteq\mathrm{P}\). Closure of \(\mathrm{P}\) under complementation would then imply \(\mathrm{NP}\subseteq\mathrm{P}\). Conversely, \(\mathrm{P}=\mathrm{NP}\) implies \(\mathrm{P}=\mathrm{coNP}\), giving a polynomial-time algorithm by the membership proof.

Under polynomial-time many-one reductions, the problem is \(\mathrm{NP}\)-hard if and only if \(\mathrm{NP}=\mathrm{coNP}\): hardness and membership would imply \(\mathrm{NP}\subseteq\mathrm{coNP}\), hence equality by complementation; equality would make its established \(\mathrm{coNP}\)-hardness also \(\mathrm{NP}\)-hardness.

Under polynomial-time Turing reductions, it is unconditionally \(\mathrm{NP}\)-hard. For any language \(L\in\mathrm{NP}\), its complement belongs to \(\mathrm{coNP}\) and therefore many-one reduces to this problem. One oracle query followed by negating the answer decides membership in \(L\).
