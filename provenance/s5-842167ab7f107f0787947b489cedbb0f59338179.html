The anchor (named result in the paper)

Theorem 1.3 — class: algorithmic

The continuous mirror question, as graded

Given finite complete XOS types \(T\), rational masses \(\mu_t\) with \(\sum_t\mu_t=1\), rational per-capita supplies \(\rho_b\) of indivisible item kinds \(b\in B\), and valuations \(v_t(q)=\max_k\sum_{b\in B}w_{t,k,b}q_b\) for integral bundle count vectors \(q\in\mathbb{Z}_{\ge 0}^{B}\), find aggregate masses \(x_{t,q}\ge 0\) satisfying \(\sum_q x_{t,q}=\mu_t\) and \(\sum_{t,q}q_bx_{t,q}=\rho_b\), such that \(x_{t,q}>0\) implies \(v_t(q)\ge (3/13)M_t(\rho)\), where \(M_t(\rho)=\max\{\lambda:\exists y_q\ge0,\ \sum_qy_q=1,\ \sum_qq_by_q=\rho_b,\ y_q>0\Rightarrow v_t(q)\ge\lambda\}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types.
There are \(m=|B|\geq1\) indivisible item kinds with per-capita supplies \(\rho_b\in\mathbb{Q}_{\geq0}\). Type \(t\) is specified by \(K_t\geq1\) explicitly listed additive clauses with weights \(w_{t,k,b}\in\mathbb{Q}_{\geq0}\), giving \(v_t(q)=\max_{1\leq k\leq K_t}\sum_{b\in B}w_{t,k,b}q_b\) for \(q\in\mathbb{Z}_{\geq0}^{B}\).
Bundles may contain arbitrarily many copies; only aggregate supplies constrain allocation. Empty bundles and zero benchmark values are allowed.
Define \(M_t(\rho)=\max\{\lambda\in\mathbb{R}_{\geq0}:\exists\text{ finitely supported }y_q\geq0,\ \sum_qy_q=1,\ \sum_qq_by_q=\rho_b\ (b\in B),\ y_q>0\Rightarrow v_t(q)\geq\lambda\}\).
An allocation is a finitely supported family of nonnegative rational masses \(x_{t,q}\) satisfying \(\sum_qx_{t,q}=\mu_t\) and \(\sum_{t,q}q_bx_{t,q}=\rho_b\) for every \(b\in B\). It is \(3/13\)-fair if \(x_{t,q}>0\Rightarrow v_t(q)\geq(3/13)M_t(\rho)\).
Let \(K=\sum_tK_t\) and let \(L\) be the total binary input length; benchmark values are not supplied as input.

Does every such society admit a \(3/13\)-fair allocation, and, if so, can one be found in time polynomial in \(m,\tau,K,L\), or is achieving this guarantee \(\mathrm{NP}\)-hard?

For finite agents and indivisible goods, a deterministic \(3/13\)-MMS allocation always exists and has a constructive algorithm; that algorithm has no polynomial-time guarantee. [Source](https://arxiv.org/html/2308.14545v2)
No result settling this exact mass model was identified in the literature search.

Modeling choices made when packaging the task

  • Interpreted complete XOS types as explicitly listed finite clause families with nonnegative binary-rational weights; each family is nonempty.
  • Specified nonnegative binary-rational supplies and nonempty type and item-kind sets.
  • Used finite-support distributions in the benchmark and finite-support rational aggregate allocations to give the computational problem a finite representation.
  • Retained the stated unbounded integral bundle domain, with repeated copies permitted and no individual supply cap.
  • Allowed empty bundles and zero benchmark values, consistent with the discrete MMS definition; did not impose the proof's positive-MMS scaling convention.
  • Specified that benchmark values must be derived from the input rather than supplied.

1. Result

Every society in the question admits a fully benchmark-fair allocation. Moreover, a \(\tfrac14\)-fair allocation can be found in time polynomial in \(m,\tau,K,L\). Since \(\tfrac14>\tfrac3{13}\), this resolves the requested guarantee in polynomial time.

The essential feature of the stated model is that every type’s benchmark uses the same mean supply vector \(\rho\). Benchmark distributions can therefore be mixed according to the type masses. The computational task is to find sufficiently good distributions without computing the benchmarks exactly.

All constructions below use binary-encoded bundle multiplicities and rational masses.

2. Benchmark attainment and full-fairness existence

Write \(S=\{b\in B:\rho_b>0\}\). Any distribution with mean \(\rho\) assigns zero copies of every \(b\notin S\) in every positive-mass bundle: otherwise its nonnegative expected multiplicity for that kind would be positive. Thus we may initially work only with kinds in \(S\).

For a fixed type \(t\), define

\[ \text{[formula intentionally expressed inline below]} \]

\(U_t=\sum_{b\in S}\rho_b\max_{1\leq k\leq K_t}w_{t,k,b}.\)

For every bundle \(q\),

\(v_t(q)\leq\sum_{b\in S}q_b\max_k w_{t,k,b}.\)

Consequently, if a distribution with mean \(\rho\) gives value at least \(\lambda\) in every positive-mass bundle, then

\(\lambda\leq\sum_q y_qv_t(q)\leq U_t.\)

A finitely supported rational distribution with mean \(\rho\) always exists. For example, round each coordinate independently to its floor or ceiling with probabilities giving the prescribed expectation. Hence the benchmark feasibility set is nonempty.

Let \(D_t\) be a common denominator of the weights of type \(t\). Every integer-bundle value belongs to \(D_t^{-1}\mathbb Z_{\geq0}\). For any finitely supported distribution \(y\), its minimum supported value

\(h_t(y)=\min\{v_t(q):y_q>0\}\)

therefore belongs to that lattice. If \(y\) has mean \(\rho\), the preceding bound gives \(h_t(y)\leq U_t\).

Thus the set of attainable minimum supported values is a nonempty subset of the finite set

\(\{j/D_t:j\in\mathbb Z_{\geq0},\ j/D_t\leq U_t\}.\)

It has a largest element, attained by some finitely supported distribution. This element is exactly \(M_t(\rho)\), so the maximum in the question’s definition exists.

Furthermore, an attaining distribution can be chosen rational. Fix an attaining finite support. The equations prescribing total mass one and mean \(\rho\), together with nonnegativity, define a nonempty rational polytope. A vertex of this polytope is rational, and every bundle remaining in its support still has value at least \(M_t(\rho)\).

Choose such a rational benchmark distribution \(y^t\) for each type, and put

\(x_{t,q}=\mu_t y^t_q.\)

Then

\(\sum_qx_{t,q}=\mu_t,\qquad \sum_{t,q}q_bx_{t,q}=\sum_t\mu_t\rho_b=\rho_b.\)

Every positive-mass bundle of type \(t\) has value at least \(M_t(\rho)\). This proves full benchmark-fairness existence. It does not yet provide a polynomial-time construction.

3. A polynomial-size threshold construction

We now prove an algorithmic lemma.

Threshold lemma. Given a type \(t\) and a positive rational threshold \(\lambda\), one can construct an explicit rational linear program of polynomial size with these properties:

  • If \(\lambda\leq M_t(\rho)\), the program is feasible.
  • From any feasible solution, one can recover a finitely supported rational distribution \(y\) satisfying

\(\sum_qy_q=1\), \(\sum_qq_by_q\leq\rho_b\), and \(y_q>0\Rightarrow v_t(q)\geq\lambda/2\).

  • The construction, solution recovery, and output encoding require polynomial time and size in the input length and the bit length of \(\lambda\).

Here the supply constraint is initially an inequality. Exact supply restoration will follow in Section 5.

3.1 Binary blocks for one clause

Fix a clause \(k\) having at least one positive weight on \(S\). For each \(b\in S\) with \(w_{t,k,b}>0\), define

\(Q_{k,b}=\left\lceil\lambda/w_{t,k,b}\right\rceil.\)

Create blocks consisting of \(2^j\) copies of kind \(b\), for

\(0\leq j\leq\lfloor\log_2 Q_{k,b}\rfloor.\)

Each block may be selected either zero or one times. Let \(n_k\) be the number of blocks, and enumerate them as \(i=1,\ldots,n_k\). Block \(i\) has a multiplicity vector \(c_i\) and clause value

\(p_i=\sum_b w_{t,k,b}c_{i,b}.\)

Since \(Q_{k,b}\geq1\), we have \(n_k\geq1\).

For each block set

\(a_i=\left\lfloor 2n_k\,\min\{p_i,\lambda\}/\lambda\right\rfloor.\)

These are integers between zero and \(2n_k\). We accept a selected subset \(I\) of blocks when

\(\sum_{i\in I}a_i\geq n_k.\)

Every accepted subset has true clause value at least \(\lambda/2\), because

\(\sum_{i\in I}p_i \geq\sum_{i\in I}\min\{p_i,\lambda\} \geq\frac{\lambda}{2n_k}\sum_{i\in I}a_i \geq\lambda/2.\)

3.2 Every threshold-good bundle contains an accepted subbundle

Suppose \(q\) satisfies the clause inequality

\(\sum_b w_{t,k,b}q_b\geq\lambda.\)

Discard its coordinates having zero clause weight, and truncate every remaining coordinate to

\(q'_b=\min\{q_b,Q_{k,b}\}.\)

Then \(q'\leq q\) coordinatewise and its clause value remains at least \(\lambda\). Indeed, if a coordinate was truncated, that coordinate alone now contributes at least \(\lambda\); if none was truncated, the clause value is unchanged.

Each integer \(q'_b\leq Q_{k,b}\) has a binary expansion using the blocks constructed above. Let \(I\) denote the resulting selected subset. Since its total clause value is at least \(\lambda\),

\(\sum_{i\in I}\min\{p_i,\lambda\}\geq\lambda.\)

Using \(\lfloor z\rfloor\geq z-1\) and \(|I|\leq n_k\), we obtain

\(\sum_{i\in I}a_i \geq\frac{2n_k}{\lambda}\sum_{i\in I}\min\{p_i,\lambda\}-|I| \geq2n_k-|I| \geq n_k.\)

Thus \(q'\) is accepted.

3.3 Encoding all accepted subsets by a flow network

For clause \(k\), construct a layered directed acyclic graph. At layer \(i\), the state \(s\in\{0,\ldots,n_k\}\) records the rounded value accumulated so far, capped at \(n_k\).

For block \(i\), include:

  • a skip edge that leaves \(s\) unchanged;
  • a take edge that changes \(s\) to \(\min\{n_k,s+a_i\}\), carrying multiplicity vector \(c_i\).

The clause source is state zero before the first block. Its accepting terminal is state \(n_k\) after the last block. Paths from source to accepting terminal encode exactly the accepted subsets. The graph has \(O(n_k^2)\) vertices and edges.

Combine these graphs for all clauses having a positive weight on \(S\), using a common source and common sink. Give connecting and skip edges zero multiplicity vectors.

The linear program asks for a nonnegative unit source-to-sink flow \(f\), with flow conservation at every other vertex, subject to

\(\sum_e c_{e,b}f_e\leq\rho_b\qquad(b\in S).\)

This is an explicit finite rational linear program.

If \(\lambda\leq M_t(\rho)\), take an attaining benchmark distribution. For every supported bundle, choose a clause witnessing value at least \(\lambda\), and replace that bundle by the accepted subbundle from Section 3.2. Sending its probability along the corresponding path produces a feasible unit flow: the replacement only reduces multiplicities.

Conversely, a feasible rational flow decomposes into rational source-to-sink path flows. Each path gives a bundle worth at least \(\lambda/2\) under its selected clause, hence also under \(v_t\). The flow resource constraints give the required expectation inequalities.

A path decomposition uses at most the number of edges: repeatedly subtract the smallest positive flow on a positive-flow source-to-sink path, eliminating at least one edge each time. Acyclicity and flow conservation ensure that this process decomposes the entire flow.

Finally,

\(n_k=\sum_{\substack{b\in S\\w_{t,k,b}>0}} \bigl(1+\lfloor\log_2 Q_{k,b}\rfloor\bigr).\)

This is polynomial in the input length and the bit length of \(\lambda\). Block multiplicities and all other coefficients have polynomial bit length. Standard polynomial-time rational linear programming therefore decides feasibility and returns a polynomial-bit rational solution when feasible. Path decomposition also takes polynomial time and preserves polynomial output size.

This proves the threshold lemma.

4. Finding a quarter-benchmark distribution

Process each type separately.

If \(U_t=0\), then \(M_t(\rho)=0\), and initially give that type the empty-bundle distribution.

Otherwise let

\(w_t^{\min}=\min\{w_{t,k,b}:b\in S,\ w_{t,k,b}>0\}.\)

We first establish the implication

\(M_t(\rho)>0\ \Rightarrow\ w_t^{\min}\leq M_t(\rho)\leq U_t.\)

The upper bound was proved earlier. For the lower bound, take an attaining positive-benchmark distribution. Every supported bundle has positive value, so some clause contains a positive-weight item appearing at least once. Consequently every such bundle has value at least \(w_t^{\min}\). The same distribution therefore witnesses benchmark at least \(w_t^{\min}\).

Run the threshold construction at every threshold

\(\lambda_j=2^j w_t^{\min}\), for integers \(j\geq0\) satisfying \(\lambda_j\leq U_t\).

If any program is feasible, choose the largest tested threshold with a feasible program and recover its distribution. If none is feasible, use the empty-bundle distribution.

Suppose \(M_t(\rho)>0\). There is a largest tested threshold \(\lambda_*\leq M_t(\rho)\), and

\(\lambda_*\leq M_t(\rho)<2\lambda_*.\)

The program for \(\lambda_*\) is feasible by the threshold lemma. Therefore the chosen feasible threshold \(\widehat\lambda_t\) satisfies \(\widehat\lambda_t\geq\lambda_*\), and every recovered positive-mass bundle satisfies

\(v_t(q)\geq\widehat\lambda_t/2 \geq\lambda_*/2 >M_t(\rho)/4.\)

If no tested program is feasible, the same argument shows that \(M_t(\rho)=0\). Thus the empty-bundle fallback is valid. Whenever \(M_t(\rho)=0\), any recovered distribution is also fair.

For every type we have consequently constructed a rational distribution \(y^t\) such that

\(\sum_q y^t_q=1,\qquad \sum_q q_by^t_q\leq\rho_b,\qquad y^t_q>0\Rightarrow v_t(q)\geq M_t(\rho)/4.\)

The number of tested thresholds is at most

\(1+\left\lfloor\log_2(U_t/w_t^{\min})\right\rfloor\)

when the threshold list is nonempty. This is polynomial in the binary input length. No monotonicity of the threshold programs is needed: we explicitly test the entire list.

5. Restoring exact supplies

Set \(x_{t,q}=\mu_t y^t_q\). These masses give every type its prescribed total mass and satisfy quarter-benchmark fairness. Their aggregate consumption \(r\) satisfies

\(r_b=\sum_{t,q}q_bx_{t,q}\leq\rho_b.\)

Put \(\delta_b=\rho_b-r_b\). We now allocate these remaining supplies exactly, preserving fairness and polynomial support size.

Choose any positive entry \(x_{t_0,q_0}=x>0\), and define

\(h_b=\delta_b/x,\qquad d_b=\lfloor h_b\rfloor,\qquad f_b=h_b-d_b.\)

We need a small rational distribution of integer addition vectors with mean \(h\).

Sort the distinct numbers among zero, one, and the fractions \(f_b\) lying strictly between zero and one:

\(0=z_0<z_1<\cdots<z_\ell=1.\)

There are at most \(m+1\) resulting intervals. For each interval choose its midpoint \(\theta_j\), and define

\(\pi_j=z_{j+1}-z_j,\qquad a^{(j)}_b=d_b+\mathbf1_{\{\theta_j<f_b\}}.\)

These are rational probabilities and integer vectors. They satisfy

\(\sum_j\pi_j=1,\qquad \sum_j\pi_j a^{(j)}_b=d_b+f_b=h_b.\)

For the second identity, the intervals whose midpoints lie below \(f_b\) have total length exactly \(f_b\).

Replace the original entry by entries of type \(t_0\) assigning mass \(x\pi_j\) to bundle \(q_0+a^{(j)}\). The type’s total mass is unchanged, and aggregate consumption increases by

\(x\sum_j\pi_j a^{(j)}_b=xh_b=\delta_b.\)

Thus every supply equality now holds exactly.

Because all weights are nonnegative, \(v_{t_0}\) is coordinatewise monotone. Every replacement bundle has value at least \(v_{t_0}(q_0)\), so fairness is preserved. This replacement increases support size by at most \(m\).

6. Complexity and conclusion

The algorithm never expands rational type masses or supplies into a finite population.

For every tested threshold:

  • the binary block counts are polynomial in the input length;
  • the flow network has polynomially many vertices and edges;
  • its coefficients have polynomial bit length;
  • rational linear programming and path decomposition take polynomial time.

There are polynomially many thresholds across all types. Multiplying path probabilities by the masses \(\mu_t\) preserves polynomial bit length. The final supply-restoration step uses rational arithmetic, sorting, and at most \(m+1\) replacement bundles; its probabilities and multiplicities also have polynomial bit length.

Therefore the algorithm outputs an explicitly listed, finitely supported rational allocation in time polynomial in \(m,\tau,K,L\). Every positive-mass bundle satisfies

\(v_t(q)\geq\tfrac14 M_t(\rho)\geq\tfrac3{13}M_t(\rho).\)

Both the existence question and the requested computational guarantee are resolved.
