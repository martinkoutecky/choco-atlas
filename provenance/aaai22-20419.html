The continuous mirror question, as graded

Given alternatives \(A\), types \(T\) with complete rankings \(\succ_t\), rational masses \(\mu_t\ge0\) summing to \(1\), and \(k/2<q\le k<m\), where each type has a common hidden distance row \(\delta(t,\cdot)\), determine whether a polynomial-time algorithm can output a polynomial-size shortlist \(P\) of \(k\)-committees such that, for every ranking-consistent pseudometric satisfying \(\delta(t,a)\le\delta(t,b)+\delta(t',b)+\delta(t',a)\), \(\min_{C\in P}\sum_t\mu_t c_{t,q}(C\mid\delta)<\left(1+\frac{2}{e}+\varepsilon\right)\min_{|O|=k}\sum_t\mu_t c_{t,q}(O\mid\delta)\), in time polynomial in \(m\), \(\tau=|T|\), and the encoding length of \(\mu\).

An admissible hidden distance array \(\delta:T\times A\to\mathbb R_{\ge0}\) has one common row per type and satisfies \(a\succ_t b\Rightarrow\delta(t,a)\le\delta(t,b)\) and \(\delta(t,a)\le\delta(t,b)+\delta(t',b)+\delta(t',a)\) for every \(t,t'\in T\) and \(a,b\in A\). Distance ties may be broken arbitrarily in the supplied rankings.
A committee is a subset \(C\subseteq A\) of size \(k\). Define \(c_{t,q}(C\mid\delta)\) as the distance to its \(q\)-th alternative in ranking \(\succ_t\), and \(\operatorname{SC}_\mu(C\mid\delta)=\sum_{t\in T}\mu_t c_{t,q}(C\mid\delta)\).

Does a deterministic algorithm produce such a shortlist with size and running time polynomial in \(m,\tau,L\), for each fixed \(\varepsilon>0\), or is achieving this approximation guarantee NP-hard?

For finite lists of agents, the stated hardness result says that polynomial-time construction of a polynomial-size shortlist with this guarantee implies \(\mathrm P=\mathrm{NP}\). In the same finite-agent model, the shortlist consisting of each agent’s top-\(k\) committee guarantees approximation factor \(3\).

Conclusion and interpretation

Taking the finite-agent hardness assertion in the question as a premise, the intended weighted-support problem is NP-hard in the stated sense: a polynomial-time algorithm producing a polynomial-size shortlist would imply \(\mathrm P=\mathrm{NP}\). The transfer requires averaging distances within each ranking type; simply identifying agents would not justify it.

There are two qualifications. Literally, the strict inequality is impossible for the admissible array \(\delta\equiv0\). I therefore address the intended approximation requirement when the optimal cost is positive, with zero-cost instances requiring a zero-cost committee.

Also, the published finite-agent theorem uses \(1+2/e-\varepsilon\), whereas the question supplies \(1+2/e+\varepsilon\). Below I prove the transfer, distinguish its conditional consequence from the published result, and establish a polynomial-time guarantee for sufficiently large \(\varepsilon\).

Proven lemma: compression preserves all committee costs

Let a finite profile have agents \(N=\{1,\ldots,n\}\). Partition its agents into nonempty classes \(N_t\) according to their identical supplied rankings. Set \(n_t=|N_t|\) and \(\mu_t=n_t/n\).

For any admissible finite-agent distance array \(d\), define

\(\displaystyle \bar\delta(t,a)=\frac1{n_t}\sum_{i\in N_t}d(i,a).\)

I claim that \(\bar\delta\) is admissible for the compressed profile.

Nonnegativity is preserved by averaging. If \(a\succ_t b\), every agent \(i\in N_t\) satisfies \(d(i,a)\le d(i,b)\), so \(\bar\delta(t,a)\le\bar\delta(t,b)\).

For the quadrilateral inequality, fix types \(t,s\) and alternatives \(a,b\). For every pair \(i\in N_t\), \(j\in N_s\),

\(d(i,a)\le d(i,b)+d(j,b)+d(j,a).\)

Averaging over all \(n_tn_s\) pairs gives

\(\bar\delta(t,a)\le\bar\delta(t,b)+\bar\delta(s,b)+\bar\delta(s,a).\)

Thus \(\bar\delta\) satisfies every required constraint.

Now fix any committee \(C\). Let \(a_t(C)\) be its alternative in position \(q\) under ranking \(\succ_t\). This alternative is the same for every agent in \(N_t\), even when their distance rows differ. Consequently,

\(\displaystyle \operatorname{SC}_\mu(C\mid\bar\delta) =\sum_t\frac{n_t}{n}\bar\delta(t,a_t(C)) =\frac1n\sum_{i\in N}c_{i,q}(C\mid d). \)

This identity holds simultaneously for every committee. Therefore it also preserves the optimal committee cost and the minimum cost attained by any fixed shortlist, up to the common factor \(1/n\).

Proven consequence: any finite-agent hardness transfers

Suppose a deterministic support-model algorithm constructs a polynomial-size shortlist with approximation factor \(R\).

Given an explicitly listed finite-agent profile, compress it as above and run that algorithm. This transformation is polynomial-time: \(\tau\le n\), and each mass \(n_t/n\), represented by binary-encoded numerator and denominator, has bit length \(O(\log n)\). Hence the compressed input length is polynomial in the original input length.

The output depends only on the compressed rankings and masses. For each admissible finite-agent array \(d\), its averaged array \(\bar\delta\) is admissible, so the support-model guarantee applies. By the cost identity, the resulting shortlist satisfies

\(\displaystyle \min_{C\in P}\sum_{i\in N}c_{i,q}(C\mid d) < R\min_{|O|=k}\sum_{i\in N}c_{i,q}(O\mid d), \)

whenever the optimal cost is positive. Zero-cost recovery transfers by the same identity.

Thus a polynomial-time support-model construction yields a polynomial-time finite-agent construction with exactly the same approximation factor. The condition \(1\le k/2<q\le k<m\) is unchanged.

Conditional conclusion. If the finite-agent hardness assertion supplied in the question holds at \(R=1+2/e+\varepsilon\), then such a support-model algorithm implies \(\mathrm P=\mathrm{NP}\). Requiring one common distance row per type does not evade that assertion.

Proven upper bound: the weighted top-\(k\) shortlist

The following bound also identifies a limitation of the supplied hardness assertion.

Write \(c_t(C)=c_{t,q}(C\mid\delta)\). First, committee costs satisfy

\(c_t(X)\le c_t(Y)+c_s(Y)+c_s(X).\)

To prove this, let \(B_u(C)\) denote the first \(q\) alternatives of \(C\) under ranking \(\succ_u\).

Because \(2q>k\), choose \(a\in B_t(Y)\cap B_s(Y)\). Also choose \(b\in B_s(X)\) whose position under \(\succ_t\), restricted to \(X\), is at least \(q\). Such a \(b\) exists because these two subsets of \(X\) have sizes \(q\) and \(k-q+1\), whose sum exceeds \(k\). The ranking constraints and quadrilateral inequality give

\(c_t(X)\le\delta(t,b)\le\delta(t,a)+\delta(s,a)+\delta(s,b)\le c_t(Y)+c_s(Y)+c_s(X).\)

Let \(C_s\) be type \(s\)’s top-\(k\) committee, and let \(O\) be optimal. Since \(C_s\) contains type \(s\)’s globally first \(q\) alternatives,

\(c_s(C_s)\le c_s(O).\)

For \(t\ne s\), the preceding inequality therefore gives

\(c_t(C_s)\le c_t(O)+2c_s(O).\)

For \(t=s\), use the stronger bound \(c_s(C_s)\le c_s(O)\). Summing with masses yields

\(\displaystyle \operatorname{SC}_\mu(C_s) \le \operatorname{SC}_\mu(O)+2c_s(O)-2\mu_s c_s(O). \)

Average this inequality over \(s\), with weights \(\mu_s\). Since the minimum is no greater than this weighted average,

\(\displaystyle \min_s\operatorname{SC}_\mu(C_s) \le 3\operatorname{SC}_\mu(O)-2\sum_s\mu_s^2c_s(O). \)

Define \(\mu_{\min}=\min_s\mu_s>0\). Because \(\mu_s^2\ge\mu_{\min}\mu_s\),

\(\displaystyle \min_s\operatorname{SC}_\mu(C_s) \le (3-2\mu_{\min})\operatorname{SC}_\mu(O). \)

The shortlist \(P=\{C_s:s\in T\}\) is nonempty, has at most \(\tau\) committees, and is constructible in polynomial time. Its guarantee is strictly below \(3\) whenever the optimum is positive, and it recovers zero optimal cost.

In particular, it satisfies the requested positive-optimum guarantee whenever

\(\varepsilon\ge 2-2/e.\)

Thus the supplied hardness assertion cannot apply to every positive \(\varepsilon\), unless \(\mathrm P=\mathrm{NP}\).
