The anchor (named result in the paper)

Theorem 5 — class: hardness

Let A be an algorithm which on input a ranking proﬁle with n agents and m alternatives, and integers k and q with 1 ⩽k/2 < q ⩽k < m, runs in time polynomial in m and n and returns a set P of (polynomially many) k-sized committees of alternatives with the following property: For every distance function d, there is a committee C ∈P such that SCq(C|d) < (1 + 2/e + ε) · SCq(O|d), where O is a committee of minimum social cost according to d, and ε is a positive constant. Then, P = NP. Extensions and Open Problems In this work, we extended the metric distortion framework to multiwinner voting.

The continuous mirror question, as graded

Given alternatives \(A\), types \(T\) with complete rankings \(\succ_t\), rational masses \(\mu_t\ge0\) summing to \(1\), and \(k/2<q\le k<m\), where each type has a common hidden distance row \(\delta(t,\cdot)\), determine whether a polynomial-time algorithm can output a polynomial-size shortlist \(P\) of \(k\)-committees such that, for every ranking-consistent pseudometric satisfying \(\delta(t,a)\le\delta(t,b)+\delta(t',b)+\delta(t',a)\), \(\min_{C\in P}\sum_t\mu_t c_{t,q}(C\mid\delta)<\left(1+\frac{2}{e}+\varepsilon\right)\min_{|O|=k}\sum_t\mu_t c_{t,q}(O\mid\delta)\), in time polynomial in \(m\), \(\tau=|T|\), and the encoding length of \(\mu\).

Packaged proof task (what the prover saw — nothing else)

Definitions. An instance has alternatives \(A\), types \(T\) with complete rankings \(\succ_t\), rational masses \(\mu_t\geq0\) with \(\sum_t\mu_t=1\), and \(k/2<q\leq k<|A|\). An admissible distance row system is a nonnegative \(\delta:T imes A o\mathbb R_{\geq0}\) such that \(a\succ_t b\Rightarrow\delta(t,a)\leq\delta(t,b)\) and \(\delta(t,a)\leq\delta(t,b)+\delta(t',b)+\delta(t',a)\) for all \(t,t'\in T\) and \(a,b\in A\).

For a \(k\)-committee \(C\), let \(c_{t,q}(C\mid\delta)\) be the \(q\)-th smallest value in \(\{\delta(t,a):a\in C\}\), and let \(\operatorname{SC}_q(C\mid\delta)=\sum_{t\in T}\mu_t c_{t,q}(C\mid\delta)\).

Target. For every fixed \(\varepsilon>0\), is it polynomial-time solvable, or NP-hard, to output a polynomial-size set \(P\) of \(k\)-committees such that every admissible \(\delta\) has some \(C\in P\) with \(\operatorname{SC}_q(C\mid\delta)<(1+2/e+\varepsilon)\min_{|O|=k}\operatorname{SC}_q(O\mid\delta)\)?

Nearest known results. For finite, unweighted agent profiles, no polynomial-time algorithm can always output such a polynomial-size shortlist unless \(\mathrm P=\mathrm{NP}\).

Conclusion

As stated, the task is infeasible: no shortlist \(P\), even of exponential or unlimited size, satisfies the required strict inequality. Consequently, the proposed polynomial-time-versus-hardness dichotomy is not well-posed.

Zero-distance obstruction

Define the row system \(\delta_0\) by

\[ \delta_0(t,a)=0 \]

for every \(t\in T\) and \(a\in A\).

This row system is admissible:

  • It is nonnegative.
  • If \(a\succ_t b\), then \(\delta_0(t,a)=0\leq 0=\delta_0(t,b)\).
  • For all \(t,t'\in T\) and \(a,b\in A\),

\[ \delta_0(t,a)=0 \leq 0+0+0 = \delta_0(t,b)+\delta_0(t',b)+\delta_0(t',a). \]

For every \(k\)-committee \(C\), all \(k\) values in \(\{\delta_0(t,a):a\in C\}\) are zero. Hence

\[ c_{t,q}(C\mid\delta_0)=0 \]

for every \(t\), and therefore

\[ \operatorname{SC}_q(C\mid\delta_0) = \sum_{t\in T}\mu_t\cdot 0 = 0. \]

In particular,

\[ \min_{|O|=k}\operatorname{SC}_q(O\mid\delta_0)=0. \]

Thus the required inequality for \(\delta_0\) becomes

\[ 0< \left(1+\frac{2}{e}+\varepsilon\right)0 = 0, \]

which is false. This holds for every committee \(C\), so no set \(P\) can satisfy the specification.

Complexity consequence

The output relation has no feasible output on any instance. It is therefore not a total search problem whose complexity can meaningfully be classified as polynomial-time solvable versus NP-hard. If an algorithm were allowed to answer “infeasible,” the corresponding decision problem would instead be trivial: every instance is infeasible.

Hardness after a natural repair

The nearest finite-profile hardness result does transfer immediately after repairing the zero-optimum issue, for example by either:

  • replacing the strict inequality by a non-strict inequality; or
  • retaining the strict inequality but quantifying only over admissible systems whose optimum is positive.

Indeed, let a finite unweighted profile have agent set \(N\), where \(n=|N|\). Construct a type instance by taking one labelled type \(t_i\) for every \(i\in N\), copying its ranking, and setting

\[ \mu_{t_i}=\frac1n. \]

The formal definition permits different types to carry the same ranking, so this construction does not require rankings to be distinct. For every committee \(C\) and every distance system \(d\) from the finite instance, take

\[ \delta(t_i,a)=d(i,a). \]

Every ranking-consistent metric satisfies the displayed row inequalities by the triangle inequality. Moreover,

\[ \operatorname{SC}_q(C\mid\delta) = \frac1n\operatorname{SC}^{\mathrm{finite}}_q(C\mid d), \]

and consequently

\[ \min_{|O|=k}\operatorname{SC}_q(O\mid\delta) = \frac1n \min_{|O|=k}\operatorname{SC}^{\mathrm{finite}}_q(O\mid d). \]

Multiplication by the positive number \(n\) preserves every strict approximation inequality. The transformation and the binary encoding of the masses \(1/n\) have polynomial size. Hence an algorithm for the positive-optimum repaired problem would give the forbidden finite-profile algorithm.

For the non-strict repair, apply the hypothetical algorithm with parameter \(\varepsilon/2\). Whenever the finite optimum is positive,

\[ \operatorname{SC}_q(C) \leq \left(1+\frac2e+\frac{\varepsilon}{2}\right)\operatorname{OPT} < \left(1+\frac2e+\varepsilon\right)\operatorname{OPT}. \]

Thus the known finite-profile barrier again applies. Under either natural repair, the intended answer is NP-hard in the stated conditional sense: a polynomial-time algorithm would imply \(\mathrm P=\mathrm{NP}\).

Verification report

Scope and conclusion

The prover correctly identifies a fatal issue in the specification: the universally quantified class of admissible row systems contains the all-zero system, while the requested approximation inequality is strict. Consequently, no committee—and therefore no shortlist of any size—can satisfy the requirement.

This fully resolves the target as written. The later discussion of repaired formulations is unnecessary and contains a small but genuine unsupported extrapolation from the stated nearest known result.

Step-by-step verification

1. Construction of the zero row system

The prover defines \(\delta_0(t,a)=0\) for every \(t\in T\) and \(a\in A\).

This is well-defined and nonnegative.

2. Ranking consistency

For every \(a\succ_t b\), the required condition is

\(\delta_0(t,a)\leq\delta_0(t,b)\).

Both sides equal \(0\), so this condition holds.

3. Row inequality

The required inequality is

\(\delta_0(t,a)\leq\delta_0(t,b)+\delta_0(t',b)+\delta_0(t',a)\).

Substitution gives \(0\leq0\), so this condition also holds for every permitted choice of indices. Thus \(\delta_0\) is admissible.

4. Committee costs under \(\delta_0\)

For any \(k\)-committee \(C\), every member \(a\in C\) has \(\delta_0(t,a)=0\). Therefore the \(q\)-th smallest of these \(k\) values is \(0\), independently of \(q\) within the stated range.

Hence \(c_{t,q}(C\mid\delta_0)=0\) for every \(t\), and

\(\operatorname{SC}_q(C\mid\delta_0)=\sum_t\mu_t0=0\).

This computation is correct.

5. Optimum under \(\delta_0\)

Every \(k\)-committee has cost \(0\), so

\(\min_{|O|=k}\operatorname{SC}_q(O\mid\delta_0)=0\).

The condition \(k<|A|\) ensures that \(k\)-committees exist.

6. Failure of the required strict inequality

For every committee \(C\), the requested inequality becomes

\(0<(1+2/e+\varepsilon)0=0\),

which is false. This is independent of the value of \(\varepsilon>0\).

Since the shortlist condition must hold for every admissible \(\delta\), failure at the single admissible system \(\delta_0\) proves that no shortlist can satisfy the specification.

7. Complexity conclusion

The statement that the requested output relation has no feasible output on any instance follows: every instance admits the same all-zero row system. Thus the problem, as formulated as a mandatory output task, is infeasible rather than polynomial-time solvable.

Describing the associated feasibility decision problem as trivial is also correct, provided the decision question is whether such a shortlist exists.

Auxiliary discussion of repaired formulations

The encoding of an unweighted profile by labelled types of mass \(1/n\) is valid under the definitions, and the scaling identity for social cost is correct.

However, the asserted hardness transfer for both proposed repairs is not fully justified from the nearest known result as stated. The argument explicitly obtains the needed strict inequality only when the finite-instance optimum is positive. The prover does not establish that the cited finite-profile hardness theorem remains valid when restricted to positive-optimum distance systems, nor that its distance model guarantees positive optimum on every relevant instance.

Additionally, the stated nearest known result gives a conditional nonexistence of a polynomial-time algorithm unless \(\mathrm P=\mathrm{NP}\). Calling the repaired problem formally “NP-hard” would require the precise reduction or theorem supplying that classification. These auxiliary gaps do not affect the zero-distance obstruction or the resolution of the actual target.
