The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), and rational directed scores \(w_{t,t'}\), let \(\operatorname{OPT}_\infty(\mu,W)\) be the limit of the maximum per-capita FHG welfare over finite clone populations with \(q\mu_t\) agents of each type, as \(q\to\infty\) through valid denominators. Compute a feasible pair-mass vector \(p\), with \(p_{t,t'}\ge 0\) and \(2p_{t,t}+\sum_{t'\ne t}p_{\min(t,t'),\max(t,t')}\le\mu_t\), maximizing \(V(p)=\sum_{t<t'}(w_{t,t'}+w_{t',t})p_{t,t'}+\sum_t2w_{t,t}p_{t,t}\), such that the resulting pair-and-singleton partition has welfare \(V(p)/2\ge\operatorname{OPT}_\infty(\mu,W)/2\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T=\{1,\ldots,\tau\}\): the types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. There is no independent \(m\) parameter.
The input includes arbitrary signed rational directed scores \(W=(w_{t,s})\). For each positive integer \(q\) with all \(q\mu_t\) integral, create \(q\mu_t\) distinct agents of type \(t\). Distinct agents of types \(t,s\) have directed score \(w_{t,s}\), including when \(t=s\); an agent's score toward itself is zero. Use standard FHG utilities with denominator equal to the full coalition size. All partitions into nonempty coalitions are allowed.
Let \(A_q=q^{-1}\max_\pi\sum_i u_i(\pi(i))\), and write \(\operatorname{OPT}_\infty(\mu,W)=\lim_{q\to\infty}A_q\) along these admissible integers, provided this limit exists.
A pair-mass vector has rational coordinates \(p_{t,s}\geq0\) for \(t\leq s\), measured as numbers of pairs per unit population, and satisfies \(2p_{t,t}+\sum_{s\ne t}p_{\min(t,s),\max(t,s)}\leq\mu_t\). Unused agent mass forms singletons. Its per-capita welfare is \(V(p)/2\), where \(V(p)=\sum_{t<s}(w_{t,s}+w_{s,t})p_{t,s}+\sum_t2w_{t,t}p_{t,t}\).

Does the clone-limit optimum exist for every input, and can an algorithm polynomial in \(\tau\) and \(L\) compute a feasible maximizer \(p\) of \(V\) whose welfare satisfies \(V(p)/2\geq\operatorname{OPT}_\infty(\mu,W)/2\)?

For finite FHGs with arbitrary scores, a polynomial-time algorithm returning pairs and singletons achieves a \(2\)-approximation of optimal utilitarian welfare ([Ferraioli–Varricchio](https://arxiv.org/html/2505.13642v1)). No result settling this exact support-encoded clone-limit formulation was located in the literature search.

  • Allow arbitrary signed rational scores, following the anchor's unrestricted domain.
  • Normalize pair masses as pair counts per unit population, and assign unused agent mass to singletons.
  • Allow arbitrary nonempty coalitions in the clone benchmark, with the full coalition size in the FHG denominator.
  • Require rational output coordinates and allow any maximizer when ties occur.
  • Include existence of the stated clone limit in the target rather than assuming it.
  • Use running-time parameters tau and total input bit length L because this model has no independent m parameter.

Result

Yes to both questions. The clone-limit optimum exists for every input. Moreover, an exact rational linear program of size polynomial in \(\tau\) and \(L\) returns a feasible maximizer \(p^*\) satisfying

\(\displaystyle \frac{V(p^*)}{2}\geq\frac{\operatorname{OPT}_\infty(\mu,W)}{2}.\)

The proof below handles arbitrary signed directed scores, including interactions between distinct agents of the same type.

1. Existence of the clone limit

Write each mass in lowest terms, and let \(D\) be the least common multiple of their denominators. The admissible population sizes are exactly the positive multiples of \(D\).

For admissible \(q\), let \(F(q)\) denote the maximum total welfare, so \(A_q=F(q)/q\). This maximum exists because the agent set has finitely many partitions.

Set \(M=\max_{t,s}|w_{t,s}|\). An agent in a coalition of size \(k\) has utility at most \(M(k-1)/k\leq M\). Singletons have utility zero. Consequently,

\(\displaystyle 0\leq F(q)\leq qM.\)

Define \(S=\sup_{n\geq1}A_{nD}\), which is therefore finite. We prove that the sequence converges to \(S\).

Fix an admissible population size \(q_0=kD\). For any admissible \(q=nD\), write \(n=rk+s\), where \(0\leq s<k\). For every type, the population can be divided into \(r\) blocks containing \(q_0\mu_t\) agents of that type, plus a remainder containing \(sD\mu_t\) agents.

Use an optimal population-\(q_0\) partition in each block and put every remaining agent in a singleton. Each copied coalition has exactly its original utilities: its composition and size are unchanged, and scores depend only on types. Thus

\(\displaystyle F(q)\geq rF(q_0),\qquad A_q\geq\frac{rq_0}{q}A_{q_0}.\)

As admissible \(q\) tends to infinity, \(rq_0/q\) tends to one. Hence

\(\displaystyle \liminf_{\substack{q\to\infty\\D\mid q}}A_q\geq A_{q_0}.\)

Since this holds for every admissible \(q_0\), the lower limit is at least \(S\). Every term is at most \(S\), so the upper limit is at most \(S\). Therefore

\(\displaystyle \operatorname{OPT}_\infty(\mu,W)=\lim_{\substack{q\to\infty\\D\mid q}}A_q=\sup_{n\geq1}A_{nD}.\)

2. Every finite partition yields a feasible pair-mass vector

For distinct types define \(a_{t,s}=w_{t,s}+w_{s,t}\).

Fix an admissible \(q\) and any partition \(\pi\). For a coalition \(C\), write \(n_t(C)\) for its number of type-\(t\) agents and \(k_C=|C|\). Its total welfare is

\(\displaystyle H(C)=\frac{\sum_{t<s}a_{t,s}n_t(C)n_s(C)+\sum_t w_{t,t}n_t(C)(n_t(C)-1)}{k_C}.\)

Indeed, there are \(n_t(C)n_s(C)\) unordered cross-type pairs and \(n_t(C)(n_t(C)-1)/2\) unordered same-type pairs. Each contributes both directed scores, divided by the full coalition size. The subtraction of one excludes self-interactions.

Define rational pair masses by

\(\displaystyle p_{t,s}^{\pi}=\frac1q\sum_{C\in\pi}\frac{n_t(C)n_s(C)}{k_C}\quad(t<s),\)

and

\(\displaystyle p_{t,t}^{\pi}=\frac1q\sum_{C\in\pi}\frac{n_t(C)(n_t(C)-1)}{2k_C}.\)

These coordinates are nonnegative. For each type \(t\), their capacity usage is

\(\displaystyle 2p_{t,t}^{\pi}+\sum_{s\ne t}p_{\min(t,s),\max(t,s)}^{\pi} =\frac1q\sum_{C\in\pi}\frac{n_t(C)(k_C-1)}{k_C} \leq\frac1q\sum_{C\in\pi}n_t(C)=\mu_t.\)

Thus \(p^\pi\) is feasible. Substitution into the objective gives the exact identity

\(\displaystyle V(p^\pi)=\frac1q\sum_{C\in\pi}H(C)=\frac1q\sum_i u_i(\pi(i)).\)

This identity uses no assumption about score signs.

Let \(V^*\) be the maximum pair objective. Applying the identity to an optimal partition at each admissible population size yields

\(\displaystyle V^*\geq A_q.\)

Taking the limit established above proves

\(\displaystyle V^*\geq\operatorname{OPT}_\infty(\mu,W).\)

Therefore every feasible maximizer \(p^*\) has the requested welfare guarantee.

3. Exact polynomial-time computation

The algorithm solves the following rational linear program:

\(\displaystyle \text{maximize }\sum_{t<s}(w_{t,s}+w_{s,t})p_{t,s}+\sum_t2w_{t,t}p_{t,t},\)

subject to

\(\displaystyle p_{t,s}\geq0\quad(t\leq s),\)

and

\(\displaystyle 2p_{t,t}+\sum_{s\ne t}p_{\min(t,s),\max(t,s)}\leq\mu_t\quad(t\in T).\)

There are \(\tau(\tau+1)/2\) variables and \(\tau\) capacity constraints, together with nonnegativity constraints. The capacity matrix has entries in \(\{0,1,2\}\). The right-hand sides and objective coefficients have binary encoding length polynomial in \(L\); forming a sum of two input rationals preserves this bound. Thus the explicit program has encoding length polynomial in \(\tau\) and \(L\).

The feasible region is nonempty because it contains zero. It is bounded because

\(\displaystyle p_{t,t}\leq\mu_t/2,\qquad p_{t,s}\leq\min\{\mu_t,\mu_s\}\quad(t<s).\)

It is also closed, so the objective attains its maximum.

We apply the standard polynomial-time theorem for rational linear programming: an explicitly encoded rational linear program that is feasible and has a finite optimum admits an exact rational optimal solution computable in time polynomial in its binary encoding length. The preceding observations verify these hypotheses. The algorithm therefore returns the required rational maximizer in time polynomial in \(\tau\) and \(L\), without constructing a clone population.

4. Realizability and tightness of the guarantee

Every feasible rational pair vector \(p\) can be realized by a finite clone partition. Choose a positive integer \(Q\) clearing the denominators of all masses and all coordinates of \(p\). Form exactly \(Qp_{t,s}\) pairs of each type combination.

For each type \(t\), this consumes

\(\displaystyle Q\left(2p_{t,t}+\sum_{s\ne t}p_{\min(t,s),\max(t,s)}\right)\leq Q\mu_t\)

agents. All these counts are integers, so distinct agents can be allocated to the pairs, and the remaining agents form singletons.

A cross-type pair has total welfare \((w_{t,s}+w_{s,t})/2\); a same-type pair has total welfare \(w_{t,t}\). Hence this partition has per-capita welfare \(V(p)/2\). The supremum characterization from Section 1 implies

\(\displaystyle \frac{V(p)}2\leq\operatorname{OPT}_\infty(\mu,W).\)

In particular,

\(\displaystyle \frac{\operatorname{OPT}_\infty(\mu,W)}2 \leq\frac{V^*}2 \leq\operatorname{OPT}_\infty(\mu,W).\)

The factor is tight for pair-and-singleton solutions. Take \(\tau=1\), \(\mu_1=1\), and \(w_{1,1}=1\). A coalition of size \(k\) has total welfare \(k-1\), so a partition with \(c\) coalitions has total welfare \(q-c\). The grand coalition is optimal, giving \(A_q=1-1/q\) and \(\operatorname{OPT}_\infty=1\). The pair program maximizes \(2p_{1,1}\) subject to \(2p_{1,1}\leq1\), so its optimal welfare is exactly \(1/2\).

This agrees with the finite pair-and-singleton guarantee in [Ferraioli–Varricchio, Theorem 4](https://arxiv.org/html/2505.13642v1#S4.SS3). The limit and the polynomial bound for the support encoding have been proved directly above.
