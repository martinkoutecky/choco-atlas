Theorem 1 (Additive Valuations) — class: algorithmic

The continuous mirror question, as graded

Given a finite set of capped integral bundle patterns \(\mathcal{B}\) over goods \(G\), complete additive valuation types \(T\), type masses \(\mu\), and per-capita supplies \(q\), find \(x_{t,b}\ge 0\) satisfying \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_g=q_g\), together with a normalized certificate distribution \(z^{t,b}\) over integral bundles for every \(x_{t,b}>0\), with marked focal bundle \(b\), such that \(v_t(b)\ge (4/5)\operatorname{pmm}_t(b,c)\) for every certificate-supported bundle \(c\), where \(\operatorname{pmm}_t(b,c)=\max_a\min\{v_t(a),v_t(b+c-a)\}\).

Packaged proof task (what the prover saw — nothing else)

Let \(G\) contain \(m\geq1\) goods. The input explicitly lists a nonempty family \(\mathcal B\subseteq\prod_{g\in G}\{0,\ldots,h_g\}\) of \(K\) admissible integral bundle patterns, with binary integer caps \(h_g\geq0\); empty bundles are permitted.
A society is given by its support: the list of the \(\tau\geq1\) types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types; normalize \(\sum_t\mu_t=1\). Each type specifies nonnegative binary rational additive values for every good. Per-capita supplies \(q_g\geq0\) are binary rationals; \(L\) is the total input bit length.
An allocation consists of \(x_{t,b}\geq0\) satisfying \(\sum_{b\in\mathcal B}x_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_g=q_g\) for every good.
For each \(x_{t,b}>0\), a certificate is a distribution \(z^{t,b}\geq0\) on \(\mathcal B\), satisfying \(\sum_c z^{t,b}_c=1\) and \(\sum_c z^{t,b}_c c_g=q_g\) for every good, with focal bundle \(b\) marked separately. The focal individual has zero mass, so marking \(b\) does not require \(z^{t,b}_b>0\). Certificates may differ independently across focal pairs.
Define \(\operatorname{pmm}_t(b,c)=\max_{a\in\mathbb Z_{\geq0}^{G},\,a\leq b+c}\min\{v_t(a),v_t(b+c-a)\}\); inequalities between vectors are coordinatewise, and repartitioned bundles need not belong to \(\mathcal B\) or obey its caps.
Require \(v_t(b)\geq\frac45\operatorname{pmm}_t(b,c)\) whenever \(z^{t,b}_c>0\).
At the fixed approximation factor \(\frac45\), can such allocations and certificates be found, or infeasibility reported, in time polynomial in \(m,\tau,K,L\), or is deciding their existence NP-hard?
For finite agents with unrestricted bundles of distinct indivisible goods and nonnegative additive valuations, \(\frac45\)-EPMMS allocations always exist and are computable in polynomial time ([Feldman–Fiat–Nissan–Ponitka](https://arxiv.org/html/2606.18921v1)). No result settling the distributional problem defined above was located.

Modeling choices made when packaging the task

  • Made the bundle family an explicit nonempty list, with binary nonnegative integer coordinate caps; empty bundles remain permitted.
  • Normalized total society mass to one and specified nonnegative binary rational values and supplies.
  • Required every certificate to have total mass one and the same per-capita supplies as the allocation, carrying over the requirement that a certificate allocates all goods.
  • Used the given admissible bundle family for both allocations and certificates.
  • Interpreted the marked focal bundle as the bundle of a zero-mass individual; it need not receive positive probability in the certificate distribution.
  • Allowed certificates to differ independently for each positive allocation entry.
  • Defined pairwise maximin share using all integral repartitions of the combined multiset, without imposing allocation-pattern restrictions or individual caps on the hypothetical pieces.
  • Included infeasibility reporting because arbitrary pattern restrictions and supplies need not admit an allocation.

Exact classification

Deciding existence is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions. Deciding infeasibility is \(\mathrm{NP}\)-complete. Hardness holds already with \(\tau=1\), \(K=2\), all caps \(h_g=1\), positive integral values, and supplies \(q_g=\frac12\).

Consequently, a polynomial-time algorithm that finds allocations and certificates or reports infeasibility exists if and only if \(\mathrm P=\mathrm{NP}\).

There is a reduction-convention qualification: existence is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. Under polynomial-time many-one reductions, it is \(\mathrm{NP}\)-hard if and only if \(\mathrm{NP}=\mathrm{coNP}\). The proof below establishes this precise classification.

1. An exact linear formulation

Call a triple \((t,b,c)\) forbidden when

\[ \operatorname{pmm}_t(b,c)>\frac54v_t(b). \]

Equivalently, the triple is forbidden when there exists an integral vector \(a\) satisfying

\[ 0\leq a\leq b+c,\qquad v_t(a)>\frac54v_t(b),\qquad v_t(b+c-a)>\frac54v_t(b). \]

The equivalence follows directly from the definition of \(\operatorname{pmm}_t\): its maximum is attained because the set of integral vectors between \(0\) and \(b+c\) is finite. Let \(F\) denote the set of forbidden triples.

Introduce nonnegative variables \(x_{t,b}\) and \(y_{t,b,c}\). Consider the following rational linear system:

\[ \sum_{b\in\mathcal B}x_{t,b}=\mu_t \qquad\text{for every }t, \]

\[ \sum_{t,b}x_{t,b}b_g=q_g \qquad\text{for every }g, \]

\[ \sum_{c\in\mathcal B}y_{t,b,c}=x_{t,b} \qquad\text{for every }(t,b), \]

\[ \sum_{c\in\mathcal B}y_{t,b,c}c_g=q_gx_{t,b} \qquad\text{for every }(t,b,g), \]

\[ y_{t,b,c}=0 \qquad\text{for every }(t,b,c)\in F. \]

Lemma. This system is feasible if and only if the requested allocation and certificates exist.

Proof. Given an allocation and its certificates, set

\[ y_{t,b,c}=x_{t,b}z^{t,b}_c \]

whenever \(x_{t,b}>0\), and set all corresponding \(y\)-variables to zero when \(x_{t,b}=0\). The certificate normalization and supply equalities give the third and fourth groups of equations. Fairness gives the last group.

Conversely, suppose the system has a solution. For every pair with \(x_{t,b}>0\), define

\[ z^{t,b}_c=\frac{y_{t,b,c}}{x_{t,b}}. \]

The third and fourth groups of equations imply that this is a probability distribution with expected bundle \(q\). The last group ensures that every pattern receiving positive certificate probability satisfies the required fairness inequality. Pairs with zero allocation mass need no certificate. This proves the equivalence. \(\square\)

The system has \(\tau K+\tau K^2\) variables and polynomially many constraints. Its encoding length is polynomial in the input length. Crucially, it imposes no requirement that the focal bundle receive positive certificate probability.

2. Existence belongs to \(\mathrm{coNP}\)

A forbidden triple has a polynomial-length witness: the integral vector \(a\) above. Each coordinate satisfies \(a_g\leq 2h_g\), so its binary encoding has polynomial length. Both strict valuation inequalities can be checked by exact rational arithmetic in polynomial time.

Here is an \(\mathrm{NP}\) verification procedure for infeasibility:

  • Guess a set \(R\) of at most \(\tau K^2\) triples, together with a witnessing repartition for each.
  • Verify that every triple in \(R\) is forbidden.
  • Form the linear system from Section 1, imposing \(y_{t,b,c}=0\) only for triples in \(R\).
  • Accept if this rational linear system is infeasible.

Step 4 is polynomial-time by the standard polynomial-time algorithm for rational linear-programming feasibility.

For soundness, verified witnesses imply \(R\subseteq F\). The system using \(R\) therefore relaxes the exact system using \(F\). If even the relaxed system is infeasible, no requested allocation exists.

For completeness, if no requested allocation exists, choose \(R=F\) and supply a witnessing repartition for every forbidden triple. There are at most \(\tau K^2\) such triples, and the resulting exact system is infeasible by the lemma.

Thus infeasibility belongs to \(\mathrm{NP}\), and existence belongs to \(\mathrm{coNP}\).

3. A two-pattern hardness reduction

We reduce the complement of PARTITION to existence.

We use the classical \(\mathrm{NP}\)-completeness of PARTITION for binary-encoded positive integers. [Karp’s original paper](https://studylib.net/doc/27985824/karp1972) establishes this result. Restricting to instances with even total preserves \(\mathrm{NP}\)-completeness: doubling every input integer preserves the answer and makes the total even.

Let the source instance consist of positive integers \(u_1,\ldots,u_n\), with

\[ \sum_{i=1}^n u_i=2W,\qquad W\geq1. \]

The source question is whether some subset has sum \(W\).

3.1 Construction and encoding

Set

\[ A=4W-2,\qquad H=A+W=5W-2. \]

Create distinct goods \(g_1,\ldots,g_n,r,s\), all with cap one. There is one type of mass one, with additive values

\[ v(g_i)=u_i,\qquad v(r)=v(s)=A. \]

Define exactly two admissible patterns:

\[ b=\{r\},\qquad c=\{g_1,\ldots,g_n,s\}, \]

where set notation denotes the corresponding binary incidence vectors. Set \(q_g=\frac12\) for every good.

All values are positive integers because \(A\geq2\). The construction has polynomial encoding length: computing \(W\) and \(A\) requires only binary addition and multiplication by a constant.

3.2 The allocation and certificates are forced

Only \(b\) contains \(r\), and only \(c\) contains \(s\). Their supply equalities force

\[ x_b=x_c=\frac12. \]

These probabilities satisfy every supply equality, including those for the original goods. Thus every constructed instance admits an allocation when fairness is ignored.

Likewise, any probability distribution on \(\{b,c\}\) with expected bundle \(q\) must satisfy

\[ z_b=z_c=\frac12. \]

Consequently, both positive focal pairs must use this same certificate.

For any pattern \(d\), unrestricted integral repartitioning gives

\[ \operatorname{pmm}(d,d)=v(d). \]

Indeed, the split \(d,d\) attains \(v(d)\), and no split can have minimum value greater than half the total value \(2v(d)\). Hence both self-comparisons satisfy fairness.

Moreover,

\[ v(b)=A,\qquad v(c)=A+2W, \]

and the combined value is \(2H\). Therefore

\[ \operatorname{pmm}(c,b)\leq H\leq v(c), \]

so the focal comparison from \(c\) to \(b\) also satisfies fairness.

The constructed instance is therefore feasible exactly when

\[ \operatorname{pmm}(b,c)\leq\frac54A. \]

3.3 The remaining comparison encodes PARTITION

Every good occurs exactly once in \(b+c\). Its unrestricted integral repartitions are therefore precisely the subsets of these distinct goods and their complements.

All item values are integers, so \(\operatorname{pmm}(b,c)\) is an integer. Since the total value is \(2H\),

\[ \operatorname{pmm}(b,c)\leq H. \]

We claim that

\[ \operatorname{pmm}(b,c)=H \quad\Longleftrightarrow\quad \text{some subset of the original integers has sum }W. \]

For the forward implication, attaining minimum value \(H\) forces both parts to have value exactly \(H\). A part of value \(H\) must contain exactly one of \(r,s\):

  • With neither, its value is at most \(2W<H\).
  • With both, its value is at least \(2A>H\).

Both strict inequalities follow from

\[ A-W=3W-2>0. \]

Removing the unique padding good of value \(A\) leaves original goods of total value \(H-A=W\).

Conversely, an original subset of value \(W\), together with \(r\), has value \(H\). Its complement also has value \(H\), proving the reverse implication.

Finally,

\[ \frac54A =\frac54(4W-2) =5W-\frac52 =H-\frac12. \]

Thus:

  • If PARTITION is a yes-instance, then \(\operatorname{pmm}(b,c)=H>H-\frac12\), so the required fairness inequality fails.
  • If PARTITION is a no-instance, integrality gives \(\operatorname{pmm}(b,c)\leq H-1<H-\frac12\), so the inequality holds.

We have proved the exact equivalence

\[ \text{constructed instance admits allocation and certificates} \quad\Longleftrightarrow\quad \text{source PARTITION instance is a no-instance}. \]

This is a polynomial-time many-one reduction from the complement of PARTITION to existence. Together with Section 2, it proves that existence is \(\mathrm{coNP}\)-complete and infeasibility is \(\mathrm{NP}\)-complete.

4. Consequences for the requested algorithm

A polynomial-time construction-or-infeasibility algorithm would decide PARTITION: construct the instance above, run the algorithm, and interpret an infeasibility report as a yes-answer to PARTITION. Hence such an algorithm would imply \(\mathrm P=\mathrm{NP}\).

Conversely, if \(\mathrm P=\mathrm{NP}\), the existence of a violating repartition can be decided in polynomial time for each of the polynomially many triples. We can then form the exact linear system and solve it in polynomial time. Rational linear programming returns a rational feasible solution of polynomial encoding length; the divisions from Section 1 recover the requested certificates.

Therefore the requested algorithm exists if and only if \(\mathrm P=\mathrm{NP}\).

For the reduction terminology, one call to an existence oracle, followed by negating its answer, solves PARTITION. This proves \(\mathrm{NP}\)-hardness under polynomial-time Turing reductions. Many-one \(\mathrm{NP}\)-hardness of existence would instead imply \(\mathrm{NP}\subseteq\mathrm{coNP}\), hence \(\mathrm{NP}=\mathrm{coNP}\); the converse follows from its \(\mathrm{coNP}\)-completeness.

The [finite-agent theorem of Feldman–Fiat–Nissan–Ponitka](https://arxiv.org/html/2606.18921v1) concerns unrestricted allocations. Here the explicit pattern family forces both the allocation and certificates, while the fairness test permits unrestricted repartitions. The reduction uses precisely that distinction.
