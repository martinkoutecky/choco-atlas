The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), and \(\tau\) supported approval sets \(A\subseteq C\) with positive rational masses \(\mu_A\) summing to \(1\), output a committee \(W\subseteq C\) of size \(k\) such that (i) for every \(c\in C\setminus W\), \(\sum_{A:\,c\in A,\,A\cap W=\emptyset}\mu_A<1/k\), and (ii) there is no size-\(k\) committee \(W'\) with \(|A\cap W'|\ge |A\cap W|\) for every supported type \(A\), strictly for at least one type.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be an explicitly listed candidate set with \(m\geq 1\), and let \(k\) be an integer with \(1\leq k\leq m\).
A society is given by its support: a list \(\mathcal S\) of \(\tau\) distinct approval sets \(A\subseteq C\), each with positive binary rational mass \(\mu_A\), where \(\sum_{A\in\mathcal S}\mu_A=1\). Empty approval sets are allowed. Here \(\tau\) is the support size, not the number of possible approval sets; \(L\) is the total input bit length.
Output any committee \(W\subseteq C\) with \(|W|=k\) satisfying both conditions:
JR: for every \(c\in C\setminus W\), \(\sum_{A\in\mathcal S:\,c\in A,\,A\cap W=\emptyset}\mu_A<1/k\).
PO: there is no committee \(W'\subseteq C\) with \(|W'|=k\) such that \(|A\cap W'|\geq |A\cap W|\) for every \(A\in\mathcal S\), with strict inequality for at least one supported type.

Is this search problem solvable in time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For explicitly listed finite voters, computing any committee satisfying JR and PO jointly is NP-hard. [Source](https://arxiv.org/html/2609.08357v1).
No result explicitly treating this exact rational-mass search problem was located in the literature search.

  • Retained a search task allowing any qualifying committee, so no tie-breaking convention is required.

Conclusion

The search problem is NP-hard. Consequently, an algorithm running in time polynomial in \(m,\tau,k,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The reduction aggregates identical approval sets in an explicitly listed electorate. It preserves every committee’s JR and PO status, so it works regardless of which valid committee the algorithm returns.

1. The finite-voter hardness theorem

We use the following established result: given an explicitly listed finite approval profile and a committee size, computing any committee satisfying both JR and PO is NP-hard. The definitions in that theorem use the threshold \(n/k\) for JR and coordinatewise approval counts for Pareto dominance, exactly as required below. See [Dong, Theorem 1](https://arxiv.org/html/2609.08357v1).

We now give a polynomial-time reduction from that search problem to the problem in the question.

2. Constructing the rational-mass instance

Let the source instance have candidate set \(C\), committee size \(k\), and an explicitly listed electorate \(V\) of size \(n\geq 1\). Voter \(v\) has approval set \(A_v\subseteq C\).

Define the distinct support sets and their multiplicities by

\(\mathcal S=\{A_v:v\in V\}\), and \(n_A=|\{v\in V:A_v=A\}|\) for \(A\in\mathcal S\).

Assign each supported type the mass

\(\mu_A=n_A/n\).

Retain the same candidate set and committee size. Every mass is a positive rational, and

\(\sum_{A\in\mathcal S}\mu_A=\frac{1}{n}\sum_{A\in\mathcal S}n_A=1\).

Empty approval sets, if present, are aggregated in precisely the same way.

This construction takes polynomial time: encode approval sets as bit vectors over the explicitly listed candidates, group equal vectors, and count their occurrences. Moreover, \(\tau\leq n\), and each numerator and denominator has \(O(\log(n+1))\) bits. Thus the resulting total input length \(L\), as well as \(m,\tau,k\), is polynomially bounded in the source input length.

3. Exact preservation of JR

Fix any committee \(W\subseteq C\) with \(|W|=k\), and any candidate \(c\in C\setminus W\). Let

\(U_c(W)=\{v\in V:c\in A_v,\ A_v\cap W=\emptyset\}\).

Grouping voters by approval set gives the exact identity

\(\displaystyle \sum_{\substack{A\in\mathcal S\\c\in A,\ A\cap W=\emptyset}}\mu_A=\frac{|U_c(W)|}{n}\).

In the finite electorate, a JR violation associated with \(c\) exists exactly when \(|U_c(W)|\geq n/k\):

  • If this inequality holds, the voters in \(U_c(W)\) form a sufficiently large group sharing \(c\), all of whom are unrepresented.
  • Conversely, any unrepresented group sharing \(c\) is contained in \(U_c(W)\), so its size cannot exceed \(|U_c(W)|\).

Therefore finite-voter JR holds exactly when, for every \(c\in C\setminus W\),

\(\displaystyle |U_c(W)|<\frac{n}{k}\quad\Longleftrightarrow\quad \sum_{\substack{A\in\mathcal S\\c\in A,\ A\cap W=\emptyset}}\mu_A<\frac{1}{k}\).

This is precisely the JR condition in the question. The equivalence also preserves violations occurring at equality.

4. Exact preservation of PO

Fix two size-\(k\) committees \(W,W'\).

Since every voter’s approval set belongs to \(\mathcal S\), and every supported set occurs for at least one voter,

\(\displaystyle |A_v\cap W'|\geq |A_v\cap W|\ \text{for every }v\in V\)

holds if and only if

\(\displaystyle |A\cap W'|\geq |A\cap W|\ \text{for every }A\in\mathcal S\).

Likewise, strict inequality holds for at least one voter if and only if it holds for at least one supported type. Thus \(W'\) Pareto-dominates \(W\) in the finite profile exactly when it does so in the rational-mass instance.

Consequently, PO is preserved in both directions.

5. Hardness consequence

Suppose an algorithm solved the rational-mass search problem in time polynomial in \(m,\tau,k,L\).

Given any explicit finite-voter instance, construct its aggregated rational-mass instance and run that algorithm. By Sections 3 and 4, its returned committee satisfies JR and PO in the original electorate. By Section 2, the entire procedure runs in polynomial time.

This contradicts the finite-voter hardness theorem unless \(\mathrm{P}=\mathrm{NP}\). More directly, composing its hardness reduction with this aggregation proves NP-hardness of the present search problem.

Only masses of the form \(n_A/n\), with polynomially bounded \(n\), are needed for this conclusion.

6. Existence for every rational-mass instance

For completeness, the requested output always exists, including when empty approval sets have positive mass.

First construct a JR committee. Start with \(W=\emptyset\). Whenever \(|W|<k\) and an unselected candidate has unrepresented approving mass at least \(1/k\), add that candidate.

Each addition newly represents mass at least \(1/k\). The types newly represented at different steps are disjoint, because represented types remain represented as the committee grows.

If the procedure makes \(k\) additions, their total newly represented mass is at least \(1\). Since the society has total mass \(1\), no positive unrepresented mass remains, so JR holds.

If it stops before \(k\) additions, every unselected candidate has unrepresented approving mass strictly below \(1/k\). Fill the remaining seats arbitrarily. Adding candidates can only decrease unrepresented approving mass, so the completed committee satisfies JR.

There are finitely many size-\(k\) committees. Among those satisfying JR, choose one maximizing

\(\displaystyle F(W)=\sum_{A\in\mathcal S}|A\cap W|\).

Suppose \(W'\) Pareto-dominated this maximizer \(W\). Every type represented by \(W\) would remain represented by \(W'\). Hence, for each \(c\notin W'\), its unrepresented approving mass under \(W'\) would be at most that under \(W\); also \(c\notin W\), since \(c\in W\) would represent every type approving it under \(W\), and dominance would keep those types represented under \(W'\). Equivalently, whether or not \(c\in W\), its unrepresented mass under \(W'\) is either bounded by the JR threshold for \(W\) or is zero. Thus \(W'\) satisfies JR.

Coordinatewise dominance, with a strict increase for at least one supported type, also gives \(F(W')>F(W)\), contradicting maximality. Therefore \(W\) is PO.

This establishes existence; the hardness result concerns computing such a committee.
