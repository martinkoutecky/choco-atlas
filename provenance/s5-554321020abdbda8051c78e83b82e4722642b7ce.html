The continuous mirror question, as graded

Given finite projects \(C\), rational costs \(\operatorname{cost}(c)\), budget \(b>0\), finite complete additive valuation types \(\Theta\) with \(u_\theta:C\to[0,1]\cap\mathbb{Q}\), and rational population masses \(\mu\in\mathbb{Q}_{\geq 0}^{\Theta}\) satisfying \(\sum_\theta\mu_\theta=1\), output an integral project set \(W\subseteq C\) with \(\operatorname{cost}(W)\leq b\) satisfying mass-EJR: for every \(T\subseteq C\), \(\alpha:C\to[0,1]\), and subpopulation \(\lambda\in\mathbb{R}_{\geq 0}^{\Theta}\) with \(\lambda\leq\mu\), if \(\sum_\theta\lambda_\theta\geq\operatorname{cost}(T)/b\) and \(u_\theta(c)\geq\alpha(c)\) for every \(\theta\) with \(\lambda_\theta>0\) and every \(c\in T\), then some such \(\theta\) satisfies \(u_\theta(W)\geq\sum_{c\in T}\alpha(c)\).

Packaged proof task (what the prover saw — nothing else)

Given finite \(C\), rational \(\operatorname{cost}:C\to\mathbb{Q}_{\geq0}\), \(b>0\), finite types \(\Theta\), rational masses \(\mu_\theta\geq0\) summing to \(1\), and additive \(u_\theta:C\to[0,1]\cap\mathbb{Q}\), find \(W\subseteq C\) with \(\operatorname{cost}(W)\leq b\). Write \(u_\theta(W)=\sum_{c\in W}u_\theta(c)\).

\(W\) satisfies mass-EJR if, for every \(T\subseteq C\), \(\alpha:C\to[0,1]\), and \(\lambda\in\mathbb{R}_{\geq0}^{\Theta}\) with \(\lambda\leq\mu\), whenever \(\sum_\theta\lambda_\theta\geq\operatorname{cost}(T)/b\) and \(u_\theta(c)\geq\alpha(c)\) for every \(\theta\) with \(\lambda_\theta>0\) and every \(c\in T\), some such \(\theta\) has \(u_\theta(W)\geq\sum_{c\in T}\alpha(c)\).

Target. Is finding a mass-EJR outcome solvable in polynomial time, or is it NP-hard?

For finite individual voters with additive utilities and arbitrary project costs, EJR outcomes exist, but—unless \(P=NP\)—no strongly polynomial-time aggregation rule can always return one. This follows from the one-voter case, where EJR requires solving knapsack.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

1. The stated definition admits no outcome

There is a degenerate witness that violates mass-EJR for every \(W\), independently of its cost or utilities.

Choose \(T=\varnothing\), let \(\alpha(c)=0\) for every \(c\in C\), and let \(\lambda_\theta=0\) for every \(\theta\in\Theta\). Then:

  • \(0\leq\lambda_\theta\leq\mu_\theta\) for every \(\theta\).
  • \(\sum_{\theta\in\Theta}\lambda_\theta=0=\operatorname{cost}(\varnothing)/b\).
  • The utility hypothesis holds vacuously.

The conclusion nevertheless requires a type \(\theta\) with \(\lambda_\theta>0\). No such type exists.

Thus under the definition as written, no mass-EJR outcome exists on any instance. Consequently, the stated search task does not have the proposed polynomial-time-versus-NP-hard classification as a total search problem.

2. With positive coalition mass required, the intended problem is NP-hard

For completeness, consider the explicitly modified definition that additionally requires \(\sum_\theta\lambda_\theta>0\). For this modification, the one-type argument establishes ordinary NP-hardness with binary-encoded rational inputs, not merely an obstruction to strongly polynomial algorithms.

One-type characterization

Suppose \(\Theta=\{\theta\}\) and \(\mu_\theta=1\). A feasible outcome \(W\) satisfies the modified definition if and only if it maximizes \(u_\theta(W)\) over all feasible subsets.

Necessity. For any feasible \(T\), choose \(\lambda_\theta=1\) and \(\alpha(c)=u_\theta(c)\) for every \(c\in C\). The hypotheses hold because \(\operatorname{cost}(T)/b\leq1\). The conclusion gives \(u_\theta(W)\geq u_\theta(T)\).

Sufficiency. Suppose \(W\) maximizes utility, and consider any witness satisfying the modified hypotheses. Positive coalition mass means \(\lambda_\theta>0\). Moreover, \(\operatorname{cost}(T)/b\leq\lambda_\theta\leq1\), so \(T\) is feasible. The utility hypothesis and optimality imply
\(\sum_{c\in T}\alpha(c)\leq u_\theta(T)\leq u_\theta(W)\).
This is precisely the required conclusion.

Explicit reduction from SUBSET SUM

Take a SUBSET SUM instance consisting of positive integers \(a_1,\ldots,a_n\) and a positive integer target \(B\), all encoded in binary. Write \(A=\sum_{i=1}^n a_i\). Construct one type of mass \(1\), projects \(c_1,\ldots,c_n\), and set
\(\operatorname{cost}(c_i)=a_i\), \(u_\theta(c_i)=a_i/A\), and \(b=B\).

All utilities belong to \([0,1]\cap\mathbb{Q}\). The construction has polynomial encoding length: \(A\) has at most the maximum input-integer bit length plus \(\lceil\log_2 n\rceil+1\) bits.

By the characterization, every outcome satisfying the modified definition maximizes \(\sum_{c_i\in W}a_i\) subject to \(\sum_{c_i\in W}a_i\leq B\). Hence a subset summing to \(B\) exists if and only if the returned outcome has cost exactly \(B\).

A polynomial-time algorithm returning such an outcome would therefore decide SUBSET SUM in polynomial time, using one call and a polynomial-time check. This proves NP-hardness of the modified search task.

3. Conclusion

The literal definition is inconsistent because it permits an empty coalition. Adding the requirement of positive coalition mass removes this defect; for that modified definition, finding an outcome is NP-hard already with one type.
