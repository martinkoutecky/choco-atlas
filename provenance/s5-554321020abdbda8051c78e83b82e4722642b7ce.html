The continuous mirror question, as graded

Given finite projects \(C\), rational costs \(\operatorname{cost}(c)\), budget \(b>0\), finite complete additive valuation types \(\Theta\) with \(u_\theta:C\to[0,1]\cap\mathbb{Q}\), and rational population masses \(\mu\in\mathbb{Q}_{\geq 0}^{\Theta}\) satisfying \(\sum_\theta\mu_\theta=1\), output an integral project set \(W\subseteq C\) with \(\operatorname{cost}(W)\leq b\) satisfying mass-EJR: for every \(T\subseteq C\), \(\alpha:C\to[0,1]\), and subpopulation \(\lambda\in\mathbb{R}_{\geq 0}^{\Theta}\) with \(\lambda\leq\mu\), if \(\sum_\theta\lambda_\theta\geq\operatorname{cost}(T)/b\) and \(u_\theta(c)\geq\alpha(c)\) for every \(\theta\) with \(\lambda_\theta>0\) and every \(c\in T\), then some such \(\theta\) satisfies \(u_\theta(W)\geq\sum_{c\in T}\alpha(c)\).

Write \(\operatorname{cost}(A)=\sum_{c\in A}\operatorname{cost}(c)\) and \(u_\theta(A)=\sum_{c\in A}u_\theta(c)\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).
A feasible outcome \(W\subseteq C\) satisfies \(\operatorname{cost}(W)\leq b\). Result

Finding a feasible integral mass-EJR outcome is \(\mathrm{NP}\)-hard, already when \(\tau=1\). Thus no algorithm polynomial in \(m,\tau,L\) exists unless \(\mathrm{P}=\mathrm{NP}\).

The proof gives weak hardness directly for the specified mass formulation.

1. One supported type forces utility maximization

Suppose \(\Theta=\{\theta\}\) and \(\mu_\theta=1\). Write \(u=u_\theta\).

Lemma. A feasible outcome \(W\) satisfies mass-EJR if and only if \(W\) maximizes \(u(A)\) over all feasible \(A\subseteq C\).

Proof. First suppose \(W\) satisfies mass-EJR. Let \(T\subseteq C\) be any feasible set. Choose \(\lambda_\theta=1\) and \(\alpha(c)=u(c)\) for every \(c\in C\). These choices are admissible because \(u(c)\in[0,1]\). Moreover, feasibility gives \(\operatorname{cost}(T)/b\leq1=\lambda_\theta\), and the utility premise holds with equality.

There is only one supported type, so the mass-EJR conclusion is \(u(W)\geq\sum_{c\in T}u(c)=u(T)\). Since \(T\) was arbitrary, \(W\) maximizes feasible utility.

Conversely, suppose \(W\) maximizes feasible utility. Consider any \(T,\alpha,\lambda\) satisfying the mass-EJR premises. The positive subpopulation condition and \(\lambda\leq\mu\) give \(0<\lambda_\theta\leq1\). Hence \(\operatorname{cost}(T)/b\leq\lambda_\theta\leq1\), so \(T\) is feasible. Since \(\lambda_\theta>0\), the utility premise gives \(\alpha(c)\leq u(c)\) for every \(c\in T\). Consequently,
\(\sum_{c\in T}\alpha(c)\leq u(T)\leq u(W)\), which is precisely the required conclusion. This proves the lemma.

In particular, these instances always have a solution: the finite, nonempty family of feasible sets has a utility maximizer.

2. Reduction from SUBSET SUM

We use the standard \(\mathrm{NP}\)-complete SUBSET SUM problem: given positive integers \(a_1,\ldots,a_n\) and a positive target \(B\), encoded in binary, decide whether some subset sums exactly to \(B\). This is the classical exact-sum knapsack problem in [Karp’s completeness theorem](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Let \(M\) be a power of two satisfying \(M\geq\max_i a_i\). Construct:

  • Projects \(C=\{c_1,\ldots,c_n\}\), with \(\operatorname{cost}(c_i)=a_i\).
  • Budget \(b=B\).
  • One type \(\theta\), with mass \(\mu_\theta=1\).
  • Utilities \(u_\theta(c_i)=a_i/M\).

Every utility is a positive binary rational in \((0,1]\), so every project has positive utility for a supported type. All other input requirements also hold.

For every project set \(A\), we have \(u_\theta(A)=\operatorname{cost}(A)/M\). By the lemma, every feasible mass-EJR outcome \(W\) therefore maximizes \(\operatorname{cost}(W)\) subject to \(\operatorname{cost}(W)\leq B\).

Run the proposed search algorithm and answer YES exactly when its output satisfies \(\operatorname{cost}(W)=B\).

If the SUBSET SUM instance is YES, a feasible set has cost \(B\). Optimality and feasibility force the returned outcome to have cost exactly \(B\).

If the instance is NO, no project set has cost \(B\), so the returned outcome necessarily fails that equality.

Thus a single call to the search algorithm decides SUBSET SUM, regardless of which valid outcome it returns.

3. Encoding and running time

Let \(N\) denote the binary length of the SUBSET SUM instance. Choose \(M=2^k\), where \(k\) is the binary length of \(\max_i a_i\). Then \(k=O(N)\).

The construction has \(m=n\), \(\tau=1\), and total input length \(L=O(N^2)\): each utility numerator and denominator uses \(O(N)\) bits. Constructing the instance takes \(O(N^2)\) bit operations. Summing the returned costs and comparing with \(B\) takes \(O(m(L+\log m))\) bit operations.

An algorithm running in \(\operatorname{poly}(m,\tau,L)\) would consequently decide SUBSET SUM in polynomial time. This establishes the claimed search hardness. Strong hardness is not needed to settle the question.
