Result

For both \(\xi=\mathrm{card}\) and \(\xi=\mathrm{ws}\), the stated mass-based decision problem is \(\mathrm{NP}\)-complete. Hardness already holds when \(\tau=1\) and \(q=1\). Consequently, neither variant has a polynomial-time algorithm unless \(\mathrm P=\mathrm{NP}\).

Write \(N=|\mathcal A|\) and \(D=\sum_{t\in T}|R_t|\).

1. Hardness for both objectives

The supplied paper’s [Theorem 1](https://arxiv.org/pdf/2308.03376) proves \(\mathrm{NP}\)-completeness of the single-decision-maker problem for both objectives. Its hardness construction uses explicitly listed alternatives and comparisons \((A,\emptyset)\), with \(A\ne\emptyset\). These comparisons satisfy the present promise: the strict weak order placing all nonempty alternatives in one class above \(\emptyset\) contains every listed comparison.

The paper’s notation permits an empty interaction. Such an interaction contributes the same constant to every alternative, so deleting it preserves every comparison and does not increase either objective. Thus excluding empty interactions does not affect this hardness result.

For either objective, transform a single-decision-maker instance into the present problem by retaining its features, alternatives, comparisons, and budget, and introducing one type with those comparisons and mass \(1\). Set \(q=1\).

Any qualifying selection must contain this type. Its coefficient requirements and interaction budget are exactly those of the original instance. Therefore the transformation preserves both yes-instances and no-instances. It takes polynomial time and proves \(\mathrm{NP}\)-hardness for both variants.

Hardness also persists with genuine selection: set \(q=1/2\), give the original type mass \(3/4\), and introduce a second type with empty comparisons and mass \(1/4\). The second type alone cannot meet the threshold, whereas a compatible original type can.

2. Polynomial-size shared interaction certificates

The binary encoding of \(k\) requires care: simply guessing up to \(k\) interactions need not give a polynomial-size certificate. The following compression lemma resolves this.

Lemma. Every feasible instance has a feasible interaction set of cardinality at most \(\min\{k,D,N-1\}\), without increasing either objective.

Proof. Start with any feasible interaction set \(\theta\), selected types \(T'\), and their coefficients.

Construct a matrix \(C\) whose rows are all listed comparisons, retaining the type label, and whose columns are the interactions in \(\theta\). Define

\(C_{(t,A,B),S}=\mathbf 1[S\subseteq A]-\mathbf 1[S\subseteq B]\).

Choose a subset \(\theta_0\subseteq\theta\) whose columns form a basis of the column space of \(C\).

For each selected type \(t\), regard its coefficient vector \(v^t\) as indexed by all of \(\theta\). Because the columns indexed by \(\theta_0\) span those of \(C\), there exists a coefficient vector \(w^t\) on \(\theta_0\) satisfying

\(C_{\theta_0}w^t=Cv^t\).

In particular, every utility difference in a comparison belonging to type \(t\) is preserved. Thus the same types remain compatible with the common set \(\theta_0\). Taking a subset cannot increase either cost.

It remains to bound its size. Certainly \(\operatorname{rank}(C)\le D\). Also write \(C=HZ\), where

\(Z_{A,S}=\mathbf 1[S\subseteq A]\),

and each row of \(H\) has a \(1\) at its preferred alternative and a \(-1\) at its other alternative. Every row of \(H\) sums to zero. Hence \(\operatorname{rank}(H)\le N-1\), and consequently \(\operatorname{rank}(C)\le N-1\).

Finally, every interaction is nonempty, so \(|\theta|\le\xi(\theta)\le k\) for either objective. Therefore

\(|\theta_0|=\operatorname{rank}(C)\le\min\{k,D,N-1\}\).

This proves the lemma.

3. Polynomial-time verification and membership in \(\mathrm{NP}\)

A certificate consists only of a list of distinct nonempty interactions \(\theta\). By the lemma, a yes-instance has such a certificate with \(s=|\theta|\le\min\{k,D,N-1\}\), encoded using \(ms\) bits.

First check the interaction budget. Then determine separately whether each type is compatible.

For type \(t\), let \(C_t\) be the matrix of its comparison differences on \(\theta\). Compatibility means that \(C_tv>0\), coordinatewise. If \(R_t\ne\emptyset\), this is equivalent to the ordinary rational linear feasibility problem

\(C_tv\ge\mathbf 1\).

Indeed, a solution of the latter satisfies the strict inequalities. Conversely, if \(C_tv>0\), the minimum \(\delta\) of its finitely many coordinates is positive, and \(v/\delta\) satisfies \(C_t(v/\delta)\ge\mathbf 1\). A type with empty comparisons is automatically compatible.

These linear programs have unrestricted real variables and coefficients in \(\{-1,0,1\}\). Rational linear programming feasibility is decidable in polynomial bit time.

Let \(T_\theta\) be the set of compatible types. Because each type has independent coefficients, the largest achievable mass for this fixed interaction set is exactly

\(M(\theta)=\sum_{t\in T_\theta}\mu_t\).

Necessity follows because every selected type must belong to \(T_\theta\). Sufficiency follows by selecting all of \(T_\theta\) and choosing a feasible coefficient vector separately for each type. Thus the verifier accepts exactly when the budget holds and \(M(\theta)\ge q\).

The rational sum and threshold comparison can be performed exactly in polynomial time: a product of the input denominators has bit length at most the sum of their bit lengths.

For a certificate with \(s\) interactions, constructing all containment indicators takes \(O(mNs)\) time, and constructing the comparison matrices takes \(O(Ds)\) time. Including the linear programs and rational arithmetic, verification takes

\(O(mNs+Ds)+\operatorname{poly}\!\bigl(L+\tau+s+D(s+1)\bigr)\).

Since \(m,\tau,N,D\) are bounded by the explicit input length, and \(s\le\min\{k,D,N-1\}\), this is polynomial in \(L\). Both variants therefore belong to \(\mathrm{NP}\), completing the classification.

4. An explicit deterministic running-time bound

Set \(b=\min\{k,D,N-1\}\). Enumerate every interaction set of cardinality at most \(b\), discard those exceeding the chosen budget, and apply the preceding verifier. The compression lemma guarantees completeness.

There are \(2^m-1\) possible nonempty interactions. This gives a deterministic running-time bound

\(\displaystyle \left(\sum_{j=0}^{b}\binom{2^m-1}{j}\right)\operatorname{poly}(m,\tau,L,N,D)\le (b+1)2^{mb}\operatorname{poly}(m,\tau,L,N,D)\).

Here the numerical dependence on \(k\) enters through \(b\); its binary encoding is included in \(L\). If \(D=0\), the answer is immediately yes: the empty interaction set satisfies every type, giving total mass \(1\).
