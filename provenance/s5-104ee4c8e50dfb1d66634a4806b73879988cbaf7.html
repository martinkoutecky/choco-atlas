The continuous mirror question, as graded

Given a finite set \(J\) of item classes, ℓ layers, and a finite set \(T\) of preference types, where each type \(t\) has rational mass \(μ_t≥0\) with ∑_t μ_t=1 and a strict incomplete ranking of \(J\) in each layer, and each item class \(j\) has rational supply \(q_j\), does there exist a feasible allocation that is Pareto optimal in at least α layers? Represent the allocation by flows \(x_{t,j},x_{t,⊥}≥0\) with \(x_{t,⊥}+∑_{j∈J}x_{t,j}=μ_t\) and ∑_t x_{t,j}≤q_j\); it is Pareto optimal in a layer if no feasible measurable reassignment weakly improves almost every individual in that layer and strictly improves a positive mass.

Packaged proof task (what the prover saw — nothing else)

Let \(J\) be a finite set of \(m\) item classes with binary rational supplies \(q_j\geq0\), and let \(1\leq\alpha\leq\ell\) be integers. A society is given by its support: the list of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type represents an atomless population of mass \(\mu_t\) and has, in each layer \(r\), a strict ranking of an acceptable subset \(A_{t,r}\subseteq J\), possibly empty. The unassigned outcome \(\bot\) is below every acceptable item; unlisted items are forbidden in that layer. Let \(d=\max_{t,r}|A_{t,r}|\).
An allocation consists of real flows \(x_{t,j},x_{t,\bot}\geq0\) satisfying \(x_{t,\bot}+\sum_{j\in J}x_{t,j}=\mu_t\) and \(\sum_t x_{t,j}\leq q_j\). These flows partition each type's population among individual item outcomes and \(\bot\).
An allocation is legal in layer \(r\) if \(x_{t,j}=0\) whenever \(j\notin A_{t,r}\). It is Pareto optimal in that layer if it is legal and no feasible measurable reassignment, legal in that layer, weakly improves almost every individual and strictly improves a positive mass. Reassignments may exchange held items and use unused supply.

Is deciding whether one allocation is Pareto optimal in at least \(\alpha\) layers solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,L,\ell,\alpha,d\), where \(L\) is the total input bit length.

For finite agents and distinct unit-capacity items, this decision problem is para-NP-hard for both \(\ell+d\) and \(\ell+(m-d)\). [Steindl and Zehavi](https://arxiv.org/pdf/2004.00655v2).
No result settling this exact atomless, multiple-layer decision problem was located.

Modeling choices made when packaging the task

  • Specified nonnegative binary rational supplies; no normalization of total supply is imposed.
  • Restricted the support to positive masses and interpreted each type as an atomless population whose individuals receive single item outcomes.
  • Restored layer-specific legality: unlisted items are forbidden, and both the allocation and any dominating reassignment must be legal in each layer counted toward optimality; legality in other layers is not required.
  • Specified that the unassigned outcome is below every acceptable item, while empty acceptable sets remain permitted.
  • Restored the integer domain 1 <= alpha <= ell, defined d as the maximum acceptable-list length, and defined L as total input bit length.
  • Allowed real allocation flows and measurable reassignments that can exchange held items or consume unused supply.

Result and interpretation

I interpret the question as asking whether there exists an allocation that is Pareto optimal in at least \(\alpha\) layers.

This existence problem is \(\mathrm{NP}\)-complete. More precisely:

  • For \(\alpha=1\), every instance is a yes-instance, and a suitable allocation can be constructed in polynomial time.
  • For every fixed pair \(2\leq\alpha\leq\ell\), the problem is \(\mathrm{NP}\)-complete.
  • The atomless problem is para-\(\mathrm{NP}\)-hard for both \(\ell+d\) and \(\ell+(m-d)\).

The key is a rounding lemma: when masses and supplies have a common denominator, a common Pareto-optimal allocation can be rounded to that denominator while preserving optimality in every selected layer.

If an allocation is supplied as input, checking its optimality in the layers is polynomial-time solvable.

1. A characterization of Pareto optimality

Write \(\Omega=J\cup\{\bot\}\). For a feasible allocation \(x\), define the unused supply of item \(j\) by

\(\displaystyle s_j(x)=q_j-\sum_t x_{t,j}.\)

Fix a layer \(r\), and suppose \(x\) is legal in that layer. Define a directed graph \(G_r(x)\) on \(\Omega\). Include an arc \(a\to b\) precisely when some type \(t\) satisfies:

  • \(x_{t,a}>0\);
  • \(b\in A_{t,r}\);
  • type \(t\) strictly prefers \(b\) to \(a\) in layer \(r\).

There are no arcs into \(\bot\).

Lemma 1. A legal allocation \(x\) is Pareto optimal in layer \(r\) if and only if:

  • \(G_r(x)\) is acyclic;
  • every item with an incoming arc has exhausted supply.

Proof.

Suppose there is an arc \(a\to b\) with \(s_b(x)>0\), witnessed by type \(t\). Choose

\(\displaystyle 0<\varepsilon\leq\min\{x_{t,a},s_b(x)\}.\)

Atomlessness permits choosing a measurable subset of mass \(\varepsilon\) from the type-\(t\) individuals currently receiving \(a\). Give these individuals \(b\). This is a feasible strict improvement.

Next, suppose the graph contains a simple directed cycle

\(\displaystyle a_1\to a_2\to\cdots\to a_k\to a_1.\)

For each arc choose a witnessing type \(t_i\), and choose a positive \(\varepsilon\) no larger than every \(x_{t_i,a_i}\). Move mass \(\varepsilon\) from outcome \(a_i\) to outcome \(a_{i+1}\), with indices taken cyclically. The source groups are disjoint because the \(a_i\) are distinct. Each item loses and gains the same mass, and every moved individual strictly improves. Thus either obstruction contradicts Pareto optimality.

Conversely, suppose both conditions hold and a Pareto improvement exists. Let \(f_{ab}\) be the total mass of individuals whose outcome changes from \(a\) to \(b\). Retain only changes between distinct outcomes.

Strict rankings imply that every positive \(f_{ab}\) corresponds to an arc of \(G_r(x)\). Moreover, at least one \(f_{ab}\) is positive, because a positive mass strictly improves. For each item \(j\), feasibility of the reassignment gives

\(\displaystyle \sum_a f_{aj}-\sum_b f_{jb}\leq s_j(x).\)

If \(f_{ab}>0\), then \(b\) has an incoming graph arc, so \(s_b(x)=0\). The displayed inequality therefore implies

\(\displaystyle \sum_c f_{bc}\geq\sum_a f_{ab}>0.\)

Hence every vertex receiving positive reassignment flow also sends positive reassignment flow. Following such flows in a finite graph produces a directed cycle. This contradicts acyclicity. \(\square\)

This proof uses individual improvements directly; it does not replace them with an assumed welfare criterion.

2. Preserving optimality on a face

Let \(R\) be a collection of layers in which \(x\) is Pareto optimal. Consider all feasible allocations \(y\) satisfying

\(\displaystyle x_{t,a}=0\ \Longrightarrow\ y_{t,a}=0\)

and

\(\displaystyle s_j(x)=0\ \Longrightarrow\ s_j(y)=0.\)

Lemma 2. Every such \(y\) is Pareto optimal in every layer of \(R\).

Proof.

For each \(r\in R\), the zero-coordinate restrictions preserve legality and give

\(\displaystyle G_r(y)\subseteq G_r(x).\)

Thus \(G_r(y)\) is acyclic. Any item with an incoming arc in \(G_r(y)\) also has an incoming arc in \(G_r(x)\), so Lemma 1 says that it is exhausted under \(x\). The exhaustion restrictions make it exhausted under \(y\) as well. Lemma 1 now applies to \(y\). \(\square\)

The freedom to remove positive flows is important: exact preservation of the support is unnecessary.

3. Simultaneous rounding

Lemma 3. Suppose \(D\) is a positive integer such that every \(D\mu_t\) and \(Dq_j\) is an integer. If an allocation is Pareto optimal in every layer of \(R\), then there is such an allocation whose coordinates are all integer multiples of \(1/D\).

Proof.

Let \(x\) be the assumed allocation. Consider the polytope of variables \(z_{t,a}\) defined by

\(\displaystyle z_{t,a}\geq0,\qquad \sum_{a\in\Omega}z_{t,a}=D\mu_t,\qquad \sum_tz_{t,j}\leq Dq_j,\)

together with the restrictions

\(\displaystyle z_{t,a}=0\quad\text{whenever }x_{t,a}=0,\)

and

\(\displaystyle \sum_tz_{t,j}=Dq_j\quad\text{whenever }s_j(x)=0.\)

This polytope is nonempty because it contains \(Dx\). It is bounded because every coordinate is bounded by its type's row sum. Hence it has a vertex.

We show that every vertex is integral. Fix a vertex and eliminate its zero coordinates. The active type equations and item constraints must have full column rank on the remaining coordinates. Otherwise a nonzero vector in their common nullspace, multiplied by a sufficiently small positive or negative scalar, would preserve all constraints and contradict the vertex property.

Choose a square nonsingular matrix \(C\) of these active equations. Multiply item rows by \(-1\). Every column then has at most one entry \(+1\) and at most one entry \(-1\).

Every square submatrix of such a matrix has determinant in \(\{0,1,-1\}\). Indeed, induction applies if some column has at most one nonzero entry, by expansion along that column. Otherwise every column has exactly two opposite entries, so the sum of the rows is zero and the determinant vanishes.

Consequently, the nonsingular matrix \(C\) has determinant \(1\) or \(-1\). Its right-hand side is integral. Cramer's rule therefore makes all remaining coordinates integral.

Choose an integral vertex \(z\) and set \(y=z/D\). Lemma 2 proves that \(y\) is Pareto optimal in every layer of \(R\). \(\square\)

The lemma applies even if the original witness \(x\) has irrational coordinates.

4. Transferring finite-agent hardness

The finite problem has distinct unit-capacity items, strict possibly incomplete rankings, and the unassigned outcome below every acceptable item. Steindl and Zehavi prove hardness for every fixed pair \(2\leq\alpha\leq\ell\), and para-\(\mathrm{NP}\)-hardness for \(\ell+d\) and \(\ell+(m-d)\). These are Theorem 9 and Corollary 6 of their [paper](https://arxiv.org/pdf/2004.00655v2).

We give a polynomial reduction that preserves the relevant parameters.

Take a finite instance with \(n\) agents. Group agents having identical rankings in every layer. For each resulting type \(t\), let \(n_t\) be its number of agents, and set

\(\displaystyle \mu_t=\frac{n_t}{n},\qquad q_j=\frac1n.\)

Copy the rankings unchanged.

These masses are positive and sum to \(1\). The support size is the actual number of distinct profiles, so \(\tau\leq n\). The numbers \(m,\ell,\alpha,d\) are unchanged, and the added rational data have polynomial bit length.

We prove equivalence.

From a finite assignment to an atomless allocation.
Given a finite assignment \(p\), set

\(\displaystyle x_{t,a}=\frac{\#\{\text{agents of type }t\text{ receiving }a\text{ under }p\}}{n}.\)

Suppose \(p\) is Pareto optimal in layer \(r\). Its induced graph cannot have an arc into an unused item: the witnessing agent could take that item.

It also cannot contain a directed cycle. Each source item on a simple cycle has a unique owner. Since the source items are distinct, their owners are distinct, and exchanging the cycle items strictly improves every participating owner.

Thus the induced allocation satisfies Lemma 1 and is atomless Pareto optimal in layer \(r\). This holds simultaneously for every layer in which \(p\) is optimal.

From an atomless allocation to a finite assignment.
Suppose an atomless allocation is Pareto optimal in the layers \(R\). Apply Lemma 3 with \(D=n\). Obtain an allocation \(y\) such that

\(\displaystyle z_{t,a}=ny_{t,a}\)

is integral. Its row sums are \(n_t\), and each real item's column sum is at most \(1\).

Therefore these integer counts define a finite assignment: distribute the specified outcomes among the \(n_t\) agents of each type.

If that assignment admitted a Pareto improvement in a layer of \(R\), represent each finite agent by a measurable population block of mass \(1/n\). The same reassignment of blocks would weakly improve everyone and strictly improve positive mass in the atomless allocation \(y\). This contradicts its Pareto optimality.

The reduction is therefore correct. It proves general \(\mathrm{NP}\)-hardness and preserves both parameter hardness results.

5. Membership in \(\mathrm{NP}\)

Let \(D\) be the product of the denominators appearing in all masses and supplies. Its binary length is \(O(L)\), and it satisfies the hypotheses of Lemma 3.

Every yes-instance consequently has a witness \(x=z/D\), where all \(z_{t,a}\) are nonnegative integers. Since each coordinate is at most its type mass and the total population mass is \(1\),

\(\displaystyle 0\leq z_{t,a}\leq D.\)

Thus the allocation has an encoding of size

\(\displaystyle O\bigl(\tau(m+1)L\bigr).\)

A certificate also specifies \(\alpha\) successful layers. Verification consists of exact feasibility and legality checks, followed by Lemma 1 in those layers.

In one layer, graph construction requires at most \(O(\tau(d+1)^2)\) potential improvement arcs, in addition to inspecting the allocation and computing exhausted supplies. Acyclicity is checked by a graph search. All rational arithmetic has polynomial bit complexity.

The verifier therefore runs in

\(\displaystyle \operatorname{poly}\bigl(L+\tau(m+1)+\alpha\tau(d+1)^2\bigr).\)

Together with the reduction, this proves \(\mathrm{NP}\)-completeness.

6. Explicit deterministic running times

For arbitrary supplies, the following exact algorithm also gives a parameterized upper bound.

Enumerate:

  • a set \(R\) of \(\alpha\) layers;
  • a set \(S\subseteq J\) of items required to be exhausted;
  • for every \(r\in R\), a permutation \(\pi_r\) of the items.

Extend each permutation by \(\pi_r(\bot)=0\).

Allow a coordinate \(x_{t,a}\) only if it is legal in every selected layer and, for every \(r\in R\) and every item \(b\) preferred to \(a\),

\(\displaystyle b\in S\quad\text{and}\quad \pi_r(a)<\pi_r(b).\)

Set all other coordinates to zero. Test feasibility of the original flow constraints together with

\(\displaystyle \sum_tx_{t,j}=q_j\qquad(j\in S).\)

This is a rational linear program with \(\tau(m+1)\) variables.

Any feasible solution has acyclic improvement graphs, because their arcs follow the selected permutations. Every incoming-arc target lies in \(S\), hence is exhausted. Lemma 1 proves soundness.

Conversely, given a successful allocation, take its \(\alpha\) successful layers, its actual exhausted-item set, and topological orders of its improvement graphs. Because \(\bot\) has no incoming arcs, it can be placed first. These choices leave every positive coordinate allowed, so the corresponding linear program is feasible.

The running time is therefore

\(\displaystyle \binom{\ell}{\alpha}\,2^m(m!)^\alpha\, \operatorname{poly}\bigl(L+\tau(m+1)+\alpha\tau(d+1)^2\bigr).\)

In particular, this is fixed-parameter tractable in \(m+\ell\). It does not require expanding the populations into potentially exponentially many agents.

Finally, when \(\alpha=1\), choose any layer and maximize a linear utility objective assigning strictly increasing positive integer utilities along each type's acceptable ranking and utility \(0\) to \(\bot\). The legal feasible polytope is nonempty and bounded. Any measurable Pareto improvement would strictly increase this objective, so an optimizer is Pareto optimal. Construction takes

\(\displaystyle \operatorname{poly}\bigl(L+\tau(m+1)\bigr)\)

time; the existence decision itself always returns yes on valid input.
