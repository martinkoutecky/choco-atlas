The continuous mirror question, as graded

Given a finite set of data categories \(K\), distances \(d\), a finite support \(T\) of buyer types with rational masses \(\mu_t\), type parameters \(b_t,w_{tq},r_{tq}\), and per-capita supplies \(s_j\), define \(C_t(S)=\sum_{q\in K}w_{tq}\mathbf{1}[\exists j\in S:\ d(q,j)\le r_{tq}]\) for each integral bundle \(S\subseteq K\). Choose masses \(x_{t,S}\ge 0\) satisfying \(\sum_{S\subseteq K}x_{t,S}=\mu_t\) for each type and \(\sum_{t\in T}\sum_{S:j\in S}x_{t,S}\le s_j\) for each category. What is the complexity of maximizing \(\sum_{t\in T}\sum_{S\subseteq K}x_{t,S}b_tC_t(S)\) in \(|K|\), \(\tau=|T|\), and the input bit length?

Packaged proof task (what the prover saw — nothing else)

Let \(K\) be a nonempty set of data categories, with \(m=|K|\). Distances are supplied as a symmetric nonnegative rational matrix \(d\), with \(d(j,j)=0\); no triangle inequality is required.
A society is given by its support: the list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
Each type has nonnegative rational parameters \(b_t,w_{tq},r_{tq}\), with \(\sum_{q\in K}w_{tq}=1\). Each category has a nonnegative rational per-capita supply \(s_j\). Let \(L\) be the total binary input length.
For an integral bundle \(S\subseteq K\), define \(C_t(S)=\sum_{q\in K}w_{tq}\mathbf{1}[\exists j\in S:\ d(q,j)\le r_{tq}]\).
An allocation assigns nonnegative real masses \(x_{t,S}\) to bundles, including the empty bundle, subject to \(\sum_{S\subseteq K}x_{t,S}=\mu_t\) for every type and \(\sum_{t\in T}\sum_{S\subseteq K:j\in S}x_{t,S}\le s_j\) for every category. Each recipient receives an integral bundle; masses of recipients may be split among bundles.
The welfare is \(\sum_{t\in T}\sum_{S\subseteq K}x_{t,S}b_tC_t(S)\).

Is exact maximization of this welfare solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

Discrete welfare maximization with exclusive item allocation is NP-hard even with two buyers having buyer-specific constant radii, or three buyers sharing one radius, in both cases with uniform weights; it admits a polynomial-time \((1-1/e)\)-approximation. [Verified source](https://arxiv.org/html/2508.16007v2)
No result settling the exact mass-allocation problem above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to 1, so supplies and welfare are measured per capita.
  • Restored nonnegative bids and weights and the per-type weight normalization from the discrete model, excluding types with zero total weight.
  • Specified nonnegative rational radii, allowing radius zero as used by the hardness result.
  • Specified an explicitly encoded symmetric nonnegative rational distance matrix with zero diagonal; imposed no triangle inequality because the model allows general distance or similarity measures.
  • Specified nonnegative rational supplies, allowing zero and supplies exceeding 1; the latter are simply redundant capacities.
  • Required a nonempty category set and included the empty bundle, permitting recipients to receive nothing.
  • Used nonnegative real allocation masses while retaining integral bundles for each recipient; defined L to include all binary rational input data.

Result

Exact welfare maximization is \(\mathrm{NP}\text{-hard}\), already with \(\tau=2\), equal type masses, and a constant radius for each type. The reduction below even uses a distance matrix satisfying the triangle inequality.

The proof accounts explicitly for arbitrary mixtures of bundles.

1. Set Cover instance and construction

We reduce from Set Cover: given a universe \(U=\{u_1,\ldots,u_n\}\), sets \(A_1,\ldots,A_h\subseteq U\), and an integer \(k\), decide whether at most \(k\) sets cover \(U\). This problem is \(\mathrm{NP}\text{-complete}\). [Karp, *Reducibility among Combinatorial Problems*](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

We may restrict to \(n,h\ge 1\) and \(\bigcup_{i=1}^h A_i=U\): instances violating these conditions are decidable directly and can be replaced by fixed yes or no instances satisfying them.

Create two disjoint groups of categories:

\[ I=\{a_1,\ldots,a_h\},\qquad Q=\{q_1,\ldots,q_n\},\qquad K=I\cup Q. \]

Here \(a_i\) represents set \(A_i\), and \(q_\ell\) represents element \(u_\ell\). Set supplies to

\[ s_{a_i}=\frac12,\qquad s_{q_\ell}=0. \]

Define \(d(j,j)=0\). For distinct categories, set

\[ d(a_i,q_\ell)=d(q_\ell,a_i)= \begin{cases} 1,&u_\ell\in A_i,\\ 2,&u_\ell\notin A_i, \end{cases} \]

and set all remaining off-diagonal distances to \(2\).

This matrix is symmetric and nonnegative. It also satisfies the triangle inequality: for three distinct categories, the sum of two distances is at least \(2\), while the third distance is at most \(2\); repeated-category cases hold immediately.

Let \(B=h+1\). Introduce two types:

  • Type \(1\): \(\mu_1=\frac12\), \(b_1=Bn\), radius \(r_{1q}=1\) for every category, and weights \(w_{1q_\ell}=1/n\), \(w_{1a_i}=0\).
  • Type \(2\): \(\mu_2=\frac12\), \(b_2=h\), radius \(r_{2q}=0\) for every category, and weights \(w_{2a_i}=1/h\), \(w_{2q_\ell}=0\).

Both weight vectors sum to \(1\), and all parameters satisfy the task’s hypotheses.

2. Bundle valuations

Because each category in \(Q\) has zero supply, any feasible allocation assigns zero mass to every bundle containing such a category. Indeed, its supply constraint is a sum of nonnegative masses bounded above by zero. We therefore need consider only bundles \(S\subseteq I\).

Define

\[ a(S)=\left|\bigcup_{i:a_i\in S}A_i\right|. \]

For type \(1\), a query category \(q_\ell\) is covered precisely when some selected set contains \(u_\ell\). Consequently,

\[ b_1C_1(S)=Bn\frac{a(S)}n=B\,a(S). \]

For type \(2\), radius zero covers only selected categories themselves, since every off-diagonal distance is positive. Thus,

\[ b_2C_2(S)=h\frac{|S|}h=|S|. \]

The second type therefore has additive welfare equal to bundle size.

3. Exact optimum, allowing arbitrary mixtures

For any feasible allocation, let

\[ \alpha_i=\sum_{S\subseteq I:a_i\in S}x_{1,S}, \qquad \beta_i=\sum_{S\subseteq I:a_i\in S}x_{2,S}. \]

The supply constraints give \(\alpha_i+\beta_i\le\frac12\). Hence its welfare \(W\) satisfies

\[ \begin{aligned} W &=\sum_{S\subseteq I}x_{1,S}B\,a(S)+\sum_{i=1}^h\beta_i\\ &\le \frac h2+\sum_{S\subseteq I}x_{1,S}B\,a(S)-\sum_{i=1}^h\alpha_i\\ &=\frac h2+\sum_{S\subseteq I}x_{1,S}\bigl(B\,a(S)-|S|\bigr)\\ &\le \frac h2+\frac12\max_{S\subseteq I}\bigl(B\,a(S)-|S|\bigr). \end{aligned} \]

The third line uses \(\sum_i\alpha_i=\sum_Sx_{1,S}|S|\); the last uses \(\sum_Sx_{1,S}=\mu_1=\frac12\).

This upper bound is attained. Choose a maximizing bundle \(S^\star\), give all type \(1\) mass that bundle, and give all type \(2\) mass \(I\setminus S^\star\). Every item category consumes exactly \(\frac12\) supply, and the resulting welfare is

\[ \frac12B\,a(S^\star)+\frac12(h-|S^\star|). \]

Therefore the exact optimum is

\[ W^\star=\frac h2+\frac12\max_{S\subseteq I}\bigl(B\,a(S)-|S|\bigr). \]

In particular, mixing bundles cannot improve upon this expression.

4. Recovering the minimum cover size

Let \(c\) denote the minimum number of sets covering \(U\), which exists because their union is \(U\).

Every incomplete-cover bundle satisfies

\[ B\,a(S)-|S|\le B(n-1)=Bn-(h+1). \]

The full bundle \(I\), by contrast, satisfies

\[ B\,a(I)-|I|=Bn-h>Bn-(h+1). \]

Thus every maximizer in the preceding formula covers all of \(U\). Among full-cover bundles, maximizing \(Bn-|S|\) means minimizing \(|S|\). It follows that

\[ W^\star=\frac{h+Bn-c}{2}. \]

Set the welfare threshold to

\[ H=\frac{h+Bn-k}{2}. \]

Then

\[ W^\star\ge H \quad\Longleftrightarrow\quad c\le k. \]

The construction has \(m=n+h\) categories and two types. Its distance matrix has polynomial size, and all numerical parameters have polynomial binary encoding length. This is therefore a polynomial-time many-one reduction from Set Cover to the welfare-threshold problem.

Consequently, computing the exact maximum welfare is \(\mathrm{NP}\text{-hard}\); a polynomial-time exact algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

Verdict

The proof is correct and resolves the task: exact welfare maximization is \(\mathrm{NP}\)-hard, already with two types of equal mass and a constant radius for each type. The argument explicitly handles arbitrary mixtures of integral bundles. No major or minor mathematical issues were found.

Step-by-step verification

1. Source problem and restrictions

The stated Set Cover decision problem is the standard \(\mathrm{NP}\)-complete problem. Its use as the hardness source is justified by [Karp’s original paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

The restrictions \(n,h\geq 1\) and \(\bigcup_i A_i=U\) are legitimate. Instances outside these restrictions can be decided directly and replaced by fixed instances with the same answer satisfying the restrictions. This preprocessing requires no solution of a nontrivial Set Cover instance.

The union assumption guarantees that the minimum cover size \(c\) used later exists.

2. Validity of the constructed instance

Every constructed parameter meets the task’s requirements:

  • \(K=I\cup Q\) is nonempty, with \(m=n+h\).
  • Both masses are positive rationals and sum to \(1\).
  • Supplies, weights, radii, and benefit coefficients are nonnegative rationals.
  • Type \(1\)’s weights sum to \(n(1/n)=1\); type \(2\)’s weights sum to \(h(1/h)=1\).
  • Each type has a constant radius across all categories.
  • The distance matrix is symmetric, has zero diagonal, and has positive off-diagonal entries.

The stronger triangle-inequality claim is also correct. For three distinct categories, either side distance is at most \(2\), while the sum of the other two is at least \(2\). When categories repeat, the required inequality follows directly from symmetry, nonnegativity, and the zero diagonal.

3. Elimination of zero-supply categories

For each \(q_\ell\), its supply constraint is a finite sum of nonnegative variables bounded by zero. Every term in that sum must therefore vanish.

Consequently, every bundle containing any category of \(Q\) receives zero mass, for either type. Restricting all subsequent sums to \(S\subseteq I\) preserves the full feasible welfare calculation, including the empty bundle.

4. Bundle valuations

For type \(1\), a positively weighted query category \(q_\ell\) is within radius \(1\) of a selected category \(a_i\) exactly when \(u_\ell\in A_i\). Hence
\[ b_1C_1(S)=B\,a(S) \]
is correct.

For type \(2\), radius zero reaches only the selected categories themselves because all off-diagonal distances are positive. Its positively weighted categories are precisely \(I\), so
\[ b_2C_2(S)=|S| \]
is correct.

Both identities hold for every \(S\subseteq I\), including \(S=\varnothing\).

5. Upper bound for arbitrary mixtures

The marginal quantities \(\alpha_i\) and \(\beta_i\) correctly measure the masses of each type receiving category \(a_i\). Feasibility implies
\[ \alpha_i+\beta_i\leq \frac12. \]

Type \(2\)’s total welfare equals \(\sum_i\beta_i\), since its valuation is additive. Summing the supply inequalities therefore gives exactly the stated welfare upper bound.

The identity
\[ \sum_i\alpha_i=\sum_{S\subseteq I}x_{1,S}|S| \]
is valid by exchanging finite sums.

Finally, the coefficients \(x_{1,S}\) are nonnegative and sum to \(1/2\). Thus their weighted sum of \(B\,a(S)-|S|\) is at most one half of the maximum of that expression. This step applies to every feasible mixture; it makes no deterministic-allocation assumption.

6. Attainment of the upper bound

A maximizing bundle exists because there are finitely many subsets of \(I\).

Assigning mass \(1/2\) of type \(1\) to \(S^\star\) and mass \(1/2\) of type \(2\) to \(I\setminus S^\star\) satisfies both type-mass equalities. Each item category is assigned to exactly one of those two masses and therefore consumes exactly its supply \(1/2\). No zero-supply category is assigned.

The displayed welfare equals the upper bound. The claimed exact formula for \(W^\star\) follows, and mixtures cannot improve it.

7. Identification of minimum covers

If \(S\) is incomplete, integrality of \(a(S)\) gives \(a(S)\leq n-1\). Since \(|S|\geq0\),
\[ B\,a(S)-|S|\leq B(n-1)=Bn-(h+1). \]

The full bundle covers the universe and has value \(Bn-h\), strictly exceeding that bound. Therefore every maximizing bundle is a full cover.

For full covers, the expression is \(Bn-|S|\). Its maximum is consequently \(Bn-c\), exactly as claimed. Substitution yields
\[ W^\star=\frac{h+Bn-c}{2}. \]

The threshold equivalence \(W^\star\geq H\) if and only if \(c\leq k\) has the correct inequality direction and no additional restriction on \(k\) is needed.

8. Encoding and complexity conclusion

The construction has \((n+h)^2\) distance entries and two types. All parameters have polynomial binary encoding length; the threshold also has polynomial length, including the encoding of \(k\). The construction can be performed in polynomial time.

It is therefore a valid polynomial-time many-one reduction to the welfare-threshold problem. An algorithm computing the exact optimum would decide that threshold problem by exact comparison, establishing the claimed hardness of exact maximization.

Required clarification and feedback

None. The proof establishes the claimed hardness without relying on the discrete allocation result or assuming that fractional masses behave integrally.
