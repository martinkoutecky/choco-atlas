The continuous mirror question, as graded

Given a finite item set \(M\), budget \(q\), and rational distribution \(\mu\) over finitely many complete monotone submodular valuation types \(v_t:2^M\to\mathbb{Q}_{\ge 0}\), choose an integral project \(S\subseteq M\) with \(|S|\le q\) maximizing \(W_\mu(S)=\sum_t\mu_t v_t(S)\), or approximate its optimum within a specified factor.

Packaged proof task (what the prover saw — nothing else)

Let \(M\) be an item set with \(|M|=m\ge1\), and let \(q\in\{1,\ldots,m\}\). A society is given by its support: \(\tau\ge1\) distinct types with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type is a normalized monotone submodular valuation \(v_t:2^M\to\mathbb Q_{\ge0}\), with \(v_t(\varnothing)=0\). Its encoding consists of a relevant-item set \(D_t\subseteq M\) and an explicit rational table on \(2^{D_t}\), with \(v_t(S)=v_t(S\cap D_t)\). Let \(L\) be the total input bit length.
Choose an integral common project \(S\subseteq M\), \(|S|\le q\), maximizing \(W_\mu(S)=\sum_{t=1}^{\tau}\mu_t v_t(S)\). An \(\alpha\)-approximation returns such a project with value at least \(\alpha\max_{|T|\le q}W_\mu(T)\).

For each fixed \(0<\varepsilon<1/e\), does this problem admit a \((1-1/e+\varepsilon)\)-approximation in time polynomial in \(m,\tau,L,q\), or is achieving this ratio NP-hard?

For discrete combinatorial public projects, achieving \((1-1/e+\varepsilon)\) is NP-hard even when each valuation depends on a constant number of items; a \((1-1/e)\)-approximation is available using value queries. [Dobzinski–Vondrák](https://theory.stanford.edu/~jvondrak/data/submod-comm.pdf)

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, as required by a distribution.
  • Required valuations to vanish on the empty set, following the discrete valuation convention.
  • Resolved the missing valuation encoding using explicit tables on relevant-item sets; unrestricted table sizes allow general valuations while including the anchor's constant-size subclass.
  • Made the budget an integer between one and the number of items, excluding trivial budgets.
  • Selected the computational approximation threshold from the anchor, rather than its separate communication thresholds; restricted epsilon so the requested ratio is below one.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed \(0<\varepsilon<1/e\), achieving a \((1-1/e+\varepsilon)\)-approximation is \(\mathrm{NP}\)-hard. This holds even when every valuation has only zero and one as table entries and depends on a constant number of items.

Here, the constant may depend on \(\varepsilon\). The hardness concerns the full input family, with varying \(m,\tau,q\); special cases such as \(q=m\) are readily solvable.

Known hardness theorem

We use the computational part of Dobzinski–Vondrák’s Theorem 1.3. For every fixed \(\varepsilon>0\), approximating
\[ \max_{|S|\le q}\sum_{i=1}^{n}f_i(S) \]
within \(1-1/e+\varepsilon\) is \(\mathrm{NP}\)-hard, even for valuations
\[ f_i(S)=\min\{1,|S\cap D_i|\}, \]
where each \(D_i\) has size at most a constant \(d=d(\varepsilon)\). Section 5.2 establishes precisely this restriction: items represent sets in a maximum-coverage instance, and each player represents an element. Thus the valuations have explicit tables with entries in \(\{0,1\}\). [Dobzinski–Vondrák, Theorem 1.3 and Section 5.2](https://theory.stanford.edu/~jvondrak/data/submod-comm.pdf)

The remaining issue is to transfer this theorem to a society represented by distinct types and normalized rational masses.

Construction of the society

Fix a hard instance from the theorem, retaining its item set and budget.

Partition the player indices into classes \(C_1,\ldots,C_\tau\), putting two indices in the same class exactly when their relevant-item sets are equal. For each class, let \(D_t\) be its common relevant-item set, and define
\[ r_t=|C_t|,\qquad \mu_t=\frac{r_t}{n},\qquad v_t(S)=\min\{1,|S\cap D_t|\}. \]

We verify all required properties.

Distinct types. If \(D_t\ne D_u\), choose an item \(a\) in their symmetric difference. Exactly one of \(v_t(\{a\})\) and \(v_u(\{a\})\) equals one. Consequently, these are distinct valuation functions, and \(\tau\) is their actual support size.

Masses. Every class is nonempty, so \(\mu_t>0\). Since the classes partition the players,
\[ \sum_{t=1}^{\tau}\mu_t =\frac{\sum_{t=1}^{\tau}r_t}{n}=1. \]
Each mass has a binary rational encoding using \(O(\log(n+1))\) bits.

Valuations. Clearly, \(v_t(\varnothing)=0\), and \(v_t\) is nonnegative and monotone. To check submodularity, consider \(A\subseteq B\) and \(a\notin B\). The marginal value of adding \(a\) to a set \(X\) is one precisely when \(a\in D_t\) and \(X\cap D_t=\varnothing\); otherwise it is zero. If this marginal is one at \(B\), it is also one at \(A\). Hence marginal values decrease under inclusion, which is the diminishing-returns characterization of submodularity.

Moreover, \(v_t(S)=v_t(S\cap D_t)\), so the relevant-item representation is valid.

Encoding and construction time. Each table has at most \(2^d\) entries, all zero or one. Equal relevant-item sets can be grouped in polynomial time. Since \(d\) is fixed and \(\tau\le n\), the resulting total input length \(L\) is polynomial in the source instance’s length.

Exact preservation of approximation ratios

Write
\[ F(S)=\sum_{i=1}^{n}f_i(S) \]
for the source objective. For every project \(S\),
\[ W_\mu(S) =\sum_{t=1}^{\tau}\frac{r_t}{n}v_t(S) =\frac{1}{n}\sum_{i=1}^{n}f_i(S) =\frac{F(S)}{n}. \]

The feasible projects are identical in the two instances. Therefore their optimal values satisfy
\[ \operatorname{OPT}_{W} =\frac{\operatorname{OPT}_{F}}{n}. \]

Suppose an algorithm for the stated problem returns a feasible \(S\) satisfying
\[ W_\mu(S)\ge (1-1/e+\varepsilon)\operatorname{OPT}_{W}. \]
Multiplying by \(n\) gives
\[ F(S)\ge (1-1/e+\varepsilon)\operatorname{OPT}_{F}. \]

Thus the same project provides the forbidden approximation for the source problem. Because \(m,\tau,L,q\) are polynomially bounded in the source input length, an algorithm polynomial in these quantities would yield a polynomial-time algorithm contradicting the cited hardness theorem unless \(\mathrm{P}=\mathrm{NP}\).

Conclusion

The distinct-support requirement and the normalization of masses preserve the hardness: merging repeated valuations changes every project’s objective by the same positive factor. Therefore the requested approximation ratio is \(\mathrm{NP}\)-hard under the exact explicit-table encoding in the question.
