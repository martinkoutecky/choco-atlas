Result. Both problems are polynomial-time solvable, including construction of a coalition. For the prescribed dimension \(m=2\), an exact algorithm has the conservative bit-time bound \(O(m\tau^6L^2)\).

Moreover, the unweighted existence theorem stated in the question implies that every valid rational-mass input admits such a coalition. I prove this extension below; the algorithmic bound follows independently from an explicit finite search.

1. Reduce both norms to open squares

For \(\ell_\infty\), let \(T\) be the identity. For \(\ell_1\), define
\(T(a,b)=(a+b,a-b)\).
The identity
\(\max\{|a+b|,|a-b|\}=|a|+|b|\)
follows by considering whether \(a,b\) have the same sign. Consequently,
\(\|T(u)-T(v)\|_\infty=\|u-v\|_1\).

The map is invertible, with
\(T^{-1}(c,d)=((c+d)/2,(c-d)/2)\).
Thus freely placed challengers correspond bijectively under this transformation, and all strict comparisons are preserved.

Write \(q_p=T(p)\). Fix a nonempty coalition \(S\subseteq P\) of size at most three, and define
\(r_p(S)=\min_{s\in S}\|q_p-q_s\|_\infty\).

A transformed challenger \(z=T(x)\) captures \(p\) precisely when
\(\|z-q_p\|_\infty<r_p(S)\).
Equivalently, it belongs to the open square
\(B_p(S)=(q_{p,1}-r_p(S),q_{p,1}+r_p(S))\times(q_{p,2}-r_p(S),q_{p,2}+r_p(S))\).

If \(r_p(S)=0\), this square is empty, as required. In particular, members of \(S\) cannot themselves be captured.

The fixed-coalition problem is therefore to compute
\(F(S)=\sup_{z\in\mathbb R^2}\sum_{p:\,z\in B_p(S)}\mu_p\).

2. An exact finite set of challenger locations

For each coordinate \(j\in\{1,2\}\), form the set of boundary coordinates
\(E_j=\{q_{p,j}-r_p(S),q_{p,j}+r_p(S):p\in P\}\).
After removing duplicates, write its elements in increasing order as
\(e_{j,1}<\cdots<e_{j,k_j}\),
where \(1\leq k_j\leq2\tau\).

These endpoints partition the real line into singleton endpoints and the open intervals between consecutive endpoints, together with the two unbounded intervals. Choose one representative from each piece:
\(G_j=\{e_{j,i}:1\leq i\leq k_j\}\cup\{(e_{j,i}+e_{j,i+1})/2:1\leq i<k_j\}\cup\{e_{j,1}-1,e_{j,k_j}+1\}\).

There are \(2k_j+1\leq4\tau+1\) representatives.

For every type \(p\), membership in
\((q_{p,j}-r_p(S),q_{p,j}+r_p(S))\)
is constant on each piece of this partition: both endpoints of that interval belong to \(E_j\). This statement includes empty intervals and singleton partition pieces.

Hence, for every \(z\in\mathbb R^2\), choosing representatives \(g_j\in G_j\) from the pieces containing \(z_j\) gives
\(z\in B_p(S)\Longleftrightarrow(g_1,g_2)\in B_p(S)\)
for every \(p\in P\).

Every capture set is therefore realized at one of the \(O(\tau^2)\) grid locations, and
\(F(S)=\max_{g\in G_1\times G_2}\sum_{p:\,g\in B_p(S)}\mu_p\).

This proves that the supremum is attained and gives an exact computation. Coincident boundaries and distance ties require no perturbation: endpoint representatives are checked using the original strict inequalities.

3. Decision, construction, and bit complexity

Enumerate all nonempty subsets \(S\subseteq P\) with \(|S|\leq3\). For each:

  • Compute all radii \(r_p(S)\).
  • Construct the two representative sets \(G_1,G_2\).
  • Evaluate the captured mass at every location in \(G_1\times G_2\).
  • Return \(S\) if every evaluated mass is at most \(1/2\).

If all candidates fail, report that no qualifying coalition exists. Correctness follows from the exact formula for \(F(S)\) and exhaustive enumeration of the permitted coalitions.

There are
\(\sum_{h=1}^{\min\{3,\tau\}}\binom{\tau}{h}=O(\tau^3)\)
coalitions. For each coalition, radius computation takes \(O(m\tau)\) arithmetic operations, sorting takes \(O(\tau\log\tau)\) comparisons, and checking all grid locations against all types takes \(O(m\tau^3)\) operations. The total is \(O(m\tau^6)\) arithmetic operations for \(m=2\).

To verify the bit bound, first write each mass as
\(\mu_p=c_p/d_p\),
with positive integer denominator, and set
\(D=\prod_{p\in P}d_p\) and \(w_p=c_p(D/d_p)\).
These integers have \(O(L)\) bits: the sum of the input denominator lengths is at most \(L\), and \(0<w_p\leq D\).

At each grid location, compute the integer sum
\(W=\sum_{p:\,g\in B_p(S)}w_p\).
Then the exact acceptance test is \(2W\leq D\). All partial sums have \(O(L)\) bits because \(\sum_pw_p=D\).

Transformed coordinates, radii, endpoints, and grid representatives also have \(O(L)\)-bit rational representations. Each is obtained using a bounded number of additions, subtractions, absolute values, and divisions by two on input coordinates; taking a minimum selects an existing value. Rational comparisons can therefore be performed by cross multiplication in \(O(L^2)\) bit operations using schoolbook integer arithmetic.

Including preprocessing, the resulting bit-time bound is
\(O(m\tau^6L^2)\), with \(m=2\).
The algorithm operates directly on the \(\tau\) support locations and their encoded masses.

4. The stated unweighted theorem also guarantees weighted existence

The unweighted result supplied in the question states that every nonempty finite planar point set has a nonempty defending subset of size at most three against every freely placed challenger under either norm. This is [Theorem 5.7 of de Azevedo and Hennebelle](https://arxiv.org/html/2608.27653v1).

Here is a replication-and-limit proof extending that statement to the present rational masses.

Choose a positive integer \(N\) such that
\(n_p=N\mu_p\)
is a positive integer for every \(p\). Then \(\sum_pn_p=N\).

For each positive integer \(k\), replace each \(p\) by \(n_p\) distinct points
\(v_{p,1}^{(k)},\ldots,v_{p,n_p}^{(k)}\)
satisfying
\(\|v_{p,i}^{(k)}-p\|_\ell<1/k\).
Choose all \(N\) points distinct. This is possible because every norm ball of positive radius contains infinitely many points.

Apply the unweighted theorem to this finite set \(V_k\). Its hypotheses hold: \(V_k\) is a nonempty set of distinct planar locations, defenders are selected from \(V_k\), and challengers are freely placed. Obtain a nonempty coalition \(Q_k\subseteq V_k\) of size at most three whose captured count never exceeds \(N/2\).

Let \(S_k\subseteq P\) consist of the original types corresponding to members of \(Q_k\). It is nonempty and has size at most three. There are only finitely many possible \(S_k\), so some fixed set \(S\) occurs for infinitely many indices \(k\).

Suppose, for contradiction, that a challenger \(x\) captures a set \(A\subseteq P\) against \(S\) with
\(\sum_{p\in A}\mu_p>1/2\).
Because \(A,S\) are finite and every capture comparison is strict,
\(\gamma=\min_{p\in A,\,s\in S}\bigl(\|p-s\|_\ell-\|p-x\|_\ell\bigr)>0\).

Choose an index with \(S_k=S\) and \(3/k<\gamma\). For every copy \(v\) of a type \(p\in A\) and every defender \(q\in Q_k\) corresponding to \(s\in S\), the triangle inequality gives
\(\|v-x\|_\ell<\|p-x\|_\ell+1/k\)
and
\(\|v-q\|_\ell>\|p-s\|_\ell-2/k\).
Therefore,
\(\|v-q\|_\ell-\|v-x\|_\ell>\gamma-3/k>0\).

Thus \(x\) captures every copy of every type in \(A\) against \(Q_k\). The captured count is at least
\(\sum_{p\in A}n_p=N\sum_{p\in A}\mu_p>N/2\),
contradicting the choice of \(Q_k\).

Hence \(S\) satisfies the required weighted guarantee. This argument permits ties in the original society: a hypothetical violation supplies the positive strict margin used above.

The replication is solely an existence proof; \(N\) may be exponentially large. The polynomial algorithm in Sections 1–3 searches the original support and returns a valid coalition.
