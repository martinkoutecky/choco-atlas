Theorem 1 — class: other

The continuous mirror question, as graded

Given a finite set of location types \(T\), rational masses \(\mu_t>0\) summing to \(1\), a source \(0\), and a nonnegative symmetric link-cost matrix \(C\) on \(\{0\}\cup T\), with zero cost between residents of the same type, compute a minimum-cost spanning tree on the support and the mass-weighted Borůvka allocation \(a_t\), where \(\mu_t a_t\) is type \(t\)’s total contribution. Determine whether the allocation is independent of arc order and equals the limit of the discrete folk allocations when each type is replicated in proportion to \(\mu_t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) location types with positive binary rational masses \(\mu_t\), summing to \(1\). The support size \(\tau\) counts listed types, not possible types. Let \(V=\{0\}\cup T\), with source \(0\notin T\), and let \(C\) be a nonnegative symmetric rational cost matrix with zero diagonal. Residents of the same type have zero mutual link cost; other resident and source costs are inherited from \(C\). Write \(m=|V|\) and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
For a total order \(\pi\) of undirected edges, construct \(H^\pi\) by Borůvka’s algorithm, with only components excluding the source selecting edges and ties resolved by \(\pi\).
Define the mass allocation as follows. Initially \(r_e=0\) for every \(e\in H^\pi\), including zero-cost edges, and \(a_t^\pi=0\). At each stage, form components of the edges with \(r_e=1\). Each component excluding the source selects its cheapest outgoing edge, breaking ties by \(\pi\); assign that edge \(b_t\) to every type in the component. Types in the source component are inactive.
Set \(w_e=\sum_{t:b_t=e}\mu_t\) and \(p=\min_{e:w_e>0}(1-r_e)/w_e\). Update \(r_e\leftarrow r_e+p w_e\) and \(a_t^\pi\leftarrow a_t^\pi+pC_{b_t}\) for active types; repeat until every tree edge has \(r_e=1\). Type \(t\)'s total contribution is \(\mu_t a_t^\pi\).
For a finite resident set \(N\) with costs \(D\), define its discrete folk allocation \(\varphi\) as the Shapley value of the cost game whose coalition cost is the minimum spanning tree cost on \(S\cup\{0\}\) under \(D^*\), where \(D^*_{ij}=\min_{P:i\leadsto j}\max_{e\in P}D_e\), paths use all of \(N\cup\{0\}\), and the empty coalition costs zero.
For each positive integer \(n\) with all \(n\mu_t\) integral, let \(N_t^{(n)}\) contain \(n\mu_t\) residents of type \(t\), and let \(\varphi^{(n)}\) be their discrete folk allocation with inherited costs.

Is exact computation of \(H^\pi\) and \(a^\pi\) polynomial-time in \(m,\tau,L\), or NP-hard?
For every such instance, is \(a^\pi\) independent of \(\pi\), and does \(\mu_t a_t^\pi=\lim_{n\to\infty}\sum_{i\in N_t^{(n)}}\varphi_i^{(n)}\) hold for every \(t\), along the admissible integers \(n\), or can either property fail?

For finite agents, the Borůvka allocation with unit resident weights is independent of edge order and equals the discrete folk allocation ([Bergantiños–Vidal-Puga](https://vidalpuga.webs.uvigo.es/papers/cstapproaches.pdf)). The folk allocation also has the stated irreducible-game Shapley definition ([Trudeau–Vidal-Puga](https://vidalpuga.webs.uvigo.es/papers/shapleycst.pdf)).
No result settling this exact mass procedure and replication limit was located in the literature search.

  • Defined the unspecified mass-weighted Borůvka procedure by replacing the number of assigned residents with their total mass in the common payment increment and edge-payment update.
  • Used a single total edge order for tie-breaking, excluded the source component from selection and payment, and merged components only through fully paid edges, including zero-cost edges.
  • Defined the discrete folk allocation through its irreducible-game Shapley representation to make the replication comparison self-contained.
  • Interpreted proportional replication as exact counts along integers clearing the mass denominators, and compared total contributions by type; equivalently, per-unit-mass allocations correspond to population-scaled individual contributions.
  • Defined the otherwise unspecified size parameter m as the number of support vertices including the source, and L as total binary input length.

1. Result

Exact computation of \(H^\pi\) and \(a^\pi\) is polynomial-time solvable in \(m,\tau,L\).

However, both proposed invariance properties can fail. A two-type instance with unequal masses and equal positive link costs gives different allocations for different edge orders, and one of those allocations differs from the replication limit.

The proofs below use the procedures and Shapley definition in the question directly.

2. The mass procedure is well-defined and has at most \(\tau\) stages

Order all edges lexicographically by \((C_e,\pi(e))\), so every edge has a distinct position. Let \(K\) be the tree obtained by scanning edges in this order and retaining an edge whenever its endpoints are in different current components.

The resulting graph is acyclic by construction. It is connected: if two final components remained, an edge between them would have joined different components when scanned and therefore would have been retained. Thus \(K\) is a spanning tree.

We first establish a cut property. For any nonempty proper subset \(S\subset V\), its first outgoing edge \(e\) in the lexicographic order belongs to \(K\). Indeed, if \(e\) were rejected, its endpoints would already be connected by retained edges preceding \(e\). That connecting path must cross the cut of \(S\), contradicting the choice of \(e\).

Consequently, every edge selected during the specified Borůvka construction belongs to \(K\). Its evolving graph is therefore a forest. Whenever it is disconnected, a component excluding the source selects an edge crossing its boundary, adding at least one new edge. After at most \(\tau=m-1\) rounds it is connected, and hence its final tree satisfies \(H^\pi=K\).

The same cut property applies during the mass procedure: every component’s selected edge belongs to \(H^\pi\), even if the minimum is sought over the full cost matrix.

At any unfinished stage, the saturated edges form a disconnected subforest of \(H^\pi\). Every component excluding the source contains a type and therefore has positive mass. Its selected outgoing edge is unsaturated, since a saturated edge would connect vertices in the same saturated component. Thus:

  • Some edge has \(w_e>0\).
  • Every edge with \(w_e>0\) has \(r_e<1\).
  • The prescribed \(p\) is positive, preserves \(r_e\leq 1\), and makes at least one previously unsaturated edge satisfy \(r_e=1\).

There are only \(\tau\) tree edges, so the procedure terminates after at most \(\tau\) stages. This argument includes zero-cost edges: their costs do not affect saturation.

For completeness, the procedure also satisfies the accounting identity

\(\displaystyle \sum_{t\in T}\mu_t a_t^\pi=\sum_{e\in H^\pi}C_e.\)

Both sides start at zero if the right side is temporarily written as \(\sum_e C_e r_e\). In one stage their respective increments are \(p\sum_t\mu_t C_{b_t}\) and \(p\sum_e w_e C_e\), which are equal by the definition of \(w_e\).

3. Exact arithmetic has polynomial bit complexity

The stage bound alone does not establish polynomial running time; we must bound intermediate rational sizes.

Write every mass as \(\mu_t=q_t/Q\), using \(Q\) equal to the product of the input mass denominators. Then \(q_t\) are positive integers, \(\sum_t q_t=Q\), and \(\log_2 Q=O(L)\).

Likewise, let \(R\) be the product of the denominators of costs on \(H^\pi\), and write \(C_e=k_e/R\) with integer \(k_e\). We have \(\log_2 R=O(L)\).

Maintain integer representations

\(\displaystyle r_e=\frac{x_e}{D},\qquad a_t^\pi=\frac{Q A_t}{R D},\)

initially with \(D=1\) and all numerators zero. At a stage, write \(w_e=W_e/Q\), where \(W_e\) is an integer satisfying \(0\leq W_e\leq Q\).

Choose an edge \(f\) minimizing \((D-x_e)/W_e\) among edges with \(W_e>0\), and put \(u=D-x_f\) and \(v=W_f\). Then

\(\displaystyle p=\frac{Q u}{D v}.\)

The exact updates can be performed entirely with integers:

\(\displaystyle D'=Dv,\qquad x'_e=vx_e+uW_e.\)

For an active type, set \(A'_t=vA_t+u k_{b_t}\); for an inactive type, set \(A'_t=vA_t\). Substitution into the representations verifies both prescribed updates.

Since each stage multiplies \(D\) by an integer at most \(Q\), and there are at most \(\tau\) stages,

\(\displaystyle D\leq Q^\tau.\)

Also, \(0\leq x_e\leq D\). Since \(p\leq Q\), each allocation satisfies \(0\leq a_t^\pi\leq \tau Q C_{\max}\), where \(C_{\max}\) is the largest input cost. Consequently, every integer just described has bit length

\(\displaystyle B=O\bigl((\tau+1)L+\log m\bigr).\)

A direct implementation scans the \(O(m^2)\) edges in each Borůvka round and allocation stage to identify component minima. Component construction, mass aggregation, comparisons, and updates fit within \(O(m^2)\) integer operations per round or stage. Representing \(\pi\) by edge ranks also fits within the stated bound.

Using schoolbook integer arithmetic gives the conservative bit-operation bound

\(\displaystyle O\!\left(\tau m^2\bigl((\tau+1)L+\log m\bigr)^2\right).\)

Thus exact computation is polynomial in the requested parameters; it does not require constructing a replicated population.

4. One instance refutes both universal properties

Take \(T=\{1,2\}\), masses \(\mu_1=3/4\), \(\mu_2=1/4\), and costs

\(\displaystyle C_{01}=C_{02}=C_{12}=1,\qquad C_{ii}=0.\)

First consider the edge order \(\pi_{\mathrm{s}}\) given by \(\{0,1\}\prec\{0,2\}\prec\{1,2\}\). Both singleton type components select their source edges, so

\(\displaystyle H^{\pi_{\mathrm{s}}}=\{\{0,1\},\{0,2\}\}.\)

The first allocation stage has weights \(w_{01}=3/4\) and \(w_{02}=1/4\), giving \(p=4/3\). It saturates \(\{0,1\}\), leaves \(r_{02}=1/3\), and gives both types allocation \(4/3\).

Type \(1\) is then inactive. The remaining stage has

\(\displaystyle p=\frac{1-1/3}{1/4}=\frac83.\)

Therefore,

\(\displaystyle (a_1^{\pi_{\mathrm{s}}},a_2^{\pi_{\mathrm{s}}})=\left(\frac43,4\right),\qquad (\mu_1a_1^{\pi_{\mathrm{s}}},\mu_2a_2^{\pi_{\mathrm{s}}})=(1,1).\)

Now consider \(\pi_{\mathrm{r}}\), given by \(\{1,2\}\prec\{0,1\}\prec\{0,2\}\). Both singleton types first select \(\{1,2\}\), and their merged component subsequently selects \(\{0,1\}\). Hence

\(\displaystyle H^{\pi_{\mathrm{r}}}=\{\{1,2\},\{0,1\}\}.\)

In the first allocation stage, \(w_{12}=\mu_1+\mu_2=1\), so \(p=1\). Both types receive allocation \(1\), and the resident edge saturates. In the second stage, their merged component selects \(\{0,1\}\), again with weight \(1\) and \(p=1\).

Thus,

\(\displaystyle (a_1^{\pi_{\mathrm{r}}},a_2^{\pi_{\mathrm{r}}})=(2,2),\qquad (\mu_1a_1^{\pi_{\mathrm{r}}},\mu_2a_2^{\pi_{\mathrm{r}}})=\left(\frac32,\frac12\right).\)

The allocation \(a^\pi\) therefore depends on \(\pi\).

5. The replicated folk allocation for this instance

The admissible population sizes are precisely the positive multiples of \(4\). For each such \(n\), there are \(3n/4\) residents of type \(1\) and \(n/4\) residents of type \(2\).

In the inherited resident matrix, same-type costs are zero, while different-type and source costs are one. Its irreducible matrix \(D^*\) has exactly these same values:

  • A direct same-type edge gives bottleneck value zero.
  • Every path between different types, or between the source and a resident, contains a cost-one edge. A direct edge achieves bottleneck value one.

For any coalition \(S\), let \(k\) be the number of types represented in \(S\). The zero-cost graph on \(S\cup\{0\}\) has exactly \(k+1\) components: one for each represented type and one for the source. Every spanning tree therefore needs at least \(k\) cost-one edges. Connecting one resident of each represented type to the source, and connecting its remaining residents by zero-cost edges, achieves cost \(k\).

The coalition cost game is consequently

\(\displaystyle v(S)=\mathbf{1}_{S\cap N_1^{(n)}\neq\varnothing}+\mathbf{1}_{S\cap N_2^{(n)}\neq\varnothing}.\)

A resident’s marginal cost in a permutation is one exactly when that resident is the first member of its type to appear; otherwise it is zero. Among the \(n\mu_t\) residents of type \(t\), each is equally likely to appear first. The Shapley allocation therefore satisfies

\(\displaystyle \varphi_i^{(n)}=\frac{1}{n\mu_t}\quad\text{for }i\in N_t^{(n)}.\)

It follows, for every admissible \(n\), that

\(\displaystyle \sum_{i\in N_t^{(n)}}\varphi_i^{(n)}=1.\)

Both replication limits equal one. Under \(\pi_{\mathrm{r}}\), however, the mass contributions are \(3/2\) and \(1/2\). Thus the proposed equality fails for both types.

This does not contradict the [finite-agent Borůvka theorem](https://vidalpuga.webs.uvigo.es/papers/cstapproaches.pdf), which concerns unit resident weights. Replacing those weights by type masses in the stated procedure can change the allocation, as the explicit calculations show.

1. The tree construction

The auxiliary tree \(K\) is well-defined because ordering edges by \((C_e,\pi(e))\) gives a strict total order.

The acyclicity and connectivity arguments are correct. In particular, if two final components remained, an edge between them would also have joined different components when scanned, so it would have been retained.

The cut property is correctly proved: rejection of the first edge crossing a cut would require an already-retained path between its endpoints. That path must contain an earlier edge crossing the same cut, a contradiction.

Every Borůvka selection is the first edge crossing its component’s cut in this order, so it belongs to \(K\). Consequently:

  • Simultaneous selections cannot introduce a cycle.
  • Whenever the evolving forest is disconnected, at least one component excluding the source exists and selects a new edge.
  • There are only \(\tau=m-1\) possible tree edges to add.

Thus the construction terminates within \(\tau\) rounds. Its final connected spanning subgraph of \(K\) must equal \(K\), establishing \(H^\pi=K\).

The same cut property correctly places every selected edge in \(H^\pi\), including when outgoing edges are considered in the full graph.

At an unfinished stage, the saturated edges cannot form a connected graph: a connected spanning subgraph of a tree contains every tree edge. Therefore a component excluding the source exists. Such a component contains at least one type and has strictly positive mass.

A selected outgoing edge is unsaturated because a saturated edge’s endpoints lie in the same saturated component. Hence every denominator used in defining \(p\) is positive, and every corresponding numerator is strictly positive.

The update preserves \(0\leq r_e\leq1\), saturates at least one new edge, and never decreases any \(r_e\). The bound of at most \(\tau\) stages follows. Zero-cost edges cause no exception because their costs do not enter the saturation rule.

The bounds \(1\leq v\leq Q\), \(D\leq Q^\tau\), and \(0\leq x_e\leq D\) are justified. Since a positive edge weight is at least \(1/Q\), the inequality \(p\leq Q\) holds. Consequently, the allocation and numerator bounds yield the claimed intermediate bit length
