The continuous mirror question, as graded

Given a finite set of complete exchange types \(T\), rational masses \(\mu_t\) summing to \(1\), compatible type pairs with rational country-utility contributions \(a^p_{ts}\), and a rational target allocation \(x\), choose exchange masses \(y_{ts}\ge 0\). Require \(\sum_{s\ne t} y_{ts}+2y_{tt}\le\mu_t\) for each type \(t\). Maximize total exchange welfare \(W(y)=\sum_{t\le s}(\sum_{p\in P}a^p_{ts})y_{ts}\), then among maximizers minimize \(\max_{p\in P}|x_p-\sum_{t\le s}a^p_{ts}y_{ts}|\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types; \(\sum_{t\in T}\mu_t=1\). There are two countries, \(P=\{1,2\}\), and \(m=|P|=2\), each owning positive mass.
Each complete type records its country \(c(t)\), compatibility, and transplant utilities with every support type. Compatibility is symmetric and explicitly listed as unordered pairs \(E\), possibly including \(\{t,t\}\). For each compatible pair, the utility \(q_{ts}\in\mathbb Q_{>0}\) of a transplant from type \(t\) to type \(s\) is specified in each direction. Set \(a^p_{ts}=q_{st}\mathbf1_{c(t)=p}+q_{ts}\mathbf1_{c(s)=p}\).
Choose real exchange masses \(y_{ts}=y_{st}\ge0\), one variable per compatible unordered pair, with incompatible variables zero and \(\sum_{s\ne t}y_{ts}+2y_{tt}\le\mu_t\) for every \(t\). A diagonal exchange uses two distinct individuals of the same type; unused mass is allowed.
Define \(u_p(y)=\sum_{\{t,s\}\in E}a^p_{ts}y_{ts}\), \(W(y)=\sum_{p\in P}u_p(y)\), and \(W^*=\max_y W(y)\) over feasible exchanges. The input target \(x\in\mathbb Q^P\) satisfies \(\sum_p x_p=W^*\); its coordinates may be negative. Compute a feasible exchange allocation maximizing \(W(y)\) and, among such allocations, minimizing \(\max_{p\in P}|x_p-u_p(y)|\). Any minimizer is acceptable. All rational input data are encoded in binary; \(L\) is the total input bit length.

For finite patient–donor pools, minimizing the maximum country deviation among maximum-welfare two-way exchanges is NP-hard even with two countries. [Verified discrete result](https://link.springer.com/article/10.1007/s10107-025-02200-9).

Result

The continuous problem is polynomial-time solvable in \(m,\tau,L\), with an exact rational optimum. Under the promised equality \(\sum_p x_p=W^*\), a single rational linear program suffices. The argument also works for any explicitly listed number of countries.

1. The feasible exchange polytope

Let \(n=|E|\). Use one variable \(y_e\) for each compatible unordered pair \(e\), including diagonal pairs.

Define the incidence matrix \(A\in\{0,1,2\}^{\tau\times n}\) by counting endpoints with multiplicity: \(A_{te}=1\) when \(e\) is a nondiagonal pair incident to \(t\), \(A_{te}=2\) when \(e=\{t,t\}\), and \(A_{te}=0\) otherwise. The feasible exchanges are exactly

\[ K=\{y\in\mathbb R^n:Ay\le\mu,\ y\ge0\}. \]

Thus the factor of two for diagonal exchanges is incorporated explicitly.

The set \(K\) contains the zero vector and is closed. Every column of \(A\) sums to two, so every \(y\in K\) satisfies

\[ 2\sum_{e\in E}y_e =\sum_{t\in T}(Ay)_t \le\sum_{t\in T}\mu_t =1. \]

Consequently \(K\) is bounded and hence compact. This also covers \(E=\varnothing\), when there is only the empty exchange allocation.

For each country \(p\), write \(a^p_e\) for the utility coefficient given in the question, and set \(w_e=\sum_p a^p_e\). Then

\[ u_p(y)=\sum_{e\in E}a^p_e y_e, \qquad W(y)=\sum_{e\in E}w_e y_e. \]

These are rational linear functions. In particular, the maximum defining \(W^*\) is attained.

2. A linear program for the requested optimum

Compute the rational number \(X=\sum_p x_p\). By the input promise, \(X=W^*\). Therefore the nonempty set

\[ F=\left\{y\in K:\sum_{e\in E}w_e y_e=X\right\} \]

is exactly the set of maximum-welfare exchanges.

For \(y\in F\), define \(d(y)=\max_p|x_p-u_p(y)|\). All utility coefficients are nonnegative, so

\[ 0\le u_p(y)\le\sum_r u_r(y)=X. \]

Since the zero exchange is feasible, \(X=W^*\ge0\). Hence, with the rational bound \(B=X+\max_p|x_p|\), every \(y\in F\) satisfies \(d(y)\le B\).

Introduce one real variable \(\delta\) and solve the following linear program:

\[ \begin{aligned} \text{minimize}\quad &\delta\\ \text{subject to}\quad &Ay\le\mu,\\ &y_e\ge0 &&(e\in E),\\ &\sum_{e\in E}w_e y_e=X,\\ &x_p-\sum_{e\in E}a^p_e y_e\le\delta &&(p\in P),\\ &\sum_{e\in E}a^p_e y_e-x_p\le\delta &&(p\in P),\\ &0\le\delta\le B. \end{aligned} \]

This linear program is feasible: choose any \(y\in F\) and set \(\delta=d(y)\). Its feasible region is closed and bounded, so its minimum is attained.

Correctness. Every feasible pair \((y,\delta)\) has \(y\in F\), and the two deviation inequalities for each country imply \(d(y)\le\delta\). Conversely, for every \(y\in F\), the pair \((y,d(y))\) is feasible. It follows that the linear-program optimum equals \(\min_{y\in F}d(y)\), and the exchange component of any optimal solution is a requested allocation.

Negative coordinates of \(x\) cause no difficulty: neither the absolute-value linearization nor its correctness assumes \(x_p\ge0\).

3. Polynomial bit complexity and exact output

We apply the standard rational linear-programming theorem: an explicitly represented linear program with rational coefficients can be solved exactly in time polynomial in its binary encoding length, returning a rational optimal solution when an optimum exists. This theorem includes equality constraints and feasible regions of lower dimension. See [Theorem 17.1 and the discussion of removing dimensionality assumptions](https://courses.cs.washington.edu/courses/cse521/22au/521-lecture-16.pdf).

Its hypotheses hold here:

  • There are \(n+1\) variables, where \(n\le\tau(\tau+1)/2\).
  • Counting an equality as two inequalities, there are \(n+\tau+2m+4\) inequalities.
  • Every coefficient is rational. Each \(a^p_e\) is a sum of at most two input utilities, and each \(w_e=q_{ts}+q_{st}\), including \(w_{\{t,t\}}=2q_{tt}\).
  • Computing \(X\), \(B\), and all coefficients uses rational arithmetic with polynomial bit length. Consequently the complete linear-program encoding has size polynomial in \(m,\tau,L\).
  • Feasibility and attainment were proved above.

For completeness, exact output does not require exponentially many bits. A nonempty bounded rational polyhedron has an optimal vertex for a linear objective. At such a vertex, \(n+1\) linearly independent active constraints determine the coordinates. Clearing denominators gives an integer system of polynomial bit length. If its entries have absolute value at most \(H\), each determinant in Cramer’s rule has absolute value at most \((n+1)!\,H^{n+1}\). Thus every output numerator and denominator has polynomial bit length.

The algorithm therefore constructs the displayed program, solves it using an exact polynomial-time rational linear-programming algorithm, and returns its exchange coordinates.

4. Relation to the discrete hardness result

The cited [discrete hardness theorem](https://link.springer.com/article/10.1007/s10107-025-02200-9) concerns selecting an indivisible matching. Here exchange masses are continuous, and the stated capacity inequalities describe the entire feasible set. The linear program above is therefore an exact formulation of this task. No integrality requirement or additional matching constraint is needed.
