The continuous mirror question, as graded

Given a finite Boolean SyDS template \(S=(G,\{f_v\})\), where \(G\) is a DAG of maximum in-degree \(3\), consider an atomless unit-mass population of independent copies of \(S\). Each copy has an internal configuration \(q\in\{0,1\}^{V(G)}\) and follows the template's synchronous update. Decide whether every measurable initial population profile reaches, after some finite time, a profile in which almost every copy is at a fixed point.

Packaged proof task (what the prover saw — nothing else)

Input is a Boolean synchronous dynamical system \(S=(G,\{f_v\})\), where \(G\) is a finite simple DAG with maximum in-degree \(3\), \(m=|V(G)|\), and each deterministic function \(f_v:\{0,1\}^{\delta^-(v)\cup\{v\}}\to\{0,1\}\) is given by its truth table; \(\delta^-(v)\) denotes the in-neighbors of \(v\). Define \(F(q)_v=f_v(q|_{\delta^-(v)\cup\{v\}})\), with all vertices updated simultaneously. Self-state dependence is allowed and does not count toward in-degree.
The population is \([0,1]\) with Lebesgue measure \(\lambda\). An initial profile is any measurable map \(Q_0:[0,1]\to\{0,1\}^{V(G)}\); copies evolve independently by \(Q_t(a)=F^t(Q_0(a))\).
A finitely encoded society is given by its support: the list of its \(\tau\) positive-mass configuration types, each with its mass as a binary rational, summing to \(1\). Here \(\tau\) is support size, not \(2^m\). Let \(L\) be the total input bit length; express running times in \(m,\tau,L\), noting that only \(S\) is input and societies are universally quantified. The measurable-profile quantifier also includes profiles with irrational type masses.
Decide whether \(\forall Q_0\ \exists T\in\mathbb{Z}_{\geq0}:\lambda(\{a:F(Q_T(a))=Q_T(a)\})=1\). The finite time \(T\) may depend on the profile, and different copies may reach different fixed points.

Result

The universal population-convergence problem is \(\mathsf{coNP}\)-complete under polynomial-time many-one reductions, and therefore \(\mathsf{NP}\)-hard under polynomial-time Turing reductions. This holds even when the maximum in-degree is \(2\).

Consequently, the problem belongs to \(\mathsf{P}\) if and only if \(\mathsf{P}=\mathsf{NP}\).

The proof below establishes the population equivalence, a polynomial-time verifier for nonconvergence, and a direct bounded-degree hardness reduction.

1. The population quantifier is equivalent to discrete convergence

Write \(\Omega=\{0,1\}^{V(G)}\). Say that a configuration \(q\in\Omega\) converges if there exists \(t\geq 0\) such that \(F^{t+1}(q)=F^t(q)\). Once this equality holds, every subsequent configuration is the same fixed point.

For a measurable profile \(Q_0\), define

\[ \]
\(E_q=Q_0^{-1}(\{q\})\), \(\qquad p_q=\lambda(E_q)\), \(\qquad q\in\Omega.\)

The sets \(E_q\) form a finite measurable partition, so \(p_q\geq 0\) and \(\sum_{q\in\Omega}p_q=1\). Determinism and independent evolution give, for every \(t\geq 0\),

\[ \]
\(\lambda(\{a:F(Q_t(a))=Q_t(a)\})=\sum_{\{q:F^{t+1}(q)=F^t(q)\}}p_q.\)

Thus a particular profile satisfies the requested convergence property exactly when every configuration with positive mass converges:

  • If such a configuration \(q\) does not converge, the displayed measure is at most \(1-p_q<1\) at every time.
  • If every positive-mass configuration converges, choose a convergence time \(t_q\) for each one. There are finitely many such configurations, so \(T=\max_{\{q:p_q>0\}}t_q\) is finite. At time \(T\), the displayed measure equals \(1\).

It follows that

\[ \]
\(\text{universal population convergence}\quad\Longleftrightarrow\quad\text{every }q\in\Omega\text{ converges}.\)

For the forward implication, apply the population property to each constant measurable profile \(Q_0(a)=q\). The reverse implication follows from the finite-support argument above.

This argument allows arbitrary real masses, including irrational masses. Although the population is atomless, the configuration space is finite. Moreover, every failure already has a witness society with support size \(\tau=1\) and rational mass \(1\).

2. Every convergent orbit reaches a fixed point within \(m\) steps

This stronger time bound uses both Boolean states and acyclicity.

For each vertex \(v\), define its height recursively by

\[ \]
\(h(v)=1+\max_{u\in\delta^-(v)}h(u),\)

where the maximum over an empty set is \(0\). Because \(G\) is a DAG, these heights are well defined. If \(m>0\), their maximum \(H\) satisfies \(H\leq m\).

Lemma. If an orbit \(q_t=F^t(q_0)\) eventually reaches a fixed point, then the coordinate \(q_t(v)\) is constant for all \(t\geq h(v)\).

Proof. Proceed in topological order. Assume the claim holds for every in-neighbor of \(v\), and put

\[ \]
\(p=\max_{u\in\delta^-(v)}h(u)=h(v)-1.\)

All in-neighbor coordinates are constant from time \(p\) onward. Denote their constant tuple by \(b\). Hence, for every \(t\geq p\), the coordinate at \(v\) follows the autonomous unary Boolean map

\[ \]
\(q_{t+1}(v)=g(q_t(v)),\qquad g(s)=f_v(b,s).\)

There are exactly four unary Boolean maps: the two constant maps, the identity, and negation.

Negation cannot occur here, because it would make \(q_t(v)\) alternate forever, contradicting the assumed eventual fixed point. For the identity, the coordinate is already constant from time \(p\). For either constant map, it is constant from time \(p+1=h(v)\).

This also covers sources, for which \(p=0\), and completes the induction. \(\square\)

Therefore every convergent orbit is fixed by time \(H\), and in particular by time \(m\). Equivalently, for every initial configuration \(q\),

\[ \]
\(q\text{ converges}\quad\Longleftrightarrow\quad F^{m+1}(q)=F^m(q).\)

When \(m=0\), the unique empty configuration is already fixed, so the same equivalence holds.

Together with Section 1, this also shows that every yes-instance admits the common population convergence time \(T=m\), independently of the profile.

3. Membership in \(\mathsf{coNP}\) and running times

A certificate that universal population convergence fails is an initial configuration \(q\), encoded by \(m\) bits.

The verifier computes \(F^m(q)\) and checks whether \(F^{m+1}(q)\neq F^m(q)\). By Section 2, this inequality holds exactly when \(q\) does not converge. Section 1 then makes the constant profile at \(q\) a population counterexample.

Each local truth table has at most \(2^4=16\) entries: at most three in-neighbor bits and one self-state bit. After parsing the input, one synchronous update uses \(O(m)\) table evaluations. Verification therefore uses \(O(m^2)\) table evaluations and polynomial time in the input length \(L\). Thus the problem belongs to \(\mathsf{coNP}\).

For clarity, the following bounds count word operations after storing the constant-size truth tables:

| Task | Running time |
|---|---|
| Test convergence from one supplied configuration | \(O(L+m^2)\) |
| Test convergence of a supplied valid society with support size \(\tau\) | \(O(L+\tau m^2)\) |
| Decide universal convergence by enumerating all configurations | \(O(L+2^m m^2)\) |

These bounds give polynomial bit-time algorithms for the first two tasks.

For the supplied-society task, simulate each of its \(\tau\) positive-mass types and apply Section 1. The promised positive masses need no arithmetic: their magnitudes do not affect the answer. Here \(L\) includes the supplied society encoding.

For the actual universal decision problem, only \(S\) is input, so \(L\) is the encoding length of \(S\), and \(\tau\) is not an input parameter. The exponential enumeration bound does not replace \(2^m\) by the support size of a particular society.

4. Direct hardness reduction with maximum in-degree \(2\)

We give a polynomial-time many-one reduction from \(\mathsf{UNSAT}\) for formulas in \(3\)-CNF, using the standard \(\mathsf{coNP}\)-completeness of that problem.

Let \(\varphi\) be such a formula. Construct an acyclic Boolean circuit computing \(\varphi\), with gates of fan-in at most \(2\):

  • Introduce an input vertex \(x_i\) for each variable.
  • Use a distinct copy or negation gate for each literal occurrence.
  • Compute each three-literal clause using two binary OR gates.
  • Combine clause outputs using binary AND gates.

All gate vertices are distinct, and every gate takes inputs only from preceding vertices. Hence the resulting graph is a finite simple DAG of maximum in-degree \(2\). The circuit has size polynomial in the formula length. A formula with no clauses can instead use a constant-\(1\) output.

Turn this circuit into a synchronous dynamical system as follows. Each variable vertex preserves its initial bit:

\[ \]
\(f_{x_i}(s)=s.\)

Each circuit gate computes its usual Boolean operation on its in-neighbor states and ignores its own state.

Let \(o\) be the circuit output. Add one final vertex \(z\), with the sole incoming edge \(o\to z\), and define

\[ \]
\(f_z(b,s)=b(1-s),\)

where \(b\) is the state of \(o\) and \(s\) is the self-state of \(z\). Thus \(z\) becomes \(0\) when the output is \(0\), and toggles when the output is \(1\).

The new vertex is a sink, so the graph remains a simple DAG of maximum in-degree \(2\). Every local function has a constant-size truth table, making the construction polynomial-time.

Unsatisfiable formulas give universal convergence

Consider any initial configuration, including arbitrary initial values at all gates and at \(z\). The variable vertices preserve an assignment \(a\).

Give input vertices circuit depth \(0\), and each gate depth one plus the maximum depth of its inputs. Induction on depth shows that a gate of depth \(d\) has its correct circuit-evaluation value at every time \(t\geq d\): its update reads predecessor values from time \(t-1\), when those predecessors are already correct.

Let \(D\) be the maximum circuit depth. At every time \(t\geq D\), all circuit vertices are stable and the output equals \(\varphi(a)\).

If \(\varphi\) is unsatisfiable, this output is \(0\). Consequently \(z\) is \(0\) from time \(D+1\) onward. The entire configuration is then fixed.

Since the initial configuration was arbitrary, every configuration converges.

Satisfiable formulas give a nonconvergent configuration

Suppose an assignment \(a\) satisfies \(\varphi\). Initialize each variable according to \(a\), and initialize each gate to its correct circuit-evaluation value.

The entire circuit is fixed from time \(0\), and \(o\) remains \(1\). Consequently,

\[ \]
\(q_{t+1}(z)=1-q_t(z)\qquad\text{for every }t\geq 0.\)

Thus \(z\) alternates forever, and the configuration never reaches a fixed point. Its constant population profile witnesses failure of universal population convergence.

We have proved

\[ \]
\(\varphi\in\mathsf{UNSAT}\quad\Longleftrightarrow\quad S_\varphi\text{ has universal population convergence}.\)

This establishes \(\mathsf{coNP}\)-hardness under polynomial-time many-one reductions. Together with Section 3, it establishes \(\mathsf{coNP}\)-completeness.

5. The requested Turing-hardness conclusion

Given a \(3\)-CNF formula \(\varphi\), construct \(S_\varphi\), ask one universal-convergence oracle query, and negate the oracle’s answer. By Section 4, the resulting answer decides satisfiability.

Therefore the problem is \(\mathsf{NP}\)-hard under polynomial-time Turing reductions. This conclusion does not assert \(\mathsf{NP}\)-hardness under many-one reductions.

The discrete classification agrees with Theorem 5.1 of [Rosenkrantz et al., *Synchronous Dynamical Systems on Directed Acyclic Graphs: Complexity and Algorithms*](https://cdn.aaai.org/ojs/17351/17351-13-20845-1-2-20210518.pdf). The direct proof above independently verifies the truth-table encoding and the bounded in-degree restriction needed here.

Finally, if the population problem were in \(\mathsf{P}\), the one-query reduction would put \(3\)-SAT in \(\mathsf{P}\), implying \(\mathsf{P}=\mathsf{NP}\). Conversely, that equality implies \(\mathsf{coNP}=\mathsf{P}\), and Section 3 would then put the population problem in \(\mathsf{P}\).
