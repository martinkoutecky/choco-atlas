The continuous mirror question, as graded

Given a finite local coalition-formation game \(I=(V,L,\mathcal{C},w,\mathcal{G})\), an explicit rational initial distribution \(x^0\) over its coalition structures, and a round bound \(B\), can mass be routed in at most \(B\) synchronous rounds along legal local-improvement transitions so that all terminal mass is on locally stable states? Each unit of mass represents identical copies of the game, and each copy takes at most one improvement step per round.

A state \(S\subseteq\mathcal C\) consists of pairwise disjoint coalitions; uncovered agents receive zero. Its visibility graph has edges \(L_{\mathrm{perm}}\cup\bigcup_{D\in S}E(K_D)\), where \(K_D\) is the clique on \(D\).

Classification

The problem is \(\mathrm{NP}\)-hard. In fact, it is \(\mathrm{NP}\)-complete on a restricted family with:

  • one supported initial state, namely the empty state, with mass one;
  • the single fixed formation graph \(\mathcal G=\{K_5\}\);
  • every allowed coalition permanently accessible;
  • all payoffs equal to one;
  • \(m=\Theta(n)\).

Thus a polynomial-time algorithm for the stated problem would imply \(\mathrm P=\mathrm{NP}\). The reduction below concerns reaching any locally stable state within the deadline.

1. Divisible mass reduces exactly to individual reachability

For a state \(S\), let \(d(S)\) be the minimum number of legal improvements needed to reach a locally stable state, with \(d(S)=\infty\) if no such path exists.

Lemma. If the positive-mass support consists of states \(S_1,\ldots,S_\tau\), then all mass can reach locally stable states within \(B\) rounds if and only if \(d(S_i)\le B\) for every \(i\).

Proof. Label mass by its initial state. After \(B\) rounds, every copy initially in \(S_i\) has followed a sequence containing at most \(B\) legal improvements. If no such sequence ends in a stable state, none of that type’s positive mass can finish in a stable state. Splitting cannot change this conclusion.

Conversely, choose a path of length at most \(B\) from each supported state to a stable state. Route that type’s entire mass along its chosen path, then let it wait. These routes can run simultaneously because copies do not interact and transitions have no capacities. \(\square\)

Consequently, the minimum feasible horizon is \(\max_{1\le i\le\tau}d(S_i)\). The positive masses’ numerical values do not affect feasibility.

2. A bounded-occurrence satisfiability transformation

We use the classical \(\mathrm{NP}\)-completeness of satisfiability for CNF formulas with at most three literals per clause. [Karp, *Reducibility Among Combinatorial Problems*](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf)

We first transform such a formula \(\varphi\) into an equisatisfiable formula \(\psi\) in which each positive literal and each negative literal occurs at most twice.

For an original variable \(x\) with \(d\) occurrences, replace its occurrences by distinct variables \(x_1,\ldots,x_d\), preserving their signs. When \(d\ge2\), add the clauses

\(\displaystyle (\neg x_i\lor x_{i+1})\quad\text{for }1\le i\le d,\qquad x_{d+1}=x_1.\)

For \(d=1\), add no consistency clause. Variables with no occurrences can be discarded.

These clauses force all copies of \(x\) to have the same value: if one is true, the cyclic implications force every copy to be true; otherwise every copy is false. Conversely, assigning all copies the original variable’s value satisfies all consistency clauses. Therefore \(\varphi\) is satisfiable exactly when \(\psi\) is satisfiable.

Each new variable appears once in an original clause. For a cycle of length at least two, it additionally appears once positively and once negatively in consistency clauses. Hence each sign occurs at most twice. All clauses still have at most three literals, and the transformation has polynomial size.

Write \(q\) for the number of variables of \(\psi\), and \(r\) for its number of clauses.

3. A small maximal independent set encodes satisfiability

Construct a simple undirected graph \(H\) as follows.

For each variable \(y_i\), introduce three vertices \(t_i,f_i,h_i\), and make them a triangle. For each clause, introduce a vertex \(c_j\). Connect \(c_j\) to \(t_i\) when its clause contains \(y_i\), and to \(f_i\) when its clause contains \(\neg y_i\). Add no other edges.

Thus \(|V(H)|=3q+r\). Its maximum degree is at most four:

  • \(t_i\) and \(f_i\) each have two triangle neighbors and at most two clause neighbors;
  • \(h_i\) has degree two;
  • each clause vertex has at most three neighbors.

An independent set is maximal when no additional vertex can be added while preserving independence. Equivalently, every vertex outside it has a neighbor in it; such a set is also called an independent dominating set.

Lemma. The formula \(\psi\) is satisfiable if and only if \(H\) has a maximal independent set of size at most \(q\).

Proof, forward direction. Given a satisfying assignment, select \(t_i\) when \(y_i\) is true and \(f_i\) when it is false. The resulting set \(A\) has size \(q\) and is independent, because it selects one vertex per triangle and there are no edges between different variable triangles.

It dominates every variable triangle. It also dominates each clause vertex: a true literal in that clause supplies an adjacent selected vertex. Hence \(A\) is maximal independent.

Proof, reverse direction. Let \(A\) be a maximal independent set with \(|A|\le q\). The vertex \(h_i\) has neighbors only inside its own triangle. To dominate \(h_i\), the set \(A\) must contain a vertex of that triangle.

The \(q\) disjoint triangles therefore require at least \(q\) selected vertices. The budget forces exactly one selected vertex per triangle and no selected clause vertices.

Assign \(y_i\) true if \(t_i\in A\), false if \(f_i\in A\), and arbitrarily if \(h_i\in A\). Every clause vertex must have a selected neighbor. Such a neighbor is a \(t_i\) or \(f_i\) representing a literal made true by this assignment. Therefore every clause is satisfied. \(\square\)

4. Encoding the graph by permanently accessible coalitions

Let \(U=V(H)\) and \(m=|U|\). Introduce:

  • one agent \(a_e\) for every edge \(e\in E(H)\);
  • for each vertex \(u\), exactly \(5-\deg_H(u)\) fresh private agents \(p_{u,1},\ldots,p_{u,5-\deg_H(u)}\).

All these agents are distinct. Define one allowed coalition per graph vertex:

\(\displaystyle C_u=\{a_e:e\in E(H),\ u\in e\}\ \cup\ \{p_{u,1},\ldots,p_{u,5-\deg_H(u)}\}.\)

Because \(\deg_H(u)\le4\), every coalition has exactly five agents and at least one private agent. In particular, the coalitions are distinct.

For distinct vertices \(u,v\),

\(\displaystyle C_u\cap C_v=\begin{cases}\{a_{\{u,v\}}\},&\{u,v\}\in E(H),\\ \varnothing,&\{u,v\}\notin E(H).\end{cases}\)

Indeed, private agents belong to only one coalition, and an edge agent belongs precisely to its two endpoint coalitions.

Set

\(\displaystyle L_{\mathrm{perm}}=\bigcup_{u\in U}E(K_{C_u}),\qquad \mathcal G=\{K_5\},\qquad w(C_u)=1.\)

Each allowed coalition induces a permanent clique, so it is accessible in every state. The permanent graph is simple and undirected.

Take initial state \(S_0=\varnothing\), give it mass one, and set \(B=q\).

Legal improvements and stability

Since all payoffs equal one, a coalition intersecting a selected coalition cannot locally block: the required strict inequality would be \(1>1\). A coalition disjoint from the entire state does locally block, because it is accessible and all its members currently receive zero.

Therefore every legal improvement simply adds a disjoint coalition and deletes nothing.

Under the correspondence

\(\displaystyle A=\{u\in U:C_u\in S\},\)

valid states correspond exactly to independent sets of \(H\). Moreover, a state is locally stable exactly when every unselected coalition intersects a selected coalition. By the intersection identity above, this is precisely maximal independence of \(A\).

Every independent set can be reached from the empty state by adding its coalitions in any order. Each addition is legal, and exactly \(|A|\) improvements are used. Consequently,

\(\displaystyle \text{a stable state is reachable within }q\text{ rounds}\ \Longleftrightarrow\ H\text{ has a maximal independent set of size at most }q.\)

Combining this equivalence with the preceding lemma and the mass-routing lemma proves

\(\displaystyle \varphi\text{ is satisfiable}\ \Longleftrightarrow\ \text{all mass can reach stability within }B.\)

This is a polynomial-time many-one reduction.

Size and restricted completeness

The number of agents is

\(\displaystyle n=|E(H)|+\sum_{u\in U}(5-\deg_H(u))=5m-|E(H)|.\)

Maximum degree four implies \(|E(H)|\le2m\), so

\(\displaystyle 3m\le n\le5m.\)

Thus \(m=\Theta(n)\). There are at most \(10m\) permanent links, and the formation graph has five vertices and ten edges. With indexed agents and standard explicit lists, the output bit length is \(O(m\log(m+1))\), including the binary deadline.

This restricted problem also belongs to \(\mathrm{NP}\): a certificate lists at most \(\min(B,m)\) coalitions. In polynomial time, one checks that they are pairwise disjoint and that every unselected coalition intersects a selected coalition. These conditions certify a reachable stable state. Hence the restricted problem is \(\mathrm{NP}\)-complete, establishing \(\mathrm{NP}\)-hardness of the full problem.

5. General termination and an explicit running-time upper bound

A strictly increasing potential

Order the allowed coalitions \(C_1,\ldots,C_m\) by nonincreasing payoff, breaking ties arbitrarily. Define

\(\displaystyle \Phi(S)=\sum_{C_j\in S}2^{m-j}.\)

If a legal improvement inserts \(C_j\), every deleted coalition has strictly smaller payoff and therefore an index greater than \(j\). If \(R\) is the set of deleted indices, then

\(\displaystyle \Phi(S')-\Phi(S)=2^{m-j}-\sum_{\ell\in R}2^{m-\ell}\ge1,\)

because the sum of all terms with indices greater than \(j\) is \(2^{m-j}-1\).

Thus every improvement path has length at most \(2^m-1\). A path extended whenever a blocker exists must terminate at a stable state. In particular, every valid instance is feasible whenever \(B\ge2^m-1\).

Exhaustive decision algorithm

For a listed formation graph \(Q\), write \(k_Q=|V(Q)|\) and \(e_Q=|E(Q)|\). Define

\(\displaystyle \mathcal A_{\mathcal G}(n)=1+\sum_{\substack{Q\in\mathcal G\\1\le k_Q\le n}}k_Q!\,(k_Q+e_Q).\)

Given a visibility graph and a coalition, accessibility can be decided by enumerating every bijection for each formation graph of matching order. Checking one bijection requires checking its mapped edges; the expression above bounds this enumeration, up to polynomial bit-operation factors.

An exact algorithm proceeds as follows:

  • Precompute coalition intersections and payoff comparisons.
  • Enumerate the at most \(2^m\) candidate states, retaining the pairwise disjoint ones.
  • Compute every legal outgoing improvement and identify states with no outgoing improvement.
  • Run a backward, multi-source shortest-path search from these stable states.
  • Check the computed distance against \(B\) for each of the \(\tau\) supported states.

A valid state’s visibility graph can be constructed in \(O(n^2)\) elementary operations: disjointness gives \(\sum_{D\in S}|D|^2\le n^2\). There are at most \(m\) outgoing improvements per state. A convenient coarse deterministic running-time bound is

\(\displaystyle O\!\left(\left[1+m^2n+\tau m+2^m\bigl(n^2+m^2+m\mathcal A_{\mathcal G}(n)\bigr)\right]L^3\right).\)

The polynomial factor accommodates binary rational comparisons and manipulation of state identifiers and distances. The algorithm compares distances with the binary encoding of \(B\); it does not iterate through the numerical value of \(B\).

When formation graphs have bounded order, this becomes \(2^m\operatorname{poly}(n,m,\tau,L)\). For unrestricted explicitly listed formation graphs, the factorial enumeration gives the coarser bound \(2^{O(m+n\log(n+1))}\operatorname{poly}(L)\).

The hardness construction already has constant formation-graph size and permanently accessible coalitions. Every path in that construction uses at most \(m\) improvements; the difficulty is deciding whether stability can be reached within the smaller specified deadline.
