The anchor (named result in the paper)

Theorem 3 — class: hardness

The continuous mirror question, as graded

Given rational type masses \(\mu_t\), rational per-capita supplies \(s_o\), and weak-order types over object kinds \(O\), output a finite-support rational allocation \(x_{t,b}\) of integral bundles \(b\in\mathbb{Z}_{\ge 0}^{m}\) using at most \(s_o\) mass of each object, such that all positive-mass agents receive equal-size bundles and no agent SD-envies another. Require the allocation to be maximal under positive-mass couplings that weakly extend every assigned bundle, and complete whenever any complete EF allocation exists.

Packaged proof task (what the prover saw — nothing else)

Let \(O\) contain \(m\geq 1\) object kinds, all acceptable to everyone; copies of a kind are interchangeable. Each type \(t\) has a weak order \(\succsim_t\) over \(O\), with ties retained.
A society is given by its support: the list of the \(\tau\geq 1\) types with positive mass, each with its mass \(\mu_t\) as a binary rational, normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Supplies \(s_o\geq 0\) are binary rational quantities per unit society mass; let \(L\) be the total input bit length.
An allocation has finitely many nonzero rational masses \(x_{t,b}\geq 0\), indexed by integral bundles \(b\in\mathbb Z_{\geq 0}^{m}\), with \(\sum_bx_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_o\leq s_o\) for every \(o\). Bundle vectors are encoded in binary.
Write \(U_t(o)=\{a\in O:a\succsim_t o\}\) and \(b\succsim_t^{SD}c\) when \(\sum_{a\in U_t(o)}b_a\geq\sum_{a\in U_t(o)}c_a\) for every \(o\in O\).
An allocation is EF when all supported bundles have one common size \(k\in\mathbb Z_{\geq 0}\), and \(b\succsim_t^{SD}c\) whenever \(x_{t,b}>0\) and \(x_{u,c}>0\), including \(t=u\). It is complete when every supply constraint is tight.
An EF allocation \(x\) is maximal if there is no feasible EF allocation \(y\) admitting nonnegative rational couplings \(\lambda_{t,b,c}\) with \(\sum_c\lambda_{t,b,c}=x_{t,b}\), \(\sum_b\lambda_{t,b,c}=y_{t,c}\), \(c\geq b\) coordinatewise wherever \(\lambda_{t,b,c}>0\), and \(\sum_{t,b,c:c\neq b}\lambda_{t,b,c}>0\).
The computational problem is to output such a maximal rational EF allocation, required to be complete whenever any complete rational EF allocation exists.

Is this continuous allocation problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents, computing a maximal EF assignment that is complete whenever a complete EF assignment exists is NP-hard ([Aziz](https://arxiv.org/pdf/1409.6765)); complete EF existence is NP-complete even with dichotomous preferences ([Aziz et al.](https://arxiv.org/pdf/1312.6546)).
Probabilistic serial achieves SD-envy-freeness for fractional random assignments ([Hashimoto et al.](https://www.econtheory.org/ojs/index.php/te/article/viewFile/20140253/10217/318)); that guarantee compares lotteries rather than every realized integral bundle. No result settling the problem defined above was located.

  • Normalized total society mass to one, interpreting supplies as quantities per unit society mass.
  • Required a nonempty society and object-kind set; allowed zero supplies and empty bundles, as partial discrete assignments allow unallocated objects.
  • Carried over universal acceptability and treated copies of each kind as interchangeable, without imposing a one-copy-per-agent restriction.
  • Interpreted x as allocated population mass, requiring its bundle marginal for each type to equal that type's mass.
  • Interpreted envy-freeness agentwise across every pair of positive-mass bundle classes, including classes of the same type; retained preference ties without tie-breaking.
  • Interpreted weak extension as coordinatewise bundle containment, using couplings that preserve types and strictly add objects on positive mass.
  • Quantified maximality and complete-allocation existence over finite-support rational allocations and rational couplings, matching the requested allocation domain.
  • Specified binary encoding of integral bundle coordinates and total input bit length L.

Result

The problem is \(\mathsf{NP}\)-hard, even when every preference order is strict and \(\tau\leq 3\). Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathsf{P}=\mathsf{NP}\).

The key is that, under strict preferences, the stated EF condition prevents a type from splitting its mass between different bundles.

1. Strict preferences force one bundle per type

Lemma. Suppose type \(t\) strictly ranks the kinds as \(o_1\succ_t\cdots\succ_t o_m\). In any EF allocation, exactly one bundle has positive mass for \(t\).

Proof. Let \(b,c\) both have positive mass for \(t\). Because EF includes comparisons within a type, both \(b\succsim_t^{SD}c\) and \(c\succsim_t^{SD}b\) hold. Therefore, for every \(j\in\{1,\ldots,m\}\),

\(\displaystyle \sum_{\ell=1}^{j}b_{o_\ell}=\sum_{\ell=1}^{j}c_{o_\ell}.\)

For \(j=1\), this gives \(b_{o_1}=c_{o_1}\). Subtracting the equality for \(j-1\) from that for \(j\) gives \(b_{o_j}=c_{o_j}\) for every remaining coordinate. Thus \(b=c\).

Since \(\mu_t>0\), at least one bundle is supported. Its mass must equal \(\mu_t\). \(\square\)

Notice that this argument uses the original EF definition without refining or deleting any ties: strict orders are simply a permitted special case.

2. The finite problem used in the reduction

We use the following established theorem:

Given three finite agents, indivisible items, and a strict ordering of all items for each agent, deciding whether a complete necessarily envy-free allocation exists is \(\mathsf{NP}\)-complete.

This is Theorem 1 of Aziz, Schlotter, and Walsh, *Computational complexity of necessary envy-freeness*. Their Proposition 1 characterizes necessary envy-freeness by exactly the prefix-count inequalities used in the question. [Published paper](https://real.mtak.hu/187117/1/1-s2.0-S0165489623000677-main.pdf).

Explicitly, writing \(B_i\) for agent \(i\)'s assigned set, the condition is that, for every pair \(i,j\) and every prefix \(U_i(o)\),

\(\displaystyle |B_i\cap U_i(o)|\geq |B_j\cap U_i(o)|.\)

Taking the prefix containing all items, and comparing in both directions, shows that all three bundles have the same cardinality.

We restrict to nonempty item sets. Removing the trivial empty instance does not affect hardness.

3. Reduction to continuous complete EF existence

Take an instance of that finite problem, with item set \(O\) of size \(m\).

Create one object kind for each item. Group agents with identical strict preference orders into types. Let \(r_t\) be the number of agents in group \(t\), and set

\(\displaystyle \mu_t=\frac{r_t}{3},\qquad s_o=\frac13\quad\text{for every }o\in O.\)

Thus \(\tau\leq 3\), every mass is positive, and \(\sum_t\mu_t=1\). The construction has polynomial encoding length. Grouping identical orders ensures that the input is genuinely a list of supported types.

We prove equivalence in both directions.

Finite complete EF implies continuous complete EF

Suppose the finite instance has a complete EF assignment.

Agents with identical strict orders must have identical bundle vectors: their mutual EF comparisons imply equality of every prefix count, and hence of every coordinate, by the argument in Section 1. Write \(b_t\) for this common vector.

Define the continuous allocation by

\(\displaystyle x_{t,b_t}=\mu_t,\)

with every other mass zero.

All supported bundles have the same size, and all required SD comparisons follow from the finite assignment. For every kind \(o\), completeness of the finite assignment gives

\(\displaystyle \sum_t x_{t,b_t}(b_t)_o=\frac13\sum_t r_t(b_t)_o=\frac13=s_o.\)

Hence this is a complete rational EF allocation.

Continuous complete EF implies finite complete EF

Conversely, suppose the constructed instance has a complete rational EF allocation.

By Section 1, each type supports one integral bundle \(b_t\), with mass \(\mu_t=r_t/3\). Completeness gives, for every \(o\),

\(\displaystyle \sum_t r_t(b_t)_o=1.\)

Every summand is a nonnegative integer. Consequently, each coordinate \((b_t)_o\) belongs to \(\{0,1\}\), and the item \(o\) occurs exactly once when \(b_t\) is assigned to each of the \(r_t\) original agents of type \(t\).

This produces a partition of the finite items. Its bundles have one common size. The continuous EF comparisons supply precisely the prefix inequalities required for finite EF, including comparisons between agents with identical orders.

Thus the finite instance has a complete EF assignment.

We have therefore proved a polynomial many-one reduction to continuous complete EF existence.

4. Consequence for the requested output problem

Suppose a polynomial-time algorithm outputs a maximal rational EF allocation and always outputs a complete allocation whenever one exists.

Apply it to the constructed instance and check whether every supply constraint is tight. This check uses polynomial-time exact rational arithmetic.

By the proved equivalence:

  • On a YES-instance of the finite problem, the algorithm must output a complete allocation.
  • On a NO-instance, its feasible EF output cannot be complete.

Thus one call to the proposed algorithm would decide an \(\mathsf{NP}\)-complete problem in polynomial time.

The maximality requirement creates no incompatibility with completeness. Indeed, if \(x\) is complete, then any coupling satisfying \(c\geq b\) and assigning positive mass to \(c\neq b\) would give

\(\displaystyle \sum_{t,c}y_{t,c}|c|-\sum_{t,b}x_{t,b}|b|=\sum_{t,b,c}\lambda_{t,b,c}(|c|-|b|)>0.\)

But completeness gives \(\sum_{t,b}x_{t,b}|b|=\sum_o s_o\), while feasibility requires \(\sum_{t,c}y_{t,c}|c|\leq\sum_o s_o\). This is a contradiction. Hence every complete EF allocation is already maximal.

Therefore the output problem is \(\mathsf{NP}\)-hard. Divisibility of population masses does not remove hardness because self-EF makes every strict-preference type deterministic.

1. Strict preferences force a single supported bundle

The lemma correctly uses the requirement that EF comparisons include bundles supported by the same type.

For any two such bundles \(b,c\), mutual SD dominance gives equality of every prefix sum in the type’s strict ordering. The first prefix determines the first coordinate, and subtracting consecutive prefix equalities determines every remaining coordinate. Thus \(b=c\).

Since \(\mu_t>0\) and the allocation’s masses sum to \(\mu_t\), at least one bundle is supported. Its mass is necessarily \(\mu_t\). This also covers \(m=1\) and the zero bundle.

Strictness is essential to the coordinate-recovery argument, and the prover explicitly restricts its reduction to strict preferences. It does not assume that ties in general can be discarded.

2. The cited hardness theorem applies

The external theorem is accurately stated. The published paper defines preference lists as strict linear orders over all items and complete allocations as partitions of the item set. Its Theorem 1 establishes NP-completeness of complete necessary envy-free allocation existence for exactly three agents. Its Proposition 1 characterizes this property by the prefix-count inequalities written in the proof. [Aziz, Schlotter, and Walsh, *Computational complexity of necessary envy-freeness*](https://real.mtak.hu/187117/1/1-s2.0-S0165489623000677-main.pdf).

The correspondence with the task is exact for finite allocations:

  • Each item becomes a separate kind.
  • Each assigned set becomes its integral incidence vector.
  • A strict-order prefix is precisely a set \(U_i(o)\).
  • Comparisons of an agent’s bundle with itself add only tautological inequalities.

The full-prefix inequalities in both directions correctly imply equal bundle cardinalities. Thus the task’s common-size requirement introduces no additional restriction on complete finite EF allocations.

Excluding empty item sets does not affect hardness and ensures \(m\geq 1\), as required.

3. The constructed continuous instance is valid

Grouping identical preference orders produces genuine supported types. Their multiplicities satisfy \(r_t\geq 1\) and \(\sum_t r_t=3\), so the masses \(\mu_t=r_t/3\) are positive and normalized.

The supplies \(s_o=1/3\) are admissible rational quantities. These constants have bounded binary encoding length, and grouping and copying the preference lists require polynomial time. Consequently, the construction has polynomial size and \(\tau\leq 3\).

4. Finite completeness implies continuous completeness

For agents with identical strict orders, their mutual EF comparisons give equal prefix counts and therefore equal bundle vectors. This justifies defining a single bundle \(b_t\) for each grouped type.

Assigning mass \(\mu_t\) to \(b_t\) satisfies the type-mass constraints. Equal bundle sizes and all intertype SD comparisons follow from the finite assignment.

The supply computation is correct:
\[ \sum_t x_{t,b_t}(b_t)_o =\frac{1}{3}\sum_t r_t(b_t)_o =\frac{1}{3}. \]
The final equality uses the fact that each finite item is assigned exactly once.

Identical agents receiving identical vectors is restrictive when items are unique, but this does not invalidate the argument: it is a necessary consequence of finite EF under identical strict orders.

5. Continuous completeness implies finite completeness

The lemma ensures that each type has exactly one integral bundle \(b_t\), with mass \(r_t/3\). Tightness of each supply constraint then gives
\[ \sum_t r_t(b_t)_o=1. \]

All summands are nonnegative integers. Therefore no coordinate can exceed one, and replicating each type’s bundle across its \(r_t\) agents assigns every item exactly once. In particular, a type with \(r_t>1\) cannot receive a positive coordinate; the displayed equation itself enforces this restriction.

The replicated bundles have the common size required by continuous EF. Comparisons between different types follow directly from continuous EF; comparisons within one type hold because the replicated bundles coincide.

Both directions of the existence equivalence are therefore established.

6. The requested output algorithm would decide the hard problem

The completeness guarantee supplies the required distinction:

  • If a complete finite allocation exists, the equivalent continuous instance has a complete rational EF allocation, so the algorithm must output a complete allocation.
  • If no complete finite allocation exists, the equivalence rules out a complete continuous EF output.

Checking tightness uses exact rational arithmetic in time polynomial in the encoded output length. A polynomial-time algorithm necessarily writes only polynomially many output bits, so this check is polynomial in the original input length as well.

This establishes hardness of the output task through one algorithm call followed by a polynomial-time check. The prover does not claim NP membership for the general continuous problem, and none is needed.

7. Completeness is compatible with maximality

The coupling identity follows from its two marginal conditions. Coordinatewise domination gives \(|c|-|b|\geq 0\), and if \(c\neq b\), at least one integral coordinate increases, so \(|c|-|b|>0\).

The required positive mass on changed bundles therefore makes the total expected size strictly increase. Completeness already uses total supply \(\sum_o s_o\), while feasibility bounds any allocation’s expected size by that same quantity. The resulting contradiction correctly proves that every complete EF allocation is maximal.
