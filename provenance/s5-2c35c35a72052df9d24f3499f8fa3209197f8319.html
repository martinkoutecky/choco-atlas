The continuous mirror question, as graded

Given \(n\) items and a supplied sample size \(r\), let \(\mu\) be a rational-mass distribution supported on \(\tau\) rankings, where \(\mu_t=N_t/r\) and the counts arise from \(r\) independent Mallows samples with fixed parameter \(\beta>0\) around an unknown order. Can a randomized algorithm, given \(\mu\), return a permutation minimizing \(\sum_t \mu_t d_K(t,\sigma)\) with error probability at most \(n^{-\alpha}\) and running time polynomial in \(n,\tau,L\) for fixed \(\alpha,\beta\)?

For each unknown center and each supplied sample size, failure probability is measured jointly over the Mallows samples and the algorithm's randomness.

Result

The problem admits a randomized algorithm with the stated guarantee. For every fixed \(\alpha,\beta>0\), its running time is polynomial in \(m,\tau,L\), and its failure probability is at most \(n^{-\alpha}\), uniformly over the unknown center and the supplied sample size.

The key is a split: small samples can be expanded efficiently; sufficiently large samples have a consistent pairwise majority with high probability.

1. Exact computation from the compressed input

Write \(a\prec_t b\) when ranking \(t\) places \(a\) before \(b\). Recover the integer multiplicities \(N_t=r\mu_t\) using exact rational arithmetic. The input promise ensures that these are positive integers summing to \(r\).

For distinct items, define

\[ C_{ab}=\sum_t N_t\,\mathbf 1\{a\prec_t b\}. \]

Thus \(C_{ab}+C_{ba}=r\), and

\[ F_\mu(\sigma)=\frac1r\sum_{a\prec_\sigma b}C_{ba}. \]

All pairwise counts can be computed using \(O(\tau n^2)\) additions of integers with \(O(\log r)\) bits. Consequently, this computation is polynomial in \(n,\tau,L\), even when \(r\) is exponentially large.

Form the directed graph having edge \(a\to b\) precisely when \(C_{ab}>C_{ba}\). If this graph is acyclic, every topological ordering is an exact optimizer: it attains, for every unordered pair, its minimum possible contribution. Its objective value is therefore

\[ \frac1r\sum_{\{a,b\}}\min\{C_{ab},C_{ba}\}, \]

which is a lower bound for every permutation.

2. A uniform pairwise bias under Mallows sampling

Put \(q=e^{-\beta}\), so \(0<q<1\). We prove that whenever \(a\prec_\pi b\),

\[ \Pr[a\prec_T b]\geq\frac1{1+q}. \]

Relabel items by their positions in the center, so that the center is the identity and \(a<b\). This simultaneous relabeling preserves Kendall distance.

Partition rankings into those placing \(b\) before \(a\) and those placing \(a\) before \(b\). Swapping the positions of \(a,b\) is a bijection from the first class to the second. For a ranking \(t\) in the first class, let \(t'\) be its image. Then

\[ d_K(t,\pi)-d_K(t',\pi)=1+2k\geq1, \]

where \(k\) counts the items \(c\) satisfying \(a<c<b\) whose positions in \(t\) lie between the positions of \(b,a\).

Indeed, swapping removes the inversion of \(a,b\). Each such intermediate item loses two inversions. Items outside the positional interval have unchanged comparisons with both endpoints; items inside that interval but outside the central interval have unchanged total inversion contribution.

Hence the unnormalized Mallows weights satisfy

\[ q^{d_K(t,\pi)}\leq q\,q^{d_K(t',\pi)}. \]

Summing over the bijection gives

\[ \Pr[b\prec_T a]\leq q\,\Pr[a\prec_T b], \]

which proves the claimed bound.

3. Large samples have a consistent majority

Fix a centrally ordered pair \(a\prec_\pi b\). For the independent samples \(T_1,\ldots,T_r\), let

\[ X_i=\mathbf 1\{a\prec_{T_i}b\},\qquad S=\sum_{i=1}^rX_i. \]

The variables are independent Bernoulli variables with common success probability \(p\geq1/(1+q)\). Since \(q<1\), Markov’s inequality gives

\[ \Pr[S\leq r/2] \leq q^{-r/2}\mathbb E[q^S] =q^{-r/2}(1-p+pq)^r \leq\left(\frac{2\sqrt q}{1+q}\right)^r. \]

The last inequality follows because \(1-p+pq\) decreases with \(p\), and its value at \(p=1/(1+q)\) is \(2q/(1+q)\).

Define the positive constant

\[ c_\beta=\log\left(\frac{1+q}{2\sqrt q}\right)>0. \]

A union bound, requiring no independence between different pairs, yields

\[ \Pr[\text{some pair lacks a strict majority agreeing with }\pi] \leq \binom n2 e^{-c_\beta r}. \]

Choose a fixed positive integer \(K\) satisfying

\[ c_\beta K\geq(\alpha+2)\log 2, \]

and put \(h=\lceil\log_2 n\rceil\). If \(r\geq Kh\), the preceding probability is at most

\[ \binom n2 n^{-(\alpha+2)} <\frac12n^{-\alpha}. \]

On the complementary event, the majority graph is exactly the total order \(\pi\). Its topological ordering is therefore an exact empirical optimizer by Section 1.

The large-sample algorithm computes the majority graph, returns a topological ordering if it is acyclic, and otherwise returns any fixed permutation. Its failure probability is below \(n^{-\alpha}\), and its running time is polynomial in the compressed input length.

4. Small samples: expansion and restoration of sample order

Suppose \(r<Kh\). Since \(K\) depends only on the fixed parameters, now \(r=O_{\alpha,\beta}(\log n)\). Expanding every support type into \(N_t\) copies therefore takes polynomial time.

Use the supplied explicit-sample theorem with error parameter \(\gamma=\alpha+1\): for independent Mallows samples, it returns an exact optimizer in randomized polynomial time, with failure probability below \(n^{-\gamma}\). This is the exact maximum-likelihood guarantee of [Braverman–Mossel, Theorem 7](https://arxiv.org/pdf/0910.1191). Its objective is the required one because the sample likelihood at \(\sigma\) is \(Z_n(\beta)^{-r}\exp(-\beta rF_\mu(\sigma))\).

One detail needs care: an arbitrary ordering of the expanded copies need not itself have the distribution of an independent sample sequence. We restore that distribution by randomly ordering the copies.

Here is an implementation with bounded polynomial running time. Choose a fixed integer \(k\geq\alpha+2\), and give each labeled copy an independent uniform \(b\)-bit priority, where

\[ b=k\lceil\log_2 n\rceil+2\lceil\log_2 r\rceil. \]

If any priorities coincide, return a fixed permutation. Otherwise, sort the copies by priority and run the explicit-sample algorithm. The collision probability is at most

\[ \binom r2\,2^{-b}\leq\frac12n^{-k}. \]

Conditional on no collision, the ordering of the labeled copies is uniform. Consequently, conditional on the supplied multiplicities, the resulting type sequence is uniform among sequences with those multiplicities.

This is precisely the conditional distribution of the original independent samples: every sequence with multiplicities \(N_t\) has the same probability \(\prod_t\Pr[T=t]^{N_t}\). Furthermore, the probability of no priority collision depends only on \(r,b\), so conditioning on it does not change the distribution of the multiplicities. Thus the reconstructed sequence, conditional on no collision, has the required independent Mallows distribution.

All hypotheses of the explicit-sample theorem are now satisfied. The total failure probability in this branch is at most

\[ n^{-(\alpha+1)}+\frac12n^{-(\alpha+2)} =n^{-\alpha}\left(\frac1n+\frac1{2n^2}\right) <n^{-\alpha}, \]

using \(n\geq2\).

5. Combined guarantee

The algorithm compares the binary integer \(r\) with \(K\lceil\log_2 n\rceil\), then runs the appropriate branch.

For small \(r\), expansion has polynomial size and the randomized reconstruction permits application of the exact explicit-sample theorem. For large \(r\), pairwise counts are computed directly from the support and binary multiplicities.

Both branches run in polynomial time in \(m=n,\tau,L\). Both satisfy the required failure bound for every unknown center and every supplied \(r\). This settles the stated sampling-and-error question affirmatively.
