Theorem 6.1 — class: algorithmic

The continuous mirror question, as graded

Given rational type shares \(\mu_t\), additive valuations \(v_t\) over \(d\) item categories, exact continuum MMS benchmarks \(\eta_t\), and one unit of each category per unit mass, with \(v_t(g)\leq\eta_t/2\) for every type and category, can an algorithm output a rational flow \(x_{t,b}\u005c) in time polynomial in d,\tau\) and input bit length \(L\)? Here each \(b\in\mathbb{Z}_{\geq 0}^d\) has \(\sum_g b_g=d\), each unit of mass receives one indivisible bundle, \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}x_{t,b}b_g=1\) for every category \(g\), and every bundle with \(x_{t,b}>0\) satisfies \(v_t\cdot b\geq\eta_t/2\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_t\mu_t=1\).
There are \(m=d\geq1\) item categories, each with supply one. Type \(t\) has public additive values \(v_t\in\mathbb{Q}_{\geq0}^d\); individual bundles contain integer numbers of items.
Define its continuum MMS by \(\eta_t=\sup_q\min_{b:q_b>0}v_t\cdot b\), where \(q\) ranges over finitely supported distributions on \(\mathbb{Z}_{\geq0}^d\) satisfying \(\sum_bq_b=1\) and \(\sum_bq_bb_g=1\) for every category \(g\). Benchmark bundles have unrestricted cardinality, as in ordinary MMS.
The exact benchmarks \(\eta_t\in\mathbb{Q}_{\geq0}\) are supplied and promised correct, with \(v_t(g)\leq\eta_t/2\) for every \(t,g\). Let \(L\) be the total binary input length.
An allocation is a nonnegative rational flow indexed by \(t\) and \(b\in B_d=\{b\in\mathbb{Z}_{\geq0}^d:\sum_gb_g=d\}\), specified by its nonzero entries, satisfying \(\sum_bx_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_g=1\).
Each individual receives one whole bundle; the required guarantee is \(x_{t,b}>0\Rightarrow v_t\cdot b\geq\eta_t/2\).

Is constructing such a half-MMS allocation, or determining that none exists, solvable in time polynomial in \(m=d,\tau,L\), or is this problem NP-hard?

For finitely many agents with nonnegative additive valuations and every item worth at most half its recipient's MMS benchmark, Round-Robin computes a half-MMS allocation in polynomial time. Resolution

The problem as defined is polynomial-time solvable for all promised inputs. Every individual can receive one item from every category, and this bundle achieves their full continuum MMS. This observation applies to arbitrary \(d\) and \(\tau\), so it settles the general case, rather than only a degenerate subcase.

1. The continuum benchmark equals total value

Fix a type \(t\), and define \(S_t=\sum_{g=1}^d v_t(g)\).

For any finitely supported distribution \(q\) allowed in the benchmark definition, its expected bundle value is
\[ \sum_b q_b(v_t\cdot b) =\sum_{g=1}^d v_t(g)\sum_b q_b b_g =\sum_{g=1}^d v_t(g) =S_t. \]
The minimum value among bundles having positive probability cannot exceed their probability-weighted average. Therefore every such distribution satisfies \(\min_{b:q_b>0}v_t\cdot b\leq S_t\), and taking the supremum gives \(\eta_t\leq S_t\).

Conversely, let \(\mathbf{1}=(1,\ldots,1)\in\mathbb{Z}_{\geq0}^d\). The distribution concentrated on \(\mathbf{1}\) has expected count one in every category, so it is admissible. Its sole bundle has value \(v_t\cdot\mathbf{1}=S_t\). Consequently \(\eta_t\geq S_t\).

Thus \(\eta_t=S_t\) for every type. This argument uses the benchmark’s unrestricted cardinality exactly as specified.

2. Constructing the allocation

For every supported type \(t\), output the single entry \(x_{t,\mathbf{1}}=\mu_t\), with all other entries zero.

We verify each requirement:

  • Bundle cardinality: \(\sum_{g=1}^d\mathbf{1}_g=d\), so \(\mathbf{1}\in B_d\).
  • Type masses: \(\sum_b x_{t,b}=x_{t,\mathbf{1}}=\mu_t\).
  • Category supplies: For every category \(g\), \(\sum_{t,b}x_{t,b}b_g=\sum_t\mu_t\mathbf{1}_g=\sum_t\mu_t=1\).
  • Value guarantee: Every allocated bundle satisfies \(v_t\cdot\mathbf{1}=S_t=\eta_t\geq\eta_t/2\).

The allocation is rational because each \(\mu_t\) is rational. Zero benchmarks cause no exception. The assumption \(v_t(g)\leq\eta_t/2\) is unnecessary for this construction.

3. Complexity and interpretation

The output has exactly \(\tau\) nonzero entries. Each bundle has \(d\) coordinates equal to one, and each flow value is copied from the input. Constructing this explicit representation takes time polynomial in \(d,\tau,L\).

Hence every promised instance is feasible, and the algorithm always returns an allocation.

The simplification follows from the stipulated continuum flow model: category supply one and population mass one permit the common bundle \(\mathbf{1}\) for the entire population. A nontrivial variant would require different constraints; none are needed to settle the specified problem.
