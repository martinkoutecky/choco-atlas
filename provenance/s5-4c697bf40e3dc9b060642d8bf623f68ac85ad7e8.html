Theorem 1 — class: hardness

The continuous mirror question, as graded

Given \(r\) binary issues and a finite support \(S\subseteq\{0,1\}^r\) with binary-rational masses \(\mu_v\geq 0\) summing to \(1\), find \(x\in\{0,1\}^r\) maximizing \(A_\mu(x)=\sum_{v\in S}\mu_v\,\mathbf{1}[d_H(v,x)<r/2]\).

Packaged proof task (what the prover saw — nothing else)

Given a positive integer \(r\) of binary issues, a society is specified by its support \(S\subseteq\{0,1\}^r\): the list of its \(\tau=|S|\) distinct types with positive binary-rational masses \(\mu_v\), where \(\sum_{v\in S}\mu_v=1\). The support size \(\tau\) is not the number \(2^r\) of possible types. Let \(L\) be the total input bit length; state running times in \(r\), \(\tau\), and \(L\) (here \(r\) plays the role of the issue-count parameter \(m\)).
A report is any \(x\in\{0,1\}^r\). Type \(v\) approves precisely when \(d_H(v,x)<r/2\), where \(d_H\) is Hamming distance; equality gives no approval. Define \(A_\mu(x)=\sum_{v\in S}\mu_v\mathbf{1}[d_H(v,x)<r/2]\). The problem is to return a report maximizing \(A_\mu\); any maximizer is acceptable.

Is this mass-based Maximum Approval Pandering problem solvable in polynomial time in \(r,\tau,L\), or is it NP-hard?

For an explicitly listed finite electorate, maximizing the number of approvals under this same strict Hamming-distance threshold is NP-hard ([Sun et al., 2023](https://proceedings.mlr.press/v216/sun23b/sun23b.pdf)).
No result specifically addressing the normalized binary-rational mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Require a positive issue count, consistent with the discrete agreement measure's division by the issue count.
  • Remove zero-mass entries so the supplied list is exactly the positive-mass support.
  • Allow any maximizing report when the optimum is attained by multiple reports.
  • Use r as the size parameter corresponding to m in the general society-input convention; this optimization problem has no candidate-count parameter.

1. Result and the hardness premise

The mass-based problem is NP-hard, even when all masses are finite binary fractions. Consequently, a polynomial-time algorithm in \(r,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

We use the finite-electorate hardness result supplied in the question: given an explicitly listed electorate \(v^{(1)},\ldots,v^{(N)}\in\{0,1\}^r\), finding a report maximizing
\(C(x)=\sum_{i=1}^{N}\mathbf{1}[d_H(v^{(i)},x)<r/2]\)
is NP-hard. This is precisely Problem 1 and Theorem 1 of [Sun et al. (2023)](https://proceedings.mlr.press/v216/sun23b/sun23b.pdf). In particular, its reports and strict approval threshold agree with those in the present problem.

2. Exact normalization when rationals have binary-encoded numerators and denominators

Group identical voters into distinct types. Let \(S\) be the resulting support, let \(\tau=|S|\), and let \(c_v\) denote the multiplicity of type \(v\). Thus \(c_v\) is a positive integer and \(\sum_{v\in S}c_v=N\).

Assign mass \(\mu_v=c_v/N\). These masses are positive, sum to one, and have binary numerator and denominator lengths bounded by \(O(\log(N+1))\). For every report \(x\),
\(A_\mu(x)=\sum_{v\in S}(c_v/N)\mathbf{1}[d_H(v,x)<r/2]=C(x)/N\).

Therefore the two objectives have exactly the same maximizers, including all ties. The output instance has
\(L=O(\tau(r+\log(N+1)))\),
and \(\tau\leq N\). Grouping the explicitly listed voters and forming the masses takes polynomial time in the source input length.

An algorithm returning any maximizer of the mass objective would consequently return a maximizer of the finite-electorate objective. This proves NP-hardness under this encoding convention.

3. Hardness also holds for finite binary fractions

If “binary-rational” instead requires dyadic masses, the fractions \(c_v/N\) need not be admissible. The following construction resolves that issue while preserving every strict comparison of approval counts.

Choose a power of two \(Q\) satisfying
\(4N\tau\leq Q<8N\tau\).
For each \(v\in S\), initially set
\(b_v=\lfloor Qc_v/N\rfloor\).
Define the integer
\(R=Q-\sum_{v\in S}b_v\).

Because \(\sum_{v\in S}Qc_v/N=Q\), the number \(R\) is the sum of \(\tau\) fractional parts. Hence \(0\leq R<\tau\). Add one to \(b_v\) for any \(R\) distinct types, obtaining integers \(a_v\), and set \(\mu_v=a_v/Q\).

These masses satisfy all input requirements:

  • Their sum is one because \(\sum_{v\in S}a_v=Q\).
  • They are positive because \(Qc_v/N\geq Q/N\geq4\tau\), so already \(b_v\geq1\).
  • They are dyadic because \(Q\) is a power of two.
  • Each satisfies \(|\mu_v-c_v/N|\leq1/Q\), whether or not its numerator was incremented.

It follows that, for every report \(x\),
\(\left|A_\mu(x)-C(x)/N\right|\leq\tau/Q\).

Now suppose \(C(x)>C(y)\). Approval counts are integers, so \(C(x)-C(y)\geq1\). Consequently,
\(A_\mu(x)-A_\mu(y)\geq1/N-2\tau/Q\geq1/(2N)>0\).

Thus every strict comparison of finite-electorate approval counts is preserved. If \(y\) failed to maximize \(C\), some \(x\) would have \(C(x)>C(y)\), forcing \(A_\mu(x)>A_\mu(y)\). Therefore every mass maximizer maximizes the original approval count. Splitting ties between equal counts causes no difficulty, since any original maximizer is acceptable.

Finally, \(\log Q=O(\log(N\tau+1))=O(\log(N+1))\), since \(\tau\leq N\). The output again has
\(L=O(\tau(r+\log(N+1)))\).
All rounding and grouping operations use polynomial time. This completes the reduction even under the dyadic interpretation.

4. Running time and the support-size distinction

For comparison, exhaustive search gives an exact algorithm with running time
\(O\!\left(\tau L^2+2^r\tau\bigl(r\log(r+1)+L\bigr)\right)\)
in bit operations under standard explicit binary rational encoding.

To justify this bound, write each mass as \(p_v/q_v\). Precompute the common denominator \(D=\prod_{v\in S}q_v\) and integer weights \(w_v=p_v(D/q_v)\). The bit length of \(D\) is \(O(L)\), and schoolbook arithmetic gives the stated \(O(\tau L^2)\) preprocessing bound. For each report, compute the \(\tau\) Hamming distances and sum the approved integer weights. Comparing these sums is equivalent to comparing approval masses.

Hence the problem is polynomial-time solvable for fixed \(r\), but NP-hard when \(r\) varies. The reduction uses only the explicitly listed \(\tau\) support types; it never lists all \(2^r\) possible types.
