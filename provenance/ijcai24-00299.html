The continuous mirror question, as graded

Given finite types \(T\), rational masses \(\mu_t\) summing to \(1\), and for each type \(t\) a finite menu of per-unit bribes \((b_{t,j},p_{t,j})\) with \(p_{t,j}\in(0,1]\), choose masses \(x_{t,j}\ge0\) satisfying \(\sum_j x_{t,j}=\mu_t\) and \(\sum_{t,j}b_{t,j}x_{t,j}\le\beta\). Decide whether \(G(x)=\exp\!\left(\sum_{t,j}x_{t,j}\ln p_{t,j}\right)\ge\theta\).

Packaged proof task (what the prover saw — nothing else)

For each finite type \(t\in T\), a rational mass \(\mu_t\ge 0\) is split among its finite menu of actions \((b_{t,j},p_{t,j})\), where \(b_{t,j}\), \(\beta\), and \(\theta\) are rational and \(p_{t,j}\in(0,1]\). Choose \(x_{t,j}\ge0\) with \(\sum_jx_{t,j}=\mu_t\) for every \(t\), total cost \(\sum_{t,j}b_{t,j}x_{t,j}\le\beta\), and success value \(G(x)=\exp\!\left(\sum_{t,j}x_{t,j}\ln p_{t,j}\right)\).

Target. Is deciding whether there exists such an \(x\) with \(G(x)\ge\theta\) solvable in polynomial time, or is it NP-hard?

Nearest known results. The discrete counterpart, in which one action is selected for each individual player subject to an integer budget and the selected probabilities are multiplied, is weakly NP-hard. It is also \(\mathrm{W}[1]\)-hard when parameterized by the number of players. No result for this exact continuous mass-allocation problem is verified here.

Exact Complexity of Continuous Mass Allocation

Conclusion

In the standard Turing model with binary-encoded rationals, the problem is polynomial-time equivalent to exact comparison of succinct products of powers, denoted \(\mathrm{PoE}_{\ge}\).

Consequently, the continuous allocation itself introduces no combinatorial hardness: an optimal allocation can be constructed by a fractional-knapsack algorithm. However, deciding whether its exact success value meets the rational threshold requires comparing a variable-length linear form in logarithms. The general complexity of this comparison problem is not currently known to be in \(\mathrm{P}\), nor is it known to be \(\mathrm{NP}\)-hard.

Thus the requested dichotomy cannot presently be resolved unconditionally. The problem is conditionally in \(\mathrm{P}\) under standard number-theoretic conjectures concerning linear forms in logarithms, and unconditionally in \(\mathrm{P}\) when the number of distinct probabilities is bounded by a constant.

1. Computational model and elementary cases

Assume every rational is encoded in binary and the variables \(x_{t,j}\) range over the nonnegative reals. Write

\[ \ell_{t,j}=\ln p_{t,j}\leq 0. \]

Because the exponential function is strictly increasing, for \(0<\theta\leq 1\),

\[ G(x)\geq\theta \quad\Longleftrightarrow\quad \sum_{t,j}x_{t,j}\ell_{t,j}\geq\ln\theta. \]

The following boundary cases are elementary:

  • If \(\theta\leq 0\), every feasible allocation satisfies \(G(x)>\theta\).
  • If \(\theta>1\), no allocation satisfies the threshold because \(G(x)\leq 1\).
  • If a positive-mass type has an empty menu, the instance is infeasible.
  • If \(\theta=1\), all positive allocated mass must be assigned to actions with \(p_{t,j}=1\); feasibility can then be checked using rational costs alone.

Henceforth assume \(0<\theta<1\) and that every positive-mass type has a nonempty menu.

2. The comparison problem \(\mathrm{PoE}_{\ge}\)

An instance of \(\mathrm{PoE}_{\ge}\) consists of positive integers \(a_1,\ldots,a_n,c_1,\ldots,c_m\) and positive integer exponents \(u_1,\ldots,u_n,v_1,\ldots,v_m\), all in binary. The question is whether

\[ \prod_{i=1}^{n}a_i^{u_i} \geq \prod_{j=1}^{m}c_j^{v_j}. \]

Equivalently, it asks for the sign of

\[ \sum_{i=1}^{n}u_i\ln a_i-\sum_{j=1}^{m}v_j\ln c_j. \]

Equality testing is polynomial-time solvable, but exact inequality testing with a variable number of bases is a longstanding arithmetic-complexity problem. The established results needed below are:

  • If the total number of bases is bounded by a constant, \(\mathrm{PoE}_{\ge}\) is unconditionally in \(\mathrm{P}\).
  • For an unbounded number of bases, it is in \(\mathrm{P}\) under either the Lang–Waldschmidt conjecture or Baker’s refined \(ABC\) conjecture.

These statements are proved by Etessami, Stewart, and Yannakakis using lower bounds for nonzero linear forms in logarithms; see [Proposition 3.7 and the surrounding discussion](https://arxiv.org/abs/1304.5429).

3. Structure of an optimal allocation

Lemma 1: Upper-hull representation

For a fixed type \(t\) with \(\mu_t>0\), consider the points

\[ P_{t,j}=(b_{t,j},\ell_{t,j}). \]

The pairs consisting of total cost and logarithmic success contribution achievable by this type form

\[ \mu_t\operatorname{conv}\{P_{t,j}:j\in J_t\}. \]

For any fixed total cost, the largest logarithmic contribution lies on the upper boundary of this convex hull.

Proof

Let \(y_{t,j}=x_{t,j}/\mu_t\). Then \(y_{t,j}\geq0\) and \(\sum_jy_{t,j}=1\), while

\[ \left( \sum_jb_{t,j}x_{t,j}, \sum_j\ell_{t,j}x_{t,j} \right) = \mu_t\sum_jy_{t,j}P_{t,j}. \]

Thus the achievable set is precisely the displayed scaled convex hull. At a prescribed first coordinate, replacing a point below the upper boundary by the upper-boundary point with the same first coordinate preserves cost and weakly increases the objective. ∎

After retaining only the best probability among actions of equal cost, let the upper-hull vertices for type \(t\) be

\[ (b_{t,0},\ell_{t,0}),\ldots,(b_{t,r_t},\ell_{t,r_t}), \]

ordered by strictly increasing cost. Their slopes

\[ s_{t,k} = \frac{\ell_{t,k+1}-\ell_{t,k}} {b_{t,k+1}-b_{t,k}} \]

are strictly decreasing in \(k\), after redundant collinear vertices are removed.

The total cost capacity of segment \((t,k)\) is

\[ q_{t,k} = \mu_t(b_{t,k+1}-b_{t,k}), \]

and using \(z\in[0,q_{t,k}]\) units of this capacity changes the logarithmic objective by \(s_{t,k}z\).

Lemma 2: Fractional-knapsack optimality

Let

\[ C_0=\sum_t\mu_t b_{t,0}, \qquad R=\beta-C_0. \]

If \(R<0\), the instance is infeasible. Otherwise, an optimal allocation is obtained by sorting all positive-slope hull segments in nonincreasing order of \(s_{t,k}\) and filling them greedily until either their capacities or the remaining budget \(R\) are exhausted.

Proof

Every feasible allocation has cost at least \(C_0\), because \(b_{t,0}\) is the minimum cost available to type \(t\). Thus \(C_0>\beta\) implies infeasibility.

Suppose \(R\geq0\). By Lemma 1, it suffices to consider upper-hull allocations. Moving along the upper hull of one type uses its segments in order. Hence the problem becomes

\[ \max\sum_{t,k}s_{t,k}z_{t,k} \]

subject to

\[ 0\leq z_{t,k}\leq q_{t,k}, \qquad \sum_{t,k}z_{t,k}\leq R, \]

together with the condition that later segments of a type can be used only after earlier segments have been filled.

If the precedence conditions are omitted, this is ordinary fractional knapsack. Its greedy solution fills positive-slope segments in nonincreasing slope order; the usual exchange argument proves optimality. Indeed, if a lower-slope segment is used while a higher-slope segment is not full, transferring a sufficiently small common amount of resource from the former to the latter weakly increases the objective.

For each type, its segment slopes are already decreasing. Therefore the global greedy order automatically respects the typewise precedence conditions. Equal slopes may be ordered with earlier segments of the same type first. Thus the fractional-knapsack optimum is feasible for the original problem and is optimal there as well. Nonpositive-slope segments need not be used because the budget is an upper bound. ∎

The greedy solution places each type either at one upper-hull vertex or on one upper-hull segment. Since all costs, masses, and the remaining budget are rational, the resulting optimal allocation \(x^*\) is rational and has polynomial encoding length.

4. Exact construction of the optimizer is polynomial-time

It remains to verify that the hulls and the slope ordering can be computed exactly.

Comparing two slopes reduces to deciding the sign of

\[ (b_{v}-b_{u})(\ell_{z}-\ell_{w}) - (b_{z}-b_{w})(\ell_{v}-\ell_{u}). \]

After clearing rational denominators, this is an integer linear combination of logarithms of at most four rational probabilities. Writing each rational probability as a ratio of two integers produces at most eight integer logarithms.

The number eight is a universal constant. Therefore every hull-orientation and slope-order comparison is polynomial-time solvable by the fixed-number-of-bases result for linear forms in logarithms. There are only polynomially many such comparisons. Hence \(x^*\) can be constructed in polynomial time without invoking the unresolved variable-factor comparison problem.

5. Reduction of the allocation problem to \(\mathrm{PoE}_{\ge}\)

Write every positive component of the computed optimum as

\[ x^*_{t,j}=\frac{r_{t,j}}{s_{t,j}} \]

in lowest terms. Let \(Q\) be the product of all denominators \(s_{t,j}\). Although the numerical value of \(Q\) can be large, its binary encoding length is at most the sum of the encoding lengths of the denominators and is therefore polynomial.

Set \(e_{t,j}=Qx^*_{t,j}\in\mathbb Z_{\geq0}\). Then

\[ G(x^*)\geq\theta \quad\Longleftrightarrow\quad \prod_{t,j}p_{t,j}^{e_{t,j}}\geq\theta^Q. \]

Write \(p_{t,j}=u_{t,j}/v_{t,j}\) and \(\theta=u_0/v_0\). Clearing denominators gives

\[ \left(\prod_{t,j}u_{t,j}^{e_{t,j}}\right)v_0^Q \geq \left(\prod_{t,j}v_{t,j}^{e_{t,j}}\right)u_0^Q. \]

This is an instance of \(\mathrm{PoE}_{\ge}\) of polynomial encoding length. Therefore the allocation problem polynomial-time many-one reduces to \(\mathrm{PoE}_{\ge}\).

6. Reverse reduction, even with no allocation choices

Theorem

The problem \(\mathrm{PoE}_{\ge}\) polynomial-time many-one reduces to the continuous mass-allocation problem, even when every menu has exactly one action, all costs are zero, the budget is zero, and the total mass is one.

Proof

Consider the \(\mathrm{PoE}_{\ge}\) instance

\[ A=\prod_{i=1}^{n}a_i^{u_i}, \qquad C=\prod_{j=1}^{m}c_j^{v_j}. \]

Let

\[ U=\sum_i u_i, \qquad V=\sum_j v_j, \qquad E=U+V, \]

and choose

\[ K=1+\max\{a_1,\ldots,a_n,c_1,\ldots,c_m\}. \]

For each left-hand factor \(a_i^{u_i}\), create a singleton-menu type with

\[ \mu_i=\frac{u_i}{E}, \qquad p_i=\frac{a_i}{K}, \qquad b_i=0. \]

For each right-hand factor \(c_j^{v_j}\), create a singleton-menu type with

\[ \mu'_j=\frac{v_j}{E}, \qquad p'_j=\frac{1}{Kc_j}, \qquad b'_j=0. \]

Set \(\beta=0\) and \(\theta=1/K\). All probabilities lie in \((0,1]\), and the total mass is

\[ \sum_i\mu_i+\sum_j\mu'_j = \frac{U+V}{E} = 1. \]

Because every menu is a singleton, there is exactly one allocation. Its success value is

\[ \begin{aligned} G &= \prod_i\left(\frac{a_i}{K}\right)^{u_i/E} \prod_j\left(\frac{1}{Kc_j}\right)^{v_j/E} \\ &= K^{-(U+V)/E} \left(\frac{A}{C}\right)^{1/E} \\ &= \frac{1}{K}\left(\frac{A}{C}\right)^{1/E}. \end{aligned} \]

Since \(E>0\),

\[ G\geq\frac1K \quad\Longleftrightarrow\quad \left(\frac AC\right)^{1/E}\geq1 \quad\Longleftrightarrow\quad A\geq C. \]

All constructed rationals have polynomial encoding length. This proves the reduction. ∎

7. Consequences

The two reductions establish polynomial-time equivalence between the target problem and \(\mathrm{PoE}_{\ge}\).

In particular:

  • The weak \(\mathrm{NP}\)-hardness of the discrete selection problem does not transfer through the allocation structure. Arbitrary splitting convexifies each type’s choices, leaving a fractional-knapsack problem.
  • Exact arithmetic nevertheless prevents an unconditional claim that the problem is in \(\mathrm{P}\). This obstruction is already present when every type has only one action.
  • Under the Lang–Waldschmidt conjecture or Baker’s refined \(ABC\) conjecture, the problem is in \(\mathrm{P}\).
  • If the number of distinct input probabilities is bounded by a constant, the final comparison contains only constantly many bases, so the problem is unconditionally in \(\mathrm{P}\).
  • With an explicitly supplied inverse-polynomial promise gap between the optimal logarithmic value and \(\ln\theta\), polynomial-precision logarithmic approximation also yields a polynomial-time algorithm.

The unresolved point is therefore arithmetic rather than combinatorial.

Overall assessment

The prover gives a substantial and apparently correct polynomial-time equivalence between the continuous allocation problem and exact comparison of products of powers. The convex-hull reduction, fractional-knapsack optimization, forward reduction, and reverse reduction are internally consistent.

However, the output does not resolve the requested polynomial-time-versus-NP-hard dichotomy. Its assertion that the comparison problem is *currently* neither known to be in \(\mathrm P\) nor known to be NP-hard is supported only by a 2014 source. Because that present-day literature-status claim is central to the answer, it remains unverified as written.

Accordingly, the output constitutes genuine partial progress rather than a resolution of the target.

Step-by-step audit

1. Logarithmic reformulation and boundary cases

For \(0<\theta\leq 1\), the equivalence

\[ G(x)\geq\theta \quad\Longleftrightarrow\quad \sum_{t,j}x_{t,j}\ln p_{t,j}\geq\ln\theta \]

is correct because the exponential function is strictly increasing.

The statements for \(\theta>1\) and \(\theta=1\) are correct. In particular, since every \(\ln p_{t,j}\leq0\), equality \(G(x)=1\) requires every action receiving positive mass to have probability \(1\).

There is a minor incompleteness for \(\theta\leq0\). The statement that every *feasible* allocation satisfies the threshold does not itself decide whether a feasible allocation exists. Budget infeasibility must still be checked. This is routine but is not explicitly incorporated into the boundary-case algorithm.

There is also a minor notation problem later: types of zero mass are allowed to have empty menus, but \(C_0=\sum_t\mu_tb_{t,0}\) is undefined for such types. The sum should explicitly range only over types for which a baseline action was defined.

2. Use of the product-of-exponentials comparison result

The cited Etessami–Stewart–Yannakakis result does support the following claims:

  • exact equality is polynomial-time decidable;
  • exact inequality is polynomial-time decidable when the number of bases is a fixed constant;
  • the unrestricted inequality problem is polynomial-time decidable conditionally on the stated number-theoretic conjectures.

These claims agree with [the cited paper’s abstract and Proposition 3.7 discussion](https://arxiv.org/abs/1304.5429).

The paper does not, by itself, establish that the unrestricted problem remains unresolved in 2026. The prover supplies no current survey, later citation, or bounded literature check supporting the sentences “not currently known” and “cannot presently be resolved.” This is a major verification gap because those sentences are the central answer to the user’s target.

3. Upper-hull representation

Lemma 1 is correct for \(\mu_t>0\). Normalizing by \(y_{t,j}=x_{t,j}/\mu_t\) identifies the achievable cost-log-value pairs exactly with the scaled convex hull.

After retaining only the highest log value at each repeated cost, the leftmost upper-hull vertex indeed has minimum available cost. Ordering upper-hull vertices by cost gives decreasing segment slopes after removing collinear vertices, as required by concavity of the upper boundary.

4. Fractional-knapsack reduction

The baseline cost argument is valid: every allocation for type \(t\) has cost at least \(\mu_tb_{t,0}\), even when costs may be negative.

The segment formulation is also correct. Movement along an upper hull uses its segments in precedence order, and the decreasing-slope property ensures that globally sorting segments by decreasing slope respects this precedence. If slopes tie, putting an earlier segment before a later tied segment is sufficient.

Discarding nonpositive-slope segments is valid because the budget is an upper bound rather than an equality constraint.

Thus the fractional-knapsack argument correctly constructs an optimizer, subject to the zero-mass notation issue already noted.

5. Exact construction of the optimizer

A hull-orientation or slope-order comparison does reduce, after clearing rational cost denominators, to the sign of a linear form involving only constantly many logarithms of rational probabilities. Replacing each rational probability by a numerator and denominator produces at most eight positive-integer bases.

The cited fixed-base comparison theorem therefore applies after moving negative integer coefficients to the opposite side. The prover does not state this sign-splitting explicitly, but it is a routine representational step and does not undermine the conclusion.

The relevant rational coefficients have polynomial bit length because they arise from a polynomial number of additions, subtractions, and multiplications of binary-encoded rationals. The greedy allocation has at most one partially filled segment globally, and its interpolation weights are rational with polynomial encoding length. The optimizer-construction claim is therefore supported.

6. Forward reduction to product comparison

Taking \(Q\) to be the product of the denominators of the positive components of \(x^*\) is valid. Although \(Q\) may be numerically enormous, its bit length is bounded by the sum of the denominator bit lengths.

The equivalence

\[ G(x^*)\geq\theta \quad\Longleftrightarrow\quad \prod_{t,j}p_{t,j}^{Qx^*_{t,j}}\geq\theta^Q \]

is correct, and clearing rational bases produces a polynomial-size product-of-powers instance. Zero exponents can simply be omitted.

The write-up does not explicitly provide the fixed yes/no instances needed to make the reduction total for \(\theta\leq0\), \(\theta=1\), or \(\theta>1\). This is a minor many-one-reduction presentation gap, because those cases are decidable using rational comparisons alone.

7. Reverse reduction

The reverse reduction is algebraically correct. With \(E=U+V\), the unique singleton-menu allocation has

\[ G = \frac1K\left(\frac AC\right)^{1/E}, \]

and because \(E>0\),

\[ G\geq\frac1K \quad\Longleftrightarrow\quad A\geq C. \]

The constructed probabilities lie in \((0,1]\), all costs and the budget are zero, and the masses sum to one.

The encoding-length claim is also correct: sums such as \(E\) have polynomial binary length, and each rational \(u_i/E\), \(v_j/E\), \(a_i/K\), and \(1/(Kc_j)\) has polynomial encoding length.

This argument assumes the product-comparison instance contains at least one factor, so that \(E>0\). That matches the prover’s stated positive-list formulation; if empty lists were permitted, the trivial empty instance would need separate handling.

8. Consequences

The claimed polynomial-time equivalence follows from the two reductions, apart from the routine boundary-case presentation gaps.

The bounded-distinct-probabilities consequence is sound: a constant number of rational probabilities yields a constant number of numerator and denominator bases, with only the two threshold bases added.

The promise-gap statement is too informal to verify fully because “inverse-polynomial” is not explicitly tied to the input encoding length and the promise is not formally stated. It is auxiliary and does not affect the equivalence result.

Minimum clarification required

The prover should supply a current authoritative source, or explicitly delimit a documented literature search, establishing that unrestricted product-of-powers inequality comparison remains neither known to be in \(\mathrm P\) nor known to be NP-hard. It should also state how the elementary threshold cases are mapped in the claimed many-one reduction and restrict \(C_0\) to types with defined baseline actions.
