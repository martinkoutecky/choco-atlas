The continuous mirror question, as graded

Given \(n,k,\epsilon,\delta\) and a society \(\mu\) over strict-ranking types whose induced pairwise probabilities satisfy SST and STI, with access only through iid pairwise polls, what is the worst-case minimum expected number of polls needed by an adaptive policy to return \(U\), \(|U|=k\), with probability at least \(1-\delta\) such that \(p_{ij}\ge \frac12-\epsilon\) for every \(i\in U\) and \(j\notin U\)? Theorem 5 gives an \(O(n\epsilon^{-2}\log(k/\delta))\) upper bound, and Theorem 2 gives a matching worst-case lower bound up to constants in its stated parameter range.

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge2\), \(1\le k\le\lfloor m/2\rfloor\), and binary rationals \(\epsilon,\delta\in(0,1/2)\) be given.
A society is given by its support: \(\tau\) distinct strict complete rankings \(\sigma_a\), each with positive binary-rational mass \(w_a\), with \(\sum_a w_a=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
Define \(p_{ij}=\sum_{a:i\text{ precedes }j\text{ in }\sigma_a}w_a\) for distinct items, \(p_{ii}=1/2\), and \(\Delta_{ij}=|p_{ij}-1/2|\).
Promise SST: there exists a strict total order \(\succ\) such that \(i\succ j\) implies \(p_{ij}>1/2\), and \(i\succ j\succ\ell\) implies \(p_{i\ell}\ge\max\{p_{ij},p_{j\ell}\}\). Promise STI: \(\Delta_{i\ell}\le\Delta_{ij}+\Delta_{j\ell}\) for all items.
A policy may inspect the support and adaptively query distinct pairs. Each query independently draws a fresh ranking from the society and returns the item ranked higher; each query costs one comparison.
The policy must terminate and return \(U\) with \(|U|=k\), satisfying \(p_{ij}\ge1/2-\epsilon\) for every \(i\in U,j\notin U\), with probability at least \(1-\delta\) on every promised input. Its objective is to minimize worst-case expected comparisons over promised inputs with the specified parameters.

Is there a policy attaining the minimum worst-case expected comparison count with expected running time polynomial in \(m,\tau,L,k\), or is this policy optimization problem NP-hard?

For independent comparison oracles satisfying SST and STI, an algorithm uses \(O(m\epsilon^{-2}\log(k/\delta))\) expected comparisons; a matching worst-instance lower bound holds for \(\epsilon\in(0,1/128)\), \(\delta\in(0,e^{-4}/4)\). [Source](https://proceedings.mlr.press/v119/ren20a/ren20a.pdf).
The oracle upper bound also covers comparisons generated by ranking distributions, but does not classify optimization when the rational support is available to the policy.

Result

The minimum worst-case expected comparison count is \(0\), and a deterministic policy attains it in polynomial running time.

The explicit weighted support makes oracle queries unnecessary. This settles the entire stated parameter range; the computational point to verify is that the policy can recover a suitable set using exact rational arithmetic in polynomial time.

1. Compute the pairwise probabilities exactly

Label the items by \(\{1,\ldots,m\}\). Write each supplied weight as \(w_a=n_a/q_a\), where \(n_a,q_a\) are positive integers encoded in binary. Define

\(Q=\prod_{a=1}^{\tau}q_a,\qquad W_a=n_a(Q/q_a).\)

Then \(W_a=Qw_a\) is an integer, and the normalization of the weights gives

\(\sum_{a=1}^{\tau}W_a=Q.\)

For each ranking, construct its position array \(\operatorname{pos}_a(i)\). For each pair of distinct items, compute

\(N_{ij}=\sum_{a:\operatorname{pos}_a(i)<\operatorname{pos}_a(j)}W_a.\)

By the definition of the society,

\(p_{ij}=N_{ij}/Q.\)

Consequently, the policy determines whether \(p_{ij}>1/2\) by the exact integer test \(2N_{ij}>Q\). These are computations on the supplied input and require no oracle queries.

Because every support ranking is strict and complete, exactly one of \(i,j\) precedes the other in each ranking. Thus

\(p_{ij}+p_{ji}=1\)

for every pair of distinct items.

2. Recover the promised order

Let \(r_1\succ r_2\succ\cdots\succ r_m\) be an order whose existence is guaranteed by SST.

For \(s<t\), the strict-majority part of SST gives \(p_{r_s r_t}>1/2\). Conversely, for \(s>t\), it gives \(p_{r_t r_s}>1/2\), and the complement identity implies \(p_{r_s r_t}<1/2\).

Therefore, the relation \(p_{ij}>1/2\) agrees exactly with the promised order.

Compute each item's number of majority victories,

\(d_i=\bigl|\{j\ne i:2N_{ij}>Q\}\bigr|.\)

An item \(r_s\) defeats precisely the \(m-s\) items below it, so

\(d_{r_s}=m-s.\)

In particular, the victory counts are exactly the distinct integers \(\{0,\ldots,m-1\}\). The policy returns

\(U=\{i:d_i\ge m-k\}.\)

It follows that \(U=\{r_1,\ldots,r_k\}\), and hence \(|U|=k\).

For every \(i\in U\) and \(j\notin U\), we have \(i\succ j\), so

\(p_{ij}>1/2>1/2-\epsilon.\)

The returned set therefore satisfies the required condition deterministically, with success probability \(1\), which is at least \(1-\delta\). Neither STI nor the additional three-item inequality in SST is needed for this construction.

3. Polynomial bit complexity

The binary length of \(Q\) is at most \(1+\sum_a\log_2 q_a\), and therefore is \(O(L)\). Also, positivity and normalization give

\(0<W_a\le Q,\qquad 0\le N_{ij}\le Q.\)

Thus every integer used in computing the weights and pairwise sums has \(O(L)\) bits. Victory counters have \(O(\log m)\) bits.

Constructing the position arrays takes \(O(\tau m)\) entries. Computing all pairwise sums uses \(O(\tau m^2)\) additions and position tests; computing the victory counts uses \(O(m^2)\) integer comparisons. Forming \(Q\) and the integers \(W_a\) requires \(O(\tau)\) multiplications and exact divisions on integers of \(O(L)\) bits.

Elementary binary arithmetic performs each such operation in polynomial time in \(L\). Consequently, the policy terminates in deterministic time polynomial in \(m,\tau,L,k\). Its expected running time has the same bound.

4. Exact optimality and the oracle bounds

Let \(C_\pi(S)\) denote the number of oracle queries made by an admissible policy \(\pi\) on society \(S\). Query counts are nonnegative, so every admissible policy satisfies

\(\sup_S\mathbb{E}[C_\pi(S)]\ge 0.\)

For the constructed policy \(\pi_0\), we have \(C_{\pi_0}(S)=0\) on every promised input. Hence

\(\min_{\pi}\sup_S\mathbb{E}[C_\pi(S)]=0,\)

with the minimum attained by \(\pi_0\).

The cited paper studies an unknown true ranking learned through noisy comparison outcomes. Its positive comparison lower bound concerns that information model. The present policy additionally receives the exact weighted support, from which it computes the probabilities directly; this explains why that lower bound does not apply here. [Ren, Liu, and Shroff, Sections 1.2 and 3.1](https://proceedings.mlr.press/v119/ren20a/ren20a.pdf).
