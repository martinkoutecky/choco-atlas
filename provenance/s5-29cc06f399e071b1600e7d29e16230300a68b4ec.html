The continuous mirror question, as graded

Given a finite school set \(S\), finite type set \(\Theta\), rational masses \(\mu_\theta\), per-capita capacities \(\kappa_s\), type data \((v_\theta,\Lambda_\theta,\omega_\theta,\pi_\theta)\), homogeneous school priorities, and an explicit lottery rule when capacity cuts through a priority block, compute a pure nonatomic DSPDA reporting equilibrium \(\sigma:\Theta\to\mathcal R\). An infinitesimal agent of each type must weakly prefer its report to every alternative under the induced lottery, and the output must include the allocation masses \(x_{\theta,s}\) or report nonexistence.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_\theta\mu_\theta=1\), and let \(L\) be the total input bit length.
Let \(S\) contain \(m\ge2\) schools, including an outside option \(0\) with capacity \(\kappa_0=1\) and value \(v_{\theta,0}=0\). Other capacities are positive binary rationals. Type data are binary rational values \(v_{\theta,s}\in\mathbb R\), loss dominance \(\Lambda_\theta\ge0\), and common school priority \(\omega_\theta\in[0,1]\); higher priority is preferred at every school.
Reports \(\mathcal R\) are all strict permutations of \(S\); placing schools after \(0\) permits truncation, including abstention. Equal match values are allowed.
Fix the lottery rule as follows: after reports are submitted, agents receive unobserved uniform keys \(u\in[0,1]\), shared across schools; type \(\theta\) has mass density \(\mu_\theta\,du\). Define nonatomic DSPDA by processing scores in decreasing order and keys within each score in increasing order, assigning each infinitesimal agent its highest reported school with remaining capacity.
For a profile \(\sigma:\Theta\to\mathcal R\), let \(F_\theta(r;\sigma)\) be the school lottery obtained by an infinitesimal type-\(\theta\) agent reporting \(r\), with aggregate reports fixed. Beliefs \(\pi_\theta\) are correct beliefs induced by this rule and profile, rather than independent subjective inputs.
Evaluate any lottery \(F=(f_s)_{s\in S}\) by \(U_\theta(F)=\sum_s f_s v_{\theta,s}-\frac{\Lambda_\theta}{2}\sum_{s,t}f_sf_t|v_{\theta,s}-v_{\theta,t}|\); each alternative report supplies its own reference lottery.
A pure reporting equilibrium satisfies \(U_\theta(F_\theta(\sigma(\theta);\sigma))\ge U_\theta(F_\theta(r;\sigma))\) for every \(\theta\) and \(r\in\mathcal R\). Its allocation masses are \(x_{\theta,s}=\mu_\theta F_{\theta,s}(\sigma(\theta);\sigma)\).
Can an exact pure reporting equilibrium and its allocation masses, or a determination of nonexistence, be computed in polynomial time in \(m,\tau,L\), or is this computational problem NP-hard?
For finite students and finite type spaces, homogeneous priorities with a common deterministic tie-breaking rule admit an essentially unique pure choice-acclimating Bayesian Nash equilibrium after report indifferences are resolved publicly ([2019 result](https://rationality-and-competition.de/wp-content/uploads/2019/12/208.pdf)).
A later version establishes mixed-strategy equilibrium existence for finite type spaces ([later result](https://arxiv.org/html/2207.14666)); neither statement supplies a polynomial-time complexity bound. No result settling the exact nonatomic problem above was identified.

Modeling choices made when packaging the task

  • Normalize total population mass to one so that per-capita capacities have an unambiguous meaning.
  • Include a zero-valued outside option with capacity one; full permutations then preserve truncation and abstention.
  • Use rational match values of either sign, nonnegative rational loss dominance, positive rational school capacities, and rational common priority scores in the unit interval.
  • Resolve the unspecified lottery rule using a uniform individual key shared across schools and unknown when reports are chosen; specify its continuum allocation through common-priority processing.
  • Interpret the undefined belief datum pi as correct beliefs induced by the profile and lottery, consistent with Bayesian equilibrium, rather than arbitrary subjective beliefs.
  • Require one report per supported type, chosen before lottery keys are revealed; deviations change only an infinitesimal agent's report.
  • Allow equal match values and weak best-response inequalities without imposing an equilibrium selection rule.

Result

The requested computational problem is \(\mathrm{NP}\text{-hard}\). Indeed, deciding whether a pure reporting equilibrium exists is \(\mathrm{NP}\text{-complete}\) already for a restricted family with:

  • \(m=2\): one school and the outside option;
  • identical priorities \(\omega_\theta=\frac12\);
  • identical loss dominance \(\Lambda_\theta=2\);
  • dyadic rational masses and capacities.

The reduction uses the specified infinitesimal-deviation equilibrium condition: a deviation changes an individual’s report while keeping aggregate reports fixed.

1. Exact lotteries with two schools

Let \(S=\{0,1\}\), with \(\kappa_0=1\) and \(\kappa_1=\kappa>0\). Suppose every type has the same priority. There are exactly two reports:

  • Apply: \((1,0)\).
  • Abstain: \((0,1)\).

For any profile, let \(A\) be the total mass reporting Apply.

At key \(u<1\), the total mass processed is \(u\). Consequently, the mass already assigned to the outside option is at most \(u<1\), so the outside option remains available. Abstain therefore gives the outside option with certainty.

Before school \(1\) fills, its assignment rate is \(A\,du\). Thus an infinitesimal agent reporting Apply obtains school \(1\) with probability

\(\displaystyle q(A)= \begin{cases} 1,&A=0,\\ \min\{1,\kappa/A\},&A>0. \end{cases}\)

This formula also applies to an infinitesimal deviator whose type currently abstains: aggregate reports remain fixed, and the deviator’s key is uniform and unobserved. Whether the agent at the exact exhaustion key is admitted has no effect on the lottery.

Write \(v=v_{\theta,1}\). Applying induces probabilities \(q\) and \(1-q\) on values \(v\) and \(0\). Substitution into the stipulated utility gives

\(\displaystyle U_\theta(\mathrm{Apply})=qv-\Lambda_\theta q(1-q)|v|,\qquad U_\theta(\mathrm{Abstain})=0.\)

In particular, when \(\Lambda_\theta=2\) and \(v>0\),

\(\displaystyle U_\theta(\mathrm{Apply})=vq(2q-1).\)

Because \(\kappa>0\) and \(A\leq1\), we always have \(q>0\). Therefore a positive-value type strictly prefers Apply when \(q>\frac12\), strictly prefers Abstain when \(q<\frac12\), and is indifferent exactly when \(q=\frac12\).

For \(v=-1\) and \(\Lambda_\theta=2\),

\(\displaystyle U_\theta(\mathrm{Apply})=-q-2q(1-q)<0.\)

Such a type strictly prefers Abstain under every profile.

2. Polynomial reduction from Partition

Use the standard \(\mathrm{NP}\text{-complete}\) problem \(\mathrm{PARTITION}\): given positive binary integers \(a_1,\ldots,a_n\), determine whether some subset \(I\subseteq\{1,\ldots,n\}\) satisfies

\(\displaystyle \sum_{i\in I}a_i=\frac12\sum_{i=1}^n a_i.\)

Its completeness is a classical result of [Karp](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Set \(W=\sum_{i=1}^n a_i\), and choose \(D=2^d\) to be the smallest power of two strictly greater than \(W\).

Construct \(n+1\) supported types. For each \(i\in\{1,\ldots,n\}\), set

\(\displaystyle \mu_i=\frac{a_i}{D},\qquad v_{i,1}=i,\qquad v_{i,0}=0,\qquad \Lambda_i=2,\qquad \omega_i=\frac12.\)

Introduce a padding type \(\ast\) with

\(\displaystyle \mu_\ast=1-\frac WD,\qquad v_{\ast,1}=-1,\qquad v_{\ast,0}=0,\qquad \Lambda_\ast=2,\qquad \omega_\ast=\frac12.\)

Finally, set

\(\displaystyle \kappa_0=1,\qquad \kappa_1=\frac{W}{4D}.\)

Every mass and capacity is positive. The masses sum to one. All rational data are dyadic, so the construction works even if “binary rational” requires a finite binary expansion.

The positive-value types are distinct because their school values are distinct; the padding type is also distinct. Hence the actual support size is \(\tau=n+1\).

The bit length of \(D\) is \(O(\log W)\), and each value \(i\) has bit length \(O(\log n)\). Since \(\log W\) is polynomially bounded by the Partition input length, the entire construction takes polynomial time and has polynomial output length.

3. Equilibrium existence is equivalent to partition

The padding type strictly prefers Abstain by Section 1. Thus, in any equilibrium, the applicant mass has the form

\(\displaystyle A=\sum_{i\in I}\frac{a_i}{D}\)

for some subset \(I\) of positive-value types. Write \(M=W/D\) for their total mass.

Necessity

Suppose a pure equilibrium exists, and let \(q=q(A)\).

If \(q>\frac12\), every positive-value type strictly prefers Apply. Equilibrium would therefore require \(A=M\). But then

\(\displaystyle q=\frac{\kappa_1}{M}=\frac{W/(4D)}{W/D}=\frac14,\)

a contradiction.

If \(q<\frac12\), every positive-value type strictly prefers Abstain. Equilibrium would therefore require \(A=0\), which gives \(q=1\), again a contradiction.

Consequently, every equilibrium must satisfy \(q=\frac12\). In particular, \(A>0\), and the lottery formula implies

\(\displaystyle \frac{\kappa_1}{A}=\frac12,\qquad A=2\kappa_1=\frac{W}{2D}.\)

Combining this with the definition of \(A\) yields

\(\displaystyle \sum_{i\in I}a_i=\frac W2.\)

Thus equilibrium existence implies a YES instance of Partition.

Sufficiency

Conversely, suppose \(I\) satisfies \(\sum_{i\in I}a_i=W/2\).

Let precisely the types in \(I\) report Apply. Let all other types, including the padding type, report Abstain. Then

\(\displaystyle A=\frac{W}{2D},\qquad q=\frac{\kappa_1}{A}=\frac12.\)

Every positive-value type is indifferent between the two reports. The padding type strictly prefers its chosen report, Abstain. Since these are the only possible reports, all equilibrium inequalities hold.

Therefore,

\(\displaystyle \text{a pure reporting equilibrium exists}\quad\Longleftrightarrow\quad \text{the Partition instance is YES}.\)

4. Allocation masses and complexity consequence

For a partition witness \(I\), the associated equilibrium allocation is explicit:

\(\displaystyle (x_{i,1},x_{i,0})= \begin{cases} \left(\frac{a_i}{2D},\frac{a_i}{2D}\right),&i\in I,\\ \left(0,\frac{a_i}{D}\right),&i\notin I, \end{cases}\)

and

\(\displaystyle (x_{\ast,1},x_{\ast,0})=\left(0,1-\frac WD\right).\)

School \(1\) receives total mass \(\sum_{i\in I}a_i/(2D)=W/(4D)=\kappa_1\), as required.

On this restricted family, equilibrium existence belongs to \(\mathrm{NP}\): a certificate specifies the applying types, and the rational calculations in Section 1 verify every equilibrium inequality in polynomial time. Together with the reduction, this establishes \(\mathrm{NP}\text{-completeness}\) of restricted equilibrium existence.

An algorithm polynomial in \(m,\tau,L\) that always returns an exact pure equilibrium and its allocation, or correctly reports nonexistence, would decide Partition in polynomial time. Thus the requested problem is \(\mathrm{NP}\text{-hard}\), and such an algorithm cannot exist unless \(\mathrm{P}=\mathrm{NP}\).

5. Relation to the cited existence results

The [2019 pure-existence argument](https://rationality-and-competition.de/wp-content/uploads/2019/12/208.pdf) uses a publicly known deterministic tie-breaking order and proceeds through priority positions. Here keys are unobserved when reports are submitted, and a pure profile assigns one report to the entire positive mass of each supported type. These are different hypotheses.

Likewise, the [later mixed-existence theorem](https://arxiv.org/html/2207.14666) concerns finite students and permits mixed reports. The reduction concerns exactly the pure, type-constant nonatomic profiles requested here.

The hardness comes from an exact requirement: positive-value types can simultaneously apply and abstain only at admission probability \(q=\frac12\), forcing a subset of supported type masses to sum to a prescribed target.
