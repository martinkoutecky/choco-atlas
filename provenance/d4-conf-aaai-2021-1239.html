The continuous mirror question, as graded

Given alternatives \(X\), ranking types \(T=\mathcal{L}(X)\), a target rational society \(\mu^\star\), a desired outcome \(X^\star\), and a finite quantifier-free corpus \(A\) of grounded outcome constraints at listed rational societies \(\mu_j\), does there exist \(A_N\subseteq A\) and an explanation \(A_E\) consisting of instances of \(A_N\) such that \(A_N\) is satisfied by some population rule \(F:\Delta(T)\to 2^X\setminus\{\varnothing\}\), every rule satisfying \(A_E\) selects exactly \(X^\star\) at \(\mu^\star\), and no proper subset of \(A_E\) forces that outcome?

Packaged proof task (what the prover saw — nothing else)

Let \(X\) contain \(m\geq 1\) alternatives, let \(T=\mathcal L(X)\) be the strict ranking types, and let \(\Delta(T)\) be the distributions on \(T\) with nonnegative masses summing to \(1\).
A society is given by its support: the list of its \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) denotes the maximum support size among input societies, not the number \(m!\) of possible types.
The input comprises a target rational society \(\mu^\star\), a nonempty desired outcome \(X^\star\subseteq X\), listed rational societies \(\mu_1,\ldots,\mu_q\), and a finite corpus \(A\) of explicitly written Boolean formulas over atoms \(o(x,\mu_j)\), using negation and conjunction with the usual Boolean abbreviations.
A population rule is any function \(F:\Delta(T)\to 2^X\setminus\{\varnothing\}\); the atom \(o(x,\mu_j)\) means \(x\in F(\mu_j)\). Equal distributions denote the same society. Satisfaction uses ordinary Boolean semantics.
Because the corpus is quantifier-free, a formula's only instance is itself: an explanation therefore satisfies \(A_E\subseteq A_N\subseteq A\).
Call such a pair a justification if some rule satisfies \(A_N\), every rule satisfying \(A_E\) has \(F(\mu^\star)=X^\star\), and for every \(B\subsetneq A_E\) some rule satisfying \(B\) has \(F(\mu^\star)\neq X^\star\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,q,|A|,L\).

Is deciding whether a justification exists solvable in polynomial time, or is it NP-hard?

For finite electorates with explicitly given quantifier-free corpora, justification existence is \(\Sigma_2^P\)-complete. [Boixel and de Haan](https://ojs.aaai.org/index.php/AAAI/article/download/16656/16463)
No result for exactly the distribution-based problem above was located in the literature search.

Modeling choices made when packaging the task

  • Specified strict ranking types and normalized nonnegative masses, following the stated distribution domain.
  • Specified grounded outcome constraints as explicitly written arbitrary Boolean formulas over outcome-membership atoms, preserving the quantifier-free language's Boolean expressiveness.
  • Made instancehood the identity relation on quantifier-free formulas, so A_E is a subset of A_N; extracting subformulas is not an allowed instantiation.
  • Required a nonempty desired outcome, consistent with the rule's nonempty winning sets.
  • Allowed arbitrary population rules on the entire simplex, without additional regularity requirements, and identified society constants representing equal distributions.
  • Defined tau as the maximum input support size and L as total binary input length, and included the number of listed societies and corpus size as runtime parameters.
  • Interpreted minimality witnesses as rules satisfying each proper subset of the explanation, consistent with the discrete algorithm's use of the definition.

Result

The problem is \(\Sigma_2^P\)-complete, and therefore NP-hard. Hardness holds even when \(m=2\) and \(\tau=2\).

The proof below applies directly to rational distributions; it does not require transferring the finite-electorate result.

1. Minimality can be handled by finite deletion

Write \(G\) for the condition \(F(\mu^\star)=X^\star\). A set of formulas is *satisfiable* if some population rule satisfies every formula in it.

Lemma. A justification exists if and only if there is a satisfiable subset \(S\subseteq A\) such that every rule satisfying \(S\) satisfies \(G\).

Proof. If \((A_N,A_E)\) is a justification, a rule satisfying \(A_N\) also satisfies \(A_E\), because \(A_E\subseteq A_N\). Thus \(S=A_E\) is satisfiable and forces \(G\).

Conversely, suppose such an \(S\) exists. Because \(S\) is finite, choose an inclusion-minimal subset \(E\subseteq S\) that forces \(G\). The rule witnessing satisfiability of \(S\) also witnesses satisfiability of \(E\). For every proper subset \(B\subsetneq E\), minimality means that \(B\) does not force \(G\); equivalently, some rule satisfies \(B\) and violates \(G\). Hence \(A_N=A_E=E\) is a justification. \(\square\)

For the degenerate case \(m=1\), every rule necessarily returns \(X=X^\star\), so the empty pair is always a justification. The hardness construction uses \(m=2\).

2. The rule semantics have a polynomial-size Boolean representation

Identify equal distributions among \(\mu^\star,\mu_1,\ldots,\mu_q\), and let their distinct values be \(\nu_1,\ldots,\nu_r\), where \(r\leq q+1\).

For every \(s\in\{1,\ldots,r\}\) and \(x\in X\), introduce a Boolean variable \(z_{s,x}\). Its intended meaning is \(x\in F(\nu_s)\). Valid assignments are exactly those satisfying

\(D=\displaystyle\bigwedge_{s=1}^{r}\left(\bigvee_{x\in X}z_{s,x}\right).\)

Indeed, each conjunct requires a nonempty outcome. Conversely, every assignment satisfying \(D\) extends to a population rule: use the assigned outcomes on these distinct societies and a fixed singleton outcome everywhere else.

Replace each corpus atom by its corresponding variable. If \(\nu_{s^\star}=\mu^\star\), the target condition becomes

\(G=\displaystyle\left(\bigwedge_{x\in X^\star}z_{s^\star,x}\right)\wedge\left(\bigwedge_{x\in X\setminus X^\star}\neg z_{s^\star,x}\right).\)

Thus, for any \(S\subseteq A\), rule satisfiability is precisely satisfiability of \(D\wedge\bigwedge_{\alpha\in S}\alpha\), and forcing the target means that this Boolean formula entails \(G\). This representation uses \(N=mr\leq m(q+1)\) variables. It never enumerates the \(m!\) ranking types.

Distribution equality is also polynomial-time computable. Match the explicitly listed rankings and compare their rational masses exactly by cross multiplication. Comparing all pairs of societies by a straightforward implementation takes at most

\(P=O\!\left((q+1)^2\tau^2L^2\right)\)

bit operations: there are at most \(\tau^2\) support-entry comparisons per society pair, and an entry comparison costs at most \(O(L^2)\).

3. Membership in \(\Sigma_2^P\) and running times

Let \(a=|A|\). By the lemma, it suffices to guess a subset \(S\subseteq A\) and a valid Boolean assignment \(v\) satisfying \(S\), then require every valid assignment satisfying \(S\) to satisfy \(G\).

More explicitly, if \(C_S=\bigwedge_{\alpha\in S}\alpha\), the required condition is

\(\displaystyle\exists(S,v)\ \forall w:\quad D(v)\wedge C_S(v)\wedge\bigl(\neg D(w)\vee\neg C_S(w)\vee G(w)\bigr).\)

Here \(S\) uses \(a\) bits, and each assignment uses \(N\leq m(q+1)\) bits. The predicate is polynomial-time evaluable. This proves membership in \(\Sigma_2^P\).

For explicit running-time bounds, a conservative bit-operation bound for evaluating the predicate after preprocessing is

\(O\!\left((L+a+m(q+1))^2\right).\)

Equivalently, a nondeterministic algorithm guesses \(S\) and its satisfying assignment, then makes one NP-oracle query asking whether a valid counterexample to \(G\) exists. Its non-oracle work is bounded by

\(O\!\left(P+(L+a+m(q+1))^2\right).\)

A deterministic exhaustive algorithm scans all assignments for each subset \(S\), recording whether \(S\) has a valid model and whether it has a valid model violating \(G\). Its running time is bounded by

\(O\!\left((q+1)^2\tau^2L^2+2^{\,|A|+m(q+1)}(L+|A|+m(q+1))^2\right).\)

4. Hardness with two alternatives and support size two

We reduce from the standard \(\Sigma_2^P\)-complete problem of deciding the truth of a quantified Boolean formula

\(\displaystyle\exists u_1,\ldots,u_k\ \forall v_1,\ldots,v_\ell:\ \varphi(u_1,\ldots,u_k,v_1,\ldots,v_\ell),\)

where \(\varphi\) is explicitly given in \(3\)-DNF. This source problem and its completeness are stated in the proof of Theorem 6 of [Boixel and de Haan](https://ojs.aaai.org/index.php/AAAI/article/download/16656/16463).

Put \(n=k+\ell\). We may assume \(n\geq1\), since adding an unused variable preserves truth.

Constructing distinct rational societies

Set \(X=\{a,b\}\), with ranking types \(t_+=(a\succ b)\) and \(t_-=(b\succ a)\). Choose

\(D_0=2^{\lceil\log_2(n+2)\rceil}.\)

For each \(i\in\{1,\ldots,n+1\}\), define

\(\mu_i(t_+)=i/D_0,\qquad \mu_i(t_-)=(D_0-i)/D_0.\)

Both masses are positive, sum to one, and are dyadic rationals with \(O(\log(n+2))\)-bit encodings. The societies are pairwise distinct because their masses on \(t_+\) differ.

Take \(q=n+1\), \(\mu^\star=\mu_{n+1}\), and \(X^\star=\{a\}\). Thus every society has support size exactly two.

Constructing the corpus

For \(i\leq n\), write \(p_i=o(a,\mu_i)\). Interpret \(p_1,\ldots,p_k\) as the existential variables and \(p_{k+1},\ldots,p_n\) as the universal variables. Let \(\widehat\varphi\) be the resulting atom substitution in \(\varphi\).

Define

\(G=o(a,\mu_{n+1})\wedge\neg o(b,\mu_{n+1}),\qquad h=\neg\widehat\varphi\vee G,\)

and set

\(A=\{p_i,\neg p_i:1\leq i\leq k\}\cup\{h\}.\)

All formulas are quantifier-free and use the permitted Boolean abbreviations.

Every assignment to \(p_1,\ldots,p_n\) is realizable: choose outcome \(\{a\}\) at \(\mu_i\) when \(p_i\) is true and \(\{b\}\) when it is false. Independently, choosing \(\{a\}\) at the target makes \(G\) true, while choosing \(\{b\}\) makes \(G\) false. Independence holds because all these societies are distinct.

Forward implication

Suppose the quantified formula is true. Let \(\alpha\) be an existential assignment witnessing its truth, and choose

\(S_\alpha=\{h\}\cup\{p_i:\alpha(u_i)=1\}\cup\{\neg p_i:\alpha(u_i)=0\}.\)

This set is satisfiable: realize the selected existential assignment, choose arbitrary universal values, and choose target outcome \(\{a\}\). Then \(G\), and hence \(h\), is true.

Now consider any rule satisfying \(S_\alpha\). Its existential values equal \(\alpha\), and its universal values form some assignment \(\beta\). By the defining property of \(\alpha\), \(\widehat\varphi\) is true. Since the rule also satisfies \(h=\neg\widehat\varphi\vee G\), it must satisfy \(G\).

Thus \(S_\alpha\) is satisfiable and forces the target. The lemma gives a justification.

Reverse implication

Suppose a justification exists. By the lemma, there is a satisfiable \(S\subseteq A\) forcing \(G\).

First, \(h\in S\). Otherwise, every formula in \(S\) concerns a non-target society. Modify a rule satisfying \(S\) only at the target, giving it outcome \(\{b\}\). The modified rule still satisfies \(S\), but violates \(G\), a contradiction.

Second, \(S\) cannot contain both \(p_i\) and \(\neg p_i\), because \(S\) is satisfiable. Its selected literals therefore define a consistent partial assignment to the existential variables. Extend that assignment arbitrarily to a total assignment \(\alpha\).

Fix any assignment \(\beta\) to the universal variables. If \(\varphi(\alpha,\beta)\) were false, realize \(\alpha,\beta\) at the corresponding societies and give the target outcome \(\{b\}\). Every selected literal is satisfied. Moreover, \(\widehat\varphi\) is false, so \(h\) is satisfied even though \(G\) is false. This would be a rule satisfying \(S\) and violating \(G\), again a contradiction.

Consequently, \(\varphi(\alpha,\beta)\) is true for every \(\beta\). The quantified formula is true.

Size and construction time

The reduction has parameters

\(m=2,\qquad \tau=2,\qquad q=n+1,\qquad |A|=2k+1.\)

If \(K\) is the total bit length of the source instance, the constructed input has length \(O(K\log(K+2))\) and can be produced in polynomial time. Boolean abbreviations expand into negation and conjunction with only a linear increase in formula length.

Both directions are proved, so this is a polynomial-time many-one reduction.

Conclusion

Justification existence is \(\Sigma_2^P\)-complete, even with two alternatives and support size two. In particular, it is NP-hard and cannot be polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).
