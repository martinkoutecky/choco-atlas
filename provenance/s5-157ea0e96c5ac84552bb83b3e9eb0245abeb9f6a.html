The continuous mirror question, as graded

Given item classes \(M\), types \(T\) with rational masses \(\mu_t\), a finite OR bid menu for each type, and rational per-capita supplies \(\kappa_j\), find a mass allocation maximizing total bid value. Each agent receives an integral feasible pack of pairwise-disjoint bids, while the aggregate use of each item class \(j\) is at most \(\kappa_j\). Require WPM: whenever positive mass receives a pack containing \((B',a')\), no supported type has a bid \((B,a)\) with \(B\subseteq B'\) and \(a>a'\). The decision version asks whether such an allocation has value at least \(R\).

Packaged proof task (what the prover saw — nothing else)

Let \(M\) be \(m\geq 1\) item classes. A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has an explicitly listed finite OR bid menu \(D_t\). A bid \((B,a)\) has \(\varnothing\neq B\subseteq M\) and positive rational value \(a\). Supplies \(\kappa_j\) are nonnegative binary rationals, and the threshold \(R\) is rational.
A feasible pack \(P\subseteq D_t\) consists of bids with pairwise-disjoint bundles; the empty pack is allowed. Its value is \(v(P)=\sum_{(B,a)\in P}a\), and its use of class \(j\) is \(u_j(P)=\mathbf{1}\{j\in\bigcup_{(B,a)\in P}B\}\).
A mass allocation assigns nonnegative real masses \(x_{t,P}\) to feasible packs, with \(\sum_Px_{t,P}=\mu_t\) and \(\sum_{t,P}x_{t,P}u_j(P)\leq\kappa_j\) for every \(j\). Thus each individual receives an integral pack, while a type's mass may be split among packs.
Winner-price-monotonicity (WPM) requires that whenever \(x_{t,P}>0\) and \((B',a')\in P\), there is no bid \((B,a)\in D_s\) of any supported type \(s\), including \(s=t\), with \(B\subseteq B'\) and \(a>a'\). Equal values do not violate WPM.
The decision problem asks whether a WPM mass allocation has total value \(\sum_{t,P}x_{t,P}v(P)\geq R\). Write running times in \(m\), \(\tau\), the total number \(q\) of listed bids, and the total input bit length \(L\).

Is this WPM mass-allocation decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite bidders, greedy and hill-climbing winner-determination algorithms have a final-allocation WPM guarantee; this is a property guarantee, not an exact-optimization complexity classification. [Verified extended treatment](https://www.agent.soc.i.kyoto-u.ac.jp/~ito/papers/fukuta-WAIS2009.pdf).
No result settling exactly the mass-allocation decision problem above was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive rational type masses to sum to one, interpreting supplies and objective values per capita.
  • Required nonempty bid bundles and positive rational bid values, following the discrete bid domain and WPM definition; required at least one item class.
  • Allowed nonnegative rational supplies and a rational threshold, since the continuous supply and threshold domains were unspecified.
  • Made a pack a subset of the listed menu, allowed the empty pack, and made OR pack values additive.
  • Specified that type mass can be divided among integral packs using nonnegative real allocation masses.
  • Made WPM comparisons range over all listed bids of supported types, including the receiving type, regardless of whether the competing bid is allocated; equal values are permitted.
  • Specified explicit menu encoding and included the total listed-bid count and total input bit length in running-time parameters.

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even with \(\tau=1\), unit mass, unit supplies, unit bid values, and every bundle containing exactly three item classes.

The proof uses the stated definition of WPM, including its strict comparison of bid values.

1. WPM is a polynomial-time restriction on individual bids

Call a listed bid \((B',a')\in D_t\) *admissible* if there is no listed bid \((B,a)\), across all supported types, satisfying \(B\subseteq B'\) and \(a>a'\). Let \(D_t^\ast\) contain precisely the admissible bids of type \(t\).

An allocation satisfies WPM if and only if every pack assigned positive mass consists entirely of admissible bids. Indeed, an inadmissible bid in such a pack directly violates WPM; conversely, admissibility excludes every possible witness to a violation.

Thus we can first delete all inadmissible bids, checking dominance against the original menus. Comparing all pairs takes \(O(L+qm+q^2(m+L^2))\) bit operations using bundle incidence vectors and ordinary integer arithmetic.

The remaining difficulty is optimizing over disjoint packs.

2. Polynomial-time reduction from perfect three-dimensional matching

We use the standard \(\mathrm{NP}\)-complete problem perfect three-dimensional matching: given three disjoint sets \(X,Y,Z\), each of cardinality \(n\geq1\), and an explicitly listed set \(E\subseteq X\times Y\times Z\), decide whether \(E\) contains \(n\) triples having no repeated coordinate. This is the three-dimensional matching problem in [Karp’s original completeness theorem](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Construct the following mass-allocation instance:

  • \(M=X\cup Y\cup Z\), so \(m=3n\).
  • There is one supported type \(t\), with \(\mu_t=1\).
  • For every \((x,y,z)\in E\), list the bid \((\{x,y,z\},1)\) in \(D_t\).
  • Set \(\kappa_j=1\) for every \(j\in M\).
  • Set \(R=n\).

Here \(q=|E|\). All bundles are nonempty, and all numerical data satisfy the required encoding conditions. After relabeling classes, the construction takes \(O((m+q)\log(m+2))\) bit operations and produces an instance of that bit length.

Every pack satisfies WPM. All listed values equal \(1\), so the strict inequality required for a WPM violation never holds.

Packs are exactly three-dimensional matchings. Because \(X,Y,Z\) are disjoint, two constructed bundles intersect exactly when their source triples share a coordinate. Consequently, a feasible pack \(P\) is a matching and has value \(v(P)=|P|\leq n\).

If the matching instance is yes, assign the entire mass to a perfect matching pack \(P\). Each class is used once, so every supply constraint holds, and the total value is \(n=R\).

If the allocation instance is yes, its value satisfies

\(\displaystyle n\leq\sum_P x_{t,P}|P|\leq n\sum_Px_{t,P}=n.\)

If no pack had cardinality \(n\), every pack would have cardinality at most \(n-1\), and therefore

\(\displaystyle \sum_Px_{t,P}|P|\leq(n-1)\sum_Px_{t,P}=n-1,\)

a contradiction. Hence a perfect matching exists.

This proves the required equivalence. In particular, allowing a type’s mass to split does not defeat the reduction: an average of pack values cannot exceed the largest pack value.

Therefore the stated decision problem is \(\mathrm{NP}\)-hard.

3. Membership in \(\mathrm{NP}\), despite real allocation masses

We prove that every yes-instance has a polynomial-size rational certificate.

After filtering bids, consider all feasible packs over the menus \(D_t^\ast\). There are finitely many, although potentially exponentially many. Introduce a nonnegative slack \(s_j\) for each supply constraint. The allocation constraints become

\(\displaystyle \sum_Px_{t,P}=\mu_t\quad(t\in T),\qquad \sum_{t,P}x_{t,P}u_j(P)+s_j=\kappa_j\quad(j\in M).\)

Write this system as \(Az=b\), \(z\geq0\), where \(z\) includes allocation and slack variables. There are \(d=\tau+m\) rows, and every entry of \(A\) is \(0\) or \(1\).

The feasible set is nonempty: assign each type entirely to the empty pack. It is compact, since \(0\leq x_{t,P}\leq\mu_t\) and \(0\leq s_j\leq\kappa_j\). Thus the linear welfare objective attains its maximum.

Choose an optimal solution \(z^\ast\) having the fewest positive coordinates. Its positive-coordinate columns of \(A\) are linearly independent:

  • Otherwise, there is a nonzero vector \(h\), supported on those coordinates, with \(Ah=0\).
  • For sufficiently small positive \(\varepsilon\), both \(z^\ast+\varepsilon h\) and \(z^\ast-\varepsilon h\) remain nonnegative and feasible.
  • Optimality forces the objective’s inner product with \(h\) to equal zero; otherwise one of these perturbations improves welfare.
  • Move in a direction along \(h\) until a positive coordinate first becomes zero. Such a direction exists because \(h\neq0\). Feasibility and optimality are preserved, while the number of positive coordinates decreases, a contradiction.

Consequently, at most \(d\) coordinates are positive, including slacks.

We also need a bound on their rational encoding lengths. Let \(k\leq d\) be the number of positive coordinates. Their independent columns contain a nonsingular \(k\times k\) row submatrix \(C\). The positive coordinates satisfy \(Cz^\ast_{\mathrm{supp}}=b'\).

Let \(D\) be the product of the input denominators occurring in \(b\). Its bit length is \(O(L)\), and the integer entries of \(Db'\) also have bit length \(O(L)\). Cramer’s rule gives

\(\displaystyle z_i^\ast=\frac{\det(C_i)}{D\det(C)},\)

where \(C_i\) replaces column \(i\) of \(C\) by \(Db'\). The determinant expansion yields \(|\det(C)|\leq k!\) and \(|\det(C_i)|\leq k!\,2^{O(L)}\). Therefore every positive coordinate has numerator and denominator bit length \(O(L+d\log(d+1))\).

A yes-instance thus has a certificate listing at most \(m+\tau\) packs, their types, and their rational masses. Each pack can be represented by a bit vector over its type’s explicitly listed bids. A verifier checks disjointness, WPM, type masses, supplies, and the threshold by exact rational arithmetic in \(\operatorname{poly}(m,\tau,q,L)\) time.

Hence the problem belongs to \(\mathrm{NP}\). Together with Section 2, this proves \(\mathrm{NP}\)-completeness.

4. An exact running-time bound

For completeness, the problem admits an exact algorithm with running time \(2^{O(m)}\operatorname{poly}(m,\tau,q,L)\).

After WPM filtering, define \(F_t(S)\) as the largest value of a pack of type \(t\) whose union is exactly \(S\subseteq M\). Use \(F_t(\varnothing)=0\) and mark unreachable sets separately. For nonempty \(S\),

\(\displaystyle F_t(S)=\max_{\substack{(B,a)\in D_t^\ast\\B\subseteq S}}\bigl(a+F_t(S\setminus B)\bigr),\)

omitting unreachable terms. This recurrence is exact: removing any bid from a pack leaves a pack on the complementary union, and adjoining \(B\) to a pack on \(S\setminus B\) preserves disjointness. Since \(B\neq\varnothing\), subsets can be processed in increasing cardinality.

Computing these tables takes \(O(q2^m\operatorname{poly}(m,L)+\tau2^m)\) time. Then solve the rational linear program with one variable \(y_{t,S}\) for each reachable pair:

\(\displaystyle \max\sum_{t,S}y_{t,S}F_t(S),\qquad \sum_Sy_{t,S}=\mu_t,\qquad \sum_{t,S:\,j\in S}y_{t,S}\leq\kappa_j,\qquad y_{t,S}\geq0.\)

Replacing a pack by a maximizing pack with the same union preserves resource use and WPM. Conversely, every reachable union has a realizing pack. The compressed program therefore has exactly the original optimum. It has at most \(\tau2^m\) variables and rational coefficients of polynomial bit length, giving the stated bound by polynomial-time rational linear programming.

Thus fixed \(m\) permits polynomial time, while unrestricted \(m\) gives an \(\mathrm{NP}\)-complete problem.
