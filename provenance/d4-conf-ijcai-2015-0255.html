The continuous mirror question, as graded

Given \(\tau\) ranking types \(t\in S_n\) with positive rational masses \(\mu_t\) summing to \(1\), and fixed strictly decreasing rational weights \(w\), find a ranking \(\rho\in S_n\) minimizing \(\sum_t \mu_t d_{PS}(\rho,t)\).

Packaged proof task (what the prover saw — nothing else)

Let \(m\geq 1\) be the number of items. A ranking \(\pi\in S_m\) maps each item to its position, with position \(1\) best. A society is given by its support: the list of the \(\tau\) distinct ranking types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number \(m!\) of possible types.
A common weight vector \(w\in\mathbb{Q}^m\) is supplied in binary and satisfies \(w_1>\cdots>w_m\); its entries may have either sign. Define positional Spearman distance by \(d_{PS}(\rho,t)=\sum_{i=1}^{m}(w_{\rho(i)}-w_{t(i)})^2\). Let \(L\) be the total input bit length.
Find a full ranking \(\rho\in S_m\) minimizing \(\sum_t\mu_t d_{PS}(\rho,t)\); any minimizer is acceptable.

Is computing such an optimal ranking possible in time polynomial in \(m,\tau,L\), or is this optimization problem NP-hard?

For an explicitly listed finite society, positional Spearman minimizers are precisely the rankings returned by the positional scoring rule with the same strictly decreasing weights, yielding a polynomial-time algorithm. This establishes the discrete analogue; it does not state a complexity result for binary-encoded rational-mass support input.

Modeling choices made when packaging the task

  • Interpreted 'fixed weights' as one supplied rational vector common to every distance evaluation, allowing a uniform problem with varying numbers of items.
  • Allowed weights of either sign because the discrete scoring-rule definition imposes only their ordering.
  • Resolved ties by accepting any minimizing full ranking, consistent with allowing multiple equally good aggregate rankings.
  • Used m for the number of items and defined L as the total input bit length.

Result

The problem is polynomial-time solvable, including for binary-encoded rational masses. Compute each item’s expected positional weight and rank the items in decreasing order of these scores. The rational arithmetic can be performed exactly with polynomially many bits.

1. Reduction to positional scores

For each item \(i\), define
\(s_i=\sum_{t=1}^{\tau}\mu_t w_{t(i)}\).

Expanding the objective gives
\( F(\rho) =\sum_{i=1}^{m}w_{\rho(i)}^2 -2\sum_{i=1}^{m}w_{\rho(i)}s_i +\sum_{t=1}^{\tau}\mu_t\sum_{i=1}^{m}w_{t(i)}^2. \)

Because every ranking is a permutation, both \(\sum_i w_{\rho(i)}^2\) and \(\sum_i w_{t(i)}^2\) equal \(\sum_{j=1}^{m}w_j^2\). Using \(\sum_t\mu_t=1\), we obtain
\( F(\rho)=2\sum_{j=1}^{m}w_j^2-2\sum_{i=1}^{m}w_{\rho(i)}s_i. \)

Thus minimizing \(F\) is equivalent to maximizing
\(H(\rho)=\sum_i w_{\rho(i)}s_i\).
This identity holds regardless of the signs of the weights.

2. Sorting the scores is optimal

Write the items in their order under a ranking as \(i_1,\ldots,i_m\), so that \(\rho(i_j)=j\). Suppose adjacent positions satisfy \(s_{i_j}<s_{i_{j+1}}\). Swapping these two items changes \(H\) by
\( (w_j-w_{j+1})(s_{i_{j+1}}-s_{i_j})>0, \)
since the weights are strictly decreasing.

Repeatedly swapping adjacent score inversions terminates: each swap decreases the number of pairs whose earlier item has strictly smaller score. The resulting score sequence is nonincreasing, and \(H\) never decreases.

Every ranking with nonincreasing scores has the same value of \(H\), because the numerical score sequence is the same; only items with equal scores can exchange positions. Consequently, every such ranking maximizes \(H\). Conversely, any ranking whose scores are not nonincreasing has an adjacent inversion and therefore cannot maximize \(H\).

Hence the minimizers are precisely the rankings that order items by decreasing \(s_i\), with arbitrary tie-breaking.

3. Exact computation has polynomial bit complexity

Write the input rationals as
\(w_j=a_j/b_j\) and \(\mu_t=p_t/q_t\), with integer numerators and positive integer denominators. Define
\( B=\prod_{j=1}^{m}b_j,\qquad Q=\prod_{t=1}^{\tau}q_t, \)
and the integers
\( W_j=a_j(B/b_j),\qquad P_t=p_t(Q/q_t). \)

For each item, compute the integer
\( S_i=\sum_{t=1}^{\tau}P_tW_{t(i)}. \)
Then \(s_i=S_i/(BQ)\). Because the denominator \(BQ\) is common and positive, sorting the integers \(S_i\) sorts the scores exactly.

We now bound all intermediate integer sizes. Since \(L\) is the total input bit length, the products \(B\) and \(Q\) each have \(O(L+1)\) bits. Also, \(|a_j|\leq 2^L\), so the coarse bound \(|W_j|\leq 2^{2L}\) suffices. Positivity and normalization of the masses imply
\( P_t>0,\qquad \sum_{t=1}^{\tau}P_t=Q. \)
Therefore
\( |S_i| \leq\sum_tP_t|W_{t(i)}| \leq Q\max_j|W_j| \leq 2^{3L}. \)
The same bound applies to every partial sum used to compute \(S_i\). Thus all required integers have \(O(L+1)\) bits.

Constructing these integers requires \(O(m+\tau+m\tau)\) integer arithmetic operations. Sorting requires \(O(m\log m)\) integer comparisons. Integer multiplication, exact division, addition, and comparison on these bit lengths all take polynomial time.

4. Algorithm and conclusion

  • Compute \(B,Q\), the integers \(W_j,P_t\), and each integer score \(S_i\).
  • Sort the items by decreasing \(S_i\), breaking ties arbitrarily.
  • Assign positions \(1,\ldots,m\) in that order.

The resulting ranking is optimal, and the running time is polynomial in \(m,\tau,L\). This directly handles the rational-mass support representation without expanding masses into repeated voters.
