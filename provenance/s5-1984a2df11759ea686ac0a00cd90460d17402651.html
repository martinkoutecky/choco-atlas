The continuous mirror question, as graded

Given a finite school set \(C\), a finite support \(X\) of types with rational masses \(\mu_x\) summing to one, and for each type an explicit finite list of positive-probability uncertainty events \(j\) with feasible set \(B_{xj}\) and assigned school \(\alpha_{xj}\), compute each type’s relation set \(P_x\) and, for every ordered pair \(a,b\in C\), compute \(M_{ab}=\sum_{x\in X}\mu_x\mathbf{1}\{(a,b)\in P_x\}\). Here \(P_x\) is the transitive closure of the relations \((\alpha_{xj},c)\) for \(c\in B_{xj}\setminus\{\alpha_{xj}\}\).

Result. The exact computation is solvable in deterministic polynomial time in \(m,\tau,K,L\). The proof includes the bit complexity of mass aggregation.

1. Computing each transitive closure

For each type \(x\), construct the directed graph \(G_x=(C,E_x)\) by scanning its listed events. An event contributes the edges \((\alpha_{xj},c)\) for every \(c\in B_{xj}\setminus\{\alpha_{xj}\}\). Since each feasible set has at most \(m\) members, this requires at most \(Km\) edge insertions across all types.

By the compatibility hypothesis, there exists a strict order \(\succ_x\) such that \(a\succ_x b\) for every edge \((a,b)\in E_x\). Consequently, \(G_x\) is acyclic: a directed cycle would, by transitivity of \(\succ_x\), imply \(a\succ_x a\), contradicting irreflexivity. The order itself need not be supplied or computed.

Let \(Q_x\) contain precisely the pairs \((a,b)\) for which \(G_x\) has a directed path of positive length from \(a\) to \(b\). Then \(Q_x=P_x\). Indeed:

  • Every edge is a path of length one, so \(E_x\subseteq Q_x\).
  • Concatenating paths proves that \(Q_x\) is transitive.
  • If a transitive relation contains \(E_x\), induction on path length shows that it contains every pair in \(Q_x\).

Thus \(Q_x\) is exactly the smallest transitive relation containing \(E_x\). Acyclicity also implies that \((a,a)\notin P_x\) for every school \(a\).

Run breadth-first search from every school \(a\) in \(G_x\), and output \((a,b)\) for each reached school \(b\ne a\). Correctness follows directly: every discovered vertex has a path from the source, while induction along any path shows that every reachable vertex is discovered. Excluding the source therefore gives precisely \(P_x\).

Writing \(e_x=|E_x|\), these searches take \(O(m(m+e_x))\) graph operations per type. Since \(e_x\leq m(m-1)\), constructing all graphs and computing all closures requires \(O(Km+\tau m^3)\) graph operations. Storing all closures as Boolean matrices uses \(O(\tau m^2)\) bits.

2. Exact aggregation with polynomial bit length

Use the usual exact encoding of a binary rational as a numerator and denominator written in binary. Write \(\mu_x=p_x/q_x\), where \(p_x,q_x\) are positive integers. Dyadic rational masses are a special case.

Define the common denominator \(D=\prod_{x\in X}q_x\), and define the integer weight \(w_x=p_x(D/q_x)\). Each division is exact, and \(w_x=D\mu_x\). Since the masses sum to one, \(\sum_{x\in X}w_x=D\).

For every ordered pair, compute the integer

\[ N_{ab}=\sum_{\substack{x\in X\\(a,b)\in P_x}}w_x. \]

Then output \(M_{ab}=N_{ab}/D\). This is exact because

\[ \frac{N_{ab}}{D} =\sum_{x\in X}\frac{w_x}{D}\mathbf{1}\{(a,b)\in P_x\} =\sum_{x\in X}\mu_x\mathbf{1}\{(a,b)\in P_x\}. \]

It remains to bound the integer sizes. If \(\operatorname{bits}(q_x)\) denotes the binary length of \(q_x\), then \(\sum_x\operatorname{bits}(q_x)\leq L\). Hence

\[ \log_2 D=\sum_x\log_2 q_x \leq\sum_x\operatorname{bits}(q_x)\leq L. \]

Thus \(D\) has at most \(L+1\) bits. Every partial product used to construct \(D\) is at most \(D\). Moreover, positivity and normalization give \(0<w_x\leq D\) and \(0\leq N_{ab}\leq D\); every partial numerator sum satisfies the same bound. All arithmetic therefore involves integers of \(O(L)\) bits.

Constructing \(D\) and all weights takes \(O(\tau)\) integer arithmetic operations. Aggregating all pairs takes at most \(O(\tau m^2)\) integer additions. Elementary binary multiplication and division on \(O(L)\)-bit integers take \(O(L^2)\) bit operations, so this arithmetic is polynomial in the stated parameters. Fractions need not be reduced to represent exact rationals; if reduced output is required, computing \(\gcd(N_{ab},D)\) for each pair also takes polynomial time.

The output itself has polynomial size: \(O(\tau m^2)\) bits for the closures and \(O(m^2(L+1))\) bits for the rational masses.

3. Complexity classification

Together, the graph algorithm and bounded-length integer arithmetic give a deterministic polynomial-time algorithm for every promised input. In the standard terminology for function problems, this computation belongs to \(\mathrm{FP}\).

Accordingly, NP-hardness under polynomial-time Turing reductions would imply \(\mathrm{P}=\mathrm{NP}\): replace every oracle call in such a reduction with the polynomial-time algorithm proved above.

The decisive hypothesis is that all \(\tau\) support types and all \(K\) events are explicitly listed. The required mass is a sum over those listed types, and each summand’s indicator is decided by graph reachability.
