The continuous mirror question, as graded

Given a finite signal-type set \(T\) and an explicitly listed finite family \(\mathcal Q\) of rational C.I.I.D. models, each specifying \(\pi=\Pr[W=1]\) and conditional type distributions \(\lambda^0,\lambda^1\), consider the continuum limit in which \(W=w\) induces type masses \(\lambda_t^w\). The aggregator observes only the resulting mass distribution over truthful report pairs \((f_Q(t),p_Q(t))\), where \(p_Q(t)\) is the expectation of an independent peer's forecast conditional on type \(t\). Compute a rule \(A\) minimizing the worst-case expected squared error against the posterior given the full signal-type mass profile, over \(Q\in\mathcal Q\), and determine the exact minimax regret and its complexity in \(|T|\), \(|\mathcal Q|\), and input bit length.

Packaged proof task (what the prover saw — nothing else)

Input: a nonempty finite type set \(T\), with \(m=|T|\), and a nonempty explicitly listed family \(\mathcal Q\) of rational models. Each model specifies \(\pi_Q\in(0,1)\) and nonnegative conditional distributions \(\lambda_Q^0,\lambda_Q^1\) on \(T\), each summing to \(1\); individual signals are independent and identically distributed conditional on \(W\in\{0,1\}\).
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational. Support size means the number of positive-mass types, not the number of possible types; here masses sum to \(1\). Let \(\tau\) be the maximum support size of the conditional societies and \(L\) the total input bit length.
For each model, let \(T_Q=\{t:(1-\pi_Q)\lambda_{Q,t}^0+\pi_Q\lambda_{Q,t}^1>0\}\). Truthful reports are \(f_Q(t)=\frac{\pi_Q\lambda_{Q,t}^1}{(1-\pi_Q)\lambda_{Q,t}^0+\pi_Q\lambda_{Q,t}^1}\) and \(p_Q(t)=\sum_{u\in T_Q}[(1-f_Q(t))\lambda_{Q,u}^0+f_Q(t)\lambda_{Q,u}^1]f_Q(u)\).
Conditional on \(W=w\), the full type-mass profile is exactly \(X=\lambda_Q^w\). The aggregator observes only \(D_Q^w=\sum_{t\in T_Q}\lambda_{Q,t}^w\delta_{(f_Q(t),p_Q(t))}\), with coincident report pairs merged; \(\delta\) denotes unit point mass.
The benchmark knows \(Q\) and \(X\): write \(b_Q^w=\Pr_Q[W=1\mid X=\lambda_Q^w]\). Thus \(b_Q^w=w\) when the two conditional profiles differ, and \(b_Q^w=\pi_Q\) when they coincide.
An admissible rule \(A\) assigns a forecast in \([0,1]\) to every attainable report distribution, knows \(\mathcal Q\), and does not know the selected model. Define \(R^*=\min_A\max_{Q\in\mathcal Q}\{(1-\pi_Q)(A(D_Q^0)-b_Q^0)^2+\pi_Q(A(D_Q^1)-b_Q^1)^2\}\).

Can an exact minimizing rule and \(R^*\) be computed in polynomial time in \(m,\tau,|\mathcal Q|,L\), or is deciding \(R^*\le r\), for a binary rational input \(r\in[0,1]\), NP-hard?

For finite populations, an explicit peer-expectation aggregator has expected squared regret tending to zero for each fixed C.I.I.D. model as population size grows; this is a convergence result, not a polynomial-time minimax theorem. [Kong](https://arxiv.org/pdf/2402.06062v1)
Infinite-population state recovery from forecasts and expectations of population-average forecasts is known under imperfect-information and minimal-informativeness assumptions. [Chen, Mueller-Frank, and Pai](https://arxiv.org/pdf/2102.02666v1)
Finite-family robust aggregation admits an FPTAS under constant model-support and suitable convexity and oracle assumptions; this does not establish exact complexity for the problem above. [Guo et al.](https://arxiv.org/pdf/2401.17743)

Modeling choices made when packaging the task

  • Restricted priors to the open unit interval, following the discrete model; conditional masses are nonnegative binary rationals normalized to one.
  • Defined truthful forecasts only for types with positive unconditional probability under the selected model; types absent in both states contribute no reports.
  • Interpreted the continuum profile as exactly the conditional type distribution, and defined the benchmark by conditioning within the selected model, including coincident conditional profiles.
  • Made observations anonymous distributions of report pairs, merging coincident pairs and withholding type labels.
  • Allowed all deterministic rules with forecasts in the closed unit interval, with no continuity restriction; rules know the listed family but not its selected member.
  • Defined the requested size parameters by setting m to the type-universe size, tau to the maximum conditional support size, and L to total input bit length.
  • Added a rational regret threshold to give the NP-hardness alternative a precise decision formulation.

Result

The problem is polynomial-time solvable, and in fact \(R^*=0\) for every valid input. A single rule, independent of \(\mathcal Q\), exactly recovers every benchmark.

This follows from the stipulated observation of the exact conditional report distribution. The argument covers informative models as well as uninformative and perfectly revealing models.

1. Identities for one model

Fix a model and suppress its subscript. Define
\(q_t=(1-\pi)\lambda_t^0+\pi\lambda_t^1\) on \(T_Q\), and let
\(a=\sum_t\lambda_t^0 f(t)\), \(c=\sum_t\lambda_t^1 f(t)\), and \(\beta=c-a\).

By the definition of peer expectations,
\(p(t)=a+\beta f(t)\).

Bayes’ formula gives
\(q_t f(t)=\pi\lambda_t^1\) and
\(q_t(1-f(t))=(1-\pi)\lambda_t^0\).
Consequently,
\(\sum_t q_t f(t)=\pi\),
\(\sum_t q_t f(t)^2=\pi c\), and
\((1-\pi)a+\pi c=\pi\).

Substituting \(c=a+\beta\) into the last identity yields
\(a=\pi(1-\beta)\) and \(c=\pi+(1-\pi)\beta\).

Moreover,
\(\operatorname{Var}_q(f)=\pi c-\pi^2=\pi(1-\pi)\beta\).
Since \(f(t)\in[0,1]\), we have
\(0\le\operatorname{Var}_q(f)\le\pi(1-\pi)\).
Thus \(0\le\beta\le1\).

We also need the precise equality condition
\(\beta=0\Longleftrightarrow\lambda^0=\lambda^1\).

Indeed, if \(\beta=0\), the variance vanishes. Every \(q_t\) on \(T_Q\) is positive, so every \(f(t)\) equals its mean \(\pi\). The two Bayes identities then imply
\(\lambda_t^1=q_t=\lambda_t^0\).
Outside \(T_Q\), both conditional masses vanish. Conversely, equal conditional distributions give \(f(t)=\pi\) everywhere on their support, hence \(\beta=0\).

2. A rule using only the observed distribution

For a report distribution \(D=\sum_j d_j\delta_{(x_j,y_j)}\), define its two coordinate means by
\(F(D)=\sum_j d_jx_j\) and \(P(D)=\sum_j d_jy_j\).

Define
\(A(D)=\begin{cases} 0,&P(D)>F(D),\\ 1,&P(D)<F(D),\\ F(D),&P(D)=F(D). \end{cases}\)

This rule takes values in \([0,1]\) and uses only \(D\). Merging coincident report pairs preserves both coordinate means.

For the fixed model,
\(F(D^0)=a\) and \(F(D^1)=c\).
Because \(p(t)=a+\beta f(t)\), we also have
\(P(D^w)=a+\beta F(D^w)\).

Therefore,
\(P(D^0)-F(D^0)=\beta a=\pi\beta(1-\beta)\),

and
\(P(D^1)-F(D^1)=a+\beta c-c =-\beta(1-c)=-(1-\pi)\beta(1-\beta)\).

These identities determine the rule’s behavior in every case.

Case 1: \(0<\beta<1\)

Because \(0<\pi<1\), the first difference is strictly positive and the second strictly negative. Hence
\(A(D^0)=0\) and \(A(D^1)=1\).

The conditional profiles differ, by the equality characterization above. Thus these outputs equal \(b^0\) and \(b^1\).

Case 2: \(\beta=0\)

The conditional profiles coincide, so \(b^0=b^1=\pi\). The identities for \(a\) and \(c\) give \(a=c=\pi\), and both coordinate differences vanish. Hence
\(A(D^0)=A(D^1)=\pi\).

Case 3: \(\beta=1\)

Here \(a=0\) and \(c=1\). Both coordinate differences again vanish, but the rule outputs
\(A(D^0)=F(D^0)=0\) and \(A(D^1)=F(D^1)=1\).

Since \(\beta\ne0\), the conditional profiles differ, so these outputs again equal the benchmarks.

We have therefore proved, for every model and both states,
\(A(D_Q^w)=b_Q^w\).
In particular, if observations coincide across models, their benchmark values necessarily coincide.

3. Optimal value

Every model’s regret under this rule is
\((1-\pi_Q)(A(D_Q^0)-b_Q^0)^2+\pi_Q(A(D_Q^1)-b_Q^1)^2=0\).

All regret terms are nonnegative for every admissible rule. Thus \(R^*=0\), and the displayed rule is an exact minimizer.

4. Exact polynomial-time computation

The rule above already gives a constant-size description of an exact minimizer. If an explicit table on all attainable distributions is required, construct it as follows:

  • For each model, form \(T_Q\) from the two listed conditional supports and compute all \(f_Q(t)\) exactly.
  • Compute \(a_Q\) and \(c_Q\), then use

\(p_Q(t)=a_Q+(c_Q-a_Q)f_Q(t)\).

  • Construct both \(D_Q^w\), merging identical rational report pairs and discarding zero masses.
  • Deduplicate these distributions and assign each the value given by \(A\).

Each \(T_Q\) has size at most \(\min\{m,2\tau\}\), and there are at most \(2|\mathcal Q|\) attainable distributions.

All calculations involve a polynomial number of rational additions, multiplications, divisions by positive rationals, and exact comparisons. Intermediate bit lengths are polynomial in \(L\): the formulas have fixed arithmetic depth apart from finite sums, whose denominators can be bounded by products of polynomially many polynomial-length denominators. Reduced rational representations permit exact equality checks and canonical ordering.

Consequently, the table and \(R^*=0\) can be computed in polynomial time in \(m,\tau,|\mathcal Q|,L\). For every permitted threshold \(r\in[0,1]\), the answer to \(R^*\le r\) is yes.

The proof relies on the exact-profile premise. The finite-population convergence result mentioned in the question concerns empirical observations; it is separate from the exact identities established here. [Kong](https://arxiv.org/pdf/2402.06062v1)
