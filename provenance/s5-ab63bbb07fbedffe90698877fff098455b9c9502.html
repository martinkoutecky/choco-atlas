The continuous mirror question, as graded

Given \(q\) goods categories, rational per-capita supplies \(\rho_j\), and a finite set \(T\) of additive types with rational masses \(\mu_t\) summing to \(1\) and values \(a_{tj}\), find a finite-support allocation \(x_{t,B}\ge 0\) over integral bundles \(B\in\mathbb Z_{\ge 0}^q\). Require \(\sum_B x_{t,B}=\mu_t\), \(\sum_{t,B}x_{t,B}B_j\le\rho_j\), and define residual supply \(u_j=\rho_j-\sum_{t,B}x_{t,B}B_j\). For every pair \((t,B),(s,C)\) with positive assigned mass and every \(j\) with \(C_j>0\), require \(\sum_k a_{tk}B_k\ge\sum_k a_{tk}(C_k-\mathbf 1[k=j])\); also require \(\sum_k a_{tk}B_k\ge\sum_k a_{tk}u_k\) for every assigned type-bundle pair and \(\sum_j u_j\le 1\).

Packaged proof task (what the prover saw — nothing else)

Let \(m=q\ge 1\) be the number of goods categories, with per-capita supplies \(\rho_j\in\mathbb Q_{\ge 0}\). A society is given by its support: the list \(T\) of \(\tau\ge 1\) types with positive masses \(\mu_t\) given as binary rationals, where \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types. Type \(t\) has additive values \(a_{tj}\in\mathbb Q_{\ge 0}\), and \(v_t(z)=\sum_{j=1}^m a_{tj}z_j\) for \(z\in\mathbb R_{\ge 0}^m\). Let \(L\) be the total binary input length.
An allocation consists of masses \(x_{t,B}\in\mathbb R_{\ge 0}\), with only finitely many positive entries, indexed by \(t\in T\) and integral bundles \(B\in\mathbb Z_{\ge 0}^m\); the bundle support is chosen by the allocation.
Require \(\sum_B x_{t,B}=\mu_t\) and \(u_j:=\rho_j-\sum_{t,B}x_{t,B}B_j\ge 0\) for every category, with \(\sum_j u_j\le 1\).
For every \((t,B),(s,C)\) with \(x_{t,B}>0\) and \(x_{s,C}>0\), require \(v_t(B)\ge v_t(C-e_j)\) whenever \(C_j>0\), where \(e_j\) is the \(j\)-th unit vector. This includes removal of goods worth zero to the comparing type and comparisons within a type.
Also require \(v_t(B)\ge v_t(u)\) whenever \(x_{t,B}>0\). All fairness comparisons are weak; equal values are allowed.

Is deciding whether such an allocation exists in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite societies with \(n\ge 2\) agents and nonnegative additive valuations, an EFX allocation exists leaving at most \(n-2\) goods unallocated, with no agent envying the unallocated bundle ([Berger, Cohen, Feldman and Fiat](https://arxiv.org/pdf/2102.10654)). This is an existence guarantee, not a polynomial-time complexity classification.
No result settling the exact mass feasibility problem defined above was located in the literature search.

Modeling choices made when packaging the task

  • The signs of supplies and additive values were unspecified; both are nonnegative binary rationals, consistent with monotone valuations of goods.
  • Allocation masses are nonnegative reals with finite support chosen by the allocation; the target is feasibility of the stated allocation constraints.
  • Set m=q, the number of goods categories, and define L as the total binary input length; there is no finite population-size parameter.
  • Allow zero values and ties, and apply EFX after removal of every present good, including goods worth zero to the comparing type, as dictated by the discrete definition.
  • Restrict the discrete anchor statement to n at least two, since its literal n−2 bound cannot apply to one agent; this imposes no lower bound of two on the continuous support size.

Result

The decision problem is in \(\mathrm P\): every input satisfying the stated hypotheses admits a feasible allocation.

This holds for arbitrary supported types and nonnegative additive valuations. The finite-society existence theorem suffices because rational masses and supplies can be represented exactly by a finite replicated society.

Finite-society theorem

We use the following theorem of Berger, Cohen, Feldman and Fiat: for a finite society of \(n\ge 2\) agents with nonnegative additive valuations, there exists a partial allocation \((S_1,\ldots,S_n)\), with unallocated item set \(P\), satisfying:

  • For distinct agents \(i,k\) and every item \(g\in S_k\),

\(w_i(S_i)\ge w_i(S_k\setminus\{g\})\).

  • Every agent satisfies \(w_i(S_i)\ge w_i(P)\).
  • The number of unallocated items satisfies \(|P|\le n-2\).

The item-removal condition includes zero-valued items: the paper defines strong envy using removal of any item, without a positivity restriction. Its nondegeneracy reduction also accommodates equal bundle values. See [Theorem 2, Section 2, and Appendix A](https://arxiv.org/pdf/2102.10654).

Exact finite replication

Choose a positive integer \(D\) divisible by every denominator occurring in the masses \(\mu_t\) and supplies \(\rho_j\). Set \(N=2D\), so \(N\ge 2\).

For each type \(t\), define \(r_t=N\mu_t\). These are positive integers, and
\(\sum_{t\in T}r_t=N\).
For each category \(j\), define \(K_j=N\rho_j\), a nonnegative integer.

Construct a finite society with \(r_t\) agents of type \(t\), and \(K_j\) individually labelled items of category \(j\). An agent \(i\) of type \(t\) values each category-\(j\) item at \(a_{tj}\). Thus, writing \(b(S)\) for the category-count vector of an item set \(S\), its valuation is
\(w_i(S)=v_t(b(S))\).

This society has exactly \(N\) agents and finitely many items. Its valuations are nonnegative and additive, so the finite-society theorem applies.

Fix an allocation supplied by that theorem. Define the integral vectors
\(B_i=b(S_i)\) and \(U=b(P)\).

Construction and verification of the mass allocation

For every type \(t\) and integral bundle \(B\), set

\(x_{t,B}=\dfrac{|\{i:\ i\text{ has type }t,\ B_i=B\}|}{N}\).

These masses are nonnegative rationals. At most \(N\) entries are positive, so the required finite-support condition holds.

Type masses

Each type-\(t\) agent is counted exactly once. Consequently,

\(\sum_B x_{t,B}=\dfrac{r_t}{N}=\mu_t\).

Supplies and leftover bound

For every category \(j\), item conservation gives
\(\sum_{i=1}^{N}(B_i)_j+U_j=K_j\).
Therefore,

\(\sum_{t,B}x_{t,B}B_j=\dfrac{1}{N}\sum_{i=1}^{N}(B_i)_j =\rho_j-\dfrac{U_j}{N}\).

The leftover vector prescribed by the problem is consequently \(u=U/N\), which is coordinatewise nonnegative. Moreover,

\(\sum_{j=1}^{m}u_j=\dfrac{|P|}{N}\le\dfrac{N-2}{N}<1\).

Thus both supply requirements hold.

Every required bundle comparison

Take any positive entries \(x_{t,B}\) and \(x_{s,C}\), and any category \(j\) with \(C_j>0\). By construction, there are finite agents \(i,k\) of types \(t,s\), respectively, with \(B_i=B\) and \(B_k=C\).

If \(i\ne k\), choose a category-\(j\) item \(g\in S_k\), which exists because \(C_j>0\). Finite EFX gives

\(v_t(B)=w_i(S_i)\ge w_i(S_k\setminus\{g\})=v_t(C-e_j)\).

This argument also applies when \(t=s\): the theorem compares individual agents, including agents of identical type. It applies when \(a_{tj}=0\), because removal of zero-valued items is included.

If \(i=k\), then \(t=s\) and \(B=C\). Nonnegativity gives

\(v_t(B)-v_t(C-e_j)=a_{tj}\ge 0\).

Hence all required comparisons, including comparisons within a type and self-comparisons, hold.

No envy of the leftover vector

For any positive \(x_{t,B}\), choose a corresponding type-\(t\) agent \(i\). The finite theorem gives

\(v_t(B)=w_i(S_i)\ge w_i(P)=v_t(U)=N\,v_t(u)\).

Since \(N\ge 1\) and \(v_t(u)\ge 0\), this implies \(v_t(B)\ge v_t(u)\), as required.

This verifies every constraint.

Decision complexity

The algorithm returns YES on every valid input. If input validity must also be checked, parsing the binary rationals, checking their signs, and verifying \(\sum_t\mu_t=1\) take polynomial time in \(L\).

The replicated society can be exponentially large. It is used only to prove existence; the decision algorithm never constructs it. Thus the absence of a polynomial-time allocation algorithm in the finite theorem does not obstruct this decision classification.
