The continuous mirror question, as graded

Given projects \(\mathcal P\), lecturers \(\mathcal L\), supported complete preference types \(T\) with rational masses \(\mu_t\) summing to \(1\), and rational per-capita project capacities and lecturer lower and upper quotas, decide feasibility and compute both a maximum-mass feasible allocation with lexicographically maximum rank profile \((q_1,\ldots,q_R)\) and one with lexicographically minimum reverse profile \((q_R,\ldots,q_1)\).

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal P\) contain \(m\geq1\) projects and \(\mathcal L\) contain \(k\geq1\) lecturers; nonempty sets \(P_\ell\) partition \(\mathcal P\), specifying each project's unique lecturer. Lecturers have no preferences.
A society is given by its support: the list \(T\) of \(\tau\) types with positive mass, each with its mass \(\mu_t\) as a binary rational, and \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies a complete weak order over all projects, all of which are acceptable. Define \(r_t(p)=1+|\{p'\in\mathcal P:p'\succ_t p\}|\) and \(R=\max_{t,p}r_t(p)\); ties are retained without breaking them.
Project capacities \(c_p\geq0\) and lecturer quotas \(0\leq d_\ell^-\leq d_\ell^+\), with \(d_\ell^+>0\), are binary rationals measured in units of total society mass.
An allocation consists of divisible masses \(x_{tp}\geq0\), satisfying \(\sum_p x_{tp}\leq\mu_t\), \(\sum_t x_{tp}\leq c_p\), and \(d_\ell^-\leq\sum_{p\in P_\ell,t\in T}x_{tp}\leq d_\ell^+\). Unallocated mass is allowed; every lecturer's lower quota is mandatory.
Define allocated mass \(a(x)=\sum_{t,p}x_{tp}\) and rank profile \(q_r(x)=\sum_{t,p:r_t(p)=r}x_{tp}\). The computational problem decides feasibility and, when feasible, computes two exact allocations maximizing \(a(x)\): one lexicographically maximizing \((q_1,\ldots,q_R)\), the other lexicographically minimizing \((q_R,\ldots,q_1)\).
Is this continuous allocation problem solvable in polynomial time in \(m,\tau,k,R,L\), where \(L\) is the total input bit length, or is it NP-hard?
For discrete students, feasibility and both corresponding constrained profile-optimal maximum matchings can be computed in \(O(n^2RE)\) time, where \(n\) is the number of students and \(E\) is the total preference-list length; incomplete lists and ties are allowed.
This discrete result does not establish the complexity of the supported rational-mass formulation.

Modeling choices made when packaging the task

  • Interpreted complete preference types as complete weak orders over all projects, allowing ties as in the discrete model and treating all projects as acceptable.
  • Specified the unique project-to-lecturer map by a partition into nonempty offering sets.
  • Defined allocations as divisible type masses that may be split across projects, with residual mass left unmatched.
  • Specified unconditional lecturer lower quotas, project upper capacities only, and no lecturer preferences.
  • Used the discrete rank convention: one plus the number of strictly preferred projects, including the rank gaps induced by ties.
  • Specified nonnegative rational project capacities and lecturer lower quotas, with positive lecturer upper quotas at least their lower quotas. Replaced the discrete positive-unit upper-quota condition by positivity in normalized mass units.
  • Specified nonempty project and lecturer sets, exact allocation computation, and total input bit length as the encoding parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Theorem. The problem is solvable in polynomial time in \(m,\tau,k,R,L\). Both requested allocations can be computed exactly using at most \(2R+1\) rational linear programs.

Allocation polytope. Let \(N=\tau m\), and let \(Q\subseteq\mathbb R^N\) be defined by the allocation constraints:
\[ x_{tp}\geq0,\qquad \sum_p x_{tp}\leq\mu_t,\qquad \sum_t x_{tp}\leq c_p, \]
\[ d_\ell^-\leq\sum_{p\in P_\ell,t\in T}x_{tp}\leq d_\ell^+. \]
Thus \(Q\) is exactly the set of feasible allocations. It has \(N\) variables and \(N+\tau+m+2k\) inequalities. Its constraint matrix has entries in \(\{-1,0,1\}\), and its right-hand sides are input rationals.

Every coordinate satisfies \(0\leq x_{tp}\leq\mu_t\leq1\). Consequently, \(Q\) is bounded and closed; when nonempty, it is compact.

Compute the ranks directly from the supplied weak orders. Within each tie class, every project receives one plus the number of projects in preceding classes. This preserves ties and gives \(R\leq m\). Each \(q_r\), including any identically zero rank coordinate, is a linear function with coefficients in \(\{0,1\}\).

We use the standard exact rational linear-programming theorem: an explicitly represented rational linear program can be checked for feasibility and, when its optimum is finite, an exact rational optimal solution can be computed in time polynomial in its binary encoding length. This includes equality constraints and feasible regions of lower dimension. See [Trevisan’s linear-programming notes, Sections 2.4–2.5](https://lucatrevisan.github.io/cs261/lecture05.pdf). Below we verify that every program constructed has polynomial encoding length.

Maximum allocated mass. First solve the linear program maximizing \(a(x)\) over \(Q\). If it is infeasible, report infeasibility. Otherwise, compactness ensures that the maximum is attained. Let its exact value be \(A\), and define
\[ Q_0=\{x\in Q:a(x)=A\}. \]
This is a nonempty compact polytope consisting precisely of the maximum-mass allocations.

Lexicographic maximization. Starting with \(F_0=Q_0\), for \(r=1,\ldots,R\), solve
\[ u_r=\max\{q_r(x):x\in F_{r-1}\}, \qquad F_r=\{x\in F_{r-1}:q_r(x)=u_r\}. \]
Each feasible region remains nonempty and compact because the preceding optimum is attained. Return the allocation produced by the final optimization; it belongs to \(F_R\).

To prove correctness, let \(x\in F_R\). Suppose some \(y\in Q_0\) had a lexicographically larger forward profile. At its first differing rank \(j\), we would have
\[ q_i(y)=u_i\quad(i<j),\qquad q_j(y)>u_j. \]
The equalities imply \(y\in F_{j-1}\), contradicting the definition of \(u_j\). Hence \(x\) has the required lexicographically maximal profile.

Lexicographic minimization. Independently start with \(G_{R+1}=Q_0\). For \(r=R,R-1,\ldots,1\), solve
\[ w_r=\min\{q_r(x):x\in G_{r+1}\}, \qquad G_r=\{x\in G_{r+1}:q_r(x)=w_r\}. \]
Again, every feasible region is nonempty and compact. Return the allocation from the final optimization, which belongs to \(G_1\).

If \(y\in Q_0\) had a lexicographically smaller reverse profile than an allocation in \(G_1\), let \(j\) be the first differing rank when examining \(R,R-1,\ldots,1\). Then
\[ q_i(y)=w_i\quad(i>j),\qquad q_j(y)<w_j. \]
Thus \(y\in G_{j+1}\), contradicting the definition of \(w_j\). This proves the second optimization’s correctness.

Polynomial encoding length. It remains to bound the exact values \(A,u_r,w_r\) that become right-hand sides in subsequent programs. Polynomially many LP calls alone would not establish this bound.

First, all the successive feasible regions are faces of the original polytope \(Q\). Indeed, a linear objective’s maximizers or minimizers on a polytope form a face: if a convex combination attains the optimum, both endpoints must attain it, since their objective values lie on the same side of that optimum. Applying this observation successively shows that whenever a point in a successive region is a nontrivial convex combination of points of \(Q\), both endpoints belong to that region. Consequently, every vertex of a successive region is a vertex of \(Q\).

A linear objective on a nonempty compact polytope attains its optimum at a vertex. Therefore each value \(A,u_r,w_r\) is the value of its corresponding objective at some vertex of the *original* polytope \(Q\).

We now bound those original vertices directly. Write the original inequalities as \(Bx\leq b\). Let \(D\) be the product of the denominators of the entries of \(b\). Since these rationals are part of the input,
\[ D\leq2^L,\qquad |b_i|\leq2^L,\qquad |Db_i|\leq2^{2L}. \]

At a vertex \(v\), the active constraint rows span \(\mathbb R^N\). Otherwise, a nonzero direction orthogonal to all active rows would allow sufficiently small perturbations in both directions while preserving every inequality, contradicting extremality. Choose \(N\) independent active rows, giving
\[ Hv=b', \]
where \(H\) is an invertible integer matrix with entries in \(\{-1,0,1\}\).

By Cramer’s rule,
\[ v_i=\frac{\det H_i(Db')}{D\det H}, \]
where \(H_i(Db')\) replaces column \(i\) of \(H\) by \(Db'\). Hadamard’s determinant bound, applied to columns, gives
\[ |\det H|\leq N^{N/2}, \qquad |\det H_i(Db')|\leq2^{2L}N^{N/2}. \]
For the second inequality, the replaced column has Euclidean norm at most \(\sqrt N\,2^{2L}\), and each other column has norm at most \(\sqrt N\).

All coordinates therefore have a common denominator of absolute value at most \(2^L N^{N/2}\). Any sum of a subset of coordinates has numerator of absolute value at most \(N2^{2L}N^{N/2}\). In particular, every vertex value of \(a\) or \(q_r\) has binary encoding length
\[ O\!\left(L+N\log(N+1)\right). \]
This uniformly bounds all the added right-hand sides, independently of the number of preceding optimization stages.

Each constructed LP consequently has \(N=\tau m\) variables, \(O(N+\tau+m+k+R)\) constraints, and polynomial total encoding length. Equality constraints can be represented by two inequalities. Exact rational LP algorithms therefore solve all \(2R+1\) programs in polynomial total time and return allocations of polynomial encoding length.

This establishes the supported rational-mass formulation directly, without expanding rational masses into discrete students.
