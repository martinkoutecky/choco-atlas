The anchor (named result in the paper)

Theorem 4 — class: hardness

The continuous mirror question, as graded

Given a finite set \(T\) of reviewer types with rational masses \(\mu_t\) summing to \(1\), \(q\) interchangeable paper classes with rational per-capita supplies \(\beta_r\) summing to \(k\), and utilities \(u_t(r)\in\{\upsilon_1,\upsilon_2,\upsilon_3\}\), where \(0\le\upsilon_1<\upsilon_2<\upsilon_3\), what is the maximum \(\lambda\) for which there are nonnegative masses \(x_{t,z}\) assigned to integral bundle patterns \(z\in\mathbb Z_{\ge0}^q\), \(\sum_r z_r=k\), such that \(\sum_z x_{t,z}=\mu_t\), \(\sum_{t,z}z_r x_{t,z}\le\beta_r\) for every class \(r\), and \(x_{t,z}>0\) only if \(\sum_r z_r u_t(r)\ge\lambda\)? Determine the problem's complexity in the number of types, classes, and the input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) reviewer types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=q\ge1\) paper classes with nonnegative binary rational supplies \(\beta_r\), summing to \(k\), where \(k\ge2\) is a binary encoded integer. All classes are available to every type; papers within each class are interchangeable.
The input specifies common binary rational values \(0\le\upsilon_1<\upsilon_2<\upsilon_3\) and utilities \(u_t(r)\in\{\upsilon_1,\upsilon_2,\upsilon_3\}\). Let \(L\) be the total input bit length.
Let \(Z_k=\{z\in\mathbb Z_{\ge0}^{m}:\sum_r z_r=k\}\). An allocation consists of real masses \(x_{t,z}\ge0\) satisfying \(\sum_{z\in Z_k}x_{t,z}=\mu_t\) and \(\sum_{t,z}z_r x_{t,z}\le\beta_r\) for every class.
Its value is \(\min\{\sum_r z_r u_t(r):x_{t,z}>0\}\); let \(\mathrm{OPT}\) be the maximum such value. Thus every positive mass receives an integral bundle, and types may split among bundles.
Set \(\rho=\frac{\upsilon_2+(k-1)\upsilon_1}{\min\{2\upsilon_2,\upsilon_1+\upsilon_3\}+(k-2)\upsilon_1}\).
For each fixed rational \(\varepsilon>0\), on instances with \(\rho+\varepsilon\le1\), can an allocation of value at least \((\rho+\varepsilon)\mathrm{OPT}\) be computed in time polynomial in \(m,\tau,L\) (including only binary length dependence on \(k\)), or is achieving this guarantee NP-hard?
For finite agents and individual goods, achieving the same ratio is NP-hard for every fixed \(k\ge2\) and fixed utility triple, even when every good is available to every agent. [Source](https://aamas.csc.liv.ac.uk/AAMAS/aamas2014/proceedings/aamas/p997.pdf)
No result settling this approximation question for the precise mass formulation above was located in the literature search.

Result

The mass formulation is polynomial-time solvable, even exactly. An allocation of value \(\mathrm{OPT}\), represented by at most \(m+\tau\) positive rational masses, can be computed in time polynomial in \(m,\tau,L\). In particular, the dependence on \(k\) is through its binary encoding length.

The proof uses the configuration linear program and an exact separation oracle obtained from integer programming in three variables.

1. Integer utility thresholds

Write the three utility values as rationals and let \(D\) be the product of their denominators. Define \(a_j=D\upsilon_j\) for \(j\in\{1,2,3\}\). These are nonnegative integers, and their binary encoding lengths, together with that of \(D\), are polynomial in \(L\).

Every scaled bundle utility is an integer between \(ka_1\) and \(ka_3\). For an integer threshold \(h\), define

\[ C_t(h)=\left\{z\in\mathbb Z_{\ge0}^{m}:\sum_r z_r=k,\quad D\sum_r u_t(r)z_r\ge h\right\}. \]

Thus an allocation has value at least \(h/D\) precisely when all its positive variables use bundles in \(C_t(h)\).

Classes with \(\beta_r=0\) can be deleted. Indeed, their supply constraint forces \(z_r=0\) for every bundle receiving positive mass. At least one class remains because the supplies sum to \(k>0\). Below, \(R\) denotes the remaining classes, so every \(\beta_r\), \(r\in R\), is positive.

Threshold \(ka_1\) is feasible. To see this directly, let \(e_r\) be the unit vector for class \(r\), and set

\[ x_{t,ke_r}=\mu_t\frac{\beta_r}{k}. \]

The type masses sum correctly, and class \(r\) receives total consumption \(\beta_r\). Every bundle has scaled utility at least \(ka_1\).

2. A linear program for threshold feasibility

For a fixed \(h\), consider the following linear program, whose variables are indexed by \(t\in T\) and \(z\in C_t(h)\):

\[ F(h)=\max \sum_{t\in T}\sum_{z\in C_t(h)}x_{t,z}, \]

subject to

\[ x_{t,z}\ge0,\qquad \sum_{z\in C_t(h)}x_{t,z}\le\mu_t \quad(t\in T), \]

and

\[ \sum_{t\in T}\sum_{z\in C_t(h)}z_r x_{t,z}\le\beta_r \quad(r\in R). \]

This is a finite linear program: each bundle coordinate lies between \(0\) and \(k\). Its feasible region is nonempty and bounded, and \(F(h)\le\sum_t\mu_t=1\).

Claim. Threshold \(h/D\) is feasible if and only if \(F(h)=1\).

Proof. Any allocation attaining the threshold is feasible for this linear program and has objective value \(1\). Conversely, suppose a feasible solution has objective value \(1\). The nonnegative deficits

\[ \mu_t-\sum_{z\in C_t(h)}x_{t,z} \]

sum to zero, so every deficit is zero. Consequently, every type receives exactly its required mass, and every positive variable uses a bundle meeting the threshold. This is an allocation of value at least \(h/D\). \(\square\)

Its dual is

\[ \min_{\alpha,p}\left(\sum_{t\in T}\mu_t\alpha_t+ \sum_{r\in R}\beta_rp_r\right), \]

subject to

\[ \alpha_t\ge0,\qquad p_r\ge0, \]

and

\[ \alpha_t+\sum_{r\in R}p_rz_r\ge1 \quad(t\in T,\ z\in C_t(h)). \]

There are only \(\tau+|R|\) dual variables. The remaining task is to separate its implicitly specified bundle inequalities in polynomial time.

3. Exact separation using three integer variables

Fix a rational candidate \((\alpha,p)\). Negative coordinates immediately yield violated nonnegativity constraints, so assume all coordinates are nonnegative.

For a type \(t\), partition the remaining classes according to its utilities:

\[ R_{t,j}=\{r\in R:u_t(r)=\upsilon_j\}, \qquad j\in\{1,2,3\}. \]

For each nonempty group, choose a class \(r_{t,j}\) minimizing \(p_r\), and write \(c_{t,j}=p_{r_{t,j}}\). For an empty group, set \(c_{t,j}=0\) and impose \(n_j=0\) below.

Consider integer counts \(n_1,n_2,n_3\) satisfying

\[ n_j\ge0,\qquad n_1+n_2+n_3=k,\qquad a_1n_1+a_2n_2+a_3n_3\ge h, \]

with \(n_j=0\) whenever \(R_{t,j}\) is empty.

For these counts, the cheapest bundle puts all \(n_j\) papers from utility group \(j\) in class \(r_{t,j}\). Its price is \(\sum_j c_{t,j}n_j\). This assertion uses exactly the stated bundle model: a class may occur repeatedly, and supply restrictions constrain aggregate consumption rather than each individual bundle.

It follows that type \(t\) has a violated dual bundle inequality if and only if such integer counts exist with

\[ \sum_{j=1}^{3}c_{t,j}n_j<1-\alpha_t. \]

Here are both directions explicitly:

  • If a bundle \(z\in C_t(h)\) violates the dual inequality, take \(n_j=\sum_{r\in R_{t,j}}z_r\). Replacing every paper by a cheapest class in its utility group preserves its utility and weakly decreases its price. These counts therefore satisfy the strict inequality.
  • Conversely, counts satisfying the strict inequality yield a bundle by setting \(z_{r_{t,j}}=n_j\) for each nonempty group and all other coordinates to zero. This bundle belongs to \(C_t(h)\) and violates the dual inequality.

The strict inequality can be encoded exactly as an integer linear constraint. Let \(Q\) be the product of the denominators of \(\alpha_t,c_{t,1},c_{t,2},c_{t,3}\). Then it is equivalent to

\[ \sum_{j=1}^{3}(Qc_{t,j})n_j \le Q(1-\alpha_t)-1. \]

All coefficients in this inequality are integers.

We have therefore reduced separation for one type to integer linear feasibility in three variables, with a constant number of constraints. Lenstra’s fixed-dimensional integer-programming theorem solves this in time polynomial in the binary length of the coefficients. Its dimension hypothesis is satisfied independently of \(m,\tau,k\). [Lenstra, *Integer Programming with a Fixed Number of Variables*](https://pub.math.leidenuniv.nl/~lenstrahw/PUBLICATIONS/1983i/art.pdf).

A feasible integer witness can also be recovered in polynomial time. Even using only a feasibility routine, one can determine each coordinate by binary search over \(\{0,\ldots,k\}\), successively fixing the recovered coordinates. This requires only a polynomial number of calls.

Scanning the classes to obtain the cheapest representatives and applying this procedure to each listed type gives an exact polynomial-time separation oracle for the dual. Its running time is polynomial in \(m,\tau,L\) and the encoding length of the query.

4. Exact LP solution and allocation recovery

We use the constructive separation–optimization theorem for rational linear programming: with polynomially many variables, a known polynomial bound on individual constraint encoding lengths, and a polynomial-time exact separation oracle returning original violated inequalities, one can compute the exact optimum and recover an optimal solution of the dual linear program using polynomially many inequalities. Equivalently, for an LP with implicitly specified columns, one can recover an optimal solution supported on polynomially many columns. This includes exact rational computation and does not require full-dimensional feasible regions. [Grötschel–Lovász–Schrijver, *Geometric Algorithms and Combinatorial Optimization*](https://link.springer.com/book/10.1007/978-3-642-78240-4).

The hypotheses hold here:

  • The dual dimension is \(\tau+|R|\).
  • Every bundle inequality has coefficients in \(\{0,\ldots,k\}\) and right-hand side \(1\); its encoding length is polynomial in \(m,L\).
  • Section 3 supplies the required exact separation oracle.
  • A bounded search region containing an optimum is explicitly available, as shown next.

The dual point \(\alpha_t=1\), \(p_r=0\) is feasible and has objective value \(1\). Because every objective coefficient is positive, any nonnegative point with objective at most \(1\) satisfies

\[ \alpha_t\le\frac1{\mu_t},\qquad p_r\le\frac1{\beta_r}. \]

Thus these rational coordinate bounds retain an optimal dual solution and have polynomial encoding length.

For completeness, these bounds also permit constructive recovery without changing the relevant restricted LP values. Retain the polynomial collection of bundle inequalities produced by the constructive ellipsoid procedure. Any dual restricted to those inequalities still admits \(\alpha_t=1,p_r=0\). Its minimum is attained: its nonnegative objective sublevel set at value \(1\) is compact because all objective coefficients are positive. Every minimizer lies within the same coordinate bounds. Consequently, removing those computational bounds leaves the restricted dual optimum unchanged.

The corresponding restricted primal keeps only the bundle variables associated with these retained inequalities. Strong duality gives it the same optimum \(F(h)\), and it can now be solved as an explicitly described polynomial-size LP. This standard primal-recovery procedure is also described in the proof of Theorem 3.5 of [Roughgarden–Kearns, *Marginals-to-Models Reducibility*](https://timroughgarden.org/papers/marg.pdf).

Choosing an optimal basic feasible solution yields at most \(\tau+|R|\le\tau+m\) positive bundle variables: after introducing slack variables, there are only \(\tau+|R|\) equations.

All returned masses have polynomial binary encoding length. Indeed, a basis matrix has dimension at most \(d=\tau+m\) and integer entries of absolute value at most \(k\). Hadamard’s determinant bound and Cramer’s rule, after clearing the rational right-hand-side denominators, bound the solution encoding lengths polynomially in \(d,L,\log k\). Each bundle also has polynomial encoding length because its coordinates are at most \(k\).

Therefore \(F(h)\) can be computed exactly, and whenever \(F(h)=1\), an explicit sparse allocation meeting the threshold can be returned.

5. Finding the exact optimum

Threshold feasibility is monotone: \(C_t(h+1)\subseteq C_t(h)\).

Binary search over the integer interval from \(ka_1\) to \(ka_3\), using the exact test \(F(h)=1\), finds the largest feasible integer threshold \(h^\star\). The number of iterations is at most

\[ O\!\left(\log\bigl(k(a_3-a_1)+1\bigr)\right), \]

which is polynomial in \(L\).

Every allocation’s scaled value is an integer, since it is the minimum of finitely many integer bundle utilities. Feasible allocations exist by Section 1, and there are finitely many possible values. Hence the largest feasible threshold satisfies

\[ h^\star=D\,\mathrm{OPT}. \]

Recovering the primal solution at \(h^\star\) therefore produces an allocation of value exactly \(\mathrm{OPT}\).

6. Consequence for the requested guarantee

The exact algorithm applies to every instance described in the question. On instances satisfying \(\rho+\varepsilon\le1\), nonnegativity of utilities gives

\[ \mathrm{OPT}\ge(\rho+\varepsilon)\mathrm{OPT}. \]

Thus the requested guarantee is achievable in polynomial time.

This does not contradict the cited finite-agent hardness result. In that model, each agent must receive a single bundle of individual goods. In the present model, a type may split its mass among bundles, and feasibility is exactly linear in those masses. No integrality condition forces a type to choose one bundle. The cited result concerns the former formulation. [Ferraioli–Gourvès–Monnot, *On Regular and Approximately Fair Allocations of Indivisible Goods*](https://aamas.csc.liv.ac.uk/AAMAS/aamas2014/proceedings/aamas/p997.pdf).
