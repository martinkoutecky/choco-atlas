Theorem 4.10 — class: hardness

The continuous mirror question, as graded

Given \(m\) candidates, a scoring rule \(f\), a target \(p\), and a finite support of rankings \(\pi\) with binary-rational registered and eligible masses \(r_\pi,u_\pi\), normalized so that \(\sum_\pi(r_\pi+u_\pi)=1\), decide whether there are rational mobilized masses \(x_\pi\) and a budget \(\kappa\) such that \(0\le x_\pi\le u_\pi\), \(\sum_\pi x_\pi\le\kappa\), and \(\sum_\pi(r_\pi+x_\pi)(\alpha^{f,m}_{\operatorname{pos}_\pi(p)}-\alpha^{f,m}_{\operatorname{pos}_\pi(c)})\ge0\) for every candidate \(c\).

Packaged proof task (what the prover saw — nothing else)

Fix a pure scoring generator \(f\) that computes, in time polynomial in \(m\), a nonincreasing vector \(\alpha^{f,m}\in\mathbb Q^m\); deleting one entry of \(\alpha^{f,m}\) gives \(\alpha^{f,m-1}\). Assume \(\alpha^{f,m_0}_4>\alpha^{f,m_0}_{m_0-2}\) for some \(m_0\ge7\).
An instance has a candidate set \(C\) of size \(m\ge1\), a target \(p\in C\), and an input budget \(\kappa\in\mathbb Q\cap[0,1]\).
A society is given by its support: a list of \(\tau\) strict rankings \(\pi\) of \(C\), each with binary-rational registered and eligible masses \(r_\pi,u_\pi\ge0\), where \(r_\pi+u_\pi>0\) and \(\sum_\pi(r_\pi+u_\pi)=1\). Thus \(\tau\) is the support size, not the number of possible rankings.
Eligible mass may be mobilized in rational portions at unit cost per unit mass; registered mass remains present. Ties count as wins for \(p\).
Decide whether there exist \(x_\pi\in\mathbb Q\) satisfying \(0\le x_\pi\le u_\pi\), \(\sum_\pi x_\pi\le\kappa\), and \(\sum_\pi(r_\pi+x_\pi)(\alpha^{f,m}_{\operatorname{pos}_\pi(p)}-\alpha^{f,m}_{\operatorname{pos}_\pi(c)})\ge0\) for every \(c\in C\), where \(\operatorname{pos}_\pi(c)\) is the position of \(c\) in \(\pi\).
Let \(L\) be the total bit length of the masses, budget, and scoring coefficients; state running times in \(m,\tau,L\).

For each such fixed \(f\), is this continuous constructive control problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

Discrete constructive control by adding at most a given number of unweighted voters is NP-complete for every fixed generator satisfying the stated conditions. [Verified source](https://arxiv.org/pdf/1404.4560v1)

  • The graded question existentially quantified the budget; made it a binary-rational input, as the discrete problem supplies the number of voters that may be added. Restricted it to [0,1], since total available mass is at most 1.
  • The representation and scope of f were unspecified; treated it as a fixed polynomial-time uniform pure rational scoring generator satisfying the anchor's strict coefficient condition.
  • Specified nonnegative registered and eligible masses, positive combined mass for each listed ranking, strict complete rankings, and support size as the number of listed rankings.
  • Specified that ties count as wins, matching the discrete requirement that the target be a winner.
  • Specified unit cost per unit of mobilized mass and defined L to include the rational scoring coefficients.

Polynomial-time solvability

The continuous problem is solvable in time polynomial in \(m,\tau,L\) for every fixed generator in the question. In fact, the proof applies to any polynomial-time computable rational scoring vectors; purity and the stated score gap are unnecessary.

1. Linear programming formulation

Enumerate the supplied rankings as \(\pi_1,\ldots,\pi_\tau\), and write their masses as \(r_i,u_i\). Set \(\alpha=\alpha^{f,m}\). For each opponent \(c\in C\setminus\{p\}\), define

\(\displaystyle d_{ci}=\alpha_{\operatorname{pos}_{\pi_i}(p)}-\alpha_{\operatorname{pos}_{\pi_i}(c)},\qquad b_c=-\sum_{i=1}^{\tau}r_i d_{ci}.\)

Consider the real polyhedron \(P\subseteq\mathbb R^\tau\) defined by

\(\displaystyle 0\le x_i\le u_i\quad(1\le i\le\tau),\)

\(\displaystyle \sum_{i=1}^{\tau}x_i\le\kappa,\)

\(\displaystyle \sum_{i=1}^{\tau}d_{ci}x_i\ge b_c\quad(c\in C\setminus\{p\}).\)

There are \(\tau\) variables and \(2\tau+m\) inequalities.

For each opponent \(c\), its inequality is equivalent to

\(\displaystyle \sum_{i=1}^{\tau}(r_i+x_i)\bigl(\alpha_{\operatorname{pos}_{\pi_i}(p)}-\alpha_{\operatorname{pos}_{\pi_i}(c)}\bigr)\ge0.\)

Thus it states exactly that \(p\)'s score is at least \(c\)'s score. The omitted inequality for \(c=p\) is identically satisfied. The remaining inequalities express precisely the mobilization bounds and budget.

Consequently, the original instance is a yes-instance exactly when \(P\) contains a rational point. We next justify replacing rational feasibility by real feasibility.

2. Rational feasibility and witness size

Let \(D\) be the product of the positive denominators of all input masses, the budget, and the scoring coefficients, represented as binary fractions. Since their total encoding length is \(L\), we have \(D\le2^L\).

Every \(d_{ci}\) has denominator dividing \(D\). Every product \(r_i d_{ci}\), and hence every \(b_c\), has denominator dividing \(D^2\). Multiplying all inequalities by the positive integer \(D^2\) therefore gives an equivalent system with integer coefficients.

These integer coefficients have \(O(L)\) bits. Indeed, each scoring coefficient has absolute value at most \(2^L\), so

\(\displaystyle |d_{ci}|\le2^{L+1}.\)

The normalization and nonnegativity imply \(\sum_i r_i\le1\), giving

\(\displaystyle |b_c|\le\sum_i r_i|d_{ci}|\le2^{L+1}.\)

Also \(u_i,\kappa\in[0,1]\). After multiplication by \(D^2\), all matrix and right-hand-side entries consequently have absolute value at most \(2^{3L+1}\).

Suppose \(P\) is nonempty. It is closed and bounded because \(0\le x_i\le u_i\le1\), so it is compact. Obtain a point \(v\) by successively minimizing coordinates \(x_1,\ldots,x_\tau\), each time restricting to the preceding minimizers. Compactness ensures that every minimum exists, and the final set is a singleton.

This point is extreme: if \(v=(y+z)/2\) with \(y,z\in P\), minimality of the first coordinate forces \(y_1=z_1=v_1\). Successive minimality forces equality of every subsequent coordinate, so \(y=z=v\).

The active constraint normals at \(v\) span \(\mathbb R^\tau\). Otherwise, take a nonzero vector \(h\) orthogonal to all active normals. Active constraints remain equalities at \(v\pm\varepsilon h\). Each inactive constraint has positive slack, so, because there are finitely many constraints, sufficiently small \(\varepsilon>0\) preserves them all. Both points then belong to \(P\), contradicting extremality.

Choose \(\tau\) linearly independent active constraints from the integer system. They give \(Av=a\), where \(A\) is a nonsingular integer matrix. Cramer's rule yields

\(\displaystyle v_j=\frac{\det A_j}{\det A},\)

where \(A_j\) replaces column \(j\) by \(a\). Hence \(v\) is rational.

For completeness, if all entries are bounded by \(H=2^{3L+1}\), Hadamard's inequality gives

\(\displaystyle |\det A|,\ |\det A_j|\le(\sqrt{\tau}\,H)^\tau.\)

Thus each coordinate has numerator and denominator bit length \(O(\tau(L+\log(\tau+1)))\), and the entire witness has polynomial bit length.

We have proved that \(P\) is real-feasible if and only if it is rational-feasible.

3. Algorithm and running time

Use the standard exact linear programming theorem: feasibility of an explicitly given integer linear inequality system can be decided in time polynomial in its binary encoding length, including when its feasible region has empty interior. This is the polynomial-time feasibility theorem for the ellipsoid method; see [MIT's linear programming lecture notes, slides 25–28](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

All hypotheses hold here: the integer system is explicit, has finitely many inequalities, and has polynomial encoding length. A sufficient bound for that length is

\(\displaystyle B=O\bigl((m+2\tau)(\tau+1)(L+\log(m+\tau+2))\bigr).\)

The algorithm computes the scoring vector, reads the supplied rankings to determine positions, constructs the integer system, and decides its feasibility. These construction steps take polynomial time in \(m,\tau,L\). If \(T_f(m)\) denotes the fixed generator's polynomial running time, the total running time is

\(\displaystyle T_f(m)+\operatorname{poly}\bigl(m\tau\log(m+1)+L+B\bigr)=\operatorname{poly}(m,\tau,L).\)

Only the \(\tau\) supplied rankings are used; no enumeration of all possible rankings occurs. Non-strict inequalities preserve ties exactly. For \(m=1\), choosing every \(x_i=0\) always succeeds.

4. Relation to the discrete problem

The discrete problem restricts each mobilization amount to an integer voter count. Here rational portions are permitted, so the feasible set is the rational part of a polyhedron whose real feasibility is decidable in polynomial time. Discrete hardness therefore does not transfer merely by rescaling voter counts into masses: the rescaled continuous instance also admits fractional choices.

The requested classification is membership in \(\mathrm P\); NP-hardness under polynomial-time many-one reductions would therefore imply \(\mathrm P=\mathrm{NP}\).
