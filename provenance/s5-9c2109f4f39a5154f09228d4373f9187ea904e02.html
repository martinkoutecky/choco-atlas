Result

The search problem is \(\mathrm{NP}\)-hard, even when all utilities belong to \(\{0,1,\ldots,5\}\). Consequently, an algorithm running in time polynomial in \(m,\tau,k,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The key is that aggregating identical voters preserves FJR exactly. No expansion of binary-rational masses is needed for the hardness reduction.

1. The discrete-voter hardness theorem

We use the following known result: finding an FJR committee for explicitly listed voters is \(\mathrm{NP}\)-hard, even with unit costs and utilities in \(\{0,1,\ldots,5\}\). Its FJR definition permits the demanding project set to overlap the committee, exactly as in the question. See [Definition 1 and Theorem 4.1 of the cited paper](https://arxiv.org/html/2609.02030v1#S4).

For an electorate \(N\) of size \(n\), discrete FJR requires, for every nonempty \(S\subseteq N\) and every \(D\subseteq C\),

\(\displaystyle \frac{|S|}{n}\geq\frac{|D|}{k}\quad\Longrightarrow\quad \max_{i\in S}u_i(W)\geq\min_{i\in S}u_i(D).\)

We next prove that this condition survives aggregation without any change to its meaning.

2. Exact aggregation lemma

Lemma. Partition an explicitly listed electorate into its distinct utility types \(T\). Let \(N_t\) be the voters of type \(t\), and assign mass \(\mu_t=|N_t|/n\). A committee satisfies discrete FJR if and only if it satisfies the mass-based FJR condition in the question.

Proof.

First suppose \(W\) satisfies discrete FJR. Take any nonempty \(Q\subseteq T\) and any \(D\subseteq C\) with \(\sum_{t\in Q}\mu_t\geq |D|/k\). Define the voter coalition \(S=\bigcup_{t\in Q}N_t\). Then

\(\displaystyle \frac{|S|}{n}=\sum_{t\in Q}\mu_t\geq\frac{|D|}{k}.\)

Since the utility functions occurring in \(S\) are exactly those indexed by \(Q\),

\(\displaystyle \max_{i\in S}u_i(W)=\max_{t\in Q}u_t(W),\qquad \min_{i\in S}u_i(D)=\min_{t\in Q}u_t(D).\)

Discrete FJR therefore gives the required mass-based inequality.

Conversely, suppose \(W\) satisfies mass-based FJR. Take any nonempty voter coalition \(S\subseteq N\) and any \(D\subseteq C\) with \(|S|/n\geq |D|/k\). Let \(Q\) consist of the types represented in \(S\). Because \(S\subseteq\bigcup_{t\in Q}N_t\),

\(\displaystyle \sum_{t\in Q}\mu_t=\frac{\left|\bigcup_{t\in Q}N_t\right|}{n}\geq\frac{|S|}{n}\geq\frac{|D|}{k}.\)

Every type in \(Q\) occurs in \(S\), so the same equalities of utility extrema hold. Mass-based FJR consequently implies the discrete FJR inequality for \(S,D\). This proves both directions. \(\square\)

The essential point is that adding copies of types already represented in a coalition increases its population share and leaves both utility extrema unchanged.

3. Polynomial reduction and encoding size

Take an instance of the discrete search problem from Section 1. Keep \(C,k\), group voters with identical utility vectors, and output one entry per distinct type, with mass \(|N_t|/n\).

This produces a valid support instance:

  • Every listed mass is positive.
  • The masses sum to \(1\).
  • All listed utility types are distinct.
  • Utilities remain in \(\{0,1,\ldots,5\}\).

Each mass has a numerator and denominator using \(O(\log(n+1))\) bits. With standard project indexing, the resulting input length satisfies

\(\displaystyle L=O\!\left(\tau m+\tau\log(n+1)+m\log(m+1)\right).\)

Grouping the explicitly listed utility vectors and constructing these fractions takes polynomial time in the original input length. In particular, the reduction never expands a rational mass into voters.

If a target algorithm ran in time \(p(m,\tau,k,L)\) for some polynomial \(p\), its running time on the reduced instance would be polynomial in the original input length: \(\tau\leq n\), \(k<m\), and the displayed encoding bound is polynomial.

By the aggregation lemma, every committee returned by that algorithm would satisfy FJR for the original electorate. Thus it would solve the discrete search problem in polynomial time, contradicting the cited hardness theorem unless \(\mathrm{P}=\mathrm{NP}\).

This proves the claimed search hardness by a polynomial, solution-preserving reduction.

4. Existence and an explicit finite running-time bound

The rational-support formulation still always admits an FJR committee.

To see this, write \(\mu_t=a_t/b_t\) and take \(N=\prod_{t\in T}b_t\). Replace type \(t\) conceptually by \(N\mu_t\) identical voters. These multiplicities are positive integers summing to \(N\). The discrete FJR existence theorem applies, and the aggregation lemma transfers its committee back to the support instance. See [Proposition 2 of the cited paper](https://arxiv.org/html/2609.02030v1#S2.SS2).

This expansion establishes existence; its size need not be polynomial in \(L\).

For an explicit algorithm without expansion, define

\(\displaystyle H(m,k)=\sum_{j=0}^{k}\binom{m}{j}.\)

Enumerate all \(H(m,k)\) feasible committees. For each committee, check every nonempty \(Q\subseteq T\) and every \(D\subseteq C\) of size at most \(k\). Sets \(D\) larger than \(k\) cannot meet the mass condition because total mass is \(1\).

Each check uses exact rational and integer arithmetic in time polynomial in \(m,\tau,k,L\). Rational sums have polynomial bit length: the product of their input denominators has bit length bounded by the sum of the denominator bit lengths. Hence exhaustive search runs in

\(\displaystyle O\!\left(2^\tau H(m,k)^2\,\operatorname{poly}(m,\tau,k,L)\right).\)

Existence guarantees that this search returns a committee. The hardness result rules out replacing this bound by a general polynomial bound unless \(\mathrm{P}=\mathrm{NP}\).
