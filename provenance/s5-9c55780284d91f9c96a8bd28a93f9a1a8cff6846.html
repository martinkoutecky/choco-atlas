The continuous mirror question, as graded

Given a finite directed unsigned graph \(H=(T,A)\) with maximum indegree at most \(6\), an initial role state \(y:T\to\{-1,+1\}\), and target role \(u\in T\), form the measured society \(X=T\times[0,1]\) with \(\nu(\{t\}\times B)=|B|/|T|\), and arcs \((s,q)\to(t,q)\) whenever \((s,t)\in A\). Under synchronous \(d_{(3,4)}\), with every member of role \(t\) starting at \(y(t)\), decide whether there is an integer \(k\ge 0\) such that \(\omega_k(u,q)=+1\) for almost every \(q\in[0,1]\).

Packaged proof task (what the prover saw — nothing else)

Let \(H=(T,A)\) be a finite nonempty loopless directed unsigned graph without parallel arcs, allowing opposite arcs, with maximum indegree at most \(6\); let \(y:T\to\{-1,+1\}\) and \(u\in T\).
A society is given by its support: the list of its \(\tau=|T|\) types with positive mass, each mass a binary rational; here every type has mass \(1/\tau\). Support size means listed types, not the number of possible types. Set \(m=|A|\) and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Define \(X=T\times[0,1]\) with \(\nu(\{t\}\times B)=\operatorname{Leb}(B)/\tau\) for measurable \(B\). Its arcs are exactly \((s,q)\to(t,q)\) for \((s,t)\in A\).
Initially \(\omega_0(t,q)=y(t)\). For \(k\ge0\), let \(p_k(t,q)=|\{s:(s,t)\in A,\ \omega_k(s,q)=+1\}|\), counting individual in-neighbors rather than their mass.
Update every member synchronously: \(\omega_{k+1}(t,q)=+1\) precisely when either \(\omega_k(t,q)=+1\) and \(p_k(t,q)\ge3\), or \(\omega_k(t,q)=-1\) and \(p_k(t,q)\ge4\); otherwise set it to \(-1\).

Is deciding whether there exists an integer \(k\ge0\) such that \(\omega_k(u,q)=+1\) for Lebesgue-almost every \(q\in[0,1]\) solvable in polynomial time, or is it NP-hard?

For finite societies, synchronous reachability of a positive opinion at one specified vertex under these thresholds is PSPACE-complete, even on unsigned directed graphs of maximum indegree \(6\). [Di Ianni](https://doi.org/10.3390/appliedmath3010002)
No published complexity result for exactly the measured model specified here was located in the literature search.

Result

The problem is \(\mathrm{PSPACE}\)-complete, and therefore \(\mathrm{NP}\)-hard, under polynomial-time many-one reductions. The continuous coordinate does not change the finite dynamics.

1. Exact correspondence with the finite process

For a configuration \(z:T\to\{-1,+1\}\), define
\(p_z(t)=|\{s:(s,t)\in A,\ z(s)=+1\}|\).
Let \(F(z)(t)=+1\) precisely when either \(z(t)=+1\) and \(p_z(t)\ge3\), or \(z(t)=-1\) and \(p_z(t)\ge4\); otherwise let \(F(z)(t)=-1\).

Define the finite trajectory by \(z_0=y\) and \(z_{k+1}=F(z_k)\).

Lemma. For every integer \(k\ge0\), every \(t\in T\), and every \(q\in[0,1]\),
\(\omega_k(t,q)=z_k(t)\).

Proof. At time \(0\), this is the specified initialization. Suppose it holds at time \(k\). The in-neighbors of \((t,q)\) are exactly the distinct members \((s,q)\) with \((s,t)\in A\). Consequently,
\(p_k(t,q)=|\{s:(s,t)\in A,\ z_k(s)=+1\}|=p_{z_k}(t)\).
The measured and finite processes therefore apply identical update conditions, giving \(\omega_{k+1}(t,q)=F(z_k)(t)=z_{k+1}(t)\). Induction proves the claim. \(\square\)

Thus, for each \(k\), the set \(\{q:\omega_k(u,q)=+1\}\) is either all of \([0,1]\) or empty. In particular,
\(\exists k\ge0:\omega_k(u,q)=+1\text{ for Lebesgue-almost every }q\)
holds if and only if
\(\exists k\ge0:z_k(u)=+1\).

This is an exact equivalence; no exceptional null set is needed.

2. Polynomial-time hardness reduction

We use the finite \(\mathrm{PSPACE}\)-completeness result supplied in the task: synchronous positive-opinion reachability at a specified vertex is \(\mathrm{PSPACE}\)-complete for these thresholds on the stated class of unsigned directed graphs of maximum indegree \(6\). The threshold rule and degree restriction agree with Di Ianni’s finite result. [Di Ianni, *Game of Life-like Opinion Dynamics*](https://www.mdpi.com/2673-9909/3/1/2)

Take a finite instance with \(n\ge1\) vertices. To ensure that every uniform mass even has a finite binary expansion, set \(r=2^{\lceil\log_2 n\rceil}\) and add \(r-n\) isolated vertices, initially negative. Keep the original distinguished vertex.

The added vertices remain negative because they have no in-neighbors. They do not affect any original vertex. The resulting graph remains nonempty, loopless, unsigned, without parallel arcs, and of maximum indegree at most \(6\).

Use its vertices as the explicitly listed types, each with mass \(1/r\), and prescribe the measured arcs exactly as in the question. The support size is \(\tau=r<2n\), the number of arcs remains \(m\), and each mass requires \(O(\log(n+1))\) bits.

For a finite input of bit length \(L_{\mathrm{fin}}\), copying its encoding and writing the added types and masses takes \(O(L_{\mathrm{fin}}+n\log(n+1))\) time and produces an encoding of that same asymptotic size. Hence this is a polynomial-time reduction.

By the lemma and the independence of the added vertices, the finite instance is positive exactly when the measured instance is positive. The measured problem is therefore \(\mathrm{PSPACE}\)-hard, hence \(\mathrm{NP}\)-hard.

3. Polynomial-space upper bound and running time

There are \(N=2^\tau\) finite configurations. Among \(z_0,\ldots,z_N\), two coincide. Since the update map is deterministic, the trajectory thereafter repeats configurations already encountered. Therefore, if the distinguished vertex ever becomes positive, it does so at some time \(k<N\).

An algorithm can inspect \(z_k(u)\) for \(k=0,\ldots,N-1\), generating each next configuration synchronously with separate current and next arrays. It needs no table of previously visited configurations.

One update takes \(O(m+\tau)\) operations: scan the arcs to count positive in-neighbors, then update each vertex. Counts are bounded by \(6\). A counter for the \(N\) iterations uses \(O(\tau)\) bits, and its increment takes at most \(O(\tau)\) bit operations.

On a standard word RAM, including input parsing, this gives time
\(O(L+2^\tau(m+\tau))\)
and a conservative space bound of
\(O(L+(m+\tau)\log(\tau+1))\) bits.
Since \(m\le6\tau\), the time bound simplifies to \(O(L+\tau2^\tau)\). The space bound is polynomial in the explicit input length, proving membership in \(\mathrm{PSPACE}\).

Combining both directions proves \(\mathrm{PSPACE}\)-completeness. Polynomial-time solvability would therefore be equivalent to \(\mathrm{P}=\mathrm{PSPACE}\).
