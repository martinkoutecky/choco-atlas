The continuous mirror question, as graded

Given a fixed finite feature set \(V\), a support \(T\) of complete strict acyclic CP-nets \(N_t\) over \(V\), positive rational masses \(\mu_t\) summing to \(1\), two outcomes \(o,o'\), and a rational threshold \(q\in[0,1]\), decide whether \(\sum_{t\in T:\,N_t\models o\succ o'}\mu_t\ge q\).

Packaged proof task (what the prover saw — nothing else)

An instance has a nonempty feature set \(V\), with \(m=|V|\), and explicitly listed finite domains \(D_X\), each of size at least two; these are shared by all types and may vary between instances.
A type is a CP-net whose dependency graph is acyclic and whose explicitly supplied conditional preference table gives a strict total order on \(D_X\) for every assignment to the parents of \(X\).
An outcome belongs to \(\Omega=\prod_{X\in V}D_X\). An improving flip changes exactly one feature to any locally preferred value under the current parent assignment. Write \(N_t\models o\succ o'\) precisely when a sequence of at least one improving flip leads from \(o'\) to \(o\).
A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), satisfying \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible CP-nets.
Given this society, outcomes \(o,o'\in\Omega\), and a binary rational threshold \(q\in[0,1]\), decide whether \(\sum_{t\in T:\,N_t\models o\succ o'}\mu_t\ge q\). Equality meets the threshold; incomparable types contribute zero.
Measure running time in \(m\), \(\tau\), \(d=\max_X|D_X|\), and total input bit length \(L\), including domains, graphs, tables, outcomes, masses, and threshold.

Is this rational-mass dominance-threshold problem solvable in polynomial time in \(m,\tau,d,L\), or is it NP-hard?

Known results: individual dominance admits a computable positive rank-gap lower bound, giving a sound necessary-condition pruning test ([Laing–Thwaites–Gosling](https://doi.org/10.1613/jair.1.11323)); individual dominance is NP-hard even for binary acyclic CP-nets ([Boutilier et al.](https://www2.cs.sfu.ca/CourseCentral/411/jim/CPNets.JAIR04.pdf)).
For finite unweighted societies, strict-majority dominance is NP-complete on polynomially connected acyclic binary CP-nets ([Lukasiewicz–Malizia](https://arxiv.org/pdf/1806.10018)). No classification specifically using the explicit-support rational-mass input above was verified.

Result

The rational-mass dominance-threshold problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions. This holds even for binary domains and a fixed support size. Therefore, a polynomial-time algorithm in \(m,\tau,d,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. The individual dominance problem used in the reduction

We use the following established theorem: deciding whether an improving-flip sequence leads from \(o'\) to \(o\) is \(\mathrm{NP}\)-hard for binary acyclic CP-nets with fully specified strict conditional preferences. The hardness construction in Theorem 15 and Appendix A of [Boutilier et al.](https://www2.cs.sfu.ca/CourseCentral/411/jim/CPNets.JAIR04.pdf) has at most six parents per feature.

This theorem applies to the encoding in the question. With binary domains and at most six parents, each conditional preference table has at most \(2^6\) rows. Thus the source hardness construction has polynomial size even when every table row is explicitly supplied. Binary flips also coincide exactly with the improving flips allowed here.

2. Direct reduction to the stated problem

Given such an individual dominance instance \((N,o,o')\), construct a society with

\[ \]
\(T=\{t\},\qquad N_t=N,\qquad \mu_t=1,\qquad q=1.\)

Copy the feature set, domains, graph, tables, and queried outcomes unchanged. This is a valid instance: the single mass is positive and sums to one, and the threshold belongs to the permitted interval.

Its supporting mass is exactly

\( \displaystyle \sum_{t:\,N_t\models o\succ o'}\mu_t = \begin{cases} 1,&N\models o\succ o',\\ 0,&N\not\models o\succ o'. \end{cases} \)

Consequently, the supporting mass meets the threshold if and only if the original dominance instance is positive.

The construction copies the source input and adds constant-size data. In particular, \(\tau=1\), \(d=2\), and the output length is polynomial in the source length. Hence an algorithm polynomial in \(m,\tau,d,L\) would solve the source problem in polynomial time. This proves the claimed hardness.

3. Hardness with two distinct types and equal masses

The singleton reduction already settles the question. To show that hardness persists with multiple supported types, we give a second reduction with fixed \(\tau=2\), equal masses, and fixed \(q=\frac12\).

Start with the same source instance \((N,o,o')\). Add a fresh binary feature \(Z\), and define extended outcomes

\(\widehat o=(o,Z=0),\qquad \widehat o'=(o',Z=0).\)

Construct two types on this common feature set and these common domains:

  • Type \(A\): retain \(N\) on the original features; make \(Z\) isolated with unconditional preference \(1\succ 0\).
  • Type \(B\): make every feature independent. For each original feature \(X\), prefer \(o'[X]\) to its other domain value. For \(Z\), prefer \(0\succ 1\).

Both graphs are acyclic, and all tables give strict total orders. The types are distinct because their preferences for \(Z\) differ.

Preservation for type \(A\). We claim that

\(N_A\models\widehat o\succ\widehat o' \quad\Longleftrightarrow\quad N\models o\succ o'.\)

For the forward implication, consider a positive-length improving sequence between the extended outcomes. If it flipped \(Z\), that flip would necessarily change \(0\) to \(1\). No improving flip could return \(Z\) to \(0\), contradicting the target assignment. Thus the sequence never flips \(Z\). Every step changes an original feature under exactly its original parent assignment and preference table, so the same positive-length sequence witnesses dominance in \(N\).

For the reverse implication, any improving sequence in \(N\) remains improving in \(N_A\) while \(Z\) stays at \(0\).

No support from type \(B\). At \(\widehat o'\), every feature has its unconditionally preferred value in \(N_B\). Therefore no improving flip is available. Since dominance requires at least one flip,

\(N_B\not\models\widehat o\succ\widehat o'.\)

Now assign \(\mu_A=\mu_B=\frac12\) and set \(q=\frac12\). The supporting mass is \(\frac12\) precisely when the original dominance instance is positive, and is zero otherwise. Because equality meets the threshold, this is another correct many-one reduction.

The construction adds one feature, copies one original CP-net, and supplies only unconditional tables for the second type. Its encoding size is polynomial. Thus hardness holds even with two distinct supported types and equal, constant-size rational masses.

4. Exact arithmetic and the scope of the conclusion

Once the supporting types are known, the rational comparison is polynomial-time computable. Write \(\mu_t=a_t/b_t\) and \(q=c/e\), with positive denominators, and let

\(Q=e\prod_{t\in T}b_t.\)

For any specified subset \(S\subseteq T\), the threshold test is equivalent to the integer comparison

\(\displaystyle \sum_{t\in S}a_t(Q/b_t)\ \ge\ c(Q/e). \)

The bit length of \(Q\) is bounded by the sum of the input denominator lengths, hence by \(O(L)\). All intermediate integers have polynomial bit length, and there are polynomially many arithmetic operations.

The hardness therefore already occurs in determining individual dominance, with constant-size masses and thresholds. A sound necessary-condition pruning test does not change the reduction: deciding whether an unpruned type actually supports the comparison remains necessary.

The proved classification is \(\mathrm{NP}\)-hard. No claim of \(\mathrm{NP}\)-completeness for the unrestricted input class is needed to settle the question.
