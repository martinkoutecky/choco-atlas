The continuous mirror question, as graded

Given candidates \(C\), a tie-breaking order, a target \(c^\star\), an integer \(k\), and a finite support of partial-ranking types \(P_t\) with rational masses \(\mu_t>0\) summing to \(1\), let \(A_t\) be the candidates that type \(t\) can rank first in a completion. A feasible completion assigns \(x_{t,a}\geq 0\) for \(a\in A_t\), with \(\sum_{a\in A_t}x_{t,a}=\mu_t\); candidate \(a\)'s plurality score is \(\sum_t x_{t,a}\). Decide whether some feasible completion puts \(c^\star\) in the top \(k\), and whether every feasible completion does.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq2\) candidates. The input includes a strict linear tie-breaking order \(\succ_{\mathrm{tie}}\), a target \(c^\star\in C\), and an integer \(1\leq k\leq m\), with \(k\) part of the input.
A society is given by its support: a list of \(\tau\) distinct partial-order types \(P_t\) on \(C\), each explicitly represented and carrying positive binary-rational mass \(\mu_t\), with \(\sum_t\mu_t=1\). These orders specify strict comparisons; completions are linear extensions. Here \(\tau\) is the support size, not the number of possible types.
Let \(A_t\) be the candidates appearing first in some linear extension of \(P_t\). A feasible mass completion consists of real numbers \(x_{t,a}\geq0\) for \(a\in A_t\), satisfying \(\sum_{a\in A_t}x_{t,a}=\mu_t\); set \(x_{t,a}=0\) otherwise.
Under plurality, candidate \(a\) has score \(s_x(a)=\sum_t x_{t,a}\). Sort candidates by decreasing score, breaking equal scores by \(\succ_{\mathrm{tie}}\); write \(r_x(a)\) for the resulting position.
The possible decision problem asks whether some feasible \(x\) satisfies \(r_x(c^\star)\leq k\); the necessary decision problem asks whether every feasible \(x\) does. Let \(L\) be the total input bit length; express running times in \(m,\tau,L,k\).

Is continuous possible top-\(k\) membership in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?
Is the complement of continuous necessary top-\(k\) membership in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite lists of voters under plurality, possible top-\(k\) membership is \(\mathrm{NP}\)-complete and necessary membership is \(\mathrm{coNP}\)-complete; possible membership is also \(\mathrm{W}[2]\)-hard parameterized by \(k\). [Imber and Kimelfeld](https://arxiv.org/html/2002.09212)
No result settling these exact mass-completion problems was located in the literature search.

Result

Both decision problems are \(\mathrm{NP}\)-complete when \(k\) is part of the input. Consequently, continuous necessary top-\(k\) membership is \(\mathrm{coNP}\)-complete.

The hardness holds even when every mass is dyadic, \(\tau=O(m)\), and the target has a fixed positive score in every completion.

The constructions adapt the source problems used in [Imber and Kimelfeld, Theorems 2 and 9](https://arxiv.org/html/2002.09212). The proofs below explicitly handle divisible mass, normalization, and distinct support types.

1. Representing and merging support types

For a nonempty set \(A\subseteq C\), define the strict partial order \(P(A)\) by placing every member of \(A\) above every member of \(C\setminus A\), with no comparisons within either set.

Its possible first candidates are exactly \(A\): a member of \(A\) can be placed first, whereas every candidate outside \(A\) has a predecessor. Thus each row specified below by an allowed set \(A\) is realizable by an explicitly represented partial order containing at most \(m^2\) comparisons.

We will initially describe some constructions using repeated rows. These can be merged without changing the attainable score vectors.

Indeed, suppose rows with the same allowed set \(A\) have masses \(\nu_1,\ldots,\nu_\ell\), and let \(\nu=\sum_i\nu_i\). Their allocations can be summed to obtain an allocation of the merged row. Conversely, a merged allocation \(y_a\), satisfying \(\sum_{a\in A}y_a=\nu\), can be refined by setting \(x_{i,a}=(\nu_i/\nu)y_a\). This refinement preserves every candidate’s total score.

Because all constructed orders are \(P(A)\), merging equal allowed sets produces a list of distinct partial-order types. Merging dyadic masses preserves dyadicity and positivity.

2. Linear programming, running times, and membership in \(\mathrm{NP}\)

Write \(c=c^\star\), and let \(R=C\setminus\{c\}\). A rival \(a\) precedes \(c\) precisely when either:

  • \(a\succ_{\mathrm{tie}}c\) and \(s_x(a)\geq s_x(c)\); or
  • \(c\succ_{\mathrm{tie}}a\) and \(s_x(a)>s_x(c)\).

The mass-completion constraints are rational linear constraints with \(E=\sum_t|A_t|\leq m\tau\) allocation variables.

2.1 Possible membership

Enumerate every set \(B\subseteq R\) of size \(k-1\). Treat \(B\) as the rivals permitted to precede \(c\), and require every rival outside \(B\) to follow \(c\):

  • for \(a\in R\setminus B\) with \(a\succ_{\mathrm{tie}}c\), require \(s_x(c)-s_x(a)>0\);
  • for \(a\in R\setminus B\) with \(c\succ_{\mathrm{tie}}a\), require \(s_x(c)-s_x(a)\geq0\).

Some such system is feasible exactly when possible membership holds. For the forward direction, extend the set of rivals actually preceding \(c\) to a set of size \(k-1\). For the reverse direction, only members of \(B\) can precede \(c\).

To handle strict inequalities exactly, introduce \(0\leq\varepsilon\leq1\), replace each strict inequality by \(s_x(c)-s_x(a)\geq\varepsilon\), and maximize \(\varepsilon\).

The original system is feasible exactly when this linear program is feasible and its optimum is positive. A feasible point satisfying finitely many strict inequalities has a positive minimum slack. Conversely, positive \(\varepsilon\) implies all the required strict inequalities. If there are no strict inequalities, \(\varepsilon\) can be set to \(1\).

This gives running time

\(\displaystyle \binom{m-1}{k-1}\operatorname{poly}(m\tau+L).\)

For \(k=m\), the answer is always yes.

2.2 Complement of necessary membership

For \(k\leq m-1\), enumerate every set \(B\subseteq R\) of size \(k\), and require every member of \(B\) to precede \(c\):

  • if \(a\succ_{\mathrm{tie}}c\), require \(s_x(a)-s_x(c)\geq0\);
  • if \(c\succ_{\mathrm{tie}}a\), require \(s_x(a)-s_x(c)>0\).

Again, a common margin \(\varepsilon\) handles all strict inequalities. Some system is feasible exactly when a completion has at least \(k\) rivals preceding \(c\), equivalently \(r_x(c)>k\).

The running time is

\(\displaystyle \binom{m-1}{k}\operatorname{poly}(m\tau+L).\)

For \(k=m\), the answer is always no. In particular, both problems are polynomial-time solvable for every fixed \(k\), with bounds respectively \(m^{k-1}\operatorname{poly}(m\tau+L)\) and \(m^k\operatorname{poly}(m\tau+L)\).

2.3 Polynomial-size rational witnesses

Both problems belong to \(\mathrm{NP}\), despite allowing real allocations.

Each margin linear program has at most \(N=E+1\) variables. Its feasible region is closed and bounded: every allocation lies between \(0\) and its row mass, and \(\varepsilon\in[0,1]\). Whenever its optimum is positive, an optimal vertex exists.

All constraint coefficients are in \(\{0,1,-1\}\). Let \(Q\) be the product of the denominators of the input masses; its bit length is \(O(L)\). At a vertex, choose \(N\) linearly independent active constraints. Cramer’s rule, together with the determinant bound \(N^{N/2}\), shows that every coordinate has bit length \(O(L+N\log N)\).

Thus every yes-instance has a polynomial-size rational allocation witnessing the required rank. Exact rational arithmetic verifies its feasibility and rank in polynomial time.

3. Possible membership is \(\mathrm{NP}\)-hard

We reduce from Dominating Set: given an undirected graph \(G=(V,F)\), with \(n=|V|\geq1\), and a budget \(1\leq b\leq n\), decide whether there exists \(D\subseteq V\), \(|D|\leq b\), meeting every closed neighborhood \(N[u]\). This decision problem is \(\mathrm{NP}\)-complete.

3.1 Construction

Let \(C=V\cup\{c,d\}\), where \(c\) is the target. Choose \(M\) to be the smallest power of two satisfying \(M\geq2n+3\), and put \(w=1/M\).

Create the following rows:

| Allowed set | Mass | Number of rows |
|---|---:|---:|
| \(\{v\}\), for each \(v\in V\) | \(w\) | \(n\) |
| \(N[u]\), for each \(u\in V\) | \(w\) | \(n\) |
| \(\{c\}\) | \(w\) | \(1\) |
| \(\{d\}\) | \(1-(2n+1)w\) | \(1\) |

Every mass is positive and dyadic, and their sum is \(1\). The last mass is at least \(2w\).

Choose a tie order with \(d\succ_{\mathrm{tie}}c\succ_{\mathrm{tie}}v\) for every \(v\in V\), and set \(k=b+2\). Merge duplicate types as in Section 1.

3.2 Correctness

Every completion has \(s_x(c)=w\) and \(s_x(d)\geq2w\). Every graph candidate has its fixed baseline \(w\), plus whatever it receives from neighborhood rows.

Define \(D_x=\{v\in V:s_x(v)>w\}\). The tie order places \(c\) before every graph candidate whose score equals \(w\). Therefore

\(\displaystyle r_x(c)=2+|D_x|.\)

Moreover, \(D_x\) is a dominating set. For each \(u\), its neighborhood row distributes positive mass \(w\) among finitely many members of \(N[u]\). At least one member receives a positive allocation from that row and consequently belongs to \(D_x\). Hence \(D_x\cap N[u]\neq\varnothing\).

It follows that \(r_x(c)\leq b+2\) implies \(|D_x|\leq b\), giving a dominating set of the required size.

Conversely, suppose \(D\) is a dominating set with \(|D|\leq b\). For each \(u\), choose a member of \(D\cap N[u]\) and allocate its entire neighborhood-row mass there. Every vertex outside \(D\) retains score \(w\), so \(D_x\subseteq D\). Consequently \(r_x(c)\leq2+|D|\leq b+2\).

This proves the required equivalence.

3.3 Size and parameter

The output has \(m=n+2\), support size \(\tau\leq2n+2\), and masses with \(O(\log n)\) bits. Its explicit partial orders have polynomial total size, so this is a polynomial-time reduction.

Since \(k=b+2\), it also preserves the standard \(\mathrm{W}[2]\)-hardness of Dominating Set parameterized by its budget. Thus continuous possible membership remains \(\mathrm{W}[2]\)-hard parameterized by \(k\).

4. The complement of necessary membership is \(\mathrm{NP}\)-hard

We reduce from Exact Cover by 3-Sets, abbreviated X3C. Its input consists of a universe \(U\), \(|U|=3q\), \(q\geq1\), and a family \(\mathcal E\) of distinct three-element subsets of \(U\). The question is whether \(q\) members of \(\mathcal E\) partition \(U\). X3C is \(\mathrm{NP}\)-complete.

We may assume \(|\mathcal E|\geq q\) and every element occurs in some set. Violations are immediately recognizable no-instances and can be mapped to the fixed no-instance with two candidates, all mass forced to the target, and \(k=1\).

4.1 Construction

Use one candidate for each set in \(\mathcal E\), together with target \(c\) and padding candidate \(d\).

Choose \(M\) to be the smallest power of two satisfying \(M\geq3q+7\), and put \(w=1/M\). For each \(u\in U\), let \(A_u=\{e\in\mathcal E:u\in e\}\), which is nonempty.

Create these rows:

| Allowed set | Mass | Number of rows |
|---|---:|---:|
| \(A_u\), for each \(u\in U\) | \(w\) | \(3q\) |
| \(\{c\}\) | \(3w\) | \(1\) |
| \(\{d\}\) | \(1-(3q+3)w\) | \(1\) |

All masses are positive dyadic numbers summing to \(1\). The padding mass is at least \(4w\).

Place every set candidate before \(c\) in the tie order, and set \(k=q+1\). Merge duplicate types.

4.2 Saturation forces disjointness

Work with the unmerged rows, which attain exactly the same score vectors.

Every completion has \(s_x(c)=3w\) and \(s_x(d)\geq4w\). A set candidate \(e\) can receive mass only from the three element rows corresponding to its members. Each row has mass \(w\), so \(s_x(e)\leq3w\).

Equality holds only if all three of those rows allocate their entire masses to \(e\): three nonnegative summands, each at most \(w\), can sum to \(3w\) only when each equals \(w\).

Define \(Q_x=\{e\in\mathcal E:s_x(e)=3w\}\). Its sets are pairwise disjoint. If distinct \(e,f\in Q_x\) shared an element \(u\), the row for \(u\) would have to allocate mass \(w\) to each of them, exceeding its total mass \(w\).

Thus continuous splitting cannot create overlapping saturated candidates.

4.3 Correctness

A set candidate precedes \(c\) exactly when it belongs to \(Q_x\): its score cannot exceed \(3w\), and it wins the tie at \(3w\). Candidate \(d\) always precedes \(c\). Hence

\(\displaystyle r_x(c)=2+|Q_x|.\)

If \(r_x(c)>k=q+1\), then \(|Q_x|\geq q\). Choose \(q\) members of \(Q_x\). They are pairwise disjoint three-element subsets of the \(3q\)-element universe, so their union is all of \(U\). They form an exact cover.

Conversely, given an exact cover \(\mathcal Q\), allocate each element row entirely to its unique covering set. Every member of \(\mathcal Q\) receives score \(3w\), and every other set candidate receives score \(0\). Therefore \(r_x(c)=q+2>q+1=k\).

The constructed instance is a yes-instance of the complement of necessary membership exactly when the X3C instance has an exact cover.

4.4 Size

Writing \(h=|\mathcal E|\), the construction has \(m=h+2\) and \(\tau\leq3q+2\). Since \(h\geq q\), the support size is \(O(m)\). Every mass has \(O(\log q)\) bits, and all partial orders are explicitly constructible in polynomial time.

5. Classification

The rational-witness argument and the two reductions establish:

  • Continuous possible top-\(k\) membership is \(\mathrm{NP}\)-complete.
  • The complement of continuous necessary top-\(k\) membership is \(\mathrm{NP}\)-complete.
  • Continuous necessary top-\(k\) membership is therefore \(\mathrm{coNP}\)-complete.

These settle both target questions. Polynomial-time algorithms for the unrestricted problems would imply \(\mathrm{P}=\mathrm{NP}\).
