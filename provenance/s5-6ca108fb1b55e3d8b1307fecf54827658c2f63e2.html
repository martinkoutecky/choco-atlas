The continuous mirror question, as graded

Given a finite set of types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), rational initial opinions \(s_t\in[-1,1]\), confidence indices \(\alpha_t\in(0,1)\), and signed block-level trust coefficients \(w_{t,u}\), choose changes \(\delta_t\) satisfying \(-1\le s_t+\delta_t\le1\) and \(\sum_t\mu_t|\delta_t|\le B\). The expressed opinions \(z_t\) satisfy \(\left(\alpha_t+(1-\alpha_t)\sum_u\mu_u|w_{t,u}|\right)z_t=\alpha_t(s_t+\delta_t)+(1-\alpha_t)\sum_u\mu_u w_{t,u}z_u\). Find a feasible \(\delta\) maximizing the mean equilibrium opinion \(\sum_t\mu_tz_t\), and return the maximum value.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Inputs also include binary-rational internal opinions \(s_t\in[-1,1]\), fixed confidence indices \(\alpha_t\in(0,1)\), directed trust coefficients \(w_{t,u}\in\mathbb Q\), and budget \(B\in\mathbb Q_{\geq0}\). Zero trust coefficients mean absent interactions; within-type interactions are allowed.
Choose one real change \(\delta_t\) for each entire type, satisfying \(-1\leq s_t+\delta_t\leq1\) and \(\sum_{t\in T}\mu_t|\delta_t|\leq B\).
The equilibrium expressed opinions are defined by \(\left(\alpha_t+(1-\alpha_t)\sum_{u\in T}\mu_u|w_{t,u}|\right)z_t=\alpha_t(s_t+\delta_t)+(1-\alpha_t)\sum_{u\in T}\mu_uw_{t,u}z_u\) for every \(t\in T\).
The optimization problem returns a maximizing feasible change vector and the exact maximum of \(\sum_{t\in T}\mu_tz_t\); any maximizer is acceptable. Let \(L\) be the total binary input length and \(m\) the number of nonzero trust coefficients; express running times in \(m,\tau,L\).

Is this exact mass-based opinion maximization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents with fixed confidence indices, signed trust, bounded internal opinions, and an unweighted absolute-change budget, an exact polynomial-time optimization algorithm is known ([He et al.](https://arxiv.org/abs/2103.05835)).
No result settling exactly the support-encoded mass problem above was identified in the literature search.

Modeling choices made when packaging the task

  • Trust coefficients were not assigned an encoding or magnitude domain: use arbitrary binary rationals, since the general network definition imposes no magnitude bound.
  • The budget domain was unspecified: use a nonnegative binary rational, including zero.
  • Within-type trust was unspecified: allow it as interaction among members of the same positive-mass block.
  • Confidence indices are fixed input data throughout the intervention, consistent with the fixed-confidence setting.
  • Changes are real and uniform within each type; require exact optimization and allow any maximizer.
  • Define the otherwise unspecified size parameter m as the number of nonzero directed trust coefficients and L as total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Answer and encoding convention

The problem is solvable exactly in polynomial time. The equilibrium objective is linear in the changes, and the mass-weighted budget reduces the optimization to fractional knapsack.

I use the standard binary-input interpretation: the fixed confidence indices \(\alpha_t\) are rational numbers whose encodings count toward \(L\). Here “fixed” means that they are not decision variables. If arbitrary unencoded real confidence indices were intended, an exact bit-complexity question would require an additional representation convention. The structural arguments below hold for all real \(\alpha_t\in(0,1)\).

2. The equilibrium exists uniquely

Index the support by \(\{1,\ldots,\tau\}\). Write \(\boldsymbol{\mu}=(\mu_t)_t\), \(D=\operatorname{diag}(\alpha_t)\), and define

\(A_{t,u}=\mathbf{1}_{t=u}\left(\alpha_t+(1-\alpha_t)\sum_v\mu_v|w_{t,v}|\right)-(1-\alpha_t)\mu_u w_{t,u}.\)

The equilibrium equations are precisely

\(Az=D(s+\delta).\)

For each row, including its within-type interaction,

\(A_{t,t}=\alpha_t+(1-\alpha_t)\left(\sum_{u\ne t}\mu_u|w_{t,u}|+\mu_t(|w_{t,t}|-w_{t,t})\right)>0.\)

Consequently,

\(A_{t,t}-\sum_{u\ne t}|A_{t,u}|=\alpha_t+(1-\alpha_t)\mu_t(|w_{t,t}|-w_{t,t})>0.\)

Thus \(A\) is strictly diagonally dominant. To verify nonsingularity directly, suppose \(Av=0\) with \(v\ne0\), and choose \(t\) maximizing \(|v_t|\). Then

\(A_{t,t}|v_t|=\left|\sum_{u\ne t}A_{t,u}v_u\right|\leq\sum_{u\ne t}|A_{t,u}||v_t|<A_{t,t}|v_t|,\)

a contradiction. Therefore every change vector determines exactly one equilibrium.

3. Compute the linear objective coefficients

Solve the single transpose system

\(A^{\mathsf T}y=\boldsymbol{\mu},\)

and define \(c=Dy\). Since \(A\) is nonsingular, this system has a unique solution. The objective becomes

\(\boldsymbol{\mu}^{\mathsf T}z=y^{\mathsf T}Az=y^{\mathsf T}D(s+\delta)=c^{\mathsf T}s+\sum_t c_t\delta_t.\)

Under the rational encoding convention, \(y\) and \(c\) are rational and can be computed exactly. Signed trust can produce negative \(c_t\); the algorithm handles either sign.

If \(c_t\delta_t<0\), replacing \(\delta_t\) by zero increases the objective and decreases expenditure. This replacement preserves the opinion bound because \(s_t\in[-1,1]\). If \(c_t=0\), setting \(\delta_t=0\) preserves the objective and decreases expenditure.

Hence an optimum exists with changes only in the improving direction. For each \(t\) with \(c_t\ne0\), define

\(U_t=\begin{cases}1-s_t,&c_t>0,\\1+s_t,&c_t<0,\end{cases}\qquad C_t=\mu_tU_t,\qquad \rho_t=\dfrac{|c_t|}{\mu_t}.\)

Here \(C_t\) is the maximum useful expenditure on type \(t\), and \(\rho_t\) is its objective gain per unit expenditure.

Setting \(b_t=\mu_t|\delta_t|\) gives the equivalent optimization problem

\(\displaystyle \max\sum_{t:c_t\ne0}\rho_tb_t\quad\text{subject to}\quad 0\leq b_t\leq C_t,\qquad\sum_t b_t\leq B.\)

The equivalence is exact: an expenditure vector determines the feasible changes

\(\delta_t=\operatorname{sgn}(c_t)b_t/\mu_t\)

for \(c_t\ne0\), with zero changes on the remaining types.

4. An exact greedy algorithm and its proof

List the types with nonzero coefficients as \(t_1,\ldots,t_q\), ordered so that

\(\rho_{t_1}\geq\cdots\geq\rho_{t_q}>0.\)

Starting with remaining budget \(R=B\), successively set

\(b^*_{t_j}=\min(C_{t_j},R),\qquad R\leftarrow R-b^*_{t_j}.\)

Ties may be broken arbitrarily. If \(q=0\), return \(\delta^*=0\).

To prove optimality when \(q>0\), abbreviate the ordered quantities by \(b_j,C_j,\rho_j\). For any feasible expenditure vector, its prefix expenditures satisfy

\(P_j:=\sum_{i=1}^j b_i\leq\min\left(B,\sum_{i=1}^j C_i\right).\)

The greedy vector attains equality for every prefix:

\(P_j^*=\min\left(B,\sum_{i=1}^j C_i\right).\)

This follows inductively: at each step, greedy fills the next capacity or exhausts the remaining budget.

The telescoping identity

\(\displaystyle \sum_{j=1}^q\rho_jb_j=\rho_qP_q+\sum_{j=1}^{q-1}(\rho_j-\rho_{j+1})P_j\)

expresses the objective as a linear combination of prefix expenditures with nonnegative coefficients. Since \(P_j\leq P_j^*\) for every \(j\), every feasible vector has objective at most the greedy vector’s objective.

Therefore the returned changes are globally optimal. The exact maximum is

\(\displaystyle V^*=c^{\mathsf T}s+\sum_{j=1}^q\rho_{t_j}b^*_{t_j}.\)

This also covers zero budget, zero capacities, and budgets exceeding all useful expenditure.

5. Running time and exact bit complexity

Matrix construction uses \(O(m+\tau^2)\) arithmetic operations. One exact linear solve uses \(O(\tau^3)\) arithmetic operations; sorting and allocation use \(O(\tau\log(\tau+1))\). Thus the arithmetic-operation count is

\(O\!\left(m+\tau^3+\tau\log(\tau+1)\right).\)

Here is an explicit polynomial bit bound.

Let \(Q\) be the product of all denominators in the rational input. Its bit length is \(O(L)\). Each entry of \(A\) is a sum of products involving at most three input rationals, so

\(H=Q^3A^{\mathsf T},\qquad r=Q^3\boldsymbol{\mu}\)

are integral. Their entries have \(O(L)\) bits: input trust magnitudes are at most \(2^{O(L)}\), while \(\sum_t\mu_t=1\).

Every leading principal submatrix of \(A\) is strictly diagonally dominant, because restricting a row only decreases its off-diagonal absolute sum. Therefore all leading principal minors of \(H\) are nonzero.

Apply [Bareiss’s fraction-free elimination](https://www.ams.org/mcom/1968-22-103/S0025-5718-1968-0226829-0/S0025-5718-1968-0226829-0.pdf) to the augmented integer system \([H\mid r]\). With nonzero leading principal minors, the divisions are exact and the stored entries are minors of the original augmented matrix. Hadamard’s determinant bound consequently gives an intermediate bit-length bound

\(K=O\!\left(\tau\bigl(L+\log(\tau+1)\bigr)\right).\)

The solve, including back substitution, can retain this bound. Indeed, if \(d=\det H\), Cramer’s rule shows that \(v=dy\) is an integer vector whose entries are determinants with \(O(K)\) bits. Back substitution for \(v\) uses exact integer divisions and products of these bounded integers.

The subsequent arithmetic also has polynomially bounded size:

  • All capacities, budget residuals, and expenditures have denominators dividing \(Q^2\).
  • Each returned change has denominator dividing \(Q^2p_t\), where \(p_t\) is the input numerator of \(\mu_t\).
  • The coefficients \(c_t\) have a common denominator dividing \(dQ\). Hence the final objective has a common denominator dividing \(dQ^3\prod_t p_t\), whose bit length is \(O(K)\), since the numerator encodings collectively have length at most \(L\).

Exact comparisons and arithmetic therefore involve \(O(K)\)-bit integers. Using schoolbook integer arithmetic gives the conservative bit-operation bound

\(O\!\left(\bigl(m+\tau^3+\tau\log(\tau+1)\bigr)\tau^2\bigl(L+\log(\tau+1)\bigr)^2\right).\)

Thus both an exact maximizing change vector and the exact maximum are computable in polynomial time in \(m,\tau,L\), directly from the support representation.
