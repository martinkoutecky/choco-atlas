The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), integer voting weights \(w_t\), a fixed finite affiliation set \(\mathcal{K}\), nonempty memberships \(A_t\subseteq\mathcal{K}\), and a rational quota fraction \(\theta\in(0,1)\), let \(\bar w=\sum_t\mu_t w_t\) and \(Q=\theta\bar w\). For each admissible scale \(N\) with \(N\mu_t\) and \(NQ\) integral, form the weighted-majority game with \(N\mu_t\) delegates of type \(t\), quota \(NQ\), and affiliation coalitions containing exactly the delegates whose type belongs to that affiliation. Assuming \(Q\) is not an endpoint \(B_R\) or \(B_R+\Delta_{k,R}\) for any relevant \(t,k,R\), determine and compute the exact limit, for each type \(t\), of the sum of its delegates’ configuration indices as \(N\to\infty\) through admissible scales.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types. Each type has a binary encoded weight \(w_t\in\mathbb Z_{\geq0}\) and nonempty membership \(A_t\subseteq\mathcal K\). The affiliation set \(\mathcal K\) is fixed, with \(m=|\mathcal K|\); the sets \(D_k=\{t:k\in A_t\}\) must be nonempty and pairwise distinct. Let \(L\) be the total input bit length.
Given binary rational \(\theta\in(0,1)\), require \(\bar w=\sum_t\mu_tw_t>0\) and set \(Q=\theta\bar w\). For every positive integer \(N\) with all \(N\mu_t\) and \(NQ\) integral, let \(P_N\) contain \(N\mu_t\) delegates of type \(t\), and let \(C_k^N\) contain precisely the delegates with \(k\in A_t\).
Write \(f_N(S)=\mathbf1\{\sum_{i\in S}w_{t(i)}\geq NQ\}\). For a delegate \(i\) of type \(t\), define its configuration index by
\(\Phi_i^N=\sum_{k\in A_t}\sum_{R\subseteq\mathcal K\setminus A_t}\sum_{U\subseteq C_k^N\setminus\{i\}}\frac{|R|!(m-|R|-1)!}{m!}\frac{|U|!(|C_k^N|-|U|-1)!}{|C_k^N|!}\bigl[f_N(U\cup S_R^N\cup\{i\})-f_N(U\cup S_R^N)\bigr]\), where \(S_R^N=\bigcup_{\ell\in R}C_\ell^N\).
Different pairs \((R,U)\) are separate summands even when their unions coincide; weights in a union are counted only once. No further normalization is applied.
For \(R\subseteq\mathcal K\setminus A_t\), define \(D_R=\{s:A_s\cap R\neq\varnothing\}\), \(B_R=\sum_{s\in D_R}\mu_sw_s\), and \(\Delta_{k,R}=\sum_{s\in D_k\setminus D_R}\mu_sw_s\). Promise \(Q\notin\{B_R,B_R+\Delta_{k,R}\}\) for every \(t\in T\), \(k\in A_t\), and such \(R\).

Do all limits \(F_t=\lim_{N\to\infty}\sum_{i\in P_N:t(i)=t}\Phi_i^N\), through admissible scales, exist, and is their exact computation polynomial-time or NP-hard? State running times in \(m,\tau,L\), treating \(m\) as fixed.

For finite societies, a [generating-function construction](https://arxiv.org/pdf/1507.00216) computes the configuration index exactly; the stated result supplies no polynomial bound in binary input length.

1. Result

All the limits exist. Their exact computation is polynomial-time for fixed \(m\).

More precisely, let
\(\alpha_m(r)=r!(m-r-1)!/m!\).
Then, for every type \(t\),

\[ F_t = \mu_t w_t \sum_{k\in A_t} \sum_{\substack{R\subseteq\mathcal K\setminus A_t\\ B_R<Q<B_R+\Delta_{k,R}}} \frac{\alpha_m(|R|)}{\Delta_{k,R}}. \tag{1} \]

Every denominator appearing in this sum is positive. An empty sum is zero.

Below is a proof, including the lattice issue caused by integer weights, followed by an exact algorithm and its bit complexity.

2. An exact integral representation

Fix \(t\), \(k\in A_t\), \(R\subseteq\mathcal K\setminus A_t\), and a delegate \(i\) of type \(t\). Write \(n=|C_k^N|\).

The elementary beta-integral identity gives

\[ \frac{|U|!(n-|U|-1)!}{n!} = \int_0^1 p^{|U|}(1-p)^{n-1-|U|}\,dp. \]

Consequently, the inner sum in the definition of \(\Phi_i^N\) equals the integral, over \(p\in[0,1]\), of the expected marginal contribution when every delegate in \(C_k^N\setminus\{i\}\) is independently selected with probability \(p\).

Delegates in \(C_k^N\cap S_R^N\) have no effect on that marginal contribution: their weights are already included in the union. Summing over their independent selections contributes a factor of one.

Thus only delegates whose types belong to

\[ E_{k,R}=D_k\setminus D_R \]

remain random. Since \(A_t\cap R=\varnothing\), type \(t\) belongs to \(E_{k,R}\), and \(i\notin S_R^N\).

Let \(X_N(p)\) be the total weight of the independently selected delegates in this active set, excluding \(i\). The weight already supplied by \(S_R^N\) is exactly \(NB_R\). Hence the inner sum is exactly

\[ I_{t,k,R}^{N} = \int_0^1 \Pr\!\left\{ N(Q-B_R)-w_t \leq X_N(p) < N(Q-B_R) \right\}\,dp. \tag{2} \]

This identity preserves all summands in the question, including different pairs whose unions coincide.

If \(Q<B_R\), the baseline already wins, so \(I_{t,k,R}^{N}=0\). If \(Q>B_R+\Delta_{k,R}\), even the entire active set cannot reach the quota, so again \(I_{t,k,R}^{N}=0\).

By the promise, the only remaining case is

\[ B_R<Q<B_R+\Delta_{k,R}. \tag{3} \]

If \(w_t=0\), every marginal contribution is zero. It therefore remains to analyze (2) when \(w_t>0\) and (3) holds.

3. The interior asymptotic, including lattice effects

We prove the asymptotic needed for each fixed pair.

Fix an active set \(E\) containing \(t\), and put

\[ w=w_t>0,\qquad \Delta=\sum_{s\in E}\mu_s w_s,\qquad V=\sum_{s\in E}\mu_s w_s^2. \]

Assume \(0<q<\Delta\). For each admissible \(N\), let \(X_N(p)\) select independently, with probability \(p\), each of the \(N\mu_s\) delegates of type \(s\in E\), except for one designated delegate of type \(t\). Suppose also that \(Nq\) is integral.

We claim that

\[ \lim_{N\to\infty} N\int_0^1 \Pr\{Nq-w\leq X_N(p)<Nq\}\,dp = \frac{w}{\Delta}. \tag{4} \]

All limits and estimates below are through the admissible scales.

3.1 A uniform local estimate

Ignore zero-weight types and define

\[ g=\gcd\{w_s:s\in E,\ w_s>0\}. \]

In particular, \(g\mid w\), and \(X_N(p)\) takes values in \(g\mathbb Z\). Its mean and variance are

\[ M_N(p)=p(N\Delta-w),\qquad \sigma_N^2(p)=p(1-p)(NV-w^2). \tag{5} \]

For any fixed closed interval \(J\subset(0,1)\), uniformly for \(p\in J\) and \(z\in g\mathbb Z\),

\[ \Pr\{X_N(p)=z\} = \frac{g}{\sqrt{2\pi}\,\sigma_N(p)} \exp\!\left( -\frac{(z-M_N(p))^2}{2\sigma_N^2(p)} \right) + O(N^{-1}). \tag{6} \]

Here and below, constants may depend on the fixed society and on \(J\).

For completeness, this estimate follows directly from Fourier inversion. Set \(b_s=w_s/g\) for the positive-weight types and \(Y_N=X_N/g\). Its characteristic function is

\[ \varphi_N(u) = \prod_s (1-p+pe^{iu b_s})^{N\mu_s-\mathbf1\{s=t\}}. \]

The integers \(b_s\) have greatest common divisor one. Also,

\[ |1-p+pe^{iu b_s}|^2 = 1-4p(1-p)\sin^2(ub_s/2). \]

Therefore, on every compact subset of \([-\pi,\pi]\) avoiding zero, the product is exponentially small in \(N\), uniformly for \(p\in J\). Indeed, all factors can have modulus one simultaneously only when \(ub_s\in2\pi\mathbb Z\) for every \(s\); the greatest-common-divisor condition then forces \(u\in2\pi\mathbb Z\).

Near zero, the centered logarithm satisfies

\[ \log\!\left(e^{-iu\mathbb EY_N}\varphi_N(u)\right) = -\frac{\operatorname{Var}(Y_N)}2u^2 + O(N|u|^3), \]

uniformly for \(p\in J\). The variance is bounded above and below by positive constants times \(N\). Taking a sufficiently small fixed neighborhood of zero, the difference between the centered characteristic function and its Gaussian approximation is consequently bounded by

\[ CN|u|^3e^{-cNu^2}. \]

Its integral is \(O(N^{-1})\). The remaining characteristic-function integral and the omitted Gaussian tails are exponentially small. Fourier inversion now gives (6), uniformly in the lattice location \(z\).

3.2 Concentration confines the integral

Let \(p_*=q/\Delta\in(0,1)\), and define

\[ W_N=\{p\in[0,1]:|p-p_*|\leq N^{-2/5}\}. \]

For \(p\notin W_N\), every value in the pivotal interval
\([Nq-w,Nq)\) lies at distance at least

\[ \Delta N^{3/5}-2w \]

from \(M_N(p)\). For sufficiently large \(N\), this is at least
\(\Delta N^{3/5}/2\).

Hoeffding’s inequality applies because the summands are independent and a delegate of type \(s\) contributes a variable in \([0,w_s]\). The sum of their squared ranges is \(NV-w^2\). It follows that

\[ \Pr\{Nq-w\leq X_N(p)<Nq\} \leq 2e^{-cN^{1/5}} \qquad(p\notin W_N). \tag{7} \]

Thus the integral outside \(W_N\) is \(o(N^{-1})\).

3.3 Integrating the local estimate

For all sufficiently large \(N\), \(W_N\) lies inside a fixed closed interval \(J\subset(0,1)\).

Because \(Nq\) is integral and \(g\mid w\), the interval

\[ [Nq-w,Nq)\cap\mathbb Z \]

contains exactly \(w/g\) elements of \(g\mathbb Z\), independently of the residue of \(Nq\) modulo \(g\).

For any such lattice value \(z_N\), we have \(z_N=Nq+O(1)\). Write

\[ K_N(p,z_N) = \frac{1}{\sqrt{2\pi}\,\sigma_N(p)} \exp\!\left( -\frac{(z_N-M_N(p))^2}{2\sigma_N^2(p)} \right). \]

We next show, uniformly over these finitely many possible offsets, that

\[ N\int_{W_N}K_N(p,z_N)\,dp \longrightarrow \frac1\Delta. \tag{8} \]

Substitute \(p=p_*+x/\sqrt N\). For each fixed \(x\),

\[ \frac{\sigma_N^2(p)}N \longrightarrow v_*=p_*(1-p_*)V>0, \]

and

\[ \frac{z_N-M_N(p)}{\sqrt N} \longrightarrow -\Delta x. \]

The transformed domain is \(|x|\leq N^{1/10}\). Moreover, throughout this domain, \(\sigma_N^2(p)\) lies between positive constants times \(N\), and

\[ z_N-M_N(p)=-\Delta\sqrt N\,x+O(1). \]

These facts bound the transformed integrand by \(Ce^{-cx^2}\), uniformly in \(N\) and in the bounded offset of \(z_N\). Dominated convergence therefore gives

\[ \lim_{N\to\infty} N\int_{W_N}K_N(p,z_N)\,dp = \frac1{\sqrt{2\pi v_*}} \int_{\mathbb R} e^{-\Delta^2x^2/(2v_*)}\,dx = \frac1\Delta. \]

Finally, integrating the error in (6) over \(W_N\) gives

\[ O(N^{-1})\,|W_N| = O(N^{-7/5}) = o(N^{-1}). \]

There are exactly \(w/g\) contributing lattice values, each with the factor \(g\) in (6). Combining (7) and (8) proves

\[ N\int_0^1 \Pr\{Nq-w\leq X_N(p)<Nq\}\,dp \longrightarrow \frac{w}{g}\frac{g}{\Delta} = \frac{w}{\Delta}, \]

which is (4).

4. Existence and the explicit formula

Apply (4) to each pair satisfying (3), with

\[ q=Q-B_R,\qquad E=D_k\setminus D_R. \]

The required integrality holds: \(NQ\) is integral by admissibility, and

\[ NB_R=\sum_{s\in D_R}(N\mu_s)w_s \]

is integral as well. Thus \(Nq\) is integral.

We obtain

\[ N I_{t,k,R}^{N} \longrightarrow \frac{w_t}{\Delta_{k,R}} \]

for an interior pair. For every other pair, its contribution is identically zero, as established in Section 2.

All delegates of type \(t\) have the same index, and their number is \(N\mu_t\). Hence

\[ \sum_{i:t(i)=t}\Phi_i^N = \mu_t \sum_{k\in A_t} \sum_{R\subseteq\mathcal K\setminus A_t} \alpha_m(|R|)\,N I_{t,k,R}^{N}. \]

This is a finite sum. Taking its limit proves (1).

There are infinitely many admissible scales: every multiple of a common denominator of the rational numbers \(\mu_t\) and \(Q\) is admissible. The estimates above hold along all sufficiently large admissible scales, so no subsequence choice is involved.

A normalization check

The formula also gives

\[ F_t\geq0,\qquad \sum_{t\in T}F_t=1. \tag{9} \]

To verify the second identity, fix \(k\) and \(R\subseteq\mathcal K\setminus\{k\}\). The eligible types in (1) are precisely \(D_k\setminus D_R\). Their weight masses sum to \(\Delta_{k,R}\). Therefore, when \(B_R<Q<B_R+\Delta_{k,R}\), their aggregate contribution for this pair is \(\alpha_m(|R|)\).

Define the affiliation-level game

\[ v(R)=\mathbf1\{B_R\geq Q\}. \]

If \(\Delta_{k,R}>0\), some positive-weight eligible type exists, so the promise excludes both endpoint equalities. Consequently,

\[ \mathbf1\{B_R<Q<B_R+\Delta_{k,R}\} = v(R\cup\{k\})-v(R). \]

If \(\Delta_{k,R}=0\), both sides are zero.

In a uniformly random permutation of the \(m\) affiliations, the probability that exactly \(R\) precedes \(k\) is \(\alpha_m(|R|)\). Along each permutation, these marginal differences telescope to

\[ v(\mathcal K)-v(\varnothing)=1, \]

because \(0<Q<\bar w\). Summing proves (9). No additional normalization is needed.

5. Exact computation and running time

The following algorithm computes (1) entirely from the support.

Write \(\theta=u/v\), with positive integers \(u<v\). Let \(H\) be the product of the denominators of the masses, and define integers

\[ h_t=H\mu_tw_t,\qquad h=\sum_t h_t. \]

For every \(R\subseteq\mathcal K\) and every \(k\notin R\), compute

\[ b_R=\sum_{s\in D_R}h_s,\qquad d_{k,R}=\sum_{s\in D_k\setminus D_R}h_s. \]

The interior test is the exact integer comparison

\[ vb_R<uh<v(b_R+d_{k,R}). \tag{10} \]

Also, whenever this test holds,

\[ \frac{\mu_tw_t}{\Delta_{k,R}}=\frac{h_t}{d_{k,R}}. \]

There are

\[ E=m2^{m-1} \]

pairs \((k,R)\) with \(k\notin R\). Computing their sums and then evaluating the eligible terms for every type takes \(O(\tau m2^m)\) integer arithmetic operations.

To bound bit lengths explicitly, let

\[ G=\prod_{\substack{k\notin R\\d_{k,R}>0}}d_{k,R}, \qquad D=m!G, \]

with an empty product interpreted as one. An exact numerator for \(F_t\), over the common denominator \(D\), is

\[ h_t \sum_{\substack{k\in A_t,\ R\subseteq\mathcal K\setminus A_t\\ vb_R<uh<v(b_R+d_{k,R})}} |R|!(m-|R|-1)!\,\frac{G}{d_{k,R}}. \tag{11} \]

Every division in (11) is exact.

The integers \(H,h_t,h,b_R,d_{k,R}\) have \(O(L)\) bits. Indeed, \(H\) has at most the sum of the input denominator bit lengths, and

\[ h=H\bar w\leq H\max_t w_t. \]

Thus all integers used in (11) have at most

\[ B=O\!\left(EL+m\log(m+1)\right) \]

bits. Using elementary quadratic-time integer arithmetic, a conservative total bound is

\[ O\!\left( \tau m2^m \left[m2^mL+m\log(m+1)\right]^2 \right) \]

bit operations. The output fractions need not be reduced; reducing them also takes polynomial time.

For fixed \(m\), this becomes \(O(\tau L^2)\), and hence \(O(L^3)\) since \(\tau\leq L\). The output length is \(O(\tau B)\).

The [cited generating-function paper](https://arxiv.org/pdf/1507.00216) studies exact indices for finite games with coalition configurations. The algorithm above instead evaluates the proved support-level limit formula directly.

Thus the requested fixed-\(m\) problem is polynomial-time solvable. The displayed bound is exponential in \(m\); it does not settle complexity when \(m\) is variable.
