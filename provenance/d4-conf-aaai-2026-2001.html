The continuous mirror question, as graded

For each ranking \(t\), let \(p_t(c)\) denote the position of candidate \(c\). Because all positions are distinct, \(t\) recognizes a nonempty set \(X\) exactly when
\(\max_{c\in X}p_t(c)-\min_{c\in X}p_t(c)+1=|X|\).
Indeed, the interval between the two extreme positions contains exactly that many positions; equality means that every position in it belongs to \(X\).

Precompute the position tables. Scanning all candidates once per ranking computes the minimum and maximum positions for every part, using \(O(\tau m\log(m+1))\) bit operations.

Recognition masses can be compared exactly in polynomial time. Write \(\mu_t=a_t/q_t\) and \(\alpha=u/v\), with binary-encoded positive integer numerators and denominators. Set
\(D=v\prod_{t\in T}q_t\),
\(W_t=a_t(D/q_t)\), and \(A=u(D/v)\).
The integer \(D\) has \(O(L)\) bits. Since each mass and the threshold are at most one, \(W_t\) and \(A\) also have \(O(L)\) bits. For every part \(X_i\), the threshold condition is precisely
\(\sum_{t:\,t\text{ recognizes }X_i}W_t\geq A\).

Using schoolbook integer arithmetic, preprocessing takes \(O(L^3)\) bit operations, and verification thereafter takes \(O(\tau mL)\). Thus a conservative verification bound is \(O(L^3+\tau mL)\). The binary encodings of \(b\) and \(k\) require only comparisons; no iteration up to their numerical values is needed. This proves membership in \(\mathsf{NP}\).

\(2\cdot10+12\cdot9=128\).

Now merge voters with identical rankings. Let \(T\) contain precisely the distinct rankings, and give each ranking \(t\) mass
\(\mu_t=\sum_{j:\,v_j=t}\lambda_j\).
Finally, set \(\alpha=1/8=16/128\).

This produces a valid support representation: rankings are distinct, masses are positive, their sum is one, and \(\tau\leq14\). Every mass has a constant-length dyadic representation.

For any nonempty \(X\subseteq C\), merging preserves its total recognition weight:
\(r(X)=\sum_{j:\,v_j\text{ recognizes }X}\lambda_j\).
If at most one source voter recognizes \(X\), then
\(r(X)\leq10/128<16/128=\alpha\).
If at least two source voters recognize \(X\), then
\(r(X)\geq18/128>16/128=\alpha\).
Consequently,
\(r(X)\geq\alpha\)
holds if and only if at least two source voters recognize \(X\).

Candidate sets, size bounds, and part bounds agree, so the two instances have identical feasible partitions. In particular, recognizing voters may differ between parts in both formulations.
