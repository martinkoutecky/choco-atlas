The continuous mirror question, as graded

Given \(m\) identical machines, a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), processing times \(p_t\), and a per-machine polymatroid \(P_\rho\) induced by a repeated-job matroid, choose \(z_{it}\geq 0\) with \(\sum_i z_{it}=\mu_t\) and \((z_{it})_{t\in T}\in P_\rho\) for each machine; minimize \(\max_i\sum_t p_tz_{it}\).

Result

For the stated divisible-mass formulation, an exactly optimal schedule is computable in polynomial time. The key is that every machine has the same convex feasibility constraints.

Feasibility of equal division

Define
\[ z_{it}=\frac{\mu_t}{m} \qquad\text{for every machine }i\text{ and type }t. \]

These masses are nonnegative and satisfy
\[ \sum_{i=1}^{m}z_{it}=\mu_t. \]

To verify the matroid constraints, use the feasibility promise: let \(\widehat z\) be any feasible schedule. For every subset \(S\subseteq T\), each machine satisfies
\[ \sum_{t\in S}\widehat z_{it}\leq\rho(S). \]
Summing over machines and using the prescribed type totals gives
\[ \sum_{t\in S}\mu_t =\sum_{i=1}^{m}\sum_{t\in S}\widehat z_{it} \leq m\rho(S). \]
Consequently, for every machine \(i\),
\[ \sum_{t\in S}z_{it} =\frac{1}{m}\sum_{t\in S}\mu_t \leq\rho(S). \]
This holds for every subset \(S\), so \(z_i\in P_\rho\). Thus equal division is feasible. The algorithm does not need to know \(\widehat z\); its existence justifies feasibility of the explicit output.

Exact optimality

Let
\[ W=\sum_{t\in T}p_t\mu_t \]
be the total processing load. For any feasible schedule \(y\), conservation of each type implies
\[ \sum_{i=1}^{m}\sum_{t\in T}p_ty_{it} =\sum_{t\in T}p_t\mu_t=W. \]
The largest machine load is at least the average, hence
\[ C(y)\geq\frac{W}{m}. \]

In the equal-division schedule, every machine has load
\[ \sum_{t\in T}p_tz_{it} =\frac{1}{m}\sum_{t\in T}p_t\mu_t =\frac{W}{m}. \]
Therefore
\[ C(z)=\mathrm{OPT}=\frac{W}{m}. \]
Since \(m\geq1\), \(p_{\max}\geq0\), and \(N\geq1\), this also proves the requested guarantee:
\[ C(z)\leq\mathrm{OPT} +\left(1-\frac1m\right)\frac{p_{\max}}{N}. \]

Bit complexity and scope

Write each input mass as \(\mu_t=a_t/b_t\), with positive binary integers \(a_t,b_t\). Output
\[ z_{it}=\frac{a_t}{mb_t}. \]
Each output rational has bit length bounded by a constant times \(L+\log(m+1)\). Computing the denominators and writing the \(m\tau\) entries therefore takes polynomially many bit operations in \(m,\tau,L\), even if fractions are reduced to lowest terms.

The algorithm makes zero oracle calls and never expands the \(N\) jobs. Neither the matroid representation nor its integrality properties are needed beyond the promised common constraints.

The cited [indivisible-job result](https://arxiv.org/html/2608.13983v1#S4.SS1) concerns an additional restriction: whole jobs must be assigned to machines. In the formulation here, arbitrary division permits equal sharing and yields exact optimality.
