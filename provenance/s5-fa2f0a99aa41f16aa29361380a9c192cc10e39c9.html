The continuous mirror question, as graded

Given a finite type set \(T\), distinct house classes \(H=\{h_t:t\in T\}\), and positive rational masses \(\mu_t\) summing to \(1\), each member of type \(t\) has strict ranking \(\succ_t\) and owns one indivisible house of class \(h_t\), with supply \(q_{h_t}=\mu_t\). Find an assignment flow \(x_{t,h}\ge 0\) with \(\sum_h x_{t,h}=\mu_t\) and \(\sum_t x_{t,h}=q_h\), such that no positive-mass coalition can block it: a blocker chooses \(z_{t,h}\le x_{t,h}\) and reassignment masses \(y_{t,h,r}\ge 0\), where \(\sum_r y_{t,h,r}=z_{t,h}\), \(y_{t,h,r}>0\) only if \(r\succeq_t h\), \(\sum_{t,h}y_{t,h,r}\le\sum_{t:h_t=r}\sum_h z_{t,h}\) for every \(r\), and \(\sum_{t,h,r:\,r\succ_t h}y_{t,h,r}>0\). Is there an algorithm polynomial in \(|T|\) and the input bit length that computes such a flow?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
There are \(m=\tau\) distinct house classes \(H=\{h_t:t\in T\}\). Each member of type \(t\) privately owns one house of class \(h_t\), whose aggregate supply is \(q_{h_t}=\mu_t\), and has a strict linear order \(\succ_t\) on \(H\). All classes are acceptable; every member receives exactly one house, and there are no transfers.
An assignment is a flow \(x_{t,h}\geq0\) satisfying \(\sum_{h\in H}x_{t,h}=\mu_t\) and \(\sum_{t\in T}x_{t,h}=q_h\). Flow entries describe masses receiving individual houses.
A blocking coalition selects real masses \(0\leq z_{t,h}\leq x_{t,h}\) with \(\sum_{t,h}z_{t,h}>0\), and real reassignment masses \(y_{t,h,r}\geq0\), indexed by \(t\in T\) and \(h,r\in H\), satisfying:
\(\sum_r y_{t,h,r}=z_{t,h}\); \(y_{t,h,r}>0\) only when \(r\succeq_t h\), where \(\succeq_t\) includes equality;
\(\sum_{t,h}y_{t,h,r}\leq\sum_{t:h_t=r}\sum_h z_{t,h}\) for every \(r\in H\); and \(\sum_{t,h,r:\,r\succ_t h}y_{t,h,r}>0\).
Call a flow unblocked if no such coalition exists.

Can an unblocked rational assignment flow be computed on every instance in time polynomial in \(m,\tau,L\), or is this computational problem NP-hard?

For finite private-ownership economies, the outcomes of YRMH-IGYT coincide with the rectified, refined exclusion, and exclusion cores, and with the strong core whenever it is nonempty. [Zhang](https://arxiv.org/html/2005.09351v2)
For finite agents with fractional endowments and stochastic-dominance blocking, the strong core may be empty and the weak core is nonempty; that model does not allow the assignment-dependent selection of submasses defined here. [Yu and Zhang](https://arxiv.org/html/2508.11151v1)
No result settling this exact computational problem was identified in the literature search.

Modeling choices made when packaging the task

  • The ranking domain was unspecified: rankings are strict linear orders over all house classes, and all classes are acceptable, matching the full-assignment housing-market specialization.
  • The representation of the computed flow was unspecified: output entries are exact binary rationals; blocking masses range over nonnegative reals.
  • The interpretation of a fractional flow was unspecified: entries represent masses of members receiving individual houses, rather than lotteries evaluated by a representative type.
  • Set m equal to the number of house classes and tau equal to the positive-mass support size; both coincide here because the endowed classes are distinct.

Result

Existence can be decided in polynomial time, and the unique unblocked flow can be computed whenever it exists. However, some instances admit no unblocked flow, even with two types.

More precisely, run ordinary top trading cycles with one agent per type, ignoring the masses. Let \(\pi:T\to T\) be its output permutation, so type \(t\) receives class \(h_{\pi(t)}\). Then:

An unblocked assignment exists if and only if \(\mu_t=\mu_{\pi(t)}\) for every \(t\in T\). When it exists, it is unique: set \(x_{t,h_{\pi(t)}}=\mu_t\), with all other entries zero.

Thus the total search problem in the question is not always feasible. Both the version allowing a report of nonexistence and the search problem promised to have a solution are polynomial-time solvable.

The proof below applies directly to the stated blocking definition, including arbitrary real submasses.

1. Blocking is characterized by directed cycles

Identify each class \(h_s\) with its owning type \(s\).

For a feasible flow \(x\), define a directed multigraph \(G_x\) on vertex set \(T\). For every \(x_{t,h}>0\) and every class \(h_s\succeq_t h\), include an edge \(t\to s\), labelled by the original assignment class \(h\). Mark that edge strict when \(h_s\succ_t h\).

We first record an elementary fact.

Circulation fact. In a finite directed multigraph carrying a nonnegative flow with equal incoming and outgoing flow at every vertex, each positive-flow edge lies on a directed cycle.

Proof. Consider a positive-flow edge \(u\to v\). A self-loop already is a cycle. Otherwise, let \(R\) be the vertices reachable from \(v\) through positive-flow edges. If \(u\notin R\), no positive flow leaves \(R\), whereas positive flow enters \(R\) along \(u\to v\). This contradicts conservation summed over \(R\). Therefore a path from \(v\) to \(u\) exists; a simple such path together with \(u\to v\) gives the required cycle. \(\square\)

Lemma 1. A feasible flow \(x\) is blocked if and only if \(G_x\) contains a directed cycle with at least one strict edge.

Proof, cycle implies blocking. Take a simple directed cycle \(t_1\to t_2\to\cdots\to t_k\to t_1\), allowing a self-loop. Write \(t_{k+1}=t_1\), and let \(h_i\) be the label of its edge \(t_i\to t_{i+1}\).

By definition, \(x_{t_i,h_i}>0\) and \(h_{t_{i+1}}\succeq_{t_i}h_i\). Choose \(\varepsilon=\min_i x_{t_i,h_i}>0\). Select mass \(z_{t_i,h_i}=\varepsilon\) at every cycle vertex and reassign it by setting \(y_{t_i,h_i,h_{t_{i+1}}}=\varepsilon\). Set all other entries to zero.

Every participating type contributes mass \(\varepsilon\) of its owned class, and each such class is demanded in exactly that amount. Every selected member weakly improves. A strict edge gives strictly improving mass \(\varepsilon\). These masses therefore form a blocking coalition.

Proof, blocking implies a cycle. Let \(z,y\) witness blocking, and put \(Z_t=\sum_h z_{t,h}\). Regard each positive \(y_{t,h,h_s}\) as flow on the corresponding labelled edge \(t\to s\). Its outgoing flow at \(t\) is \(Z_t\). The house constraints give incoming flow at \(s\) at most \(Z_s\).

Total incoming flow equals total outgoing flow, both being \(\sum_t Z_t\). Consequently every one of these inequalities is an equality, so this edge flow is a circulation.

The strict-improvement requirement supplies a positive-flow strict edge. By the circulation fact, it lies on a directed cycle consisting of positive-flow edges. All those edges belong to \(G_x\), since positive \(y_{t,h,h_s}\) implies \(x_{t,h}>0\) and \(h_s\succeq_t h\). \(\square\)

2. Every unblocked flow assigns one class per type

Lemma 2. If \(x\) is unblocked, each row has exactly one positive entry.

Proof. Define another directed graph whose edge \(t\to s\) carries flow \(x_{t,h_s}\). Feasibility gives outgoing flow \(\mu_t\) and incoming flow \(q_{h_t}=\mu_t\) at vertex \(t\). Hence this is a circulation.

Suppose a row has positive entries \(x_{t,h_a}\) and \(x_{t,h_b}\) for distinct \(a,b\). Strict preferences allow us to name them so that \(h_a\succ_t h_b\).

The positive assignment edge \(t\to a\) lies on a cycle by the circulation fact. Thus, if \(a\ne t\), there is a simple path from \(a\) to \(t\) through positive assignment edges.

Every edge \(u\to v\) of that path belongs to \(G_x\), labelled by \(h_v\): its recipient can keep its original class \(h_v\). Meanwhile \(G_x\) contains the strict edge \(t\to a\) labelled by \(h_b\), because \(x_{t,h_b}>0\) and \(h_a\succ_t h_b\).

This strict edge and the path form a blocking cycle. If \(a=t\), the strict edge itself is a self-loop. Either case contradicts Lemma 1.

Thus every row has at most one positive entry. Its positive row sum \(\mu_t\) ensures exactly one. \(\square\)

Let \(\rho(t)\) denote the owner of the class assigned to type \(t\). Then \(x_{t,h_{\rho(t)}}=\mu_t\).

Every column has positive supply, so \(\rho:T\to T\) is surjective. Since its domain and codomain have the same finite size, it is a permutation. Each column therefore has exactly one contributing type, and feasibility becomes

\(\mu_t=\mu_{\rho(t)}\) for every \(t\in T\).

This proves that every unblocked flow is a permutation assignment preserving masses.

3. The only possible permutation is ordinary TTC

For any permutation \(\rho\), define \(G_\rho\) to contain \(t\to s\) exactly when \(h_s\succeq_t h_{\rho(t)}\), marking the edge strict when this preference is strict.

For a feasible permutation flow, this is precisely the graph of Lemma 1.

We recall the TTC construction. Initially all types are active. At each round:

  • Every active type points to the owner of its most-preferred class among active owners.
  • Execute every directed cycle, assigning each cycle type the class it points to.
  • Remove all cycle types and their owned classes.

A finite graph in which every vertex has one outgoing edge contains a cycle. Hence at least one type leaves each round. The algorithm terminates and yields a permutation \(\pi\); each executed cycle permutes exactly the classes owned by its vertices.

The classical strict-preference TTC characterization is discussed in [Zhang’s paper](https://arxiv.org/html/2005.09351v2). The following argument proves the graph property needed here directly.

Lemma 3. \(G_\rho\) has no directed cycle containing a strict edge if and only if \(\rho=\pi\).

Proof of necessity. Consider a first-round TTC cycle. Each type on it points to its globally most-preferred class. Consequently every cycle edge belongs to \(G_\rho\). If \(\rho\) differs from the TTC assignment at any cycle vertex, the corresponding edge is strict. The assumed absence of strict cycles therefore forces agreement at every vertex of every first-round cycle.

These assignments permute exactly the removed types’ owned classes. Because \(\rho\) is a permutation, it consequently maps the remaining types onto the remaining owners.

Proceed inductively. At a later round, earlier agreement ensures that each remaining type’s \(\rho\)-assigned class is still active. Its TTC choice is its most-preferred active class, so the edges of every current TTC cycle again belong to \(G_\rho\). Any disagreement would make one edge strict. Thus agreement is forced throughout that round. Induction proves \(\rho=\pi\).

Proof of sufficiency. Let \(d(t)\) be the round when TTC removes type \(t\). Consider any directed cycle in \(G_\pi\), and choose a vertex \(t\) with minimum removal round among its vertices. Let \(s\) be its successor on this directed cycle.

Since \(d(s)\geq d(t)\), class \(h_s\) was active when \(t\) departed. At that round, \(h_{\pi(t)}\) was \(t\)’s uniquely most-preferred active class. The edge condition \(h_s\succeq_t h_{\pi(t)}\) therefore forces \(s=\pi(t)\); this edge is not strict.

Furthermore, \(t\) and \(\pi(t)\) belong to the same executed TTC cycle, so \(d(s)=d(t)\). Apply the same reasoning to the successor edge from \(s\), and continue around the directed cycle. Every edge is an equality edge. Thus no directed cycle contains a strict edge. \(\square\)

4. Exact existence and uniqueness theorem

We can now prove the stated characterization.

If an unblocked flow exists, Lemma 2 makes it a permutation flow with permutation \(\rho\). Lemma 1 excludes strict directed cycles in \(G_\rho\), and Lemma 3 forces \(\rho=\pi\). Column feasibility then requires \(\mu_t=\mu_{\pi(t)}\) for every type.

Conversely, suppose these mass equalities hold. Set \(x^*_{t,h_{\pi(t)}}=\mu_t\), with every other entry zero. The row sums are correct. Since \(\pi\) is a permutation, column \(h_s\) receives exactly \(\mu_{\pi^{-1}(s)}=\mu_s=q_{h_s}\). Thus \(x^*\) is feasible.

Lemma 3 excludes strict cycles in its blocking graph, and Lemma 1 consequently proves it unblocked.

The necessity argument also proves uniqueness. In particular, existence of any real unblocked flow implies existence of this rational one. Equivalently, existence requires equal masses within every executed TTC cycle.

5. Nonexistence already occurs with two types

Take \(T=\{a,b\}\), masses \(\mu_a=\frac14\) and \(\mu_b=\frac34\), and preferences \(h_b\succ_a h_a\) and \(h_a\succ_b h_b\).

TTC exchanges the two classes, so \(\pi(a)=b\) and \(\pi(b)=a\). The required mass equality fails. Hence no unblocked flow exists.

The role of assignment-dependent submass selection is particularly visible in the feasible flow \(x_{a,h_b}=\frac14\), \(x_{b,h_a}=\frac14\), \(x_{b,h_b}=\frac12\). Select mass \(\frac14\) from type \(a\)’s recipients of \(h_b\), and mass \(\frac14\) from type \(b\)’s recipients of \(h_b\). Their endowments supply \(\frac14\) of each class. Give \(h_b\) back to the selected type-\(a\) members and give \(h_a\) to the selected type-\(b\) members. The former remain unchanged and the latter strictly improve, so this flow is blocked.

This uses selection by current assignment, whereas the [Yu–Zhang model](https://arxiv.org/html/2508.11151v1) defines coalition improvement through stochastic dominance of agents’ assignment vectors.

6. Polynomial-time algorithm and conclusion

The algorithm is:

  • Compute ordinary TTC on the types, obtaining \(\pi\).
  • Test whether \(\mu_t=\mu_{\pi(t)}\) for every type.
  • If any equality fails, report that no unblocked assignment exists. Otherwise output the unique flow described above.

There are at most \(\tau\) TTC rounds. Scanning all preference lists anew in every round already gives a polynomial bound, at most \(O(\tau^3)\) elementary operations because \(m=\tau\). Equality of binary-encoded rational masses can be checked by cross-multiplication of their encoded numerators and denominators, in time polynomial in \(L\). The output only copies input masses and writes zeros, so its encoding length is polynomial as well.

Thus existence belongs to \(\mathrm{P}\), and construction is polynomial-time whenever existence holds. Standard NP-hardness of the existence problem would imply \(\mathrm{P}=\mathrm{NP}\). The unconditional requirement to produce an unblocked flow on every instance fails because such a flow need not exist.
