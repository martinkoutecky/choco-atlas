The continuous mirror question, as graded

Given finite classes \(Q\), rational masses \(\lambda_q\) summing to \(1\), stubbornness values \(\alpha_q\), and a symmetric nonnegative interaction kernel \(K_{qr}\), choose belief-\(1\) masses \(\beta_q\in[0,\lambda_q]\) and ask whether \(\sum_q\beta_q\le(1-\epsilon)/2\) permits a finite sequence of best-response mass moves from the truthful state to an equilibrium with opinion-\(1\) mass greater than \(1/2\). For mass \(x_{q,b}\) of class \(q\) with belief \(b\) expressing opinion \(1\), let \(y_r=x_{r,0}+x_{r,1}\); the cost of opinion \(a\in\{0,1\}\) is \(c_{q,b}(a;x)=\alpha_q|a-b|+(1-\alpha_q)\sum_{r\in Q}K_{qr}(y_r\text{ if }a=0,\ \lambda_r-y_r\text{ if }a=1)\). A move shifts positive mass currently playing a strictly more costly opinion to the cheaper one; equilibrium means no positive mass can strictly lower its cost by switching.

Here \(\tau\) counts supported types, not possible types. Each type has rational stubbornness \(0<\alpha_q<1\); the input also specifies a symmetric nonnegative rational kernel \(K\), with diagonal entries allowed and no normalization. Let \(L\) be the total binary input length.
Choose real belief masses \(0\le\beta_q\le\lambda_q\), and put \(t_{q,1}=\beta_q\), \(t_{q,0}=\lambda_q-\beta_q\). Beliefs remain fixed throughout the dynamics.
A state specifies real masses \(0\le x_{q,b}\le t_{q,b}\) expressing opinion \(1\); the remaining \(t_{q,b}-x_{q,b}\) express opinion \(0\). Write \(y_q=x_{q,0}+x_{q,1}\). The truthful state has \(x_{q,0}=0\) and \(x_{q,1}=\beta_q\).
For \(a,b\in\{0,1\}\), the individual cost is \(c_{q,b}(a;x)=\alpha_q|a-b|+(1-\alpha_q)\sum_{r\in Q}K_{qr}\bigl((1-a)y_r+a(\lambda_r-y_r)\bigr)\).

An equilibrium has no positive mass expressing a strictly more costly opinion. The decision problem asks whether some \(\beta\) with \(\sum_q\beta_q\le(1-\epsilon)/2\) admits a finite sequence of these moves from the truthful state to an equilibrium with \(\sum_q y_q>1/2\).

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard, for each fixed rational \(0<\epsilon<133/155\)?

1. Result

The decision problem is \(\mathrm{NP}\text{-hard}\) for every fixed rational \(0<\epsilon<133/155\). In fact, the proof works for every fixed rational \(0<\epsilon<1\).

We give an independent reduction from PARTITION. It handles arbitrary real belief assignments and arbitrary partial moves. The constructed masses can all be dyadic rationals.

2. Strict-response thresholds

For each type, define

\(h_q=\alpha_q/(1-\alpha_q)>0\), and \(F_q(y)=\sum_r K_{qr}(2y_r-\lambda_r)\).

Direct subtraction of the specified costs gives

\(c_{q,b}(1;x)-c_{q,b}(0;x)=(1-\alpha_q)\bigl((1-2b)h_q-F_q(y)\bigr)\).

Consequently:

  • Belief-\(0\) mass can move from opinion \(0\) to opinion \(1\) exactly when \(F_q(y)>h_q\).
  • Belief-\(0\) mass at opinion \(0\) is stable when \(F_q(y)\le h_q\).
  • Belief-\(0\) mass at opinion \(1\) is stable when \(F_q(y)\ge h_q\).
  • Belief-\(1\) mass at opinion \(1\) is stable when \(F_q(y)\ge-h_q\).

These conditions use the state before the move, including its diagonal contribution, exactly as required by the problem.

3. The integer instance and numerical gaps

We use the standard \(\mathrm{NP}\)-complete problem PARTITION: given positive binary-encoded integers \(v_1,\ldots,v_n\), decide whether some subset sums to half their total. See [Karp, *Reducibility Among Combinatorial Problems*](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Let \(P=\sum_{j=1}^n v_j\). Form \(N=n+1\) positive integer weights by setting

\(w_j=2v_j\) for \(1\le j\le n\), and \(w_N=2P+1\).

Define

\(T=3P+1\), and \(W=\sum_{i=1}^N w_i=4P+1\).

A subset of the augmented weights sums to \(T\) if and only if the original PARTITION instance is positive. Indeed, the original augmented weights total \(2P<T\), so a subset summing to \(T\) must contain \(w_N\). Its other weights must then sum to \(P\), equivalently its original integers sum to \(P/2\).

Also,

\(W/T=(4P+1)/(3P+1)<4/3\).

Fix the problem’s belief budget

\(B=(1-\epsilon)/2\),

and define positive rationals

\(g=B\epsilon/(16(T+1))\), and \(c=(B-g)/T\).

Choose dyadic rationals \(d,a\) satisfying

\((1/2+g/2)/T<d<(1/2+g)/T\),

\(c<a<\min\{2c,d\}\).

These intervals are nonempty: \(c>0\), and \(dT>1/2>B-g=cT\). Polynomial-time choices are justified in Section 7.

We will use three numerical properties.

First, the budget distinguishes integer weights \(T\) and \(T+1\):

\(cT=B-g<B\),

\(c(T+1)-B=\bigl(B-g(T+1)\bigr)/T=B(1-\epsilon/16)/T>0\).

Second, total activated weight at most \(T-1\) cannot produce a majority:

\(d-c<(\epsilon/2+2g)/T\),

and therefore

\(B+(d-c)(T-1)<1/2+\bigl(2g(T-1)-\epsilon/2\bigr)/T<1/2\).

For the last inequality, observe that

\(2g(T-1)=B\epsilon(T-1)/(8(T+1))<\epsilon/16<\epsilon/2\).

Third, the constructed components leave positive mass for an isolated type:

Since \(g<B/16<1/32<1/4\),

\(dW<(1/2+g)(W/T)<(3/4)(4/3)=1\).

4. Construction of the society

Put

\(\ell=d-a>0\), \(u=2c-a>0\), and \(D=1+\ell/u>1\).

For each weight \(w_i\), create two types \(s_i,f_i\), with masses

\(\lambda_{s_i}=aw_i\), and \(\lambda_{f_i}=\ell w_i\).

Thus their combined mass is \(dw_i\).

Within this pair, set

\(K_{s_i s_i}=D\), \(K_{s_i f_i}=K_{f_i s_i}=1\), and \(K_{f_i f_i}=0\).

All interactions between different pairs are zero. For both types in pair \(i\), set

\(h_{s_i}=h_{f_i}=uw_i\),

by choosing

\(\alpha_{s_i}=\alpha_{f_i}=uw_i/(1+uw_i)\).

These stubbornness values are rational and strictly between \(0\) and \(1\).

Finally, add an isolated type \(z\), with

\(\lambda_z=1-dW>0\), \(\alpha_z=1/2\), and \(K_{zq}=K_{qz}=0\) for every type \(q\).

The kernel is symmetric and nonnegative. All masses are positive and sum to \(1\). The support has \(\tau=2N+1\) types.

For a state restricted to pair \(i\), write \(y_s=y_{s_i}\) and \(y_f=y_{f_i}\). Its fields are

\(F_{s_i}=D(2y_s-aw_i)+(2y_f-\ell w_i)\),

\(F_{f_i}=2y_s-aw_i\).

Because \(Du-\ell=u\) and \(a+u=2c\), these give the useful identities

\(F_{s_i}-h_{s_i}=2D(y_s-cw_i)+2y_f\),

\(F_{f_i}-h_{f_i}=2(y_s-cw_i)\).

The isolated type always remains truthful: with zero interactions, expressing one’s own belief is strictly cheaper. Hence \(y_z=\beta_z\) throughout every permitted sequence.

5. Soundness for arbitrary fractional assignments and moves

Fix any admissible real belief assignment and any finite permitted sequence starting from its truthful state. Define the initial belief-\(1\) mass in pair \(i\) by

\(b_i=\beta_{s_i}+\beta_{f_i}\).

Call pair \(i\) activated if, at some point in this sequence, a positive amount of its belief-\(0\) mass moves from opinion \(0\) to opinion \(1\).

First-move lemma

Every activated pair satisfies \(b_i>cw_i\).

To prove this, consider the state immediately before its first such move. Until then, its belief-\(0\) mass remains at opinion \(0\). Regardless of any moves by belief-\(1\) mass, we therefore have

\(y_s\le\beta_{s_i}\), and \(y_f\le\beta_{f_i}\).

If the first move occurs at \(f_i\), strict improvement and the field identity imply

\(y_s>cw_i\).

Thus \(b_i\ge\beta_{s_i}\ge y_s>cw_i\).

If it occurs at \(s_i\), strict improvement implies

\(y_s+y_f/D>cw_i\).

Since \(D>1\) and all masses are nonnegative,

\(b_i=\beta_{s_i}+\beta_{f_i}\ge y_s+y_f/D>cw_i\).

This proves the lemma. It does not restrict move sizes, move order, or subsequent reversals.

Bound on every state reached

Let \(A\) be the set of activated pairs and let

\(S=\sum_{i\in A}w_i\).

The first-move lemma and the belief budget imply

\(cS\le\sum_{i\in A}b_i\le\sum_q\beta_q\le B\).

Since \(c(T+1)>B\) and \(S\) is an integer, necessarily \(S\le T\).

An unactivated pair has no belief-\(0\) mass at opinion \(1\), so its opinion-\(1\) mass is at most \(b_i\). An activated pair has total mass \(dw_i\), so its opinion-\(1\) mass is at most \(dw_i\). Together with \(y_z=\beta_z\), this yields

\(\sum_q y_q\le\beta_z+\sum_{i\notin A}b_i+\sum_{i\in A}dw_i\),

\(=\sum_q\beta_q+\sum_{i\in A}(dw_i-b_i)\le B+(d-c)S\).

If \(S\le T-1\), Section 3 gives \(\sum_q y_q<1/2\). Therefore, any successful sequence must have \(S=T\).

Its activated pairs consequently identify a subset of the augmented integer weights summing exactly to \(T\). By Section 3, the original PARTITION instance is positive.

This establishes soundness even for reaching a majority state without requiring equilibrium.

6. Completeness and an explicit equilibrium

Suppose a subset \(I\) of augmented weights satisfies

\(\sum_{i\in I}w_i=T\).

Choose

\(\delta=\min\{(a-c)/2,\;g/(2T)\}>0\).

For each selected pair, assign

\(\beta_{s_i}=(c+\delta)w_i\), and \(\beta_{f_i}=0\).

Assign zero belief-\(1\) mass to every other type.

The assignment is admissible because \(c+\delta<a\). Its total belief-\(1\) mass is

\(\sum_q\beta_q=(c+\delta)T\le B-g/2<B\).

Starting from the truthful state, perform the following two moves in each selected pair.

Move at \(s_i\). Initially, \(y_s=(c+\delta)w_i\) and \(y_f=0\). Hence

\(F_{s_i}-h_{s_i}=2D\delta w_i>0\).

Transfer all its belief-\(0\) mass to opinion \(1\). This is a permitted positive move and leaves \(y_s=aw_i\).

Move at \(f_i\). Now

\(F_{f_i}-h_{f_i}=2(a-c)w_i>0\).

Transfer all its mass, which has belief \(0\), to opinion \(1\). The pair now expresses opinion \(1\) throughout.

Different pairs do not interact, so these moves can be performed independently. The sequence has \(2|I|\) moves.

The resulting state is an equilibrium:

  • In a selected pair, \(y_s=aw_i\) and \(y_f=\ell w_i\), giving

\(F_{s_i}-h_{s_i}=2D(a-c)w_i+2\ell w_i>0\),

\(F_{f_i}-h_{f_i}=2(a-c)w_i>0\).

All mass expresses opinion \(1\), which is stable for both beliefs.

  • In an unselected pair, all mass has belief and opinion \(0\). Its fields are

\(F_{s_i}=-Daw_i-\ell w_i<0\), and \(F_{f_i}=-aw_i<0\).

Thus opinion \(0\) is stable.

  • The isolated type is truthful and stable.

Finally, the equilibrium’s opinion-\(1\) mass is

\(\sum_qy_q=d\sum_{i\in I}w_i=dT>1/2+g/2>1/2\).

This proves completeness.

7. Polynomial encoding and conclusion

All constructed quantities have polynomial binary length in the original PARTITION input. Indeed, \(P,T,W\) have polynomial binary length, and \(\epsilon\) is fixed.

For completeness, dyadic choices inside the specified intervals can be made efficiently. Given rational endpoints \(r<s\), choose an integer \(k\) with

\(2^{-k}<(s-r)/2\),

and set

\(j=\lfloor 2^k r\rfloor+1\).

Then

\(r<j2^{-k}\le r+2^{-k}<s\).

When the endpoints have polynomial binary length, their positive difference is bounded below by an inverse exponential with polynomial exponent. Thus a polynomially bounded \(k\) suffices, and this procedure uses polynomial-time integer arithmetic. Apply it first to choose \(d\), then to choose \(a\).

The masses \(aw_i\), \((d-a)w_i\), and \(1-dW\) are dyadic. The kernel entries and stubbornness values are rational with polynomial binary length. There are linearly many supported types, and even a dense encoding of the kernel has polynomial size.

We have therefore constructed a polynomial-time many-one reduction from PARTITION to the stated decision problem with \(m=2\). Soundness covers every real belief assignment and every finite permitted trajectory; completeness supplies an explicit finite trajectory to a majority equilibrium.

The decision problem is consequently \(\mathrm{NP}\text{-hard}\) throughout the requested range, and admits no polynomial-time algorithm in \(m,\tau,L\) unless \(\mathrm{P}=\mathrm{NP}\).
