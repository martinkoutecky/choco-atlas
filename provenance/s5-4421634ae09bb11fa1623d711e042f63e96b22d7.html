The continuous mirror question, as graded

Given a finite set \(T\) of additive valuation types with rational masses \(\mu_t\) summing to \(1\), a finite set \(J\) of item classes with per-person supplies \(s_j\), and integral bundles \(S\subseteq J\) for each person, let \(y_{t,S}\) be the mass of type \(t\) assigned bundle \(S\). Subject to \(\sum_S y_{t,S}=\mu_t\) and \(\sum_{t,S:j\in S}y_{t,S}\le s_j\), compute or approximate the maximum population Nash welfare \(\exp(\sum_{t,S}y_{t,S}\log v_t(S))\), where \(v_t(S)=\sum_{j\in S}v_{tj}\); define the optimum as zero if no feasible assignment gives positive value to all positive-mass types.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau=|T|\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=|J|\ge1\) item classes with nonnegative binary-rational per-person supplies \(s_j\), with \(\sum_j s_j\ge1\). Values \(v_{tj}\) are nonnegative binary rationals, and \(v_t(S)=\sum_{j\in S}v_{tj}\).
Each person receives an integral bundle \(S\subseteq J\), containing at most one copy of each class; a type's mass may be split among bundles, and supplies may remain unused.
An assignment consists of masses \(y_{t,S}\ge0\) satisfying \(\sum_{S\subseteq J}y_{t,S}=\mu_t\) and \(\sum_{t,S:j\in S}y_{t,S}\le s_j\).
Its population Nash welfare is \(W(y)=\exp(\sum_{t,S:y_{t,S}>0}y_{t,S}\log v_t(S))\), with \(W(y)=0\) if any positive-mass assigned bundle has zero value. Let \(\mathrm{OPT}=\max_y W(y)\).
An approximation factor \(\rho\ge1\) means finding a feasible assignment with \(W(y)\ge\mathrm{OPT}/\rho\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L\) and any approximation parameter.

Does this population problem admit a polynomial-time \((\sqrt{8/7}-\delta)\)-approximation for some constant \(0<\delta<\sqrt{8/7}-1\), or is achieving every such factor NP-hard?

For finite agents with additive valuations, every constant \((\sqrt{8/7}-\delta)\)-approximation is impossible unless \(\mathrm{P}=\mathrm{NP}\). [Garg–Hoefer–Mehlhorn](https://arxiv.org/abs/1707.04428v3)
For the related weighted finite-agent configuration relaxation with unit supplies and unit bundle-distribution mass per agent, Feng–Li obtain additive log-objective error \(\log(1+\varepsilon)\) in polynomial time in the input size and \(1/\varepsilon\). Their stated result does not cover arbitrary population masses and supplies; no result settling that exact domain was located. [Feng–Li](https://arxiv.org/html/2404.15607v2)

Modeling choices made when packaging the task

  • Specified nonnegative binary-rational values and supplies, and nonempty item and type sets.
  • Carried over the discrete assumption that there are at least as many items as agents as aggregate per-person supply at least one.
  • Interpreted positive value for all types as positive value for almost every person: every bundle assigned positive mass must have positive value; otherwise welfare is zero.
  • Preserved bundles as subsets, so each person receives at most one copy of each item class, while allowing mass splitting and unused supply.
  • Used multiplicative welfare approximation and restricted delta so the requested factor exceeds one.

Result

The population problem admits a deterministic fully polynomial-time approximation scheme. For every \(\varepsilon>0\), one can output a feasible assignment satisfying \(W(y)\ge \mathrm{OPT}/(1+\varepsilon)\) in time \(\operatorname{poly}(m,\tau,L,1/\varepsilon)\).

In particular, take \(\varepsilon=1/16\) and \(\delta=\sqrt{8/7}-17/16\). Since \(289\cdot7<256\cdot8\), we have \(0<\delta<\sqrt{8/7}-1\). Thus the requested \((\sqrt{8/7}-\delta)\)-approximation exists.

The proof below constructs a polynomial-size rational linear program. Its variables describe masses flowing through graphs whose paths encode integral bundles. Population masses and supplies enter directly as right-hand sides.

1. Positive welfare and the logarithmic objective

Call a bundle \(S\) positive for type \(t\) if \(v_t(S)>0\).

First, we can determine in polynomial time whether any assignment has positive welfare. Construct a flow network with:

  • an arc from the source to each type \(t\), of capacity \(\mu_t\);
  • an arc from type \(t\) to class \(j\), of capacity \(1\), whenever \(v_{tj}>0\);
  • an arc from class \(j\) to the sink, of capacity \(s_j\).

There is an assignment with positive welfare if and only if this network admits a flow of value \(1\).

Indeed, such a flow assigns every person a positively valued singleton. Conversely, given an assignment with positive welfare, choose one positively valued item from each assigned bundle and retain only that item. Additivity and nonnegativity guarantee that such an item exists, and removing items cannot increase supply consumption. The resulting singleton assignment gives a flow of value \(1\).

All capacities are rational, so this test runs in \(\operatorname{poly}(m,\tau,L)\) time. If the maximum flow has value less than \(1\), then \(\mathrm{OPT}=0\), and assigning everyone the empty bundle meets every approximation guarantee.

Henceforth assume positive welfare is feasible. For assignments supported on positive bundles, define \(H(y)=\sum_{t,S}y_{t,S}\log v_t(S)\). Maximizing welfare is equivalent to maximizing \(H\).

The positive-bundle feasible region is a nonempty compact polytope: it has finitely many variables, closed constraints, and \(0\le y_{t,S}\le\mu_t\). Its objective has finite coefficients. Consequently, an optimum exists, and its value is \(H^*=\log\mathrm{OPT}\).

2. Rounding bundle values with relative error

Fix \(0<\varepsilon\le1\), and set \(\eta=\varepsilon/8\) and \(\zeta=\varepsilon/8\).

For a type \(t\), choose an anchor \(a\in J\) satisfying \(v_{ta}>0\). Write \(A=v_{ta}\), and restrict attention to bundles containing \(a\) whose other items have values at most \(A\). Define

\( h_{ta}=\eta A/m,\qquad q_{taj}=\left\lfloor v_{tj}/h_{ta}\right\rfloor \)

for each eligible item \(j\), namely each \(j\) with \(v_{tj}\le A\). The rounded value of such a bundle is

\( r_{ta}(S)=h_{ta}\sum_{j\in S}q_{taj}. \)

Because each item loses less than \(h_{ta}\) in rounding and \(|S|\le m\),

\( r_{ta}(S)\le v_t(S),\qquad r_{ta}(S)\ge v_t(S)-mh_{ta} =v_t(S)-\eta A \ge(1-\eta)v_t(S). \)

The last inequality uses \(a\in S\), hence \(A\le v_t(S)\). Therefore,

\( \log v_t(S)+\log(1-\eta) \le\log r_{ta}(S) \le\log v_t(S). \)

Every positive bundle has a representation of this kind: choose an item of maximum value in that bundle as its anchor.

Crucially, the integer scores have polynomial range. For every eligible item,

\( 0\le q_{taj}\le\lfloor m/\eta\rfloor, \)

so every bundle score is at most

\( Q=m\lfloor m/\eta\rfloor=O(m^2/\eta). \)

Also, \(q_{taa}=\lfloor m/\eta\rfloor>0\), so every anchored bundle has positive rounded value.

This value-rounding step is related to the rounding in Appendix A of [Feng–Li](https://arxiv.org/html/2404.15607v2). The following graph formulation and analysis explicitly handle the population domain in the question.

3. A polynomial-size flow formulation

For each type \(t\), create a source \(o_t\) and a sink \(d_t\). Between them, create a separate layered graph for every positive anchor \(a\).

The graph for \((t,a)\) processes the eligible items other than \(a\), in a fixed order. A state records the processing position and the accumulated integer score.

Its edges are as follows.

  • An entrance edge from \(o_t\) initializes the score to \(q_{taa}\) and records consumption of class \(a\).
  • At an item \(j\), a skip edge preserves the score and consumes nothing.
  • At that same item, an include edge increases the score by \(q_{taj}\) and records consumption of class \(j\).
  • From each final state of score \(q\), a terminal edge goes to \(d_t\), with objective coefficient \(\log(h_{ta}q)\).

Skip and include edges remain distinct even when \(q_{taj}=0\). Scores range from \(q_{taa}\) to \(Q\).

Every source-to-sink path specifies a bundle containing the anchor and at most one copy of every class. Conversely, every bundle represented by this anchor gives such a path. The path’s terminal coefficient is exactly the logarithm of its rounded value.

Each anchor graph has \(O(mQ)=O(m^3/\eta)\) vertices and edges. There are at most \(\tau m\) anchor graphs, giving a total size of \(O(\tau m^4/\varepsilon)\).

Let \(f_e\) denote the mass on edge \(e\), and let \(d_{ej}\in\{0,1\}\) indicate whether that edge records consumption of class \(j\). Impose:

  • nonnegativity and the harmless bounds \(f_e\le1\);
  • flow conservation at every intermediate vertex;
  • total flow \(\mu_t\) from \(o_t\) to \(d_t\);
  • the resource constraints \(\sum_e d_{ej}f_e\le s_j\) for every class \(j\).

These are exact rational constraints.

Assignments produce feasible flows

Represent each positive bundle using one of its maximum-value items as anchor, and route its assigned mass along the corresponding path.

This preserves type masses and class consumption exactly. Each edge carries at most the total mass of its type, which is at most \(1\). Thus the edge bounds impose no additional restriction.

Feasible flows produce assignments

All these graphs are acyclic. A nonnegative feasible flow therefore decomposes into source-to-sink paths.

Explicitly, start at a source with positive remaining flow and follow positive-flow edges. Conservation ensures that the path cannot terminate at an intermediate vertex, and acyclicity ensures that it reaches its sink. Subtract the minimum edge flow on the path and repeat. Each subtraction removes at least one positive-flow edge, so at most the number of edges many paths are extracted.

Give each extracted path’s bundle to a mass equal to its path weight, and aggregate duplicate bundles. The resulting assignment satisfies all type-mass and supply constraints exactly.

If \(C(f)\) denotes the objective using the exact terminal coefficients, this decomposition yields an assignment \(y\) satisfying

\( H(y)\ge C(f), \)

because the actual value of every path bundle is at least its rounded value.

4. Rational approximation of the logarithms

To obtain a rational LP, replace each terminal coefficient \(\log(h_{ta}q)\) by a rational number \(c_{taq}\) with

\( |c_{taq}-\log(h_{ta}q)|\le\zeta. \)

These coefficients can be computed with polynomial bit complexity.

Here are explicit bounds and a computation method. Every positive input value lies between \(2^{-L}\) and \(2^L\). For every terminal state,

\( h_{ta}q \ge h_{ta}q_{taa} \ge(1-\eta)A \ge2^{-(L+1)}, \)

and \(h_{ta}q\le mA\le m2^L\). Their rational representations have bit length polynomial in \(L+\log m+\log(1/\varepsilon)\).

For a positive rational \(r\), write \(r=2^k u\), with \(1\le u<2\). Then \(|k|=O(L+\log m)\). For \(z=(u-1)/(u+1)\), use

\( \log u =2\sum_{\ell=0}^{N-1}\frac{z^{2\ell+1}}{2\ell+1}+R_N, \qquad |R_N|\le3\cdot3^{-(2N+1)}. \)

The bound follows by summing the absolute tail geometrically, since \(0\le z<1/3\). The same formula computes \(\log2\), with \(z=1/3\). Consequently, approximating \(k\log2+\log u\) to error \(\zeta\) requires only \(N=O(\log((|k|+1)/\zeta))\) terms. Exact rational evaluation of these finite sums has polynomial bit complexity.

Let \(\widehat C(f)\) be the rational LP objective. Every feasible flow has total terminal mass \(\sum_t\mu_t=1\), so

\( |\widehat C(f)-C(f)|\le\zeta. \)

The standard polynomial-time theorem for rational linear programming now applies: the LP has explicitly listed rational coefficients, polynomially many variables and constraints, a nonempty feasible region, and bounded variables. It returns an exact rational optimizer \(\widehat f\) with polynomial encoding length.

5. Approximation guarantee

Let \(y^*\) maximize the original logarithmic objective, and represent it as a feasible graph flow \(f^*\). Section 2 gives

\( C(f^*)\ge H^*+\log(1-\eta), \)

because the total assigned mass is \(1\).

Let \(\widehat y\) be the assignment obtained by decomposing \(\widehat f\). Optimality of \(\widehat f\) for the rational objective and the coefficient-error bound give

\( H(\widehat y) \ge C(\widehat f) \ge\widehat C(\widehat f)-\zeta \ge\widehat C(f^*)-\zeta \ge C(f^*)-2\zeta \ge H^*+\log(1-\eta)-2\zeta. \)

Thus the additive loss is at most \(-\log(1-\eta)+2\zeta\). Since \(\eta=\varepsilon/8\le1/8\),

\( -\log(1-\eta)+2\zeta \le\frac{\eta}{1-\eta}+\frac{\varepsilon}{4} \le\frac{\varepsilon}{7}+\frac{\varepsilon}{4} =\frac{11\varepsilon}{28} \le\frac{\varepsilon}{2}. \)

Finally,

\( \log(1+\varepsilon) =\int_0^\varepsilon\frac{dx}{1+x} \ge\frac{\varepsilon}{1+\varepsilon} \ge\frac{\varepsilon}{2}. \)

Therefore \(H(\widehat y)\ge H^*-\log(1+\varepsilon)\). Exponentiating proves

\( W(\widehat y)\ge\frac{\mathrm{OPT}}{1+\varepsilon}. \)

For \(\varepsilon>1\), running the algorithm with parameter \(1\) gives the required guarantee.

6. Running time and relation to finite-agent hardness

The flow formulation has \(O(\tau m^4/\varepsilon)\) vertices and edges. Its coefficients have polynomial bit length, rational LP optimization takes polynomial time, and flow decomposition outputs at most \(O(\tau m^4/\varepsilon)\) bundle records. The overall running time is \(\operatorname{poly}(m,\tau,L,1/\varepsilon)\).

To avoid dependence on unnecessarily precise parameter encodings, one may use a dyadic internal parameter between \(\varepsilon/2\) and \(\varepsilon\). Its encoding length is \(O(\log(1/\varepsilon))\), and the guarantee and running-time bound remain valid.

The [finite-agent hardness result](https://arxiv.org/abs/1707.04428v3) does not transfer by assigning each finite agent mass \(1/n\) and each item supply \(1/n\). Under that scaling, population assignments correspond to fractional configuration solutions: an agent’s corresponding type mass can be split among several bundles. The algorithm above outputs those bundle masses directly; it requires no conversion into one bundle per finite agent.
