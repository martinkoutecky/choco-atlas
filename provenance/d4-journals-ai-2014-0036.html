The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\), thresholds \(b_t\), type-level influence coefficients \(W_{st}\), and prescribed masses \(p_t\leq\mu_t\), decide whether a nonatomic type-block LIG has an equilibrium in which at least \(p_t\) mass of each type chooses \(+1\). Let \(z_t\in[p_t,\mu_t]\) be the mass of type \(t\) choosing \(+1\), set \(a_t=2z_t-\mu_t\), and define \(F_t=\sum_{s\in T}W_{st}a_s-b_t\). Every agent, including those in the prescribed mass, must best respond: \(z_t=\mu_t\) when \(F_t>0\), \(z_t=0\) when \(F_t<0\), and any \(z_t\in[0,\mu_t]\) when \(F_t=0\), with a split at indifference assigning pure actions to different agents.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type is a nonatomic block whose agents choose one of \(m=2\) actions, \(\{-1,+1\}\). Input thresholds \(b_t\) and directed influence coefficients \(W_{st}\) are arbitrary signed binary rationals, including \(W_{tt}\); input requirements satisfy \(0\leq p_t\leq\mu_t\) and \(\sum_t p_t>0\).
For a measurable pure-action assignment, let \(z_t\in[0,\mu_t]\) be the mass choosing \(+1\), set \(a_t=2z_t-\mu_t\), and define \(F_t=\sum_{s\in T}W_{st}a_s-b_t\). A type-\(t\) agent choosing \(x\) receives payoff \(xF_t\); an individual deviation leaves all aggregates unchanged.
An equilibrium requires \(z_t=\mu_t\) if \(F_t>0\), \(z_t=0\) if \(F_t<0\), and permits any \(z_t\in[0,\mu_t]\) if \(F_t=0\), assigning pure actions to different indifferent agents. Every agent, including the prescribed mass, must best respond.
Decide whether such an equilibrium exists with \(z_t\geq p_t\) for every \(t\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this equilibrium-existence problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite linear influence games with signed weights and thresholds, deciding whether a pure-strategy Nash equilibrium exists in which a designated nonempty subset chooses \(+1\) is NP-complete ([Irfan and Ortiz](https://arxiv.org/abs/1303.2147)).
No result settling exactly the nonatomic problem defined above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to total mass 1, interpreting the society as a distribution over types.
  • Specified all thresholds and influence coefficients as binary rationals of arbitrary sign, matching the discrete model's unrestricted signs.
  • Required nonnegative prescribed masses and positive total prescribed mass, carrying over the designated subset's nonemptiness.
  • Allowed within-type influence W_tt: exclusion of an individual's self-influence does not exclude influence from other agents of the same nonatomic type.
  • Allowed real equilibrium masses and measurable pure-action assignments, with exact indifference permitting arbitrary splits.
  • Defined m as the fixed number of actions, 2, and L as the total binary input length.

Result

The problem is \(\mathrm{NP}\)-complete, already for \(m=2\). Hardness holds even when all types have equal dyadic masses and every requirement is either \(0\) or the type’s entire mass.

An exact algorithm runs in \(3^\tau\operatorname{poly}(m,\tau,L)\) time. Thus polynomial time in all three parameters would imply \(\mathrm{P}=\mathrm{NP}\).

1. Equilibrium conditions and membership in \(\mathrm{NP}\)

Write \(a_t=2z_t-\mu_t\). The mass requirement becomes

\[ 2p_t-\mu_t\leq a_t\leq\mu_t, \]

and the influence field is \(F_t=\sum_s W_{st}a_s-b_t\).

For each type, equilibrium is equivalent to satisfying at least one of these three regimes:

  • \(a_t=-\mu_t\) and \(F_t\leq0\).
  • \(a_t=\mu_t\) and \(F_t\geq0\).
  • \(F_t=0\).

The mass bounds remain imposed in every regime. To verify the equivalence, an endpoint aggregate assigns everyone the corresponding action, which is optimal precisely under the stated weak sign condition. An interior aggregate assigns positive mass to both actions, so both must be optimal; their payoffs are \(F_t\) and \(-F_t\), requiring \(F_t=0\). Conversely, when \(F_t=0\), any permitted split is an equilibrium.

Guess one regime for each type. The resulting constraints form a rational linear feasibility problem with \(\tau\) variables and \(O(\tau)\) constraints. Its encoding length is polynomial in \(L\): all coefficients are input rationals, apart from the bounds obtained by rational arithmetic.

The polynomial-time theorem for rational linear programming therefore gives a deterministic polynomial-time verifier for the guessed regime list. This proves membership in \(\mathrm{NP}\). Enumerating all \(3^\tau\) lists gives the claimed exact running time.

Nonatomicity ensures that every feasible mass split can be realized by measurable pure-action assignments within each type.

2. Reduction from three-SAT

Let a three-SAT instance have variables \(v_1,\ldots,v_n\) and clauses \(C_1,\ldots,C_k\), each containing three literal occurrences. We may restrict to \(n,k\geq1\); empty instances are trivial and do not affect hardness.

Create:

  • a variable type \(V_i\) for each variable;
  • two literal types \(P_i,Q_i\) for its positive and negative literals;
  • a clause type \(D_j\) for each clause.

There are \(M=3n+k\) types so far. Let \(N\) be the smallest power of two with \(N\geq M\), and add \(N-M\) dummy types. Set

\[ \tau=N,\qquad \mu_t=\frac1N \]

for every type. These masses are positive dyadic rationals and sum to \(1\).

Define the normalized aggregate

\[ x_t=\frac{a_t}{\mu_t}=Na_t\in[-1,1]. \]

Thus \(x_t=-1\) means everyone chooses \(-1\), \(x_t=1\) means everyone chooses \(+1\), and an interior value represents a split.

Fields and requirements

Specify the fields as follows:

\[ F_{V_i}=x_{V_i}, \]

\[ F_{P_i}=x_{V_i}-\frac12, \qquad F_{Q_i}=-x_{V_i}-\frac12. \]

For a literal \(\ell\), write \(A(\ell)=P_i\) when \(\ell=v_i\), and \(A(\ell)=Q_i\) when \(\ell=\neg v_i\). For each clause \(C_j=(\ell_{j1}\lor\ell_{j2}\lor\ell_{j3})\), set

\[ F_{D_j}=x_{A(\ell_{j1})}+x_{A(\ell_{j2})}+x_{A(\ell_{j3})}+1. \]

For every dummy type \(H\), set \(F_H=1\).

Finally, impose

\[ p_{D_j}=\mu_{D_j}=\frac1N, \qquad p_t=0\quad\text{for all other types}. \]

Hence \(\sum_t p_t=k/N>0\), as required.

These fields have exactly the permitted form. Explicitly:

  • \(W_{V_i,V_i}=N\), with \(b_{V_i}=0\);
  • \(W_{V_i,P_i}=N\) and \(W_{V_i,Q_i}=-N\), with \(b_{P_i}=b_{Q_i}=1/2\);
  • each literal occurrence contributes weight \(N\) from its literal type to its clause type, with \(b_{D_j}=-1\);
  • dummy types have zero incoming weights and threshold \(-1\).

All unspecified weights are zero. Repeated literal occurrences contribute their multiplicity to the corresponding coefficient.

3. Behavior forced by equilibrium

Variable types

At a variable type, the field is \(F_{V_i}=x_{V_i}\).

If \(0<x_{V_i}<1\), then \(F_{V_i}>0\), so equilibrium requires \(x_{V_i}=1\), a contradiction. Similarly, \(-1<x_{V_i}<0\) is impossible. Consequently, every equilibrium satisfies

\[ x_{V_i}\in\{-1,0,1\}. \]

All three values are compatible with that type’s equilibrium condition: the endpoints have the matching strict sign, and \(0\) gives indifference.

Literal types

The literal fields never vanish at these three possible variable values. Their uniquely determined equilibrium aggregates are:

| \(x_{V_i}\) | \(x_{P_i}\) | \(x_{Q_i}\) |
|---|---|---|
| \(-1\) | \(-1\) | \(1\) |
| \(0\) | \(-1\) | \(-1\) |
| \(1\) | \(1\) | \(-1\) |

Indeed, \(x_{V_i}-1/2>0\) exactly when \(x_{V_i}=1\), and \(-x_{V_i}-1/2>0\) exactly when \(x_{V_i}=-1\).

Thus a positive literal type chooses \(+1\) exactly when its variable aggregate is \(1\); a negative literal type does so exactly when its variable aggregate is \(-1\). A variable aggregate of \(0\) activates neither literal.

Clause types

The requirement \(p_{D_j}=\mu_{D_j}\) forces \(x_{D_j}=1\). This is an equilibrium precisely when \(F_{D_j}\geq0\).

Let \(r_j\) be the number of literal occurrences in clause \(C_j\) whose literal type has aggregate \(1\). The other \(3-r_j\) occurrences have aggregate \(-1\). Therefore

\[ F_{D_j}=r_j-(3-r_j)+1=2r_j-2. \]

It follows that the clause requirement is compatible with equilibrium exactly when

\[ r_j\geq1. \]

The equality case \(r_j=1\) gives \(F_{D_j}=0\); assigning the entire clause type to \(+1\) is then permitted by the stated equilibrium definition.

4. Correctness of the reduction

A satisfying assignment produces a feasible equilibrium

Given a satisfying Boolean assignment, set \(x_{V_i}=1\) for true variables and \(x_{V_i}=-1\) for false variables.

Set the literal aggregates according to the table, and set every clause and dummy aggregate to \(1\).

Each variable type best responds because its field equals its endpoint aggregate. Each literal type best responds because its aggregate matches the strict sign of its field. Every clause has at least one true literal, so \(r_j\geq1\) and \(F_{D_j}\geq0\). Dummy types have positive field and aggregate \(1\).

Thus all agents best respond, and every mass requirement holds.

A feasible equilibrium produces a satisfying assignment

Conversely, suppose the constructed instance has a feasible equilibrium.

For each variable, assign it true when \(x_{V_i}=1\), false when \(x_{V_i}=-1\), and arbitrarily when \(x_{V_i}=0\).

Every clause must have \(r_j\geq1\). Choose one of its literal occurrences whose literal aggregate is \(1\). The table shows that this occurrence comes from a variable with a nonzero aggregate and that the resulting Boolean assignment makes this literal true.

The arbitrary assignments to zero-aggregate variables cannot change these witnessed true literals. Hence every clause is satisfied.

This proves the equivalence between satisfiability and existence of the required nonatomic equilibrium.

5. Encoding size and conclusion

Because \(M\leq N<2M\), the constructed support size is \(O(n+k)\). Every nonzero weight has magnitude at most \(3N\); thresholds belong to \(\{-1,0,1/2\}\); masses and requirements are dyadic rationals with \(O(\log N)\) bits.

Even a dense encoding of the influence matrix has length \(O(N^2\log N)\), so the construction is a polynomial-time reduction.

The reduction proves \(\mathrm{NP}\)-hardness for fixed \(m=2\). Together with membership in \(\mathrm{NP}\), it establishes \(\mathrm{NP}\)-completeness for exactly the nonatomic problem in the question.
