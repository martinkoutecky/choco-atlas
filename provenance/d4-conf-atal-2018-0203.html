The continuous mirror question, as graded

Given a finite horizon \(T\), resident types \(i\) with rational masses \(\mu_i\), resource types \(j\) with per-capita supplies \(q_j\), time-dependent values \(v_{tij}\), and compatibility restrictions, optimize the sum of the per-period minimum utility and a stability reward. A feasible plan is a finite-support distribution \(x_{i,h}\) over histories \(h\), where each history gives each resident an integral bundle \(b_{t,j}(h)\), \(\sum_h x_{i,h}=\mu_i\), and \(\sum_{i,h}x_{i,h}b_{t,j}(h)=q_j\) at every time and for each resource type. The per-period minimum is taken over positive-mass histories, and stability counts the mass of resource copies retained by residents between consecutive periods.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\geq1\) resident types with positive binary-rational masses \(\mu_i\), normalized by \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types.
The offline input specifies \(T\geq2\) periods, \(m\geq1\) persistent resource types, constant per-capita supplies \(q_j\in\mathbb{Q}_{\geq0}\), values \(v_{tij}\in\mathbb{Q}_{\geq0}\), compatibility indicators \(a_{tij}\in\{0,1\}\), and a reward \(K\in\mathbb{Q}_{>0}\). Every positive-supply resource type has a compatible resident type at each period.
A history \(h\) for resident type \(i\) specifies bundles \(b_{t,j}(h)\in\mathbb{Z}_{\geq0}\), with \(b_{t,j}(h)=0\) whenever \(a_{tij}=0\). There is no additional bound on bundle size; empty bundles are allowed.
A plan assigns nonnegative real masses \(x_{i,h}\) to finitely many histories, satisfying \(\sum_hx_{i,h}=\mu_i\) and \(\sum_{i,h}x_{i,h}b_{t,j}(h)=q_j\) for every \(t,j\). Each history follows the same residents throughout the horizon.
Copies within a resource type are interchangeable; between adjacent periods, a resident retains \(\min\{b_{t,j}(h),b_{t+1,j}(h)\}\) copies, with remaining copies transferable.
Define \(F(x)=\sum_{t=1}^{T}\min_{i,h:x_{i,h}>0}\sum_{j=1}^{m}v_{tij}b_{t,j}(h)+K\sum_{t=1}^{T-1}\sum_{i,h}x_{i,h}\sum_{j=1}^{m}\min\{b_{t,j}(h),b_{t+1,j}(h)\}\).

Given a binary-rational threshold \(B\), is deciding whether a feasible finite-support plan satisfies \(F(x)\geq B\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,T,L\), where \(L\) is the total input bit length.

The discrete counterpart is \(\mathrm{NP}\)-hard even with two agents, no compatibility restrictions, and homogeneous values in \(\{0,1\}\); its static restriction is trivial. [Discrete hardness source](https://www.ifaamas.org/Proceedings/aamas2018/pdfs/p766.pdf)
No complexity result for this precise mass-and-history model was located in the literature search.

Modeling choices made when packaging the task

  • Normalize total resident mass to one so the stated supplies are per capita.
  • Use fixed resident and resource populations, a horizon of at least two periods, nonnegative binary-rational supplies and values, and a positive binary-rational retention reward K.
  • Represent compatibility by time-dependent indicators and require each positive-supply resource type to have a compatible resident type at every period.
  • Interpret integral bundles as nonnegative integer counts, allow empty bundles, and impose no individual bundle cap beyond the stated aggregate supply equations.
  • Allow nonnegative real plan masses with finite support; histories follow persistent residents rather than merely resident types independently at each period.
  • Treat resource copies within a type as interchangeable and count retained copies by the minimum of consecutive bundle counts.
  • Formulate exact optimization through existence of a feasible plan meeting a rational threshold, without assuming that a supremum is attained.

Result

The decision problem is \(\mathrm{NP}\)-hard, even when \(\tau=1\), all resources are compatible at every period, every supply is \(\tfrac12\), all values belong to \(\{0,1\}\), and \(K=1\).

The reduction below handles arbitrary real masses and unbounded integer bundles. Its yes-instances have witnesses consisting of just two constant histories.

1. Boolean source problem

A not-all-equal clause is satisfied when its literals include both a true literal and a false literal. We first establish hardness of not-all-equal satisfiability with three literals on distinct variables per clause.

Start from the standard \(\mathrm{NP}\)-complete problem \(\mathrm{3SAT}\); see [Schaefer’s satisfiability paper](https://doi.org/10.1145/800133.804350). We may assume that each clause has three distinct variables. Indeed, discard tautologies and remove repeated literals. A resulting two-literal clause \(a\lor b\) can be replaced by
\((a\lor b\lor u)\land(a\lor b\lor\neg u)\), with fresh \(u\). A unit clause \(a\) can be replaced by the four clauses \(a\lor u^{\epsilon}\lor v^{\delta}\), using all choices of signs on fresh \(u,v\). These replacements preserve satisfiability and increase size by only a constant factor.

Introduce one fresh global variable \(z\). Replace each original clause \(a\lor b\lor c\) by

\[ \operatorname{NAE}(a,b,s),\qquad \operatorname{NAE}(\neg s,c,z), \]

where \(s\) is fresh for that clause.

For fixed truth values of \(a,b,c,z\), these two clauses admit a choice of \(s\) exactly when \(a,b,c,z\) are not all equal:

  • If \(a=b=p\), the first clause forces \(s=1-p\). The second then fails exactly when \(c=z=p\).
  • If \(a\ne b\), the first clause accepts either value of \(s\). If \(c=z\), choose \(\neg s\ne c\); otherwise the second clause accepts either choice.

An original satisfying assignment therefore extends to a satisfying not-all-equal assignment by setting \(z=0\). Conversely, complementing every variable preserves every not-all-equal clause. Thus any satisfying transformed assignment can be complemented, if necessary, so that \(z=0\). The equivalence just proved then implies that every original clause has a true literal.

Consequently, this not-all-equal problem is \(\mathrm{NP}\)-hard. Its clauses use three distinct variables.

2. Construction of the society

Let \(\Phi\) be such a not-all-equal instance, with variables \(y_1,\ldots,y_n\) and clauses \(C_1,\ldots,C_c\). Restricting to nonempty instances ensures \(n+2c\geq2\).

Create one resident type of mass \(\mu_1=1\). For each variable \(y_k\), create two persistent resource types \(j_k^+\) and \(j_k^-\). Set

\[ m=2n,\qquad q_j=\tfrac12,\qquad K=1, \]

and make every resource compatible at every period.

For a literal \(\ell\), let \(j(\ell)\) denote its corresponding resource: \(j(y_k)=j_k^+\) and \(j(\neg y_k)=j_k^-\).

There are \(T=n+2c\) periods:

  • Variable periods. For each variable \(y_k\), one period values exactly \(j_k^+\) and \(j_k^-\), each at one.
  • Clause periods. For each clause \(C_r=(\ell_1,\ell_2,\ell_3)\), one period values exactly \(j(\ell_1),j(\ell_2),j(\ell_3)\), each at one. Another period values exactly \(j(\neg\ell_1),j(\neg\ell_2),j(\neg\ell_3)\), each at one.

All other values are zero. Set the threshold to

\[ B=T+n(T-1). \]

Every constructed input satisfies the hypotheses in the question.

3. Universal upper bound and its equality conditions

Fix any feasible finite-support plan. Since there is one resident type, write its positive history masses as \(x_h\), with \(\sum_hx_h=1\). Define the period minimum

\[ r_t=\min_{h:x_h>0}\sum_jv_{t1j}b_{t,j}(h). \]

Every history’s utility is an integer, so \(r_t\) is an integer. Feasibility gives its mass-weighted average as

\[ \sum_hx_h\sum_jv_{t1j}b_{t,j}(h) =\sum_jv_{t1j}q_j. \]

This average is one at a variable period and \(\tfrac32\) at either clause period. The minimum cannot exceed the average; hence, in every period,

\[ r_t\leq1. \]

Let \(R\) denote total retention, before multiplication by \(K\). The identity

\[ \min\{u,v\}=\frac{u+v-|u-v|}{2} \]

and the resource equalities imply

\[ R =n(T-1) -\frac12\sum_{t=1}^{T-1}\sum_hx_h \sum_j|b_{t,j}(h)-b_{t+1,j}(h)|. \]

Therefore \(R\leq n(T-1)\), and

\[ F(x)=\sum_tr_t+R\leq T+n(T-1)=B. \]

If \(F(x)\geq B\), every bound above must be tight: \(r_t=1\) for every period and \(R=n(T-1)\). Every summand in the retention deficit is nonnegative. Since each supported history has positive mass, equality forces

\[ b_{t,j}(h)=b_{t+1,j}(h) \]

for every supported history, resource, and adjacent pair of periods. Thus each supported history has a constant bundle throughout the horizon.

4. A threshold-achieving plan implies satisfiability

Suppose \(F(x)\geq B\). By the preceding section, every supported history has a constant bundle \(b_j(h)\), and every period minimum equals one.

At the variable period for \(y_k\), every supported history satisfies

\[ b_{j_k^+}(h)+b_{j_k^-}(h)\geq1. \]

The mass-weighted average of this sum is \(q_{j_k^+}+q_{j_k^-}=1\). Consequently every supported history satisfies equality:

\[ b_{j_k^+}(h)+b_{j_k^-}(h)=1. \]

Because the counts are nonnegative integers, each pair is either \((1,0)\) or \((0,1)\). This excludes all larger bundles without imposing an additional bundle bound.

Select any supported history and define \(y_k\) to be true exactly when \(b_{j_k^+}(h)=1\).

For a clause \(C_r=(\ell_1,\ell_2,\ell_3)\), its two periods require

\[ \sum_{a=1}^{3}b_{j(\ell_a)}(h)\geq1, \qquad \sum_{a=1}^{3}b_{j(\neg\ell_a)}(h)\geq1. \]

The variable-pair equalities make the second sum equal to three minus the first. Hence the first sum belongs to \(\{1,2\}\): the clause has both a true and a false literal. The selected history therefore yields a satisfying assignment for \(\Phi\).

5. Satisfiability implies a threshold-achieving plan

Conversely, let \(A\) satisfy \(\Phi\). Construct two constant histories, one encoding \(A\) and the other its global complement:

  • Each history contains exactly one resource from each variable pair.
  • Give each history mass \(\tfrac12\).

Every resource then has mass-weighted count \(\tfrac12=q_j\) at every period, so the plan is feasible.

At every variable period, both histories have utility one. At a clause period, the utilities are one and two, because \(A\) satisfies the not-all-equal clause and complementation reverses its literal truth values. The same holds for the complementary clause period. Thus every period minimum is one.

Each history retains its entire bundle of \(n\) resources across every transition. Therefore

\[ F(x)=T+n(T-1)=B. \]

Together with the previous section, this proves the equivalence

\[ \Phi\text{ is satisfiable} \quad\Longleftrightarrow\quad \text{a feasible finite-support plan satisfies }F(x)\geq B. \]

6. Running times and conclusion

The Boolean transformation increases the numbers of variables and clauses only linearly. The society construction has

\[ \tau=1,\qquad m=2n,\qquad T=n+2c. \]

Writing the dense value and compatibility tables takes \(O(m\tau T)\) time. Including reading the source instance and computing the threshold, the reduction takes \(O(L_{\Phi}+m\tau T)\) bit operations. Under the standard explicit table encoding, its output length satisfies \(L=O(mT+\log(mT))\). Thus the reduction is polynomial.

All numerical inputs except \(B\) are fixed constants, and \(B=O(mT)\). The hardness therefore does not depend on large numerical magnitudes.

For the constructed family, enumerating Boolean assignments gives an exact algorithm in \(O(L+2^{m/2}mT)\) time. For the general problem, an algorithm polynomial in \(m,\tau,T,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The requested classification is therefore \(\mathrm{NP}\)-hard.
