The continuous mirror question, as graded

Given finite contexts \(\Omega\), action sets \(A_\omega\), optimal subsets \(Good_\omega\), and agent types \(t\) with rational vote probabilities \(q_{t,\omega}(a)\), decide whether a rational mass distribution \(\mu\) over types exists such that, at every context, all actions in \(Good_\omega\) have equal vote mass and strictly exceed every action outside \(Good_\omega\), where \(v_{\mu,\omega}(a)=\sum_t\mu_tq_{t,\omega}(a)\). With uniform tie-breaking, this makes each optimal action equally likely at each context and each combination of optimal actions equally likely across independent contexts.

Packaged proof task (what the prover saw — nothing else)

Input consists of a nonempty finite context set \(\Omega\), explicitly listed finite action sets \(A_\omega\), nonempty subsets \(Good_\omega\subseteq A_\omega\), and a nonempty explicit catalogue \(T\) of \(k\) available agent types. Each type supplies binary rational probabilities \(q_{t,\omega}(a)\geq0\) satisfying \(\sum_{a\in A_\omega}q_{t,\omega}(a)=1\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types. The sought society may use any subset of \(T\), with \(\mu_t\geq0\) and \(\sum_{t\in T}\mu_t=1\); there is no prescribed support bound.
Define \(v_{\mu,\omega}(a)=\sum_{t\in T}\mu_tq_{t,\omega}(a)\). Feasibility requires \(v_{\mu,\omega}(a)=v_{\mu,\omega}(a')\) for all \(a,a'\in Good_\omega\), and \(v_{\mu,\omega}(a)>v_{\mu,\omega}(b)\) for all \(a\in Good_\omega\), \(b\in A_\omega\setminus Good_\omega\), at every context.
Plurality uses these vote masses directly, with uniform tie-breaking independently across contexts; optimal solutions are exactly \(\prod_{\omega\in\Omega}Good_\omega\). Thus a feasible society selects each optimal solution with probability \(1/\prod_{\omega\in\Omega}|Good_\omega|\).
Write running times in \(m=\sum_{\omega\in\Omega}|A_\omega|\), \(k\), \(\tau\), \(|\Omega|\), and the total input bit length \(L\).

Is deciding whether such a rational society exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

The [discrete asymptotic result](https://eprints.lancs.ac.uk/id/eprint/81442/1/COIN2015Book.pdf) claims that, under symmetric diverse-agent assumptions, sampled teams become optimal with probability tending to one along sizes \(n=c\prod_{d\in D}d\), where \(D\) contains a divisor greater than one of each \(|Good_\omega|\), as \(c\to\infty\); it supplies no polynomial-time decision algorithm.
No result settling this exact continuous feasibility problem was located in the literature search.

Modeling choices made when packaging the task

  • Made the available type catalogue finite and explicitly listed; distinguished its size k from the chosen society's support size tau, and allowed zero mass on unused types without a support bound.
  • Normalized total society mass to one and required every vote-probability vector to be nonnegative and sum to one.
  • Required nonempty contexts, a nonempty type catalogue, and nonempty optimal-action sets; allowed all actions to be optimal, in which case the strict comparisons are vacuous.
  • Interpreted plurality in the continuous model as comparison of deterministic vote masses, with independent uniform tie-breaking across contexts.
  • Retained the graded question's arbitrary rational probability vectors rather than imposing the discrete anchor's symmetric preferred-subset sampling model.

Result

The decision problem is in \(\mathrm{P}\). A feasible rational society, when one exists, can also be constructed in polynomial time.

Here “binary rational” means a rational number whose numerator and denominator are encoded in binary. The proof uses the explicit catalogue of all \(k\) types and imposes no support bound.

1. Reduce the number of comparisons

For each context \(\omega\), choose a reference action \(g_\omega\in Good_\omega\). Define the rational coefficients

\(e_{\omega,a,t}=q_{t,\omega}(a)-q_{t,\omega}(g_\omega)\), for \(a\in Good_\omega\setminus\{g_\omega\}\),

and

\(d_{\omega,b,t}=q_{t,\omega}(g_\omega)-q_{t,\omega}(b)\), for \(b\in A_\omega\setminus Good_\omega\).

The original requirements are equivalent to

\(\sum_{t\in T}e_{\omega,a,t}\mu_t=0\) for every indicated good action, and

\(\sum_{t\in T}d_{\omega,b,t}\mu_t>0\) for every indicated bad action.

Indeed, the equalities make every good action’s vote mass equal to that of \(g_\omega\). Consequently, comparing \(g_\omega\) with every bad action suffices.

There are

\(\sum_{\omega\in\Omega}(|Good_\omega|-1)\)

equality rows and

\(\sum_{\omega\in\Omega}(|A_\omega|-|Good_\omega|)\)

strict inequality rows. Their total is \(m-|\Omega|\).

2. Remove strict inequalities by scaling

Consider the following ordinary rational linear feasibility problem, with variables \(x_t\), one for each type:

  • \(x_t\geq 0\) for every \(t\in T\);
  • \(\sum_{t\in T}x_t\geq 1\);
  • \(\sum_{t\in T}e_{\omega,a,t}x_t=0\) for every equality row;
  • \(\sum_{t\in T}d_{\omega,b,t}x_t\geq 1\) for every good–bad comparison row.

Call its feasible polyhedron \(Q\).

Claim. A feasible rational society exists if and only if \(Q\) contains a rational point.

Forward direction. Suppose \(\mu\) is a feasible rational society. If there are good–bad comparison rows, define

\(\delta=\min_{\omega,\;b\in A_\omega\setminus Good_\omega}\sum_{t\in T}d_{\omega,b,t}\mu_t\).

This is the minimum of a nonempty finite collection of positive rational numbers, so \(\delta>0\) and \(\delta\) is rational. Set

\(\alpha=\max\{1,\delta^{-1}\}\), and \(x_t=\alpha\mu_t\).

Nonnegativity and all homogeneous equalities are preserved. Moreover,

\(\sum_t x_t=\alpha\geq 1\)

and every comparison satisfies

\(\sum_t d_{\omega,b,t}x_t\geq\alpha\delta\geq 1\).

Thus \(x\in Q\).

If there are no comparison rows, take \(x=\mu\). The equalities still have to hold; they are retained in \(Q\).

Reverse direction. Suppose \(x\in Q\) is rational. Let

\(S=\sum_{t\in T}x_t\geq 1\), and \(\mu_t=x_t/S\).

These are nonnegative rational masses summing to one. Every equality is preserved, and every good–bad comparison satisfies

\(\sum_t d_{\omega,b,t}\mu_t=\frac{\sum_t d_{\omega,b,t}x_t}{S}\geq\frac1S>0\).

Therefore \(\mu\) is a feasible society. This proves the claim.

3. Rational witnesses have polynomial bit length

We verify that real feasibility of \(Q\) also supplies a rational witness of manageable size.

Suppose \(Q\neq\varnothing\), and choose \(x^0\in Q\). The set

\(Q\cap\{x:\sum_t x_t\leq\sum_t x_t^0\}\)

is nonempty, closed, and bounded: every coordinate lies between zero and \(\sum_t x_t^0\). Consequently, minimizing \(\sum_t x_t\) over \(Q\) attains a minimum \(S_*\).

The minimizing set

\(F=\{x\in Q:\sum_t x_t=S_*\}\)

is a nonempty bounded polytope and hence has a vertex \(x^*\). This is also a vertex of \(Q\): if \(x^*\) were a nontrivial convex combination of two points of \(Q\), minimality would force both points to have coordinate sum \(S_*\), contradicting extremality in \(F\).

At a vertex, the equality rows and active inequality rows span the full \(k\)-dimensional space. Otherwise, a nonzero direction orthogonal to all these rows would permit sufficiently small perturbations in both directions. All inactive inequalities have positive slack, so both perturbations would remain feasible, contradicting extremality.

Thus \(x^*\) is uniquely determined by \(k\) independent tight rows. Clear denominators in these rows to obtain an integer system

\(Mx^*=h\), with \(\det M\neq 0\).

Each original coefficient is a difference of probabilities and has absolute value at most one. In any row, multiplying by the product of the denominators of the probabilities appearing in that row clears denominators. Those probabilities are entries of the original input, so this product is at most \(2^L\). Therefore every entry of \(M\) and \(h\) has absolute value at most \(2^L\).

By Cramer’s rule and the determinant expansion,

\(|\det M|\leq k!\,2^{kL}\),

and the same bound holds for each determinant obtained by replacing a column of \(M\) with \(h\). Hence we can write

\(x_t^*=p_t/D\),

where \(D\) is a positive integer and each \(p_t\) is a nonnegative integer, all with \(O(k(L+\log(k+1)))\) bits.

Normalizing cancels the common denominator:

\(\mu_t=\frac{p_t}{\sum_{s\in T}p_s}\).

The denominator is positive because \(\sum_t x_t^*\geq 1\), and it has the same polynomial bit bound. Thus a feasible real instance always has a feasible rational society of polynomial encoding length.

4. Polynomial-time algorithm and running times

Use the standard rational linear-programming theorem: feasibility of an explicitly given system of rational linear equalities and non-strict inequalities can be decided in polynomial time in its encoding length, and a rational feasible point can be constructed when one exists. This is polynomial time in the binary encoding model; see the [MIT notes on linear programming, Sections 11–13](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/908fe54d659623efadda2d033b895caf_notes_lp.pdf).

The algorithm is:

  • Construct the coefficients from Section 1 and the system \(Q\).
  • Decide rational linear feasibility of \(Q\).
  • If infeasible, answer no.
  • Otherwise, obtain a rational feasible \(x\), normalize it, and output its positive masses.

The system has \(k\) variables and

\(k+1+m-|\Omega|\)

rows when an equality counts as one row. Replacing each equality by two inequalities still gives \(O(k+m)\) rows. Its construction uses \(O(km)\) rational subtractions, and its encoding length is polynomial in \(m,k,|\Omega|,L\).

The decision and construction running times are therefore

\(\operatorname{poly}(m,k,|\Omega|,L)\).

Because the catalogue and action sets are explicit, these parameters are bounded by the input length, so the running time is also \(\operatorname{poly}(L)\).

For a supplied society of support size \(\tau\), all vote masses can be computed and checked using \(O(\tau m)\) rational arithmetic operations. The bit running time is polynomial in the combined encoding length of the instance and society. For a polynomial-length society constructed above, this is \(O(\tau m\,\operatorname{poly}(L))\).

5. A support bound follows without imposing one

The vertex witness above additionally satisfies

\(\tau\leq\min\{k,\;m-|\Omega|+1\}\).

To prove this, let \(\tau\) be the number of positive coordinates of \(x^*\). Exactly \(k-\tau\) nonnegativity constraints are active. Besides these, \(Q\) has only \(m-|\Omega|+1\) rows: the action-comparison rows and the row \(\sum_t x_t\geq 1\).

Since the active rows must have rank \(k\),

\(k\leq(k-\tau)+(m-|\Omega|+1)\),

which gives the bound. Normalization preserves the support.

This is an existence bound on a witness; the algorithm does not enumerate supports.

6. Relation to the asymptotic result

The [cited discrete result](https://eprints.lancs.ac.uk/id/eprint/81442/1/COIN2015Book.pdf), Theorem 1, concerns asymptotic sampling under additional assumptions. The decision algorithm proved here follows directly from the finite explicit rational input and does not require that theorem.

Under the stipulated independent uniform tie-breaking, a feasible society makes the maximizing actions exactly \(Good_\omega\) at each context. Hence each solution in \(\prod_{\omega\in\Omega}Good_\omega\) receives probability \(1/\prod_{\omega\in\Omega}|Good_\omega|\), as required.

The exact continuous feasibility problem is therefore polynomial-time solvable. NP-hardness under polynomial-time many-one reductions would imply \(\mathrm{P}=\mathrm{NP}\).
