The continuous mirror question, as graded

Given a graph \(G\) with candidate set \(C=V(G)\), a nonempty zone \(Z\subseteq C\), and a rational distribution \(\mu\) over complete rankings of \(C\), decide whether weighted IRV elects a member of \(Z\) for every nonempty slate \(K\subseteq C\) with \(K\cap Z\neq\emptyset\).

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,E)\) be a finite connected unweighted undirected graph, with candidate set \(C=V\), \(m=|C|\geq1\), distinct candidate IDs \(1,\ldots,m\), and a nonempty zone \(Z\subseteq C\).
A society is given by its support: the list of its \(\tau\) distinct strict complete rankings of \(C\) with positive masses, each mass a binary rational; the masses sum to \(1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Rankings are supplied explicitly and need not be induced by graph distances. Each slate contains at most one candidate per vertex.
Weighted IRV uses these rankings restricted to the remaining candidates, with each type contributing its entire mass to its highest-ranked survivor. Elimination ties remove the largest-ID candidate; the last survivor wins.
Call \(Z\) an exclusion zone when every nonempty slate \(K\subseteq C\) satisfying \(K\cap Z\neq\emptyset\) has its weighted-IRV winner in \(Z\).
Is deciding whether \(Z\) is an exclusion zone in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard under polynomial-time Turing reductions?
Discrete exclusion-zone verification is \(\mathrm{coNP}\)-complete for deterministic IRV, with a stated extension to deterministic rank-based elimination rules satisfying Strong Forced Elimination; verification with one distance-ranking voter per vertex is polynomial-time on trees. Result

The problem is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions, and therefore \(\mathrm{NP}\)-hard under polynomial-time Turing reductions.

Hardness holds even when \(G\) is a path and \(Z\) is a singleton. The reduction below uses explicitly supplied strict rankings and polynomially many rational masses.

1. Membership in \(\mathrm{coNP}\)

A certificate that \(Z\) is not an exclusion zone is a slate \(K\subseteq C\) satisfying \(K\cap Z\neq\emptyset\), whose winner lies outside \(Z\). The slate requires \(m\) bits.

We give an exact polynomial-time verifier. Write the masses as \(p_i/q_i\), for \(1\leq i\leq\tau\), and define \(D=\prod_{i=1}^{\tau}q_i\). Replace each mass by the integer weight \(w_i=p_i(D/q_i)\). This multiplies every score by \(D\), preserving all comparisons and ties.

The binary length of \(D\) is \(O(L)\). Because the masses sum to \(1\), the integer weights sum to \(D\), so every score also has \(O(L)\) bits. Using elementary integer arithmetic, this preprocessing takes \(O(\tau L^2)\) bit operations.

During IRV, maintain a pointer to each ranking’s highest-ranked survivor. Each pointer advances at most \(m\) times. Recomputing scores and selecting the prescribed eliminated candidate over at most \(m-1\) rounds takes \(O((\tau m+m^2)L)\) bit operations. Thus a counterexample can be verified in

\(O\bigl(\tau L^2+(\tau m+m^2)L\bigr)\)

bit operations. Consequently, exclusion-zone verification belongs to \(\mathrm{coNP}\).

2. Reduction from Exact Cover by 3-Sets

We use the standard \(\mathrm{NP}\)-complete problem Exact Cover by 3-Sets, abbreviated \(\mathrm{X3C}\). Its input consists of an explicitly listed universe \(U\), with \(|U|=3n\), and a family \(\mathcal S=\{S_1,\ldots,S_r\}\) of three-element subsets of \(U\). The question is whether some subfamily partitions \(U\). We restrict to \(n\geq1\), which leaves the problem \(\mathrm{NP}\)-complete. [Reference for the standard complexity classification](https://arxiv.org/abs/2206.10389).

Construction

Create candidates \(C=\{s,c_1,\ldots,c_r\}\), where \(c_i\) represents \(S_i\). Give \(s\) ID \(1\) and \(c_i\) ID \(i+1\). Let \(G\) be the path through these candidates, and set \(Z=\{s\}\).

Let \(T=6n+5\). Supply the following ballots:

  • One ballot of mass \(5/T\), ranking \(s\) first and then \(c_1,\ldots,c_r\).
  • For each \(x\in U\), one ballot of mass \(2/T\). It ranks all candidates \(c_i\) with \(x\in S_i\) first, in increasing index order; then \(s\); then all remaining candidates, again in increasing index order.

Every ballot is a strict complete ranking. The masses are positive and sum to \(1\), since \(5+2|U|=T\).

If several ballots have identical rankings, merge them by adding their masses. This preserves every score on every slate, because identical rankings have the same highest-ranked survivor. The resulting support therefore consists of distinct rankings, with

\(m=r+1\quad\text{and}\quad\tau\leq3n+1\).

All merged masses have denominator \(T\) and numerators at most \(T\), requiring \(O(\log(n+2))\) bits each. The output bit length is bounded by

\(O\bigl((3n+1)(r+1)\log(r+2)+(3n+1)\log(n+2)\bigr)\).

Constructing the rankings, sorting them, and merging duplicates takes polynomial time in the source input length.

3. First-round scores on every relevant slate

Consider any slate \(K=\{s\}\cup\{c_i:i\in I\}\), with \(I\subseteq\{1,\ldots,r\}\).

Multiply its first-round scores by \(T\). Thus the distinguished ballot has weight \(5\), and each element ballot has weight \(2\).

Let \(u\) be the number of elements not covered by the selected sets \(\{S_i:i\in I\}\). An element ballot supports \(s\) exactly when its element is uncovered. Otherwise, it supports its highest-ranked selected incident set candidate. Therefore,

\(\operatorname{score}_K(s)=5+2u\).

For each \(i\in I\), let \(a_i\) count the element ballots supporting \(c_i\). Only elements of \(S_i\) can support it, so \(0\leq a_i\leq3\), and

\(\operatorname{score}_K(c_i)=2a_i\in\{0,2,4,6\}\).

These formulas hold for every slate containing \(s\).

4. Correctness of the reduction

An exact cover makes \(Z\) fail

Suppose \(\{S_i:i\in I\}\) is an exact cover. Run the election on \(K=\{s\}\cup\{c_i:i\in I\}\).

Each element has exactly one selected incident set candidate, so each selected candidate receives all three of its element ballots. No element ballot supports \(s\). Consequently,

\(\operatorname{score}_K(s)=5\quad\text{and}\quad\operatorname{score}_K(c_i)=6\ \text{for every }i\in I\).

Thus \(s\) is uniquely lowest and is eliminated first. Since \(n\geq1\), at least one set candidate remains, and the eventual winner lies outside \(Z\). Hence \(Z\) is not an exclusion zone.

Without an exact cover, \(s\) wins every relevant slate

Suppose the source instance has no exact cover. Consider any slate containing \(s\) and at least one set candidate.

If \(u\geq1\), then \(\operatorname{score}_K(s)\geq7\), while every selected set candidate has score at most \(6\). Thus \(s\) cannot be eliminated.

Now suppose \(u=0\). We claim that some selected candidate satisfies \(a_i\leq2\). Otherwise every selected candidate would satisfy \(a_i=3\), receiving the ballots of all three elements of its set.

Two selected sets could then not overlap: the ballot of a shared element cannot contribute its entire weight to both candidates. Moreover, \(u=0\) means the selected sets cover \(U\). They would therefore form an exact cover, contrary to the assumption.

Hence some selected candidate has score at most \(4\), strictly below \(s\)’s score \(5\). Again, \(s\) cannot be eliminated.

We have proved that every slate containing \(s\) and another candidate has a candidate with strictly smaller score than \(s\). After an elimination, the surviving candidates form another such slate, and their scores are obtained from the same restricted rankings. Applying the argument repeatedly shows that \(s\) survives every elimination and wins. The singleton slate \(\{s\}\) also elects \(s\).

Therefore \(Z=\{s\}\) is an exclusion zone.

All comparisons protecting or eliminating \(s\) are strict. Ties between other candidates may occur, but the prescribed largest-ID elimination rule cannot affect either direction of the proof.

5. Complexity conclusion

The polynomial-time construction satisfies

\(\text{the }\mathrm{X3C}\text{ instance has an exact cover}\quad\Longleftrightarrow\quad Z\text{ is not an exclusion zone}\).

Equivalently, it is a many-one reduction from the \(\mathrm{coNP}\)-complete complement of \(\mathrm{X3C}\) to exclusion-zone verification. Together with Section 1, this proves \(\mathrm{coNP}\)-completeness.

An oracle deciding exclusion-zone verification decides \(\mathrm{X3C}\) with one query followed by negating the answer. Thus the requested problem is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. A polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The path restriction causes no conflict with tractability for distance rankings on trees: the present model permits the explicitly constructed rankings above.
