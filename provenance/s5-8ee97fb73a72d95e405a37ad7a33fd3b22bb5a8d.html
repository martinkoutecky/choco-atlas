The continuous mirror question, as graded

Given two insolvent creditor populations \(j\in\{1,2\}\), each with finite claim types \(t\in T_j\), rational masses \(\mu^j_t\ge 0\) summing to \(1\), rational claims \(q^j_t\ge 0\), and rational asset per creditor \(a_j>0\), where \(\Lambda_j=\sum_{t\in T_j}\mu^j_tq^j_t\ge a_j\), define \(\Phi_j=\int_0^1[\min\{a_j,u\Lambda_j\}-\max\{0,a_j-(1-u)\Lambda_j\}]\,du=a_j-a_j^2/\Lambda_j\). Decide whether \(\Phi_1=\Phi_2\), returning the exact values.

Packaged proof task (what the prover saw — nothing else)

For each \(j\in\{1,2\}\), a creditor society is given by its support \(T_j\): a nonempty list of types with positive binary rational masses \(\mu_t^j\) summing to \(1\), nonnegative binary rational claims \(q_t^j\), and a positive binary rational asset per creditor \(a_j\). Require \(\Lambda_j=\sum_{t\in T_j}\mu_t^jq_t^j\ge a_j\), allowing borderline solvency.
Write \(\tau_j=|T_j|\) and \(\tau=\tau_1+\tau_2\); these count supported types, not all possible types. Let \(L\) be the total input bit length; claims have one coordinate, so \(m=1\).
At \(u\in[0,1]\), the predecessor population contains fraction \(u\) of every type. Its worth with the firm is \(\min\{a_j,u\Lambda_j\}\), and without the firm is \(\max\{0,a_j-(1-u)\Lambda_j\}\).
Define the firm's continuous payoff by \(\Phi_j=\int_0^1[\min\{a_j,u\Lambda_j\}-\max\{0,a_j-(1-u)\Lambda_j\}]\,du=a_j-a_j^2/\Lambda_j\). The computational problem decides exact equality \(\Phi_1=\Phi_2\) and returns both exact rational payoffs.

Is this continuous equality problem solvable in polynomial time in \(m,\tau,L\), including computing both exact payoffs, or is it NP-hard?

For finite creditor lists, equality of the firm's Shapley payoffs in two liability games is reported NP-hard, and exact payoff computation is reported NP-hard. [Published source](https://real.mtak.hu/160355/1/1-s2.0-S0377221721008584-main.pdf)
No result settling exactly the continuous problem defined here was located in the literature search.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Proven result. The continuous problem as defined is solvable in deterministic polynomial time. Exact equality belongs to \(\mathrm{P}\), and both exact rational payoffs can be computed in \(\mathrm{FP}\). This includes borderline solvency.

Derivation of the payoff. Fix either society and suppress its index. By hypothesis, \(\Lambda\ge a>0\), so \(x=a/\Lambda\) is well defined and belongs to \((0,1]\). The first integrand changes formula at \(u=x\), giving

\(\displaystyle \int_0^1\min\{a,u\Lambda\}\,du=\int_0^x u\Lambda\,du+\int_x^1 a\,du=\frac{\Lambda x^2}{2}+a(1-x)=a-\frac{a^2}{2\Lambda}.\)

The second integrand is zero up to \(u=1-x\), and thereafter equals \(\Lambda(u-(1-x))\). Consequently,

\(\displaystyle \int_0^1\max\{0,a-(1-u)\Lambda\}\,du=\int_{1-x}^1\Lambda(u-(1-x))\,du=\frac{\Lambda x^2}{2}=\frac{a^2}{2\Lambda}.\)

Subtracting proves

\(\displaystyle \Phi=a-\frac{a^2}{\Lambda}.\)

Both calculations remain valid when \(x=1\). In particular, \(\Lambda=a\) gives \(\Phi=0\). Thus each society’s payoff depends only on its asset \(a\) and weighted aggregate claim \(\Lambda\).

Exact algorithm and bit complexity. Write the input rationals for society \(j\) as

\(\displaystyle \mu_t^j=\frac{p_t^j}{d_t^j},\qquad q_t^j=\frac{r_t^j}{s_t^j},\qquad a_j=\frac{A_j}{B_j},\)

with positive denominators, \(p_t^j,A_j>0\), and \(r_t^j\ge0\). Reduced input fractions are unnecessary. Define the integers

\(\displaystyle D_j=\prod_{t\in T_j}d_t^js_t^j,\qquad N_j=\sum_{t\in T_j}p_t^jr_t^j\frac{D_j}{d_t^js_t^j}.\)

Every division in this expression is exact, and \(\Lambda_j=N_j/D_j\). The promise \(\Lambda_j\ge a_j>0\) ensures \(N_j>0\) and \(B_jN_j-A_jD_j\ge0\). Therefore compute

\(\displaystyle U_j=A_j(B_jN_j-A_jD_j),\qquad V_j=B_j^2N_j.\)

Then \(V_j>0\) and \(\Phi_j=U_j/V_j\). Return these fractions, optionally reduced by their greatest common divisors. Decide equality by the exact integer test

\(\displaystyle U_1V_2=U_2V_1.\)

We must also bound the sizes of these integers. Since \(L\) counts all input bits, the sum of the binary lengths of the denominator factors in \(D_j\) is at most \(L\). Hence \(D_j<2^L\). Similarly, \(p_t^jr_t^j<2^L\), so every summand defining \(N_j\) is less than \(2^{2L}\). Thus

\(\displaystyle 0<N_j<\tau_j2^{2L}.\)

It follows that \(D_j,N_j\), all intermediate integers, the output numerators and denominators, and the equality-test products have \(O(L+\log(\tau+1))\) bits.

The construction uses \(O(\tau+1)\) integer arithmetic operations, plus at most two greatest-common-divisor computations. Elementary multiplication and long division on \(b\)-bit integers take \(O(b^2)\) bit operations; the Euclidean algorithm has a polynomial bound, for example \(O(b^3)\). Consequently, a sufficient overall bound is

\(\displaystyle O\!\left((\tau+1)(L+\log(\tau+1))^3\right).\)

This proves polynomial running time and polynomial output length. Because \(m=1\) throughout the specified problem, it also establishes the requested polynomial dependence on \(m,\tau,L\).

Relation to finite-game hardness. Theorem 19 of the cited paper establishes NP-hardness for equality of the firm’s Shapley payoffs in two finite liability games. [Csóka, Illés and Solymosi, *On the Shapley value of liability games*](https://real.mtak.hu/160355/1/1-s2.0-S0377221721008584-main.pdf)

That result concerns a different payoff computation. Here the stipulated predecessor population contains the same fraction \(u\) of every supported type, so its aggregate claim is exactly \(u\Lambda_j\), and the integral reduces to the rational formula proved above. The explicit polynomial algorithm settles this continuous problem independently of the finite-game result. Its equality decision problem could be NP-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).
