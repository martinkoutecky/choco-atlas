Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Complexity of Mass-Aggregated Phragmén Control

Result

Assume the rational distribution is represented explicitly by listing its positive-mass approval types and binary-encoded masses. Constructive control by deleting at most \(r\) projects for mass-aggregated Phragmén is \(\mathrm{NP\text{-}complete}\). In particular, it is \(\mathrm{NP\text{-}hard}\), even when all project costs are \(1\).

Consequently, it is not polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).

1. Finite-profile aggregation lemma

Consider an ordinary finite Phragmén instance with voters \(1,\ldots,n\). For every approval type \(t\subseteq P_0\), let \(n_t\) be the number of voters whose approval set is exactly \(t\), and define

\[ \mu_t=\frac{n_t}{n}. \]

Types with \(n_t=0\) need not be represented.

Lemma

Run ordinary finite-voter Phragmén and mass-aggregated Phragmén on the same project set, with the same costs, budget, and tie-breaking order. At corresponding stages, if \(x_t\) is the common finite-voter balance of voters of type \(t\), then the mass balance satisfies

\[ b_t=n x_t. \]

Moreover, the two executions fund exactly the same sequence of projects.

Proof

Voters of the same type always have equal balances: they start at \(0\), increase at the same rate, and are reset simultaneously because they approve exactly the same projects.

Initially, \(b_t=x_t=0\), so the claimed invariant holds.

Suppose it holds immediately before the next project is chosen. For a surviving project \(q\), let \(\delta_q^{\mathrm F}\) be its waiting time in the finite execution. It satisfies

\[ \sum_{t:q\in t}n_t\bigl(x_t+\delta_q^{\mathrm F}\bigr)=\kappa(q). \]

In the mass execution, evaluate the payment accumulated after waiting \(n\delta_q^{\mathrm F}\). Using \(b_t=nx_t\) and \(\mu_t=n_t/n\), it is

\[ \sum_{t:q\in t}\mu_t\bigl(b_t+n\delta_q^{\mathrm F}\bigr) = \sum_{t:q\in t}\frac{n_t}{n} \bigl(nx_t+n\delta_q^{\mathrm F}\bigr) = \sum_{t:q\in t}n_t\bigl(x_t+\delta_q^{\mathrm F}\bigr) = \kappa(q). \]

For a project with positive supporter mass, the left-hand side is strictly increasing in the waiting time. Hence

\[ \delta_q^{\mathrm M}=n\delta_q^{\mathrm F}. \]

Projects without supporters can never pay a positive cost in either execution.

Thus every candidate waiting time is multiplied by the same positive factor \(n\). The minimizing project is therefore the same, equality of waiting times is preserved, and the fixed tie-breaking order selects the same project.

After the waiting period, every non-reset mass balance satisfies

\[ b_t+\delta_q^{\mathrm M} = nx_t+n\delta_q^{\mathrm F} = n\bigl(x_t+\delta_q^{\mathrm F}\bigr). \]

Approving voters and their corresponding mass types are reset to \(0\) in both executions. The balance invariant is therefore preserved.

Because project costs and the budget are identical, the accumulated funded cost is also identical. Consequently, budget-based removal deletes the same projects. Induction over the funded projects proves the lemma. \(\square\)

2. Preservation under project deletion

Let \(D\subseteq P_0\) be any deletion set. Apply the lemma to the remaining project set \(P_0\setminus D\).

If two original approval types become identical after deleting \(D\), keeping them as separate mass types causes no difficulty. They start with equal balances and have identical reset histories on \(P_0\setminus D\), so their contributions can equivalently be summed.

Therefore, for every deletion set \(D\), the finite and mass-aggregated executions have exactly the same funded outcome. In particular, a distinguished project \(p\) is funded after deleting \(D\) in the finite instance if and only if it is funded after deleting \(D\) in the mass instance.

3. Polynomial reduction and hardness

Take an instance of constructive control by deleting projects for ordinary finite-voter Phragmén. By the stated nearest known result, this problem is \(\mathrm{NP\text{-}hard}\), even when every project has cost \(1\).

Construct the mass instance as follows:

  • retain the same projects, costs, budget, distinguished project, deletion bound, and tie-breaking order;
  • count the voters of every approval type \(t\);
  • output the positive masses \(\mu_t=n_t/n\).

There are at most \(n\) positive-mass types, and every mass has a binary representation of polynomial length. Thus the construction is polynomial-time.

By the preceding lemma, every deletion set succeeds in the finite instance exactly when it succeeds in the mass instance. This is a polynomial many-one reduction. Hence mass-aggregated constructive deletion control is \(\mathrm{NP\text{-}hard}\), even with unit costs.

If costs and budgets are required to be interpreted literally as per-capita quantities, one may instead set

\[ \kappa^{\mathrm M}(q)=\frac{\kappa^{\mathrm F}(q)}{n}, \qquad \mathcal B^{\mathrm M}=\frac{\mathcal B^{\mathrm F}}{n}. \]

Then the two executions have equal rather than \(n\)-scaled waiting times. This alternative still gives a polynomial reduction with rational costs.

4. Membership in \(\mathrm{NP}\)

A certificate is a set \(D\subseteq P_0\setminus\{p\}\) with \(|D|\le r\). It remains to show that the resulting mass execution can be simulated in polynomial time using exact rational arithmetic.

At any stage, define

\[ M_q=\sum_{t:q\in t}\mu_t, \qquad S_q=\sum_{t:q\in t}\mu_t b_t. \]

For \(M_q>0\), the waiting time is

\[ \delta_q=\frac{\kappa(q)-S_q}{M_q}. \]

The standard Phragmén invariant gives \(S_q\le\kappa(q)\) for every surviving project. Indeed, this holds initially; advancing by the minimum waiting time cannot make an unselected project exceed its cost, and resetting balances only decreases its accumulated supporter balance.

Thus each iteration requires only rational additions, divisions, and comparisons. There are at most \(|P_0|\) funding iterations.

For completeness, the intermediate rational numbers have polynomial bit length. Choose a common denominator \(Q\) for all input masses and costs and write

\[ \mu_t=\frac{u_t}{Q}, \qquad \kappa(q)=\frac{k_q}{Q}. \]

For each project let \(A_q=\sum_{t:q\in t}u_t\). If \(\rho_t\) is the absolute time at which type \(t\) was last reset, the absolute time at which \(q\) can be funded is

\[ T_q= \frac{\kappa(q)+\sum_{t:q\in t}\mu_t\rho_t}{M_q} = \frac{k_q+\sum_{t:q\in t}u_t\rho_t}{A_q}. \]

Every \(\rho_t\) is either \(0\) or a previously selected event time. Let \(A\) be the product of all positive \(A_q\). Inductively, after \(j\) funding events, every stored event-time denominator divides \(A^j\). Its bit length is therefore at most

\[ j\sum_q \log A_q, \]

which is polynomial in the input length.

Furthermore, \(T_q\) is a convex combination of previous reset times plus \(\kappa(q)/M_q\). Hence, with \(H=\max_q\kappa(q)/M_q\), the \(j\)-th selected event time is at most \(jH\). Its numerator consequently also has polynomial bit length.

The execution and the question whether \(p\) is funded can therefore be verified in polynomial time. The control problem belongs to \(\mathrm{NP}\).

5. Conclusion and scope

Combining membership with the reduction proves \(\mathrm{NP\text{-}completeness}\). Aggregating voters by approval type does not eliminate the finite-profile hardness because every finite profile embeds exactly as a polynomial-size rational mass profile.

The argument does not establish hardness when the number of positive-mass types is bounded by a fixed constant. That is a separate restricted problem.

Step-by-step audit

1. Finite-profile aggregation lemma

The scaling invariant \(b_t=n x_t\) is correct.

  • Voters sharing an approval type have identical balances because they begin equally, accrue at the same rate, and are reset simultaneously.
  • Substituting \(\mu_t=n_t/n\) and \(b_t=n x_t\) correctly gives \(\delta_q^{\mathrm M}=n\delta_q^{\mathrm F}\).
  • Multiplication by the common positive factor \(n\) preserves all comparisons and ties between candidate waiting times.
  • The reset operation preserves the scaling invariant.
  • Identical project costs and budget imply identical budget-based removals.

Projects having zero supporter mass cannot satisfy the payment equation for positive cost, matching the finite execution. No error appears in this lemma.

2. Preservation under deletion

Applying the lemma to \(P_0\setminus D\) is valid for every fixed deletion set \(D\).

If distinct original types become identical after deletion, they indeed have identical balance and reset histories on the remaining project set. Keeping them separate does not alter their aggregate contribution. Thus success of each deletion set is preserved.

3. Hardness reduction

Under sparse positive-support encoding, the reduction is correct and polynomial:

  • There are at most \(n\) positive-mass types in an explicitly listed \(n\)-voter profile.
  • Each mass \(n_t/n\) has polynomial binary length.
  • The aggregation lemma gives the required equivalence for every deletion set.
  • Unit project costs are retained in the unscaled construction.

The optional normalized construction with costs and budget divided by \(n\) is also internally consistent, although it is unnecessary for the unit-cost hardness claim.

4. Membership in \(\mathrm{NP}\)

The simulation argument is sound.

For a surviving project with \(M_q>0\), the formula \(\delta_q=(\kappa(q)-S_q)/M_q\) follows directly from the payment equation. The asserted invariant \(S_q\leq\kappa(q)\) is preserved because advancing by the minimum candidate waiting time cannot overfund another surviving project, while resets only decrease its supporter balance.

The absolute-time formula is correct: if \(\rho_t\) is the last reset time, then the current balance at absolute time \(T\) is \(T-\rho_t\), yielding the displayed expression for \(T_q\).

The denominator bound is also valid after choosing a common input denominator. At each event, division introduces at most a factor \(A_q\), and \(A_q\) divides the product \(A\). Since there are at most \(|P_0|\) events, denominator bit lengths remain polynomial.

The upper bound by successive additions of \(H=\max_q\kappa(q)/M_q\) suffices to bound numerator bit lengths polynomially. Budget comparisons and accumulation of at most \(|P_0|\) input costs are routine exact rational operations.

Thus membership in \(\mathrm{NP}\) is established for the stated sparse encoding.

Major scope issue

The user task does not define how the distribution over approval types is encoded. The prover inserts the assumption:

“Assume the rational distribution is represented explicitly by listing its positive-mass approval types and binary-encoded masses.”

This is a material restriction, not merely notation. Complexity is measured against the representation length, and listing all \(2^{|P_0|}\) approval types, listing only positive types, or using a succinct representation can produce different complexity analyses. In particular, the finite-profile reduction is polynomial only for the sparse positive-support representation used by the prover.

Therefore, the proof justifies the conditional statement “sparse explicit encoding implies \(\mathrm{NP}\)-completeness,” but it does not settle the unqualified problem or establish a representation-dependent split.

Otherwise, the prover must separately classify the other intended representation models.
