The continuous mirror question, as graded

Given rational type masses \(\mu\), per-capita supplies \(\beta\) of indivisible goods, observable ordinal rankings, and hidden shared valuations \(v_t(g)\in\{h_t,\ell_t\}\), determine the minimum number \(q\) of adaptive queries \((t,g)\mapsto v_t(g)\) per type needed to output a finite-support distribution \(x\) over integral bundles satisfying \(\sum_B x_{t,B}=\mu_t\), \(\sum_{t,B}x_{t,B}B_g=\beta_g\), and \(v_t(B)\ge \frac{1}{2}v_t(B'\setminus\{g\})\) for every supported pair of bundles and every \(g\in B'\), with complexity independent of an arbitrary clone count.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq2\) goods, with binary-rational per-capita supplies \(0<\beta_g\leq1\). Integral bundles are subsets \(B\subseteq G\), including the empty bundle; \(B_g\) denotes their incidence coordinates.
Each type has a shared hidden additive valuation with \(v_t(g)\in\{h_t,\ell_t\}\), where \(h_t>\ell_t\geq0\) are hidden rationals; either value may be absent. Observable strict rankings order values nonincreasingly, with ties broken by a fixed rule.
A deterministic algorithm may adaptively query \((t,g)\) to learn \(v_t(g)\); each query counts once for type \(t\), regardless of its mass. Let \(L\) bound the total binary encoding length of the public input and hidden valuation profile.
An allocation is an explicitly listed finite-support family of nonnegative rational masses \(x_{t,B}\) satisfying \(\sum_Bx_{t,B}=\mu_t\) and \(\sum_{t,B}x_{t,B}B_g=\beta_g\).
It is \(\tfrac12\)-EFX if, whenever \(x_{t,B}>0\) and \(x_{s,B'}>0\), \(v_t(B)\geq\tfrac12v_t(B'\setminus\{g\})\) for every \(g\in B'\), including when \(s=t\). Empty envied bundles impose no condition.
The algorithm must output such an allocation or correctly report that none exists, for every hidden profile consistent with the rankings. State running times in \(m,\tau,L\) and the query budget, independently of any clone count.

What is the minimum worst-case per-type query bound \(q(m,\tau,L)\) permitting a polynomial-time algorithm for this \(\tfrac12\)-EFX allocation problem, or is this approximation computationally hard even with full valuation information?

For finite societies of \(n\geq2\) agents with personalized bivalued additive valuations, an ordinal algorithm augmented with \(O(\log n)\) value queries per agent computes a complete \(\tfrac12\)-EFX allocation ([source](https://arxiv.org/html/2602.08714v1#S5)).
No result settling this support-wide fairness requirement with rational type masses and per-capita supplies was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to one and interpreted supplies as positive per-capita quantities at most one, consistent with bundles being subsets of distinct goods.
  • Interpreted integral bundles as subsets, allowing empty bundles, rather than multisets; no bundle contains repeated copies of a good.
  • Specified additive valuations with hidden personalized levels h_t > ell_t >= 0, allowing one level to be absent, and fixed tie-breaking for observable rankings.
  • Restricted hidden values to binary rationals and included their encoding length in the bound L so polynomial running time has a bit-model meaning.
  • Interpreted the query budget as a deterministic worst-case maximum for each type, with answers shared across its entire mass.
  • Applied fairness to all positive-mass supported bundle pairs, including distinct bundles assigned within the same type.
  • Allowed a correct infeasibility report because arbitrary per-capita supplies are not covered by the discrete allocation existence guarantee.

Rigorous partial results

The unrestricted problem remains unresolved here: I do not prove polynomial-time solvability or hardness when both $m$ and $\tau$ vary.

The following results substantially narrow it:

  • There is an exact algorithm using $O(\log m)$ queries per type and running in

$$ 2^{O(m+\tau\log(m+1))}\operatorname{poly}(m,\tau,L). $$

  • For every fixed support size $\tau$, the problem is polynomial-time solvable. More precisely, an exact algorithm runs in

$$ (m+1)^{2\tau+O(2^\tau)}\operatorname{poly}(\tau,L) $$
and uses $O(\log m)$ queries per type.

  • For one type under the additional promise $\ell=0$, exactly two queries suffice and are necessary in the worst case, for every $m\geq2$ and sufficiently large $L$.
  • Fully informed feasibility belongs to $\mathrm{NP}$.

All algorithms below produce explicitly listed rational subset bundles. Their bounds do not involve a clone count.

1. Residual values and valuation recovery

For a type $t$, define
$$ R_t(\varnothing)=0,\qquad R_t(C)=\max_{g\in C}v_t(C\setminus\{g\}) \quad\text{if }C\neq\varnothing. $$
By additivity,
$$ R_t(C)=v_t(C)-\min_{g\in C}v_t(g) \quad\text{if }C\neq\varnothing. $$

Let $S$ be the set of bundles used by an allocation, regardless of their recipients. The allocation is $\tfrac12$-EFX exactly when
$$ 2v_t(B)\geq \max_{C\in S}R_t(C) $$
for every positive coordinate $x_{t,B}$.

Indeed, the right-hand side takes the maximum over every required envied bundle and every removed good. Conversely, bounding this maximum implies each required comparison. Including $R_t(\varnothing)=0$ adds only an inequality already implied by nonnegative valuations.

Consequently, deleting supported type–bundle pairs preserves fairness, provided the allocation equations remain satisfied.

Recovering the occurring values

Write a type’s ranking as $g_1,\ldots,g_m$. Query $g_1$ and $g_m$.

If their values agree, nonincreasing order forces every good to have that value. Otherwise, the answers identify the two occurring values, and the high-valued goods form a prefix. Binary search locates its last position using at most $\lceil\log_2(m-1)\rceil$ additional queries.

Thus full recovery needs at most
$$ Q(m)=\min\{m,\;2+\lceil\log_2(m-1)\rceil\} $$
queries per type and polynomial additional computation. This recovery observation also appears in [Section 5 of the cited paper](https://arxiv.org/html/2602.08714v1#S5); the argument above applies directly to the present model.

An absent hidden value need not be recovered. For subsequent computations, a constant positive row of value $c$ can be represented using auxiliary values $h=c$, $\ell=0$, with every good high. An all-zero row can be represented using $h=1$, $\ell=0$, with every good low. These auxiliary representations leave the actual valuation function unchanged.

A fully informed polynomial-time algorithm can therefore be preceded by recovery using $Q(m)$ queries per type. Conversely, an explicitly supplied valuation profile permits direct simulation of a query algorithm. Hence the existence of a polynomial-time algorithm is equivalent in the two information models.

2. Polynomial-size certificates

Proposition. Every feasible instance has a fair allocation with at most $m+\tau$ positive type–bundle pairs. Each positive mass has encoding length
$$ O\bigl(L+(m+\tau)\log(m+\tau)\bigr). $$

Proof. Start with any feasible allocation and restrict attention to its positive coordinates. Its allocation equations are
$$ Ax=b, $$
where $A$ has $r=m+\tau$ rows. A column for $(t,B)$ consists of the unit vector identifying $t$, followed by the incidence vector of $B$. Thus $A$ is a zero–one matrix.

If the retained columns are dependent, choose a nonzero rational vector $z$ with $Az=0$. Summing the type rows gives $\sum_i z_i=0$, so $z$ has both signs. Set
$$ \lambda=\min_{i:z_i>0}\frac{x_i}{z_i} $$
and replace $x$ by $x-\lambda z$. This preserves all equations, keeps every coordinate nonnegative, and removes at least one positive coordinate. No new supported pair appears, so fairness is preserved.

Repeating leaves $k\leq r$ linearly independent columns. Select $k$ rows making their square submatrix $C$ nonsingular.

Let $D$ be the product of the denominators of all public masses and supplies. Then $\log_2D=O(L)$, and every coordinate of $Db$ is an integer between $0$ and $D$. Cramer’s rule represents each remaining mass with denominator $D\det C$ and numerator equal to a determinant having one column from $Db$.

Hadamard’s inequality gives
$$ |\det C|\leq k^{k/2}, $$
and bounds each numerator determinant by $Dk^{k/2}$. This proves the encoding bound. $\square$

A certificate lists these pairs and masses. Exact verification checks the allocation equations and all supported fairness comparisons in polynomial time. Therefore fully informed feasibility belongs to $\mathrm{NP}$.

3. An exact search over residual thresholds

The bivalued promise makes the set of possible residual values small.

For each type $t$, using the representation described in Section 1, define
$$ D_t= \{a h_t+b\ell_t: a,b\in\mathbb Z_{\geq0},\ a+b\leq m-1\}. $$
Then
$$ |D_t|\leq \frac{m(m+1)}2. $$

Every residual $R_t(C)$ belongs to $D_t$. To see this, if $C$ contains a low-valued good, removing a minimum-valued good leaves some number of high and low goods, with total at most $m-1$. If $C$ contains only high-valued goods, its residual is $(|C|-1)h_t$. The empty bundle has residual $0\in D_t$.

Enumerate vectors
$$ \rho=(\rho_1,\ldots,\rho_\tau) \in D_1\times\cdots\times D_\tau. $$
For a fixed vector, call $(t,B)$ admissible when
$$ R_s(B)\leq\rho_s\quad\text{for every type }s, \qquad 2v_t(B)\geq\rho_t. $$

Solve the rational linear feasibility problem consisting of the allocation equations, with nonnegative variables only for admissible pairs.

Soundness. Every used bundle satisfies $R_s(B)\leq\rho_s$ for every observer $s$. Every positive own pair satisfies $2v_t(B)\geq\rho_t$. Hence every required fairness comparison holds.

Completeness. Given a fair allocation with used family $S$, choose
$$ \rho_t=\max_{C\in S}R_t(C). $$
Each $\rho_t$ belongs to $D_t$, and every positive pair is admissible for this vector. Thus its allocation solves one enumerated linear program.

There are at most $(m+1)^{2\tau}$ threshold vectors. For each, the linear program has at most $\tau2^m$ variables and $m+\tau$ allocation equations.

The standard rational linear-programming theorem decides feasibility and returns an exact rational solution in time polynomial in the numbers of variables and constraints and the total binary encoding length. Here every coefficient and right-hand side is rational, of polynomial encoding length in $m,\tau,L$. Its hypotheses therefore hold.

After valuation recovery, the resulting running time is
$$ (m+1)^{2\tau}2^{O(m)} \operatorname{poly}(m,\tau,L) = 2^{O(m+\tau\log(m+1))} \operatorname{poly}(m,\tau,L). $$

This improves the doubly exponential family search, but is not polynomial when both parameters vary.

4. Polynomial time for fixed support size

The preceding search can be compressed by grouping goods that have the same valuation pattern across types.

4.1 Valuation classes and count vectors

Partition the goods into nonempty classes
$$ G_1,\ldots,G_p $$
such that every type assigns the same value to all goods within a class. Each good has a binary high–low pattern across the $\tau$ types, so
$$ p\leq\min\{m,2^\tau\}. $$

Write $n_c=|G_c|$ and let $w_{t,c}$ be type $t$’s value for a good in $G_c$. A bundle is described, for valuation purposes, by its count vector
$$ k=(k_1,\ldots,k_p),\qquad 0\leq k_c\leq n_c. $$
There are
$$ K=\prod_{c=1}^p(n_c+1) $$
such vectors. In particular,
$$ K\leq(m+1)^p, \qquad K\leq2^m, $$
where the second inequality follows from $n_c+1\leq2^{n_c}$.

Define
$$ V_t(k)=\sum_{c=1}^p k_cw_{t,c}. $$
For a nonzero count vector, define
$$ \mathcal R_t(k) = V_t(k)-\min_{c:k_c>0}w_{t,c}, $$
and set $\mathcal R_t(0)=0$.

Every bundle with count vector $k$ has value $V_t(k)$ and residual $\mathcal R_t(k)$.

4.2 A compressed linear program

Fix a threshold vector $\rho$ from Section 3. Retain $(t,k)$ precisely when
$$ \mathcal R_s(k)\leq\rho_s \quad\text{for every }s, \qquad 2V_t(k)\geq\rho_t. $$

For each retained pair introduce:

  • $y_{t,k}$, its total recipient mass;
  • $z_{t,k,g}$, the mass within this group receiving good $g$.

Impose
$$ y_{t,k}\geq0,\qquad 0\leq z_{t,k,g}\leq y_{t,k}, $$
$$ \sum_k y_{t,k}=\mu_t, $$
$$ \sum_{t,k}z_{t,k,g}=\beta_g, $$
and, for every class $G_c$,
$$ \sum_{g\in G_c}z_{t,k,g}=k_cy_{t,k}. $$

These conditions are necessary for an allocation using the retained count vectors: sum its masses within each group and sum its good incidences.

Their sufficiency requires an explicit subset decomposition.

4.3 Rational subset decomposition

Lemma. Suppose $y>0$ and rational numbers $z_g$ satisfy
$$ 0\leq z_g\leq y,\qquad \sum_{g\in G_c}z_g=k_cy $$
for every class, where each $k_c$ is an integer. Then these marginals can be realized by a rational distribution supported on at most $m+1$ bundles, each containing exactly $k_c$ goods from $G_c$.

Proof. Put $p_g=z_g/y$. Order each class arbitrarily. For its ordered goods, define cumulative sums
$$ P_{c,0}=0,\qquad P_{c,i}=\sum_{j=1}^i p_{g_{c,j}}. $$
The final sum is $P_{c,n_c}=k_c$.

For $u\in[0,1)$, include $g_{c,i}$ if its interval
$$ [P_{c,i-1},P_{c,i}) $$
contains a point $u+j$ for an integer $j$.

The interval has length $p_{g_{c,i}}\leq1$, so it contains at most one such point. The intervals partition $[0,k_c)$, which contains exactly $k_c$ points of the form $u+j$. Consequently, exactly $k_c$ goods are selected from the class.

The measure of values of $u$ selecting a particular good is its interval length, namely $p_g$. Indeed,
$$ \int_0^1 \sum_{j\in\mathbb Z} \mathbf 1_{[P_{c,i-1},P_{c,i})}(u+j)\,du = P_{c,i}-P_{c,i-1}. $$
Because the sum takes only values $0$ and $1$, this is the inclusion probability.

Use the same parameter $u$ for every class. The bundle changes only at fractional parts of cumulative sums. There are at most $m$ such points, apart from the endpoints $0$ and $1$, so $[0,1)$ has at most $m+1$ intervals of constant bundle membership.

All breakpoints are rational. Assign each interval’s length to its bundle, ignoring the endpoints of measure zero. Multiplying by $y$ realizes the required masses $z_g$. Sorting the breakpoints and constructing the bundles uses polynomially many exact rational operations. $\square$

4.4 Correctness and running time

Apply the lemma separately to every positive $y_{t,k}$. If $y_{t,k}=0$, the inequalities force every corresponding $z_{t,k,g}$ to be zero.

The resulting bundles have the prescribed count vectors. Therefore they satisfy all the threshold inequalities, and Section 3 proves fairness. The linear equations give the required type masses and supplies exactly.

Conversely, grouping any feasible allocation by recipient type and count vector produces a feasible solution of this compressed program. Thus the compressed search is sound and complete.

Each program has at most
$$ \tau K(m+1) $$
variables and polynomially many constraints in $m,\tau,K$. Its coefficients are integers bounded by $m$, together with the public rational masses and supplies. Rational linear programming therefore applies with polynomial bit complexity in these quantities and $L$.

The complete running time is
$$ (m+1)^{2\tau}\operatorname{poly}(m,\tau,K,L). $$
Using $K\leq(m+1)^{2^\tau}$ gives
$$ (m+1)^{2\tau+O(2^\tau)} \operatorname{poly}(\tau,L). $$

This is polynomial in $m$ and $L$ for every fixed $\tau$. Recovery uses at most $Q(m)$ queries per type. The decomposition produces an explicit allocation with at most $\tau K(m+1)$ listed positive pairs before merging duplicates.

Thus fully informed hardness, if established, must involve unbounded support size unless $\mathrm{P}=\mathrm{NP}$.

5. Fixed numbers of goods and the corrected earlier bound

For completeness, the family-enumeration method also gives polynomial time for every fixed $m$, even when $\tau$ varies.

Enumerate nonempty families $S\subseteq2^G$. For each family, allow $(t,B)$ only when
$$ B\in S,\qquad 2v_t(B)\geq\max_{C\in S}R_t(C), $$
and solve the allocation equations on these variables.

Any solution is fair because its actual used family is contained in $S$. Conversely, the actual used family of any fair allocation occurs in the enumeration and makes all its positive pairs eligible.

There are fewer than $2^{2^m}$ families. Each linear program has at most $\tau2^m$ variables and polynomial encoding length in its expanded dimensions and $L$. The justified running-time bound is therefore
$$ 2^{2^m+O(m)}\operatorname{poly}(m,\tau,L). $$

The additional $2^{O(m)}$ factor cannot be absorbed into $\operatorname{poly}(m,\tau,L)$. This repairs the bound identified by the verifier.

In particular, when $m=2$, this algorithm is polynomial in $\tau,L$ and uses two queries per type.

6. One type with zero low value: an exact characterization

Assume now that $\tau=1$ and, additionally, that the hidden values are $h>0$ and $\ell=0$. Either value may be absent.

Let $H$ be the set of high-valued goods, and define
$$ A=\sum_{g\in H}\beta_g, \qquad M=\max_{g\notin H}\beta_g, $$
where the maximum over an empty set is $0$.

Theorem. A fair allocation exists exactly when
$$ A\geq1 \quad\text{or}\quad A+M\leq1. $$

Necessity when $A<1$

The expected number of high goods in a bundle is $A$. If every positive bundle contained a high good, this expectation would be at least $1$. Thus some positive bundle has value zero.

Fairness from this bundle requires every used bundle $C$ to satisfy $R(C)=0$. A bundle containing a high good and any other good has positive residual: remove that other good, leaving the high good. Therefore every high-containing bundle must be a singleton.

The singleton for high good $g$ must have mass $\beta_g$. Their total mass is $A$. All other bundles lie within the low-good set and have total mass $1-A$. Hence every low good satisfies
$$ \beta_g\leq1-A. $$
Equivalently, $A+M\leq1$.

Sufficiency when $A<1$

Assign each high good its singleton mass $\beta_g$. On the remaining mass $1-A$, distribute low goods with conditional marginals
$$ \frac{\beta_g}{1-A}\in[0,1]. $$
For example, take a common parameter $u\in[0,1)$ and include low good $g$ when $u<\beta_g/(1-A)$. Sorting these rational thresholds produces a finite rational distribution.

Every used bundle has residual zero: it is either a high singleton or contains only zero-valued goods. Thus the allocation is fair.

Sufficiency when $A\geq1$

Order the high goods and apply the interval construction from Section 4 with interval lengths $\beta_g$. The final cumulative sum is now $A$, possibly nonintegral. Every selected high-good set has cardinality either $\lfloor A\rfloor$ or $\lceil A\rceil$, and each high good has marginal $\beta_g$.

Include each low good when $u<\beta_g$, using the same parameter. This preserves its marginal without changing high-good counts.

Put $a=\lfloor A\rfloor\geq1$. Every positive own bundle has value at least $ah$, and every used bundle has value at most $(a+1)h$. Since
$$ a+1\leq2a, $$
we have, for every pair of used bundles,
$$ 2v(B)\geq v(C)\geq R(C). $$
The allocation is fair. Rational breakpoints again give an explicit polynomial-size allocation. $\square$

7. Exactly two queries in this one-type subclass

The preceding characterization can be used without recovering the high–low transition.

Write the ranking as $g_1,\ldots,g_m$. The actual high set is a prefix of some length $k\in\{0,\ldots,m\}$. From the public supplies define
$$ A_j=\sum_{i=1}^j\beta_{g_i}, \qquad M_j=\max_{i>j}\beta_{g_i}, \qquad f_j=A_j+M_j, $$
with $A_0=0$ and $M_m=0$.

Let
$$ r=\min\{j:A_j\geq1\}, $$
taking $r=m+1$ if this set is empty.

The sequence $f_j$ is nondecreasing. Indeed, for $0\leq j<m$,
$$ M_j=\max\{\beta_{g_{j+1}},M_{j+1}\}, $$
so
$$ f_{j+1}-f_j = \beta_{g_{j+1}}+M_{j+1} -\max\{\beta_{g_{j+1}},M_{j+1}\} = \min\{\beta_{g_{j+1}},M_{j+1}\} \geq0. $$

Define
$$ s=\max\{j:0\leq j\leq m,\ j<r,\ f_j\leq1\}. $$
This set is nonempty because $f_0=\max_g\beta_g\leq1$.

The characterization in Section 6 now says that the feasible transition lengths are precisely
$$ k\leq s \quad\text{or}\quad k\geq r. $$

Identifying the feasible regime

If $s=m$, every possible profile belongs to the first regime and no query is needed.

Otherwise query $g_{s+1}$.

  • An answer of zero implies $k\leq s$.
  • A positive answer implies $k\geq s+1$. If $r=m+1$, the instance is infeasible. Otherwise query $g_r$, unless it was already queried. A positive answer implies $k\geq r$; a zero answer implies $s<k<r$, which is infeasible.

This uses at most two queries.

Producing an allocation without knowing $k$

For the regime $k\leq s$, assign every good in the prefix of length $s$ its singleton mass $\beta_g$. The remaining mass is $1-A_s>0$. Since
$$ A_s+M_s\leq1, $$
the suffix supplies can be realized within that remaining mass.

All actual high goods lie in the singleton prefix. Every suffix good has value zero. Thus every used residual is zero.

For the regime $k\geq r$, use the interval construction on all goods, in ranking order, with interval lengths $\beta_{g_i}$. For every prefix length $j$, its selected cardinality is either $\lfloor A_j\rfloor$ or $\lceil A_j\rceil$. This holds simultaneously for all prefixes because the intervals for the first $j$ goods partition $[0,A_j)$.

In particular, the actual high-prefix count is between $\lfloor A_k\rfloor$ and $\lceil A_k\rceil$. Since $k\geq r$, we have $A_k\geq1$, and the fairness calculation from Section 6 applies.

Both constructions have polynomially many rational breakpoints and run in $\operatorname{poly}(m,L)$ time.

Two queries are necessary

Fix supplies
$$ \beta_g=\frac34 \quad\text{for every good}. $$
Choose the public ranking to be the fixed tie order $g_1,\ldots,g_m$. Consider three profiles with values in $\{1,0\}$:

  • no high goods;
  • only $g_1$ high;
  • exactly $g_1,g_2$ high.

They share the ranking. By Section 6, the first is feasible, the second is infeasible because $A=M=\tfrac34$, and the third is feasible because $A=\tfrac32$.

A deterministic algorithm using at most one query chooses its queried good from the common public input.

If it queries $g_1$, the second and third profiles both answer $1$. If it queries any other good, the first and second profiles both answer $0$. In either case it cannot distinguish a feasible profile from an infeasible one.

Therefore two queries are necessary, even if the two possible values $1$ and $0$ are known in advance. Together with the algorithm above, this proves the exact worst-case bound of two queries for this subclass, for every $m\geq2$ and sufficiently large $L$.

8. What is established about the original query bound

For the original problem with one type, the fixed-support algorithm proves polynomial-time solvability. The lower bound just proved applies to this larger valuation class, while full recovery supplies the upper bound. Thus, for sufficiently large $L$,
$$ 2\leq q(m,1,L)\leq Q(m). $$
In particular,
$$ q(2,1,L)=2. $$

For arbitrary $\tau$, a polynomial-time algorithm exists for every fixed $m$, and for every fixed $\tau$. When both vary, the exact threshold search gives the stated exponential algorithm and fully informed feasibility lies in $\mathrm{NP}$.

What remains unresolved is the unrestricted complexity classification and, where polynomial-time solvability holds, the minimum query budget for general bivalued valuations with possibly positive low values.
