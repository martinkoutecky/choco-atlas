The anchor (named result in the paper)

Theorem 1 — class: other

The continuous mirror question, as graded

Given a finite type set \(T\), a compatibility graph \(H\), rational type masses \(\mu_t>0\) summing to \(1\), and integer per-agent capacities \(b_t\), consider a nonatomic population in which every agent of type \(t\) can exchange with every agent of each compatible type; exchanges remain integral for each individual, including exchanges between distinct agents of the same type. Find a feasible assignment of population mass to integral exchange patterns that maximizes total exchanges and whose per-capita expected utility profile Lorenz-dominates that of every other maximum-exchange assignment. Equivalently, for an aggregate exchange plan \(x\), set \(d_t(x)=\sum_{s\ne t:\{t,s\}\in F}x_{ts}+2\mathbf{1}_{\{\{t,t\}\in F\}}x_{tt}\) and \(u_t=d_t(x)/\mu_t\); require a maximum plan to maximize \(L_u(q)=\min\{\sum_t a_tu_t:0\le a_t\le\mu_t,\ \sum_t a_t=q\}\) for every \(q\in[0,1]\), among all feasible maximum plans.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(T\) lists the \(\tau\) types with positive masses \(\mu_t\), encoded as binary rationals with \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
The input also contains an undirected compatibility graph \(H=(T,F)\), allowing loops, and positive integer capacities \(b_t\) encoded in binary. Write \(m=|F|\) and let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
Each type is a nonatomic population. Compatible agents may exchange any number of units, subject to their individual capacities; every unit exchanged gives each endpoint one unit of utility. There are no edge capacities, and self-exchange is forbidden; a loop permits exchanges between distinct agents of the same type.
An integral pattern for type \(t\) is \(k\in\mathbb Z_{\geq0}^{T}\) with \(\sum_s k_s\leq b_t\) and \(k_s=0\) whenever \(\{t,s\}\notin F\). Denote the set of these patterns by \(K_t\).
An assignment consists of nonnegative pattern masses \(z_{t,k}\), with \(\sum_{k\in K_t}z_{t,k}=\mu_t\). Its exchange endpoints must be paired between compatible distinct agents: writing \(y_{ts}=\sum_{k\in K_t}z_{t,k}k_s\), require \(y_{ts}=y_{st}\) for distinct types; same-type endpoints are paired within that type.
The aggregate plan has \(x_{ts}=y_{ts}\) for distinct compatible types and \(x_{tt}=y_{tt}/2\) for loops. Its total exchanges are \(M(x)=\sum_{\{t,s\}\in F}x_{ts}\), counting each unordered pair once.
Define \(d_t(x)=\sum_{s\ne t:\{t,s\}\in F}x_{ts}+2\mathbf1_{\{t,t\}\in F}x_{tt}\), \(u_t=d_t(x)/\mu_t\), and \(L_u(q)=\min\{\sum_t a_tu_t:0\leq a_t\leq\mu_t,\ \sum_ta_t=q\}\).
The required assignment maximizes \(M(x)\) and satisfies \(L_u(q)\geq L_v(q)\) for every \(q\in[0,1]\) and every utility profile \(v\) induced by another maximum-exchange assignment. Fairness compares type-average expected utilities, weighted by population mass.

Is finding such an assignment, or determining that none exists, solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite uncapacitated networks with indivisible exchanges, the egalitarian expected utility profile is realizable by a lottery over integral maximum \(b\)-matchings, obtained through an LP decomposition ([Chandramouli–Sethuraman](https://arxiv.org/pdf/2002.02749)).
For finite unit-capacity pairwise exchange, an egalitarian lottery has a Lorenz-dominant utility profile ([Roth–Sönmez–Ünver](https://web.stanford.edu/~alroth/papers/pairedexchange.pdf)). No result settling this exact nonatomic computational problem was located.

Modeling choices made when packaging the task

  • Restricted the unspecified integer capacities to positive integers, following the discrete model, and specified binary encoding.
  • Specified uncapacitated pairwise exchanges, allowing repeated unit exchanges between the same compatible agents, as in the anchor's model.
  • Defined feasibility through integral individual patterns, population masses, and pairing of exchange endpoints; type loops permit exchanges between distinct agents only.
  • Retained the graded question's fairness criterion on type-average expected utilities rather than realized individual utilities.
  • Included determining nonexistence because the continuous question does not establish that a universally Lorenz-dominant maximum assignment exists.
  • Defined m as the number of compatibility edges, including loops, and L as the total input bit length.

Result

The problem is solvable in polynomial time in \(m,\tau,L\). An exact algorithm uses \(O(\tau^2)\) rational linear programs, each of polynomial encoding length and with \(O(m+\tau)\) variables and constraints. Its bit running time is therefore

\( \displaystyle O\!\left(\tau^2\operatorname{poly}(m+\tau,L)\right). \)

It returns either the required assignment or a correct determination that no such assignment exists. A returned assignment needs at most \(2m+\tau\) nonzero integral patterns.

The proof has three parts: characterize aggregate feasibility, construct the only possible Lorenz-dominant profile, and test that candidate by finitely many linear programs.

1. Aggregate feasibility is exactly a linear polytope

Put \(c_t=\mu_t b_t\), and define

\( \displaystyle P=\left\{x\in\mathbb R_{\geq0}^{F}:d_t(x)\leq c_t\text{ for every }t\in T\right\}. \)

Claim. An aggregate plan is induced by an admissible assignment if and only if it belongs to \(P\).

For necessity, an assignment satisfies

\( \displaystyle d_t(x)=\sum_{k\in K_t}z_{t,k}\sum_s k_s \leq b_t\sum_{k\in K_t}z_{t,k}=\mu_t b_t. \)

For sufficiency, take \(x\in P\). Define its directed endpoint quantities by

\( \displaystyle y_{ts}=x_{ts}\quad(s\neq t),\qquad y_{tt}=2x_{tt} \)

whenever the corresponding edge exists, and use zero otherwise. For each compatible \(s\), assign mass

\( \displaystyle z_{t,b_te_s}=\frac{y_{ts}}{b_t} \)

to the integral pattern \(b_te_s\). Assign the remaining mass to the zero pattern:

\( \displaystyle z_{t,0}=\mu_t-\frac{d_t(x)}{b_t}\geq0. \)

These masses sum to \(\mu_t\) and produce exactly the endpoint quantities \(y_{ts}\).

We must also verify that the endpoints can be paired between distinct agents. Represent each allocated population group by an interval of its mass.

For a distinct-type edge, the relevant groups have masses \(a=y_{ts}/b_t\) and \(a'=y_{st}/b_s\), so \(b_ta=b_sa'=x_{ts}\). Represent the endpoints of the first group by

\( \displaystyle [0,a)\times\{0,\ldots,b_t-1\}, \)

with population measure on each layer. The map \((r,j)\mapsto ja+r\) identifies this endpoint space with \([0,x_{ts})\), preserving measure. The corresponding map for the other group does the same. Pair endpoints having the same interval coordinate. Every agent uses exactly its assigned number of units, and paired agents have different types.

For a loop, divide the group assigned pattern \(b_te_t\) into two equal populations. Pair corresponding agents across the two halves, exchanging \(b_t\) units per pair. The agents are distinct, and the resulting exchange mass is \(y_{tt}/2=x_{tt}\).

Thus \(P\) is the exact aggregate feasible set. The interval maps give compact pairing descriptions; capacities need not be expanded into individual units.

The polytope \(P\) is nonempty and compact: zero is feasible, and every edge variable is bounded by an incident type’s capacity constraint. Compute

\( \displaystyle M^*=\max_{x\in P}\sum_{e\in F}x_e,\qquad P^*=\left\{x\in P:\sum_{e\in F}x_e=M^*\right\}. \)

The maximum-exchange utility profiles form the nonempty compact convex rational polytope

\( \displaystyle \mathcal U=\left\{u:\exists x\in P^*,\ \mu_tu_t=d_t(x)\text{ for every }t\right\}. \)

Every \(u\in\mathcal U\) has the same weighted total:

\( \displaystyle \sum_t\mu_tu_t=2M^*. \)

2. A useful equivalent formulation of Lorenz dominance

For any utility profile \(u\), define

\( \displaystyle D_u(h)=\sum_t\mu_t(h-u_t)_+,\qquad (r)_+=\max\{r,0\}. \)

The following identities hold:

\( \displaystyle D_u(h)=\max_{0\leq q\leq1}\{hq-L_u(q)\}, \)

\( \displaystyle L_u(q)=\sup_{h\in\mathbb R}\{hq-D_u(h)\}. \)

To prove the first identity, maximize \(\sum_t a_t(h-u_t)\) over all \(0\leq a_t\leq\mu_t\). Maximizing separately in each coordinate gives \(D_u(h)\). Grouping feasible choices by \(q=\sum_ta_t\) gives the displayed expression.

For the second identity, every feasible choice of the \(a_t\) with total \(q\) satisfies

\( \displaystyle \sum_ta_tu_t\geq hq-\sum_t\mu_t(h-u_t)_+=hq-D_u(h). \)

Equality is achieved by choosing a cutoff \(h\), taking all population below that cutoff, none above it, and enough population at the cutoff to reach \(q\). Such a cutoff exists by ordering the finitely many utility levels. The endpoint cases use a cutoff below all utilities or above all utilities.

Consequently,

\( \displaystyle L_u(q)\geq L_v(q)\text{ for every }q \quad\Longleftrightarrow\quad D_u(h)\leq D_v(h)\text{ for every }h. \)

This equivalence uses the population weights exactly as specified in the question.

3. Constructing the only possible Lorenz-dominant profile

We construct a candidate by successive max–min optimization. Its definition does not assume that a Lorenz-dominant profile exists.

Initially let \(C_0=\mathcal U\), with every coordinate active. At stage \(j\), let \(R\) denote the remaining active coordinates and compute

\( \displaystyle \lambda_j=\max_{u\in C_{j-1}}\min_{t\in R}u_t. \)

This is a linear program: introduce a variable \(\lambda\) and impose \(u_t\geq\lambda\) for every active \(t\). Define the optimal face

\( \displaystyle C_j=\{u\in C_{j-1}:u_t\geq\lambda_j\text{ for every }t\in R\}. \)

Identify the forced coordinates

\( \displaystyle S_j=\left\{t\in R:\max_{u\in C_j}u_t=\lambda_j\right\}. \)

Each membership test is another linear program. Every coordinate in \(S_j\) equals \(\lambda_j\) throughout \(C_j\); remove these coordinates from the active set.

The set \(S_j\) is nonempty. Otherwise, for every active coordinate there would be a point in \(C_j\) at which that coordinate exceeds \(\lambda_j\). Averaging those points would give a point at which every active coordinate exceeds \(\lambda_j\), contradicting its optimality.

The same averaging argument shows that, if active coordinates remain, there is a point in \(C_j\) at which all of them exceed \(\lambda_j\). Thus the successive levels are strictly increasing.

After at most \(\tau\) stages, every coordinate is fixed. Denote the resulting profile by \(u^*\), with levels

\( \displaystyle \lambda_1<\cdots<\lambda_r,\qquad u_t^*=\lambda_j\text{ for }t\in S_j. \)

Why every Lorenz-dominant profile must equal this candidate

Suppose \(w\in\mathcal U\) Lorenz-dominates every profile in \(\mathcal U\). We prove inductively that its successive level sets are exactly the sets \(S_j\) above.

At a stage, let \(F\) be the previously fixed coordinates. By induction, \(w\) agrees with their fixed utilities, and its remaining coordinates have strictly greater utility than all coordinates in \(F\). Set

\( \displaystyle p=\sum_{t\in F}\mu_t,\qquad W_F=\sum_{t\in F}\mu_tw_t,\qquad \beta=\min_{t\in R}w_t. \)

Because \(w\in C_{j-1}\), the definition of \(\lambda_j\) gives \(\beta\leq\lambda_j\). If \(\beta<\lambda_j\), choose \(v\in C_j\). For sufficiently small positive \(\varepsilon\),

\( \displaystyle L_w(p+\varepsilon)=W_F+\beta\varepsilon,\qquad L_v(p+\varepsilon)\geq W_F+\lambda_j\varepsilon. \)

This contradicts Lorenz dominance. Therefore \(\beta=\lambda_j\), and \(w\in C_j\).

Let \(B=\{t\in R:w_t=\lambda_j\}\). Forced coordinates imply \(S_j\subseteq B\). There is a profile \(v\in C_j\) whose coordinates outside \(S_j\) all exceed \(\lambda_j\), by averaging the witnesses used above.

If \(B\setminus S_j\) were nonempty, choose

\( \displaystyle 0<\varepsilon<\sum_{t\in B\setminus S_j}\mu_t,\qquad q=p+\sum_{t\in S_j}\mu_t+\varepsilon. \)

Then

\( \displaystyle L_w(q)=W_F+\lambda_j\left(\sum_{t\in S_j}\mu_t+\varepsilon\right), \)

whereas \(L_v(q)\) is strictly greater: after the fixed populations \(F\) and \(S_j\), all remaining utilities of \(v\) exceed \(\lambda_j\). This is again a contradiction. Hence \(B=S_j\).

The induction proves \(w=u^*\). Therefore, if the candidate fails Lorenz dominance, no required assignment exists.

4. Testing the candidate with at most one LP per level

For \(j<r\), define the strict level prefixes

\( \displaystyle A_j=S_1\cup\cdots\cup S_j,\qquad c_j^*=\sum_{t\in A_j}\mu_tu_t^*. \)

Compute

\( \displaystyle C_j^*=\max_{x\in P^*}\sum_{t\in A_j}d_t(x). \)

The candidate is feasible, so \(C_j^*\geq c_j^*\). The exact test is

\( \displaystyle u^*\text{ is Lorenz-dominant in }\mathcal U \quad\Longleftrightarrow\quad C_j^*=c_j^*\text{ for every }j<r. \)

Necessity

Suppose one equality fails. Choose a profile \(v\in\mathcal U\) with

\( \displaystyle \Delta=\sum_{t\in A_j}\mu_t(v_t-u_t^*)>0, \)

and choose \(h\) strictly between \(\lambda_j\) and \(\lambda_{j+1}\). By convexity,

\( \displaystyle u^\theta=(1-\theta)u^*+\theta v\in\mathcal U. \)

For sufficiently small positive \(\theta\), the coordinates below \(h\) remain exactly those in \(A_j\). Hence

\( \displaystyle D_{u^\theta}(h)=D_{u^*}(h)-\theta\Delta<D_{u^*}(h). \)

The equivalence in Section 2 shows that \(u^*\) does not Lorenz-dominate \(u^\theta\).

Sufficiency

Suppose all equalities hold. For arbitrary \(h\), let

\( \displaystyle A(h)=\{t:u_t^*<h\}. \)

This is an empty set, one of the tested prefixes, or all of \(T\). In every case, \(u^*\) maximizes \(\sum_{t\in A(h)}\mu_tu_t\) over \(\mathcal U\): for the full set, this follows from the fixed weighted total.

For any \(v\in\mathcal U\),

\( \displaystyle D_v(h) \geq\sum_{t\in A(h)}\mu_t(h-v_t) \geq\sum_{t\in A(h)}\mu_t(h-u_t^*) =D_{u^*}(h). \)

Thus \(D_{u^*}(h)\leq D_v(h)\) for every \(h\), proving the required Lorenz dominance.

This is a test of the entire Lorenz curve, including every population quantile.

5. Exact bit complexity and assignment output

There is one LP for \(M^*\), at most \(\tau\) max–min LPs, at most \(\tau^2\) forced-coordinate LPs, and at most \(\tau-1\) prefix-test LPs. A final feasibility LP can recover \(x^*\in P^*\) inducing \(u^*\).

All have \(O(m+\tau)\) variables and constraints. Previous stages can be represented by fixed coordinates and a single current lower bound for each remaining coordinate, so constraints need not accumulate quadratically.

We also need a bit-length bound for the successive levels. The first optimum \(M^*\) has polynomial encoding length by the usual rational-polytope vertex bound. To bound the levels without assuming that repeated optimization preserves bit length, fix the groups already identified before stage \(j\), and consider the bounded rational polytope with variables \(x,u,a_1,\ldots,a_j\) and constraints

\( \displaystyle x\in P^*,\qquad \mu_tu_t=d_t(x),\qquad 0\leq a_1\leq\cdots\leq a_j\leq\max_tb_t, \)

\( \displaystyle u_t=a_i\quad(t\in S_i,\ i<j),\qquad u_t\geq a_j\quad(t\text{ still active}). \)

Its coefficients come from the original input and \(M^*\). Its lexicographically maximal tuple \((a_1,\ldots,a_j)\) is exactly \((\lambda_1,\ldots,\lambda_j)\):

  • Maximizing \(a_1\) cannot exceed the original first max–min optimum.
  • After fixing earlier optima, maximizing \(a_i\) cannot exceed the corresponding stage optimum.
  • A stage-\(j\) optimal profile attains all these bounds simultaneously.

Successive linear optimization defines a nonempty face of this bounded polytope, containing a vertex. Therefore all the levels occur as coordinates of a vertex of a polytope with polynomial encoding length and \(O(m+\tau)\) variables. Cramer’s rule and the determinant bound give polynomial encoding lengths for every \(\lambda_i\).

Consequently every LP used by the algorithm has polynomial encoding length. Exact rational LP feasibility and optimization are polynomial-time solvable; all these LPs are nonempty with bounded objectives, so the theorem applies. See [Khachiyan’s polynomial-time linear programming theorem](https://www.mathnet.ru/eng/zvmmf5239).

The overall bit running time is therefore

\( \displaystyle O\!\left(\tau^2\operatorname{poly}(m+\tau,L)\right). \)

If every prefix test passes, recover \(x^*\) and output the pattern masses from Section 1. There is at most one nonzero full-capacity pattern per directed compatibility incidence, plus one zero pattern per type, giving at most \(2m+\tau\) nonzero patterns. Their masses, integer entries, and compact pairing descriptions all have polynomial encoding length.

If a prefix test fails, Section 4 proves that the candidate is not Lorenz-dominant, and Section 3 proves that no other profile can be Lorenz-dominant. Thus either outcome is correct.
