The continuous mirror question, as graded

Given \(\tau\) nonatomic valuation types \(\nu_t\) on \([0,1]\), rational proportions \(\mu_t\), and population scale \(N\), can a deterministic Robertson–Webb procedure output finite-union bundles \(B_{tj}\) and cohort masses \(\lambda_{tj}>0\) such that \(\sum_j\lambda_{tj}=N\mu_t\), \(\sum_{t,j}\lambda_{tj}\mathbf{1}_{B_{tj}}(x)=1\) almost everywhere, and each type has a common bundle value \(\nu_t(B_{tj})=u_t\geq 1/N\), with values invariant under relabelling? What query complexity is achievable in \(\tau\), mass bit length \(L\), \(\log N\), and output size?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\geq1\) distinct nonatomic probability measures \(\nu_t\) on the cake \([0,1]\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total mass bit length. The population scale \(N\geq1\) is a binary-encoded integer; \(N\mu_t\) need not be integral. The cake has one component, so \(m=1\).
Valuations are accessed through exact Robertson–Webb queries, with cuts returning the leftmost valid cutpoint. Count oracle queries and exact arithmetic/comparison operations separately, treating each as unit cost.
Output finitely many cohorts for each type, with real masses \(\lambda_{tj}>0\) and bundles \(B_{tj}\) that are finite unions of intervals, satisfying \(\sum_j\lambda_{tj}=N\mu_t\), \(\sum_{t,j}\lambda_{tj}\mathbf{1}_{B_{tj}}(x)=1\) for Lebesgue-almost every \(x\), and \(\nu_t(B_{tj})=u_t\geq1/N\) for every cohort of type \(t\). Bundles may overlap; the weighted coverage equation defines feasibility.
Symmetry means that permuting the support entries, carrying their measures and masses together, preserves each corresponding value \(u_t\). Let \(S\) count output cohort records and interval endpoints, represented as exact scalars.

Does this construction problem admit a deterministic polynomial-time Robertson–Webb algorithm, or is it NP-hard even for binary-rational piecewise-constant valuation densities? What query complexity is achievable in \(\tau,L,\log N,S\), with operation bounds also accounting for any explicit valuation encoding length?

  • Normalized the positive rational proportions to sum to one and interpreted the support as distinct valuation types.
  • Took N to be a positive binary-encoded integer, corresponding to the discrete population count, without requiring integral type populations.
  • Allowed positive real cohort masses and overlapping bundles, retaining the graded question's weighted coverage definition.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem has a deterministic algorithm whose query count and operation count are polynomial in the output size \(S\). It works for arbitrary nonatomic valuations and does not require integral population masses.

A running-time bound polynomial only in \(\tau,L,\log N\) is impossible with the required explicit output, because some instances require at least \(N\) cohort records.

Construction and proof. For each type \(t\), independently construct a partition of the entire cake into \(N\) intervals of equal \(\nu_t\)-value.

Set \(x_{t,0}=0\) and \(x_{t,N}=1\). For each \(j\in\{1,\ldots,N-1\}\), ask the Robertson–Webb cut query with starting point \(0\) and target value \(j/N\), obtaining \(x_{t,j}\).

To verify that these queries are valid, define \(F_t(x)=\nu_t([0,x])\). Nonatomicity implies that \(F_t\) is continuous, with \(F_t(0)=0\) and \(F_t(1)=1\). Thus every target \(j/N\) is attained. Moreover, distinct increasing targets have strictly increasing cutpoints, regardless of any intervals on which \(F_t\) is constant. The stipulated leftmost-cut convention therefore determines valid endpoints.

Output, for each \(t\) and \(j\in\{1,\ldots,N\}\), the cohort

\[ \lambda_{tj}=\mu_t,\qquad B_{tj}=[x_{t,j-1},x_{t,j}]. \]

All masses are positive. For each type, their sum is

\[ \sum_{j=1}^{N}\lambda_{tj}=N\mu_t. \]

Because interval endpoints have zero \(\nu_t\)-measure, every cohort has value

\[ \nu_t(B_{tj})=F_t(x_{t,j})-F_t(x_{t,j-1})=\frac1N. \]

Outside the finite set of all partition endpoints, exactly one bundle of each type contains \(x\). Consequently,

\[ \sum_{t=1}^{\tau}\sum_{j=1}^{N}\lambda_{tj}\mathbf1_{B_{tj}}(x) =\sum_{t=1}^{\tau}\mu_t=1. \]

This proves the required coverage equation for Lebesgue-almost every \(x\).

Finally, every type receives the value \(u_t=1/N\), independently of the ordering of the support entries. Hence the construction is symmetric. When \(N=1\), the same construction uses the whole cake for every type and requires no queries.

Complexity. The algorithm makes exactly \(\tau(N-1)\) cut queries and no evaluation queries. It outputs \(\tau N\) cohort records, each containing one interval, so \(S=\Theta(\tau N)\). Its bounds are therefore:

  • Robertson–Webb queries: \(O(S)\).
  • Exact arithmetic/comparison operations, including reading the numerical input and writing the output: \(O(L+\log N+S)\).

These bounds use precisely the stipulated unit-cost model for exact scalars.

If the valuations instead have explicit piecewise-constant densities, no oracle queries are necessary. In the standard encoding listing consecutive density intervals, compute cumulative masses and scan through them while locating the increasing targets \(j/N\). Within a positive-density interval \([a,b]\), with density \(d\) and cumulative mass \(c\) at \(a\), the target \(q\) has cutpoint \(a+(q-c)/d\). Zero-density intervals can be skipped, retaining the earliest endpoint when a target equals an already attained cumulative mass. Thus, for total valuation encoding length \(E\), the operation bound is \(O(E+L+\log N+S)\).

Why output size must appear. Suppose all valuations are absolutely continuous with respect to Lebesgue measure. Every output bundle has positive valuation, hence positive Lebesgue measure. The coverage equation then forces each cohort mass to satisfy \(\lambda_{tj}\leq1\): otherwise coverage would exceed \(1\) on a positive-measure subset of its bundle.

Writing \(K_t\) for the number of cohorts of type \(t\), it follows that

\[ K_t\geq\lceil N\mu_t\rceil,\qquad \sum_tK_t\geq N. \]

In particular, a single uniform valuation already requires at least \(N\) cohort records, although \(N\) is encoded using only \(O(\log N)\) bits.

Thus the intended output-sensitive question is completely settled by the construction above. A polynomial-time bound excluding \(S\) fails because of unavoidable output length.
