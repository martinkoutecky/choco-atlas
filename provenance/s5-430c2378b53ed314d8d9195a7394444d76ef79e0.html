The continuous mirror question, as graded

Given \(r\) regions, a finite support \(T\) of incumbent types with rational masses \(\mu_t\) summing to \(1\), each type’s home region \(k(t)\) and nonnegative benefits \(b_t^k\) (zero outside its home region), and entrant benefits \(\beta^k\) normalized per incumbent, compute the limiting EOL allocation. For each region set \(G_k=\beta^k+\sum_{t\in T}\mu_t b_t^k\); let \(k^\ast\in\operatorname{argmax}_k G_k\), \(G=\max_k G_k\), \(S=\max_{k\ne k^\ast}G_k\), \(I=\max(\beta^{k^\ast},S)\), and \(q=\sum_{t:k(t)=k^\ast}\mu_t\). If the optimum is unique and \(q>0\), return entrant allocation \(I\), per-incumbent allocation \(y_t=(G-I)/q\) for types in \(k^\ast\), and \(y_t=0\) otherwise. If the optimum is tied or \(q=0\), return entrant allocation \(G\) and \(y_t=0\) for all types. The output satisfies \(I+\sum_t\mu_t y_t=G\) in the unique, positive-mass case.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) incumbent types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=r\geq2\) regions. Each type has a home region \(k(t)\) and nonnegative binary rational benefits \(b_t^k\), with \(b_t^k=0\) outside its home region. Entrant benefits \(\beta^k\) are nonnegative binary rationals normalized per incumbent; regions may have zero incumbent mass. Let \(L\) be the total input bit length.
Define \(G_k=\beta^k+\sum_t\mu_t b_t^k\), choose any \(k^\ast\in\operatorname{argmax}_kG_k\), and put \(G=G_{k^\ast}\), \(S=\max_{k\ne k^\ast}G_k\), \(I=\max\{\beta^{k^\ast},S\}\), and \(q=\sum_{t:k(t)=k^\ast}\mu_t\).
The limiting egalitarian optimal location (EOL) allocation consists of entrant allocation \(x_0\) and incumbent payoff densities \(y_t\). If the maximizing region is unique and \(q>0\), it is defined by \(x_0=I\), \(y_t=(G-I)/q\) for \(k(t)=k^\ast\), and \(y_t=0\) otherwise. If the maximum is tied or \(q=0\), it is \(x_0=G\) and \(y_t=0\) for every type.
Thus type \(t\) receives total allocation \(\mu_t y_t\), and \(x_0+\sum_t\mu_t y_t=G\).

Is exact computation of this limiting EOL allocation possible in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finitely many incumbents, EOL equals the nucleolus of the agglomeration game, in which regional externalities require cooperation of the entrant and all incumbents in that region; this allocation is polynomial-time computable. [Verified published version](https://d-nb.info/1275701876/34).
No result settling exactly this support-based limiting formulation was located in the literature search.

Modeling choices made when packaging the task

  • Require at least two regions because the second-best-region maximum otherwise has an empty domain.
  • Specify all benefits, including entrant benefits, as nonnegative binary rationals, following the discrete benefit domain and making exact computation a finite-input problem.
  • Define L as the total input bit length and identify m with the number r of regions.
  • Interpret y_t as an incumbent payoff density, so the allocation to an entire type is mu_t y_t; x_0 uses the stated per-incumbent normalization.
  • Retain empty regions and zero benefits, which the discrete model explicitly permits.

Result

The allocation defined in the question is exactly computable in deterministic polynomial time in \(m,\tau,L\). The proof evaluates the given formula directly and bounds the bit lengths of all intermediate integers. It requires no expansion of types into individual incumbents.

The [published paper](https://d-nb.info/1275701876/34) concerns a finite population of firms. The argument below establishes the computational claim for the support-based definition supplied here.

Exact algorithm

Write every input rational as a nonnegative integer numerator divided by a positive integer denominator. Let \(D\) be the product of all these denominators. Every input denominator divides \(D\), so the following are integers:

\(A_t=D\mu_t,\qquad B_t=Db_t^{k(t)},\qquad C_k=D\beta^k.\)

The mass normalization gives \(\sum_t A_t=D\).

For each region, compute

\(H_k=DC_k+\sum_{t:k(t)=k}A_tB_t.\)

Because benefits vanish outside the home region,

\(G_k=H_k/D^2.\)

Choose a region \(k^\ast\) maximizing \(H_k\), set \(H=H_{k^\ast}\), and count how many regions attain \(H\). Also compute

\(Q=\sum_{t:k(t)=k^\ast}A_t.\)

Return the allocation as follows.

  • If at least two regions attain \(H\), or if \(Q=0\), return \(x_0=H/D^2\) and \(y_t=0\) for every type.
  • Otherwise compute

\(J=\max\{DC_{k^\ast},\max_{k\ne k^\ast}H_k\}\).
Return \(x_0=J/D^2\), and for each type return
\(y_t=(H-J)/(DQ)\) if \(k(t)=k^\ast\), and \(y_t=0\) otherwise.

The maximum over other regions exists because \(m\geq2\). In the second branch, \(Q>0\), so every output denominator is positive.

Correctness

All regional totals have the same positive denominator \(D^2\). Consequently, comparing the integers \(H_k\) identifies precisely the maximizing regions and detects ties exactly. Moreover, \(q=Q/D\), so \(Q=0\) holds precisely when \(q=0\). The first branch therefore implements exactly the specified tied-maximum and zero-mass cases.

In the second branch, the maximizing region is unique and \(q>0\). The definitions give

\(S=\max_{k\ne k^\ast}H_k/D^2,\qquad \beta^{k^\ast}=DC_{k^\ast}/D^2,\qquad I=J/D^2.\)

Hence the computed incumbent density is exactly

\((G-I)/q=((H-J)/D^2)/(Q/D)=(H-J)/(DQ).\)

Thus both branches return the allocation in the question.

Nonnegativity also follows directly. Each regional incumbent contribution is nonnegative, so \(DC_{k^\ast}\leq H\); maximality gives \(H_k\leq H\) for every other region. Therefore \(J\leq H\). In the second branch, conservation follows from

\(x_0+\sum_t\mu_ty_t=J/D^2+(Q/D)(H-J)/(DQ)=H/D^2=G.\)

In the first branch, conservation is immediate because \(x_0=G\) and every incumbent density is zero. When the maximum is tied, this output is independent of the chosen maximizer.

Polynomial bit complexity

The sum of the binary lengths of all input denominators is at most \(L\). Therefore \(D\leq2^L\), and its binary length is at most \(L+1\). Every input numerator is also at most \(2^L\).

For an input rational \(a/d\), its scaled integer is \(a(D/d)\), which is at most \(2^{2L}\). Thus \(A_t,B_t,C_k\leq2^{2L}\), and

\(0\leq H_k\leq(\tau+1)2^{4L}.\)

Every regional total therefore has \(O(L+\log(\tau+1))\) bits. The same bound applies to \(H\), \(J\), and \(H-J\).

Since the masses sum to one, \(0\leq Q\leq D\). Consequently, the output denominators \(D^2\) and \(DQ\) are at most \(D^2\), and have \(O(L)\) bits. Every output rational has polynomial encoding length, including when \(q\) is very small.

Constructing \(D\), scaling the rationals, accumulating regional sums, finding maxima, and producing the outputs require a polynomial number of integer operations in \(m,\tau,L\). Each operation involves integers of polynomial bit length. Standard binary integer arithmetic therefore implements the entire algorithm in polynomial time. If reduced fractions are required, Euclidean greatest-common-divisor computations also take polynomial time.

If total type allocations are requested as well, multiplying each computed density by \(\mu_t\) preserves polynomial bit complexity.

This completes the proof for the stated limiting allocation.
