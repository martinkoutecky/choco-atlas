The continuous mirror question, as graded

Given \(d\) fixed binary questions, \(\tau\) worker types with rational masses \(\mu_t\ge 0\) summing to \(1\), \(p_{\mathrm{obs}}\in(0,1]\), and exact rational report masses \(\nu_{j,+},\nu_{j,-},\nu_{j,0}\), promised to arise from unknown labels \(x\in\{-1,+1\}^d\), abilities \(a_t\in[\tfrac12,1]\), and difficulties \(h_j\in[0,1]\) with \(Q_{tj}=a_t(1-h_j)+\tfrac12h_j\), compute \(\hat x\) with \(L_Q(\hat x,x)=0\), where \(L_Q(\hat x,x)=\frac1d\sum_j\mathbf 1\{\hat x_j\ne x_j\}\sum_t\mu_t(2Q_{tj}-1)^2\). The report masses satisfy \(\nu_{j,+}-\nu_{j,-}=p_{\mathrm{obs}}x_j\sum_t\mu_t(2Q_{tj}-1)\); under R1, choose the sign of each nonzero imbalance and either label on a tie.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) worker types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m=d\ge1\) binary questions. The input also contains a known binary rational \(p_{\mathrm{obs}}\in(0,1]\) and nonnegative binary-rational report masses \(\nu_{j,+},\nu_{j,-},\nu_{j,0}\) for each question. Let \(L\) be the total input bit length.
The input is promised to admit unknown labels \(x\in\{-1,+1\}^d\), real abilities \(a_t\in[\tfrac12,1]\), and real difficulties \(h_j\in[0,1]\), with \(Q_{tj}=a_t(1-h_j)+\tfrac12h_j\).
The reports are exact population masses: \(\nu_{j,x_j}=p_{\mathrm{obs}}\sum_t\mu_tQ_{tj}\), \(\nu_{j,-x_j}=p_{\mathrm{obs}}\sum_t\mu_t(1-Q_{tj})\), and \(\nu_{j,0}=1-p_{\mathrm{obs}}\).
An admissible output is \(\hat x\in\{-1,+1\}^d\) satisfying \(L_Q(\hat x,x)=\frac1d\sum_{j=1}^d\mathbf1\{\hat x_j\ne x_j\}\sum_{t=1}^{\tau}\mu_t(2Q_{tj}-1)^2=0\) for every latent realization consistent with the input.

Is this promised exact-mass recovery problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite workers with independent randomly missing noisy responses, the polynomial-time OBI-WAN estimator recovers each sufficiently informative question with high probability under this ability–difficulty model, subject to sufficient total signal, \(d\ge n\), and \(p_{\mathrm{obs}}\ge1/n\).
That finite-sample guarantee concerns random observations rather than the exact population report masses specified here.

Modeling choices made when packaging the task

  • Treat the number of questions as an input parameter, with m=d, rather than a globally fixed constant.
  • Require positive masses in the support and omit zero-mass types.
  • Require p_obs to be a binary rational so that the computational input has a finite encoding.
  • Specify all three report masses using the symmetric-error and independent-observation model, rather than specifying only their imbalance.
  • Allow real latent abilities and difficulties; only the observed input must be rational.
  • Require zero loss for every latent realization consistent with the reports, since the unknown realization is not supplied.
  • Retain the graded question's normalized population model and positive observation probability. The finite-sample restrictions d≥n and p_obs≥1/n have no worker-count parameter here; support size is not substituted for n.
  • Remove the supplied sign-selection prescription from the task because it suggests a solution.

Result

The promised exact-mass recovery problem is solvable in polynomial time. Choose the label with the larger report mass, breaking ties arbitrarily.

Proof

Fix any latent realization consistent with the input. Define the signal of worker type \(t\) on question \(j\) by

\(s_{tj}:=2Q_{tj}-1=(2a_t-1)(1-h_j).\)

Because \(a_t\in[\tfrac12,1]\) and \(h_j\in[0,1]\), we have \(s_{tj}\ge0\).

Let \(\Delta_j:=\nu_{j,+}-\nu_{j,-}\). The exact report equations imply

\(\Delta_j=p_{\mathrm{obs}}x_j\sum_{t=1}^{\tau}\mu_t s_{tj}.\)

Indeed, when \(x_j=+1\), subtracting the incorrect report mass from the correct report mass gives the positive expression; when \(x_j=-1\), the order of those two masses reverses.

There are two cases.

  • Unequal report masses. If \(\Delta_j\ne0\), then \(p_{\mathrm{obs}}>0\) and \(\sum_t\mu_t s_{tj}\ge0\) force \(x_j\) to have the same sign as \(\Delta_j\). Thus every consistent realization has the label selected by the algorithm.
  • Equal report masses. If \(\Delta_j=0\), then

\(\sum_t\mu_t s_{tj}=0\).
Every summand is nonnegative, and every \(\mu_t\) is strictly positive. Consequently \(s_{tj}=0\) for every \(t\), and hence
\(\sum_t\mu_t(2Q_{tj}-1)^2=0\).
Either output label therefore contributes zero loss, even if it differs from the latent label.

The realization was arbitrary. For every consistent realization, each unequal-mass question is labeled correctly and each tied question has zero loss weight. Therefore the algorithm satisfies

\(L_Q(\hat x,x)=0\)

for every latent realization consistent with the input.

Algorithm and complexity

For each question \(j\), output \(\hat x_j=+1\) if \(\nu_{j,+}\ge\nu_{j,-}\), and output \(\hat x_j=-1\) otherwise.

These are exact comparisons of input rationals. For positive denominators, comparing \(u/v\) with \(r/s\) reduces to comparing the integers \(us\) and \(rv\). Their bit lengths are bounded by a constant multiple of \(L\), so ordinary integer arithmetic gives polynomial running time; for example, \(O(mL^2+L+\tau)\) is a valid coarse bound. No latent parameters need to be reconstructed.

The decisive feature is that exact report differences cannot fluctuate: every worker’s signal is nonnegative. The stated finite-sample OBI-WAN guarantee concerns a different observation model and is unnecessary for this conclusion.
