The continuous mirror question, as graded

Given applicant types and position types with rational masses, strict rankings over opposite-side types, and a rational distribution over type-and-upward-shift events, find a base-stable matching flow \(x_{bg}\) maximizing the probability that the matching remains stable after the selected event shifts one uniformly sampled member’s list.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; \(\tau\) is the support size, not the number of possible types. Let \(B\) and \(G\) be applicant and position types, \(m=|G|\), and \(\tau=|B|+|G|\); masses \(a_b,d_g>0\) sum to \(1\) on each side.
A bipartite graph \(E\) specifies mutual acceptability. Each type strictly ranks its acceptable opposite-side types; members of the same type are indifferent. Every acceptable partner is preferred to being unmatched, denoted \(\bot\).
A matching flow has real entries \(x_{bg}\geq0\), vanishes outside \(E\), and satisfies \(\sum_gx_{bg}\leq a_b\), \(\sum_bx_{bg}\leq d_g\). Write \(u_b=a_b-\sum_gx_{bg}\) and \(v_g=d_g-\sum_bx_{bg}\).
For \((b,g)\in E\), define \(D_b(g)=u_b+\sum_{h:g\succ_b h}x_{bh}\) and \(D_g(b)=v_g+\sum_{c:b\succ_g c}x_{cg}\). Base stability means \(D_b(g)D_g(b)=0\) for every acceptable pair.
The input explicitly lists \(k\geq1\) events with nonnegative binary-rational probabilities \(p_e\) summing to \(1\). An event selects a type on either side and moves one acceptable opposite-side type above a nonempty contiguous block immediately preceding it; all other comparisons and acceptability remain unchanged.
After choosing an event, sample one member uniformly within its selected type, retaining that member's partner. For applicant type \(b\), the partner is \(g\) with probability \(x_{bg}/a_b\), or \(\bot\) with probability \(u_b/a_b\); use the symmetric distribution for position types.
For an applicant event with shifted ranking \(\succ_b^e\) and sampled partner \(h\), survival means there is no acceptable \(g\succ_b^e h\) with \(D_g(b)>0\); define position-event survival symmetrically. Thus the selected member is tested for blocking with positive mass of willing counterparts, even though the member itself has zero mass. Let \(R(x)\) be the resulting survival probability, averaged over events and sampled partners.

Is maximizing \(R(x)\) over base-stable matching flows solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,k,L\), where \(L\) is the total input bit length.

The discrete problem with one random upward shift and possibly incomplete lists has a polynomial-time algorithm ([Mai–Vazirani](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ESA.2018.60)).
For real-valued stable allocations, a strongly polynomial algorithm finds a stable allocation ([Baïou–Balinski, corrected version](https://pubsonline.informs.org/doi/pdf/10.1287/moor.27.4.662.302)); this result does not address the single-member survival objective above. No result settling this exact continuous objective was located.

Modeling choices made when packaging the task

  • Normalized each side's total mass to one, reflecting equal-sized sides in the discrete model; defined m as the number of position types and tau as the combined support size.
  • Retained incomplete lists through mutual acceptability, with unmatched ranked below every acceptable partner and shifts restricted to existing acceptable entries.
  • Interpreted type rankings as strict between distinct acceptable types, with indifference between individual members of the same type.
  • Defined base stability by the absence of positive masses on both sides that strictly prefer one another to their current partners or unmatched status.
  • Resolved uniform member sampling using the flow's conditional partner distribution, including unmatched members, while keeping the matching fixed after the event.
  • Resolved the zero-mass singleton ambiguity by explicitly testing the selected member against positive mass of willing counterparts.
  • Required each upward shift to cross a nonempty block and specified an explicit nonempty event list with probabilities summing to one.
  • Used feasible partial flows with no blocking pairs rather than an additional maximum-cardinality requirement, consistent with the intended stable-matching problem.

Result

Maximizing \(R(x)\) is polynomial-time solvable.

Let \(s=|E|+\tau+1\). The proof below gives an exact algorithm using \(O(s^5+ks)\) arithmetic operations on numbers of polynomial bit length. A conservative bit-complexity bound is

\(O\!\left((s^5+ks+L)L^2\right)=O\!\left(((m\tau)^5+km\tau+L)L^2\right).\)

The algorithm uses a rotation representation of stable allocations, followed by one minimum-cut computation. The main points requiring proof are that partial rotations can be rounded without worsening the objective, and that the resulting quadratic objective has the signs required for a minimum-cut representation.

1. Exact failure probability for one event

Consider an applicant event selecting \(b\), promoting \(g\), and crossing the block \(H\) immediately preceding \(g\). Define

\(q_e(x)=\sum_{h\in H}x_{bh},\qquad W_e(x)=D_g(b),\qquad \mu_e=a_b.\)

For a position event selecting \(g\), promoting \(b\), and crossing the applicant block \(H\), define

\(q_e(x)=\sum_{c\in H}x_{cg},\qquad W_e(x)=D_b(g),\qquad \mu_e=d_g.\)

Lemma 1. On every base-stable flow, the conditional failure probability of event \(e\) is

\(f_e(x)=\dfrac{q_e(x)}{\mu_e}\mathbf 1[W_e(x)>0].\)

Proof. First consider an applicant event. Suppose a sampled partner \(h\) has positive probability, and an acceptable position \(j\) was already preferred to \(h\) before the shift.

If \(h\) is an acceptable partner, then \(x_{bh}>0\), so \(D_b(j)\geq x_{bh}>0\). If \(h=\bot\), then \(u_b>0\), so \(D_b(j)\geq u_b>0\). In either case, base stability implies \(D_j(b)=0\). Thus a comparison already present before the shift cannot cause failure.

The only newly favorable comparison is between the promoted type \(g\) and a retained partner \(h\in H\). Such a sampled member fails precisely when \(D_g(b)>0\). The probability of retaining a partner in \(H\) is \(q_e(x)/a_b\).

The same argument with the sides exchanged proves the position-event formula. \(\square\)

Consequently, maximizing survival is equivalent to minimizing

\(F(x)=1-R(x)=\sum_e \dfrac{p_e}{\mu_e}q_e(x)\mathbf 1[W_e(x)>0].\)

All coefficients \(p_e/\mu_e\) are nonnegative, and every \(q_e\) and \(W_e\) is a nonnegative affine function on feasible flows.

2. Applying the stable-allocation rotation theorem

2.1 Checking the model correspondence

Add a dummy applicant \(b_0\) and a dummy position \(g_0\), each of mass \(1\). Every real type ranks its dummy counterpart last. Each dummy ranks all real opposite-side types above the other dummy, using any strict order among the real types.

A feasible original flow has a unique extension with full marginals:

\(x_{b g_0}=u_b,\qquad x_{b_0 g}=v_g,\qquad x_{b_0g_0}=\sum_{b,g}x_{bg}.\)

Indeed, writing \(T=\sum_{b,g}x_{bg}\), the dummy applicant receives total flow \((1-T)+T=1\), and the dummy position does likewise.

Give every augmented edge an upper capacity equal to the smaller endpoint mass. These capacities do not restrict feasible flows.

The usual capacitated stable-allocation condition tests an edge only when it is below its upper capacity. Here, if an edge reaches that capacity, one endpoint assigns its entire mass to the other endpoint, so that endpoint’s dissatisfaction is zero. Thus the capacitated condition is equivalent to the problem’s product condition.

On original edges, assignments to the dummy counterparts reproduce unmatched mass in the dissatisfaction expressions. On edges incident with a dummy, a real endpoint cannot prefer the dummy to any current partner. The dummy–dummy edge likewise has no worse partner at either endpoint. Therefore extension and restriction give a bijection between original base-stable flows and augmented stable allocations.

The augmented instance has \(\tau+2\) vertices, \(s\) edges, positive rational quotas, and strict preferences over its acceptable edges.

2.2 The rotation representation

We use the following known representation: an initial stable allocation \(x^0\), a rotation poset \(P\) with \(N\leq 2s\) elements, positive amounts \(r_\rho\), and signed cycle vectors \(v_\rho\) can be constructed. Every stable allocation has the form

\(x(y)=x^0+\sum_{\rho\in P}y_\rho v_\rho,\)

where \(0\leq y_\rho\leq r_\rho\), and \(y_\sigma>0\) requires \(y_\rho=r_\rho\) for every \(\rho\prec\sigma\). Conversely, every such vector gives a stable allocation. Each cycle transfers flow from a better to a worse partner at each participating applicant, and from a worse to a better partner at each participating position. Rotations sharing a vertex are comparable. The representation can be written down in \(O(s(\tau+2))\) arithmetic operations. These are the rotation results in [Dean–Munshi, Section 4, Lemmas 6–12](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf).

In particular, fully applied rotations correspond to ideals of \(P\). Write \(z_\rho\in\{0,1\}\) for their indicators. Their allocations are

\(x(z)=x^0+\sum_\rho r_\rho z_\rho v_\rho,\)

subject to \(z_\sigma\leq z_\rho\) whenever \(\rho\prec\sigma\).

3. Partial rotations can be rounded

Lemma 2. Every stable allocation admits a stable allocation using only fully applied or unapplied rotations, with no larger failure probability.

Proof. Suppose \(0<y_\rho<r_\rho\). All predecessors of \(\rho\) are fully applied, and all successors are unapplied. Hence replacing \(y_\rho\) by any \(t\in[0,r_\rho]\), while fixing the other coordinates, preserves the representation constraints and stability.

For each event, both \(q_e(t)\) and \(W_e(t)\) are affine and nonnegative throughout this interval.

A nonnegative affine function is either identically zero or strictly positive throughout the open interval. Thus:

  • If \(W_e\) is identically zero, this event contributes zero throughout.
  • Otherwise, its contribution on the open interval is the affine function \((p_e/\mu_e)q_e(t)\). At either endpoint, its contribution equals this affine value or drops to zero.

Put \(\lambda=t/r_\rho\). Since \(q_e\) is nonnegative at the endpoints, this gives

\(F(x(t))\geq (1-\lambda)F(x(0))+\lambda F(x(r_\rho)).\)

At least one endpoint therefore has failure probability no larger than \(F(x(t))\). Move to such an endpoint.

Repeating removes all partial coordinates in at most \(N\) steps. \(\square\)

There are finitely many ideals. Lemma 2 therefore also proves that an optimum is attained, despite possible discontinuities at zero willingness. It suffices to optimize over binary ideal indicators \(z\).

4. Willingness becomes a single rotation indicator

For every event, write its crossed-block mass as

\(q_e(z)=q_e^0+\sum_\rho \delta_{e\rho}z_\rho,\)

where \(q_e^0=q_e(x^0)\), and \(\delta_{e\rho}\) is the change caused by fully applying \(\rho\).

Consider an applicant event selecting \(b\) and promoting \(g\). Rotations affecting \(g\) form a chain, and each improves \(g\)’s assignment. Consequently \(D_g(b)\) is nonincreasing along that chain. An ideal selects a prefix of the chain. Therefore its willingness indicator is either constant, or

\(\mathbf 1[D_g(b)>0]=1-z_\sigma,\)

where \(\sigma\) is the first rotation whose full application makes \(D_g(b)=0\).

For a position event selecting \(g\) and promoting \(b\), rotations affecting \(b\) form a chain and worsen \(b\)’s assignment. Thus \(D_b(g)\) is nondecreasing, and its indicator is either constant, or

\(\mathbf 1[D_b(g)>0]=z_\sigma,\)

where \(\sigma\) is the first rotation whose full application makes \(D_b(g)>0\).

These assertions also cover a rotation that reaches the threshold only at its endpoint: this section concerns full rotations, and Lemma 2 already handles partial ones.

5. The essential sign lemma

The following lemma supplies the minimum-cut signs.

Lemma 3.

  • For an applicant event with nonconstant indicator \(1-z_\sigma\), every rotation \(\rho\) incomparable with \(\sigma\) satisfies \(\delta_{e\rho}\geq0\).
  • For a position event with nonconstant indicator \(z_\sigma\), every rotation \(\rho\) incomparable with \(\sigma\) satisfies \(\delta_{e\rho}\leq0\).

Proof. For incomparable \(\rho,\sigma\), let \(I\) be the union of their sets of proper predecessors. Then

\(I,\quad I\cup\{\rho\},\quad I\cup\{\sigma\},\quad I\cup\{\rho,\sigma\}\)

are all ideals. Both rotations can therefore be applied after \(I\), in either order.

Applicant event

Suppose \(\delta_{e\rho}<0\). At applicant \(b\), rotation \(\rho\) must transfer positive flow from a partner in the crossed block \(H\) to a worse partner outside \(H\).

Because \(H\) immediately precedes the promoted type \(g\), the receiving partner is either \(g\) or a type below \(g\).

If the receiving partner is \(g\), then \(\rho\) contains vertex \(g\). The threshold rotation \(\sigma\) also contains \(g\), so the rotations are comparable—a contradiction.

Otherwise, after applying \(\rho\) to \(I\), applicant \(b\) has positive flow below \(g\), giving \(D_b(g)>0\). But \(\sigma\) remains unapplied, so the event’s indicator gives \(D_g(b)>0\). This contradicts stability of the allocation associated with \(I\cup\{\rho\}\).

Hence \(\delta_{e\rho}\geq0\).

Position event

Suppose \(\delta_{e\rho}>0\). At position \(g\), rotation \(\rho\) must transfer positive flow from a worse applicant outside \(H\) to an applicant in \(H\).

The departing applicant is either the promoted type \(b\) or a type below \(b\).

If it is \(b\), then \(\rho\) and the threshold rotation \(\sigma\) share \(b\), contradicting incomparability.

Otherwise, consider the allocation associated with \(I\cup\{\sigma\}\), before applying \(\rho\). The edge from the departing applicant must have positive flow: applying \(\rho\) decreases it by \(r_\rho>0\), and the resulting allocation is nonnegative. Since that applicant is below \(b\), we have \(D_g(b)>0\). Meanwhile, \(\sigma\) has been applied, so \(D_b(g)>0\).

This contradicts stability of \(I\cup\{\sigma\}\). Therefore \(\delta_{e\rho}\leq0\). \(\square\)

6. A quadratic objective with nonpositive pair coefficients

Expand the loss of an applicant event with nonconstant willingness:

\(\dfrac{p_e}{a_b}\left(q_e^0+\sum_\rho\delta_{e\rho}z_\rho\right)(1-z_\sigma).\)

Its quadratic coefficient on \(z_\rho z_\sigma\) is \(-(p_e/a_b)\delta_{e\rho}\).

For a position event, expand

\(\dfrac{p_e}{d_g}\left(q_e^0+\sum_\rho\delta_{e\rho}z_\rho\right)z_\sigma.\)

Its quadratic coefficient is \((p_e/d_g)\delta_{e\rho}\).

For comparable rotations, products become linear on ideals:

  • If \(\rho\prec\sigma\), then \(z_\rho z_\sigma=z_\sigma\).
  • If \(\sigma\prec\rho\), then \(z_\rho z_\sigma=z_\rho\).
  • Also \(z_\rho^2=z_\rho\).

For incomparable rotations, Lemma 3 shows that both kinds of quadratic coefficient are nonpositive. Events with constant willingness already give affine contributions.

After aggregation, the exact loss on ideals therefore has the form

\(F(z)=C+\sum_\rho A_\rho z_\rho+\sum_{\{\rho,\sigma\}}B_{\rho\sigma}z_\rho z_\sigma,\qquad B_{\rho\sigma}\leq0.\)

7. Minimum-cut construction

Use one graph vertex per rotation, with \(z_\rho=1\) meaning that the vertex lies on the source side of the cut.

For a pair term \(-c z_\rho z_\sigma\), where \(c\geq0\), use the identity

\(-c z_\rho z_\sigma=c z_\rho(1-z_\sigma)-c z_\rho.\)

The first term is represented by an arc \(\rho\to\sigma\) of capacity \(c\); the second is added to the unary coefficient.

A unary term \(\alpha z_\rho\) is represented as follows:

  • If \(\alpha\geq0\), add an arc \(\rho\to t\) of capacity \(\alpha\).
  • If \(\alpha<0\), use \(\alpha z_\rho=(-\alpha)(1-z_\rho)+\alpha\), and add an arc \(s\to\rho\) of capacity \(-\alpha\).

The additive constants do not affect minimizers.

Finally, enforce each precedence constraint \(z_\sigma\leq z_\rho\) by an arc \(\sigma\to\rho\) of capacity \(M\), where \(M\) exceeds the sum of all finite capacities. The all-zero assignment is an ideal and has cut capacity below \(M\). Thus a minimum cut cannot violate any precedence constraint.

The minimum cut consequently minimizes \(F\) over ideals. Lemma 2 shows that this also minimizes \(F\) over all real-valued base-stable flows. Restricting the resulting augmented allocation to the original edges gives an optimal flow for the stated objective.

8. Running time and exact arithmetic

The augmented instance has \(s=|E|+\tau+1\) edges and \(N=O(s)\) rotations.

The computational steps are:

  • Construct the rotation representation in \(O(s\tau)\) arithmetic operations.
  • Compute the transitive closure of the rotation order in \(O(s^3)\) operations.
  • Construct all event coefficients and willingness thresholds in \(O(ks)\) arithmetic operations. Record each rotation’s departing and receiving partner at each participating vertex; rank comparisons then give each event’s coefficient in constant time per rotation.
  • Aggregate pair coefficients. The cut graph has \(O(s)\) vertices and \(O(s^2)\) arcs.
  • Run Edmonds–Karp, requiring \(O(s^5)\) arithmetic operations.

For bit complexity, let \(Q\) be the product of the input mass denominators. It has \(O(L)\) bits. Scaling quotas by \(Q\) makes them integral; the stable-allocation augmentations use residual minima and preserve integrality. Hence \(x^0\) and all \(r_\rho\) have denominators dividing \(Q\).

A common denominator for the objective coefficients is obtained by multiplying \(Q\), all probability denominators, and the numerators of the masses of selected types, using each selected type once. This denominator also has \(O(L)\) bits. Moreover,

\(q_e^0/\mu_e\leq1,\qquad |\delta_{e\rho}|/\mu_e\leq1.\)

Since \(\sum_e p_e=1\), expansion, aggregation, and the cut conversion produce capacities of polynomial magnitude before denominator scaling. Thus all integer capacities and intermediate arithmetic values have \(O(L+\log s)\) bits.

Using ordinary exact arithmetic gives the conservative bound

\(O\!\left((s^5+ks+L)L^2\right).\)

Finally, \(|E|\leq m(\tau-m)\), so \(s=O(m\tau)\), yielding the announced bound in \(m,\tau,k,L\).
