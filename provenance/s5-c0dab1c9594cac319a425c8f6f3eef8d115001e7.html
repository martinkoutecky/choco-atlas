The anchor (named result in the paper)

Proposition 1 — class: algorithmic

The continuous mirror question, as graded

Given a finite artist set \(N\) and an explicitly listed rational distribution \(\mu=(\mu_L)_{\varnothing\ne L\subseteq N}\) over user types \(L\), compute exactly \(r_i=\sum_{L\ni i}\mu_L/|L|\) for every \(i\in N\), or decide whether \(r_i\ge q\) for a rational threshold \(q\).

Packaged proof task (what the prover saw — nothing else)

Let \(N\) be a nonempty finite artist set, with \(m=|N|\). A user type is a nonempty subset \(A\subseteq N\) consisting of the artists that user streamed.
A society is given by its support: an explicit list \(\mathcal S\) of \(\tau\) distinct types with positive binary rational masses \(\mu_A\), satisfying \(\sum_{A\in\mathcal S}\mu_A=1\). Unlisted types have zero mass; \(\tau\) is the support size, not the number of possible types.
Each unit of user mass pays one unit, divided equally among its streamed artists. Define \(r_i=\sum_{A\in\mathcal S:i\in A}\mu_A/|A|\). The computation problem outputs every \(r_i\) exactly as a binary rational; the decision problem additionally receives \(i\in N\) and \(q\in\mathbb Q\) and asks whether \(r_i\ge q\).
Let \(L\) be the total binary input length, including the explicitly encoded subsets and, for decision, the designated artist and threshold. State running times in \(m,\tau,L\).

Is exact computation of all \(r_i\) solvable in polynomial time, or is it NP-hard? Is the threshold decision problem in \(\mathrm P\), or is it NP-hard?

For finitely many explicitly listed users with nonempty streamed sets, the Shapley allocation is \(\sum_{j:i\in A_j}1/|A_j|\), giving polynomial-time computation ([published result](https://doi.org/10.1016/j.infoecopol.2025.101142)). No separate complexity result for the rational-mass input model is established by this source.

Modeling choices made when packaging the task

  • Use m for the number of artists and A for a user type, reserving L for total binary input length.
  • Interpret the rational distribution as a probability distribution with total mass one and unit payment per unit mass.
  • Specify a nonempty artist set, explicit subset encodings, a designated artist for threshold decision, an unrestricted rational threshold, and exact binary rational outputs.
  • Interpret the malformed nested summation as a sum over users whose streamed sets contain the designated artist, consistent with the accompanying prose and the corrected formula displayed in the publisher's indexed version.

Conclusion and encoding conventions

Exact computation is in \(\mathrm{FP}\), and the threshold decision problem is in \(\mathrm P\), under the usual explicit encoding of the artist set.

Here an exact “binary rational” means a numerator–denominator pair of binary integers. A terminating base-two expansion would be insufficient: a single type containing three artists gives each artist revenue \(\frac13\).

We prove running-time bounds of \(\mathrm O((m+\tau+1)L^2)\) for all revenues and \(\mathrm O((\tau+1)L^2)\) for threshold decision. These bounds use elementary integer arithmetic.

1. A common denominator has polynomial bit length

Write each input mass as \(\mu_A=a_A/b_A\), where \(a_A,b_A\) are positive integers, and put \(k_A=|A|\). Reduced input fractions are unnecessary.

Define

\( D=\prod_{A\in\mathcal S}(b_Ak_A). \)

Every \(b_Ak_A\) divides \(D\). Therefore the integer

\( w_A=a_A\frac{D}{b_Ak_A} \)

satisfies \(w_A/D=\mu_A/|A|\).

Let \(E=\sum_{A\in\mathcal S}|A|\) be the total number of incidences in the support. Explicitly encoding the subsets requires at least \(\mathrm\Omega(E)\) bits, so \(E=\mathrm O(L)\). Also, the total bit length of all input denominators is at most \(L\). Consequently,

\( \log_2 D =\sum_{A\in\mathcal S}\log_2 b_A+ \sum_{A\in\mathcal S}\log_2 k_A \le L+E =\mathrm O(L), \)

where we used \(\log_2 k_A\le k_A\).

Thus \(D\) has \(\mathrm O(L)\) bits. This is the key point: multiplying the denominators makes their bit lengths add.

2. Exact computation of every revenue

Initialize \(X_i=0\) for every \(i\in N\). For each listed type \(A\), compute \(w_A\) and add it to \(X_i\) for each \(i\in A\). Output \(X_i/D\), optionally reduced.

For every artist \(i\), the resulting value is exactly

\( \frac{X_i}{D} =\sum_{A\in\mathcal S:\,i\in A}\frac{w_A}{D} =\sum_{A\in\mathcal S:\,i\in A}\frac{\mu_A}{|A|} =r_i. \)

All arithmetic operands have \(\mathrm O(L)\) bits. To verify this for the accumulated numerators, positivity and normalization give

\( 0\le \frac{X_i}{D} \le\sum_{A\in\mathcal S}\mu_A =1. \)

Hence \(0\le X_i\le D\). Every intermediate accumulator obeys the same bound because it sums a subset of the nonnegative contributions.

Using schoolbook arithmetic, multiplication and division of \(\mathrm O(L)\)-bit integers cost \(\mathrm O(L^2)\), and addition costs \(\mathrm O(L)\). The algorithm performs:

  • \(\mathrm O(\tau)\) multiplications to construct \(D\);
  • one exact division and one multiplication per type to construct \(w_A\);
  • \(E\) additions to accumulate the revenues;
  • at most \(m\) fraction reductions and the output of \(m\) fractions.

Fraction reduction also takes \(\mathrm O(L^2)\) per artist using binary gcd. Briefly, after removing powers of two, a subtraction step on odd positive integers \(u<v\) replaces their sum \(u+v\) by \(u+(v-u)/2=(u+v)/2\). Thus there are \(\mathrm O(L)\) such steps, each requiring \(\mathrm O(L)\) bit operations; shifts and comparisons fit the same bound.

Since \(E=\mathrm O(L)\), the total running time is

\( \mathrm O\!\left(L+\tau L^2+EL+mL^2\right) =\mathrm O\!\left((m+\tau+1)L^2\right). \)

Each output fraction has \(\mathrm O(L)\) bits, so the total output length is \(\mathrm O(mL)\). Artists with zero revenue can be output as \(0/1\).

3. Threshold decision

For the designated artist \(i\), construct \(D\) and accumulate only

\( X_i=\sum_{A\in\mathcal S:\,i\in A}w_A. \)

Write the threshold as \(q=c/d\), with \(c\) an integer and \(d>0\). Because both denominators are positive,

\( r_i\ge q \quad\Longleftrightarrow\quad X_i d\ge cD. \)

This comparison is exact, including when \(q\) is negative. The threshold’s numerator and denominator are included in \(L\), so both cross-products have \(\mathrm O(L)\) bits and take \(\mathrm O(L^2)\) time to compute.

Reading the support and testing membership costs at most \(\mathrm O(L)\) with its explicit encoding. There are at most \(\tau\) contribution calculations. No fraction reduction is required. The resulting decision bound is

\( \mathrm O\!\left((\tau+1)L^2\right). \)

Thus threshold decision belongs to \(\mathrm P\).

4. Scope of the complexity conclusion

With an explicitly encoded artist set, \(m=\mathrm O(L)\), and with explicitly listed support, \(\tau=\mathrm O(L)\). The bounds above are therefore polynomial in the input length. The proof directly handles rational masses and does not require expanding them into individual users or invoking the cited finite-user result.

If the artist universe were instead encoded succinctly, allowing \(m\) to be exponentially larger than \(L\), explicitly outputting all \(m\) revenues would itself require \(\mathrm\Omega(m)\) time. The computation bound remains polynomial in \(m,\tau,L\); threshold decision remains polynomial in \(L\). The intended explicit-input model avoids this output-size issue.

Polynomial-time solvability is the answer to both questions. NP-hardness under standard polynomial-time reductions would imply \(\mathrm P=\mathrm{NP}\).
