The continuous mirror question, as graded

Given a candidate set \(A\), a finite support \(T\subseteq 2^A\) of ideal boards with positive rational masses \(\mu_t\) summing to \(1\), a threshold \(\sigma\), an explicit finite proposal set \(Q\) containing the type peaks and current public proposals, and status quo \(s=\varnothing\), let \(u_t(c)=d(t,s)-d(t,c)\). For each distinct \(p,q\in Q\), form at most two canonical Hamming midpoints using a fixed ordering of \(A\). Define \(\Phi^\mu_\sigma(c)=\sup\{z:\sum_{t:u_t(c)\ge z}\mu_t\ge\sigma\}\). Find a generated midpoint \(c^*\) of maximum \(\Phi^\mu_\sigma\), and return it if its score exceeds \(\max_{x\in Q}\Phi^\mu_\sigma(x)\); otherwise return \(\bot\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be an ordered candidate set with \(m=|A|\); boards are unrestricted subsets of \(A\), with Hamming distance \(d\) and status quo \(s=\varnothing\).
A society is given by its support: the list \(T\subseteq 2^A\) of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a binary rational threshold \(\sigma\in[1/2,1)\) and an explicit finite proposal set \(Q\subseteq 2^A\) containing \(T\) and the current public proposals. Write \(b=|Q|\) and let \(L\) be the total input bit length.
Define \(u_t(c)=d(t,s)-d(t,c)\) and \(\Phi^\mu_\sigma(c)=\sup\{z\in\mathbb R:\sum_{t:u_t(c)\ge z}\mu_t\ge\sigma\}\).
For every ordered pair \(p,q\in Q\) with \(p\ne q\), list \(p\triangle q\) in candidate order and generate the boards obtained from \(p\) by toggling its first \(\lfloor d(p,q)/2\rfloor\) and first \(\lceil d(p,q)/2\rceil\) entries; discard duplicates.
Among all generated boards, choose \(c^*\) maximizing \(\Phi^\mu_\sigma\), breaking ties lexicographically by incidence vectors. Return \(c^*\) if \(\Phi^\mu_\sigma(c^*)>\max_{x\in Q}\Phi^\mu_\sigma(x)\); otherwise return \(\bot\). Return \(\bot\) also if no board is generated.

Is computing this output solvable in polynomial time in \(m,\tau,b,L\), or is it NP-hard?

For an explicit finite list of members, bounded-candidate pairwise Heuristic P is polynomial-time in the board setting. This discrete result concerns explicitly listed members and does not classify the binary rational mass-input problem defined above.

Modeling choices made when packaging the task

  • The threshold domain was unspecified; use a binary rational sigma in [1/2,1), matching the discrete threshold domain.
  • Canonical Hamming midpoints were unspecified; use the floor and ceiling halfway points on the coordinate-flipping path determined by the candidate order, for every ordered pair of distinct proposals.
  • Tie-breaking was unspecified; use lexicographic order of board incidence vectors.
  • The empty generated-candidate case was unspecified; return bottom.
  • Use unrestricted boards, as in the graded question, and retain the explicitly supplied proposal set without imposing a bound tied to support size.
  • Define L as total input bit length and include the explicit proposal-set size b among the running-time parameters.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The output is computable in polynomial time in \(m,\tau,b,L\). The rule generates at most \(2b(b-1)\) boards, and each board’s score can be evaluated exactly using integers whose bit lengths are polynomially bounded.

  • Exact evaluation of the score.

Fix a board \(c\subseteq A\). Since \(s=\varnothing\), the Hamming-distance identity gives
\[ u_t(c)=|t|-|t\triangle c|=2|t\cap c|-|c|. \]
Thus every utility is an integer in \(\{-m,\ldots,m\}\), computable by scanning the incidence vectors of \(t\) and \(c\).

Write the input masses as \(\mu_t=a_t/d_t\) and the threshold as \(\sigma=r/h\), with positive denominators. Define
\[ D=h\prod_{t\in T}d_t,\qquad W_t=a_t(D/d_t),\qquad R=r(D/h). \]
These are integers satisfying
\[ W_t=D\mu_t,\qquad R=D\sigma,\qquad \sum_{t\in T}W_t=D. \]
Consequently, for every set of types \(S\subseteq T\),
\[ \sum_{t\in S}\mu_t\ge \sigma \quad\Longleftrightarrow\quad \sum_{t\in S}W_t\ge R. \]

Let \(v_1>\cdots>v_k\) be the distinct utilities attained by the supported types, and put
\[ C_j=\sum_{t:u_t(c)\ge v_j}W_t,\qquad C_0=0. \]
Because \(C_k=D\) and \(0<R\le D\), there is a least index \(j\) with \(C_j\ge R\).

We claim that \(\Phi^\mu_\sigma(c)=v_j\). At \(z=v_j\), the required mass is \(C_j/D\ge\sigma\), so \(v_j\) is feasible. For every real \(z>v_j\), all types with \(u_t(c)\ge z\) belong to utility groups preceding group \(j\). Their total mass is therefore at most \(C_{j-1}/D<\sigma\). No such \(z\) is feasible. This proves the claim directly from the definition of the supremum.

To compute the score, place each weight \(W_t\) into the bucket indexed by \(u_t(c)\), then scan the buckets from \(m\) down to \(-m\). The first utility at which the cumulative weight reaches \(R\) is exactly the score. This uses \(O(m\tau)\) incidence-vector operations and \(O(m+\tau)\) integer additions and comparisons.

  • Polynomial bit complexity.

The sum of the bit lengths of the input denominators is at most \(L\). Hence
\[ \log_2 D=\log_2 h+\sum_{t\in T}\log_2 d_t=O(L). \]
Moreover, positivity and normalization imply \(0<W_t\le D\), while \(0<R\le D\). Every bucket weight and cumulative weight is also at most \(D\).

Thus all weights and cumulative sums have \(O(L)\) bits. Utilities and bucket indices have \(O(\log(m+1))\) bits. The preprocessing that constructs \(D,W_t,R\), and every subsequent score evaluation, use polynomially many arithmetic operations on numbers of polynomially bounded bit length. Standard exact integer arithmetic therefore gives polynomial bit complexity. No numerical approximation is needed.

  • Enumeration and selection.

First compute
\[ M_Q=\max_{x\in Q}\Phi^\mu_\sigma(x) \]
by evaluating the \(b\) explicitly listed boards.

There are \(b(b-1)\) ordered pairs of distinct proposals. For each pair, scan the candidates in order to obtain \(p\triangle q\), and construct the two specified boards by toggling the required prefixes. Each pair takes \(O(m)\) incidence-vector operations and generates at most two boards. The total number of generated occurrences is therefore at most \(2b(b-1)\).

Evaluate every generated occurrence and maintain the best board under score maximization and the stipulated lexicographic tie rule. Comparing two incidence vectors takes \(O(m)\) operations. Explicit duplicate removal is unnecessary: repeating a board cannot change either the maximum score or the lexicographically selected maximizer.

If no board is generated, return \(\bot\). Otherwise, let the maintained board be \(c^*\). Return \(c^*\) precisely when its integer score exceeds \(M_Q\), and return \(\bot\) otherwise. These are exactly the required output conditions.

The algorithm performs at most \(b+2b(b-1)\) score evaluations, together with polynomially many board-construction and comparison operations. By the preceding bit-complexity argument, its total running time is polynomial in \(m,\tau,b,L\). This resolves the binary rational mass-input problem as stated.
