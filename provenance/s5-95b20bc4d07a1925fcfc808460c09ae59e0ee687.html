The continuous mirror question, as graded

Given attributes \(\mathcal A\) with finite domains \(D_X\), and a support \(\{(o_i,\mu_i)\}_{i=1}^{\tau}\) of configurations with positive binary-rational masses summing to one, compute a single-branch LP-tree with one attribute per node that minimizes \(\sum_{i=1}^{\tau}\mu_i\,\operatorname{rank}(\phi,o_i)\).

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal A\) contain \(m\geq1\) attributes with explicitly listed finite domains satisfying \(2\leq |D_X|\leq d\), and let \(\Omega=\prod_{X\in\mathcal A}D_X\).
A society is given by its support: \(\tau\) distinct configuration types \(o_i\in\Omega\), each with positive binary-rational mass \(\mu_i\), with \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible configurations; configurations outside the support have zero mass. Let \(L\) be the total input bit length.
A single-branch LP-tree with one attribute per node specifies a permutation of all attributes, each appearing exactly once, and an unconditional strict total order on each attribute's entire domain; these induce the usual lexicographic order \(\succ_\phi\) on \(\Omega\).
Define \(\operatorname{rank}(\phi,o)=1+|\{o'\in\Omega:o'\succ_\phi o\}|\). Compute a tree minimizing \(\sum_{i=1}^{\tau}\mu_i\operatorname{rank}(\phi,o_i)\); any minimizing tree is acceptable.

Is this exact optimization problem solvable in polynomial time in \(m,\tau,d,L\), or is it NP-hard?

For an explicitly listed sample multiset \(S\), exact optimization over this class is reported to take \(O(m\log m\,|S|d\log d)\) time. An optimality characterization is also stated for arbitrary probability distributions, but no complexity bound for binary-rational support input is stated. [Source](https://arxiv.org/pdf/2209.11505v1)

Modeling choices made when packaging the task

  • Restored the domain-size condition that every attribute has at least two values; took the attribute set to be nonempty.
  • Made domain enumeration explicit and defined L as total input bit length.
  • Required every attribute to appear exactly once, with unconditional strict total orders over complete domains.
  • Specified that ranks count all configurations in the Cartesian product, including configurations of zero mass.
  • Allowed any minimizing tree when several optima exist; imposed no additional promise connecting the input distribution to an unknown target preference.

Result

The exact optimization problem is solvable in polynomial time in \(m,\tau,d,L\).

The algorithm orders each attribute’s values by decreasing marginal probability, then orders the attributes by an explicitly computable score. This agrees with Proposition 3 of the [cited paper](https://arxiv.org/pdf/2209.11505v1). Below is a self-contained proof, including the bit-complexity argument for binary-rational support input.

1. Decomposing the objective

Write \(n_X=|D_X|\). For a strict total order on \(D_X\), define \(r_X(x)\) as the number of values preceding \(x\). Thus \(r_X(x)\) ranges from \(0\) to \(n_X-1\).

Consider a tree whose attributes, from root to leaf, are \(X_1,\ldots,X_m\). For every configuration \(o\),

\( \displaystyle \operatorname{rank}(\phi,o) = 1+\sum_{k=1}^{m}r_{X_k}(o[X_k]) \prod_{\ell=k+1}^{m}n_{X_\ell}. \)

Here and below, an empty product equals \(1\).

Indeed, every configuration preceding \(o\) has a unique first attribute \(X_k\) at which it differs from \(o\). Its earlier values must equal those of \(o\); its value at \(X_k\) has \(r_{X_k}(o[X_k])\) choices; and its later values are arbitrary. These disjoint classes give the formula.

Define the marginal probability

\( \displaystyle p_X(x)=\sum_{\{i:o_i[X]=x\}}\mu_i. \)

Taking the weighted sum of the rank formula gives

\( \displaystyle F(\phi):=\sum_{i=1}^{\tau}\mu_i\operatorname{rank}(\phi,o_i) = 1+\sum_{k=1}^{m} \left(\sum_{x\in D_{X_k}}p_{X_k}(x)r_{X_k}(x)\right) \prod_{\ell=k+1}^{m}n_{X_\ell}. \)

This identity uses only linearity of expectation. No independence assumption is needed.

2. Optimal value orders

Fix an attribute permutation. Each attribute’s local expected position is multiplied by a positive coefficient, and changing its value order affects no other summand. Consequently, its order can be optimized separately.

Suppose two adjacent values \(x,y\) occupy positions \(j,j+1\), with \(x\) preceding \(y\). Their contribution to the local expected position is

\( \displaystyle j\,p_X(x)+(j+1)p_X(y). \)

After exchanging them, it is

\( \displaystyle j\,p_X(y)+(j+1)p_X(x). \)

The old contribution minus the new contribution equals \(p_X(y)-p_X(x)\). Thus exchanging an adjacent pair whose probabilities increase strictly decreases the objective. Repeated exchanges produce a value order of non-increasing marginal probability.

Let \(x_{X,1},\ldots,x_{X,n_X}\) be such an order, and define

\( \displaystyle a_X=\sum_{j=1}^{n_X}(j-1)p_X(x_{X,j}). \)

The exchange argument proves that \(a_X\) is the minimum possible local expected position. Equal probabilities may be ordered arbitrarily. Values absent from the support have probability zero and are included in the order.

Therefore, for every attribute permutation, the minimum objective over its value orders is

\( \displaystyle G(X_1,\ldots,X_m) = 1+\sum_{k=1}^{m}a_{X_k} \prod_{\ell=k+1}^{m}n_{X_\ell}. \)

3. Optimal attribute order

Define

\( \displaystyle s_X=\frac{a_X}{n_X-1}. \)

This is well-defined because \(n_X\geq 2\).

Consider adjacent attributes \(X,Y\), and let \(T\) be the product of the domain sizes of all attributes following them. Their combined contribution when \(X\) precedes \(Y\) is

\( \displaystyle T(a_Xn_Y+a_Y). \)

When \(Y\) precedes \(X\), it is

\( \displaystyle T(a_Yn_X+a_X). \)

All other contributions remain unchanged: earlier attributes have the same product of later domain sizes, and later attributes retain their positions relative to one another. Hence

\( \displaystyle G(\ldots,X,Y,\ldots)-G(\ldots,Y,X,\ldots) = T\bigl(a_X(n_Y-1)-a_Y(n_X-1)\bigr) = T(n_X-1)(n_Y-1)(s_X-s_Y). \)

Every factor outside \(s_X-s_Y\) is positive. Thus an adjacent score inversion can be exchanged to decrease the objective; exchanging equal scores leaves it unchanged.

Fix any deterministic tie-breaking rule. Starting from any permutation, adjacent exchanges sort it by non-decreasing score, with the chosen tie-breaking rule, without increasing the objective. Therefore that sorted permutation is globally optimal.

Combining this with Section 2 proves that an optimal tree is obtained by:

  • Ordering each \(D_X\) by non-increasing \(p_X(x)\).
  • Computing \(a_X\) and \(s_X=a_X/(n_X-1)\).
  • Ordering attributes from root to leaf by non-decreasing \(s_X\).

This also covers \(m=1\).

4. Exact computation from binary-rational support

It remains to show that the algorithm has polynomial bit complexity, without expanding masses into sample multiplicities.

Write each input mass as \(\mu_i=u_i/v_i\), where \(u_i,v_i\) are positive integers represented in binary. Set

\( \displaystyle Q=\prod_{i=1}^{\tau}v_i, \qquad w_i=u_i(Q/v_i). \)

The divisions are exact. Since the masses sum to \(1\),

\( \displaystyle \mu_i=\frac{w_i}{Q}, \qquad \sum_{i=1}^{\tau}w_i=Q. \)

Moreover,

\( \displaystyle \log_2 Q = \sum_{i=1}^{\tau}\log_2 v_i \leq L. \)

Thus \(Q\) has \(O(L+1)\) bits, even if its numerical value is exponential in the input length.

For every listed domain value, compute the integer marginal mass

\( \displaystyle M_X(x)=\sum_{\{i:o_i[X]=x\}}w_i. \)

Initialize every domain entry to zero, then scan the support. This takes \(O(md+m\tau)\) integer operations once values have been indexed. Such indexing is polynomial-time because the domains and configurations are explicitly listed.

Sort each domain by decreasing \(M_X(x)\). For its resulting order, compute

\( \displaystyle A_X=\sum_{j=1}^{n_X}(j-1)M_X(x_{X,j}). \)

Then \(a_X=A_X/Q\). Attribute scores can be compared entirely with integers:

\( \displaystyle s_X\leq s_Y \quad\Longleftrightarrow\quad A_X(n_Y-1)\leq A_Y(n_X-1). \)

No floating-point approximation or rational division is used in these comparisons.

The integer sizes satisfy

\( \displaystyle 0\leq M_X(x)\leq Q, \qquad 0\leq A_X\leq(n_X-1)Q, \qquad A_X(n_Y-1)\leq(d-1)^2Q. \)

Consequently, all integers used in constructing and comparing the scores have \(O(L+\log(d+1))\) bits.

Computing the common denominator and weights uses \(O(\tau)\) integer multiplications and divisions. Marginal accumulation, domain sorting, score construction, and attribute sorting use

\( \displaystyle O\bigl(m\tau+md\log d+m\log(m+1)\bigr) \)

additional integer operations and comparisons. Each operation has polynomial bit cost by the bounds above. The output contains one attribute permutation and explicitly listed value orders, so its size is polynomial as well.

Hence the algorithm runs in polynomial time in \(m,\tau,d,L\).

5. Relation to the sample bound

Expanding the rational masses into a multiset could produce an exponentially large sample, so the sample running-time bound alone does not establish the desired result. The argument above avoids that expansion: it accumulates integer marginal weights directly and performs exact score comparisons on integers of polynomial bit length.

No enumeration of \(\Omega\) is required.
