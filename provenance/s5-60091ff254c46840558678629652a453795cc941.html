The continuous mirror question, as graded

Given a finite set of roles \(T\), positive rational masses \(\mu_p\) summing to \(1\), and directed trust weights \(a_{pq}\), define \(e_p(x)\) as the minimum incoming weight \(a_{qp}\) over roles with \(x_q<\mu_q\), or \(0\) if there is no such role, and set \(V_\mu(x)=\sum_{(p,q)\in E_T}a_{pq}x_px_q+\sum_{p\in T}x_pe_p(x)\) for \(0\le x\le\mu\). For each integer \(h\) with \(h\mu_p\) integral, form the symmetric clone game \(v_h(S)=V_\mu(x(S))\), where \(x_p(S)\) is the mass of role-\(p\) clones in \(S\). Prove whether \(\Phi_p=\lim_{h\to\infty}h\phi_{p,1}(v_h)\) exists and compute all \(\Phi_p\), with complexity measured in \(|T|\), the input bit length, and requested precision.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) roles with positive binary rational masses \(\mu_p\), where \(\sum_{p\in T}\mu_p=1\). Here \(\tau\) is the support size, not the number of possible types; set \(m=|T|=\tau\).
The input includes a loopless directed graph \((T,E_T)\) with binary rational edge weights \(a_{pq}\in[0,1]\). Missing edges are excluded from minima; present edges of weight zero are included.
For \(x\in\prod_{p\in T}[0,\mu_p]\), define \(e_p(x)=\min\{a_{qp}:(q,p)\in E_T,\ x_q<\mu_q\}\), with empty minimum zero, and \(V_\mu(x)=\sum_{(p,q)\in E_T}a_{pq}x_px_q+\sum_{p\in T}x_pe_p(x)\).
For each positive integer \(h\) satisfying \(h\mu_p\in\mathbb Z\) for every role, let \(N_h=\{(p,k):p\in T,\ 1\le k\le h\mu_p\}\); every clone has mass \(1/h\). Define \(x_p(S)=|S\cap\{(p,k):1\le k\le h\mu_p\}|/h\) and \(v_h(S)=V_\mu(x(S))\).
Let \(\phi_{p,1}(v_h)\) denote the standard Shapley value of clone \((p,1)\). Define \(\Phi_p=\lim_{h\to\infty,\ h\mu_q\in\mathbb Z\ \forall q}h\phi_{p,1}(v_h)\), whenever this limit exists. The computational problem takes a precision parameter \(b\in\mathbb Z_{>0}\) and computes rational approximations to all \(\Phi_p\) with absolute error at most \(2^{-b}\); \(L\) is the total bit length of the graph, weights, and masses.

Do all limits \(\Phi_p\) exist for every input, and is their computation to precision \(2^{-b}\) polynomial-time in \(m,\tau,L,b\), or NP-hard?

Result

All limits exist, and all their values can be computed exactly as rational numbers in polynomial time. Consequently, the requested approximation problem is polynomial-time solvable in \(m=\tau\), \(L\), and \(b\).

The [cited paper](https://arxiv.org/html/2605.18157v1) uses unanimity decompositions for its discrete trust game. We prove the required decomposition directly for the normalized clone game in this question.

1. Notation and the formula

For each role \(j\), let \(d_j\) be its number of incoming neighbors. When \(d_j>0\), order these neighbors as \(q_{j,1},\ldots,q_{j,d_j}\) so that

\(\displaystyle b_j(1):=a_{q_{j,1}j}\leq\cdots\leq b_j(d_j):=a_{q_{j,d_j}j}.\)

Break ties arbitrarily. Define

\(\displaystyle A_j(t):=\{q_{j,1},\ldots,q_{j,t}\},\qquad M_j(t):=\sum_{q\in A_j(t)}\mu_q,\)

with \(A_j(0)=\varnothing\). For an incoming neighbor \(p\) of \(j\), let \(r_j(p)\) denote its position in this ordering.

Set

\(\displaystyle \beta_p:=\begin{cases}b_p(1),&d_p>0,\\0,&d_p=0,\end{cases}\)

and define the internal contribution

\(\displaystyle I_p:=\frac12\sum_{q:(p,q)\in E_T}a_{pq}\mu_q+\frac12\sum_{q:(q,p)\in E_T}a_{qp}\mu_q.\)

We will prove the following exact formula:

\(\displaystyle \Phi_p = I_p+\beta_p+ \sum_{j:(p,j)\in E_T}\mu_j \left[ \sum_{t=r_j(p)+1}^{d_j} \frac{b_j(t)-b_j(t-1)}{M_j(t-1)} - \frac{b_j(d_j)}{M_j(d_j)} \right]. \)

An empty sum is zero. Every denominator appearing here is strictly positive: it is the sum of positive masses over a nonempty set.

2. Decomposition of the external minimum

For a set of roles \(A\subseteq T\), define the completion indicator

\(\displaystyle F_A(x):=\mathbf 1\{x_q=\mu_q\text{ for every }q\in A\}.\)

In particular, \(F_\varnothing(x)=1\).

For a role \(j\) with \(d_j>0\), put \(b_j(0)=0\). We claim that

\(\displaystyle e_j(x)= \sum_{t=1}^{d_j} \bigl(b_j(t)-b_j(t-1)\bigr)F_{A_j(t-1)}(x) - b_j(d_j)F_{A_j(d_j)}(x). \)

To prove this, first suppose that some incoming role is incomplete, and let \(r\) be the smallest index such that \(x_{q_{j,r}}<\mu_{q_{j,r}}\). Then \(F_{A_j(t-1)}(x)=1\) exactly for \(t\leq r\), and \(F_{A_j(d_j)}(x)=0\). The right-hand side therefore equals

\(\displaystyle \sum_{t=1}^{r}\bigl(b_j(t)-b_j(t-1)\bigr)=b_j(r).\)

By the chosen ordering, \(b_j(r)\) is precisely the minimum weight among incomplete incoming roles.

If every incoming role is complete, all the completion indicators equal one. The right-hand side is then \(b_j(d_j)-b_j(d_j)=0\), agreeing with the prescribed empty minimum.

This proof includes tied weights and present edges of weight zero. Missing edges never enter the ordering. When \(d_j=0\), the external term is identically zero.

3. Shapley values of the component clone games

Fix an admissible integer \(h\), and write

\(\displaystyle C_p:=\{(p,k):1\leq k\leq h\mu_p\},\qquad C_A:=\bigcup_{q\in A}C_q.\)

For a nonempty set \(R\) of clones, its unanimity game is

\(\displaystyle u_R(S):=\mathbf 1\{R\subseteq S\}.\)

Its Shapley value is \(1/|R|\) for each clone in \(R\), and zero for every other clone. Indeed, in a uniformly random permutation, a clone in \(R\) has marginal contribution one exactly when it is last among the members of \(R\). Each member has probability \(1/|R|\) of being last.

The Shapley value is linear, because its defining average of marginal contributions is linear in the characteristic function.

The internal component

For each directed edge \((p,q)\in E_T\), looplessness gives \(p\ne q\), and

\(\displaystyle a_{pq}x_p(S)x_q(S) = \frac{a_{pq}}{h^2} \sum_{c\in C_p}\sum_{d\in C_q}u_{\{c,d\}}(S). \)

Each two-clone unanimity game assigns half its coefficient to each member. Thus this edge contributes

\(\displaystyle \frac{a_{pq}|C_q|}{2h^2} = \frac{a_{pq}\mu_q}{2h} \)

to the Shapley value of any clone of \(p\). Likewise, it contributes \(a_{pq}\mu_p/(2h)\) to any clone of \(q\).

Summing the incident edges proves that the internal contribution to \(h\phi_{p,1}(v_h)\) is exactly \(I_p\), independently of \(h\).

An external component

Fix \(j\) and a set \(A\subseteq T\setminus\{j\}\). Consider

\(\displaystyle W_{j,A,h}(S):=x_j(S)F_A(x(S)).\)

A role \(q\) is complete precisely when all clones in \(C_q\) belong to \(S\). Therefore

\(\displaystyle W_{j,A,h}(S) = \frac1h\sum_{c\in C_j}u_{C_A\cup\{c\}}(S). \)

Write \(M(A):=\sum_{q\in A}\mu_q\), including \(M(\varnothing)=0\). Each unanimity set in this sum has size \(hM(A)+1\). Applying the unanimity formula gives

\(\displaystyle h\phi_{p,1}(W_{j,A,h}) = \begin{cases} \dfrac{1}{hM(A)+1},&p=j,\\[6pt] \dfrac{h\mu_j}{hM(A)+1},&p\in A,\\[6pt] 0,&p\notin A\cup\{j\}. \end{cases} \)

For \(p=j\), its designated clone occurs in exactly one summand. For \(p\in A\), it occurs in all \(h\mu_j\) summands. These observations justify both nonzero cases.

Consequently,

\(\displaystyle \lim_{h\to\infty}h\phi_{p,1}(W_{j,A,h}) = \begin{cases} 1,&A=\varnothing,\ p=j,\\[4pt] \dfrac{\mu_j}{M(A)},&A\ne\varnothing,\ p\in A,\\[6pt] 0,&\text{otherwise}. \end{cases} \)

Positivity of the masses ensures \(M(A)>0\) whenever \(A\ne\varnothing\).

4. Existence of all limits

Multiplying the decomposition in Section 2 by \(x_j(S)\) expresses the external contribution of role \(j\) as

\(\displaystyle x_j(S)e_j(x(S)) = \sum_{t=1}^{d_j} \bigl(b_j(t)-b_j(t-1)\bigr)W_{j,A_j(t-1),h}(S) - b_j(d_j)W_{j,A_j(d_j),h}(S). \)

Every set \(A_j(t)\) excludes \(j\), because the graph is loopless. Hence all component formulas from Section 3 apply.

For the receiving role \(j\), only the empty-prefix term survives in the limit. Its coefficient is \(b_j(1)\). All other own-role contributions tend to zero because their completion sets have positive mass.

For an incoming role \(p\), a prefix \(A_j(t-1)\) contains \(p\) exactly when \(t\geq r_j(p)+1\). Its limiting contribution is therefore

\(\displaystyle \mu_j \left[ \sum_{t=r_j(p)+1}^{d_j} \frac{b_j(t)-b_j(t-1)}{M_j(t-1)} - \frac{b_j(d_j)}{M_j(d_j)} \right]. \)

Roles outside \(\{j\}\cup A_j(d_j)\) receive zero from this external component.

There are finitely many components, so linearity permits taking the limit term by term. Adding the internal contribution yields precisely the formula in Section 1.

Finally, admissible integers \(h\) form an unbounded set: every positive multiple of a common denominator of the masses is admissible. Since each component converges as \(h\) tends to infinity, it also converges along this admissible set. This proves existence of every required \(\Phi_p\).

5. Polynomial-time exact computation

The formula gives the following algorithm:

  • Sort the incoming edges of every role by weight.
  • Compute the prefix masses \(M_j(t)\).
  • Initialize each output with \(I_p+\beta_p\).
  • For each role \(j\) and each index \(2\leq t\leq d_j\), add

\(\mu_j(b_j(t)-b_j(t-1))/M_j(t-1)\) to every role in \(A_j(t-1)\).

  • For each role \(j\) with \(d_j>0\), subtract

\(\mu_j b_j(d_j)/M_j(d_j)\) from every incoming role of \(j\).

There are at most \(m(m-1)\) edges. Sorting takes polynomial time, and the updates require at most \(O(m^3)\) rational arithmetic operations.

To verify the bit complexity, write each mass as \(\mu_q=u_q/v_q\). A common denominator \(D=\prod_{q\in T}v_q\) has bit length at most the sum of the input denominator lengths, hence \(O(L)\). Every prefix mass can be represented with denominator \(D\). Since it lies in \([0,1]\), its numerator also has \(O(L)\) bits.

Thus every individual summand used by the algorithm has numerator and denominator of polynomial bit length. Each output adds at most \(O(m^2)\) such summands. Using the product of their denominators as a common denominator still gives polynomial bit length; the numerator gains at most an additional logarithmic factor from summing polynomially many terms. Exact rational arithmetic therefore takes polynomial bit time overall.

The resulting exact rational values already satisfy every requested error tolerance. If dyadic approximations are preferred, output

\(\displaystyle \widehat\Phi_p:=2^{-b}\left\lfloor 2^b\Phi_p\right\rfloor.\)

Then \(|\widehat\Phi_p-\Phi_p|<2^{-b}\), including when \(\Phi_p\) is negative. The additional arithmetic is polynomial in \(L\), \(m\), and \(b\).

6. A check on the boundary contributions

The completion terms cannot be discarded merely because each clone has vanishing mass. They can produce nonzero, even negative, limiting allocations.

For example, take two roles with \(\mu_1=\mu_2=1/2\), and the single edge \((1,2)\) of weight one. The formula gives

\(\displaystyle \Phi_1=\frac14-\frac{\mu_2}{\mu_1}=-\frac34,\qquad \Phi_2=\frac14+1=\frac54.\)

Their mass-weighted sum is

\(\displaystyle \mu_1\Phi_1+\mu_2\Phi_2=\frac14=V_\mu(\mu),\)

as required by Shapley efficiency. The negative contribution reflects the disappearance of the external term when the last clone of role \(1\) enters.
