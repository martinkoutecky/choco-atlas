The continuous mirror question, as graded

Given candidates \(C\), a committee size \(k\), disjoint candidate labels with interval and dominance constraints, a reference committee \(X\), and a rational distribution \(\mu\) over \(\tau\) complete rankings of \(C\), does there exist a size-\(k\) feasible committee \(Y\) whose SNTV score \(\sum_{c\in Y}\sum_{t}\mu_t\,\mathbf{1}[t\text{ ranks }c\text{ first}]\) is at least the score of \(X\)?

Packaged proof task (what the prover saw — nothing else)

Input consists of a candidate set \(C\) with \(|C|=m\), an integer \(1\le k\le m\), pairwise disjoint labels \(\lambda_1,\ldots,\lambda_p\subseteq C\), an explicit list of \(s\) constraints, and a reference committee \(X\subseteq C\) with \(|X|=k\). Labels need not cover \(C\), and \(X\) need not satisfy the constraints.
A society is given by its support: the list of the \(\tau\) distinct types with positive mass, each with its mass as a binary rational. Here types are strict complete rankings of \(C\), masses satisfy \(\sum_{t=1}^{\tau}\mu_t=1\), and \(\tau\) is the support size, not the number of possible rankings.
An interval constraint \(\operatorname{Interval}(a,b,\lambda_i)\), with integer \(0\le a\le b\le m\), requires \(a\le |Y\cap\lambda_i|\le b\). A dominance constraint \(\operatorname{Dominance}(\lambda_i,\lambda_j)\) requires \(|Y\cap\lambda_i|\ge |Y\cap\lambda_j|\). A feasible committee is a subset \(Y\subseteq C\) of cardinality \(k\) satisfying every constraint.
Define the SNTV score \(S_\mu(Z)=\sum_{c\in Z}\sum_{t=1}^{\tau}\mu_t\mathbf{1}\{t\text{ ranks }c\text{ first}\}\). The decision problem asks whether a feasible committee \(Y\) satisfies \(S_\mu(Y)\ge S_\mu(X)\); score ties are accepted.
Let \(L\) be the total binary input length. State running times in \(m,\tau,L,k,p,s\).

Is this distributional constrained SNTV committee decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For an electorate given as an explicit finite list of voters, constrained winner existence with disjoint labels is \(\mathrm{NP}\)-complete even for SNTV ([Ianovski](https://arxiv.org/abs/1902.05909v6)). No separate result for exactly the distributional formulation above was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one and required strictly positive binary rational masses on its explicitly listed support.
  • Interpreted complete rankings as strict linear orders.
  • Specified integer committee size between one and the number of candidates, and integer interval endpoints between zero and the number of candidates.
  • Specified that the reference committee has the requested cardinality but need not be feasible, as permitted by the discrete definition and used by the anchor.
  • Kept committees as ordinary candidate subsets and constraints as integer membership counts; only the electorate is distributional.
  • Allowed labels to leave candidates unlabeled, since disjointness does not require coverage, and imposed no structural restriction on dominance constraints.
  • Accepted equal scores without additional tie-breaking and defined the total input bit length and constraint-count parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The stated decision problem is \(\mathrm{NP}\)-complete, even when all labels are singletons and all masses are dyadic rationals. Thus it is \(\mathrm{NP}\)-hard; a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The proof below directly handles the distributional input and the threshold supplied by the reference committee.

Membership in \(\mathrm{NP}\)

Write each input mass as \(\mu_t=a_t/b_t\), where \(a_t,b_t\) are positive integers encoded in binary. Define
\[ D=\prod_{t=1}^{\tau}b_t, \qquad A_t=a_t(D/b_t), \qquad W(c)=\sum_{\substack{t\\t\text{ ranks }c\text{ first}}}A_t. \]
Then, for every committee \(Z\),
\[ S_\mu(Z)=\frac{1}{D}\sum_{c\in Z}W(c). \]
Consequently, score comparison is exactly the integer comparison
\[ \sum_{c\in Y}W(c)\ge \sum_{c\in X}W(c). \]

The binary length of \(D\) is at most \(L+1\), because the sum of the binary lengths of the input denominators is at most \(L\). Moreover, normalization gives
\[ \sum_{t=1}^{\tau}A_t=D, \]
so all candidate weights and committee weight sums also have \(O(L)\) bits.

A certificate lists the \(k\) members of \(Y\). Its length is \(O(k\log(m+1))\). The verifier checks that these candidates are distinct, computes each label count, verifies all \(s\) constraints, and performs the integer score comparison. Using schoolbook integer arithmetic, a conservative bound for preprocessing and verification is
\[ O\!\left(L+(\tau+m+p+s+k)L^2\right) \]
bit operations. This is polynomial in the input length, proving membership in \(\mathrm{NP}\).

Reduction from CLIQUE

Use the standard \(\mathrm{NP}\)-complete problem CLIQUE: given an explicitly represented simple undirected graph \(G=(V,E)\) and an integer \(r\), decide whether \(G\) contains a clique of size \(r\).

We may restrict to \(2\le r\le |V|\): cases outside this range are decidable immediately and can be mapped to fixed yes- or no-instances.

Write
\[ n=|V|,\qquad e=|E|,\qquad q=\binom r2. \]
If \(e<q\), the graph cannot contain an \(r\)-clique. In this case, output a fixed no-instance: one candidate \(z\), committee size \(1\), label \(\{z\}\), constraint \(\operatorname{Interval}(0,0,\{z\})\), reference committee \(\{z\}\), and one ranking with mass \(1\). No committee is feasible.

Henceforth assume \(e\ge q\), so \(e\ge1\).

Candidates, labels, and constraints

Introduce:

  • a candidate \(v^\ast\) for each vertex \(v\in V\);
  • a candidate \(f^\ast\) for each edge \(f\in E\);
  • one additional candidate \(d\).

Assign every candidate its own singleton label. Denote these labels by \(\lambda_v=\{v^\ast\}\), \(\lambda_f=\{f^\ast\}\), and \(\lambda_d=\{d\}\). They are pairwise disjoint and cover the candidate set.

Set
\[ k=r+q. \]
Since \(n\ge r\) and \(e\ge q\), we have \(1\le k\le n+e+1=m\).

For each edge \(f=\{u,v\}\), impose
\[ \operatorname{Dominance}(\lambda_u,\lambda_f), \qquad \operatorname{Dominance}(\lambda_v,\lambda_f). \]
Also impose
\[ \operatorname{Interval}(0,0,\lambda_d). \]

Because the relevant labels are singletons, these constraints ensure that selecting an edge candidate requires selecting both endpoint candidates. The additional candidate \(d\) is forbidden.

The parameters are
\[ m=p=n+e+1,\qquad s=2e+1. \]

Society and reference committee

Let \(N\) be the smallest power of two satisfying \(N\ge e\).

For each edge \(f\), create a strict complete ranking with \(f^\ast\) first, followed by all other candidates in a fixed order. Give this type mass \(1/N\).

If \(N>e\), create one further strict complete ranking with \(d\) first and give it mass \((N-e)/N\). If \(N=e\), omit this type.

These types are distinct because their first-ranked candidates are distinct. Every listed mass is positive, every mass is dyadic, and their sum is
\[ \frac eN+\frac{N-e}{N}=1, \]
where the second term is absent when it is zero. Thus this is a valid society with
\[ \tau=e+\mathbf 1\{N>e\}\le e+1. \]

Every edge candidate has SNTV weight \(1/N\), and every vertex candidate has weight zero. The remaining weight belongs to the forbidden candidate \(d\).

Choose \(X\) to consist of any \(r\) vertex candidates and any \(q\) edge candidates. These choices exist by the assumptions \(n\ge r\) and \(e\ge q\). Then
\[ |X|=k,\qquad S_\mu(X)=\frac qN. \]
The task permits \(X\) to violate the constraints.

Correctness of the reduction

An \(r\)-clique gives an accepted committee

Suppose \(U\subseteq V\) is an \(r\)-clique. Select its \(r\) vertex candidates and the \(q\) edge candidates corresponding to all edges inside \(U\).

The resulting committee \(Y\) has size \(r+q=k\). Every selected edge has both endpoints selected, so all dominance constraints hold. Also \(d\notin Y\). Hence \(Y\) is feasible, and
\[ S_\mu(Y)=\frac qN=S_\mu(X). \]
Since score ties are accepted, the constructed instance is a yes-instance.

An accepted committee gives an \(r\)-clique

Conversely, suppose \(Y\) is feasible and \(S_\mu(Y)\ge S_\mu(X)\). Let \(a\) be its number of vertex candidates and \(b\) its number of edge candidates.

The interval constraint excludes \(d\), so
\[ a+b=r+q. \]
Only edge candidates contribute to \(Y\)'s score. Therefore
\[ \frac bN=S_\mu(Y)\ge S_\mu(X)=\frac qN, \]
which implies \(b\ge q\), and consequently \(a\le r\).

Each selected edge has both endpoints among the \(a\) selected vertices. Since \(G\) is simple,
\[ b\le \binom a2\le \binom r2=q. \]
Combining this with \(b\ge q\) gives
\[ b=q,\qquad a=r. \]

There are exactly \(\binom r2=q\) unordered pairs among the selected vertices, and \(Y\) contains \(q\) distinct edges joining them. Every pair must therefore be an edge of \(G\). The selected vertices form an \(r\)-clique.

This proves the required equivalence.

Encoding size and running times

Since \(e\le \binom n2\), the construction has
\[ m=p=O(n^2),\qquad s=O(n^2),\qquad \tau=O(n^2),\qquad k=O(n^2). \]
Each mass requires \(O(\log(e+1))\) bits. Listing all complete rankings and the remaining input yields an output length \(L_{\mathrm{out}}\) bounded by
\[ O\!\left( \tau m\log(m+1) +(m+p+s+k)\log(m+1) +\tau\log(e+1) \right) =O\!\left(n^4\log(n+1)\right). \]
The construction can be performed within the same polynomial bound. Thus it is a polynomial-time many-one reduction.

For completeness, a general deterministic algorithm can preprocess the integer weights and enumerate all \(\binom mk\) committees. A conservative bit-operation bound is
\[ O\!\left( L+(\tau+m+p+s+k)L^2 +\binom mk(m+p+s+k)L^2 \right). \]
This is polynomial for fixed \(k\), while the unrestricted problem is \(\mathrm{NP}\)-complete.
