The continuous mirror question, as graded

Given a finite support \(\mathcal T\) of \(\tau\) types with rational masses \(\mu_t\ge 0\), \(\sum_{t\in\mathcal T}\mu_t=1\), additive values \(u_t(e)\ge 0\) for resource categories \(e\), per-capita supplies \(q_e\ge 0\), and an explicitly listed family \(\mathcal F\) of groups \(F\subseteq\mathcal T\), choose amounts \(x_{t,e}\ge 0\) per person of type \(t\), subject to \(\sum_{t\in\mathcal T}\mu_t x_{t,e}\le q_e\) for each \(e\). Find the largest \(\rho\) and a feasible allocation such that, for every group with positive benchmark, \(\sum_{t\in F}\mu_t\sum_e u_t(e)x_{t,e}\ge \rho\,\mu(F)\sum_e q_e\max_{t\in F}u_t(e)\), where \(\mu(F)=\sum_{t\in F}\mu_t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(\mathcal T\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) divisible resource categories, nonnegative binary-rational per-capita supplies \(q_e\), and nonnegative binary-rational additive values \(u_t(e)\), measured in common units. An explicitly listed family \(\mathcal F\) contains \(g\) nonempty protected subsets of \(\mathcal T\), with arbitrary intersections.
An allocation specifies amounts \(x_{t,e}\ge0\) per person of type \(t\), subject to \(\sum_{t\in\mathcal T}\mu_t x_{t,e}\le q_e\) for every category \(e\); unused supply is permitted.
Define \(\mu(F)=\sum_{t\in F}\mu_t\), the group benchmark \(B_F=\mu(F)\sum_e q_e\max_{t\in F}u_t(e)\), and received welfare \(W_F(x)=\sum_{t\in F}\mu_t\sum_e u_t(e)x_{t,e}\).
Compute the largest \(\rho\ge0\) for which a feasible allocation satisfies \(W_F(x)\ge\rho B_F\) for every \(F\in\mathcal F\) with \(B_F>0\), together with an optimal allocation. If every benchmark is zero, report an unbounded objective and any feasible allocation. No fairness constraints apply to unlisted groups.

Is this exact optimization problem solvable in polynomial time in \(m,\tau,g,L\), where \(L\) is the total input bit length, or is it NP-hard?

For a finite list of agents and divisible goods, maximizing the minimum fraction of group proportional shares is polynomial-time solvable ([Feige and Tahan, 2022](https://arxiv.org/abs/2204.06820v1)). No separately stated result for this precise distribution-over-types formulation was identified in the search.

  • Specified binary-rational encoding for values and supplies, and defined L as the total input bit length.
  • Required nonempty protected groups so their maximum valuations are defined; imposed no restriction on intersections or on the number of listed groups.

  • Took rho to be nonnegative without an upper cap, matching the anchor's maximization rather than imposing rho at most one.

Result

The exact optimization problem is solvable in polynomial time in \(m,\tau,g,L\). Both the optimal value and an optimal allocation can be returned as exact rational numbers. The proof uses a linear program directly on the listed types.

1. An equivalent linear program

For each type \(t\) and category \(e\), introduce the aggregate amount
\(y_{t,e}=\mu_t x_{t,e}\).
Because every \(\mu_t>0\), this change of variables is invertible, with
\(x_{t,e}=y_{t,e}/\mu_t\).

The supply constraints become
\(\sum_{t\in\mathcal T}y_{t,e}\le q_e\), and group welfare becomes
\(W_F(x)=\sum_{t\in F}\sum_{e=1}^m u_t(e)y_{t,e}\).

Compute every benchmark \(B_F\), and define
\(\mathcal F_+=\{F\in\mathcal F:B_F>0\}\).
Consider the following linear program:

  • Maximize \(\rho\).
  • Require \(\sum_{t\in\mathcal T}y_{t,e}\le q_e\) for every \(e\).
  • Require \(\sum_{t\in F}\sum_{e=1}^m u_t(e)y_{t,e}-B_F\rho\ge0\) for every \(F\in\mathcal F_+\).
  • Require \(y_{t,e}\ge0\) for every \(t,e\), and \(\rho\ge0\).

All benchmarks are constants computed from the input, so every constraint is linear. There are \(m\tau+1\) variables and at most \(m+g+m\tau+1\) inequalities.

The invertible substitution preserves supply feasibility, every group welfare, and the objective. Thus this linear program is exactly equivalent to the stated optimization problem. Arbitrary intersections cause no difficulty: each listed group contributes its own inequality.

2. Unboundedness and attainment

If \(\mathcal F_+\) is empty, no constraint restricts \(\rho\). The objective is therefore unbounded, and the zero allocation is feasible, as required.

Suppose instead that \(\mathcal F_+\) is nonempty. The point \(y=0,\rho=0\) proves feasibility.

For a group \(F\), write
\(M_{F,e}=\max_{t\in F}u_t(e)\) and
\(U_F=\sum_{e=1}^m q_eM_{F,e}\).
For every supply-feasible \(y\), nonnegativity and the supply constraints imply

\(\displaystyle \sum_{t\in F}\sum_{e=1}^m u_t(e)y_{t,e} \le \sum_{e=1}^m M_{F,e}\sum_{t\in F}y_{t,e} \le \sum_{e=1}^m M_{F,e}q_e =U_F. \)

For \(F\in\mathcal F_+\), we have \(B_F=\mu(F)U_F>0\). Consequently, the group constraint implies
\(\rho\mu(F)U_F\le U_F\), hence
\(\rho\le1/\mu(F)\).

Choose any \(F_0\in\mathcal F_+\). Every feasible point therefore satisfies
\(0\le\rho\le1/\mu(F_0)\).
Also, each coordinate satisfies \(0\le y_{t,e}\le q_e\).

The feasible region is thus nonempty, closed, and bounded. It is compact, so the continuous linear objective attains a finite maximum.

3. Polynomial encoding length and exact computation

The benchmarks can be computed using at most \(gm\tau\) rational comparisons, together with polynomially many additions and multiplications:

\(\displaystyle B_F= \left(\sum_{t\in F}\mu_t\right) \left(\sum_{e=1}^m q_e\max_{t\in F}u_t(e)\right). \)

These computations have polynomial bit complexity. Explicitly, a sum of \(k\) rationals whose numerators and denominators each have at most \(b\) bits can be represented over the product of their denominators. Its numerator and denominator then have \(O(kb+\log(k+1))\) bits. A product of two rationals adds their numerator and denominator bit lengths. Applying these bounds to the displayed expression gives polynomial bit length for every benchmark.

The linear program therefore has polynomial total encoding length: its coefficients are input valuations, computed benchmarks, supplies, and constants.

We use the standard rational linear programming theorem: an explicitly represented linear program with rational coefficients can be solved in time polynomial in its total binary encoding length; when a finite optimum exists, an exact rational optimal solution can be returned. Polynomial-time solvability for rational coefficients is recalled in [Adler and Beling, *Polynomial Algorithms for Linear Programming over the Algebraic Numbers*](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf).

All hypotheses hold here: the program is explicit, has rational coefficients and polynomial encoding length, and, when \(\mathcal F_+\ne\varnothing\), is feasible with an attained finite optimum.

For completeness, the exact output also has polynomial bit length. A linear objective on a nonempty compact polyhedron has an optimal vertex. At a vertex in dimension \(n=m\tau+1\), one can select \(n\) linearly independent tight constraints. Clear their denominators, obtaining an integer system \(Az=b\) whose entries have polynomial bit length. Cramer’s rule expresses each coordinate as a ratio of determinants. If the entries have absolute value at most \(2^s\), Hadamard’s inequality bounds these determinants by \(n^{n/2}2^{ns}\), giving \(O(n(s+\log(n+1)))\) bits. Thus exact output size creates no obstruction.

Finally, from an exact optimal solution \((y^*,\rho^*)\), return
\(x^*_{t,e}=y^*_{t,e}/\mu_t\).
Each division takes polynomial time and increases bit length only polynomially. By the equivalence proved above, this allocation is feasible and achieves \(\rho^*\).

4. Conclusion

The algorithm computes the benchmarks, reports unboundedness with the zero allocation if all benchmarks vanish, and otherwise solves the rational linear program and converts its solution back to per-person amounts.

This directly extends the linear-programming approach in [Feige and Tahan, Proposition 2.2.1](https://arxiv.org/pdf/2204.06820v1). Its running time depends on the listed support size \(\tau\); it requires no expansion of rational masses into individual agents.
