Classification

Theorem

For every fixed integer \(1\le p<\infty\), both constructive and destructive control with rational voter masses are \(\mathrm{NP}\)-complete. In particular, both are \(\mathrm{NP}\)-hard and therefore are not polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).

If \(p\) is supplied as part of the input, both problems remain \(\mathrm{NP}\)-hard, already on instances with \(p=1\).

Reduction from unweighted voters

Fix \(p\). Consider an instance of the corresponding finite unweighted problem, consisting of candidates \(c_1,c_2\in\{0,1\}^d\), voters

\[ v^1,\ldots,v^n\in\{0,1\}^d, \]

and budget \(\epsilon\). By the premise, the constructive and destructive versions of this problem are each \(\mathrm{NP}\)-complete.

Let \(u^1,\ldots,u^\tau\) be the distinct vectors appearing among the voters. For each \(r\), let

\[ m_r=\bigl|\{i:v^i=u^r\}\bigr| \]

be the multiplicity of \(u^r\). Construct the rational-mass instance by setting

\[ q^r=u^r, \qquad \mu_r=\frac{m_r}{n}. \]

These masses are nonnegative and satisfy

\[ \sum_{r=1}^{\tau}\mu_r = \frac{1}{n}\sum_{r=1}^{\tau}m_r = 1. \]

Each rational number \(m_r/n\) has encoding length \(O(\log n)\), and the distinct opinions and their multiplicities can be computed in polynomial time. Thus this is a polynomial-time transformation. It also works if the target formulation requires the \(q^r\) to be pairwise distinct.

Preservation of the election outcome

Fix any feasible perceived position \(\widetilde c_1\). Define

\[ A_r(\widetilde c_1)= \begin{cases} 1,&\text{if }\|\widetilde c_1-u^r\|_p\le \|c_2-u^r\|_p,\\ 0,&\text{otherwise.} \end{cases} \]

The mass voting for \(c_1\) in the constructed instance is

\[ \begin{aligned} M(\widetilde c_1) &=\sum_{r=1}^{\tau}\mu_r A_r(\widetilde c_1)\\ &=\frac{1}{n}\sum_{r=1}^{\tau}m_rA_r(\widetilde c_1)\\ &=\frac{1}{n} \bigl|\{i:\|\widetilde c_1-v^i\|_p \le \|c_2-v^i\|_p\}\bigr|. \end{aligned} \]

Consequently,

\[ M(\widetilde c_1)\ge\frac12 \]

holds exactly when at least half of the original voters vote for \(c_1\). Likewise,

\[ M(\widetilde c_1)<\frac12 \]

holds exactly when fewer than half of the original voters vote for \(c_1\). The weak voter-level inequality also preserves the rule that distance ties favor \(c_1\).

The candidates, budget, and set of feasible perceived positions are unchanged. Therefore:

  • the constructive unweighted instance is a yes-instance exactly when the constructed rational-mass constructive instance is a yes-instance;
  • the destructive unweighted instance is a yes-instance exactly when the constructed rational-mass destructive instance is a yes-instance.

Since the respective source problems are \(\mathrm{NP}\)-complete, both rational-mass problems are \(\mathrm{NP}\)-hard.

The known algorithm for a constant number of distinct opinions does not apply: the reduction only gives \(\tau\le n\), and \(\tau\) is unbounded.

Membership in \(\mathrm{NP}\) for fixed \(p\)

A certificate is the vector \(\widetilde c_1\in\{0,1\}^d\).

For binary vectors \(x,y\), let \(H(x,y)\) denote their Hamming distance. Then

\[ \|x-y\|_p=H(x,y)^{1/p}. \]

Hence a type \(q^r\) votes for \(c_1\) exactly when

\[ H(\widetilde c_1,q^r)\le H(c_2,q^r), \]

which can be checked in \(O(d)\) time.

Writing \(\epsilon=a/b\) with \(a\ge0\) and \(b>0\), budget feasibility is equivalent to

\[ H(\widetilde c_1,c_1)b^p\le a^p. \]

For fixed \(p\), this comparison uses integers of polynomial encoding length. Finally, the supporting rational masses can be added and compared exactly with \(1/2\) in polynomial time.

Thus both problems belong to \(\mathrm{NP}\) for every fixed \(p\), proving the stated \(\mathrm{NP}\)-completeness.
