The continuous mirror question, as graded

Given a path of \(m\) standardized chore locations with per-capita supplies \(\rho_v\ge0\) satisfying \(\sum_v\rho_v=1\), finitely many complete additive disutility types \(T\), rational type masses \(\mu_t\), population scale \(\lambda\), and \(c\ge1\), choose mass variables \(x_{t,I}\ge0\) for every path interval \(I\) and the empty bundle, subject to \(\sum_Ix_{t,I}=\lambda\mu_t\), \(\sum_{t,I\ni v}x_{t,I}=\lambda\rho_v\), and \(x_{t,I}>0\Rightarrow u_t(I)\le cU_t(\lambda\rho)/\lambda\), where \(U_t(\lambda\rho)=\sum_v\lambda\rho_vu_t(v)\); decide whether such a mass allocation exists.

Packaged proof task (what the prover saw — nothing else)

Let \(V=\{1,\ldots,m\}\), with \(m\ge1\), be the vertices of a path in order. Each location supplies standardized chore units; its per-capita supply is a binary rational \(\rho_v\ge0\), with \(\sum_v\rho_v=1\).
A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
Each type specifies complete additive disutilities \(u_t(v)\in\mathbb{Q}_{\ge0}\), normalized by \(\sum_vu_t(v)=1\). The input also contains binary rationals \(\lambda>0\) and \(c\ge1\); total population mass is \(\lambda\).
Let \(\mathcal B\) consist of all nonempty path intervals and \(\varnothing\). Receiving \(I\in\mathcal B\) means receiving one standardized unit at each \(v\in I\), with \(u_t(I)=\sum_{v\in I}u_t(v)\) and \(u_t(\varnothing)=0\).
A mass allocation consists of real variables \(x_{t,I}\ge0\), representing type mass receiving bundle \(I\), satisfying \(\sum_{I\in\mathcal B}x_{t,I}=\lambda\mu_t\) for every \(t\) and \(\sum_{t\in T}\sum_{I\ni v}x_{t,I}=\lambda\rho_v\) for every \(v\).
Require \(x_{t,I}>0\Rightarrow u_t(I)\le cU_t(\lambda\rho)/\lambda\), where \(U_t(\lambda\rho)=\sum_v\lambda\rho_vu_t(v)\). Empty bundles are permitted, and all supply must be allocated.

Is deciding whether such a mass allocation exists in \(\mathsf P\), or is it \(\mathsf{NP}\)-hard? State running times in \(m\), \(\tau\), and the total binary input length \(L\), including the encodings of \(\lambda\) and \(c\).

For finitely many agents and indivisible chores on a path, deciding existence of a connected allocation with each agent's normalized additive disutility at most \(c/n\) is \(\mathsf{NP}\)-complete for every fixed rational \(c\ge1\). [Bouveret, Cechlárová, and Lesca](https://recherche.noiraudes.net/resources/papers/JAAMAS19.pdf)

Result

The decision problem is in \(\mathsf P\). A polynomial-size rational linear program exactly characterizes feasibility, even when \(\tau\) is unrestricted and \(c\) is part of the input.

The proof uses the stated mass formulation: each type’s mass may be split among several bundles.

1. Normalize the population mass

Define
\(\displaystyle a_t:=\sum_{v=1}^{m}\rho_vu_t(v).\)

Since \(\lambda>0\), the admissibility threshold simplifies to
\(\displaystyle \frac{cU_t(\lambda\rho)}{\lambda}=ca_t.\)

For every allocation variable, set \(\displaystyle y_{t,I}:=x_{t,I}/\lambda\). The mass and supply equations become
\(\displaystyle \sum_{I\in\mathcal B}y_{t,I}=\mu_t\quad(t\in T)\)
and
\(\displaystyle \sum_{t\in T}\sum_{I\ni v}y_{t,I}=\rho_v\quad(v\in V).\)

Conversely, multiplying any solution of these normalized equations by \(\lambda\) recovers the original equations. Positive coordinates are preserved by this scaling. Thus feasibility is independent of the numerical value of \(\lambda\).

2. Enumerate admissible bundles

For each listed type \(t\), define
\(\displaystyle \mathcal A_t:=\{I\in\mathcal B:u_t(I)\le ca_t\}.\)

The empty bundle belongs to \(\mathcal A_t\), because its disutility is zero and \(ca_t\ge0\).

There are exactly \(\displaystyle m(m+1)/2\) nonempty path intervals. To test them, compute the prefix sums
\(\displaystyle P_t(0)=0,\qquad P_t(j)=\sum_{v=1}^{j}u_t(v).\)

Then, for \(\displaystyle 1\le i\le j\le m\),
\(\displaystyle u_t([i,j])=P_t(j)-P_t(i-1).\)

Consequently, all admissibility tests require \(\displaystyle O(\tau m^2)\) exact rational arithmetic operations, after computing the prefix sums and thresholds. Equality with the threshold is accepted.

3. An exact linear programming formulation

Introduce one variable \(y_{t,I}\) for each \(\displaystyle t\in T\) and \(\displaystyle I\in\mathcal A_t\). Consider the following rational linear feasibility problem:

\(\displaystyle y_{t,I}\ge0\qquad(t\in T,\ I\in\mathcal A_t),\)

\(\displaystyle \sum_{I\in\mathcal A_t}y_{t,I}=\mu_t\qquad(t\in T),\)

\(\displaystyle \sum_{t\in T}\sum_{\substack{I\in\mathcal A_t\\v\in I}}y_{t,I}=\rho_v\qquad(v\in V).\)

Equivalence proof. Suppose an allocation satisfying the task exists. Normalize it by \(\lambda\). If \(I\notin\mathcal A_t\), its disutility exceeds the threshold, so the admissibility implication forces \(x_{t,I}=0\). Restricting the normalized allocation to admissible bundles therefore satisfies the displayed linear program.

Conversely, suppose the linear program is feasible. Set \(\displaystyle x_{t,I}=\lambda y_{t,I}\) on admissible bundles and set all other coordinates to zero. The normalized equations imply the original mass and supply equations. Every positive coordinate corresponds to an admissible bundle, so its disutility meets the required threshold. This proves both directions.

In particular, the implication involving \(x_{t,I}>0\) introduces no strict constraint: it simply excludes variables for bundles whose disutility exceeds a threshold determined by the input.

4. Binary complexity and running time

Let \(N\) denote the number of variables and \(q\) the number of equality rows. Then
\(\displaystyle N\le\tau\left(1+\frac{m(m+1)}2\right)=O(\tau m^2),\qquad q=\tau+m.\)

The matrix entries are all in \(\{0,1\}\), and the right-hand side consists of the input rationals \(\mu_t\) and \(\rho_v\).

Admissibility can also be determined with polynomial bit complexity. Every prefix sum and threshold has a representation with \(O(L)\) bits: common denominators can be chosen as products of input denominators, whose total binary length is \(O(L)\); the products and sums in the thresholds increase this bound only by a constant factor. Exact comparisons therefore take \(\operatorname{poly}(L)\) bit operations each. Preprocessing takes
\(\displaystyle O\!\left(\tau m^2\operatorname{poly}(L)\right).\)

In standard form, with nonnegativity specified separately, the dense linear program has encoding length
\(\displaystyle B=O\!\left(L+Nq\right)=O\!\left(L+\tau m^2(\tau+m)\right).\)

The rational linear programming theorem gives an exact feasibility algorithm polynomial in the system’s binary encoding length; it applies to rational systems without requiring a nonempty interior. See [Khachiyan’s polynomial-time linear programming theorem](https://www.mathnet.ru/eng/dan42319). Here all coefficients and right-hand sides are rational, and the explicit system has the polynomial encoding bound just established.

Thus a valid overall bit-time bound is
\(\displaystyle O\!\left(\tau m^2\operatorname{poly}(L)\right)+\operatorname{poly}\!\left(L+\tau m^2(\tau+m)\right),\)
or, equivalently,
\(\displaystyle \left(L+\tau m^2(\tau+m)\right)^{O(1)}.\)

This includes reading the encodings of \(\lambda\) and \(c\). The algorithm has no dependence polynomial in their numerical magnitudes.

5. Why the finite-agent hardness does not transfer

The finite indivisible problem requires each agent to receive a single bundle and each chore to have a single recipient. Those discrete restrictions are absent from the mass formulation: a type’s population mass can be split among admissible bundles. Thus the cited finite-agent hardness theorem does not establish hardness here.

The mass problem nevertheless has infeasible instances. For example, take \(m=2\), one type of mass \(1\), \(\rho_1=\rho_2=1/2\), \(u_t(1)=1\), \(u_t(2)=0\), and \(c=1\). The threshold is \(1/2\). Every interval containing vertex \(1\) has disutility \(1\), so its positive supply cannot be allocated.

The linear program decides such instances as well as feasible ones, completing the classification.
