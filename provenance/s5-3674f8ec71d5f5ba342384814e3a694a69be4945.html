The anchor (named result in the paper)

Theorem 5 (Complexity of Nash Stability) — class: hardness

The continuous mirror question, as graded

Given a finite type set \(T\), rational population shares \(\mu_t\), a maximum team size \(M\), and type-level capabilities and preferences, find rational nonnegative intensities \(z_q\) over integral team templates \(q\in\mathbb{Z}_{\ge 0}^{T}\) with \(1\leq |q|\leq M\), satisfying \(\sum_q q_t z_q=\mu_t\) for every type \(t\), such that no member of any used template \(q\) prefers a used destination template \(r+\mathbf e_t\) or a singleton to \(q\); report if no such intensities exist.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Input also includes binary integers \(m,M\geq1\), rational capabilities \(c_t\in[0,1]^m\), and rational \(\epsilon\geq0\). Let \(Q=\{q\in\mathbb Z_{\geq0}^{T}:1\leq|q|\leq M\}\), where \(|q|=\sum_tq_t\), and let \(\mathbf e_t\) be the unit vector for type \(t\).
For \(q\in Q\), define \(v(q)=m^{-1}\sum_{j=1}^{m}\max_{t:q_t>0}c_{tj}-\frac{3}{20}|q|^{13/10}\) and \(u(q)=v(q)/|q|\); values may be negative.
Each type has an explicitly tabulated integer rank \(h_t(q)\) for every \(q\in Q\) with \(q_t>0\); larger ranks mean strict preference and equal ranks mean indifference. These fixed preferences are promised to satisfy \(u(q)>u(s)+\epsilon\implies h_t(q)>h_t(s)\) whenever \(q_t,s_t>0\).
Seek rational intensities \(z_q\geq0\) satisfying \(\sum_{q\in Q}q_tz_q=\mu_t\) for every \(t\). A template is used precisely when \(z_q>0\).
Stability requires, for every used \(q\) and type \(t\) with \(q_t>0\), both \(h_t(q)\geq h_t(\mathbf e_t)\) and \(h_t(q)\geq h_t(r+\mathbf e_t)\) for every used \(r\) with \(|r|<M\). This includes another team of template \(q\) when \(r=q\); the enlarged destination need not already be used, and receiving members have no veto.
Is deciding whether such stable intensities exist in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,M,L\), where \(L\) is the total input bit length, including the preference tables.
Finite-agent Nash-stable partition computation is reported \(\mathrm{NP}\)-hard with unbounded capability dimension, although the accompanying argument supplies no reduction. [Source](https://arxiv.org/html/2604.14386v1)
For general finite hedonic games, Nash-stable existence has \(\mathrm{NP}\)-complete decision problems. [Ballester](https://www.sciencedirect.com/science/article/pii/S0899825603002628) No result settling this precise mass/template problem was located.

Modeling choices made when packaging the task

  • Normalized the positive rational population shares to total mass one; integral team counts are not bounded by individual population shares.
  • Used m for the capability dimension, allowed it to vary, and retained the specified componentwise maximum, average coverage, and coordination cost with exact exponent 13/10.
  • Made the unspecified preference encoding explicit through complete integer-rank tables, allowing ties and requiring fixed complete, transitive preferences.
  • Restored the anchor's epsilon-rationality condition using a nonnegative rational input epsilon; imposed no potential-alignment or value-gap assumptions.
  • Interpreted a used destination as an existing team template r, rather than requiring the enlarged template r plus the arriving member to be used.
  • Restricted joins to destinations below capacity, retained unconditional singleton departures, and allowed joins to another team having the source template.
  • Targeted the existence decision problem underlying the request to find intensities or report nonexistence; counted all preference-table entries in the input bit length.

1. Proven classification

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even with fixed parameters \(m=1\), \(M=3\), and \(\epsilon=1\), with all capabilities zero, all masses dyadic, and every rank in \(\{-1,0,1,2\}\).

The proof below is a direct reduction for rational intensities. It therefore establishes hardness for the stated mass/template model without transferring hardness from finite-agent partition problems.

2. Polynomial certificates and a deterministic running time

Let

\(N=|Q|=\binom{\tau+M}{M}-1.\)

There are exactly

\(R=\tau\binom{\tau+M-1}{M-1}\)

required rank entries: for each type \(t\), subtracting \(\mathbf e_t\) bijects templates containing \(t\) with nonnegative integer vectors of total size at most \(M-1\). Since every template has at least one rank entry, \(N\leq R\leq L\).

Sparse-support lemma

Claim. Every instance admitting stable rational intensities admits such intensities supported on at most \(\tau\) linearly independent templates.

Proof. Write the mass equations as \(Az=\mu\), where the column indexed by \(q\) is the integer vector \(q\). Suppose a stable rational solution has positive support \(S\), and its columns are linearly dependent. There is a nonzero rational vector \(d\), supported on \(S\), with \(Ad=0\).

The vector \(d\) has both positive and negative entries: otherwise the nonnegative, nonzero columns of \(A\) could not have weighted sum zero. Set

\(\lambda=\min_{q\in S:\,d_q>0}z_q/d_q.\)

Then \(z'=z-\lambda d\) is rational, nonnegative, satisfies the same mass equations, and has strictly smaller positive support.

Stability is preserved when positive support shrinks: every remaining source and destination template was already used in the original stable solution. Thus all required comparisons remain valid. Repeating gives linearly independent support, of size at most \(\tau\). \(\square\)

Certificate bit length

Let the resulting support have size \(k\leq\tau\). Select \(k\) rows yielding a nonsingular integer submatrix \(B\). Let \(D\) be the product of the denominators of the input masses. Its bit length is \(O(L)\), and the selected entries of \(D\mu\) are integers between zero and \(D\).

Cramer's rule writes each intensity as

\(z_i=\dfrac{\det B_i}{D\det B},\)

where \(B_i\) replaces one column of \(B\) by the selected entries of \(D\mu\). The determinant expansion gives

\(|\det B|\leq k!M^k,\qquad |\det B_i|\leq k!DM^{k-1}.\)

Consequently, each intensity has bit length

\(O\!\left(L+\tau\log(\tau+1)+\tau\log(M+1)\right).\)

A certificate lists at most \(\tau\) templates and their positive rational intensities. A verifier checks the mass equations, singleton comparisons, and all ordered source/destination comparisons within that support. This takes polynomial bit time in \(m,\tau,L,\log(M+1)\). The utility promise need not be recomputed when verifying promised inputs. Hence the problem belongs to \(\mathrm{NP}\).

A deterministic algorithm enumerates supports of size at most \(\tau\), rejects dependent columns, solves the remaining mass equations exactly, and tests positivity and stability. Its bit running time is bounded by

\(O(L)+(N+1)^\tau\operatorname{poly}\!\left(\tau,L,\log(M+1)\right).\)

In particular, this is \(L^{\tau+O(1)}\), and also bounded by

\((M+1)^{\tau^2}\operatorname{poly}\!\left(m,\tau,L,\log(M+1)\right).\)

Thus fixed support size gives polynomial time under the explicit-table encoding. Capability dimension contributes only through reading the input; stability itself uses the supplied ranks.

3. Reduction from satisfiability

Take a formula with variables \(x_1,\ldots,x_n\) and clauses \(C_1,\ldots,C_k\), each containing three literals. We reduce its satisfiability problem to the stated decision problem.

For type labels \(X,Y,Z\), abbreviate templates by

\([X]=\mathbf e_X,\qquad [X,Y]=\mathbf e_X+\mathbf e_Y,\qquad [X,Y,Z]=\mathbf e_X+\mathbf e_Y+\mathbf e_Z.\)

Introduce:

  • Four types \(A_i,B_i,C_i,D_i\) for every variable.
  • Six types \(P_j,U_j,V_j,W_{j1},W_{j2},W_{j3}\) for every clause.
  • One sentinel type \(s\).

All labels denote distinct types. Thus

\(\tau=4n+6k+1.\)

Put \(H=4n+6k\), \(b=\lceil\log_2(H+1)\rceil\), and \(\delta=2^{-b}\). Every ordinary type has mass \(\delta\), while

\(\mu_s=1-H\delta>0.\)

These are positive dyadic masses summing to one.

Set \(m=1\), \(M=3\), \(\epsilon=1\), and every capability equal to zero. For every template,

\(u(q)=-\frac{3}{20}|q|^{3/10}.\)

Since \(1\leq |q|\leq3\), these utilities lie in \([-9/20,0]\). Their differences are strictly less than \(\epsilon\), so the preference-consistency implication is vacuous. Every rank table constructed below satisfies the promise.

Rank tables

Set every singleton rank to zero. Initially set every nonsingleton rank to \(-1\), then make exactly the following changes.

For each variable, allow these four pairs:

| Template | Rank of first named member | Rank of second named member |
|---|---:|---:|
| \([A_i,B_i]\) | \(1\) | \(1\) |
| \([B_i,C_i]\) | \(1\) | \(1\) |
| \([C_i,D_i]\) | \(2\) | \(1\) |
| \([A_i,D_i]\) | \(2\) | \(1\) |

Also set

\(h_{C_i}([A_i,B_i,C_i])=2.\)

For each clause, allow all nine pairs

\([X,W_{j\ell}],\qquad X\in\{P_j,U_j,V_j\},\quad \ell\in\{1,2,3\},\)

giving both members rank \(1\).

For the literal in position \(\ell\) of clause \(j\):

  • If it is \(x_i\), set \(h_{C_i}([P_j,W_{j\ell},C_i])=2\).
  • If it is \(\neg x_i\), set \(h_{A_i}([P_j,W_{j\ell},A_i])=2\).

Finally, for every ordinary type \(t\), set

\(h_s([s,t])=1,\)

leaving \(h_t([s,t])=-1\).

All entries not specified remain at their initial values. In particular, repeated-type pairs and triples retain rank \(-1\).

4. Exactly which templates can be used

Every used template must give each member rank at least its singleton rank, namely zero.

Every triple has a member of rank \(-1\). Indeed, an exceptional triple has exactly one member of rank \(2\) and its other members have rank \(-1\); all other triples have only rank \(-1\). The exceptions cannot collide: variable exceptions contain only variable-gadget types, whereas clause exceptions contain their distinct clause-position types and one variable type.

Thus no triple can be used.

Among pairs, only the four variable pairs and nine clause pairs per gadget give every member nonnegative rank. Sentinel pairs fail the singleton comparison for their ordinary member; all remaining pairs also fail it.

Consequently, the sentinel can occur only in its singleton, and mass balance forces

\(z_{[s]}=\mu_s>0.\)

No ordinary singleton can be used. If \([t]\) were used, the sentinel in the used template \([s]\) would prefer joining it, because

\(h_s([s])=0<1=h_s([s,t]).\)

Therefore every ordinary type must be covered entirely by its gadget's allowed pairs.

5. Stability forces a satisfying assignment

Variable gadgets cannot mix their two patterns

Fix variable \(i\), and let the four allowed pair intensities be \(y_{AB},y_{BC},y_{CD},y_{AD}\). Their mass equations are

\(y_{AB}+y_{AD}=\delta,\qquad y_{AB}+y_{BC}=\delta,\)

\(y_{BC}+y_{CD}=\delta,\qquad y_{CD}+y_{AD}=\delta.\)

Hence, for some \(a\in[0,\delta]\),

\(y_{AB}=y_{CD}=a,\qquad y_{BC}=y_{AD}=\delta-a.\)

Suppose \(0<a<\delta\). Both \([A_i,B_i]\) and \([B_i,C_i]\) are then used. A member of type \(C_i\) in the latter template prefers joining the former, since

\(h_{C_i}([B_i,C_i])=1<2=h_{C_i}([A_i,B_i,C_i]).\)

The destination pair has size less than \(M\), so this violates stability.

Therefore \(a\) is either zero or \(\delta\). Interpret:

  • \(a=\delta\): \(x_i\) is true, with pairs \([A_i,B_i]\) and \([C_i,D_i]\).
  • \(a=0\): \(x_i\) is false, with pairs \([B_i,C_i]\) and \([A_i,D_i]\).

Each listed pair has intensity \(\delta\).

Every clause has a true literal

The mass equation for \(P_j\) gives

\(\sum_{\ell=1}^{3}z_{[P_j,W_{j\ell}]}=\delta.\)

Choose a position \(\ell\) whose pair has positive intensity.

If that position contains \(x_i\), a false variable assignment would place \(C_i\) in the used pair \([B_i,C_i]\), at rank \(1\). Joining the used clause pair yields rank \(2\), violating stability. Thus \(x_i\) must be true.

If that position contains \(\neg x_i\), a true variable assignment would place \(A_i\) in \([A_i,B_i]\), at rank \(1\). Joining the clause pair again yields rank \(2\), violating stability. Thus \(x_i\) must be false.

The selected literal is therefore true. Every clause is satisfied.

This proves that existence of stable intensities implies satisfiability.

6. A satisfying assignment produces stable intensities

Conversely, take a satisfying assignment.

For each variable, use its corresponding two pairs with intensity \(\delta\). For each clause, choose a true literal position \(\ell\), pair \(P_j\) with \(W_{j\ell}\), and pair \(U_j,V_j\) bijectively with the two remaining \(W\)-types. Give these three pairs intensity \(\delta\). Use \([s]\) with intensity \(\mu_s\).

These intensities satisfy every mass equation. We verify every stability comparison.

Singleton comparisons. Used ordinary pairs give each member rank at least \(1\); the sentinel singleton has rank zero. All satisfy their singleton comparisons.

Joining the sentinel singleton. An ordinary type receives rank \(-1\) in \([s,t]\). The sentinel receives rank \(-1\) in \([s,s]\). Neither improves.

Joining a used ordinary pair. The enlarged template is a triple. Its joining member receives rank \(-1\), except in these two cases:

  • The destination is \([A_i,B_i]\) and the joining type is \(C_i\). That destination is used only when \(x_i\) is true. Then \(C_i\)'s current pair is \([C_i,D_i]\), also giving rank \(2\).
  • The destination is a selected clause pair and the joining type is its designated variable type. The selected literal is true. For a positive literal, \(C_i\)'s current pair gives rank \(2\); for a negative literal, \(A_i\)'s current pair gives rank \(2\).

Thus no comparison gives a strict improvement. This covers destinations equal to the source template as well: their enlargements contain a repeated type and have joining-member rank \(-1\).

The constructed intensities are stable. Together with Section 5, this proves the reduction's equivalence.

7. Encoding size and conclusion

For \(M=3\), the construction has

\(N=\binom{\tau+3}{3}-1=O(\tau^3)\)

templates and

\(R=\tau\binom{\tau+2}{2}=O(\tau^3)\)

rank entries. Ranks have constant bit length, and masses have \(O(\log\tau)\)-bit encodings. The complete preference tables can therefore be generated in polynomial time. Even an encoding that repeats a full template vector beside every entry has size \(O(\tau^4\log(\tau+1))\).

The reduction proves \(\mathrm{NP}\)-hardness for the fixed parameter values stated in Section 1.
