The continuous mirror question, as graded

Given supported types \(T\) with rational masses \(\mu_t\) summing to one, house categories \(H\) with rational per-capita supplies \(\sigma_h\) totaling at least one, and binary utilities \(u_t(h)\), choose nonnegative flows \(x_{t,h}\) with \(\sum_h x_{t,h}=\mu_t\) and \(\sum_t x_{t,h}\le\sigma_h\). Is there a feasible flow assigning at least \(q\) total mass to envy-free units, where an assignment of type \(t\) to category \(h\) is envy-free exactly when \(u_t(h)\ge u_t(h')\) for every category \(h'\) receiving positive mass?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge 1\) house categories \(H\), nonnegative binary-rational supplies \(\sigma_h\) with \(\sum_h\sigma_h\ge 1\), utilities \(u_t(h)\in\{0,1\}\), and a positive binary-rational threshold \(q\).
A feasible allocation consists of real flows \(x_{t,h}\ge 0\) satisfying \(\sum_hx_{t,h}=\mu_t\) and \(\sum_tx_{t,h}\le\sigma_h\); unused supply is allowed.
Put \(S(x)=\{h\in H:\sum_tx_{t,h}>0\}\). Mass assigned from type \(t\) to category \(h\) is envy-free exactly when \(u_t(h)\ge u_t(h')\) for every \(h'\in S(x)\); utility ties cause no envy, and unused categories are ignored.
Define \(V(x)=\sum_{t\in T}\sum_{h\in H}x_{t,h}\mathbf{1}\{u_t(h)\ge u_t(h')\text{ for every }h'\in S(x)\}\). The decision problem asks whether a feasible allocation with \(V(x)\ge q\) exists. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents assigned distinct houses, deciding whether at least a specified positive number of agents are envy-free is NP-complete even with binary utilities. [Kamiyama–Manurangsi–Suksompong](https://arxiv.org/pdf/2106.06925)
For finite agents, deciding whether every agent can be envy-free is polynomial-time solvable. [Gan–Suksompong–Voudouris](https://arxiv.org/abs/1905.00468)
No result settling this precise mass-allocation problem was located in the literature search.

Modeling choices made when packaging the task

  • The threshold domain was unspecified; q is a positive binary rational, carrying over the discrete requirement of a positive threshold. Thresholds above one are permitted.
  • Supply signs were unspecified; supplies are nonnegative, allowing zero-supply categories.
  • Flow domains were unspecified; flows are real and types may split their mass among categories.
  • The mass objective was informal; it counts each assigned portion separately according to its type and destination, rather than declaring an entire type envy-free.
  • The size and encoding conventions were unspecified; the support and category set are nonempty, and L denotes total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The proof accounts for divisible allocations, merges agents with identical utility profiles into support types, and works even when all masses and supplies are dyadic rationals.

Since \(V(x)\le 1\), instances with \(q>1\) are immediate no-instances. The hardness concerns thresholds \(0<q\le 1\).

1. Fixing an allowed set of categories

For a nonempty subset \(S\subseteq H\), define, for \(h\in S\),

\(c^S_{t,h}=\mathbf{1}\{u_t(h)\ge \max_{g\in S}u_t(g)\}\).

Consider the rational linear program that maximizes

\(F_S(x)=\sum_{t\in T}\sum_{h\in S}c^S_{t,h}x_{t,h}\)

subject to

  • \(x_{t,h}\ge 0\);
  • \(\sum_{h\in S}x_{t,h}=\mu_t\) for every \(t\);
  • \(\sum_{t\in T}x_{t,h}\le \sigma_h\) for every \(h\in S\).

Flows outside \(S\) are zero. Categories in \(S\) need not receive positive flow.

Claim. The original instance is a yes-instance if and only if some nonempty \(S\subseteq H\) has a feasible solution to this linear program with \(F_S(x)\ge q\).

Proof. For the forward direction, take \(S=S(x)\) from a witnessing allocation. The coefficients then express exactly the stated envy-free condition, so \(F_S(x)=V(x)\).

Conversely, suppose the linear program has such a solution. Its actual support \(R=S(x)\) is nonempty and satisfies \(R\subseteq S\). Whenever \(c^S_{t,h}=1\), we have

\(u_t(h)\ge \max_{g\in S}u_t(g)\ge \max_{g\in R}u_t(g)\).

Thus every unit counted by \(F_S(x)\) is also counted by \(V(x)\). Hence \(V(x)\ge F_S(x)\ge q\). \(\square\)

The linear program has at most \(m\tau\) variables and \(O(m\tau+m+\tau)\) constraints, with encoding length polynomial in \(m,\tau,L\). Rational linear programming therefore solves it in \(\operatorname{poly}(m,\tau,L)\) time.

Consequently:

  • an \(m\)-bit certificate specifying \(S\) has a polynomial-time verifier, proving membership in \(\mathrm{NP}\);
  • enumerating all \(S\) gives an exact algorithm taking \(2^m\operatorname{poly}(m,\tau,L)\) time.

The use of allowed sets avoids imposing strict positivity constraints on the flows.

2. Divisibility does not improve the optimum for normalized finite instances

Consider a finite instance with \(N\) agents and \(M\ge N\) distinct houses. Every agent receives exactly one house, and assignments are injective.

Group agents with identical utility profiles into types. Let \(a_t\) be the number of agents of type \(t\), so \(\sum_t a_t=N\). Construct a mass instance with

\(\mu_t=a_t/N,\qquad \sigma_h=1/N\).

Utilities remain unchanged.

Lemma. For every feasible mass allocation \(x\), there is a finite assignment with at least \(N V(x)\) envy-free agents.

Proof. Set \(S=S(x)\) and \(y_{t,h}=Nx_{t,h}\). Then

\(\sum_{h\in S}y_{t,h}=a_t,\qquad \sum_t y_{t,h}\le 1,\qquad y_{t,h}\ge 0\).

Using the coefficients \(c^S_{t,h}\) from Section 1, maximize the linear objective

\(\sum_{t,h\in S}c^S_{t,h}y_{t,h}\)

over these constraints. The scaled allocation \(Nx\) is feasible and has objective value \(NV(x)\).

This linear program has an integral optimum. Here are the relevant integrality details. Introduce nonnegative slack variables \(s_h\), making each house constraint

\(\sum_t y_{t,h}+s_h=1\).

Multiply these house equations by \(-1\). Each column for \(y_{t,h}\) now has one entry \(+1\) and one entry \(-1\); each slack column has a single entry \(-1\). This matrix is totally unimodular: in any square submatrix, a column with at most one nonzero permits induction by determinant expansion; otherwise every column has two opposite entries, so the rows sum to zero and the determinant vanishes. Thus every nonsingular square submatrix has determinant \(+1\) or \(-1\).

The right-hand sides are integers. The feasible region is nonempty and bounded, so a linear optimum exists at an extreme point. Total unimodularity and Cramer’s rule imply that this extreme point is integral.

Choose such an optimal \(y^\ast\). Since each house has capacity one, every entry \(y^\ast_{t,h}\) is either zero or one. Type \(t\) receives exactly \(a_t\) distinct houses; assign these houses bijectively to its \(a_t\) agents. This gives an injective finite assignment \(\varphi\).

Its used houses form a subset of \(S\). Therefore, whenever \(c^S_{t,h}=1\), an agent of type \(t\) assigned \(h\) is envy-free in \(\varphi\). It follows that

\(\operatorname{Val}(\varphi)\ge \sum_{t,h\in S}c^S_{t,h}y^\ast_{t,h}\ge NV(x)\).

This proves the lemma. \(\square\)

Conversely, every finite assignment induces a mass allocation by giving its assigned agent-house pairs mass \(1/N\). Identical agents can be aggregated, and the envy-free mass is exactly \(\operatorname{Val}(\varphi)/N\).

Hence the two optimum values satisfy

\(\max_x V(x)=\frac{1}{N}\max_\varphi \operatorname{Val}(\varphi)\).

The essential point is that rounding may remove used categories. Removing categories can only preserve or improve envy-freeness.

3. Padding to make all numerical inputs dyadic

We reduce from the following established \(\mathrm{NP}\)-complete problem: given \(N\) agents, \(M\ge N\) houses, binary utilities, and a positive integer \(k\), determine whether an injective assignment makes at least \(k\) agents envy-free. This is [Kamiyama–Manurangsi–Suksompong, Theorem 3.5](https://arxiv.org/pdf/2106.06925).

We may restrict to \(1\le k\le N\), because thresholds outside that range are trivial.

Let \(D\) be the smallest power of two strictly greater than \(N\), and put \(r=D-N\). Then \(1\le r\le N\) and \(D\le 2N\).

Create a padded finite instance with:

  • the original \(N\) agents and \(M\) houses;
  • \(r\) additional agents and \(r\) additional houses;
  • utility zero for every original agent on every additional house;
  • utility one for every additional agent on every additional house, and zero on every original house.

Padding claim. The original instance admits at least \(k\) envy-free agents if and only if the padded instance admits at least \(k+r\).

Proof. Forward: retain a witnessing original assignment and assign the additional agents bijectively to the additional houses. The additional agents are all envy-free. The original envy-free agents remain envy-free because the added houses have utility zero for them.

Reverse: suppose a padded assignment has at least \(k+r\) envy-free agents. At most \(r\) are additional agents, so at least \(k\) original agents are envy-free.

We now move all original agents onto original houses while preserving every original agent who is already envy-free.

Let \(p\) be the number of original agents assigned additional houses, and let \(a\) be the number of additional agents assigned original houses. The additional houses accommodate \(p\) original agents and \(r-a\) additional agents. Their number is \(r\), so

\(p+(r-a)\le r,\qquad\text{hence }p\le a\).

Assign the \(p\) displaced original agents to \(p\) distinct original houses formerly occupied by additional agents. Keep every other original agent’s assignment. Finally, assign all additional agents bijectively to the additional houses.

The newly used original houses were already used before this modification. An originally envy-free original agent whose assignment stays fixed therefore remains envy-free: the set of used original houses only shrinks, and additional houses have utility zero.

An originally envy-free original agent moved from an additional house previously received utility zero. Envy-freeness therefore means that every previously used house had utility zero for that agent. Its new original house was previously used, so it still receives utility zero and remains envy-free.

Thus at least \(k\) original agents remain envy-free. Restricting their resulting assignment to the original houses gives a witnessing assignment for the original instance. \(\square\)

4. The polynomial reduction

Apply the normalized construction of Section 2 to the padded instance, which has exactly \(D\) agents.

Merge identical utility profiles into support types. If type \(t\) contains \(a_t\) padded agents, set

\(\mu_t=a_t/D\).

Give every one of the \(M+r\) house categories supply

\(\sigma_h=1/D\),

and set the threshold to

\(q=(k+r)/D\).

This satisfies every requirement of the mass problem:

  • every listed type has positive mass, and the masses sum to one;
  • all utilities are binary;
  • total supply is \((M+r)/D\ge (N+r)/D=1\);
  • all masses, supplies, and the threshold are dyadic rationals;
  • \(0<q\le 1\).

By Section 2, the mass instance is a yes-instance exactly when the padded finite instance has at least \(k+r\) envy-free agents. By the padding claim, this holds exactly when the original finite instance has at least \(k\).

The constructed support size satisfies \(\tau\le N+1\), and the number of categories is \(m=M+r\le M+N\). Numerical entries require \(O(\log N)\) bits. Constructing the padded utility table and grouping identical profiles take polynomial time in the source input length. Thus this is a polynomial-time many-one reduction.

Together with Section 1, it proves \(\mathrm{NP}\)-completeness for the precise support-based mass-allocation problem.
