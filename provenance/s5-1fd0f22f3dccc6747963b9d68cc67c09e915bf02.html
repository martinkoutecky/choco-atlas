The continuous mirror question, as graded

Given a connected planar type graph \(H=(T,F)\), rational masses \(\mu_t>0\) summing to \(1\), rational edge weights \(w_{tu}\), and a rational threshold \(B\), partition the atomless mass at each type into coalitions whose positive-mass type supports induce connected subgraphs of \(H\). Decide whether the supremum of \(J=\sum_{\{t,u\}\in F} w_{tu}\sum_{A}\lambda(A\cap I_t)\lambda(A\cap I_u)\) is at least \(B\), where \(I_t\) is the type-\(t\) mass interval.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. The input also gives a connected simple undirected planar graph \(H=(T,F)\), with \(T\) this support, signed rational weights \(w_{tu}\in\mathbb{Q}\), and a threshold \(B\in\mathbb{Q}\); masses satisfy \(\sum_{t\in T}\mu_t=1\).
Realize type \(t\) as a disjoint interval \(I_t\) of Lebesgue measure \(\mu_t\), and write \(\lambda\) for Lebesgue measure. A feasible coalition structure \(\mathcal C\) is a finite or countable partition of \(\bigsqcup_{t\in T}I_t\), modulo null sets, into measurable coalitions of positive mass. Types may split arbitrarily among coalitions; there is no bound on coalition number or size.
For every \(A\in\mathcal C\), its support \(S_A=\{t\in T:\lambda(A\cap I_t)>0\}\) must induce a connected subgraph of \(H\); singleton supports are allowed. Define \(J(\mathcal C)=\sum_{\{t,u\}\in F}w_{tu}\sum_{A\in\mathcal C}\lambda(A\cap I_t)\lambda(A\cap I_u)\).
Let \(m=|F|\) and let \(L\) be the total binary input length. State running times in \(m,\tau,L\).

Is deciding whether \(\sup_{\mathcal C\text{ feasible}}J(\mathcal C)\ge B\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite indivisible vertices, deciding whether a connected coalition partition achieves a given threshold for the sum of internal edge weights is NP-complete on planar graphs; this is also established in the [later full version](https://arxiv.org/pdf/1401.6428). No complexity classification for this precise atomless formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Specified a simple undirected graph, following the full discrete definition; edge weights and the threshold may have either sign.
  • Specified measurable coalitions and finite or countable partitions exhaustive modulo null sets, with positive-mass coalitions; null sets do not affect the objective.
  • Allowed arbitrary real mass splits, singleton type supports, and no bound on coalition number or size.
  • Defined m as the number of graph edges and L as the total binary input length, since no candidate-count parameter exists here.

Result

The decision problem is \(\mathrm{NP}\)-complete, hence \(\mathrm{NP}\)-hard. In particular, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The key fact is that arbitrary splitting of types does not increase the optimum. The supremum is attained by a coalition structure with at most \(\tau\) coalitions, each containing whole type intervals.

1. Exact equivalence with a finite partition problem

Define the effective edge weights
\[ a_{tu}=w_{tu}\mu_t\mu_u. \]
For a partition \(\mathcal P\) of \(T\), define
\[ V(\mathcal P) = \sum_{\{t,u\}\in F} a_{tu}\, \mathbf 1\{t,u\text{ belong to the same block of }\mathcal P\}. \]
Call \(\mathcal P\) connected if every block induces a connected subgraph of \(H\). There are finitely many such partitions, so
\[ M=\max_{\mathcal P\text{ connected}}V(\mathcal P) \]
exists.

We prove
\[ \sup_{\mathcal C\text{ feasible}}J(\mathcal C)=M. \]

Upper bound by independent rounding

Fix a feasible finite or countable coalition structure \(\mathcal C\). Write
\[ x_{tA}=\lambda(A\cap I_t). \]
Because \(\mathcal C\) partitions the population modulo null sets,
\[ x_{tA}\ge 0, \qquad \sum_{A\in\mathcal C}x_{tA}=\mu_t. \]
The objective is well-defined: for every edge,
\[ 0\le \sum_{A\in\mathcal C}x_{tA}x_{uA} \le \left(\sum_{A\in\mathcal C}x_{tA}\right) \left(\sum_{A\in\mathcal C}x_{uA}\right) =\mu_t\mu_u. \]
Consequently, all relevant signed sums converge absolutely.

For each type \(t\), independently choose a label \(Z_t\in\mathcal C\) with probabilities
\[ \Pr(Z_t=A)=\frac{x_{tA}}{\mu_t}. \]
These are probability distributions because every \(\mu_t\) is positive. Only finitely many independent choices are required, even when \(\mathcal C\) is countable.

Group types with equal labels. For an edge \(\{t,u\}\), independence gives
\[ \Pr(Z_t=Z_u) = \sum_{A\in\mathcal C} \frac{x_{tA}x_{uA}}{\mu_t\mu_u}. \]
Thus the expected value of this random type partition is
\[ \begin{aligned} \mathbb E[V] &= \sum_{\{t,u\}\in F} w_{tu}\mu_t\mu_u\,\Pr(Z_t=Z_u)\\ &= \sum_{\{t,u\}\in F} w_{tu}\sum_{A\in\mathcal C}x_{tA}x_{uA}\\ &=J(\mathcal C). \end{aligned} \]
Linearity of expectation applies to signed weights because the edge set is finite and the random value is bounded in absolute value by \(\sum_{\{t,u\}\in F}|a_{tu}|\).

A label group need not induce a connected graph. Refine each group into the connected components of its induced subgraph. This preserves the objective exactly: endpoints of an edge that were in the same group remain in the same component, since that edge itself connects them. Endpoints in different groups remain separated.

The refined partition is therefore connected and has value at most \(M\) for every outcome. Taking expectations proves
\[ J(\mathcal C)\le M. \]

Attainment of the upper bound

Conversely, given a connected type partition \(\mathcal P\), form
\[ A_S=\bigcup_{t\in S}I_t \qquad(S\in\mathcal P). \]
These are measurable coalitions of positive mass, and their supports are exactly the connected blocks \(S\). Their objective value is
\[ J(\{A_S:S\in\mathcal P\})=V(\mathcal P). \]
Applying this construction to a maximizing partition proves the claimed equality and attainment.

This argument does not require planarity.

2. Polynomial reduction proving hardness

Use the finite planar problem supplied in the question: given a connected simple planar graph, signed rational edge weights \(c_{tu}\), and a rational threshold \(K\), decide whether some connected vertex partition has internal-edge sum at least \(K\). Its \(\mathrm{NP}\)-completeness is established by Theorem 2 of [Voice, Polukarov, and Jennings, *Coalition Structure Generation over Graphs*](https://arxiv.org/pdf/1401.6428).

Here is a reduction that uses dyadic masses, so it also works if “binary rational” is interpreted as requiring finite binary expansions.

Keep the graph unchanged, with \(\tau\) vertices. Choose a distinguished vertex \(r\) and set
\[ k=\lceil\log_2\tau\rceil, \qquad \mu_t=2^{-k}\quad(t\ne r), \qquad \mu_r=\frac{2^k-\tau+1}{2^k}. \]
All masses are positive dyadic rationals and their sum is \(1\). Set
\[ w_{tu}=\frac{c_{tu}}{\mu_t\mu_u}, \qquad B=K. \]
The graph remains connected, simple, and planar. For every type partition,
\[ w_{tu}\mu_t\mu_u=c_{tu}, \]
so Section 1 proves that the atomless optimum equals the original finite optimum. The two threshold answers therefore coincide.

Each mass needs \(O(\log(\tau+1))\) bits, and each transformed edge weight adds only \(O(\log(\tau+1))\) bits to its original representation. If the source input length is \(L_{\mathrm{src}}\), the output length satisfies
\[ L=O\!\left(L_{\mathrm{src}}+(m+\tau)\log(\tau+1)\right). \]
The reduction takes \((m+\tau)\operatorname{poly}(L_{\mathrm{src}}+\log(\tau+1))\) bit operations. This proves \(\mathrm{NP}\)-hardness.

3. Membership and running times

By Section 1, a yes-instance has a certificate consisting of a connected partition of the \(\tau\) types. Encode it using one block label per type, requiring \(O(\tau\log(\tau+1))\) bits.

Connectivity of all blocks can be checked together by traversing the graph while retaining only edges whose endpoints have the same label. Their value is the exact rational sum
\[ \sum_{\substack{\{t,u\}\in F\\t,u\text{ have the same label}}} w_{tu}\mu_t\mu_u. \]

For completeness, exact arithmetic has a polynomial bit bound. Write all input rationals with positive denominators. A common denominator for every effective edge weight and \(B\) is
\[ D= \left(\prod_{\{t,u\}\in F}\operatorname{den}(w_{tu})\right) \left(\prod_{t\in T}\operatorname{den}(\mu_t)\right)^2 \operatorname{den}(B). \]
Its bit length is \(O(L)\). Scaling by \(D\) permits integer summation and comparison using integers of \(O(L)\) bits. With schoolbook arithmetic, preprocessing and certificate verification take
\[ O\!\left((m+\tau)L^2\right) \]
bit operations. Hence the problem belongs to \(\mathrm{NP}\).

An elementary exact algorithm enumerates all \(2^m\) edge subsets and evaluates the partition into connected components of each subset. Every connected partition occurs: choose a spanning tree inside each block and take their union. Including exact arithmetic, this yields the bound
\[ O\!\left(2^m(m+\tau)L^2\right). \]

Thus the classification is complete, including countably many coalitions and the non-strict supremum threshold.
