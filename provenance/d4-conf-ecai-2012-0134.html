The continuous mirror question, as graded

Given a matroid activity instance \(M=(X,\mathcal F)\), nonnegative revenue weights \(w\), \(p\) visitor types of equal mass \(1/p\) identified with activity labels, and a positive integer \(k\), compute an integral base \(B\) whose revenue is at least \((k-1)/k\) of the maximum base revenue and whose served population mass is at least \(1/k\) of the maximum mass any base can serve. A type is served when \(B\) contains an activity with its label.

Packaged proof task (what the prover saw — nothing else)

Let \(M=(X,\mathcal F)\) be a matroid on \(m\geq1\) activities, supplied by an independence oracle with polynomial evaluation time \(T_{\mathrm{ind}}\). Each activity has one label \(\lambda(x)\) and a nonnegative binary rational revenue \(w(x)\); labels partition \(X\). No simplicity restriction is imposed.
A society is given by its support: the list of the \(\tau=p\geq1\) types with positive mass, each with its mass as a binary rational. Types are exactly the activity labels and each has mass \(1/p\), so total mass is one. The support size \(\tau\) is not the number of possible types.
A feasible outcome is an integral base \(B\). Define \(R(B)=\sum_{x\in B}w(x)\) and \(S(B)=\sum_{\ell\in\lambda(B)}1/p\). Let \(R^*=\max_{B\text{ base}}R(B)\) and \(S^*=\max_{B\text{ base}}S(B)\), with separate maxima.
The input also contains a positive integer \(k\), encoded in binary; \(L\) denotes the total explicit input bit length. Guarantees use inequalities, including when an optimum is zero.

Does a deterministic algorithm, polynomial in \(m,\tau,L,\log k,T_{\mathrm{ind}}\), always return a base \(B\) satisfying \(R(B)\geq\frac{k-1}{k}R^*\) and \(S(B)\geq\frac1kS^*\)?

Known results: a deterministic polynomial-time algorithm achieves these ratios for nonnegative revenue and the number of distinct labels on arbitrary matroids ([source](https://doi.org/10.3233/978-1-61499-098-7-360)). The specified equal-mass formulation is exactly that problem after normalizing label count by \(p\); consequently this target is already settled.

Modeling choices made when packaging the task

  • Specified nonnegative binary rational revenues and binary encoding of k to make bit complexity precise.
  • Used the polynomial-time independence-oracle model stipulated for the discrete problem.
  • Identified the support with all activity labels, with equal positive masses summing to one, as required by the graded question.
  • Expressed guarantees as inequalities so zero optima remain well-defined.

Conclusion

Yes. The known label-count theorem applies to this equal-mass formulation. The binary encoding of \(k\) also causes no difficulty, as shown below.

Applicable known theorem

Theorem 3 of Gourvès, Monnot, and Tlilane, *Approximate Tradeoffs on Matroids*, gives the following result:

For an arbitrary matroid with nonnegative element weights and one label per element, a deterministic polynomial-time algorithm returns a base \(B\) satisfying
\[ W(B)\geq \frac{k-1}{k}\max_{A\text{ base}}W(A), \qquad |\lambda(B)|\geq \frac1k\max_{A\text{ base}}|\lambda(A)|. \]
The parameter \(k\) is an input positive integer. No simplicity assumption is required in this case. The paper’s “uniform” assumption means that every label has unit gain; it does not require a uniform matroid. Its algorithm uses greedy selection and cardinality matroid intersection. [Theorem 3 and Section 8](https://pdfs.semanticscholar.org/d933/f0c91c297eefa247ed9367932330fdb08726.pdf).

We use this established theorem rather than reprove it.

Normalization and exact arithmetic

Define
\[ C(B)=|\lambda(B)|, \qquad C^*=\max_{B\text{ base}}C(B). \]
Because every supported type is an activity label and has mass \(1/p\),
\[ S(B)=\frac{C(B)}p, \qquad S^*=\frac{C^*}p. \]
The second identity follows because multiplication by the fixed positive constant \(1/p\) preserves maximizers. Consequently,
\[ C(B)\geq \frac{C^*}{k} \quad\Longleftrightarrow\quad S(B)\geq \frac{S^*}{k}. \]

If integer weights are desired, write each revenue as \(w(x)=a_x/b_x\), where \(a_x\geq0\) and \(b_x\geq1\) are integers. Set
\[ D=\prod_{x\in X}b_x, \qquad u(x)=a_x(D/b_x). \]
Then \(u(x)\) is a nonnegative integer and
\[ U(B):=\sum_{x\in B}u(x)=D R(B), \qquad U^*=D R^*. \]
Thus the revenue guarantee for \(U\) is exactly the requested guarantee for \(R\). The bit length of \(D\) is at most the sum of the denominator bit lengths, and every \(u(x)\) has bit length \(O(L)\). This transformation takes polynomial time.

Algorithm and correctness

First compute a maximum-revenue base \(B_R\) by the matroid greedy algorithm, processing elements in nonincreasing revenue order and accepting an element whenever independence is preserved. Fix an input order to break ties deterministically. Let \(r=|B_R|\).

Rank zero

If \(r=0\), the only base is empty. Hence \(R^*=S^*=0\), and returning it satisfies both inequalities.

Assume henceforth that \(r\geq1\).

Large binary parameter

If \(k>m\), return \(B_R\). Its revenue is \(R^*\), so the revenue inequality holds.

Every nonempty base has at least one label, while \(C^*\leq m\). Therefore,
\[ C(B_R)\geq1>\frac{m}{k}\geq\frac{C^*}{k}. \]
Dividing by \(p>0\) proves the satisfaction inequality.

Zero revenue optimum

Suppose \(k\leq m\) and \(R^*=0\). Compute a maximum-cardinality common independent set \(I\) of:

  • the given matroid \(M\);
  • the partition matroid permitting at most one element of each label.

Extend \(I\) to a base \(B\) of \(M\).

To verify optimal satisfaction, every base \(A\) contains a subset with exactly one representative of each label. That subset is independent in both matroids and has size \(C(A)\). Hence \(|I|\geq C^*\). Conversely, any common independent set extends to a base, whose label count is at least its cardinality. Hence \(|I|\leq C^*\). Thus
\[ C(B)\geq |I|=C^*, \]
and therefore \(S(B)=S^*\). Nonnegativity gives \(R(B)\geq0=\frac{k-1}{k}R^*\).

Remaining case

Suppose \(k\leq m\) and \(R^*>0\). Apply the stated theorem to \(M\), the original labels, and the integer weights \(u\). All hypotheses hold: \(M\) is an arbitrary oracle matroid, labels partition its ground set, and weights are nonnegative.

Its returned base satisfies
\[ D R(B)\geq \frac{k-1}{k}D R^*, \qquad C(B)\geq\frac{C^*}{k}. \]
Division by \(D>0\) and \(p>0\), respectively, gives both requested inequalities.

Running time

Greedy optimization and base extension require polynomially many independence queries. The partition-matroid oracle checks label multiplicities in polynomial time, so deterministic cardinality matroid intersection is polynomial in \(m,\tau,L,T_{\mathrm{ind}}\).

The known tradeoff algorithm is invoked only when \(k\leq m\); thus even polynomial dependence on the numerical value of \(k\) is polynomial in \(m\). Larger values require only a binary comparison and the greedy branch. All arithmetic uses polynomial bit length.

The complete algorithm is therefore deterministic and polynomial in \(m,\tau,L,\log k,T_{\mathrm{ind}}\).
