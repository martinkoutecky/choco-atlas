The continuous mirror question, as graded

Given disjoint candidate sets \(C,D\), a target \(p\in C\), a bound \(k\), and a rational distribution \(\mu\) with finite support over strict rankings of \(C\cup D\), is there an \(E\subseteq D\) with \(|E|\le k\) such that \(p\) is a Copeland winner among \(C\cup E\)? For each pair, a candidate receives a Copeland point only when it is preferred by mass strictly greater than \(1/2\); rankings are restricted to the participating candidates.

Packaged proof task (what the prover saw — nothing else)

Given finite disjoint candidate sets \(C,D\), a designated candidate \(p\in C\), and a binary-encoded nonnegative integer \(k\), let \(m=|C\cup D|\).
A society is given by its support: a list of \(\tau\) distinct strict rankings of \(C\cup D\), each with a positive binary-rational mass, with masses summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length. State running times in \(m,\tau,L,k\).
For any participating set \(A=C\cup E\), restrict each ranking to \(A\). Under \(\mathrm{Copeland}^{0}\), a candidate receives one point against another candidate exactly when the mass preferring it exceeds \(1/2\); losses and pairwise ties receive zero points. Every candidate with maximum total score is a winner, with no further tie-breaking.
The decision problem asks whether some \(E\subseteq D\) with \(|E|\le k\) makes \(p\) a winner.

Is this decision problem solvable in polynomial time in the encoded input size, or is it \(\mathrm{NP}\)-hard?

For explicitly listed discrete voters with strict rankings, constructive control by adding at most \(k\) candidates under \(\mathrm{Copeland}^{0}\) is \(\mathrm{NP}\)-complete, allowing co-winners; the result also holds when a unique winner is required. [Source](https://arxiv.org/pdf/0809.4484).
No result explicitly addressing this normalized binary-rational mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Specified that the rational distribution has positive support masses summing to one.
  • Interpreted winner as allowing co-winners, following the discrete control definition; no further tie-breaking is used.
  • Specified that k is a binary-encoded nonnegative integer supplied as part of the input.
  • Defined m as the total number of registered and available candidates and L as the total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete. This holds even when every mass is a dyadic rational, meaning a rational whose denominator is a power of two. Consequently, a polynomial-time algorithm in the encoded input size exists if and only if \(\mathrm{P}=\mathrm{NP}\).

Polynomial-time verification

Write the support as \((R_i,w_i)_{i=1}^{\tau}\), where \(R_i\) is a strict ranking and \(w_i=a_i/b_i>0\), with numerator and denominator encoded in binary.

For distinct candidates \(x,y\), define
\(M(x,y)=\sum_{i:\,x\text{ precedes }y\text{ in }R_i}w_i\).
Let \(W(x,y)=1\) when \(M(x,y)>1/2\), and \(W(x,y)=0\) otherwise.

Restricting a ranking to a participating set preserves the relative order of every surviving pair. Therefore, for any participating set \(A\) and any \(x\in A\), its score is exactly
\(s_A(x)=\sum_{y\in A\setminus\{x\}}W(x,y)\).

These quantities can be computed with polynomially bounded exact arithmetic. Set
\(Q=\prod_{i=1}^{\tau}b_i\) and \(u_i=a_i(Q/b_i)\).
The bit length of \(Q\) is at most \(L+1\). Moreover, normalization gives \(\sum_i u_i=Q\), so every partial sum of the positive integers \(u_i\) is at most \(Q\). Thus
\(W(x,y)=1\) exactly when \(2\sum_{i:\,x\text{ precedes }y\text{ in }R_i}u_i>Q\).
Equality is detected exactly and awards zero points.

Using schoolbook integer arithmetic, computing the \(u_i\), inverse rankings, and all pairwise outcomes takes
\(O(\tau L^2+\tau m^2L)\)
bit operations.

A certificate is a bit vector specifying \(E\subseteq D\). Verify that \(|E|\le k\), then compute the scores on \(A=C\cup E\) and check
\(s_A(p)\ge s_A(x)\) for every \(x\in A\).
After pairwise preprocessing, this takes
\(O(m^2\log(m+1)+L)\)
bit operations. The certificate and verification time are polynomial in the encoded input size, proving membership in \(\mathrm{NP}\).

Polynomial reduction from discrete voters

We use the supplied discrete-voter hardness result. Specifically, Theorem 4.9 of Faliszewski, Hemaspaandra, Hemaspaandra, and Rothe proves hardness for adding a bounded number of candidates, including \(\mathrm{Copeland}^{0}\), strict rankings, and the nonunique-winner model. These are precisely the voting rule, preference restriction, and success condition needed here. [Source, Theorem 4.9](https://arxiv.org/pdf/0809.4484).

Take such an instance with \(n>0\) explicitly listed voters. Keep \(C,D,p,k\) unchanged. We construct a normalized society preserving every pairwise outcome.

Choose the least power of two \(T\) satisfying \(T\ge 2n\). Then \(2n\le T<4n\). Form a voter multiset as follows:

  • Include two copies of each original voter.
  • Choose any strict ranking \(R\) of \(C\cup D\), and let \(R^{\mathrm{rev}}\) be its reverse.
  • Include \((T-2n)/2\) copies of each of \(R\) and \(R^{\mathrm{rev}}\).

The multiplicity in the third step is a nonnegative integer because both \(T\) and \(2n\) are even. The resulting multiset has exactly \(T\) voters.

Now group identical rankings. For every ranking \(S\) with positive multiplicity \(c_S\), output \(S\) once with mass \(c_S/T\). These masses are positive dyadic rationals and sum to one. The output rankings are distinct, as required.

Preservation of pairwise outcomes

For distinct candidates \(x,y\), let \(v(x,y)\) count original voters preferring \(x\) to \(y\), and define the original margin
\(\Delta(x,y)=v(x,y)-v(y,x)\).

Doubling the original voters changes this margin to \(2\Delta(x,y)\). Each added pair consisting of \(R\) and \(R^{\mathrm{rev}}\) contributes zero: exactly one ranking prefers \(x\) to \(y\).

Consequently, the normalized society satisfies
\(2M(x,y)-1=2\Delta(x,y)/T\).
Since \(T>0\), this identity preserves the sign of every margin. In particular:

  • An original strict victory remains a strict victory.
  • An original strict loss remains a strict loss.
  • An original pairwise tie remains an exact tie.

Restriction to any \(C\cup E\) preserves these pairwise comparisons. Hence every participating candidate has exactly the same \(\mathrm{Copeland}^{0}\) score before and after the transformation. For every \(E\subseteq D\),
\(p\) is an original winner on \(C\cup E\) if and only if \(p\) is a normalized-society winner on \(C\cup E\).

Because the budget is unchanged, the reduction preserves the answer to the control problem.

Polynomial encoding size

There are at most \(n+2\) distinct output rankings. Each multiplicity and \(T\) require \(O(\log(n+1))\) bits. After relabeling candidates by integers, the output bit length is bounded by
\(O((n+2)(m\log(m+1)+\log(n+1))+\log(k+2))\).

The source explicitly lists its voters, so this size is polynomial in its input length. Grouping rankings and computing their masses also take polynomial time; no enumeration of all possible rankings is used.

If zero-voter source instances are permitted, they always have a yes answer in the co-winner model, since all scores are zero. They can be mapped to the fixed yes instance with \(C=\{p\}\), \(D=\varnothing\), \(k=0\), and one ranking of mass one. Thus the reduction covers that case as well.

This proves \(\mathrm{NP}\)-hardness and, together with membership, \(\mathrm{NP}\)-completeness.

Explicit deterministic running time

Let \(d=|D|\), \(k'=\min\{k,d\}\), and
\(B(d,k')=\sum_{j=0}^{k'}\binom{d}{j}\).

Precompute the pairwise outcomes, then enumerate all eligible subsets and verify their scores. The resulting exact algorithm runs in
\(O(\tau L^2+\tau m^2L+B(d,k')m^2\log(m+1))\)
bit operations.

Thus the problem is polynomial-time solvable for every fixed budget \(k\), while the general problem with binary-encoded, variable \(k\) is \(\mathrm{NP}\)-complete.
