The continuous mirror question, as graded

Given rational masses \(\mu_t\) over the six strict rankings of \(\{a,b,c\}\) and a target candidate \(x\), does there exist a sequence of finite electorates with integer type counts \(N_t^{(r)}\), totals \(n_r\to\infty\), and \(N_t^{(r)}/n_r\to\mu_t\), such that \(x\in S_B(N^{(r)})\) for every \(r\), where \(S_B\) is the paper’s Borda solution after iterated elimination of weakly dominated strategies?

Packaged proof task (what the prover saw — nothing else)

Let \(A=\{a,b,c\}\), with \(m=3\), and let types be strict rankings of \(A\). A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Masses sum to \(1\); omitted types have mass \(0\). Let \(L\) be the total input bit length.
For integer counts \(N_t\geq0\) with \(n=\sum_tN_t>0\), form the complete-information voting game containing \(N_t\) individual voters of type \(t\). Each voter independently chooses any ranking ballot under Borda.
An indifferent tiebreaker may report any strict ordering of \(A\), selecting the highest-ranked candidate among those tied for the highest score. Its reports are never eliminated.
Starting with all ballots, simultaneously delete every weakly dominated ballot at each round until no further deletion is possible. Domination must be by another remaining pure ballot, weakly improve the voter's outcome against every remaining opposing ballot profile and every tiebreaker report, and strictly improve it for at least one such pair.
Define \(S_B(N)\) as all candidates obtainable from remaining ballot profiles and tiebreaker reports.
Given the society and \(x\in A\), decide whether there exist integer count vectors \(N^{(r)}\) with \(n_r=\sum_tN_t^{(r)}\to\infty\), \(N_t^{(r)}/n_r\to\mu_t\) for every type, and \(x\in S_B(N^{(r)})\) for every \(r\). Types of zero limiting mass may occur in these electorates.
Is this limiting membership problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and \(L\), with \(m=3\) fixed.
For finite electorates, an exact characterization determines when the Borda solution is a singleton; otherwise the solution is \(A\). [Basteck (2022)](https://doi.org/10.1007/s00199-021-01353-w)
No result settling this exact limiting membership problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the rational masses to sum to one, as required by convergence of electorate proportions.
  • Specified strategic ranking ballots, domination by remaining pure ballots, simultaneous elimination, and universal quantification over the permanently unrestricted indifferent tiebreaker's reports, following the discrete definitions.
  • Allowed zero-mass types to occur with vanishing proportions in approximating electorates, since the stated sequence question imposes convergence rather than identical support.
  • Fixed the candidate count at three and defined L as the total input bit length.

Result

The limiting membership problem is in \(\mathrm{P}\) for fixed \(m=3\).

More generally, there are computable functions \(f\) and \(g\), depending only on \(m\), giving a running-time bound

\(f(m)+g(m)\bigl(L+\tau m\lceil\log_2(m+1)\rceil+1\bigr)^2.\)

Thus, for \(m=3\), the bound is \(O(L^2)\), since \(\tau\leq 6\). The preprocessing implicit in \(f(m)\) may be enormous. This is a complexity classification, not a practical implementation.

The proof works directly with the specified simultaneous deletion procedure.

1. Deletion takes a bounded number of rounds

Let \(\mathcal T\) be the set of all strict preference types and \(\mathcal B\) the set of all ranking ballots. Write \(k=m!\); both sets have size \(k\). Count vectors have coordinates for all types, including those omitted from the society’s support.

For a fixed electorate, let \(I=\{t:N_t>0\}\). At every deletion round, all voters of any given type \(t\in I\) have the same remaining ballot set.

To prove this, initially their ballot sets coincide. Suppose they coincide at some round. Transposing two voters of the same type gives a bijection between their opposing profiles, preserves the aggregate Borda scores, and preserves their preferences. Therefore a ballot is dominated for one voter exactly when it is dominated for the other. Simultaneous deletion preserves the equality of their ballot sets.

Consequently, a deletion state is a tuple \(B=(B_t)_{t\in I}\), where each \(B_t\) is a nonempty subset of \(\mathcal B\).

Nonemptiness requires justification. On a fixed nonempty domain of opposing profiles and tiebreaker reports, pure weak dominance with a strict improvement somewhere is an irreflexive, transitive relation. Indeed, composing two pointwise weak improvements gives a pointwise weak improvement, and a strict witness for either comparison remains strict after composition. A finite nonempty ballot set therefore contains an undominated ballot. Simultaneous deletion cannot empty it.

Every round that changes the state deletes at least one type–ballot pair. At most

\(|I|(k-1)\leq k(k-1)\)

such pairs can be deleted. Once a round makes no change, all subsequent rounds make no change. Hence after

\(R=k(k-1)\)

rounds the state is terminal, independently of the electorate size and the magnitudes of its counts. For \(m=3\), \(R=30\).

2. Finite membership is Presburger-definable

Presburger arithmetic is first-order arithmetic on nonnegative integers using addition, order, and integer constants. Multiplication by a fixed integer is permitted as repeated addition; multiplication of two variables is not.

Fix a presence set \(I\), a state \(B\), a present type \(t\), and ballots \(p,q\in B_t\). We describe exactly when \(q\) dominates \(p\).

Encoding opposing profiles

For \(s\in I\) and \(b\in B_s\), introduce a nonnegative integer \(y_{s,b}\), the number of opposing voters of type \(s\) casting ballot \(b\). The feasibility constraints are

\(\displaystyle \sum_{b\in B_s}y_{s,b}+\mathbf 1_{\{s=t\}}=N_s\quad(s\in I).\)

Every opposing profile produces such an allocation. Conversely, every feasible allocation can be realized by assigning ballots to the individually labelled opposing voters.

Let \(s_b(j)\in\{0,\ldots,m-1\}\) be candidate \(j\)’s Borda score on ballot \(b\). If the distinguished voter casts \(p\), candidate \(j\)’s total score is

\(\displaystyle H_j^p(y)=s_p(j)+\sum_{s\in I}\sum_{b\in B_s}s_b(j)y_{s,b}.\)

These are linear expressions with fixed integer coefficients.

For a fixed tiebreaker ranking \(\rho\), candidate \(j\) wins under \(p\) precisely when, for every \(h\neq j\),

  • \(H_j^p(y)\geq H_h^p(y)\) if \(\rho\) ranks \(j\) above \(h\);
  • \(H_j^p(y)>H_h^p(y)\) if \(\rho\) ranks \(h\) above \(j\).

Thus winner predicates are Presburger formulas.

Encoding domination

Assign utility \(u_t(j)=m-\operatorname{rank}_t(j)\). Only the resulting strict ordering matters.

Define \(\operatorname{Bad}_{t,p,q}^B(N)\) to assert that there exist a feasible allocation \(y\) and a tiebreaker ranking \(\rho\) for which the winner under \(q\) is strictly worse for type \(t\) than the winner under \(p\).

Define \(\operatorname{Good}_{t,p,q}^B(N)\) analogously, requiring the winner under \(q\) to be strictly better.

These are Presburger formulas: enumerate the finitely many rankings \(\rho\) and ordered winner pairs, and existentially quantify \(y\). The same allocation and the same tiebreaker report are used for both ballots.

The exact domination predicate is therefore

\(\operatorname{Dom}_{t,p,q}^B(N) =\neg\operatorname{Bad}_{t,p,q}^B(N)\land \operatorname{Good}_{t,p,q}^B(N).\)

A ballot \(p\in B_t\) is deleted exactly when this predicate holds for some \(q\in B_t\).

Encoding the complete procedure

There are finitely many presence sets and deletion states, depending only on \(m\). For every pair of states \(B,C\), the assertion that \(C\) is obtained from \(B\) by one simultaneous deletion round is a finite Boolean combination of the domination predicates.

Enumerate all state sequences of length \(R+1\), starting with all ballots. Conjoin their transition predicates and the appropriate presence conditions \(N_t>0\) or \(N_t=0\).

Finally, membership of \(x\) in the resulting solution is expressed by existentially quantifying ballot allocations for all voters in the terminal state and requiring \(x\)’s score to be at least every other candidate’s score. This condition is sufficient because the tiebreaker may rank \(x\) first among the tied maximizers.

It follows that

\(E_x=\{N\in\mathbb N^k:\sum_tN_t>0,\ x\in S_B(N)\}\)

is defined by an effectively constructible Presburger formula \(\Phi_{m,x}(N)\). Crucially, this formula depends only on \(m\) and \(x\), not on the society’s masses or input bit length.

3. Semilinear structure

A linear set in \(\mathbb N^k\) has the form

\(\displaystyle b+\sum_{j=1}^{q}\mathbb N v_j,\)

where \(b,v_1,\ldots,v_q\in\mathbb N^k\). A semilinear set is a finite union of linear sets.

The Ginsburg–Spanier theorem states that subsets of \(\mathbb N^k\) definable in Presburger arithmetic are exactly the semilinear sets. It applies here because \(\Phi_{m,x}\) uses only integer constants, addition, order, Boolean operations, and integer quantification. See [Ginsburg and Spanier, *Semigroups, Presburger formulas, and languages*](https://www.csa.iisc.ac.in/~deepakd/atc-common/ginsburg-spanier-PJM-1966.pdf).

Hence

\(\displaystyle E_x=\bigcup_{\ell=1}^{h} \left(b_\ell+\sum_{j=1}^{q_\ell}\mathbb N v_{\ell j}\right).\)

This representation can be computed effectively. One explicit, potentially very slow procedure enumerates finite semilinear descriptions and uses Presburger decidability to test equivalence with \(\Phi_{m,x}\). The theorem guarantees eventual termination. Thus this preprocessing is a computable function of \(m\) alone.

Discard zero period vectors. For each component with at least one remaining period, define the rational polytope

\(\displaystyle P_\ell=\operatorname{conv} \left\{\frac{v_{\ell j}}{\lVert v_{\ell j}\rVert_1}:1\leq j\leq q_\ell\right\}.\)

Components without nonzero periods are singletons and contribute no asymptotic directions.

4. Exact characterization of the limits

We prove the required limit statement, rather than merely replacing finite inequalities by their limiting versions.

Lemma. For a linear set \(H=b+\sum_{j=1}^{q}\mathbb N v_j\), with every \(v_j\neq0\), its attainable normalized limits along sequences with diverging total count are exactly

\(\displaystyle \operatorname{conv}\left\{\frac{v_j}{\lVert v_j\rVert_1}:1\leq j\leq q\right\}.\)

Necessity. Suppose

\(\displaystyle N^{(r)}=b+\sum_j c_j^{(r)}v_j,\qquad n_r=\lVert N^{(r)}\rVert_1\longrightarrow\infty.\)

Put \(M_r=\sum_j c_j^{(r)}v_j\). Since all coordinates are nonnegative,

\(\lVert M_r\rVert_1=n_r-\lVert b\rVert_1\longrightarrow\infty.\)

For all sufficiently large \(r\),

\(\displaystyle \frac{M_r}{\lVert M_r\rVert_1} =\sum_j \frac{c_j^{(r)}\lVert v_j\rVert_1}{\lVert M_r\rVert_1} \frac{v_j}{\lVert v_j\rVert_1}\)

is a convex combination of the normalized periods. Moreover,

\(\displaystyle \left\lVert \frac{N^{(r)}}{n_r} -\frac{M_r}{\lVert M_r\rVert_1} \right\rVert_1 \leq\frac{2\lVert b\rVert_1}{n_r}\longrightarrow0.\)

The convex hull is closed, being the convex hull of finitely many points. Therefore any normalized limit belongs to it.

Sufficiency. Suppose

\(\displaystyle \mu=\sum_j\lambda_j\frac{v_j}{\lVert v_j\rVert_1}, \qquad \lambda_j\geq0,\qquad\sum_j\lambda_j=1.\)

Choose

\(\displaystyle c_j^{(r)} =\left\lfloor\frac{r\lambda_j}{\lVert v_j\rVert_1}\right\rfloor, \qquad N^{(r)}=b+\sum_jc_j^{(r)}v_j.\)

Then \(N^{(r)}\in H\) and \(N^{(r)}/r\to\mu\). Since \(\lVert\mu\rVert_1=1\), also \(n_r/r\to1\). Consequently \(n_r\to\infty\) and \(N^{(r)}/n_r\to\mu\). Discarding a finite initial segment ensures every electorate is nonempty. This proves the lemma.

For the finite union describing \(E_x\), any witnessing sequence has an infinite subsequence in one component. That subsequence retains its normalized limit and its diverging total count. Conversely, the lemma constructs a witnessing sequence inside any component whose polytope contains \(\mu\).

Thus the exact answer criterion is

\(\displaystyle \text{limiting membership holds} \quad\Longleftrightarrow\quad \mu\in\bigcup_{\ell:q_\ell>0}P_\ell.\)

Zero-mass types and boundary points

The criterion uses all \(k\) coordinates and closed polytopes, so it includes both boundary societies and types of zero limiting mass.

In fact, because the input \(\mu\) is rational, a stronger statement holds: whenever membership is possible, it has a witnessing sequence in which every zero-mass type has a bounded count.

To justify this, a rational point in a convex hull of rational vertices has rational convex coefficients. Choose a representation with minimal support. Its vertices are affinely independent; otherwise an affine dependence allows adjustment of the coefficients until one becomes zero, contradicting minimality. The coefficients consequently solve a full-rank rational linear system and are rational.

Choose a positive integer \(D\) such that every \(D\lambda_j/\lVert v_j\rVert_1\) is an integer. Then

\(\displaystyle w=\sum_j\frac{D\lambda_j}{\lVert v_j\rVert_1}v_j=D\mu\)

is an integer combination of periods with nonnegative integer coefficients. The sequence \(N^{(r)}=b+rw\) lies in the component and converges after normalization to \(\mu\). If \(\mu_t=0\), then \(w_t=0\), so \(N_t^{(r)}=b_t\) throughout.

5. Algorithm and running time

The algorithm is:

  • Precompute the semilinear representation of \(E_x\), its normalized-period polytopes, and rational linear inequalities describing each polytope.
  • Expand the supplied society into all \(m!\) coordinates, assigning mass zero to omitted types.
  • Test whether \(\mu\) satisfies every inequality of at least one polytope.

The inequality descriptions can be obtained effectively by eliminating the convex-combination variables from each finite rational linear system. All their coefficients, dimensions, and numbers depend only on \(m\).

For the query, multiply the input denominators to obtain a common denominator. Its bit length is at most the sum of their input bit lengths, hence \(O(L)\). Each fixed rational inequality can then be checked exactly using integer arithmetic. With elementary quadratic-time arithmetic, the total bound is

\(f(m)+g(m)\bigl(L+\tau m\lceil\log_2(m+1)\rceil+1\bigr)^2\)

for computable functions \(f,g\). No enumeration up to an electorate size is required.

For \(m=3\), all preprocessing data are fixed constants, there are six type coordinates, and \(\tau\leq6\). The resulting decision problem is therefore polynomial-time solvable.

The induction is valid. Initially, voters of a given type have identical ballot sets. At a subsequent round, transposing two such voters identifies their opposing-profile domains, preserves aggregate scores for each tested ballot, and preserves preferences. Their domination tests therefore agree. This justifies representing a state by one remaining ballot set per present type.

  • Nonemptiness and the round bound.

On the fixed domain used in a deletion round, pure weak dominance with a strict witness is irreflexive and transitive. A strict improvement remains strict when composed with a weak improvement because outcomes are ordered by the voter’s strict preference ranking. Thus every finite nonempty ballot set contains an undominated ballot.

Consequently, each present type can lose at most \(k-1\) ballots, where \(k=m!\). Every changing round removes at least one type–ballot pair, giving the bound \(R=k(k-1)\). For \(m=3\), this is \(30\). If all \(R\) rounds change the state, the deletion budget is exhausted and every present type has one ballot left; otherwise a stationary round has already occurred. In either case, the state after \(R\) rounds is terminal.

The allocation constraints correctly exclude exactly the distinguished voter:
\(\sum_{b\in B_s}y_{s,b}+\mathbf 1_{\{s=t\}}=N_s\).

Every feasible allocation is realizable by labelled opposing voters, and every opposing profile yields such an allocation. Aggregation loses no information relevant to Borda outcomes.

The winner predicates also handle ties correctly. A candidate needs a weak score inequality against candidates ranked below it by the tiebreaker, and a strict inequality against candidates ranked above it. This exactly describes selection among the score maximizers.

\(\neg\operatorname{Bad}_{t,p,q}^B(N)\land\operatorname{Good}_{t,p,q}^B(N)\)

All score coefficients and all enumerated rankings and winner pairs are fixed once \(m\) is fixed. No multiplication of variables enters the formulas.
