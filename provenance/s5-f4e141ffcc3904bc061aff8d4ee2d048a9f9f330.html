The continuous mirror question, as graded

Given a finite set of client types \(T\), rational masses \(\mu_t\) summing to \(1\), a rational symmetric pair-allocation matrix \(A\), and an exact polynomial-time separation oracle for the rational polyhedral epigraph of \(r(x)=W(x)-x^{\mathsf T}Ax\) on \(X=\prod_{t\in T}[0,\mu_t]\), decide whether \(r(x)\geq 0\) for every \(x\in X\); if not, return a rational violating composition.

Packaged proof task (what the prover saw — nothing else)

A society is specified by its support: a nonempty list \(T\) of \(\tau\) client types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here the composition dimension is \(m=\tau\); support size does not count unlisted possible types.
A coalition composition is any \(x\in X=\prod_{t\in T}[0,\mu_t]\). Its net transferable surplus is a finite function \(W:X\to\mathbb R\), with \(W(0)=0\); surplus may be negative.
A fixed matrix \(A\in\mathbb Q^{\tau\times\tau}\) is symmetric and may have signed entries. Total participant allocation is \(x^{\mathsf T}Ax\), counting both endpoints of each interaction; diagonal entries represent interactions within a type. Retained coordinator slack is \(r(x)=W(x)-x^{\mathsf T}Ax\).
The input supplies an exact strong separation oracle for the rational polyhedron \(E=\{(x,z):x\in X,\ z\ge r(x)\}\), and a known bound \(B\) on its facet complexity. Oracle calls run in time polynomial in the query length and input parameters. Let \(L\) be the binary encoding length of the masses, matrix, and oracle description; count running time in \(m,\tau,L,B\).
Decide whether \(r(x)\ge0\) for every \(x\in X\); otherwise return a rational composition \(x\in X\) with \(r(x)<0\).

Is this verification problem, including producing a rational violation, solvable in time polynomial in \(m,\tau,L,B\), or is its decision problem NP-hard?

For finite agents, budget verification is polynomial in oracle time when the retained-slack set function is submodular and polynomial-time evaluable; submodular surplus and nonnegative pair rewards suffice.
For continuous polyhedra, strong separation and strong linear optimization are equivalent in polynomial oracle time under known facet-complexity bounds ([Grötschel–Lovász–Schrijver](https://www.zib.de/userpage/groetschel/pubnew/paper/groetschellovaszschrijver1988.pdf)). This is a general polyhedral result rather than a result formulated for this coalition-verification problem.

Modeling choices made when packaging the task

  • Added a known facet-complexity bound B and counted runtime polynomially in B, because a rational polyhedral epigraph and an exact separation oracle alone do not specify the encoding bounds needed for exact oracle complexity.
  • Normalized W(0)=r(0)=0, following the discrete empty-coalition convention.
  • Specified that W is finite on the whole composition box and may be negative, consistently with net transferable surplus.
  • Allowed signed matrix entries and within-type diagonal interactions: the discrete prohibition on self-interaction does not exclude interactions between distinct clients of the same type.
  • Used m=τ for the composition dimension; this model has no separate candidate or alternative parameter.
  • Did not impose viability of every positive pure-type composition: an atomless society has no positive-mass singleton, and singleton pre-screening supplies no such restriction.

Result. The verification problem, including producing a rational violation, is solvable in time polynomial in \(m,\tau,L,B\).

The decisive assumption is that the input provides exact strong separation for the rational polyhedron \(E\), which is the epigraph of the retained slack itself.

1. The epigraph assumption forces polyhedral convexity.

Because \(E\) is a rational polyhedron, it has a finite description
\[ E=\{(x,z):a_i^{\mathsf T}x+b_i z\le d_i,\ i=1,\ldots,N\}, \]
with rational coefficients. This description is used only in the proof; the algorithm need not enumerate it.

Every coefficient \(b_i\) is nonpositive. Indeed, \((0,z)\in E\) for every \(z\ge0\), since \(r(0)=W(0)=0\). An inequality with \(b_i>0\) would fail for sufficiently large \(z\).

Let \(I=\{i:b_i<0\}\). This set is nonempty: otherwise every defining inequality would be independent of \(z\), and feasibility of \((0,0)\) would imply feasibility of \((0,-1)\), contradicting \(r(0)=0\).

For each \(x\in X\), all inequalities with \(b_i=0\) hold, because the fiber above \(x\) is nonempty. The remaining inequalities are equivalent to
\[ z\ge \frac{a_i^{\mathsf T}x-d_i}{-b_i}\qquad(i\in I). \]
Consequently,
\[ r(x)=\max_{i\in I}\frac{a_i^{\mathsf T}x-d_i}{-b_i} \qquad(x\in X). \]

Thus \(r\) is a finite maximum of rational affine functions. In particular, it is convex and continuous on \(X\).

2. The relevant linear optimization problem has an attained finite optimum.

The box \(X\) is nonempty and compact. By continuity, \(r\) attains a finite minimum
\[ \gamma=\min_{x\in X}r(x). \]
By the definition of the epigraph,
\[ \gamma=\min\{z:(x,z)\in E\}. \]
Indeed, every feasible pair satisfies \(z\ge r(x)\ge\gamma\), while a minimizing composition \(x_0\) gives the feasible pair \((x_0,\gamma)\).

Also, \(\gamma\le r(0)=0\). Therefore the desired universal inequality holds exactly when \(\gamma=0\); a violation exists exactly when \(\gamma<0\).

Although \(E\) is unbounded upwards, this objective is bounded below and attains its optimum.

3. Exact polynomial-time algorithm and correctness.

We use the strong separation–optimization theorem: for a rational polyhedron with known dimension and facet-complexity bound, an exact strong separation oracle permits strong linear optimization in oracle-polynomial time. For an attained finite optimum, this returns a rational optimal point, with polynomial encoding length. See the theorem stated in [Grötschel and Nešetřil’s account](https://www.zib.de/userpage/groetschel/pubnew/groetschel-nesetril.pdf).

Its hypotheses hold here:

  • \(E\) is a rational polyhedron in dimension \(m+1\).
  • Its facet complexity is bounded by the supplied \(B\).
  • The input supplies exact strong separation for \(E\).
  • The objective, minimizing the last coordinate, is rational and has encoding length polynomial in \(m\).
  • Section 2 proves that its optimum is finite and attained.

Apply this theorem to obtain a rational optimal pair \((x^\ast,z^\ast)\in E\). Compare \(z^\ast\) with zero using exact rational arithmetic.

If \(z^\ast\ge0\), then for every \(x\in X\), the pair \((x,r(x))\) belongs to \(E\), so optimality gives
\[ r(x)\ge z^\ast\ge0. \]
Return that verification succeeds.

If \(z^\ast<0\), feasibility gives
\[ x^\ast\in X,\qquad r(x^\ast)\le z^\ast<0. \]
Return the rational composition \(x^\ast\).

The theorem bounds both the number of oracle calls and their query lengths polynomially in \(m+1,B\). Combining this with the assumed polynomial running time of each oracle call gives total time polynomial in \(m,\tau,L,B\). Its output-length guarantee also ensures that the returned composition can be written in polynomial time. Exact optimization handles strict negativity without requiring a separately supplied numerical gap.

4. Scope of the conclusion.

No sign restriction on \(A\), and no separate submodularity assumption, is needed. These conclusions follow because the oracle describes the epigraph of \(r=W-x^{\mathsf T}Ax\). Providing an oracle for a different function would not establish the hypotheses used above.

Thus the stated problem has a polynomial-time algorithm. Under the usual polynomial-time reductions, NP-hardness of its decision problem would imply \(\mathrm P=\mathrm{NP}\).
