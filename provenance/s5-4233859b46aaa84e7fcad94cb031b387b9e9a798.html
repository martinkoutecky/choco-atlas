Lemma 5.3 — class: other

The continuous mirror question, as graded

Given a frame satisfying the paper’s interval-case assumptions, an issue order \(\pi\), and binary-rational masses over complete rational judgment types on its agenda, compute the complete consistent collective judgment set produced by sequential majority: at each issue choose the sign with greater total supporting mass, choose \(P_w\) on a tie, and choose the only sign consistent with prior decisions whenever consistency forces one.

Packaged proof task (what the prover saw — nothing else)

Let \(r,k\) be binary-encoded integers with \(\gcd(r,k)=1\) and \(1\le k<r/3\). Set \(m=r\), \(W=\mathbb Z/r\mathbb Z\), and \(A=\{0,\ldots,k\}\); all translations are modulo \(r\).
The agenda is \(\{P_w,\neg P_w:w\in W\}\), where \(P_w\) is true under a valuation \(V\subseteq W\) exactly when \(A+w\subseteq V\). A judgment set is consistent if some common valuation satisfies it, and complete if it contains exactly one sign for every issue.
A society is given by its support: the list of the \(\tau\) distinct complete consistent judgment types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Each type is an explicit \(m\)-bit vector. Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
The input also gives an explicit permutation \(\pi\) of \(W\). Starting with the empty judgment set, process issues in this order. If only one sign preserves consistency, choose it; otherwise choose the sign with greater supporting mass, choosing \(P_w\) on a tie. Output the resulting complete collective judgment set.

Is computing this outcome polynomial-time in \(m,\tau,L,k\), or is it NP-hard?

For discrete profiles, interval coverage satisfies \(A+w\subseteq\bigcup_{s\in J_+}(A+s)\) exactly when \(d_-(w)+d_+(w)\le k+1\), where \(d_\pm(w)=\min\{t\in\{0,\ldots,k\}:w\pm t\in J_+\}\), with an empty minimum assigned \(k+1\).
With acceptance counts supplied, discrete sequential majority has an implementation using \(O(mk)\) arithmetic operations; this bound does not specify binary-rational mass arithmetic.

Modeling choices made when packaging the task

  • Expanded the interval-case assumptions to A={0,...,k}, gcd(r,k)=1, and 1≤k<r/3, retaining the conditions imposed throughout the aggregation section.
  • Used the finite translate agenda shared by both frame classes after semantic reduction, with m=r issues and consistency witnessed by an unrestricted valuation V⊆W.
  • Normalized the positive rational masses to sum to one; the graded question did not specify total mass.
  • Encoded each supported judgment type as an explicit issue-sign vector and the issue order as an explicit permutation; defined L as total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Computing the outcome is polynomial-time solvable, including exact arithmetic on the binary-rational masses. An explicit algorithm has bit complexity bounded by \(O(\tau L^2+m\tau L+m^2\log m)\).

The proof uses a direct consistency criterion and does not require expanding the weighted society into individual voters.

1. Consistency is determined by a union

Write \(B_w=A+w\). For a partial judgment set, let \(J_+\subseteq W\) contain its positive issues and \(J_-\subseteq W\) its negative issues. Define \(U=\bigcup_{w\in J_+}B_w\).

Lemma. The partial judgment set is consistent if and only if \(B_v\nsubseteq U\) for every \(v\in J_-\).

Proof. Any valuation \(V\) satisfying all positive judgments must contain every \(B_w\) with \(w\in J_+\), hence must contain \(U\). If \(B_v\subseteq U\) for some \(v\in J_-\), then \(B_v\subseteq V\), contradicting the required judgment \(\neg P_v\).

Conversely, suppose \(B_v\nsubseteq U\) for every \(v\in J_-\). The valuation \(V=U\) satisfies every positive judgment. It also satisfies every negative judgment, since each corresponding interval has a point outside \(U\). Thus it witnesses consistency. \(\square\)

Consequently, when processing issue \(w\), the feasibility tests are exactly:

  • Adding \(\neg P_w\) is feasible if and only if \(B_w\nsubseteq U\).
  • Adding \(P_w\) is feasible if and only if \(B_v\nsubseteq U\cup B_w\) for every \(v\in J_-\).

At least one sign is feasible whenever the current judgments are consistent: any valuation witnessing current consistency satisfies one of the two signs for issue \(w\).

These tests establish that consistency checking here requires no search over valuations.

2. Exact majority comparisons have polynomial bit complexity

Write each input mass as \(\mu_t=p_t/q_t\), with positive binary-encoded integers \(p_t,q_t\). Dyadic binary rationals are included in this representation.

Set \(D=\prod_{t=1}^{\tau}q_t\) and \(b_t=p_t(D/q_t)\). Each \(b_t\) is a positive integer, and normalization gives \(\sum_{t=1}^{\tau}b_t=D\).

The denominator product has polynomial bit length: \(\log_2 D=\sum_{t=1}^{\tau}\log_2q_t\le L\). Thus \(D\) has at most \(L+1\) bits. Since the positive integers \(b_t\) sum to \(D\), each \(b_t\) also has at most \(L+1\) bits.

For each issue \(w\), let \(x_{t,w}\in\{0,1\}\) be the input bit indicating whether type \(t\) accepts \(P_w\), and compute \(C_w=\sum_{t=1}^{\tau}b_tx_{t,w}\). The supporting masses of the two signs are respectively \(C_w/D\) and \((D-C_w)/D\). Therefore the preferred sign, including the prescribed tie rule, is \(P_w\) exactly when \(2C_w\ge D\).

All partial sums defining \(C_w\) lie between zero and \(D\). Hence all these comparisons use integers with \(O(L)\) bits.

Using schoolbook integer arithmetic, forming \(D\) and all \(b_t\) costs \(O(\tau L^2)\) bit operations. Computing all \(C_w\) costs \(O(m\tau L)\) bit operations. The numerical value of \(D\) may be exponential in \(L\), but the algorithm uses its binary representation throughout.

3. A polynomial-time sequential algorithm

Maintain the covered-set indicator \(u_i=\mathbf 1_{\{i\in U\}}\), for representatives \(i\in\{0,\ldots,m-1\}\), together with the set \(J_-\).

For each issue \(w\), in the supplied order:

  • Determine its preferred sign by comparing \(2C_w\) with \(D\).
  • Test whether that sign is feasible using the criterion above.
  • Choose it if feasible; otherwise choose the opposite sign.
  • If \(P_w\) was chosen, replace \(U\) by \(U\cup B_w\). If \(\neg P_w\) was chosen, add \(w\) to \(J_-\).

For completeness, the feasibility tests can be implemented in \(O(m)\) arithmetic operations per issue.

Given any candidate covered set \(T\subseteq W\), form prefix sums of its indicator duplicated around the circle: \(S_0=0\) and \(S_{j+1}=S_j+\mathbf 1_{\{j\bmod m\in T\}}\) for \(0\le j<2m\). Since \(k<m\), for every representative \(v\in\{0,\ldots,m-1\}\),

\(B_v\subseteq T\quad\Longleftrightarrow\quad S_{v+k+1}-S_v=k+1.\)

Indeed, the difference counts exactly the \(k+1\) consecutive points of the cyclic interval \(B_v\).

To test a positive sign, construct the indicator of \(T=U\cup B_w\), compute its prefix sums, and check the displayed condition for every \(v\in J_-\). Constructing the indicator and prefix sums takes \(O(m)\) operations, and there are at most \(m\) negative judgments to check.

To test a negative sign, use \(T=U\) and check just \(B_w\). This also takes at most \(O(m)\) operations, including prefix construction.

All prefix sums lie between zero and \(2m\), so these operations use \(O(\log m)\)-bit integers. Across the \(m\) issues, the consistency work therefore costs \(O(m^2\log m)\) bit operations.

4. Correctness and conclusion

Initially the empty judgment set is consistent. Inductively, the feasibility tests are exact by the lemma. If the preferred sign is feasible, the algorithm selects precisely the sign required by the majority rule. If it is infeasible, the other sign is feasible and is the unique permissible choice. Thus every step agrees with the specified procedure and preserves consistency.

Because the supplied order is a permutation of \(W\), the algorithm finishes with exactly one sign for every issue. Its output is therefore the required complete collective judgment set.

Combining the arithmetic and consistency costs gives the stated bound \(O(\tau L^2+m\tau L+m^2\log m)\), which is polynomial in the requested parameters. Neither coprimality nor the stronger restriction \(k<r/3\) is needed for this algorithm; the proof already applies whenever \(k<m\).
