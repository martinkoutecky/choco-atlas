The continuous mirror question, as graded

Given a finite set of request types \(T\), population masses \(\mu_t\), vehicle capacity \(Q\), and feasible route configurations \(r\) with type-count vectors \(a_r\) and costs \(c_r\), let \(p_t\) be a proposed per-passenger charge. Determine whether any blocking mass exists by maximizing \(\sum_r (p^\top a_r-c_r)x_r\) subject to \(\sum_r a_{tr}x_r\le\mu_t\) for each \(t\) and \(x_r\ge0\); if the optimum is positive, return a blocking route mixture, and otherwise certify none exists.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) request types with positive binary-rational masses \(\mu_t\); \(\tau\) is the support size, not the number of possible types. Masses need not sum to one.
Each type specifies an origin and destination. Capacity \(Q\ge1\) is an integer counting all participants, including the driver; every participant may drive.
The input explicitly lists the complete set \(R\) of \(m\) route configurations and their positive binary-rational minimum costs \(c_r\). Each configuration has \(a_r\in\mathbb Z_{\ge0}^{\tau}\) with \(1\le\sum_t a_{tr}\le Q\); all such count vectors are represented, including singletons. A feasible route starts at one participant's origin, ends at that participant's destination, and picks up each other participant before dropping them off.
A route mixture \(x\in\mathbb R_{\ge0}^{m}\) serves mass \(Ax\), where \(A=(a_{tr})\), and costs \(\sum_r c_rx_r\); fractional route quantities and proportional costs are allowed.
For \(0\le v\le\mu\), define \(C(v)=\min\{\sum_r c_rx_r:Ax=v,\ x\ge0\}\). Promise that the mass game has a nonempty core: some \(q\in\mathbb R^{\tau}\) satisfies \(q^\top\mu=C(\mu)\) and \(q^\top v\le C(v)\) for every \(0\le v\le\mu\).
Given binary-rational proposed charges \(p\in\mathbb Q^{\tau}\), with either sign allowed, define \(B(p)=\max\{\sum_r(p^\top a_r-c_r)x_r:Ax\le\mu,\ x\ge0\}\). Blocking mass exists exactly when \(B(p)>0\); the computational problem also requests a blocking mixture when one exists.

Is deciding whether \(B(p)>0\), and producing a blocking mixture when it does, solvable in polynomial time or NP-hard? State running times in \(m\), \(\tau\), \(L\), and \(Q\), where \(L\) is the total binary input length.

For discrete ridesharing games with nonempty core, coalition inequalities for groups larger than vehicle capacity are redundant. Discrete prize-collecting ridesharing and pickup-and-delivery routing subproblems with routes represented implicitly are reported NP-hard; this does not classify the explicitly listed mass problem. [Source](https://lquadrifoglio.engr.tamu.edu/wp-content/uploads/sites/221/2021/03/TRB_Nucleolus.pdf)

Modeling choices made when packaging the task

  • Settled route representation as an explicit complete list with supplied minimum costs, rather than an implicit geographic routing problem; defined m as the list size.
  • Settled masses as positive binary rationals without unit normalization, preserving population size in passenger units.
  • Specified nonempty integer type-count configurations, singleton availability, positive rational route costs, and capacity counting the driver as a participant.
  • Made fractional route quantities and proportional costs explicit, as required by the graded mass formulation.
  • Carried over the anchor's nonempty-core promise using the fractional coalition cost C(v).
  • Allowed signed rational proposed charges because the discrete allocation definition imposes no nonnegativity constraint; did not require the proposal itself to belong to the core or balance the total cost.
  • Included the full population among eligible blocking masses, following the graded optimization domain.

Result

The problem is polynomial-time solvable. More precisely,

\(B(p)>0\quad\Longleftrightarrow\quad \text{there exists }r\in R\text{ with }p^\top a_r>c_r.\)

A scan of the explicitly listed routes decides the problem. Whenever the answer is positive, a blocking mixture using just one route can be produced.

The algorithm takes \(O(m\tau)\) exact arithmetic operations, or \(O(m\tau L^2)\) bit operations using elementary integer arithmetic. There is no additional dependence on the numerical value of \(Q\).

1. Existence of the optima

Write \(F=\{x\in\mathbb R_{\ge0}^{m}:Ax\le\mu\}\). This set contains \(0\).

For every route \(r\), its count vector is nonzero, so some type \(t\) has \(a_{tr}\ge1\). Nonnegativity of all entries of \(A\) implies that every \(x\in F\) satisfies

\(a_{tr}x_r\le(Ax)_t\le\mu_t,\)

and hence \(x_r\le\mu_t/a_{tr}\). Thus every coordinate of \(F\) is bounded. Since \(F\) is also closed, it is compact. Consequently, the continuous linear objective defining \(B(p)\) attains its maximum.

For every \(0\le v\le\mu\), the singleton configurations provide a feasible mixture serving exactly \(v\): assign quantity \(v_t\) to a singleton route of type \(t\). The feasible set defining \(C(v)\) is a closed subset of \(F\), so its minimum is also attained.

2. Exact characterization of blocking

Define the profit coefficient of route \(r\) by

\(g_r=p^\top a_r-c_r.\)

Claim. Blocking exists if and only if some \(g_r>0\).

Proof. Suppose first that every \(g_r\le0\). For every feasible \(x\ge0\),

\(\displaystyle \sum_{r=1}^{m}g_rx_r\le0.\)

The zero mixture has objective value \(0\), so \(B(p)=0\).

Conversely, suppose \(g_r>0\) for a particular route \(r\). Define

\(\displaystyle \lambda_r=\min_{\{t:a_{tr}>0\}}\frac{\mu_t}{a_{tr}}.\)

The set over which this minimum is taken is nonempty. Every numerator is strictly positive, so \(\lambda_r>0\).

Let \(x_r=\lambda_r\) and \(x_s=0\) for every \(s\ne r\). For types with \(a_{tr}>0\), the definition of \(\lambda_r\) gives \(\lambda_ra_{tr}\le\mu_t\); for the other types, this inequality holds because its left side is zero. Thus \(Ax\le\mu\). Its objective value is

\(\displaystyle \sum_{s=1}^{m}g_sx_s=\lambda_rg_r>0.\)

Therefore \(B(p)>0\), proving the claim.

This mixture also certifies blocking directly in terms of coalition cost. Its served mass is \(v=\lambda_ra_r\), and

\(C(v)\le\lambda_rc_r<\lambda_rp^\top a_r=p^\top v.\)

The first inequality holds because the constructed mixture is a feasible way to serve \(v\). No optimal routing computation is needed to establish that this mass blocks.

3. Algorithm and exact running time

The algorithm is:

  • For each listed route \(r\), compute \(g_r=p^\top a_r-c_r\) exactly.
  • If every \(g_r\le0\), report that no blocking mass exists.
  • Otherwise, choose a route with \(g_r>0\), compute \(\lambda_r\) as above, and output the mixture supported on that route.

Negative proposed charges cause no difficulty: the proof uses only the signs of the resulting \(g_r\).

Computing all dot products takes \(O(m\tau)\) arithmetic operations. Constructing the witness takes another \(O(\tau)\) operations.

For an explicit bit bound, represent each rational as a signed integer numerator divided by a positive integer denominator. Let \(D\) be the product of the denominators of all charges and route costs. The sum of their encoded lengths is at most \(L\), so \(D\) has \(O(L)\) bits. Form the integers

\(\widehat p_t=Dp_t,\qquad \widehat c_r=Dc_r.\)

Then the sign of \(g_r\) is exactly the sign of the integer

\(\displaystyle h_r=\sum_{t=1}^{\tau}\widehat p_ta_{tr}-\widehat c_r.\)

All intermediate integers have \(O(L)\) bits. Indeed, the scaled charges and costs have \(O(L)\) bits, each count satisfies \(a_{tr}\le Q\), and accumulating \(\tau\) terms adds at most \(O(\log\tau)\) bits. Both \(\log Q\) and \(\log\tau\) are bounded by the total input length.

Using elementary multiplication and division, each required integer operation costs at most \(O(L^2)\) bit operations. Constructing the scaled data, scanning the routes, and comparing the witness ratios therefore takes

\(O(m\tau L^2)\)

bit operations.

The selected ratio \(\lambda_r=\mu_t/a_{tr}\) has \(O(L)\) bits. A witness can be output as a route index and this rational quantity, or as the full vector of length \(m\).

Capacity enters through the encoded count vectors and through the size of the explicit list. In particular, because every nonzero count vector of total size at most \(Q\) is represented,

\(\displaystyle m\ge\binom{\tau+Q}{Q}-1.\)

Here the binomial coefficient counts all nonnegative vectors of length \(\tau\) whose coordinate sum is at most \(Q\), including the zero vector. Thus the required explicit input itself can be large; the algorithm does not enumerate configurations beyond those already supplied.

4. Role of the core promise

The algorithm does not require the promise of a nonempty core. In fact, that promise follows automatically from the stated fractional model.

The linear program defining \(C(\mu)\) has dual

\(\displaystyle \max\{q^\top\mu:A^\top q\le c,\ q\in\mathbb R^\tau\}.\)

The primal is feasible by the singleton configurations and has a finite optimum, as proved above. Linear programming strong duality therefore supplies a dual optimal \(q\) satisfying \(q^\top\mu=C(\mu)\).

For any \(0\le v\le\mu\) and any mixture \(x\ge0\) serving \(v\),

\(q^\top v=q^\top Ax=(A^\top q)^\top x\le c^\top x.\)

Taking the minimum over mixtures serving \(v\) gives \(q^\top v\le C(v)\). Hence this \(q\) belongs to the promised core.

5. Why implicit-routing hardness does not classify this problem

The cited paper’s discrete formulation uses binary route indicators and describes obtaining route costs through precedence-constrained routing optimization. See its [Section 2](https://lquadrifoglio.engr.tamu.edu/wp-content/uploads/sites/221/2021/03/TRB_Nucleolus.pdf).

Here, all configurations and their minimum costs are already supplied. Moreover, strictly positive support masses and fractional route quantities allow any profitable listed configuration to be scaled into a feasible blocker. These hypotheses yield the exact scan criterion proved above.

Thus the requested decision and witness problems are polynomial-time solvable. An NP-hardness classification under standard polynomial-time reductions would consequently imply \(\mathrm{P}=\mathrm{NP}\).
