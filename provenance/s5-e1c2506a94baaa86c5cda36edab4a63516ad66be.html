The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) summing to \(1\), and a rational utility \(u_q\ge 0\) for each multiset \(q\) of one to three types, choose \(y_q\ge 0\), the mass of teams of profile \(q\) per unit population, subject to \(\sum_q q_t y_q=\mu_t\) for every \(t\in T\). Find an allocation maximizing \(\sum_q |q|u_q y_q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Let \(m=3\) be the maximum team size and \(Q=\{q\in\mathbb Z_{\ge0}^{T}:1\le |q|:=\sum_t q_t\le m\}\). Repeated types are allowed; \(q_t\) is their multiplicity. The input explicitly gives a nonnegative binary rational \(u_q\) for every \(q\in Q\), the utility received by each team member.
An allocation consists of real team masses \(y_q\ge0\) satisfying \(\sum_{q\in Q}q_ty_q=\mu_t\) for every \(t\in T\). Its welfare is \(W(y)=\sum_{q\in Q}|q|u_qy_q\); write \(\mathrm{OPT}=\max_y W(y)\). All profiles are permitted, including singletons; no stability or individual rationality constraints are imposed.
Let \(L\) be the total input bit length. State running times in \(m,\tau,L\) and the approximation parameter \(\varepsilon\), with \(m=3\) fixed.

Does this welfare maximization problem admit a PTAS, or is it APX-hard?

For finite agents with common utility within each coalition, welfare maximization with coalition size at most \(3\) is APX-complete; with size at most \(2\), it is polynomial-time solvable. [Source](https://arxiv.org/pdf/2205.11939).
No result addressing exactly the mass allocation model above was located in the literature search.

Modeling choices made when packaging the task

  • Remove zero-mass types and use the remaining nonempty support as T.
  • Define m as the maximum team size, fixed at three, and L as the total input bit length.
  • Interpret u_q as each member's utility, so a team contributes |q|u_q to welfare.
  • Retain the complete utility table and all profiles supplied in the continuous question. The discrete welfare objective imposes no stability constraints; the individually rational coalition-list representation is not treated as an additional feasibility constraint.

Exact polynomial-time solvability

The stated mass allocation problem is exactly solvable in polynomial time. Consequently, it admits a PTAS—and an FPTAS—with running time independent of the approximation parameter. Under the standard assumption \(\mathrm{P}\ne\mathrm{NP}\), it is not APX-hard under the usual approximation-preserving reductions.

This conclusion uses precisely the given model: team masses may be arbitrary nonnegative real numbers, and every profile’s utility is explicitly supplied.

1. The allocation problem is a linear program

Write \(N=|Q|\). Define the matrix \(A\in\mathbb{Z}_{\ge 0}^{\tau\times N}\) and objective vector \(c\in\mathbb{Q}_{\ge 0}^{N}\) by \(A_{tq}=q_t\) and \(c_q=|q|u_q\).

The optimization problem is therefore exactly the rational linear program

\( \displaystyle \max\{c^{\mathsf T}y:Ay=\mu,\ y\ge 0\}. \)

Indeed, its feasible vectors are precisely the allocations in the question, and its objective is precisely their welfare. There are no additional constraints requiring team masses to be integral or to lie on a prescribed rational grid.

The program is feasible: for the singleton profile \(e_t\), set \(y_{e_t}=\mu_t\), and set all other coordinates to zero.

For every feasible allocation, summing the type constraints gives

\( \displaystyle \sum_{q\in Q}|q|y_q=\sum_{t\in T}\mu_t=1. \)

Because every summand is nonnegative, \(0\le y_q\le 1/|q|\) for every profile. Thus the feasible region is closed and bounded, hence compact. The linear objective consequently attains a finite maximum. In particular, if \(U=\max_{q\in Q}u_q\), then \(0\le W(y)\le U\).

2. The explicit linear program has polynomial size

For a fixed team size \(k\), the number of profiles is \(\binom{\tau+k-1}{k}\): these are the nonnegative integer vectors with coordinate sum \(k\). Summing over permitted sizes gives

\( \displaystyle N=\sum_{k=1}^{m}\binom{\tau+k-1}{k}=\binom{\tau+m}{m}-1. \)

For \(m=3\), this becomes

\( \displaystyle N=\tau+\binom{\tau+1}{2}+\binom{\tau+2}{3}=\Theta(\tau^3). \)

The linear program has \(N\) variables, \(\tau\) equality constraints, and \(N\) nonnegativity constraints. Every matrix entry is an integer between \(0\) and \(m\). Multiplying \(u_q\) by \(|q|\) increases its rational encoding length by at most \(O(\log(m+1))\).

Accordingly, a dense encoding of this linear program has bit length

\( \displaystyle B=O\!\left(L+(\tau+1)(N+1)\log(m+1)\right). \)

The profiles, matrix, and objective can all be constructed in time polynomial in this bound. This construction uses the support size \(\tau\); it never enumerates any ambient universe of possible types.

3. Exact optimization and running time

Use the standard polynomial-time theorem for rational linear programming: a linear program with binary rational coefficients can be solved in time polynomial in its total encoding length, returning an exact rational optimum and an optimal rational solution whenever the program is feasible and its optimum is finite. The ellipsoid method establishes this theorem; polynomial bounds on the encoding length of basic feasible solutions justify exact rational output. See [Goemans’s linear-programming notes](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/72e3bdf718c625bc850cdab40b416516_lec11.pdf).

All hypotheses have been checked: the coefficients are rational, the program has an explicit finite encoding, singleton allocations establish feasibility, and the conservation identity establishes boundedness.

Thus an exact algorithm has bit running time

\( \displaystyle \left[L+(\tau+1)\binom{\tau+m}{m}\log(m+1)\right]^{O(1)}. \)

For the required fixed value \(m=3\), this is

\( \displaystyle (L+\tau^4)^{O(1)}=L^{O(1)}, \)

where the last equality as a polynomial-time bound follows from \(\tau\le L\).

For every \(0<\varepsilon<1\), the returned optimum \(y^\star\) satisfies \(W(y^\star)=\mathrm{OPT}\ge(1-\varepsilon)\mathrm{OPT}\), including when \(\mathrm{OPT}=0\). The optimization algorithm does not use \(\varepsilon\), so its running time is independent of that parameter.

4. Why finite-agent hardness does not transfer

The cited finite-agent result concerns partitions of indivisible agents ([Caskurlu and Kizilkaya, Corollary 4](https://arxiv.org/pdf/2205.11939)). Such partitions impose discrete restrictions absent from the mass model. The resulting difference can affect the optimal value.

For an explicit example, take four types with masses \(\mu_t=1/4\). Give utility \(1\) to each triple of three distinct types, and utility \(0\) to every other profile.

There are four such triples. Assign mass \(1/12\) to each. Each type belongs to exactly three triples, so its allocated mass is \(3(1/12)=1/4\). This allocation is feasible and has welfare \(4\cdot3\cdot(1/12)=1\). Since all utilities are at most \(1\), the conservation identity proves that this is optimal.

By contrast, with one indivisible agent of each type, a partition contains at most one triple. Its maximum total welfare is \(3\), or normalized welfare \(3/4\).

Thus even this small instance distinguishes fractional mass allocation from finite-agent partitioning. The polynomial-time linear program solves the allocation problem itself; no rounding to an indivisible partition is required.
