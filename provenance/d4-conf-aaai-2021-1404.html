Here \(q_{t0}\) is the unassigned fraction, the pair sum is ordered to count both agents' disconnection costs, and facility opening costs are zero. Results

For the objective in the question:

  • The decision problem is \(\mathrm{NP}\)-complete, already for \(m=3\).
  • There is a deterministic polynomial-time multiplicative \(2\)-approximation, running in \((m+\tau+L)^{O(1)}\) time.
  • Minimization is \(\mathrm{APX}\)-hard already for \(m=3\). Consequently, there is no polynomial-time approximation scheme unless \(\mathrm{P}=\mathrm{NP}\).
  • Assuming the Unique Games Conjecture, no polynomial-time \((2-\varepsilon)\)-approximation exists for any fixed \(0<\varepsilon<1\), when \(m\) is unrestricted.
  • For \(m=1\) or \(m=2\), exact minimization is polynomial-time solvable.

The central fact is that fractional assignments never improve the optimum, including when diagonal costs are positive.

1. A pure optimum always exists

Call an assignment pure if, for each supported type \(t\), one coordinate of \((q_{t0},\ldots,q_{tm})\) equals \(1\).

Fix every assignment vector except that of type \(t\). Set

\(h_t=\mu_t^2d_{tt}\).

Using symmetry of the pair costs, the part of \(J\) depending on this vector is

\[ C+\sum_{k=1}^{m} \left(\mu_ta_{tk}-2\mu_t\sum_{u\ne t}\mu_ud_{tu}q_{uk}\right)q_{tk} -h_t\sum_{k=1}^{m}q_{tk}^{\,2}, \]

where \(C\) is independent of the vector being changed.

Since \(h_t\ge0\), this is a concave function on the simplex. Write \(e_k\) for its vertex corresponding to assignment \(k\), including \(k=0\). Concavity gives

\[ J(q)\ge \sum_{k=0}^{m}q_{tk}\, J(q_1,\ldots,q_{t-1},e_k,q_{t+1},\ldots,q_\tau). \]

The right side is a convex combination. Therefore some vertex replacement has objective at most \(J(q)\).

Apply this replacement successively to all \(\tau\) types. The resulting assignment is pure and has no larger objective. Furthermore, the feasible set is compact and \(J\) is continuous, so a minimum exists. Applying the replacements to a minimizer proves

\[ \min_qJ(q)=\min_{\text{pure }q}J(q). \]

This argument also gives a polynomial-time purification procedure for rational assignments: evaluate the \(m+1\) vertex replacements for each type and choose a cheapest one.

In particular, a pure assignment is a certificate for a yes-instance of the decision problem. It has \(\tau\) labels, and its rational objective can be evaluated and compared with \(B\) in polynomial bit complexity. Thus the decision problem belongs to \(\mathrm{NP}\).

2. Exact conversion to uniform metric labeling

Define

\[ c_{tk}=\mu_ta_{tk},\qquad h_t=\mu_t^2d_{tt},\qquad w_{tu}=2\mu_t\mu_ud_{tu}\quad(t<u). \]

For a pure assignment \(s_t\in\{0,1,\ldots,m\}\), its objective is

\[ J(s)= \sum_{t:s_t\ne0}c_{t,s_t} +\sum_{t:s_t=0}h_t +\sum_{t<u}w_{tu} \left(1-\mathbf 1_{\{s_t=s_u\ne0\}}\right). \]

The factor \(2\) in \(w_{tu}\) accounts for the two ordered off-diagonal pairs. The diagonal contribution is exactly \(h_t\) when type \(t\) is unassigned, and zero otherwise.

To represent unassignment correctly, introduce one private label \(p_t\) for each type. The label set consists of the \(m\) facility labels and these \(\tau\) private labels. Type \(t\) may use its own private label to represent being unassigned.

Give type \(t\) unary costs \(c_{tk}\) for facility labels and \(h_t\) for \(p_t\). Put edge weight \(w_{tu}\) between types \(t\) and \(u\), with edge cost zero for equal labels and \(w_{tu}\) for different labels.

Because different types have different private labels, two unassigned types pay their full disconnection cost, as required.

The private-label restrictions can be enforced with finite nonnegative costs. Let

\[ U=\sum_th_t+\sum_{t<u}w_{tu}, \qquad M=2U+1. \]

Here \(U\) is the cost of assigning every type to its own private label. Assign unary cost \(M\) when type \(t\) uses \(p_u\) with \(u\ne t\).

Every labeling violating a private-label restriction costs at least \(M>U\). Hence an optimal labeling satisfies the restrictions, and its optimum equals \(\min_qJ(q)\).

Polynomial-time \(2\)-approximation

We use the following established theorem: uniform metric labeling with arbitrary nonnegative unary costs and edge weights admits a deterministic polynomial-time \(2\)-approximation. The deterministic version is obtained by derandomizing LP rounding. [Kleinberg–Tardos, Sections 3 and 5](https://www.cs.cornell.edu/home/kleinber/focs99-mrf.pdf).

All hypotheses hold for the instance constructed above: the label metric is the uniform metric, and every unary cost and edge weight is a finite nonnegative rational.

The algorithm returns a labeling of cost at most

\[ 2\,\mathrm{OPT}\le2U<M. \]

Consequently, it cannot violate a private-label restriction. Translating its labels back gives a pure feasible assignment satisfying

\[ J(s)\le2\min_qJ(q). \]

There are \(\tau\) vertices, \(m+\tau\) labels, and at most \(\binom{\tau}{2}\) edges. All transformed coefficients have polynomial bit length. Construction and approximation therefore take \((m+\tau+L)^{O(1)}\) time. No approximation parameter is required.

The guarantee includes the case \(\mathrm{OPT}=0\): the returned objective must then be zero.

3. A reduction preserving the optimum and approximation ratios

Consider list uniform labeling. Its input is an undirected graph \(G=(V,E)\), nonnegative rational edge weights \(w_e\), a label set \(\{1,\ldots,m\}\), and a nonempty allowed-label list \(A_v\) for each vertex. Its objective is

\[ F(\ell)=\sum_{\{u,v\}\in E}w_{uv}\, \mathbf 1_{\{\ell_u\ne\ell_v\}}, \qquad \ell_v\in A_v. \]

Write \(n=|V|\), \(W=\sum_{e\in E}w_e\), and \(H=W+1\).

Construct a society with one supported type per vertex and masses \(\mu_v=1/n\). Set

\[ a_{vk}= \begin{cases} 0,&k\in A_v,\\ nH,&k\notin A_v, \end{cases} \qquad d_{vv}=n^2H, \]

and, for distinct vertices, set

\[ d_{uv}= \begin{cases} n^2w_{uv}/2,&\{u,v\}\in E,\\ 0,&\{u,v\}\notin E. \end{cases} \]

These coefficients satisfy every required sign and symmetry condition.

For a pure assignment:

  • an unassigned type contributes diagonal cost \(H\);
  • a type using a forbidden facility contributes connection cost \(H\);
  • an edge whose endpoints use different allowed facilities contributes exactly \(w_{uv}\), after summing its two ordered pair terms.

Every valid list labeling therefore gives a pure assignment with exactly the same cost. Every pure assignment containing an unassigned type or a forbidden facility costs at least \(H\).

Conversely, choosing any allowed label for each vertex gives a valid labeling costing at most \(W<H\). Thus no optimal pure assignment is invalid. Section 1 now proves

\[ \min_qJ(q)=\min_\ell F(\ell). \]

There is also a polynomial-time solution conversion preserving approximation ratios. Purify any rational fractional solution first. If the resulting assignment is valid, retain it. Otherwise replace it by any valid list labeling. This replacement costs at most \(W\), whereas the invalid assignment costs at least \(H>W\). Hence the final list-labeling cost never exceeds the original mass-objective cost.

The construction uses \(O(nm+n^2)\) rational entries and polynomial bit length. Its diagonal costs exceed all off-diagonal costs, so the supported types are distinct.

If “binary rational” is intended to require dyadic rationals, first pad the graph with isolated vertices having unrestricted lists until \(n\) is a power of two. This preserves the optimum and allows equal dyadic masses. Integer-weight hardness instances then produce dyadic costs as well.

NP-completeness and APX-hardness

Three-terminal edge multiway cut is the special case with three labels: each terminal has its own singleton list, and every other vertex permits all three labels. Labelings and terminal-separating cuts have the same optimum: crossing edges separate the terminals; conversely, components remaining after a separating cut can be labeled according to their terminal, with terminal-free components labeled arbitrarily.

Three-terminal multiway cut is \(\mathrm{NP}\)-hard and \(\mathrm{MAX\ SNP}\)-hard. [Dahlhaus et al., *The Complexity of Multiterminal Cuts*](https://doi.org/10.1137/S0097539792225297); the approximation hardness is also recalled in [Bérczi et al., Section 1](https://karthik.ise.illinois.edu/pubs/multiway-cut-integrality-gap.pdf).

The reduction above preserves the optimum and converts solutions without increasing cost. It therefore proves:

  • The mass decision problem is \(\mathrm{NP}\)-hard for \(m=3\), and hence \(\mathrm{NP}\)-complete by Section 1.
  • Mass-objective minimization is \(\mathrm{APX}\)-hard for \(m=3\).
  • There exists a constant \(\eta>0\) such that a polynomial-time \((1+\eta)\)-approximation would imply \(\mathrm{P}=\mathrm{NP}\). In particular, no PTAS exists unless \(\mathrm{P}=\mathrm{NP}\).

4. A matching conditional approximation lower bound

A stronger established result applies to list uniform labeling:

Assuming the Unique Games Conjecture, for every fixed \(k\ge3\), approximation within \(2-2/k-\delta\) is hard for every fixed \(\delta>0\) for which this factor exceeds \(1\).

This follows from the fixed-metric hardness theorem and the uniform-metric integrality-gap bound in [Manokaran–Naor–Raghavendra–Schwartz, Theorem 1.3 and its accompanying table](https://people.eecs.berkeley.edu/~prasad/Files/mlpaper.pdf). Their restricted metric-labeling formulation uses allowed-label lists, exactly as required here.

Apply Section 3 with \(m=k\). It preserves both the optimum and approximation ratios, so the same conditional hardness holds for the mass objective.

For any fixed \(0<\varepsilon<1\), choose a fixed \(k>4/\varepsilon\) and set \(\delta=\varepsilon/2\). Then

\[ 2-\frac2k-\delta>2-\varepsilon. \]

A \((2-\varepsilon)\)-approximation would consequently contradict that conditional hardness. Thus the polynomial-time factor \(2\) is optimal for unrestricted \(m\), assuming the Unique Games Conjecture.

This does not establish factor-\(2\) hardness from \(\mathrm{P}\ne\mathrm{NP}\) alone.

5. Exact polynomial-time algorithms for one or two facilities

The pure-optimum result also exposes a tractable boundary.

Two facilities

Encode the three possibilities by binary variables:

\[ s_t=1:\ (X_t,Y_t)=(0,0),\qquad s_t=0:\ (X_t,Y_t)=(1,0),\qquad s_t=2:\ (X_t,Y_t)=(1,1). \]

The allowed encodings are exactly those satisfying \(Y_t\le X_t\). Put \(z_t=X_t-Y_t\), which indicates unassignment.

For all nine ordered pairs of states, the disconnection indicator satisfies

\[ 1-\mathbf 1_{\{s_t=s_u\ne0\}} = \frac{|X_t-X_u|+|Y_t-Y_u|+z_t+z_u}{2}. \]

Indeed, equal facility states give zero; two unassigned states give one; and each pair of distinct states gives one.

Define

\[ b_t=h_t+\frac12\sum_{u\ne t}w_{tu}. \]

Substitution into the pure objective gives

\[ J= \sum_tc_{t1} +\sum_t(b_t-c_{t1})X_t +\sum_t(c_{t2}-b_t)Y_t +\frac12\sum_{t<u}w_{tu} \bigl(|X_t-X_u|+|Y_t-Y_u|\bigr). \]

This expression can be minimized by a single minimum cut:

  • each absolute-difference term is an undirected cut edge of the displayed nonnegative capacity;
  • a unary term \(\beta Z\) is represented by a terminal edge: for \(\beta\ge0\), charge \(\beta\) when \(Z=1\); for \(\beta<0\), charge \(-\beta\) when \(Z=0\) and add the constant \(\beta\);
  • taking value \(1\) to mean the source side, a directed arc from \(Y_t\) to \(X_t\) enforces \(Y_t\le X_t\). Choose its capacity larger than the sum of all other capacities.

A feasible encoding exists, so the last choice excludes every violating cut from optimality. The network has \(2\tau+2\) vertices and \(O(\tau^2)\) arcs, with polynomial-length rational capacities. Exact minimization takes \((\tau+L)^{O(1)}\) time.

One facility

Let \(X_t=1\) mean assigned and \(X_t=0\) mean unassigned. The corresponding identity is

\[ 1-X_tX_u = \frac{|X_t-X_u|+(1-X_t)+(1-X_u)}2. \]

Substitution again gives unary terms plus nonnegative absolute-difference terms, hence a minimum-cut formulation of polynomial size.

6. Running time when the support is small

An exact algorithm also runs in

\[ 2^{O(\tau\log(\tau+1))}(m+\tau+L)^{O(1)}. \]

To prove this, enumerate the unassigned subset and a partition of the remaining types into nonempty facility groups. Different groups must receive different facilities.

For a fixed pattern, all diagonal and disconnection costs are determined. Assigning group \(G\) to facility \(k\) has connection cost

\[ \sum_{t\in G}\mu_ta_{tk}. \]

The cheapest injective assignment of groups to facilities is a polynomial-time minimum-cost bipartite matching problem. Patterns with more than \(m\) groups are infeasible.

The number of patterns is the Bell number \(\operatorname{Bell}(\tau+1)\): introduce one distinguished element whose block contains exactly the unassigned types. This number is at most \((\tau+1)^{\tau+1}\), proving the stated bound.

Thus every fixed support size permits polynomial-time exact minimization, while hardness occurs as \(\tau\) grows.
