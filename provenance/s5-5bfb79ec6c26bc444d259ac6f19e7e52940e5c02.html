Proposition 3.2 — class: other

The continuous mirror question, as graded

Given rational type masses \(\mu_t\) summing to \(1\), group labels \(g(t)\), eligibility sets \(A_t\), and per-capita resource capacities \(\kappa_j\), compute a maximum-throughput feasible flow \(y_{tj}\) satisfying \(\sum_{j\in A_t} y_{tj}\le \mu_t\) and \(\sum_{t:j\in A_t} y_{tj}\le \kappa_j\), with group totals \(x_c=\sum_{t:g(t)=c}\sum_{j\in A_t}y_{tj}\) equalized as \(x_c/r(c)\), where \(r(c)\) is the maximum flow using only group \(c\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) resources with binary rational capacities \(\kappa_j\geq0\), and \(C\geq1\) groups. Each type has one label \(g(t)\in\{1,\ldots,C\}\) and an explicitly listed eligibility set \(A_t\subseteq\{1,\ldots,m\}\).
A feasible allocation consists of divisible flows \(y_{tj}\geq0\) for \(j\in A_t\), satisfying \(\sum_{j\in A_t}y_{tj}\leq\mu_t\) and \(\sum_{t:j\in A_t}y_{tj}\leq\kappa_j\). Its group totals are \(x_c=\sum_{t:g(t)=c}\sum_{j\in A_t}y_{tj}\).
Define \(r(c)\) as the maximum throughput under these same capacities when only types labeled \(c\) may receive resources; assume \(r(c)>0\) for every group. An allocation is opportunity-fair when \(x_c/r(c)=x_{c'}/r(c')\) for every pair of groups.
The optimization problem is to compute an exact allocation maximizing \(\sum_c x_c\) among feasible opportunity-fair allocations. Let \(L\) be the total binary input length.

Is this optimization problem solvable in time polynomial in \(m,\tau,C,L\), or is it \(\mathrm{NP}\)-hard?

For finite colored matroids, the convex hull of feasible group-count vectors is the polymatroid whose rank on a group subset is the maximum feasible allocation using those groups. Maximum-throughput opportunity-fair fractional allocations are computable in polynomial time given a polynomial-time independence oracle. [Source](https://arxiv.org/html/2403.00397v3)
No result for exactly the rational-support mass problem stated here was located in the literature search.

Modeling choices made when packaging the task

  • Specified nonnegative binary rational resource capacities, explicit eligibility sets, and nonnegative divisible flows; empty eligibility sets remain allowed.
  • Required positive isolated opportunity r(c) for every group, resolving the undefined ratios at zero opportunity.
  • Defined isolation using the original capacities and original group masses, without renormalizing the group to mass one.
  • Specified exact allocation optimization, defined m as the resource count and C as the group count, and defined L as total binary input length.

Result

The optimization problem is solvable exactly in time polynomial in \(m,\tau,C,L\).

The proof uses \(C\) maximum-flow computations followed by one linear program of polynomial encoding length.

1. Computing the isolation throughputs exactly

Let \(E=\{(t,j):j\in A_t\}\) and \(q=|E|\). Since eligibility sets are explicitly listed, \(q\leq \tau m\).

First replace each capacity by \(\kappa'_j=\min\{\kappa_j,1\}\). This preserves every feasible allocation: nonnegativity and the type constraints imply

\(\displaystyle \sum_{t:j\in A_t}y_{tj}\leq\sum_t\sum_{j\in A_t}y_{tj}\leq\sum_t\mu_t=1.\)

For a group \(c\), construct a directed network with source \(s\), sink \(v\), a vertex for each type labeled \(c\), and a vertex for each resource. Its arcs and capacities are:

  • \(s\to t\), with capacity \(\mu_t\);
  • \(t\to j\), with capacity \(1\), whenever \(j\in A_t\);
  • \(j\to v\), with capacity \(\kappa'_j\).

Every allocation restricted to group \(c\) defines a flow: put \(y_{tj}\) on \(t\to j\), its row sum on \(s\to t\), and its column sum on \(j\to v\). These satisfy conservation and capacities. Conversely, the flows on the type-to-resource arcs of any feasible network flow define an allocation restricted to group \(c\). In both directions, flow value equals allocation throughput. Thus the maximum-flow value is exactly \(r(c)\).

To control bit lengths, write the input masses and capacities as ratios of binary integers, and let \(D\) be the product of their positive denominators. Then \(\log_2D=O(L)\), and multiplying all network capacities by \(D\) gives integer capacities between \(0\) and \(D\). Truncating capacities to \(1\) introduces no new denominators.

Run, for example, the Edmonds–Karp maximum-flow algorithm on each scaled network. Its number of augmentations is polynomial in the numbers of vertices and arcs, independently of capacity magnitudes. All arithmetic uses integers of \(O(L)\) bits. Because the initial capacities are integers, every augmentation and the resulting maximum-flow value are integers.

Denote the scaled maximum-flow value by \(a_c\). Scaling flows establishes

\(\displaystyle r(c)=\frac{a_c}{D}.\)

The assumption \(r(c)>0\), together with total mass \(1\), gives \(1\leq a_c\leq D\). Consequently, all isolation throughputs are computable exactly in polynomial time and have polynomial binary encoding length.

2. A polynomial-size linear program

Introduce variables \(z_{tj}\) for \((t,j)\in E\), representing \(D y_{tj}\), and a variable \(\lambda\), representing the common opportunity ratio.

Consider the following linear program:

\(\displaystyle \text{maximize }\lambda\)

subject to

\(\displaystyle z_{tj}\geq0 \qquad ((t,j)\in E),\)

\(\displaystyle \sum_{j\in A_t}z_{tj}\leq D\mu_t \qquad (t=1,\ldots,\tau),\)

\(\displaystyle \sum_{t:j\in A_t}z_{tj}\leq D\kappa'_j \qquad (j=1,\ldots,m),\)

\(\displaystyle \sum_{t:g(t)=c}\sum_{j\in A_t}z_{tj}=a_c\lambda \qquad (c=1,\ldots,C),\)

\(\displaystyle 0\leq\lambda\leq1.\)

All coefficients and right-hand sides are integers of absolute value at most \(D\).

3. Equivalence and optimality

From an opportunity-fair allocation to an LP solution. Let \(y\) be feasible and opportunity-fair. Since all \(r(c)>0\), there is a common value \(\lambda\) such that \(x_c=\lambda r(c)\) for every group.

Nonnegativity gives \(\lambda\geq0\). To prove \(\lambda\leq1\), retain only the allocation to group \(c\). Removing other groups’ flows preserves feasibility, so the definition of \(r(c)\) gives \(x_c\leq r(c)\). Dividing by the positive quantity \(r(c)\) yields \(\lambda\leq1\).

Set \(z_{tj}=D y_{tj}\). The type and resource inequalities follow by scaling. For each group,

\(\displaystyle \sum_{t:g(t)=c}\sum_{j\in A_t}z_{tj}=D x_c=D\lambda r(c)=a_c\lambda.\)

Thus \((z,\lambda)\) is LP-feasible.

From an LP solution to an opportunity-fair allocation. Conversely, let \((z,\lambda)\) satisfy the LP and set \(y_{tj}=z_{tj}/D\). The scaled inequalities imply allocation feasibility. The group equations give

\(\displaystyle x_c=\frac{a_c\lambda}{D}=\lambda r(c),\)

so \(y\) is opportunity-fair.

Finally, every corresponding allocation has throughput

\(\displaystyle \sum_c x_c=\lambda\sum_c r(c)=\frac{\lambda}{D}\sum_c a_c.\)

Since \(\sum_c a_c>0\) is a fixed constant, maximizing \(\lambda\) is exactly equivalent to maximizing total throughput. Hence an optimal LP solution yields an optimal opportunity-fair allocation.

4. Exact polynomial-time computation

The LP has \(q+1\) variables and \(O(q+\tau+m+C)\) constraints. Its integer entries have \(O(L)\) bits, so its total encoding length is polynomial in \(m,\tau,C,L\).

We apply the standard polynomial-time theorem for rational linear programming: an explicitly encoded rational LP can be solved in polynomial bit complexity, returning an exact rational optimum when an optimum exists. This is the classical polynomial solvability result of [Khachiyan](https://www.mathnet.ru/eng/zvmmf5239).

Here its hypotheses hold:

  • the coefficients, objective, and right-hand sides are explicitly encoded rational numbers;
  • the feasible set is nonempty, because \(z=0,\lambda=0\) is feasible;
  • the feasible set is bounded, because each \(z_{tj}\leq D\mu_t\leq D\) and \(0\leq\lambda\leq1\).

For completeness, the exact output also has polynomial length. A linear objective on a nonempty bounded polyhedron attains its optimum at a vertex. Put \(n=q+1\). At a vertex, choose \(n\) linearly independent active constraint rows, obtaining an invertible integer system \(Bu=b\). Every entry of \(B\) and \(b\) has absolute value at most \(D\).

By Cramer’s rule, each coordinate is a ratio of integer determinants. Hadamard’s inequality bounds the absolute values of both denominator and numerator determinants by

\(\displaystyle (\sqrt n\,D)^n.\)

Their binary lengths are therefore \(O(n(L+\log n))\). Dividing the resulting \(z_{tj}\) by \(D\) adds only \(O(L)\) bits per coordinate.

Thus the algorithm computes and outputs an exact optimal allocation in polynomial time. This directly settles the rational-support problem without requiring a matroid representation.
