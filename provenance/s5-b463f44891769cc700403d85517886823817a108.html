The anchor (named result in the paper)

Theorem 1 — class: hardness

The continuous mirror question, as graded

Given a finite type set \(T\), type masses \(\mu_t\ge0\) with \(\sum_t\mu_t=1\), feature incidences \(a_{ft}\in\{0,1\}\), target panel mass \(\kappa\), and quota bounds \(\ell_f,u_f\), decide whether there exists a measurable selected subpopulation with masses \(y_t\) satisfying \(0\le y_t\le\mu_t\), \(\sum_t y_t=\kappa\), and \(\ell_f\le\sum_t a_{ft}y_t\le u_f\) for every feature \(f\).

Packaged proof task (what the prover saw — nothing else)

Let \(T\) and \(F\) be finite sets of types and features. Each type \(t\) is a nonatomic population of rational mass \(\mu_t\geq 0\), with \(\sum_{t\in T}\mu_t=1\). A type has feature \(f\) exactly when \(a_{ft}=1\), where \(a_{ft}\in\{0,1\}\). Given rational target mass \(\kappa\) and rational quota bounds \(\ell_f,u_f\), selection may take any mass \(y_t\) with \(0\leq y_t\leq\mu_t\). It is feasible when \(\sum_{t\in T}y_t=\kappa\) and \(\ell_f\leq\sum_{t\in T}a_{ft}y_t\leq u_f\) for every \(f\in F\). All rational inputs are encoded in binary.

Is deciding feasibility for this continuous panel-selection problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For a finite pool of indivisible agents, deciding whether a panel of the required size satisfies all feature quotas is \(\mathrm{NP}\)-hard. That result does not establish the complexity of selection from nonatomic type masses.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

Conclusion

The continuous panel-selection feasibility problem is in \(\mathrm{P}\). It is exactly a rational linear-programming feasibility problem of polynomial encoding length.

Proof

Write \(n=|T|\) and \(m=|F|\). Introduce one real variable \(y_t\) for each type \(t\in T\), representing the selected mass of that type.

Express all feasibility conditions as linear inequalities:

  • For each \(t\in T\), impose \(y_t\leq\mu_t\) and \(-y_t\leq 0\).
  • Impose \(\sum_{t\in T}y_t\leq\kappa\) and \(-\sum_{t\in T}y_t\leq-\kappa\).
  • For each \(f\in F\), impose \(\sum_{t\in T}a_{ft}y_t\leq u_f\) and \(-\sum_{t\in T}a_{ft}y_t\leq-\ell_f\).

The resulting system has \(n\) variables and \(2n+2m+2\) inequalities. Its coefficient matrix has entries in \(\{-1,0,1\}\), and its right-hand side consists of input rationals, their negatives, and zeros.

Equivalence. Any feasible selection satisfies these inequalities by definition. Conversely, any real solution satisfies the individual mass bounds; the two total-mass inequalities force \(\sum_{t\in T}y_t=\kappa\); and the two inequalities for each feature enforce its lower and upper quotas. By the premise that any mass \(y_t\in[0,\mu_t]\) may be selected, this solution is an admissible selection. No integrality condition is needed.

Polynomial encoding length. Let \(L\) denote the total binary input length. The explicitly listed types and features give \(n,m\leq L\). Even a dense representation of the constructed system uses only polynomially many entries in \(L\). Negating or copying a rational increases its encoding length by at most a constant per copy. Hence the system can be constructed in polynomial time and has polynomial encoding length.

We apply the following standard theorem on rational linear programming:

Given a rational matrix \(B\) and rational vector \(b\), both encoded in binary, there is a deterministic algorithm deciding whether a real vector \(x\) satisfies \(Bx\leq b\), in time polynomial in the total encoding length.

This theorem decides exact feasibility; it does not require strict feasibility or a feasible region with nonempty interior. Thus the total-mass equality and any tight quotas cause no difficulty.

Our constructed system has rational coefficients and polynomial encoding length, so the theorem yields a polynomial-time feasibility algorithm. This proves membership in \(\mathrm{P}\).

Why the indivisible case differs

For indivisible agents, selection variables must be integral. That requirement is absent here and changes feasibility. For example, consider two types with masses \(\mu_1=\mu_2=1/2\), with one feature possessed only by type \(1\). Set \(\kappa=1/2\) and \(\ell_f=u_f=1/4\). Continuous selection is feasible with \(y_1=y_2=1/4\). If each type instead consisted of one indivisible agent of mass \(1/2\), no selection could attain feature mass \(1/4\).

Consequently, hardness for indivisible selection does not establish hardness here. Under polynomial-time many-one reductions, the continuous problem could be \(\mathrm{NP}\)-hard only if \(\mathrm{P}=\mathrm{NP}\).
