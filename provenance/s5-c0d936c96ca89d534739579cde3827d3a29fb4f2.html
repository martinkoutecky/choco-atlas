The continuous mirror question, as graded

Given a connected finite site graph \(H=(V,E)\), valuation types \(T\) with rational masses \(\mu_t\) summing to \(1\), rational additive utilities \(u_t(v)\), site capacities \(\rho_v\), and an average allocation target \(r\), decide whether there exist nonnegative variables \(x_{t,B}\), indexed by nonempty connected bundles \(B\subseteq V\), such that \(\sum_B x_{t,B}=\mu_t\), \(\sum_{t,B\ni v}x_{t,B}\le\rho_v\), \(\sum_{t,B}|B|x_{t,B}=r\), and \(x_{t,B}x_{s,D}>0\Rightarrow u_t(B)\ge u_t(D)\) for all supported bundles, where \(u_t(B)=\sum_{v\in B}u_t(v)\).

Packaged proof task (what the prover saw — nothing else)

Given a finite simple connected undirected graph \(H=(V,E)\), let \(m=|V|\ge1\). A society is given by its support: the list of the \(\tau\ge1\) valuation types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has additive utilities \(u_t(v)\in\mathbb Q_{\ge0}\), with \(\sum_{v\in V}u_t(v)>0\). Inputs also include capacities \(\rho_v\in\mathbb Q_{\ge0}\) and an average allocation target \(r\in\mathbb Q\cap[1,m]\). All rationals are binary encoded; \(L\) is the total input bit length.
Let \(\mathcal B=\{B\subseteq V:B\ne\varnothing,\ H[B]\text{ is connected}\}\); this family is implicit, not supplied as an explicit list. A variable \(x_{t,B}\in\mathbb R_{\ge0}\) denotes the mass of type \(t\) receiving bundle \(B\), and \(u_t(B)=\sum_{v\in B}u_t(v)\).
Feasibility requires \(\sum_{B\in\mathcal B}x_{t,B}=\mu_t\) for every \(t\), \(\sum_t\sum_{B\in\mathcal B:v\in B}x_{t,B}\le\rho_v\) for every \(v\), and \(\sum_t\sum_{B\in\mathcal B}|B|x_{t,B}=r\).
Envy-freeness requires \(x_{t,B}x_{s,D}>0\Rightarrow u_t(B)\ge u_t(D)\) for every \(t,s\) and \(B,D\in\mathcal B\), including \(t=s\); utility ties are allowed. Define \(k=\lceil r\rceil+\tau\).

Is deciding feasibility in \(\mathsf P\) or \(\mathsf{NP}\)-hard? If it is \(\mathsf{NP}\)-hard, is it nevertheless \(\mathsf{FPT}\) parameterized by \(k\)? State running times in \(m,\tau,L\), and \(k\).

For discrete agents receiving pairwise disjoint nonempty connected bundles totaling exactly \(p\) vertices, envy-free feasibility is \(\mathsf W[1]\)-hard parameterized by \(p+n\), even on stars with two agents having identical binary valuations ([Gahlawat–Zehavi](https://link.springer.com/article/10.1007/s10458-026-09760-w)).
The complete-allocation special case is \(\mathsf{NP}\)-complete even on stars, so the discrete incomplete problem is also \(\mathsf{NP}\)-hard ([Bouveret et al.](https://dominik-peters.de/publications/cakecutting.pdf)); later work establishes \(\mathsf W[1]\)-hardness for \(p+n\) with unary valuations on stars ([E. S.–Lokshtanov](https://drops.dagstuhl.de/storage/00lipics/lipics-vol360-fsttcs2025/LIPIcs.FSTTCS.2025.29/LIPIcs.FSTTCS.2025.29.pdf)).
No complexity classification for this precise mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Restricted rational utilities to nonnegative values and required each supported type to value at least one site positively, following the discrete goods domain and nondegeneracy assumption.
  • Specified a nonempty finite simple undirected graph and interpreted connected bundles through induced subgraphs.
  • Specified nonnegative binary rational capacities, measured in the same normalized mass units as the society; zero capacities are allowed.
  • Restricted the rational average target to [1,m], reflecting nonempty bundles and the normalized counterpart of n≤p≤m.
  • Specified real nonnegative allocation masses and an implicit family of all eligible bundles.
  • For the additional parameterized question, chose k=ceil(r)+tau because the normalized formulation supplies an average allocation target and a support size, but no finite agent count or integer total allocation parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

The problem is \(\mathsf{NP}\)-complete, even with one valuation type, a star graph, and the fixed target \(r=5/4\). These instances have \(k=\lceil r\rceil+\tau=3\).

Consequently, an \(\mathsf{FPT}\) algorithm parameterized by \(k\) would imply \(\mathsf P=\mathsf{NP}\). The same obstruction rules out an \(\mathsf{XP}\) algorithm under that assumption.

A deterministic algorithm for general instances runs in time \(2^{O(m\tau)}\operatorname{poly}(m,\tau,L)\), hence also in time \(2^{O(mk)}\operatorname{poly}(m,k,L)\).

1. Self-envy forces equal utility within each type

For an allocation \(x\), call \((t,B)\) supported when \(x_{t,B}>0\).

If \((t,B)\) and \((t,D)\) are both supported, envy-freeness applied in both directions gives \(u_t(B)\ge u_t(D)\) and \(u_t(D)\ge u_t(B)\). Thus \(u_t(B)=u_t(D)\).

Because \(\mu_t>0\), every type has a supported bundle. Therefore every envy-free allocation determines a utility level \(c_t\) for each type, with the following properties:

  • Every bundle assigned positive mass to type \(t\) has utility \(c_t\) under \(u_t\).
  • Every bundle assigned positive mass to any type has utility at most \(c_t\) under \(u_t\).

Conversely, these two properties imply envy-freeness: a supported type-\(t\) bundle has utility \(c_t\), while every other supported bundle has utility at most \(c_t\) under \(u_t\).

2. Hardness with \(k=3\)

Source problem

We reduce from binary-encoded \(\mathsf{SUBSET\ SUM}\): given positive integers \(a_1,\ldots,a_n,T\), decide whether some \(S\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in S}a_i=T\). Its \(\mathsf{NP}\)-completeness is classical; it appears as the exact “KNAPSACK” problem in [Karp’s original paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

We may restrict to \(n\ge1\) and \(0<a_i<T\). Indeed, delete entries exceeding \(T\). An entry equal to \(T\) immediately certifies a yes-instance, and an empty remaining list certifies a no-instance. These cases can be mapped to the fixed restricted instances \((1,1;2)\) and \((1;2)\), respectively. All other instances already satisfy the restriction. Hence this restricted source problem remains \(\mathsf{NP}\)-hard.

Construction

Given a restricted source instance, construct a star with center \(c\) and the following leaves:

  • A distinguished leaf \(d\).
  • Item leaves \(v_1,\ldots,v_n\).
  • Padding leaves \(z_1,\ldots,z_n\).

Thus \(m=2n+2\). Use one type, of mass \(\mu_1=1\), and write its utility as \(u\). Set

\(u(c)=0,\qquad u(d)=T,\qquad u(v_i)=a_i,\qquad u(z_i)=0.\)

Define \(\varepsilon=1/(4n)\), and set

\(\rho_c=\varepsilon,\qquad \rho_d=1-\varepsilon,\qquad \rho_{v_i}=\rho_{z_i}=\varepsilon,\qquad r=5/4.\)

All hypotheses hold: the graph is finite, simple, and connected; utilities are nonnegative with positive total; capacities are nonnegative; and \(r\in[1,m]\).

If the source input has bit length \(b\), the constructed input has bit length \(O(b+n\log n)\), and construction takes polynomial time. Moreover,

\(k=\lceil5/4\rceil+1=3.\)

Forward implication

Suppose \(\sum_{i\in S}a_i=T\). Choose any \(n-|S|\) padding leaves, forming a set \(Z\), and let

\(B=\{c\}\cup\{v_i:i\in S\}\cup Z.\)

The bundle \(B\) is connected, has \(|B|=n+1\), and satisfies \(u(B)=T\).

Allocate mass \(1-\varepsilon\) to \(\{d\}\) and mass \(\varepsilon\) to \(B\). The total mass is one. The distinguished leaf has load \(1-\varepsilon\); every vertex of \(B\) has load \(\varepsilon\); all other vertices have load zero. Thus every capacity constraint holds.

The average bundle size is

\((1-\varepsilon)\cdot1+\varepsilon(n+1)=1+n\varepsilon=5/4=r.\)

Both supported bundles have utility \(T\), so the allocation is envy-free.

Reverse implication

Suppose the constructed instance admits a feasible envy-free allocation. Write \(x_B\) for its single-type variables, and let

\(z=\sum_{B:c\in B}x_B.\)

The center capacity gives \(z\le\varepsilon\).

Every connected bundle omitting \(c\) is a singleton. Apart from \(d\), there are \(2n\) leaves, each with capacity \(\varepsilon\). Consequently,

\(x_{\{d\}}=1-z-\sum_{\ell\ne d,c}x_{\{\ell\}}\ge1-(2n+1)\varepsilon=(2n-1)/(4n)>0.\)

Thus \(\{d\}\) is supported. By self-envy, every supported bundle has utility \(u(d)=T\).

Every singleton other than \(\{d\}\) has utility strictly below \(T\). Hence every supported bundle other than \(\{d\}\) contains \(c\), and therefore

\(x_{\{d\}}+z=1.\)

Since \(z\le\varepsilon\), this gives \(x_{\{d\}}\ge1-\varepsilon\). On the other hand, the capacity of \(d\) implies

\(x_{\{d\}}+\sum_{B:c,d\in B}x_B\le1-\varepsilon.\)

These inequalities force \(x_{\{d\}}=1-\varepsilon\), \(z=\varepsilon\), and zero mass on every bundle containing both \(c\) and \(d\).

Because \(z=\varepsilon>0\), some supported bundle \(B\) contains \(c\) and omits \(d\). Its only positive-utility vertices are item leaves. Since \(u(B)=T\), the set

\(S=\{i:v_i\in B\}\)

satisfies \(\sum_{i\in S}a_i=T\). The source instance is therefore a yes-instance.

This completes the reduction.

3. Polynomial-size certificates

We now prove membership in \(\mathsf{NP}\), despite the implicit bundle family and real-valued variables.

Suppose a feasible envy-free allocation exists, and let \(\mathcal S\) be its finite set of supported pairs \((t,B)\). Restrict the allocation variables to \(\mathcal S\). Introduce one nonnegative slack variable for each capacity inequality.

The resulting system has \(q=\tau+m+1\) equality rows: \(\tau\) type-mass equations, \(m\) capacity equations, and one average-size equation. Its coefficient matrix is integral, with entries bounded in absolute value by \(m\).

The system is feasible. Its feasible region is also bounded: each allocation variable is at most its type’s mass, and each slack is at most its corresponding capacity. Thus it is a nonempty compact polytope and has an extreme point.

At any extreme point, the columns corresponding to positive coordinates are linearly independent. Otherwise, a nonzero dependence supported on those coordinates would allow sufficiently small perturbations in both directions, preserving all equations and nonnegativity, contradicting extremality. Therefore at most \(q\) coordinates are positive, including slacks. In particular, at most \(q\) allocation variables are positive.

These coordinates have polynomial bit length. To see this explicitly, let their number be \(d\le q\), and select \(d\) rows giving a nonsingular square submatrix. Let \(Q\) be the product of the denominators of the right-hand-side rationals. Its bit length is \(O(L)\). Cramer’s rule, together with the determinant bound \(d!m^d\), gives bit length \(O(L+q\log(qm))\) for each coordinate.

The new allocation uses a subset of the original supported pairs, so it remains envy-free.

A certificate therefore consists of at most \(\tau+m+1\) type–bundle pairs, their vertex sets, and rational masses of polynomial bit length. Connectivity, feasibility, and every required envy comparison can all be checked by exact rational arithmetic in \(\operatorname{poly}(m,\tau,L)\) time.

Hence the problem belongs to \(\mathsf{NP}\). Together with the reduction, it is \(\mathsf{NP}\)-complete.

4. Deterministic running time

Enumerate all nonempty connected vertex sets. Their number \(N\) satisfies \(N\le2^m-1\).

For each type \(t\), guess a bundle \(A_t\) and define \(c_t=u_t(A_t)\). There are at most \(N^\tau\) such guesses.

For a fixed guess, allow a variable \(x_{s,B}\) precisely when

\(u_s(B)=c_s\quad\text{and}\quad u_t(B)\le c_t\text{ for every }t.\)

Solve the original feasibility constraints over these allowed variables using exact rational linear programming.

If the linear program is feasible, Section 1 shows that its allocation is envy-free. Conversely, from any feasible envy-free allocation, choose one supported bundle \(A_t\) for each type. Section 1 shows that this guess allows every variable used by that allocation. Thus the algorithm is complete.

Each linear program has at most \(\tau N\) variables and \(\tau+m+1\) constraints. All coefficients have polynomial bit length. The resulting running time is

\(N^\tau\operatorname{poly}(\tau N,m,L)=2^{O(m\tau)}\operatorname{poly}(m,\tau,L).\)

Since \(\tau\le k\), this also gives \(2^{O(mk)}\operatorname{poly}(m,k,L)\).

5. Parameterized consequence

An algorithm with running time \(f(k)\operatorname{poly}(m,\tau,L)\) would run in polynomial time on the reduction above, because every constructed instance has \(k=3\). It would therefore solve an \(\mathsf{NP}\)-hard problem in polynomial time.

The same argument excludes running times of the form \(f(k)(m+\tau+L)^{g(k)}\), unless \(\mathsf P=\mathsf{NP}\). Thus even \(\mathsf{XP}\) parameterized by \(k\) is ruled out under that assumption.

The decisive feature is that \(r\) bounds an average, while a bundle of \(n+1\) vertices may receive mass \(1/(4n)\). Consequently, bounded \(k\) does not bound the size of supported bundles.
