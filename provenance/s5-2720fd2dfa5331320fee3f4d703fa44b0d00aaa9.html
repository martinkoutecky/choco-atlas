The continuous mirror question, as graded

Given candidates \(C\), a finite support \(S\) of partial orders on \(C\), positive binary-rational masses \(\mu_P\) summing to \(1\), and a target \(c^\star\), decide whether there are nonnegative rational masses \(x_{P,\rho}\), for \(P\in S\) and each linear extension \(\rho\) of \(P\), such that \(\sum_{\rho\in\operatorname{LE}(P)}x_{P,\rho}=\mu_P\) for every \(P\), and \(\sum_{P,\rho}x_{P,\rho}(m-\operatorname{rank}_{\rho}(d))\leq\sum_{P,\rho}x_{P,\rho}(m-\operatorname{rank}_{\rho}(c^\star))\) for every \(d\ne c^\star\), where \(m=|C|\).

Packaged proof task (what the prover saw — nothing else)

Given a nonempty candidate set \(C\), let \(m=|C|\) and let \(c^\star\in C\). A society is given by its support: a list \(S\) of \(\tau\) distinct strict partial orders on \(C\), each explicitly represented by its ordered pairs and assigned a positive binary-rational mass \(\mu_P\), with \(\sum_{P\in S}\mu_P=1\). Here \(\tau=|S|\) is the support size, not the number of possible types; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
Let \(\operatorname{LE}(P)\) denote the linear extensions of \(P\), with ranks numbered from \(1\) (best) to \(m\). A completion may split each type's mass among its linear extensions: \(x_{P,\rho}\in\mathbb{Q}_{\geq0}\) and \(\sum_{\rho\in\operatorname{LE}(P)}x_{P,\rho}=\mu_P\).
Under Borda, define \(B_x(d)=\sum_{P\in S}\sum_{\rho\in\operatorname{LE}(P)}x_{P,\rho}(m-\operatorname{rank}_\rho(d))\). Call a completion feasible when \(B_x(d)\leq B_x(c^\star)\) for every \(d\in C\setminus\{c^\star\}\); tied highest scores count as winning.

Is deciding whether such a feasible completion exists in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For a finite list of indivisible voters with arbitrary partial orders, Borda possible-winner determination is \(\mathrm{NP}\)-complete. [Verified classification](https://theo.delemazure.fr/more/acmtds.pdf).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The problem is \(\mathrm{NP}\)-complete. This holds even when every mass is dyadic and the support size satisfies \(\tau\leq 3m\).

The proof below gives a polynomial many-one reduction. It explicitly accounts for mass splitting: the lower bound used in the reduction holds for every linear extension and therefore survives arbitrary averaging.

1. An auxiliary rank-sum problem

For a strict partial order \(Q\) on a set \(V\), a nonempty subset \(A\subseteq V\), and an integer \(H\), consider whether some linear extension \(\lambda\) satisfies

\(\displaystyle \sum_{a\in A}\operatorname{rank}_{\lambda}(a)\leq H.\)

We first prove that this problem is \(\mathrm{NP}\)-hard.

Our starting problem is Minimum Linear Arrangement: given a simple undirected graph \(G=(U,E)\) and an integer \(K\), decide whether there is a bijection \(\pi:U\to\{1,\ldots,n\}\), where \(n=|U|\), satisfying

\(\displaystyle \operatorname{LA}(\pi):=\sum_{\{u,v\}\in E}|\pi(u)-\pi(v)|\leq K.\)

This problem is \(\mathrm{NP}\)-complete by [Garey, Johnson, and Stockmeyer](https://doi.org/10.1016/0304-3975(76)90059-1).

Instances with no edges, negative \(K\), or \(K>|E|(n-1)\) can be decided immediately and mapped to fixed yes- or no-instances. Thus, for the construction, assume \(n\geq2\), \(E\neq\varnothing\), and \(0\leq K\leq |E|(n-1)\).

Let

\(\displaystyle D=\max_{v\in U}\deg(v),\qquad q=nD,\qquad M=q^2+1.\)

Construct a partial order \(Q_0\) as follows.

  • For each vertex \(v\), create a chain \(v_1\prec\cdots\prec v_M\).
  • For each edge \(\{u,v\}\), create two distinguished elements, each required to follow both \(u_M\) and \(v_M\).
  • For each vertex \(v\), create \(D-\deg(v)\) additional distinguished elements, each required to follow \(v_M\).

There are no other generating precedence constraints. Take their transitive closure, so the order is explicitly represented as required.

Let \(A_0\) be the set of distinguished elements. Its size is

\(\displaystyle |A_0|=2|E|+\sum_v(D-\deg(v))=nD=q.\)

The total number of elements is \(N_0=nM+q\).

Lower bound for every extension. Fix a linear extension \(\lambda\). Order the vertices by the ranks of their last chain elements \(v_M\); denote the resulting bijection by \(\pi\).

When \(v_M\) occurs, all elements of the \(\pi(v)\) completed vertex chains have already occurred. Therefore

\(\displaystyle \operatorname{rank}_{\lambda}(v_M)\geq M\pi(v).\)

Every distinguished element follows its prescribed last chain elements. Consequently,

\(\displaystyle \sum_{a\in A_0}\operatorname{rank}_{\lambda}(a) \geq M\left( 2\sum_{\{u,v\}\in E}\max\{\pi(u),\pi(v)\} +\sum_v(D-\deg(v))\pi(v) \right). \)

Using \(2\max\{i,j\}=i+j+|i-j|\), the expression in parentheses equals

\(\displaystyle \sum_v\deg(v)\pi(v)+\operatorname{LA}(\pi) +\sum_v(D-\deg(v))\pi(v) = D\frac{n(n+1)}2+\operatorname{LA}(\pi). \)

Thus every extension satisfies

\[\displaystyle \sum_{a\in A_0}\operatorname{rank}_{\lambda}(a) \geq M\left(D\frac{n(n+1)}2+\operatorname{LA}(\pi)\right). \tag{1} \]

Upper bound from an arrangement. Conversely, fix any arrangement \(\pi\). Process the vertex chains consecutively in that order. After each chain, place every distinguished element whose prescribed predecessors have now been completed.

A distinguished element whose last required vertex has arrangement position \(j\) has rank at most \(Mj+q\): there are exactly \(Mj\) vertex-chain elements before it and at most \(q\) distinguished elements up to its position. Summing gives

\[\displaystyle \sum_{a\in A_0}\operatorname{rank}_{\lambda}(a) \leq M\left(D\frac{n(n+1)}2+\operatorname{LA}(\pi)\right)+q^2. \tag{2} \]

Define

\(\displaystyle H_0=M\left(D\frac{n(n+1)}2+K\right)+q^2.\)

If an arrangement has value at most \(K\), inequality (2) gives an extension of rank sum at most \(H_0\). If every arrangement has value at least \(K+1\), inequality (1) gives, for every extension,

\(\displaystyle \sum_{a\in A_0}\operatorname{rank}_{\lambda}(a) \geq M\left(D\frac{n(n+1)}2+K+1\right)>H_0, \)

because \(M>q^2\). This proves the claimed equivalence.

All sizes are polynomial: \(q=O(n^2)\), \(M=O(n^4)\), and \(N_0=O(n^5)\).

We will also need \(0\leq H_0\leq qN_0\). Indeed, \(|E|\leq nD/2\), so

\(\displaystyle H_0 \leq M\left(D\frac{n(n+1)}2+D\frac{n(n-1)}2\right)+q^2 =MDn^2+q^2=qN_0. \)

2. Padding the distinguished set

To ensure dyadic masses later, make the distinguished-set size a power of two.

Let \(k\) be the smallest power of two at least \(q\), and put \(r=k-q\). Add a chain of \(r\) new distinguished elements before every element of \(Q_0\). Denote the resulting order by \(Q\), its distinguished set by \(A\), and its ground-set size by \(N=N_0+r\).

Every old element’s rank increases by \(r\), and the new distinguished ranks are exactly \(1,\ldots,r\). Hence set

\(\displaystyle H=H_0+rq+\frac{r(r+1)}2.\)

Then

\(\displaystyle \exists\lambda\in\operatorname{LE}(Q_0): \sum_{a\in A_0}\operatorname{rank}_{\lambda}(a)\leq H_0 \quad\Longleftrightarrow\quad \exists\lambda\in\operatorname{LE}(Q): \sum_{a\in A}\operatorname{rank}_{\lambda}(a)\leq H. \)

Here \(|A|=k\), \(k\) is a power of two, and \(0\leq H\leq kN\). For the last inequality,

\(\displaystyle kN-H=(qN_0-H_0)+rN_0+\frac{r(r-1)}2\geq0. \)

Write

\(\displaystyle T=\min_{\lambda\in\operatorname{LE}(Q)} \sum_{a\in A}\operatorname{rank}_{\lambda}(a).\)

The auxiliary question is now exactly whether \(T\leq H\).

3. The types whose masses may split

Let \(m\) be the smallest power of two at least \(N+1\). The election candidates are the elements of \(Q\), the designated candidate \(c^\star\), and \(s=m-N-1\) padding candidates.

Define a partial order \(P\) by:

  • reversing all precedence relations of \(Q\);
  • placing every element of \(Q\) above \(c^\star\);
  • placing the padding candidates below \(c^\star\) in a fixed chain.

For any extension \(\lambda\) of \(Q\), reverse \(\lambda\), then append \(c^\star\) and the padding chain. This gives every extension of \(P\). Its Borda scores satisfy

\[\displaystyle b(c^\star)=s,\qquad b(a)=s+\operatorname{rank}_{\lambda}(a)\quad(a\in V). \tag{3} \]

Choose a cyclic permutation \(\sigma\) of the \(k\) elements of \(A\), fixing every other candidate. For \(j\in\{0,\ldots,k-1\}\), include the relabeled order

\(\displaystyle P_j=\sigma^j(P)\)

with mass \(\varepsilon/k\), where

\(\displaystyle \varepsilon=\frac1{32m^2}.\)

These types have total mass \(\varepsilon\). Since \(m\) and \(k\) are powers of two, their masses are dyadic.

For any completion of these types, let \(V(d)\) denote their aggregate contribution to candidate \(d\). Equation (3) gives

\(\displaystyle V(c^\star)=\varepsilon s.\)

Undoing the relabeling in any extension of any \(P_j\) produces an extension of \(Q\). Its distinguished rank sum is at least \(T\). Averaging therefore preserves the bound:

\[\displaystyle \sum_{a\in A}V(a)-kV(c^\star)\geq\varepsilon T. \tag{4} \]

There is also a completion attaining equality while giving all distinguished candidates the same score. Choose an extension of \(Q\) attaining \(T\), reverse it, and use its corresponding relabeling for each \(P_j\). Each distinguished candidate occupies each distinguished role exactly once across the cyclic relabelings. Consequently,

\[\displaystyle V(a)=\varepsilon\left(s+\frac Tk\right) \quad\text{for every }a\in A. \tag{5} \]

4. Constructing the fixed score differences

The remaining mass \(R=1-\varepsilon\) will be assigned to total orders. Their aggregate scores, denoted by \(F(d)\), must satisfy

\[\displaystyle F(d)-F(c^\star)=g_d,\qquad g_d= \begin{cases} -\varepsilon H/k,&d\in A,\\ -\varepsilon m,&d\notin A\cup\{c^\star\}. \end{cases} \tag{6} \]

We now construct these total-order types explicitly.

Put

\(\displaystyle z_{c^\star}=-\frac1m\sum_{d\ne c^\star}g_d,\qquad z_d=z_{c^\star}+g_d\quad(d\ne c^\star). \)

Then \(\sum_d z_d=0\), and \(z_d-z_{c^\star}=g_d\). All these numbers are dyadic.

For a total order \(\rho\), let \(b(\rho)\) be its Borda vector and let \(\bar\rho\) be its reversal. Coordinatewise,

\(\displaystyle b(\rho)+b(\bar\rho)=(m-1)\mathbf1.\)

Suppose \(\rho\) places \(a\) immediately above \(b\), and let \(\rho'\) swap those two adjacent candidates. Then

\[\displaystyle b(\rho')+b(\bar\rho) =(m-1)\mathbf1+e_b-e_a. \tag{7} \]

For each \(d\ne c^\star\) with \(z_d\ne0\), use this pair of total orders, assigning mass \(|z_d|\) to each:

  • if \(z_d>0\), transfer the unit in (7) from \(c^\star\) to \(d\);
  • if \(z_d<0\), transfer it from \(d\) to \(c^\star\).

Together, these pairs produce perturbation \(z\) around a uniform score vector. Their total mass is

\(\displaystyle R_0=2\sum_{d\ne c^\star}|z_d|.\)

Since \(H/k\leq N<m\), we have \(|g_d|\leq\varepsilon m\). Hence \(|z_{c^\star}|\leq\varepsilon m\) and \(|z_d|\leq2\varepsilon m\), giving

\(\displaystyle R_0\leq4\varepsilon m(m-1)<\frac18<R. \)

Assign mass \((R-R_0)/2\) to each of an arbitrary total order and its reversal. This supplies the remaining mass and contributes uniformly.

The resulting fixed scores are therefore

\(\displaystyle F(d)=R\frac{m-1}{2}+z_d,\)

which proves (6). Every included mass is positive and dyadic; zero-mass pairs are omitted.

5. Equivalence with feasible completion

Suppose first that \(c^\star\) wins in a completion. For every \(a\in A\), equations (6) and the winning condition give

\(\displaystyle 0\geq B(a)-B(c^\star) =V(a)-V(c^\star)-\varepsilon H/k. \)

Summing over \(A\) and applying (4),

\(\displaystyle 0\geq \sum_{a\in A}V(a)-kV(c^\star)-\varepsilon H \geq\varepsilon(T-H). \)

Because \(\varepsilon>0\), this implies \(T\leq H\). Thus splitting cannot turn an auxiliary no-instance into a feasible election.

Conversely, suppose \(T\leq H\). Use the cyclic completion from (5). For each \(a\in A\),

\(\displaystyle B(a)-B(c^\star)=\varepsilon(T-H)/k\leq0. \)

Every other competing candidate has fixed-score difference \(-\varepsilon m\). In each variable extension, its score exceeds the score of \(c^\star\) by at most \(N<m\): for an original element this follows from (3), and for a padding candidate the difference is negative. Consequently,

\(\displaystyle B(d)-B(c^\star)\leq-\varepsilon m+\varepsilon N<0 \quad(d\notin A\cup\{c^\star\}). \)

Therefore \(c^\star\) wins, with ties permitted as stipulated.

We have proved the exact equivalence

\(\displaystyle \text{the constructed society has a feasible completion} \quad\Longleftrightarrow\quad T\leq H. \)

6. Distinct support orders and encoding size

The construction initially produces a weighted list in which some orders may coincide. Merge equal orders by summing their masses.

This preserves feasibility exactly. In one direction, sum the component completions. In the other direction, if equal-order components had masses \(\alpha_1,\ldots,\alpha_t\), split a completion of their merged mass proportionally: component \(i\) receives fraction \(\alpha_i/(\sum_j\alpha_j)\) of each extension’s assigned mass. All resulting masses remain rational and produce the same aggregate scores.

There are at most \(k\) variable components and \(2(m-1)+2\) fixed components. After merging,

\(\displaystyle \tau\leq k+2m\leq3m.\)

All input masses have \(O(\log m)\) bits: their denominators are powers of two obtained from \(32m^2\), \(k\), \(m\), and one additional factor of two, while \(H\leq kN\).

Each order can be represented by \(O(m^2)\) ordered pairs. Thus the constructed input satisfies

\(\displaystyle L=O(m^3\log m).\)

Since \(m=O(n^5)\), explicitly producing all pairs and merging duplicate orders takes polynomial time in the source input length. This completes the polynomial many-one hardness reduction.

7. Membership in \(\mathrm{NP}\) and running times

For a general input, use one variable \(x_{P,\rho}\) for every supported order and each of its linear extensions. The feasibility conditions form a finite rational linear program with:

  • \(\tau\) mass equalities;
  • \(m-1\) winner inequalities;
  • nonnegative variables.

Introduce one nonnegative slack variable per winner inequality. There are \(u=\tau+m-1\) equality rows, and every matrix coefficient is an integer of absolute value at most \(m\).

The feasible set is bounded: completion variables sum to one, and each slack is at most \(m-1\). If it is nonempty, it has an extreme point. At an extreme point, the columns corresponding to positive coordinates are linearly independent; otherwise a sufficiently small perturbation in a column dependence would express the point as the midpoint of two distinct feasible points. Hence at most \(u\) coordinates are positive.

Let \(D_{\mathrm{in}}\) be the product of the input mass denominators. Its bit length is \(O(L)\). Applying Cramer’s rule to a nonsingular minor for the positive coordinates, and bounding determinants by Hadamard’s inequality, shows that each positive coordinate has bit length

\(\displaystyle O\!\left(L+u\log(um)\right).\)

Thus a yes-instance has a polynomial-size certificate consisting of at most \(\tau+m-1\) listed linear extensions and their rational assigned masses. Checking precedence pairs, mass equalities, and Borda inequalities takes \(\operatorname{poly}(m,\tau,L)\) time. Therefore the problem belongs to \(\mathrm{NP}\).

A direct deterministic algorithm enumerates at most \(\tau m!\) extensions and solves the resulting rational linear program, taking

\(\displaystyle (\tau m!)^{O(1)}\operatorname{poly}(m,\tau,L)\)

time. The completeness result rules out a running time polynomial in \(m,\tau,L\) unless \(\mathrm{P}=\mathrm{NP}\).
