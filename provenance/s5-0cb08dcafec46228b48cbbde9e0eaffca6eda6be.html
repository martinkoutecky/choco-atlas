The continuous mirror question, as graded

Given a rational finite-support distribution \(\mu\) over approval types \(A_t\subseteq P\), rational per-capita project costs \(c_p\), a common per-capita budget \(\beta\), fixed project tie-breaking, and the current continuous EES state, compute \(\delta^*=\inf\{\delta>0:\text{EES at }\beta+\delta\text{ changes }W\text{ or a type's paying mass for some project}\}\). Report whether the infimum is attained, or report \(+\infty\) if no such change occurs.

Packaged proof task (what the prover saw — nothing else)

Let \(P\) contain \(m\geq1\) indivisible projects, with costs \(c_p\in\mathbb Q_{>0}\), and fix a total order for project tie-breaking. Utilities are approval utilities: one unit per approved selected project. The common initial budget is \(\beta\in\mathbb Q_{\geq0}\).
A society is given by its support: the list of the \(\tau\) approval types \(A_t\subseteq P\) with positive masses \(\mu_t\), each a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval sets. Each type represents divisible, nonatomic mass.
Continuous Exact Equal Shares (EES) starts with no selected projects and budget \(\beta\) for every individual. For each unselected project \(p\), consider all positive-mass measurable coalitions \(V\) of its approvers such that every participant's remaining budget is at least \(c_p/\mu(V)\). Its offer is the maximum feasible \(\mu(V)/c_p\); a project with no feasible coalition has no offer.
Select the project with highest offer, breaking project ties by the fixed order; its maximum-mass coalition pays \(c_p/\mu(V)\) per participating individual. Include all approving individuals able to pay this share. Debit their budgets, select the project once, and repeat until no offer exists.
Write \(S(a)=(W(a),H(a))\) for the terminal state obtained by restarting EES with initial individual budget \(a\), where \(H_{t,p}(a)\) is the mass of type \(t\) paying for project \(p\), and is zero for unselected projects. The input includes a rational state promised to equal \(S(\beta)\). Let \(L\) be the total binary input length.
Compute exactly \(\delta^*=\inf\{\delta>0:S(\beta+\delta)\ne S(\beta)\}\), reporting whether this infimum belongs to the defining set; report \(+\infty\) when that set is empty. Equality compares both the selected set and every type's paying mass.

Is this exact next-change problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite society of \(n\) voters, the corresponding next-change problem with approval utilities has an \(O(mn)\) arithmetic-operation algorithm ([discrete result](https://arxiv.org/html/2502.11797v1)). No result settling the exact nonatomic problem defined here was identified.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one, so project costs and the common individual budget use consistent per-capita units.
  • Specified approval utilities, as required by the algorithmic anchor, rather than general uniform utilities.
  • Excluded zero-cost projects because the EES offer and equal-share formulas divide by project cost; retained the permitted zero initial budget.
  • Interpreted type masses as nonatomic and allowed arbitrary measurable subcoalitions, carrying over EES's maximization of coalition size and weak affordability inequalities.
  • Defined the current state as a promised terminal EES outcome, with paying mass recorded separately for each type and project; increased-budget outcomes restart EES from scratch.
  • Defined attainment as membership in the set of strictly positive changing increments, including when the infimum is zero, and used positive infinity for an empty set.
  • Specified total binary input length and distinguished arithmetic-operation bounds for the discrete anchor from the requested bit complexity.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The exact next-change problem is polynomial-time solvable in \(m,\tau,L\). Whenever \(\delta^*\) is finite, it is strictly positive and belongs to the defining set.

The proof gives an algorithm using \(O(m^2\tau+m\tau\log(\tau+1))\) rational arithmetic operations and comparisons, with polynomially bounded operand lengths.

1. Maximum coalitions consist of whole types

Suppose that, at some stage, every individual of type \(t\) has the same remaining budget \(b_t\). This holds initially.

Fix a project \(p\), and let \(V\) be any feasible coalition of mass \(x>0\). Define \(E_x\) to contain all approving types whose budgets satisfy \(b_t\geq c_p/x\). Every participant in \(V\) belongs to \(E_x\), so its mass \(M\) satisfies \(M\geq x\). Every individual in \(E_x\) can afford \(c_p/x\), and hence can afford \(c_p/M\). Thus \(E_x\) is feasible.

Order the approving types by decreasing remaining budget, keeping types with equal budgets together. Each set \(E_x\) is a prefix of this order ending at a budget block. There are at most \(\tau\) such prefixes. Consequently:

  • A feasible coalition exists exactly when some such prefix is feasible.
  • The maximum feasible mass is the largest mass among the feasible prefixes.
  • The maximum coalition is unique up to null sets.

For the last assertion, let \(M^*\) be the largest feasible prefix mass. Any feasible coalition of mass \(M^*\) is contained in \(E_{M^*}\). This set is feasible and has mass at least \(M^*\); maximality forces its mass to equal \(M^*\). Hence the coalition equals \(E_{M^*}\) up to a null set.

In particular, the maximum coalition includes exactly all approvers able to afford its share. Entire types pay or do not pay. Debiting this coalition preserves uniform budgets within each type, so the argument applies inductively throughout EES.

Therefore, in every actual terminal state,

\(H_{t,p}(a)\in\{0,\mu_t\}\).

No enumeration of arbitrary measurable coalitions or subsets of approval types is needed.

2. The terminal state determines the execution

A trace records the ordered selected projects and the paying types for each.

For a selected project \(p\), define its paying mass and individual share by

\(M_p=\sum_t H_{t,p}(a),\qquad s_p=c_p/M_p.\)

We claim that every execution selects projects in increasing order of \(s_p\), breaking equal-share ties by the fixed project order.

Indeed, suppose \(p\) is selected before \(q\). The coalition that eventually pays for \(q\) was also feasible immediately before \(p\) was selected: each participant had at least as much budget then, because budgets only decrease. Hence the offer of \(q\) at that earlier stage was at least \(1/s_q\).

The selected project \(p\) had offer \(1/s_p\), which was at least the offer of \(q\). Thus \(s_p\leq s_q\).

If \(s_p=s_q\), those inequalities force the earlier offer of \(q\) to equal the selected offer of \(p\). The fixed tie-breaking order must therefore prefer \(p\) to \(q\).

This proves the claim. Since the terminal state determines all \(s_p\), it determines the selection order. By Section 1, it also determines the paying types of each project.

Thus, for any two initial budgets:

Their terminal states are equal if and only if their traces are equal.

This property rules out the possibility that a changed execution merely reorders projects while preserving the complete terminal state.

3. Feasibility thresholds along the original trace

Run EES at budget \(\beta\), using Section 1 to compute each offer. Let its trace select \(p_1,\ldots,p_k\), with paying-type sets \(C_1,\ldots,C_k\), where \(k\leq m\). Write

\(M_j=\sum_{t\in C_j}\mu_t,\qquad s_j=c_{p_j}/M_j.\)

For each prefix length \(i\in\{0,\ldots,k\}\), define the expenditure of type \(t\) along that prefix:

\(d_{i,t}=\sum_{\substack{1\leq j\leq i\\t\in C_j}}s_j.\)

If an execution at initial budget \(a\) follows this prefix, its remaining type budgets are exactly \(a-d_{i,t}\).

Let \(P_i=P\setminus\{p_1,\ldots,p_i\}\). Fix \(p\in P_i\). Among its approving types, let the distinct expenditure values be

\(h_1<\cdots<h_\ell.\)

Projects without approvers have no candidates. For each \(j\in\{1,\ldots,\ell\}\), define

\(C_{i,p,j}=\{t:p\in A_t,\ d_{i,t}\leq h_j\},\qquad M_{i,p,j}=\sum_{t\in C_{i,p,j}}\mu_t.\)

These are exactly the budget-block prefixes from Section 1: smaller expenditure means larger remaining budget.

The candidate coalition \(C_{i,p,j}\) is feasible precisely when

\(a-h_j\geq c_p/M_{i,p,j}.\)

Equivalently, its exact activation threshold is

\(T_{i,p,j}=h_j+c_p/M_{i,p,j}.\)

When feasible, this coalition provides the candidate offer

\(r_{i,p,j}=M_{i,p,j}/c_p.\)

Section 1 shows that the actual offer of a project is the largest offer among its feasible candidates. Thus these at most \(\tau\) candidates describe its offer completely.

4. Algorithm

Write \(p\prec q\) when project tie-breaking prefers \(p\) to \(q\).

At every nonterminal prefix \(i<k\), the original next project is \(p_{i+1}\), with offer \(b_i=M_{i+1}/c_{p_{i+1}}\).

Call a candidate \((i,p,j)\) disrupting when either

\(r_{i,p,j}>b_i,\)

or

\(r_{i,p,j}=b_i\quad\text{and}\quad p\prec p_{i+1}.\)

The first condition includes a larger paying coalition for the original next project itself.

At the terminal prefix \(i=k\), call every candidate disrupting, because any feasible candidate prevents termination.

Let

\(D=\min\{T_{i,p,j}:(i,p,j)\text{ is disrupting}\},\)

with \(D=+\infty\) if there are no disrupting candidates.

The algorithm outputs \(+\infty\) when \(D=+\infty\). Otherwise it outputs \(\delta^*=D-\beta\) and reports that this infimum belongs to the defining set.

The promised state can be checked against the simulated state, but the algorithm does not need it to reconstruct the original execution.

5. Correctness and attainment

Every disrupting threshold exceeds \(\beta\)

Suppose a disrupting candidate at a nonterminal prefix had \(T_{i,p,j}\leq\beta\). It would be feasible in the original execution and would either provide a strictly higher offer than the selected project or win an offer tie against it. Both contradict the original choice.

At the terminal prefix, a candidate with threshold at most \(\beta\) would contradict termination.

Therefore every disrupting threshold is strictly greater than \(\beta\). Since there are finitely many candidates, finite \(D\) satisfies \(D>\beta\).

The state is unchanged below \(D\)

Fix \(a\geq\beta\) with \(a<D\). We prove by induction that EES follows the original trace.

Suppose the first \(i<k\) selections agree with the original trace. Type budgets are then \(a-d_{i,t}\). The original next coalition remains feasible: it was feasible at \(\beta\), and all these budgets have increased by \(a-\beta\).

No disrupting candidate is feasible, because every such candidate has threshold at least \(D>a\). Consequently, no project can defeat the original next choice, and that project's maximum feasible paying mass cannot increase.

The paying coalition also stays the same: its mass determines the unique maximum coalition from Section 1. This establishes the induction step.

After the original \(k\) selections, every remaining candidate is disrupting and has threshold greater than \(a\). Hence EES terminates.

Thus \(S(a)=S(\beta)\) for every \(\beta\leq a<D\).

If \(D=+\infty\), the same argument applies to every finite \(a\geq\beta\).

The state changes at \(D\)

Suppose \(D<+\infty\), and choose a disrupting candidate attaining this minimum.

In fact, fix any \(a\geq D\). If \(S(a)=S(\beta)\), Section 2 forces the execution at \(a\) to follow the entire original trace.

At the prefix associated with the chosen candidate, its threshold satisfies \(T_{i,p,j}=D\leq a\), so it is feasible. If that prefix is nonterminal, the candidate defeats the original choice. If it is terminal, the candidate prevents termination. Either conclusion contradicts the alleged identical trace.

Therefore \(S(a)\ne S(\beta)\) for every \(a\geq D\).

We have proved the exact description

\(\{\delta>0:S(\beta+\delta)\ne S(\beta)\}=[D-\beta,+\infty)\)

when \(D\) is finite. This set is empty when \(D=+\infty\).

In particular, every finite infimum is positive and attained.

6. Polynomial running time and bit complexity

There are at most \(m+1\) original prefixes. At each prefix, sort all types by \(d_{i,t}\) once. For each remaining project, scan this order, accumulate approving masses, and emit a candidate after each expenditure block.

There are at most \(m\tau\) candidates per prefix and \(O(m^2\tau)\) candidates overall. Simulating the original choice, testing whether candidates are disrupting, and maintaining the minimum threshold require a constant number of rational operations per candidate. Sorting costs \(O(m\tau\log(\tau+1))\) comparisons overall.

It remains to bound operand lengths.

Let \(Q\) be the product of the input mass denominators. Its binary length is \(O(L)\). Every coalition mass is \(N/Q\) for an integer \(N\) satisfying \(1\leq N\leq Q\), because total mass is one.

For an input cost \(c_p=u_p/v_p\), every candidate or selected share has the form

\(c_p/(N/Q)=u_pQ/(v_pN),\)

whose numerator and denominator have \(O(L)\) bits.

Each expenditure \(d_{i,t}\) is a sum of at most \(m\) such shares. Using the product of their denominators as a common denominator bounds its numerator and denominator lengths by \(O(mL+\log(m+1))\). Every activation threshold adds one further share, so it has the same polynomial bound. Candidate offers, comparisons, and the final subtraction \(D-\beta\) also use polynomially many bits.

Exact rational arithmetic and comparison on these operands take polynomial time. The whole algorithm therefore runs in polynomial time in \(m,\tau,L\).

1. Maximum coalitions and uniform type budgets

The enlargement argument is valid. For a feasible coalition of mass \(x>0\), every participant belongs to \(E_x\). Its mass \(M\) therefore satisfies \(M\geq x>0\), and
\(c_p/M\leq c_p/x\).
Thus every individual in \(E_x\) can afford the enlarged coalition’s share.

Uniform budgets within each type imply that \(E_x\) contains whole types and ends at a budget block. Consequently, every feasible coalition is bounded in mass by a feasible prefix, and the finite collection of prefixes contains a maximum.

The uniqueness argument also holds. A feasible coalition of maximum mass \(M^*\) is contained, up to null sets, in \(E_{M^*}\). That enlarged set is feasible, so maximality forces its mass to equal \(M^*\). Containment and equal mass then establish equality up to null sets.

Debiting this unique coalition preserves uniform budgets within each type. The induction from the common initial budget is therefore justified. In particular, the assertion
\(H_{t,p}(a)\in\{0,\mu_t\}\)
is valid.

Projects with no approvers are correctly excluded.

2. Reconstruction of the trace from the terminal state

For every selected project, its paying mass is positive, so the share \(s_p=c_p/M_p\) is defined.

If \(p\) precedes \(q\), the eventual paying coalition for \(q\) was feasible immediately before selecting \(p\): its members’ budgets could only have been larger at that earlier time. Hence the earlier offer of \(q\) was at least \(1/s_q\), while the selected offer was \(1/s_p\). This establishes \(s_p\leq s_q\).

When the shares are equal, the inequalities force an actual offer tie at the earlier selection. The fixed project order therefore places \(p\) before \(q\).

Thus sorting the terminal projects by share and then by the fixed tie-breaking order reconstructs their execution order. The recorded paying masses determine their paying types. Conversely, identical traces produce identical selected sets and paying masses.

The claimed equivalence between terminal-state equality and trace equality is justified. This is essential to the later exclusion of state recurrence.

3. Candidate coalitions and activation thresholds

Conditional on following an original prefix, the budgets are exactly \(a-d_{i,t}\). Their order is independent of \(a\), and equal expenditures correspond exactly to equal budgets.

For the candidate ending at expenditure \(h_j\), its least remaining budget is \(a-h_j\). Its feasibility condition is therefore precisely
\(a-h_j\geq c_p/M_{i,p,j}\).
The resulting threshold
\(T_{i,p,j}=h_j+c_p/M_{i,p,j}\)
is correct, including equality at activation.

All candidate masses are positive. Section 1 justifies taking the largest feasible candidate offer as the actual project offer. No arbitrary subset enumeration is required.

4. Disrupting-candidate criterion

The criterion captures every way the next trace entry can change:

  • A strictly larger offer defeats the original choice.
  • An equal offer from an earlier project wins the fixed tie-break.
  • A strictly larger offer for the original project itself means that its maximum paying mass has increased.

Equal offers from later projects do not change the selection. For the original project, equal offer means equal paying mass; together with feasibility of the original coalition and uniqueness, this preserves its paying coalition.

At the terminal prefix, any feasible candidate prevents termination, so treating every candidate there as disrupting is correct.

5. Correctness, positivity, and attainment

Every disrupting threshold must exceed \(\beta\). Otherwise its candidate would already have contradicted either the original project choice or original termination. Finiteness of the candidate collection then makes a finite minimum \(D\) strictly larger than \(\beta\).

The induction for \(\beta\leq a<D\) is sound. Once the prefix agrees, the original next coalition remains feasible because all remaining budgets have increased by the same amount. No disrupting candidate is feasible. The original project consequently remains selected with the same maximum paying mass and, by uniqueness, the same paying coalition.

At the terminal prefix, no candidate is feasible, so the execution terminates with the original state. The same reasoning applies to every finite \(a\geq\beta\) when \(D=+\infty\).

For \(a\geq D\), assuming terminal-state equality forces the entire original trace by Section 2. A candidate attaining \(D\) is then feasible at its associated prefix and contradicts that trace. This argument validly rules out a later return to the original state.

Therefore the displayed characterization
\(\{\delta>0:S(\beta+\delta)\ne S(\beta)\}=[D-\beta,+\infty)\)
is correct for finite \(D\). Its left endpoint is positive and attained. The empty-set case is also handled correctly.

There are at most \(m+1\) prefixes and at most \(m\tau\) candidates per prefix. Sorting once per prefix and scanning the sorted types for each remaining project supports the claimed
\(O(m^2\tau+m\tau\log(\tau+1))\)
arithmetic-operation and comparison bound.

The bit-length argument is valid:

  • The product \(Q\) of input mass denominators has \(O(L)\) bits.
  • Every positive coalition mass can be represented as \(N/Q\), with \(1\leq N\leq Q\).
  • Every share \(u_pQ/(v_pN)\) has numerator and denominator of \(O(L)\) bits.
  • Summing at most \(m\) such shares gives polynomially bounded expenditure representations.
  • Thresholds, offers, comparisons, and the final subtraction retain polynomial operand lengths.

Thus the arithmetic-operation bound translates into polynomial binary running time.

The promised state need not be used: independently simulating the specified deterministic process at \(\beta\) correctly reconstructs it.
