The continuous mirror question, as graded

Given \(m=2^a\), a finite type set \(\Theta\) with masses \(\mu_\theta\), valuation densities \(v_{\theta j}\), and per-capita capacities \(\kappa_j(x)\), compute a finite mass allocation \(\{(w_{\theta r},B^{\theta r})\}\) such that \(\sum_r w_{\theta r}=\mu_\theta\), every \(B^{\theta r}\) is contiguous and non-overlapping across layers, \(\sum_{\theta,r}w_{\theta r}\mathbf 1[x\in B^{\theta r}_j]=\kappa_j(x)\) almost everywhere, and \(V_\theta(B^{\theta r})\ge p_\theta=\sum_j\int_0^1\kappa_j(x)v_{\theta j}(x)\,dx\) for every supported bundle.

Packaged proof task (what the prover saw — nothing else)

Let \(m=2^a\), with \(a\in\mathbb Z_{\ge0}\), and let each layer be \([0,1]\).
A society is given by its support: the list of \(\tau\) types with positive masses \(\mu_\theta\), each a binary rational, with \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
The densities \(v_{\theta j}\) and per-capita capacities \(\kappa_j\) are explicitly given nonnegative piecewise-constant functions with binary-rational breakpoints and values; require \(\sum_j\int_0^1v_{\theta j}(x)\,dx=1\) and \(\sum_j\kappa_j(x)\le1\) almost everywhere. Let \(L\) be the total input bit length.
A bundle \(B=(B_j)_{j=1}^m\) contains one interval, possibly empty, in each layer; intervals in different layers must have disjoint interiors. Define \(V_\theta(B)=\sum_j\int_{B_j}v_{\theta j}(x)\,dx\) and \(p_\theta=\sum_j\int_0^1\kappa_j(x)v_{\theta j}(x)\,dx\).
A finite mass allocation consists of finitely many bundles \(B^{\theta r}\) with positive weights \(w_{\theta r}\), satisfying \(\sum_r w_{\theta r}=\mu_\theta\), \(\sum_{\theta,r}w_{\theta r}\mathbf1[x\in B^{\theta r}_j]=\kappa_j(x)\) almost everywhere for every layer, and \(V_\theta(B^{\theta r})\ge p_\theta\) for every supported bundle. Weights and interval endpoints must be binary rationals; endpoint conventions are immaterial.

Can such an allocation be computed, or nonexistence decided, in time polynomial in \(m,\tau,L\), or is deciding existence \(\mathrm{NP}\)-hard?

For finitely many agents, a complete proportional allocation with contiguous, non-overlapping bundles exists whenever \(n\ge m=2^a\). [Hosseini–Igarashi–Searns](https://www.ijcai.org/proceedings/2020/0026.pdf)
Later work establishes finite-agent existence for every \(n\ge m\); it does not settle the prescribed-capacity mass problem above. [Igarashi–Meunier](https://arxiv.org/pdf/2106.02262)

Modeling choices made when packaging the task

  • Normalized total population mass to one, making capacities per capita.
  • Used full unit-interval layers, as specified by the graded question's integration domain.
  • Carried over nonnegative additive valuations and normalization to total value one for each type.
  • Allowed a = 0, following the source's convention that nonnegative integers include zero.
  • Required nonnegative capacities whose pointwise sum is at most one, the mass counterpart of the restriction that an individual can use at most one layer at a time.
  • Chose explicitly encoded rational piecewise-constant densities and capacities because arbitrary integrable functions provide no finite bit-complexity input model.
  • Required rational output weights and endpoints to specify an exact finite computational output.
  • Allowed empty layer intervals and treated non-overlap and completeness modulo endpoints, consistent with the intended nonatomic cake model.
  • Included a nonexistence outcome because the graded question's prescribed capacity profiles have no supplied existence guarantee.

Result

Deciding existence is \(\mathrm{NP}\)-hard, even when \(\tau=1\), all numerical data are dyadic rationals, and each capacity takes only the values \(0\) and \(1/2\).

We prove this by a polynomial-time reduction from PARTITION. Consequently, an algorithm that computes an allocation or decides nonexistence in time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. Source problem and construction

PARTITION asks whether given positive integers \(b_1,\ldots,b_k\), encoded in binary, admit a subset \(T\subseteq\{1,\ldots,k\}\) satisfying

\(\displaystyle \sum_{j\in T}b_j=\frac12\sum_{j=1}^k b_j.\)

This problem is \(\mathrm{NP}\)-complete; see the [MIT lecture notes on NP-completeness](https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/f2829e57caade7e7f21d765b8e7b9058_MIT6_046JS15_lec16.pdf).

Let \(m\) be the smallest power of two at least \(k\), and pad the list by setting \(b_j=0\) for \(k<j\le m\). Define

\(\displaystyle S=\sum_{j=1}^m b_j,\qquad Q=2^{\lceil\log_2 S\rceil},\qquad \ell=\frac1{4m}.\)

There is one supported type, with mass \(\mu=1\); we suppress its type index.

For each layer \(j\), define two windows of length \(\ell\):

\(\displaystyle A_j=[(4j-4)\ell,(4j-3)\ell],\qquad C_j=[(4j-2)\ell,(4j-1)\ell].\)

All these windows have pairwise disjoint interiors. Within each layer, the two windows are separated by a gap of length \(\ell\).

Set

\(\displaystyle \kappa_j(x)=\frac12\mathbf1_{A_j\cup C_j}(x).\)

To normalize the valuation, let \(R=[\ell,2\ell]\), which is the gap between \(A_1\) and \(C_1\), and set

\(\displaystyle v_j(x)=\frac{b_j}{Q\ell}\mathbf1_{A_j}(x)+\mathbf1_{\{j=1\}}\frac{Q-S}{Q\ell}\mathbf1_R(x).\)

Endpoint conventions do not affect any integral.

Verification of the input conditions

All densities are nonnegative because \(Q\ge S\). Their total integral is

\(\displaystyle \sum_{j=1}^m\int_0^1v_j(x)\,dx=\frac{S}{Q}+\frac{Q-S}{Q}=1.\)

Since the capacity windows have pairwise disjoint interiors,

\(\displaystyle \sum_{j=1}^m\kappa_j(x)\le\frac12\le1\)

almost everywhere.

The normalization density on \(R\) encounters zero capacity in layer \(1\). Thus the required value of every supported bundle is

\(\displaystyle p=\sum_{j=1}^m\int_0^1\kappa_j(x)v_j(x)\,dx=\frac{S}{2Q}.\)

Every breakpoint and density value is dyadic: both \(4m\) and \(Q\) are powers of two. Each function has only a constant number of pieces. Also \(m<2k\), and \(\log_2 Q\) is bounded by the binary encoding length of the source instance. Therefore the construction has polynomial bit length and is computable in polynomial time.

2. Exact capacities force whole-window choices

Suppose a finite allocation exists. Write its bundles as \(B^r\), with positive weights \(w_r\) satisfying \(\sum_r w_r=1\). Let \(\lambda\) denote Lebesgue measure.

Fix a layer \(j\). Integrating the capacity equation outside its two windows gives

\(\displaystyle 0=\int_{[0,1]\setminus(A_j\cup C_j)}\kappa_j(x)\,dx=\sum_r w_r\,\lambda\bigl(B_j^r\setminus(A_j\cup C_j)\bigr).\)

Every term is nonnegative, and every weight is positive. Hence

\(\displaystyle \lambda\bigl(B_j^r\setminus(A_j\cup C_j)\bigr)=0\)

for every \(r\).

An interval having positive-length intersection with both windows would contain their intervening gap. Therefore each interval \(B_j^r\) lies, up to a null set, in at most one window. In particular,

\(\displaystyle \lambda(B_j^r)\le\ell.\)

Integrating the capacity equation over the entire layer yields

\(\displaystyle \sum_r w_r\lambda(B_j^r)=\int_0^1\kappa_j(x)\,dx=\ell.\)

Because the weights sum to one and every interval has length at most \(\ell\),

\(\displaystyle \sum_r w_r\bigl(\ell-\lambda(B_j^r)\bigr)=0.\)

Positivity again forces \(\lambda(B_j^r)=\ell\) for every \(r\). Consequently, every supported bundle takes exactly one whole window, \(A_j\) or \(C_j\), in each layer, up to endpoint conventions.

In particular, no supported bundle obtains positive value from the normalization region \(R\).

3. An allocation implies a partition

For each supported bundle, define

\(\displaystyle T_r=\{j:B_j^r=A_j\text{ up to a null set}\}.\)

Its value is therefore

\(\displaystyle V(B^r)=\frac1Q\sum_{j\in T_r}b_j.\)

The capacity equations also determine the weighted average value. Using the finite sum and integrating them against the densities gives

\(\displaystyle \sum_r w_rV(B^r)=\sum_j\int_0^1v_j(x)\sum_r w_r\mathbf1[x\in B_j^r]\,dx=\sum_j\int_0^1v_j(x)\kappa_j(x)\,dx=p.\)

Fairness requires \(V(B^r)\ge p\) for every \(r\). Hence

\(\displaystyle \sum_r w_r\bigl(V(B^r)-p\bigr)=0\)

is a sum of nonnegative terms with positive weights. It follows that every supported bundle has value exactly \(p\). Thus

\(\displaystyle \sum_{j\in T_r}b_j=Qp=\frac S2.\)

Removing the padded zero entries gives a solution of the original PARTITION instance.

This proves that a NO-instance of PARTITION cannot admit an allocation.

4. A partition gives an explicit allocation

Conversely, suppose \(T\subseteq\{1,\ldots,k\}\) satisfies \(\sum_{j\in T}b_j=S/2\).

Construct two bundles:

  • \(B_j^1=A_j\) for \(j\in T\), and \(B_j^1=C_j\) otherwise.
  • \(B_j^2=C_j\) for \(j\in T\), and \(B_j^2=A_j\) otherwise.

Assign each bundle weight \(1/2\).

All chosen windows across different layers have disjoint interiors, so both bundles satisfy the non-overlap condition. In every layer, exactly one bundle takes \(A_j\) and the other takes \(C_j\). Their weighted indicators therefore equal \(\kappa_j\) almost everywhere.

Their values are

\(\displaystyle V(B^1)=\frac1Q\sum_{j\in T}b_j=\frac S{2Q}=p,\)

and

\(\displaystyle V(B^2)=\frac1Q\sum_{j\notin T}b_j=\frac S{2Q}=p.\)

The weights are positive dyadic rationals summing to the type mass \(1\), and all endpoints are dyadic. Thus this is a valid finite mass allocation.

5. Conclusion and relation to finite-agent existence

We have proved the exact equivalence

\(\displaystyle \text{the PARTITION instance is YES}\quad\Longleftrightarrow\quad\text{the constructed society admits an allocation}.\)

Together with the polynomial encoding bound, this establishes \(\mathrm{NP}\)-hardness under all the stated restrictions.

The cited finite-agent existence results do not contradict this reduction: their guarantees concern proportional divisions without prescribing the spatial capacity functions used here. See [Hosseini–Igarashi–Searns](https://www.ijcai.org/proceedings/2020/0026.pdf) and [Igarashi–Meunier](https://arxiv.org/pdf/2106.02262). In this construction, exact capacities force discrete window choices, and proportionality then forces an exact partition.
