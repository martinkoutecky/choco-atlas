The anchor (named result in the paper)

Theorem 7 — class: hardness

The continuous mirror question, as graded

Given a finite candidate set \(A\), committee size \(k\), finite voter-type set \(\mathcal T\), and rational distribution \(\mu\) over \(\mathcal T\), compute an integral committee \(W\in\binom{A}{k}\) with no integral committee \(U\in\binom{A}{k}\) such that \(U\succeq_t^{\mathcal B}W\) for every \(t\) with \(\mu_t>0\) and \(U\succ_t^{\mathcal B}W\) for some such \(t\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\geq 1\) candidates and let \(1\leq k\leq m\) be an input integer. Each voter type \(t\) specifies a weak order on \(A\), represented by ordered, nonempty indifference classes \(E_t^1,\ldots,E_t^{r_t}\), best first, partitioning \(A\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
For a nonempty integral committee \(W\), define \(b_t(W)=\min\{j:W\cap E_t^j\neq\varnothing\}\). The best extension satisfies \(U\succeq_t^{\mathcal B}W\) iff \(b_t(U)\leq b_t(W)\), and \(U\succ_t^{\mathcal B}W\) iff \(b_t(U)<b_t(W)\).
Compute \(W\subseteq A\) with \(|W|=k\) for which no integral \(U\subseteq A\), \(|U|=k\), satisfies \(b_t(U)\leq b_t(W)\) for every supported type and strict inequality for at least one supported type.

Is this computation problem solvable in polynomial time in \(m,\tau,L,k\), or is it NP-hard?

For finite electorates, computing a committee Pareto optimal under the best extension is NP-hard even with dichotomous preferences (exactly two nonempty indifference classes per voter). With strict preferences, polynomial-time computation is known.

Modeling choices made when packaging the task

  • Specified voter types as weak orders represented by ordered nonempty indifference classes, following the discrete domain.
  • Required positive supported masses summing to one, interpreting the given distribution as a probability distribution.
  • Required an input integer committee size between one and the number of candidates, excluding empty committees for which the best extension is undefined.
  • Defined L as the total input bit length.

Result

The computation problem is \(\mathrm{NP}\)-hard, even when every supported type has exactly two nonempty indifference classes and its top class contains exactly two candidates. This holds with positive dyadic masses of polynomial encoding length.

The finite-electorate result is Theorem 8 of [Aziz, Lang, and Monnot, *Computing Pareto Optimal Committees*](https://www.ijcai.org/Proceedings/16/Papers/016.pdf). The following direct reduction verifies hardness for the support representation in the question.

A property of dichotomous preferences

For each supported type \(t\), write its two classes as \(E_t^1\) and \(E_t^2=A\setminus E_t^1\). A nonempty committee \(W\) has \(b_t(W)=1\) if it intersects \(E_t^1\), and \(b_t(W)=2\) otherwise.

Lemma. If some size-\(k\) committee intersects every supported type’s top class, then every Pareto-optimal size-\(k\) committee intersects every supported type’s top class.

Proof. Let \(U\) be a size-\(k\) committee intersecting every top class. Then \(b_t(U)=1\) for every supported type \(t\).

Suppose a size-\(k\) committee \(W\) misses the top class of some supported type \(s\). For every supported type \(t\), we have \(b_t(U)=1\leq b_t(W)\), while \(b_s(U)=1<2=b_s(W)\). Thus \(U\) Pareto dominates \(W\), so \(W\) is not Pareto optimal. Conversely, a committee intersecting every top class is Pareto optimal, since no rank can be strictly smaller than \(1\). This proves the lemma. \(\square\)

Reduction from Vertex Cover

We use the standard \(\mathrm{NP}\)-complete Vertex Cover problem: given a finite simple graph \(G=(V,E)\) and an integer \(k\), decide whether some \(C\subseteq V\), with \(|C|\leq k\), intersects every edge.

It suffices to consider instances with \(E\neq\varnothing\) and \(1\leq k\leq |V|\). The excluded cases can be decided immediately, so a polynomial-time algorithm on this restricted family would solve general Vertex Cover.

Let \(n=|V|\) and \(s=|E|\). Construct the society as follows.

  • Candidates. Let \(A=V\cup\{d\}\), where \(d\) is a new candidate. Thus \(m=n+1\). Keep the committee size equal to \(k\).
  • Supported types. For every edge \(e=\{u,v\}\in E\), introduce one type with classes \(E_e^1=\{u,v\}\) and \(E_e^2=A\setminus\{u,v\}\).

Both classes are nonempty: the first contains the two endpoints, and the second contains \(d\). Because the graph is simple, distinct edges give distinct types. Hence \(\tau=s\).

  • Masses. Enumerate the edges as \(e_1,\ldots,e_s\), and put \(q=\lceil\log_2 s\rceil\). Assign \(\mu_{e_i}=2^{-q}\) for \(1\leq i<s\), and assign \(\mu_{e_s}=(2^q-s+1)/2^q\).

Since \(2^q\geq s\), all masses are positive. Their sum is \((s-1+2^q-s+1)/2^q=1\). Each is a dyadic rational requiring \(O(\log(s+1))\) bits.

The constructed instance is valid because \(1\leq k\leq n<m\). Explicitly listing all classes and masses takes \(O(s(n+1)\log(n+2)+s\log(s+1))\) bits, so the construction is polynomial in the graph’s input length.

Correctness for every possible output

We first prove the equivalence:

\(G\) has a vertex cover of size at most \(k\) if and only if a size-\(k\) committee intersects every supported type’s top class.

Forward direction. Let \(C\subseteq V\) be a vertex cover with \(|C|\leq k\). Since \(k\leq n\), extend \(C\) to a set \(U\subseteq V\) of exactly \(k\) vertices. Adding vertices preserves coverage. Thus \(U\cap E_e^1=U\cap e\neq\varnothing\) for every edge \(e\).

Reverse direction. Let \(W\subseteq A\) have size \(k\) and intersect every top class. Put \(C=W\cap V\). Then \(|C|\leq k\). Every edge has both endpoints in \(V\), so \(C\cap e=W\cap e\neq\varnothing\) for every \(e\in E\). Therefore \(C\) is a vertex cover.

Now suppose we have an algorithm returning any Pareto-optimal size-\(k\) committee. Run it once on the constructed society, obtaining \(W\), and accept the Vertex Cover instance exactly when \(W\cap e\neq\varnothing\) for every edge \(e\).

  • If the graph has a vertex cover of size at most \(k\), the forward direction provides a committee intersecting every top class. The lemma forces every Pareto-optimal output \(W\) to intersect every top class, so the test accepts.
  • If the graph has no such vertex cover, the reverse direction shows that no size-\(k\) committee can intersect every top class. Therefore the test rejects, regardless of the algorithm’s output.

The final test takes polynomial time. Consequently, a polynomial-time algorithm in \(m,\tau,L,k\) would decide Vertex Cover in polynomial time.

Conclusion

The problem is \(\mathrm{NP}\)-hard under a polynomial-time reduction using one call to the committee-computation algorithm. Therefore it has no polynomial-time algorithm in the stated input parameters unless \(\mathrm{P}=\mathrm{NP}\).

The masses affect this proof only through positivity: the dominance condition depends on which types are supported, not on their mass magnitudes. The reduction uses explicitly listed, distinct types and requires no expansion into individual voters.
