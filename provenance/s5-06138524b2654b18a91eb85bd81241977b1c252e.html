The continuous mirror question, as graded

Given finite student and laboratory types with rational masses, student capacities one, laboratory capacities \(q_\ell\), strict student rankings, weak laboratory rankings with ties, and preference-consistent weights \(w_\ell(s)\), find a mass assignment \(x_{s\ell}\ge 0\) satisfying \(\sum_\ell x_{s\ell}=\mu_s\) and \(\sum_s x_{s\ell}=q_\ell\nu_\ell\), stable in the sense that for every pair \((s,\ell)\), either \(D_{s\ell}(x)=0\) or \(E_{\ell s}(x)=0\), that minimizes \(\max_\ell U_\ell(x)-\min_\ell U_\ell(x)\), where \(U_\ell(x)=\sum_s w_\ell(s)x_{s\ell}/(q_\ell\nu_\ell)\), \(D_{s\ell}(x)=\sum_{\ell':\,\ell\succ_s\ell'}x_{s\ell'}\), and \(E_{\ell s}(x)=\sum_{s':\,s\succ_\ell s'}x_{s'\ell}\).

Packaged proof task (what the prover saw — nothing else)

Let \(S\) and \(\mathcal L\) be nonempty finite sets of student and laboratory types, with \(m=|\mathcal L|\). A society is given by its support: the list of its \(\tau=|S|+|\mathcal L|\) types with positive masses \(\mu_s,\nu_\ell\), each a binary rational; \(\tau\) counts listed types, not possible types.
Normalize \(\sum_s\mu_s+\sum_\ell\nu_\ell=1\), and require \(\sum_s\mu_s=\sum_\ell q_\ell\nu_\ell\). Students have capacity one; laboratory capacities \(q_\ell\) are positive binary integers. All student–laboratory pairs are acceptable.
Each student strictly ranks all laboratory types; each laboratory weakly ranks all student types. Write \(\succ\) for strict preference, retaining ties without breaking them. Explicit binary rational weights \(w_\ell(s)\), of either sign, satisfy \(s\succ_\ell t\Rightarrow w_\ell(s)\geq w_\ell(t)\); tied types need not have equal weights.
A mass assignment consists of real entries \(x_{s\ell}\geq0\) with \(\sum_\ell x_{s\ell}=\mu_s\) and \(\sum_s x_{s\ell}=q_\ell\nu_\ell\).
Define \(D_{s\ell}(x)=\sum_{\ell':\,\ell\succ_s\ell'}x_{s\ell'}\) and \(E_{\ell s}(x)=\sum_{s':\,s\succ_\ell s'}x_{s'\ell}\). The assignment is stable exactly when, for every \((s,\ell)\in S\times\mathcal L\), either \(D_{s\ell}(x)=0\) or \(E_{\ell s}(x)=0\).
Set \(U_\ell(x)=\frac{\sum_s w_\ell(s)x_{s\ell}}{q_\ell\nu_\ell}\) and \(G(x)=\max_\ell U_\ell(x)-\min_\ell U_\ell(x)\). Given a binary rational threshold \(g\geq0\), the decision problem asks whether a stable assignment with \(G(x)\leq g\) exists. Let \(L\) be the total input bit length, including capacities, weights, rankings, masses, and threshold.

Is this continuous minimum utility gap decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and \(L\).

The discrete difference objective is NP-hard even with student capacities one, ties only at laboratories, complete acceptability, and average utilities compared across all laboratories; with strict preferences, the discrete objective is polynomial-time solvable. For unit-capacity fractional marriage markets, maximizing welfare under ordinal stability is polynomial-time solvable with strict preferences; this concerns a different objective. Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when every laboratory has capacity \(1\), all types have the same positive dyadic mass, every weight belongs to \(\{0,1\}\), weights are equal within laboratory ties, and \(g=0\).

Writing \(n=|S|=\tau-m\), an exact algorithm runs in

\(\displaystyle n^m\operatorname{poly}(m\tau,L).\)

Thus the problem is polynomial-time solvable for every fixed \(m\), but a polynomial-time algorithm for unrestricted \(m\) would imply \(\mathrm P=\mathrm{NP}\).

A support lemma for equal masses

Lemma. Suppose there are \(N\) student types and \(N\) laboratory types, every capacity is \(1\), and every type has mass \(\delta>0\). If \(x\) is stable, then the graph of its positive entries contains a perfect matching. Moreover, every perfect matching in that graph is weakly stable under the given preferences.

Proof. Let \(H\) have an edge \((s,\ell)\) exactly when \(x_{s\ell}>0\). For a subset \(A\) of student types, let \(N_H(A)\) denote its laboratory neighbors. The marginal equations give

\(\displaystyle \delta|A| =\sum_{s\in A}\sum_{\ell\in N_H(A)}x_{s\ell} \leq\sum_{\ell\in N_H(A)}\sum_s x_{s\ell} =\delta|N_H(A)|. \)

Because \(\delta>0\), Hall’s condition holds. Hall’s marriage theorem therefore supplies a perfect matching in \(H\).

Now let \(M\) be any perfect matching in \(H\). Suppose that \((s,\ell)\) blocks \(M\). Writing \(t=M^{-1}(\ell)\), blocking means

\(\displaystyle \ell\succ_s M(s)\qquad\text{and}\qquad s\succ_\ell t.\)

Both matching edges belong to \(H\), so

\(\displaystyle D_{s\ell}(x)\geq x_{s,M(s)}>0, \qquad E_{\ell s}(x)\geq x_{t,\ell}>0. \)

This contradicts the stated stability condition. Hence \(M\) is weakly stable. \(\square\)

This lemma does not assert that every fractional stable assignment is integral. It asserts that an integral stable matching can be selected from its positive support.

Hardness reduction

The source problem

We use the following known \(\mathrm{NP}\)-complete problem: given equally sized sides of a stable marriage instance with incomplete, mutually acceptable preference lists, strict preferences on one side, and ties permitted only on the other, determine whether a perfect weakly stable matching exists.

The reduction proving Lemma 2.1 of Manlove, Irving, Iwama, Miyazaki, and Morita’s *Hard Variants of Stable Marriage* establishes this perfect-matching version: its target cardinality equals the number of participants on either side, and the first side’s lists are strict. [Source, Lemma 2.1 and its proof](https://www.dcs.gla.ac.uk/~davidm/pubs/TR-1999-43.pdf).

Let the source instance have student set \(S_0\), laboratory set \(\mathcal L_0\), and mutually acceptable edge set \(A_0\), with

\(\displaystyle |S_0|=|\mathcal L_0|=n_0.\)

A source matching is weakly stable if no acceptable pair strictly prefers each other to their respective partners, with an unmatched participant preferring any acceptable partner to remaining unmatched.

Construction

Let \(N\) be the smallest power of two satisfying \(N\geq n_0+1\), and put \(d=N-n_0\). Add \(d\) student types \(a_1,\ldots,a_d\) and \(d\) laboratory types \(b_1,\ldots,b_d\).

Every laboratory has capacity \(1\). Every student and laboratory type has mass

\(\displaystyle \delta=\frac{1}{2N}.\)

These masses are positive dyadic rationals. There are \(N\) types on each side, so

\(\displaystyle \sum_s\mu_s+\sum_\ell\nu_\ell=2N\delta=1, \qquad \sum_s\mu_s=N\delta=\sum_\ell q_\ell\nu_\ell. \)

Make all student–laboratory pairs acceptable in the constructed market. Specify preferences as follows.

  • Each original student retains its original strict list, followed by all previously unlisted laboratories, including the added laboratories, in any strict order.
  • Each original laboratory retains its original weak list, followed by a single bottom tie containing all previously unlisted students, including the added students.
  • Each \(a_j\) ranks \(b_j\) first and all other laboratories afterward in a strict order.
  • Each \(b_j\) ranks \(a_j\) first and all other students afterward in a strict order.

For an original laboratory \(\ell\), set \(w_\ell(s)=1\) when \((s,\ell)\in A_0\), and set \(w_\ell(s)=0\) otherwise. For every added laboratory \(b_j\), set \(w_{b_j}(s)=1\) for every student type \(s\). Set \(g=0\).

These weights satisfy the required monotonicity. At an original laboratory, every weight-\(1\) student precedes every weight-\(0\) student; weights are constant within each original tie and within the appended tie. At an added laboratory, all weights are equal.

Added pairs are forced

In any stable assignment, consider \((a_j,b_j)\). Because they rank each other first,

\(\displaystyle D_{a_jb_j}(x)=\delta-x_{a_jb_j}, \qquad E_{b_ja_j}(x)=\delta-x_{a_jb_j}. \)

The marginal equations imply \(x_{a_jb_j}\leq\delta\). Stability requires at least one of these identical nonnegative quantities to vanish. Consequently,

\(\displaystyle x_{a_jb_j}=\delta.\)

The row and column equations then force every other entry in that row or column to be zero.

Forward implication

Suppose the source instance has a perfect weakly stable matching \(M_0\). Assign mass \(\delta\) to each edge of \(M_0\) and to every added pair \((a_j,b_j)\), and assign zero elsewhere.

The marginal equations hold. To verify stability, consider all possible pairs.

  • For an originally acceptable pair, both \(D_{s\ell}(x)\) and \(E_{\ell s}(x)\) would be positive exactly when that pair blocks \(M_0\). This cannot occur.
  • For an original student and any laboratory outside that student’s original acceptable list, the assigned partner precedes that laboratory. Hence \(D_{s\ell}(x)=0\).
  • Every added student receives its first choice, so its \(D_{s\ell}(x)\) is zero for every laboratory.

These cases exhaust all pairs. The assignment is stable.

Each original laboratory receives only weight-\(1\) mass, and every added laboratory also has utility \(1\). Therefore \(G(x)=0\).

Reverse implication

Suppose the constructed instance has a stable assignment with \(G(x)\leq0\). Since \(G(x)\) is nonnegative, all laboratory utilities are equal. Every added laboratory has utility \(1\), so every original laboratory also has utility \(1\).

For an original laboratory \(\ell\),

\(\displaystyle 1=U_\ell(x) =\frac{\sum_{s:(s,\ell)\in A_0}x_{s\ell}}{\delta}. \)

Its total assigned mass is \(\delta\). Nonnegativity therefore implies

\(\displaystyle x_{s\ell}=0\quad\text{for every }(s,\ell)\notin A_0.\)

The forced added pairs also exclude all assignments between original and added types.

Apply the support lemma to the complete constructed market. It yields a perfect weakly stable matching using only positive entries of \(x\). This matching contains every \((a_j,b_j)\), and all its remaining edges belong to \(A_0\).

Delete the added pairs. The resulting matching is perfect in the source instance. Any source blocking pair would also block the constructed matching, because preferences between original acceptable partners were preserved. Thus the source matching is weakly stable.

We have proved the equivalence

\(\displaystyle \text{the source instance has a perfect weakly stable matching} \quad\Longleftrightarrow\quad \text{the constructed instance has stable }x\text{ with }G(x)=0. \)

Size of the reduction

Here \(m=N<2(n_0+1)\) and \(\tau=2m\). Complete preference lists, binary weights, unit capacities, and dyadic masses have total encoding length \(L=O(m^2\log m)\) under an explicit-list encoding. The construction takes polynomial time in the source input length.

This proves \(\mathrm{NP}\)-hardness under all the restrictions stated above.

Membership in \(\mathrm{NP}\) and an exact algorithm

The argument below applies to the general masses, capacities, weights, and threshold in the question.

For each laboratory \(\ell\), number its indifference classes from best to worst, and write \(r_\ell(s)\) for the class containing \(s\). Let \(k_\ell\) be the number of classes, so \(k_\ell\leq n\).

Choose one cutoff \(c_\ell\in\{1,\ldots,k_\ell\}\) per laboratory. For the cutoff vector \(c\), impose the marginal equations and nonnegativity, together with

\(\displaystyle x_{s\ell}=0\quad\text{if }r_\ell(s)>c_\ell, \)

and

\(\displaystyle D_{s\ell}(x)=0\quad\text{if }r_\ell(s)<c_\ell. \)

Claim. The stable assignments are exactly the union of these linear feasible sets over all cutoff vectors.

Proof. First suppose an assignment satisfies the constraints for \(c\). For any pair \((s,\ell)\):

  • If \(r_\ell(s)<c_\ell\), the constraints give \(D_{s\ell}(x)=0\).
  • If \(r_\ell(s)\geq c_\ell\), every positively assigned student at \(\ell\) has class at most \(c_\ell\), and therefore is not strictly worse than \(s\). Hence \(E_{\ell s}(x)=0\).

Thus the assignment is stable.

Conversely, let \(x\) be stable. Since \(q_\ell\nu_\ell>0\), laboratory \(\ell\) has a positively assigned student. Define

\(\displaystyle c_\ell=\max\{r_\ell(s):x_{s\ell}>0\}.\)

No assigned student is below this cutoff. If \(r_\ell(s)<c_\ell\), some positive mass at class \(c_\ell\) is strictly worse than \(s\), so \(E_{\ell s}(x)>0\). Stability forces \(D_{s\ell}(x)=0\). Hence all cutoff constraints hold. \(\square\)

For fixed \(c\), the utility-gap condition is also linear. Put \(b_\ell=q_\ell\nu_\ell>0\), introduce a real variable \(h\), and require

\(\displaystyle b_\ell h \leq \sum_s w_\ell(s)x_{s\ell} \leq b_\ell(h+g) \qquad\text{for every }\ell. \)

These inequalities are equivalent to \(G(x)\leq g\): they place every utility in the common interval from \(h\) to \(h+g\); conversely, take \(h=\min_\ell U_\ell(x)\).

Each cutoff choice therefore gives a rational linear feasibility problem with polynomial encoding length. Products \(q_\ell\nu_\ell\) have polynomial bit length; capacities are never expanded into individual seats.

A certificate consists only of the \(m\) cutoff labels, using \(O(m\log(n+1))\) bits. A verifier constructs the corresponding linear program and checks feasibility in \(\operatorname{poly}(m\tau,L)\) bit time. This proves membership in \(\mathrm{NP}\), despite assignments being permitted to have arbitrary real entries.

Finally, there are at most

\(\displaystyle \prod_{\ell\in\mathcal L}k_\ell\leq n^m\)

cutoff choices. Enumerating them gives the stated exact running time

\(\displaystyle (\tau-m)^m\operatorname{poly}(m\tau,L). \)

Together with the reduction, this establishes \(\mathrm{NP}\)-completeness.
