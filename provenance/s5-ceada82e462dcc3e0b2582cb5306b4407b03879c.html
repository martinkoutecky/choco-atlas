Conclusion

The fractional-split welfare guarantee holds, and the mechanism is universally truthful and exactly budget balanced. Under truthful reports, it can be computed in time polynomial in \(\tau,L\).

There is one input-size qualification: if arbitrary report profiles can have support and encoding length larger than the true society’s \(\tau,L\), computation is polynomial in the reported input’s size. A running-time bound depending only on the true society’s \(\tau,L\) cannot hold for unrestricted larger report lists.

The proof below establishes the economic extension completely, including zero prices and existence of reachable states. Its uniform-price argument is the integral counterpart of Lemma 4 in [Zheng–Cheng–Xu–Deng](https://arxiv.org/html/2410.07023v1); no sampling or concentration theorem is needed.

1. Finite-support optimization and exact scaling

Write \(\Omega_t\) for the individuals of true type \(t\), and define

\[ G=\sum_t\mu_t\Gamma_t>0,\qquad A=\sum_t\mu_tv_t\Gamma_t,\qquad H=\operatorname{OPT}(\mu). \]

For an allocation \(x\), let \(y=\Gamma+x\) denote final resource holdings. Physical feasibility and balance become

\[ y\geq0,\qquad \int_\Omega y\,d\nu=G. \]

The welfare contribution of type \(t\) is

\[ v_t\Gamma_t+\min\{v_tx,B_t\} =\min\{v_ty,v_t\Gamma_t+B_t\}. \]

We first justify replacing allocations within a type by their averages. More generally, suppose a subpopulation contains mass \(w_t>0\) of each represented type. For any feasible allocation, define

\[ \bar y_t=\frac{1}{w_t}\int_{S\cap\Omega_t}y\,d\nu. \]

Integrating each of the two upper bounds on the welfare contribution gives

\[ \int_{S\cap\Omega_t}\min\{v_ty,v_t\Gamma_t+B_t\}\,d\nu \leq w_t\min\{v_t\bar y_t,v_t\Gamma_t+B_t\}. \]

The allocation constant at \(\bar y_t\) within each type preserves balance and attains the right-hand side. Consequently, the optimum is exactly the value of the following rational linear program:

\[ \begin{aligned} \text{maximize}\quad &\sum_t w_tz_t,\\ \text{subject to}\quad &y_t\geq0,\quad z_t\geq0,\\ &z_t\leq v_ty_t,\\ &z_t\leq v_t\Gamma_t+B_t,\\ &\sum_t w_ty_t=\sum_t w_t\Gamma_t. \end{aligned} \]

The feasible set is nonempty: take \(y_t=\Gamma_t\) and \(z_t=v_t\Gamma_t\). It is bounded, since every positive weight gives

\[ y_t\leq\frac{\sum_s w_s\Gamma_s}{w_t}, \qquad z_t\leq v_t\Gamma_t+B_t. \]

Thus an optimum exists. In particular,

\[ 0\leq A\leq H\leq A+\sum_t\mu_tB_t<\infty. \]

If every weight \(w_t\) is multiplied by the same positive constant \(c\), the balance constraint has the same feasible allocations, while the objective is multiplied by \(c\). Therefore the optimum scales exactly by \(c\).

The supplied split satisfies

\[ \nu(F\cap\Omega_t)=\beta\mu_t, \qquad \nu(R\cap\Omega_t)=(1-\beta)\mu_t. \]

Under truthful reports, exact scaling therefore gives

\[ \operatorname{OPT}_v(F)=\beta H, \qquad \operatorname{OPT}_v(R)=(1-\beta)H. \]

Also,

\[ G_R:=\int_R\Gamma\,d\nu=(1-\beta)G>0. \]

Hence the truthful price is

\[ \lambda =\frac{1-\beta}{\beta}\frac{\beta H}{2(1-\beta)G} =\frac{H}{2G} =\frac{\operatorname{OPT}_v(R)}{2G_R}. \]

This is an exact identity for every permitted split.

2. Reachable states exist for every report profile

For every finite-support report profile, \(Q\) is finite and nonnegative. Indeed, its objective is bounded above by the integral of \(b\Gamma+B\), and the zero-trade allocation has nonnegative welfare. Thus the mechanism defines a finite price \(\lambda\geq0\).

We show that this price always admits a reachable state, using the true values to determine trading preferences.

If \(\lambda=0\), take \(x=0\) everywhere. Every active individual is a buyer because values are nonnegative. There are no active sellers, so the seller-exhaustion condition holds vacuously. All feasibility conditions hold.

Suppose \(\lambda>0\), and write

\[ \mathcal B=\{a\in R:v(a)\geq\lambda\}, \qquad \mathcal S=\{a\in R:v(a)<\lambda\}. \]

Define aggregate buying capacity and selling capacity by

\[ D=\int_{\mathcal B}\frac{B}{\lambda}\,d\nu, \qquad T=\int_{\mathcal S}\Gamma\,d\nu. \]

Both are finite.

If \(D\leq T\) and \(T>0\), set

\[ x(a)=\frac{B(a)}{\lambda}\quad(a\in\mathcal B), \qquad x(a)=-\frac{D}{T}\Gamma(a)\quad(a\in\mathcal S). \]

This allocation balances, satisfies all constraints, and exhausts every buyer’s budget.

If \(D>T\), then \(D>0\). Set

\[ x(a)=\frac{T}{D}\frac{B(a)}{\lambda}\quad(a\in\mathcal B), \qquad x(a)=-\Gamma(a)\quad(a\in\mathcal S). \]

This allocation balances, satisfies all constraints, and exhausts every seller’s endowment.

Finally, if \(D=T=0\), take \(x=0\) on sellers and \(x=B/\lambda\) on buyers. Both nonnegative capacity integrals vanish, so balance holds, and every buyer exhausts its budget.

In every case, set \(x=0\) on \(F\) and \(p=\lambda x\) on \(R\). These allocations are integrable. Thus the utility infimum is taken over a nonempty set for every report profile.

3. Universal truthfulness and profitability

Fix the true population, a realization of the identity-based split, and all reports except that of one individual \(a\).

If \(a\in F\), then every reachable state gives

\[ x(a)=p(a)=0. \]

Its market utility is therefore zero for every report, even if its report changes the price.

If \(a\in R\), its report does not enter \(Q=\operatorname{OPT}_b(F)\). Budgets, endowments, and membership are public and fixed, so its report changes neither the denominator defining \(\lambda\) nor its trading restrictions. Moreover, the problem defines buyer and seller status using true values, rather than reports.

Consequently, changing this individual’s report leaves the entire reachable-state set unchanged. The function being minimized,

\[ v(a)x(a)-p(a), \]

is also unchanged. Its market utility is therefore identical for every report.

Thus truthful reporting weakly maximizes every individual’s market utility for every fixed profile of others’ reports and every fixed realization of the split. This proves universal truthfulness.

For profitability, every reachable state satisfies

\[ \int_\Omega p\,d\nu =\lambda\int_Rx\,d\nu =\lambda\int_\Omega x\,d\nu =0. \]

The second equality uses the freezing of \(F\), and the third uses balance. The mechanism is exactly budget balanced for every report profile.

4. Welfare in every truthful reachable state

Assume truthful reports and first suppose \(H>0\), so \(\lambda>0\). Put

\[ C=\operatorname{OPT}_v(R)=(1-\beta)H. \]

Section 1 gives \(\lambda G_R=C/2\). Retain the buyer and seller sets from Section 2.

Every physically feasible individual contribution is nonnegative, because

\[ v\Gamma+\min\{vx,B\} =\min\{v(\Gamma+x),v\Gamma+B\}\geq0. \]

We now consider the two exhaustion conditions.

Case 1: Every active seller sells its entire endowment

For sellers, \(x=-\Gamma\), so their welfare contribution is zero.

For buyers, feasibility gives \(x\geq0\) and \(\lambda x\leq B\). Since \(v\geq\lambda\),

\[ v\Gamma\geq\lambda\Gamma, \qquad \min\{vx,B\}\geq\lambda x. \]

Therefore

\[ W_{v,R}(x) \geq \lambda\int_{\mathcal B}(\Gamma+x)\,d\nu. \]

Balance and seller exhaustion imply

\[ \int_{\mathcal B}x\,d\nu =-\int_{\mathcal S}x\,d\nu =\int_{\mathcal S}\Gamma\,d\nu. \]

It follows that

\[ W_{v,R}(x)\geq\lambda G_R=\frac{C}{2}. \]

Case 2: Every active buyer exhausts its budget

Every buyer has \(x=B/\lambda\). Since \(v\geq\lambda\), its welfare contribution equals \(v\Gamma+B\). Define

\[ K=\int_{\mathcal B}(v\Gamma+B)\,d\nu. \]

Nonnegativity of seller contributions gives \(W_{v,R}(x)\geq K\).

To compare \(K\) with the optimum, consider any feasible allocation \(z\) on \(R\), without imposing the mechanism’s trading-direction restrictions. Buyers contribute at most \(K\). On sellers, physical feasibility and \(v<\lambda\) give

\[ v\Gamma+\min\{vz,B\} \leq v(\Gamma+z) \leq\lambda(\Gamma+z). \]

All final holdings are nonnegative, and their total is \(G_R\). Therefore

\[ \int_{\mathcal S}(\Gamma+z)\,d\nu\leq G_R, \]

and hence

\[ W_{v,R}(z)\leq K+\lambda G_R. \]

Taking the supremum over feasible \(z\) yields

\[ C\leq K+\lambda G_R=K+\frac{C}{2}. \]

Thus \(K\geq C/2\), proving again that

\[ W_{v,R}(x)\geq\frac{C}{2}. \]

Combining the active and frozen populations

Every reachable state satisfies at least one exhaustion condition, so the preceding cases cover all reachable states. Frozen individuals contribute their initial welfare:

\[ W_{v,F}(0)=\beta A. \]

Consequently, the following slightly stronger bound holds:

\[ W_{v,\Omega}(x) \geq \beta A+\frac{1-\beta}{2}H \geq \frac{1-\beta}{2}\operatorname{OPT}(\mu). \]

If \(H=0\), physical feasibility makes welfare nonnegative, which directly proves the requested bound. This also handles the truthful zero-price case.

Thus the guarantee holds for every reachable state, every supplied proportional split, and every \(\beta\in(0,1/2)\). Its guaranteed coefficient tends to \(1/2\) as \(\beta\) tends to zero.

5. Polynomial implementation and the precise input-size qualification

The linear program in Section 1 has two variables per support cell and a linear number of constraints. Its coefficients are rational, its feasible region is nonempty and bounded, and its encoding length is polynomial in the support input’s bit length. Standard exact rational linear programming therefore computes its optimum in polynomial time.

Under truthful reports, the frozen support has weights \(\beta\mu_t\), whose combined encoding length is polynomial in \(L\). Thus \(Q\), \(\lambda\), and the succinct trading rules are computable in time polynomial in \(\tau,L\). Since \(m=1\), this supplies the requested dependence on \(m\) as well. Membership in \(F\) is supplied by the population model; the algorithm need not infer or construct it.

For computational report profiles, the input must encode the reported values and their masses in \(F\), together with public budgets and endowments. If this rational support input has size \(\tau'\) and bit length \(L'\), the same argument gives polynomial time in \(\tau',L'\). Finite support alone does not bound these quantities by the true society’s \(\tau,L\).

Indeed, the latter distinction cannot be removed. Fix a true society with one type,

\[ (v,B,\Gamma)=(0,1,1),\qquad \mu=1, \]

and fix \(\beta=1/4\). Its true input size is constant.

Partition \(F\) into \(k\) report cells, each of mass \(\beta/k\), with distinct rational reports satisfying

\[ 0<b_i\leq\frac{1}{2k}. \]

Let \(b_{\max}=\max_i b_i\). For every feasible allocation on \(F\),

\[ W_{b,F}(x) \leq b_{\max}\int_F(\Gamma+x)\,d\nu =\beta b_{\max}. \]

Equality is attainable: give all frozen resources to a cell reporting \(b_{\max}\). Its individuals then have final holdings \(k\), hence net purchases \(k-1\), and

\[ b_{\max}(k-1)<1=B. \]

Their welfare is therefore uncapped, and the resulting total welfare is \(\beta b_{\max}\). Thus

\[ Q=\beta b_{\max}, \qquad \lambda=\frac{b_{\max}}{2}. \]

Computing the exact price from an unsorted explicit list therefore requires finding the maximum of \(k\) reported values, requiring inspection of all \(k\) entries in the worst case. No bound polynomial only in the constant true \(\tau,L\) can cover these inputs.

Accordingly, the fractional-split economic extension succeeds completely. Its implementation is polynomial in the encoded support input; the stronger complexity assertion for arbitrarily larger report inputs, measured only against the original true society, is false.
