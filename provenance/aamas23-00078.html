The continuous mirror question, as graded

Given finite behavioural types \(T\), rational masses \(\mu_t\) with \(\sum_t\mu_t=1\), rational \(a\in(0,1)\), costs \(c_t\), and rational piecewise-linear nondecreasing benefit functions \(g_t:[0,1]\to\mathbb{Q}_{\ge 0}\), let \(T_+=\{t:\mu_t>0\}\), \(F_t(q)=g_t(q)+a\min_{s\in T_+}g_s(q)\), and \(q=\sum_t\mu_tz_t\). Decide whether there exists \(z\in[0,1]^T\), realizable by a measurable pure assignment, such that \(z_t=0\Rightarrow D^+F_t(q)\le c_t\), \(z_t=1\Rightarrow D^-F_t(q)\ge c_t\), and \(0<z_t<1\Rightarrow D^-F_t(q)\ge c_t\ge D^+F_t(q)\), where \(D^-\) and \(D^+\) are one-sided derivatives; output \(z\) if it exists.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) behavioural types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types.
Input also includes binary rational \(a\in(0,1)\), costs \(c_t\ge0\), and continuous nondecreasing piecewise-linear functions \(g_t:[0,1]\to\mathbb R_{\ge0}\), explicitly encoded by rational breakpoints and values. Let \(m\) be the total number of encoded linear pieces and \(L\) the total input bit length; state running times in \(m,\tau,L\).
Realize the society as disjoint atomless intervals \(I_t\) of lengths \(\mu_t\). A measurable pure assignment \(x:\bigsqcup_t I_t\to\{0,1\}\) realizes \(z\in[0,1]^T\) when \(\int_{I_t}x=\mu_tz_t\).
Define \(q=\sum_t\mu_tz_t\) and \(F_t(q)=g_t(q)+a\min_{s\in T}g_s(q)\); the minimum includes every supported type, irrespective of its assigned action.
Call \(z\) feasible when it is realizable and, for every \(t\), \(z_t=0\Rightarrow D^+F_t(q)\le c_t\), \(z_t=1\Rightarrow D^-F_t(q)\ge c_t\), and \(0<z_t<1\Rightarrow D^-F_t(q)\ge c_t\ge D^+F_t(q)\).
Here \(D^-\) and \(D^+\) are left and right derivatives; at \(q=0\) only the right condition applies, and at \(q=1\) only the left condition applies. Equalities are permitted.

Is deciding whether a feasible assignment exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? In the polynomial-time case, can a realizing vector \(z\) also be computed in polynomial time?

Discrete egalitarian binary networked public goods games admit an \(O(n^2)\) equilibrium-existence algorithm on clique relation graphs; on general relation graphs existence is NP-complete, even when the prosocial graph equals the relation graph. [Li et al. (2023)](https://www.ifaamas.org/Proceedings/aamas2023/pdfs/p609.pdf)
No result settling this exact continuous derivative-feasibility problem was located in the literature search.

Modeling choices made when packaging the task

  • Costs were unspecified in sign; require nonnegative binary rational costs, matching the discrete cost domain.
  • Interpret rational piecewise-linear benefits as continuous real-valued functions encoded by rational breakpoints and values; a nonconstant continuous function cannot have exclusively rational values on a real interval.
  • Specify an atomless interval realization of each supported type to define measurable pure assignments.
  • At aggregate endpoints use only the derivative available within the benefit domain; positive masses force every type to choose the corresponding endpoint action.
  • Omit zero-mass types entirely, following the required support encoding.
  • Define m as the total number of encoded linear pieces and L as total input bit length, since this model has no candidate-count parameter.

Result

The decision problem is in \(\mathrm P\). Whenever a feasible assignment exists, a rational realizing vector \(z\) can also be computed in polynomial time. Moreover, such a vector can be chosen with at most one coordinate strictly between \(0\) and \(1\).

A conservative bound for both decision and construction is

\(\displaystyle O\!\left(m^2\bigl(\tau+\log(m+1)\bigr)L^3\right)\)

bit operations. The proof directly handles the stated derivative conditions, including corners and equalities.

1. Realizability imposes no additional restriction

Every vector \(z\in[0,1]^T\) is realizable.

Indeed, write each interval as \(I_t=[d_t,d_t+\mu_t)\), ignoring endpoints of measure zero. Set \(x=1\) on \([d_t,d_t+\mu_tz_t)\) and \(x=0\) on the rest of \(I_t\). This assignment is measurable and satisfies

\(\displaystyle \int_{I_t}x=\mu_tz_t.\)

Thus it suffices to find a vector satisfying the derivative conditions and the aggregate equation \(q=\sum_t\mu_tz_t\).

2. Exact feasibility at a fixed aggregate

Fix \(q\in(0,1)\), and write

\(\displaystyle \lambda_t(q)=D^-F_t(q),\qquad \rho_t(q)=D^+F_t(q).\)

Define two statements for each type:

\(\displaystyle A_t(q):\ \lambda_t(q)\ge c_t,\qquad B_t(q):\ \rho_t(q)\le c_t.\)

The admissible values of \(z_t\) are exactly as follows.

| \(A_t(q)\) | \(B_t(q)\) | Admissible values |
|---|---|---|
| true | true | \([0,1]\) |
| true | false | \(\{1\}\) |
| false | true | \(\{0\}\) |
| false | false | \(\varnothing\) |

To verify the table, the value \(z_t=0\) requires precisely \(B_t(q)\), the value \(z_t=1\) requires precisely \(A_t(q)\), and a value strictly between them requires both statements.

If any admissible set is empty, this \(q\) is infeasible. Otherwise, partition the types into \(T_1(q)\), forced to one; \(T_0(q)\), forced to zero; and \(T_f(q)\), allowed any value in \([0,1]\). Put

\(\displaystyle \ell(q)=\sum_{t\in T_1(q)}\mu_t,\qquad u(q)=\ell(q)+\sum_{t\in T_f(q)}\mu_t.\)

Fixed-aggregate criterion. A feasible vector with aggregate \(q\) exists exactly when no admissible set is empty and

\(\displaystyle \ell(q)\le q\le u(q).\)

Necessity follows because the forced-one types contribute \(\ell(q)\), while the free types contribute between zero and their total mass.

For sufficiency, let \(r=q-\ell(q)\). Then

\(\displaystyle 0\le r\le\sum_{t\in T_f(q)}\mu_t.\)

Set the forced coordinates to their required values. Process the free types in any order, assigning

\(\displaystyle y_t=\min\{\mu_t,r\},\qquad z_t=\frac{y_t}{\mu_t},\)

and replacing \(r\) by \(r-y_t\). The total available capacity ensures that the final residual is zero. Hence the resulting aggregate is exactly \(q\), and every coordinate is admissible.

This construction has at most one fractional coordinate: every free type before the possible partially filled type is assigned one, and every type after it is assigned zero.

At the endpoints, positivity of every mass gives simpler tests:

  • Aggregate \(q=0\) forces every \(z_t=0\), so it is feasible exactly when \(D^+F_t(0)\le c_t\) for every \(t\).
  • Aggregate \(q=1\) forces every \(z_t=1\), so it is feasible exactly when \(D^-F_t(1)\ge c_t\) for every \(t\).

These tests use precisely the specified endpoint conventions.

3. A polynomial-size partition of the aggregate domain

Write

\(\displaystyle h(q)=\min_{s\in T}g_s(q),\qquad F_t(q)=g_t(q)+ah(q).\)

We construct rational points

\(\displaystyle 0=b_0<b_1<\cdots<b_N=1\)

such that every \(g_t\), and also \(h\), is affine on each open interval \((b_i,b_{i+1})\).

Begin with all encoded breakpoints and the endpoints \(0,1\). Each of the \(m\) encoded pieces has an affine expression on its domain. For every pair of pieces whose affine expressions have different slopes, compute their unique intersection coordinate. Include that coordinate if it belongs to both piece domains. Parallel or identical expressions require no additional point.

There are at most \(\binom m2\) intersection candidates and at most \(m+\tau\) encoded endpoints. Sorting and removing duplicates therefore gives \(O(m^2)\) partition points.

To prove the required property, fix an open partition interval \(J=(b_i,b_{i+1})\). Since every original breakpoint is included, each \(g_t\) has one affine expression on \(J\).

Two such expressions with different slopes cannot cross inside \(J\): their intersection would have been included in the partition. Expressions with equal slopes are either identical or have a constant strict ordering. Consequently, choose a type minimizing \(g_t\) at the midpoint of \(J\). Its affine expression remains minimal throughout \(J\). Thus \(h\) is affine on \(J\).

This reasoning includes all supported types in the minimum, independently of their eventual actions.

Let \(p_{t,i}\) denote the slope of \(g_t\) on \(J\), and let \(v_i\) denote the slope of \(h\) there. The slope of \(F_t\) on \(J\) is

\(\displaystyle d_{t,i}=p_{t,i}+av_i.\)

All these quantities are rational and computable exactly.

4. Testing every interval and every partition point

Open intervals

For \(q\in(b_i,b_{i+1})\), both one-sided derivatives equal \(d_{t,i}\). Hence the classification is constant throughout this interval:

  • \(d_{t,i}>c_t\) forces \(z_t=1\).
  • \(d_{t,i}<c_t\) forces \(z_t=0\).
  • \(d_{t,i}=c_t\) allows every \(z_t\in[0,1]\).

Let \(\ell_i,u_i\) be the corresponding bounds from Section 2. Some aggregate in this open interval is feasible exactly when

\(\displaystyle [\ell_i,u_i]\cap(b_i,b_{i+1})\ne\varnothing.\)

Because \(\ell_i\le u_i\), this is equivalent to the two strict inequalities

\(\displaystyle u_i>b_i,\qquad \ell_i<b_{i+1}.\)

When they hold, define

\(\displaystyle \alpha=\max\{\ell_i,b_i\},\qquad \beta=\min\{u_i,b_{i+1}\},\qquad q=\frac{\alpha+\beta}{2}.\)

Here \(\alpha\le\beta\), \(\beta>b_i\), and \(\alpha<b_{i+1}\). Therefore the chosen \(q\) lies in both \([\ell_i,u_i]\) and \((b_i,b_{i+1})\), including when \(\alpha=\beta\). Section 2 then constructs the vector.

Interior partition points

Every \(g_t\) is continuous, and the minimum of finitely many continuous functions is continuous. Thus every \(F_t\) is continuous.

At an interior partition point \(b_i\), continuity and affinity on the adjacent intervals give

\(\displaystyle D^-F_t(b_i)=d_{t,i-1},\qquad D^+F_t(b_i)=d_{t,i}.\)

Indeed, on either adjacent interval the affine expression extends continuously to \(b_i\), so its difference quotient at that endpoint equals its slope.

Apply the complete four-case table from Section 2 using these two derivatives. Reject this point if any type has an empty admissible set; otherwise accept precisely when

\(\displaystyle \ell(b_i)\le b_i\le u(b_i).\)

If accepted, construct the vector with \(q=b_i\).

Endpoints and completeness

At \(0\), use the slopes from the first interval and the right-derivative endpoint test. At \(1\), use the slopes from the last interval and the left-derivative endpoint test.

Every \(q\in[0,1]\) is either a partition point or belongs to one of the open partition intervals. Each test is necessary and sufficient on its respective part of the domain. Therefore the algorithm accepts exactly the instances admitting a feasible assignment.

5. Running time and output size

Constructing the affine expressions takes \(O(m)\) rational arithmetic operations. Enumerating pairwise intersections takes \(O(m^2)\), and sorting the candidates takes \(O(m^2\log(m+1))\) rational comparisons.

Scan the partition intervals from left to right, maintaining each type’s current encoded piece. These pointers advance at most \(m\) times in total. On each interval, evaluating all \(\tau\) current affine expressions at its midpoint identifies the minimum and its slope in \(O(\tau)\) arithmetic operations.

Computing the derivative slopes, testing an interval, and testing an adjacent partition point likewise each take \(O(\tau)\) operations. Only the slope vectors for the two adjacent intervals are needed. The total is consequently

\(\displaystyle O\!\left(m^2\bigl(\tau+\log(m+1)\bigr)\right)\)

exact rational operations and comparisons. Witness construction takes another \(O(\tau)\).

All rational operands can be kept to \(O(L)\) bits:

  • Piece coefficients, intersections, midpoints, values, and derivative slopes use a bounded number of arithmetic operations on input rationals.
  • Mass sums have denominators dividing the product of the encoded mass denominators, whose total bit length is at most \(L\).
  • The chosen aggregate, residuals, and divisions by positive masses also have \(O(L)\)-bit rational representations.

Using reduced fractions and elementary integer algorithms, \(O(L^3)\) bit operations per rational operation is a conservative bound. Including input reading yields the claimed bound

\(\displaystyle O\!\left(m^2\bigl(\tau+\log(m+1)\bigr)L^3\right).\)

The output vector has \(O(\tau L)\) bits. A measurable realizing assignment is then specified by the initial subinterval of length \(\mu_tz_t\) in each \(I_t\).

6. Feasibility is not automatic

The algorithm is needed even for two types. Consider

\(\displaystyle \mu_1=\mu_2=\frac12,\qquad a=\frac12,\qquad c_1=c_2=\frac32,\)

with

\(\displaystyle g_1(q)=2\min\left\{q,\frac12\right\},\qquad g_2(q)=2+2\max\left\{q-\frac12,0\right\}.\)

These functions satisfy all stated hypotheses. Since \(g_1(q)\le1<2\le g_2(q)\), their minimum is always \(g_1\).

For \(q<\frac12\), the slopes of \(F_1,F_2\) are \(3,1\). The derivative conditions force \(z_1=1,z_2=0\), giving aggregate \(\frac12\), a contradiction.

For \(q>\frac12\), the slopes are \(0,2\). They force \(z_1=0,z_2=1\), again giving aggregate \(\frac12\). These arguments also exclude the respective endpoints.

At \(q=\frac12\), type \(2\) has

\(\displaystyle D^-F_2\left(\frac12\right)=1<\frac32<2=D^+F_2\left(\frac12\right).\)

Neither action, nor a fractional coordinate, is admissible for that type. Thus this instance has no feasible assignment, demonstrating why partition points must be checked separately.

  • One is admissible exactly when \(A_t(q)\) holds.

These possibilities exhaust \([0,1]\). In particular, when both statements fail, neither a pure nor a fractional coordinate is possible.

3. The partition

The proposed partition contains every original breakpoint and every intersection of distinct-slope piece expressions within their common domains. Thus, inside an open partition interval, each type has a fixed affine expression, and distinct expressions cannot change their ordering.

Choosing a midpoint minimizer therefore identifies an expression attaining the minimum throughout that interval. Identical expressions cause no ambiguity in the minimum’s slope. Parallel distinct expressions retain a strict ordering.

This establishes that \(h\), and hence every \(F_t\), is affine on each open partition interval. The slope formula \(d_{t,i}=p_{t,i}+av_i\) is correct.

The size bound is also valid: there are at most quadratically many pairwise intersections. Every supported function requires at least one encoded piece, so \(\tau\le m\); consequently, the stated \(O(m+\tau)\) endpoint count is compatible with the overall \(O(m^2)\) partition bound.

No theorem about lower-envelope complexity is being assumed without proof.

The bit-size argument is sound under rational cost encoding.
