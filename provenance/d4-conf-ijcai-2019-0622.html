Theorem 3.1(i) — class: hardness

The continuous mirror question, as graded

Given a finite support \(T\) of equal-sized district patterns with rational masses \(\mu_t\) summing to \(1\), true and reported vote-share vectors \(q_t,\tilde q_t\in\Delta_m\), a recount budget \(\beta\), target \(a\), tie-breaking order, and reported-profile winner \(b\ne a\), decide whether there are masses \(x_t\in[0,\mu_t]\) with \(\sum_t x_t\le\beta\) such that \(S_c(x)=\sum_t((\mu_t-x_t)\tilde q_{tc}+x_tq_{tc})\) makes \(a\) the winner under that order.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) district types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
Let \(C\) be the candidate set, \(|C|=m\ge3\). Each type represents districts of the same positive size and specifies true and reported vote-share vectors \(q_t,\tilde q_t\in\mathbb Q_{\ge0}^m\), each with coordinate sum \(1\).
The input also specifies a binary-rational recount budget \(\beta\in[0,1]\), a strict linear tie-breaking order \(\succ\) on \(C\), and a target \(a\in C\). The reported-profile Plurality winner is \(b\ne a\); there is no promise that \(a\) wins the true profile.
A recount chooses real masses \(0\le x_t\le\mu_t\) with \(\sum_{t\in T}x_t\le\beta\), restoring the true shares on that mass of districts. The resulting score is \(S_c(x)=\sum_{t\in T}((\mu_t-x_t)\tilde q_{tc}+x_tq_{tc})\).
Candidate \(a\) wins precisely when \(S_a(x)>S_c(x)\) for every \(c\succ a\), and \(S_a(x)\ge S_c(x)\) for every other \(c\ne a\). Let \(L\) be the total binary input bit length; state running times in \(m,\tau,L\).

Is deciding whether such a recount makes \(a\) win solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

Discrete Plurality recounting with indivisible districts and binary vote counts is NP-complete even for \(m=3\), without an equal-district-size restriction. [Source](https://www.ijcai.org/proceedings/2019/0037.pdf)
No published result settling exactly the continuous problem defined here was identified in the search.

Modeling choices made when packaging the task

  • Specified all true and reported vote shares as nonnegative binary rationals with coordinate sum one.
  • Normalized the recount budget to a binary rational in [0,1], measured in district mass.
  • Carried over the candidate-domain condition m >= 3 and made tie-breaking a strict linear order, with strict score inequalities against candidates favored over the target.
  • Interpreted recounting as restoring entire district patterns on any real submass of a type, with cost equal to the recounted district mass.
  • Did not require the target to be the true-profile winner, since the discrete recounting decision problem permits any target different from the reported winner.

Result

The problem is solvable in polynomial time in \(m,\tau,L\). The proof uses a rational linear program with \(\tau+1\) variables. Strict tie-breaking inequalities are handled by maximizing a common positive margin.

1. Expressing score differences

For each candidate \(c\ne a\), define the reported score difference

\(r_c=\sum_{t\in T}\mu_t(\tilde q_{ta}-\tilde q_{tc})\)

and the change in that difference per unit of recounted mass

\(d_{tc}=(q_{ta}-\tilde q_{ta})-(q_{tc}-\tilde q_{tc}).\)

Expanding the given score formula yields

\(S_a(x)-S_c(x)=r_c+\sum_{t\in T}d_{tc}x_t.\)

Thus every score comparison is an affine inequality in the \(\tau\) recount variables.

Let \(H=\{c\in C\setminus\{a\}:c\succ a\}\) and \(K=C\setminus(H\cup\{a\})\). A feasible recount makes \(a\) win exactly when these differences are positive for candidates in \(H\) and nonnegative for candidates in \(K\).

2. A linear program incorporating tie-breaking

Introduce a variable \(\varepsilon\). Maximize \(\varepsilon\) subject to:

  • \(0\le x_t\le\mu_t\) for every \(t\in T\);
  • \(\sum_{t\in T}x_t\le\beta\);
  • \(0\le\varepsilon\le1\);
  • \(r_c+\sum_{t\in T}d_{tc}x_t\ge\varepsilon\) for every \(c\in H\);
  • \(r_c+\sum_{t\in T}d_{tc}x_t\ge0\) for every \(c\in K\).

All constraints are non-strict linear inequalities with rational coefficients.

This program has \(\tau+1\) variables and \(2\tau+m+2\) inequalities. Its feasible region is closed and contained in the bounded box

\(\left(\prod_{t\in T}[0,\mu_t]\right)\times[0,1].\)

Consequently, if the program is feasible, its maximum is attained. Denote the maximum by \(\varepsilon^\star\).

3. Proof of equivalence

Claim. A recount making \(a\) win exists if and only if the linear program is feasible and \(\varepsilon^\star>0\).

Forward direction. Suppose \(x\) is a feasible recount making \(a\) win.

If \(H\ne\varnothing\), define

\(\varepsilon=\min\left(\{1\}\cup\{S_a(x)-S_c(x):c\in H\}\right).\)

Every difference appearing in this finite minimum is strictly positive, so \(0<\varepsilon\le1\). The score constraints for \(H\) hold by the definition of the minimum. Those for \(K\) hold because \(a\) wins. The remaining constraints hold because \(x\) is a feasible recount. Hence \((x,\varepsilon)\) is feasible, and \(\varepsilon^\star\ge\varepsilon>0\).

If \(H=\varnothing\), choose \(\varepsilon=1\). There are no score constraints involving \(\varepsilon\), and every required comparison is nonnegative. Thus \((x,1)\) is feasible, again giving \(\varepsilon^\star>0\).

Reverse direction. Suppose the program is feasible and \(\varepsilon^\star>0\). Let \((x^\star,\varepsilon^\star)\) attain its maximum.

The bounds and budget constraint make \(x^\star\) a feasible recount. For each \(c\in H\),

\(S_a(x^\star)-S_c(x^\star)\ge\varepsilon^\star>0.\)

For each \(c\in K\),

\(S_a(x^\star)-S_c(x^\star)\ge0.\)

These are precisely the stated winning conditions for \(a\). This proves the claim.

In particular, merely testing the feasibility of all comparisons after replacing strict inequalities by non-strict ones would be insufficient. Testing whether the optimal margin is positive preserves the tie-breaking rule exactly.

4. Polynomial bit complexity and algorithm

We use the standard rational linear programming theorem: a linear program with binary-encoded rational coefficients can be solved in deterministic time polynomial in its number of variables, number of constraints, and total encoding length. The algorithm detects infeasibility and, when a finite optimum is attained, can return an exact rational optimum and an optimal rational solution. Polynomial-time rational linear programming follows from the ellipsoid method. [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/php/archive.phtml?jrnid=zvmmf&option_lang=eng&paperid=5239&wshow=paper).

Here its hypotheses hold: all coefficients are rational, the constraints and objective are linear, and every feasible instance of the constructed program has an attained finite optimum.

We must also check that constructing the program does not cause excessive coefficient growth. Each \(d_{tc}\) is a signed sum of four input rationals. Each \(r_c\) is a sum of products of input rationals. For a fixed \(c\), a common denominator can be obtained by multiplying the denominators of the masses and the two relevant reported coordinates for every type. The sum of their binary lengths is \(O(L)\), so this denominator has \(O(L)\) bits.

Moreover, \(|r_c|\le1\): it is a weighted sum, with weights summing to \(1\), of differences in \([-1,1]\). Thus the corresponding numerator also has \(O(L)\) bits. The same polynomial bound holds for every coefficient of the program. These coefficients can be computed by exact rational arithmetic in polynomial time.

A dense encoding of the resulting program therefore has length

\(B=O((m+\tau)(\tau+1)L).\)

The decision algorithm constructs the program, solves it exactly, rejects if it is infeasible, and otherwise accepts exactly when its rational optimum satisfies \(\varepsilon^\star>0\). The final comparison is an exact sign test on a rational number; no numerical tolerance is needed.

Its running time is

\(\operatorname{poly}\!\left(\tau+1,\;2\tau+m+2,\;(m+\tau)(\tau+1)L\right),\)

which is polynomial in \(m,\tau,L\). It uses one variable per listed support type and never enumerates unlisted possible types.

5. Relation to the discrete problem

The [cited discrete hardness result](https://www.ijcai.org/proceedings/2019/0037.pdf) concerns indivisible districts. Here the permitted masses form intervals \(x_t\in[0,\mu_t]\), and all budget and winning conditions admit the linear formulation proved above.

The argument applies to every instance specified in the question, including instances where \(a\) does not win the true profile. No additional promise is required.
