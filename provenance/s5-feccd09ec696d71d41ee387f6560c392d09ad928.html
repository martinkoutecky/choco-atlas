The continuous mirror question, as graded

Given a finite type set \(T\), rational type-mass vector \(\mu\), and rational piecewise-linear positively homogeneous component-value function \(V\), does the greedy selection of feasible profiles \(x\le r\) maximizing \(V(x)/\|x\|_1\), with residual mass \(r\), generate the unique groupwise farsightedly stable set of measurable networks under egalitarian per-capita payoffs, and can its component-profile decompositions be computed?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_t\mu_t=1\), and realize each type as a disjoint interval of Lebesgue measure \(\mu_t\) in an atomless agent space \(A\).
The input includes a continuous, rational piecewise-linear, positively homogeneous function \(V:\mathbb R_{\ge0}^{\tau}\to\mathbb R\), specified by \(m\) explicitly listed rational polyhedral cones covering its domain and a rational linear form on each cone, agreeing on overlaps. Values may be negative; \(L\) is the total binary input length.
A network is a symmetric measurable binary function on \(A^2\), identified up to product-null changes. Its components are maximal measurable connected blocks of positive measure: a block is connected if every partition into two positive-measure parts has positive edge measure between them; remaining agents are isolated.
A component \(C\) has profile \(x_t=\lambda(C\cap A_t)\), value \(V(x)\), and payoff \(V(x)/\|x\|_1\) to each member. Total value is the sum of component values; isolated agents receive zero. Every nonzero profile bounded by the available mass is feasible.
A measurable coalition \(S\) of positive measure may add edges only inside \(S\) and delete edges only incident to \(S\), with these restrictions interpreted almost everywhere; both operations may occur in one move.
A farsighted improving path is a finite sequence of distinct successive networks in which each moving coalition strictly prefers the terminal network to its current network almost everywhere. Write \(F(g)\) for the distinct terminal networks reachable from \(g\).
A nonempty set \(H\) is groupwise farsightedly stable if every move by \(S\) from \(g\in H\) to \(g'\notin H\) has some \(h\in F(g')\cap H\) with \(\lambda\{a\in S:u_a(h)\le u_a(g)\}>0\), every \(g\notin H\) satisfies \(F(g)\cap H\ne\varnothing\), and no proper subset satisfies these two conditions.
Starting with \(r=\mu\), greedily select any nonzero \(x\le r\) maximizing \(V(x)/\|x\|_1\), provided its value is nonnegative, and replace \(r\) by \(r-x\). Retain all ties. Allow finite or countable selections, leaving residual mass isolated only when no feasible profile has positive per-capita value; zero-valued maximizing components are optional.
Let \(G_{\mathrm{gr}}\) contain every network whose component profiles admit such an ordering. A finite rational decomposition consists of the selected profiles in order and the isolated residual profile.
Does \(G_{\mathrm{gr}}\) equal the unique groupwise farsightedly stable set?
Is computing one finite rational greedy decomposition polynomial-time solvable in \(m,\tau,L\), or NP-hard?
For finite societies, greedy maximum-per-capita selection is established as a characterization of the unique pairwise and groupwise farsightedly stable set under componentwise egalitarian payoffs and strict coalition improvement; no polynomial-time bound is asserted. Conclusions and interpretation

The answers are:

  • No: \(G_{\mathrm{gr}}\) need not equal the unique groupwise farsightedly stable set. A counterexample exists with two types and a strictly positive linear value function.
  • Polynomial-time solvable: one finite rational greedy decomposition can be computed using at most \(m\tau\) rational linear programs, with polynomial total bit complexity.

I interpret a countable greedy run as an ordinary sequence indexed by \(\mathbb N\), with its unselected residual left isolated. Allowing further selections after a countable limit stage would be a different, transfinite rule. The distinction matters for the counterexample.

All networks, coalitions, and modifications below are understood modulo the null sets specified in the question.

1. A two-type counterexample

Take \(\tau=2\), \(\mu_1=\mu_2=\tfrac12\), and

\(V(x_1,x_2)=x_1+\tfrac12x_2.\)

This satisfies every input hypothesis: it is rational, continuous, linear, and positively homogeneous, and one cone suffices to describe it. Its value is strictly positive on every nonzero nonnegative profile.

For any nonzero profile, its per-capita value is

\(\displaystyle \frac{V(x_1,x_2)}{x_1+x_2}=1-\frac{x_2}{2(x_1+x_2)}.\)

Consequently, whenever positive type-one mass remains, the maximum feasible per-capita value is \(1\), and a profile attains it exactly when it contains only type-one agents. Once type-one mass is exhausted, every nonzero remaining profile has per-capita value \(\tfrac12\).

Realize \(A_1=[0,\tfrac12)\) and \(A_2=[\tfrac12,1)\). Partition \(A_1\), up to a null set, into intervals \(B_n\) with

\(\lambda(B_n)=2^{-n-1}\), for \(n\in\mathbb N\).

Define \(g_\ast\) to have complete components on each \(B_n\) and on \(A_2\), and no edges between these blocks. These are its maximal connected blocks: each complete block is connected, and a union containing positive mass from different blocks has a partition with zero cross-edge measure.

Every type-one agent receives \(1\), and every type-two agent receives \(\tfrac12\).

The network has no greedy ordering

A finite run cannot list its infinitely many components.

In any countably infinite sequential ordering, the component \(A_2\) occurs at some finite position. Only finitely many \(B_n\) precede it, so positive type-one mass remains at that position. The maximum available per-capita value is therefore \(1\), whereas the \(A_2\) component has per-capita value \(\tfrac12\). Its selection violates the greedy rule.

Thus \(g_\ast\notin G_{\mathrm{gr}}\).

We next prove that \(g_\ast\) must belong to every stable set, and in fact identify the unique stable set for this input.

2. The unique stable set in the counterexample

Let \(K\) consist of all networks satisfying both conditions:

  • Every positive-measure component contains only one type.
  • The isolated residual has measure zero.

Every network in \(K\) gives the same payoff function: \(1\) on \(A_1\) and \(\tfrac12\) on \(A_2\). The set is nonempty, since the network with complete components \(A_1\) and \(A_2\) belongs to it.

Lemma 1: Every network in \(K\) has no farsighted improving path

Fix \(k\in K\). Suppose, for contradiction, that a farsighted improving path from \(k\) has terminal network \(h\).

In every possible network, every agent’s payoff is at most \(1\): component per-capita values are at most \(1\), and isolated agents receive zero.

Consider the path successively. Initially, all type-one agents receive \(1\). They therefore cannot participate in its first moving coalition on a positive-measure subset, because the terminal payoff cannot strictly exceed their current payoff.

A move whose coalition contains only type-two agents almost everywhere preserves the entire type-one subnetwork. It also cannot create edges between the types: additions require both endpoints to lie in the coalition, and initially there are no such cross-type edges.

Inductively, type-one agents remain in their original components and receive \(1\) throughout the path. At every step, strict terminal improvement excludes them from the moving coalition. Hence no cross-type edges arise anywhere along the path.

It follows that every type-two agent’s terminal payoff is at most \(\tfrac12\), since its terminal component, if any, contains only type-two agents. But initially every type-two agent receives \(\tfrac12\). The first moving coalition thus cannot satisfy strict terminal improvement, either.

This contradiction proves \(F(k)=\varnothing\).

Lemma 2: Every network outside \(K\) reaches \(K\) in at most two moves

Fix \(g\notin K\). Positive-measure components are at most countable, so the payoff-defined coalitions used below are measurable.

Let

\(S_1=\{a\in A_1:u_a(g)<1\}.\)

This coalition comprises the isolated type-one agents and all type-one agents belonging to mixed components.

If \(\lambda(S_1)>0\), let \(S_1\) delete every edge incident to itself and form a complete component on itself. Call the resulting network \(g_1\). This is an allowed move.

All type-one agents now belong to pure type-one components:

  • Agents in \(S_1\) belong to the newly formed complete component.
  • Agents in \(A_1\setminus S_1\) already belonged to pure type-one components, which the move preserves.

Moreover, no cross-type edges remain. Every type-one agent formerly belonging to a mixed component was in \(S_1\), and all its incident edges were deleted.

If \(\lambda(S_1)=0\), set \(g_1=g\) and omit this move. The same conclusions hold almost everywhere.

Now let \(S_2\) be the isolated type-two agents in \(g_1\). If \(\lambda(S_2)>0\), let them form a complete component on themselves. Their current payoff is zero and their resulting payoff is \(\tfrac12\). All existing components remain pure.

Denote the final network by \(h\). Then \(h\in K\). The retained moves form a farsighted improving path to \(h\):

  • Every agent in \(S_1\) receives \(1\) at \(h\), strictly exceeding its payoff at \(g\).
  • Every agent in \(S_2\) receives \(\tfrac12\) at \(h\), strictly exceeding its payoff at \(g_1\).

Every retained move changes payoffs on a positive-measure set, so successive networks are distinct. Because \(g\notin K\), at least one move is retained. Therefore \(F(g)\cap K\ne\varnothing\).

Proposition: \(K\) is the unique groupwise farsightedly stable set

Lemma 2 establishes external stability.

For deterrence, consider any allowed move by a positive-measure coalition \(S\) from \(k\in K\) to \(g'\notin K\). By Lemma 2, some \(h\in F(g')\cap K\) exists. Since every network in \(K\) gives the same payoff function,

\(u_a(h)=u_a(k)\) almost everywhere.

Thus the required deterrence set has measure \(\lambda(S)>0\).

Finally, every set satisfying external stability must contain \(K\). Indeed, omitting any \(k\in K\) would require a terminal network in \(F(k)\), contradicting Lemma 1. Therefore:

  • No proper subset of \(K\) satisfies external stability.
  • Any proper superset of \(K\) fails the required minimality, because \(K\) already satisfies deterrence and external stability.

This proves uniqueness.

In particular, \(g_\ast\in K\) but \(g_\ast\notin G_{\mathrm{gr}}\). Hence \(G_{\mathrm{gr}}\) fails even external stability for this input.

The obstruction is infinite sequential ordering, despite strictly positive component values. The [supplied finite-society paper](https://cerec.be/wp-content/uploads/2017/12/characterization_farsighted_networks7.pdf) explicitly uses finiteness to ensure that its component-selection procedure terminates.

3. Computing a finite rational greedy decomposition

We now treat the full input class.

Write the supplied cones as \(C_1,\ldots,C_m\), with \(V(x)=c_j^\top x\) on \(C_j\).

Lemma 3: The greedy maximum depends only on the residual support

Let \(r\ne0\), and define \(I=\{t:r_t>0\}\). Define the simplex face

\(\Delta_I=\{y\in\mathbb R_{\ge0}^{\tau}:\sum_t y_t=1,\ y_t=0\text{ for }t\notin I\}.\)

For every feasible nonzero \(x\le r\), the normalized direction \(y=x/\|x\|_1\) belongs to \(\Delta_I\). Positive homogeneity gives

\(\displaystyle \frac{V(x)}{\|x\|_1}=V(y).\)

Conversely, every \(y\in\Delta_I\) can be scaled to a feasible nonzero profile. Specifically, set

\(\displaystyle \alpha=\min_{t:y_t>0}\frac{r_t}{y_t}>0.\)

Then \(x=\alpha y\le r\), and its per-capita value is \(V(y)\).

Therefore the greedy maximum is exactly

\(\displaystyle p_I=\max_{y\in\Delta_I}V(y).\)

The set \(\Delta_I\) is nonempty and compact, and \(V\) is continuous, so this maximum exists.

Computing a maximizing direction

For each cone, solve the rational linear program

\(\displaystyle p_{I,j}=\max\{c_j^\top y:y\in C_j\cap\Delta_I\},\)

discarding infeasible programs. Each feasible region is compact. Since the cones cover the domain,

\(p_I=\max_{j:C_j\cap\Delta_I\ne\varnothing}p_{I,j}.\)

This equality does not require convexity or concavity of \(V\): the algorithm separately optimizes its explicitly listed linear pieces.

We use the standard rational linear-programming theorem: feasibility and optimization of a rational linear program are polynomial-time computable, and when a finite optimum exists, an exact rational optimizer of polynomial encoding length can be returned. Here the coefficients are rational, the descriptions have polynomial size, and every feasible program has a finite attained optimum. For a cone supplied by generators, auxiliary nonnegative generator coefficients give the corresponding linear program.

Thus \(m\) linear programs suffice to compute \(p_I\) and a rational maximizing direction \(y\).

The algorithm and termination

Starting with \(r=\mu\), repeat:

  • If \(r=0\), terminate.
  • Compute \(p_I\) and a rational maximizing direction \(y\).
  • If \(p_I\le0\), terminate and leave \(r\) isolated.
  • Otherwise, set \(\alpha=\min_{t:y_t>0}r_t/y_t\), select \(x=\alpha y\), and replace \(r\) by \(r-x\).

Every selected profile is a greedy maximizer by Lemma 3 and has positive value. Stopping when \(p_I=0\) is permitted because zero-valued maximizing components are optional.

Each selection exhausts at least one currently positive coordinate: a coordinate attaining the defining minimum for \(\alpha\) becomes zero. Exhausted coordinates never become positive again. Consequently, at most \(\tau\) profiles are selected.

If the algorithm stops with a nonzero residual, Lemma 3 shows that no feasible profile has positive per-capita value. Thus the isolated residual satisfies the stipulated stopping rule.

Polynomial bit complexity

It remains to control the sizes of the exact rational residuals.

The direction programs depend on the input cones and the support \(I\), rather than on the numerical magnitudes of \(r\). Hence their returned directions have a uniform polynomial encoding bound. Write any returned direction as \(y=b/E\), using a common positive integer denominator, with

\(b_t\in\mathbb Z_{\ge0}\) and \(\sum_t b_t=E.\)

Both \(E\) and all \(b_t\) have polynomial bit length.

Represent the current residual as \(r=a/D\) with a common positive integer denominator. If coordinate \(k\) attains the scaling minimum, then \(b_k>0\), and

\(\displaystyle \alpha=\frac{a_kE}{Db_k},\qquad x_t=\frac{a_kb_t}{Db_k},\qquad r'_t=\frac{a_tb_k-a_kb_t}{Db_k}.\)

Thus a valid next common denominator is \(D'=Db_k\). Its bit length increases by at most the polynomial bit length of \(b_k\). Over at most \(\tau\) iterations, the denominator length therefore remains polynomial.

All residual and selected coordinates lie between zero and one. Their numerators in these common-denominator representations consequently have polynomial bit length as well. The initial common denominator has polynomial bit length because it can be taken as the product of the input mass denominators.

The algorithm uses at most \(m\tau\) linear programs and polynomially many arithmetic operations on polynomial-length integers. Its running time and output length are polynomial in \(m,\tau,L\).

4. Scope of the negative answer

The counterexample would admit a transfinite greedy ordering of order type \(\omega+1\): select all the \(B_n\), take the residual at the limit, and then select \(A_2\). That procedure permits a selection after infinitely many preceding selections.

Under the ordinary finite-or-countably-infinite sequential rule used here, no such position exists. The counterexample therefore settles the stated sequential characterization negatively. No characterization for a modified transfinite rule is asserted.
