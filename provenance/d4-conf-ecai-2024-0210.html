The continuous mirror question, as graded

Given a project set \(P\), horizon \(\ell\), and a support of \(\tau\) UP approval-trajectory types \(\theta\), each with binary-rational mass \(\mu_\theta>0\) summing to \(1\), is there an outcome \(o\in P^\ell\) such that \(u_\theta(o)=\sum_{t=1}^{\ell}\mathbf{1}[o_t\in S_{\theta t}]\ge 1\) for every supported type? Here each \(S_{\theta t}\) is a singleton project approval set.

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a project set with \(m\ge 1\), and let \(\ell\ge 1\) be an integer horizon.
A society is given by its support: a list of \(\tau\ge 1\) distinct approval-trajectory types \(\theta\), each with binary-rational mass \(\mu_\theta>0\), where \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
Each trajectory is explicitly listed as \((S_{\theta 1},\ldots,S_{\theta\ell})\), with every \(S_{\theta t}\subseteq P\) a singleton; this is the unique-preferences (UP) domain.
An outcome is a deterministic sequence \(o\in P^\ell\); projects may be repeated across timesteps. Define \(u_\theta(o)=\sum_{t=1}^{\ell}\mathbf{1}[o_t\in S_{\theta t}]\).
The decision problem asks whether an outcome exists with \(u_\theta(o)\ge 1\) for every supported type. Let \(L\) be the total binary input length; state running times in \(m,\tau,\ell,L\).

Is this decision problem solvable in polynomial time in \(m,\tau,\ell,L\), or is it NP-hard?

For a finite list of agents, deciding whether every agent can receive utility at least \(1\) is NP-complete even in the UP domain. [Source](https://arxiv.org/html/2408.13637v2#S3).
No separate classification for the distribution-over-types formulation is asserted here.

Classification

The problem is \(\mathrm{NP}\)-complete, even when all masses are positive dyadic rationals. Consequently, a polynomial-time algorithm in \(m,\tau,\ell,L\) exists if and only if \(\mathrm{P}=\mathrm{NP}\).

The key observation is that masses do not affect feasibility: the requirement applies separately to every supported trajectory.

Membership in \(\mathrm{NP}\)

Write \(S_{\theta t}=\{a_{\theta t}\}\), where \(a_{\theta t}\in P\). An outcome \(o\) satisfies type \(\theta\) precisely when there exists \(t\in\{1,\ldots,\ell\}\) with \(o_t=a_{\theta t}\).

A certificate is the sequence \(o\in P^\ell\). With projects indexed by integers, its length is \(O(\ell\log(m+1))\), which is polynomial in \(L\) because trajectories are explicitly listed and \(\tau\ge 1\).

The verifier checks that every chosen project belongs to \(P\), then checks the above condition for each supported type. This requires at most \(\tau\ell\) project comparisons. With binary project indices, verification takes \(O(L+\tau\ell\log(m+1))\) time using indexed storage. Thus the problem belongs to \(\mathrm{NP}\).

Polynomial Reduction from the Finite-Agent Problem

Theorem 3.1 of the cited paper establishes \(\mathrm{NP}\)-completeness for explicitly listed finite agents, with singleton approvals at every timestep and utility threshold \(1\). Its outcomes also choose one project per timestep and allow repetitions, so its feasibility condition matches ours. [Source: Theorem 3.1 and model definitions](https://arxiv.org/html/2408.13637v2#S3).

Consider such a finite-agent instance with \(n\ge 1\) agents. Keep its project set and horizon unchanged.

Construct distinct types. Partition the agents according to equality of their entire approval trajectories, and retain one trajectory from each class. Let the resulting support size be \(\tau\), so \(1\le\tau\le n\). The trajectories are distinct by construction, and every approval set remains a singleton.

Assign valid masses. Set \(q=\lceil\log_2\tau\rceil\), and number the retained types from \(1\) through \(\tau\). Define

\(\displaystyle \mu_j=\frac{1}{2^q}\quad(1\le j<\tau),\qquad \mu_\tau=\frac{2^q-\tau+1}{2^q}.\)

These are dyadic rationals. Since \(2^q\ge\tau\), every mass is positive. Their sum is

\(\displaystyle \sum_{j=1}^{\tau}\mu_j=\frac{\tau-1+2^q-\tau+1}{2^q}=1.\)

This also handles \(\tau=1\): then \(q=0\) and the sole mass is \(1\). Each mass requires \(O(\log(\tau+1))\) bits, so all masses together require \(O(\tau\log(\tau+1))\) bits.

Prove equivalence. For any outcome \(o\), an agent and the retained type representing its trajectory have exactly the same utility. Therefore,

\(\displaystyle \bigl[u_i(o)\ge1\text{ for every original agent }i\bigr]\quad\Longleftrightarrow\quad\bigl[u_\theta(o)\ge1\text{ for every retained type }\theta\bigr].\)

Thus the original instance is feasible exactly when the constructed support instance is feasible.

Check polynomial size and time. Let \(L_{\mathrm{fin}}\) be the original input length. Pairwise trajectory comparisons suffice to remove duplicates in time \(O(L_{\mathrm{fin}}+n^2\ell\log(m+1))\). Writing the masses adds \(O(n\log(n+1))\) time and bits. Since the finite-agent trajectories are explicitly listed, these bounds are polynomial in \(L_{\mathrm{fin}}\).

This is a polynomial many-one reduction from an \(\mathrm{NP}\)-complete problem, proving \(\mathrm{NP}\)-hardness. Together with membership, it proves \(\mathrm{NP}\)-completeness.

Running-Time Upper Bound

Enumerating all \(m^\ell\) outcomes and checking each gives a deterministic algorithm with running time \(O(L+m^\ell\tau\ell\log(m+1))\) using indexed storage. This bound is exponential in general; replacing agents by distinct supported types does not remove the hardness.
