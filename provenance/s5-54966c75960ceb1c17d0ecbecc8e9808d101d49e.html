The continuous mirror question, as graded

Given a finite DAG \(G\) of permission types, rational masses \(\mu_t>0\) summing to \(1\), and non-negative rational per-agent contributions \(a_t\), consider every admissible integer \(q\) for which \(q\mu_t\) is integral. Form a \(q\)-agent game with \(q\mu_t\) identical agents of type \(t\), permission arcs from every type-\(s\) agent to every type-\(t\) agent when \((s,t)\in G\), additive contributions \(a_t\), and the paper's disjunctive restriction. Does the vector of common per-agent nucleolus payoffs by type converge as \(q\) grows, and, if so, what is its limit; otherwise, can non-convergence be proved?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Input also includes a DAG \(G=(T,E)\) and binary rational contributions \(a_t\geq0\). Write \(m=|E|\) and let \(L\) be the total input bit length.
For each admissible \(q\in\mathbb N_{>0}\) satisfying \(q\mu_t\in\mathbb Z\) for every \(t\), create \(q\mu_t\) agents of type \(t\). Put an arc from every type-\(s\) agent to every type-\(t\) agent exactly when \((s,t)\in E\), with no other arcs; denote this agent graph by \(D_q\).
A coalition \(F\) is feasible if every member having an incoming arc in \(D_q\) has at least one direct predecessor in \(F\); agents with no predecessors require no permission. Let \(\sigma_q(S)\) be the union of all feasible subsets of \(S\), and define \(r_q(S)=\sum_{i\in\sigma_q(S)}a_{t(i)}\), where \(t(i)\) is agent \(i\)'s type.
Use the ordinary nucleolus over imputations. Symmetry gives a common payoff \(x_t^{(q)}\) to each type-\(t\) agent; these are per-agent payoffs, without division by \(q\). Convergence means convergence in \(\mathbb R^\tau\) along all admissible \(q\to\infty\).
For a decision formulation, additionally input \(t_0\in T\) and \(b\in\mathbb Q\), encoded in binary: accept exactly when \(x^{(q)}\) converges and its limit satisfies \(x_{t_0}^*\geq b\). Include these inputs in \(L\); state running times in \(m,\tau,L\).

Does \(x^{(q)}\) converge for every input, or can non-convergence occur, and what is its limit whenever it converges?
Is the convergence-and-limit-threshold decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite agent graphs, the nucleolus of every non-negative additive disjunctive game with an acyclic permission structure is computable by an algorithm using \(O(n^4)\) operations, where \(n\) is the number of agents ([finite algorithm](https://papers.tinbergen.nl/08104.pdf)); the [published result](https://doi.org/10.1016/j.ejor.2010.05.028) also asserts polynomial-time computation.
No result settling this exact replication-limit problem was identified in the literature search.

Result

Every input converges. In fact, the per-agent nucleolus eventually equals the contribution vector exactly: \(x_t^{(q)}=a_t\) for every \(t\in T\) and every sufficiently large admissible \(q\).

Consequently, \(x_t^*=a_t\), and the decision problem is in \(\mathrm P\).

Feasibility after deleting one agent

Write \(\mu_{\min}=\min_{t\in T}\mu_t>0\), and set \(q_0=\lceil 2/\mu_{\min}\rceil\). Fix any admissible \(q\geq q_0\). Each type then has \(n_t=q\mu_t\geq2\) agents.

Let \(N\) be the agent set, write \(a_i=a_{t(i)}\), and define \(A=\sum_{i\in N}a_i\).

The grand coalition \(N\) is feasible: every agent having an incoming arc has a predecessor in \(N\).

Moreover, \(N\setminus\{i\}\) is feasible for every agent \(i\). Indeed, consider any member \(j\) having an incoming arc. Some type \(s\) satisfies \((s,t(j))\in E\), and every type-\(s\) agent is a direct predecessor of \(j\). There are at least two such agents, so deleting \(i\) leaves at least one predecessor of \(j\).

For any feasible coalition \(S\), the definition of \(\sigma_q\) gives \(\sigma_q(S)=S\): the union defining \(\sigma_q(S)\) contains \(S\) itself and is contained in \(S\). Therefore, \(r_q(N)=A\) and \(r_q(N\setminus\{i\})=A-a_i\).

Exact determination of the nucleolus

Consider the agent payoff vector \(z\) defined by \(z_i=a_i\).

For every coalition \(S\), nonnegativity of the contributions and \(\sigma_q(S)\subseteq S\) imply
\(r_q(S)=\sum_{i\in\sigma_q(S)}a_i\leq\sum_{i\in S}a_i=z(S)\).

Thus \(z\) is efficient and individually rational, and all its coalition excesses \(e_q(S,z)=r_q(S)-z(S)\) are nonpositive.

Now let \(y\neq z\) be any other imputation. Efficiency gives \(\sum_{i\in N}y_i=A=\sum_{i\in N}a_i\). Hence some agent \(i\) satisfies \(y_i>a_i\): otherwise every coordinate would satisfy \(y_i\leq a_i\), with at least one strict inequality, contradicting equality of the sums.

For this agent, efficiency and the deletion formula give
\(e_q(N\setminus\{i\},y)=(A-a_i)-(A-y_i)=y_i-a_i>0\).

There are at least two agents, so \(N\setminus\{i\}\) is a nonempty proper coalition. The largest excess at \(y\) is therefore positive, whereas the largest excess at \(z\) is nonpositive. Consequently, the sorted excess vector at \(z\) is strictly lexicographically smaller than that at \(y\), already in its first coordinate.

This proves directly from the ordinary nucleolus definition that \(z\) is its unique minimizer. Hence \(x_t^{(q)}=a_t\) for every type \(t\) whenever \(q\geq q_0\) is admissible.

Convergence and decision complexity

Admissible replication sizes are unbounded: if \(d\) is a common multiple of the denominators of the rational masses, every positive multiple of \(d\) is admissible. The eventual equality proved above therefore establishes convergence along all admissible \(q\to\infty\), with limit \(x^*=(a_t)_{t\in T}\).

The decision algorithm accepts precisely when \(a_{t_0}\geq b\).

To compare exactly, write \(a_{t_0}=p/d\) and \(b=u/v\), with \(d,v>0\). Acceptance is equivalent to \(pv\geq ud\). Reading the input and performing these signed integer products and comparison takes \(O(m+\tau+L^2)\) bit operations using schoolbook arithmetic and \(O(L)\) space. No replicated agent graph needs to be constructed.
