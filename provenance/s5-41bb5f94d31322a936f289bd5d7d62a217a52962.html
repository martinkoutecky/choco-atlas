The continuous mirror question, as graded

Given a finite alternative set \(A\), rational type masses \(\mu_h\), initial preorders \(\pi_h(0)\), quorum fractions \(\alpha_h\), and a symmetric block interaction kernel \(W\) realizable by exact equitable network blow-ups, compute the terminal preorder \(\pi_h^*\) for each type. At each round, type \(h\) forms \(R_h^t\) from comparisons supported by at least \(\alpha_h\) of its neighbors, takes the transitive-reflexive closure \((R_h^t)^+\), and updates by \(\pi_h(t+1)=\pi_h(t)\vee(R_h^t)^+\), where \(q_{hg}=\mu_gW_{hg}/\sum_j\mu_jW_{hj}\) gives the neighbor type proportions.

Each type has an explicitly represented initial preorder \(\pi_h(0)\subseteq A\times A\), possibly incomplete and allowing indifference, and a binary-rational quorum fraction \(0<\alpha_h\leq1\).
The input includes a symmetric nonnegative binary-rational matrix \(W\), with \(d_h=\sum_g\mu_gW_{hg}>0\); define \(q_{hg}=\mu_gW_{hg}/d_h\).
Exact equitable realizability is promised: there exists a finite simple undirected graph partitioned into classes of sizes \(n_h=n\mu_h\), such that every vertex in class \(h\) has the same positive degree \(D_h\) and exactly \(D_hq_{hg}\) neighbors in class \(g\). The realizing graph is not part of the input.
Types communicate their current preorders faithfully and update synchronously, with fixed masses, quorums, and kernel.
At round \(t\), set \(R_h^t=\{(a,b)\in A\times A:\sum_{g:(a,b)\in\pi_g(t)}q_{hg}\geq\alpha_h\}\), including equality at the quorum.
Write \(S^+\) for transitive-reflexive closure and \(P\vee Q=(P\cup Q)^+\); update \(\pi_h(t+1)=\pi_h(t)\vee(R_h^t)^+\). The terminal profile \((\pi_h^*)_h\) is the eventual constant profile reached from the specified initial profile.
Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Can the terminal profile \((\pi_h^*)_h\) be computed in time polynomial in \(m,\tau,L\), or is computing it NP-hard?

For finite networks and finite alternatives, inflationary preorder dynamics converge in finite time to a fixed profile equal to the join of their trajectory; this convergence result states no polynomial running-time bound. [Riess et al.](https://arxiv.org/html/2310.00179v2)

Result

The terminal profile is computable in time polynomial in \(m,\tau,L\). There are at most \(\tau m(m-1)\) rounds in which the profile changes, and every round can be computed using polynomial-time exact arithmetic.

The key is to bound the length of an increasing trajectory by the number of individual comparisons that can be added. The number of possible preorders need not be polynomial.

1. A polynomial bound on changing rounds

Write \(\boldsymbol{\pi}(t)=(\pi_h(t))_{h=1}^{\tau}\). By the update rule and the definition of transitive-reflexive closure,

\[ \pi_h(t)\subseteq\pi_h(t+1) \]

for every \(h,t\). Thus comparisons are never removed.

Define the integer potential

\[ \Phi(t)=\sum_{h=1}^{\tau}|\pi_h(t)|. \]

Each initial preorder is reflexive, so \(\Phi(0)\geq\tau m\). Every relation is contained in \(A\times A\), so \(\Phi(t)\leq\tau m^2\).

If \(\boldsymbol{\pi}(t+1)\neq\boldsymbol{\pi}(t)\), some type gains at least one ordered pair. Consequently,

\[ \Phi(t+1)\geq\Phi(t)+1. \]

There can therefore be at most

\[ K=\tau m^2-\Phi(0)\leq\tau m(m-1) \]

changing rounds.

The update is a deterministic function of the current profile with fixed parameters. Hence, once two consecutive profiles agree, all subsequent profiles agree. Simulation terminates after at most \(K+1\) update evaluations, including the final evaluation that detects equality.

This gives an explicit round bound beyond the finite-convergence statement in [Riess et al., Theorem 3](https://arxiv.org/html/2310.00179v2).

2. Exact quorum tests with bounded integer sizes

Write the input rationals as

\[ \mu_g=\frac{a_g}{b_g},\qquad W_{hg}=\frac{e_{hg}}{f_{hg}},\qquad \alpha_h=\frac{u_h}{v_h}, \]

with positive denominators. Numerators of matrix entries may be zero.

Choose the common denominator

\[ B=\left(\prod_{g=1}^{\tau}b_g\right) \left(\prod_{h,g=1}^{\tau}f_{hg}\right), \]

and precompute the nonnegative integers

\[ c_{hg}=B\mu_gW_{hg} =\frac{B}{b_gf_{hg}}a_ge_{hg}, \qquad s_h=\sum_{g=1}^{\tau}c_{hg}. \]

The quotient defining \(c_{hg}\) is integral because both denominator factors occur in \(B\). Moreover,

\[ s_h=Bd_h>0,\qquad q_{hg}=\frac{c_{hg}}{s_h}. \]

For a pair \((a,b)\), let

\[ G_t(a,b)=\{g:(a,b)\in\pi_g(t)\}. \]

Multiplying the quorum inequality by the positive integer \(v_hs_h\) gives the exact equivalence

\[ \sum_{g\in G_t(a,b)}q_{hg}\geq\alpha_h \quad\Longleftrightarrow\quad v_h\sum_{g\in G_t(a,b)}c_{hg}\geq u_hs_h. \]

Precompute the integer threshold

\[ T_h=\left\lceil\frac{u_hs_h}{v_h}\right\rceil. \]

Since the supporting sum is an integer,

\[ (a,b)\in R_h^t \quad\Longleftrightarrow\quad \sum_{g\in G_t(a,b)}c_{hg}\geq T_h. \]

This includes equality at the original quorum exactly.

The bit length of \(B\) is bounded by the sum of the encoded denominator lengths, hence is \(O(L)\). Each \(c_{hg}\) also has \(O(L)\) bits. Summing at most \(\tau\) such integers gives \(O(L+\log\tau)=O(L)\) bits, since the explicit input contains \(\tau\) types. Threshold computation and all subsequent quorum tests therefore use integers of \(O(L)\) bits. Their sizes do not grow with the number of rounds.

3. Algorithm and correctness

Represent each current relation by an \(m\times m\) Boolean matrix. In each round:

  • Compute all \(R_h^t\) using the integer quorum tests above, reading only the current matrices.
  • For every type, compute

\[ \widehat{\pi}_h=(\pi_h(t)\cup R_h^t)^+ \]
by Boolean transitive closure, including the diagonal.

  • If all \(\widehat{\pi}_h=\pi_h(t)\), output the current profile. Otherwise replace all matrices simultaneously and repeat.

The closure in step 2 equals the specified update:

\[ (\pi_h(t)\cup R_h^t)^+ = (\pi_h(t)\cup(R_h^t)^+)^+. \]

To verify this identity, the left-hand side is a preorder containing \(R_h^t\), so it contains \((R_h^t)^+\), and therefore contains the right-hand side. Conversely, \(R_h^t\subseteq(R_h^t)^+\), so monotonicity of closure gives the reverse inclusion.

Thus every simulated round agrees exactly with the prescribed synchronous dynamics. Induction from the initial profile proves correctness at every time. Section 1 guarantees termination, and the equality test guarantees that the returned profile is precisely the terminal profile reached from the specified initialization.

4. Running time and the realization promise

Using schoolbook integer arithmetic, preprocessing costs

\[ O(\tau^2L^2). \]

For one round, computing the supporting sums for all types and ordered pairs costs

\[ O(\tau^2m^2L). \]

Boolean transitive closure for all types costs \(O(\tau m^3)\). Comparing successive profiles costs \(O(\tau m^2)\), absorbed by these bounds.

Consequently, a running-time bound is

\[ O\!\left( \tau^2L^2+ \bigl(\tau m(m-1)+1\bigr) \bigl(\tau^2m^2L+\tau m^3\bigr) \right). \]

In particular, the simpler bound

\[ O(\tau^2L^2+\tau^3m^4L+\tau^2m^5) \]

is polynomial in the requested parameters.

No realizing graph must be constructed. If one interprets the dynamics on a promised equitable realization, class uniformity is preserved inductively: every class-\(h\) vertex sees exactly the same fraction \(q_{hg}\) of class-\(g\) neighbors, and vertices within each class have identical current preorders. Their quorum sets and subsequent updates therefore agree. The explicitly represented support suffices, regardless of the realizing graph’s size.
