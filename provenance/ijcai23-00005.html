Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given rational \(p\in(0,1)\), rational \(\alpha\in(0,1]\), and \(\varepsilon>0\), with society \(\mu=(1-p,p)\), output rational \(z\) such that \(\left|z-\lim_{N\to\infty}\mathbb{E}[T_{\lfloor pN\rfloor}(N)]/N^2\right|\le\varepsilon\), equivalently \(\left|z-\frac{-p\ln p-(1-p)\ln(1-p)}{\alpha}\right|\le\varepsilon\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here types are the \(m=2\) opinions \(0,1\), with normalized masses \(\mu=(1-p,p)\), so \(\tau=2\).
Inputs are binary rationals \(p\in(0,1)\), \(\alpha\in(0,1]\), and \(\varepsilon>0\); let \(L\) be their total encoding length.
For each integer \(N\ge2\), start a complete graph without self-loops with \(\lfloor pN\rfloor\) agents holding opinion \(1\). Each step selects an agent uniformly, selects one of its neighbors uniformly, and copies that neighbor's opinion with probability \(\alpha\), independently; otherwise no opinion changes. Let \(T_k(N)\) be the random number of steps until unanimity when initially \(k\) agents hold opinion \(1\).
The computational problem is to output rational \(z\) satisfying \(\left|z-F(p,\alpha)\right|\le\varepsilon\), where \(F(p,\alpha)=\lim_{N\to\infty}\mathbb E[T_{\lfloor pN\rfloor}(N)]/N^2=[-p\ln p-(1-p)\ln(1-p)]/\alpha\).

Can this additive approximation be computed in time polynomial in \(m,\tau,L\), or is it NP-hard?

Known results: discretely, \(\mathbb E[T_k(N)]=N^2h(k/N)/\alpha+O(N/\alpha)\) for \(1\le k<N\), where \(h(q)=-q\ln q-(1-q)\ln(1-q)\). This also identifies the continuous value above, but supplies no bit-complexity classification for its approximation. [Becchetti et al.](https://arxiv.org/html/2305.07377v2)

Modeling choices made when packaging the task

  • Specified the otherwise unencoded tolerance epsilon as a positive binary rational and included its encoding in L.
  • Restored the asynchronous update schedule, complete graph without self-loops, independent adoption probability, and time measured in individual update steps.
  • Defined T_k(N) as a random consensus time so that the expectation in the continuous question is unambiguous.
  • Interpreted m as the number of opinions, fixed at two; both supported types have positive mass and total mass one.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Proven classification

The additive approximation problem is deterministically polynomial-time solvable in the standard bit model. Since \(m=\tau=2\), a polynomial bound in \(L\) is also polynomial in \(m,\tau,L\).

We use the stated identity
\(F(p,\alpha)=h(p)/\alpha\), where
\(h(p)=-p\ln p-(1-p)\ln(1-p)\).
The discrete consensus-time analysis is supplied by [Becchetti et al.](https://arxiv.org/html/2305.07377v2). Below we prove the bit-complexity bound directly, using exact rational arithmetic.

1. Encoding bounds

A binary rational is represented by an explicitly written binary numerator and positive binary denominator. Because the total input length is \(L\), every input numerator and denominator is less than \(2^L\). Consequently,

\(\displaystyle p\ge 2^{-L},\qquad 1-p\ge 2^{-L},\qquad \alpha\ge 2^{-L},\qquad \varepsilon\ge 2^{-L}.\)

For \(1-p\), write \(p=a/d\), with \(0<a<d\); then \(1-p=(d-a)/d\), whose positive numerator is at least one.

Set \(\delta=\alpha\varepsilon\). Thus \(\delta\ge 2^{-2L}\). It suffices to approximate \(h(p)\) within \(\delta\), because subsequent division by \(\alpha\) then produces error at most \(\varepsilon\).

Choose the smallest nonnegative integer \(b\) satisfying

\(\displaystyle 2^{-b}\le \frac{\delta}{2(L+1)}.\)

This choice can be made using exact rational comparisons. Moreover,

\(\displaystyle b\le 2L+\left\lceil\log_2\bigl(2(L+1)\bigr)\right\rceil=O(L).\)

Indeed, the integer on the right satisfies the required inequality by \(\delta\ge 2^{-2L}\).

2. A rational approximation to logarithms

For a rational \(y\in[1,2]\), put

\(\displaystyle t=\frac{y-1}{y+1},\qquad S_M(y)=2\sum_{j=0}^{M-1}\frac{t^{2j+1}}{2j+1}.\)

Here \(0\le t\le 1/3\), and \(S_M(y)\) is rational.

We claim that, for every integer \(M\ge 1\),

\(\displaystyle 0\le \ln y-S_M(y)\le 9^{-M}\le 2^{-2M}.\)

To prove this, note that \(y=(1+t)/(1-t)\), so

\(\displaystyle \ln y=2\int_0^t\frac{1}{1-s^2}\,ds.\)

The finite geometric identity

\(\displaystyle \frac{1}{1-s^2}=\sum_{j=0}^{M-1}s^{2j}+\frac{s^{2M}}{1-s^2}\)

therefore gives the exact remainder formula

\(\displaystyle \ln y-S_M(y)=2\int_0^t\frac{s^{2M}}{1-s^2}\,ds.\)

The integrand is nonnegative. Since \(s\le t\le 1/3\),

\(\displaystyle \ln y-S_M(y)\le \frac{2t^{2M+1}}{(2M+1)(1-t^2)} \le \frac{3}{4(2M+1)}\,9^{-M}\le 9^{-M}.\)

Finally, \(9^{-M}\le 4^{-M}=2^{-2M}\), proving the claim.

3. Rescaling the input arguments

For each \(q\in\{p,1-p\}\), choose the smallest nonnegative integer \(r_q\) such that \(2^{r_q}q\ge 1\), and define \(y_q=2^{r_q}q\).

Minimality gives \(1\le y_q<2\). Also \(q\ge 2^{-L}\), so \(r_q\le L\). These integers are found by at most \(L\) exact comparisons.

The logarithm identity is

\(\displaystyle \ln q=\ln y_q-r_q\ln 2.\)

Set \(M=b+1\), and define the rational approximation

\(\displaystyle A(q)=S_M(y_q)-r_qS_M(2).\)

Applying the bound from Section 2 to both logarithms gives

\(\displaystyle |A(q)-\ln q| \le (r_q+1)2^{-2M} \le (L+1)2^{-b} \le \frac{\delta}{2}.\)

The middle inequality holds because \(b\ge 0\) and \(M=b+1\), hence \(2^{-2M}\le 2^{-b}\).

4. Output and error guarantee

Compute, using exact rational arithmetic,

\(\displaystyle H=-pA(p)-(1-p)A(1-p),\qquad z=\frac{H}{\alpha}.\)

The coefficients \(p\) and \(1-p\) are nonnegative and sum to one. Therefore,

\(\displaystyle |H-h(p)| \le p\,|A(p)-\ln p|+(1-p)\,|A(1-p)-\ln(1-p)| \le \frac{\delta}{2}.\)

Since \(\alpha>0\),

\(\displaystyle |z-F(p,\alpha)| =\frac{|H-h(p)|}{\alpha} \le \frac{\delta}{2\alpha} =\frac{\varepsilon}{2} \le \varepsilon.\)

Thus the algorithm returns a valid rational answer.

5. Bit complexity

We must bound the sizes of intermediate integers, not merely the number of arithmetic operations.

The rational arguments \(y_p,y_{1-p},2\), and hence their corresponding values of \(t\), have \(O(L)\)-bit numerators and denominators: forming \(y_q\) shifts its numerator by at most \(L\) bits, and forming \(t\) uses rational addition and division.

Write any such \(t\) as \(u/v\), with \(u,v\) having \(O(L)\) bits. The summand

\(\displaystyle \frac{2u^{2j+1}}{(2j+1)v^{2j+1}}\)

has numerator and denominator lengths \(O((j+1)L+\log(j+1))\).

There are \(M=O(L)\) summands. Even a naive implementation that adds fractions by multiplying their denominators has intermediate denominator length bounded by

\(\displaystyle O\!\left(\sum_{j=0}^{M-1}\bigl((j+1)L+\log(j+1)\bigr)\right) =O(LM^2+M\log M)=O(L^3).\)

The numerator lengths are polynomial as well: all summands are nonnegative and at most \(2\), so every partial sum is at most \(2M\). Its numerator consequently needs at most its denominator length plus \(O(\log M)\) bits.

Powers, sums, and the final rational operations require only polynomially many integer operations on integers of polynomial bit length. Elementary binary arithmetic therefore implements the entire algorithm in polynomial time. The output \(z\) also has polynomial encoding length.

In particular, small \(\alpha\) causes no exponential running time: the precision requirement depends on the bit length of \(\alpha\), rather than on the numerical value of \(1/\alpha\).

Conclusion

The target approximation problem admits a deterministic polynomial-time algorithm. An NP-hardness result under polynomial-time reductions allowing calls to such an approximation algorithm would therefore imply \(\mathrm{P}=\mathrm{NP}\).
