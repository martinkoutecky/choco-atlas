The continuous mirror question, as graded

Given a finite core graph \(G[C]\) with thresholds \(\theta_c\), and peripheral types \(i\in[r]\) with rational masses \(\mu_i\), common neighborhoods \(A_i\subseteq C\), thresholds \(\theta_i\), and no edges among peripheral agents, choose core seed bits \(z_c\in\{0,1\}\) and seeded masses \(x_i\in[0,\mu_i]\) minimizing \(\sum_{c\in C}z_c+\sum_i x_i\). Under irreversible threshold diffusion, core vertices count active core neighbors as one each and active peripheral neighbors by mass; unseeded mass of type \(i\) activates once at least \(\theta_i\) vertices in \(A_i\) are active. What is the exact minimum seed cost needed to activate the entire population, and can it be computed with fixed-parameter dependence on \(|C|\) and polynomial dependence on the number of types and input bit length?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts listed types, not possible types. There are \(m=|C|\) distinguished core types, each an indivisible vertex of mass one, and \(r=\tau-m\) divisible peripheral types.
The core graph \(G[C]\) is finite, simple and undirected. Peripheral type \(i\) has mass \(\mu_i>0\) and neighborhood \(A_i\subseteq C\); there are no peripheral edges. Masses are not normalized. Thresholds are positive integers satisfying \(\theta_i\leq |A_i|\) and \(\theta_c\leq |N_{G[C]}(c)|+\sum_{i:c\in A_i}\mu_i\).
Choose seeds \(z_c\in\{0,1\}\) and \(x_i\in[0,\mu_i]\), with real divisible masses \(x_i\), at cost \(\sum_c z_c+\sum_i x_i\). Initially exactly these seeds are active.
Diffusion is irreversible and synchronous. In each round, an inactive core vertex \(c\) activates if its active core neighbors plus the active mass of peripheral types adjacent to \(c\), measured at the preceding round, total at least \(\theta_c\). All remaining mass of type \(i\) activates if at least \(\theta_i\) vertices of \(A_i\) were active at the preceding round. Equality triggers activation.
Let \(\operatorname{OPT}\) be the minimum seed cost that eventually activates every core vertex and all peripheral mass. The input includes a nonnegative binary rational budget \(B\); \(L\) is the total input bit length.

Is deciding \(\operatorname{OPT}\leq B\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?
If it is NP-hard, can \(\operatorname{OPT}\) nevertheless be computed exactly in time \(f(m)\operatorname{poly}(m,\tau,L)\) for some computable \(f\)?

Discrete Target Set Selection admits exact optimization in \(2^{O(t\log t)}n^{O(1)}\) time, where \(t\) is minimum vertex cover size ([Banerjee–Mathew–Panolan](https://arxiv.org/abs/1812.01482)).
It is NP-hard even on bounded-degree bipartite graphs with thresholds at most two ([Chen](https://www.lamsade.dauphine.fr/~bazgan/ChenSIAM.pdf)), and \(\mathrm{W}[1]\)-hard parameterized by neighborhood diversity ([Dvořák–Knop–Toufar](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ISAAC.2018.18)); the latter uses a different parameter from vertex cover.
No result settling this precise hybrid mass model was located in the literature search.

  • Threshold domains were unspecified; retained positive integers from the discrete definition.
  • Carried over the vertex-cover algorithm's threshold-at-most-degree restriction, using total incident mass for core vertices and neighborhood cardinality for peripheral types; peripheral neighborhoods are consequently nonempty.
  • Mass normalization was unspecified; used arbitrary positive rational masses without normalization, preserving the unit mass and cost of each core vertex.
  • Made the support convention explicit by counting each distinguished core vertex as a separate indivisible type of mass one, so tau=m+r.

Result

The budget decision problem is \(\mathrm{NP}\)-complete. Nevertheless, \(\operatorname{OPT}\) can be computed exactly in time

\(2^{O(m\log(m+1))}\operatorname{poly}(m,\tau,L)\).

Hardness holds even when the core graph is edgeless, every peripheral mass is one, and every peripheral threshold is one.

The [cited discrete algorithm](https://arxiv.org/abs/1812.01482) concerns indivisible vertices. The proof below establishes the hybrid result directly using rational linear programming.

1. NP-hardness with an edgeless core

The case \(r=0\) already contains ordinary Target Set Selection. We prove hardness for a restriction with genuinely divisible peripheral types.

Reduce from the standard \(\mathrm{NP}\)-complete Vertex Cover problem. Let \(H=(V,E)\) be a finite simple undirected graph without isolated vertices. This restriction preserves hardness: deleting isolated vertices does not change the minimum vertex-cover size.

Construct the following society:

  • The core is \(C=V\), with no core edges.
  • For every edge \(e=\{u,v\}\), introduce one peripheral type with \(\mu_e=1\), \(A_e=\{u,v\}\), and \(\theta_e=1\).
  • Give core vertex \(v\) threshold \(\theta_v=d_H(v)\).

All input requirements hold. Core thresholds are positive, and the total peripheral mass adjacent to \(v\) is exactly \(d_H(v)\). Peripheral thresholds satisfy \(1\leq |A_e|=2\). The support has \(\tau=|V|+|E|\) listed types.

We prove that this society satisfies

\(\operatorname{OPT}=\operatorname{vc}(H)\),

where \(\operatorname{vc}(H)\) denotes the minimum vertex-cover size.

Upper bound

Let \(Q\subseteq V\) be a vertex cover. Seed precisely the core vertices in \(Q\), and set every peripheral seed mass to zero.

Every peripheral type has a seeded endpoint, so all peripheral mass activates in round one. Every remaining core vertex then receives its full adjacent mass \(d_H(v)\) and activates in round two. Thus

\(\operatorname{OPT}\leq |Q|\),

and minimizing over \(Q\) gives \(\operatorname{OPT}\leq\operatorname{vc}(H)\).

Lower bound, including fractional seeds

Consider any successful seed choice. Let

\(S=\{v\in V:z_v=1\}\quad\text{and}\quad F=\{e\in E:x_e=1\}\).

We claim that every edge either has an endpoint in \(S\) or belongs to \(F\).

Take an edge \(e=\{u,v\}\) with neither endpoint seeded. Let \(t\) be the first round in which either endpoint activates. Before round \(t\), neither endpoint is active. Therefore peripheral type \(e\) has not activated its remaining mass; its active mass in round \(t-1\) is exactly \(x_e\).

Suppose endpoint \(w\) activates in round \(t\). Its threshold is \(d_H(w)\). It has exactly \(d_H(w)\) adjacent peripheral types, each contributing at most one. Consequently, reaching its threshold requires every adjacent type to contribute one. In particular, \(x_e=1\), proving the claim.

Starting with \(S\), add one endpoint of each edge not already covered by \(S\). Every such edge belongs to \(F\), so this produces a vertex cover of size at most \(|S|+|F|\). Hence

\(\operatorname{vc}(H)\leq |S|+|F|\leq |S|+\sum_{e\in E}x_e\).

The last expression is the seed cost. Since the successful choice was arbitrary,

\(\operatorname{vc}(H)\leq\operatorname{OPT}\).

This proves the equality. Using the Vertex Cover budget as \(B\) gives a polynomial-time reduction and establishes \(\mathrm{NP}\)-hardness.

2. Linear programs indexed by core activation orders

We now treat arbitrary instances, including arbitrary binary rational masses.

Write \(N_C(c)\) for the core neighbors of \(c\). Fix:

  • a set \(S\subseteq C\) of seeded core vertices;
  • a permutation \(\pi=(v_1,\ldots,v_k)\) of \(C\setminus S\), where \(k=m-|S|\).

For each position \(j\), define

\(P_j=S\cup\{v_1,\ldots,v_{j-1}\}\),

and let

\(H_j=\{i:|A_i\cap P_j|\geq\theta_i\}\).

Thus \(H_j\) consists of peripheral types that can activate fully once all cores in \(P_j\) are active.

Associate with \((S,\pi)\) the linear program minimizing \(\sum_{i=1}^{r}x_i\), subject to the bounds

\(0\leq x_i\leq\mu_i\qquad(1\leq i\leq r)\),

and, for every \(j\),

\[ |N_C(v_j)\cap P_j| +\sum_{\substack{i\in H_j\\v_j\in A_i}}\mu_i +\sum_{\substack{i\notin H_j\\v_j\in A_i}}x_i \geq\theta_{v_j}. \]

Here and below, this displayed expression is simply a linear inequality in the seed variables: its first two terms are constants.

Let \(\lambda(S,\pi)\) denote its minimum objective value, with value \(+\infty\) when it is infeasible.

We prove the exact characterization

\(\operatorname{OPT}=\min_{S,\pi}\bigl(|S|+\lambda(S,\pi)\bigr)\).

3. Proof of the characterization

Feasible linear programs guarantee successful synchronous diffusion

Suppose \(x\) is feasible for the program associated with \((S,\pi)\). Seed the cores in \(S\) and peripheral masses \(x_i\).

We prove inductively that each \(v_j\) eventually activates.

The cores in \(S\) are active initially. Suppose all cores in \(P_j\) are active by some round \(T\). Every type in \(H_j\) then has at least its required number of active core neighbors in round \(T\), so its full mass is active by round \(T+1\).

At round \(T+1\):

  • the core neighbors in \(N_C(v_j)\cap P_j\) are active;
  • each adjacent peripheral type in \(H_j\) contributes \(\mu_i\);
  • every other adjacent peripheral type contributes at least its persistent seed mass \(x_i\).

The linear-program inequality therefore ensures that \(v_j\) is active by round \(T+2\), unless it activated earlier. This completes the induction.

Once every core is active, every peripheral type activates fully in the next round because \(\theta_i\leq |A_i|\). Hence the seed choice is successful, with cost \(|S|+\sum_i x_i\).

This argument uses the actual synchronous process; it does not assume asynchronous updates.

Every successful seed choice satisfies one of the linear programs

Conversely, consider any successful seed choice, allowing real seed masses. Let \(S\) be its seeded core set. Order the other core vertices by their actual activation rounds, breaking ties arbitrarily, obtaining \(\pi=(v_1,\ldots,v_k)\).

Fix \(j\), and let \(t_j\) be the activation round of \(v_j\). Every core active in round \(t_j-1\) belongs to \(P_j\).

Consider a peripheral type \(i\notin H_j\). If \(x_i=\mu_i\), its active mass is already \(x_i\). Otherwise, suppose its remaining mass had activated by round \(t_j-1\). Its activation rule would imply that at least \(\theta_i\) vertices of \(A_i\) were active in an earlier round. All those cores belong to \(P_j\), contradicting \(i\notin H_j\).

Thus every type outside \(H_j\) contributes exactly \(x_i\) in round \(t_j-1\). A type in \(H_j\) contributes at most \(\mu_i\). Consequently, the actual support that activated \(v_j\) is at most

\[ |N_C(v_j)\cap P_j| +\sum_{\substack{i\in H_j\\v_j\in A_i}}\mu_i +\sum_{\substack{i\notin H_j\\v_j\in A_i}}x_i. \]

Since the actual support reached \(\theta_{v_j}\), the corresponding linear-program inequality holds. This applies to every \(j\), so the successful seed vector is feasible for this program.

Attainment of the optimum

Each feasible program has a closed, bounded feasible set, because \(0\leq x_i\leq\mu_i\). Its linear objective therefore attains a minimum.

There are finitely many choices of \((S,\pi)\), and at least one is feasible: choose \(S=C\), with no activation-order constraints and all peripheral seed masses zero.

The two directions above show both the stated characterization and that the original minimum is attained.

4. Exact fixed-parameter algorithm

Enumerate every \(S\subseteq C\) and every permutation of \(C\setminus S\). For each choice, build and solve its rational linear program, then return the least value \(|S|+\lambda(S,\pi)\).

The number of programs is at most

\(2^m m!=2^{O(m\log(m+1))}\).

Each program has \(r\) variables and \(2r+k\) inequalities. Its coefficients are integers of bounded magnitude; its right-hand sides are integers minus sums of input rational masses. These sums have polynomial encoding length. For example, taking the product of all input mass denominators gives a common denominator whose binary length is at most the total denominator encoding length.

We use the standard bit-complexity theorem for rational linear programming: feasibility and optimization can be performed in time polynomial in the rational input encoding length, with an exact rational optimum returned for a nonempty bounded feasible region. The hypotheses hold here because every feasible region lies in the bounded box \(\prod_i[0,\mu_i]\).

Building and solving one program therefore takes \(\operatorname{poly}(m,\tau,L)\) time. The total running time is

\(2^{O(m\log(m+1))}\operatorname{poly}(m,\tau,L)\).

The algorithm uses one variable per listed peripheral type. It does not expand masses into individual vertices or enumerate unlisted possible types.

5. Membership in NP

The presence of real seed variables does not prevent polynomial-length certificates.

If a successful real seed choice has cost at most \(B\), Section 3 places it in one of the rational linear programs. That program has an optimal vertex whose objective is no larger.

Such a vertex has polynomial-length rational coordinates. To verify this explicitly, suppose \(r>0\). A vertex is determined by \(r\) linearly independent tight inequalities, written as \(Ax=b\). The entries of \(A\) belong to \(\{-1,0,1\}\). Let \(D\) be the product of the input mass denominators. Then \(Db\) is integral, with polynomial binary length.

Cramer’s rule expresses each coordinate as

\(x_\ell=\dfrac{\det A_\ell}{D\det A}\),

where \(A_\ell\) replaces column \(\ell\) of \(A\) by \(Db\). If \(M=\max(1,\max_j|(Db)_j|)\), determinant expansion gives

\(|\det A|\leq r!\quad\text{and}\quad|\det A_\ell|\leq r!M\).

Thus all coordinates have polynomial binary length. The case \(r=0\) requires no mass coordinates.

A certificate consists of \(S\), the permutation \(\pi\), and these rational seed masses. A verifier checks the box constraints, all activation-order inequalities, and the budget inequality

\(|S|+\sum_i x_i\leq B\).

All checks use polynomial-time exact rational arithmetic. Section 3 proves that every accepted certificate guarantees successful synchronous diffusion. Therefore the decision problem belongs to \(\mathrm{NP}\), and together with Section 1 it is \(\mathrm{NP}\)-complete.
