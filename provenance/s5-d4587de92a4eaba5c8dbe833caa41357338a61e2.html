The continuous mirror question, as graded

Given rational buyer-type masses μ_b summing to \(1\), rational per-capita supplies \(q_i\) summing to \(1\), and rational valuations \(v_{bi}\), find a componentwise least price vector \(p\) satisfying the listed lattice-linear price constraints, together with an allocation \(y_{bi}\geq 0\) such that \(\sum_i y_{bi}=μ_b\), \(\sum_b y_{bi}=q_i\), and \(y_{bi}>0\) only when item type \(i\) maximizes \(v_{bi}-p_i\) for type \(b\); report infeasibility if no such price and allocation exist.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of the \(\tau\) buyer types with positive masses \(\mu_b\), each encoded as a binary rational, with \(\sum_b\mu_b=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) item types with positive binary rational supplies \(q_i\), where \(\sum_iq_i=1\), and nonnegative binary rational valuations \(v_{bi}\). Set \(T_i=\max_bv_{bi}\); prices range over \(0\leq p_i\leq T_i\).
The input includes \(k\) price constraints, each of the form \(p_i\geq p_j\) or \(p_i-p_j\leq d\), with binary rational \(d\geq0\). Equality and absolute difference bounds may be expressed by pairs of these constraints.
A price is feasible if it satisfies all constraints and admits an allocation \(y_{bi}\geq0\) with \(\sum_i y_{bi}=\mu_b\), \(\sum_b y_{bi}=q_i\), and \(y_{bi}>0\Rightarrow i\in\operatorname*{arg\,max}_j(v_{bj}-p_j)\). Ties permit splitting mass; every buyer receives one unit per capita, with no outside option.
Find a componentwise least feasible price \(p^*\), meaning \(p_i^*\leq p_i\) for every feasible price \(p\) and every \(i\), together with an allocation witnessing feasibility; report infeasibility if the feasible set is empty.

Is this computational problem solvable in polynomial time in \(m,\tau,k,L\), where \(L\) is the total binary input length, or is it NP-hard?

For finite societies with equally many indivisible items and bidders, lattice-linear predicate detection finds the least feasible bounded price when valid advancement steps have a positive uniform minimum \(\varepsilon\); its iteration bound is \(\sum_i\lceil T_i/\varepsilon\rceil\), which need not be polynomial in binary input length. The corresponding constrained auction algorithm is also given in the [published treatment](https://users.ece.utexas.edu/~garg/dist/garg-spaa20.pdf).
No result settling this precise mass problem was identified in the literature search.

Modeling choices made when packaging the task

  • The graded question omitted valuation signs and price bounds; use nonnegative valuations and the discrete algorithm's bounds 0 <= p_i <= max_b v_bi.
  • No constraint encoding was specified; use an explicit finite list of the price comparisons and difference bounds described for the market problem, rather than an unspecified predicate oracle.
  • Supplies are positive for every listed item type, matching the presence of an actual item in every discrete price coordinate.
  • Utility ties permit splitting mass among maximizers, and there is no outside option, matching the discrete perfect-matching definition.

Result

The problem is solvable in polynomial time in \(m,\tau,k,L\). Whenever the feasible set is nonempty, it has a componentwise least price. An exact algorithm computes that price and a witnessing allocation using one transportation linear program followed by a difference-constraint calculation.

The key fact is that every feasible price supports any fixed welfare-maximizing allocation. Thus, after computing one such allocation, the allocation-dependent demand conditions become ordinary linear difference inequalities.

1. Fixing one optimal allocation captures all feasible prices

Let \(\mathcal Y\) be the set of allocations satisfying the prescribed marginals:

\( \mathcal Y=\left\{y\in\mathbb R_{\geq0}^{\tau\times m}:\ \sum_i y_{bi}=\mu_b\text{ for every }b,\ \sum_b y_{bi}=q_i\text{ for every }i\right\}. \)

Define welfare by

\( W(y)=\sum_{b,i}v_{bi}y_{bi}. \)

The set \(\mathcal Y\) is nonempty: \(y_{bi}=\mu_bq_i\) satisfies both sets of marginal equations because \(\sum_b\mu_b=\sum_iq_i=1\). It is closed and bounded, since every entry lies between \(0\) and \(1\). Consequently, the transportation linear program

\( \max_{y\in\mathcal Y}W(y) \)

has an optimum. Fix an optimal allocation \(\bar y\).

Lemma. A price vector \(p\) admits an allocation satisfying the demand condition if and only if

\( p_j\geq p_i+v_{bj}-v_{bi}\qquad\text{for every }(b,i)\text{ with }\bar y_{bi}>0,\text{ and every }j. \)

Proof. For any price vector \(p\), define

\( u_b(p)=\max_j(v_{bj}-p_j),\qquad G(p)=\sum_b\mu_bu_b(p)+\sum_iq_ip_i. \)

The values \(u_b(p)\) may be negative; this is consistent with the absence of an outside option.

For every \(z\in\mathcal Y\), the marginal equations give

\( G(p)-W(z)=\sum_{b,i}z_{bi}\bigl(u_b(p)+p_i-v_{bi}\bigr)\geq0. \)

Indeed, each summand is nonnegative because \(u_b(p)\geq v_{bi}-p_i\).

Suppose \(p\) admits a demand-respecting allocation \(y\). Whenever \(y_{bi}>0\), the demand condition gives \(u_b(p)=v_{bi}-p_i\). Hence the preceding identity yields \(G(p)=W(y)\). Since \(W(z)\leq G(p)\) for every \(z\in\mathcal Y\), the allocation \(y\) maximizes welfare. Therefore,

\( W(\bar y)=W(y)=G(p). \)

Applying the identity to \(\bar y\), we obtain

\( 0=\sum_{b,i}\bar y_{bi}\bigl(u_b(p)+p_i-v_{bi}\bigr). \)

All summands are nonnegative. Thus \(\bar y_{bi}>0\) implies \(u_b(p)=v_{bi}-p_i\), and consequently

\( v_{bi}-p_i\geq v_{bj}-p_j \)

for every \(j\). Rearranging gives the asserted inequalities.

Conversely, those inequalities say exactly that every item \(i\) with \(\bar y_{bi}>0\) maximizes \(v_{bj}-p_j\). Since \(\bar y\) already has the required marginals, it witnesses the demand condition. This proves the lemma.

Consequently, the original feasible-price set is exactly the set satisfying the lemma’s inequalities, the input price constraints, and the box bounds. No choice among alternative optimal allocations is necessary.

2. Difference constraints have a least nonnegative solution

Construct a directed weighted graph on the item set. An edge \(a\to c\) of weight \(w\) represents

\( p_c\geq p_a+w. \)

Use the following edges:

| Source of inequality | Edge | Weight |
|---|---|---|
| \(\bar y_{bi}>0\), comparing item \(i\) with item \(j\) | \(i\to j\) | \(v_{bj}-v_{bi}\) |
| Input constraint \(p_i\geq p_j\) | \(j\to i\) | \(0\) |
| Input constraint \(p_i-p_j\leq d\) | \(i\to j\) | \(-d\) |

For now, impose nonnegativity and these edge inequalities; check the upper bounds afterward.

A directed cycle of strictly positive total weight makes the edge inequalities infeasible. Summing its inequalities gives \(p_a\geq p_a+c\) with \(c>0\), a contradiction.

Suppose there is no positive-weight directed cycle. For each item \(i\), define \(D_i\) to be the maximum weight of a directed walk ending at \(i\), starting at any item. Include the walk of length zero, with weight zero.

These maxima are finite and attained. To see this, whenever a walk repeats a vertex, its intervening closed subwalk has nonpositive weight: every closed walk decomposes into directed cycles, all of which have nonpositive weight. Removing that subwalk preserves the endpoint and does not decrease the weight. Repeating this removal leaves a simple path, containing at most \(m-1\) edges.

Proposition. The vector \(D\) is the componentwise least nonnegative solution of the edge inequalities.

Proof. Length-zero walks give \(D_i\geq0\). For an edge \(a\to c\) of weight \(w\), append that edge to a walk attaining \(D_a\). By the definition of \(D_c\),

\( D_c\geq D_a+w. \)

Thus \(D\) satisfies every edge inequality.

Now let \(p\) be any nonnegative solution. Along a walk from \(a\) to \(i\) with total weight \(w\), repeated application of the edge inequalities gives

\( p_i\geq p_a+w\geq w. \)

Taking the maximum over all such walks proves \(p_i\geq D_i\) for every \(i\).

It follows that the original instance is infeasible precisely when either:

  • the graph contains a positive-weight directed cycle; or
  • there is no such cycle, but \(D_i>T_i\) for some item \(i\).

For the second case, every feasible price would satisfy \(p_i\geq D_i>T_i\).

Otherwise, \(D\) satisfies the box bounds and every required difference inequality. The lemma shows that \(\bar y\) witnesses its feasibility. Moreover, every feasible price dominates \(D\). Hence the required output is

\( p^*=D,\qquad y^*=\bar y. \)

This also covers \(m=1\) and items with \(T_i=0\).

3. Exact polynomial-time implementation

The only general optimization theorem needed is the standard rational linear-programming theorem: an LP with rational data can be solved in time polynomial in its binary encoding length, returning an exact rational optimum when the feasible region is nonempty and the optimum is finite. Polynomial-time solvability and polynomial-size rational solutions are covered in [these CMU linear-programming notes](https://www.cs.cmu.edu/~odonnell/toolkit13/lecture13.pdf).

Here its hypotheses hold: the transportation LP has rational data, \(\tau m\) variables, \(\tau+m\) marginal equations, and a nonempty bounded feasible region. Its encoding length is polynomial in the given input length. Compute an exact rational optimum \(\bar y\), so testing \(\bar y_{bi}>0\) requires no numerical tolerance.

The resulting graph has at most

\( E\leq\tau m^2+k \)

edges. Its weights are input rationals or differences of two input valuations, so their binary lengths are polynomial in \(L\).

For completeness, the graph calculation can be implemented with a fixed number of synchronous relaxation rounds. Initialize \(D_i^{(0)}=0\), and set

\( D_i^{(r+1)}=\max\left(\{D_i^{(r)}\}\cup\{D_a^{(r)}+w:\ a\to i\text{ is an edge of weight }w\}\right). \)

By induction, \(D_i^{(r)}\) is the maximum weight of a walk of at most \(r\) edges ending at \(i\), with an arbitrary starting item.

Compute through round \(m\).

  • If \(D^{(m)}\neq D^{(m-1)}\), report infeasibility. Without positive cycles, the path-removal argument above would make all maxima attainable within \(m-1\) edges, so an improvement is impossible.
  • Otherwise, set \(D=D^{(m-1)}\). Equality between these rounds means that \(D\) satisfies every edge inequality, because the update leaves every coordinate unchanged.
  • Check \(D_i\leq T_i\) for every item. If these checks pass, return \((D,\bar y)\); otherwise report infeasibility.

The relaxation phase uses \(O(m(E+m))\) exact rational arithmetic operations. Every intermediate coordinate is the weight of a walk containing at most \(m\) edges, hence a sum of at most \(m\) polynomial-length rational numbers. Such sums have polynomial binary length: a common denominator can be taken as the product of those denominators, whose bit lengths add. Thus the arithmetic, comparisons, and output lengths are all polynomially bounded.

The complete algorithm therefore runs in polynomial time in \(m,\tau,k,L\).

4. Relation to the auction iteration bound

The uniform-increment bound in Theorem 2.5 of the [published treatment](https://users.ece.utexas.edu/~garg/dist/garg-spaa20.pdf) is not needed here. Fixing a welfare optimum converts demand feasibility into difference constraints, whose least solution is computed by a number of relaxation rounds bounded by \(m\), independently of price magnitudes or a minimum positive increment.
