The continuous mirror question, as graded

Fix \(k\ge3\). Given a finite set \(T\) of complete patient-donor types, a type-level directed compatibility relation \(A\subseteq T\times T\), and rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), compute the maximum total mass that can be assigned to vertex-disjoint exchange cycles of lengths at most \(k\). Equivalently, choose \(x_p\ge0\) for every compatible cyclic type pattern \(p\) of length \(2\le |p|\le k\), subject to \(\sum_p a_{p,t}x_p\le\mu_t\) for each \(t\in T\), maximizing \(\sum_p |p|x_p\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) patient–donor types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Compatibility is specified explicitly by \(A\subseteq T\times T\): a donor of type \(s\) can donate to a patient of type \(t\) exactly when \((s,t)\in A\). Let \(m=|A|\) and let \(L\) be the total binary input length.
Fix an integer \(k\ge3\). Let \(\mathcal P\) contain the cyclic type sequences \(p=(t_1,\ldots,t_\ell)\), up to rotation, with \(2\le\ell\le k\) and \((t_i,t_{i+1})\in A\), using \(t_{\ell+1}=t_1\). Types may repeat; occurrences represent distinct participants. Diagonal compatibility permits donations between distinct participants of the same type, never a singleton exchange.
Write \(a_{p,t}\) for the number of occurrences of \(t\) in \(p\). Mass is divisible: choose real \(x_p\ge0\) subject to \(\sum_{p\in\mathcal P}a_{p,t}x_p\le\mu_t\) for every \(t\). Unused mass is allowed. The objective is \(\operatorname{OPT}=\max\sum_{p\in\mathcal P}|p|x_p\).

For each fixed \(k\ge3\), is computing \(\operatorname{OPT}\) exactly solvable in polynomial time in \(m,\tau,L\), or is it NP-hard? State running times in \(m,\tau,L\) and \(k\).

For finite individual societies represented by simple directed graphs, maximizing the number of vertices covered by vertex-disjoint directed cycles of lengths between \(2\) and \(k\) is APX-complete, hence NP-hard, for every fixed \(k\ge3\) (Biró, Manlove and Rizzi, 2009).

Modeling choices made when packaging the task

  • Discard zero-mass types so that the supplied list is exactly the positive-mass support.
  • Interpret cyclic type patterns as sequences that may repeat types, since distinct individual participants may share a type; define capacity consumption by occurrence multiplicity.
  • Allow diagonal type compatibility to describe donations between distinct participants of the same type, while excluding length-one exchanges.
  • Define m as the number of explicitly supplied compatibility arcs and L as the total binary input length.

Result

Computing \(\operatorname{OPT}\) exactly is polynomial-time solvable for every fixed \(k\ge3\).

In fact, define \(h=\min\{k,\max\{2,\tau\}\}\). An exact algorithm runs in
\[ \bigl(L+\log k+h\tau(m+\tau)\bigr)^{O(1)} \]
bit operations, with an absolute constant exponent. Thus the problem remains polynomial-time solvable when \(k\) is supplied in binary.

The proof constructs a polynomial-size rational linear program whose optimum equals the stated fractional exchange optimum.

1. Reducing the effective length bound

Write \(\operatorname{OPT}_j\) for the optimum with maximum exchange length \(j\). We first prove \(\operatorname{OPT}_k=\operatorname{OPT}_h\).

Every permitted type sequence is a directed closed walk. Its edge occurrences can be partitioned into directed simple cycles, including loops of length one. Here a simple cycle has no repeated vertex except its closing vertex.

To justify the partition, take a shortest nonempty closed subwalk. It has no repeated internal vertex, since such a repetition would give a shorter nonempty closed subwalk. Remove its edge occurrences and splice the remaining walk at its coinciding endpoints. Repeat until no edges remain.

This partition preserves the number of occurrences of every type: each occurrence is counted as the tail of one edge.

If \(h=k\), there is nothing to prove. Otherwise, every simple cycle of length at least two has length at most \(\tau\le h\). For a loop at type \(t\), diagonal compatibility holds, so \((t,t)\) is a permitted length-two sequence. A loop component carrying weight \(x\) can be replaced by this sequence carrying weight \(x/2\). Both consume mass \(x\) of type \(t\) and contribute \(x\) to the objective.

Consequently, replacing every exchange by these components preserves all type consumption and the objective, while using only lengths between two and \(h\). This proves \(\operatorname{OPT}_k\le\operatorname{OPT}_h\). The reverse inequality follows from \(h\le k\).

2. A compact linear program

For each starting type \(s\in T\), construct a separate directed graph \(D_s\). Its vertices are a source \(r_s\), a sink \(b_s\), and vertices \((i,t)\) for \(1\le i\le h\) and \(t\in T\).

Add the following arcs:

  • For each \((s,t)\in A\), add \(r_s\to(1,t)\).
  • For each \(1\le i<h\) and \((u,v)\in A\), add \((i,u)\to(i+1,v)\).
  • For each \(2\le i\le h\), add \((i,s)\to b_s\).

Call the first two kinds compatibility arcs, and the third kind exit arcs. Label a source compatibility arc by \(s\), and an arc \((i,u)\to(i+1,v)\) by \(u\). These labels identify the participant mass consumed by the arcs.

The graph \(D_s\) is acyclic: compatibility arcs strictly increase the layer, and the sink has no outgoing arcs.

Introduce a nonnegative flow variable \(f_e^s\) for every arc \(e\) of \(D_s\). At every vertex other than the source and sink, impose flow conservation:
\[ \sum_{e\in\delta^-(v)}f_e^s = \sum_{e\in\delta^+(v)}f_e^s. \]

Let \(C_s\) denote the compatibility arcs of \(D_s\), and let \(\lambda(e)\) be their labels. Impose the shared type capacities
\[ \sum_{s\in T}\ \sum_{\substack{e\in C_s\\\lambda(e)=t}}f_e^s \le\mu_t \qquad(t\in T). \]

Maximize
\[ \sum_{s\in T}\sum_{e\in C_s}f_e^s. \]

No prescribed source supply is imposed; the program chooses how much exchange mass to send.

3. Proof of exact equivalence

Exchanges produce feasible flows

Consider an exchange \(p=(t_1,\ldots,t_\ell)\), where \(2\le\ell\le h\). Choose its representative starting at \(s=t_1\). It gives the path
\[ r_s\to(1,t_2)\to\cdots\to(\ell-1,t_\ell) \to(\ell,s)\to b_s. \]

Every compatibility arc exists by the definition of \(p\), and the final exit exists because \(\ell\ge2\).

Sending flow \(x_p\) along this path consumes \(a_{p,t}x_p\) of type \(t\): the compatibility-arc labels, in order, are exactly \(t_1,\ldots,t_\ell\). Its objective contribution is \(\ell x_p\).

Superposing these paths for all exchanges therefore gives a feasible flow with the same objective. Hence the flow optimum is at least \(\operatorname{OPT}_h\).

Feasible flows produce exchanges

Every nonnegative flow in \(D_s\) satisfying the internal conservation equations decomposes into nonnegative source-to-sink path flows.

For completeness, start with any positive-flow arc. Following positive-flow predecessors must reach the source: conservation prevents stopping at an internal vertex, and acyclicity prevents infinite continuation. Likewise, following positive-flow successors reaches the sink. Subtract the minimum flow on the resulting path. At least one positive-flow arc disappears, so repeating this procedure terminates after finitely many steps and decomposes the whole flow.

Every resulting path exits at some \((\ell,s)\), where \(2\le\ell\le h\). Its \(\ell\) compatibility arcs describe a directed closed walk starting and ending at \(s\), hence a permitted cyclic type sequence. Repeated types are allowed by the task.

For a path of weight \(w\), its compatibility labels give precisely the sequence’s occurrence counts. Thus replacing the path by an exchange of weight \(w\) preserves every type’s consumption and the objective contribution \(\ell w\). If several paths describe rotations of the same sequence, their weights can simply be added.

The resulting exchange assignment is feasible. Therefore the flow optimum is at most \(\operatorname{OPT}_h\), proving equality.

In particular, no singleton exchange is introduced: exits begin at layer two. Diagonal compatibility correctly allows paths representing \((t,t)\).

4. Size, exact arithmetic, and running time

Across all starting types, the number of compatibility arcs is
\[ m+(h-1)\tau m, \]
and the number of exit arcs is \((h-1)\tau\). The linear program therefore has \(O(h\tau(m+1))\) variables, \(h\tau^2\) conservation equations, and \(\tau\) mass inequalities, besides nonnegativity constraints.

Its matrix coefficients belong to \(\{-1,0,1\}\), its objective coefficients belong to \(\{0,1\}\), and its only nonzero right-hand sides are the given rational masses. Its complete binary description consequently has length polynomial in \(L+h\tau(m+\tau)\).

The zero flow is feasible. Summing the mass inequalities bounds the objective by \(\sum_t\mu_t=1\). Moreover, each compatibility-arc flow is at most one; conservation bounds each exit-arc flow by the sum of compatibility-arc flows, also at most one. Thus the feasible set is nonempty and bounded.

The standard rational linear programming theorem computes an exact optimal rational value in time polynomial in the binary description length; this is an exact optimization guarantee, not merely an approximation guarantee. See [Grötschel, Lovász and Schrijver, *The ellipsoid method and its consequences in combinatorial optimization*](https://www.zib.de/userpage/groetschel/pubnew/paper/groetschellovaszschrijver1981a.pdf).

All its hypotheses hold here: the program is explicitly represented, rational, feasible, and bounded. Applying it proves the claimed bit running time
\[ \bigl(L+\log k+h\tau(m+\tau)\bigr)^{O(1)}. \]

For fixed \(k\), this is polynomial in \(m,\tau,L\). Since \(h\le\max\{2,\tau\}\), it is also polynomial in the input length when \(k\) is variable.

5. Why the finite-society hardness does not transfer

The supplied APX-completeness result concerns indivisible vertices and vertex-disjoint cycles. Here the exchange weights are arbitrary nonnegative real numbers.

For example, assigning each vertex of an individual society its own type and mass \(1/\tau\) yields a fractional packing problem. An individual-society solution would additionally require each exchange weight to be an integer multiple of \(1/\tau\). Those integrality restrictions are absent from the stated problem.

The linear program above solves exactly the divisible-mass problem, so the finite-society hardness result presents no contradiction.
