The continuous mirror question, as graded

Given a finite-support rational distribution μ over complete tree or \(1\)-bounded CP-net types on fixed binary attributes, choose for each attribute an input CPT minimizing weighted swap disagreement and assemble them into an aggregate CP-net \hat N. Does \(D_μ(\hat N)≤(4/3)\mathrm{OPT}_μ\), where \(D_μ(N)=\sum_M μ_M f_\mathrm{swap}(N,M)\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types; masses satisfy \(\sum_M\mu_M=1\). State running times in the number of attributes \(m\), support size \(\tau\), and total input bit length \(L\).
Each type is a complete CP-net on the same \(m\ge2\) binary attributes, with strict CPT preferences and at most one parent per attribute; cycles are permitted. A parent cannot be the attribute itself. Tree CP-nets are included.
A swap is an unordered pair of outcomes differing in exactly one attribute; its orientation is determined directly by that attribute's CPT. Let \(f_{\mathrm{swap},j}(N,M)\) count swaps of attribute \(j\) oriented differently by \(N\) and \(M\), and let \(f_{\mathrm{swap}}=\sum_{j=1}^m f_{\mathrm{swap},j}\).
Define \(D_\mu(N)=\sum_M\mu_M f_{\mathrm{swap}}(N,M)\) and \(\mathrm{OPT}_\mu=\min_N D_\mu(N)\), where the minimum ranges over all complete CP-nets on these attributes, allowing arbitrary parent sets and cycles.
For each attribute \(j\), choose a CPT occurring at that attribute in the support that minimizes \(\sum_M\mu_M f_{\mathrm{swap},j}(N,M)\), and assemble the chosen CPTs into \(\widehat N\). Ties may be resolved arbitrarily; the assembled graph need not be a tree or acyclic.
Does this rule run in time polynomial in \(m,\tau,L\) and guarantee \(D_\mu(\widehat N)\le\frac{4}{3}\mathrm{OPT}_\mu\) for every such society and every minimizing tie choice?
For finite multisets of complete \(1\)-bounded CP-nets, choosing the best input CPT independently at each attribute gives a polynomial-time \(\frac{4}{3}\)-approximation; the bound is tight. [Ali, Ogundare, Yang and Zilles (2025)](https://ifaamas.csc.liv.ac.uk/Proceedings/aamas2025/pdfs/p78.pdf)
No separately stated guarantee for binary-rational mass inputs was located in the literature search.

1. Result

Yes. The rule guarantees \(D_\mu(\widehat N)\le \frac43\mathrm{OPT}_\mu\) for every minimizing tie choice. With standard binary encoding of rational numerators and denominators, a conservative running-time bound is \(O\!\left(L+m\tau^2(L+m)^2\right)\) bit operations.

The approximation guarantee follows by exact scaling from the multiset theorem; the algorithm operates directly on the weighted support.

2. Separating the attributes

For a CPT \(C\) at attribute \(j\), let \(\delta_j(C,C')\) be the number of attribute-\(j\) swaps on which \(C\) and \(C'\) disagree. Write \(C_{M,j}\) for the CPT of type \(M\), and define

\(d_j(C)=\sum_M\mu_M\delta_j(C,C_{M,j}),\qquad o_j=\min_C d_j(C),\)

where the minimum permits every parent set excluding \(j\).

Each assignment to the other \(m-1\) attributes specifies exactly one unordered attribute-\(j\) swap. A complete CPT with all those attributes as parents can prescribe its orientation independently for every assignment. Consequently, every possible orientation function is feasible locally, and the local minimum exists.

For every complete CP-net \(N\),

\(D_\mu(N)=\sum_{j=1}^m d_j(C_{N,j})\ge \sum_{j=1}^m o_j.\)

Conversely, choose a minimizing CPT for each attribute and assemble them. This is feasible because cycles and arbitrary parent sets are allowed. Thus

\(\mathrm{OPT}_\mu=\sum_{j=1}^m o_j.\)

This argument concerns direct swap orientations only; it requires no consistency of a transitive preference relation.

3. Extending the multiset guarantee to rational masses

The local form of the known theorem is: for any nonempty finite multiset \(\mathcal P\) of complete \(1\)-bounded CPTs at one attribute,

\(\min_{C\in\mathcal P}\sum_{T\in\mathcal P}\delta_j(C,T)\le \frac43\min_C\sum_{T\in\mathcal P}\delta_j(C,T),\)

where the right-hand minimum allows arbitrary parent sets. This is the best-input-CPT guarantee established by [Ali, Ogundare, Yang and Zilles, Theorem 5.1 and its preceding formulation](https://ifaamas.csc.liv.ac.uk/Proceedings/aamas2025/pdfs/p78.pdf).

Write each positive mass as \(\mu_M=p_M/q_M\), with positive integer numerator and denominator. Set

\(Q=\prod_M q_M,\qquad a_M=p_M(Q/q_M).\)

Then \(a_M\) is a positive integer, \(a_M/Q=\mu_M\), and normalization gives \(\sum_M a_M=Q\).

For each attribute \(j\), form a *mathematical* multiset \(\mathcal P_j\) containing \(a_M\) copies of \(C_{M,j}\). For every candidate CPT \(C\), including unrestricted ones,

\(\sum_{T\in\mathcal P_j}\delta_j(C,T)=\sum_M a_M\delta_j(C,C_{M,j})=Qd_j(C).\)

Because every \(a_M\) is positive, the CPTs occurring in \(\mathcal P_j\) are exactly those occurring at attribute \(j\) in the support. Therefore

\(\min_{C\in\mathcal P_j}\sum_{T\in\mathcal P_j}\delta_j(C,T)=Q\min_{C\text{ occurring in the support}}d_j(C),\)

and the unrestricted multiset optimum equals \(Qo_j\).

All theorem hypotheses hold: the multiset is finite and nonempty, its CPTs are complete and \(1\)-bounded, and there are \(m\ge2\) binary attributes. A one-parent CPT whose rows agree can equivalently be represented as an unconditional CPT, without changing any disagreement or candidate cost. Cycles elsewhere in an input graph have no effect on the local theorem.

Applying the theorem and dividing by \(Q>0\) yields

\(d_j(\widehat C_j)\le \frac43o_j.\)

Every minimizing tie choice has this same local objective value, so the inequality holds for every such choice. If \(o_j=0\), positivity of all masses implies that a locally optimal CPT agrees with every support CPT on every swap; hence all support CPTs agree with each other and the selected cost is also zero.

Summing over attributes proves

\(D_\mu(\widehat N)=\sum_jd_j(\widehat C_j)\le \frac43\sum_jo_j=\frac43\mathrm{OPT}_\mu.\)

4. Polynomial-time implementation

The multisets above need not be constructed.

For two input CPTs \(C,C'\) at attribute \(j\), let \(P,P'\) be their parent sets and \(S=P\cup P'\). Since both CPTs are \(1\)-bounded, \(|S|\le2\). For an assignment \(x\) to \(S\), let \(b_C(x|_P)\) denote the value preferred by \(C\). Then

\(\delta_j(C,C')=2^{m-1-|S|}\sum_{x\in\{0,1\}^{S}}\mathbf1\!\left[b_C(x|_P)\ne b_{C'}(x|_{P'})\right].\)

Indeed, each assignment to \(S\) extends to exactly \(2^{m-1-|S|}\) assignments to the other attributes, and therefore to that many swaps. The formula examines at most four assignments.

Compute \(Q\) and the integers \(a_M\). For every attribute and every support candidate, compute the integer score

\(s_j(C)=\sum_M a_M\delta_j(C,C_{M,j})=Qd_j(C),\)

and select any candidate of minimum score.

There are at most \(m\tau^2\) pairwise disagreement computations and score terms. The binary length of \(Q\) is \(O(L)\), and \(a_M\le Q\). Every score is bounded by \(Q2^{m-1}\), so all score arithmetic uses \(O(L+m)\) bits.

Using schoolbook integer arithmetic, denominator preprocessing costs \(O(\tau L^2)\), and scoring and comparisons cost at most \(O\!\left(m\tau^2(L+m)^2\right)\). Including input reading gives the stated bound. The output contains only \(m\) selected input CPTs and is polynomial in size.
