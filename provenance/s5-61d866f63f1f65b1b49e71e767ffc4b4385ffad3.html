The anchor (named result in the paper)

Proposition 4 — class: algorithmic

The continuous mirror question, as graded

Given a finite support of belief types \(p_t\in\mathbb{Q}\cap[0,1]\) with rational masses \(\mu_t>0\) summing to \(1\), compute the equal-wealth parimutuel equilibrium price \(q\) for state \(1\) and a type-level allocation \(x_t\in\mathbb{R}_+^2\). Each type maximizes \(p_tx_{t,1}+(1-p_t)x_{t,2}\) subject to \(qx_{t,1}+(1-q)x_{t,2}\le1\), and market clearing requires \(\sum_t\mu_tx_t=(1,1)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list of \(\tau\) distinct belief types \(p_t\in\mathbb{Q}\cap[0,1]\), each with positive binary rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length and \(m=2\) is the number of states.
Each individual has wealth \(1\); \(x_t\) denotes consumption per individual of type \(t\), and aggregate supply is \((1,1)\).
An equilibrium consists of \(q\in[0,1]\) and \(x_t\in\mathbb{R}_{\geq0}^2\) such that \(x_t\in\operatorname*{arg\,max}_{y\in\mathbb{R}_{\geq0}^2:\ qy_1+(1-q)y_2\leq1}\{p_ty_1+(1-p_t)y_2\}\) for every \(t\), and \(\sum_t\mu_tx_t=(1,1)\).
Zero prices and endpoint beliefs are allowed. Any maximizing allocation is admissible when a type is indifferent. The computational problem is to find an exact equilibrium with rational coordinates.

Is this equilibrium computation problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For \(n\) discrete individuals with wealth \(1/n\) each, the equilibrium price is \(\operatorname{med}(p_1,\ldots,p_n,1/n,\ldots,(n-1)/n)\), yielding polynomial-time price computation ([Chambers–Echenique–Hayashi](https://arxiv.org/html/2405.01655v1)).
For finite linear Fisher markets with positive budgets and every good valued by some buyer, exact equilibrium computation has a strongly polynomial algorithm ([Végh](https://personal.lse.ac.uk/veghl/papers/vegh-quadratic.pdf)).

Modeling choices made when packaging the task

  • Made the price domain explicit as [0,1], including zero prices; retained endpoint beliefs as allowed by the discrete anchor.
  • Specified that type allocations are per-individual consumption, consistent with mass-weighted clearing and wealth 1.
  • Settled the unspecified precision requirement as exact computation of a rational equilibrium.
  • Allowed any optimal allocation at indifference, without imposing a tie-breaking rule.
  • Defined m as the fixed number of states, 2, and L as the total binary input bit length.

Result

The problem is solvable in polynomial time in \(\tau,L\), with \(m=2\). An exact equilibrium can be computed directly from the weighted support, without expanding rational masses into individual agents.

The proof below includes zero prices, endpoint beliefs, and indifferent types.

1. Characterization of equilibrium prices

For \(q\in[0,1]\), define

\[ A(q)=\sum_{t:p_t>q}\mu_t,\qquad M(q)=\sum_{t:p_t=q}\mu_t,\qquad B(q)=A(q)+M(q). \]

Claim. A price \(q\) admits an equilibrium allocation if and only if

\[ A(q)\leq q\leq B(q). \]

Interior prices: necessity

Suppose \(0<q<1\). The difference between the two utility-per-price ratios is

\[ \frac{p_t}{q}-\frac{1-p_t}{1-q} =\frac{p_t-q}{q(1-q)}. \]

Every maximizing bundle spends the full budget: otherwise, increasing consumption of a good with positive utility coefficient would strictly improve utility. Consequently:

  • If \(p_t>q\), the unique maximizing bundle is \(x_t=(1/q,0)\).
  • If \(p_t<q\), the unique maximizing bundle is \(x_t=(0,1/(1-q))\).
  • If \(p_t=q\), every nonnegative bundle satisfying \(qx_{t1}+(1-q)x_{t2}=1\) is maximizing.

These conclusions also follow directly by bounding utility by the larger utility-per-price ratio times expenditure; equality requires spending only on goods attaining that ratio.

Multiplying first-good market clearing by \(q\) gives

\[ q=A(q)+\sum_{t:p_t=q}\mu_t qx_{t1}. \]

For an indifferent type, \(0\leq qx_{t1}\leq1\). Thus the last sum lies between \(0\) and \(M(q)\), proving the stated inequalities.

Interior prices: sufficiency and an explicit allocation

Suppose \(A(q)\leq q\leq B(q)\), and write \(A=A(q)\), \(M=M(q)\).

For strict preferences, use the unique maximizing bundles above. If \(M=0\), the inequalities imply \(A=q\). Hence aggregate consumption is

\[ \left(\frac{A}{q},\frac{1-A}{1-q}\right)=(1,1). \]

If \(M>0\), put \(r=q-A\). The inequalities give \(0\leq r\leq M\). Assign every indifferent type the bundle

\[ x_t=\left(\frac{r}{Mq},\frac{M-r}{M(1-q)}\right). \]

It is nonnegative and spends exactly one:

\[ qx_{t1}+(1-q)x_{t2} =\frac rM+\frac{M-r}{M}=1. \]

Since \(p_t=q\), its utility equals its expenditure, so this bundle maximizes utility.

Aggregate first-good consumption is

\[ \frac Aq+M\frac{r}{Mq} =\frac{A+r}{q}=1. \]

The total mass strictly below \(q\) is \(1-A-M\), so aggregate second-good consumption is

\[ \frac{1-A-M}{1-q} +M\frac{M-r}{M(1-q)} =\frac{1-A-r}{1-q}=1. \]

Thus the allocation is an equilibrium.

Zero prices

At \(q=0\), any type with \(p_t>0\) has unbounded utility because the first good is free. Such a type has no maximizing bundle. Therefore an equilibrium at \(q=0\) requires all beliefs to equal \(0\). Conversely, in that case \(x_t=(1,1)\) for every type is maximizing and clears both goods.

The condition \(A(0)\leq0\leq B(0)\) says exactly that all beliefs equal \(0\), because every mass is positive.

Similarly, \(q=1\) admits an equilibrium exactly when all beliefs equal \(1\), again with \(x_t=(1,1)\). This is equivalent to \(A(1)\leq1\leq B(1)\).

The characterization therefore holds on the entire closed interval.

2. Finding the price by sorting and scanning

Relabel the support so that

\[ p_1<p_2<\cdots<p_\tau. \]

Define tail masses

\[ W_i=\sum_{j=i+1}^{\tau}\mu_j \quad(1\leq i\leq\tau),\qquad W_0=1. \]

In particular, \(W_\tau=0\) and \(W_{i-1}=W_i+\mu_i\).

Let \(k\) be the smallest index satisfying \(p_k\geq W_k\). This index exists because \(p_\tau\geq0=W_\tau\). Output

\[ q=\min\{p_k,W_{k-1}\}. \]

We verify that this price satisfies the characterization.

Case 1: \(p_k\leq W_{k-1}\). Then \(q=p_k\), and

\[ A(q)=W_k\leq p_k\leq W_{k-1}=W_k+\mu_k=B(q). \]

Case 2: \(p_k>W_{k-1}\). This requires \(k>1\), because \(p_1\leq1=W_0\). Minimality of \(k\) gives

\[ p_{k-1}<W_{k-1}<p_k. \]

Thus \(q=W_{k-1}\) lies strictly between consecutive support beliefs. Exactly the types indexed \(k,\ldots,\tau\) lie above \(q\), and their mass is \(W_{k-1}\). Therefore

\[ A(q)=B(q)=W_{k-1}=q. \]

Both cases yield an equilibrium price. Section 1 constructs the corresponding rational allocation, including any endpoint case.

For completeness, the equilibrium price is unique. If \(q<q'\) both satisfied the characterization, then \(\{t:p_t\geq q'\}\subseteq\{t:p_t>q\}\), implying

\[ q'\leq B(q')\leq A(q)\leq q, \]

a contradiction.

3. Exact arithmetic and polynomial bit complexity

Assume each input rational is encoded by a binary numerator and a positive binary denominator. Let \(D\) be the product of all denominators appearing in the beliefs and masses. Its bit length is \(O(L)\).

Write

\[ p_i=P_i/D,\qquad \mu_i=U_i/D, \]

where \(P_i,U_i\) are integers. The input assumptions give \(0\leq P_i\leq D\), \(U_i>0\), and \(\sum_iU_i=D\).

Sorting beliefs becomes sorting the integers \(P_i\). Define integer tails

\[ T_i=\sum_{j=i+1}^{\tau}U_j,\qquad T_0=D. \]

The price algorithm finds the first \(k\) with \(P_k\geq T_k\), and returns \(q=Q/D\), where

\[ Q=\min\{P_k,T_{k-1}\}. \]

All these integers have \(O(L)\) bits.

For an interior price, strict-preference bundles are

\[ (D/Q,0)\quad\text{or}\quad(0,D/(D-Q)). \]

For indifferent types, let

\[ H=\sum_{i:P_i>Q}U_i,\qquad J=\sum_{i:P_i=Q}U_i. \]

When \(J>0\), the allocation formula becomes

\[ x_i= \left( \frac{D(Q-H)}{JQ}, \frac{D(J-Q+H)}{J(D-Q)} \right). \]

The price characterization guarantees \(0\leq Q-H\leq J\). Every numerator and denominator in these coordinates is bounded by \(D^2\), so each coordinate has \(O(L)\) bits. Endpoint allocations have constant-size coordinates.

Constructing the common denominator, converting inputs, computing tails, and constructing allocations require \(O(\tau)\) integer arithmetic operations. Sorting requires \(O(\tau\log(\tau+1))\) comparisons. All operations involve \(O(L)\)-bit integers and are polynomial-time. For example, elementary arithmetic gives the conservative bound

\[ O\!\left(\tau\log(\tau+1)L^2\right). \]

The total output length is \(O(\tau L)\).

4. Connection with linear Fisher markets

The support representation also gives a finite linear Fisher market directly. Set \(z_t=\mu_tx_t\). Type \(t\) becomes one buyer with budget \(\mu_t>0\), utility coefficients \((p_t,1-p_t)\), and aggregate goods supply \((1,1)\). Scaling bundles by \(\mu_t\) preserves maximization because it scales both the budget and utility by that positive constant.

Both goods are valued by some buyer unless all beliefs equal one endpoint; those exceptions were explicitly handled above. Thus the remaining instances also fall under the cited strongly polynomial linear Fisher-market algorithm. [Végh, *Strongly Polynomial Algorithm for a Class of Minimum-Cost Flow Problems with Separable Convex Objectives*](https://personal.lse.ac.uk/veghl/papers/vegh-quadratic.pdf).

The explicit two-state proof establishes the requested polynomial-time result independently.
