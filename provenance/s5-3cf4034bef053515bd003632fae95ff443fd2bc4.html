The continuous mirror question, as graded

Given a tree airline network, a coalition \(S\), and a finite support \(T\) of passenger types \(t=(o_t,d_t,r_t)\) with rational masses \(\mu_t\) summing to \(1\), let \(P_t\) be the unique route for type \(t\) and \(A(P_t)\) its carriers. Given rational per-capita leg capacities \(\kappa_e\), find a served-mass vector \(x\) maximizing \(\sum_{t:A(P_t)\subseteq S} r_t x_t\), subject to \(0\le x_t\le\mu_t\) and \(\sum_{t:e\in P_t}x_t\le\kappa_e\) for each leg \(e\) owned by a carrier in \(S\).

Result

An exact revenue-maximizing feasible vector is computable in polynomial time. The associated decision problem belongs to \(\mathrm{P}\), and hence cannot be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions unless \(\mathrm{P}=\mathrm{NP}\).

This conclusion uses the stated real-valued served masses and explicitly listed support of size \(\tau\).

1. An exact linear-programming formulation

Write \(\operatorname{owner}(e)\) for the owner of edge \(e\). Define the eligible types and coalition edges by

\(T_S=\{t\in T:A(P_t)\subseteq S\}\), and \(E_S=\{e\in E:\operatorname{owner}(e)\in S\}\).

Let \(n=|T_S|\leq\tau\) and \(k=|E_S|\leq m\). For each \(e\in E_S\) and \(t\in T_S\), define the path-incidence coefficient

\(H_{et}=1\) if \(e\in P_t\), and \(H_{et}=0\) otherwise.

Consider the rational linear program

\(\displaystyle \max_{x\in\mathbb R^n}\sum_{t\in T_S}r_tx_t\),

subject to

\(\displaystyle \sum_{t\in T_S}H_{et}x_t\leq\kappa_e\quad(e\in E_S)\),

and

\(\displaystyle 0\leq x_t\leq\mu_t\quad(t\in T_S)\).

It has \(n\) variables and \(k+2n\) inequalities.

This formulation is equivalent to the given problem:

  • Any feasible vector in the original problem restricts to a feasible LP vector, because every ineligible coordinate is zero.
  • Conversely, extend any feasible LP vector by setting \(x_t=0\) for \(t\notin T_S\). The demand bounds and eligibility requirements then hold. Every required edge-capacity inequality holds because its contribution from ineligible types is zero.
  • Both vectors have the same revenue.

If \(n=0\), the all-zero vector is optimal. Otherwise, the LP is feasible because it contains the zero vector. Its feasible set is closed and contained in the bounded box \(\prod_{t\in T_S}[0,\mu_t]\). Consequently it is compact, so the continuous linear objective attains its maximum.

2. Exactness and binary output size

We use the standard rational linear-programming theorem: an explicitly encoded LP with rational coefficients can be solved in time polynomial in its binary encoding length, returning an exact rational optimal solution when it is feasible and has a finite optimum. Rational data reduce to integer data by clearing denominators with polynomial encoding growth; polynomial-time feasibility and its reduction to exact optimization are described in [MIT’s ellipsoid-method notes](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

All hypotheses hold here: the LP is explicit, its coefficients are rational, and feasibility and boundedness were proved above.

For completeness, the output also admits a direct polynomial bit-size bound. A linear objective on a nonempty compact polytope has an optimal vertex. At any vertex, the active constraint rows span \(\mathbb R^n\): otherwise a nonzero vector orthogonal to all active rows would permit sufficiently small feasible movements in both directions, contradicting extremality.

Thus an optimal vertex satisfies \(Cx=b\), where \(C\) consists of \(n\) linearly independent active rows. Its entries belong to \(\{-1,0,1\}\); the entries of \(b\) are selected capacities, masses, or zeros.

Let \(D\) be the product of the denominators of all input capacities and masses. Its binary length is \(O(L)\), and \(Db\) is integral. Cramer’s rule gives

\(\displaystyle x_j=\frac{\det C^{(j)}}{D\det C}\),

where \(C^{(j)}\) replaces column \(j\) of \(C\) by \(Db\).

Hadamard’s inequality gives \(|\det C|\leq n^{n/2}\). Each entry of \(Db\) has binary length \(O(L)\); applying Hadamard’s inequality to \(C^{(j)}\) therefore bounds its determinant’s binary length by \(O(L+n\log(n+1))\). Hence each coordinate has an exact rational representation using

\(\displaystyle O(L+n\log(n+1))\)

bits. The full served-mass vector consequently has polynomial encoding length. No numerical approximation is needed for the claimed result.

3. Construction and running time

A tree with \(m\) edges has \(m+1\) vertices. After indexing vertices and airlines and recording membership in \(S\), find each listed type’s unique path by a tree traversal. Each traversal takes \(O(m)\) graph operations. While processing the path, check eligibility and record its edge incidences.

Thus path construction and eligibility filtering take

\(\displaystyle O(m+|A|+m\tau)\)

operations on indexed graph data, in addition to reading and indexing the input.

A dense encoding of the resulting LP has binary length

\(\displaystyle B=O\!\left(L+n(k+2n)\right) =O\!\left(L+m\tau+\tau^2\right)\).

The rational coefficients outside the incidence matrix are copied from the input; the matrix entries have constant-size encodings.

Combining polynomial-time input processing with exact rational LP gives the following overall bit-complexity bound:

\(\displaystyle \operatorname{poly}\!\left(m,\tau,|A|,L\right)\),

or, more explicitly,

\(\displaystyle \operatorname{poly}\!\left(L+m+|A|+\tau+m\tau+\tau^2\right)\).

This is a polynomial bound in binary input length, without a claim of strong polynomiality. It depends on the listed support size \(\tau\), without enumerating other possible passenger types.

For the decision problem, compute an exact optimum \(x^*\) and compare the rational number \(\sum_{t\in T_S}r_tx_t^*\) with \(q\). Rational arithmetic and comparison take polynomial time using the output-size bound above. Here \(L\) includes the encoding of \(q\).

4. Relation to the discrete benchmark

The proof is independent of the claimed integer-seat benchmark. In this formulation, served masses are real variables, so the displayed LP is the optimization problem itself. Demand bounds simply contribute the inequalities \(x_t\leq\mu_t\). An integrality theorem is therefore unnecessary to establish exact polynomial-time solvability.
