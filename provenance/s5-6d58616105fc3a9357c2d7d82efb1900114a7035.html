The continuous mirror question, as graded

Given a finite metric type set T, rational masses \(\mu_t\ge 0\) summing to 1, a cluster count k, and a clustering \(x_{tj}\ge 0\) with \(\sum_{j=1}^k x_{tj}=\mu_t\), audit its FJR approximation. A coalition chooses portions \(0\le\eta_{tj}\le x_{tj}\) with \(\sum_{t,j}\eta_{tj}\ge 1/k\), and has type masses \(\nu_t=\sum_j\eta_{tj}\). Let \(b_{tj}=\max_{u:x_{uj}>0}d(t,u)\) be the baseline maximum loss for type t in cluster j, and let \(D(\nu)=\max_{t,u:\nu_t>0,\nu_u>0}d(t,u)\) be the coalition's maximum loss. Determine the exact audit value \(\rho(x)=\max\{1,\sup_{\eta}\,\min_{(t,j):\eta_{tj}>0} b_{tj}/D(\nu)\}\), with positive-over-zero interpreted as infinity and zero-over-zero as 1; or return a \(\lambda\)-approximation \(\theta\) satisfying \(\theta\le\rho(x)\le\lambda\theta\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Here \(m=|T|=\tau\).
Input also includes a finite rational distance matrix \(d\), symmetric and nonnegative with zero diagonal and satisfying the triangle inequality; distinct types may have distance zero. A positive integer \(k\) and binary rational allocations \(x_{tj}\ge0\) satisfy \(\sum_{j=1}^k x_{tj}=\mu_t\); empty clusters are allowed. Let \(L\) be the total input bit length.
A coalition selects real portions \(0\le\eta_{tj}\le x_{tj}\) with \(\sum_{t,j}\eta_{tj}\ge1/k\), and has masses \(\nu_t=\sum_j\eta_{tj}\).
For occupied cells define \(b_{tj}=\max_{u:x_{uj}>0}d(t,u)\); define \(D(\nu)=\max_{t,u:\nu_t>0,\nu_u>0}d(t,u)\).
The maximum-loss FJR audit value is \(\rho(x)=\max\{1,\sup_{\eta}\min_{(t,j):\eta_{tj}>0} b_{tj}/D(\nu)\}\), where the supremum ranges over eligible coalitions, positive-over-zero is \(\infty\), and zero-over-zero is \(1\).
A \(\lambda\)-approximate audit returns \(\theta\in\mathbb{Q}_{\ge0}\cup\{\infty\}\) satisfying \(\theta\le\rho(x)\le\lambda\theta\).

For each fixed rational \(1\le\lambda<2\), is continuous maximum-loss FJR auditing solvable in time polynomial in \(m,\tau,k,L\), or is achieving this approximation NP-hard?

For finite agents, maximum-loss FJR auditing admits a polynomial-time \(2\)-approximation, but no polynomial-time \(\lambda\)-approximation for any \(\lambda<2\) unless \(\mathrm{P}=\mathrm{NP}\). [Source](https://www.cs.toronto.edu/~emicha/papers/fair-noncentroid-clustering.pdf)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed rational \(1\le\lambda<2\), achieving the specified approximation is \(\mathrm{NP}\)-hard. Consequently, a polynomial-time algorithm exists only if \(\mathrm{P}=\mathrm{NP}\).

We prove this even when all masses are dyadic rationals, all mass is allocated to one cluster, and every distance between distinct types belongs to \(\{1,2\}\).

1. Starting problem and padding

We reduce from the standard \(\mathrm{NP}\)-complete CLIQUE problem, also used in the [finite-agent hardness proof, Appendix A.7](https://www.cs.toronto.edu/~emicha/papers/fair-noncentroid-clustering.pdf). Its input is a simple undirected graph \(G\) on \(n\) vertices and an integer \(s\), with \(2\le s\le n\); the question is whether \(G\) contains a clique of size at least \(s\).

Let \(r\) be the smallest power of two satisfying \(r\ge s\), and put \(p=r-s\). Construct a graph \(H\) by adding \(p\) vertices that are pairwise adjacent and adjacent to every original vertex. Write \(N=n+p\).

Then \(H\) has a clique of size at least \(r\) if and only if \(G\) has a clique of size at least \(s\):

  • A clique containing \(s\) original vertices extends to one containing \(s+p=r\) vertices.
  • Any clique containing at least \(r\) vertices of \(H\) contains at least \(r-p=s\) original vertices, which form a clique in \(G\).

2. Constructing the society

Let \(K\) be the smallest power of two satisfying \(K\ge N\), and set \(k=K\).

The support consists of the \(N\) vertices of \(H\), called vertex types, and \(K\) additional dummy types. Thus \(m=\tau=N+K\).

Give each vertex type mass

\(\displaystyle \mu_v=\frac{1}{Kr},\)

and each dummy type mass

\(\displaystyle \mu_z=\frac{1-N/(Kr)}{K}=\frac{Kr-N}{K^2r}.\)

These masses are positive: \(N\le K\) and \(r\ge2\) imply \(N/(Kr)\le1/2\). Their sum is

\(\displaystyle N\frac{1}{Kr}+K\frac{1-N/(Kr)}{K}=1.\)

Because \(K\) and \(r\) are powers of two, every mass is dyadic. Moreover, every individual type has mass strictly below the coalition threshold:

\(\displaystyle \mu_v<\frac1K,\qquad 0<\mu_z<\frac1K.\)

Allocate every type entirely to cluster \(1\):

\(\displaystyle x_{t1}=\mu_t,\qquad x_{tj}=0\quad\text{for }2\le j\le K.\)

The remaining clusters are empty, as permitted.

Define the distances by

\(\displaystyle d(t,u)= \begin{cases} 0,&t=u,\\ 1,&t,u\text{ are adjacent vertex types in }H,\\ 2,&\text{otherwise}. \end{cases}\)

This is a finite rational metric. Symmetry, nonnegativity, and the zero diagonal follow directly. For three distinct types, the sum of two distances is at least \(2\), whereas the remaining distance is at most \(2\). Triangles with repeated types satisfy the triangle inequality immediately.

Every occupied cell has current loss \(2\). A vertex type has distance \(2\) to every dummy type; a dummy type has distance \(2\) to another dummy type, since \(K\ge N\ge2\). Therefore

\(\displaystyle b_{t1}=2\quad\text{for every }t\in T.\)

3. What real portions can achieve

Consider any eligible coalition, and define its type support by

\(\displaystyle S=\{t:\nu_t>0\}.\)

Only cluster \(1\) is occupied, so \(\nu_t=\eta_{t1}\le\mu_t\). Consequently,

\(\displaystyle \frac1K\le\sum_{t\in S}\nu_t\le\sum_{t\in S}\mu_t.\)

Since every individual type has mass strictly below \(1/K\), an eligible coalition must contain at least two types. All distinct types have positive distance, so no eligible coalition has zero diameter. Its diameter belongs to \(\{1,2\}\), and its audit ratio is exactly

\(\displaystyle \min_{(t,j):\eta_{tj}>0}\frac{b_{tj}}{D(\nu)}=\frac{2}{D(\nu)}\in\{1,2\}.\)

We now characterize when diameter \(1\) is possible.

If \(D(\nu)=1\), no dummy type belongs to \(S\): a dummy has distance \(2\) to every other type, and \(|S|\ge2\). Thus \(S\) consists entirely of vertex types. Their pairwise distances are \(1\), so they form a clique in \(H\). Their available mass bounds give

\(\displaystyle \frac1K\le\sum_{t\in S}\nu_t\le\frac{|S|}{Kr},\)

hence \(|S|\ge r\).

Conversely, if \(H\) has a clique containing \(r\) vertices, select the full mass of precisely those vertices. The resulting coalition has mass

\(\displaystyle r\frac{1}{Kr}=\frac1K,\)

and diameter \(1\), because \(r\ge2\).

We have therefore proved:

An eligible coalition of diameter \(1\) exists if and only if \(H\) contains a clique of size at least \(r\).

This argument explicitly allows arbitrary real portions. Dividing masses cannot make a smaller vertex support reach the required total mass.

4. Exact audit gap

If \(G\) contains a clique of size at least \(s\), the preceding construction supplies an eligible coalition with ratio \(2\). Every eligible coalition has ratio at most \(2\), so \(\rho(x)=2\).

If \(G\) contains no such clique, no eligible coalition has diameter \(1\). Every eligible coalition therefore has diameter \(2\) and ratio \(1\). Eligible coalitions exist—for example, selecting the entire society has mass \(1\). Thus \(\rho(x)=1\).

Hence the constructed instance satisfies

\(\displaystyle \rho(x)= \begin{cases} 2,&G\text{ contains a clique of size at least }s,\\ 1,&G\text{ contains no clique of size at least }s. \end{cases}\)

In particular, the zero-denominator conventions never enter this reduction.

5. Polynomial size and approximation hardness

Since \(r<2s\), we have \(N=n+r-s<2n\). Also \(K<2N\). Consequently, \(m=\tau=N+K\) and \(k=K\) are both \(O(n)\).

Every mass has binary encoding length \(O(\log n)\). The distance matrix and the allocation matrix each have \(O(n^2)\) entries. The complete constructed input therefore has bit length \(L=O(n^2\log n)\) and is computable in polynomial time.

Suppose a polynomial-time \(\lambda\)-approximate auditor existed for a fixed rational \(1\le\lambda<2\), returning \(\theta\) with \(\theta\le\rho(x)\le\lambda\theta\).

On the constructed instances:

  • If \(\rho(x)=1\), then \(\theta\le1\).
  • If \(\rho(x)=2\), then \(\theta\ge2/\lambda>1\).

The output is finite because \(\theta\le\rho(x)\le2\). Comparing its rational value with \(1\) therefore decides CLIQUE in polynomial time. This proves the claimed approximation hardness for the specified divisible-mass auditing problem.
