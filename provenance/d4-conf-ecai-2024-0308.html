Conclusion

The problem is NP-hard for every fixed \(k\ge 2\) and every fixed nonempty refinement \(\gamma\subseteq TC\). Hardness holds already for \(\tau=1\), mass \(\mu_1=1\), and coefficients belonging to \(\{-2,0,1\}\). Consequently, a running time polynomial in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).

1. Aggregation preserves the utility representation

Define the aggregate coefficients and utility by
\(\bar\omega_S=\sum_{t=1}^{\tau}\mu_t\omega_S^t\) and
\(U(A)=\sum_{S\in[E]^k,\ S\subseteq A}\bar\omega_S\).

Interchanging finite sums gives
\[ \sum_{t=1}^{\tau}\mu_tu_t(A)=U(A), \qquad \Phi_\mu(A,B)=U(A)-U(B). \]
Thus, by the Top Cycle identity stipulated in the question,
\(TC(2^E,\Phi_\mu)=\operatorname*{arg\,max}_{A\subseteq E}U(A)\).
Every valid output from \(\gamma\) must therefore maximize \(U\).

There are \(N_k(m)=\sum_{j=1}^{\min(k,m)}\binom mj=O((m+1)^k)\) coefficients per type. Aggregation uses \(O(\tau N_k(m))\) rational arithmetic operations and takes polynomial bit time. For example, elementary integer arithmetic gives the conservative bound
\(O(\tau(m+1)^k(L+1)^2)\): for any fixed coefficient, the products of the input denominators have \(O(L)\) bits, and the corresponding numerator also has \(O(L)\) bits.

This establishes efficient preprocessing; it does not establish efficient maximization.

2. Explicit hardness reduction

We reduce from the classical NP-complete Independent Set decision problem: given a finite simple undirected graph \(G=(V,F)\) and an integer \(r\), determine whether there is an independent vertex set of cardinality at least \(r\).

Construct an instance with \(E=V\), \(m=|V|\), one type, and \(\mu_1=1\). Explicitly list all required coefficients, setting
\[ \omega^1_S= \begin{cases} 1 & \text{if }|S|=1,\\ -2 & \text{if }|S|=2\text{ and }S\in F,\\ 0 & \text{otherwise}. \end{cases} \]
Here an edge is identified with its two-element endpoint set. All coefficients of cardinality greater than two are zero, so the construction applies to every fixed \(k\ge2\). The mass is positive and binary-rational, and every coefficient is an allowed rational number.

For \(A\subseteq V\), let \(e_G(A)\) denote the number of graph edges with both endpoints in \(A\). The resulting utility is
\(U(A)=|A|-2e_G(A)\).

Claim. The utility maximizers are exactly the maximum independent sets of \(G\).

Proof. Suppose \(A\) is not independent. Choose a vertex \(v\in A\) incident to an edge within \(A\), and let \(d_A(v)\ge1\) be its degree in the induced graph on \(A\). Deleting \(v\) removes exactly \(d_A(v)\) induced edges. Hence
\[ U(A\setminus\{v\})-U(A) =(|A|-1)-2(e_G(A)-d_A(v))-(|A|-2e_G(A)) =2d_A(v)-1\ge1. \]
Therefore no non-independent set maximizes utility.

For every independent set \(I\), we have \(e_G(I)=0\), so \(U(I)=|I|\). Because a maximizer exists on the finite domain and every maximizer is independent, the maximum utility equals the maximum independent-set cardinality. Consequently, the maximizers are precisely the maximum independent sets. This also covers the admissible empty alternative. \(\square\)

3. Every permissible output solves the source instance

Let \(A^\star\) be any valid output of the mass-society search problem. Since
\(A^\star\in\gamma(2^E,\Phi_\mu)\subseteq TC(2^E,\Phi_\mu)\),
the preceding claim implies that \(A^\star\) is a maximum independent set. Therefore the source instance is a yes-instance exactly when \(|A^\star|\ge r\).

The construction explicitly lists \(O((m+1)^k)\) coefficients, each of constant binary length. Even charging for subset labels, its encoding length and construction time are \(O((m+1)^k\log(m+2))\). Since \(k\) is fixed and \(\tau=1\), both are polynomial in the graph input size. Checking the cardinality of the returned set also takes polynomial time.

Thus one call to any correct search algorithm, followed by polynomial-time processing, decides an NP-complete problem. The reduction works for every permissible output, irrespective of how \(\gamma\) chooses among tied maximizers.

4. Relation to the supplied result

The same transfer follows immediately from the supplied single-model theorem: use one type of mass one and copy its coefficients. The induced preference intensities, Top Cycle, and \(\gamma\)-choice set are unchanged. The cited paper’s Theorem 3 explicitly establishes hardness with zero bilinear coefficients and pads higher-degree coefficients with zeros. [Gilbert, Ouaguenouni and Spanjaard, Theorem 3](https://ebooks.iospress.nl/pdf/doi/10.3233/FAIA240887).

No separate mass-society hardness theorem is needed; the one-type subclass already proves the requested result.
