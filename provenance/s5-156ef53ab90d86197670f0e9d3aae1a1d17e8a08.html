The continuous mirror question, as graded

Given \(m\) alternatives, rational masses \(\mu_j\) and observed rankings \(\succ_j\) for finitely many cohorts, with an adversarial hidden common valuation vector \(v_j\) per cohort consistent with its ranking, design a randomized mechanism that queries at most \(q\) values per cohort and returns \(a\in A\), minimizing worst-case distortion \(\max_v \frac{\max_{b\in A}\sum_j\mu_j v_j(b)}{\mathbb{E}[\sum_j\mu_j v_j(\hat a)]}\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge2\) alternatives. A society is given by its support: \(\tau\ge1\) cohorts with positive binary rational masses \(\mu_j\), summing to \(1\), and observed strict rankings \(\succ_j\). Here \(\tau\) is the support size, not the number of possible rankings; distinct cohorts may have identical rankings.
Each cohort has one hidden valuation vector \(v_j\in\mathbb{Q}_{\ge0}^{A}\), shared by its entire mass, with \(a\succ_j b\Rightarrow v_j(a)\ge v_j(b)\). Values have no per-cohort normalization or upper bound.
A randomized mechanism observes the support and rankings, may adaptively query exact values \(v_j(a)\), and returns one alternative \(\hat a\). It makes at most \(q\in\{0,\ldots,m\}\) queries to each cohort on every execution; queries cannot be multiplied by subdividing its mass. Valuations are fixed before the mechanism's random choices.
Write \(W_v(a)=\sum_{j=1}^{\tau}\mu_jv_j(a)\) and \(D_M(\mu,P)=\sup_{v\text{ consistent with }P,\,\max_bW_v(b)>0}\frac{\max_{b\in A}W_v(b)}{\mathbb{E}_M[W_v(\hat a)]}\), with a zero denominator giving \(+\infty\). Let \(L\) be the total bit length of the observed input and query answers; state running times in \(m,\tau,L,q\).
Can a randomized mechanism running in polynomial time achieve \(D_M(\mu,P)=O(\log m)\) for every supported society using \(q=O(\log m)\) value queries per cohort, or is this approximation guarantee impossible?
For finite electorates with unrestricted nonnegative valuations, a randomized mechanism achieves \(O(\log m)\) worst-case distortion with \(O(\log m)\) queries per agent ([source](https://arxiv.org/html/2307.07350v4)). A later deterministic mechanism achieves \(O(\lambda\min\{n,m\}^{1/\lambda})\) distortion in polynomial time using \(\lambda\) queries per agent ([source](https://www.cs.toronto.edu/~nisarg/papers/value-queries.pdf)).
No result explicitly treating this supported mass model was located.

Modeling choices made when packaging the task

  • Normalize total mass to one; common rescaling of all masses leaves distortion unchanged.
  • Use unrestricted nonnegative valuations and weak value consistency with strict observed rankings, allowing value ties as in the discrete model.
  • Restrict hidden values to binary rationals to specify bit complexity, without imposing a value bound or per-cohort normalization.
  • Allow adaptive randomized queries, impose the query cap on every execution, and fix valuations before mechanism randomness.
  • Treat cohorts as valuation types; identical observed rankings need not imply identical hidden valuations, and subdividing a cohort does not grant additional queries.
  • Replace the stated maximum over hidden valuations by a supremum, exclude all-zero welfare profiles, and assign infinite distortion when positive optimal welfare meets zero expected returned welfare.
  • Include query-answer encoding lengths in L and require at least two alternatives and nonempty support.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Yes. A polynomial-time randomized mechanism achieves \(O(\log m)\) distortion using \(O(\log m)\) queries per cohort. No subdivision of cohort mass is needed.

More explicitly, let \(R=\lceil\log_2(2m)\rceil\) and \(K=2^{\lceil\log_2 R\rceil}\). The mechanism below satisfies

\(D_M(\mu,P)\le 2K<4\lceil\log_2(2m)\rceil\)

and uses at most \(q_0=1+\lceil\log_2 m\rceil\le m\) queries per cohort on every execution. Thus it respects any supplied budget \(q\ge q_0\).

Why the finite-electorate result transfers

For each cohort, define the effective valuation \(u_j(a)=\mu_jv_j(a)\). Since \(\mu_j>0\), this scaling preserves its ranking and nonnegativity. Moreover,

\(\sum_{j=1}^{\tau}u_j(a)=W_v(a).\)

A query for \(u_j(a)\) is answered using exactly one query for \(v_j(a)\), followed by multiplication by the known mass. Conversely, every nonnegative rational effective valuation consistent with the ranking corresponds to an admissible cohort valuation \(v_j=u_j/\mu_j\). This correspondence relies on the absence of normalization or upper bounds.

Consequently, the cohort problem is equivalent, for query budgets and welfare, to an unrestricted finite electorate with \(\tau\) agents. The randomized finite-electorate theorem therefore already gives a positive answer. Its threshold mechanism is specified in [Definition 14 and Theorem 15 of Caragiannis–Fehrs](https://arxiv.org/html/2307.07350v4#S5.SS2).

For completeness, here is an explicit weighted implementation and a self-contained proof.

Mechanism

Fix a deterministic order for breaking ties. Write \(a_{j,1},\ldots,a_{j,m}\) for cohort \(j\)’s ranking.

  • Query each cohort’s top value \(\nu_j=v_j(a_{j,1})\).
  • Choose \(r\) uniformly from \(\{1,\ldots,K\}\).
  • For each cohort with \(\nu_j>0\), determine the prefix

\(S_{j,r}=\{a\in A:v_j(a)\ge \nu_j/2^r\}\)
by binary search along its ranking. If \(\nu_j=0\), all its values are zero; set \(S_{j,r}=A\) without further queries.

  • Return an alternative \(a_r\) maximizing

\(B_r(a)=\sum_{j=1}^{\tau}\mu_j\nu_j\mathbf{1}\{a\in S_{j,r}\}.\)

The set searched in step 3 is a prefix because the valuations are weakly decreasing along the observed strict ranking. Only the sampled threshold is searched.

Because \(K\) is a power of two, sampling \(r\) takes exactly \(\log_2 K\) fair random bits.

Proof of the distortion guarantee

Fix an admissible valuation profile \(v\) before the random choice. Let \(a^\star\) maximize welfare, and put \(\mathrm{OPT}=W_v(a^\star)>0\).

First, we establish a scalar inequality. For \(\nu\ge0\) and \(0\le x\le\nu\), define

\(h_K(x;\nu)=\sum_{r=1}^{K}\frac{\nu}{2^r}\mathbf{1}\{x\ge\nu/2^r\}.\)

Then

\(h_K(x;\nu)\ge x-\nu/2^K.\)

If \(\nu=0\), the assertion is immediate. If \(\nu>0\) and \(x<\nu/2^K\), its right-hand side is negative, whereas its left-hand side is zero.

Otherwise, let \(k\) be the smallest index in \(\{1,\ldots,K\}\) with \(x\ge\nu/2^k\). Precisely the indices \(k,\ldots,K\) contribute, so the finite geometric sum gives

\(h_K(x;\nu)=\nu\sum_{r=k}^{K}2^{-r}=\nu(2^{1-k}-2^{-K}).\)

For \(k=1\), we have \(x\le\nu=\nu2^{1-k}\). For \(k>1\), minimality gives \(x<\nu/2^{k-1}=\nu2^{1-k}\). Both cases prove the claimed inequality.

Next, define \(F_r(a)=2^{-r}B_r(a)\). Whenever \(a\in S_{j,r}\), cohort \(j\)’s value for \(a\) is at least \(\nu_j/2^r\). Summing with positive masses therefore gives

\(W_v(a)\ge F_r(a).\)

Since \(a_r\) maximizes \(B_r\), it also maximizes \(F_r\). Hence

\(W_v(a_r)\ge F_r(a_r)\ge F_r(a^\star).\)

Summing over the possible random choices and applying the scalar inequality yields

\(\sum_{r=1}^{K}W_v(a_r)\ge\sum_{j=1}^{\tau}\mu_j h_K(v_j(a^\star);\nu_j)\ge \mathrm{OPT}-2^{-K}T,\)

where \(T=\sum_{j=1}^{\tau}\mu_j\nu_j\).

To bound \(T\), use nonnegativity and the fact that each \(\nu_j\) is one of cohort \(j\)’s values:

\(T\le\sum_{j=1}^{\tau}\mu_j\sum_{a\in A}v_j(a)=\sum_{a\in A}W_v(a)\le m\,\mathrm{OPT}.\)

Since \(K\ge R=\lceil\log_2(2m)\rceil\), we have \(m2^{-K}\le1/2\). Consequently,

\(\sum_{r=1}^{K}W_v(a_r)\ge \mathrm{OPT}/2.\)

Uniform sampling now implies

\(\mathbb{E}_M[W_v(\hat a)]=\frac1K\sum_{r=1}^{K}W_v(a_r)\ge\frac{\mathrm{OPT}}{2K}.\)

This holds for every fixed admissible \(v\) with positive optimum. Taking the supremum in the definition of distortion proves \(D_M(\mu,P)\le2K\). Finally, \(K<2R\), giving the stated logarithmic bound.

Query count and running time

For a cohort with positive top value, position \(1\) is known to satisfy the threshold. Use a fictitious failing position \(m+1\). Binary search starts with an interval of length \(m\) and requires at most \(\lceil\log_2 m\rceil\) additional queries to locate the last satisfying position. Including the top query gives \(q_0=1+\lceil\log_2 m\rceil\). Cohorts with zero top value require only that query.

After constructing inverse rankings, membership in each discovered prefix is determined by comparing ranks. Computing all alternative scores takes \(O(\tau m)\) rational additions; the searches use \(O(\tau q)\) comparisons.

All intermediate rational numbers can be represented with \(O(L)\) bits. Indeed, score denominators can be taken as products of the denominators of the masses and queried top values, whose total encoded length is bounded by \(L\). Thresholds add only \(O(K)=O(\log m)\) bits. Using schoolbook integer arithmetic, a conservative running-time bound is therefore \(O(\tau(m+q)L^2)\) bit operations.

The mechanism is polynomial-time, keeps every cohort intact, and respects its query cap on every execution.
