The continuous mirror question, as graded

Given a finite candidate set \(C\), rational type masses \(\mu_t\), per-capita weights \(w_t\), and an acyclic type-level delegation forest, an unvoted unit of type \(t\) delegates uniformly across its parent type’s pool. Given an online sequence of events \((t,\delta,c)\), each selecting mass \(\delta\) symmetrically from the still-unvoted mass of type \(t\) to vote for \(c\), compute the exact candidate tally vector after every event. Determine whether this can be done in time polynomial in the number of candidates, the number of types, the event count, and the input bit length, independent of the represented population size.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) candidates and \(\tau\geq1\) types. Each type has a nonnegative binary-rational per-capita voting weight \(w_t\); its initial weight is \(\mu_tw_t\).
A fixed acyclic parent map gives each nonroot type one parent type. Delegation is uniform by mass across the parent's entire pool, including both voted and unvoted units.
Initially nobody has voted. Each of \(q\) online events \((t,\delta,c)\) has \(c\in C\) and binary-rational \(0<\delta\leq u_t\), where \(u_t\) is the remaining unvoted mass of type \(t\). It selects the fraction \(\delta/u_t\) symmetrically from that mass, including the same fraction of every incoming delegation stream. Selected units permanently vote for \(c\); no unit votes twice.
Voted units cast their own and received weight for their chosen candidate; unvoted units forward both to their parent. Unvoted root units leave both uncounted. Candidate tallies reflect the current delegation resolution, so a later direct vote replaces the affected earlier delegated contributions.
Compute the exact candidate tally vector after each event, before seeing the next. Let \(L\) be the total binary input length; include preprocessing and exact arithmetic in running times.

Can this online exact tallying problem be solved in time polynomial in \(m,\tau,q,L\), independent of any represented population size, or is it NP-hard?

For discrete voters with fixed single-proxy delegation, tally updates take \(O(\log n)\) operations per vote after \(O(n)\) preprocessing, with a bounded candidate set ([Fan et al.](https://arxiv.org/html/1911.08774v2)).
A different fractional delegation model with ranked proxies has a polynomial-time outcome algorithm ([Utke and Schmidt-Kraepelin](https://arxiv.org/abs/2307.01174)); no result settling this exact continuous online problem was located.

Modeling choices made when packaging the task

  • Normalized positive type masses to sum to one, interpreting the society as a distribution over types.
  • Specified nonnegative binary-rational per-capita weights, consistent with stake-based voting power; zero weights are allowed.
  • Interpreted the parent's pool as its entire fixed mass, including voted and unvoted units, with uniformity measured by mass rather than voting weight.
  • Made symmetric event selection apply equally to every incoming delegation stream on the remaining unvoted mass.
  • Specified that voted units absorb both their own and incoming weight, while unvoted units forward both; unresolved weight at an unvoted root is uncounted.
  • Carried over initially empty voting, fixed delegation, and one permanent direct vote per unit; required positive rational event masses bounded by remaining unvoted mass.
  • Treated the candidate count as variable, as requested by the continuous question, while retaining the bounded-candidate qualification on the discrete operation bound.
  • Included preprocessing and rational bit complexity in the polynomial-time target.

Result

The online exact tallying problem is polynomial-time solvable under the stated rules. The algorithm works directly on the \(\tau\) supported types and requires no representation of individual voters.

The proof has two parts: a finite-state recurrence that computes the correct current tallies, and a polynomial bound on the bit lengths of all rational numbers used.

1. State and the consequence of uniform delegation

Write \(p(t)\) for the parent of a nonroot type \(t\), and let \(\operatorname{ch}(t)=\{s:p(s)=t\}\).

After any event prefix, maintain:

  • \(u_t\): the unvoted mass of type \(t\);
  • \(v_{t,c}\): the mass of type \(t\) that has permanently voted for candidate \(c\).

Initially, \(u_t=\mu_t\) and \(v_{t,c}=0\). An event \((t,\delta,c)\) changes only

\(u_t\leftarrow u_t-\delta,\qquad v_{t,c}\leftarrow v_{t,c}+\delta.\)

Because no unit votes twice, these quantities satisfy

\(u_t+\sum_{c\in C}v_{t,c}=\mu_t.\)

Define the fractions

\(f_t=\dfrac{u_t}{\mu_t},\qquad g_{t,c}=\dfrac{v_{t,c}}{\mu_t}.\)

All divisions are defined because every supported type has positive mass. Moreover,

\(f_t+\sum_{c\in C}g_{t,c}=1.\)

Suppose the current total incoming delegated weight at type \(t\) is \(I_t\). Uniform delegation across the entire pool gives an incoming weight density of \(I_t/\mu_t\). Together with the type’s own weight, the total density is

\(w_t+\dfrac{I_t}{\mu_t}.\)

Consequently, a cohort of mass \(x\) within this type currently holds weight

\(x\left(w_t+\dfrac{I_t}{\mu_t}\right).\)

This applies to unvoted cohorts and to cohorts that voted earlier. Their chosen candidates are permanent, but their received delegated weights can change as the current delegation resolution changes.

The symmetric-selection rule agrees with this description. Before an event, the unvoted cohort receives delegated weight \(u_t I_t/\mu_t\). Selecting the fraction \(\delta/u_t\) of every incoming stream selects delegated weight

\(\dfrac{\delta}{u_t}\dfrac{u_t}{\mu_t}I_t=\dfrac{\delta}{\mu_t}I_t,\)

as well as own weight \(\delta w_t\). Thus the masses \(u_t\) and \(v_{t,c}\) suffice; no additional record of the selection history is needed.

2. Exact flow recurrence

Let \(R_t\) denote the total current weight available at type \(t\), including its own weight and all incoming weight. Let \(F_t\) denote its outgoing weight, or its uncounted weight if it is a root. Finally, let \(A_{t,c}\) denote the weight currently cast for \(c\) at type \(t\).

The preceding density calculation gives

\(R_t=\mu_t w_t+\sum_{s\in\operatorname{ch}(t)}F_s,\)

\(F_t=f_tR_t,\qquad A_{t,c}=g_{t,c}R_t.\)

The candidate tally is therefore

\(T_c=\sum_{t=1}^{\tau}A_{t,c}.\)

Correctness. Since the parent map is acyclic, its edges form a rooted forest. Process every child before its parent.

For a leaf, there is no incoming weight, so \(R_t=\mu_t w_t\); the formulas for \(F_t\) and \(A_{t,c}\) follow from the cohort masses. Inductively, once all children of \(t\) have been processed correctly, their outgoing weights give exactly the incoming weight at \(t\). Uniform distribution then gives the stated formulas at \(t\). This proves correctness at every type and hence for every candidate tally.

The recurrence also has a unique solution: each type’s values are determined by its already-determined children.

In particular, when a later direct vote reduces a child’s outgoing weight, recomputation reduces the weight received by the parent and its ancestors. This replaces the affected earlier delegated contributions exactly as required.

3. Online algorithm and arithmetic-operation count

Preprocess the forest to obtain an order in which every child precedes its parent. This takes \(O(\tau)\) graph operations. Initialize the state and compute the own weights \(\mu_t w_t\).

Upon receiving an event:

  • Update \(u_t\) and \(v_{t,c}\).
  • Reset all incoming-weight accumulators and candidate tallies to zero.
  • Traverse the types in the preprocessed order. At each type, compute \(R_t\), add \(g_{t,c}R_t\) to each candidate tally, and add \(f_tR_t\) to its parent’s incoming accumulator when a parent exists.
  • Output the entire tally vector before accepting the next event.

This uses \(O(m\tau)\) rational arithmetic operations per event and \(O(m\tau)\) stored rational numbers. It uses only the current event and the preceding state.

These operation counts alone do not establish polynomial bit complexity. That requires the following bound.

4. Polynomial bounds on rational bit lengths

Use the standard binary encoding of rational numerators and denominators. The argument also covers explicitly encoded dyadic rationals.

Write the input masses and weights as

\(\mu_t=\dfrac{a_t}{b_t},\qquad w_t=\dfrac{k_t}{d_t},\)

where \(a_t,b_t,d_t\) are positive integers and \(k_t\) is a nonnegative integer. Reduction to lowest terms is not necessary here.

Fix an arbitrary event prefix. Let \(e_j\) be the denominator of the increment \(\delta_j\) in each event already received, and define

\(D=\left(\prod_{t=1}^{\tau}b_t\right)\left(\prod_{j\text{ in the prefix}}e_j\right),\qquad E=\prod_{t=1}^{\tau}d_t,\qquad A=\prod_{t=1}^{\tau}a_t.\)

These quantities are used only in the proof; the algorithm need not construct them.

State fractions

Every \(u_t\) and \(v_{t,c}\) is an integer multiple of \(1/D\), since it is a sum or difference of input masses and increments whose denominators divide \(D\).

If \(u_t=U_t/D\), then

\(f_t=\dfrac{U_tb_t}{Da_t}.\)

The same argument applies to \(g_{t,c}\). Thus their reduced denominators divide \(Da_t\). The denominator of the own weight \(\mu_t w_t\) divides \(DE\).

Flow and tally denominators

For a descendant \(s\) of \(t\), let \(P(s,t)\) be the types on the parent path from \(s\) to \(t\), excluding \(t\). For \(s=t\), this path is empty and its product is \(1\).

Expanding the recurrence gives

\(R_t=\sum_{s\text{ in the subtree of }t}\mu_s w_s\prod_{x\in P(s,t)}f_x.\)

This identity follows by induction from the recurrence for \(R_t\).

Multiplying by \(f_t\) or by \(g_{t,c}\) gives the corresponding expansions for \(F_t\) and \(A_{t,c}\). In each individual term, each type contributes at most one fraction \(f_x\) or \(g_{x,c}\): acyclicity prevents repeated types along a path.

It follows that every term’s denominator divides

\(H=DE\prod_{t=1}^{\tau}(Da_t)=D^{\tau+1}EA.\)

Therefore the reduced denominators of every \(R_t\), \(F_t\), \(A_{t,c}\), and \(T_c\) divide \(H\). Their sums also have denominators dividing \(H\), regardless of the number of terms.

The total binary input length bounds the sums of the binary lengths of the integers appearing in these products. Consequently,

\(\log_2 D\leq L,\qquad \log_2 E\leq L,\qquad \log_2 A\leq L,\)

and hence

\(\log_2 H\leq(\tau+3)L.\)

Numerators and intermediate values

Let the total initial weight be

\(W=\sum_{t=1}^{\tau}\mu_t w_t.\)

Since the masses sum to \(1\),

\(W\leq\max_t w_t\leq 2^L.\)

Induction on subtrees, using \(0\leq f_t\leq1\), shows that \(R_t\) is at most the total initial weight in its subtree. Thus \(R_t\), \(F_t\), and \(A_{t,c}\) are all at most \(W\).

Candidate tallies satisfy the same bound. Indeed, at each type,

\(\sum_{c\in C}A_{t,c}+F_t=R_t.\)

Summing over all types cancels every nonroot outgoing weight against its parent’s incoming weight, giving

\(\sum_{c\in C}T_c+\sum_{t\text{ a root}}F_t=W.\)

All terms are nonnegative, so each \(T_c\leq W\). Partial sums used in the algorithm are also bounded by \(W\).

A nonnegative rational of value at most \(2^L\), whose reduced denominator divides \(H\), has reduced numerator at most \(2^LH\). Therefore all maintained quantities have numerator and denominator bit lengths

\(O((\tau+1)(L+1)).\)

Reduce rational results after each operation. The temporary integer products and sums involved in one operation have only a constant-factor increase in this bound.

5. Total running time

Set \(B=(\tau+4)(L+1)\). All arithmetic operands have \(O(B)\) bits.

Elementary integer arithmetic and the Euclidean algorithm implement a reduced rational addition, subtraction, multiplication, or division in \(O(B^3)\) bit operations. This conservative bound suffices.

Including preprocessing, state initialization, event processing, and writing all outputs, the total running time is

\(O\!\left(L+(q+1)m\tau B^3\right).\)

The space bound is

\(O(m\tau B+L)\)

bits. These bounds are polynomial in \(m,\tau,q,L\) and independent of any represented population size. The bit-length proof applies separately to every prefix, so it does not require advance knowledge of future events.

6. Conclusion and scope

The polynomial-time alternative holds. The essential facts are uniform allocation across the parent’s entire pool and an acyclic, single-parent map. They yield the finite-state recurrence and ensure that each expanded flow term contains at most one fraction per type.

The proof is direct and does not require the algorithms for [discrete single-proxy tallying studied by Fan et al.](https://arxiv.org/html/1911.08774v2) or for [fractional ranked delegations studied by Utke and Schmidt-Kraepelin](https://arxiv.org/abs/2307.01174).

The critical density assertion follows from the task’s explicit rule that delegation is uniform by mass across the parent’s entire pool, including voted and unvoted units.

\((\delta/u_t)(u_t/\mu_t)I_t=(\delta/\mu_t)I_t\).

At roots, \(F_t\) represents uncounted weight and is correctly excluded from the candidate tallies. Summing \(A_{t,c}\) over types counts each terminal contribution at its voting type.

The uniqueness claim also follows from this traversal: each type’s values depend only on already determined children.
