The continuous mirror question, as graded

Given a finite support \(T\) of complete valuation types with positive rational masses \(\mu_t\), and explicit values \(v_t(B)\) for bundles \(B\subseteq M\), compute the limiting item baseline prices and bundle prices when the society is replicated to high multiplicity with fixed scarce supply. For each item \(\ell\), the price is \(p_\ell=\max_{t\in T}\max_{\substack{B\in\mathcal B_t\ \ell\in B}} v_t(B)/|B|\), taking the inner maximum as \(0\) if no such bundle exists; then \(p(B)=|B|\max_{\ell\in B}p_\ell\).

Packaged proof task (what the prover saw — nothing else)

Let \(M\) be a set of \(m\geq 1\) items, with one unit of each item available. A society is given by its support: a list \(T\) of \(\tau\geq 1\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type supplies an explicit table of nonnegative binary rational values \(v_t(B)\) for every \(B\subseteq M\), with \(v_t(\varnothing)=0\) and free disposal. Values are private, utilities are quasi-linear, and there are no allocative externalities. Let \(L\) be the total input bit length, including these tables and masses.
Define \(\mathcal B_t=\{B\subseteq M:B\neq\varnothing\text{ and }v_t(C)<v_t(B)\text{ for every }C\subsetneq B\}\).
Replication means taking \(k\mu_t\) identical bidders of each type, along integers \(k\) making these counts integral, while retaining the fixed item supply.
The limiting prices to compute exactly are \(p_\ell=\max_{t\in T}\max_{B\in\mathcal B_t:\,\ell\in B}v_t(B)/|B|\), with an empty inner maximum equal to \(0\), and \(p(B)=|B|\max_{\ell\in B}p_\ell\) for nonempty bundles, with \(p(\varnothing)=0\). Compute every item price and every bundle price.

Is exact computation of these limiting prices possible in time polynomial in \(m\), \(\tau\), and \(L\), or is it NP-hard?

For finite bidders, the AM-MB ascending auction under straightforward bidding is known to converge, as the price increment tends to zero, to item baselines given by the second-largest bidder-specific maximum minimal-bundle average value. This is a convergence result, without a polynomial bit-complexity bound. [Source](https://cdn.aaai.org/AAAI/2005/AAAI05-042.pdf)
No result settling this exact support-and-mass pricing problem was located in the literature search.

Exact computation is polynomial-time solvable

With the stated explicit valuation-table representation, every item price and every bundle price can be computed exactly in time polynomial in \(m\), \(\tau\), and \(L\). The essential point is that the input already contains \(\tau 2^m\) valuation entries, so enumerating all bundles is polynomial in the input length.

1. Recognizing minimal bundles

Free disposal means that \(v_t(C)\leq v_t(D)\) whenever \(C\subseteq D\).

Lemma. For every type \(t\) and every nonempty bundle \(B\),
\[ B\in\mathcal B_t \quad\Longleftrightarrow\quad v_t(B\setminus\{\ell\})<v_t(B) \text{ for every }\ell\in B. \]

Proof. If \(B\in\mathcal B_t\), each \(B\setminus\{\ell\}\) is a proper subset of \(B\), so every indicated inequality follows from the definition.

Conversely, suppose all the indicated inequalities hold. Let \(C\subsetneq B\). Choose \(\ell\in B\setminus C\). Then \(C\subseteq B\setminus\{\ell\}\), and free disposal gives
\[ v_t(C)\leq v_t(B\setminus\{\ell\})<v_t(B). \]
This holds for every proper subset \(C\), proving \(B\in\mathcal B_t\). \(\square\)

Thus testing whether a bundle is minimal requires at most \(m\) comparisons of explicit table entries.

2. Exact algorithm and correctness

Index the valuation tables by the \(m\)-bit incidence vectors of bundles.

  • Initialize \(p_\ell=0\) for every item \(\ell\in M\).
  • For each type \(t\) and each nonempty bundle \(B\), use the lemma to test whether \(B\in\mathcal B_t\).
  • Whenever the test succeeds, compute \(a_{t,B}=v_t(B)/|B|\). For each \(\ell\in B\), replace \(p_\ell\) by \(\max\{p_\ell,a_{t,B}\}\).
  • Output the resulting item prices. Output \(p(\varnothing)=0\); for each nonempty \(B\), compute and output \(p(B)=|B|\max_{\ell\in B}p_\ell\).

By the lemma, step 3 processes exactly the pairs \((t,B)\) with \(B\in\mathcal B_t\). For an item \(\ell\), it processes exactly those pairs additionally satisfying \(\ell\in B\). Consequently, its final value is precisely
\[ p_\ell=\max_{t\in T}\max_{\substack{B\in\mathcal B_t\\\ell\in B}} \frac{v_t(B)}{|B|}. \]
If there are no qualifying pairs, the initialized value remains zero. Otherwise, initialization at zero does not affect the maximum because all values are nonnegative. Step 4 then evaluates the stipulated bundle-price formula exactly.

3. Polynomial bit complexity

Every explicit rational entry requires at least one bit. Hence \(L\geq\tau 2^m\), and in particular \(2^m\leq L\).

Testing all bundles uses at most \(\tau m2^m\) rational comparisons. Updating all item maxima uses at most another \(\tau m2^m\) comparisons. Computing all bundle prices uses at most \(m2^m\) comparisons and \(2^m\) multiplications.

These operations have polynomial bit complexity. To see this explicitly, write a valuation as \(v_t(B)=a/b\), with \(a\geq0\) and \(b>0\). Both integers have at most \(L\) bits. For \(s=|B|\), represent its average as \(a/(bs)\). Its numerator and denominator therefore have \(O(L+\log m)\) bits.

Compare two rational candidates by cross multiplication: \(a_1/d_1<a_2/d_2\) exactly when \(a_1d_2<a_2d_1\). All integers involved have \(O(L+\log m)\) bits, so ordinary integer arithmetic suffices in polynomial time.

Each maximum retains one existing candidate; taking maxima does not accumulate denominators. Finally, multiplying an item price by a bundle size adds at most \(O(\log m)\) numerator bits. Thus every output price has a representation of \(O(L+\log m)\) bits. Fractions can also be reduced in polynomial time if required.

Including bundle indices, the complete output has \(O(2^m(m+L+\log m))\) bits, which is polynomial in \(m\) and \(L\). Table indexing and all remaining bookkeeping likewise require polynomial time. Therefore the entire algorithm has polynomial bit complexity in the requested parameters.

4. Scope of the conclusion

The masses do not enter the prescribed price formulas. Their positivity specifies which types belong to the support; the algorithm need not construct replicated bidders.

The [cited auction convergence result](https://cdn.aaai.org/AAAI/2005/AAAI05-042.pdf) supplies context, but the complexity conclusion follows directly from evaluating the given formulas. The algorithm enumerates exponentially many bundles in \(m\), yet this is polynomial in the length of the explicit input tables.
