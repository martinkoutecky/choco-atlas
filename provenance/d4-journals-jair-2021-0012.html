The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\ge0\) summing to \(1\), integer \(k\ge3\), symmetric rational interactions \(w_{tu}\), and rational threshold \(\theta\), choose \(x_{tq}\ge0\) with \(\sum_{q=1}^{k}x_{tq}=\mu_t\) for every \(t\), and compute an assignment maximizing \(F(x)=\frac12\sum_{q=1}^{k}\sum_{t,u\in T}w_{tu}x_{tq}x_{uq}\), or decide whether \(\max_x F(x)\ge\theta\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of \(\tau\) types with positive masses \(\mu_t\), each a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a binary integer \(k\ge3\) and symmetric binary rational interactions \(w_{tu}\), with both positive and negative entries; normalize nonzero entries to \(|w_{tu}|\ge1\). Zero entries represent absent interactions. Diagonal entries describe interactions between distinct agents of the same type.
All input is available offline. An assignment consists of real masses \(x_{tq}\ge0\) satisfying \(\sum_{q=1}^{k}x_{tq}=\mu_t\). Empty coalitions are allowed, so there are at most \(k\) nonempty coalitions, with no coalition-size bound.
Maximize \(F(x)=\frac12\sum_{q=1}^{k}\sum_{t,u\in T}w_{tu}x_{tq}x_{uq}\), and write \(\mathrm{OPT}=\max_xF(x)\). A multiplicative approximation with finite factor \(\rho\ge1\) returns a feasible rational assignment satisfying \(F(x)\ge\mathrm{OPT}/\rho\) whenever \(\mathrm{OPT}>0\); it must return a feasible assignment on other inputs as well. Assignments may list only nonempty coalitions.
Let \(L\) be the total input bit length. State running times and approximation factors in \(\tau\), \(k\), and \(L\); this model has no separate \(m\) parameter.

Does this continuous maximization problem admit a polynomial-time algorithm with any finite multiplicative approximation factor, or is every such approximation NP-hard?

Modeling choices made when packaging the task

  • Discard zero-mass types and use the positive-mass support as the input society.
  • Interpret k as an upper bound on the number of nonempty coalitions, allow empty labels, and impose no coalition-size bound.
  • Carry over the mixed-sign domain and the normalization that every nonzero interaction has absolute value at least one.
  • Retain diagonal type interactions as interactions between distinct agents of the same type; individual self-interactions have zero mass in the continuum.
  • Define multiplicative guarantees only when the optimum is positive, while requiring a feasible output on every input, to avoid the ambiguity of multiplicative approximation for negative objectives.
  • Use rational outputs represented by their nonempty coalitions, while allowing real masses in the optimization domain.
  • There is no separate m parameter in this interaction model; use support size, coalition bound, and total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Every finite multiplicative approximation is NP-hard, already for \(k=3\). Consequently, unless \(\mathrm{P}=\mathrm{NP}\), there is no polynomial-time approximation with any finite factor \(\rho(\tau,k,L)\), even one that depends arbitrarily on the input parameters.

The proof uses the permitted diagonal interactions and explicitly accounts for fractional assignments.

1. Reduction from graph coloring

Fix an integer \(k\ge3\). We use the NP-completeness of graph \(3\)-colorability. [Garey, Johnson, and Stockmeyer](https://doi.org/10.1016/0304-3975%2876%2990059-1) establish this standard result.

Graph \(k\)-colorability is NP-hard for every such fixed \(k\): given a graph for \(3\)-colorability, add a clique of \(k-3\) vertices, each adjacent to every original vertex. The clique occupies \(k-3\) distinct colors unavailable to the original graph, so the resulting graph is \(k\)-colorable exactly when the original graph is \(3\)-colorable. For fixed \(k\), this transformation has polynomial size.

Let \(G=(V,E)\) be the resulting graph. Add isolated vertices until \(n=|V|\ge2\) is a power of two. This preserves \(k\)-colorability and increases the number of vertices by at most a constant factor.

Construct a society with support \(T=V\cup\{a\}\), where \(a\) is an additional type. Thus \(\tau=n+1\). Set

\(\displaystyle \mu_v=\frac1{2n}\quad(v\in V),\qquad \mu_a=\frac12.\)

These masses are positive dyadic rationals and sum to one. Define the symmetric interactions by

\(\displaystyle w_{vv}=8n^2\quad(v\in V),\)

\(\displaystyle w_{uv}=-8n^2\quad\text{if }\{u,v\}\in E,\)

\(\displaystyle w_{aa}=-8k(n-1),\)

with every remaining entry zero.

All nonzero interactions are integers of absolute value at least one, and both signs occur.

Writing \(z_q=x_{aq}\), the objective becomes

\(\displaystyle F(x)=4n^2\sum_{v\in V}\sum_{q=1}^k x_{vq}^2-8n^2\sum_{\{u,v\}\in E}\sum_{q=1}^k x_{uq}x_{vq}-4k(n-1)\sum_{q=1}^k z_q^2.\)

The edge coefficient accounts for the two symmetric entries in the original objective.

2. Fractional graph types can be rounded without loss

Fix any feasible assignment and a vertex type \(v\). Hold all other rows fixed, and write \(y_q=x_{vq}\) and \(\mu=1/(2n)\). As a function of this row alone, the objective has the form

\(\displaystyle g(y)=C+4n^2\sum_{q=1}^k y_q^2+\sum_{q=1}^k b_qy_q,\)

where \(C\) and the \(b_q\) do not depend on \(y\). The feasible row satisfies \(y_q\ge0\) and \(\sum_qy_q=\mu\).

Let \(\alpha_q=y_q/\mu\), and let \(e_q\) denote the \(q\)-th coordinate vector. Direct calculation gives

\(\displaystyle \sum_{q=1}^k\alpha_qg(\mu e_q)-g(y)=4n^2\left(\mu^2-\sum_{q=1}^k y_q^2\right)\ge0.\)

The inequality follows from

\(\displaystyle \mu^2=\left(\sum_qy_q\right)^2=\sum_qy_q^2+2\sum_{q<r}y_qy_r\ge\sum_qy_q^2.\)

Because the \(\alpha_q\) are nonnegative and sum to one, some \(q\) satisfies \(g(\mu e_q)\ge g(y)\). Moving all of type \(v\)'s mass into that coalition therefore does not decrease the objective.

Apply this argument successively to all \(n\) vertex types, using the current assignment at each step. The resulting feasible assignment has every vertex type entirely in one coalition and has objective at least that of the starting assignment. The additional type \(a\) has remained unchanged.

Thus allowing real, divisible masses cannot improve the optimum beyond assignments with unsplit vertex types.

3. The additional type supplies an exact offset

Type \(a\) has no interactions with any other type. Since \(\sum_qz_q=1/2\), Cauchy–Schwarz gives

\(\displaystyle \sum_{q=1}^kz_q^2\ge\frac{(\sum_qz_q)^2}{k}=\frac1{4k}.\)

Its contribution consequently satisfies

\(\displaystyle -4k(n-1)\sum_{q=1}^kz_q^2\le-(n-1).\)

Equality holds at the feasible rational choice \(z_q=1/(2k)\) for every \(q\). We may therefore replace its row by this uniform row without decreasing the objective.

This uses exactly \(k\) nonempty coalitions, which is permitted by the model.

4. Exact optimum and sign gap

An assignment with unsplit vertex types defines a coloring \(c:V\to\{1,\ldots,k\}\). Let

\(\displaystyle b(c)=|\{\{u,v\}\in E:c(u)=c(v)\}|\)

be its number of monochromatic edges.

Each vertex diagonal contributes

\(\displaystyle \frac12(8n^2)\left(\frac1{2n}\right)^2=1.\)

Each monochromatic edge contributes

\(\displaystyle (-8n^2)\left(\frac1{2n}\right)^2=-2,\)

and every other edge contributes zero. With type \(a\) uniformly distributed, the total is therefore

\(\displaystyle F(x)=n-2b(c)-(n-1)=1-2b(c).\)

Define \(b_k(G)=\min_c b(c)\). Sections 2 and 3 show that every feasible real assignment can be replaced by one of the preceding form without decreasing its objective. Conversely, every coloring yields such a feasible rational assignment. Hence the exact continuous optimum is

\(\displaystyle \mathrm{OPT}=1-2b_k(G).\)

In particular:

  • If \(G\) is \(k\)-colorable, then \(\mathrm{OPT}=1\).
  • If \(G\) is not \(k\)-colorable, then \(b_k(G)\ge1\), so \(\mathrm{OPT}\le-1\).

This is a gap for the full continuous feasible region.

5. Approximation hardness and encoding size

Suppose an algorithm always returns a feasible rational assignment and has some finite approximation factor \(\rho(\tau,k,L)\ge1\).

On a colorable instance, its guarantee forces

\(\displaystyle F(x)\ge\frac{\mathrm{OPT}}{\rho(\tau,k,L)}=\frac1{\rho(\tau,k,L)}>0.\)

On a noncolorable instance, feasibility alone forces \(F(x)\le\mathrm{OPT}\le-1\).

Thus checking the sign of the returned objective decides graph \(k\)-colorability. No evaluation or bound on the approximation factor is needed.

For a polynomial-time algorithm, the output has polynomial bit length. Its objective is a finite sum of products of binary rationals, so its sign can be computed exactly in polynomial time. Taking \(k=3\) therefore gives a polynomial-time decision algorithm for an NP-complete problem.

The constructed instance has \(\tau=n+1\). Under an explicit matrix encoding, its total bit length satisfies

\(\displaystyle L=O(\tau^2\log\tau+\log k).\)

The construction takes polynomial time in \(\tau+\log k\); for each fixed \(k\), the preceding graph transformation is also polynomial. In particular, the hardness excludes algorithms running in \(\operatorname{poly}(L)\), or even in \(\operatorname{poly}(\tau,k,L)\), with any finite factor \(\rho(\tau,k,L)\), unless \(\mathrm{P}=\mathrm{NP}\).

1. Source problem and graph preprocessing

The cited result that graph \(3\)-colorability is NP-complete is valid for finite simple undirected graphs, the standard interpretation used by the construction. The cited paper explicitly establishes NP-completeness results for graph \(3\)-colorability. [Garey, Johnson, and Stockmeyer](https://doi.org/10.1016/0304-3975%2876%2990059-1)

For each fixed \(k\ge3\), the clique construction correctly transfers hardness to graph \(k\)-colorability:

  • The added clique requires \(k-3\) distinct colors.
  • Its adjacency to every original vertex prevents those colors from being used on the original graph.
  • Conversely, a proper \(3\)-coloring of the original graph extends by assigning distinct additional colors to the clique.

For \(k=3\), no clique vertices are added. The polynomial-size claim correctly requires \(k\) to be fixed; the proof states this restriction.

Adding isolated vertices preserves colorability. Padding to a power of two with \(n\ge2\) has only constant-factor overhead. These isolated vertices are included consistently in all subsequent counts and coefficients.

Assessment: correct.

2. Validity of the society instance

The construction satisfies the input restrictions:

  • The support size is exactly \(\tau=n+1\).
  • Every mass is positive.
  • The total mass is \(n/(2n)+1/2=1\).

  • The interaction matrix is symmetric.
  • Every nonzero interaction is an integer of absolute value at least one.

3. Rounding fractional vertex rows

With other rows fixed, the dependence on one vertex row is exactly the stated quadratic-plus-linear expression. There are no omitted nonlinear terms involving that row: interactions with other types are linear in its coordinates.

  • The constant terms cancel.

The resulting conclusion concerns the existence of a dominating assignment with unsplit vertex rows. It does not require every optimizer to have unsplit rows.

4. Optimization of the additional type

The stated Cauchy–Schwarz inequality applies to the \(k\) real coordinates \(z_q\), whose sum is \(1/2\). It gives \(\sum_qz_q^2\ge1/(4k)\).

Since \(-4k(n-1)<0\), multiplying by this coefficient gives the claimed upper bound \(-(n-1)\). The direction of the inequality is correct.

The uniform row \(z_q=1/(2k)\) attains equality, is feasible, and is rational. Its lack of interactions with other types makes this replacement independent of the vertex rows.

The distinction between dyadic input masses and rational output coordinates causes no problem: the task permits rational assignments. Using all \(k\) coalitions also respects the model.

Assessment: correct.

5. Exact optimum and sign gap

For an unsplit vertex row, its diagonal contribution is exactly \(1\). A monochromatic edge contributes exactly \(-2\); an edge joining distinct coalitions contributes zero.

Thus the stated total \(n-2b(c)-(n-1)=1-2b(c)\) is correct.

Both directions needed for the optimum identity are present:

  • Every feasible real assignment is dominated by an assignment associated with a coloring and a uniform additional row.
  • Every coloring yields a feasible rational assignment of that form.

Therefore \(\mathrm{OPT}=1-2b_k(G)\) follows.

If the graph is colorable, \(b_k(G)=0\), so \(\mathrm{OPT}=1\). If it is not colorable, every coloring has at least one monochromatic edge, so \(\mathrm{OPT}\le-1\).

In particular, the negative upper bound holds for all feasible fractional assignments, not merely the rounded assignments.

Assessment: correct. The sign gap settles the continuous formulation.

6. Approximation-to-decision argument

On a colorable instance, any finite factor \(\rho(\tau,k,L)\ge1\) forces the returned objective to be strictly positive.

On a noncolorable instance, the requirement to return a feasible assignment forces its objective to be at most \(-1\), even though no approximation guarantee is required when the optimum is nonpositive.

Thus the returned objective’s sign distinguishes the two cases. The proof correctly avoids needing to compute, represent, or bound the approximation factor.

For a polynomial-time algorithm, the explicit rational output has polynomial bit length. Evaluating its quadratic objective and determining its sign using exact rational arithmetic takes polynomial time. This remains valid even when a positive returned value is very small.

Fixing \(k=3\) therefore gives the claimed polynomial-time decision procedure for an NP-complete problem if such an approximation algorithm exists.

Assessment: correct.
