The continuous mirror question, as graded

Given rational agent-type masses \(\mu_v\), rational per-capita supplies \(\sigma_e\) of indivisible item types, and for each item type \(e\) at most two eligible agent types receiving the same utility \(w_e\), choose nonnegative bundle masses \(y_{v,B}\), where \(B\) is an integral subset of item types eligible for \(v\), so that \(\sum_B y_{v,B}=\mu_v\), \(\sum_{v,B:e\in B}y_{v,B}\le\sigma_e\), and every used bundle satisfies \(\sum_{e\in B}w_e\ge\lambda\); maximize \(\lambda\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\ge1\) agent types with positive binary-rational masses \(\mu_v\), normalized by \(\sum_v\mu_v=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) item types. Each item type \(e\) has binary-rational per-capita supply \(\sigma_e\ge0\), binary-rational utility \(w_e>0\), and an eligibility set \(E_e\) containing at most two agent types; eligible types receive utility \(w_e\), and other types receive zero.
For type \(v\), a bundle is an integral subset \(B\subseteq\{e:v\in E_e\}\): it contains at most one item of each item type. Distinct item types may have identical weights and eligibility sets.
An allocation consists of nonnegative bundle masses \(y_{v,B}\) satisfying \(\sum_B y_{v,B}=\mu_v\) and \(\sum_{v,B:e\in B}y_{v,B}\le\sigma_e\). Unused supply is allowed.
Its guaranteed utility is the largest \(\lambda\ge0\) such that every bundle with \(y_{v,B}>0\) satisfies \(\sum_{e\in B}w_e\ge\lambda\). Let \(\mathrm{OPT}\) be the maximum guaranteed utility, and let \(L\) be the total binary input length.

Does this mass-allocation problem admit a \((2-\delta)\)-approximation in time polynomial in \(m,\tau,L\) for some fixed \(0<\delta<1\), or is obtaining such an approximation NP-hard for every fixed \(0<\delta<1\)?

For discrete agents and items, obtaining a \((2-\delta)\)-approximation is NP-hard even with equal utilities at the two eligible endpoints; a polynomial-time \((2+\varepsilon)\)-approximation exists even with unequal endpoint utilities. [Source](https://arxiv.org/pdf/0901.0205)
For the discrete configuration LP with unit agent demands and unit item capacities, a feasible threshold can be approximated within \(1-\varepsilon\) in polynomial time for fixed \(\varepsilon>0\); this is a neighboring result, not a statement about arbitrary rational masses and supplies. [Source](https://www.cis.upenn.edu/~sanjeev/postscript/max-min-allocation.pdf)

Modeling choices made when packaging the task

  • Normalized total agent mass to one so that supplies have the stated per-capita meaning.
  • Specified nonnegative rational supplies and positive rational utilities; zero-utility item types can be discarded without affecting the objective.
  • Specified nonempty society and item list, while allowing zero optimum and unused supply.
  • Retained the graded question's subset convention: each bundle contains at most one item of each item type, with distinct identical item types allowed.
  • Restricted the approximation parameter to 0<δ<1 so that the approximation factor exceeds one.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Proven result

The mass-allocation problem admits an FPTAS. More precisely, for every rational \(0<\varepsilon<1\), an allocation guaranteeing at least \((1-\varepsilon)\mathrm{OPT}\) can be computed in time polynomial in \(m,\tau,L,1/\varepsilon\).

Taking \(\varepsilon=1/3\) gives a polynomial-time \(3/2\)-approximation, answering the question affirmatively with \(\delta=1/2\).

The proof works for arbitrary eligibility sets; the restriction to at most two eligible types is unnecessary.

1. Threshold feasibility is exactly a configuration LP

Write \(I_v=\{e:v\in E_e\}\) and \(w(B)=\sum_{e\in B}w_e\).

For a threshold \(T>0\), define \(\mathcal C_v(T)=\{B\subseteq I_v:w(B)\ge T\}\). An allocation guaranteeing \(T\) exists exactly when the following finite, potentially exponential-size linear system is feasible:

\(y_{v,B}\ge0\quad(v,\ B\in\mathcal C_v(T))\),

\(\sum_{B\in\mathcal C_v(T)}y_{v,B}=\mu_v\quad(v)\),

\(\sum_v\sum_{\substack{B\in\mathcal C_v(T)\\e\in B}}y_{v,B}\le\sigma_e\quad(e)\).

This equivalence follows directly from the definition: every positive-mass bundle must belong to the corresponding configuration family.

We will replace these families by rounded families that have a polynomial-size flow representation. The masses and supplies remain unchanged.

2. Utility rounding gives a threshold guarantee

Fix \(T>0\), and let \(N>m\) be an integer. Define

\(a_e=\left\lfloor N\min\{w_e,T\}/T\right\rfloor\), and \(K=N-m\).

Thus \(0\le a_e\le N\). Call a bundle \(B\) rounded-admissible if \(\sum_{e\in B}a_e\ge K\).

Lemma.

  • Every bundle of utility at least \(T\) is rounded-admissible.
  • Every rounded-admissible bundle has utility at least \((1-m/N)T\).

Proof. Suppose \(w(B)\ge T\). Then \(\sum_{e\in B}\min\{w_e,T\}\ge T\): if some item has weight at least \(T\), that item alone contributes \(T\); otherwise truncation changes no weight.

Using \(\lfloor x\rfloor\ge x-1\) and \(|B|\le m\), we obtain

\(\sum_{e\in B}a_e\ge \frac{N}{T}\sum_{e\in B}\min\{w_e,T\}-|B|\ge N-m=K\).

Conversely, the definition gives \(a_e\le Nw_e/T\). Therefore, if \(B\) is rounded-admissible,

\(w(B)\ge \frac{T}{N}\sum_{e\in B}a_e\ge \frac{T}{N}K=(1-m/N)T\).

This proves both assertions. Consequently, rounded threshold feasibility has the following two properties:

  • If \(T\) is feasible in the original instance, the rounded system is feasible.
  • A feasible rounded system produces an original allocation guaranteeing \((1-m/N)T\).

3. A polynomial-size LP for rounded feasibility

For each type \(v\), construct a directed acyclic multigraph. Its vertices are \((j,q)\), where \(0\le j\le m\) and \(0\le q\le K\). The layer \(j\) records that the first \(j\) item types have been considered.

At layer \(j-1\), include the following arcs for every state \(q\):

  • A skip arc from \((j-1,q)\) to \((j,q)\).
  • If \(j\in I_v\), a take arc, labeled \(j\), from \((j-1,q)\) to \((j,\min\{K,q+a_j\})\).

Keep skip and take arcs distinct even when their endpoints coincide. The source is \(s_v=(0,0)\), and the sink is \(t_v=(m,K)\).

A path selects a bundle by taking precisely its labeled items. Each item is considered once, so the bundle contains at most one copy of each item type. Induction over the layers shows that the state after processing a bundle prefix is its rounded utility capped at \(K\). Hence source-to-sink paths correspond exactly to rounded-admissible bundles.

Introduce a nonnegative flow variable \(f_{v,h}\) for every arc \(h\) in type \(v\)'s graph. Impose:

  • Flow conservation at every vertex other than \(s_v,t_v\).
  • Net outflow \(\mu_v\) at \(s_v\) and net inflow \(\mu_v\) at \(t_v\).
  • For each item \(e\), the supply constraint

\(\sum_v\sum_{\substack{h:\ h\text{ is a take arc}\\h\text{ labeled }e}}f_{v,h}\le\sigma_e\).

Proposition. This flow LP is feasible if and only if an allocation using only rounded-admissible bundles exists.

Proof. Given such an allocation, send \(y_{v,B}\) units along the path corresponding to \(B\). The type-mass equations give the required flow values, and each selected item contributes once to its supply constraint.

Conversely, a nonnegative flow in a directed acyclic graph decomposes into source-to-sink paths. Here is an explicit recovery procedure. Start at a positive-flow arc leaving the source and follow positive-flow arcs. Conservation prevents the walk from stopping at an intermediate vertex, and acyclicity prevents repetition, so it reaches the sink. Subtract the minimum flow on this path and record that amount as its bundle mass.

Each iteration removes at least one positive-flow arc. After at most the number of arcs iterations, the residual flow is zero: a nonzero residual with zero source value would contradict conservation and acyclicity. Thus the recovered path masses sum to \(\mu_v\). Their item consumption equals the original take-arc flow, so every supply constraint remains satisfied. Every recovered bundle is rounded-admissible. This proves the proposition.

Each graph has \((m+1)(K+1)\) vertices and at most \(2m(K+1)\) arcs. The LP therefore has \(O(\tau mN)\) variables and constraints.

We use the standard rational linear-programming theorem: feasibility of an explicitly given rational linear system can be decided, and a rational feasible point recovered when one exists, in time polynomial in its binary encoding length. Its hypotheses hold here: the LP is explicit, its matrix entries belong to \(\{-1,0,1\}\), and its right-hand sides are the input rationals \(\mu_v,\sigma_e\).

The recovered feasible point has polynomial binary length. Path decomposition uses only polynomially many comparisons and subtractions, so it also returns an explicit allocation of polynomial encoding length. No denominator-sized population expansion is involved.

4. Searching for an approximately optimal threshold

Fix rational \(0<\varepsilon<1\), and choose

\(N=\left\lceil 3m/\varepsilon\right\rceil\), \(\eta=\varepsilon/3\), and \(q=1+\eta\).

Then \(m/N\le\eta\), so a successful rounded test at \(T\) produces an allocation guaranteeing at least \((1-\eta)T\).

Let \(w_{\min}=\min_e w_e>0\) and \(U=\sum_e w_e\). Every bundle has utility at most \(U\), hence \(\mathrm{OPT}\le U\).

Also, if \(\mathrm{OPT}>0\), then \(\mathrm{OPT}\ge w_{\min}\). Indeed, every positive-utility bundle is nonempty and therefore has utility at least \(w_{\min}\); any allocation with positive guarantee already guarantees \(w_{\min}\).

For completeness, the maximum defining \(\mathrm{OPT}\) is attained. There are finitely many bundles, and an allocation's guaranteed utility is the minimum utility among its positive-mass bundles. Thus the set of attainable guarantees is a nonempty finite set.

Test rounded feasibility at every threshold

\(T_j=w_{\min}q^j\), for \(j=0,\ldots,J\),

where \(J\) is the largest index for which \(T_J\le U\).

If no test succeeds, return the allocation assigning the empty bundle to every type. This case has \(\mathrm{OPT}=0\): otherwise \(w_{\min}\) would be feasible, and its rounded test would succeed by the lemma.

Suppose now that \(\mathrm{OPT}>0\). Let \(j^*\) be the largest index with \(T_{j^*}\le\mathrm{OPT}\). Since the next geometric threshold exceeds \(\mathrm{OPT}\),

\(T_{j^*}>\mathrm{OPT}/q\).

The original threshold \(T_{j^*}\) is feasible, so its rounded test succeeds. Choose the largest successful tested threshold \(\widehat T\) and recover its allocation. Its guaranteed utility \(\lambda\) satisfies

\(\lambda\ge(1-\eta)\widehat T\ge(1-\eta)T_{j^*}\ge\frac{1-\eta}{1+\eta}\mathrm{OPT}\).

Finally,

\(\frac{1-\eta}{1+\eta}=1-\frac{2\eta}{1+\eta}\ge1-2\eta=1-\frac{2\varepsilon}{3}\ge1-\varepsilon\).

This proves the required approximation guarantee.

5. Binary complexity

The number of thresholds is

\(J+1=O\!\left(1+\frac{\log(U/w_{\min})}{\varepsilon}\right)\).

A positive input rational of encoding length at most \(L\) lies between \(2^{-L}\) and \(2^L\). Therefore \(U/w_{\min}\le m\,2^{2L}\), and the number of tests is \(O((L+\log m)/\varepsilon)\).

All thresholds are computed exactly as rational numbers. If the encoding length of \(\varepsilon\) is \(b\), the numerator and denominator of \(T_j=w_{\min}(1+\varepsilon/3)^j\) have length \(O(L+jb)\). Computing each \(a_e\) requires exact rational comparison, multiplication, division, and integer flooring, all in polynomial time in these lengths.

Moreover, \(N=O(m/\varepsilon)\), so every rounded flow LP has polynomial size. Exact rational LP solution and path recovery therefore give total running time polynomial in \(m,\tau,L,1/\varepsilon\) and the encoding length of \(\varepsilon\).

This establishes an FPTAS for the stated input model.

6. Why discrete hardness does not transfer

If a discrete instance has \(n\) agents, setting each type mass and each item supply to \(1/n\), then rescaling allocation masses by \(n\), gives its configuration LP. It does not impose an integral choice of one bundle for each agent: bundle masses may split among configurations.

The supplied paper treats configuration-LP solution and subsequent rounding to a discrete allocation as separate steps; see [Section 6.1 of *On Allocating Goods to Maximize Fairness*](https://www.cis.upenn.edu/~sanjeev/postscript/max-min-allocation.pdf). In the present problem, a feasible configuration mixture is already a valid allocation. The proof above handles arbitrary rational masses and supplies directly.

Thus the first alternative holds: choosing \(\varepsilon=1/3\) yields a polynomial-time \(3/2=(2-\delta)\)-approximation with \(\delta=1/2\).
