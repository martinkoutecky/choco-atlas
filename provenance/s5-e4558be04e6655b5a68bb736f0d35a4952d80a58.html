The continuous mirror question, as graded

Given a finite item set \(G\), finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), rational per-capita supplies \(\kappa_j\), and type data \(t=(S_t,\theta_t)\), compute a feasible mass allocation \(x_t\) maximizing \(\sum_{t\in T}\theta_t x_t\), subject to \(0\le x_t\le\mu_t\) and \(\sum_{t:j\in S_t}x_t\le\kappa_j\) for every \(j\in G\).

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a finite item set, with \(m=|G|\). A society is given by its support: the list of \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types.
Each type \(t\) has a publicly known set \(S_t\subseteq G\) and a nonnegative rational value \(\theta_t\) for receiving one copy of every item in \(S_t\). Masses satisfy \(\sum_t\mu_t=1\); per-capita supplies \(\kappa_j\) are nonnegative binary rationals.
An allocation serves a divisible mass \(x_t\) of each type, with \(0\le x_t\le\mu_t\) and \(\sum_{t:j\in S_t}x_t\le\kappa_j\) for each \(j\in G\). Its welfare is \(W(x)=\sum_t\theta_t x_t\); let \(\mathrm{OPT}\) be the maximum feasible welfare. Let \(L\) be the total binary input length.

For every rational \(\varepsilon\in(0,1)\), can a feasible allocation with expected welfare at least \((1-\varepsilon)\mathrm{OPT}\) be computed in time polynomial in \(m,\tau,L,1/\varepsilon\), or is this approximation guarantee computationally hard?

For discrete known single-minded bidders, a randomized polynomial-time algorithm guarantees expected welfare at least \((1-\varepsilon')(1-2/K^c)\mathrm{OPT}\), where \(K\) is the largest requested-set size, provided every item multiplicity is sufficiently large, of order \(\log K\), with constants depending on \(\varepsilon'\) and \(c\).
Fractional bidder allocations with linear welfare are also explicitly studied as an LP formulation in [Archer, Papadimitriou, Talwar, and Tardos](https://www.microsoft.com/en-us/research/wp-content/uploads/2003/01/pub03-comb-auc.pdf); no separate result for this support-encoded mass formulation was verified.

Modeling choices made when packaging the task

  • The anchor is an approximation result despite its algorithmic label, so the target retains near-optimal approximation rather than asking for exact optimization.
  • Values and supplies are nonnegative binary rationals; zero values and zero supplies are permitted.
  • Serving a mass means satisfying that mass's entire requested set, consuming one unit of each requested item per unit mass.
  • No minimum supply is imposed: the discrete logarithmic multiplicity assumption concerns unnormalized copy counts and has no specified counterpart in the normalized mass input.
  • The discrete tunable approximation factors are expressed through one rational accuracy parameter, with running time polynomial in its reciprocal.

Result

An exact optimal allocation can be computed deterministically in time polynomial in \(m,\tau,L\). Consequently, the requested approximation guarantee holds for every rational \(\varepsilon\in(0,1)\), without any lower bound on supplies or restriction on requested-set sizes.

The proof uses precisely the stated model: each type’s served mass is divisible, and welfare is linear in that mass.

1. An exact linear-programming formulation

Index the listed types by \(t\in\{1,\ldots,\tau\}\). Define the incidence matrix \(A\in\{0,1\}^{m\times\tau}\) by \(A_{jt}=1\) if \(j\in S_t\), and \(A_{jt}=0\) otherwise.

Consider the rational linear program
\[ \max\left\{\theta^{\mathsf T}x: Ax\leq\kappa,\quad 0\leq x\leq\mu\right\}. \]

Its feasible vectors are exactly the allocations in the question:

  • The bounds \(0\leq x_t\leq\mu_t\) express how much mass of type \(t\) may be served.
  • For each item \(j\), the inequality \((Ax)_j\leq\kappa_j\) is exactly its supply constraint.
  • The objective \(\theta^{\mathsf T}x\) equals \(W(x)\).

Thus the LP optimum equals \(\mathrm{OPT}\); there is no relaxation gap.

The feasible region is nonempty because \(x=0\) is feasible. It is closed and bounded because it lies in \(\prod_{t=1}^{\tau}[0,\mu_t]\). Therefore the continuous linear objective attains a finite maximum.

2. Polynomial encoding and exact computation

The LP has \(\tau\) variables and \(m+2\tau\) inequalities. Its constraint coefficients belong to \(\{-1,0,1\}\); its remaining numerical data are the input rationals \(\kappa,\mu,\theta\).

Constructing the incidence matrix from the explicitly listed sets takes polynomial time. Even a dense encoding of the entire LP has length
\[ O\!\left(m\tau+\tau^2+L\right), \]
which is polynomial in the requested parameters.

We apply the standard exact rational linear-programming theorem: a linear program with explicitly encoded rational coefficients can be solved in time polynomial in its binary encoding length, returning an exact rational optimal solution whenever it is feasible with a finite optimum. Exact polynomial-time methods, including recovery of rational solutions, are discussed in §1.3 of [*Linear Programming using Limited-Precision Oracles*](https://optimization-online.org/wp-content/uploads/2019/12/7507.pdf).

All hypotheses have been checked: the LP is explicitly encoded, rational, feasible, and has a finite attained optimum. Hence an exact optimal vector \(x^*\) can be computed and output in time polynomial in \(m,\tau,L\).

Crucially, the construction uses one variable per supported type. It does not expand a binary rational mass into individual bidders or enumerate types absent from the support.

3. The approximation guarantee

Return \(x^*\) deterministically. Its feasibility follows from the LP constraints, and
\[ \mathbb{E}[W(x^*)] =W(x^*) =\mathrm{OPT} \geq(1-\varepsilon)\mathrm{OPT}. \]
The last inequality follows from \(\mathrm{OPT}\geq0\), since the zero allocation is feasible.

The algorithm need not use \(\varepsilon\), so its runtime is, in particular, polynomial in \(m,\tau,L,1/\varepsilon\). The argument also covers \(\mathrm{OPT}=0\).

4. Why the discrete approximation theorem is unnecessary

Discrete bidders require indivisible service decisions. Here, every value \(x_t\in[0,\mu_t]\) satisfying the supply constraints is an admissible allocation. Consequently, solving the LP already produces the required allocation, with no rounding step or associated welfare loss.

This directly establishes tractability for the support-encoded mass formulation, independently of any separate published theorem about that formulation.
