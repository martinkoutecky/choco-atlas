The continuous mirror question, as graded

Given a finite type set \(T\), rational type masses \(\mu_t\), a fixed maximum team size \(K\), team-size densities \(\rho_g\), and values \(w_g(a)\) for teams with type-count vector \(a\), compute the limiting average total coalition value per agent over uniformly chosen partitions with those team-size densities.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Fix a maximum team size \(K\ge1\). Input team densities \(\rho_g\in\mathbb{Q}_{\ge0}\), for \(1\le g\le K\), count teams per agent and satisfy \(\sum_{g=1}^K g\rho_g=1\).
For every \(a\in\mathbb{Z}_{\ge0}^{T}\) with \(\sum_t a_t=g\le K\) and \(g\ge1\), an explicit table gives a binary rational value \(w_g(a)\ge0\). Let \(m\) be the number of table entries and \(L\) the total input bit length.
For each positive integer \(n\) making all \(n\mu_t\) and \(n\rho_g\) integers, take \(n\) distinct labeled agents, with \(n\mu_t\) agents of type \(t\). Choose \(\Pi_n\) uniformly among unordered set partitions having exactly \(n\rho_g\) nonempty teams of size \(g\); every agent belongs to exactly one team.
Write \(a(C)\) for the type-count vector of team \(C\), and define the limiting average value per agent by \(D=\lim_{n\to\infty}\frac{1}{n}\mathbb{E}[\sum_{C\in\Pi_n}w_{|C|}(a(C))]\), along those admissible integers.

Does \(D\) exist for every admissible input, and is its exact computation polynomial-time solvable in \(m,\tau,L\) for every fixed \(K\), or is deciding \(D\ge q\), for an input binary rational threshold \(q\), NP-hard for some fixed \(K\)?

Discrete: for any prescribed multiset of team sizes, the uniform average total partition value equals the sum, with multiplicities, of the average coalition values at those sizes. [Verified source](https://cdn.aaai.org/AAAI/2007/AAAI07-188.pdf).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The limit exists for every admissible input, and its exact computation is polynomial-time solvable for every fixed \(K\). Explicitly,

\[ D=\sum_{g=1}^{K}\rho_g \sum_{\substack{a\in\mathbb Z_{\ge0}^{T}\\ \sum_t a_t=g}} w_g(a)\frac{g!}{\prod_{t\in T}a_t!} \prod_{t\in T}\mu_t^{a_t}. \]

Thus deciding \(D\ge q\) is also polynomial-time solvable for every fixed \(K\).

1. Admissible populations and partitions exist

All masses and densities are rational. Let \(d\) be the least common multiple of their denominators. Every positive multiple \(n\) of \(d\) is admissible, so admissible integers are unbounded.

Fix an admissible \(n\), and write \(N_t=n\mu_t\) and \(b_g=n\rho_g\). These are nonnegative integers, and

\[ \sum_{t\in T}N_t=n, \qquad \sum_{g=1}^{K}g b_g=n. \]

Consequently, the labeled agents can be partitioned into \(b_g\) teams of size \(g\): arrange the agents in any order and divide them into blocks of the prescribed sizes. The set on which the uniform distribution is defined is therefore nonempty.

Types impose no restriction on which partitions are allowed; they determine only the values assigned to their teams.

2. Exact finite-population expectation

Take an admissible \(n\ge K\). For any subset \(S\) of the labeled agents, let \(I_S\) be the indicator that \(S\) is a team in \(\Pi_n\).

For a fixed size \(g\), every subset \(S\) of size \(g\) has the same inclusion probability. Indeed, any permutation of agent labels bijects the allowed partitions with themselves, preserves their uniform distribution, and can map any such subset to any other.

Every allowed partition has exactly \(b_g\) teams of size \(g\). Hence

\[ \sum_{|S|=g}I_S=b_g, \qquad \mathbb P(I_S=1)=\frac{b_g}{\binom ng}. \]

By linearity of expectation,

\[ \frac1n\mathbb E\!\left[ \sum_{C\in\Pi_n}w_{|C|}(a(C)) \right] = \sum_{g=1}^{K}\rho_g \frac1{\binom ng} \sum_{|S|=g}w_g(a(S)). \]

This argument applies directly to unordered partitions. It also proves, in this setting, the discrete averaging identity stated in Theorem 1 of the supplied [Rahwan et al. paper](https://cdn.aaai.org/AAAI/2007/AAAI07-188.pdf).

Define

\[ A_g=\left\{a\in\mathbb Z_{\ge0}^{T}:\sum_{t\in T}a_t=g\right\}. \]

For \(a\in A_g\), the number of subsets with type-count vector \(a\) is \(\prod_{t\in T}\binom{N_t}{a_t}\). Here \(\binom{N_t}{a_t}=0\) when \(a_t>N_t\). Grouping the subsets by their type counts gives the exact identity

\[ \frac1n\mathbb E\!\left[ \sum_{C\in\Pi_n}w_{|C|}(a(C)) \right] = \sum_{g=1}^{K}\rho_g \sum_{a\in A_g} w_g(a) \frac{\prod_{t\in T}\binom{n\mu_t}{a_t}}{\binom ng}. \tag{1} \]

No independence between teams is needed.

3. Passage to the limit

For a nonnegative integer \(r\), define the falling factorial by \((x)_0=1\) and \((x)_r=\prod_{j=0}^{r-1}(x-j)\).

For each fixed \(g\) and \(a\in A_g\),

\[ \frac{\prod_t\binom{n\mu_t}{a_t}}{\binom ng} = \frac{g!}{\prod_t a_t!} \frac{\prod_t(n\mu_t)_{a_t}}{(n)_g}. \]

Because \(\sum_t a_t=g\), dividing the numerator and denominator of the last fraction by \(n^g\) yields

\[ \frac{\prod_t(n\mu_t)_{a_t}}{(n)_g} = \frac{ \prod_{t\in T}\prod_{j=0}^{a_t-1}(\mu_t-j/n) }{ \prod_{j=0}^{g-1}(1-j/n) } \longrightarrow \prod_{t\in T}\mu_t^{a_t}. \]

The denominator converges to \(1\), and every product has finitely many factors. For the fixed input, the sums in (1) also have finitely many terms. Taking their limits term by term proves the asserted formula for \(D\), along all admissible integers.

The coefficient

\[ \frac{g!}{\prod_t a_t!}\prod_t\mu_t^{a_t} \]

is the multinomial probability of type-count vector \(a\) in \(g\) independent draws from the type distribution. Thus the limiting contribution of size \(g\) is its team density multiplied by its multinomial average value.

4. Exact computation and bit complexity

It remains to verify that evaluating the formula takes polynomial bit time.

Write the input rationals with integer numerators and positive integer denominators:

\[ \mu_t=\frac{u_t}{v_t}, \qquad \rho_g=\frac{r_g}{s_g}, \qquad w_g(a)=\frac{x_{g,a}}{y_{g,a}}. \]

Set

\[ B_\mu=\prod_{t\in T}v_t, \qquad B_\rho=\prod_{g=1}^{K}s_g, \qquad B_w=\prod_{g=1}^{K}\prod_{a\in A_g}y_{g,a}, \qquad Q=B_\mu^K B_\rho B_w. \]

Each summand in the formula for \(D\) has an integer numerator over the denominator

\[ s_g y_{g,a}\prod_t v_t^{a_t}, \]

since \(g!/\prod_t a_t!\) is an integer. This denominator divides \(Q\): each exponent \(a_t\) is at most \(K\). Therefore \(D=P/Q\) for a nonnegative integer \(P\).

The sum of the binary lengths of the input denominators is at most \(L\). Consequently, \(Q\) has bit length \(O(KL)\), which is \(O(L)\) for fixed \(K\).

The numerator also has polynomial length. Let \(W=\max_{g,a}w_g(a)\). The multinomial theorem and \(\sum_t\mu_t=1\) give

\[ \sum_{a\in A_g} \frac{g!}{\prod_t a_t!}\prod_t\mu_t^{a_t}=1. \]

Moreover, \(\sum_g\rho_g\le\sum_g g\rho_g=1\). Hence

\[ 0\le D\le W, \qquad 0\le P=QD\le QW. \]

Because \(W\) is an input rational, its magnitude is at most \(2^L\). Thus \(P\) also has bit length \(O(KL+L)\). All partial sums after scaling by \(Q\) satisfy the same bound, because the summands are nonnegative.

An exact algorithm now proceeds as follows:

  • Compute \(Q\), factorials through \(K\), and the powers \(u_t^r,v_t^r\) for \(0\le r\le K\).
  • Scan each of the \(m\) table entries and compute its summand, scaled by \(Q\), using integer multiplication and exact division.
  • Add the scaled summands to obtain \(P\), and reduce \(P/Q\) by their greatest common divisor if desired.

Scanning dense type-count vectors takes \(O(m\tau)\) elementary steps. All arithmetic operands have polynomial bit length, and integer arithmetic and greatest common divisor computation take polynomial time. This proves exact polynomial-time computability in \(m,\tau,L\) for every fixed \(K\).

Finally, write the threshold as \(q=h/j\), with \(j>0\). Comparing \(D\ge q\) is exactly the integer comparison \(Pj\ge hQ\), which also takes polynomial time.
