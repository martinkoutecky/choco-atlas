The continuous mirror question, as graded

For a fixed scoring rule \(r\) in either anchored class, given candidates \(C\), a target \(c^\star\), and a finite support \(T\) of ordered-partition types with positive binary-rational masses \(\mu_t\) summing to \(1\), determine whether there are \(x_{t,\pi}\ge 0\) for each strict refinement \(\pi\) of type \(t\), such that \(\sum_{\pi}x_{t,\pi}=\mu_t\) for every \(t\), and \(\sum_{t,\pi}x_{t,\pi}\alpha^{(m)}_{\mathrm{pos}_{\pi}(c^\star)}\ge \sum_{t,\pi}x_{t,\pi}\alpha^{(m)}_{\mathrm{pos}_{\pi}(d)}\) for every \(d\in C\).

Packaged proof task (what the prover saw — nothing else)

Fix a pure positional scoring rule \(r\) whose scoring vectors have at least four distinct values for all sufficiently large candidate counts. Write its polynomial-time computable vector in rank order as \(\alpha^{(m)}_1\ge\cdots\ge\alpha^{(m)}_m=0\), with nonnegative integer entries of greatest common divisor one; purity means successive vectors are obtained by inserting one entry while preserving this order.
An instance has a candidate set \(C\), with \(m=|C|\ge2\), and a distinguished candidate \(c^\star\in C\). Each type \(t\) is an ordered partition \((A_{t,1},\ldots,A_{t,q_t})\) of \(C\) into nonempty blocks: every candidate in an earlier block precedes every candidate in a later block, and candidates within a block are incomparable. Let \(\Pi(t)\) be its strict linear refinements, with positions numbered from the top starting at \(1\).
A society is given by its support: the list \(T\) of the \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types. Let \(L\) be the total binary encoding length of the instance and its scoring vector; state running times in \(m,\tau,L\).
The mass possible-co-winner problem asks whether there exist real numbers \(x_{t,\pi}\ge0\), indexed by \(t\in T\) and \(\pi\in\Pi(t)\), such that \(\sum_{\pi\in\Pi(t)}x_{t,\pi}=\mu_t\) for every \(t\), and \(\sum_{t\in T}\sum_{\pi\in\Pi(t)}x_{t,\pi}\alpha^{(m)}_{\operatorname{pos}_{\pi}(c^\star)}\ge\sum_{t\in T}\sum_{\pi\in\Pi(t)}x_{t,\pi}\alpha^{(m)}_{\operatorname{pos}_{\pi}(d)}\) for every \(d\in C\). Ties count as co-winning. Refinements are implicit, not listed in the input.

For each fixed \(r\) in this class, is the mass possible-co-winner problem in P or NP-hard?

For finite lists of unweighted voters with partitioned preferences, possible co-winning is NP-complete for this class of rules ([Kenig](https://arxiv.org/pdf/1802.09001)). A later statement explicitly requires purity and confirms NP-completeness for rules with eventually exactly \(K\ge4\) distinct scores ([Kenig, 2019](https://www.ifaamas.org/Proceedings/aamas2019/pdfs/p2051.pdf)).
No result settling exactly the mass problem above was located in the literature search.

Result

For every fixed rule \(r\) in the question, the mass possible-co-winner problem belongs to \(\mathrm{P}\). It can be decided in \((\tau m^2 L)^{O(1)}\) bit operations.

The proof applies to every rational positional scoring vector. Purity and the number of distinct scores impose no additional difficulty.

1. A polynomial-size linear program

For each type \(t\), define the first position occupied by block \(A_{t,i}\) as

\(b_{t,i}=1+\sum_{h<i}|A_{t,h}|\),

and its position interval as

\(J_{t,i}=\{b_{t,i},\ldots,b_{t,i}+|A_{t,i}|-1\}\).

For a candidate \(d\in A_{t,i}\), put \(J_t(d)=J_{t,i}\). In every refinement of \(t\), candidate \(d\) occupies a position in \(J_t(d)\).

Introduce a real variable \(y_{t,d,j}\) for every \(t\in T\), \(d\in C\), and \(j\in J_t(d)\). Its intended meaning is the mass of type \(t\) that assigns candidate \(d\) to position \(j\).

Impose nonnegativity and the following equations:

  • For every \(t\in T\) and \(d\in C\),

\(\displaystyle \sum_{j\in J_t(d)}y_{t,d,j}=\mu_t.\)

  • For every \(t\in T\) and \(j\in\{1,\ldots,m\}\),

\(\displaystyle \sum_{\substack{d\in C\\j\in J_t(d)}}y_{t,d,j}=\mu_t.\)

These equations require every candidate to be assigned throughout its type’s mass, and every position to be occupied throughout that mass.

Define the total score of candidate \(d\) by

\(\displaystyle S_d(y)=\sum_{t\in T}\sum_{j\in J_t(d)}\alpha^{(m)}_j y_{t,d,j}.\)

Finally, impose

\(\displaystyle S_{c^\star}(y)\ge S_d(y)\qquad(d\in C\setminus\{c^\star\}).\)

Call the resulting rational linear feasibility problem \(\mathcal L\).

We will prove that \(\mathcal L\) is feasible exactly when the given mass instance admits a possible co-winner.

2. Decomposition lemma

Lemma. Let \(Y\) be a nonnegative \(m\)-by-\(m\) real matrix whose row sums and column sums all equal \(a>0\). Then there are permutation matrices \(P_1,\ldots,P_k\) and positive real numbers \(\lambda_1,\ldots,\lambda_k\) such that

\(\displaystyle Y=\sum_{\ell=1}^k\lambda_\ell P_\ell,\qquad \sum_{\ell=1}^k\lambda_\ell=a.\)

Every \(P_\ell\) uses only entries where \(Y\) is positive, and \(k\) is at most the number of positive entries of \(Y\).

Proof. We give a finite subtraction procedure.

Suppose the current residual matrix \(R\) is nonnegative and has all row and column sums equal to \(\rho>0\). Construct a bipartite graph with rows on the left, columns on the right, and an edge precisely where \(R_{d,j}>0\).

For any set \(U\) of rows, let \(N(U)\) be its neighboring columns. All positive entries in those rows lie in columns \(N(U)\). Consequently,

\(\displaystyle \rho|U|=\sum_{d\in U}\sum_{j\in N(U)}R_{d,j}\le \sum_{j\in N(U)}\sum_{d=1}^m R_{d,j}=\rho|N(U)|.\)

Since \(\rho>0\), this proves \(|U|\le |N(U)|\). Hall’s marriage theorem therefore supplies a perfect matching. Let \(P\) be its permutation matrix and set

\(\displaystyle \varepsilon=\min\{R_{d,j}:P_{d,j}=1\}>0.\)

The matrix \(R-\varepsilon P\) remains nonnegative, and all its row and column sums equal \(\rho-\varepsilon\). Moreover, at least one positive entry becomes zero, and no zero entry becomes positive.

Start with \(R=Y\) and \(\rho=a\), and repeat while \(\rho>0\). Each iteration strictly decreases the number of positive entries, so the procedure terminates after at most the initial number of positive entries. At termination the common row sum is zero; nonnegativity then implies that the residual matrix is zero.

Recording the selected matrices and subtracted amounts gives the asserted decomposition. The common row sum decreases from \(a\) to zero, so the amounts sum to \(a\). Every selected edge belonged to the original positive support because that support only shrinks. \(\square\)

3. Exact equivalence with the mass problem

A mass solution gives an LP solution

Suppose \(x_{t,\pi}\) satisfies the requirements in the question. Define

\(\displaystyle y_{t,d,j}=\sum_{\substack{\pi\in\Pi(t)\\\operatorname{pos}_\pi(d)=j}}x_{t,\pi}\qquad(j\in J_t(d)).\)

Every refinement assigns each candidate to exactly one permitted position, so the candidate equations hold. Every refinement also assigns exactly one candidate to each position, so the position equations hold.

Furthermore,

\(\displaystyle S_d(y)=\sum_{t\in T}\sum_{\pi\in\Pi(t)}x_{t,\pi}\alpha^{(m)}_{\operatorname{pos}_\pi(d)}.\)

Thus the original co-winner inequalities imply the LP’s co-winner inequalities. Hence \(\mathcal L\) is feasible.

An LP solution gives a mass solution

Conversely, suppose \(y\) satisfies \(\mathcal L\). For each type \(t\), form the matrix

\(\displaystyle Y^t_{d,j}=\begin{cases}y_{t,d,j},&j\in J_t(d),\\0,&j\notin J_t(d).\end{cases}\)

The LP equations say that every row sum and column sum of \(Y^t\) equals \(\mu_t>0\). Apply the lemma to obtain

\(\displaystyle Y^t=\sum_{\ell=1}^{k_t}\lambda_{t,\ell}P_{t,\ell},\qquad \sum_{\ell=1}^{k_t}\lambda_{t,\ell}=\mu_t.\)

Each permutation matrix \(P_{t,\ell}\) assigns candidates only to their permitted position intervals. It therefore defines a strict linear refinement \(\pi_{t,\ell}\) of \(t\): every position assigned to an earlier block precedes every position assigned to a later block.

Assign mass \(\lambda_{t,\ell}\) to refinement \(\pi_{t,\ell}\), adding masses if the same refinement occurs more than once, and assign zero to all other refinements. These masses sum to \(\mu_t\) and have assignment marginals exactly \(Y^t\). Their total candidate scores consequently equal \(S_d(y)\).

The LP inequalities now imply that \(c^\star\) co-wins. This proves the equivalence.

4. Bit complexity

The number of variables is

\(\displaystyle N=\sum_{t\in T}\sum_{i=1}^{q_t}|A_{t,i}|^2\le \tau m^2.\)

There are \(2\tau m\) assignment equations, \(m-1\) co-winner inequalities, and \(N\) nonnegativity conditions. Every numerical coefficient is zero, a signed scoring entry, or a given mass, and therefore has \(O(L)\) bits.

The intervals, variables, and constraints can be constructed in time polynomial in \(m,\tau,L\). Including coefficient indices, the resulting LP has binary encoding length polynomial in these parameters.

Rational linear feasibility is decidable exactly in polynomial time in its binary encoding length; this includes systems with equalities and feasible sets of empty interior. See [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/eng/zvmmf5239). All hypotheses apply here because every coefficient and right-hand side is rational and explicitly encoded.

Constructing and deciding \(\mathcal L\) therefore takes \((\tau m^2L)^{O(1)}\) bit operations. The algorithm handles ties through weak inequalities and never enumerates the implicit refinements.

5. Why finite-voter hardness does not transfer

The finite-voter problem requires choosing one refinement for each voter, whereas the stated mass problem permits splitting a type’s mass. This distinguishes it from the model in [Kenig’s paper](https://arxiv.org/pdf/1802.09001).

The distinction already changes feasibility for four-candidate Borda, whose vector is \((3,2,1,0)\). Let the candidates be \(\{c^\star,a,b,d\}\), and take four types, each of mass \(1/4\):

  • The partitioned type \((\{a,b,d\},\{c^\star\})\).
  • The strict type \(a\succ c^\star\succ b\succ d\).
  • The strict type \(b\succ c^\star\succ d\succ a\).
  • The strict type \(d\succ c^\star\succ a\succ b\).

Before multiplying by \(1/4\), the three strict types contribute score \(6\) to \(c^\star\) and score \(4\) to each opponent.

Split the partitioned type uniformly over its six refinements. Each opponent receives average score \((3+2+1)/3=2\), while \(c^\star\) receives zero. Thus every candidate’s total mass score is \(6/4\), and \(c^\star\) co-wins.

If instead these are four unweighted voters, the partitioned voter must give score \(3\) to some opponent. That opponent finishes with score \(7\), exceeding \(c^\star\)’s score \(6\). Hence the corresponding finite-voter instance is infeasible.

The LP equivalence above settles the stated mass problem completely.
