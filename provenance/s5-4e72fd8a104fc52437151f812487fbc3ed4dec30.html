The continuous mirror question, as graded

Given finite valuation types \(T\) with positive rational masses \(\mu_t\) summing to \(1\), additive values \(v_t(g)\), and indivisible-good lots \(g\) with rational supplies \(q_g\), each lot must be assigned to one type and is compatible with \(t\) only if \(t\in S_g=\{s:v_s(g)>0\}\) and \(q_g=\mu_t\), so each person of that type receives one copy. Let \(M_t=\max_g v_t(g)\), \(T_t=\{g:v_t(g)=M_t>0\}\), and form \(C_2\) by joining lots whose positive supports overlap in at least two types. Decide whether there is an injective anchor choice \(h(t)\in T_t\) with \(q_{h(t)}=\mu_t\) such that, after precoloring each anchor by its type, every nonempty residual lot set \(Y\) contains a lot \(g\) with \(d_{C_2[Y]}(g)<|L_h(g)|\), where \(L_h(g)=\{t\in S_g:q_g=\mu_t\}\setminus\{t:gh(t)\in E(C_2)\}\); if so, produce a compatible list coloring and the resulting EFX0 allocation of common integral bundles to each type.

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) counts listed types, not possible types. There are \(m\) lots \(G\), with positive binary-rational supplies \(q_g\) and nonnegative binary-rational additive per-person values \(v_t(g)\). Let \(L\) be the total input bit length.
Require \(S_g=\{t:v_t(g)>0\}\ne\varnothing\) for every lot. Each lot is assigned wholly to one type \(t\in S_g\) with \(q_g=\mu_t\), giving each person of that type one indivisible copy; no splitting is allowed.
Set \(M_t=\max_{g\in G}v_t(g)\), with \(M_t=0\) if \(G=\varnothing\), \(T^+=\{t:M_t>0\}\), \(a=|T^+|\), \(T_t=\{g:v_t(g)=M_t>0\}\), and \(p=\sum_{t\in T^+}(|T_t|-1)\). All maximum ties are retained.
The graph \(C_2\) has vertex set \(G\), with distinct lots adjacent exactly when \(|S_g\cap S_f|\ge2\). An anchor map is an injection \(h:T^+\to G\) satisfying \(h(t)\in T_t\) and \(q_{h(t)}=\mu_t\); write \(H=h(T^+)\) and precolor \(h(t)\) by \(t\).
For \(g\in G\setminus H\), define \(L_h(g)=\{t\in S_g:q_g=\mu_t\}\setminus\{t\in T^+:gh(t)\in E(C_2)\}\). An anchor map is accepted exactly when every nonempty \(Y\subseteq G\setminus H\) contains \(g\in Y\) with \(d_{C_2[Y]}(g)<|L_h(g)|\).
Recognition asks whether an accepted anchor map exists; search also returns such a map and a proper compatible list coloring extending its precolors. The coloring gives the common integral bundle \(B_t\) of each type; all-good \(\mathrm{EFX}_0\) means \(v_s(B_s)\ge v_s(B_t\setminus\{g\})\) for every \(s,t\in T\) and \(g\in B_t\), including observer-zero goods.

The mass-based recognition problem is \(\mathrm{NP}\)-complete. The associated task of finding an accepted anchor map and its coloring, or reporting that none exists, is therefore \(\mathrm{NP}\)-hard. Once an accepted map is given, coloring and allocation construction take polynomial time.

The hardness proof below uses only valuations in \(\{0,1,2\}\), positive dyadic masses and supplies, at most two maximum goods per type, and a bipartite conflict graph of maximum degree three.

Fixed-anchor verification and construction. Write
\(A(g)=\{t\in S_g:q_g=\mu_t\}\).
For a specified valid anchor map \(h\), put \(\ell_h(g)=|L_h(g)|\). Repeatedly delete a residual vertex whose current degree is strictly smaller than \(\ell_h(g)\).

This procedure deletes every residual vertex if and only if \(h\) is accepted:

  • If it stops at a nonempty set \(Y\), every \(g\in Y\) satisfies \(d_{C_2[Y]}(g)\geq\ell_h(g)\), directly violating acceptance.
  • If it deletes every vertex, take any nonempty residual set \(Y\). Its first deleted vertex \(g\) still had all its neighbors in \(Y\) present when deleted. Consequently, \(d_{C_2[Y]}(g)\) is at most its degree at deletion, which was strictly smaller than \(\ell_h(g)\).

Thus an anchor map is a polynomially verifiable certificate, proving membership in \(\mathrm{NP}\).

If verification succeeds, color the residual vertices in reverse deletion order. When inserting \(g\), its already colored residual neighbors are among the vertices present when \(g\) was deleted. There are fewer than \(|L_h(g)|\) such neighbors, so some color in \(L_h(g)\) remains available. The definition of \(L_h(g)\) excludes conflicts with adjacent anchors. The anchors themselves have distinct colors because \(h\) assigns one distinct lot to each active type. This constructs the required proper compatible coloring.

Hardness construction. We reduce from satisfiability of formulas in which every clause contains exactly three distinct variables and every variable occurs twice positively and twice negatively. This problem remains \(\mathrm{NP}\)-complete even when every clause is monotone, as proved in [Döcker, *Monotone 3-Sat-(2,2) is NP-complete*](https://arxiv.org/abs/1912.08032). Our construction uses the three-distinct-variable and occurrence conditions; it does not require monotonicity.

Let the input formula have variables \(x_1,\ldots,x_n\) and clauses \(C_1,\ldots,C_c\). We may restrict to nonempty formulas, so \(c\geq1\). Denote the three literals of \(C_j\) by \(\lambda_{j1},\lambda_{j2},\lambda_{j3}\).

Introduce the following types and lots:

  • For each variable \(x_i\), introduce a type \(X_i\) and two literal lots \(u_i^+\) and \(u_i^-\). Set

\(v_{X_i}(u_i^+)=v_{X_i}(u_i^-)=2\).

  • For each clause \(C_j\), introduce a clause lot \(z_j\), three types \(Y_{j1},Y_{j2},Y_{j3}\), and three private lots \(b_{j1},b_{j2},b_{j3}\). Set

\(v_{Y_{jk}}(z_j)=1\) and \(v_{Y_{jk}}(b_{jk})=2\).

  • For each literal occurrence \((j,k)\), introduce two types \(D_{jk1},D_{jk2}\), each with its own private lot \(d_{jkr}\). Write \(u(\lambda_{jk})\) for the literal lot corresponding to \(\lambda_{jk}\). Set, for \(r\in\{1,2\}\),

\(v_{D_{jkr}}(z_j)=v_{D_{jkr}}(u(\lambda_{jk}))=1\) and
\(v_{D_{jkr}}(d_{jkr})=2\).

All unspecified valuations are zero. Every lot has nonempty positive support.

We next assign masses and supplies, including their normalization. Put \(W=n+30c\), choose an integer \(K\) with \(2^K>2W\), and set \(\delta=2^{-K}\).

Initially assign mass \(\delta\) to every \(X_i\), mass \(2\delta\) to every \(Y_{jk}\), and mass \(4\delta\) to every \(D_{jkr}\). Their total mass is \(W\delta\). Choose one distinguished \(D\)-type and replace its mass by
\(\mu_*=1-(W-4)\delta\).
The masses now sum to one. Moreover, \(\mu_*>1/2\), while \(4\delta<1/2\), so the distinguished mass differs from all three other masses.

Give each literal lot supply \(\delta\), each clause lot supply \(2\delta\), and each private lot supply equal to its private type’s mass. All masses and supplies are positive dyadic rationals with encoding length \(O(\log(n+c))\).

The resulting instance has
\(m=2n+10c\), \(\tau=a=n+9c\), and \(p=n\).
Indeed, every type is active; each \(X_i\) has exactly two maximum lots, and every other type has a unique maximum lot. The full explicit instance has polynomial size, for example
\(L=O((n+c)^2\log(n+c))\).

Verification of the constructed graph and lists. Every private lot has singleton support, so it is isolated in \(C_2\).

A literal lot and a clause lot share exactly the two \(D\)-types introduced for their incidence when that literal occurs in the clause. Otherwise their supports are disjoint. Two distinct clause lots have disjoint supports. Two distinct literal lots have disjoint supports except that \(u_i^+\) and \(u_i^-\) share the single type \(X_i\).

Consequently, the only conflict edges are
\(u(\lambda_{jk})z_j\).
The graph is bipartite. Each literal lot has degree two, because its literal occurs twice; each clause lot has degree three. Private lots have degree zero.

Mass compatibility gives precisely the following owner lists:

  • \(A(u_i^+)=A(u_i^-)=\{X_i\}\);
  • \(A(z_j)=\{Y_{j1},Y_{j2},Y_{j3}\}\);
  • each private lot has only its private type as a compatible owner.

In particular, the \(D\)-types create conflict edges but cannot own literal or clause lots: their masses differ from both supplies \(\delta\) and \(2\delta\).

Every anchor map must anchor each \(Y\)-type and each \(D\)-type at its unique private maximum lot. For each \(X_i\), it must choose exactly one of \(u_i^+\) and \(u_i^-\). All these choices are automatically injective and mass compatible.

After removing the anchors, the residual vertices consist of one unchosen literal lot per variable and all clause lots. Their residual lists remain unchanged:

  • Private anchors are isolated.
  • The two literal lots of a variable are nonadjacent, so the chosen lot does not block \(X_i\) at the unchosen lot.
  • Clause lists contain only their \(Y\)-types, whose anchors are isolated.

Thus every residual literal lot has list size one, and every clause lot has list size three.

Proof of the reduction’s equivalence. Interpret choosing \(u_i^+\) as the anchor of \(X_i\) as assigning \(x_i\) true, and choosing \(u_i^-\) as assigning it false. A literal’s lot is therefore removed as an anchor exactly when that literal is true.

Suppose this assignment satisfies every clause. Each clause lot loses at least one of its three literal neighbors, so its residual degree is at most two, strictly smaller than its list size three. Delete all clause lots. Every remaining literal lot is then isolated and has list size one, so it can also be deleted. The fixed-anchor criterion proves acceptance.

Conversely, suppose the assignment leaves some clauses unsatisfied. Let \(U\) be their nonempty index set, and let \(Y\) contain their clause lots together with every literal lot incident to one of them.

Every literal in an unsatisfied clause is false, so none of these literal lots was anchored. Hence \(Y\) is a residual set. Every clause lot in \(Y\) has all three neighbors in \(Y\), giving degree three, equal to its list size. Every literal lot in \(Y\) has at least one clause neighbor in \(Y\), giving degree at least one, equal to or greater than its list size. No vertex of \(Y\) satisfies the strict inequality required for acceptance.

Therefore an anchor map is accepted exactly when its associated assignment satisfies the formula. The construction is polynomial, proving \(\mathrm{NP}\)-hardness and, with membership, \(\mathrm{NP}\)-completeness.

The distinction from the unfiltered discrete problem is essential: its support lists would include the \(D\)-types at the endpoints. The cited paper leaves that discrete recognition problem unresolved; the reduction here uses mass incompatibility to exclude those colors while retaining their conflict edges. [Wang, Section 6](https://arxiv.org/html/2608.30203v1)

Recognition and search running times. For each active type, define its mass-compatible maximum candidates by
\(F_t=\{g\in T_t:q_g=\mu_t\}\).
Reject immediately if some \(F_t\) is empty. Otherwise enumerate choices from these sets, discard noninjective choices, and apply the fixed-anchor verifier.

Let \(N=\prod_{t\in T^+}|F_t|\), and let \(b=\lceil\log_2(m+\tau+2)\rceil\). For \(m\geq1\), a conservative bit-time bound for recognition, search, coloring, and allocation construction together is
\(O\!\left(m\tau L^2+\left[\tau m^2+N(m^2+m\tau)\right]b\right)\).

Here rational comparisons and preprocessing fit within \(O(m\tau L^2)\) using schoolbook arithmetic. Constructing \(C_2\) takes \(O(\tau m^2)\) support checks. Each enumerated choice requires \(O(m^2+m\tau)\) elementary operations for list construction and peeling; reverse coloring fits within the same bound.

Since \(|F_t|\leq|T_t|\leq m\), we have \(N\leq m^a\). Also, for every integer \(s\geq1\), \(s\leq2^{s-1}\), so
\(N\leq\prod_{t\in T^+}|T_t|\leq2^p\).
Thus both recognition and search have bounds
\(O(m^a\operatorname{poly}(L))\) and
\(O(2^p\operatorname{poly}(L))\):
they are XP in \(a\) and FPT in \(p\). These bounds coexist with the hardness result; the reduction has \(p=n\).

If \(m=0\), the empty anchor map is accepted, and every type receives the empty bundle.

Allocation and all-good fairness. Let \(o(g)\) be the constructed color of lot \(g\), and define
\(B_t=\{g:o(g)=t\}\).
Compatibility ensures \(t\in S_g\) and \(q_g=\mu_t\), so assigning that entire lot to type \(t\) gives each person of that type one copy. The bundles partition the lots.

Every active type receives its maximum anchor. By nonnegativity,
\(v_t(B_t)\geq M_t\).
For an inactive type the same inequality holds because its valuation is identically zero.

Fix distinct types \(s,t\). At most one lot in \(B_t\) has positive value to \(s\): otherwise two such lots would both support \(s\) and their owner \(t\), making them adjacent in \(C_2\) despite having the same color. Therefore, for every \(g\in B_t\),
\(v_s(B_t\setminus\{g\})\leq M_s\leq v_s(B_s)\).
This includes deletion of observer-zero goods. For \(s=t\), the required inequality follows directly from nonnegative values.

The constructed common integral bundles therefore satisfy all-good \(\mathrm{EFX}_0\). This proves the allocation guarantee for accepted certificates; the hardness result concerns recognition of those certificates.
