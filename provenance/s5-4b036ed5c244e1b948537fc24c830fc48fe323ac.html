The continuous mirror question, as graded

Given rational type masses \(\mu_t\), rational per-capita supplies \(s_g\), and additive valuation vectors \(v_t\) sharing a common good order, find a complete mass allocation \(x_{t,b}\) over integral bundles \(b\in\mathbb{Z}_{\ge 0}^{G}\) satisfying \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_g=s_g\). Define \(\operatorname{MMS}_{3/2,t}(s)\) as the supremum, over distributions \(\pi\) on integral bundles with \(\mathbb{E}_{\pi}[b_g]=s_g/(3/2)\), of \(\inf_{b\in\operatorname{supp}(\pi)}v_t(b)\); require \(v_t(b)\ge\operatorname{MMS}_{3/2,t}(s)\) whenever \(x_{t,b}>0\), and require \(v_t(b)\ge v_t(c-e_g)\) whenever \(x_{t,b}x_{u,c}>0\) and \(c_g>0\), where \(e_g\) is one copy of good \(g\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types; normalize \(\sum_t\mu_t=1\).
Let \(G=\{1,\ldots,m\}\), with \(m,\tau\ge1\). Supplies \(s_g\) and additive valuation coefficients \(v_{t,g}\) are nonnegative binary rationals, with \(v_{t,1}\ge\cdots\ge v_{t,m}\) for every type; ties and zero values are allowed. Let \(L\) be the total input bit length.
Bundles are unrestricted vectors \(b\in\mathbb Z_{\ge0}^{G}\), including the empty bundle, valued additively by \(v_t\). Define \(\operatorname{MMS}_{3/2,t}(s)=\sup_{\pi}\inf_{b\in\operatorname{supp}(\pi)}v_t(b)\), where \(\pi\) ranges over probability distributions on these bundles satisfying \(\mathbb E_\pi[b_g]=2s_g/3\) for every good.
A complete mass allocation consists of nonnegative real masses \(x_{t,b}\) satisfying \(\sum_bx_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_g=s_g\). Countable bundle supports are allowed.
Require \(v_t(b)\ge\operatorname{MMS}_{3/2,t}(s)\) whenever \(x_{t,b}>0\), and EFX: \(v_t(b)\ge v_t(c-e_g)\) whenever \(x_{t,b}>0\), \(x_{u,c}>0\), and \(c_g>0\), where \(e_g\) is one copy of good \(g\). These comparisons include \(t=u\) and removal of zero-valued goods.

Is deciding whether such a complete mass allocation exists in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,L\).

For finite ordered additive instances, complete allocations simultaneously satisfying EFX and each agent's maximin value for partitions into \(\lceil3n/2\rceil\) bundles always exist; a constructive algorithm is given without a polynomial-time bound for this guarantee. [Akrami–Reichert](https://arxiv.org/html/2602.15566v2)

Result

The decision problem is in \(\mathrm P\): every valid instance is feasible. In fact, a complete allocation with finite support and rational masses always exists.

The key is an exact replication argument. First, each distributional benchmark has a finite rational witnessing distribution. One common scaling then turns these witnesses into partitions of a finite ordered instance, to which the supplied finite-agent theorem applies.

1. Each benchmark is attained

Fix a type \(t\), and write \(a=2s/3\) coordinatewise.

There exists a finite rational distribution with mean \(a\): independently in each coordinate, round \(a_g\) to \(\lfloor a_g\rfloor\) or \(\lceil a_g\rceil\), with probabilities giving expectation \(a_g\).

Choose a positive integer \(D_t\) such that every \(D_tv_{t,g}\) is an integer. Every bundle value therefore belongs to \(\frac1{D_t}\mathbb Z_{\ge0}\). Consequently, for any distribution \(\pi\), its nonempty set of support values has a minimum. Its guaranteed value is thus

\[ \text{not used} \]

\(q(\pi)=\min_{b\in\operatorname{supp}(\pi)}v_t(b)\in\frac1{D_t}\mathbb Z_{\ge0}.\)

If \(\pi\) has mean \(a\), additivity gives

\(\mathbb E_\pi[v_t(b)]=\sum_gv_{t,g}a_g=\frac23\sum_gv_{t,g}s_g.\)

Since every support bundle has value at least \(q(\pi)\), we obtain

\(0\le q(\pi)\le\frac23\sum_gv_{t,g}s_g.\)

Thus the set of achievable guaranteed values is nonempty and contained in a finite set of lattice values. It has a largest element, attained by some distribution. Denote this element by

\(q_t=\operatorname{MMS}_{3/2,t}(s).\)

This proves attainment, including for countable supports.

2. Every attained threshold has a finite rational witness

We prove a slightly more general statement.

Lemma. Let \(v\) be a nonnegative additive valuation, let \(a\in\mathbb Q_{\ge0}^m\), and suppose a distribution with mean \(a\) is supported on bundles of value at least \(q\). Then a finite rational distribution with the same mean and the same guarantee exists.

Proof. If \(q=0\), independent coordinate rounding of \(a\) gives the required distribution. Assume \(q>0\).

Starting from any support bundle \(b\), delete copies while preserving value at least \(q\), until obtaining a coordinatewise minimal bundle \(d\le b\). In particular, \(d\) contains no zero-valued good, and

\(v(d-e_g)<q\quad\text{whenever }d_g>0.\)

Let \(\delta=\min\{v_g:v_g>0\}\), which exists because \(q>0\) is achievable. Write \(|d|_1=\sum_gd_g\). Choosing any \(g\) present in \(d\), we have

\((|d|_1-1)\delta\le v(d-e_g)<q.\)

Hence

\(|d|_1\le\lceil q/\delta\rceil.\)

There are therefore only finitely many possible minimal bundles. Let \(S\) be their set.

Choose one such reduction for each original support bundle. The induced distribution on \(S\) has probabilities \(p_d\) satisfying

\(\sum_{d\in S}p_d=1,\qquad p_d\ge0,\qquad \sum_{d\in S}p_dd_g\le a_g\quad\text{for every }g.\)

These constraints define a nonempty bounded polytope with rational coefficients. It has a rational point: a vertex is determined by a full-rank subsystem of active rational constraints, whose unique solution is rational. Choose such rational probabilities, and define

\(r_g=a_g-\sum_{d\in S}p_dd_g\in\mathbb Q_{\ge0}.\)

Construct an independent finite rational random vector \(Z\in\mathbb Z_{\ge0}^m\) with expectation \(r\), again by coordinatewise rounding. Sample \(d\) according to \(p\), and output \(d+Z\). Then

\(\mathbb E[d+Z]=a,\qquad v(d+Z)\ge v(d)\ge q.\)

The resulting distribution has finite support and rational probabilities. This proves the lemma. \(\square\)

Applying the lemma to Section 1 gives, for each type \(t\), bundles \(b^{t,1},\ldots,b^{t,h_t}\) and positive rational probabilities \(p_{t,1},\ldots,p_{t,h_t}\) such that

\(\sum_jp_{t,j}=1,\qquad \sum_jp_{t,j}b^{t,j}_g=\frac23s_g,\qquad v_t(b^{t,j})\ge q_t.\)

3. Exact replication into a finite ordered instance

Choose a positive integer \(D\) divisible by the denominators of every \(\mu_t\), every \(s_g\), and every \(p_{t,j}\). Set

\(n=2D,\qquad k=3D=\lceil3n/2\rceil.\)

Construct a finite instance with:

  • \(n\mu_t\) agents of type \(t\);
  • \(ns_g\) distinguishable copies of good \(g\);
  • value \(v_{t,g}\) for each copy of good \(g\) to an agent of type \(t\).

All these multiplicities are integers. There are exactly \(n\) agents because \(\sum_t\mu_t=1\).

The instance is ordered: list all copies of good \(1\), followed by those of good \(2\), and so on. Every agent weakly ranks this list in the same order, including ties and zero values.

Fix a type \(t\). Form \(kp_{t,j}\) bundles with count vector \(b^{t,j}\), for each \(j\). These multiplicities are integers, and the total number of bundles is \(k\). The number of copies of good \(g\) used is

\(\sum_jkp_{t,j}b^{t,j}_g=k\cdot\frac23s_g=ns_g.\)

Thus these bundles form an exact partition of all finite goods: distinguishable copies of each good can be assigned to the specified bundle slots because the counts match. Every bundle in this partition has value at least \(q_t\).

Writing \(M\) for the finite goods and defining

\(\operatorname{MMS}^{k}_i(M)=\max_{(P_1,\ldots,P_k)\text{ partition of }M}\min_{\ell}v_i(P_\ell),\)

we conclude that every replicated agent \(i\) of type \(t\) satisfies

\(\operatorname{MMS}^{k}_i(M)\ge q_t.\)

The partitions witnessing this inequality may differ between types; the definition of each agent’s maximin value permits this.

If all supplies vanish, assigning the empty bundle to every type already proves feasibility. Hence we may proceed with the finite instance above whenever some supply is positive.

4. Apply the finite theorem and transfer back

The supplied theorem states that every finite ordered additive instance has a complete allocation that is EFX and gives each agent its maximin value for partitions into \(\lceil3n/2\rceil\) bundles. Its EFX definition compares removal of every good, including zero-valued goods. These are precisely the properties needed here. [Akrami–Reichert, Theorem 1 and Definition 4](https://arxiv.org/html/2602.15566v2)

All hypotheses hold for the replicated instance. Obtain a complete allocation \((A_i)_{i=1}^n\). If agent \(i\) has type \(t\), then

\(v_t(A_i)\ge\operatorname{MMS}^{k}_i(M)\ge q_t.\)

Let \(b(i)\) be the vector counting the copies of each original good in \(A_i\). Define

\(x_{t,b}=\frac1n\bigl|\{i:i\text{ has type }t,\ b(i)=b\}\bigr|.\)

These masses are rational and have finite support. Counting agents gives

\(\sum_bx_{t,b}=\frac{n\mu_t}{n}=\mu_t.\)

Completeness of the finite allocation gives, for every good \(g\),

\(\sum_{t,b}x_{t,b}b_g=\frac{ns_g}{n}=s_g.\)

Every positively allocated bundle satisfies the required benchmark, since

\(x_{t,b}>0\implies v_t(b)\ge q_t=\operatorname{MMS}_{3/2,t}(s).\)

It remains to verify all required EFX comparisons. Suppose \(x_{t,b}>0\), \(x_{u,c}>0\), and \(c_g>0\).

If \((t,b)\ne(u,c)\), choose agents \(i,j\) representing these two positively allocated pairs. They are distinct. Removing one copy of good \(g\) from \(A_j\), finite EFX gives

\(v_t(b)\ge v_t(c-e_g).\)

This covers comparisons within the same type when the bundles differ, as well as all comparisons between different types.

If \((t,b)=(u,c)\), the comparison follows directly from nonnegativity:

\(v_t(c-e_g)=v_t(b)-v_{t,g}\le v_t(b).\)

Thus the allocation satisfies the question’s full EFX requirement, including same-type comparisons and removal of zero-valued goods. Universal existence is proved. \(\square\)

5. Decision running time

On the stipulated valid inputs, the decision algorithm simply returns YES. Including reading the input, its running time is \(O(L+m\tau)=O(L)\), since the explicit valuation table is part of the input.

The replication argument establishes existence; it does not assert a polynomial running time for constructing the allocation. Construction is unnecessary for this decision problem.
