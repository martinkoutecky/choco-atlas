Proposition 6.3 — class: other

The continuous mirror question, as graded

For each \(n\), let \(N_n\) contain \(n\) interchangeable unit-weight voters, use the symmetric-majority game \(m_{k_n}\) with \(k_n=\lceil\theta n\rceil\), and choose \(S_n\subseteq N_n\) with \(|S_n|=\lfloor xn\rfloor\). For fixed rational \(\theta\in(1/2,1)\) and \(x\in(0,1]\), determine whether \(F(\theta,x)=\lim_{n\to\infty}C^{m_{k_n}}_{\mathrm{SO}}(S_n)\) exists and, if so, its exact value.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported types, not possible types. Here the society has one interchangeable voter type of total mass \(1\), and a coalition has mass \(x\).
Fix \(\theta\in\mathbb{Q}\cap(1/2,1)\) and \(x\in(0,1]\). For sufficiently large integers \(n\), take \(N_n\) consisting of \(n\) unit-weight voters, set \(k_n=\lceil\theta n\rceil\), and choose any \(S_n\subseteq N_n\) of size \(s_n=\lfloor xn\rfloor\ge2\). Define \(m_{k_n}(A)=\mathbf{1}_{\{|A|\ge k_n\}}\).
For a finite game \(v\) and coalition \(S\) of size \(s\ge2\), choose uniformly a permutation \(\sigma\) of all voters in which the members of \(S\) occupy consecutive positions; independently choose \(r\) uniformly from \(\{1,\ldots,s-1\}\).
Let \(T\) be the voters preceding this block, \(R\) its first \(r\) members, and \(U=S\setminus R\). The Shapley–Owen coopetition index is \(C^v_{\mathrm{SO}}(S)=\mathbb{E}[v(S\cup T)-v(R\cup T)-v(U\cup T)+v(T)]\).

Does \(F(\theta,x)=\lim_{n\to\infty}C^{m_{k_n}}_{\mathrm{SO}}(S_n)\) exist for every admissible \((\theta,x)\), and, wherever it exists, what is its exact value?
For binary-rational \(x\), is exact evaluation of this limit in polynomial time or NP-hard? State running times in \(\tau\), the total input bit length \(L\), and any additional parameters; there is no candidate parameter \(m\) here.

Known discrete results give an explicit finite-size formula for this index in symmetric majority games. [Aleandri and Dall’Aglio](https://arxiv.org/html/2407.01383v2)
A subsequent extension treats finite monotone transferable-utility games and axiomatizes Shapley–Owen coopetition; no result for this precise scaling limit was located. [Finite-game extension](https://arxiv.org/html/2511.15441v1)

Modeling choices made when packaging the task

  • Normalized the one supported voter type to total mass 1, with x denoting the coalition's share.
  • Defined the index through uniform consecutive-block permutations and an independent uniform nonempty internal cut, retaining the unnormalized coopetition index.
  • Restricted the sequence to sufficiently large n with floor(xn) at least 2, because the index requires two nonempty internal blocks.
  • Retained real x for the limit question and restricted x to binary rationals only for the computational question; L includes the encoded rational parameters.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The limit exists for every admissible \((\theta,x)\). Its exact value is

\( \displaystyle F(\theta,x)= \begin{cases} 0, & 0<x\leq 1-\theta,\\[4pt] \dfrac{(1-\theta)(\theta+x-1)}{x(1-x)}, & 1-\theta<x<\theta,\\[8pt] \dfrac{2\theta-1}{x}, & \theta\leq x\leq 1. \end{cases} \)

For binary-rational \(x\), exact evaluation is polynomial-time solvable. With total input bit length \(L\), including the encoding of \(\theta\) if it is supplied as input, an elementary implementation uses \(O(\tau+L^2)\) bit operations. Here \(\tau=1\), so this is \(O(L^2)\); there is no dependence on \(n\) or any candidate parameter.

1. An exact finite-size identity

Fix integers \(n,s,k\) satisfying \(2\leq s\leq n\) and \(1\leq k\leq n\). Write \(t=|T|\).

For each fixed block position \(t\in\{0,\ldots,n-s\}\), there are exactly \(s!(n-s)!\) admissible permutations: choose an ordering of the members of \(S\), and an ordering of the remaining voters. Thus \(t\) is uniform on \(\{0,\ldots,n-s\}\). By the stipulated independence, \(r\) is independent of \(t\) and uniform on \(\{1,\ldots,s-1\}\).

The interaction being averaged is

\( \displaystyle \mathbf{1}_{\{t+s\geq k\}} -\mathbf{1}_{\{t+r\geq k\}} -\mathbf{1}_{\{t+s-r\geq k\}} +\mathbf{1}_{\{t\geq k\}}. \)

If \(t\geq k\), all four indicators equal one, so the interaction is zero. If \(t+s<k\), all four equal zero.

It remains to consider \(t<k\leq t+s\). Put \(d=k-t\), so \(1\leq d\leq s\). Since \(r\) and \(s-r\) are both uniform on \(\{1,\ldots,s-1\}\),

\( \displaystyle \mathbb{P}(r\geq d) =\mathbb{P}(s-r\geq d) =\frac{s-d}{s-1}. \)

Consequently, the conditional mean interaction is

\( \displaystyle 1-\frac{2(s-d)}{s-1} =\frac{2d-s-1}{s-1}. \)

The active values of \(d\) are precisely the integers between

\( \displaystyle \ell=\max\{1,k-(n-s)\}, \qquad u=\min\{s,k\}. \)

The hypotheses imply \(\ell\leq u\). Averaging over \(t\), equivalently summing over these active values of \(d\), gives

\[ \displaystyle C_{\mathrm{SO}}^{m_k}(S) =\frac{\sum_{d=\ell}^{u}(2d-s-1)} {(n-s+1)(s-1)} =\frac{(u-\ell+1)(\ell+u-s-1)} {(n-s+1)(s-1)}. \tag{1} \]

This identity depends only on \(s\), so the choice of the particular coalition is immaterial. It follows directly from the sampling law in the question; related finite symmetric-majority formulas appear in [Aleandri and Dall’Aglio, Proposition 6.3](https://arxiv.org/html/2407.01383v2).

2. Convergence when \(0<x<1\)

Now take \(s=s_n=\lfloor xn\rfloor\) and \(k=k_n=\lceil\theta n\rceil\). The rounding inequalities give

\( \displaystyle \frac{s_n}{n}\longrightarrow x, \qquad \frac{k_n}{n}\longrightarrow\theta. \)

Define \(\ell_n,u_n\) as in (1), and put

\( \displaystyle a=\max\{0,\theta+x-1\}, \qquad b=\min\{x,\theta\}. \)

Continuity of maximum and minimum implies

\( \displaystyle \frac{\ell_n}{n}\longrightarrow a, \qquad \frac{u_n}{n}\longrightarrow b. \)

Dividing the numerator and denominator in (1) by \(n^2\), we obtain

\[ \displaystyle C_{\mathrm{SO}}^{m_{k_n}}(S_n) = \frac{ \left(\frac{u_n-\ell_n+1}{n}\right) \left(\frac{\ell_n+u_n-s_n-1}{n}\right)} { \left(\frac{n-s_n+1}{n}\right) \left(\frac{s_n-1}{n}\right)} \longrightarrow \frac{(b-a)(a+b-x)}{x(1-x)}. \tag{2} \]

The denominator in the limiting expression is strictly positive because \(0<x<1\). Thus this argument also covers both interior breakpoints without any assumption about how the rounding behaves there.

To simplify (2), use \(1-\theta<\theta\):

  • If \(0<x\leq1-\theta\), then \(a=0\) and \(b=x\). Hence \(a+b-x=0\), giving \(F(\theta,x)=0\).
  • If \(1-\theta<x<\theta\), then \(a=\theta+x-1\) and \(b=x\). Therefore \(b-a=1-\theta\) and \(a+b-x=\theta+x-1\), giving the middle expression.
  • If \(\theta\leq x<1\), then \(a=\theta+x-1\) and \(b=\theta\). Therefore \(b-a=1-x\) and \(a+b-x=2\theta-1\), giving \(F(\theta,x)=(2\theta-1)/x\).

At \(x=1-\theta\), the middle expression tends to zero. At \(x=\theta\), its value would be \((2\theta-1)/\theta\), agreeing with the third expression.

3. The endpoint \(x=1\)

Here \(s_n=n\), so there are no voters outside the block and \(t=0\). Formula (1), with \(\ell_n=u_n=k_n\), becomes

\( \displaystyle C_{\mathrm{SO}}^{m_{k_n}}(N_n) =\frac{2k_n-n-1}{n-1} \longrightarrow 2\theta-1. \)

This is exactly the asserted third expression at \(x=1\). All admissible cases are therefore resolved.

4. Exact evaluation and bit complexity

Write \(\theta=A/B\) and \(x=P/Q\), with positive integer denominators. The algorithm selects the appropriate branch by integer comparisons:

  • \(BP\leq(B-A)Q\) selects the zero branch.
  • Otherwise, \(BP<AQ\) selects the middle branch.
  • Otherwise, it selects the last branch.

The two nonzero expressions can be computed as

\( \displaystyle \frac{(B-A)(AQ+BP-BQ)Q}{B^2P(Q-P)} \quad\text{and}\quad \frac{(2A-B)Q}{BP}, \)

respectively. The middle branch has \(x<\theta<1\), so \(Q-P>0\); every denominator used by the algorithm is nonzero.

These computations require a constant number of integer additions, comparisons, and multiplications. Every intermediate integer has \(O(L)\) bits because it is formed from a bounded number of input integers. Schoolbook multiplication therefore costs \(O(L^2)\) bit operations in total. If a reduced fraction is required, binary greatest-common-divisor computation and exact division also fit within \(O(L^2)\) bit operations. The output has \(O(L)\) bits.

Including input reading, the running time is \(O(\tau+L^2)\), which here equals \(O(L^2)\) because the supported society has exactly one type. The same bound applies when \(\theta\) is fixed, with constants depending on its fixed encoding. No finite electorate needs to be constructed.
