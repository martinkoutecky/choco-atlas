For \(x_i>0\), let each contributor of type \(i\) supply \(q_i=y_i/x_i\); require \(y_i=0\) if \(x_i=0\). Result and computational interpretation

Additive-\(\eta\) welfare maximization is polynomial-time solvable for every fixed positive rational \(\gamma\).

I use the intended bit-model reading that the qualities \(\theta_i\) are binary-rational inputs whose encodings count toward \(L\). Arbitrary unencoded real qualities would require a computational model to be specified. Real allocation coordinates are output using exact algebraic representations: defining polynomials and root-isolating data.

The proof applies directly to mass allocations. It does not require extending the finite-agent characterization.

1. Eliminating the participation variables

Define

\(\displaystyle B=\alpha(1+n)^{-\gamma}+\frac{cn}{2a},\qquad \kappa=\frac{2a}{c},\qquad W_{\mathrm{out}}=\sum_i h_i u_i.\)

For any nonempty allocation, define its participation threshold by

\(\displaystyle t=\vartheta+\alpha(1+N)^{-\gamma}-B.\)

Subtracting the outside utility from the common model utility gives

\(\displaystyle g_i:=\ell-u_i=2a(\theta_i-t).\)

Consequently:

  • If \(g_i<0\), neither contributing nor noncontributing participation is possible, so \(z_i=x_i=0\).
  • If \(y_i>0\), then \(x_i>0\), and contributor participation requires \(cy_i\leq x_i g_i\leq h_i g_i\).
  • If \(g_i=0\), positive sample supply is impossible, but participation with zero supply is permitted.

Thus every feasible allocation satisfies

\(\displaystyle 0\leq y_i\leq C_i(t),\qquad C_i(t):=\kappa h_i(\theta_i-t)_+,\)

where \(v_+=\max\{v,0\}\).

Conversely, suppose \(N>0\), \(t\), and sample supplies satisfy

\[\displaystyle \sum_i y_i=N,\qquad \sum_i\theta_i y_i=N\bigl[t+B-\alpha(1+N)^{-\gamma}\bigr],\qquad 0\leq y_i\leq C_i(t).\tag{1}\]

Construct participation as follows. Set \(z_i=h_i\) when \(\theta_i\geq t\), and \(z_i=0\) otherwise. Set \(x_i=h_i\) when \(y_i>0\), and \(x_i=0\) otherwise.

The moment equality in (1) ensures that the allocation’s threshold is exactly \(t\). Every noncontributor has \(g_i\geq0\), and every positive supplier satisfies

\(\displaystyle cq_i=\frac{cy_i}{h_i}\leq 2a(\theta_i-t)=g_i.\)

Hence this is a feasible allocation.

For any original allocation,

\(\displaystyle W-W_{\mathrm{out}}=\sum_i z_i g_i-cN.\)

At fixed \(N,t,y\), admitting all types with nonnegative \(g_i\) maximizes this expression. Its resulting value is

\[\displaystyle G(N,t)=2a\sum_i h_i(\theta_i-t)_+-cN.\tag{2}\]

Therefore the original problem is exactly equivalent to maximizing (2) subject to (1), together with the empty allocation, whose gain is zero.

2. An exact description of the moment constraints

We next eliminate all the sample variables from feasibility.

Moment lemma. Let \(C_i\geq0\), and let \(0<N\leq\sum_i C_i\). There exist supplies satisfying

\(\displaystyle 0\leq y_i\leq C_i,\qquad \sum_i y_i=N,\qquad \sum_i\theta_i y_i=M\)

if and only if, for every \(k\in\{1,\ldots,\tau\}\),

\[\displaystyle L_k(N,C)\leq M\leq U_k(N,C),\tag{3}\]

where

\(\displaystyle L_k(N,C)=\theta_kN-\sum_{i<k}(\theta_k-\theta_i)C_i,\)

\(\displaystyle U_k(N,C)=\theta_kN+\sum_{i>k}(\theta_i-\theta_k)C_i.\)

Proof. For any admissible supplies,

\(\displaystyle \sum_i\theta_i y_i=\theta_kN+\sum_i(\theta_i-\theta_k)y_i.\)

For \(i<k\), the coefficient \(\theta_i-\theta_k\) is negative, so replacing \(y_i\) by its upper bound \(C_i\) gives a lower bound. For \(i>k\), its contribution is nonnegative. This proves the lower inequality in (3). The upper inequality follows by the reverse argument.

To obtain the minimum moment, fill capacities in increasing quality order until the total reaches \(N\). If \(k\) is the final index used, then every earlier capacity is filled and every later supply is zero. Its moment equals \(L_k(N,C)\). Since all the lower bounds hold, the minimum moment is therefore

\(\displaystyle M^-=\max_k L_k(N,C).\)

Similarly, filling capacities in decreasing quality order gives

\(\displaystyle M^+=\min_k U_k(N,C).\)

The set of admissible supplies is convex. Convex combinations of these two greedy supplies attain every moment between \(M^-\) and \(M^+\). Thus (3) is sufficient as well. \(\square\)

Applying the lemma with \(C_i=C_i(t)\), feasibility is exactly

\(\displaystyle N\leq\sum_i C_i(t),\qquad L_k(N,C(t))\leq N[t+B-\alpha(1+N)^{-\gamma}]\leq U_k(N,C(t))\)

for every \(k\). There are only a linear number of inequalities.

3. Reduction to three algebraic variables

Write the fixed exponent as \(\gamma=p/q\), where \(p,q\) are fixed positive integers. Introduce

\(\displaystyle r=(1+n)^{1/q},\qquad s=(1+N)^{1/q}.\)

Then

\[\displaystyle r>1,\qquad r^{p+q}=\frac{2a\gamma\alpha}{c},\qquad s>1,\qquad N=s^q-1.\tag{4}\]

The positive-root conditions select the intended values uniquely. Define the polynomials

\(\displaystyle D(r)=\alpha+\frac{c}{2a}(r^q-1)r^p,\qquad P(r,s)=r^p s^p.\)

We have

\(\displaystyle B=\frac{D(r)}{r^p},\qquad \alpha(1+N)^{-\gamma}=\frac{\alpha}{s^p}.\)

Thus the desired quality moment, multiplied by the strictly positive denominator \(P\), is the polynomial

\[\displaystyle Z(r,s,t)=(s^q-1)\bigl[tP(r,s)+D(r)s^p-\alpha r^p\bigr].\tag{5}\]

It remains to handle the positive parts in the capacities and objective. Every feasible nonempty allocation has \(t<\theta_\tau\): some \(y_i>0\), which requires \(\theta_i>t\). Hence it suffices to examine these \(\tau\) intervals:

\(\displaystyle I_0=\{t:t\leq\theta_1\},\qquad I_j=\{t:\theta_j\leq t\leq\theta_{j+1}\}\quad(1\leq j<\tau).\)

On interval \(I_j\), define the linear capacity polynomials by \(C_i^{(j)}(t)=0\) for \(i\leq j\), and

\(\displaystyle C_i^{(j)}(t)=\kappa h_i(\theta_i-t)\quad\text{for }i>j.\)

These equal \(C_i(t)\) throughout \(I_j\), including its endpoints. The gain becomes the polynomial

\[\displaystyle G_j(s,t)=2a\sum_{i>j}h_i(\theta_i-t)-c(s^q-1).\tag{6}\]

For a rational target gain \(\lambda\), consider the following system in just the three real variables \(r,s,t\):

  • The constraints (4) and \(t\in I_j\).
  • The capacity inequality

\(\displaystyle s^q-1\leq\sum_i C_i^{(j)}(t).\)

  • For every \(k\), the moment inequalities

\(\displaystyle P(r,s)L_k(s^q-1,C^{(j)}(t))\leq Z(r,s,t)\leq P(r,s)U_k(s^q-1,C^{(j)}(t)).\)

  • The welfare inequality \(G_j(s,t)\geq\lambda\).

Because \(P(r,s)>0\), multiplying the moment inequalities by \(P\) preserves their directions. Sections 1 and 2 prove both directions of the equivalence:

Some interval system is feasible if and only if some nonempty allocation has gain at least \(\lambda\).

Each system has a linear number of polynomial constraints. Its degrees are bounded, for example, by \(2p+2q+1\), independently of \(\tau\). All coefficients are rational and have bit length polynomial in \(L\); clearing denominators preserves polynomial encoding size.

4. Polynomial-time feasibility and allocation reconstruction

I use the following standard consequence of effective real-algebraic decision and sampling algorithms:

Fixed-dimensional algebraic feasibility. For fixed numbers of variables and fixed degree bounds, feasibility of a Boolean combination of rational polynomial equalities and strict or weak inequalities is decidable in polynomial bit complexity. If feasible, an exact real algebraic sample point of polynomial encoding size can also be computed.

The relevant algorithms and complexity bounds are described in [Basu’s survey, Sections 2.1.2, 2.2, and 2.5](https://arxiv.org/pdf/1409.1534); Theorem 2.27 includes coefficient bit-size bounds.

Its hypotheses hold here: there are three variables, the degree bound depends only on fixed \(\gamma\), and both the number of constraints and their encoding lengths are polynomial in \(\tau,L\) and the bit length of \(\lambda\). Testing the \(\tau\) interval systems therefore gives a polynomial-time feasibility oracle.

A sample point also yields an allocation constructively. Compute its \(N,t,C_i(t)\) and desired moment

\(\displaystyle M=N[t+B-\alpha(1+N)^{-\gamma}].\)

Let \(y^-\) and \(y^+\) be the increasing-order and decreasing-order greedy supplies from the moment lemma, with moments \(M^-\) and \(M^+\).

If \(M^-=M^+\), use \(y=y^-\). Otherwise set

\(\displaystyle \rho=\frac{M-M^-}{M^+-M^-},\qquad y=(1-\rho)y^-+\rho y^+.\)

The feasibility inequalities imply \(0\leq\rho\leq1\), so this supply satisfies (1). Construct \(z,x\) as in Section 1.

All these operations use the same three algebraic sample coordinates. The greedy supplies and their moments are polynomial expressions in those coordinates, and the mixing formula uses rational expressions of bounded degree. Thus the allocation has polynomial-size algebraic descriptions and can be reconstructed in polynomial time.

5. Welfare bounds and additive approximation

We need a bound whose logarithm is polynomial in the input length.

Consider the standalone normalized loss

\(\displaystyle \phi(v)=\alpha(1+v)^{-\gamma}+\frac{c}{2a}v,\qquad v\geq0.\)

Its derivatives are

\(\displaystyle \phi'(v)=-\alpha\gamma(1+v)^{-(\gamma+1)}+\frac{c}{2a},\)

\(\displaystyle \phi''(v)=\alpha\gamma(\gamma+1)(1+v)^{-(\gamma+2)}>0.\)

The input inequality gives \(\phi'(0)<0\), and the unique derivative zero is \(n>0\). Consequently,

\[\displaystyle 0<B=\phi(n)<\phi(0)=\alpha.\tag{7}\]

Put

\(\displaystyle H=\sum_i h_i,\qquad \Delta=\theta_\tau-\theta_1,\qquad V=2aH(\alpha+\Delta).\)

For every feasible nonempty allocation, \(\vartheta\geq\theta_1\). Therefore

\(\displaystyle \theta_i-t=\theta_i-\vartheta+B-\alpha(1+N)^{-\gamma}\leq\Delta+\alpha.\)

Using (2), this proves \(G(N,t)\leq V\). Also, the total-capacity inequality implies

\(\displaystyle cN\leq c\sum_i C_i(t)=2a\sum_i h_i(\theta_i-t)_+,\)

so \(G(N,t)\geq0\).

Let \(G^\star\) be the supremum achievable gain, including the empty allocation. We have proved

\(\displaystyle 0\leq G^\star\leq V.\)

Now bisect the interval with initial endpoints \(b=0\) and \(d=V+1\), storing the empty allocation as a witness for \(b\). At each step query the algebraic feasibility oracle at \(\lambda=(b+d)/2\).

  • If feasible, replace \(b\) by \(\lambda\) and store the reconstructed allocation.
  • If infeasible, replace \(d\) by \(\lambda\).

These updates maintain \(b\leq G^\star\leq d\), together with a stored allocation of gain at least \(b\). After

\(\displaystyle K=\left\lceil\log_2\frac{V+1}{\eta}\right\rceil\)

steps, \(d-b\leq\eta\). Hence the stored allocation satisfies

\(\displaystyle W\geq W_{\mathrm{out}}+G^\star-\eta.\)

The rational number \(V\) has bit length polynomial in \(L\), so \(K\) is polynomial in \(L+\log(1/\eta)\). The queried thresholds have polynomial bit length as well. Every oracle call and the final reconstruction run in polynomial time.

Thus the total running time is polynomial in \(\tau\), \(L\), and \(\log(1/\eta)\), with the polynomial allowed to depend on the fixed exponent \(\gamma\).
