The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), a symmetric rational valuation matrix \(V\) with nonzero entries, and rational \(\varepsilon>0\), find a finite list of rational coalition compositions \(q^k\ge 0\), with \(\sum_k q^k\le\mu\), whose welfare \(\sum_k (q^k)^{\mathsf T}Vq^k\) is within additive \(\varepsilon\) of the maximum over all measurable partitions of the atomless population. Determine the computational complexity in \(|T|\), input bit length, and \(\varepsilon\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types. Here \(m=\tau\); there is no separate ground-set parameter.
The population is the Lebesgue unit interval, divided into measurable type sets of masses \(\mu_t\). Input also includes a symmetric matrix \(V\in\mathbb{Q}^{\tau\times\tau}\) with every entry nonzero, of either sign, and binary-rational \(\varepsilon>0\). Let \(L\) be the total input bit length, including \(\varepsilon\).
A coalition is a measurable set with composition \(q_t\) equal to its type-\(t\) mass. A type-\(t\) member has utility \(\sum_s V_{ts}q_s\), so coalition welfare is \(q^{\mathsf T}Vq\); diagonal entries value distinct members of the same type, and excluding oneself changes no mass.
Partitions cover the population by disjoint measurable coalitions, with no restriction on coalition sizes or number. Their welfare is the sum over their at most countably many positive-mass coalitions; zero-mass coalitions contribute zero. Define \(\mathrm{OPT}\) as the supremum of this welfare.
The computational problem is to find a finite list \(q^1,\ldots,q^K\in\mathbb{Q}_{\ge0}^{\tau}\) with \(\sum_k q^k\le\mu\) coordinatewise and \(\sum_k(q^k)^{\mathsf T}Vq^k\ge\mathrm{OPT}-\varepsilon\). Residual mass is partitioned into singletons.

Is this additive-\(\varepsilon\) search problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard when \(\varepsilon\) is part of the binary input?

For finite agents, maximizing utilitarian welfare in additively separable hedonic games is strongly NP-hard even with symmetric, nonzero pairwise valuations. [Source](https://arxiv.org/pdf/1005.4540v3)
No result settling exactly the continuous problem defined above was located in the literature search.

Modeling choices made when packaging the task

  • Made the atomless population concrete as the Lebesgue unit interval with measurable type sets of the specified masses.
  • Interpreted diagonal valuations as interactions between distinct agents of the same type; excluding an individual from its own coalition integral has no effect.
  • Allowed unrestricted measurable coalitions, including singletons, and defined partition welfare through the countably many positive-mass coalitions.
  • Interpreted unallocated mass in the finite output as singleton coalitions, preserving exhaustive population coverage.
  • Used the supremum as the optimization benchmark to avoid assuming that a maximizing measurable partition exists.
  • Counted the binary encoding of epsilon in the total input length, so polynomial time means polynomial in precision bit length.
  • Identified m with tau because this problem has no separate candidate, item, or ground-set parameter.

Result

The additive-\(\varepsilon\) search problem is \(\mathrm{NP}\text{-hard}\). This holds even when every diagonal entry equals \(1\), all valuations are nonzero integers, all supported types have equal dyadic masses, and \(1/\varepsilon\) is polynomially bounded in \(\tau\).

The crucial fact is that positive diagonal entries allow fractional compositions to be rounded to partitions that keep every type together.

1. A rounding lemma

Lemma. Suppose \(V\) is symmetric and \(V_{tt}\ge 0\) for every type \(t\). From any finite feasible list \(q^1,\ldots,q^K\), one can construct a partition keeping each type entirely within one coalition, with welfare at least
\(\sum_{k=1}^K(q^k)^{\mathsf T}Vq^k\).
For rational input, this construction takes polynomial time in the combined input and list encoding lengths.

Proof. Let \(r_t=\mu_t-\sum_kq_t^k\). Append one composition \(r_te_t\) for each type \(t\), where \(e_t\) is its coordinate vector. These added compositions contribute
\(\sum_tV_{tt}r_t^2\ge 0\).
Thus we now have finitely many coalition labels, with every type’s mass fully allocated.

Fix a type \(t\), keeping the allocations of all other types fixed. Write its current allocations as \(x_1,\ldots,x_J\), with \(\sum_jx_j=\mu_t\). Set
\(d=V_{tt}\) and \(b_j=\sum_{s\ne t}V_{ts}q_s^j\).
By symmetry, total welfare has the form

\(F=C+d\sum_{j=1}^Jx_j^2+2\sum_{j=1}^Jb_jx_j,\)

where \(C\) does not depend on this type’s allocation.

If all of type \(t\) is placed at label \(j\), the resulting welfare is
\(F_j=C+d\mu_t^2+2\mu_tb_j\).
Taking the weighted average with weights \(x_j/\mu_t\) gives

\(\displaystyle \sum_{j=1}^J\frac{x_j}{\mu_t}F_j =C+d\mu_t^2+2\sum_{j=1}^Jb_jx_j \ge F.\)

The inequality follows from \(d\ge 0\) and
\(\sum_jx_j^2\le(\sum_jx_j)^2=\mu_t^2\).
Consequently, at least one label receives all of type \(t\) without decreasing welfare.

Perform this operation once for each type. Previously processed types remain unsplit. At the end, discard empty labels; the remaining labels define a partition of the types. Grouping the corresponding measurable type sets realizes this partition.

For rational data, all comparisons are exact rational comparisons. Throughout the procedure, each coordinate is either an original allocation, a residual allocation, zero, or its full type mass. There are \(K+\tau\) labels and \(\tau\) steps, so the arithmetic and encoding lengths are polynomially bounded. This proves the lemma.

Consequence for arbitrary measurable partitions. Under the lemma’s hypotheses, let \(M_*\) denote the maximum welfare among partitions keeping every type together. There are finitely many partitions of the supported types, so this maximum exists.

For any measurable population partition, enumerate its positive-mass coalitions as \(q^1,q^2,\ldots\). With \(s_k=\sum_tq_t^k\) and \(D=\max_{t,s}|V_{ts}|\),

\(\displaystyle \sum_k\left|(q^k)^{\mathsf T}Vq^k\right| \le D\sum_ks_k^2 \le D\left(\sum_ks_k\right)^2 \le D.\)

Thus its welfare series converges absolutely. The lemma applied to every finite prefix gives

\(\displaystyle \sum_{k=1}^J(q^k)^{\mathsf T}Vq^k\le M_*.\)

Taking the limit proves that every measurable partition has welfare at most \(M_*\). Conversely, a maximizing partition of the types is a permissible population partition. Therefore

\(\mathrm{OPT}=M_*.\)

This also handles residual mass lying in arbitrarily many zero-mass coalitions.

2. An explicit reduction from maximum cut

We use the known \(\mathrm{NP}\)-completeness of deciding whether an unweighted simple graph has a cut of at least a specified size. See [Garey, Johnson, and Stockmeyer, *Some simplified NP-complete graph problems*](https://www.sciencedirect.com/science/article/pii/0304397576900591).

Let \(G=(U,E)\) be such a graph, with \(n=|U|\ge 1\). Define

\(H=\binom n2,\qquad M=H+1,\qquad A=nM+1,\qquad B=nA+1.\)

Choose \(N\) to be the least power of two satisfying \(N\ge n+2\). Create:

  • one type for each vertex of \(G\);
  • two anchor types \(a,b\);
  • \(N-n-2\) dummy types.

Every type has mass \(1/N\). Thus \(m=\tau=N\), all masses are positive dyadic rationals, and their sum is \(1\).

Define the symmetric valuation matrix by the following rules:

  • \(V_{tt}=1\) for every type;
  • \(V_{ab}=-B\);
  • \(V_{av}=V_{bv}=A\) for every vertex type \(v\);
  • \(V_{uv}=-M\) when \(\{u,v\}\in E\);
  • \(V_{uv}=-1\) for distinct nonadjacent vertex types;
  • every off-diagonal entry involving a dummy type is \(-1\).

All entries are nonzero.

For a partition \(\mathcal P\) of the types, define its integer score

\(\displaystyle S(\mathcal P)=\sum_{C\in\mathcal P}\sum_{t,s\in C}V_{ts}.\)

Because every type has mass \(1/N\), the corresponding population welfare is \(S(\mathcal P)/N^2\). Let \(S_*\) be the maximum integer score. The rounding lemma gives

\(\mathrm{OPT}=S_*/N^2.\)

We next determine the structure of every maximizing type partition.

Dummy types are alone

If a dummy shares a coalition with \(r\ge 1\) other types, separating it into its own coalition removes \(r\) unordered interactions, each of valuation \(-1\). Its diagonal contribution is unchanged, so its separation increases \(S\) by \(2r>0\).

Hence every dummy is alone in a maximizing partition.

The anchors are separated

Suppose both anchors belong to one coalition. After the preceding observation, its other members are some set \(R\) of vertex types. Separating \(b\) into its own coalition changes the score by

\(2(B-A|R|)\ge 2(B-An)=2>0.\)

Therefore the anchors belong to different coalitions in every maximizing partition.

Every vertex belongs to an anchor coalition

Suppose a nonempty coalition \(R\) contains only vertex types. Merge it with the coalition containing \(a\). If that anchor coalition contains \(r\le n\) vertex types, the sum of the newly introduced unordered valuations is at least

\(A|R|-M|R|r\ge |R|(A-Mn)=|R|>0.\)

Here every valuation between two distinct vertex types is at least \(-M\). The merger therefore strictly increases the score.

It follows that every maximizing partition consists of two anchor coalitions containing all vertex types, together with isolated dummy types.

Its vertex assignment is a maximum cut

An assignment to the two anchors defines a cut of \(G\). Let \(c\) be the number of graph edges crossing this cut, and let \(u_0\) be the number of nonedges whose endpoints lie on the same side. The score is

\(S=N+2\bigl(nA-M(|E|-c)-u_0\bigr).\)

Indeed, the diagonals contribute \(N\), each vertex contributes one anchor interaction of value \(A\), each uncut edge contributes \(-M\), and each uncut nonedge contributes \(-1\).

Consider two assignments with cut sizes \(c_1>c_2\). Their score difference satisfies

\(S_1-S_2 =2\bigl(M(c_1-c_2)-(u_{0,1}-u_{0,2})\bigr) \ge 2(M-H)=2>0,\)

because \(0\le u_{0,i}\le H\).

Thus every assignment with a larger graph cut has a strictly larger score. In particular, every maximizing type partition yields a maximum cut of \(G\).

3. Binary precision forces an exact optimum

Set

\(\varepsilon=\frac{1}{2N^2}.\)

Suppose an algorithm returns any valid finite rational list for this constructed instance. Its welfare \(W\) satisfies

\(W\ge\mathrm{OPT}-\varepsilon =\frac{S_*}{N^2}-\frac{1}{2N^2}.\)

Apply the rounding lemma to the returned list. This produces a type partition \(\widehat{\mathcal P}\) whose welfare is at least \(W\). Consequently,

\(S(\widehat{\mathcal P})\ge S_*-\frac12.\)

Both scores are integers, and \(S_*\) is the maximum. Therefore

\(S(\widehat{\mathcal P})=S_*.\)

The rounded partition is exactly optimal. By the structural analysis above, reading which vertices accompany \(a\) and \(b\) gives a maximum cut. Comparing its size with the original decision threshold solves the maximum-cut decision problem.

4. Encoding size and conclusion

The construction satisfies \(N<2(n+2)\). The valuation magnitudes are polynomially bounded:

\(M=O(n^2),\qquad A=O(n^3),\qquad B=O(n^4).\)

Each valuation therefore uses \(O(\log n)\) bits. If \(N=2^r\), then the masses are \(2^{-r}\) and \(\varepsilon=2^{-(2r+1)}\), also requiring only \(O(\log n)\) bits each. Hence the entire constructed instance has polynomial encoding length.

A polynomial-time search algorithm would have polynomial output length, so the exact rounding procedure would also run in polynomial time. It would then solve the \(\mathrm{NP}\)-complete maximum-cut decision problem in polynomial time.

This proves the requested \(\mathrm{NP}\)-hardness. In particular, the search problem is not polynomial-time solvable unless \(\mathrm P=\mathrm{NP}\).
