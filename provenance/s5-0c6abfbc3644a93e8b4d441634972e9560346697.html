The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), and a symmetric binary affinity function \(w:T\times T\to\{0,1\}\), choose a welfare-maximizing assignment of type mass to a fixed finite menu \(\mathcal H\) of bounded-size seat components. The input includes rational component masses \(\nu_H\) with \(\sum_{H\in\mathcal H}\nu_H|V(H)|=1\). For each type assignment \(\phi:V(H)\to T\), choose rational configuration mass \(\lambda_{H,\phi}\geq 0\), with \(\sum_\phi\lambda_{H,\phi}=\nu_H\) and \(\sum_{H,\phi}\lambda_{H,\phi}|\phi^{-1}(t)|=\mu_t\). Maximize total per-capita B-utility welfare, where each unit of mass receives a whole seat and its neighbors in its component.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. The input also gives a symmetric affinity matrix \(w:T\times T\to\{0,1\}\).
Fix a nonempty finite menu \(\mathcal H\) of nonempty connected simple undirected seat graphs, each with at most \(m\) vertices; the menu and its size bound are constants independent of the input. Input component masses \(\nu_H\) are nonnegative binary rationals satisfying \(\sum_H\nu_H|V(H)|=1\). Let \(L\) be the total input bit length; express running times in \(m,\tau,L\).
A configuration is any map \(\phi:V(H)\to T\), allowing repeated types. The value \(w(t,t)\) describes affinity between distinct occupants of type \(t\). At seat \(v\), B-utility is \(b_{H,\phi}(v)=\max_{u\in N_H(v)}w(\phi(v),\phi(u))\), with utility zero when \(N_H(v)=\varnothing\).
Choose rational configuration masses \(\lambda_{H,\phi}\geq0\) satisfying \(\sum_\phi\lambda_{H,\phi}=\nu_H\) for every \(H\), and \(\sum_{H,\phi}\lambda_{H,\phi}|\phi^{-1}(t)|=\mu_t\) for every \(t\). Each configuration supplies whole seats and their neighbors to its assigned mass. Maximize per-capita welfare \(\sum_{H,\phi}\lambda_{H,\phi}\sum_{v\in V(H)}b_{H,\phi}(v)\).

For every fixed menu \(\mathcal H\), is this continuous welfare-maximization problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard for some fixed menu?

Discrete maximum-welfare seat arrangement with B-utility is NP-hard even with symmetric binary affinities and planar seat graphs of bounded degree; the construction uses triangles and stars of bounded size. [Verified source](https://arxiv.org/html/2406.09965v2#S5).
No published result settling this exact continuous configuration-mass problem was identified in the literature search.

Result

For every fixed menu \(\mathcal H\), the problem is polynomial-time solvable, including computation of the exact optimal welfare and rational configuration masses attaining it.

The essential observation is that the number of configurations is polynomial in the support size when the maximum component size is fixed.

1. An explicit linear program

Write \(k=|\mathcal H|\) and \(n_H=|V(H)|\). Label the vertices of each graph once and for all. Since repetitions of types are allowed, the number of configurations for \(H\) is exactly \(\tau^{n_H}\). Thus the total number of variables is

\(N=\sum_{H\in\mathcal H}\tau^{n_H}\leq k\tau^m.\)

For each configuration define its type counts and total welfare by

\(a_{t,H,\phi}=|\phi^{-1}(t)|,\qquad c_{H,\phi}=\sum_{v\in V(H)}b_{H,\phi}(v).\)

These are integers satisfying \(0\leq a_{t,H,\phi}\leq m\) and \(0\leq c_{H,\phi}\leq n_H\leq m\).

The optimization problem is precisely the following rational linear program:

\(\displaystyle \max_{\lambda\geq0}\sum_{H,\phi}c_{H,\phi}\lambda_{H,\phi},\)

subject to

\(\displaystyle \sum_{\phi:V(H)\to T}\lambda_{H,\phi}=\nu_H\quad(H\in\mathcal H),\)

and

\(\displaystyle \sum_{H,\phi}a_{t,H,\phi}\lambda_{H,\phi}=\mu_t\quad(t\in T).\)

There are \(r=\tau+k\) equality constraints. The objective coefficients are fixed once configurations have been enumerated: changing a configuration’s mass scales the welfare of its whole seat component linearly. Consequently, this linear program introduces no relaxation beyond the configuration masses explicitly permitted in the question.

2. Feasibility and attainment

For each \(H\) and \(t\), let \(\phi_{H,t}\) be the constant configuration assigning type \(t\) to every vertex. Set

\(\lambda_{H,\phi_{H,t}}=\nu_H\mu_t,\)

and set all other configuration masses to zero. Because \(H\) is nonempty, its constant configurations for different types are distinct.

For every graph, the assigned component mass is

\(\displaystyle \sum_t\nu_H\mu_t=\nu_H.\)

For every type, the assigned occupant mass is

\(\displaystyle \sum_H n_H\nu_H\mu_t=\mu_t,\)

using the two normalization assumptions. This is therefore a rational feasible solution.

Consider also the feasible set over real configuration masses. It is closed, and every coordinate satisfies \(0\leq\lambda_{H,\phi}\leq\nu_H\). It is thus a nonempty compact polytope. The linear objective attains a maximum on it. Moreover, every feasible solution satisfies

\(\displaystyle 0\leq\sum_{H,\phi}c_{H,\phi}\lambda_{H,\phi}\leq\sum_H n_H\nu_H=1.\)

The rational linear-programming theorem used below returns a rational optimizer. Hence the real maximum is attained within the rational solutions required by the question.

3. Encoding size and exact running time

All configurations can be enumerated explicitly. For each one:

  • Its type counts can be computed by scanning at most \(m\) vertices.
  • Its welfare can be computed by examining at most \(m(m-1)/2\) edges. For each seat, record whether an incident edge has affinity one. This also handles repeated types using the supplied diagonal affinities.
  • Its column of constraint coefficients and its objective coefficient can then be written down.

In standard form, nonnegativity is implicit. A dense encoding of the equality matrix and objective therefore has total bit length

\(B=O\!\left(L+N(r+1)\log(m+1)\right).\)

Indeed, the matrix and objective contain \(O(N(r+1))\) integers of magnitude at most \(m\), while the right-hand sides are the supplied rational masses.

We use the standard polynomial-time theorem for rational linear programming: an explicitly encoded rational linear program can be solved in time polynomial in its total binary encoding length, with an exact rational optimizer returned when the optimum is finite and attained. Polynomial solvability here concerns bit complexity, rather than unit-cost arithmetic on arbitrary real numbers. See the discussion of this theorem in [Dadush, Huiberts, Natura, and Végh](https://link.springer.com/article/10.1007/s10107-023-01956-2).

Its hypotheses hold: all coefficients are rational, the entire program is explicitly available, and Section 2 proves feasibility and boundedness. Redundant equalities and zero component masses cause no difficulty for this theorem.

Including construction of the program, a valid bit-operation bound is

\(\displaystyle \left[L+km^2\tau^m+k\tau^m(\tau+k+1)\log(m+1)\right]^{O(1)}.\)

For a fixed menu, \(k\) is constant, so this can also be expressed as

\(\displaystyle \tau^{O(m)}\operatorname{poly}(m,L).\)

Since \(m\) is fixed independently of the input, this is polynomial in \(L\). The resulting rational masses give an optimal arrangement in exactly the representation specified by the task. Their welfare can be evaluated exactly by rational arithmetic.

4. Relation to discrete hardness

The cited [discrete hardness theorem](https://arxiv.org/html/2406.09965v2#S5) concerns assignments of indivisible agents to seats. Such assignments impose integer restrictions on configuration counts.

The present problem explicitly allows rational configuration masses. Its feasible set is the linear-programming polytope above, and no conversion to integer configuration counts is required. Thus discrete hardness does not contradict the polynomial-time algorithm.

The conclusion holds for every fixed menu in the question. The dependence on \(\tau^m\) does not establish polynomial time when component size is allowed to grow with the input.
