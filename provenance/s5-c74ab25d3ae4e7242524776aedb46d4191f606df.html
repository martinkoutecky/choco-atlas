The continuous mirror question, as graded

Given candidates \(C\), fixed \(k>1\), a target \(c\), rational masses \(\mu_t\) over a finite support of nonmanipulator partial-order types, and rational manipulator mass \(\alpha>0\), with \(\sum_t\mu_t+\alpha=1\), can the cohort masses be allocated among rankings extending their partial orders and the manipulator mass among ballots so that \(c\) wins uniquely under \(k\)-approval?

Packaged proof task (what the prover saw — nothing else)

Fix an integer \(k>1\). The input consists of a candidate set \(C\) with \(m=|C|>k\), a target \(c\in C\), and a society given by its support: the list of \(\tau\) nonmanipulator partial-order types \(P_t\), each with positive mass \(\mu_t\) encoded as a binary rational. Here \(\tau\) is the support size, not the number of possible types. Manipulator mass \(\alpha>0\) is also a binary rational, with \(\sum_t\mu_t+\alpha=1\).
Let \(\mathcal R\) be the strict linear rankings of \(C\), and \(E_t\subseteq\mathcal R\) the rankings extending \(P_t\). An allocation chooses nonnegative real masses \(x_{t,r}\) for \(r\in E_t\) and \(y_r\) for \(r\in\mathcal R\), satisfying \(\sum_{r\in E_t}x_{t,r}=\mu_t\) and \(\sum_{r\in\mathcal R}y_r=\alpha\). Thus each cohort may split its mass, and manipulators have unrestricted ballots.
Use standard \(k\)-approval, weighting each ballot by its assigned mass. The decision problem asks whether an allocation exists for which \(c\)'s score strictly exceeds every other candidate's score; ties do not count as success. Let \(L\) be the total input bit length, including explicitly encoded partial orders; express running times in \(m,\tau,L\), with \(k\) fixed.

For every fixed integer \(k>1\), is this continuous weak-manipulation decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

Discrete weak manipulation under \(k\)-approval is \(\mathrm{NP}\)-complete for every fixed \(k>1\), even with one manipulator and requiring a unique winner. [Source](https://arxiv.org/pdf/1504.08256).
No result settling this exact divisible-mass problem was identified in the literature search.

Modeling choices made when packaging the task

  • Require m>k, consistent with the nonconstant positional scoring vectors used in the discrete definition; approving every candidate is excluded.
  • Allow nonnegative real allocation masses and arbitrary splitting within every cohort, making divisibility explicit.
  • Encode partial orders explicitly and define L as the total input bit length.
  • Allow empty nonmanipulator support, since the discrete definition imposes no nonemptiness condition on nonmanipulators.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed integer \(k>1\), the stated continuous weak-manipulation problem belongs to \(\mathrm P\).

The key is that a ballot’s contribution under \(k\)-approval depends only on its top \(k\) candidates. There are polynomially many such sets when \(k\) is fixed, and divisible masses permit an exact linear-programming formulation.

1. Characterizing attainable approval sets

Write \(a\succ_t b\) when partial order \(P_t\) requires \(a\) to precede \(b\). Define

\(\displaystyle \mathcal F_t=\{S\subseteq C: |S|=k,\ \text{and }b\in S,\ a\succ_t b\Longrightarrow a\in S\}.\)

Lemma. A set \(S\subseteq C\) of size \(k\) is the top \(k\) set of some ranking extending \(P_t\) if and only if \(S\in\mathcal F_t\).

Proof. If \(S\) is the top \(k\) set of an extension and \(b\in S\), every candidate required to precede \(b\) also lies in its first \(k\) positions. Thus \(S\in\mathcal F_t\).

Conversely, suppose \(S\in\mathcal F_t\). Choose linear extensions of the restrictions of \(P_t\) to \(S\) and to \(C\setminus S\), and concatenate them, placing \(S\) first. Such extensions exist because every finite partial order has a linear extension: repeatedly select an element with no required predecessor.

The concatenation respects relations within each part. It also respects every relation from \(S\) to \(C\setminus S\). A relation requiring a candidate outside \(S\) to precede one inside \(S\) is excluded by the definition of \(\mathcal F_t\). Hence the concatenation extends \(P_t\) and has top \(k\) set \(S\). \(\square\)

Let \(\mathcal F_0=\{S\subseteq C:|S|=k\}\), the approval sets available to manipulators.

2. An exact formulation using approval sets

Introduce nonnegative real variables \(z_{t,S}\) for \(S\in\mathcal F_t\), and \(u_S\) for \(S\in\mathcal F_0\), subject to

\(\displaystyle \sum_{S\in\mathcal F_t}z_{t,S}=\mu_t\qquad(t=1,\ldots,\tau),\)

\(\displaystyle \sum_{S\in\mathcal F_0}u_S=\alpha.\)

For candidate \(a\in C\), define its score by

\(\displaystyle s_a=\sum_{t=1}^{\tau}\sum_{\substack{S\in\mathcal F_t\\a\in S}}z_{t,S}+\sum_{\substack{S\in\mathcal F_0\\a\in S}}u_S.\)

Lemma. These variables describe exactly the score vectors attainable by allocations in the question.

Proof. Given an original allocation, aggregate all ranking masses with the same top \(k\) set:

\(\displaystyle z_{t,S}=\sum_{\substack{r\in E_t\\\operatorname{Top}_k(r)=S}}x_{t,r},\qquad u_S=\sum_{\substack{r\in\mathcal R\\\operatorname{Top}_k(r)=S}}y_r.\)

The first lemma ensures that the resulting sets belong to the specified families. Aggregation preserves cohort masses and every candidate’s score.

Conversely, for each \(t\) and each \(S\in\mathcal F_t\), choose one extending ranking with top \(k\) set \(S\), whose existence follows from the first lemma, and assign it mass \(z_{t,S}\). For each manipulator set \(S\), choose any ranking putting \(S\) first and assign it mass \(u_S\). Set all other ranking masses to zero. This produces an original allocation with exactly the stated scores and masses. \(\square\)

3. Testing strict victory

Add a real variable \(\delta\) and solve the linear program

\(\displaystyle \text{maximize }\delta,\)

subject to the preceding mass and nonnegativity constraints, together with

\(\displaystyle s_c-s_a\ge\delta\qquad(a\in C\setminus\{c\}),\qquad -1\le\delta\le1.\)

This program is nonempty: choose one approval set for each cohort and for the manipulators, assign their full masses to those sets, and take \(\delta=-1\). Every score lies in \([0,1]\), because total ballot mass is one.

Its feasible region is compact. Each mass variable is nonnegative and bounded by its cohort’s mass, and \(\delta\) is bounded. Consequently, the optimum \(\delta^*\) exists.

Proposition. A successful allocation exists if and only if \(\delta^*>0\).

Proof. If an allocation makes \(c\) strictly beat every rival, the finite collection of positive gaps has a positive minimum:

\(\displaystyle d=\min_{a\ne c}(s_c-s_a)>0.\)

Aggregation gives a feasible solution with \(\delta=d\), so \(\delta^*>0\).

Conversely, an optimal solution with \(\delta^*>0\) satisfies \(s_c-s_a\ge\delta^*>0\) for every rival. The second lemma converts it into a successful original allocation. \(\square\)

The comparison with zero is exact. We use the standard rational linear-programming theorem: an explicitly given rational linear program can be solved in time polynomial in its binary encoding length, with an exact optimal value when the feasible region is nonempty and the objective is bounded. These hypotheses have all been verified above. See [Khachiyan’s polynomial-time linear-programming theorem](https://www.mathnet.ru/eng/dan42319).

For completeness, the winning margin cannot require superpolynomial precision relative to this program’s size. Let \(N\) be its number of variables, and let \(D\) be the product of the input denominators of all masses. An optimal vertex exists for a nonempty compact polytope. At that vertex, choose \(N\) linearly independent active constraints. Their coefficient matrix \(A\) has entries in \(\{-1,0,1\}\), and their right-hand sides become integral after multiplication by \(D\). Cramer’s rule therefore gives

\(\displaystyle \delta^*=\frac{q}{D\det A}\quad\text{for some integer }q.\)

Hadamard’s inequality gives \(|\det A|\le N^{N/2}\le N^N\). Thus, if \(\delta^*>0\), then

\(\displaystyle \delta^*\ge\frac{1}{DN^N}.\)

Since \(\log_2D\le L\), this bound has polynomial binary length. Strict victory is therefore handled without treating ties as successes or choosing an unjustified tolerance.

4. Running time

Put \(B=\binom{m}{k}\). The program has at most

\(\displaystyle N=(\tau+1)B+1\)

variables and \(\tau+m+2\) constraints apart from nonnegativity.

Compute the transitive closure of each explicitly encoded partial order in \(O(\tau m^3)\) time. Enumerate all \(B\) candidate sets of size \(k\). For each cohort and set, test the condition in Section 1 by inspecting all possible predecessors of its members. This takes \(O(km)\) time per test, hence total preprocessing time

\(\displaystyle O\!\left(L+\tau m^3+\tau km\binom{m}{k}\right)=O_k\!\left(L+\tau m^3+\tau m^{k+1}\right).\)

All program coefficients belong to \(\{-1,0,1\}\); the only other numerical data are the input masses and the bounds on \(\delta\). Its dense encoding length is

\(\displaystyle O\!\left(L+(\tau+m+2)\bigl((\tau+1)B+1\bigr)\right).\)

Consequently, preprocessing followed by exact rational linear programming takes

\(\displaystyle O_k(L+\tau m^3+\tau m^{k+1})+\operatorname{poly}\!\left(L+(\tau+m+2)\bigl((\tau+1)m^k+1\bigr)\right)\)

bit operations. This is polynomial in \(m,\tau,L\) for every fixed \(k>1\).

Divisibility is essential to this formulation: each cohort may distribute its mass among approval sets. The discrete problem instead requires indivisible choices, so its stated hardness does not contradict this algorithm.
