The continuous mirror question, as graded

Given a finite type set \(T\) with rational masses \(\mu_t>0\) summing to \(1\), additive valuations \(v_{tg}\geq 0\) for \(m\) resource classes, per-person welfare weights \(a_t\geq 0\) with \(\sum_t\mu_ta_t=1\), and rational per-capita supplies \(s_g\), find a finite-support mass assignment \(x_{t,k}\geq 0\) to integral bundles \(k\in\mathbb{Z}_{\geq 0}^m\). Require \(\sum_k x_{t,k}=\mu_t\) and \(\sum_{t,k}k_gx_{t,k}\leq s_g\), and define \(u_t(k)=\sum_g v_{tg}k_g\) and \(W(x)=\sum_{t,k}a_tx_{t,k}\log u_t(k)\). With \(\nu_t=\mu_ta_t\), does there exist an algorithm polynomial in \(m,\tau,L,\log(1/\epsilon)\) that returns a feasible \(x\) with \(W(x)\geq \mathrm{OPT}-2\log 2-\frac{1}{2e}-2D_{\mathrm{KL}}(\nu\| \mu)-\epsilon\), where \(L\) is the rational input bit length and feasible welfare is positive?

Packaged proof task (what the prover saw — nothing else)

A society is specified by its support: a list \(T\) of \(\tau\geq1\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) resource classes, binary rational valuations \(v_{tg}\geq0\), finite per-capita supplies \(s_g\geq0\), and per-person weights \(a_t\geq0\), with \(\sum_t\mu_ta_t=1\); supplies and weights are binary rationals. Let \(L\) be the total rational input bit length.
An assignment splits each type among integral bundles \(k\in\mathbb Z_{\geq0}^m\): finitely many masses \(x_{t,k}\geq0\) are nonzero, \(\sum_kx_{t,k}=\mu_t\), and \(\sum_{t,k}k_gx_{t,k}\leq s_g\) for every \(g\). Unused supply is allowed, and there is no additional bound on individual bundles.
Set \(u_t(k)=\sum_gv_{tg}k_g\) and \(W(x)=\sum_{t:a_t>0}\sum_{k:x_{t,k}>0}a_tx_{t,k}\log u_t(k)\), using natural logarithms and \(\log0=-\infty\); zero-weight types contribute zero.
Assume some feasible finite-support assignment has finite \(W\), equivalently positive weighted geometric welfare. Let \(\mathrm{OPT}=\sup_xW(x)\) over feasible finite-support assignments, and \(\nu_t=\mu_ta_t\), with \(D_{\mathrm{KL}}(\nu\|\mu)=\sum_{t:\nu_t>0}\nu_t\log(\nu_t/\mu_t)\).

Does there exist an algorithm, polynomial in \(m,\tau,L,\log(1/\epsilon)\), that for every binary rational \(0<\epsilon<1\) returns an explicitly listed feasible assignment with binary rational masses and binary integer bundles satisfying \(W(x)\geq\mathrm{OPT}-2\log2-\frac{1}{2e}-2D_{\mathrm{KL}}(\nu\|\mu)-\epsilon\)?

For finite agents and explicitly listed indivisible items, a polynomial-time algorithm achieves additive log-welfare loss \(2\log2+\frac{1}{2e}+2D_{\mathrm{KL}}(w\|\mathbf1/n)\), where \(w\) is the normalized agent-weight vector ([Brown et al.](https://arxiv.org/pdf/2401.02918)).
A stronger deterministic \(e^{1/e}+\delta\) approximation for that discrete problem runs in time polynomial in input size and \(1/\delta\) ([Feng–Li](https://theoretics.episciences.org/16348/pdf)); no result settling this precise mass-assignment guarantee was identified.

Modeling choices made when packaging the task

  • Required valuations and weights to be binary rationals so that the rational input bit length is defined; supplies are finite nonnegative binary rationals.
  • Interpreted positive feasible welfare as existence of a feasible finite-support assignment with positive weighted geometric welfare, equivalently finite log welfare, rather than requiring positive log welfare.
  • Retained nonnegative weights and omitted zero-weight terms from welfare; positive mass assigned zero utility at a positive-weight type gives negative infinite log welfare.
  • Used natural logarithms and the zero-term convention for KL divergence.
  • Defined OPT as a supremum over feasible finite-support assignments, without assuming attainment.
  • Specified explicit binary rational output masses, binary integer bundles, and a binary rational accuracy parameter strictly between zero and one.
  • Retained unused supply and unrestricted nonnegative integral bundle coordinates as stated in the continuous question; required nonempty type support and at least one resource class.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Yes. There is an algorithm polynomial in \(m,\tau,L\) that returns an explicitly listed feasible assignment with binary encoded rational masses and satisfies
\[ W(x)\geq \mathrm{OPT}-\log 2-\frac12. \]
This is stronger than the requested guarantee. The proof uses the ability to split each type among bundles.

Here, “binary rational” is interpreted as a rational number whose numerator and denominator are encoded in binary.

1. Preliminary bounds

Let \(A=\{t:a_t>0\}\), \(a_{\max}=\max_{t\in A}a_t\), and \(S=\sum_gs_g\). The normalization gives
\[ \sum_{t\in A}\mu_ta_t=1. \]
The finite-welfare feasibility assumption implies \(A\neq\varnothing\), \(S>0\), and that every type in \(A\) has some positive valuation.

Let
\[ V_+=\max_{t\in A,g}v_{tg}, \qquad V_-=\min\{v_{tg}:t\in A,\ v_{tg}>0\}. \]
Both are positive.

The optimum is finite. Indeed, for any feasible finite-welfare assignment, the mean utility conditional on type \(t\in A\) satisfies
\[ \frac{1}{\mu_t}\sum_kx_{t,k}u_t(k) \leq \frac{V_+S}{\mu_t}. \]
Applying Jensen’s inequality to the probabilities \(x_{t,k}/\mu_t\) gives
\[ W(x)\leq \sum_{t\in A}\mu_ta_t \log\!\left(\frac{V_+S}{\mu_t}\right)<\infty. \]
Together with the promise, this proves that \(\mathrm{OPT}\) is a finite real number.

Zero-weight types can always receive the zero bundle. Henceforth only types in \(A\) require allocation variables.

2. Truncating individual bundles

Define the positive integer
\[ B=\max\left\{1,\left\lceil4a_{\max}S\right\rceil\right\}. \]

Consider any feasible finite-support assignment \(x\) with finite welfare. Replace each bundle \(k\) of a positive-weight type by \(k'\), where
\[ k'_g=\min\{k_g,B\}. \]
This preserves type masses and cannot increase resource consumption. It also preserves positive utility.

For a bundle with positive utility, put
\[ M=\max\left\{1,\max_g\frac{k_g}{B}\right\}. \]
Coordinatewise, \(k_g\leq Mk'_g\); thus \(u_t(k)\leq Mu_t(k')\). Consequently,
\[ \log u_t(k)-\log u_t(k') \leq\log M \leq M-1 \leq\frac{\sum_gk_g}{B}. \]
Summing with coefficients \(a_tx_{t,k}\), the welfare loss is at most
\[ \frac{1}{B}\sum_{t\in A,k,g}a_tx_{t,k}k_g \leq\frac{a_{\max}S}{B} \leq\frac14. \]

Therefore every feasible finite-welfare assignment can be replaced by one using only bundles in \(\{0,\ldots,B\}^m\), with welfare loss at most \(1/4\).

3. Replacing a bundle by single-class bundles

We now prove the central rounding lemma.

Fix a type \(t\in A\) and an integral bundle \(k\) with positive utility \(u=u_t(k)\). For every class with \(v_{tg}k_g>0\), define
\[ q_g=\frac{v_{tg}k_g}{u}, \qquad r_g=\frac{u}{v_{tg}}, \qquad n_g=2^{\lfloor\log_2r_g\rfloor}. \]
The \(q_g\) sum to one. Moreover, \(r_g\geq k_g\geq1\), so \(n_g\) is a positive integer and
\[ n_g\leq r_g<2n_g. \]

Replace the bundle by a lottery that gives \(n_g\) units of class \(g\), and no other resources, with probability \(q_g\).

For each resource class \(g\), its expected consumption is
\[ q_gn_g\leq q_gr_g=k_g. \]
Every bundle occurring in this lottery has utility
\[ v_{tg}n_g>\frac{u}{2}. \]
Its expected log utility is therefore at least \(\log u-\log2\).

Apply this replacement separately to every bundle in the truncated assignment. Type masses are preserved, resource consumption does not increase, and the total welfare loss is at most
\[ \sum_{t\in A,k}a_tx_{t,k}\log2 =\log2. \]

For a truncated bundle,
\[ \frac{u_t(k)}{v_{tg}} \leq\frac{mBV_+}{V_-}. \]
Set
\[ R=\frac{mBV_+}{V_-}, \qquad J=\left\lceil\log_2R\right\rceil. \]
Thus every resulting bundle belongs to the explicitly listed set
\[ \{2^je_g:0\leq j\leq J\}, \]
where \(e_g\) is the \(g\)-th unit vector.

We have proved that restricting positive-weight types to these bundles loses at most \(\log2+1/4\) relative to \(\mathrm{OPT}\).

4. A polynomial-size linear program

For every \(t\in A\), every \(g\) with \(v_{tg}>0\), and every \(0\leq j\leq J\), introduce a variable \(y_{tgj}\), representing the mass receiving bundle \(2^je_g\).

The feasible region \(P\) is defined by
\[ y_{tgj}\geq0, \qquad \sum_{g:v_{tg}>0}\sum_{j=0}^Jy_{tgj}=\mu_t \quad(t\in A), \]
and
\[ \sum_{\substack{t\in A\\v_{tg}>0}}\sum_{j=0}^J2^jy_{tgj} \leq s_g \quad(g=1,\ldots,m). \]

Define its true welfare objective by
\[ F(y)= \sum_{\substack{t\in A,\ g:v_{tg}>0\\0\leq j\leq J}} a_ty_{tgj}\log(v_{tg}2^j). \]

The preceding transformations establish that \(P\) is nonempty. Every variable is bounded by \(\mu_t\), so \(P\) is compact. Hence \(F\) attains a maximum \(F^\star\).

For every feasible finite-welfare assignment \(x\), the transformations produce a point in \(P\) with welfare at least \(W(x)-\log2-1/4\). Taking the supremum over \(x\) gives
\[ F^\star\geq\mathrm{OPT}-\log2-\frac14. \]

5. Rational coefficients and polynomial complexity

The logarithmic coefficients need not be rational. For each coefficient, compute a rational approximation \(\ell_{tgj}\) satisfying
\[ \left|\ell_{tgj}-\log(v_{tg}2^j)\right|\leq\frac18. \]
Use the rational objective
\[ \widehat F(y)=\sum_{t,g,j}a_ty_{tgj}\ell_{tgj}. \]

For every \(y\in P\), normalization gives
\[ |F(y)-\widehat F(y)| \leq\frac18\sum_{t,g,j}a_ty_{tgj} =\frac18. \]
Let \(\widehat y\) maximize \(\widehat F\) over \(P\), and let \(y^\star\) maximize \(F\). Then
\[ F(\widehat y) \geq\widehat F(\widehat y)-\frac18 \geq\widehat F(y^\star)-\frac18 \geq F^\star-\frac14. \]
Consequently,
\[ F(\widehat y)\geq\mathrm{OPT}-\log2-\frac12. \]

We verify the computational requirements.

  • Number and size of bundles. Every input rational has numerator and denominator of at most \(L\) bits. Thus \(a_{\max}\leq2^L\), \(S\leq m2^L\), and \(V_+/V_-\leq2^{2L}\). It follows that \(J=O(L+\log m)\). There are at most \(\tau m(J+1)\) variables, and each listed bundle has polynomial binary length. The integer \(J\) can be computed by exact rational comparisons with powers of two.
  • Logarithm approximation. For a positive rational \(z\), write \(z=2^hr\) with \(1\leq r<2\). For \(b=(r-1)/(r+1)\), one has

\[ \log r=2\sum_{i=0}^{\infty}\frac{b^{2i+1}}{2i+1}, \qquad 0\leq b<\frac13. \]
After \(N\) terms, the error is at most
\[ \frac{2b^{2N+1}}{(2N+1)(1-b^2)}. \]
The same series with \(b=1/3\) approximates \(\log2\). Approximating each logarithm to error \(1/[16(|h|+1)]\) yields \(\log z=h\log2+\log r\) to error at most \(1/8\). The geometric error bound and polynomially bounded \(|h|\) show that this takes polynomial time and produces rationals of polynomial bit length.

  • Linear programming. We use the standard polynomial-time theorem for rational linear programming: a nonempty bounded rational LP admits an exactly optimal rational solution computable in time polynomial in its dimensions and rational encoding length, with polynomial output length. Its hypotheses hold here: \(P\) is nonempty and bounded, and all constraints and coefficients of \(\widehat F\) are rational with polynomial encoding length.

Output every positive \(\widehat y_{tgj}\) as the mass assigned to bundle \(2^je_g\). For each zero-weight type, output mass \(\mu_t\) at the zero bundle. This is an explicitly listed feasible assignment with the required encodings.

The algorithm runs in time polynomial in \(m,\tau,L\), independently of \(\epsilon\).

6. Comparison with the requested guarantee

For completeness, the divergence is nonnegative even when some weights vanish. Using \(\log z\leq z-1\),
\[ -D_{\mathrm{KL}}(\nu\|\mu) =\sum_{t:\nu_t>0}\nu_t\log\frac{\mu_t}{\nu_t} \leq\sum_{t:\nu_t>0}\mu_t-1 \leq0. \]
Also,
\[ \log2=\int_1^2\frac{dr}{r}\geq\frac12. \]
Therefore
\[ \log2+\frac12 \leq2\log2 < 2\log2+\frac{1}{2e} +2D_{\mathrm{KL}}(\nu\|\mu)+\epsilon. \]
The proved welfare bound implies the requested one for every specified \(\epsilon\).
