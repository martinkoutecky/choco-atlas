The continuous mirror question, as graded

Given candidates \(O\), a finite ranking-type set \(T\subseteq L(O)\), rational focal mass \(\alpha\in(0,1]\), focal true ranking \(r\in T\), a fixed deterministic tie-break order, and a \(k\)-approval or positional scoring rule, choose a report \(r'\in T\). For every residual distribution \(\nu\in\Delta(T)\), the resulting society is \(\mu_{\nu,r'}=\alpha e_{r'}+(1-\alpha)\nu\). Define \(B_\alpha(r')\) and \(W_\alpha(r')\) as the focal type's best and worst possible winners under \(r\), over all \(\nu\). Decide whether some \(r'\) satisfies \(W_\alpha(r')\succ_r W_\alpha(r)\) or \(B_\alpha(r')\succ_r B_\alpha(r)\), and output such a report.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

Both \(k\)-approval and positional scoring with an input rational vector are polynomial-time solvable. An improving report, whenever one exists, can also be produced in polynomial time.

The proof uses the explicitly listed domain \(T\): there are only \(d\) reports to examine, and winner attainability for each report is an exact rational linear-programming problem. This settles the specified model for arbitrary admissible \(k\), signed scoring vectors, and deterministic tie-breaking.

1. Scores and attainable winners

For \(t\in T\) and \(c\in O\), let \(p_t(c)\) be the position of \(c\) in ranking \(t\). Define its per-unit-mass score by

  • \(a_{ct}=1\) if \(p_t(c)\leq k\), and \(a_{ct}=0\) otherwise, for \(k\)-approval;
  • \(a_{ct}=s_{p_t(c)}\) for positional scoring.

Fix a report \(q\in T\). Write the residual distribution as \(x=(x_t)_{t\in T}\), where \(x_t\geq0\) and \(\sum_{t\in T}x_t=1\). Candidate \(c\)'s score is

\(S_c(q,x)=\alpha a_{cq}+(1-\alpha)\sum_{t\in T}a_{ct}x_t.\)

Define

\(A(q)=\{c\in O:\text{there exists }x\in\Delta(T)\text{ for which }c\text{ wins under report }q\}.\)

This set is nonempty: \(T\neq\varnothing\), so a residual distribution exists, and every resulting society has a unique winner after tie-breaking. Since \(A(q)\) is a finite set, its best and worst elements according to \(r\) exist. These are precisely \(B_\alpha(q)\) and \(W_\alpha(q)\). Their existence does not require the winner map to be continuous.

2. Exact winner-attainability lemma

Let \(H(c)\) be the set of candidates preceding \(c\) in the tie-break order. For each opponent \(j\neq c\), put

\(D_{cj}(q,x)=\alpha(a_{cq}-a_{jq})+(1-\alpha)\sum_{t\in T}(a_{ct}-a_{jt})x_t.\)

Thus \(D_{cj}(q,x)=S_c(q,x)-S_j(q,x)\).

Lemma. Candidate \(c\) belongs to \(A(q)\) if and only if the following linear program is feasible and has strictly positive optimal value.

Maximize \(\varepsilon\), subject to:

  • \(x_t\geq0\) for every \(t\in T\);
  • \(\sum_{t\in T}x_t=1\);
  • \(0\leq\varepsilon\leq1\);
  • \(D_{cj}(q,x)\geq\varepsilon\) for every \(j\in H(c)\);
  • \(D_{cj}(q,x)\geq0\) for every \(j\in O\setminus(H(c)\cup\{c\})\).

Proof. Suppose first that \(c\) wins for some residual distribution \(x\). It must have a strictly larger score than every \(j\in H(c)\): equality would make the tie-break select a candidate preceding \(c\). It must have at least as large a score as every other opponent.

If \(H(c)\neq\varnothing\), choose

\(\varepsilon=\min\bigl(\{1\}\cup\{D_{cj}(q,x):j\in H(c)\}\bigr).\)

This minimum is positive because the set is finite and all its elements are positive. If \(H(c)=\varnothing\), choose \(\varepsilon=1\). In either case, the LP has a feasible point with positive objective value.

Conversely, suppose the LP has a feasible point with \(\varepsilon>0\). Then \(c\) strictly outscores every candidate preceding it in the tie-break order and weakly outscores every remaining opponent. Consequently, \(c\) is the selected winner.

Finally, the feasible region, when nonempty, is a closed subset of \(\Delta(T)\times[0,1]\), hence compact. The objective therefore attains its maximum. Thus a positive feasible margin exists exactly when the optimal value is positive. \(\square\)

All coefficients are rational. Exact rational linear programming can decide infeasibility and compute the optimal value in polynomial bit time; this is the standard polynomial-time LP theorem originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319). Its hypotheses apply here because the LP is explicitly represented, has rational coefficients, and has a bounded feasible region.

In particular, the test compares the exact optimum with zero. Replacing strict inequalities by weak inequalities, or choosing an arbitrary numerical tolerance, would not establish the lemma.

The construction also covers \(\alpha=1\): the residual terms vanish, and the LP simply checks the winner determined by the focal report.

3. Decision algorithm and report construction

Let \(\rho(c)=p_r(c)\), so smaller values mean greater preference according to the true ranking. For each \(q\in T\), perform the lemma's test for every \(c\in O\), thereby computing \(A(q)\). Set

\(b(q)=\min_{c\in A(q)}\rho(c),\qquad w(q)=\max_{c\in A(q)}\rho(c).\)

By definition,

\(b(q)=\rho(B_\alpha(q)),\qquad w(q)=\rho(W_\alpha(q)).\)

The algorithm returns any report \(q\in T\) satisfying

\(b(q)<b(r)\quad\text{or}\quad w(q)<w(r).\)

If there is no such report, it returns NO.

Correctness. Each set \(A(q)\) is computed exactly by the lemma. Consequently, the two comparisons are respectively equivalent to

\(B_\alpha(q)\succ_r B_\alpha(r)\quad\text{and}\quad W_\alpha(q)\succ_r W_\alpha(r).\)

Every admissible report is examined because \(T\) is explicitly listed. Hence the algorithm returns a report exactly when an improving report exists. The returned ranking itself is the requested witness. \(\square\)

4. Running times and encoding bounds

Let \(\ell_\alpha\) be the binary encoding length of \(\alpha\), with \(\ell_\alpha\leq L\). To state the bounds independently of a particular LP implementation, let \(\mathsf{LP}(n,h,b)\) denote a fixed polynomial upper bound on the bit time to assemble and solve a rational LP with \(n\) variables, at most \(h\) inequalities, and coefficient encoding length at most \(b\).

Each attainability LP has:

  • \(d+1\) variables;
  • \(d+m+3\) inequalities, counting the equality as two inequalities;
  • coefficient encoding length \(O(\ell_\alpha+1)\) for \(k\)-approval;
  • coefficient encoding length \(O(L+1)\) for input positional scoring.

For the coefficient bounds, approval-score differences belong to \(\{-1,0,1\}\). In the positional case, each coefficient uses a difference of two input scores and multiplication by either \(\alpha\) or \(1-\alpha\). These rational operations increase encoding length by at most a constant multiple of \(L+1\), including when scores are negative.

There are at most \(dm\) LP optimizations. A conservative bit-time bound for approval is

\(O\!\left(L+dm(L+1)^2+dm\,\mathsf{LP}\!\left(d+1,d+m+3,O(\ell_\alpha+1)\right)\right).\)

For input positional scoring, a conservative bound is

\(O\!\left(L+dm(L+1)^2+dm\,\mathsf{LP}\!\left(d+1,d+m+3,O(L+1)\right)\right).\)

The preprocessing term allows straightforward binary arithmetic and construction of the score table. Computing the best and worst attainable ranks requires another \(O(dm)\) elementary comparisons. Outputting the chosen ranking requires \(O(m\log m)\) bits under indexed candidate encoding.

Thus both decision and report construction take polynomial time in \(m,d,\tau,L\). For approval, the bound is uniform over all \(1\leq k<m\), with no additional factor exponential in \(k\).

The support size \(\tau\) has no separate algorithmic dependence beyond reading the input, already included in \(O(L)\). Under the stated definition, the attainable sets depend on \(T,\alpha,r\), the rule, and tie-breaking. They do not depend on the listed current society: residual distributions range over all of \(\Delta(T)\), rather than being constrained by that society's positive support or masses.

5. Relation to the discrete result

The cited [Aziz–Lam paper](https://arxiv.org/pdf/2111.01983v3) gives the stated approval algorithm and positional-scoring reduction for the discrete unweighted setting. The proof above directly settles the continuous problem specified here: residual masses are real LP variables, and the admissible reports are explicitly enumerable.

The running time is polynomial in the listed domain size \(d\). If one lists every ranking, then \(d=m!\); this proof does not assert a running time polynomial in \(m\) alone for an implicitly represented unrestricted domain.
