The continuous mirror question, as graded

Fix rational \(\alpha\in(0,1)\). Given a finite support \(T\) of agent types, rational masses \(\mu_t\geq 0\) summing to \(1\), and rational reported coefficients \(\theta_t\geq 0\), with at least one positive coefficient, choose per-capita allocations \(x_t\geq 0\) maximizing \(\sum_{t\in T}\mu_t\theta_t x_t^{1-\alpha}/(1-\alpha)\), subject to \(\sum_{t\in T}\mu_t x_t\leq 1\), and report the common unit price. The total resource supply scales with population so this constraint remains per capita.

For each fixed rational \(\alpha\in(0,1)\), is computing the optimal allocation and common unit price in this representation polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For every fixed rational \(\alpha\in(0,1)\), the optimal allocation and common unit price are polynomial-time computable in the specified exact circuit representation. Both are unique.

Write \(\alpha=p/q\), where \(p,q\) are fixed positive integers with \(p<q\). Define

\[ a_t=\sqrt[p]{\theta_t^{\,q}}, \qquad S=\sum_{t\in T}\mu_t a_t. \]

Because some \(\theta_t>0\) and all masses are positive, \(S>0\). The outputs are

\[ x_t^*=\frac{a_t}{S}, \qquad \lambda^*=\sqrt[q]{S^{\,p}}. \]

Proof of optimality and uniqueness

Let \(f_t(z)=\theta_t z^{1-\alpha}/(1-\alpha)\) for \(z\geq0\), and let \(F(x)=\sum_t\mu_t f_t(x_t)\).

The proposed allocation is nonnegative and exhausts the resource:

\[ \sum_t\mu_t x_t^*=\frac{\sum_t\mu_t a_t}{S}=1. \]

If \(\theta_t>0\), then \(x_t^*>0\). Using \(a_t=\theta_t^{1/\alpha}\), we obtain

\[ f_t'(x_t^*) =\theta_t(x_t^*)^{-\alpha} =\theta_t a_t^{-\alpha}S^\alpha =S^\alpha =\lambda^*. \]

For such a type, \(f_t'(z)=\theta_t z^{-\alpha}\) is strictly decreasing on \(z>0\). Consequently, for every \(y\geq0\),

\[ f_t(y)\leq f_t(x_t^*)+\lambda^*(y-x_t^*), \]

with equality exactly when \(y=x_t^*\). For positive \(y\), this follows by integrating the strictly decreasing derivative between \(y\) and \(x_t^*\). At \(y=0\), strictness follows explicitly from

\[ f_t(x_t^*)-\lambda^*x_t^* =\frac{\alpha}{1-\alpha}\theta_t(x_t^*)^{1-\alpha}>0. \]

If \(\theta_t=0\), then \(a_t=x_t^*=0\) and \(f_t\) is identically zero. The same inequality holds because \(\lambda^*>0\); equality occurs exactly when \(y=0=x_t^*\).

Multiplying these inequalities by the positive masses and summing gives, for every nonnegative allocation \(y\),

\[ F(y)\leq F(x^*)+\lambda^*\left(\sum_t\mu_t y_t-1\right). \]

For feasible \(y\), the parenthesized term is nonpositive, proving \(F(y)\leq F(x^*)\). If any coordinate differs from \(x^*\), its scalar inequality is strict. Thus \(x^*\) is the unique optimum.

Verification of the common dual price

Use the resource Lagrangian

\[ \mathcal L(x,\ell)=F(x)-\ell\left(\sum_t\mu_t x_t-1\right), \qquad \ell\geq0, \]

with nonnegativity retained in the domain. Define \(g(\ell)=\sup_{x\geq0}\mathcal L(x,\ell)\).

The inequality proved above implies \(\mathcal L(x,\lambda^*)\leq F(x^*)\) for every \(x\geq0\). Equality holds at \(x^*\), so \(g(\lambda^*)=F(x^*)\).

For every \(\ell\geq0\), resource exhaustion gives

\[ g(\ell)\geq\mathcal L(x^*,\ell)=F(x^*). \]

Therefore \(\lambda^*\) is an optimal resource multiplier.

It is also unique. If \(\ell\) is another optimal multiplier, then \(x^*\) attains the supremum defining \(g(\ell)\). Choose any type with \(\theta_t>0\). Since \(x_t^*>0\), differentiation in that coordinate at this maximizer yields

\[ 0=\mu_t\left(f_t'(x_t^*)-\ell\right) =\mu_t(\lambda^*-\ell). \]

Since \(\mu_t>0\), necessarily \(\ell=\lambda^*\). The common unit price is therefore precisely the stated \(\lambda^*\), and each per-capita payment is \(\lambda^*x_t^*\).

Exact circuit construction and running time

Construct the outputs directly:

  • For each type, compute \(\theta_t^q\) by multiplication and apply a nonnegative root gate of degree \(p\), obtaining \(a_t\).
  • Compute \(S=\sum_t\mu_t a_t\).
  • Output each \(x_t^*=a_t/S\). These divisions are valid because \(S>0\).
  • Compute \(S^p\) and apply a root gate of degree \(q\), obtaining \(\lambda^*\).

Integer powers can be constructed by repeated squaring. Since \(\alpha\) is fixed, both \(p\) and \(q\), and hence their binary encodings, are constants independent of the input. The circuit uses \(O(\tau)\) gates, with input constants of total bit length at most \(L\). Including binary wire indices, a shared circuit has length \(O(L+\tau\log(\tau+1))\).

If separate circuits are required for individual outputs, copying the shared computation increases the length only polynomially. Payments also require only one additional multiplication per type.

Thus the algorithm constructs valid exact outputs in polynomial time in \(\tau,L\); here \(m=1\). No expansion of the resulting algebraic numbers is required.
