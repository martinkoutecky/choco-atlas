The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), rational valuations \(v_{t,o}\) for \(m\) resource classes, and variables \(z_{t,o}\ge 0\) satisfying \(\sum_{t\in T}\mu_t z_{t,o}=1\), decide whether there exists an allocation with \(U_t(z)=\sum_o v_{t,o}z_{t,o}\) that is fractionally Pareto-optimal across positive-mass types, proportional \(\bigl(U_t(z)\ge\sum_o v_{t,o}\bigr)\) or envy-free \(\bigl(U_t(z)\ge\sum_o v_{t,o}z_{t',o}\ \text{for all }t,t'\bigr)\), and \(S(z)=\sum_o\bigl(|\{t:\mu_t>0,\ z_{t,o}>0\}|-1\bigr)=0\).

Packaged proof task (what the prover saw — nothing else)

Given finite types \(T\), positive rational masses \(\mu_t\) summing to \(1\), \(m\) unit-supply resource classes, and rational additive valuations \(v_{t,o}\), an allocation has \(z_{t,o}\geq0\) and \(\sum_t\mu_tz_{t,o}=1\) for every \(o\). Let \(U_t(z)=\sum_o v_{t,o}z_{t,o}\).
It is fractionally Pareto-optimal if no feasible \(\tilde z\) satisfies \(U_t(\tilde z)\geq U_t(z)\) for every \(t\), with a strict inequality for some \(t\). Require either proportionality \(U_t(z)\geq\sum_o v_{t,o}\) for every \(t\), or envy-freeness \(U_t(z)\geq\sum_o v_{t,o}z_{t',o}\) for all \(t,t'\). Define \(S(z)=\sum_o(|\{t:z_{t,o}>0\}|-1)\).

Is deciding whether there exists a fractionally Pareto-optimal, proportional (respectively envy-free) allocation with \(S(z)=0\) solvable in polynomial time, or NP-hard?

For discrete unit-mass agents and divisible objects, zero-sharing feasibility subject to fractional Pareto-optimality and proportionality, or envy-freeness, is NP-hard even for every fixed number of at least two agents.

Result

Both decision problems are NP-hard, even for every fixed number \(n\geq 2\) of types and equal masses \(\mu_t=1/n\).

This follows from the discrete-agent hardness statement supplied in the question: rescaling each agent’s bundle preserves fractional Pareto-optimality, the relevant fairness condition, and the sharing count.

Reduction

Fix an integer \(n\geq 2\). Consider an instance of the stated source problem with \(n\) discrete agents, \(m\) divisible unit-supply objects, and rational additive valuations \(v_{t,o}\).

Write a feasible source allocation as \(x\), where
\( x_{t,o}\geq 0 \)
and
\( \sum_{t=1}^n x_{t,o}=1 \)
for every object \(o\). Define its utilities by
\( u_t(x)=\sum_o v_{t,o}x_{t,o}. \)

Construct a target instance with the same valuations and resource classes, one type for each source agent, and masses
\( \mu_t=1/n. \)
These masses are positive rationals summing to \(1\). The construction has polynomial encoding length and takes polynomial time.

Associate to every source allocation \(x\) the target allocation
\( z_{t,o}=n x_{t,o}. \)

We verify every required property.

Feasibility and sharing

For each resource class \(o\),
\( \sum_t\mu_tz_{t,o} =\sum_t(1/n)(n x_{t,o}) =\sum_t x_{t,o} =1. \)
Thus \(z\) is feasible. Conversely, every feasible target allocation \(z\) gives a feasible source allocation \(x=z/n\). These maps are inverses, so they give a bijection between the two feasible sets.

Because \(n>0\),
\( z_{t,o}>0 \)
holds exactly when
\( x_{t,o}>0. \)
Consequently,
\( S(z)=\sum_o\bigl(|\{t:x_{t,o}>0\}|-1\bigr). \)
Feasibility ensures that every object has at least one positive recipient. Hence this sum is zero exactly when each source object has one recipient, which is precisely source zero-sharing feasibility.

Fairness

For every type \(t\), utilities satisfy
\( U_t(z)=\sum_o v_{t,o}n x_{t,o}=n u_t(x). \)

Proportionality

In the source model with \(n\) discrete agents, proportionality requires
\( u_t(x)\geq \frac{1}{n}\sum_o v_{t,o} \)
for every \(t\).

Multiplying by the positive number \(n\), this is equivalent to
\( U_t(z)\geq\sum_o v_{t,o}, \)
which is exactly target proportionality.

Envy-freeness

For every pair \(t,t'\),
\( \sum_o v_{t,o}z_{t',o} =n\sum_o v_{t,o}x_{t',o}. \)
Therefore the target inequality
\( U_t(z)\geq\sum_o v_{t,o}z_{t',o} \)
is equivalent, after division by \(n\), to
\( u_t(x)\geq\sum_o v_{t,o}x_{t',o}. \)
Thus target envy-freeness is equivalent to source envy-freeness.

Fractional Pareto-optimality

Suppose \(x\) is not fractionally Pareto-optimal. There is a feasible source allocation \(\tilde x\) such that
\( u_t(\tilde x)\geq u_t(x) \)
for all \(t\), strictly for at least one \(t\). The feasible target allocation \(\tilde z=n\tilde x\) then satisfies
\( U_t(\tilde z)=n u_t(\tilde x)\geq n u_t(x)=U_t(z), \)
with the same strict inequality. Hence \(z\) is not fractionally Pareto-optimal.

Conversely, any feasible target allocation \(\tilde z\) that Pareto-dominates \(z\) yields the feasible source allocation \(\tilde x=\tilde z/n\) that Pareto-dominates \(x\), since division by \(n>0\) preserves both weak and strict utility inequalities.

Thus \(x\) is fractionally Pareto-optimal if and only if \(z\) is. This equivalence considers all feasible competing allocations, without imposing fairness or zero sharing on those competitors, as required by the definition.

Conclusion

For either fairness requirement, the source instance admits a fractionally Pareto-optimal, fair allocation with zero sharing if and only if the constructed target instance does.

The supplied source hardness theorem therefore gives NP-hardness of both target problems. Because the reduction preserves the number of agents as the number of types, this holds for every fixed number \(n\geq 2\) of types, already with equal masses.
