The continuous mirror question, as graded

Given finite variables and domains, a lexicographic preference language, complete stakeholder types \(\Gamma_1,\ldots,\Gamma_\tau\subseteq L\), rational masses \(\mu_1,\ldots,\mu_\tau\), and \(\varepsilon,\rho\in[0,1]\cap\mathbb{Q}\), decide whether the population has a middle-ground witness: if \(U_\mu=\bigcup_{\theta:\mu_\theta>0}\Gamma_\theta\) is consistent, output \(U_\mu\); otherwise output some \(b\in\mathcal{B}=\{\mathbf{1}_v\ge\mathbf{0}_v,\mathbf{1}_v>\mathbf{0}:v\in V\}\) satisfying \(\sum_{\theta:\{\psi,b\}\text{ is consistent for every }\psi\in\Gamma_\theta}\mu_\theta\ge1-\varepsilon\) and \(\sum_{\theta:\Gamma_\theta\models_{\mathcal L}b}\mu_\theta\ge\rho\), or report NO.

Packaged proof task (what the prover saw — nothing else)

A packet Φ is a finite set of strict or non-strict comparisons α > β and α ≥ β between alternatives α,β ∈ ∏_{v∈V}D_v. A hierarchical model is a nonempty sequence π=(Y_1,…,Y_k) of nonempty subsets of V; subsets may overlap. At each level, compare ⊕_{v∈Y_i}α(v) and ⊕_{v∈Y_i}β(v), using the given total order, lexicographically by increasing i. Thus π satisfies α>β exactly when the first unequal level favors α, and satisfies α≥β also when all levels tie.

Target. Is the explicitly represented rational-distribution problem in P or NP-hard: given {(Φ_θ,μ_θ)}_{θ∈Θ}, does there exist π satisfying every Φ_θ with μ_θ>0, equivalently with μ_θ-weighted satisfied mass \(1\)?

For the discrete problem of deciding whether one finite set of such preference statements has a satisfying hierarchical model, NP-completeness is known when ⊕ is polynomial-time computable.

Complexity Classification

Theorem

Under the stated assumption that the single-packet satisfiability problem is \(\mathrm{NP\text{-}complete}\), the explicitly represented rational-distribution problem is also \(\mathrm{NP\text{-}complete}\). In particular, it is \(\mathrm{NP\text{-}hard}\) and is not polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).

Proof

Let the input be a finite rational distribution

\[ \mathcal D=\{(\Phi_\theta,\mu_\theta):\theta\in\Theta\}, \]

where every \(\mu_\theta\) is nonnegative and

\[ \sum_{\theta\in\Theta}\mu_\theta=1. \]

For a hierarchical model \(\pi\), define its satisfied mass by

\[ M_{\mathcal D}(\pi) = \sum_{\theta\in\Theta} \mu_\theta\mathbf 1[\pi\text{ satisfies }\Phi_\theta]. \]

Lemma 1: Characterization of mass \(1\)

A hierarchical model \(\pi\) has \(M_{\mathcal D}(\pi)=1\) if and only if it satisfies every \(\Phi_\theta\) with \(\mu_\theta>0\).

Indeed, if all positive-mass packets are satisfied, every summand with positive coefficient contributes its full weight, while zero-mass packets contribute nothing. Hence

\[ M_{\mathcal D}(\pi)=\sum_{\theta\in\Theta}\mu_\theta=1. \]

Conversely, suppose \(\pi\) fails some packet \(\Phi_{\theta_0}\) with \(\mu_{\theta_0}>0\). Then

\[ M_{\mathcal D}(\pi) \leq \sum_{\theta\neq\theta_0}\mu_\theta = 1-\mu_{\theta_0} <1. \]

This proves the lemma.

Lemma 2: Reduction to one packet

Construct the finite set of comparisons

\[ \Phi^+ = \bigcup_{\theta:\,\mu_\theta>0}\Phi_\theta. \]

For every hierarchical model \(\pi\),

\[ \pi\text{ satisfies }\Phi^+ \quad\Longleftrightarrow\quad \pi\text{ satisfies every }\Phi_\theta\text{ with }\mu_\theta>0. \]

This follows directly from the meaning of satisfaction of a finite set: \(\pi\) satisfies a set of comparisons exactly when it satisfies each comparison in that set.

The construction is polynomial-time. Testing whether an explicitly encoded rational number is positive is polynomial-time, and

\[ |\Phi^+| \leq \sum_{\theta\in\Theta}|\Phi_\theta|. \]

Thus the distribution problem reduces in polynomial time to the known single-packet satisfiability problem. Since that problem belongs to \(\mathrm{NP}\), the distribution problem belongs to \(\mathrm{NP}\).

Lemma 3: Hardness

Conversely, let \(\Phi\) be an arbitrary instance of the known single-packet satisfiability problem. Construct the distribution with one support point:

\[ \Theta=\{\theta^\ast\}, \qquad \Phi_{\theta^\ast}=\Phi, \qquad \mu_{\theta^\ast}=1. \]

A hierarchical model has satisfied mass \(1\) for this distribution if and only if it satisfies \(\Phi\). The construction is plainly polynomial-time. Therefore the single-packet problem reduces to the distribution problem, proving \(\mathrm{NP\text{-}hardness}\).

Conclusion

The two problems are polynomial-time many-one equivalent. Consequently, the explicit rational weights introduce no additional computational difficulty at the mass-\(1\) threshold: they merely determine which packets have positive support. The distribution problem is \(\mathrm{NP\text{-}complete}\).
