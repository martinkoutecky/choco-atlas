The continuous mirror question, as graded

Given finite encoded support points \(p_1,\ldots,p_\tau\in\mathbb{R}^2\), binary-rational masses \(\mu_i>0\) summing to \(1\), a finite encoded candidate-site set \(M\subset\mathbb{R}^2\), and \(k\le |M|\), does there exist \(X\subseteq M\) with \(|X|=k\) such that for every \(y\in M\), \(\sum_{i:\,\|p_i-y\|_2<d(p_i,X)}\mu_i<1/k\), where \(d(p_i,X)=\min_{x\in X}\|p_i-x\|_2\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: distinct points \(p_1,\ldots,p_\tau\in\mathbb{Q}^2\) with positive binary-rational masses \(\mu_i\) satisfying \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a nonempty candidate-site set \(M\subset\mathbb{Q}^2\), with \(m=|M|\), and an integer \(1\le k\le m\). Coordinates are binary rationals; \(L\) is the total input bit length.
For \(X\subseteq M\) with \(|X|=k\), define \(d(p_i,X)=\min_{x\in X}\|p_i-x\|_2\). Call \(X\) proportionally fair if \(\sum_{i:\,\|p_i-y\|_2<d(p_i,X)}\mu_i<1/k\) for every \(y\in M\).
Distance ties do not count as improvements; improving mass exactly \(1/k\) blocks. Centers and deviations must both belong to \(M\).

Is deciding whether a proportionally fair \(X\) exists solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,k,L\).

For finite equally weighted populations and finite candidate sites in the Euclidean plane, existence of an exactly proportionally fair clustering is NP-hard. [Micha–Shah](https://www.cs.toronto.edu/~nisarg/papers/fair_clustering.pdf)
Distributional existence and sampling results are known for unrestricted center locations with improving mass bounded by \(1/k\) inclusively; these use a different site domain and quota boundary. [Mandal–Shah–Yu](https://www.cs.toronto.edu/~nisarg/papers/fair-clustering-distributions.pdf)

Modeling choices made when packaging the task

  • Resolved unspecified finite coordinate encoding by requiring binary-rational coordinates for support points and candidate sites, and defined L as total input bit length.
  • Made the budget positive: 1 ≤ k ≤ |M|, excluding the undefined quota and nearest-center distance at k = 0.
  • Represented support by distinct locations, aggregating any repeated location into one type.

Result

The decision problem is \(\mathrm{NP}\)-complete. This holds even with distinct support points, integer coordinates, and equal dyadic masses.

An exact algorithm takes
\[ O\!\left(\binom{m}{k}\tau(m+k)L^2\right) \]
bit operations using schoolbook arithmetic. Thus the problem is polynomial-time solvable for each fixed \(k\), but a polynomial-time algorithm for unrestricted inputs would imply \(\mathrm{P}=\mathrm{NP}\).

The cases \(k=1\) and \(k=m\) always admit a fair solution. For \(k=1\), choose a site minimizing the mass-weighted sum of squared distances: a blocking site would strictly improve every support point and therefore reduce this sum. For \(k=m\), choose all sites.

1. Exact verification and membership in \(\mathrm{NP}\)

Write \(M=\{y_1,\ldots,y_m\}\), and define the rational squared distances
\[ q_{ij}=\|p_i-y_j\|_2^2. \]
For a proposed \(k\)-element set \(X\), compute
\[ r_i=\min_{y_j\in X}q_{ij}. \]
Squaring preserves the order of nonnegative distances. Consequently, the improving mass at \(y_j\) is exactly
\[ b_j=\sum_{i:q_{ij}<r_i}\mu_i, \]
and \(X\) is fair precisely when \(kb_j<1\) for every \(j\). Both strict distance comparisons and the quota boundary are therefore checked exactly.

For completeness, suppose \(\mu_i=a_i/b_i\), with positive integer denominators. Set \(D=\prod_i b_i\) and \(w_i=a_i(D/b_i)\). Then
\[ b_j=\frac{1}{D}\sum_{i:q_{ij}<r_i}w_i, \]
so the quota test is the integer comparison
\[ k\sum_{i:q_{ij}<r_i}w_i<D. \]
The bit lengths of \(D\), the weights, and their sums are \(O(L)\). Squared distances and the cross-products needed to compare them also have \(O(L)\) bits.

Computing and checking all these quantities takes
\[ O\!\left(\tau(m+k)L^2\right) \]
bit operations. A certificate consists of the indices of the selected sites and has polynomial length. Hence the problem belongs to \(\mathrm{NP}\).

2. The finite-population hardness theorem applies

The known result used here is Theorem 10 of [Micha–Shah, *Proportionally Fair Clustering Revisited*](https://www.cs.toronto.edu/~nisarg/papers/fair_clustering.pdf): existence is \(\mathrm{NP}\)-hard for equally weighted finite populations and finite candidate sets in the Euclidean plane. Their definition forbids a coalition of cardinality at least \(n/k\) whose members all strictly improve. Their reduction uses \(n=2k\).

Thus its quota boundary agrees exactly with the present problem: two improving voters block when \(n=2k\).

There is one encoding issue to address. The published construction uses an equilateral auxiliary triangle. The following modification gives rational coordinates without changing the auxiliary gadget’s required behavior.

Rational realization of the auxiliary gadget

Use three voters
\[ h_1=(0,0),\qquad h_2=(1,0),\qquad h_3=(1/2,7/8) \]
and three candidate sites
\[ f_1=(1/4,0),\qquad f_2=(7/8,7/32),\qquad f_3=(3/8,21/32). \]
Their squared-distance matrix, multiplied by \(1024\), is
\[ \begin{pmatrix} 64&833&585\\ 576&65&841\\ 848&585&65 \end{pmatrix}. \]
Therefore their strict preferences are
\[ h_1:\ f_1<f_3<f_2,\qquad h_2:\ f_2<f_1<f_3,\qquad h_3:\ f_3<f_2<f_1, \]
where the order denotes increasing distance.

With only \(f_1\) selected, \(h_2,h_3\) improve at \(f_2\). With only \(f_2\), \(h_1,h_3\) improve at \(f_3\). With only \(f_3\), \(h_1,h_2\) improve at \(f_1\). With no local site selected, placing the gadget sufficiently far from other sites makes all three voters improve at a local site.

Conversely, any two local sites are fair within this gadget: each selected site is one voter’s favorite, and the unselected site improves only its corresponding voter. Thus this rational gadget requires exactly two centers, as required by the reduction.

The remaining construction uses axis-aligned chains with an inverse-polynomial perturbation parameter and circumcenters of noncollinear triangles. Choosing that parameter rational gives polynomial-bit rational chain coordinates. A circumcenter \(z\) of rational points \(a,b,c\) satisfies
\[ 2(b-a)\mathbin{\cdot}z=\|b\|_2^2-\|a\|_2^2,\qquad 2(c-a)\mathbin{\cdot}z=\|c\|_2^2-\|a\|_2^2. \]
Noncollinearity makes this system nonsingular, so its solution is rational with polynomial bit length. The auxiliary gadgets can be translated to rational locations sufficiently far apart. These observations provide a polynomial-bit rational realization of the cited reduction. [Micha–Shah, Appendix C](https://www.cs.toronto.edu/~nisarg/papers/fair_clustering.pdf)

Finally, multiply every coordinate by the product of all coordinate denominators. This product has polynomial bit length. The resulting coordinates are integers, and uniform scaling preserves every distance comparison, including ties.

We therefore have hardness instances with integer coordinates, distinct voters, and \(n=2k\).

3. Reduction to a support with equal dyadic masses

This step also handles the stricter interpretation of “binary rational” as a dyadic rational.

Take an integer-coordinate hardness instance with \(n=2k\). Let \(N\) be the smallest power of two satisfying \(N\ge n\), and put
\[ r=(N-n)/2,\qquad K=k+r=N/2. \]
Add \(r\) isolated pairs of voters. Each pair consists of two integer points at distance \(1\), both also candidate sites.

Choose an integer \(B>1\) larger than the diameter of the original voters and sites. Place the added pairs so that distances between different components exceed \(B\). Such locations have polynomial bit length: if all original coordinates have absolute value at most \(C\), take \(B=4C+4\) and place pair \(j\) at
\[ ((j+1)(4B+4),0),\qquad ((j+1)(4B+4)+1,0). \]

Give every voter mass \(1/N\). The new quota is
\[ 1/K=2/N, \]
so exactly two or more improving voters block. All masses are positive dyadic rationals, sum to one, and occur at distinct support points.

We prove equivalence.

Forward direction. Suppose the original instance has a fair \(k\)-element set \(X\). Select \(X\) and one site from each added pair, giving exactly \(K\) sites.

Original voters receive their distances from \(X\), since every added site is farther than \(B\). An original deviation improves at most one original voter and no added voter. A deviation into an added pair improves at most its unselected voter: every other component already has a selected site closer than that deviation. Hence the enlarged solution is fair.

Reverse direction. Suppose the enlarged instance has a fair \(K\)-element set \(X'\). Each added pair must contain a selected site. Otherwise both its voters improve at either local site and block.

Let \(Z\) be the selected original sites. Consequently, \(|Z|\le K-r=k\). Moreover, \(Z\) is nonempty: if all selected sites were in added pairs, every original voter would improve at any original candidate site, producing at least two improvements.

Because \(Z\) is nonempty, every original voter’s nearest selected site belongs to \(Z\): original distances are less than \(B\), and added sites are farther than \(B\). Thus an original site improving two original voters relative to \(Z\) would also block \(X'\). No such site exists.

Pad \(Z\) to exactly \(k\) original sites. Adding sites only decreases voters’ current distances, so it cannot create a new improvement. The padded set is an original fair solution.

The transformation has polynomial size: \(N<2n\), and fewer than \(n/2\) pairs are added. It preserves the finite site domain, strict distance improvements, and blocking at equality. This proves \(\mathrm{NP}\)-hardness under the stated restrictions.

Together with Section 1, it proves \(\mathrm{NP}\)-completeness.

4. Exact running times and the support parameter

Enumerating all \(k\)-element subsets and applying the verifier gives the bound
\[ O\!\left(\binom{m}{k}\tau(m+k)L^2\right). \]
In particular, this is
\[ O\!\left(m^k\tau(m+k)L^2\right) \]
for fixed \(k\).

There is also a polynomial algorithm for each fixed support size \(\tau\). If \(X\) is fair, choose one nearest selected site for each support point and let \(S\) be their union. Then
\[ 1\le |S|\le\min(k,\tau),\qquad d(p_i,S)=d(p_i,X) \]
for every \(i\). Thus \(S\) passes the same improvement tests with quota \(1/k\). Conversely, any such \(S\) passing those tests can be padded to \(k\) sites, preserving fairness.

Enumerating these smaller subsets therefore takes
\[ O\!\left( L^2\tau \sum_{j=1}^{\min(k,\tau)} \binom{m}{j}(m+j) \right). \]
This uses the actual support size \(\tau\); it does not expand rational masses into a population whose cardinality could be exponentially large.
