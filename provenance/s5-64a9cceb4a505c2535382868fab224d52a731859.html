The continuous mirror question, as graded

Given a finite bipartite type graph \(H=(A\cup B,E)\), positive rational masses \(\mu_t\) summing to \(1\), integer per-member capacities \(b_t\), nonnegative rational edge values \(w_{uv}\), and nonnegative per-type shares \(q_t\) satisfying \(\sum_t\mu_tq_t=V(\mu)\), decide whether \(q\) is in the core. For every coalition mass vector \(0\le z\le\mu\), define \(V(z)=\max \sum_{(u,v)\in E}w_{uv}x_{uv}\), over \(x\ge0\) with \(\sum_vx_{uv}\le b_uz_u\) and \(\sum_ux_{uv}\le b_vz_v\); the question is whether \(\sum_tz_tq_t\ge V(z)\) for every such \(z\).

Result and characterization

The problem is in \(\mathrm P\). Under the stated efficiency promise, core membership is equivalent to the following \(\,m\,\) inequalities:
\[ \frac{q_u}{b_u}+\frac{q_v}{b_v}\ge w_{uv} \qquad\text{for every }(u,v)\in E. \]
Checking them exactly takes \(\mathrm O((m+\tau)L^2)\) bit operations using schoolbook integer arithmetic.

The key is that continuous coalitions can choose endpoint masses that supply exactly the same amount of capacity.

Proof of necessity

Assume that \(\,q\,\) belongs to the core. Fix an edge \(\,(u,v)\in E\,\), and set
\[ h=\min\{b_u\mu_u,b_v\mu_v\}. \]
Both supported masses and both capacities are positive, so \(\,h>0\,\).

Define a coalition by
\[ z_u=\frac{h}{b_u},\qquad z_v=\frac{h}{b_v}, \qquad z_t=0\quad(t\notin\{u,v\}). \]
The definition of \(\,h\,\) gives \(\,0\le z\le\mu\,\). Assigning \(\,x_{uv}=h\,\) and zero to every other edge is feasible: its load at each endpoint is exactly that endpoint’s coalition capacity. Consequently,
\[ V(z)\ge h w_{uv}. \]
Core membership therefore implies
\[ h\left(\frac{q_u}{b_u}+\frac{q_v}{b_v}\right) =\sum_t z_tq_t \ge V(z) \ge h w_{uv}. \]
Division by the positive number \(\,h\,\) proves the required edge inequality.

In particular, every failed edge inequality supplies an explicit blocking coalition of the form above.

Proof of sufficiency

Assume that every edge inequality holds. Define \(\,p_t=q_t/b_t\,\); then \(\,p_t\ge0\,\).

Fix any real coalition \(\,0\le z\le\mu\,\) and any feasible edge-flow vector \(\,x\,\) for that coalition. For each type \(\,t\,\), let \(\,\ell_t(x)\,\) be the sum of flows on its incident edges. Feasibility gives \(\,\ell_t(x)\le b_tz_t\,\).

Using the edge inequalities, regrouping the finite sum by endpoints, and then using \(\,p_t\ge0\,\), we obtain
\[ \sum_{(u,v)\in E}w_{uv}x_{uv} \le \sum_{(u,v)\in E}(p_u+p_v)x_{uv} = \sum_t p_t\ell_t(x) \le \sum_t p_tb_tz_t = \sum_t q_tz_t. \]
This bounds the objective of every feasible flow. Maximizing over those flows yields \(\,V(z)\le\sum_tq_tz_t\,\), as required.

The necessity and sufficiency arguments establish the characterization. They actually characterize coalition domination without using efficiency; the promised equality \(\,\sum_t\mu_tq_t=V(\mu)\,\) makes these dominating shares core allocations.

Exact algorithm and bit complexity

Read the input and check the edge inequalities one by one. Accept precisely when all pass. No optimization problem needs to be solved under the efficiency promise.

For an explicit integer comparison, write \(\,q_t=N_t/D_t\,\) and \(\,w_{uv}=R_{uv}/S_{uv}\,\), with positive denominators. The inequality for \(\,(u,v)\,\) is equivalent to
\[ N_uD_vb_vS_{uv}+N_vD_ub_uS_{uv} \ge R_{uv}D_ub_uD_vb_v. \]
Clearing denominators preserves the inequality because every denominator and capacity is positive.

Each side involves a constant number of products and additions of input integers. All intermediate integers have \(\,\mathrm O(L)\,\) bits, so each edge comparison costs \(\,\mathrm O(L^2)\,\) bit operations with schoolbook multiplication. Including input processing gives the stated bound \(\,\mathrm O((m+\tau)L^2)\,\). This bound has no dependence on the numerical magnitudes of capacities or inverse masses beyond their encoded lengths.

Why the finite-agent hardness does not transfer

The [cited paper](https://arxiv.org/html/2502.01914v1) studies coalitions that are subsets of indivisible vertex agents and proves \(\,\mathrm{coNP}\)-completeness for its edge-unconstrained model. Such coalitions cannot generally balance endpoint capacities by selecting fractions of agents.

For example, consider two finite agents joined by an edge of value \(\,1\,\), with capacities \(\,2\,\) and \(\,1\,\). Their grand-coalition value is \(\,1\,\), and the allocation \(\,(1,0)\,\) is in their finite core: both singleton values are zero.

For the corresponding continuous instance, take \(\,\mu_u=\mu_v=1/2\,\), capacities \(\,b_u=2\,\), \(\,b_v=1\,\), and shares \(\,q_u=1\,\), \(\,q_v=0\,\). Efficiency holds because \(\,V(\mu)=1/2=\sum_t\mu_tq_t\,\). But the coalition \(\,z_u=1/4\,\), \(\,z_v=1/2\,\) has value \(\,1/2\,\) and receives only \(\,1/4\,\). Continuous coalition selection imposes the stronger edge conditions proved above.
