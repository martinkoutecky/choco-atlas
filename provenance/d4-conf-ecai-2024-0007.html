The continuous mirror question, as graded

Given a finite shared slate \(A\subseteq\mathbb{Q}^p\), rational comparison records \(\Lambda_t\subseteq\mathbb{Q}^p\) for each supported type \(t\), and rational masses \(\mu_t\ge 0\) summing to \(1\), find an alternative \(a\in A\) minimizing \(\sum_t\mu_t\,\mathrm{MRR}^{D_1}_A(a;V_{\Lambda_t})\), and return the exact minimum and all minimizing alternatives. Here \(V_{\Lambda_t}=\{w\in\mathbb{R}^p_{\ge0}:w\cdot\lambda\ge0\text{ for every }\lambda\in\Lambda_t\}\), and \(D^1_A(w)=\operatorname{Val}_A(w)-\operatorname{Wor}_A(w)\).

Packaged proof task (what the prover saw — nothing else)

Given an explicitly listed nonempty shared slate \(A\subseteq\mathbb{Q}^p\), let \(m=|A|\) and \(p\ge1\); objective coordinates may have either sign, and higher utility is better.
A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies an explicitly listed finite set \(\Lambda_t\subseteq\mathbb{Q}^p\) of weak comparison constraints, defining \(V_{\Lambda_t}=\{w\in\mathbb{R}_{\ge0}^p:w\cdot\lambda\ge0\text{ for every }\lambda\in\Lambda_t\}\). Records need not compare alternatives from \(A\); empty records and cones consisting only of zero are allowed. Weights are not normalized.
Define \(\operatorname{Val}_A(w)=\max_{b\in A}w\cdot b\), \(\operatorname{Wor}_A(w)=\min_{b\in A}w\cdot b\), and \(D_A^1(w)=\operatorname{Val}_A(w)-\operatorname{Wor}_A(w)\).
For \(a\in A\), define \(r_A(a,w)=(\operatorname{Val}_A(w)-w\cdot a)/D_A^1(w)\) when \(D_A^1(w)>0\), and \(r_A(a,w)=0\) otherwise; define \(\mathrm{MRR}^{D_1}_A(a;V)=\sup_{w\in V}r_A(a,w)\).
The computational problem is to return the exact minimum of \(F(a)=\sum_{t=1}^{\tau}\mu_t\mathrm{MRR}^{D_1}_A(a;V_{\Lambda_t})\) over \(a\in A\), together with every minimizing alternative. Let \(q=\sum_t|\Lambda_t|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,p,q,L\).

Is this exact mass-weighted minimization problem solvable in polynomial time in \(m,\tau,p,q,L\), or is it NP-hard?

For a single type and an explicitly listed finite slate, all alternatives' maximum range-relative regrets can be computed in polynomial time using linear programming. [Source](https://doi.org/10.3233/FAIA240884)

Result

The problem is solvable exactly in polynomial time in \(m,\tau,p,q,L\). An algorithm uses at most \(\tau m^2\) rational linear programs, followed by exact rational arithmetic to return the minimum and every minimizing alternative.

For \(m=1\), every regret is zero. The argument below also covers this case, empty records, and cones consisting only of zero.

1. Linear programs for each type

Write \(V_t=V_{\Lambda_t}\). Since its defining inequalities are homogeneous, \(w\in V_t\) implies \(cw\in V_t\) for every \(c\ge 0\).

For each type \(t\) and each pair \(a,b\in A\), define the linear program

\( \displaystyle \begin{aligned} v_{t,a,b}=\max_w\quad &(b-a)\cdot w\\ \text{subject to}\quad &w_j\ge 0 &&(j=1,\ldots,p),\\ &\lambda\cdot w\ge 0 &&(\lambda\in\Lambda_t),\\ &0\le (b-d)\cdot w\le 1 &&(d\in A\setminus\{b\}). \end{aligned} \)

The final constraints require that \(b\) maximize utility and that the utility range be at most one.

Every such LP is feasible because \(w=0\) satisfies all constraints. Taking \(d=a\) shows that its objective lies between zero and one when \(a\ne b\); when \(a=b\), the objective is identically zero. Thus every LP has a finite optimum.

We use the standard theorem that a rational LP can be solved exactly in polynomial bit time, including when the feasible region is unbounded or has empty interior, provided its objective has a finite optimum. Polynomial-time LP algorithms and polynomial-size rational solutions are discussed in the [MIT algorithm notes](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html) and [rational-output bounds](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/908fe54d659623efadda2d033b895caf_notes_lp.pdf).

2. Proof that the LPs compute the required regret

Claim. For every \(t\) and \(a\in A\),

\( \displaystyle \mathrm{MRR}^{D_1}_A(a;V_t)=\max_{b\in A}v_{t,a,b}. \)

Proof. Denote the left-hand side by \(M_t(a)\). Because \(a\in A\), the regret numerator lies between zero and the utility range whenever that range is positive. Together with the definition at zero range, this gives \(0\le r_A(a,w)\le 1\).

First fix \(b\in A\) and a feasible vector \(w\) for its LP. The constraints imply that \(b\) maximizes utility, so

\( \displaystyle D_A^1(w)=\max_{d\in A}(b-d)\cdot w\le 1. \)

If \(D_A^1(w)=0\), all alternatives have equal utility and \((b-a)\cdot w=0\le M_t(a)\).

If \(D_A^1(w)>0\), then

\( \displaystyle (b-a)\cdot w =D_A^1(w)\,r_A(a,w) \le r_A(a,w) \le M_t(a). \)

Here the first inequality uses both \(D_A^1(w)\le 1\) and \(r_A(a,w)\ge 0\); the last uses \(w\in V_t\). Consequently, \(v_{t,a,b}\le M_t(a)\), and therefore

\( \displaystyle \max_{b\in A}v_{t,a,b}\le M_t(a). \)

For the reverse inequality, take any \(w\in V_t\) with \(D_A^1(w)>0\). Because \(A\) is finite and nonempty, choose \(b\in A\) maximizing \(w\cdot b\). Put

\( \displaystyle \widehat w=\frac{w}{D_A^1(w)}. \)

Homogeneity gives \(\widehat w\in V_t\). For each \(d\in A\), maximality of \(b\) and the definition of the range give

\( \displaystyle 0\le(b-d)\cdot w\le D_A^1(w). \)

After division, these are exactly the LP’s range constraints. Thus \(\widehat w\) is feasible and

\( \displaystyle r_A(a,w) =\frac{(b-a)\cdot w}{D_A^1(w)} =(b-a)\cdot\widehat w \le v_{t,a,b} \le\max_{c\in A}v_{t,a,c}. \)

For weights with zero range, the regret is zero, whereas every LP optimum is nonnegative. Hence the same upper bound holds for all \(w\in V_t\). Taking the supremum proves the reverse inequality and the claim. \(\square\)

This proof uses no sign restriction on the alternatives’ coordinates. It also treats zero-range weights directly, without imposing a normalization on them.

3. Exact mass-weighted minimization

The algorithm is:

  • Solve all LPs and compute \(R_t(a)=\max_{b\in A}v_{t,a,b}\).
  • For every \(a\in A\), compute the rational number \(F(a)=\sum_{t=1}^{\tau}\mu_tR_t(a)\) exactly.
  • Compute \(F_{\min}=\min_{a\in A}F(a)\) and return it together with \(\{a\in A:F(a)=F_{\min}\}\).

Section 2 proves that these are precisely the required scores.

Every LP optimum is rational with polynomial encoding length. Multiplication by a rational mass preserves polynomial encoding length. Summing \(\tau\) rational terms also does: a common denominator can be chosen as the product of their denominators, whose bit length is the sum of their bit lengths. The corresponding numerator has polynomial bit length as well.

Thus scores and ties can be compared exactly by cross-multiplication of integers of polynomial bit length. Enumerating every minimizing alternative requires at most \(m\) output entries.

4. Running time

Let \(q_t=|\Lambda_t|\), so \(\sum_tq_t=q\). Each LP has:

  • \(p\) variables;
  • \(p+q_t+2(m-1)\) inequalities;
  • rational coefficients obtained from input coordinates and their differences.

Every coefficient has bit length \(O(L+1)\). A conservative bound on the total encoding length of one LP is

\( \displaystyle B_t=O\!\left((p+1)(p+q_t+m+1)(L+1)\right). \)

Let \(T_{\mathrm{LP}}(n,k,B)\) be a polynomial bit-time bound for exact rational LP with \(n\) variables, \(k\) inequalities, and encoding length \(B\). The total running time is

\( \displaystyle O\!\left( m^2\sum_{t=1}^{\tau} T_{\mathrm{LP}}\!\left(p,p+q_t+2(m-1),B_t\right) \right) +\operatorname{poly}(m,\tau,p,q,L), \)

where the additional polynomial covers LP construction, rational aggregation, and exact comparisons. In particular, this is

\( \displaystyle O\!\left(\tau m^2\,\operatorname{poly}(p+q+m+L)\right) \)

bit operations, after enlarging the fixed polynomial to include postprocessing.

The explicitly listed support permits processing each type separately, and the explicitly listed slate permits comparing all candidate scores. These two facts establish polynomial-time solvability of the exact mass-weighted problem.
