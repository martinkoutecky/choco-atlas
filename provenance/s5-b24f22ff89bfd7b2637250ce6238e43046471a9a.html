Theorem 2 — class: algorithmic

The continuous mirror question, as graded

Given applicant types \(t\in[\tau]\) with masses \(\mu_t\), scores \(v_t\), fits \(e_{it}\), acceptance probabilities \(p_t\), uncertainty levels \(\delta_t\), remaining quota per capita \(r_k\), and parameters \(\gamma_i,\eta_{i,k}\), choose the approached fraction \(x_t\in[0,1]\) of each type to minimize \(\sum_t \mu_t x_t(v_t+e_{it})(\eta_{i,k}\delta_t-p_t)+\gamma_i\max\{\sum_t\mu_t x_t p_t-r_k,0\}\). Return an optimal \(x\) and its objective value.

Packaged proof task (what the prover saw — nothing else)

Fix an agent \(i\in\{1,\ldots,m\}\) and a stage \(k\in\{1,\ldots,K\}\). Only applicants still available and never previously approached by this agent are represented.
A society is given by its support: the list of the \(\tau\geq1\) types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_t\mu_t=1\) using the original applicant population; unavailable mass may be represented separately and cannot be approached.
Each eligible type has score \(v_t\in[0,1]\), fit \(e_{it}\in[0,1]\), acceptance probability \(p_t\in(0,1]\) at the fixed state, and uncertainty \(\delta_t\in(0,1/2]\), meaning half the range of its acceptance probability over states. Types with equal scores have equal \(p_t\) and \(\delta_t\).
All numerical inputs are binary rationals, with total encoding length \(L\). The remaining quota per original applicant is \(r_k\in(0,1]\); the marginal over-quota penalty satisfies \(\gamma_i>\max_t(v_t+e_{it})\). Take \(\eta_{i,k}>0\) when \(k<K\), and \(\eta_{i,K}=0\).
An action approaches any fraction \(x_t\in[0,1]\) of each eligible type; there is no hard quota constraint. Define \(F(x)=\sum_t\mu_tx_t(v_t+e_{it})(\eta_{i,k}\delta_t-p_t)+\gamma_i\max\{\sum_t\mu_tx_tp_t-r_k,0\}\), with sums over eligible types, and \(F^\star=\min_x F(x)\).

Can the continuous society attain the additive approximation guarantee \(F(x)\leq F^\star+0\), returning such an action and its value in time polynomial in \(m,\tau,K,L\), or is attaining this guarantee NP-hard?

For finite applicants, a greedy strategy has a proved nonnegative additive loss bound; the bound is also claimed to vanish for a continuum when acceptance probabilities are continuous in score. This continuum claim does not establish computational complexity for the rational support representation specified here. Result

The exact additive guarantee is attainable in polynomial time. An optimal action and its exact rational value can be computed using \(O(\tau\log(\tau+1))\) rational arithmetic operations, with polynomially bounded bit lengths.

The argument uses the ability to approach fractions of types. No continuity assumption on acceptance probabilities as functions of score is needed.

1. Rewrite the objective

Fix the given agent and stage, and abbreviate \(r=r_k\), \(\eta=\eta_{i,k}\), and \(\gamma=\gamma_i\). Let \(E\) be the eligible types, with \(n=|E|\leq\tau\). Unavailable mass contributes no decision variable; eligible masses retain their normalization relative to the original population.

For each \(t\in E\), define

\(u_t=v_t+e_{it},\qquad a_t=\mu_tp_t,\qquad \rho_t=u_t\left(1-\frac{\eta\delta_t}{p_t}\right).\)

Since \(\mu_t>0\) and \(p_t>0\), we have \(a_t>0\). Introduce \(z_t=a_tx_t\). Thus \(z_t\) is the expected acceptance mass contributed by type \(t\), and the admissible interval becomes \(0\leq z_t\leq a_t\). Conversely, every such \(z_t\) determines an admissible fraction \(x_t=z_t/a_t\).

The objective becomes

\(F(x)=-\sum_{t\in E}\rho_tz_t+\gamma\max\left\{\sum_{t\in E}z_t-r,0\right\}.\)

Because \(\eta\geq0\), \(\delta_t>0\), and \(u_t\geq0\),

\(\rho_t\leq u_t<\gamma.\)

This strict inequality is the key consequence of the penalty hypothesis.

2. Every optimum stays within the expected quota

Lemma. If an admissible action has total expected acceptance mass \(S=\sum_{t\in E}z_t>r\), another admissible action has strictly smaller objective value.

Proof. Set \(\widehat z_t=(r/S)z_t\). Since \(0<r/S<1\), all bounds \(0\leq\widehat z_t\leq a_t\) hold, and \(\sum_t\widehat z_t=r\). Hence

\(F(z)-F(\widehat z)=\left(1-\frac rS\right)\left(\gamma S-\sum_t\rho_tz_t\right)=\left(1-\frac rS\right)\sum_t(\gamma-\rho_t)z_t>0.\)

The last inequality follows because every \(\gamma-\rho_t\) is positive and \(S>0\), so at least one \(z_t\) is positive. Here \(F(z)\) denotes the rewritten objective. This proves the lemma.

The original objective is continuous on the compact box of admissible fractions, so a minimum exists. The lemma shows that every minimizer satisfies \(\sum_tz_t\leq r\). Consequently,

\(F^\star=-\max\left\{\sum_{t\in E}\rho_tz_t:\ 0\leq z_t\leq a_t,\ \sum_{t\in E}z_t\leq r\right\}.\)

This is a fractional knapsack problem with optional unused capacity.

3. Exact algorithm

Initialize every \(z_t^\star=0\) and the remaining capacity \(R=r\).

  • Keep only types with \(\rho_t>0\).
  • Sort these types in nonincreasing order of \(\rho_t\), breaking ties arbitrarily.
  • In that order, assign \(z_t^\star=\min\{a_t,R\}\), replace \(R\) by \(R-z_t^\star\), and stop if \(R=0\).
  • Return \(x_t^\star=z_t^\star/a_t\) and the exact value \(F(x^\star)=-\sum_t\rho_tz_t^\star\).

If no eligible type has positive \(\rho_t\), this returns the zero action with value zero. At most one type receives a fraction strictly between zero and one.

4. Proof of greedy optimality

Let \(A=\sum_{\rho_t>0}a_t\). We prove that the algorithm maximizes \(\sum_t\rho_tz_t\) over the quota-feasible box.

If \(A\leq r\), the algorithm fills every positive-\(\rho_t\) type and leaves every nonpositive-\(\rho_t\) type empty. Set \(\lambda=0\).

If \(A>r\), let \(h\) be the first type whose inclusion reaches the quota in the sorted list, and set \(\lambda=\rho_h>0\). The algorithm then satisfies

\(\sum_tz_t^\star=r,\qquad z_t^\star=a_t\ \text{whenever }\rho_t>\lambda,\qquad z_t^\star=0\ \text{whenever }\rho_t<\lambda.\)

The same two coordinate conditions hold in the first case with \(\lambda=0\).

Now consider any feasible \(z\). For each type,

\((\rho_t-\lambda)(z_t-z_t^\star)\leq0.\)

Indeed, if \(\rho_t>\lambda\), then \(z_t^\star=a_t\) and \(z_t\leq a_t\). If \(\rho_t<\lambda\), then \(z_t^\star=0\) and \(z_t\geq0\). If equality holds, the product is zero.

Therefore,

\(\sum_t\rho_t(z_t-z_t^\star)=\sum_t(\rho_t-\lambda)(z_t-z_t^\star)+\lambda\left(\sum_tz_t-\sum_tz_t^\star\right)\leq0.\)

For \(\lambda=0\), the last term vanishes. For \(\lambda>0\), it is nonpositive because \(\sum_tz_t\leq r=\sum_tz_t^\star\).

Thus \(z^\star\) maximizes the reduced objective. Together with the preceding lemma, this proves global optimality for the original problem:

\(F(x^\star)=F^\star.\)

5. Exact bit complexity

Represent output rationals by binary-encoded integer numerators and positive denominators.

Each \(a_t\) and \(\rho_t\) requires only a fixed number of rational arithmetic operations on inputs of total encoding length \(L\), so each has \(O(L)\) bits. Signs and ordering comparisons are exact: rational comparisons reduce to integer cross multiplication.

Sorting takes \(O(n\log(n+1))\) comparisons. During allocation, every remaining capacity is \(r\) minus a prefix sum of the \(a_t\). A sum of at most \(n+1\) rationals of \(O(L)\) bits has polynomial encoding length: taking the product of their denominators gives a denominator with \(O(nL)\) bits, and the numerator also has polynomially many bits. Reducing fractions cannot increase these bounds.

The possible partial fraction \(R/a_t\), and the returned objective value, therefore also have polynomial encoding lengths. All required integer arithmetic has polynomial bit complexity.

The algorithm consequently runs in time polynomial in \(\tau,L\), and hence in \(m,\tau,K,L\). It operates on the listed support types and does not enumerate possible types or individual applicants.

6. Relation to the continuum claim

[Dai and Jordan, Theorem 2](https://proceedings.neurips.cc/paper_files/paper/2021/file/6a571fe98a2ba453e84923b447d79cff-Paper.pdf) state that their nonnegative greedy loss bound vanishes for a continuum under continuity in score.

For the representation in this question, the proof above independently establishes both exact optimality and polynomial bit complexity. Equal-score restrictions and continuity in score are unnecessary for this algorithm; the supplied rational coefficients and permission to split types suffice.
