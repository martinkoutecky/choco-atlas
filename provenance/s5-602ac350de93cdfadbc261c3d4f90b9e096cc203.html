The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), per-institution cash \(b_t\ge 0\), and per-institution liabilities \(q_{tu}\ge 0\) from type \(t\) to type \(u\), with exposures uniform within each type pair, let \(B_t=\mu_t b_t\) and \(L_{tu}=\mu_t q_{tu}\). Given a proposed aggregate allocation \(y_t\ge 0\) with \(\sum_t y_t=\sum_t B_t\), decide whether there are transfers \(x_{tu}\) such that \(0\le x_{tu}\le L_{tu}\), \(y_t=B_t+\sum_{u\ne t}x_{ut}-\sum_{u\ne t}x_{tu}\), and \(\sum_{u\ne t}x_{tu}\le B_t+\sum_{u\ne t}x_{ut}\) for every \(t\); if so, return such transfers.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of its \(\tau=|T|\) positive-mass types, with binary rational masses \(\mu_t>0\) satisfying \(\sum_{t\in T}\mu_t=1\). The parameter \(\tau\) is the support size, not the number of possible types.
For each type, the input specifies nonnegative binary rational cash \(b_t\) per institution; for each distinct pair, it specifies nonnegative binary rational liabilities \(q_{tu}\), the total owed by one institution of type \(t\) to institutions of type \(u\), distributed uniformly within that recipient type. Set \(B_t=\mu_t b_t\) and \(L_{tu}=\mu_t q_{tu}\). Transfers within a type are omitted because they do not change its aggregate allocation.
The proposed allocation consists of nonnegative binary rationals \(y_t\) with \(\sum_t y_t=\sum_t B_t\). Let \(L\) denote the total input bit length.
A feasible aggregate transfer scheme consists of real numbers \(x_{tu}\), for distinct types, satisfying \(0\le x_{tu}\le L_{tu}\), \(y_t=B_t+\sum_{u\ne t}x_{ut}-\sum_{u\ne t}x_{tu}\), and \(\sum_{u\ne t}x_{tu}\le B_t+\sum_{u\ne t}x_{ut}\) for every \(t\). Cyclic transfers are permitted, and liabilities need not be paid in full.

Is deciding whether a feasible aggregate transfer scheme exists solvable in polynomial time in \(\tau\) and \(L\), or is it NP-hard? In the polynomial-time case, can such transfers also be returned in polynomial time?

For finite agents with nonnegative cash and bilateral liabilities, feasible transfer allocations are exactly those satisfying every coalition's lower bound given by its cash minus its liabilities to outsiders; feasibility and transfer construction are polynomial-time computable. [Finite-agent characterization](https://doi.org/10.1007/s00186-017-0621-1).

Modeling choices made when packaging the task

  • Removed zero-mass types so that the input lists precisely the positive-mass support.
  • Specified cash, liabilities, and the proposed allocation as binary rationals, and defined L as the total input bit length.
  • Interpreted q_tu as the total liability per institution to the entire recipient type, consistently with the stated aggregate capacity L_tu = mu_t q_tu.
  • Omitted within-type transfers because they cancel in aggregate balances and can be set to zero.
  • Allowed real-valued transfers, cyclic transfers, and partial payment of liabilities, as in the finite-agent transfer-scheme definition.
  • Used tau and L as the running-time parameters; this problem has no separate m parameter.

Result

The decision problem is polynomial-time solvable in \(\tau\) and \(L\). Whenever a feasible scheme exists, exact rational transfers can also be returned in polynomial time.

The proof works directly with the listed support types; it does not expand types into individual institutions.

1. The spending inequalities are redundant

For a type \(t\), write its total incoming and outgoing transfers as

\(I_t=\sum_{u\ne t}x_{ut}\), and \(O_t=\sum_{u\ne t}x_{tu}\).

The required balance equation gives

\(B_t+I_t-O_t=y_t\).

Since the input satisfies \(y_t\ge 0\), this implies

\(O_t=B_t+I_t-y_t\le B_t+I_t\).

Thus it suffices to enforce the transfer capacities and balance equations. This deduction uses precisely the stated simultaneous constraints, under which cyclic transfers are permitted.

2. Reduction to maximum flow

Let \(C=\sum_{t\in T}B_t=\sum_{t\in T}y_t\). Construct a directed capacitated network with vertex set \(T\cup\{s,r\}\), where \(s\) is a new source and \(r\) a new sink. Its arcs are:

  • \(s\to t\), with capacity \(B_t\), for every \(t\in T\);
  • \(t\to r\), with capacity \(y_t\), for every \(t\in T\);
  • \(t\to u\), with capacity \(L_{tu}\), for every distinct pair \(t,u\in T\).

A flow assigns a nonnegative amount to each arc, bounded by its capacity, and satisfies conservation at every vertex in \(T\). The network has \(\tau+2\) vertices and at most \(\tau(\tau-1)+2\tau\) arcs.

Claim. A feasible aggregate transfer scheme exists if and only if this network admits a flow of value \(C\).

Proof, forward direction. Suppose \(x\) is a feasible scheme. Define

\(f(s,t)=B_t,\qquad f(t,r)=y_t,\qquad f(t,u)=x_{tu}\).

All capacity bounds hold. At each type vertex, the allocation equation rearranges to

\(B_t+\sum_{u\ne t}x_{ut}=y_t+\sum_{u\ne t}x_{tu}\),

which is exactly flow conservation. Consequently \(f\) is a flow of value \(\sum_t B_t=C\).

Proof, reverse direction. Suppose \(f\) is a flow of value \(C\). The source has no incoming arcs, and the capacities of its outgoing arcs sum to \(C\). Therefore every source arc is saturated: if even one were below capacity, the total outgoing flow would be less than \(C\). Hence \(f(s,t)=B_t\) for every \(t\).

Likewise, the sink has no outgoing arcs, and its incoming capacities sum to \(C\). Thus \(f(t,r)=y_t\) for every \(t\).

Set \(x_{tu}=f(t,u)\). The internal arc capacities give \(0\le x_{tu}\le L_{tu}\). Conservation at each type gives

\(B_t+\sum_{u\ne t}x_{ut}=y_t+\sum_{u\ne t}x_{tu}\),

so all balance equations hold. Section 1 then supplies the spending inequalities. Thus \(x\) is feasible. This proves the claim.

Because all outgoing source capacities sum to \(C\), no flow can have value greater than \(C\). The decision algorithm therefore computes a maximum flow and accepts exactly when its value equals \(C\).

3. Exact arithmetic and polynomial bit complexity

We must ensure that the algorithm is polynomial in the binary encoding length, independently of the numerical magnitudes of the capacities.

First compute the rational products \(B_t=\mu_t b_t\) and \(L_{tu}=\mu_t q_{tu}\). Multiplication of binary integers is polynomial-time, and the numerator and denominator lengths of a product are bounded by the sums of the corresponding input lengths. There are at most \(\tau^2+\tau\) network capacities. Consequently their total encoding length, denoted \(K\), is polynomial in \(\tau\) and \(L\).

Write each capacity \(c_e\) as \(a_e/d_e\), with nonnegative integer \(a_e\) and positive integer \(d_e\). Define

\(D=\prod_e d_e\).

The binary length of \(D\) is at most the sum of the binary lengths of these denominators, up to a constant; hence it is \(O(K)\). Replace each capacity by the integer

\(\widehat c_e=a_e(D/d_e)=Dc_e\).

All scaled capacities have polynomial binary length. Scaling establishes a bijection between flows in the original network and flows in the scaled network, multiplying their values by \(D\).

Run the Edmonds–Karp maximum-flow algorithm on this finite network with nonnegative integer capacities. Its bound is \(O(VE^2)\) graph and arithmetic operations, independent of capacity magnitude. Here \(V=\tau+2\) and \(E=O(\tau^2)\). See the [Boost documentation for the Edmonds–Karp bound](https://www.boost.org/doc/libs/1_40_0/libs/graph/doc/edmonds_karp_max_flow.html).

Starting from zero flow, each augmentation uses an integer residual bottleneck. Thus all computed arc flows remain integers. Their values are bounded by their capacities; residual quantities can be maintained with polynomially many bits as well. Each arithmetic operation therefore has polynomial bit cost. The complete computation takes polynomial time in \(\tau\) and \(L\).

If the maximum-flow value is \(DC\), return

\(x_{tu}=\widehat f(t,u)/D\).

These are exact rational transfers satisfying the original constraints. Each returned numerator and denominator has polynomial binary length, and there are at most \(\tau(\tau-1)\) transfers. Thus construction and output are also polynomial-time.

If \(C=0\), nonnegativity forces every \(B_t\) and \(y_t\) to be zero, and the all-zero transfer scheme is feasible. The same algorithm handles this case.

4. Coalition characterization and an infeasibility certificate

The reduction also yields the precise aggregate coalition characterization.

For \(S\subseteq T\), define

\(B(S)=\sum_{t\in S}B_t,\qquad y(S)=\sum_{t\in S}y_t,\qquad L(S,T\setminus S)=\sum_{t\in S,\ u\notin S}L_{tu}\).

Claim. A feasible scheme exists if and only if every \(S\subseteq T\) satisfies

\(y(S)\ge B(S)-L(S,T\setminus S)\).

Proof. Every source–sink cut has source side \(\{s\}\cup S\) for some \(S\subseteq T\). The arcs crossing from this side to its complement are exactly the source arcs to \(T\setminus S\), the sink arcs from \(S\), and the liability arcs from \(S\) to \(T\setminus S\). Its capacity is therefore

\(B(T\setminus S)+y(S)+L(S,T\setminus S)=C-B(S)+y(S)+L(S,T\setminus S)\).

This capacity is at least \(C\) precisely when the stated coalition inequality holds.

The max-flow/min-cut theorem applies because the constructed network is finite and directed with nonnegative capacities. It says that the maximum-flow value equals the minimum cut capacity. Hence all coalition inequalities hold if and only if the maximum-flow value is \(C\), which Section 2 proved equivalent to feasibility.

Moreover, if feasibility fails, a minimum cut produces a coalition \(S\) with

\(y(S)<B(S)-L(S,T\setminus S)\),

giving a polynomially computable certificate of infeasibility. There is no need to enumerate all coalitions.
