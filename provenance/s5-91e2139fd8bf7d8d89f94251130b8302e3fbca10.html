The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), a directed compatibility graph on \(T\), and a partial preference order for each type over permitted representative types with being a root ranked last, let an atomless population \(\Omega\) be partitioned into type classes of masses \(\mu_t\). A branching is a measurable parent map from agents to permitted representatives or to the root, with every parent chain reaching a root in finitely many steps. Agents compare branchings by the representative type they choose, with incomparable choices tied. For the normalized mass vote margin \(\Delta_\mu(B',B)\), decide whether there exists a branching \(B\) such that \(\sup_{B'}\Delta_\mu(B',B)\le\kappa\), where \(B'\) ranges over admissible measurable branchings and \(\kappa\in[0,1]\).

A society is given by its support: a list of the \(\tau\) types \(T\) with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Let \(\Omega=T\times[0,1]\) have measure \(\nu(\{t\}\times A)=\mu_t\lambda(A)\), where \(\lambda\) is Lebesgue measure.
The input includes a directed compatibility graph \(H=(T,E)\) with \(m=|E|\) arcs, possibly including type loops, and an explicitly represented strict partial order \(\succ_t\) over \(P_t=\{s:(s,t)\in E\}\). Adjoin an option \(\bot\), strictly worse than every permitted representative type, meaning that the agent remains a root.
A branching \(B\) is a measurable parent map \(p_B:\Omega\to\Omega\cup\{\bot\}\): if \(a\) has type \(t\) and \(p_B(a)\) has type \(s\), then \((s,t)\in E\) and \(p_B(a)\ne a\). Every agent's parent chain must reach \(\bot\) after finitely many steps. Representatives have no capacity constraints; roots may have zero total mass.
Write \(c_B(a)\) for the immediate parent's type, or \(\bot\). Identical or incomparable choices receive vote zero; define \(\Delta_\mu(B',B)=\nu(\{a:c_{B'}(a)\succ_{t(a)}c_B(a)\})-\nu(\{a:c_B(a)\succ_{t(a)}c_{B'}(a)\})\).
Given a binary rational \(\kappa\in[0,1]\), is deciding whether some branching \(B\) satisfies \(\sup_{B'}\Delta_\mu(B',B)\le\kappa\), over all admissible measurable branchings \(B'\), in \(\mathsf{P}\) or \(\mathsf{NP}\)-hard? State running times in \(m\), \(\tau\), and the total input bit length \(L\).
For finite societies, deciding whether a branching has unpopularity margin at most a given integer is \(\mathsf{NP}\)-hard for arbitrary partial preferences; the established result allows parallel edges with distinct preferences. Minimum margin under weak rankings is computable in polynomial time. [Source](https://real.mtak.hu/136885/1/Kavitha2021_Article_PopularBranchingsAndTheirDualC.pdf)
Popular lotteries over finite branchings always exist and can be computed in polynomial time; their comparisons use expected votes. Conclusion

The problem is in \(\mathsf{P}\). Every valid instance admits a branching with unpopularity margin exactly \(\,0\).

The decisive assumption is that roots may have zero mass. This applies to the full stated model, including arbitrary partial preferences and type loops.

1. Realizing arbitrary choices almost everywhere

Write \(\,Q_t=P_t\cup\{\bot\}\). A measurable choice assignment is a measurable map \(\,d:\Omega\to T\cup\{\bot\}\) satisfying \(\,d(a)\in Q_{t(a)}\).

Lemma. Every measurable choice assignment is realized almost everywhere by an admissible branching whose parent chains terminate after at most two parent-map applications.

Proof. For each type \(\,s\in T\), select the agent \(\,r_s=(s,0)\). Let \(\,R=\{r_s:s\in T\}\). Since \(\,T\) is finite and each singleton has Lebesgue measure zero, \(\,\nu(R)=0\).

Define the parent map as follows:

  • Every agent in \(\,R\) has parent \(\,\bot\).
  • For \(\,a\notin R\) with \(\,d(a)=\bot\), set \(\,p(a)=\bot\).
  • For \(\,a\notin R\) with \(\,d(a)=s\in T\), set \(\,p(a)=r_s\).

Compatibility follows from \(\,d(a)\in Q_{t(a)}\). Whenever the parent is an agent, it belongs to \(\,R\), whereas the child does not; hence there is no self-parenting, even when \(\,s=t(a)\).

Every nonroot points to an agent in \(\,R\), which is a root. Thus all parent chains terminate. The map is measurable because it has finite range and measurable fibers: its fibers are obtained from the measurable fibers of \(\,d\) by adding or removing finitely many points.

Outside \(\,R\), the immediate-parent type equals \(\,d(a)\). This proves the lemma. \(\square\)

2. An exact formula for the margin

Let \(\,M_t\subseteq Q_t\) denote the maximal options: \(\,q\in M_t\) precisely when no \(\,u\in Q_t\) satisfies \(\,u\succ_t q\). Define

\(\,N_B=\{a\in\Omega:c_B(a)\notin M_{t(a)}\}\).

Proposition. For every admissible branching \(\,B\),

\(\displaystyle \sup_{B'}\Delta_\mu(B',B)=\nu(N_B)\).

Moreover, the supremum is attained.

Proof. If an agent strictly prefers its choice in \(\,B'\) to its choice in \(\,B\), its choice in \(\,B\) is not maximal. Therefore the set of positive voters is contained in \(\,N_B\). Subtracting the nonnegative mass of negative voters gives \(\,\Delta_\mu(B',B)\le\nu(N_B)\).

For the reverse inequality, for each type \(\,t\) and nonmaximal option \(\,q\in Q_t\), choose an option \(\,h_t(q)\succ_t q\). Such an option exists by the definition of nonmaximality. For maximal options, set \(\,h_t(q)=q\).

The assignment \(\,d(a)=h_{t(a)}(c_B(a))\) is measurable because each \(\,Q_t\) is finite. By the lemma, an admissible branching \(\,B'\) realizes this assignment outside a null set. Consequently, almost every agent in \(\,N_B\) votes positively, and almost every agent outside \(\,N_B\) receives its original choice. There are no negative voters except possibly on the null exceptional set. Hence \(\,\Delta_\mu(B',B)=\nu(N_B)\). \(\square\)

In particular, a branching is popular exactly when almost every agent receives a maximal option.

3. Construction of a zero-margin branching

For each type \(\,t\) with \(\,P_t\ne\varnothing\), choose a maximal element \(\,s_t\in P_t\). Such an element exists: a finite strict partial order cannot have an indefinitely continuing sequence of strict improvements.

When \(\,P_t=\varnothing\), choose \(\,\bot\). These choices are maximal in \(\,Q_t\), because every permitted representative is strictly better than \(\,\bot\).

Apply the lemma to the assignment that gives every agent of type \(\,t\) the selected option. The resulting branching \(\,B\) has maximal choices almost everywhere, so the proposition gives \(\,\sup_{B'}\Delta_\mu(B',B)=0\).

Since the input satisfies \(\,\kappa\in[0,1]\), this branching satisfies the required inequality.

4. Running time and relation to finite societies

On the promised valid inputs, the decision algorithm always returns yes. It takes constant time if reading the input is unnecessary, or \(\,O(L)\) time including a complete input scan.

A witness has a finite description consisting of one selected option and one designated root per type. With indexed types and explicitly listed preference pairs, mark every worse endpoint of a preference pair and select an unmarked permitted option for each type. This takes \(\,O(L+m+\tau)\) word operations. A direct implementation that scans the explicit relation separately for each candidate uses \(\,O((m+\tau+1)L)\) bit operations, hence polynomial time in the total input length.

The cited finite-society hardness result does not contradict this conclusion: finite branchings require roots among agents whose votes have positive weight. Here the designated representatives collectively have zero mass. The finite hardness theorem therefore does not transfer to this model.
