The continuous mirror question, as graded

Given finite complete agent types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), good types \(J\) with rational per-capita supplies \(q_j\), binary valuations \(v_{tj}\), and a symmetric block-adjacency relation \(W\), decide whether there are finite-support rational bundle distributions \(x_{t,\mathbf b}\) over integral bundles \(\mathbf b\in\mathbb Z_{\ge0}^{J}\) such that \(\sum_{\mathbf b}x_{t,\mathbf b}=\mu_t\), \(\sum_{t,\mathbf b}x_{t,\mathbf b}b_j=q_j\), goods are allocated only to valuers, and \(v_t\cdot\mathbf b\ge v_t\cdot\mathbf b'\) for every \(W_{tu}=1\) and every bundle \(\mathbf b,\mathbf b'\) in the respective supports.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; types encode both valuations and network position, so equal valuations need not identify types.
There are \(m=|J|\ge1\) good types with binary-rational per-capita supplies \(q_j\ge0\). Additive valuations satisfy \(v_{tj}\in\{0,1\}\), and every good type with positive supply is valued by some type.
The input includes a symmetric matrix \(W\in\{0,1\}^{T\times T}\): \(W_{tu}=1\) means every individual of type \(t\) is adjacent to every individual of type \(u\); a diagonal entry specifies adjacency between distinct individuals within that type.
A feasible allocation consists of nonnegative rational masses \(x_{t,\mathbf b}\) with finite support over integral bundles \(\mathbf b\in\mathbb Z_{\ge0}^{J}\), satisfying \(\sum_{\mathbf b}x_{t,\mathbf b}=\mu_t\) and \(\sum_{t,\mathbf b}x_{t,\mathbf b}b_j=q_j\). Empty bundles are permitted; bundle sizes have no prescribed bound. Non-wastefulness requires \(x_{t,\mathbf b}>0\Rightarrow b_j=0\) whenever \(v_{tj}=0\).
Local envy-freeness requires \(v_t\cdot\mathbf b\ge v_t\cdot\mathbf b'\) whenever \(W_{tu}=1\), \(x_{t,\mathbf b}>0\), and \(x_{u,\mathbf b'}>0\), including within-type comparisons when \(W_{tt}=1\).
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is deciding whether such a complete, non-wasteful, locally envy-free allocation exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finitely many individual agents on an undirected graph, deciding existence of a Pareto-efficient, locally envy-free allocation is NP-complete even with only two distinct additive binary valuation vectors. With every good valued by someone, Pareto efficiency is equivalent to completeness and non-wastefulness. [Source](https://arxiv.org/pdf/2111.11528)
No result settling this exact mass-and-integral-bundle problem was located in the literature search.

Modeling choices made when packaging the task

  • Supplies were unsigned in the graded question; they are nonnegative binary rationals, and every positive-supply good type must be valued by someone, carrying over the condition used to identify Pareto efficiency with completeness and non-wastefulness.
  • Complete types distinguish network position as well as valuations; types with identical valuation vectors are not automatically merged.
  • The block relation applies to every pair of individuals in the indicated blocks. Diagonal entries are allowed and describe adjacency between distinct individuals within a block.
  • Bundle-distribution entries are nonnegative rational masses, rather than conditional probabilities, and support means strictly positive entries.
  • Empty bundles are allowed, as in the discrete allocation model; no bundle-size bound is imposed beyond the graded question's integral-bundle domain.
  • The size parameter m counts good types, and L is the total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is \(\mathrm{NP}\)-hard, even with one good type, identical valuations, dyadic masses and supply, and a type graph consisting of disjoint edges with zero diagonal.

Thus an algorithm running in \((m+\tau+L)^{O(1)}\) time would imply \(\mathrm{P}=\mathrm{NP}\). The proof below directly addresses fractional masses and integral bundles.

1. An adjacent pair forces a common integer bundle size

Suppose there is one good, valued by every type. An integral bundle is then specified by its size \(k\in\mathbb Z_{\ge0}\).

Consider adjacent types \(a,b\), both having positive mass. If sizes \(k,\ell\) occur with positive mass at \(a,b\), respectively, local envy-freeness in the two directions gives \(k\ge\ell\) and \(\ell\ge k\). Hence \(k=\ell\).

Both types have nonempty allocation support because their masses are positive. Fixing one supported bundle at either type therefore shows that every supported bundle at both types has one common integer size.

Consequently, if the graph consists of disjoint pairs indexed by \(i\), and pair \(i\) has total mass \(p_i\), feasibility is equivalent to the existence of integers \(z_i\in\mathbb Z_{\ge0}\) satisfying

\(q=\sum_i p_i z_i.\)

For the converse, give every individual in pair \(i\) the bundle of size \(z_i\). This allocation has finite rational support, is non-wasteful, and satisfies every envy comparison.

2. Encoding Exact Cover as an integer equation

We reduce from Exact Cover: given an explicitly listed universe \(U=\{1,\ldots,r\}\) and nonempty subsets \(S_1,\ldots,S_s\subseteq U\), decide whether some subfamily covers each element exactly once. This problem is \(\mathrm{NP}\)-complete. Removing empty sets and excluding the trivial empty-universe case preserves hardness. [Karp, *Reducibility Among Combinatorial Problems*](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Set

\(B=r+1,\qquad P=B^r,\qquad D=\sum_{a=1}^{r}B^{a-1},\qquad K=rP+D.\)

Since \(r\ge1\), we have \(0<D<P\). Introduce positive integer coefficients

\(c_0=P,\qquad c_j=P+\sum_{a\in S_j}B^{a-1}\quad(1\le j\le s).\)

The coefficient \(c_0\) will serve as a filler.

Claim. An exact cover exists if and only if there are nonnegative integers \(z_0,\ldots,z_s\) satisfying

\(\sum_{j=0}^{s}c_jz_j=K.\)

Forward direction. Suppose an exact cover uses \(k\) sets. Because the selected sets are nonempty and disjoint, \(k\le r\). Give each selected set coefficient multiplicity \(1\), each unselected coefficient multiplicity \(0\), and set \(z_0=r-k\).

The selected sets contribute each lower digit exactly once, so

\(\sum_{j=0}^{s}c_jz_j=(r-k)P+kP+D=K.\)

Reverse direction. Suppose the integer equation holds. Define

\(N=\sum_{j=0}^{s}z_j,\qquad d_a=\sum_{\substack{1\le j\le s\\a\in S_j}}z_j.\)

Every coefficient is at least \(P\). Therefore

\(NP\le K<(r+1)P,\)

which implies \(N\le r\). Also \(0\le d_a\le N\le r=B-1\). Expanding the equation gives

\(NP+\sum_{a=1}^{r}d_aB^{a-1}=rP+\sum_{a=1}^{r}B^{a-1}.\)

Every coefficient in these base-\(B\) expansions lies between \(0\) and \(B-1\), so there are no carries. Uniqueness of base-\(B\) representation implies

\(N=r,\qquad d_a=1\quad\text{for every }a\in U.\)

For each \(j\ge1\), choose an element \(a\in S_j\). Then \(z_j\le d_a=1\), so \(z_j\in\{0,1\}\). The equalities \(d_a=1\) say precisely that the sets with \(z_j=1\) form an exact cover. This proves the claim.

3. Constructing the society

Let \(A=\sum_{j=0}^{s}c_j\). Choose the smallest integer \(h\) satisfying \(2^h>A+K\), and introduce a padding coefficient

\(c_\star=2^h-A.\)

Then \(c_\star>K\), and the coefficients including padding sum to \(2^h\).

For each index \(i\in\{0,1,\ldots,s,\star\}\), create two types \(t_i^-,t_i^+\), each with mass

\(\mu_{t_i^-}=\mu_{t_i^+}=\dfrac{c_i}{2^{h+1}}.\)

Use one good type, valued at \(1\) by every type, with supply

\(q=\dfrac{K}{2^h}.\)

Put an edge between \(t_i^-\) and \(t_i^+\) for each \(i\), and no other edges. In particular, every diagonal entry of \(W\) is zero.

All input requirements hold:

  • Every mass is a positive dyadic rational.
  • The masses sum to \(\sum_i c_i/2^h=1\).
  • The supply satisfies \(0<q<1\), and every type values the good.
  • The matrix \(W\) is symmetric.
  • Types sharing valuations remain separate entries in the support, as permitted by the task.

The parameters are \(m=1\) and \(\tau=2(s+2)\).

4. Correctness of the reduction

By Section 1, any feasible allocation assigns a common integer bundle size \(z_i\) to both types of pair \(i\). Supply feasibility becomes

\(\sum_i \dfrac{c_i}{2^h}z_i=\dfrac{K}{2^h},\)

or equivalently,

\(\sum_{j=0}^{s}c_jz_j+c_\star z_\star=K.\)

Because all terms are nonnegative and \(c_\star>K\), necessarily \(z_\star=0\). Thus every feasible allocation yields the integer equation of Section 2, and hence an exact cover.

Conversely, an exact cover yields the integers constructed in Section 2. Set \(z_\star=0\), and give both types in pair \(i\) only the bundle of size \(z_i\), assigning that bundle the type’s entire mass.

These allocation masses are rational and have finite support. The integer equation proves exact supply exhaustion. Non-wastefulness holds because everyone values the good. Adjacent types receive equal bundle sizes, so local envy-freeness holds.

Therefore the constructed society admits the required allocation if and only if the Exact Cover instance is a yes-instance.

5. Encoding size and complexity

Each ordinary coefficient is smaller than \(2B^r\). Hence

\(h=O\bigl(r\log(r+1)+\log(s+r+2)\bigr).\)

All coefficients, masses, and supply therefore have polynomial binary encoding length. Including the explicitly supplied matrix \(W\), the resulting length satisfies

\(L=O\bigl((s+2)^2+(s+2)[r\log(r+1)+\log(s+r+2)]\bigr).\)

The construction uses polynomially many arithmetic operations on integers of polynomial bit length, so it is a polynomial-time many-one reduction.

The restricted family used here is also in \(\mathrm{NP}\). A certificate lists the common integer size for each pair. For pair mass \(p_i>0\), feasibility implies \(z_i\le q/p_i\), whose binary length is \(O(L)\). Exact rational arithmetic verifies the supply equation in \(O(\tau L^2)\) bit operations; checking the graph restriction takes \(O(\tau^2)\) time. Thus this restricted family is \(\mathrm{NP}\)-complete.

For the full problem, the reduction establishes the requested answer: \(\mathrm{NP}\)-hard. Fractional allocation masses do not remove the encoded integer choices, because adjacency forces each pair’s entire positive mass to use a single integral bundle size.
