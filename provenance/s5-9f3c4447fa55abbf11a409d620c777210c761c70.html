The continuous mirror question, as graded

Given \(\tau\) agent types with rational masses \(\mu_t>0\), rational per-capita supplies \(q_j\) of \(m\) item types, rational additive values \(v_{tj}\), and type welfare coefficients \(a_t>0\) satisfying \(\sum_t \mu_t a_t=1\), choose a finite-support distribution of mass \(\lambda_{tB}\ge 0\) over integral bundles \(B\in\mathbb{Z}_{\ge 0}^m\). Require \(\sum_B\lambda_{tB}=\mu_t\) and \(\sum_{t,B}\lambda_{tB}B_j=q_j\). Assuming a positive-welfare feasible allocation exists, can an algorithm running in time polynomial in \(m,\tau\), and the binary input length \(L\) return such a distribution whose weighted NSW, \(\exp(\sum_{t,B}\lambda_{tB}a_t\ln(\sum_j v_{tj}B_j))\), is at least \(e^{-1/e}\) times the optimum?

A society is given by its support: a list of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) item types with binary-rational per-capita supplies \(q_j>0\), additive values \(v_{tj}\geq0\), and welfare coefficients \(a_t>0\) satisfying \(\sum_t\mu_ta_t=1\). Every agent type values some item positively, and every item type has positive value to some agent type. Let \(L\) be the total binary input length.
An allocation is a finite-support family of masses \(\lambda_{tB}\geq0\) over bundles \(B\in\mathbb Z_{\geq0}^m\), with \(B_j=0\) whenever \(v_{tj}=0\), satisfying \(\sum_B\lambda_{tB}=\mu_t\) and \(\sum_{t,B}\lambda_{tB}B_j=q_j\). Bundle multiplicities have no additional upper bounds.
Write \(u_t(B)=\sum_jv_{tj}B_j\) and \(W(\lambda)=\exp(\sum_{t,B:\lambda_{tB}>0}\lambda_{tB}a_t\ln u_t(B))\), with \(W(\lambda)=0\) if any positive-mass bundle has zero utility. Assume a positive-welfare feasible allocation exists, and let \(\mathrm{OPT}\) be the supremum of feasible welfare.

Answer

Yes. In fact, the mass-allocation problem admits a stronger approximation scheme.

Theorem. For every rational \(0<\eta\le1\), an algorithm returns an explicitly listed feasible allocation with rational masses of polynomial binary encoding length and
\(W(\lambda)\ge e^{-\eta}\mathrm{OPT}\).
Its running time is polynomial in \(m,\tau,L,1/\eta\) and the encoding length of \(\eta\).

Taking \(\eta=1/4\) proves the requested guarantee, since \(1/4<1/e\).

The key is to optimize distributions over bundles directly. The configuration-LP viewpoint also appears in [Feng–Li](https://theoretics.episciences.org/16348/pdf). In the present model, the resulting distribution is itself an admissible allocation. Below, a polynomial-size flow formulation constructs that distribution without expanding agents or item copies.

All rational numbers in the proof are represented by binary-encoded numerators and denominators.

1. Logarithmic welfare and a bounded-bundle reduction

For a positive-welfare allocation, define
\(\Phi(\lambda)=\sum_{t,B}\lambda_{tB}a_t\ln u_t(B)\),
so \(W(\lambda)=e^{\Phi(\lambda)}\).

Temporarily permit under-supply allocations: they satisfy the type-mass equalities but use at most \(q_j\) of each item. We will restore exact supply equalities at the end.

Set
\(A=\max_t a_t\) and \(Q=\sum_jq_j\).
Choose an integer \(h\ge1\) such that
\(C=2^h-1\ge 3AQ/\eta\).
Both \(h\) and the binary encoding length of \(C\) are polynomial in the input length and the encoding length of \(\eta\).

For any bundle \(B\), define its coordinatewise truncation by
\(B^{C}_j=\min\{B_j,C\}\).
Truncation preserves positive utility because \(C\ge1\).

We claim that
\(0\le\ln u_t(B)-\ln u_t(B^C)\le C^{-1}\sum_jB_j\).

To prove this, put
\(r=\max\{1,\max_j B_j/C\}\).
For every coordinate, \(B_j\le rB^C_j\), hence \(u_t(B)\le r u_t(B^C)\). If \(r=1\), the logarithmic difference is zero. Otherwise,
\(\ln r\le r=\max_jB_j/C\le C^{-1}\sum_jB_j\),
which proves the claim.

Consequently, truncating every bundle of any feasible positive-welfare allocation \(\lambda\) produces an under-supply allocation \(\lambda^C\) satisfying

\(\displaystyle \Phi(\lambda)-\Phi(\lambda^C) \le \frac1C\sum_{t,B}\lambda_{tB}a_t\sum_jB_j \le \frac{AQ}{C} \le\frac{\eta}{3}. \)

Thus it suffices to optimize distributions over bundles with coordinates at most \(C\), allowing a further additive logarithmic loss.

2. A polynomial-size graph representing bounded bundles

Let \(K=mh\) and \(\delta=\eta/(3K)\).

Fix a type \(t\), and write
\(J_t=\{j:v_{tj}>0\}\).
By hypothesis, \(J_t\) is nonempty. Define
\(\ell_t=\min_{j\in J_t}v_{tj}\) and
\(R_t=C\sum_{j\in J_t}v_{tj}\).

Every admissible bounded bundle has a binary representation
\(B_j=\sum_{k=0}^{h-1}2^k b_{jk}\),
where \(b_{jk}\in\{0,1\}\), for \(j\in J_t\).
There are \(K_t=h|J_t|\le K\) binary decisions.

Construct the rational geometric grid
\(g_{tr}=\ell_t(1+\delta)^r\),
stopping at the first index \(N_t\) for which \(g_{tN_t}>R_t\).

For \(\ell_t\le y\le R_t\), let \(D_t(y)\) be the largest grid value at most \(y\). Then

\(\displaystyle \frac{y}{1+\delta}\le D_t(y)\le y.\)

Process the binary decisions in any fixed order. The graph state records a rounded partial utility \(s\), initially zero.

For the decision associated with \((j,k)\):

  • skipping the bit leaves \(s\) unchanged and consumes no items;
  • selecting it moves to \(D_t(s+2^kv_{tj})\) and consumes exactly \(2^k\) units of item \(j\).

Construct only states reachable from the initial state. Since each decision is processed once, the true partial utility never exceeds \(R_t\), so every required transition is defined. Connect each positive terminal state to a sink; leave the zero terminal state without an outgoing edge.

Every source-to-sink path therefore describes an admissible bounded bundle with positive utility. Conversely, every such bundle determines a path.

Utility approximation along a path

Let \(U_i\) be the true partial utility after \(i\) decisions and \(s_i\) the graph state. We prove inductively that

\(\displaystyle \frac{U_i}{(1+\delta)^i}\le s_i\le U_i. \)

Initially both quantities are zero. A skip preserves the upper bound and only weakens the required lower bound. On selecting a bit of value \(w>0\),

\(\displaystyle s_i\ge\frac{s_{i-1}+w}{1+\delta} \ge\frac{U_{i-1}+w}{(1+\delta)^i}, \)

and \(s_i\le s_{i-1}+w\le U_i\).

Thus, for a path describing bundle \(B\) and ending at state \(s>0\),

\(\displaystyle 0\le\ln u_t(B)-\ln s \le K\ln(1+\delta) \le K\delta =\frac{\eta}{3}. \)

Crucially, this approximation changes only the utility state. Item counts remain exact.

3. The flow linear program

For each type \(t\), place a nonnegative flow of total value \(\mu_t\) from its graph source to its sink, with conservation at every other vertex.

If an arc selects bit \((j,k)\), label its resource consumption by \(2^k\) units of item \(j\). Impose the exact rational inequalities

\(\displaystyle \sum_{\substack{t,\;e:\ e\text{ selects}\\\text{a bit of item }j}} 2^{k(e)}f_{te}\le q_j \qquad\text{for every }j. \)

Let \(y_{ts}\) be the flow on the arc from positive terminal state \(s\) to the sink. Define the real-valued objective

\(\displaystyle F(f)=\sum_{t,s>0}a_t y_{ts}\ln s.\)

Every under-supply distribution over bounded positive-utility bundles induces a feasible flow by sending each bundle’s mass along its path. In particular, the bounded-bundle reduction proves that this LP’s feasible region is nonempty.

The graph is acyclic, and each type’s total flow is \(\mu_t\). Therefore every arc flow is at most \(\mu_t\), so the feasible region is bounded.

Replace logarithms by rational coefficients

Compute rational coefficients \(c_{ts}\) satisfying
\(|c_{ts}-\ln s|\le\eta/6\).
Maximize the rational linear objective

\(\displaystyle \widehat F(f)=\sum_{t,s>0}a_t y_{ts}c_{ts}.\)

For every feasible flow,
\(\sum_s y_{ts}=\mu_t\), and therefore

\(\displaystyle |\widehat F(f)-F(f)| \le\frac{\eta}{6}\sum_ta_t\mu_t =\frac{\eta}{6}. \)

Let \(f^*\) be an exact rational optimum of this rational LP. For every feasible comparison flow \(f\),

\(\displaystyle F(f^*) \ge\widehat F(f^*)-\frac{\eta}{6} \ge\widehat F(f)-\frac{\eta}{6} \ge F(f)-\frac{\eta}{3}. \)

Hence rationalizing the objective incurs at most another \(\eta/3\) loss.

4. Extracting an explicit bundle distribution

Decompose each type’s flow \(f^*\) into source-to-sink paths. This can be done by repeatedly selecting a path of positive-flow arcs and subtracting its minimum arc flow.

Each iteration removes at least one positive-flow arc. Thus the total number of extracted paths is at most the total number of graph arcs.

Give each path’s bundle the mass extracted along that path. This produces an explicitly listed rational under-supply allocation \(\lambda^0\) with:

  • total type-\(t\) mass exactly \(\mu_t\);
  • item consumption at most \(q_j\);
  • positive utility on every positive-mass bundle;
  • logarithmic welfare \(\Phi(\lambda^0)\ge F(f^*)\).

The last inequality follows because the actual utility of each path’s bundle is at least its terminal state.

Now fix any feasible positive-welfare allocation \(\lambda\), without assuming that an optimum is attained. Its truncated allocation induces a comparison flow \(f\). The preceding bounds give

\(\displaystyle F(f) \ge\Phi(\lambda^C)-\frac{\eta}{3} \ge\Phi(\lambda)-\frac{2\eta}{3}. \)

It follows that

\(\displaystyle \Phi(\lambda^0) \ge F(f^*) \ge\Phi(\lambda)-\eta. \)

The only remaining task is to fill unused supplies exactly.

5. Restoring exact supplies with at most \(m\) additional entries

Let
\(d_j=q_j-\sum_{t,B}\lambda^0_{tB}B_j\ge0\).

For each item \(j\), choose a type \(t(j)\) with \(v_{t(j),j}>0\), which exists by hypothesis. For each type receiving at least one assigned item, choose one existing bundle entry of that type, with positive mass \(\rho_t\). Let \(I_t=\{j:t(j)=t\}\).

For \(j\in I_t\), write

\(\displaystyle \frac{d_j}{\rho_t}=n_j+\theta_j, \qquad n_j=\left\lfloor\frac{d_j}{\rho_t}\right\rfloor, \quad 0\le\theta_j<1. \)

Partition the interval \([0,1]\) at the distinct points
\(\{0,1\}\cup\{\theta_j:j\in I_t\}\).

For each resulting interval, choose an interior point \(x\). Replace the selected bundle entry by an entry of mass \(\rho_t\) times the interval length, adding to its bundle

\(\displaystyle n_j+\mathbf 1_{\{x<\theta_j\}}\)

units of every \(j\in I_t\).

The total replacement mass remains \(\rho_t\). The mass of intervals lying below \(\theta_j\) is \(\rho_t\theta_j\), so the total added supply of item \(j\) is exactly

\(\displaystyle \rho_t n_j+\rho_t\theta_j=d_j. \)

All masses are rational. Every added item is positively valued by the receiving type, and every replacement bundle contains its original bundle. Thus welfare cannot decrease.

There are at most \(|I_t|+1\) replacement entries for the selected entry of type \(t\). Summing over types, this operation increases the support size by at most \(m\).

Denote the completed allocation by \(\lambda^{\mathrm{out}}\). It is feasible for the original supply equalities and satisfies
\(\Phi(\lambda^{\mathrm{out}})\ge\Phi(\lambda^0)\).

6. Polynomial running time and output length

We check the numerical and combinatorial bounds explicitly.

First,
\(h=O(L+\log m+\log(1/\eta))\), hence \(K=mh\) is polynomially bounded. The rational numbers \(\ell_t\) and \(R_t\) have polynomial encoding length, so
\(\ln(R_t/\ell_t)\) is polynomially bounded.

Since \(0<\delta\le1\), we have \(\ln(1+\delta)\ge\delta/2\). Therefore

\(\displaystyle N_t \le 1+\frac{\ln(R_t/\ell_t)}{\ln(1+\delta)} \le 1+\frac{2\ln(R_t/\ell_t)}{\delta}. \)

Thus each graph has polynomially many layers, states and arcs. Grid values are exact rational powers with polynomially bounded exponents, so their encoding lengths are also polynomial. Graph construction uses only rational arithmetic and comparisons.

For completeness, logarithms can be approximated in polynomial time using rational arithmetic. Given positive rational \(s\), write \(s=2^b y\) with \(1\le y<2\). For \(z=(y-1)/(y+1)\), we have \(0\le z<1/3\) and

\(\displaystyle \ln y=2\sum_{r=0}^{\infty}\frac{z^{2r+1}}{2r+1}. \)

The tail after \(N\) terms is at most \((3/4)9^{-N}\). The same formula computes \(\ln2\) using \(z=1/3\). Since \(\ln s=b\ln2+\ln y\), polynomially many rational operations suffice for the required error \(\eta/6\).

The resulting LP has polynomial size and rational coefficients of polynomial encoding length. The standard polynomial-time theorem for rational linear programming applies: its feasible region is nonempty and bounded, so an exact rational optimal solution of polynomial encoding length can be computed.

Path decomposition uses polynomially many rational subtractions. Its masses consequently have polynomial encoding length. Finally, the supply-completion construction uses rational division, floors and sorting on polynomial-length numbers. Its bundle multiplicities also have polynomial binary encoding length, even when their numerical values are large.

Hence the entire algorithm, including its explicit output, has the claimed polynomial bounds.

7. Guarantee against the supremum

For every feasible positive-welfare allocation \(\lambda\), we have proved

\(\displaystyle \Phi(\lambda^{\mathrm{out}})\ge\Phi(\lambda)-\eta, \)

and therefore
\(W(\lambda^{\mathrm{out}})\ge e^{-\eta}W(\lambda)\).

The welfare supremum is finite. Indeed, the weights \(\lambda_{tB}a_t\) sum to one, so Jensen’s inequality gives

\(\displaystyle \Phi(\lambda) \le\ln\!\left(\sum_{t,B}\lambda_{tB}a_tu_t(B)\right) \le\ln\!\left(A\sum_jq_j\max_t v_{tj}\right). \)

Taking the supremum over feasible allocations therefore yields

\(\displaystyle W(\lambda^{\mathrm{out}})\ge e^{-\eta}\mathrm{OPT}. \)

With the fixed rational choice \(\eta=1/4\), the running time is polynomial in \(m,\tau,L\), and

\(\displaystyle W(\lambda^{\mathrm{out}}) \ge e^{-1/4}\mathrm{OPT} \ge e^{-1/e}\mathrm{OPT}. \)

This settles the stated mass-allocation guarantee.
