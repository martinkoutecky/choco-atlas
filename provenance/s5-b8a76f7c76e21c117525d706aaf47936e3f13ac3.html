Theorem \ref{thm:EF_NP-complete_Chores_Binary} — class: hardness

The continuous mirror question, as graded

Given finite types \(T\), recurring chore types \(J\), rational population masses \(\mu\), rational per-capita supplies \(\lambda\), and binary incidences \(a_{t,j}\in\{0,1\}\), decide whether there exists a finite-support rational distribution \(\nu_{t,b}\) over integral bundles \(b\in\mathbb{Z}_{\ge0}^{J}\) satisfying \(\sum_b\nu_{t,b}=\mu_t\), \(\sum_{t,b}\nu_{t,b}b_j=\lambda_j\), and \(u_t(b)\ge u_t(b')\) for every occupied \(b\) of type \(t\) and every occupied bundle \(b'\), where \(u_t(b)=-\sum_j a_{t,j}b_j\); if feasible, output such a distribution.

Packaged proof task (what the prover saw — nothing else)

Definitions. An instance has finite type set \(T\), chore set \(J\), rational masses \(\mu_t\ge0\), supplies \(\lambda_j\ge0\), and incidences \(a_{t,j}\in\{0,1\}\). A type-\(t\) integral bundle is \(b\in\mathbb Z_{\ge0}^{J}\), with utility \(u_t(b)=-\sum_{j\in J}a_{t,j}b_j\).
A feasible allocation is a finite-support family \(\nu_{t,b}\in\mathbb Q_{\ge0}\) such that \(\sum_b\nu_{t,b}=\mu_t\) for every \(t\), \(\sum_{t,b}\nu_{t,b}b_j=\lambda_j\) for every \(j\), and, whenever \(\nu_{t,b}>0\) and \(\nu_{t',b'}>0\), \(u_t(b)\ge u_t(b')\).

Target. Is feasibility of this continuous envy-free chore-allocation problem, with construction of a feasible \(\nu\) when one exists, solvable in polynomial time or NP-hard?

Nearest known results. For a finite list of agents and indivisible chores, deciding whether an envy-free allocation exists is strongly NP-complete even with additive values in \(\{-1,0\}\).
No result for the mass-distribution formulation above is verified here.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

Result. The problem is \(\mathrm{NP}\)-hard, even when every type has mass \(2\) and every supply is an integer bounded polynomially in the number of types. The reduction below also converts any feasible allocation into a solution of the source problem.

Source problem and construction. We reduce from Set Splitting: given a finite universe \(V\) and a family \(\mathcal E\) of subsets of \(V\), decide whether there is a partition \(V=V_0\mathbin{\dot\cup}V_1\) such that every \(E\in\mathcal E\) intersects both parts. This problem is \(\mathrm{NP}\)-complete; it is also the source problem in [Bhaskar, Sricharan, and Vaish, Appendix A.1](https://arxiv.org/html/2012.06788#A1).

Write \(n=|V|\), \(m=|\mathcal E|\), and \(r=n+2m\). We may assume \(n\geq1\), since adding an isolated vertex preserves the answer.

Construct the following chore-allocation instance.

  • There is one distinguished type \(z\), one type \(p_v\) for each \(v\in V\), and two types \(q_{E,0},q_{E,1}\) for each \(E\in\mathcal E\). Call the latter \(r\) types the *test types*.
  • Every type has mass \(2\).
  • There is a chore \(d\) with supply \(\lambda_d=2r\).
  • For each \(v\in V\) and \(c\in\{0,1\}\), there is a chore \(x_{v,c}\) with supply \(\lambda_{x_{v,c}}=1\).

The incidences are specified by listing the chores each type dislikes:

| Type | Disliked chores |
|---|---|
| \(z\) | \(d\) |
| \(p_v\) | \(d,x_{v,0},x_{v,1}\) |
| \(q_{E,c}\) | \(d\) and all \(x_{v,c}\) with \(v\in E\) |

All other incidences are zero. In particular, every type dislikes \(d\).

The construction has \(r+1\) types and \(2n+1\) chores and is computable in polynomial time.

A consequence of envy-freeness. Define the nonnegative integer cost \(c_t(b)=-u_t(b)=\sum_j a_{t,j}b_j\).

In any feasible allocation, all supported bundles of the same type \(t\) have a common cost \(k_t\in\mathbb Z_{\geq0}\). Indeed, applying envy-freeness in both directions to two such bundles gives both cost inequalities, hence equality.

Moreover, every supported bundle \(b\), regardless of its recipient type, satisfies \(c_t(b)\geq k_t\). If \(M=\sum_s\mu_s\), summing this inequality against the allocation masses gives

\(\displaystyle M k_t\leq\sum_{s,b}\nu_{s,b}c_t(b)=\sum_j a_{t,j}\lambda_j.\)

The equality follows from the supply constraints and the linearity of \(c_t\).

Soundness: a feasible allocation yields a set splitting. Suppose the constructed instance has a feasible allocation.

Its total mass is \(M=2(r+1)\), and its total chore supply is \(2r+2n\). Since \(r\geq n\), the preceding inequality implies, for every type \(t\),

\(\displaystyle k_t\leq\frac{2r+2n}{2(r+1)}\leq\frac{2r}{r+1}<2.\)

Thus \(k_t\in\{0,1\}\).

The distinguished type dislikes only \(d\), so the sharper bound

\(\displaystyle k_z\leq\frac{\lambda_d}{M}=\frac{r}{r+1}<1\)

forces \(k_z=0\). Consequently, every supported bundle of type \(z\) contains no \(d\).

For a test type \(t\), every supported bundle satisfies \(b_d\leq c_t(b)=k_t\leq1\). All supply of \(d\) must therefore be accommodated by the test types, whose total mass is exactly \(2r\). More explicitly,

\(\displaystyle 2r=\lambda_d=\sum_{t\neq z,b}\nu_{t,b}b_d\leq\sum_{t\neq z,b}\nu_{t,b}=2r.\)

Equality forces \(b_d=1\) in every positively weighted test-type bundle: otherwise the finite sum would be strictly smaller. Hence every test type has \(k_t=1\).

Now consider any supported bundle \(b\) of type \(z\). Envy-freeness for type \(p_v\), together with \(b_d=0\), implies

\(\displaystyle b_{x_{v,0}}+b_{x_{v,1}}=c_{p_v}(b)\geq1\qquad(v\in V).\)

Define \(W(b)=\sum_{v\in V}(b_{x_{v,0}}+b_{x_{v,1}})\). Every supported type-\(z\) bundle therefore has \(W(b)\geq n\).

The total supply of these vertex chores is \(2n\), while type \(z\) has mass \(2\). The supply equations give

\(\displaystyle 0=\sum_b\nu_{z,b}\bigl(W(b)-n\bigr)+\sum_{t\neq z,b}\nu_{t,b}W(b).\)

Every term is nonnegative. Therefore every supported type-\(z\) bundle has \(W(b)=n\). Its \(n\) pair sums are each at least \(1\), so each equals \(1\):

\(\displaystyle b_{x_{v,0}}+b_{x_{v,1}}=1\qquad(v\in V).\)

Because bundle coordinates are nonnegative integers, each such bundle chooses exactly one of the two chores associated with each vertex.

Choose any supported bundle \(b\) of type \(z\), which exists because \(\mu_z=2\). Define

\(\displaystyle V_c=\{v\in V:b_{x_{v,c}}=1\}\qquad(c\in\{0,1\}).\)

These sets partition \(V\). For every \(E\in\mathcal E\) and \(c\in\{0,1\}\), envy-freeness for test type \(q_{E,c}\) gives

\(\displaystyle |E\cap V_c|=\sum_{v\in E}b_{x_{v,c}}=c_{q_{E,c}}(b)\geq k_{q_{E,c}}=1.\)

Thus every edge intersects both parts, as required.

Completeness: a set splitting yields a feasible allocation. Conversely, suppose \(V=V_0\mathbin{\dot\cup}V_1\) splits every edge.

Let \(b^{(0)}\) contain \(x_{v,c}\) when \(v\in V_c\), and let \(b^{(1)}\) contain the complementary choice \(x_{v,1-c}\). Each selected coordinate equals \(1\); all other coordinates, including \(d\), equal zero.

Assign type \(z\) mass \(1\) at each of \(b^{(0)}\) and \(b^{(1)}\). Assign every test type mass \(2\) at the bundle containing exactly one \(d\).

All type masses are correct. Every vertex chore appears in exactly one of the two distinguished bundles, so its allocated quantity is \(1\). The test types consume exactly \(2r\) copies of \(d\).

It remains to check envy-freeness.

  • Type \(z\) has cost zero in both its bundles and therefore envies no bundle.
  • Every test type has own cost \(1\) and evaluates every other test-type bundle at cost \(1\).
  • A type \(p_v\) evaluates each distinguished bundle at cost \(1\).
  • A type \(q_{E,c}\) evaluates the distinguished bundles at costs \(|E\cap V_c|\) and \(|E\cap V_{1-c}|\), respectively. Both are at least \(1\).

Thus the allocation is feasible. It has only \(r+2\) positively weighted type–bundle pairs.

Complexity conclusion. The constructed instance is feasible exactly when the Set Splitting instance is a yes-instance. The proof applies to arbitrary rational, finite-support allocations; it places no restriction on how a type may split its mass.

Therefore feasibility is \(\mathrm{NP}\)-hard. The hardness holds with polynomially bounded integer numerical data. An algorithm that decides feasibility and constructs a feasible allocation whenever one exists cannot run in polynomial time unless \(\mathrm P=\mathrm{NP}\).
