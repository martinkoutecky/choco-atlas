The continuous mirror question, as graded

For fixed \(d\), given distinct rational ideal points \(x_1,\ldots,x_\tau\in\mathbb{Q}^d\), positive rational masses \(\mu_i\) summing to \(1\), and \(\varepsilon\in(0,1/2]\), find a proposal \(p\) such that \(\beta_\mu(p)\ge(1-\varepsilon)\beta(\mu)\), where \(\beta_\mu(p)\) is the supremum of values \(\beta\in(0,1]\) for which, for every \(q\in\mathbb{R}^d\), the mass of types satisfying \(\beta\|x_i-p\|<\|x_i-q\|\) is at least the mass satisfying \(\beta\|x_i-p\|>\|x_i-q\|\), and \(\beta(\mu)=\sup_p\beta_\mu(p)\). Can this be done in time polynomial in \(\tau\), the input bit length \(L\), and \(1/\varepsilon\)?

Here \(\tau\ge1\) is the support size, not the number of possible types. The input also contains a binary rational \(\varepsilon\in(0,1/2]\); let \(L\) be the total input bit length.
For \(p\in\mathbb R^d\) and \(b\in(0,1]\), call \(p\) a \(b\)-plurality point if, for every \(q\in\mathbb R^d\), \(\sum_{i:b\|x_i-p\|_2<\|x_i-q\|_2}\mu_i\ge\sum_{i:b\|x_i-p\|_2>\|x_i-q\|_2}\mu_i\). Types at equality abstain; tied total masses are permitted.

Result

Yes. For every fixed \(d\), the requested proposal can be computed in time polynomial in \(\tau\) and \(L\). Thus the requested polynomial dependence on \(\tau,L,1/\varepsilon\) holds.

The proof uses an exact feasibility algorithm in fixed dimension, followed by binary search. It handles abstentions and tied total masses explicitly, and does not require the supremum defining \(\beta(\mu)\) to be attained.

1. The real-algebraic tool

We use the following standard consequence of sampled cylindrical algebraic decomposition, abbreviated CAD.

Fixed-dimensional CAD theorem. Fix the number of variables \(k\) and a degree bound \(D\). Given \(s\) integer polynomials in \(k\) variables, of degrees at most \(D\) and coefficient bit lengths at most \(T\), one can construct a complete sign-invariant CAD, for a prescribed variable order, in time polynomial in \(s,T\). The construction supplies the decompositions at every coordinate level, their projection relationships, and exact real-algebraic sample points of polynomial encoding length.

Here “sign-invariant” means that each input polynomial has constant sign on each cell. “Cylindrical” means, in particular, that every cell projects onto a cell at each preceding coordinate level. All cell dimensions are included.

These are standard CAD properties and complexity bounds; see [Basu–Pollack–Roy, *Cylindrical Decomposition Algorithm*](https://link.springer.com/chapter/10.1007/3-540-33099-2_12), and [Basu’s survey, Section 2.1.2](https://www.math.purdue.edu/~sbasu/raag_survey2011_final.pdf). For fixed \(k,D\), exact projection, algebraic arithmetic, and root isolation give polynomial bit complexity. No general-position hypothesis is required.

2. Exact feasibility for a prescribed rational value

Lemma. For fixed \(d\), given a rational \(b\in(0,1]\), one can decide whether a \(b\)-plurality point exists, and produce one if it does, in time polynomial in \(\tau,L,\operatorname{bits}(b)\).

Proof. Write each mass as \(\mu_i=a_i/c_i\), with positive integers \(a_i,c_i\). Define

\(H=\prod_{i=1}^{\tau}c_i,\qquad w_i=a_i(H/c_i).\)

Then \(w_i=H\mu_i\) and \(\sum_iw_i=H\). The binary length of \(H\) is at most the sum of the binary lengths of the denominators, hence is \(O(L)\). The weights and all their signed sums therefore have polynomial bit length.

For each support point, introduce the polynomial

\(F_i(p,q)=\sum_{j=1}^{d}(q_j-x_{ij})^2-b^2\sum_{j=1}^{d}(p_j-x_{ij})^2.\)

Because both distances are nonnegative,

  • \(F_i(p,q)>0\) means that type \(i\) strictly supports \(p\);
  • \(F_i(p,q)<0\) means that type \(i\) strictly supports \(q\);
  • \(F_i(p,q)=0\) means that type \(i\) abstains.

Consequently, the exact plurality condition is

\(\sum_{i=1}^{\tau}w_i\operatorname{sgn}F_i(p,q)\geq0\quad\text{for every }q\in\mathbb R^d.\)

Clear the denominators of each \(F_i\) by multiplying it by a positive integer. This preserves its sign. The resulting integer polynomials have degree at most \(2\), and coefficient bit lengths \(O_d(L+\operatorname{bits}(b))\).

Construct a complete sign-invariant CAD in the \(2d\) variables, ordered as

\(p_1,\ldots,p_d,q_1,\ldots,q_d.\)

For every cell \(C\) of this decomposition, compute

\(\Delta(C)=\sum_{i=1}^{\tau}w_i\sigma_i(C),\qquad \sigma_i(C)=\operatorname{sgn}(F_i|_C).\)

Call \(C\) bad exactly when \(\Delta(C)<0\). Equality is accepted.

Let \(A\) be a cell of the induced decomposition of the first \(d\) coordinates, namely proposal space. We claim that every point of \(A\) is feasible exactly when no bad cell projects onto \(A\).

To verify both directions:

  • If a bad cell \(C\) projects onto \(A\), then for every \(p\in A\), surjectivity of the projection supplies a \(q\) with \((p,q)\in C\). This competitor defeats \(p\).
  • If no bad cell projects onto \(A\), take any \(p\in A\) and any \(q\). The point \((p,q)\) belongs to a cell whose projection is \(A\). That cell is not bad, so the required mass inequality holds.

Thus feasibility is decided by inspecting the projection relationships. If a feasible proposal cell exists, return its algebraic sample point.

The CAD theorem applies with \(k=2d\), \(D=2\), \(s=\tau\), and coefficient bit length \(O_d(L+\operatorname{bits}(b))\). All these parameters satisfy its hypotheses. Label computation adds only polynomial-time integer arithmetic. The returned coordinates have standard exact algebraic encodings of polynomial length. This proves the lemma.

Including cells of every dimension is essential: a defeating competitor can lie on equality surfaces where some types abstain.

3. A positive feasible value of polynomial encoding length

We next construct a rational \(\alpha>0\) and an explicit \(\alpha\)-plurality point, with \(\operatorname{bits}(\alpha)=O_d(L)\).

If some \(\mu_j\geq1/2\), return \(p=x_j\) immediately. For \(b=1\), every \(q\neq p\) loses type \(j\), so the mass supporting \(p\) is at least \(1/2\), while the mass supporting \(q\) is at most \(1/2\). For \(q=p\), all types abstain. Therefore \(\beta_\mu(p)=1\), which is optimal. This includes the case \(\tau=1\).

For the remainder, assume \(\mu_i<1/2\) for every \(i\). In particular, \(\tau\geq3\). Define

\(\delta=\min_{i<j}\max_{1\leq k\leq d}|x_{ik}-x_{jk}|,\qquad M=\max_{i,k}|x_{ik}-x_{1k}|.\)

Distinctness gives \(\delta>0\), and \(M>0\). Moreover, \(\delta\leq M\): any pair consisting of \(x_1\) and another support point has coordinate distance at most \(M\).

Set

\(\alpha=\frac{\delta}{4dM},\qquad p_0=x_1.\)

Then \(0<\alpha\leq1/(4d)\). For every \(i\),

\(\alpha\|x_i-p_0\|_2\leq\alpha\sqrt d\,M\leq\alpha dM=\delta/4.\)

On the other hand, for distinct \(i,j\),

\(\|x_i-x_j\|_2\geq\max_k|x_{ik}-x_{jk}|\geq\delta.\)

Hence the closed balls centered at \(x_i\), with radii \(\alpha\|x_i-p_0\|_2\), are pairwise disjoint. Indeed, the sum of any two radii is at most \(\delta/2\), strictly smaller than their center distance.

Fix any competitor \(q\). At most one type can fail to strictly support \(p_0\): such a type must have \(q\) in its corresponding closed ball. If that type is \(i\), the mass strictly supporting \(p_0\) is at least \(1-\mu_i\), whereas the mass supporting \(q\) is at most \(\mu_i\). Since \(\mu_i<1/2\), the plurality inequality holds. If there is no such type, all types support \(p_0\).

Thus \(p_0\) is an \(\alpha\)-plurality point.

Finally, \(\delta\) and \(M\) are selected from rational coordinate differences. They and \(\alpha\) have bit lengths \(O_d(L)\), and can be computed with polynomially many exact rational operations. In particular,

\(\log(1/\alpha)=O_d(L).\)

4. Binary search and its guarantee

Let

\(\mathcal F=\{b\in(0,1]:\text{a }b\text{-plurality point exists}\},\qquad B=\beta(\mu).\)

Directly from the definitions,

\(B=\sup\mathcal F.\)

Indeed, \(\mathcal F\) is the union, over all proposals, of their feasible parameter sets; taking the supremum of this union equals taking the supremum of their individual suprema.

Feasibility is downward monotone. For fixed \(p,q,i\), decreasing \(b\) weakly increases \(F_i(p,q)\), hence weakly increases its sign. Since all masses are positive, it weakly increases the mass supporting \(p\) minus the mass supporting \(q\). Therefore, a \(b\)-plurality point is also a \(b'\)-plurality point whenever \(0<b'\leq b\).

Initialize

\(\ell=\alpha,\qquad u=1,\)

and store \(p_0\) as a witness for \(\ell\). Maintain these invariants:

  • the stored proposal is an \(\ell\)-plurality point;
  • \(\ell\leq B\leq u\).

While \(u-\ell>\varepsilon\alpha\), set \(m=(\ell+u)/2\) and run the feasibility algorithm.

  • If feasible, replace \(\ell\) by \(m\) and store the returned witness.
  • If infeasible, replace \(u\) by \(m\).

The latter update preserves \(B\leq u\): if \(B>m\), the definition of supremum would give a feasible \(b>m\), and downward monotonicity would make \(m\) feasible, a contradiction.

At termination, the stored proposal \(p\) satisfies

\(\beta_\mu(p)\geq\ell\geq B-\varepsilon\alpha\geq B-\varepsilon B=(1-\varepsilon)\beta(\mu),\)

where the penultimate inequality uses \(\alpha\leq B\).

This argument permits either inclusion or exclusion of the optimal endpoint from \(\mathcal F\).

5. Bit complexity

Each iteration halves the interval length. Consequently, the number of iterations is

\(O\!\left(\log\frac1{\varepsilon\alpha}\right)=O_d\!\left(L+\log\frac1\varepsilon\right).\)

After this many midpoint operations, every queried rational has bit length \(O_d(L+\log(1/\varepsilon))\): denominators acquire only one additional factor of \(2\) per iteration.

Each feasibility call therefore takes polynomial time in \(\tau,L,\log(1/\varepsilon)\), and so does the whole algorithm. Since the binary encoding of \(\varepsilon\) is included in \(L\), we have \(\log(1/\varepsilon)=O(L)\). The total running time is consequently

\((\tau+L)^{O_d(1)}.\)

Binary mass magnitudes affect only exact integer label arithmetic; the support size controls the number of defining polynomials. The resulting proposal has a polynomial-length exact real-algebraic encoding and satisfies the requested guarantee.
