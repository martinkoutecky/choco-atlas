Theorem 4.3 — class: hardness

The continuous mirror question, as graded

Given finite \(T\), rational masses μ_t≥0 summing to \(1\), and a symmetric rational affinity matrix \(a_{ts}\), let an atomless population have type-\(t\) mass μ_t. Does there exist a measurable partition ℱ such that no positive-mass measurable set \(X\) has almost every member strictly prefer forming \(X\), with utility \(u_t(X)=\sum_{s\in T}a_{ts}q_s(X)\), to their current coalition in ℱ?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). The support size \(\tau\) counts listed types, not all possible types.
The remaining input is a symmetric matrix \(A=(a_{ts})_{t,s\in T}\) of arbitrary signed binary rationals, including arbitrary diagonal entries. Let \(L\) be the total input bit length; the matrix dimension is \(m=\tau\). State running times in \(m,\tau,L\).
Represent the population by \([0,1]\) with Lebesgue measure \(\lambda\), partitioned into type intervals \(I_t\) of lengths \(\mu_t\); write \(t(x)\) for the type of individual \(x\).
For every measurable coalition \(C\), define its absolute type masses by \(q_s(C)=\lambda(C\cap I_s)\) and utilities by \(u_t(C)=\sum_{s\in T}a_{ts}q_s(C)\). These masses are not normalized by coalition size; null coalitions have zero utility.
An admissible partition \(\mathcal F\) consists of nonempty measurable coalitions covering the population, with no restriction on their number; singleton coalitions and splitting a type among coalitions are allowed. Let \(\mathcal F(x)\) denote the coalition containing \(x\).
A measurable set \(X\) blocks \(\mathcal F\) if \(\lambda(X)>0\) and \(u_{t(x)}(X)>u_{t(x)}(\mathcal F(x))\) for \(\lambda\)-almost every \(x\in X\). Members may come from any existing coalitions; indifference does not count as improvement. A partition is core stable if no such set exists.

Is deciding whether an admissible core-stable partition exists solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For finite symmetric additively separable hedonic games, core-stable partition existence is \(\Sigma_2^p\)-complete even on graphs of vertex cover number \(12\). [Source](https://drops.dagstuhl.de/storage/00lipics/lipics-vol322-isaac2024/LIPIcs.ISAAC.2024.39/LIPIcs.ISAAC.2024.39.pdf)
No result settling this exact atomless decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Defined the unspecified q_s(X) as absolute type-s mass, preserving additive rather than average utilities.
  • Made measurable partition mean a partition into nonempty measurable cells, without a cardinality restriction; allowed null cells and singletons, preserving the discrete option of remaining alone.
  • Chose the unit interval with Lebesgue measure and type intervals as a concrete atomless population representation.
  • Retained arbitrary signed rational diagonal affinities: these describe interactions between distinct individuals of the same type, while an individual's own mass is zero.
  • Removed zero-mass types from the supplied list to enforce support-based input encoding.
  • Identified m with the affinity-matrix dimension τ because this problem has no separate candidate or alternative dimension.

Result

The decision problem is \(\mathrm{NP}\)-hard. In fact, it is \(\Sigma_2^p\)-hard under polynomial-time many-one reductions.

This holds even when all masses are equal dyadic rationals and \(A\) is an integer symmetric matrix with the same positive entry on every diagonal position.

The proof establishes two implications for a suitable transformation of finite games:

\[ \text{finite strict core nonempty} \Longrightarrow \text{atomless core nonempty} \Longrightarrow \text{finite core nonempty}. \]

We then apply a known finite-game reduction whose yes-instances have a nonempty strict core and whose no-instances have an empty core.

1. The finite hardness result used

For a finite game on \(N\), let \(w_{ij}=w_{ji}\) be integer weights, with \(w_{ii}=0\), and define

\(v_i(S)=\sum_{j\in S\setminus\{i\}}w_{ij}\).

A finite partition \(P\) is core stable if no nonempty \(S\subseteq N\) satisfies \(v_i(S)>v_i(P(i))\) for every \(i\in S\). It is strict-core stable if no \(S\) satisfies these inequalities weakly for every member and strictly for at least one member.

We use the following precise feature of Peters’s reduction: a polynomial-time transformation from a \(\Sigma_2^p\)-complete quantified-formula problem produces symmetric integer games \(G_\Phi\) satisfying

\(\Phi\text{ is true}\Longleftrightarrow G_\Phi\text{ has a strict-core-stable partition}\Longleftrightarrow G_\Phi\text{ has a core-stable partition}\).

These equivalences hold for the same constructed game, as established by equivalences (i)–(iii) in the proof of [Peters, Theorem 2](https://arxiv.org/pdf/1509.02333).

We may pad such a game with isolated agents so that its number \(n\) of agents is a power of two and \(n\geq 2\). This preserves both core-existence properties. Indeed, deleting isolated agents does not change original agents’ utilities. Conversely, extend any original stable partition by isolated singletons. An isolated agent cannot strictly improve, and any weak blocker containing an improving original agent would project to a weak blocker in the original game.

2. Construction of the atomless instance

Let \(G\) be any padded finite symmetric integer game on \(N=\{1,\ldots,n\}\). Set

\(B=\max\bigl(\{1\}\cup\{|w_{ij}|:i\neq j\}\bigr),\qquad K=(n-1)B,\qquad H=4(K+1)^2.\)

In particular,

\(H>2K^2,\qquad H>2K.\)

Create one listed type per finite agent, with

\(\mu_i=1/n,\qquad a_{ii}=nH,\qquad a_{ij}=nw_{ij}\quad(i\neq j).\)

Thus \(m=\tau=n\), the masses are positive dyadic rationals summing to \(1\), and \(A\) is symmetric.

For any measurable coalition \(C\), write

\(z_i(C)=n\lambda(C\cap I_i)\).

Then \(0\leq z_i(C)\leq 1\), and its utility is exactly

\(u_i(C)=Hz_i(C)+\sum_{j\neq i}w_{ij}z_j(C).\)

The contribution from other types always has absolute value at most \(K\):

\(\left|\sum_{j\neq i}w_{ij}z_j(C)\right|\leq K.\)

We prove both implications announced above for this construction.

3. A finite strict-core partition gives an atomless core partition

Suppose \(P\) is strict-core stable in \(G\). Form the atomless partition

\(\mathcal F_P=\left\{\bigcup_{i\in S}I_i:S\in P\right\}.\)

Every individual of type \(i\) receives the constant incumbent utility \(H+v_i(P(i))\).

Assume, for contradiction, that a measurable \(X\) blocks \(\mathcal F_P\). Put

\(S=\{i:z_i(X)>0\},\qquad d_i=1-z_i(X)\quad(i\in S).\)

Since \(\lambda(X)>0\), the finite set \(S\) is nonempty. For each \(i\in S\), a positive measure of type \(i\) belongs to \(X\), so the almost-everywhere blocking condition requires the strict numerical inequality

\(g_i:=u_i(X)-H-v_i(P(i))>0.\)

Define the integer

\(\Delta_i=v_i(S)-v_i(P(i)).\)

Expanding the utility gives

\(g_i=\Delta_i-Hd_i-\sum_{j\in S\setminus\{i\}}w_{ij}d_j.\)

Bounding the omitted fractions

The new utility is at most \(H(1-d_i)+K\), whereas the incumbent utility is at least \(H-K\). Hence \(g_i>0\) implies

\(Hd_i<2K.\)

Consequently, with \(d_*=\max_{i\in S}d_i\),

\(d_*<2K/H.\)

No participant can be worse off in the finite coalition

If \(\Delta_i<0\), integrality gives \(\Delta_i\leq -1\). Therefore

\(g_i\leq -1+Kd_*<-1+2K^2/H<0,\)

contradicting \(g_i>0\). Thus \(\Delta_i\geq 0\) for every \(i\in S\).

Strict-core stability of \(P\) now implies \(\Delta_i=0\) for every \(i\in S\): otherwise \(S\) would weakly improve every member and strictly improve at least one.

Choose \(i_*\in S\) with \(d_{i_*}=d_*\). Since all \(\Delta_i\) vanish,

\(g_{i_*}=-Hd_*-\sum_{j\in S\setminus\{i_*\}}w_{i_*j}d_j\leq -(H-K)d_*\leq 0.\)

This again contradicts blocking, including when \(d_*=0\). Therefore \(\mathcal F_P\) is core stable.

Proved implication: finite strict-core existence implies atomless core existence.

4. An arbitrary atomless core partition gives a finite core partition

Suppose the constructed atomless instance has a core-stable admissible partition \(\mathcal F\). We allow arbitrary splitting, arbitrarily many coalitions, and null coalitions.

Each type has a coalition containing almost all its mass

There are at most countably many positive-measure coalitions: for each positive integer \(r\), at most \(r\) disjoint coalitions can have measure at least \(1/r\).

This also makes incumbent utilities measurable. On the countably many positive-measure coalitions they are constant for each type; elsewhere the incumbent coalition is null and its utility is zero.

The pure-type coalition \(I_i\) gives its members utility \(H\). Since it does not block, the measurable set

\(E_i=\{x\in I_i:u_i(\mathcal F(x))\geq H\}\)

has positive measure. Null incumbent coalitions have utility zero, so \(E_i\) lies in the union of the positive-measure coalitions. Countability therefore supplies a coalition \(D_i\in\mathcal F\) such that \(\lambda(E_i\cap D_i)>0\).

Its type-\(i\) utility is at least \(H\). The bound on other-type contributions gives

\(H\leq Hz_i(D_i)+K,\)

and hence, writing \(\varepsilon=K/H\),

\(z_i(D_i)\geq 1-\varepsilon.\)

Because \(\varepsilon<1/2\), at most one coalition can satisfy this inequality for a given type: two disjoint such coalitions would together contain more than its total mass. Thus \(D_i\) is uniquely determined.

Forming the finite partition

Define a partition \(P\) of \(N\) by

\(P(i)=\{j:D_j=D_i\}.\)

For every \(j\),

\(\left|z_j(D_i)-\mathbf 1_{\{j\in P(i)\}}\right|\leq\varepsilon.\)

Indeed, if \(D_j=D_i\), its mass is between \(1-\varepsilon\) and \(1\). If \(D_j\neq D_i\), disjointness gives

\(z_j(D_i)\leq 1-z_j(D_j)\leq\varepsilon.\)

Therefore

\(\left|\sum_{j\neq i}w_{ij}z_j(D_i)-v_i(P(i))\right|\leq K\varepsilon.\)

A finite blocker would produce an atomless blocker

Suppose \(S\subseteq N\) blocks \(P\). Since all finite utilities are integers,

\(v_i(S)-v_i(P(i))\geq 1\qquad(i\in S).\)

Construct the measurable coalition

\(X=\bigcup_{i\in S}(I_i\cap D_i).\)

It has positive measure. For every \(j\in S\), it takes exactly the type-\(j\) mass from \(D_j\); for \(j\notin S\), it takes none. Consequently,

\(\left|\sum_{j\neq i}w_{ij}z_j(X)-v_i(S)\right|\leq K\varepsilon\qquad(i\in S).\)

Every type-\(i\) member of \(X\) comes from \(D_i\). Also \(z_i(X)=z_i(D_i)\), so the diagonal contributions cancel exactly when comparing new and incumbent utilities. Using the two error bounds,

\(u_i(X)-u_i(D_i)\geq v_i(S)-v_i(P(i))-2K\varepsilon\geq 1-2K^2/H>0.\)

Thus every member of \(X\) strictly improves, contradicting core stability of \(\mathcal F\).

Therefore \(P\) is core stable.

Proved implication: atomless core existence implies finite core existence.

5. Hardness and bit complexity

Apply the construction to the padded game \(G_\Phi\) from Section 1.

If \(\Phi\) is true, \(G_\Phi\) has a strict-core-stable partition, so Section 3 supplies an atomless core-stable partition.

If the atomless instance has a core-stable partition, Section 4 supplies a finite core-stable partition of \(G_\Phi\), so \(\Phi\) is true.

We have therefore proved the exact equivalence

\(\Phi\text{ is true}\Longleftrightarrow\text{the constructed atomless instance has an admissible core-stable partition}.\)

For the size bound, let

\(\beta=1+\lceil\log_2 n\rceil+\lceil\log_2 B\rceil.\)

Every output matrix entry and mass has bit length \(O(\beta)\), because \(H=O(n^2B^2)\). Thus

\(m=\tau=n,\qquad L=O(m^2\beta).\)

The finite-to-atomless transformation takes \(O(m^2\beta^2)\) bit operations using schoolbook integer arithmetic. This is polynomial in \(m=\tau\) and \(L\), and also polynomial in the finite input length. Composing it with Peters’s polynomial-time reduction proves \(\Sigma_2^p\)-hardness, and hence \(\mathrm{NP}\)-hardness.

Accordingly, a decision algorithm running in \((m+\tau+L)^{O(1)}\) time would imply \(\mathrm P=\mathrm{NP}\).

The definitions of finite core stability and strict-core stability match those needed by the argument: core blocking requires every member to improve strictly; strict-core blocking requires every member to improve weakly and at least one strictly.

The critical citation is accurate. Peters’s proof of Theorem 2 explicitly establishes equivalence between formula truth, strict-core existence, and core existence for the same symmetric additive game. Padding by isolated agents preserves both existence properties:

Padding to the next power of two increases the number of agents by at most a constant factor. Requiring at least two agents also causes no difficulty.

The constructed instance satisfies the task’s input restrictions. There are exactly \(n\) listed types, each with positive dyadic mass \(1/n\); the masses sum to one. The matrix is symmetric and integral, with the same positive diagonal entry \(nH\).

\(u_i(C)=Hz_i(C)+\sum_{j\ne i}w_{ij}z_j(C)\).

3. Finite strict core implies atomless core

The expansion

Assessment: The first implication is fully established. The use of the finite strict core, rather than merely the finite core, is justified and essential to the written argument.

4. Atomless core implies finite core

The treatment of arbitrary admissible partitions is sound. Positive-measure coalitions are countable by the stated measure bound. Incumbent utilities are measurable because they are constant on each measurable type intersection with these coalitions and zero on the measurable complement of their union. This does not require the union of an arbitrary family of null coalitions to be independently measurable.

For each type, failure of \(I_i\) to block implies that \(E_i\) has positive measure. Otherwise its members would strictly prefer utility \(H\) almost everywhere. Null incumbent coalitions give zero utility, so countability supplies the stated coalition \(D_i\).

The bound \(z_i(D_i)\geq1-\varepsilon\) follows correctly. Uniqueness holds because \(2(1-\varepsilon)>1\). Equality of the coalitions \(D_i\) therefore defines a finite partition.

Both mass approximation cases are valid: a type assigned to \(D_i\) contributes at least \(1-\varepsilon\), while a type assigned elsewhere contributes at most \(\varepsilon\). The resulting weighted error is at most \(K\varepsilon\).

For a finite blocker, integrality supplies improvement at least one. The constructed \(X\) is a finite union of measurable sets and has positive measure. Each participating type contributes exactly its mass in its own \(D_i\), so the diagonal terms cancel exactly. The two off-diagonal error bounds give

\(u_i(X)-u_i(D_i)\geq1-2K^2/H>0\).

Every member of \(X\) has the incumbent coalition used in this comparison. Thus \(X\) blocks, producing the required contradiction.

Assessment: The second implication is fully established without imposing any additional restrictions on admissible partitions.
