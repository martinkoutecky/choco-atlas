The continuous mirror question, as graded

Given finite patient-donor types \(\mathcal T\), object types \(\mathcal O\), rational masses \(\mu_t\), an endowment map \(e\), weak preferences \(R_t\), acceptability, and rational weights \(w_{to}\), find \(x_{to}\geq0\) with \(\sum_o x_{to}=\mu_t\), \(\sum_{t:e(t)=o}\mu_t\) supplied to object type \(o\), and zero mass on unacceptable assignments, maximizing \(\sum_{t,o}w_{to}x_{to}\) or deciding feasibility, subject to there being no positive-mass blocking deviation: no \(q_{to}\leq x_{to}\) and \(z_{t,o,o'}\geq0\) with \(\sum_{o'}z_{t,o,o'}=q_{to}\), \(\sum_{t,o}z_{t,o,o'}=\sum_{t:e(t)=o'}\sum_o q_{to}\), positive support only on \(o'R_to\), and positive mass on some \(o'P_to\).

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal O\) contain \(m\geq2\) object types. A society is given by its support: the list \(\mathcal T\) of its \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has an endowment \(e(t)\in\mathcal O\) and a complete, transitive weak preference relation \(R_t\); write \(P_t\) for its strict part. Every object type has positive endowed mass. Object \(o\) is acceptable to \(t\) exactly when \(oR_te(t)\); ties are retained.
An allocation is a real matrix \(x\geq0\) satisfying \(\sum_o x_{to}=\mu_t\), \(\sum_t x_{to}=\sum_{t:e(t)=o}\mu_t\), and \(x_{to}=0\) on unacceptable assignments. Exchanges have no length bound.
A blocking deviation consists of real arrays \(0\leq q_{to}\leq x_{to}\) and \(z_{t,o,o'}\geq0\) satisfying \(\sum_{o'}z_{t,o,o'}=q_{to}\) and \(\sum_{t,o}z_{t,o,o'}=\sum_{t:e(t)=o'}\sum_o q_{to}\) for every \(o'\).
Require \(z_{t,o,o'}=0\) unless \(o'R_to\), and \(\sum_{t,o,o':\,o'P_to}z_{t,o,o'}>0\). Thus selected mass trades its original endowments, with every selected portion weakly improving and positive mass strictly improving. An allocation is in the mass strong core when no such deviation exists.
Given arbitrary rational weights \(w_{to}\) and a rational threshold \(B\), the weight-threshold problem asks whether a mass strong-core allocation satisfies \(\sum_{t,o}w_{to}x_{to}\geq B\); feasibility omits this inequality. Let \(L\) be the total input bit length.

Result

Both mass strong-core feasibility and the mass strong-core weight-threshold problem belong to \(\mathrm P\).

A conservative running-time bound for either problem is
\(O((m+\tau)^3L^2)\) bit operations. The algorithm works directly with the listed types and rational masses.

The key result is that the mass strong core is exactly a transportation polytope whose permitted assignments can be computed from preferences and endowments.

1. Blocking deviations are characterized by directed cycles

Write \(c_a=\sum_{t:e(t)=a}\mu_t\) for the endowed mass of object \(a\).

For a feasible allocation \(x\), construct a directed multigraph \(G_x\) on \(\mathcal O\). For every positive cell \(x_{to}\) and every object \(b\) satisfying \(bR_to\), include an edge from \(e(t)\) to \(b\), labelled by \((t,o,b)\). Mark that edge strict exactly when \(bP_to\).

Lemma 1. An allocation \(x\) is blocked if and only if \(G_x\) contains a directed cycle with a strict edge.

Proof. Suppose first that a blocking deviation \((q,z)\) exists. Define
\(h_{ab}=\sum_{t:e(t)=a}\sum_o z_{t,o,b}\).

The deviation equations imply
\(\sum_b h_{ab}=\sum_{t:e(t)=a}\sum_o q_{to}=\sum_b h_{ba}\).
Thus \(h\) is a nonnegative circulation.

Choose a positive strict entry \(z_{t,o,b}\), and put \(a=e(t)\). The positive edge \(a\to b\) belongs to a directed cycle of positive \(h\)-edges. To justify this, let \(W\) be the vertices reachable from \(b\) using positive edges. If \(a\notin W\), then no positive edge leaves \(W\), whereas \(a\to b\) supplies positive flow into \(W\), contradicting circulation balance summed over \(W\).

Choose a simple return path from \(b\) to \(a\). Each of its edges has a positive \(z\)-entry providing a label in \(G_x\), because positive \(z_{t,o,b}\) implies \(x_{to}>0\). Together with the chosen strict edge, these labels give the required cycle.

Conversely, suppose a simple directed cycle has labels \((t_i,o_i,b_i)\), where \(b_i=e(t_{i+1})\), with indices interpreted cyclically. Choose
\(0<\varepsilon\leq\min_i x_{t_i o_i}\).
Select mass \(\varepsilon\) from each indicated cell and send it to \(b_i\).

The sources on a simple cycle are distinct, so the selected cells are distinct. Each cycle vertex supplies and receives exactly \(\varepsilon\) units of its object. Consequently all deviation equations hold. Every selected portion weakly improves, and the strict edge supplies positive strict improvement. A strict self-loop is handled by the same construction. ∎

This lemma uses real portions of mass; it requires no discrete-agent interpretation.

2. Compute a partition using all top-choice ties

For a nonempty set \(U\subseteq\mathcal O\), retain the types whose endowments lie in \(U\), and define
\(\operatorname{Top}_t(U)=\{b\in U:bR_ta\text{ for every }a\in U\}\).

Construct a directed graph \(D_U\) on \(U\), with an edge \(e(t)\to b\) for every retained type \(t\) and every \(b\in\operatorname{Top}_t(U)\). All ties are included.

Starting with \(U_1=\mathcal O\), repeatedly perform the following steps:

  • Choose any sink strongly connected component \(S_i\) of \(D_{U_i}\).
  • For every type with \(e(t)\in S_i\), permit exactly the assignments to \(\operatorname{Top}_t(U_i)\).
  • Set \(U_{i+1}=U_i\setminus S_i\), continuing until no objects remain.

A sink component exists in every finite nonempty directed graph. Moreover, if \(e(t)\in S_i\), then
\(\operatorname{Top}_t(U_i)\subseteq S_i\):
otherwise a top-choice edge would leave the sink component.

The procedure produces a partition \(S_1,\ldots,S_k\), with \(k\leq m\), and a permitted assignment set
\(F=\bigcup_{i=1}^k\{(t,b):e(t)\in S_i,\ b\in\operatorname{Top}_t(U_i)\}\).

Every permitted assignment is acceptable: \(e(t)\in U_i\), so a top object in \(U_i\) is weakly preferred to \(e(t)\).

3. Necessity: every core allocation uses only permitted assignments

Lemma 2. Every mass strong-core allocation \(x\) satisfies \(x_{to}=0\) whenever \((t,o)\notin F\).

Proof. Consider first \(U_1=\mathcal O\). Every edge of \(D_{U_1}\) is present in \(G_x\): a globally top object is weakly preferred to every object assigned to its type.

Suppose a type with \(e(t)\in S_1\) receives positive mass of an object \(o\notin\operatorname{Top}_t(U_1)\). For any \(b\in\operatorname{Top}_t(U_1)\), completeness and transitivity give \(bP_to\). Thus \(G_x\) has a strict edge \(e(t)\to b\).

Both endpoints lie in \(S_1\), and strong connectivity supplies a return path in \(D_{U_1}\), hence in \(G_x\). Lemma 1 then gives a blocking deviation, a contradiction.

Therefore every type endowed in \(S_1\) receives only top objects in \(S_1\). Those types have total mass
\(\sum_{t:e(t)\in S_1}\mu_t=\sum_{o\in S_1}c_o\).
They consequently consume all the supply in \(S_1\). Nonnegativity and column feasibility imply that no type endowed outside \(S_1\) receives any object in \(S_1\).

The restriction of \(x\) to \(U_2\) and its endowed types is therefore feasible. It also has no blocking deviation: any deviation in the restriction extends to the original instance by setting all other entries to zero.

Repeat the argument on this restriction. Every edge of \(D_{U_2}\) is weakly improving relative to each retained type’s assigned objects, because those assignments lie in \(U_2\). Strong connectivity again forces the types endowed in \(S_2\) to receive only their top objects in \(U_2\), and mass balance separates that block from the remainder.

Induction proves the assertion for every block. Normalization of the remaining total mass is unnecessary. ∎

4. Sufficiency: every feasible allocation on these assignments is in the core

Lemma 3. Every feasible allocation supported on \(F\) belongs to the mass strong core.

Proof. Let \(x_{to}>0\), with \(e(t)\in S_i\). Then \(o\in\operatorname{Top}_t(U_i)\).

If \(bR_to\) and \(b\in U_i\), transitivity implies that \(b\) is also top in \(U_i\). Therefore \(b\in S_i\). If \(bP_to\), then \(b\notin U_i\), so \(b\) belongs to an earlier block.

Consequently every edge of \(G_x\) goes from block \(S_i\) to some block \(S_j\) with \(j\leq i\), and every strict edge has \(j<i\).

Along a directed cycle, block indices cannot decrease strictly: they must return to their starting value. Hence no directed cycle contains a strict edge. Lemma 1 proves that \(x\) is unblocked. ∎

Together, Lemmas 2 and 3 give the exact characterization:
the mass strong core consists of the nonnegative matrices satisfying the original row and column equations and vanishing outside \(F\).

Thus it is a rational transportation polytope. Feasibility is a transportation feasibility problem, and weight optimization is linear optimization over this polytope.

5. An exact flow algorithm for both problems

The following construction also gives an explicit bit-complexity bound.

Let \(D\) be the product of the denominators of the masses, and set
\(a_t=D\mu_t\) and \(d_o=Dc_o=\sum_{t:e(t)=o}a_t\).
These are positive integers, and
\(\sum_t a_t=\sum_o d_o=D\).
All these integers have \(O(L)\) bits.

For the weight-threshold problem, let \(H\) be the product of the denominators of all weights and \(B\). Define
\(v_{to}=Hw_{to}\),
\(W=\max_{(t,o)\in F}v_{to}\), and
\(C_{to}=W-v_{to}\) for \((t,o)\in F\).

These are integer costs with \(C_{to}\geq0\). Write
\(C_{\max}=\max_{(t,o)\in F}C_{to}\) and \(M=DC_{\max}+1\).

Build an uncapacitated minimum-cost flow network as follows:

  • Each type node \(t\) has supply \(a_t\).
  • Each object node \(o\) has demand \(d_o\).
  • Each permitted pair \((t,o)\in F\) gives an arc \(t\to o\) of cost \(C_{to}\).
  • Add an auxiliary node \(r\) of balance zero, and arcs in both directions between \(r\) and every other node, each of cost \(M\).

This network is strongly connected and always feasible: supply can travel from type nodes through \(r\) to object nodes. All costs are nonnegative integers.

Compute an integral minimum-cost flow, optimal also among real flows.

The original core is nonempty exactly when the returned flow uses no auxiliary arc.

Indeed, a core allocation gives a real flow on the permitted arcs after multiplication by \(D\). Its total cost is at most \(DC_{\max}\). Any integral flow using an auxiliary arc has cost at least \(M>DC_{\max}\). Therefore, whenever a core allocation exists, an integral optimum of the augmented network uses no auxiliary arc. Conversely, a flow using no auxiliary arc, divided by \(D\), satisfies precisely the core’s transportation constraints.

When feasible, the returned flow minimizes cost over all real flows on the permitted arcs. If its cost is \(K\), its allocation’s weight is
\((DW-K)/(DH)\).
Hence the threshold answer is yes exactly when
\(DW-K\geq D(HB)\),
an exact integer comparison.

For feasibility alone, use zero costs on permitted arcs and cost \(1\) on auxiliary arcs.

6. Running time and numerical bounds

The partition can be constructed in \(O(m^2\tau)\) graph operations after reading the preferences: there are at most \(m\) rounds, and each round scans at most \(\tau m\) type-object pairs and computes strongly connected components.

The flow network has
\(N=\tau+m+1\) vertices and
\(E\leq\tau m+2(\tau+m)=O(N^2)\) arcs.

We use the classical right-hand-side scaling minimum-cost flow algorithm. For a strongly connected uncapacitated network with nonnegative costs and integral balanced supplies bounded in absolute value by \(U\), it returns an integral optimum using \(O(N\log(2+U))\) shortest-path computations, maintaining nonnegative residual reduced costs. These are exactly the hypotheses verified above. See Section 3 of [Orlin’s minimum-cost flow paper](https://personal.math.ubc.ca/~anstee/math523/StronglyPolynomialNetworkFlow.pdf).

Here \(U\leq D\), so \(\log(2+U)=O(L)\). Dense Dijkstra takes \(O(N^2+E)=O(N^2)\) arithmetic operations per computation. Thus the flow computation uses \(O(N^3L)\) arithmetic operations.

For completeness, their operands have \(O(L)\) bits:

  • Scaling increments are bounded by \(2D\), and there are \(O(NL)\) augmentations, so stored flows are bounded by \(O(NLD)\).
  • Normalize node potentials so the auxiliary node’s potential is zero. Both auxiliary arcs remain available because they are uncapacitated. Nonnegative reduced costs then imply that every other potential has absolute value at most \(M\).
  • Every residual reduced cost is therefore at most \(3M\), and a shortest-path distance is at most \(3NM\).

Since \(D\) and \(M\) have \(O(L)\) bits and \(N=O(L)\), all these quantities have \(O(L)\) bits. Additions, subtractions, comparisons, and scaling operations consequently cost \(O(L)\) bit operations each.

Clearing denominators and constructing costs also take polynomial time within the stated bound. Including preference processing gives, for either problem,
\(O((m+\tau)^3L^2)\) bit operations.

7. Feasibility can fail even with strict preferences over object types

Consider objects \(A,B\) and three types:

| Type | Endowment | Mass | Preference |
|---|---|---|---|
| \(t_1\) | \(A\) | \(\frac14\) | \(B\,P_{t_1}\,A\) |
| \(t_2\) | \(A\) | \(\frac14\) | \(A\,P_{t_2}\,B\) |
| \(t_3\) | \(B\) | \(\frac12\) | \(A\,P_{t_3}\,B\) |

The top-choice graph is strongly connected, so the characterization forces all types to receive their global top objects. Types \(t_2,t_3\) then require \(\frac34\) units of \(A\), whereas only \(\frac12\) units are endowed. The mass strong core is empty.

Thus polynomial-time feasibility is a substantive decision problem, even under strict preferences over object types.
