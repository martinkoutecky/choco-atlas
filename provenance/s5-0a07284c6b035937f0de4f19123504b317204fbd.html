The continuous mirror question, as graded

Given a shared ontology \(O=(D,\Sigma)\), a conjunctive query \(q\), a candidate answer \(a\), a finite supported set \(T\) of consistent user types with possibilistic networks \(\Gamma_t\), binary-rational masses \(\mu_t>0\) summing to \(1\), and a rational threshold \(\theta\), decide whether \(\sum_{t:\,a\in S_t(q)}\mu_t\ge\theta\), where \(S_t(q)\) is the set of skyline answers under \((O,\Gamma_t)\).

Packaged proof task (what the prover saw — nothing else)

Fix a finite program \(\Sigma\) of full TGDs and negative constraints; the database \(D\), query, and preference networks vary. Write \(O=(D,\Sigma)\), and let \(q(\mathbf{x})=\exists\mathbf{y}\,\varphi(\mathbf{x},\mathbf{y})\) be a CQ and \(a\) a tuple of constants of the appropriate arity.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types; require \(\sum_{t\in T}\mu_t=1\).
Each type supplies a possibilistic network \(\Gamma_t\): a DAG on variables \(V_t\), pairwise disjoint finite domains containing at least two ground atoms each, and explicit conditional possibility tables with binary-rational entries in \([0,1]\). All atoms in a variable's domain have its associated predicate; each conditional table row has maximum \(1\).
An outcome \(o\) selects one atom per variable. Set \(O_o=(D\cup\{o(X):X\in V_t\},\Sigma)\) and \(\pi_t(o)=\prod_{X\in V_t}\pi_t(o(X)\mid o(\operatorname{pa}(X)))\). An outcome is consistent when \(O_o\) has a model. Promise that each type has a consistent outcome and that consistent outcomes whose augmented ontologies have identical model sets have equal possibility values.
Each type also supplies a predicate-preserving bijection \(\beta_t\) from a selected subset \(\varphi_t\) of query atoms to a subset of \(V_t\). Let \(\mathbf{y}_t\) be the quantified variables occurring in \(\varphi_t\), and \(\overline{\mathbf{y}}_t=\mathbf{y}\setminus\mathbf{y}_t\).
For a consistent outcome, define \(A_t(o)\) as the tuples \(b\) for which a substitution \(h\) of \(\mathbf{x}\cup\mathbf{y}_t\) by constants satisfies \(h(\mathbf{x})=b\), \(D\cup\Sigma\models\exists\overline{\mathbf{y}}_t\,h(\varphi)\), and \(h(\alpha)=o(\beta_t(\alpha))\) for every \(\alpha\in\varphi_t\).
Define \(S_t(q)\) as the union of \(A_t(o)\) over consistent outcomes having no consistent outcome \(o'\) with \(A_t(o')\ne\varnothing\) and \(\pi_t(o')>\pi_t(o)\); ties are retained. Given binary-rational \(\theta\), the decision problem asks whether \(\sum_{t:\,a\in S_t(q)}\mu_t\ge\theta\).
Let \(m=\max_{t\in T}|V_t|\) and \(L\) be the total binary input length, including all domains, tables, mappings, masses, and the threshold; express running times in \(m,\tau,L,|D|,|q|,|a|\).

Is this mass-threshold skyline-membership problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard, under the fixed-program convention above?

Single-user CQ skyline membership with full TGDs and negative constraints is \(\Delta_2^{\mathrm{P}}\)-hard, and belongs to \(\Delta_2^{\mathrm{P}}\), in fixed-program complexity. [Source](https://lat.inf.tu-dresden.de/research/reports/2016/BFLST-LTCS-16-10.pdf)
No result for this exact distribution-over-types threshold problem was identified in the literature search.

1. Result. Under the exact definitions and promises in the question, the problem is \(\mathrm{NP}\)-complete in fixed-program complexity. In particular, it is \(\mathrm{NP}\)-hard.

The upper bound holds for every fixed program \(\Sigma\). Hardness holds already for \(\Sigma=\varnothing\), a fixed database, one type, one network variable, and a nonempty query-to-network mapping.

The key point is that the model-equivalence promise makes skyline membership independent of the possibility values.

2. A collapse lemma for skyline membership.

Fix a type \(t\). Write \(W_t=\beta_t(\varphi_t)\) for its mapped network variables. Define \(C_t(q)\) to contain precisely those tuples \(b\) for which there exists a substitution \(h\) satisfying:

  • \(h(\mathbf{x})=b\);
  • \(D\cup\Sigma\models\exists\overline{\mathbf{y}}_t\,h(\varphi)\);
  • \(h(\alpha)\in\operatorname{Dom}(\beta_t(\alpha))\) for every \(\alpha\in\varphi_t\).

Thus \(C_t(q)\) imposes the answer conditions and mapped-domain restrictions, without specifying an outcome.

Lemma. On promised inputs, \(S_t(q)=C_t(q)\).

*Proof.* First, every tuple in any \(A_t(o)\) satisfies these three conditions. Consequently, \(S_t(q)\subseteq C_t(q)\).

For the reverse inclusion, observe that whenever \(h\) satisfies condition 2, every mapped atom \(h(\alpha)\) is entailed by \(D\cup\Sigma\). Indeed, all variables occurring in \(\alpha\) belong to \(\mathbf{x}\cup\mathbf{y}_t\), so \(h(\alpha)\) is ground. It is a conjunct of \(h(\varphi)\), independent of the remaining existentially quantified variables. Therefore

\(D\cup\Sigma\models\exists\overline{\mathbf{y}}_t\,h(\varphi)\quad\Longrightarrow\quad D\cup\Sigma\models h(\alpha).\)

Now take \(b\in C_t(q)\), witnessed by \(h\). By the consistency promise, there is a consistent outcome \(o_0\). Construct an outcome \(\widehat{o}\) by replacing each mapped value \(o_0(\beta_t(\alpha))\) with \(h(\alpha)\), while retaining every unmapped value.

This outcome is consistent: every model of \(O_{o_0}\) satisfies the retained atoms and also the replacement atoms, because the latter are consequences of \(D\cup\Sigma\). Moreover, \(b\in A_t(\widehat{o})\).

Hence the finite set

\(F_t=\{o:o\text{ is consistent and }A_t(o)\ne\varnothing\}\)

is nonempty. Choose \(o^\star\in F_t\) maximizing \(\pi_t(o^\star)\).

Construct \(o_b\) by retaining the unmapped values of \(o^\star\) and replacing its mapped values with those prescribed by \(h\). Because \(A_t(o^\star)\ne\varnothing\), the observation above shows that every mapped atom of \(o^\star\) is already entailed by \(D\cup\Sigma\). The replacement atoms are also entailed. Thus

\(\operatorname{mods}(O_{o^\star})=\operatorname{mods}(O_{o_b}).\)

Both outcomes are consistent. The model-equivalence promise therefore gives

\(\pi_t(o_b)=\pi_t(o^\star).\)

Since \(b\in A_t(o_b)\) and \(o^\star\) maximizes possibility among answer-producing consistent outcomes, no such outcome has possibility strictly greater than \(\pi_t(o_b)\). Ties are retained, so \(b\in S_t(q)\). This proves the lemma. \(\square\)

Notice that both promises were used: the first supplies an initial consistent extension; the second makes the replacement outcome tie with a maximizing outcome.

3. Membership in NP.

Let \(I_D\) be the closure of \(D\) under the full TGDs in \(\Sigma\).

Because \(\Sigma\) is fixed and contains no existential heads, this closure can be computed in polynomial time. More explicitly, the rules introduce no new constants, their predicate arities and numbers of variables are fixed, and consequently there are only polynomially many possible derived ground atoms and rule instantiations.

The base ontology is consistent: any model of a promised consistent augmented ontology is also a model of \(D\cup\Sigma\). Therefore \(I_D\) satisfies the negative constraints. Otherwise, a constraint violation in \(I_D\) would occur in every model extending \(I_D\), contradicting consistency.

Every model of \(D\cup\Sigma\) contains \(I_D\), and \(I_D\) is itself a model. Consequently, for every grounded partial substitution \(h\),

\(D\cup\Sigma\models\exists\overline{\mathbf{y}}_t\,h(\varphi)\quad\Longleftrightarrow\quad I_D\models\exists\overline{\mathbf{y}}_t\,h(\varphi).\)

It follows from the lemma that \(a\in S_t(q)\) has a polynomial certificate: a substitution \(g\) for all query variables such that

\(g(\mathbf{x})=a,\qquad g(\varphi)\subseteq I_D,\qquad g(\alpha)\in\operatorname{Dom}(\beta_t(\alpha))\text{ for every }\alpha\in\varphi_t.\)

The equivalence is exact. Such a \(g\) gives the required \(h\) by restriction. Conversely, a qualifying \(h\) has an extension \(g\) witnessing its existential query in \(I_D\). Variables not occurring in any atom, if permitted, can use one fixed dummy constant.

For the mass-threshold problem, guess a subset \(J\subseteq T\), together with one certificate of this form for each \(t\in J\). Verify all certificates and check

\(\sum_{t\in J}\mu_t\ge\theta.\)

This verifier is sound because every certified type qualifies, and every mass is positive. It is complete because, on a yes-instance, one may choose all qualifying types.

The rational comparison takes polynomial time: the product of the encoded denominators of the masses and threshold has binary length bounded by their total input length. Scaling to this common denominator gives an exact integer comparison.

Thus the promised decision problem belongs to \(\mathrm{NP}\).

4. Deterministic running time.

Set

\(B=2+L+|D|+|q|+|a|+m+\tau,\)

and let \(k=|\mathbf{y}|\). Let \(n\) be the number of constants appearing in the input or fixed program, including a dummy constant if needed; then \(n=O(B)\).

Compute \(I_D\) once. For each type, enumerate assignments to the \(k\) quantified variables, fixing \(\mathbf{x}\) to \(a\), and test the certificate conditions above. After determining the qualifying types, sum their masses exactly.

For some constant \(c_\Sigma\) depending only on the fixed program, this gives the bound

\(O\!\left(B^{c_\Sigma}+\tau n^k B^{c_\Sigma}+\tau L^2\right).\)

In particular, since \(k\le |q|\), a simpler bound is

\(O\!\left((\tau+1)B^{|q|+c_\Sigma}\right).\)

The dependence on \(m\) is polynomial through the input size; enumerating network outcomes is unnecessary. If the query is fixed, this algorithm is polynomial-time. With varying queries, the following reduction establishes hardness.

5. NP-hardness with a nonempty mapping.

Reduce from the standard \(\mathrm{NP}\)-complete problem of deciding whether a finite undirected graph has a proper coloring with three colors.

Fix \(\Sigma=\varnothing\). Choose distinct constants \(c_1,c_2,c_3,d_0,d_1\), and fix the database

\(D=\{\operatorname{Color}(c_i):1\le i\le3\}\cup\{E(c_i,c_j):1\le i,j\le3,\ i\ne j\}\cup\{P(d_0),P(d_1)\}.\)

For an input graph \(G=(U,F)\), construct the query

\(q_G(z)=\exists(y_v)_{v\in U}\left(P(z)\land\bigwedge_{v\in U}\operatorname{Color}(y_v)\land\bigwedge_{\{u,v\}\in F}E(y_u,y_v)\right).\)

Use one type with mass \(1\), threshold \(\theta=1\), and candidate tuple \(a=(d_0)\).

Its network has one variable \(X\), with domain \(\{P(d_0),P(d_1)\}\). Both entries in its unconditional possibility table are \(1\). Select \(\varphi_t=\{P(z)\}\) and set \(\beta_t(P(z))=X\).

All requirements hold:

  • The network is a DAG; its domain contains two atoms with the same predicate.
  • Its table is explicit, binary-rational, and normalized.
  • Both outcomes are consistent.
  • Both augmented ontologies have exactly the models of \(D\), since their selected atoms already belong to \(D\).
  • Their possibilities are equal, satisfying the equivalence promise.
  • The mapping is predicate-preserving and nonempty.

A substitution witnessing the existential part of \(q_G(d_0)\) must send every \(y_v\) to one of \(c_1,c_2,c_3\). The edge atoms require adjacent vertices to receive different constants. Therefore

\(D\models q_G(d_0)\quad\Longleftrightarrow\quad G\text{ is three-colorable}.\)

The outcome selecting \(P(d_0)\) produces \(d_0\) exactly in this case. Both outcomes have possibility \(1\), so neither is excluded by strict domination. Hence

\(a\in S_t(q_G)\quad\Longleftrightarrow\quad G\text{ is three-colorable}.\)

With mass and threshold both \(1\), this is precisely the requested threshold decision. The construction has polynomial size, establishing \(\mathrm{NP}\)-hardness and completing the \(\mathrm{NP}\)-completeness proof.
