The continuous mirror question, as graded

Given \(n\) alternatives and a rational mass distribution \(\mu\) over types \(t=(b,\pi)\), where \(b\) is a reliability stratum and \(\pi\) is a reported ranking, recover the common hidden order \(\sigma\). Assume the weighted pairwise margins of \(\mu\), using the reliability weights from the reconstruction rule, are strictly consistent with \(\sigma\); this is the population-consistency promise, as holds for the corresponding Mallows population law.

Packaged proof task (what the prover saw — nothing else)

There are \(m=n\ge2\) alternatives. Each type is \(t=(b,\pi)\), where \(b\) is a reliability-stratum label and \(\pi\) is a strict ranking; \(\pi(i)\) denotes the position of alternative \(i\). Each occurring stratum has a supplied positive binary-rational reliability estimate \(\widehat\beta_b\), with reconstruction weight \(w_b=\min\{\widehat\beta_b,1\}\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational, with \(\sum_t\mu(t)=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length, including rankings and reliability estimates; state running times in \(m,\tau,L\).
For distinct alternatives define \(D(i,j)=\sum_{(b,\pi)}\mu(b,\pi)w_b\bigl(\mathbf1[\pi(i)<\pi(j)]-\mathbf1[\pi(j)<\pi(i)]\bigr)\). The input promises that an unknown strict order \(\sigma\) satisfies \(D(i,j)>0\) if and only if \(\sigma(i)<\sigma(j)\), for every distinct pair. Recover \(\sigma\); behavior outside this promise is unrestricted.

Is this promised exact-recovery problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For independent discrete samples from Mallows models sharing a hidden order, polynomial-time exact reconstruction succeeds with probability at least \(1-m^{-\Theta(1)}\) when positive parameter estimates satisfy \(\widehat\beta_u/\alpha\le\beta_u\le\alpha\widehat\beta_u\), \(\alpha\ge1\), and \(\sum_{u=1}^{N}\min\{\beta_u^2,1\}\ge c\alpha^2\ln m\) for a sufficiently large absolute constant \(c\). [Chierichetti, Dasgupta, Kumar and Lattanzi](https://doi.org/10.4230/LIPIcs.APPROX-RANDOM.2014.604).

Modeling choices made when packaging the task

  • Reliability strata had no specified numerical representation: each occurring stratum carries a supplied positive binary-rational estimate, and its weight is the estimate capped at one, as in exact reconstruction.
  • Normalized the mass distribution to total mass one and required strict complete rankings.
  • Made population consistency explicit as strict agreement of every weighted pairwise margin with a single hidden order; ties are excluded and behavior outside the promise is unrestricted.
  • Used m=n for the number of alternatives and included all supplied data in the total encoding length L.
  • The discrete sample-size condition controls sampling error; the continuous task instead uses its stated population-consistency promise, without imposing a sample-count condition on normalized masses.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The promised exact-recovery problem is solvable in polynomial time. A deterministic algorithm recovers the hidden order in \(O(m^2\tau L^2)\) bit operations.

Algorithm and correctness

Index the supported types by \(s=1,\ldots,\tau\), writing each as \((b_s,\pi_s)\) with mass \(\mu_s\). First compute every reconstruction weight \(w_b=\min\{\widehat\beta_b,1\}\).

For each unordered pair of alternatives, compute \(D(i,j)\) exactly. Define

\(\displaystyle c_i=\bigl|\{j\ne i:D(j,i)>0\}\bigr|,\qquad \widehat\sigma(i)=c_i+1.\)

Return the alternatives in increasing order of \(\widehat\sigma(i)\).

To prove correctness, fix an alternative \(i\). The promise gives, for every \(j\ne i\),

\(\displaystyle D(j,i)>0\quad\Longleftrightarrow\quad \sigma(j)<\sigma(i).\)

Consequently, \(c_i\) counts exactly the alternatives preceding \(i\) in the hidden strict order. Since its positions are \(1,\ldots,m\), this count is \(\sigma(i)-1\). Thus \(\widehat\sigma(i)=\sigma(i)\) for every alternative. In particular, the computed positions are distinct and recover the entire order.

Exact arithmetic and running time

We must ensure that determining the signs requires only polynomially many bit operations, even when a margin is very small.

Write the input masses and clipped weights as positive integer fractions,

\(\displaystyle \mu_s=\frac{p_s}{q_s},\qquad w_b=\frac{r_b}{d_b}.\)

Clipping an estimate exceeding \(1\) replaces it by \(1/1\). These representations therefore have total bit length \(O(L)\). Let \(B\) be the set of occurring strata and form the common denominator

\(\displaystyle Q=\left(\prod_{s=1}^{\tau}q_s\right)\left(\prod_{b\in B}d_b\right).\)

The bit length of \(Q\) is \(O(L)\): the logarithm of a product is the sum of the logarithms of its factors, and each denominator appears once in this product.

For every supported type, compute the positive integer

\(\displaystyle A_s=p_s r_{b_s}\frac{Q}{q_s d_{b_s}}.\)

This is an integer because \(q_s d_{b_s}\) divides \(Q\). For each pair, compute

\(\displaystyle S_{ij}=\sum_{s=1}^{\tau}A_s\left(\mathbf1[\pi_s(i)<\pi_s(j)]-\mathbf1[\pi_s(j)<\pi_s(i)]\right).\)

By construction, \(S_{ij}=QD(i,j)\). Since \(Q>0\), its integer sign is exactly the required sign.

Moreover,

\(\displaystyle \sum_{s=1}^{\tau}A_s=Q\sum_{s=1}^{\tau}\mu_s w_{b_s}\le Q\sum_{s=1}^{\tau}\mu_s=Q.\)

Thus every partial signed sum has absolute value at most \(Q\), so all accumulated integers have \(O(L)\) bits.

There are at most \(\tau\) occurring strata. Using elementary integer arithmetic, constructing \(Q\) and all \(A_s\) costs \(O(\tau L^2)\) bit operations. Precomputing ranking positions and computing all pairwise sums costs \(O(m^2\tau L)\) bit operations. Counting predecessors and writing the output fit within that bound. Hence the total is \(O(\tau L^2+m^2\tau L)\), and in particular \(O(m^2\tau L^2)\).

Role of the statistical premise

The proof uses only the supplied support and the promised pairwise signs. It requires no Mallows assumption or probabilistic reconstruction theorem. The stated sampling result concerns when sampled data permit reliable reconstruction; here the deterministic promise already guarantees that every computed sign agrees with the hidden order.

Step-by-step verification

The masses, reliability estimates, and rankings are explicitly available for the \(\tau\) supported types. Clipping each positive reliability estimate at \(1\) produces precisely the required weight \(w_b\). The algorithm does not enumerate unsupported types.

For every alternative \(i\), the promise states that
\[ D(j,i)>0\quad\Longleftrightarrow\quad \sigma(j)<\sigma(i) \]
for every \(j\ne i\). Therefore, the count \(c_i\) is exactly the number of alternatives preceding \(i\).

Since \(\sigma\) is a strict order with positions \(1,\ldots,m\), this gives \(c_i=\sigma(i)-1\). Hence \(\widehat\sigma(i)=c_i+1=\sigma(i)\). This establishes recovery for every promised input, including \(m=2\).

Computing only unordered pairs is sufficient: the defining expression gives \(D(j,i)=-D(i,j)\). The promise also excludes zero margins on distinct pairs. No behavior outside the promise needs to be established.

The fraction representations of the input masses and clipped weights have total bit length \(O(L)\). Clipping an estimate to \(1/1\) does not increase this bound.

In
\[ Q=\left(\prod_{s=1}^{\tau}q_s\right)\left(\prod_{b\in B}d_b\right), \]
the total bit length of the factors is \(O(L)\), so \(Q\) has \(O(L)\) bits.

For each supported type, both factors \(q_s\) and \(d_{b_s}\) occur in the product defining \(Q\). Thus \(q_s d_{b_s}\) divides \(Q\), including when these two factors share prime divisors. Consequently, every \(A_s\) is indeed a positive integer.

\[ A_s=Q\mu_s w_{b_s}. \]
Consequently, the displayed expression for \(S_{ij}\) satisfies \(S_{ij}=QD(i,j)\). Since \(Q>0\), comparing \(S_{ij}\) with zero determines the sign of \(D(i,j)\) exactly. Arbitrarily small nonzero margins therefore cause no precision problem.

Positivity of the masses and weights, the bound \(w_b\le1\), and normalization of the masses yield
\[ \sum_{s=1}^{\tau}A_s =Q\sum_{s=1}^{\tau}\mu_s w_{b_s} \le Q. \]
Each partial signed sum has absolute value at most the sum of its included positive coefficients, hence at most \(Q\). All such sums therefore require only \(O(L)\) bits. The intermediate products used to construct the coefficients also have \(O(L)\) bits.

There are at most \(\tau\) occurring strata. Elementary multiplication and exact division on integers of \(O(L)\) bits support the claimed \(O(\tau L^2)\) preprocessing bound.

The resulting bound
\[ O(\tau L^2+m^2\tau L) \]
