The continuous mirror question, as graded

Given compatible preference classes \(R\), a finite support of incumbent-marked types \(\alpha=(r,s)\) with rational masses \(\mu_\alpha\), and a feasible baseline matching, decide whether there is a feasible mass matching \(x\) with positive vote margin. For each compatible pair \(\alpha=(r,s),\beta=(q,t)\), let \(x_{\alpha\beta}\geq 0\) be paired mass, and let \(u_\alpha\geq 0\) be unmatched mass, subject to \(\sum_{\beta\ne\alpha}x_{\alpha\beta}+2x_{\alpha\alpha}+u_\alpha=\mu_\alpha\). With \(\delta_{(r,s)}(q)=1\) if \(q\succ_r s\), \(-1\) if \(s\succ_r q\), and \(0\) if \(q=s\), test whether \(\Delta(x,u)=\sum_{\{\alpha,\beta\}}x_{\alpha\beta}(\delta_\alpha(q)+\delta_\beta(r))+\sum_\alpha u_\alpha\delta_\alpha(\bot)>0\) is feasible.

Let \(R\) be an explicitly listed set of \(m\geq1\) preference classes, with an explicitly given symmetric compatibility relation \(C\subseteq R\times R\), possibly containing diagonal pairs. Each class \(r\) strictly ranks its compatible partner classes, with every such class preferred to being unmatched, denoted \(\bot\); partners of the same class are indifferent.
A society is given by its support: the list of the \(\tau\) types \(\alpha=(r,s)\) with positive mass, each mass \(\mu_\alpha\) a binary rational, with \(\sum_\alpha\mu_\alpha=1\). Here \(s\) is the incumbent partner class or \(\bot\), and \(s\neq\bot\) requires \((r,s)\in C\). The parameter \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
For each unordered compatible pair of supported types \(\alpha=(r,s),\beta=(q,t)\), including diagonal pairs, a mass matching has real paired mass \(x_{\alpha\beta}\geq0\); it also has unmatched mass \(u_\alpha\geq0\). Set incompatible entries to zero and require \(\sum_{\beta\neq\alpha}x_{\alpha\beta}+2x_{\alpha\alpha}+u_\alpha=\mu_\alpha\). Diagonal paired mass joins distinct individuals of the same type.
The input includes a feasible baseline with binary rational entries \((b,v)\): \(b_{\alpha\beta}>0\) only when \(s=q\) and \(t=r\), and \(v_\alpha=\mu_\alpha\) for \(s=\bot\), otherwise \(v_\alpha=0\).
For \(z\) a compatible partner class or \(\bot\), define \(\delta_{(r,s)}(z)=1\) if \(z\succ_r s\), \(-1\) if \(s\succ_r z\), and \(0\) if \(z=s\). Define \(\Delta(x,u)=\sum_{\{\alpha,\beta\}}x_{\alpha\beta}(\delta_\alpha(q)+\delta_\beta(r))+\sum_\alpha u_\alpha\delta_\alpha(\bot)\), counting each unordered pair once, including diagonal pairs.

Is deciding whether a feasible mass matching satisfies \(\Delta(x,u)>0\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite agents with strict neighbor preferences, testing a given matching's popularity takes \(\mathcal O(|E|)\) time ([Bérczi-Kovács and Kosztolányi](https://real.mtak.hu/225128/1/2312.01880v3.pdf)).
Fractional popularity against a fixed integral matching on a finite graph has a dual-witness characterization ([Kavitha](https://drops.dagstuhl.de/storage/00lipics/lipics-vol150-fsttcs2019/LIPIcs.FSTTCS.2019.20/LIPIcs.FSTTCS.2019.20.pdf)) and a combinatorial characterization ([Bérczi-Kovács and Kosztolányi](https://real.mtak.hu/225128/1/2312.01880v3.pdf)); these results do not state the arbitrary-rational-mass, incumbent-marked support problem above.

Result

The problem is solvable in polynomial time in \(m,\tau,L\).

I interpret the question as asking whether there exists a feasible mass matching with \(\Delta(x,u)>0\). The proof uses a polynomial-size rational linear program and an explicit bound that permits exact testing of strict positivity.

1. Linear-programming formulation

Index the supported types by \(\alpha_1,\ldots,\alpha_\tau\), where \(\alpha_i=(r_i,s_i)\). Let \(E\) contain the unordered compatible pairs of supported types, including permitted diagonal pairs.

For each pair \(\{i,j\}\in E\), define its objective coefficient by
\(c_{ij}=\delta_{\alpha_i}(r_j)+\delta_{\alpha_j}(r_i)\).
For unmatched mass, define \(d_i=\delta_{\alpha_i}(\bot)\).

In particular, a diagonal variable has coefficient \(c_{ii}=2\delta_{\alpha_i}(r_i)\), correctly counting both individuals in each pair.

Consider the linear program
\(\max \bigl(\sum_{\{i,j\}\in E}c_{ij}x_{ij}+\sum_{i=1}^{\tau}d_i u_i\bigr)\),
subject to, for every supported type \(i\),
\(\sum_{j\ne i:\{i,j\}\in E}x_{ij}+2x_{ii}+u_i=\mu_i\),
and nonnegativity of all variables. When the diagonal pair is incompatible, its variable and term are omitted.

These are exactly the feasibility constraints and objective in the question. Thus the requested answer is yes precisely when this linear program has positive optimal value.

There are at most \(N=\tau(\tau+1)/2+\tau\) variables and exactly \(\tau\) mass equations. Its constraint coefficients belong to \(\{0,1,2\}\), its objective coefficients are integers of absolute value at most \(2\), and its right-hand sides are the given rational masses. Compatibility and objective coefficients can be computed from the explicitly listed input in polynomial time.

The feasible region is nonempty because the supplied baseline is feasible. Moreover, that baseline has objective value zero: every positive baseline pair gives both endpoint types their incumbent partner class, and every positive baseline unmatched entry belongs to a type whose incumbent is \(\bot\).

Every variable is bounded by a mass equation: \(x_{ij}\leq\mu_i\) for distinct types, \(2x_{ii}\leq\mu_i\) for diagonal pairs, and \(u_i\leq\mu_i\). Consequently the feasible region is compact, so the objective attains a finite maximum \(V\), with \(V\geq0\).

2. Exact treatment of strict positivity

Write the program as \(\max\{c^{\mathsf T}y:Ay=\mu,\ y\geq0\}\), collecting all paired and unmatched variables into \(y\).

The matrix \(A\) has rank \(\tau\), since the unmatched-variable columns form the identity matrix. Every column has Euclidean norm at most \(2\): it is either \(e_i+e_j\), \(2e_i\), or \(e_i\).

We first justify the existence of an optimal solution supported on linearly independent columns. Choose an optimal solution with the smallest number of positive coordinates. If its supported columns were dependent, there would be a nonzero vector \(h\), supported on those coordinates, with \(Ah=0\).

For sufficiently small positive \(\eta\), both \(y+\eta h\) and \(y-\eta h\) would remain nonnegative and feasible. Optimality therefore forces \(c^{\mathsf T}h=0\); otherwise one of these perturbations would improve the objective. Also, \(h\) must have both positive and negative coordinates, because every column of \(A\) is nonnegative and nonzero. Increasing the perturbation in one direction until a coordinate first becomes zero would preserve feasibility and optimality while reducing support, a contradiction.

Extend these independent supported columns to a basis of \(\tau\) columns of \(A\), forming a nonsingular integer matrix \(B\). The optimal solution is zero outside this basis and satisfies \(y_B=B^{-1}\mu\).

Write each mass as \(\mu_i=a_i/d_i\), with positive integer denominator \(d_i\), and set \(D=\prod_{i=1}^{\tau}d_i\). Then \(D\mu\) is an integer vector, and \(D\) has \(O(L)\) bits.

The adjugate formula gives
\(y_B=\operatorname{adj}(B)(D\mu)/(D\det B)\).
Since the objective coefficients are integers, the optimum therefore has the form \(V=k/(D\det B)\) for some integer \(k\).

By Hadamard’s determinant inequality and the column-norm bound,
\(1\leq|\det B|\leq2^\tau\).
Consequently, whenever \(V>0\),
\(V\geq1/(D|\det B|)\geq1/(D2^\tau)\).

Define \(\varepsilon=1/(D2^\tau)\). We have proved the exact equivalence
\(V>0\iff\exists y\geq0\text{ with }Ay=\mu\text{ and }c^{\mathsf T}y\geq\varepsilon\).
The reverse implication follows immediately from \(\varepsilon>0\).

Thus strict positivity can be replaced by a non-strict rational inequality. The threshold has \(O(L+\tau)\) bits.

3. Polynomial-time decision algorithm

Construct the rational linear system
\(Ay=\mu,\quad y\geq0,\quad c^{\mathsf T}y\geq1/(D2^\tau)\),
and test its feasibility.

The standard polynomial-time theorem for rational linear programming states that feasibility of an explicitly encoded rational linear system is decidable in time polynomial in its binary encoding length. See [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/eng/zvmmf5239).

Here all hypotheses hold: the system is explicit, has \(O(\tau^2)\) variables and polynomially many constraints, and every coefficient has polynomial bit length. Equalities can be represented by two inequalities. Construction and feasibility testing therefore take polynomial time in \(m,\tau,L\).

By the equivalence proved above, the system is feasible exactly when an improving mass matching exists. This proves the claimed polynomial-time solvability directly for the stated arbitrary-rational-mass model.
