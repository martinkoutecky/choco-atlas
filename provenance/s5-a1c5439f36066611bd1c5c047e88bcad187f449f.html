The continuous mirror question, as graded

Given finite driver types \(T\) with rational masses \(\mu_t\), and request classes \(J\) with rational demand densities \(q_j\in[0,1]\), where each type \(t\) has additive rational profits \(p_t(S)=\sum_{j\in S}w_{tj}\) and feasibility indicators \(f_{tj}\), decide separately for \(F\in\{\mathrm{EQ1},\mathrm{EF1}\}\) whether there are nonnegative masses \(x_{t,S}\) over integral bundles \(S\subseteq J\). Require \(\sum_S x_{t,S}=\mu_t\), forbid bundles containing requests infeasible for \(t\), and assign each serviceable class \(j\) exactly mass \(q_j\). For every two positive-mass type-bundle cells \((t,S)\) and \((u,U)\) with \(U\ne\varnothing\), require the paper’s \(F\) condition: for EQ1, some \(j\in U\) satisfies \(p_t(S)\ge p_u(U\setminus\{j\})\); for EF1, some \(j\in U\) satisfies \(p_t(S)\ge p_t(U\setminus\{j\})\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) driver types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\) request classes \(J\), binary-rational demands \(q_j\in[0,1]\), profits \(w_{tj}\in\mathbb{Q}_{\ge0}\), and feasibility indicators \(f_{tj}\in\{0,1\}\). Define \(p_t(S)=\sum_{j\in S}w_{tj}\) for every \(S\subseteq J\), including bundles infeasible for \(t\). A class is serviceable if \(f_{tj}=1\) for some \(t\).
An allocation consists of real masses \(x_{t,S}\ge0\) over integral bundles \(S\subseteq J\), with \(\sum_{S\subseteq J}x_{t,S}=\mu_t\) and \(x_{t,S}=0\) whenever \(S\) contains a class infeasible for \(t\). Empty bundles are allowed; there are no additional bundle constraints.
Completeness requires \(\sum_{t\in T}\sum_{S\ni j}x_{t,S}=q_j\) for each serviceable class; unserviceable classes receive zero mass and their demands impose no requirement.
For every ordered pair of cells \((t,S),(u,U)\) with \(x_{t,S}>0\), \(x_{u,U}>0\), and \(U\ne\varnothing\), EQ1 requires some \(j\in U\) with \(p_t(S)\ge p_u(U\setminus\{j\})\); EF1 instead requires some \(j\in U\) with \(p_t(S)\ge p_t(U\setminus\{j\})\). These comparisons include profits from classes infeasible for the comparing type.

For each \(F\in\{\mathrm{EQ1},\mathrm{EF1}\}\) separately, is deciding whether a feasible complete allocation satisfying \(F\) exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and the total binary input length \(L\).

For finitely many individual drivers and indivisible requests, each corresponding existence problem is weakly \(\mathrm{NP}\)-hard, even with three drivers and identical additive profits ([discrete hardness](https://arxiv.org/pdf/2208.07094)). No result settling this exact distribution-over-types problem was identified in the literature search.

Modeling choices made when packaging the task

  • The mass normalization was unspecified; normalized total driver mass to one, consistent with a distribution over types.
  • Profit signs were unspecified; required nonnegative rational weights, consistent with monotone additive profits, while permitting zero weights.
  • Defined serviceability by feasibility for at least one positive-mass support type; unserviceable classes receive no allocation and their stated demands are ignored.
  • The allocation-mass domain was unspecified; allowed nonnegative real masses.
  • Explicitly retained profits on infeasible classes in fairness comparisons, allowed empty bundles, and imposed only the per-class feasibility constraints.

Classification. Both existence problems are \(\mathrm{NP}\)-complete, even with \(\tau=2\), identical positive integer profits, and dyadic masses and demands.

The following deterministic upper bounds hold for general instances:

| Fairness notion | Exact decision time |
|---|---|
| \(\mathrm{EQ1}\) | \(2^{O(m)}\operatorname{poly}(m,\tau,L)\) |
| \(\mathrm{EF1}\) | \(2^{O(m\tau)}\operatorname{poly}(m,\tau,L)\) |

In particular, neither problem admits a \(\operatorname{poly}(m,\tau,L)\)-time algorithm unless \(\mathrm{P}=\mathrm{NP}\). The hardness proof below applies directly to distributions over types.

Reduction from PARTITION. We use the standard \(\mathrm{NP}\)-complete problem PARTITION: given positive binary-encoded integers \(a_1,\ldots,a_n\), decide whether some subset has sum half their total. Its hardness is established in [Karp’s original paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Put \(B=\sum_{i=1}^{n}a_i\). Construct two types, \(v\) and \(h\), with \(\mu_v=\mu_h=\frac12\). There are \(n\) item classes \(j_1,\ldots,j_n\) and two anchor classes \(c_1,c_2\).

Their demands, profits, and feasibilities are:

| Classes | Demand | Profit for either type | Feasible for |
|---|---|---|---|
| \(j_i\) | \(\frac14\) | \(2a_i\) | \(v\) only |
| \(c_1,c_2\) | \(\frac12\) each | \(B\) each | \(h\) only |

All classes are serviceable. Profits are identical across types, including on infeasible classes. Consequently, \(\mathrm{EQ1}\) and \(\mathrm{EF1}\) coincide on every allocation in this constructed instance.

The construction has \(m=n+2\) and \(\tau=2\). Since \(B\) has polynomial binary length, the reduction takes polynomial time in the PARTITION input length.

We prove that the constructed society admits a feasible complete fair allocation exactly when the PARTITION instance is positive.

Necessity. Each anchor class can be served only by type \(h\). Its demand equals the entire mass \(\mu_h=\frac12\). Thus every positive-mass bundle of type \(h\) contains both anchors. Feasibility excludes all item classes from those bundles, so

\[ \text{ } \]

\(x_{h,\{c_1,c_2\}}=\frac12.\)

This anchor bundle has profit \(2B\), and deleting either anchor leaves profit \(B\). Comparing any positive-mass cell \((v,S)\) against it therefore forces, under either fairness notion,

\(p_v(S)\ge B.\)

On the other hand, completeness and additivity give

\(\displaystyle \sum_{S\subseteq\{j_1,\ldots,j_n\}}x_{v,S}p_v(S) =\sum_{i=1}^{n}2a_i\sum_{S\ni j_i}x_{v,S} =\sum_{i=1}^{n}2a_i\cdot\frac14 =\frac B2. \)

Because the total mass of type \(v\) is \(\frac12\), it follows that

\(\displaystyle \sum_S x_{v,S}\bigl(p_v(S)-B\bigr)=0. \)

Every summand is nonnegative. Hence every positive-mass bundle of type \(v\) has profit exactly \(B\). At least one such bundle exists, since \(\mu_v>0\). Its item indices satisfy

\(\displaystyle \sum_{i:j_i\in S}2a_i=B,\)

which is precisely a partition into two equal sums.

Sufficiency. Suppose \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in I}a_i=B/2\). Write \(S_I=\{j_i:i\in I\}\) and \(S_{\overline I}=\{j_i:i\notin I\}\). Allocate

\(x_{v,S_I}=x_{v,S_{\overline I}}=\frac14,\qquad x_{h,\{c_1,c_2\}}=\frac12,\)

with all other masses zero.

This is feasible. Each item class occurs in exactly one of the two type-\(v\) bundles and therefore receives mass \(\frac14\); each anchor receives mass \(\frac12\). Thus it is complete.

Both type-\(v\) bundles have profit \(B\), while the anchor bundle has profit \(2B\). Every comparing cell therefore has profit at least \(B\). Deleting either anchor from the anchor bundle leaves profit \(B\). Deleting any item from either type-\(v\) bundle leaves profit at most \(B\), by nonnegativity. These statements verify every required ordered comparison. Identical profits make them valid for both \(\mathrm{EQ1}\) and \(\mathrm{EF1}\).

This proves polynomial-time many-one \(\mathrm{NP}\)-hardness for both problems, already with \(\tau=2\).

Polynomial certificates and membership in \(\mathrm{NP}\). Let \(s\le m\) be the number of serviceable classes, and put \(d=\tau+s\).

For any fixed collection of feasible cells, the type-mass and completeness equations have the form \(Ax=b\). The matrix \(A\) has \(d\) rows and entries in \(\{0,1\}\): a cell’s column indicates its type and the serviceable classes in its bundle.

Suppose a fair allocation exists. We show that one exists with at most \(d\) positive cells whose masses have polynomial binary length.

If its positive columns are linearly dependent, choose a nonzero vector \(c\) on those columns with \(Ac=0\). Summing the type rows gives \(\sum_i c_i=0\), so \(c\) has both positive and negative entries. Set

\(\displaystyle \varepsilon=\min_{i:c_i>0}\frac{x_i}{c_i}>0,\qquad x'=x-\varepsilon c.\)

Then \(x'\) remains nonnegative, satisfies \(Ax'=b\), and has strictly fewer positive cells. Its support is a subset of the previous support, so all fairness comparisons remain valid. Repeating this operation yields linearly independent positive columns, numbering \(k\le d\).

Choose \(k\) rows on which those columns form a nonsingular square matrix \(M\). Their masses are uniquely determined by \(Mx=b'\). Let \(D\) be the product of the denominators occurring in \(b\). Its binary length is \(O(L)\), and \(Db'\) is integral. Cramer’s rule expresses every mass with denominator \(D\det M\).

Hadamard’s inequality gives \(|\det M|\le k^{k/2}\). Because the coordinates of \(b'\) lie in \([0,1]\), replacing one column of \(M\) by \(Db'\) gives a determinant of absolute value at most \(Dk^{k/2}\). Thus each mass has binary length

\(O\bigl(L+k\log(k+1)\bigr).\)

A certificate lists these at most \(d\) cells, their bundles, and their rational masses. Its length is polynomial in \(m,\tau,L\). A verifier checks feasibility, all mass and demand equations, and every ordered fairness comparison using exact rational arithmetic in polynomial time.

Therefore both problems belong to \(\mathrm{NP}\), completing the \(\mathrm{NP}\)-completeness proofs.

Exact algorithms and running times. Define, for every type \(t\) and bundle \(U\),

\(\displaystyle r_t(U)= \begin{cases} p_t(U)-\max_{j\in U}w_{tj},&U\ne\varnothing,\\ 0,&U=\varnothing. \end{cases} \)

For nonempty \(U\), this is the smallest profit remaining after deleting one class. Importantly, \(r_t(U)\) uses all listed profits, including profits on classes infeasible for \(t\).

For \(\mathrm{EQ1}\), let \(a\) be the minimum own profit among all positive cells. Fairness is equivalent to every positive cell \((t,S)\) satisfying

\(p_t(S)\ge a,\qquad r_t(S)\le a.\)

Indeed, the minimum-profit cell forces every target’s residual profit to be at most \(a\); conversely, these inequalities verify every comparison.

The value \(a\) belongs to the list of own profits of feasible cells, containing at most \(\tau2^m\) candidates. For each candidate, retain exactly the feasible cells satisfying the two inequalities and solve the linear program consisting of nonnegativity, type-mass equations, and serviceable-class demand equations. Accept if any such program is feasible. The programs have at most \(\tau2^m\) variables, \(m+\tau\) equations, and rational encoding length polynomial in \(m,\tau2^m,L\). Polynomial-time rational linear programming therefore gives total time

\(2^{O(m)}\operatorname{poly}(m,\tau,L).\)

For \(\mathrm{EF1}\), define separately for each type

\(\displaystyle a_t=\min_{S:x_{t,S}>0}p_t(S).\)

Each minimum exists because \(\mu_t>0\). Fairness is equivalent to every positive cell \((u,U)\) satisfying

\(p_u(U)\ge a_u,\qquad r_t(U)\le a_t\quad\text{for every }t\in T.\)

The necessity follows by comparing each target against a minimum-profit cell of each type. Conversely, these inequalities imply that every comparing cell’s own profit dominates the target’s residual profit.

Each \(a_t\) has at most \(2^m\) possible values. Enumerate the at most \(2^{m\tau}\) threshold vectors, retain the corresponding permitted feasible cells, and solve the same mass-and-demand linear program. This yields total time

\(2^{O(m\tau)}\operatorname{poly}(m,\tau,L).\)

Both algorithms enforce the stated support-based comparisons exactly.
