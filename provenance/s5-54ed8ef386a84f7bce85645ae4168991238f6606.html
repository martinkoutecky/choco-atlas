The continuous mirror question, as graded

Given finite good classes \(G\), valuation types \(T\), rational population distribution \(\mu\in\Delta(T)\), rational per-capita supplies \(q_g\), nonnegative additive weights \(w_{tg}\), and \(\varepsilon>0\), find nonnegative masses \(y_{t,B}\) for integral bundles \(B\subseteq G\) satisfying \(\sum_{B\subseteq G}y_{t,B}=\mu_t\), \(\sum_{t,B:g\in B}y_{t,B}\le q_g\), and \(p_g=q_g-\sum_{t,B:g\in B}y_{t,B}\), with \(\sum_g p_g<1\). Writing \(v_t(B)=\sum_{g\in B}w_{tg}\), require for every supported \(y_{t,B}>0\), every supported \(y_{u,B'}>0\), and every \(g\in B'\), \((1+\varepsilon)v_t(B)\ge v_t(B'\setminus\{g\})\), and require \((1+\varepsilon)v_t(B)\ge\sum_g w_{tg}p_g\) for every supported type-bundle pair.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The problem as stated is \(\mathrm{NP}\)-hard under binary encoding of the numerical input, even with one type. The reduction uses a rational tolerance supplied as part of the input and one good with supply greater than one. Both are permitted by the definitions.

I prove hardness by showing that feasibility is equivalent to PARTITION on a polynomially constructed instance.

Source problem and construction. Consider positive integers \(a_1,\ldots,a_n\) with total \(\sum_{i=1}^n a_i=2K\), where \(K\ge1\). PARTITION asks whether some subset sums to \(K\). This problem is \(\mathrm{NP}\)-complete; restricting to even total preserves hardness, since doubling every input integer produces an equivalent instance with even total. See [Karp’s original completeness results](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Construct a single-type instance, with type mass \(\mu_t=1\). There are ordinary goods \(1,\ldots,n\) and a dummy good \(d\). Set

\(\displaystyle w_{t,i}=a_i,\qquad q_i=\frac12\quad(1\le i\le n),\qquad w_{t,d}=0.\)

Define

\(\displaystyle \eta=\frac1{8K},\qquad q_d=2-\eta,\qquad \varepsilon=\frac1{2K}.\)

All these numbers have polynomial binary encoding length. Write \(v(B)\) for the single type’s value and \(y_B\) for its bundle masses.

A partition gives a feasible solution. Suppose \(S\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in S}a_i=K\). Give mass \(1/2\) to each of the bundles

\(\displaystyle S\cup\{d\},\qquad (\{1,\ldots,n\}\setminus S)\cup\{d\}.\)

Every ordinary good has allocated mass \(1/2\), and the dummy has allocated mass \(1\). Consequently,

\(\displaystyle p_i=0\quad(1\le i\le n),\qquad p_d=1-\eta,\qquad \sum_g p_g=1-\eta<1.\)

Both supported bundles have value \(K\). Removing any good from either bundle leaves value at most \(K\), so every required EFX inequality holds. The pool has value zero because only the zero-value dummy remains in it. Thus the pool-value inequalities also hold.

Every feasible solution yields a partition. Conversely, suppose a feasible solution exists. Define its allocation marginals by

\(\displaystyle x_i=\sum_{B:i\in B}y_B,\qquad x_d=\sum_{B:d\in B}y_B.\)

Because total bundle mass is one and the ordinary supply constraints hold,

\(\displaystyle 0\le x_d\le1,\qquad 0\le x_i\le\frac12.\)

Let

\(\displaystyle \beta=1-x_d,\qquad r_i=\frac12-x_i.\)

Here \(\beta\) is exactly the total mass of bundles omitting the dummy, and every \(r_i\) is nonnegative. The residual supplies are

\(\displaystyle p_i=r_i,\qquad p_d=2-\eta-x_d=1-\eta+\beta.\)

Therefore, the strict pool bound implies

\(\displaystyle \beta+\sum_{i=1}^n r_i<\eta. \tag{1}\)

Let \(U\) denote the expected value of an allocated bundle. Additivity gives

\(\displaystyle U=\sum_B y_Bv(B)=\sum_{i=1}^n a_ix_i=K-\sum_{i=1}^n a_ir_i.\)

Every \(a_i\le2K\). Using (1), we obtain

\(\displaystyle K-\frac14=K-2K\eta<U\le K. \tag{2}\)

Now let \(s\) be the minimum value among the positively supported bundles. This minimum exists because the bundle set is finite, and \(s\le U\le K\).

For every positively supported bundle \(B\) containing \(d\), apply the EFX requirement with a minimum-value bundle on the left and with \(g=d\) removed from \(B\). Since the dummy has zero value,

\(\displaystyle v(B)=v(B\setminus\{d\})\le(1+\varepsilon)s\le(1+\varepsilon)K=K+\frac12.\)

Bundle values are integers. Hence every supported bundle containing the dummy has value at most \(K\).

Suppose, toward a contradiction, that no subset of ordinary goods has value exactly \(K\). Then every supported bundle containing the dummy has value at most \(K-1\). Every bundle omitting it has value at most \(2K\), the total value of all ordinary goods. Since the respective masses are \(1-\beta\) and \(\beta\),

\(\displaystyle U\le(1-\beta)(K-1)+\beta(2K)=K-1+(K+1)\beta.\)

By (1), \(\beta<\eta\), so

\(\displaystyle U<K-1+\frac{K+1}{8K}\le K-\frac34,\)

where the last inequality follows from \(K\ge1\), which gives \(K+1\le2K\). This contradicts (2).

Thus some subset of ordinary goods sums to \(K\). Indeed, the argument shows that some positively supported bundle containing the dummy must have value exactly \(K\), so such a bundle directly yields a partition.

This proves the equivalence

\(\displaystyle \text{PARTITION instance is feasible}\quad\Longleftrightarrow\quad\text{constructed distribution instance is feasible}.\)

Since the construction is polynomial, deciding feasibility—and hence solving the stated problem with correct infeasibility reporting—is \(\mathrm{NP}\)-hard.

Scope of the conclusion. The proof uses two features explicitly allowed in the question: \(q_d>1\), and the requirement to check removal of every good, including a zero-value good.

The tolerance satisfies \(1/\varepsilon=2K\), which can be exponentially large in the binary input length. Accordingly, this establishes ordinary \(\mathrm{NP}\)-hardness, but does not rule out an algorithm polynomial in \(1/\varepsilon\) and the remaining input length. It also does not establish hardness for fixed positive tolerance or under the additional restriction \(q_g\le1\).

The stronger extraction statement is also justified: if no supported dummy-containing bundle had value \(K\), the same expectation contradiction would apply.
