Lemma III.1 — class: algorithmic

The continuous mirror question, as graded

Given rational type masses μ_t, linear utility vectors u_t, disagreement utilities d_t, per-capita asset supplies b_k, and ε > 0, start from a feasible utility profile q. For each type r, find a feasible type-level allocation y^r maximizing its per-capita utility while keeping every other type s at q_s; then average these allocations with weights μ_r to obtain the next allocation and profile. Does this weighted Raiffa iteration reach an ε-Pareto-efficient profile, and how many rounds are required in terms of K, τ, input bit length, ε, and the smallest positive type mass?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. There are \(K\ge1\) divisible assets, positive rational per-capita supplies \(b_k\), strictly positive rational utility coefficients \(u_{tk}\), rational disagreement utilities \(d_t\), and rational \(\varepsilon>0\).
A type-level allocation specifies per-capita quantities \(x_{tk}\ge0\) satisfying \(\sum_t\mu_tx_{tk}=b_k\) for every asset; type \(t\)'s utility is \(v_t(x)=\sum_k u_{tk}x_{tk}\). Let \(V_d=\{v(x):v(x)\ge d\}\), and assume the supplied rational initial profile \(q^0\) belongs to \(V_d\).
At round \(j\), for every type \(r\), choose any allocation \(y^{r,j}\) maximizing \(v_r(y^{r,j})\), subject to feasibility, \(v_s(y^{r,j})=q_s^j\) for every \(s\ne r\), and \(v_r(y^{r,j})\ge q_r^j\). Set \(x^{j+1}=\sum_r\mu_ry^{r,j}\) and \(q^{j+1}=v(x^{j+1})\); all maximizations use the same current profile.
Define \(\partial V_d=\{z\in V_d:\text{there is no }w\in V_d\text{ with }w_t>z_t\text{ for every }t\}\). A profile \(q\) is \(\varepsilon\)-Pareto-efficient if some \(z\in\partial V_d\) satisfies \(\max_t|q_t-z_t|<\varepsilon\). Let \(L\) be the total binary input length and \(\mu_{\min}=\min_t\mu_t\).

Does this weighted Raiffa iteration always reach an \(\varepsilon\)-Pareto-efficient profile in finitely many rounds?
What are its worst-case round and bit-complexity bounds in \(K,\tau,L,\varepsilon,\mu_{\min}\); is the required number of rounds polynomial in the binary input length, or can it be superpolynomial?

For finitely many players, the equal-weight Raiffa iteration has a stated convergence result to \(\varepsilon\)-Pareto efficiency and uses one LP per player per round ([Zehavi–Leshem](https://arxiv.org/pdf/1403.7707)).
Weighted continuous-time Raiffa dynamics have a verified convergence theorem under regularity assumptions; that theorem concerns an ODE rather than this discrete-round iteration ([Driesen–Eccles–Wegner](https://link.springer.com/article/10.1007/s00182-017-0567-9)). Result

Yes. The stated iteration reaches an \(\varepsilon\)-Pareto-efficient profile after polynomially many rounds. This holds for every choice of maximizing allocations.

Define
\(A=\max_t\sum_{k=1}^K b_k u_{tk}\)
and \(\log^+ a=\max\{0,\log a\}\), where \(\log\) is the natural logarithm. If \(N_\varepsilon\) is the first qualifying round, then

\(N_\varepsilon\le 1+\tau\log^+(\tau A/\varepsilon)=O(\tau L).\)

An exact implementation using rational basic optimal LP solutions has polynomial bit complexity in \(K,\tau,L\). In particular, neither the round bound nor the bit-complexity bound requires a factor \(1/\mu_{\min}\).

The proof depends on the specified notion of Pareto efficiency: proximity to the boundary is certified by one type’s restricted ideal endpoint.

1. Feasibility and the profile update

Let \(X\) be the set of feasible allocations. It is nonempty, closed, and bounded: every feasible allocation satisfies

\(0\le x_{tk}\le b_k/\mu_t.\)

Consequently, every optimization in the question has a maximizer whenever its current profile is feasible.

For \(q\in V_d\), define

\(h_r(q)=\max\{v_r(y):y\in X,\ v_s(y)=q_s\text{ for all }s\ne r\}\)

and \(\Delta_r(q)=h_r(q)-q_r\).

An allocation realizing \(q\) is feasible for this maximization, so \(\Delta_r(q)\ge0\). Thus omitting the additional constraint \(v_r(y)\ge q_r\) does not change the optimum.

Every maximizing allocation for type \(r\) has the same utility profile,

\(e^r(q)=q+\Delta_r(q)e_r,\)

where \(e_r\) is the \(r\)-th coordinate vector. Linearity therefore gives the exact update

\(q_t^{j+1}=q_t^j+\mu_t\Delta_t(q^j).\)

In particular, the profile sequence is independent of the choices among maximizing allocations. The averaged allocation is feasible, and \(q^{j+1}\ge q^j\ge d\), so all subsequent profiles belong to \(V_d\).

2. A trimming lemma

We will repeatedly use the following elementary operation.

Suppose an allocation \(y\) gives every type \(s\ne r\) utility at least \(q_s\), where \(q_s\ge0\). Set

\(\lambda_s=q_s/v_s(y)\)

when \(v_s(y)>0\), and set \(\lambda_s=1\) when \(v_s(y)=0\). The latter case necessarily has \(q_s=0\).

Replace each other type’s allocation by \(\widetilde y_{sk}=\lambda_s y_{sk}\), and give the removed resources to type \(r\):

\(\widetilde y_{rk}=y_{rk}+\mu_r^{-1}\sum_{s\ne r}\mu_s(1-\lambda_s)y_{sk}.\)

This preserves every supply equality and nonnegativity. It gives \(v_s(\widetilde y)=q_s\) for \(s\ne r\), while

\(v_r(\widetilde y)\ge v_r(y).\)

Moreover, if some other type’s utility was strictly reduced, then some positive quantity was transferred. Strict positivity of \(u_{rk}\) implies a strict increase in type \(r\)’s utility.

All profiles considered below have nonnegative coordinates because they arise from feasible allocations.

3. Ideal endpoints certify proximity to the boundary

Claim. For every \(q\in V_d\) and every type \(r\), \(e^r(q)\in\partial V_d\).

Suppose instead that some \(w\in V_d\) satisfies \(w_t>e_t^r(q)\) for every type. Take an allocation realizing \(w\), and apply the trimming lemma to make every other type’s utility exactly \(q_s\). Type \(r\)’s resulting utility is at least \(w_r>h_r(q)\), contradicting the definition of \(h_r(q)\).

In fact, the same argument excludes any \(w\ge e^r(q)\) with at least one strict inequality: if the strict improvement belongs to another type, trimming transfers a positive quantity to \(r\).

Since \(e^r(q)\) differs from \(q\) only in coordinate \(r\),

\(\|e^r(q)-q\|_\infty=\Delta_r(q).\)

Consequently,

\(\min_r\Delta_r(q)<\varepsilon \quad\Longrightarrow\quad q\text{ is }\varepsilon\text{-Pareto-efficient}.\)

This uses the strict tolerance in the question.

4. Geometric contraction and the round bound

Claim. If \(p,q\in V_d\) and \(p\ge q\), then \(h_r(p)\le h_r(q)\).

Indeed, take a maximizing allocation for \(h_r(p)\). Its other types have utilities \(p_s\ge q_s\). Trimming them to \(q_s\) produces an allocation feasible for \(h_r(q)\), without decreasing type \(r\)’s utility.

Applying this claim to \(q^{j+1}\ge q^j\) yields

\(\Delta_r(q^{j+1}) =h_r(q^{j+1})-q_r^{j+1} \le h_r(q^j)-q_r^j-\mu_r\Delta_r(q^j) =(1-\mu_r)\Delta_r(q^j).\)

Thus, for every type,

\(\Delta_r(q^j)\le(1-\mu_r)^j\Delta_r(q^0).\)

Define the absolute utility bound

\(U_r=\mu_r^{-1}\sum_k b_k u_{rk}.\)

The allocation bounds give \(0\le\Delta_r(q^0)\le U_r\). For any chosen type \(r\), therefore, a sufficient number of rounds is

\(J_r=\left\lfloor\mu_r^{-1}\log^+(U_r/\varepsilon)\right\rfloor+1.\)

For \(0<\mu_r<1\), the inequality \((1-\mu_r)^j\le\exp(-\mu_r j)\) shows that \(\Delta_r(q^{J_r})<\varepsilon\).

Now choose a type \(r_*\) of largest mass. Since the masses sum to one,

\(\mu_{r_*}\ge1/\tau,\qquad U_{r_*}\le\tau A.\)

Hence

\(N_\varepsilon\le J_{r_*}\le1+\tau\log^+(\tau A/\varepsilon).\)

If \(\tau=1\), the allocation is fixed by the supply equalities and the initial profile is already efficient.

Every numerical input has binary length at most \(L\), and the total input length bounds the logarithms of \(A\) and \(1/\varepsilon\). Therefore

\(N_\varepsilon=O(\tau L),\)

which is polynomial in the binary input length.

For comparison, requiring every unilateral gain to be small gives the valid but unnecessary bound

\(\max_r\Delta_r(q^j)\le(1-\mu_{\min})^j\max_r U_r.\)

The resulting dependence on \(1/\mu_{\min}\) is avoided by the boundary certificate from a single type.

The entire profile sequence also converges: every coordinate is increasing and bounded. Its limit belongs to \(V_d\), by compactness. If a feasible profile strictly dominated that limit, trimming it to the other coordinates of \(q^j\) would give a fixed positive lower bound on \(\Delta_r(q^j)\), contradicting its geometric decay. Thus the limit belongs to \(\partial V_d\).

5. Exact rational bit complexity

Although arbitrary maximizing allocations may contain irrational coordinates, the profile sequence is rational and uniquely determined. A finite bit-complexity statement for allocations therefore concerns an implementation that chooses rational basic optimal solutions.

Each maximization can be written with \(n=K\tau\) nonnegative variables and at most \(m=K+\tau-1\) equality constraints. These are the supply constraints and the other types’ utility equalities. Its coefficients are fixed across rounds; only its right-hand side changes.

Here is a denominator-growth bound.

Choose a positive integer \(D\) clearing the denominators of all input rationals. Because their total encoding length is \(L\),

\(\log_2D=O(L).\)

Multiplying each LP’s equalities by \(D\) produces an integer coefficient matrix whose entries have bit length \(O(L)\).

Suppose the coordinates of \(q^j\) share an integer denominator \(D_j\). After selecting independent equality rows, a basic solution uses an invertible integer matrix of order at most \(m\). Hadamard’s inequality bounds the bit length of its nonzero determinant by

\(H=O\bigl(m(L+\log m)\bigr).\)

Cramer’s rule shows that, for type \(r\), all coordinates of a basic optimal allocation have a common denominator dividing \(D_j\Delta_{r,j}\), where

\(1\le\Delta_{r,j}\le2^H.\)

Including utility coefficients and averaging weights, a common denominator for \(q^{j+1}\) is

\(D_{j+1}=D^2D_j\prod_{r=1}^{\tau}\Delta_{r,j}.\)

The essential point is that the common denominator \(D_j\) occurs once, rather than being multiplied once per type. Consequently,

\(\log_2D_{j+1}\le\log_2D_j+O(L)+\tau H.\)

Taking \(D_0=D\), and using the absolute bounds on utilities, each profile coordinate and each chosen basic allocation coordinate can be represented with

\(B_j=O\bigl(L+j\tau(K+\tau)(L+\log(K+\tau))\bigr)\)

bits.

The standard exact rational LP theorem supplies optimal rational solutions in time polynomial in the LP dimensions and encoding length. Its hypotheses hold here: the data are rational, and every LP has a nonempty bounded feasible set.

An implementation can compute all \(\tau\) ideal values at each profile and stop whenever \(\min_r\Delta_r(q^j)<\varepsilon\). It uses at most \(\tau(N_\varepsilon+1)\) LP solves. Thus its total bit complexity is bounded by

\(\tau(N_\varepsilon+1)\operatorname{poly}(K\tau,K+\tau,L+B_{N_\varepsilon}),\)

and is polynomial in \(K,\tau,L\). These are valid upper bounds; no optimal polynomial exponent is asserted.

6. A logarithmic lower bound and failure of exact finite termination

Consider the fixed instance

\(\tau=2,\quad K=2,\quad \mu_1=\mu_2=b_1=b_2=\tfrac12,\)

with utility rows \((2,1)\) and \((1,2)\), disagreement profile \(d=(0,0)\), and initial profile \(q^0=(1,1)\).

Let \(a,b\in[0,1]\) be the fractions of the first and second assets assigned to type \(1\). The feasible utility profiles are exactly

\((v_1,v_2)=(2a+b,\ 3-a-2b).\)

The profile \(q^0\) corresponds to \(a=0,b=1\).

For a symmetric current profile \((q,q)\), with \(1\le q\le2\), maximizing type \(1\)’s utility subject to type \(2\)’s utility being \(q\) gives

\(h_1(q,q)=3-q/2.\)

Indeed, the equality requires \(a+2b=3-q\), and the maximizing choice is \(a=1,\ b=(2-q)/2\). Symmetry gives the same ideal value for type \(2\). Therefore the update is

\(q^{j+1}=\tfrac12(q^j+3-q^j/2),\)

and induction yields the profile

\(q^j=(2-4^{-j},\,2-4^{-j}).\)

To identify its distance to the boundary, observe:

  • If \(a<1\) and \(b>0\), replacing \((a,b)\) by \((a+\eta,b-\eta)\), for sufficiently small \(\eta>0\), increases both utilities by \(\eta\).
  • If \(a=1\), the profile maximizes the positive linear functional \(v_1+v_2/2\).
  • If \(b=0\), it maximizes the positive linear functional \(v_1/2+v_2\).

Hence the boundary consists exactly of profiles with \(a=1\) or \(b=0\). Every boundary profile has at least one coordinate at least \(2\), and \((2,2)\) itself belongs to the boundary. It follows that

\(\operatorname{dist}_\infty(q^j,\partial V_d)=4^{-j}.\)

For \(0<\varepsilon\le1\), the first qualifying round is therefore

\(N_\varepsilon=\lfloor\log_4(1/\varepsilon)\rfloor+1.\)

Thus logarithmically many rounds in \(1/\varepsilon\) can be necessary, even with fixed \(K,\tau,\mu_{\min}\). Exact finite termination need not occur.

Relation to the cited results

[Zehavi–Leshem](https://arxiv.org/pdf/1403.7707) formulate the equal-weight restricted-ideal and midpoint procedure using one LP per player. The argument above directly proves contraction and complexity for the mass-weighted discrete iteration; it does not require the continuous-time theorem.
