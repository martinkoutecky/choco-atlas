The continuous mirror question, as graded

Given a path \(P=(V,E)\), complete valuation types \(T\), rational masses \(\mu_t\) with \(\sum_t\mu_t=1\), and replicated per-capita supply, decide whether there are variables \(x_{t,I}\ge 0\) for integral intervals \(I\subseteq V\) such that \(\sum_I x_{t,I}=\mu_t\), \(\sum_{t,I\ni v}x_{t,I}\le\beta_v\), and \(x_{t,I}>0\Rightarrow u_t(I)\ge\rho\). In the uniform replication of a finite \(n_0\)-agent instance, take \(K\) path copies and \(K\) population copies, scale item utilities by \(1/K\), and set \(\beta_v=\rho=1/n_0\), so the finite quota \(1/(Kn_0)\) becomes the mass-limit quota \(\rho\).

Packaged proof task (what the prover saw — nothing else)

Given a path \(P=(V,E)\), rational per-item supplies \(\beta_v\), a threshold \(\rho\), and finitely many valuation types \(T\) with rational masses \(\mu_t\ge 0\), \(\sum_{t\in T}\mu_t=1\), each type \(t\) has an additive rational valuation \(u_t\) on subsets of \(V\). Target: Is this continuous proportional connected-allocation problem on paths solvable in polynomial time, or is it NP-hard?

Result

The problem is solvable in polynomial time, under the standard assumption that the threshold \(\rho\), like the other numerical inputs, is rational and encoded in binary.

The key fact is that a path has only quadratically many connected subsets. Thus the stated problem can be written explicitly as a rational linear-programming feasibility problem of polynomial size.

Construction

Write the vertices in path order as \(v_1,\ldots,v_n\), and let \(k=|T|\). Every nonempty connected subset is uniquely an interval
\[ I_{i,j}=\{v_i,v_{i+1},\ldots,v_j\}, \qquad 1\le i\le j\le n. \]
There are exactly \(n(n+1)/2\) such intervals.

For each type \(t\), write \(a_{t,\ell}=u_t(\{v_\ell\})\). Additivity gives
\[ u_t(I_{i,j})=\sum_{\ell=i}^{j}a_{t,\ell}. \]
Compute the set of eligible intervals
\[ A_t=\left\{(i,j):1\le i\le j\le n,\ \sum_{\ell=i}^{j}a_{t,\ell}\ge\rho\right\}. \]

Introduce one real variable \(y_{t,i,j}\) for each \(t\in T\) and \((i,j)\in A_t\). Test feasibility of the following linear system:
\[ y_{t,i,j}\ge 0 \qquad (t\in T,\ (i,j)\in A_t), \]
\[ \sum_{(i,j)\in A_t}y_{t,i,j}=\mu_t \qquad (t\in T), \]
\[ \sum_{t\in T} \sum_{\substack{(i,j)\in A_t\\ i\le \ell\le j}} y_{t,i,j}\le\beta_{v_\ell} \qquad (1\le\ell\le n). \]
An empty sum is zero. In particular, a type with positive mass and no eligible interval makes the system infeasible.

Proof of equivalence

Suppose first that the original allocation variables \(x_{t,I}\) are feasible. If \(u_t(I)<\rho\), the implication in the question rules out \(x_{t,I}>0\). Since \(x_{t,I}\ge0\), necessarily \(x_{t,I}=0\).

Consequently, setting \(y_{t,i,j}=x_{t,I_{i,j}}\) for eligible intervals preserves every type’s total mass and every vertex’s total consumption. These variables satisfy the constructed linear system.

Conversely, suppose the constructed system has a feasible solution. Set \(x_{t,I_{i,j}}=y_{t,i,j}\) for eligible intervals and set \(x_{t,I_{i,j}}=0\) for all other intervals. The linear constraints give the required mass equalities and supply inequalities. Every positive variable corresponds to an eligible interval, so its value is at least \(\rho\). Thus the original allocation is feasible.

The two feasibility questions are therefore equivalent.

Polynomial running time and exactness

Let \(L\) be the total binary input length. Each interval value is a sum of at most \(n\) input rationals. Such a sum has polynomial encoding length: using the product of the denominators as a common denominator yields numerator and denominator bit lengths bounded by \(O(nL+\log n)\). Exact comparisons with rational \(\rho\) therefore take polynomial time. Enumerating and testing all \(k n(n+1)/2\) type–interval pairs is polynomial.

The resulting linear system has at most \(k n(n+1)/2\) variables, \(k\) mass equalities, and \(n\) supply inequalities, in addition to nonnegativity. All matrix entries are zero or one, and the right-hand sides are input rationals. Even a dense encoding of this system has polynomial length.

The polynomial-time theorem for rational linear programming states that feasibility of a finite system of linear equalities and inequalities with binary-encoded rational coefficients can be decided in time polynomial in its encoding length. All its hypotheses hold here. Applying that theorem gives an exact polynomial-time decision algorithm.

This reasoning does not require nonnegative valuations or normalization. If the empty set is also permitted as an interval, adding one eligible empty-interval variable per type when \(0\ge\rho\) preserves the same conclusion.

Relation to the indivisible problem

The cited indivisible problem imposes discrete choices and pairwise disjointness. Here each type’s mass may be divided among eligible intervals, and vertex usage is constrained by linear inequalities. The explicit linear program above fully captures those continuous requirements, so hardness of the indivisible variant does not establish hardness of this problem.
