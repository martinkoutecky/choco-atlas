The continuous mirror question, as graded

Given a finite type set \(K\), rational masses \(\mu_r\) summing to \(1\), \(m\) alternatives, rational continuous piecewise-affine functions \(g_j:[0,1]^{|K|}\to\mathbb{Q}\), and a rational threshold \(q\), does there exist an allocation \(x_{rj}\ge 0\) with \(\sum_{j=1}^{m}x_{rj}=\mu_r\) for each \(r\in K\) and \(\sum_{j=1}^{m}g_j(x_{\cdot j})\ge q\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(K\) of \(\tau\ge 1\) types with positive binary-rational masses \(\mu_r\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge 1\) labeled alternatives. For each alternative, the input specifies a continuous piecewise-affine function \(g_j:[0,1]^\tau\to\mathbb R\) by an explicit finite list of rational polyhedra covering the cube and rational affine formulas agreeing on overlaps. Polyhedra are specified by binary-rational linear inequalities.
Function values may have either sign, and \(g_j(0)\) need not vanish. The threshold \(q\in\mathbb Q\) is given in binary. Let \(L\) be the total input bit length, including all function descriptions.
An allocation consists of real numbers \(x_{rj}\ge 0\) satisfying \(\sum_{j=1}^m x_{rj}=\mu_r\) for every \(r\in K\). Types may be split among alternatives, and alternatives may receive zero mass. Write \(x_{\cdot j}=(x_{rj})_{r\in K}\).

Is deciding whether an allocation satisfies \(\sum_{j=1}^m g_j(x_{\cdot j})\ge q\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

Discrete simultaneous coalition structure generation and assignment—partitioning agents among labeled alternatives, allowing empty coalitions, with an additive coalition-to-alternative objective—is stated to be NP-complete in the [verified discrete result](https://ojs.aaai.org/index.php/AAAI/article/download/17349/17156).
No result settling this exact continuous problem was located in the literature search.

Modeling choices made when packaging the task

  • Replaced the stated rational codomain by a real codomain with rational affine coefficients: a continuous rational-valued function on the cube would necessarily be constant.
  • Specified the missing function encoding as an explicit polyhedral cover with rational inequalities and affine formulas agreeing on overlaps; included its full encoding in L.
  • Retained only positive-mass types in the support and required a nonempty support and at least one alternative.
  • Specified real, divisible allocations and allowed zero-mass alternatives, carrying over the permission for empty coalitions.
  • Allowed signed function values, signed thresholds, and arbitrary values at zero, consistent with the unrestricted discrete valuation domain.

Result

Interpreting the question as asking whether there exists an allocation meeting the threshold, the problem is \(\mathrm{NP}\)-hard. Under the stated promises on the function descriptions, it also belongs to \(\mathrm{NP}\).

Hardness already holds with \(\tau=1\), mass \(\mu_1=1\), threshold \(q=0\), and exactly three affine pieces per alternative.

1. Reduction from Subset Sum

We use the classical \(\mathrm{NP}\)-hardness of Subset Sum with positive integers: given binary-encoded \(w_1,\ldots,w_n\) and a positive target \(B\), decide whether some \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in I}w_i=B\). This positive-integer formulation and its hardness are stated in [Polak, Rohwedder, and Węgrzycki, *Knapsack and Subset Sum with Small Items*](https://arxiv.org/html/2105.04035).

Let \(S=\sum_{i=1}^n w_i\), and choose a power of two \(N=2^k>\max\{S,B\}\). Construct a society with one type of mass \(1\) and \(m=n+1\) labeled alternatives. Define

\(a_i=w_i/N\quad (1\le i\le n),\qquad a_{n+1}=(N-B)/N.\)

Every \(a_j\) is a dyadic rational strictly between \(0\) and \(1\). For each alternative, define

\(g_j(t)=-\min\{t,\lvert t-a_j\rvert\},\qquad 0\le t\le1.\)

The explicit polyhedral description consists of the following three closed intervals and affine formulas:

| Polyhedron | Affine formula |
|---|---|
| \(0\le t\le a_j/2\) | \(-t\) |
| \(a_j/2\le t\le a_j\) | \(t-a_j\) |
| \(a_j\le t\le1\) | \(a_j-t\) |

These intervals cover \([0,1]\). At \(t=a_j/2\), both incident formulas equal \(-a_j/2\); at \(t=a_j\), both equal \(0\). Thus the formulas agree on overlaps and define a continuous piecewise-affine function.

Moreover,

\(g_j(t)\le0,\qquad g_j(t)=0\ \Longleftrightarrow\ t\in\{0,a_j\}.\)

Indeed, both quantities inside the minimum are nonnegative, and their minimum vanishes precisely when \(t=0\) or \(\lvert t-a_j\rvert=0\).

Set \(q=0\). Writing \(x_j=x_{1j}\), allocation feasibility becomes

\(x_j\ge0,\qquad \sum_{j=1}^{n+1}x_j=1.\)

Polynomial encoding size

The integer \(k\) is polynomially bounded by the source input length: \(\log_2 S\) is at most the maximum input weight bit length plus \(\log_2 n\). Consequently, all breakpoints and affine coefficients have polynomial bit length.

Each function uses three intervals, each specified by two dyadic linear inequalities. The construction therefore has polynomial total bit length and is computable in polynomial time. It satisfies the input requirements even if “binary-rational” is interpreted specifically as dyadic rational.

2. Correctness of the reduction

A Subset Sum solution gives a successful allocation

Suppose \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in I}w_i=B\). Allocate

\(x_i=a_i\) for \(i\in I\), \(x_i=0\) for \(i\notin I\), and \(x_{n+1}=a_{n+1}\).

The total allocated mass is

\(\sum_{j=1}^{n+1}x_j=B/N+(N-B)/N=1.\)

Every coordinate is a zero of its corresponding function. Hence \(\sum_j g_j(x_j)=0\ge q\).

A successful allocation gives a Subset Sum solution

Conversely, suppose a feasible allocation satisfies \(\sum_j g_j(x_j)\ge0\). Each summand is nonpositive, so every summand must equal zero. Therefore \(x_j\in\{0,a_j\}\) for every \(j\).

The last alternative must receive \(a_{n+1}\). Otherwise,

\(\sum_{j=1}^{n+1}x_j\le\sum_{i=1}^n a_i=S/N<1,\)

contradicting feasibility.

Let \(I=\{i\in\{1,\ldots,n\}:x_i=a_i\}\). The allocation equality now gives

\(\sum_{i\in I}w_i/N+(N-B)/N=1,\)

and thus \(\sum_{i\in I}w_i=B\).

This proves the equivalence and establishes \(\mathrm{NP}\)-hardness. Splitting is fully allowed; the functions force the required discrete choices only for allocations meeting the threshold.

3. Polynomial-size certificates

We now prove membership in \(\mathrm{NP}\) for inputs satisfying the stated representation promises.

Suppose a successful real allocation exists. For each alternative \(j\), select one listed polyhedron \(P_j\) containing \(x_{\cdot j}\), and write its affine formula as

\(g_j(z)=c_j^{\mathsf T}z+b_j\quad\text{on }P_j.\)

Such a selection exists because the listed polyhedra cover the cube. Consider the rational linear system

\(x_{rj}\ge0,\qquad \sum_{j=1}^m x_{rj}=\mu_r,\qquad x_{\cdot j}\in P_j,\)

together with

\(\sum_{j=1}^m(c_j^{\mathsf T}x_{\cdot j}+b_j)\ge q.\)

Its feasible set is nonempty because it contains the original allocation. It is bounded because \(0\le x_{rj}\le\mu_r\le1\). It is closed because all constraints are non-strict linear inequalities or equalities. Therefore it is a nonempty rational polytope.

Here is the certificate-size argument explicitly. Put \(D=m\tau\). A nonempty bounded polytope has a vertex: successively minimize each of its \(D\) coordinates over the previously obtained minimizing face. Compactness ensures each minimum exists, and after all coordinates are fixed the resulting singleton is an extreme point.

At a vertex, the active constraint normals span \(\mathbb R^D\). Otherwise, a nonzero vector orthogonal to every active normal would permit sufficiently small movements in both directions while preserving all constraints, contradicting extremality. Thus the vertex is determined by \(D\) independent active equations.

After clearing denominators in each equation, let every integer coefficient and right-hand side have absolute value at most \(2^H\). The value \(H\) is polynomially bounded in \(m,\tau,L\): the selected system has polynomial size, and clearing denominators multiplies only polynomially many binary-encoded denominators.

By Cramer’s rule, each vertex coordinate is a ratio of integer determinants. Each determinant has absolute value at most \(D!\,2^{DH}\), so each coordinate has numerator and denominator bit lengths bounded by \(O(DH+D\log D)\).

Consequently, a certificate consists of the selected polyhedron indices and a polynomial-size rational allocation. Exact rational arithmetic verifies polyhedron membership, all allocation constraints, and the objective inequality in polynomial time. Agreement of formulas on overlaps ensures that the verified affine values are the specified function values.

4. Hardness also holds for nonnegative, nondecreasing functions

The reduction can be strengthened. Replace each function by \(h_j(t)=t+g_j(t)\), and set the threshold to \(1\). Its three formulas are respectively \(0\), \(2t-a_j\), and \(a_j\). Hence \(h_j\) is continuous, nonnegative, nondecreasing, and satisfies \(h_j(0)=0\).

For every feasible allocation,

\(\sum_j h_j(x_j)=1+\sum_j g_j(x_j).\)

Thus the new threshold is met exactly when the original threshold is met.

The requested decision problem is therefore \(\mathrm{NP}\)-hard, with polynomially checkable certificates under its representation promises. A polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
