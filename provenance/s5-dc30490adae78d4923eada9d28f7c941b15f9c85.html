Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given candidates \(C\), \(\tau\) strict ranking types \(t_i\), rational masses \(\mu_i\ge 0\) summing to \(1\), and rational \(\epsilon\in(0,\tfrac12)\), compute a lottery \(q\) over \(C\) with support size at most \(\lceil 100/\epsilon^2\rceil\) such that, for every \(a\in C\), \(\sum_{b\in C}q_b\sum_{i=1}^{\tau}\mu_i\,\mathbf{1}[a\succ_{t_i}b]\le \tfrac12+\epsilon\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set of size \(m\). A society is given by its support: \(\tau\) distinct strict ranking types \(t_i\), each with positive binary-rational mass \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) counts supported types, not all possible rankings.
The input also includes binary-rational \(\epsilon\in(0,\tfrac12)\); let \(L\) be the total input bit length. Define \(p(a,b)=\sum_{i=1}^{\tau}\mu_i\mathbf{1}[a\succ_{t_i}b]\), with \(p(a,a)=0\).
Compute a rational lottery \(q\) over \(C\) satisfying \(|\{b:q_b>0\}|\leq\lceil100/\epsilon^2\rceil\) and \(\sum_{b\in C}q_bp(a,b)\leq\tfrac12+\epsilon\) for every \(a\in C\).

Is this search problem solvable deterministically in time polynomial in \(m,\tau,L\), or is it NP-hard?
State running times in \(m,\tau,L\) and \(1/\epsilon\).

For explicitly listed equally weighted voters, lotteries satisfying these inequalities with support \((1+o(1))\pi/(8\epsilon^2)\) exist; an expected polynomial-time randomized construction is established by [Charikar, Ramakrishnan, and Wang](https://arxiv.org/html/2504.20372v3).
No deterministic polynomial-time resolution for the precise binary-rational support input problem above was verified.

Modeling choices made when packaging the task

  • Removed zero-mass types so that τ is exactly the positive-mass support size.
  • Required a nonempty candidate set and retained the strict-ranking convention p(a,a)=0.
  • Specified binary-rational lottery probabilities and total input bit length L.
  • Interpreted P as deterministic polynomial time in the binary input size; dependence on 1/ε must be reported explicitly.

Deterministic polynomial-time solution

The search problem is deterministically solvable in time polynomial in \(m,\tau,L\). In fact, the construction below produces support at most \(\lceil16/\epsilon^2\rceil\).

The proof uses the rank-error averaging idea in [Charikar, Ramakrishnan, and Wang](https://arxiv.org/html/2504.20372v3), together with an exact dynamic program for the conditional expectations. The dynamic program works directly with the supported ranking types and their rational masses.

1. Compute an exact maximal lottery

Let \(P=(p(a,b))_{a,b\in C}\), and define
\[ \]
\(A_{ab}=p(a,b)-\tfrac12\) for \(a\ne b\), and \(A_{aa}=0\).

Because rankings are strict and the masses sum to one, \(p(a,b)+p(b,a)=1\) whenever \(a\ne b\). Consequently, \(A^\mathsf{T}=-A\).

Write \(\Delta(C)\) for the simplex of lotteries over \(C\). We first establish that the rational linear program
\[ \]
\(x\in\Delta(C),\qquad Ax\leq0\)
is feasible.

Indeed, the finite zero-sum minimax theorem applies to the finite real matrix \(A\), giving
\[ \]
\(\displaystyle \max_{y\in\Delta(C)}\min_{x\in\Delta(C)}y^\mathsf{T}Ax = \min_{x\in\Delta(C)}\max_{y\in\Delta(C)}y^\mathsf{T}Ax. \)

For every lottery \(z\), skew-symmetry gives \(z^\mathsf{T}Az=0\). Choosing \(x=y\) shows that the left-hand side is at most zero; choosing \(y=x\) shows that the right-hand side is at least zero. Thus their common value is zero, and a minimizing lottery \(x\) satisfies \(Ax\leq0\).

For this lottery,
\[ \]
\(\displaystyle (Px)_a=(Ax)_a+\tfrac12(1-x_a)\leq\tfrac12 \qquad\text{for every }a\in C. \)

The feasible polytope is nonempty, bounded, and rational. Standard deterministic polynomial-time algorithms for rational linear programming therefore compute a rational feasible vertex \(x\).

Set \(k=\lceil16/\epsilon^2\rceil\). If \(m\leq k\), output \(x\) immediately. Its support and inequalities already satisfy the requirements.

Henceforth assume \(k<m\).

2. A potential controlling every candidate

For ranking type \(i\), list candidates from worst to best:
\[ \]
\(c_{i,1},\ldots,c_{i,m}.\)

Define its nested prefix sets
\[ \]
\(B_{i,j}=\{c_{i,1},\ldots,c_{i,j}\},\qquad 0\leq j\leq m,\)
where \(B_{i,0}=\varnothing\).

For any lottery \(q\), put
\[ \]
\(\displaystyle D_i(q)=\max_{0\leq j\leq m}\bigl(q(B_{i,j})-x(B_{i,j})\bigr), \qquad \Phi(q)=\sum_{i=1}^{\tau}\mu_iD_i(q). \)

The empty prefix ensures \(D_i(q)\geq0\).

If \(a=c_{i,j}\), the candidates ranked below \(a\) are exactly \(B_{i,j-1}\). Therefore
\[ \]
\(\displaystyle \sum_bq_bp(a,b)-\sum_bx_bp(a,b) = \sum_{i=1}^{\tau}\mu_i \bigl(q(B_{i,j_i(a)-1})-x(B_{i,j_i(a)-1})\bigr) \leq\Phi(q), \)
where \(j_i(a)\) denotes the position of \(a\) in type \(i\).

It follows that \(\Phi(q)\leq\epsilon\) implies all the required inequalities.

3. A self-contained expectation bound

Let \(Z_1,\ldots,Z_k\) be independent samples from \(x\), and let \(\widehat q\) be their empirical lottery. We prove
\[ \]
\(\displaystyle \mathbb E D_i(\widehat q)\leq\frac4{\sqrt{k}}\)
for every type \(i\).

Fix a type and abbreviate \(f_j(z)=\mathbf1[z\in B_{i,j}]\). Let \(Z'_1,\ldots,Z'_k\) be an independent copy of the sample. Conditional Jensen’s inequality, applied to the maximum absolute coordinate, gives
\[ \]
\(\displaystyle \mathbb E\max_j\left|\sum_{h=1}^{k} \bigl(f_j(Z_h)-\mathbb Ef_j(Z_h)\bigr)\right| \leq \mathbb E\max_j\left|\sum_{h=1}^{k} \bigl(f_j(Z_h)-f_j(Z'_h)\bigr)\right|. \)

Introduce independent uniform signs \(\sigma_h\in\{-1,1\}\). Independently swapping each pair \((Z_h,Z'_h)\) preserves its joint distribution, so the last expectation equals
\[ \]
\(\displaystyle \mathbb E\max_j\left|\sum_{h=1}^{k} \sigma_h\bigl(f_j(Z_h)-f_j(Z'_h)\bigr)\right|. \)

The triangle inequality and identical distributions of the two samples bound this by
\[ \]
\(\displaystyle 2\,\mathbb E\max_j\left|\sum_{h=1}^{k}\sigma_hf_j(Z_h)\right|. \)

Condition on the \(Z_h\), and sort them from worst to best in the fixed ranking. Each prefix set selects a prefix of this sorted sample, possibly skipping some prefix lengths when candidates repeat. The reordered signs remain independent uniform signs. Consequently, the last maximum is bounded by
\[ \]
\(\displaystyle M_k=\max_{0\leq s\leq k}|S_s|, \qquad S_s=\sum_{h=1}^{s}\sigma_h. \)

For completeness, \(\mathbb EM_k\leq2\sqrt{k}\). To see this, for \(t>0\) let \(T\) be the first index with \(|S_T|\geq t\). Independence and zero mean of subsequent increments give, for each \(s\leq k\),
\[ \]
\(\displaystyle \mathbb E[S_k^2\mathbf1[T=s]] = \mathbb E[(S_s^2+k-s)\mathbf1[T=s]] \geq t^2\Pr(T=s). \)

Summing and using \(\mathbb ES_k^2=k\) yields
\[ \]
\(\displaystyle \Pr(M_k\geq t)\leq\min\{1,k/t^2\}.\)

Integration therefore gives
\[ \]
\(\displaystyle \mathbb EM_k \leq\int_0^{\sqrt{k}}1\,dt+ \int_{\sqrt{k}}^\infty\frac{k}{t^2}\,dt =2\sqrt{k}. \)

Combining these bounds and dividing by \(k\), we obtain
\[ \]
\(\displaystyle \mathbb E D_i(\widehat q) \leq \mathbb E\max_j|\widehat q(B_{i,j})-x(B_{i,j})| \leq\frac4{\sqrt{k}}. \)

Linearity of expectation, with no independence assumption between types, now gives
\[ \]
\(\displaystyle \mathbb E\Phi(\widehat q) \leq\sum_i\mu_i\frac4{\sqrt{k}} =\frac4{\sqrt{k}} \leq\epsilon. \)

The remaining task is to make this expectation argument deterministic.

4. Compute conditional expectations exactly

Suppose \(\ell\) sample positions have been fixed and \(r=k-\ell\) remain independent samples from \(x\).

Fix one ranking type and suppress its index. Write its order as \(c_1,\ldots,c_m\), and let
\[ \]
\(\displaystyle H_j=\#\{\text{fixed samples in }B_j\}, \qquad X_j=x(B_j). \)

If \(R_j\) counts the remaining samples in \(B_j\), the completed type error is
\[ \]
\(\displaystyle D=\max_{0\leq j\leq m} \left(\frac{H_j+R_j}{k}-X_j\right). \)

We give an exact polynomial-time algorithm for its conditional expectation.

4.1. The possible error values

Every realization of \(D\) belongs to the rational set
\[ \]
\(\displaystyle V=\{0\}\cup \left\{\frac{s}{k}-X_j: 0\leq j\leq m,\ 0\leq s\leq k,\ 0\leq\frac{s}{k}-X_j\leq1\right\}. \)

This set has \(O(mk)\) elements. Sort its distinct elements as
\[ \]
\(0=v_0<v_1<\cdots<v_N.\)

It suffices to compute \(F(v)=\Pr(D\leq v)\) for each \(v\in V\), because
\[ \]
\(\displaystyle \mathbb ED = \sum_{a=1}^{N}v_a\bigl(F(v_a)-F(v_{a-1})\bigr). \)

The omitted probability mass at zero contributes zero.

4.2. A cumulative-count dynamic program

Choose a common integer denominator \(d\) for \(x\), and write
\[ \]
\(x_{c_j}=w_j/d,\qquad w_j\in\mathbb Z_{\geq0},\qquad \sum_jw_j=d.\)

For a threshold \(v\), define
\[ \]
\(\displaystyle u_j=\lfloor k(v+X_j)\rfloor-H_j.\)

Then \(D\leq v\) holds exactly when \(R_j\leq u_j\) for every \(j\).

Initialize \(G_0(0)=1\) and \(G_0(s)=0\) for \(1\leq s\leq r\). For \(j=1,\ldots,m\), compute
\[ \]
\(\displaystyle G_j(s)= \begin{cases} \displaystyle\sum_{e=0}^{s}\binom{s}{e}w_j^eG_{j-1}(s-e), & s\leq u_j,\\ 0,&s>u_j, \end{cases} \qquad 0\leq s\leq r. \)

Here \(w_j^0=1\), including when \(w_j=0\).

To verify the recurrence explicitly, \(G_j(s)\) equals
\[ \]
\(\displaystyle \sum_{\substack{e_1+\cdots+e_j=s\\ e_1+\cdots+e_a\leq u_a\ \text{for }1\leq a\leq j}} \frac{s!}{e_1!\cdots e_j!}\prod_{a=1}^{j}w_a^{e_a}. \)

Separating \(e_j=e\) gives the recurrence, since
\[ \]
\(\displaystyle \frac{s!}{e_1!\cdots e_{j-1}!e!} = \binom{s}{e}\frac{(s-e)!}{e_1!\cdots e_{j-1}!}. \)

At \(j=m\) and \(s=r\), these are precisely the multinomial weights of all allowed remaining sample-count vectors. Thus
\[ \]
\(\displaystyle F(v)=\frac{G_m(r)}{d^r}.\)

This remains valid for \(r=0\) and for zero lottery coordinates.

For one threshold, the recurrence uses \(O(mk^2)\) arithmetic operations. Evaluating all \(O(mk)\) thresholds computes one type’s conditional expectation in \(O(m^2k^3)\) arithmetic operations.

5. Deterministically choose the samples

For a fixed sample prefix \(z_1,\ldots,z_\ell\), let
\[ \]
\(\displaystyle \Psi(z_1,\ldots,z_\ell) = \mathbb E[\Phi(\widehat q)\mid Z_1=z_1,\ldots,Z_\ell=z_\ell]. \)

Section 4 computes this quantity exactly: compute each type’s conditional expectation and take the rational weighted sum using \(\mu_i\).

For every candidate \(b\) with \(x_b>0\), compute the expectation after fixing the next sample to \(b\). Independence of the remaining samples gives
\[ \]
\(\displaystyle \Psi(z_1,\ldots,z_\ell) = \sum_{b:x_b>0}x_b\, \Psi(z_1,\ldots,z_\ell,b). \)

Therefore at least one such \(b\) has conditional expectation at most the current one. Choose a minimizing candidate, with deterministic tie-breaking.

After \(k\) choices, there is no remaining randomness, and
\[ \]
\(\displaystyle \Phi(q)=\Psi(z_1,\ldots,z_k) \leq\Psi(\varnothing) =\mathbb E\Phi(\widehat q) \leq\epsilon. \)

Output the empirical lottery
\[ \]
\(\displaystyle q_b=\frac{\#\{h:z_h=b\}}{k}.\)

It is rational, has support at most \(k\), and Section 2 gives
\[ \]
\(\displaystyle \sum_bq_bp(a,b)\leq\tfrac12+\epsilon \qquad\text{for every }a\in C. \)

Finally, \(k=\lceil16/\epsilon^2\rceil\leq\lceil100/\epsilon^2\rceil\), as required.

6. Bit complexity and dependence on \(\epsilon\)

The pairwise matrix can be constructed using \(O(\tau m^2)\) rational additions. A common denominator for the input masses has \(O(L)\) bits, so the resulting linear program has encoding length polynomial in \(m,\tau,L\).

We may choose the feasible vertex \(x\) so that its common denominator \(d\) has
\[ \]
\(B=O(m(L+\log(m+1)))\)
bits. Indeed, clear the input-mass denominators in the constraints; their integer coefficients have \(O(L)\) bits. At a vertex, Cramer’s rule applies to \(m\) independent active constraints, whose determinants have the stated bit bound.

The dynamic program has \(0\leq G_j(s)\leq d^s\): it sums the weights of a subset of length-\(s\) strings. Hence its integers have \(O(kB)\) bits.

All type-error thresholds have denominator \(kd\), and their conditional probabilities have denominator \(d^r\). Thus a type’s conditional expectation has denominator dividing \(kd^{r+1}\). Taking the weighted sum over types adds only \(O(L)\) bits to a common denominator. Exact comparisons therefore use numbers of \(O(L+kB+\log(k+1))\) bits.

There are at most \(km\) candidate evaluations, each involving \(\tau\) type expectations. The arithmetic-operation bound is consequently
\[ \]
\(\displaystyle O(\tau m^3k^4).\)

Using ordinary quadratic-time integer arithmetic, a sufficient bit-operation bound for the sampling branch is
\[ \]
\(\displaystyle O\!\left(\tau m^5k^6(L+\log(m+1))^2\right), \)
in addition to polynomial-time preprocessing and linear programming.

Put \(h=\min\{m,\lceil16/\epsilon^2\rceil\}\). A uniform bound for the whole algorithm is
\[ \]
\(\displaystyle P(m,\tau,L)+ O\!\left(\tau m^5h^6(L+\log(m+1))^2\right), \)
where \(P\) is a polynomial covering preprocessing and linear programming.

This yields both:

  • A bound of \(P(m,\tau,L)+O(\tau m^5\epsilon^{-12}(L+\log(m+1))^2)\).
  • A bound of \(P(m,\tau,L)+O(\tau m^{11}(L+\log(m+1))^2)\), polynomial in \(m,\tau,L\) alone.

The second bound follows because the dynamic program runs only when \(k<m\). Neither the ranking masses nor a very small binary-encoded \(\epsilon\) require expanding the society into explicitly listed voters.
