The continuous mirror question, as graded

Given a finite rational outcome set \(S=\{(\alpha_j,\beta_j)\}_j\), rival types \(T\) with masses \(\mu_t>0\) summing to \(1\), per-team score gaps \(c_t\), and rational masses \(q_{tu}\) of fixtures with type \(t\) at home against type \(u\), does there exist an outcome allocation with masses \(x_{tu,j}\ge 0\) such that \(\sum_j x_{tu,j}=q_{tu}\) for every \(t,u\), and \(\sum_{u,j}(\alpha_jx_{tu,j}+\beta_jx_{ut,j})\le \mu_t c_t\) for every \(t\)? The schedule and allocation are type-regular: every team of type \(t\) has the same per-capita fixture and outcome proportions against each type, so these inequalities ensure no rival finishes above the target’s fixed score.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge 1\) rival types with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
The input also contains a nonempty outcome set \(S=\{(\alpha_j,\beta_j)\}_{j=1}^{m}\subseteq\mathbb Q^2\), arbitrary rational per-team score gaps \(c_t\), and nonnegative rational fixture masses \(q_{tu}\) for every ordered pair \((t,u)\). Outcome coordinates and gaps may have either sign. The target team has finished its fixtures; ties with its fixed final score count as winning.
An outcome awards \(\alpha_j\) points to the home team and \(\beta_j\) to the away team. Fixtures may repeat; \(q_{tt}\) represents fixtures between distinct teams of the same type. Fixture masses need not sum to \(1\).
An allocation consists of real masses \(x_{tu,j}\ge 0\). It is type-regular: each team of type \(t\) has home outcome proportions \(x_{tu,j}/\mu_t\) against type \(u\), and away outcome proportions \(x_{ut,j}/\mu_t\) against type \(u\).
Feasibility requires \(\sum_{j=1}^{m}x_{tu,j}=q_{tu}\) for every \(t,u\), and \(\sum_{u\in T}\sum_{j=1}^{m}(\alpha_jx_{tu,j}+\beta_jx_{ut,j})\le\mu_t c_t\) for every \(t\). Let \(L\) be the total binary encoding length of the input.

Is deciding feasibility for this continuous problem in \(\mathrm P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For discrete teams and indivisible fixtures, feasibility is \(\mathrm{NP}\)-complete already for the fixed set \(S=\{(0,3),(1,1),(3,0)\}\).
The discrete problem is polynomial-time solvable for each fixed set \(S=\{(i,r-i):i\in\{0,\ldots,r\}\}\), where \(r\ge 1\) is an integer.

Modeling choices made when packaging the task

  • Required a nonempty outcome set and at least one positive-mass rival type.
  • Allowed signed rational outcome coordinates and score gaps, following the unrestricted real domains of the discrete definition.
  • Specified nonnegative rational fixture masses with no total-mass normalization; repeated fixtures are allowed.
  • Allowed same-type fixtures between distinct teams, rather than excluding diagonal type pairs.
  • Specified real allocation masses and interpreted type regularity through per-capita home and away allocations.
  • Made explicit that the target has finished its fixtures and that ties count as winning.
  • Defined m as the outcome-set size and L as the total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The continuous feasibility problem belongs to \(\mathrm P\), with running time polynomial in \(m,\tau,L\). The decisive point is that all allocation variables are real and all constraints are linear.

Linear-program formulation. Index the types by \(T=\{1,\ldots,\tau\}\). Introduce one real variable \(x_{ab,j}\) for every \(a,b\in T\) and \(j\in\{1,\ldots,m\}\). There are \(n=m\tau^2\) variables.

For each type \(t\), define the coefficient of \(x_{ab,j}\) in its score constraint by
\[ A_{t,(a,b,j)} = \mathbf 1_{\{a=t\}}\alpha_j+\mathbf 1_{\{b=t\}}\beta_j. \]
Thus feasibility is exactly feasibility of the rational linear program
\[ x_{ab,j}\ge 0,\qquad \sum_{j=1}^{m}x_{ab,j}=q_{ab},\qquad \sum_{a,b\in T}\sum_{j=1}^{m}A_{t,(a,b,j)}x_{ab,j}\le \mu_t c_t. \]

In particular, a fixture between teams of the same type has coefficient \(A_{t,(t,t,j)}=\alpha_j+\beta_j\). This correctly includes both its home and away score contributions.

These constraints are equivalent to the constraints in the question: regrouping the last sum gives
\[ \sum_{a,b\in T}\sum_{j=1}^{m}A_{t,(a,b,j)}x_{ab,j} = \sum_{u\in T}\sum_{j=1}^{m} \bigl(\alpha_jx_{tu,j}+\beta_jx_{ut,j}\bigr). \]
Type regularity introduces no additional unknowns or nonlinear constraints. Each \(\mu_t\) is a fixed positive rational, so the stated per-team proportions are well-defined for every allocation.

Encoding size and polynomial-time solvability. Replace each fixture equality by two inequalities. Including nonnegativity, the program then has \(n=m\tau^2\) variables and \(k=2\tau^2+\tau+n\) inequalities.

Every matrix coefficient is one of \(0,-1,1,\alpha_j,\beta_j,\alpha_j+\beta_j\), possibly with its sign reversed. Every right-hand side is \(0\), a signed fixture mass, or a product \(\mu_t c_t\). Adding or multiplying two binary-encoded rationals produces a rational whose encoding length is bounded by a constant times the sum of their encoding lengths. Consequently, every constructed coefficient has encoding length \(O(L+1)\). Even a dense representation of the entire program has length \(O((kn+k)(L+1))\), which is polynomial in \(m,\tau,L\), and can be constructed in polynomial time.

The polynomial-time theorem for rational linear programming states that feasibility of a system of rational linear inequalities over real variables can be decided in time polynomial in the system’s binary encoding length. Its hypotheses hold here: the system is finite, all coefficients are rational, and every constraint is linear. The theorem decides exact feasibility, including cases where the feasible set has empty interior. It therefore handles the weak inequalities required by the rule that ties count as winning.

Applying this theorem proves the claimed polynomial running time.

Relation to the discrete problem. Indivisible fixtures restrict allocations to discrete choices; that restriction is absent here. Continuous masses allow mixtures of outcomes, and the resulting feasibility conditions form a linear program. The stated discrete \(\mathrm{NP}\)-completeness result therefore does not imply hardness of this continuous version. The argument applies to every outcome set supplied in the input, including sets whose coordinates have either sign.
