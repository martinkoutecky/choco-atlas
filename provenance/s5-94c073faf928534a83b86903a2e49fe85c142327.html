The continuous mirror question, as graded

Given finitely many household types \(T\), rational masses \(\mu_t>0\) summing to \(1\), demands \(d_t>0\), and per-capita supply \(s<D:=\sum_{t\in T}\mu_t d_t\), with every household connected directly to the source, compute the largest \(r\) for which a feasible schedule exists. A schedule is a measurable function \(h_t:[0,1]^2\to\{0,1\}\), where \(z\) indexes households within type \(t\) and \(u\) is time; it must satisfy \(\sum_t\mu_t d_t\int_0^1h_t(z,u)\,dz\le s\) for almost every \(u\), and \(\int_0^1h_t(z,u)\,du\ge r\) for almost every household \(z\) of every type. Return \(r\) and a concise description of a schedule attaining it.

Each type has a binary-rational demand \(d_t>0\); constant per-capita supply is a binary rational \(s\) satisfying \(0<s<D:=\sum_{t\in T}\mu_t d_t\). Let \(L\) be the total input bit length. Every household is directly connected to the source.
Type \(t\) consists of an atomless population indexed by \(z\in[0,1]\), with mass measure \(\mu_t\,dz\); time is \(u\in[0,1]\). A schedule consists of jointly Lebesgue-measurable functions \(h_t:[0,1]^2\to\{0,1\}\). Connection supplies the full demand; utility is connection duration.
For \(r\in[0,1]\), feasibility means \(\sum_{t\in T}\mu_t d_t\int_0^1h_t(z,u)\,dz\le s\) for almost every \(u\), and \(\int_0^1h_t(z,u)\,du\ge r\) for almost every \(z\), for each \(t\). All integrals and null sets use Lebesgue measure.
The computational problem is to return the exact largest feasible \(r\) and an attaining schedule, represented by finite formulas using binary-rational constants, arithmetic, comparisons, and Boolean operations to specify each \(h_t\).

For finitely many individual households with the same connection-duration utilities and direct source connections, computing the optimum is NP-hard, even deciding whether \(r\ge\tfrac12\); a leximin FPTAS is also known for tree networks. [Source](https://arxiv.org/html/2506.02193v1)

Result

The exact atomless problem is solvable in polynomial time. Its optimum is \(r^\star=s/D\), and an attaining schedule has a constant number of arithmetic operations and comparisons per type.

The proof uses the atomless population within each type: at every time, exactly the fraction \(r^\star\) of each type is connected, while every household receives connection duration \(r^\star\).

1. Upper bound

Let \(r\) be feasible, with schedule \(h_t\). Because each \(h_t\) is jointly measurable, nonnegative, and bounded, Tonelli’s theorem allows us to interchange its population and time integrals.

Integrating the household duration constraints and then the capacity constraint gives

\[ rD =\sum_{t\in T}\mu_t d_t\int_0^1 r\,dz \le \sum_{t\in T}\mu_t d_t\int_0^1\int_0^1 h_t(z,u)\,du\,dz =\int_0^1\sum_{t\in T}\mu_t d_t\int_0^1h_t(z,u)\,dz\,du \le s. \]

The exceptional null sets do not affect these integrals. Since \(D>0\), every feasible value satisfies \(r\le s/D\).

2. A finite formula attaining the bound

Write \(s/D=p/q\), where \(p,q\) are positive integers. The hypothesis \(0<s<D\) implies \(0<p<q\). Put \(r_0=p/q\).

For every type \(t\), define \(h_t(z,u)\) to be the truth value, interpreted as either \(0\) or \(1\), of the formula

\[ \bigl(z\ge u\ \land\ q(z-u)<p\bigr) \ \lor\ \bigl(z<u\ \land\ q(z-u+1)<p\bigr). \]

This formula uses only integer constants, arithmetic, comparisons, and Boolean operations. Its two branches are disjoint. Moreover, each branch defines an intersection of affine half-planes, so \(h_t\) is jointly Lebesgue-measurable.

Capacity at each time

Fix \(u\in[0,1]\). The first branch selects \(z\in[u,u+r_0)\cap[0,1]\), whose measure is \(\min(r_0,1-u)\).

The second branch selects \(z\in[0,1]\) satisfying \(z<u+r_0-1\). Because \(r_0<1\), this inequality already implies \(z<u\). Its measure is \(\max(0,u+r_0-1)\).

Thus, for every \(u\),

\[ \int_0^1h_t(z,u)\,dz =\min(r_0,1-u)+\max(0,u+r_0-1) =r_0. \]

Indeed, when \(u\le1-r_0\), the two terms are \(r_0\) and \(0\); when \(u>1-r_0\), they are \(1-u\) and \(u+r_0-1\).

Consequently, the total load at every time is

\[ \sum_{t\in T}\mu_t d_t\int_0^1h_t(z,u)\,dz =r_0D=s. \]

Duration of each household

Fix \(z\in[0,1]\). The first branch selects \(u\in(z-r_0,z]\cap[0,1]\), with measure \(\min(r_0,z)\).

The second branch selects \(u>z+1-r_0\) within \([0,1]\). Since \(r_0<1\), this inequality implies \(u>z\), as required by that branch. Its measure is \(\max(0,r_0-z)\).

Therefore, for every \(z\),

\[ \int_0^1h_t(z,u)\,du =\min(r_0,z)+\max(0,r_0-z) =r_0. \]

For \(z\le r_0\), the terms are \(z\) and \(r_0-z\); for \(z>r_0\), they are \(r_0\) and \(0\).

The schedule therefore attains \(r_0=s/D\). Combined with the upper bound, this proves \(r^\star=s/D\).

3. Exact computation and output size

To verify polynomial bit complexity, write the binary-encoded input rationals as \(\mu_t=a_t/b_t\), \(d_t=c_t/e_t\), and \(s=f/g\), with positive integer numerators and denominators.

Compute

\[ Q=\prod_{t\in T}b_te_t, \qquad A=\sum_{t\in T}a_tc_t\,\frac{Q}{b_te_t}. \]

Every indicated division is exact, and \(D=A/Q\). Hence we may use the integers \(p=fQ\) and \(q=gA\). They satisfy \(p/q=s/D\) and \(0<p<q\); reduction to lowest terms is unnecessary.

The bit length of \(Q\) is bounded by the sum of the input denominator lengths. Each summand defining \(A\) has \(O(L)\) bits, so \(A\), \(p\), and \(q\) have \(O(L+\log\tau)\) bits. Computing them requires \(O(\tau)\) integer arithmetic operations on integers of polynomial bit length and therefore takes polynomial time.

The exact optimum is returned as the fraction \(p/q\). For each type, the algorithm outputs the formula from Section 2. Even if the constants are repeated separately in every formula, the total schedule representation has size \(O(\tau(L+\log\tau))\).

Thus both exact optimization and construction of an attaining schedule take time polynomial in \(\tau,L\), with \(m=1\).

4. Relation to the finite-household result

The [cited paper](https://arxiv.org/html/2506.02193v1) defines configurations as subsets of finitely many individually indexed households and establishes hardness in that model.

Here, each type contains an atomless population. The construction above selects exactly the fraction \(r^\star\) of every type at every time. Such fractions need not be realizable by subsets of a finite population, so the finite-household hardness does not transfer to this problem.
