The continuous mirror question, as graded

Given an item set \(E\), types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), rational nonnegative per-member utilities \(u_{tj}\), and per-capita submodular capacities \(\rho\), choose type-level assignment lotteries \(x_{tj}\ge 0\). Require \(\sum_j x_{tj}\le 1\) and \(z_j=\sum_t\mu_t x_{tj}\in P(\rho)\); define \(U_t(x_t)=\sum_j u_{tj}x_{tj}\), require envy-freeness \(U_t(x_t)\ge U_t(x_s)\) for every \(t,s\), and weighted Nash welfare \(W_\mu(x)=\exp(\sum_t\mu_t\log U_t(x_t))\). Let \(W_\mu^*\) be the maximum over all feasible assignments, without the envy-free constraint. Can an algorithm, polynomial in \(|E|\), \(|T|\), the input bit length, and \(\log(1/eta)\), return an envy-free feasible assignment with \(W_\mu(x)\ge W_\mu^*/(e^{1/e}+\eta)\), using value-oracle access to \(\rho\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq1\) types \(T\) with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) items \(E\), binary rational utilities \(u_{tj}\geq0\), and per-capita capacities given by a normalized monotone submodular function \(\rho:2^E\to\mathbb{Q}_{\geq0}\), with \(\rho(\emptyset)=0\), accessible through an exact value oracle.
Let \(L\) be the explicit input bit length plus a supplied uniform bound on the bit length of oracle answers. Define \(P(\rho)=\{z\in\mathbb{R}_{\geq0}^E:\sum_{j\in S}z_j\leq\rho(S)\text{ for every }S\subseteq E\}\).
An assignment specifies the same lottery \(x_t\) for every member of type \(t\): \(x_{tj}\geq0\), \(\sum_jx_{tj}\leq1\), and \(z_j=\sum_t\mu_tx_{tj}\), with \(z\in P(\rho)\). Unassigned probability is permitted.
Write \(U_t(v)=\sum_ju_{tj}v_j\). Envy-freeness means \(U_t(x_t)\geq U_t(x_s)\) for every \(t,s\in T\).
Define \(W_\mu(x)=\prod_tU_t(x_t)^{\mu_t}\), taking it to be zero if any utility is zero, and let \(W_\mu^*\) be its maximum over feasible assignments without envy-freeness.

Can an algorithm, for every binary rational \(0<\eta<1\), return an envy-free feasible assignment satisfying \(W_\mu(x)\geq W_\mu^*/(\mathrm{e}^{1/\mathrm{e}}+\eta)\), with running time and number of value-oracle queries polynomial in \(m,\tau,L,\log(1/\eta)\)?

For finitely many equally weighted agents, maximizing Nash welfare subject to envy-freeness gives an \(\mathrm{e}^{1/\mathrm{e}}\)-approximation; polynomial arithmetic-operation and value-oracle bounds are established for approximate computation. [Finite-agent result](https://arxiv.org/html/2507.03359v2#Thmtheorem3.4)
No result settling the stated guarantee with arbitrary binary rational masses and polynomial dependence on support size was identified in the literature search.

Modeling choices made when packaging the task

  • Specified that capacities are nonnegative, monotone, and normalized, as required by the underlying submodular assignment model.
  • Specified rational capacity values, exact oracle answers, and a uniform oracle-answer bit-length bound included in L, to make the requested bit-complexity bound well-defined.
  • Extended welfare to zero utilities using the weighted product convention, preserving the permitted nonnegative utility domain.
  • Restricted the accuracy parameter to binary rational 0<eta<1 so that its encoding and log(1/eta) dependence are well-defined.
  • Made the item set and society nonempty and explicitly retained partial lotteries with at most one assigned item per member.

Result

Yes. The finite-agent welfare bound extends to rational masses by replication and averaging. Replication is needed only for the existence proof. The algorithm works directly with the \(\tau\) types.

To obtain the requested bit complexity while preserving exact feasibility and envy-freeness, we optimize an implicit rational piecewise-linear approximation to the logarithmic objective.

Write \(C=\mathrm{e}^{1/\mathrm{e}}\).

1. Removing the zero-welfare case

Query every singleton and define
\[ J=\{j\in E:\rho(\{j\})>0\}. \]

For \(j\notin J\), feasibility implies \(\sum_t\mu_tx_{tj}=0\). Since every mass is positive and every assignment coordinate is nonnegative, \(x_{tj}=0\) for every type.

Consequently, if some type has zero utility for every item in \(J\), then \(W_\mu^*=0\). Returning the zero assignment settles this case.

Otherwise, restrict the instance to \(J\). The restricted capacity function remains normalized, monotone, and submodular. For each type, divide its utilities by
\[ c_t=\max_{j\in J}u_{tj}>0. \]
This preserves envy-freeness and multiplies all welfare values by the same positive factor \(\prod_tc_t^{-\mu_t}\). Thus approximation ratios are unchanged. Henceforth utilities are normalized so that
\[ 0\leq u_{tj}\leq1,\qquad \max_{j\in J}u_{tj}=1. \]

Let
\[ r=\min_{j\in J}\rho(\{j\}),\qquad d=\frac{\min\{1,r\}}{m}. \]
Give every type the identical lottery \(b\), where \(b_j=d\) for \(j\in J\).

Its row sum is at most \(md\leq1\). For every nonempty \(S\subseteq J\), monotonicity gives
\[ b(S)\leq md\leq r\leq\rho(S). \]
Because the masses sum to one, its aggregate consumption is also \(b\). Thus this assignment is feasible and envy-free, and
\[ U_t(b)\geq d>0 \]
for every type. The rational number \(d\) has polynomial encoding length.

2. Extending the welfare bound to rational masses

Let \(\mathcal F\) be the feasible assignment polytope and let \(\mathcal F_{\mathrm{EF}}\) be its envy-free subpolytope. Both are compact. The welfare function is continuous, and the preceding assignment has positive welfare, so both welfare maxima exist and are positive.

We prove
\[ \max_{x\in\mathcal F_{\mathrm{EF}}}W_\mu(x) \ \geq\ \frac{W_\mu^*}{C}. \tag{1} \]

Choose an integer \(D\) for which \(n_t=D\mu_t\) is a positive integer for every type. Construct a finite-agent instance with \(n_t\) identical agents of type \(t\), and capacity function
\[ \rho_D(S)=D\rho(S). \]
There are \(D\) agents because \(\sum_t\mu_t=1\).

The function \(\rho_D\) satisfies the hypotheses of the finite-agent welfare theorem: it is normalized, monotone, and submodular, and agents have nonnegative linear utilities and row sums at most one. The existence part of [Theorem 3.4](https://arxiv.org/html/2507.03359v2#Thmtheorem3.4) therefore supplies an envy-free finite assignment whose Nash welfare is at least the unrestricted finite optimum divided by \(C\).

Lifting any type assignment to all its copies preserves feasibility. Moreover, its finite Nash welfare is exactly
\[ \prod_t U_t(x_t)^{n_t/D} = W_\mu(x). \]
The unrestricted finite optimum is therefore at least \(W_\mu^*\).

Now take the finite envy-free assignment \(y\), and average within each type:
\[ \bar y_t=\frac1{n_t}\sum_{a\text{ of type }t}y_a. \]
Row constraints survive averaging, and
\[ \sum_t\mu_t\bar y_t = \frac1D\sum_a y_a \in P(\rho). \]

For any types \(t,s\), finite envy-freeness gives \(U_t(y_a)\geq U_t(y_b)\) for every copy \(a\) of \(t\) and copy \(b\) of \(s\). Averaging these inequalities proves
\[ U_t(\bar y_t)\geq U_t(\bar y_s). \]
Thus \(\bar y\) is envy-free.

Finally, concavity of the logarithm gives
\[ \sum_t\mu_t\log U_t(\bar y_t) \geq \frac1D\sum_a\log U_{\operatorname{type}(a)}(y_a). \]
All utilities here are positive because the finite welfare guarantee is positive. Averaging therefore does not decrease welfare, proving (1).

The possibly enormous value of \(D\) is used only in this existence argument.

3. Restricting utilities away from zero

Define
\[ F(x)=\sum_t\mu_t\log U_t(x_t). \]
On positive-utility assignments, \(F(x)=\log W_\mu(x)\).

Set
\[ \theta=\frac{\eta}{16}, \qquad a=\theta d, \qquad \delta=\frac{\eta}{16}, \]
and introduce the rational polytope
\[ K= \{x\in\mathcal F_{\mathrm{EF}}:U_t(x_t)\geq a \text{ for every }t\}. \]
Normalization and the row constraints imply \(U_t(x_t)\leq1\) throughout \(K\).

Let \(x^{\mathrm{EF}}\) maximize welfare over \(\mathcal F_{\mathrm{EF}}\), and mix it with the common lottery:
\[ x^\theta=(1-\theta)x^{\mathrm{EF}}+\theta b. \]
Every defining constraint is linear, so \(x^\theta\) is feasible and envy-free. Furthermore,
\[ U_t(x^\theta_t)\geq\theta U_t(b)\geq a, \]
so \(x^\theta\in K\). Also,
\[ F(x^\theta) \geq F(x^{\mathrm{EF}})+\log(1-\theta) \geq F(x^{\mathrm{EF}})-2\theta. \tag{2} \]
The last inequality follows from
\[ -\log(1-\theta) =\int_0^\theta\frac{ds}{1-s} \leq2\theta, \]
since \(\theta<1/2\).

Thus restricting to \(K\) loses at most \(2\theta\) in logarithmic welfare.

4. An implicit rational approximation to the logarithm

We construct a concave rational piecewise-linear function \(g\) satisfying
\[ |g(q)-\log q|\leq\delta \qquad(a\leq q\leq1), \tag{3} \]
with polynomial-time exact evaluation and supporting-line computation.

Choose \(N=2^k\) sufficiently large that
\[ h=\frac{1-a}{N}\leq\frac{\delta a}{2}. \]
Here \(k\) is polynomially bounded in \(L+\log m+\log(1/\eta)\). Define grid points
\[ q_i=a+ih,\qquad 0\leq i\leq N. \]

Choose a precision \(p\) such that
\[ \gamma=2^{-p}\leq \min\left\{\frac{h^2}{8},\frac{\delta}{2}\right\}. \]
For each grid point, let \(r_i\) be a deterministically computed dyadic approximation satisfying
\[ |r_i-\log q_i|\leq\gamma. \]
Define \(g\) by linear interpolation of the points \((q_i,r_i)\).

Although this defines exponentially many grid values, the algorithm computes only queried values.

Concavity

For an interior grid point, the second difference of the exact logarithm satisfies
\[ \log(q_i+h)-2\log q_i+\log(q_i-h) = -\int_{-h}^{h}\frac{h-|s|}{(q_i+s)^2}\,ds \leq-h^2. \]
Indeed, all \(q_i+s\) lie in \([a,1]\), so their squared reciprocals are at least one.

Replacing logarithms by the \(r_i\) changes a second difference by at most \(4\gamma\). Hence
\[ r_{i+1}-2r_i+r_{i-1} \leq-h^2+4\gamma \leq-\frac{h^2}{2}<0. \]
The interpolation slopes decrease, proving concavity.

Approximation error

The logarithm is \(1/a\)-Lipschitz on \([a,1]\). Its exact linear interpolant on any grid interval consequently differs from it by at most \(h/a\). Perturbing the endpoint values contributes at most \(\gamma\). Therefore
\[ |g(q)-\log q| \leq\frac{h}{a}+\gamma \leq\delta, \]
proving (3).

Exact evaluation and coefficient size

Given rational \(q\in[a,1]\), integer division identifies its grid interval. Computing its two endpoint approximations determines \(g(q)\) and that segment’s affine extension exactly.

The logarithm approximations themselves require polynomial bit time. Explicitly, scale a positive rational \(q\) as \(q=2^\ell w\), with \(1\leq w<2\), and use
\[ \log w = 2\sum_{n=0}^{\infty} \frac{1}{2n+1} \left(\frac{w-1}{w+1}\right)^{2n+1}. \]
The ratio has absolute value at most \(1/3\), giving geometric convergence. The same series computes \(\log2\). Truncation followed by deterministic dyadic rounding produces the required error in polynomial time.

Every grid point, dyadic value, and segment coefficient has polynomial encoding length in \(L,m,\log(1/\eta)\). This holds despite the number of segments being exponential.

5. Exact optimization over a rational polytope

Introduce variables \(v_t\), and solve
\[ \max \sum_t\mu_tv_t \]
subject to
\[ x\in K,\qquad -B\leq v_t\leq g(U_t(x_t)) \quad\text{for every }t, \tag{4} \]
where
\[ B=2+\left\lceil\log_2(1/a)\right\rceil. \]

The lower bound does not interfere with optimization: by (3), \(g(q)>-B\) throughout \([a,1]\).

Because \(g\) is concave and piecewise linear, it equals the minimum of its segment extensions. Thus (4) defines a bounded rational polytope \(Q\). Its dimension is at most \(\tau m+\tau\), and every defining inequality has polynomial encoding length.

We now give a polynomial-time strong separation oracle for \(Q\).

First check all explicit inequalities: nonnegativity, row sums, envy-freeness, utility lower bounds, and the bounds on \(v_t\).

To check the polymatroid constraints, form \(z_j=\sum_t\mu_tx_{tj}\) and minimize
\[ S\longmapsto\rho(S)-\sum_{j\in S}z_j. \]
This function is submodular because the second term is modular. A negative minimum supplies a violated capacity inequality; a nonnegative minimum certifies every capacity inequality. Exact value-oracle submodular minimization is polynomial-time, including polynomial bit complexity for rational answers of bounded encoding length; see [Iwata–Fleischer–Fujishige](https://arxiv.org/abs/math/0004089).

Finally, evaluate \(g(U_t(x_t))\) exactly. If \(v_t\) exceeds this value, the affine extension of the active segment gives a violated inequality valid throughout \(Q\). Concavity, proved above, guarantees its validity.

The strong separation–optimization theorem for well-described rational polyhedra now solves (4) exactly in polynomial bit time and polynomially many separation calls. Its hypotheses are precisely bounded dimension and inequality encoding length, a rational objective, and a strong separation oracle; full dimensionality is unnecessary. See [Grötschel–Lovász–Schrijver, Chapter 6](https://www.zib.de/userpage/groetschel/pubnew/paper/groetschellovaszschrijver1988.pdf).

Thus the algorithm returns a rational assignment \(\hat x\in K\), with exact feasibility and exact envy-freeness.

Writing
\[ G(x)=\sum_t\mu_tg(U_t(x_t)), \]
optimality in (4) means that \(\hat x\) maximizes \(G\) over \(K\). Since the masses sum to one, (3) implies
\[ |G(x)-F(x)|\leq\delta \qquad(x\in K). \]
Consequently,
\[ F(\hat x) \geq G(\hat x)-\delta \geq G(x^\theta)-\delta \geq F(x^\theta)-2\delta. \tag{5} \]

6. Welfare guarantee and complexity

Combining (1), (2), and (5) yields
\[ F(\hat x) \geq \log W_\mu^*-\log C-2\theta-2\delta = \log W_\mu^*-\log C-\frac{\eta}{4}. \]
Therefore
\[ W_\mu(\hat x) \geq \frac{W_\mu^*}{C\,\mathrm{e}^{\eta/4}}. \]

To compare denominators, \(C<2\), and
\[ \log\left(1+\frac{\eta}{C}\right) \geq\frac{\eta}{C+\eta} >\frac{\eta}{3} >\frac{\eta}{4}. \]
Here the first inequality follows by integrating \(1/(1+s)\) on \([0,\eta/C]\). Hence
\[ C\,\mathrm{e}^{\eta/4}<C+\eta, \]
which proves the requested guarantee.

Finally, every positive singleton oracle answer is at least \(2^{-O(L)}\), so
\[ \log(1/a)=O\bigl(L+\log m+\log(1/\eta)\bigr). \]
All rational coefficients used by the implicit linear program therefore have polynomial encoding length. Each separation call uses polynomial bit time and polynomially many value-oracle queries, and exact linear optimization makes polynomially many such calls.

The total running time and number of value-oracle queries are consequently polynomial in \(m,\tau,L,\log(1/\eta)\), with explicit input-reading time included in the input-length convention.
