The computation is solvable exactly in deterministic polynomial time. All output coordinates are rational.

Set \(S=L+m^2\log_2(m+1)\). A conservative bound, using ordinary integer arithmetic, is

\( \displaystyle O\!\left((\tau m^2+m^6)S^2\right) \)

bit operations. The algorithm uses \(O(\tau m^2+m^6)\) arithmetic operations on integers with \(O(S)\) bits. Each output coordinate has \(O(S)\) bits.

The geometric decomposition agrees with the least-squares characterizations in [Hirani–Kalyanaraman–Watts](https://arxiv.org/html/1011.1716v4) and [Jiang–Lim–Yao–Ye](https://www.math.ucdavis.edu/~saito/data/tensor/jiang-lim-yao-ye-hodgerank.pdf). The proof below establishes the exact rational computation and its bit complexity directly, including disconnected graphs and zero components.

1. An auxiliary system indexed by edges

Write \(n=|E|\), \(k=|T|\), \(A=\partial_1\), and \(B=\partial_2\). Thus \(n\leq\binom m2\) and \(k\leq\binom m3\).

The signed boundary of each triangle has zero vertex boundary: for a cyclically oriented triangle its vertex boundary is \((v-u)+(w-v)+(u-w)=0\). Changing orientations preserves this identity. Consequently,

\( \displaystyle AB=0. \)

Let \(\Delta=A^TA+BB^T=\Delta_1\). For every \(z\in\mathbb R^E\),

\( \displaystyle z^T\Delta z=\|Az\|^2+\|B^Tz\|^2. \)

It follows that

\( \displaystyle \ker\Delta=\ker A\cap\ker B^T. \)

We will solve the rational linear system

\[ \displaystyle \Delta^2x=\Delta\omega. \tag{1} \]

This system is always consistent. Indeed, symmetry gives \(\operatorname{im}\Delta=(\ker\Delta)^\perp\). Moreover,

\( \displaystyle z^T\Delta^2z=\|\Delta z\|^2, \)

so \(\ker\Delta^2=\ker\Delta\). Therefore \(\operatorname{im}\Delta^2=\operatorname{im}\Delta\), which contains \(\Delta\omega\).

Given any solution of (1), define

\[ \displaystyle \alpha=Ax,\qquad \beta=B^Tx,\qquad h=\omega-\Delta x. \tag{2} \]

These formulas produce all the requested outputs without solving a system whose unknowns are indexed by triangles.

2. Correctness and the required normalizations

Orthogonal decomposition

By construction,

\( \displaystyle \omega=A^T\alpha+B\beta+h. \)

Equation (1) implies \(\Delta h=0\), hence \(Ah=0\) and \(B^Th=0\). Therefore \(h\) is orthogonal to both \(\operatorname{im}A^T\) and \(\operatorname{im}B\). These latter spaces are orthogonal because

\( \displaystyle \langle A^Ta,Bb\rangle=a^TABb=0. \)

Thus the three terms in (2) give the required orthogonal decomposition.

The score vector minimizes the objective

Set \(r=\omega-A^T\alpha=B\beta+h\). Since \(AB=0\) and \(Ah=0\), we have \(Ar=0\). For any \(z\in\mathbb R^C\),

\( \displaystyle \|\omega-A^T(\alpha+z)\|^2 =\|r-A^Tz\|^2 =\|r\|^2+\|A^Tz\|^2, \)

where the cross term vanishes because \(\langle r,A^Tz\rangle=\langle Ar,z\rangle=0\). Hence \(\alpha\) minimizes the stated objective.

For a connected component \(D\), let \(\mathbf 1_D\) denote its vertex indicator. Every edge column has total zero on \(D\), so \(\mathbf 1_D^TA=0\). Therefore

\( \displaystyle \sum_{v\in D}\alpha_v=\mathbf 1_D^TAx=0. \)

The normalized minimizer is unique. Indeed, equality in the preceding objective identity requires \(A^Tz=0\). This means \(z_v=z_u\) along every edge, so \(z\) is constant on each connected component. If its sum on each component is also zero, then \(z=0\).

The triangle potential has minimum norm

We have \(\beta=B^Tx\), so \(\beta\) is orthogonal to \(\ker B\). Any other representation \(\widetilde\beta\) of the same triangle component satisfies \(B\widetilde\beta=B\beta\); therefore \(\widetilde\beta=\beta+z\) for some \(z\in\ker B\). Consequently,

\( \displaystyle \|\widetilde\beta\|^2=\|\beta\|^2+\|z\|^2. \)

Thus \(\beta\) is the unique minimum-norm representation.

These conclusions do not depend on which solution of (1) is chosen. The difference \(d\) of two solutions belongs to \(\ker\Delta^2=\ker\Delta\), and hence satisfies \(Ad=0\), \(B^Td=0\), and \(\Delta d=0\).

3. Exact construction from the support

Write each input mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\), and define

\( \displaystyle D=\prod_{t=1}^{\tau}b_t,\qquad w_t=a_t(D/b_t). \)

The integer \(D\) has \(O(L)\) bits. The positivity and normalization of the masses imply \(\sum_t w_t=D\).

Invert each ranking into a position array. Each sign \(q_t(e)\) can then be obtained by comparing the two positions. Compute the integer edge vector

\( \displaystyle W_e=\sum_{t=1}^{\tau}w_tq_t(e). \)

Then \(\omega=W/D\) and \(|W_e|\leq D\). This step requires \(O(\tau(m+n))\) arithmetic operations, together with reading the input.

Enumerate triangles by checking all vertex triples, requiring \(O(m^3)\) graph operations. Construct \(\Delta=A^TA+BB^T\). Each triangle contributes only nine signed entries to \(BB^T\), so construction takes \(O(n^2+k)\) arithmetic operations.

Now form

\( \displaystyle H=\Delta^2,\qquad g=\Delta W, \)

and solve the consistent integer-coefficient system

\[ \displaystyle HX=g. \tag{3} \]

Setting \(x=X/D\) gives a solution of (1).

If \(n=0\), no linear solve is needed: return \(\alpha=0\) and the empty vectors \(\beta,h\).

4. Bit complexity of the exact solve

Bounds on the coefficients

Assume \(n>0\), so \(m\geq2\).

A diagonal entry of \(A^TA\) is \(2\), and a diagonal entry of \(BB^T\) counts triangles containing that edge, at most \(m-2\). For distinct edges, each of the corresponding entries in \(A^TA\) and \(BB^T\) has absolute value at most \(1\): two distinct edges share at most one vertex and belong together to at most one triangle. Therefore

\( \displaystyle |\Delta_{ij}|\leq m. \)

It follows that

\[ \displaystyle |H_{ij}|\leq nm^2,\qquad |g_i|\leq nmD. \tag{4} \]

Thus the coefficient matrix has \(O(\log(m+1))\)-bit entries, while the right-hand side has \(O(L+\log(m+1))\)-bit entries.

Rank deficiency causes no difficulty

The matrix \(H=\Delta^2\) is positive semidefinite. Symmetric elimination can select a nonsingular principal submatrix \(Q\) of order \(s=\operatorname{rank}H\).

To justify this selection, after choosing an invertible principal block, its Schur complement remains positive semidefinite: its quadratic form is obtained by minimizing the original quadratic form over the eliminated coordinates. A nonzero positive semidefinite matrix has a positive diagonal entry. Indeed, if all diagonal entries vanish, evaluating its quadratic form on coordinate-vector sums and differences forces every off-diagonal entry to vanish.

Thus a positive diagonal pivot exists until the remaining Schur complement is zero.

The selected \(s\) rows span the row space of \(H\). Set all variables outside the selected indices to zero, and solve \(QX_I=g_I\). Since (3) is consistent, satisfying these independent rows satisfies every row. This yields a rational solution of (3).

Fraction-free elimination has polynomial-size intermediates

For completeness, fraction-free elimination updates remaining entries by

\( \displaystyle f'_{ij}=\frac{f_{pp}f_{ij}-f_{ip}f_{pj}}{d}, \)

where \(d\) is the preceding pivot determinant, initially \(1\). The bordered-minor determinant identity shows inductively that each updated entry is a determinant of a bordered submatrix; in particular, every indicated division is exact. The same identity applies to the augmented right-hand-side column.

Let \(U=nm^2\) and \(V=nmD\). By the determinant expansion, an order-\(\ell\) minor using only coefficient columns has absolute value at most \(\ell!U^\ell\). A minor with one right-hand-side column has absolute value at most \(\ell!U^{\ell-1}V\). Since \(\ell\leq n\), their bit lengths are respectively

\( \displaystyle O(n\log(m+1)),\qquad O(L+n\log(m+1)). \)

These bounds also control exact back substitution. Specifically, let \(\delta=\det Q\). By Cramer’s rule the solution has the form \(X_I=N_I/\delta\), where each entry of \(N_I\) is an integer determinant with one right-hand-side column. Back substitution can compute these integer numerators using the common denominator \(\delta\); its divisions are exact because these Cramer numerators are integers.

There are \(O(n^3)\) elimination operations. All operands, products, and intermediate sums have

\( \displaystyle O(L+n\log(m+1))=O(S) \)

bits. Ordinary integer multiplication and division therefore give an \(O(n^3S^2)\) bit bound for the solve.

Output size

Extend \(N_I\) by zeros outside the selected indices. The outputs can all use the common denominator \(D\delta\):

\( \displaystyle \alpha=\frac{AN}{D\delta},\qquad \beta=\frac{B^TN}{D\delta},\qquad h=\frac{\delta W-\Delta N}{D\delta}. \)

The determinant bounds above show that every numerator and denominator has \(O(S)\) bits. Reducing fractions, if desired, preserves the stated time bound.

5. Total running time and degenerate cases

Computing the pairwise data, enumerating triangles, constructing and squaring \(\Delta\), solving (3), and assembling the outputs requires

\( \displaystyle O(\tau m^2+m^6) \)

integer arithmetic operations. Accounting for the \(O(S)\)-bit operands gives

\( \displaystyle O\!\left((\tau m^2+m^6)\bigl(L+m^2\log_2(m+1)\bigr)^2\right) \)

bit operations. There are \(O(m^3)\) output coordinates, each with polynomial bit length.

Isolated vertices receive score zero. If there are no triangles, \(\beta\) is empty. If any decomposition component vanishes, the formulas return zero for that component and remain valid. The support is processed as the supplied list of \(\tau\) rankings; no enumeration of all possible rankings is needed.

Because the rankings are explicitly listed, \(m\) and \(\tau\) are bounded by the input length under the stated encoding. The displayed bound is therefore polynomial in \(L\), settling the exact computation as polynomial-time solvable.
