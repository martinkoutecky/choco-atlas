The continuous mirror question, as graded

Given a finite set of complete tenant types \(\mathcal T\) with rational masses \(\mu_t\) summing to \(1\), \(\sigma\) room classes with rational proportions \(q_r\) summing to \(1\), a rational room-supply ratio \(\kappa\in[1/2,1]\), and utility tables \(u_t(s,r)\) and \(u_t(\bot,r)\), find a welfare-maximizing feasible mass assignment. Its variables are nonnegative masses \(x^S_{t,r}\) of type-\(t\) singles and \(x^P_{\{t,s\},r}\) of pairs in room class \(r\); each type’s assigned mass must equal \(\mu_t\), counting two units for a same-type pair, and each class must use room mass \(\kappa q_r\). Maximize the total utility of singles and pairs, where a pair of distinct types \(t,s\) contributes \(u_t(s,r)+u_s(t,r)\) and a same-type pair contributes \(2u_t(t,r)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq1\) complete tenant types \(\mathcal T\), each with positive binary-rational mass \(\mu_t\), with \(\sum_t\mu_t=1\). Here \(\tau\) counts supported types, not possible types; there is no separate finite-agent count \(m\).
There are \(\sigma\geq1\) room classes with positive binary-rational proportions \(q_r\), where \(\sum_rq_r=1\), and a binary-rational room-supply ratio \(\kappa\in[1/2,1]\). All entries of the explicitly supplied tables \(u_t(s,r)\) and \(u_t(\bot,r)\) are nonnegative binary rationals; \(\bot\) denotes living alone. Utilities may depend jointly on roommate type and room class and need not be symmetric.
Choose nonnegative real masses \(x^S_{t,r}\) of singles and \(x^P_{\{t,s\},r}\) of pairs, indexed by unordered pairs with repetition. Same-type pairs contain two distinct tenants of that type; all pairings are allowed, and masses may split arbitrarily.
Feasibility requires \(\sum_r(x^S_{t,r}+\sum_{s\ne t}x^P_{\{t,s\},r}+2x^P_{\{t,t\},r})=\mu_t\) for every type and \(\sum_tx^S_{t,r}+\sum_{t\leq s}x^P_{\{t,s\},r}=\kappa q_r\) for every class, using any fixed ordering of types. Every room is occupied by one single or one pair.
Define \(W(x)=\sum_{t,r}u_t(\bot,r)x^S_{t,r}+\sum_{r,t\leq s}(u_t(s,r)+u_s(t,r))x^P_{\{t,s\},r}\), and let \(\mathrm{OPT}\) be its maximum over feasible assignments. Welfare is measured before rent; no prices or fairness constraints are imposed. Let \(L\) be the total binary input length.

For every fixed \(\varepsilon>0\), is there an algorithm polynomial in \(\tau,\sigma,L\) returning a feasible assignment with \(W(x)\geq\mathrm{OPT}/(4/3+\varepsilon)\), or is achieving this approximation guarantee NP-hard?

Huang, Kitch, and Melas-Kyriazi claim a polynomial-time \((4/3+\varepsilon)\)-approximation for discrete assignments with twice as many tenants as rooms. [Source](https://arxiv.org/html/2409.14600v1)
Their cited approximation result concerns unweighted set packing, so it does not itself establish the claimed weighted guarantee. [Source](https://arxiv.org/html/1304.1424v2)

Result

The stated mass-assignment problem is polynomial-time solvable exactly. Consequently, it admits the requested approximation for every fixed \(\varepsilon>0\).

This conclusion concerns the full formulation given in the question, including arbitrary asymmetric utilities, arbitrary supported types, and every permitted supply ratio. The decisive feature is that assignment masses may split arbitrarily.

1. The optimization problem is an explicit linear program

Fix an ordering of the supported types. There are

\[ N=\sigma\tau+\sigma\frac{\tau(\tau+1)}2 \]

variables: one \(x^S_{t,r}\) for each single-type/class combination and one \(x^P_{\{t,s\},r}\) for each unordered type pair and class.

Collect these variables into a vector \(x\). Define a matrix \(A\) with one row for each type and one row for each room class:

  • A single variable \(x^S_{t,r}\) has coefficient \(1\) in the type-\(t\) row and the class-\(r\) row.
  • A pair variable \(x^P_{\{t,s\},r}\), with \(t\ne s\), has coefficient \(1\) in each of the two type rows and in the class-\(r\) row.
  • A same-type pair variable \(x^P_{\{t,t\},r}\) has coefficient \(2\) in the type-\(t\) row and coefficient \(1\) in the class-\(r\) row.

All other entries are zero. Let

\[ b=\bigl((\mu_t)_{t\in\mathcal T},(\kappa q_r)_{r=1}^{\sigma}\bigr). \]

Define objective coefficients by

\[ c^S_{t,r}=u_t(\bot,r), \qquad c^P_{\{t,s\},r}=u_t(s,r)+u_s(t,r). \]

The resulting program is

\[ \max\{c^{\mathsf T}x:Ax=b,\ x\geq0\}. \]

Its equalities are exactly the feasibility conditions in the question, and its objective is exactly \(W(x)\). Thus it optimizes over the stipulated assignments themselves. No integrality condition or rounding step is required.

2. Every permitted instance is feasible

Set

\[ a=2\kappa-1, \qquad p=1-\kappa. \]

The hypothesis \(\kappa\in[1/2,1]\) implies \(a,p\geq0\). Define

\[ x^S_{t,r}=a\mu_tq_r, \]

\[ x^P_{\{t,s\},r}=2p\mu_t\mu_sq_r \quad(t<s), \qquad x^P_{\{t,t\},r}=p\mu_t^2q_r. \]

For each type \(t\) and class \(r\), its tenant mass is

\[ \begin{aligned} x^S_{t,r} +\sum_{s\ne t}x^P_{\{t,s\},r} +2x^P_{\{t,t\},r} &=a\mu_tq_r +2p\mu_tq_r\sum_{s\ne t}\mu_s +2p\mu_t^2q_r\\ &=(a+2p)\mu_tq_r\\ &=\mu_tq_r. \end{aligned} \]

Summing over classes gives \(\mu_t\).

For each class \(r\), the room mass is

\[ \begin{aligned} \sum_t x^S_{t,r} +\sum_{t\leq s}x^P_{\{t,s\},r} &=aq_r +pq_r\left(\sum_t\mu_t^2+2\sum_{t<s}\mu_t\mu_s\right)\\ &=aq_r+pq_r\left(\sum_t\mu_t\right)^2\\ &=(a+p)q_r\\ &=\kappa q_r. \end{aligned} \]

Hence this assignment is feasible, including at both endpoints of the supply interval. Same-type pair masses consume twice their mass in tenants, exactly as required.

3. Exact optimization has polynomial bit complexity

The linear program has \(N=O(\sigma\tau^2)\) variables and \(\tau+\sigma\) equality constraints. Its matrix entries belong to \(\{0,1,2\}\).

Its remaining coefficients are obtained from input rationals using either one multiplication, for \(\kappa q_r\), or one addition, for pair utilities. These operations produce rational numbers of bit length \(O(L)\). Consequently, even a dense encoding of the whole linear program has length polynomial in \(\tau,\sigma,L\), and it can be constructed in polynomial time.

The feasible set is nonempty by Section 2. It is also bounded: every variable occurs with coefficient at least \(1\) in some tenant constraint, whose other terms are nonnegative. Therefore every variable satisfies \(0\leq x_j\leq1\). The feasible set is closed, so it is compact. The linear objective consequently attains a finite maximum.

We now apply the standard exact rational linear-programming theorem: a linear program with explicitly encoded rational coefficients can be solved in time polynomial in its binary encoding length; when feasible with a finite optimum, an exact rational optimal solution can be returned. This is the polynomial-time solvability theorem for rational linear programming. [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/eng/zvmmf5239).

All its hypotheses have been checked here: explicit rational data, polynomial encoding length, feasibility, and a finite attained optimum. Equalities can, if necessary, be represented by two opposite inequalities. No full-dimensionality assumption is needed, so the endpoint cases are covered as well.

The algorithm is therefore:

  • Construct the linear program above.
  • Solve it using an exact polynomial-time rational linear-programming algorithm.
  • Return its coordinates as the single and pair masses.

The returned assignment \(x^\star\) is feasible and satisfies \(W(x^\star)=\mathrm{OPT}\). Since all utilities are nonnegative, \(\mathrm{OPT}\geq0\); therefore, for every \(\varepsilon>0\),

\[ W(x^\star)=\mathrm{OPT} \geq\frac{\mathrm{OPT}}{4/3+\varepsilon}. \]

The algorithm is independent of \(\varepsilon\).

4. Relation to the cited discrete result

The [Huang–Kitch–Melas-Kyriazi formulation](https://arxiv.org/html/2409.14600v1) assigns individual tenants and individual rooms through a partition and a permutation. Those discrete restrictions are absent from the specified mass formulation.

The cited [Cygan result](https://arxiv.org/html/1304.1424v2) concerns cardinality set packing and distinguishes the weighted variant separately. Its applicability to the discrete weighted claim is unnecessary for the proof above: the mass problem is solved directly and exactly by linear programming.
