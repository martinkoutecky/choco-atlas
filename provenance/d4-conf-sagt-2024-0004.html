The continuous mirror question, as graded

Result

The problem is polynomial-time solvable in \(\tau,k,L\). Let \(h=\min\{k,\tau\}\). A direct dynamic program computes an optimal placement and the exact minimum cost using

\(O(h\tau^2+k)\)

arithmetic operations. With ordinary binary encodings of rational numbers, the algorithm below has the bit-time bound

\(O(\tau^2L^2+h\tau^2L+kL)\).

The \(kL\) term accounts for explicitly outputting \(k\) rational locations. The proof applies to the given weights directly, without expanding masses into equally weighted individuals.

1. A weighted median minimizes one block’s cost

For \(1\leq \ell\leq u\leq\tau\), define

\(H(\ell,u)=\min_{z\in\mathbb R}\sum_{i=\ell}^{u}\mu_i|a_i-z|\).

Write \(M=\sum_{i=\ell}^{u}\mu_i\), and let \(r\) be the smallest index satisfying

\(\displaystyle \sum_{i=\ell}^{r}\mu_i\geq \frac{M}{2}\).

Then \(a_r\) attains the minimum defining \(H(\ell,u)\).

To prove this, set \(F(z)=\sum_{i=\ell}^{u}\mu_i|a_i-z|\). If \(z\geq a_r\), every point with index at most \(r\) contributes exactly \(\mu_i(z-a_r)\) to \(F(z)-F(a_r)\). For every other point, the triangle inequality gives a contribution at least \(-\mu_i(z-a_r)\). Consequently,

\(\displaystyle F(z)-F(a_r)\geq \left(2\sum_{i=\ell}^{r}\mu_i-M\right)(z-a_r)\geq0.\)

If \(z\leq a_r\), the analogous argument gives

\(\displaystyle F(z)-F(a_r)\geq \left(2\sum_{i=r}^{u}\mu_i-M\right)(a_r-z)\geq0.\)

The last inequality holds because the minimality of \(r\) implies \(\sum_{i=\ell}^{r-1}\mu_i<M/2\), so \(\sum_{i=r}^{u}\mu_i>M/2\).

Thus

\(\displaystyle H(\ell,u)=\sum_{i=\ell}^{u}\mu_i|a_i-a_r|.\)

In particular, an optimal facility for each block can be chosen from the input support.

2. Unrestricted placements reduce to consecutive blocks

Take any \(k\)-tuple of real facility locations. Remove duplicates and sort the remaining locations as \(c_1<\cdots<c_q\), where \(q\leq k\). Assign each support point to a nearest facility, breaking ties consistently.

The assigned facility indices are nondecreasing along the support. Indeed, suppose \(a_i<a_j\), but \(a_i\) is assigned to \(c_p\) and \(a_j\) to \(c_s\), with \(p>s\). Their nearest-facility inequalities imply

\(\displaystyle |a_i-c_p|\leq|a_i-c_s|\quad\Longrightarrow\quad a_i\geq\frac{c_s+c_p}{2},\)

and

\(\displaystyle |a_j-c_s|\leq|a_j-c_p|\quad\Longrightarrow\quad a_j\leq\frac{c_s+c_p}{2}.\)

These conclusions contradict \(a_i<a_j\).

After discarding facilities assigned no support points, the assignment therefore partitions the support into at most \(h\) nonempty consecutive blocks.

Let \(P\) be the minimum, over all such partitions, of the sum of their block costs \(H\). There are finitely many partitions, so this minimum exists.

For every real placement \(y\), its nearest-facility partition satisfies

\(\displaystyle P\leq \sum_{\text{assigned blocks }[\ell,u]}H(\ell,u)\leq C_\mu(y).\)

Conversely, choose a partition attaining \(P\), place one facility at a weighted median of each block, and repeat any chosen location until there are exactly \(k\) facilities. Each point can use its block’s facility, hence this placement satisfies \(C_\mu(y)\leq P\). Applying the preceding inequality to this same placement gives equality.

Therefore the unrestricted optimum equals \(P\), and some optimum uses only input support locations. This also establishes existence of a minimizer.

3. Dynamic programming and reconstruction

Let \(D(t,j)\) be the minimum sum of block costs for a partition of \(a_1,\ldots,a_j\) into exactly \(t\) nonempty consecutive blocks. Set

\(D(0,0)=0,\qquad D(0,j)=+\infty\text{ for }j>0,\qquad D(t,j)=+\infty\text{ for }j<t.\)

For \(1\leq t\leq h\) and \(t\leq j\leq\tau\), use the recurrence

\(\displaystyle D(t,j)=\min_{t-1\leq s<j}\bigl(D(t-1,s)+H(s+1,j)\bigr).\)

Every partition counted by \(D(t,j)\) has a unique final block \([s+1,j]\); its preceding blocks partition the first \(s\) points. Conversely, any feasible preceding partition followed by this final block is feasible. These two observations prove the recurrence.

By Section 2, the exact optimal cost is

\(\displaystyle \operatorname{OPT}=\min_{1\leq t\leq h}D(t,\tau).\)

Store a minimizing predecessor \(s\) at every finite table entry. Choose a minimizing terminal value, trace its predecessors to recover the blocks, and output their weighted medians. Pad the resulting list with repetitions to obtain exactly \(k\) locations.

If \(k\geq\tau\), the simpler solution places a facility at every \(a_i\), pads with repetitions, and has exact cost \(0\).

4. Exact arithmetic and running time

Use the usual binary encoding of each rational by its integer numerator and positive integer denominator. Write

\(a_i=p_i/q_i,\qquad \mu_i=b_i/d_i,\qquad q_i,d_i>0.\)

Define common denominators and scaled integers by

\(\displaystyle Q=\prod_{i=1}^{\tau}q_i,\qquad B=\prod_{i=1}^{\tau}d_i,\qquad A_i=Qa_i,\qquad w_i=B\mu_i.\)

Then the \(A_i\) are strictly increasing integers, the \(w_i\) are positive integers, and \(\sum_iw_i=B\). Every scaled cost satisfies

\(\displaystyle \sum_i\mu_i|a_i-a_r|=\frac{1}{BQ}\sum_iw_i|A_i-A_r|.\)

Thus all comparisons and optimization can use integers.

Define prefix sums

\(\displaystyle W_j=\sum_{i=1}^{j}w_i,\qquad T_j=\sum_{i=1}^{j}w_iA_i,\qquad W_0=T_0=0.\)

For a block \([\ell,u]\), its median index is the smallest \(r\) satisfying

\(2(W_r-W_{\ell-1})\geq W_u-W_{\ell-1}.\)

Its integer cost is

\(\displaystyle G(\ell,u)=A_r(W_r-W_{\ell-1})-(T_r-T_{\ell-1})+(T_u-T_r)-A_r(W_u-W_r).\)

The first two terms sum \(w_i(A_r-A_i)\) over indices at most \(r\); the last two sum \(w_i(A_i-A_r)\) over indices greater than \(r\). Therefore \(H(\ell,u)=G(\ell,u)/(BQ)\).

For each fixed \(\ell\), the threshold \((W_u+W_{\ell-1})/2\) increases as \(u\) increases. Hence the median index never decreases. A forward scan finds all median indices for this \(\ell\) in \(O(\tau)\) operations. The prefix-sum formula then evaluates each block cost in constant arithmetic time. All block costs and median indices take \(O(\tau^2)\) arithmetic operations.

Run the dynamic program on the integers \(G\). It has \(O(h\tau)\) entries and at most \(\tau\) candidates per entry, giving \(O(h\tau^2)\) integer additions and comparisons. If its optimal integer value is \(V\), return the exact rational cost \(V/(BQ)\); reduction of this fraction is unnecessary.

To verify the bit bound:

  • The total input length bounds the sums of the denominator bit lengths, so \(Q\) and \(B\) have \(O(L)\) bits.
  • Each \(A_i\) has \(O(L)\) bits. Also, \(w_i\leq B\) and \(|T_j|\leq B\max_i|A_i|\), so prefix sums have \(O(L)\) bits.
  • Every block cost and feasible partition cost is at most \(B(A_\tau-A_1)\). Dynamic-programming values and candidates therefore have \(O(L)\) bits.
  • Scaling and computing all block costs take \(O(\tau^2L^2)\) bit operations with elementary integer arithmetic. Dynamic-programming additions and comparisons take \(O(h\tau^2L)\). Explicit output takes \(O(kL)\).

This proves the claimed polynomial running time. Working storage, excluding the output list, is \(O((\tau^2+h\tau)L)\) bits.

5. Complexity classification and the cited result

The supplied paper defines its line problem with arbitrary nonnegative weights and support-restricted facilities. Setting its startup costs to zero gives the present support-restricted problem; it also provides dynamic programming and placement reconstruction. Section 2 above proves the required equivalence with unrestricted placement. See [Fleischer, Golin, and Zhang, *Online Maintenance of k-Medians and k-Covers on a Line*](https://cse.hkust.edu.hk/faculty/golin/pubs/Algorithmica_KMedian_On_Line.pdf).

If \(k\) is binary-encoded, it can be exponentially large in \(L\). Explicitly listing \(k\) locations then necessarily takes at least \(\Omega(k)\) output time. The optimal cost and a representation consisting of at most \(\tau\) locations plus a repetition count are computable in polynomial time in \(L\). The requested explicit output is computable in polynomial time in \(\tau,k,L\).

Thus the target problem is tractable; its Wasserstein interpretation is not needed for the complexity classification.
