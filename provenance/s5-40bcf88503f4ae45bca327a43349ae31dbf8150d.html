Theorem 4.1 — class: hardness

The continuous mirror question, as graded

Given candidates \(C\), a committee \(W\subseteq C\) of size \(k\), and types \(t\) with rational masses \(\mu_t\) summing to \(1\) and listed Lottery supports \(\mathcal B_t\), does there exist a mass assignment \(x_{t,A}\geq 0\) with \(\sum_{A\in\mathcal B_t}x_{t,A}=\mu_t\) such that, for every \(c\in C\setminus W\), \(\sum_{t,A:\,c\in A,\,A\cap W=\emptyset}x_{t,A}<1/k\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(|C|=m\), and let \(W\subseteq C\) be a given committee with \(|W|=k\), where \(1\leq k\leq m\).
A society is given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has an explicitly listed, nonempty family \(\mathcal B_t\subseteq 2^C\) of possible approval sets; an approval set may be empty. These are the positive-probability options of a Lottery support; their probabilities impose no constraints on the assignment.
A feasible assignment consists of real masses \(x_{t,A}\geq0\) satisfying \(\sum_{A\in\mathcal B_t}x_{t,A}=\mu_t\) for every type and \(\sum_{t}\sum_{\substack{A\in\mathcal B_t:\ c\in A,\ A\cap W=\emptyset}}x_{t,A}<1/k\) for every \(c\in C\setminus W\).
Let \(s=\sum_t|\mathcal B_t|\) and let \(L\) be the total binary input length. State running times in \(m,\tau,s,k,L\).
Is deciding whether a feasible assignment exists solvable in polynomial time, or is it NP-hard?
For discrete voters with independent lotteries, deciding whether a fixed committee satisfies justified representation with positive probability is NP-complete, even with at most three supported approval sets per voter and \(k=n/2\), where \(n\) is the number of voters.
That discrete result does not classify the mass-assignment problem above.

Modeling choices made when packaging the task

  • Specified the committee-size domain as an integer between one and the number of candidates.
  • Required each listed Lottery support to be nonempty, while allowing empty approval sets, as permitted by the discrete definitions.
  • Specified assignment variables as real masses, with no indivisibility requirement.
  • Clarified that Lottery probabilities need not be supplied or preserved: only positive-probability supports matter for the stated existential question.
  • Defined the total support-list size and total binary input length for running-time statements.

Conclusion

The mass-assignment problem is solvable in polynomial time by exact rational linear programming. The strict inequalities can be handled by comparing a rational optimum exactly with \(1/k\).

1. A linear-programming formulation

For each listed option \(A\in\mathcal B_t\) and candidate \(c\in C\setminus W\), define
\(a_{c,t,A}=1\) if \(c\in A\) and \(A\cap W=\emptyset\), and define \(a_{c,t,A}=0\) otherwise.

The load of candidate \(c\) under an assignment \(x\) is
\(\ell_c(x)=\sum_t\sum_{A\in\mathcal B_t}a_{c,t,A}x_{t,A}\).
Thus the required inequalities are precisely \(\ell_c(x)<1/k\).

Consider the following linear program in the \(s\) assignment variables and one additional variable \(z\):

  • Minimize \(z\).
  • Require \(\sum_{A\in\mathcal B_t}x_{t,A}=\mu_t\) for every type \(t\).
  • Require \(x_{t,A}\geq0\) for every listed option.
  • Require \(\ell_c(x)\leq z\) for every \(c\in C\setminus W\).
  • Require \(0\leq z\leq1\).

Let its optimal value be \(z^\star\).

This program is feasible: choose one option from each nonempty family, assign that option the entire mass \(\mu_t\), and set \(z=1\). Indeed, every candidate load is at most the total assigned mass, which is \(1\).

Its feasible region is compact. It is closed because all constraints are nonstrict linear constraints; it is bounded because \(0\leq x_{t,A}\leq\mu_t\leq1\) and \(0\leq z\leq1\). Consequently, the optimum is attained.

If \(k=m\), the original candidate inequalities are vacuous and an assignment always exists. The program also handles this case: it has no load constraints and \(z^\star=0\).

2. Equivalence, including strictness

Claim. A feasible assignment for the original problem exists if and only if \(z^\star<1/k\).

Proof. Suppose first that an original feasible assignment \(x\) exists. When \(C\setminus W\) is nonempty, set \(z=\max_{c\in C\setminus W}\ell_c(x)\). This is the maximum of finitely many numbers strictly below \(1/k\), so \(z<1/k\). Also \(0\leq z\leq1\), and \((x,z)\) satisfies the linear program. Hence \(z^\star\leq z<1/k\). When there are no outside candidates, take \(z=0\).

Conversely, suppose \(z^\star<1/k\). Let \((x^\star,z^\star)\) be an optimal solution, whose existence was established above. For every outside candidate,
\(\ell_c(x^\star)\leq z^\star<1/k\).
The remaining constraints give exactly the required nonnegativity and type-mass equalities. Thus \(x^\star\) is an original feasible assignment. \(\square\)

In particular, an optimum equal to \(1/k\) must be rejected.

3. Exact computation and running time

We use the standard rational linear-programming theorem: a linear program with binary rational data can be solved exactly in bit time polynomial in its numbers of variables and constraints and its total encoding length. For a feasible program with an attained finite optimum, this yields an exact rational optimal solution. This is the polynomial-time solvability theorem originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here: the program is feasible and compact, every matrix and objective coefficient belongs to \(\{-1,0,1\}\), and the only nonintegral right-hand sides are the supplied rational masses.

There are \(N=s+1\) variables. After replacing each equality by two inequalities, there are
\(R=2\tau+(m-k)+s+2\)
inequalities. A dense binary encoding of the program has length
\(B=O\!\left(L+(s+1)(s+\tau+m)\right)\):
matrix entries need constant space, and duplicating the mass right-hand sides increases their total encoding length by only a constant factor.

If the exact optimum is represented as \(z^\star=p/q\), with \(q>0\), accept precisely when \(kp<q\). This integer comparison is exact; the linear-programming theorem ensures that the returned rational numbers have polynomial encoding length.

Therefore the overall bit running time is bounded by
\(\operatorname{poly}\!\left(L+(s+1)(s+\tau+m)+\log(k+1)\right)\).
This states the dependence on all requested parameters; dependence on the numerical threshold parameter uses only \(\log(k+1)\).

For completeness, candidates whose load coefficient row is identically zero can be omitted, since their inequality is automatically satisfied. If the candidate universe is encoded implicitly, only outside candidates occurring in explicitly listed relevant approval sets need rows. Their number is bounded by the explicit input length, so the algorithm is polynomial in \(L\) under that encoding as well.

4. Why discrete hardness does not transfer

Continuous divisibility changes feasibility. Consider \(W=\{w_1,w_2\}\), \(k=2\), and three outside candidates \(a,b,c\). Let there be four types, each of mass \(1/4\), each with options \(\{\{a\},\{b\},\{c\}\}\).

The continuous assignment \(x_{t,\{a\}}=x_{t,\{b\}}=x_{t,\{c\}}=1/12\) gives every outside candidate load \(4/12=1/3<1/2\), so it is feasible.

If these types instead represent four indivisible voters, every realization assigns each voter to one of the three singleton options. By the pigeonhole principle, some candidate receives at least two voters, giving load at least \(2/4=1/2\); every realization fails the strict condition. This example has three options per voter and \(k=n/2\).

Thus even feasibility can differ between the continuous and discrete models. The continuous problem is settled by the linear program above.
