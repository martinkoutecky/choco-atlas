The continuous mirror question, as graded

Given a population scale \(N\), rational type proportions \((\mu_t)_{t\in T}\) summing to \(1\), normalized Robertson–Webb valuation oracles \(v_t\), and \(K=|T|\leq \epsilon N-1\), compute a mass assignment of connected intervals on \([0,1]\). Each type \(t\) must receive total mass \(N\mu_t\); at almost every point \(z\), the total mass assigned intervals containing \(z\) must equal \(1\). For every type \(t\), every interval \(I\) assigned positive mass to \(t\), and every interval \(J\) assigned positive mass to any type, require \(v_t(I)\geq v_t(J)-\epsilon\). Empty intervals may receive mass.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types with positive binary-rational proportions \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Given a positive binary-rational population scale \(N\) and binary-rational \(\epsilon\in(0,1)\), assume \(\tau\leq\epsilon N-1\). Let \(L\) be the total bit length of these rational inputs.
Each type has a nonnegative, additive, nonatomic valuation \(v_t\), normalized by \(v_t([0,1])=1\), accessed through Robertson–Webb evaluation and cut queries. Cuts return the leftmost qualifying point, or \(1\) if none exists. Use the standard unit-cost oracle arithmetic model; endpoints may be exact oracle-returned reals.
A mass assignment is a finite list \((t_a,I_a,w_a)_{a=1}^{m}\), where \(w_a\) is a positive rational and \(I_a\subseteq[0,1]\) is a connected interval or the empty set, with \(v_t(\varnothing)=0\). Require \(\sum_{a:t_a=t}w_a=N\mu_t\) for every type and \(\sum_{a:z\in I_a}w_a=1\) for Lebesgue-almost every \(z\in[0,1]\). Endpoints do not affect coverage.
The assignment is \(\epsilon\)-additively envy-free if \(v_{t_a}(I_a)\geq v_{t_a}(I_b)-\epsilon\) for every pair of records \(a,b\), including records assigning empty intervals.

Is computing such an \(\epsilon\)-additively envy-free mass assignment possible with output size \(m\), rational output bit length, oracle queries, and computation bounded by \(\operatorname{poly}(\tau,L,N,1/\epsilon)\), or is attaining this approximation NP-hard even with polynomial-time implementable valuation oracles?

For a finite society of \(n\) agents with at most \(\epsilon n-1\) distinct valuations, a connected \(\epsilon\)-additively envy-free complete allocation, allowing empty pieces, is computable in time polynomial in \(n\) and \(1/\epsilon\). Result

The problem is polynomial-time solvable in the stated oracle model. In fact, the construction has complexity polynomial in \(\tau,L,1/\epsilon\), with no additional dependence on the numerical value of \(N\).

The key is to partition the cake into intervals that every supported type values at most \(\epsilon\). Such a partition is also used in [Barman–Kulkarni, Algorithm 2 and Theorem 16](https://drops.dagstuhl.de/opus/volltexte/2023/18068/pdf/LIPIcs-ICALP-2023-16.pdf). We prove the required partition properties below and then give an explicit rational mass assignment.

1. A partition into universally small intervals

Set \(T=\lceil 1/\epsilon\rceil\). For each supported type \(t\), define \(x_{t,0}=0\), \(x_{t,T}=1\), and obtain the intermediate points through the queries
\[ x_{t,k}=\operatorname{Cut}_t(0,k\epsilon), \qquad 1\leq k\leq T-1. \]

To justify these queries, let \(F_t(x)=v_t([0,x])\). Nonatomicity makes \(F_t\) continuous, and normalization gives \(F_t(0)=0\) and \(F_t(1)=1\). Because \(0<k\epsilon<1\), the qualifying set is nonempty, and its leftmost point satisfies \(F_t(x_{t,k})=k\epsilon\). Indeed, a strictly larger value at that point would, by continuity, give an earlier qualifying point.

Consequently, the points for each type are strictly increasing. Additivity and nonatomicity give
\[ v_t([x_{t,k-1},x_{t,k}])=\epsilon \quad\text{for }1\leq k\leq T-1, \]
while the final interval has value \(1-(T-1)\epsilon\leq\epsilon\).

Sort and deduplicate the union of these points over the \(\tau\) supported types, writing the result as
\[ 0=z_0<z_1<\cdots<z_K=1. \]
Let \(J_j=[z_{j-1},z_j]\) for \(1\leq j\leq K\).

Every \(J_j\) lies within one interval of each type’s partition: otherwise, an intermediate cut point of that type would lie strictly between two consecutive union points. Nonnegativity and additivity imply monotonicity under inclusion. Thus
\[ v_t(J_j)\leq\epsilon \qquad\text{for every }t,j. \]

There are at most \(\tau(T-1)\) interior cut points, so
\[ K\leq 1+\tau(T-1)\leq 1+\frac{\tau}{\epsilon}. \]
Using the promised inequality \(\tau\leq\epsilon N-1\), we obtain
\[ K\leq N+1-\frac1\epsilon<N. \]
In particular, the population mass suffices to give every \(J_j\) total weight \(1\).

2. Assigning arbitrary rational type masses

Write \(s_t=N\mu_t\), and define cumulative masses
\[ S_0=0,\qquad S_t=\sum_{u=1}^{t}s_u. \]
All these numbers are rational, and \(S_\tau=N\).

Use an auxiliary mass coordinate on \([0,N]\). Type \(t\) occupies the interval \(A_t=[S_{t-1},S_t]\). Partition this coordinate into the bins
\[ B_j=[j-1,j]\quad(1\leq j\leq K), \qquad B_{\varnothing}=[K,N]. \]
The last bin has positive length because \(K<N\).

For every intersection of positive length \(A_t\cap B_j\), output the record
\[ (t,J_j,w_{t,j}), \qquad w_{t,j}=\min(S_t,j)-\max(S_{t-1},j-1). \]
For every intersection of positive length \(A_t\cap B_{\varnothing}\), output
\[ (t,\varnothing,w_{t,\varnothing}), \qquad w_{t,\varnothing}=S_t-\max(S_{t-1},K). \]
Intersections of zero length produce no record. All emitted weights are positive rationals.

Here the auxiliary coordinate splits population mass: each record associated with \(B_j\) receives the entire cake interval \(J_j\).

Type totals

The bins partition \([0,N]\) up to endpoints. Therefore, their intersections with \(A_t\) have total length \(s_t\), giving
\[ \sum_{a:t_a=t}w_a=s_t=N\mu_t. \]

Cake coverage

The type intervals partition the auxiliary coordinate. Hence, for each cake interval,
\[ \sum_t w_{t,j}=|B_j|=1. \]
At every cake point outside the finite set of partition endpoints, exactly one \(J_j\) contains that point. Empty intervals contribute nothing. Thus
\[ \sum_{a:z\in I_a}w_a=1 \]
for Lebesgue-almost every \(z\in[0,1]\).

Record count

The common refinement of the type intervals and the bins has interior boundaries among the \(\tau-1\) numbers \(S_1,\ldots,S_{\tau-1}\) and the \(K\) integers \(1,\ldots,K\). It therefore has at most \(\tau+K\) positive-length cells. Each emitted record corresponds to exactly one such cell, so
\[ m\leq\tau+K\leq 1+\tau\lceil1/\epsilon\rceil. \]

3. Envy-freeness, including empty records

Every output interval is either empty or one of the \(J_j\). Therefore, for every supported type \(t\) and every record \(b\),
\[ v_t(I_b)\leq\epsilon. \]
For any pair of records \(a,b\), nonnegativity now gives
\[ v_{t_a}(I_a)\geq0 \geq v_{t_a}(I_b)-\epsilon. \]
This proves the required \(\epsilon\)-additive envy-freeness, including when \(I_a=\varnothing\).

4. Oracle and encoding complexity

The construction makes exactly \(\tau(T-1)\) cut queries and requires no evaluation queries. Sorting the returned endpoints uses polynomially many exact comparisons in the stated unit-cost oracle arithmetic model. Endpoint representations are allowed by the question.

The auxiliary-coordinate partitions can be merged in linear time after their boundaries are computed, generating at most \(\tau+K\) records.

For an explicit weight-encoding bound, write \(N=p_0/q_0\) and \(\mu_t=p_t/q_t\), and set
\[ D=q_0\prod_{t=1}^{\tau}q_t. \]
The binary length of \(D\) is \(O(L)\). Every \(s_t\), every \(S_t\), and every integer bin boundary is an integer multiple of \(1/D\); consequently, so is every emitted weight. Each weight lies in \((0,N]\), so its numerator over denominator \(D\) is at most \(DN\), also of binary length \(O(L)\). Reduction to lowest terms cannot increase this bound.

Thus each weight has \(O(L)\) bits, and the total rational output bit length is \(O(mL)\). All rational calculations can be performed in polynomial bit complexity.

This establishes every requested bound and settles the positive algorithmic alternative.
