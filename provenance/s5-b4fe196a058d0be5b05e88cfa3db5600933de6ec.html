The continuous mirror question, as graded

Given a finite alternative set \(C\) and a rational distribution \(\mu\) over at most \(\tau\) complete rankings of \(C\), compute the final set of ordered pairs certified by Iterated 3MOT, using \(\mu\)-weighted ranking frequencies in its inequalities. Does the resulting set certify that each reported pair appears in that order in every minimizer of \(D_\mu(\rho)=\sum_{\sigma}\mu_\sigma d^3_{\mathrm{KT}}(\rho,\sigma)\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq1\) alternatives. A society is given by its support: the list of \(\tau\) distinct complete strict rankings with positive binary rational masses \(\mu_\sigma\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
For distinct alternatives, let \(n_{a_1\cdots a_j}=\sum_{\sigma:a_1\succ_\sigma\cdots\succ_\sigma a_j}\mu_\sigma\) and \(\delta_{xy}=n_{xy}-n_{yx}\).
Define \(P_{x,y,z}=3n_{xzy}+n_{xyz}+n_{zxy}+n_{zyx}-4n_{yzx}-2n_{yxz}\) and \(Q_{x,y,z}=n_{xyz}+n_{xzy}-n_{yxz}-n_{yzx}\).
Define \(R_{y,x,z,t}=2n_{yztx}+2n_{yzxt}+n_{ytzx}+n_{ytxz}\) and \(S_{y,x,z,t}=R_{y,x,z,t}-R_{x,y,z,t}\).
For a relation \(U\), write \(\overline U\) for its transitive closure, \(L_y(U)=\{z:(z,y)\in U\}\), and \(R_x(U)=\{z:(x,z)\in U\}\).
Iterated 3MOT starts with \(U_{-1}=\varnothing\). For each \(k\geq0\) and distinct \(x,y\), set \(Y_k(x,y)=C\setminus(L_y(\overline U_{k-1})\cup\{x,y\})\) and \(X_k(x,y)=Y_k(x,y)\setminus R_x(\overline U_{k-1})\).
Let \(U_k\) consist exactly of the pairs \((x,y)\) satisfying \(Q_{x,y,z}\geq0\) for every \(z\in Y_k(x,y)\) and \(2\delta_{xy}>\sum_{z\in X_k(x,y)}\max\{0,-P_{x,y,z}+\sum_{t\in Y_k(x,y)\setminus\{z\}}\max\{0,S_{y,x,z,t}\}\}\). All tests within a round use the preceding round; empty sums are zero. The final reported relation is \(F=\bigcup_{k\geq0}\overline U_k\).
Let \(d^3_{\mathrm{KT}}(\rho,\sigma)=\sum_{A\subseteq C,\,1\leq|A|\leq3}\mathbf1[\operatorname{top}_A(\rho)\neq\operatorname{top}_A(\sigma)]\), where \(\operatorname{top}_A\) is the highest-ranked element of \(A\), and let \(D_\mu(\rho)=\sum_\sigma\mu_\sigma d^3_{\mathrm{KT}}(\rho,\sigma)\). Minimizers range over all complete strict rankings, with no tie-breaking between minimizers.

Is computing \(F\) polynomial-time solvable in \(m,\tau,L\), or is it NP-hard? Does every \((x,y)\in F\) satisfy \(x\succ_\rho y\) in every minimizer \(\rho\) of \(D_\mu\)?

Result

Computing \(F\) is polynomial-time solvable in \(m,\tau,L\). Every \((x,y)\in F\) satisfies \(x\succ_\rho y\) in every minimizer \(\rho\) of \(D_\mu\).

An explicit upper bound using elementary integer arithmetic is

\(O\!\left(L+\tau L^2+(\tau m^4+m^6)\bigl(L+\log(m+1)\bigr)\right)\)

bit operations. This bound does not depend on the number of voters obtained by expanding the rational masses.

For \(m=1\), the reported relation is empty. The argument below covers all \(m\geq1\).

1. Exact scaling to integer weights

Write each input mass as \(\mu_\sigma=a_\sigma/b_\sigma\), with positive integers \(a_\sigma,b_\sigma\). Define

\(H=\prod_{\sigma\in\operatorname{supp}(\mu)}b_\sigma,\qquad w_\sigma=a_\sigma(H/b_\sigma).\)

Every \(w_\sigma\) is a positive integer, and normalization gives

\(\sum_\sigma w_\sigma=H\sum_\sigma\mu_\sigma=H.\)

For each ordered tuple of distinct alternatives, define its integer count by

\(N_{a_1\cdots a_j}=\sum_{\sigma:a_1\succ_\sigma\cdots\succ_\sigma a_j}w_\sigma=Hn_{a_1\cdots a_j}.\)

Let \(\widehat\delta,\widehat P,\widehat Q,\widehat R,\widehat S\) be the quantities in the question computed from \(N\) instead of \(n\). Their definitions are linear, so each hatted quantity is \(H\) times its corresponding original quantity.

For every real \(u\), positivity of \(H\) gives

\(\max\{0,Hu\}=H\max\{0,u\}.\)

Consequently, for any fixed preceding relation, the entire right-hand side of the strict test is multiplied by \(H\), as is its left-hand side. Every \(Q\)-test is also preserved. Thus all tests have exactly the same outcomes after scaling, including strict inequalities and equalities.

Starting from the same empty relation, induction on the round number therefore proves that the integer-weight computation produces exactly the original sequence \(U_k\), its closures, and \(F\).

2. Monotonicity and a finite stopping rule

Let \(T(A)\) denote the relation obtained by applying one round with preceding relation \(A\). We prove that

\(A\subseteq B\quad\Longrightarrow\quad T(A)\subseteq T(B).\)

Transitive closure preserves inclusion: every directed path using edges of \(A\) also uses edges of \(B\). Hence

\(\overline A\subseteq\overline B,\qquad L_y(\overline A)\subseteq L_y(\overline B),\qquad R_x(\overline A)\subseteq R_x(\overline B).\)

For each fixed pair \((x,y)\), write \(Y_A,X_A\) and \(Y_B,X_B\) for its test sets. These inclusions imply

\(Y_B\subseteq Y_A,\qquad X_B\subseteq X_A.\)

The \(Q\)-condition becomes weaker because it is checked on a smaller set.

For the strict condition, every inner summand \(\max\{0,S_{y,x,z,t}\}\) is nonnegative. Shrinking \(Y\) can therefore only decrease the inner sum. Since the function \(u\mapsto\max\{0,u\}\) is nondecreasing, each retained outer summand can only decrease. Shrinking \(X\) additionally removes nonnegative outer summands. The complete right-hand side consequently cannot increase. A pair passing the strict test for \(A\) therefore passes it for \(B\), proving the claimed monotonicity.

Now \(U_{-1}=\varnothing\subseteq U_0\). Inductively,

\(U_{k-1}\subseteq U_k\quad\Longrightarrow\quad U_k=T(U_{k-1})\subseteq T(U_k)=U_{k+1}.\)

There are only \(M=m(m-1)\) possible ordered pairs of distinct alternatives. Every strict increase adds at least one pair, so there are at most \(M\) strict increases. Thus an equality \(U_k=U_{k-1}\) is detected within \(M+1\) round evaluations.

Once equality occurs, the deterministic recurrence remains constant forever. Because the closures are also increasing, the final output is precisely

\(F=\overline U_k\)

at that stopping round.

3. Polynomial bit complexity

The binary length of \(H\) is \(O(L)\): its logarithm is the sum of the logarithms of the input denominators. Moreover,

\(0<w_\sigma\leq H,\qquad 0\leq N_{a_1\cdots a_j}\leq H.\)

Computing \(H\) and all \(w_\sigma\) requires \(O(\tau L^2)\) bit operations using elementary multiplication and division.

For each support ranking, store the position of every alternative. Whether a specified tuple occurs in the required relative order can then be determined using a constant number of position comparisons.

There are \(O(m^4)\) ordered tuples of distinct alternatives of lengths two through four. Computing all their integer counts directly from the support therefore takes \(O(\tau m^4)\) additions and tuple checks. The hatted quantities are then computed using \(O(m^4)\) further arithmetic operations.

Each hatted quantity is a fixed linear combination of counts bounded by \(H\), and hence has magnitude \(O(H)\). An inner sum has magnitude \(O(mH)\), and the complete outer sum has magnitude \(O(m^2H)\). All arithmetic operands therefore have

\(O\!\left(L+\log(m+1)\right)\)

bits. Addition, subtraction, comparison, and multiplication by the fixed coefficients have linear cost in this bit length.

In each round:

  • Transitive closure takes \(O(m^3)\) Boolean operations.
  • Constructing all test sets takes \(O(m^3)\) elementary operations.
  • Checking all \(O(m^2)\) pairs takes \(O(m^4)\) arithmetic and comparison operations, because each pair has at most \(O(m^2)\) inner summands.

There are \(O(m^2)\) rounds. Including input processing and the final closure yields the stated bound

\(O\!\left(L+\tau L^2+(\tau m^4+m^6)\bigl(L+\log(m+1)\bigr)\right).\)

The algorithm processes only the \(\tau\) support rankings and their integer weights; it never constructs an expanded voter list.

4. Soundness for every minimizer

We use the following established finite-profile result: for any finite multiset of complete strict rankings, the recurrence in the question, computed using unnormalized vote counts, reports only pairs that hold in every minimizer of total \(3\)-wise Kendall–tau distance. This is [Phung and Hamel, Theorem 25](https://arxiv.org/html/2305.00140v2#S6); its quantities and recurrence agree with those specified here.

Consider, solely for this proof, the finite unweighted profile \(V\) containing \(w_\sigma\) copies of each support ranking \(\sigma\). This profile meets the theorem’s hypotheses: all rankings are complete and strict, all multiplicities are positive integers, and their sum is the finite integer \(H\). Repeated rankings are permitted.

Its tuple counts are exactly \(N_{a_1\cdots a_j}\). Section 1 therefore shows that its Iterated 3MOT relation is exactly the rational-support relation \(F\).

For every complete strict ranking \(\rho\), its unweighted objective satisfies

\(\sum_{v\in V}d^3_{\mathrm{KT}}(\rho,v)=\sum_\sigma w_\sigma d^3_{\mathrm{KT}}(\rho,\sigma)=H D_\mu(\rho).\)

Multiplication by a positive constant preserves every comparison and every tie between objective values. Thus the set of minimizers for \(V\) is exactly the set of minimizers of \(D_\mu\).

Applying the finite-profile theorem now proves that each \((x,y)\in F\) satisfies \(x\succ_\rho y\) in every minimizer of \(D_\mu\). No choice or tie-breaking among minimizers is involved.
