The continuous mirror question, as graded

Given a finite candidate set \(C\), approval types \(\mathcal T\subseteq\binom{C}{6}\), and positive rational masses \(\mu_S\) summing to \(1\), is there a split \(x_S\in[0,\mu_S]\) and distinct candidates \(p,q\in C\) such that \(p\) uniquely wins the first group and \(q\) uniquely wins the second? Equivalently, can one maximize \(\delta\) subject to \(\sum_{S\ni p}x_S\ge\sum_{S\ni c}x_S+\delta\) for every \(c\ne p\), and \(\sum_{S\ni q}(\mu_S-x_S)\ge\sum_{S\ni c}(\mu_S-x_S)+\delta\) for every \(c\ne q\), with optimum \(\delta>0\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m\ge 6\). A society is given by its support: a nonempty list \(\mathcal T\subseteq\binom{C}{6}\) of \(\tau\) distinct approval types, each with positive binary rational mass \(\mu_S\), with \(\sum_{S\in\mathcal T}\mu_S=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
A split chooses real masses \(x_S\in[0,\mu_S]\), assigning \(x_S\) to the first group and \(\mu_S-x_S\) to the second. Each group must have positive total mass; no prescribed group sizes apply.
For group masses \(y_S\), candidate \(c\) has approval score \(\sum_{S\in\mathcal T:c\in S}y_S\). A unique winner must strictly outscore every other candidate; ties do not qualify.
The decision problem asks whether a split exists with distinct candidates \(p,q\in C\) uniquely winning the first and second groups, respectively; both leaders are chosen as part of the solution.

Is this continuous two-group approval partition problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For indivisible voters, partitioning into two groups with distinct unique approval winners is NP-hard even when every voter approves exactly six candidates ([source](https://www.ijcai.org/Proceedings/16/Papers/042.pdf)). No result settling this exact continuous problem was located in the literature search.

Modeling choices made when packaging the task

  • Made the input domain explicit: at least six candidates and a nonempty support, as required by positive total mass on six-candidate approval types.
  • Explicitly required positive mass in both groups, consistent with groups having unique winners; this is already implied by strict winning inequalities.
  • Specified that split masses are real, group sizes are unrestricted, and ties do not qualify.

Polynomial-time solvability

The problem is solvable in polynomial time in \(m,\tau,L\). Enumerate the possible distinct leaders and, for each pair, solve a rational linear program that maximizes a common margin. A strictly positive optimum is equivalent to a valid split.

1. Linear program for fixed leaders

Fix an ordered pair \(p,q\in C\) with \(p\ne q\). For each candidate \(c\), define its total approval mass and its first-group score by

\(v_c=\sum_{S\in\mathcal T:c\in S}\mu_S,\qquad A_c(x)=\sum_{S\in\mathcal T:c\in S}x_S.\)

Its second-group score is consequently \(v_c-A_c(x)\).

Introduce a real variable \(\varepsilon\), and maximize \(\varepsilon\) subject to the following constraints:

  • \(0\le x_S\le\mu_S\) for every \(S\in\mathcal T\).
  • \(0\le\varepsilon\le1\).
  • \(\sum_{S\in\mathcal T}x_S\ge\varepsilon\) and \(1-\sum_{S\in\mathcal T}x_S\ge\varepsilon\).
  • \(A_p(x)-A_c(x)\ge\varepsilon\) for every \(c\in C\setminus\{p\}\).
  • \((v_q-A_q(x))-(v_c-A_c(x))\ge\varepsilon\) for every \(c\in C\setminus\{q\}\).

All constraints are linear. In particular, the last family can be written as

\(v_q-v_c-\sum_{S\in\mathcal T}\bigl(\mathbf 1_{\{q\in S\}}-\mathbf 1_{\{c\in S\}}\bigr)x_S\ge\varepsilon.\)

If the program is feasible, its feasible region is closed and bounded: every \(x_S\) lies in a bounded interval, as does \(\varepsilon\). Thus its maximum is attained.

2. Exact equivalence with a valid split

Claim. A split with first-group unique winner \(p\) and second-group unique winner \(q\) exists if and only if this linear program is feasible and has strictly positive optimum.

Proof. Suppose first that such a split \(x\) exists. Both group masses are positive. Moreover, each of the following score differences is positive:

\(A_p(x)-A_c(x)\quad(c\ne p),\)

\((v_q-A_q(x))-(v_c-A_c(x))\quad(c\ne q).\)

Take \(\varepsilon\) to be the minimum of \(1\), the two group masses, and all these score differences. This is the minimum of a finite, nonempty collection of positive real numbers, so \(\varepsilon>0\). Every linear-program constraint holds. Hence the optimum is positive.

Conversely, suppose a feasible solution has \(\varepsilon>0\). The group-mass constraints make both groups positive. Every first-group comparison gives \(A_p(x)>A_c(x)\) for \(c\ne p\), so \(p\) is its unique winner. Every second-group comparison similarly makes \(q\) its unique winner. The box constraints ensure that these groups form an admissible split. Since \(p\ne q\), the split meets every requirement. This proves the claim.

3. Polynomial bit complexity and algorithm

We use the standard polynomial-time theorem for rational linear programming: a linear program with binary-encoded rational data can be tested for feasibility and, when feasible with a finite optimum, optimized exactly in time polynomial in its encoding length.

Here each program has \(\tau+1\) variables and \(2\tau+2(m-1)+4\) inequalities. Its coefficients and right-hand sides have polynomial bit length. To verify the latter explicitly, write each input mass as \(\mu_S=a_S/b_S\), and let \(D=\prod_{S\in\mathcal T}b_S\). The binary length of \(D\) is at most the sum of the input denominator lengths, hence is \(O(L)\). Every \(v_c\) and every difference \(v_q-v_c\) has denominator dividing \(D\). Because \(0\le v_c\le1\), their numerators over denominator \(D\) also have \(O(L)\) bits. All remaining data are input masses or small integers.

Thus each program has encoding length polynomial in \(m,\tau,L\). Exact optimization decides whether its optimum is positive; no numerical tolerance or assumed lower bound on a winning margin is needed.

The algorithm is therefore:

  • Enumerate the \(m(m-1)\) ordered pairs \(p\ne q\).
  • Solve the corresponding linear program for each pair.
  • Accept if any program has positive optimum; otherwise reject.

The equivalence proved above establishes correctness, and the number and size of the programs establish polynomial running time. An accepting program also supplies a rational split of polynomial encoding length.

4. Scope

The proof does not use the restriction that each approval type has size six, so it also applies to arbitrary explicitly listed approval types. The [cited hardness result](https://www.ijcai.org/Proceedings/16/Papers/042.pdf) concerns indivisible voters; allowing each type’s mass to split continuously permits the linear-programming algorithm above.
