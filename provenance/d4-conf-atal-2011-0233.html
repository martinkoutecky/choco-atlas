The continuous mirror question, as graded

Given a finite support of acyclic CP-net types \(t\), each with a complete conditional preference model and rational mass \(\mu_t>0\) satisfying \(\sum_t \mu_t=1\), and outcomes \(\alpha,\beta\), compute exactly \(p_{\alpha\succ\beta}=\sum_{t:\,N_t\models\alpha\succ\beta}\mu_t\).

Packaged proof task (what the prover saw — nothing else)

All types share variables \(X_1,\ldots,X_m\), with explicitly listed finite nonempty domains \(D_i\); an outcome is an element of \(\prod_i D_i\). Each type \(t\) specifies an acyclic CP-net \(N_t\), with an explicitly listed strict total order on \(D_i\) for every assignment to the parents of \(X_i\); dependency graphs may differ across types.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types; \(\sum_t\mu_t=1\). Let \(L\) be the total binary input length and \(d=\max_i|D_i|\); state running times in \(m,\tau,d,L\).
Write \(N_t\models\alpha\succ\beta\) exactly when a nonempty sequence of improving flips leads from \(\beta\) to \(\alpha\): each flip changes one variable to any strictly preferred value in its current parent context, leaving all other variables fixed.
Given distinct outcomes \(\alpha,\beta\), the required output is the exact rational \(p_{\alpha\succ\beta}=\sum_{t:\,N_t\models\alpha\succ\beta}\mu_t\).

Is exact computation of \(p_{\alpha\succ\beta}\) possible in polynomial time in \(m,\tau,d,L\), or is it NP-hard?

DT* is complete for arbitrary acyclic CP-nets, without a polynomial worst-case guarantee ([Li, Vo and Kowalczyk](https://www.ifaamas.org/Proceedings/aamas2011/papers/D2_R49.pdf)); discrete dominance is NP-complete even for binary acyclic networks with at most one directed path between any two variables ([Boutilier et al.](https://arxiv.org/pdf/1107.0023)).
Dominance probability is \(\#\mathrm{P}\)-hard for acyclic probabilistic CP-nets whose local preference rules are sampled independently; that representation specifies the distribution implicitly rather than listing its support ([Bigot et al.](https://arxiv.org/pdf/1309.6817)). No result for exactly the explicit-support problem was verified.

Modeling choices made when packaging the task

  • Made the common variable set and finite domains explicit; allowed type-specific dependency graphs.
  • Interpreted complete conditional preference models as explicitly listed conditional preference tables with strict total orders and no ties.
  • Specified that an improving flip may choose any strictly better value, including a nonadjacent value in a multivalued domain.
  • Restricted the query to distinct outcomes, matching strict dominance and avoiding the algorithm's acceptance of an empty sequence when the outcomes coincide.
  • Defined m as the number of variables, d as the maximum domain size, and L as the total binary input length.

Result

Exact computation is \(\mathrm{NP}\)-hard, already when \(\tau=1\) and \(d=2\). Consequently, an algorithm polynomial in \(m,\tau,d,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

Dominance hardness and the input representation

We use the following established theorem: deciding whether an improving-flip sequence connects two specified outcomes is \(\mathrm{NP}\)-complete for binary acyclic CP-nets whose graphs have at most one directed path between any two variables. The hardness construction has maximum indegree at most six, fully specified strict preferences, and distinct source and target outcomes. See Theorem 15 and its proof in Appendix A of [Boutilier et al.](https://arxiv.org/pdf/1107.0023).

These restrictions satisfy the present task’s hypotheses. In particular, every variable has at most \(2^6\) parent assignments, so explicitly listing every CPT row preserves the polynomial size of the hardness construction. Since domains are binary, its improving flips also coincide exactly with the flips permitted here.

Reduction to exact probability computation

Take an instance \((N,\alpha,\beta)\) from that restricted dominance problem. Construct a society with the same variables, domains, and outcomes, and exactly one supported type:

\(N_1=N,\qquad \mu_1=1.\)

This is a valid explicit-support instance: its mass is positive, has a constant-length binary rational encoding, and sums to one. The construction merely copies the dominance instance and adds the mass, so it takes linear time in its encoding length.

By the definition of the required probability,

\(p_{\alpha\succ\beta}=\mathbf{1}\{N\models\alpha\succ\beta\}.\)

Thus the exact output is one precisely for yes-instances of dominance, and zero otherwise. One call to an exact probability algorithm, followed by comparison with one, therefore decides the restricted dominance problem.

If exact computation took time polynomial in \(m,\tau,d,L\), this reduction would yield a polynomial-time dominance algorithm: here \(\tau=1\), \(d=2\), and both \(m\) and the constructed length \(L\) are bounded polynomially by the original input length. This proves the claimed hardness.

Explicit support and running time

Explicit support makes the aggregation straightforward once dominance has been decided for each listed type. It does not make those dominance decisions polynomial-time solvable.

For completeness, a direct exact algorithm has running time

\(O\!\left(\tau m d^{m+1}\operatorname{poly}(L)\right).\)

To justify this bound, let \(K=\prod_{i=1}^{m}|D_i|\), so \(K\leq d^m\). For each type, form the outcome graph implicitly: its vertices are outcomes, and its edges are improving flips. Each vertex has at most \(m(d-1)\) candidate outgoing edges. Checking a candidate against the explicitly listed CPT takes polynomial time in \(L\).

A graph search starting at \(\beta\) consequently decides reachability of \(\alpha\) in \(O(Kmd\operatorname{poly}(L))\) time per type. Every generated edge is an allowed improving flip, and every allowed improving flip is generated, so reachability is exactly the task’s dominance relation. Because \(\alpha\neq\beta\), a successful path is necessarily nonempty.

The final rational summation also takes polynomial time in the input length. Write each mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\), and let \(S\) be the set of types for which dominance holds. Set

\(B=\prod_{t=1}^{\tau}b_t,\qquad A=\sum_{t\in S}a_t(B/b_t).\)

Then the required output is \(A/B\), reduced if desired. The binary length of \(B\) is at most the sum of the denominator encoding lengths plus a constant, hence \(O(L)\). Since the masses sum to one, \(0\leq A\leq B\), so \(A\) also has \(O(L)\) bits. Products, exact divisions, additions, and reduction by a greatest common divisor therefore require only polynomial time.

The hardness proof uses discrete dominance directly; no transfer from an implicitly represented probabilistic CP-net is needed.
