The continuous mirror question, as graded

Given a candidate set \(C\), a finite support \(R\) of ranking types of length at least two, rational masses \(\mu_r>0\) summing to \(1\), and a rational threshold \(\alpha\in(0,1]\), compute the paper’s unweighted consensus scores over the population. For each item \(x\) and ordered pair \(x,y\), let \(p_x=\sum_{r:x\in r}\mu_r\) and \(p_{xy}=\sum_{r:x\text{ precedes }y\text{ in }r}\mu_r\). For each type \(r\), count its listed items with \(p_x\ge\alpha\) and its listed ordered pairs with \(p_{xy}\ge\alpha\), normalize by the numbers of items and pairs in \(r\) to obtain \(\kappa_1^r(\alpha)\) and \(\kappa_2^r(\alpha)\), and return \(K_i(\alpha)=\sum_{r\in R}\mu_r\kappa_i^r(\alpha)\) for \(i\in\{1,2\}\), together with the supported pattern sets.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq2\) candidates. A ranking type \(r=(r_1,\ldots,r_{\ell_r})\) is a strict ordered list of distinct candidates, with \(2\leq\ell_r\leq m\); incomplete rankings are allowed.
A society is given by its support: the list \(R\) of its \(\tau\) types with positive mass, each mass \(\mu_r\) a binary rational, with \(\sum_{r\in R}\mu_r=1\). Here \(\tau\) is the support size, not the number of possible types. The input also contains a binary rational threshold \(\alpha\in(0,1]\); let \(L\) be the total input bit length.
Define \(p_x=\sum_{r:x\in r}\mu_r\) and, for distinct candidates, \(p_{xy}=\sum_{r:x\text{ precedes }y\text{ in }r}\mu_r\); a pair contributes only when both candidates are listed, without any adjacency requirement.
The supported pattern sets are \(S_1(\alpha)=\{x\in C:p_x\geq\alpha\}\) and \(S_2(\alpha)=\{(x,y)\in C^2:x\neq y,\ p_{xy}\geq\alpha\}\).
For each type, define \(\kappa_1^r(\alpha)=|\{i:r_i\in S_1(\alpha)\}|/\ell_r\) and \(\kappa_2^r(\alpha)=|\{(i,j):i<j,\ (r_i,r_j)\in S_2(\alpha)\}|/\binom{\ell_r}{2}\), and let \(K_i(\alpha)=\sum_{r\in R}\mu_r\kappa_i^r(\alpha)\) for \(i\in\{1,2\}\).
The computational problem is to return the exact rational scores \(K_1(\alpha),K_2(\alpha)\) and the explicitly listed sets \(S_1(\alpha),S_2(\alpha)\).

Is this computation solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite list of rankings and an integer support threshold, a binary matrix representation expresses the individual scores through its trace and off-diagonal sum, and an algorithm computes the scores and supported patterns ([source](https://arxiv.org/abs/1905.12966)). Result

The computation is solvable in deterministic polynomial time in \(m,\tau,L\), including exact rational scores and explicit lists of both supported pattern sets.

The proof below applies to all the stated inputs, including incomplete rankings, unequal rational masses, and support values exactly equal to the threshold.

1. Convert the masses to integer weights

Write each input mass as \(\mu_r=a_r/b_r\), where \(a_r,b_r\) are positive integers encoded in binary. Write \(\alpha=u/v\), with positive integers \(u,v\).

Define
\[ Q=\prod_{r\in R}b_r,\qquad w_r=a_r(Q/b_r). \]

Each division \(Q/b_r\) is exact, and \(w_r/Q=\mu_r\). The assumption that the masses sum to one gives
\[ \sum_{r\in R}w_r=Q. \]

The algorithm computes these integers directly.

2. Compute the supported pattern sets

Initialize integer counters \(W_x=0\) for every candidate \(x\), and \(W_{xy}=0\) for every ordered pair of distinct candidates.

For each ranking \(r=(r_1,\ldots,r_{\ell_r})\):

  • For every position \(i\), add \(w_r\) to \(W_{r_i}\).
  • For every pair of positions \(i<j\), add \(w_r\) to \(W_{r_i r_j}\).

Because a ranking has distinct candidates, its weight is added exactly once to \(W_x\) when it contains \(x\). Likewise, its weight is added exactly once to \(W_{xy}\) when it lists both candidates with \(x\) preceding \(y\). Thus, after processing all rankings,
\[ W_x=Qp_x,\qquad W_{xy}=Qp_{xy}. \]

Enumerating all \(i<j\) includes nonadjacent pairs, as required.

Since \(Q,v\) are positive, exact threshold comparisons are
\[ p_x\geq\alpha\iff vW_x\geq uQ, \qquad p_{xy}\geq\alpha\iff vW_{xy}\geq uQ. \]

Use these integer comparisons to construct and explicitly list \(S_1(\alpha)\) and \(S_2(\alpha)\). Equality is included.

The number of counter updates is
\[ \sum_{r\in R}\left(\ell_r+\binom{\ell_r}{2}\right) \leq \tau\left(m+\binom m2\right), \]
and constructing the sets requires at most \(m+m(m-1)\) comparisons.

3. Compute the exact scores

Store membership in the two supported sets in Boolean tables. For each ranking, compute
\[ c_{1r}=\bigl|\{i:r_i\in S_1(\alpha)\}\bigr|, \qquad c_{2r}=\bigl|\{(i,j):i<j,\ (r_i,r_j)\in S_2(\alpha)\}\bigr|. \]

Define
\[ d_{1r}=\ell_r,\qquad d_{2r}=\binom{\ell_r}{2}. \]

The hypothesis \(\ell_r\geq2\) ensures that both denominators are positive. By definition,
\[ \kappa_i^r(\alpha)=\frac{c_{ir}}{d_{ir}} \quad\text{for }i\in\{1,2\}. \]

For each \(i\in\{1,2\}\), form the integers
\[ D_i=\prod_{r\in R}d_{ir}, \qquad T_i=\sum_{r\in R}w_r c_{ir}(D_i/d_{ir}). \]

Every division \(D_i/d_{ir}\) is exact. Return the rational number \(T_i/(QD_i)\), reduced by a greatest common divisor if desired. Indeed,
\[ \frac{T_i}{QD_i} = \sum_{r\in R}\frac{w_r}{Q}\frac{c_{ir}}{d_{ir}} = \sum_{r\in R}\mu_r\kappa_i^r(\alpha) = K_i(\alpha). \]

This proves correctness of both scores.

4. Bit complexity and output size

It remains to verify that the exact integers have polynomial bit length.

The total encoding length of the input denominators is at most \(L\), so
\[ \log_2 Q=\sum_{r\in R}\log_2 b_r\leq L. \]
Consequently, \(Q\) has at most \(L+1\) bits. Since the weights are positive and sum to \(Q\), every weight and every support counter is at most \(Q\). The threshold products \(vW_x\), \(vW_{xy}\), and \(uQ\) therefore have \(O(L)\) bits.

For the score denominators, \(d_{1r}\leq m\) and \(d_{2r}\leq m^2\). Hence
\[ \log_2 D_1\leq\tau\log_2 m, \qquad \log_2 D_2\leq2\tau\log_2 m. \]

Moreover, \(0\leq c_{ir}\leq d_{ir}\), so every summand defining \(T_i\) satisfies
\[ 0\leq w_r c_{ir}(D_i/d_{ir})\leq w_rD_i. \]
Summing and using \(\sum_r w_r=Q\) yields
\[ 0\leq T_i\leq QD_i. \]

Thus the score numerators, denominators, and intermediate integers have \(O(L+\tau\log m)\) bits. Products used to construct these integers also have this bit bound, up to a constant factor.

Both ranking scans require \(O(\tau m^2)\) operations, and the tables require \(O(m^2)\) entries. There are only polynomially many additional integer operations. Binary addition, comparison, multiplication, division, and greatest common divisor computation all take polynomial time in their operand bit lengths. Therefore the entire algorithm has polynomial bit complexity in \(m,\tau,L\).

Finally, the explicit sets have at most \(m\) and \(m(m-1)\) elements, respectively, and the exact score representations have polynomial bit length. The required output size is therefore polynomial as well.

5. Relation to the cited formulation

The cited paper defines singleton and ordered-pair support patterns and provides a matrix-based method for computing their scores in the finite-list setting. See [Xue et al., Section III](https://arxiv.org/pdf/1905.12966).

The proof above independently settles the stated rational-mass problem. Its essential arithmetic observation is that a common denominator may be large in numerical value while still having polynomial binary length. Computing with the integer weights avoids expanding the society into individual rankings.
