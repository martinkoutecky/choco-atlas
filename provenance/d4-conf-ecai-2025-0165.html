The continuous mirror question, as graded

At each round \(r\), add to \(W_r\) the lexicographically first candidate \(c\in C\setminus W_r\) maximizing \(\Delta_\mu(c\mid W_r)=\sum_{A:\,c\in A,\ A\cap W_r=\varnothing}\mu_A\). Classification

Mass sequential Chamberlin–Courant candidate membership is in \(\mathrm P\). In fact, it is \(\mathrm P\)-complete under logspace many-one reductions. The associated computation problem is in \(\mathrm{FP}\).

Both problems admit the bit-operation running-time bound
\[ O\!\left(\tau L^2+m(\tau+k)L\right). \]
Thus candidate membership could be \(\mathrm{NP}\)-hard under polynomial-time reductions only if \(\mathrm P=\mathrm{NP}\).

1. Exact integer representation

Write each input mass as \(\mu_A=p_A/q_A\), where the positive integers \(p_A,q_A\) are encoded in binary. Define
\[ D=\prod_{A\in\mathcal S}q_A, \qquad w_A=p_A(D/q_A). \]

Each \(w_A\) is a positive integer, and normalization gives
\[ \sum_{A\in\mathcal S}w_A =D\sum_{A\in\mathcal S}\mu_A =D. \]

The bit length of \(D\) is at most one plus the sum of the bit lengths of the input denominators, hence is \(O(L)\). Because \(0<w_A\leq D\), every weight also has \(O(L)\) bits.

For every committee \(W\) and available candidate \(c\), define
\[ G(c\mid W) =\sum_{\substack{A\in\mathcal S\\c\in A,\ A\cap W=\varnothing}}w_A. \]
Then
\[ G(c\mid W)=D\,\Delta_\mu(c\mid W). \]

Since \(D>0\), the integer scores preserve all strict comparisons and all ties. Furthermore, \(0\leq G(c\mid W)\leq D\), so every score has \(O(L)\) bits.

Using schoolbook integer multiplication and division, constructing \(D\) and all weights takes \(O(\tau L^2)\) bit operations. The algorithm never needs to expand the masses into individual voters.

2. Algorithm and correctness

Maintain a selected-candidate flag, a covered-type flag, and an integer score \(g_c\) for each candidate. Initially set
\[ g_c=\sum_{A\in\mathcal S:\,c\in A}w_A. \]

Perform exactly \(k\) rounds:

  • Scan the unselected candidates in their given lexicographic order. Choose a candidate with maximum score, retaining the first candidate when scores tie.
  • Mark that candidate \(x\) selected.
  • For each previously uncovered type \(A\) containing \(x\), mark \(A\) covered and subtract \(w_A\) from \(g_c\) for every still-unselected candidate \(c\in A\).

The invariant after round \(r\) is that a type \(A\) is covered precisely when \(A\cap W_r\neq\varnothing\), and that every unselected candidate satisfies
\[ g_c =\sum_{\substack{A\in\mathcal S\\c\in A,\ A\cap W_r=\varnothing}}w_A. \]

Initially, this follows from \(W_0=\varnothing\). Suppose it holds before selecting \(x\). A type changes from uncovered to covered exactly when it was previously uncovered and contains \(x\). For every remaining candidate, the update subtracts exactly the contributions of those newly covered types. Therefore the invariant holds after the round.

By Section 1, maximizing \(g_c\) with the stated tie-breaking is exactly the prescribed choice. Induction proves that the algorithm produces \(W_k\).

There is always an available candidate because \(r<k\leq m\). The algorithm continues even when all scores are zero, choosing the lexicographically first available candidate. Empty approval types contribute to no score and are handled without exception.

3. Running time

Use an incidence table recording whether each candidate belongs to each listed type. A conservative construction bound, including comparisons of encoded candidate names, is \(O(m\tau L)\) bit operations.

Initialization requires at most \(m\tau\) additions of \(O(L)\)-bit integers. The candidate scans require at most \(km\) comparisons of such integers.

Each type becomes covered at most once. Consequently, all score updates together require at most \(m\tau\) subtractions. Finding newly covered types by scanning the support each round requires \(k\tau\) incidence checks; since \(k\leq m\), this is at most \(m\tau\).

Including integer preprocessing, the total bound is therefore
\[ O\!\left(\tau L^2+m(\tau+k)L\right) \]
bit operations. This bound applies both to outputting \(W_k\) and to deciding whether \(d\in W_k\). Because the candidates and support are explicitly listed, their counts are bounded by the input length, so the bound is polynomial in \(L\).

4. Transfer of discrete-voter hardness

We use the supplied discrete-voter theorem: sequential Chamberlin–Courant candidate membership is \(\mathrm P\)-hard under logspace reductions, even on instances where tie-breaking is never invoked. This is established in Section 3.1 of [Fitzsimmons, Hassan, and Hemaspaandra](https://arxiv.org/html/2501.15006v3#S3.SS1).

Let a discrete election have explicitly listed voters with approval sets \(A_1,\ldots,A_n\). We may ensure \(n\geq1\) by adding one empty voter if necessary; an empty voter changes no marginal gain.

For each distinct approval set \(A\), let
\[ h_A=|\{i:A_i=A\}|, \qquad \mu_A=\frac{h_A}{n}. \]
Output the support consisting of those distinct sets, with these masses, and retain the candidates, their order, \(k\), and \(d\).

This is a valid target instance: all masses are positive, and
\[ \sum_A\mu_A=\frac{\sum_A h_A}{n}=1. \]

For every candidate \(c\) and committee \(W\),
\[ \Delta_\mu(c\mid W) =\frac1n |\{i:c\in A_i,\ A_i\cap W=\varnothing\}|. \]
Thus every mass marginal is the corresponding discrete marginal multiplied by the same positive factor. All comparisons and ties are preserved, so induction over the rounds shows that the entire selection sequence is identical. In particular, candidate membership is preserved, and instances with unique maximizing candidates retain that property.

The conversion is computable in logspace. For each voter position \(i\), repeated scans determine whether its approval set occurred earlier. If not, further scans count its multiplicity and output the set with mass \(h_A/n\). Equality of approval sets can be checked by scanning the candidates and comparing membership. Only a constant number of input-position counters and counts are needed, each using logarithmic space. If reduced fractions are required, their greatest common divisor can also be computed using logarithmic space.

Hence discrete-voter membership logspace-reduces to normalized rational-mass membership. Combined with the polynomial-time algorithm, this proves \(\mathrm P\)-completeness.
