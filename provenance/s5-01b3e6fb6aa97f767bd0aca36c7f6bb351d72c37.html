The continuous mirror question, as graded

Given \(p\in\mathbb{Q}\) with \(p>1/2\) and a rational mass distribution \(\mu\) over prediction types \(C=\{+,-\}\), choose \(y\in\{+,-\}\) maximizing \(\ell_\mu(y)=\sum_{v\in C}\mu_v\log\Pr(v\mid y)\), where \(\Pr(v\mid y)=p\) when \(v=y\) and \(1-p\) otherwise; return both labels in case of a tie.

A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\mu_v\geq0\), \(\sum_{v\in C}\mu_v=1\), and omitted types have zero mass; \(\tau\) is the support size, not the number of possible types.
Return the complete set \(\operatorname*{arg\,max}_{y\in C}\ell_\mu(y)\), where \(\ell_\mu(y)=\sum_{v\in C}\mu_v\log\Pr(v\mid y)\); return both labels in a tie. Let \(L\) be the total binary input length, including \(p\); state running times in \(m,\tau,L\).

Is this exact mass-based likelihood-maximization problem solvable in polynomial time, or is it NP-hard?

Result

The exact rational-mass problem is polynomial-time solvable, including exact detection of ties. For the stipulated \(m=2\), it admits an \(O(m+\tau+L)\) bit-operation algorithm, hence an \(O(L)\) algorithm.

Exact likelihood comparison

Write \(\mu_+=\mu_{+}\) and \(\mu_-=\mu_{-}\). By the given conditional prediction model,

\(\ell_\mu(+)=\mu_+\log p+\mu_-\log(1-p)\),

\(\ell_\mu(-)=\mu_+\log(1-p)+\mu_-\log p\).

Subtracting gives

\(\ell_\mu(+)-\ell_\mu(-)=(\mu_+-\mu_-)\log\!\left(\frac{p}{1-p}\right)\).

The hypothesis \(1/2<p<1\) implies \(p>1-p>0\). Consequently, \(p/(1-p)>1\), so its logarithm is strictly positive. The likelihood difference therefore has exactly the same sign as \(\mu_+-\mu_-\).

Since \(\mu_++\mu_-=1\), we have \(\mu_+-\mu_-=2\mu_+-1\). Thus the complete maximizing set is:

  • \(\{+\}\) if \(\mu_+>1/2\);
  • \(\{-\}\) if \(\mu_+<1/2\);
  • \(\{+,-\}\) if \(\mu_+=1/2\).

This proves the decision rule for every promised input, including omitted types and ties. No logarithm needs to be computed or approximated.

Algorithm and running time

Scan the support list to find the mass of \(+\). If \(+\) is omitted, set its mass to zero.

Represent the resulting rational mass as \(\mu_+=a/b\), where \(a\) and \(b\) are binary integers and \(b>0\). Reduction to lowest terms is unnecessary. Compare \(2a\) with \(b\), and return the corresponding set above. This comparison is exact because

\(\frac{a}{b}>\frac12\ \Longleftrightarrow\ 2a>b\),

with the analogous equivalences for equality and strict inequality.

Doubling a binary integer and comparing two binary integers take time linear in their bit lengths. Reading the support and its encodings takes \(O(\tau+L)\) bit operations; producing the maximizing set takes \(O(m)\). Hence the total bound is \(O(m+\tau+L)\).

Here \(m=2\), and normalization guarantees \(1\leq\tau\leq2\). Therefore the running time is \(O(L)\). Binary dyadic encodings give the same bound by an exact comparison with \(1/2\). The length of the encoding of \(p\) is included in \(L\); its proximity to \(1/2\) creates no numerical difficulty because only the promised strict inequality is used.

Relation to finite majority voting

For empirical masses from \(n\) predictions, with \(k\) predictions equal to \(+\), we have \(\mu_+=k/n\). The proved rule selects \(+\) precisely when \(2k>n\), and returns both labels when \(2k=n\). This recovers the majority rule discussed in the [supplied source](https://arxiv.org/html/2002.03153v2).

The proof above also covers arbitrary rational masses directly, without expanding them into a finite population. Thus the absence of an identified result for that formulation does not leave the stated binary problem unresolved.
