The continuous mirror question, as graded

Given finite item categories \(G\), finite agent types \(R\) with complete strict rankings \(\succ_r\), rational masses \(\mu_r\) summing to \(1\), and rational per-capita supplies \(q_g\in[0,1]\) with \(\sum_{g\in G}q_g=\ell\), does there exist \(x_{r,B}\ge0\) over integral bundles \(B\in\binom{G}{\ell}\) such that \(\sum_Bx_{r,B}=\mu_r\), \(\sum_{r\in R}\sum_{B\ni g}x_{r,B}=q_g\), and \(x_{r,B}x_{s,C}>0\Rightarrow B\succeq_{\mathrm{NDD}}^r C\) for all \(r,s,B,C\)?

Packaged proof task (what the prover saw — nothing else)

Let \(G\) be a set of \(m\) goods categories and let \(\ell\) be an input integer with \(2\le\ell\le m\). Each individual receives an integral bundle containing at most one item per category.
A society is given by its support: the list \(R\) of \(\tau\ge1\) types with positive masses \(\mu_r\), each a binary rational, with \(\sum_r\mu_r=1\), and complete strict rankings \(\succ_r\) of \(G\). Here \(\tau\) is the support size, not the number of possible rankings. Supplies are binary rationals \(q_g\in[0,1]\) with \(\sum_gq_g=\ell\); let \(L\) be the total input bit length.
For a ranking \(g_1\succ_r\cdots\succ_r g_m\), a DD utility is a strictly positive real additive utility consistent with that ranking and satisfying \(u(g_j)-u(g_{j+1})\ge u(g_{j+1})-u(g_{j+2})\) for \(1\le j\le m-2\). Define \(B\succeq^r_{\mathrm{NDD}}C\) to mean \(u(B)\ge u(C)\) for every such utility.
Write \(\mathcal B=\binom{G}{\ell}\). An allocation consists of real masses \(x_{r,B}\ge0\), indexed by \(r\in R\) and \(B\in\mathcal B\), satisfying \(\sum_{B\in\mathcal B}x_{r,B}=\mu_r\) and \(\sum_{r\in R}\sum_{B\ni g}x_{r,B}=q_g\).
Require \(x_{r,B}>0\land x_{s,C}>0\Rightarrow B\succeq^r_{\mathrm{NDD}}C\) for every \(r,s\in R\) and \(B,C\in\mathcal B\), including \(r=s\).

Is deciding whether such an allocation exists solvable in polynomial time in \(m,\tau,L,\ell\), or is it \(\mathrm{NP}\)-hard?

For finitely many agents and distinct indivisible goods, existence of a necessary-DD-envy-free allocation is \(\mathrm{NP}\)-complete with an unbounded number \(n\ge3\) of agents, already with exactly \(2n\) goods; checking a specified allocation is polynomial-time. [Source](https://www.jair.org/index.php/jair/article/download/11994/26566/23118).
No result settling this exact supportwise mass-allocation problem was located in the literature search.

Modeling choices made when packaging the task

  • The NDD relation was undefined in the continuous question; it universally quantifies over strictly positive real additive utilities consistent with the strict ranking and satisfying weak diminishing-difference inequalities.
  • The bundle-size domain was unspecified; take an input integer ell with 2 ≤ ell ≤ m, retaining the anchor's regime of at least two goods per individual.
  • Allocation masses were not assigned a number domain; allow nonnegative real masses, while the input masses and supplies remain binary rationals.
  • The finite-agent lower bound n ≥ 3 has no direct counterpart in a normalized nonatomic society; impose no lower bound of three on the number of supported types.
  • The bit-length parameter was unspecified; L denotes the total binary input length, and running times are stated in m, tau, L, and ell.

Result

The decision problem is \(\mathrm{NP}\)-complete, already when \(\ell=2\) and \(m=2\tau\). Hardness holds even when all masses and supplies are dyadic rationals.

The key is that the requirement including \(r=s\) forces every type to receive a single fixed bundle.

1. Each type receives exactly one bundle

Lemma. For a fixed strict ranking, if \(B\succeq_{\mathrm{NDD}}C\) and \(C\succeq_{\mathrm{NDD}}B\), then \(B=C\).

Proof. Write the ranking as \(g_1\succ\cdots\succ g_m\), and consider the additive utility defined by

\(u(g_j)=2^{m-j}\).

It is strictly positive and consistent with the ranking. Its consecutive differences are \(2^{m-j-1}\), so they decrease as \(j\) increases. Thus it is a DD utility.

Distinct subsets have distinct utility totals: at the first position where two subsets differ, the corresponding power of two exceeds the sum of all subsequent powers. Mutual necessary dominance would imply \(u(B)=u(C)\), which therefore forces \(B=C\). \(\square\)

Now suppose an allocation satisfies the task’s conditions. If \(x_{r,B}>0\) and \(x_{r,C}>0\), applying the envy condition in both orders gives mutual necessary dominance under ranking \(r\). The lemma implies \(B=C\).

Since \(\mu_r>0\), exactly one bundle \(B_r\) has positive mass for type \(r\), and that mass is \(\mu_r\). Consequently, feasibility is equivalent to choosing bundles \(B_r\in\binom{G}{\ell}\) satisfying

\(\displaystyle \sum_{r:g\in B_r}\mu_r=q_g\quad\text{for every }g\in G,\)

and

\(\displaystyle B_r\succeq^r_{\mathrm{NDD}}B_s\quad\text{for every }r,s\in R.\)

This equivalence eliminates the potentially exponential allocation support and all real-valued certificate variables.

2. Membership in \(\mathrm{NP}\)

A certificate lists the bundle \(B_r\) for every type. Its length is \(O(\tau\ell\log m)\). Supply equalities can be checked using exact rational arithmetic in polynomial time.

For completeness, the necessary-DD comparisons also admit the following explicit polynomial-time test.

Fix a ranking \(g_1\succ\cdots\succ g_m\). For \(1\le k\le m-1\), define

\(\displaystyle H_k(B)=\sum_{j:g_j\in B}\max\{k-j+1,0\}.\)

For equal-cardinality bundles,

\(\displaystyle B\succeq_{\mathrm{NDD}}C\quad\Longleftrightarrow\quad H_k(B)\ge H_k(C)\text{ for every }1\le k\le m-1.\)

To prove this, let \(d_j=u(g_j)-u(g_{j+1})\). The DD conditions say

\(d_1\ge\cdots\ge d_{m-1}>0.\)

Set \(a_{m-1}=d_{m-1}>0\), and \(a_k=d_k-d_{k+1}\ge0\) for \(k<m-1\). Telescoping gives

\(\displaystyle u(g_j)=u(g_m)+\sum_{k=1}^{m-1}a_k\max\{k-j+1,0\}.\)

Because \(|B|=|C|\), the constant term cancels, giving

\(\displaystyle u(B)-u(C)=\sum_{k=1}^{m-1}a_k\bigl(H_k(B)-H_k(C)\bigr).\)

Thus all the stated inequalities imply necessary dominance.

Conversely, if the inequality fails for \(k=m-1\), choose \(u(g_m)=1\), \(a_{m-1}=1\), and all other coefficients zero. If it fails for some \(k<m-1\), make the same choices but additionally set \(a_k=T\), where \(T>0\) is sufficiently large. The resulting utility is strictly positive, strictly decreasing, and DD, and satisfies \(u(B)<u(C)\). This proves the characterization.

All \(H_k\) are integers of polynomial bit length and can be computed in polynomial time. Checking every ordered pair of types therefore gives a polynomial-time verifier. The problem belongs to \(\mathrm{NP}\).

3. The finite-agent hardness source

We use the established \(\mathrm{NP}\)-hardness of necessary-DD-envy-free allocation for an unbounded number \(n\ge3\) of agents and exactly \(2n\) distinct goods. Moreover, the construction in Appendix C gives different top goods to all agents, so its rankings are pairwise distinct. These properties are verified directly in [Segal-Halevi, Hassidim, and Aziz, Theorem 7.4 and Appendix C](https://www.jair.org/index.php/jair/article/download/11994/26566/23118).

Every necessary-DD-envy-free allocation in such a finite instance gives exactly two goods to each agent. Indeed, for any ranking, the utilities

\(u_K(g_j)=K+2n-j,\qquad K>0,\)

are strictly positive DD utilities. If an agent’s bundle were smaller than another bundle, then for sufficiently large \(K\) that agent would envy the larger bundle. Hence envy-freeness forces equal cardinalities, and partitioning \(2n\) goods among \(n\) agents forces cardinality two.

Thus the source problem asks whether the original goods can be partitioned into pairs \(B_1,\ldots,B_n\) with

\(B_i\succeq_{\mathrm{NDD}}^i B_j\)

for every ordered pair of agents.

4. Reduction using dyadic masses and supplies

Let a source instance have goods \(G_0\), where \(|G_0|=2n\), and the pairwise distinct rankings described above.

Let \(D\) be the smallest power of two satisfying \(D\ge2n\), and put

\(\displaystyle \delta=1-\frac nD.\)

Construct the target instance as follows:

  • Add two goods \(a,b\), giving \(G=G_0\cup\{a,b\}\).
  • Set \(\ell=2\).
  • For each original agent \(i\), create a type of mass \(\mu_i=1/D\). Preserve its original ranking and append \(a\succ_i b\) below every original good.
  • Create one additional type \(*\), of mass \(\mu_*=\delta\), ranking \(a\succ_* b\) above every original good.
  • Set \(q_g=1/D\) for \(g\in G_0\), and \(q_a=q_b=\delta\).

There are \(\tau=n+1\) types and \(m=2n+2=2\tau\) goods. The types have distinct rankings because the original top goods are distinct and the additional type has top good \(a\).

All masses and supplies are positive dyadic rationals. They satisfy

\(\displaystyle \sum_r\mu_r=\frac nD+\delta=1,\)

and

\(\displaystyle \sum_gq_g=\frac{2n}{D}+2\delta=2=\ell.\)

Furthermore, \(\delta\ge1/2>1/D\). Since \(2n\le D<4n\), the numerical encoding length is polynomial.

Preservation of comparisons between original bundles

For an original type, its extended ranking preserves necessary-DD comparisons between bundles contained in \(G_0\).

One direction follows because restricting any DD utility for the extended ranking to its initial segment \(G_0\) gives a DD utility for the original ranking.

For the converse, take any original DD utility \(v\). Let \(z\) be its worst good, and let \(d>0\) be its last consecutive utility difference. Choose

\(\displaystyle 0<\varepsilon<\min\{d,v(z)/2\},\)

and extend it by

\(v(a)=v(z)-\varepsilon,\qquad v(b)=v(z)-2\varepsilon.\)

These values are positive. The appended differences are \(\varepsilon,\varepsilon\), both at most \(d\), so the extended utility remains DD and respects the extended ranking. Therefore every original DD utility has an admissible extension, establishing preservation in both directions.

Forward implication

Suppose the source instance has a necessary-DD-envy-free partition \(B_1,\ldots,B_n\).

Assign mass \(1/D\) of original type \(i\) to \(B_i\), and assign the entire additional type to \(\{a,b\}\). The supply equations hold because each original good occurs in exactly one original bundle.

Comparisons between original types hold by preservation of necessary-DD comparisons.

For every original type, both goods in its bundle rank above both \(a\) and \(b\), so its bundle has strictly greater utility than \(\{a,b\}\) under every consistent additive utility. For type \(*\), both \(a\) and \(b\) rank above every original good, so the reverse cross-type comparisons also hold. Within-type comparisons are reflexive because each type receives only one bundle.

Thus the target instance is feasible.

Reverse implication

Suppose the target instance is feasible. Section 1 implies that each type receives one fixed pair.

The additional type cannot receive any original good \(g\): doing so would consume mass \(\delta\) of that good, exceeding its entire supply \(q_g=1/D\). Its bundle must therefore be \(\{a,b\}\).

This consumes the full supplies of \(a\) and \(b\). Since every original type has positive mass, none can receive either good. Hence every original type receives a pair \(B_i\subseteq G_0\).

For each original good \(g\), its supply equation becomes

\(\displaystyle \frac1D\left|\{i:g\in B_i\}\right|=\frac1D.\)

Therefore exactly one original type receives \(g\), and the pairs \(B_1,\ldots,B_n\) partition \(G_0\).

The target envy conditions give necessary-DD dominance between every ordered pair of original bundles under the extended rankings. By the comparison-preservation argument, these are precisely the required comparisons under the original rankings. Hence the source instance has a necessary-DD-envy-free allocation.

5. Conclusion

The construction is a polynomial-time many-one reduction, and its two implications establish equivalence. Together with membership in \(\mathrm{NP}\), this proves \(\mathrm{NP}\)-completeness, even for \(\ell=2\), \(m=2\tau\), and dyadic input masses and supplies. Consequently, a polynomial-time algorithm in the stated parameters would imply \(\mathrm{P}=\mathrm{NP}\).
