The continuous mirror question, as graded

Given a finite set \(T\) of strict rankings over \(m\) objects, rational type masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), and feasible rational quota shares \(\ell_j,u_j\), compute exactly the type-conditioned lottery \(p_{tj}\) produced by unit-demand MPS. Let \(x_{tj}=\mu_t p_{tj}\) and \(y_j=\sum_{t\in T}x_{tj}\). Starting from \(x=0\), each type consumes its most-preferred available object at aggregate rate \(\mu_t\); availability is governed by \(\sum_j x_{tj}\le\mu_t\), \(y_j\le u_j\), and \(\sum_j\max\{\ell_j,y_j\}\le1\). Return the endpoint probabilities \(p_{tj}=x_{tj}/\mu_t\).

Packaged proof task (what the prover saw — nothing else)

Let \(O\) be a set of \(m\geq1\) objects, all acceptable. A society is given by its support: a list \(T\) of \(\tau\geq1\) distinct strict rankings of \(O\), each with positive binary rational mass \(\mu_t\), with \(\sum_t\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible rankings; let \(L\) be the total input bit length.
Each individual demands exactly one object. Binary rational quota shares satisfy \(0\leq\ell_j\leq u_j\leq1\), \(u_j>0\), and \(\sum_j\ell_j\leq1\leq\sum_j u_j\).
Define unit-demand minimums probabilistic serial (MPS) as follows. At time \(s\in[0,1]\), let \(x_{tj}(s)\geq0\) be allocated mass, \(y_j(s)=\sum_t x_{tj}(s)\), and \(H(s)=\sum_j\max\{\ell_j,y_j(s)\}\); initially \(x(0)=0\).
A type \(t\) can consume while \(\sum_j x_{tj}(s)<\mu_t\). Object \(j\) is available precisely when \(y_j(s)<u_j\) and either \(H(s)<1\) or \(y_j(s)<\ell_j\).
Each consuming type allocates mass at aggregate rate \(\mu_t\) to its highest-ranked available object. Apply all simultaneous availability changes together and continue to time \(s=1\). The required output is the exact rational matrix \(p_{tj}=x_{tj}(1)/\mu_t\).

Can this endpoint matrix be computed in time polynomial in \(m,\tau,L\), or is its exact computation NP-hard under polynomial-time Turing reductions?

For finite agents, the coordinatewise downward closure of feasible unit-demand fractional assignments is characterized by row bounds, object capacities, and \(\sum_j\max\{\ell_j,y_j\}\leq1\) after normalization; a polynomial-time MPS algorithm is also established ([Sandholtz–Tai](https://arxiv.org/html/2605.26367v1)).
An earlier finite-agent PSLQ mechanism uses the same restriction to objects with unmet minimum quotas ([Bojko](https://arxiv.org/html/2012.11028)). No result settling exact computation with binary rational support masses was verified.

Modeling choices made when packaging the task

  • Made feasible quota shares explicit: positive upper shares at most one, nonnegative lower shares no larger than upper shares, and total lower and upper shares bracketing one.
  • Made rankings complete and all objects acceptable, with exactly one object demanded per individual and nonempty object and support sets.
  • Resolved availability at a binding maximum-sum constraint using the discrete mechanism's positive-increment definition: only objects strictly below their minimum remain available.
  • Specified the unit time horizon, simultaneous handling of availability changes, and exact binary rational output.
  • Defined L as total input bit length and used polynomial-time Turing reductions for hardness of the exact-output function.

Exact computation is polynomial-time solvable

The endpoint matrix can be computed in time polynomial in \(m,\tau,L\). The algorithm operates directly on the listed support types. It uses at most \(2m+2\) event intervals, and every intermediate rational number has polynomial bit length.

The event structure parallels Algorithm 1 of [Sandholtz–Tai](https://arxiv.org/html/2605.26367v1). Bojko’s [Definition 5.2](https://arxiv.org/html/2012.11028) likewise restricts consumption to objects with unmet minimums once the remaining demand equals the minimum deficit. The proof below establishes correctness and bit complexity directly for the rational-mass model in the question.

1. Invariants and existence of available objects

Write \(x_{tj}\), \(y_j\), and \(H\) for the state at the current time \(s\). We will maintain

\(\displaystyle \sum_j x_{tj}=\mu_t s\quad\text{for every }t,\qquad 0\leq y_j\leq u_j\quad\text{for every }j,\qquad H\leq1.\)

These hold initially by the assumptions on the quotas. Summing the row equalities and using \(\sum_t\mu_t=1\) gives

\(\displaystyle \sum_j y_j=s.\)

Consequently, every type remains able to consume whenever \(s<1\): positivity of \(\mu_t\) implies \(\mu_t s<\mu_t\).

We first show that any state satisfying these invariants with \(s<1\) has an available object.

  • If \(H<1\), availability is equivalent to \(y_j<u_j\). If no object were available, all would satisfy \(y_j=u_j\), giving \(s=\sum_j u_j\geq1\), a contradiction.
  • If \(H=1\), every object satisfying \(y_j<\ell_j\) is available, since \(\ell_j\leq u_j\). If no object were available, we would therefore have \(y_j\geq\ell_j\) for every \(j\). This would give \(1=H=\sum_j y_j=s\), again a contradiction.

Thus, before time \(1\), all types can consume continuously at their prescribed rates.

2. The exact event algorithm

At a current state with \(s<1\), compute the available set

\(\displaystyle A=\{j:y_j<u_j\text{ and }(H<1\text{ or }y_j<\ell_j)\}.\)

For each type \(t\), let \(c(t)\) be its highest-ranked object in \(A\). This exists by Section 1 and is unique because rankings are strict.

Define \(v_{tj}=\mu_t\) when \(j=c(t)\), and \(v_{tj}=0\) otherwise. The aggregate object rates are

\(\displaystyle r_j=\sum_t v_{tj},\qquad \sum_j r_j=1.\)

Also define

\(\displaystyle B=\{j:y_j\geq\ell_j\},\qquad g=\sum_{j\in B}r_j.\)

Until a previously unmet minimum is reached, the slope of \(H\) is \(g\). The inclusion of equality in \(B\) is essential: when \(y_j=\ell_j\), additional consumption immediately increases \(\max\{\ell_j,y_j\}\).

Form the following candidate durations:

  • End of the time horizon: \(1-s\).
  • Capacity events: \((u_j-y_j)/r_j\) for every \(j\) with \(r_j>0\).
  • Minimum events: \((\ell_j-y_j)/r_j\) for every \(j\) with \(r_j>0\) and \(y_j<\ell_j\).
  • Global constraint event: \((1-H)/g\), included only when \(H<1\) and \(g>0\).

Let \(\delta\) be their minimum. All included durations are strictly positive. In particular, \(r_j>0\) implies that some type chose \(j\), so \(j\) is available and \(y_j<u_j\).

Update

\(\displaystyle x_{tj}\leftarrow x_{tj}+\delta v_{tj},\qquad y_j\leftarrow y_j+\delta r_j,\qquad s\leftarrow s+\delta.\)

If \(s<1\), recompute \(H\), the available set, and all choices from the updated state. This recomputation applies every simultaneous availability change together.

Minimum events are included even when they do not change availability, because they can change the slope of \(H\).

3. Correctness and termination

We prove inductively that each algorithmic interval follows the prescribed MPS dynamics and preserves the invariants.

Fix a current state satisfying the invariants. For an elapsed time \(h\) with \(0\leq h<\delta\), no positive-rate object has reached its capacity or crossed a previously unmet minimum.

For \(j\in B\), its contribution to \(H\) therefore equals \(y_j+h r_j\). For \(j\notin B\), its contribution remains \(\ell_j\). Hence

\(\displaystyle H(s+h)=H(s)+hg.\)

If \(H(s)<1\), the global candidate, when present, prevents \(H\) from reaching \(1\) before \(\delta\). If \(g=0\), \(H\) remains constant instead.

If \(H(s)=1\), every chosen object has an unmet minimum, by the availability rule. Thus all positive rates are on objects outside \(B\), so \(g=0\). Accordingly, \(H\) remains equal to \(1\) throughout this interval.

These observations show that availability is unchanged for \(0\leq h<\delta\). Therefore each type keeps consuming its selected object, exactly as the algorithm specifies.

At the endpoint:

  • capacity candidates ensure \(y_j+\delta r_j\leq u_j\);
  • the formula for \(H\) and the global candidate ensure \(H(s+\delta)\leq1\);
  • each row satisfies

\(\displaystyle \sum_j(x_{tj}+\delta v_{tj})=\mu_t s+\delta\mu_t=\mu_t(s+\delta).\)

Thus the invariants hold at the new state. Recomputing availability gives precisely the prescribed choices after all simultaneous changes. This also covers \(H(0)=1\), equal lower and upper quotas, and ties among event times.

Every interval ending before time \(1\) reaches at least one of these boundaries:

  • a previously unmet minimum;
  • a previously unreached capacity;
  • \(H=1\), starting from \(H<1\).

All \(y_j\) are nondecreasing, so each object can have at most one minimum event and one capacity event. Since \(H\) is nondecreasing and remains at most \(1\), the global event occurs at most once. Including the final interval, the number \(K\) of intervals satisfies

\(\displaystyle K\leq2m+2.\)

This proves termination at time \(1\), and the interval-by-interval argument proves that the computed state is the MPS endpoint.

In particular, \(\sum_jx_{tj}(1)=\mu_t\). The endpoint also satisfies all minimum quotas: since \(\sum_jy_j(1)=1\),

\(\displaystyle 0\leq\sum_j\bigl(\max\{\ell_j,y_j(1)\}-y_j(1)\bigr)=H(1)-1\leq0.\)

Each summand is nonnegative, so each is zero, giving \(y_j(1)\geq\ell_j\).

4. Polynomial bit complexity

A polynomial bound on event count alone would not establish polynomial time for exact rational output. We now bound the sizes of all arithmetic operands.

Let \(D\) be the product of the positive denominators appearing in all input masses and quota shares. Then every input rational has denominator dividing \(D\), and

\(\displaystyle \log_2(D+1)=O(L).\)

Write

\(\displaystyle \mu_t=\frac{a_t}{D},\qquad a_t\in\mathbb Z_{>0},\qquad\sum_ta_t=D.\)

For any interval, each object rate has the form

\(\displaystyle r_j=\frac{b_j}{D},\qquad b_j=\sum_{t:c(t)=j}a_t.\)

Thus \(0\leq b_j\leq D\). Similarly, \(g=b_H/D\) for an integer \(b_H\) with \(0\leq b_H\leq D\).

A common denominator for the state

Maintain a common denominator \(E\), divisible by \(D\), for the current time and every allocation coordinate:

\(\displaystyle s=\frac{S}{E},\qquad x_{tj}=\frac{X_{tj}}{E}.\)

Initially choose \(E=D\), with all numerators zero. Then every \(y_j\), every quota, and \(H\) also has an integer numerator over \(E\).

Every capacity, minimum, or global candidate duration can therefore be written as

\(\displaystyle \delta_{\mathrm{candidate}}=\frac{Dn}{Eb},\)

where \(n\) is the positive integer numerator of the corresponding remaining slack over \(E\), and \(1\leq b\leq D\).

The final-time candidate has this same form by taking

\(\displaystyle n=E(1-s),\qquad b=D.\)

Consequently, whichever candidate is selected, its duration has a representation \(\delta=Dn/(Eb)\) with \(1\leq b\leq D\).

Set \(E'=Eb\). For the time update,

\(\displaystyle s+\delta=\frac{Sb+Dn}{Eb}.\)

For an allocation coordinate, let \(a_{tj}=a_t\) if \(j=c(t)\), and \(a_{tj}=0\) otherwise. Then

\(\displaystyle x_{tj}+\delta v_{tj}=\frac{X_{tj}}{E}+\frac{Dn}{Eb}\frac{a_{tj}}{D}=\frac{X_{tj}b+a_{tj}n}{Eb}.\)

Thus the updated state again has the asserted common denominator. Each interval multiplies that denominator by an integer at most \(D\).

After \(k\) intervals,

\(\displaystyle E=D\prod_{i=1}^{k}b_i\leq D^{k+1}.\)

Because \(k\leq2m+2\), the denominator has \(O(mL)\) bits. The state coordinates all lie in \([0,1]\), so their nonnegative integer numerators are at most \(E\) and have the same bit bound.

Candidate durations also have polynomial bit length. They can be compared exactly by integer cross multiplication; their common factor \(D/E\) even allows comparison of \(n/b\) directly.

Arithmetic work and output size

Each interval requires scanning the \(\tau\) rankings, calculating rates and candidates, comparing \(O(m)\) candidates, and updating \(m\tau\) coordinates. This uses \(O(m\tau+m)\) arithmetic operations per interval, all on integers of \(O(mL)\) bits. Standard binary integer arithmetic therefore yields polynomial total running time.

Finally, if \(x_{tj}(1)=X_{tj}/E\), the required output is

\(\displaystyle p_{tj}=\frac{x_{tj}(1)}{\mu_t}=\frac{X_{tj}D}{Ea_t}.\)

Both numerator and denominator have \(O(mL)\) bits. Reducing each fraction by an integer greatest common divisor also takes polynomial time.

5. Conclusion

The exact endpoint matrix is computable in polynomial time in \(m,\tau,L\), with polynomial output length. No expansion of rational masses into a finite population is needed.

Under the usual definition of polynomial-time Turing hardness, NP-hardness of this computation would consequently imply \(\mathrm P=\mathrm{NP}\).
