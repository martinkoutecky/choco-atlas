The continuous mirror question, as graded

Given finite agent types \(A\) with rational masses \(\mu_a\) summing to one, finite good types \(\Xi\), and binary values \(v(a,\xi)\), consider finite adversarially ordered batches \((\xi_r,q_r)\) of rational mass with \(\sum_r q_r=1\). Each unit good is assigned irrevocably on arrival, and every agent receives an integral bundle \(z\in\mathbb{Z}_{\ge 0}^{|\Xi|}\). For this type system, determine the best deterministic competitive ratio \(C_{\det}=\sup_{\pi}\inf_{\sigma:\operatorname{OPT}(\sigma)>0}\operatorname{ALG}_{\pi}(\sigma)/\operatorname{OPT}(\sigma)\), where utility is the essential minimum over the agent mass and the offline benchmark knows the full batch sequence; in particular, does \(C_{\det}=0\) already for two equal-mass types with public and type-specific goods?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\geq2\) types \(a\in A\) with positive masses \(\mu_a\), each a binary rational, with \(\sum_a\mu_a=1\). Here \(\tau\) is the support size, not the number of possible types. There are \(m=|\Xi|\geq1\) good types, with known values \(v(a,\xi)\in\{0,1\}\); every agent type values at least one good type positively. State any running times in \(m,\tau,L\), and the number of batches \(R\), where \(L\) is the total binary input length.
Represent type \(a\) by an atomless interval \(I_a\) of length \(\mu_a\). Each individual \(s\in I_a\) initially has bundle \(z(s)=0\) and must always have a measurable integral bundle \(z(s)\in\mathbb Z_{\geq0}^{m}\), of value \(u(s)=\sum_{\xi\in\Xi}v(a,\xi)z_\xi(s)\).
An adversary chooses any finite sequence \(\sigma=((\xi_r,q_r))_{r=1}^{R}\), with positive binary-rational masses \(q_r\) and \(\sum_rq_r=1\). On seeing a batch, a deterministic policy must allocate it completely before the next arrival: it chooses measurable integer increments \(k_r(s)\geq0\), with \(\sum_a\int_{I_a}k_r(s)\,ds=q_r\), and replaces \(z(s)\) by \(z(s)+k_r(s)e_{\xi_r}\). Previous allocations are irrevocable; different individuals of the same type may receive different bundles.
The policy knows the society, value table, and total arriving mass, but no future batches or their number. Its value is \(\operatorname{ALG}_\pi(\sigma)=\operatorname*{ess\,inf}_s u(s)\). The offline value \(\operatorname{OPT}(\sigma)\) is the supremum of the same objective over allocations knowing the entire sequence and obeying the same constraints. Define the purely multiplicative ratio \(C_{\det}(A,\mu,\Xi,v)=\sup_\pi\inf_{\sigma:\operatorname{OPT}(\sigma)>0}\operatorname{ALG}_\pi(\sigma)/\operatorname{OPT}(\sigma)\), with no additive allowance.

What is \(C_{\det}(A,\mu,\Xi,v)\)? In particular, for two types of mass \(1/2\) and three good types with value vectors \((1,1),(1,0),(0,1)\), is \(C_{\det}=0\) or \(C_{\det}>0\)?

For discrete agents and indivisible binary-valued goods, every deterministic online algorithm has purely multiplicative competitive ratio zero under adversarial arrivals.
For finite-agent fractional or randomized allocation, an adversarial upper bound of \(1/n\) is also known ([Hajiaghayi et al.](https://arxiv.org/html/2210.07333)). No result settling the atomless, individually integral model above was located.

Modeling choices made when packaging the task

  • Made the population atomless and defined batch mass through integrals of integer bundle increments, resolving the meaning of unit goods in a mass society.
  • Allowed a deterministic policy to allocate differently within a type, while preserving each individual's integral bundle.
  • Required every arriving batch to be allocated completely before the next batch, with no reassignment.
  • Specified that the society and value table are known, while future batch contents and the number of batches are unknown.
  • Excluded types valuing every good at zero, so the infimum over positive-offline-value sequences is nonempty.
  • Used a purely multiplicative ratio, as explicitly specified in the continuous question; the supplied counterexample establishes this convention rather than ruling out every additive allowance.
  • Specified the two-type special case to have exactly one public and one private good type for each type.

1. Exact characterization

For each supported agent type \(a\), define its set of valued goods by
\[ S_a=\{\xi\in\Xi:v(a,\xi)=1\}. \]
By hypothesis, every \(S_a\) is nonempty.

A family of sets is laminar if any two members are disjoint or one contains the other.

Theorem. The competitive ratio is characterized as follows:

  • \(C_{\det}(A,\mu,\Xi,v)=1\) if \(\{S_a:a\in A\}\) is laminar.
  • \(C_{\det}(A,\mu,\Xi,v)=0\) otherwise.

Equal sets are allowed in a laminar family. The characterization depends on the positive support, not on the numerical masses beyond their positivity.

In particular, the two types in the question have valued-good sets \(\{c,x\}\) and \(\{c,y\}\). These intersect and neither contains the other, so \(C_{\det}=0\).

2. Total mass forces a dichotomy

Write \(b(s)=\sum_{\xi\in\Xi}z_\xi(s)\) for the final number of goods received by individual \(s\). Every complete allocation satisfies

\[ \int b(s)\,ds=1, \qquad 0\leq u(s)\leq b(s). \]

If its essential minimum utility is positive, integrality implies \(u(s)\geq1\) almost everywhere. Consequently,

\[ 1\leq\int u(s)\,ds\leq\int b(s)\,ds=1. \]

Both \(u(s)-1\) and \(b(s)-u(s)\) are nonnegative almost everywhere and have integral zero. Thus

\[ u(s)=b(s)=1 \quad\text{almost everywhere}. \]

Therefore a positive objective requires almost every individual to receive exactly one good, which that individual values. Every allocation’s objective is either \(0\) or \(1\), and hence so is \(\operatorname{OPT}(\sigma)\).

Moreover, positive-offline-value sequences exist: choose one valued good for each type \(a\), issue a batch of mass \(\mu_a\) of that good, and allocate it to all of \(I_a\).

It follows that every policy’s worst-case ratio belongs to \(\{0,1\}\). A positive competitive ratio is possible precisely when some policy succeeds on every offline-feasible sequence.

We will also use the following consequence. For any successful offline allocation, let \(F_{r,a}\) be the mass of batch \(r\) assigned to type \(a\). Then

\[ F_{r,a}\geq0,\qquad \sum_aF_{r,a}=q_r,\qquad \sum_rF_{r,a}=\mu_a, \]

and \(F_{r,a}=0\) whenever \(\xi_r\notin S_a\). Thus successful allocations supply a finite transportation matrix supported on valued pairs.

3. Laminar societies admit a successful online policy

Assume the valued-good sets are laminar. Fix an ordering of types by increasing \(|S_a|\), breaking ties deterministically.

When a batch of good \(\xi\) arrives, allocate one unit per individual to previously unserved individuals who value \(\xi\), processing their types in this order.

The types valuing \(\xi\) form a chain under inclusion: their sets all contain \(\xi\), so laminarity makes every pair comparable. Thus the rule serves the least flexible eligible types first.

Within each type, use an initial segment of its remaining unserved interval. This gives measurable, individually integral allocations.

If a batch exceeds the remaining eligible mass, allocate the eligible portion as above and allocate the surplus legally to a fixed measurable set of the appropriate measure; thereafter arbitrary legal allocations suffice. We prove that this fallback never occurs on an offline-feasible sequence.

Exchange lemma

Suppose the remaining demand of type \(a\) is \(d_a\), and the current and future batches have a feasible transportation matrix with column sums \(d_a\).

Let the current good be \(\xi\), its mass be \(q\), and its eligible types be \(a_1,\ldots,a_t\), ordered so that

\[ S_{a_1}\subseteq\cdots\subseteq S_{a_t}. \]

Let \(y_i\) be the greedy allocation to type \(a_i\). Feasibility implies \(q\leq\sum_i d_{a_i}\), so greedy allocates the entire batch.

We transform the feasible matrix to agree with this allocation. Process eligible types in order. Suppose earlier current-row entries already equal their greedy values, and write

\[ \rho=q-\sum_{h<i}y_h. \]

If the current-row entry for \(a_i\) is \(x_i\), then

\[ x_i\leq\min(d_{a_i},\rho)=y_i. \]

If \(x_i<y_i\), the deficit can be supplied by exchanging current goods assigned to later types with future goods assigned to \(a_i\):

  • Later types currently receive total mass \(\rho-x_i\geq y_i-x_i\).
  • Future batches assign \(d_{a_i}-x_i\geq y_i-x_i\) to \(a_i\).
  • Every such future good belongs to \(S_{a_i}\), and therefore also belongs to \(S_{a_j}\) for every later eligible type \(a_j\).

For each exchanged amount, transfer current good \(\xi\) from \(a_j\) to \(a_i\), and transfer the same amount of a future good from \(a_i\) to \(a_j\). Every affected pair remains valued; row and column sums remain unchanged.

Splitting matrix entries as needed completes the deficit. Repeating this finite operation through the eligible types makes the current row equal to the greedy allocation. Removing that row leaves a feasible matrix for the future batches with demands \(d_a-y_a\).

Applying the lemma

Fix any offline-feasible sequence. Initially, its successful offline allocation gives a feasible transportation matrix with demands \(\mu_a\).

The exchange lemma shows inductively that each greedy allocation:

  • allocates the current batch completely to unserved eligible individuals; and
  • leaves a feasible transportation matrix for the remaining batches.

Thus fallback never occurs. At termination, all remaining demands are zero, so almost every individual has received exactly one valued good.

This policy achieves \(\operatorname{ALG}(\sigma)=1\) whenever \(\operatorname{OPT}(\sigma)=1\), proving the laminar case.

4. Every laminarity violation forces ratio zero

Suppose \(S_a\) and \(S_b\) intersect but neither contains the other. Choose a common good \(g\in S_a\cap S_b\).

For a set of types \(B\), write \(\mu(B)=\sum_{c\in B}\mu_c\). Define

\[ C_a=\{c\in A:g\in S_c,\ S_c\subseteq S_a\}, \qquad C_b=\{c\in A:g\in S_c,\ S_c\subseteq S_b\}. \]

Because \(a\in C_a\setminus C_b\) and \(b\in C_b\setminus C_a\), positivity of the masses gives

\[ \alpha=\mu(C_a\setminus C_b)>0, \qquad \beta=\mu(C_b\setminus C_a)>0. \]

Set

\[ \gamma=\mu(C_a\cap C_b), \qquad q=\gamma+\frac12\min(\alpha,\beta). \]

This is a positive binary-rational mass satisfying

\[ \gamma<q<\min\bigl(\mu(C_a),\mu(C_b)\bigr)<1. \]

Both adversarial sequences will begin with the same batch \((g,q)\).

A feasible continuation forcing the first allocation into \(C_a\)

Define

\[ T_a=\Xi\setminus S_a, \qquad N_a=\{c\in A:S_c\cap T_a\neq\varnothing\}. \]

Then

\[ C_a=\{c:g\in S_c\}\setminus N_a. \]

Construct an offline allocation and its continuation as follows:

  • Allocate the initial mass \(q\) of \(g\) to a measurable subset of the individuals in \(C_a\), giving each recipient one unit.
  • For every type \(c\in N_a\), choose a good in \(S_c\cap T_a\), and supply mass \(\mu_c\) of that good.
  • Give every remaining unserved individual one selected valued good.

The initial subset can be chosen with rational mass within each type by filling types in a fixed order. Consequently, all continuation masses are rational. Aggregate equal goods and omit zero masses.

This produces a legal finite continuation of total mass \(1-q\), with offline value \(1\). Its total supply of goods belonging to \(T_a\) is exactly \(\mu(N_a)\): every type in \(N_a\) receives one such good, while types outside \(N_a\) value no such good.

Now suppose an online policy succeeds on this continuation. By Section 2, every individual receives exactly one valued good almost everywhere. All goods in \(T_a\) must therefore go to individuals in \(N_a\). Their mass \(\mu(N_a)\) exhausts those individuals’ entire receiving capacity.

Hence the first batch cannot allocate anything to \(N_a\). Its recipients must also value \(g\). Thus successful first-batch allocation must lie entirely in \(C_a\).

The identical construction with \(b\) yields another offline-feasible continuation forcing the first allocation entirely into \(C_b\).

The two requirements are incompatible

A deterministic policy makes the same first allocation on these two sequences, since their observed first batch is identical.

If it succeeded on both, its first increment \(k_1(s)\) would satisfy, almost everywhere:

  • \(k_1(s)\leq1\);
  • \(k_1(s)=0\) outside \(C_a\cap C_b\).

Therefore,

\[ q=\int k_1(s)\,ds \leq\mu(C_a\cap C_b) =\gamma, \]

contradicting \(q>\gamma\).

At least one of the two offline-feasible sequences defeats every deterministic policy. This proves \(C_{\det}=0\) whenever the family is nonlaminar.

Each constructed continuation uses at most \(m\) batches after aggregation, so the obstruction requires at most \(m+1\) batches in total.

5. The stated two-type example

Let \(c\) be the common good, and let \(x,y\) be valued only by the first and second type, respectively.

Issue a first batch \((c,1/2)\). Consider these two continuations:

  • \((x,1/2)\): success requires the entire common-good batch to have gone to the second type.
  • \((y,1/2)\): success requires the entire common-good batch to have gone to the first type.

Both sequences have offline value \(1\). The identical first allocation cannot satisfy both requirements. Therefore \(C_{\det}=0\).

6. Computation and running time

Testing laminarity by comparing all pairs of the \(\tau\) supported types takes \(O(m\tau^2)\) Boolean operations.

For a laminar society, ordering types takes \(O(\tau\log\tau)\) comparisons after computing their set sizes. The online policy uses \(O(\tau)\) rational arithmetic operations and at most \(O(\tau)\) interval increments per batch.

For \(R\) batches, let \(L\) be the total binary input length, including their encodings. A coarse bit-time bound is

\[ O\!\left((m\tau^2+\tau\log\tau+R\tau)L^2\right). \]

Indeed, the product of the denominators seen so far provides a common denominator with \(O(L)\) bits; maintaining it requires no knowledge of future batches. All stored interval lengths and arithmetic operands then have \(O(L)\) bits.

The characterization and policy use only the listed support types, with no enumeration of possible binary valuation vectors.

Consequently, every allocation has objective zero or one. The same holds for the offline supremum: if that supremum is one, some allocation must have objective one, since the attainable objectives belong to \(\{0,1\}\). There is no unattained-supremum problem.

The construction supplying each type with one selected valued good establishes that the set of sequences with positive offline value is nonempty. 2. The laminar policy and exchange lemma

For a fixed arriving good, all eligible valuation sets contain that good. Laminarity therefore makes them comparable by inclusion. Ordering by cardinality respects this inclusion order; ties between eligible types have equal valuation sets.

The policy’s allocation to initial segments of unserved intervals is measurable and individually integral. The fallback also defines legal behavior on infeasible sequences: a batch’s surplus is at most one, so a measurable recipient set of that measure exists.

The exchange lemma is valid:

  • Feasibility implies that the current batch mass does not exceed total eligible remaining demand.

  • If there is a deficit, later eligible entries contain enough current-row mass, and future entries for \(a_i\) contain enough mass to exchange.

  • Each exchange preserves nonnegativity and row and column totals.

The assertion that splitting entries completes the deficit requires no missing lemma: the matrix has finitely many entries, and each exchange can exhaust a donor entry or finish the deficit.

Removing the adjusted current row leaves precisely the residual demands asserted. Induction therefore applies through the entire finite sequence. At termination, feasibility with no remaining rows forces every residual demand to vanish. This proves success on every offline-feasible sequence and establishes the laminar case.
