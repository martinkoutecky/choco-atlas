The continuous mirror question, as graded

Given a finite type set \(T=R\sqcup S\), rational mass vector \(\mu\), rational type interaction rates \(\lambda_{uv}\), trust parameters \(\theta_{uv}\), and stubborn beliefs \(x_s\), define \(Q^\mu_{uv}=\mu_v\lambda_{uv}\theta_{uv}\) for regular \(u\), with diagonal entries making regular rows sum to zero. Compute the exact stationary type means \(h_u\), or an additive-\(\varepsilon\) approximation, satisfying \(\sum_v Q^\mu_{uv}h_v=0\) for \(u\in R\) and \(h_s=x_s\) for \(s\in S\).

For distinct \(u\in R\), \(v\in T\), the input gives binary rational interaction rates \(\lambda_{uv}\geq0\) and trust parameters: \(0<\theta_{uv}\leq1\) when \(\lambda_{uv}>0\), and \(\theta_{uv}=0\) otherwise. Define \(Q^\mu_{uv}=\mu_v\lambda_{uv}\theta_{uv}\) for \(u\in R\), \(v\ne u\), and \(Q^\mu_{uu}=-\sum_{v\ne u}Q^\mu_{uv}\); stubborn rows are zero. Interactions within a type contribute nothing to its mean equation.

1. Classification

Both exact and additive-approximate stationary-mean computation are polynomial-time solvable. Exact computation has polynomial running time and polynomial output length in \(\tau\) and \(L\). Consequently, additive-\(\varepsilon\) computation is polynomial-time in \(\tau\), \(L\), and \(\log(1/\varepsilon)\).

The harmonic interpretation is consistent with the cited [Acemoğlu–Como–Fagnani–Ozdaglar paper](https://pubsonline.informs.org/doi/10.1287/moor.1120.0570). We prove the complexity classification directly for the specified rational mass input, without expanding masses into individual agents.

2. The rational linear system

Let \(n=|R|\), and write \(q_{uv}=\mu_v\lambda_{uv}\theta_{uv}\) for \(u\in R\), \(v\ne u\). Define

\[ d_u=\sum_{v\ne u}q_{uv}. \]

Because masses are positive and trust parameters are positive on positive-rate edges,

\[ q_{uv}>0\quad\Longleftrightarrow\quad\lambda_{uv}>0. \]

The reachability assumption therefore implies \(d_u>0\) for every \(u\in R\).

Define the rational matrix \(A\), indexed by \(R\), and vector \(b\) by

\[ A_{uu}=d_u,\qquad A_{uv}=-q_{uv}\quad(u\ne v,\ u,v\in R),\qquad b_u=\sum_{s\in S}q_{us}x_s. \]

Separating regular and stubborn terms in the given harmonic equations gives exactly

\[ Ah_R=b. \]

Thus it suffices to solve this explicitly represented rational system and append the given stubborn coordinates.

3. Nonsingularity and bounds on the means

Lemma. The matrix \(A\) is nonsingular.

Proof. Suppose \(Az=0\), and extend \(z\) to \(T\) by setting \(z_s=0\) for \(s\in S\). Then

\[ z_u=\sum_{v\ne u}\frac{q_{uv}}{d_u}z_v \qquad(u\in R). \]

The coefficients are nonnegative and sum to one.

If \(z\ne0\), replace \(z\) by \(-z\) if necessary so that \(M=\max_{v\in T}z_v>0\). A vertex \(u\) attaining \(M\) must be regular. Its averaging equation implies

\[ 0=\sum_{v\ne u}q_{uv}(M-z_v). \]

Every summand is nonnegative. Hence every positive-rate out-neighbor of \(u\) also has value \(M\). Propagating along a positive-rate path from \(u\) to a stubborn type forces that stubborn type to have value \(M\), contradicting its value zero. Therefore \(z=0\), proving nonsingularity. \(\square\)

Consequently, the system has a unique rational solution.

The same maximum argument gives

\[ \min_{s\in S}x_s\leq h_u\leq\max_{s\in S}x_s \qquad(u\in T). \]

Indeed, a maximum strictly above all stubborn beliefs would propagate along a path to a stubborn type, a contradiction. Applying this argument to \(-h\) proves the lower bound. Signed stubborn beliefs cause no difficulty.

4. Polynomial bit complexity of exact computation

Counting arithmetic operations alone would be insufficient: we must bound both intermediate integers and the output.

Clearing denominators

Write every input rational as an integer numerator divided by a positive integer denominator. Let \(D\) be the product of all these denominators. Since their total binary encoding length is at most \(L\),

\[ D\leq 2^L. \]

Each \(q_{uv}\) is a product of three input rationals, so its denominator divides \(D^3\). Each \(q_{us}x_s\) has denominator dividing \(D^4\). Therefore

\[ M=D^4A,\qquad c=D^4b \]

are integer objects, and \(Mh_R=c\) is equivalent to the original system.

Every input numerator has absolute value at most \(2^L\). Using \(\mu_v\leq1\) and \(\theta_{uv}\leq1\), we obtain

\[ 0\leq q_{uv}\leq2^L,\qquad |A_{uv}|\leq\tau2^L,\qquad |b_u|\leq\tau2^{2L}. \]

Thus every entry of \(M\) and \(c\) has absolute value at most

\[ H=\tau2^{6L}. \]

In particular, their entry bit lengths are \(O(L+\log\tau)\), and they can be constructed in polynomial time.

Determinant computation with bounded intermediate sizes

We justify the needed elementary algorithmic fact.

Lemma. For an integer matrix \(C\) of dimension \(n\), with entries bounded in absolute value by \(H\geq1\), its determinant can be computed in time polynomial in \(n\) and \(\log H\).

Proof. The determinant expansion bounds every minor of order \(j\) by

\[ j!H^j\leq n!H^n. \]

Hence all minors have bit length \(O(n(\log H+\log n))\).

Perform Gaussian elimination over the rationals, reducing fractions after arithmetic operations and swapping rows when necessary. After \(k\) successful pivots, consider the corresponding row-permuted original matrix in block form

\[ C'= \begin{pmatrix} P&U\\ V&W \end{pmatrix}, \]

where \(P\) is the nonsingular leading block of order \(k\). The remaining matrix is the Schur complement \(W-VP^{-1}U\). Each of its entries satisfies

\[ (W-VP^{-1}U)_{ij} = \frac{ \det\begin{pmatrix} P&U_{\cdot j}\\ V_{i\cdot}&W_{ij} \end{pmatrix} }{\det P}. \]

This identity follows by subtracting \(V_{i\cdot}P^{-1}\) times the upper block rows from the last row of the bordered matrix.

Both determinants in the ratio are minors of the row-permuted input matrix. Therefore each reduced elimination entry has numerator and denominator bit length \(O(n(\log H+\log n))\). Each update uses a fixed number of rational arithmetic operations, so its temporary operands also have polynomial bit length.

If no pivot exists in the current column, the remaining Schur complement has a zero column and the determinant is zero. Otherwise, elimination finishes, and the determinant is the signed product of the pivots. That product also has polynomial bit length during its computation.

There are \(O(n^3)\) arithmetic operations. Integer arithmetic and fraction reduction by the Euclidean algorithm take polynomial time in operand bit length, proving the claim. \(\square\)

Computing the solution

For each \(i\in R\), let \(M^{(i)}\) be obtained from \(M\) by replacing column \(i\) with \(c\). Since \(M\) is nonsingular, Cramer’s rule gives

\[ h_i=\frac{\det M^{(i)}}{\det M}. \]

For completeness, this identity follows from determinant multilinearity: substitute \(c=Mh_R\) into the replaced column. Every term except the \(i\)-th has two equal columns and vanishes.

All \(n+1\) matrices have entries bounded by \(H\). The lemma computes their determinants in polynomial time. Moreover,

\[ |\det M|,\ |\det M^{(i)}|\leq n!H^n. \]

Thus each output coordinate, after reduction, has numerator and denominator bit length

\[ O\bigl(n(L+\log\tau)\bigr). \]

There are at most \(\tau\) coordinates. Hence the total exact output length and the complete running time are polynomial in \(\tau\) and \(L\).

5. Additive approximation

The exact algorithm already solves the approximation task: output \(\widehat h=h\). Its error is zero for every permitted \(\varepsilon\), and its running time is polynomial in \(\tau\) and \(L\).

If dyadic output is desired, choose

\[ k=\left\lceil\log_2(1/\varepsilon)\right\rceil,\qquad \widehat h_u=2^{-k}\left\lfloor2^kh_u\right\rfloor. \]

For every coordinate, including negative ones,

\[ 0\leq h_u-\widehat h_u<2^{-k}\leq\varepsilon. \]

The maximum principle and input bounds give \(|h_u|\leq2^L\), so these dyadic outputs have \(O(L+k)\) bits per coordinate. Computing them from the exact rational solution takes polynomial time in \(\tau\), \(L\), and \(k\).

No lower bound on interaction rates, absorption probability, or numerical conditioning is needed.

6. Meaning of the hardness alternative

Exact computation belongs to \(\mathrm{FP}\), and additive computation has a polynomial-time algorithm with the requested parameter dependence.

Accordingly, NP-hardness under polynomial-time Turing reductions for either task would imply \(\mathrm{P}=\mathrm{NP}\): replace every oracle call by the polynomial-time algorithm proved above. The unconditional classification established here is polynomial-time solvability.
