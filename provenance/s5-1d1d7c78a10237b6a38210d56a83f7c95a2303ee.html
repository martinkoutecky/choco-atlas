The continuous mirror question, as graded

Given a finite candidate set \(C\), a rational distribution \(\mu\) over complete rankings of \(C\), and a proposed zone \(Z\subseteq C\), decide whether every candidate set \(K\subseteq C\) with \(K\cap Z\ne\emptyset\) has its fractional-mass IRV winner in \(Z\). In each round, each type's mass supports its highest-ranked remaining candidate, and the paper's fixed deterministic tie-breaking resolves elimination ties.

Packaged proof task (what the prover saw — nothing else)

Let \(C=\{c_1,\ldots,c_m\}\), with \(m\geq1\), and let \(\varnothing\ne Z\subseteq C\).
A society is given by its support: a list of \(\tau\) distinct strict complete rankings of \(C\), each with positive binary-rational mass, with masses summing to \(1\). Here \(\tau\) is the support size, not the number \(m!\) of possible rankings; rankings are unrestricted.
For each nonempty candidate set \(K\subseteq C\), restrict every ranking to \(K\) and run fractional-mass IRV: each type's entire mass supports its highest-ranked remaining candidate; eliminate one candidate of minimum total mass each round, eliminating the largest-index candidate among ties, until one remains. Denote the winner by \(w_\mu(K)\).
The verification problem asks whether \(w_\mu(K)\in Z\) for every \(K\subseteq C\) satisfying \(K\cap Z\ne\varnothing\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this verification problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard under polynomial-time Turing reductions?

Discrete exclusion-zone verification is \(\mathrm{coNP}\)-complete for deterministic rank-based elimination rules satisfying Strong Forced Elimination, including IRV with graph-induced preferences. [Source](https://arxiv.org/html/2603.10290v1)
For continuous spatial societies, uniform voters on any hyperrectangle of dimension \(d\geq2\) have no nontrivial IRV exclusion zones under \(\ell_1\) or \(\ell_2\) distance preferences. [Source](https://arxiv.org/html/2502.16719v2)
No result settling this exact verification problem with explicitly supported rational ranking masses and the specified deterministic tie-breaking was located.

Modeling choices made when packaging the task

  • Complete rankings are strict total orders, matching the deterministic resolution of ranking ties in the discrete model.
  • Candidate indices serve as fixed IDs; among candidates tied for minimum supporting mass, eliminate the largest index.
  • Require a nonempty candidate universe and a nonempty proposed zone, as in the discrete definition; allow the whole universe as a zone.
  • Make the distribution normalization explicit: positive support masses sum to one.
  • Interpret NP-hardness using polynomial-time Turing reductions because the anchor concerns a universally quantified coNP-complete decision problem.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The verification problem is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions, and therefore \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. Hardness holds even when \(|Z|=1\), \(\tau\leq m\), and every mass is a dyadic rational with encoding length \(O(\log m)\).

The reduction below is direct and does not require transferring the graph-based hardness theorem.

1. Exact simulation and membership in \(\mathrm{coNP}\).

Write the input masses as \(\mu_i=p_i/q_i\), with numerators and denominators encoded in binary. Set

\(\displaystyle D=\prod_{i=1}^{\tau}q_i,\qquad a_i=p_i(D/q_i).\)

These are integers with \(O(L)\) bits, and \(\sum_i a_i=D\). Replacing masses by integer weights \(a_i\) preserves every tally comparison and tie. Computing these weights takes \(O(L^3)\) bit operations using elementary arithmetic. This bound also applies if the input masses are specifically required to be dyadic.

For a given nonempty \(K\), maintain a pointer in each ranking to its highest-ranked remaining candidate, together with lists of types currently supporting each candidate. When a candidate is eliminated, advance the pointers of its supporting types and update the tallies. Each pointer traverses at most \(m\) entries during the entire election, so there are \(O(m\tau)\) pointer advances and tally updates. Scanning the remaining candidates to find each successive minimum requires \(O(m^2)\) comparisons. Integer arithmetic and comparisons involve \(O(L)\) bits.

Consequently, one election can be simulated exactly in

\(\displaystyle O\!\left(L^3+(m\tau+m^2)L\right)\)

bit operations, including preprocessing.

A certificate that verification fails is an \(m\)-bit description of a set \(K\) satisfying \(K\cap Z\neq\varnothing\) and \(w_\mu(K)\notin Z\). The simulation verifies this certificate in polynomial time. Hence the verification problem belongs to \(\mathrm{coNP}\).

For completeness, exhaustive enumeration gives a deterministic algorithm running in

\(\displaystyle O\!\left(L^3+2^m(m\tau+m^2)L\right),\)

with the integer-weight preprocessing performed once.

2. The source problem.

We use the known \(\mathrm{NP}\)-completeness of Restricted Exact Cover by 3-Sets: the input consists of a universe \(U\) with \(|U|=3n\) and a family \(\mathcal S\) of three-element subsets, with each element occurring in exactly three members of \(\mathcal S\). The question is whether some subfamily partitions \(U\). This hardness fact is stated in [Appendix B.3 of the supplied source](https://arxiv.org/html/2603.10290v1#S0.SS3).

Take \(n\geq1\). Counting incidences gives \(|\mathcal S|=3n\), so write \(\mathcal S=\{S_1,\ldots,S_{3n}\}\).

3. Construction with dyadic masses.

Create candidates \(c_1,\ldots,c_{3n}\), one for each set, and a distinguished candidate \(u=c_{3n+1}\). Thus

\(\displaystyle m=3n+1,\qquad Z=\{u\}.\)

We choose integer weights whose total is a power of two. Let \(Q\) be the smallest power of two satisfying

\(\displaystyle Q>(3n+2)(3n+3),\)

and define

\(\displaystyle p=\left\lfloor\frac{Q}{3n+3}\right\rfloor+1,\qquad r=Q-3np.\)

The interval with endpoints \(Q/(3n+3)\) and \(Q/(3n+2)\) has length

\(\displaystyle \frac{Q}{(3n+2)(3n+3)}>1.\)

By the definition of \(p\),

\(\displaystyle \frac{Q}{3n+3}<p\leq\frac{Q}{3n+3}+1<\frac{Q}{3n+2}.\)

Multiplying these inequalities by the positive denominators and using \(r=Q-3np\) yields

\(\displaystyle 2p<r<3p.\)

For every element \(x\in U\), create a ranking of mass \(p/Q\). Its order is:

  • All candidates \(c_j\) with \(x\in S_j\), in increasing index order.
  • The candidate \(u\).
  • All remaining set candidates, in increasing index order.

Also create one ranking of mass \(r/Q\), placing \(u\) first and then all set candidates in increasing index order.

Each ranking is strict and complete. All masses are positive dyadic rationals, and their sum is

\(\displaystyle 3n\frac pQ+\frac rQ=1.\)

If several element rankings coincide, merge them and add their masses. Merging preserves every election tally and produces the required list of distinct rankings. There are at most \(3n+1=m\) support types.

Because \(Q=O(n^2)\), every resulting mass has encoding length \(O(\log(n+2))\). The output length is \(O(m^2\log(m+1))\), and the construction, including sorting and merging rankings, takes \(O(m^2\log^2(m+1))\) bit operations. Thus it is a polynomial-time reduction.

4. Tallies while \(u\) remains.

Consider any round whose remaining candidates are

\(\displaystyle R=\{u\}\cup\{c_j:j\in F\},\)

where \(F\neq\varnothing\). Scale the tallies by \(Q\), so that element rankings have weight \(p\) and the distinguished ranking has weight \(r\).

Let \(h\) be the number of elements not covered by the selected sets \(\{S_j:j\in F\}\). An element ranking supports \(u\) exactly when its element is uncovered: every selected set containing that element appears before \(u\), and every other set appears after \(u\). Therefore

\(\displaystyle T(u)=r+hp.\)

For \(j\in F\), let \(t_j\) be the number of element rankings supporting \(c_j\). Such an element necessarily belongs to \(S_j\). Since \(|S_j|=3\),

\(\displaystyle T(c_j)=pt_j,\qquad 0\leq t_j\leq3.\)

These formulas hold at every round while \(u\) remains, regardless of earlier eliminations.

Suppose \(u\) is eliminated in this round. Being a minimum-tally candidate requires

\(\displaystyle r+hp\leq pt_j\leq3p\qquad\text{for every }j\in F.\)

If \(h\geq1\), then \(r+hp\geq r+p>3p\), a contradiction. Hence \(h=0\). The inequalities now imply \(pt_j\geq r>2p\). Because \(t_j\) is an integer at most three, necessarily \(t_j=3\) for every selected set.

Thus every selected set has all three of its elements assigned to its candidate. Each element is assigned to only one candidate, so the selected sets are pairwise disjoint. Since \(h=0\), they also cover \(U\). They form an exact cover.

We have proved: whenever \(u\) is eliminated before the final survivor, the remaining set candidates correspond to an exact cover.

5. Correctness of the reduction.

Suppose an exact cover exists, and let \(F\) index its sets. Run the election on

\(\displaystyle K=\{u\}\cup\{c_j:j\in F\}.\)

Every element belongs to exactly one selected set, so each selected set candidate receives scaled tally \(3p\), whereas \(u\) receives \(r<3p\). Thus \(u\) is the unique minimum and is eliminated first. The winner lies outside \(Z\), so verification fails.

Conversely, suppose there is no exact cover. Take any \(K\) containing \(u\). If \(K=\{u\}\), then \(u\) wins. Otherwise, the preceding argument shows that \(u\) cannot be eliminated at any round with more than one remaining candidate: such an elimination would exhibit an exact cover. Consequently \(u\) is the final survivor. Verification therefore succeeds.

Hence

\(\displaystyle (U,\mathcal S)\text{ has an exact cover}\quad\Longleftrightarrow\quad\text{the constructed verification instance is rejected}.\)

All comparisons determining whether \(u\) can be eliminated are strict. The proof therefore applies to the specified largest-index elimination tie-break.

6. Complexity conclusion.

The same construction reduces the complement of Restricted Exact Cover by 3-Sets to verification. Together with membership in \(\mathrm{coNP}\), this proves \(\mathrm{coNP}\)-completeness under polynomial-time many-one reductions.

An oracle for verification also decides Restricted Exact Cover by 3-Sets with one query, by negating the oracle’s answer. Thus verification is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions, as requested. It belongs to \(\mathrm P\) if and only if \(\mathrm P=\mathrm{NP}\).

Since \(r>2p\), each integral \(t_j\) must equal three. Each remaining set candidate therefore receives all three elements of its set. Overlapping selected sets would require their shared element to support two candidates simultaneously, which cannot occur. Together with \(h=0\), this proves that the remaining sets form an exact cover.

This argument applies at every relevant round and makes no assumption about earlier elimination choices.

Thus \(u\) never ties a set candidate while it remains. Ties among other candidates do not affect the argument. The specified deterministic tie-break is therefore fully accommodated.
