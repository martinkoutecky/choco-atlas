The continuous mirror question, as graded

Given a finite set of parties \(P\), a binary-rational voter mass \(\mu_i>0\) for each party-choice type \(i\in P\), with \(\sum_{i\in P}\mu_i=1\), an integer house size \(H\), and a fixed tie priority, compute the seat allocation obtained by applying DCEL to claims \(d_i=\lfloor H\mu_i\rfloor+1\) and estate \(H\). Equivalently, give each party \(\lfloor H\mu_i\rfloor\) seats and assign the remaining seats by descending fractional remainder of \(H\mu_i\).

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a nonempty finite set of parties, with \(m=|P|\). A society is given by its support: the list of its \(\tau\) party-choice types with positive mass, each mass \(\mu_i\) a binary rational, with \(\sum_{i\in P}\mu_i=1\). Here every party has positive mass, so \(\tau=m\); \(\tau\) denotes support size, not the number of possible types.
The input also contains a binary-encoded house size \(H\in\mathbb Z_{\geq0}\) and a strict total priority order for breaking ties. Let \(L\) be the total input bit length; output seat counts in binary and state running times in \(m,\tau,L\), including dependence on \(\log(H+1)\).
Set \(q_i=H\mu_i\), \(d_i=\lfloor q_i\rfloor+1\), and estate \(E=H\). The discrete constrained equal losses rule (DCEL) first computes \(c_i=\max\{0,d_i-\lambda\}\), choosing \(\lambda>0\) so that \(\sum_i c_i=H\), and assigns \(\lfloor c_i\rfloor\) seats to each party.
It then assigns the remaining seats, at most one per party with nonintegral \(c_i\), in descending order of \(q_i-\lfloor q_i\rfloor\), breaking equal remainders by the fixed priority. The required output is this unique integer allocation.

Is computing this allocation polynomial-time solvable in the binary input length, or is it NP-hard?

For integer vote counts, DCEL with this remainder priority equals Hamilton’s greatest-remainder method ([Sánchez-Soriano, Llorca and Algaba](https://doi.org/10.5277/ord160208)).
No separate complexity theorem for this exact rational-mass input model was verified.

  • Seat-output encoding was unspecified: return one binary integer count per party.
  • The support convention was unspecified: all listed parties have positive mass, so the support size equals the number of parties; use total input bit length for L.

Result

Computing the allocation is polynomial-time solvable in the binary input length. In fact, the stated DCEL rule equals Hamilton’s greatest-remainder method for every rational-mass input in the question.

The proof below is independent of the cited result for integer votes.

Exact form of the constrained allocation

For each party \(i\), define its integer quota and remainder by

\(b_i=\lfloor H\mu_i\rfloor,\qquad r_i=H\mu_i-b_i.\)

Thus \(0\leq r_i<1\), and the claim used by DCEL is \(d_i=b_i+1\). Define

\(K=H-\sum_{i\in P}b_i.\)

Since the masses sum to one,

\(K=\sum_{i\in P}r_i.\)

Consequently, \(K\) is an integer satisfying \(0\leq K<m\). In particular, the rational remainders always sum to an integer.

Set

\(\lambda_*=1-\frac{K}{m}.\)

Because \(0\leq K<m\), we have \(0<\lambda_*\leq1\). For every party,

\(d_i-\lambda_*=b_i+\frac{K}{m}\geq0.\)

Therefore the constrained allocation associated with this choice is

\(c_i=\max\{0,d_i-\lambda_*\}=b_i+\frac{K}{m}.\)

It satisfies the estate constraint exactly:

\(\sum_{i\in P}c_i=\sum_{i\in P}b_i+K=H.\)

For completeness, when \(H>0\), this is the unique admissible value of \(\lambda\). Indeed, let \(f(\lambda)=\sum_i\max\{0,d_i-\lambda\}\). If \(\lambda_1<\lambda_2\) and \(f(\lambda_2)>0\), some party has \(d_i>\lambda_2\). Its contribution decreases strictly between these two values, while every other contribution is nonincreasing. Hence \(f(\lambda_1)>f(\lambda_2)\), proving uniqueness at any positive estate.

When \(H=0\), every \(d_i=1\). Although any \(\lambda\geq1\) meets the estate constraint, every such choice gives \(c_i=0\). Thus the allocation remains uniquely defined.

Identification with Hamilton’s method

There are two cases.

  • \(K=0\). The formula above gives \(c_i=b_i\) for every party. These are integers summing to \(H\), so the final allocation is \(b_i\).
  • \(1\leq K<m\). Since \(0<K/m<1\), every \(c_i\) is nonintegral and \(\lfloor c_i\rfloor=b_i\). Exactly \(K\) seats remain. DCEL awards these seats to the first \(K\) parties in descending order of \(r_i\), using the given priority order for equal remainders.

Accordingly, in all cases the output is

\(s_i=b_i+\mathbf{1}\{i\text{ is among the first }K\text{ parties in remainder order}\}.\)

This is precisely Hamilton’s greatest-remainder allocation. The fixed priority order makes the selection unique.

Exact algorithm and bit complexity

Write each input mass as \(\mu_i=a_i/v_i\), with positive binary-encoded integers \(a_i,v_i\). This also covers dyadic binary rationals.

The algorithm is:

  • Compute the integer quotient and remainder

\(Ha_i=b_iv_i+u_i\), where \(0\leq u_i<v_i\).

  • Compute \(K=H-\sum_i b_i\).
  • Sort the parties by decreasing \(u_i/v_i\), breaking ties by the supplied priority.
  • Output \(b_i+1\) for the first \(K\) parties and \(b_i\) for all others.

All comparisons are exact: compare \(u_i/v_i\) with \(u_j/v_j\) by comparing the integers \(u_iv_j\) and \(u_jv_i\).

To give an explicit bound, let

\(h=\max\{1,\lceil\log_2(H+1)\rceil\},\qquad B=L+h+1.\)

The quota products, divisions, accumulated sums, and comparison products involve integers with \(O(B)\) bits. Using schoolbook multiplication and binary long division, each arithmetic operation needed here costs \(O(B^2)\) bit operations. Computing all quotas takes \(O(\tau B^2)\); comparison sorting takes \(O(m\log_2(m+1)B^2)\). Hence a valid total bound is

\(O\!\left((\tau+m\log_2(m+1))(L+h+1)^2\right).\)

Here \(\tau=m\), so this becomes

\(O\!\left(m\log_2(m+1)(L+\log_2(H+1)+1)^2\right).\)

Because \(H\) is part of the binary input, \(h=O(L)\); the bound is therefore polynomial in \(L\). Each output seat count lies between zero and \(H\), requiring at most \(h\) bits. The algorithm never iterates over the \(H\) individual seats.
