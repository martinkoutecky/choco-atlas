The continuous mirror question, as graded

Given a finite support \(T\) of complete compatibility types, rational masses \(\mu_t>0\) with \(\sum_t\mu_t=1\), and compatible exchange patterns \(\kappa\) of length at most fixed \(L=3\), solve the mass cycle-packing LP \(\max\sum_{\kappa}(\sum_t a_{\kappa t})z_\kappa\) subject to \(\sum_{\kappa}a_{\kappa t}z_\kappa\le\mu_t\) and \(z_\kappa\ge0\). For every type \(t\), compute the exact interval \([\underline q_t,\overline q_t]\) of \(q_t(z)=\sum_\kappa a_{\kappa t}z_\kappa/\mu_t\) over the optimal face, and output the partition into types with \(q_t=1\) always, \(q_t=0\) always, or \(0<q_t<1\) for some optimum.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type represents incompatible patient–donor pairs. An explicit table \(C\in\{0,1\}^{T\times T}\) specifies whether every donor of type \(s\) is compatible with every patient of type \(t\). A diagonal entry concerns distinct pairs of the same type; donation within a pair is excluded.
Let \(\mathcal K\) contain all cyclic sequences \(\kappa=(t_1,\ldots,t_r)\), up to rotation, with \(r\in\{2,3\}\) and \(C_{t_i,t_{i+1}}=1\), using cyclic indices. Types may repeat, representing distinct pairs. Let \(a_{\kappa t}\) count occurrences of \(t\) in \(\kappa\).
Consider \(\max\{\sum_{\kappa\in\mathcal K}(\sum_{t\in T}a_{\kappa t})z_\kappa:\sum_{\kappa\in\mathcal K}a_{\kappa t}z_\kappa\leq\mu_t\ \forall t\in T,\ z_\kappa\geq0\}\). Let \(F\) be its optimal face and \(q_t(z)=\sum_{\kappa\in\mathcal K}a_{\kappa t}z_\kappa/\mu_t\).
The required outputs are an optimal packing and value, each exact interval \([\min_{z\in F}q_t(z),\max_{z\in F}q_t(z)]\), and the partition into types always fully served, always unserved, or satisfying \(0<q_t(z)<1\) for some \(z\in F\). Let \(m=\tau^2\) count compatibility-table entries and \(L\) be total input bit length; state running times in \(m,\tau,L\), with cycle bound fixed at \(3\).

Is this computation solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite societies with binary selection variables, the always-selected, never-selected, and variably-selected partition can be computed using at most \(n+1\) integer-program optimizations, each adding at most one constraint. This is a solver-call bound, not a polynomial-time guarantee.

Modeling choices made when packaging the task

  • Made complete compatibility explicit as a directed Boolean table whose entries apply uniformly to all pairs of the indicated types.
  • Excluded singleton exchanges because the represented patient–donor pairs are internally incompatible; allowed cycles of lengths two and three.
  • Allowed repeated types in a cycle, representing distinct pairs, and defined diagonal compatibility accordingly.
  • Defined exchange-pattern multiplicities and identified cyclic rotations as the same pattern.
  • Reserved L for input bit length, replacing the graded question's use of L for the fixed cycle bound.
  • Defined m as the number of compatibility-table entries because this problem has no candidate-count parameter.
  • Retained the graded question's interior-service category, including types whose service fraction is fixed strictly between zero and one.

Result

The entire computation is polynomial-time solvable in \(m,\tau,L\). An exact algorithm uses at most \(2\tau+1\) rational linear-program optimizations.

The variables in the stated problem are continuous. Repeated types in a cycle remain allowed throughout the argument.

1. Polynomially many cycle variables

Index the types by \(\{1,\ldots,\tau\}\). Enumerate every ordered sequence of length \(2\) or \(3\), including sequences with repeated types. For each sequence, check the required compatibility entries and retain it only if it is lexicographically smallest among its cyclic rotations.

This enumerates precisely \(\mathcal K\): compatibility is invariant under rotation, and each rotation class has one smallest sequence. Reversal is not identified unless it is also a rotation.

Writing \(N=|\mathcal K|\), we have
\[ N\leq \tau^2+\tau^3. \]
Enumeration takes \(O(m+\tau^3)\) table-access operations, including reading the compatibility table. With binary indices, its bit cost is \(O(L+(m+\tau^3)\log(\tau+1))\).

Define the matrix and objective coefficients by \(A_{t\kappa}=a_{\kappa t}\) and \(c_\kappa=\sum_t a_{\kappa t}\). Every column of \(A\) has nonnegative integer entries, with column sum \(c_\kappa\in\{2,3\}\). The packing problem is therefore
\[ \max\{c^\mathsf Tz:Az\leq\mu,\ z\geq0\}. \]

If \(N=0\), the unique packing is the empty vector, the value is \(0\), and every service interval is \([0,0]\). Henceforth suppose \(N>0\).

2. Existence and exact optimization

Let \(P=\{z\geq0:Az\leq\mu\}\). This set is nonempty because \(0\in P\). For every \(z\in P\),
\[ c^\mathsf Tz =\sum_t(Az)_t \leq\sum_t\mu_t =1. \]
Since \(c_\kappa\geq2\) and all variables are nonnegative, this also implies \(z_\kappa\leq1/2\) for every \(\kappa\). Thus \(P\) is a compact rational polytope.

We use the standard rational linear-programming theorem: an explicitly represented rational LP can be solved exactly in time polynomial in its binary encoding length, returning a rational optimizer and optimal value whenever a finite optimum exists. Rational data can be converted to integer data by clearing denominators with polynomial encoding growth. See the [MIT notes on polynomial-time linear optimization](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

Here the representation is explicit and rational, and feasibility and boundedness were proved above. One LP optimization therefore returns an exact optimal packing \(z^\star\) and value \(V=c^\mathsf Tz^\star\).

The optimal face is exactly
\[ F=\{z\geq0:Az\leq\mu,\ c^\mathsf Tz=V\}. \]
It is nonempty, compact, and convex.

3. Exact service intervals

For each type \(t\), solve the two LPs
\[ u_t^-=\min_{z\in F}(Az)_t, \qquad u_t^+=\max_{z\in F}(Az)_t. \]
Each uses the original constraints together with the single equality \(c^\mathsf Tz=V\). An implementation using only inequalities represents this equality by two inequalities.

Because \(\mu_t>0\), the requested interval is precisely
\[ [\ell_t,h_t] = \left[\frac{u_t^-}{\mu_t},\frac{u_t^+}{\mu_t}\right]. \]
Both extrema are attained, since \(F\) is compact and the objectives are continuous. Moreover, every value between the endpoints is attained: convex combinations of endpoint optimizers lie in \(F\), and \(q_t\) is linear in \(z\).

This computes all exact intervals with another \(2\tau\) LP optimizations.

4. The requested partition

Feasibility and positivity of the masses give \(0\leq q_t(z)\leq1\). Define
\[ T_{\mathrm{full}}=\{t:\ell_t=1\}, \qquad T_{\mathrm{zero}}=\{t:h_t=0\}, \]
and
\[ T_{\mathrm{interior}}=\{t:\ell_t<1\text{ and }h_t>0\}. \]

The first two definitions characterize types always fully served and always unserved, respectively.

For the third, necessity follows immediately: if some \(z\in F\) satisfies \(0<q_t(z)<1\), then \(\ell_t<1\) and \(h_t>0\).

For sufficiency, choose endpoint optimizers \(z^-,z^+\in F\). Their midpoint \(\bar z=(z^-+z^+)/2\) belongs to \(F\), and
\[ q_t(\bar z)=\frac{\ell_t+h_t}{2}. \]
If \(h_t>0\), this quantity is positive. If \(\ell_t<1\), then \(\ell_t+h_t<2\), because \(h_t\leq1\). Hence \(0<q_t(\bar z)<1\).

These three sets are disjoint and exhaustive. In particular, a type with the same strictly intermediate service level in every optimal packing belongs to \(T_{\mathrm{interior}}\), exactly as the question requires.

5. Bit complexity and running time

A dense encoding of \(A\), the objectives, and the original right-hand side has length
\[ B=O(L+\tau N)=O(L+\tau^4). \]
We must also verify that adding the exact value \(V\) preserves this bound.

Let \(D\) be the product of the denominators of the input masses and write \(\mu_t=b_t/D\). The binary length of \(D\) is \(O(L)\). Introduce slack variables:
\[ Az+s=\mu,\qquad z,s\geq0. \]
The matrix \([A\ I]\) has rank \(\tau\). Every vertex corresponds to a nonsingular \(\tau\times\tau\) basis matrix \(H\). Indeed, the columns indexed by positive variables must be independent; otherwise a sufficiently small perturbation in both directions along a dependence would contradict extremality. These independent columns can be extended to a basis.

Every column of \([A\ I]\) has Euclidean norm at most \(3\). Hadamard’s inequality gives
\[ 1\leq|\det H|\leq3^\tau. \]
By Cramer’s rule, every basic coordinate has denominator dividing \(D|\det H|\). All feasible coordinates lie in \([0,1]\), so their numerators and denominators have \(O(L+\tau)\) bits.

An optimal vertex exists because \(P\) is a nonempty compact polytope. Consequently \(V\) also has \(O(L+\tau)\) bits: it has the same possible denominator and lies in \([0,1]\).

The service extrema likewise have short exact representations. Each extremum is attained at a vertex of \(F\), and every vertex of \(F\) is a vertex of \(P\). To justify the latter assertion, any decomposition of a point of \(F\) into feasible points must use points with objective value \(V\); otherwise their average objective would be below \(V\). Thus such a decomposition already lies in \(F\).

At such a vertex, writing \((Az)_t=p/(D|\det H|)\) gives
\[ q_t(z)=\frac{p}{b_t|\det H|}. \]
Since \(0\leq q_t(z)\leq1\), both numerator and denominator again have \(O(L+\tau)\) bits.

Therefore every auxiliary LP has encoding length \(O(L+\tau^4)\), and all requested exact outputs have polynomial length. For some fixed polynomial \(p_{\mathrm{LP}}\) bounding exact rational LP optimization, the total bit running time is bounded by
\[ (2\tau+1)\,p_{\mathrm{LP}}\!\bigl(O(L+\tau^4)\bigr) +\operatorname{poly}(L+m+\tau^4). \]
Because \(m=\tau^2\), this is also
\[ \operatorname{poly}(L+m^2)=\operatorname{poly}(m,\tau,L). \]

The finite-society integer-program solver-call bound does not change this conclusion. Here both the number of calls and the cost of each call are polynomial, because the explicitly stated optimization problems are rational linear programs.
