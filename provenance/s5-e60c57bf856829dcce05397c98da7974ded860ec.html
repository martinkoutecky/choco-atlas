The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), and symmetric rational costs \(\gamma(t,u)\) between types and the source, replicate \(n\mu_t\) agents of each type and play the paper's game with a uniformly random order. Does the limit \(\Lambda_t=\lim_{n\to\infty}\frac{1}{n}\mathbb{E}_{\pi}\left[\sum_{i:\,\mathrm{type}(i)=t}\mathrm{payment}_i(\pi)\right]\) exist along integers \(n\) for which every \(n\mu_t\) is integral, and how can \(\Lambda\) be computed?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. There is one source \(0\); write \(m=\tau+1\) for the number of node kinds.
Input costs \(\gamma(t,u)\) for \(t,u\in T\cup\{0\}\) are finite, symmetric, nonnegative binary rationals. For distinct agents of types \(t,u\), their edge costs \(\gamma(t,u)\), including when \(t=u\); source edges cost \(\gamma(t,0)\). Individual node self-costs are zero, and self-loops are unavailable.
For every positive integer \(n\) with all \(n\mu_t\) integral, create \(n\mu_t\) distinct agents of type \(t\). Start with no edges and choose a uniformly random permutation \(\pi\) of these agents.
Each agent acts once, in this order. If her current connected component is \(A\), she selects any edge \(\{i,j\}\) with \(i\in A\) and \(j\notin A\), possibly joining the source or an agent who has not acted; add that edge and charge its entire cost to the acting agent. Agents minimize their own payments.
Use subgame-perfect equilibrium play: at every history select a cheapest available edge, resolving ties lexicographically under fixed node labels. Let \(p_i^{(n)}(\pi)\) be agent \(i\)'s payment, and define \(\Lambda_t=\lim_{n\to\infty,\;n\mu_u\in\mathbb Z\;\forall u\in T}\frac{1}{n}\mathbb E_\pi[\sum_{i:\operatorname{type}(i)=t}p_i^{(n)}(\pi)]\), whenever this limit exists.
For the computational question, additionally supply \(t\in T\) and a binary rational threshold \(q\); let \(L\) be the total input bit length, including masses, costs, and threshold.

Do all limits \(\Lambda_t\) exist, and how can \(\Lambda\) be computed?
On inputs where the limits exist, is deciding \(\Lambda_t\ge q\) polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?

For finite populations, the expected subgame-perfect payment allocation is unique and equals the folk rule ([Hernández, Peris, and Vidal-Puga](https://doi.org/10.1016/j.ejor.2022.09.015)); the ordinary finite folk rule has polynomial-time algorithms ([Lorenzo-Freire, González-Maestro, and Alonso-Meijide](https://doi.org/10.1016/j.dam.2023.06.001)).
No result settling this support-encoded replication-limit problem was located in the literature search.

Result

All limits exist. Define

\(a_t:=\min_{u\in T\cup\{0\}}\gamma(t,u)\).

Then

\(\boxed{\Lambda_t=\mu_t a_t\qquad(t\in T).}\)

The minimum includes \(\gamma(t,t)\), the cost between distinct agents of type \(t\). Consequently, computing \(\Lambda\), and deciding whether \(\Lambda_t\ge q\), are polynomial-time solvable in the stated binary encoding.

1. A finite-population formula

Consider any finite population \(N\), with source \(0\) and edge costs \(c_{ij}\). Choose \(M\) at least as large as every edge cost. For \(x\in[0,M]\), let \(G_x\) contain precisely the edges whose costs are at most \(x\), and let \(C_i(x)\) be the connected component containing agent \(i\).

Write \(F_i\) for agent \(i\)'s finite folk-rule payment. We will establish

\(F_i=\displaystyle\int_0^M h_i(x)\,dx,\)

where \(h_i(x)=0\) if \(0\in C_i(x)\), and otherwise \(h_i(x)=1/|C_i(x)|\).

We use the supplied finite equilibrium theorem and the characterization of the folk rule as the Shapley value of the minimum-spanning-tree cost game for the irreducible cost matrix. Both characterizations are stated in [Hernández, Peris, and Vidal-Puga](https://vidalpuga.webs.uvigo.es/papers/folkimplementation.pdf). Their hypotheses apply here: the population is finite, costs are symmetric, finite and nonnegative, and individual diagonal costs are zero.

Here is a derivation of the integral formula.

Define the irreducible costs, for distinct nodes, by

\(d_{ij}:=\min_{P:i\leadsto j}\max_{e\in P}c_e,\)

where the minimum ranges over paths in the full population graph. Set \(d_{ii}=0\). Thus \(d_{ij}\le x\) exactly when \(i\) and \(j\) belong to the same component of \(G_x\).

For \(S\subseteq N\), let \(v(S)\) be the minimum-spanning-tree cost on \(S\cup\{0\}\) using costs \(d\). At threshold \(x\), its graph consists of cliques obtained by intersecting the components of \(G_x\) with \(S\cup\{0\}\). Therefore its number of components minus one is

\(\displaystyle\sum_{\substack{C\text{ component of }G_x\\0\notin C}}\mathbf 1\{S\cap C\ne\varnothing\}.\)

For any finite weighted complete graph, its minimum-spanning-tree cost equals the integral of its threshold component count minus one. Indeed, after processing all edges of cost at most \(x\), Kruskal's algorithm has a spanning tree within each threshold component. If there are \(k(x)\) such components, the completed tree has exactly \(k(x)-1\) edges of cost greater than \(x\). Integrating this count sums the tree's edge costs.

Consequently,

\(v(S)=\displaystyle\int_0^M\sum_{\substack{C\text{ component of }G_x\\0\notin C}}\mathbf 1\{S\cap C\ne\varnothing\}\,dx.\)

For a fixed non-source component \(C\), the coalition function \(\mathbf 1\{S\cap C\ne\varnothing\}\) has Shapley payment \(1/|C|\) for each member of \(C\), and zero for other agents. To see this, its marginal contribution is one precisely for the first member of \(C\) in a uniformly random permutation. Each member has probability \(1/|C|\) of being first.

Taking Shapley values in the preceding integral proves the formula for \(F_i\). This interchange is justified directly: the Shapley value is a finite average, and the integrands are bounded step functions.

By the supplied equilibrium theorem,

\(\mathbb E_\pi[p_i^{(n)}(\pi)]=F_i^{(n)}.\)

2. A uniform replication bound

Fix a type \(t\). Write \(N_t=n\mu_t\), and suppose every type has at least two agents. This holds for all sufficiently large admissible \(n\), because every \(\mu_t\) is positive.

Take

\(M:=\max_{r,u\in T\cup\{0\}}\gamma(r,u).\)

If \(0\le x<a_t\), every type-\(t\) agent is isolated in \(G_x\): every edge incident to her has cost at least \(a_t\). Hence

\(\displaystyle\sum_{i:\operatorname{type}(i)=t}h_i(x)=N_t.\)

If \(x\ge a_t\), all type-\(t\) agents belong to one component. Indeed, choose a kind attaining the minimum defining \(a_t\):

  • If it is \(0\), every type-\(t\) agent is adjacent to the source.
  • If it is some \(u\ne t\), every type-\(t\) agent is adjacent to any chosen type-\(u\) agent, which exists by positive support.
  • If it is \(t\), all distinct type-\(t\) agents are mutually adjacent.

Let this common component be \(C\). If it contains the source, the summed integrand is zero. Otherwise it is \(N_t/|C|\), which is at most one because \(C\) contains all \(N_t\) type-\(t\) agents. Thus, throughout \(x\ge a_t\),

\(0\le\displaystyle\sum_{i:\operatorname{type}(i)=t}h_i(x)\le1.\)

Integrating gives the finite bound

\(N_ta_t\le\mathbb E_\pi\!\left[\displaystyle\sum_{i:\operatorname{type}(i)=t}p_i^{(n)}(\pi)\right]\le N_ta_t+(M-a_t).\)

After dividing by \(n\),

\(\boxed{0\le\frac1n\mathbb E_\pi\!\left[\sum_{i:\operatorname{type}(i)=t}p_i^{(n)}(\pi)\right]-\mu_ta_t\le\frac{M-a_t}{n}.}\)

This also covers zero costs and ties.

3. Existence of every limit

Let \(D\) be a common multiple of the denominators of the masses. Every positive multiple of \(D\) is admissible, so admissible population sizes are unbounded.

The bound above holds for every sufficiently large admissible \(n\), and its upper error tends to zero. Therefore, along the entire admissible sequence,

\(\Lambda_t=\mu_ta_t.\)

Since \(t\) was arbitrary, every coordinate of \(\Lambda\) exists.

4. Exact computation and complexity

To compute the allocation:

  • For each \(t\), find \(a_t=\min_{u\in T\cup\{0\}}\gamma(t,u)\).
  • Return \(\Lambda_t=\mu_ta_t\).

This requires \(O(\tau m)\) rational comparisons and \(\tau\) rational multiplications, without constructing a replicated population.

For the decision problem, write \(\mu_t=A/B\), \(a_t=C/D\), and \(q=E/F\), with positive denominators. Then

\(\Lambda_t\ge q\quad\Longleftrightarrow\quad ACF\ge EBD.\)

The integers in these products have \(O(L)\) bits. Exact comparison and multiplication therefore take polynomial bit time. The decision problem belongs to \(\mathrm P\).
