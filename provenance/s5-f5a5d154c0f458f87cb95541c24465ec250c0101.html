Theorem 13 — class: hardness

The continuous mirror question, as graded

Given candidates \(C\), approval-ballot types \(B_1,\ldots,B_\tau\subseteq C\) with rational masses \(\mu_i>0\) summing to \(1\), and a rational budget \(0\leq\beta<1\), decide whether rational deletion masses \(x_i\in[0,\mu_i]\) exist with \(\sum_i x_i\leq\beta\) such that \(\left|\arg\max_{c\in C}\sum_i(\mu_i-x_i)\mathbf{1}[c\in B_i]\right|<\left|\arg\max_{c\in C}\sum_i\mu_i\mathbf{1}[c\in B_i]\right|\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty finite candidate set with \(m=|C|\). A society is given by its support: distinct approval types \(B_1,\ldots,B_\tau\subseteq C\), possibly empty, with positive binary rational masses \(\mu_i\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible approval sets.
The input also includes a binary rational budget \(0\leq\beta<1\); let \(L\) be the total input bit length. Deleting mass has unit cost, and rational deletions satisfy \(0\leq x_i\leq\mu_i\) and \(\sum_i x_i\leq\beta\).
Define \(s_x(c)=\sum_{i:c\in B_i}(\mu_i-x_i)\) and \(W(x)=\operatorname*{arg\,max}_{c\in C}s_x(c)\). The elected committee contains every maximum-score candidate, with no tie-breaking, even when every score is zero. Candidates remain fixed.
The decision problem asks whether such deletions exist with \(|W(x)|<|W(0)|\).

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite lists of indivisible voters, deciding whether deleting at most a given budget strictly reduces this committee's size is \(\mathrm{NP}\)-hard.
No result settling exactly the rational-mass deletion problem was located.

Modeling choices made when packaging the task

  • Required a nonempty candidate set so the maximum-score committee is defined; singleton instances remain allowed.
  • Made support types distinct and defined L as the total binary input length.
  • Allowed empty approval ballots, consistent with the unrestricted approval-ballot domain.
  • Specified unit deletion cost and retained all maximum-score candidates, including when every score is zero.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Polynomial-time solvability

The decision problem is solvable in polynomial time in \(m,\tau,L\). It suffices to solve at most \(m\) rational linear programs.

The main point is that a successful deletion can be perturbed so that all elected candidates have identical approval profiles.

1. Approval-profile classes

For each candidate \(c\in C\), define its approval profile
\(a(c)=(a_1(c),\ldots,a_\tau(c))\in\{0,1\}^{\tau}\), where \(a_i(c)=1\) precisely when \(c\in B_i\). Thus
\(s_x(c)=a(c)^{\mathsf T}(\mu-x)\).

Partition \(C\) into equivalence classes \(E_1,\ldots,E_r\) according to equality of approval profiles. Candidates in the same class have equal scores for every deletion vector. Consequently, every winner set is a union of whole classes.

Write \(k=|W(0)|\). If \(k=1\), the answer is NO, because the nonempty finite candidate set always has at least one maximizer. If \(\beta=0\), the answer is also NO, because the only feasible deletion is \(x=0\).

Henceforth assume \(\beta>0\) and \(k>1\).

2. Perturbation lemma

Let
\(P=\{x\in\mathbb R^\tau:0\leq x_i\leq\mu_i\text{ for every }i,\ \sum_i x_i\leq\beta\}\).

Lemma. For every feasible rational vector \(x^*\in P\), there exists a feasible rational vector \(\widehat x\in P\) such that \(W(\widehat x)\) is a single approval-profile class contained in \(W(x^*)\).

Proof. First, \(P\) has nonempty interior in \(\mathbb R^\tau\). Indeed, set \(z_i=\beta\mu_i/2\). Positivity of the masses and \(0<\beta<1\) give
\(0<z_i<\mu_i\), while \(\sum_i z_i=\beta/2<\beta\).

Let \(S=W(x^*)\), and choose \(c_0\in S\). Every \(d\in C\setminus S\) satisfies
\(s_{x^*}(c_0)>s_{x^*}(d)\).
These finitely many strict inequalities persist in some neighborhood \(U\) of \(x^*\), since scores are affine, hence continuous. Every point of \(U\) therefore has all its winners in \(S\).

For sufficiently small rational \(\alpha\in(0,1)\), the rational point
\(y=(1-\alpha)x^*+\alpha z\)
belongs to \(U\) and lies in the interior of \(P\). Explicitly,
\(y_i\geq\alpha z_i>0\),
\(\mu_i-y_i\geq\alpha(\mu_i-z_i)>0\), and
\(\sum_i y_i\leq(1-\alpha)\beta+\alpha\beta/2<\beta\).
Thus an open ball around \(y\) lies inside \(P\cap U\).

For candidates with different profiles, their tie equation is
\((a(c)-a(d))^{\mathsf T}(\mu-x)=0\).
Its normal vector is nonzero, so it defines a proper affine hyperplane. We can choose a rational point in the ball avoiding all these finitely many hyperplanes, as follows.

For each nonzero normal vector \(b\), the polynomial
\(p_b(t)=\sum_{i=1}^{\tau}b_i t^{i-1}\)
is nonzero and has finitely many roots. Choose an integer \(t\) that is a root of none of these polynomials, and put
\(v=(1,t,\ldots,t^{\tau-1})\).
Then \(b^{\mathsf T}v\neq0\) for every normal vector. Along the line \(y+\lambda v\), each tie hyperplane excludes at most one value of \(\lambda\). Choose a sufficiently small rational \(\lambda\) avoiding those finitely many values.

The resulting point \(\widehat x=y+\lambda v\) is rational and belongs to \(P\cap U\). Different approval-profile classes have different scores there, so exactly one class maximizes the score. Since \(\widehat x\in U\), that class is contained in \(S\). This proves the lemma. \(\square\)

Corollary. A successful deletion exists if and only if some approval-profile class \(E_j\) with \(|E_j|<k\) can strictly outscore every candidate outside \(E_j\).

For necessity, apply the lemma to a successful deletion: the resulting winning class is contained in its winner set and therefore has size less than \(k\). Sufficiency follows because a class strictly beating every outsider is exactly the winner set.

3. Linear-programming algorithm

For each class \(E_j\) with \(|E_j|<k\), choose a representative \(c_j\). Solve the following linear program over real variables \(x_1,\ldots,x_\tau,\delta\):

  • Maximize \(\delta\).
  • Require \(0\leq x_i\leq\mu_i\) for every \(i\).
  • Require \(\sum_i x_i\leq\beta\).
  • Require \(0\leq\delta\leq1\).
  • For every \(d\in C\setminus E_j\), require

\(s_x(c_j)-s_x(d)\geq\delta\).

The last constraints are explicitly
\((a(c_j)-a(d))^{\mathsf T}(\mu-x)\geq\delta\),
so this is a rational linear program.

Return YES if one of these programs is feasible with strictly positive optimum; otherwise return NO.

The bound \(\delta\leq1\) loses no strict-winning solution: every candidate score lies between \(0\) and \(1\).

Correctness.

If a program has positive optimum, its rational optimal solution satisfies
\(s_x(c_j)>s_x(d)\) for every outsider \(d\). Candidates within \(E_j\) have the same score, so \(W(x)=E_j\) and \(|W(x)|<k\).

Conversely, suppose a successful rational deletion exists. By the corollary, some eligible class \(E_j\) strictly beats every outsider at a feasible rational deletion \(\widehat x\). Because there are finitely many outsiders and \(E_j\neq C\), the minimum gap
\(\gamma=\min_{d\in C\setminus E_j}(s_{\widehat x}(c_j)-s_{\widehat x}(d))\)
is a positive rational number. Also \(\gamma\leq1\). Therefore \((\widehat x,\gamma)\) is feasible for that class’s program, whose optimum is positive.

The algorithm is consequently equivalent to the original decision problem.

4. Polynomial bit complexity

Computing all approval profiles, their classes, the initial scores, and \(k\) takes polynomial time.

There are at most \(m\) programs. Each has \(\tau+1\) variables and \(O(\tau+m)\) constraints. Apart from the input masses and budget, its coefficients are integers from \(\{-1,0,1\}\) and rational score differences.

These score differences have polynomial encoding length. To see this explicitly, write \(\mu_i=p_i/q_i\) and let \(D=\prod_i q_i\). The bit length of \(D\) is at most the sum of the denominator bit lengths, hence \(O(L)\). Every score difference can be expressed over denominator \(D\), with numerator of absolute value at most \(D\), since scores lie in \([0,1]\).

We use the standard rational linear-programming theorem: feasibility and exact optimization are computable in polynomial time in the dimensions and binary encoding length. Polynomial-time rational linear programming was established by [Khachiyan](https://www.mathnet.ru/eng/dan42319). Its hypotheses apply here: every program has rational data, and any nonempty feasible region is compact because all variables are bounded. Thus an exact rational optimum can be computed and compared with zero.

This exact comparison handles arbitrarily small positive score gaps; no numerical tolerance or assumed minimum gap is needed.

5. Why strictness matters

Consider \(C=\{a_1,a_2,b\}\), with mass \(3/5\) approving exactly \(\{a_1,a_2\}\) and mass \(2/5\) approving exactly \(\{b\}\). Initially the committee is \(\{a_1,a_2\}\).

Let \(u\) and \(v\) be the respective deleted masses. Candidate \(b\) strictly beats the other class precisely when
\(2/5-v>3/5-u\), equivalently \(u-v>1/5\).

For \(\beta\leq1/5\), this is impossible because \(u-v\leq u+v\leq\beta\). At \(\beta=1/5\), deleting that mass from the first type only creates a three-candidate tie. For \(\beta>1/5\), choose rational \(u\) with
\(1/5<u<\min\{\beta,3/5\}\)
and set \(v=0\); then the committee becomes \(\{b\}\).

Thus weakly reaching the maximum score does not suffice. The positive-margin test captures exactly the required strict reduction.
