Theorem 3 — class: other

The continuous mirror question, as graded

Given a finite set of valuation types \(T\), masses \(\mu\in\Delta(T)\), item-type count \(t\), additive valuations \(v_a\in\mathbb{Q}_{\ge0}^{t}\), and per-capita supplies \(q\in\mathbb{Q}_{\ge0}^{t}\), find integral bundles \(b_a\in\mathbb{Z}_{\ge0}^{t}\) satisfying \(\sum_{a\in T}\mu_a b_{a,z}=q_z\) for every item type \(z\), maximizing \(\min_{a\ne a'}v_a\cdot(b_a-b_{a'})\); report whether the optimum is nonnegative, or report infeasibility.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge2\) valuation types with positive binary-rational masses \(\mu_a\), where \(\sum_{a\in T}\mu_a=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(t\) types of indivisible goods, with binary-rational per-capita supplies \(q\in\mathbb Q_{>0}^{t}\). Each type has a nonzero additive valuation \(v_a\in\mathbb Q_{\ge0}^{t}\); valuation vectors of distinct types are not positive scalar multiples. Values are used as supplied, without normalization.
An allocation assigns the same deterministic integral bundle \(b_a\in\mathbb Z_{\ge0}^{t}\) to everyone of type \(a\), and must allocate all supplies: \(\sum_{a\in T}\mu_a b_{a,z}=q_z\) for every \(z\). Its minimum envy gap is \(\gamma(b)=\min_{a\ne a'}v_a\cdot(b_a-b_{a'})\); envy-freeness allows equality and means \(\gamma(b)\ge0\).
The computational problem is to find a feasible allocation maximizing \(\gamma(b)\), report its exact value and whether it is nonnegative, or report infeasibility. Let \(L\) be the total binary input length; use \(m=t\) for the item-coordinate count, since no finite total number of items is supplied.

Is this exact optimization problem solvable in polynomial time in \(m=t\), \(\tau\), and \(L\), or is it NP-hard?

For finite societies with \(n\) agents in groups of sizes \(n_i\), an envy-free allocation with identical bundles within each group is guaranteed when each item multiplicity is divisible by \(g=\gcd_i n_i\) and exceeds a threshold of order \(tn^3/(g\delta^2)\), where \(\delta>0\) is the minimum angle between group valuation vectors. [Verified existence result](https://arxiv.org/html/2511.03810v2).
No result settling the exact rational-mass problem stated above was located in the literature search.

  • Require positive supplies for listed item types, matching the discrete convention that every listed item type is present.
  • Retain the graded question's unnormalized objective; the anchor's auxiliary normalized fractional objective does not redefine the stated optimization problem.
  • Treat the allocation as one deterministic integral bundle per supported type, with complete supply allocation and weak envy-freeness.
  • Use m=t as the item-coordinate count and L as total binary input length; the mass model has no finite total item count.

Result

The exact optimization problem is \(\mathrm{NP}\)-hard, already for \(\tau=2\), equal masses, strictly positive valuations, and supplies \(q_z=\frac12\) for every coordinate. Every instance in the reduction is feasible.

Consequently, a polynomial-time algorithm in \(m=t\), \(\tau\), and \(L\) would imply \(\mathrm{P}=\mathrm{NP}\). In fact, deciding whether a feasible envy-free allocation exists is \(\mathrm{NP}\)-complete.

Reduction from PARTITION

We use the standard \(\mathrm{NP}\)-complete problem PARTITION: given positive binary-encoded integers \(a_1,\ldots,a_k\), decide whether some subset has sum \(\frac12\sum_{z=1}^k a_z\). Its classical hardness follows from [Karp’s reduction theorem](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

We may restrict to \(k\ge2\): every instance with one positive integer is a NO-instance and can be replaced by the fixed NO-instance \((1,2)\).

Construct a society with \(t=m=k\) item coordinates and two supported types, with

\(\mu_1=\mu_2=\frac12,\qquad q_z=\frac12\quad\text{for every }z.\)

Set the supplied valuation vectors to

\(v_1=(a_1,a_2,\ldots,a_k),\qquad v_2=(a_1+\frac12,a_2,\ldots,a_k).\)

All entries are positive binary rationals. The vectors are not positive scalar multiples: their equal, positive second coordinates would force the scalar to equal \(1\), contradicting their unequal first coordinates.

The construction copies the input integers and changes one coefficient by \(\frac12\), so its encoding length and construction time are polynomial in the PARTITION input length.

Feasible allocations and their envy gaps

For each coordinate, the supply equation becomes

\(\frac12 b_{1,z}+\frac12 b_{2,z}=\frac12,\)

hence \(b_{1,z}+b_{2,z}=1\). Because both entries are nonnegative integers, every feasible allocation has the form

\(b_1=x,\qquad b_2=\mathbf 1-x,\qquad x\in\{0,1\}^k.\)

Conversely, every such \(x\) gives a feasible allocation. Thus feasibility is guaranteed.

Define the integer

\(D(x)=\sum_{z=1}^k a_z(2x_z-1)=2\sum_{z:x_z=1}a_z-\sum_{z=1}^k a_z.\)

There are exactly two ordered comparisons between distinct types. Their gaps are

\(v_1\cdot(b_1-b_2)=D(x)\)

and

\(v_2\cdot(b_2-b_1)=-D(x)+\frac12(1-2x_1).\)

Therefore

\(\gamma(x)=\min\left\{D(x),-D(x)+\frac12(1-2x_1)\right\}.\)

Envy-freeness implies an equal partition

If \(\gamma(x)\ge0\), then both comparison gaps are nonnegative, giving

\(0\le D(x)\le\frac12(1-2x_1)\le\frac12.\)

Since \(D(x)\) is an integer, necessarily \(D(x)=0\). Its defining equation shows that the coordinates assigned to type \(1\) form an equal partition.

An equal partition implies envy-freeness

Suppose an equal partition exists. Its complement is also an equal partition, so choose its orientation so that coordinate \(1\) lies outside the subset assigned to type \(1\). Then \(D(x)=0\) and \(x_1=0\). The two comparison gaps are \(0\) and \(\frac12\), hence \(\gamma(x)=0\).

We have proved the equivalence

\(\text{PARTITION is YES}\quad\Longleftrightarrow\quad\max_b\gamma(b)\ge0.\)

Moreover, the optimum is exactly \(0\) in YES-instances. Indeed, if \(D(x)=0\), the first gap is \(0\). If \(D(x)\ne0\), integrality gives two cases:

  • If \(D(x)\le-1\), then \(\gamma(x)\le-1\).
  • If \(D(x)\ge1\), then \(\gamma(x)\le-D(x)+\frac12\le-\frac12\).

Thus NO-instances have optimum at most \(-\frac12\). An exact optimizer, or merely its requested nonnegativity report, therefore decides PARTITION.

Certificate size and decision complexity

For any instance of the stated problem, positivity of the masses and nonnegativity of bundles imply

\(0\le b_{a,z}\le\frac{q_z}{\mu_a}.\)

Each bound has polynomial binary length in \(L\). Consequently, any feasible allocation has a polynomial-size encoding, and the feasible set is finite.

Given an allocation, one can verify integrality, nonnegativity, all supply equalities, and all envy inequalities using polynomial-time exact rational arithmetic. Hence the decision problem “does a feasible allocation with \(\gamma(b)\ge0\) exist?” belongs to \(\mathrm{NP}\). Together with the reduction, this establishes its \(\mathrm{NP}\)-completeness and the optimization problem’s \(\mathrm{NP}\)-hardness.

Relation to the existence theorem

The reduction corresponds to a finite society with two agents and one copy of each item coordinate. The cited [existence theorem](https://arxiv.org/html/2511.03810v2) guarantees envy-freeness under sufficiently large item multiplicities. Our construction imposes no such lower bound, so the hardness result is compatible with that theorem.
