The continuous mirror question, as graded

Given a finite set of destinations \(H\), a listed set of strict ranking types \(T\) with rational masses \(\mu_t\), and rational per-capita capacities \(q_h\), let \(f(t)\) be type \(t\)'s first choice, \(F=\{f(t):t\in T\}\), and \(d_h=\sum_{t:f(t)=h}\mu_t\). In the regime \(q_h\le d_h\) for every \(h\in F\), \(H\setminus F\ne\varnothing\), and \(\sum_{h\in H}q_h\ge1\), find rational flows \(x_{t,h}\ge0\) with \(\sum_h x_{t,h}=\mu_t\), \(\sum_t x_{t,h}\le q_h\), \(\sum_{t:f(t)=h}x_{t,h}=q_h\) for \(h\in F\), and \(x_{t,h}=0\) whenever \(h\in F\) and \(f(t)\ne h\). Among feasible flows, maximize \(\sum_t x_{t,s(t)}\), where \(s(t)\) is the most preferred destination in \(H\setminus F\); among ties, maximize \(\sum_{t,h}x_{t,h}(m+1-\operatorname{rank}_t(h))\). Each unit of mass receives one whole destination; the flow allows a type's population to split across destinations.

A feasible allocation consists of rational flows \(x_{t,h}\ge0\) satisfying \(\sum_{h\in H}x_{t,h}=\mu_t\), \(\sum_{t\in T}x_{t,h}\le q_h\), \(\sum_{t:f(t)=h}x_{t,h}=q_h\) for \(h\in F\), and \(x_{t,h}=0\) if \(h\in F\) and \(f(t)\ne h\). Result

Computing a rational lexicographically optimal feasible allocation is polynomial-time solvable in \(m,\tau,L\).

The proof uses two exact rational linear programs. The permitted splitting of each type’s population makes the stated flow constraints the full feasible-allocation description.

1. Feasibility under the stated assumptions

Write \(N=H\setminus F\), \(Q_F=\sum_{h\in F}q_h\), and \(C=\sum_{h\in N}q_h\). Because the first-choice groups partition the support, \(\sum_{h\in F}d_h=1\). Hence \(Q_F\le 1\), using \(q_h\le d_h\).

For every type \(t\), define its allocation to its first choice by
\(a_t=\mu_t q_{f(t)}/d_{f(t)}\).
The denominator is positive because \(d_{f(t)}\ge\mu_t>0\). Moreover, \(0\le a_t\le\mu_t\), and for every \(h\in F\),

\(\sum_{t:f(t)=h}a_t=(q_h/d_h)\sum_{t:f(t)=h}\mu_t=q_h.\)

Define \(r_t=\mu_t-a_t\). The total remaining mass is
\(R=\sum_t r_t=1-Q_F\).
The assumption on total capacity gives
\(C=\sum_{h\in H}q_h-Q_F\ge 1-Q_F=R\).

If \(C>0\), set \(x_{t,f(t)}=a_t\), set \(x_{t,h}=0\) for \(h\in F\setminus\{f(t)\}\), and set \(x_{t,h}=r_tq_h/C\) for \(h\in N\). Then each type’s row sums to \(\mu_t\), and each destination \(h\in N\) receives
\(\sum_t x_{t,h}=Rq_h/C\le q_h\).
Every first-choice destination receives exactly its required capacity from its supporters.

If \(C=0\), then \(0\le R\le C=0\). Since every \(r_t\) is nonnegative, every \(r_t=0\). Assigning only the amounts \(a_t\) is therefore feasible.

All these quantities are rational. Thus the required rational feasible set is nonempty.

2. The two linear programs

Let \(P\subseteq\mathbb R^{\tau m}\) be the polyhedron defined by the stated constraints, allowing real flows temporarily. Explicitly, its constraints are:

  • \(x_{t,h}\ge0\) for every \(t,h\);
  • \(\sum_{h\in H}x_{t,h}=\mu_t\) for every \(t\);
  • \(\sum_{t\in T}x_{t,h}\le q_h\) for every \(h\);
  • \(\sum_{t:f(t)=h}x_{t,h}=q_h\) for every \(h\in F\);
  • \(x_{t,h}=0\) whenever \(h\in F\) and \(f(t)\ne h\).

The construction above proves \(P\ne\varnothing\). Also, nonnegativity and the row equations imply \(0\le x_{t,h}\le\mu_t\). Consequently, \(P\) is closed and bounded, hence compact.

Define the two linear objectives by
\(A(x)=\sum_{t\in T}x_{t,s(t)}\) and
\(B(x)=\sum_{t\in T,h\in H}(m+1-\operatorname{rank}_t(h))x_{t,h}\).
The destinations \(s(t)\) are well-defined because \(N\ne\varnothing\) and each ranking is strict.

First solve the linear program maximizing \(A(x)\) over \(P\), and compute its exact optimal value \(\alpha\).

Next solve the linear program maximizing \(B(x)\) subject to \(x\in P\) and the additional equality \(A(x)=\alpha\).

The second feasible set is nonempty because the first maximum is attained. It is also compact. Thus both maxima exist.

Let \(x^\star\) be an optimum of the second program. For any \(y\in P\), the first program gives \(A(y)\le\alpha=A(x^\star)\). If equality holds, then \(y\) is feasible for the second program, so \(B(y)\le B(x^\star)\). These two statements are exactly lexicographic optimality.

3. Exactness and polynomial bit complexity

We use the standard rational linear-programming theorem: an explicitly represented linear program with binary rational data can be solved in polynomial bit time, returning an exact rational optimum when the feasible set is nonempty and the objective has an attained finite maximum. This is the classical polynomial-time solvability theorem for rational linear programming. [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/eng/zvmmf5239)

Here its hypotheses hold for both programs by the preceding compactness and feasibility arguments. Their encoding sizes are polynomial:

  • Initial formulation. There are \(n=\tau m\) variables and \(O(\tau m+\tau+m)\) constraints. Constraint coefficients belong to \(\{-1,0,1\}\), after writing equalities as inequalities if necessary. Right-hand sides are input rationals. The primary objective has coefficients in \(\{0,1\}\); secondary coefficients are integers between \(1\) and \(m\). Computing \(F\), all \(s(t)\), and all rank coefficients takes polynomial time by scanning the supplied rankings.
  • The exact primary optimum has polynomial bit length. A linear functional on a nonempty compact polyhedron attains its maximum at a vertex. At a vertex of \(P\), the active constraint normals span \(\mathbb R^n\): otherwise a nonzero direction orthogonal to them would permit sufficiently small feasible perturbations in both directions, contradicting extremality. Select \(n\) independent active constraints. They give a nonsingular rational linear system determining the vertex.

Clearing denominators row by row produces integer coefficients of bit length \(O(L+1)\). Hadamard’s determinant bound and Cramer’s rule therefore bound each vertex coordinate’s numerator and denominator bit length by \(O(n(L+\log(n+1)+1))\). Summing the \(\tau\) coordinates appearing in \(A\) preserves polynomial bit length: a common denominator can be chosen as the product of their denominators. Thus \(\alpha\) has polynomial bit length.

  • Second formulation and output. The equality \(A(x)=\alpha\) adds one row with polynomial encoding length. The second program therefore also has polynomial input size, and exact rational linear programming returns \(x^\star\) in polynomial bit time. Its rational output has polynomial total length.

Although we optimized over real polyhedra, both programs have rational optimal vertices. Hence their optima are also attained among the rational allocations required by the question.

4. Relation to individual assignments and the cited result

The flow interpretation respects the requirement that each individual receives one whole destination: for each type, partition its population into groups of masses \(x^\star_{t,h}\), and assign each group to its corresponding destination. The task explicitly permits this population splitting.

No expansion into a potentially enormous number of individual agents is needed. The algorithm operates directly on the \(\tau\) supported types and the binary rational data.

The cited finite-agent theorem establishes a cubic-time Pareto-efficient minimal-envy matching algorithm. The secondary score objective here is handled directly by the second linear program; the present proof does not require an extension of that matching algorithm. [Kondratev–Nesterov, Theorem 5](https://arxiv.org/pdf/1902.08003v1)
