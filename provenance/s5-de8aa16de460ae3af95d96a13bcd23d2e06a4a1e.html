Proposition 1 — class: algorithmic

The continuous mirror question, as graded

Given a finite support \(U\) of candidate types \(u=(a_u,p_u)\), rational masses \(\mu_u>0\) summing to \(1\), a committee mass \(\kappa\), and normalized lower quotas \(q_i\), choose \(x_u\in[0,\mu_u]\) with \(\sum_u x_u=\kappa\). Let \(z_i=\sum_u a_{u,i}x_u\). Return an allocation satisfying both conditions: there are no types \(u,v\) with \(p_u>p_v\), \(x_u<\mu_u\), and \(x_v>0\) such that \(z_i>q_i\) for every attribute \(i\) held by \(v\) but not \(u\); and there is no feasible exchange of any amount \(0<\epsilon\le\min(\mu_u-x_u,x_v)\) from selected type \(v\) to type \(u\) whose resulting attribute vector strictly dominates \(z\). Extend domination to real-valued counts by requiring each already-met quota to remain met, each unmet quota either to be met or to have its shortfall weakly reduced, with at least one strict improvement.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(U\) of \(\tau\) candidate types with positive binary-rational masses \(\mu_u\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. There are \(m\) attributes; each type is \(u=(a_u,p_u)\), with \(a_u\in\{0,1\}^m\) and rational priority \(p_u\). Larger priorities are preferred; equal priorities are tied.
The remaining inputs are a rational committee mass \(0<\kappa\leq1\) and nonnegative rational lower quotas \(q_i\), measured in society-mass units. Quotas are soft and need not be attainable. Let \(L\) be the total binary input length.
An allocation has \(0\leq x_u\leq\mu_u\), \(\sum_{u\in U}x_u=\kappa\), and attribute masses \(z_i=\sum_{u\in U}a_{u,i}x_u\). Write \(d_i(z)=\max\{q_i-z_i,0\}\). A vector \(z'\) strictly dominates \(z\) when \(d_i(z')\leq d_i(z)\) for every attribute and the inequality is strict for at least one attribute.
Find an allocation satisfying both conditions:

  • Justified envy-freeness: there are no distinct types \(u,v\) with \(p_u>p_v\), \(x_u<\mu_u\), \(x_v>0\), and \(z_i>q_i\) for every attribute with \(a_{v,i}=1\) and \(a_{u,i}=0\). This last condition holds vacuously when there are no such attributes.
  • Local type optimality: there are no distinct types \(u,v\) and real amount \(0<\epsilon\leq\min\{\mu_u-x_u,x_v\}\) such that \(z+\epsilon(a_u-a_v)\) strictly dominates \(z\); the exchange increases \(x_u\) and decreases \(x_v\) by \(\epsilon\).

Can an allocation satisfying both conditions be computed in time polynomial in \(m,\tau,L\), or is this search problem NP-hard?

For finite candidates, a polynomial-time algorithm returns a committee satisfying both conditions under single-candidate swaps; the revised result states a bound of \(O(|C|^3)\). [Aziz, revised manuscript](https://www.cse.unsw.edu.au/~haziz/diverse-commt.pdf)

Polynomial-time solvability

The search problem is polynomial-time solvable. Minimize total quota shortfall, then maximize total priority among allocations attaining that minimum. Both stages are rational linear programs.

The argument below applies to the exact continuous formulation in the question, including unattainable quotas and tied priorities.

1. Two-stage optimization

Let the feasible allocation set be

\(P=\{x\in\mathbb{R}^{U}:0\leq x_u\leq\mu_u\text{ for every }u,\ \sum_{u\in U}x_u=\kappa\}\).

This set is nonempty: \(x_u=\kappa\mu_u\) is feasible because \(0<\kappa\leq1\) and \(\sum_u\mu_u=1\). It is also compact.

Define total shortfall and total priority by

\(F(x)=\sum_{i=1}^{m}\max\{q_i-\sum_{u\in U}a_{u,i}x_u,0\}\),

\(S(x)=\sum_{u\in U}p_ux_u\).

Introduce auxiliary variables \(s_i\). The first linear program minimizes \(\sum_{i=1}^{m}s_i\), subject to:

  • \(x\in P\);
  • \(0\leq s_i\leq q_i\) for every attribute \(i\);
  • \(s_i\geq q_i-\sum_{u\in U}a_{u,i}x_u\) for every attribute \(i\).

For any feasible allocation \(x\), its actual deficits satisfy these constraints: attribute masses are nonnegative, so \(0\leq d_i(z(x))\leq q_i\). Conversely, every feasible auxiliary vector satisfies \(s_i\geq d_i(z(x))\). Consequently, the first optimum is exactly

\(D^*=\min_{x\in P}F(x)\).

The second linear program maximizes \(S(x)\), subject to all first-stage constraints and the additional equality

\(\sum_{i=1}^{m}s_i=D^*\).

It is feasible because the first program attains its optimum. Both feasible regions are compact, so both programs attain their optima.

Return the allocation \(x^*\) from any second-stage optimum.

For every second-stage feasible pair \((x,s)\),

\(D^*\leq F(x)\leq\sum_i s_i=D^*\).

Thus its allocation satisfies \(F(x)=D^*\). Conversely, any allocation with \(F(x)=D^*\) extends to a second-stage feasible pair by taking its actual deficits as \(s\). Therefore,

\(F(x^*)=D^*\), and \(S(x^*)=\max\{S(x):x\in P,\ F(x)=D^*\}\).

2. Local type optimality

Suppose, for contradiction, that distinct types \(u,v\) and an admissible amount \(\epsilon>0\) yield a strictly dominating exchange.

Define \(x'\) by increasing \(x_u^*\) by \(\epsilon\), decreasing \(x_v^*\) by \(\epsilon\), and leaving all other coordinates unchanged. The bound

\(\epsilon\leq\min\{\mu_u-x_u^*,x_v^*\}\)

ensures \(x'\in P\), and its attribute vector is

\(z(x')=z(x^*)+\epsilon(a_u-a_v)\).

Strict domination means that every deficit weakly decreases and at least one strictly decreases. Summing the finitely many deficits gives

\(F(x')<F(x^*)=D^*\).

This contradicts the definition of \(D^*\). Hence \(x^*\) satisfies local type optimality. Indeed, it admits no strictly dominating feasible allocation, even one involving multiple types.

3. Justified envy-freeness

Write \(z=z(x^*)\). Suppose, for contradiction, that distinct types \(u,v\) witness justified envy:

\(p_u>p_v,\qquad x_u^*<\mu_u,\qquad x_v^*>0\),

and \(z_i>q_i\) for every attribute in the loss set

\(B=\{i:a_{v,i}=1,\ a_{u,i}=0\}\).

Choose

\(\epsilon=\frac12\min\bigl(\{\mu_u-x_u^*,x_v^*\}\cup\{z_i-q_i:i\in B\}\bigr)\).

Every member of this finite set is positive, and the set contains the two capacity terms even when \(B\) is empty. Thus \(\epsilon>0\), and the exchange produces a feasible allocation \(x'\).

We check each attribute:

  • If \(i\in B\), then \(z_i'=z_i-\epsilon>q_i\). Its deficit remains zero.
  • If \(a_{u,i}=1\) and \(a_{v,i}=0\), then \(z_i'=z_i+\epsilon\). Its deficit cannot increase.
  • If \(a_{u,i}=a_{v,i}\), then \(z_i'=z_i\). Its deficit is unchanged.

Therefore \(F(x')\leq F(x^*)=D^*\). Since \(x'\) is feasible and \(D^*\) is the global minimum, equality must hold:

\(F(x')=D^*\).

But the priority change is

\(S(x')-S(x^*)=\epsilon(p_u-p_v)>0\).

This contradicts second-stage optimality. Hence \(x^*\) is justified envy-free.

The empty loss set is covered by the same argument, and tied priorities require no additional treatment because justified envy requires a strict priority inequality.

4. Polynomial bit complexity

We use the standard rational linear-programming theorem: an explicitly represented rational linear program can be solved exactly in time polynomial in its binary encoding length, returning a rational optimum when one exists. See [MIT’s linear-programming algorithm notes](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html).

Each program has \(\tau+m\) variables and \(O(\tau+m)\) constraints, with \(O(m\tau)\) attribute coefficients. The first program therefore has encoding length polynomial in \(m,\tau,L\).

The exact optimum \(D^*\) also has polynomial binary length. To see this, let \(n=\tau+m\). Clear denominators in each constraint row; the resulting integer coefficients have polynomial bit length, say at most \(B\). An optimal vertex is determined by \(n\) independent active constraints. By Cramer’s rule, its coordinates are ratios of determinants whose absolute values are at most \(n!2^{nB}\). Their binary lengths, and the binary length of their objective sum \(D^*\), are therefore polynomial in \(m,\tau,L\).

Adding the equality \(\sum_i s_i=D^*\) consequently preserves polynomial encoding length. Exact rational LP algorithms solve both stages in polynomial time and return a rational allocation of polynomial encoding length.

This construction works directly with the listed support; it requires no expansion into individual candidates. It settles the continuous problem independently of the finite-candidate swap algorithm in [Aziz’s revised manuscript](https://www.cse.unsw.edu.au/~haziz/diverse-commt.pdf).
