The continuous mirror question, as graded

Given a finite support \(K\) of complete approval types with rational masses \(\mu_\theta\), where \(\sum_{\theta\in K}\mu_\theta=1\), and \(T\) rounds with explicit menus \(\mathcal C_r\subseteq 2^K\), choose \(S_r\in\mathcal C_r\) to maximize \(\exp\!\left(\sum_{\theta\in K}\mu_\theta\log(1+\sum_{r=1}^T \mathbf 1[\theta\in S_r])\right)\). Is it NP-hard to approximate this optimum within a factor of \(1.092\), even when \(\mu_\theta=1/|K|\) for every type and every allowed option covers mass \(1/T\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(K\) of \(\tau=|K|\) distinct complete approval types, each with positive binary rational mass \(\mu_\theta\), with \(\sum_{\theta\in K}\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(T\in\mathbb Z_{>0}\) rounds, each with an explicitly listed nonempty menu \(\mathcal C_r\subseteq 2^K\). A type's complete approval profile specifies its binary approval of every round-labelled option; option \(S\) is approved exactly by the types in \(S\).
Let \(m=\sum_{r=1}^T|\mathcal C_r|\), and let \(L\) be the total binary input length, including masses and option incidences. State running times in \(m,\tau,T,L\).
A feasible outcome selects one whole option \(S_r\in\mathcal C_r\) per round; the same subset may be selected in multiple rounds when available. Its welfare is \(W(S)=\exp\bigl(\sum_{\theta\in K}\mu_\theta\log(1+\sum_{r=1}^T\mathbf 1\{\theta\in S_r\})\bigr)\), with natural logarithms. Write \(\mathrm{OPT}=\max_S W(S)\).
Restrict to instances with \(\mu_\theta=1/\tau\) for every type and \(\sum_{\theta\in A}\mu_\theta=1/T\) for every allowed option \(A\).

Is obtaining a feasible outcome with \(W(S)\ge\mathrm{OPT}/1.092\) polynomial-time solvable, or is this approximation problem NP-hard under these restrictions?

Discrete fair coverage with valuations equal to one plus coverage count is NP-hard to approximate within \(1.092\), even with explicit identical menus whose options all have size \(n/T\); it also admits an \(18+o(1)\)-approximation when weight maximization admits an FPTAS. Result

The approximation problem is NP-hard, even with identical explicit menus in every round. The requirement that support types have distinct complete approval profiles needs an additional construction; simply treating each agent in the cited reduction as a type does not establish it.

1. The known hardness gap

We use the following established gap from the proof of Theorem 8 in [Barman, Krishna, Narahari, and Sadhukhan](https://arxiv.org/pdf/2207.01970v1).

The source instances have an explicit universe \(U\) of \(n\) agents, an integer \(T\), and an explicit nonempty family \(\mathcal F\). Every member of \(\mathcal F\) has size \(n/T\), and every round has menu \(\mathcal F\). For an outcome \(F=(F_1,\ldots,F_T)\), define
\[ \]
\(G(F)=\left(\prod_{i\in U}\left(1+\sum_{r=1}^{T}\mathbf 1\{i\in F_r\}\right)\right)^{1/n}.\)

The cited proof establishes that distinguishing the following cases is NP-hard:

  • YES: \(\max_F G(F)\ge 2\).
  • NO: every feasible \(F\) satisfies \(G(F)\le 1.83\).

We may restrict to \(T\ge 2\): when \(T=1\), every allowed set is the entire universe, so every such instance is a YES instance. Also \(T\le n\), since \(n/T\) is a positive integer.

The remainder is a reduction from this gap that enforces distinct support types.

2. Construction of the society

Set \(q=10000T\) and \(N=qn\). Introduce the labelled elements

\(V=U\times\{1,\ldots,q\}.\)

For \(A\in\mathcal F\), let its lift be

\(\widehat A=A\times\{1,\ldots,q\}.\)

Choose any \(A_0\in\mathcal F\), put \(B=\widehat A_0\), and fix \(x_0\in B\) and \(y_0\in V\setminus B\). These choices exist because \(T\ge2\) and \(|B|=N/T\).

In every round, use the same menu consisting of all lifted sets and the following additional sets:

\(D_x=(B\setminus\{x\})\cup\{y_0\}\quad\text{for every }x\in B,\)

\(E_y=(B\setminus\{x_0\})\cup\{y\}\quad\text{for every }y\in V\setminus B.\)

Remove duplicate options. Each element of \(V\) defines a complete approval profile by membership in these round-labelled options.

Distinctness of the profiles

Every two elements have different profiles:

  • If \(x,x'\in B\) are distinct, then \(D_x\) excludes \(x\) and includes \(x'\).
  • If \(y,y'\in V\setminus B\) are distinct, then \(E_y\) includes \(y\) and excludes \(y'\).
  • If one element belongs to \(B\) and the other does not, the option \(B\) distinguishes them.

All these options remain available after duplicate removal. Thus the profiles form a support \(K\) of exactly \(\tau=N\) distinct types.

Assign every type mass \(\mu_\theta=1/N\), encoded as a binary rational.

Option masses

Every lifted option has size \(q(n/T)=N/T\). Every additional option replaces one member of \(B\) with one nonmember, so also has size \(N/T\). Consequently, every allowed option \(S\) satisfies

\(\sum_{\theta\in S}\mu_\theta=|S|/N=1/T.\)

The construction therefore satisfies all the required restrictions.

3. Bounding the benefit of the additional options

With uniform masses, the constructed welfare is

\(W(S)=\left(\prod_{v\in V}(1+c_v(S))\right)^{1/N},\)

where \(c_v(S)\) is the number of selected options containing \(v\).

If an outcome uses only lifted options, all \(q\) copies of each original agent receive its original coverage count. Hence lifting preserves welfare exactly:

\(W(\widehat F_1,\ldots,\widehat F_T)=G(F).\)

Now consider an arbitrary constructed outcome \(S\). Replace each selected additional option by \(B\), leaving lifted selections unchanged. Call the resulting outcome \(S^0\). It projects to a feasible source outcome \(F\), and therefore \(W(S^0)=G(F)\).

We bound the change when transforming \(S^0\) back into \(S\), one round at a time. Each replacement changes \(B\) into \(B\setminus\{x\}\cup\{y\}\), with \(x\in B\) and \(y\notin B\). Immediately before this replacement, write \(v_x=1+c_x\) and \(v_y=1+c_y\). Since that round currently selects \(B\), we have \(v_x\ge2\), while \(v_y\ge1\).

The change in log welfare is exactly

\(\Delta\log W=\frac1N\left(\log(v_x-1)-\log v_x+\log(v_y+1)-\log v_y\right).\)

The first difference is negative, and \((v_y+1)/v_y\le2\). Thus

\(\Delta\log W\le\frac{\log2}{N}.\)

There are at most \(T\) replacements. It follows that

\(W(S)\le G(F)\exp\left(\frac{T\log2}{N}\right)\le G(F)e^{1/10000},\)

because \(N=10000Tn\) and \(\log2<1\).

4. The hardness gap survives

In a source YES instance, lifting a source outcome of welfare at least \(2\) gives a constructed outcome of the same welfare. Thus the constructed optimum is at least \(2\).

In a source NO instance, the preceding bound applies to every constructed outcome, giving

\(W(S)\le1.83e^{1/10000}\le\frac{18300}{9999}.\)

For the last inequality, the exponential series gives \(e^z\le\sum_{j=0}^{\infty}z^j=1/(1-z)\) for \(0\le z<1\).

Choose the rational threshold \(h=1831/1000\). The relevant strict inequalities are

\(\frac{18300}{9999}<\frac{1831}{1000}<\frac{500}{273}=\frac{2}{1.092}.\)

They follow by cross multiplication:

\(18300000<18308169,\qquad 499863<500000.\)

Therefore, a hypothetical algorithm guaranteeing \(W(S)\ge\mathrm{OPT}/1.092\) would output:

  • welfare strictly greater than \(h\) on constructed YES instances;
  • welfare strictly less than \(h\) on constructed NO instances.

It would distinguish the NP-hard source gap.

5. Encoding, running time, and exact comparison

Let \(p=|\mathcal F|\). The constructed instance has

\(\tau=10000Tn,\qquad m\le T(p+\tau).\)

Because \(T\le n\), these quantities are polynomial in the explicit source input length. Dense option incidences and complete profiles can be constructed, with duplicates removed using a binary trie, in \(O(m\tau+\tau\log\tau)\) bit operations. The resulting input length \(L\) is polynomial in the source input length.

The separating threshold requires no numerical evaluation of logarithms. For a returned outcome, compute the integer

\(P=\prod_{\theta\in K}(1+c_\theta).\)

Then

\(W(S)>h\quad\Longleftrightarrow\quad1000^\tau P>1831^\tau.\)

The integers have \(O(\tau\log(T+1))\) bits. Reading the instance, computing counts, and performing this comparison with ordinary integer arithmetic takes

\(O\left(L+T\tau\log(T+1)+\tau^2\log^2(T+1)\right)\)

bit operations. Thus an approximation algorithm polynomial in \(m,\tau,T,L\), together with this reduction and comparison, would solve the source gap in polynomial time.

Consequently, obtaining the specified feasible approximation is NP-hard under all the stated restrictions, and is not polynomial-time solvable unless \(\mathrm P=\mathrm{NP}\).
