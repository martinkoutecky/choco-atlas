The continuous mirror question, as graded

Given candidates \(C\), a rational distribution \(\mu\) over partial-order types \(O\) on \(C\), each with at most four undetermined pairs, and target \(c^\star\), decide whether there are masses \(x_{O,V}\ge0\) for linear extensions \(V\supseteq O\) such that \(\sum_{V\supseteq O}x_{O,V}=\mu_O\) for every \(O\), and \(\sum_{O,V}x_{O,V}s_{\mathrm{Borda}}(V,c^\star)\ge\sum_{O,V}x_{O,V}s_{\mathrm{Borda}}(V,a)\) for every \(a\ne c^\star\).

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal L(O)\) be the linear orders extending a partial order \(O\) on candidates \(C\). The input gives rational masses \(\mu_O\) for finitely many \(O\), each with at most four undetermined pairs, and a candidate \(c^\star\).

A completion chooses \(x_{O,V}\ge 0\) for every \(V\in\mathcal L(O)\), with \(\sum_{V\in\mathcal L(O)}x_{O,V}=\mu_O\). It makes \(c^\star\) a Borda co-winner when \(\sum_{O,V}x_{O,V}s_{\mathrm{Borda}}(V,c^\star)\ge\sum_{O,V}x_{O,V}s_{\mathrm{Borda}}(V,a)\) for every \(a\ne c^\star\).

Target. Is this Mass-Borda Possible Co-Winner problem solvable in polynomial time, or is it NP-hard?

Nearest known results. The discrete Borda Possible Winner and Possible Co-Winner problems are NP-complete even when every partial order has at most four undetermined pairs. No verified result is listed here for the exact rational-mass formulation above.

Result

Mass-Borda Possible Co-Winner is solvable in polynomial time. The bound on undetermined pairs gives at most \(16\) linear extensions per input partial order. Since masses may be split, the problem is exactly a rational linear-programming feasibility problem of polynomial size.

1. Enumerating the linear extensions

Let \(m=|C|\), and let \(q\) be the number of input partial orders. An undetermined pair of a partial order \(O\) is an unordered pair of distinct candidates that are incomparable in \(O\). Write \(k_O\) for their number; by hypothesis, \(k_O\leq 4\).

Lemma. The set \(\mathcal L(O)\) has at most \(2^{k_O}\leq 16\) elements and can be enumerated in polynomial time.

Proof. Every linear extension specifies one of the two orientations of each undetermined pair. These orientations uniquely determine the extension: all other pairwise comparisons are already fixed by \(O\). Thus the map from extensions to orientation choices is injective, proving the bound.

For enumeration, first compute the transitive closure of the given partial-order representation, so that every determined comparison is available. For each of the \(2^{k_O}\) orientation choices, form the directed graph containing the comparisons of \(O\) and the chosen orientations. This graph contains exactly one directed edge for each unordered pair of distinct candidates.

If the graph contains a directed cycle, no linear order can respect all its edges, so discard that choice. Otherwise, a topological ordering exists. It is unique because the edge between any two candidates fixes their relative order. This ordering extends \(O\).

Conversely, any linear extension supplies an orientation choice whose graph is acyclic, and the procedure recovers that extension. Transitive closure, cycle detection, and topological sorting all take polynomial time; there are at most \(16\) choices. This proves the lemma. ∎

2. The linear program

For each enumerated extension \(V\in\mathcal L(O)\), introduce a real variable \(x_{O,V}\). Let \(\operatorname{pos}_V(a)\) denote the position of candidate \(a\), with the first position numbered \(1\). Define its Borda score by \(s(V,a)=m-\operatorname{pos}_V(a)\).

Construct the following feasibility system:

  • Nonnegativity: \(x_{O,V}\geq 0\) for every \(O\) and \(V\in\mathcal L(O)\).
  • Mass conservation: \(\sum_{V\in\mathcal L(O)}x_{O,V}=\mu_O\) for every \(O\).
  • Co-winner inequalities: for every \(a\in C\setminus\{c^\star\}\),

\(\displaystyle \sum_O\sum_{V\in\mathcal L(O)}\bigl(s(V,c^\star)-s(V,a)\bigr)x_{O,V}\geq 0.\)

Equivalence. A completion making \(c^\star\) a co-winner assigns nonnegative masses satisfying mass conservation. Subtracting each rival’s total score from the total score of \(c^\star\) gives precisely the corresponding co-winner inequality. Hence that completion is feasible for the system.

Conversely, a feasible solution assigns admissible masses to every linear extension and conserves each input mass. Each co-winner inequality says that the total score of \(c^\star\) is at least the corresponding rival’s total score. Thus the feasible solution is a successful completion.

This equivalence is exact; it does not use any rounding or approximation.

3. Encoding size and polynomial-time feasibility

The number of variables is \(N=\sum_O|\mathcal L(O)|\leq 16q\). There are \(N\) nonnegativity inequalities, \(q\) mass equalities, and \(m-1\) co-winner inequalities. Each equality can be replaced by two inequalities.

Every coefficient on the left is an integer of absolute value at most \(\max\{1,m-1\}\), requiring \(O(\log(m+1))\) bits. The right-hand sides are zero or input rational masses, up to sign. Consequently, the complete rational system has encoding length polynomial in the original input length.

We now apply the standard rational linear-programming theorem: feasibility of an explicitly given system of rational linear inequalities can be decided in time polynomial in its total binary encoding length. This is exact feasibility, including systems with equality constraints; see [Trevisan’s linear-programming notes](https://theory.stanford.edu/~trevisan/books/cs261.pdf).

The hypotheses hold here: the system is explicit, every coefficient is rational, and its encoding length is polynomial. Enumerating the extensions, constructing the system, and deciding feasibility therefore all take polynomial time.

4. Why the discrete hardness result does not transfer

A discrete voter must choose a single extension. Here, the mass associated with a partial order may be distributed among several extensions. Consequently, the displayed system has continuous variables and requires no integrality constraints. The cited discrete hardness result concerns a different feasible set and does not establish hardness for this formulation.
