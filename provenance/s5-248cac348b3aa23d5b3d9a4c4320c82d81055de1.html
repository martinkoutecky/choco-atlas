The continuous mirror question, as graded

Given \(d\) weighted thresholds, \(\tau\) voter types with rational masses \(\mu_t>0\) summing to \(1\), weight vectors \(w_t\), and quotas \(q_r\), decide whether every pair of distinct types is comparable under the following relation: \(a\succeq_\infty b\) if, for every \(0<\delta\le\min(\mu_a,\mu_b)\) and every feasible background \(x\) with \(x_a,x_b\le\mu_{a,b}-\delta\), victory after adding \(\delta\) of type \(b\) implies victory after adding \(\delta\) of type \(a\). Here \(0\le x_t\le\mu_t\), and \(x\) wins exactly when \(\sum_t w_{rt}x_t\ge q_r\) for every threshold \(r\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) voter types with positive binary rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m:=d\ge1\) supplied thresholds, with binary rational weights \(w_{rt}\ge0\) and quotas \(0<q_r\le\sum_{t=1}^{\tau}w_{rt}\mu_t\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A coalition is a real vector \(x\) satisfying \(0\le x_t\le\mu_t\). It wins exactly when \(\sum_{t=1}^{\tau}w_{rt}x_t\ge q_r\) for every \(r\); equality meets a quota.
For distinct types \(a,b\), define \(a\succeq_\infty b\) when, for every real \(0<\delta\le\min(\mu_a,\mu_b)\) and every coalition \(x\) satisfying \(x_a\le\mu_a-\delta\) and \(x_b\le\mu_b-\delta\), victory of \(x+\delta e_b\) implies victory of \(x+\delta e_a\), where \(e_t\) is the coordinate unit vector.
Call the society linear if every distinct pair \(a,b\) satisfies \(a\succeq_\infty b\) or \(b\succeq_\infty a\).

Is deciding whether such a society is linear solvable in polynomial time, or is it NP-hard?

For finite players, determining linearity of an intersection of weighted voting games is reported NP-hard, already with two thresholds; the reduction maps yes instances of PARTITION to non-linear games. [Aziz, 2008](https://arxiv.org/abs/0809.0519), [Aziz, 2009](https://comsoc-community.org/assets/theses/phd-aziz.pdf).
No complexity classification for exactly the mass-based relation defined above was located in the literature search.

Modeling choices made when packaging the task

  • Weights and quotas had unspecified encoding and domains; use binary rational nonnegative weights and positive quotas.
  • Require each quota to be attainable by the full society, carrying over the requirement that each constituent weighted voting game has a losing empty coalition and a winning grand coalition.
  • Coalition coordinates and exchanged masses range over the reals, while input data remain rational.
  • Use m=d for the number of supplied thresholds, rather than the minimum number needed to represent the winning rule; L is the total input bit length.
  • Allow any positive support size and any positive number of thresholds; comparability is vacuous for a singleton support.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Deciding linearity for the stated mass-based relation is polynomial-time solvable. The algorithm uses at most \(m\tau(\tau-1)\) rational linear programs, each with \(\tau+1\) variables and \(m+2\tau+4\) inequalities. Its total bit running time is \(O\!\left(L+m\tau^2p(m+\tau+L)\right)\) for a fixed polynomial \(p\).

The proof below applies to exactly the simultaneous headroom conditions in the question.

1. A linear program for a directed comparison.

Fix distinct types \(a,b\), and write \(h_{ab}:=\min(\mu_a,\mu_b)\). Let \(F_{ab}\) consist of the real vectors \((x,\delta)\) satisfying:

  • \(0\le x_t\le\mu_t\) for every \(t\in\{1,\ldots,\tau\}\);
  • \(0\le\delta\le h_{ab}\);
  • \(x_a+\delta\le\mu_a\) and \(x_b+\delta\le\mu_b\);
  • \(\sum_{t=1}^{\tau}w_{st}x_t+\delta w_{sb}\ge q_s\) for every \(s\in\{1,\ldots,m\}\).

The last group of inequalities says precisely that \(x+\delta e_b\) wins. The preceding inequalities ensure that both substituted vectors are valid coalitions.

This is a nonempty, compact rational polytope. Indeed, all constraints are weak linear inequalities, and all variables are bounded. Nonemptiness follows from the feasible point \((x,\delta)=(\mu,0)\), because the hypotheses give \(\sum_t w_{st}\mu_t\ge q_s\) for every \(s\).

For each quota index \(r\), compute the exact optimum

\(V_{abr}:=\max_{(x,\delta)\in F_{ab}}\left(q_r-\sum_{t=1}^{\tau}w_{rt}x_t-\delta w_{ra}\right).\)

The maximum exists by compactness. Its objective is the shortfall at quota \(r\) after substituting type \(a\).

2. Exact characterization of failure.

We claim that

\(a\not\succeq_\infty b\quad\Longleftrightarrow\quad V_{abr}>0\text{ for some }r\in\{1,\ldots,m\}.\)

*Forward implication.* If \(a\not\succeq_\infty b\), negating the defining universal implication gives a permitted pair \((x,\delta)\), with \(\delta>0\), such that \(x+\delta e_b\) wins and \(x+\delta e_a\) loses.

Consequently, \((x,\delta)\in F_{ab}\). Since losing means failing at least one quota, some \(r\) satisfies

\(\sum_t w_{rt}x_t+\delta w_{ra}<q_r.\)

The corresponding objective value is strictly positive, so \(V_{abr}>0\).

*Reverse implication.* Suppose \(V_{abr}>0\), and choose a maximizing point \((x,\delta)\in F_{ab}\). Its positive objective gives

\(\sum_t w_{rt}x_t+\delta w_{ra}<q_r,\)

so \(x+\delta e_a\) loses, whereas membership in \(F_{ab}\) ensures that \(x+\delta e_b\) wins.

It remains to check the required strict condition \(\delta>0\). If \(\delta=0\), the winning constraint for quota \(r\) would give \(\sum_t w_{rt}x_t\ge q_r\), making the objective nonpositive. This contradicts \(V_{abr}>0\). Thus \(\delta>0\), and all remaining witness conditions already hold by the definition of \(F_{ab}\).

This proves the equivalence. In particular, permitting zero transfer in the linear program introduces no false counterexamples. Also, an optimum equal to zero is correctly treated as absence of a counterexample: equality meets a quota.

3. Algorithm and correctness.

For every ordered pair of distinct types \(a,b\), compute \(V_{abr}\) for all quota indices \(r\). Declare \(a\succeq_\infty b\) exactly when every such optimum is nonpositive.

The proved equivalence establishes that every directed comparison is correct. Then inspect each unordered pair \(\{a,b\}\):

  • If both directed comparisons fail, return “nonlinear.”
  • If every pair has at least one successful directed comparison, return “linear.”

These are exactly the alternatives in the supplied definition. The two failures for an incomparable pair may have different witnesses; the algorithm tests them independently. When \(\tau=1\), there are no distinct pairs, so the society is linear vacuously.

4. Bit complexity and the finite-player distinction.

Each linear program has \(\tau+1\) variables. There are \(2\tau\) coordinate bounds, two transfer bounds, two headroom inequalities, and \(m\) winning inequalities, totaling \(m+2\tau+4\).

Every coefficient is an input rational, a copied input rational, or one of the constants \(0,1,-1\). The transfer bound \(h_{ab}\) is one of the two supplied masses. Hence each program has binary encoding length polynomial in \(m,\tau,L\).

The standard polynomial-time theorem for rational linear programming computes an exact rational optimum on a nonempty bounded rational polytope in polynomial bit time. Its hypotheses were verified above. Thus the sign tests are exact even when a positive optimum is very small. With at most \(m\tau(\tau-1)\) programs, this proves the stated polynomial running time.

The reported finite-player hardness concerns discrete coalition choices. [Aziz (2008)](https://arxiv.org/abs/0809.0519) gives the cited hardness result for multiple weighted voting games. Here, the coalition coordinates and transfer amount are already continuous, so the linear programs describe the witness sets exactly. The algorithm therefore does not require transferring that finite-player result to the mass-based model.
