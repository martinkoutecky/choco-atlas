The continuous mirror question, as graded

Given a finite edge-weighted graph \(G=(V,E)\) with shortest-path metric \(d\), a rational distribution \(\mu\) over \(V\), and an integer \(k\), decide whether there is a set \(Y\subseteq V\) of \(k\) centers such that for every \(z\in V\setminus Y\) and every submeasure \(0\leq\nu_v\leq\mu_v\) with \(\sum_{v\in V}\nu_v\geq 1/k\), \(\sum_{v\in V}\nu_v d(v,z)\geq\sum_{v\in V}\nu_v d(v,Y)\), where \(d(v,Y)=\min_{y\in Y}d(v,y)\).

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,E)\) be a finite connected undirected graph with positive binary-rational edge lengths, shortest-path metric \(d\), and \(m=|V|\). Every vertex is an eligible center. Let \(1\leq k\leq m\) be an input integer.
A society is given by its support: a list of \(\tau\) vertices with positive binary-rational masses \(\mu_v\), summing to \(1\); unlisted vertices have mass zero. Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L,k\).
For \(Y\subseteq V\) with \(|Y|=k\), define \(d(v,Y)=\min_{y\in Y}d(v,y)\). A coalition is a real submeasure \(\nu\) satisfying \(0\leq\nu_v\leq\mu_v\). It blocks \(Y\) if \(\sum_{v\in V}\nu_v\geq 1/k\) and some \(z\in V\setminus Y\) satisfies \(\sum_{v\in V}\nu_v d(v,z)<\sum_{v\in V}\nu_v d(v,Y)\). Call \(Y\) core-stable if no coalition blocks it; equality does not block.

Is deciding whether a core-stable set of \(k\) centers exists solvable in polynomial time, or is it NP-hard?

For indivisible agents, existence of a clustering immune to strictly improving total-distance deviations by coalitions of size at least \(\alpha n/k\) is NP-complete for every fixed \(\alpha\geq1\), including exact core stability at \(\alpha=1\), even on connected weighted graph metrics. Result

The decision problem is \(\mathrm{NP}\)-complete. This holds even when the input graph is complete, all edge lengths belong to \(\{1,2\}\), every vertex has mass \(\mu_v=1/m\), and \(k=m/2\). Moreover, \(m\) can be a power of two, so the masses are dyadic rationals.

The proof below handles arbitrary real submeasures directly.

1. Polynomial-time verification of a proposed set

Fix a set \(Y\) of \(k\) centers. Write \(S=\operatorname{supp}(\mu)\), \(q=1/k\), and, for each proposed deviating center \(z\), define
\(a_v=d(v,Y)-d(v,z)\).

A coalition blocks through \(z\) precisely when its mass is at least \(q\) and its gain \(\sum_{v\in S}\nu_v a_v\) is positive.

It suffices to consider coalitions of mass exactly \(q\). Indeed, if a blocking coalition has mass \(s\geq q\), then \(\nu'_v=(q/s)\nu_v\) remains a submeasure, has mass \(q\), and has positive gain.

Order the support vertices so that \(a_1\geq\cdots\geq a_\tau\). Put \(P_i=\sum_{h=1}^{i}\mu_h\), \(P_0=0\), and let \(j\) be the least index with \(P_j\geq q\). The maximum gain among mass-\(q\) submeasures is
\(B_z=\sum_{i<j}\mu_i a_i+(q-P_{j-1})a_j\).

To prove this, set \(\lambda=a_j\). For any feasible mass-\(q\) submeasure,
\(\sum_i\nu_i a_i=\lambda q+\sum_i\nu_i(a_i-\lambda)\leq\lambda q+\sum_{i<j}\mu_i(a_i-\lambda)=B_z\).
Here the inequality uses \(\nu_i\leq\mu_i\) for \(i<j\), and \(a_i-\lambda\leq0\) for \(i>j\). Equality is attained by taking all mass before \(j\), mass \(q-P_{j-1}\) at \(j\), and zero afterward.

Consequently, \(Y\) is core-stable exactly when \(B_z\leq0\) for every \(z\in V\setminus Y\). Equality is correctly accepted.

All computations can use exact integer arithmetic after clearing denominators. The resulting integers have \(O(L)\) bits: products of input denominators have total bit length \(O(L)\), and shortest paths use at most \(m-1\) edges. Using Floyd–Warshall and straightforward integer arithmetic, a conservative verification bound is
\(O\!\left((m^3+\tau k+m\tau\log(\tau+1)+L)L^2\right)\)
bit operations.

Thus a list of \(k\) vertices is a polynomial-size certificate with a polynomial-time verifier, proving membership in \(\mathrm{NP}\).

2. A metric characterization by vertex covers

Let \(H=(W,F)\) be a simple graph without isolated vertices, with even order \(m=|W|\). Construct a complete weighted graph \(G\) on \(W\), assigning length one to pairs in \(F\) and length two to all other distinct pairs.

Its shortest-path distances are exactly these assigned lengths. Adjacent pairs have distance one; nonadjacent pairs have a direct edge of length two, and every path with at least two edges has length at least two.

Give every vertex mass \(1/m\) and set \(k=m/2\).

Claim. A set \(Y\subseteq W\) of size \(k\) is core-stable if and only if it is a vertex cover of \(H\).

A stable set must cover every edge. Suppose \(\{u,v\}\in F\) has neither endpoint in \(Y\). Take the coalition consisting of the full masses at \(u\) and \(v\). Its mass is \(2/m=1/k\). Its current total distance is at least \(2/m\), whereas deviating to \(u\) gives total distance \(1/m\). This strictly blocks \(Y\).

Every vertex cover is stable against real submeasures. Suppose \(Y\) covers every edge. Its complement is independent. Since \(H\) has no isolated vertices, every vertex outside \(Y\) has a neighbor in \(Y\), hence has distance one to \(Y\).

Fix \(z\notin Y\). Its gain coefficient is \(a_z=1\). For every other vertex \(v\), we have \(a_v\leq-1\):

  • If \(v\in Y\), then \(d(v,Y)=0\) and \(d(v,z)\geq1\).
  • If \(v\notin Y\) and \(v\neq z\), independence gives \(d(v,z)=2\), while \(d(v,Y)=1\).

Therefore, for any real submeasure of mass \(s\geq2/m\),
\(\sum_v\nu_v a_v\leq\nu_z-\sum_{v\neq z}\nu_v=2\nu_z-s\leq2/m-s\leq0\).

The second inequality uses the capacity bound \(\nu_z\leq1/m\). Thus no coalition strictly improves, proving the claim.

3. Making the vertex-cover budget exactly half the vertices

We use the standard \(\mathrm{NP}\)-completeness of Vertex Cover; it is also the source problem in [Li et al., Theorem 17](https://arxiv.org/pdf/2203.17146). The following padding argument supplies the precise restriction needed here.

Vertex Cover remains \(\mathrm{NP}\)-hard on graphs without isolated vertices and with budget \(1\leq b<N\), where \(N\) is the vertex count. To justify this restriction, delete isolated vertices from an arbitrary instance. Instances with no remaining edges, budget zero, or budget at least the remaining vertex count are decidable immediately and can be mapped to fixed instances: an edge with budget one is a yes-instance, and a triangle with budget one is a no-instance. Every other instance satisfies the restriction.

Start with such an instance \((H,b)\), and put \(\Delta=N-2b\).

If \(\Delta\geq0\), form \(H_1\) by adding \(\Delta\) disjoint triangles, and put \(b_1=b+2\Delta\). Each triangle has minimum vertex-cover size two, so
\(|V(H_1)|=N+3\Delta=2b_1\).

If \(\Delta<0\), put \(s=-\Delta\), add \(s\) disjoint paths on three vertices, and put \(b_1=b+s\). Each such path has minimum vertex-cover size one, so
\(|V(H_1)|=N+3s=2b_1\).

In either case, minimum vertex-cover sizes add across the disjoint components. Hence
\(H\text{ has a cover of size at most }b\iff H_1\text{ has a cover of size at most }b_1\).

Also, \(H_1\) has no isolated vertices and has \(O(N)\) vertices.

To obtain dyadic masses, let \(m\) be the smallest power of two at least \(N_1=|V(H_1)|\). Both \(m\) and \(N_1\) are even. Add \(t=(m-N_1)/2\) disjoint edges to obtain \(H_2\). Each added edge requires one cover vertex, giving
\(H_1\text{ has a cover of size at most }b_1\iff H_2\text{ has a cover of size at most }b_1+t=m/2\).

A cover of size less than \(m/2\) can be enlarged to size exactly \(m/2\), since adding vertices preserves the cover property. Thus Vertex Cover is \(\mathrm{NP}\)-hard under all three restrictions: no isolated vertices, a power-of-two vertex count \(m\), and budget exactly \(m/2\).

4. Completing the reduction

Apply the construction in Section 2 to \(H_2\), with uniform masses \(1/m\) and \(k=m/2\). It produces a connected complete graph with positive integer edge lengths. Every vertex is an eligible center, and every vertex is in the support, so \(\tau=m\). Since \(m\) is a power of two, every mass is dyadic.

The established equivalences give
\(H\text{ has a cover of size at most }b\iff H_2\text{ has a cover of size exactly }m/2\iff G\text{ admits a core-stable set of }k\text{ centers}\).

The padding creates \(m=O(N)\) vertices. Writing the complete weighted graph and masses takes \(O(N^2\log(N+1))\) bit operations and output bits. This is a polynomial-time many-one reduction.

Together with Section 1, this proves \(\mathrm{NP}\)-completeness. In particular, the general decision problem has no polynomial-time algorithm unless \(\mathrm{P}=\mathrm{NP}\).
