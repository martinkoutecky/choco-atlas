The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), a compact rational piecewise-linear worth function \(w:[0,\mu]\to\mathbb{Q}\), and \(\varepsilon>0\), suppose that for every \(r\) with \(r\mu_t\in\mathbb{Z}\), the game \(v_r(S)=r\,w((|S\cap N_{r,t}|/r)_{t\in T})\) is balanced and two-bound, and its per-type nucleolus payoffs converge; compute a vector within \(\varepsilon\) of their limit.

Require \(w(0)=0\); worths may have either sign. Also input a binary rational \(\varepsilon>0\); \(L\) is the total input bit length.

Promise that every such game is balanced and two-bound: its nonempty core is \(C(v_r)=\{x\in\mathbb R^{N_r}:\sum_i x_i=v_r(N_r),\ l_i\le x_i\le u_i\}\) for some real bounds \(l,u\), which are not supplied.

Result

The promised problem is polynomial-time solvable. In fact, the limit is rational and can be computed exactly in time polynomial in \(m,\tau,L\).

The key is to split every type into two equal groups. The limiting feasible group payoffs have a polynomial-size linear programming representation. A bound-tightening lemma then connects their coordinate extrema to the finite nucleoli.

1. The weighted Talmud rule

Write \(W=w(\mu)\). For nonnegative claims \(c=(c_t)_{t\in T}\), put \(C=\sum_t\mu_t c_t\). For \(0\le E\le C\), define the weighted Talmud allocation \(\mathcal T_\mu(E,c)\) by

\[ \mathcal T_{\mu,t}(E,c)= \begin{cases} \min\{c_t/2,\lambda\},&E\le C/2,\\ c_t-\min\{c_t/2,\lambda\},&E>C/2, \end{cases} \]

where the weighted allocations sum to \(E\). Equivalently, in the second branch the weighted sum of \(\min\{c_t/2,\lambda\}\) is \(C-E\). Directly from this definition,

\[ \mathcal T_\mu(E,c)=c-\mathcal T_\mu(C-E,c). \]

For bounds \(\alpha\le\beta\) satisfying \(\sum_t\mu_t\alpha_t\le W\le\sum_t\mu_t\beta_t\), define

\[ \Phi(W;\alpha,\beta) = \alpha+\mathcal T_\mu\left(W-\sum_t\mu_t\alpha_t,\beta-\alpha\right). \]

We use the finite nucleolus formula supplied in the question, namely [Theorem 3 of Gong, Dietzenbacher and Peters](https://link.springer.com/article/10.1007/s10479-022-04949-0). Its hypotheses hold for every promised finite game.

If such a game's core has type-symmetric bounds \(\alpha_t,\beta_t\), then its common type payoff is \(\Phi(W;\alpha,\beta)_t\): the finite estate and total claims are \(r\) times their weighted counterparts, and the equation determining the allocation parameter divides by \(r\).

2. A continuous feasible set with two groups per type

Put \(p_t=\mu_t/2\). Index the two groups of type \(t\) by \(b\in\{1,2\}\), and let \(z_{t,b}\) denote their individual payoffs.

Define

\[ \mathcal D=\prod_{t\in T,\ b\in\{1,2\}}[0,p_t], \qquad (Bs)_t=s_{t,1}+s_{t,2}. \]

The continuous feasible set is

\[ K= \left\{ z: \sum_{t,b}p_tz_{t,b}=W,\quad \sum_{t,b}s_{t,b}z_{t,b}\ge w(Bs) \text{ for every }s\in\mathcal D \right\}. \]

Here coalition amounts can vary continuously within each group.

First, we establish a uniform bound. Write the affine formula on input piece \(j\) as \(a_j\cdot x+b_j\), and set \(M=\max_j\|a_j\|_1\). Then

\[ |w(x)-w(y)|\le M\|x-y\|_\infty \]

throughout the domain. Indeed, the segment joining \(x\) and \(y\) can be partitioned into finitely many subsegments on which an input affine formula applies; the slope bound holds on each, and continuity permits summing the bounds.

For \(z\in K\), use a coalition containing amount \(h>0\) only from group \((t,b)\). Since \(w(0)=0\),

\[ hz_{t,b}\ge w(he_t)\ge-Mh. \]

Using the grand coalition with amount \(h\) removed from that group gives

\[ W-hz_{t,b}\ge w(\mu-he_t), \]

so \(z_{t,b}\le M\). Consequently, \(K\subseteq[-M,M]^{2\tau}\). It is closed because it is an intersection of closed halfspaces and an efficiency hyperplane.

Nonemptiness will follow from the finite games below.

3. Finite group feasible sets converge to \(K\)

Choose a positive integer \(D\) such that \(D\mu_t\) is integral for every type. Restrict attention to \(r\in2D\mathbb Z_{>0}\), so every type can be partitioned into two groups of exactly \(rp_t\) players.

Let \(K_r\) be the set of payoffs constant within each group that belong to \(C(v_r)\). A coalition can select any integral number of players from each group. Dividing its core inequality by \(r\) therefore gives

\[ K_r= \left\{ z: \sum_{t,b}p_tz_{t,b}=W,\quad \sum_{t,b}s_{t,b}z_{t,b}\ge w(Bs) \text{ for every }s\in\mathcal D\cap r^{-1}\mathbb Z^{2\tau} \right\}. \]

Each \(K_r\) is nonempty: average any core payoff over permutations within each group. Convexity and symmetry preserve core membership.

Singleton and complementary-singleton inequalities, together with the Lipschitz bound, give \(K_r\subseteq[-M,M]^{2\tau}\). Also, \(K\subseteq K_r\).

We claim that every limit point of feasible group payoffs belongs to \(K\). Suppose \(r_k\to\infty\), \(z^{(k)}\in K_{r_k}\), and \(z^{(k)}\to z\). For any \(s\in\mathcal D\), round each coordinate down to a multiple of \(1/r_k\), obtaining \(s^{(k)}\in\mathcal D\cap r_k^{-1}\mathbb Z^{2\tau}\). Then \(s^{(k)}\to s\), and passage to the limit in the corresponding core inequality gives

\[ \sum_{t,b}s_{t,b}z_{t,b}\ge w(Bs). \]

Efficiency passes to the limit as well. Thus \(z\in K\). Boundedness and nonemptiness of the \(K_r\) now imply that \(K\) is nonempty and compact.

Coordinate extrema

Define

\[ A_t^{(r)}=\min_{z\in K_r}z_{t,1}, \qquad B_t^{(r)}=\max_{z\in K_r}z_{t,1}, \]

and similarly define \(A_t,B_t\) using \(K\). Swapping the two groups of a type preserves both feasible sets, so these extrema are the same for the second group.

Because \(K\subseteq K_r\), we have \(A_t^{(r)}\le A_t\) and \(B_t^{(r)}\ge B_t\). Conversely, any sequence of minimizers or maximizers has a convergent subsequence, and its limit belongs to \(K\). Therefore,

\[ A_t^{(r)}\longrightarrow A_t, \qquad B_t^{(r)}\longrightarrow B_t. \]

Where the two-bound promise enters

Let \(\alpha_t^{(r)},\beta_t^{(r)}\) be the exact individual core extrema in \(v_r\). These are type-symmetric because the game is invariant under within-type permutations.

They describe the core. Indeed, tightening any supplied box representation to the exact coordinate extrema still contains the core and remains inside the original representation. Hence

\[ K_r= \left\{ z: \alpha_t^{(r)}\le z_{t,b}\le\beta_t^{(r)},\quad \sum_{t,b}p_tz_{t,b}=W \right\}. \]

The same elementary tightening argument shows that \(K_r\) is also described by its group coordinate bounds \(A_t^{(r)},B_t^{(r)}\).

4. Tightening group bounds preserves the weighted Talmud payoff

We prove the lemma needed to replace the unknown individual bounds by the computable group bounds.

Lemma. Suppose

\[ P= \left\{ z: \alpha_t\le z_{t,b}\le\beta_t,\quad \sum_{t,b}p_tz_{t,b}=W \right\} \]

is nonempty, where \(p_t=\mu_t/2\). Let \(A_t,B_t\) be its coordinate extrema. Then

\[ \Phi(W;\alpha,\beta)=\Phi(W;A,B). \]

Proof. Put

\[ c_t=\beta_t-\alpha_t,\qquad E=W-\sum_t\mu_t\alpha_t,\qquad C=\sum_t\mu_tc_t. \]

Nonemptiness gives \(0\le E\le C\). After subtracting the lower bounds, the feasible weighted allocations lie between zero and their claims. Maximizing or minimizing one group coordinate gives

\[ B_t=\alpha_t+\min\{c_t,E/p_t\}, \qquad A_t=\beta_t-\min\{c_t,(C-E)/p_t\}. \]

These extrema are attained: the remaining coordinates can allocate every amount between zero and their total capacity.

We first tighten only the upper bounds. Set

\[ c'_t=\min\{c_t,E/p_t\}, \qquad \beta'_t=\alpha_t+c'_t. \]

This leaves \(P\) unchanged, since the nonnegative weighted allocation to any single group cannot exceed \(E\).

It also leaves the weighted Talmud allocation unchanged. If \(C<2E\), then

\[ c_t\le C/\mu_t<E/p_t, \]

so nothing is truncated.

Suppose instead that \(C\ge2E\). If a type is truncated, its new weighted total claim is

\[ \mu_tc'_t=\mu_tE/p_t=2E. \]

Thus the new total claims are still at least \(2E\). Let \(\lambda\) be an allocation parameter for the original lower branch. For a truncated type, \(c_t/2>E/\mu_t\). Its award must therefore be \(\lambda\), with \(\lambda\le E/\mu_t=c'_t/2\); otherwise that type alone would receive more than the estate. Hence truncation leaves every award unchanged. This argument includes \(E=0\), for which all awards vanish.

We next tighten the lower bounds by applying the same argument to losses. Write

\[ C'=\sum_t\mu_tc'_t,\qquad F=C'-E, \qquad d_t=\min\{c'_t,F/p_t\}, \qquad \alpha'_t=\beta'_t-d_t. \]

Reflection around the upper bounds turns feasible payoffs into feasible losses with estate \(F\) and claims \(c'\). Thus \(\alpha'\) is the exact lower coordinate bound of \(P\). Since upper tightening did not change \(P\), we have \(\alpha'=A\) and \(\beta'=B\).

Upper truncation invariance applied to losses gives \(\mathcal T_\mu(F,c')=\mathcal T_\mu(F,d)\). Self-duality consequently yields

\[ \Phi(W;\alpha,\beta') = \beta'-\mathcal T_\mu(F,c') = \beta'-\mathcal T_\mu(F,d) = \Phi(W;\alpha',\beta'). \]

Together with upper tightening invariance, this proves the lemma. \(\square\)

The use of two equal groups is essential to the argument: a truncated type retains weighted total claim \(2E\).

5. Identifying the nucleolus limit

For each selected \(r\), the finite theorem and the lemma give

\[ \eta_t(v_r) = \Phi\left(W;\alpha^{(r)},\beta^{(r)}\right)_t = \Phi\left(W;A^{(r)},B^{(r)}\right)_t. \]

We verify the continuity needed to pass to the limit.

For nonnegative \(d\) and \(0\le e\le\sum_t\mu_td_t\), let \(\Psi_\mu(e,d)\) have coordinates \(\min\{d_t,\lambda\}\), with weighted sum \(e\). One can choose \(0\le\lambda\le\max_t d_t\). The allocation vector is unique: increasing \(\lambda\) increases every coordinate weakly, so equal weighted sums, with positive weights, force every coordinate to remain unchanged.

If \((e,d)\) converges, the chosen parameters are bounded. Every convergent subsequence of parameters gives a limiting allocation satisfying the limiting weighted equation. Uniqueness therefore proves continuity of \(\Psi_\mu\).

The weighted Talmud rule is

\[ \mathcal T_\mu(E,c)=\Psi_\mu(E,c/2) \quad\text{when }E\le C/2, \]

and

\[ \mathcal T_\mu(E,c)=c-\Psi_\mu(C-E,c/2) \quad\text{when }E\ge C/2. \]

Both expressions equal \(c/2\) at the common boundary. Thus \(\mathcal T_\mu\), and hence \(\Phi\), is continuous on its feasible parameter domain.

Using the convergence of the group extrema gives

\[ \lim_{\substack{r\to\infty\\r\in2D\mathbb Z_{>0}}}\eta_t(v_r) = \Phi(W;A,B)_t. \]

The promised limit along all admissible integers must equal this subsequence limit. Consequently,

\[ a=\Phi(W;A,B). \]

This identifies the target without using a convergence rate.

6. Computing the group extrema by polynomial-size LPs

Let input piece \(j\) have polyhedron \(P_j\) and affine formula \(a_j\cdot x+b_j\). Define the bounded polyhedron

\[ Q_j=\{s\in\mathcal D:Bs\in P_j\}. \]

Using the input's explicit rational inequalities and the box constraints, write \(Q_j=\{s:G_js\le h_j\}\). Empty pieces can be detected and discarded by rational LP feasibility checks. Let \(\widehat a_j\) repeat each coefficient of \(a_j\) in the two group coordinates.

The constraints contributed to \(K\) by piece \(j\) are exactly

\[ \max_{s\in Q_j}(\widehat a_j-z)\cdot s\le-b_j. \]

For every remaining piece, \(Q_j\) is nonempty and compact. Its maximum is therefore finite and attained. Linear programming duality makes the displayed condition equivalent to the existence of \(y_j\) satisfying

\[ y_j\ge0,\qquad G_j^{\mathsf T}y_j=\widehat a_j-z,\qquad h_j^{\mathsf T}y_j\le-b_j. \]

Include these constraints for every piece, together with efficiency. This gives an extended linear description whose projection onto \(z\) is exactly \(K\).

Its size is polynomial in the input size: original inequalities acquire two copies of each type coefficient, and each piece adds \(4\tau\) box inequalities. All coefficients are rational with polynomial encoding length.

Since \(K\) is nonempty and compact, minimizing and maximizing \(z_{t,1}\) in this extended LP computes \(A_t,B_t\). Thus only \(2\tau\) optimization LPs are needed after the piece feasibility checks. The standard polynomial-time theorem for rational linear programming applies: the systems have polynomial binary encoding length, are feasible, and have finite attained objective values. Their exact optimal values are rational with polynomial encoding length.

7. Exact output and complexity

After computing \(A,B\), set

\[ c_t=B_t-A_t,\qquad E=W-\sum_t\mu_tA_t,\qquad C=\sum_t\mu_tc_t. \]

Nonemptiness of \(K\) ensures \(0\le E\le C\). Compute \(q=\Phi(W;A,B)\).

The remaining allocation parameter is obtained by sorting \(c_t/2\). For the relevant estate \(e\), equal to \(E\) or \(C-E\), and a fixed set \(S\) of saturated types, the parameter is

\[ \lambda= \frac{e-\sum_{t\in S}\mu_tc_t/2} {\sum_{t\notin S}\mu_t}. \]

Checking successive intervals between sorted thresholds finds the appropriate parameter in polynomial time. Zero estate and complete saturation are handled directly. All arithmetic is rational and has polynomial bit complexity.

By the preceding proof, \(q=a\), so the requested error bound holds for every input \(\varepsilon>0\). The whole computation takes time polynomial in \(m,\tau,L\).
