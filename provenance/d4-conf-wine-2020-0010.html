The continuous mirror question, as graded

Given \(n\), \(M\), \(\tau\), \(L\), and an unknown probability measure \(\mu\) on at most \(\tau\) integral unit-demand types \(b\in\{0,\ldots,M\}^n\), with binary-rational masses summing to \(1\), an exact oracle returns \(x_\mu(p)=\sum_b\mu_b e^{i_b(p)}\) at tie-avoiding prices \(p\), where \(i_b(p)\in\arg\max_{i\in[n]_0}(b_i-p_i)\) and \(b_0=p_0=0\). Recover every supported pair \((b,\mu_b)\), minimizing the number of oracle queries.

Exact recovery is possible with at most

oracle queries and bit running time polynomial in \(m,\tau,L,\log(M+1)\).

The proof uses the known total mass to obtain cumulative mass queries, then recovers one supported type at a time. It applies directly to positive rational masses.

2. Obtaining cumulative mass from an admissible query

Write \(S\subseteq\{0,\ldots,M\}^n\) for the hidden support. For an integer vector \(q\), define

\(\displaystyle F(q)=\sum_{\substack{b\in S\\b_i\le q_i\ \text{for every }i}}\mu_b.\)

Choose a power of two \(D>n\), with \(D\le 2(n+1)\), and query prices

\(\displaystyle p_i=q_i+\frac{i}{D},\qquad 1\le i\le n.\)

These are binary-rational prices. This query has a unique maximizer for every integer type, regardless of the hidden support:

  • A good’s utility cannot equal the outside utility zero, because \(b_i-q_i-i/D\) is nonintegral.
  • Two distinct goods cannot have equal utilities. Such equality would imply

\(\displaystyle (b_i-q_i)-(b_j-q_j)=\frac{i-j}{D}\).
The left side is integral, whereas the right side is nonzero and has absolute value less than one.

Moreover, the outside option is chosen exactly when every good’s utility is negative. Integrality gives

\(\displaystyle b_i-p_i<0\quad\Longleftrightarrow\quad b_i\le q_i.\)

Consequently, one oracle query computes

\(\displaystyle F(q)=1-\sum_{i=1}^n x_{\mu,i}(p).\)

Thus the oracle supplies the exact mass in any integer lower orthant, using prices guaranteed to be admissible.

3. Recovering one remaining supported type

Suppose a set \(T\subseteq S\) of types and their exact masses has already been recovered. Define the residual cumulative mass

\(\displaystyle F_T(q)=F(q)-\sum_{\substack{b\in T\\b_i\le q_i\ \text{for every }i}}\mu_b =\sum_{\substack{b\in S\setminus T\\b_i\le q_i\ \text{for every }i}}\mu_b.\)

A single original oracle query therefore evaluates \(F_T(q)\), followed by explicit subtraction of known masses.

Because all remaining masses are positive,

\(\displaystyle F_T(q)>0\quad\Longleftrightarrow\quad \text{some }b\in S\setminus T\text{ satisfies }b_i\le q_i\text{ for every }i.\)

Assume \(R=S\setminus T\) is nonempty. We determine coordinates \(a_1,\ldots,a_n\) successively.

Before determining coordinate \(j\), maintain the invariant

\(\displaystyle A_{j-1} =\{b\in R:b_i\le a_i\text{ for }i<j\} =\{b\in R:b_i=a_i\text{ for }i<j\} \ne\varnothing.\)

For \(j=1\), both sets equal \(R\), so the invariant holds.

For an integer \(t\), let

\(\displaystyle q^{(j)}(t)=(a_1,\ldots,a_{j-1},t,M,\ldots,M).\)

Since all supported coordinates are at most \(M\),

\(\displaystyle F_T(q^{(j)}(t))>0 \quad\Longleftrightarrow\quad \text{some }b\in A_{j-1}\text{ has }b_j\le t.\)

This predicate is monotone in \(t\). It is false at \(t=-1\), by nonnegativity of the coordinates, and true at \(t=M\), by nonemptiness of \(A_{j-1}\). Binary search therefore finds its smallest true integer \(a_j\), using at most \(\lceil\log_2(M+1)\rceil\) evaluations.

Equivalently,

\(\displaystyle a_j=\min_{b\in A_{j-1}}b_j.\)

Hence the set

\(\displaystyle A_j=\{b\in A_{j-1}:b_j\le a_j\}\)

is nonempty, and every member satisfies \(b_j=a_j\). Together with the preceding invariant, this proves the invariant for the next coordinate.

After all coordinates have been determined,

\(\displaystyle \varnothing\ne A_n=\{b\in R:b=a\},\qquad a=(a_1,\ldots,a_n).\)

Since the support contains distinct types, \(A_n=\{a\}\). In particular, \(a\) is a remaining supported type, and one additional cumulative mass query gives its exact mass:

\(\displaystyle F_T(a)=\mu_a.\)

This completes the recovery of one pair.

4. Complete algorithm and query bound

Start with \(T=\varnothing\). Repeat the preceding procedure exactly \(\tau\) times, adding the recovered pair to \(T\) after each iteration.

Inductively, every recovered type belongs to the original support and has its correct mass. Each iteration selects a type outside \(T\), so all recovered types are distinct. Before iteration \(k\le\tau\), precisely \(\tau-k+1\) types remain; thus the nonemptiness assumption always holds. After the final iteration, every supported pair has been recovered.

Each iteration uses at most \(n\lceil\log_2(M+1)\rceil\) queries to find the coordinates and one query to obtain the mass. With \(m=n\), the total is therefore

\(\displaystyle \tau\bigl(m\lceil\log_2(M+1)\rceil+1\bigr) =O(m\tau\log(M+1)).\)

5. Polynomial bit running time

The exact arithmetic does not require a number of operations proportional to the reciprocal of a small mass.

To bound its cost, write each hidden mass in reduced form as \(\mu_b=u_b/v_b\), and let

\(\displaystyle Q=\prod_{b\in S}v_b.\)

The total encoding-length bound implies \(\log_2 Q=O(L)\). Every subset sum of hidden masses has denominator dividing \(Q\). Since every such sum lies between zero and one, its reduced numerator and denominator have \(O(L)\) bits.

In particular:

  • Every oracle response coordinate is such a subset sum.
  • Every cumulative mass and residual cumulative mass is such a subset sum.
  • Every recovered mass has \(O(L)\) bits.

When partial sums and differences are reduced after each operation, their bit lengths also remain \(O(L)\). Exact positivity tests therefore take polynomial time in \(L\).

Every queried coordinate \(q_i\) lies between zero and \(M\). The price \(p_i=q_i+i/D\) has bit length \(O(\log(M+1)+\log(n+1))\).

For each cumulative mass evaluation, the algorithm sums the \(n\) response coordinates, checks coordinatewise domination for at most \(\tau\) recovered types, and subtracts their relevant masses. This requires \(O(n\tau+n+\tau)\) comparisons and arithmetic operations on numbers of polynomially bounded bit length. Combined with the proved polynomial query bound, this establishes polynomial bit running time in the required parameters.

The argument here directly proves the normalized positive rational-mass bound, without converting masses into integer multiplicities. Its decisive ingredients are known total mass, integral type coordinates, positive masses, and exact oracle responses.
