The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) summing to one, a downward-closed set \(\mathcal Q\subseteq\mathbb Z_{\ge0}^{T}\) of feasible ride templates with \(1\le\sum_t q_t\le 3\), and costs \(c_t(q)\) for each represented type, decide whether there are masses \(x_q\ge0\) satisfying \(\sum_{q\in\mathcal Q}q_tx_q=\mu_t\) for every \(t\), with no RSIE move. A move exists if two distinct rides have active patterns \(q,r\), a type \(t\) has \(q_t>0\), \(q-e_t\) and \(r+e_t\) are feasible, \(c_t(r+e_t)<c_t(q)\), and \(c_s(r+e_t)\le c_s(r)\) for every type \(s\) with \(r_s>0\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input explicitly lists \(m\) nonempty ride templates \(\mathcal Q\subseteq\mathbb Z_{\ge0}^{T}\), each with \(1\le\sum_t q_t\le3\). All singleton templates \(e_t\) are included, where \(e_t\) is the unit vector of type \(t\); \(\mathcal Q\cup\{0\}\) is downward closed coordinatewise.
For each \(q\in\mathcal Q\) and \(t\) with \(q_t>0\), the input supplies a nonnegative binary rational individual cost \(c_t(q)\), shared by all occupants of type \(t\). Costs are otherwise arbitrary, with ties allowed and no budget-balance requirement. Let \(L\) be the total input bit length.
An assignment consists of real ride masses \(x_q\ge0\) satisfying \(\sum_{q\in\mathcal Q}q_tx_q=\mu_t\) for every \(t\in T\). A template is active exactly when \(x_q>0\).
A blocking transfer exists if \(q\) is active, \(q_t>0\), and a receiving template \(r\) is either active or \(0\), with \(q-e_t\in\mathcal Q\cup\{0\}\), \(r+e_t\in\mathcal Q\), \(c_t(r+e_t)<c_t(q)\), and \(c_s(r+e_t)\le c_s(r)\) for every \(s\) with \(r_s>0\). The receiving ride is distinct from the source ride, but their templates may coincide: positive ride mass provides distinct copies. The virtual receiver \(0\) is always available and represents leaving to travel alone; its acceptance condition is vacuous. No consent from occupants left behind is required.
A ridepooling semi-individual equilibrium (RSIE) is an assignment with no blocking transfer.

Is deciding whether such a continuous RSIE exists solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite, individually listed passengers, deciding RSIE existence is \(\mathrm{NP}\)-complete even when rides contain at most three passengers. [Fielbaum et al.](https://pure.tudelft.nl/ws/portalfiles/portal/118525659/1_s2.0_S0377221721009930_main.pdf)
No result settling this exact continuous problem was located in the literature search.

Modeling choices made when packaging the task

  • Removed zero-mass types from the society's support and retained total mass one.
  • Specified explicit template and cost tables, defined m as the number of nonempty templates, and L as total input bit length.
  • Resolved the incompatibility between downward closure and exclusion of the zero template by requiring downward closure of Q together with zero; required every singleton template to be feasible.
  • Restored the always-available empty receiving group, allowing a passenger to leave and travel alone even when no singleton ride is active.
  • Interpreted distinct rides as distinct copies rather than distinct templates, allowing transfers between two rides having the same active template.
  • Specified real assignment masses and nonnegative binary rational individual costs; allowed cost ties and imposed no budget-balance restriction.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Every valid instance admits a continuous RSIE. Consequently, the existence decision problem is polynomial-time solvable: on the promised input class, the answer is always YES.

The proof uses the matrix form of Scarf’s lemma. Its applicability to general nonnegative matrices is essential because templates may contain repeated occupants of one type.

1. Individually rational templates

Write \(|q|=\sum_{t\in T}q_t\), and define

\(\mathcal Q_{\mathrm{IR}}=\{q\in\mathcal Q:c_t(q)\le c_t(e_t)\text{ whenever }q_t>0\}.\)

All singleton templates belong to \(\mathcal Q_{\mathrm{IR}}\).

Any active template outside this set would permit an occupant to leave for the virtual receiver \(0\). Downward closure makes the source remainder feasible, so this would be a blocking transfer. Thus every RSIE uses only individually rational templates.

We also need the following observation. Suppose an assignment uses only \(\mathcal Q_{\mathrm{IR}}\), and a blocking transfer has source \(q\), moving type \(t\), and nonzero receiver \(r\). Set \(h=r+e_t\). Then

\(c_t(h)<c_t(q)\le c_t(e_t).\)

For every other type \(s\) occurring in \(h\), acceptance gives

\(c_s(h)\le c_s(r)\le c_s(e_s).\)

Therefore \(h\in\mathcal Q_{\mathrm{IR}}\). Moreover, leaving for receiver \(0\) cannot block such an assignment, because its active templates are individually rational.

2. Auxiliary utilities

We introduce auxiliary utilities solely for the existence proof; the input costs remain unchanged.

Let \(\delta\) be the smallest positive difference between two supplied costs for the same type:

\(\delta=\min\{c_t(p)-c_t(q):p,q\in\mathcal Q,\ p_tq_t>0,\ c_t(p)>c_t(q)\}.\)

If this set is empty, take \(\delta=1\). Otherwise it is finite and nonempty, so \(\delta>0\). Set \(\varepsilon=\delta/4\).

For \(q\in\mathcal Q_{\mathrm{IR}}\) and \(q_t>0\), define

\(u_t(q)=c_t(e_t)-c_t(q)+\varepsilon(|q|-1).\)

These utilities have three properties.

  • Singletons are least preferred. We have \(u_t(e_t)=0\). Every individually rational nonsingleton containing \(t\) has utility at least \(\varepsilon>0\).
  • Strict cost improvements remain strict utility improvements. If \(c_t(h)<c_t(q)\), then, because both template sizes lie between \(1\) and \(3\),

\(u_t(h)-u_t(q)=c_t(q)-c_t(h)+\varepsilon(|h|-|q|)\ge\delta-2\varepsilon=\delta/2>0.\)

  • Weak acceptance becomes strict improvement. If \(h=r+e_t\), \(r_s>0\), and \(c_s(h)\le c_s(r)\), then

\(u_s(h)-u_s(r)=c_s(r)-c_s(h)+\varepsilon\ge\varepsilon>0.\)

Thus any blocking transfer makes the moving type strictly better off in auxiliary utility and also makes every type already in the receiver strictly better off.

3. Scarf’s lemma

We use the following matrix formulation of Scarf’s lemma, stated, for example, as Theorem 5.1 in [Kintali et al., *Reducibility Among Fractional Stability Problems*](https://eccc.weizmann.ac.il/report/2009/041/download#page=31).

Let \(n<N\). Suppose \(A,C\in\mathbb R^{n\times N}\), the first \(n\) columns of \(A\) form the identity matrix, \(b\in\mathbb R_{\ge0}^{n}\), and \(\{x\ge0:Ax=b\}\) is bounded. Suppose also that

\(C_{i,i}\le C_{i,k}\le C_{i,j}\)

whenever \(i,j\le n\), \(i\ne j\), and \(k>n\). Then there exists \(x\ge0\) satisfying \(Ax=b\) such that, for every column \(k\), some row \(i\) satisfies

\(C_{i,k}\le C_{i,p}\quad\text{for every }p\text{ with }x_p>0.\)

The theorem allows arbitrary real entries in \(A\), arbitrary nonnegative \(b\), and ties in \(C\).

4. Applying the lemma

Enumerate the types as \(1,\ldots,\tau\). Let \(N=|\mathcal Q_{\mathrm{IR}}|\), placing the singleton templates first.

If \(N=\tau\), the singleton assignment is already an RSIE: any blocking transfer to a nonzero receiver would, by Section 1, produce an individually rational nonsingleton, contrary to \(N=\tau\). Hence assume \(N>\tau\).

Define the template matrix by

\(A_{t,q}=q_t,\)

and take \(b=\mu\). Its first \(\tau\) columns form the identity matrix. The feasible set is nonempty because \(x_{e_t}=\mu_t\) is feasible. It is bounded because every feasible assignment satisfies

\(\sum_{q\in\mathcal Q_{\mathrm{IR}}}|q|x_q=\sum_{t\in T}\mu_t=1,\)

and therefore \(\sum_qx_q\le1\).

Let

\(U_{\max}=\max\{u_t(q):q\in\mathcal Q_{\mathrm{IR}},\ q_t>0\},\qquad H=U_{\max}+1.\)

Define the ordinal matrix \(C\) as follows:

  • \(C_{t,e_t}=0\).
  • \(C_{t,e_s}=H+1\) when \(s\ne t\).
  • For nonsingleton \(q\) containing \(t\), set \(C_{t,q}=u_t(q)\).
  • For nonsingleton \(q\) not containing \(t\), set \(C_{t,q}=H\).

Every entry in a nonsingleton column is strictly between \(0\) and \(H+1\). Thus the required inequalities for \(C\) hold.

Scarf’s lemma supplies a feasible assignment \(x\) with the stated domination property. We now show that it implies

\(\text{for every }h\in\mathcal Q_{\mathrm{IR}},\text{ some }s\text{ with }h_s>0\text{ satisfies }u_s(h)\le u_s(p)\)

for every active template \(p\) containing \(s\).

Indeed, let \(s\) be a dominating row for column \(h\). Since \(\mu_s>0\), mass balance ensures that some active template \(p\) contains \(s\). Hence

\(C_{s,h}\le C_{s,p}=u_s(p)\le U_{\max}<H.\)

If \(h\) did not contain \(s\), its entry in row \(s\) would be \(H\) or \(H+1\), a contradiction. Therefore \(h_s>0\), and domination gives the asserted utility inequalities for every active template containing \(s\).

5. No transfer can block

Extend \(x\) to the original template list by assigning zero mass to every template outside \(\mathcal Q_{\mathrm{IR}}\).

Suppose, for contradiction, that a blocking transfer exists. Let \(q\) be its active source, \(t\) its moving type, and \(r\) its receiver.

Receiver \(0\) is impossible by individual rationality. Thus \(r\) is active and nonzero. Set \(h=r+e_t\); Section 1 proves that \(h\in\mathcal Q_{\mathrm{IR}}\).

Choose a type \(s\) witnessing the domination property for \(h\).

  • If \(s=t\), the mover’s strict cost improvement and Section 2 give \(u_t(h)>u_t(q)\). This contradicts domination because \(q\) is active and contains \(t\).
  • If \(s\ne t\), then \(r_s>0\). Acceptance and Section 2 give \(u_s(h)>u_s(r)\). This contradicts domination because \(r\) is active and contains \(s\).

Both cases are impossible. Therefore \(x\) is an RSIE.

This argument also covers transfers between distinct copies of the same active template, and templates with repeated occupants: neither the matrix lemma nor the contradiction assumes distinct types within a ride.

6. Decision complexity

The existence theorem settles the requested decision problem. Every input satisfying the stated hypotheses is a YES-instance, so returning YES is correct; if input validation is included, it can be performed in polynomial time in \(m,\tau,L\).

The proof concerns continuous ride masses. Scarf’s lemma supplies a fractional assignment, so it does not imply existence for finite passenger partitions or conflict with the finite-model hardness result. The argument establishes no polynomial-time bound for constructing an equilibrium.
