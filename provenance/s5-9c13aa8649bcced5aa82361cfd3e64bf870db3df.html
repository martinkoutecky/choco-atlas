The continuous mirror question, as graded

Given an explicit finite state set \(S\), rational type masses \(\mu_t>0\) summing to \(1\), type payoffs \(w_t(s)\), state-specific voting weights \(a_{s,t}>0\), and rational quotas \(\theta_s\) satisfying \(\frac12\sum_t a_{s,t}\mu_t\le\theta_s<\sum_t a_{s,t}\mu_t\), compute the fixed-point set \(D\) of maps satisfying the paper’s three stability axioms and, for each initial state \(s_0\), all attainable terminal states \(\phi(s_0)\). In state \(s\), a coalition is a vector of measurable type masses \(q_t\in[0,\mu_t]\) and wins when \(\sum_t a_{s,t}q_t>\theta_s\).

Packaged proof task (what the prover saw — nothing else)

Let \(S\) be an explicitly listed nonempty state set, with \(m=|S|\). A society is given by its support: the list of \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length.
Each type is an atomless population with constant payoffs and voting weights. The input gives positive binary rational payoffs \(w_t(s)\), positive binary rational weights \(a_{s,t}\), and binary rational quotas satisfying \(\frac12\sum_t a_{s,t}\mu_t\le\theta_s<\sum_t a_{s,t}\mu_t\).
A coalition is a nonzero vector of real masses \(q_t\in[0,\mu_t]\); it wins in \(s\) exactly when \(\sum_t a_{s,t}q_t>\theta_s\). Define \(y\succ_s x\) exactly when \(\sum_{t:w_t(y)>w_t(x)}a_{s,t}\mu_t>\theta_s\). Payoff ties give no strict support.
Promise that the directed graph with edges \(x\to y\) exactly when \(y\succ_x x\) is acyclic. Also, for each \(s\), promise that the graph on \(B_s=\{x\in S:x\succ_s s\}\), with edges \(x\to y\) exactly when \(y\succ_s x\), is acyclic.
All state transitions are feasible. Let \(\Phi\) contain precisely the maps \(\phi:S\to S\) satisfying, for all \(x,z\in S\): desirability, \(\phi(x)=x\) or \(\phi(x)\succ_x x\); stability, \(\phi(\phi(x))=\phi(x)\); and rationality, there is no \(z\) with \(\phi(z)=z\), \(z\succ_x x\), and \(z\succ_x\phi(x)\).
Define \(D=\{s\in S:\exists\phi\in\Phi,\ \phi(s)=s\}\) and, for every initial state \(s_0\), \(T(s_0)=\{\phi(s_0):\phi\in\Phi\}\).

Can \(D\) and all sets \(T(s_0)\) be computed in time polynomial in \(m,\tau,L\), or is this computation NP-hard?

For finite societies under these acyclicity conditions, existence, a recursive characterization of all admissible maps, and equality of their fixed-point sets are established by [Acemoglu, Egorov, and Sonin](https://www.nber.org/system/files/working_papers/w14239/w14239.pdf).
The [published version](https://economics.mit.edu/sites/default/files/publications/Dynamics%20and%20Stability%20of%20Constitutions%2C%20Coalition.pdf) confirms that the weaker strict acyclicity conditions suffice for this characterization. Polynomial-time solvability

Both \(D\) and all sets \(T(s_0)\) can be computed in time polynomial in \(m,\tau,L\). The key is that all admissible maps have the same fixed-point set, and their choices of images are independent once this set is known.

The construction below agrees with the recursive characterization in Theorem 1(ii) and the weaker strict acyclicity condition in footnote 15 of the [published paper](https://economics.mit.edu/sites/default/files/publications/Dynamics%20and%20Stability%20of%20Constitutions%2C%20Coalition.pdf). We prove its correctness directly for the stated mass input.

1. Fixed-point sets satisfy a graph condition

Let \(G\) be the directed graph on \(S\) with an edge \(x\to y\) precisely when \(y\succ_x x\). Thus the out-neighbor set of \(x\) is \(B_x\). By promise, \(G\) is acyclic.

For any \(\phi\in\Phi\), write
\[ F_\phi=\{x\in S:\phi(x)=x\}. \]
We claim that, for every \(x\in S\),
\[ x\in F_\phi \quad\Longleftrightarrow\quad B_x\cap F_\phi=\varnothing. \tag{1} \]

To prove the forward implication, suppose \(x\in F_\phi\). If \(z\in B_x\cap F_\phi\), then
\[ \phi(z)=z,\qquad z\succ_x x,\qquad z\succ_x\phi(x), \]
where the last condition follows from \(\phi(x)=x\). This violates rationality.

For the reverse implication, suppose \(x\notin F_\phi\). Desirability gives \(\phi(x)\succ_x x\), while stability gives \(\phi(\phi(x))=\phi(x)\). Hence
\[ \phi(x)\in B_x\cap F_\phi, \]
so this intersection is nonempty. This proves (1).

A set satisfying (1) is usually called a kernel of \(G\): it contains no edge between its members, and every vertex outside it has an outgoing edge to a member.

2. The acyclic graph has a unique kernel

Choose an ordering \(v_1,\ldots,v_m\) such that every edge \(v_i\to v_j\) satisfies \(j<i\). Such an ordering exists because \(G\) is a finite acyclic graph: repeatedly remove a sink and list vertices in their removal order. A nonempty finite acyclic graph has a sink, since otherwise following outgoing edges would eventually repeat a vertex and produce a directed cycle.

Construct sets \(F_0,\ldots,F_m\) as follows. Start with \(F_0=\varnothing\). At step \(i\), set
\[ F_i= \begin{cases} F_{i-1}\cup\{v_i\},& B_{v_i}\cap F_{i-1}=\varnothing,\\ F_{i-1},& B_{v_i}\cap F_{i-1}\ne\varnothing. \end{cases} \tag{2} \]
Let \(F=F_m\).

Every out-neighbor of \(v_i\) occurs before \(v_i\). Therefore later steps cannot change whether an out-neighbor of \(v_i\) belongs to the constructed set. Consequently, (2) gives
\[ v_i\in F \quad\Longleftrightarrow\quad B_{v_i}\cap F=\varnothing. \]
Thus \(F\) satisfies (1). It is nonempty because the construction includes \(v_1\).

For uniqueness, let \(K\subseteq S\) satisfy (1). Proceed by induction through the ordering. All out-neighbors of \(v_i\) occur earlier, so once membership in \(K\) is determined for those earlier vertices, (1) determines membership of \(v_i\) uniquely. Its decision is precisely the decision in (2). Therefore \(K=F\).

It follows that every admissible map, if one exists, has fixed-point set exactly \(F\). We next construct such maps and determine all possible images.

3. All admissible maps are obtained by independent choices

For each \(x\notin F\), define
\[ C_x=F\cap B_x. \]
By (1), \(C_x\ne\varnothing\).

Define its set of undominated alternatives, using the voting rule at \(x\), by
\[ M_x=\{y\in C_x:\text{there is no }z\in C_x \text{ with }z\succ_x y\}. \tag{3} \]
These are exactly the sinks of the graph on \(C_x\) whose edges are \(y\to z\) when \(z\succ_x y\).

The graph on \(B_x\) with these edges is acyclic by the second promise. Its induced subgraph on \(C_x\) is therefore acyclic. Since \(C_x\) is finite and nonempty, it has a sink. Hence
\[ M_x\ne\varnothing. \tag{4} \]
For \(x\in F\), define \(M_x=\{x\}\).

We now prove the full characterization
\[ \Phi=\{\phi:S\to S:\phi(x)\in M_x \text{ for every }x\in S\}. \tag{5} \]

Necessity. Let \(\phi\in\Phi\). Its fixed-point set is \(F\), by Sections 1–2. Thus \(\phi(x)=x\) for \(x\in F\).

If \(x\notin F\), desirability and stability imply \(\phi(x)\in C_x\). Rationality excludes every \(z\in C_x\) satisfying \(z\succ_x\phi(x)\). Therefore \(\phi(x)\in M_x\).

Sufficiency. Choose any \(\phi(x)\in M_x\) independently for each \(x\). We verify all three axioms.

  • Desirability: If \(x\in F\), then \(\phi(x)=x\). Otherwise, \(\phi(x)\in C_x\subseteq B_x\), so \(\phi(x)\succ_x x\).
  • Stability: Every image belongs to \(F\), and every member of \(F\) maps to itself. Hence \(\phi(\phi(x))=\phi(x)\).
  • Rationality: The fixed-point set of this map is exactly \(F\): states in \(F\) map to themselves, and states outside \(F\) map into \(F\). If \(x\in F\), then \(F\cap B_x=\varnothing\), so there is no fixed \(z\) with \(z\succ_x x\). If \(x\notin F\), any fixed \(z\) satisfying \(z\succ_x x\) belongs to \(C_x\); equation (3) excludes \(z\succ_x\phi(x)\).

This proves (5). In particular, \(\Phi\ne\varnothing\), by (4).

Consequently,
\[ D=F, \qquad T(x)= \begin{cases} \{x\},&x\in F,\\ \{y\in F\cap B_x:\text{there is no }z\in F\cap B_x \text{ with }z\succ_x y\},&x\notin F. \end{cases} \tag{6} \]
Every element displayed in \(T(x)\) is attainable: choose it as the image of \(x\), choose any allowed image at each other state, and apply (5).

4. Exact computation and bit complexity

It remains to show that all relations needed in this construction can be computed in polynomial time from the support list.

For each state \(s\) and type \(t\), write
\[ a_{s,t}\mu_t=\frac{p_{s,t}}{d_{s,t}}, \qquad \theta_s=\frac{c_s}{e_s}, \]
with positive integer denominators. Reduction to lowest terms is unnecessary.

For each \(s\), form
\[ Q_s=e_s\prod_{t=1}^{\tau}d_{s,t}, \qquad h_{s,t}=p_{s,t}\frac{Q_s}{d_{s,t}}, \qquad k_s=c_s\frac{Q_s}{e_s}. \]
All these are integers, and
\[ y\succ_s x \quad\Longleftrightarrow\quad \sum_{\{t:w_t(y)>w_t(x)\}}h_{s,t}>k_s. \tag{7} \]

Payoff comparisons are exact rational comparisons by cross multiplication. In particular, payoff ties contribute nothing to (7), and equality with the quota is correctly treated as losing.

The bit length of each denominator \(d_{s,t}\) is at most the sum of the input denominator lengths for \(a_{s,t}\) and \(\mu_t\). For any fixed \(s\), summing these lengths over the support, and adding the denominator length of \(\theta_s\), gives \(O(L)\). Therefore \(Q_s\), each \(h_{s,t}\), and \(k_s\) have \(O(L)\) bits. A sum of at most \(\tau\) such integers also has \(O(L)\) bits, since its additional length is at most \(O(\log\tau)\).

The algorithm is therefore:

  • Compute \(y\succ_s x\) for all triples \((s,x,y)\) using (7).
  • Construct \(G\), find the ordering from Section 2, and compute \(F\) using (2).
  • Compute every set in (6) by testing the stored relations.

Step 1 requires \(O(m^3\tau)\) arithmetic operations on integers of \(O(L)\) bits. Steps 2–3 require \(O(m^3)\) additional graph and table operations. Using ordinary quadratic-time integer arithmetic gives the conservative bit-time bound
\[ O(m^3\tau L^2). \]
The output consists of at most \(m+m^2\) state memberships.

Thus the explicitly listed support suffices for a polynomial-time algorithm; neither coalition enumeration nor expansion into finitely many individuals is required.
