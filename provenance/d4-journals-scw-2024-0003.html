The continuous mirror question, as graded

Given four candidates \(C\) and a rational distribution \(\mu\) over their strict rankings, decide whether there are candidate locations \(p_c\in\mathbb R^2\) and, for every ranking type \(t\) with \(\mu_t>0\), a voter location \(q_t\in\mathbb R^2\) such that \(\|q_t-p_c\|_2<\|q_t-p_{c'}\|_2\) exactly when \(t\) ranks \(c\) above \(c'\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a set of \(m=4\) candidates. A society is given by its support: a list \(S\) of \(\tau\) distinct strict rankings of \(C\), each with positive binary rational mass \(\mu_t\), with \(\sum_{t\in S}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
Call the society realizable if there exist candidate locations \(p_c\in\mathbb R^2\) and one voter location \(q_t\in\mathbb R^2\) for every \(t\in S\), such that, for every distinct \(c,c'\in C\), \(c\succ_t c'\iff\|q_t-p_c\|_2<\|q_t-p_{c'}\|_2\). Locations are unrestricted real points, and distance ties are forbidden.

Is deciding realizability in \(\mathrm P\), with running time polynomial in \(m,\tau,L\) for fixed \(m=4\), or is it NP-hard?

Known discrete result: realizable four-candidate profiles are exactly the subsets, up to candidate relabeling, of three maximal realizable profiles, each containing \(18\) rankings. [Source](https://arxiv.org/pdf/2202.03185).
For the stated distribution model, polynomial-time recognition follows from this characterization because realizability depends only on the support. This is an inference from the verified characterization, and means the requested open target is already settled.

Conclusion

Realizability is decidable in \(\mathrm P\) for fixed \(m=4\). The rational masses do not affect realizability; the verified characterization gives a finite, explicit recognition algorithm.

1. Reduction to the support

Let \(P_S\) be the unweighted profile with candidate set \(C\) and one voter for each ranking \(t\in S\).

Lemma. The given society is realizable if and only if \(P_S\) is realizable.

Proof. Both definitions require exactly the same candidate locations \(p_c\) and voter locations \(q_t\), satisfying exactly the same strict distance comparisons. None of these constraints contains \(\mu_t\). Consequently, a realization of either object is a realization of the other. Positivity ensures that every listed ranking belongs to the support. \(\square\)

Thus there is no need to expand rational masses into voter multiplicities.

2. Verified characterization and explicit templates

Theorem 2 of Escoffier, Spanjaard, and Tydrichová states that a four-candidate profile is Euclidean in the plane under \(\ell_2\) if and only if it is isomorphic, by candidate relabeling, to a subprofile of one of three specified profiles. Each template contains \(18\) rankings. The paper’s Definition 1 uses strict distance inequalities, so its notion of realization matches the present problem. [Source, Definition 1 and Theorem 2](https://arxiv.org/pdf/2202.03185).

Here is a compact specification of those templates. Let \(\mathcal R\) be the set of all \(24\) rankings on \(\{1,2,3,4\}\). Write \(ijkl\) for the ranking \(i\succ j\succ k\succ l\). Define \(M_i=\mathcal R\setminus F_i\), using the following complements of the profiles displayed in Theorem 2:

| Template | Excluded rankings |
|---|---|
| \(M_1\) | \(F_1=\{1324,1342,1432,3124,3142,3412\}\) |
| \(M_2\) | \(F_2=\{2143,2341,2413,2431,4213,4231\}\) |
| \(M_3\) | \(F_3=\{1342,1432,3142,3412,4132,4312\}\) |

The characterization therefore states precisely that \(P_S\) is realizable if and only if there exist \(i\in\{1,2,3\}\) and a bijection \(\sigma:\{1,2,3,4\}\to C\) such that \(S\subseteq\sigma(M_i)\). Here \(\sigma\) acts on every entry of a ranking.

Its hypotheses hold: the input has four candidates, strict rankings, and planar Euclidean distance. No restrictions on locations are added.

3. Recognition algorithm and correctness

Use the following algorithm:

  • Read the input and retain its support \(S\).
  • For each of the three templates and each of the \(24\) candidate bijections \(\sigma\), test whether every \(t\in S\) satisfies \(\sigma^{-1}(t)\notin F_i\).
  • Accept if any test succeeds; otherwise reject.

Soundness. Suppose the algorithm accepts for \(i,\sigma\). Its test establishes \(S\subseteq\sigma(M_i)\). By the characterization, \(M_i\) has a realization. Relabel its candidate locations using \(\sigma\), and retain the voter locations corresponding to rankings in \(S\). Every required strict comparison remains satisfied. The support lemma then gives a realization of the society.

Completeness. Suppose the society is realizable. By the support lemma, \(P_S\) is realizable. The characterization supplies \(i,\sigma\) with \(S\subseteq\sigma(M_i)\). The algorithm examines this pair, and every support ranking passes its membership test. Hence the algorithm accepts. \(\square\)

4. Running time

There are exactly \(3\cdot24=72\) template-and-relabeling tests. Each examines \(\tau\) rankings, and each ranking has four entries. Membership in an excluded set requires comparison with only six fixed rankings.

After normalizing candidate labels, the recognition computation therefore takes \(O(\tau)\) time. Reading and normalizing the input takes \(O(L)\) time because there are only four candidate labels. On the promised valid inputs, the total running time is \(O(L+\tau)\), hence polynomial in \(m,\tau,L\) for fixed \(m=4\).

This settles the stated target. Under polynomial-time many-one reductions, NP-hardness of this restricted problem would imply \(\mathrm P=\mathrm{NP}\).
