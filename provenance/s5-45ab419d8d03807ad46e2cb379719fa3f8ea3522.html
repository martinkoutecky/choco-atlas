The continuous mirror question, as graded

Given a graph \(G\), form the three valuations and goods from Theorem 5.1, and take three types with masses \(\mu_i=1/3\) and per-capita supply \(q_g=1/3\) for every good \(g\). Decide whether there are nonnegative bundle masses \(x_{i,S}\) with \(\sum_{S\subseteq M}x_{i,S}=\mu_i\) and \(\sum_{i,S:g\in S}x_{i,S}=q_g\), such that every pair of positively represented type-bundle classes satisfies EF1 and no alternative allocation dominates under a type-preserving coupling that weakly benefits every person and strictly benefits a positive mass.

Packaged proof task (what the prover saw — nothing else)

Input is a finite simple undirected graph \(G=(V,E)\), with even \(n=|V|\) and \(e=|E|\geq1\). Let \(M=A\mathbin{\dot\cup}B\mathbin{\dot\cup}P\), where \(|A|=3\), \(|B|=5\), and \(P=\{p_v:v\in V\}\); write \(m=|M|=n+8\).
Define \(u_1,u_2\) by the following matrices, with rows indexed by \(a=0,1,2,3\) and columns by \(b=0,1,2,3,4,5\): \(u_1=\begin{pmatrix}0&13&26&39&46&53\\25&38&47&50&53&54\\28&41&50&53&54&55\\29&42&51&54&55&56\end{pmatrix}\), \(u_2=\begin{pmatrix}0&13&26&39&50&51\\17&28&39&46&53&54\\32&39&46&53&54&55\\47&50&53&54&55&56\end{pmatrix}\).
For \(S\subseteq M\), put \(a=|S\cap A|\), \(b=|S\cap B|\), \(r=|S\cap P|\), and \(c(S)=|\{\{v,w\}\in E:p_v\in S\text{ or }p_w\in S\}|\). With \(\lambda=n+2\), the three valuations are \(w_1(S)=\lambda(eu_1(a,b)+3c(S))+r\), \(w_2(S)=\lambda e u_2(a,b)+r\), and \(w_3(S)=\lambda r\). These are normalized, nonnegative integer-valued monotone submodular valuations.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; \(\tau\) is the support size, not the number of possible types. Here \(\tau=3\), the types have valuations \(w_i\) and masses \(\mu_i=1/3\), and total mass is \(1\). Every good has per-capita supply \(q_g=1/3\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
An allocation consists of real masses \(x_{i,S}\geq0\) for \(i\in\{1,2,3\}\), \(S\subseteq M\), satisfying \(\sum_S x_{i,S}=\mu_i\) and \(\sum_i\sum_{S:g\in S}x_{i,S}=q_g\) for every \(g\in M\).
Require EF1 between every ordered pair of positive-mass classes, including classes of the same type: if \(x_{i,S}x_{j,T}>0\), then \(T=\varnothing\) or there is \(g\in T\) with \(w_i(S)\geq w_i(T\setminus\{g\})\).
An allocation is Pareto optimal if there is no feasible allocation \(y\) and nonnegative real coupling \(z_{i,S,T}\) with \(\sum_Tz_{i,S,T}=x_{i,S}\), \(\sum_Sz_{i,S,T}=y_{i,T}\), and \(z_{i,S,T}>0\Rightarrow w_i(T)\geq w_i(S)\), such that \(\sum_{i,S,T:w_i(T)>w_i(S)}z_{i,S,T}>0\). The competing allocation need not satisfy EF1.

Is deciding whether an allocation satisfying both EF1 and this Pareto optimality exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For the corresponding discrete problem with three agents and one copy of each good, existence of an EF1 and Pareto-optimal allocation is NP-hard even on this graph-generated family; only the eight pairs involving type \(3\) and goods in \(A\cup B\) have zero marginals. [Source](https://arxiv.org/html/2607.23367).
No result settling this precise mass-allocation problem was located in the literature search.

Modeling choices made when packaging the task

  • Restricted the input to finite simple undirected graphs with even vertex count and at least one edge, matching the nontrivial source instances used in the discrete construction.
  • Expanded the graph-generated goods and valuations explicitly, retaining the scale n+2 and using a separate symbol for it so L denotes input bit length.
  • Allowed real allocation and coupling masses; the binary-rational requirement applies to the input society and supplies.
  • Applied EF1 to all ordered positive-mass class pairs, including classes within one type, because such classes represent distinct people.
  • Made Pareto comparisons range over all allocations satisfying the same exact supply and type-mass equalities, without requiring the competing allocation to satisfy EF1.

Result

The problem is polynomial-time solvable on the stated family. Every valid input graph admits an allocation satisfying both EF1 and the specified Pareto optimality.

The construction uses fractional masses of classes: type \(2\) mixes two different core-bundle patterns. There are \(41\) positive-mass classes, while the society’s support size remains \(\tau=3\).

1. Preliminary facts

Write \(C=A\mathbin{\dot\cup}B\) for the eight core goods, and put \(H=\lambda e\). Since \(e\geq1\) and \(\lambda=n+2\), we have \(H>n\).

Choose a vertex \(v_*\) of maximum degree, and write \(\Delta=\deg(v_*)\). Because the graph has an edge, \(\Delta\geq1\).

For a core bundle \(D\subseteq C\), write \(u_i(D)=u_i(|D\cap A|,|D\cap B|)\). The given matrices yield:

| Core size \(k\) | \(\max_{|D|=k}u_1(D)\) | \(\max_{|D|=k}u_2(D)\) |
|---|---|---|
| \(0\) | \(0\) | \(0\) |
| \(1\) | \(25\) | \(17\) |
| \(2\) | \(38\) | \(32\) |
| \(3\) | \(47\) | \(47\) |
| \(4\) | \(50\) | \(50\) |

For example, the four possible count pairs of size \(4\) are \((0,4),(1,3),(2,2),(3,1)\). Their values are respectively \((46,50,50,42)\) for type \(1\), and \((50,46,46,50)\) for type \(2\). The other rows follow by the same enumeration.

Consequently, for either type, core value at least \(50\) requires at least four core goods. With exactly four core goods, that value must equal \(50\).

We also need one fact about the entire first matrix: every entry below \(50\) is at most \(47\).

2. Construction and feasibility

Define the allocation as follows; every unlisted mass is zero.

  • Type \(1\): For every \(D\subseteq C\) with counts \((1,3)\), set

\(x_{1,D\cup\{p_{v_*}\}}=1/90\).
There are \(3\binom{5}{3}=30\) such bundles.

  • Type \(2\):
  • For each four-element subset \(D\subseteq B\), set \(x_{2,D}=1/45\).
  • For each \(b\in B\), set \(x_{2,A\cup\{b\}}=2/45\).
  • Type \(3\): Set

\(x_{3,P\setminus\{p_{v_*}\}}=1/3\).

The type masses are respectively
\(30/90=1/3\),
\(5/45+10/45=1/3\),
and \(1/3\).

For feasibility, consider bundle probabilities conditional on type, obtained by multiplying class masses by \(3\):

| Good | Type \(1\) inclusion probability | Type \(2\) inclusion probability | Type \(3\) inclusion probability |
|---|---|---|---|
| Any \(a\in A\) | \(1/3\) | \(2/3\) | \(0\) |
| Any \(b\in B\) | \(3/5\) | \(2/5\) | \(0\) |
| \(p_{v_*}\) | \(1\) | \(0\) | \(0\) |
| Any other vertex good | \(0\) | \(0\) | \(1\) |

For type \(2\), the conditional probabilities of the two count patterns are \(1/3\) for \((0,4)\) and \(2/3\) for \((3,1)\). Thus a particular \(B\)-good has inclusion probability
\((1/3)(4/5)+(2/3)(1/5)=2/5\), as displayed.

Each row sums to \(1\). Multiplying by the common type mass \(1/3\) gives exactly the required supply \(1/3\) for every good.

All positive-mass classes of a given type have the same own utility:

\(W_1=50H+3\lambda\Delta+1,\qquad W_2=50H,\qquad W_3=\lambda(n-1).\)

Indeed, the type \(1\) core value is \(u_1(1,3)=50\), and its singleton vertex set covers \(\Delta\) edges. Both type \(2\) patterns have value \(u_2(0,4)=u_2(3,1)=50\).

3. EF1, including within types

For classes of the same type, own utilities equal \(W_i\). Monotonicity therefore gives \(w_i(T\setminus\{g\})\leq w_i(T)=W_i=w_i(S)\) for any deletion from a nonempty target bundle. This proves every within-type comparison.

For the six comparisons between different types:

  • Type \(1\) toward type \(2\): Delete a \(B\)-good. A target with counts \((0,4)\) then has type \(1\) value \(39H\); a target with counts \((3,1)\) then has value \(29H\). Both are below \(W_1\).
  • Type \(2\) toward type \(1\): Delete the unique \(A\)-good. The remaining bundle has type \(2\) value \(39H+1<50H=W_2\).
  • Type \(1\) toward type \(3\): The target’s value is at most \(3H+n-1<50H\leq W_1\). Thus any deletion suffices.
  • Type \(2\) toward type \(3\): The target’s value is \(n-1<50H=W_2\), so any deletion suffices.
  • Type \(3\) toward type \(1\): Delete \(p_{v_*}\). The remaining bundle has type \(3\) value zero.
  • Type \(3\) toward type \(2\): The target contains only core goods, so its type \(3\) value remains zero after any deletion.

Here the strict bounds use \(H>n\). All constructed bundles are nonempty because \(n\geq2\). Hence the allocation satisfies every required EF1 comparison.

4. Pareto optimality against arbitrary mass allocations

Let \(y\) be any feasible competing allocation admitting a coupling \(z\) that weakly improves every recipient. We prove that no positive coupling mass can improve strictly.

Because every original class of type \(i\) has utility \(W_i\), every positive-mass destination bundle of that type must satisfy

\(y_{i,T}>0\ \Longrightarrow\ w_i(T)\geq W_i.\)

To justify this implication, the coupling identity \(y_{i,T}=\sum_S z_{i,S,T}>0\) gives a source \(S\) with \(z_{i,S,T}>0\). Its original utility is \(W_i\), so the coupling’s weak-improvement condition applies.

Put \(\beta_{i,T}=3y_{i,T}\). Then each type’s \(\beta\)-mass sums to \(1\), and each good has total \(\beta\)-supply \(1\). For a bundle \(T\), write \(k(T)=|T\cap C|\) and \(r(T)=|T\cap P|\). Feasibility implies

\(\sum_{i,T}\beta_{i,T}k(T)=8,\qquad \sum_{i,T}\beta_{i,T}r(T)=n.\)

4.1. The core resource bound forces four goods per recipient

For a positive-mass type \(1\) destination, suppose its core value were below \(50\). It would then be at most \(47\), giving

\(w_1(T)\leq47H+3\lambda e+n=50H+n<W_1.\)

The last inequality follows from \(\Delta\geq1\) and \(3\lambda\Delta+1>n\). This contradicts weak improvement. Therefore its core value is at least \(50\).

For a positive-mass type \(2\) destination, a core value below \(50\) would, by integrality, be at most \(49\). Consequently,

\(w_2(T)\leq49H+n<50H=W_2,\)

again a contradiction.

The preliminary table now shows that every positive-mass destination of types \(1\) and \(2\) contains at least four core goods. Since each type has total \(\beta\)-mass \(1\), they already require total core supply at least \(4+4=8\).

Exactly eight core goods are available. Equality therefore forces:

  • every positive-mass destination of types \(1\) and \(2\) to contain exactly four core goods;
  • every positive-mass destination of type \(3\) to contain no core goods.

The same table then forces the core value of every destination of types \(1\) and \(2\) to equal \(50\).

4.2. The vertex resource bound forces one vertex for type \(1\)

For a positive-mass type \(1\) destination, weak improvement now reads

\(3\lambda(c(T)-\Delta)+r(T)\geq1.\)

If \(c(T)\leq\Delta-1\), the left side is at most \(-3\lambda+n<1\), a contradiction. Thus \(c(T)\geq\Delta\geq1\). In particular, \(r(T)\geq1\).

For a positive-mass type \(3\) destination, weak improvement requires \(r(T)\geq n-1\).

Types \(1\) and \(3\) therefore require total vertex supply at least \(1+(n-1)=n\), exhausting the available supply. Equality forces every positive-mass destination to have:

  • \(r(T)=1\) for type \(1\);
  • \(r(T)=0\) for type \(2\);
  • \(r(T)=n-1\) for type \(3\).

A singleton vertex set covers at most \(\Delta\) edges, by the choice of \(v_*\). For type \(1\), combining this with \(c(T)\geq\Delta\) yields \(c(T)=\Delta\).

Thus every positive-mass destination has exactly its type’s original utility:

\(w_1(T)=W_1,\qquad w_2(T)=W_2,\qquad w_3(T)=W_3.\)

No positive coupling mass can improve strictly. This proves Pareto optimality under the stated definition, without imposing EF1 on the competing allocation.

5. Complexity and the discrete distinction

Finding \(v_*\) takes \(O(n+e)\) word operations with a standard explicit graph encoding. The construction outputs \(41\) bundles with constant-size rational masses. A conservative bit-time bound is

\(O\!\left(L+(m^2+\tau)\log(m+2)\right),\qquad \tau=3.\)

On the promised input family, the decision answer is always yes.

The [cited discrete result](https://arxiv.org/html/2607.23367) concerns allocations with one bundle per agent. Here type \(2\) can mix the patterns \((0,4)\) and \((3,1)\), producing expected core counts \((2,2)\) while every class retains core value \(50\). This fractional option bypasses the discrete obstruction.
