The continuous mirror question, as graded

Given a finite support of CRG types with masses \(\mu_t\), each type’s accepted goals and per-agent resource endowments \(e(t,r)\), per-population goal demands \(q(g,r)\), and target mass \(\kappa\), does there exist a mass vector \(x\) and goal set \(S\subseteq G\) such that \(0\le x_t\le\mu_t\), \(\sum_t x_t=\kappa\), every type with \(x_t>0\) accepts at least one goal in \(S\), and \(\sum_t x_t e(t,r)\ge\sum_{g\in S}q(g,r)\) for every resource \(r\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) representational types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Let \(G\) and \(R\) be finite nonempty sets of goals and resources, with \(m=|G|\) and \(d=|R|\). Type \(t\) specifies an accepted-goal set \(A_t\subseteq G\), possibly empty, and per-agent endowments \(e(t,r)\in\mathbb{Z}_{\ge0}\); identical descriptions constitute one type.
Each goal has binary rational demands \(q(g,r)\ge0\), measured per unit of total population. A selected goal is achieved in full, incurs its demand once, and satisfies all participating mass of every type accepting it. Demands add across goals; resources are pooled within the coalition.
The input also specifies a binary rational target \(0<\kappa\le1\). A successful coalition consists of \(x\in\mathbb{R}^{\tau}\) and \(\varnothing\ne S\subseteq G\) satisfying \(0\le x_t\le\mu_t\), \(\sum_t x_t=\kappa\), \(x_t>0\Rightarrow A_t\cap S\ne\varnothing\), and \(\sum_t x_t e(t,r)\ge\sum_{g\in S}q(g,r)\) for every \(r\in R\).
Let \(L\) be the total input bit length; state running times in \(m,\tau,d,L\).

Is deciding whether such a successful coalition exists in \(\mathrm{P}\), or is it NP-hard?
If it is NP-hard, is it nevertheless FPT parameterized by \(\tau\)?

For explicitly listed discrete agents, existence of a successful coalition of exact size \(k\) is polynomial-time solvable for every fixed number of types, an XP result ([source](https://u.cs.biu.ac.il/~sarit/data/articles/On_Agent_Types.pdf)).
The discrete problem is NP-hard and \(\mathrm{W}[1]\)-hard parameterized by \(k\) ([source](https://u.cs.biu.ac.il/~sarit/data/articles/shortetal-aamas09.pdf)). No result settling this exact continuous formulation was located.

Modeling choices made when packaging the task

  • Normalized the society to total mass 1 and restricted the exact target mass to a positive binary rational at most 1.
  • Used representational types, determined by identical accepted-goal sets and endowment vectors, because the continuous input supplies these descriptions.
  • Retained nonnegative integer per-agent endowments from the discrete model; allowed nonnegative binary rational goal demands because they are measured per unit of total population.
  • Allowed empty accepted-goal sets and zero resource quantities, as the supplied discrete definition does.
  • Specified finite nonempty goal and resource sets and a nonempty achieved-goal set, consistent with positive target mass and the successful-coalition convention.
  • Specified real coalition masses and clarified that goals remain indivisible, with additive demands charged once rather than scaled by coalition mass.

1. Result

The problem is \(\mathrm{NP}\)-complete and is \(\mathrm{W}[1]\)-hard parameterized by the support size \(\tau\). Consequently, it is not FPT in \(\tau\) unless \(\mathrm{FPT}=\mathrm{W}[1]\).

Hardness holds even when \(\kappa=1\), every endowment equals \(1\), and every demand belongs to \(\{0,1\}\).

Nevertheless, there is an XP algorithm with running time

\(\displaystyle \left(\sum_{j=1}^{\min\{m,\tau\}}\binom{m}{j}\right)\operatorname{poly}(m,\tau,d,L)\le (m+1)^\tau\operatorname{poly}(m,\tau,d,L).\)

The proofs below apply directly to the stated continuous formulation.

2. Membership in \(\mathrm{NP}\) and an XP algorithm

For a nonempty goal set \(S\subseteq G\), define

\(\displaystyle B(S)=\{t:A_t\cap S\ne\varnothing\},\qquad Q_S(r)=\sum_{g\in S}q(g,r).\)

A successful coalition using \(S\) exists exactly when the following rational linear system is feasible:

\(\displaystyle 0\le x_t\le\mu_t\quad\text{for every }t,\)

\(\displaystyle x_t=0\quad\text{for every }t\notin B(S),\)

\(\displaystyle \sum_{t=1}^{\tau}x_t=\kappa,\)

\(\displaystyle \sum_{t=1}^{\tau}x_t e(t,r)\ge Q_S(r)\quad\text{for every }r\in R.\)

Indeed, forcing unsatisfied types to have zero participation is equivalent to the required implication \(x_t>0\Rightarrow A_t\cap S\ne\varnothing\). All remaining constraints are precisely those in the question.

This system has \(\tau\) variables and \(O(\tau+d)\) constraints. Its encoding length is polynomial in \(L\): summing input rationals produces rationals of polynomial bit length, since a common denominator can be chosen as the product of their denominators. Rational linear-programming feasibility is decidable in polynomial time.

Thus a verifier can take \(S\), encoded by \(m\) bits, as its certificate and check the system in time \(\operatorname{poly}(m,\tau,d,L)\). This proves membership in \(\mathrm{NP}\), despite allowing real participation masses.

Lemma. Whenever a successful coalition exists, one exists using at most \(\tau\) goals.

Proof. Let \((x,S)\) be successful and put \(T_+=\{t:x_t>0\}\). Since \(\kappa>0\), this set is nonempty. For each \(t\in T_+\), choose one goal \(g_t\in A_t\cap S\), and put

\(\displaystyle S'=\{g_t:t\in T_+\}.\)

Then \(S'\) is nonempty, satisfies every participating type, and has size at most \(|T_+|\le\tau\). Moreover, \(S'\subseteq S\) and demands are nonnegative, so

\(\displaystyle Q_{S'}(r)\le Q_S(r)\le\sum_t x_t e(t,r)\)

for every resource \(r\). Hence \((x,S')\) is successful. \(\square\)

Enumerating all nonempty goal sets of size at most \(\min\{m,\tau\}\), and checking each linear system, therefore gives the stated XP running time. In particular, the continuous problem is polynomial-time solvable for every fixed \(\tau\).

3. A reduction from Clique

Let \(H=(V,E)\) be a simple undirected graph with \(n=|V|\), and let \(2\le k\le n\). We construct an instance that admits a successful coalition exactly when \(H\) has a clique of size \(k\).

The restriction \(2\le k\le n\) does not affect either classical or parameterized hardness: excluded cases can be decided directly. We use the standard NP-completeness of Clique and its \(\mathrm{W}[1]\)-completeness parameterized by \(k\). The latter also follows from the \(\mathrm{W}[1]\)-completeness of Independent Set by complementing the graph without changing \(k\). [Downey and Fellows](https://homepages.ecs.vuw.ac.nz/~downey/publications/2.pdf)

Types, masses, and goals

Create exactly \(k\) types, indexed by \(i\in\{1,\ldots,k\}\). Create goals

\(\displaystyle G=\{g_{i,v}:1\le i\le k,\ v\in V\},\)

and give type \(i\) the accepted-goal set

\(\displaystyle A_i=\{g_{i,v}:v\in V\}.\)

These sets are nonempty and pairwise disjoint. Thus the type descriptions are distinct, as required, and \(\tau=k\). The number of goals is \(m=kn\).

Choose positive dyadic masses

\(\displaystyle \mu_i=2^{-i}\quad(1\le i<k),\qquad \mu_k=2^{-(k-1)}.\)

Their sum is \(1\), since

\(\displaystyle \sum_{i=1}^{k-1}2^{-i}+2^{-(k-1)}=1.\)

Set \(\kappa=1\).

Resources, endowments, and demands

For positions \(i<j\), call a vertex pair \((u,v)\) incompatible when either \(u=v\) or \(\{u,v\}\notin E\).

For every such choice of \(i,j,u,v\), create a resource \(r_{i,j,u,v}\). Also create a dummy resource \(r_0\), ensuring that \(R\) is nonempty.

Set

\(\displaystyle e(i,r)=1\quad\text{for every type }i\text{ and resource }r.\)

For an incompatibility resource \(r_{i,j,u,v}\), set

\(\displaystyle q(g,r_{i,j,u,v})= \begin{cases} 1,&g\in\{g_{i,u},g_{j,v}\},\\ 0,&\text{otherwise}. \end{cases}\)

All goals have zero demand on \(r_0\). These demands are charged once per selected goal, exactly as stipulated in the question.

The number of resources satisfies

\(\displaystyle d=1+\binom{k}{2}\bigl(n^2-2|E|\bigr)\le 1+\binom{k}{2}n^2.\)

All demands and endowments use constant-size numerical encodings; the masses have total bit length \(O(k^2)\). With an explicit table encoding, both the output length and construction time are bounded by \(O(k^3n^3\log(kn+2))\). Since \(k\le n\), this is a polynomial-time construction.

Why the coalition masses are forced

Any feasible participation vector satisfies

\(\displaystyle \sum_{i=1}^k(\mu_i-x_i)=1-\kappa=0.\)

Each summand is nonnegative. Therefore every summand is zero, giving

\(\displaystyle x_i=\mu_i>0\quad\text{for every }i.\)

Consequently, every type must be satisfied. Also, every resource has available amount exactly

\(\displaystyle \sum_i x_i e(i,r)=\sum_i\mu_i=1.\)

Forward implication

Suppose \(H\) has a clique consisting of distinct vertices \(v_1,\ldots,v_k\). Select

\(\displaystyle S=\{g_{i,v_i}:1\le i\le k\},\qquad x_i=\mu_i.\)

Every type accepts its corresponding selected goal.

Consider any incompatibility resource \(r_{i,j,u,v}\). Its demand could equal \(2\) only if both \(g_{i,u}\) and \(g_{j,v}\) were selected. This would imply \(u=v_i\) and \(v=v_j\). But \(v_i,v_j\) are distinct adjacent vertices, so that pair is compatible, contradicting the existence of this resource.

Thus each incompatibility resource has demand at most \(1\), equal to its available amount. The dummy resource has demand zero. Hence \((x,S)\) is successful.

Reverse implication

Suppose \((x,S)\) is successful. Every \(x_i\) is positive, so \(S\cap A_i\ne\varnothing\) for every \(i\). Choose one vertex \(v_i\) such that \(g_{i,v_i}\in S\).

Fix \(i<j\). If \(v_i=v_j\) or \(\{v_i,v_j\}\notin E\), the construction contains resource \(r_{i,j,v_i,v_j}\). Both of its demand-incurring goals belong to \(S\), so its total demand is \(2\). Its available amount is \(1\), a contradiction.

Therefore the vertices \(v_1,\ldots,v_k\) are pairwise distinct and pairwise adjacent. They form a clique of size \(k\).

This proves the equivalence in both directions.

4. Complexity consequences

The construction is a polynomial-time reduction from Clique. Together with membership in \(\mathrm{NP}\), it proves that the continuous problem is \(\mathrm{NP}\)-complete.

It is also a parameterized reduction: the output support size is exactly \(\tau=k\). Hence the problem is \(\mathrm{W}[1]\)-hard parameterized by \(\tau\). An algorithm running in time

\(\displaystyle f(\tau)(m+\tau+d+L)^c,\)

with computable \(f\) and constant \(c\) independent of \(\tau\), would give an FPT algorithm for parameterized Clique and imply \(\mathrm{FPT}=\mathrm{W}[1]\).

The XP algorithm is consistent with the cited discrete fixed-type result: polynomial time for each fixed number of types does not require a polynomial exponent independent of that number. [Shrot, Aumann, and Kraus, Theorem 5.3](https://u.cs.biu.ac.il/~sarit/data/articles/On_Agent_Types.pdf)
