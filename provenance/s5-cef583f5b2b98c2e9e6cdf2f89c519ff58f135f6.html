The continuous mirror question, as graded

Input a finite set of delegation roles \(T\), rational masses \(\mu_t>0\) summing to \(1\), rational transition probabilities \(q_{su}\) with \(\sum_u q_{su}\leq 1\), a rational selected share \(\kappa\), and a rational threshold \(c\). Choose \(x_t\in[0,\mu_t]\) with \(\sum_t x_t=\kappa\). For each selected type \(t\), define the first-hit probabilities by \(h_{st}=q_{st}x_t/\mu_t+\sum_u q_{su}(\mu_u-x_u)h_{ut}/\mu_u\), and let \(b_t=x_t+\sum_s(\mu_s-x_s)h_{st}\). Decide whether some \(x\) satisfies \(b_t\geq c x_t\) for every \(t\) with \(x_t>0\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) delegation types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not all possible types.
Input also consists of binary rational probabilities \(q_{su}\geq0\) with \(\sum_u q_{su}\leq1\), a selected share \(0<\kappa\leq1\), and a threshold \(c\geq0\). Let \(m\) count positive transitions and \(L\) be the total input bit length; self-transitions are allowed.
Choose real masses \(0\leq x_t\leq\mu_t\) with \(\sum_t x_t=\kappa\). Selected mass absorbs delegations and never delegates onward.
From unselected type \(s\), move to type \(u\) with probability \(q_{su}\); there, absorb into its selected mass with probability \(x_u/\mu_u\), otherwise continue from its unselected mass. Missing transition probability terminates without representation; trajectories that never absorb contribute nothing.
For each \(t\) with \(x_t>0\), define \(h_{st}\) as the probability of eventual absorption into selected type \(t\), equivalently the least nonnegative solution of \(h_{st}=q_{st}x_t/\mu_t+\sum_{u\in T}q_{su}(\mu_u-x_u)h_{ut}/\mu_u\).
Define represented mass \(b_t=x_t+\sum_{s\in T}(\mu_s-x_s)h_{st}\). Feasibility means \(b_t\geq c x_t\) for every \(t\) with \(x_t>0\).

Is deciding feasibility solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For discrete agents, selecting a prescribed number of absorbing vertices so that each receives at least a threshold of represented weight is \(\mathrm{NP}\)-hard on general directed graphs and polynomial-time solvable when every vertex has at most one outgoing edge. [Source](https://arxiv.org/html/2608.13188v1)
No result settling exactly the continuous formulation above was identified in the literature search.

Modeling choices made when packaging the task

  • Restricted the selected share to 0 < kappa <= 1, reflecting a nonempty slate within the society, and the threshold to c >= 0, matching the discrete decision definition.
  • Specified nonnegative transition probabilities and allowed self-transitions, consistent with the delegation graph domain.
  • Resolved potentially nonunique first-hit equations by taking their least nonnegative solution; nonabsorbing trajectories and missing transition probability yield no represented mass.
  • Specified real-valued selections, since input rationality does not impose rationality on continuous solutions.
  • Defined m as the number of positive transitions and L as total input bit length.

Result

The continuous feasibility problem is \(\mathrm{NP}\)-hard, already for the fixed threshold \(c=2\). The reduction below allows arbitrary real selected masses; its soundness does not assume integral selection.

For \(c\leq1\), feasibility is immediate: choose \(x_t=\kappa\mu_t\), and use \(b_t\geq x_t\). The hardness concerns the general problem.

1. A weighted independent-set lemma

For a simple undirected graph \(G\), let \(N[i]\) denote the closed neighborhood of vertex \(i\), and let \(\alpha(G)\) denote its maximum independent-set size.

Lemma. Suppose \(w_i\geq0\) and, whenever \(w_i>0\),

\(\displaystyle \sum_{j\in N[i]}w_j\leq1.\)

Then \(\displaystyle \sum_iw_i\leq\alpha(G)\).

Proof. Restrict to the induced graph on vertices with positive weight. Independently assign vertex \(i\) an exponential random variable \(E_i\) of rate \(w_i\). Select \(i\) if its variable is smaller than those of all its neighbors.

With probability one there are no ties. The selected vertices form an independent set: adjacent vertices cannot both have the smaller variable.

Writing \(\sigma_i=\sum_{j\in N[i]}w_j\), the probability that \(i\) is selected is

\(\displaystyle \Pr(i\text{ is selected})=\int_0^\infty w_i e^{-\sigma_i t}\,dt=\frac{w_i}{\sigma_i}\geq w_i.\)

Consequently,

\(\displaystyle \alpha(G)\geq\mathbb E[\text{number selected}]=\sum_i\frac{w_i}{\sigma_i}\geq\sum_iw_i.\)

This proves the lemma.

2. Construction of the society

We reduce from Independent Set: given a simple undirected graph \(G\) on \(n\geq1\) vertices and an integer \(1\leq k\leq n\), decide whether \(\alpha(G)\geq k\). This is a standard \(\mathrm{NP}\)-complete problem; see, for example, [Trevisan’s complexity notes](https://theory.stanford.edu/~trevisan/notes/complexitynotes01.pdf).

Let \(A\) be the adjacency matrix of \(G\), and define

\(\displaystyle \varepsilon=\frac1{2n},\qquad \lambda=\frac1{16n^3},\qquad C=2\bigl(1+\lambda(1+\varepsilon)\bigr).\)

There are two supported types per vertex: a candidate type \(v_i\) and a feeder type \(p_i\).

Write \(d_i\) for the degree of vertex \(i\), and put

\(\displaystyle D=\sum_{i=1}^n(d_i+1),\qquad \mu=\frac1{C(n-\lambda D)}.\)

Assign masses

\(\displaystyle \mu_{v_i}=\mu,\qquad \mu_{p_i}=\mu\bigl(C-1-C\lambda(d_i+1)\bigr).\)

The positive transitions are

\(\displaystyle q_{p_i v_i}=1,\qquad q_{v_i v_j}=\lambda\quad\text{when }j=i\text{ or }\{i,j\}\in E(G).\)

All other transitions are zero. Set

\(\displaystyle c=2,\qquad \kappa=k\mu.\)

We check that this is a valid input. Let

\(\displaystyle r=n\lambda=\frac1{16n^2}\leq\frac1{16}.\)

Each candidate’s outgoing probability is \(\lambda(d_i+1)\leq r\), while each feeder’s outgoing probability is one. Moreover,

\(\displaystyle C-1-C\lambda(d_i+1)\geq C(1-r)-1\geq2\cdot\frac{15}{16}-1=\frac78>0.\)

Thus every listed type has positive mass. The masses sum to

\(\displaystyle \sum_i(\mu_{v_i}+\mu_{p_i})=\mu C(n-\lambda D)=1.\)

Since the feeders have positive total mass, \(n\mu<1\), and hence \(0<\kappa=k\mu<1\).

3. Absorption and occupation identities

No transition enters a feeder. Therefore its represented mass is exactly its selected mass:

\(\displaystyle b_{p_i}=x_{p_i}.\)

Because \(c=2\), every feasible selection must satisfy \(x_{p_i}=0\).

We henceforth consider selections with all feeders unselected, and abbreviate \(x_i=x_{v_i}\). Define

\(\displaystyle a_i=\frac{x_i}{\mu},\qquad P=\lambda(I+A),\qquad g_i=\mu+\mu_{p_i}.\)

The matrix \(P\) is symmetric, nonnegative, and has maximum row sum at most \(r<1\).

Let \(z_i\) be the total expected mass of visits to candidate \(v_i\), counting each visit immediately before its absorption decision. Initial candidate mass contributes \(\mu\), and its feeder contributes \(\mu_{p_i}\). On any visit to candidate \(j\), the fraction continuing is \(1-a_j\). Thus

\(\displaystyle z=g+P\operatorname{diag}(1-a_i)z.\)

This equation has a unique finite nonnegative solution: the matrix multiplying \(z\) has maximum row sum at most \(r<1\), so its inverse is given by a convergent nonnegative geometric series.

These visit counts agree with the task’s least-solution semantics. Indeed, after entering a candidate, the probability of continuing for another candidate step is at most \(r\); infinite continuation consequently has probability zero. Summing absorption over visits gives

\(\displaystyle b_i=a_i z_i.\)

In particular, for \(x_i>0\),

\(\displaystyle \frac{b_i}{x_i}=\frac{z_i}{\mu}.\)

Our feeder masses were chosen so that

\(\displaystyle g_i=C\mu-C\mu\lambda(d_i+1).\)

Consequently the vector \(z^0=C\mu\mathbf1\) satisfies \(z^0=g+Pz^0\).

Using \(b_i=a_i z_i\), the occupation equation also reads \(z=g+P(z-b)\). Subtracting it from the equation for \(z^0\) yields

\(\displaystyle z^0-z=P(z^0-z)+Pb.\)

Therefore

\(\displaystyle z^0-z=Rb,\qquad R=(I-P)^{-1}P=\sum_{\ell=1}^\infty P^\ell.\)

Every matrix in this series is nonnegative, so

\(\displaystyle R\geq P,\qquad 0\leq b_i\leq z_i\leq C\mu.\)

We will also use

\(\displaystyle \|R-P\|_\infty\leq\sum_{\ell=2}^\infty r^\ell=\frac{r^2}{1-r}.\)

4. Every feasible fractional selection implies a large independent set

Suppose the constructed instance has a feasible selection. Its feeders are unselected, so

\(\displaystyle \sum_i x_i=k\mu.\)

Whenever \(x_i>0\), feasibility and the occupation identity imply

\(\displaystyle z_i\geq2\mu.\)

Hence, for such \(i\),

\(\displaystyle (Rb)_i=C\mu-z_i\leq(C-2)\mu=2\lambda(1+\varepsilon)\mu.\)

On the other hand, feasibility gives \(b_j\geq2x_j\) for every candidate \(j\): this is the required inequality when \(x_j>0\), and both sides vanish when \(x_j=0\). Since \(R\geq P\),

\(\displaystyle (Rb)_i\geq(Pb)_i=\lambda\sum_{j\in N[i]}b_j\geq2\lambda\sum_{j\in N[i]}x_j.\)

Combining these inequalities gives, whenever \(x_i>0\),

\(\displaystyle \sum_{j\in N[i]}x_j\leq(1+\varepsilon)\mu.\)

Apply the lemma to \(w_i=x_i/((1+\varepsilon)\mu)\). It follows that

\(\displaystyle k\mu=\sum_i x_i\leq(1+\varepsilon)\mu\,\alpha(G).\)

If \(\alpha(G)\leq k-1\), this would imply

\(\displaystyle k\leq(1+\varepsilon)(k-1)=k-1+\frac{k-1}{2n}<k,\)

a contradiction. Thus feasibility implies \(\alpha(G)\geq k\).

This argument covers all real fractional selections.

5. An independent set gives a feasible selection

Conversely, suppose \(G\) contains an independent set \(S\) of size exactly \(k\). Select every candidate in \(S\) completely:

\(\displaystyle x_i=\mu\text{ for }i\in S,\qquad x_i=0\text{ for }i\notin S,\qquad x_{p_i}=0.\)

The selected share is exactly \(k\mu=\kappa\). We prove feasibility.

For \(i\in S\), full selection gives \(b_i=z_i\). For \(j\notin S\), \(b_j=0\). Independence of \(S\) therefore implies

\(\displaystyle (Pb)_i=\lambda z_i\qquad(i\in S).\)

Define \(e=(R-P)b\). The occupation identity becomes, for \(i\in S\),

\(\displaystyle C\mu-z_i=\lambda z_i+e_i,\qquad z_i=\frac{C\mu-e_i}{1+\lambda}.\)

Because \(0\leq b_j\leq C\mu\),

\(\displaystyle 0\leq e_i\leq C\mu\frac{r^2}{1-r}.\)

Now \(\lambda\leq1/16\), \(\varepsilon\leq1/2\), and therefore \(C\leq35/16<3\). Together with \(r\leq1/16\), this gives

\(\displaystyle e_i\leq4\mu n^2\lambda^2=\frac{\lambda\varepsilon\mu}{2}.\)

Consequently,

\(\displaystyle z_i\geq\frac{2(1+\lambda+\lambda\varepsilon)\mu-\lambda\varepsilon\mu/2}{1+\lambda} =2\mu+\frac{3\lambda\varepsilon\mu}{2(1+\lambda)}>2\mu.\)

Thus every selected candidate satisfies

\(\displaystyle b_i=z_i\geq2\mu=2x_i.\)

The selection is feasible.

6. Complexity and conclusion

We have proved the exact equivalence

\(\displaystyle \text{constructed society is feasible}\quad\Longleftrightarrow\quad\alpha(G)\geq k.\)

The construction has precisely \(\tau=2n\) supported types and \(m=2n+2|E(G)|\) positive transitions. Every mass and parameter is a rational number whose numerator and denominator have \(O(\log n)\) bits. The construction therefore has polynomial total bit length and is computable in polynomial time.

This proves \(\mathrm{NP}\)-hardness of the continuous formulation, even with \(c=2\), feeders having one outgoing transition, and candidate transition row sums at most \(1/16\). A polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
