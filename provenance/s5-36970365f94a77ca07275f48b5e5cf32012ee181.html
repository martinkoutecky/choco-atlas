The continuous mirror question, as graded

Given a rational distribution μ over applicant types, each recording its applications, first choice, and scores, together with overlapping quota sets p and per-capita quotas q_p, compute the set F of types whose first-choice application is selected by the Hungarian score-tier choice rule for every quota set containing that programme. Certify that, whenever a stable mass allocation exists, all of each type's mass in F is assigned to its first choice in every such allocation.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq1\) programmes. A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_a\) a binary rational, with \(\sum_a\mu_a=1\). Here \(\tau\) is the support size, not the number of possible types. Each type has a nonempty strict preference list of acceptable programmes, first choice \(f_a\), and nonnegative integer application scores encoded in binary; being unmatched is worse than every listed programme.
The input includes \(k\) nonempty, possibly overlapping quota sets \(p\subseteq C\), including every singleton, with nonnegative binary rational per-capita upper quotas \(q_p\). A type's scores at all listed programmes in any one quota set must agree; denote this common score by \(s_{ap}\).
For each \(p\), retain each type's most preferred application inside \(p\), carrying mass \(\mu_a\). The Hungarian choice \(\operatorname{Ch}^{H}_p\) accepts complete score tiers in descending order until the next tier would exceed \(q_p\), then rejects that tier and all lower tiers; ties are never split.
For each \(p\), let \(T_p=\{0\}\cup\{s_{ap}+1:a\text{ applies inside }p\}\). A cutoff vector \(t\in\prod_pT_p\) assigns all of each type's mass to its most preferred listed programme \(j\) satisfying \(s_{ap}\geq t_p\) for every \(p\ni j\), or leaves it unmatched if none qualifies.
Such a mass allocation is stable if every quota is respected and, for every \(p\) with \(t_p>0\), lowering \(t_p\) to the preceding element of \(T_p\), holding all other cutoffs fixed and recomputing assignments, makes the mass assigned inside \(p\) strictly exceed \(q_p\).
Define \(F=\{a:(a,f_a)\in\operatorname{Ch}^{H}_p\text{ for every }p\ni f_a\}\). Let \(L\) be the total input bit length; state running times in \(m,\tau,k,L\).

Can \(F\) be computed in polynomial time in \(m,\tau,k,L\), or is deciding membership in \(F\) NP-hard? Does every stable mass allocation, whenever one exists, assign all mass of every type in \(F\) to its first choice?

In the finite model, the corresponding first-choice selection condition guarantees inclusion in every Hungarian stable allocation ([verified discrete result](https://unipub.lib.uni-corvinus.hu/6841/1/1-s2.0-S0377221721007232-main.pdf)). No result settling this exact mass formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total applicant mass to one, so the supplied per-capita quotas directly bound assigned masses.
  • Specified complete strict preference lists, nonempty application lists, and unmatched status as worse than every acceptable programme.
  • Carried over nonnegative integer scores, score consistency within each quota set, and inclusion of every singleton quota; quotas may be zero.
  • Resolved selection from all applications by retaining each type's most preferred application within the quota set and counting its mass once.
  • Defined mass allocations through common cutoffs, preserving equal treatment by assigning each type's entire mass together rather than splitting tied mass.
  • Specified cutoff domains and the next-tier lowering operation, including the zero boundary, to express the discrete non-wastefulness condition without irrelevant gaps between scores.
  • Separated computation of the prescribed set from the universal first-choice guarantee, since the anchor establishes a forcing property rather than a complexity classification.

Result

Both questions are resolved:

  • \(F\) can be computed in polynomial time in \(m,\tau,k,L\).
  • Every stable mass allocation assigns all mass of every type in \(F\) to its first choice.

The proof allows arbitrary overlap among quota sets. It directly establishes the mass analogue of Lemma 3 in the [cited paper](https://unipub.lib.uni-corvinus.hu/6841/1/1-s2.0-S0377221721007232-main.pdf), without expanding rational masses into individual applicants.

1. Reference cutoffs and Hungarian choice

For each quota set \(p\), define
\( A_p=\{a:a\text{ lists at least one programme in }p\}. \)
The score-consistency hypothesis makes \(s_{ap}\) well-defined for every \(a\in A_p\).

For any nonnegative integer \(u\), define the total qualifying applicant mass
\( W_p(u)=\sum_{a\in A_p:\,s_{ap}\geq u}\mu_a. \)
Each type is counted once, consistently with retaining its most preferred application inside \(p\). The function \(W_p\) is nonincreasing.

Define the reference cutoff
\( h_p=\min\{u\in T_p:W_p(u)\leq q_p\}. \)
This minimum exists: if \(A_p\) is empty, \(W_p(0)=0\); otherwise, \(1+\max_{a\in A_p}s_{ap}\) belongs to \(T_p\) and admits no mass.

Lemma 1. The Hungarian choice for \(p\) accepts precisely the retained applications of types satisfying \(s_{ap}\geq h_p\).

Proof. If \(A_p\) is empty, the statement is immediate. Otherwise, write its distinct scores in descending order as
\( r_1>r_2>\cdots>r_d, \)
and define cumulative tier masses by
\( S_0=0,\qquad S_i=\sum_{a\in A_p:\,s_{ap}\geq r_i}\mu_a \quad(1\leq i\leq d). \)

Every tier has positive mass, so these cumulative masses strictly increase. Let
\( \ell=\max\{i\in\{0,\ldots,d\}:S_i\leq q_p\}. \)
The Hungarian rule accepts exactly the first \(\ell\) tiers.

If \(\ell=d\), all applicant mass fits, so \(h_p=0\), which accepts every tier.

If \(\ell<d\), put \(v=r_{\ell+1}+1\). Then \(v\in T_p\) and
\( W_p(v)=S_\ell\leq q_p. \)
Every \(u\in T_p\) with \(u<v\) is an integer satisfying \(u\leq r_{\ell+1}\). Consequently,
\( W_p(u)\geq S_{\ell+1}>q_p. \)
Thus \(h_p=v\), which accepts exactly the first \(\ell\) tiers. This proves the lemma.

Whenever \(f_a\in p\), the retained application of type \(a\) inside \(p\) is its first choice. Hence Lemma 1 gives the characterization
\( a\in F \quad\Longleftrightarrow\quad s_{ap}\geq h_p\text{ for every }p\ni f_a. \)

Equivalently, membership can be checked using cumulative tier masses:
\( a\in F \quad\Longleftrightarrow\quad W_p(s_{ap})\leq q_p\text{ for every }p\ni f_a. \)

2. Polynomial-time computation

An explicit algorithm is:

  • Build programme-membership tables for the quota sets.
  • For each \(p\), scan each type’s preference list to identify its retained application inside \(p\), if any.
  • Sort these types by descending \(s_{ap}\), group equal scores, and accumulate complete tier masses. Stop at the first tier whose inclusion exceeds \(q_p\). This computes \(h_p\).
  • Include \(a\) in \(F\) exactly when \(s_{ap}\geq h_p\) for every quota set containing \(f_a\).

There are at most \(\tau\) retained applications per quota set. Preference scanning uses \(O(k\tau m)\) operations; sorting uses \(O(k\tau\log(\tau+1))\) score comparisons.

For exact arithmetic, write all masses and quotas as rational numbers and let \(D\) be the product of their denominators. Because their encodings are included in the total input length \(L\), \(D\) has \(O(L)\) bits. The scaled quantities
\( w_a=D\mu_a,\qquad Q_p=Dq_p \)
are integers with \(O(L)\) bits. Thus every tier test can be performed exactly by comparing an integer cumulative mass with \(Q_p\).

Using schoolbook integer arithmetic, a conservative bit-operation bound for the complete computation is
\( O\!\left((\tau+k)L^2+ k\tau\bigl(m+\log(\tau+1)\bigr)L\right). \)
Here the first term covers construction of the common denominator and scaled integers; the second covers scanning, sorting, accumulation, and membership checks.

Therefore computing the entire set \(F\), and in particular deciding membership in it, is polynomial-time solvable in the stated input parameters.

3. Every stable cutoff is bounded by its reference cutoff

Lemma 2. Every stable cutoff vector \(t\) satisfies \(t_p\leq h_p\) for every quota set \(p\).

Proof. Suppose instead that \(t_p>h_p\) for some \(p\). Since both values belong to \(T_p\), the predecessor \(u\) of \(t_p\) in \(T_p\) satisfies \(u\geq h_p\). Also \(t_p>0\).

Lower only the cutoff for \(p\) to \(u\), and recompute assignments as prescribed in the stability definition. Let \(B\) be the types now assigned to programmes inside \(p\).

For each \(b\in B\), its assigned programme lies in \(p\), so eligibility requires \(s_{bp}\geq u\). Thus
\( B\subseteq\{b\in A_p:s_{bp}\geq u\}. \)
The mass assigned inside \(p\) is therefore at most
\( \sum_{b\in B}\mu_b \leq W_p(u) \leq W_p(h_p) \leq q_p. \)

This contradicts stability, which requires that lowering the positive cutoff \(t_p\) to its predecessor make the assigned mass inside \(p\) strictly exceed \(q_p\). Hence \(t_p\leq h_p\).

This argument remains valid with overlapping quotas: every type assigned inside \(p\) must pass \(p\)’s cutoff, regardless of the other eligibility conditions.

4. First-choice inclusion in every stable allocation

Let \(t\) induce any stable mass allocation, and fix \(a\in F\).

For every quota set \(p\) containing \(f_a\), Lemma 1 and the definition of \(F\) give \(s_{ap}\geq h_p\). Lemma 2 gives \(h_p\geq t_p\). Consequently,
\( s_{ap}\geq h_p\geq t_p \qquad\text{for every }p\ni f_a. \)

Thus \(f_a\) satisfies every cutoff required for eligibility. Since it is type \(a\)’s first choice, the assignment rule assigns all of its mass \(\mu_a\) to \(f_a\).

This proves the preservation statement for every stable mass allocation whenever one exists.
