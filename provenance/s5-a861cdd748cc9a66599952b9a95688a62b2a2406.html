The continuous mirror question, as graded

Given a finite set of provider types \(T\), masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), rates \(\lambda_t<\xi_t\), fixed \(\alpha\in(0,1]\), and a required coalition mass vector \(z\in[0,\mu]\), find the coordinatewise largest minimizer \(y^*\) of \(V_\alpha(y)=\frac{\Lambda(y)^\alpha}{\Xi(y)^\alpha-\Lambda(y)^\alpha}\) over \(z\le y\le\mu\), and return its cost, where \(\Lambda(y)=\sum_t y_t\lambda_t\), \(\Xi(y)=\sum_t y_t\xi_t\), and \(V_\alpha(0)=0\).

A society is given by its support: a nonempty list \(T\) of \(\tau\) provider types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has binary-rational rates \(0<\lambda_t<\xi_t\). Fix a rational constant \(\alpha\in(0,1]\). The input also specifies binary-rational required masses \(0\le z_t\le\mu_t\), including the possibility \(z=0\).
A coalition is a real mass vector \(y\) with \(z\le y\le\mu\), with inequalities interpreted coordinatewise. Define \(\Lambda(y)=\sum_{t\in T}y_t\lambda_t\), \(\Xi(y)=\sum_{t\in T}y_t\xi_t\), and \(V_\alpha(y)=\Lambda(y)^\alpha/(\Xi(y)^\alpha-\Lambda(y)^\alpha)\) for \(y\ne0\), with \(V_\alpha(0)=0\).
The computational problem is to find the coordinatewise largest minimizer \(y^*\): a minimizer dominating every other minimizer in every coordinate, and return its exact cost. Costs may be represented by expressions using rational numbers and the fixed power \(\alpha\).
Let \(L\) be the total binary input length. State running times in \(\tau\) and \(L\); this model has no separate \(m\) parameter, and \(\alpha\) is fixed.

Result

The problem is polynomial-time solvable. An exact algorithm uses \(O(\tau\log(\tau+1))\) arithmetic operations, or conservatively \(O(\tau\log(\tau+1)L^2)\) bit operations under standard binary encoding of rational numbers. After utilization ratios are ordered, only \(O(\tau)\) arithmetic operations are needed.

The proof below directly handles real mass vectors. The related indivisible-coalition construction appears in Section 3 of [Anily and Haviv](https://coller.tau.ac.il/sites/coller.tau.ac.il/files/media_server/Recanati/management/anily/35.pdf).

1. Zero required mass and reduction to a ratio

For every nonzero feasible vector \(y\), positivity of the rates and \(\lambda_t<\xi_t\) imply

\( 0<\Lambda(y)<\Xi(y). \)

Consequently, \(V_\alpha(y)>0\). If \(z=0\), the zero vector is feasible and has cost zero. It is therefore the unique minimizer, so the answer is \(y^*=0\), with exact cost zero.

Henceforth assume \(z\ne0\). Define the feasible box

\( \mathcal B=\{y\in\mathbb R^T:z\le y\le\mu\}. \)

Every \(y\in\mathcal B\) satisfies \(\Xi(y)\ge\Xi(z)>0\). Define

\( R(y)=\frac{\Lambda(y)}{\Xi(y)},\qquad f_\alpha(r)=\frac{r^\alpha}{1-r^\alpha}\quad(0<r<1). \)

Then \(V_\alpha(y)=f_\alpha(R(y))\). For \(0<a<b<1\),

\( f_\alpha(b)-f_\alpha(a) =\frac{b^\alpha-a^\alpha}{(1-b^\alpha)(1-a^\alpha)}>0, \)

because \(\alpha>0\). Thus minimizing \(V_\alpha\) is equivalent to minimizing \(R\), with exactly the same minimizers.

The box \(\mathcal B\) is nonempty and compact, and \(R\) is continuous on it because its denominator is bounded below by \(\Xi(z)>0\). Therefore its minimum

\( r_*=\min_{y\in\mathcal B}R(y) \)

exists and satisfies \(0<r_*<1\).

2. Complete characterization of the minimizers

Define each type’s utilization by \(u_t=\lambda_t/\xi_t\), and put

\( a_t=\lambda_t-r_*\xi_t=\xi_t(u_t-r_*). \)

Consider the linear function

\( F(y)=\Lambda(y)-r_*\Xi(y)=\sum_{t\in T}a_ty_t. \)

Since \(\Xi(y)>0\), the definition of \(r_*\) gives \(F(y)\ge0\) throughout \(\mathcal B\), with equality precisely when \(R(y)=r_*\). In particular,

\( \min_{y\in\mathcal B}F(y)=0. \)

Linear minimization over this box separates by coordinate. Its minimum is

\( F_{\min} =\sum_{a_t>0}a_tz_t+\sum_{a_t<0}a_t\mu_t. \)

For any feasible \(y\),

\( F(y)-F_{\min} =\sum_{a_t>0}a_t(y_t-z_t) +\sum_{a_t<0}(-a_t)(\mu_t-y_t). \)

Every summand is nonnegative. Since \(F_{\min}=0\), equality holds exactly when every summand vanishes. Thus all cost minimizers are characterized as follows:

  • If \(u_t<r_*\), then \(y_t=\mu_t\).
  • If \(u_t>r_*\), then \(y_t=z_t\).
  • If \(u_t=r_*\), then \(y_t\) may be any number in \([z_t,\mu_t]\).

In particular, a coordinatewise largest minimizer exists: choose \(y_t^*=\mu_t\) whenever \(u_t\le r_*\), and choose \(y_t^*=z_t\) whenever \(u_t>r_*\).

This vector is a minimizer by the characterization. Every other minimizer agrees with it at the strict inequalities and is at most \(\mu_t=y_t^*\) at a tie. Hence it dominates every other minimizer.

3. Exact algorithm using sorted prefixes

Order the types so that

\( u_1\le u_2\le\cdots\le u_\tau, \)

breaking ties arbitrarily. For each \(k\in\{0,\ldots,\tau\}\), define a candidate \(y^{(k)}\) by setting its first \(k\) coordinates to their upper bounds \(\mu_t\), and its remaining coordinates to their lower bounds \(z_t\).

Compute the totals by initializing

\( A_0=\sum_{t=1}^{\tau}z_t\lambda_t,\qquad B_0=\sum_{t=1}^{\tau}z_t\xi_t, \)

and updating, for \(k=1,\ldots,\tau\),

\( A_k=A_{k-1}+(\mu_k-z_k)\lambda_k,\qquad B_k=B_{k-1}+(\mu_k-z_k)\xi_k. \)

Here \(A_k=\Lambda(y^{(k)})\) and \(B_k=\Xi(y^{(k)})>0\).

Let \(k_*=\lvert\{t:u_t\le r_*\}\rvert\). Section 2 shows that \(y^{(k_*)}=y^*\). Thus one of these candidates attains the global minimum. Conversely, every candidate is feasible, so none has ratio below \(r_*\). Therefore

\( r_*=\min_{0\le k\le\tau}\frac{A_k}{B_k}. \)

This proves the following algorithm correct:

  • If \(z=0\), return the zero vector and cost zero.
  • Sort the types by utilization.
  • Scan the \(\tau+1\) prefix candidates and compute their minimum ratio \(r_*\).
  • Return \(y_t^*=\mu_t\) if \(\lambda_t\le r_*\xi_t\), and \(y_t^*=z_t\) otherwise.
  • Return the exact cost expression

\( V_\alpha(y^*)=\frac{r_*^\alpha}{1-r_*^\alpha}. \)

All comparisons are rational comparisons. For example, candidate ratios are compared by cross multiplication:

\( \frac{A_i}{B_i}\le\frac{A_j}{B_j} \quad\Longleftrightarrow\quad A_iB_j\le A_jB_i, \)

using positivity of both denominators. No comparison or numerical approximation of irrational powers is required.

4. Binary running time and output size

Sorting takes \(O(\tau\log(\tau+1))\) rational comparisons. Initialization, the prefix scan, and reconstruction each take \(O(\tau)\) arithmetic operations. The scan is linear once the utilization order is available.

To verify polynomial bit complexity, write the input rationals as binary-encoded numerator–denominator pairs. Let \(D\) be the product of the denominators of all input masses, required masses, and rates. Its binary length is \(O(L)\). Each product \(z_t\lambda_t\), \(\mu_t\lambda_t\), \(z_t\xi_t\), or \(\mu_t\xi_t\) has denominator dividing \(D\).

Accordingly, store the prefix totals as integers \(DA_k\) and \(DB_k\). They have \(O(L)\) bits: every candidate satisfies \(\sum_t y_t^{(k)}\le1\), so

\( A_k\le\max_t\lambda_t,\qquad B_k\le\max_t\xi_t, \)

and these maxima, as well as \(D\), have \(O(L)\)-bit representations.

Constructing the scaled contributions, updating totals, and comparing ratios therefore use integers of \(O(L)\) bits. Schoolbook integer arithmetic gives the conservative bound

\( O\!\left(\tau\log(\tau+1)L^2\right) \)

bit operations.

Every coordinate of \(y^*\) is copied from an input endpoint. The ratio \(r_*\) has an \(O(L)\)-bit rational representation, and the permitted expression for its cost has polynomial length because \(\alpha\) is fixed.

Thus both the coordinatewise largest minimizer and its exact cost are computable in polynomial time.
