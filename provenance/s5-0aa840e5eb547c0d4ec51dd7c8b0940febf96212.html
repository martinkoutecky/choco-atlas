The continuous mirror question, as graded

Given finite type sets \(A\) and \(B\), rational type masses \(\mu_t\), integral per-agent capacities, acceptability lists, and weak rankings over opposite-side types, compute a Pareto stable mass matching. Represent each type’s mass by distributions over integral partner-count vectors, require those distributions to sum to the input masses and their type-pair link masses to balance, and require that no positive mass of mutually improving pairs can match or that any feasible reassignment can make almost every agent weakly better off and positive mass strictly better off. Is there an exact algorithm polynomial in support size \(\tau\) and binary input length \(L\)?

Packaged proof task (what the prover saw — nothing else)

Let \(A,B\) be disjoint nonempty finite type sets. A society is given by its support: the list of its \(\tau=|A|+|B|\) types with positive mass, each mass \(\mu_t\) a binary rational; \(\tau\) is the support size, not the number of possible types. Assume \(\sum_t\mu_t=1\), without requiring equal masses on the two sides. Write \(m=\max\{|A|,|B|\}\) and let \(L\) be the total binary input length.
Each type \(t\) has a binary-encoded capacity \(q_t\in\mathbb Z_{\ge0}\) and a transitive weak ranking of its acceptable opposite-side types, all strictly preferred to an empty slot. Only mutually acceptable links are allowed.
Let \(K_t\) contain the integral partner-count vectors \(k\) with \(\sum_u k_u\le q_t\), supported on mutually acceptable types. Multiple partners of the same type are allowed, but partners are distinct individuals in an atomless population.
A mass matching consists of distributions \(x_t(k)\ge0\) satisfying \(\sum_{k\in K_t}x_t(k)=\mu_t\) and \(\sum_{k\in K_a}k_bx_a(k)=\sum_{k\in K_b}k_ax_b(k)\) for every \(a\in A,b\in B\). Represent the output by listing only positive entries, with binary rational weights and binary integral vectors.
For each rank prefix \(P\) of type \(t\)'s acceptable list, define \(\ell\succeq_t k\) exactly when \(\sum_{u\in P}\ell_u\ge\sum_{u\in P}k_u\) for every such prefix; define \(\ell\succ_t k\) when additionally one inequality is strict. Other bundle pairs may be incomparable.
An agent with vector \(k\) strictly wants a new partner of type \(u\) if \(\sum_v k_v<q_t\), or if \(k_v>0\) for some \(v\) with \(u\succ_t v\), allowing that worse link to be dropped. Pairwise stability means no mutually acceptable \(a,b\) have positive masses on both sides strictly wanting such a new link; existing links between their types do not preclude blocking.
A Pareto improvement is another feasible mass matching \(y\), together with nonnegative couplings \(\gamma_t(k,\ell)\) whose row marginals are \(x_t\) and column marginals are \(y_t\), supported on \(\ell\succeq_t k\), with \(\sum_t\sum_{\ell\succ_t k}\gamma_t(k,\ell)>0\). Competing matchings and couplings may have real weights. Pareto stability requires pairwise stability and absence of any Pareto improvement.
Is computing a Pareto stable mass matching, or reporting that none exists, solvable in time polynomial in \(m,\tau,L\), or is this search problem NP-hard?
For finite individually listed agents with the same bundle partial order, a Pareto stable matching always exists and is computable in polynomial time; [Chen and Li](https://www.sciencedirect.com/science/article/abs/pii/S0304406819300400) also establish an efficient construction with weak preferences on both sides.
No exact algorithm or hardness classification for the mass matching problem defined here was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to one, without imposing equal total masses on the two sides.
  • Allowed nonnegative integral capacities, including zero, and encoded capacities in binary.
  • Specified the responsive lattice preference as rank-prefix dominance, retaining incomparability rather than completing the bundle order.
  • Interpreted partner-count vectors as allowing multiple distinct individuals of the same opposite-side type in an atomless population.
  • Restored the blocking move that drops a strictly worse existing partner; existing links between types do not exhaust possible new individual pairs.
  • Defined individual-preserving Pareto reassignment through couplings of old and new bundles, allowing real-valued competing assignments.
  • Specified sparse rational output and included reporting nonexistence because the discrete existence guarantee has not been established for this continuous model.
  • Defined the size parameters m and L explicitly.

Result

The search problem is solvable in time polynomial in \(m,\tau,L\). A Pareto stable mass matching always exists.

The construction uses a polynomial-time stable-allocation algorithm, followed by one rational linear program. The key is that pairwise stability depends only on aggregate partner counts, while every permitted Pareto improvement weakly increases all aggregate rank-prefix counts.

1. Aggregate flows and their realization

Let \(E\subseteq A\times B\) be the set of mutually acceptable pairs, and put \(c_t=q_t\mu_t\). For an incident pair, write \(f_{tu}=f_{ut}\) for its aggregate link mass.

Every feasible mass matching \(x\) determines a flow by

\(f_{tu}=\sum_{k\in K_t}k_u x_t(k).\)

The balance equations make this definition consistent at both endpoints. Moreover,

\(f_e\ge 0,\qquad \sum_{u:\,tu\in E}f_{tu}\le c_t\quad\text{for every }t.\)

Conversely, every real flow satisfying these inequalities is realizable. When \(q_t>0\), let \(\mathbf e_u\) denote the partner-count unit vector for type \(u\), and set

\(x_t(q_t\mathbf e_u)=\frac{f_{tu}}{q_t},\qquad x_t(0)=\mu_t-\frac{1}{q_t}\sum_u f_{tu}.\)

These weights are nonnegative and sum to \(\mu_t\). Each vector \(q_t\mathbf e_u\) belongs to \(K_t\), because multiple partners of the same type are allowed. Its contribution to the aggregate count of type \(u\) is exactly \(f_{tu}\).

When \(q_t=0\), all incident flows are necessarily zero; set \(x_t(0)=\mu_t\).

Thus flow feasibility and mass-matching feasibility are equivalent. Rational flows give rational outputs with at most

\(2|E|+\tau\)

positive entries across all types.

2. Pairwise stability is determined by the flow

Write type \(t\)'s acceptable indifference classes, from best to worst, as \(R_{t,1},\ldots,R_{t,r_t}\), and let

\(P_{t,j}=\bigcup_{i=1}^{j}R_{t,i}.\)

Classes may contain types that are not mutually acceptable; their corresponding partner counts are always zero. Define

\(N_{t,j}(k)=\sum_{u\in P_{t,j}}k_u,\qquad F_{t,j}(f)=\sum_{\substack{u\in P_{t,j}\\tu\in E}}f_{tu}.\)

For every realization \(x\) of \(f\),

\(F_{t,j}(f)=\sum_{k\in K_t}N_{t,j}(k)x_t(k).\)

Suppose \(u\in R_{t,j}\) is mutually acceptable. An agent with vector \(k\) strictly wants a new partner of type \(u\) if and only if

\(N_{t,j}(k)<q_t.\)

Indeed, if the agent has a vacant slot, this inequality holds. If the agent is full, it holds exactly when some existing partner lies outside \(P_{t,j}\), hence is strictly worse than \(u\). Conversely, either condition in the stated definition of wanting implies the inequality.

Since \(0\le N_{t,j}(k)\le q_t\),

\(c_t-F_{t,j}(f)=\sum_k\bigl(q_t-N_{t,j}(k)\bigr)x_t(k).\)

Every summand is nonnegative. Consequently, positive mass of type \(t\) strictly wants \(u\) exactly when

\(F_{t,j}(f)<c_t.\)

For an edge \(ab\in E\), let \(j_a(b)\) and \(j_b(a)\) denote its ranks at its endpoints. We obtain the following exact characterization:

A realization of \(f\) is pairwise stable if and only if, for every \(ab\in E\),

\(F_{a,j_a(b)}(f)=c_a\quad\text{or}\quad F_{b,j_b(a)}(f)=c_b.\)

In particular, all realizations of the same flow have the same pairwise-stability status.

A useful consequence is monotonicity: if \(f\) is pairwise stable and a feasible flow \(g\) satisfies

\(F_{t,j}(g)\ge F_{t,j}(f)\quad\text{for every }t,j,\)

then \(g\) is pairwise stable. To prove this, take an endpoint equality witnessing stability of any edge under \(f\). Its prefix total under \(g\) is at least \(c_t\), while feasibility bounds it above by \(c_t\). The equality therefore persists.

3. Computing a stable initial flow

We use the following established stable-allocation result.

Stable-allocation theorem. For a finite bipartite graph with positive vertex quotas, nonnegative edge capacities, and strict preferences over incident edges, a stable allocation exists and is computable by a strongly polynomial algorithm. An edge blocks precisely when it is below its capacity and both endpoints have either unused quota or positive allocation on a worse edge. The inductive algorithm preserves integrality, using additions, subtractions, and minima. See Sections 1–2, Theorem 2 and Corollary 1 of [Baïou and Balinski’s corrected paper](https://pubsonline.informs.org/doi/pdf/10.1287/moor.27.4.662.302).

Here is the application, including the encoding details.

Write \(\mu_t=p_t/d_t\), with integers encoded in binary, and choose

\(D=\prod_t d_t,\qquad C_t=Dc_t=Dq_t\mu_t.\)

Each \(C_t\) is an integer, and \(D\) has binary length at most the sum of the denominator lengths in the input.

Temporarily delete vertices with \(C_t=0\), assigning zero flow to their incident edges. On the remaining graph:

  • use vertex quotas \(C_t\);
  • break preference ties arbitrarily, preserving every original strict comparison;
  • give every edge capacity \(M=1+\sum_t C_t\).

These data satisfy the theorem's hypotheses. If either side is empty, simply use the zero flow.

Otherwise, the theorem computes an integral stable allocation \(h\). Every edge is strictly below its artificial capacity, because

\(h_{tu}\le C_t<M.\)

Therefore, for every retained edge, one endpoint's prefix through that edge in the refined strict ranking is saturated. The original weak-ranking prefix contains this refined prefix. Its total is consequently also the endpoint quota: it cannot exceed that quota by feasibility.

Set

\(f^0_e=h_e/D.\)

This is a rational feasible flow satisfying the stability characterization from Section 2. Edges incident to deleted vertices satisfy it as well, because the corresponding endpoint has \(c_t=0\).

The algorithm does not expand quotas into individual units. Strong polynomiality, together with polynomial-length integer data and integral intermediate allocations, gives polynomial bit complexity for this step.

4. The prefix-maximizing linear program

Consider the polytope

\(\mathcal Q=\left\{f\in\mathbb R_{\ge0}^{E}:\ \sum_u f_{tu}\le c_t\ \text{for every }t,\quad F_{t,j}(f)\ge F_{t,j}(f^0)\ \text{for every }t,j\right\}.\)

It is nonempty, since \(f^0\in\mathcal Q\), and bounded, since every edge flow is bounded by each endpoint quota.

Maximize the linear objective

\(H(f)=\sum_t\sum_{j=1}^{r_t}F_{t,j}(f)\)

over \(\mathcal Q\), and compute a rational optimum \(f^*\).

Every flow in \(\mathcal Q\) is pairwise stable by the monotonicity proved in Section 2. Hence any realization \(x^*\) of \(f^*\) is pairwise stable.

The constraints compare aggregate prefix totals only. We do not claim that these comparisons imply the existence of dominating couplings; the proof below needs only the converse implication.

5. Proof of Pareto efficiency against real competitors

Realize \(f^*\) by the construction in Section 1. Suppose, for contradiction, that a feasible mass matching \(y\), with possibly real weights, Pareto improves this realization through couplings \(\gamma_t(k,\ell)\).

Let \(g\) be the aggregate flow of \(y\). Using the coupling marginals gives, for every prefix,

\(F_{t,j}(g)-F_{t,j}(f^*)=\sum_{k,\ell}\gamma_t(k,\ell)\bigl(N_{t,j}(\ell)-N_{t,j}(k)\bigr).\)

Every supported pair satisfies \(\ell\succeq_t k\), so every summand is nonnegative. Therefore,

\(F_{t,j}(g)\ge F_{t,j}(f^*)\ge F_{t,j}(f^0).\)

Since \(y\) is feasible, \(g\) satisfies the flow-capacity inequalities. Thus \(g\in\mathcal Q\).

Define the integer-valued bundle score

\(U_t(k)=\sum_{j=1}^{r_t}N_{t,j}(k).\)

If \(\ell\succeq_t k\), then \(U_t(\ell)-U_t(k)\ge0\). If \(\ell\succ_t k\), at least one integer prefix count increases strictly and none decreases, so

\(U_t(\ell)-U_t(k)\ge1.\)

It follows that

\(H(g)-H(f^*)=\sum_t\sum_{k,\ell}\gamma_t(k,\ell)\bigl(U_t(\ell)-U_t(k)\bigr)\ge\sum_t\sum_{\ell\succ_t k}\gamma_t(k,\ell)>0.\)

This contradicts optimality of \(f^*\) over \(\mathcal Q\).

The contradiction applies to real competitors and real couplings: the rational linear program optimizes over its entire real feasible polytope. Hence \(x^*\) admits no Pareto improvement and is Pareto stable.

6. Polynomial complexity and output size

There are at most \(|E|\le m^2\) flow variables and at most \(\sum_t r_t\le\tau m\) prefix constraints. The linear program has polynomial encoding length:

  • its constraint coefficients are zero or one;
  • each objective coefficient is at most \(2m\);
  • its right-hand sides are the quotas \(c_t\) and prefix totals of the polynomial-length rational flow \(f^0\).

Polynomial-time rational linear programming therefore computes an optimum of polynomial binary length. More explicitly, an optimal vertex is determined by independent tight constraints; determinant bounds for their integer coefficient matrix bound its coordinate lengths polynomially.

The realization formulas divide these coordinates by the input integers \(q_t\) and take rational sums. Thus all output weights have polynomial binary length. Each listed integral vector has at most \(m\) coordinates, each either zero or the binary-encoded capacity \(q_t\). There are at most \(2|E|+\tau\) positive entries.

Both computation and output size are therefore polynomial in \(m,\tau,L\). No valid instance requires a report of nonexistence.
