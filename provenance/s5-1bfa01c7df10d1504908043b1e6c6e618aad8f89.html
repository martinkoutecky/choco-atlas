The continuous mirror question, as graded

Given a finite set of dwelling classes \(H\), a support \(T\) of types, and a rational distribution \(\mu\) over \(T\), where each type specifies a strict ranking over \(H\) and an initial endowment class \(\eta(t)\), compute a feasible core allocation or report that none exists. An allocation is a rational flow \(x_{t,h}\ge 0\) with \(\sum_h x_{t,h}=\mu_t\) and \(\sum_t x_{t,h}=q_h\), where \(q_h=\sum_{t:\eta(t)=h}\mu_t\). A blocking coalition may select positive mass from each type currently assigned to each class, pool its members’ initial endowments, and reassign them so that every participant weakly prefers their new class and positive mass strictly prefers it. Determine the complexity of exact core-finding as a function of \(|H|\), \(\tau=|T|\), and input bit length \(L\).

Packaged proof task (what the prover saw — nothing else)

Let \(H\) be a nonempty set of \(m\) house categories. A society is given by its support: the list \(T\) of its \(\tau\) positive-mass types, each with a binary rational mass \(\mu_t>0\), with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
Each type specifies an endowment category \(e(t)\in H\) and a strict ranking \(\succ_t\) of an acceptable set \(N_t\subseteq H\) containing \(e(t)\). Write \(b\succeq_t a\) when \(b=a\) or \(b\succ_t a\). There are no monetary transfers.
An aggregate assignment has rational entries \(x_{t,h}\ge0\), with \(x_{t,h}=0\) for \(h\notin N_t\), \(\sum_hx_{t,h}=\mu_t\), and \(\sum_tx_{t,h}=q_h:=\sum_{t:e(t)=h}\mu_t\).
A block consists of real amounts \(0\le z_{t,a}\le x_{t,a}\) and \(y_{t,a,b}\ge0\), indexed by \(t\in T\) and \(a,b\in H\), satisfying \(\sum_by_{t,a,b}=z_{t,a}\) and \(\sum_{t,a}y_{t,a,b}=\sum_{t:e(t)=b}\sum_a z_{t,a}\) for every \(b\).
Require \(y_{t,a,b}>0\) only if \(a,b\in N_t\) and \(b\succeq_t a\), and require \(\sum_{t,a,b:b\succ_t a}y_{t,a,b}>0\). Thus coalitions may select any portion of a type's mass currently receiving a category, and trade only their original endowments.
The computational problem is to find a rational assignment admitting no block, or report that none exists.

Is this problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For distinct indivisible houses and strict preferences, core computation is \(\mathrm{CC}\)-hard and has an \(O(n^2)\) sequential algorithm for \(n\) agents ([Zheng–Garg](https://arxiv.org/html/1905.03111)).
For finite agents with fractional endowments, a strong core defined using stochastic-dominance blocking can be empty; that model does not allow the selected-mass coalitions defined above ([Yu–Zhang](https://arxiv.org/html/2508.11151v1)).
No complexity classification for exactly the selected-mass problem above was located.

Modeling choices made when packaging the task

  • The ranking domain was unspecified. Allow strict rankings of acceptable subsets containing the endowment, and prohibit assignments and reassignments to unacceptable categories.
  • The domains of blocking amounts were unspecified. Allow real nonnegative amounts, while retaining rational output assignments.
  • The graded search question did not specify an output when no unblocked assignment exists. Allow reporting nonexistence rather than assuming discrete core existence carries over.
  • Interpret the type masses as divisible populations receiving individual categories; coalitions can select arbitrary submasses distinguished by their current assigned category.

Result

The problem is polynomial-time solvable in \(m,\tau,L\).

More precisely, there is an algorithm that either constructs an assignment admitting no block or correctly reports that none exists. Whenever such an assignment exists, it is unique, and each type receives its entire mass in one category.

The proof below works directly with the listed types and their rational masses.

1. A graph characterization of blocking

First remove every category with \(q_h=0\). This preserves the problem: feasibility forces every assignment entry in such a category to be zero; moreover, no type is endowed with that category, so a coalition cannot supply or receive it. The remaining category set is nonempty.

Fix a feasible assignment \(x\). Construct a directed multigraph \(G_x\) on the remaining categories. For every triple \((t,a,b)\) satisfying

\[ x_{t,a}>0,\qquad b\succeq_t a, \]

include an edge from \(e(t)\) to \(b\), labelled by \((t,a,b)\). Mark this edge strict when \(b\succ_t a\). Self-loops are allowed.

Lemma 1. An assignment admits a block if and only if \(G_x\) has a directed cycle containing a strict edge.

Proof. Suppose first that \((z,y)\) is a block. Interpret each positive \(y_{t,a,b}\) as flow on the edge from \(e(t)\) to \(b\). Its label is valid because

\[ y_{t,a,b}>0\ \Longrightarrow\ z_{t,a}>0\ \Longrightarrow\ x_{t,a}>0, \]

and the blocking definition requires \(b\succeq_t a\).

At any category \(h\), total outgoing flow equals

\[ \sum_{t:e(t)=h}\sum_{a,b}y_{t,a,b} = \sum_{t:e(t)=h}\sum_a z_{t,a}. \]

The coalition’s resource equation says that this is also total incoming flow. Thus the positive flows form a circulation. At least one positive-flow edge is strict.

Every positive-flow edge of a finite circulation lies on a directed cycle. To verify this, consider an edge \(u\to v\). If \(u=v\), it is already a cycle. Otherwise, let \(S\) consist of the vertices reachable from \(v\) using positive-flow edges. If \(u\notin S\), no positive flow leaves \(S\), whereas the edge \(u\to v\) brings positive flow into \(S\). Summing flow conservation over \(S\) gives a contradiction. Hence there is a path from \(v\) to \(u\), and a simple such path together with \(u\to v\) gives a cycle. Applying this to a positive strict edge proves one direction.

Conversely, suppose a simple directed cycle has edge labels

\[ (t_i,a_i,b_i),\qquad i=1,\ldots,r, \]

with at least one strict edge. Choose

\[ 0<\varepsilon\leq \min_{1\leq i\leq r}x_{t_i,a_i}. \]

Put \(y_{t_i,a_i,b_i}=\varepsilon\) on each cycle edge and put all other entries of \(y\) equal to zero. Define \(z_{t,a}=\sum_b y_{t,a,b}\).

Because the cycle is simple, its edge tails are distinct. Since an edge labelled by type \(t\) has tail \(e(t)\), no type, and hence no pair \((t,a)\), occurs twice. Therefore \(z_{t,a}\leq x_{t,a}\). Each cycle vertex has equal incoming and outgoing flow, which gives precisely the coalition’s resource equations. Every selected person weakly improves, and the strict edge gives positive strict improvement. This is a block. \(\square\)

2. Sink components force assignments

We will also consider residual markets whose masses have total less than one. The assignment and blocking equations remain the same; their arguments do not require normalization.

Let \(R\) be the categories of such a residual market, with precisely those types whose endowments belong to \(R\). Every remaining category has positive supply. For each remaining type define \(f_R(t)\) as its most preferred category in \(N_t\cap R\). This exists because \(e(t)\in N_t\cap R\).

Construct the top-choice graph \(F_R\) on \(R\), with an edge

\[ e(t)\longrightarrow f_R(t) \]

for every remaining type. A sink strongly connected component is a strongly connected component with no edge leaving it.

For a sink component \(C\), define its top-choice demand at category \(h\in C\) by

\[ d_C(h):=\sum_{\substack{t:e(t)\in C\\ f_R(t)=h}}\mu_t. \]

Lemma 2. In every feasible residual assignment \(x\) admitting no block, every type endowed in \(C\) receives its entire mass at its top choice:

\[ x_{t,f_R(t)}=\mu_t \qquad\text{for every }t\text{ with }e(t)\in C. \]

Consequently,

\[ d_C(h)=q_h \qquad\text{for every }h\in C, \]

and no type endowed outside \(C\) receives a category in \(C\).

Proof. Every edge of \(F_R\) is present in the underlying graph of \(G_x\). Indeed, for each type \(t\), some \(a\in R\) has \(x_{t,a}>0\), and \(f_R(t)\succeq_t a\).

Now take a type \(t\) endowed in \(C\). Since \(C\) is a sink, \(f_R(t)\in C\). Suppose \(x_{t,a}>0\) for some \(a\ne f_R(t)\). Strict preferences and maximality of \(f_R(t)\) give \(f_R(t)\succ_t a\), so \(G_x\) contains the strict edge

\[ e(t)\longrightarrow f_R(t). \]

Strong connectivity of \(C\) gives a path in \(F_R\), and hence in \(G_x\), from \(f_R(t)\) back to \(e(t)\). Thus the strict edge lies on a directed cycle, contradicting Lemma 1. This proves the asserted assignment.

All types endowed in \(C\) therefore receive categories in \(C\). Their total assigned mass is exactly

\[ \sum_{t:e(t)\in C}\mu_t=\sum_{h\in C}q_h. \]

For each \(h\in C\), feasibility gives \(d_C(h)\leq q_h\). Summing these inequalities gives equality of their two sides, so each individual inequality is an equality. Consequently these owners exhaust every category in \(C\), leaving none for outside types. \(\square\)

In particular, a single failed equality \(d_C(h)=q_h\) certifies that the residual market has no assignment admitting no block.

3. The algorithm

Initially let \(R\) contain all positive-supply categories, and initialize every entry of the output assignment to zero.

Repeat while \(R\) is nonempty:

  • Compute \(f_R(t)\) for every type with \(e(t)\in R\), and construct \(F_R\).
  • Find all sink strongly connected components of \(F_R\).
  • For each such component \(C\), check \(d_C(h)=q_h\) for every \(h\in C\). If any check fails, report that no assignment admitting no block exists.
  • Otherwise, for every type endowed in one of these components, set \(x_{t,f_R(t)}=\mu_t\).
  • Remove those components from \(R\), together with the types endowed in them.

Every remaining category has an owner, so every vertex of \(F_R\) has an outgoing edge. A finite nonempty directed graph has a sink strongly connected component. Thus every successful round removes at least one category, and there are at most \(m\) rounds.

4. Correctness

Reporting nonexistence is correct

Suppose the original market has an assignment admitting no block.

By Lemma 2, its assignment to the owners of every first-round sink component is forced. Those owners exhaust their components’ supplies and consume no other categories. Deleting them therefore leaves a feasible assignment for the residual market.

That residual assignment also admits no block: any residual block extends to an original block by setting all selected amounts and trades involving deleted types or categories equal to zero.

Apply the same argument inductively at every round. If an original assignment admitting no block exists, every balance check made by the algorithm must succeed. Hence a failed check correctly certifies nonexistence.

A returned assignment is feasible

Each type is assigned its entire mass to an acceptable category. A sink component receives assignments only from its own owners, and its balance checks ensure that each category receives exactly its supply. Distinct removed components are disjoint, and eventually all positive-supply categories are removed.

Thus the returned assignment satisfies every feasibility equation. Its entries are rational, since every nonzero entry is an input mass.

A returned assignment admits no block

Let \(k(h)\) be the round in which category \(h\) was removed. A type endowed at \(h=e(t)\) is assigned a category \(a=f_R(t)\) belonging to its own sink component, so

\[ k(a)=k(e(t)). \]

Consider any edge of \(G_x\), labelled by \((t,a,b)\). Here \(a\) is the type’s assigned category and \(b\succeq_t a\).

If \(b\) was still available in the round when \(t\) was assigned, strict preferences and the definition of \(f_R(t)\) imply \(b=a\). Otherwise \(b\) was removed earlier. Consequently every edge satisfies

\[ k(b)\leq k(e(t)), \]

and every strict edge satisfies

\[ k(b)<k(e(t)). \]

Along a directed cycle the round numbers cannot increase. Such a cycle cannot contain a strict decrease, because it returns to its starting vertex. Therefore \(G_x\) has no directed cycle containing a strict edge. Lemma 1 proves that the returned assignment admits no block.

Uniqueness

Lemma 2 forces every assignment made in the first round in any assignment admitting no block. After restriction to the residual market, it forces every second-round assignment, and so on.

Thus, whenever an assignment admitting no block exists, the algorithm returns the unique one. In particular, every type receives just one category.

5. Polynomial bit complexity

Each round uses at most \(m\) vertices and \(\tau\) top-choice edges. Top choices can be found by scanning the input rankings; strongly connected components and sink components can be computed in linear time in the graph size. There are at most \(m\) rounds, so the number of graph operations and ranking scans is polynomial in \(m,\tau,L\).

The exact mass checks also have polynomial bit complexity. Write each input mass as \(\mu_t=p_t/d_t\), with positive integers \(p_t,d_t\), and let

\[ D:=\prod_{t\in T}d_t, \qquad w_t:=p_t(D/d_t). \]

The bit length of \(D\) is at most the sum of the input denominators’ bit lengths, hence is \(O(L)\). Since \(\sum_t\mu_t=1\), we have \(\sum_t w_t=D\). Every supply and demand check can therefore be performed by summing and comparing integers of \(O(L)\) bits.

The algorithm never expands rational masses into individual agents. Its output entries are either zero or an input mass, so its output length is polynomial as well.

6. Emptiness and relation to finite models

Existence is not automatic. For example, take two categories \(A,B\), a type of mass \(2/3\) endowed with \(A\) and ranking \(B\succ A\), and a type of mass \(1/3\) endowed with \(B\) and ranking \(A\succ B\). The top-choice graph has the single sink component \(\{A,B\}\), but its demand for \(A\) is \(1/3\), whereas its supply is \(2/3\). Lemma 2 proves nonexistence.

The construction is related to the top trading segmentation used for finite houseswapping markets with indifferences by [Quint–Wako](https://cowles.yale.edu/sites/default/files/2022-08/d1416.pdf). The proof above establishes correctness directly for the selected-mass blocking definition and gives a running time polynomial in the support representation.
