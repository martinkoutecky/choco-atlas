The continuous mirror question, as graded

Given rational type masses \(\mu_\theta\) summing to \(1\), population scale \(q\), item classes \(G\) with \(q b_g\) identical indivisible copies, divisible supply \(q b_C\), and additive values \(v_{\theta g},v_{\theta C}\), let \(p_\theta=\sum_{g\in G}b_gv_{\theta g}+b_Cv_{\theta C}\) and \(\alpha_\theta=\sum_g b_gv_{\theta g}/p_\theta\). Find a finite-support mass distribution \(x_{\theta,B,z}\) over integral bundles \(B\in\mathbb{Z}_{\ge0}^{G}\) and divisible quantities \(z\ge0\), with type marginals \(\mu_\theta\), average supply constraints \(\sum xB_g\le b_g\) and \(\sum xz\le b_C\), and every supported configuration satisfying \(v_\theta(B,z)+\alpha_\theta h_\theta(B)\ge p_\theta\), where \(h_\theta(B)=\max\{v_{\theta g}:B_g<qb_g\}\) and the empty maximum is \(0\). Decide whether this construction is solvable in time polynomial in \(\tau\), \(|G|\), \(\log q\), and the input bit length; when masses are multiples of \(1/q\), it must recover the corresponding finite-clone allocation.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_\theta\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Let \(G\) contain \(m\) item classes. Input includes a binary-encoded integer \(q\ge1\), positive rational supplies \(b_g\) with \(qb_g\in\mathbb Z_{>0}\), homogeneous divisible supply \(qb_C\) with rational \(b_C\ge0\), and nonnegative rational additive values \(v_{\theta g},v_{\theta C}\). Let \(L\) be the total input bit length.
Define \(p_\theta=\sum_{g\in G}b_gv_{\theta g}+b_Cv_{\theta C}>0\), \(\alpha_\theta=(\sum_{g\in G}b_gv_{\theta g})/p_\theta\), and \(v_\theta(B,z)=\sum_{g\in G}B_gv_{\theta g}+zv_{\theta C}\).
A configuration has \(B\in\mathbb Z_{\ge0}^{G}\), \(B_g\le qb_g\), and rational \(0\le z\le qb_C\). Define \(h_\theta(B)=\max\{v_{\theta g}:B_g<qb_g\}\), with empty maximum \(0\).
Construct a finitely supported nonnegative rational mass distribution \(x_{\theta,B,z}\) satisfying \(\sum_{B,z}x_{\theta,B,z}=\mu_\theta\), \(\sum_{\theta,B,z}x_{\theta,B,z}B_g=b_g\), and \(\sum_{\theta,B,z}x_{\theta,B,z}z=b_C\), or determine infeasibility.
Every supported configuration must satisfy \(v_\theta(B,z)+\alpha_\theta h_\theta(B)\ge p_\theta\); the extra item is hypothetical and does not consume supply.
Whenever all \(q\mu_\theta\) are integers, additionally require \(qx_{\theta,B,z}\in\mathbb Z_{\ge0}\): these counts specify an allocation to \(q\) clones with \(q\mu_\theta\) clones of each type.

Is this exact construction problem solvable in time polynomial in \(m,\tau,\log q,L\), or is it NP-hard?

For explicitly listed agents and indivisible goods, proportionality up to the agent’s indivisibility ratio times the value of one outside item is always achievable in polynomial time, counting Robertson–Webb queries at unit cost. [Li, Li, Liu, and Wu](https://arxiv.org/html/2404.18132v1).
No result settling this exact mass-distribution problem with binary population scale and finite-clone recovery was located.

Modeling choices made when packaging the task

  • Population scale is a positive binary-encoded integer; each represented item class has a positive integral total number of copies.
  • Values and supplies are nonnegative binary rationals, with positive total value for every supported type, as required by the discrete normalization.
  • The divisible resource is homogeneous, as specified by the single per-unit value in the continuous question; either kind of resource may be absent.
  • Each configuration is bounded by the entire physical supply, a restriction omitted from the graded formulation.
  • Supply inequalities are replaced by equalities to carry over the discrete requirement that all goods be allocated.
  • Finite-clone recovery means integral configuration counts when all type masses are multiples of the reciprocal population scale; allocations remain represented by configuration counts.
  • Supported quantities and masses are rational, and infeasibility is included in the construction problem.
  • The empty-maximum convention permits an already proportional configuration without an outside item, consistent with the intended purely divisible case despite the literal existential quantifier retained in the full version.

1. Result

The problem is polynomial-time solvable. Every input satisfying the stated hypotheses is feasible.

More precisely, one can construct a rational distribution with support size \(O(\tau(m+\tau))\), using polynomially many operations on numbers of polynomial bit length. When all \(q\mu_\theta\) are integers, the construction satisfies the required integrality condition.

The proof uses bag filling and minimum required cake, related to Algorithm 1 of [Li, Li, Liu, and Wu](https://arxiv.org/html/2404.18132v1). The correctness and compression arguments needed here are proved below.

Write \(N_g=qb_g\) and \(C=qb_C\). Thus \(N_g\) is the integer number of copies of class \(g\), and \(C\) is the total divisible supply. For every type,

\[ \sum_g N_gv_{\theta g}+Cv_{\theta C}=qp_\theta. \]

2. Monotonicity of the acceptance condition

Define \(H_\theta=\max_{g\in G}v_{\theta g}\), with value \(0\) when \(G\) is empty, and define

\[ F_\theta(B,z)=v_\theta(B,z)+\alpha_\theta h_\theta(B). \]

Since all values are nonnegative and \(p_\theta>0\), we have \(0\leq\alpha_\theta\leq1\).

We first prove that \(F_\theta\) is nondecreasing when items or divisible supply are added within the configuration bounds.

Adding divisible supply cannot decrease \(F_\theta\). Consider adding one copy of class \(g\), where \(B_g<N_g\). The value of the bundle increases by \(v_{\theta g}\). The outside maximum can decrease only if this addition exhausts class \(g\) in the bundle. In that case its decrease is at most \(v_{\theta g}\). Consequently,

\[ F_\theta(B+e_g,z)-F_\theta(B,z) \geq (1-\alpha_\theta)v_{\theta g}\geq0. \]

Here \(e_g\) is the unit vector of class \(g\).

In particular, if \(p_\theta\leq\alpha_\theta H_\theta\), then the empty configuration is acceptable for type \(\theta\), and monotonicity implies that every configuration is acceptable for that type.

3. Construction for arbitrary integer type counts

We first solve the following auxiliary problem: prescribe arbitrary nonnegative integer counts \(n_\theta\) summing to \(q\), and allocate all supplies to these \(q\) clones. The counts need not equal \(q\mu_\theta\).

The proportional target and indivisibility ratio remain \(p_\theta\) and \(\alpha_\theta\), because the total resource value for any clone of type \(\theta\) is \(qp_\theta\), independently of the type counts.

Call a type *empty-acceptable* if \(p_\theta\leq\alpha_\theta H_\theta\).

If every present type is empty-acceptable, give the entire supply to one clone and empty configurations to all others. This is acceptable and uses all supplies.

Otherwise, give empty configurations to every clone of an empty-acceptable type. Every remaining type then satisfies

\[ p_\theta>\alpha_\theta H_\theta. \]

Fix an ordering of the item classes, with copies of each class consecutive. The following algorithm is initially conceptual; Section 5 implements it without enumerating copies or clones.

While at least two clones remain, inspect prefixes of the ordered remaining items.

  • If some prefix is acceptable with no cake for some remaining type, take the shortest such prefix. Write it as \(B+\{o\}\), where \(o\) is its last item.
  • If no such prefix exists, let \(B\) contain all remaining items, with no item \(o\).

In either case, \(B\) alone is unacceptable for every remaining type. Define its strictly positive deficit

\[ D_\theta(B)=p_\theta-v_\theta(B,0)-\alpha_\theta h_\theta(B)>0. \]

The minimum required divisible amount for type \(\theta\) is

\[ \delta_\theta(B)= \begin{cases} D_\theta(B)/v_{\theta C},&v_{\theta C}>0,\\ +\infty,&v_{\theta C}=0. \end{cases} \]

Let \(\delta=\min_\theta\delta_\theta(B)\), over remaining types, and let \(T\) be the remaining divisible supply.

If \(\delta\leq T\), give \((B,\delta)\) to a clone attaining this minimum. Call this a *cake round*.

If \(\delta>T\), give \(B+\{o\}\), with no cake, to a type for which that prefix is acceptable. Call this an *item round*. We will prove that \(o\) necessarily exists in this case.

Remove the allocated clone and its actual resources. Finally, give all remaining resources to the last clone.

The outside maximum always uses the original totals \(N_g\), exactly as required in the question.

4. Proof that the integer-count construction works

Include the initial empty allocations in the conceptual sequence of allocations. Number the clones by their removal order, and fix a non-empty-acceptable type \(\theta\) still present before allocation \(j\).

In the following calculations, abbreviate \(p=p_\theta\), \(\alpha=\alpha_\theta\), and \(v=v_\theta\).

For each earlier allocation \(i\), let \(B_i\) be its bag before any item-round last item is added.

For an initial empty allocation,

\[ v(A_i)=0\leq p-\alpha h_\theta(B_i), \]

because \(h_\theta(B_i)=H_\theta\) and \(p>\alpha H_\theta\).

For a cake round, the chosen divisible amount is no larger than the amount required by type \(\theta\), which was still present. Hence

\[ v(A_i)\leq p-\alpha h_\theta(B_i). \]

This also holds when \(v_{\theta C}=0\), since \(B_i\) is then strictly below the acceptance threshold.

For an item round with last item \(o_i\), unacceptability of \(B_i\) gives

\[ v(A_i)\leq p-\alpha h_\theta(B_i)+v_\theta(o_i). \]

These inequalities bound the resources removed from the viewpoint of every surviving type.

4.1. A bound from the first item round

Suppose an item round occurred before allocation \(j\), and let \(k\) be the first item round.

Every allocation before \(k\) was an initial empty allocation or a cake round. Each had total value at most \(p\) to type \(\theta\), so its divisible component also had value at most \(p\).

At round \(k\), the remaining divisible supply \(T_k\) was insufficient for every remaining type. Thus

\[ v_\theta(B_k,0)+v_{\theta C}T_k+\alpha h_\theta(B_k)<p, \]

and therefore \(v_{\theta C}T_k<p\). Accounting for all initial divisible supply gives

\[ Cv_{\theta C} =\sum_{i<k}z_iv_{\theta C}+T_kv_{\theta C} \leq kp. \]

Since \(Cv_{\theta C}=(1-\alpha)qp\), division by \(p>0\) yields

\[ q\alpha\geq q-k. \]

4.2. A residual-value bound

Let \(d\) be the number of item rounds before allocation \(j\), and let

\[ W=\max\{v_\theta(o_i):i<j\text{ is an item round}\}. \]

If \(d>0\), every item used in this maximum lies outside every earlier pre-addition bag \(B_i\). Indeed, an earlier item-round last item was already allocated elsewhere; the last item of the same round is excluded from \(B_i\); and a later item-round last item could not have belonged to a previously allocated bag.

Consequently, \(h_\theta(B_i)\geq W\) for every \(i<j\). The total removed value is therefore at most

\[ (j-1)(p-\alpha W)+dW. \]

Let \(r=q-j+1\) be the number of remaining clones, and let \(R_\theta\) be the value of all remaining resources to type \(\theta\). Then

\[ R_\theta \geq qp-(j-1)(p-\alpha W)-dW =r(p-\alpha W)+(q\alpha-d)W. \]

Because the first item round was \(k\), we have \(d\leq j-k\leq q-k\). Section 4.1 therefore implies \(q\alpha-d\geq0\), and hence

\[ R_\theta\geq r(p-\alpha W). \]

Moreover, \(W\leq H_\theta\), so \(p-\alpha W>0\).

If no item round occurred before \(j\), all earlier allocations had value at most \(p\), giving instead

\[ R_\theta\geq rp. \]

4.3. Every iteration is defined

The only potentially undefined situation is that no acceptable item prefix exists and \(\delta>T\).

When no acceptable prefix exists, \(B\) contains all remaining items. Every previously consumed item-round last item lies outside \(B\), so \(h_\theta(B)\geq W\).

If there were earlier item rounds, the residual bound gives

\[ v_\theta(B,0)+Tv_{\theta C} =R_\theta \geq r(p_\theta-\alpha_\theta W) \geq p_\theta-\alpha_\theta h_\theta(B). \]

The second inequality uses \(r\geq1\) and \(p_\theta-\alpha_\theta W>0\).

If there were no earlier item rounds, the same conclusion follows from \(R_\theta\geq rp_\theta\).

Since \(B\) alone is unacceptable, these inequalities imply \(v_{\theta C}>0\) and \(\delta_\theta(B)\leq T\). Thus a cake round is available. The potentially undefined situation cannot occur.

Every cake-round recipient satisfies the acceptance condition by the definition of its required amount. Every item-round recipient satisfies it by the choice of the crossing prefix.

4.4. The last clone is acceptable

Let \(A\) be the entire remaining configuration.

If no item round occurred, its value to the last clone is at least \(p_\theta\).

Otherwise, every previously consumed item-round last item lies outside \(A\), so \(h_\theta(A)\geq W\). Applying the residual bound with \(r=1\) gives

\[ v_\theta(A)\geq p_\theta-\alpha_\theta W \geq p_\theta-\alpha_\theta h_\theta(A). \]

Thus the last clone is acceptable as well.

This proves feasibility for every integer type-count vector summing to \(q\).

5. Polynomial implementation by batching

We now implement the conceptual construction in polynomial time.

Maintain remaining class stocks \(S_g\), remaining divisible supply \(T\), and remaining type counts. Resolve all ties by a fixed type order.

5.1. Prefixes can be searched in binary

For a prefix of length \(\ell\), its class-count vector is computable from the stocks \(S_g\) without enumerating copies.

By Section 2, acceptance for each type is nondecreasing with prefix length. The predicate “some remaining type accepts this prefix” is therefore monotone.

The first acceptable prefix can be found using binary search, with \(O(\log(1+\sum_gN_g))\) predicate evaluations. Each evaluation uses polynomially many rational operations.

5.2. Repeated rounds within one class

Suppose class \(a\) is the first nonempty remaining class. For the current set of remaining types, define

\[ t_a=\min\{t\in\{1,\ldots,N_a\}: F_\theta(te_a,0)\geq p_\theta \text{ for some remaining type }\theta\}, \]

with \(t_a=+\infty\) if no such integer exists. This is also computable by binary search.

If \(S_a\geq t_a\), the shortest crossing prefix consists entirely of class \(a\), and its pre-addition bag is \((t_a-1)e_a\).

As long as the remaining type set is fixed and \(S_a\geq t_a\), this bag, its deficits, and all tie choices are fixed. This uses the fact that \(h_\theta\) depends on the original totals \(N_g\), rather than on remaining stocks.

Let \(r\) be the remaining clone count and \(n_\theta\) the remaining count of the chosen recipient type.

For a cake round, the fixed configuration is \(((t_a-1)e_a,z)\), with \(z>0\). Execute \(K\) identical rounds together, where

\[ K=\min\left\{ n_\theta,\ r-1,\ \left\lfloor T/z\right\rfloor,\ K_{\mathrm{goods}} \right\}, \]

and

\[ K_{\mathrm{goods}}= \begin{cases} +\infty,&t_a=1,\\ \left\lfloor(S_a-1)/(t_a-1)\right\rfloor,&t_a>1. \end{cases} \]

The goods bound is exactly the largest number of repetitions for which every repetition starts with at least \(t_a\) copies available.

For an item round, the fixed configuration is \((t_ae_a,0)\). Execute

\[ K=\min\left\{ n_\theta,\ r-1,\ \left\lfloor S_a/t_a\right\rfloor \right\} \]

identical rounds together.

These batches reproduce the conceptual algorithm: every intermediate round has the same crossing prefix and recipient, remains in the same cake or item case, and has sufficient resources.

5.3. Exceptional rounds and the batch bound

If \(S_a<t_a\), including the case \(t_a=+\infty\), no prefix lying entirely in the remaining copies of class \(a\) is acceptable.

Therefore the pre-addition bag \(B\) contains all remaining copies of class \(a\): either the crossing occurs in a later class, or no crossing exists. Execute this round individually. It exhausts class \(a\), so there are at most \(m\) such exceptional rounds.

Between changes of the remaining type set or the first nonempty class, the value \(t_a\) and the cake requirement are fixed. Within such an interval:

  • a cake batch can end because the cake becomes insufficient, after which the algorithm uses item rounds;
  • any other batch endpoint exhausts a type, leaves the last clone, or leaves too few copies for the crossing prefix;
  • the last possibility is followed by an exceptional round exhausting the first class.

Thus each interval has only a constant number of batches and exceptional rounds. Types disappear at most \(\tau\) times, and the first nonempty class changes at most \(m\) times.

If no items remain, the bag is empty and the minimum cake requirement depends only on the remaining type set. Batch identical cake rounds in the same way. Such a batch must exhaust a type or leave the last clone: otherwise it would leave at least two clones with the same minimum requirement exceeding the remaining cake, contradicting Section 4.3.

Initial empty allocations require at most one record per type. Overall, the integer-count construction produces \(O(m+\tau)\) configuration records, each carrying an integer multiplicity.

6. Nonintegral type masses

It remains to represent arbitrary masses using integer type-count vectors summing to \(q\).

Set

\[ y_\theta=q\mu_\theta,\qquad a_\theta=\lfloor y_\theta\rfloor,\qquad f_\theta=y_\theta-a_\theta. \]

Since \(\sum_\theta y_\theta=q\), the number \(s=\sum_\theta f_\theta\) is an integer.

If \(s=0\), use the single count vector \(n_\theta=y_\theta\).

Otherwise, order the types and set \(F_0=0\) and \(F_\theta=\sum_{\eta\leq\theta}f_\eta\). For \(u\in[0,1)\), define \(e_\theta(u)\) to be the number of points

\[ u,\ u+1,\ldots,u+s-1 \]

in the interval \([F_{\theta-1},F_\theta)\).

Because this interval has length \(f_\theta<1\), we have \(e_\theta(u)\in\{0,1\}\). The intervals partition \([0,s)\), so \(\sum_\theta e_\theta(u)=s\). Therefore

\[ n_\theta(u)=a_\theta+e_\theta(u) \]

is a nonnegative integer count vector summing to \(q\).

Furthermore,

\[ \int_0^1e_\theta(u)\,du =\sum_{\ell=0}^{s-1} \operatorname{length}\bigl([F_{\theta-1},F_\theta)\cap[\ell,\ell+1)\bigr) =f_\theta. \]

The vector \(e(u)\) changes only at fractional parts of the cumulative sums \(F_\theta\). Partitioning \([0,1)\) at these rational breakpoints gives at most \(\tau\) intervals. Choose a rational interior point from each interval, and let its length be \(\lambda_j\).

This constructs, using rational arithmetic, at most \(\tau\) integer count vectors \(n^j\) such that

\[ \sum_j\lambda_j=1,\qquad \sum_j\lambda_jn^j_\theta=q\mu_\theta. \]

Apply Sections 3–5 separately to each vector \(n^j\), always using the original supplies and the original \(p_\theta,\alpha_\theta\). Let \(k^j_{\theta,B,z}\) be the integer configuration multiplicities produced.

Define

\[ x_{\theta,B,z}=\frac1q\sum_j\lambda_jk^j_{\theta,B,z}, \]

combining repeated configurations.

The type-mass equations follow from

\[ \sum_{B,z}x_{\theta,B,z} =\frac1q\sum_j\lambda_jn^j_\theta =\mu_\theta. \]

Every constituent allocation uses all supplies. Hence

\[ \sum_{\theta,B,z}x_{\theta,B,z}B_g=N_g/q=b_g, \qquad \sum_{\theta,B,z}x_{\theta,B,z}z=C/q=b_C. \]

Every supported configuration is acceptable and respects the bounds, because it occurs in a constituent allocation proved correct above.

When all \(q\mu_\theta\) are integers, there is only one count vector and its weight is \(1\). Consequently,

\[ qx_{\theta,B,z}=k_{\theta,B,z}\in\mathbb Z_{\geq0}, \]

as required.

7. Encoding size and running time

The global stocks \(N_g\), all type counts, and every bundle coordinate have polynomial bit length. Their potentially large numerical values are handled by binary search and integer batching.

The quantities \(p_\theta\) and \(\alpha_\theta\) have polynomial bit length. Each nonfinal divisible amount is of the form

\[ \frac{ p_\theta-\sum_gB_gv_{\theta g}-\alpha_\theta h_\theta(B) }{v_{\theta C}}, \]

with a positive denominator and polynomial-bit bundle coordinates. It therefore has polynomial bit length.

There are only \(O(m+\tau)\) batches per count vector. The remaining divisible supply is obtained by subtracting polynomially many rational batch totals, so its bit length remains polynomial. The profile weights and the final masses likewise have polynomial bit length.

There are at most \(\tau\) count vectors, each producing \(O(m+\tau)\) records. Thus the output support has size \(O(\tau(m+\tau))\), and the complete construction takes time polynomial in \(m,\tau,\log q,L\).
