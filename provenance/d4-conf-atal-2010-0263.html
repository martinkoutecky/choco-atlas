The continuous mirror question, as graded

Given a shared protocol \(\alpha\) with explicit characterisations, a mode \(\sigma\in\{\mathrm{weak},\mathrm{strong}\}\), and a rational distribution \(\mu\) over supported types \(t=(\psi_t,\phi_t)\), what exact mass of the society has a type for which \(\alpha\) matches from \(\psi_t\) to \(\phi_t\) in mode \(\sigma\)?

Packaged proof task (what the prover saw — nothing else)

Fix a propositional vocabulary of \(m\) atoms. Preconditions, postconditions and goals are consistent sets of signed literals, representing conjunctions; entailment in the matching rule means literal-set inclusion. Initial states are sets of positive literals.
A shared protocol \(\alpha\) is supplied with its complete explicit list \(C=\{(P_i,Q_i):1\le i\le n\}\) of path characterisations: \(P_i\) is a path's weakest precondition and \(Q_i\) its maximal postcondition. Characterisation generation is outside the input problem.
A society is given by its support: the list of the \(\tau\) types \(t=(\psi_t,\phi_t)\) with positive mass, each with its mass \(\mu_t\) as a binary rational. Require \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
For each type let \(A_t=\{i:P_i\subseteq\psi_t\}\). Weak matching means \(\exists i\in A_t\;Q_i\supseteq\phi_t\); strong matching means \(A_t\ne\varnothing\) and \(\forall i\in A_t\;Q_i\supseteq\phi_t\). Thus strong matching requires an executable terminating outcome.
Given \(\sigma\in\{\mathrm{weak},\mathrm{strong}\}\), the required exact mass is \(M_\sigma=\sum_{t:\,\alpha\text{ matches }t\text{ in mode }\sigma}\mu_t\). Let \(L\) be the total binary input length.

Is computing \(M_\sigma\) solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,n,L\).

For a single initial-state/goal pair, explicit-characterisation matching has a worst-case bound of \(2n\) entailment operations for either mode; DFS uses \(e+2n\), where \(e\) counts protocol-tree traversals. [Source](https://nms.kcl.ac.uk/peter.mcburney/downloads/pubs/2010/pm-2010-08.pdf)
No prior result settling this exact distribution-over-types mass problem was identified.

  • The distribution normalization was unspecified: require strictly positive rational support masses summing to one.

  • Size parameters were unspecified: define m as the vocabulary size, n as the explicit characterisation count, and L as total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

For both weak and strong matching, computing the exact mass is polynomial-time solvable.

With literal sets represented by bit vectors, a running-time bound is \(O(\tau n(m+1)+L^2)\) bit operations, including exact rational summation. For ordinary explicit literal-list input, direct comparisons give an alternative bound of \(O(L^2)\), without allocating vectors over the entire vocabulary. These bounds allow an unreduced numerator–denominator output; requiring a reduced fraction still gives polynomial time.

1. Determining which supported types match

For each supported type \(t\) and characterisation \(i\), define Boolean values
\[ \]
\(E_{ti}=[P_i\subseteq\psi_t]\) and \(G_{ti}=[\phi_t\subseteq Q_i]\), where brackets denote the truth value of the enclosed statement.

The definitions in the question give
\[ \]
\(w_t=\bigvee_{i=1}^{n}(E_{ti}\land G_{ti})\)
for weak matching, and
\[ \]
\(s_t=\left(\bigvee_{i=1}^{n}E_{ti}\right)\land\neg\left(\bigvee_{i=1}^{n}(E_{ti}\land\neg G_{ti})\right)\)
for strong matching.

The strong formula explicitly requires at least one executable characterisation. Thus it rejects a type when \(A_t=\varnothing\), including when \(n=0\).

An algorithm scans the characterisations for each type. It checks \(E_{ti}\), and checks \(G_{ti}\) only when \(E_{ti}\) is true. During this scan it records whether there is:

  • an executable characterisation;
  • an executable characterisation satisfying the goal;
  • an executable characterisation failing the goal.

Weak matching holds exactly when the second flag is true. Strong matching holds exactly when the first flag is true and the third is false. These equivalences prove correctness directly from the given matching rules.

There are at most \(2n\) inclusion tests per type, hence at most \(2\tau n\) overall. This also recovers the single-pair operation bound reported in the [cited paper](https://nms.kcl.ac.uk/peter.mcburney/downloads/pubs/2010/pm-2010-08.pdf).

2. Cost of the inclusion tests

Bit-vector representation

Represent a signed-literal set by two vectors of length \(m\), one for positive literals and one for negative literals. Inclusion holds exactly when every set bit of the first set is also set in the second, separately for both signs. Each inclusion test therefore costs \(O(m+1)\) bit operations.

Constructing these vectors costs \(O(L+(n+\tau)(m+1))\). For \(n\geq 1\), the support condition implies \(\tau\geq 1\), so \(n+\tau\leq 2n\tau\). Consequently, preprocessing and matching together cost
\[ \]
\(O(L+\tau n(m+1)).\)

When \(n=0\), both masses are immediately zero.

Explicit literal-list representation

A polynomial bound in \(L\) does not require allocating all \(m\) coordinates.

For literal sets \(U,V\), let \(b(U)\) and \(b(V)\) be their total literal-encoding lengths. Test \(U\subseteq V\) by comparing each literal of \(U\) against the literals of \(V\). Comparing two encoded literals of positive lengths \(a,b\) costs \(O(a+b)\), which is \(O(ab)\). Thus inclusion costs \(O(1+b(U)b(V))\).

Summing the precondition-test costs over all type–characterisation pairs gives
\[ \]
\(O\!\left(n\tau+\left(\sum_i b(P_i)\right)\left(\sum_t b(\psi_t)\right)\right)=O(L^2).\)

The same calculation for the goal tests uses \(\sum_i b(Q_i)\) and \(\sum_t b(\phi_t)\), and also gives \(O(L^2)\). Here every aggregate encoding length is at most \(L\), and \(n,\tau\leq L\) because both lists are explicit.

Hence all matching decisions can be computed in \(O(L^2)\) bit operations, even if many vocabulary atoms never occur in the input.

3. Exact rational summation

Use the standard binary numerator–denominator encoding, writing each mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\). Let \(T_\sigma\) be the set of types accepted by the preceding algorithm.

Start with \(N=0,D=1\). For each \(t\in T_\sigma\), replace
\[ \]
\((N,D)\longleftarrow(Nb_t+a_tD,\;Db_t),\)
using the previous values on the right.

Inductively, \(N/D\) equals the sum of the masses processed so far. Therefore the final output is exactly
\[ \]
\(M_\sigma=N/D.\)

It remains to bound the arithmetic cost. At every stage, \(D\) is a product of input denominators, so its binary length is at most
\[ \]
\(1+\sum_t\operatorname{bitlength}(b_t)=O(L).\)

All masses are positive and their total is one. Every partial sum consequently lies in \([0,1]\), giving \(0\leq N\leq D\). Thus the numerator also has \(O(L)\) bits.

Let \(\ell_t\) be the combined binary length of \(a_t,b_t\). Schoolbook multiplication and addition implement one update in \(O(L(\ell_t+1))\) bit operations. Since \(\sum_t\ell_t\leq L\) and \(\tau\leq L\), all updates together cost \(O(L^2)\). The output fraction has \(O(L)\) bits.

If a reduced fraction is required, compute \(\gcd(N,D)\) and divide both integers by it. A straightforward Euclidean implementation gives a sufficient additional bound of \(O(L^3)\): every two remainder steps at least halve the current operand, so there are \(O(L)\) divisions, each costing at most \(O(L^2)\).

4. Conclusion and scope

For either matching mode, the proved bounds are:

| Implementation | Exact fraction output | Reduced fraction output |
|---|---:|---:|
| Bit vectors | \(O(\tau n(m+1)+L^2)\) | \(O(\tau n(m+1)+L^3)\) |
| Direct literal-list comparisons | \(O(L^2)\) | \(O(L^3)\) |

The algorithm examines only the \(\tau\) explicitly supported types and the \(n\) explicitly supplied characterisations. It does not enumerate possible types or generate protocol characterisations. Under precisely these input assumptions, exact mass computation is polynomial-time solvable.
