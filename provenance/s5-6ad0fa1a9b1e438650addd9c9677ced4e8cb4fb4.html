The continuous mirror question, as graded

Given a finite set of types \(T\) with rational masses \(\mu_t\) summing to \(1\), baseline score vectors \(p_t\), and a fixed target pairing \(\bar t\) in which paired types have equal mass, find the minimum cost of choosing one revised score vector \(z_t\) for each type, with cost \(\sum_{t\in T}\mu_t\sum_{u\in N(t)}|z_t(u)-p_t(u)|\), such that every nonmatching acceptable pair \(t,u\) satisfies \(z_t(u)\le z_t(\bar t)\) or \(z_u(t)\le z_u(\bar u)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau=|T|\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) counts supported types, not all possible types.
Acceptability is an undirected simple graph \(G=(T,E)\), with \(m=|E|\) and neighbor sets \(N(t)\). The fixed target pairing is a fixed-point-free involution \(t\mapsto\bar t\), with \(\{t,\bar t\}\in E\) and \(\mu_t=\mu_{\bar t}\); all mass of each type is paired with its target type.
Each baseline coordinate \(p_t(u)\) is a nonnegative binary rational. Choose one vector \(z_t\in\mathbb R_{\ge0}^{N(t)}\) for the entire mass of each type; every coordinate, including the target-partner coordinate, may change without an upper bound. Larger scores mean better partners; ties are allowed and require no tie-breaking.
The target pairing must be weakly stable: for every \(\{t,u\}\in E\) with \(u\ne\bar t\), require \(z_t(u)\le z_t(\bar t)\) or \(z_u(t)\le z_u(\bar u)\).
Minimize \(C(z)=\sum_{t\in T}\mu_t\sum_{u\in N(t)}|z_t(u)-p_t(u)|\). Let \(L\) be the total binary encoding length of the input.

Is this exact minimum-cost problem polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?

For finite agents, the corresponding unweighted problem is NP-hard even with unit capacities; it is polynomial-time solvable on bipartite acceptability graphs and admits a polynomial-time \(2\)-approximation on general graphs. [Bérczi–Csáji–Király](https://arxiv.org/pdf/2204.13485)
No result for exactly the mass model specified above was located in the literature search.

Modeling choices made when packaging the task

  • Specified acceptability as an undirected simple graph, excluding self-pairs and allowing general nonbipartite graphs, as in the discrete model.
  • Interpreted the target pairing as a fixed-point-free involution covering every supported type, with acceptable target partners. This makes every target-partner coordinate defined and implies maximality.
  • Restricted baseline scores to nonnegative binary rationals for finite encoding, and revised scores to nonnegative reals, following the discrete score domain.
  • Specified that all coordinates may change without upper bounds and that ties use weak stability without tie-breaking.
  • Defined m as the number of acceptable type pairs and L as the total input encoding length.

Result

The exact minimum-cost problem is NP-hard, even when every mass is the same positive dyadic rational and every baseline score belongs to \(\{0,1\}\). Its decision version is NP-complete.

The proof works directly with supported types and one score vector per type.

1. A normalization lemma

Lemma. Every feasible profile \(z\) can be replaced, without increasing its cost, by a feasible profile that leaves every non-target coordinate at its baseline and only increases target-partner coordinates.

Proof. Fix a type \(t\). Write \(a_t=p_t(\bar t)\), and define
\[ S_t=\{u\in N(t)\setminus\{\bar t\}:z_t(u)\le z_t(\bar t)\}, \qquad h_t=\max\bigl(\{a_t\}\cup\{p_t(u):u\in S_t\}\bigr). \]
Define the replacement profile by
\[ z_t^*(\bar t)=h_t, \qquad z_t^*(u)=p_t(u)\quad\text{for }u\ne\bar t. \]

To compare costs, take any \(u\in S_t\). Since \(z_t(u)\le z_t(\bar t)\),
\[ \begin{aligned} p_t(u)-a_t &=(p_t(u)-z_t(u))+(z_t(u)-z_t(\bar t))+(z_t(\bar t)-a_t)\\ &\le |p_t(u)-z_t(u)|+|z_t(\bar t)-a_t|\\ &\le \sum_{v\in N(t)}|z_t(v)-p_t(v)|. \end{aligned} \]
The final sum is also nonnegative. Taking the maximum over these inequalities and zero gives
\[ h_t-a_t\le \sum_{v\in N(t)}|z_t(v)-p_t(v)|. \]
The replacement changes only the target coordinate, at unweighted cost \(h_t-a_t\). Multiplying by \(\mu_t\) and summing over types proves \(C(z^*)\le C(z)\).

For feasibility, consider any non-target edge \(\{t,u\}\). The feasibility of \(z\) implies \(u\in S_t\) or \(t\in S_u\). In the first case,
\[ z_t^*(u)=p_t(u)\le h_t=z_t^*(\bar t), \]
and the second case gives the corresponding inequality at \(u\). Thus every stability constraint remains satisfied. This proves the lemma.

2. Reduction from Vertex Cover

Let \(H=(V,F)\) be an instance of Vertex Cover, with \(n=|V|\ge1\). A vertex cover is a set \(S\subseteq V\) containing at least one endpoint of every edge. Denote its minimum possible cardinality by \(\operatorname{vc}(H)\).

Let \(P\) be the least power of two satisfying \(P\ge2n\). Construct a society as follows.

  • For each \(v\in V\), create a primary type \(v\) and a private partner \(v'\), with \(\bar v=v'\) and \(\overline{v'}=v\).
  • Add \(P-2n\) further types, partitioned into target pairs. These types have no edges except their target edges.
  • Include every target edge and every edge of \(F\) between primary types.
  • Give every type mass \(\mu_t=1/P\).
  • Set every target-coordinate baseline to zero. For every \(\{v,w\}\in F\), set \(p_v(w)=p_w(v)=1\).

This satisfies all input requirements. In particular, all masses are positive dyadic rationals, their sum is one, and target partners have equal masses. The number \(P-2n\) is even, so the additional target pairs exist.

We prove the exact identity
\[ \operatorname{OPT}=\frac{\operatorname{vc}(H)}{P}. \]

Upper bound

Let \(S\) be any vertex cover of \(H\). Leave all coordinates at baseline except that, for each \(v\in S\), set \(z_v(v')=1\).

Every non-target edge \(\{v,w\}\in F\) has an endpoint in \(S\). At that endpoint, its score equals the target-partner score, so the required weak-stability inequality holds. Ties are permitted by the stated model.

Exactly one coordinate changes by one for each member of \(S\). Therefore
\[ C(z)=\frac{|S|}{P}, \qquad \operatorname{OPT}\le\frac{\operatorname{vc}(H)}{P}. \]

Lower bound

Take any feasible profile \(z\), and apply the normalization lemma to obtain \(z^*\) with \(C(z^*)\le C(z)\).

Every primary target score in \(z^*\) belongs to \(\{0,1\}\), because the lemma selects a maximum of baseline scores. Every private partner and every additional type has target score zero, since it has no non-target neighbors.

Define
\[ S=\{v\in V:z_v^*(v')=1\}. \]
For any \(\{v,w\}\in F\), both non-target scores remain one. Stability therefore requires
\[ 1\le z_v^*(v')\quad\text{or}\quad1\le z_w^*(w'). \]
Consequently \(v\in S\) or \(w\in S\), so \(S\) is a vertex cover. Moreover,
\[ C(z)\ge C(z^*)=\frac{|S|}{P}\ge\frac{\operatorname{vc}(H)}{P}. \]
Together with the upper bound, this proves the identity.

3. Encoding size and decision complexity

Because \(2n\le P<4n\), the constructed instance has
\[ \tau=P<4n, \qquad m=|F|+\frac P2. \]
Each mass requires only \(O(\log n)\) bits, and baseline scores are zero or one. Thus the construction has polynomial binary encoding length.

For a Vertex Cover decision instance with integer bound \(k\), use the cost threshold \(B=k/P\). The proved identity gives
\[ \operatorname{OPT}\le B \quad\Longleftrightarrow\quad \operatorname{vc}(H)\le k. \]
Since Vertex Cover is NP-complete, this is a polynomial-time reduction proving NP-hardness.

For completeness, the decision problem also belongs to NP. By the normalization lemma, it suffices to certify a target score \(h_t\) for each type, chosen from the finite input-derived set
\[ A_t=\{p_t(\bar t)\}\cup \{p_t(u):u\in N(t)\setminus\{\bar t\},\ p_t(u)\ge p_t(\bar t)\}. \]
All non-target coordinates remain at baseline. Such a certificate has polynomial length. A verifier checks every stability inequality and the exact rational cost
\[ \sum_{t\in T}\mu_t\bigl(h_t-p_t(\bar t)\bigr)\le B \]
using polynomial-time binary rational arithmetic.

These finite certificates also establish that the minimum is attained: the finite family is nonempty, because raising every target score to its largest incident baseline is feasible, and every feasible real profile has a no-more-expensive representative in this family.

4. Conclusion

The specified mass model is NP-hard, and its threshold decision version is NP-complete. Hence an exact algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The underlying vertex-cover gadget also appears in [Bérczi–Csáji–Király, Theorem 12](https://arxiv.org/pdf/2204.13485). The construction above explicitly verifies that normalized dyadic masses, equal partner masses, and one vector per supported type preserve the reduction.
