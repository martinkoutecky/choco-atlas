The continuous mirror question, as graded

Given an explicit finite alternative set \(W\), a support \(T_+\) of \(\tau\) complete, equal-depth RCL formula types \(\varphi_t=A^t_1\triangledown\cdots\triangledown A^t_d\), binary-rational masses \(\mu_t>0\) summing to \(1\), and a rational quota \(\alpha\in(0,1]\), define \(h_t(w)=\min\{j:w\models A^t_j\}\) and \(q_\alpha(w)=\min\{k:\sum_{t:h_t(w)\le k}\mu_t\ge\alpha\}\). Compute the alternatives \(w\in W\) minimizing \(q_\alpha(w)\). When \(\mu_t=n_t/n\) and \(\alpha=\tau_0/n\), this agrees with the finite \(F_{\tau_0}\) choice rule on equal-depth profiles.

Packaged proof task (what the prover saw — nothing else)

Let \(W\) be an explicitly listed nonempty set of \(m\) distinct truth assignments over a finite nonempty propositional vocabulary. A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type is an explicitly written priority list \(\varphi_t=A^t_1\triangledown\cdots\triangledown A^t_d\), with common depth \(d\ge1\), where each \(A^t_j\) is a propositional formula and every \(w\in W\) satisfies at least one \(A^t_j\). Earlier positions have higher priority; formulas may overlap, and empty levels retain their positions.
Given a binary-rational quota \(\alpha\in(0,1]\), define \(h_t(w)=\min\{j\in\{1,\ldots,d\}:w\models A^t_j\}\) and \(q_\alpha(w)=\min\{k\in\{1,\ldots,d\}:\sum_{t:h_t(w)\le k}\mu_t\ge\alpha\}\). The output is \(\operatorname*{arg\,min}_{w\in W}q_\alpha(w)\), including every tie. Let \(L\) be the total binary input length; state running times in \(m,\tau,d,L\).

Is computing this choice set solvable in polynomial time in \(m,\tau,d,L\), or is it NP-hard?

Known discrete result: RCL model checking, including computing the truth set of an explicitly supplied formula \(\psi\), takes \(O(m\lVert\psi\rVert)\) time, where \(\lVert\psi\rVert\) is its symbol count ([source](https://www.ifaamas.org/Proceedings/aamas2015/aamas/p979.pdf)). Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Computing the entire choice set is polynomial-time solvable. A conservative bound, including exact rational arithmetic, is \(O((m+\tau+1)L^2+m(\tau+d)L)\) bit operations.

The proof uses the explicitly listed assignments and support directly.

1. Convert masses and quota to integer weights

Write the input rationals as \(\mu_t=a_t/b_t\) and \(\alpha=a_0/b_0\), with positive integer numerators and denominators encoded in binary. Explicit terminating binary fractions can also be converted to this representation within polynomial time.

Define

\(D=\prod_{i=0}^{\tau}b_i,\qquad M_t=a_t(D/b_t),\qquad Q=a_0(D/b_0).\)

Every division is exact. For any subset \(T\subseteq\{1,\ldots,\tau\}\),

\(\sum_{t\in T}\mu_t\ge\alpha\quad\Longleftrightarrow\quad\sum_{t\in T}M_t\ge Q,\)

because multiplication by the positive integer \(D\) preserves inequalities.

The total bit length of the input denominators is \(O(L)\), so

\(\log_2 D=\sum_{i=0}^{\tau}\log_2 b_i=O(L).\)

Thus \(D\) has \(O(L)\) bits, even if its numerical value is large. Moreover, the hypotheses give

\(\sum_{t=1}^{\tau}M_t=D,\qquad 0<Q\le D.\)

Consequently, all weights, quota values, and partial weight sums used below have \(O(L)\) bits. Schoolbook multiplication and division compute these integers in \(O((\tau+1)L^2)\) bit operations.

2. Compute each assignment’s quota rank

Process each \(w\in W\) as follows.

  • For each supported type \(t\), evaluate \(A^t_1,\ldots,A^t_d\) in their original order. Record the first satisfied position as \(h_t(w)\). The coverage hypothesis guarantees that this position exists.
  • Initialize integer buckets \(B_1(w),\ldots,B_d(w)\) to zero. For each type, add \(M_t\) to bucket \(B_{h_t(w)}(w)\).
  • Scan positions in increasing order, maintaining \(C_k(w)=\sum_{j=1}^{k}B_j(w)\). Record the first position for which \(C_k(w)\ge Q\).

For correctness, the bucket construction gives, for every position \(k\),

\(C_k(w)=\sum_{t:h_t(w)\le k}M_t =D\sum_{t:h_t(w)\le k}\mu_t.\)

Therefore,

\(C_k(w)\ge Q\quad\Longleftrightarrow\quad \sum_{t:h_t(w)\le k}\mu_t\ge\alpha.\)

The first position found by the scan is consequently exactly \(q_\alpha(w)\). The scan always succeeds: every type contributes to some bucket, so \(C_d(w)=D\ge Q\).

Overlapping formulas cause no double counting, because each type contributes only at its first satisfied position. Empty levels retain their indices and simply receive zero bucket weight.

3. Return all minimizers

Maintain a current minimum rank and a list of assignments attaining it. When processing an assignment with a smaller rank, replace the list by that assignment; when its rank equals the current minimum, append it.

After any nonempty prefix of the assignment list, this procedure stores exactly the assignments attaining the minimum rank within that prefix. This follows inductively from the three possibilities: smaller, equal, or larger rank. After all assignments have been processed, the stored list is therefore precisely

\(\operatorname*{arg\,min}_{w\in W}q_\alpha(w),\)

including every tie.

4. Running time

Let \(S=\sum_{t=1}^{\tau}\sum_{j=1}^{d}\lVert A^t_j\rVert\), so \(S=O(L)\).

Under the usual indexed-variable representation, bottom-up propositional evaluation takes \(O(S)\) Boolean operations per assignment: each formula node is evaluated once from its children, with atomic values supplied by the assignment. For a conservative bit-operation bound that also allows identifier lookup by scanning the explicit assignment, \(O(L^2)\) per assignment suffices. Thus all formula evaluation and rank extraction cost \(O(mL^2)\).

For each assignment, bucket initialization, the \(\tau\) weight additions, and the scan through \(d\) positions cost \(O((\tau+d)L)\) bit operations. Tracking the minimum and writing the explicitly listed winners fit within the resulting bound. Together with integer preprocessing, the total is

\(O((m+\tau+1)L^2+m(\tau+d)L).\)

This is polynomial in all requested parameters. Since the assignments, types, and levels are explicitly listed, \(m,\tau,d=O(L)\); the displayed bound is also \(O(L^3)\).

The supplied [RCL model-checking result](https://www.ifaamas.org/Proceedings/aamas2015/aamas/p979.pdf) measures the size of the supplied formula. The algorithm above establishes the result directly, without requiring construction of an expanded aggregate formula.
