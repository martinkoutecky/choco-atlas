The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), type parameters \(\alpha_t\), per-capita stakes \(w_0,w_1\), and a rational polytope \(\mathcal Q\) of limiting obstruction profiles \((u,v)\), compute the minimum \(\kappa\) and an optimal offer-rate vector \(p\) satisfying \(\kappa=\min_{p\ge0}\sum_{t\in T}\mu_t p_t\), subject to \(\sum_{t\in T}(u_t+v_t)p_t+\sum_{t\in T}v_t\alpha_t(w_1-w_0)\ge w_0\) for every \((u,v)\in\mathcal Q\); determine whether \(\kappa\le w_1\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=2\) alternatives, status quo and reform. Inputs include binary-rational parameters \(\alpha_t\ge0\) and per-capita stakes \(0<w_0<w_1\). An offer rate \(p_t\ge0\) is paid per unit mass of type \(t\).
The complete family of obstruction profiles is supplied as a nonempty rational polytope \(\mathcal Q=\{(u,v):A(u,v)\le b\}\), with \(r\) explicitly listed inequalities, contained in \(\{(u,v):u_t,v_t\ge0,\ u_t+v_t\le\mu_t\text{ for every }t\}\).
Here \(u_t\) and \(v_t\) are absolute masses of nonpivotal and pivotal obstruction participants, respectively; their counteroffer costs per unit mass are \(p_t\) and \(p_t+\alpha_t(w_1-w_0)\). The supplied polytope is the input; no underlying voting rule must be reconstructed.
Define \(\kappa=\min_{p\in\mathbb R_{\ge0}^{T}}\sum_{t\in T}\mu_t p_t\), subject to \(\sum_{t\in T}(u_t+v_t)p_t+\sum_{t\in T}v_t\alpha_t(w_1-w_0)\ge w_0\) for every \((u,v)\in\mathcal Q\).
Set \(\kappa=+\infty\) when infeasible; equality in a deterrence constraint or in \(\kappa\le w_1\) is accepted. Let \(L\) be the total binary input length; state running times in \(m,\tau,r,L\).

Is deciding whether \(\kappa\le w_1\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? Can \(\kappa\) and an optimal offer-rate vector, when feasible, be computed in time polynomial in \(m,\tau,r,L\)?

For finite legislatures, the minimum deterrent expenditure equals the maximum subbalanced weighted obstruction worth, and comparison with the first lobby’s stake characterizes the selected equilibrium outcome ([Le Breton, Sudhölter and Zaporozhets](https://www.tse-fr.eu/sites/default/files/medias/doc/by/zaporozhets/sequential.pdf)).
No result addressing exactly the supplied-polytope mass problem was located in the literature search.

  • Interpreted u and v as absolute masses of disjoint nonpivotal and pivotal participants, imposing coordinatewise nonnegativity and u_t + v_t <= mu_t.

Result

The decision problem is in \(\mathrm P\). Moreover, whenever deterrence is feasible, \(\kappa\) and an optimal offer-rate vector can be computed exactly in time polynomial in \(m,\tau,r,L\), with \(m=2\).

The proof uses the supplied polytope directly and standard linear programming duality.

1. The inner minimization problem

Write \(x=(u,v)\in\mathbb R^{2\tau}\), and define

\(\displaystyle a_t=\alpha_t(w_1-w_0),\qquad c(p)=(p,p+a).\)

Thus every \(a_t\) is nonnegative, and the deterrence condition for an offer vector \(p\) is

\(\displaystyle \min_{x\in\mathcal Q}c(p)^{\mathsf T}x\ge w_0.\)

The promised containment of \(\mathcal Q\) implies that every coordinate of \(x\in\mathcal Q\) is between zero and the corresponding \(\mu_t\). Because \(\mathcal Q\) is nonempty and closed, it is compact. Consequently, for every fixed \(p\), this inner minimization is feasible, has a finite value, and attains its minimum.

Use exactly the supplied representation \(Ax\le b\), treating \(x\) as unrestricted in sign in the LP formulation. Its nonnegativity already follows from the promised containment. The dual of the inner problem is

\(\displaystyle \max_{y\in\mathbb R^r_{\ge0}}\{-b^{\mathsf T}y:A^{\mathsf T}y=-c(p)\}.\)

To check the signs explicitly, if \(Ax\le b\), \(y\ge0\), and \(A^{\mathsf T}y=-c(p)\), then

\(\displaystyle c(p)^{\mathsf T}x=-y^{\mathsf T}Ax\ge-y^{\mathsf T}b.\)

Linear programming strong duality applies because the primal is feasible with finite optimum. Therefore the dual has an optimal solution and the same optimal value.

2. An exact finite LP

Partition the columns of \(A\) as \(A=(A_u\ A_v)\). Strong duality gives the following equivalence for every \(p\ge0\):

\(\displaystyle p\text{ deters every }x\in\mathcal Q \quad\Longleftrightarrow\quad \exists y\ge0:\ A_u^{\mathsf T}y=-p,\ A_v^{\mathsf T}y=-p-a,\ -b^{\mathsf T}y\ge w_0.\)

Indeed, the forward direction follows by taking an optimal inner dual solution. The reverse direction follows from the weak-duality inequality proved above.

It follows that \(\kappa\) is exactly the optimal value of the finite rational LP

\(\displaystyle \text{minimize }\mu^{\mathsf T}p\)

subject to

\(\displaystyle p\ge0,\qquad y\ge0,\)

\(\displaystyle A_u^{\mathsf T}y+p=0,\qquad A_v^{\mathsf T}y+p=-a,\)

\(\displaystyle b^{\mathsf T}y\le-w_0.\)

This LP has \(\tau+r\) variables, \(2\tau\) scalar equalities, and \(\tau+r+1\) scalar inequalities, counting nonnegativity.

For the decision problem, add the single inequality

\(\displaystyle \mu^{\mathsf T}p\le w_1.\)

The resulting LP is feasible exactly when an offer vector with expenditure at most \(w_1\) deters every profile. The attainment argument below establishes that this is equivalent to \(\kappa\le w_1\), including equality.

3. Feasibility and attainment

There is also a direct characterization of infeasibility:

\(\displaystyle \text{Deterrence is feasible}\quad\Longleftrightarrow\quad 0\notin\mathcal Q.\)

Proof. If \(0\in\mathcal Q\), its deterrence constraint reads \(0\ge w_0\), which is impossible because \(w_0>0\).

Conversely, suppose \(0\notin\mathcal Q\). Define

\(\displaystyle s(u,v)=\sum_{t\in T}(u_t+v_t).\)

All coordinates in \(\mathcal Q\) are nonnegative, so \(s(u,v)=0\) holds exactly at the origin. Compactness and exclusion of the origin therefore imply

\(\displaystyle \delta=\min_{(u,v)\in\mathcal Q}s(u,v)>0.\)

Set \(p_t=w_0/\delta\) for every type. For every profile in \(\mathcal Q\),

\(\displaystyle \sum_t(u_t+v_t)p_t+\sum_t v_ta_t \ge \frac{w_0}{\delta}s(u,v)\ge w_0.\)

This proves feasibility. In particular, under the stated promises, infeasibility can be recognized simply by testing whether the origin satisfies the supplied inequalities.

Now suppose deterrence is feasible, and choose any feasible vector \(p^{(0)}\). Let \(C=\mu^{\mathsf T}p^{(0)}\). The feasible offer set is closed: it is an intersection of closed halfspaces and the nonnegative orthant. Its expenditure sublevel set

\(\displaystyle \{p:p\text{ is feasible},\ \mu^{\mathsf T}p\le C\}\)

is nonempty and closed. It is also bounded, because positivity of every \(\mu_t\) implies

\(\displaystyle 0\le p_t\le C/\mu_t.\)

Hence this sublevel set is compact, and the continuous objective \(\mu^{\mathsf T}p\) attains its minimum there. Any vector outside the sublevel set has expenditure greater than \(C\), so this attained minimum is the global minimum. Thus every feasible instance has an optimal offer vector.

4. Exact polynomial-time computation

Every coefficient in the finite LP is rational. Computing \(a_t=\alpha_t(w_1-w_0)\) increases binary encoding length by at most a polynomial in \(L\): rational subtraction and multiplication have this property. The dimensions and total encoding length of the constructed LP are therefore polynomial in \(\tau,r,L\).

The standard polynomial-time theorem for rational linear programming provides exact feasibility decisions and, for a feasible LP with finite optimum, an exact rational optimal solution and value. Its hypotheses hold here:

  • The formulation is a finite rational LP of polynomial encoding length.
  • On a feasible instance, the objective is bounded below by zero.
  • The optimum is attained, as established above.

Therefore an algorithm can return \(+\infty\) on an infeasible instance; otherwise it can return an optimal solution \((p^*,y^*)\) and compute \(\kappa=\mu^{\mathsf T}p^*\) exactly. Feasibility of the budget-augmented LP decides \(\kappa\le w_1\) without numerical tolerance, so equality is accepted.

Both procedures run in time \((m+\tau+r+L)^{O(1)}\), with \(m=2\). Consequently, the problem is polynomial-time solvable; an \(\mathrm{NP}\)-hardness classification under polynomial-time reductions would imply \(\mathrm P=\mathrm{NP}\).
