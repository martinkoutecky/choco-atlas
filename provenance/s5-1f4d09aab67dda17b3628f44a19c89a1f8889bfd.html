Theorem 6.3 — class: other

The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), and rational per-agent coefficients \(a_t\ge 0\) with \(Z=\sum_{t\in T}\mu_ta_t>0\), consider any admissible type maps \(g_t:[0,1]\to[0,1]\) and the atomless population aggregate \(F(x)=Z^{-1}\sum_{t\in T}\mu_ta_t\int_0^1g_t(x_t(u))\,du\). For each \(N\) with \(N\mu_t\) integral, form the finite replica with \(N\mu_t\) agents of type \(t\), each weighted \(a_t/(NZ)\). Compute the limits, as \(N\) grows through such values, of the sums of the paper's \(\phi\)- and \(\psi\)-importance indices within each type.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types. Each type has a binary-rational coefficient \(a_t\geq0\), with \(Z=\sum_t\mu_ta_t>0\).
Admissible maps \(g_t:[0,1]\to[0,1]\) are continuous, surjective and weakly increasing. Each type occupies an atomless unit interval with Lebesgue measure; profiles \(x_t:[0,1]\to[0,1]\) are measurable, and \(F(x)=Z^{-1}\sum_t\mu_ta_t\int_0^1g_t(x_t(u))\,du\).
For every integer \(N\geq2\) with all \(N\mu_t\) integral, let \(A_N\) contain \(N\mu_t\) agents of type \(t\), and define \(f_N(x)=\sum_{i\in A_N}a_{t(i)}g_{t(i)}(x_i)/(NZ)\).
For a finite aggregation function \(f\), write \(R_f(S,x)=f(x_S,\mathbf1_{A\setminus S})-f(x_S,\mathbf0_{A\setminus S})\). Define \(\phi_i(f)=\mathbb E[R_f(P_i,x)-R_f(P_i\cup\{i\},x)]\), where the ordering is uniform, \(P_i\) contains agents preceding \(i\), and states are independent uniform draws from \([0,1]\).
Define \(\widetilde\psi_i(f)=\mathbb E[f(x_{-i},1)-f(x_{-i},0)]\) under the same state distribution, and \(\psi_i(f)=\widetilde\psi_i(f)/\sum_j\widetilde\psi_j(f)\).
The requested outputs are \(\lim_{N\to\infty}\sum_{i:t(i)=t}\phi_i(f_N)\) and \(\lim_{N\to\infty}\sum_{i:t(i)=t}\psi_i(f_N)\), for every supported type, along the admissible replica sizes.

Is exact computation of these typewise replica limits uniformly over admissible maps possible in polynomial time, or is it NP-hard? State running times in \(m=1\), \(\tau\) and the total rational-input bit length \(L\).

Known finite result: for every separable aggregate \(f(x)=\sum_iw_ih_i(x_i)\) with nonnegative weights summing to \(1\) and admissible maps, \(\phi_i(f)=\psi_i(f)=w_i\). [Source](https://arxiv.org/pdf/1803.04138v2).
Consequently, the specified replica-limit computation is already covered by this finite identity; its complexity is not an open literature question.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

For \(m=1\), exact computation is polynomial-time solvable. Both requested limits equal
\[ \boxed{\frac{\mu_ta_t}{Z}} \]
for every supported type \(t\). They are independent of the admissible maps.

Endpoint values and finite weights. Since \(g_t\) is increasing and surjective onto \([0,1]\), its minimum and maximum occur at its endpoints, and therefore
\[ g_t(0)=0,\qquad g_t(1)=1. \]
Fix an admissible replica size \(N\), and define
\[ w_i=\frac{a_{t(i)}}{NZ}. \]
These weights are nonnegative, and
\[ \sum_{i\in A_N}w_i =\frac{\sum_{t\in T}(N\mu_t)a_t}{NZ}=1. \]
Thus \(f_N(x)=\sum_{i\in A_N}w_i g_{t(i)}(x_i)\).

Direct computation of both indices. For every subset \(S\subseteq A_N\) and every state vector \(x\), the contributions of agents in \(S\) cancel in the defining difference. Hence
\[ R_{f_N}(S,x) =\sum_{j\notin S}w_j\bigl(g_{t(j)}(1)-g_{t(j)}(0)\bigr) =\sum_{j\notin S}w_j. \]
Because \(i\notin P_i\), this gives, for every ordering and state vector,
\[ R_{f_N}(P_i,x)-R_{f_N}(P_i\cup\{i\},x)=w_i. \]
Taking expectations proves \(\phi_i(f_N)=w_i\).

Likewise, for every choice of the other agents’ states,
\[ f_N(x_{-i},1)-f_N(x_{-i},0)=w_i. \]
Consequently \(\widetilde\psi_i(f_N)=w_i\). Since the weights sum to \(1\), normalization gives \(\psi_i(f_N)=w_i\). This directly proves the supplied finite identity in the present setting.

Typewise replica limits. There are exactly \(N\mu_t\) agents of type \(t\), so for every admissible \(N\),
\[ \sum_{i:t(i)=t}\phi_i(f_N) =\sum_{i:t(i)=t}\psi_i(f_N) =(N\mu_t)\frac{a_t}{NZ} =\frac{\mu_ta_t}{Z}. \]
The admissible sizes are unbounded: every sufficiently large multiple of a common denominator of the masses is admissible. Since both sequences are constant along these sizes, both limits exist and have the stated values. Types with \(a_t=0\) receive zero; the hypothesis \(Z>0\) guarantees that normalization is defined.

Exact algorithm and running time. Compute \(b_t=\mu_ta_t\), sum \(Z=\sum_t b_t\), and output \(b_t/Z\) for both indices. For \(m=1\), this takes \(O(\tau)\) exact arithmetic operations.

Here is an explicit polynomial bit bound under standard binary numerator-and-denominator encoding. Write
\[ \mu_t=\frac{p_t}{q_t},\qquad a_t=\frac{r_t}{s_t}, \]
with positive denominators, and set
\[ D=\prod_{t\in T}q_ts_t,\qquad c_t=p_tr_t\frac{D}{q_ts_t},\qquad C=\sum_{t\in T}c_t. \]
Each \(c_t\) is an integer, \(C=DZ>0\), and the exact output is \(c_t/C\). All intermediate integers have \(O(L)\) bits: their lengths are bounded by sums of input integer lengths, with at most an additional \(O(\log\tau)\) bits for summation. There are \(O(\tau)\) integer operations. Schoolbook multiplication and division therefore give a bit running time of
\[ O(\tau L^2). \]
Unreduced fractions already constitute exact outputs. No replica population needs to be constructed, and no evaluation or representation of the maps is needed.

Thus the problem belongs to polynomial time uniformly over all admissible maps. An NP-hardness claim under polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).
