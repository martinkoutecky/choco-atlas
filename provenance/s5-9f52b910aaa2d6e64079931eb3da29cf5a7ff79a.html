Theorem 1 — class: algorithmic

The continuous mirror question, as graded

Given supported vacancy types \(U\) and applicant types \(V\), with rational masses \(\alpha_u\) and \(\beta_v\) summing to \(1\) on each side, and each type’s incomplete weak ranking of the other side’s types, compute the aspiration intensities \(a_{uv}\) for mutually ranked pairs \(E\) that maximize \(\sum_{(u,v)\in E}\lambda_{uv}h_{uv}a_{uv}\), subject to \(\sum_{(u,v)\in E}\lambda_{uv}a_{uv}^{2}=1\) and \(0<a_{uv}\leq1\). Here \(\lambda_{uv}=\alpha_u\beta_v/\sum_{(u',v')\in E}\alpha_{u'}\beta_{v'}\), the normalized Borda score of a type is the mass it ranks below plus half the tied mass divided by the mass it ranks, and \(h_{uv}\) is the paper’s regularized reciprocal-difference coefficient for the two sides’ scores.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of its \(\tau\) types with positive binary rational masses; \(\tau\) is the support size, not the number of possible types. Here the supports are vacancy types \(U\) and applicant types \(V\), with \(\tau=|U|+|V|\), \(m=\max\{|U|,|V|\}\), and total input bit length \(L\).
Each side has total mass \(1\). Each type supplies a weak ranking of a nonempty subset of the opposite support; ties remain ties. Let \(E\ne\varnothing\) contain exactly the mutually ranked pairs.
For a ranked pair, define \(s_{uv}\) as the applicant mass strictly below \(v\) in \(u\)'s ranking plus half the mass tied with \(v\), including \(v\)'s own mass, divided by the total applicant mass ranked by \(u\). Define \(t_{uv}\) symmetrically using vacancy masses and \(v\)'s ranking.
Given a binary rational \(b>1\), set \(h_{uv}=b^{-|s_{uv}-t_{uv}|}\) and \(\lambda_{uv}=\alpha_u\beta_v/\sum_{(u',v')\in E}\alpha_{u'}\beta_{v'}\).
The optimization problem is to compute aspiration intensities maximizing \(\sum_{(u,v)\in E}\lambda_{uv}h_{uv}a_{uv}\), subject to \(\sum_{(u,v)\in E}\lambda_{uv}a_{uv}^{2}=1\) and \(0<a_{uv}\leq1\) for every \((u,v)\in E\).

Is computing an exact optimizer for this problem possible in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite lists of agents, an explicit closed-form optimizer is known for the corresponding unweighted quadratic-normalization aspiration problem ([Yu and Yue, 2017](https://doi.org/10.12973/ejmste/78100)). No result settling this exact mass-weighted problem was identified in the search.

Modeling choices made when packaging the task

  • Specified the regularized reciprocal-difference coefficient as b raised to minus the absolute score difference, with b>1 supplied as a binary rational and included in L.
  • Required nonempty ranking domains and a nonempty mutually ranked pair set so that score and pair-weight denominators are defined.
  • Interpreted tied mass as the entire indifference class, including the evaluated type's mass, as appropriate for a distribution of individuals.
  • Retained the graded mass Borda convention; the finite generalized Borda convention has an additional half-unit offset that has no specified individual-mass counterpart.
  • Retained the graded closed upper bound on aspiration intensities; the finite model uses a strict upper bound.
  • Defined m as the larger support size, tau as the combined support size, and L as the total binary input length.
  • Did not translate inequalities between finite agent counts into inequalities between support sizes: both continuous populations have unit mass, and support sizes count types rather than individuals.
  • Specified exact optimizer computation as the computational question.

Result and interpretation

An exact optimizer can be computed in time polynomial in \(m,\tau,L\): the unique feasible vector is \(a_{uv}=1\) for every \((u,v)\in E\).

The normalization makes the entire stated problem degenerate, including instances with arbitrarily large supports. I retain the explicitly specified constraints below, then explain the difference from the nontrivial finite-agent formulation.

Proof for the stated problem

Write \(\alpha_u>0\) and \(\beta_v>0\) for the masses of vacancy type \(u\) and applicant type \(v\), respectively. Define

\(Z=\sum_{(u,v)\in E}\alpha_u\beta_v.\)

Because \(E\ne\varnothing\) and every mass is positive, \(Z>0\). Consequently,

\(\lambda_{uv}=\alpha_u\beta_v/Z>0\quad\text{and}\quad\sum_{(u,v)\in E}\lambda_{uv}=1.\)

Let \(a\) be any feasible vector. The bounds \(0<a_{uv}\leq1\) imply \(1-a_{uv}^{2}\geq0\). Subtracting the quadratic normalization from the sum of the weights gives

\(\sum_{(u,v)\in E}\lambda_{uv}(1-a_{uv}^{2})=1-1=0.\)

Every summand is nonnegative. A finite sum of nonnegative numbers equals zero only if every summand equals zero. Since each \(\lambda_{uv}>0\), we obtain \(a_{uv}^{2}=1\) for every edge. Positivity then implies \(a_{uv}=1\).

Conversely, the vector with every coordinate equal to \(1\) satisfies both the coordinate bounds and the normalization. Thus the feasible set contains exactly this vector, which is necessarily the unique optimizer.

This argument requires no evaluation of \(s_{uv}\), \(t_{uv}\), or \(h_{uv}\). Their definitions are well-defined because every ranked subset is nonempty and all masses are positive, but their values cannot affect a singleton feasible set.

Exact algorithm and complexity

Parse the rankings, identify the mutually ranked pairs, and output \(((u,v),1)\) for each \((u,v)\in E\).

There are at most \(|U||V|\leq m^{2}\) possible pairs. Membership tables for the two sides’ rankings allow mutual acceptability to be checked for every pair in polynomial time. Parsing the explicit input and writing the indexed output also take polynomial time in \(m,\tau,L\).

Every output coordinate is the rational number \(1\), with constant-size encoding. Hence this is an exact algorithm in the ordinary bit model; no algebraic-number representation or numerical approximation is needed.

The nontrivial finite-agent comparison

Yu and Yue’s model uses the unweighted normalization \(\sum a_{ij}^{2}=1\), as shown in model (M-1) and Theorem 1 on page 8158. [Yu and Yue, 2017](https://www.ejmste.com/download/extend-topsis-based-two-sided-matching-decision-in-incomplete-indifferent-order-relations-setting-5201.pdf)

The distinction changes the feasible region. If \(N=|E|\) and all edge weights are \(1/N\), the normalization in the present task becomes \(\sum_{(u,v)\in E}a_{uv}^{2}=N\), which forces every coordinate to its upper bound.

For comparison, retaining the present objective but replacing the normalization by \(\sum_{(u,v)\in E}a_{uv}^{2}=1\) gives a nontrivial allocation when \(N>1\). Put \(c_{uv}=\lambda_{uv}h_{uv}>0\). Its unique optimizer is

\(a_{uv}^{*}=\dfrac{c_{uv}}{\sqrt{\sum_{(u',v')\in E}c_{u'v'}^{2}}}.\)

Indeed, Cauchy–Schwarz bounds the objective by \(\sqrt{\sum c_{uv}^{2}}\), with equality precisely when the vector \(a\) is a positive scalar multiple of \(c\). The normalization fixes that scalar, and the displayed coordinates lie in \((0,1]\). This comparison explains the nontrivial closed-form allocation, but it changes an explicit constraint and is therefore a different computational problem.
