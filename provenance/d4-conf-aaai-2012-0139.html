The continuous mirror question, as graded

Given finite agent-type and house-type sets \(P,Q\), rational masses \(\mu_p\) and supplies \(\nu_q\) summing to one, weak preference orders over \(Q\), an endowment type \(e(p)\) satisfying \(\sum_{p:e(p)=q}\mu_p=\nu_q\), and a strict priority order on \(Q\), define mass-TTAS by the corresponding paired-symmetric absorbing-set deletions and priority-driven cycle updates, moving the maximum feasible mass along each implemented cycle and splitting residual types as needed. Does every such instance terminate in a number of rounds polynomial in the support size \(\tau\) and input bit length \(L\), or can some instances require superpolynomially many rounds?

Packaged proof task (what the prover saw — nothing else)

Let \(P\) be a finite set of agent types and \(Q\) a finite set of house types, with \(m=|Q|\). A society is given by its support: the list of the \(\tau=|P|\) types with positive mass, each mass encoded as a binary rational; \(\tau\) is the support size, not the number of possible types. Each type has a complete, transitive weak preference order over \(Q\) and an endowment type \(e(p)\). Positive rational masses and supplies satisfy \(\sum_p\mu_p=\sum_q\nu_q=1\) and \(\sum_{p:e(p)=q}\mu_p=\nu_q\). A strict priority order on \(Q\) is supplied. Let \(L\) be the total input bit length; state bounds in \(m,\tau,L\).
Maintain active holdings \(x_{pq}\), initially \(x_{p,e(p)}=\mu_p\) and zero elsewhere; a positive entry represents a block of type \(p\) currently holding type \(q\). Merge blocks with identical \((p,q)\).
At the start of each round, construct a bipartite digraph with positive blocks and house types having positive active supply. Each block points to every maximally preferred active house type; each house type points to all blocks holding it. An absorbing set is a strongly connected component with no outgoing edge. It is paired-symmetric if every vertex has a neighbor joined to it in both directions.
Finalize and delete all paired-symmetric absorbing sets, assigning their blocks their current holdings. In each other absorbing set identified at the start of the round, retain for each block holding \(q\) only its edge to the first maximally preferred house type strictly after \(q\) in the priority order, wrapping to the first maximally preferred type if necessary; retain all house-to-holder edges.
Batch trades using this frozen graph: give each block residual capacity equal to its current mass, repeatedly choose the lexicographically first simple directed cycle under the input label order (represent cycles by their least cyclic rotation), and reserve \(\delta\), the minimum residual block capacity on that cycle. Reduce each participating block's residual capacity by \(\delta\), discard exhausted blocks, and continue until no cycle remains. Apply all reserved trades simultaneously: on a cycle with blocks \((p_i,q_i)\) pointing to \(q_{i+1}\), subtract \(\delta\) from each \(x_{p_iq_i}\) and add it to \(x_{p_iq_{i+1}}\), with cyclic indices. Newly received holdings participate only in the next round. Include cycles whose participants are indifferent between their old and new holdings. Termination means no active mass remains; one round comprises this deletion and trading batch.
Does every instance of this mass-TTAS process terminate within a number of rounds polynomial in \(m,\tau,L\), or can instances require superpolynomially many rounds, possibly infinitely many?
Discrete TTAS terminates, but for suitable supplied priorities there are markets with \(n=2k+1\) agents requiring at least \(2^k\) rounds ([Aziz–de Keijzer](https://comsoc-community.org/assets/proceedings/comsoc-2012/Aziz.pdf)). No result settling the round complexity of the mass process specified here was located.

Modeling choices made when packaging the task

  • Restricted P and Q to positive-mass and positive-supply support; defined m as the number of house types and L as the total input bit length.
  • Interpreted splitting through current-holding blocks (p,q), merging identical blocks; house types point to all positive-mass current holders.
  • Resolved the priority successor as the first maximally preferred type strictly after the currently held type, with wraparound.
  • Finalized departing blocks at their current holdings and retained cycles consisting entirely of indifferent trades.
  • Resolved overlapping mass cycles by lexicographic residual-capacity batching on a frozen graph, with simultaneous updates and received holdings deferred to the next round; input labels determine the auxiliary order.
  • Counted one deletion-and-trading batch as a round and included nontermination as an infinite round count.
