The continuous mirror question, as graded

Given voter types \(k\) with binary-rational masses \(\mu_k\), per-unit voting weights \(a_k\) satisfying \(\sum_k \mu_k a_k=1\), and quota \(q\), compute the allocation \(x\) minimizing \(\max\{1-\sum_k z_kx_k: 0\le z_k\le\mu_k,\ \sum_k a_kz_k\ge q\}\), subject to \(x_k\ge0\) and \(\sum_k\mu_kx_k=1\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) voter types with positive binary-rational masses \(\mu_k\), where \(\sum_k\mu_k=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a nonnegative binary-rational per-unit voting weight \(a_k\), with \(\sum_k\mu_ka_k=1\); the binary-rational quota satisfies \(0<q<1\). Each type's population is nonatomic.
A coalition is any real vector \(z\) with \(0\le z_k\le\mu_k\); it wins exactly when \(\sum_ka_kz_k\ge q\), and its worth is then \(1\), otherwise \(0\).
An allocation assigns a real payoff density \(x_k\ge0\) to each type, with \(\sum_k\mu_kx_k=1\); coalition \(z\) receives \(\sum_kz_kx_k\).
The computational problem is to compute any exact minimizer of \(F(x)=\max\{1-\sum_kz_kx_k:0\le z_k\le\mu_k,\ \sum_ka_kz_k\ge q\}\) over these allocations.
Let \(L\) be the total binary input length. State running times in \(\tau\) and \(L\); there is no separate alternative-count parameter \(m\).

Is this exact allocation problem solvable in polynomial time in \(\tau\) and \(L\), or is it NP-hard?

For discrete weighted majority games with nonnegative integer weights, the nucleus and nucleolus uniquely equal normalized weights whenever \(\min\{\bar q,1-\bar q\}m^{\circ}>2tW^2\), where \(\bar q\) is the normalized quota, \(t\) counts distinct weights, \(W\) is the largest integer weight, and \(m^{\circ}\) is the smallest weight-type multiplicity. [Kurz–Napel–Nohn](https://arxiv.org/html/1310.0004v3)
Without that condition, constructing a discrete least-core allocation is NP-hard. [Elkind–Goldberg–Goldberg–Wooldridge](https://www.cs.ox.ac.uk/people/paul.goldberg/papers/wvg.pdf)

Modeling choices made when packaging the task

  • Normalized population mass to one because the society is a distribution over types; voting weight and payoff totals remain separately normalized to one.
  • Specified nonnegative binary-rational voting weights and a binary-rational quota strictly between zero and one, following the normalized weighted-majority domain.
  • Made each type nonatomic and allowed arbitrary real coalition submasses, so individual rationality gives nonnegative payoff densities.
  • Requested any exact minimizing allocation because the graded question minimizes only the largest excess and specifies no further selection among minimizers.

Result

The problem is polynomial-time solvable. For every instance satisfying the stated hypotheses, the unique minimizer is \(x_k^*=a_k\) for every \(k\), and the optimal value is \(F(x^*)=1-q\).

Computing this allocation requires only copying the input weights, taking \(O(\tau+L)\) bit operations.

1. A universal lower bound

Define the coalition \(z^0\) by \(z_k^0=q\mu_k\). Since \(0<q<1\) and every \(\mu_k>0\), it satisfies \(0<z_k^0<\mu_k\). Its voting weight is

\(\displaystyle \sum_k a_kz_k^0=q\sum_k\mu_ka_k=q.\)

Thus \(z^0\) wins. For every feasible allocation \(x\), its payoff is

\(\displaystyle \sum_k z_k^0x_k=q\sum_k\mu_kx_k=q.\)

Because \(F(x)\) maximizes dissatisfaction over all winning coalitions, this proves \(F(x)\ge 1-q\).

The maximum defining \(F\) exists: the winning-coalition set is nonempty, closed, and bounded, and the maximized function is continuous.

2. The weights attain the bound

Set \(x_k^*=a_k\). This allocation is nonnegative and satisfies \(\sum_k\mu_kx_k^*=1\).

For every winning coalition \(z\),

\(\displaystyle \sum_k z_kx_k^*=\sum_k a_kz_k\ge q.\)

Consequently \(F(x^*)\le 1-q\). Together with the preceding lower bound, this gives \(F(x^*)=1-q\) and proves optimality.

3. Uniqueness, including zero-weight types

Write \(u\cdot v=\sum_k u_kv_k\). Let \(x\) be any feasible allocation different from \(a\). Since \(\sum_k\mu_ka_k=1\), the vector \(a\) is nonzero. Define

\(\displaystyle \lambda=\frac{a\cdot x}{a\cdot a},\qquad d=x-\lambda a.\)

Then \(a\cdot d=0\). Moreover, \(d\ne0\): otherwise \(x=\lambda a\), and the two normalization equations would imply \(\lambda=1\), contradicting \(x\ne a\). Therefore

\(\displaystyle x\cdot d=(\lambda a+d)\cdot d=d\cdot d>0.\)

We now perturb the coalition from Section 1. Define

\(\displaystyle \eta=\min\{q,1-q\}\min_k\mu_k>0,\qquad \varepsilon=\frac{\eta}{2\max_k|d_k|}>0,\qquad z=q\mu-\varepsilon d.\)

For every coordinate, \(|\varepsilon d_k|\le\eta/2\), while both distances from \(q\mu_k\) to the endpoints of \([0,\mu_k]\) are at least \(\eta\). Hence \(0<z_k<\mu_k\).

Its voting weight remains exactly the quota:

\(\displaystyle a\cdot z=q(a\cdot\mu)-\varepsilon(a\cdot d)=q.\)

Thus \(z\) wins, but its payoff under \(x\) is

\(\displaystyle x\cdot z=q(x\cdot\mu)-\varepsilon(x\cdot d)=q-\varepsilon(d\cdot d)<q.\)

It follows that \(F(x)>1-q\). Every feasible allocation different from \(a\) is therefore strictly worse. This argument also covers coordinates with \(a_k=0\).

4. Algorithm and relation to the discrete results

On the promised valid input, output \(x_k=a_k\) for each listed type. No arithmetic or optimization is required. Scanning the input and copying these rational encodings takes \(O(\tau+L)\) bit operations, with output length \(O(L)\).

The cited [Kurz–Napel–Nohn result](https://arxiv.org/html/1310.0004v3) and [Elkind–Goldberg–Goldberg–Wooldridge hardness result](https://www.cs.ox.ac.uk/people/paul.goldberg/papers/wvg.pdf) concern discrete games. The decisive feature here is that \(q\mu\), and sufficiently small perturbations of it, are admissible coalitions. Indivisible voters do not generally permit these coalitions. The proof above settles the specified continuous problem directly for every allowed quota and support.
