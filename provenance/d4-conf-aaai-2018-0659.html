The continuous mirror question, as graded

Given channels \(C\), a weighted diversity graph \((D,W)\), viewer types \(T\) with rational masses \(\mu_t\) summing to \(1\) and preference sets \(P_t\), a block social graph \(H\), a hop bound \(h\), and a population-share threshold \(\rho\), choose a nonempty channel set \(K\) and selected masses \(x_t\in[0,\mu_t]\). Require \(\sum_{t:q\in P_t}x_t\ge\rho\) for every \(q\in K\), require \(P_t\cap K\ne\varnothing\) whenever \(x_t>0\), and require every pair of types with positive selected mass to be at distance at most \(h\) in \(H\). Find a feasible pair \((x,K)\) maximizing \(\sum_{[q,r]\in D(K)}W[q,r]/|K|\), or report that none exists.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a set of \(m\ge 1\) channels. Its diversity graph \((C,D)\) is simple and undirected, with binary rational weights \(W[q,r]\in[0,1]\); absent edges contribute zero.
A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\), each with a preference set \(P_t\subseteq C\). Here \(\tau\) is the support size, not the number of possible types.
The block social graph \(H\) is a simple undirected unweighted graph on \(T\). Distances are shortest hop distances in the full graph, allowing unselected intermediate types; disconnected pairs have distance \(\infty\), and \(d_H(t,t)=0\). Input also includes a positive integer \(h\) and a binary rational threshold \(\rho\in(0,1]\), measured against the entire society.
Choose \(\varnothing\ne K\subseteq C\) and real selected masses \(0\le x_t\le\mu_t\), satisfying \(\sum_{t:q\in P_t}x_t\ge\rho\) for every \(q\in K\), \(P_t\cap K\ne\varnothing\) whenever \(x_t>0\), and \(d_H(t,u)\le h\) whenever \(x_t,x_u>0\).
Find a feasible pair maximizing \(\omega(K)=\frac{\sum_{\{q,r\}\in D(K)}W[q,r]}{|K|}\), where \(D(K)\) consists of diversity edges with both endpoints in \(K\), each counted once, or report infeasibility. Any maximizer is acceptable.
Is this exact continuous optimization problem solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,L,h\), where \(L\) is the total binary input length.
The discrete counterpart, selecting individual viewers with a positive minimum viewer count per channel, is NP-hard and inapproximable within any finite factor unless \(\mathrm{P}=\mathrm{NP}\). [Source](https://cdn.aaai.org/ojs/11310/11310-13-14838-1-2-20201228.pdf)
A later discrete study reiterates these hardness claims. [Source](https://pure.psu.edu/en/publications/on-efficient-processing-of-queries-for-live-multi-streaming-soire/) No result settling exactly the mass formulation above was found in the literature search.

Modeling choices made when packaging the task

  • Specified binary rational diversity weights in [0,1], following the discrete weight domain and making the input finite.
  • Specified simple undirected diversity and social graphs, with the block social graph having exactly the support types as vertices and same-type distance zero.
  • Specified distances in the full social graph, allowing unselected intermediate types, as in the discrete definition; disconnected pairs have infinite distance.
  • Specified a positive integer hop bound and a population-share threshold in (0,1], preserving a positive minimum-interest requirement and the given total-mass normalization.
  • Allowed empty preference sets and singleton channel selections, since the discrete formulation does not exclude them; required at least one input channel.
  • Kept selected masses real within their stated intervals and allowed any maximizing pair, resolving the numerical domain and objective ties.
  • Defined L as total binary input length and explicitly identified support size as the number of positive-mass types.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is NP-hard, even when \(m=3\), \(h=1\), and every constructed instance has a feasible solution with strictly positive objective value. Its threshold decision version is NP-complete.

An exact algorithm runs in \(2^\tau\operatorname{poly}(m,\tau,L)\) time, including polynomial preprocessing of distances. Thus it is polynomial-time solvable for fixed support size \(\tau\), but fixing the number of channels does not remove the hardness.

1. Selected masses can always be saturated

For a feasible solution \((K,x)\), define its positive support by
\[ S=\{t\in T:x_t>0\}. \]
Replace its masses by \(x'_t=\mu_t\) for \(t\in S\), and \(x'_t=0\) otherwise.

This preserves feasibility:

  • Each channel’s selected mass can only increase.
  • Every selected type still prefers at least one channel in \(K\).
  • The positive support is unchanged, so all distance constraints remain satisfied.

Consequently, a feasible solution always has a representative whose coordinates belong to \(\{0,\mu_t\}\). Its objective is unchanged because the objective depends only on \(K\).

Call \(S\subseteq T\) compatible if \(d_H(t,u)\le h\) for every \(t,u\in S\). Define
\[ A(S)=\left\{q\in C:\sum_{\substack{t\in S\\q\in P_t}}\mu_t\ge\rho\right\}. \]

For every compatible \(S\), every nonempty \(K\subseteq A(S)\) is feasible. Indeed, select full mass precisely from
\[ S_K=\{t\in S:P_t\cap K\ne\varnothing\}. \]
This subset remains compatible. For every \(q\in K\), all types in \(S\) preferring \(q\) belong to \(S_K\), so removing the other types does not reduce coverage of \(q\).

Conversely, the positive support of any feasible solution is compatible and satisfies \(K\subseteq A(S)\). Therefore the optimization problem is exactly
\[ \max_{\substack{S\subseteq T\\S\text{ compatible}\\A(S)\ne\varnothing}} \ \max_{\varnothing\ne K\subseteq A(S)} \frac{\sum_{\{q,r\}\in D(K)}W[q,r]}{|K|}. \]

2. Hardness with guaranteed feasibility and positive optimum

Reduce from CLIQUE: given a simple graph \(G=(V,E)\), with \(n=|V|\), and an integer \(1\le k\le n\), determine whether \(G\) has a clique of size at least \(k\). This restricted range retains NP-completeness.

Construct the following instance:

  • Channels: \(C=\{a,b,c\}\).
  • Diversity edges: \(W[a,b]=1/2\) and \(W[b,c]=1\); no other edges.
  • Types: one type \(t_v\) for each \(v\in V\), and one additional type \(z\).
  • Preferences: \(P_{t_v}=\{b,c\}\) and \(P_z=\{a,b\}\).
  • Masses and threshold:

\[ \mu_{t_v}=\frac1{n+k},\qquad \mu_z=\frac{k}{n+k},\qquad \rho=\frac{k}{n+k}. \]

  • Social graph: a copy of \(G\) on the types \(t_v\), together with isolated vertex \(z\).
  • Distance bound: \(h=1\).

All masses are positive and sum to \(1\). The construction has \(\tau=n+1\), uses rationals of polynomial binary length, and takes polynomial time.

Selecting \(K=\{a,b\}\) and mass \(\mu_z=\rho\) is always feasible. Its objective is
\[ \omega(\{a,b\})=\frac{1/2}{2}=\frac14. \]

We now classify every feasible solution.

If \(z\) has positive selected mass, no original type can have positive selected mass, because \(z\) is disconnected from all of them. Coverage then forces \(K\subseteq\{a,b\}\), so the objective is at most \(1/4\).

If \(z\) has zero selected mass, all selected types are original types. Coverage forces \(K\subseteq\{b,c\}\). Since \(h=1\), distinct selected types must correspond to adjacent vertices of \(G\); hence their support is a clique.

For \(K=\{b,c\}\), a support \(S\subseteq V\) can provide at most \(|S|/(n+k)\) mass to either channel. Thus feasibility implies
\[ \frac{|S|}{n+k}\ge\frac{k}{n+k}, \]
and therefore \(|S|\ge k\). Conversely, any clique of size at least \(k\), selected at full mass, makes \(\{b,c\}\) feasible. Its objective is \(1/2\). Singleton channel sets have objective zero.

It follows that
\[ \operatorname{OPT}= \begin{cases} 1/2,&\text{if }G\text{ has a clique of size at least }k,\\ 1/4,&\text{otherwise}. \end{cases} \]

Hence an exact optimizer decides CLIQUE on instances that are always feasible and always have positive optimum. This proves the claimed NP-hardness without relying on infeasibility or a zero optimum.

3. Decision complexity and approximation

For a binary rational target \(\lambda\), consider the decision question: does a feasible solution with \(\omega(K)\ge\lambda\) exist?

By the saturation result, a certificate consists only of \(K\) and a support \(S\); its masses are determined as \(\mu_t\) on \(S\) and zero elsewhere. Distances, preference conditions, rational coverage sums, and the objective comparison can all be checked in polynomial time. Thus this decision problem belongs to NP. Section 2 proves NP-hardness with \(\lambda=1/2\), so it is NP-complete.

Feasibility alone is already NP-complete for \(m=1\): use \(H=G\), \(h=1\), let every type prefer the sole channel, and set \(\mu_t=1/n\) and \(\rho=k/n\). Feasibility is equivalent to having a clique of size at least \(k\).

The mass formulation also inherits a direct finite-factor obstruction. To verify this independently, construct two channels \(a,b\) with \(W[a,b]=1\). Give every original type preference \(\{a,b\}\) and mass \(1/(n+2k)\). Add two isolated types, preferring only \(a\) and only \(b\), respectively, each of mass \(k/(n+2k)\). Set \(\rho=k/(n+2k)\) and \(h=1\).

Each singleton channel is feasible using its isolated type. The pair \(\{a,b\}\) is feasible exactly when the original graph has a clique of size at least \(k\): isolated types cannot join any other selected type, and neither alone covers both channels. Therefore the optimum is \(1/2\) in yes-instances and zero in no-instances.

Any polynomial-time multiplicative approximation with a finite factor, returning a feasible solution on these always-feasible instances, must return positive value in every yes-instance. Testing whether its output value is positive would decide CLIQUE. Thus such an approximation is impossible unless \(\mathrm P=\mathrm{NP}\).

4. Exact running time

Compute shortest-hop distances in the full graph \(H\), as stipulated. Running breadth-first search from every type takes
\[ O\!\left(\tau\bigl(\tau+|E(H)|\bigr)\right) \]
graph operations, at most \(O(\tau^3)\).

For distinct types, every finite shortest-path distance is at most \(\tau-1\). Consequently, the numerical magnitude of \(h\) causes no additional search cost: comparisons may use \(\min\{h,\tau-1\}\), while disconnected pairs remain incompatible.

Enumerate the \(2^\tau\) subsets \(S\), retaining the compatible ones. For each, calculate \(A(S)\) by exact rational arithmetic. It remains to solve the weighted densest-subgraph problem on \(A(S)\), which has a polynomial-time exact solution. Here is a justification.

For a nonempty eligible channel set \(A\), introduce variables \(z_q\ge0\) and \(y_{qr}\ge0\), with the linear program
\[ \max \sum_{\{q,r\}\in D(A)}W[q,r]y_{qr}, \qquad \sum_{q\in A}z_q=1, \qquad y_{qr}\le z_q,\quad y_{qr}\le z_r. \]

Every nonempty \(K\subseteq A\) gives a feasible point by setting \(z_q=1/|K|\) on \(K\), zero elsewhere, and \(y_{qr}=1/|K|\) for edges inside \(K\), zero elsewhere. Its LP objective is \(\omega(K)\).

For the reverse direction, take any feasible LP point. Let the distinct positive values of its \(z_q\) be
\[ 0=a_0<a_1<\cdots<a_s, \]
and define \(K_i=\{q:z_q\ge a_i\}\). Then
\[ \sum_{i=1}^s(a_i-a_{i-1})|K_i|=\sum_qz_q=1, \]
and
\[ \sum_{\{q,r\}\in D(A)}W[q,r]y_{qr} \le \sum_{i=1}^s(a_i-a_{i-1}) \sum_{\{q,r\}\in D(K_i)}W[q,r]. \]
The expression on the right is a weighted average of the densities \(\omega(K_i)\), with weights \((a_i-a_{i-1})|K_i|\) summing to \(1\). Hence some \(K_i\) has density at least the LP objective. At an optimal LP point, such a set is an optimal channel set.

This rational LP has \(O(m^2)\) variables and constraints and polynomial encoding length, so polynomial-time rational linear programming applies. The level sets also give an explicit optimal channel set.

The resulting exact algorithm therefore takes
\[ 2^\tau\operatorname{poly}(m,\tau,L) \]
bit operations, including distance preprocessing, and uses polynomial space when subsets are processed sequentially. It reports infeasibility if every compatible support has empty \(A(S)\); otherwise it returns an optimal channel set and full masses on the corresponding \(S_K\).

The reduction shows that a running time polynomial jointly in the input parameters is impossible unless \(\mathrm P=\mathrm{NP}\), already for constant \(m=3\) and \(h=1\).
