Statement 2 — class: algorithmic

The continuous mirror question, as graded

Given a finite-support distribution \(\nu\) over claim-award pairs \((v_i,x_i)\), with rational masses \(\mu_i>0\) summing to \(1\), positive claims, integral awards, and per-authority supply \(\sum_i\mu_i x_i=\kappa\), consider the strict-order regime \(v_1>\cdots>v_\tau\) and \(x_1>\cdots>x_\tau\). Classify whether every pair of positive-mass population groups \(A,B\), with every award in \(A\) greater than every award in \(B\), satisfies \(\frac{\int_A x\,d\nu}{\int_A v\,d\nu}>\frac{\int_B x\,d\nu}{\int_B v\,d\nu}\), satisfies the reverse inequality throughout, or satisfies neither uniformly.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\ge2\) types \((v_i,x_i)\) with positive masses \(\mu_i\), each mass a binary rational; \(\tau\) is the support size, not the number of possible types.
Claims \(v_i\) are positive binary rationals, awards \(x_i\) are nonnegative binary integers, and \(\sum_i\mu_i=1\). Assume \(v_1>\cdots>v_\tau\) and \(x_1>\cdots>x_\tau\), with supplied positive binary rational supply \(\kappa=\sum_i\mu_i x_i\).
A population group may take any fraction of each type: represent groups by real vectors \(a,b\) satisfying \(0\le a_i,b_i\), \(a_i+b_i\le\mu_i\), and \(\sum_i a_i,\sum_i b_i>0\). An admissible pair additionally satisfies \(x_i>x_j\) whenever \(a_i>0\) and \(b_j>0\); groups need not exhaust the society.
Define \(R(a)=\frac{\sum_i a_i x_i}{\sum_i a_i v_i}\). Classify the input as large-favoring if every admissible pair satisfies \(R(a)>R(b)\), small-favoring if every admissible pair satisfies \(R(a)<R(b)\), and neither otherwise; equality violates either strict condition.
Let \(L\) be the total binary input length. Measure running times in \(\tau,L,\kappa\); this model has no separate candidate parameter \(m\).

Is this continuous classification problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For finite lists of \(n\) beneficiaries under the same strict orders, total favoring in either direction can be classified using \(n-1\) adjacent award-to-claim ratio comparisons, giving a polynomial-time algorithm. Classification theorem

The continuous classification problem is solvable in polynomial time. It requires exactly \(\tau-1\) adjacent ratio comparisons, with a conservative bound of \(O(\tau L^2)\) bit operations, independent of the numerical value of \(\kappa\).

Define \(r_i=x_i/v_i\). Then:

  • The society is large-favoring if and only if \(r_1>r_2>\cdots>r_\tau\).
  • The society is small-favoring if and only if \(r_1<r_2<\cdots<r_\tau\).
  • Otherwise, it is neither.

This extends the finite-list criterion in Statement 2 of [Bolun (2021)](https://jes.utm.md/wp-content/uploads/sites/20/2021/04/JES-1-2021_47-60.pdf). The following proof establishes the extension directly for arbitrary real fractional groups.

Proof

1. Adjacent comparisons are necessary

Fix any \(i\) with \(1\le i<\tau\). Choose groups consisting entirely of types \(i\) and \(i+1\): set \(a_i=\mu_i\), \(b_{i+1}=\mu_{i+1}\), and every other coordinate to zero.

Both groups have positive mass because the input lists only types with positive masses. They satisfy every capacity constraint, and they are admissible because \(x_i>x_{i+1}\). Their ratios are

\(R(a)=\mu_i x_i/(\mu_i v_i)=r_i\), and \(R(b)=\mu_{i+1}x_{i+1}/(\mu_{i+1}v_{i+1})=r_{i+1}\).

Consequently, large-favoring requires \(r_i>r_{i+1}\) for every adjacent pair. Small-favoring requires \(r_i<r_{i+1}\) for every adjacent pair. In particular, an adjacent equality violates both strict classifications.

2. Adjacent comparisons are sufficient

Let \((a,b)\) be any admissible pair. Write \(V(a)=\sum_i a_i v_i\) and \(V(b)=\sum_j b_j v_j\). These quantities are strictly positive: every claim is positive, every coordinate is nonnegative, and both groups have positive total mass.

Expanding the difference of the ratios gives the exact identity

\(R(a)-R(b)=\dfrac{\sum_{i=1}^{\tau}\sum_{j=1}^{\tau}a_i b_j(x_i v_j-x_j v_i)}{V(a)V(b)}=\dfrac{\sum_{i=1}^{\tau}\sum_{j=1}^{\tau}a_i b_j v_i v_j(r_i-r_j)}{V(a)V(b)}.\)

Whenever \(a_i b_j>0\), admissibility implies \(x_i>x_j\). Since the awards are strictly decreasing in the supplied order, this implies \(i<j\).

Suppose first that every adjacent comparison satisfies \(r_i>r_{i+1}\). Transitivity gives \(r_i>r_j\) whenever \(i<j\). Thus every nonzero summand in the numerator is positive. At least one such summand exists because both groups have nonempty supports. The numerator and denominator are therefore positive, so \(R(a)>R(b)\).

If instead every adjacent comparison satisfies \(r_i<r_{i+1}\), transitivity gives \(r_i<r_j\) whenever \(i<j\). Every nonzero summand is then negative, and at least one exists. Hence \(R(a)<R(b)\).

This argument applies to all feasible real group vectors, without any rationality assumption on their coordinates.

3. All remaining inputs are neither

If the ratios fail to be strictly decreasing, some adjacent pair satisfies \(r_i\le r_{i+1}\); the groups constructed in step 1 violate large-favoring.

If the ratios fail to be strictly increasing, some adjacent pair satisfies \(r_j\ge r_{j+1}\); the corresponding groups violate small-favoring.

Therefore, when neither strict chain holds, neither classification holds. This completes the characterization.

Exact algorithm and bit complexity

Represent each positive rational claim as \(v_i=p_i/q_i\), with positive binary integers \(p_i,q_i\). Then \(r_i=x_i q_i/p_i\), and the sign of \(r_i-r_{i+1}\) is exactly the sign of the integer

\(D_i=x_i q_i p_{i+1}-x_{i+1}q_{i+1}p_i.\)

The algorithm computes these signs for \(1\le i<\tau\) and returns:

  • Large-favoring if all signs are positive.
  • Small-favoring if all signs are negative.
  • Neither otherwise.

No floating-point arithmetic or enumeration of groups is needed.

Each input integer has at most \(L\) bits. Each product in \(D_i\) has at most \(3L\) bits and can be computed using a constant number of schoolbook multiplications in \(O(L^2)\) bit operations. Subtraction and sign determination take \(O(L)\) further operations. Thus the total running time is \(O(\tau L^2)\), polynomial in the binary input length.

Positive masses guarantee the necessary witness groups exist; their magnitudes do not otherwise affect the classification. The supplied \(\kappa\) is not used by the algorithm. In particular, the bound has no dependence on its numerical magnitude and uses only the support size \(\tau\).
