The continuous mirror question, as graded

Given a unit-mass society with finite support \(T\) of \(\tau\) retailer types and rational masses \(\mu_\theta\), where each type specifies per-retailer excess supply \(e_\theta\), unmet demand \(d_\theta\), salvage value \(s_\theta\), selling price \(p_\theta\), shortage penalty \(\rho_\theta\), equity weight \(w_\theta\), and pairwise logistics costs \(\kappa_{\theta\phi}\), compute an optimal type-to-type flow \(x_{\theta\phi}\) and a transshipment price \(r_{\theta\phi}\) for each used pair. Require \(\sum_\phi x_{\theta\phi}\leq\mu_\theta e_\theta\), \(\sum_\theta x_{\theta\phi}\leq\mu_\phi d_\phi\), \(x_{\theta\phi}\geq0\), and \(s_\theta\leq r_{\theta\phi}\leq p_\phi+\rho_\phi-\kappa_{\theta\phi}\) on eligible pairs; maximize \(\sum_{\theta,\phi}x_{\theta\phi}[w_\theta(r_{\theta\phi}-s_\theta)+w_\phi(p_\phi+\rho_\phi-r_{\theta\phi}-\kappa_{\theta\phi})]\).

Packaged proof task (what the prover saw — nothing else)

A unit-mass society for a single product is given by its support: a list \(T\) of \(\tau\) retailer types with positive binary-rational masses \(\mu_\theta\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies nonnegative rational excess supply \(e_\theta\), unmet demand \(d_\theta\), salvage value \(s_\theta\), selling price \(p_\theta\), shortage penalty \(\rho_\theta\), and fixed equity weight \(w_\theta\), with \(e_\theta d_\theta=0\). Directed per-unit logistics costs \(\kappa_{\theta\phi}\) are nonnegative rationals paid by the receiver.
Let \(E=\{(\theta,\phi):\theta\ne\phi,\ e_\theta>0,\ d_\phi>0,\ s_\theta\le p_\phi+\rho_\phi-\kappa_{\theta\phi}\}\). Flows outside \(E\) are zero; no intermediate forwarding is allowed.
Choose divisible aggregate flows \(x_{\theta\phi}\ge0\) satisfying \(\sum_\phi x_{\theta\phi}\le\mu_\theta e_\theta\) and \(\sum_\theta x_{\theta\phi}\le\mu_\phi d_\phi\), and one per-unit price \(r_{\theta\phi}\in[s_\theta,p_\phi+\rho_\phi-\kappa_{\theta\phi}]\) for each used pair.
Compute a flow and prices maximizing \(\sum_{(\theta,\phi)\in E}x_{\theta\phi}[w_\theta(r_{\theta\phi}-s_\theta)+w_\phi(p_\phi+\rho_\phi-r_{\theta\phi}-\kappa_{\theta\phi})]\). Any optimum is acceptable.
Let \(L\) be the total binary input length; the number of products is fixed at \(m=1\).

Is this continuous allocation-and-pricing problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite list of retailers, a strongly polynomial algorithm for weighted-value transshipment allocation and pricing is stated in the [WVT algorithmic result](https://www.cse.iitb.ac.in/~swaprava/papers/inventory_control.pdf).

Result

The problem is solvable exactly in polynomial time in \(\tau,L\), hence in \(m,\tau,L\) for the stipulated \(m=1\). The support masses become rational capacities in a linear program of polynomial size.

1. Optimize each price independently

For each \((\theta,\phi)\in E\), define the receiver’s maximum acceptable price and the available surplus by

\(u_{\theta\phi}=p_\phi+\rho_\phi-\kappa_{\theta\phi},\qquad \Delta_{\theta\phi}=u_{\theta\phi}-s_\theta\ge 0.\)

For an admissible price \(r\in[s_\theta,u_{\theta\phi}]\), the weighted benefit per unit is

\(g_{\theta\phi}(r)=w_\theta(r-s_\theta)+w_\phi(u_{\theta\phi}-r)=w_\phi\Delta_{\theta\phi}+(w_\theta-w_\phi)(r-s_\theta).\)

This is affine in \(r\). Therefore:

  • If \(w_\theta\ge w_\phi\), choose \(r^*_{\theta\phi}=u_{\theta\phi}\).
  • If \(w_\theta<w_\phi\), choose \(r^*_{\theta\phi}=s_\theta\).

When the weights are equal, every admissible price is optimal. In every case, the maximum weighted benefit per unit equals

\(c_{\theta\phi}=\max\{w_\theta,w_\phi\}\Delta_{\theta\phi}.\)

These prices depend only on the input. Their simultaneous use is feasible because the problem imposes no constraints coupling prices on different pairs.

For any feasible allocation and prices, nonnegativity of the flows gives

\(\displaystyle \sum_{(\theta,\phi)\in E}x_{\theta\phi}g_{\theta\phi}(r_{\theta\phi})\le \sum_{(\theta,\phi)\in E}c_{\theta\phi}x_{\theta\phi}.\)

Conversely, every feasible allocation attains equality when equipped with the prices \(r^*_{\theta\phi}\). Thus eliminating prices preserves the optimum exactly.

2. Solve the resulting linear program

Define the aggregate supply and demand capacities by

\(a_\theta=\mu_\theta e_\theta,\qquad b_\theta=\mu_\theta d_\theta.\)

The remaining optimization is the following rational linear program:

\(\displaystyle \max_x\ \sum_{(\theta,\phi)\in E}c_{\theta\phi}x_{\theta\phi},\)

subject to

\(\displaystyle \sum_{\phi:(\theta,\phi)\in E}x_{\theta\phi}\le a_\theta\quad\text{for every }\theta\in T,\)

\(\displaystyle \sum_{\theta:(\theta,\phi)\in E}x_{\theta\phi}\le b_\phi\quad\text{for every }\phi\in T,\)

\(x_{\theta\phi}\ge 0\quad\text{for every }(\theta,\phi)\in E.\)

These are precisely the original flow constraints, with flows outside \(E\) fixed to zero.

The zero allocation is feasible. Moreover, each variable satisfies \(0\le x_{\theta\phi}\le a_\theta\). Consequently, the feasible set is closed and bounded, and the linear objective attains a finite maximum. If \(E\) is empty, the zero allocation already solves the problem.

Let \(x^*\) be an optimal solution of this linear program. For every used pair, output the price \(r^*_{\theta\phi}\) from Section 1. The resulting allocation and prices are feasible and achieve the linear program’s optimum. The inequality proved in Section 1 shows that no original feasible solution can do better. This proves correctness.

3. Verify polynomial input and output size

There are at most \(\tau(\tau-1)\) variables and at most \(2\tau+|E|\) inequalities, counting nonnegativity.

The set \(E\) can be constructed by testing each ordered pair using exact rational comparisons. Each capacity \(a_\theta,b_\theta\) and coefficient \(c_{\theta\phi}\) requires only a constant number of additions, subtractions, comparisons, and multiplications of input rationals.

To check encoding size explicitly, multiplying rationals multiplies their numerators and denominators, so their binary lengths add. Adding rationals can use the product of their denominators, again giving a length bounded by the sum of the operand lengths plus a constant. Because each derived coefficient uses a constant number of input values, its binary length is \(O(L)\). The constraint matrix has entries only in \(\{-1,0,1\}\). Thus the entire linear program has encoding length polynomial in \(\tau,L\).

We apply the standard rational linear programming theorem: a linear program with binary-encoded rational data can be solved in time polynomial in its encoding length, returning an exact rational optimum when it is feasible and has a finite optimum. Polynomial-time methods and recovery of an optimal vertex are discussed in [MIT’s notes on algorithms for linear programming](https://courses.csail.mit.edu/6.854/18/Notes/n14-LP_algorithms.html).

All hypotheses have been verified: the data are rational, the encoding is polynomial in size, and the program is feasible with a finite optimum. The returned allocation therefore has polynomial output length. Each recovered price is either an input salvage value or the rational expression \(p_\phi+\rho_\phi-\kappa_{\theta\phi}\), so prices also have polynomial output length.

4. Why support encoding causes no hardness

The masses enter only through \(a_\theta=\mu_\theta e_\theta\) and \(b_\theta=\mu_\theta d_\theta\). The algorithm operates directly on the \(\tau\) listed types; it never expands a mass into individual retailers.

The linked [WVT paper, Theorem 3 and its appendix proof](https://www.cse.iitb.ac.in/~swaprava/papers/inventory_control.pdf), likewise eliminates prices before reducing allocation to bipartite weighted matching. The argument above independently handles rational mass capacities and proves the requested polynomial-time conclusion.

Accordingly, NP-hardness under polynomial-time reductions would imply \(\mathrm{P}=\mathrm{NP}\).
