Results

For the recursion stated in the question:

  • The decision problem is \(\mathrm{NP}\)-hard, even when every type has constant conditional preference tables and maximum indegree one.
  • Explicitly computing \(Q_\mu\) can require outputting \(2^m\) outcomes. Exact generation and minimization admit running time \(2^m\operatorname{poly}(m,\tau,L)\).
  • The stated Pareto guarantee fails for this exact recursion. A counterexample has \(m=4\), \(\tau=4\), and equal masses.

Below are proofs, including an output-sensitive generation bound. The unrestricted decision problem is also in \(\mathrm{PSPACE}\); I do not claim that it is in \(\mathrm{NP}\).

1. Preliminary properties

I use improving-flip dominance: an outcome strictly dominates another when a nonempty improving-flip path connects the latter to the former. This is the standard CP-net semantics. [Boutilier et al., *CP-nets*](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume21/boutilier04a.pdf).

The recursion is well-defined

At a state with unassigned variables and nonempty \(S\), every \(E_t\) is nonempty. Indeed, a source of the dependency graph induced by the unassigned variables has all its parents in \(Z\). Thus a hitting set \(Y\) exists and is nonempty.

Every recursive branch has nonempty \(S_y\):

  • If \(Y=C\), every type satisfies \(Y\cap E_t\subseteq C\), so every type remains.
  • Otherwise choose \(X\in Y\setminus C\). Because \(X\) is conflicting and binary, some eliciting type prefers the value opposite to \(y[X]\). That type remains in \(S_y\).

Every recursive step assigns at least one new variable. Therefore the recursion terminates, and \(Q_\mu\) is nonempty.

Different branches at a node assign different values to \(Y\), so their completed outcomes are disjoint. Writing \(q=|Q_\mu|\), the recursion tree, with terminal assignments represented as separate leaves, consequently has at most \((m+1)q\) nodes.

Ranks are finite and have at most \(m\) bits

Fix a type \(t\) and a topological ordering \(W_1,\ldots,W_m\). Define \(b_i(o)=1\) when \(o[W_i]\) is locally preferred under its parent assignment, and \(b_i(o)=0\) otherwise.

An improving flip of \(W_i\) leaves \(b_1,\ldots,b_{i-1}\) unchanged and changes \(b_i\) from zero to one. Thus the string \(b_1(o)\cdots b_m(o)\) strictly increases lexicographically along every improving flip.

The improving graph is therefore acyclic. Its unique sink is the unique outcome with every variable locally preferred, obtained in topological order. Every improving path extends to that sink, and hence

\(\displaystyle 0\leq \operatorname{rank}_t(o)\leq 2^m-1.\)

2. A direct \(\mathrm{NP}\)-hardness reduction

The reduction uses constant local preferences. In such a type, let \(s\) be the vector of preferred values. Every improving flip corrects exactly one coordinate differing from \(s\), and that coordinate can never flip again. Consequently,

\(\displaystyle \operatorname{rank}_t(o)=d_H(o,s),\)

where \(d_H\) denotes Hamming distance.

Dependency arcs can still affect elicitation even when their conditional tables are constant. Such redundant arcs are permitted by the stated hypotheses.

2.1 From satisfiability to a balanced vertex-cover instance

Take a formula with \(c\geq1\) clauses, each containing three literal occurrences.

Construct a graph \(H\) with one vertex for each occurrence. Join:

  • every pair of occurrences in the same clause;
  • every pair representing complementary literals.

Each clause forms a triangle, so an independent set contains at most one vertex per clause.

The formula is satisfiable if and only if \(H\) has an independent set of size \(c\):

  • From a satisfying assignment, select one true occurrence per clause. Selected occurrences cannot be complementary.
  • An independent set of size \(c\) selects exactly one occurrence per clause and contains no complementary pair. Assigning its selected literals true extends to a satisfying assignment.

Now add \(c\) isolated vertices, producing a graph \(G\) with \(m=4c\) vertices. Set \(k=2c=m/2\). Since \(\alpha(G)=\alpha(H)+c\), the formula is satisfiable if and only if \(G\) has a vertex cover of size at most \(k\).

A cover of size at most \(k\) can be extended to one of size exactly \(k\).

2.2 Hamming constraints encode the cover

Consider the following binary strings of length \(m\):

  • \(0^m\);
  • \(1^m\);
  • for every edge \(e=\{i,j\}\), its incidence string \(s_e\), with ones precisely at \(i,j\).

Suppose \(x\) has Hamming distance at most \(k=m/2\) from both constant strings. Its weight \(w(x)\) must satisfy

\(\displaystyle w(x)\leq k,\qquad m-w(x)\leq k,\)

so \(w(x)=k\).

For an edge \(e=\{i,j\}\), let \(h_e=x_i+x_j\). Then

\(\displaystyle d_H(x,s_e)=w(x)+2-2h_e=k+2-2h_e.\)

Thus \(d_H(x,s_e)\leq k\) holds exactly when \(h_e\geq1\), meaning that the vertices selected by \(x\) cover \(e\).

Therefore a string within distance \(k\) of every listed string exists exactly when \(G\) has a vertex cover of size at most \(k\).

2.3 Realizing the constraints while forcing the full shortlist

For every coordinate \(i\) and bit \(b\), introduce a type \(N_{i,b}\) with:

  • dependency graph consisting of the arcs \(X_i\to X_j\) for all \(j\neq i\);
  • preferred value \(b\) for every variable, in every table row.

For every edge \(e\), introduce another type with the same star graph rooted at \(X_1\), and constant preferred-value vector \(s_e\).

These types satisfy all input requirements:

  • They are complete, binary, and acyclic.
  • Every conditional table has at most two rows.
  • The \(N_{i,b}\) are distinct as explicitly specified CP-nets.
  • Edge types are mutually distinct and differ from the constant-vector types.

There are \(\tau=2m+|E(G)|\) types, and their explicit descriptions have polynomial total length.

Positive dyadic masses can be supplied as follows. Let \(D=2^{\lceil\log_2\tau\rceil}\). Give the first \(\tau-1\) types mass \(1/D\), and the final type mass \((D-\tau+1)/D\). These masses are positive, sum to one, and have polynomial encoding length.

At the initial recursion state, \(E_{N_{i,b}}=\{X_i\}\). Hence every hitting set must contain every variable, so \(Y=V\).

For each \(X_i\), the types \(N_{i,0}\) and \(N_{i,1}\) elicit opposite values. Therefore every variable is conflicting. The terminal rule gives

\(\displaystyle Q_\mu=\{0,1\}^m.\)

Since all tables are constant,

\(\displaystyle R_\mu(x)=\max\left\{d_H(x,0^m),\,d_H(x,1^m),\,\max_{e\in E(G)}d_H(x,s_e)\right\}.\)

The preceding equivalences prove

\(\displaystyle \exists x\in Q_\mu:\ R_\mu(x)\leq k \quad\Longleftrightarrow\quad \text{the original formula is satisfiable}.\)

This is a polynomial-time reduction, proving \(\mathrm{NP}\)-hardness. On this restricted family, verification consists only of Hamming-distance calculations, so the restricted decision problem is \(\mathrm{NP}\)-complete.

An algorithm returning a minimizing member in time polynomial in the input length would also solve these instances by checking its Hamming distances. Thus computing a minimizing member is \(\mathrm{NP}\)-hard.

3. Exact computation and running times

Let \(q=|Q_\mu|\). Listing outcomes as bit strings has output size \(mq\).

3.1 Selecting the specified hitting set

At a node with \(r\) unassigned variables, exhaustive enumeration of subsets selects the prescribed \(Y\) in time

\(\displaystyle 2^r\operatorname{poly}(m,\tau,L).\)

There is also an algorithm exponential in the current support size \(s=|S|\), rather than in \(r\).

For each eligible variable, record the subset of types it covers. Process variables successively, using dynamic programming indexed by the covered subset of \(S\). Minimize the additive objective

\(\displaystyle \left(|Y|,\ |Y\setminus C|,\ -\sum_{X_i\in Y}2^{m-i}\right)\)

lexicographically. At fixed cardinality, the final component implements the required lexicographic tie-breaking: at the smallest differing index, the set containing that index is preferred.

This takes \(2^s\operatorname{poly}(m,\tau,L)\) time. Moreover, a minimum hitting set has size at most \(s\), because choosing one member of each \(E_t\) produces a hitting set of that size. Thus generating its branches also fits this bound.

3.2 Generating \(Q_\mu\)

The recursion-tree bound immediately gives

\(\displaystyle T_Q=O\!\left(mq\,2^\tau\operatorname{poly}(m,\tau,L)\right).\)

A second bound follows by using subset enumeration at each node. At any fixed recursion depth, the partial assignments at distinct nodes define disjoint completion sets. Therefore, if node \(v\) has \(r_v\) unassigned variables,

\(\displaystyle \sum_{v\text{ at that depth}}2^{r_v}\leq2^m.\)

There are at most \(m+1\) depths, giving

\(\displaystyle T_Q=O\!\left(m2^m\operatorname{poly}(m,\tau,L)\right).\)

Choosing the faster local hitting-set algorithm yields the combined bound

\(\displaystyle T_Q= O\!\left( \min\{m2^m,\ mq2^\tau\}\operatorname{poly}(m,\tau,L) \right).\)

These are algorithmic upper bounds, rather than claims of optimal output-sensitive complexity.

The output lower bound is unavoidable. Using only the types \(N_{i,0},N_{i,1}\) from the reduction gives \(\tau=2m\), polynomial input length, and \(q=2^m\). Explicit generation then requires at least \(\Omega(m2^m)\) bit-output operations.

3.3 Computing a minimizing member

For each type, enumerate its improving graph on all \(2^m\) outcomes. The code \(b_1(o)\cdots b_m(o)\) from Section 1 supplies a topological ordering.

Process outcomes in reverse order and apply

\(\displaystyle \operatorname{rank}_t(o)= \begin{cases} 0,&o=o_t^\star,\\ 1+\max_{o\to_t o'}\operatorname{rank}_t(o'),&o\neq o_t^\star. \end{cases}\)

Every nonoptimal outcome has an improving successor, and every successor has already been processed. This computes all ranks in time

\(\displaystyle \tau2^m\operatorname{poly}(m,L).\)

Maintain the maximum rank over types for each outcome, then enumerate \(Q_\mu\) and retain a member with minimum maximum rank. The total time is

\(\displaystyle T_{\mathrm{both}} =O\!\left( T_Q+\tau2^m\operatorname{poly}(m,L)+mq \right) =2^m\operatorname{poly}(m,\tau,L).\)

Processing types successively requires exponential rank storage of \(O(m2^m)\) bits, plus polynomial working storage. Explicitly retaining the shortlist adds \(O(mq)\) bits.

3.4 A polynomial-space decision upper bound

Membership of a proposed outcome in \(Q_\mu\) can be checked in polynomial space. At each stage, enumerate hitting sets to identify \(Y\); reject if the proposed outcome violates a consistent assignment; otherwise follow its uniquely determined branch. There are at most \(m\) stages.

Rank thresholds also admit polynomial-space checking. For \(k<2^m-1\),

\(\displaystyle \operatorname{rank}_t(o)>k \quad\Longleftrightarrow\quad \text{an improving path of length }k+1\text{ starts at }o. \)

The reverse implication uses the fact that every improving path extends to the optimum.

Existence of an improving walk of a specified length \(\ell\) between two outcomes can be evaluated recursively by enumerating a midpoint and splitting \(\ell\) into \(\lfloor\ell/2\rfloor\) and \(\lceil\ell/2\rceil\). The recursion depth is \(O(m)\), and each level stores only polynomially many bits. Acyclicity ensures that these walks are paths.

Enumerating possible candidates and checking membership and rank thresholds therefore uses polynomial space. Thus the unrestricted decision problem belongs to \(\mathrm{PSPACE}\).

4. Counterexample to Pareto-optimality

Let \(A=X_1\), \(B=X_2\), \(C=X_3\), and \(D=X_4\). Give four types \(N_1,N_2,N_3,N_4\) mass \(1/4\) each.

The following table specifies every conditional preference table. Each cell contains the ordered parent tuple followed by the vector of preferred bits in lexicographic parent-assignment order. A preferred bit \(b\) means the strict order \(b\succ1-b\).

| Variable | \(N_1\) | \(N_2\) | \(N_3\) | \(N_4\) |
|---|---|---|---|---|
| \(A\) | \((D);(0,1)\) | \(\varnothing;(1)\) | \(\varnothing;(0)\) | \(\varnothing;(0)\) |
| \(B\) | \(\varnothing;(0)\) | \((A);(1,0)\) | \(\varnothing;(0)\) | \((A);(1,0)\) |
| \(C\) | \((A,B);(1,0,0,0)\) | \((A);(0,1)\) | \(\varnothing;(1)\) | \(\varnothing;(1)\) |
| \(D\) | \((B);(1,0)\) | \(\varnothing;(1)\) | \(\varnothing;(1)\) | \((A,C);(1,1,0,1)\) |

Valid topological orders are respectively \((B,D,A,C)\), \((A,D,B,C)\), \((A,B,C,D)\), and \((A,C,B,D)\). Hence all four types satisfy the hypotheses.

4.1 The recursion includes \(1000\)

Outcomes below are written in coordinate order \((A,B,C,D)\).

Initially,

\(\displaystyle E_1=\{B\},\qquad E_2=\{A,D\},\qquad E_3=\{A,B,C,D\},\qquad E_4=\{A,C\}. \)

A hitting set must contain \(B\). Its only possible second variable covering both \(E_2\) and \(E_4\) is \(A\). Thus \(Y=\{A,B\}\) is the unique minimum hitting set.

Here \(B\) is consistent with preferred value zero, while \(A\) is conflicting. Follow the branch \(A=1,B=0\). The retained types are exactly \(N_1,N_3,N_4\):

  • \(N_1\) elicits only the consistent variable \(B\);
  • \(N_2\) agrees with the selected conflicting value of \(A\), so it is removed;
  • \(N_3,N_4\) prefer \(A=0\), so they remain.

At the next state,

\(\displaystyle E_1=\{C,D\},\qquad E_3=\{C,D\},\qquad E_4=\{C\}.\)

Therefore \(Y=\{C\}\). Its preferred values are zero in \(N_1\) and one in \(N_3,N_4\). Follow \(C=0\), which removes \(N_1\) and retains \(N_3,N_4\).

Only \(D\) remains. Type \(N_3\) prefers \(D=1\), whereas \(N_4\), under \(A=1,C=0\), prefers \(D=0\). The terminal rule includes both values. In particular,

\(\displaystyle o=1000\in Q_\mu.\)

4.2 The outcome \(1011\) strictly dominates it in every type

For \(N_1\), the following path is improving:

\(\displaystyle 1000\to0000\to0010\to0011\to1011.\)

The four flips are justified as follows:

  • With \(D=0\), \(A=0\) is preferred.
  • With \(A=B=0\), \(C=1\) is preferred.
  • With \(B=0\), \(D=1\) is preferred.
  • With \(D=1\), \(A=1\) is preferred.

For each of \(N_2,N_3,N_4\), there is the improving path

\(\displaystyle 1000\to1010\to1011.\)

Indeed, all three prefer \(C=1\) at the first outcome. Types \(N_2,N_3\) unconditionally prefer \(D=1\); type \(N_4\) prefers \(D=1\) once \(A=C=1\).

Thus \(1011\) strictly dominates \(1000\) in every support type. Consequently, \(1000\) fails the stated Pareto-optimality condition.

This counterexample concerns the exact displayed recursion. The cited finite-society guarantee cannot be applied to that recursion without reconciling the procedural rules.
