Theorem 7.1 — class: other

The continuous mirror question, as graded

Given a candidate set \(A\), a finite support \(\mathcal{T}\) of voter types, and rational masses \(\mu_t>0\) summing to \(1\), where each type \(t\) specifies a subset \(S_t\subseteq A\) and a strict order \(\pi_t\) on \(S_t\), find a total ranking \(\sigma\) of \(A\) minimizing \(\sum_{t\in\mathcal{T}}\mu_t d_t(\sigma)\), where \(d_t(\sigma)\) counts the pairs in \(S_t\) whose order under \(\sigma\) disagrees with \(\pi_t\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a candidate set with \(m=|A|\geq 1\). A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational \(\mu_t>0\), with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies \(S_t\subseteq A\) and a strict total order \(\pi_t\) on \(S_t\). For a strict total ranking \(\sigma\) of \(A\), let \(d_t(\sigma)\) count unordered pairs in \(S_t\) ordered oppositely by \(\sigma\) and \(\pi_t\); unobserved pairs contribute nothing.
Define \(F(\sigma)=\sum_t\mu_t d_t(\sigma)\). Any minimizing ranking is acceptable. The decision input also contains a binary rational threshold \(B\geq0\); let \(L\) be the total input bit length. State running times in \(m,\tau,L\).

Is deciding whether some strict total ranking \(\sigma\) satisfies \(F(\sigma)\leq B\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For discrete binary comparisons, Kemeny optimization has equivalent convex-hull linear-optimization and minimum weighted feedback-arc-set formulations, with appropriate objective constants ([Jiang et al.](https://web.stanford.edu/~yyye/hodgeRank2011.pdf)).
[Dwork et al.](https://archives.iw3c2.org/www10/cdrom/papers/577/) already define normalized average Kendall disagreement for partial rankings and prove NP-hardness for four full rankings. This covers the uniform-mass case of the stated objective, so the proposed complexity target is already settled.

Modeling choices made when packaging the task

  • Added a nonnegative binary rational threshold to state the decision version of exact minimization.
  • Defined L as the total encoded input length, including the threshold.
  • Required a nonempty candidate set and allowed any optimum when several rankings attain the minimum.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when \(\tau=4\), every type ranks all candidates, and every mass equals \(\frac14\). Consequently, a polynomial-time algorithm in \(m,\tau,L\) exists only if \(\mathrm{P}=\mathrm{NP}\).

For \(m=1\), the objective is always zero. The hardness concerns instances with unbounded \(m\).

Membership in \(\mathrm{NP}\) and verification time

A certificate is a permutation \(\sigma\) of the explicitly given candidate set \(A\), encoded using \(O(m\log(m+1))\) bits. Check that every candidate occurs exactly once and construct its position in \(\sigma\).

For each type, write its input order as \(\pi_t=(a_{t,1},\ldots,a_{t,s_t})\). Then

\(d_t(\sigma)=\bigl|\{(i,j):1\leq i<j\leq s_t,\ \operatorname{pos}_{\sigma}(a_{t,i})>\operatorname{pos}_{\sigma}(a_{t,j})\}\bigr|\).

Thus all disagreement counts can be computed with at most \(O(\tau m^2)\) pair comparisons.

The threshold comparison can be performed exactly. Write \(\mu_t=p_t/q_t\) and \(B=b/r\), with positive integer denominators, and set

\(Q=r\prod_{t=1}^{\tau}q_t,\qquad N=\sum_{t=1}^{\tau}p_t d_t(\sigma)\frac{Q}{q_t}\).

Then \(F(\sigma)\leq B\) holds exactly when

\(N\leq b\frac{Q}{r}\).

The integer \(Q\) has \(O(L)\) bits. Since the masses sum to one,

\(0\leq N=QF(\sigma)\leq Q\binom{m}{2}\).

Therefore all integers needed for this computation have \(O(L+\log(m+1))\) bits. With ordinary quadratic-time integer arithmetic, a conservative verification bound is

\(O\!\left((L+m+\tau m^2)(L+\log(m+1))^2\right)\)

bit operations. This proves membership in \(\mathrm{NP}\).

Hardness from four full rankings

Use the following established theorem: given four strict total rankings \(\rho_1,\ldots,\rho_4\) of a common candidate set and a nonnegative integer \(K\), deciding whether a ranking \(\sigma\) satisfies

\(\sum_{i=1}^{4}d(\sigma,\rho_i)\leq K\)

is \(\mathrm{NP}\)-complete, where \(d\) counts disagreeing unordered pairs. This is the decision hardness stated in [Dwork et al., Appendix B, Theorem 11](https://archives.iw3c2.org/www10/cdrom/papers/577/#:~:text=Theorem%2011). Their distance normalization in Section 2.1.1 merely multiplies the full-ranking objective by a positive constant.

Keep the same candidates. For each distinct ranking \(\rho\) among the four input rankings, create one type with \(S_\rho=A\), order \(\rho\), and mass

\(\mu_\rho=\frac{|\{i:\rho_i=\rho\}|}{4}\).

These masses are positive binary rationals and sum to one. Importantly, identical rankings have been merged, so the resulting input is a support representation with \(\tau\leq4\).

Set \(B=K/4\). For every ranking \(\sigma\),

\(F(\sigma)=\frac14\sum_{i=1}^{4}d(\sigma,\rho_i)\).

Hence \(F(\sigma)\leq B\) if and only if the source inequality holds. Constructing the support and threshold takes polynomial time and adds only constant overhead to the threshold’s bit length. This is a polynomial many-one reduction, proving hardness.

Hardness with exactly four equal-mass support types

The following padding removes the possible repetitions in the preceding reduction.

Add three new candidates \(x,y,z\). Extend each source ranking by putting the original candidates first, followed respectively by the four orders

\((x,y,z),\quad(z,y,x),\quad(x,z,y),\quad(y,z,x)\).

Call the extended rankings \(\widehat{\rho}_1,\ldots,\widehat{\rho}_4\). They are distinct, so assigning mass \(\frac14\) to each gives exactly four support types.

Each pair of new candidates is ordered in either direction by exactly two of these rankings. Therefore, under every output ranking, that pair contributes \(\frac12\) to the weighted objective. The three pairs together contribute \(\frac32\).

For any ranking \(\widehat{\sigma}\) of the extended candidate set, let \(\sigma\) be its restriction to the original candidates. Splitting disagreement pairs into original pairs, new pairs, and pairs with one candidate of each kind gives

\(\widehat F(\widehat{\sigma})=\frac14\sum_{i=1}^{4}d(\sigma,\rho_i)+\frac32+C(\widehat{\sigma})\),

where \(C(\widehat{\sigma})\geq0\) is the contribution from pairs of the third kind. All input rankings put every original candidate before every new candidate, so \(C(\widehat{\sigma})=0\) whenever the output does likewise.

Consequently,

\(\min_{\widehat{\sigma}}\widehat F(\widehat{\sigma})=\frac14\min_{\sigma}\sum_{i=1}^{4}d(\sigma,\rho_i)+\frac32\).

Choosing \(\widehat B=(K+6)/4\) preserves the source decision answer. The construction adds only three candidates and uses constant-length masses. This proves the claimed hardness for exactly four distinct, equally weighted full-ranking types.

Running-time consequence

The hardness already holds for constant \(\tau\), so bounding the support size does not yield a polynomial-time algorithm in \(m,L\), unless \(\mathrm{P}=\mathrm{NP}\).

A direct exact algorithm enumerates all \(m!\) rankings and uses the verifier above, giving the unconditional upper bound

\(O\!\left(m!(L+m+\tau m^2)(L+\log(m+1))^2\right)\)

bit operations. Taking the smallest computed objective also returns an acceptable minimizing ranking.
