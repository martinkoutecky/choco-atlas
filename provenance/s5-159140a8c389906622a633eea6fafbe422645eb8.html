The continuous mirror question, as graded

Given finite type sets \(T_A,T_B,T_D\), rational type masses \(\mu_a,\nu_b,\delta_d\) summing to \(1\) on each side, and strict rankings of pairs of opposite-side types, choose masses \(x_{abd}\ge 0\) with marginals \(\mu,\nu,\delta\). For type \(a\), let its assigned pair have distribution \(q_a(b,d)=x_{abd}/\mu_a\), and define \(q_b(a,d)=x_{abd}/\nu_b\) and \(q_d(a,b)=x_{abd}/\delta_d\). Independently sample one agent from each side and draw each agent’s assigned pair from its type’s distribution; let \(I(x)\) be the probability all three prefer the sampled triple’s partners to their assigned pairs. Maximize \(1-I(x)\); for a fixed \(c<1\), ask whether the optimum is \(1\) or at most \(c\).

Result

The promise problem is polynomial-time solvable: every valid instance satisfies \(\mathrm{OPT}=1\). This holds for arbitrary positive rational masses and arbitrary complete strict pair rankings.

The key is that, although the objectives differ away from zero, the cited fractional hypergraph stability condition coincides with zero independent-sampling instability on a fully assigned society.

1. Characterizing zero instability

Let \(V=T_A\cup T_B\cup T_D\) and \(E=T_A\times T_B\times T_D\). Write \(w_a=\mu_a\), \(w_b=\nu_b\), and \(w_d=\delta_d\). For a vertex \(v\), let \(E(v)\) denote its incident triples. Its ranking of opposite-side pairs induces a strict ranking \(\succ_v\) of \(E(v)\).

For a feasible assignment \(x\), a triple \(e\), and an endpoint \(v\in e\), define

\(\displaystyle W_v(e)=\sum_{\substack{f\in E(v)\\ e\succ_v f}}x_f.\)

Thus \(W_v(e)/w_v\) is the probability that \(v\) strictly prefers its pair in \(e\) to its independently drawn assigned pair.

Conditional on sampling \(e=(a,b,d)\), the three improvement events are independent. Consequently,

\(\displaystyle I(x)=\sum_{e=(a,b,d)\in E}\mu_a\nu_b\delta_d\,\frac{W_a(e)}{\mu_a}\frac{W_b(e)}{\nu_b}\frac{W_d(e)}{\delta_d}=\sum_{e=(a,b,d)\in E}W_a(e)W_b(e)W_d(e).\)

All summands are nonnegative. Therefore,

\(\displaystyle I(x)=0\quad\Longleftrightarrow\quad\text{every }e\in E\text{ has an endpoint }v\in e\text{ with }W_v(e)=0.\)

Because the rankings are strict and the total assigned mass at \(v\) is \(w_v\), this endpoint condition is equivalently

\(\displaystyle x_e+\sum_{\substack{f\in E(v)\\f\succ_v e}}x_f=w_v.\)

Equality with the proposed pair is included here because it is never a strict improvement.

2. The fractional stability existence theorem

We use the following established theorem.

Fractional stability theorem. For any finite hypergraph with a strict total ranking of the incident edges at every vertex, there exists a vector \(y\) such that:

  • \(y_g\geq0\) for every edge \(g\);
  • \(\sum_{g\ni u}y_g\leq1\) for every vertex \(u\);
  • for every edge \(g\), some endpoint \(u\in g\) satisfies

\(\displaystyle y_g+\sum_{\substack{h\ni u\\h\succ_u g}}y_h=1.\)

This is the existence theorem of Aharoni and Fleiner; the precise displayed formulation appears in Section 2 of [Ishizuka and Kamiyama](https://drops.dagstuhl.de/storage/00lipics/lipics-vol123-isaac2018/LIPIcs.ISAAC.2018.11/LIPIcs.ISAAC.2018.11.pdf).

We next establish the full-assignment property needed to apply it.

Lemma. In a complete tripartite hypergraph with exactly \(N\) vertices on each side, every stable fractional matching in the theorem above saturates every vertex.

Proof. Set \(S=\sum_g y_g\). Each edge meets each side exactly once, so the sum of vertex loads on each side equals \(S\). In particular, \(S\leq N\).

Suppose \(S<N\). On each side, the sum of loads is strictly smaller than the number of vertices, so each side contains an unsaturated vertex. Choose such vertices \(\alpha,\beta,\eta\), one from each side. Completeness guarantees the edge \(g=(\alpha,\beta,\eta)\).

At every endpoint \(u\) of this edge,

\(\displaystyle y_g+\sum_{\substack{h\ni u\\h\succ_u g}}y_h\leq\sum_{h\ni u}y_h<1.\)

This contradicts stability of \(g\). Hence \(S=N\). On each side, \(N\) loads bounded above by \(1\) sum to \(N\); every load therefore equals \(1\). This proves the lemma.

3. Constructing an assignment for arbitrary rational masses

Choose a positive integer \(N\) that is a common denominator of all masses, and put \(k_v=Nw_v\). Every \(k_v\) is a positive integer, and the sum of the \(k_v\)'s on each side is \(N\).

Replace each type \(v\) by \(k_v\) distinct clones. Let \(\pi\) map each clone to its original type. Form the complete tripartite hypergraph on these clones.

For each clone of \(v\), rank opposite-side clone pairs primarily by \(v\)'s ranking of their original type pairs. Within each block having the same original pair, choose any strict order. This produces a strict total ranking. In particular, whenever an original incident triple \(e\) is strictly preferred to another original incident triple \(f\), every corresponding clone triple of \(e\) is strictly preferred to every corresponding clone triple of \(f\).

The cloned hypergraph is finite, and all its vertex rankings are strict total orders, so the fractional stability theorem applies. Let \(y\) be its stable fractional matching. There are exactly \(N\) clones on each side; the lemma therefore gives

\(\displaystyle \sum_{g\ni u}y_g=1\qquad\text{for every clone }u.\)

Aggregate back to the original types by setting

\(\displaystyle x_e=\frac1N\sum_{\substack{g\\\pi(g)=e}}y_g.\)

The coordinates are nonnegative. For every original type \(v\),

\(\displaystyle \sum_{e\ni v}x_e=\frac1N\sum_{\substack{u\\\pi(u)=v}}\sum_{g\ni u}y_g=\frac{k_v}{N}=w_v.\)

Here every clone edge mapping to an edge incident with \(v\) contains exactly one clone of \(v\). Thus the aggregation satisfies precisely the required marginal constraints.

4. The aggregated assignment has zero instability

Suppose, for a contradiction, that \(I(x)>0\). By Section 1, some original triple \(e=(a,b,d)\) satisfies

\(\displaystyle W_a(e)>0,\qquad W_b(e)>0,\qquad W_d(e)>0.\)

For each \(v\in\{a,b,d\}\), positivity of \(W_v(e)\) supplies an original incident triple \(f_v\) with \(x_{f_v}>0\) and \(e\succ_v f_v\). By the aggregation formula, some clone edge \(h_v\) mapping to \(f_v\) has \(y_{h_v}>0\). Let \(u_v\) be its endpoint mapping to \(v\).

Completeness of the cloned hypergraph supplies the edge

\(\displaystyle g=(u_a,u_b,u_d).\)

This edge maps to \(e\). By the construction of the clone rankings, \(g\succ_{u_v}h_v\) for each of its three endpoints.

Each \(u_v\) has total load \(1\), and its positive mass \(y_{h_v}\) lies on an edge strictly worse than \(g\). Hence

\(\displaystyle y_g+\sum_{\substack{h\ni u_v\\h\succ_{u_v}g}}y_h\leq1-y_{h_v}<1.\)

Thus no endpoint of \(g\) satisfies the fractional stability condition, contradicting stability of \(y\).

It follows that \(I(x)=0\). Since \(I\) is a probability, every feasible assignment has \(1-I(x)\leq1\); the constructed assignment attains equality. Therefore \(\mathrm{OPT}=1\).

5. Complexity consequence

For every fixed \(c\in(0,1)\), the negative promise class \(\mathrm{OPT}\leq c\) is empty. The decision algorithm simply returns the alternative \(\mathrm{OPT}=1\). It takes constant time on a trusted valid input, or \(O(L)\) time to read the input.

The cloning argument proves existence; its potentially large expansion is never performed by this decision algorithm. No polynomial-time construction of an optimal assignment is needed.

The cited discrete hardness theorem concerns integral marriages. It does not transfer to this relaxation: even its discrete negative instances acquire zero-instability fractional assignments by the argument above. Likewise, hardness of finding a fractional stable matching does not imply hardness of deciding its existence.
