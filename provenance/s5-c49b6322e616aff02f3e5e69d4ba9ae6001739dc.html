The continuous mirror question, as graded

Given alternatives \(A\), \(k\), \(\gamma=(1-p)/p\in(0,1)\), a rational distribution \(\mu\) over ranking types \(T=L(A)\), and an evidence scale \(\lambda>0\), output a \(k\)-subset \(S\subseteq A\) maximizing \(\sum_{\sigma:\sigma^{-1}(1)\in S} \frac{\gamma^{\lambda\sum_{\rho\in T}\mu_\rho d_K(\rho,\sigma)}}{\sum_{\pi\in T}\gamma^{\lambda\sum_{\rho\in T}\mu_\rho d_K(\rho,\pi)}}\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge2\) alternatives, let \(1\le k<m\), and let \(T=L(A)\) be the strict complete rankings, with \(\sigma(a)\) denoting the position of \(a\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not \(m!\); masses sum to \(1\), and unlisted types have zero mass.
The input also contains binary rationals \(\gamma\in(0,1)\) and \(\lambda>0\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L,k\).
Using Kendall tau distance \(d_K\) and a uniform prior over hidden rankings, define \(q(\sigma)=\gamma^{\lambda\sum_{\rho\in T}\mu_\rho d_K(\rho,\sigma)}/\sum_{\pi\in T}\gamma^{\lambda\sum_{\rho\in T}\mu_\rho d_K(\rho,\pi)}\).
The problem is to output any \(S\subseteq A\) with \(|S|=k\) maximizing \(\sum_{\sigma\in T:\sigma^{-1}(1)\in S}q(\sigma)\); ties permit any maximizing set, and optimality is exact.

Is this problem solvable in polynomial time in \(m,\tau,L,k\), or is it \(\mathrm{NP}\)-hard?

For finite lists of voters, exact selection maximizing the probability of including the hidden top alternative is \(\mathrm{NP}\)-hard under both noisy orders and noisy comparisons for every nontrivial committee size. [Source](https://procaccia.info/wp-content/uploads/2020/03/mle.pdf).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions, already for \(k=1\). Consequently, a polynomial-time algorithm in \(m,\tau,L,k\) would imply \(\mathrm{P}=\mathrm{NP}\).

The proof below uses only rational masses, fixes \(\gamma=1/2\), and uses a positive integer \(\lambda\). Thus exact comparisons involving irrational powers are unnecessary for the hardness result.

1. The normalization preserves finite profiles

For a list of \(N\) rankings \(\rho_1,\ldots,\rho_N\), let \(c_\rho\) be the multiplicity of ranking \(\rho\). Represent its society by the positive masses \(\mu_\rho=c_\rho/N\). For every hidden ranking \(\sigma\),

\(\displaystyle N\sum_{\rho}\mu_\rho d_K(\rho,\sigma)=\sum_{i=1}^{N}d_K(\rho_i,\sigma).\)

Thus choosing \(\lambda=Nh\), for a positive integer \(h\), makes the unnormalized posterior weight exactly

\(\displaystyle \gamma^{\lambda\sum_\rho\mu_\rho d_K(\rho,\sigma)} =\gamma^{h\sum_{i=1}^{N}d_K(\rho_i,\sigma)}.\)

Aggregating identical voters therefore preserves these weights exactly. It produces at most \(N\) supported types, with rational masses of polynomial encoding length. This explains why normalization to total mass \(1\) does not obstruct transferring finite-profile hardness.

We now give an explicit reduction, including the required parameter bounds.

2. Encoding a tournament by supported rankings

A tournament \(G\) has exactly one directed edge between every two distinct vertices. For a ranking \(\sigma\) of its vertices, define \(F_G(\sigma)\) to be the number of backward edges: edges \(u\to v\) with \(\sigma(u)>\sigma(v)\).

Computing \(\min_\sigma F_G(\sigma)\) is \(\mathrm{NP}\)-hard. This is equivalent to minimum feedback arc set: deleting the backward edges leaves an acyclic graph; conversely, a topological ordering after deleting a feedback arc set has all its backward edges among the deleted edges. The hardness theorem applies to unweighted tournaments. [Charbit, Thomassé, and Yeo, Theorem 2](https://perso.ens-lyon.fr/stephan.thomasse/liste/feedback.pdf).

Let \(G\) have \(s\ge2\) vertices. For each edge \(u\to v\), choose an ordering \(R\) of the other vertices and introduce the following two voters:

\(\displaystyle u\succ v\succ R,\qquad \operatorname{rev}(R)\succ u\succ v.\)

Both voters prefer \(u\) to \(v\). On every other unordered pair, their preferences are opposite: this follows from reversal within \(R\), and from placing \(R\) below the endpoints in the first ranking and above them in the second.

There are \(N=2\binom{s}{2}=s(s-1)\) voters. Consequently, for every edge \(u\to v\), exactly \(N/2+1\) voters prefer \(u\) to \(v\), and \(N/2-1\) prefer \(v\) to \(u\).

Define the total Kendall cost

\(\displaystyle D_G(\sigma)=\sum_{i=1}^{N}d_K(\rho_i,\sigma).\)

Each forward edge contributes \(N/2-1\) disagreements, and each backward edge contributes \(N/2+1\). Therefore

\(\displaystyle D_G(\sigma)=C_s+2F_G(\sigma),\qquad C_s=\binom{s}{2}\left(\frac N2-1\right).\)

This identity holds for every ranking.

3. An exact posterior winner begins an optimal ranking

Start with a tournament on \(r\ge2\) vertices, and fix

\(\displaystyle h=r\lceil\log_2 r\rceil+1.\)

For every tournament encountered below, construct the preceding society and set

\(\displaystyle \gamma=\frac12,\qquad \lambda=Nh,\qquad k=1.\)

By Sections 1 and 2, its unnormalized posterior weight is

\(\displaystyle 2^{-hD_G(\sigma)} =2^{-hC_s}\,2^{-2hF_G(\sigma)}.\)

The first factor is independent of \(\sigma\). Hence maximizing the posterior probability of being first is equivalent to maximizing

\(\displaystyle W_G(a)= \sum_{\sigma:\,\sigma(a)=1}2^{-2hF_G(\sigma)}.\)

Lemma. Every alternative maximizing \(W_G(a)\) is first in some ranking minimizing \(F_G\).

Proof. Write \(f=\min_\sigma F_G(\sigma)\). Suppose that no optimal ranking begins with \(a\). Since feedback counts are integers, every ranking beginning with \(a\) has feedback count at least \(f+1\). There are exactly \((s-1)!\) such rankings, so

\(\displaystyle W_G(a)\le(s-1)!\,2^{-2h(f+1)}.\)

Choose an optimal ranking and let \(b\) be its first alternative. Its single contribution gives

\(\displaystyle W_G(b)\ge2^{-2hf}.\)

Because \(s\le r\),

\(\displaystyle (s-1)!\le r^r<2^h<2^{2h}.\)

It follows that \(W_G(a)<W_G(b)\). Thus \(a\) cannot maximize \(W_G\). This proves the lemma, including arbitrary tie handling. \(\square\)

4. Recovering a minimum-feedback ranking

Assume an oracle outputs any exact maximizing committee for the stated problem.

Apply it with \(k=1\) to the society constructed from \(G\), and let its answer be \(\{a\}\). By the lemma, \(a\) begins a minimum-feedback ranking.

Let \(b_G(a)\) be the number of edges directed into \(a\). For every ranking \(\pi\) of the other vertices,

\(\displaystyle F_G(a\succ\pi)=b_G(a)+F_{G-a}(\pi).\)

The first term is independent of \(\pi\). Therefore, because an optimal ranking of \(G\) begins with \(a\), appending any optimal ranking of \(G-a\) also yields an optimal ranking of \(G\).

Repeat the construction and oracle call on \(G-a\), continuing until one vertex remains. Induction using the displayed identity proves that the resulting complete ranking minimizes \(F_G\). This uses at most \(r-1\) oracle calls. Counting its backward edges gives the minimum feedback arc set size.

Thus an exact selection oracle solves an \(\mathrm{NP}\)-hard problem by a polynomial-time Turing reduction.

5. Support size and running time

A query on \(s\) alternatives has

\(\displaystyle m=s,\qquad \tau\le s(s-1),\qquad k=1.\)

After aggregating identical rankings, every mass has the form \(c/N\), requiring \(O(\log s)\) bits. Each supported ranking requires \(O(s\log s)\) bits. The parameter \(\lambda=Nh\) requires \(O(\log r)\) bits. Consequently,

\(\displaystyle L_s=O(s^3\log s+\log r)=O(r^3\log r).\)

All query construction, aggregation, and final verification take \(O(r^4\operatorname{polylog} r)\) bit operations using straightforward implementations.

If the proposed selection algorithm had running time bounded by a polynomial \(P(m,\tau,L,k)\), the resulting tournament algorithm would have a polynomial bound of the form

\(\displaystyle O(r^4\operatorname{polylog}r) +r\,P\!\left(r,r^2,O(r^3\log r),1\right).\)

This contradicts the cited hardness theorem unless \(\mathrm{P}=\mathrm{NP}\).

The target question is therefore settled for input committee size \(k\): hardness already holds on its restriction \(k=1\). No assertion about membership in \(\mathrm{NP}\), or about hardness for each separately fixed committee size, is needed.

3. Encoding tournament edges

For the two voters associated with \(u\to v\), both rank \(u\) above \(v\). Their preferences cancel on every other pair: pairs within \(R\) are reversed, and pairs between an endpoint and a vertex of \(R\) are reversed by the block placements.

For any fixed tournament edge, its own voter pair therefore supplies two votes in its direction, while each other voter pair supplies one vote in each direction. With \(N=2\binom{s}{2}\), the counts \(N/2+1\) and \(N/2-1\) follow.

Kendall distance counts disagreeing unordered pairs. Hence each forward edge contributes \(N/2-1\), each backward edge contributes \(N/2+1\), and
\[ D_G(\sigma)=\binom{s}{2}(N/2-1)+2F_G(\sigma) \]
is correct for every ranking.

The construction also works for \(s=2\): \(R\) is empty, the two voters coincide, and aggregation is permitted.
