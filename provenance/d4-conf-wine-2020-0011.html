The continuous mirror question, as graded

Given categories \(\Theta\), a finite support \(\mathcal T\) of complete advertiser types \(t=(\theta,v)\) with rational masses \(\mu_t\) summing to \(1\), and \(N\) ordered slots with rational capacities \(q_j\) summing to \(1\), nonincreasing discounts \(\alpha_{\theta,j}\), and gap matrix \(G\), choose \(z_{t,j}\in\{0,1\}\) and assigned masses \(x_{t,j}\ge 0\). Require \(\sum_t z_{t,j}\le 1\), \(x_{t,j}\le q_jz_{t,j}\), and \(\sum_jx_{t,j}\le\mu_t\); if \(z_{t,j}=1\) for category \(\theta\), then \(z_{t',\ell}=0\) for every type \(t'\) of category \(\phi\) and every \(1\le\ell-j\le G_{\theta\phi}\). Maximize \(\sum_{t=(\theta,v),j}v\alpha_{\theta,j}x_{t,j}\).

Packaged proof task (what the prover saw — nothing else)

Let \(\Theta\) be a nonempty set of \(k\) categories. A society is given by its support: a list \(\mathcal T\) of \(\tau\) distinct complete types \(t=(\theta,v)\), each with positive binary rational mass \(\mu_t\), where \(v\ge0\) is rational and \(\sum_t\mu_t=1\). Every category occurs in the support; \(\tau\) counts listed types, not all possible types.
There are \(m=N\ge1\) ordered slots with positive rational capacities \(q_j\) satisfying \(\sum_jq_j=1\). Each category has rational discounts \(\alpha_{\theta,1}\ge\cdots\ge\alpha_{\theta,m}\ge0\). The directed gap matrix has entries \(G_{\theta\phi}\in\mathbb Z_{\ge0}\), including diagonal entries.
Choose \(z_{t,j}\in\{0,1\}\) and real masses \(x_{t,j}\ge0\), subject to \(\sum_tz_{t,j}\le1\), \(x_{t,j}\le q_jz_{t,j}\), and \(\sum_jx_{t,j}\le\mu_t\). Mass may be split across slots; capacities and supply may remain unused.
For all \(t=(\theta,v)\), \(t'=(\phi,v')\), and slots \(j<\ell\) with \(\ell-j\le G_{\theta\phi}\), require \(z_{t,j}+z_{t',\ell}\le1\). Gaps count slot indices, irrespective of capacities or intervening empty slots.
Maximize \(W=\sum_{t=(\theta,v),j}v\alpha_{\theta,j}x_{t,j}\), and let \(\mathrm{OPT}\) denote its maximum. Let \(L\) be the total binary input length; express running times in \(m,\tau,k,L\).

For each fixed \(0<\varepsilon<1\), is there an algorithm polynomial in \(m,\tau,k,L\) that returns a feasible allocation with \(W\ge\mathrm{OPT}/k^{1-\varepsilon}\), or is achieving this approximation guarantee NP-hard?

The discrete problem assigns each individual ad to at most one slot and is NP-hard to approximate within \(k^{1-\varepsilon}\) for every fixed \(0<\varepsilon<1\), even with all discounts equal to \(1\); it also has an exact \(O(km^{2k+1})\) dynamic program ([verified discrete results](https://arxiv.org/pdf/1907.04400)).
No result settling this exact mass allocation model was located in the literature search.

Modeling choices made when packaging the task

  • Specified nonnegative rational values and nonnegative rational, weakly decreasing discounts, following the discrete definition; imposed no additional upper bound on discounts.
  • Specified directed nonnegative integer gaps, including self-category gaps, measured in slot indices.
  • Required positive slot capacities and at least one slot; zero-capacity slots have no allocation role but would otherwise affect gap distances.
  • Took the category set to consist of categories represented in the positive-mass support, so the approximation parameter excludes unused categories.
  • Retained divisible real assigned masses, splitting across slots, unused supply, and partially filled slots as permitted by the graded constraints.
  • Retained gap constraints on binary selections even when their assigned mass is zero, exactly as stated in the graded question.
  • Used m=N for the number of slots and L for total binary input length.
  • Restricted the approximation exponent to fixed epsilon between zero and one, the meaningful range for the stated maximization guarantee.

Result

For every fixed \(0<\varepsilon<1\), achieving the guarantee \(W\ge \mathrm{OPT}/k^{1-\varepsilon}\) is \(\mathrm{NP}\)-hard. Thus no algorithm polynomial in \(m,\tau,k,L\) achieves this guarantee unless \(\mathrm{P}=\mathrm{NP}\).

The hardness holds with all discounts equal to \(1\), symmetric gaps, zero diagonal gaps, and dyadic masses and capacities. The proof explicitly allows mass splitting.

Known hardness theorem

For every fixed \(0<\varepsilon<1\), approximating maximum independent set on an \(n\)-vertex graph within \(n^{1-\varepsilon}\) is \(\mathrm{NP}\)-hard. This follows from [Zuckerman’s maximum-clique hardness theorem](https://www.theoryofcomputing.org/articles/v003a006/) by taking graph complements: complementation preserves the number of vertices and converts cliques into independent sets of exactly the same cardinality.

We give an approximation-preserving reduction from this problem.

Construction of the mass-allocation instance

Let \(H=(V,E)\) be a simple undirected graph with \(n\ge1\) vertices. Write \(a(H)\) for its maximum independent-set cardinality.

Set \(k=n\), with one category \(\theta_u\) for each vertex \(u\in V\). Let \(b\) be the smallest power of two satisfying \(b\ge n\). Set \(m=N=b\).

Construct the support as follows:

  • For every vertex \(u\), include the complete type \(t_u=(\theta_u,1)\) with mass \(\mu_{t_u}=1/b\).
  • If \(b>n\), choose any vertex \(u_0\) and additionally include the type \(t_0=(\theta_{u_0},0)\) with mass \(\mu_{t_0}=(b-n)/b\).

The additional type introduces no additional category. Consequently, \(\tau=k\) when \(b=n\), and \(\tau=k+1\) otherwise. All listed types are distinct, all listed masses are positive, every category occurs, and the masses sum to \(1\). All masses are dyadic.

For every slot \(j\), set \(q_j=1/b\). For every category and slot, set \(\alpha_{\theta,j}=1\). These capacities are positive and sum to \(1\), and the discounts satisfy the required monotonicity.

Finally, define
\(\displaystyle G_{\theta_u\theta_v}=\begin{cases}b,&\{u,v\}\in E,\\0,&\text{otherwise}.\end{cases}\)

The matrix is symmetric and has zero diagonal. For adjacent vertices, the gap covers every possible distance between two slots, because that distance is at most \(b-1\).

Exact correspondence of optimal values

We prove that \(\mathrm{OPT}=a(H)/b\).

Every feasible allocation yields an independent set

Given a feasible allocation \((z,x)\), define
\(\displaystyle S=\{u\in V:\text{some listed type of category }\theta_u\text{ has }z_{t,j}=1\text{ for some }j\}.\)

Suppose adjacent vertices \(u,v\) both belonged to \(S\). Choose witnessing assignments in slots \(j,\ell\).

They cannot occupy the same slot, because each slot permits at most one selected type. If \(j<\ell\), then \(\ell-j\le b-1\le G_{\theta_u\theta_v}\), so the gap constraint forbids the two assignments. If \(\ell<j\), the symmetric gap gives the same contradiction. Therefore \(S\) is independent.

The only positive-valued type in category \(\theta_u\) is \(t_u\), whose total supply is \(1/b\). The additional type, if present, contributes zero welfare. Since all discounts equal \(1\), every feasible allocation satisfies
\(\displaystyle W=\sum_{u\in V}\sum_{j=1}^{b}x_{t_u,j}\le\sum_{u\in S}\mu_{t_u}=\frac{|S|}{b}\le\frac{a(H)}{b}.\)

This inequality uses the total supply constraint for each type, so it remains valid when its mass is split across multiple slots.

Every independent set yields a feasible allocation

Let \(I\subseteq V\) be independent. Assign each type \(t_u\), for \(u\in I\), to a different slot, and place mass \(1/b\) there. Set all other variables to zero.

There are enough slots because \(|I|\le n\le b\). Each occupied slot receives exactly its capacity, and each selected type uses exactly its supply.

Each selected category occurs once, so diagonal gaps cause no restriction. Distinct selected categories correspond to nonadjacent vertices, so their gaps are zero; their distinct slot indices have positive distance and hence trigger no gap constraint.

The allocation is therefore feasible and has welfare \(|I|/b\). Taking a maximum independent set proves \(\mathrm{OPT}\ge a(H)/b\), completing the equality.

Approximation transfer and running time

Suppose an algorithm polynomial in \(m,\tau,k,L\) returned a feasible allocation satisfying \(W\ge\mathrm{OPT}/k^{1-\varepsilon}\). Apply it to the constructed instance and extract \(S\) from its binary assignment variables.

The preceding proof gives
\(\displaystyle |S|\ge bW\ge\frac{b\,\mathrm{OPT}}{k^{1-\varepsilon}}=\frac{a(H)}{n^{1-\varepsilon}}.\)

Thus the algorithm would approximate maximum independent set within \(n^{1-\varepsilon}\).

The reduction has \(k=n\), \(m=b<2k\), and \(\tau\le k+1\). Its binary input length is \(L=O(k^2\log(k+1))\), and it can be constructed within that many bit operations. Extracting \(S\) requires \(O(m\tau)\) inspections of binary assignment variables. Hence a running time polynomial in \(m,\tau,k,L\) would give a polynomial-time algorithm for the prohibited independent-set approximation.

This proves the claimed hardness for the exact mass-allocation model.
