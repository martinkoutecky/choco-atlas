The continuous mirror question, as graded

Given housing classes \(H\) on a common axis, a list of \(\tau\) complete strict single-peaked rankings \(r\), rational type masses \(\mu_r\geq 0\) summing to \(1\), and rational per-capita class capacities \(\sigma_h\) with \(\sum_h \sigma_h>1\), choose assignment masses \(y_{r,h}\geq 0\) satisfying \(\sum_h y_{r,h}=\mu_r\) and \(\sum_r y_{r,h}\leq \sigma_h\). Let \(S(y)=\{h:\sum_r y_{r,h}>0\}\) and \(\mathcal E(y)=\sum_{r,h}y_{r,h}\mathbf{1}[\exists g\in S(y):g\succ_r h]\). Find a feasible assignment minimizing \(\mathcal E(y)\).

Packaged proof task (what the prover saw — nothing else)

Let \(H\) be a nonempty set of \(m\) housing classes with a supplied common axis. Types are complete strict rankings \(\succ_r\) of \(H\), single-peaked on that axis.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_r\) a binary rational, with \(\sum_r\mu_r=1\). Here \(\tau\) is the support size, not the number of possible rankings.
Class capacities are binary rationals \(\sigma_h\geq0\), with \(\sum_h\sigma_h>1\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
An assignment consists of real masses \(y_{r,h}\geq0\) satisfying \(\sum_h y_{r,h}=\mu_r\) and \(\sum_r y_{r,h}\leq\sigma_h\); types may be split among classes and capacity may remain unused.
Define \(S(y)=\{h\in H:\sum_r y_{r,h}>0\}\) and the envious mass \(\mathcal E(y)=\sum_{r,h}y_{r,h}\mathbf 1[\exists g\in S(y):g\succ_r h]\). Thus any positive occupied mass in a preferred class triggers envy, including mass of the same type.

Is finding a feasible assignment minimizing \(\mathcal E(y)\) solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For discrete injective allocations with more houses than agents and complete strict single-peaked rankings on a common axis, minimizing the number of envious agents admits a polynomial-time algorithm, with reported runtime \(O(m^2)\). [Source](https://arxiv.org/html/2511.07022v1)
No result settling this exact mass-and-occupied-support formulation was located in the literature search.

Modeling choices made when packaging the task

  • The signs of capacities were unspecified; capacities are nonnegative binary rationals, allowing zero capacity.
  • The assignment-mass domain was unspecified beyond nonnegativity; masses are real and may split a type among classes.
  • Zero-mass entries are omitted to enforce the required support representation.
  • L denotes the total input bit length, including the axis, rankings, masses, and capacities.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Complexity classification

Finding an assignment minimizing envious mass is \(\mathrm{NP}\text{-hard}\). The threshold decision problem is \(\mathrm{NP}\text{-complete}\).

The hardness holds even when every mass and capacity is a positive dyadic rational and \(\tau=m\). Thus a running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. Source problem and parameters

We reduce from Subset Sum: given positive binary integers \(a_1,\ldots,a_n\) and an integer \(B\), decide whether some \(I\subseteq\{1,\ldots,n\}\) satisfies

\(\displaystyle \sum_{i\in I}a_i=B.\)

Subset Sum is a standard \(\mathrm{NP}\text{-hard}\) problem; see, for example, [Polak, Rohwedder, and Węgrzycki](https://arxiv.org/abs/2105.04035). Write \(A=\sum_{i=1}^n a_i\). We may restrict to \(0<B<A\): cases outside this range are immediately decidable and can be mapped to fixed yes or no instances within the range.

Let \(D\) be the smallest power of two satisfying \(D\geq 8(n+1)A\). Define

\(\displaystyle c_i=\frac{a_i}{D},\qquad C=\frac{A}{D},\qquad \delta=\frac{B}{D},\qquad G=2C,\qquad K=1-2(n+1)C-\delta.\)

These numbers are dyadic rationals. Moreover,

\(\displaystyle 0<\delta<C\leq\frac{1}{8(n+1)}\leq\frac{1}{16},\)

and

\(\displaystyle K\geq\frac34-\delta>\frac34-C\geq\frac{11}{16}>C.\)

In particular, all parameters used as masses or capacities below are positive.

2. Housing instance

Use the \(2n+1\) classes on the supplied axis

\(\displaystyle z<p_1<q_1<p_2<q_2<\cdots<p_n<q_n.\)

Their capacities are

\(\displaystyle \sigma_z=K,\qquad \sigma_{p_i}=G+2c_i,\qquad \sigma_{q_i}=c_i.\)

There are \(2n+1\) supported types:

| Type | Mass | Peak |
|---|---:|---|
| Anchor type \(r_0\) | \(K+\delta\) | \(z\) |
| Guard type \(s_i\) | \(G\) | \(p_i\) |
| Item type \(r_i\) | \(2c_i\) | \(q_i\) |

For each type, complete its ranking as follows: rank its peak first, then all classes to its left in decreasing axis order, then all classes to its right in increasing axis order.

Each ranking is complete and strict. On either side of its peak, classes become less preferred as their distance along the axis increases, so every ranking is single-peaked. In particular, item type \(r_i\) ranks \(q_i\) first and \(p_i\) second. The types have distinct peaks and hence are distinct.

The masses sum to one:

\(\displaystyle (K+\delta)+nG+2\sum_i c_i=K+\delta+2(n+1)C=1.\)

The total capacity is

\(\displaystyle K+\sum_i(G+2c_i+c_i)=1-\delta+C>1.\)

Thus the construction satisfies every input promise.

All numerical data have bit length \(O(\log n+\log A)\), because \(D<16(n+1)A\). Explicitly writing the rankings and numerical data takes polynomial time and produces

\(\displaystyle m=\tau=2n+1,\qquad L=O\!\left(n^2\log(n+1)+n(\log(n+1)+\log A)\right).\)

3. Capacity forces all baseline classes to be occupied

Let

\(\displaystyle F=\{z,p_1,\ldots,p_n\}.\)

Its total capacity is

\(\displaystyle \sum_{h\in F}\sigma_h=K+nG+2C=1-\delta.\)

Every class in \(F\) has capacity greater than \(C\): this follows from \(K>C\) and \(\sigma_{p_i}=2C+2c_i>C\).

Suppose a feasible assignment left some \(h\in F\) unoccupied. The total capacity available in its occupied support would then be at most

\(\displaystyle \sum_{g\in H}\sigma_g-\sigma_h =1-\delta+C-\sigma_h<1-\delta<1.\)

That cannot accommodate population mass one. Therefore every feasible assignment occupies every class in \(F\).

For a feasible assignment \(y\), define

\(\displaystyle I(y)=\{i:q_i\in S(y)\},\qquad t(y)=\sum_{i\in I(y)}c_i.\)

Its support is precisely \(F\cup\{q_i:i\in I(y)\}\). Consequently, feasibility requires

\(\displaystyle 1\leq\sum_{h\in S(y)}\sigma_h=1-\delta+t(y),\)

so

\[\displaystyle t(y)\geq\delta.\tag{1}\]

4. Occupying optional classes forces envy

Because \(z\) is occupied and is the anchor type’s peak, all anchor-type mass assigned outside \(z\) is envious. The anchor type has mass \(K+\delta\), whereas \(z\) has capacity \(K\). Thus its envious mass is at least \(\delta\).

For each \(i\in I(y)\), class \(q_i\) is occupied and is item type \(r_i\)’s peak. Hence every part of that type assigned outside \(q_i\) is envious. Its mass is \(2c_i\), while \(q_i\) has capacity \(c_i\), so its envious mass is at least \(c_i\).

These are different types, and all remaining envy contributions are nonnegative. Therefore

\[\displaystyle \mathcal E(y)\geq\delta+\sum_{i\in I(y)}c_i=\delta+t(y).\tag{2}\]

Set the decision threshold to \(\eta=2\delta\). If \(\mathcal E(y)\leq\eta\), inequalities (1) and (2) imply

\(\displaystyle \delta\leq t(y)\leq\delta.\)

Thus \(t(y)=\delta\), equivalently

\(\displaystyle \sum_{i\in I(y)}a_i=B.\)

This proves that a housing yes-instance implies a Subset Sum yes-instance. The argument applies to arbitrary real assignments and arbitrary positive occupation amounts.

5. A subset summing to the target gives an assignment

Conversely, suppose \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{i\in I}a_i=B\), so \(\sum_{i\in I}c_i=\delta\).

Define the assignment by the following nonzero entries; all other entries are zero:

  • Assign guard type \(s_i\)’s entire mass \(G\) to \(p_i\).
  • For \(i\notin I\), assign item type \(r_i\)’s entire mass \(2c_i\) to \(p_i\).
  • For \(i\in I\), assign mass \(c_i\) of item type \(r_i\) to each of \(p_i\) and \(q_i\).
  • Assign anchor-type mass \(K\) to \(z\), and mass \(c_i\) to \(p_i\) for each \(i\in I\).

Every type receives its prescribed total mass. In particular, the anchor row sums to \(K+\sum_{i\in I}c_i=K+\delta\).

Class \(z\) receives exactly \(K\). Each \(p_i\) receives exactly \(G+2c_i\), and each occupied \(q_i\) receives exactly \(c_i\). Hence the assignment is feasible, with support \(F\cup\{q_i:i\in I\}\).

Its envy is exactly:

  • Anchor mass outside \(z\): \(\delta\).
  • Item mass at \(p_i\) for \(i\in I\): \(\sum_{i\in I}c_i=\delta\).

Guards are at their peaks. For \(i\notin I\), item type \(r_i\) is at its second choice \(p_i\), and its only preferred class \(q_i\) is unoccupied. Item mass at \(q_i\) is at its peak. Therefore

\(\displaystyle \mathcal E(y)=2\delta=\eta.\)

We have proved the exact equivalence

\(\displaystyle \exists I:\sum_{i\in I}a_i=B \quad\Longleftrightarrow\quad \exists\text{ feasible }y:\mathcal E(y)\leq2\delta.\)

This establishes \(\mathrm{NP}\text{-hardness}\).

6. Decision membership and an exact exponential algorithm

The use of real assignments does not obstruct membership in \(\mathrm{NP}\).

For any nonempty \(S\subseteq H\), let \(b_r(S)\) be type \(r\)’s most preferred class in \(S\). Consider the rational linear program with variables \(y_{r,h}\) for \(h\in S\), the usual row and capacity constraints, and objective

\(\displaystyle C_S(y)=\sum_r\sum_{h\in S\setminus\{b_r(S)\}}y_{r,h}.\)

Classes in \(S\) may receive zero mass. If the resulting actual support is \(T\subseteq S\), then

\(\displaystyle \mathcal E(y)\leq C_S(y),\)

because every preferred occupied class belongs to \(S\).

A decision certificate is the subset \(S\). Verify it by checking feasibility of this linear program with the additional inequality \(C_S(y)\leq\eta\).

This verifier is sound by the preceding inequality. It is complete because, for any assignment satisfying the threshold, choosing \(S=S(y)\) gives \(C_S(y)=\mathcal E(y)\). The linear program has at most \(m\tau\) variables, rational coefficients, and polynomial encoding length. Rational linear programming therefore verifies the certificate in time polynomial in \(m,\tau,L+\ell(\eta)\), where \(\ell(\eta)\) is the threshold’s bit length. The decision problem is consequently \(\mathrm{NP}\text{-complete}\).

For completeness, minimizing \(C_S\) over all nonempty subsets \(S\) gives an exact algorithm running in

\(\displaystyle 2^m\operatorname{poly}(m,\tau,L).\)

Indeed, let \(v\) be the smallest feasible linear-program optimum. Every assignment \(y\), evaluated using \(S(y)\), satisfies \(\mathcal E(y)=C_{S(y)}(y)\geq v\). An optimizer of a linear program attaining \(v\) has actual envy at most \(v\), and therefore exactly \(v\). This also proves that a rational optimal assignment exists.

The known polynomial result concerns [discrete injective allocations](https://arxiv.org/html/2511.07022v1). Here, occupying \(q_i\) makes all of its type’s mass outside \(q_i\) envious, although \(q_i\) can accommodate only half that type. Together with the forced baseline support, this produces the exact subset-sum constraint.
