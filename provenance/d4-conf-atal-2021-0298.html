Result

The decision problem is \(\mathrm{NP}\)-complete. Consequently, computing an optimal shortlist and its exact value is \(\mathrm{NP}\)-hard and has no polynomial-time algorithm unless \(\mathrm{P}=\mathrm{NP}\).

Hardness holds even when all catalogue coordinates are binary, all masses are equal, and every uncertainty polytope has dimension \(p-1\), the full dimension of the simplex. Thus the conclusion does not depend on allowing singleton uncertainty sets.

For a prescribed shortlist, however, its exact regret is polynomial-time computable.

1. Exact evaluation of a prescribed shortlist

Write \(\Delta_p=\{w\in\mathbb{R}^p:w_i\geq0,\ \sum_iw_i=1\}\). For a nonempty \(B\subseteq A\), define

\(g_B(w)=\max_{a\in A}a\cdot w-\max_{b\in B}b\cdot w\), and \(r_t(B)=\max_{w\in W_t}g_B(w)\).

Each \(W_t\) is nonempty and compact: its weak inequalities define a closed set, and it lies in the bounded simplex. The function \(g_B\) is continuous, so every maximum defining \(r_t(B)\) is attained.

Because the types’ uncertainty choices are independent,

\(R_\mu(B)=\sum_{t=1}^{\tau}\mu_t r_t(B)\).

Indeed, every feasible tuple gives a sum at most the right-hand side. Choosing a maximizing \(w_t\) for each type simultaneously attains equality.

For each \(t\) and \(a\in A\), let

\(v_{t,a}(B)=\max\{z:w\in W_t,\ z\leq(a-b)\cdot w\text{ for every }b\in B\}\).

For fixed \(w\), the largest feasible \(z\) equals

\(\min_{b\in B}(a-b)\cdot w=a\cdot w-\max_{b\in B}b\cdot w\).

Interchanging the two maxima, one over a finite set and the other over a compact set, therefore gives

\(r_t(B)=\max_{a\in A}v_{t,a}(B)\).

Thus evaluation requires exactly \(m\tau\) rational linear programs, each with \(p+1\) variables and \(k\) additional shortlist inequalities.

To check boundedness explicitly, set \(M=\max_{a\in A,\ i}|a_i|\). Since every feasible \(w\) belongs to \(\Delta_p\), one has \(|(a-b)\cdot w|\leq2M\). We may therefore add \(-2M\leq z\leq2M\) without changing the optimum. The resulting feasible region is a nonempty bounded rational polytope, even if \(W_t\) is lower-dimensional.

We use the standard rational linear programming theorem: an explicitly encoded rational linear program can be solved in time polynomial in its binary encoding length, with an exact rational optimum when finite. This is the polynomial-time linear programming result originating with [Khachiyan](https://www.mathnet.ru/eng/dan42319). The hypotheses hold here: every coefficient is rational, the constraints are explicit, and the preceding bounds establish feasibility and boundedness.

Every constructed program has encoding length polynomial in \(p,k,L\). Its optimum has polynomial binary length, and taking maxima and forming the mass-weighted sum preserves polynomial binary length. Hence, for some fixed polynomial \(P\), exact evaluation takes time

\(O\!\left(m\tau P(p,k,L)\right)\).

A certificate for the decision problem is a list of \(k\) distinct catalogue indices. Checking the indices, computing the exact regret, and comparing it with \(q\) are polynomial-time operations. Therefore the decision problem belongs to \(\mathrm{NP}\).

2. A polynomial reduction from satisfiability

We reduce from the standard \(\mathrm{NP}\)-complete satisfiability problem for formulas whose clauses contain at most three literals, listed in [Karp’s original paper](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

Let the source formula have variables \(x_1,\ldots,x_n\) and nonempty clauses \(C_1,\ldots,C_c\), with \(n,c\geq1\). These restrictions preserve hardness: formulas with an empty clause or no clauses can be replaced, respectively, by a fixed unsatisfiable or satisfiable formula satisfying the restrictions.

Set \(N=n+c\). We construct

\(m=2n,\qquad k=n,\qquad \tau=N,\qquad p=N+2n=3n+c\).

Catalogue

Label the coordinates as follows:

  • Variable coordinates \(v_1,\ldots,v_n\).
  • Clause coordinates \(d_1,\ldots,d_c\).
  • Private coordinates \(h_\ell\), one for each literal \(\ell\in\{x_1,\neg x_1,\ldots,x_n,\neg x_n\}\).

For each literal \(\ell\), construct an item \(a^\ell\in\{0,1\}^p\) by the rules:

  • \(a^\ell_{v_i}=1\) precisely when \(\ell\) is \(x_i\) or \(\neg x_i\).
  • \(a^\ell_{d_j}=1\) precisely when \(\ell\) occurs in \(C_j\).
  • \(a^\ell_{h_{\ell'}}=1\) precisely when \(\ell=\ell'\).

All remaining entries are zero. The private coordinates ensure that all \(2n\) items are distinct, as required for a catalogue defined as a set.

Call the variable and clause coordinates the test coordinates. Every test coordinate has catalogue maximum \(1\): both literals of a variable have value \(1\) at its variable coordinate, and every clause is nonempty.

Say that \(B\) covers a test coordinate \(j\) if some \(b\in B\) has \(b_j=1\).

Types and uncertainty polytopes

There is one type for each test coordinate \(j\), with mass

\(\mu_j=1/N\).

Set \(\varepsilon=1/(2N)\), and define

\(W_j=\{w\in\Delta_p:w_j\geq1-\varepsilon\},\qquad q=\varepsilon\).

These polytopes have explicit weak rational descriptions. They are nonempty because \(e_j\in W_j\).

They also have dimension \(p-1\). To verify this, consider the point with

\(w_j=1-\varepsilon/2,\qquad w_i=\varepsilon/(2(p-1))\quad(i\neq j)\).

Every coordinate is strictly positive and \(w_j>1-\varepsilon\). Consequently, a sufficiently small neighborhood of this point within the hyperplane \(\sum_iw_i=1\) remains in \(W_j\).

The catalogue has \(2np\) binary entries. Each polytope uses \(p\) nonnegativity inequalities, two inequalities for the simplex equality, and one additional inequality. Masses and thresholds have binary length \(O(\log N)\). The entire construction therefore has size, and can be produced in time, polynomial in the source input length.

3. The threshold separates coverage from noncoverage

If every test coordinate is covered

Fix a type \(j\), and choose \(b\in B\) with \(b_j=1\). For every \(w\in W_j\), binary nonnegative catalogue coordinates imply

\(\max_{a\in A}a\cdot w\leq1\),

whereas

\(\max_{b'\in B}b'\cdot w\geq b\cdot w\geq w_j\geq1-\varepsilon\).

Thus \(g_B(w)\leq\varepsilon\), so \(r_j(B)\leq\varepsilon\). Summing over the equal masses gives

\(R_\mu(B)\leq\sum_{j=1}^{N}(1/N)\varepsilon=\varepsilon=q\).

If some test coordinate is uncovered

Suppose \(j\) is uncovered. At the feasible point \(w=e_j\), every selected item has utility \(0\), while the catalogue maximum is \(1\). Hence \(r_j(B)\geq1\).

All type regrets are nonnegative because \(B\subseteq A\). Therefore

\(R_\mu(B)\geq\mu_jr_j(B)\geq1/N>1/(2N)=q\).

We have proved the exact equivalence

\(R_\mu(B)\leq q\quad\Longleftrightarrow\quad B\text{ covers every test coordinate}\).

4. Coverage is equivalent to satisfiability

Suppose the formula is satisfiable. Select the item corresponding to the true literal of each variable. This produces exactly \(n=k\) items and covers every variable coordinate. Every clause has a true literal, so every clause coordinate is also covered. Section 3 gives \(R_\mu(B)\leq q\).

Conversely, suppose a shortlist of exactly \(n\) items satisfies \(R_\mu(B)\leq q\). It covers all test coordinates.

Only \(a^{x_i}\) and \(a^{\neg x_i}\) cover variable coordinate \(v_i\). Thus the shortlist must contain at least one item from each of the \(n\) disjoint literal pairs. Since it contains exactly \(n\) items, it contains exactly one item from each pair.

Assign \(x_i\) true precisely when \(a^{x_i}\) is selected. Every clause coordinate is covered by a selected literal occurring in that clause. That literal is true under the assignment, so every clause is satisfied.

This proves a polynomial many-one reduction and establishes \(\mathrm{NP}\)-hardness. Together with Section 1, it proves \(\mathrm{NP}\)-completeness.

5. Exact optimization and running times

An exact optimization algorithm would decide the decision problem by comparing its returned value with \(q\). Exact optimization is therefore \(\mathrm{NP}\)-hard.

There is nevertheless an exact exhaustive algorithm: enumerate all shortlists of size \(k\), evaluate each by Section 1, and retain one with minimum value. Its running time is

\(O\!\left(\binom{m}{k}\,m\tau P(p,k,L)\right)\).

In particular, this is at most \(O\!\left(m^{k+1}\tau P(p,k,L)\right)\), so optimization is polynomial-time solvable for every fixed \(k\). For \(k=m\), the optimum is immediately \(0\).

The finite-scenario SAT equivalence mentioned in the question concerns a common maximum-regret threshold, as developed by [Toffano, Viappiani and Wilson](https://ifaamas.csc.liv.ac.uk/Proceedings/aamas2021/pdfs/p1326.pdf). The proof above directly handles the mass-weighted objective: independence permits exact evaluation by separate linear programs, while the constructed threshold gap makes shortlist selection \(\mathrm{NP}\)-complete.
