The continuous mirror question, as graded

Given \(q\) ordered accuracy cohorts and rational report masses \(\mu_{j,b}\ge 0\), with \(\sum_{j=1}^q\sum_{b\in\{0,1\}}\mu_{j,b}=1\), choose \(y\in\{0,1\}\) minimizing \(D^\epsilon_\mu(y)=\sup_{1-\epsilon\ge p_1\ge\cdots\ge p_q\ge 1/2}\exp\!\left(\sum_{j=1}^q(\mu_{j,1-y}-\mu_{j,y})\log\frac{p_j}{1-p_j}\right)\).

Packaged proof task (what the prover saw — nothing else)

A society has \(m=2\) possible reports and \(q\ge 1\) nonempty accuracy cohorts, ordered from most to least accurate. A type is a pair \((j,b)\), where \(j\in\{1,\ldots,q\}\) and \(b\in\{0,1\}\). All mass in cohort \(j\) shares one unknown accuracy \(p_j\).
The society is given by its support: the list of the \(\tau\) types with positive mass, each mass encoded as a binary rational. Thus \(\tau\) is the support size, not the number of possible types. Missing types have mass zero, and \(\sum_{j=1}^q\sum_{b\in\{0,1\}}\mu_{j,b}=1\).
The input also includes a binary rational \(\epsilon\in(0,1/2)\). Feasible accuracies are real numbers satisfying \(1-\epsilon\ge p_1\ge\cdots\ge p_q\ge 1/2\); equality is allowed. Let \(L\) be the total input bit length.
Define \(D^\epsilon_\mu(y)=\sup_{1-\epsilon\ge p_1\ge\cdots\ge p_q\ge 1/2}\exp\!\left(\sum_{j=1}^q(\mu_{j,1-y}-\mu_{j,y})\log\frac{p_j}{1-p_j}\right)\). The computational problem is to return a minimizing \(y\in\{0,1\}\); either bit is permitted when both minimize. State running times in \(m,\tau,q,L\).

Is this exact minimizer-selection problem solvable in polynomial time in \(m,\tau,q,L\), or is it NP-hard?

For a finite ordered list of \(n\) binary judgments with independently varying ordered accuracies, distortion minimization is computable in \(O(n)\) time for every \(\epsilon\in(0,1/2)\). [Source](https://www.cs.toronto.edu/~nisarg/papers/ranked-binary-judgments.pdf)
No published result settling the exact rational-mass cohort problem above was identified in the literature searches.

Result

The exact minimizer-selection problem is polynomial-time solvable. For \(m=2\), a deterministic algorithm uses \(O((\tau+q)L^2)\) bit operations, equivalently \(O(m(\tau+q)L^2)\). The minimizing reports are independent of \(\epsilon\).

Exact distortion formula

Define the signed cohort masses and their prefix sums by
\(a_j=\mu_{j,1}-\mu_{j,0}\), \(S_0=0\), and
\(S_k=\sum_{j=1}^k a_j\) for \(1\le k\le q\).

Let
\(A=\max_{0\le k\le q}S_k\),
\(B=-\min_{0\le k\le q}S_k\), and
\(R=(1-\epsilon)/\epsilon>1\).
We will prove
\(D^\epsilon_\mu(0)=R^A\) and \(D^\epsilon_\mu(1)=R^B\).

First set \(H=\log R>0\) and introduce the log odds
\(x_j=\log(p_j/(1-p_j))\).
The function \(p\mapsto\log(p/(1-p))\) is continuous and strictly increasing on the permitted interval, with endpoint values \(0\) and \(H\). Thus this transformation is a bijection between the feasible accuracy vectors and
\(\{x\in\mathbb R^q:H\ge x_1\ge\cdots\ge x_q\ge0\}\).

We establish the following identity for arbitrary real coefficients \(c_1,\ldots,c_q\). With \(C_0=0\) and \(C_k=\sum_{j=1}^k c_j\),
\[ \max_{H\ge x_1\ge\cdots\ge x_q\ge0}\sum_{j=1}^q c_jx_j =H\max_{0\le k\le q}C_k. \]
Here and below, this displayed identity is understood as
\(\max_{H\ge x_1\ge\cdots\ge x_q\ge0}\sum_{j=1}^q c_jx_j=H\max_{0\le k\le q}C_k\).

To prove it, set \(x_{q+1}=0\) and \(d_k=x_k-x_{k+1}\). Then \(d_k\ge0\), \(\sum_{k=1}^q d_k=x_1\le H\), and \(x_j=\sum_{k=j}^q d_k\). Consequently,
\(\sum_{j=1}^q c_jx_j=\sum_{k=1}^q d_kC_k\).

Writing \(M=\max_{0\le k\le q}C_k\), we have \(M\ge0\) because \(C_0=0\). Hence
\(\sum_{k=1}^q d_kC_k\le M\sum_{k=1}^q d_k\le HM\).

This bound is attained. If \(M=0\), choose every \(x_j=0\). If \(M>0\), choose an index \(k\ge1\) with \(C_k=M\), and set \(x_j=H\) for \(j\le k\) and \(x_j=0\) for \(j>k\). This vector is feasible and its objective value is \(HC_k=HM\).

For report \(0\), the coefficients in the stated distortion objective are \(a_j\); for report \(1\), they are \(-a_j\). Applying the identity gives maximum exponents \(HA\) and \(HB\), respectively. Since the exponential is increasing, the distortion formulas follow. In particular, the supremum is attained by a feasible accuracy vector whose first \(k\) coordinates equal \(1-\epsilon\) and whose remaining coordinates equal \(1/2\).

Exact selection rule

Because \(R>1\), comparing the distortions is equivalent to comparing \(A\) and \(B\). Therefore return:

  • \(0\) if \(A\le B\);
  • \(1\) if \(A>B\).

When \(A=B\), both reports minimize distortion, so this rule validly returns \(0\). No logarithm, exponential, or approximation needs to be computed.

The algorithm forms each cohort difference \(a_j\), scans its prefix sums, and maintains their minimum and maximum, including the initial value \(S_0=0\).

Bit complexity

Write each supported mass as \(\mu_{j,b}=u_{j,b}/v_{j,b}\), with positive integers \(u_{j,b},v_{j,b}\). Let
\(Q=\prod_{(j,b)\text{ in the support}}v_{j,b}\).

The sum of the denominator encoding lengths is at most \(L\), so \(Q\) has \(O(L)\) bits. Convert every supported mass to the integer
\(W_{j,b}=u_{j,b}(Q/v_{j,b})=Q\mu_{j,b}\), assigning zero to missing types.

These integers are nonnegative and sum to \(Q\). Thus every integer prefix difference
\(T_k=\sum_{j=1}^k(W_{j,1}-W_{j,0})=QS_k\)
lies between \(-Q\) and \(Q\) and has \(O(L)\) bits. Comparing \(\max_k T_k\) and \(-\min_k T_k\) gives exactly the same answer as comparing \(A\) and \(B\), since \(Q>0\).

Using schoolbook integer arithmetic:

  • Forming \(Q\) and converting all supported masses costs \(O(\tau L^2)\) bit operations.
  • If the support is unordered, sorting its records by cohort costs \(O(\tau L\log(\tau+1))\) bit operations, which is \(O(\tau L^2)\).
  • Aggregating cohorts and scanning the integer prefix sums costs \(O((\tau+q)L)\) bit operations.

Therefore the total is \(O((\tau+q)L^2)=O(m(\tau+q)L^2)\) for \(m=2\). Since every cohort is nonempty, \(q\le\tau\le2q\), so \(O(\tau L^2)\) is also a valid bound.

This proof directly establishes the rational-mass cohort result. It is consistent with the prefix-strength characterization for finite ordered binary judgments in [Lemma 1 and Theorem 1 of the supplied paper](https://www.cs.toronto.edu/~nisarg/papers/ranked-binary-judgments.pdf).
