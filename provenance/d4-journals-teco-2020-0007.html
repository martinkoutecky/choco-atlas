The anchor (named result in the paper)

Theorem 1 — class: hardness

The continuous mirror question, as graded

Given rational masses \(\mu_t\) over a finite set of complete agent types \(T\), repeated item classes \(J\) partitioned into blocks \(J_1,\ldots,J_l\), per-capita supplies \(b_j\), utilities \(v_{tj}\), quota-group map \(g:T\to[k]\), quota masses \(\Lambda_{pq}\), and threshold \(U\), decide whether there exist masses \(x_{tj}\ge 0\) satisfying \(\sum_j x_{tj}\le\mu_t\), \(\sum_t x_{tj}\le b_j\), \(\sum_{t:g(t)=p}\sum_{j\in J_q}x_{tj}\le\Lambda_{pq}\), and \(\sum_{t,j}v_{tj}x_{tj}\ge U\), where each unit of agent mass receives one integral item from its class.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) complete types with positive mass, each mass encoded as a binary rational; \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_{t\in T}\mu_t=1\). Each type specifies its quota group and its utility for every item class.
Let \(J\) contain \(m\ge1\) item classes, partitioned into \(l\ge1\) nonempty blocks \(J_1,\ldots,J_l\). Class \(j\) has positive rational per-capita supply \(b_j\). The surjective map \(g:T\to\{1,\ldots,k\}\) specifies the quota groups.
Utilities \(v_{tj}\ge0\), quota masses \(0\le\Lambda_{pq}\le\sum_{j\in J_q}b_j\), and the threshold \(U>0\) are binary rationals. Utilities need not be normalized or constant within a quota group or block. Let \(L\) be the total input bit length.
Each type represents an atomless population. Its mass may be divided among item classes, but every individual receives at most one whole item; individuals and supplies may remain unassigned. The variable \(x_{tj}\) denotes the mass of type \(t\) assigned an item of class \(j\).
The decision problem asks whether there exist real masses \(x_{tj}\ge0\) satisfying \(\sum_{j\in J}x_{tj}\le\mu_t\) for every \(t\), \(\sum_{t\in T}x_{tj}\le b_j\) for every \(j\), \(\sum_{t:g(t)=p}\sum_{j\in J_q}x_{tj}\le\Lambda_{pq}\) for every \(p,q\), and \(\sum_{t\in T}\sum_{j\in J}v_{tj}x_{tj}\ge U\).

Is this continuous assignment decision problem solvable in time polynomial in \(m,\tau,k,l,L\), or is it NP-hard?

The finite-agent version with indivisible items and integer quota caps is NP-complete. It admits polynomial-time algorithms when utilities are constant within each quota group for every item, or within each block for every agent.
These discrete results do not classify the atomless mass problem defined above.

Modeling choices made when packaging the task

  • Normalized total agent mass to one, interpreting supplies and quota masses in the same per-capita units.
  • Interpreted complete types as specifying both the quota group and the entire utility vector; different complete types may share a quota group.
  • Specified atomless populations and allowed splitting type mass among classes while giving each individual at most one whole item.
  • Specified nonnegative rational utilities without utility normalization, nonnegative rational quota masses, and a positive rational threshold, following the discrete domains with binary encoding.
  • Used nonempty blocks, positive-supply item classes, and nonempty quota groups; zero-supply classes and unused group labels can be omitted.
  • Carried over the quota upper bound by replacing block cardinality with total block supply.

Result

The continuous assignment decision problem is polynomial-time solvable in \(m,\tau,k,l,L\). This holds for arbitrary utilities satisfying the stated hypotheses.

1. Exact linear feasibility formulation

Let \(N=\tau m\), and introduce one real variable \(x_{tj}\) for each listed type \(t\in T\) and class \(j\in J\). Construct the following system:

  • \(-x_{tj}\le 0\) for every \(t,j\).
  • \(\sum_{j\in J}x_{tj}\le\mu_t\) for every \(t\).
  • \(\sum_{t\in T}x_{tj}\le b_j\) for every \(j\).
  • \(\sum_{t:g(t)=p}\sum_{j\in J_q}x_{tj}\le\Lambda_{pq}\) for every \(p,q\).
  • \(-\sum_{t\in T}\sum_{j\in J}v_{tj}x_{tj}\le -U\).

These are linear inequalities with rational coefficients. Their number is

\(r=N+\tau+m+kl+1.\)

This system is feasible if and only if the input society admits the requested assignment: its inequalities are precisely the constraints in the question, with nonnegativity and the utility threshold rewritten using the same inequality direction.

There is also no additional indivisibility condition hidden in this formulation. By the stated atomless divisibility premise, for each type \(t\), masses \(x_{tj}\) with \(\sum_jx_{tj}\le\mu_t\) can be assigned to disjoint subpopulations, one for each class. Each assigned individual receives one whole item; the residual population remains unassigned. The supply and quota inequalities impose the remaining restrictions.

2. Polynomial encoding size

Every coefficient of the system is \(0\), \(1\), \(-1\), or \(-v_{tj}\). Every right-hand side is \(0\), \(\mu_t\), \(b_j\), \(\Lambda_{pq}\), or \(-U\).

Thus the input rationals can be copied directly, with sign changes where necessary. Even a dense encoding of the resulting matrix and right-hand side has bit length

\(B=O\!\left(L+r(N+1)\right).\)

To verify that this is polynomial, surjectivity of \(g\) gives \(k\le\tau\), and nonemptiness of every block gives \(l\le m\). Consequently, \(kl\le N\). Also, since \(\tau,m\ge1\), we have \(\tau+m\le2N\). Hence

\(r\le4N+1,\qquad B=O(L+N^2).\)

Crucially, all \(\tau m\) utility entries are explicitly listed in the input, so \(N=O(L)\). Therefore the linear system has encoding length polynomial in \(L\), and it can be constructed in polynomial time. No enumeration of unlisted possible types is required.

3. Exact polynomial-time decision

We apply the standard polynomial-time linear feasibility theorem: given a rational matrix \(A\) and rational vector \(d\), feasibility of \(Ax\le d\) over the real numbers can be decided in deterministic time polynomial in the binary encoding length of \(A,d\). This is the rational-data form of [Khachiyan’s theorem](https://www.mathnet.ru/eng/dan42319).

All its hypotheses hold here: the system is finite, explicitly constructed, linear, and rational, with polynomial encoding length. The theorem decides exact feasibility, including cases where feasible points lie on constraint boundaries. In particular, equality with the utility threshold causes no approximation issue.

Applying this algorithm to the constructed system therefore decides the assignment problem in polynomial time.

4. Relation to the discrete problem

The finite-agent problem imposes integer assignment variables. The present problem permits real assignment masses, so rational linear feasibility applies without any integrality requirement. The stated discrete hardness therefore does not transfer to this atomless model.

The continuous problem belongs to \(\mathrm{P}\); under polynomial-time many-one reductions, it could be NP-hard only if \(\mathrm{P}=\mathrm{NP}\).
