The continuous mirror question, as graded

Given rational distributions \(\mu\) and \(\nu\) over finite supports of Boolean types \(t=(a_t,\alpha_t)\in\{0,1\}^d\times\{0,1\}^d\) and \(s=(a_s,\alpha_s)\in\{0,1\}^d\times\{0,1\}^d\), output a stable coupling \(x\). The coupling must satisfy \(\sum_s x_{t,s}=\mu_t\) and \(\sum_t x_{t,s}=\nu_s\); stability means there are no \(t,s,t',s'\) with \(x_{t,s'}>0\), \(x_{t',s}>0\), \(\alpha_t\cdot a_s>\alpha_t\cdot a_{s'}\), and \(\alpha_s\cdot a_t>\alpha_s\cdot a_{t'}\).

Packaged proof task (what the prover saw — nothing else)

Two societies have nonempty supports \(T,S\) of Boolean types \(p=(a_p,\alpha_p)\in\{0,1\}^{m}\times\{0,1\}^{m}\), where \(m=d\geq1\). Every opposite-side type is acceptable; type \(p\) values type \(q\) by \(\alpha_p\cdot a_q\), with larger values preferred and equal values tied.
Each society is given by its support: the list of types with positive mass, each mass a binary rational. The distributions satisfy \(\sum_{t\in T}\mu_t=\sum_{s\in S}\nu_s=1\). Let \(\tau=|T|+|S|\) be the total support size, counting types separately on the two sides, not the number of possible Boolean types; let \(L\) be the total input bit length.
Output a rational coupling \(x\geq0\) satisfying \(\sum_s x_{t,s}=\mu_t\) and \(\sum_t x_{t,s}=\nu_s\).
The coupling is weakly stable if there are no \(t,t'\in T\), \(s,s'\in S\) with \(x_{t,s'}>0\), \(x_{t',s}>0\), \(\alpha_t\cdot a_s>\alpha_t\cdot a_{s'}\), and \(\alpha_s\cdot a_t>\alpha_s\cdot a_{t'}\). Mass is divisible, and stability uses these strict comparisons without resolving ties.

Is finding such a stable coupling solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,L\).

For finite societies with \(n\) agents on each side, finding a weakly stable matching is polynomial-time solvable, but assuming SETH, for every \(\varepsilon>0\) there is a \(c\) for which Boolean dimension \(d=c\log n\) requires time \(\Omega(n^{2-\varepsilon})\).
For divisible allocations with explicitly listed strict preferences and vertex and edge capacities, Dean and Munshi give an \(O(E\log V)\) algorithm, where \(E,V\) count edges and vertices; their stated model permits nonintegral data but excludes ties ([source](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf)).

Modeling choices made when packaging the task

  • Normalized each society's total mass to 1, following the question's use of distributions and preserving equal total mass on the two sides.
  • Required nonnegative rational output entries, making the coupling and its finite output encoding explicit.
  • Used complete acceptability and weak stability with unresolved ties, consistent with the discrete definitions.
  • Identified m with the attribute dimension d, defined tau as the sum of the two support sizes, and defined L as total input bit length.
  • Allowed arbitrary positive support sizes and arbitrary dimension m at least 1; the discrete relation d=c log n belongs to the lower bound, not to the continuous input domain.

Result

Finding a weakly stable coupling is polynomial-time solvable. Arbitrarily refining the ties and applying a strict stable-allocation algorithm is valid, provided that we check edge capacities and full allocation.

Writing \(E=|T||S|\), the algorithm uses
\[ O\!\left(mE+E\log\tau\right) \]
arithmetic and comparison operations after reading the input. Thus its bound in the requested parameters is
\[ O\!\left(m\tau^2+\tau^2\log\tau\right). \]
A conservative exact implementation has bit complexity
\[ O\!\left(L^3+m\tau^2\log(m+1)+\tau^3L\right). \]
The distinction between arithmetic operations and bit operations matters because the masses are binary rationals.

1. Strictly refine the preferences

Enumerate the supports as \(T=\{t_1,\ldots,t_k\}\) and \(S=\{s_1,\ldots,s_\ell\}\), so \(\tau=k+\ell\).

For each \(t\in T\), order \(S\) by decreasing \(\alpha_t\cdot a_s\), breaking equal values by the enumeration of \(S\). Likewise, each \(s\in S\) orders \(T\) by decreasing \(\alpha_s\cdot a_t\), breaking ties by the enumeration of \(T\).

Denote these strict orders by \(\succ_t\) and \(\succ_s\). Their essential property is
\[ \alpha_t\cdot a_s>\alpha_t\cdot a_{s'} \quad\Longrightarrow\quad s\succ_t s', \]
and analogously on the other side.

Computing both directional scores for every pair takes \(O(mE)\) arithmetic operations. Sorting all preference lists takes
\[ O(k\ell\log\ell+\ell k\log k)=O(E\log\tau) \]
comparisons.

These refined preferences are internal to the algorithm; the required output will satisfy the original definition using strict score comparisons.

2. Construct a strict stable-allocation instance

Give each real vertex its prescribed quota:
\[ b(t)=\mu_t,\qquad b(s)=\nu_s. \]
Include every real edge \((t,s)\), with capacity
\[ u(t,s)=\min\{\mu_t,\nu_s\}. \]

Add a dummy vertex \(t_0\) on the \(T\) side and a dummy vertex \(s_0\) on the \(S\) side, both with quota \(1\). Add edges with capacities
\[ u(t,s_0)=\mu_t,\qquad u(t_0,s)=\nu_s,\qquad u(t_0,s_0)=1. \]

Each real vertex ranks its dummy partner last. Each dummy ranks all real vertices in an arbitrary strict order, followed by the other dummy.

The augmented instance has
\[ V=\tau+2,\qquad E'=E+\tau+1. \]
Since both supports are nonempty,
\[ \tau=k+\ell\leq k\ell+1=E+1, \]
so \(E'=O(E)\).

For this capacitated instance, an edge \((i,j)\) blocks an allocation \(y\) precisely when:

  • \(y_{i,j}<u(i,j)\);
  • \(i\) has positive allocation to a partner strictly below \(j\);
  • \(j\) has positive allocation to a partner strictly below \(i\).

The instance is feasible: assign \(y_{t,s}=\mu_t\nu_s\), assign \(y_{t_0,s_0}=1\), and assign zero to all remaining edges. Indeed, \(\mu_t\nu_s\leq\min\{\mu_t,\nu_s\}\), and all quota equalities hold.

We now invoke the strict bipartite stable-allocation theorem: with strict preference lists and vertex and edge capacities, a stable allocation can be computed in \(O(E'\log V)\) arithmetic operations, including for nonintegral data. Its straightforward augmentation implementation takes \(O(E'V)\) operations. The augmentation amounts are selected through minima of residual quantities, and allocations are updated by addition and subtraction. These are the results and operations established in [Dean and Munshi, Sections 2–3](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf).

All hypotheses hold: our graph is bipartite, all lists are strict, all capacities and quotas are positive rationals, and the dummy construction gives the required feasible instance.

Let \(y\) be the resulting stable allocation.

3. Prove that every real quota is filled by real partners

Define the total allocation between real vertices by
\[ z=\sum_{t\in T}\sum_{s\in S}y_{t,s}. \]
The real quotas on either side sum to \(1\). Consequently,
\[ \sum_{t\in T}y_{t,s_0}=1-z, \qquad \sum_{s\in S}y_{t_0,s}=1-z. \]

Suppose \(z<1\). Then some \(t\in T\) and \(s\in S\) satisfy
\[ y_{t,s_0}>0,\qquad y_{t_0,s}>0. \]
The quota equalities imply
\[ y_{t,s}\leq\mu_t-y_{t,s_0}<\mu_t, \qquad y_{t,s}\leq\nu_s-y_{t_0,s}<\nu_s. \]
Hence
\[ y_{t,s}<\min\{\mu_t,\nu_s\}=u(t,s). \]

Moreover, \(t\) strictly prefers \(s\) to \(s_0\), and \(s\) strictly prefers \(t\) to \(t_0\). Thus \((t,s)\) blocks \(y\), contradicting its stability.

Therefore \(z=1\). Both sums of real-to-dummy allocations are zero; nonnegativity makes every such allocation zero individually.

It follows that the restriction
\[ x_{t,s}=y_{t,s},\qquad t\in T,\ s\in S, \]
satisfies exactly
\[ \sum_{s\in S}x_{t,s}=\mu_t,\qquad \sum_{t\in T}x_{t,s}=\nu_s. \]

4. Prove weak stability under the original preferences

Suppose, toward a contradiction, that \(x\) is blocked in the sense of the question. Then there exist \(t,t'\in T\) and \(s,s'\in S\) with
\[ x_{t,s'}>0,\qquad x_{t',s}>0, \]
and
\[ \alpha_t\cdot a_s>\alpha_t\cdot a_{s'}, \qquad \alpha_s\cdot a_t>\alpha_s\cdot a_{t'}. \]

The strict inequalities imply \(s'\neq s\) and \(t'\neq t\). Using the marginal equalities,
\[ x_{t,s}\leq\mu_t-x_{t,s'}<\mu_t, \qquad x_{t,s}\leq\nu_s-x_{t',s}<\nu_s. \]
Thus the edge is unsaturated:
\[ y_{t,s}=x_{t,s}<u(t,s). \]

The refinement preserves both strict score improvements, so
\[ s\succ_t s',\qquad t\succ_s t'. \]
The two positive allocations therefore witness a blocking edge \((t,s)\) in the augmented strict instance. This contradicts stability of \(y\).

Hence \(x\) is weakly stable according to the exact definition in the question.

5. Rational output and bit complexity

Write each input mass as \(a_i/b_i\), with positive integers encoded in binary. This also covers the special case of dyadic masses. Set
\[ Q=\prod_i b_i. \]
The binary length of \(Q\) is \(O(L)\), because the sum of the input denominator lengths is at most \(L\).

Scale every quota and capacity by \(Q\). All are now integers between \(0\) and \(Q\). This scaling preserves feasibility and stability: it preserves positive allocations and whether an edge is saturated.

Run the augmentation algorithm on the scaled instance. Starting from integer data, every residual quantity is integral. Each augmentation amount is a minimum of integral residual quantities, and each update adds or subtracts that amount. Inductively, all allocations remain integral.

Let its real-edge output be \(X_{t,s}\). Return
\[ x_{t,s}=\frac{X_{t,s}}{Q}. \]
Since \(0\leq X_{t,s}\leq Q\), every returned rational has \(O(L)\) bits. The entire dense output has \(O(EL)\) bits.

For an explicit, conservative bit bound, use the straightforward augmentation implementation:

  • Computing \(Q\) and the scaled masses by schoolbook integer arithmetic costs \(O(L^3)\) bit operations.
  • Computing the Boolean scores costs \(O(mE\log(m+1))\) bit operations.
  • Sorting costs \(O(E\log\tau)\) comparisons on keys of \(O(L)\) bits.
  • The augmentation implementation performs \(O(E'V)=O(E\tau)\) operations on explicit integer allocations, residuals, and quota sums of \(O(L)\) bits. These additions, subtractions, and comparisons cost \(O(L)\) each.

Because \(\log\tau\leq\tau\), the resulting bound is
\[ O\!\left(L^3+mE\log(m+1)+E\tau L\right) \subseteq O\!\left(L^3+m\tau^2\log(m+1)+\tau^3L\right). \]

Separately, the faster implementation gives the arithmetic-operation bound
\[ O(mE+E\log\tau) \subseteq O(m\tau^2+\tau^2\log\tau). \]

6. Relation to the stated finite-population bound

For finite populations with \(n\) agents on each side, \(\tau\leq2n\). When \(\tau=\Theta(n)\) and \(m=\Theta(\log n)\), the arithmetic upper bound above is \(O(n^2\log n)\), so it does not conflict with the stated SETH barrier against truly subquadratic algorithms.

When many agents share types, the support size can be substantially smaller than the population size. The algorithm works directly on those supports and binary masses; it never expands rational mass into individual agents or enumerates all possible Boolean types.
