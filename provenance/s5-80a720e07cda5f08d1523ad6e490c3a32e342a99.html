Result

The continuous profit-threshold problem is in \(\mathrm{P}\). An exact algorithm uses \(\mathrm{O}(\tau^2)\) rational arithmetic operations. A conservative bound with elementary integer arithmetic is \(\mathrm{O}(\tau^4L^2)\) bit operations, including the comparison with \(B\).

The proof first excludes positive profit from serving only one user type, then reduces the remaining optimization to a piecewise-linear function of one variable.

1. Computing payments and excluding single-type profit

Define the nonnegative coefficients \(v_{it}=\lambda_i a_{it}\), the total willingness to pay \(U_i(x)=\sum_t v_{it}x_t\), and the admission cost \(C(x)=\sum_t r_tx_t\).

For every supported creator type,
\[ r_t=\max\{\min(v_{1t},v_{2t}),q_1v_{1t},q_2v_{2t}\}. \]
Here and below, the displayed formula is understood as \(r_t=\max\{\min(v_{1t},v_{2t}),q_1v_{1t},q_2v_{2t}\}\).

To verify it, suppose first that \(v_{1t}<v_{2t}\). For \(0\le u\le v_{1t}\), both user types pay, so the revenue is \(u(q_1+q_2)=u\). Its maximum on this interval is \(v_{1t}\). For \(v_{1t}<u\le v_{2t}\), only type \(2\) pays, and the maximum is \(q_2v_{2t}\). Above \(v_{2t}\), revenue is zero. Consequently \(r_t=\max\{v_{1t},q_2v_{2t}\}\); the additional candidate \(q_1v_{1t}\) cannot exceed \(v_{1t}\). The reverse ordering is symmetric. If the two values are equal, their common value is the maximum revenue. This also covers zero values.

In particular, \(r_t\ge q_iv_{it}\) for each \(i\). Therefore, if exactly user type \(i\) subscribes, then \(z\le U_i(x)\) and
\(q_i z-C(x)\le q_iU_i(x)-C(x)=\sum_t(q_iv_{it}-r_t)x_t\le0\).

If neither type subscribes, profit is \(-C(x)\le0\). Closing yields zero. Thus positive profit requires both types to subscribe.

2. Exact reduction to both types subscribing

Let \(X=\prod_{t=1}^{\tau}[0,\mu_t]\), and define
\(M=\max_{x\in X}\{\min(U_1(x),U_2(x))-C(x)\}\).

This maximum exists because \(X\) is compact and the objective is continuous. Also, \(M\ge0\), by taking \(x=0\).

For any \(x\in X\), choose \(z=\min(U_1(x),U_2(x))\). Both user types subscribe, including any indifferent type. Since \(q_1+q_2=1\), profit equals \(\min(U_1(x),U_2(x))-C(x)\). Hence \(M\) is attainable in the original problem.

Conversely, whenever both types subscribe, \(z\le\min(U_1(x),U_2(x))\), so profit is at most \(M\). All other subscribing sets yield profit at most zero, hence at most \(M\).

Therefore the original maximum profit equals \(M\). Equivalently, it is the value of the linear program
\( \max\{z-\sum_t r_tx_t:0\le x_t\le\mu_t,\ 0\le z\le\sum_t v_{1t}x_t,\ z\le\sum_t v_{2t}x_t\} \).

This already establishes polynomial-time solvability by rational linear programming. The following direct algorithm gives an explicit running-time bound.

3. A one-variable formula for the optimum

For \(p\in[0,1]\), define
\(F(p)=\sum_{t=1}^{\tau}\mu_t\max\{0,pv_{1t}+(1-p)v_{2t}-r_t\}\).

We prove \(M=\min_{p\in[0,1]}F(p)\).

Upper bound

For any \(x\in X\) and \(p\in[0,1]\),
\(\min(U_1(x),U_2(x))-C(x)\le pU_1(x)+(1-p)U_2(x)-C(x)\).

The expression on the right is
\(\sum_t[pv_{1t}+(1-p)v_{2t}-r_t]x_t\).
Maximizing each term independently over \(0\le x_t\le\mu_t\) gives \(F(p)\). Thus \(M\le F(p)\) for every \(p\), and consequently \(M\le\min_pF(p)\).

Attainment of the bound

Because \(F\) is continuous, it has a minimizer \(p^*\in[0,1]\). Write
\(d_t=v_{1t}-v_{2t}\) and \(h_t=v_{2t}-r_t+p^*d_t\).

The maximizers over \(X\) of \(\sum_t h_tx_t\) have the following coordinates:

  • If \(h_t>0\), then \(x_t=\mu_t\).
  • If \(h_t<0\), then \(x_t=0\).
  • If \(h_t=0\), any \(x_t\in[0,\mu_t]\) is allowed.

Among these maximizers, the smallest and largest possible values of
\(D(x)=U_1(x)-U_2(x)=\sum_t d_tx_t\)
are respectively
\(D_{\min}=\sum_{h_t>0}\mu_td_t+\sum_{h_t=0,\ d_t<0}\mu_td_t\)
and
\(D_{\max}=\sum_{h_t>0}\mu_td_t+\sum_{h_t=0,\ d_t>0}\mu_td_t\).

Every value between these endpoints is attainable: take a convex combination of maximizers attaining the two endpoints. The combination remains a maximizer, and \(D\) is linear.

The left derivative of \(F\) at \(p^*\), when defined within the domain, is \(D_{\min}\); its right derivative is \(D_{\max}\). Indeed, a term with \(h_t>0\) contributes slope \(\mu_td_t\), a term with \(h_t<0\) contributes zero, and a term with \(h_t=0\) contributes left slope \(\mu_t\min(0,d_t)\) and right slope \(\mu_t\max(0,d_t)\).

There are three cases.

  • If \(0<p^*<1\): Minimality implies \(D_{\min}\le0\le D_{\max}\). Choose a maximizing \(x\) with \(D(x)=0\). Then \(U_1(x)=U_2(x)\), and

\(F(p^*)=p^*U_1(x)+(1-p^*)U_2(x)-C(x)=\min(U_1(x),U_2(x))-C(x)\le M\).

  • If \(p^*=0\): Minimality implies the right derivative \(D_{\max}\ge0\). Choose a maximizing \(x\) attaining \(D_{\max}\). Then \(U_1(x)\ge U_2(x)\), so

\(F(0)=U_2(x)-C(x)=\min(U_1(x),U_2(x))-C(x)\le M\).

  • If \(p^*=1\): Minimality implies the left derivative \(D_{\min}\le0\). Choose a maximizing \(x\) attaining \(D_{\min}\). Then \(U_1(x)\le U_2(x)\), so

\(F(1)=U_1(x)-C(x)=\min(U_1(x),U_2(x))-C(x)\le M\).

Together with the upper bound, this proves the claimed equality, including boundary and indifference cases.

4. Exact algorithm and bit complexity

Each summand of \(F\) is the maximum of zero and an affine function. Its only possible breakpoint occurs, when \(v_{1t}\ne v_{2t}\), at
\(p_t=(r_t-v_{2t})/(v_{1t}-v_{2t})\).

Form the candidate set
\(\mathcal P=\{0,1\}\cup\{p_t:v_{1t}\ne v_{2t},\ 0\le p_t\le1\}\).

It contains at most \(\tau+2\) points. Between consecutive candidate points, every summand, and hence \(F\), is affine. An affine function on a closed interval attains its minimum at an endpoint; if constant, both endpoints attain it. Therefore
\(M=\min_{p\in\mathcal P}F(p)\).

The decision algorithm is:

  • Compute \(v_{it}\) and \(r_t\).
  • Construct \(\mathcal P\).
  • Evaluate \(F\) exactly at every candidate and retain the smallest value \(M\).
  • Return yes precisely when \(M\ge B\).

Sorting is unnecessary. Constructing the candidates takes \(\mathrm{O}(\tau)\) rational operations, and their evaluations take \(\mathrm{O}(\tau^2)\).

For the bit bound, every coefficient and candidate is formed using a fixed number of arithmetic operations on input rationals, so each has \(\mathrm{O}(L)\) bits. Each summand evaluated at a candidate likewise has \(\mathrm{O}(L)\) bits. Adding at most \(\tau\) such fractions, even without reduction, produces numerators and denominators of \(\mathrm{O}(\tau L)\) bits: their lengths grow at most additively with each summand’s encoding length.

Thus all arithmetic and comparisons can use integers of \(\mathrm{O}(\tau L)\) bits. Elementary multiplication and cross-multiplication cost \(\mathrm{O}((\tau L)^2)\) bit operations each. Across \(\mathrm{O}(\tau^2)\) rational operations, this gives the conservative bound \(\mathrm{O}(\tau^4L^2)\). The final comparison includes \(B\), whose encoding is part of \(L\).

The algorithm uses only the listed support and its masses; it requires no finite creator-count parameter \(m\). The [supplied paper](https://pubsonline.informs.org/doi/abs/10.1287/mnsc.2022.4307) reports portfolio-selection hardness and approximation results, but those do not obstruct the exact continuous optimization proved here.
