The continuous mirror question, as graded

Given a finite component repository \(E\), compatibility constraints, a Boolean goal model \(R\), optional traits \(O\), and a nonempty feasible design set \(\mathcal D=\{C\subseteq E: C\text{ is compatible and its composition satisfies }R\}\), suppose each type \(t\) has a CI-net preference relation \(\succ_t\) over subsets of \(O\), with rational mass \(\mu_t\ge 0\) and \(\sum_t\mu_t=1\). Let \(\gamma(C)\subseteq O\) be the optional traits achieved by design \(C\), and let \(\operatorname{Top}_t=\{C\in\mathcal D:\nexists C'\in\mathcal D,\ \gamma(C')\succ_t\gamma(C)\}\). Find a design \(C\in\mathcal D\) maximizing \(\sum_{t:C\in\operatorname{Top}_t}\mu_t\).

Packaged proof task (what the prover saw — nothing else)

Let \(E\) be a finite component repository, \(n=|E|\), and \(O\) a set of optional traits, \(m=|O|\). A design is a nonempty subset \(C\subseteq E\), encoded by its incidence vector.
Compatibility is specified by a Boolean circuit on that vector. The requirement \(R\) is a rooted AND–OR DAG with nonempty child sets; each leaf's satisfaction is specified by a Boolean circuit on the design vector, and internal nodes evaluate their indicated operators.
Optional traits have MAKE and BREAK links from requirement nodes: a trait is achieved exactly when at least one satisfied node has a MAKE link to it and no satisfied node has a BREAK link to it. Write \(\gamma(C)\subseteq O\) for the achieved traits.
Promise that \(\mathcal D=\{C\subseteq E:C\ne\varnothing,\ C\text{ is compatible and satisfies the root of }R\}\ne\varnothing\); this set is implicit, not enumerated in the input.
A society is given by its support: the list of its \(\tau\) types with positive masses \(\mu_t\) encoded as binary rationals, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies a consistent CI-net: a finite list of statements \((S^+,S^-,A,B)\) of pairwise disjoint subsets of \(O\). Its strict relation \(\succ_t\) is the transitive closure of proper-superset preference and all comparisons \(Z\cup S^+\cup A\succ_t Z\cup S^+\cup B\), where \(Z\subseteq O\setminus(S^+\cup S^-\cup A\cup B)\); consistency means this closure is irreflexive.
Define \(\operatorname{Top}_t=\{C\in\mathcal D:\nexists C'\in\mathcal D,\ \gamma(C')\succ_t\gamma(C)\}\) and \(F(C)=\sum_{t:C\in\operatorname{Top}_t}\mu_t\). Incomparable maximal outcomes all qualify, and any maximizing design may be returned.
Is exact maximization of \(F(C)\) over \(C\in\mathcal D\) polynomial-time solvable or NP-hard? State running times in \(m,n,\tau,L\), where \(L\) is the total binary input length, including the circuits, goal graph, links, CI-nets, and masses.
The single-stakeholder discrete algorithm is sound and complete for returning a nondominated satisfying goal assignment, or detecting that none exists; this establishes correctness rather than a polynomial-time bound.
Dominance testing for consistent CI-nets is PSPACE-complete ([Bouveret–Endriss–Lang](https://www.ijcai.org/Proceedings/09/Papers/022.pdf)). No result settling this exact mass-weighted maximization problem was identified in the search.

Modeling choices made when packaging the task

  • The representation of compatibility and composition-dependent satisfaction was unspecified; use explicitly supplied Boolean circuits on component-selection vectors, allowing interactions between components.
  • Represent the Boolean requirement by a rooted AND–OR DAG with nonempty child sets, following the requirement decomposition and excluding empty requirements.
  • Define optional-trait achievement using MAKE/BREAK links: at least one positive contribution and no negative contribution from satisfied requirement nodes.
  • Require nonempty designs, following the intended composition of one or more components.
  • Promise consistent CI-nets and use their smallest induced strict preference relations, rather than arbitrary extensions of the stated preferences.
  • Treat the feasible design set as implicit in the supplied model, rather than an explicitly enumerated input.
  • Omit zero-mass types from the support, retain total mass one, and allow any maximizing design without additional tie-breaking.

Result

Exact maximization is \(\mathrm{NP}\)-hard. More strongly, returning any maximizing design is \(\mathrm{PSPACE}\)-hard, even with \(n=2\), \(\tau=2\), exactly two feasible designs, and no BREAK links.

The associated decision problem, “is \(\max_{C\in\mathcal D}F(C)\geq q\)?”, is \(\mathrm{PSPACE}\)-complete. Thus a polynomial-time exact optimizer would imply \(\mathrm{P}=\mathrm{PSPACE}\).

The proofs below respect both promises: feasibility is nonempty, and every supplied CI-net is consistent.

1. Dominance instances used in the reduction

For a consistent CI-net \(N\), write \(X\succ_N Y\) for its induced strict relation. We use the established theorem that deciding this relation is \(\mathrm{PSPACE}\)-complete for consistent CI-nets. Its consistency hypothesis is exactly the promise in the present task. See Proposition 6 of [Bouveret–Endriss–Lang](https://www.ijcai.org/Proceedings/09/Papers/022.pdf).

We may restrict the source problem to pairs \(X,Y\subseteq O\) that are incomparable under inclusion. Here is a precise justification.

  • If \(X\supsetneq Y\), then \(X\succ_N Y\) by proper-superset preference.
  • If \(Y\supsetneq X\), then \(Y\succ_N X\); consistency forbids \(X\succ_N Y\).
  • If \(X=Y\), consistency again forbids \(X\succ_N Y\).

These cases are decidable in polynomial time. To reduce unrestricted dominance to dominance on incomparable pairs, retain each incomparable instance and replace each remaining instance by a fixed incomparable instance with the computed answer. Suitable fixed instances use \(X=\{a\}\), \(Y=\{b\}\): the net containing \((\varnothing,\varnothing,\{a\},\{b\})\) gives a yes-instance, and the empty net gives a no-instance. Both are consistent.

Consequently, dominance on incomparable pairs remains \(\mathrm{PSPACE}\)-complete.

2. A consistent net preferring the second outcome

Fix a source instance consisting of a consistent CI-net \(N\) and inclusion-incomparable bundles \(X,Y\subseteq O\). Put \(k=|O|\).

Construct a second CI-net \(N_Y\) containing the single statement

\[ \bigl(X\cap Y,\ O\setminus(X\cup Y),\ Y\setminus X,\ X\setminus Y\bigr). \]

The four sets are pairwise disjoint and together exhaust \(O\). Therefore the only permitted context is \(Z=\varnothing\), and this statement gives exactly the generating comparison \(Y\succ_{N_Y}X\).

To verify consistency, assign each trait a positive weight:

\[ w(o)= \begin{cases} k+1,&o\in Y\setminus X,\\ 1,&o\notin Y\setminus X. \end{cases} \qquad U(W)=\sum_{o\in W}w(o). \]

Every proper-superset comparison strictly increases \(U\). The additional comparison also does, since

\[ U(Y)-U(X) =(k+1)|Y\setminus X|-|X\setminus Y| \geq (k+1)-k =1. \]

Here \(Y\setminus X\neq\varnothing\) follows from inclusion-incomparability. Every generating comparison, and hence every comparison in the transitive closure, strictly increases \(U\). An irreflexive closure follows. Thus \(N_Y\) is consistent.

3. Realizing exactly two feasible designs

Take the repository \(E=\{e_X,e_Y\}\). Let its design coordinates be \(x_X,x_Y\), and let compatibility require exactly one coordinate to be true. The feasible designs will be

\[ C_X=\{e_X\}, \qquad C_Y=\{e_Y\}. \]

Construct the requirement as an OR root with a constant-true leaf and one leaf \(\ell_o\) for each \(o\in O\). The leaf circuit for \(\ell_o\) computes

\[ \bigl(x_X\land\mathbf 1_{o\in X}\bigr) \lor \bigl(x_Y\land\mathbf 1_{o\in Y}\bigr), \]

where each membership indicator is a circuit constant. Give \(\ell_o\) a MAKE link to \(o\), and include no other trait links.

The constant-true leaf ensures that the root is satisfied. Compatibility excludes the other design vectors. Therefore

\[ \mathcal D=\{C_X,C_Y\}, \qquad \gamma(C_X)=X, \qquad \gamma(C_Y)=Y. \]

In particular, the feasibility promise holds independently of the dominance answer. This construction has polynomial input length and uses \(n=2\).

4. The unique optimizer decides dominance

Use two society types:

  • Type \(1\) has CI-net \(N\) and mass \(\mu_1=3/4\).
  • Type \(2\) has CI-net \(N_Y\) and mass \(\mu_2=1/4\).

Both masses are positive binary rationals and sum to one. Type \(2\) has the unique top design \(C_Y\), because \(Y\succ_{N_Y}X\) and consistency forbids the reverse comparison.

There are two cases.

Case A: \(X\succ_N Y\)

Consistency implies \(Y\not\succ_N X\). Since there are only two feasible outcomes, type \(1\) has the unique top design \(C_X\). Hence

\[ F(C_X)=3/4, \qquad F(C_Y)=1/4. \]

The unique maximizing design is \(C_X\).

Case B: \(X\not\succ_N Y\)

The only other feasible outcome does not dominate \(Y\), so \(C_Y\in\operatorname{Top}_1\). Thus

\[ F(C_Y)=1. \]

Design \(C_X\) receives no mass from type \(2\), so \(F(C_X)\leq 3/4\). The unique maximizing design is \(C_Y\). This argument includes both possibilities: \(Y\succ_N X\), and incomparability between \(X\) and \(Y\).

We have proved

\[ \text{optimizer returns }C_X \quad\Longleftrightarrow\quad X\succ_N Y. \]

A polynomial-time exact optimizer would therefore decide consistent CI-net dominance in polynomial time. This proves \(\mathrm{PSPACE}\)-hardness of returning a maximizing design.

The same construction gives

\[ \max_{C\in\mathcal D}F(C)= \begin{cases} 3/4,&X\succ_N Y,\\ 1,&X\not\succ_N Y. \end{cases} \]

With threshold \(q=7/8\), the decision answer is yes exactly for non-dominance. Deterministic polynomial space is closed under complement, so non-dominance is also \(\mathrm{PSPACE}\)-complete. The threshold problem is consequently \(\mathrm{PSPACE}\)-hard.

5. Exact running-time bounds

Let

\[ \Gamma=\{\gamma(C):C\in\mathcal D\}, \qquad r=|\Gamma| \leq\min\{2^n-1,2^m\}. \]

Designs achieving the same bundle have identical top-membership for every type, and hence identical scores. It is therefore sufficient to keep one representative design per bundle in \(\Gamma\).

An explicit enumeration algorithm

First enumerate the nonempty design vectors, evaluate compatibility and the requirement circuits, and record the achieved bundles of feasible designs. This takes

\[ 2^n\operatorname{poly}(n,m,L) \]

time.

For each type, construct a directed graph on all \(2^m\) bundles, orienting edges from preferred to less preferred bundles:

  • Include edges deleting one trait. Their transitive closure gives every proper-superset comparison.
  • For every CI statement, include its comparison for every permitted context \(Z\).

If type \(t\) has \(s_t\) statements, the graph has at most \((m+s_t)2^m\) edges. Reachability is exactly the specified strict relation.

For each source bundle in \(\Gamma\), traverse this graph and mark every other reachable bundle in \(\Gamma\) as dominated. A bundle qualifies for that type precisely when it remains unmarked.

These traversals must use all \(2^m\) bundles: the definition permits preference paths whose intermediate bundles are not achieved by feasible designs.

Finally, sum the masses of qualifying types for each bundle and return a representative with maximum score. Exact rational arithmetic takes polynomial time per operation: a common denominator formed from the input denominators has bit length at most their total encoded bit length, bounded by \(L\).

For a fixed polynomial \(p\), the resulting running time is bounded by

\[ O\!\left( p(n,m,\tau,L) \left[ 2^n+\tau\,2^m\min\{2^n,2^m\} \right] \right). \]

A simpler bound is

\[ O\!\left( p(n,m,\tau,L)[2^n+\tau\,4^m] \right). \]

This algorithm is sound and complete; its running time is exponential.

A polynomial-space algorithm

Dominance can also be checked without storing its exponential graph. Adjacency is computable in polynomial time from two bundle vectors. Recursive reachability uses a midpoint bundle and halves the allowed path length at each recursive level. Since a reachable pair has a simple path of length at most \(2^m-1\), recursion depth \(O(m)\) suffices.

Enumerating every possible midpoint at each level gives dominance-testing time

\[ 2^{O(m^2)}\operatorname{poly}(m,L) \]

and polynomial space.

Now enumerate candidate designs sequentially. For each candidate and type, enumerate every feasible competing design and test whether its outcome dominates the candidate’s outcome. Compute the score exactly and retain the best design and score seen so far. All counters, bundles, rational accumulators, and recursive reachability data require polynomial space.

A time bound for this version is

\[ \tau\,4^n\,2^{O(m^2)}\operatorname{poly}(n,m,L). \]

It proves that exact maximization is computable in polynomial space. Comparing the computed optimum with an input rational threshold also uses polynomial space, including the threshold’s encoding in the input length. Combined with Section 4, this establishes \(\mathrm{PSPACE}\)-completeness of threshold decision.

6. Hardness already present with one type

There is also a simpler, independent obstruction to polynomial-time optimization, even when \(m=1\), \(\tau=1\), and the CI-net is empty.

Given a Boolean formula \(\varphi\) on \(k\) variables, take \(k\) assignment components and one mandatory component \(e_0\). Compatibility requires \(e_0\), and the requirement root is always satisfied. Thus every assignment gives a nonempty feasible design.

Use one optional trait \(o\), achieved exactly when the assignment satisfies \(\varphi\). This is realized by a leaf computing \(\varphi\) with a MAKE link to \(o\), alongside a constant-true leaf under an OR root.

The empty CI-net is consistent and prefers \(\{o\}\) to \(\varnothing\) by proper-superset preference.

If \(\varphi\) is satisfiable, every maximizing design must encode a satisfying assignment: all designs achieving \(\varnothing\) are dominated by a feasible design achieving \(\{o\}\). If \(\varphi\) is unsatisfiable, every feasible design achieves \(\varnothing\). Evaluating \(\varphi\) on any returned optimizer therefore decides satisfiability.

This proves \(\mathrm{NP}\)-hardness of returning an optimizer with \(n=k+1\), \(m=1\), and \(\tau=1\). In this construction the optimum score is always \(1\), so this particular reduction does not establish hardness of computing the optimum value.

Accordingly, soundness and completeness of a single-stakeholder algorithm do not imply a polynomial-time bound, even when dominance itself is trivial.
