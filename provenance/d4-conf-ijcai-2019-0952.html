The continuous mirror question, as graded

Given \(m\) candidates and an explicit rational distribution \(\mu\) over complete rankings, promised to equal the uniform distribution \(U(T)\) over rankings single-peaked on a unique labeled tree \(T\), output \(T\).

Packaged proof task (what the prover saw — nothing else)

Let \(C=\{1,\ldots,m\}\), with \(m\geq1\). Rankings are strict total orders. A ranking is single-peaked on an undirected tree \(T\) with vertex set \(C\) if each nonempty initial segment induces a connected subgraph of \(T\). Let \(S(T)\) contain all such rankings, and let \(U(T)\) assign mass \(1/|S(T)|\) to each of them and zero elsewhere.
A society is given by its support: the list of the \(\tau\) distinct rankings with positive mass, each mass a binary rational, with masses summing to \(1\). Here \(\tau\) is the support size, not the number \(m!\) of possible rankings; \(L\) is the total input bit length.
The input distribution \(\mu\) is promised to equal \(U(T)\) for exactly one labeled tree \(T\). The reconstruction problem outputs the edge set of \(T\); no behavior is prescribed outside the promise.

Is this promised exact reconstruction problem solvable in deterministic time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite samples, a polynomial-time procedure recovers the generating tree with probability at least \(1-\delta\) from \(2m\alpha\) independent samples from \(U(T)\), where \(0<\delta<1\) and \(\alpha\geq2\ln m+\ln(1/\delta)\). [Source](https://www.ijcai.org/proceedings/2019/0082.pdf)
No result settling exact reconstruction from an explicitly listed distribution was located in the literature search.

Modeling choices made when packaging the task

  • Complete rankings mean strict total orders, following the discrete definition.
  • The tree is undirected and has exactly the candidate labels as vertices; reconstruction returns its edge set.
  • Distribution masses sum to one, and omitted rankings have zero mass.
  • Allow m≥1, including the well-defined singleton tree.
  • L denotes total input bit length, including rankings and rational masses.
  • Uniqueness concerns the equality μ=U(T); behavior outside this promise is unrestricted.

1. Result

The promised reconstruction problem is solvable in deterministic polynomial time. For \(m\geq 2\), the tree’s edges are exactly the unordered pairs appearing in the first two positions of a listed ranking.

The proof also shows that the uniqueness promise is redundant: the full support determines the labeled tree.

2. Structural lemma

Write a ranking as \(r=(r_1,\ldots,r_m)\), from highest to lowest preference.

Lemma. For any tree \(T\) on \(C\), with \(m\geq 2\),
\[ E(T)=\bigl\{\{r_1,r_2\}:r\in S(T)\bigr\}. \]

Proof. We prove both inclusions.

First, let \(r\in S(T)\). By definition, its two-vertex initial segment \(\{r_1,r_2\}\) induces a connected subgraph of \(T\). A graph induced by two distinct vertices is connected precisely when they are adjacent. Therefore \(\{r_1,r_2\}\in E(T)\).

Conversely, fix an edge \(\{x,y\}\in E(T)\). Begin a ranking with \(x,y\). This initial segment induces a connected subgraph.

Suppose we have constructed an initial segment whose vertex set \(A\) induces a connected subgraph, and \(A\neq C\). Because \(T\) is connected and \(A\) is nonempty and proper, an edge joins some vertex of \(A\) to some vertex \(z\in C\setminus A\). Indeed, if no such edge existed, there would be no path from \(A\) to its complement, contradicting connectivity. Append \(z\). The induced subgraph on \(A\cup\{z\}\) is connected, since it contains the connected subgraph on \(A\) and an edge joining \(z\) to that subgraph.

Repeating this step produces a strict total order of all vertices. Its singleton initial segment is connected, its two-vertex initial segment is connected, and every subsequent initial segment is connected by construction. Thus the resulting ranking belongs to \(S(T)\) and begins with \(x,y\). This proves the reverse inclusion. \(\square\)

3. Algorithm and correctness

Let \(R\) be the explicitly listed support of \(\mu\).

  • If \(m=1\), output the empty edge set.
  • Otherwise, for each \(r\in R\), record the pair \((\min\{r_1,r_2\},\max\{r_1,r_2\})\).
  • Sort these pairs, remove duplicates, and output the corresponding unordered edges.

Under the promise \(\mu=U(T)\), every ranking in \(S(T)\) has positive mass, and every ranking outside \(S(T)\) has zero mass. Since the input lists the entire positive support, \(R=S(T)\). The lemma therefore proves that the algorithm outputs exactly \(E(T)\). For \(m=1\), the unique tree has no edges, so the first step is also correct.

The numerical masses need not be used. Moreover, if \(U(T)=U(T')\), their supports coincide, so the lemma gives \(E(T)=E(T')\). Hence the generating labeled tree is necessarily unique.

4. Running time and relation to sampling

Reading the input takes \(O(L)\) bit operations. Each vertex label uses \(O(\log(m+1))\) bits. Deterministic comparison sorting of the \(\tau\) recorded pairs, followed by duplicate removal, takes \(O(\tau\log(\tau+1)\log(m+1))\) bit operations. Thus the total running time is
\[ O\bigl(L+\tau\log(\tau+1)\log(m+1)\bigr), \]
which is polynomial in \(m,\tau,L\).

This argument uses the entire support. A finite sample can omit rankings witnessing an edge, so the sample-recovery question in the [cited paper](https://www.ijcai.org/proceedings/2019/0082.pdf) requires additional analysis.
