The continuous mirror question, as graded

Given categories \(\mathcal K\) and rational masses \(\mu_t>0\) over supported types \(t=(\succ_t,e_t)\), where \(\succ_t\) is a strict ranking of categories and \(e_t\) is the endowed category, compute a mass allocation \(y_{t,k}\) satisfying \(\sum_k y_{t,k}=\mu_t\) and \(\sum_{t:e_t=k}\mu_t=\nu_k=\sum_t y_{t,k}\), with no mass rectification block, or report that none exists. A block selects submass from current type-category assignments and reallocates it using the selected agents’ endowed-category supplies, with weak improvement for all selected mass and strict improvement for positive mass; indifferent participating mass currently assigned category \(k\) is admissible only if the coalition owns all copies of \(k\), that is, \(E_k=\nu_k\).

Packaged proof task (what the prover saw — nothing else)

Let \(\mathcal K\) be a nonempty set of \(m\) categories. A society is given by its support: a list of \(\tau\) types \(t=(\succ_t,e_t)\), each with positive binary-rational mass \(\mu_t\), where \(\succ_t\) strictly ranks all categories and \(e_t\in\mathcal K\). Masses sum to \(1\); agents are indifferent precisely between copies of the same category.
Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total binary input length. Every category has positive supply \(\nu_k=\sum_{t:e_t=k}\mu_t\).
An allocation is a nonnegative mass matrix \(y\) satisfying \(\sum_k y_{t,k}=\mu_t\) and \(\sum_t y_{t,k}=\nu_k\).
A mass rectification block is a nonnegative real array \(z_{t,k,\ell}\), representing selected type-\(t\) mass currently receiving \(k\) and reassigned to \(\ell\), with \(\sum_\ell z_{t,k,\ell}\le y_{t,k}\).
Its endowed supply is \(E_j=\sum_{t:e_t=j}\sum_{k,\ell}z_{t,k,\ell}\); require \(\sum_{t,k}z_{t,k,j}=E_j\) for every \(j\). Require \(z_{t,k,\ell}=0\) unless \(\ell=k\) or \(\ell\succ_t k\), and \(\sum_{t,k,\ell:\ell\succ_t k}z_{t,k,\ell}>0\).
Unaffected participation is admissible only when \(z_{t,k,k}>0\Rightarrow E_k=\nu_k\). No welfare restriction is imposed on agents outside the coalition.
The computational problem is to output an exact rational allocation admitting no such block, or report that no allocation exists.

Is this problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

In finite housing markets with strict rankings of categories and indifference among their copies, every TTC outcome belongs to the rectified strong core. [Zhang](https://arxiv.org/html/2511.21158v4)
For the same finite preference domain, TTC with fixed tie-breaking is also Pareto efficient and group strategy-proof. [Sandholtz and Tai](https://arxiv.org/abs/2503.18144v3)
No result settling the exact mass-allocation problem above was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total mass to one because the question specifies a distribution; each unit of agent mass owns and receives one unit of category mass.
  • Required a nonempty category set and positive supply for every listed category, interpreting categories as classes of existing objects.
  • Formalized selection and reassignment jointly by an array indexed by type, current category, and new category, allowing arbitrary real submass and requiring exact use of the selected agents’ endowments.
  • Specified exact rational output, while nonexistence means that no real feasible unblocked allocation exists.
  • Imposed no welfare condition on outsiders, as coalition blocking restricts only participating agents.

Result

The problem is solvable in time polynomial in \(m,\tau,L\). Moreover, every input satisfying the stated hypotheses admits an allocation with no mass rectification block.

The algorithm batches TTC without expanding rational masses into individual agents. The finite stability property is stated in [Zhang, Proposition 3](https://arxiv.org/html/2511.21158v4#S4); we prove the needed property directly below, then justify its extension to arbitrary real blocks.

1. An exact batched algorithm

Write \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\), and set

\[ D=\prod_{t=1}^{\tau}b_t, \qquad w_t=D\mu_t. \]

Thus the \(w_t\) are positive integers and \(\sum_t w_t=D\). The binary length of \(D\) is \(O(L)\).

Fix an order of the supported types. Maintain integer residual masses \(r_t\), initially \(w_t\), and an integer allocation matrix \(Y\), initially zero.

In each phase:

  • Call \(t\) active when \(r_t>0\). For each category \(j\) with an active endowed owner, let \(p(j)\) be its first active endowed type in the fixed order.
  • For each active \(t\), let \(c(t)\) be its favorite category among those with an active endowed owner.
  • Form the functional directed graph

\[ t\longrightarrow f(t):=p(c(t)) \]
on active types.

  • Let \(U\) be the union of the vertices in all directed cycles. Set

\[ d=\min_{t\in U}r_t. \]

  • For every \(t\in U\), update

\[ Y_{t,c(t)}\leftarrow Y_{t,c(t)}+d, \qquad r_t\leftarrow r_t-d. \]

A nonempty finite functional graph contains a directed cycle, so every phase is defined. Each phase exhausts at least one active type, and exhausted types never return. Consequently there are at most \(\tau\) phases.

Return \(y_{t,k}=Y_{t,k}/D\).

Feasibility

The row invariant is

\[ \sum_kY_{t,k}+r_t=w_t. \]

For columns, observe that \(f\) restricts to a permutation of \(U\), and \(c(t)=e_{f(t)}\). Hence, for every category \(j\),

\[ \bigl|\{t\in U:c(t)=j\}\bigr| = \bigl|\{t\in U:e_t=j\}\bigr|. \]

The mass assigned to category \(j\) in a phase therefore equals the endowed mass of category \(j\) removed in that phase. This proves the column invariant

\[ \sum_tY_{t,j}+\sum_{t:e_t=j}r_t=D\nu_j. \]

At termination all residual masses vanish. Dividing the invariants by \(D\) gives precisely the required row and column sums.

2. Batching exactly reproduces finite TTC

For this proof only, expand type \(t\) into \(w_t\) individual agents, each endowed with one copy of \(e_t\).

Label these agents by their type order and then by an index within the type. Within every category, every agent breaks ties by the label of the copy’s endowed owner. Category comparisons remain those of the agent’s type.

At any stage of TTC:

  • Every remaining agent of type \(t\) chooses category \(c(t)\).
  • Within that category, it chooses the copy belonging to the first remaining agent of type \(p(c(t))\).

Thus every pointed-to agent is the first remaining agent of some type. No other agent can belong to a directed cycle, because it has no incoming edge. The individual TTC cycles therefore correspond exactly to the cycles of the type graph \(f\).

One TTC round removes one agent of every type in \(U\), assigning that agent category \(c(t)\). For the next \(d\) rounds, the type graph stays unchanged until the end of the last round: no participating type becomes exhausted earlier, and all other types retain their residual populations. Hence these \(d\) rounds perform exactly one phase of the batched algorithm.

Induction over phases proves that \(Y\) is the category-count matrix of this finite TTC run.

We also need the following consequence.

Replication invariance. If all initial weights are multiplied by a positive integer \(s\), the output matrix is multiplied by \(s\).

Indeed, the active sets, chosen categories, and cycle sets remain identical; every residual mass and every batch size is multiplied by \(s\). This follows inductively from the update rule.

The expanded market is used only in the proof. The algorithm never constructs it.

3. Finite TTC admits no admissible rectification block

We prove the finite statement for agents strictly ranking categories and indifferent between their copies.

Let \(x\) be a TTC allocation. Suppose a coalition \(C\) can reassign its endowed objects so that every member weakly improves, some member strictly improves, and every unaffected member receiving category \(k\) has all endowed owners of category \(k\) in \(C\).

Order the TTC cycles by removal time, breaking ties between cycles in the same round arbitrarily. Each agent receives a favorite category among the objects remaining when its cycle is removed. This remains true under the chosen ordering: its pointed-to object belongs to its own cycle and survives until that cycle is removed.

Let \(H\) be the first cycle containing a coalition member who strictly improves under the proposed reassignment. Every coalition member in an earlier cycle is unaffected.

Earlier cycles are wholly inside or outside the coalition

Consider an earlier cycle containing \(i\in C\). Let \(i'\) be its successor, so that \(i\) receives the object endowed to \(i'\) under TTC.

Since \(i\) is unaffected, the proposed reassignment gives it the same category as \(x(i)\). Admissibility therefore requires every endowed owner of that category to belong to \(C\). In particular, \(i'\in C\).

The same argument applies successively around the cycle, since every coalition member in that earlier cycle is unaffected. Thus the entire cycle belongs to \(C\).

Consequently each earlier cycle is either contained in \(C\) or disjoint from \(C\).

The desired category has already been used

Choose a strictly improving coalition member \(i\) in \(H\), and let \(j\) be its category under the proposed reassignment. Then \(j\succ_i x(i)\).

No copy of \(j\) remains when \(H\) is removed; otherwise TTC would assign \(i\) a category at least as desirable as \(j\). Therefore every endowed owner of category \(j\) belongs to an earlier cycle.

Let \(A\) be the coalition members in earlier cycles. By the preceding argument, \(A\) is a union of complete cycles. TTC reallocates the endowed objects within each cycle, so its category assignments to \(A\) have exactly the category counts of \(A\)’s endowments.

All members of \(A\) are unaffected. Their proposed category assignments therefore have those same counts.

Every coalition-owned copy of \(j\) is endowed to a member of \(A\). The proposed assignments to \(A\) already use exactly that many copies of \(j\), leaving none for \(i\in C\setminus A\). This contradicts feasibility of the coalition’s reassignment.

This proves the finite stability statement.

4. A real block implies a rational block

Lemma. For any rational allocation \(y\), existence of a real mass rectification block implies existence of a rational one.

Proof. Suppose \(z^0\) is a real block. Define

\[ S=\{k:\text{there exists }t\text{ with }z^0_{t,k,k}>0\}. \]

Consider the polyhedron \(P\) defined by:

  • nonnegativity and the capacity inequalities

\[ \sum_\ell z_{t,k,\ell}\le y_{t,k}; \]

  • the endowed-supply balance equalities from the question;
  • zero entries for forbidden preference transitions;
  • \(z_{t,k,k}=0\) whenever \(k\notin S\);
  • \(E_k=\nu_k\) whenever \(k\in S\).

All coefficients and right-hand sides are rational. The original block \(z^0\) belongs to \(P\), so \(P\) is nonempty. Every coordinate is bounded by its corresponding \(y_{t,k}\), making \(P\) compact.

Maximize the linear function

\[ F(z)=\sum_{t,k,\ell:\ell\succ_t k}z_{t,k,\ell} \]

over \(P\). Its maximum is positive because \(F(z^0)>0\).

A linear function on a nonempty bounded rational polyhedron has a rational maximizer. To justify the rationality, choose a vertex of its maximizing face. This is a vertex of the original polyhedron, whose coordinates are determined by a nonsingular system of rational active constraints; Gaussian elimination gives rational coordinates.

Let \(z^*\) be such a maximizer. It satisfies all block constraints and has \(F(z^*)>0\). Moreover, any positive diagonal entry has its category in \(S\), where the required saturation equality is imposed. Thus \(z^*\) is a rational mass rectification block. \(\square\)

5. Stability against arbitrary real mass blocks

Let \(y=Y/D\) be the algorithm’s output. Suppose it admits a real block. By Section 4, it admits a rational block \(z\).

Choose a positive integer \(N\) divisible by \(D\) and by the denominators of all entries of \(z\). Then \(N\mu_t\), \(Ny_{t,k}\), and \(Nz_{t,k,\ell}\) are integers.

Expand type \(t\) into \(N\mu_t\) agents. Since \(N/D\) is an integer, replication invariance and Section 2 show that finite TTC produces exactly \(Ny_{t,k}\) agents of type \(t\) assigned category \(k\).

We now realize the block as a finite coalition:

  • From the agents in each type-category cell \((t,k)\), select \(Nz_{t,k,\ell}\) distinct agents for every destination \(\ell\). The capacity inequalities ensure enough agents exist.
  • For each category \(j\), the selected agents endow exactly \(NE_j\) copies, and their proposed destinations demand exactly \(NE_j\) copies. Assign the coalition’s endowed copies bijectively to these destination slots.

Every selected agent weakly improves. Since the strict-improvement sum is positive and its scaled terms are integers, at least one selected agent strictly improves.

If a selected agent is unaffected in category \(k\), then some \(z_{t,k,k}>0\), so \(E_k=\nu_k\). The coalition consequently contains every endowed owner of category \(k\). Thus the finite coalition satisfies exactly the admissibility condition in Section 3.

It would block a finite TTC allocation, contradicting Section 3. Therefore \(y\) admits no real mass rectification block.

6. Polynomial bit complexity

There are at most \(\tau\) phases. In each phase:

  • representatives can be found by scanning the active types;
  • each type’s favorite available category can be found by scanning its ranking;
  • cycles of the functional graph can be found in linear time;
  • updates require at most \(\tau\) integer additions and subtractions.

This gives \(O(\tau^2m)\) elementary arithmetic operations, apart from polynomial preprocessing and output work.

Every residual mass, batch size, and allocation numerator lies between \(0\) and \(D\), whose binary length is \(O(L)\). All arithmetic therefore has polynomial bit cost. The output has \(\tau m\) rational entries with numerators and denominators of \(O(L)\) bits.

Hence the algorithm outputs an exact rational unblocked allocation in time polynomial in \(m,\tau,L\). On inputs satisfying the stated hypotheses, the “no allocation exists” outcome is never necessary.

1. Integer scaling and termination

The scaling is valid: \(D=\prod_t b_t\) is divisible by every denominator, so every \(w_t=D\mu_t\) is a positive integer. The normalization of masses gives \(\sum_t w_t=D\).

The bit-length claim is correct. The binary length of the product is bounded by the sum of the binary lengths of its factors, which is \(O(L)\). The numerical value of \(D\) can be exponentially large without invalidating this bound.

Whenever an active type exists, its endowed category is available. Thus every active type has a well-defined favorite available category and a well-defined successor. The resulting nonempty finite functional graph has at least one directed cycle.

The batch size is positive and no greater than any participating residual mass. Each phase therefore preserves nonnegativity and exhausts at least one type. There are at most \(\tau\) phases, and termination leaves every residual mass zero.

Assessment: Correct.

2. Allocation feasibility

The row invariant follows directly from the paired allocation and residual updates.

For the column invariant, the restriction of \(f\) to the union \(U\) of its cycles is a permutation. The identity \(c(t)=e_{f(t)}\) consequently gives the stated equality of category counts. Because every participating type contributes the same amount \(d\), equality of these counts gives equality between the assigned category mass and the removed endowed category mass.

The initial column invariant holds by the definition of supply. At termination, division by \(D\) gives all required row and column sums. All allocation entries are nonnegative.

3. Exact correspondence with finite TTC

The specified tie-breaking is fixed and respects strict category rankings. Every agent chooses the first remaining endowed copy within its favorite available category.

Only the first remaining agent of a type can receive an incoming edge. Every vertex of a directed cycle must receive an incoming edge, so no other agent can belong to a cycle. Among the first remaining agents, the successor relation is exactly the type graph \(f\). This verifies the claimed cycle correspondence.

During the \(d\) simulated rounds, no participating type disappears before the last round. Nonparticipating types retain their populations. Changing the first remaining agent within a surviving type does not change the category or representative-type choices. Hence the type graph remains unchanged throughout the batch.

Replication invariance also follows from the stated update rule: multiplying residuals by a positive integer preserves active sets and multiplies every batch size and allocation increment by that integer.

4. Finite stability
