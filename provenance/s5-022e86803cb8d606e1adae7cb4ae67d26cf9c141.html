The continuous mirror question, as graded

Given a finite MDP \(M\), its occupancy polytope \(\mathcal O\), a finite support \(T\) of normalized reward types \(R_t\), and rational masses \(\mu_t\ge 0\) summing to \(1\), find \(x\in\mathcal O\) maximizing \(\sum_{t\in T}\mu_t\,\mathbf{1}[\langle x,R_t\rangle=\max_{y\in\mathcal O}\langle y,R_t\rangle]\). The output is a maximizing occupancy measure, representing a policy with maximum individually optimal population mass.

Packaged proof task (what the prover saw — nothing else)

Let \(S,A\) be nonempty finite sets, \(m=|S||A|\), and let \(P(s'\mid s,a)\) be rational transition probabilities. Choose either normalized discounted occupancy, with rational \(0<\gamma<1\) and rational initial distribution \(d_0\), or average occupancy, with \(\gamma=1\) and a selectable stationary initial distribution.
Define \(\mathcal O=\{x\ge0:\sum_{s,a}x(s,a)=1,\ \sum_a x(s,a)=(1-\gamma)d_0(s)+\gamma\sum_{s',a'}P(s\mid s',a')x(s',a')\ \forall s\}\); the initial-distribution term is omitted in the average case.
A society is given by its support: the list of \(\tau\) distinct reward types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each \(R_t\in\mathbb Q^{S\times A}\) may have either sign and satisfies \(\min_{x\in\mathcal O}\langle x,R_t\rangle=0\) and \(\max_{x\in\mathcal O}\langle x,R_t\rangle=1\); types indifferent over all occupancies are excluded.
Set \(F(x)=\sum_t\mu_t\mathbf1[\langle x,R_t\rangle=1]\) and \(\mathrm{OPT}=\max_{x\in\mathcal O}F(x)\). Every individually optimal occupancy receives approval, including ties; stochastic policies are allowed.
For each fixed \(\epsilon\in(0,1/2)\), is there an algorithm polynomial in \(m,\tau,L\) returning \(x\in\mathcal O\) with \(F(x)\ge\tau^{-(1/2-\epsilon)}\mathrm{OPT}\), or is achieving this guarantee NP-hard? Here \(L\) is the total binary input length.
For finite-agent policy plurality, the corresponding \(n^{-(1/2-\epsilon)}\) approximation is impossible in polynomial time unless \(\mathbf P=\mathbf{NP}\). [Source](https://ebadian.org/preprint/policy_aggregation.pdf)
This already covers the stated mass problem on equal-mass supports: the score is merely normalized by the population size. Consequently, this target is already settled under \(\mathbf P\ne\mathbf{NP}\).

Conclusion

Achieving the requested guarantee is NP-hard: for every fixed \(\epsilon\in(0,1/2)\), such a polynomial-time algorithm would imply \(\mathbf P=\mathbf{NP}\). This holds for both occupancy conventions.

The finite-agent hardness does transfer to support size. The transfer requires checking the relation between the population size \(n\) and the number of distinct types \(\tau\); simply identifying them would overlook repeated types.

The finite-agent hardness premise

Write \(c=1/2-\epsilon>0\). For a population of \(n\) agents with normalized rewards \(Q_1,\ldots,Q_n\), define

\(C(x)=\sum_{i=1}^n\mathbf1[\langle x,Q_i\rangle=1]\)

and \(C^\star=\max_{x\in\mathcal O}C(x)\).

The stated finite-agent result rules out a polynomial-time algorithm guaranteeing \(C(x)\ge n^{-c}C^\star\), unless \(\mathbf P=\mathbf{NP}\). The cited paper’s plurality definition approves every individually optimal policy, and its policy space includes stochastic policies, so these conventions agree with the task. [Policy Aggregation, Section 5, Theorem 4](https://ebadian.org/preprint/policy_aggregation.pdf).

A support-compression lemma

Lemma. A polynomial-time algorithm for the mass problem with guarantee \(\tau^{-c}\mathrm{OPT}\) yields a polynomial-time algorithm for finite-agent plurality with guarantee \(n^{-c}C^\star\).

Proof. Take any normalized finite-agent instance with no indifferent agents. List its distinct reward vectors as \(R_1,\ldots,R_\tau\). For each \(t\), let

\(k_t=|\{i:Q_i=R_t\}|\), and \(\mu_t=k_t/n\).

These masses are positive rational numbers, satisfy \(\sum_t\mu_t=1\), and have binary encoding length polynomial in the original input length. The rewards retain their normalization because each \(R_t\) is one of the original rewards. Moreover, \(\tau\le n\).

For every feasible occupancy \(x\), grouping equal rewards gives the exact identity

\(F(x)=\sum_{t=1}^{\tau}\frac{k_t}{n}\mathbf1[\langle x,R_t\rangle=1]=\frac{C(x)}{n}\).

Consequently, \(\mathrm{OPT}=C^\star/n\).

Suppose the proposed mass algorithm returns \(x\) satisfying \(F(x)\ge\tau^{-c}\mathrm{OPT}\). Multiplication by \(n\) yields

\(C(x)\ge\tau^{-c}C^\star\ge n^{-c}C^\star\),

where the last inequality follows from \(\tau\le n\) and \(c>0\).

The transformation only groups explicitly listed agents; it never expands a binary-encoded mass into a population. Its output length is polynomial in the finite-agent input length. Hence an algorithm polynomial in \(m,\tau,L\) becomes a polynomial-time finite-agent algorithm with the forbidden guarantee. This proves the lemma. \(\square\)

Applying the lemma to the finite-agent hardness premise establishes the claimed impossibility.

Compatibility with both occupancy conventions

The hard construction uses rational transitions that send every state-action pair uniformly to the \(q\) states. For discounting, choose the rational initial distribution \(d_0(s)=1/q\) and, for example, \(\gamma=1/2\). In either convention, the occupancy equations then reduce to

\(\sum_a x(s,a)=1/q\quad\text{for every }s\).

Indeed, \(\sum_{s',a'}P(s\mid s',a')x(s',a')=1/q\) because the total occupancy is \(1\). Conversely, these state-marginal equations imply the required flow equations.

Thus the same feasible polytope occurs in both cases. In the average case, its uniform state marginal is an admissible selectable stationary initial distribution. These are the rational hard instances used in the paper. [Policy Aggregation, Appendix B](https://ebadian.org/preprint/policy_aggregation.pdf).

Why equal-mass supports also suffice

The paper’s independent-set construction assigns one reward to each graph vertex. After removing isolated vertices, every reward is nonconstant. Its normalized reward equals \(q/\deg(v)\) on the state-action coordinates corresponding to vertex \(v\), and equals \(0\) elsewhere. Different vertices have disjoint, nonempty positive supports, so their normalized rewards are distinct. Consequently, that construction has \(\tau=n\) and masses \(1/n\). [Policy Aggregation, Appendix B.1](https://ebadian.org/preprint/policy_aggregation.pdf).

Removing isolated vertices does not weaken the needed independent-set hardness. To verify this, suppose an algorithm on graphs without isolated vertices guarantees a \(k^{-c}\) fraction of the maximum independent-set size on \(k\) vertices. Given any graph on \(n\) vertices, let \(r\) be its number of isolated vertices and let \(H\) be the remaining graph, with \(k=n-r\). If \(k=0\), return all vertices. Otherwise, combine all isolated vertices with the algorithm’s independent set in \(H\). Writing \(\alpha\) for maximum independent-set size, the result has size at least

\(r+k^{-c}\alpha(H)\ge n^{-c}\bigl(r+\alpha(H)\bigr)=n^{-c}\alpha(G)\).

Here \(r\ge n^{-c}r\), \(k^{-c}\ge n^{-c}\), and \(\alpha(G)=r+\alpha(H)\). Therefore hardness persists without isolated vertices, validating the equal-mass restriction.
