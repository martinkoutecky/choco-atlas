The continuous mirror question, as graded

Given a radial feeder \(H=(V,E)\), finite types \(T\) located at feeder nodes, rational masses \(\mu_t\) summing to \(1\), and each type’s finite integral offer menu \(Q_t\subseteq\mathbb{Z}\) with rational utilities \(u_t(q)\), compute a welfare-maximizing allocation of mass to offers and signed edge flows. The allocation variables \(a_{tq}\geq 0\) must satisfy \(\sum_{q\in Q_t}a_{tq}=\mu_t\); at each node \(v\), incoming flow minus outgoing flow must equal \(\sum_{t\in T_v}\sum_{q\in Q_t}q\,a_{tq}\); and each edge flow must satisfy \(|f_e|\leq\kappa_e\), where \(\kappa_e\) is capacity per unit of normalized population. The objective is to maximize \(\sum_t\sum_{q\in Q_t}a_{tq}u_t(q)\).

Packaged proof task (what the prover saw — nothing else)

Let \(H=(V,E)\) be a finite undirected tree with \(m=|V|\), arbitrarily oriented for recording signed flows. Each edge has a binary-rational capacity \(\kappa_e\geq0\), measured per unit of normalized population; there is no external energy supply or disposal.
A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Each type has a specified node \(\ell(t)\in V\) and an explicitly listed finite menu \(Q_t\subseteq\mathbb Z\) containing \(0\), with values \(u_t(q)\in\mathbb Q\) of either sign, including a finite value at \(0\). Positive quantities mean consumption and negative quantities mean production; unlisted quantities are unavailable.
Mass may be divided among mutually exclusive offers: choose real \(a_{tq}\geq0\) and signed real flows \(f_e\) satisfying \(\sum_{q\in Q_t}a_{tq}=\mu_t\), \(|f_e|\leq\kappa_e\), and, at every node \(v\), \(\sum_{e\text{ entering }v}f_e-\sum_{e\text{ leaving }v}f_e=\sum_{t:\ell(t)=v}\sum_{q\in Q_t}q a_{tq}\). Zero net consumption permits energy relay.
The optimization problem is to compute an allocation and flows maximizing \(\sum_t\sum_{q\in Q_t}a_{tq}u_t(q)\). Let \(s=\sum_t|Q_t|\) and let \(L\) be the total binary input length; state running times in \(m,\tau,s,L\). Any maximizing allocation is acceptable.

Is this continuous energy-allocation problem solvable in polynomial time in \(m,\tau,s,L\), or is it NP-hard?

For discrete prosumers, [RadPro](https://ifaamas.csc.liv.ac.uk/Proceedings/aamas2015/aamas/p1285.pdf) computes each tree message in \(O(d_j C_j s_j+d_j^2C_j^2)\) operations, where \(d_j\) is node degree, \(C_j\) the largest incident integral capacity, and \(s_j\) the menu size; this is a numerical-capacity bound, not a polynomial binary-input bound.
A [continuous-energy follow-up](https://www.iiia.csic.es/media/filer_public/ea/e6/eae6d188-b1ca-4269-842b-5aaa99b707c8/5500.pdf) gives a mixed-integer formulation for individual prosumers with piecewise-linear valuations, rather than divisible type masses. Conclusion

The problem is solvable exactly in polynomial time in \(m,\tau,s,L\). Divisible type masses make the stated optimization problem a rational linear program of polynomial encoding length.

1. Exact linear-program formulation

Let \(B\) be the signed node-edge incidence matrix of the given orientation: for an edge \(e\) directed from \(x\) to \(y\), let \(B_{xe}=-1\), \(B_{ye}=1\), and all other entries in its column be zero.

Introduce one real variable \(a_{tq}\) for every explicitly listed offer \(q\in Q_t\), and one real variable \(f_e\) for every edge. Maximize

\( \displaystyle \sum_{t=1}^{\tau}\sum_{q\in Q_t}u_t(q)a_{tq} \)

subject to:

  • \(a_{tq}\geq 0\) for every listed offer;
  • \(\sum_{q\in Q_t}a_{tq}=\mu_t\) for every type \(t\);
  • \(-\kappa_e\leq f_e\leq\kappa_e\) for every edge \(e\);
  • \(\sum_{e\in E}B_{ve}f_e-\sum_{t:\ell(t)=v}\sum_{q\in Q_t}q\,a_{tq}=0\) for every node \(v\).

Every coefficient and right-hand side is rational. In particular, each quantity \(q\) is a fixed integer coefficient, so \(q\,a_{tq}\) is linear in the decision variables.

This formulation is exact: its feasible points are precisely the allocations and flows allowed by the question, and its objective is precisely their welfare. There are no integrality restrictions to enforce, because the premises explicitly allow each type’s mass to be divided among offers.

Summing all node equations cancels every flow term, since each column of \(B\) sums to zero. Thus every feasible point satisfies

\( \displaystyle \sum_{t=1}^{\tau}\sum_{q\in Q_t}q\,a_{tq}=0, \)

as required by the absence of external supply or disposal. The node equations also permit relay through a node with zero net consumption.

2. Feasibility and attainment

The feasible set is nonempty. Set \(a_{t0}=\mu_t\), set every other allocation variable to zero, and set every flow to zero. This is feasible because every menu contains \(0\) and every capacity is nonnegative.

Nonnegativity and the type-mass equations imply \(0\leq a_{tq}\leq\mu_t\leq 1\). Each flow lies in the finite interval \([-\kappa_e,\kappa_e]\). Consequently, the feasible set is bounded. It is also closed, being defined by finitely many linear equalities and non-strict inequalities.

The feasible set is therefore a nonempty compact polytope. The linear objective is continuous and hence attains a finite maximum. Negative utilities, including negative values at \(0\), do not affect this argument.

3. Binary encoding and running time

Because the graph is a tree, \(|E|=m-1\). The formulation has

\(n=s+m-1\)

variables. Replacing every equality by two inequalities gives

\(M=s+2(m-1)+2\tau+2m\)

inequalities, counting allocation nonnegativity and both flow bounds.

In a dense matrix representation, the total binary encoding length \(T\), including the objective, satisfies

\(T=O(L+Mn).\)

Indeed, each original numerical datum is copied only a constant number of times: quantities appear in the node constraints, masses in the type constraints, capacities in the flow bounds, and utilities in the objective. The remaining matrix entries are \(0\), \(1\), or \(-1\). Thus the formulation can be constructed in polynomial time in \(m,\tau,s,L\), without enumerating any intermediate quantity or capacity value.

We apply the standard exact rational linear-programming theorem: an explicitly given rational linear program can be solved in time polynomial in its binary encoding length, with an exact rational optimizer returned whenever the feasible set is nonempty and the optimum is finite. Exact polynomial-time methods are discussed in Section 1.3 of [*Linear Programming using Limited-Precision Oracles*](https://optimization-online.org/wp-content/uploads/2019/12/7507.pdf).

All hypotheses hold here: the formulation is explicit and rational, its encoding length is polynomially bounded, and Section 2 proves feasibility and a finite attained optimum. Redundant balance equations or zero capacities cause no difficulty; the theorem does not require a full-dimensional feasible set.

The resulting running time is

\((m+\tau+s+L)^{O(1)}\)

bit operations, and the returned coordinates directly give the requested maximizing allocation and flows.

For completeness, exact output has polynomial length as well. A bounded rational polytope has an optimal vertex. At a vertex, \(n\) linearly independent tight constraints determine the coordinates. Clearing denominators produces an integer system whose entries have \(O(L)\) bits. Hadamard’s inequality bounds the absolute values of its determinant and the column-replacement determinants by \(n^{n/2}2^{O(nL)}\). Cramer’s rule therefore gives each coordinate numerator and denominator with \(O(n(L+\log n))\) bits.

4. Why discrete-prosumer bounds do not obstruct this result

For an indivisible prosumer, selecting one offer requires a discrete choice. Here, the premise permits arbitrary nonnegative portions of a type’s mass to select different offers. The variables \(a_{tq}\) represent those portions directly.

Accordingly, neither a numerical-capacity dynamic program nor a mixed-integer formulation is needed for this mass-allocation model. Arbitrary menu values and large binary-encoded capacities remain coefficients and bounds in a polynomial-size linear program.
