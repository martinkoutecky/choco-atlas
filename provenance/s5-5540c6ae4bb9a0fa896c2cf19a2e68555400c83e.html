The continuous mirror question, as graded

Given a finite set of resource classes \(J\), bundles \(\mathcal B\), complete agent types \(\mathcal T\) with rational masses \(\mu_t\), and per-capita supplies \(q_j\), lift a \(c\)-approximate monotone strongly loser-independent greedy allocation rule to a fluid allocation that may split type mass at capacity boundaries while each individual receives an integral bundle. In the resulting nonatomic critical-price auction, does every equilibrium in which agents do not overbid achieve expected per-capita welfare at least \(\operatorname{OPT}_\infty(\mu,q)/(c+1)\)? The equilibrium is over measurable type-dependent bidding strategies, with each infinitesimal agent best responding while taking aggregate bid mass as fixed.

Conclusion and scope

The guarantee can fail under the stated refinement conditions, interpreting empirical convergence as weak convergence of report distributions. There is a counterexample with \(m=\tau=1\) and \(c=2\), for which \(W=0\) but \(\operatorname{OPT}_\infty=1/2\).

The construction uses one diverging bid of vanishing empirical mass. Thus the limiting equilibrium obeys no overbidding, although its finite refinements do not. This distinction matters: below, I also prove the requested bound for one resource when every finite refinement preserves no overbidding. The general problem under that stronger interpretation remains open in this analysis.

1. A finite greedy rule satisfying all the allocation-rule hypotheses

Let \(J=\{a\}\) and \(\mathcal B=\{\varnothing,\{a\}\}\). Write an agent’s report as its nonnegative bid \(b_i\) on \(\{a\}\). For a population of \(n\) agents, let \(Q\) be the integer number of available units.

Define \(A\) as follows.

Initially, both bundle priorities use the function \(r(z)=z\). After the first accepted allocation, let \(M\) be its declared value and, when \(n\geq2\), set
\[ h=\frac{M}{n-1}. \]
For every subsequent iteration, both bundle priorities use
\[ r(z)= \begin{cases} 0,&z\leq h,\\ z,&z>h. \end{cases} \]
Here and below these formulas denote ordinary mathematical expressions; the empty-bundle bid is always zero.

At each iteration, select the highest-priority feasible agent–bundle pair and remove that agent. Fix ties by putting all empty-bundle pairs before all nonempty-bundle pairs, and then ordering agents by their labels. For \(n=1\), only the initial iteration is needed.

Each priority function is nondecreasing in its argument. The two bundles have identical priority functions, so priorities are nonincreasing under bundle inclusion. Adaptation uses only the first accepted allocation and its declared value.

The rule is a \(2\)-approximation

If \(Q=0\), optimal welfare is zero. If all bids are zero, the same conclusion holds. Otherwise, provided \(Q\geq1\), the first allocation gives \(\{a\}\) to a maximum bidder, with bid \(M>0\).

For \(n\geq2\), divide the remaining agents into
\[ H=\{i:b_i>h\},\qquad L=\{i:b_i\leq h\}. \]
The rule allocates to agents in \(H\) in descending bid order until capacity is exhausted. Agents in \(L\) receive the empty bundle: their item priority is zero, and their empty pair precedes every zero-priority item pair.

Let \(D\) be the rule’s declared welfare.

If the rule fills all \(Q\) units, it selects the \(Q\) largest bids, so it is optimal. Otherwise, it allocates to the first winner and every agent in \(H\). Any further contribution to optimal declared welfare comes from \(L\), whose total bid is at most
\[ \sum_{i\in L}b_i\leq(n-1)h=M. \]
Consequently,
\[ \operatorname{OPT}_{\mathrm{fin}}\leq D+M\leq2D. \]
The case \(n=1\) is optimal. Thus \(c=2\) works for every finite report profile and supply.

Component-wise monotonicity

Suppose an agent receives \(\{a\}\), and increase only its bid.

If it was the first winner, it remains a maximum bidder and still wins. Otherwise, its original bid exceeded \(h\). Increasing it either makes the agent the first winner or leaves the original first winner unchanged. In the latter case, \(h\) is unchanged and the agent moves weakly earlier in the descending order of \(H\), preserving its allocation.

Strong loser-independence

Here is a direct verification that also handles adaptation.

Compare executions on \(d\) and \(d'\) whose final allocations differ. Consider their first different selected pair.

If a bid on any previously accepted nonempty allocation changed, that bid supplies the required witness. Otherwise, the accepted history and its declared values are identical before this iteration, so both executions use the same priority functions.

Let the selected pairs at this iteration be \((\ell,U)\) under \(d\) and \((j,T)\) under \(d'\).

If the bid on \((\ell,U)\) changed, then \(U\neq\varnothing\) and \(A_\ell(d)=U\), giving a witness. Otherwise, the bid on \((j,T)\) must have changed, since fixed priorities and fixed ties could not otherwise change the selected pair.

Now change only agent \(j\)’s report to \(d'_j\). The common prefix is preserved: at each earlier iteration, its selected pair beats every unchanged agent’s pair as in the execution on \(d\), and beats agent \(j\)’s new pairs as in the execution on \(d'\). At the first differing iteration, \((j,T)\) beats the original highest pair and therefore every unchanged competitor. It also beats agent \(j\)’s other pairs. Hence
\[ A_j(d'_j,d_{-j})=T. \]
Since an empty-bundle bid cannot change, \(T\neq\varnothing\). This proves the required property.

2. Society and refinement convention

Take one type with
\[ \mu=1,\qquad v(\{a\})=1,\qquad v(\varnothing)=0,\qquad q_a=\frac12. \]
All numerical data are binary rationals, and the valuation satisfies the required normalization and monotonicity.

Use even populations \(N\), with supply \(N/2\).

Fix the following refinement convention before bidding. For any prescribed report distribution \(\sigma\):

  • Choose deterministic quantile representatives approximating \(\sigma\).
  • Cap their bids at \(\sqrt N\).
  • Replace the first agent’s bid by \(N^2\).

This convention gives weak empirical convergence to \(\sigma\). Indeed, uncapped quantile empirical measures converge weakly to \(\sigma\); the cap tends to infinity and therefore preserves this convergence. Replacing one representative changes the integral of any bounded test function \(f\) by at most \(2\lVert f\rVert_\infty/N\).

Thus the exceptional bid is invisible to weak empirical convergence.

Population allocation limit

The exceptional agent is the first winner. It establishes
\[ h_N=\frac{N^2}{N-1}>N. \]
Every remaining bid is at most \(\sqrt N<h_N\), so every remaining agent receives the empty bundle.

Exactly one item is allocated. Dividing allocation counts by \(N\) therefore gives limiting masses
\[ x_{\{a\}}=0,\qquad x_{\varnothing}=1. \]

Individual response limit

Fix any admissible replacement report \(d\), with finite bid \(z=d(\{a\})\).

For sufficiently large \(N\), \(z<h_N\). If the uniformly selected agent is not the exceptional agent, the exceptional first allocation persists and the selected agent receives the empty bundle.

The exceptional agent is selected with probability \(1/N\). Regardless of what happens in that event,
\[ \Pr(\text{selected agent receives }\{a\})\leq\frac1N. \]
Consequently, for every fixed report and aggregate distribution,
\[ K(\{a\}\mid d,\nu)=0,\qquad K(\varnothing\mid d,\nu)=1. \]

These kernels are measurable, their limits exist, and integrating them against any prescribed report distribution gives exactly the population allocation limit. Thus the required allocation–response consistency holds.

3. A no-overbidding equilibrium with zero welfare

Let the equilibrium report distribution be the point mass at the zero report.

It obeys no overbidding, since
\[ d(\{a\})=0\leq1=v(\{a\}). \]

For every finite \(z\),
\[ K(\{a\}\mid d^{\{a\},z},\nu)=0. \]
Therefore
\[ \theta(\{a\},\nu)=+\infty,\qquad \theta(\varnothing,\nu)=0. \]
Only the empty bundle is allocated in the fluid mechanism, so every allocated bundle has a finite price.

Every admissible report gives utility zero. Hence the zero report maximizes utility over all reports, including unrestricted deviations, and is a nonatomic equilibrium.

Its welfare is
\[ W=0. \]
The fluid optimum allocates the item to mass \(1/2\), giving
\[ \operatorname{OPT}_\infty=\frac12. \]
Since \(c=2\), the proposed inequality would require
\[ 0=W\geq\frac{\operatorname{OPT}_\infty}{c+1}=\frac16, \]
which is false.

4. Why the finite theorem does not exclude this construction

The finite refinements are neither no-overbidding equilibria nor no-overbidding report profiles: the exceptional agent bids \(N^2\) despite having value one. The [Lucier–Borodin finite equilibrium theorem](https://arxiv.org/pdf/0909.0892v2) therefore does not apply to them.

More specifically, the finite declared welfare divided by population size is \(N\), whereas declared welfare under the limiting zero-report distribution is zero. Weak empirical convergence controls bounded test functions; it does not control this unbounded welfare contribution.

Thus the construction identifies a missing refinement condition, rather than a contradiction with the finite result.

5. Proven result for refinements preserving no overbidding

To address the substantive interpretation that excludes the exceptional bids, impose the additional condition that every finite refinement satisfies
\[ b_i^N\leq v_{\operatorname{type}(i)}(\{a\}). \]

Proposition. For one resource and \(\mathcal B=\{\varnothing,\{a\}\}\), every equilibrium in the question then satisfies
\[ W\geq\frac{\operatorname{OPT}_\infty}{c+1}. \]

The proposition allows adaptive priorities and does not require convergence of finite critical prices.

Step 1: A finite threshold inequality

Fix a finite report profile \(b\), and let \(T_i\) be the infimum bid at which agent \(i\) wins the item against \(b_{-i}\).

Component-wise monotonicity makes the winning bids an upper interval. When capacity is positive, \(T_i\) is finite: otherwise, an arbitrarily large bid by \(i\) would violate the \(c\)-approximation guarantee.

For every feasible set \(S\) of item recipients,
\[ \sum_{i\in S}T_i\leq cD, \]
where \(D\) is the rule’s declared welfare.

To prove this, fix \(\varepsilon>0\) and, for each \(i\in S\), raise its bid to
\[ b_i^*=\max\{b_i,T_i-\varepsilon\}. \]
A changed bidder was originally a loser, because a winner’s bid is at least its threshold. Its unilateral modified bid remains below its threshold, so it still loses. Strong loser-independence therefore preserves the entire allocation under all these changes. Its declared welfare remains \(D\).

The modified optimal welfare is at least \(\sum_{i\in S}(T_i-\varepsilon)\). Applying the approximation guarantee and then letting \(\varepsilon\) tend to zero proves the inequality.

Step 2: Average thresholds and take the response limit

Write \(a_t=v_t(\{a\})\). Let an optimal fluid allocation give item mass \(x_t\) to type \(t\).

In refinement \(N\), choose uniformly a subset of \(k_t^N=\lfloor Nx_t\rfloor\) agents from each type. Their union is feasible, since its size is at most \(\lfloor Nq_a\rfloor\). Averaging the preceding inequality and using finite no overbidding gives
\[ \sum_t k_t^N\operatorname{avg}_{i\text{ of type }t}\min\{T_i^N,a_t\} \leq cD_N\leq cN W_N, \]
where \(W_N\) is finite per-capita true welfare.

Let \(p_{t,N}(z)\) be the probability that a uniformly selected type-\(t\) agent wins after replacing its bid by \(z\). Except at the finitely many threshold endpoints,
\[ p_{t,N}(z)=\operatorname{avg}_{i\text{ of type }t}\mathbf1_{\{z>T_i^N\}}. \]
Consequently,
\[ \int_0^{a_t}p_{t,N}(z)\,dz =a_t-\operatorname{avg}_{i\text{ of type }t}\min\{T_i^N,a_t\}. \]

By the assumed individual-response convergence, \(p_{t,N}(z)\) tends pointwise to \(p_t(z)=K_t(\{a\}\mid d^{\{a\},z},\nu)\). Bounded convergence applies on \([0,a_t]\). Population allocation consistency also gives \(W_N\to W\). Hence, setting \(I_t=\int_0^{a_t}p_t(z)\,dz\), we obtain
\[ \sum_t x_t(a_t-I_t)\leq cW. \]

Step 3: Equilibrium utility bounds the response integral

Each \(p_t\) is nondecreasing, as a pointwise limit of nondecreasing functions. By the definition of \(\theta_t=\theta_t(\{a\},\nu)\),
\[ I_t\leq p_t(a_t)(a_t-\theta_t) \]
whenever \(p_t(a_t)>0\). If \(p_t(a_t)=0\), then \(I_t=0\), and bidding \(a_t\) yields utility zero.

Thus bidding \(a_t\) always yields utility at least \(I_t\). If \(U_t\) denotes equilibrium utility, equilibrium implies
\[ U_t\geq I_t\geq0. \]
Payments are nonnegative, so
\[ \sum_t\mu_tU_t\leq W. \]
Using \(x_t\leq\mu_t\), we conclude
\[ \operatorname{OPT}_\infty =\sum_t x_ta_t \leq cW+\sum_t x_tI_t \leq cW+\sum_t\mu_tU_t \leq(c+1)W. \]
If supply is zero, both optimal and equilibrium welfare are zero, completing that case.

This proves the stronger-refinement one-resource result. It does not settle the corresponding general bundle model.

Verdict

The counterexample is sound under weak convergence of empirical report distributions. It satisfies the stated finite allocation-rule requirements and the fluid allocation–response consistency requirement, while its limiting equilibrium has $W=0$ and $\operatorname{OPT}_\infty=1/2$.

The construction depends essentially on allowing finite refinements to contain reports outside the support of the limiting report distribution, including overbids. The task imposes no overbidding on the equilibrium distribution and does not explicitly impose it on finite refinements. Thus this dependence does not invalidate the counterexample under the stated conditions.

The supplemental one-resource result is also sound. Two minor conventions should be made explicit: the topology of empirical convergence and the interpretation of expected utility when an unreachable bundle has infinite critical price.

1. Finite allocation rule

Definition and priority conditions

For one resource, a normalized report is completely specified by its nonnegative item bid. The rule is therefore defined on every admissible finite report profile.

Both priority functions are nondecreasing: the adaptive function is zero through $h$ and jumps to positive values above $h$. Assigning the same priority function to both bundles satisfies the bundle-inclusion condition when priorities are compared at the same bid. The tie order is fixed independently of bids.

The adaptation depends only on the first accepted allocation and its declared value, as permitted.

The rule is also defined when capacity is exhausted: empty bundles remain feasible, so all remaining agents can be removed.

The approximation guarantee

The cases of zero capacity, zero bids, and a single agent are correctly handled.

With positive capacity and a positive maximum bid, the first winner has declared value $M$. Subsequently, precisely the remaining bids above $h=M/(n-1)$ have positive item priority. These agents are served in descending bid order, subject to capacity.

If all available units are filled, the selected agents have the largest bids. Otherwise, all agents above the threshold receive the item, and any additional contribution to the optimum comes from the remaining agents. The bound
$$ \sum_{i\in L}b_i\leq(n-1)h=M $$
is correct. Since the first winner contributes $M$ to $D$, the conclusion
$$ \operatorname{OPT}_{\mathrm{fin}}\leq D+M\leq2D $$
follows.

For a nonintegral supply, the effective finite capacity is its integer part, because individuals consume whole units. The same argument applies. No approximation failure is hidden in this domain issue.

Component-wise monotonicity

The argument is correct.

Increasing the first winner’s bid preserves its first allocation. Increasing another winner’s bid either makes that agent the first winner or leaves the original first winner, and hence the threshold, unchanged. In the latter case, the agent remains above the threshold and cannot move later in the allocation order.

The empty-bundle case is vacuous because admissible reports keep its bid fixed at zero.

Strong loser-independence

The first-divergence argument is valid.

If a previously accepted nonempty bundle has a changed bid, its recipient under the original execution supplies the required witness.

Otherwise, both executions have identical accepted histories and identical adaptive priority functions immediately before their first different selected pair. If both selected pairs had unchanged bids, their relative ranking under the fixed tie order could not reverse. Thus, when the original selected pair has unchanged bid, the newly selected pair must have changed bid.

The hybrid-profile argument correctly preserves the common prefix: its selected pair defeats unchanged competitors according to the original execution and the changed agent’s pairs according to the modified execution. The changed agent therefore receives the newly selected bundle in the unilateral hybrid profile.

A changed selected bid cannot belong to the empty bundle. The witness consequently satisfies the required nonemptiness condition.

2. Refinement convention and limits

Empirical convergence

The convergence argument is correct for weak convergence.

Quantile representatives approximate any probability distribution on finite nonnegative bids. Capping at $\sqrt N$, which tends to infinity, preserves that weak limit. Replacing one representative changes the empirical integral of a bounded test function by at most
$$ \frac{2\lVert f\rVert_\infty}{N}. $$
Thus the exceptional bid does not affect the weak limit.

The convention is fixed before bidding and applies to every prescribed report distribution in this one-type model.

Minor issue: The task does not specify the topology of empirical convergence. The prover explicitly chooses weak convergence, which is a natural interpretation, but the conclusion should retain this qualification. A stronger convergence requirement controlling unbounded bids would require a separate analysis.

Population allocation limit

The calculation
$$ h_N=\frac{N^2}{N-1}>N>\sqrt N $$
is correct for the even populations used.

The exceptional agent wins first. Every remaining bid lies below the adaptive threshold, so exactly one item is allocated. Consequently, the limiting item mass is zero and the limiting empty-bundle mass is one.

These limiting masses are feasible.

Individual response limit

For every fixed finite replacement bid $z$, sufficiently large populations satisfy both $z<N^2$ and $z<h_N$.

If the replaced agent is not exceptional, the exceptional first allocation persists and the replaced agent loses. The probability of selecting the exceptional agent is exactly $1/N$. Therefore the stated bound on item-winning probability is correct, irrespective of the outcome when that exceptional agent is replaced.

The limit kernels are constant:
$$ K(\{a\}\mid d,\nu)=0,\qquad K(\varnothing\mid d,\nu)=1. $$
They are measurable, exist for every admissible fixed report, and integrate to the population allocation limit. The required consistency holds.

3. Equilibrium and welfare failure

The zero-report distribution satisfies no overbidding.

Since no finite single-minded bid has positive limiting item-winning probability, the item’s critical price is infinite. The empty bundle has price zero and is the only bundle received with positive probability. Thus every allocated bundle has finite price.

Minor issue: The displayed expected-utility formula formally contains a zero-probability term with infinite price. The write-up should explicitly interpret utility as expectation over received bundles, or specify that zero-probability summands are omitted. Under that natural interpretation, every report has utility zero.

With this convention, the zero report maximizes utility over all admissible reports, including unrestricted deviations. The equilibrium claim follows.

The welfare and optimum calculations are correct:
$$ W=0,\qquad \operatorname{OPT}_\infty=\frac12. $$
For $c=2$, the requested lower bound is $1/6$, so the guarantee fails.

The finite refinements violate no overbidding, but that property was imposed only on the limiting equilibrium distribution. They also need not be finite equilibria. The finite equilibrium theorem therefore does not contradict this construction.

4. Supplemental one-resource proposition

Finite threshold inequality

The threshold argument is correct when capacity is positive.

Component-wise monotonicity gives an upper interval of winning bids. A finite threshold follows from the approximation guarantee: if the agent never won at arbitrarily large bids, the rule’s declared welfare would remain bounded by the other agents’ bids while optimal welfare became unbounded.

For the simultaneous modifications, every changed agent was originally a loser and still loses after its unilateral modification below threshold. If the combined modification changed the allocation, strong loser-independence would require one of these changed agents to win either originally or under its unilateral modification. Both possibilities have been excluded.

Thus the allocation and declared welfare remain unchanged. Applying the approximation guarantee to the modified profile and letting $\varepsilon$ decrease to zero proves the stated threshold inequality.

Averaging and passage to the limit

The randomly selected subsets are feasible because
$$ \sum_t\lfloor Nx_t\rfloor\leq\lfloor Nq_a\rfloor. $$
Averaging the threshold inequality and replacing thresholds by their truncated values preserves its direction.

Finite no overbidding correctly gives $D_N\leq NW_N$. The response-probability integral identity is unaffected by the finitely many threshold endpoints. Bounded convergence applies on each finite interval $[0,a_t]$.

Allocation–response consistency gives convergence of true welfare because the support has finitely many fixed valuation values. The resulting inequality
$$ \sum_t x_t(a_t-I_t)\leq cW $$
is justified.

Equilibrium utility bound

The limiting response probabilities are nondecreasing. They vanish below the critical price and are bounded above by $p_t(a_t)$ on the integration interval. The stated bound on $I_t$ follows.

When $p_t(a_t)=0$, both the integral and the item contribution to the deviation’s expected utility are zero, subject to the utility convention identified above.

Equilibrium therefore gives $U_t\geq I_t\geq0$. Nonnegative payments give
$$ \sum_t\mu_tU_t\leq W. $$
Combining this with $x_t\leq\mu_t$ yields the claimed approximation. The zero-supply case is correctly handled.

This establishes the supplemental proposition only for the specified one-resource bundle family. The prover accurately leaves the stronger-refinement general bundle problem unresolved.

  • Define expected utility using only bundles received with positive probability, thereby avoiding undefined products involving infinite prices.

Neither clarification requires new mathematics.
