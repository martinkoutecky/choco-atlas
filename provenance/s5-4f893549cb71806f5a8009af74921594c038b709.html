The continuous mirror question, as graded

Given finite buyer and seller type sets with rational masses totaling one on each side, rational expected values and costs under posterior \(\pi\), and per-capita externality coefficients, choose feasible match masses \(x_{as}\geq 0\) with \(\sum_s x_{as}\leq\alpha_a\) and \(\sum_a x_{as}\leq\beta_s\). For a rational threshold \(K\), decide whether there is a feasible \(x\) such that \(\sum_{a,s}x_{as}\mathbb{E}_{\pi}[u_{as}-v_{as}]-\sum_{a,s,a',s'}x_{as}x_{a's'}\mathbb{E}_{\pi}[c_{as}^{a's'}]\geq K\).

Each society is given by its support: the types with positive mass, each mass a binary rational; \(\sum_a\alpha_a=\sum_s\beta_s=1\). Put \(m=|S|\) and \(\tau=|A|+|S|\); \(\tau\) counts supported types, not possible types.
The input supplies posterior expected values \(U_{as}\), assignment costs \(V_{as}\), and directed per-capita externality coefficients \(C_{as}^{a's'}\), all binary rationals in \([0,M]\) for a supplied rational \(M>0\). No symmetry is assumed. A unit of \((a,s)\) match mass incurs cost \(C_{as}^{a's'}x_{a's'}\) from \((a',s')\) match mass; unmatched buyers incur no externalities. Equal type labels may represent distinct agents, so these coefficients also apply when labels coincide.

Result

The decision problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard even when \(m=1\), \(M=1\), every population mass is dyadic, and the externality coefficients are symmetric with zero diagonal.

Consequently, a running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. Reduction from Independent Set

We use the standard \(\mathrm{NP}\)-completeness of Independent Set: given a finite simple undirected graph \(G\) on \(n\) vertices and an integer \(k\) with \(1\leq k\leq n\), decide whether \(G\) has an independent set of size at least \(k\). This is equivalent, by graph complementation, to the classical CLIQUE problem. [Karp, *Reducibility among Combinatorial Problems*](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Let \(N\) be the smallest power of two satisfying \(N\geq n\). Add \(N-n\) isolated vertices to \(G\), obtaining a graph \(H\) on vertices \(1,\ldots,N\). Write \(\iota(G)\) and \(\iota(H)\) for their maximum independent-set sizes. Because the added vertices are isolated,

\[ \iota(H)=\iota(G)+N-n. \]

Construct the following society:

  • \(A=\{1,\ldots,N\}\) and \(S=\{s_0\}\).
  • \(\alpha_i=1/N\) for every buyer type, and \(\beta_{s_0}=1\).
  • \(M=1\), \(U_{i s_0}=1/N\), and \(V_{i s_0}=0\).
  • \(C_{i s_0}^{j s_0}=1\) when \(\{i,j\}\in E(H)\), and \(C_{i s_0}^{j s_0}=0\) otherwise.
  • \(K=(k+N-n)/N^2\).

All supported types have positive mass, and both populations have total mass \(1\). Every supplied value and coefficient lies in \([0,1]\). Since \(H\) is simple, diagonal externality coefficients vanish. Its undirected edges give symmetric coefficients, which are permitted by the problem.

Moreover, all nonintegral input numbers are dyadic because \(N\) is a power of two.

Feasibility becomes a box

Put \(x_i=x_{i s_0}\). The buyer constraints are \(0\leq x_i\leq 1/N\). These already imply the seller constraint:

\[ \sum_{i=1}^{N}x_i\leq N\cdot\frac1N=1. \]

Thus the feasible set is exactly \([0,1/N]^N\). After setting \(z_i=Nx_i\), it becomes \([0,1]^N\).

Because the externality sum uses ordered pairs, each undirected edge contributes twice. Therefore,

\[ W(x)=\frac{1}{N^2}F_H(z), \qquad F_H(z)=\sum_{i=1}^{N}z_i -2\sum_{\{i,j\}\in E(H)}z_i z_j. \]

2. Fractional allocations cannot improve this construction

We prove the exact identity

\[ \max_{z\in[0,1]^N}F_H(z)=\iota(H). \]

Step 1: Move to a box vertex without decreasing the objective

Fix all coordinates except \(z_i\). Since the diagonal coefficients vanish, the dependence on \(z_i\) is affine:

\[ F_H(z)= \left(1-2\sum_{j:\{i,j\}\in E(H)}z_j\right)z_i +\text{a term independent of }z_i. \]

An affine function on \([0,1]\) attains its maximum at an endpoint. Consequently, replacing \(z_i\) by either \(0\) or \(1\), whichever gives the larger value, does not decrease \(F_H\).

Perform this replacement successively for every coordinate. Each intermediate vector remains feasible because the feasible set is a box. The resulting vector belongs to \(\{0,1\}^N\) and has objective value at least that of the original vector.

Hence the continuous maximum equals the maximum over box vertices.

Step 2: Identify the best box vertices

A vector in \(\{0,1\}^N\) is the indicator of a vertex subset \(T\). Let \(e_H(T)\) count edges with both endpoints in \(T\). Its objective value is

\[ F_H(\mathbf 1_T)=|T|-2e_H(T). \]

If \(T\) contains an edge, choose a vertex \(v\in T\) with induced degree \(\deg_T(v)\geq1\). Removing it changes the objective by

\[ F_H(\mathbf 1_{T\setminus\{v\}}) -F_H(\mathbf 1_T) =-1+2\deg_T(v)\geq1. \]

Repeated removal terminates at an independent set \(I\), with objective at least that of \(T\). Therefore,

\[ F_H(\mathbf 1_T)\leq |I|\leq\iota(H). \]

Conversely, a maximum independent set \(I\) satisfies \(e_H(I)=0\), so \(F_H(\mathbf 1_I)=\iota(H)\). This proves the identity.

Correctness and size of the reduction

It follows that

\[ \max_x W(x)=\frac{\iota(H)}{N^2} =\frac{\iota(G)+N-n}{N^2}. \]

Thus,

\[ \exists x\text{ feasible with }W(x)\geq K \quad\Longleftrightarrow\quad \iota(G)\geq k. \]

The constructed instance has \(m=1\) and \(\tau=N+1\). Since \(N<2n\), its explicit encoding has length \(L=O(n^2\log(n+1))\), and the construction takes \(O(n^2\log(n+1))\) bit operations using an adjacency-matrix representation.

This is a polynomial-time many-one reduction, proving the asserted restricted \(\mathrm{NP}\)-hardness.

3. Membership in \(\mathrm{NP}\)

We now prove that real allocation variables admit polynomial-size rational certificates, including when the threshold equals the optimum.

Let

\[ d=|A||S|=m(\tau-m). \]

Index the match coordinates by \(1,\ldots,d\). Write the feasible polytope as

\[ P=\{x\in\mathbb R^d:Gx\leq h\}. \]

There are \(d+\tau\) inequalities: nonnegativity, buyer capacities, and seller capacities. The polytope is nonempty because it contains \(0\), and compact because every coordinate is between \(0\) and \(1\).

Let \(\ell_{as}=U_{as}-V_{as}\), and regard the externality coefficients as a matrix \(C\). Define the symmetric rational matrix \(Q=C+C^{\mathsf T}\). Then

\[ W(x)=\ell^{\mathsf T}x-\frac12x^{\mathsf T}Qx, \qquad \nabla W(x)=\ell-Qx. \]

Continuity and compactness give a global maximizer \(x^*\in P\).

A rational polytope containing equally good allocations

Let \(I\) index all inequalities tight at \(x^*\), and set \(B=G_I\). Choose a rational matrix \(D\) whose columns form a basis of \(\ker B\).

For every direction \(v\in\ker B\), both \(x^*+tv\) and \(x^*-tv\) are feasible for sufficiently small positive \(t\). Indeed, the tight inequalities remain equalities, while all other inequalities have positive slack. Optimality therefore implies

\[ D^{\mathsf T}(\ell-Qx^*)=0. \]

Consider the rational polytope

\[ R=\left\{ y\in P: By=h_I,\quad D^{\mathsf T}(\ell-Qy)=0 \right\}. \]

It is nonempty because it contains \(x^*\), and bounded because it is contained in \(P\).

We claim that every \(y\in R\) has the same surplus as \(x^*\). Set \(\delta=y-x^*\). The active equalities imply \(B\delta=0\), so \(\delta=Dv\) for some vector \(v\). Stationarity at \(x^*\) gives

\[ \delta^{\mathsf T}(\ell-Qx^*)=0. \]

Subtracting the stationarity equations at \(y\) and \(x^*\) gives \(D^{\mathsf T}Q\delta=0\), and hence

\[ \delta^{\mathsf T}Q\delta =v^{\mathsf T}D^{\mathsf T}Q\delta=0. \]

Expanding the quadratic objective now yields

\[ W(y)-W(x^*) =\delta^{\mathsf T}(\ell-Qx^*) -\frac12\delta^{\mathsf T}Q\delta =0. \]

Polynomial encoding length

Rational Gaussian elimination constructs \(D\) with encoding length polynomial in \(m,\tau,L\). Consequently, the rational coefficients defining \(R\) also have polynomial encoding length.

Choose a vertex \(y\) of the nonempty bounded polytope \(R\). At a vertex, \(d\) linearly independent defining constraints determine \(y\): otherwise a nonzero direction preserving all tight constraints would give a feasible segment through \(y\), contradicting extremality.

After clearing denominators, Cramer’s rule expresses its coordinates as ratios of integer determinants. If the resulting integer entries have at most \(b\) bits, each determinant has \(O(d(b+\log(d+1)))\) bits, by the determinant expansion bound. Thus \(y\) has total encoding length polynomial in \(m,\tau,L\).

As proved above, \(W(y)=W(x^*)\). Every yes-instance therefore has a polynomial-size rational feasible allocation meeting the threshold. Exact rational arithmetic verifies its constraints and surplus in \(\operatorname{poly}(m,\tau,L)\) time. The problem belongs to \(\mathrm{NP}\).

4. Running-time consequences

Combining the reduction and certificate argument proves \(\mathrm{NP}\)-completeness.

An exact deterministic upper bound is

\[ 2^{\,m(\tau-m)+\tau}\operatorname{poly}(m,\tau,L). \]

To obtain it, enumerate every subset \(I\) of the \(d+\tau\) inequalities. For each subset, construct \(B,D,R\) as above, test feasibility of \(R\) by rational linear programming, and evaluate \(W\) at a returned rational point when \(R\) is nonempty. Each iteration takes polynomial time.

For the subset of inequalities tight at a global maximizer, every returned point has globally optimal surplus by the preceding calculation. Every point returned for any other subset is still feasible. Thus the largest evaluated surplus is exactly the optimum.

The complexity classification concerns the specified continuous allocation problem directly. It is compatible with the supplied paper’s existence of a truthful implementation supporting a surplus-maximizing assignment; that existence statement does not provide a polynomial-time optimization algorithm. [Daddario, McLean, and Postlewaite](https://arxiv.org/pdf/2305.01477v1).
