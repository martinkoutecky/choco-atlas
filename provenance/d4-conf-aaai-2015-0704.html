The continuous mirror question, as graded

For fixed \(p\ge 3\), an instance gives a candidate set \(C\), a committee bound \(K\), a finite support \(\mathcal A\) of approval types \(A\subseteq C\) with \(|A|\le p\), binary-rational masses \(\mu_A>0\) summing to \(1\), and a rational threshold \(q\). Is there a committee \(W\subseteq C\), \(|W|\le K\), such that \(\sum_{A:A\cap W\ne\varnothing}\mu_A\ge q\)?

Packaged proof task (what the prover saw — nothing else)

Fix an integer \(p\ge 3\). An instance gives a candidate set \(C\), with \(m=|C|\), a nonnegative integer committee bound \(K\), and a threshold \(q\in\mathbb Q\).
A society is given by its support: a list \(\mathcal A\) of distinct approval types \(A\subseteq C\), each satisfying \(|A|\le p\), with positive binary-rational masses \(\mu_A\) summing to \(1\). Empty approval types are allowed.
Here \(\tau=|\mathcal A|\) is the support size, not the number of possible approval types; \(L\) is the total input bit length.
A committee is a subset \(W\subseteq C\) with \(|W|\le K\). Its represented mass is \(\sum_{A\in\mathcal A:A\cap W\ne\varnothing}\mu_A\). The decision problem asks whether some committee has represented mass at least \(q\).

Is this decision problem in \(\mathrm P\) or \(\mathrm{NP}\)-hard for each fixed \(p\ge3\)? If it is \(\mathrm{NP}\)-hard, is it nevertheless \(\mathrm{FPT}\) parameterized by \(K\)? State running times in \(m,\tau,L,K\).

Discrete MaxCover with frequencies bounded by fixed \(p\ge3\) is \(\mathrm{W[1]}\)-complete parameterized by \(K\), and is \(\mathrm{NP}\)-complete even with frequency bound \(2\). [Verified source](https://arxiv.org/html/1309.4405).
No result settling the exact normalized rational-mass formulation was verified in the literature search.

Modeling choices made when packaging the task

  • Specified K as a nonnegative integer, matching the discrete MaxCover definition; no upper bound by the number of candidates is imposed.
  • Allowed empty approval types, matching the absence of a positive lower bound on element frequencies.
  • Retained an arbitrary rational threshold q, including values outside the interval [0,1], as the graded question states.
  • Defined L as the total input bit length and K as the parameter for the FPT question.

Classification

For every fixed \(p\ge 3\), the decision problem is \(\mathrm{NP}\)-complete and is \(\mathrm{W[1]}\)-hard parameterized by \(K\). Consequently, it has no exact algorithm running in \(f(K)\operatorname{poly}(m,\tau,L)\) time unless \(\mathrm{FPT}=\mathrm{W[1]}\).

The hardness reduction below uses only dyadic masses, so it applies whether “binary-rational” means dyadic rationals or arbitrary rationals encoded in binary.

1. Exact verification and membership in \(\mathrm{NP}\)

Write each mass as \(\mu_A=a_A/b_A\), with positive integer denominator, and write \(q=u/v\), with \(v>0\). Define the common denominator

\(D_0=v\prod_{A\in\mathcal A}b_A.\)

Set \(w_A=a_A(D_0/b_A)\) and \(Q=u(D_0/v)\). For every committee \(W\),

\(\displaystyle \sum_{A:A\cap W\ne\varnothing}\mu_A\ge q \quad\Longleftrightarrow\quad \sum_{A:A\cap W\ne\varnothing}w_A\ge Q.\)

The bit length of \(D_0\) is at most the sum of the input denominator bit lengths, hence is \(O(L)\). The integers \(w_A\) and \(Q\) also have \(O(L)\) bits. Schoolbook multiplication and division therefore construct these integers in \(O((\tau+1)L^2)\) bit operations.

A certificate lists at most \(\min(K,m)\) candidates. Check its validity and scan every approval type to determine whether it intersects the committee. Each type contains at most \(p\) candidates, and the subsequent integer additions and comparison are polynomial in \(L\). A conservative bound for verification, including preprocessing, is

\(O((m+p\tau+1)L^2).\)

Thus the problem belongs to \(\mathrm{NP}\).

2. A polynomial reduction preserving \(K\)

Consider an explicit discrete MaxCover instance with universe \(U\), sets \(S_1,\ldots,S_m\), committee bound \(K\), and integer target \(t\). Each element belongs to at most \(p\) sets.

The supplied source establishes \(\mathrm{NP}\)-completeness even for frequency bound \(2\), and \(\mathrm{W[1]}\)-completeness for every fixed frequency bound \(p\ge3\), parameterized by \(K\). These are the source problems used here. [Skowron–Faliszewski, Sections 3–4](https://arxiv.org/html/1309.4405).

First handle trivial source instances. If \(t\le0\), output a fixed yes-instance; if \(t>|U|\), output a fixed no-instance. Both can use the same bound \(K\), the empty candidate set, and the sole approval type \(\varnothing\) of mass \(1\), with thresholds \(0\) and \(1\), respectively.

It remains to consider \(n=|U|\ge1\) and \(1\le t\le n\).

Construction

Let \(C=\{1,\ldots,m\}\). For each element \(e\in U\), define its approval type by

\(A_e=\{i:e\in S_i\}.\)

The frequency hypothesis gives \(|A_e|\le p\), including the possibility \(A_e=\varnothing\).

For each occurring type \(A\), let

\(c_A=|\{e\in U:A_e=A\}|.\)

Take \(c_A=0\) for absent types. Choose the power of two

\(D=2^{\lceil\log_2 n\rceil}.\)

For every nonempty type with \(c_A>0\), assign mass

\(\mu_A=c_A/D.\)

Assign the empty type mass

\(\mu_\varnothing=(c_\varnothing+D-n)/D,\)

and include it in the support precisely when this quantity is positive. Finally, retain the committee bound \(K\) and set \(q=t/D\).

Validity and encoding size

Every listed mass is positive and dyadic. Approval types are distinct because equal types were grouped. Their sizes remain at most \(p\).

The masses sum to \(1\), since

\(\displaystyle \sum_{A\ne\varnothing}\mu_A+\mu_\varnothing =\frac{n-c_\varnothing+c_\varnothing+D-n}{D}=1,\)

where a zero empty-type mass contributes nothing and is omitted.

There are at most \(n+1\) support types. Since \(n\le D<2n\), every mass and the threshold have \(O(\log(n+1))\) bits. With candidates indexed in binary, the output length is bounded by

\(O\!\left( m\log(m+1) +(n+1)\bigl(p\log(m+1)+\log(n+1)\bigr) +\log(K+1) \right).\)

Grouping types and producing this output takes polynomial time in the explicit source input length. No multiplicity is expanded.

Equivalence

Let \(W\subseteq C\). An element \(e\) is covered by the selected source sets exactly when

\(e\in\bigcup_{i\in W}S_i \quad\Longleftrightarrow\quad A_e\cap W\ne\varnothing.\)

The empty approval type is never represented. Therefore,

\(\displaystyle \sum_{A:A\cap W\ne\varnothing}\mu_A =\frac{\left|\bigcup_{i\in W}S_i\right|}{D}.\)

Consequently,

\(\displaystyle \sum_{A:A\cap W\ne\varnothing}\mu_A\ge q \quad\Longleftrightarrow\quad \left|\bigcup_{i\in W}S_i\right|\ge t.\)

The two instances have identical answers, and their committee bounds are identical.

3. Hardness consequences

For classical complexity, apply the reduction to the frequency-\(2\) MaxCover problem. Its output types have size at most \(2\), so they satisfy every fixed bound \(p\ge3\). This proves \(\mathrm{NP}\)-hardness. Together with Section 1, it proves \(\mathrm{NP}\)-completeness.

For parameterized complexity, fix \(p\ge3\) and apply the reduction to the supplied \(\mathrm{W[1]}\)-complete frequency-\(p\) MaxCover problem. The reduction is polynomial and preserves \(K\), hence is a parameterized reduction. Our problem is therefore \(\mathrm{W[1]}\)-hard.

If an exact algorithm ran in \(f(K)\operatorname{poly}(m,\tau,L)\) time, composing it with this reduction would give an \(\mathrm{FPT}\) algorithm for that \(\mathrm{W[1]}\)-complete source problem. This would imply \(\mathrm{FPT}=\mathrm{W[1]}\).

This argument establishes hardness for the rational-mass formulation; it does not assert its membership in \(\mathrm{W[1]}\).

4. Exact running time

An explicit exhaustive algorithm gives an \(\mathrm{XP}\) upper bound.

Let

\(R=\bigcup_{A\in\mathcal A}A,\qquad r=|R|\le\min(m,p\tau),\qquad k=\min(K,r).\)

Candidates outside \(R\) represent no mass and can be removed from a committee. Representation is monotone under adding candidates: every represented type remains represented. Thus every committee contained in \(R\) of size at most \(k\) can be extended to one of size exactly \(k\) without decreasing its represented mass.

It therefore suffices to enumerate the \(\binom{r}{k}\) subsets of \(R\) of size \(k\) and verify each exactly. Using Section 1, a conservative bit-operation bound is

\(O\!\left( (m+p\tau+1)L^2 +\binom{r}{k}(r+p\tau+1)L^2 \right).\)

In particular, this is bounded by

\(O\!\left( (\min(m,p\tau)+1)^K(m+p\tau+1)L^2 \right).\)

The exponent depending on \(K\) makes this an \(\mathrm{XP}\) bound, rather than an \(\mathrm{FPT}\) bound.

The boundary cases are polynomial: thresholds \(q\le0\) are always attainable; thresholds \(q>1\) are impossible; \(K=0\) permits represented mass \(0\); and \(K\ge r\) permits the maximum mass \(1-\mu_\varnothing\), taking \(\mu_\varnothing=0\) when absent.
