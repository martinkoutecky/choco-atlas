The continuous mirror question, as graded

Given a finite support of complete agent types \(\theta\), with rational masses \(\mu_\theta\) summing to one, task sets \(K_\theta\), admissible slices \(S_{\theta k}\), and values \(V_{\theta ks}\), compute a feasible mass assignment \(y_{\theta ks}\) maximizing \(\sum_{\theta,k,s} V_{\theta ks}y_{\theta ks}\). Require \(\sum_{s\in S_{\theta k}}y_{\theta ks}\leq\mu_\theta\) for each task and \(x_s=\sum_{\theta,k}y_{\theta ks}\) to satisfy the service-node and governance capacity constraints, with capacities normalized per capita. Each assigned unit of mass receives one indivisible slice. Determine the problem’s complexity in the support size, task and slice counts, DAG size, and input bit length.

Result

Exact welfare maximization is polynomial-time solvable in the stated parameters. Its welfare-threshold decision problem belongs to \(\mathrm{P}\).

The proof uses an explicit rational linear program. In fact, laminarity is unnecessary for this conclusion: the same argument applies to arbitrary service DAGs under the stated loading rule.

1. An exact linear-programming formulation

Let \(\Theta\) be the explicitly listed support, with \(|\Theta|=\tau\), and define

\(\mathcal A=\{(\theta,k,s):\theta\in\Theta,\ k\in K_\theta,\ s\in S_{\theta k}\}\).

Write \(a=|\mathcal A|\). Since each task admits at most \(m\) slices, \(a\leq Tm\).

Introduce one variable \(y_{\theta ks}\) for each element of \(\mathcal A\). Maximize

\(\displaystyle W(y)=\sum_{(\theta,k,s)\in\mathcal A}V_{\theta ks}y_{\theta ks}\)

subject to the following constraints:

  • Nonnegativity: \(y_{\theta ks}\geq0\) for every \((\theta,k,s)\in\mathcal A\).
  • Task bounds: \(\displaystyle\sum_{s\in S_{\theta k}}y_{\theta ks}\leq\mu_\theta\) for every \(\theta\in\Theta\) and \(k\in K_\theta\).
  • Service capacities: \(\displaystyle\sum_{\substack{(\theta,k,s)\in\mathcal A\\s\in D_v}}y_{\theta ks}\leq c_v\) for every \(v\in N\).
  • Governance bounds: \(\displaystyle\sum_{\substack{(\theta,k,s)\in\mathcal A\\s=r}}y_{\theta ks}\leq u_r\) for every \(r\in S\).

These are precisely the task, capacity, and governance inequalities in the question after substituting the definition of \(x_s\). Each variable occurs once in a service constraint exactly when its slice belongs to \(D_v\). Thus multiple paths from \(v\) to that slice do not multiply its load.

There are \(a\) variables and \(a+T+|N|+m\) inequalities. Every constraint coefficient belongs to \(\{-1,0,1\}\); the right-hand sides and objective coefficients are input rationals.

2. Why the formulation respects whole individual tasks

The problem defines assignments through their masses, so the preceding formulation already matches its definition. Nevertheless, we can verify that these masses can be realized jointly while each individual task receives at most one whole slice.

Fix a type \(\theta\) and represent its population mass by the interval \(I_\theta=[0,\mu_\theta)\), equipped with length measure. For each task \(k\), independently partition this interval into disjoint half-open intervals of lengths \(y_{\theta ks}\), one for each admissible slice \(s\), followed by an unserved interval of length

\(\displaystyle\mu_\theta-\sum_{s\in S_{\theta k}}y_{\theta ks}\).

This last length is nonnegative by the task constraint. Assign task \(k\) to slice \(s\) precisely on its corresponding interval.

For every point of \(I_\theta\), each task therefore has exactly one label: an admissible slice or “unserved.” Different tasks may be served simultaneously, as permitted by the absence of cross-task constraints.

Taking the common refinement of all these interval partitions gives complete task-assignment profiles. Their masses reproduce every \(y_{\theta ks}\). Consequently:

  • The mass of assignments to slice \(s\) is exactly \(x_s\).
  • The load at node \(v\) is exactly \(\sum_{s\in D_v}x_s\).
  • Additive welfare is exactly \(W(y)\).

Conversely, any individual assignment induces nonnegative masses satisfying all the displayed inequalities, with the same welfare. Hence the linear program is exact, rather than a relaxation.

This construction also avoids enumerating all possible profiles: the common refinement has only polynomially many intervals, because its endpoints come from the explicitly listed task partitions.

3. Polynomial construction and exact rational optimization

Each \(D_v\) can be computed by graph reachability. For example, traverse the reversed DAG from each slice sink and record which nodes reach it. This takes \(O(m(|N|+|E|)+|N|)\) time. The linear program can then be written explicitly in polynomial time.

Its complete binary encoding has polynomial length in \(m,\tau,T,|N|,|E|,L\). Repeating a type mass in several task constraints causes only polynomial growth because there are exactly \(T\) listed tasks.

The feasible region is nonempty: the zero assignment satisfies every constraint. Moreover, each variable satisfies

\(0\leq y_{\theta ks}\leq\mu_\theta\leq1\),

because it is one nonnegative summand in its task constraint. Thus the feasible region is bounded and closed, and the linear objective attains its maximum. If \(a=0\), the optimum is simply zero.

We now apply the standard exact rational linear-programming theorem: a nonempty bounded polyhedron given by explicit rational inequalities can be optimized exactly in time polynomial in the full binary encoding length, returning a rational optimal solution. One precise formulation, including an optimal-vertex output guarantee, is [Theorem 1 in Yang Cai’s thesis, p. 38](https://www.cs.yale.edu/homes/cai/publication/thesis/thesis.pdf#page=38). Its hypotheses hold here: the feasible region is a nonempty polytope, all data are rational, and testing the explicit inequalities provides a polynomial-time separation oracle.

For completeness, the output-size issue can also be checked directly. Let \(Q\) be the product of the denominators appearing in the input masses and bounds. Its binary length is \(O(L)\), and it clears every constraint right-hand side.

At a vertex, select \(a\) linearly independent active constraints and write their equations as \(By=b\). Such constraints exist: otherwise a nonzero direction orthogonal to all active constraint normals would permit sufficiently small feasible movement in both directions, contradicting extremality.

The matrix \(B\) is an invertible integer matrix with entries in \(\{-1,0,1\}\), and \(Qb\) is integral. Cramer’s rule gives

\(\displaystyle y_i=\frac{\det B_i(Qb)}{Q\det B}\),

where \(B_i(Qb)\) replaces column \(i\) of \(B\) by \(Qb\). Hadamard’s inequality bounds \(|\det B|\) by \(a^{a/2}\). Each coordinate of \(Qb\) has \(O(L)\) bits, so the same inequality gives numerator and denominator lengths of \(O(L+a\log(a+1))\).

Therefore an optimal vertex has polynomial binary encoding length. Exact optimization does not require expanding rational masses into a population whose size depends on denominator magnitudes.

4. Welfare-threshold decision and conclusion

Given a binary-rational threshold \(h\), compute an exact maximizing assignment \(y^*\), evaluate the rational number \(W(y^*)\), and compare it with \(h\). These arithmetic operations have polynomial bit complexity because the input and output rational encodings have polynomial length.

The answer to the threshold problem is “yes” exactly when \(W(y^*)\geq h\). Thus the decision problem belongs to \(\mathrm{P}\); it could be NP-hard under polynomial-time reductions only if \(\mathrm{P}=\mathrm{NP}\).

This classification follows directly from the rational-mass model and does not rely on the discrete guarantee mentioned in the question.
