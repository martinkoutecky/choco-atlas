The continuous mirror question, as graded

Given rational type masses \(\mu\), a symmetric binary type-adjacency matrix \(A\), and \(k\), compute \(p_{aj} \ge 0\) with row sums \(\mu\) and column sums \(1/k\) such that no coalition represented by \(\zeta_{aj} \le p_{aj}\) of total mass \(1/k\) satisfies \(\sum_b A_{ab} z_b > (2k-1) \sum_b A_{ab} p_{bj}\) for every participating type \(a\) assigned from group \(j\), where \(z_a = \sum_j \zeta_{aj}\).

Packaged proof task (what the prover saw — nothing else)

A society is atomless and given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_a\), summing to \(1\). The support size \(\tau\) counts listed types, not possible types. Input also includes a symmetric matrix \(A\in\{0,1\}^{\tau\times\tau}\) and an integer \(k\ge2\). Here \(m=\tau\) is the matrix dimension, and \(L\) is the total input bit length; state running times in \(m,\tau,k,L\).
The entry \(A_{ab}\) specifies friendship between distinct individuals of types \(a,b\); diagonal entries may be either binary value. A type-\(a\) individual's utility for a group with type masses \(x_b\) is \(\sum_b A_{ab}x_b\).
A balanced assignment is a rational matrix \(p\ge0\) satisfying \(\sum_{j=1}^k p_{aj}=\mu_a\) and \(\sum_{a=1}^{\tau}p_{aj}=1/k\); types may be split among groups.
A coalition is any real matrix \(\zeta\) with \(0\le\zeta_{aj}\le p_{aj}\) and \(\sum_{a,j}\zeta_{aj}=1/k\). Write \(z_a=\sum_j\zeta_{aj}\). It blocks at factor \(2k-1\) if \(\sum_b A_{ab}z_b>(2k-1)\sum_b A_{ab}p_{bj}\) for every pair \((a,j)\) with \(\zeta_{aj}>0\). An assignment with no such coalition is in the \((2k-1,0)\)-core.

Can a balanced assignment in the \((2k-1,0)\)-core always be computed in time polynomial in \(m,\tau,k,L\), or is this search problem NP-hard?

For finite undirected friendship graphs with \(n\ge k^2+k\), a balanced \((2k-1,0)\)-core partition can be computed in polynomial time ([Li et al.](https://www.cs.toronto.edu/~nisarg/papers/fair-partition.pdf)).
For finite graphs with \(k=2\), a \((2+\varepsilon)\)-core partition can be computed in polynomial time for fixed \(\varepsilon>0\) ([Viswanathan](https://arxiv.org/abs/2605.03238)). No result settling the exact atomless search problem above was identified.

Modeling choices made when packaging the task

  • Normalized total mass to 1, as required by k column sums of 1/k, and interpreted each positive type mass as divisible atomless population.
  • Allowed binary diagonal entries to describe friendships between distinct individuals of the same type; an individual's own singleton has zero mass.
  • Required rational assignment entries for finite computational output, while allowing real coalition masses and imposing strict improvement exactly where coalition participation is positive.
  • Took k≥2 and identified m with the adjacency-matrix dimension τ; there is no separate ground set.
  • The finite condition n≥k²+k has no population-count counterpart in an atomless probability society; imposed no analogous restriction on support size τ.

Result

The search problem is polynomial-time solvable. In fact, uniform type splitting produces a balanced assignment in the stronger \((k,0)\)-core.

This uses precisely the stated permission to split every type among all groups.

Construction and proof

For each type \(a\) and group \(j\), set \(p_{aj}=\mu_a/k\). These entries are nonnegative rational numbers, and balance follows from

\(\sum_{j=1}^k p_{aj}=\mu_a\), and \(\sum_{a=1}^{\tau}p_{aj}=(1/k)\sum_{a=1}^{\tau}\mu_a=1/k\).

Define \(d_a=\sum_{b=1}^{\tau}A_{ab}\mu_b\), the utility of a type-\(a\) individual for the whole society. Their utility in every assigned group is

\(\sum_b A_{ab}p_{bj}=d_a/k\).

Now consider any feasible real coalition \(\zeta\), and write \(z_b=\sum_j\zeta_{bj}\). Its capacity constraints imply, for every type \(b\),

\(0\le z_b\le\sum_jp_{bj}=\mu_b\).

Since every entry of \(A\) is nonnegative, for every type \(a\) and group \(j\),

\(\sum_b A_{ab}z_b\le\sum_b A_{ab}\mu_b=d_a=k\sum_b A_{ab}p_{bj}\).

Consequently, no pair \((a,j)\) can satisfy the strict blocking inequality at factor \(k\). In particular, no feasible coalition blocks at that factor.

Finally, \(k\le2k-1\) because \(k\ge2\). Assigned utilities are nonnegative, so the same inequality excludes blocking at factor \(2k-1\). This proves the required guarantee, including when some utilities are zero and regardless of the diagonal entries of \(A\).

Running time and encoding

Write each input mass as \(\mu_a=r_a/s_a\), with positive binary integers. Output each entry as the rational number \(r_a/(ks_a)\); reduction to lowest terms is unnecessary.

Every entry has bit length \(O(L+\log(k+1))\). Reading the input, multiplying denominators, and writing all \(\tau k\) entries takes, for example, the conservative bound

\(O\!\left(m^2+L+\tau k\bigl(L+\log(k+1)\bigr)^2\right)\)

bit operations using elementary integer arithmetic. Here \(m=\tau\). Thus the running time and output length are polynomial in \(m,\tau,k,L\), without expanding the masses into individual agents.

Sharpness of the stronger uniform guarantee

The factor \(k\) is tight for this construction. Take two types with masses \(\mu_1=1/k\) and \(\mu_2=1-1/k\), and let \(A_{11}=1\), with every other entry zero.

Under uniform splitting, every type-\(1\) individual receives utility \(1/k^2\). The coalition consisting of all type-\(1\) individuals is feasible, has mass \(1/k\), and gives each member utility \(1/k\). It therefore blocks at every nonnegative factor \(\alpha<k\).

This sharpness statement concerns uniform splitting only; the construction above already settles the requested factor \(2k-1\).

\[ \sum_b A_{ab}p_{bj}=d_a/k \]
for every type \(a\) and group \(j\). The utility is therefore independent of the assigned group, as claimed.

\[ \sum_b A_{ab}z_b\le d_a =k\sum_b A_{ab}p_{bj}. \]
This holds for every pair \((a,j)\), including all pairs with \(\zeta_{aj}>0\). Consequently, the strict inequality required for blocking at factor \(k\) cannot hold. Symmetry is not needed for the argument, but this does not affect its validity under the stated assumptions.

\[ O\!\left(m^2+L+\tau k\bigl(L+\log(k+1)\bigr)^2\right) \]

The strict blocking inequality therefore holds exactly when \(\alpha<k\). The prover correctly limits this sharpness claim to the uniform construction.
