The continuous mirror question, as graded

For finite \(p\), let \(D_p(\mu,X)=\left(\sum_{t\in T}\mu_tw_t^p\sum_{j\ne k}|R^t_{jk}-X_{jk}|^p\right)^{1/p}\); let \(D_\infty(\mu,X)=\max_{t\in T,\ j\ne k}w_t|R^t_{jk}-X_{jk}|\).

Given \(m\geq2\) criteria, a society is specified by its support \(T\): the list of its \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has rational off-diagonal pairwise judgments \(R^t_{jk}\) and a nonnegative rational influence weight \(w_t\). Judgments may be signed; any additional preference restrictions are explicit input constraints.
The consensus consists of real coordinates \(X_{jk}\), for \(j\ne k\), constrained to a nonempty rational polyhedron \(F\), given by an explicit list of weak linear inequalities. Diagonal entries are ignored.
Let \(\varnothing\ne P\subseteq\{1,2,\infty\}\), with rational weights \(\lambda_p\geq0\) not all zero. Define \(D_p(\mu,X)=(\sum_{t\in T}\mu_tw_t^p\sum_{j\ne k}|R^t_{jk}-X_{jk}|^p)^{1/p}\) for finite \(p\), and \(D_\infty(\mu,X)=\max_{t\in T,\,j\ne k}w_t|R^t_{jk}-X_{jk}|\).
The objective is \(f(X)=\sum_{p\in P}\lambda_pD_p(\mu,X)\). Its exact threshold problem asks, given a binary-rational \(q\geq0\), whether some \(X\in F\) satisfies \(f(X)\leq q\), including equality.
Is this exact threshold problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), the number of inequalities defining \(F\), and the total input bit length \(L\).
For finite lists of individuals, consensus minimization is equivalent to a nonnegative weighted sum of residual norms; this is a reformulation, not an exact bit-complexity classification. [Salas-Molina, Bistaffa, and Rodríguez-Aguilar](https://arxiv.org/html/2401.07818v2)

Result

The exact threshold problem is in \(\mathrm{P}\), including equality.

Let \(s\) be the number of inequalities defining \(F\). A deterministic algorithm runs in

\[ (m^{2}\tau+s+L)^{O(1)} \]

bit operations. Its dependence is on the explicitly listed support size \(\tau\).

The proof has two ingredients: the optimal value has algebraic degree at most two with polynomially bounded coefficient lengths, and it can be approximated to exponentially small additive error using polynomially many rational convex quadratic programs.

1. Notation and the linear cases

Write \(n=m(m-1)\), enumerate the off-diagonal coordinates, and identify \(X\) with \(x\in\mathbb{R}^{n}\). Let \(r_t\in\mathbb{Q}^{n}\) be the judgment vector of type \(t\). Set \(\lambda_p=0\) when \(p\notin P\), and define

\[ h(x)=\lambda_1\sum_{t,i}\mu_tw_t|x_i-r_{ti}| +\lambda_\infty\max_{t,i}w_t|x_i-r_{ti}|. \]

Thus \(h\) is nonnegative, convex, and piecewise affine, with rational coefficients.

If every \(w_t=0\), the objective vanishes identically. The answer is yes because \(F\neq\varnothing\) and \(q\geq0\).

If \(\lambda_2=0\), introduce variables satisfying

\[ u_{ti}\geq x_i-r_{ti},\qquad u_{ti}\geq r_{ti}-x_i, \]

and

\[ z\geq w_t(x_i-r_{ti}),\qquad z\geq w_t(r_{ti}-x_i). \]

The threshold condition is equivalent to feasibility of these inequalities, \(x\in F\), and

\[ \lambda_1\sum_{t,i}\mu_tw_tu_{ti}+\lambda_\infty z\leq q. \]

Indeed, any such variables give an upper bound on \(h(x)\); conversely, choosing the actual absolute residuals and their weighted maximum gives the required variables whenever \(h(x)\leq q\).

This is rational linear feasibility with \(O(\tau n)\) variables and \(O(s+\tau n)\) inequalities, and therefore is solvable exactly in polynomial time.

For the remainder, assume \(\gamma=\lambda_2>0\) and some \(w_t>0\).

2. The quadratic residual and a bounded feasible set

Define

\[ a=\sum_t\mu_tw_t^2,\qquad b=\frac{1}{a}\sum_t\mu_tw_t^2r_t,\qquad \beta=\sum_t\mu_tw_t^2\|r_t-b\|_2^2. \]

Because all masses are positive and some influence weight is positive, \(a>0\). All three quantities are rational, and \(\beta\geq0\).

Expanding the squares and using
\(\sum_t\mu_tw_t^2(r_t-b)=0\) gives

\[ D_2(\mu,x)^2 =\sum_t\mu_tw_t^2\|x-r_t\|_2^2 =a\|x-b\|_2^2+\beta. \]

Put \(Q(x)=a\|x-b\|_2^2+\beta\). The objective becomes

\[ f(x)=h(x)+\gamma\sqrt{Q(x)}. \]

Its rational data have encoding lengths polynomial in the original input length.

Moreover,

\[ f(x)\geq\gamma\sqrt a\,\|x-b\|_2. \]

Consequently, \(f\) is coercive. Since \(F\) is nonempty and closed, \(f\) attains a minimum on \(F\). Denote its minimum value by \(v\).

We can restrict the optimization to a rational polytope of polynomial encoding length. Obtain a rational \(x_0\in F\) by exact linear programming, and set

\[ U=h(x_0)+\gamma\bigl(Q(x_0)+1\bigr). \]

The inequality \(\sqrt y\leq y+1\) for \(y\geq0\) implies \(v\leq f(x_0)\leq U\). Every minimizer therefore satisfies

\[ \|x-b\|_2\leq\frac{U}{\gamma\sqrt a}. \]

Since \(\sqrt a\geq\min\{1,a\}\), define the rational number

\[ R=1+\max_i|b_i|+\frac{U}{\gamma\min\{1,a\}}, \qquad \mathcal K=F\cap[-R,R]^n. \]

Then \(\mathcal K\) is nonempty, compact, and contains every minimizer. All its defining coefficients have polynomial encoding length.

3. The optimal value has degree at most two

We prove a stronger statement needed for exact threshold comparisons:

There are rationals \(\delta,\rho\), with \(\rho\geq0\), such that
\(v=\delta+\sqrt\rho\). Their numerator and denominator lengths admit an effectively computable polynomial bound in the input size.

Partition the space into closed rational polyhedral cells by choosing signs for all residuals \(x_i-r_{ti}\) and choosing a maximizer among the affine expressions
\(\pm w_t(x_i-r_{ti})\). On each cell, \(h\) is one rational affine function,

\[ h(x)=c^{\mathsf T}x+d. \]

Ties cause no difficulty: the cells cover the space, and the selected expression remains equal to \(h\) on each cell. Although there can be exponentially many cells, we will not enumerate them.

Choose a minimizer \(x_*\) and a cell containing it. Intersect that cell with \(\mathcal K\), and let \(H\) be the affine hull of its smallest face containing \(x_*\). Let \(V\) be the direction space of \(H\).

If \(Q(x_*)=0\), then \(x_*=b\) and \(\beta=0\), because \(a>0\). Thus \(v=h(b)\) is rational, giving the claimed form with \(\rho=0\).

Suppose instead that \(Q(x_*)>0\), and write \(s_*=\sqrt{Q(x_*)}\). Let \(p\) be the orthogonal projection of \(b\) onto \(H\), and \(E\) the orthogonal projector onto \(V\). These are rational. Explicitly, if

\[ H=\{x:Ax=e\} \]

with \(A\) having independent rows, then

\[ p=b+A^{\mathsf T}(AA^{\mathsf T})^{-1}(e-Ab), \qquad E=I-A^{\mathsf T}(AA^{\mathsf T})^{-1}A. \]

The matrix \(AA^{\mathsf T}\) is invertible because the rows of \(A\) are independent. If \(H=\mathbb{R}^n\), use \(p=b\) and \(E=I\).

Write \(x_*=p+u\), where \(u\in V\), and put \(\ell=Ec\).

Because \(x_*\) lies in the relative interior of the selected face, every direction in \(V\) permits sufficiently small movements in both signs within that face. The objective is differentiable near \(x_*\) on this cell. Its directional derivative must therefore vanish on \(V\), yielding

\[ \ell+\frac{\gamma a}{s_*}u=0, \qquad u=-\frac{s_*}{\gamma a}\ell. \]

Define the rational quantities

\[ \kappa=a\|p-b\|_2^2+\beta, \qquad \eta=1-\frac{\|\ell\|_2^2}{\gamma^2a}. \]

Orthogonality of \(p-b\) and \(u\) gives

\[ s_*^2=\kappa+a\|u\|_2^2 =\kappa+\frac{s_*^2\|\ell\|_2^2}{\gamma^2a}, \]

so \(\eta s_*^2=\kappa\). With \(\delta=c^{\mathsf T}p+d\), we also obtain

\[ v=\delta+c^{\mathsf T}u+\gamma s_* =\delta+\gamma\eta s_*. \]

There are two cases.

  • If \(\kappa>0\), then \(\eta>0\), and

\[ v=\delta+\sqrt{\gamma^2\kappa\eta}. \]

  • If \(\kappa=0\), then \(\eta=0\), since \(s_*>0\), and \(v=\delta\).

This proves the asserted algebraic form.

To verify the coefficient-length bound, observe first that cell coefficients are sums of at most polynomially many products of input rationals. Their lengths consequently have a computable polynomial bound, uniformly over all sign and maximizer choices.

The affine hull \(H\) can be specified using at most \(n\) independent active equations from that cell and \(\mathcal K\). Clearing denominators and applying Hadamard’s determinant bound shows that the inverse matrices in the projection formulas have polynomially bounded rational lengths. The displayed formulas for \(p,E,\ell,\kappa,\eta,\delta,\rho\) then preserve polynomial length.

This is an effective uniform bound: propagate bounds for rational sums, products, and determinants through these formulas, using \(n\) as the maximum matrix dimension. It does not require knowing which face contains the minimizer.

Choose a computable integer \(B\geq1\), polynomially bounded in the input size, such that the reduced numerators and denominators of \(\delta,\rho,q\) are all at most \(2^B\) in absolute value.

4. Separation from the rational threshold

We now show that whenever \(v\neq q\),

\[ |v-q|\geq\Delta,\qquad \Delta=2^{-6B-2}. \]

Put \(\zeta=\delta-q\). Its denominator is at most \(2^{2B}\), and \(|\zeta|\leq2^{B+1}\).

If \(\zeta>0\), then \(v-q\geq\zeta\geq2^{-2B}\). If \(\zeta=0\) and \(v\neq q\), then \(\rho>0\), so \(|v-q|=\sqrt\rho\geq2^{-B/2}\).

If \(\zeta<0\), rationalization gives, whenever \(v\neq q\),

\[ |v-q| =\frac{|\rho-\zeta^2|}{\sqrt\rho+|\zeta|}. \]

The nonzero rational numerator has denominator at most \(2^{5B}\), hence magnitude at least \(2^{-5B}\). The denominator is at most \(2^{B+2}\). Thus the quotient is at least \(2^{-6B-2}\), as claimed.

The equality case is excluded from this separation statement and will be accepted explicitly by the decision algorithm.

5. Polynomial-time additive approximation

We next construct, for any positive rational \(\varepsilon\), a rational number \(V_\varepsilon\) satisfying

\[ v\leq V_\varepsilon\leq v+\varepsilon \]

in time polynomial in the input size and \(\log(1/\varepsilon)\).

We use the classical exact convex quadratic programming theorem: a rational positive semidefinite quadratic objective over a nonempty rational polytope has an exact rational minimizer computable in polynomial bit time. Singular Hessians and lower-dimensional polytopes are permitted. See [Kozlov, Tarasov, and Khachiyan, *Polynomial solvability of convex quadratic programming*](https://www.mathnet.ru/eng/dan43059).

For \(t>0\), define

\[ G(t)=\min_{x\in\mathcal K} \left[h(x)+\frac{\gamma}{2}\left(\frac{Q(x)}t+t\right)\right]. \]

For rational \(t\), this is a rational convex quadratic program: lift \(h\) using the variables from Section 1. To make the lifted set compact, set

\[ C=R+\max_{t,i}|r_{ti}|,\qquad W=\max_t w_t, \]

and add \(0\leq u_{ti}\leq C\) and \(0\leq z\leq WC\). For every \(x\in\mathcal K\), its actual residuals satisfy these bounds. Thus these additions preserve the projected objective.

The lifted quadratic Hessian is positive semidefinite, and the lifted feasible set is a nonempty rational polytope. The quadratic programming theorem therefore applies. In particular, we can compute \(G(t)\) exactly as a rational number.

The minimizing \(x\), denoted \(x_t\), is unique because \(a>0\) makes \(h(x)+\gamma Q(x)/(2t)\) strictly convex in \(x\).

The quadratic-over-linear function \(Q(x)/t\) is jointly convex for \(t>0\), so \(G\) is convex. Also,

\[ G'(t)=\frac{\gamma}{2}\left(1-\frac{Q(x_t)}{t^2}\right). \]

For completeness, uniqueness and compactness imply continuity of \(x_t\): any subsequential limit as the parameter approaches \(t\) must minimize the limiting objective, hence must equal \(x_t\). Comparing the objectives at \(x_t\) and \(x_{t+u}\), dividing the resulting upper and lower bounds by \(u\), and taking \(u\to0\) gives the displayed derivative. Thus the derivative is exactly computable and rational at every rational parameter.

The inequality \(Q(x)/t+t\geq2\sqrt{Q(x)}\) gives \(G(t)\geq v\).

Fix a minimizer \(x_*\), and set \(t_*=\sqrt{Q(x_*)}\). If \(t_*>0\), then \(G(t_*)=v\). If \(t_*=0\), evaluating at \(x_*\) gives \(G(t)\leq v+\gamma t/2\).

Take

\[ S=\frac U\gamma+1,\qquad \alpha=\min\left\{\frac S2,\frac{\varepsilon}{\gamma}\right\}. \]

Since \(t_*\leq U/\gamma<S\), the minimum of \(G\) on \([\alpha,S]\) lies between \(v\) and \(v+\varepsilon/2\). Indeed, if \(t_*\geq\alpha\), it equals \(v\); otherwise,

\[ G(\alpha)\leq v+\frac{\gamma(\alpha-t_*)^2}{2\alpha} \leq v+\frac{\gamma\alpha}{2} \leq v+\frac{\varepsilon}{2}. \]

We also have a computable rational Lipschitz bound on this interval. Write \(h_0=h(x_0)\) and \(Q_0=Q(x_0)\). Evaluating at \(x_0\), and using \(h(x_t)\geq0\), yields

\[ Q(x_t)\leq Q_0+t^2+\frac{2th_0}{\gamma}. \]

Consequently, for \(\alpha\leq t\leq S\),

\[ |G'(t)|\leq D, \qquad D=\frac{\gamma}{2} \left(1+\frac{Q_0+S^2+2Sh_0/\gamma}{\alpha^2}\right). \]

All these rationals have encoding length polynomial in the input size and \(\log(1/\varepsilon)\).

Minimize \(G\) on \([\alpha,S]\) by derivative bisection:

  • If \(G'(\alpha)\geq0\), use \(\alpha\).
  • If \(G'(S)\leq0\), use \(S\).
  • Otherwise, bisect, retaining an interval whose endpoint derivatives have opposite signs. A zero derivative is already a minimizer.

Stop when the interval width is at most \(\varepsilon/(2D)\). It contains a minimizer, and evaluating \(G\) at either endpoint incurs error at most \(\varepsilon/2\). The resulting rational value \(V_\varepsilon\) therefore satisfies the required bounds.

The number of bisections is polynomial in the input size and \(\log(1/\varepsilon)\). Every parameter queried has polynomial encoding length, and every quadratic program has \(O(\tau n)\) variables and \(O(s+\tau n)\) inequalities. This establishes the claimed polynomial approximation time.

6. Exact decision and running time

Compute the bound \(B\) from Section 3, set \(\Delta=2^{-6B-2}\), and run Section 5 with \(\varepsilon=\Delta/4\). Accept exactly when

\[ V_\varepsilon\leq q+\frac{\Delta}{2}. \]

If \(v\leq q\), including equality, then

\[ V_\varepsilon\leq v+\frac{\Delta}{4} \leq q+\frac{\Delta}{4}, \]

so the algorithm accepts.

If \(v>q\), Section 4 gives \(v\geq q+\Delta\). Since \(V_\varepsilon\geq v\), the algorithm rejects.

Because the minimum is attained, deciding \(v\leq q\) is exactly the requested existential threshold problem.

Finally, \(B\) is polynomially bounded, so \(\log(1/\varepsilon)\) is polynomially bounded. The algorithm makes polynomially many quadratic-programming calls, each with polynomially encoded rational data. Substituting \(n=m(m-1)\) gives total deterministic bit complexity

\[ (m^2\tau+s+L)^{O(1)}. \]

No expansion of rational masses into individual copies is used.
