The continuous mirror question, as graded

Fix two values \(l<h\) with constant ratio \(h/l\), a finite set \(\Theta\) of public classes, and a rational distribution \(\nu\) over \(\Theta\times\{l,h\}\) of binary encoding length \(L\). Feasibility is a downward-closed set \(\mathcal F\subseteq[0,1]^{\Theta}\), given by a membership oracle, of feasible aggregate service masses. A black-box allocation rule \(\mathcal A\) maps each such distribution to service rates \(x_{\theta,r}(\nu)\in[0,1]\), with \(y_\theta=\sum_{r\in\{l,h\}}\nu_{\theta,r}x_{\theta,r}(\nu)\in\mathcal F\). Does there exist a uniform wrapper running in time polynomial in the support size \(\tau\) and \(L\), with polynomially many adaptive queries to \(\mathcal A\) and the feasibility oracle, that for every \(\mathcal A,\mathcal F,\nu\) returns feasible rates monotone in reported value, \(x_{\theta,h}(\nu)\ge x_{\theta,l}(\nu)\), and welfare at least \(c\sum_{\theta,r}r\nu_{\theta,r}x_{\theta,r}(\nu)\) for some fixed \(c>0\)?

Packaged proof task (what the prover saw — nothing else)

Fix positive rational values \(0<l<h\), with \(h/l\) constant, and a nonempty public class set \(\Theta\); write \(m=|\Theta|\).
A society is a probability distribution \(\nu\) on \(\Theta\times\{l,h\}\), given by its support: the list of its \(\tau\) positive-mass types and their binary rational masses. Thus \(\tau\) is the support size, not the number \(2m\) of possible types. Let \(L\) be the total input bit length, including the class list.
Feasibility is a nonempty set \(\mathcal F\subseteq[0,1]^\Theta\), accessible only by a membership oracle, satisfying \(y\in\mathcal F\) and \(0\le z\le y\Rightarrow z\in\mathcal F\). Convexity is not assumed.
An allocation oracle \(\mathcal A\) accepts any rational probability distribution \(\mu\) on the same type space and returns rates \(a_{\theta,r}(\mu)\in[0,1]\) for every type, satisfying \((\sum_r\mu_{\theta,r}a_{\theta,r}(\mu))_{\theta\in\Theta}\in\mathcal F\). Both oracles remain fixed throughout a computation.
Queries, allocation responses and outputs use exact binary rationals; allocation-response length is bounded by a fixed polynomial in query length. Oracle calls have unit cost, with reading and writing counted separately.
A wrapper may query both oracles adaptively and must return rates \(x_{\theta,r}(\nu)\in[0,1]\) for all types, including those of zero mass. Every returned vector must satisfy \((\sum_r\nu_{\theta,r}x_{\theta,r}(\nu))_\theta\in\mathcal F\) and \(x_{\theta,h}(\nu)\ge x_{\theta,l}(\nu)\) for every \(\theta\), at the same distribution \(\nu\). Randomization is allowed; these requirements hold almost surely, and welfare is evaluated in expectation.

Does a uniform wrapper with running time and adaptive query count polynomial in \(m,\tau,L\) exist that, for every \(\mathcal A,\mathcal F,\nu\), guarantees \(\mathbb E[\sum_{\theta,r}r\nu_{\theta,r}x_{\theta,r}(\nu)]\ge c\sum_{\theta,r}r\nu_{\theta,r}a_{\theta,r}(\nu)\) for some constant \(c>0\) independent of \(m,\tau,L,\mathcal A,\mathcal F,\nu\), or is such a constant-fraction guarantee impossible?

For finite agents with binary allocations and constant \(h/l\), no polynomial-time monotone transformation preserves a constant fraction of welfare at every valuation profile, even with adaptive feasibility queries and randomization ([Suksompong](https://link.springer.com/article/10.1007/s00224-018-9898-6)).
For the same discrete setting, a polynomial-time transformation does preserve an \(l/h\) fraction of the worst-case approximation ratio, a different benchmark ([Suksompong](https://link.springer.com/article/10.1007/s00224-018-9898-6)). No result settling exactly the distribution-and-aggregate-feasibility problem above was located.

Modeling choices made when packaging the task

  • Required positive rational values and a nonempty class set, excluding zero or negative values for which the intended multiplicative welfare benchmark degenerates.
  • Normalized society mass to one and required a nonempty feasibility set.
  • Defined m as the explicitly listed number of public classes and included their encoding in L, so zero-mass classes do not create an unaccounted output-size requirement.
  • Specified that allocation queries may use any rational distribution on the same fixed type space, as the graded question imposes no restriction preserving class marginals.
  • Required rates and monotonicity for absent types, interpreting monotonicity exactly as the graded within-distribution inequality.
  • Specified exact rational oracle interfaces and polynomially bounded allocation-response lengths to make polynomial bit complexity meaningful.
  • Allowed randomized wrappers with feasibility and the stated within-distribution monotonicity almost surely, and the welfare guarantee in expectation; the graded question leaves randomized guarantees unspecified.
  • Allowed the preservation constant to depend on the fixed value ratio, but not on the society, its encoding, or either oracle.

Result

A deterministic polynomial-time wrapper exists with \(c=1\). It makes one allocation-oracle query and no feasibility queries.

The construction preserves every class’s aggregate allocation exactly. Consequently, neither convexity nor downward closure is needed. We choose transfer parameters to be dyadic rationals, so the construction also respects a literal interpretation of “binary rationals” as finite binary expansions.

Construction

Query \(\mathcal A\) at \(\nu\), and write \(a_{\theta,r}=a_{\theta,r}(\nu)\). For each class, define

\(p_{\theta,l}=\nu_{\theta,l}\), \(p_{\theta,h}=\nu_{\theta,h}\), and \(q_\theta=p_{\theta,l}a_{\theta,l}+p_{\theta,h}a_{\theta,h}\),

taking unlisted masses to be zero. The oracle guarantee gives \((q_\theta)_{\theta\in\Theta}\in\mathcal F\).

Process each class independently. Suppress its index and write \(p_l,p_h,\alpha=a_{\theta,l},\beta=a_{\theta,h}\).

  • If \(p_l=p_h=0\), return \(x_l=x_h=0\).
  • If \(p_l>0\) and \(p_h=0\), return \(x_l=x_h=\alpha\).
  • If \(p_l=0\) and \(p_h>0\), return \(x_l=0\), \(x_h=\beta\).
  • If both masses are positive and \(\alpha\leq\beta\), return the original rates.
  • If both masses are positive and \(\alpha>\beta\), perform the transfer below.

For the last case, put \(p=p_l+p_h\) and \(q=p_l\alpha+p_h\beta\), and define

\(T=\dfrac{\alpha-\beta}{p}\), \(\qquad U=\min\left\{\dfrac{\alpha}{p_h},\dfrac{1-\beta}{p_l}\right\}\).

We will prove that \(U>T>0\). Choose a dyadic rational \(s\) with \(T\leq s<U\), and return

\(x_l=\alpha-p_hs\), \(\qquad x_h=\beta+p_ls\).

Here is an explicit choice of \(s\). Compute \(U-T=u/v\) with positive integers \(u,v\), and let \(k\) be the binary bit length of \(v\). Set

\(s=2^{-k}\left\lceil 2^kT\right\rceil\).

Since \(2^{-k}<1/v\leq U-T\), this satisfies

\(T\leq s<T+2^{-k}<U\).

Validity and feasibility

First, the transfer interval is nonempty. Because \(\alpha>\beta\), we have \(\alpha>0\) and \(\beta<1\). Positive masses therefore imply \(0<q<p\). Direct calculation gives

\(\dfrac{\alpha}{p_h}-T=\dfrac{q}{p_hp}>0\),

and

\(\dfrac{1-\beta}{p_l}-T=\dfrac{p-q}{p_lp}>0\).

Thus both quantities defining \(U\) exceed \(T\).

For the transferred rates, \(s<U\leq\alpha/p_h\) and \(s<U\leq(1-\beta)/p_l\) imply

\(0\leq x_l\leq\alpha\leq1\), \(\qquad 0\leq\beta\leq x_h\leq1\).

Moreover,

\(x_h-x_l=\beta-\alpha+(p_l+p_h)s=p(s-T)\geq0\).

The aggregate allocation is unchanged:

\(p_lx_l+p_hx_h=p_l(\alpha-p_hs)+p_h(\beta+p_ls)=p_l\alpha+p_h\beta=q\).

The other four cases also return rates in \([0,1]\), satisfy \(x_h\geq x_l\), and preserve the aggregate \(q\). In particular, the zero-mass cases explicitly assign rates to absent types.

Applying this argument to every class yields

\(\left(\sum_{r\in\{l,h\}}\nu_{\theta,r}x_{\theta,r}\right)_{\theta\in\Theta}=(q_\theta)_{\theta\in\Theta}\in\mathcal F\).

This proves feasibility without any membership query.

Welfare guarantee

In a transferred class, the welfare change is

\(lp_l(x_l-\alpha)+hp_h(x_h-\beta)=lp_l(-p_hs)+hp_h(p_ls)=(h-l)p_lp_hs\geq0\).

Every other case preserves welfare exactly: either the original rates are retained or only zero-mass rates change. Summing over classes proves

\(\sum_{\theta,r}r\nu_{\theta,r}x_{\theta,r}\geq\sum_{\theta,r}r\nu_{\theta,r}a_{\theta,r}(\nu)\).

The wrapper is deterministic, so this also establishes the required expected-welfare inequality with \(c=1\).

Bit complexity

Let \(B\) be the allocation response’s total bit length. The query is the input distribution itself, whose encoding has length \(O(L)\). By hypothesis, \(B\) is bounded by a fixed polynomial in \(L\).

For each class, the construction performs a constant number of rational arithmetic operations and comparisons. The numerators and denominators of \(T\), \(U\), and \(U-T\) have bit lengths \(O(L+B)\): each expression uses only a fixed number of additions, multiplications, and divisions on input rationals.

Consequently, \(k=O(L+B)\), and computing \(\lceil 2^kT\rceil\) requires polynomial-time integer arithmetic. Both \(s\) and the returned rates have bit lengths \(O(L+B)\). If the input masses and oracle rates are dyadic, the returned rates are also dyadic, since their formulas use only addition and multiplication with the dyadic number \(s\).

Reading the support and response, processing all \(m\) classes, and writing all \(2m\) rates therefore take time polynomial in \(m,\tau,L\). The adaptive query count is exactly one.

Relation to the discrete benchmark

In the cited finite-agent model, monotonicity compares allocations at distinct valuation profiles when one agent changes its report. [Suksompong’s definition](https://link.springer.com/article/10.1007/s00224-018-9898-6) explicitly makes this comparison. The present requirement compares two rates at the same distribution \(\nu\). Transferring allocation between those rates preserves the precise aggregate vector on which feasibility depends.

Finally, \(c=1\) is the largest possible universal factor. Take one class, put all mass on its high type, let \(\mathcal F=[0,1]\), and let the allocation oracle return rate \(1\) for both types at every query. Its welfare at this society is \(h\), and every wrapper’s welfare is at most \(h\).
