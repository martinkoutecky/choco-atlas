The continuous mirror question, as graded

Given a standardized finite experiment battery and a society represented by a finite support of response-record types \(r\), each with rational mass \(\mu_r\), compute the maximum mass \(\sum_{r\in S}\mu_r\) of types \(S\) for which there exist strictly increasing values \(\phi_m\) and strictly decreasing values \(\varphi_t\) satisfying \(\phi_m+\varphi_t\geq\phi_n+\varphi_s\) for every revealed comparison \((m,t)R^*(n,s)\) in that type’s record.

Packaged proof task (what the prover saw — nothing else)

A battery consists of \(k\geq 1\) explicitly listed nonempty finite menus \(A_j\) of options \((a,t)\), with binary rational payments \(a\geq 0\) and binary integer delays \(t\geq 0\); repeated menus are allowed. Let \(m=|\bigcup_j A_j|\), and let \(M,T\) be the sets of observed payments and delays.
A response-record type \(r\) specifies exactly one choice \(x_j^r\in A_j\) for every trial. Define \(xR_r^*y\) whenever some trial chooses \(x\) while offering \(y\); these comparisons are weak, so tied options may be chosen without a fixed tie-breaking rule.
A society is given by its support: the list of the \(\tau\) response-record types with positive mass, each mass \(\mu_r\) a binary rational, with \(\sum_r\mu_r=1\). Here \(\tau\) is the support size, not the number of possible response records; \(L\) is the total input bit length.
A subset \(S\) of supported types is feasible if there is one shared pair of real-valued sequences \((\phi_a)_{a\in M}\), \((\varphi_t)_{t\in T}\), strictly increasing in payment and strictly decreasing in delay, such that \(\phi_a+\varphi_t\geq\phi_b+\varphi_s\) for every \((a,t)R_r^*(b,s)\) with \(r\in S\). Selection retains each type's entire record; \(S=\varnothing\) is allowed.
Define \(\operatorname{OPT}=\max_{S\text{ feasible}}\sum_{r\in S}\mu_r\). Its threshold decision problem takes an additional binary rational \(q\in[0,1]\) and asks whether \(\operatorname{OPT}\geq q\).

Is computing \(\operatorname{OPT}\) possible in time polynomial in \(m,\tau,k,L\), or is the threshold decision problem \(\mathrm{NP}\)-hard?

For finite choice data, discounted-utility rationalizability is equivalent to feasibility of the displayed monotone additive inequalities, with strictly increasing positive felicity and strictly decreasing positive discounting normalized at delay zero. [Finite-data characterization](https://mpra.ub.uni-muenchen.de/56596/1/MPRA_paper_56596.pdf).
A later treatment likewise characterizes rationalizability of finite preference comparisons over dated rewards. [Published characterization](https://www.sciencedirect.com/science/article/abs/pii/S0899825618301271). No result settling this exact support-weighted, shared-rationalization selection problem was located.

Modeling choices made when packaging the task

  • Made the standardized battery explicit as nonempty finite menus shared by all types, with one recorded choice per trial and repeated menus permitted.
  • Restricted payments to nonnegative binary rationals for finite input encoding; delays are nonnegative binary integers, including zero.
  • Normalized positive rational masses to sum to one.
  • Specified one common pair of monotone sequences for all selected types and retention of each selected type's entire record.
  • Kept revealed comparisons weak, allowing utility ties without a fixed tie-breaking rule.
  • Allowed the empty selected subset and introduced a rational threshold to state hardness precisely.
  • Defined m as the number of distinct offered options, k as the number of trials, and L as total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The threshold decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when every menu has exactly two options, the observed delays are \(\{0,1,2\}\), all supported types have equal mass, every individual record is feasible, and the threshold is fixed at \(q=1/3\).

Consequently, computing \(\operatorname{OPT}\) exactly in time polynomial in \(m,\tau,k,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. Polynomial verification of a selected subset.

Fix a subset \(S\) of supported types. Order the observed payments and delays as
\(a_1<\cdots<a_p\) and \(t_1<\cdots<t_d\).

Consider the rational linear system consisting of all revealed-choice inequalities from \(S\), together with

\(\phi_{a_{i+1}}-\phi_{a_i}\geq 1\quad(1\leq i<p)\)

and

\(\varphi_{t_i}-\varphi_{t_{i+1}}\geq 1\quad(1\leq i<d).\)

This system is feasible exactly when \(S\) is feasible under the original strict monotonicity requirements:

  • A solution to this system is strictly monotone.
  • Conversely, suppose a strictly monotone solution exists. If there are any adjacent monotonicity gaps, let \(\delta>0\) be their minimum. Multiplying both sequences by \(1/\delta\) makes every such gap at least \(1\). Every revealed-choice inequality remains valid because it is homogeneous. If neither sequence has an adjacent gap, there is nothing to normalize.

There are at most \(2m\) variables and at most \(\tau km+2m\) constraints. Their coefficients and right-hand sides are integers of bounded magnitude, so the system has polynomial encoding length. Rational linear-program feasibility is decidable in polynomial time, by the [polynomial-time linear-programming theorem](https://www.mathnet.ru/eng/dan42319).

A verifier can therefore guess \(S\), check its feasibility, and compare the exact rational sum \(\sum_{r\in S}\mu_r\) with \(q\), all in polynomial time. Thus the threshold problem belongs to \(\mathrm{NP}\).

2. Encoding a graph by a common battery.

Let \(G=(V,E)\) be a finite simple graph with no isolated vertices. Write \(n=|V|\), enumerate its edges as \(e_1,\ldots,e_h\), and arbitrarily designate their endpoints by \(e_i=\{u_i,v_i\}\).

For each edge introduce three options:

\(P_i=(2i-1,0),\qquad Q_i=(2i,1),\qquad H_i=(2i,2).\)

The battery has two menus per edge:

\(A_{2i-1}=\{P_i,Q_i\},\qquad A_{2i}=\{P_i,H_i\}.\)

For each vertex \(w\in V\), define one complete response-record type \(r_w\). Its choices on the two menus for edge \(e_i\) are:

| Vertex | Choice from \(A_{2i-1}\) | Choice from \(A_{2i}\) |
|---|---|---|
| \(w=u_i\) | \(P_i\) | \(P_i\) |
| \(w=v_i\) | \(Q_i\) | \(H_i\) |
| \(w\notin\{u_i,v_i\}\) | \(Q_i\) | \(P_i\) |

Give every type mass \(\mu_{r_w}=1/n\).

These are distinct response-record types. Indeed, each vertex \(w\) has an incident edge. If \(w=u_i\), its choice \(P_i\) from the first menu differs from every other vertex’s choice there. If \(w=v_i\), its choice \(H_i\) from the second menu differs from every other vertex’s choice there.

The construction satisfies

\(\tau=n,\qquad k=2h,\qquad m=3h,\qquad T=\{0,1,2\}.\)

All payments are positive integers at most \(2h\), and all menus and records are explicitly listed.

3. Proven equivalence: feasible subsets are independent sets.

For \(W\subseteq V\), let \(S_W=\{r_w:w\in W\}\). We prove that \(S_W\) is feasible if and only if \(W\) is independent in \(G\).

*Necessity.*

Suppose that both endpoints \(u_i,v_i\) of an edge belong to \(W\). Define

\(\Delta_i=\phi_{2i}-\phi_{2i-1},\qquad D_1=\varphi_0-\varphi_1,\qquad D_2=\varphi_0-\varphi_2.\)

Strict decrease of the delay sequence implies \(D_2>D_1\).

Record \(r_{u_i}\) chooses \(P_i\) over \(Q_i\), so

\(\phi_{2i-1}+\varphi_0\geq\phi_{2i}+\varphi_1,\)

which gives \(\Delta_i\leq D_1\).

Record \(r_{v_i}\) chooses \(H_i\) over \(P_i\), so

\(\phi_{2i}+\varphi_2\geq\phi_{2i-1}+\varphi_0,\)

which gives \(\Delta_i\geq D_2\).

Together these imply \(D_2\leq\Delta_i\leq D_1\), contradicting \(D_2>D_1\). Therefore a feasible subset cannot contain both endpoints of any edge.

*Sufficiency.*

Suppose \(W\) is independent. Set

\(\varphi_0=0,\qquad\varphi_1=-1,\qquad\varphi_2=-2.\)

For each edge define a positive payment increment \(d_i\) by:

  • \(d_i=1\) if \(u_i\in W\);
  • \(d_i=2\) if \(v_i\in W\);
  • \(d_i=3/2\) if neither endpoint belongs to \(W\).

Independence ensures that the first two cases never overlap. Define

\(\phi_{2i-1}=4(i-1),\qquad \phi_{2i}=4(i-1)+d_i.\)

These payment values are strictly increasing. Within a pair the increment is positive, and between consecutive pairs,

\(\phi_{2i}\leq4(i-1)+2<4i=\phi_{2i+1}.\)

Let \(U(a,t)=\phi_a+\varphi_t\). The relevant utility differences are

\(U(Q_i)-U(P_i)=d_i-1,\qquad U(H_i)-U(P_i)=d_i-2.\)

We check every selected record’s choices.

  • If \(u_i\in W\), then \(d_i=1\). Thus \(P_i,Q_i\) tie, while \(P_i\) strictly exceeds \(H_i\). The endpoint record chooses \(P_i\) in both menus. Every other selected record chooses \(Q_i\) in the first and \(P_i\) in the second. All choices maximize utility.
  • If \(v_i\in W\), then \(d_i=2\). Thus \(Q_i\) strictly exceeds \(P_i\), while \(P_i,H_i\) tie. The endpoint record chooses \(Q_i,H_i\); every other selected record chooses \(Q_i,P_i\). All choices maximize utility.
  • If neither endpoint belongs to \(W\), then \(d_i=3/2\). Thus \(Q_i\) strictly exceeds \(P_i\), and \(P_i\) strictly exceeds \(H_i\). Every selected record chooses \(Q_i,P_i\), as required.

This verifies all comparisons in all menus using one shared pair of sequences. The allowed freedom to choose either tied option is used explicitly.

Hence

\(S_W\text{ is feasible}\quad\Longleftrightarrow\quad W\text{ is independent in }G.\)

Writing \(\alpha(G)\) for the maximum independent-set cardinality, we obtain the exact identity

\(\operatorname{OPT}=\alpha(G)/n.\)

In particular, every individual supported record is feasible, because every singleton vertex set is independent.

4. Hardness at the fixed threshold \(q=1/3\).

We reduce from \(\mathrm{3SAT}\), whose \(\mathrm{NP}\)-completeness is a standard theorem; see [Karp’s original paper](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

Take a formula with \(c\geq1\) clauses, each having three literal occurrences. Clauses with fewer nonzero numbers of literals can be padded by repeating a literal without changing satisfiability.

Construct a graph with one vertex for each literal occurrence. Join the three vertices of each clause into a triangle. Also join any two distinct vertices whose literals are complementary. This graph has \(n=3c\) vertices and no isolated vertices.

Every independent set has size at most \(c\), because it contains at most one vertex from each clause triangle. Moreover:

  • A satisfying assignment gives an independent set of size \(c\): choose one true literal occurrence from each clause. Two chosen literals cannot be complementary because both are true under the same assignment.
  • An independent set of size \(c\) chooses exactly one occurrence from every clause and contains no complementary pair. Assign each variable appearing in a chosen occurrence the value making that literal true. These requirements are consistent; assign all remaining variables arbitrarily. Every clause then contains a chosen true literal.

Thus the formula is satisfiable exactly when \(\alpha(G)=c\).

Apply the battery construction above and use \(q=1/3\). Then

\(\operatorname{OPT}\geq1/3 \quad\Longleftrightarrow\quad \alpha(G)/(3c)\geq1/3 \quad\Longleftrightarrow\quad \alpha(G)\geq c \quad\Longleftrightarrow\quad \text{the formula is satisfiable}.\)

The graph has at most \(\binom{3c}{2}\) edges. The battery contains two menus per edge and \(3c\) explicitly listed records, each specifying every choice. Payments require \(O(\log(h+1))\) bits, and masses \(1/(3c)\) require \(O(\log(c+1))\) bits. Consequently the entire reduction has polynomial output length and runs in polynomial time.

This proves \(\mathrm{NP}\)-hardness under all the restrictions stated at the beginning. Together with polynomial verification, it proves \(\mathrm{NP}\)-completeness.
