The continuous mirror question, as graded

Given schools \(O\), ranking types \(T\), rational masses \(\mu_t\) summing to \(1\), per-capita capacities \(q_j\), and a feasible type-symmetric probabilistic assignment \(p_{tj}\), determine whether the target masses \(\mu_t p_{tj}\) have an exact finite lottery representation by ex-post Pareto-efficient assignments of an atomless population. If so, return such a lottery maximizing the minimum total mass assigned a school among outcomes with positive weight; otherwise, certify that no such lottery exists.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) strict ranking types over \(O\cup\{\varnothing\}\) with positive masses \(\mu_t\) encoded as binary rationals, where \(\sum_t\mu_t=1\). Here \(m=|O|\geq1\), and \(\tau\) is the support size, not the number of possible rankings; \(\varnothing\) means unassigned and may occur anywhere in a ranking.
Each school has positive rational capacity \(q_j\), measured in population mass. The input probabilities \(p_{tj}\) are binary rationals satisfying \(p_{tj}\geq0\), \(\sum_jp_{tj}\leq1\), and \(\sum_t\mu_tp_{tj}\leq q_j\). Schools have no preferences or priorities.
Realize the population as disjoint atomless intervals \(A_t\) of Lebesgue measure \(\mu_t\). An outcome is a measurable assignment \(f:\bigcup_tA_t\to O\cup\{\varnothing\}\) with \(x_{tj}=|A_t\cap f^{-1}(j)|\) and \(\sum_tx_{tj}\leq q_j\). Types may split among schools within an outcome.
An outcome is Pareto efficient if no feasible measurable reassignment weakly improves the assigned option for almost every person and strictly improves it on a set of positive mass, using each person's type ranking.
An exact finite lottery consists of efficient outcomes \(f^1,\ldots,f^r\) and real weights \(\lambda_\ell>0\) with \(\sum_\ell\lambda_\ell=1\) and \(\sum_\ell\lambda_\ell x^\ell_{tj}=\mu_tp_{tj}\) for every type–school pair. Exactness concerns these masses; no individual probability constraints are imposed.
The problem is to determine whether such a lottery exists and, when it does, find one maximizing \(\min_{1\leq\ell\leq r}\sum_{t,j}x^\ell_{tj}\).

Is this exact feasibility-and-maximin lottery problem solvable in polynomial time in \(m\), \(\tau\), and the total input bit length \(L\), or is it NP-hard?

For finite agents, maximizing the minimum number assigned over efficient exact decompositions is NP-hard ([Demeulemeester et al.](https://arxiv.org/pdf/2101.00579)). Even deciding existence of an efficient decomposition is NP-complete with unit-capacity objects ([Aziz et al.](https://arxiv.org/abs/1409.6076)).
No result settling exactly the atomless mass-lottery problem above was located in the literature search.

Modeling choices made when packaging the task

  • Ranking types are strict orders including an outside option at any position, allowing unacceptable schools.
  • Capacities are positive binary rationals measured in population mass; no equality between total capacity and population mass is imposed.
  • The population is represented by atomless intervals, and deterministic outcomes may split each type's mass.
  • Pareto comparisons hold almost everywhere and require strict improvement on positive mass, excluding null-set improvements.
  • Exact lottery representation matches type–school masses, rather than each individual's marginal probabilities.
  • Lottery weights and outcome masses may be real; only the input data are required to be binary rationals.
  • The school set is nonempty, and the input assignment need only satisfy feasibility, without a promise of efficient decomposability.

Result

The exact feasibility-and-maximin lottery problem is \(\mathrm{NP}\)-hard. In fact, deciding exact feasibility is already \(\mathrm{NP}\)-hard on instances where every efficient outcome assigns the entire population. Thus, on every feasible instance produced by the reduction, the optimal maximin value is \(1\).

The proof below allows types to split within outcomes and uses only the type–school mass constraints specified in the question.

1. The finite source problem

We use the following established result: given \(n\) agents with strict preferences over \(n\) unit-capacity objects and a rational doubly stochastic matrix \(P\), deciding whether \(P\) is a convex combination of Pareto-efficient permutation assignments is \(\mathrm{NP}\)-complete. This is Theorem 2 of [Aziz, Mackenzie, Xia, and Ye, *Structure and complexity of ex post efficient random assignments*](https://arxiv.org/pdf/1409.6076).

Write the objects as \(o_1,\ldots,o_n\), and denote agent \(i\)'s preference by \(\succ_i\). The input matrix satisfies

\(\displaystyle P_{ij}\geq 0,\qquad \sum_{j=1}^{n}P_{ij}=1,\qquad \sum_{i=1}^{n}P_{ij}=1.\)

A permutation \(\pi\) assigns object \(o_{\pi(i)}\) to agent \(i\). Its matrix \(M^\pi\) has entry \(1\) at \((i,\pi(i))\) and entry \(0\) elsewhere. It is Pareto efficient if no permutation \(\sigma\) satisfies

\(\displaystyle o_{\sigma(i)}\succeq_i o_{\pi(i)}\quad\text{for every }i,\)

with strict preference for at least one agent.

We construct an atomless instance that admits an exact efficient lottery if and only if the finite source instance admits such a decomposition.

2. Construction of distinct ranking types

Introduce the school set

\(\displaystyle O=\{o_1,\ldots,o_n\}\cup\{d_1,\ldots,d_n\}.\)

The schools \(d_1,\ldots,d_n\) serve to distinguish ranking types.

For each finite agent \(i\), introduce one type of mass

\(\displaystyle \mu_i=\frac1n.\)

Its strict ranking consists of:

  • All original schools, in agent \(i\)'s original order.
  • The outside option \(\varnothing\).
  • School \(d_i\), followed by the other dummy schools in increasing index order.

These \(n\) rankings are pairwise distinct because their first dummy school differs. Hence the society has support size exactly \(\tau=n\), even if some finite agents had identical original preferences.

Give every school capacity

\(\displaystyle q_{o_j}=q_{d_j}=\frac1n.\)

Set the input probabilities to

\(\displaystyle p_{i,o_j}=P_{ij},\qquad p_{i,d_j}=0.\)

All input conditions hold. Each probability row sums to \(1\), and each original school has expected mass

\(\displaystyle \sum_{i=1}^{n}\mu_i p_{i,o_j}=\frac1n\sum_{i=1}^{n}P_{ij}=\frac1n=q_{o_j}.\)

Every dummy school has expected mass \(0\).

3. Efficient outcomes fill all original schools

Lemma 1. Every Pareto-efficient outcome of the constructed instance assigns everyone, up to a null set, to original schools and fills each original school to capacity.

Proof. If a dummy school receives positive mass, reassign that mass to \(\varnothing\). This is feasible and strictly improves everyone moved, since every type ranks \(\varnothing\) above every dummy school. Therefore an efficient outcome assigns zero mass to dummy schools.

Suppose its unassigned mass is \(u>0\). Its total assignment to original schools is then \(1-u\), whereas their total capacity is \(1\). Consequently, some original school has positive slack. Some type also has positive unassigned mass. Move a sufficiently small positive mass of that type from \(\varnothing\) to the school with slack. Atomlessness permits selecting such a measurable subset. This strictly improves the selected people and changes no other person's assignment.

Thus an efficient outcome has \(u=0\). Its original-school loads sum to \(1\), each load is at most \(1/n\), and there are \(n\) original schools. Every load must therefore equal \(1/n\). \(\square\)

For an efficient outcome, define its normalized original-school matrix by

\(\displaystyle B_{ij}=n x_{i,o_j}.\)

Lemma 1 implies that \(B\) is doubly stochastic.

Conversely, every doubly stochastic matrix \(B\) is realizable as a feasible measurable outcome with masses \(x_{i,o_j}=B_{ij}/n\): partition each interval \(A_i\) into measurable pieces of those masses.

4. Relating atomless efficiency to permutation efficiency

We use the Birkhoff–von Neumann theorem in the following precise form:

Every real nonnegative doubly stochastic matrix \(B\) is a finite convex combination \(B=\sum_k\alpha_kM^{\pi_k}\), where \(\alpha_k>0\), \(\sum_k\alpha_k=1\), and the matrices \(M^{\pi_k}\) are permutation matrices.

Furthermore, every permutation appearing in such a decomposition is supported on the positive entries of \(B\). Indeed, \(M^{\pi_k}_{ij}=1\) implies \(B_{ij}\geq\alpha_k>0\).

4.1. Supported permutations of an efficient outcome are efficient

Lemma 2. Let \(f\) be an efficient outcome of the constructed instance, with normalized matrix \(B\). If a permutation \(\pi\) satisfies \(B_{i,\pi(i)}>0\) for every \(i\), then \(\pi\) is Pareto efficient in the finite source instance.

Proof. Suppose instead that a permutation \(\sigma\) Pareto dominates \(\pi\). Define

\(\displaystyle I=\{i:\sigma(i)\neq\pi(i)\}.\)

This set is nonempty. Since preferences are strict, every \(i\in I\) strictly prefers \(o_{\sigma(i)}\) to \(o_{\pi(i)}\).

Choose a mass \(\varepsilon\) satisfying

\(\displaystyle 0<\varepsilon<\min_{i\in I}x_{i,o_{\pi(i)}}.\)

The minimum is positive by the support assumption. For every \(i\in I\), select a measurable subset of mass \(\varepsilon\) from the people of type \(i\) currently assigned to \(o_{\pi(i)}\), and move it to \(o_{\sigma(i)}\).

Each school has unchanged total load. To verify this explicitly, its load change is

\(\displaystyle \Delta_j=\varepsilon\sum_{i\in I}\bigl(\mathbf1_{\{\sigma(i)=j\}}-\mathbf1_{\{\pi(i)=j\}}\bigr)=0.\)

The sum over \(I\) equals the sum over all agents because the omitted terms vanish; the latter sum is zero because both \(\sigma\) and \(\pi\) are permutations.

The reassignment is therefore feasible. Everyone moved strictly improves, and everyone else keeps their assignment. The strictly improved mass is \(|I|\varepsilon>0\), contradicting the efficiency of \(f\). \(\square\)

It follows that the normalized matrix of every efficient atomless outcome is a convex combination of efficient finite permutations: apply Birkhoff–von Neumann to its doubly stochastic matrix and then apply Lemma 2 to every supported permutation.

4.2. Efficient permutations yield efficient atomless outcomes

Lemma 3. If \(\pi\) is an efficient finite permutation, assigning the entire interval \(A_i\) to \(o_{\pi(i)}\) gives a Pareto-efficient atomless outcome.

Proof. This outcome is feasible because every original school receives exactly one type of mass \(1/n\).

Suppose a feasible measurable reassignment weakly improves almost everyone and strictly improves a set of positive mass. Every person initially receives an original school. Since all original schools are above \(\varnothing\) and all dummy schools, a weak improvement assigns everyone to original schools, up to a null set.

Let \(y_{ij}\) be the new type–school masses and define \(C_{ij}=ny_{ij}\). Every row of \(C\) sums to \(1\). Every column sums to at most \(1\), and their total sum is \(n\). Hence every column sums to \(1\), so \(C\) is doubly stochastic.

Moreover,

\(\displaystyle C_{ij}>0\ \Longrightarrow\ o_j\succeq_i o_{\pi(i)}.\)

Positive strictly improved mass implies that some pair \((i,j)\) satisfies both \(C_{ij}>0\) and \(o_j\succ_i o_{\pi(i)}\).

Decompose \(C\) into permutation matrices by Birkhoff–von Neumann. Every permutation in the decomposition assigns each agent an object weakly preferred to their object under \(\pi\), because it uses only positive entries of \(C\). At least one permutation uses the strictly better pair \((i,j)\), since \(C_{ij}>0\).

That permutation Pareto dominates \(\pi\), contradicting its finite efficiency. \(\square\)

5. Exact feasibility is preserved in both directions

Proposition. The constructed atomless instance admits an exact finite lottery over efficient outcomes if and only if \(P\) admits a decomposition into efficient finite permutation assignments.

Proof, finite to atomless. Suppose

\(\displaystyle P=\sum_{k=1}^{s}\alpha_kM^{\pi_k}\)

is a decomposition into efficient permutations with positive weights summing to \(1\). For each \(\pi_k\), assign all of \(A_i\) to \(o_{\pi_k(i)}\). Lemma 3 proves that each outcome is efficient. Their expected masses are

\(\displaystyle \sum_{k=1}^{s}\alpha_k x^{k}_{i,o_j}=\frac1n\sum_{k=1}^{s}\alpha_kM^{\pi_k}_{ij}=\frac{P_{ij}}n=\mu_i p_{i,o_j}.\)

Dummy-school masses are zero. The lottery is exact.

Proof, atomless to finite. Suppose an exact finite lottery has efficient outcomes \(f^1,\ldots,f^r\) and positive weights \(\lambda_\ell\). Let \(B^\ell\) be their normalized original-school matrices. Exactness gives

\(\displaystyle \sum_{\ell=1}^{r}\lambda_\ell B^\ell_{ij}=n\mu_i p_{i,o_j}=P_{ij},\)

and hence

\(\displaystyle P=\sum_{\ell=1}^{r}\lambda_\ell B^\ell.\)

Each \(B^\ell\) is doubly stochastic by Lemma 1. By Birkhoff–von Neumann and Lemma 2, it has a finite decomposition

\(\displaystyle B^\ell=\sum_{k=1}^{s_\ell}\alpha_{\ell k}M^{\pi_{\ell k}}\)

into efficient finite permutations. Substituting yields

\(\displaystyle P=\sum_{\ell=1}^{r}\sum_{k=1}^{s_\ell}\lambda_\ell\alpha_{\ell k}M^{\pi_{\ell k}}.\)

All weights are positive, and their sum is \(1\). This is the required finite efficient decomposition. \(\square\)

This argument applies to arbitrary real lottery weights and arbitrary real masses within outcomes.

6. Complexity and the maximin objective

The construction has \(m=2n\) schools and \(\tau=n\) distinct ranking types. Its rankings and probability matrix have polynomial size. The newly introduced masses and capacities are \(1/n\), whose rational encodings have length \(O(\log n)\). Thus the construction is a polynomial-time many-one reduction.

By the proposition, it preserves yes and no instances of the \(\mathrm{NP}\)-complete finite source problem. Therefore exact atomless feasibility is \(\mathrm{NP}\)-hard.

Finally, Lemma 1 shows that every efficient outcome in every constructed instance satisfies

\(\displaystyle \sum_{i=1}^{n}\sum_{j\in O}x_{ij}=1.\)

Consequently, whenever an exact efficient lottery exists, its minimum assigned mass—and therefore its optimal maximin value—is \(1\).

An algorithm solving the stated combined feasibility-and-maximin problem would decide feasibility for these instances and thereby solve the finite source problem. Hence the combined problem is \(\mathrm{NP}\)-hard and cannot be polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).

The contradiction argument is rigorous.

The moved population has positive mass \(|I|\varepsilon\), and everyone else retains their assignment. This contradicts atomless Pareto efficiency exactly as defined in USER_TASK.

Therefore every permutation in a Birkhoff decomposition of an efficient outcome’s normalized matrix is efficient in the finite source problem.

6. Lemma 3: efficient permutations produce efficient atomless outcomes

The initial assignment is feasible and fills each original school.

Under any almost-everywhere weak improvement, no positive mass can move to the outside option or to dummy schools: all these options are strictly worse than each person’s original assignment. Thus the reassignment’s original-school matrix \(C\) has row sums \(1\).

Its column sums are at most \(1\), and their total is \(n\). Consequently, all column sums equal \(1\), establishing the remaining Birkhoff hypotheses.

A positive entry of \(C\) corresponds only to an option weakly preferred to the initial option; exceptional null sets contribute no positive mass. Positive strictly improved mass implies a strictly better positive entry because there are only finitely many type–school pairs.

Every permutation in the decomposition uses only weakly improving entries. The strictly better positive entry must appear in at least one permutation, since otherwise the decomposed matrix would be zero at that entry. That permutation therefore dominates \(\pi\), yielding the required contradiction.

This argument explicitly covers fractional reassignment within types.

In the finite-to-atomless direction, Lemma 3 supplies efficient outcomes, and scaling each permutation matrix by \(1/n\) gives precisely the required expected masses. Dummy-school expectations are zero.

In the atomless-to-finite direction, exactness gives
\[ P=\sum_{\ell=1}^{r}\lambda_\ell B^\ell. \]
Each \(B^\ell\) admits a finite decomposition into efficient permutations by Lemma 2 and Birkhoff–von Neumann. Substitution produces finitely many terms with positive product weights. Their sum is
\[ \sum_{\ell=1}^{r}\sum_{k=1}^{s_\ell}\lambda_\ell\alpha_{\ell k} =\sum_{\ell=1}^{r}\lambda_\ell=1. \]

No rationality assumption on lottery weights or outcome masses is introduced. The argument therefore establishes the equivalence for the real weights and masses allowed by USER_TASK.
