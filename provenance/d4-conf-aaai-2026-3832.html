The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), an approval-ballot support \(\mathcal T\subseteq 2^C\), positive rational masses \(\mu_A\) summing to \(1\), a threshold \(k'\ge 2\), and \(X\in\{\mathrm{JR},\mathrm{EJR}^+\}\), are there two size-\(k\) committees \(W_1,W_2\) with \(|W_1\setminus W_2|\ge k'\), both satisfying mass-\(X\)? For each \(W\), mass-\(\mathrm{JR}\) requires \(\sum_{A:\,c\in A,\ |A\cap W|<1}\mu_A<1/k\) for every \(c\notin W\); mass-\(\mathrm{EJR}^+\) requires \(\sum_{A:\,c\in A,\ |A\cap W|<\ell}\mu_A<\ell/k\) for every \(c\notin W\) and \(\ell\in[k]\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\), and let \(2\le k'\le k\le m\) be integers. Fix \(X\in\{\mathrm{JR},\mathrm{EJR}^+\}\).
A society is given by its support: a list \(\mathcal T\subseteq 2^C\) of distinct approval types with positive binary rational masses \(\mu_A\) summing to \(1\). Empty approval types are allowed. The support size is \(\tau=|\mathcal T|\), not the number of possible approval types; let \(L\) be the total input bit length.
A committee is a subset \(W\subseteq C\) with \(|W|=k\). It satisfies mass-\(\mathrm{JR}\) if \(\sum_{A\in\mathcal T:\,c\in A,\,|A\cap W|<1}\mu_A<1/k\) for every \(c\in C\setminus W\).
It satisfies mass-\(\mathrm{EJR}^+\) if \(\sum_{A\in\mathcal T:\,c\in A,\,|A\cap W|<\ell}\mu_A<\ell/k\) for every \(c\in C\setminus W\) and integer \(1\le\ell\le k\).
The decision problem asks whether there exist two committees \(W_1,W_2\), both satisfying mass-\(X\), with \(|W_1\setminus W_2|\ge k'\). State running times in \(m,\tau,L,k,k'\).

For each fixed \(X\in\{\mathrm{JR},\mathrm{EJR}^+\}\), is this decision problem solvable in polynomial time or is it NP-hard?

For finite voter lists, the corresponding problem is NP-complete for every fixed \(k'\ge2\), W[1]-hard parameterized by \(k\), and FPT parameterized by the number of voters. [Source](https://arxiv.org/html/2511.09479)
No result explicitly treating this exact rational-mass decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Restricted the integer parameters to 2 ≤ k' ≤ k ≤ m, carrying over the discrete threshold and committee-size domains.
  • Allowed empty approval types, consistent with the unrestricted subset domain for approval ballots.
  • Defined L as the total input bit length and treated each axiom as a separate fixed variant.

Classification

For each fixed \(X\in\{\mathrm{JR},\mathrm{EJR}^+\}\), the rational-mass problem is NP-complete, already for every fixed \(k'\ge 2\). It is therefore not polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).

The finite-voter hardness transfers by merging identical ballots. Below I prove this transfer, give explicit verification and exhaustive-search bounds, and establish an FPT algorithm parameterized by the actual support size \(\tau\).

1. Exact verification and membership in NP

Write each mass as \(\mu_A=p_A/q_A\), where the positive integers \(p_A,q_A\) are encoded in binary. Define

\(\displaystyle Q=\prod_{A\in\mathcal T}q_A,\qquad b_A=p_A(Q/q_A).\)

Then \(\mu_A=b_A/Q\), and the promised normalization gives \(\sum_A b_A=Q\). The binary length of \(Q\) is at most the sum of the binary lengths of the denominators, hence is \(O(L)\). Thus this construction uses integers of polynomial bit length; it does not expand the society into voters.

For a committee \(W\), put \(s_A=|A\cap W|\). Its condition for a candidate \(c\notin W\) and level \(\ell\) is exactly

\(\displaystyle k\sum_{\substack{A\in\mathcal T\\c\in A,\ s_A<\ell}}b_A<\ell Q.\)

Consequently, equality at the threshold is detected exactly.

Let \(B=L+\lceil\log_2(m+1)\rceil+1\). Using elementary integer arithmetic, the denominator preprocessing takes \(O(\tau B^2)\) bit operations. Computing all \(s_A\) takes \(O(m\tau B)\) bit operations using an incidence table.

For JR, only \(\ell=1\) is checked. A verifier therefore runs in

\(\displaystyle V_{\mathrm{JR}}=O\bigl((\tau+m\tau)B^2\bigr).\)

For EJR\(^{+}\), for each candidate \(c\), accumulate the weights of its approving types in buckets indexed by \(s_A\in\{0,\ldots,k\}\). Prefix sums give the relevant weight for every \(\ell\). Including exact comparisons, the running time is

\(\displaystyle V_{\mathrm{EJR}^+}=O\bigl((\tau+m\tau+mk)B^2\bigr).\)

A certificate consists of \(W_1,W_2\). Their sizes, their distance, and both proportionality conditions are verifiable within these polynomial bounds. Hence both problems belong to \(\mathrm{NP}\).

2. A polynomial reduction from finite voter lists

The finite-voter theorem supplied in the question states that, for each fixed \(k'\ge2\), both corresponding problems are NP-complete and W[1]-hard parameterized by \(k\). Its distance is precisely \(|W_1\setminus W_2|\), and its EJR\(^{+}\) definition uses groups of size at least \(\ell n/k\). [Boehmer, Glessen, and Peters, Definition 2.1 and Theorem 3.3](https://arxiv.org/html/2511.09479)

Consider such a finite instance with \(n>0\) voters and ballots \(A_1,\ldots,A_n\). For every distinct occurring ballot \(A\), let

\(\displaystyle n_A=|\{i:A_i=A\}|,\qquad \mu_A=n_A/n.\)

Keep \(C,k,k'\) unchanged and output the support of distinct ballots with these masses.

Every output mass is positive, their sum is \(1\), and their numerators and denominators have \(O(\log(n+1))\) bits. There are at most \(n\) support types. Sorting the ballots, counting multiplicities, and writing these fractions take polynomial time in the explicit finite-instance length. Empty ballots, if present, are treated in exactly the same way.

For every committee \(W\), candidate \(c\), and integer \(\ell\),

\(\displaystyle \sum_{\substack{A\in\mathcal T\\c\in A,\ |A\cap W|<\ell}}\mu_A = \frac{|\{i:c\in A_i,\ |A_i\cap W|<\ell\}|}{n}. \)

To check equivalence with the finite definition, let \(U\) be the voter set in the numerator. A violating group exists precisely when \(|U|\ge\ell n/k\):

  • If such a group exists, it is contained in \(U\), so \(U\) meets the threshold.
  • If \(U\) meets the threshold, \(U\) itself is a violating group.

Therefore \(W\) satisfies finite JR, respectively finite EJR\(^{+}\), if and only if it satisfies the corresponding mass axiom. The reduction preserves every feasible committee, and hence every feasible pair and its distance.

This proves NP-hardness for both fixed choices of \(X\), already for each fixed \(k'\ge2\). Together with Section 1, it proves NP-completeness. Because \(k\) is unchanged, the same reduction also transfers W[1]-hardness parameterized by \(k\).

3. Exhaustive-search running time

For any two committees,

\(\displaystyle |W_1\cup W_2|=k+|W_1\setminus W_2|.\)

Thus an instance with \(m<k+k'\) can immediately be rejected.

Otherwise, enumerating all ordered pairs of size-\(k\) committees and verifying them gives the bound

\(\displaystyle O\left(\binom{m}{k}^{\,2}V_X\right)\subseteq O\left(m^{2k}V_X\right).\)

Here \(V_X\) is the explicit bit-operation bound from Section 1. The distance test takes \(O(m)\) additional operations per pair. This is an XP algorithm parameterized by \(k\).

4. An FPT algorithm parameterized by the support size

The finite-voter FPT result cannot simply be applied after expanding rational masses: that expansion might be exponentially large. The following argument works directly with the \(\tau\) support types.

4.1. A subset characterization

Index the support types as \(A_1,\ldots,A_\tau\). For a nonempty set \(S\subseteq\{1,\ldots,\tau\}\), define

\(\displaystyle \mu(S)=\sum_{i\in S}\mu_{A_i},\)

and define integer thresholds

\(\displaystyle t_{\mathrm{JR}}(S)= \begin{cases} 1,&k\mu(S)\ge1,\\ 0,&k\mu(S)<1, \end{cases} \qquad t_{\mathrm{EJR}^+}(S)=\lfloor k\mu(S)\rfloor. \)

For a candidate \(c\), let \(P(c)=\{i:c\in A_i\}\). For a committee \(W\), let \(s_i=|A_i\cap W|\).

Lemma. The committee \(W\) satisfies mass-\(X\) if and only if, for every \(c\notin W\) and every nonempty \(S\subseteq P(c)\),

\(\displaystyle \max_{i\in S}s_i\ge t_X(S).\)

Proof for EJR\(^{+}\). Suppose \(W\) satisfies the axiom. If \(t=t_{\mathrm{EJR}^+}(S)>0\) and all \(s_i<t\) for \(i\in S\), then the mass of types approving \(c\) with representation below \(t\) is at least \(\mu(S)\ge t/k\). This violates the axiom at level \(t\). The level is permitted because \(1\le t\le k\). When \(t=0\), the inequality is automatic.

Conversely, suppose the axiom fails at \(c\notin W\) and level \(\ell\). Set \(S=\{i\in P(c):s_i<\ell\}\). Its mass is at least \(\ell/k\), so \(S\) is nonempty and \(t_{\mathrm{EJR}^+}(S)\ge\ell\). Every \(s_i\) in \(S\) is smaller than \(\ell\), contradicting the asserted inequality.

Proof for JR. A violation consists precisely of approving types with \(s_i=0\) whose combined mass is at least \(1/k\). Such a set violates the displayed condition with threshold \(1\), and any failed condition with threshold \(1\) supplies such a violation. Conditions with threshold \(0\) are automatic. \(\square\)

4.2. Candidate classes and integer programs

Partition candidates according to their signatures \(P(c)\). Let the occurring classes be \(D_1,\ldots,D_r\), with signatures \(P_j\) and sizes \(n_j\). Then

\(\displaystyle r\le\min(m,2^\tau).\)

For each committee index \(b\in\{1,2\}\), guess a set \(F_b\) of classes that the committee includes in full. Also, for every nonempty support subset \(S\), guess a witness \(w_b(S)\in S\).

For each collection of guesses, construct an integer program with \(3r\) variables:

  • \(x_{j,b}\), the number of candidates selected from \(D_j\) by committee \(b\);
  • \(z_j\), the number selected by both committees from \(D_j\).

Impose

\(\displaystyle 0\le x_{j,b}\le n_j,\qquad \sum_jx_{j,b}=k, \)

together with

\(\displaystyle x_{j,b}=n_j\quad(j\in F_b),\qquad x_{j,b}\le n_j-1\quad(j\notin F_b). \)

The overlap constraints are

\(\displaystyle 0\le z_j,\qquad z_j\le x_{j,1},\qquad z_j\le x_{j,2},\qquad z_j\ge x_{j,1}+x_{j,2}-n_j, \)

and

\(\displaystyle \sum_jz_j\le k-k'.\)

Finally, whenever a nonempty \(S\) is contained in \(P_j\) for some \(j\notin F_b\), impose

\(\displaystyle \sum_{\substack{h\\w_b(S)\in P_h}}x_{h,b}\ge t_X(S). \)

All variables are required to be integers.

Correctness. Given a feasible committee pair, choose its actual full classes and intersection sizes. The lemma supplies a witness for every relevant subset \(S\); choose arbitrary witnesses for irrelevant subsets. These choices satisfy the program.

Conversely, an integer solution can be realized within each class by selecting \(z_j\) common candidates, \(x_{j,1}-z_j\) candidates only for the first committee, and \(x_{j,2}-z_j\) only for the second. The overlap constraints make all these numbers nonnegative and ensure that their total is at most \(n_j\). The resulting committees have size \(k\) and distance at least \(k'\).

A class has an outside candidate exactly when it is not in \(F_b\). For every such class, the final constraints enforce the lemma for all nonempty subsets of its signature. Hence both realized committees satisfy mass-\(X\).

4.3. Running time

The number of collections of guesses is at most

\(\displaystyle 2^{2r}\left(\prod_{\varnothing\ne S\subseteq\{1,\ldots,\tau\}}|S|\right)^2 \le 2^{2r}\tau^{\,2(2^\tau-1)}. \)

All thresholds are computed exactly using the common denominator from Section 1. Each program has \(3r\) integer variables, \(O(r+2^\tau)\) constraints, and integer coefficients of polynomial bit length.

The fixed-dimension integer-programming algorithm has running time \(2^{O(d^3)}H^{O(1)}\) for \(d\) integer variables and binary input length \(H\). [Lenstra’s theorem and its running-time bound](https://doi.org/10.1145/800061.808749) Its hypotheses apply here: each branch is a finite system of linear inequalities with integer coefficients and integer variables.

Substituting \(d=3r\) and \(r\le2^\tau\), and including preprocessing and all guesses, gives the conservative bound

\(\displaystyle 2^{O(8^\tau)} \bigl(m+\tau+L+\log(k+1)+\log(k'+1)\bigr)^{O(1)}. \)

Thus both rational-mass problems are FPT parameterized by the support size \(\tau\), even though they are NP-complete in general.
