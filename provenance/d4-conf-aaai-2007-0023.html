Each type is a finite possibilistic base \(B_t\) of pairs \((\psi,w)\), with binary rational \(w\in(0,1]\); its underlying classical base is consistent and complete, hence has exactly one model. Individual priority strata need not be complete.
Let \(\lambda_1>\cdots>\lambda_\ell>0\) be all distinct input weights and \(K_t^r=\{\psi:(\psi,\lambda_r)\in B_t\}\). Define \(d_H(\omega,K)=\min_{\nu\models\bigwedge K}d_H(\omega,\nu)\), using Hamming distance; an empty stratum has distance zero.

Result

The decision problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions, even when \(\tau=\ell=1\), the sole mass is \(1\), the sole weight and query threshold are both \(1/2\), and the query is an atom. Thus a polynomial-time algorithm in the total binary input length \(L\) would imply \(\mathrm{P}=\mathrm{NP}\).

A deterministic upper bound is \(2^m\operatorname{poly}(L)\). More explicitly, the enumeration algorithm below uses \(O(2^m[L+\tau\ell(m+1)])\) elementary evaluation, graph, and arithmetic operations, plus polynomial preprocessing; its arithmetic operands have polynomial bit length. The problem also belongs to \(\Delta_2^p=\mathrm{P}^{\mathrm{NP}}\).

1. The canonical cuts

Write \(\Omega=\{0,1\}^{P}\). Every stratum is consistent: the unique model of the underlying complete base of type \(t\) satisfies every subset of that base. Hence every distance in the definition is finite. Since \(\kappa\) is satisfiable, minimization over finite nonempty sets shows that every \(S_r\) is nonempty.

For \(b\in(0,1]\), define \(r(b)=|\{j:\lambda_j\ge b\}|\). We claim that

\(\operatorname{Mod}((C_\pi)_{\ge b})=\{\omega:\pi(\omega)>1-b\}=S_{r(b)+1}.\)

To prove the first equality, the formulas in this cut are precisely those associated with realized values \(c\le 1-b\). An interpretation satisfying \(\pi(\omega)>1-b\) satisfies every such formula. Conversely, if \(\pi(\omega)\le 1-b\), its own realized value \(c=\pi(\omega)<1\) contributes a formula to the cut, and \(\omega\) fails that formula.

For the second equality, interpretations outside \(S_1\) have possibility \(0\), so they fail the strict inequality. An interpretation removed at level \(j\) has possibility \(1-\lambda_j\), and therefore satisfies the inequality exactly when \(\lambda_j<b\). Final survivors have possibility \(1\). This gives precisely \(S_{r(b)+1}\).

In particular, every cut under consideration is consistent.

For completeness, this also removes the universal quantification over larger thresholds:

  • If \(a=1\), acceptance means simply \(S_{r(1)+1}\subseteq\operatorname{Mod}(\phi)\).
  • If \(a<1\) and \(a\) is not an input weight, acceptance is impossible. Indeed, some \(b>a\) sufficiently close to \(a\) has exactly the same cut.
  • If \(a=\lambda_j<1\), acceptance is equivalent to

\(S_{j+1}\subseteq\operatorname{Mod}(\phi)\) and \(S_j\not\subseteq\operatorname{Mod}(\phi)\).

For the last assertion, a threshold immediately above \(\lambda_j\) has model set \(S_j\). Every other larger threshold has a model set containing \(S_j\), so a countermodel in \(S_j\) witnesses failure of entailment at all larger thresholds.

2. A reduction satisfying every input promise

We reduce propositional satisfiability to the specified decision problem.

Let \(F\) be a propositional formula on variables \(x_1,\ldots,x_n\), with \(n\ge1\). Restricting satisfiability to this case preserves its \(\mathrm{NP}\)-hardness; an unused variable can be added if necessary.

Introduce fresh variables \(q,z_1,\ldots,z_{n+2}\), and set

\(P=\{x_1,\ldots,x_n,q,z_1,\ldots,z_{n+2}\}.\)

Define

\(A=q\land F\land\bigwedge_{i=1}^{n+2}\neg z_i,\)

\(E=\neg q\land\bigwedge_{i=1}^{n}\neg x_i\land\bigwedge_{i=1}^{n+2}z_i,\)

and \(\kappa=A\lor E\).

The formula \(E\) has exactly one model, denoted \(\eta\). Consequently, \(\kappa\) is satisfiable regardless of whether \(F\) is satisfiable.

There is one type, with mass \(\rho_1=1\), and base

\(B_1=\{(\neg p,1/2):p\in P\}.\)

Its underlying classical base has exactly one model, the all-zero interpretation \(\mathbf{0}\). Thus this base is consistent and complete, as required. There is exactly one priority level, \(\lambda_1=1/2\).

Choose the query \((\phi,a)=(q,1/2)\).

The construction uses \(m=2n+3\) variables and polynomial binary encoding length. All formulas are explicit ordinary propositional formulas.

Computing the minimizers

The sole stratum has model set \(\{\mathbf{0}\}\). Therefore its objective is

\(d_H(\omega,K_1^1)=d_H(\omega,\mathbf{0}),\)

the number of true variables in \(\omega\).

The fallback model \(\eta\) has precisely the \(n+2\) variables \(z_i\) true. Hence

\(d_H(\eta,\mathbf{0})=n+2.\)

Every model \(\omega\) of \(A\) has \(q\) true, all \(z_i\) false, and at most \(n\) true variables among the \(x_i\). Therefore

\(d_H(\omega,\mathbf{0})\le n+1<n+2.\)

It follows that:

  • If \(F\) is satisfiable, \(A\) has a model, and every minimizer in \(S_2\) satisfies \(A\). In particular, every minimizer satisfies \(q\).
  • If \(F\) is unsatisfiable, \(\kappa\) has only the model \(\eta\). Thus \(S_2=\{\eta\}\), and \(S_2\) does not entail \(q\).

Verifying the exact threshold condition

By Section 1,

\(\operatorname{Mod}((C_\pi)_{\ge 1/2})=S_2.\)

This cut is consistent and entails \(q\) exactly when \(F\) is satisfiable.

For every \(b\in(1/2,1]\), no priority weight is at least \(b\), so

\(\operatorname{Mod}((C_\pi)_{\ge b})=S_1=\operatorname{Mod}(\kappa).\)

The fallback model \(\eta\) belongs to \(S_1\) and falsifies \(q\). Therefore none of these larger cuts entails \(q\), independently of the satisfiability of \(F\).

We have proved the exact equivalence

\(F\text{ is satisfiable}\quad\Longleftrightarrow\quad\text{the constructed query is accepted}.\)

This proves \(\mathrm{NP}\)-hardness, including the required failure of entailment at every larger threshold.

3. Deterministic running time

The following algorithm works for the general promised input and never constructs formulas representing survivor sets.

Let \(k=|\{r:\lambda_r\ge a\}|\le\ell\). Section 1 shows that only these \(k\) levels can matter.

Exact arithmetic

Write each mass as \(\rho_t=u_t/v_t\), and let

\(D=\prod_{t=1}^{\tau}v_t,\qquad c_t=u_t(D/v_t).\)

Then every \(c_t\) is a positive integer and \(\sum_t c_t=D\). Multiplying an objective by \(D\) preserves its minimizers, so use the integer scores

\(F_r(\omega)=\sum_{t=1}^{\tau}c_t\,d_H(\omega,K_t^r).\)

They satisfy \(0\le F_r(\omega)\le mD\). The binary length of \(D\) is at most the sum of the denominator lengths, hence \(O(L)\). All scores consequently have \(O(L+\log(m+1))\) bits.

Computing every stratum distance

Enumerate the \(2^m\) interpretations. For each relevant nonempty stratum, evaluate its formulas to identify its models.

Consider the graph whose vertices are interpretations and whose edges join interpretations differing in one variable. Its graph distance equals Hamming distance: every differing coordinate must be changed, and changing each such coordinate once gives a path of that length.

A breadth-first search initialized at all models of a stratum therefore computes its distance from every interpretation. Each search costs \(O((m+1)2^m)\) graph operations. Empty strata contribute distance zero directly.

The combined formula-evaluation cost is \(O(L2^m)\), because each input formula belongs to just one stratum of one type.

Retaining minimizers and testing the query

Initialize the survivor mask with the models of \(\kappa\). At each relevant level, accumulate the integer scores, find their minimum among current survivors, and retain every interpretation attaining it. Finally, apply the entailment and countermodel tests from Section 1.

The resulting operation count, including evaluation of \(\kappa\) and \(\phi\), is

\(O(2^m[L+\tau k(m+1)]),\)

plus polynomial preprocessing. These are elementary evaluation, graph, and arithmetic operations on operands of polynomial bit length. Thus the deterministic bit running time is

\(2^m\operatorname{poly}(L+m+\tau+\ell)=2^m\operatorname{poly}(L),\)

where the last equality uses the explicit input encoding, under which \(m,\tau,\ell\) are bounded by a polynomial in \(L\). In particular, this is polynomial for fixed \(m\), but the hardness reduction already fixes \(\tau=\ell=1\).

4. An oracle upper bound

A direct argument gives membership in \(\Delta_2^p=\mathrm{P}^{\mathrm{NP}}\), also for binary rational masses.

Let \(h_j\) be the optimum integer score at level \(j\). Suppose \(h_1,\ldots,h_{r-1}\) are known. To test whether the next optimum is at most an integer \(u\), ask whether there exist:

  • an interpretation \(\omega\models\kappa\);
  • interpretations \(\nu_t^j\models\bigwedge K_t^j\), for all \(t\) and \(j\le r\);

such that

\(\sum_t c_t d_H(\omega,\nu_t^j)\le h_j\quad(j<r),\)

and

\(\sum_t c_t d_H(\omega,\nu_t^r)\le u.\)

This is an \(\mathrm{NP}\) predicate: the certificate has \(O(m\tau r)\) bits, and all formulas and binary inequalities can be checked in polynomial time.

For any fixed \(\omega\), each actual stratum distance is at most its witnessed distance. Conversely, witnesses attaining every actual distance exist and can be chosen independently. Therefore the existential inequalities are equivalent to the corresponding inequalities on actual scores.

Moreover, within \(\operatorname{Mod}(\kappa)\), the conditions \(F_j(\omega)\le h_j\) for all \(j<r\) characterize \(S_r\). This follows inductively because \(h_j\) is the minimum over \(S_j\): once earlier conditions hold, a score at most \(h_j\) must equal that minimum.

Binary search on \([0,mD]\) now computes each \(h_r\) with \(O(L+\log(m+1))\) oracle calls. Entailment and its required predecessor failure are checked with at most two further calls, adding \(\omega\models\neg\phi\) to the same certificate conditions. The total is

\(O(k[L+\log(m+1)]+1)\)

calls to an \(\mathrm{NP}\) oracle, with polynomial computation and query length.

The cited paper’s Proposition 11 and Corollary 2 likewise describe an oracle bound for its discrete setting, rather than an ordinary polynomial-time algorithm. Our hardness proof applies directly to the complete-type problem specified here. [Qi, *A Model-based Approach for Merging Prioritized Knowledge Bases in Possibilistic Logic*](https://cdn.aaai.org/AAAI/2007/AAAI07-074.pdf)
