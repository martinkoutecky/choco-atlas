The continuous mirror question, as graded

Given finite candidate sites \(C\) in a metric space, voter types \(T\) represented by points \(p_t\), a rational distribution \(\mu\), committee size \(k\), and threshold \(\rho\), does there exist \(S\subseteq C\) with \(\lvert S\rvert=k\) such that \(\min_{t:\mu_t>0}\max_{c\in S} d(p_t,c)\ge\rho\)? The optimization version maximizes this minimum value.

Packaged proof task (what the prover saw — nothing else)

Input: a finite candidate set \(C\) with \(m=|C|\), voter locations \(p_t\) in an arbitrary metric space, and the full distance matrix on the distinct points in \(C\cup\{p_t:t\in T\}\), with nonnegative binary rational entries satisfying the metric axioms. Voters and candidates may share a location.
A society is given by its support: the list \(T\) of its \(\tau\ge1\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Also given are an integer \(1\le k\le m\) and a positive binary rational threshold \(\rho\). A committee is a subset \(S\subseteq C\) of exactly \(k\) sites; its value is \(F(S)=\min_{t\in T}\max_{c\in S}d(p_t,c)\). Equal distances are allowed, and threshold equality qualifies.
The decision problem asks whether some committee satisfies \(F(S)\ge\rho\); the optimization version maximizes \(F(S)\). Let \(L\) be the total binary input length; state running times in \(m,\tau,L,k\).

Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For a finite list of voters, the same committee decision problem is \(\mathrm{NP}\)-hard even for graph shortest-path metrics; it is polynomial-time solvable for planar Euclidean locations. [Source](https://doi.org/10.4230/LIPIcs.FSTTCS.2024.24)
No separate result explicitly treating the rational-distribution formulation was located.

Modeling choices made when packaging the task

  • Specified an explicit full binary rational distance matrix on the relevant distinct locations, since the graded question left the representation of an arbitrary metric unspecified.
  • Normalized the positive rational masses to sum to one, following the stated distribution interpretation, and required nonempty support.
  • Restricted the threshold to positive binary rationals, preserving the discrete definition's positivity while giving a finite input encoding.
  • Required an integer committee size between one and the number of candidate sites, excluding empty committees and infeasible oversized committees.
  • Allowed voter–candidate co-location and distance ties; retained the discrete definition's weak threshold inequality.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when \(\rho=2\), all distances between distinct input points belong to \(\{1,2\}\), and all masses are positive dyadic rationals. Consequently, exact optimization is \(\mathrm{NP}\)-hard.

The parameter \(\tau\) below is the number of explicitly listed support types.

1. Threshold feasibility is Set Cover

For each candidate \(c\), define
\[ A_c=\{t\in T:d(p_t,c)\ge\rho\}. \]

For every nonempty committee \(S\),
\[ F(S)\ge\rho \quad\Longleftrightarrow\quad (\forall t\in T)(\exists c\in S)\ d(p_t,c)\ge\rho \quad\Longleftrightarrow\quad \bigcup_{c\in S}A_c=T. \]

Thus feasibility asks whether these sets cover the support using exactly \(k\) candidates.

Covering with at most \(k\) candidates is equivalent: because \(k\le m\), any smaller cover can be extended to size \(k\), and adding candidates preserves coverage. The masses do not enter this equivalence.

2. Explicit polynomial reduction

We reduce from the standard \(\mathrm{NP}\)-complete Set Cover problem: given a nonempty universe \(U=\{u_1,\ldots,u_\tau\}\), sets \(B_1,\ldots,B_m\subseteq U\), and \(1\le k\le m\), determine whether at most \(k\) sets cover \(U\).

Create distinct candidate points \(c_1,\ldots,c_m\) and distinct voter points \(p_1,\ldots,p_\tau\), disjoint from the candidate points. Set \(\rho=2\). Define
\[ d(p_i,c_j)= \begin{cases} 2,&u_i\in B_j,\\ 1,&u_i\notin B_j. \end{cases} \]
Give every other pair of distinct points distance \(1\), impose symmetry, and give every point distance \(0\) from itself.

Metric verification. Positivity, symmetry, and identity of indiscernibles hold by construction. For three pairwise distinct points \(x,y,z\),
\[ d(x,z)\le2\le d(x,y)+d(y,z). \]
If any points coincide, the triangle inequality follows immediately from the zero diagonal and symmetry. Hence the entire supplied matrix is a metric.

Valid rational masses. Let \(b=\lceil\log_2\tau\rceil\), and assign
\[ \mu_i=2^{-b}\quad(1\le i<\tau), \qquad \mu_\tau=1-(\tau-1)2^{-b}. \]
Since \(\tau\le2^b\), every mass is positive. Their sum is \(1\), and each has binary encoding length \(O(\log(\tau+1))\). This also handles \(\tau=1\), when its sole mass is \(1\).

Correctness. By construction,
\[ d(p_i,c_j)\ge2\quad\Longleftrightarrow\quad u_i\in B_j. \]
Therefore a committee satisfies the threshold precisely when its associated sets cover \(U\). A cover of size at most \(k\) can be padded to exactly \(k\), as established above. Conversely, a feasible size-\(k\) committee supplies a cover using \(k\) sets.

The output length is
\[ O\!\left((m+\tau)^2+\tau\log(\tau+1)\right), \]
and the full matrix and masses can be constructed in polynomial time. This proves \(\mathrm{NP}\)-hardness for the stated encoding.

Graph-metric realization. Add an auxiliary vertex \(h\). Put an unweighted edge between every pair of input points whose prescribed distance is \(1\), and connect \(h\) to every input point. Prescribed distance-\(1\) pairs have shortest-path distance \(1\). Prescribed distance-\(2\) pairs have no direct edge and have a length-\(2\) path through \(h\), so their shortest-path distance is exactly \(2\). Thus these matrices also arise from unweighted graph shortest-path metrics.

3. Membership in \(\mathrm{NP}\)

A certificate lists the \(k\) distinct candidate indices. Its length is \(O(k\log(m+1))\).

Check distinctness and, for each support type, verify that some listed candidate has distance at least \(\rho\). Rational comparisons are exact: comparing \(a/b\) and \(r/s\), with positive denominators, reduces to comparing \(as\) and \(rb\).

Using elementary binary arithmetic, each comparison takes \(O(L^2)\) bit operations. A conservative verification bound is
\[ O\!\left(L+(m+\tau k)L^2\right). \]
The input promises valid masses and a valid metric. Hence the decision problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness.

4. Exact algorithms and optimization

Enumerating all size-\(k\) committees and evaluating their values gives an exact optimization algorithm in
\[ O\!\left(L+\binom{m}{k}\tau kL^2\right) \]
bit operations. The same bound applies to decision. In particular, both problems are polynomial-time solvable for every fixed \(k\).

Decision is also polynomial-time solvable for every fixed \(\tau\). First compute each threshold set \(A_c\). Maintain a table indexed by subsets \(Q\subseteq T\), storing the minimum number of processed candidates whose covered-type union is exactly \(Q\). Initially only the empty union has finite value, namely \(0\). When processing \(c\), each state \(Q\) permits either skipping \(c\), or taking it and updating \(Q\cup A_c\) with one additional candidate.

Induction over processed candidates proves the table invariant: these are exactly the two possibilities for every subset of processed candidates. The answer is yes precisely when the final value for \(T\) is at most \(k\). A conservative running-time bound is
\[ O\!\left(L+m\tau\,2^\tau L^2\right). \]

Exact optimization is \(\mathrm{NP}\)-hard because computing its optimum would decide whether that optimum reaches the supplied threshold.

5. Relation to the cited voter-list result

For a finite voter list, merge repeated locations and assign each resulting location its multiplicity divided by the list length. This preserves every committee value, since repeating an entry does not change a minimum. These rational masses have polynomial encoding length.

Thus the support formulation inherits voter-list hardness; the direct reduction above additionally verifies its rational-encoding requirements. The cited paper studies the corresponding farthest-member objective and proves general-metric hardness in Theorem 7. [Gupta et al., FSTTCS 2024](https://drops.dagstuhl.de/storage/00lipics/lipics-vol323-fsttcs2024/LIPIcs.FSTTCS.2024.24/LIPIcs.FSTTCS.2024.24.pdf)
