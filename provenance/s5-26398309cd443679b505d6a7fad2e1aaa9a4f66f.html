The continuous mirror question, as graded

Given rational cohort masses \(\mu_t\), \(K\) goods categories with rational per-capita supplies \(r_g\) and \(\rho=\sum_g r_g\), reported values \(\hat v_{t,g}\), and a promise that compatible hidden values satisfy \(v_{t,g}\in[0,b]\) and \(|v_{t,g}-\hat v_{t,g}-\delta_t|\le\varepsilon\) for some \(\delta_t\ge0\), compute a sparse rational mass assignment \(x_{t,q}\) in time polynomial in \(\tau\), \(K\), and input bit length \(L\). Bundles \(q\in\mathbb{Z}_{\ge0}^K\) must satisfy \(\|q\|_1\in\{\lfloor\rho\rfloor,\lceil\rho\rceil\}\), with \(\sum_q x_{t,q}=\mu_t\) and \(\sum_{t,q}q_gx_{t,q}=r_g\); for every compatible value matrix, every assigned bundle \(q\) of type \(t\), and every bundle \(q'\) assigned positive mass, require \(\sum_g v_{t,g}(q'_g-q_g)\le 2\varepsilon\lceil\rho\rceil+b\).

Result

The search problem is polynomial-time solvable in \(m,\tau,L\). A deterministic algorithm produces a robust assignment with at most \(\tau+m\) positive entries.

The construction compresses round-robin on a potentially enormous discrete society. Its running time depends on the binary encoding length of the masses and supplies, rather than on the number of agents or items in that discrete society.

The [cited paper, Theorem 3](https://daniel-halpern.com/files/fair-division-inaccurate.pdf), provides the discrete motivation. Below, both the compressed construction and its robust guarantee are proved directly.

1. An integer representation

Write the masses and supplies as fractions with positive integer denominators. Let \(N\) be twice the product of all these denominators. Define

\(n_t:=N\mu_t,\qquad M_g:=Nr_g,\qquad M:=\sum_g M_g=N\rho.\)

These are integers, each \(n_t\) is positive, and \(\sum_t n_t=N\). Moreover, \(N\geq2\).

Consider a conceptual discrete instance consisting of:

  • \(N\) virtual agents, with \(n_t\) consecutive agents of each type \(t\);
  • \(M_g\) identical items of category \(g\).

Every virtual agent represents population mass \(1/N\). Its report for an item of category \(g\) is \(\hat v_{t,g}\).

Fix a ranking of categories for each type by decreasing report, breaking ties by category index. Run conceptual round-robin in the fixed agent order, using these rankings.

We will simulate this process without enumerating its agents, items, or rounds.

2. Compressed round-robin

Index virtual agents by the integers in \([0,N)\). Define type boundaries

\(A_0:=0,\qquad A_t:=\sum_{u=1}^{t}n_u.\)

Thus type \(t\) occupies \([A_{t-1},A_t)\).

Maintain a partition of \([0,N)\) into intervals with integer endpoints. Each interval lies within one type block and stores a single integer bundle vector shared by all its agents. Initially, the intervals are the type blocks and every bundle is zero.

Let \(R_g\) denote the remaining integer inventory of category \(g\), initially \(M_g\). Every iteration below begins at a round boundary.

Batching complete rounds

If any inventory remains, let \(p_t\) be type \(t\)'s highest-ranked category with positive remaining inventory. Define

\(C_g:=\sum_{t:p_t=g}n_t.\)

Here \(C_g\) is the number of picks of category \(g\) in one round if every type keeps its current first choice. In particular, \(\sum_g C_g=N\).

Compute the integer

\(h:=\min_{g:C_g>0}\left\lfloor R_g/C_g\right\rfloor.\)

If \(h>0\), process \(h\) complete rounds at once:

  • add \(h\,e_{p_t}\) to every stored bundle of type \(t\), where \(e_g\) is the unit vector for category \(g\);
  • replace each inventory by \(R_g-hC_g\);
  • return to the beginning of the iteration.

This batch exactly reproduces round-robin. Consider the planned sequence consisting of \(h\) rounds with choices \(p_t\). For category \(g\), that sequence makes exactly \(hC_g\) picks, and \(R_g\geq hC_g\). Consequently, category \(g\) is available before every planned pick of it.

At each planned pick, the agent’s initially highest-ranked available category therefore remains available. Other categories can only disappear, so that planned category remains highest-ranked among those still available. Induction over the planned picks proves the claim.

Processing an exceptional round

If \(h=0\), process one round, or its final incomplete portion, by scanning the type blocks from left to right.

Suppose the next unprocessed agent has index \(s\) and belongs to type \(t\). Let \(g\) be type \(t\)'s highest-ranked category with \(R_g>0\), and set

\(\ell:=\min\{A_t-s,R_g\}.\)

Give one category-\(g\) item to every agent in \([s,s+\ell)\). This means adding \(e_g\) to the stored bundles on that interval, splitting stored intervals at its endpoints when necessary. Then replace \(R_g\) by \(R_g-\ell\) and advance \(s\) to \(s+\ell\).

Continue until the round finishes or all inventories are zero. If inventories remain after a complete round, return to batching.

This segment operation is exact: throughout its interior the type and available categories are unchanged. Its endpoint is either a type boundary or the exhaustion of the selected category.

3. Polynomially many operations and sparse output

A category can become exhausted only once. There are therefore at most \(m\) exhaustion events.

Number of exceptional rounds

Every exceptional round exhausts at least one category.

Indeed, \(h=0\) means that some category satisfies \(C_g>0\) and \(R_g<C_g\). If a complete round were processed without any exhaustion, availability would remain unchanged throughout that round. Its choices would therefore be precisely the \(p_t\), requiring \(C_g\) items of category \(g\), which is impossible.

If processing instead stops because all inventories are zero, an exhaustion has also occurred. Thus there are at most \(m\) exceptional rounds.

Within one exceptional round, each segment ends at a type boundary or an exhaustion. Across all exceptional rounds, there are consequently at most \(m\tau+m\) segments.

Number of batches

If a positive batch exhausts a category, charge that batch to one such exhaustion.

If it exhausts no category, availability is unchanged. A category attaining the minimum defining \(h\) has new inventory

\(0<R_g-hC_g<C_g.\)

The next iteration therefore has \(h=0\), and its exceptional round exhausts a category. Charge the batch to an exhaustion in that round.

These charges use distinct exhaustion events: every iteration advances the process, and each batch without an exhaustion is immediately followed by its exceptional round. Hence there are at most \(m\) positive batches.

Number of stored intervals

Initially there are \(\tau\) intervals.

Batches introduce no new boundaries. During an exceptional round, a segment starts at a type boundary or the endpoint of the preceding segment, so its starting boundary already exists. Its ending boundary is either:

  • a type boundary, which already exists; or
  • the position of a category exhaustion, which introduces at most one boundary.

Thus at most \(m\) new boundaries are introduced, and the final partition contains at most \(\tau+m\) intervals.

For a final interval \([\alpha,\beta)\) of type \(t\) with bundle \(q\), output population mass

\(x_{t,q}:=(\beta-\alpha)/N.\)

If several intervals have the same pair \((t,q)\), combine their masses. Every output mass is positive and rational, and the output has at most \(\tau+m\) entries.

4. Feasibility and balance

The compressed algorithm exactly reproduces the conceptual round-robin allocation.

Every virtual agent receives a bundle, possibly the zero bundle. Since the intervals partition each type block, the output satisfies

\(\sum_q x_{t,q}=n_t/N=\mu_t.\)

All \(M_g\) items of every category are allocated, giving

\(\sum_{t,q}q_gx_{t,q}=M_g/N=r_g.\)

Round-robin allocates \(M\) items in the fixed cyclic order of \(N\) agents. There are \(\lfloor M/N\rfloor\) complete rounds, followed by at most one incomplete round. Every bundle therefore has cardinality in

\(\{\lfloor M/N\rfloor,\lceil M/N\rceil\}=\{\lfloor\rho\rfloor,\lceil\rho\rceil\}.\)

Thus all assignment constraints hold exactly.

5. Robust envy bound

Fix an arbitrary compatible matrix and compatible shifts. Write

\(v_{t,g}=\hat v_{t,g}+\delta_t+\eta_{t,g},\qquad |\eta_{t,g}|\leq\varepsilon.\)

Whenever \(\hat v_{t,g}\geq\hat v_{t,h}\), cancellation of the common shift gives

\(v_{t,h}-v_{t,g}=(\hat v_{t,h}-\hat v_{t,g})+(\eta_{t,h}-\eta_{t,g})\leq2\varepsilon.\)

This inference permits negative reports and requires no bound on \(\delta_t\).

Consider virtual agent \(i\) of type \(t\), with pick sequence \(a_1,\ldots,a_A\), and another virtual agent \(j\), with pick sequence \(c_1,\ldots,c_B\). Here each sequence records item categories, and valuations below use type \(t\)'s row.

If \(B=0\), nonnegativity of values implies that \(i\)'s envy is at most zero.

Suppose \(B\geq1\). Balance gives \(A\geq B-1\). For each \(k\) with \(1\leq k\leq B-1\), agent \(i\)'s \(k\)-th pick occurs in round \(k\), before agent \(j\)'s \((k+1)\)-st pick in round \(k+1\).

The particular item eventually chosen in that later pick is still available at \(i\)'s earlier pick. Hence the round-robin choice satisfies

\(\hat v_{t,a_k}\geq\hat v_{t,c_{k+1}},\)

and therefore

\(v_{t,c_{k+1}}-v_{t,a_k}\leq2\varepsilon.\)

Now separate \(j\)'s first item, pair its remaining items with \(i\)'s first \(B-1\) items, and use nonnegativity for any remaining items of \(i\). This gives

\(\displaystyle \sum_{k=1}^{B}v_{t,c_k}-\sum_{k=1}^{A}v_{t,a_k} = v_{t,c_1} +\sum_{k=1}^{B-1}(v_{t,c_{k+1}}-v_{t,a_k}) -\sum_{k=B}^{A}v_{t,a_k} \leq b+2\varepsilon(B-1), \)

where an empty sum is zero.

Since \(B\leq\lceil\rho\rceil\), the required bound follows:

\(\displaystyle \sum_{k=1}^{B}v_{t,c_k}-\sum_{k=1}^{A}v_{t,a_k} \leq b+2\varepsilon\lceil\rho\rceil. \)

Every positive output entry is realized by at least one virtual agent. Thus, for any positive entries \(x_{t,q}\) and \(x_{u,q'}\), choose corresponding virtual agents and apply the preceding inequality. If the entries coincide, the comparison is zero. This also covers distinct bundles assigned within the same type.

The algorithm uses only reports, masses, and supplies. Because the compatible matrix was arbitrary, this single output satisfies all the required comparisons simultaneously for every compatible matrix.

6. Binary running time

The product defining \(N\) has binary length \(O(L)\): the sum of the binary lengths of its denominator factors is bounded by the input length.

The integers \(n_t\), \(M_g\), interval endpoints, inventories, demands, and batch counts all have binary lengths polynomial in \(L+\log m\). Bundle coordinates are bounded by \(\lceil\rho\rceil\), whose binary length is also polynomial in the input length. Each output mass has numerator at most \(N\) and denominator \(N\).

Category rankings can be computed by polynomially many exact rational comparisons. The algorithm performs at most \(m\) batches and \(m\tau+m\) exceptional segments, maintaining at most \(\tau+m\) intervals and \(m\) bundle coordinates per interval. Each operation uses exact integer arithmetic on numbers of polynomial binary length.

Therefore both the running time and the output encoding length are polynomial in \(m,\tau,L\). This completes the proof.
