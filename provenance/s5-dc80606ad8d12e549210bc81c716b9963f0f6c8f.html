The continuous mirror question, as graded

Given \(m\) binary proposals and a finite-support rational distribution \(\mu\) over complete preference vectors \(v\in\{0,1\}^m\), with proposals revealed online through the distributions of prefixes, does there exist a polynomial-time online rule choosing \(A_j\in\{0,1\}\) such that every supported type \(v\) receives utility \(\sum_{j=1}^m\mathbf{1}[A_j=v_j]\ge \min_{w\in\operatorname{supp}(\mu)}\sum_{j=1}^m\mathbf{1}[v_j=w_j]\)?

Packaged proof task (what the prover saw — nothing else)

Let \(m\geq1\). A society is encoded by its nonempty support \(S\subseteq\{0,1\}^m\): a list of \(\tau=|S|\) distinct types with positive binary-rational masses \(\mu(v)\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total bit length of this encoding.
At step \(j\), the rule receives only the prefix distribution \(\mu_j(p)=\sum_{v\in S:v_{1:j}=p}\mu(v)\), listed by its positive-mass prefixes. It must irrevocably choose \(A_j\in\{0,1\}\); its choice depends only on the prefix distributions received so far, with no advance knowledge of the horizon or unrevealed suffixes.
Define \(u_v(A)=\sum_{j=1}^m\mathbf{1}[A_j=v_j]\) and \(g_v(S)=\min_{w\in S}\sum_{j=1}^m\mathbf{1}[v_j=w_j]\). The required guarantee is \(u_v(A)\geq g_v(S)\) for every \(v\in S\), for every finite input society.

Does a deterministic online rule achieve this guarantee for all societies, and, if such a rule exists, can its total running time be polynomial in \(m,\tau,L\)?

For finite societies, adaptive maximin share is obtained by partitioning the proposals into \(n\) possibly empty bundles and maximizing utility against the worst bijective assignment of bundles to agents, each of whom decides its assigned proposals. No online algorithm guarantees this share for \(n\geq7\). [Source](https://arxiv.org/html/2408.08767v1)
This is an online impossibility result for a different benchmark, rather than an NP-hardness result for the guarantee defined above. No result settling the exact distribution-and-prefix problem was located.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: all listed masses are positive binary rationals and sum to one, with nonempty support and at least one proposal.
  • Specified deterministic, irrevocable decisions and a universal guarantee over all finite societies.
  • Resolved prefix revelation as an explicit list of distinct positive-mass prefixes with aggregated masses; the full support encoding is used to measure input size but is not available in advance.
  • Excluded advance horizon information to follow the definition that online choices depend only on revealed columns; support size and encoding length are complexity measures, not additional observations.

Result

Yes. A deterministic online rule achieves the guarantee in polynomial total time.

The key observation is that every outcome belonging to \(S\) satisfies the benchmark. The prefix information allows the rule to construct such an outcome online, for every nonempty support, without knowing the horizon.

The online rule

Let \(P_j=\{v_{1:j}:v\in S\}\), which is exactly the set of positive-mass prefixes listed in the input at step \(j\). Positivity of all masses ensures this equality.

Maintain the already chosen prefix \(q=A_1\cdots A_{j-1}\), initially the empty string. At step \(j\):

  • If \(q0\in P_j\), choose \(A_j=0\).
  • Otherwise, choose \(A_j=1\).

Then append \(A_j\) to \(q\).

Membership in \(P_j\) is determined solely from the current input list. The rule is deterministic, and uses neither unrevealed suffixes nor the horizon.

Proof that the rule always follows a supported prefix

We prove by induction that after every step \(j\), the chosen prefix \(A_{1:j}\) belongs to \(P_j\).

Before the first step, the empty prefix has an extension in \(S\), because \(S\) is nonempty.

Suppose the previously chosen prefix \(q=A_{1:j-1}\) has an extension \(v\in S\). The next bit of \(v\) is either zero or one, so at least one of \(q0,q1\) belongs to \(P_j\).

If \(q0\in P_j\), the rule chooses it. Otherwise, the preceding observation implies \(q1\in P_j\), and the rule chooses that prefix. This proves the induction step.

At the actual final step, \(P_m=S\). Consequently, the complete outcome satisfies \(A\in S\). The argument applies to every finite horizon, although the rule never knows which step is final.

Proof of the guarantee

Fix any \(v\in S\). Since \(A\in S\), its agreement with \(v\) is one of the values over which the defining minimum for \(g_v(S)\) is taken. Therefore,

\(u_v(A)=\sum_{j=1}^{m}\mathbf{1}[A_j=v_j]\geq\min_{w\in S}\sum_{j=1}^{m}\mathbf{1}[w_j=v_j]=g_v(S)\).

The same outcome \(A\) satisfies this inequality for every \(v\in S\). This completes the correctness proof.

Polynomial running time

At step \(j\), there are at most \(\tau\) positive prefixes, each of length \(j\). A linear scan tests whether \(q0\) occurs using \(O(j\tau)\) bit comparisons. Summing over all steps gives \(O(m^2\tau)\) comparisons. No arithmetic on masses is needed.

For completeness, reading the rational masses also has polynomial cost under the standard explicit binary encoding. Write the original masses as \(\mu(v)=a_v/b_v\), and set \(D=\prod_{v\in S}b_v\). The binary length of \(D\) is \(O(L)\). Every prefix mass is \(N/D\) for an integer \(N\) satisfying \(0<N\leq D\), since it is a sum of original masses and is at most one. Thus each prefix mass has an exact numerator-denominator encoding of \(O(L)\) bits; reducing the fraction cannot increase this bound.

The total length of all prefix distributions is therefore \(O(m\tau(m+L))\). Including input traversal, the rule runs in \(O(m\tau(m+L))\) total bit time, which is polynomial in the requested parameters.

Relation to adaptive maximin share

The [cited paper](https://arxiv.org/html/2408.08767v1) uses a benchmark that optimizes over partitions and then minimizes over assignments of bundles. That benchmark can exceed the minimum agreement with a single supported type used here.

For example, take eight agents and eight proposals: one agent has type \(0^8\), and seven have type \(1^8\). The corresponding masses are \(1/8\) and \(7/8\). Both supported types have \(g_v(S)=0\), so the rule’s outcome \(0^8\) satisfies the present guarantee. But partitioning the proposals into eight singleton bundles guarantees every type-\(1^8\) agent utility seven under every bijective assignment. Thus this rule need not achieve adaptive maximin share, and the two conclusions are compatible.
