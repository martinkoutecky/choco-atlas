The continuous mirror question, as graded

Given a finite program set \(C\), student types \(T\) with rational masses \(\mu_t\) summing to \(1\), strict type rankings, strict program priorities over types, and rational per-capita capacities \(\kappa_i\), compute the student-optimal stable assignment-mass matrix \(x_{ti}\), including unmatched mass, subject to \(\sum_i x_{ti}=\mu_t\) and \(\sum_t x_{ti}\leq\kappa_i\). Does this allocation equal the sequence-independent limit of normalized finite student-optimal stable matchings—and thus of the finite SPE outcomes in Theorem 3.1—whenever type frequencies and capacities converge to \(\mu\) and \(\kappa\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty set of \(m\) programs. A society is given by its support: the list of the \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length.
Each type has a strict ranking \(\succ_t\) of \(C\cup\{\varnothing\}\), and each program has a strict priority order \(\succ_i\) on \(T\cup\{\varnothing\}\). The outside option determines acceptability on both sides. Capacities \(\kappa_i\) are nonnegative binary rationals; programs have responsive preferences and prefer filling seats with acceptable types.
A feasible matrix has real entries \(x_{ti}\geq0\), including \(x_{t\varnothing}\), with \(\sum_{i\in C\cup\{\varnothing\}}x_{ti}=\mu_t\) and \(\sum_t x_{ti}\leq\kappa_i\); positive program assignments must be mutually acceptable.
It is stable if there are no \(t,i,j\) with \(x_{tj}>0\), \(i\succ_t j\), \(t\succ_i\varnothing\), and either \(\sum_u x_{ui}<\kappa_i\) or \(x_{ui}>0\) for some \(u\) with \(t\succ_i u\). Equal-type mass cannot displace itself.
A stable matrix \(x^S\) is student-optimal if, for every stable \(y\), type \(t\), and cutoff alternative \(a\), \(\sum_{j\succeq_t a}x^S_{tj}\geq\sum_{j\succeq_t a}y_{tj}\).
Finite approximations have \(N\to\infty\) students drawn from these types, counts \(n_t^N\), and integer quotas \(q_i^N\), with \(n_t^N/N\to\mu_t\) and \(q_i^N/N\to\kappa_i\). Students retain their type rankings; programs use responsive preferences with arbitrary strict refinements within each type, preserving the type order and acceptability. Let \(X^N_{ti}\) count type-\(t\) students assigned to \(i\) in the finite student-optimal stable matching, including unmatched students.
The finite sequential game lets students, in any fixed order, publicly choose one program or remain unmatched; programs then simultaneously choose their preferred subsets of applicants, and only accepted applicants are matched.

Does every input admit a unique student-optimal stable matrix? Is computing such a matrix, or reporting its nonexistence, in \(\mathrm{P}\) with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?
Whenever \(x^S\) exists, does \(X^N/N\to x^S\) entrywise for every finite approximation and every within-type priority refinement, and hence for all finite SPE outcomes, or can this limit claim fail?

In finite markets with strict student preferences and substitutive program preferences, every SPE outcome of the sequential game is the student-optimal stable matching, independently of student order ([Alcalde–Romero-Medina](https://doi.org/10.1016/j.econlet.2004.06.013)).
For a different continuum model with zero mass at each program priority score, convergence of finite stable matchings is established when the continuum stable matching is unique; this does not cover the positive-mass type model above ([Azevedo–Leshno](https://eduardomazevedo.github.io/papers/Azevedo-Leshno-Supply-and-Demand-Matching.pdf)).

1. Reduction to stable allocation

We use the bipartite stable-allocation theorem. Its inputs are a finite bipartite graph, strict orders over incident neighbors, positive vertex budgets \(b_v\), and finite edge upper bounds \(u_{rc}\). Feasible allocations satisfy the vertex budgets and edge bounds. Stability means that, for every edge \((r,c)\),

\(z_{rc}<u_{rc}\ \Longrightarrow\ \sum_{d\succeq_r c}z_{rd}=b_r\ \text{ or }\ \sum_{s\succeq_c r}z_{sc}=b_c.\)

The theorem guarantees a stable allocation and a row-optimal stable allocation \(z^R\), computable with strongly polynomially many arithmetic operations. Row optimality means that, for every stable \(y\),

\(z^R_{rc}<y_{rc}\ \Longrightarrow\ z^R_{rd}=0\text{ for every }d\prec_r c.\)

These facts follow from the inductive and row-optimal algorithms in Baïou–Balinski’s corrected reprint, specifically Theorem 2, Corollary 1, Theorem 10, and Corollary 4. Their numerical operations are additions, subtractions, comparisons, and minima. [Corrected stable-allocation paper](https://pubsonline.informs.org/doi/pdf/10.1287/moor.27.4.662.302).

Construct an instance as follows.

  • The row vertices are the \(\tau\) supported types, with budgets \(b_t=\mu_t\).
  • The column vertices are the programs with positive capacity, with budgets \(b_i=\kappa_i\), together with a dummy program \(d\) of budget \(1\).
  • Include a real-program edge exactly when the pair is mutually acceptable.
  • Connect every type to \(d\). Each type ranks its real neighbors according to \(\succ_t\), followed by \(d\). Give \(d\) any strict order over the types.
  • Give every included edge upper bound \(2\).

Programs of zero capacity can be omitted because their assignment entries must be zero. All retained vertex budgets are positive. Moreover, every feasible edge allocation is at most \(\mu_t\leq 1\), so the upper bound \(2\) never binds.

Every stable allocation of this constructed instance saturates every type budget. Indeed, if some type \(t\) is unsaturated, then

\(\sum_u z_{ud}\leq\sum_{u,c}z_{uc}<\sum_u\mu_u=1.\)

Thus \(d\) is unsaturated. At the edge \((t,d)\), both cumulative sums in the stability condition are strictly below their budgets, producing a blocking edge.

Consequently, identifying \(z_{td}\) with \(x_{t\varnothing}\) gives a feasible matrix in the question.

We now check stability exactly. For a real-program edge \((t,i)\), saturation of the type budget gives

\(\sum_{j\succeq_t i}x_{tj}<\mu_t \ \Longleftrightarrow\ x_{tj}>0\text{ for some }j\prec_t i.\)

Similarly, feasibility at \(i\) gives

\(\sum_{u\succeq_i t}x_{ui}<\kappa_i \ \Longleftrightarrow\ \sum_u x_{ui}<\kappa_i \text{ or }x_{ui}>0\text{ for some }u\prec_i t.\)

These are precisely the two sides of a blocking triple in the question. In particular, the program’s cumulative sum includes type \(t\) itself: equal-type mass cannot displace itself.

Dummy edges cannot block once type budgets are saturated, because \(d\) is every type’s last neighbor. Conversely, every stable matrix from the question becomes a stable allocation after replacing \(\varnothing\) by \(d\). Thus the construction gives a bijection between the two sets of stable objects.

2. Existence and uniqueness of the required optimum

Let \(z^R\) be the row-optimal allocation, and let \(x^S\) be its corresponding matrix. It is stable by the preceding equivalence.

Fix any stable matrix \(y\), type \(t\), and cutoff alternative \(a\). Suppose, for contradiction, that

\(\sum_{j\succeq_t a}x^S_{tj}<\sum_{j\succeq_t a}y_{tj}.\)

Some alternative \(j\succeq_t a\) must then satisfy \(x^S_{tj}<y_{tj}\). Its positive assignment in \(y\) means that it corresponds to an included edge, interpreting \(\varnothing\) as \(d\).

Row optimality implies that \(x^S\) assigns no mass of type \(t\) to any alternative strictly below \(j\). Hence all its type-\(t\) mass lies weakly above \(j\), and therefore weakly above \(a\). It follows that

\(\sum_{\ell\succeq_t a}x^S_{t\ell}=\mu_t \geq\sum_{\ell\succeq_t a}y_{t\ell},\)

a contradiction. Omitted alternatives have zero assignments and cause no difficulty. Thus \(x^S\) satisfies every cumulative inequality required in the question.

For uniqueness, suppose \(x\) and \(x'\) both satisfy student optimality. Applying their defining inequalities to each other makes every type’s cumulative sums equal. Differences of consecutive cumulative sums recover individual entries, since rankings are strict. Therefore \(x=x'\).

3. Polynomial bit complexity

The constructed instance has \(\tau\) row vertices, at most \(m+1\) column vertices, and at most \(\tau(m+1)\) edges. Its encoding length is polynomial in \(m,\tau,L\).

Apply the stable-allocation algorithms cited above. Their arithmetic-operation count is polynomial in these graph dimensions.

To check bit complexity, let \(D\) be the product of all denominators of the input masses and capacities. Its binary length is \(O(L)\). Scale budgets and edge bounds by \(D\). The algorithms now operate on integers, using additions, subtractions, comparisons, and minima. Stored quantities are allocations, budgets, sums, and residual capacities; their binary lengths remain polynomial in \(m,\tau,L\). Dividing the output by \(D\) therefore gives an exact rational matrix in polynomial time.

Thus the requested computation is in \(\mathrm{P}\). On every valid input, the algorithm returns the unique student-optimal stable matrix.

4. A counterexample to universal convergence

Take types \(A,B\) and programs \(1,2\), with

\(\mu_A=\mu_B=\kappa_1=\kappa_2=\tfrac12.\)

All pairs are mutually acceptable. Preferences and priorities are

\(1\succ_A2\succ_A\varnothing,\qquad 2\succ_B1\succ_B\varnothing,\)

\(B\succ_1A\succ_1\varnothing,\qquad A\succ_2B\succ_2\varnothing.\)

The student-optimal matrix is

| Type | Program \(1\) | Program \(2\) | \(\varnothing\) |
|---|---:|---:|---:|
| \(A\) | \(\tfrac12\) | \(0\) | \(0\) |
| \(B\) | \(0\) | \(\tfrac12\) | \(0\) |

It is stable because every student receives their first choice. It dominates every feasible matrix in the required cumulative order.

For clarity, the entire continuum stable set can also be determined. No stable matrix can have \(x_{A\varnothing}>0\): then \(x_{A2}<\tfrac12\), so program \(2\) either has a vacancy or assigns positive mass to \(B\). Since \(A\) has highest priority there, either possibility blocks. Likewise, \(x_{B\varnothing}>0\) would block at program \(1\).

Thus all mass is assigned, and both programs are full. The row and column equations force the following form, for \(0\leq\delta\leq\tfrac12\):

| Type | Program \(1\) | Program \(2\) | \(\varnothing\) |
|---|---:|---:|---:|
| \(A\) | \(\tfrac12-\delta\) | \(\delta\) | \(0\) |
| \(B\) | \(\delta\) | \(\tfrac12-\delta\) | \(0\) |

Every such matrix is stable. Type \(A\) mass at program \(2\) would prefer program \(1\), but program \(1\) is full and contains only \(B\), which has higher priority, and \(A\), which cannot displace itself. The argument for type \(B\) is symmetric. The student-optimal endpoint is \(\delta=0\).

Now define a finite approximation for every \(N\geq2\). Put \(k=\lfloor N/2\rfloor\) and set

\(n_A^N=k,\qquad n_B^N=N-k,\qquad q_1^N=k-1,\qquad q_2^N=k.\)

These normalized counts and quotas converge to the specified masses and capacities. Choose any permitted strict refinements within each type.

We show that every finite stable matching has the following counts:

| Type | Program \(1\) | Program \(2\) | Unmatched |
|---|---:|---:|---:|
| \(A\) | \(k\cdot0\) | \(k\) | \(0\) |
| \(B\) | \(k-1\) | \(0\) | \(N-2k+1\) |

The first entry is simply \(0\); the proof is as follows.

  • Every \(A\)-student is matched. If an \(A\)-student were unmatched, fewer than \(k\) \(A\)-students would occupy program \(2\). That program has \(k\) seats, so it would have a vacancy or an assigned \(B\)-student. The unmatched \(A\)-student would block in either case.
  • Some \(B\)-student is unmatched. Total capacity is \(2k-1<N\), and every \(A\)-student is matched.
  • No \(A\)-student is assigned to program \(1\). Otherwise an unmatched \(B\)-student would block there, because every \(B\)-student outranks every \(A\)-student at program \(1\).
  • Therefore all \(k\) \(A\)-students occupy program \(2\), filling it. Program \(1\) must contain \(k-1\) \(B\)-students: a vacancy would block with an unmatched \(B\)-student.

These arguments use only comparisons between different types. They hold for every within-type refinement. Existence can also be checked directly: assign all \(A\)-students to program \(2\), assign program \(1\) its highest-ranked \(k-1\) \(B\)-students, and leave the remaining \(B\)-students unmatched. No pair blocks.

In particular, the finite student-optimal stable matching has these counts. Hence \(X^N/N\) converges entrywise to

| Type | Program \(1\) | Program \(2\) | \(\varnothing\) |
|---|---:|---:|---:|
| \(A\) | \(0\) | \(\tfrac12\) | \(0\) |
| \(B\) | \(\tfrac12\) | \(0\) | \(0\) |

This is the opposite endpoint, \(\delta=\tfrac12\), and differs from \(x^S\). For example,

\(X^N_{A1}/N=0\quad\text{for every }N,\qquad x^S_{A1}=\tfrac12.\)

The finite programs’ responsive preferences are substitutive, and all individual preferences and refinements are strict. Therefore the finite SPE theorem stated in the question applies: every SPE outcome has these same counts, independently of student order. Thus convergence to \(x^S\) fails for all SPE outcomes along this approximation. [Alcalde–Romero-Medina](https://www.sciencedirect.com/science/article/pii/S0165176504002514).

5. What convergence does hold

A useful positive statement is that every accumulation point of normalized finite stable matchings is a stable matrix.

Indeed, normalized matrices lie in a bounded finite-dimensional set. Any subsequential limit \(x\) satisfies feasibility and acceptability by passage to the limit.

If \(x\) had a blocking triple \((t,i,j)\), then \(x_{tj}>0\). Either program \(i\) would have strictly positive vacancy, or \(x_{ui}>0\) for some strictly lower-priority type \(u\). These strict inequalities persist along the convergent subsequence. For sufficiently large finite markets, they supply a type-\(t\) student at \(j\) and either an empty seat at \(i\) or a lower-priority student there. That is a finite blocking pair, contradicting stability.

Consequently, if the continuum input has exactly one stable matrix, every finite stable approximation converges to it: otherwise a subsequence staying a positive distance away would have a different stable accumulation point.

The counterexample has multiple stable matrices. Its uniquely defined student-optimal matrix need not be selected by finite approximations.
