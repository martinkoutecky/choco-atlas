The continuous mirror question, as graded

Given candidates \(C\) and a finite support \(T\) of \(\tau\) types, each with ranking \(\succ_t\), known monotone weight vector \(w_t\), and binary-rational mass \(\mu_t\) summing to \(1\), let \(X\) be a measurable population partitioned into sets \(X_t\) of mass \(\mu_t\). For every measurable metric \(d\) on \(X\cup C\) with finite costs and consistent with each type’s ranking, can an algorithm using only \(C,T\), the rankings, weights, and masses output a ranking \(\sigma\) satisfying \(\int_X\sum_{j=1}^m w_{t(x),j}d(x,\sigma_j)\,dx \leq 3\min_{\pi\in S_C}\int_X\sum_{j=1}^m w_{t(x),j}d(x,\pi_j)\,dx\), in time polynomial in \(m,\tau\), and the input bit length \(L\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a set of \(m\geq1\) candidates. A society is given by its support: a list \(T\) of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type has a strict ranking \(\succ_t\) of \(C\) and a known binary-rational weight vector satisfying \(w_{t,1}\geq\cdots\geq w_{t,m}\geq0\), with no further normalization. Let \(L\) be the total input bit length.
A realization is an atomless probability space \((X,\mathcal A,\nu)\), disjoint from \(C\), with a measurable partition \((X_t)_{t\in T}\) satisfying \(\nu(X_t)=\mu_t\). Write \(t(x)=t\) for \(x\in X_t\).
Admissible distances are measurable pseudometrics \(d\) on \(X\cup C\), allowing distinct points to be co-located, satisfying \(a\succ_t b\Rightarrow d(x,a)\leq d(x,b)\) for every \(x\in X_t\). Distance ties may therefore be ordered arbitrarily in the strict input rankings.
For a permutation \(\pi\in S_C\), define \(\operatorname{SC}_d(\pi)=\int_X\sum_{j=1}^m w_{t(x),j}d(x,\pi_j)\,d\nu(x)\); restrict to admissible distances for which these costs are finite.

Does a deterministic algorithm using only \(C,T,(\succ_t,w_t,\mu_t)_{t\in T}\) run in time polynomial in \(m,\tau,L\) and output a single ranking \(\sigma\in S_C\) such that \(\operatorname{SC}_d(\sigma)\leq3\min_{\pi\in S_C}\operatorname{SC}_d(\pi)\) for every realization and every admissible \(d\), including when the minimum is zero?

For finite societies with known monotone weights, Recursive FractionalVeto runs in polynomial time and achieves distortion at most \(3\), optimal among deterministic weight-aware rules. [Discrete result](https://arxiv.org/html/2608.21790v1).
No result settling this exact atomless-population guarantee was identified in the literature search.

Modeling choices made when packaging the task

  • The weight encoding was unspecified; weights are binary rationals included in L, nonnegative and nonincreasing, with no normalization and with zero vectors allowed.
  • The population measure was unspecified; use an atomless probability space with measurable type classes of the prescribed masses.
  • Use pseudometrics to preserve the discrete model's explicit allowance for co-location.
  • Input rankings are strict permutations, while metric consistency uses weak distance inequalities and permits distance ties.
  • Interpret finite costs as finiteness of the weighted cost of every ranking; express the guarantee as an inequality even when the optimum is zero.
  • Make determinism and the quantifier order explicit: one ranking computed from the support data must work for every compatible population realization and distance.

Result

Yes. Replace each type by one finite voter with weight vector \(\widetilde w_t=\mu_t w_t\), and run deterministic Recursive FractionalVeto on that finite instance. This takes time polynomial in \(m,\tau,L\) and satisfies the requested inequality, including when the optimum is zero.

The essential point is that averaging distances within a type preserves the conditions needed to extend those distances to a finite pseudometric.

1. Algorithm and the finite theorem

Let \(T_+=\{t\in T:w_{t,1}>0\}\). By monotonicity and nonnegativity, every type outside \(T_+\) has an identically zero weight vector.

If \(T_+\) is empty, output any fixed ordering of \(C\). Every ranking then has cost zero.

Otherwise, construct a finite voter set \(V=\{v_t:t\in T_+\}\), using fresh labels disjoint from \(C\). Give \(v_t\) ranking \(\succ_t\) and weights

\(\displaystyle \widetilde w_{t,j}=\mu_t w_{t,j}.\)

Run Recursive FractionalVeto on this finite instance, with every algorithmic choice resolved by fixed input orders, and output its ranking \(\sigma\).

We use the supplied finite result in the following form: Recursive FractionalVeto runs in polynomial time on finite elections with known rational, nonnegative, monotone positional weights. For every consistent pseudometric with positive optimal cost, its output has cost at most three times the optimum. No normalization of the weight vectors is required, and consistency permits distance ties and co-location. These are the hypotheses of [Section 3.2 and Theorem 8 of the cited paper](https://arxiv.org/html/2608.21790v1#S3.SS2).

The transformed weights remain nonnegative and monotone. Multiplying two binary-encoded rational numbers increases their encoding length by at most the sum of their operand lengths, up to a constant. Consequently, the transformed instance has polynomial encoding length and at most \(\tau\) voters. The stated finite algorithm therefore gives the required polynomial running time.

2. Mean distances are finite and preserve consistency

Fix an arbitrary realization and admissible pseudometric \(d\). Write

\(\displaystyle \delta(a,b)=d(a,b)\qquad(a,b\in C).\)

For each \(t\in T_+\), define its mean candidate distances by

\(\displaystyle h_t(a)=\frac{1}{\mu_t}\int_{X_t}d(x,a)\,d\nu(x).\)

These means are finite. Indeed, choose any ranking \(\rho\), and let \(a_0=\rho_1\). Nonnegativity of every cost contribution gives

\(\displaystyle w_{t,1}\int_{X_t}d(x,a_0)\,d\nu(x)\leq\operatorname{SC}_d(\rho)<\infty.\)

Since \(w_{t,1}>0\), the integral on the left is finite. For every other candidate \(a\), the triangle inequality gives

\(\displaystyle d(x,a)\leq d(x,a_0)+\delta(a_0,a),\)

so its integral over \(X_t\) is finite as well.

Integrating the ranking-consistency inequalities yields

\(\displaystyle a\succ_t b\quad\Longrightarrow\quad h_t(a)\leq h_t(b).\)

Moreover, the original triangle inequalities, integrated against the probability measure \(\nu|_{X_t}/\mu_t\), imply that for every \(a,b\in C\),

\[\displaystyle h_t(a)\leq h_t(b)+\delta(a,b),\qquad \delta(a,b)\leq h_t(a)+h_t(b).\tag{1}\]

We next show that these mean distances are realizable by a finite pseudometric.

3. Pseudometric extension lemma

Lemma. There exists a pseudometric \(D\) on \(V\cup C\) satisfying

\(\displaystyle D(a,b)=\delta(a,b),\qquad D(v_t,a)=h_t(a).\)

Proof. Form a finite undirected graph on \(V\cup C\). Connect every pair of distinct candidates \(a,b\) by an edge of length \(\delta(a,b)\), and connect every voter \(v_t\) to every candidate \(a\) by an edge of length \(h_t(a)\). Define \(D\) to be shortest-path distance.

The graph is connected and all edge lengths are finite and nonnegative. Shortest-path distance is therefore finite, symmetric, zero on the diagonal, and satisfies the triangle inequality by concatenation of paths. Zero-length edges are permitted, so it is a pseudometric.

It remains to verify that shortest paths preserve the prescribed edge lengths.

Consider a path between two candidates. Every internal voter occurs between two candidates, say \(a,v_t,b\). By the second inequality in (1), replacing this segment by the candidate edge from \(a\) to \(b\) does not increase its length. After all such replacements, the path uses only candidates. The triangle inequality for \(\delta\) shows that its length is at least the direct candidate distance. Since the direct edge is available,

\(\displaystyle D(a,b)=\delta(a,b).\)

Now consider a path from \(v_t\) to a candidate \(a\). We may remove repeated-vertex cycles without increasing its length. Its first edge goes to some candidate \(b\). Replacing all remaining internal voter segments as above shows that the path has length at least

\(\displaystyle h_t(b)+\delta(b,a)\geq h_t(a),\)

where the final inequality is the first inequality in (1). The direct edge from \(v_t\) to \(a\) has length \(h_t(a)\), proving

\(\displaystyle D(v_t,a)=h_t(a).\)

This proves the lemma. \(\square\)

By Section 2, \(D\) is consistent with every finite voter’s input ranking.

4. Exact preservation of every ranking’s cost

Define the finite-instance cost under \(D\) by

\(\displaystyle \operatorname{SC}^{\mathrm{fin}}_D(\pi) =\sum_{t\in T_+}\sum_{j=1}^m\widetilde w_{t,j}D(v_t,\pi_j).\)

For every ranking \(\pi\), the extension lemma and the definitions give

\[\displaystyle \operatorname{SC}^{\mathrm{fin}}_D(\pi) =\sum_{t\in T_+}\sum_{j=1}^m \mu_t w_{t,j}\frac{1}{\mu_t} \int_{X_t}d(x,\pi_j)\,d\nu(x) =\operatorname{SC}_d(\pi).\tag{2}\]

The last equality uses the measurable partition and the fact that omitted types have zero weights. All sums are finite.

Thus the finite construction preserves the costs of all rankings, and hence preserves their minimum.

5. The zero-optimum case

For completeness, the finite theorem’s positive-optimum guarantee also implies the required inequality at zero optimum.

Let

\(\displaystyle H=\sum_{t\in T_+}\sum_{j=1}^m\widetilde w_{t,j}>0.\)

For any \(\varepsilon>0\), define on the same finite vertex set

\(\displaystyle D_\varepsilon(u,z)=D(u,z)+\varepsilon\,\mathbf 1_{\{u\ne z\}}.\)

The added term is a metric, so \(D_\varepsilon\) is a pseudometric. Each voter–candidate distance increases by exactly \(\varepsilon\); consequently, ranking consistency is preserved and every ranking satisfies

\(\displaystyle \operatorname{SC}^{\mathrm{fin}}_{D_\varepsilon}(\pi) =\operatorname{SC}^{\mathrm{fin}}_D(\pi)+\varepsilon H. \)

The optimum under \(D_\varepsilon\) is positive. The algorithm’s output remains \(\sigma\), because its input contains only rankings and weights. Applying the finite theorem gives

\(\displaystyle \operatorname{SC}^{\mathrm{fin}}_D(\sigma)+\varepsilon H \leq 3\left(\min_{\pi\in S_C}\operatorname{SC}^{\mathrm{fin}}_D(\pi) +\varepsilon H\right). \)

Letting \(\varepsilon\) decrease to zero proves the finite inequality without any positivity assumption. Using (2), we obtain

\(\displaystyle \operatorname{SC}_d(\sigma) \leq 3\min_{\pi\in S_C}\operatorname{SC}_d(\pi). \)

In particular, a zero optimum forces the output cost to be zero.

The realization and \(d\) were arbitrary, whereas \(\sigma\) depends only on the supplied support data. Therefore the same output ranking satisfies the guarantee for every realization and every admissible \(d\). Atomlessness is not needed for this argument.
