Theorem 3.1 — class: algorithmic

The continuous mirror question, as graded

Given a population distribution \(\mu\) over a finite support of weak rankings of \(n\) arms, accessible by sampling a fresh respondent for each queried pair, what query complexity is necessary and sufficient for an adaptive learner to return an arm of maximum Copeland score with error probability at most \(\delta\)?

Packaged proof task (what the prover saw — nothing else)

Let \(m=n\geq2\) be the number of arms. A society is given by its support: a list of \(\tau\) weak rankings with positive binary-rational masses summing to \(1\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
The learner receives this list and a binary-rational \(\delta\in(0,1/2)\). It may adaptively query distinct arms \(i,j\); each query independently draws a fresh respondent from \(\mu\) and reveals only whether \(i\succ j\), \(i\sim j\), or \(j\succ i\).
Write \(p^+_{ij}=\mu(i\succ j)\), \(p^0_{ij}=\mu(i\sim j)\), and \(p^-_{ij}=\mu(j\succ i)\). Require every triple to have a unique largest entry; zero probabilities are allowed.
Define \(\operatorname{CP}(i)=\sum_{j\ne i}\mathbf{1}\{p^+_{ij}>\max(p^0_{ij},p^-_{ij})\}+\tfrac12\sum_{j\ne i}\mathbf{1}\{p^0_{ij}>\max(p^+_{ij},p^-_{ij})\}\), and \(C=\arg\max_i\operatorname{CP}(i)\).
The learner stops after \(T\) queries and returns any \(\hat i\in C\) with probability at least \(1-\delta\); no particular winner is required when scores tie. Measure query complexity by worst-case expected \(T\), and running time in \(m,\tau,L\) and \(\log(1/\delta)\).

Is finding a maximum-score arm from this support representation in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? What is the necessary and sufficient query complexity under the stated access model?

For unrestricted ternary pair-feedback distributions with unique modes, POCOWISTA guarantees correct identification within \(O(\sum_{i<j}\Delta_{ij}^{-2}\log(m/(\sqrt{\delta}\Delta_{ij})))\) queries with probability at least \(1-\delta\), where \(\Delta_{ij}\) is the largest probability minus the second largest. This is an oracle sample bound, not a finite-society complexity classification. [Verified source](https://proceedings.mlr.press/v238/bengs24a/bengs24a.pdf).
That upper bound also covers feedback induced by ranking distributions; the cited result does not classify computation from an explicit rational support list.

Conclusion

Finding a maximum-score arm from the explicit rational support list is polynomial-time solvable. Under the stated access model, the necessary and sufficient worst-case expected query complexity is exactly \(0\).

The zero-query conclusion follows because the learner receives the entire distribution. The substantive computational issue is whether exact probability comparisons remain polynomial in the input bit length; they do, even when the mode gaps are very small.

1. Exact computation of pairwise probabilities

Write the support as \((R_h,w_h)_{h=1}^{\tau}\), where \(R_h\) is a weak ranking and \(w_h=a_h/b_h\), with positive integers \(a_h,b_h\). By hypothesis, \(\sum_{h=1}^{\tau}w_h=1\).

Represent each weak ranking by rank labels \(r_h(i)\), assigning equal labels to tied arms and smaller labels to preferred arms. Thus \(i\succ j\) in \(R_h\) exactly when \(r_h(i)<r_h(j)\). These labels can be extracted in polynomial time from the explicit rankings.

Define the common denominator and integer weights by \(D=\prod_{h=1}^{\tau}b_h\) and \(W_h=a_h(D/b_h)\). Each division is exact, and \(\sum_h W_h=D\).

For each unordered pair \(i<j\), compute
\(A^+_{ij}=\sum_{h:r_h(i)<r_h(j)}W_h\),
\(A^0_{ij}=\sum_{h:r_h(i)=r_h(j)}W_h\), and
\(A^-_{ij}=\sum_{h:r_h(i)>r_h(j)}W_h\).

These three cases partition the support, so
\((p^+_{ij},p^0_{ij},p^-_{ij})=(A^+_{ij},A^0_{ij},A^-_{ij})/D\).

Because \(D>0\), comparing probabilities is equivalent to comparing their integer numerators. The unique-mode promise ensures that precisely one of these three integers is largest. Zero probabilities cause no difficulty.

2. Computing a maximum-score arm

Initialize integer scores \(s_i=0\). Process every pair \(i<j\):

  • If \(A^+_{ij}\) is largest, increase \(s_i\) by \(2\).
  • If \(A^-_{ij}\) is largest, increase \(s_j\) by \(2\).
  • If \(A^0_{ij}\) is largest, increase both \(s_i\) and \(s_j\) by \(1\).

A strict-preference mode contributes one Copeland point to its preferred arm and zero to the other. An indifference mode contributes one-half point to each. Consequently, after all pairs have been processed, \(s_i=2\operatorname{CP}(i)\) for every arm \(i\).

Return an arm with maximum \(s_i\), choosing the smallest index if several arms attain that maximum. Multiplication by \(2\) preserves maximizers, so the returned arm belongs to \(C\).

3. Polynomial bit complexity

The sum of the binary encoding lengths of the denominators is at most \(L\). Therefore \(D\) has at most \(L+1\) bits.

Moreover, positivity and \(\sum_hW_h=D\) imply \(0<W_h\leq D\). Every pairwise numerator also lies between \(0\) and \(D\). Thus all probability calculations use integers with \(O(L)\) bits.

Using elementary integer arithmetic, constructing \(D\) and the \(W_h\) takes \(O(\tau L^2)\) bit operations. Computing all pairwise numerators requires \(O(\tau m^2)\) additions of \(O(L)\)-bit integers. Mode comparisons take \(O(m^2L)\) bit operations. Finally, \(0\leq s_i\leq2(m-1)\), so score updates and maximization are polynomial-time operations.

Including input parsing, a conservative bound is
\(O\!\left(L+\tau L^2+\tau m^2(L+\log m)\right)\).
This is polynomial in the requested parameters and has no additional dependence on \(\delta\).

Hence the search problem belongs to \(\mathrm{FP}\), and the corresponding score-threshold decision problem belongs to \(\mathrm{P}\). An \(\mathrm{NP}\)-hardness classification under standard polynomial-time reductions would therefore imply \(\mathrm{P}=\mathrm{NP}\).

4. Necessary and sufficient query complexity

The algorithm above is deterministic and uses only the supplied list. It makes no respondent queries, so \(T=0\) on every valid input. Its success probability is \(1\), which satisfies the required confidence for every allowed \(\delta\).

Conversely, query counts are nonnegative, so every learner has \(\mathbb{E}[T]\geq0\). Combining these bounds proves that the optimal worst-case expected query complexity is exactly \(0\).

The cited [POCOWISTA paper](https://proceedings.mlr.press/v238/bengs24a/bengs24a.pdf) studies identification through noisy pairwise observations. Its oracle upper bound remains applicable if one elects to sample, but it cannot establish a positive query requirement when the distribution is already supplied explicitly.

For example, take two opposite strict rankings with masses \(1/2+2^{-b}\) and \(1/2-2^{-b}\), where \(b\geq2\). Their pairwise mode gap is \(\Delta_{12}=2^{1-b}\). Despite this exponentially small gap, the supplied masses permit exact winner identification in time polynomial in \(b\), with zero queries.
