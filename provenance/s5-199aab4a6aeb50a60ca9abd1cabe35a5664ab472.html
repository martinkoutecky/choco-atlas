The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), a type \(a\) with \(\mu_a>0\), and an efficiently evaluable gradient of a continuously differentiable aggregate game \(V:\prod_{t\in T}[0,\mu_t]\to\mathbb{R}\) with \(V(0)=0\) and \(|\partial_a V|\le B\), estimate \(\phi_a=\int_0^1\partial_a V(u\mu)\,du\) within additive error \(\varepsilon\) with probability at least \(1-\delta\). This is the limiting per-capita Shapley value for a representative type-\(a\) member in finite games with \(N\mu_t\) members of each type and coalition value \(v_N(S)=N V(x(S))\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types \(T\), each with positive binary-rational mass \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; there is no separate candidate parameter \(m\).
Given \(a\in T\), let \(V:\prod_{t\in T}[0,\mu_t]\to\mathbb R\) have a continuously differentiable extension to a neighborhood of its domain, with \(V(0)=0\). Values and derivatives may have either sign.
The input includes binary rationals \(B>0\), \(\varepsilon>0\), and \(0<\delta<1\), with the promise \(|\partial_aV(x)|\le B\) throughout the domain.
Access to \(\nabla V\) is through a supplied evaluator: given oracle access to binary approximations of a real input \(x\) and precision \(q\in\mathbb N\), it returns a rational vector within \(2^{-q}\) in maximum norm, in uniformly polynomial time in \(\tau,L,q\). Let \(L\) be the total binary input-description length, including the evaluator.
The desired per-capita payoff is \(\phi_a=\int_0^1\partial_aV(u\mu)\,du\); the total payoff to type \(a\) is \(\mu_a\phi_a\).

Does estimating \(\phi_a\) within additive error \(\varepsilon\), with probability at least \(1-\delta\), admit a randomized algorithm polynomial in \(\tau,L,1+B/\varepsilon,\log(1/\delta)\), or is this approximation problem NP-hard?

Discrete: for any fixed \(K\ge2\), applying successive powers of a bijection to each independent uniform player order produces blocks whose marginal-contribution sample mean converges almost surely to the Shapley value; this is a consistency result, without a finite-error running-time bound. [Illés–Kerényi](https://link.springer.com/article/10.1007/s00291-026-00863-0).
Continuous: the Aumann–Shapley value of continuously differentiable vector-measure games is given by the diagonal derivative integral; this identifies the payoff rather than settling its approximation complexity. [Milchtaich](https://ratio.huji.ac.il/files/dp89.pdf).

Result

The approximation admits a randomized algorithm with running time polynomial in \(\tau,L,1+B/\varepsilon,\log(1/\delta)\). The proof must account for both sampling error and the finite computation of each sample.

We use the standard bit-cost interpretation of the real-input evaluator: requesting and reading approximations to precision \(r\) is charged for that precision. Thus a polynomial-time evaluator call can request only polynomially many bits at polynomial precisions.

1. Reduction to a bounded expectation

Write \(\mu=(\mu_t)_{t\in T}\), and define

\(f(u)=\partial_a V(u\mu),\qquad u\in[0,1].\)

Because \(V\) has a continuously differentiable extension, \(f\) is continuous. Moreover, \(u\mu\) belongs to the promised domain, so

\(|f(u)|\le B\qquad\text{for every }u\in[0,1].\)

Consequently, if \(U\) is uniform on \([0,1]\), then

\(\mathbb E[f(U)]=\int_0^1 f(u)\,du=\phi_a.\)

In particular, \(|\phi_a|\le B\). If \(\varepsilon\ge B\), outputting zero already meets the requirement. Henceforth assume \(0<\varepsilon<B\).

2. Computing a sample using finitely many random bits

An exact uniform real cannot be written down by a finite algorithm. Nevertheless, its approximation oracle can be supplied to the evaluator using lazily generated random bits.

Let \(b_1,b_2,\ldots\) be independent fair bits, and define the conceptual random real and its finite prefixes by

\(U=\sum_{j=1}^{\infty}b_j2^{-j},\qquad U_s=\sum_{j=1}^{s}b_j2^{-j}.\)

The real \(U\) is uniform on \([0,1]\), and

\(0\le U-U_s\le 2^{-s}.\)

We supply an approximation oracle for \(x=\mu U\). On a request at precision \(r\), generate and retain the first \(r+2\) bits, and return the dyadic vector with coordinates

\(d_{t,r}=2^{-(r+1)}\left\lfloor 2^{r+1}\mu_t U_{r+2}\right\rfloor.\)

Since the masses are positive and sum to one, \(0<\mu_t\le1\). Therefore

\(0\le \mu_tU-d_{t,r} \le \mu_t(U-U_{r+2})+\bigl(\mu_tU_{r+2}-d_{t,r}\bigr) <2^{-(r+2)}+2^{-(r+1)} <2^{-r}.\)

Thus these responses form a valid binary-approximation oracle for \(x\). They can be computed using exact integer arithmetic in time polynomial in \(\tau,L,r\). The same stored bit stream is used for every query in this evaluator call, so all responses approximate the same real vector.

Choose an integer \(q\ge1\) such that

\(2^{-q}\le\varepsilon/4.\)

Run the supplied gradient evaluator at precision \(q\) with this oracle, and retain coordinate \(a\) of its rational output, denoted \(Y\). Its guarantee gives, for every bit stream,

\(|Y-f(U)|\le 2^{-q}\le\varepsilon/4.\)

The evaluator terminates in polynomial time and requests only polynomial precision. Consequently, this procedure consumes finitely many random bits and runs in time polynomial in \(\tau,L,q\). It requires no separately supplied modulus of continuity.

3. Algorithm and probability guarantee

Choose the least positive integer \(h\) satisfying \(2^{-h}\le\delta/2\), and set

\(N=\left\lceil 8h(B/\varepsilon)^2\right\rceil.\)

Perform \(N\) independent copies of the sample procedure, using independent bit streams. Output the rational number

\(\widehat\phi_a=\frac1N\sum_{i=1}^{N}Y_i.\)

For analysis, let \(U_i\) be the uniform real represented by the \(i\)-th stream, and let \(Z_i=f(U_i)\). The variables \(Z_i\) are independent, lie in \([-B,B]\), and have expectation \(\phi_a\).

Hoeffding’s inequality states that, for independent variables in \([-B,B]\),

\(\Pr\left(\left|\frac1N\sum_{i=1}^{N}Z_i-\phi_a\right|\ge t\right) \le 2\exp\left(-\frac{Nt^2}{2B^2}\right).\)

All its hypotheses have just been checked. Taking \(t=\varepsilon/2\) gives

\(\Pr\left(\left|\frac1N\sum_{i=1}^{N}Z_i-\phi_a\right|\ge\varepsilon/2\right) \le 2\exp\left(-\frac{N\varepsilon^2}{8B^2}\right) \le 2e^{-h} \le 2^{1-h} \le\delta.\)

Furthermore, the evaluator errors satisfy the deterministic bound

\(\left|\widehat\phi_a-\frac1N\sum_{i=1}^{N}Z_i\right| \le\frac1N\sum_{i=1}^{N}|Y_i-Z_i| \le\varepsilon/4.\)

Outside the exceptional event of probability at most \(\delta\), the triangle inequality therefore yields

\(|\widehat\phi_a-\phi_a| \le\varepsilon/4+\varepsilon/2 <\varepsilon.\)

This proves the required success probability.

4. Running time and scope

The integers \(h,q,N\) can be selected by rational comparisons and integer arithmetic; no exact computation of a logarithm is needed. Their sizes satisfy

\(h=O(1+\log(1/\delta)),\qquad q=O(1+\log^+(1/\varepsilon)),\)

and

\(N=O\left(1+(B/\varepsilon)^2(1+\log(1/\delta))\right),\)

where \(\log^+(z)=\max\{0,\log z\}\). With ordinary binary-rational encoding, \(q=O(L+1)\).

Each evaluator call, including its implemented input oracle, takes polynomial time in \(\tau,L,q\). Its rational output has polynomial encoding length. Exact summation and division of the \(N\) outputs also take polynomial time: even multiplying all their denominators produces only \(N\) times their maximum denominator bit length.

Hence the entire algorithm has the claimed polynomial running time. Multiplying its output by \(\mu_a\) additionally estimates the total payoff with error at most \(\mu_a\varepsilon\).

The cited [continuous payoff formula](https://ratio.huji.ac.il/files/dp89.pdf) identifies the integral, while the cited [discrete sampling result](https://link.springer.com/article/10.1007/s00291-026-00863-0) establishes consistency. The finite-error guarantee here follows from the bounded derivative, the evaluator promise, and concentration.

This settles the randomized-algorithm alternative. The dependence on \(B/\varepsilon\) is numerical: exponentially large \(B/\varepsilon\) can still lead to exponential running time in the binary input length.
