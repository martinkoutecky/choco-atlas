The continuous mirror question, as graded

Given projects \(P\), degree sets \(D_j\) with costs \(c_{jd}\) including \(c_{j0}=0\), budget \(b\), complete voter types \(\Theta\) with rational masses \(\mu_\theta\) summing to \(1\), and interval reports \((\ell_\theta(j),h_\theta(j))\), decide whether there exists one \(d_j\in D_j\) per project such that \(\sum_j c_{jd_j}\le b\) and \(\sum_j c_{jd_j}\sum_{\theta:\ell_\theta(j)\le c_{jd_j}\le h_\theta(j)}\mu_\theta\ge K\).

Packaged proof task (what the prover saw — nothing else)

Definitions. Each project \(j\in P\) has permissible degrees \(D(P_j)\), including a zero-cost degree; degree \(t\) has cost \(c_j^t\). A complete ranged-approval type \( heta\) specifies permissible-cost bounds \(\ell_ heta(j)\le h_ heta(j)\) for every project, and has rational mass \(\mu_ heta\).
A valid outcome \(S\) chooses exactly one degree for every project and has total cost \(c(S)\le b\). Write \(c_S(j)\) for the chosen cost of project \(j\), and define \(U^c_\mu(S)=\sum_ heta\mu_ heta\sum_{j:c_S(j)>0}c_S(j)\mathbf{1}[\ell_ heta(j)\le c_S(j)\le h_ heta(j)]\).

Target. Is deciding whether a valid outcome \(S\) with \(U^c_\mu(S)\ge q\) exists solvable in polynomial time, or is it NP-hard?

Nearest known results. With a finite list of voters instead of weighted types, the corresponding cost-utility decision problem is NP-hard, even when every project has only a zero degree and one positive degree. No verified result for the weighted-type version is known here.

Complexity Classification

Theorem

Under the standard explicit binary encoding of project degrees, costs, type masses, interval bounds, budget, and threshold, the weighted-type cost-utility decision problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard even under all of the following restrictions:

  • There is exactly one complete ranged-approval type.
  • Its mass is \(1\).
  • Every project has exactly two degrees: one zero-cost degree and one positive-cost degree.
  • The unique type approves the positive degree of every project.

Reduction from \(\textsc{Subset Sum}\)

Consider an instance of \(\textsc{Subset Sum}\) consisting of positive integers \(a_1,\ldots,a_n\) and a target \(B\), all encoded in binary. The question is whether there exists a set \(I\subseteq\{1,\ldots,n\}\) satisfying \(\sum_{j\in I}a_j=B\).

Construct the following weighted-type cost-utility instance.

For every \(j\in\{1,\ldots,n\}\), introduce a project \(P_j\) with two permissible degrees:

  • a zero degree of cost \(0\);
  • a positive degree of cost \(a_j\).

Set the budget and utility threshold to

\[ b=B \qquad\text{and}\qquad q=B. \]

Introduce one complete ranged-approval type \(\theta\), with rational mass

\[ \mu_\theta=1. \]

For every project \(P_j\), define its bounds by

\[ \ell_\theta(j)=h_\theta(j)=a_j. \]

Thus, whenever the positive degree of \(P_j\) is chosen, its cost lies in the unique type's approval range.

The construction is computable in polynomial time and introduces no numbers larger than those already occurring in the \(\textsc{Subset Sum}\) instance.

Correctness of the Reduction

Let \(S\) be any outcome of the constructed instance, and let

\[ I(S)=\{j:c_S(j)=a_j\} \]

be the set of projects whose positive degree is selected.

Because every other selected degree has cost \(0\),

\[ c(S)=\sum_{j\in I(S)}a_j. \]

For every \(j\in I(S)\), one has

\[ \ell_\theta(j)=a_j=c_S(j)=h_\theta(j), \]

so the unique type approves the selected positive degree. Consequently,

\[ \begin{aligned} U^c_\mu(S) &=\mu_\theta \sum_{j:c_S(j)>0} c_S(j)\mathbf{1} [\ell_\theta(j)\leq c_S(j)\leq h_\theta(j)]\\ &=\sum_{j\in I(S)}a_j\\ &=c(S). \end{aligned} \]

Therefore, \(S\) is valid and meets the utility threshold exactly when

\[ c(S)\leq B \qquad\text{and}\qquad U^c_\mu(S)\geq B. \]

Since \(U^c_\mu(S)=c(S)\), these two inequalities hold exactly when

\[ c(S)=B. \]

Equivalently,

\[ \sum_{j\in I(S)}a_j=B. \]

Hence the constructed instance is a yes-instance precisely when the original \(\textsc{Subset Sum}\) instance is a yes-instance. This proves \(\mathrm{NP}\)-hardness.

Membership in \(\mathrm{NP}\)

A certificate specifies one degree for every project. Given such a certificate, one can compute the total cost and utility by exact rational arithmetic and check

\[ c(S)\leq b \qquad\text{and}\qquad U^c_\mu(S)\geq q. \]

There are only polynomially many explicitly represented project-type pairs, and the bit length of intermediate rational sums is polynomial in the total input length. Verification therefore takes polynomial time.

Thus the problem belongs to \(\mathrm{NP}\). Together with the reduction, it is \(\mathrm{NP}\)-complete.

Conclusion

The weighted-type representation does not yield a polynomial-time algorithm in general. Hardness already occurs with one type of unit mass because the budget upper bound and utility lower bound together enforce an exact subset-sum equality. The reduction establishes weak \(\mathrm{NP}\)-hardness; stronger hardness under unary or bounded costs is not claimed.

Verification Report

Summary

The reduction from \(\textsc{Subset Sum}\) is correct and establishes NP-hardness under the claimed restrictions. The membership-in-\(\mathrm{NP}\) argument is also valid under the stated explicit binary encoding. Thus the prover correctly establishes NP-completeness.

There is one minor overstatement: NP-hardness alone does not unconditionally rule out a polynomial-time algorithm, since that would require assuming \(\mathrm{P}\ne\mathrm{NP}\). This does not affect the NP-hardness or NP-completeness theorem.

Step-by-step audit

  • Source problem. The prover uses the standard binary-encoded \(\textsc{Subset Sum}\) problem with positive integer inputs. This is NP-complete and is an appropriate source for weak NP-hardness.
  • Construction. Each integer \(a_j\) becomes a project with costs \(0\) and \(a_j\). Setting \(b=q=B\), using one type of mass \(1\), and setting

\[ \ell_\theta(j)=h_\theta(j)=a_j \]
satisfies all claimed restrictions. The construction has polynomial size.

  • Cost identity. For the selected-positive set

\[ I(S)=\{j:c_S(j)=a_j\}, \]
the equality
\[ c(S)=\sum_{j\in I(S)}a_j \]
follows directly because all remaining selected degrees have cost \(0\).

  • Utility identity. Every selected positive degree is approved because its cost equals both interval endpoints. Since the unique type has mass \(1\),

\[ U^c_\mu(S)=\sum_{j\in I(S)}a_j=c(S). \]
The definition explicitly excludes zero-cost choices from the inner sum, so no unexamined contribution arises from zero degrees.

  • Equivalence. Validity and the utility threshold require

\[ c(S)\le B \quad\text{and}\quad U^c_\mu(S)\ge B. \]
Substituting \(U^c_\mu(S)=c(S)\) yields \(c(S)=B\). Hence feasible outcomes correspond exactly to subsets summing to \(B\). Both directions are established.

  • NP membership. Under explicit encoding, a certificate contains one degree index per project and therefore has polynomial length. Costs and utilities can be evaluated by exact rational arithmetic. Adding polynomially many input rationals produces numerator and denominator bit lengths polynomial in the total input length, so verification is polynomial-time.
  • Strength of hardness. The prover correctly identifies the result as weak NP-hardness and does not claim strong hardness.

Issue

  • Minor: The sentence “The weighted-type representation does not yield a polynomial-time algorithm in general” is not an unconditional consequence of NP-hardness. The established classification is NP-completeness; exclusion of polynomial-time solvability additionally depends on \(\mathrm{P}\ne\mathrm{NP}\). The theorem and reduction themselves remain correct.
