The continuous mirror question, as graded

Given a pool of \(M\) indivisible items and a population of claimant types \(t\) with rational masses \(\mu_t\), \(\sum_t\mu_t=1\), shared monotone bundle preferences, and entitlement weights \(w_t\), set \(a_{t,N}=w_t/(N\sum_u\mu_u w_u)\). For each type, let \(R_t=\{(l,d):1\le l\le d\le M,\ l/d\le a_{t,N}\}\). Find sets \(Q_t\subseteq R_t\) minimizing \(\sum_t\mu_t|Q_t|\), subject to every pair in \(R_t\) being dominated by a pair in \(Q_t\), using the paper’s dominance relation.

Result

The problem is exactly solvable in polynomial time in \(m,\tau,L\). Its dependence on \(N\) is only through the binary encoding length of \(N\).

The key fact is that dominance is a preorder, and the allowed choices are also the requirements to be covered. For each type, the minimum cover consists of one representative from each maximal equivalence class under dominance.

1. Dominance defines a preorder

Write \(p\unrhd q\) when the integer pair \(p\) universally dominates the integer pair \(q\), as defined in the question.

This relation is reflexive: every maximin share is weakly preferred to itself. It is also transitive. Indeed, if \(p\unrhd q\) and \(q\unrhd r\), then for every finite item set and every permitted ordering,
\(\operatorname{MMS}_{p}(X)\succeq\operatorname{MMS}_{q}(X)\succeq\operatorname{MMS}_{r}(X)\).
Transitivity of the ordering therefore gives \(p\unrhd r\).

Define \(p\sim q\) when both \(p\unrhd q\) and \(q\unrhd p\). This is an equivalence relation. Dominance induces a partial order on its equivalence classes: the induced relation is well-defined by transitivity, and antisymmetry follows from the definition of \(\sim\).

For a finite set of pairs \(R\), call an equivalence class maximal if no different class in \(R\) dominates it.

2. A finite preorder has an exact minimum-cover formula

Lemma. Let \(R\) be a finite set equipped with a preorder \(\unrhd\). The minimum cardinality of a subset \(Q\subseteq R\) such that every element of \(R\) is dominated by some element of \(Q\) equals the number of maximal equivalence classes of \(R\).

Proof. First consider a maximal class \(C\), and choose \(c\in C\). Any feasible cover must contain some \(q\) with \(q\unrhd c\). By maximality of \(C\), the class of \(q\) must equal \(C\). Consequently, every feasible cover meets every maximal class. Distinct classes are disjoint, so this gives the required lower bound.

For the upper bound, select one representative from each maximal class. Every class in a finite partially ordered set is dominated by a maximal class: starting at any nonmaximal class, move to a strictly dominating class; finiteness forces this process to terminate. Transitivity then shows that the selected representatives cover all of \(R\).

For \(R=\varnothing\), both the minimum cardinality and the number of maximal classes are zero. \(\square\)

Thus this is a minimum-cover problem whose optimum follows directly from the preorder structure.

3. Only one candidate per denominator is needed

Fix a type \(t\), and abbreviate \(a=a_{t,N}\). For each \(d\in\{1,\ldots,m\}\), define
\(\ell_d=\lfloor da\rfloor\), and let

\(S_t=\{(\ell_d,d):1\leq d\leq m,\ \ell_d\geq1\}\).

Because \(0<a<1\), every retained numerator satisfies \(1\leq\ell_d<d\). Hence \(S_t\subseteq R_t\) and \(|S_t|\leq m\).

We next justify that every pair in \(R_t\) is dominated by a pair in \(S_t\).

Same-denominator monotonicity. If \(1\leq l\leq k\leq d\), then \((k,d)\unrhd(l,d)\).

To prove this, fix a finite \(X\), a permitted ordering, and a partition attaining \(\operatorname{MMS}_{l,d}(X)\). Such a partition exists because there are finitely many partitions. Every union of \(k\) parts contains a union of \(l\) parts. By weak monotonicity, it is at least as good as that contained union, which in turn is at least as good as the worst union of \(l\) parts in this partition. Therefore the worst union of \(k\) parts is at least as good as \(\operatorname{MMS}_{l,d}(X)\). Optimizing over partitions proves the assertion.

Now, if \((l,d)\in R_t\), then \(l\leq\lfloor da\rfloor=\ell_d\). The assertion gives \((\ell_d,d)\unrhd(l,d)\), with \((\ell_d,d)\in S_t\).

Claim. The maximal equivalence classes of \(R_t\) correspond bijectively to the maximal equivalence classes of \(S_t\).

Proof. Every maximal class of \(R_t\) meets \(S_t\): for an element \(r=(l,d)\) of that class, its corresponding element \((\ell_d,d)\in S_t\) dominates \(r\), so maximality forces it into the same class. Its intersection with \(S_t\) is maximal there.

Conversely, let \(s\in S_t\) belong to a maximal class of \(S_t\). Suppose some \(r\in R_t\) dominates \(s\). Choose \(v\in S_t\) dominating \(r\), using the preceding construction. Then \(v\unrhd r\unrhd s\). Maximality in \(S_t\) implies \(s\unrhd v\), and hence \(s\unrhd r\). Thus \(r\sim s\), proving that the class of \(s\) is maximal in \(R_t\).

These correspondences preserve equivalence, so they are bijective. \(\square\)

Let \(c_t\) denote this common number of maximal classes. By Section 2, \(c_t\) is exactly the minimum possible cardinality of \(Q_t\).

4. Computing the maximal classes

For an explicit dominance test, use Lemma 3.1 of the cited paper. For \(1\leq l\leq d\) and \(1\leq l'\leq d'\), put
\(q=\lceil d'/d\rceil\) and \(r=qd-d'\). Then

\((l,d)\unrhd(l',d')\quad\Longleftrightarrow\quad ql-\min(l,r)\geq l'\).

The lemma applies to finite item sets, weakly monotone weak orderings, and partitions allowing empty parts, exactly as required here. It tests universal dominance, rather than dominance restricted to the given item pool. [The Maximin Share Dominance Relation, Lemma 3.1](https://arxiv.org/pdf/1912.08763)

For each type:

  • Construct \(S_t\) using exact rational arithmetic.
  • Build a directed graph on \(S_t\), with an edge \(p\to q\) whenever \(p\unrhd q\).
  • Compute its strongly connected components.
  • Count the components with no incoming edge from another component; this count is \(c_t\). Select one representative from each such component.

The strongly connected components are precisely the equivalence classes: mutual dominance gives edges in both directions, while directed paths imply dominance by transitivity. Components with no incoming edge from another component are exactly the maximal classes.

The selected representatives cover \(S_t\), and therefore cover \(R_t\), since every element of \(R_t\) is dominated by an element of \(S_t\).

5. Mass weighting and bit complexity

The constraints for different types are independent. Every feasible family satisfies \(|Q_t|\geq c_t\). Since every \(\mu_t\) is positive,

\(\sum_t\mu_t|Q_t|\geq\sum_t\mu_t c_t\).

Choosing the representatives constructed above for every type attains equality. Therefore the exact optimum is

\(\operatorname{OPT}=\sum_{t=1}^{\tau}\mu_t c_t\).

The threshold decision is obtained by comparing this rational number exactly with \(K\).

To give a conservative explicit bit bound, put
\(B=L+\tau\lceil\log_2(m+1)\rceil\).
The normalization \(W=\sum_u\mu_u w_u\), the entitlements \(w_t/(NW)\), and the final weighted sum can all be computed using integers of \(O(B)\) bits. For example, sums may use products of the input denominators as common denominators; their bit lengths are bounded by sums of input bit lengths.

There are at most \(m\) candidates per type and \(m^2\) dominance tests per type. Each dominance test uses integer arithmetic on \(O(\log(m+1))\)-bit integers. Candidate construction requires \(O(m)\) exact rational operations per type, and graph processing takes \(O(m^2)\) time per type.

Using elementary quadratic-time integer arithmetic, a valid overall bound is
\(O(\tau m^2 B^2)\) bit operations. This is polynomial in \(m,\tau,L\), and the algorithm also outputs optimal sets \(Q_t\).

No step enumerates a population of size \(N\), or uses integrality of \(N\mu_t\). The numerical magnitude of \(N\) introduces no additional running-time factor.
