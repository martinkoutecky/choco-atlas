The continuous mirror question, as graded

Given a finite ordered proposal set \(P=\{p_1,\ldots,p_m\}\), a finite set of complete types \(T\) with rational masses \(\mu_t\ge0\) summing to \(1\), and an integer \(\lambda\), where each \(P_t^+\) is an interval and \(P_t^?\) has the paper’s endpoint-adjacent form, define allowable arcs \(t\to g\) by \(P_t^{+!}\cap P_g^-=\varnothing\), \(P_t^{-!}\cap P_g^+=\varnothing\), and \(|P_t^!|<|P_g^!|\). Let \(R(t)\) be reachability including \(t\). Choose rational \(y_{t,g}\ge0\) with \(\sum_{g\in R(t)}y_{t,g}=\mu_t\), require \(y_{t,g}>0\Rightarrow\mu_g>0\), and interpret \(y\) as a measurable limit of realizable delegation DAGs with vanishing sink identities. Set \(\nu_g=\sum_t y_{t,g}\). Is there such a plan for which at least \(\lambda\) proposals satisfy \(\operatorname{poss}_\nu(p)\subseteq\operatorname{corr}_\mu(p)\), where \(\operatorname{corr}_\mu(p)=\{1:\sum_{t:p\in P_t^+}\mu_t\ge1/2\}\cup\{0:\sum_{t:p\in P_t^-}\mu_t\ge1/2\}\) and \(\operatorname{poss}_\nu(p)=\{1:\sum_{g:p\in P_g^{+!}\cup P_g^?}\nu_g\ge1/2\}\cup\{0:\sum_{g:p\in P_g^{-!}\cup P_g^?}\nu_g\ge1/2\}\)?

Each \(P_t^+\) is an interval; write \(P_t^-=P\setminus P_t^+\), \(P_t^!=P\setminus P_t^?\), and \(P_t^{\star!}=P_t^\star\cap P_t^!\). For \(P_t^+=\{p_j,\ldots,p_k\}\neq\varnothing\), require \(P_t^?=L_t\cup R_t\), where \(L_t,R_t\) are intervals and each is empty or meets \(\{p_{j-1},p_j\}\) and \(\{p_k,p_{k+1}\}\), respectively.
Put an arc \(t\to g\) when \(P_t^{+!}\cap P_g^-=\varnothing\), \(P_t^{-!}\cap P_g^+=\varnothing\), and \(|P_t^!|<|P_g^!|\); let \(R(t)\) include \(t\). Complexity Classification

Theorem

The mass-type constrained liquid-democracy problem is \(\mathrm{NP}\)-complete, even on the stated one-dimensional endpoint-adjacent domain.

The published finite-agent hardness construction motivates the proposal ordering, but fractional mass splitting invalidates that construction verbatim. The reduction below adds score gadgets that recover the required discrete choice. The argument is self-contained. The finite-agent result appears in [Alouf-Heffetz et al., *Better Collective Decisions via Uncertainty Reduction*](https://arxiv.org/abs/2207.04983).

1. Linear form of proposal safety

For a plan \(y\), define

\[ W_p^0(\nu)=\sum_{g:p\in P_g^{-!}\cup P_g^?}\nu_g, \qquad W_p^1(\nu)=\sum_{g:p\in P_g^{+!}\cup P_g^?}\nu_g. \]

If \(\operatorname{corr}_\mu(p)=\{1\}\), then \(p\) is counted precisely when

\[ W_p^0(\nu)<\frac12. \]

Indeed, \(0\in\operatorname{poss}_\nu(p)\) precisely when \(W_p^0(\nu)\geq 1/2\).

Similarly, if \(\operatorname{corr}_\mu(p)=\{0\}\), then \(p\) is counted precisely when

\[ W_p^1(\nu)<\frac12. \]

Finally, if \(\operatorname{corr}_\mu(p)=\{0,1\}\), then \(p\) is counted for every plan.

Thus each nonautomatic proposal contributes one strict rational linear inequality.

2. Membership in \(\mathrm{NP}\)

Guess a set \(S\subseteq P\) of exactly \(\lambda\) proposals. Introduce a variable \(\delta\) and impose the plan constraints together with

\[ W_p^0(\nu)\leq \frac12-\delta \]

for every \(p\in S\) with \(\operatorname{corr}_\mu(p)=\{1\}\), and the analogous inequality involving \(W_p^1\) when \(\operatorname{corr}_\mu(p)=\{0\}\). Add \(0\leq\delta\leq1\).

This is a rational linear program of polynomial size. There is a plan strictly satisfying all required inequalities if and only if the maximum possible \(\delta\) is positive:

  • If a plan strictly satisfies the finitely many inequalities, their minimum slack is positive.
  • If the LP has \(\delta>0\), all the original strict inequalities hold.

Rational linear programming and comparison of its optimum with \(0\) are polynomial-time operations. Hence the problem belongs to \(\mathrm{NP}\).

3. Reduction source and proposal gadgets

Reduce from \(\mathrm{Vertex\ Cover}\) on simple cubic graphs. Let \(G=(V,E)\), let \(n=|V|\), and let \(\kappa\) be the requested cover size. Fix an arbitrary order on \(E\).

For every edge \(e=\{u,v\}\), introduce the ordered gadget

\[ s_e,\ r_{e,u},\ p_e,\ r_{e,v}. \]

The order of \(u,v\) inside the gadget is arbitrary. All edge gadgets occur first, in the fixed edge order.

For every vertex \(u\), introduce the gadget

\[ s_u,\ p_u,\ q_u,\ d_u,\ \ell_{u,1},\ \ell_{u,2}. \]

All vertex gadgets follow the edge gadgets. Thus the total number of proposals is

\[ M=4|E|+6n=12n, \]

because \(|E|=3n/2\).

For a vertex \(u\), write its three incident edges as \(a<b<c\).

3.1 Edge-chain types

For each \(e\in\{a,b,c\}\), introduce two types \(v^u_{e,1}\) and \(v^u_{e,2}\), having the same positive interval.

  • For \(e=a\), their positive interval is the shortest interval containing \(p_a,r_{a,u},r_{b,u}\). Set

\[ P_{v^u_{a,1}}^?=\{p_a,r_{a,u}\}, \qquad P_{v^u_{a,2}}^?=\{r_{b,u}\}. \]

  • For \(e=b\), replace \(a,b\) by \(b,c\).
  • For \(e=c\), use the shortest interval containing \(p_c,r_{c,u},p_u\), and set

\[ P_{v^u_{c,1}}^?=\{p_c,r_{c,u}\}, \qquad P_{v^u_{c,2}}^?=\{p_u\}. \]

Each uncertainty set is an interval touching the appropriate endpoint of the positive interval.

3.2 Vertex-choice types

Introduce types \(v^u_1,v^u_2\), both having positive interval

\[ \{p_u,q_u,d_u,\ell_{u,1},\ell_{u,2}\}. \]

Set

\[ P_{v^u_1}^?=\{p_u,q_u,d_u\}, \qquad P_{v^u_2}^?=\{\ell_{u,1},\ell_{u,2}\}. \]

Again these are endpoint-adjacent uncertainty intervals.

There are \(8n\) coding types in total.

4. The delegation graph

For every constructed pair, the two types have identical positive intervals. Moreover,

\[ |P_{v^u_{e,1}}^?|=2>1=|P_{v^u_{e,2}}^?| \]

and

\[ |P_{v^u_1}^?|=3>2=|P_{v^u_2}^?|. \]

Hence the intended arcs

\[ v^u_{e,1}\longrightarrow v^u_{e,2}, \qquad v^u_1\longrightarrow v^u_2 \]

exist.

There are no other arcs between coding types. To verify this, observe that every separator \(s_e,s_u\) is certain for every coding type. Therefore, two types connected by an arc must agree on all separators. For every edge-chain interval, its pattern on the separators identifies its first and last gadgets. Since \(G\) is simple, two distinct vertices cannot give different pairs with the same first and last edge gadgets. The only intervals contained entirely within one gadget are the private vertex intervals; intervals belonging to different vertices are disjoint, and each source type has certain positive positions in its own interval, so cross-vertex compatibility fails.

Balancing types introduced below are fully certain. They cannot delegate because no type is more certain. Every coding type has at least two certain positive positions and at least one certain negative position. Consequently it cannot delegate to either an all-positive balancing type or a singleton-positive balancing type.

Thus the delegation graph is a disjoint union of the intended directed edges and isolated balancing types.

5. Rational masses and exact margins

Let

\[ \eta=\frac{1}{100Mn}, \qquad \varepsilon=\frac{\eta}{10}. \]

Give every coding type mass \(\eta\). Their total mass is

\[ \rho=8n\eta. \]

For a coding source, write

\[ x_{u,e}=y_{v^u_{e,1},v^u_{e,2}}, \qquad z_u=y_{v^u_1,v^u_2}. \]

Thus \(0\leq x_{u,e},z_u\leq\eta\).

We now add fully certain balancing types so as to obtain the following initial values of \(W_p^0\).

| Proposal | Initial \(W_p^0\) | Change under delegation | Safety condition |
|---|---:|---:|---|
| \(p_e\), \(e=\{u,v\}\) | \(1/2+2\varepsilon\) | \(-x_{u,e}-x_{v,e}\) | \(x_{u,e}+x_{v,e}>2\varepsilon\) |
| \(r_{b,u}\) | \(1/2\) | \(x_{u,a}-x_{u,b}\) | \(x_{u,a}<x_{u,b}\) |
| \(r_{c,u}\) | \(1/2\) | \(x_{u,b}-x_{u,c}\) | \(x_{u,b}<x_{u,c}\) |
| \(p_u\) | \(1/2\) | \(x_{u,c}-z_u\) | \(x_{u,c}<z_u\) |
| \(q_u\) | \(1/2+\varepsilon\) | \(-z_u\) | \(z_u>\varepsilon\) |
| \(\ell_{u,1},\ell_{u,2}\) | \(1/2-\varepsilon\) | \(+z_u\) | \(z_u<\varepsilon\) |

All other proposals are made automatic by arranging that their underlying positive mass is exactly \(1/2\), so that their correct-outcome set is \(\{0,1\}\).

5.1 Existence of the balancing masses

Let \(c_p^!\) be the coding mass that is certainly positive on \(p\), and let \(c_p^+\) be the total coding mass positive on \(p\).

For a critical proposal with desired initial value \(b_p=W_p^0\), prescribe balancing certain-positive mass

\[ d_p=1-b_p-c_p^!. \]

For an automatic proposal prescribe

\[ d_p=\frac12-c_p^+. \]

For every proposal,

\[ \frac12-\rho-2\varepsilon \leq d_p \leq \frac12+\varepsilon. \]

Introduce one fully certain all-positive type of mass

\[ A=\frac{\sum_{p\in P}d_p-(1-\rho)}{M-1}, \]

and, for every proposal \(p\), a fully certain singleton-positive type of mass

\[ A_p=d_p-A. \]

These masses sum to \(1-\rho\).

They are nonnegative. First, \(A>0\) because \(M\geq48\) and every \(d_p\) is close to \(1/2\). Second,

\[ A \leq \frac12+\frac{M\varepsilon+\rho-1/2}{M-1} \leq \frac12-\rho-2\varepsilon \leq \min_p d_p, \]

where the middle inequality follows from

\[ M\rho+(3M-2)\varepsilon<\frac12. \]

For the chosen \(\eta,\varepsilon\), the left-hand side is less than \(0.081\). Hence every \(A_p\geq0\).

All masses are rational with polynomial encoding length. The balancing positive sets are either \(P\) or singletons and therefore satisfy the interval condition.

For every critical proposal the positive-uncertain coding mass is large enough to ensure that its underlying positive mass is strictly greater than \(1/2\). For example, at \(p_e\) it is \(2\eta>2\varepsilon\), and at \(q_u\) it is \(\eta>\varepsilon\). Thus every critical proposal has

\[ \operatorname{corr}_\mu(p)=\{1\}. \]

This proves every equivalence in the table.

6. The score threshold

For each vertex \(u\), call

\[ q_u,\ell_{u,1},\ell_{u,2} \]

its choice proposals. Their safety conditions imply:

  • If \(z_u<\varepsilon\), exactly the two low proposals \(\ell_{u,1},\ell_{u,2}\) are safe.
  • If \(z_u>\varepsilon\), exactly the high proposal \(q_u\) is safe.
  • If \(z_u=\varepsilon\), none is safe.

Thus at most two of the three choice proposals are safe. Define

\[ \lambda=M-n-\kappa. \]

The quantity \(M-n\) is the score obtained if every automatic, edge, and chain proposal is safe and every vertex obtains the maximum of two safe choice proposals.

7. Vertex cover implies a sufficiently good plan

Suppose \(X\subseteq V\) is a vertex cover of size \(h\leq\kappa\).

For \(u\notin X\), set

\[ x_{u,a}=\frac{\varepsilon}{10}, \quad x_{u,b}=\frac{2\varepsilon}{10}, \quad x_{u,c}=\frac{3\varepsilon}{10}, \quad z_u=\frac{4\varepsilon}{10}. \]

For \(u\in X\), set

\[ x_{u,a}=3\varepsilon, \quad x_{u,b}=4\varepsilon, \quad x_{u,c}=5\varepsilon, \quad z_u=6\varepsilon. \]

All these numbers are at most \(\eta\), because \(\varepsilon=\eta/10\).

Every chain inequality is strict. Every edge \(e\) has an endpoint in \(X\), and its flow from that endpoint is at least \(3\varepsilon\). Therefore

\[ x_{u,e}+x_{v,e}>2\varepsilon, \]

so every edge proposal is safe.

A vertex outside \(X\) contributes two safe choice proposals, while a vertex in \(X\) contributes one. Hence the total score is

\[ M-n-h\geq M-n-\kappa=\lambda. \]

8. A sufficiently good plan implies a vertex cover

Consider an arbitrary plan, and let \(S\) be its number of safe proposals. Define its deficit from the upper benchmark by

\[ D=(M-n)-S. \]

For a vertex \(u\), let its choice deficit be \(2\) minus the number of safe proposals among \(q_u,\ell_{u,1},\ell_{u,2}\). Let its chain deficit be the number of unsafe proposals among

\[ r_{b,u},r_{c,u},p_u. \]

Let \(U\) be the number of unsafe edge proposals. Since all automatic proposals are always safe,

\[ D= \sum_{u\in V}\text{choice-deficit}(u) + \sum_{u\in V}\text{chain-deficit}(u) + U. \]

Construct a set \(C\subseteq V\) as follows.

  • Add every \(u\) with \(z_u\geq\varepsilon\). Each such vertex has choice deficit at least \(1\).
  • Add every \(u\) with \(z_u<\varepsilon\) and at least one unsafe chain proposal. Each such vertex contributes at least \(1\) to the chain deficit.
  • For every unsafe edge proposal whose edge is not yet covered, add one endpoint.

This gives

\[ |C|\leq D. \]

It remains to show that every safe edge is already covered after the first two steps. Suppose \(e=\{u,v\}\) is safe and neither endpoint was added. Then

\[ z_u<\varepsilon,\qquad z_v<\varepsilon, \]

and all three chain inequalities are safe at both endpoints. Consequently, for the edge-specific variables,

\[ x_{u,e}<z_u<\varepsilon, \qquad x_{v,e}<z_v<\varepsilon. \]

Therefore

\[ x_{u,e}+x_{v,e}<2\varepsilon, \]

contradicting the safety condition for \(p_e\). Hence \(C\) covers every safe edge, and the third step covers all remaining edges.

If \(S\geq\lambda=M-n-\kappa\), then \(D\leq\kappa\). Thus \(G\) has a vertex cover of size at most \(\kappa\).

9. Conclusion

The reduction is polynomial, all masses have polynomial binary encoding length, every positive set is an interval, and every uncertainty set has the required endpoint-adjacent form. The reduction proves \(\mathrm{NP}\)-hardness, while Section 2 proves membership in \(\mathrm{NP}\). Therefore the exact mass-type problem is \(\mathrm{NP}\)-complete.

Step-by-step audit

1. Safety as a strict linear inequality

The characterization is correct.

For any proposal \(p\),

\[ 0\in\operatorname{poss}_\nu(p) \quad\Longleftrightarrow\quad W_p^0(\nu)\geq\frac12. \]

Thus, when \(\operatorname{corr}_\mu(p)=\{1\}\), safety is exactly \(W_p^0(\nu)<1/2\). The analogous statement for \(\operatorname{corr}_\mu(p)=\{0\}\) is also correct.

Because \(P_t^-\) is the complement of \(P_t^+\), the positive and negative underlying masses sum to \(1\). Hence the listed correlation cases are exhaustive, and proposals with correlation set \(\{0,1\}\) are automatically safe.

2. Membership in NP

The LP argument correctly handles strict inequalities by maximizing a common slack \(\delta\).

For a fixed guessed set \(S\), finitely many strict inequalities are simultaneously feasible exactly when their minimum slack can be chosen positive. Rational LP optimization and exact comparison of the rational optimum with zero are polynomial-time operations.

Guessing exactly \(\lambda\) proposals is sufficient: if a plan makes at least \(\lambda\) proposals safe, one may select any \(\lambda\) of them.

The phrase “plan constraints” implicitly must include setting \(y_{t,g}=0\) whenever \(\mu_g=0\), as required by the definition. This is routine and does not affect the conclusion.

3. Construction size and interval restrictions

The counts are correct:

\[ 4|E|+6n=4\left(\frac{3n}{2}\right)+6n=12n=M, \]

and there are \(6n+2n=8n\) coding types.

Each constructed positive set is an interval. In an edge-chain pair, \(\{p_e,r_{e,u}\}\) consists of adjacent positions in the edge gadget, regardless of which endpoint was placed first. It lies at the appropriate endpoint of the positive interval. The singleton uncertainty set at the other end likewise meets the opposite endpoint. The vertex-choice uncertainty intervals also occupy the two ends of their positive interval.

Fully certain balancing types have empty uncertainty sets and therefore satisfy the endpoint-adjacent condition.

4. Delegation graph

For each intended pair, the positive intervals coincide and the source has a larger uncertainty set, hence fewer certain proposals. The two sign-compatibility conditions for an arc are consequently satisfied in the stated direction.

The exclusion of unintended arcs is sound in substance:

  • All separators are certain for coding types.
  • An arc between two types forces agreement at every position that is certain for both, hence at every separator.
  • The separator signature determines the first and last gadgets spanned by a nonprivate interval.
  • Simplicity of \(G\) prevents two distinct vertices from sharing the same pair of incident edge gadgets.
  • Private vertex intervals are disjoint, and every coding source has certain-positive positions, excluding cross-vertex arcs.
  • A fully certain type cannot be a delegation source because no type has a larger certain set.
  • A coding type cannot delegate to an all-positive balancing type because it has a certain-negative position.
  • It cannot delegate to a singleton-positive balancing type because it has at least two certain-positive positions.

Thus the claimed disjoint union of intended directed edges and isolated balancing types is supported.

5. Verification of the flow table

Moving \(x_{u,a}\) from \(v^u_{a,1}\) to \(v^u_{a,2}\):

  • decreases \(W^0\) by \(x_{u,a}\) at \(p_a\) and \(r_{a,u}\);
  • increases it by \(x_{u,a}\) at \(r_{b,u}\).

The corresponding \(b\)-pair decreases \(W^0\) at \(p_b,r_{b,u}\) and increases it at \(r_{c,u}\). The \(c\)-pair decreases it at \(p_c,r_{c,u}\) and increases it at \(p_u\).

Moving \(z_u\) to \(v^u_2\) decreases \(W^0\) at \(p_u,q_u,d_u\) and increases it at \(\ell_{u,1},\ell_{u,2}\).

These changes give exactly the six rows of the table and their strict safety inequalities.

6. Balancing masses

The total balancing mass calculation is correct:

\[ A+\sum_{p\in P}(d_p-A) =\sum_{p\in P}d_p-(M-1)A =1-\rho. \]

The displayed upper bound for \(A\) is algebraically correct. The condition needed for

\[ A\leq\frac12-\rho-2\varepsilon \]

is precisely

\[ M\rho+(3M-2)\varepsilon\leq\frac12, \]

and the chosen parameters satisfy this with substantial slack.

The proof that \(A>0\), however, is only stated as “every \(d_p\) is close to \(1/2\).” The preceding lower bound does make this a routine calculation, but the calculation should be written explicitly. The assertion \(M\geq48\) also assumes that the cubic source graph is nonempty; the reduction does not separately mention the empty cubic graph, for which \(n=0\) would make \(\eta\) undefined.

7. Correct-outcome sets of critical proposals

The conclusion that every critical proposal has correlation set \(\{1\}\) is correct, but only two cases are shown explicitly.

The omitted cases are routine:

  • At \(r_{b,u}\), \(r_{c,u}\), and \(p_u\), the prescribed \(W^0\) value is \(1/2\), while there is positive coding mass that is positive but uncertain.
  • At each \(\ell_{u,i}\), the prescribed value is already \(1/2-\varepsilon\), so the certainly positive mass exceeds \(1/2\).

The prover should state these checks because the safety table depends on every critical proposal having exactly the singleton correct set \(\{1\}\).

8. Score threshold

The choice-proposal analysis correctly treats the strict boundary:

  • \(z_u<\varepsilon\) makes exactly the two low proposals safe.
  • \(z_u>\varepsilon\) makes exactly \(q_u\) safe.
  • \(z_u=\varepsilon\) makes all three unsafe.

The proposal categories contain:

  • \(3n/2\) edge proposals;
  • \(3n\) chain proposals;
  • \(3n\) choice proposals;
  • the remaining \(9n/2\) automatic proposals.

Consequently, the benchmark is

\[ \frac{9n}{2}+\frac{3n}{2}+3n+2n=11n=M-n. \]

9. Forward implication

All assigned flows lie in \([0,\eta]\), since the largest is \(6\varepsilon=3\eta/5\).

Both selected and unselected vertices satisfy the three strict chain inequalities. Every covered edge receives at least \(3\varepsilon\) from a selected endpoint, so its edge inequality is satisfied.

The resulting score is correctly computed as

\[ M-n-h\geq M-n-\kappa. \]

10. Reverse implication

The deficit identity is exact because automatic, edge, chain, and choice proposals partition all proposals.

Steps 1 and 2 select disjoint classes of vertices and charge each selected vertex to at least one unit of choice or chain deficit. Step 3 adds at most one vertex for each unsafe edge, so

\[ |C|\leq D. \]

If a safe edge had neither endpoint selected in the first two steps, then at each endpoint \(z_u<\varepsilon\) and every chain inequality would be safe. Therefore every incident edge variable satisfies \(x_{u,e}<z_u<\varepsilon\). The two endpoint contributions would sum to less than \(2\varepsilon\), contradicting edge safety.

Thus \(C\) is a vertex cover, and a score of at least \(M-n-\kappa\) implies \(|C|\leq\kappa\).
