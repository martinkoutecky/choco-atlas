Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Polynomial-time solvability

Theorem

Under the formulation exactly as stated, with \(T\), \(A\), \(d_0\), \(r\), and all rational numbers given explicitly in binary, the maximum rooted mass of \(r\) is computable in polynomial time. Consequently, the threshold decision problem belongs to \(\mathrm P\).

The proof uses two stated features of the model:

  • A type mass may be divided among arbitrarily many subcohorts.
  • Zero-mass subcohorts are allowed because \(a_v\geq 0\).

The second feature permits zero-mass ancestors to realize any permitted delegation path without consuming the masses of its intermediate roles.

1. Reachability and feasible immediate actions

Let \(G=(T,A)\), with an arc \(t\to u\) whenever \((t,u)\in A\). Write \(u\leadsto s\) if \(G\) contains a directed path from \(u\) to \(s\), allowing a path of length zero.

For each \(t\in T\), define two sets of possible immediate actions.

The set \(Q_t^r\) consists of:

  • \(\mathrm{vote}\), if \(t=r\);
  • every \(u\in T\) such that \((t,u)\in A\) and \(u\leadsto r\).

Thus \(Q_t^r\) contains precisely the immediate actions available to a type-\(t\) subcohort whose root has role \(r\).

The set \(Q_t^{\neg r}\) consists of:

  • \(\mathrm{vote}\), if \(t\neq r\);
  • every \(u\in T\) such that \((t,u)\in A\) and there exists \(s\neq r\) with \(u\leadsto s\).

Thus \(Q_t^{\neg r}\) contains precisely the immediate actions available to a type-\(t\) subcohort whose root does not have role \(r\).

Define the immediate-action cost

\[ c_t(q)=\mathbf 1[q\neq d_0(t)]. \]

Define

\[ \alpha_t=\min_{q\in Q_t^r}c_t(q), \qquad \beta_t=\min_{q\in Q_t^{\neg r}}c_t(q), \]

where the minimum of an empty set is \(+\infty\). Every finite value among \(\alpha_t,\beta_t\) belongs to \(\{0,1\}\).

At least one of \(\alpha_t,\beta_t\) is finite: if \(t=r\), voting realizes root \(r\); if \(t\neq r\), voting realizes a root different from \(r\).

2. Immediate-action characterization

Lemma 1

A type-\(t\) subcohort can have root role \(r\) and immediate action \(q\) if and only if \(q\in Q_t^r\). It can have a root role different from \(r\) and immediate action \(q\) if and only if \(q\in Q_t^{\neg r}\).

Proof

Suppose a node \(v\) of role \(t\) has root role \(r\).

If \(v\) is a root, then its immediate action is \(\mathrm{vote}\), and necessarily \(t=r\). Hence \(\mathrm{vote}\in Q_t^r\).

Otherwise, let its parent have role \(u\). Then \((t,u)\in A\). The sequence of roles along the ancestors of \(v\) gives a directed walk from \(u\) to \(r\), so \(u\leadsto r\). Hence \(u\in Q_t^r\).

Conversely, suppose \(q\in Q_t^r\). If \(q=\mathrm{vote}\), then \(t=r\), so a single type-\(r\) root realizes the action. If \(q=u\in T\), choose a simple directed path from \(u\) to \(r\). Create a type-\(t\) node whose parent has role \(u\), followed by zero-mass nodes having the successive roles on that path, with the final type-\(r\) node as a root. This is a finite acyclic chain and realizes immediate action \(u\) and root role \(r\).

The proof for \(Q_t^{\neg r}\) is identical, choosing a terminal role \(s\neq r\). ∎

3. Exact reduction to one variable per type

Let \(x_t\) denote the amount of type-\(t\) mass whose root has role \(r\).

Necessarily,

\[ 0\leq x_t\leq\mu_t. \]

If \(\alpha_t=+\infty\), then \(x_t=0\). If \(\beta_t=+\infty\), then \(x_t=\mu_t\).

Lemma 2

For every feasible forest with target-rooted masses \(x_t\), its cost is at least

\[ \sum_{t:\alpha_t<+\infty}\alpha_t x_t+ \sum_{t:\beta_t<+\infty}\beta_t(\mu_t-x_t). \]

Conversely, every vector satisfying the preceding bounds and forced equalities is realized by a finite acyclic forest having exactly this cost.

Proof

Consider all type-\(t\) nodes rooted at \(r\). By Lemma 1, each such node takes an action in \(Q_t^r\), whose cost is at least \(\alpha_t\). Their total mass is \(x_t\), so their total cost is at least \(\alpha_t x_t\).

Likewise, every type-\(t\) node not rooted at \(r\) has immediate-action cost at least \(\beta_t\), and their total mass is \(\mu_t-x_t\). Summing over all types proves the lower bound.

For the converse, whenever \(x_t>0\), choose an action in \(Q_t^r\) attaining \(\alpha_t\). By Lemma 1, realize a type-\(t\) subcohort of mass \(x_t\) with that action, using zero-mass ancestors along a suitable path.

Whenever \(\mu_t-x_t>0\), choose an action in \(Q_t^{\neg r}\) attaining \(\beta_t\) and similarly realize a subcohort of mass \(\mu_t-x_t\).

Use a separate chain for every constructed subcohort. The union is a finite acyclic forest. For each type \(t\), the positive masses sum to \(x_t+(\mu_t-x_t)=\mu_t\); all scaffolding nodes have mass zero. Its cost is exactly the displayed expression. ∎

Therefore the original problem is exactly the linear program

\[ \max \sum_{t\in T}x_t \]

subject to the bounds and forced equalities above and

\[ \sum_t\bigl(\alpha_t x_t+\beta_t(\mu_t-x_t)\bigr)\leq B, \]

with terms involving an impossible alternative replaced by the corresponding forced equality.

4. Closed form for the optimum

Define

\[ m_t=\min\{\alpha_t,\beta_t\}, \qquad C_{\min}=\sum_{t\in T}\mu_t m_t, \]

where the minimum is over the finite alternatives. By Lemma 2, \(C_{\min}\) is the minimum cost of any forest.

Define \(y_t\) as follows:

  • \(y_t=\mu_t\) if \(\beta_t=+\infty\);
  • \(y_t=0\) if \(\alpha_t=+\infty\);
  • \(y_t=\mu_t\) if both values are finite and \(\alpha_t\leq\beta_t\);
  • \(y_t=0\) if both values are finite and \(\alpha_t>\beta_t\).

Let

\[ X_0=\sum_{t\in T}y_t. \]

This allocation has cost \(C_{\min}\), with ties resolved in favor of being rooted at \(r\).

Let

\[ H=\{t\in T:\alpha_t,\beta_t<+\infty\text{ and }\alpha_t>\beta_t\}, \qquad M_H=\sum_{t\in H}\mu_t. \]

Because all finite costs belong to \(\{0,1\}\), every \(t\in H\) satisfies \(\alpha_t=1\) and \(\beta_t=0\).

Proposition 3

If \(B<C_{\min}\), no feasible forest exists. If \(B\geq C_{\min}\), the maximum rooted mass is

\[ X^\star=X_0+\min\{M_H,B-C_{\min}\}. \]

Proof

For a type with both alternatives feasible and \(\alpha_t\leq\beta_t\), increasing \(x_t\) toward \(\mu_t\) weakly decreases cost and increases the objective. Hence an optimum has \(x_t=\mu_t\) for every such type. Types with an impossible alternative are forced as specified by \(y_t\).

Only types in \(H\) remain variable. Relative to the minimum-cost allocation, assigning \(x_t\) target-rooted mass for \(t\in H\) increases both the cost and the objective by exactly \(x_t\). Hence the reduced problem is

\[ \max \sum_{t\in H}x_t \quad\text{subject to}\quad \sum_{t\in H}x_t\leq B-C_{\min}, \qquad 0\leq x_t\leq\mu_t. \]

Its optimum is \(\min\{M_H,B-C_{\min}\}\). This value is attained by filling the types in \(H\) successively, fractionally filling the last one if necessary. Lemma 2 then supplies a forest attaining the resulting objective. ∎

5. Polynomial-time algorithm

The algorithm is:

  • Compute directed reachability in \(G\), for example by a graph search from every role.
  • Enumerate \(Q_t^r\) and \(Q_t^{\neg r}\), and compute \(\alpha_t\) and \(\beta_t\).
  • Compute \(C_{\min}\), \(X_0\), and \(M_H\) by exact rational arithmetic.
  • If \(B<C_{\min}\), report infeasibility. Otherwise return \(X^\star\) from Proposition 3.
  • For the decision problem, answer yes exactly when \(B\geq C_{\min}\) and \(X^\star\geq\theta\).

Reachability takes polynomial time in \(|T|+|A|\). All remaining operations are polynomially many additions and comparisons of binary-encoded rationals. Their intermediate bit lengths remain polynomial in the input length.

An explicit optimal forest also has polynomial size: there are at most two positive-mass chains per type, and every reachability path may be chosen simple, with at most \(|T|-1\) arcs.

6. Relation to the finite-voter hardness result

The finite-voter NP-completeness result does not transfer to this formulation. Here each type mass may be divided fractionally, and the budget charges changed mass rather than the number of indivisible changed voters. Consequently, the residual optimization is a fractional knapsack with unit marginal cost, not a cardinality-constrained integral selection problem.

The use of zero-mass ancestors is also essential to this exact characterization. Requiring every listed subcohort to have positive mass or imposing capacity constraints on parent subcohorts would define a different problem and is not covered by this proof.
