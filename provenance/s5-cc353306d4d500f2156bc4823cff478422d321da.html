Theorem 5.5 — class: algorithmic

The continuous mirror question, as graded

Given candidates \(C\), approval types \(A_1,\ldots,A_\tau\subseteq C\), and positive binary-rational masses \(\mu_1,\ldots,\mu_\tau\) summing to \(1\), compute the exact Hamming Pairwise Agreement for \(0<p<1\), where \(q_j=\sum_{t:c_j\in A_t}\mu_t\) and \(p=\frac{1}{m}\sum_{j=1}^m q_j\): return \(1-\frac{\sum_{j=1}^m q_j(1-q_j)}{mp(1-p)}\).

Packaged proof task (what the prover saw — nothing else)

Let \(C=\{c_1,\ldots,c_m\}\), with \(m\geq 1\). A society is given by its support: the list of \(\tau\) distinct approval types \(A_t\subseteq C\), each with positive mass \(\mu_t\) given as a binary rational, and \(\sum_{t=1}^{\tau}\mu_t=1\). Types are encoded by their approval incidence vectors; \(\tau\) is the support size, not the number \(2^m\) of possible types. Let \(L\) be the total input bit length.
Define \(q_j=\sum_{t:c_j\in A_t}\mu_t\) and the saturation \(p=\frac{1}{m}\sum_{j=1}^{m}q_j\), and restrict inputs to \(0<p<1\). The computational problem is to compute the exact rational Hamming Pairwise Agreement \(H=1-\frac{\sum_{j=1}^{m}q_j(1-q_j)}{mp(1-p)}\).

Is exact computation of \(H\) solvable in polynomial time in \(m,\tau,L\) in the bit model, or is it NP-hard?

For a discrete approval election with \(m\) candidates and \(n\) explicitly listed voters, Hamming Pairwise Agreement is computable in \(O(mn)\) arithmetic operations.

Conclusion

Exact computation of \(H\) is polynomial-time solvable in the bit model. The explicitly listed support suffices: computing the marginals requires no enumeration of the \(2^m\) possible approval types. Both the intermediate integers and the exact output have polynomially bounded bit length.

1. Convert the masses to a common denominator

Write each input mass as \(\mu_t=a_t/b_t\), where \(a_t,b_t\) are positive integers encoded in binary. Define

\(B=\prod_{t=1}^{\tau}b_t,\qquad w_t=a_t(B/b_t).\)

Each division \(B/b_t\) is exact, and \(\mu_t=w_t/B\). The normalization assumption gives

\(\sum_{t=1}^{\tau}w_t=B.\)

For each candidate, compute the integer

\(Q_j=\sum_{t:c_j\in A_t}w_t.\)

Then \(q_j=Q_j/B\) and \(0\leq Q_j\leq B\). These sums can be computed by scanning the \(\tau\) supplied incidence vectors, using at most \(m\tau\) integer additions.

Set

\(S=\sum_{j=1}^{m}Q_j,\qquad U=\sum_{j=1}^{m}Q_j^2.\)

Since \(p=S/(mB)\), the promise \(0<p<1\) implies \(0<S<mB\).

2. An exact integer formula for the output

Substituting the quantities above gives

\(\sum_{j=1}^{m}q_j(1-q_j)=\dfrac{BS-U}{B^2}\)

and

\(mp(1-p)=\dfrac{S(mB-S)}{mB^2}.\)

Consequently,

\(H=1-\dfrac{m(BS-U)}{S(mB-S)} =\dfrac{mU-S^2}{S(mB-S)}.\)

Thus the algorithm computes

\(N=mU-S^2,\qquad D=S(mB-S)\)

and outputs \(N/D\), reducing it by \(\gcd(N,D)\) if a reduced fraction is required. The promised restriction ensures \(D>0\), so the output is always defined.

For completeness, the numerator is nonnegative because

\(mU-S^2=\sum_{1\leq j<k\leq m}(Q_j-Q_k)^2\geq 0.\)

Also,

\(D-N=m(BS-U)=m\sum_{j=1}^{m}Q_j(B-Q_j)\geq 0.\)

Hence \(0\leq H\leq 1\), including the case \(N=0\), for which the reduced output is \(0/1\).

3. Bit complexity

Let

\(K=L+\lceil\log_2(m+1)\rceil+2.\)

The binary length of \(B\) is at most one plus the sum of the binary lengths of the input denominators, hence at most \(L+1\). Moreover,

\(0<w_t\leq B,\quad 0\leq Q_j\leq B,\quad S\leq mB,\quad U\leq mB^2.\)

The first bound follows from positivity and \(\sum_t w_t=B\). Therefore every integer used above, including \(N\) and \(D\), has \(O(K)\) bits: in particular, \(mU\), \(S^2\), and \(D\) are bounded by \(m^2B^2\). Intermediate products forming \(B\) are also bounded by \(B\).

The algorithm uses:

  • \(O(\tau)\) integer multiplications and exact divisions to construct \(B\) and the \(w_t\);
  • \(O(m\tau)\) integer additions to construct the marginals;
  • \(O(m)\) additions and multiplications to construct \(S,U,N,D\);
  • one greatest-common-divisor computation and two exact divisions to reduce the result.

Schoolbook addition takes \(O(K)\) bit operations, and multiplication or division takes \(O(K^2)\). The Euclidean algorithm uses \(O(K)\) divisions on integers of at most \(O(K)\) bits, yielding the sufficient bound \(O(K^3)\) for reduction. A conservative total bound is therefore

\(O\!\left(L+(\tau+m)K^2+m\tau K+K^3\right),\)

which is polynomial in \(m,\tau,L\). The reduced numerator and denominator also have \(O(K)\) bits, so writing the exact answer takes polynomial time.

4. Complexity classification

The exact rational-valued function belongs to \(\mathrm{FP}\). The stated \(O(mn)\) arithmetic-operation algorithm for explicitly listed voters is consistent with this result; binary rational masses additionally require the bit-length analysis established above.

If exact computation were NP-hard under polynomial-time Turing reductions, this polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).
