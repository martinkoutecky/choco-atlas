The continuous mirror question, as graded

Given an agenda whose conclusions are positive monotone clauses of length two and their negations, a distribution \(\mu\) with binary-rational masses over complete consistent premise assignments, a consistent desired set \(J\), and a rational budget \(\beta\in[0,1]\), decide whether there are transfers \(x_{t,u}\ge 0\) from supported types \(t\) to complete consistent destination types \(u\), with \(\sum_u x_{t,u}\le\mu_t\) for each \(t\) and \(\sum_{t,u\ne t}x_{t,u}\le\beta\). The resulting mass is \(\mu'_u=\mu_u-\sum_v x_{u,v}+\sum_t x_{t,u}\). Let \(F(\nu)\) accept a premise exactly when its mass under \(\nu\) exceeds \(1/2\), then derive conclusions as in the paper; decide whether \(|J\setminus F(\mu')|<|J\setminus F(\mu)|\).

Packaged proof task (what the prover saw — nothing else)

Let \(\Phi\) be an explicitly listed agenda containing \(m\) premise variables and their negations, together with positive clauses \(p_i\lor p_j\), \(i\ne j\), and their negations; formulas have no multiplicities. Types are all assignments in \(T=\{0,1\}^m\), each inducing a complete consistent judgment set; there are no additional integrity constraints.
A society is given by its support: the list \(S\subseteq T\) of the \(\tau\) types with positive mass, each mass a binary rational, with \(\sum_{t\in S}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Set \(\mu_u=0\) outside \(S\).
The input also contains a possibly incomplete consistent desired set \(J\subseteq\Phi\), which may contain premise literals, and a binary-rational budget \(\beta\in[0,1]\).
A feasible intervention consists of real transfers \(x_{t,u}\ge0\) for \(t\in S\), \(u\in T\), with \(\sum_{u\in T}x_{t,u}\le\mu_t\) and \(\sum_{t\in S}\sum_{u\ne t}x_{t,u}\le\beta\). Each unit of mass moved to a different assignment costs one, regardless of how many premises change; destination types need not be supported initially.
Extend transfers by zero for sources outside \(S\), and define \(\mu'_u=\mu_u-\sum_{v\in T}x_{u,v}+\sum_{t\in S}x_{t,u}\).
For any distribution \(\nu\), the collective assignment sets \(p_i\) true exactly when \(\sum_{u:u_i=1}\nu_u>1/2\); ties set it false. Let \(F(\nu)\) contain the corresponding premise literals and exactly the conclusions true under this assignment.
The decision problem asks whether a feasible intervention satisfies \(|J\setminus F(\mu')|<|J\setminus F(\mu)|\). Let \(L\) be the total input bit length; state running times in \(m,\tau,|\Phi|,L\).

Is this continuous bribery decision problem solvable in polynomial time, or is it \(\mathsf{NP}\)-hard?

For finite societies, changing at most \(k\) whole judgment sets to obtain the same strict improvement is \(\mathsf{NP}\)-hard and \(\mathsf{W}[2]\)-hard parameterized by \(k\), even at majority quota with these conclusion restrictions; it is polynomial-time solvable for each fixed \(k\). [Source](https://arxiv.org/html/2402.16016v1).
No result settling the exact mass-transfer problem was identified in the literature search.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: positive supported masses sum to one, and unsupported types have zero initial mass.
  • Defined m as the number of premise variables and L as the total input bit length; included agenda size in running-time notation.
  • Specified an agenda without formula multiplicities, with two distinct variables in each length-two positive clause.
  • Specified that every Boolean premise assignment is an admissible type, with no additional integrity constraints.
  • Made explicit that J is a subset of the agenda, may be incomplete, and may include premise literals, as in the discrete bribery definition.
  • Completed the aggregation rule by making tied premises false and evaluating every conclusion and its negation under the collective assignment.
  • Specified real-valued transfers, unrestricted destination assignments, zero transfers from unsupported sources, and unit cost per moved mass independent of the number of changed premises.

Result

The continuous mass-transfer problem is \(\mathsf{NP}\)-complete. In particular, it is \(\mathsf{NP}\)-hard even when all input masses and the budget are dyadic rationals.

The proof treats fractional transfers directly; it does not infer hardness from the whole-judgment-set bribery result in the [provided paper](https://arxiv.org/html/2402.16016v1).

1. Polynomial-time verification of a proposed collective assignment

Write \(r_i=\sum_{t\in S}\mu_t t_i\) for the initial marginal of premise \(p_i\).

Lemma 1. A collective assignment \(a\in\{0,1\}^m\) is attainable within budget if and only if it is attainable by sending all moved mass to the single destination \(a\).

Proof. Delete diagonal transfers, which affect neither the distribution nor the cost. Given an intervention attaining \(a\), let \(y_t\) be the total mass moved from source \(t\).

Redirect this mass to \(a\). When \(t=a\), simply leave it in place. For a coordinate with \(a_i=1\), this redirection weakly increases its final marginal: the new destination has coordinate \(1\), whereas every original destination had coordinate at most \(1\). For a coordinate with \(a_i=0\), redirection weakly decreases its final marginal.

Consequently, every strict majority required by \(a\) remains strict, and every marginal required to be at most \(1/2\) remains so. Source capacities remain satisfied, and cost does not increase. The converse is immediate. \(\square\)

For a fixed \(a\), introduce variables \(y_t\), \(t\in S\), and \(\epsilon\). Solve the rational linear program maximizing \(\epsilon\), subject to

\(0\le y_t\le\mu_t,\qquad \sum_{t\in S}y_t\le\beta,\qquad 0\le\epsilon\le1,\)

and, for each premise,

\(r_i+\sum_{t\in S}y_t(a_i-t_i)\ge\frac12+\epsilon\quad\text{if }a_i=1,\)

\(r_i+\sum_{t\in S}y_t(a_i-t_i)\le\frac12\quad\text{if }a_i=0.\)

The assignment is attainable exactly when this program is feasible and its optimum is positive. Indeed, finitely many strict majority inequalities have a common positive slack whenever they all hold. If \(a\) has no true coordinates, any feasible solution permits \(\epsilon=1\).

The program has \(\tau+1\) variables, \(O(m+\tau)\) constraints, and coefficients of bit length polynomial in \(L\). Exact rational linear programming therefore decides attainability in \(\operatorname{poly}(m,\tau,L)\) time.

A nondeterministic algorithm guesses \(a\), evaluates the improvement condition in \(\operatorname{poly}(|\Phi|,L)\) time, and performs this attainability test. Thus the problem belongs to \(\mathsf{NP}\). Enumerating all assignments also gives a deterministic running time of

\(2^m\operatorname{poly}(m,\tau,|\Phi|,L).\)

2. Preparing the clique instance

We reduce from the standard \(\mathsf{NP}\)-complete problem Clique. Let the input be a simple graph \(G_0\) on \(N\) vertices and a target \(q\), with \(2\le q\le N\).

Add \(h\) new vertices, each adjacent to every other vertex, where \(h\in\{N+4,N+5\}\) is chosen so that

\(k=q+h\)

is odd. Call the resulting graph \(G=(V,E)\), put \(n=N+h\), and designate one new vertex \(a\).

Then \(G_0\) has a \(q\)-clique if and only if \(G\) has a \(k\)-clique containing \(a\):

  • A \(q\)-clique together with all \(h\) new vertices gives such a clique.
  • Any \(k\)-clique contains at least \(k-h=q\) original vertices, which form a clique in \(G_0\).

Define

\(D=n^2,\qquad C=\binom{k}{2},\qquad H=D(k-1)-C.\)

Here \(k\ge5\), \(k\le n\), and

\(2(k-1)-n=2q+h-N-2\ge6.\)

Consequently,

\(2H-nD=(2(k-1)-n)D-k(k-1)>0.\)

Also \(H>D\), because \(C<D/2\) and \(k\ge5\).

Choose a positive dyadic rational \(w\) satisfying

\(\frac{1}{2(H+1)}<w\le\frac{1}{2H}.\)

Such a number can be computed with \(O(\log n)\) bits. Explicitly, choose \(b\) with \(2^b>2H(H+1)\) and set

\(w=\frac{\lfloor 2^{b-1}/H\rfloor}{2^b}.\)

Rounding downward changes \(1/(2H)\) by less than \(2^{-b}\), which is smaller than the width of the displayed interval.

Set the intervention budget to

\(\beta=\frac12-Dw.\)

Since \(H>D\), we have \(0<\beta<1/2\).

3. Constructing the society

Introduce a vertex premise \(x_v\) for every \(v\in V\), and auxiliary premises \(y_1,\ldots,y_c\), where

\(c=\frac{k-1}{2}.\)

All supported types set every auxiliary premise false. Their vertex coordinates and masses are:

  • For each edge \(\{u,v\}\in E\), a type setting exactly \(x_u,x_v\) false, with mass \(w\).
  • For each vertex \(v\), a type setting exactly \(x_v\) false, with mass \((D-\deg_G(v))w\).
  • A type setting every vertex premise true, with mass

\(1-w(nD-|E|)\).

These types are distinct. Every mass is positive: \(D>\deg_G(v)\), and

\(w(nD-|E|)\le\frac{nD}{2H}<1.\)

Their masses sum to one because the first two groups have total mass

\(w|E|+w\sum_{v\in V}(D-\deg_G(v))=w(nD-|E|).\)

For each vertex \(v\), its total false mass is

\(w\deg_G(v)+(D-\deg_G(v))w=Dw.\)

Therefore every vertex premise initially has marginal

\(r_v=1-Dw=\frac12+\beta,\)

and is collectively true. Every auxiliary premise is collectively false.

Moreover, auxiliary premises remain collectively false under every feasible intervention: starting from marginal zero, any such premise can gain at most the total moved mass, which is at most \(\beta<1/2\).

4. Exactly which vertex sets can be turned false?

For \(A\subseteq V\), write \(s=|A|\) and let \(e_G(A)\) denote the number of edges induced by \(A\).

Lemma 2. For nonempty \(A\), an intervention making every \(x_v\), \(v\in A\), collectively false exists if and only if

\(w\bigl(D(s-1)-e_G(A)\bigr)\le\frac12.\)

When this inequality holds, an intervention can make precisely the vertex premises indexed by \(A\) false.

Proof. Again delete diagonal transfers, and let \(B\le\beta\) be the moved mass.

For any \(v\in A\), its marginal must decrease from \(1/2+\beta\) to at most \(1/2\), a decrease of at least \(\beta\). Each unit of moved mass decreases this marginal by at most one. Hence \(B=\beta\), and every positive transfer must move from a source with \(x_v=1\) to a destination with \(x_v=0\).

This holds simultaneously for every \(v\in A\). Thus all moved mass must come from supported types whose vertex coordinates are true throughout \(A\). Their total mass must be at least \(\beta\).

We calculate this common-source mass. Summing the false mass \(Dw\) over vertices in \(A\) counts an edge type twice exactly when both endpoints lie in \(A\). No supported type has more than two false vertex coordinates. Therefore the mass of types false on at least one vertex in \(A\) is

\(w(Ds-e_G(A)).\)

The common-source mass is consequently

\(M_A=1-w(Ds-e_G(A)).\)

Necessity follows by substituting \(\beta=1/2-Dw\) into \(M_A\ge\beta\).

Conversely, if \(M_A\ge\beta\), take total mass \(\beta\) from those common sources and send it to the assignment that sets precisely the vertex premises in \(A\) false and every auxiliary premise false. Each selected vertex marginal becomes exactly \(1/2\), so ties make it false. Every other vertex marginal weakly increases and remains true. Since \(A\) is nonempty, every selected source differs from the destination, so the cost is exactly \(\beta\). \(\square\)

Two consequences enforce the clique constraint.

First, at most \(k\) vertex premises can become false. If \(s>k\), then

\(D(s-1)-e_G(A)\ge D(s-1)-\binom{s}{2},\)

and

\(D(s-1)-\binom{s}{2}-H =(s-k)\left(D-\frac{s+k-1}{2}\right)>1.\)

Thus \(D(s-1)-e_G(A)\ge H+1\). Our choice of \(w\) gives \(w(H+1)>1/2\), contradicting Lemma 2.

Second, a set of exactly \(k\) vertex premises can become false if and only if its vertices form a clique. For \(s=k\),

\(D(s-1)-e_G(A)=H+C-e_G(A).\)

If \(A\) is a clique, this equals \(H\), and \(wH\le1/2\). Otherwise it is at least \(H+1\), and \(w(H+1)>1/2\).

5. Constructing the agenda and desired set

The agenda contains all premise literals and the following positive clauses and their negations:

  • \(x_u\lor x_v\) for every \(\{u,v\}\in E\);
  • \(x_v\lor y_j\) for every \(v\in V\) and \(1\le j\le c\).

Every clause uses distinct premises. There are no repeated formulas.

Set

\(J= \{\neg(x_u\lor x_v):\{u,v\}\in E\} \;\cup\; \{x_v\lor y_j:v\in V,\ 1\le j\le c\} \;\cup\; \{\neg x_a\}.\)

This desired set is consistent: the assignment setting every vertex premise false and every auxiliary premise true satisfies all its formulas.

Let \(A\) be the vertex premises made collectively false by an intervention. Auxiliary premises remain false, as proved above. Relative to the initial outcome:

  • Exactly \(e_G(A)\) desired negative edge clauses become satisfied.
  • Exactly \(c|A|\) desired positive clauses cease to be satisfied.
  • The desired literal \(\neg x_a\) becomes satisfied exactly when \(a\in A\).

Thus the improvement in the number of satisfied desired formulas is

\(\Delta(A)=e_G(A)-c|A|+\mathbf{1}_{a\in A}.\)

The problem’s strict-improvement condition is exactly \(\Delta(A)>0\).

If \(A=\varnothing\), then \(\Delta(A)=0\). If \(1\le s=|A|<k\), then

\(\Delta(A)\le\binom{s}{2}-\frac{k-1}{2}s+1 =1-\frac{s(k-s)}{2}.\)

Because

\(s(k-s)-(k-1)=(s-1)(k-1-s)\ge0,\)

and \(k\ge5\), this upper bound is negative.

Sets larger than \(k\) are unattainable. An attainable set of size \(k\) is a clique, and for such a set,

\(\Delta(A)=\binom{k}{2}-\frac{k-1}{2}k+\mathbf{1}_{a\in A} =\mathbf{1}_{a\in A}.\)

Therefore strict improvement is possible exactly when \(G\) has a \(k\)-clique containing \(a\), equivalently when \(G_0\) has a \(q\)-clique.

6. Size and complexity conclusion

The construction has

\(m=n+\frac{k-1}{2}=O(n),\)

\(\tau=n+|E|+1=O(n^2),\)

and

\(|\Phi|=2\left(m+|E|+n\frac{k-1}{2}\right)=O(n^2).\)

All masses and the budget are dyadic rationals with \(O(\log n)\) bits. Explicitly listing the support assignments takes \(O(n^3)\) bits, and the entire reduction is computable in polynomial time, for example \(O(n^3\operatorname{poly}(\log n))\) bit operations.

Together with Section 1, this proves \(\mathsf{NP}\)-completeness. Hence a running time polynomial in \(m,\tau,|\Phi|,L\) would imply \(\mathsf{P}=\mathsf{NP}\).
