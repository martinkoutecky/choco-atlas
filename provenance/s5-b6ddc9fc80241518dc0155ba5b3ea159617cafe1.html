The continuous mirror question, as graded

Given candidates \(C\) of size \(d\), a partition into groups \(G_1,\ldots,G_g\), rational fairness bounds \(\alpha_i,\beta_i\), block parameters \(k,b\), and a rational distribution \(\mu\) supported on \(\tau\) rankings, find a block-fair permutation \(\sigma\) whose expected Kendall tau distance \(\sum_{\pi}\mu_\pi\mathcal K(\pi,\sigma)\) is at most \(3\) times the minimum over feasible permutations. Feasibility requires \(\alpha_i\ell\le |P_\ell(\sigma)\cap G_i|\le\beta_i\ell\) for every \(i\) and every prefix length \(\ell\ge k\) divisible by \(b\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m=d\ge1\) candidates partitioned into \(g\) nonempty groups \(G_1,\ldots,G_g\). Input bounds satisfy \(\alpha_i,\beta_i\in[0,1]\cap\mathbb Q\); parameters satisfy \(k\in\{1,\ldots,m\}\), \(b\in\mathbb Z_{>0}\), and \(b\alpha_i,b\beta_i\in\mathbb Z\) for every \(i\).
A society is given by its support: the list of the \(\tau\) strict rankings with positive mass, each mass \(\mu_\pi\) a binary rational, with \(\sum_\pi\mu_\pi=1\). Here \(\tau\) is the support size, not the number \(m!\) of possible rankings. Let \(L\) be the total input bit length; state running times in \(m,\tau,g,k,b,L\).
For a permutation \(\sigma\), let \(P_\ell(\sigma)\) be its first \(\ell\) candidates. Define \(\mathcal F\) to contain exactly those permutations satisfying \(\alpha_i\ell\le |P_\ell(\sigma)\cap G_i|\le\beta_i\ell\) for every \(i\) and every \(\ell\in\{k,\ldots,m\}\) divisible by \(b\). Assume \(\mathcal F\ne\varnothing\).
Using Kendall tau distance \(\mathcal K\), define \(D_\mu(\sigma)=\sum_{\pi\in\operatorname{supp}(\mu)}\mu_\pi\mathcal K(\pi,\sigma)\) and \(\mathrm{OPT}_\mu=\min_{\sigma\in\mathcal F}D_\mu(\sigma)\).

Does this problem admit an algorithm, polynomial in \(m,\tau,g,L\), returning \(\sigma\in\mathcal F\) with \(D_\mu(\sigma)\le3\mathrm{OPT}_\mu\), or is achieving this approximation guarantee NP-hard?

For an unweighted set of \(n\) rankings, a \(3\)-approximation for block-fair Kendall tau aggregation runs in \(\mathcal O(nm^2+n^2m\log m)\). [Fair Rank Aggregation](https://arxiv.org/pdf/2308.10499)
Later work gives a polynomial-time \(2.881\)-approximation for unweighted aggregation under block fairness. [Improved Rank Aggregation Under Fairness Constraint](https://www.ijcai.org/proceedings/2025/0038.pdf)
No result explicitly treating this binary-rational support-mass formulation was verified.

Result

There is a deterministic algorithm, polynomial in \(m,\tau,g,L\), returning a feasible ranking with cost at most \(3\mathrm{OPT}_\mu\). Binary-rational masses can be handled directly, without expanding the support into a multiset.

1. Exact projection onto the feasible set

We use the following published result: given a ranking \(\pi\), a partition into arbitrarily many groups, rational proportional bounds, and block parameters \(k,b\), an exact closest block-fair ranking under Kendall tau distance can be computed in \(\mathcal O(m^2)\) arithmetic operations. This is Theorem 3.4, with block fairness defined in Definition 2.5, of [Fair Rank Aggregation](https://arxiv.org/pdf/2308.10499).

Its hypotheses match this task:

  • The groups partition the candidates.
  • The bounds are rational and belong to \([0,1]\).
  • Constraints apply precisely at prefix lengths \(\ell\ge k\) divisible by \(b\).
  • At those lengths, \(\alpha_i\ell\) and \(\beta_i\ell\) are integers, because \(b\alpha_i,b\beta_i\) are integers.
  • A feasible ranking exists by assumption.

Consequently, for every input ranking \(\pi\), we can compute a ranking \(T(\pi)\in\mathcal F\) satisfying

\(\mathcal K(\pi,T(\pi))=\min_{\sigma\in\mathcal F}\mathcal K(\pi,\sigma).\)

If there are no constrained prefix lengths, take \(T(\pi)=\pi\).

2. Algorithm for weighted support

Enumerate the support as \(\pi_1,\ldots,\pi_\tau\), with weights \(\mu_1,\ldots,\mu_\tau\).

  • Compute \(\sigma_j=T(\pi_j)\) for every \(j\).
  • Compute each weighted score \(S_j=\sum_{s=1}^{\tau}\mu_s\mathcal K(\pi_s,\sigma_j)\) exactly.
  • Return a ranking \(\widehat\sigma\) with minimum score among \(\sigma_1,\ldots,\sigma_\tau\).

Every possible output belongs to \(\mathcal F\). The weights affect score evaluation; they do not increase the number of projections.

3. Proof of the approximation guarantee

Kendall tau distance counts unordered candidate pairs on which two rankings disagree. For each pair, disagreement between two rankings implies disagreement with at least one of any third ranking. Summing this observation over pairs proves the triangle inequality.

Since \(\mathcal F\) is finite and nonempty, an optimal ranking \(\sigma^\star\in\mathcal F\) exists.

The numbers \(\mathcal K(\pi_j,\sigma^\star)\) have weighted average \(\mathrm{OPT}_\mu\). Therefore some support index \(j^\star\) satisfies

\(\mathcal K(\pi_{j^\star},\sigma^\star)\le\mathrm{OPT}_\mu.\)

Indeed, if every one were strictly larger, their average would also be strictly larger, because all weights are positive and sum to one.

Exactness of the projection, with \(\sigma^\star\) as a feasible comparator, gives

\(\mathcal K(\pi_{j^\star},\sigma_{j^\star})\le\mathcal K(\pi_{j^\star},\sigma^\star).\)

Applying the triangle inequality,

\(\mathcal K(\sigma^\star,\sigma_{j^\star})\le\mathcal K(\sigma^\star,\pi_{j^\star})+\mathcal K(\pi_{j^\star},\sigma_{j^\star})\le2\mathrm{OPT}_\mu.\)

For each support ranking \(\pi_s\), another application gives

\(\mathcal K(\pi_s,\sigma_{j^\star})\le\mathcal K(\pi_s,\sigma^\star)+\mathcal K(\sigma^\star,\sigma_{j^\star}).\)

Multiplying by \(\mu_s\), summing, and using \(\sum_s\mu_s=1\), we obtain

\(D_\mu(\sigma_{j^\star})\le\mathrm{OPT}_\mu+\mathcal K(\sigma^\star,\sigma_{j^\star})\le3\mathrm{OPT}_\mu.\)

The algorithm minimizes the weighted score over all projected rankings, so

\(D_\mu(\widehat\sigma)\le D_\mu(\sigma_{j^\star})\le3\mathrm{OPT}_\mu.\)

This argument also covers \(\mathrm{OPT}_\mu=0\); no division by the optimum is used.

4. Running time and exact arithmetic

There are \(\tau\) projections and \(\tau^2\) distance evaluations. A distance evaluation takes \(\mathcal O(m\log(m+1))\) operations: express one ranking in the position coordinates of the other and count inversions by merge sort. Thus the combinatorial operation count is

\(\mathcal O\!\left(\tau m^2+\tau^2m\log(m+1)\right).\)

The number of constrained prefixes is

\(q=\max\!\left\{0,\left\lfloor m/b\right\rfloor-\left\lceil k/b\right\rceil+1\right\}\le m.\)

The projection algorithm processes these prefixes in decreasing order. Hence there is no iteration count proportional to the numerical value of \(b\). Also, \(g\le m\), since all groups are nonempty.

To verify polynomial bit complexity, write \(\mu_s=a_s/d_s\), where the numerators and positive denominators are binary integers. Define

\(Q=\prod_{s=1}^{\tau}d_s,\qquad w_s=a_s(Q/d_s).\)

These are integers, and \(\sum_sw_s=Q\). Their bit lengths are \(\mathcal O(L)\), because the sum of the input denominator bit lengths is at most \(L\).

Instead of comparing rational scores, compare the integers

\(N_j=\sum_{s=1}^{\tau}w_s\mathcal K(\pi_s,\sigma_j)=Q S_j.\)

Multiplication by the common positive \(Q\) preserves their ordering. Moreover,

\(0\le N_j\le Q\binom m2,\)

so each score has \(\mathcal O(L+\log(m+1))\) bits. Exact quota computations likewise use integers of this bit length: multiply a rational bound’s numerator by a prefix length, then divide by its denominator.

Using schoolbook integer arithmetic, a conservative total bit-operation bound is

\(\mathcal O\!\left(\left[L+\tau m^2+\tau^2m\log(m+1)\right]\left[L+\log(m+1)\right]^2\right).\)

This is polynomial in \(m,\tau,g,L\), uniformly over the allowed \(k,b\). A common denominator may have a large numerical value, but only its binary representation is used.
