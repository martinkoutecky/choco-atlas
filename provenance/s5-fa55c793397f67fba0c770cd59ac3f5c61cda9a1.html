The continuous mirror question, as graded

Given finite type and good-kind sets \(T\) and \(G\), rational additive values \(v_t(g)\), type masses \(\mu_t\ge 0\) summing to \(1\), and rational per-capita supplies \(q_g\ge 0\) summing to an integer \(R\), consider integral bundles \(B\in\mathbb{N}^{G}\) with \(\sum_g B_g=R\). Can an exact NC algorithm, measured in the compressed input’s bit length, output rational masses \(x_{t,B}\ge 0\) such that \(\sum_B x_{t,B}=\mu_t\), \(\sum_{t,B}x_{t,B}B_g=q_g\) for every \(g\), and whenever \(x_{t,B}>0\) and \(x_{u,B'}>0\), there is some \(g\) with \(B'_g>0\) for which \(v_t(B)\ge v_t(B'-e_g)\)? In particular, does an efficient algorithm exist when each kind is valued by only a constant number of types and each type values only polylogarithmically many kinds?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m=|G|\geq1\) good kinds, nonnegative binary-rational additive values \(v_t(g)\), and nonnegative binary-rational per-capita supplies \(q_g\) with \(\sum_gq_g=R\in\mathbb Z_{\geq1}\). Let \(L\) be the total input bit length, including the binary encoding of \(R\).
Allowed bundles are \(\mathcal B_R=\{B\in\mathbb Z_{\geq0}^{G}:\sum_gB_g=R\}\), with \(v_t(B)=\sum_gB_gv_t(g)\).
Compute an exact allocation, represented by a list of nonzero binary-rational masses \(x_{t,B}\); omitted entries are zero and bundle coordinates are binary integers. Require \(\sum_Bx_{t,B}=\mu_t\) and \(\sum_{t,B}x_{t,B}B_g=q_g\) for every kind \(g\).
Require supportwise EF1: for every ordered pair \((t,B),(u,B')\) with positive allocated masses, including pairs with \(t=u\), there exists \(g\) with \(B'_g>0\) such that \(v_t(B)\geq v_t(B'-e_g)\), where \(e_g\) is the unit vector for kind \(g\).
For sparsity, set \(S_g=\{t:v_t(g)>0\}\), \(r=\max_g|S_g|\), and let \(\Delta\) be the maximum degree of the intersection graph of the distinct sets \(S_g\); repeated sets give one vertex.
Is computing such an allocation polynomial-time solvable in the compressed input, or NP-hard? Does the answer change when \(r=O(1)\) and \(\Delta\leq(\log(2+m+\tau))^c\) for a fixed constant \(c\), including the case where each type positively values only polylogarithmically many kinds? State running times in \(m,\tau,L,R,r,\Delta\).
For finite agents and individually listed goods, EF1 can be computed at constant hypergraph rank \(r\) in depth \(O(\Delta\log^4 M)\) and work \(O(M^{r+1})\), where \(M\) counts individual goods; hence polylogarithmic \(\Delta\) gives an \(\mathsf{NC}\) algorithm.   • Restricted values to nonnegative rationals, as required by the discrete goods model.
  • Excluded R=0 so that the stipulated removal of one good always has a nonempty comparison bundle.
  • Specified a sparse output list with binary-encoded bundle coordinates and rational masses, rather than requiring enumeration of every possible bundle.
  • Defined m as the number of good kinds and L as the entire compressed input bit length; R remains binary encoded.
  • Defined hypergraph edge degree using intersections between distinct positive-valuation type sets, matching the anchor's grouping of repeated hyperedges.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is polynomial-time solvable in the compressed input, without any sparsity assumption.

More precisely, there is a deterministic algorithm that outputs a feasible supportwise EF1 allocation with at most \(\tau+m\) nonzero entries. A conservative bit-complexity bound is

\(O\!\left(m(\tau+m)\log(2+m+\tau)L^2\right).\)

Its space usage is \(O\!\left(m(\tau+m)L\right)\) bits. These bounds have no multiplicative dependence on \(R\), \(r\), or \(\Delta\); the binary length of \(R\) is already included in \(L\).

The construction compresses fixed-order round robin by batching rounds between depletion events.

1. A finite instance used only for the proof

Write each input mass and supply as a ratio of binary-encoded integers. Let \(N\) be the product of their positive denominators. Thus

\(n_t=N\mu_t\in\mathbb Z_{>0},\qquad H_g=Nq_g\in\mathbb Z_{\geq0}.\)

We have

\(\sum_t n_t=N,\qquad \sum_g H_g=NR.\)

The binary length of \(N\) is \(O(L)\), even though its numerical value may be exponential in \(L\).

Consider a virtual finite instance consisting of \(n_t\) agents of type \(t\) and \(H_g\) individual goods of kind \(g\). Order agents by type, with all agents of each type consecutive. Fix, for each type, a preference ordering of kinds by nonincreasing value, breaking ties by kind index.

Run ordinary round robin in this fixed agent order for exactly \(R\) rounds. Every agent chooses its favorite remaining kind in every round. This is well-defined: there are exactly \(NR\) goods initially, so a good remains before every scheduled pick.

We will compute this allocation without listing the virtual agents or goods.

2. Round robin satisfies the required supportwise EF1

For virtual agent \(a\), let \(g_a^j\) denote its chosen kind in round \(j\), and let \(B_a\) be its final bundle. Fix an ordered pair of agents \(a,b\), and evaluate both bundles using the values of \(a\)'s type \(t\).

If \(a\) precedes \(b\), then the individual good chosen by \(b\) in round \(j\) is still available when \(a\) chooses in that round. Greedy choice therefore gives

\(v_t(g_a^j)\geq v_t(g_b^j)\)

for every round \(j\). Summing gives \(v_t(B_a)\geq v_t(B_b)\). Since values are nonnegative, removing any good from \(B_b\) preserves the required inequality.

If \(a\) follows \(b\), then the individual good chosen by \(b\) in round \(j+1\) is still available when \(a\) chooses in round \(j\). Consequently,

\(v_t(g_a^j)\geq v_t(g_b^{j+1})\qquad(1\leq j<R).\)

Using nonnegativity for \(a\)'s last pick, we obtain

\(v_t(B_a)\geq \sum_{j=1}^{R-1}v_t(g_a^j)\geq \sum_{j=2}^{R}v_t(g_b^j)=v_t(B_b-e_{g_b^1}).\)

For \(R=1\), both sums are empty, and the same argument applies. Finally, if \(a=b\), removing any good weakly decreases its bundle value.

Thus round robin satisfies EF1 for every ordered pair, including pairs of agents with identical types.

After aggregation, every positive-mass type–bundle class contains at least one virtual agent. Choosing representatives proves the required supportwise EF1 condition. For a class compared with itself, the preceding self-comparison applies.

3. Batching complete rounds

At a round boundary, let \(h_g\) be the remaining number of virtual goods of kind \(g\), and let \(s\) be the number of rounds remaining.

For each type \(t\), let \(f_t\) be its favorite kind among those with \(h_g>0\). Define the demand of one unchanged round by

\(d_g=\sum_{t:f_t=g}n_t.\)

In particular, \(\sum_g d_g=N\).

Compute

\(k=\min\left\{s,\ \min_{g:d_g>0}\left\lfloor\frac{h_g}{d_g}\right\rfloor\right\}.\)

When \(k>0\)

Simulate \(k\) complete rounds at once:

  • every agent of type \(t\) receives \(k\) copies of \(f_t\);
  • replace each \(h_g\) by \(h_g-kd_g\);
  • replace \(s\) by \(s-k\).

To justify the simulation, consider batch round \(\ell\), where \(1\leq\ell\leq k\). Before this round, every demanded kind \(g\) has at least

\(h_g-(\ell-1)d_g\geq(k-\ell+1)d_g\geq d_g\)

copies remaining, where \(h_g\) denotes its supply before the batch.

Hence every agent scheduled to choose \(g\) can do so. An agent's designated favorite remains available at its turn, and deleting other kinds cannot make another remaining kind preferable. Induction over the picks and rounds proves that this batch exactly reproduces ordinary round robin.

When \(k=0\)

Simulate one round by processing type blocks consecutively.

If the unprocessed suffix of the current type block has \(z\) agents, and its favorite available kind is \(g\), allocate that kind to the next

\(\min\{z,h_g\}\)

agents. Update the supply and continue.

Each such chunk either finishes a type block or exhausts a kind. Thus this operation handles arbitrarily large type blocks using integer counts.

Moreover, this round necessarily exhausts a kind. Indeed, \(k=0\) implies that some kind has \(0<h_g<d_g\). If no kind were exhausted during the round, availability would remain unchanged, all types would make their initial favorite choices, and that kind would have to supply \(d_g\) copies—a contradiction.

4. Only linearly many phases occur

Kinds are never replenished, so there are at most \(m\) depletion events.

Every explicitly simulated round exhausts a kind. Therefore there are at most \(m\) such rounds.

Consider a positive batch that does not exhaust any kind and does not finish the algorithm. Availability, and hence the vector \(d\), remains unchanged. Because \(k\) was maximal, some demanded kind has residual supply less than \(d_g\). The next iteration therefore has \(k=0\) and explicitly simulates a round.

A positive batch that exhausts a kind can be charged to a depletion event. Every other positive batch can be charged to the following explicitly simulated round, with at most one terminal exception. Consequently, there are at most \(2m+1\) phases in total.

This bound is independent of the numerical value of \(R\).

5. Constructing a small exact output

Number the virtual agents consecutively from \(0\) to \(N-1\). Let the type-block boundaries be

\(a_0=0,\qquad a_t=\sum_{u=1}^{t}n_u.\)

Represent consecutive agents by integer intervals: the interval \([a,b)\) represents agents with indices \(a,a+1,\ldots,b-1\).

During execution, record:

  • for each batch, its multiplicity \(k\) and the chosen kind for each type;
  • for each explicit round, its consecutive allocation chunks and their chosen kinds.

Start with the partition into the \(\tau\) type intervals. Refine this partition at every recorded chunk endpoint.

A batch creates no new boundary inside a type block. In an explicit round, a chunk can end inside a type block only because its chosen kind is exhausted. Each kind is exhausted at most once. There are therefore at most \(m\) additional boundaries, and the final partition has at most

\(K\leq\tau+m\)

nonempty intervals.

Every recorded choice is constant on each final interval. Replaying the recorded phases constructs its common integer bundle \(B\): a batch adds \(k\) copies of its chosen kind, and an explicit round adds one copy.

For an interval \([a,b)\) of type \(t\), assign mass

\(x_{t,B}=\frac{b-a}{N}.\)

Combine entries with identical \((t,B)\).

These masses are positive binary-encoded rationals. If “binary-rational” is intended specifically to mean dyadic rational, the construction also meets that interpretation: dyadic input masses and supplies make \(N\) a power of two.

Exact feasibility

Every virtual agent receives one good in each of \(R\) rounds, so every output bundle belongs to \(\mathcal B_R\).

The intervals partition each type block, giving

\(\sum_Bx_{t,B}=\frac{n_t}{N}=\mu_t.\)

Exactly \(H_g\) virtual goods of kind \(g\) are allocated, giving

\(\sum_{t,B}x_{t,B}B_g=\frac{H_g}{N}=q_g.\)

Section 2 proves supportwise EF1. Thus all requested conditions hold.

6. Bit complexity

All manipulated integers have \(O(L)\) bits:

  • \(N\) has \(O(L)\) bits;
  • supplies and their residuals are at most \(NR\);
  • interval endpoints are at most \(N\);
  • batch multiplicities and bundle coordinates are at most \(R\).

Use sorted preference lists and a pointer for each type. A pointer advances only when a kind is exhausted, so all pointers together advance at most \(\tau m\) times.

Preference sorting takes \(O(\tau m\log(2+m))\) comparisons. Computing demands, batching, and processing explicit rounds takes \(O(m(\tau+m))\) additional arithmetic operations.

For output construction, sort the final boundaries and replay every phase over the final intervals. An explicit round's chunk list and the final partition can be traversed together in increasing agent order. Finally, sort the at most \(K\) entries by type and bundle to combine duplicates. Lexicographic bundle comparison examines at most \(m\) coordinates.

A conservative total bound is therefore

\(O\!\left(m(\tau+m)\log(2+m+\tau)\right)\)

operations on \(O(L)\)-bit integers or rationals. Schoolbook exact arithmetic yields the claimed bit bound

\(O\!\left(m(\tau+m)\log(2+m+\tau)L^2\right).\)

The output itself uses

\(O\!\left((\tau+m)\bigl(L+m\log(R+1)\bigr)\right)\)

bits.

7. Sparsity and the cited parallel result

The answer remains polynomial-time solvable when \(r=O(1)\) and \(\Delta\leq(\log(2+m+\tau))^c\). The same running-time bound applies, with no dependence on \(r\) or \(\Delta\).

For completeness, let \(p\) be the maximum number of kinds positively valued by a type. If \(p\geq1\), then

\(\Delta\leq r(p-1).\)

Indeed, every distinct set intersecting a fixed nonempty set \(S\) contains some type \(t\in S\). There are at most \(p-1\) other distinct sets containing that type. Summing over \(t\in S\) proves the bound. If all values are zero, the intersection graph has just the empty-set vertex and degree zero.

The cited [Theorem 3.4](https://arxiv.org/html/2605.16791v1#S3.SS1) gives the stated parallel guarantee for individually listed goods and bounded rank measured over individual agents. It does not directly provide that guarantee here: our virtual expansion has \(NR\) individual goods, and a kind is positively valued by \(\sum_{t\in S_g}n_t\) virtual agents, which can be exponentially large even when \(r\) is constant.

The construction above establishes polynomial-time solvability of the exact compressed problem. It does not establish a compressed-input \(\mathsf{NC}\) bound.

Step-by-step verification

1. The virtual finite instance is valid

Taking \(N\) to be the product of the positive denominators makes every \(n_t=N\mu_t\) and \(H_g=Nq_g\) an integer. Positive masses ensure \(n_t>0\). The input identities give

\[ \sum_t n_t=N,\qquad \sum_g H_g=NR. \]

The bit length of a product is bounded by the sum of its factors’ bit lengths, so \(N\) has \(O(L)\) bits. Likewise, \(NR\) has \(O(L)\) bits because the encoding of \(R\) is included in \(L\).

The virtual instance is used as a correctness model; the algorithm does not enumerate its agents or goods. Before each scheduled pick, fewer than \(NR\) picks have occurred, so some good remains. Exactly \(R\) complete rounds are consequently well-defined.

2. The EF1 argument checks every ordered pair

For distinct agents \(a,b\), the two possible positions in the fixed order are handled correctly.

  • If \(a\) precedes \(b\), the individual good subsequently selected by \(b\) in round \(j\) remains available at \(a\)’s turn in that round. Greedy choice yields the stated comparison for every \(j\). Summing proves that \(a\) does not envy \(b\). Nonnegative values justify removing any good from \(b\)’s nonempty bundle.
  • If \(a\) follows \(b\), the good selected by \(b\) in round \(j+1\) remains available at \(a\)’s turn in round \(j\). The comparisons therefore hold for \(1\leq j<R\). Discarding \(a\)’s last, nonnegative contribution gives exactly the inequality obtained by removing \(b\)’s first good.

For \(R=1\), the second comparison has empty sums, and the remaining inequality follows from nonnegativity. Self-comparison also holds by nonnegativity.

Aggregation preserves the conclusion: every positive type–bundle mass has a virtual representative, and its bundle and valuation are exactly those appearing in the required supportwise inequality. Different bundles of the same type are covered by the distinct-agent argument. Identical type–bundle classes are covered by self-comparison.

3. Positive batches reproduce the finite process exactly

For every demanded kind, the choice of \(k\) guarantees enough copies for all its designated recipients throughout all \(k\) rounds.

The displayed inequality correctly establishes that, at the start of each batch round, at least one complete round’s demand remains. During that round, earlier designated picks cannot consume more than the corresponding portion of this demand.

Each type’s designated favorite therefore remains available at its turn. Removing other kinds cannot improve them relative to that favorite under the fixed preference ordering. This also handles tied and zero values because the tie-breaking rule is fixed.

Thus the batch allocates exactly the goods that ordinary round robin would allocate.

4. Explicit rounds and the phase bound are correct

Within a type block, all unprocessed agents have the same preference ordering. They therefore select the current favorite until either the block finishes or that kind is exhausted. The chunk size \(\min\{z,h_g\}\) correctly implements this behavior.

When \(k=0\), some demanded kind satisfies \(0<h_g<d_g\). If no kind were exhausted, availability would stay unchanged throughout the round, forcing the original demand \(d_g\) for this undersupplied kind. This contradiction proves that every explicit round exhausts a kind.

The phase count is also valid. Let:

  • \(E\) count explicit rounds;
  • \(D\) count positive batches that exhaust a kind;
  • \(U\) count positive batches that neither exhaust a kind nor terminate execution.

Distinct phases counted by \(E+D\) exhaust distinct kinds, so \(E+D\leq m\). Each phase counted by \(U\) is immediately followed by an explicit round, giving \(U\leq E\). There is at most one terminal positive batch. Consequently,

\[ E+D+U+1\leq m+E+1\leq 2m+1. \]

The bound has no dependence on the numerical value of \(R\).

5. The small output representation is justified

Batches allocate uniformly within each type block and create no internal boundaries.

During an explicit round, a chunk endpoint strictly inside a type block can arise only from exhausting a kind. Since a kind is exhausted at most once, there are at most \(m\) such endpoints over the entire execution.

Refining the initial \(\tau\) type intervals therefore produces at most \(\tau+m\) nonempty intervals. Every recorded allocation choice is constant on each resulting interval, so replaying the phases gives its exact common bundle.

The mass \((b-a)/N\) is positive and has a binary rational encoding of \(O(L)\) bits. Combining identical entries cannot increase support size.

The discussion of dyadic inputs is correct: a product of dyadic denominators is a power of two, so the output masses remain dyadic under that interpretation.

6. Exact feasibility follows from the simulation

Every virtual agent receives exactly \(R\) goods, so every output bundle lies in \(\mathcal B_R\).

The intervals partition each type block, proving the required type-mass equations. The simulation allocates all \(H_g\) copies of every kind, proving the supply equations after division by \(N\).

These are exact integer and rational identities; no approximation or limiting argument is used.

7. The running-time, space, and output bounds are supported

All integer quantities used by the algorithm have \(O(L)\) bits. Exact comparisons of input rational values also require only \(O(L)\)-bit intermediate products.

The operation counts are consistent:

  • Sorting preferences uses \(O(\tau m\log(2+m))\) comparisons.
  • Preference pointers advance at most \(\tau m\) times altogether.
  • Computing demands and updating supplies across \(O(m)\) phases costs \(O(m(\tau+m))\) operations.
  • Explicit rounds contain \(O(m\tau+m)\) chunks altogether: block completions contribute at most \(\tau\) per explicit round, and exhaustion chunks contribute at most \(m\) globally.
  • Replaying phases over at most \(\tau+m\) intervals costs \(O(m(\tau+m))\) operations.
  • Sorting output entries uses at most \(m\) coordinate comparisons per bundle comparison.

These support the claimed conservative bit bound

\[ O\!\left(m(\tau+m)\log(2+m+\tau)L^2\right). \]

The stored preference lists, phase records, intervals, and bundles fit within the claimed \(O(m(\tau+m)L)\) bits. The output-size bound correctly accounts for rational masses and \(m\) binary bundle coordinates per entry.

8. Sparsity and the external theorem are treated appropriately

The inequality \(\Delta\leq r(p-1)\) is valid. For each type in a fixed nonempty set \(S\), at most \(p-1\) other distinct support sets contain that type. Summing may overcount neighboring sets, which is harmless for an upper bound. Empty sets have no neighbors, and the all-zero case is handled.
