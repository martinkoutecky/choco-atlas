The continuous mirror question, as graded

Given \(m\) items and a supported ranking distribution \(\mu\), with \(\mu_t=n_t/r\) for integer counts \(n_t\) summing to \(r\), promised to be the empirical histogram of \(r\) independent Mallows draws with parameter \(\beta\), compute a permutation \(\sigma\) minimizing \(F_\mu(\sigma)=\sum_t\mu_t d_K(t,\sigma)\). Can this be done directly from the support and counts, with the high-probability guarantee and running-time bound of Theorem 7, while accounting for support size and bit length?

Packaged proof task (what the prover saw — nothing else)

There are \(m\ge 2\) items; types are strict complete rankings. A society is given by its support: the list of its \(\tau\) distinct types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible rankings.
The input also gives a binary integer \(r\ge 1\) and positive integer counts \(n_t\), with \(\sum_t n_t=r\) and \(\mu_t=n_t/r\). Let \(L\) be the total input bit length. Define \(F_\mu(\sigma)=\sum_t\mu_t d_K(t,\sigma)\), where \(d_K\) is Kendall tau distance; any minimizing permutation is acceptable.
For the sampling guarantee, fix \(\beta>0\) and \(\alpha>0\). An unknown common center \(\pi\) generates \(r\) independent rankings with probability \(\Pr[t\mid\pi]=e^{-\beta d_K(t,\pi)}/\sum_{u\in S_m}e^{-\beta d_K(u,\pi)}\); the input is their histogram. Failure probability is measured jointly over these draws and algorithmic randomness, uniformly over \(\pi\). State running times in \(m,\tau,L,r,\beta,\alpha\).

Is exact minimization of \(F_\mu\) from the supported histogram in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?
Separately, can a minimizer be computed directly from the histogram with failure probability below \(m^{-\alpha}\) and running time \(\operatorname{poly}(\tau,L)\,m^{1+O(\alpha/(\beta r))}2^{O(\alpha/\beta+1/\beta^2)}\log^2 m\)?

For explicit independent Mallows samples, randomized exact reconstruction has the displayed dependence on \(m,r,\beta,\alpha\) and the stated failure guarantee. [Braverman–Mossel](https://arxiv.org/html/0910.1191v1)
Worst-case Kemeny aggregation is already NP-hard for four complete rankings. [Dwork–Kumar–Naor–Sivakumar](https://www.wisdom.weizmann.ac.il/~naor/PAPERS/rank_www10.html) Consequently, the first question is already settled for supported empirical histograms; this is an inference from the verified result, not an open target.

Modeling choices made when packaging the task

  • Rankings are strict and complete; masses sum to one, and all listed counts are positive.
  • The sample size is supplied explicitly in binary: normalized masses alone do not determine it.
  • The unknown Mallows center is common to all draws; the guarantee is uniform over centers and averages over both sampling and algorithmic randomness.
  • Any exact minimizer is acceptable; no tie-breaking requirement is imposed.

Conclusion

Worst-case exact minimization is \(\mathrm{NP}\)-hard, already for \(r=4\) and \(\tau\leq 4\).

Separately, the requested sampling guarantee holds directly from the histogram, with running time
\(\operatorname{poly}(\tau,L)\,m^{1+O(\alpha/(\beta r))}2^{O(\alpha/\beta+1/\beta^2)}\log^2 m\).
The proof uses the explicit-sample reconstruction theorem stipulated in the question and verifies that its algorithm can operate on histogram statistics.

1. Objective and worst-case hardness

Let \(p_t(a)\) denote the position of item \(a\) in ranking \(t\). Define the integer objective
\(D_H(\sigma)=\sum_t n_t d_K(t,\sigma)\).
Since \(r>0\), we have \(D_H(\sigma)=rF_\mu(\sigma)\), so these objectives have exactly the same minimizers.

The known hardness result states that computing a Kemeny optimum for four complete rankings is \(\mathrm{NP}\)-hard. [Dwork–Kumar–Naor–Sivakumar, Appendix B](https://www.wisdom.weizmann.ac.il/~naor/PAPERS/rank_www10.html)

Given such rankings \(s_1,s_2,s_3,s_4\), construct their histogram: for each distinct ranking \(t\), let \(n_t\) be its number of occurrences, set \(r=4\), and set \(\mu_t=n_t/4\). This construction takes polynomial time, produces \(\tau\leq 4\) distinct supported types, and satisfies every input requirement. For every permutation \(\sigma\),
\(\displaystyle F_\mu(\sigma)=\frac14\sum_{i=1}^{4}d_K(s_i,\sigma)\).

Thus a minimizer for the constructed histogram is a Kemeny optimum for the original four rankings. This proves the claimed hardness. In particular, a worst-case polynomial-time exact algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

2. Statistics computable without expanding the histogram

For every item \(a\), define its total position
\(\displaystyle P_H(a)=\sum_t n_t p_t(a)\).

For distinct items \(a,b\), define the pairwise vote count
\(\displaystyle Q_H(a,b)=\sum_t n_t\mathbf{1}\{p_t(a)<p_t(b)\}\).

Suppose \(x_1,\ldots,x_r\) is any ordered sample sequence with histogram \(H\). Grouping equal rankings gives the exact identities
\(\displaystyle P_H(a)=\sum_{i=1}^{r}p_{x_i}(a)\)
and
\(\displaystyle Q_H(a,b)=\sum_{i=1}^{r}\mathbf{1}\{p_{x_i}(a)<p_{x_i}(b)\}\).

These identities hold for every sample sequence, without a probabilistic assumption. In particular, sorting items by their average sample positions is equivalent to sorting them by the integers \(P_H(a)\), because their common denominator is \(r\).

The pairwise counts also determine the objective. Each unordered pair contributes one disagreement precisely when the candidate ranking reverses its observed order. Therefore
\(\displaystyle D_H(\sigma)=\sum_{\substack{a,b\\p_\sigma(a)<p_\sigma(b)}}Q_H(b,a)\).

Exactly one orientation of each unordered pair occurs in this sum. Since \(Q_H(a,b)+Q_H(b,a)=r\), it follows that
\(\displaystyle D_H(\sigma)=r\binom m2-\sum_{\substack{a,b\\p_\sigma(a)<p_\sigma(b)}}Q_H(a,b)\).

Consequently, minimizing \(F_\mu\) is equivalent to maximizing the pairwise score in the last sum. All these quantities can be computed using binary integer arithmetic; constructing the list of \(r\) observations is unnecessary.

3. Transferring the reconstruction algorithm

The reconstruction theorem supplied in the question gives an explicit-sample algorithm with operation bound
\(\displaystyle T_0=m^{1+O(\alpha/(\beta r))}2^{O(\alpha/\beta+1/\beta^2)}\log^2m\)
and failure probability below \(m^{-\alpha}\).

The implementation relevant here first sorts average item positions and then applies a dynamic program whose scoring input consists of pairwise vote counts. Thus its dependence on the observations is through these statistics and the sample count \(r\). [Braverman–Mossel, Sections 2–3 and Theorem 7](https://arxiv.org/html/0910.1191v1)

Define the histogram algorithm as follows:

  • Compute \(P_H(a)\) and \(Q_H(a,b)\).
  • Form the initial order by sorting \(P_H(a)\), using a fixed rule for ties.
  • Run the reconstruction algorithm’s subsequent computation with these exact statistics, the supplied \(r\), and the parameters \(\beta,\alpha\).

The identities in Section 2 show that this supplies exactly the statistics that the explicit-sample implementation would obtain. With the same tie rule and algorithmic random bits, its subsequent computation is identical.

For completeness, the maximum-likelihood objective appearing in the reconstruction theorem is exactly the objective required here. Relabeling items shows that the Mallows normalizing constant is independent of its center. Hence, for any candidate center \(\sigma\), the likelihood of an ordered sample sequence is
\(\displaystyle Z_m(\beta)^{-r}\exp\!\left(-\beta\sum_{i=1}^{r}d_K(x_i,\sigma)\right)\).

Because \(\beta>0\), maximizing this likelihood is equivalent to minimizing \(D_H(\sigma)\), and hence \(F_\mu(\sigma)\). The histogram likelihood has the additional factor \(r!/\prod_t n_t!\); that factor is independent of \(\sigma\) and does not change its maximizers.

4. Failure probability, including uniformity over the center

Fix an arbitrary center \(\pi\). Let \(X=(X_1,\ldots,X_r)\) be the independent Mallows draws specified in the question, let \(H(X)\) be their histogram, and let \(U\) denote the reconstruction algorithm’s randomness.

Couple the explicit-sample and histogram implementations by using the same \(U\). Their statistics agree for every realization of \(X\), so their outputs agree. Their empirical objectives also agree. Therefore their failure events agree, giving
\(\displaystyle \Pr_{\pi,U}\!\left[ \text{histogram output}\notin\operatorname*{arg\,min}_{\sigma}F_{\mu_{H(X)}}(\sigma) \right]<m^{-\alpha}. \)

This applies to every \(\pi\), so the guarantee is uniform over the unknown center.

The independence assumption is used for the original \(r\) draws when applying the reconstruction theorem. No independence assumption is imposed on the distinct types in the histogram, and no new observations are sampled from it.

5. Bit complexity and dependence on the binary count

Let \(B\) be an integer bit bound sufficient to store \(rm^2\), so \(B=O(\log r+\log m)\). The statistics satisfy
\(P_H(a)\leq rm\) and \(Q_H(a,b)\leq r\); any total objective score is at most \(r\binom m2\).

After constructing position arrays for the supported rankings, all statistics can be computed in
\(O(\tau m^2B^2)\) bit operations using elementary integer arithmetic. Comparing average positions requires only comparing their integer numerators.

The subsequent score additions and comparisons have \(O(B)\)-bit operands, so a polynomial factor in \(B\) suffices to convert the reconstruction operation bound into a bit-operation bound.

Because the input explicitly contains at least one complete ranking and the binary integer \(r\), both \(m\) and \(B\) are bounded by polynomials in \(L\). Thus the preprocessing and arithmetic overhead are absorbed into \(\operatorname{poly}(\tau,L)\). The total running time is therefore
\(\displaystyle \operatorname{poly}(\tau,L)\, m^{1+O(\alpha/(\beta r))} 2^{O(\alpha/\beta+1/\beta^2)} \log^2m. \)

In particular, histogram processing introduces no factor linear in the possibly exponentially large value of \(r\). This proves the requested sampling result alongside the worst-case hardness result.
