Theorem 1.2 — class: algorithmic

The continuous mirror question, as graded

Given a finite candidate set \(C\), ranking types \(T\subseteq\operatorname{Perm}(C)\), rational masses \(\mu\in\Delta(T)\), and fixed \(\varepsilon>0\), output multiplicities \(z\in\mathbb{Z}_{\ge 0}^{C}\) with \(\sum_{j\in C}z_j=K(\varepsilon)\) such that the uniform lottery \(p_z(j)=z_j/K(\varepsilon)\) has worst-case metric distortion \(\operatorname{dist}_{\mu}(p_z)\le\frac52+\varepsilon\), with the supremum over hidden pseudometrics consistent with an atomless voter space carrying masses \(\mu_t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) strict ranking types on a nonempty candidate set \(C\), each with a positive binary rational mass \(\mu_t\), with \(\sum_t\mu_t=1\). Here \(m=|C|\), \(\tau\) is the support size, not the number of possible rankings, and \(L\) is the total input bit length.
Represent voters by \([0,1]\) with Lebesgue measure, partitioned into measurable sets \(A_t\) of measures \(\mu_t\). An admissible hidden pseudometric \(d\) on the disjoint union \([0,1]\sqcup C\) has measurable, integrable candidate-distance functions and satisfies \(d(v,i)\le d(v,j)\) whenever type \(t\) ranks \(i\) above \(j\), for every \(v\in A_t\). Distance ties are permitted.
Define \(\operatorname{SC}_d(j)=\int_0^1d(v,j)\,dv\) and \(\operatorname{dist}_{\mu}(p)=\sup_d\frac{\sum_{j\in C}p(j)\operatorname{SC}_d(j)}{\min_{i\in C}\operatorname{SC}_d(i)}\). A positive numerator over zero gives infinite distortion; set \(0/0=1\).
Fix \(\varepsilon>0\), put \(\bar\varepsilon=\min\{\varepsilon,1/5\}\), and fix \(K(\varepsilon)=\left\lceil\frac{27\pi}{8\bar\varepsilon^3}\left(1+\sqrt{\bar\varepsilon/3}\right)^2\right\rceil\), independently of the society.
The computational problem is to deterministically output \(z\in\mathbb Z_{\ge0}^{C}\) with \(\sum_jz_j=K(\varepsilon)\) such that \(p_z(j)=z_j/K(\varepsilon)\) satisfies \(\operatorname{dist}_{\mu}(p_z)\le5/2+\varepsilon\); repeated candidates are allowed.

Is this search problem solvable in deterministic polynomial time in \(m,\tau,L\) for every fixed \(\varepsilon>0\), or is it NP-hard for some fixed \(\varepsilon>0\)? State any dependence on \(\varepsilon\) and \(K(\varepsilon)\).

For finite, explicitly listed voters, a deterministic polynomial-time construction achieves the same distortion guarantee and list size for every fixed \(\varepsilon\); its polynomial degree may depend on \(K(\varepsilon)\).
That result does not state a computational guarantee for the atomless model with binary rational masses.

  • The atomless voter space is represented by the unit interval with Lebesgue measure and a measurable partition realizing the type masses.

1. Exact compression of the hidden pseudometrics

Write \(T=\{1,\ldots,\tau\}\). Introduce nonnegative variables \(x_{tj}\), representing the average distance from type \(t\) to candidate \(j\), and symmetric nonnegative variables \(D_{ij}\), with \(D_{ii}=0\), representing candidate distances.

Let \(\mathcal H\) be the cone defined by the following inequalities:

  • \(D_{ij}\le D_{ik}+D_{kj}\) for all candidates \(i,j,k\).
  • \(x_{ti}\le x_{tj}\) whenever type \(t\) ranks \(i\) above \(j\).
  • \(x_{ti}-x_{tj}\le D_{ij}\) and \(x_{tj}-x_{ti}\le D_{ij}\).
  • \(D_{ij}\le x_{ti}+x_{tj}\).

Define \(S_j(x)=\sum_{t\in T}\mu_t x_{tj}\).

We prove that the achievable social-cost vectors are exactly
\(\{(S_j(x))_{j\in C}:(x,D)\in\mathcal H\}\).

First, given an admissible hidden pseudometric \(d\), set
\(D_{ij}=d(i,j)\) and
\(x_{tj}=\mu_t^{-1}\int_{A_t}d(v,j)\,dv\).
These averages exist because the candidate-distance functions are integrable and \(\mu_t>0\). Ranking consistency gives the ordering inequalities. The triangle inequalities
\(d(v,i)\le d(v,j)+D_{ij}\) and
\(D_{ij}\le d(v,i)+d(v,j)\), after integration over \(A_t\), give the remaining inequalities. Moreover, \(\operatorname{SC}_d(j)=S_j(x)\).

Conversely, take any \((x,D)\in\mathcal H\). Construct a finite undirected weighted graph with vertices \(C\sqcup T\), candidate–candidate edges of lengths \(D_{ij}\), and type–candidate edges of lengths \(x_{tj}\). Its shortest-path distances form a pseudometric.

These distances preserve the specified edge lengths. Indeed, in a path between candidates, every internal type vertex occurs in a segment \(i,t,j\). Replacing that segment by the candidate edge \(i,j\) cannot increase length, because \(D_{ij}\le x_{ti}+x_{tj}\). Candidate triangle inequalities then show that every path from \(i\) to \(j\) has length at least \(D_{ij}\).

Similarly, a path from type \(t\) to candidate \(j\), whose first candidate is \(k\), has length at least \(x_{tk}+D_{kj}\). The inequality \(x_{tj}-x_{tk}\le D_{kj}\) shows that this is at least \(x_{tj}\). Thus type–candidate distances also equal their specified lengths.

Now map each voter in \(A_t\) to the vertex \(t\), and each candidate to itself, and pull back this finite pseudometric. This gives an admissible pseudometric on \([0,1]\sqcup C\). Its candidate-distance functions are measurable, integrable, and constant on each \(A_t\), with social costs \(S_j(x)\).

This proves the exact compression.

2. Exact polynomial-time evaluation of a lottery

For a rational lottery \(p\), put
\(G_p(x)=\sum_{j\in C}p(j)S_j(x)\).
For each benchmark candidate \(i\), consider the linear program
\[ \]
\(U_i(p)=\sup\{G_p(x):(x,D)\in\mathcal H,\ S_i(x)=1\}\).

We claim that
\(\operatorname{dist}_{\mu}(p)=\max_{i\in C}U_i(p)\),
including infinite values.

Each program is feasible: take every \(x_{tj}=1\) and every \(D_{ij}=0\). This point has \(S_i=G_p=1\), so every \(U_i(p)\ge1\).

For any feasible normalized point, its realized pseudometric has minimum social cost at most \(1\). If that minimum is positive, its distortion ratio is at least \(G_p(x)\). If the minimum is zero and the numerator is positive, the ratio is infinite; if both are zero, the prescribed ratio is \(1\), again at least \(G_p(x)=0\). Hence
\(\operatorname{dist}_{\mu}(p)\ge U_i(p)\).

For the reverse inequality, consider any \((x,D)\in\mathcal H\). If all social costs are positive, choose a minimum-cost candidate \(i\) and divide all variables by \(S_i(x)\). Homogeneity makes the scaled point feasible for the \(i\)-th program, whose objective is precisely the distortion ratio.

If \(S_i(x)=0\) for some \(i\) but \(G_p(x)>0\), add \(\lambda(x,D)\) to the feasible point with all \(x_{tj}=1\) and all \(D_{ij}=0\). Because \(\mathcal H\) is a convex cone, the result remains feasible, has benchmark cost \(1\), and has objective \(1+\lambda G_p(x)\). Thus \(U_i(p)=+\infty\), as required.

Finally, if both the minimum cost and numerator vanish, the prescribed ratio \(1\) is bounded by \(\max_iU_i(p)\). This proves the claim.

There are \(O(\tau m+m^2)\) variables and \(O(\tau m^2+m^3)\) constraints per program. Their coefficients are rational and have polynomial encoding length. The standard polynomial-time theorem for rational linear programming therefore computes each exact finite optimum, or detects unboundedness, in polynomial time.

In particular, for \(p(j)=z_j/K\), distortion can be evaluated exactly in time polynomial in \(m,\tau,L,\log K\). No comparison with a potentially irrational \(\varepsilon\) is needed.

3. Transferring existence from finite voters

Write the rational masses as \(\mu_t=a_t/b_t\), and let \(Q\) be a common multiple of the denominators. Form, conceptually, a finite electorate with \(n_t=Q\mu_t\) voters of type \(t\). Each \(n_t\) is a positive integer and \(\sum_tn_t=Q\).

The compression proof applies equally to this finite electorate: replace the integrals by averages over voters of each type. Conversely, the graph construction realizes every point of \(\mathcal H\) by assigning all finite voters of a type to its type vertex. Consequently, normalized finite social costs have exactly the same achievable vectors as the atomless social costs.

It follows that, for every lottery \(p\), finite and atomless distortion are equal.

Apply the finite-voter result supplied in the question to this conceptual electorate. It yields some count vector \(z\) of total size \(K(\varepsilon)\) whose finite distortion is at most \(5/2+\varepsilon\). The equality just proved gives the same atomless guarantee.

This is an existence argument only. Although \(Q\) can be exponentially large in \(L\), the algorithm below never constructs those \(Q\) voters.

4. Deterministic construction and parameter dependence

Set \(K=K(\varepsilon)\). Enumerate all nonnegative integer vectors \(z\) with \(\sum_jz_j=K\). For each, evaluate the distortion of \(p_z\) using the linear programs above, and return a vector of minimum distortion. Exact rational comparisons suffice; unbounded values are treated as \(+\infty\).

There are \(\binom{m+K-1}{K}\le m^K\) vectors: each is the multiplicity vector of at least one ordered sequence of \(K\) candidates. Section 3 guarantees that at least one enumerated vector satisfies the target bound, so the minimum does too.

Thus the running time is
\(\binom{m+K-1}{K}\operatorname{poly}(m,\tau,L,\log K)\),
and hence at most
\(m^K\operatorname{poly}(m,\tau,L,\log K)\).

For fixed \(\varepsilon>0\), \(K(\varepsilon)\) is a fixed integer, giving deterministic polynomial time in the requested input parameters. Since
\(K(\varepsilon)=\Theta(\bar\varepsilon^{-3})\),
the displayed polynomial degree grows on the order of \(\bar\varepsilon^{-3}\). This argument does not establish a running time of the form \(f(K)\operatorname{poly}(m,\tau,L)\).
