The continuous mirror question, as graded

Given a finite result set \(Q\) represented by assignments on \(V\), and a finite-support distribution \(\mu\) over cuc-acyclic CP-theories \(\Gamma_t\) on \(V\), return for every pair \(\{\alpha,\beta\}\subseteq Q\) the exact masses of types for which \(\alpha\gg_{\Gamma_t}\beta\), for which \(\beta\gg_{\Gamma_t}\alpha\), and for which neither comparison holds. The three masses sum to \(1\); the output selects no collective ranking.

Packaged proof task (what the prover saw — nothing else)

Let \(V\) be a set of \(m\) variables with explicitly listed finite nonempty domains, and let \(Q\) be an explicitly listed set of \(q\) distinct complete assignments to \(V\).
A CP-theory \(\Gamma\) is an explicit finite list of statements \(u_\varphi:x_\varphi>x'_\varphi[W_\varphi]\), where \(u_\varphi\) assigns variables \(U_\varphi\subseteq V\), \(X_\varphi\in V\setminus U_\varphi\), \(x_\varphi\ne x'_\varphi\) are domain values of \(X_\varphi\), and \(W_\varphi\subseteq V\setminus(U_\varphi\cup\{X_\varphi\})\).
For a complete assignment \(a\), define \(\succ^X_a\) as the transitive closure of all pairs \((x_\varphi,x'_\varphi)\) with \(X_\varphi=X\) and \(a\) extending \(u_\varphi\). Local consistency means that every \(\succ^X_a\) is irreflexive.
Define \(J_a(\Gamma)\) on \(V\) to contain edges from each variable in \(U_\varphi\) to every variable in \(\{X_\varphi\}\cup W_\varphi\), for every statement, and edges from \(X_\varphi\) to every variable in \(W_\varphi\) whenever \(a\) extends \(u_\varphi\). A theory is cuc-acyclic if it is locally consistent and every \(J_a(\Gamma)\) is acyclic; inputs are promised to satisfy this condition.
Let \(\triangleright_a\) be the transitive closure of \(J_a(\Gamma)\), \(\Delta(\alpha,\beta)=\{X\in V:\alpha(X)\ne\beta(X)\}\), and \(\Theta'(\alpha,\beta)=\{Y\in\Delta(\alpha,\beta):\nexists Z\in\Delta(\alpha,\beta)\text{ with }Z\triangleright_\alpha Y\}\). Define \(\alpha\gg_\Gamma\beta\) iff \(\alpha\ne\beta\) and \(\alpha(Y)\succ^Y_\alpha\beta(Y)\) for every \(Y\in\Theta'(\alpha,\beta)\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here each type is an explicitly represented cuc-acyclic theory \(\Gamma_t\), and its mass \(p_t\) satisfies \(\sum_t p_t=1\); \(\tau\) is the support size, not the number of possible theories.
For every unordered pair \(\{\alpha,\beta\}\subseteq Q\), return exact binary rational masses \(\sum_{t:\alpha\gg_{\Gamma_t}\beta}p_t\), \(\sum_{t:\beta\gg_{\Gamma_t}\alpha}p_t\), and \(\sum_{t:\neg(\alpha\gg_{\Gamma_t}\beta)\land\neg(\beta\gg_{\Gamma_t}\alpha)}p_t\), labelled by direction. These sum to \(1\); no collective ranking is selected.
Is this exact mass computation solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,q,d,s,L\), where \(d\) is the maximum domain size, \(s\) the maximum number of statements per type, and \(L\) the total input bit length.
For a single discrete cuc-acyclic theory, the defined comparison is polynomial-time computable and is a strict partial order extending the preferences imposed by its statements; this is also established by [Wilson (2011)](https://cora.ucc.ie/bitstreams/a54e0223-1b8c-4e47-80fd-4ddff54c2f46/download). No separate result for the exact distributional output is verified here.

If \(q\leq 1\), the requested output is empty. Henceforth assume \(q\geq 2\), which implies \(m\geq 1\).

Computing comparisons for one type. Fix a listed theory \(\Gamma_t\). Index the variables and their domain values. For each \(a\in Q\), construct:

  • A directed graph \(G^X_{t,a}\) on each domain \(D_X\), containing precisely the pairs \((x_\varphi,x'_\varphi)\) whose statements have \(X_\varphi=X\) and whose conditions are extended by \(a\).
  • The directed graph \(J_a(\Gamma_t)\) from the question.

Compute their transitive closures. Denote the resulting Boolean reachability matrices by \(R^X_{t,a}\) and \(T_{t,a}\), respectively. By construction,

\(R^X_{t,a}[x,x']=1\iff x\succ^X_a x'\),

and

\(T_{t,a}[Z,Y]=1\iff Z\triangleright_a Y\).

For an ordered pair \((\alpha,\beta)\) of distinct elements of \(Q\), first compute \(B=\Delta(\alpha,\beta)\). Then compute

\(H=\{Y\in B:\text{ for every }Z\in B,\ T_{t,\alpha}[Z,Y]=0\}\).

Thus \(H=\Theta'(\alpha,\beta)\), exactly. Return true precisely when

\(R^Y_{t,\alpha}[\alpha(Y),\beta(Y)]=1\quad\text{for every }Y\in H\).

This is exactly the definition of \(\alpha\gg_{\Gamma_t}\beta\). Evaluate the reverse direction separately, using the matrices indexed by \(\beta\).

For completeness, \(H\) is nonempty: \(B\) is nonempty, and the reachability relation of the promised acyclic graph \(J_\alpha(\Gamma_t)\), restricted to \(B\), has a minimal element.

Why the three categories partition the support. We use the supplied single-theory result: for every discrete cuc-acyclic theory, the defined comparison is a strict partial order. This is also Wilson’s Theorem 5, with the graph and comparison defined in Definitions 15–16. Its hypothesis holds for every listed type by the input promise. [Wilson (2011)](https://cora.ucc.ie/bitstreams/a54e0223-1b8c-4e47-80fd-4ddff54c2f46/download)

A transitive, irreflexive relation is asymmetric: if both \(\alpha\gg_{\Gamma_t}\beta\) and \(\beta\gg_{\Gamma_t}\alpha\) held, transitivity would give \(\alpha\gg_{\Gamma_t}\alpha\), contradicting irreflexivity. Therefore each type belongs to exactly one of these categories:

  • \(\alpha\gg_{\Gamma_t}\beta\);
  • \(\beta\gg_{\Gamma_t}\alpha\);
  • neither comparison holds.

Consequently, adding each type’s mass to its category gives precisely the three requested masses, and their sum is \(\sum_t p_t=1\).

Exact arithmetic and output size. Write the explicitly encoded masses as \(p_t=n_t/b_t\), with positive integers represented in binary. This also covers dyadic masses, whose denominators are powers of \(2\). Define

\(D=\prod_{t=1}^{\tau}b_t,\qquad w_t=n_t(D/b_t)\).

Then \(w_t\) is an integer and \(p_t=w_t/D\). Since the total input bit length is \(L\),

\(\log_2 D=\sum_t\log_2 b_t\leq L\).

Thus \(D\) has at most \(L+1\) bits. Moreover, positivity and \(\sum_t p_t=1\) imply

\(\sum_t w_t=D\).

For each unordered pair, initialize three integer accumulators and add \(w_t\) to the category determined above. Every accumulator lies between \(0\) and \(D\), so it also uses at most \(L+1\) bits. Output each accumulator divided by \(D\), together with its direction label. These fractions are exact; they can optionally be reduced.

With schoolbook integer arithmetic, computing \(D\) and all \(w_t\) takes \(O(\tau L^2)\) bit operations. Accumulation takes \(O(\tau q^2L)\) bit operations. Reducing all output fractions, if required, admits the conservative bound \(O(q^2L^3)\): Euclid’s algorithm uses \(O(L)\) divisions on integers of \(O(L)\) bits, and each division costs \(O(L^2)\).

The numerical output has total size \(O(q^2L)\), apart from pair labels of \(O(q^2\log(q+2))\) bits.

Running time. The graph computation can reuse matrices across all pairs.

For each type, construct once the edges contributed unconditionally by all statements. This costs \(O(sm^2)\) graph operations, since one statement contributes at most \(m^2\) such edges.

For each \(a\in Q\):

  • Testing all statement conditions and inserting their active edges costs \(O(sm)\).
  • Computing the closure of \(J_a(\Gamma_t)\) by Boolean Floyd–Warshall costs \(O(m^3)\).
  • Computing all domain closures costs \(O(\sum_X |D_X|^3)\), which is at most \(O(md^3)\).

Matrix initialization and copying fit within these bounds. Once the matrices are available, each ordered comparison takes \(O(m^2)\) operations: compute the difference set, test reachability between its elements, and check the selected local preferences.

Hence the total number of graph and comparison operations is

\(K=O\!\left(\tau\left[sm^2+q(sm+m^3+md^3)+q^2m^2\right]\right)\).

Indexing the explicit input can be performed within \(O(L^2)\) bit operations. On a bit-cost random-access machine, charging \(O(\log(L+2))\) for operations on binary indices, a conservative total bound, including reduced rational output, is

\(O\!\left(L^2+K\log(L+2)+\tau L^2+\tau q^2L+q^2L^3\right)\).

Every parameter is polynomially bounded by the explicitly listed input size, so this is polynomial in \(L\). The algorithm uses the cuc-acyclicity promise; it does not need to verify that property over all complete assignments.

Thus the requested function belongs to \(\mathrm{FP}\). Any NP-hardness claim under polynomial-time reductions that allow recovery of NP decision answers from this output would imply \(\mathrm{P}=\mathrm{NP}\).
