The continuous mirror question, as graded

Given a finite support \(T\) of ranking types, a rational polytope \(\mathcal P\subseteq\Delta(T)\) containing an unknown society \(\mu^\star\), type-specific Borda scores \(a_t(e)\), and a uniform matroid of rank \(k\), can an adaptive algorithm query whether \(\sum_{t\in T}\mu^\star_t a_t(e)\ge\sum_{t\in T}\mu^\star_t a_t(f)\) and return a committee \(B\) with worst-case per-capita regret at most \(\delta\) over the distributions in \(\mathcal P\) consistent with the answers, using polynomially many queries and polynomial-time computation?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\ge1\) candidates, and let \(T\) list \(\tau\ge1\) distinct strict ranking types. A society is given by its support: the types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible rankings. Here the support is known, but its masses are hidden.
The input includes a nonempty rational polytope \(\mathcal P\subseteq\Delta(T)\), given by explicit rational linear inequalities, whose points have positive coordinates; an unknown rational society \(\mu^\star\in\mathcal P\); a uniform matroid of rank \(1\le k\le m\); and a binary rational tolerance \(\delta\ge0\). Let \(L\) be the total bit length of the supplied input, excluding the hidden masses.
Let \(a_t(e)\) be the Borda score of candidate \(e\) in ranking \(t\), shifted upward by one to ensure positive weights. Define additive per-capita committee utility by \(u_\mu(B)=\sum_{e\in B}\sum_{t\in T}\mu_t a_t(e)\), with feasible committees satisfying \(|B|=k\).
An adaptive algorithm may query distinct candidates \(e,f\); the oracle answers yes exactly when \(u_{\mu^\star}(\{e\})\ge u_{\mu^\star}(\{f\})\), including equality. Let \(\mathcal Q\) contain the rational societies in \(\mathcal P\) consistent with every answer. Define \(R(B,\mathcal Q)=\sup_{\mu\in\mathcal Q}\max_{B'\subseteq C,\,|B'|=k}\bigl(u_\mu(B')-u_\mu(B)\bigr)\).

Does this elicitation problem admit an algorithm that, for every hidden society, returns a committee \(B\) with \(R(B,\mathcal Q)\le\delta\), using polynomially many queries and polynomial computation time in \(m,\tau,k,L\), or is it NP-hard?

For finite matroid ground sets, interactive greedy elicitation guarantees final additive regret at most \(\delta\) with polynomially many element comparisons; polynomial computation is stated when independence and the requisite regret computations are polynomial. The same work also treats continuous linear utility parameters, but no separate theorem for this support-encoded Borda formulation was verified. [Benabbou et al. (2021)](https://ojs.aaai.org/index.php/AAAI/article/download/17452/17259)

Modeling choices made when packaging the task

  • Specified strict complete rankings and shifted standard Borda scores upward by one to preserve the anchor's strictly positive weights.
  • Normalized masses to sum to one and required the uncertainty polytope to have positive coordinates so its societies share the stated support.
  • Specified an explicit rational inequality representation of the nonempty polytope and defined input bit length to exclude hidden oracle data.
  • Required an integral committee of exactly the positive matroid rank and a nonnegative binary rational additive regret tolerance.
  • Made comparisons truthful Boolean queries, with equality answering yes and a no answer imposing a strict inequality.
  • Used a supremum over consistent rational societies because strict answers can make the consistency set nonclosed.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The elicitation problem is polynomial-time solvable. At most \(m(m-1)/2\) comparisons suffice to return a committee with regret exactly \(0\), for every hidden society and every tolerance \(\delta\ge 0\).

1. Common ordering of candidate utilities

Write \(w_\mu(e)=\sum_{t\in T}\mu_t a_t(e)\), so that \(u_\mu(B)=\sum_{e\in B}w_\mu(e)\).

A yes answer to the query \((e,f)\) imposes \(w_\mu(e)\ge w_\mu(f)\) on every consistent society. A no answer imposes \(w_\mu(e)<w_\mu(f)\).

We construct an ordering \(c_1,\ldots,c_m\) such that every society consistent with the final transcript satisfies
\(w_\mu(c_1)\ge\cdots\ge w_\mu(c_m)\).
This common ordering will certify an optimal committee throughout the final uncertainty set.

The additive utility and uniform-matroid setting also appear in [Benabbou et al. (2021)](https://ojs.aaai.org/index.php/AAAI/article/download/17452/17259). The argument below is self-contained and requires no regret computations.

2. Algorithm and ordering invariant

Process the candidates in any fixed order. Maintain a list of the candidates already processed.

To insert a new candidate \(x\) into the current list \(c_1,\ldots,c_r\), query \((x,c_i)\) successively for \(i=1,\ldots,r\). At the first yes answer, insert \(x\) immediately before \(c_i\) and stop scanning. If every answer is no, append \(x\).

After processing all candidates, return \(B=\{c_1,\ldots,c_k\}\).

We prove the invariant that the current list is weakly decreasing in utility for every rational society consistent with the current transcript.

The invariant holds for lists of size zero or one. Suppose it holds before inserting \(x\). New answers restrict the uncertainty set, so all previously established inequalities remain valid.

If the first yes occurs at position \(i\), then every currently consistent society satisfies:

  • \(w_\mu(c_j)>w_\mu(x)\) for every \(j<i\), because those queries received no answers.
  • \(w_\mu(x)\ge w_\mu(c_i)\), because the query at position \(i\) received a yes answer.
  • \(w_\mu(c_i)\ge w_\mu(c_j)\) for every \(j>i\), by the previous invariant.

Transitivity therefore gives the required weak ordering after insertion. If every answer is no, then \(w_\mu(c_j)>w_\mu(x)\) for all existing candidates, so appending \(x\) also preserves the invariant.

Thus the final ordering holds simultaneously for every \(\mu\in\mathcal Q\). Equality causes no difficulty: a yes answer supplies exactly the weak inequality needed.

3. Exact regret certificate

The actual rational society \(\mu^\star\) satisfies every answer it supplies and belongs to \(\mathcal P\). Hence \(\mu^\star\in\mathcal Q\), so \(\mathcal Q\) is nonempty.

Fix any \(\mu\in\mathcal Q\) and any competing committee \(B'\) of size \(k\). Set \(A=B\setminus B'\) and \(D=B'\setminus B\). Since \(|B|=|B'|\), we have \(|A|=|D|\).

Every candidate in \(A\) appears among the first \(k\) positions, while every candidate in \(D\) appears after them. The ordering invariant gives \(w_\mu(a)\ge w_\mu(d)\) for every \(a\in A\) and \(d\in D\).

Choose any bijection \(\phi:D\to A\). Cancellation of the candidates common to both committees yields
\(u_\mu(B')-u_\mu(B)=\sum_{d\in D}\bigl(w_\mu(d)-w_\mu(\phi(d))\bigr)\le 0\).
If \(D\) is empty, the same conclusion follows from the empty sum.

Taking \(B'=B\) gives difference zero. Consequently,
\(\max_{B'\subseteq C,\ |B'|=k}\bigl(u_\mu(B')-u_\mu(B)\bigr)=0\)
for every \(\mu\in\mathcal Q\). Taking the supremum over this nonempty set proves
\(R(B,\mathcal Q)=0\le\delta\).

This establishes robust optimality throughout the final uncertainty set, not merely optimality at the actual hidden society.

4. Complexity and conclusion

Inserting the \((r+1)\)-st candidate uses at most \(r\) queries. The total is therefore at most
\(\sum_{r=0}^{m-1}r=m(m-1)/2\).
Every query involves distinct candidates, and no unordered candidate pair is queried more than once.

List scanning and insertion take \(O(m^2)\) elementary operations. Candidate identifiers have \(O(\log(m+1))\) bits, so the ordinary computation, including input reading, is polynomial in \(m,\tau,k,L\). The algorithm does not evaluate hidden rational utilities, optimize over \(\mathcal P\), or compute regret numerically; the ordering invariant certifies zero regret directly.

Thus the stated interactive problem admits the requested polynomial-time, polynomial-query algorithm.
