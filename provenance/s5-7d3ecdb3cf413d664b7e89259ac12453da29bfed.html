The continuous mirror question, as graded

Given candidates \(C\), a committee size \(k\), a finite support \(T\subseteq 2^C\) of approval types with rational masses \(\mu_S\ge 0\) summing to \(1\), a required retained fraction \(q\), and a score threshold \(\theta\), does there exist an integral committee \(X\subseteq C\), \(|X|=k\), and retained masses \(0\le y_S\le\mu_S\) such that \(\sum_{S\in T}y_S\ge q\) and \(\sum_{S\in T}y_S s(X,S)\le\theta\)? Consider \(s(X,S)=|X\triangle S|\), \(s(X,S)=|X\setminus S|\), and \(s(X,S)=|X\setminus S|-|X\cap S|\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(|C|=m\ge1\). A society is given by its support: an explicit list \(T\subseteq2^C\) of \(\tau\) distinct approval types with positive binary rational masses \(\mu_S\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible approval types; empty approval sets are allowed.
The remaining inputs are an integer \(1\le k\le m\), a binary rational retained fraction \(0<q\le1\), and a binary rational threshold \(\theta\). Require \(\theta\ge0\) for minisum and disapproval; allow \(\theta\in\mathbb Q\) for net disapproval. Let \(L\) denote the total input bit length.
Consider separately minisum \(s(X,S)=|X\triangle S|\), disapproval \(s(X,S)=|X\setminus S|\), and net disapproval \(s(X,S)=|X\setminus S|-|X\cap S|\).
For each score, the decision problem asks whether an integral committee \(X\subseteq C\), \(|X|=k\), and real retained masses \(0\le y_S\le\mu_S\) exist with \(\sum_{S\in T}y_S\ge q\) and \(\sum_{S\in T}y_Ss(X,S)\le\theta\). The score is a total over retained mass, without renormalization.

For each of these three scores, is this decision problem solvable in polynomial time in \(m,\tau,L\), with \(k,q,\theta\) part of the input, or is it NP-hard?

The discrete problem, retaining at least a prescribed number of whole voters, is NP-complete for all three scores even when every ballot approves exactly \(3\) candidates and every candidate receives exactly \(3\) approvals ([Dey, Misra, and Narahari](https://arxiv.org/pdf/1511.04190)). A later result establishes NP-completeness even when every ballot approves exactly \(2\) candidates ([Dey, Misra, and Narahari](https://www.ifaamas.org/Proceedings/aamas2017/pdfs/p42.pdf)).
No result settling this exact formulation with divisible retained masses was located.

Modeling choices made when packaging the task

  • Specified a nonempty candidate set, a positive committee size at most the number of candidates, and a positive retained fraction at most one.
  • Removed zero-mass entries so that the supplied list is exactly the positive support; allowed empty approval sets, as in the discrete approval domain.
  • Specified binary rational input thresholds, nonnegative for the two nonnegative scores and signed for net disapproval, whose defining formula can be negative.
  • Specified real retained masses and defined L as the total input bit length.

Result

All three problems are \(\mathrm{NP}\)-complete. Hardness holds even when every approval type contains exactly two candidates and all support types have equal masses.

The proof below directly handles divisible retention; it does not assume that retained masses are integral.

A common reduction from Clique

We use the standard \(\mathrm{NP}\)-completeness of Clique: given a simple undirected graph \(G=(V,E)\) and an integer \(k\), decide whether \(G\) contains a clique of size \(k\). See [Karp’s original theorem](https://doi.org/10.1007/978-1-4684-2001-2_9).

We may restrict to \(5\le k\le |V|\). Indeed, from an instance with target \(r\ge1\), add five mutually adjacent vertices adjacent to every original vertex, and set the new target to \(r+5\). An original clique of size \(r\) extends to the new target. Conversely, a clique of size \(r+5\) contains at least \(r\) original vertices, which form an original clique.

Write \(e=|E|\) and \(h=\binom{k}{2}\). If \(e<h\), the Clique instance is necessarily negative. In this case output a fixed negative instance: five candidates, the single approval type \(\{c_1,c_2\}\) of mass \(1\), committee size \(5\), retained fraction \(1\), and threshold \(0\). The unique committee has minisum and disapproval score \(3\), and net disapproval score \(1\), so this instance is negative for every score.

Henceforth assume \(e\ge h\). Construct the society as follows:

  • The candidate set is \(C=V\), with the same committee size \(k\).
  • For every edge \(\{u,v\}\in E\), include the approval type \(S=\{u,v\}\).
  • Every type has mass \(\mu_S=1/e\).
  • Set \(q=h/e\).

Because the graph is simple, these are \(e\) distinct support types. Thus \(\tau=e\), all masses are positive, their sum is \(1\), and \(0<q\le1\).

For a committee \(X\) of size \(k\), put \(r_S=|X\cap S|\). Since each type has size \(2\), its score and minimum possible score are:

| Score | Score on \(S\) | Minimum \(b\) |
|---|---|---|
| Minisum | \(k+2-2r_S\) | \(k-2\) |
| Disapproval | \(k-r_S\) | \(k-2\) |
| Net disapproval | \(k-2r_S\) | \(k-4\) |

In every row, \(s(X,S)\ge b\), with equality precisely when \(S\subseteq X\). Our restriction \(k\ge5\) ensures \(b>0\), including for net disapproval.

For the score under consideration, set \(\theta=bq\). This threshold is positive and therefore satisfies all the required threshold restrictions.

Correctness of the reduction

A clique gives feasible retained masses

Suppose \(X\subseteq V\) is a clique of size \(k\). Exactly \(h\) edge types lie entirely inside \(X\). Retain their full masses and retain nothing from the other types.

The retained mass is \(h/e=q\). Each retained type has score \(b\), so the total score is \(bq=\theta\). Thus the constructed instance is affirmative.

Feasible retained masses force a clique

Conversely, suppose a committee \(X\) and retained masses \(y_S\) satisfy the constructed instance. Let \(R=\sum_{S\in T}y_S\), so \(R\ge q\).

Using the lower bound \(s(X,S)\ge b\), we obtain

\[ 0\ge \sum_{S\in T}y_Ss(X,S)-bq =b(R-q)+\sum_{S\in T}y_S\bigl(s(X,S)-b\bigr)\ge0. \]

Both terms on the right are nonnegative. Since \(b>0\), equality forces \(R=q\). Moreover, every summand \(y_S(s(X,S)-b)\) is nonnegative, so \(y_S>0\) is possible only when \(s(X,S)=b\), equivalently \(S\subseteq X\).

Let \(e_X\) be the number of graph edges with both endpoints in \(X\). Only these types can have positive retained mass, and each has capacity \(1/e\). Consequently,

\[ \frac{h}{e}=q=R\le\frac{e_X}{e}, \]

and hence \(e_X\ge h\). A simple graph on the \(k\) vertices of \(X\) has at most \(\binom{k}{2}=h\) edges. Therefore \(e_X=h\), meaning every pair of vertices in \(X\) is adjacent. Thus \(X\) is a clique.

This argument explicitly permits arbitrary real retained masses. Divisibility cannot overcome the capacity bound on the edge types contained in \(X\).

Polynomial encoding size

The construction has \(m=|V|\) candidates and \(\tau=e\) explicitly listed types. The rational values \(\mu_S=1/e\), \(q=h/e\), and \(\theta=bh/e\) have binary encodings of polynomial length. Computing them and listing the types takes polynomial time.

The equivalence above therefore proves \(\mathrm{NP}\)-hardness separately for all three scores.

Membership in \(\mathrm{NP}\)

For arbitrary input masses, a certificate consists only of the committee \(X\). Its size and membership in \(C\) are directly checkable.

Once \(X\) is fixed, compute each integer coefficient \(a_S=s(X,S)\). Feasibility of retained masses is then the rational linear-programming feasibility problem

\[ 0\le y_S\le\mu_S,\qquad \sum_{S\in T}y_S\ge q,\qquad \sum_{S\in T}a_Sy_S\le\theta. \]

This system has \(\tau\) variables and polynomial encoding length: all score coefficients have magnitude at most \(m\), and the remaining coefficients are input rationals. Polynomial-time rational linear programming therefore verifies feasibility in time polynomial in \(m,\tau,L\). This applies also to negative net disapproval coefficients.

Thus each problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness. In particular, a polynomial-time algorithm for any of the three would imply \(\mathrm{P}=\mathrm{NP}\).

Verification report

1. Source problem and restriction

The prover invokes the standard NP-completeness of Clique and states its decision question precisely: whether a simple undirected graph contains a clique of a specified size.

The padding argument is correct. Adding five mutually adjacent universal vertices allows any original clique of size \(r\) to extend to size \(r+5\). Conversely, any clique of size \(r+5\) contains at least \(r\) original vertices, which remain mutually adjacent.

Minor issue: The assertion that this establishes the restriction \(5\le k\le |V|\) implicitly assumes that the original target satisfies \(r\le |V_{\mathrm{original}}|\). Only \(r\ge1\) is stated. If \(r>|V_{\mathrm{original}}|\), padding preserves the violation of the upper bound.

Minimum clarification: Explicitly take the source Clique instances to satisfy \(1\le r\le |V_{\mathrm{original}}|\), or state how targets exceeding the original vertex count are handled. This is a routine source-domain clarification and does not undermine the hardness argument.

The retained fraction and mass both equal \(1\), so the retention constraint forces full retention. Each total score therefore exceeds the threshold \(0\). The instance is negative for all three scores.

Each type approves exactly two candidates, and all types have equal masses. The claimed restrictions are satisfied, including by the fixed negative instance.

| Score | Value | Lower bound \(b\) |
|---|---|---|
| Minisum | \(k+2-2r_S\) | \(k-2\) |
| Disapproval | \(k-r_S\) | \(k-2\) |

5. Forward implication

A clique of size \(k\) contains exactly \(h\) graph edges. Retaining the full mass of those edge types and zero mass elsewhere respects every capacity constraint.

The retained mass is \(h/e=q\), and its total score is \(bq=\theta\). This verifies feasibility using the unnormalized score required by the task.

No integrality assumption about retained masses is used.

6. Reverse implication

The key identity is correct:

\( \sum_S y_Ss(X,S)-bq=b(R-q)+\sum_S y_S(s(X,S)-b). \)

Feasibility makes its left side nonpositive. Both terms on the right are nonnegative because \(R\ge q\), \(b>0\), \(y_S\ge0\), and \(s(X,S)\ge b\). Therefore both terms vanish.

This legitimately forces \(R=q\). It also forces every positive retained mass to lie on a type attaining score \(b\), hence on an edge entirely contained in \(X\).

If \(e_X\) counts such edges, the individual capacities give \(R\le e_X/e\). Together with \(R=h/e\), this yields \(e_X\ge h\). Simplicity of the graph gives \(e_X\le\binom{k}{2}=h\). Thus every pair in \(X\) is adjacent.

This is a complete argument for arbitrary real retained masses. Fractional retention cannot bypass the capacity inequality.

7. Polynomial encoding and boundary cases

The number of types is polynomial in the graph size. The numerators and denominators of \(1/e\), \(h/e\), and \(bh/e\) have polynomial binary length. Their computation and the explicit listing of edge types take polynomial time.

The case \(q=1\) causes no failure: the same equality and capacity arguments apply. Graphs with no edges fall into the fixed-negative branch, so division by zero never occurs.

Empty approval types and smaller committee sizes need not occur in a hardness reduction. Their allowance in the general problem is covered by the membership argument.

8. Membership in NP

A committee is a polynomial-size certificate. Once it is fixed, the remaining constraints form exactly the rational linear feasibility system displayed by the prover.

All three score coefficients have absolute value at most \(m\), including minisum because \(X\triangle S\subseteq C\). The system has \(\tau\) variables, polynomially many constraints, and polynomial encoding length.

The invoked theorem—rational linear-programming feasibility is decidable in polynomial time in its encoding length—applies to this system. Negative net-disapproval coefficients do not invalidate its hypotheses.

A deterministic polynomial-time verifier may run that feasibility algorithm. It therefore does not need retained masses as part of its certificate.

The output settles the intended continuous problems: each is NP-complete, even with distinct approval types of size two and equal masses. Apart from explicitly specifying the source target range, the proof requires no repair.
