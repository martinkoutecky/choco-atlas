The continuous mirror question, as graded

Given finite resident types \(T\) and room classes \(J\), with rational population masses \(\mu_t\) and supply masses \(\sigma_j\) summing to one, rational values \(v_{tj}\), and a rational mass assignment \(y_{tj}\) whose row sums are \(\mu_t\) and column sums are \(\sigma_j\), suppose an initial class compensation vector \(p^0\) satisfies \(\sum_j \sigma_j p^0_j=\alpha\) and envy-freeness: whenever \(y_{tj}>0\), \(v_{tj}+p^0_j\ge v_{t\ell}+p^0_\ell\) for every \(\ell\). For an occupied root state \((k,j_0)\), find rational compensations \(p_j\) preserving that budget balance and envy-freeness such that every occupied state reaches \((k,j_0)\) in the directed graph on states with \(y_{tj}>0\), with an edge \((t,j)\to(s,\ell)\) when \(v_{tj}+p_j=v_{t\ell}+p_\ell\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) resident types with positive binary rational masses \(\mu_t\); \(\tau\) is the support size, not the number of possible types. There are \(m\geq 1\) room classes \(J\) with positive binary rational supply masses \(\sigma_j\), where \(\sum_t\mu_t=\sum_j\sigma_j=1\).
Values \(v_{tj}\in\mathbb Q\) may have either sign; utility for class \(j\) with compensation \(p_j\) is \(v_{tj}+p_j\). Compensations may have either sign and have no individual bounds. The budget \(\alpha\in\mathbb Q_{\geq 0}\) is given.
The input includes a fixed assignment \(y\in\mathbb Q_{\geq 0}^{T\times J}\) satisfying \(\sum_j y_{tj}=\mu_t\) and \(\sum_t y_{tj}=\sigma_j\), and an initial vector \(p^0\in\mathbb Q^J\). A vector \(p\) is admissible if \(\sum_j\sigma_jp_j=\alpha\) and, whenever \(y_{tj}>0\), \(v_{tj}+p_j\geq v_{t\ell}+p_\ell\) for every \(\ell\in J\); \(p^0\) is promised admissible. Ties are allowed.
Let \(S=\{(t,j):y_{tj}>0\}\), with a specified root \((k,j_0)\in S\). At compensation vector \(p\), the directed graph on \(S\) has an edge \((t,j)\to(s,\ell)\) exactly when \(v_{tj}+p_j=v_{t\ell}+p_\ell\). Paths of length zero are allowed.
The problem is to find an admissible rational vector \(p\) for which every state reaches \((k,j_0)\), or determine that none exists, keeping \(y\) fixed. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this compensation-finding problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For a discrete society with \(n\) agents and \(n\) individual objects, an algorithm keeps a given envy-free assignment fixed and finds budget-balanced compensations making every agent reach a specified agent by indifference chains in at most \(n\) iterations. [Andersson–Ehlers](https://lucris.lub.lu.se/ws/portalfiles/portal/173630778/WP21_2.pdf)

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is polynomial-time solvable. Under the promise that \(p^0\) is admissible, a solution always exists. In fact, the required compensation vector is unique.

The construction below proves this directly for the mass formulation. The cited [Andersson–Ehlers paper](https://lucris.lub.lu.se/ws/portalfiles/portal/173630778/WP21_2.pdf) supplies the related fixed-assignment algorithm for discrete societies.

1. Constructing a weighted graph. For each room class \(j\), let \(T_j=\{t:y_{tj}>0\}\). This set is nonempty because \(\sum_t y_{tj}=\sigma_j>0\).

Define a directed graph on the room classes, with an arc from every \(j\) to every \(\ell\), having weight

\(a_{j\ell}=\min_{t\in T_j}\bigl(v_{tj}+p^0_j-v_{t\ell}-p^0_\ell\bigr).\)

Every quantity inside this minimum is nonnegative by admissibility of \(p^0\). Consequently, \(a_{j\ell}\geq 0\), and \(a_{jj}=0\).

For a vector \(q=p^0+\delta\), its envy inequalities are equivalent to

\(\delta_\ell-\delta_j\leq a_{j\ell}\quad\text{for every }j,\ell.\)

Indeed, for each \(t\in T_j\), the corresponding inequality is

\(\delta_\ell-\delta_j\leq v_{tj}+p^0_j-v_{t\ell}-p^0_\ell.\)

Requiring all these inequalities is exactly equivalent to requiring their minimum.

Let \(D_j\) be the shortest-path distance from \(j\) to the root class \(j_0\), using the weights \(a_{j\ell}\). These distances are finite because the graph is complete. Nonnegative weights imply that a shortest walk can have its cycles removed without increasing its weight. Thus a shortest path exists with at most \(m-1\) arcs, and \(D_{j_0}=0\).

The distances satisfy

\(D_j\leq a_{j\ell}+D_\ell\quad\text{for every }j,\ell.\)

This follows by taking the arc from \(j\) to \(\ell\) followed by a shortest path from \(\ell\) to \(j_0\).

2. The compensation vector and its admissibility. Set

\(\overline D=\sum_{j\in J}\sigma_jD_j,\qquad p_j=p^0_j-D_j+\overline D.\)

These quantities are rational. Since \(\sum_j\sigma_j=1\) and \(p^0\) satisfies the budget,

\(\sum_j\sigma_jp_j=\alpha-\sum_j\sigma_jD_j+\overline D=\alpha.\)

For every supported pair \((t,j)\) and every class \(\ell\), the new utility gap is

\(v_{tj}+p_j-v_{t\ell}-p_\ell =\bigl(v_{tj}+p^0_j-v_{t\ell}-p^0_\ell\bigr)-D_j+D_\ell \geq a_{j\ell}-D_j+D_\ell \geq 0.\)

The first inequality uses the definition of \(a_{j\ell}\); the second uses the shortest-path inequality. Hence \(p\) is admissible and keeps \(y\) fixed.

3. Every state reaches the specified root. Consider a shortest class path from \(j\) to \(j_0\). Every arc \(h\to\ell\) on this path satisfies

\(D_h=a_{h\ell}+D_\ell.\)

To justify this, every suffix of a shortest path is itself shortest: replacing a suffix by a strictly shorter path would produce a walk of smaller total weight, contradicting shortestness.

Choose a type \(t\in T_h\) attaining the minimum defining \(a_{h\ell}\). At the constructed compensation vector,

\(v_{th}+p_h-v_{t\ell}-p_\ell=a_{h\ell}-D_h+D_\ell=0.\)

Therefore the state \((t,h)\) has an edge to every supported state whose room class is \(\ell\).

Also, any two supported states in the same room class have edges between them. Specifically, from \((s,h)\) to \((t,h)\), the required equality is the identity

\(v_{sh}+p_h=v_{sh}+p_h.\)

Starting from any state in class \(j\), we may therefore switch to a witnessing type for the first shortest-path arc, traverse that arc, and repeat. Upon reaching class \(j_0\), we take an edge to \((k,j_0)\) if necessary. Concatenation gives a directed walk to the specified root; removing repetitions gives a directed path.

This proves the required reachability for every state. When \(m=1\), the same-class argument alone proves it, including the permitted zero-length path at the root.

4. Uniqueness. Let \(q\) be any admissible vector having the required reachability, and put \(\delta_j=q_j-p^0_j\).

From the inequalities in Section 1, summing along a shortest class path gives

\(\delta_{j_0}-\delta_j\leq D_j.\)

Now consider any state edge \((t,h)\to(s,\ell)\) at \(q\). Its equality gives

\(\delta_\ell-\delta_h=v_{th}+p^0_h-v_{t\ell}-p^0_\ell.\)

The right side is at least \(a_{h\ell}\). Admissibility of \(q\), applied to all types in \(T_h\), gives the reverse bound \(\delta_\ell-\delta_h\leq a_{h\ell}\). Thus

\(\delta_\ell-\delta_h=a_{h\ell}.\)

For each class \(j\), choose a supported state in that class and a state path from it to the root. Projecting this path onto room classes produces a class walk. Summing the preceding equality along it shows that its weight is \(\delta_{j_0}-\delta_j\). By the definition of shortest-path distance,

\(D_j\leq\delta_{j_0}-\delta_j.\)

Combining the two bounds yields \(\delta_j=\delta_{j_0}-D_j\) for every \(j\). Both compensation vectors satisfy the budget, so

\(0=\sum_j\sigma_j\delta_j=\delta_{j_0}-\overline D.\)

Consequently \(q_j=p^0_j-D_j+\overline D=p_j\). The solution is unique.

5. Running time and binary encoding. Write \(s=|S|\leq\tau m\). Computing all arc weights takes \(\mathcal O(sm)\), hence \(\mathcal O(\tau m^2)\), rational arithmetic operations.

For an explicit shortest-path algorithm, initialize \(D^{(0)}_{j_0}=0\) and \(D^{(0)}_j=\infty\) otherwise, and use

\(D^{(h+1)}_j=\min\bigl(D^{(h)}_j,\min_{\ell\in J}(a_{j\ell}+D^{(h)}_\ell)\bigr).\)

Induction on \(h\) shows that \(D^{(h)}_j\) is the minimum weight of a walk from \(j\) to \(j_0\) using at most \(h\) arcs. Since a shortest path uses at most \(m-1\) arcs, \(m-1\) rounds suffice. This takes \(\mathcal O(m^3)\) arithmetic operations. Budget normalization takes another \(\mathcal O(m)\).

To bound bit complexity, let \(Q\) be the product of all input denominators. Its binary length is \(\mathcal O(L)\). Each arc weight is an integer multiple of \(1/Q\), with numerator of \(\mathcal O(L)\) bits. Each finite distance is a sum of at most \(m-1\) arc weights, so its numerator has \(\mathcal O(L+\log(m+1))\) bits. The output coordinates can be represented with denominator \(Q^2\) and numerators of the same asymptotic bit length.

Using elementary integer arithmetic, including conversion to common denominators, a sufficient bit-operation bound is

\(\mathcal O\bigl((L+\tau m^2+m^3)(L+\log(m+1))^2\bigr).\)

Thus the algorithm is polynomial in \(m,\tau,L\), and its output has polynomial binary length.
