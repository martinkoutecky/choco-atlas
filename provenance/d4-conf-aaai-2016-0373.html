The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), and for each type \(t\) either no approved coalition profile or one integral profile \(a^t\in\mathbb{Z}_{\ge 0}^{T}\) with \(a^t_t\ge 1\), choose nonnegative masses \(x_q\) of coalitions with integral type-count vectors \(q\). Require \(\sum_q q_t x_q=\mu_t\) for every \(t\), and maximize the mass of agents in approved coalitions, \(\sum_q x_q\sum_{t:a^t=q}q_t\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\) satisfying \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type \(t\) approves either no coalition profile or exactly one profile \(a^t\in\mathbb{Z}_{\ge0}^{T}\), with \(a^t_t\ge1\); all profile coordinates are binary encoded. A type approves a coalition precisely when its profile equals its listed profile, and receives utility \(1\) if it approves and \(0\) otherwise.
Allowed coalition profiles are all \(q\in\mathbb{Z}_{\ge0}^{T}\setminus\{0\}\), including singleton profiles, with no imposed upper size bound. An allocation consists of finitely supported nonnegative real coalition masses \(x_q\) satisfying \(\sum_q q_t x_q=\mu_t\) for every \(t\).
Its welfare is \(W(x)=\sum_q x_q\sum_{t:\,a^t\text{ is listed and }a^t=q}q_t\). The input additionally contains a binary rational threshold \(B\in[0,1]\).
Let \(m=\max(\{1\}\cup\{\sum_t a^s_t:a^s\text{ is listed}\})\), and let \(L\) be the total binary input length. Running times are measured in \(m,\tau,L\), with polynomial time meaning polynomial in the binary input length \(L\).

Is deciding whether a feasible allocation \(x\) satisfies \(W(x)\ge B\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For a finite society where each agent explicitly lists at most one approved coalition, deciding whether a partition satisfies at least a given number of agents is \(\mathrm{NP}\)-complete.

Modeling choices made when packaging the task

  • Turned welfare maximization into its threshold decision problem by adding a binary rational threshold \(B\in[0,1]\).
  • Excluded the zero coalition profile, since discrete coalitions are nonempty; retained singleton profiles and imposed no upper size bound, as in the graded formulation.
  • Specified coalition masses as nonnegative reals with finite support.
  • Omitted zero-mass types so that the type list is exactly the society's positive support.
  • Defined \(m\) as the maximum listed approved coalition size, defaulting to \(1\), and specified binary encoding of profile coordinates and total input length \(L\).

Result

The decision problem is in \(\mathrm{P}\), with running time polynomial in the binary input length \(L\). The unbounded set of allowed profiles can be replaced by a linear feasibility problem with at most \(\tau\) variables.

1. The profiles that contribute welfare

Let \(\mathcal A=\{p^1,\ldots,p^k\}\) be the set of distinct listed approval profiles. Since each type lists at most one profile, \(k\le\tau\).

For every allowed profile \(q\), define its welfare coefficient by

\[ w(q)=\sum_{t:\,a^t\text{ is listed and }a^t=q}q_t. \]

Thus \(w(q)=0\) whenever \(q\notin\mathcal A\). For each \(j\), let \(c_j=w(p^j)\). These coefficients are computed directly from the input, grouping types that list the same profile.

Consider the following rational linear feasibility problem, with variables \(y_1,\ldots,y_k\):

\[ y_j\ge0\quad\text{for every }j, \]

\[ \sum_{j=1}^k p^j_t y_j\le\mu_t \quad\text{for every }t\in T, \]

\[ \sum_{j=1}^k c_jy_j\ge B. \]

We prove that this system is feasible exactly when the requested allocation exists.

2. From an allocation to a feasible linear system

Suppose \(x\) is a feasible allocation with \(W(x)\ge B\). Set \(y_j=x_{p^j}\).

For every type \(t\), nonnegativity of all coalition masses gives

\[ \sum_{j=1}^k p^j_t y_j \le \sum_q q_tx_q =\mu_t. \]

Moreover, profiles outside \(\mathcal A\) have zero welfare coefficient. Consequently,

\[ \sum_{j=1}^k c_jy_j =\sum_q w(q)x_q =W(x) \ge B. \]

Hence \(y\) satisfies the linear system.

3. From a feasible linear system to an allocation

Conversely, suppose \(y\) satisfies the system. For every type \(t\), define its residual mass by

\[ r_t=\mu_t-\sum_{j=1}^k p^j_ty_j\ge0. \]

Let \(e_t\) be the singleton profile containing one member of type \(t\) and no members of other types. Construct an allocation by assigning mass \(y_j\) to profile \(p^j\) and mass \(r_t\) to profile \(e_t\). If a profile occurs in both assignments, add the assigned masses.

Every assigned profile is allowed: each listed profile is nonzero because its approving type has a positive coordinate, and singleton profiles are expressly allowed. The allocation has support size at most \(k+\tau\le2\tau\).

For every type \(t\), its total allocated mass is

\[ \sum_q q_tx_q =\sum_{j=1}^k p^j_ty_j+r_t =\mu_t. \]

Thus the allocation is feasible. Its welfare satisfies

\[ W(x) =\sum_{j=1}^k c_jy_j+\sum_{t\in T}w(e_t)r_t \ge\sum_{j=1}^k c_jy_j \ge B, \]

because every singleton welfare coefficient is nonnegative. This calculation also handles approved singleton profiles correctly.

The two directions establish the required equivalence. If \(k=0\), all welfare is zero, so the answer is yes exactly when \(B=0\); singleton coalitions still give a feasible allocation.

4. Polynomial binary encoding and running time

The system has \(k\le\tau\) variables and \(k+\tau+1\le2\tau+1\) inequalities.

Every profile coordinate is at most \(m\). Also,

\[ 0<c_j\le\sum_{t\in T}p^j_t\le m, \]

since \(c_j\) sums a subset of the profile coordinates. Thus every integer coefficient requires \(O(\log(m+1))\) bits. The rational right-hand sides are the input masses and threshold.

The system therefore has encoding length

\[ O\!\left(\tau^2\log(m+1)+L\right). \]

Both \(\tau\) and \(\log(m+1)\) are polynomially bounded in \(L\): the support is explicitly listed, and \(m\) is a sum of at most \(\tau\) binary-encoded coordinates from one input profile, or equals one. Grouping identical profiles and computing the coefficients also take polynomial time.

The rational linear programming theorem states that feasibility of an explicitly encoded finite system of rational linear inequalities can be decided exactly in time polynomial in its total binary encoding length. Its hypotheses apply here: all coefficients are rational, and the entire system has polynomial encoding length. See [Khachiyan, *A polynomial algorithm in linear programming*](https://www.mathnet.ru/eng/dan42319).

Consequently, the algorithm runs in time polynomial in \(L\), without enumerating profiles up to size \(m\).

5. Why finite-society hardness does not transfer

A finite partition must select whole coalitions of indivisible agents. Here the coalition masses are arbitrary nonnegative real numbers, and each type’s mass may be split among several profiles. The resulting constraints are linear inequalities without integrality requirements. Singleton profiles complete every feasible partial assignment.

Therefore, the stated finite-society \(\mathrm{NP}\)-completeness result does not establish hardness for this continuous allocation problem.
