Theorem 7 — class: hardness

The continuous mirror question, as graded

Given a finite support of complete \(t\)-layer ballot types \(x\), with binary-rational masses \(\mu_x\) summing to \(1\), a rule set \(R\), a distinguished candidate \(p\), a satisfaction threshold \(d\), and a rational quota \(a\), is there a shared assignment \((r_1,\ldots,r_t)\in R^t\) for which \(\sum_x \mu_x\,\mathbf{1}[\max_j \operatorname{Sat}(p,v_x^j,r_j)\ge d]\ge a\)? Theorem 7’s mirror uses \(d=1\), \(a=1\), and uniform mass on clause types.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set, \(m=|C|\), and \(p\in C\). Let \(t\ge1\) and let \(R\) be a nonempty rule set of size \(\ell\).
A society is given by its support: the list of the \(\tau\) complete types with positive binary-rational masses \(\mu_x\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has one vote \(v_x^j\) per layer \(j\). Votes and rules are represented by the explicit satisfaction table \(s_{xjr}=\operatorname{Sat}(p,v_x^j,r)\in\mathbb Z_{\ge0}\), with entries encoded in binary; no particular ranking format or named voting rule is imposed.
The input also contains a positive integer threshold \(d\) and a binary-rational quota \(a\in(0,1]\). An assignment chooses exactly one rule \(r_j\in R\) per layer, shared by every type; rules may be reused across layers.
Type \(x\) accepts \(p\) exactly when \(\max_{1\le j\le t}s_{xjr_j}\ge d\). Acceptance is the entire requirement; there is no additional comparison with other candidates or unique-winner condition.
Decide whether some assignment \((r_1,\ldots,r_t)\in R^t\) satisfies \(\sum_x\mu_x\mathbf 1[\max_{1\le j\le t}s_{xjr_j}\ge d]\ge a\). Let \(L\) be the total binary input length; state running times in \(m,\tau,t,\ell,L\).

Is this rational-mass decision problem solvable in polynomial time, or is it NP-hard?

For finite voters, the corresponding max-model problem is NP-hard even with \(\ell=2\), satisfaction entries in \(\{0,1\}\), \(d=1\), and a requirement that every voter accept. The supplied result gives no separate classification for the rational-mass formulation.

Modeling choices made when packaging the task

  • Undefined ballot and rule encodings are resolved by using explicit satisfaction tables, as permitted by the discrete definition, rather than imposing a ranking format.
  • The unspecified satisfaction-value domain is taken to be nonnegative binary-encoded integers, consistent with the discrete constructions; the threshold remains a positive integer.
  • The rational quota is restricted to (0,1], matching the discrete requirement of a positive number of accepting voters within the society's total size.
  • Candidate sets, rule sets, and layer counts are required to be nonempty so that the distinguished candidate, assignments, and maximum are defined.
  • Acceptance is interpreted solely through the satisfaction threshold, without an additional winner comparison or uniqueness requirement.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

The problem is NP-complete, even when \(m=1\), \(\ell=2\), \(d=1\), \(a=1\), and all satisfaction entries belong to \(\{0,1\}\). The hardness construction uses positive dyadic masses, so it applies even if “binary-rational” means a rational with a finite binary expansion.

Consequently, a polynomial-time algorithm exists if and only if \(\mathrm{P}=\mathrm{NP}\).

Membership in NP

A certificate specifies the selected rule \(r_j\) for each layer \(j\). Its length is \(O(t\log(\ell+1))\), which is polynomial in \(L\) because the satisfaction table is explicit.

For each supported type \(x\), compute
\(b_x=\mathbf{1}[\max_{1\le j\le t}s_{xjr_j}\ge d]\).
It remains to check exactly whether \(\sum_x\mu_x b_x\ge a\).

Write \(\mu_x=u_x/q_x\) and \(a=u_a/q_a\), with positive integer denominators. Set
\(D=q_a\prod_xq_x\),
\(W_x=u_x(D/q_x)\), and \(A=u_a(D/q_a)\).
Then the quota condition is equivalent to the integer inequality
\(\sum_xW_xb_x\ge A\).

The bit length of \(D\) is at most the sum of the denominator bit lengths, hence \(O(L)\). Since \(\mu_x\le1\) and \(a\le1\), all \(W_x\) and \(A\) also have \(O(L)\) bits. Computing these integers, evaluating acceptance, and checking the inequality takes \(O(L^3)\) bit operations using elementary integer arithmetic. Thus the problem belongs to NP.

NP-hardness with positive dyadic masses

We reduce from 3-SAT, using its standard NP-completeness.

Let the input formula be
\(\Phi=K_1\land\cdots\land K_k\),
over variables \(z_1,\ldots,z_n\), with \(n,k\ge1\). We may assume clauses are pairwise distinct as sets of literals: removing repeated literals and duplicate clauses preserves satisfiability and takes polynomial time.

Construct the following instance:

  • \(C=\{p\}\), so \(m=1\).
  • There are \(t=n\) layers, one for each variable.
  • The rule set is \(R=\{\mathsf{T},\mathsf{F}\}\), so \(\ell=2\).
  • There is one supported type \(x_i\) for each clause \(K_i\), so \(\tau=k\).
  • Set \(d=1\) and \(a=1\).

Define the satisfaction table by
\(s_{x_i j\mathsf{T}}=1\) precisely when \(z_j\) occurs in \(K_i\), and
\(s_{x_i j\mathsf{F}}=1\) precisely when \(\neg z_j\) occurs in \(K_i\).
All other entries are zero.

Distinct clauses yield distinct complete table rows: the row records exactly which positive and negative literals occur in the clause. Thus the construction does not rely on duplicate support entries.

Masses

Let \(h=\lceil\log_2 k\rceil\). Give the first \(k-1\) types mass
\(\mu_{x_i}=2^{-h}\),
and give the last type mass
\(\mu_{x_k}=(2^h-k+1)/2^h\).

These masses are positive because \(2^h\ge k\). They sum to one, since
\(\sum_{i=1}^k\mu_{x_i}=((k-1)+(2^h-k+1))/2^h=1\).
They are dyadic and each requires \(O(\log(k+1))\) bits. For \(k=1\), the construction simply assigns mass one to its sole type.

Correctness

An assignment of rules determines a Boolean assignment by declaring \(z_j\) true exactly when \(r_j=\mathsf{T}\).

For each clause \(K_i\), the construction gives
\(\max_{1\le j\le n}s_{x_i j r_j}\ge1\)
if and only if at least one literal in \(K_i\) is true. Therefore, type \(x_i\) accepts exactly when \(K_i\) is satisfied.

Because all masses are strictly positive and sum to one, accepted mass is at least \(a=1\) exactly when every supported type accepts. Indeed, if type \(x_i\) rejects, accepted mass is at most \(1-\mu_{x_i}<1\).

It follows that a rule assignment meets the quota if and only if its corresponding Boolean assignment satisfies every clause of \(\Phi\).

Size of the reduction

The satisfaction table contains \(2nk\) one-bit entries, and the masses require \(O(k\log(k+1))\) bits altogether. Thus the output length is polynomial in the formula length, and the construction is computable in polynomial time. This proves NP-hardness under the stated restrictions.

Running times and conclusion

For general parameters \(m,\tau,t,\ell,L\), verification takes \(O(L^3)\) bit operations. Enumerating all assignments gives a deterministic decision algorithm taking \(O(\ell^tL^3)\) bit operations. Neither bound has an additional dependence on \(m\), because the explicit input table already contains all satisfaction information relevant to \(p\).

The reduction proves NP-hardness, and the verification argument proves membership in NP. Hence the rational-mass formulation is NP-complete.
