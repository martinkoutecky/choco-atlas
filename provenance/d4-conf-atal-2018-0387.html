The continuous mirror question, as graded

Given a finite candidate set \(C\), designated candidate \(p\in C\), finite voter types \(T\), rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), complete rankings \(\pi_t\), nondecreasing shift-price functions \(\rho_t(k)\), and budget \(b\), decide whether there are masses \(x_{t,k}\ge 0\) with \(\sum_k x_{t,k}=\mu_t\) and \(\sum_{t,k}\rho_t(k)x_{t,k}\le b\) such that, after shifting \(p\) upward by \(k\) positions for mass \(x_{t,k}\), \(p\) is the unique winner under Hare's simultaneous minimum-plurality elimination rule.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set, \(m=|C|\), and \(p\in C\). A society is given by its support: the list of the \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Each type specifies a strict complete ranking \(\pi_t\) and its shift-price table; identical rankings may have different prices.
If \(p\) has position \(r_t\) in \(\pi_t\), the explicitly listed prices \(\rho_t(k)\), for \(k\in\{0,\ldots,r_t-1\}\), are nonnegative binary integers, nondecreasing in \(k\), with \(\rho_t(0)=0\). The budget \(b\ge0\) is a binary rational. Prices are costs per unit mass; \(L\) denotes the total input bit length.
A shift allocation consists of real masses \(x_{t,k}\ge0\) satisfying \(\sum_{k=0}^{r_t-1}x_{t,k}=\mu_t\) and \(\sum_t\sum_{k=0}^{r_t-1}\rho_t(k)x_{t,k}\le b\). Before voting begins, mass \(x_{t,k}\) adopts the ranking obtained by moving \(p\) upward exactly \(k\) positions in \(\pi_t\), preserving the relative order of all other candidates.
Hare voting repeatedly computes plurality scores by mass on the rankings restricted to the surviving candidates. If all surviving candidates have equal scores, they are all declared winners and voting stops; otherwise, every candidate attaining the minimum score is eliminated simultaneously. Thus a sole survivor wins, and no tie-breaking order is used.

Is deciding whether a feasible shift allocation makes \(p\) the unique Hare winner solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite lists of indivisible voters, constructive upward shift bribery under this rule is NP-complete ([Maushagen et al., 2018](https://aamas.csc.liv.ac.uk/Proceedings/aamas2018/pdfs/p1567.pdf)); the [2022 full version](https://link.springer.com/content/pdf/10.1007/s10472-022-09802-5.pdf) also establishes hardness in the nonunique-winner model.
With unit prices, the discrete problem is FPT in the number of candidates and separately in the number of voters, but \(\mathrm{W}[1]\)-hard in the number of shift operations ([Zhou and Guo, 2020](https://www.ifaamas.org/Proceedings/aamas2020/pdfs/p1665.pdf)). No result settling the exact divisible-mass problem above was located.

Modeling choices made when packaging the task

  • Removed zero-mass types from the supplied list so that the input lists exactly the positive-mass support; retained total mass one.
  • Interpreted complete rankings as strict linear orders and types as ranking-and-price pairs, allowing different prices for identical rankings.
  • Specified nonnegative integer prices and zero cost for no shift, following the discrete price domain; represented each price function by its finite table of attainable shifts.
  • Restricted shifts to integers from zero through the initial position of p minus one, faithfully implementing the discrete convention that shifts cannot pass the top position.
  • Specified a nonnegative binary-rational budget and interpreted prices as costs per unit mass under the normalized society.
  • Allowed real allocation masses and fixed all shifted rankings before the elimination process, preserving the relative order of other candidates.
  • Added the all-equal stopping convention, including a sole survivor, and specified simultaneous elimination without tie-breaking.
  • Defined m as the candidate count and L as the total input bit length; allowed every nonempty candidate set.

Result

The decision problem is \(\mathrm{NP}\)-complete. This holds even when all input masses and the budget are dyadic rationals, and every type initially ranks \(p\) within its first four positions.

The reduction below permits arbitrary real allocations and explicitly accounts for small shifts on expensive types.

1. Source problem

We reduce from restricted exact cover by three-element sets. An instance consists of a universe \(X\), with \(|X|=3q\) and \(q\ge1\), and a family \(\mathcal S=\{S_1,\ldots,S_{3q}\}\), where each set has three elements and each element occurs in exactly three sets. The question is whether some \(q\) sets cover \(X\). This problem is \(\mathrm{NP}\)-complete by [Gonzalez, Theorem A.1](https://www.cs.columbia.edu/~verma/classes/uml/ref/clustering_minimize_intercluster_distance_gonzalez.pdf).

The family has \(3q\) members because counting element-set incidences gives \(3|\mathcal S|=3|X|\). Moreover, any cover using at most \(q\) members must be an exact cover: these sets contain at most \(3q\) incidences altogether.

2. Construction

We first specify unnormalized masses. Normalization will divide all masses and the budget by the same positive number, leaving all score comparisons unchanged.

Introduce:

  • an element candidate \(x\) for each \(x\in X\);
  • a set candidate \(s_i\) and a sentinel \(d_i\) for each \(S_i\);
  • the preferred candidate \(p\) and a rival \(z\).

The following table specifies ranking prefixes. Complete each prefix by appending all unlisted candidates after \(p\), in any fixed order.

| Unnormalized mass | Ranking prefix | Types included |
|---|---|---|
| \(1\) | \(s_i\succ x\succ z\succ p\) | Each \(i\), each \(x\in S_i\) |
| \(1\) | \(s_i\succ p\) | Each \(i\) |
| \(3\) | \(d_i\succ s_i\succ p\) | Each \(i\) |
| \(4\) | \(x\succ z\succ p\) | Each \(x\in X\) |
| \(8\) | \(p\) | One type |
| \(\frac92\) | \(z\succ p\) | One type |

Call the \(s_i\succ p\) types cheap. Their only positive shift has price \(1\).

Set \(M=8q\). Every other type has price \(M\) for every allowed positive shift. All types have price zero for shift zero. These tables contain nonnegative integers and are nondecreasing.

Dyadic normalization

The table’s total mass is

\[ \text{(formula below)} \]

\(W_0=3q(3+1+3)+3q\cdot4+8+\frac92=33q+\frac{25}{2}.\)

To obtain dyadic normalized masses, let \(W\) be the least power of two satisfying \(W\ge W_0+100\), and put \(A=W-W_0\).

Introduce padding candidates \(h_1,\ldots,h_N\), where \(N=\lceil A/5\rceil\). Since \(A\ge100\), we have \(N\ge20\), and

\(\frac{19N}{4}\le5N-5<A\le5N.\)

Thus \(J=4A-19N\) is an integer satisfying \(0\le J\le N\). Give \(J\) padding types mass \(5\), and the other \(N-J\) padding types mass \(\frac{19}{4}\). Each has prefix \(h_\ell\succ z\succ p\), with price \(M\) for every positive shift. Their masses sum to

\(5J+\frac{19}{4}(N-J)=\frac{19N+J}{4}=A.\)

Now divide every mass by \(W\), and set the actual budget to \(b=q/W\). The masses sum to one. All masses and the budget are dyadic rationals.

Because \(W<2(W_0+100)\), we have \(N=O(q)\). The construction therefore has polynomially many candidates and types, polynomial input length, and explicitly listed price tables. Every prefix places \(p\) within its first four positions.

From now on, scores, allocated masses, and costs are measured in the unnormalized units. The budget in these units is \(q\).

3. A uniform bound on expensive shifts

Fix any feasible allocation. Let \(y_i\in[0,1]\) be the cheap mass shifted from \(s_i\succ p\) to \(p\succ s_i\). Let \(\eta\) be the total mass receiving a positive shift on expensive types.

The budget constraint is exactly

\(\sum_i y_i+M\eta\le q.\)

Consequently, \(\eta\le q/M=\frac18\).

Define the reference profile by keeping the cheap shifts \(y_i\), while restoring every expensive type to its original ranking. For a surviving set \(R\) containing \(p\), write \(s_R(c)\) and \(\bar s_R(c)\) for actual and reference plurality scores.

Moving \(p\) upward preserves the relative order of all other candidates. On a ranking restricted to \(R\), it can therefore change the top candidate only by replacing some candidate with \(p\). It cannot transfer score between two candidates different from \(p\). Hence, for every \(c\ne p\),

\(\bar s_R(c)-\eta\le s_R(c)\le\bar s_R(c),\)

and

\(\bar s_R(p)\le s_R(p)\le\bar s_R(p)+\eta.\)

These bounds hold for every surviving set containing \(p\), regardless of the actual elimination history. Also, the mass \(8\) ranking \(p\) first ensures \(s_R(p)\ge8\) throughout any round in which \(p\) survives.

4. An exact cover makes \(p\) the unique winner

Suppose \(\mathcal S'\) is an exact cover of size \(q\). Shift all cheap mass belonging to its sets, and make no expensive shifts. This costs exactly \(q\).

The initial scores are:

| Candidates | Score |
|---|---|
| \(p\) | \(8+q\) |
| Selected set candidates | \(3\) |
| Unselected set candidates | \(4\) |
| Sentinels | \(3\) |
| Element candidates | \(4\) |
| \(z\) | \(\frac92\) |
| Padding candidates | \(\frac{19}{4}\) or \(5\) |

Thus the first round simultaneously eliminates every sentinel and every selected set candidate.

Each element receives exactly one unit from the selected sets, because they form an exact cover. Each unselected set candidate receives its sentinel’s mass \(3\). The resulting scores are:

  • \(p\): \(8+4q\);
  • each element candidate: \(5\);
  • each remaining set candidate: \(7\);
  • \(z\): \(\frac92\);
  • each padding candidate: \(\frac{19}{4}\) or \(5\).

Therefore the next round eliminates \(z\) alone.

Afterward, every surviving opponent of \(p\) has score at most \(7\). Indeed, a surviving set candidate receives at most its original mass \(4\) plus sentinel mass \(3\); a surviving element receives its mass \(4\) plus at most three incident membership masses; and a padding candidate receives only its own mass, at most \(5\). No other ranking can transfer to these candidates while \(p\) survives.

Since \(p\)’s score is at least \(8\), every subsequent elimination removes opponents of \(p\). A tied stopping round containing an opponent is impossible. Eventually \(p\) is the sole survivor.

5. Without an exact cover, every feasible allocation fails

Assume the source instance has no exact cover, and fix an arbitrary feasible allocation.

5.1. The sentinel phase selects at most \(q\) sets

Consider rounds whose starting surviving set contains at least one sentinel. We prove inductively that such rounds eliminate only sentinels and set candidates.

A surviving sentinel has reference score \(3\), so the minimum actual score is at most \(3\). Until an element or padding candidate is eliminated:

  • each element has actual score at least \(4-\eta>3\);
  • \(z\) has actual score at least \(\frac92-\eta>3\);
  • each padding candidate has actual score at least \(\frac{19}{4}-\eta>3\);
  • \(p\) has score at least \(8\).

Thus none of these candidates can be eliminated in such a round. This proves the induction. The election cannot stop with equal scores during this phase, since a sentinel scores at most \(3\), whereas \(p\) scores at least \(8\). Each round removes candidates, so eventually all sentinels disappear.

Let \(I\) consist of the indices of set candidates eliminated during this phase, including those eliminated simultaneously with the last sentinels.

If \(d_i\) has already disappeared while \(s_i\) survives, the reference score of \(s_i\) is \(7-y_i\ge6\). Its actual score is consequently greater than \(3\). Therefore any \(s_i\) eliminated during the sentinel phase must have its own sentinel present at the start of its elimination round.

Its reference score in that round is \(4-y_i\). Because its actual score is at most \(3\), the perturbation bound gives

\(4-y_i-\eta\le3,\qquad\text{so}\qquad y_i\ge1-\eta.\)

Write \(r=|I|\). Since \(r\le3q<M\), the budget implies

\(q\ge\sum_i y_i+M\eta\ge r(1-\eta)+M\eta=r+(M-r)\eta\ge r.\)

Hence \(|I|\le q\). This inequality accounts for every expensive shift; it does not assume that expensive types are unbribable.

5.2. An uncovered element protects \(z\)

Immediately after the sentinel phase, every element, every padding candidate, \(p\), and \(z\) still survives. The eliminated set candidates are precisely those indexed by \(I\).

For \(x\in X\), define \(a_I(x)=|\{i\in I:x\in S_i\}|\). Its reference score is \(4+a_I(x)\). Since \(|I|\le q\) and there is no exact cover, some element is uncovered.

At this point:

| Candidates | Actual-score bound |
|---|---|
| Uncovered elements | Between \(4-\eta\) and \(4\) |
| Covered elements | At least \(5-\eta\) |
| Remaining set candidates | At least \(6-\eta\) |
| \(z\) | Between \(\frac92-\eta\) and \(\frac92\) |
| Padding candidates | At least \(\frac{19}{4}-\eta\) |
| \(p\) | At least \(8\) |

Because \(\eta\le\frac18\), every minimum-score candidate is an uncovered element. The next round therefore eliminates a nonempty collection of uncovered elements and no other candidates.

The original mass \(4\) of any such element has prefix \(x\succ z\succ p\). After its elimination, the reference score of \(z\) is at least \(\frac92+4=\frac{17}{2}\). Thus the actual score of \(z\) is at least

\(\frac{17}{2}-\eta\ge\frac{67}{8}>7.\)

5.3. The final round defeats \(p\)

As long as \(p\) and \(z\) survive, every other remaining candidate has actual score at most \(7\):

  • set candidates have reference score \(7-y_i\le7\);
  • element candidates receive at most their mass \(4\) and three membership masses;
  • padding candidates score at most \(5\).

Upward shifts cannot increase these scores. Meanwhile, \(p\) scores at least \(8\), and \(z\)’s score cannot decrease when other candidates are eliminated.

Consequently, while another candidate remains, both \(p\) and \(z\) have strictly greater scores than the minimum. The rule continues eliminating other candidates until only \(p\) and \(z\) remain.

In this final pair, the reference score of \(p\) is

\(8+3q+9q=12q+8,\)

coming from its own type, all cheap types, and all sentinel types. The reference score of \(z\) is

\(12q+9q+\frac92+A=21q+\frac92+A,\)

coming from the element types, membership types, its own type, and all padding types.

Therefore

\(s_{\{p,z\}}(z)-s_{\{p,z\}}(p)\ge9q-\frac72+A-2\eta>0.\)

The inequality is strict because \(q\ge1\), \(A\ge100\), and \(\eta\le\frac18\). Thus \(p\) is eliminated and \(z\) wins alone.

This proves that a successful allocation exists if and only if the source instance has an exact cover. The polynomial construction establishes \(\mathrm{NP}\)-hardness.

6. Membership in \(\mathrm{NP}\)

Real allocation variables require a certificate argument.

Suppose a successful real allocation exists. Its elimination history is an ordered partition \(E_1,\ldots,E_\ell\) of \(C\setminus\{p\}\), where each \(E_j\) is the nonempty batch eliminated in one round. Let \(R_j=C\setminus\bigcup_{i<j}E_i\), and choose \(e_j\in E_j\).

For this fixed history, each round’s plurality scores are linear functions of the allocation variables, with coefficients in \(\{0,1\}\). Consider the following closed rational linear system:

  • the allocation nonnegativity and type-mass equalities;
  • the budget inequality;
  • \(0\le\delta\le1\);
  • for every \(j\) and \(c\in E_j\), the equality \(s_{R_j}(c)=s_{R_j}(e_j)\);
  • for every \(j\) and \(d\in R_j\setminus E_j\), the inequality \(s_{R_j}(d)\ge s_{R_j}(e_j)+\delta\).

The successful real allocation has strictly positive gaps between each eliminated batch and every survivor. There are finitely many such gaps, so this system has a solution with \(\delta>0\).

The feasible region is bounded: \(0\le x_{t,k}\le\mu_t\), and \(0\le\delta\le1\). Hence maximizing \(\delta\) attains a positive optimum at a rational vertex.

There are at most \(\tau m+1\) variables and polynomially many constraints, all with polynomial encoding length. Clearing denominators in each row preserves polynomial coefficient bit lengths. A vertex is determined by a full-rank collection of active constraints; Cramer’s rule and the determinant bound give polynomial bit lengths for its coordinates. Thus a successful allocation exists with polynomially encoded rational masses.

A verifier can check its constraints and simulate Hare exactly using rational arithmetic. There are at most \(m-1\) elimination rounds, and all arithmetic has polynomial bit complexity. Therefore the problem belongs to \(\mathrm{NP}\).

Together with the reduction, this establishes \(\mathrm{NP}\)-completeness.
