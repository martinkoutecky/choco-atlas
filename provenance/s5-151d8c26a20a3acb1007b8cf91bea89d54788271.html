The continuous mirror question, as graded

Given a finite task set \(I\) and a finite support \(T\) of worker types, where each type \(t\) has a nonempty task bundle \(A_t\subseteq I\) and positive rational mass \(\mu_t\), find a minimum-cardinality set \(S\subseteq I\) such that \(S\cap A_t\ne\varnothing\) for every \(t\in T\).

Packaged proof task (what the prover saw — nothing else)

Let \(I\) be a finite task set, with \(m=|I|\). A society is given by its support: a list \(T\) of \(\tau\) worker types, each with an explicitly listed nonempty bundle \(A_t\subseteq I\) and positive binary rational mass \(\mu_t\). Masses need not sum to one; \(\tau\) is the support size, not the number of possible bundles.
Selecting a task costs one unit and verifies the entire mass of every type assigned that task. The bundles are fixed. Find a minimum-cardinality set \(S\subseteq I\) satisfying \(S\cap A_t\ne\varnothing\) for every \(t\in T\).
For the decision version, the input also contains a binary integer \(B\) with \(0\le B\le m\), and asks whether such a set exists with \(|S|\le B\). Let \(L\) denote the total input bit length; state running times in \(m,\tau,L\), and \(B\).

Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For a finite list of workers with fixed task bundles, minimum-cardinality Supervisor Assignment is \(\mathrm{NP}\)-hard, already when each worker has two assigned tasks. [Verified source](https://arxiv.org/pdf/1608.07886v2).

Conclusion

The decision problem is \(\mathrm{NP}\)-complete, already when every bundle contains exactly two tasks and every mass equals \(1\). Consequently, finding a minimum-cardinality feasible set is \(\mathrm{NP}\)-hard. A polynomial-time algorithm for the decision problem exists if and only if \(\mathrm{P}=\mathrm{NP}\).

1. Masses do not affect feasibility

For a selected set \(S\subseteq I\), the unverified mass is

\(\displaystyle U(S)=\sum_{\{t\in T:S\cap A_t=\varnothing\}}\mu_t.\)

Because every \(\mu_t\) is strictly positive, \(U(S)=0\) if and only if \(S\cap A_t\ne\varnothing\) for every \(t\in T\). Thus the problem is exactly Hitting Set on the explicitly listed family of bundles. The numerical values of the masses do not affect either feasibility or the optimum.

In particular, the binary masses need not be expanded into individual workers.

2. Membership in \(\mathrm{NP}\)

Let \(J=\bigcup_{t\in T}A_t\) and \(r=|J|\). Tasks outside \(J\) can be removed from any candidate solution without affecting feasibility. Hence it suffices to consider subsets of \(J\), where \(r\le m\).

A certificate lists distinct selected tasks from \(J\). Its encoding has length \(O(L)\): each selected task identifier already occurs in the input, and one can charge its length to one such occurrence.

The verifier checks that:

  • Every selected task belongs to \(J\), and no selected task is repeated.
  • The number selected is at most \(B\).
  • Each explicitly listed bundle contains a selected task.

These checks require only comparisons of task identifiers and an integer comparison with \(B\). Straightforward pairwise comparisons give a conservative bound of \(O(L^2)\) bit operations: both the input identifiers and certificate identifiers have total length \(O(L)\). Therefore the problem belongs to \(\mathrm{NP}\).

3. Polynomial reduction from Vertex Cover

We use the classical \(\mathrm{NP}\)-completeness of Vertex Cover on finite simple undirected graphs: given \(G=(V,E)\) and an integer \(k\) with \(0\le k\le |V|\), decide whether there is a set \(C\subseteq V\) of size at most \(k\) containing at least one endpoint of every edge.

Given such an instance, construct:

  • The task set \(I=V\).
  • One worker type \(t_e\) for every edge \(e=\{u,v\}\in E\).
  • The bundle \(A_{t_e}=\{u,v\}\).
  • The positive rational mass \(\mu_{t_e}=1\).
  • The budget \(B=k\).

This is a valid instance with \(m=|V|\) and \(\tau=|E|\). Every bundle contains exactly two distinct tasks. Since the graph is simple, distinct edges give distinct bundles, so the construction also satisfies an interpretation in which support entries must have distinct bundles.

For every \(S\subseteq V\),

\(\displaystyle S\text{ is feasible}\iff S\cap\{u,v\}\ne\varnothing\text{ for every }\{u,v\}\in E \iff S\text{ is a vertex cover of }G.\)

The correspondence preserves cardinality, and \(B=k\). Thus the constructed instance is a yes-instance if and only if the original Vertex Cover instance is a yes-instance.

Writing vertex identifiers in binary, the construction takes

\(\displaystyle O\bigl((m+\tau)\log(m+2)+\log(B+2)\bigr)\)

bit operations and produces an encoding of that size, up to constant factors. It is therefore a polynomial-time many-one reduction.

This is also the incidence construction used in Theorem 9 of the [cited paper](https://arxiv.org/pdf/1608.07886v2). Assigning each edge type mass \(1\) directly establishes hardness for the rational-mass formulation.

Combining the reduction with membership in \(\mathrm{NP}\) proves \(\mathrm{NP}\)-completeness.

4. Exact running-time bounds and boundary cases

If \(\tau=0\), the empty set is optimal. If \(\tau>0\) and \(B=0\), the answer is no.

Because every bundle is nonempty, choosing one task from each bundle gives a feasible set of size at most \(\tau\). Selecting all active tasks gives another bound, so the optimum is at most \(\min\{m,\tau,r\}\).

An exact decision algorithm enumerates subsets of \(J\) of size at most \(b=\min\{B,\tau,r\}\), checking each certificate as above. Its running time is

\(\displaystyle O\left(L^2\sum_{j=0}^{b}\binom{r}{j}\right) \subseteq O\left(L^2\sum_{j=0}^{\min\{B,\tau,m\}}\binom{m}{j}\right).\)

This is polynomial for every fixed \(B\), but not a polynomial-time bound when \(B\) varies with the input. Enumerating in increasing cardinality also finds a minimum set, within \(O(L^2 2^r)\) bit operations.

The reduction has only \(\tau=|E|\) support entries; it never enumerates all possible bundles.
