The continuous mirror question, as graded

Given finite agent types \(T\) with rational masses \(\mu_t\), recurring chore classes \(Q\) with rational per-capita supplies \(\lambda_q\) satisfying \(\sum_q\lambda_q\le1\), and disutilities \(d_{tq}\), decide whether all chore mass can be assigned in singleton bundles: does there exist \(y_{tq}\ge0\) such that \(\sum_t y_{tq}=\lambda_q\), \(\sum_q y_{tq}\le\mu_t\), and \(y_{tq}=0\) whenever \(d_{tq}>\sum_{q'}\lambda_{q'}d_{tq'}\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge2\) recurring chore classes \(Q\), with positive binary rational per-capita supplies \(\lambda_q\) satisfying \(\sum_q\lambda_q\le1\). Disutilities are additive, with binary rational \(d_{tq}\in(0,1]\), pairwise distinct within each type. Inputs are deterministic.
Each individual receives either no chore or one whole chore occurrence. A type may be partitioned among different classes; \(y_{tq}\) denotes the mass of type \(t\) receiving a class-\(q\) occurrence. Set \(b_t=\sum_{q\in Q}\lambda_qd_{tq}\).
Decide whether there exist real \(y_{tq}\ge0\) satisfying \(\sum_t y_{tq}=\lambda_q\) for every \(q\), \(\sum_q y_{tq}\le\mu_t\) for every \(t\), and \(y_{tq}=0\) whenever \(d_{tq}>b_t\). Equality with \(b_t\) is allowed. Let \(L\) be the total input bit length.

Is this continuous singleton proportional-allocation decision problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For discrete chores, a polynomial-time algorithm finds a singleton proportional allocation with probability at least \(1-k^{-4}\) when \(k/\log k\ge80/(\alpha\rho)\) and \(k\log k\le n/40\), for \(n\) agents and \(k\) chores whose disutilities are independent draws from a distribution on \([0,1]\) with density bounded between positive constants \(\alpha,\beta\) and mean \(\rho\). Result

The decision problem is in \(\mathrm{P}\). It reduces to a maximum-flow problem with \(\tau+m+2\) vertices and at most \(m\tau+m+\tau\) arcs. The reduction preserves feasibility exactly, and all computations can be performed with polynomial bit complexity.

1. Construct the eligibility network

Write \(\Lambda=\sum_{q\in Q}\lambda_q\), and compute \(b_t=\sum_{q\in Q}\lambda_qd_{tq}\) for each \(t\in T\).

Define the eligible pairs by \(E_{\mathrm{elig}}=\{(q,t)\in Q\times T:d_{tq}\le b_t\}\). In particular, equality is included.

Construct a directed network with source \(s\), sink \(z\), one vertex for each class \(q\), and one vertex for each supported type \(t\). Its arcs and capacities are:

| Arc | Condition | Capacity |
|---|---|---|
| \(s\to q\) | Every \(q\in Q\) | \(\lambda_q\) |
| \(q\to t\) | \((q,t)\in E_{\mathrm{elig}}\) | \(\lambda_q\) |
| \(t\to z\) | Every \(t\in T\) | \(\mu_t\) |

There are no other arcs. The total capacity leaving \(s\) is \(\Lambda\), so every feasible flow has value at most \(\Lambda\).

The algorithm accepts exactly when the maximum-flow value equals \(\Lambda\).

2. Proof of equivalence

An allocation yields a flow of value \(\Lambda\)

Suppose \(y_{tq}\) satisfies all the constraints in the question. Define

  • \(f(s,q)=\lambda_q\);
  • \(f(q,t)=y_{tq}\) for every eligible pair;
  • \(f(t,z)=\sum_{q\in Q}y_{tq}\).

For an ineligible pair, the given constraints require \(y_{tq}=0\), so omitting that arc loses no positive allocation.

At a class vertex \(q\), flow conservation holds because \(\sum_t y_{tq}=\lambda_q\). Moreover, nonnegativity and this equality imply \(y_{tq}\le\lambda_q\), verifying every class–type arc capacity.

At a type vertex \(t\), conservation holds by the definition of \(f(t,z)\), and its capacity is respected because \(\sum_q y_{tq}\le\mu_t\).

Thus \(f\) is a feasible flow with value \(\sum_q f(s,q)=\Lambda\).

A flow of value \(\Lambda\) yields an allocation

Conversely, suppose \(f\) is a feasible flow of value \(\Lambda\). Every source arc is saturated: indeed,

\(\sum_{q\in Q}\bigl(\lambda_q-f(s,q)\bigr)=\Lambda-\Lambda=0\),

and each summand is nonnegative.

Set \(y_{tq}=f(q,t)\) on eligible pairs and \(y_{tq}=0\) otherwise. Conservation at each class vertex gives

\(\sum_t y_{tq}=f(s,q)=\lambda_q\).

Conservation and the outgoing capacity at each type vertex give

\(\sum_q y_{tq}=f(t,z)\le\mu_t\).

All allocation entries are nonnegative, and positive entries occur only on eligible pairs. These are exactly the required constraints.

Consequently, a feasible allocation exists if and only if the maximum-flow value is \(\Lambda\).

3. Exact arithmetic and bit complexity

The remaining issue is to establish polynomial time in the binary input length, rather than merely in the numerical sizes of capacities.

Express every input rational as its encoded integer numerator divided by its positive integer denominator. Let \(C\) be the product of all these denominators, including those of the masses, supplies, and disutilities.

The binary length of \(C\) is \(O(L)\), since its logarithm is the sum of the logarithms of the input denominators. Its numerical value may be exponential in \(L\), but its representation has polynomial length.

Define integers \(A_t=C\mu_t\), \(S_q=C\lambda_q\), and \(H_{tq}=Cd_{tq}\). Then

\(b_t=C^{-2}\sum_{q\in Q}S_qH_{tq}\).

Thus eligibility can be tested using the exact integer comparison

\(d_{tq}\le b_t\quad\Longleftrightarrow\quad CH_{tq}\le\sum_{r\in Q}S_rH_{tr}\).

The integers \(A_t,S_q,H_{tq}\) are at most \(C\). Furthermore, the input hypotheses imply

\(\sum_r S_rH_{tr}\le C\sum_r S_r=C^2\Lambda\le C^2\).

Therefore these comparisons involve integers of \(O(L)\) bits. Computing \(C\), the scaled input values, and all eligibility tests takes polynomial time using exact integer arithmetic.

Now multiply every network capacity by \(C\). The capacities become the nonnegative integers \(S_q\) and \(A_t\), each at most \(C\). The target flow value becomes the integer \(F=\sum_q S_q\le C\). Scaling gives a bijection between feasible flows in the two networks and multiplies their values by \(C\).

Apply the Edmonds–Karp algorithm to the scaled network. For a finite directed network with nonnegative capacities, it computes a maximum flow using \(O(VE^2)\) elementary graph and arithmetic operations, independently of the numerical capacities. These hypotheses hold here. See the [MIT maximum-flow lecture notes](https://live.ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/bdafe05f4f3c20cabfd08d2fbd099f63_MIT6_046JS15_lec14A.pdf).

Here \(V=m+\tau+2\) and \(E\le m\tau+m+\tau\). Starting from zero flow, all flows and residual capacities remain integers of \(O(L)\) bits: each original arc flow stays between zero and its capacity, which is at most \(C\). Hence each arithmetic operation has polynomial bit cost.

The entire algorithm therefore runs in time polynomial in \(m,\tau,L\). If it accepts, dividing the integer class–type arc flows by \(C\) also constructs a rational feasible allocation of polynomial encoding length.

4. Conclusion

The deterministic continuous singleton proportional-allocation problem is polynomial-time solvable. The proof uses the explicitly listed support and permits each type’s mass to be split among eligible classes, exactly as stipulated. It requires no distributional assumptions; pairwise distinct disutilities are also unnecessary for the algorithm.

Under polynomial-time many-one reductions, NP-hardness of this problem would therefore imply \(\mathrm{P}=\mathrm{NP}\).
