The continuous mirror question, as graded

Given a finite set of patient-donor and NDD types, a rational mass \(\mu_t\) for each type, and a compatibility relation between types, what is the maximum patient mass that can be covered by compatible \(2\)-cycles and paths from NDDs of at most fixed length \(\ell\)? For each compatible pattern \(Q\), choose a nonnegative rate \(x_Q\), maximizing \(\sum_Q b_Q x_Q\) subject to \(\sum_Q a_{tQ}x_Q \leq \mu_t\) for every type \(t\), where \(a_{tQ}\) counts pattern \(Q\)'s use of type \(t\) and \(b_Q\) counts its patient-donor pairs.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Types are partitioned into patient-donor types \(P\) and nondirected-donor (NDD) types \(A\); \(\tau=|P|+|A|\) counts supported types, not possible biological types.
The input includes an explicit directed compatibility relation \(E\subseteq(P\cup A)\times P\), with no diagonal arcs. An arc \((s,t)\) means that a donor of type \(s\) can donate to a patient of type \(t\). Write \(m=|E|\) and let \(L\) be the total binary input length.
Fix an integer \(\ell\geq3\), independent of the input. Allowed patterns are compatible directed \(2\)-cycles of patient-donor types and compatible sequences \((a,t_1,\ldots,t_k)\), where \(a\in A\), every \(t_i\in P\), and \(1\leq k\leq\ell\). Length counts arcs. Repeated patient-donor types represent distinct individuals and consume mass once per occurrence.
For each pattern \(Q\), let \(a_{tQ}\) count occurrences of type \(t\), including its initial NDD when present, and let \(b_Q=\sum_{t\in P}a_{tQ}\). Choose divisible rates \(x_Q\geq0\) to maximize \(\operatorname{OPT}=\sum_Q b_Qx_Q\), subject to \(\sum_Q a_{tQ}x_Q\leq\mu_t\) for every type. NDD mass is consumed but contributes no patient coverage. The threshold version also supplies a binary rational \(h\in[0,1]\) and asks whether \(\operatorname{OPT}\geq h\).

For each fixed \(\ell\geq3\), is this continuous maximum-coverage problem solvable exactly in polynomial time in \(m,\tau,L\), or is its threshold version NP-hard?

Discrete maximum patient coverage by vertex-disjoint NDD paths is NP-hard for fixed \(\ell\geq3\); allowing \(2\)-cycles and paths of length at most \(2\) admits a polynomial-time algorithm. [Chang, Khare, and Shmoys](https://arxiv.org/html/2605.20070v1).
No result settling exactly the supported rational-mass problem above was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total mass to one across patient-donor and NDD types, interpreting the society as a distribution.
  • Restricted the fixed path-length bound to integers at least three, matching the hardness branch of the anchor; length counts arcs.
  • Used donor-to-patient arc orientation, no incoming arcs to NDD types, and no diagonal compatibility, consistent with incompatible patient-donor types.
  • Allowed repeated patient-donor types within a path to represent distinct individuals, counting every occurrence against type capacity.
  • Specified that each path consumes one unit of its initial NDD type per unit rate, while only patient-donor occurrences contribute to coverage.
  • Defined m as the number of explicit compatibility arcs and L as total binary input length; introduced a rational coverage threshold to specify the decision version.

Proven result. For every fixed \(\ell\geq3\), the stated continuous problem is solvable exactly in polynomial time in \(m,\tau,L\). Its threshold version belongs to \(\mathsf{P}\).

The proof uses the supported types directly; binary rational masses do not need to be expanded into individuals.

  • Enumerating all allowed patterns. Write \(p=|P|\) and \(a=|A|\), so \(p+a=\tau\). A compatible patient-donor \(2\)-cycle is specified by an unordered pair of distinct types \(s,t\in P\) for which both \((s,t)\) and \((t,s)\) belong to \(E\). There are at most \(\binom p2\) such patterns.

For each \(k\in\{1,\ldots,\ell\}\), enumerate every tuple \((a_0,t_1,\ldots,t_k)\in A\times P^k\). Retain it precisely when \((a_0,t_1)\in E\) and \((t_i,t_{i+1})\in E\) for every \(1\leq i<k\).

This enumeration allows repeated patient-donor types, as required. It imposes no distinctness test on the \(t_i\). Thus every allowed sequence appears, and every retained sequence is compatible.

If \(N\) denotes the total number of retained patterns, then

\(N\leq\binom p2+a\sum_{k=1}^{\ell}p^k\leq\tau^2+\ell\tau^{\ell+1}.\)

Since \(\ell\) is fixed, this is polynomial in \(\tau\). An adjacency table for \(E\) permits each candidate’s compatibility to be checked using at most \(\ell\) arc-membership tests. Consequently, constructing the complete pattern list takes polynomial time in \(m,\tau,L\). If the list is empty, the optimum is \(0\).

  • Constructing an exact polynomial-size linear program. Index the retained patterns by \(Q\), and define the integer matrix \(C\) by \(C_{tQ}=a_{tQ}\). Compute each entry by counting occurrences in the pattern, including its initial NDD when present. Define \(b_Q=\sum_{t\in P}C_{tQ}\).

The resulting linear program is

\(\displaystyle \max\{b^{\mathsf T}x:Cx\leq\mu,\ x\geq0\}.\)

This is exactly the optimization problem in the question: its variables are precisely all allowed pattern rates, its constraints count every occurrence against the appropriate type’s mass, and its objective counts only patient coverage.

Every matrix entry lies in \(\{0,\ldots,\ell\}\). For a chain, \(b_Q\) is its length; for a \(2\)-cycle, \(b_Q=2\). Hence \(1\leq b_Q\leq\ell\).

The program has \(N\) variables and \(\tau\) capacity constraints. Its rational right-hand side is copied directly from the input, while its integer coefficients have bounded bit length depending only on \(\ell\). Together with the bound on \(N\), these facts show that the explicit linear program has polynomial binary encoding length.

  • Exact solvability and output size. The zero vector is feasible. For every pattern \(Q\), choose a type \(t\) occurring in it. Nonnegativity and its capacity constraint imply

\(C_{tQ}x_Q\leq\sum_R C_{tR}x_R\leq\mu_t,\)

so \(0\leq x_Q\leq\mu_t/C_{tQ}\leq1\). Thus the feasible region is closed and bounded, and an optimum is attained. Moreover,

\(\displaystyle b^{\mathsf T}x=\sum_{t\in P}\sum_Q C_{tQ}x_Q\leq\sum_{t\in P}\mu_t\leq1.\)

We now apply the standard exact rational linear-programming theorem: an explicitly encoded rational linear program can be solved in polynomial time in its binary encoding length, returning an exact rational optimal solution when its optimum is finite. Exact polynomial-time algorithms, rather than merely approximate optimization, are discussed in Section 1.3 of [Gleixner and Steffy, *Linear Programming using Limited-Precision Oracles*](https://optimization-online.org/wp-content/uploads/2019/12/7507.pdf). Here the coefficients are rational, the encoding length is polynomial, feasibility holds, and the optimum is finite, so all hypotheses are satisfied.

One can also verify directly that exact output requires only polynomially many bits. Add slack variables to obtain \(Cx+s=\mu\), with \(x,s\geq0\). The augmented matrix \([C\ I_\tau]\) has full row rank, and the standard basic-solution theorem for linear programming gives an optimal basic feasible solution. Its basis matrix \(B\) is a nonsingular integer matrix of order \(\tau\), with entries bounded in absolute value by \(\ell\). Hadamard’s inequality gives

\(1\leq|\det B|\leq(\ell\sqrt{\tau})^\tau.\)

Write each mass as \(\mu_t=u_t/v_t\), with positive integer denominator \(v_t\), and put \(D=\prod_t v_t\). The binary length of \(D\) is \(O(L)\), and \(D\mu\) is integral. Cramer’s rule shows that every basic coordinate has denominator dividing \(D|\det B|\). Therefore its denominator has bit length \(O(L+\tau\log(\tau+1)+\tau\log\ell)\). Every coordinate, including each slack, lies in \([0,1]\), so its numerator has the same polynomial bound. The objective has integer coefficients and lies in \([0,1]\), giving the same conclusion for the exact optimal value.

  • Threshold decision and the discrete distinction. Once the exact rational optimum is computed, comparison with the input rational \(h\) uses integer cross-multiplication with polynomially many bits. This proves that the threshold problem belongs to \(\mathsf{P}\).

The discrete hardness result does not contradict this conclusion. It concerns vertex-disjoint, indivisible choices of paths; see Theorem 4 of [Chang, Khare, and Shmoys](https://arxiv.org/html/2605.20070v1). In the problem posed here, the variables are divisible nonnegative rates, and the type-capacity inequalities are the complete feasibility conditions. Fixed length gives polynomially many individual patterns, and continuous optimization over their rates is linear programming. No integrality property is needed.
