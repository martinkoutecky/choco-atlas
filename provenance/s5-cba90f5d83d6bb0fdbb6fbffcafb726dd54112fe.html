The continuous mirror question, as graded

Given \(m\) package kinds, supported household types \(t\) with rational masses \(\mu_t\), eligibility sets \(E_t\), values \(v_j\), and rational per-household supplies \(q_j\), maximize \(\lambda\) over mass assignments \(x_{t,a}\). Each bundle \(a\in\mathbb{Z}_{\ge 0}^m\) must be integral and satisfy \(a_j=0\) for \(j\notin E_t\); require \(\sum_a x_{t,a}=\mu_t\), \(\sum_{t,a}a_jx_{t,a}\le q_j\), and \(x_{t,a}>0\) only when \(\sum_jv_ja_j\ge\lambda\).

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge1\) be the number of package kinds. A society is given by its support: the list of \(\tau\ge1\) household types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not possible types. Each type has an eligibility set \(E_t\subseteq\{1,\ldots,m\}\). Values \(v_j\) and per-household supplies \(q_j\) are nonnegative binary rationals; \(L\) is the total input bit length.
A bundle is \(a\in\mathbb Z_{\ge0}^m\) with \(a_j=0\) whenever \(j\notin E_t\); repeated packages of an eligible kind are allowed. A mass assignment consists of nonnegative real numbers \(x_{t,a}\) satisfying \(\sum_a x_{t,a}=\mu_t\) and \(\sum_{t,a}a_jx_{t,a}\le q_j\) for every kind \(j\). It achieves \(\lambda\ge0\) if \(x_{t,a}>0\) implies \(\sum_jv_ja_j\ge\lambda\). Let \(\mathrm{OPT}\) be the supremum of achievable thresholds.

For every fixed \(\varepsilon\in(0,1/5)\), can an estimate \(\widehat\lambda\) satisfying \((1/5-\varepsilon)\mathrm{OPT}\le\widehat\lambda\le\mathrm{OPT}\) be computed in time polynomial in \(m,\tau,L\), or is obtaining this estimation guarantee NP-hard?

For finite agents and individually listed indivisible items with restricted eligibility and common item values, a polynomial-time \((1/5-\varepsilon)\)-estimation algorithm is known; estimation does not require constructing an allocation. The finite-item configuration LP optimum can also be approximated to arbitrary desired accuracy in polynomial time. [Asadpour–Feige–Saberi](https://www.wisdom.weizmann.ac.il/~feige/mypapers/santaclaus1.pdf)
No result settling this precise mass model with unrestricted integral multiplicities was verified.

Modeling choices made when packaging the task

  • Normalized total household mass to one, making the supplied per-household quantities the aggregate supply bounds.
  • Specified nonnegative binary-rational values and supplies, following the discrete nonnegative-value model and a finite binary input encoding.
  • Specified nonnegative real assignment masses; integrality applies to each household's bundle.
  • Allowed empty eligibility sets, zero supplies, and zero values, which the discrete definition does not exclude.
  • Retained unrestricted repeated packages within bundles, as explicitly required by the graded continuous question.
  • Defined the optimum as a supremum so the task does not presuppose attainment in the infinite bundle domain.
  • Made the approximation an estimate of the optimum, with a one-sided multiplicative interval, rather than requiring an allocation.

Result

The requested estimate is computable in polynomial time. In fact, the mass model admits a fully polynomial approximation scheme: for every rational accuracy parameter \(\alpha\in(0,1)\), one can compute an achievable threshold \(\widehat\lambda\) satisfying
\[ (1-\alpha)\mathrm{OPT}\le\widehat\lambda\le\mathrm{OPT} \]
in time polynomial in \(m,\tau,L,1/\alpha\).

The proof below constructs polynomial-size linear programs representing distributions of integral bundles. It allows binary-encoded, unrestricted multiplicities and does not expand rational masses into individually listed households.

1. An upper bound and an exact test for zero optimum

Write \(v\cdot a=\sum_jv_ja_j\), and let
\[ W=\sum_{j=1}^m v_jq_j. \]

If an assignment achieves \(\lambda\), then
\[ \lambda =\lambda\sum_{t,a}x_{t,a} \le\sum_{t,a}(v\cdot a)x_{t,a} =\sum_jv_j\sum_{t,a}a_jx_{t,a} \le W. \]
The interchange of sums is valid because all summands are nonnegative. Thus \(\mathrm{OPT}\le W\).

Let \(J_+=\{j:v_j>0\}\). If \(J_+\) is empty, then \(\mathrm{OPT}=0\). Otherwise define
\[ v_{\min}=\min_{j\in J_+}v_j>0. \]

Consider the following rational linear feasibility problem, with variables \(y_{tj}\) for \(j\in E_t\cap J_+\):
\[ y_{tj}\ge0,\qquad \sum_{j\in E_t\cap J_+}y_{tj}=\mu_t,\qquad \sum_{t:j\in E_t}y_{tj}\le q_j. \]

Claim. This system is feasible if and only if a positive threshold is achievable.

If the system is feasible, assign mass \(y_{tj}\) of type \(t\) the singleton bundle consisting of one package of kind \(j\). Every such bundle has value at least \(v_{\min}\), so this achieves \(v_{\min}\).

Conversely, suppose an assignment achieves some \(\lambda>0\). Every bundle used with positive mass contains at least one package of positive value. For each such bundle, select one positive-value package and discard everything else. Aggregating the resulting singleton assignments gives feasible variables \(y_{tj}\): each type retains its entire mass, and no resource consumption increases.

Consequently, infeasibility proves \(\mathrm{OPT}=0\). From now on suppose the system is feasible. We then have
\[ 0<v_{\min}\le\mathrm{OPT}\le W. \]

2. Compressing multiplicities at a candidate threshold

Fix a positive rational candidate threshold \(\lambda\) and a rational parameter \(\delta\in(0,1)\).

For each \(j\in J_+\), set
\[ B_j=\left\lceil\frac{\lambda}{v_j}\right\rceil. \]

Any eligible bundle of value at least \(\lambda\) can be replaced, without increasing any coordinate, by one satisfying
\[ a_j=0\quad(j\notin J_+),\qquad a_j\le B_j\quad(j\in J_+). \]

Indeed, first discard all zero-value packages and then cap each remaining coordinate at \(B_j\). If no coordinate changes, the value is unchanged. If some coordinate changes, that coordinate alone contributes \(B_jv_j\ge\lambda\) after capping.

Applying this replacement to an assignment preserves its type masses and cannot increase resource consumption. Although the original assignment may have countably many positive entries, the capped bundles lie in a finite set, so their masses can be aggregated.

For each kind \(j\in J_+\), introduce binary blocks with multiplicities
\[ 1,2,4,\ldots,2^{\lfloor\log_2B_j\rfloor}. \]
Every integer between zero and \(B_j\) is the sum of a subset of these blocks, by binary expansion.

Some subsets represent counts exceeding \(B_j\). This causes no problem: unrestricted multiplicities are allowed in the original model.

Enumerate all blocks by \(i=1,\ldots,n\). Block \(i\) has kind \(j_i\), multiplicity \(b_i\), and true value
\[ z_i=b_iv_{j_i}. \]
A type may select block \(i\) precisely when \(j_i\in E_t\).

3. Rounding values

Define
\[ K=\left\lceil\frac n\delta\right\rceil,\qquad w_i=\left\lfloor\frac K\lambda\min\{z_i,\lambda\}\right\rfloor,\qquad T=K-n. \]
Here \(w_i\) is an integer between zero and \(K\), and \(T>0\).

Two implications will be used.

Completeness of rounding. If a subset \(S\) of blocks has true value at least \(\lambda\), then
\[ \sum_{i\in S}w_i\ge T. \]

To prove this, first observe that
\[ \sum_{i\in S}\min\{z_i,\lambda\}\ge\lambda. \]
If a selected block has value at least \(\lambda\), its capped value already equals \(\lambda\); otherwise capping changes nothing. Therefore
\[ \sum_{i\in S}w_i \ge\frac K\lambda\sum_{i\in S}\min\{z_i,\lambda\}-|S| \ge K-n=T. \]

Soundness of rounding. If \(\sum_{i\in S}w_i\ge T\), then
\[ \sum_{i\in S}z_i \ge\frac{\lambda}{K}\sum_{i\in S}w_i \ge\lambda\frac{K-n}{K} \ge(1-\delta)\lambda. \]
The first inequality follows from the definition of \(w_i\); the last follows from \(K\ge n/\delta\).

Thus rounded coverage of \(T\) certifies a true value of at least \((1-\delta)\lambda\).

4. A polynomial-size flow LP

For each supported type \(t\), construct a directed acyclic graph with vertices
\[ (i,s),\qquad 0\le i\le n,\quad 0\le s\le T. \]
The state records the rounded value accumulated so far, capped at \(T\).

For every block index \(i\) and state \(s\), include:

  • a skip arc from \((i-1,s)\) to \((i,s)\);
  • if \(j_i\in E_t\), a take arc from \((i-1,s)\) to \((i,\min\{T,s+w_i\})\).

Keep skip and take arcs distinct even when their endpoints coincide. A take arc consumes \(b_i\) packages of kind \(j_i\); a skip arc consumes none.

Introduce nonnegative arc-flow variables \(f^t_e\). Impose flow balance
\[ \sum_{e\text{ leaving }u}f^t_e-\sum_{e\text{ entering }u}f^t_e = \begin{cases} \mu_t,&u=(0,0),\\ -\mu_t,&u=(n,T),\\ 0,&\text{otherwise}. \end{cases} \]
Finally impose the supply inequalities
\[ \sum_t\sum_{\substack{e\text{ a take arc}\\j_{i(e)}=j}} b_{i(e)}f^t_e\le q_j \qquad(j=1,\ldots,m). \]

Call this feasibility problem \(P(\lambda,\delta)\).

Completeness

If \(\lambda\) is achievable, then \(P(\lambda,\delta)\) is feasible.

Take an assignment achieving \(\lambda\), discard zero-value packages, and cap its coordinates as in Section 2. Represent every resulting coordinate by its binary blocks. Each resulting bundle has value at least \(\lambda\), so its selected blocks have rounded total at least \(T\), by Section 3.

Every such selection gives a path from \((0,0)\) to \((n,T)\) in the appropriate type graph. Send the bundle’s assigned mass along that path. Flow balances hold because the total mass of type \(t\) is \(\mu_t\). The supply constraints hold because binary representation preserves capped multiplicities, and capping only decreased consumption.

Soundness

If \(P(\lambda,\delta)\) is feasible, then \((1-\delta)\lambda\) is achievable.

For each type, decompose its flow into weighted source-to-target paths. Here this standard decomposition follows directly from acyclicity: follow positive-flow arcs from the source; conservation prevents termination at any other vertex except the target. Subtract the minimum flow on the resulting path and repeat. Each subtraction eliminates a positive-flow arc, so finitely many paths suffice.

Every path selects integral multiplicities of eligible kinds. Its final state is \(T\), which means that its selected blocks have rounded total at least \(T\). Soundness of rounding therefore gives true value at least \((1-\delta)\lambda\).

Assign each path’s weight to its represented bundle. The path weights sum to \(\mu_t\), and their aggregate resource consumption is exactly the consumption recorded by the arc-flow supply constraints. Hence this is a valid mass assignment.

We have proved the two-sided guarantee
\[ \lambda\text{ achievable}\ \Longrightarrow\ P(\lambda,\delta)\text{ feasible} \ \Longrightarrow\ (1-\delta)\lambda\text{ achievable}. \]

5. Searching for an estimate

Let the requested accuracy be a rational \(\alpha\in(0,1)\), and set
\[ \delta=\eta=\frac{\alpha}{2}. \]

Initialize
\[ \ell=v_{\min},\qquad h=W. \]
The lower endpoint is achievable, and hence its flow LP is feasible.

While \(h-\ell>\eta v_{\min}\), test \(P(\lambda,\delta)\) at the midpoint \(\lambda=(\ell+h)/2\).

  • If the LP is feasible, set \(\ell=\lambda\).
  • If it is infeasible, set \(h=\lambda\).

Throughout the search, \((1-\delta)\ell\) is achievable, by soundness.

Also, \(h\ge\mathrm{OPT}\) remains true. To verify the only nontrivial update, an infeasible LP implies that \(\lambda\) is not achievable, by completeness. Achievable thresholds are downward closed. Thus, if \(\mathrm{OPT}>\lambda\), some achievable threshold would exceed \(\lambda\), making \(\lambda\) achievable—a contradiction. Therefore \(\mathrm{OPT}\le\lambda\).

This argument does not assume that the supremum is attained, or that the approximate LP tests are monotone.

At termination, output
\[ \widehat\lambda=(1-\delta)\ell. \]
It is achievable, so \(\widehat\lambda\le\mathrm{OPT}\). Moreover,
\[ \ell\ge h-\eta v_{\min} \ge\mathrm{OPT}-\eta v_{\min} \ge(1-\eta)\mathrm{OPT}. \]
Consequently,
\[ \widehat\lambda \ge(1-\delta)(1-\eta)\mathrm{OPT} =\left(1-\frac{\alpha}{2}\right)^2\mathrm{OPT} \ge(1-\alpha)\mathrm{OPT}. \]

6. Bit complexity and conclusion

Every positive input rational lies between \(2^{-L}\) and \(2^L\), using conservative bounds. Thus
\[ W\le m2^{2L},\qquad v_{\min}\ge2^{-L},\qquad \frac{W}{v_{\min}}\le m2^{3L}. \]

Every tested threshold lies between \(v_{\min}\) and \(W\). Hence each \(B_j\) has \(O(L+\log m)\) bits, and the total number of binary blocks satisfies
\[ n=O\bigl(m(L+\log m)\bigr). \]
Since \(K=\lceil n/\delta\rceil\), the graphs together have \(O(\tau nK)\) vertices and arcs. This is polynomial in \(m,\tau,L,1/\alpha\).

The search needs \(O(L+\log m+\log(1/\alpha))\) midpoint tests. Midpoints have polynomial encoding length: after \(r\) iterations, each endpoint is \(v_{\min}+\theta(W-v_{\min})\), where \(\theta\) is a dyadic rational with denominator dividing \(2^r\).

All LP coefficients also have polynomial encoding length. Exact feasibility of an explicitly given rational linear program is decidable in polynomial time in its dimensions and total binary encoding length. Those hypotheses hold for both the initial singleton LP and every flow LP above. This proves the claimed running time.

For the question as stated, run the scheme with the fixed choice \(\alpha=1/2\). It returns
\[ \frac12\mathrm{OPT}\le\widehat\lambda\le\mathrm{OPT}, \]
which implies the requested \((1/5-\varepsilon)\) guarantee for every fixed \(\varepsilon\in(0,1/5)\).

The [Asadpour–Feige–Saberi finite-item theorem](https://www.wisdom.weizmann.ac.il/~feige/mypapers/santaclaus1.pdf) concerns rounding fractional configurations to allocations for individual players. The mass model instead permits those configurations to be distributed directly across each type’s mass. The flow construction exploits precisely that permission.
