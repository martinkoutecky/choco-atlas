The continuous mirror question, as graded

Given finitely many types \(T\), rational masses \(\mu_t\) summing to \(1\), waiting costs \(\theta_t\), a priority poset on types, and a specified block order for tied costs, arrange type \(t\) on an interval \(I_t\subseteq[0,1]\) of length \(\mu_t\) in nonincreasing order of \(\theta_t\). Compute each type’s limiting per-capita Priority-value utility \(p_t=-\sum_{u\in T}\mu_u h(t,u)\min\{\theta_t,\theta_u\}\), where \(h(t,u)=1\) if \(t\) has priority over \(u\), \(0\) if \(u\) has priority over \(t\), and \(1/2\) otherwise, including \(h(t,t)=1/2\); and its transfer profile \(z_t(q)=p_t+\theta_t q\) for \(q\in I_t\). Prove these are the limits of the discrete utilities and transfers scaled by population size, and that \(\sum_{t\in T}\int_{I_t}z_t(q)\,dq=0\).

Order types by nonincreasing waiting cost, using a specified total block order within each cost tie. Consecutive intervals \(I_t\subseteq[0,1]\) have lengths \(\mu_t\); endpoint assignments are immaterial.
Define \(h(t,u)=1\) when \(t\) strictly has priority over \(u\), \(h(t,u)=0\) for the reverse relation, and \(h(t,u)=\tfrac12\) for incomparable types or \(t=u\). Candidate utilities and transfer profiles are \(p_t=-\sum_{u\in T}\mu_u h(t,u)\min\{\theta_t,\theta_u\}\) and \(z_t(q)=p_t+\theta_t q\) for \(q\in I_t\).
For each population size \(n\) with all \(n\mu_t\) integral, replicate type \(t\) exactly \(n\mu_t\) times. Distinct replicas of the same type are incomparable; replicas of different types inherit strict type priorities. Queue these unit-service-time agents in the specified type blocks, with ranks \(\sigma_n(i)\).
For a coalition \(S\), its optimistic queueing worth is \(v_n(S)=-\min_{\rho:S\to\{1,\ldots,|S|\}\text{ bijective}}\sum_{i\in S}(\rho(i)-1)\theta_{t(i)}\), with \(v_n(\varnothing)=0\). The Priority value divides each coalition's Harsanyi dividend equally among its poset-maximal members; write its payoff as \(P_i^{(n)}\). The associated transfer is \(a_i^{(n)}=P_i^{(n)}+\theta_{t(i)}(\sigma_n(i)-1)\).
Is exact computation of all \(p_t\), interval endpoints, and affine profiles \(z_t\) polynomial-time in \(\tau,L\), or NP-hard?
Do these candidates satisfy \(P_{i_n}^{(n)}/n\to p_t\) and \(a_{i_n}^{(n)}/n\to z_t(q)\) for every sequence of type-\(t\) replicas with \((\sigma_n(i_n)-1)/n\to q\in\overline{I_t}\), and \(\sum_{t\in T}\int_{I_t}z_t(q)\,dq=0\)?

1. Result

Exact computation is polynomial-time in \(\tau,L\), and both replica limits and the budget-balance identity hold.

In fact, for every admissible population size \(n\) and every type-\(t\) replica \(i\), there is an exact identity:
\[ P_i^{(n)}=n p_t+\frac{\theta_t}{2}. \]
The correction accounts for excluding the replica itself from its same-type pair interactions.

The discrete pair allocation agrees with Proposition 6 of [Béal–Ferrières–Solal](https://crese.univ-fcomte.fr/uploads/wp/WP-2020-02.pdf). The argument below derives it directly from the definitions.

2. Pair decomposition of the queueing game

Consider any finite agent set \(N\), writing \(\theta_i=\theta_{t(i)}\). For a coalition \(S\) and a queue \(\rho\), its waiting cost is
\[ \sum_{i\in S}(\rho(i)-1)\theta_i = \sum_{\substack{i,j\in S\\ \rho(j)<\rho(i)}}\theta_i. \]

Each unordered pair \(\{i,j\}\subseteq S\) contributes the waiting cost of whichever member is later. Its contribution is therefore at least \(\min\{\theta_i,\theta_j\}\). A queue with nonincreasing waiting costs attains this lower bound for every pair simultaneously: the later member has the smaller waiting cost, with equality also when costs tie. Consequently,
\[ v_n(S)=-\sum_{\{i,j\}\subseteq S}\min\{\theta_i,\theta_j\}. \]

For completeness, the Harsanyi dividends are characterized recursively by
\[ \Delta(\varnothing)=0,\qquad \Delta(S)=v_n(S)-\sum_{A\subsetneq S}\Delta(A) \]
for nonempty \(S\). Thus they are uniquely determined by induction on coalition size. The pair decomposition exhibits them explicitly:
\[ \Delta(\{i,j\})=-\min\{\theta_i,\theta_j\}, \qquad \Delta(S)=0\quad\text{when }|S|\ne 2. \]
Indeed, summing these proposed dividends over subsets of any coalition reproduces its worth.

For a pair of distinct replicas \(i,j\), its maximal members are:

  • only \(i\), if \(t(i)\) strictly has priority over \(t(j)\);
  • only \(j\), for the reverse priority;
  • both members, if their types are incomparable or identical.

Hence the fraction of the pair dividend allocated to \(i\) is exactly \(h(t(i),t(j))\). Since all other dividends vanish,
\[ P_i^{(n)} = -\sum_{j\in N\setminus\{i\}} h(t(i),t(j))\min\{\theta_{t(i)},\theta_{t(j)}\}. \]

3. Exact replica identities and limits

Fix a type \(t\). There are \(n\mu_u\) replicas of each type \(u\). For \(u=t\), the sum for a type-\(t\) replica includes only \(n\mu_t-1\) agents. Therefore
\[ \begin{aligned} P_i^{(n)} &= -\sum_{u\ne t}n\mu_u h(t,u)\min\{\theta_t,\theta_u\} -\frac{n\mu_t-1}{2}\theta_t\\ &=n p_t+\frac{\theta_t}{2}. \end{aligned} \]
This holds for every replica of type \(t\), independently of its queue rank.

Admissible population sizes are unbounded: any positive multiple of a common denominator of the masses makes all \(n\mu_t\) integral. Taking \(n\) to infinity through such sizes gives
\[ \frac{P_{i_n}^{(n)}}n =p_t+\frac{\theta_t}{2n} \longrightarrow p_t. \]

By the definition of transfers,
\[ \frac{a_i^{(n)}}n = p_t+\theta_t\frac{\sigma_n(i)-1}{n} +\frac{\theta_t}{2n}. \]
Thus whenever \((\sigma_n(i_n)-1)/n\longrightarrow q\),
\[ \frac{a_{i_n}^{(n)}}n\longrightarrow p_t+\theta_tq=z_t(q). \]

To verify the interval interpretation, write the prescribed type order as \(t_1,\ldots,t_\tau\), and set
\[ b_0=0,\qquad b_k=\sum_{\ell=1}^{k}\mu_{t_\ell}. \]
The closure of \(I_{t_k}\) is \([b_{k-1},b_k]\). Its replicas have ranks
\[ nb_{k-1}+1,\ldots,nb_k, \]
so their normalized waiting positions lie between \(b_{k-1}\) and \(b_k-1/n\). Every limit position therefore belongs to the required closure. Because each type’s affine profile is continuous, the argument includes either endpoint.

4. Continuous budget balance

For every \(t,u\), including \(t=u\),
\[ h(t,u)+h(u,t)=1. \]
For distinct comparable types this follows from the two opposite priority relations; for incomparable or identical types both terms equal \(1/2\).

Let
\[ K=\sum_{t,u\in T}\mu_t\mu_u\min\{\theta_t,\theta_u\}. \]
Interchanging the indices in the defining sum for the weighted utilities gives
\[ \begin{aligned} 2\sum_t\mu_t p_t &= -\sum_{t,u}\mu_t\mu_u \bigl(h(t,u)+h(u,t)\bigr)\min\{\theta_t,\theta_u\}\\ &=-K. \end{aligned} \]
Thus \(\sum_t\mu_t p_t=-K/2\).

The waiting-cost part of the integrals is
\[ \begin{aligned} \sum_{k=1}^{\tau}\int_{b_{k-1}}^{b_k}\theta_{t_k}q\,dq &= \sum_{k=1}^{\tau} \theta_{t_k}\left(\mu_{t_k}b_{k-1}+\frac{\mu_{t_k}^2}{2}\right)\\ &= \sum_{\ell<k}\mu_{t_\ell}\mu_{t_k}\theta_{t_k} +\frac12\sum_k\mu_{t_k}^2\theta_{t_k}. \end{aligned} \]
Since the order has nonincreasing waiting costs,
\(\min\{\theta_{t_\ell},\theta_{t_k}\}=\theta_{t_k}\) whenever \(\ell<k\), including cost ties. Splitting \(K\) into its diagonal terms and its two equal off-diagonal sums shows that the last expression equals \(K/2\).

Consequently,
\[ \sum_{t\in T}\int_{I_t}z_t(q)\,dq = \sum_t\mu_t p_t+\frac K2=0. \]
Endpoint assignments do not change any integral.

5. Exact polynomial-time computation

The output consists of each rational intercept \(p_t\), each interval’s two rational endpoints, and each rational slope \(\theta_t\).

An exact algorithm proceeds as follows:

  • Determine all strict priority relations. If the explicit poset representation uses cover relations, compute their transitive closure in polynomial time, for example using \(O(\tau^3)\) Boolean operations.
  • Sort types by rational waiting cost, applying the specified total order within ties.
  • Compute the endpoints \(b_k\) by prefix sums of masses.
  • Evaluate each \(p_t\) using its \(\tau\)-term defining sum, then output \(z_t(q)=p_t+\theta_tq\) with its interval.

It remains to check bit complexity, rather than merely count arithmetic operations. Write the input rationals as
\[ \mu_t=\frac{a_t}{d_t},\qquad \theta_t=\frac{c_t}{e_t}, \]
with positive denominators. Set \(D=\prod_t d_t\) and \(E=\prod_t e_t\). Both products have \(O(L)\) bits because the sum of their factors’ bit lengths is bounded by the total input length.

Define integers
\[ A_t=a_t(D/d_t),\qquad B_t=c_t(E/e_t),\qquad H_{tu}=2h(t,u). \]
Here \(H_{tu}\) belongs to \(\{0,1,2\}\). Every intercept can then be computed as
\[ p_t= -\frac{\sum_u A_uH_{tu}\min\{B_t,B_u\}}{2DE}. \]
Each endpoint has the form \((\sum_{\ell\le k}A_{t_\ell})/D\).

All integers in these computations have \(O(L+\log\tau)\) bits: multiplication adds operand bit lengths, and summing \(\tau\) terms adds at most \(O(\log\tau)\) bits. Exact integer arithmetic, rational comparisons, and optional reduction by greatest common divisors therefore take polynomial time. There are polynomially many operations and only \(\tau\) output records.

This algorithm uses the support directly and never constructs a replicated population. Thus potentially large admissible population sizes do not affect the computation.
