The continuous mirror question, as graded

Given \(N\) concepts, worker response types \(r\) with rational population masses \(\mu_r\), and per-type answer frequencies \(v_{r,q,a}\) for path query \(q\) and answer \(a\), form \(Q_\mu(T)\propto \pi_0(T)\exp(\sum_{r,q,a}\mu_r v_{r,q,a}\log f_r(a\mid T,q))\) over rooted hierarchies \(T\). For \(P_\Lambda(T)=\exp(\sum_{e\in T}\lambda_e)/Z(\Lambda)\), find \(\Lambda\) within \(\epsilon\) of the minimum of \(\mathbb{E}_{T\sim Q_\mu}[-\log P_\Lambda(T)]+\beta\sum_e|\lambda_e|\); determine the convergence and finite-precision complexity in \(N\), support size \(\tau\), input bit length \(L\), and \(\epsilon^{-1}\).

A society is given by its support: a list of \(\tau\) worker types with positive binary-rational masses \(\mu_r\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies a binary-rational error rate \(0<\gamma_r<1\) and nonnegative binary-rational answer frequencies \(v_{r,q,a}\), interpreted as expected answer counts per worker, without normalization. Queries \(q=(i,j)\) concern distinct concepts, answers satisfy \(a\in\{0,1\}\), and omitted frequencies are zero.
Write \(h_q(T)=1\) precisely when \(T\) contains a directed path from \(i\) to \(j\). Define \(f_r(a\mid T,q)=1-\gamma_r\) if \(a=h_q(T)\), and \(f_r(a\mid T,q)=\gamma_r\) otherwise.

Result

The problem is \(\mathrm{NP}\)-hard, even when \(\tau=1\), \(\mu_1=1\), \(\gamma_1=1/4\), \(\beta=1/64\), and \(\epsilon=1/8192\).

More precisely, one call to an algorithm returning any valid approximate minimizer, followed by polynomial-time finite-precision computation, suffices to solve an \(\mathrm{NP}\)-complete decision problem. Thus the requested deterministic polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The proof uses the permitted, unnormalized answer frequencies. Some frequencies have exponentially large values, but their binary encodings have polynomial length.

1. The source problem

We reduce from directed Feedback Arc Set: given a loopless directed graph \(G=([n],A)\) and an integer \(k\), decide whether deleting at most \(k\) arcs makes the graph acyclic. This problem is \(\mathrm{NP}\)-complete; Karp’s reduction produces loopless graphs without parallel arcs. [Karp, *Reducibility among Combinatorial Problems*, problem 8](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

Write \(b=|A|\). For a total order \(\sigma\) of the vertices, let \(H(\sigma)\) count the arcs whose source precedes their target. Then

\(\displaystyle \operatorname{fas}(G)=b-\max_\sigma H(\sigma).\)

Indeed, deleting the backward arcs of any order leaves an acyclic graph, giving one inequality. Conversely, after deleting a minimum feedback arc set, a topological order of the remaining graph makes every retained arc forward, giving the reverse inequality.

We therefore need to recover an order maximizing \(H\).

2. An ancestry score with a unique optimal path

Set \(N=n\), and introduce the fixed root \(0\). Define

\(\displaystyle d=\binom n2,\qquad W=2^d,\qquad B=W(b+1).\)

Fix a bijection \(\ell\) from the unordered pairs, represented as \(i<j\), to \(\{0,\ldots,d-1\}\). For each rooted arborescence \(T\), define

\(\displaystyle C(T)=\sum_{\substack{i,j\in[n]\\i\ne j}}h_{(i,j)}(T),\)

\(\displaystyle H(T)=\sum_{(i,j)\in A}h_{(i,j)}(T),\)

\(\displaystyle J(T)=\sum_{1\le i<j\le n}2^{\ell(i,j)}h_{(i,j)}(T),\)

and

\(\displaystyle S(T)=B\,C(T)+W\,H(T)+J(T).\)

These quantities satisfy

\(\displaystyle 0\le C(T)\le d,\qquad 0\le H(T)\le b,\qquad 0\le J(T)\le W-1.\)

The bound on \(C\) holds because two distinct vertices cannot each be an ancestor of the other.

Moreover, \(C(T)=d\) precisely when \(T\) is a path starting at \(0\) and visiting all concept vertices. To see this, equality means every pair of concept vertices is comparable by ancestry. They therefore form a single chain. Consecutive vertices in that chain must be connected by an edge, because any intermediate vertex would also belong to the chain. The first concept vertex must likewise be a child of \(0\).

For a tree that is not such a path,

\(\displaystyle S(T)\le B(d-1)+Wb+(W-1)=Bd-1.\)

Every spanning path has score at least \(Bd\). Thus every maximizer of \(S\) is a spanning path.

On a path corresponding to an order \(\sigma\),

\(\displaystyle S(T)=Bd+W\,H(\sigma)+J(T).\)

Since \(J\) lies between \(0\) and \(W-1\), maximizing this expression first maximizes \(H\). Among orders with equal \(H\), it maximizes \(J\).

Distinct total orders have distinct vectors of pairwise comparisons. The powers of two in \(J\) encode that vector injectively, so distinct orders have distinct \(J\). Consequently:

Proven claim. There is a unique maximizing tree \(T^\star\), it is a spanning path, and its order maximizes \(H\). Since every score is an integer,

\(\displaystyle S(T^\star)-S(T)\ge 1\quad\text{for every }T\ne T^\star.\)

3. Encoding the score in the permitted posterior

Use one worker type with mass \(1\) and error rate \(1/4\). Put

\(\displaystyle K=n^2+8.\)

For every ordered pair of distinct concept vertices, supply only answer-\(1\) frequency, as follows:

\(\displaystyle v_{1,(i,j),1}=K\left(B+W\,\mathbf 1_{\{(i,j)\in A\}}+t_{ij}\right),\)

where \(t_{ij}=2^{\ell(i,j)}\) if \(i<j\), and \(t_{ij}=0\) otherwise. All answer-\(0\) frequencies are zero.

These are nonnegative integers, hence admissible binary-rational frequencies. Each requires only \(O(n^2+\log n)\) bits, and there are \(n(n-1)\) supplied frequencies. The entire construction has polynomial bit length.

For error rate \(1/4\),

\(\displaystyle f_1(1\mid T,(i,j))=\frac14\,3^{h_{(i,j)}(T)}.\)

The factors \(1/4\), and the uniform prior, contribute only constants independent of \(T\). Hence the resulting posterior is exactly

\(\displaystyle Q(T)=\frac{3^{KS(T)}}{\sum_{U\in\mathcal T}3^{KS(U)}}.\)

Each concept vertex has \(n\) possible parents, so \(|\mathcal T|\le n^n\le 2^{n^2}\). Using the score gap,

\(\displaystyle \frac{Q(T\ne T^\star)}{Q(T^\star)} =\sum_{T\ne T^\star}3^{-K(S(T^\star)-S(T))} \le |\mathcal T|\,3^{-K} \le 2^{-8}.\)

It follows that \(Q(T\ne T^\star)\le 1/256\). Define its edge marginals by \(p_e=Q(e\in T)\). Then

\(\displaystyle p_e\ge \frac{255}{256}\quad(e\in T^\star),\qquad p_e\le \frac1{256}\quad(e\notin T^\star).\)

Thus constant-accuracy posterior edge marginals would identify \(T^\star\).

4. Every sufficiently accurate optimizer reveals those marginals

For arbitrary posterior edge marginals \(p_e\), the objective equals

\(\displaystyle F(\Lambda)=\log Z(\Lambda)-\sum_e p_e\lambda_e+\beta\|\Lambda\|_1.\)

Its cross-entropy term is nonnegative, so \(F(\Lambda)\ge\beta\|\Lambda\|_1\). Since \(F\) is continuous and \(\beta>0\), its minimum is attained.

Let \(s_e(\Lambda)=P_\Lambda(e\in T)\), and write

\(\displaystyle \phi(\Lambda)=\log Z(\Lambda)-\sum_e p_e\lambda_e.\)

Differentiating the finite partition sum gives

\(\displaystyle \partial_e\phi(\Lambda)=s_e(\Lambda)-p_e,\qquad \partial_e^2\phi(\Lambda)=s_e(\Lambda)(1-s_e(\Lambda))\le\frac14.\)

Suppose \(F(\widehat\Lambda)\le\min F+\epsilon\). We claim that every coordinate satisfies

\(\displaystyle |s_e(\widehat\Lambda)-p_e|\le\beta+\sqrt{\epsilon/2}.\)

To prove this, put \(g=s_e(\widehat\Lambda)-p_e\). If \(|g|\le\beta\), the claim is immediate. Otherwise put \(a=|g|-\beta>0\), and change coordinate \(e\) by \(t=-4a\,\operatorname{sign}(g)\). The second-derivative bound and the triangle inequality for the penalty give

\(\displaystyle F(\widehat\Lambda+t\mathbf e_e)-F(\widehat\Lambda) \le gt+\frac{t^2}{8}+\beta|t| =-2a^2. \)

Therefore \(2a^2\le F(\widehat\Lambda)-\min F\le\epsilon\), proving the claim.

With the fixed values \(\beta=1/64\) and \(\epsilon=1/8192\), this yields

\(\displaystyle |s_e(\widehat\Lambda)-p_e|\le\frac3{128}.\)

It remains to compute the model marginals \(s_e(\widehat\Lambda)\) in polynomial finite-precision time.

5. Polynomial-time finite-precision decoding

Bounding the returned parameters

At \(\Lambda=0\), the model is uniform, so \(F(0)=\log|\mathcal T|\). Every valid returned optimizer therefore satisfies

\(\displaystyle \beta\|\widehat\Lambda\|_1 \le F(\widehat\Lambda) \le\log|\mathcal T|+\epsilon. \)

Consequently,

\(\displaystyle \|\widehat\Lambda\|_1\le64(n^2+1)=:M.\)

This numerical bound is polynomial in \(n\), even though the posterior frequencies can have exponentially large values.

Approximating the edge weights

Set \(\delta=1/(1024n)\). For each edge, compute a positive rational weight \(u_e\) satisfying

\(\displaystyle |\log u_e-\widehat\lambda_e|\le\delta.\)

This can be done in time polynomial in \(n\) and the bit length of \(\widehat\Lambda\). Here is an explicit justification.

For rational \(x\in[0,M]\), truncate the exponential Taylor series at degree \(r\). Taylor’s remainder and \( (r+1)!\ge((r+1)/e)^{r+1}\) imply relative error at most

\(\displaystyle \frac{x^{r+1}}{(r+1)!} \le\left(\frac{eM}{r+1}\right)^{r+1}. \)

Choose \(r+1\ge6M\) and \(2^{-(r+1)}\le\delta/2\). The relative error is then at most \(\delta/2\), which implies logarithmic error at most \(\delta\). For negative \(x\), take the reciprocal of the approximation to \(e^{-x}\). The number of terms and the bit lengths of all exact rational calculations are polynomial.

For every tree, its product of rounded weights differs from its original weight by a factor between \(e^{-n\delta}\) and \(e^{n\delta}\). After normalization, the probability ratio lies between \(e^{-2n\delta}\) and \(e^{2n\delta}\). Therefore every event probability changes by at most

\(\displaystyle e^{2n\delta}-1=e^{1/512}-1<\frac1{128}.\)

Computing marginals from rational weights

For completeness, the required determinant identity has a direct proof. Let \(\mathbf e_1,\ldots,\mathbf e_n\) be the standard basis and set \(\mathbf e_0=0\). Define an \(n\times n\) matrix whose column \(j\) is

\(\displaystyle \sum_{\substack{0\le i\le n\\i\ne j}}u_{ij}(\mathbf e_j-\mathbf e_i).\)

By multilinearity, its determinant is a sum over assignments of one parent to each concept vertex. An assignment containing a directed cycle contributes zero: the corresponding columns sum to zero around that cycle. Every other assignment reaches \(0\) and defines an arborescence. Ordering vertices with parents before children makes its selected-column matrix triangular with diagonal entries \(1\), so its determinant is \(1\).

Thus the matrix determinant equals

\(\displaystyle Z_u=\sum_{T\in\mathcal T}\prod_{e\in T}u_e.\)

Let \(Z_u^{(-e)}\) be the same determinant after setting weight \(u_e\) to zero. The exact rational marginal under these rounded weights is

\(\displaystyle \widetilde s_e=1-\frac{Z_u^{(-e)}}{Z_u}.\)

There are \(n^2\) edges. All these rational determinants can be computed exactly in polynomial time: clearing denominators gives integer matrices of polynomial bit length, and fraction-free elimination computes their determinants with polynomial bit complexity.

Combining the rounding estimate with Section 4 gives

\(\displaystyle |\widetilde s_e-p_e|<\frac1{128}+\frac3{128}=\frac1{32}.\)

Together with the posterior concentration bounds,

\(\displaystyle \widetilde s_e>\frac12\quad\Longleftrightarrow\quad e\in T^\star.\)

Hence every valid approximate optimizer permits polynomial-time recovery of the entire optimal path.

6. Completing the reduction

Given a Feedback Arc Set instance:

  • Construct the posterior of Section 3, with the fixed \(\beta\) and \(\epsilon\).
  • Obtain any rational \(\widehat\Lambda\) satisfying the requested objective guarantee.
  • Compute \(\widetilde s_e\) as above and retain precisely the edges with \(\widetilde s_e>1/2\).
  • Read the resulting path order \(\sigma^\star\), count its forward arcs, and answer yes exactly when \(b-H(\sigma^\star)\le k\).

The construction is polynomial in the original input length. The decoder is polynomial in that length and the encoding length of the returned vector. A polynomial-time optimizer necessarily returns a polynomial-length vector, so the entire decision procedure would be polynomial-time.

This establishes \(\mathrm{NP}\)-hardness through a single optimizer call, already for the fixed constants stated above.
