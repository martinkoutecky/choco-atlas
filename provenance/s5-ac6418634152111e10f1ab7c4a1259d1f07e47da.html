Theorem 3.3 — class: algorithmic

The continuous mirror question, as graded

Given a fixed finite set of complete agent types \(T\), rational masses \(\mu_t\) summing to \(1\), a population scale \(n\) with \(n\mu_t\) integral, per-type allocations \(y_t\), primitive integer signature coefficients \(a_t\), capacities \(b_t\), and allowed type-pair weights \(w_{tu}\), choose coalition masses \(x_t\in[0,\mu_t]\) and a feasible fractional \(b\)-matching \(z\), with \(\sum_{u\ne t}z_{tu}+2z_{tt}\le b_t x_t\). Minimize \(\sum_t y_t x_t-\sum_{tu}w_{tu}z_{tu}\), subject to \(\left|\sum_t a_t x_t\right|\ge 1/n\); the constantly many exceptional capacity-\(2\) agents may be represented as singleton types. Does this continuous separation problem admit an efficient algorithm, and how does its optimum relate to the discrete problem?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts listed types, not possible types. A binary-encoded integer \(n\geq1\) satisfies \(N_t=n\mu_t\in\mathbb Z_{>0}\).
Each type has an allocation \(y_t\in\mathbb Q\), capacity \(b_t\in\{1,2\}\), and signature \(a_t\in\mathbb Z\), with \(\gcd\{|a_t|:t\in T\}=1\). At most a fixed constant \(k\) types have capacity \(2\), and each has \(N_t=1\).
An explicit set \(E\) of \(m\) unordered type pairs has weights \(w_{tu}\in\mathbb Q\), of either sign. A diagonal pair \(tt\) represents edges between distinct agents of type \(t\), and is allowed only if \(N_t\geq2\).
Choose real coalition masses \(0\leq x_t\leq\mu_t\) and pair masses \(z_{tu}\geq0\) for \(tu\in E\), counting each unordered pair once and setting absent coordinates to zero. Require \(\sum_{u\ne t}z_{tu}+2z_{tt}\leq b_tx_t\) and \(\left|\sum_ta_tx_t\right|\geq1/n\); these are the complete fractional feasibility constraints.
Let \(C\) be the minimum of \(\sum_ty_tx_t-\sum_{tu\in E}w_{tu}z_{tu}\).
For comparison, expand each type into \(N_t\) distinct agents, joining every distinct pair whose types form a pair in \(E\), with the specified weight. For a coalition \(S\), let \(v(S)\) be its maximum-weight simple \(b\)-matching value, and let \(D=\frac1n\min_{S:\sum_{p\in S}a_{t(p)}\ne0}\bigl(\sum_{p\in S}y_{t(p)}-v(S)\bigr)\).

Is exact computation of \(C\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard, for fixed \(k\), with running time measured in \(m,\tau,L\), where \(L\) is the total binary input length including \(n\)? How does \(C\) compare with \(D\), and can their values differ strictly?

Discrete minimum excess subject to a nonzero integer signature is polynomial-time solvable on explicitly represented graphs with capacities at most \(2\) and only constantly many capacity-\(2\) agents. [Verified source](https://arxiv.org/html/2605.29571v1).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Exact computation of \(C\) is in \(\mathrm P\), with running time polynomial in \(m,\tau,L\). Always \(C\leq D\), and strict inequality is possible even when every capacity equals \(1\).

Polynomial-time computation. Let \(P_0\) be the polytope defined by all fractional constraints except the signature constraint, and write
\[ f(x,z)=\sum_{t\in T}y_tx_t-\sum_{tu\in E}w_{tu}z_{tu}. \]
For each \(s\in\{-1,1\}\), define the rational linear program
\[ C_s=\min\left\{f(x,z):(x,z)\in P_0,\quad s\sum_{t\in T}a_tx_t\geq\frac1n\right\}, \]
assigning \(C_s=+\infty\) if its feasible set is empty.

The equivalence
\[ \left|\sum_ta_tx_t\right|\geq\frac1n \quad\Longleftrightarrow\quad \sum_ta_tx_t\geq\frac1n \ \text{or}\ -\sum_ta_tx_t\geq\frac1n \]
proves \(C=\min\{C_{-1},C_1\}\).

Each program has \(\tau+m\) variables and \(O(\tau+m)\) constraints. Its coefficients are input rationals, the input integers \(a_t,b_t\), and \(1/n\). In particular, writing \(1/n\) requires only \(O(\log n)\) bits. Thus both programs have binary encoding length polynomial in \(m,\tau,L\).

For completeness, their feasible sets are bounded: the coalition coordinates satisfy \(0\leq x_t\leq\mu_t\); nonnegativity and the degree constraints give \(z_{tu}\leq b_t\mu_t\) for off-diagonal pairs and \(z_{tt}\leq b_t\mu_t/2\) for diagonal pairs. Each feasible set is also closed, so every nonempty one has an attained finite minimum.

At least one program is feasible. The gcd hypothesis implies that some \(a_t\neq0\). Set \(x_t=1/n\), all other coalition coordinates to zero, and \(z=0\). Since \(N_t=n\mu_t\geq1\), its upper bound is respected, and its absolute signature is \(|a_t|/n\geq1/n\).

The rational linear programming theorem computes an exact rational optimum, or detects infeasibility, in time polynomial in the binary encoding length. Applying it twice therefore computes \(C\) exactly in the required time. See [Khachiyan’s polynomial-time linear programming result](https://www.mathnet.ru/eng/dan42319).

This argument does not require the constant bound on capacity-\(2\) types. It uses precisely the stated fractional constraints.

Comparison with the discrete minimum. Fix any coalition \(S\) with nonzero integer signature, and let \(M\) be a maximum-weight simple \(b\)-matching in its induced graph. Such a matching exists because the graph is finite; negative weights cause no difficulty because the empty matching is allowed.

Let \(q_t\) count the agents of type \(t\) in \(S\), and let \(r_{tu}\) count matching edges whose endpoint types form \(tu\). Define \(x_t=q_t/n\) and \(z_{tu}=r_{tu}/n\). Then \(q_t\leq N_t\) gives \(x_t\leq\mu_t\). Summing matching degrees over the selected agents of type \(t\) gives
\[ \sum_{u\neq t}r_{tu}+2r_{tt}\leq b_tq_t, \]
which proves the fractional degree constraint after division by \(n\). Moreover,
\[ \left|\sum_ta_tx_t\right| =\frac1n\left|\sum_{p\in S}a_{t(p)}\right| \geq\frac1n, \]
because the sum on the right is a nonzero integer.

The fractional objective at this feasible point equals
\[ f(x,z)=\frac1n\left(\sum_{p\in S}y_{t(p)}-v(S)\right). \]
Taking the minimum over admissible \(S\) proves \(C\leq D\).

A strict-gap example. Take \(n=4\) and four types, each with \(\mu_t=1/4\), \(N_t=1\), \(b_t=1\), \(a_t=1\), and \(y_t=0\). Let \(E=\{12,23,13\}\), with every weight equal to \(1\). Type \(4\) is isolated. All hypotheses hold, including the gcd condition and the restriction on capacity-\(2\) types.

Set \(x_1=x_2=x_3=1/4\), \(x_4=0\), and \(z_{12}=z_{23}=z_{13}=1/8\). Each triangle vertex has incident pair mass \(1/4\), and the signature is \(3/4\). This gives objective \(-3/8\).

Conversely, summing the three triangle degree constraints gives
\[ 2(z_{12}+z_{23}+z_{13}) \leq x_1+x_2+x_3 \leq\frac34. \]
Since the objective is \(-(z_{12}+z_{23}+z_{13})\), this proves \(C=-3/8\).

In the expanded graph, every matching has at most one edge: all edges belong to a triangle on three agents. An edge’s two endpoints form an admissible coalition with matching value \(1\). Consequently \(D=-1/4\), and hence \(C=-3/8<-1/4=D\).

The cited [discrete theorem, Theorem 3.3](https://arxiv.org/html/2605.29571v1), concerns explicitly represented graphs. Its running time cannot automatically be transferred through an expansion with potentially exponentially many agents. The two compact linear programs settle the stated mass formulation directly.
