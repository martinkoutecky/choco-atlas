The continuous mirror question, as graded

Given τ complete types with rational masses μ, survival probabilities r_t, and a monotone differentiable value function g with g(0)=0 and range [0,1], consider replicated games whose coalition value is g(q(C)/n), where q_t(C) counts type-t agents and n is the population size. Under independent type-level survival, compute the limiting aggregate Shapley payoff of each type. In the smooth case, is the limit Φ_t=μ_t r_t∫_0^1 ∂_t g(λ(r⊙μ))dλ, and can all Φ_t be approximated within additive error ε with probability at least 1-δ in time polynomial in τ, the input bit length, 1/ε, log(1/δ), and the oracle cost, given a known polynomially bounded envelope for the marginal integrands?

Packaged proof task (what the prover saw — nothing else)

A society is specified by its support: \(\tau\) complete types, each combining its base-game type and survival probability, with positive binary-rational masses \(\mu_t\) summing to \(1\). Thus \(\tau\) counts supported types, not all possible types. Survival probabilities \(r_t\in[0,1]\) are binary rationals.
Let \(D=\prod_{t=1}^{\tau}[0,\mu_t]\). The coordinatewise monotone function \(g:D\to[0,1]\) satisfies \(g(0)=0\) and extends continuously differentiably to a neighborhood of \(D\).
For every positive integer \(n\) with all \(n\mu_t\) integral, form a population containing \(n\mu_t\) agents of type \(t\). Write \(q_t(C)\) for the number of type-\(t\) agents in coalition \(C\). Each agent survives independently with probability \(r_t\); if \(S_C\) is the survivor set, the reliability game's value is \(v_n(C)=\mathbb E[g(q(S_C)/n)]\). Define \(A_t^{(n)}=\sum_{i\text{ of type }t}\phi_i(v_n)\), using the standard Shapley value.
Set \(a_t=r_t\mu_t\). A supplied rational bound \(B\), polynomially bounded in \(\tau\) and the total finite input bit length \(L\), satisfies \(0\le a_t\partial_tg(\lambda a)\le B\) for every \(t\) and \(\lambda\in[0,1]\). An evaluation oracle accepts rational \(x\in D\) and an integer \(b\ge1\), returning \(g(x)\) and each partial derivative with absolute error at most \(2^{-b}\); its evaluation cost is charged to the running time.
Do the limits \(\Phi_t=\lim_{n\to\infty}A_t^{(n)}\), along the admissible population sizes, exist and equal \(a_t\int_0^1\partial_tg(\lambda a)\,d\lambda\)?
For rational \(\varepsilon,\delta\in(0,1)\), can all \(\Phi_t\) be approximated simultaneously within additive error \(\varepsilon\), with probability at least \(1-\delta\), in time polynomial in \(\tau,L,1/\varepsilon,\log(1/\delta)\) and the oracle cost?
For finite monotone simple base games with polynomial-time coalition evaluation, reliability-extension Shapley payoffs admit randomized additive approximation with polynomial dependence on population size, \(1/\varepsilon\), and \(\log(1/\delta)\).
For continuously differentiable nonatomic vector-measure games, a diagonal formula for the value is known ([Milchtaich, 1998](https://ratio.huji.ac.il/files/dp89.pdf)); this result does not address the independent-survival replication model and oracle approximation problem specified here.

Modeling choices made when packaging the task

  • Normalized total mass to one because n is the total population size; used exact replicas along population sizes making every type count integral.
  • Interpreted independent type-level survival as independent survival of individual agents with a common probability within each complete type, as required by the discrete reliability definition.
  • Defined reliability coalition values as expected surviving-coalition values, rather than the unextended base values.
  • Specified the vector domain of g and interpreted the smooth case as continuous differentiability on a neighborhood of the feasible box.
  • Specified finite-precision rational-query access to g and its gradient, charging evaluation costs; no quantitative continuity modulus is assumed.
  • Applied the supplied envelope to the weighted marginal integrands and required simultaneous accuracy for all supported types.

Conclusion and oracle interpretation

The limits exist and satisfy
\( \Phi_t=a_t\int_0^1\partial_tg(\lambda a)\,d\lambda \).

However, the stated rational-query oracle assumptions do not imply the requested polynomial-time approximation guarantee. A bounded derivative controls sampling variance, but without quantitative continuity information, finitely many rational queries cannot uniformly approximate these integrals.

Here the supplied oracle is interpreted as a black box, with no additional finite representation of \(g\) supplying a modulus of continuity. Running time is measured in the usual bit model, so a bounded-time algorithm uses finitely many random bits and rational queries.

1. An exact representation of the finite-population payoff

Fix an admissible population size \(n\), a type \(t\), and an agent \(i\) of that type. Write \(e_t\) for the \(t\)-th coordinate vector.

Generate a uniformly random ordering by assigning every agent an independent uniform arrival time in \([0,1]\). Independently assign each agent its survival indicator. Let \(P_i\) denote the agents preceding \(i\).

The permutation formula for the Shapley value gives
\( \phi_i(v_n)=\mathbb E[v_n(P_i\cup\{i\})-v_n(P_i)] \).

Couple the survival experiments in these two coalitions using the same indicators for their common agents. If \(i\) does not survive, the difference is zero. If \(i\) survives, it contributes one additional survivor of type \(t\).

Conditional on \(i\)'s arrival time being \(u\), each other type-\(s\) agent precedes \(i\) and survives with probability \(ur_s\), independently. Consequently, the preceding-survivor counts \(Z_s^{(n,t,u)}\) are independent and have distributions
\( Z_s^{(n,t,u)}\sim\operatorname{Bin}(n\mu_s-\mathbf 1_{\{s=t\}},ur_s) \).

Thus
\( \phi_i(v_n)=r_t\int_0^1\mathbb E\!\left[g((Z^{(n,t,u)}+e_t)/n)-g(Z^{(n,t,u)}/n)\right]\,du \).

All agents of type \(t\) have equal Shapley values, by symmetry. Applying the fundamental theorem of calculus to their marginal contributions yields the exact identity
\( A_t^{(n)}=a_t\int_0^1\int_0^1\mathbb E\!\left[\partial_tg((Z^{(n,t,u)}+\theta e_t)/n)\right]\,d\theta\,du \).

The segment in this formula lies in \(D\): the count of type-\(t\) agents excludes \(i\), and adding at most one restores at most the full type-\(t\) population.

2. Convergence to the diagonal formula

Set
\( Y^{(n,t,u,\theta)}=(Z^{(n,t,u)}+\theta e_t)/n \).

Its mean satisfies
\( \mathbb E Y^{(n,t,u,\theta)}=ua+((\theta-ur_t)/n)e_t \).

Each Bernoulli variance is at most \(1/4\), and the counts involve \(n-1\) agents altogether. Therefore
\( \mathbb E\|Y^{(n,t,u,\theta)}-ua\|_2^2\le (n-1)/(4n^2)+1/n^2\le 1/(4n)+1/n^2 \),
uniformly in \(u,\theta\in[0,1]\).

Since \(g\) extends continuously differentiably to a neighborhood of the compact set \(D\), its partial derivative \(\partial_tg\) is bounded and uniformly continuous on \(D\). Define
\( M_t=\sup_{x\in D}|\partial_tg(x)| \)
and
\( \omega_t(\eta)=\sup\{|\partial_tg(x)-\partial_tg(y)|:x,y\in D,\ \|x-y\|_2\le\eta\} \).

Uniform continuity gives \(\omega_t(\eta)\to0\) as \(\eta\downarrow0\). Splitting according to whether \(\|Y^{(n,t,u,\theta)}-ua\|_2\le\eta\), and applying Markov's inequality to the squared distance, gives
\( \left|\mathbb E[\partial_tg(Y^{(n,t,u,\theta)})]-\partial_tg(ua)\right|\le \omega_t(\eta)+\frac{2M_t}{\eta^2}\left(\frac1{4n}+\frac1{n^2}\right) \).

This bound is uniform in \(u,\theta\). First letting \(n\to\infty\), and then \(\eta\downarrow0\), proves uniform convergence of the expectations. Substitution into the exact payoff representation proves
\( \displaystyle\lim_{\substack{n\to\infty\\n\mu_s\in\mathbb Z\ \forall s}}A_t^{(n)}=a_t\int_0^1\partial_tg(ua)\,du \).

The admissible sizes form an unbounded set because the masses are rational. If \(r_t=0\), both sides are zero.

As a consistency check, the chain rule gives
\( \sum_{t=1}^{\tau}\Phi_t=\int_0^1\sum_{t=1}^{\tau}a_t\partial_tg(ua)\,du=g(a)-g(0)=g(a) \).

This proof treats the independent-survival replication model directly. It does not require an application of the nonatomic value theorem in [Milchtaich (1998)](https://ratio.huji.ac.il/files/dp89.pdf).

3. A rational-oracle obstruction to approximation

We prove that there is no uniform finite bit-time bound depending only on the stated explicit parameters. This rules out the requested polynomial bound.

Fix
\( \tau=2,\quad \mu_1=\mu_2=\tfrac12,\quad r_1=r_2=1,\quad B=1,\quad \varepsilon=\tfrac1{32},\quad\delta=\tfrac14 \).

Thus \(D=[0,\tfrac12]^2\) and \(a=(\tfrac12,\tfrac12)\).

Suppose a randomized algorithm has a uniform finite runtime bound on these inputs. Run it against the reference game
\( g_0(x,y)=x+y \),
using an oracle that returns its exact rational values and derivatives.

Because the algorithm uses finitely many random bits within its runtime bound, the union \(Q\) of all query points over all its possible executions is finite. We construct another admissible game agreeing with \(g_0\), including both partial derivatives, at every point in \(Q\).

Constructing the perturbation

Use coordinates \(u=x+y\) and \(v=x-y\). Let
\( S=\{x+y:(x,y)\in Q,\ x=y\} \).

Choose a continuously differentiable function \(h:\mathbb R\to[0,1]\) such that
\( h(s)=0\ \text{for every }s\in S,\qquad \int_0^1h(u)\,du\ge\tfrac34 \).

Here is an explicit construction. If \(S\) is empty, take \(h=1\). Otherwise, write \(m=|S|\), choose a positive rational \(\eta\) with \(2m\eta\le1/4\), and define
\( \beta(z)=(1-z^2)^2 \) for \(|z|\le1\), and \(\beta(z)=0\) otherwise.

The function \(\beta\) is continuously differentiable because both its value and derivative vanish at the endpoints of its support. Set
\( h(u)=\prod_{s\in S}(1-\beta((u-s)/\eta)) \).

Then \(0\le h\le1\), and \(h(s)=0\) at every prescribed point. Outside intervals of total length at most \(2m\eta\), the function equals one, proving the integral bound. Also \(H=\sup_{\mathbb R}|h'|\) is finite.

Define another continuously differentiable function by
\( \rho(z)=z(1-z^2)^2 \) for \(|z|\le1\), and \(\rho(z)=0\) otherwise.

It satisfies
\( \rho(0)=0,\quad \rho'(0)=1,\quad |\rho(z)|\le1,\quad |\rho'(z)|\le1 \).

For the last bound, inside its support,
\( \rho'(z)=1-6z^2+5z^4 \).
Writing \(s=z^2\in[0,1]\), this quadratic has maximum \(1\) and minimum \(-4/5\).

Choose a positive rational \(w\) so small that
\( wH\le1 \)
and
\( w<|x-y| \)
for every off-diagonal point \((x,y)\in Q\). Such a choice exists because \(Q\) is finite.

Now set
\( g_1(x,y)=x+y+\tfrac14w\,\rho((x-y)/w)h(x+y) \).

Checking every game hypothesis

The function \(g_1\) is continuously differentiable on the entire plane. Its derivatives are
\( \partial_xg_1=1+\tfrac14[\rho'(v/w)h(u)+w\rho(v/w)h'(u)] \)
and
\( \partial_yg_1=1+\tfrac14[-\rho'(v/w)h(u)+w\rho(v/w)h'(u)] \).

The bounds just established imply that both derivatives are at least
\( 1-\tfrac14(1+wH)\ge\tfrac12 \).
Hence \(g_1\) is coordinatewise monotone.

Since the perturbation vanishes on the diagonal,
\( g_1(0,0)=0 \)
and
\( g_1(\tfrac12,\tfrac12)=1 \).
Monotonicity therefore implies \(g_1(D)\subseteq[0,1]\).

Along the specified ray,
\( \partial_xg_1(\lambda/2,\lambda/2)=1+\tfrac14h(\lambda) \)
and
\( \partial_yg_1(\lambda/2,\lambda/2)=1-\tfrac14h(\lambda) \).

Consequently, both weighted derivatives are nonnegative and at most \(5/8\), so the supplied bound \(B=1\) is valid.

At an off-diagonal query point, \(|v/w|>1\), so \(\rho(v/w)=\rho'(v/w)=0\). At a diagonal query point, \(\rho(0)=0\) and \(h(u)=0\). Thus \(g_1\) and both its partial derivatives agree exactly with those of \(g_0\) throughout \(Q\).

All construction parameters can be rational. Both games admit valid precision oracles; at points in \(Q\), the oracles can return exactly the same answers.

Contradictory approximation requirements

By induction over adaptive queries, the algorithm has identical transcripts, and hence the same output distribution, under the two oracles.

Nevertheless, the proven limit formula gives
\( \Phi_1(g_0)=\tfrac12 \)
and
\( \Phi_1(g_1)=\tfrac12+\tfrac18\int_0^1h(u)\,du\ge\tfrac12+\tfrac3{32} \).

Their separation is greater than \(2\varepsilon=1/16\). The two intervals of acceptable first-coordinate outputs are therefore disjoint.

An identical output distribution cannot put probability at least \(3/4\) in each of two disjoint intervals. Thus the algorithm fails the requested guarantee for at least one game.

This argument is an oracle lower bound: the explicit finite inputs are fixed, and the assumptions impose no relationship between continuity information and oracle evaluation cost. It already uses exact agreement at all queried points, so increasing answer precision within the runtime budget does not resolve the obstruction.

4. What additional information would suffice

The bound \(B\) does provide the expected statistical guarantee if exact uniformly distributed real query points were available. Define
\( f_t(\lambda)=a_t\partial_tg(\lambda a) \).
For independent uniform \(U_1,\ldots,U_m\), Hoeffding's inequality and a union bound give
\( \Pr\!\left(\max_t\left|\frac1m\sum_{j=1}^mf_t(U_j)-\Phi_t\right|>\varepsilon\right)\le2\tau\exp(-2m\varepsilon^2/B^2) \).

The specified oracle accepts rational points instead. To implement this argument, a sufficient additional promise is a supplied integer \(k\), polynomially bounded in the input parameters, such that
\( |\lambda-\lambda'|\le2^{-k}\ \Longrightarrow\ |f_t(\lambda)-f_t(\lambda')|\le\varepsilon/4 \)
for every \(t\).

Sampling uniformly from the dyadic grid with mesh \(2^{-k}\) then introduces expectation bias at most \(\varepsilon/4\). Choosing oracle precision \(b\) with \(2^{-b}\le\varepsilon/4\) introduces at most another \(\varepsilon/4\), since \(a_t\le1\). Finally,
\( m\ge2B^2\varepsilon^{-2}\log(2\tau/\delta) \)
bounds the simultaneous sampling error by \(\varepsilon/2\) with probability at least \(1-\delta\).

This yields the requested polynomial dependence under that additional quantitative continuity promise. Continuous differentiability alone supplies no such uniform bound.
