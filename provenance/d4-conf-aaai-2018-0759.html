The continuous mirror question, as graded

Given a finite alternative set \(A\) and \(\tau\) complete weak-order types \(t\), each with positive binary-rational mass \(\mu_t\) summing to \(1\), compute the exact RMEC lottery. For each \(a\in A\) and rank \(j\), set \(r_{\mu,j}(a)=\sum_t\mu_t\mathbf{1}[a\in E_j(t)]\), where \(E_j(t)\) is type \(t\)’s \(j\)-th indifference class. For each type \(t\), let \(F_\mu(t)\) be the alternatives in its top class whose rank vectors are lexicographically maximal within that class; output \(p_\mu(a)=\sum_{t:a\in F_\mu(t)}\mu_t/|F_\mu(t)|\) for every \(a\in A\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a nonempty alternative set with \(m=|A|\). A society is given by its support: a list of \(\tau\) distinct complete weak-order types on \(A\), each with positive binary-rational mass \(\mu_t\), with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
Represent each type explicitly by its indifference classes \(E_1(t),\ldots,E_{k_t}(t)\), ordered from best to worst, and put \(E_j(t)=\varnothing\) for \(k_t<j\le m\).
Define \(r_\mu(a)=(r_{\mu,1}(a),\ldots,r_{\mu,m}(a))\), where \(r_{\mu,j}(a)=\sum_{t:a\in E_j(t)}\mu_t\). Let \(F_\mu(t)\) contain all alternatives in \(E_1(t)\) whose rank vectors are lexicographically maximal within \(E_1(t)\).
The RMEC lottery is \(p_\mu(a)=\sum_{t:a\in F_\mu(t)}\mu_t/|F_\mu(t)|\); all tied maximizers receive equal shares. The computational problem is to output every \(p_\mu(a)\) exactly as a binary rational.

Is exact computation of this RMEC lottery polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?

For an explicitly listed society of \(n\) agents with complete weak orders, RMEC has rational outcomes and is computable in \(O(m^2n)\) time. [Aziz, Luo, and Rizkallah](https://cgi.cse.unsw.edu.au/~haziz/equal_contribution.pdf).

Result and encoding convention

Exact computation of the support-encoded RMEC lottery is polynomial-time solvable in \(m,\tau,L\). The proof below controls both arithmetic bit complexity and output length.

Here “binary rational” means a fraction whose integer numerator and positive integer denominator are written in binary. If it instead means a terminating binary expansion, the requested output need not exist: with three alternatives and one completely indifferent type of mass \(1\), every probability is \(1/3\). We therefore use the fraction encoding intended for exact rational computation.

The explicit-agent result appears in Proposition 1 of [Aziz, Luo, and Rizkallah](https://cgi.cse.unsw.edu.au/~haziz/equal_contribution.pdf). The following argument directly handles the support encoding, without expanding masses into agents.

1. Compute integer rank vectors

Write each input mass as \(\mu_t=u_t/v_t\), where \(u_t,v_t\) are positive integers encoded in binary. Define \(D=\prod_{t=1}^{\tau}v_t\) and \(w_t=u_t(D/v_t)\).

Every division here is exact, and \(w_t=D\mu_t\). Consequently, \(\sum_{t=1}^{\tau}w_t=D\).

Initialize an integer table \(R_j(a)=0\) for every alternative \(a\) and every \(j\in\{1,\ldots,m\}\). For each type \(t\), each class \(E_j(t)\), and each \(a\in E_j(t)\), add \(w_t\) to \(R_j(a)\). Upon completion,

\(R_j(a)=\sum_{t:a\in E_j(t)}w_t=D\,r_{\mu,j}(a)\).

Because every type partitions the alternatives into its indifference classes, this construction uses exactly \(m\tau\) additions, besides initialization.

Multiplication of every vector coordinate by the same positive number \(D\) preserves lexicographic comparisons and equality. Thus the integer vectors \(R(a)=(R_1(a),\ldots,R_m(a))\) identify exactly the maximizers specified in the question.

2. Find every maximizer, including ties

For each type \(t\), scan its nonempty top class \(E_1(t)\), retaining an alternative with lexicographically largest integer rank vector. Then scan that class again and collect every alternative whose vector equals the retained vector.

Lexicographic order is a total order on these vectors, so the first scan finds a maximum. The second scan returns precisely \(F_\mu(t)\), including all tied maximizers.

Each comparison examines at most \(m\) integer coordinates. Each top class contains at most \(m\) alternatives, so all types together require \(O(m^2\tau)\) coordinate comparisons.

Put \(s_t=|F_\mu(t)|\). Nonemptiness of the top classes gives \(1\le s_t\le m\).

3. Accumulate the lottery with a common denominator

Define \(Q=\prod_{t=1}^{\tau}s_t\). Initialize \(P_a=0\) for every alternative. For each type \(t\), compute the integer \(c_t=w_t(Q/s_t)\), and add \(c_t\) to \(P_a\) for every \(a\in F_\mu(t)\).

These divisions are exact because every \(s_t\) divides \(Q\). The resulting numerator satisfies

\(P_a=\sum_{t:a\in F_\mu(t)}w_tQ/s_t\).

Therefore,

\(\displaystyle \frac{P_a}{DQ}=\sum_{t:a\in F_\mu(t)}\frac{w_t}{Ds_t}=\sum_{t:a\in F_\mu(t)}\frac{\mu_t}{|F_\mu(t)|}=p_\mu(a)\).

Outputting \(P_a/(DQ)\) thus gives every probability exactly.

Moreover, all numerators are nonnegative, and

\(\displaystyle \sum_{a\in A}P_a=\sum_{t=1}^{\tau}s_t\frac{w_tQ}{s_t}=Q\sum_{t=1}^{\tau}w_t=DQ\).

In particular, \(0\le P_a\le DQ\).

4. Bit complexity and output length

The total binary length of the input denominators is at most \(L\), so \(\log_2 D\le L\). Also, \(Q\le m^\tau\), giving \(\log_2 Q\le\tau\log_2 m\).

Set \(B=L+\tau\lceil\log_2(m+1)\rceil+2\). Every integer used above has at most \(B\) bits:

  • Each \(w_t\) and each rank-table entry lies between \(0\) and \(D\).
  • The products defining \(D\) and \(Q\) never exceed their final values.
  • Each contribution \(c_t\), each accumulating numerator \(P_a\), and the final denominator are at most \(DQ\).

The algorithm performs \(O(m^2\tau)\) integer operations and coordinate comparisons. Ordinary binary addition, comparison, multiplication, and division on integers of at most \(B\) bits each take \(O(B^2)\) time or less. Thus an explicit bit-time bound for unreduced fraction output is \(O(m^2\tau B^2)\), which is polynomial in \(m,\tau,L\).

The total output length is \(O(mB)\). If reduced fractions are required, divide each numerator and denominator by their greatest common divisor; the Euclidean algorithm adds only polynomial time.

This proves the claimed polynomial-time solvability for arbitrary explicitly binary-encoded rational masses, and hence also for dyadic input masses.
