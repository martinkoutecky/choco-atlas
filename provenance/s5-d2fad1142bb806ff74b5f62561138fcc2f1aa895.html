The continuous mirror question, as graded

Given finitely many complete TA types \(t\in T\) with binary-rational masses \(\mu_t\ge 0\), \(\sum_t\mu_t=1\), and a common course value \(q_t\in\mathbb Z_{\ge 0}\) for both courses, where each type has utility and grade \(1\) for either course, decide whether there are nonnegative rational assignments \(z_{t,i}\) such that \(\sum_{i=1}^2 z_{t,i}=\mu_t\), \(\sum_t z_{t,i}=1/2\), and \(\frac{\sum_t q_t z_{t,i}}{1/2}\ge k\) for each course \(i\in\{1,2\}\).

Packaged proof task (what the prover saw — nothing else)

There are \(m=2\) courses, each requiring mass \(1/2\). A society is given by its support: a list \(T\) of \(\tau\) complete TA types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type \(t\) has utility and grade \(1\) for either course; both courses value that type at the same binary-encoded integer \(q_t\in\mathbb Z_{>0}\). The input also contains a binary-rational threshold \(k\in\mathbb Q_{\ge0}\). Let \(L\) be the total input bit length.
An assignment may split each type's mass between courses. Feasibility requires \(z_{t,i}\in\mathbb Q_{\ge0}\), \(\sum_{i=1}^{2}z_{t,i}=\mu_t\) for every \(t\), and \(\sum_{t\in T}z_{t,i}=1/2\) for each \(i\in\{1,2\}\).
Course satisfaction requires \(\frac{\sum_{t\in T}q_tz_{t,i}}{1/2}\ge k\) for each course. Merit-based envy means strictly preferring another TA's course while having at least that TA's grade there; indifference is retained without tie-breaking.
Is deciding whether such an assignment exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?
The discrete counterpart with indivisible TAs, identical course valuations, unit TA utilities and grades, and equal capacities exhausting the population is NP-complete ([Jain, Jha, and Solanki](https://arxiv.org/html/2504.10232v1)).
No result settling this exact mass formulation was identified in the literature search.

Modeling choices made when packaging the task

  • Restricted course values to positive integers: positive TA utility requires positive course valuation in the discrete model, excluding the graded question's zero values.
  • Specified the previously undefined threshold as a nonnegative binary rational.
  • Discarded zero-mass entries so that the supplied list is exactly the positive-mass support.
  • Used m for the number of courses, fixed at two, and L for total input bit length; no finite population size is supplied.
  • Retained average course utility and the mass-normalized capacities rather than importing the hardness proof's inconsistent threshold normalization.

Result

The decision problem is polynomial-time solvable. Precisely, an assignment satisfying feasibility, course satisfaction, and merit-based envy-freeness exists if and only if

\(\displaystyle \sum_{t\in T}q_t\mu_t\ge k.\)

This characterization holds for every support size \(\tau\) and all masses and valuations allowed in the question.

Proof of the characterization

Define the total weighted course valuation by \(\displaystyle Q=\sum_{t\in T}q_t\mu_t\).

Merit-based envy imposes no additional restriction. For any types \(t,s\) and courses \(i,j\), an individual of type \(t\) assigned to course \(i\) could envy an individual of type \(s\) assigned to course \(j\) only if \(u_t(j)>u_t(i)\). Both utilities equal \(1\), so this strict inequality is false. Thus every feasible assignment is merit-based envy-free. This argument applies to every positive-mass part of each type and retains indifference as stipulated.

Necessity. Suppose an assignment satisfies both courses. Write \(\displaystyle V_i=\sum_{t\in T}q_tz_{t,i}\) for course \(i\)'s total valuation. Satisfaction requires \(V_i/(1/2)\ge k\), hence \(V_i\ge k/2\).

Because both courses have the same valuation for each type and all mass is assigned,

\(\displaystyle V_1+V_2=\sum_{t\in T}q_t(z_{t,1}+z_{t,2})=\sum_{t\in T}q_t\mu_t=Q.\)

Adding the two satisfaction inequalities gives \(Q\ge k\).

Sufficiency. Suppose \(Q\ge k\). Split every type equally:

\(\displaystyle z_{t,1}=z_{t,2}=\frac{\mu_t}{2}\quad\text{for every }t\in T.\)

These numbers are nonnegative rationals, and their sum for each type is \(\mu_t\). For either course \(i\),

\(\displaystyle \sum_{t\in T}z_{t,i}=\frac12\sum_{t\in T}\mu_t=\frac12,\)

so feasibility holds. Its average valuation is

\(\displaystyle \frac{\sum_{t\in T}q_tz_{t,i}}{1/2}=\frac{\sum_{t\in T}q_t\mu_t/2}{1/2}=Q\ge k.\)

Both courses are therefore satisfied, and the preceding envy argument completes the proof.

Exact algorithm and bit complexity

The algorithm computes \(Q\) exactly and accepts precisely when \(Q\ge k\). On acceptance, the equal split above supplies an explicit assignment.

To verify polynomial bit complexity, write the input rationals as \(\mu_t=a_t/b_t\) and \(k=c/d\), where \(a_t,b_t,d\) are positive integers and \(c\) is nonnegative. Define

\(\displaystyle D=\prod_{t\in T}b_t,\qquad S=\sum_{t\in T}q_ta_t\frac{D}{b_t}.\)

Every quotient \(D/b_t\) is an integer, and \(Q=S/D\). Since \(d,D\) are positive, the exact acceptance test is \(dS\ge cD\).

The sum of the input integers' binary lengths is at most \(L\). Consequently, \(D\), every summand defining \(S\), and the final comparison operands have \(O(L+\log\tau)=O(L)\) bits; here \(\tau\le L\) because every listed type requires input bits. Using elementary integer multiplication and division, the calculation takes \(O(\tau L^2)\) bit operations. This is polynomial in \(m,\tau,L\), with \(m=2\).

The witness entries \(a_t/(2b_t)\) also have polynomial total encoding length.

Relation to the discrete counterpart

The discrete hardness result concerns indivisible TAs; see Theorem 1 of [Jain, Jha, and Solanki](https://arxiv.org/html/2504.10232v1). The equal split used above is permitted in the mass formulation and can fail to correspond to any discrete assignment.

For example, take two types with masses \(\mu_1=\mu_2=1/2\), valuations \(q_1=1,q_2=3\), and threshold \(k=2\). The mass assignment gives each course \(1/4\) of each type and average valuation \(2\). With two indivisible TAs and capacity one per course, one course necessarily receives only the TA valued at \(1\), so it fails the threshold.
