The continuous mirror question, as graded

Given a fixed \(k\ge5\), an explicit rational distribution \(\mu\) over complete ranking types on candidates \(C\), a target \(p\), and a budget \(B\), let \(w\) be the current \(k\)-approval winner and \(E=\{t:p\succ_t w\}\). For each source type \(t\in E\) and approval set \(A\subseteq C\) with \(|A|=k\), choose transferred mass \(x_{t,A}\ge0\) with \(\sum_A x_{t,A}\le\mu_t\) and \(\sum_{t,A}x_{t,A}\le B\). Does there exist such a transfer, changing the \(k\)-approval score vector to \(s'(c)=\sum_t\mu_t\mathbf{1}[c\in\operatorname{top}_k(t)]-\sum_{t,A}x_{t,A}\mathbf{1}[c\in\operatorname{top}_k(t)]+\sum_{t,A}x_{t,A}\mathbf{1}[c\in A]\), such that \(p\) wins under the paper's tie-breaking rule?

Definitions. Fix \(k\ge5\) and a fixed tie-breaking priority order \(\triangleright\). An instance gives candidates \(C\), an explicit rational distribution \(\mu\) over complete rankings \(t\) of \(C\), target \(p\), and rational budget \(B\). Let \(w\) be the current \(k\)-approval winner, let \(E=\{t:p\succ_t w\}\), and let \(\operatorname{top}_k(t)\) be the \(k\) highest-ranked candidates of \(t\).
For every \(t\in E\) and \(A\subseteq C\) with \(|A|=k\), one may transfer mass \(x_{t,A}\ge0\) from type \(t\) to a vote approving \(A\), subject to \(\sum_Ax_{t,A}\le\mu_t\) and \(\sum_{t,A}x_{t,A}\le B\). The resulting score is \(s'(c)=\sum_t\mu_t\mathbf{1}[c\in\operatorname{top}_k(t)]-\sum_{t,A}x_{t,A}\mathbf{1}[c\in\operatorname{top}_k(t)]+\sum_{t,A}x_{t,A}\mathbf{1}[c\in A]\). The winner is the \(\triangleright\)-highest candidate of maximum \(s'\)-score.

Target. Is this rational mass-transfer \(k\)-approval problem solvable in polynomial time, or is it NP-hard?

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The problem is polynomial-time solvable for every fixed \(k\ge 5\). A linear program describes the transfers exactly, and one additional variable handles tie-breaking.

1. Polynomially many transfer variables.

Let \(n=|C|\), and let \(T\) be the explicitly listed support of \(\mu\), with \(m=|T|\). Types of zero mass cannot supply any transfer, so they may be omitted.

Compute the initial scores
\(s(c)=\sum_{t\in T}\mu_t\mathbf{1}[c\in\operatorname{top}_k(t)]\),
the current winner \(w\), and the eligible set
\(E=\{t\in T:p\succ_t w\}\).
These computations take polynomial time using exact rational arithmetic.

Write
\(\mathcal A=\{A\subseteq C:|A|=k\}\).
Because \(k\) is fixed,
\(|\mathcal A|=\binom nk\le n^k\)
is polynomial in the input size. Consequently, the variables \(x_{t,A}\) from the problem statement can all be included explicitly in a polynomial-size linear program. No relaxation of their meaning is necessary.

2. The linear program.

For each candidate \(c\), define the following affine expression in the transfer variables:

\(S_c(x)=s(c)+\sum_{t\in E}\sum_{A\in\mathcal A}x_{t,A}\bigl(\mathbf{1}[c\in A]-\mathbf{1}[c\in\operatorname{top}_k(t)]\bigr).\)

This is exactly the resulting score specified in the question.

Let \(H=\{c\in C\setminus\{p\}:c\triangleright p\}\) be the candidates with higher tie-breaking priority than \(p\), and let \(L=C\setminus(H\cup\{p\})\).

Introduce a variable \(\delta\). Maximize \(\delta\), subject to:

  • \(x_{t,A}\ge 0\) for every \(t\in E\) and \(A\in\mathcal A\);
  • \(\sum_{A\in\mathcal A}x_{t,A}\le\mu_t\) for every \(t\in E\);
  • \(\sum_{t\in E}\sum_{A\in\mathcal A}x_{t,A}\le B\);
  • \(S_p(x)-S_c(x)\ge\delta\) for every \(c\in H\);
  • \(S_p(x)-S_c(x)\ge 0\) for every \(c\in L\);
  • \(0\le\delta\le 1\).

The decision algorithm returns yes exactly when this linear program is feasible and its optimum is strictly positive.

3. Proof of equivalence.

Suppose first that an admissible transfer \(x\) makes \(p\) the winner.

For each \(c\in L\), necessarily \(S_p(x)\ge S_c(x)\), since a candidate with a strictly larger score would defeat \(p\). For each \(c\in H\), necessarily \(S_p(x)>S_c(x)\), since equality would also defeat \(p\) by tie-breaking.

If \(H\ne\varnothing\), choose

\(\delta=\min\bigl(\{1\}\cup\{S_p(x)-S_c(x):c\in H\}\bigr).\)

Every member of this finite set is positive, so \(\delta>0\). If \(H=\varnothing\), choose \(\delta=1\). In either case, \((x,\delta)\) satisfies every constraint. Thus the optimum is positive.

Conversely, suppose the linear program has a feasible solution with \(\delta>0\). Its first three families of constraints make \(x\) an admissible transfer. Its remaining score constraints imply that \(p\) strictly outscores every higher-priority candidate and weakly outscores every lower-priority candidate. Therefore \(p\) has maximum score and defeats every candidate tied with it. Hence \(p\) is the winner.

This proves the required equivalence.

4. Exact polynomial-time computation.

There are at most \(m\binom nk+1\) variables and polynomially many constraints. Each coefficient multiplying a transfer variable in a score difference belongs to \(\{-2,-1,0,1,2\}\). The other coefficients are input rationals, computed initial scores, or constants. Summing the explicitly given rationals produces numbers of polynomial binary encoding length. The entire linear program therefore has polynomial encoding length for fixed \(k\).

Its feasible region, when nonempty, is bounded: each transfer variable satisfies \(0\le x_{t,A}\le\mu_t\), and \(0\le\delta\le1\). It is also closed, being defined by finitely many non-strict linear inequalities. Thus the optimum is attained.

The standard polynomial-time theorem for rational linear programming allows feasibility and the exact rational optimum to be computed in time polynomial in this encoding length. Its hypotheses hold here: all data are rational, the program is explicitly represented, and a feasible program has a finite attained optimum. See [Khachiyan’s polynomial-time linear programming result](https://www.mathnet.ru/eng/dan42319). Comparing the exact optimum with zero therefore decides the problem; no numerical tolerance is needed. An optimal rational solution also supplies rational transfers whenever the answer is yes.

The cited discrete hardness result does not obstruct this argument: requiring indivisible vote changes introduces integrality constraints, whereas the stated mass-transfer problem permits the fractional variables used here.
