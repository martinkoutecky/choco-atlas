The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\), two resources with rational capacities \(q_1,q_2\) satisfying \(q_1+q_2=1\), binary type-level externalities \(e_{tu}\), and the valuation pattern \(v_{t1}=1,v_{t2}=0\), decide whether there are assignment masses \(x_{tr}\ge0\) with \(\sum_r x_{tr}=\mu_t\) and \(\sum_t x_{tr}=q_r\) such that every type \(t\) receiving positive mass on resource \(r\) satisfies, for every occupied resource \(s\ne r\), \(v_{tr}\ge v_{ts}\) or \(E_t(r;x)\ge E_t(s;x)\), where \(E_t(r;x)=\sum_{u\in T}e_{tu}x_{ur}\).

Packaged proof task (what the prover saw — nothing else)

A society is atomless and given by its support: a nonempty list \(T\) of \(\tau\) types with positive masses \(\mu_t\), each a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m=2\) resources with positive binary-rational capacities \(q_1,q_2\), possibly different, satisfying \(q_1+q_2=1\). Every type has internal values \(v_{t1}=1\) and \(v_{t2}=0\).
Externalities satisfy \(e_{tu}=e_{ut}\in\{0,1\}\). A diagonal entry describes externalities between distinct individuals of the same type; an individual's own contribution has zero mass.
An assignment consists of real masses \(x_{tr}\geq0\) satisfying \(\sum_{r=1}^{2}x_{tr}=\mu_t\) and \(\sum_{t\in T}x_{tr}=q_r\). Types may be split between resources. Define \(E_t(r;x)=\sum_{u\in T}e_{tu}x_{ur}\).
Call an assignment Pareto envy-free if, whenever \(x_{tr}>0\), every occupied resource \(s\neq r\) satisfies \(v_{tr}\geq v_{ts}\) or \(E_t(r;x)\geq E_t(s;x)\). Comparisons are weak; exchanging two individual positions leaves aggregate masses unchanged.

Is deciding whether such a Pareto envy-free assignment exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m=2\), \(\tau\), and the total input bit length \(L\).

For indivisible agents, existence is \(\mathrm{NP}\)-complete with two positive-capacity resources, symmetric binary externalities, and these common internal values; envy is evaluated after exchanging individual positions ([Gan, Li, and Li, 2023](https://arxiv.org/pdf/2012.04522)).
No result settling this exact atomless decision problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to one, matching the stated total capacity, and retained only positive-mass support types.
  • Required both capacities to be positive, carrying over the discrete requirement that each resource has positive capacity; capacities may differ but need not differ.
  • Required symmetric externalities, carrying over the dorm-sharing model used by the anchor.
  • Interpreted diagonal type externalities as values for distinct individuals of the same type, allowing either binary value; the discrete prohibition on valuing oneself concerns an individual, whose mass is zero here.
  • Allowed real assignment masses and splitting of types, with envy tested on every resource receiving positive mass of the type.
  • Interpreted the discrete exchange of two individual positions as an exchange of atomless individuals, which leaves aggregate externality sums unchanged.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when every mass and capacity is a dyadic rational. Thus a polynomial-time algorithm in \(\tau\) and \(L\) exists only if \(\mathrm{P}=\mathrm{NP}\).

For \(m=2\), an exact algorithm runs in \(2^\tau\operatorname{poly}(\tau,L)\) time.

1. The two-resource envy condition

Write \(y_t=x_{t2}\), so \(x_{t1}=\mu_t-y_t\). Define the total externality mass of type \(t\) by

\(d_t=\sum_{u\in T}e_{tu}\mu_u.\)

Assignment feasibility is equivalent to

\(0\leq y_t\leq\mu_t\quad(t\in T),\qquad \sum_{t\in T}y_t=q_2.\)

Individuals assigned to resource \(1\) satisfy the internal-value comparison because \(v_{t1}=1>0=v_{t2}\). For individuals assigned to resource \(2\), that comparison fails. Their externality comparison becomes

\(\sum_u e_{tu}y_u\geq\sum_u e_{tu}(\mu_u-y_u).\)

Consequently, the assignment is Pareto envy-free exactly when

\[y_t>0\quad\Longrightarrow\quad \sum_u e_{tu}y_u\geq d_t/2.\tag{1}\]

We will also use the following bound, which holds because externalities are binary:

\[\sum_u e_{tu}y_u\leq\sum_u y_u=q_2.\tag{2}\]

In particular, if \(d_t>2q_2\), equations (1) and (2) force \(y_t=0\).

There is an easy positive case: when \(q_2\geq 1/2\), the proportional assignment \(y_t=q_2\mu_t\) satisfies (1). The hardness construction below has \(q_2<1/2\).

2. Membership in \(\mathrm{NP}\) and an exact algorithm

For each subset \(S\subseteq T\), consider the rational linear system

\(0\leq y_t\leq\mu_t\quad(t\in T),\qquad \sum_t y_t=q_2,\)

\[y_t=0\quad(t\notin S),\qquad \sum_u e_{tu}y_u\geq d_t/2\quad(t\in S).\tag{3}\]

An envy-free assignment yields a feasible system by choosing \(S=\{t:y_t>0\}\). Conversely, any solution of (3) satisfies (1): every type with positive \(y_t\) belongs to \(S\) and satisfies its externality inequality. It does not matter if some types in \(S\) receive zero mass on resource \(2\).

Each system has \(\tau\) variables and \(O(\tau)\) constraints, with encoding length polynomial in \(\tau\) and \(L\). Polynomial-time rational linear programming therefore gives an exact decision algorithm with running time

\(2^\tau\operatorname{poly}(\tau,L)\qquad\text{for }m=2.\)

For completeness, real-valued assignments do not prevent membership in \(\mathrm{NP}\). Every nonempty system (3) defines a bounded rational polytope and hence has a vertex. Clearing denominators produces integer coefficients with \(O(L)\) bits: the product of the input denominators, multiplied by \(2\), is a sufficient common denominator. At a vertex, \(\tau\) independent tight constraints determine the coordinates. Cramer’s rule and determinant bounds give \(O(\tau(L+\log\tau))\) bits per coordinate.

Thus a polynomial-length certificate consists of \(S\) and a rational feasible vector \(y\). All constraints can be verified by exact rational arithmetic in polynomial time. The problem belongs to \(\mathrm{NP}\).

3. A polynomial reduction from CLIQUE

We use the classical \(\mathrm{NP}\)-complete CLIQUE problem: given a simple undirected graph and an integer threshold, decide whether the graph contains a clique of at least that size. [Karp, *Reducibility among Combinatorial Problems*](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

We may restrict to instances \(G=(V,F)\), with \(n=|V|\), satisfying

\[n/2<k\leq n.\tag{4}\]

Here is the justification for that restriction. Given any instance on \(n_0\) vertices with \(1\leq k_0\leq n_0\), add \(n_0\) vertices forming a clique and adjacent to every original vertex. The new graph has \(2n_0\) vertices and threshold \(n_0+k_0>n_0\). It contains a clique of that size exactly when the original graph contains a clique of size at least \(k_0\): a new clique contains at most \(n_0\) added vertices, while any original clique can be extended by all added vertices.

We now construct a society from an instance satisfying (4).

Types, masses, and capacities

For every vertex \(i\in V\), introduce a candidate type \(c_i\) and an auxiliary type \(a_i\). Introduce one additional type \(z\). Thus

\(\tau=2n+1.\)

Let \(\deg_G(i)\) denote the degree of vertex \(i\), and define

\(r_i=2k-\deg_G(i)-1.\)

Since \(\deg_G(i)+1\leq n<2k\), every \(r_i\) is a positive integer.

Set

\(C=n+\sum_{i\in V}r_i,\)

and let \(B\) be the smallest power of \(2\) strictly larger than \(C+2k\). Define

\[\mu_{c_i}=1/B,\qquad \mu_{a_i}=r_i/B,\qquad \mu_z=(B-C)/B.\tag{5}\]

All masses are positive, and

\(\sum_{t\in T}\mu_t=(n+\sum_i r_i+B-C)/B=1.\)

The capacities are

\[q_2=k/B,\qquad q_1=1-k/B.\tag{6}\]

They are positive and sum to \(1\). Moreover,

\[\mu_z=(B-C)/B>2k/B=2q_2.\tag{7}\]

In particular, \(q_2<1/2\).

Externalities

Set the following entries equal to \(1\), together with their symmetric counterparts:

  • \(e_{c_i c_i}=1\) for every candidate type.
  • \(e_{c_i c_j}=1\) for distinct vertices \(i,j\) precisely when \(\{i,j\}\in F\).
  • \(e_{c_i a_i}=1\) for every vertex \(i\).
  • \(e_{a_i z}=1\) for every vertex \(i\).
  • \(e_{zz}=1\).

Every other entry is \(0\). This is a symmetric binary matrix. Its diagonal entries use exactly the same-type externality interpretation specified in the question.

Every type receives the required internal values \(v_{t1}=1\) and \(v_{t2}=0\).

4. Correctness of the reduction

Auxiliary types and the additional type cannot use resource \(2\)

The total externality mass of \(z\) is

\(d_z=\mu_z+\sum_i\mu_{a_i}\geq\mu_z>2q_2.\)

For each auxiliary type,

\(d_{a_i}=\mu_{c_i}+\mu_z>2q_2.\)

The consequence of equations (1) and (2) therefore gives

\[y_z=0,\qquad y_{a_i}=0\quad(i\in V)\tag{8}\]

in every envy-free assignment. This conclusion permits arbitrary real splitting; even a positive fragment of one of these types on resource \(2\) would violate (1).

Every candidate has threshold exactly \(q_2\)

For a candidate type \(c_i\), its neighbors are itself, the candidate types corresponding to its graph neighbors, and its auxiliary type. Therefore

\[d_{c_i}=\frac{1+\deg_G(i)+r_i}{B}=\frac{2k}{B}=2q_2.\tag{9}\]

If \(y_{c_i}>0\), equations (1), (2), and (9) imply

\[\sum_t e_{c_i t}y_t=q_2.\tag{10}\]

Let

\(S=\{i\in V:y_{c_i}>0\}.\)

By (8), all resource-\(2\) mass belongs to candidate types, so

\[\sum_{i\in S}y_{c_i}=q_2.\tag{11}\]

For any \(i\in S\), subtracting (10) from (11) yields

\(0=\sum_{j\in S}(1-e_{c_i c_j})y_{c_j}.\)

Each summand is nonnegative, and every \(y_{c_j}\) appearing here is positive. Hence \(e_{c_i c_j}=1\) for all \(i,j\in S\). For distinct vertices, this means that \(S\) is a clique in \(G\).

Finally, each candidate has mass \(1/B\), so

\(\frac{k}{B}=q_2=\sum_{i\in S}y_{c_i}\leq\frac{|S|}{B}.\)

Thus \(|S|\geq k\). We have proved that existence of an envy-free assignment implies existence of the required clique.

A clique gives an envy-free assignment

Conversely, suppose \(G\) contains a clique of size at least \(k\), and choose exactly \(k\) vertices from it. Assign their candidate types entirely to resource \(2\); assign all remaining types entirely to resource \(1\).

The mass on resource \(2\) is \(k/B=q_2\), so the assignment satisfies both capacities.

Each candidate assigned to resource \(2\) has externality \(1\) toward every type assigned there, including its own type. Its externality on resource \(2\) is consequently \(q_2\). By (9), its externality on resource \(1\) is also \(q_2\). The weak comparison in (1) holds with equality.

Every type assigned to resource \(1\) satisfies the internal-value comparison. Hence the assignment is Pareto envy-free.

The constructed instance is therefore a yes-instance exactly when \(G\) has a clique of size at least \(k\).

5. Encoding size and complexity

The reduction has \(\tau=2n+1\). Since \(r_i\leq 2k-1\),

\(C=n+\sum_i r_i\leq 2kn\leq 2n^2.\)

The choice of \(B\) gives

\(B\leq 2(C+2k)=O(n^2).\)

Thus every mass and capacity in (5)–(6) is a dyadic rational with \(O(\log n)\) bits. The externality matrix has \(O(n^2)\) binary entries. Under the explicit matrix encoding, the total output length is

\(L=O(n^2+n\log n),\)

and the reduction can be implemented in \(O(n^2\log n)\) bit operations. It is therefore a polynomial-time many-one reduction.

Together with membership in \(\mathrm{NP}\), this proves \(\mathrm{NP}\)-completeness for the stated atomless problem. For \(m=2\), support enumeration gives \(2^\tau\operatorname{poly}(\tau,L)\) time; polynomial dependence on both \(\tau\) and \(L\) would imply \(\mathrm{P}=\mathrm{NP}\).
