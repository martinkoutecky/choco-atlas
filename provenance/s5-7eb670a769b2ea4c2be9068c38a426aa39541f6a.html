The continuous mirror question, as graded

Given \(m\) bins and a finite set of \(\tau\) types with rational masses \(\mu_t\), values \(v_t\), and public resource requirements \(w_{tj}\), with \(\sum_t\mu_t=1\), find a maximum-welfare allocation \(x_{tj}\ge 0\) satisfying \(\sum_j x_{tj}\le\mu_t\) and \(\sum_t w_{tj}x_{tj}\le b_j\) for each bin, where \(b_j\) is its capacity per unit population. Interpret \(x_{tj}\) as mass of agents assigned wholly to bin \(j\); the society is atomless, so each type’s mass can be partitioned without splitting any individual’s assignment.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of the \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) bins with positive binary-rational capacities \(b_j\) per unit population. Type \(t\) has positive binary-rational value \(v_t\), independent of the bin, and positive binary-rational public resource requirements \(w_{tj}\).
The society is atomless. An allocation \(x_{tj}\ge0\) partitions each type's mass among bins and an unassigned remainder; each assigned individual goes wholly to one bin.
Feasibility means \(\sum_{j=1}^m x_{tj}\le\mu_t\) for every type and \(\sum_{t=1}^{\tau}w_{tj}x_{tj}\le b_j\) for every bin. Welfare is \(W(x)=\sum_{t=1}^{\tau}\sum_{j=1}^m v_t x_{tj}\); let \(\mathrm{OPT}\) be its maximum over feasible allocations.
Let \(L\) be the total binary input length, including a rational accuracy parameter \(0<\varepsilon<1\).

For discrete indivisible agents with bin-independent positive values and public bin-dependent resource requirements, a polynomial-time truthful \((2+\varepsilon)\)-approximation mechanism is known ([Chekuri–Gamzu](https://arxiv.org/pdf/0906.2466)).

Result

The problem is exactly solvable in polynomial time. Consequently, it admits the requested \((2+\varepsilon)\)-approximation.

I use the allocation model specified in the question: different individuals of the same type may go to different bins, while each individual goes wholly to one bin. This permits continuous variables for the assigned masses without relaxing individual assignment requirements.

1. An exact linear programming formulation

Introduce one real variable \(x_{tj}\) for each supported type \(t\in\{1,\ldots,\tau\}\) and bin \(j\in\{1,\ldots,m\}\). Consider the linear program with objective

\[ \max \sum_{t=1}^{\tau}\sum_{j=1}^{m}v_t x_{tj}, \]

subject to the following constraints:

  • \(x_{tj}\ge 0\) for every \(t,j\);
  • \(\sum_{j=1}^{m}x_{tj}\le\mu_t\) for every \(t\);
  • \(\sum_{t=1}^{\tau}w_{tj}x_{tj}\le b_j\) for every \(j\).

These are exactly the feasibility constraints in the question, and the objective is exactly welfare. Thus the feasible allocations, as defined in the question, coincide with the feasible vectors of this linear program.

Atomlessness also explains why these vectors describe assignments of whole individuals. The divisibility theorem for finite atomless measures states that, for any measurable set of measure \(a\) and any \(s\in[0,a]\), there exists a measurable subset of measure \(s\). The population of each type has finite measure \(\mu_t\), and its restricted measure is atomless. Applying the theorem successively partitions that type into disjoint pieces of measures

\[ x_{t1},\ldots,x_{tm},\quad \mu_t-\sum_{j=1}^{m}x_{tj}. \]

Assign the first \(m\) pieces to their respective bins and leave the last piece unassigned. The last measure is nonnegative by the type constraint. Every individual belongs to precisely one piece, so no individual is divided between bins.

Therefore the linear program’s optimum equals \(\mathrm{OPT}\).

2. Existence and polynomial encoding size

Write \(n=\tau m\). The linear program has \(n\) variables and \(\tau+m+n\) inequalities, including nonnegativity.

Its feasible set is nonempty because \(x=0\) is feasible. Moreover, nonnegativity and the type constraints imply \(0\le x_{tj}\le\mu_t\le1\). The feasible set is closed and bounded, hence compact. The linear objective therefore attains a finite maximum.

All coefficients are rational. Only the explicitly listed supported types occur, so constructing the program requires no enumeration of additional possible types. Its binary description length \(S\) is polynomial in \(m,\tau,L\): the dimensions are polynomial, and every coefficient is either an input rational, zero, or one.

There is also an optimal solution with polynomial binary encoding length. Indeed, a linear objective on a nonempty compact polytope attains its maximum at a vertex. At such a vertex, \(n\) linearly independent active constraints determine the coordinates. Clear denominators in these constraints row by row. Each resulting integer coefficient, including the right-hand side, has binary length \(O(S)\). By the determinant expansion, the absolute values of the determinants in Cramer’s rule are at most

\[ n!\,2^{O(nS)}. \]

Their binary lengths are therefore \(O(nS+n\log n)\). Cramer’s rule represents every coordinate as a ratio of two such integers, proving polynomial output length. The output rationals need not be dyadic; the question imposes no such restriction on allocations.

3. Algorithm and guarantee

Use the standard polynomial-time theorem for rational linear programming:

Given an explicitly encoded rational linear program, a deterministic algorithm can determine feasibility and boundedness and, when a finite optimum is attained, return an exact rational optimal solution in time polynomial in its binary description length.

This is the polynomial-time solvability theorem established through the ellipsoid method; see [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/eng/zvmmf5239).

All hypotheses have been checked: the program is explicit and rational, its encoding length is polynomial, and it is feasible with an attained finite optimum. Accordingly, the algorithm constructs this program, solves it exactly, and returns its optimal vector \(x^*\).

By Section 1, this output is a feasible allocation and satisfies \(W(x^*)=\mathrm{OPT}\). Since welfare is nonnegative and \(0<\varepsilon<1\), it follows that

\[ W(x^*)=\mathrm{OPT}\ge\frac{\mathrm{OPT}}{2+\varepsilon}. \]

The running time is polynomial in \(m,\tau,L\), and hence also polynomial in \(m,\tau,L,1/\varepsilon\).

The [Chekuri–Gamzu result](https://arxiv.org/pdf/0906.2466) concerns truthful approximation mechanisms. Here the requested output is a feasible welfare-maximizing allocation; the stated problem includes no additional strategic requirement. Its atomless allocation constraints already give an exact linear program.
