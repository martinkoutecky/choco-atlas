The continuous mirror question, as graded

Given a finite preference DAG \(G=(V,A)\) and rational per-capita supplies \(q_v\ge0\) for each category \(v\in V\), find the minimum \(d\in\{0,\ldots,|V|\}\) for which there are masses \(x_B\ge0\) on integral bundles \(B\subseteq V\), with \(\sum_B x_B=1\), \(\sum_{B\ni v}x_B\le q_v\) for every \(v\), and \(x_B=0\) whenever \(\delta_G(B)>d\), where \(\delta_G(B)=|V\setminus\bigcup_{v\in B}\operatorname{succ}[v]|\).

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,A)\) be a finite simple DAG with \(m=|V|\). All agents share the strict partial preference order given by reachability: an arc points from a preferred category to a less preferred one. Define \(\operatorname{succ}[v]\) as \(v\) together with all vertices reachable from it.
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here there is one preference type, of mass \(1\), so \(\tau=1\). Supplies \(q_v\in\mathbb{Q}_{\ge0}\) are per capita; let \(L\) be the total binary input length.
An integral bundle is any \(B\subseteq V\), including the empty bundle, with dissatisfaction \(\delta_G(B)=\left|V\setminus\bigcup_{v\in B}\operatorname{succ}[v]\right|\). Supplies may remain unused.
For an input threshold \(d\in\{0,\ldots,m\}\), feasibility means that real masses \(x_B\ge0\), indexed by all integral bundles, satisfy \(\sum_{B\subseteq V}x_B=1\), \(\sum_{B\ni v}x_B\le q_v\) for every \(v\), and \(x_B=0\) whenever \(\delta_G(B)>d\). The bundle masses are allocation variables, not input types.

Is this threshold-feasibility problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard? Equivalently, what is the complexity of finding the minimum feasible \(d\)?

For a finite society with one copy of each item and pairwise disjoint bundles, threshold feasibility is \(\mathrm{NP}\)-complete for every fixed number \(k\ge3\) of agents, even with no directed path of length two and maximum in-degree two; for two agents it is solvable in linear time. [Source](https://arxiv.org/pdf/2312.01804).
No result settling exactly the mass-allocation problem above was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted the common preference graph as a single society type with mass one; bundle masses are solution variables rather than additional input types.
  • Defined closed successors using all directed paths, including the vertex itself, as required by the discrete dissatisfaction definition.
  • Retained arbitrary bundles, including the empty bundle, and unused supplies: these are permitted by the discrete allocation definition. Its nonempty-antichain restriction is a without-loss-of-generality observation, not a feasibility requirement.
  • Used threshold feasibility to state the two-sided complexity target while retaining minimum-threshold optimization as the equivalent computational question; defined L as total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Threshold feasibility is \(\mathrm{NP}\)-complete, even with \(\tau=1\), supplies in \(\{0,\tfrac12\}\), and a DAG having no directed path of length two and maximum in-degree three.

Consequently, computing the minimum feasible \(d\) is \(\mathrm{NP}\)-hard. A running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. Source problem and construction

We reduce from Positive NAE-3SAT. An instance has Boolean variables \(z_1,\ldots,z_n\) and clauses consisting of three distinct, unnegated variables. A satisfying assignment must give every clause at least one true variable and at least one false variable. This problem is \(\mathrm{NP}\)-complete, even under additional restrictions. [Darmann, Döcker, and Dorn](https://arxiv.org/abs/2412.03395).

Let the input formula have \(n\ge1\) variables and \(r\) clauses. Put \(R=n+1\).

For every variable \(z_i\), introduce two source vertices \(t_i,f_i\), each with supply \(\tfrac12\). They will represent assigning \(z_i\) true or false.

Introduce the following groups of fresh sink vertices, all with supply zero:

  • For each variable \(z_i\), a group \(U_i\) of \(R\) sinks. Add arcs from both \(t_i\) and \(f_i\) to every sink in \(U_i\).
  • For each clause \(C_j=\{z_a,z_b,z_c\}\), two groups \(T_j,F_j\), each containing \(R\) sinks. Add arcs from \(t_a,t_b,t_c\) to every sink in \(T_j\), and from \(f_a,f_b,f_c\) to every sink in \(F_j\).

There are no other vertices or arcs. Set the threshold to \(d=n\), and use the single society type of mass \(1\).

The resulting graph has

\(m=2n+(n+1)(n+2r)\)

vertices and \((n+1)(2n+6r)\) arcs. Thus its binary encoding has polynomial length. All arcs go from sources to sinks, so the graph is a simple DAG with no directed path of length two. Every sink has in-degree two or three.

We prove that the constructed instance is feasible exactly when the formula is NAE-satisfiable.

2. Feasibility implies a satisfying assignment

Suppose a feasible allocation \((x_B)_{B\subseteq V}\) exists.

First, every positive-mass bundle contains only source vertices. Indeed, for a sink \(s\), its zero supply gives

\(0\le\sum_{B\ni s}x_B\le q_s=0.\)

Because every summand is nonnegative, no bundle containing \(s\) can have positive mass.

Now consider any bundle \(B\) with \(x_B>0\). It satisfies \(\delta_G(B)\le n\).

Every sink group must be covered. The sinks within a group have identical predecessors. Since \(B\) contains only sources, if it contains none of those predecessors, all \(R=n+1\) sinks in that group are uncovered. This would give \(\delta_G(B)\ge n+1\), a contradiction.

Covering \(U_i\) therefore requires

\(B\cap\{t_i,f_i\}\ne\varnothing\)

for every \(i\). Consequently, every positive-mass bundle has \(|B|\ge n\).

On the other hand, summing the supply constraints over the source vertices gives

\(\sum_Bx_B|B|=\sum_{i=1}^{n}\left(\sum_{B\ni t_i}x_B+\sum_{B\ni f_i}x_B\right)\le n.\)

Because \(\sum_Bx_B=1\), we obtain

\(\sum_Bx_B(|B|-n)=0.\)

Every summand associated with a positive-mass bundle is nonnegative. Hence every such bundle has \(|B|=n\). Together with the requirement to meet each of the \(n\) disjoint pairs \(\{t_i,f_i\}\), this shows that every positive-mass bundle chooses exactly one source from each pair.

Choose one positive-mass bundle \(B\), which exists because the total mass is \(1\). Define an assignment by

\(z_i\text{ is true}\quad\Longleftrightarrow\quad t_i\in B.\)

For a clause \(C_j=\{z_a,z_b,z_c\}\), covering \(T_j\) requires at least one of \(t_a,t_b,t_c\) in \(B\). Thus the clause has a true variable. Covering \(F_j\) requires at least one of \(f_a,f_b,f_c\) in \(B\). Thus it also has a false variable.

Every clause is therefore NAE-satisfied.

3. A satisfying assignment implies feasibility

Conversely, suppose \(a\) is a NAE-satisfying assignment. Its Boolean complement \(\bar a\) is also NAE-satisfying: complementing every value preserves the property that each clause contains both values.

Define \(B_a\) to contain \(t_i\) when \(a(z_i)\) is true and \(f_i\) otherwise. Define \(B_{\bar a}\) analogously.

Each bundle contains exactly \(n\) sources. Each covers every variable group \(U_i\), because it chooses one source from each variable pair. Each also covers every \(T_j\) and \(F_j\), because its assignment NAE-satisfies every clause.

Thus all sinks are covered. Exactly \(n\) source vertices are uncovered: sources have no incoming arcs, so a source is covered precisely when it belongs to the bundle. Therefore,

\(\delta_G(B_a)=\delta_G(B_{\bar a})=n.\)

Assign masses

\(x_{B_a}=x_{B_{\bar a}}=\tfrac12,\)

with all other bundle masses zero. Every source belongs to exactly one of these two bundles, so its consumption is exactly \(\tfrac12\). No sink is consumed. All supply and threshold constraints hold.

These two masses are allocation variables; the society still has only its single input type of mass \(1\).

Sections 2 and 3 establish a polynomial-time many-one reduction, proving \(\mathrm{NP}\)-hardness.

4. Membership in \(\mathrm{NP}\)

We must also show that allowing real allocation masses does not require certificates of unbounded size or precision.

For an arbitrary input, define the acceptable bundle family

\(\mathcal F_d=\{B\subseteq V:\delta_G(B)\le d\}.\)

Replace every supply \(q_v\) by \(q'_v=\min\{q_v,1\}\). This preserves feasibility because the consumption of any item is at most the total mass \(1\).

Introduce nonnegative slack variables \(s_v\). Feasibility is equivalent to

\(\sum_{B\in\mathcal F_d}x_B=1,\qquad \sum_{\substack{B\in\mathcal F_d\\v\in B}}x_B+s_v=q'_v\quad(v\in V).\)

Write this as \(My=b\), with \(y\ge0\). There are \(h=m+1\) rows. A bundle column is \((1,\mathbf1_B)\), and a slack column is \((0,e_v)\); hence every entry of \(M\) is zero or one.

A certificate uses at most \(m+1\) bundles

If the system is feasible, choose a feasible \(y\) with the smallest number of positive coordinates. Its positive-coordinate columns are linearly independent.

To prove this, suppose they were dependent. There would be a nonzero vector \(z\), supported only on those coordinates, satisfying \(Mz=0\). Reverse its sign if necessary so that some coordinate is negative. Set

\(t=\min_{j:z_j<0}\frac{y_j}{-z_j}>0.\)

Then \(y+tz\) remains nonnegative and satisfies the same equations. At least one previously positive coordinate becomes zero, and no previously zero coordinate becomes positive. This contradicts minimality.

There are only \(h\) rows, so at most \(h=m+1\) coordinates are positive. In particular, at most \(m+1\) bundles have positive mass.

The masses have polynomial binary length

For a feasible instance, \(\mathcal F_d\) is nonempty. The slack columns span the last \(m\) coordinates, and any bundle column has first coordinate \(1\). Thus \(M\) has row rank \(h\).

Extend the independent positive-coordinate columns to an \(h\)-column basis, giving a nonsingular zero-one matrix \(T\). Coordinates on the added columns are zero, and the basis coordinates solve \(Ty=b\).

Let \(Q\) be the product of the denominators of the capped supplies. Its binary length is \(O(L)\). Every entry of \(Qb\) is an integer between zero and \(Q\).

By Cramer’s rule, each basis coordinate is a ratio with denominator \(Q\det T\). The determinant expansion gives

\(|\det T|\le h!,\)

and every numerator, obtained by replacing one column of \(T\) by \(Qb\), has absolute value at most \(Qh!\). Hence every mass has binary length

\(O(L+h\log h).\)

A certificate can therefore list at most \(m+1\) bundles and their rational masses, with total polynomial length. A verifier computes reachability, checks each listed bundle’s dissatisfaction, and checks the mass and supply constraints using exact rational arithmetic. All these operations take polynomial time.

Thus threshold feasibility belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness.

5. Computing the minimum threshold

Feasibility is monotone in \(d\), and \(d=m\) is always feasible using the empty bundle. Consequently, the minimum feasible threshold can be found using \(O(\log(m+1))\) queries to the threshold-feasibility decision problem.

For the reduction above, no threshold below \(n\) can be feasible. Indeed, every positive-mass bundle contains only sources and satisfies

\(\delta_G(B)\ge2n-|B|.\)

A threshold \(d<n\) would therefore force every positive-mass bundle to have \(|B|>n\), contradicting the total source supply \(n\).

The constructed instance consequently has minimum feasible threshold exactly \(n\) if and only if the formula is NAE-satisfiable. Computing that minimum is therefore \(\mathrm{NP}\)-hard.
