The continuous mirror question, as graded

Given binary issues \(X_1,\ldots,X_p\), an explicit finite support of complete conditional approval ballot types \(B\) with acyclic dependency graphs of maximum indegree \(1\), rational masses \(\mu_B>0\) summing to \(1\), and a rational threshold \(q\), does there exist an outcome \(d\in\{0,1\}^p\) such that \(\sum_B \mu_B\delta(d,B)\le q\)?

Packaged proof task (what the prover saw — nothing else)

There are \(m=p\ge 1\) binary issues \(X_1,\ldots,X_m\). A complete conditional approval ballot \(B\) specifies an acyclic directed graph \(G_B\) on the issues, with maximum indegree \(1\), and, for every issue \(X_i\) and every assignment \(u\) to its parents, an explicitly listed approval set \(a_{B,i}(u)\subseteq\{0,1\}\). Empty approval sets and approval of both values are allowed; different ballots may have different graphs.
A society is given by its support: the list of the \(\tau\) distinct ballot types with positive mass, each mass \(\mu_B\) a binary rational, with \(\sum_B\mu_B=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length, including the ballots, masses, and threshold.
Every deterministic outcome \(d\in\{0,1\}^m\) is feasible. Define \(\delta(d,B)=|\{i:d_i\notin a_{B,i}(d_{\operatorname{Par}_{G_B}(X_i)})\}|\); a parentless issue has one unconditional approval set. Given \(q\in\mathbb{Q}\), decide whether some outcome satisfies \(\sum_B\mu_B\delta(d,B)\le q\).

Is this decision problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For an explicitly listed finite electorate and an integer total-disagreement threshold, the corresponding decision problem is NP-complete even for binary issues and acyclic ballot graphs of maximum indegree \(1\).
For finite electorates with separable ballots (graphs with no edges) and unrestricted outcomes, conditional minisum winner determination is polynomial-time solvable.

Modeling choices made when packaging the task

  • Specified that approval sets may be empty or contain both binary values, as permitted by the ballot definition.
  • Specified that all deterministic binary outcomes are feasible, matching the anchor's unrestricted outcome domain.
  • Used m=p for the number of issues and defined L as the total encoded input length.

Result

The decision problem is \(\mathrm{NP}\)-complete. The hardness follows from the finite-electorate hardness stated in the question, even when every mass is a dyadic rational.

Membership in \(\mathrm{NP}\)

A certificate is an outcome \(d\in\{0,1\}^m\).

For each supported ballot \(B\) and issue \(X_i\), we read the value of its parent, if present, and consult the explicitly listed approval set. This determines \(\delta(d,B)\) using \(O(m)\) table lookups per ballot.

We can then compute and compare \(\sum_B\mu_B\delta(d,B)\) with \(q\) exactly in polynomial time. To justify the arithmetic bound, write \(\mu_B=a_B/b_B\) and \(q=c/e\), with positive denominators. The common denominator \(D=e\prod_B b_B\) has bit length at most the sum of the input denominator bit lengths, hence \(O(L)\). Multiplication by disagreement counts, which lie between \(0\) and \(m\), and summation over \(\tau\) terms increase the required bit length by at most \(O(\log m+\log\tau)\). Thus the verification uses polynomially many operations on integers of polynomial bit length.

Therefore the problem belongs to \(\mathrm{NP}\).

Hardness by converting an explicit electorate to support

We use precisely the hardness premise supplied in the question: the corresponding problem for an explicitly listed finite electorate and an integer total-disagreement threshold is \(\mathrm{NP}\)-complete under the same ballot restrictions.

Let a source instance consist of ballots \(B_1,\ldots,B_n\), where \(n\geq 1\), and an integer threshold \(K\). Its question is whether some outcome \(d\) satisfies

\(\sum_{j=1}^{n}\delta(d,B_j)\leq K.\)

We construct a support instance as follows.

1. Add neutral ballots to obtain a power-of-two electorate size.

Set \(N=2^{\lceil\log_2 n\rceil}\). Let \(B^\circ\) have an edgeless graph and unconditional approval set \(\{0,1\}\) at every issue. This is a valid complete ballot, and \(\delta(d,B^\circ)=0\) for every outcome \(d\).

Append \(N-n\) copies of \(B^\circ\). This does not change total disagreement for any outcome. Moreover, \(n\leq N<2n\), so even explicitly performing this padding has polynomial cost.

2. Aggregate identical ballot types.

For each distinct type \(B\) in the padded electorate, let \(c_B\) be its multiplicity, and assign mass \(\mu_B=c_B/N\). List only types with \(c_B>0\).

These masses are positive and sum to \(1\). They are dyadic rationals because \(N\) is a power of two. Their numerators and denominators require \(O(\log n)\) bits each. Identical types can be identified in polynomial time by comparing their parent lists and approval tables in a canonical issue order.

The resulting support has size \(\tau\leq n+1\). All original ballot graphs retain their acyclicity and maximum indegree \(1\), and the added neutral ballot satisfies these restrictions as well.

3. Scale the threshold.

Set \(q=K/N\). For every outcome \(d\), the constructed instance satisfies

\(\sum_B\mu_B\delta(d,B)=\frac{1}{N}\sum_{j=1}^{n}\delta(d,B_j),\)

because aggregation preserves multiplicities and the added ballots contribute zero. Since \(N>0\), it follows that

\(\sum_B\mu_B\delta(d,B)\leq q\quad\Longleftrightarrow\quad\sum_{j=1}^{n}\delta(d,B_j)\leq K.\)

Thus the construction preserves both yes-instances and no-instances.

The construction and its output size are polynomial in the source input length: it retains at most \(n+1\) ballot types and adds only \(O(\log n)\) bits per mass and to the threshold denominator. Hence it is a polynomial-time many-one reduction, proving \(\mathrm{NP}\)-hardness.

Conclusion

Together, membership and hardness establish \(\mathrm{NP}\)-completeness. Consequently, an algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\). Specifying the society by its support does not remove the stated finite-electorate hardness.
