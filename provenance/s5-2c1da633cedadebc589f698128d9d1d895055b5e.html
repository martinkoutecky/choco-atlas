The continuous mirror question, as graded

Given a finite set of bipartite multigraph templates mathcal H with rational copy masses rho_H and cancelable valuations, find for each template a measurable policy lambda_{H,A} over complete local allocations, with positive mass only on allocations that are EFX within that copy. Equivalently, find an EFX allocation for each template and assign all its copy mass to that allocation.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(\mathcal H\) of \(\tau\) types with positive binary-rational masses \(\rho_H\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Each type specifies a finite bipartite multigraph \(H=(V_H,E_H)\) with at least one vertex, whose vertices are agents and whose individually listed edges are indivisible goods, together with its agents' valuations.
Each valuation \(v_{H,u}:2^{E_H}\to\mathbb Z_{\ge0}\) is represented by a Boolean circuit taking a bundle's incidence vector and returning its binary value; the following properties are promised. It is monotone, has \(v_{H,u}(\varnothing)=0\), and satisfies \(v_{H,u}(S\cup\{e\})=v_{H,u}(S)\) whenever \(u\) is not an endpoint of \(e\).
Cancelable means that for all \(S,T\subseteq E_H\) and \(g\notin S\cup T\), \(v_{H,u}(S)\ge v_{H,u}(T)\) implies \(v_{H,u}(S\cup\{g\})\ge v_{H,u}(T\cup\{g\})\).
A complete local allocation \(A=(A_u)_{u\in V_H}\) partitions \(E_H\) among all vertices; any vertex may receive any edge. Use EFX with removal of every good, including goods of zero marginal value to the envying agent.
A policy assigns masses \(\lambda_{H,A}\ge0\) to complete local allocations, with \(\sum_A\lambda_{H,A}=\rho_H\) and \(\lambda_{H,A}>0\) only for allocations EFX within that copy. Copies have separate goods and agents; there are no comparisons or constraints across copies. Equivalently, the required object is one complete EFX allocation for each supported template.
Let \(m=\sum_H|E_H|\), \(n=\sum_H|V_H|\), and \(L\) be the total binary input length, including circuits and masses; state running times in \(m,n,\tau,L\).

Is computing such a policy solvable in time polynomial in \(m,n,\tau,L\), or is it NP-hard?

For a single finite bipartite multigraph with cancelable graphical valuations, a complete EFX allocation always exists and can be computed in polynomial time ([Bhaskar and Pandit](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.FSTTCS.2025.15)).

  • EFX uses removal of every good, including goods of zero marginal value to the envying agent.

Conclusion and interpretation

Computing the policy is polynomial-time solvable, under the intended promise that every valuation is cancelable in the stated sense. A policy with exactly one positive entry per supported type suffices.

1. Applying the single-template theorem

Write \(m_H=|E_H|\) and \(n_H=|V_H|\). For a complete allocation \(A\), the required EFX condition is
\[ v_{H,u}(A_u)\ge v_{H,u}(A_w\setminus\{g\}) \quad\text{for every }u,w\in V_H\text{ and }g\in A_w. \]

Bhaskar and Pandit’s Theorem 3 provides a complete EFX allocation for a finite bipartite multigraph with monotone cancelable graphical valuations. Their definition quantifies over every removed good, including goods with zero marginal value, and permits allocation to vertices other than an edge’s endpoints. Thus it matches this problem. [Theorem 3 and definitions](https://drops.dagstuhl.de/storage/00lipics/lipics-vol360-fsttcs2025/LIPIcs.FSTTCS.2025.15/LIPIcs.FSTTCS.2025.15.pdf)

All valuation hypotheses hold here: monotonicity, normalization, nonnegative integer values, cancelability, and zero marginal value for nonincident edges. In particular, repeatedly removing nonincident edges gives
\[ v_{H,u}(S)=v_{H,u}(S\cap\delta_H(u)), \]
where \(\delta_H(u)\) is the set of edges incident to \(u\).

Isolated vertices cause no difficulty: their valuations are identically zero, and they can receive empty bundles. If \(m_H=0\), assigning every vertex the empty bundle is already complete and EFX.

It remains to justify polynomial running time for the circuit representation, rather than merely assuming efficient valuation access.

2. Implementing the cutting procedure

The cited algorithm uses valuation evaluations, bundle operations, and a procedure partitioning a set of goods into two bundles that are EFX for two identical agents. Its Algorithm 1 invokes that procedure once per nonempty parallel-edge class. [Algorithm 1](https://drops.dagstuhl.de/storage/00lipics/lipics-vol360-fsttcs2025/LIPIcs.FSTTCS.2025.15/LIPIcs.FSTTCS.2025.15.pdf)

Here is a direct implementation of that procedure.

Let \(v\) be a monotone cancelable valuation and let \(S\) contain \(k\) goods. Order them as \(g_1,\ldots,g_k\) so that
\[ v(\{g_1\})\ge\cdots\ge v(\{g_k\}). \]
Starting with two empty bundles, assign each successive good to a bundle having the smaller current value, breaking ties arbitrarily.

We prove that the resulting partition is EFX. Fix a nonempty final bundle \(B\), let \(g\) be its last assigned good, and let \(C\) be the other final bundle. Immediately before assigning \(g\), the algorithm chose \(B\), so the other bundle’s value was at least \(v(B\setminus\{g\})\). Monotonicity therefore gives
\[ v(C)\ge v(B\setminus\{g\}). \]

For any \(h\in B\setminus\{g\}\), the ordering gives
\[ v(\{h\})\ge v(\{g\}). \]
Apply cancelability successively to add every good in \(B\setminus\{g,h\}\) to both singleton bundles. Each added good is absent from both current bundles, as required by the definition. Consequently,
\[ v(B\setminus\{g\})\ge v(B\setminus\{h\}). \]
Combining these inequalities proves
\[ v(C)\ge v(B\setminus\{h\}) \quad\text{for every }h\in B. \]
Applying the same argument to the other nonempty bundle proves EFX for both agents. Empty bundles impose no removal conditions. The argument also covers zero-valued goods.

This procedure uses \(O(k)\) valuation evaluations and \(O(k\log(k+1))\) comparisons, after storing singleton values.

3. Constructing the policy

For each supported type \(H\), independently run the single-template algorithm to obtain a complete EFX allocation \(A^H\). Output the sparse policy
\[ \lambda_{H,A}= \begin{cases} \rho_H,&A=A^H,\\ 0,&A\ne A^H. \end{cases} \]

For each \(H\), its policy masses sum to \(\rho_H\), and its only positive entry corresponds to a complete EFX allocation. These are exactly the required constraints, because copies have no comparisons or constraints across them.

The masses are copied from the input; no rounding or rational arithmetic is needed. Unlisted entries are implicitly zero, so exponentially many possible allocations need not be enumerated.

4. Running time and output size

Each valuation query is implemented by evaluating its Boolean circuit on a bundle incidence vector. Both the circuit size and its output bit length are bounded by \(L\), so evaluation and comparison take polynomial time in \(m_H+L\), irrespective of the numerical magnitude of the value.

The parallel-edge classes partition the goods. Hence, over all supported templates, the cutting procedures use \(O(m)\) valuation evaluations and \(O(m\log(m+1))\) comparisons. The surrounding allocation algorithm adds \(O(m+n)\) evaluations and polynomially many explicit bundle operations.

For a conservative bit-complexity bound, put
\[ N=m+n+\tau+L+2. \]
Using explicit incidence vectors and straightforward circuit evaluation, all these operations can be implemented within \(O(N^4)\) time. This bound is deliberately loose but polynomial in every requested parameter.

The sparse output contains \(\tau\) allocations and the original masses. Encoding each good by its recipient requires at most
\[ O\!\left(L+m\log(n+1)+n+\tau\right) \]
bits.

Thus the promised search problem admits a deterministic polynomial-time algorithm.
