The continuous mirror question, as graded

Given a finite alternative set \(A\) and a finite-support distribution \(\mu\) over partial orders \(\Pi_t\) on \(A\), with positive binary-rational masses summing to \(1\), decide whether there exist a linear order \(>\) on \(A\) and a weak-order completion \(\succeq_t\) of each \(\Pi_t\) such that the completed support is top monotonic with respect to \(>\), as in Definition 1.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a nonempty finite alternative set, with \(m=|A|\). A society is given by its support: \(\tau\) distinct strict partial orders \(\Pi_t\) on \(A\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length, with partial orders encoded by their ordered pairs.
Choose one weak-order completion \(\succeq_t\) for each type, requiring \(a\Pi_t b\Rightarrow a\succ_t b\), where \(\succ_t\) is its strict part. Each type's entire mass receives that completion.
For nonempty \(S\subseteq A\), let \(T_t(S)\) be the set of most-preferred alternatives in \(S\) under \(\succeq_t\). Set \(U=\bigcup_tT_t(A)\) and \(\mathcal F=\{A\}\cup\{S\subseteq U:|S|=3\}\), computed from the chosen completions.
The completed support is top monotonic with respect to a linear order \(>\) on \(A\) if, for every \(S\in\mathcal F\), every pair of support types \(t,u\) (including \(t=u\)), and every \(x\in T_t(S),y\in T_u(S),z\in S\), \((x>y>z\lor z>y>x)\) implies \(y\succeq_t z\) when \(z\in T_t(S)\cup T_u(S)\), and implies \(y\succ_t z\) otherwise. The additional requirement that each \(T_t(A)\) be a finite union of closed intervals in \(>\) is automatic for finite \(A\).

Is deciding whether such completions and a common linear order exist solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite lists of agents, existence of top-monotonic weak-order completions of strict partial orders is NP-complete ([Aziz, 2014](https://arxiv.org/abs/1403.7625)). Recognition when the weak orders are already complete is polynomial-time solvable ([Magiera and Faliszewski, 2017](https://www.ijcai.org/proceedings/2017/0046.pdf)). No separate result for the distribution-input completion problem was located.

Result

The decision problem is \(\mathsf{NP}\)-complete. In particular, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathsf{P}=\mathsf{NP}\).

The requirement that each distinct partial-order type receive one completion does not obstruct the transfer from the finite-agent problem. The essential facts are that top monotonicity is preserved by deleting agents and by duplicating completed preferences.

1. Deletion and duplication lemmas

Let \(P=(\succeq_i)_{i\in I}\) be a nonempty finite profile of weak orders on \(A\). Write \(T_i(S)\) for its top sets, \(U(P)=\bigcup_{i\in I}T_i(A)\), and \(\mathcal F(P)=\{A\}\cup\{S\subseteq U(P):|S|=3\}\).

Lemma 1: deleting agents preserves top monotonicity.
Suppose \(P\) is top monotonic with respect to \(>\), and let \(\varnothing\ne J\subseteq I\). Then the restricted profile \(P|_J\) is top monotonic with respect to the same order.

Proof. Each retained agent has exactly the same preferences and top sets as before. Moreover, \(U(P|_J)\subseteq U(P)\), so \(\mathcal F(P|_J)\subseteq\mathcal F(P)\).

Consider any \(S\in\mathcal F(P|_J)\), agents \(i,j\in J\), and alternatives \(x\in T_i(S)\), \(y\in T_j(S)\), \(z\in S\). This combination also occurs among the conditions checked for \(P\). Its antecedent, its test of membership in \(T_i(S)\cup T_j(S)\), and its required preference comparison are unchanged. Consequently, its implication holds. This covers every required condition, including those with \(i=j\). The interval requirement is automatic because \(A\) is finite. \(\square\)

Lemma 2: duplicating completed preferences preserves top monotonicity.
Suppose \(P\) is top monotonic with respect to \(>\). Let \(q:I'\to I\) be a surjection, and give each \(i'\in I'\) the weak order \(\succeq_{q(i')}\). Then the resulting profile \(P'\) is top monotonic with respect to \(>\).

Proof. For every nonempty \(S\subseteq A\), the new top sets satisfy \(T'_{i'}(S)=T_{q(i')}(S)\). Surjectivity gives \(U(P')=U(P)\), hence \(\mathcal F(P')=\mathcal F(P)\).

Every condition for a pair \(i',j'\) in \(P'\) is precisely the condition for \(q(i'),q(j')\) in \(P\), with identical top sets and preference comparisons. The latter condition holds, including when \(q(i')=q(j')\). \(\square\)

2. Removing repeated partial-order types preserves feasibility

Consider a finite-agent instance consisting of strict partial orders \((\Pi_i)_{i=1}^n\), where \(n\geq1\). Partition the agents according to equality of their partial orders. Let \(\widehat\Pi_1,\ldots,\widehat\Pi_k\) be the distinct relations.

We claim that the original instance has top-monotonic weak-order completions if and only if there is one completion of each \(\widehat\Pi_t\) forming a top-monotonic profile.

Forward implication. Suppose the agents have feasible completions, possibly different completions for agents with identical partial orders. Choose one representative agent from each class and retain its completion. By Lemma 1, the retained completed profile remains top monotonic. Its completion for class \(t\) extends \(\widehat\Pi_t\), because the representative’s original partial order equals \(\widehat\Pi_t\).

Reverse implication. Suppose one feasible completion has been chosen for each \(\widehat\Pi_t\). Give every original agent the completion of its class. Each completion preserves all strict comparisons required by that agent. Lemma 2 shows that the expanded profile remains top monotonic.

Thus repeated input types can be removed without changing the answer. This argument does not assume that repeated types originally receive identical completions.

3. Polynomial reduction to distribution input

We use the known finite-agent hardness theorem stated in the question: deciding whether a finite list of strict partial orders admits top-monotonic weak-order completions is \(\mathsf{NP}\)-complete. Aziz’s Definition 3 and Theorem 2 formulate this completion problem; his Definition 1 uses the same family of sets and the same implication as the present task. [Aziz, *Testing Top Monotonicity*](https://arxiv.org/pdf/1403.7625).

Given such an instance, keep \(A\) and construct the distinct relations \(\widehat\Pi_1,\ldots,\widehat\Pi_k\). Comparing their ordered-pair encodings and removing repetitions takes polynomial time.

To satisfy even the interpretation that “binary-rational” means a dyadic rational, let \(D=2^{\lceil\log_2 k\rceil}\). Assign masses

\(\mu_t=1/D\) for \(1\leq t<k\), and \(\mu_k=(D-k+1)/D\).

Because \(D\geq k\), every mass is positive. Their sum is

\(\sum_{t=1}^k\mu_t=((k-1)+(D-k+1))/D=1\).

This also handles \(k=1\), when \(D=1\) and \(\mu_1=1\). Each mass has an encoding of length \(O(\log(k+1))\), so the output has polynomial bit length.

The masses do not enter any top-monotonicity condition in the task. Therefore, by Section 2, the constructed distribution instance is feasible exactly when the original finite-agent instance is feasible.

All target hypotheses are satisfied: the support relations are distinct strict partial orders, every mass is positive, the masses sum to one, and each support type receives one completion. This proves \(\mathsf{NP}\)-hardness by a polynomial many-one reduction.

4. Membership in \(\mathsf{NP}\)

A certificate consists of a permutation specifying \(>\), together with a rank function \(r_t:A\to\{1,\ldots,m\}\) for each support type. Interpret ranks by

\(a\succeq_t b\) if and only if \(r_t(a)\leq r_t(b)\).

Equal ranks represent indifference. Every such function defines a weak order, and every weak order on \(A\) has such a representation. The certificate length is \(O((\tau+1)m\log(m+1))\).

The verifier first checks that the axis is a permutation and that every required pair \(a\Pi_t b\) satisfies \(r_t(a)<r_t(b)\).

It then computes each global top set, their union \(U\), and the family \(\mathcal F\). For every \(S\in\mathcal F\), it computes \(T_t(S)\) as the alternatives of minimum rank in \(S\), and checks all implications from the question.

For \(S=A\), there are at most \(\tau^2m^3\) combinations of \(t,u,x,y,z\). For each three-element set, there are at most \(27\tau^2\) combinations, and there are at most \(\binom m3\) such sets. Each implication is checked using axis positions, top-set membership, and rank comparisons. Hence verification takes polynomial time in \(m,\tau,L\).

The problem therefore belongs to \(\mathsf{NP}\), completing the proof of \(\mathsf{NP}\)-completeness.
