The continuous mirror question, as graded

Given \(C\), target \(w\), deletion budget \(\ell\), and an explicitly represented rational distribution \(\mu\) over types \(\theta=(\succ,A)\), where \(A\) is a nonempty proper prefix of \(\succ\), choose \(D\subseteq C\setminus\{w\}\) with \(|D|\le\ell\); restrict each type to \(C\setminus D\), apply the paper's rewrite rule, and decide whether \(w\) is the unique winner of the resulting mass-weighted approval election.

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m=|C|\geq2\), a target \(w\in C\), and a binary-encoded nonnegative integer deletion budget \(\ell\), consider the following decision problem.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types; masses sum to \(1\). Each type \(\theta=(\succ,A)\) consists of a strict linear order on \(C\) and a nonempty proper prefix \(A\) of that order. Let \(L\) be the total input bit length; state running times in \(m,\tau,L,\ell\).
Choose \(D\subseteq C\setminus\{w\}\) with \(|D|\leq\ell\), and put \(R=C\setminus D\). Restrict each order to \(R\) and initially set its approval set to \(A\cap R\).
When \(|R|\geq2\), replace an empty approval set by the singleton containing the highest-ranked survivor, and replace an approval set equal to \(R\) by \(R\) minus the lowest-ranked survivor; otherwise leave approvals unchanged. When \(|R|=1\), leave approvals unchanged.
Each survivor's score is the total mass of types approving it after these operations. All candidates attaining the maximum score are winners, with no tie-breaking; a sole survivor is always the unique winner. Decide whether some permitted deletion makes \(w\) the unique winner.

Is this rational-mass constructive candidate-deletion problem solvable in polynomial time, or is it \(\mathrm{NP}\)-hard?

For explicitly listed finite voters, constructive candidate deletion under this same SP-AV rewrite rule is \(\mathrm{NP}\)-hard ([Erdélyi, Nowak, and Rothe](https://arxiv.org/pdf/0806.0535)).
No result explicitly treating the support-represented rational-mass version was located in the literature search.

Modeling choices made when packaging the task

  • Normalize the positive rational masses to sum to one, as the input is a distribution.
  • Use strict linear orders and a binary-encoded nonnegative integer deletion budget, following the discrete domains.
  • Resolve the rewrite rule explicitly: empty approvals become the top singleton, whereas approval of every survivor becomes approval of every survivor except the bottom candidate.
  • Allow deletion down to the target alone; apply no rewrite in that case and regard the sole survivor as the unique winner, following the full-version convention.
  • Use exact mass-weighted approval scores and retain all score ties as multiple winners.
  • Define L as the total input bit length.

Result

The problem is \(\mathrm{NP}\)-complete under polynomial-time many-one reductions. Thus it is \(\mathrm{NP}\)-hard, and a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).

The key point is that explicitly listed voters can be converted to rational masses in polynomial time, preserving the outcome for every deletion set.

1. The finite-voter hardness result applies

We use the following known result: constructive candidate deletion for SP-AV, with explicitly listed voters and the unique-winner objective, is \(\mathrm{NP}\)-hard. This is [Erdélyi, Nowak, and Rothe, Theorem 3.10](https://arxiv.org/pdf/0806.0535#page=17).

Its hypotheses match the present problem:

  • The hard instances use strict linear orders and nonempty proper approval prefixes. In the displayed construction, every ballot has nonempty blocks on both sides of its approval line; the underlying hitting-set subsets are nonempty.
  • Section 2.2.2 specifies that, after deletion, an empty approval prefix becomes the top singleton, and a full approval prefix loses the bottom candidate.
  • The objective is to make the designated candidate the unique winner. A successful deletion therefore retains that candidate.
  • Section 2.3 makes a sole survivor a winner regardless of its approvals.

Consequently, the cited hardness holds for the finite-voter version of exactly the rule in the question.

2. Polynomial-time conversion to rational support

Take an instance from that finite-voter problem. Write its explicitly listed voters as \(\theta_1,\ldots,\theta_N\), where \(N>0\).

Group voters having identical orders and identical approval prefixes. Let the distinct types be \(\eta_1,\ldots,\eta_\tau\), with multiplicities \(n_1,\ldots,n_\tau\). Assign type \(\eta_i\) the rational mass \(p_i=n_i/N\). Keep the candidate set, target, and deletion budget unchanged.

This is a valid society: every \(p_i\) is positive, and

\(\displaystyle \sum_{i=1}^{\tau}p_i=\frac{\sum_{i=1}^{\tau}n_i}{N}=1.\)

Furthermore, \(\tau\leq N\), and each numerator and denominator needs only \(O(\log(N+1))\) bits. Grouping can be performed by sorting the explicitly listed ballots. Since those ballots are part of the source input, this takes polynomial time and produces polynomially many output bits. Fractions can also be reduced in polynomial time if the encoding requires reduced fractions.

We now prove preservation of the decision answer.

Fix any permitted deletion set \(D\), and put \(R=C\setminus D\). For each type \(\eta_i\) and survivor \(c\), define \(b_i(D,c)\in\{0,1\}\) to indicate whether that type approves \(c\) after restriction and rewriting.

The rewrite operation depends only on the type and \(R\), so all \(n_i\) voters of type \(\eta_i\) produce the same indicator. Hence the finite-voter score and rational-mass score satisfy

\(\displaystyle S_{\mathrm{finite}}(D,c)=\sum_{i=1}^{\tau}n_i b_i(D,c), \qquad S_{\mathrm{mass}}(D,c)=\sum_{i=1}^{\tau}\frac{n_i}{N}b_i(D,c) =\frac{S_{\mathrm{finite}}(D,c)}{N}. \)

Because \(N>0\), multiplication by \(1/N\) preserves all strict comparisons and all equalities. When \(|R|\geq2\), the target is therefore the unique winner in one representation exactly when it is the unique winner in the other. When \(|R|=1\), it is the unique winner in both by the specified convention.

The permitted deletion sets are unchanged. Thus the conversion preserves yes-instances and no-instances, proving \(\mathrm{NP}\)-hardness.

3. Exact verification and membership in \(\mathrm{NP}\)

A certificate is an \(m\)-bit indicator vector for \(D\). Check that \(w\notin D\) and \(|D|\leq\ell\), comparing the cardinality with the binary-encoded budget. If only \(w\) survives, accept.

Otherwise, scan each supported type, restrict its order, and apply the prescribed rewrite. This requires \(O(\tau m)\) elementary operations.

To bound the arithmetic cost, write the input masses as \(p_i=a_i/b_i\), with positive integer denominators, and define

\(\displaystyle P=\prod_{i=1}^{\tau}b_i, \qquad q_i=a_i(P/b_i).\)

The bit length of \(P\) is \(O(L)\), since the denominator bit lengths sum to at most \(L\). Moreover,

\(\displaystyle \sum_{i=1}^{\tau}q_i=P,\)

so every integer score obtained by adding the appropriate \(q_i\) lies between \(0\) and \(P\), and has \(O(L)\) bits.

Using schoolbook integer arithmetic, constructing \(P\) and all \(q_i\) takes \(O(\tau L^2)\) bit operations. Accumulating scores takes \(O(\tau mL)\) bit operations. Accept precisely when the integer score of \(w\) strictly exceeds that of every other survivor.

A conservative total verification bound is therefore

\(\displaystyle T_{\mathrm{verify}}(m,\tau,L,\ell) =O\!\left(L+\tau L^2+\tau mL\right).\)

The bit length of \(\ell\) is already included in \(L\); there is no dependence on its numerical magnitude. This proves membership in \(\mathrm{NP}\), completing the \(\mathrm{NP}\)-completeness proof.

4. Budget boundary and an explicit decision-time bound

If \(\ell\geq m-1\), the answer is immediately yes: delete every candidate other than \(w\). The hardness concerns budgets below this boundary.

For completeness, let \(k=\min\{\ell,m-1\}\). Enumerating all permitted deletion sets and applying the verifier gives the deterministic bound

\(\displaystyle O\!\left( \left[\sum_{j=0}^{k}\binom{m-1}{j}\right] \left[L+\tau L^2+\tau mL\right] \right). \)

Thus the support representation admits exact polynomial-time verification, while its decision problem remains \(\mathrm{NP}\)-complete.
