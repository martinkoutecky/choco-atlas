The continuous mirror question, as graded

Given a finite set of supported argument types \(T\), a type-uniform attack relation \(R\subseteq T\times T\), a rational distribution \(\mu\) with \(\mu_t>0\) and \(\sum_{t\in T}\mu_t=1\), a target type \(c^\star\), and a projection \(P\subseteq T\), count the distinct projected mass profiles \((q_t)_{t\in P}\) induced by stable sets \(S\subseteq T\) containing \(c^\star\), where \(S\) is conflict-free, attacks every type outside \(S\), and \(q_t=\mu_t\) for \(t\in S\) and \(q_t=0\) otherwise.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) argument types, each with positive binary rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The input also specifies an explicit type-uniform attack relation \(R\subseteq T\times T\) (self-attacks allowed), a target \(c^\star\in T\), and a projection \(P\subseteq T\), possibly empty. Let \(m=|R|\) and \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A feasible selection is a stable extension \(S\subseteq T\) containing \(c^\star\): \((S\times S)\cap R=\varnothing\), and every \(t\in T\setminus S\) has an attacker \(s\in S\) with \((s,t)\in R\). Each type is selected with its entire mass or omitted.
Its projected mass profile has \(q_t=\mu_t\) if \(t\in S\), and \(q_t=0\) otherwise, for \(t\in P\). Compute the exact number of distinct such profiles, counting identical profiles only once.

Is this exact counting problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite argumentation frameworks, counting distinct projections of stable extensions containing a designated argument is \(\#\!\cdot\!\mathrm{NP}\)-complete under parsimonious reductions. [Source](https://arxiv.org/pdf/1811.11501).

Modeling choices made when packaging the task

  • Made explicit that the target belongs to the nonempty support, as the discrete designated argument belongs to the framework.
  • Retained self-attacks and allowed an empty projection; neither is excluded by the discrete problem.
  • Defined the otherwise unspecified size variables: m is the number of attacks and L is the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Profiles are exactly projected subsets

The problem is \(\mathrm{NP}\)-hard, even when \(P=\varnothing\). More precisely, it is \(\#\!\cdot\!\mathrm{NP}\)-complete under parsimonious reductions.

For an input instance \(I\), define
\[ \mathcal E(I)=\{S\subseteq T:c^\star\in S,\ (S\times S)\cap R=\varnothing,\ \text{every }t\in T\setminus S\text{ is attacked by }S\}. \]
Here and below, “attacked by \(S\)” means that some \(s\in S\) satisfies \((s,t)\in R\).

For any \(S,S'\in\mathcal E(I)\), their projected profiles satisfy
\[ q(S)=q(S')\quad\Longleftrightarrow\quad S\cap P=S'\cap P. \]
Indeed, for each \(t\in P\), the coordinate \(q_t(S)\) is either \(0\) or \(\mu_t\). Because \(\mu_t>0\), these two values are distinct and reveal whether \(t\in S\).

Consequently, the required count is exactly
\[ F(I)=\bigl|\{S\cap P:S\in\mathcal E(I)\}\bigr|. \]
In particular, equal masses assigned to different types cause no collisions: the profile retains its type-indexed coordinates.

2. Valid masses can be assigned with polynomial encoding size

Any nonempty finite argumentation framework can be made into a society without changing its stable extensions.

Let its argument set be \(T=\{t_1,\ldots,t_\tau\}\), and put \(k=\lceil\log_2\tau\rceil\). Assign
\[ \mu_{t_i}=2^{-k}\quad(1\leq i<\tau), \qquad \mu_{t_\tau}=\frac{2^k-\tau+1}{2^k}. \]
The final numerator is positive because \(2^k\geq\tau\), and
\[ \sum_{i=1}^{\tau}\mu_{t_i} =\frac{\tau-1+2^k-\tau+1}{2^k}=1. \]
This also covers \(\tau=1\), giving its sole type mass \(1\).

Each mass has \(O(\log(\tau+1))\) encoding bits. These masses are dyadic, so the construction works even if “binary rational” requires a terminating binary expansion.

Thus, for an explicitly indexed framework of bit length \(B\), adding the masses takes \(O(\tau\log(\tau+1))\) bit operations and produces an instance of length
\[ L=O\bigl(B+\tau\log(\tau+1)\bigr). \]
The attack count \(m\) and support size \(\tau\) remain unchanged.

3. Direct proof of NP-hardness, including empty projection

We give a reduction from CNF satisfiability. Let \(\varphi\) have variables \(x_1,\ldots,x_n\) and clauses \(C_1,\ldots,C_r\).

Create the types
\[ T=\{c^\star\}\cup\{x_i,\bar x_i:1\leq i\leq n\}\cup\{d_j:1\leq j\leq r\}. \]
The attack relation consists of:

  • \((x_i,\bar x_i)\) and \((\bar x_i,x_i)\) for every variable;
  • \((d_j,d_j)\) for every clause;
  • \((\ell,d_j)\) whenever literal \(\ell\) occurs in \(C_j\).

There are no other attacks. Assign the masses from Section 2 and take \(P=\varnothing\).

We prove that stable extensions correspond bijectively to satisfying assignments.

From extensions to assignments. Let \(S\) be stable.

First, \(c^\star\in S\): otherwise stability would require an attacker of \(c^\star\), but none exists. Each \(d_j\notin S\), because its self-attack would violate conflict-freeness.

For each variable, at most one of \(x_i,\bar x_i\) lies in \(S\), because they attack each other. At least one lies in \(S\): if both were omitted, neither would have an attacker in \(S\), since their only incoming attacks are from each other. Hence exactly one is selected.

Define \(x_i\) to be true exactly when \(x_i\in S\). Every omitted clause type \(d_j\) must be attacked by \(S\). Its self-attacker is omitted, so a selected literal occurring in \(C_j\) must attack it. That literal is true under the assignment. Thus every clause is satisfied.

From assignments to extensions. Given a satisfying assignment, select \(c^\star\) and exactly the true literal type for each variable. This set is conflict-free: it contains no clause types and never contains both members of a literal pair. Every omitted literal is attacked by its selected opposite. Every clause type is attacked by a selected literal because the clause is satisfied. Therefore the set is stable.

These constructions are inverse to each other.

With \(P=\varnothing\), every feasible selection has the same empty profile. Hence
\[ F(I_\varphi)= \begin{cases} 1,&\text{if }\varphi\text{ is satisfiable},\\ 0,&\text{otherwise}. \end{cases} \]
An exact counting algorithm would therefore decide CNF satisfiability by testing whether its output is positive.

If \(h\) denotes the number of distinct literal–clause incidences, this construction has
\[ \tau=2n+r+1,\qquad m=2n+r+h, \]
and output length \(L=O((m+\tau)\log(\tau+1))\). Its construction time is polynomial in the formula’s input length and output length. Thus a running time polynomial in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).

4. Exact counting classification and an upper bound

The cited theorem states that counting distinct projected stable extensions containing a designated argument is \(\#\!\cdot\!\mathrm{NP}\)-complete under parsimonious reductions. Its definition matches the projected-subset count in Section 1. [Fichte, Hecher and Meier, Theorem 7](https://arxiv.org/pdf/1811.11501)

Section 2 gives a polynomial-time, count-preserving reduction from that problem to the society problem: retain the framework, target, and projection, and add valid positive masses. This proves \(\#\!\cdot\!\mathrm{NP}\)-hardness.

For membership, fix an ordering of \(P\). A counted object is a bit vector representing \(U\subseteq P\). Whether it should be counted is the predicate
\[ \exists S\subseteq T: \quad S\cap P=U,\quad c^\star\in S,\quad S\text{ is stable}. \]
This predicate is in \(\mathrm{NP}\). Given \(S\), mark all targets attacked by selected types while scanning \(R\); simultaneously reject any attack whose endpoints are both selected. Then check that every omitted type is marked, that \(c^\star\) is selected, and that the projection equals \(U\). Verification takes \(O(m+\tau)\) operations after reading the input.

Counting distinct polynomial-length objects satisfying an \(\mathrm{NP}\) predicate is precisely membership in \(\#\!\cdot\!\mathrm{NP}\). This proves completeness.

For an explicit exponential upper bound, enumerate every \(U\subseteq P\), and then enumerate its completions in \(T\setminus P\), counting \(U\) once if any completion is feasible. Across all \(U\), there are at most \(2^\tau\) candidate selections. The running time is
\[ O\bigl(L+2^\tau(m+\tau)\bigr) \]
in the usual indexed word-RAM model, including the counter updates. A conservative bit-operation bound is \(O(L+2^\tau(m+\tau)L)\). The answer is at most \(2^{|P|}\), so its binary output uses at most \(|P|+1\) bits.

The target question is therefore resolved: the exact counting problem is \(\mathrm{NP}\)-hard, and no polynomial-time algorithm in \(m,\tau,L\) exists unless \(\mathrm P=\mathrm{NP}\).
