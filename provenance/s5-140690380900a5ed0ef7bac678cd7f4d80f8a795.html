The continuous mirror question, as graded

Given worker types \(I\) and task types \(J\), with rational masses \(\alpha_i,\beta_j\), integer per-worker capacities \(b_i\), task values \(q_j>0\), and compatibility edges \(E\), find a feasible assignment \(x_{ij}\ge 0\) maximizing \(\sum_{(i,j)\in E}q_jx_{ij}\), subject to \(\sum_{j:(i,j)\in E}x_{ij}\le b_i\alpha_i\) and \(\sum_{i:(i,j)\in E}x_{ij}\le\beta_j\).

Packaged proof task (what the prover saw — nothing else)

The worker society is given by its support: a list of \(\tau=|I|\) worker types with positive masses \(\alpha_i\), each a binary rational; \(\tau\) is the support size, not the number of possible types. Task supply is an explicit list of \(m=|J|\) task types with positive binary-rational masses \(\beta_j\). Neither list is required to have total mass one.
Each worker type has a positive integer capacity \(b_i\), encoded in binary; each task type has a positive binary-rational value \(q_j\), common to all workers. Compatibility is an explicitly given set \(E\subseteq I\times J\).
An assignment consists of divisible masses \(x_{ij}\ge0\) for \((i,j)\in E\), satisfying \(\sum_{j:(i,j)\in E}x_{ij}\le b_i\alpha_i\) and \(\sum_{i:(i,j)\in E}x_{ij}\le\beta_j\). Its value is \(\sum_{(i,j)\in E}q_jx_{ij}\); unassigned mass is allowed. Let \(L\) be the total binary input length, including any threshold.

Is computing an exact optimal assignment polynomial-time in \(m,\tau,L\), or is deciding whether a feasible assignment has value at least a given binary-rational threshold \(K\ge0\) NP-hard?

Discrete maximum vertex-weighted bipartite \(b\)-matching admits polynomial-time optimal algorithms that are truthful when tasks can only hide incident edges; the anchor also establishes a truthful greedy mechanism with approximation ratio \(2\). These discrete guarantees do not themselves establish the complexity of the divisible-mass problem.

Result

An exact optimal assignment is computable in polynomial time in \(m,\tau,L\). Consequently, threshold decision belongs to \(\mathrm{P}\), and is not NP-hard unless \(\mathrm{P}=\mathrm{NP}\).

The proof is an exact reduction to minimum-cost flow. Binary capacities and rational masses require attention to encoding length, but do not require expanding either list.

1. Clear denominators

Write the input rationals as
\(\alpha_i=a_i/d_i\), \(\beta_j=r_j/e_j\), and \(q_j=p_j/h_j\), with positive integer numerators and denominators.

Define
\[ D=\prod_{i\in I}d_i\prod_{j\in J}e_j, \qquad H=\prod_{j\in J}h_j. \]

Set
\[ A_i=D b_i\alpha_i,\qquad B_j=D\beta_j,\qquad C_j=Hq_j. \]

All these quantities are positive integers. For an assignment \(x\), let \(y_{ij}=Dx_{ij}\). Its feasibility constraints become
\[ \sum_{j:(i,j)\in E}y_{ij}\le A_i, \qquad \sum_{i:(i,j)\in E}y_{ij}\le B_j, \qquad y_{ij}\ge0. \]

Conversely, any real vector \(y\) satisfying these constraints gives a feasible assignment \(x=y/D\). The objectives satisfy
\[ \sum_{(i,j)\in E}q_jx_{ij} = \frac{1}{DH}\sum_{(i,j)\in E}C_jy_{ij}. \]

Thus this scaling preserves the optimization problem exactly; it imposes no integrality restriction on feasible assignments.

2. Construct a minimum-cost flow instance

Let \(F=\sum_{i\in I}A_i\). Create a directed network whose vertices are a source \(s\), a sink \(t\), one vertex for each worker type, and one vertex for each task type.

The arcs have the following upper capacities and costs. All lower capacities are zero.

| Arc | Upper capacity | Cost |
|---|---:|---:|
| \(s\to i\), for \(i\in I\) | \(A_i\) | \(0\) |
| \(i\to j\), for \((i,j)\in E\) | \(\min\{A_i,B_j\}\) | \(-C_j\) |
| \(j\to t\), for \(j\in J\) | \(B_j\) | \(0\) |
| \(s\to t\) | \(F\) | \(0\) |

Require an \(s\)-\(t\) flow of value exactly \(F\), with conservation at all other vertices. The direct arc \(s\to t\) accounts for unused worker capacity. In particular, sending all \(F\) units on that arc proves feasibility.

Exact correspondence

Given a feasible scaled assignment \(y\), define
\[ f_{ij}=y_{ij},\qquad f_{si}=\sum_jy_{ij},\qquad f_{jt}=\sum_iy_{ij},\qquad f_{st}=F-\sum_{(i,j)\in E}y_{ij}. \]

The row bounds imply that \(f_{st}\ge0\), and all the specified capacities hold. In particular, nonnegativity and the row and column bounds imply \(y_{ij}\le\min\{A_i,B_j\}\). Conservation holds by construction, and the total flow value is \(F\).

Conversely, for any feasible flow of value \(F\), set \(y_{ij}=f_{ij}\). Conservation at worker and task vertices gives
\[ \sum_jy_{ij}=f_{si}\le A_i, \qquad \sum_iy_{ij}=f_{jt}\le B_j. \]
Hence \(x_{ij}=f_{ij}/D\) is a feasible assignment.

Only worker-to-task arcs have nonzero cost, so
\[ \operatorname{cost}(f) = -\sum_{(i,j)\in E}C_jf_{ij} = -DH\sum_{(i,j)\in E}q_jx_{ij}. \]

Because \(DH>0\), minimizing flow cost is exactly equivalent to maximizing assignment value. This correspondence holds for real-valued flows and assignments.

3. Exact solvability and bit complexity

We use the standard minimum-cost flow theorem: for a finite directed network with integer upper capacities, integer vertex supplies and demands, and integer arc costs, a feasible bounded instance has an integral minimum-cost flow, optimal among all real-valued feasible flows; an exact optimum is computable in polynomial time in the binary encoding length. Polynomial-time algorithms for capacitated minimum-cost flow are established, for example, by [Orlin, *A Faster Strongly Polynomial Minimum Cost Flow Algorithm*](https://pubsonline.informs.org/doi/10.1287/opre.41.2.338).

Every hypothesis holds here:

  • All capacities, costs, and the prescribed flow value \(F\) are integers.
  • Feasibility follows from the direct arc.
  • All capacities are finite, so the feasible flow set is bounded and the cost has a finite minimum.
  • Negative arc costs are permitted by the theorem.

It remains to check that the reduction has polynomial encoding length.

The binary length of a product is at most the sum of the binary lengths of its factors. Since the input denominators together occupy at most \(L\) bits, \(D\) and \(H\) each have \(O(L)\) bits. Likewise,
\[ A_i=b_i a_i(D/d_i),\qquad B_j=r_j(D/e_j),\qquad C_j=p_j(H/h_j) \]
each have \(O(L)\) bits. Summing the \(A_i\) gives \(F\) with \(O(L+\log(\tau+1))\) bits. These quantities can all be computed by polynomial-time integer arithmetic.

The network has
\[ n=\tau+m+2,\qquad a=|E|+\tau+m+1. \]
Since \(E\) is explicit and \(|E|\le\tau m\), its full binary encoding length is polynomial in \(m,\tau,L\). Therefore an exact minimum-cost flow \(f^*\) is computable within the required time bound.

Recover an optimal assignment by
\[ x^*_{ij}=f^*_{ij}/D. \]
The theorem permits choosing \(f^*\) integral. Moreover,
\[ 0\le f^*_{ij}\le\min\{A_i,B_j\}, \]
so every numerator and denominator in the returned assignment has polynomial bit length. Thus the result is an exact, explicitly representable assignment.

4. Threshold decision

Let \(Z^*=\operatorname{cost}(f^*)\). The optimal assignment value is exactly
\[ V^*=-Z^*/(DH). \]

Write the threshold as \(K=k/\ell\), where \(k\ge0\) and \(\ell>0\) are integers. A feasible assignment of value at least \(K\) exists precisely when
\[ V^*\ge K \quad\Longleftrightarrow\quad -\ell Z^*\ge kDH. \]

This is an exact integer comparison involving polynomial-length integers, and therefore takes polynomial time.

The conclusion follows directly from the divisible assignment constraints. It does not depend on transferring the discrete matching or truthfulness guarantees.
