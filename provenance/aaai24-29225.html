The continuous mirror question, as graded

Given a rational type-mass vector \(\mu\), a value oracle for a bounded \(C^2\) function \(v\) on fractional coalition masses \(x\) with \(0 \le x \le \mu\) and known derivative bounds, a query budget \(T\), tolerance \(\epsilon\), and optionally failure probability \(\delta\), estimate \(A_t = \mu_t \int_0^1 \partial_t v(\lambda \mu) d\lambda\) for all types \(t\), minimizing query complexity subject to \(\max_t E[(\hat{A}_t - A_t)^2] \le \epsilon^2\) or the corresponding \(1-\delta\) confidence guarantee.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; there is no separate parameter \(m\).
Let \(D_\mu=\prod_{t=1}^{\tau}[0,\mu_t]\). The unknown real-valued function \(v\) extends to a \(C^2\) function on a neighborhood of \(D_\mu\), satisfies \(v(0)=0\), and obeys known bounds \(|v(x)|\le B\), \(|\partial_t v(x)|\le G\), and \(|\partial_s\partial_t v(x)|\le H\) on \(D_\mu\), with \(B,G,H\ge0\) binary rationals. No monotonicity or nonnegativity is assumed.
A noiseless value oracle returns only \(v(x)\) at any chosen \(x\in D_\mu\); each call costs one query, except the known value at zero. Exact real arithmetic has unit cost, and adaptive randomized queries are allowed.
Estimate all type allocations \(A_t=\mu_t\int_0^1\partial_t v(\lambda\mu)\,d\lambda\). For \(\varepsilon>0\), require \(\max_t\mathbb E[(\widehat A_t-A_t)^2]\le\varepsilon^2\) uniformly over admissible \(v\); alternatively, for \(0<\delta<1\), require \(\Pr(\max_t|\widehat A_t-A_t|\le\varepsilon)\ge1-\delta\). Expectations and probabilities concern algorithmic randomness.
Let \(T\in\mathbb N\) bound the number of queries on every run, and let \(L\) be the total bit length of the rational input. State arithmetic running times in \(\tau,L,T,B,G,H,\varepsilon^{-1}\), and, when applicable, \(\delta^{-1}\).

What is the minimax value-oracle query complexity for these allocations under the mean-square criterion, and under the simultaneous confidence criterion, as a function of \(\mu,\tau,B,G,H,\varepsilon\) and \(\delta\)? Equivalently, what approximation accuracy is achievable with budget \(T\)?

For finite cooperative games, Stratified SVARM gives unbiased Shapley estimates with per-player MSE \(O(\log n/(T-W))\) when coalition values are uniformly bounded, after warm-up \(W=O(n\log n)\), for \(n\ge4\) and \(T>W\). [Source](https://epub.ub.uni-muenchen.de/118341/1/2302.00736v5.pdf)
Integrated Gradients uses the same straight-line allocation with zero baseline, but its numerical computation uses gradient access; this does not settle the value-only minimax problem stated here. No verified source found settles that exact problem. [Source](https://proceedings.mlr.press/v70/sundararajan17a/sundararajan17a.pdf)

Modeling choices made when packaging the task

  • Normalized masses to sum to one because the society is a distribution over types.
  • Carried over the zero value of the empty coalition as v(0)=0; retained signed values without monotonicity.
  • Made boundedness and derivative bounds explicit using supplied uniform bounds B, G, and H on values, first partials, and second partials.
  • Interpreted C2 on the closed coalition box through an extension to a neighborhood, so boundary derivatives are defined.
  • Specified noiseless exact value-only access and unit-cost real arithmetic; the graded question did not specify oracle precision or arithmetic costs.
  • Interpreted query complexity in the worst case over admissible functions, with at most T calls on every run and randomness belonging to the algorithm.
  • Chose simultaneous confidence for all types to resolve the unspecified confidence guarantee.
  • There is no underlying candidate or alternative parameter m; the ambient dimension is the support size tau.

Partial solution with stronger mass and confidence bounds

The full minimax problem remains unresolved. The results below substantially narrow the gaps identified in the notes:

  • For equal masses, the large-budget mean-square risk is

$$ R_T=\Theta\!\left(\frac{H^2\tau}{T^3}\right), $$
with universal constants and an explicit sufficient budget threshold.

  • For arbitrary masses, the large-budget upper and lower mean-square bounds differ by at most a factor of order $(\log\tau)^3$.
  • For two types, the confidence radius is characterized uniformly over $0<\delta\le 1/8$, including the transition to deterministic accuracy.

Every bound below uses only value queries. The finite-game result in [Stratified SVARM](https://epub.ub.uni-muenchen.de/118341/1/2302.00736v5.pdf) and the gradient-based computation in [Integrated Gradients](https://proceedings.mlr.press/v70/sundararajan17a/sundararajan17a.pdf) concern different information models and are not used in the proofs.

1. Definitions and elementary cases

Let $\mathcal V$ denote the admissible function class, and let $\mathfrak A_T$ denote the measurable randomized algorithms making at most $T$ value queries on every run. Define
$$ R_T=\inf_{\mathcal A\in\mathfrak A_T} \sup_{v\in\mathcal V} \max_t\mathbb E_v[(\widehat A_t-A_t)^2] $$
and
$$ e_T(\delta)= \inf\left\{\varepsilon>0: \exists\mathcal A\in\mathfrak A_T\ \forall v\in\mathcal V,\ \Pr_v\!\left(\max_t|\widehat A_t-A_t|\le\varepsilon\right) \ge1-\delta \right\}. $$
Thus the query restriction appears explicitly in both definitions.

The chain rule and $v(0)=0$ give
$$ \sum_t A_t =\int_0^1\frac{d}{d\lambda}v(\lambda\mu)\,d\lambda =v(\mu). $$
Also,
$$ |A_t|\le\mu_tG. $$

The following cases are immediate.

  • If $B=0$ or $G=0$, all allocations vanish.
  • If $\tau=1$, one query recovers $A_1=v(1)$ exactly. With zero queries,

$$ R_0=\min\{B,G\}^2. $$
The upper bound follows from $|v(1)|\le\min\{B,G\}$. For the lower bound, use the admissible functions $v(x)=\pm\min\{B,G\}x$ and average their squared errors.

  • If $H=0$, the Hessian vanishes on the interior of the box. Consequently, the gradient is constant there; continuity extends this conclusion to the box. Since $v(0)=0$, the function is linear, and querying $\mu_te_t$ for every type recovers $A_t=v(\mu_te_t)$ exactly.

Henceforth assume $\tau\ge2$ and $B,G,H>0$.

2. Improved value-only upper bounds

2.1 Subtracting the exactly recoverable radial component

Define
$$ \theta_t=\mu_t(1-\mu_t), \qquad r_t=e_t-\mu, \qquad V=v(\mu), $$
and
$$ q_t(\lambda)=\mu_t\,r_t\cdot\nabla v(\lambda\mu). $$
Because
$$ \int_0^1\mu\cdot\nabla v(\lambda\mu)\,d\lambda=V, $$
we have
$$ A_t=\mu_tV+\int_0^1q_t(\lambda)\,d\lambda. $$

The direction $r_t$ satisfies
$$ \|r_t\|_1=2(1-\mu_t). $$
It follows that
$$ |q_t(\lambda)|\le2G\theta_t. $$
Differentiating along the path and using the entrywise Hessian bound gives
$$ |q_t'(\lambda)| \le \mu_tH\|r_t\|_1\|\mu\|_1 =2H\theta_t. $$
Thus $q_t$ is Lipschitz with constant
$$ c_t=2H\theta_t. $$

This improves the mass dependence of the direct bound $H\mu_t$, particularly when one type has almost all the mass.

2.2 Approximating the integrand using two values

Fix $\lambda\in(0,1)$, put $x=\lambda\mu$, and choose
$$ 0<h\le \min\left\{ \lambda,\frac{(1-\lambda)\mu_t}{1-\mu_t} \right\}. $$
Then $x+hr_t\in D_\mu$: its other coordinates are $(\lambda-h)\mu_s$, and its $t$th coordinate is $\lambda\mu_t+h(1-\mu_t)$.

Define
$$ Q_{t,h}(x) =\mu_t\frac{v(x+hr_t)-v(x)}h. $$
Along the queried segment,
$$ |r_t^{\mathsf T}\nabla^2v\,r_t| \le H\|r_t\|_1^2. $$
The fundamental theorem of calculus therefore gives
$$ |Q_{t,h}(x)-q_t(\lambda)| \le \frac{\mu_tHh\|r_t\|_1^2}{2} =2H\mu_t(1-\mu_t)^2h. $$
In particular, the error is at most $\eta/2$ if
$$ h\le\frac{\eta}{4H\mu_t}. $$

The oracle is noiseless, so this step can be arbitrarily small without increasing the query count. It is a finite-difference approximation, not exact gradient access.

2.3 Stratified integration with finite randomness

For type $t$, partition $[0,1]$ into $n_t$ equal intervals. In each interval, independently choose one of $M_t$ equally spaced midpoints, uniformly, where $M_t$ is a power of two.

Let $U_j$ be the chosen points, and first consider the ideal estimator
$$ F_t=\frac1{n_t}\sum_{j=1}^{n_t}q_t(U_j). $$
If $U_j'$ is an independent copy, Lipschitz continuity implies
$$ \operatorname{Var}(q_t(U_j)) =\frac12\mathbb E[(q_t(U_j)-q_t(U_j'))^2] \le c_t^2\operatorname{Var}(U_j) \le\frac{c_t^2}{12n_t^2}. $$
Hence
$$ \operatorname{Var}(F_t)\le\frac{c_t^2}{12n_t^3}. $$

The expectation of $F_t$ is the composite midpoint rule with $n_tM_t$ subintervals. Its bias is at most
$$ \frac{c_t}{4n_tM_t}. $$
Choose
$$ M_t\ge\max\left\{1,\frac{c_t}{2n_t\eta}\right\}. $$
Then this bias is at most $\eta/2$. Replace every sampled integrand value by the finite difference above, also with error at most $\eta/2$.

Including the single endpoint query for $V$, the resulting estimator uses at most
$$ 1+2\sum_t n_t $$
queries and satisfies
$$ \mathbb E[(\widehat A_t-A_t)^2]^{1/2} \le\frac{c_t}{\sqrt{12}\,n_t^{3/2}}+\eta. $$

2.4 Confidence and deterministic bounds

For completeness, the needed concentration inequality follows directly from a moment-generating-function argument. If $X$ has range length $a$, then for
$$ F(s)=\log\mathbb E[e^{sX}], $$
the second derivative is a variance under the tilted distribution, so $F''(s)\le a^2/4$. Integrating twice yields
$$ \log\mathbb E[e^{s(X-\mathbb EX)}]\le\frac{s^2a^2}{8}. $$

Each summand $q_t(U_j)/n_t$ has range length at most $c_t/n_t^2$. Independence and optimization of the exponential bound give
$$ \Pr(|F_t-\mathbb EF_t|>u) \le2\exp\left(-\frac{2n_t^3u^2}{c_t^2}\right). $$
Therefore, for any estimated set $S$ of size $s\ge1$, a union bound gives
$$ \Pr\left( \forall t\in S: |\widehat A_t-A_t| \le \eta+c_t\sqrt{\frac{\log(2s/\delta)}{2n_t^3}} \right)\ge1-\delta. $$

Alternatively, use the midpoint of each stratum deterministically. On a stratum of length $1/n_t$, integrating the Lipschitz error from its midpoint gives $c_t/(4n_t^2)$. Summing strata gives
$$ |\widehat A_t-A_t| \le\frac{c_t}{4n_t}+\eta. $$

2.5 Explicit sufficient query counts

Query $V$ and set
$$ S=\{t:2G\theta_t>\varepsilon\}. $$
For types outside $S$, output $\mu_tV$. Their errors are at most $\varepsilon$.

For types in $S$, take $\eta=\varepsilon/2$. The following choices suffice:
$$ n_t= \max\left\{ 1,\left\lceil \left(\frac{c_t^2}{3\varepsilon^2}\right)^{1/3} \right\rceil \right\} $$
for mean-square error,
$$ n_t= \max\left\{ 1,\left\lceil \left( \frac{2c_t^2\log(2s/\delta)}{\varepsilon^2} \right)^{1/3} \right\rceil \right\} $$
for simultaneous confidence, and
$$ n_t= \max\left\{ 1,\left\lceil\frac{c_t}{2\varepsilon}\right\rceil \right\} $$
for deterministic error.

Consequently, sufficient query counts are respectively
$$ O\left( 1+s+ \left(\frac H\varepsilon\right)^{2/3} \sum_{t\in S}\theta_t^{2/3} \right), $$
$$ O\left( 1+s+ \left(\frac H\varepsilon\right)^{2/3} \log(2s/\delta)^{1/3} \sum_{t\in S}\theta_t^{2/3} \right), $$
and
$$ O\left( 1+s+\frac H\varepsilon\sum_{t\in S}\theta_t \right). $$
If every $\mu_tG\le\varepsilon$, the simpler zero-query estimator already suffices.

2.6 Explicit budget allocation

Put
$$ S_\theta=\sum_t\theta_t^{2/3}, \qquad Z_\theta=\sum_t\theta_t. $$
Suppose $T\ge4\tau+1$, and write $Q=T-1$.

Choose dyadic numbers $a_t$ satisfying
$$ a_t\le\theta_t^{2/3}<2a_t, $$
and set
$$ n_t=1+\left\lfloor \frac{Qa_t}{4\sum_s a_s} \right\rfloor. $$
Then
$$ 1+2\sum_tn_t \le1+2\tau+\frac Q2 \le T, $$
and
$$ n_t\ge\frac{Q\theta_t^{2/3}}{8S_\theta}. $$
Substitution into the variance bound, followed by $\eta\downarrow0$, proves
$$ R_T\le C\frac{H^2S_\theta^3}{T^3} $$
for a universal constant $C$.

The same allocation gives the randomized confidence upper bound. For deterministic quadrature, use
$$ n_t=1+\left\lfloor\frac{Q\theta_t}{4Z_\theta}\right\rfloor. $$
Its query count is again at most $T$, and its error is at most $2HZ_\theta/Q+\eta$. Thus
$$ e_T(\delta)\le CH\min\left\{ \frac{S_\theta^{3/2}\sqrt{\log(2\tau/\delta)}}{T^{3/2}}, \frac{Z_\theta}{T} \right\}. $$

These statements concern minimax infima. A finite-step implementation achieves each displayed bound with an arbitrarily small additional error.

3. A continuous family for adaptive lower bounds

A finite sign prior is insufficient for capturing the support-size dependence: one exact real answer can encode many signs. The construction below instead uses continuous parameters.

3.1 Smooth cutoff functions

Define
$$ \phi(z)= \begin{cases} (1-z^2)^3,&|z|\le1,\\ 0,&|z|>1, \end{cases} \qquad \psi(z)=z\phi(z). $$
Both functions are globally $C^2$, because their values and first two derivatives match zero at the support endpoints. Expanding the polynomials gives
$$ \phi'= -6z+12z^3-6z^5, \qquad \phi''=-6+36z^2-30z^4, $$
$$ \psi'=1-9z^2+15z^4-7z^6, \qquad \psi''=-18z+60z^3-42z^5. $$
Consequently, the following conservative bounds hold:
$$ |\phi|\le1,\quad|\phi'|\le6,\quad|\phi''|\le72, $$
$$ |\psi|\le1,\quad|\psi'|\le7,\quad|\psi''|\le84. $$
For the last two bounds, one may also use $\psi'=\phi+z\phi'$ and $\psi''=2\phi'+z\phi''$.

Furthermore,
$$ \psi(0)=0,\qquad\psi'(0)=1, $$
and direct integration gives
$$ \int_{-1}^1\phi(z)\,dz =2\left(1-1+\frac35-\frac17\right) =\frac{32}{35}. $$

3.2 Admissible parameterized functions

Fix a subset $K$ of $k\ge2$ types and an integer $N\ge1$. Set
$$ h=\frac1{2N}, \qquad c_j=\frac{j-\tfrac12}{N}, $$
$$ \kappa_N= \min\left\{ \frac H{576},\frac{NG}{10},4N^2B \right\}, \qquad d_N=\frac{8\kappa_N}{35N^2}. $$

For each $j$, take a parameter vector $a_j\in[-1,1]^k$, indexed by $K$. Define
$$ u(x)=\sum_sx_s, $$
$$ w_j(x)= \sum_{t\in K}a_{jt}x_t -\left(\sum_{t\in K}\mu_ta_{jt}\right)u(x), $$
and
$$ v_a(x)= \kappa_Nh^2 \sum_{j=1}^N \phi\left(\frac{u(x)-c_j}{h}\right) \psi\left(\frac{w_j(x)}h\right). $$

Every coefficient of $w_j$ has absolute value at most two. Longitudinal bump interiors are disjoint, and all derivatives through order two vanish at their common endpoints. Hence at most one bump contributes at any point, and
$$ |v_a|\le\kappa_Nh^2, $$
$$ |\partial_sv_a|\le(6+2\cdot7)\kappa_Nh=20\kappa_Nh, $$
$$ |\partial_r\partial_sv_a| \le(72+2\cdot6\cdot7\cdot2+84\cdot4)\kappa_N =576\kappa_N. $$
The definition of $\kappa_N$ verifies the bounds $B,G,H$. Also, $v_a$ is globally $C^2$ and $v_a(0)=0$.

On the allocation path,
$$ u(\lambda\mu)=\lambda,\qquad w_j(\lambda\mu)=0. $$
Let $\mu_K$ be the mass vector restricted to $K$, and write
$$ D_K=\operatorname{diag}(\mu_t:t\in K), \qquad C_K=I-\mathbf1\mu_K^{\mathsf T}. $$
Differentiation and integration yield the allocation vector restricted to $K$:
$$ A_K(v_a)=d_ND_KC_K\sum_{j=1}^Na_j. $$

3.3 What one query reveals

At a query point, the value depends on at most one block $a_j$, and depends on it only through the linear functional $w_j(x)$.

We may therefore give the algorithm a stronger oracle: each query may reveal an arbitrary linear functional of one selected block. This stronger oracle can simulate every original value response, by applying the known functions $\phi$ and $\psi$ to the revealed functional. A lower bound for the stronger oracle is thus a lower bound for the value oracle.

4. Lower bounds for continuous adaptive linear information

4.1 Prior and posterior geometry

Give every coordinate of every $a_j$ the independent density
$$ f(z)= \begin{cases} \cos^2(\pi z/2),&|z|\le1,\\ 0,&|z|>1. \end{cases} $$
It is a probability density, and its Fisher integral is
$$ \int_{-1}^1\frac{f'(z)^2}{f(z)}\,dz =\pi^2\int_{-1}^1\sin^2(\pi z/2)\,dz =\pi^2. $$

Include the algorithm’s random seed in the transcript $Y$. Conditional on $Y$, each block is constrained to an affine subspace by its revealed linear equations. Its density on that subspace is proportional to the original product density. The blocks remain conditionally independent.

Here is a justification that also covers adaptivity. Before each query, its block and linear functional are fixed by the preceding transcript. Conditioning that block on one linear equation restricts its density to the corresponding hyperplane, with a constant linear change-of-variables factor. Other blocks are unchanged. Induction proves the stated posterior description. A linearly dependent query does not reduce dimension.

Let $E_j$ be the tangent space of the posterior affine subspace for block $j$, and let $q_j$ be its number of queries. Then
$$ \dim E_j\ge k-q_j, \qquad \sum_jq_j\le T. $$
Consequently, imposing one additional orthogonality constraint leaves a subspace of dimension at least $k-q_j-1$.

Define the prior score
$$ s_j(a_j)=\nabla\log\prod_{t\in K}f(a_{jt}). $$
The unconditional score energy satisfies
$$ \mathbb E\sum_j\|s_j\|_2^2=Nk\pi^2. $$

All integration-by-parts identities used below are valid on the posterior affine subspaces: the product density is $C^1$, compactly supported, and vanishes at its boundary.

4.2 Mean-square lower bound

Let $P_j$ be the orthogonal projection onto $E_j\cap\mathbf1^\perp$, and put $k_j=\operatorname{rank}P_j$. Then
$$ \sum_jk_j\ge N(k-1)-T. $$
Also,
$$ P_jC_K=P_j. $$

Write $m_j=\mathbb E[a_j\mid Y]$. Integrating the divergence of
$$ P_j(a_j-m_j)\,p_j(a_j) $$
on the posterior affine subspace gives
$$ \mathbb E[(a_j-m_j)\cdot P_js_j\mid Y]=-k_j. $$
Since $P_jC_K=P_j$, the same inner product equals
$$ C_K(a_j-m_j)\cdot P_js_j. $$

Define
$$ V_j=\mathbb E[\|C_K(a_j-m_j)\|_2^2\mid Y], \qquad F_j=\mathbb E[\|P_js_j\|_2^2\mid Y]. $$
Cauchy–Schwarz, first within each block and then across blocks, gives
$$ \sum_jk_j\le \sqrt{\left(\sum_jV_j\right)\left(\sum_jF_j\right)}. $$
Applying Cauchy–Schwarz again after averaging, and using
$$ \mathbb E\sum_jF_j\le Nk\pi^2, $$
yields
$$ \mathbb E\sum_jV_j \ge \frac{[N(k-1)-T]_+^2}{Nk\pi^2}. $$

Put
$$ m_K=\min_{t\in K}\mu_t. $$
Conditional independence and the allocation formula imply that the total posterior variance of $A_K$ is at least
$$ d_N^2m_K^2\sum_jV_j. $$
Every estimator’s conditional squared error is at least the posterior variance. Dividing the total coordinate risk by $k$, and observing that a worst-case risk dominates the prior average, proves
$$ \boxed{ R_T\ge \frac{d_N^2m_K^2[N(k-1)-T]_+^2}{Nk^2\pi^2}. } $$
This holds for every subset $K$ with $k\ge2$ and every integer $N\ge1$.

4.3 Confidence lower bound

A related integration argument gives a probability bound directly.

Now let $P_j$ project onto $E_j\cap\mu_K^\perp$. Again,
$$ \sum_j\operatorname{rank}P_j\ge N(k-1)-T, $$
and this choice gives
$$ C_KP_j=P_j. $$

For a reported allocation vector, define
$$ b_t=\varepsilon\arctan\left(\frac{A_t-\widehat A_t}{\varepsilon}\right), \qquad t\in K. $$
Then
$$ |b_t|\le\frac{\pi\varepsilon}{2}, $$
and its derivative with respect to its error argument is at least $1/2$ whenever $|A_t-\widehat A_t|\le\varepsilon$.

For fixed transcript, integrate the divergence, in block $j$, of the tangent vector field
$$ P_jD_K^{-1}b. $$
Because differentiation of $A_K$ with respect to $a_j$ gives $d_ND_KC_K$, its divergence is
$$ d_N\sum_{t\in K}(P_j)_{tt} \frac1{1+((A_t-\widehat A_t)/\varepsilon)^2}. $$
Every term is nonnegative. On simultaneous success for $K$, this is at least
$$ \frac{d_N}{2}\operatorname{rank}P_j. $$

The integrated divergence identity, summed over blocks, therefore implies
$$ \frac{d_N}{2}[N(k-1)-T]_+ \Pr(\text{success on }K) \le \left| \mathbb E\left[ D_K^{-1}b\cdot\sum_jP_js_j \right]\right|. $$
Each projected score has conditional mean zero. Conditional independence consequently gives
$$ \mathbb E\left\|\sum_jP_js_j\right\|_2^2 \le Nk\pi^2. $$
Also,
$$ \|D_K^{-1}b\|_2 \le\frac{\pi\varepsilon\sqrt{k}}{2m_K}. $$
Cauchy–Schwarz now gives
$$ \frac{d_N}{2}[N(k-1)-T]_+ \Pr(\text{success on }K) \le \frac{\pi^2\varepsilon k\sqrt N}{2m_K}. $$

A uniform simultaneous guarantee implies prior-average success on $K$ at least $1-\delta$. Thus
$$ \boxed{ e_T(\delta)\ge \frac{d_Nm_K[N(k-1)-T]_+(1-\delta)} {\pi^2k\sqrt N}. } $$

5. Consequences for arbitrary masses and growing support

Order the masses as
$$ \mu_{(1)}\ge\mu_{(2)}\ge\cdots\ge\mu_{(\tau)}, $$
and define
$$ W_\mu=\max_{2\le k\le\tau}k^3\mu_{(k)}^2, \qquad K_0=\max\left\{1,\frac HG,\sqrt{\frac HB}\right\}. $$

Suppose
$$ T\ge5\tau K_0. $$
For the $k$ largest masses, choose
$$ N=\left\lceil\frac{2(T+1)}{k-1}\right\rceil. $$
Then $\kappa_N=H/576$, and
$$ N(k-1)-T\ge\frac{N(k-1)}2, \qquad N\le\frac{3(T+1)}{k-1}. $$
Since $k-1\ge k/2$, substitution into the lower bounds proves, for universal positive constants $c,C$,
$$ \boxed{ c\frac{H^2W_\mu}{(T+1)^3} \le R_T \le C\frac{H^2S_\theta^3}{T^3}. } $$
Similarly,
$$ \boxed{ c\frac{H\sqrt{W_\mu}(1-\delta)}{(T+1)^{3/2}} \le e_T(\delta) \le CH\min\left\{ \frac{S_\theta^{3/2}\sqrt{\log(2\tau/\delta)}}{T^{3/2}}, \frac{Z_\theta}{T} \right\}. } $$

5.1 The mean-square coefficient gap is at most logarithmic cubed

Write $p_i=\mu_{(i)}$. By the definition of $W_\mu$, for $i\ge2$,
$$ p_i^{2/3}\le\frac{W_\mu^{1/3}}i. $$
Furthermore,
$$ \theta_{(1)}^{2/3} =[p_1(1-p_1)]^{2/3} \le\left(\sum_{i=2}^\tau p_i\right)^{2/3} \le\sum_{i=2}^\tau p_i^{2/3}. $$
The last inequality follows from subadditivity of the power $2/3$. Since $\theta_{(i)}\le p_i$ for the other types,
$$ S_\theta \le2\sum_{i=2}^\tau p_i^{2/3} \le2W_\mu^{1/3}\sum_{i=2}^\tau\frac1i \le2W_\mu^{1/3}\log\tau. $$
Therefore,
$$ \boxed{S_\theta^3\le8W_\mu(\log\tau)^3.} $$

Thus the large-budget mean-square bounds match within a factor $O((\log\tau)^3)$ uniformly over all mass vectors. Whether this logarithmic gap is necessary remains open.

5.2 Equal masses are completely characterized in this regime

If $\mu_t=1/\tau$, then
$$ W_\mu=\tau, $$
and
$$ S_\theta^3 =\tau\left(1-\frac1\tau\right)^2. $$
Hence, for $T\ge5\tau K_0$,
$$ \boxed{ R_T=\Theta\!\left(\frac{H^2\tau}{T^3}\right), } $$
with universal implicit constants.

Equivalently, in the small-error regime in which the necessary budgets exceed this threshold, the mean-square query complexity is
$$ \Theta\!\left( H^{2/3}\tau^{1/3}\varepsilon^{-2/3} \right). $$

For equal masses, the confidence bounds give
$$ c\frac{H\sqrt{\tau}(1-\delta)}{(T+1)^{3/2}} \le e_T(\delta) \le CH\min\left\{ \frac{\sqrt{\tau\log(2\tau/\delta)}}{T^{3/2}}, \frac1T \right\}. $$
These do not establish whether the simultaneous-type logarithm is necessary.

For every fixed nondegenerate society, the same bounds prove
$$ R_T=\Theta(T^{-3}), \qquad e_T(\delta)=\Theta(T^{-3/2}) $$
for each fixed $0<\delta<1$.

6. Sharp confidence dependence for two types

Here the logarithmic dependence on $\delta$ can also be matched.

6.1 Upper bound

Suppose $\tau=2$, and write $m=\mu_1$, $b=\mu_2=1-m$. Query $V=v(\mu)$, estimate $A_1$ using the centered integrand, and return
$$ \widehat A_2=V-\widehat A_1. $$
Completeness implies that the two errors have the same absolute value.

For
$$ n=\left\lfloor\frac{T-1}{2}\right\rfloor\ge1, $$
the centered integrand has Lipschitz constant $2Hmb$. The bounds from Section 2 give
$$ R_T\le\frac{H^2m^2b^2}{3n^3} $$
and
$$ e_T(\delta)\le Hmb\min\left\{ \sqrt{\frac{2\log(2/\delta)}{n^3}}, \frac1{2n} \right\}. $$

6.2 A sign construction and its remaining uncertainty

Use the same $h,c_j,\kappa_N,d_N$ as above, but now put
$$ w(x)=bx_1-mx_2 $$
and, for independent uniform signs $\xi_j$,
$$ v_\xi(x)= \kappa_Nh^2\sum_{j=1}^N \xi_j \phi\left(\frac{x_1+x_2-c_j}{h}\right) \psi\left(\frac{w(x)}h\right). $$
The previous admissibility estimates apply, since the coefficients of $w$ have absolute value at most one. Its allocation is
$$ A_1(v_\xi)=d_Nmb\sum_{j=1}^N\xi_j. $$

Every value query depends on at most one sign. Conditional on the algorithm’s seed and transcript, unrevealed signs remain independent and uniform. At least $N-T$ signs remain.

For a sum $S_k$ of $k$ independent signs, define
$$ q_k(r)=\sup_{a\in\mathbb R}\Pr(|S_k-a|\le r). $$
Adding an independent summand cannot increase this concentration function: condition on that summand and bound each shifted interval by the original supremum. Consequently, a necessary confidence condition is
$$ q_{N-T}\left(\frac{\varepsilon}{d_Nmb}\right)\ge1-\delta. $$

6.3 An elementary Rademacher tail bound

We prove that there is a universal $c_0>0$ such that, for $k\ge1$ and $0<\delta\le1/8$,
$$ q_k(r)\ge1-\delta \quad\Longrightarrow\quad r\ge c_0\min\left\{k,\sqrt{k\log(1/\delta)}\right\}. $$

First, for every $s\ge1$,
$$ \Pr(S_s\ge\sqrt{s}/20)\ge\frac14. $$
For $s\le400$, the threshold is at most one, so the event contains every positive value. For even $s\ge2$, the zero atom is at most $1/2$; for odd $s$, there is no zero atom. Thus the positive probability is at least $1/4$.

For $s>400$, use the bound that the largest atom is at most $1/\sqrt{s+1}$. To verify it, write
$$ p_{2r}=2^{-2r}\binom{2r}{r}, \qquad p_{2r+2}=p_{2r}\frac{2r+1}{2r+2}. $$
Induction gives $p_{2r}^2\le1/(2r+1)$, because
$$ (2r+1)(2r+3)\le(2r+2)^2. $$
The odd case follows from
$$ p_{2r+1}=p_{2r}\frac{2r+1}{2r+2}. $$
An interval of radius $r$ contains at most $\lfloor r\rfloor+1$ atoms, since the lattice spacing is two. Therefore,
$$ \Pr(|S_s|<\sqrt{s}/20) \le\frac{\sqrt{s}/20+1}{\sqrt{s+1}} <\frac1{10}. $$
Symmetry proves the desired positive-tail probability.

Now split the $k$ signs into $\ell$ blocks of nearly equal size, where $1\le\ell\le k$. Each block has size at least $k/(2\ell)$. With probability at least $4^{-\ell}$, every block sum exceeds its own square-root threshold, implying
$$ S_k\ge\frac{\sqrt{k\ell}}{20\sqrt2}. $$
By symmetry, the corresponding negative event has the same probability.

An interval of radius strictly less than $\sqrt{k\ell}/(20\sqrt2)$ cannot intersect both tail sets. Hence
$$ q_k(r)\le1-4^{-\ell} \quad\text{if}\quad r<\frac{\sqrt{k\ell}}{20\sqrt2}. $$

Choose
$$ \ell= \min\left\{ k,\max\left\{ 1,\left\lfloor\frac{\log(1/\delta)}{2\log4}\right\rfloor \right\} \right\}. $$
For $\delta\le1/8$, this choice satisfies $4^{-\ell}>\delta$, and $\ell$ is at least a universal constant times $\min\{k,\log(1/\delta)\}$. This proves the claimed concentration implication.

6.4 Matching confidence radius

Take
$$ N=2(T+1). $$
For $T\ge10K_0$, we have $\kappa_N=H/576$. Applying the tail bound with $k=N-T=T+2$, and comparing with the upper bound, proves
$$ \boxed{ e_T(\delta)= \Theta\!\left( H\mu_1\mu_2 \min\left\{ \frac{\sqrt{\log(1/\delta)}}{(T+1)^{3/2}}, \frac1{T+1} \right\} \right), \qquad 0<\delta\le\frac18. } $$
The implicit constants are universal.

The same sign construction has conditional allocation variance at least $(N-T)d_N^2m^2b^2$. Together with the upper bound, it also gives
$$ \boxed{ R_T=\Theta\!\left( \frac{H^2\mu_1^2\mu_2^2}{(T+1)^3} \right) } $$
under the same sufficient budget threshold.

Thus the intermediate-confidence transition for two types is resolved in this regime: random stratification gives the square-root logarithm until $\log(1/\delta)$ reaches order $T$, after which the deterministic order is optimal.

Equivalently, when the resulting budgets lie in this large-budget regime, two-type confidence query complexity is
$$ \Theta\!\left( \min\left\{ \left(\frac{H\mu_1\mu_2}{\varepsilon}\right)^{2/3} \log(1/\delta)^{1/3}, \frac{H\mu_1\mu_2}{\varepsilon} \right\} \right). $$

7. Arithmetic running time

The upper-bound algorithms require finite randomness. Each midpoint-grid choice uses a fixed number of fair random bits, because its grid size is a power of two.

Sample counts can be computed by doubling and binary search with cubic comparisons; no exact cube-root operation is required. In confidence implementations, replace $\log(2s/\delta)$ by the larger integer
$$ \left\lceil\log_2(2s/\delta)\right\rceil. $$
Dyadic weights for $\theta_t^{2/3}$ are likewise found using cubic comparisons. Finite-difference steps use a constant number of arithmetic operations and comparisons per sample. All query points are rational when the accuracy parameters are rational.

For an accuracy-targeted implementation using at most $T$ queries, a conservative arithmetic and random-bit operation bound is
$$ O\left( L+\tau(T+1) +T\log(2+H/\varepsilon) +\tau\log(2+T+\tau/\delta) \right). $$
For mean-square or deterministic guarantees, omit the dependence on $\delta$. The factor $\tau T$ accounts for constructing query vectors. The bounds $B$ and $G$ require only input processing and comparisons in these algorithms.

For a fixed-budget implementation with additional numerical error $\eta$, replace $\varepsilon$ in this running-time bound by $\eta$. These are exact-arithmetic bounds, not bit-complexity claims for oracle answers.

8. Remaining open points

The results above do not settle the full target.

  • For arbitrary unequal masses, the large-budget mean-square coefficients $W_\mu$ and $S_\theta^3$ still need not match. Their ratio is now bounded by $O((\log\tau)^3)$, but the necessity of this gap is unproved.
  • The finite-budget transitions involving $B,G,H$ remain incompletely characterized. In particular, approximate recovery below the exact-recovery budget when $H=0$ is unresolved here.
  • For general support size, the simultaneous-confidence dependence on $\tau$ and $\delta$ is not matched. The two-type high-confidence result does not settle this question.
  • Uniform dependence as $\delta$ approaches one, where the required success probability becomes small, is not characterized here.
