The continuous mirror question, as graded

Given τ bidder types with rational shares μ_t>0 summing to 1, and rational per-capita values v_t>0 and budget impact factors α_t>0, choose a common scaled allocation q_t≥0 for each type, with A=∑_t μ_t q_t≤1. In the atomless limit, each type-t agent has value v_t q_t and budget α_t A. Compute an allocation maximizing ∑_t μ_t min{v_t q_t,α_t A} and its optimal value.

Packaged proof task (what the prover saw — nothing else)

An atomless society of total mass \(1\) receives one divisible item, so \(m=1\). It is given by its support: the list of \(\tau\geq1\) types with positive binary rational masses \(\mu_t\), satisfying \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has binary rational per-capita valuation \(v_t>0\) and budget impact factor \(\alpha_t>0\). Let \(L\) be the total input bit length.
Choose a common real allocation density \(q_t\geq0\) for each type, subject to \(A=\sum_t\mu_tq_t\leq1\). A type's aggregate allocation is \(\mu_tq_t\); densities have no separate upper bound.
An individual of type \(t\) has value \(v_tq_t\) and budget \(\alpha_tA\): an individual's own allocation has zero mass, while allocations to other individuals of the same type count toward the externality.
The objective is \(W(q)=\sum_t\mu_t\min\{v_tq_t,\alpha_tA\}\). Optimize allocation alone, without payment or incentive constraints; any maximizing allocation is acceptable.

Is computing an allocation maximizing \(W(q)\), together with its exact optimal value, possible in polynomial time in \(m,\tau,L\), or is this problem \(\mathrm{NP}\)-hard?

For finitely many bidders \(n\geq2\), with budgets \(B_i=\alpha_i\sum_{j\ne i}x_j\) and \(\sum_i x_i\leq1\), exact liquid-welfare maximization has a polynomial-time greedy algorithm ([Zheng, Cheng, Xu and Deng](https://arxiv.org/html/2504.14948v1)).
No result settling this exact atomless optimization problem was identified in the literature search.

Result

The exact atomless optimization problem is polynomial-time solvable. Sorting the supported types by valuation gives an optimal allocation and its exact rational welfare. The proof covers every support size \(\tau\geq1\).

1. Every optimum allocates the full item

Write \(A(q)=\sum_t\mu_tq_t\). For any scalar \(s\geq0\), both arguments of each minimum scale by \(s\), so

\(W(sq)=sW(q)\).

If \(A(q)=0\), positivity of the masses and nonnegativity of the densities imply \(q_t=0\) for every type, and hence \(W(q)=0\). The feasible allocation \(q_t=1\) for every type has strictly positive welfare, since all valuations and impact factors are positive.

If \(0<A(q)<1\), at least one type has positive density, so its welfare contribution is positive and \(W(q)>0\). The allocation \(\widehat q=q/A(q)\) is feasible, satisfies \(A(\widehat q)=1\), and has

\(W(\widehat q)=W(q)/A(q)>W(q)\).

Consequently, every maximizing allocation satisfies \(A=1\), and it suffices to optimize over such allocations.

2. Reduction to capped linear rewards

Define the aggregate allocation and its reward threshold by

\(x_t=\mu_tq_t,\qquad c_t=\dfrac{\mu_t\alpha_t}{v_t}>0.\)

Because \(\mu_t>0\), the correspondence \(q_t=x_t/\mu_t\) is bijective. Under \(A=1\), feasibility becomes \(x_t\geq0\) and \(\sum_t x_t=1\). Moreover,

\(\mu_t\min\{v_tq_t,\alpha_t\}=\min\{v_tx_t,\mu_t\alpha_t\}=v_t\min\{x_t,c_t\}.\)

Thus the problem is exactly to maximize

\(F(x)=\sum_{t=1}^{\tau}v_t\min\{x_t,c_t\}\)

over the unit simplex. The thresholds \(c_t\) cap the reward, not the feasible allocation.

Relabel the types so that \(v_1\geq v_2\geq\cdots\geq v_\tau\), breaking ties arbitrarily. Put

\(S_j=\sum_{i=1}^{j}c_i,\qquad S_0=0,\qquad C=S_\tau.\)

3. Exact allocation and proof of optimality

Case A: \(C\geq1\)

Let \(k\) be the smallest index such that \(S_k\geq1\). Allocate

\(x_i^*=c_i\quad(i<k),\qquad x_k^*=1-S_{k-1},\qquad x_i^*=0\quad(i>k).\)

Minimality of \(k\) gives \(S_{k-1}<1\leq S_k\), so \(0<x_k^*\leq c_k\). This allocation is nonnegative and sums to \(1\). Its welfare is

\(W^*=\sum_{i<k}\mu_i\alpha_i+v_k(1-S_{k-1}).\)

To prove optimality, take any feasible \(x\), and define \(y_i=\min\{x_i,c_i\}\). Then \(0\leq y_i\leq c_i\) and \(\sum_i y_i\leq1\). Set \(\lambda=v_k>0\). We have

\(F(x)=\lambda\sum_i y_i+\sum_i(v_i-\lambda)y_i.\)

The first term is at most \(\lambda\). For \(i<k\), the coefficient \(v_i-\lambda\) is nonnegative, so its contribution is at most \((v_i-\lambda)c_i\). For \(i\geq k\), the coefficient is nonpositive, so its contribution is at most zero. Therefore,

\(F(x)\leq\lambda+\sum_{i<k}(v_i-\lambda)c_i =\sum_{i<k}v_ic_i+v_k(1-S_{k-1})=W^*.\)

The proposed allocation attains this bound and is therefore optimal.

Case B: \(C<1\)

Allocate

\(x_1^*=c_1+(1-C),\qquad x_i^*=c_i\quad(2\leq i\leq\tau).\)

These allocations are nonnegative and sum to \(1\). Every type reaches its reward threshold, giving

\(W^*=\sum_{i=1}^{\tau}v_ic_i=\sum_{i=1}^{\tau}\mu_i\alpha_i.\)

For every feasible \(x\), each contribution satisfies \(v_i\min\{x_i,c_i\}\leq v_ic_i\). Summing proves that \(W^*\) is an upper bound, attained by the proposed allocation.

In either case, return \(q_i^*=x_i^*/\mu_i\), restoring the original type order. A density may exceed \(1\), as permitted by the problem.

4. Exact bit complexity

All calculations use rational arithmetic.

Sorting requires \(O(\tau\log\tau)\) comparisons, each performed exactly by cross multiplication of positive denominators. Computing thresholds, prefix sums, allocations, and welfare requires \(O(\tau)\) further rational operations.

To bound operand sizes, let \(\ell_t\) be the combined encoding length of \(\mu_t,v_t,\alpha_t\). The numerator and denominator of \(c_t\) have \(O(\ell_t)\) bits. A common denominator for any prefix sum can be formed by multiplying the corresponding denominators, whose total bit length is \(O(\sum_t\ell_t)=O(L)\). The summed numerator has \(O(L+\log\tau)\) bits. Reduction to lowest terms cannot increase these sizes.

The remaining formulas involve these sums and a constant number of multiplications or divisions by input rationals. Thus all intermediate numbers and each output rational have polynomial bit length. Standard exact integer arithmetic therefore implements the algorithm in time polynomial in \(\tau,L\), and hence in \(m,\tau,L\) for the stipulated \(m=1\).

5. Relation to the finite-bidder model

The [cited finite-bidder paper](https://arxiv.org/html/2504.14948v1) uses budgets \(\alpha_i(A-x_i)\). Here, the atomless premise instead gives budgets \(\alpha_tA\), even when other recipients belong to the same type. Once \(A=1\), these budgets are constant, which yields the capped-reward problem proved above. No finite-bidder theorem is needed for this argument.
