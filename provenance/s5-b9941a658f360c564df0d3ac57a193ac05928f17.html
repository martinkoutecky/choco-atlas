The continuous mirror question, as graded

Given a finite path with positions \(j\in[m]\), type masses \(\mu_t\), per-capita item capacities \(\rho_j\), and additive chore values \(u_t(j)\le 0\), compute a mass assignment \(x_{t,I}\) over integral intervals \(I\) (including the empty interval) satisfying \(\sum_I x_{t,I}=\mu_t\) and \(\sum_{t,I\ni j}x_{t,I}=\rho_j\), such that every interval receiving positive mass of type \(t\) has \(u_t(I)\ge q_t\), where \(q_t\) is the type's continuous MMS threshold obtained from the corresponding interval-distribution max-min problem.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) positions on a path, binary-rational per-capita capacities \(\rho_j\in[0,1]\), and binary-rational additive chore utilities \(u_t(j)\le0\), normalized by \(\sum_{j=1}^m u_t(j)=-1\).
Let \(\mathcal I\) contain every integral interval of the path and the empty interval; write \(u_t(I)=\sum_{j\in I}u_t(j)\).
Define \(D(\rho)=\{y\in\mathbb R_{\ge0}^{\mathcal I}:\sum_Iy_I=1,\ \sum_{I\ni j}y_I=\rho_j\text{ for every }j\}\). If \(D(\rho)=\varnothing\), declare the instance infeasible.
Otherwise define the continuous MMS threshold by \(q_t=\max_{y\in D(\rho)}\min_{I:y_I>0}u_t(I)\); the benchmark uses a hypothetical society consisting entirely of type \(t\).
An admissible assignment consists of masses \(x_{t,I}\ge0\) satisfying \(\sum_Ix_{t,I}=\mu_t\), \(\sum_{t,I\ni j}x_{t,I}=\rho_j\), and \(x_{t,I}>0\Longrightarrow u_t(I)\ge q_t\). Intervals assigned to different individuals may overlap; capacities constrain their aggregate mass.
Is deciding whether an admissible assignment exists in \(\mathrm P\) or \(\mathrm{NP}\)-hard, when the thresholds must be computed from the input? In the polynomial-time case, can an assignment also be computed in time polynomial in \(m,\tau,L\), where \(L\) is the total input bit length?
For finite agents with normalized additive chore utilities, a contiguous MMS allocation always exists and can be computed in polynomial time, as can each connected MMS threshold. [Source](https://arxiv.org/pdf/2205.10836v1)
No result settling this exact distribution-over-types problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to one, so capacities are per capita.
  • Specified all utilities and capacities as binary rationals, with capacities in [0,1], and retained the discrete normalization that each type values the full path at -1.
  • Defined the unspecified interval-distribution max-min benchmark using a unit-mass society of a single type, the same capacity vector, and the minimum utility over intervals with positive mass.
  • Declared instances with no capacity-compatible interval distribution infeasible, so their MMS thresholds need not be defined.
  • Interpreted capacities as aggregate incidence equalities without requiring a joint distribution over disjoint path partitions; the graded question specifies only mass assignments.

Result

The decision problem is in \(\mathrm P\). The thresholds can be computed exactly from the input, and an admissible assignment, when one exists, can be computed in time polynomial in \(m,\tau,L\).

The key facts are that there are polynomially many intervals and that testing a proposed threshold requires only linear feasibility.

1. The linear-programming fact used

We use the standard theorem that a finite system of rational linear equalities and inequalities can be tested for feasibility in time polynomial in its binary encoding length. When feasible, an exact rational feasible point can also be computed in polynomial time. Equalities, redundant constraints, and feasible sets of lower dimension are permitted. See the discussion of encoding size, rational solutions, and polynomial-time algorithms in [Goemans’s linear-programming notes](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/908fe54d659623efadda2d033b895caf_notes_lp.pdf).

Every application below has an explicitly constructed rational system of polynomial encoding length.

Let \(N=|\mathcal I|=1+m(m+1)/2\). Thus \(N=O(m^2)\), including the empty interval. Enumerate these intervals and compute every \(u_t(I)\) exactly.

First test feasibility of \(D(\rho)\), using its defining linear system. If it is empty, return infeasible as required. Henceforth assume \(D(\rho)\ne\varnothing\).

2. Computing each threshold exactly

Fix a supported type \(t\). Define the finite candidate set

\(V_t=\{u_t(I):I\in\mathcal I\}\).

For a rational candidate \(s\), define

\(\mathcal I_t(s)=\{I\in\mathcal I:u_t(I)\ge s\}\).

Consider the following linear feasibility system, denoted \(F_t(s)\), with one variable \(y_I\) for each \(I\in\mathcal I_t(s)\):

  • \(y_I\ge0\) for every \(I\in\mathcal I_t(s)\);
  • \(\sum_{I\in\mathcal I_t(s)}y_I=1\);
  • \(\sum_{I\in\mathcal I_t(s):\,j\in I}y_I=\rho_j\) for every \(j\in\{1,\ldots,m\}\).

Lemma. The threshold \(q_t\) is attained, belongs to \(V_t\), and satisfies

\(q_t=\max\{s\in V_t:F_t(s)\text{ is feasible}\}\).

Proof. For \(y\in D(\rho)\), its support is nonempty because \(\sum_Iy_I=1\). Consequently,

\(f_t(y)=\min_{I:y_I>0}u_t(I)\)

is well defined and belongs to \(V_t\). The image \(\{f_t(y):y\in D(\rho)\}\) is therefore a nonempty finite set. It has a largest element, attained by some \(y\in D(\rho)\). This proves that the maximum defining \(q_t\) exists and belongs to \(V_t\); no continuity assertion about \(f_t\) is needed.

For any \(s\), feasibility of \(F_t(s)\) is equivalent to the existence of \(y\in D(\rho)\) with \(f_t(y)\ge s\). Indeed, a solution of \(F_t(s)\), extended by zero on excluded intervals, is such a distribution. Conversely, if \(f_t(y)\ge s\), every positive coordinate of \(y\) belongs to \(\mathcal I_t(s)\), so its restriction solves \(F_t(s)\).

Thus feasibility implies \(s\le q_t\), and a distribution attaining \(q_t\) establishes feasibility of \(F_t(q_t)\). The asserted formula follows. \(\square\)

For completeness, normalization and nonpositive item utilities imply \(-1\le u_t(I)\le0\) for every interval. Moreover, the full interval has utility \(-1\). Hence \(-1\in V_t\) and \(F_t(-1)\) is exactly the already feasible system defining \(D(\rho)\). There is always a feasible candidate.

The algorithm can simply test every distinct value in \(V_t\) and select the largest feasible one. This uses at most \(N\) feasibility calls per type. Alternatively, sorting the candidates and using the monotonicity \(\mathcal I_t(s')\subseteq\mathcal I_t(s)\) for \(s'\ge s\) permits binary search.

Crucially, these systems use total population mass \(1\) and capacities \(\rho\), independently of \(\mu_t\). They therefore compute exactly the homogeneous-society benchmark specified in the question.

3. Deciding and constructing an admissible assignment

After computing all thresholds, let

\(\mathcal A_t=\{I\in\mathcal I:u_t(I)\ge q_t\}\).

Construct one linear feasibility system with variables \(x_{t,I}\) only for supported types \(t\) and intervals \(I\in\mathcal A_t\):

  • \(x_{t,I}\ge0\);
  • \(\sum_{I\in\mathcal A_t}x_{t,I}=\mu_t\) for every supported type \(t\);
  • \(\sum_t\sum_{I\in\mathcal A_t:\,j\in I}x_{t,I}=\rho_j\) for every position \(j\).

This system has at most \(\tau N\) variables and exactly \(\tau+m\) stated equality constraints.

Lemma. This system is feasible if and only if an admissible assignment exists.

Proof. Given a feasible solution, set \(x_{t,I}=0\) for excluded intervals. The type-mass and capacity equalities are precisely the required equalities. Every positive coordinate uses an interval in \(\mathcal A_t\), so it satisfies \(u_t(I)\ge q_t\).

Conversely, in an admissible assignment, every excluded interval necessarily has zero mass, since \(u_t(I)<q_t\). Restricting the assignment to the retained variables therefore gives a feasible solution of the displayed system. \(\square\)

Apply exact rational linear programming to this system. An infeasibility result answers no; a feasible point is the requested assignment.

4. Encoding length, running time, and output size

Write every input rational with a positive binary-encoded denominator. Let \(Q\) be the product of all input denominators. Its bit length is \(O(L)\). Every interval utility is an integer multiple of \(1/Q\), and its absolute value is at most \(1\). Hence each computed interval utility, and therefore each threshold, has bit length \(O(L)\). Exact addition, sorting, and comparisons consequently take polynomial time.

Each threshold system has at most \(N\) variables and \(m+1\) equality constraints. Its matrix entries are \(0\) or \(1\), and its right-hand side consists of \(1\) and the input capacities. Its encoding length is polynomial in \(m,L\).

The assignment system has at most \(\tau N\) variables, \(\tau+m\) equality constraints, matrix entries \(0\) or \(1\), and input masses and capacities on the right-hand side. Its encoding length is polynomial in \(m,\tau,L\).

Using exhaustive candidate testing, the algorithm makes at most \(1+\tau N+1\) linear-feasibility calls: one for \(D(\rho)\), at most \(\tau N\) for thresholds, and one for assignment. All calls have polynomial encoding length, proving the claimed polynomial running time.

There is also a direct bound on the size of an assignment witness. Write the final system as \(Ax=b,\ x\ge0\), and put \(d=\tau+m\). If feasible, choose a solution with minimum support size. Its supported columns of \(A\) must be linearly independent: otherwise, take a nonzero dependence vector \(c\) on that support. Summing the type rows gives \(\sum_i c_i=0\), so \(c\) has both positive and negative entries. With

\(\varepsilon=\min_{i:c_i>0}x_i/c_i>0\),

the vector \(x-\varepsilon c\) remains nonnegative, satisfies the same equalities, and has smaller support—a contradiction. Thus some assignment has at most \(d\) positive coordinates.

If that support has size \(k\le d\), select \(k\) rows making its column submatrix an invertible square matrix \(B\). Let \(D\) be a common denominator of the entries of \(b\), with bit length \(O(L)\), and let \(h=Db'\), where \(b'\) contains the selected right-hand sides. Cramer’s rule gives each supported coordinate as

\(x_i=\det(B_i(h))/(D\det B)\).

Since \(B\) has entries \(0\) or \(1\), and every entry of \(h\) lies between \(0\) and \(D\), Hadamard’s inequality yields

\(|\det B|\le k^{k/2}\), \(\qquad |\det(B_i(h))|\le Dk^{k/2}\).

Each coordinate therefore has bit length \(O(L+d\log(d+1))\). In particular, exact rational output has polynomial size, consistent with the constructive linear-programming theorem.

This proves both polynomial-time decision and polynomial-time construction for the specified support representation.
