The continuous mirror question, as graded

Given a bipartite multigraph \(H=(U,W;F)\) of agent types, rational masses \(\mu_v\) with total mass \(1\) on each side, and a partial order \(\succ_v\) over each type's incident contracts, choose \(x_f\geq 0\) with \(\sum_{f\ni v}x_f\leq\mu_v\). For each contract \(f\) incident to \(v\), let \(\beta_v(f)=\mu_v-\sum_{g\ni v:\, f\not\succ_v g}x_g\); require \(\beta_u(f)=0\) or \(\beta_w(f)=0\) for every \(f=uw\), and maximize \(\sum_{f\in F}x_f\). Is it UGC-hard to approximate this maximum stable mass within \(2-\delta\) for every fixed \(\delta>0\)?

A society is given by its support: the list of the \(\tau=|U|+|W|\) types with positive mass, each mass \(\mu_v\) a binary rational, with \(\sum_{u\in U}\mu_u=\sum_{w\in W}\mu_w=1\). Here \(\tau\) is the support size, not the number of possible types; write \(m=|F|\) and let \(L\) be the total input bit length.
An allocation consists of divisible masses \(x_f\in\mathbb R_{\geq0}\) satisfying \(\sum_{f\ni v}x_f\leq\mu_v\). Define \(\beta_v(f)=\mu_v-\sum_{g\ni v:\,f\not\succ_v g}x_g\).
The allocation is stable exactly when, for every contract \(f=uw\), including contracts with positive allocated mass, \(\beta_u(f)=0\) or \(\beta_w(f)=0\). Let \(\mathrm{OPT}\) be the maximum stable mass \(\sum_{f\in F}x_f\).

Does this problem admit a polynomial-time \((2-\delta)\)-approximation for some fixed \(\delta\in(0,1)\), or is such approximation NP-hard under UGC for every fixed \(\delta\in(0,1)\)? State running times in \(m,\tau,L\), and \(\delta\).

Conclusion

For every fixed \(\delta\in(0,1)\), approximating this continuous problem within \(2-\delta\) is NP-hard under UGC. The hardness already holds when all masses are equal dyadic rationals.

The key fact is that, with unit capacities, every stable divisible allocation can be rounded in polynomial time to a weakly stable discrete matching of at least the same total mass. This uses the endpoint disjunction itself.

Running times below use the standard bit model, with allocations represented by binary-encoded rationals.

1. Endpoint certificates

Write \(F(v)\) for the contracts incident to \(v\), and define the load and unused capacity by

\(\ell_v(x)=\sum_{g\in F(v)}x_g,\qquad s_v(x)=\mu_v-\ell_v(x).\)

Feasibility gives \(s_v(x)\geq0\). Partitioning the incident contracts according to whether \(f\succ_v g\) gives

\(\beta_v(f)=s_v(x)+\sum_{g\in F(v):\,f\succ_v g}x_g.\)

Every term on the right is nonnegative. Consequently,

\(\beta_v(f)=0\quad\Longleftrightarrow\quad \ell_v(x)=\mu_v\ \text{and}\ x_g=0\ \text{for every }g\in F(v)\text{ with }f\succ_v g.\)

Thus a zero endpoint certifies two things: that endpoint is saturated, and it receives no mass on any contract strictly worse than \(f\). This equivalence applies to every contract, including contracts carrying positive mass.

2. Integral rounding with unit capacities

For this section, replace every capacity by \(1\); normalization will be restored afterward.

Lemma. Every stable feasible allocation \(x\) with unit capacities admits a weakly stable discrete matching \(M\) satisfying

\(|M|\geq\sum_{f\in F}x_f.\)

For rational \(x\), such a matching can be found in polynomial time.

Proof. For each contract \(f=uw\), select an endpoint \(\sigma(f)\in\{u,w\}\) satisfying \(\beta_{\sigma(f)}(f)=0\). Such an endpoint exists by stability. Define

\(S=\{\sigma(f):f\in F\}\)

and

\(D=\bigcup_{f\in F}\{g\in F(\sigma(f)):f\succ_{\sigma(f)}g\}.\)

Consider the polytope

\(Q=\{y\in\mathbb R_{\geq0}^{F}:\ell_v(y)\leq1\text{ for all }v,\ \ell_v(y)=1\text{ for }v\in S,\ y_g=0\text{ for }g\in D\}.\)

The endpoint-certificate equivalence shows that \(x\in Q\), so \(Q\) is nonempty. It also shows that every \(y\in Q\) is stable: for each \(f\), its selected endpoint \(\sigma(f)\) is saturated, and all contracts strictly worse than \(f\) there have zero mass.

We next verify integrality. Let \(A\) be the vertex–contract incidence matrix of the bipartite multigraph. Multiplying the rows corresponding to \(W\) by \(-1\) produces a matrix with exactly one \(+1\) and one \(-1\) in each column. This matrix is totally unimodular:

  • If a square submatrix has a column with at most one nonzero entry, expansion along that column reduces its determinant to a smaller minor, up to sign.
  • Otherwise every column has both entries, so its column sum is zero. Its rows are therefore linearly dependent, and its determinant is zero.

Induction gives determinants only in \(\{0,1,-1\}\). Parallel contracts merely produce repeated incidence columns and do not affect this argument.

The constraint matrix defining \(Q\) is obtained from \(A\) by adjoining signed copies of existing rows and signed coordinate rows. These operations preserve total unimodularity. All right-hand sides are integers. At any vertex of \(Q\), a nonsingular set of active constraints therefore has determinant \(1\) or \(-1\), so its solution is integral.

Moreover, \(Q\) is bounded: each coordinate lies between \(0\) and \(1\). Maximizing \(\sum_f y_f\) over this nonempty bounded polytope has an optimal vertex \(y^*\). Its coordinates belong to \(\{0,1\}\), and the degree constraints imply that

\(M=\{f:y_f^*=1\}\)

is a matching. Since \(y^*\in Q\), it is stable under the endpoint disjunction, and

\(|M|=\sum_f y_f^*\geq\sum_f x_f.\)

To identify this with discrete weak stability, consider any matching incidence vector \(y\). At an unmatched vertex, \(\beta_v(f)=1\). At a vertex matched on \(g\), \(\beta_v(f)=1\) exactly when \(f\succ_v g\); otherwise it is zero. Hence an unselected contract violates the disjunction exactly when it weakly blocks the matching in the usual discrete sense. A selected contract satisfies the disjunction at both endpoints because strict partial orders are irreflexive. This proves the lemma. ∎

Algorithmic implementation

After constructing \(S\) and \(D\), use a flow network containing:

  • an arc \(s\to u\) with upper capacity \(1\), and lower capacity \(1\) exactly when \(u\in S\);
  • one arc \(u\to w\), of capacity \(1\), for each contract \(uw\notin D\);
  • an arc \(w\to t\) with upper capacity \(1\), and lower capacity \(1\) exactly when \(w\in S\).

Maximizing feasible flow in this network is precisely maximizing cardinality over \(Q\). The network has integral bounds, and the standard lower-bound feasibility reduction followed by residual maximum flow returns an integral optimum.

The network has \(O(\tau)\) vertices and \(O(m+\tau)\) arcs. Using Edmonds–Karp for the flow computations gives

\(O((\tau+1)(m+\tau+1)^2)\)

integer arithmetic operations. Endpoint-certificate extraction and construction require \(O(m^2+\tau)\) operations, besides reading the input.

If the rational allocation has total encoding length \(B\), exact certificate extraction and the complete rounding procedure take \(\operatorname{poly}(m,\tau,L+B)\) bit time.

3. An approximation-preserving reduction

The discrete result used here is:

Known theorem. For every fixed \(\delta\in(0,1)\), assuming UGC, maximum-cardinality weakly stable matching with arbitrary strict partial orders is NP-hard to approximate within \(2-\delta\). The model permits distinct parallel edges. These are the conventions and Theorem 3 of [Csáji, Király and Yokoi](https://arxiv.org/html/2208.09583v3).

Take an instance \(I\) of that discrete problem. Let its sides have sizes \(a\) and \(b\), and choose the least power of two \(n\) satisfying

\(n\geq\max\{a,b,1\}.\)

Add isolated vertices until each side has exactly \(n\) vertices. This preserves both the stable matchings and their cardinalities, since isolated vertices have no contracts.

Keep all contracts and partial orders, and set

\(\mu_v=1/n\)

for every vertex. These masses are positive dyadic rationals, and their sum on each side is \(1\). The new support size is exactly \(\tau=2n\).

Let \(K(I)\) denote the maximum discrete stable-matching cardinality. We claim that the resulting continuous instance satisfies

\(\mathrm{OPT}=K(I)/n.\)

First, every discrete stable matching \(M\) yields the allocation \(x_f=1/n\) on its selected contracts and zero elsewhere. Scaling its endpoint conditions by \(n\) proves that this allocation is stable, giving

\(\mathrm{OPT}\geq K(I)/n.\)

Conversely, take any continuous stable allocation \(x\) and set \(z_f=nx_f\). Its vertex capacities become \(1\). For every endpoint and contract,

\(\beta_v^{\mathrm{unit}}(f;z)=n\beta_v(f;x).\)

Thus \(z\) is stable with unit capacities. The rounding lemma gives a discrete weakly stable matching \(M\) with

\(|M|\geq\sum_f z_f=n\sum_f x_f.\)

Therefore \(\sum_f x_f\leq K(I)/n\). Together with the embedded maximum matching, this proves the claimed equality and also proves that the continuous maximum is attained.

Now suppose a polynomial-time continuous \(2-\delta\) approximation existed. Applied to this instance, it would return a stable allocation \(x\) satisfying

\(\sum_f x_f\geq\frac{\mathrm{OPT}}{2-\delta}=\frac{K(I)}{n(2-\delta)}.\)

Scale and round as above. The resulting discrete matching satisfies

\(|M|\geq n\sum_f x_f\geq\frac{K(I)}{2-\delta},\)

contradicting the cited hardness theorem. The reduction preserves the approximation ratio exactly.

Reduction size and dependence on \(\delta\)

If the discrete instance has support size \(\tau_0\), contract count \(m_0\), and bit length \(L_0\), the constructed instance has

\(m=m_0,\qquad \tau=O(\tau_0),\qquad L=O(L_0+\tau_0\log(\tau_0+2)).\)

Construction takes \(O(L_0+\tau_0\log(\tau_0+2))\) bit time by copying the instance and appending the padding and masses.

Both construction and rounding are independent of \(\delta\). Thus, for each fixed \(\delta\in(0,1)\), a running time polynomial in \(m,\tau,L\) would yield a polynomial-time discrete approximation. The same obstruction applies to a proposed bound \(f(1/\delta)\operatorname{poly}(m,\tau,L)\), since fixing \(\delta\) makes its first factor constant.

4. The polynomial-time factor-\(2\) upper bound

For completeness, the continuous problem also has a polynomial-time \(2\)-approximation.

Given any stable allocation \(x\), let

\(C=\{v:\ell_v(x)=\mu_v\}.\)

Every contract has an endpoint in \(C\), by the endpoint-certificate equivalence. Hence \(C\) is a vertex cover. For any feasible allocation \(y\), each contract is counted at least once when summing loads over \(C\), so

\(\sum_f y_f\leq\sum_{v\in C}\ell_v(y)\leq\sum_{v\in C}\mu_v=\sum_{v\in C}\ell_v(x)\leq2\sum_f x_f.\)

In particular, every stable allocation has mass at least \(\mathrm{OPT}/2\).

To obtain one efficiently, choose a total-order extension of each partial order and solve the ordinary bipartite stable-allocation problem with quotas \(\mu_v\) and redundant edge capacities

\(c_f=\min\{\mu_u,\mu_w\}\quad\text{for }f=uw.\)

The strongly polynomial stable-allocation algorithm applies to incident-edge preference orders, including parallel contracts; its standard graph implementation takes \(O(m^2)\) arithmetic operations after excluding isolated vertices. See [Biró and Fleiner, Theorem 4](https://citeseerx.ist.psu.edu/document?doi=e265a098dc8b1a0c77f40bd8784e4da0794205ff&repid=rep1&type=pdf).

Here its hypotheses give exactly the needed stability:

  • If an edge is below its capacity, ordinary stable allocation supplies a saturated endpoint with no mass on contracts worse in the extended order. Original strict comparisons are retained by the extension, so the original endpoint condition also holds.
  • If \(x_f=c_f\), an endpoint attaining the minimum quota is filled entirely by \(f\). Its original endpoint condition is therefore zero as well.

The extensions are only an internal algorithmic choice; the output satisfies the original partial-order disjunction.

Including preference processing and isolated vertices, this requires \(O(L+(m+\tau)^2)\) operations in the arithmetic model. For binary rational quotas, clear denominators using their product, whose bit length is \(O(L)\). The bipartite augmenting implementation uses additions, subtractions, comparisons and minima and preserves integral allocations after this scaling. A conservative total bit-time bound is therefore

\(O((m+\tau+L)^4).\)

This factor-\(2\) algorithm has no dependence on \(\delta\).

5. Why the cited LP gap is unnecessary

The proof retains the endpoint disjunction throughout. Fixing a zero endpoint for every contract defines a face of the bipartite capacity polytope. With unit capacities, that face is integral, allowing rounding without objective loss.

The stable set is a union of such faces; selecting the best face remains computationally hard. This explains how integral rounding can coexist with approximation hardness, without using the summed stability inequalities of the discrete LP relaxation.
