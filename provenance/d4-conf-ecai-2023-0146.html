Theorem 5 — class: hardness

The continuous mirror question, as graded

Given candidates \(C\), target \(p\), and a finite support of types \(t=(B_t,\rho_t)\) with rational masses \(\mu_t>0\) summing to \(1\), where \(B_t\in\binom{C}{3}\) is the type’s bottom-three set and \(\rho_t\) its bribery price, minimize \(\sum_t \rho_t\sum_{S\in\binom{C}{3},\,S\ne B_t} y_{t,S}\) over \(y_{t,S}\ge 0\), subject to \(\sum_{S\in\binom{C}{3}}y_{t,S}=\mu_t\) for every \(t\) and \(\sum_{t,S:\,p\in S}y_{t,S}\le\sum_{t,S:\,c\in S}y_{t,S}\) for every \(c\in C\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\ge 3\) and preferred candidate \(p\in C\). Under 3-Veto, candidates with minimum veto mass win; ties are allowed, so making \(p\) a co-winner suffices.
A society is given by its support: a list of \(\tau\) types \(t=(B_t,\rho_t)\) with positive binary rational masses \(\mu_t\) summing to \(1\), where \(B_t\in\binom{C}{3}\) and \(\rho_t\) is a nonnegative binary integer price per unit of changed mass. Here \(\tau\) is the support size, not the number of possible types.
Mass is arbitrarily divisible. Any portion of a type may be assigned any bottom-three set, at price \(\rho_t\) per unit if that set differs from \(B_t\); retaining \(B_t\) costs zero. Every such set represents an admissible strict ranking.
For real variables \(y_{t,S}\ge 0\), define the minimum bribery cost as \(\operatorname{OPT}=\min\sum_t\rho_t\sum_{S\in\binom{C}{3},\,S\ne B_t}y_{t,S}\), subject to \(\sum_{S\in\binom{C}{3}}y_{t,S}=\mu_t\) for every type and \(\sum_{t,S:\,p\in S}y_{t,S}\le\sum_{t,S:\,c\in S}y_{t,S}\) for every \(c\in C\).
The budget version additionally receives a nonnegative binary rational \(K\) and asks whether \(\operatorname{OPT}\le K\). Let \(L\) be the total binary input length, including masses, prices, and budget.

Is computing \(\operatorname{OPT}\) possible in time polynomial in \(m,\tau,L\), or is deciding whether \(\operatorname{OPT}\le K\) NP-hard?

For indivisible, unweighted voters with nonnegative integer prices and budget, constructive priced 3-Veto bribery allowing co-winners is NP-complete. This discrete result does not classify the divisible-mass problem.

  • The price domain was unspecified; prices are nonnegative binary integers, matching the discrete definition, and are interpreted as costs per unit of changed mass.
  • The candidate domain was implicit; require at least three candidates and require the preferred candidate to belong to the candidate set.
  • Winning means being a co-winner, as in the discrete nonunique-winner model; no tie-breaking is imposed.
  • Added a nonnegative binary rational budget to state the decision counterpart of minimum-cost optimization, and defined the total binary input length.

Conclusion

Computing \(\operatorname{OPT}\) is possible in time polynomial in \(m,\tau,L\). The budget problem is therefore in \(\mathrm{P}\).

The crucial observation is that there are only \(\binom{m}{3}\) possible bottom-three sets. Thus the linear program in the question already has polynomial size.

1. Constructing the linear program

Let \(\mathcal S=\binom{C}{3}\) and \(N=|\mathcal S|=\binom{m}{3}\). Enumerate these sets and introduce one nonnegative variable \(y_{t,S}\) for every type \(t\) and every \(S\in\mathcal S\). There are \(n=\tau N\le \tau m^3\) variables.

Define the integer objective coefficients by
\[ a_{t,S}= \begin{cases} 0,&S=B_t,\\ \rho_t,&S\ne B_t. \end{cases} \]
The objective is \(\sum_{t,S}a_{t,S}y_{t,S}\).

For each type, impose the mass-preservation equality
\[ \sum_{S\in\mathcal S}y_{t,S}=\mu_t. \]
For every \(c\in C\setminus\{p\}\), impose
\[ \sum_{t,S} \bigl(\mathbf 1_{\{p\in S\}}-\mathbf 1_{\{c\in S\}}\bigr)y_{t,S}\le 0. \]
Here \(\mathbf 1_{\{q\in S\}}\) equals one when \(q\in S\), and zero otherwise. These inequalities say exactly that the veto mass of \(p\) is no greater than that of any other candidate.

Consequently, feasible solutions are precisely the allowed mass assignments making \(p\) a co-winner, and their objective values are precisely their bribery costs. Arbitrary divisibility is what permits the variables to be real rather than integer.

2. Feasibility and existence of an optimum

For every \(m\ge 3\), consider the assignment
\[ y_{t,S}=\frac{\mu_t}{N} \qquad(t,\ S\in\mathcal S). \]
It preserves each type’s mass. Every candidate belongs to exactly \(\binom{m-1}{2}\) bottom-three sets, so every candidate receives veto mass
\[ \sum_t\frac{\mu_t}{N}\binom{m-1}{2} =\frac{\binom{m-1}{2}}{\binom{m}{3}} =\frac{3}{m}. \]
Thus this assignment is feasible.

Moreover, nonnegativity and mass preservation imply \(0\le y_{t,S}\le\mu_t\). The feasible set is therefore bounded; it is also closed because it is defined by finitely many linear equalities and inequalities. A linear objective attains its minimum on this nonempty compact set. In particular, \(\operatorname{OPT}\) exists and is finite.

For the degenerate case \(m=3\), the unique bottom-three set is \(C\), so all candidates always tie and \(\operatorname{OPT}=0\). The same algorithm applies to every \(m\ge4\).

3. Polynomial encoding size and exact optimization

We use the standard polynomial-time theorem for rational linear programming: an explicitly represented linear program with rational coefficients can be solved in time polynomial in its total binary encoding length; when feasible with a finite optimum, an exact rational optimal solution and objective value can be returned.

Its hypotheses hold here:

  • There are \(n=\tau\binom{m}{3}\) variables, \(\tau\) mass equalities, and \(m-1\) winner inequalities, together with nonnegativity.
  • Every constraint-matrix coefficient belongs to \(\{-1,0,1\}\).
  • The right-hand sides are the input rational masses or zero.
  • Every objective coefficient is zero or an input integer price.

Even a dense representation has encoding length bounded by
\[ O\!\left(n(\tau+m+L)+\tau L\right), \]
which is polynomial in \(m,\tau,L\). Enumerating the triples and constructing this representation also takes polynomial time.

The rational linear-programming theorem therefore computes the exact value of \(\operatorname{OPT}\) in the required polynomial time. For the budget version, comparing this exact rational value with the input rational \(K\) is a polynomial-time operation.

The cited hardness for indivisible voters does not transfer: the divisible problem permits fractional allocations and is exactly the polynomial-size linear program above.
