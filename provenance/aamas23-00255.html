The continuous mirror question, as graded

Given rational masses \(\mu_1,\ldots,\mu_\tau>0\) summing to \(1\) on communities arranged as \(C_\tau\), choose \(S\subseteq[\tau]\) minimizing \(\mu(S)=\sum_{i\in S}\mu_i\) such that forcing every resident in \(S\) blue, respectively white, makes synchronous MM reach the all-blue, respectively all-white, state for every initial assignment outside \(S\), where each community has one public color and retains it when its two neighbors tie.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a cyclically ordered list of \(\tau\ge 3\) community types with positive binary rational masses \(\mu_1,\ldots,\mu_\tau\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. The interaction graph is the simple undirected cycle \(C_\tau\), with \(m=\tau\) edges.
Each community has one public color, blue or white. In synchronous Majority Model (MM) rounds, each community adopts its two neighbors’ common color when they agree and retains its own color when they disagree. Neighbor influence is unweighted; masses determine only selection cost.
A set \(S\subseteq\{1,\ldots,\tau\}\) is winning if, for each color \(a\), every initial community coloring assigning \(a\) to all communities in \(S\) eventually reaches the all-\(a\) coloring. Selection fixes colors only initially; all communities subsequently update. Communities are selected whole, at cost \(\mu(S)=\sum_{i\in S}\mu_i\).
Given also a binary rational budget \(q\in[0,1]\), consider whether a winning set of cost at most \(q\) exists. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is deciding whether there exists a winning set \(S\) with \(\mu(S)\le q\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For the discrete MM on an unweighted cycle \(C_n\), the minimum winning-set cardinality is \(\lfloor n/2\rfloor+1\), and an optimal set has an explicit polynomial-time construction ([Zehmakan](https://link.springer.com/article/10.1007/s10458-024-09651-y)). No result settling the exact mass-cost problem above was located in the searches performed.

Modeling choices made when packaging the task

  • Interpreted forcing as an initial color assignment only, following the discrete winning-set definition; selected communities subsequently update normally.
  • Required support size at least three so that the interaction graph is a simple cycle with two distinct neighbors per community.
  • Kept neighbor influence unweighted, following the discrete MM rule; community masses affect only selection cost.
  • Interpreted outside assignments as public colors assigned to whole communities, consistent with the one-public-color assumption.
  • Expressed minimum-cost optimization through its decision version with an input binary rational budget in [0,1], and defined L as the total input bit length.
  • Used m for the number of interaction edges, following the discrete graph notation; here m equals the support size.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is in \(\mathrm{P}\). An exact algorithm uses \(\mathcal{O}(m+\tau)\) integer arithmetic operations on integers of \(\mathcal{O}(L)\) bits, and therefore \(\mathcal{O}((m+\tau)L^2)\) bit operations using elementary arithmetic. Here \(m=\tau\).

The key is a complete characterization of winning sets. The proof below is self-contained; it strengthens the cardinality characterization in [Zehmakan’s Theorem 3.2](https://link.springer.com/article/10.1007/s10458-024-09651-y) sufficiently to optimize arbitrary mass costs.

1. Exact characterization of winning sets. Write \(V=\{1,\ldots,\tau\}\), with indices interpreted cyclically. A vertex cover is a set meeting every edge; an independent set contains no adjacent vertices.

Proposition. A set \(S\subseteq V\) is winning if and only if:

  • \(V\setminus S\) is independent, equivalently \(S\) is a vertex cover.
  • \(S\) contains two adjacent vertices.

Necessity. Fix a target color \(a\), and initially assign \(a\) exactly to \(S\).

If two adjacent vertices lie outside \(S\), they initially have the opposite color. They retain that color forever: provided both have it in one round, each has a neighbor of its own color, so its neighbors either agree on that color or disagree, in which case it retains its color. Induction proves permanence. Consequently, \(S\) must meet every edge.

Suppose now that \(S\) meets every edge but contains no adjacent vertices. Each edge then has exactly one endpoint in \(S\). Thus the initial coloring alternates around the cycle, which forces \(\tau\) to be even. Every vertex has two neighbors of the opposite color, so every round flips every color. The process oscillates between the two alternating colorings and never reaches a monochromatic coloring. Therefore \(S\) must also contain an edge.

Sufficiency. Fix either target color \(a\) and any initial coloring assigning \(a\) to every vertex of \(S\). Encode \(a\) by \(1\) and the opposite color by \(0\). The update rule is exactly

\(x_i(t+1)=\operatorname{maj}\bigl(x_{i-1}(t),x_i(t),x_{i+1}(t)\bigr)\),

where \(\operatorname{maj}\) returns the value appearing at least twice. This identity follows directly from retaining the current color when the two neighbors disagree.

Initially, the vertices colored \(0\) form an independent set, since they are a subset of \(V\setminus S\). We first prove that this property persists.

Assume that no two adjacent vertices have value \(0\) at time \(t\). A vertex currently colored \(0\) has both neighbors colored \(1\), so it becomes \(1\). A vertex currently colored \(1\) becomes \(0\) exactly when both neighbors are \(0\). Hence

\(x_i(t+1)=0\quad\Longleftrightarrow\quad x_{i-1}(t)=x_{i+1}(t)=0.\)

If adjacent vertices \(i\) and \(i+1\) both became \(0\), this equivalence would imply \(x_{i+1}(t)=x_i(t)=0\), contradicting independence. Thus the vertices colored \(0\) remain independent.

By the second hypothesis, there is initially a consecutive block of at least two vertices colored \(1\). Every vertex in such a block remains \(1\) in the next round, because its own color and at least one neighbor’s color are \(1\).

Consider a vertex \(v\) immediately outside the block. If \(v\) is currently \(1\), it remains \(1\) because it has a neighbor in the block. If \(v\) is currently \(0\), both its neighbors are \(1\), by independence of the vertices colored \(0\); therefore it becomes \(1\).

Consequently, until the entire cycle is colored \(1\), the block grows by at least one vertex per round. It fills the cycle within at most \(\tau-2\) rounds. This argument applies to every allowed initial coloring and either choice of \(a\), proving that \(S\) is winning.

2. Exact mass optimization. Let \(z_i\in\{0,1\}\) indicate whether community \(i\) is selected. By the proposition, we must minimize \(\sum_{i=1}^{\tau}\mu_i z_i\) subject to

\(z_i+z_{i+1}\ge 1\quad\text{for every cyclic edge},\)

and

\(z_i=z_{i+1}=1\quad\text{for at least one cyclic edge}.\)

These conditions can be enforced by a dynamic program with a constant number of states.

First convert costs and budget to integers. Write \(\mu_i=a_i/b_i\) and \(q=a_q/b_q\), with positive integer denominators, and define

\(D=b_q\prod_{i=1}^{\tau}b_i,\qquad W_i=a_i(D/b_i),\qquad Q=a_q(D/b_q).\)

Then \(\sum_i W_i=D\), and \(\mu(S)\le q\) is equivalent to \(\sum_{i\in S}W_i\le Q\).

Run the following dynamic program separately for each fixed first bit \(s\in\{0,1\}\).

For a prefix \(z_1,\ldots,z_i\), let \(F_i^s(b,h)\) denote its minimum integer cost, subject to:

  • \(z_1=s\) and \(z_i=b\);
  • no edge within the prefix has endpoint bits \((0,0)\);
  • \(h\in\{0,1\}\) records whether an edge within the prefix has endpoint bits \((1,1)\).

Unattainable states have value \(+\infty\). Initialize

\(F_1^s(s,0)=sW_1.\)

For each state \((b,h)\) and next bit \(c\in\{0,1\}\), reject the transition if \(b=c=0\). Otherwise set \(h'=h\lor(b\land c)\), where \(\lor\) and \(\land\) are Boolean operations, and update

\(F_{i+1}^s(c,h')\leftarrow\min\bigl\{F_{i+1}^s(c,h'),\,F_i^s(b,h)+cW_{i+1}\bigr\}.\)

After processing all communities, account for the closing edge between \(\tau\) and \(1\). Accept a final state \((b,h)\) precisely when

\(b\lor s=1\qquad\text{and}\qquad h\lor(b\land s)=1.\)

The first condition covers the closing edge; the second requires a selected adjacent pair somewhere on the cycle.

Correctness. At initialization, the unique represented prefix has exactly the stated cost and properties. Each transition appends one bit, rejects exactly the newly created uncovered edge, updates the adjacent-pair flag exactly, and adds exactly the new selection cost. Induction therefore proves the stated meaning of every table entry. Future transitions depend only on the last bit, the flag, and the fixed first bit, so retaining the cheapest prefix for each state loses no feasible optimum.

The final conditions impose exactly the remaining cyclic constraints. Thus the minimum accepted cost \(K\), over both first-bit choices, is the minimum cost of a winning set. The answer is yes exactly when \(K\le Q\). A feasible state always exists because selecting all communities is winning.

3. Running time and verification. Each first-bit choice has four states per position and at most two transitions per state. The dynamic program therefore performs \(\mathcal{O}(\tau)\) additions and comparisons.

The bit length of \(D\) is \(\mathcal{O}(L)\), because it is a product of denominators whose total encoded length is at most \(L\). Every \(W_i\), \(Q\), and finite table value is at most \(D\), and hence also has \(\mathcal{O}(L)\) bits. Computing the integer costs takes \(\mathcal{O}(\tau)\) integer multiplications and divisions. Using elementary arithmetic, the complete algorithm takes \(\mathcal{O}(\tau L^2)=\mathcal{O}((m+\tau)L^2)\) bit operations. This bound depends polynomially on the encoding length, not on the numerical value of the common denominator.

As supplementary checks, exhaustive computation verified the characterization for every set and every compatible initial coloring on cycles with \(3\le\tau\le12\). The dynamic program also matched exhaustive optimization on \(270\) positive-integer weight instances with \(3\le\tau\le11\). These checks are corroboration; the proofs above establish correctness for all inputs.
