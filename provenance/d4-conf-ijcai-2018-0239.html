The continuous mirror question, as graded

Given alternatives \(A\), finite role types \(T\), rational masses \(\mu_t\) summing to \(1\), and a type-level delegation map \(\delta(t,\{a,b\})\), delete external rules \(D\) at cost \(\sum_{(t,\{a,b\})\in D}\mu_t\), and decide whether the remaining role graph admits complete transitive rankings \(R_t\) respecting every internal comparison and every surviving equality \(R_t|_{\{a,b\}}=R_{\delta(t,\{a,b\})}|_{\{a,b\}}\), within budget \(B\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq 1\) role types with positive binary rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Let \(A\) contain \(m\geq 2\) alternatives. Each type specifies every unordered pair of distinct alternatives either internally, with a strict comparison, or externally, with a delegate \(\delta(t,\{a,b\})\in T\setminus\{t\}\). Each type's internal comparisons form a strict partial order.
Let \(E\) be the set of external rules. A deletion chooses \(D\subseteq E\), costing \(\sum_{(t,\{a,b\})\in D}\mu_t\); each rule is deleted for its entire source type. Deleted pairs become unconstrained, and internal comparisons cannot be changed.
Given a nonnegative binary rational budget \(B\), feasibility means that some deletion of cost at most \(B\) admits one strict linear order \(R_t\) per type, extending its internal comparisons and satisfying \(R_t|_{\{a,b\}}=R_{\delta(t,\{a,b\})}|_{\{a,b\}}\) for every surviving rule. Here restriction denotes the comparison on that pair. Delegation cycles are allowed and must satisfy these same equalities.
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this mass-weighted consistency modification decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite voters with unit deletion costs, consistency modification is \(\mathrm{NP}\)-complete for both consistency and weak consistency; consistency testing itself is also \(\mathrm{NP}\)-complete. [Source](https://comsoc-community.org/assets/proceedings/comsoc-2018/BrillTalmonCOMSOC2018.pdf)

  • Used positive supported masses summing to one, at least one supported type, at least two alternatives, and a nonnegative binary rational budget.
  • Deletion removes only the equality imposed by an external rule, leaving that pair unconstrained; internal comparisons remain fixed.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is \(\mathrm{NP}\)-complete. Hardness holds even when all masses are equal, only one type has external rules, and there are no delegation cycles.

Membership in \(\mathrm{NP}\)

A certificate consists of one permutation \(R_t\) of the alternatives for each type \(t\).

First check that every \(R_t\) extends its type’s internal comparisons. For such a profile, define
\[ D_R=\bigl\{(t,\{a,b\})\in E: R_t|_{\{a,b\}}\ne R_{\delta(t,\{a,b\})}|_{\{a,b\}}\bigr\}. \]
Every feasible deletion admitting this profile must delete all rules in \(D_R\), because each surviving rule requires equality of the corresponding comparisons. Conversely, deleting exactly \(D_R\) makes every surviving rule satisfied. Thus the certificate is accepted precisely when
\[ \sum_{(t,\{a,b\})\in D_R}\mu_t\le B. \]

There are at most \(\tau\binom m2\) rules. The certificate has length \(\mathcal O(\tau m\log m)\), and its comparisons can be checked using position tables. Exact rational arithmetic also takes polynomial time: a common denominator obtained by multiplying the input denominators has bit length at most \(L\); the deletion counts introduce only \(\mathcal O(\log m)\) additional bits. A conservative bound for the entire verification is \(\mathcal O((L+\tau m^2)^3)\) bit operations.

Therefore the problem belongs to \(\mathrm{NP}\).

Source problem

We reduce from Feedback Arc Set in Tournaments. Its input is a tournament \(H=(V,F)\) and a nonnegative integer \(k\); the question is whether some \(F'\subseteq F\), with \(|F'|\le k\), makes \((V,F\setminus F')\) acyclic.

This decision problem is \(\mathrm{NP}\)-complete, by the deterministic hardness result of Charbit, Thomassé, and Yeo. A tournament has exactly one directed arc between every two distinct vertices. [Source](https://perso.ens-lyon.fr/stephan.thomasse/liste/feedback.pdf)

We may restrict to \(|V|\ge2\) and \(0\le k\le |F|\): the excluded instances are immediately decidable.

Construction

Set \(A=V\), \(m=|V|\), and \(N=|F|=\binom m2\). Create the following \(\tau=N+1\) types:

  • A central type \(s\), with no internal comparisons.
  • For every arc \(e=(x,y)\in F\), a type \(t_e\) whose comparisons are all internal and specify the linear order \(Q_e\): first \(x\), then \(y\), then all remaining alternatives in a fixed canonical order.

For every arc \(e=(x,y)\), let the central type delegate the pair \(\{x,y\}\) to \(t_e\).

Give every type mass \(\mu_t=1/\tau\), and set \(B=k/\tau\).

Every pair is specified exactly once for every type. Each internal relation is a strict partial order: it is empty for \(s\) and a strict linear order for each \(t_e\). Every delegate differs from its source, and every delegation leads directly to a type with only internal comparisons.

The types are distinct even if “support” requires distinct role descriptions: different arc types have different first two alternatives in their internal orders, while \(s\) has external rules. All masses are positive binary-encoded rationals and sum to \(1\).

The construction explicitly writes \(\tau\binom m2\) pair specifications. Its output length and construction time are \(\mathcal O(m^4\log m)\), using \(\tau=1+\binom m2\) and \(k\le N\).

Correctness

A feedback arc set gives a feasible deletion

Suppose \(F'\subseteq F\), \(|F'|\le k\), and \((V,F\setminus F')\) is acyclic.

Delete precisely the central type’s rules corresponding to arcs in \(F'\). Their cost is
\[ \frac{|F'|}{\tau}\le\frac{k}{\tau}=B. \]

A finite acyclic directed graph has a topological ordering. For completeness, it has a vertex of indegree zero: otherwise, repeatedly following incoming arcs would eventually repeat a vertex and produce a directed cycle. Removing such a vertex and applying induction produces an ordering in which every arc points forward.

Use this ordering as \(R_s\), with earlier alternatives ranked above later ones. Set \(R_{t_e}=Q_e\) for every arc type.

For each surviving rule associated with \(e=(x,y)\), the topological ordering ranks \(x\) above \(y\). The delegate’s order \(Q_e\) also ranks \(x\) above \(y\). Hence every surviving rule is satisfied, and every internal comparison is extended.

A feasible deletion gives a feedback arc set

Conversely, suppose a deletion \(D\) of cost at most \(B\) admits the required linear orders.

Only the central type has external rules. Thus \(D\) corresponds to an arc set \(F'\subseteq F\), and
\[ \frac{|F'|}{\tau}=\operatorname{cost}(D)\le\frac{k}{\tau}, \]
so \(|F'|\le k\).

For every surviving arc \(e=(x,y)\), the delegate’s fully internal order forces \(R_{t_e}=Q_e\). The surviving delegation therefore forces \(x\) above \(y\) in \(R_s\).

Consequently, every arc of \(F\setminus F'\) points forward in the single linear order \(R_s\). A directed cycle would force an alternative to precede itself, contradicting transitivity and irreflexivity. Hence \((V,F\setminus F')\) is acyclic.

This proves the required equivalence.

Conclusion

The polynomial reduction establishes \(\mathrm{NP}\)-hardness, and the certificate argument establishes membership in \(\mathrm{NP}\). Normalizing the masses simply scales every available deletion cost and the budget by the same factor.

If “binary rational” specifically means a dyadic rational, hardness still follows: choose a power of two \(q\ge\tau\), give every type mass \(1/q\), and add the remaining mass \(1-\tau/q\) to one fully internal type. Set \(B=k/q\). Only the central type’s mass affects deletion costs, so the same proof applies.
