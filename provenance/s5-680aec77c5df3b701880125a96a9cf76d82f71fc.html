The continuous mirror question, as graded

Given finitely many sections \(K\) with rational costs \(C(k)\), a fixed finite set of blocs \(\mathcal B\), and a finite support of trip types \(r\), each with route \(R_r \subseteq K\), bloc \(a(r)\), and positive rational mass \(\mu_r\) summing to \(1\), compute the aggregate bill \(x_r\) for each type under the mass extension of the Owen allocation. Define \(\mu_{a,k}=\sum_{r:a(r)=a,\ k\in R_r}\mu_r\) and \(\mathcal B_k=\{a:\mu_{a,k}>0\}\); then \(x_r=\mu_r\sum_{k\in R_r} C(k)/(|\mathcal B_k|\mu_{a(r),k})\).

Packaged proof task (what the prover saw — nothing else)

Let \(K\) be a nonempty ordered set of \(m\) sections with positive binary-rational fixed costs \(C(k)\), and let \(\mathcal B\) be an exogenously specified finite set of blocs.
A society is given by its support: the list of its \(\tau\) types with positive binary-rational masses \(\mu_r\), where \(\sum_r\mu_r=1\). Each type has a nonempty route \(R_r\subseteq K\) and one bloc \(a(r)\in\mathcal B\); routes may be disconnected, every section is used, and every bloc has positive mass. Here \(\tau\) is the support size, not the number of possible types.
Define \(\mu_{a,k}=\sum_{r:a(r)=a,\ k\in R_r}\mu_r\) and \(\mathcal B_k=\{a\in\mathcal B:\mu_{a,k}>0\}\). The mass Owen allocation assigns type \(r\) the aggregate bill \(x_r=\mu_r\sum_{k\in R_r}\frac{C(k)}{|\mathcal B_k|\mu_{a(r),k}}\).
The computational problem is to compute all \(x_r\) exactly as binary rationals. Let \(L\) be the total input bit length, including the explicitly listed routes and bloc memberships; state running times in \(m,\tau,L\), and \(|\mathcal B|\).

Is exact computation of this mass Owen allocation possible in polynomial time, or is it NP-hard?

For finite agents partitioned into blocs, the Owen bill is \(\sum_{k\in R_i}C(k)/(|A_k||N_{a(i),k}|)\), where \(A_k\) is the set of blocs using section \(k\) and \(N_{a,k}\) is the set of its users in bloc \(a\). This explicit formula is established by [Gómez-Rodríguez, Davila-Pena, and Casas-Méndez](https://kar.kent.ac.uk/104930/2/Cost%20allocation_Laura_pdf.pdf).
[Calvo](https://www.uv.es/ecalvo/Emilio%20Calvo_archivos/Research/Research%20in%20Game%20theory_archivos/ContOwen.pdf) gives a formula and characterization for a coalitional value in finite-type continuum games. Conclusion and encoding convention

Exact computation is possible in deterministic polynomial time. The proof applies to the explicitly listed support, with arbitrary, possibly disconnected routes.

Here “binary rationals” means fractions whose integer numerator and positive integer denominator are written in binary. Outputs need not be dyadic, even when all inputs are dyadic: with one section of cost \(1\), three types in three distinct blocs, and masses \(1/2,1/4,1/4\), every bill is \(1/3\).

The finite-agent formula appears in Proposition 3.1 of [Gómez-Rodríguez, Davila-Pena, and Casas-Méndez](https://kar.kent.ac.uk/104930/2/Cost%20allocation_Laura_pdf.pdf). For the stated computational problem, however, the mass formula is given as a definition, so the proof below needs no additional characterization theorem.

1. Integer representation of the masses

Write the input fractions as \(\mu_r=u_r/v_r\) and \(C(k)=c_k/d_k\), with positive integer numerators and denominators. Define

\(Q=\prod_{r=1}^{\tau}v_r\), and \(P_r=u_r(Q/v_r)\).

These integers are computable exactly. Moreover,

\(\mu_r=P_r/Q\), and \(\sum_{r=1}^{\tau}P_r=Q\).

The latter equality follows from the hypothesis \(\sum_r\mu_r=1\). In particular, \(0<P_r\leq Q\).

Because the denominator encodings are part of the input,

\(\log_2 Q=\sum_{r=1}^{\tau}\log_2 v_r\leq L\).

Thus \(Q\) and every \(P_r\) have \(O(L)\) bits. This construction does not require expanding a type into individual agents.

2. Algorithm and correctness

Let \(B=|\mathcal B|\) and let \(S=\sum_{r=1}^{\tau}|R_r|\) be the number of explicitly listed route incidences. Thus \(S\leq m\tau\).

Initialize an integer table \(W_{a,k}=0\) for every bloc and section. For each listed incidence \(k\in R_r\), add \(P_r\) to \(W_{a(r),k}\). Consequently,

\(W_{a,k}=\sum_{r:\,a(r)=a,\ k\in R_r}P_r=Q\mu_{a,k}\).

Next compute

\(b_k=|\{a\in\mathcal B:W_{a,k}>0\}|\).

Since \(Q>0\), we have \(b_k=|\mathcal B_k|\). Every section is used, so \(b_k\geq1\). Also, whenever \(k\in R_r\), the table entry \(W_{a(r),k}\) includes the positive summand \(P_r\), and hence is positive.

For each type, compute the rational sum

\(x_r=\sum_{k\in R_r}\frac{P_r c_k}{d_k b_k W_{a(r),k}}\).

All its denominators are positive. Each summand satisfies

\(\frac{P_r c_k}{d_k b_k W_{a(r),k}} =\frac{(P_r/Q)(c_k/d_k)}{b_k(W_{a(r),k}/Q)} =\frac{\mu_r C(k)}{|\mathcal B_k|\mu_{a(r),k}}\).

Therefore the algorithm computes exactly the allocation specified in the question.

3. Polynomial output size

Every \(W_{a,k}\) is a sum of a subset of the positive integers \(P_r\), so \(0\leq W_{a,k}\leq Q\). Every bloc has positive mass and contains at least one listed type; therefore \(B\leq\tau\).

It follows that each summand’s numerator \(P_rc_k\) and denominator \(d_kb_kW_{a(r),k}\) have \(O(L)\) bits.

For completeness, consider summing \(\ell=|R_r|\) such fractions, written as \(n_j/e_j\). A valid common-denominator representation is

\(D_r=\prod_{j=1}^{\ell}e_j\), and \(N_r=\sum_{j=1}^{\ell}n_j\prod_{i\ne j}e_i\).

There is a constant \(c\) such that every \(n_j,e_j<2^{cL}\). Hence

\(D_r<2^{c\ell L}\), and \(N_r<\ell\,2^{c\ell L}\).

Thus both output integers have \(O((\ell+1)L)\) bits. Reducing the fraction cannot increase these lengths.

Summing this bound over all types gives total output length

\(O((S+\tau)L)\subseteq O(\tau(m+1)L)\).

Since routes are explicitly listed, \(S+\tau=O(L)\), giving the stronger total output bound \(O(L^2)\).

4. Bit running time

A conservative bound, using elementary integer arithmetic and returning reduced fractions, is

\(O\!\left((mB+m+\tau)L^2+\tau(m+1)^3L^3\right)\).

Here is a justification that includes the cost of exact arithmetic.

  • Mass conversion. Constructing \(Q\) and the integers \(P_r\) uses \(O(\tau)\) multiplications and exact divisions on \(O(L)\)-bit integers. Schoolbook arithmetic therefore takes \(O(\tau L^2)\) bit operations.
  • Section and bloc totals. Initializing and scanning the dense table takes \(O(mB)\) table operations. The incidence pass performs \(S\) additions on \(O(L)\)-bit integers. Including parsing and indexing, these steps fit within \(O((mB+m+\tau+S)L^2)\).
  • Bills. Forming the summands takes \(O(SL^2)\) bit operations. Accumulate each bill without intermediate reduction using

\(N/D+n/e=(Ne+nD)/(De)\).
The preceding size bound applies to every partial sum, so all operands have \(O((m+1)L)\) bits. With \(O(S)\) arithmetic operations, this takes \(O(S(m+1)^2L^2)\).

  • Final reduction. For integers with at most \(n\) bits, Euclid’s algorithm uses \(O(n)\) divisions: within two divisions the larger argument decreases by at least a factor of two. Each schoolbook division costs \(O(n^2)\), giving the sufficient bound \(O(n^3)\) for a gcd. Taking \(n=O((m+1)L)\), reducing all bills costs \(O(\tau(m+1)^3L^3)\).

Finally, \(S\leq m\tau\), so all terms involving \(S\) are absorbed by the displayed running-time bound. The dimensions \(m,\tau,B\) are bounded by the explicit input length, so this is polynomial in \(L\).

Consequently, the exact allocation function belongs to \(\mathrm{FP}\). Under standard polynomial-time reductions, an NP-hardness claim for this task would therefore imply \(\mathrm{P}=\mathrm{NP}\).
