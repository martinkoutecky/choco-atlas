The continuous mirror question, as graded

Given finite type sets \(U\) and \(V\) with positive rational cross-distances \(d_{ij}\) from a metric, rational masses \(\mu_i,\nu_j\ge 0\) summing to \(1\) on each side, and rational \(\alpha\ge 1\), find a rational coupling \(x\ge 0\) with \(\sum_j x_{ij}=\mu_i\) and \(\sum_i x_{ij}=\nu_j\), such that no \(i,i'\in U\) and \(j,j'\in V\) satisfy \(x_{i,j'}>0\), \(x_{i',j}>0\), and \(\alpha d_{ij}<\min\{d_{i,j'},d_{i',j}\}\). Is there an algorithm polynomial in the number of types \(\tau=|U|+|V|\) and input bit length \(L\)?

Packaged proof task (what the prover saw — nothing else)

Let \(U,V\) be disjoint, nonempty finite type supports. A society is given by its support: the list of types with positive mass, each mass a binary rational; \(\tau=|U|+|V|\) is the support size, not the number of possible types. Masses satisfy \(\mu_i,\nu_j>0\) and \(\sum_i\mu_i=\sum_j\nu_j=1\).
The input contains positive binary rational distances \(d_{ij}\) on every edge of the complete bipartite graph, each equal to the shortest-path distance between its endpoints in that weighted graph, and a binary rational \(\alpha\ge1\). Put \(m=|U||V|\), and let \(L\) be the total input bit length.
A rational coupling \(x\ge0\) must satisfy \(\sum_jx_{ij}=\mu_i\) and \(\sum_ix_{ij}=\nu_j\). It is \(\alpha\)-stable if there are no \(i,i'\in U\), \(j,j'\in V\) with \(x_{i,j'}>0\), \(x_{i',j}>0\), and \(\alpha d_{ij}<\min\{d_{i,j'},d_{i',j}\}\). Equal distances do not constitute strict improvements; the condition applies even when \(x_{ij}>0\).

Is finding such an \(\alpha\)-stable rational coupling polynomial-time solvable in \(m,\tau,L\), or is it NP-hard?

For discrete metric perfect matchings on \(2n\) vertices, an algorithm transforms a supplied minimum-cost perfect matching into an \(\alpha\)-stable perfect matching in \(O(n^2\log n)\) operations. [Source](https://arxiv.org/pdf/1112.4632)
For the related continuous stable-allocation problem with strict preference lists, vertex quotas and edge capacities, a strongly polynomial algorithm uses \(O(m\log\tau)\) operations. This result concerns its own blocking-pair definition. [Source](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf)

Modeling choices made when packaging the task

  • Removed zero-mass types so the supplied type lists are precisely the positive-mass supports.
  • Specified the metric promise using the discrete definition: cross-edge weights equal shortest-path distances in the complete bipartite weighted graph.
  • Defined m as the number of cross edges and L as the total binary input length, including alpha.
  • Allowed equal distances and retained strictly improving deviations, with no tie-breaking needed in the coupling definition.
  • Explicitly retained the graded condition for already positive coupling entries; positive mass on an edge does not preclude additional mass from blocking.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Finding an \(\alpha\)-stable rational coupling is polynomial-time solvable. A greedy algorithm constructs a coupling that is already \(1\)-stable, and hence is \(\alpha\)-stable for every \(\alpha\ge 1\). The proof does not require the shortest-path assumption on the distances.

Algorithm

Fix an ordering of all \(m\) edges by nondecreasing distance, breaking ties arbitrarily.

Initialize \(x_{ij}=0\), and let \(r_i=\mu_i\) and \(s_j=\nu_j\) be the remaining masses. Process each edge \((i,j)\) once, in that order:

  • Set \(\delta=\min\{r_i,s_j\}\).
  • Set \(x_{ij}=\delta\).
  • Replace \(r_i\) by \(r_i-\delta\) and \(s_j\) by \(s_j-\delta\).

Return \(x\).

Feasibility

Throughout the algorithm, all allocations and remaining masses are nonnegative. Moreover,

\[ r_i=\mu_i-\sum_jx_{ij}, \qquad s_j=\nu_j-\sum_ix_{ij}. \]

Here and below, sums include the currently assigned entries. Each step subtracts the same amount from the total remaining mass on either side. Consequently,

\[ \sum_i r_i=\sum_j s_j \]

at every stage, since both totals initially equal \(1\).

Suppose this common total were positive at termination. There would then be some \(i\) and \(j\) with final remaining masses \(r_i>0\) and \(s_j>0\). Remaining masses never increase, so both were positive when \((i,j)\) was processed. That step subtracted their minimum, making at least one of them zero. It could never subsequently become positive, a contradiction.

Thus every final remaining mass is zero. The displayed invariants give precisely the required row and column sums, so \(x\) is a coupling.

Stability, including edges with positive allocation

Lemma. For every edge \((i,j)\), the final coupling satisfies at least one of the following:

  • Every \(j'\) with \(x_{i,j'}>0\) satisfies \(d_{i,j'}\le d_{ij}\).
  • Every \(i'\) with \(x_{i',j}>0\) satisfies \(d_{i',j}\le d_{ij}\).

Proof. Immediately after processing \((i,j)\), at least one of \(r_i,s_j\) is zero, because the algorithm subtracts their minimum.

If \(r_i=0\), no later step can allocate positive mass incident to \(i\). Every positive allocation incident to \(i\) therefore occurred no later than the processing of \((i,j)\). Since processing follows nondecreasing distance, all those edges have distance at most \(d_{ij}\). This proves the first alternative. If \(s_j=0\), the same reasoning proves the second. \(\square\)

Now suppose there were a blocking configuration as specified in the question:

\[ x_{i,j'}>0,\qquad x_{i',j}>0,\qquad \alpha d_{ij}<\min\{d_{i,j'},d_{i',j}\}. \]

Because \(d_{ij}>0\) and \(\alpha\ge1\), this implies

\[ d_{i,j'}>d_{ij} \qquad\text{and}\qquad d_{i',j}>d_{ij}. \]

These two inequalities contradict both alternatives of the lemma. Hence no blocking configuration exists.

The lemma applies to every edge \((i,j)\), including those with \(x_{ij}>0\). Equal distances cause no difficulty: the lemma gives non-strict inequalities, whereas blocking requires strict improvements.

Binary arithmetic and running time

Write the input masses as \(\mu_i=a_i/b_i\) and \(\nu_j=c_j/e_j\), with positive integer denominators. Define

\[ Q=\prod_{i\in U}b_i\prod_{j\in V}e_j. \]

The bit length of \(Q\) is \(O(L)\), because the sum of the bit lengths of these denominators is at most the total input length.

Implement the allocation steps using integer units of \(1/Q\). Initially, the remaining masses in these units are \(a_i(Q/b_i)\) and \(c_j(Q/e_j)\). All subsequent operations are integer comparisons and subtractions. Every remaining mass and allocation lies between \(0\) and \(Q\), so every such integer has \(O(L)\) bits. The returned entries are these integer allocations divided by \(Q\), and thus have polynomial encoding length.

Sorting takes \(O(m\log(m+1))\) rational comparisons. Each comparison can be performed by cross multiplication on integers of \(O(L)\) bits. Constructing \(Q\) and scaling the masses takes \(O(\tau)\) integer arithmetic operations; the edge scan takes \(O(m)\) comparisons and subtractions.

Using elementary integer arithmetic, a valid overall bit-operation bound is

\[ O\bigl((m\log(m+1)+\tau)L^2\bigr). \]

In particular, the algorithm works directly with the support and binary rational masses; it never expands masses into individual agents.

Relation to the cited allocation result

The [cited stable-allocation paper](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf) includes an edge-capacity condition in its blocking-pair definition. The proof above establishes the question’s exact condition directly, without invoking that theorem or introducing a capacity exception.
