The continuous mirror question, as graded

Given finitely many role types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), a weighted hypergraph on \(T\) of rank at most four defining \(V(y)=\sum_{E\in\mathcal E}w_E\prod_{t\in E}y_t\), nonnegative rational payoff rates \(a_t\) satisfying \(\sum_t\mu_ta_t=V(\mathbf 1)\), and a positive rational threshold \(\varepsilon\), decide whether some participation vector \(y\in[0,1]^T\) has excess \(V(y)-\sum_t\mu_ta_ty_t\ge\varepsilon\).

Is this continuous excess-threshold decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For discrete hypergraph games, deciding whether a coalition exceeds a given excess threshold at an imputation is \(\mathrm{NP}\)-hard even with rank at most four, dependency degree seven, and supermodular degree one. Dependency counts players whose presence can change another player's marginal contribution; supermodular dependency counts those whose presence can increase it.

Result

The problem is \(\mathrm{NP}\)-complete, even with hyperedges of size at most three, uniform dyadic masses, and identical positive payoff rates. Consequently, it is not in \(\mathrm P\) unless \(\mathrm P=\mathrm{NP}\).

1. Fractional participation has the same maximum as Boolean participation

Define the excess function
\(F(y)=V(y)-\sum_{t\in T}\mu_ta_ty_t\).

Every hyperedge is a set, so each variable occurs with exponent at most one in every monomial. Thus \(F\) is affine in each coordinate separately.

Fix \(y\in[0,1]^T\) and a type \(t\). Let \(y^{t,0}\) and \(y^{t,1}\) be obtained by setting coordinate \(t\) to zero and one, respectively. Affineness gives
\[ F(y)=(1-y_t)F(y^{t,0})+y_tF(y^{t,1}). \]
Since \(0\leq y_t\leq1\), at least one of these endpoint values is at least \(F(y)\).

Apply this argument successively to every coordinate, retaining an endpoint that does not decrease the excess. After \(\tau\) steps, the resulting vector \(b\in\{0,1\}^T\) satisfies \(F(b)\geq F(y)\). Therefore
\[ \max_{y\in[0,1]^T}F(y) = \max_{b\in\{0,1\}^T}F(b). \]

In particular, the continuous instance is a yes-instance exactly when it has a Boolean witness. This proves the bridge from fractional participation to discrete coalitions.

2. Membership and running times

A certificate consists of \(\tau\) bits specifying \(b\in\{0,1\}^T\). Its excess is
\[ F(b)= \sum_{\substack{E\in\mathcal E\\b_t=1\text{ for every }t\in E}}w_E - \sum_{\substack{t\in T\\b_t=1}}\mu_ta_t. \]

This expression can be compared with \(\varepsilon\) using exact rational arithmetic. To bound its bit complexity, take a common denominator equal to the product of all denominators appearing in the input. This denominator has \(O(L)\) bits and clears both the weights and the products \(\mu_ta_t\). The resulting integer coefficients and accumulated sums also have \(O(L)\) bits.

Using classical integer arithmetic, certificate verification takes
\[ O((m+\tau)L^2) \]
bit operations. Hence the problem belongs to \(\mathrm{NP}\).

Enumerating all Boolean vectors gives a deterministic decision algorithm taking
\[ O\!\left(2^\tau(m+\tau)L^2\right) \]
bit operations. The exponential factor depends on the actual support size \(\tau\).

3. A reduction satisfying every input constraint

We reduce from unweighted Max Cut: given a simple graph \(G=(U,A)\) and a positive integer \(k\), decide whether a cut contains at least \(k\) edges. This problem is \(\mathrm{NP}\)-complete. [Garey, Johnson, and Stockmeyer, *Some simplified NP-complete graph problems*](https://doi.org/10.1016/0304-3975(76)90059-1).

Write \(n=|U|\), \(p=|A|\), and \(d_v=\deg_G(v)\). Choose the smallest power of two \(q\) satisfying \(q\geq n+1\). Introduce a gate type \(z\) and a set \(D\) of \(q-n-1\) additional types. Set
\[ T=U\cup\{z\}\cup D,\qquad \tau=q,\qquad \mu_t=\frac1q,\qquad a_t=q \quad(t\in T). \]
Thus every mass is positive and dyadic, the masses sum to one, every rate is positive, and \(\mu_ta_t=1\).

Define
\[ V(y)= \sum_{t\in T}y_t + \sum_{\substack{v\in U\\d_v>0}}d_vy_zy_v - 2\sum_{\{u,v\}\in A}y_zy_uy_v. \]
This is an explicitly listed hypergraph polynomial consisting of:

  • a singleton of weight one for every type;
  • an edge \(\{z,v\}\) of weight \(d_v\) for each nonisolated graph vertex;
  • an edge \(\{z,u,v\}\) of weight \(-2\) for each graph edge \(\{u,v\}\).

Every edge has size at most three. Set \(\varepsilon=k>0\).

Verification of the payoff constraints

The handshake identity \(\sum_{v\in U}d_v=2p\) gives
\[ V(\mathbf1)=q+2p-2p=q. \]
Meanwhile,
\[ \sum_{t\in T}\mu_ta_t=q. \]
Thus efficiency holds.

For any type \(t\), all nonsingleton monomials vanish at \(\mathbf e_t\), so
\[ V(\mathbf e_t)=1=\mu_ta_t. \]
Thus every individual-rationality inequality holds, with equality.

Verification of the reduction

The singleton terms cancel the payoff terms. Hence
\[ F(y)= y_z\left( \sum_{v\in U}d_vy_v - 2\sum_{\{u,v\}\in A}y_uy_v \right). \]

Consider a Boolean vector \(b\), and put \(S=\{v\in U:b_v=1\}\).

If \(b_z=0\), then \(F(b)=0\). If \(b_z=1\), then
\[ F(b)= \sum_{\{u,v\}\in A} \left(b_u+b_v-2b_ub_v\right). \]
For each graph edge, the summand is one precisely when exactly one endpoint belongs to \(S\), and zero otherwise. Therefore
\[ F(b)=|\delta_G(S)|, \]
where \(\delta_G(S)\) denotes the edges crossing the cut.

The additional types in \(D\) have no effect on excess. It follows that
\[ \max_{b\in\{0,1\}^T}F(b) = \max_{S\subseteq U}|\delta_G(S)|. \]
By the rounding result,
\[ \exists y\in[0,1]^T:\ F(y)\geq k \quad\Longleftrightarrow\quad \exists S\subseteq U:\ |\delta_G(S)|\geq k. \]
This establishes both directions of the reduction.

Size and construction time

If \(n_+\) is the number of nonisolated graph vertices, the constructed instance has
\[ \tau=q<2(n+1),\qquad m=q+n_++p. \]
All indices, weights, masses, and rates require \(O(\log(n+2))\) bits each. Consequently,
\[ L=O((n+p)\log(n+2)+\log(k+1)). \]
The graph degrees and the explicit output can be constructed in time polynomial in the graph input length; a direct implementation takes
\[ O((n+p)\log(n+2)+\log(k+1)) \]
bit operations under the usual explicit graph encoding.

Thus the reduction is polynomial and produces valid instances. Together with membership in \(\mathrm{NP}\), it proves the claimed classification.
