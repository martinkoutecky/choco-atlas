The continuous mirror question, as graded

At round \(t\), given a finite alternative set \(A_t\), a rational distribution \(\mu\) over observable types \(\theta\), and for each type a common accrued utility \(u_\theta\) and current valuation vector \(v^t_\theta\), compute the exact set \(C_t^\infty\) of alternatives \(a\) for which there exist \(x_\theta\in(0,1]\) and \(y_\theta\in\mathbb{R}\) for zero-utility types such that \(a\) maximizes \(\sum_{u_\theta>0}\mu_\theta v^t_\theta(b)/u_\theta+\sum_{u_\theta=0}\mu_\theta(x_\theta/\varepsilon+y_\theta)v^t_\theta(b)\) over \(b\in A_t\), equivalently by testing unboundedness of the grouped LP for each \(a\).

Packaged proof task (what the prover saw — nothing else)

At a fixed round \(t\), let \(A_t\) be an explicitly listed, nonempty set of \(m\) alternatives. A society is given by its support: a list \(\Theta\) of \(\tau\) types with positive binary rational masses \(\mu_\theta\), where \(\sum_{\theta\in\Theta}\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a common accrued utility before this round \(u_\theta\in\mathbb Z_{\ge0}\) and current valuations \(v^t_\theta(b)\in\mathbb Z_{\ge0}\) for every \(b\in A_t\), all encoded in binary. Let \(L\) be the total input bit length and \(Z=\{\theta:u_\theta=0\}\).
For each \(\theta\in Z\), choose real numbers \(x_\theta\in(0,1]\) and \(y_\theta\in\mathbb R\), common to the entire type. Define \(S_{x,y}(b)=\sum_{\theta\notin Z}\mu_\theta v^t_\theta(b)/u_\theta+\sum_{\theta\in Z}\mu_\theta(x_\theta/\varepsilon+y_\theta)v^t_\theta(b)\).
The formal infinitesimal \(\varepsilon\) orders these scores lexicographically: compare the coefficient of \(\varepsilon^{-1}\) first, then the constant coefficient. Define \(C_t^\infty=\{a\in A_t:\exists(x,y)\ \forall b\in A_t,\ S_{x,y}(a)\ge S_{x,y}(b)\}\). Tied maximizers are included; empty sums are zero.

Is computing the exact set \(C_t^\infty\) possible in polynomial time in \(m,\tau,L\), or is deciding membership \(a\in C_t^\infty\) NP-hard?

For finitely many individual agents, the entire analogous proportional-fair choice set is computable in polynomial time by one LP unboundedness test per alternative; this equals the set obtainable by the infinitesimal weights above ([verified full version](https://www.rupertfreeman.com/fair_social_choice_full.pdf)).
No prior result settling this exact distribution-over-types problem was located in the search.

Modeling choices made when packaging the task

  • Specified nonnegative integer valuations and accrued utilities, encoded in binary, following the discrete valuation domain and the definition of accrued utility as a sum of past valuations.
  • Normalized the positive rational masses to sum to one, interpreting the stated distribution as a probability distribution.
  • Required a nonempty alternative set and explicitly listed support and valuation vectors.
  • Specified formal infinitesimal comparison and inclusion of all tied maximizers, including the case with no zero-utility types.
  • Interpreted the endowment parameters as common to each type, as indicated by the type-indexed continuous question.

Result

The exact set \(C_t^\infty\) is computable in polynomial time in \(m,\tau,L\). For each alternative, membership reduces to one rational LP feasibility test with at most \(2\tau\) variables.

The finite-agent unboundedness formulation appears in Algorithm 4 and Theorem 2 of the [cited full version](https://www.rupertfreeman.com/fair_social_choice_full.pdf). The proof below establishes the result directly for the given type-level definition, without expanding rational masses into individual agents.

1. Expressing the lexicographic conditions

Fix \(a\in A_t\), and let \(k=|Z|\). For each \(b\in A_t\), define the vector \(d_b\in\mathbb Q^k\) and constant \(c_b\in\mathbb Q\) by

\(\displaystyle d_{b,\theta}=\mu_\theta\bigl(v^t_\theta(a)-v^t_\theta(b)\bigr)\qquad(\theta\in Z),\)

\(\displaystyle c_b=\sum_{\theta\notin Z}\frac{\mu_\theta}{u_\theta}\bigl(v^t_\theta(a)-v^t_\theta(b)\bigr).\)

Every denominator \(u_\theta\) in this sum is positive, by the definition of \(Z\).

For any permitted vectors \(x,y\), the score difference is

\(\displaystyle S_{x,y}(a)-S_{x,y}(b)=\frac{d_b\cdot x}{\varepsilon}+c_b+d_b\cdot y.\)

Consequently, \(a\in C_t^\infty\) precisely when there exist \(x\in(0,1]^k\) and \(y\in\mathbb R^k\) such that, for every \(b\),

\(\displaystyle d_b\cdot x\ge 0,\qquad d_b\cdot x=0\ \Longrightarrow\ c_b+d_b\cdot y\ge 0.\)

If \(k=0\), these conditions reduce to \(c_b\ge 0\) for every \(b\). This case is decided by exact rational comparisons. Henceforth assume \(k>0\).

2. An ordinary LP feasibility test

For the fixed alternative \(a\), consider the following system in unrestricted real vectors \(h,q\in\mathbb R^k\):

\(\displaystyle h_\theta\ge 1\qquad\text{for every }\theta\in Z,\)

\(\displaystyle d_b\cdot h\ge 0\qquad\text{for every }b\in A_t,\)

\(\displaystyle c_b+d_b\cdot q\ge 0\qquad\text{for every }b\in A_t.\)

This is a rational linear feasibility problem with \(2k\) variables and \(k+2m\) inequalities.

Claim. This system is feasible if and only if \(a\in C_t^\infty\).

Membership implies feasibility

Suppose \(x,y\) witness \(a\in C_t^\infty\). Since \(Z\) is finite and every coordinate of \(x\) is positive,

\(\displaystyle \eta=\min_{\theta\in Z}x_\theta>0.\)

Set \(h=x/\eta\). Then \(h_\theta\ge 1\), and \(d_b\cdot h\ge 0\) for every \(b\).

To construct \(q\), write

\(\displaystyle \alpha_b=d_b\cdot x,\qquad \beta_b=c_b+d_b\cdot y.\)

The lexicographic conditions give \(\alpha_b\ge 0\) and, whenever \(\alpha_b=0\), also \(\beta_b\ge 0\).

Choose the finite real number

\(\displaystyle K=\max\left(\{0\}\cup\left\{-\frac{\beta_b}{\alpha_b}:b\in A_t,\ \alpha_b>0\right\}\right),\)

and set \(q=y+Kx\). For every alternative \(b\),

\(\displaystyle c_b+d_b\cdot q=\beta_b+K\alpha_b.\)

If \(\alpha_b=0\), this equals \(\beta_b\ge 0\). If \(\alpha_b>0\), the definition of \(K\) makes it nonnegative. Thus all inequalities of the LP hold.

This step uses the explicit finiteness of \(A_t\): a single finite \(K\) handles all comparisons.

Feasibility implies membership

Conversely, suppose \(h,q\) satisfy the LP. Define

\(\displaystyle H=\max_{\theta\in Z}h_\theta,\qquad x=h/H,\qquad y=q.\)

Because every \(h_\theta\ge 1\), we have \(H\ge 1\) and \(0<x_\theta\le 1\).

For each \(b\),

\(\displaystyle d_b\cdot x=\frac{d_b\cdot h}{H}\ge 0.\)

If this is positive, the leading coefficient makes \(S_{x,y}(a)>S_{x,y}(b)\). If it is zero, the LP gives

\(\displaystyle c_b+d_b\cdot y=c_b+d_b\cdot q\ge 0.\)

Therefore \(S_{x,y}(a)\ge S_{x,y}(b)\) lexicographically for every \(b\), including equality where appropriate. These vectors witness \(a\in C_t^\infty\), completing the equivalence.

3. Polynomial encoding and running time

All coefficients are computable exactly with polynomially many bit operations.

To check their sizes explicitly, write each input mass as \(\mu_\theta=p_\theta/r_\theta\). Each coordinate \(d_{b,\theta}\) is formed from one rational mass and one difference of binary integers, so its encoding length is polynomial in \(L\).

For \(c_b\), a common denominator is

\(\displaystyle Q=\prod_{\theta\notin Z}r_\theta u_\theta,\)

with empty product equal to \(1\). Its bit length is bounded by the sum of the bit lengths of these input factors, hence is \(O(L)\). After bringing the summands to this denominator, their integer numerators and their sum also have polynomial bit length. Thus the entire LP has encoding length polynomial in \(m,\tau,L\).

We apply the standard polynomial-time feasibility theorem for rational linear programming: a finite system of rational linear inequalities can be decided in time polynomial in its encoding length. Its hypotheses hold here; no boundedness assumption is required, and all inequalities are non-strict.

For every explicitly listed \(a\), either perform the direct comparisons when \(Z\) is empty or solve the LP above. Collect exactly those alternatives that pass. There are \(m\) tests, each of polynomial size, so this computes the exact set \(C_t^\infty\) in polynomial time.

Every variable is indexed by a type. The constructions therefore respect the requirement that weights be common to the entire type, regardless of the binary-encoded masses.
