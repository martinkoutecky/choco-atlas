The continuous mirror question, as graded

For a fixed relational schema and fixed data-tractable \(\Sigma\), given \(O=(D,\Sigma)\), a CQ \(Q\), \(k\), a shared probabilistic model if used, and \(\tau\) complete preference types over set-valued query answers with rational masses \(\mu_t\), merge each type's preferences as specified and form the mass-weighted CSU relation by net mass on each directed pair, omitting ties, taking transitive closure, and applying a fixed cycle-removal rule. Decide whether the resulting relation has a skyline answer or a nonempty iterated \(k\)-rank answer.

Packaged proof task (what the prover saw — nothing else)

Fix a relational schema and a fixed Datalog\(^{+/-}\) rule set \(\Sigma\) from a data-tractable fragment. Input: a finite database \(D\), a CQ \(Q\) with nonempty body \(\Phi\), and a binary integer \(k>0\). Let \(C\) contain all input constants, let \(H\) be the ground atoms over the schema and \(C\), and put \(m=|H|\). The set-valued answers are the distinct sets \(A=\theta\Phi\subseteq H\) with \(D\cup\Sigma\models A\), where \(\theta\) grounds every body variable using \(C\); labeled nulls are excluded.
A society is given by its support: the list of its \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Each type supplies a Boolean circuit deciding a strict partial order \(\succ_t\) on \(2^H\), with subsets encoded by incidence vectors; preferences are fully specified but may include incomparability.
Optionally, a shared circuit supplies binary-rational probabilities \(p(A)\in[0,1]\), and each type supplies a binary-rational threshold \(h_t\in[0,1]\). Merge each type by starting with its entire preference graph, visiting its original edges \((A,B)\) in lexicographic order, and reversing an edge exactly when \(p(B)-p(A)>h_t\) and the reversal preserves acyclicity; then take transitive closure. Without probabilities, merging is the identity. Denote the merged order by \(R_t\).
For distinct \(A,B\in2^H\), insert \(A\to B\) exactly when \(\sum_t\mu_t\bigl(\mathbf1[A R_t B]-\mathbf1[B R_t A]\bigr)>0\); omit ties. Take transitive closure, then apply this fixed cycle-removal rule: delete every edge whose endpoints lie in the same strongly connected component, including loops. Denote the resulting strict partial order by \(R\).
Restrict \(R\) to the set-valued answers. A skyline answer is an answer with no incoming preference edge. An iterated \(k\)-rank answer repeatedly appends the current skyline, removes its members, and continues until \(k\) distinct answers have been appended or none remain; use lexicographic order within each skyline and truncate the final layer if necessary.
Is deciding whether a skyline answer exists, or whether an iterated \(k\)-rank answer is nonempty, in \(\mathrm P\) or \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), the total input bit length \(L\), \(|D|\), \(|Q|\), and \(k\).
The finite-user CQ nonemptiness problem with polynomial-time set-preference membership is stated to be \(\Sigma_2^{\mathrm P}\)-complete; finite-user disjunctions of atomic queries admit polynomial data-complexity algorithms, modulo probability evaluation and cycle removal. [Source](https://www.cs.ox.ac.uk/files/6556/CS-RR-14-02.pdf)
An earlier single-user formulation also states \(\Sigma_2^{\mathrm P}\)-completeness for CQ nonemptiness. [Source](https://www.ijcai.org/Proceedings/13/Papers/155.pdf) No result settling exactly the rational-mass problem specified above was verified.

1. Result and scope

Both existence problems are \(\mathrm{NP}\)-complete in general combined complexity, already for one fixed binary schema, \(\Sigma=\varnothing\), one type, and no probabilities. With \(Q\) fixed, both are polynomial-time decidable.

The key fact is that, under the specified semantics, both questions are equivalent to ordinary nonemptiness of the set-valued answer set. Rational masses, preference merging, and cycle removal do not affect this equivalence.

The hardness statement concerns a fixed schema and rule set witnessing hardness. It does not mean that every possible fixed schema and \(\Sigma\) yields an NP-hard problem; unary schemas, for example, admit polynomial algorithms even when \(Q\) varies.

We treat the stipulated properties of the input circuits and masses as promises. Checking those promises is a separate problem.

2. The resulting relation is a strict partial order

Let \(V=2^H\), and let \(G\) be the directed graph obtained by weighted voting before transitive closure. Let \(T\) denote positive-length reachability in \(G\).

Two vertices belong to the same strongly connected component precisely when they are equal or mutually reachable. Taking transitive closure does not change these components. Thus the specified cycle-removal rule produces

\(R=\{(A,B)\in T:\operatorname{SCC}(A)\ne\operatorname{SCC}(B)\}\).

This relation is irreflexive because a vertex belongs to its own component.

To prove transitivity, suppose \(A R B\) and \(B R C\). Concatenating their witnessing paths gives \((A,C)\in T\). If \(A\) and \(C\) belonged to the same component, there would also be a path from \(C\) to \(A\). Consequently, \(B\) would reach \(A\) through \(C\), while \(A\) reaches \(B\). This would put \(A\) and \(B\) in the same component, contradicting \(A R B\). Hence \(A R C\).

Therefore \(R\), and its restriction to the answers, are strict partial orders.

3. Existence is exactly answer nonemptiness

Write \(\mathcal A\) for the set of distinct set-valued answers.

Every nonempty finite strict partial order has an element with no incoming edge. Indeed, otherwise one could repeatedly choose a predecessor. Finiteness would force a repeated element, producing a directed cycle, which is impossible in a strict partial order.

Since \(\mathcal A\subseteq 2^H\) is finite, this proves

\(\text{a skyline answer exists}\iff\mathcal A\ne\varnothing\).

The same argument applies after removing any skyline layer. Thus, for every \(k>0\),

\(\text{the iterated $k\)-rank answer is nonempty}\iff\mathcal A\ne\varnothing\).

More precisely, the ranking contains exactly \(\min\{k,|\mathcal A|\}\) distinct answers: whenever answers remain, the next skyline is nonempty, and the procedure stops only upon reaching the requested length or exhausting the answers. Lexicographic tie-breaking does not change this count.

4. Reduction to a finite database and the NP upper bound

Define the finite database of entailed ground atoms

\(E_D=\{a\in H:D\cup\Sigma\models a\}\).

For every grounding \(\theta\), logical entailment of a finite conjunction is equivalent to entailment of each conjunct. Therefore

\(D\cup\Sigma\models\theta\Phi\iff\theta\Phi\subseteq E_D\).

Consequently, both decision problems ask whether there exists a map from the body variables to \(C\), fixing query constants, that sends every body atom into \(E_D\).

This characterization respects the exclusion of labeled nulls. For example, the rule \(P(x)\to\exists y\,S(y)\), together with \(D=\{P(a)\}\), entails \(\exists y\,S(y)\), but does not entail \(S(a)\). When \(C=\{a\}\), the query body \(S(y)\) therefore has no answer in the present sense.

Let \(n=|C|\), let \(v\) be the number of distinct body variables, and let \(q=|Q|\). Because the schema and \(\Sigma\) are fixed and data tractable, ground atomic entailment has a polynomial-time bound \(P_\Sigma(|D|+L)\). The queried tuple may vary: this is the usual data-complexity guarantee for each of the finitely many fixed atomic query shapes.

An NP verifier guesses the \(v\) constants and checks the instantiated atoms using ground atomic entailment. The certificate requires at most \(v\lceil\log_2\max\{2,n\}\rceil\) bits.

The verifier is polynomial-time because \(v\leq q\), \(n\leq L\), and the schema has fixed maximum arity. Hence both existence problems belong to \(\mathrm{NP}\) for every fixed schema and \(\Sigma\) satisfying the stated tractability assumption.

5. NP-hardness with a fixed database

We reduce the standard NP-complete problem of graph 3-colourability.

Fix the schema consisting of one binary predicate \(E\), fix \(\Sigma=\varnothing\), and fix

\(D=\{E(i,j):i,j\in\{0,1,2\},\ i\ne j\}\).

Thus \(C=\{0,1,2\}\), \(m=9\), and \(D\) contains six facts.

Given a finite simple graph \(G\), introduce one variable \(x_u\) for each vertex incident to an edge and form the Boolean CQ with body

\(\Phi_G=\bigwedge_{\{u,w\}\in E(G)}E(x_u,x_w)\).

Choose one orientation for each undirected edge. The orientation is immaterial because the database relation is symmetric.

To guarantee a nonempty body, first add a disjoint single edge to \(G\). This preserves 3-colourability: every colouring of \(G\) extends to the new edge, and every colouring of the enlarged graph restricts to \(G\).

A grounding satisfies \(\theta\Phi_G\subseteq D\) exactly when adjacent vertices receive different elements of \(\{0,1,2\}\). Thus the answer set is nonempty exactly when \(G\) is 3-colourable. Discarding duplicate instantiated atoms does not change this equivalence, since every instantiated query atom must still belong to \(D\).

Supply one type with mass \(1\), whose circuit always returns false, and take \(k=1\). The empty preference relation is a strict partial order. All answers are skyline answers.

The construction is polynomial in the graph size, while \(m\), \(\tau\), \(|D|\), and \(k\) are constants. Therefore both problems are NP-hard. Together with Section 4, this proves NP-completeness for this fixed schema and rule set.

6. Running times

Let the fixed schema have maximum arity \(r\) and \(s\) predicates. Then

\(m=\sum_{P}n^{\operatorname{arity}(P)}\leq s\max\{1,n\}^{r}\),

so \(m\) is polynomially bounded in \(L\).

A deterministic decision algorithm first computes \(E_D\), then enumerates all groundings. Its running time is

\(O\!\left(L+mP_\Sigma(|D|+L)+n^v\operatorname{poly}(q,m,L)\right)\).

Here \(0^0=1\); if \(n=0\) and \(v>0\), the algorithm immediately returns no.

The dependence on the requested parameters is as follows:

  • \(\tau\): no preference processing is needed; reading the input is covered by \(L\).
  • \(k\): only its binary representation and positivity matter, so there is no dependence on its numeric value.
  • \(|Q|\): the grounding exponent satisfies \(v\leq |Q|\).
  • \(|D|\): atomic entailment contributes \(mP_\Sigma(|D|+L)\).
  • \(m\): materializing the entailed ground atoms takes \(m\) entailment tests.

For fixed \(Q\), the exponent \(v\) is fixed, giving polynomial time in \(|D|+L\). Conversely, Section 5 shows that fixing \(m,\tau,|D|\), and \(k\) does not make the variable-query problem tractable unless \(\mathrm P=\mathrm{NP}\).

For completeness, there is also an explicit upper bound for constructing the actual skyline or ranking. Put \(N=2^m\) and \(M=|\mathcal A|\).

For each type, enumerate its original edges over all \(N\) vertices. During merging, consider a current edge \(A\to B\). After temporarily removing it, reversing it preserves acyclicity exactly when there is no remaining path from \(A\) to \(B\): such a path would close a cycle with the proposed edge \(B\to A\). An adjacency-matrix reachability search takes \(O(N^2)\) graph operations, and there are at most \(N^2\) original edges. Hence merging takes \(O(N^4)\) graph operations per type. Subsequent closures, voting, and SCC removal fit within this bound, with polynomial factors for circuit evaluation and exact rational arithmetic.

After enumerating and deduplicating the answers, skyline layers can be generated by maintaining indegrees and processing newly available vertices in batches, sorting each batch lexicographically. A sufficient total bound is

\(O\!\left(L+mP_\Sigma(|D|+L)+n^v\operatorname{poly}(q,m,L)+\tau16^m\operatorname{poly}(m,L)+\min\{k,M\}(m+1)\right)\).

The last term accounts for writing incidence-vector answers. This is a sufficient construction bound, not an optimality claim. The existence decision avoids the entire preference-construction term.

7. Scope of the cited results

The Oxford report states a \(\Sigma_2^{\mathrm P}\)-completeness result for CQ skyline and ranking nonemptiness, and conditional polynomial data-complexity results for atomic disjunctions. Those statements cannot override the finite-order equivalence proved above for the present semantics. [Oxford report, Theorems 4–5](https://www.cs.ox.ac.uk/files/6556/CS-RR-14-02.pdf)

There is also a concrete obstacle to transferring the earlier hardness sketch: it uses sets of forall atoms to dominate sets of exists atoms, while its displayed query contains only exists atoms. Such dominating sets are not answers to that query under the query-restricted domination required here. [IJCAI paper, Theorem 16](https://www.ijcai.org/Proceedings/13/Papers/155.pdf)

Finally, NP-hardness is not universal over fixed schemas. For a unary schema, after computing \(E_D\), each variable can be treated independently: intersect the sets of constants allowed by its unary body atoms, require each intersection to be nonempty, and check all ground body atoms. This gives a polynomial algorithm even for varying \(Q\).
