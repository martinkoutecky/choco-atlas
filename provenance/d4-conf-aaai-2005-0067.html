The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to one, finite rational step-function own-utility curves \(g_t\), externality curves \(h_{r,s}\), and a rational threshold \(K\), decide whether there are action distributions \(\nu_t\) over the finitely many action regions such that \(U_t(a;\nu)=g_t(a)+\sum_{s\in T}\mu_s\int h_{t,s}(z)\,d\nu_s(z)\ge 0\) for \(\nu_t\)-almost every assigned action \(a\), and average welfare \(W(\nu)=\sum_{t\in T}\mu_t\int U_t(a;\nu)\,d\nu_t(a)\ge K\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
Each individual controls one action \(a\in\mathbb R_{\ge0}\). Input curves \(g_t\) and \(h_{r,s}\) are explicitly represented finite, right-continuous piecewise constant functions with rational breakpoints and values. Require \(g_t(0)=h_{r,s}(0)=0\), each \(g_t\) nonincreasing, and every \(h_{r,s}\) nondecreasing; hence \(g_t\le0\) and \(h_{r,s}\ge0\).
For each source type \(s\), partition \(\mathbb R_{\ge0}\) at all breakpoints of \(g_s\) and \(h_{r,s}\), including the final unbounded interval, and let \(A_s\) contain one representative per region. Set \(m=\max_s|A_s|\); let \(L\) be the total binary input length, including a threshold \(K\in\mathbb Q\).
An assignment \(\nu_t\) is a probability distribution with arbitrary real probabilities on \(A_t\), specifying the fractions of type \(t\) assigned each action. Define \(U_t(a;\nu)=g_t(a)+\sum_{s\in T}\mu_s\sum_{z\in A_s}h_{t,s}(z)\nu_s(z)\). The term \(h_{t,t}\) describes externalities from other individuals of the same type.
An assignment is feasible when \(U_t(a;\nu)\ge0\) whenever \(\nu_t(a)>0\). Its average welfare is \(W(\nu)=\sum_{t\in T}\mu_t\sum_{a\in A_t}\nu_t(a)U_t(a;\nu)\). The all-zero action assignment is allowed.

Is deciding whether a feasible assignment with \(W(\nu)\ge K\) exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finitely many individual agents, welfare-threshold feasibility is NP-complete even with one action variable per agent, nonincreasing own utility, nondecreasing externality components, and single-step components; piecewise linear concave components instead admit polynomial-time welfare maximization ([Conitzer–Sandholm](https://www.cs.cmu.edu/~conitzer/externalitiesJCSS10.pdf)).
No result settling this exact mass-distribution problem was identified in the literature search.

  • Set the action domain to the nonnegative reals, with zero as the default action, and normalized every component to zero there, consistently with zero default utility.
  • Specified explicit rational piecewise constant representations and right-continuous breakpoint conventions, matching finite combinations of the defined threshold steps.
  • Defined action regions by the common refinement of every curve depending on the source type's action, retaining the final unbounded region.
  • Interpreted distributions as fractions of a type's population with arbitrary real probabilities, and retained participation constraints for every positively assigned action.
  • Interpreted diagonal externality curves as effects from other individuals of the same type and imposed the same monotonicity as for other externalities.
  • Defined m as the maximum number of action regions and L as the total binary input length; retained an arbitrary rational threshold and allowed the default assignment because the anchor does not require nontriviality.

Result

The decision problem is \(\mathrm{NP}\)-complete. Hardness holds even when all masses are equal dyadic rationals, every nonconstant curve has its only breakpoint at \(\,1\,\), and \(\,m=2\,\).

The reduction below handles arbitrary real assignment probabilities directly.

1. Welfare is linear in the assignment probabilities

Write \(\,p_{s,a}=\nu_s(a)\,\). Since \(\,\sum_{a\in A_t}p_{t,a}=1\,\), expanding the welfare gives

\[ W(p)=\sum_{s\in T}\sum_{a\in A_s} \mu_s\left(g_s(a)+\sum_{t\in T}\mu_t h_{t,s}(a)\right)p_{s,a}. \]

Thus welfare is linear. Feasibility, however, requires an action’s utility to be nonnegative whenever its probability is positive. This conditional requirement will enforce integral choices in the reduction.

2. Construction from Set Cover

We reduce from Set Cover, whose \(\mathrm{NP}\)-completeness is classical. See [Karp’s original paper](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

An instance consists of a universe \(\,E=\{1,\ldots,q\}\,\), sets \(\,S_1,\ldots,S_n\subseteq E\,\), and an integer \(\,k\,\). The question is whether at most \(\,k\,\) sets cover \(\,E\,\). We restrict to \(\,n,q\ge1\,\) and \(\,0\le k\le n\,\); excluded cases are directly decidable, so these restrictions retain hardness.

Let \(\,N\,\) be the smallest power of two satisfying \(\,N\ge n+q+1\,\). Introduce:

  • a hub type \(\,b\,\);
  • a set type \(\,d_j\,\) for every set \(\,S_j\,\);
  • an element type \(\,e_i\,\) for every element \(\,i\,\);
  • enough dummy types to make the support size exactly \(\,N\,\).

Every type has mass \(\,\mu_t=1/N\,\). Define

\[ \delta_j=|S_j|,\qquad D_j=N+\delta_j,\qquad P=n+1, \qquad C=\frac{1}{N}\sum_{j=1}^n D_j. \]

Let \(\,\sigma(a)=0\,\) for \(\,0\le a<1\,\), and \(\,\sigma(a)=1\,\) for \(\,a\ge1\,\).

The own-utility curves are

\[ g_{d_j}(a)=-(1+D_j)\sigma(a),\qquad g_{e_i}(a)=-\sigma(a). \]

The hub and dummy types have identically zero own-utility curves.

The nonzero externality curves are precisely:

  • \(\,h_{d_j,d_j}(a)=N\sigma(a)\,\);
  • \(\,h_{d_j,b}(a)=ND_j\sigma(a)\,\);
  • \(\,h_{e_i,d_j}(a)=N\sigma(a)\,\) whenever \(\,i\in S_j\,\);
  • \(\,h_{b,e_i}(a)=N(1+NP)\sigma(a)\,\).

All other externality curves are zero. Here the first index is the receiver and the second is the source.

Set the welfare threshold to

\[ K=C+Pq-k. \]

Verification of the input requirements

Every curve is finite, explicitly represented, right-continuous, and piecewise constant. All curves vanish at zero. Own-utility curves are nonincreasing, and externality curves are nondecreasing.

Every nondummy source has exactly two regions, represented by \(\,0\,\) and \(\,1\,\). Dummy sources have one region, represented by zero. Therefore \(\,m=2\,\).

Moreover, \(\,N<2(n+q+1)\,\), and all curve values and the threshold have polynomial binary encoding length. The entire explicit construction, including zero curves, has polynomial size. All masses are positive dyadic rationals summing to one.

3. Feasibility forces integral set choices

For an arbitrary assignment, write

\[ y=\nu_b(1),\qquad x_j=\nu_{d_j}(1),\qquad z_i=\nu_{e_i}(1). \]

These numbers lie in \(\,[0,1]\,\).

For set type \(\,d_j\,\), the utility of action one is

\[ U_{d_j}(1;\nu)=-(1+D_j)+x_j+D_jy =-(1-x_j)-D_j(1-y). \]

Both terms on the right are nonpositive. If \(\,x_j>0\,\), feasibility requires this utility to be nonnegative. Consequently both terms must vanish:

\[ x_j>0\quad\Longrightarrow\quad x_j=1\ \text{and}\ y=1. \]

Thus every feasible assignment has \(\,x_j\in\{0,1\}\,\). Fractional set choices are impossible.

For element type \(\,e_i\,\),

\[ U_{e_i}(1;\nu)=-1+\sum_{j:\,i\in S_j}x_j. \]

Hence \(\,z_i>0\,\) is possible only if at least one selected set contains \(\,i\,\). Conversely, when this condition holds, assigning action one to the entire element type is feasible.

Action zero always has nonnegative utility, because its own utility is zero and all externalities are nonnegative. Both hub actions and all dummy actions likewise have nonnegative utility. These observations check every feasibility constraint.

4. Exact welfare calculation

Using the linear welfare formula from Section 1, the coefficient of the hub probability \(\,y\,\) is

\[ \frac{1}{N}\sum_{j=1}^n D_j=C. \]

For set type \(\,d_j\,\), its action-one coefficient is

\[ \frac{1}{N}\left(-(1+D_j)+1+\delta_j\right) =\frac{-D_j+\delta_j}{N}=-1. \]

The positive terms here are its self-externality and its externalities to the elements of \(\,S_j\,\).

For element type \(\,e_i\,\), its action-one coefficient is

\[ \frac{1}{N}\left(-1+(1+NP)\right)=P. \]

All action-zero coefficients and all dummy coefficients vanish. Therefore, for every assignment,

\[ W(\nu)=Cy-\sum_{j=1}^n x_j+P\sum_{i=1}^q z_i. \]

5. Correctness of the reduction

A set cover produces a feasible assignment meeting the threshold

Suppose \(\,J\subseteq\{1,\ldots,n\}\,\) covers \(\,E\,\) and \(\,|J|\le k\,\).

Choose \(\,y=1\,\), choose \(\,x_j=1\,\) exactly for \(\,j\in J\,\), and choose \(\,z_i=1\,\) for every element.

Every selected set type has action-one utility zero. Every element type has action-one utility at least zero because it is covered. All other assigned actions are feasible by Section 3. The welfare is

\[ W=C-|J|+Pq\ge C-k+Pq=K. \]

A feasible assignment meeting the threshold produces a set cover

Conversely, suppose a feasible assignment satisfies \(\,W\ge K\,\). Define

\[ J=\{j:x_j>0\}. \]

Section 3 proves that \(\,x_j=1\,\) for every \(\,j\in J\,\), so \(\,\sum_jx_j=|J|\,\). Since \(\,C>0\,\), \(\,y\le1\,\), and \(\,z_i\le1\,\),

\[ W\le C-|J|+Pq. \]

Comparing this bound with \(\,W\ge C+Pq-k\,\) yields \(\,|J|\le k\,\).

If some element were uncovered by \(\,J\,\), its feasibility constraint would force \(\,z_i=0\,\). Then

\[ W\le C-|J|+P(q-1)\le C+P(q-1). \]

But \(\,P=n+1>k\,\), so

\[ C+P(q-1)<C+Pq-k=K, \]

a contradiction. Thus \(\,J\,\) covers every element and contains at most \(\,k\,\) sets.

This proves \(\mathrm{NP}\)-hardness.

6. Membership in \(\mathrm{NP}\)

For the general problem, nondeterministically choose a nonempty subset \(\,B_t\subseteq A_t\,\) for each type. Consider the following rational linear feasibility system:

  • \(\,p_{t,a}\ge0\,\) and \(\,\sum_{a\in A_t}p_{t,a}=1\,\);
  • \(\,p_{t,a}=0\,\) whenever \(\,a\notin B_t\,\);
  • for every \(\,a\in B_t\,\),

\[ g_t(a)+\sum_{s\in T}\mu_s\sum_{z\in A_s}h_{t,s}(z)p_{s,z}\ge0; \]

  • the linear welfare expression from Section 1 is at least \(\,K\,\).

If the original instance has a feasible assignment, choosing its actual positive-probability supports makes this system feasible.

Conversely, any solution of this system is feasible for the original problem: every action with positive probability belongs to \(\,B_t\,\) and therefore has nonnegative utility. Allowing some actions in \(\,B_t\,\) to receive zero probability causes no difficulty.

There are at most \(\,\tau m\,\) variables and polynomially many constraints. Their rational coefficients can be computed with polynomial bit length from the explicitly represented input. Rational linear-programming feasibility is decidable in time polynomial in this encoding length. Thus a polynomial-length support guess followed by a polynomial-time feasibility check establishes membership in \(\mathrm{NP}\).

Arbitrary real probabilities do not enlarge the class of yes-instances beyond rational witnesses: each feasible system above is a bounded rational polytope, and a nonempty such polytope has a rational vertex of polynomial encoding length, by the determinant bounds for its defining tight constraints.

Consequently, the problem is \(\mathrm{NP}\)-complete, and a polynomial-time algorithm in \(\,m,\tau,L\,\) would imply \(\mathrm{P}=\mathrm{NP}\).
