The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), finite domains \(D_t\), symmetric nonnegative rational interaction weights \(w_{tu}\), and symmetric nonnegative rational pair-cost tables \(c_{tu}(d,e)\), choose fractions \(x_{td}\ge 0\) with \(\sum_{d\in D_t}x_{td}=1\) to minimize \(\Phi(x)=\frac{1}{2}\sum_{t,u\in T}\mu_t\mu_u w_{tu}\sum_{d\in D_t,e\in D_u}x_{td}x_{ue}c_{tu}(d,e)\). Return the minimum and a minimizing table, where each unit of population still receives one integral value; equivalently, for rational \(K\), decide whether some feasible table has \(\Phi(x)\le K\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) counts supported types, not all possible types.
Each type has an explicitly listed nonempty finite domain \(D_t\). Input includes finite nonnegative binary-rational weights \(w_{tu}=w_{ut}\), tables \(c_{tu}(d,e)=c_{ut}(e,d)\geq 0\), and a binary-rational threshold \(K\).
A feasible allocation has real fractions \(x_{td}\geq 0\) with \(\sum_{d\in D_t}x_{td}=1\): mass \(\mu_tx_{td}\) receives the single domain value \(d\), shared across all its interactions.
Its cost is \(\Phi(x)=\frac12\sum_{t,u\in T}\mu_t\mu_uw_{tu}\sum_{d\in D_t,e\in D_u}x_{td}x_{ue}c_{tu}(d,e)\). Terms with \(t=u\) represent interactions between distinct individuals of the same type and are permitted.
Decide whether a feasible allocation satisfies \(\Phi(x)\leq K\). Let \(m=\max_t|D_t|\) and \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this continuous allocation decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite agents choosing one domain value each and minimizing the sum of binary constraint costs, BnB-ADOPT terminates with the exact minimum; this is a correctness guarantee, without a polynomial-time bound, and discrete DCOP optimization is reported as \(\mathrm{NP}\)-hard. [Yeoh, Felner and Koenig](https://tzin.bgu.ac.il/~felner/2010/DFBnB.pdf)
General rational quadratic feasibility over a rational polyhedron is known to belong to \(\mathrm{NP}\); no classification of the precise mass-allocation problem above was verified. [Del Pia, Dey and Molinaro](https://arxiv.org/abs/1407.4798)

  • Excluded empty domains, which would prevent an agent from choosing a value.
  • Made table symmetry explicit as reversal of both type and value arguments.
  • Retained same-type interaction terms from the graded formula and interpreted them as interactions between distinct individuals of that type, consistent with binary constraints involving distinct agents.
  • Specified unrestricted real allocation fractions and used the threshold decision formulation to avoid an unspecified representation for exact optimization outputs.

Classification

The decision problem is \(\mathrm{NP}\)-complete. In particular, it is \(\mathrm{NP}\)-hard even when \(\tau=1\). It is also \(\mathrm{NP}\)-hard when \(m=2\) and all same-type interaction weights vanish.

An exact deterministic algorithm runs in
\[ \]
\(\displaystyle O\!\left((2^m-1)^\tau\operatorname{poly}(L)\right).\)

The proofs below account for real fractional allocations and binary encoding lengths.

1. Hardness with one supported type

We reduce from CLIQUE: given a nonempty finite simple graph \(G=(V,E)\) and an integer \(k\) with \(1\leq k\leq |V|\), decide whether \(G\) contains a clique of size at least \(k\). This restricted problem is \(\mathrm{NP}\)-complete; the omitted cases are immediately decidable. See [Karp’s original paper](https://doi.org/10.1007/978-1-4684-2001-2_9).

Construct an allocation instance with one type \(t\), setting

\(\displaystyle \mu_t=1,\qquad D_t=V,\qquad w_{tt}=k,\qquad K=\frac12.\)

Its symmetric cost table \(C=c_{tt}\) is defined by:

  • \(C_{vv}=1\) for every vertex \(v\);
  • \(C_{uv}=0\) when \(\{u,v\}\in E\);
  • \(C_{uv}=1\) when \(u\neq v\) and \(\{u,v\}\notin E\).

All input numbers are integers or dyadic rationals. The explicitly listed table has polynomial size.

Write \(\omega(G)\) for the largest clique size. We prove

\(\displaystyle \min_{\substack{x\geq 0\\ \sum_{v\in V}x_v=1}}x^\top Cx=\frac1{\omega(G)}.\)

A minimizer supported on a clique

The simplex is compact, so the continuous function \(F(x)=x^\top Cx\) attains its minimum. Choose a minimizer having the smallest possible number of positive coordinates.

Suppose two vertices \(a,b\) in its support are nonadjacent. Set \(s=x_a+x_b>0\), keep all other coordinates fixed, and replace \(x_a,x_b\) by \(r,s-r\), where \(0\leq r\leq s\).

Because \(C_{aa}=C_{bb}=C_{ab}=1\), the terms involving only these coordinates sum to

\(\displaystyle r^2+(s-r)^2+2r(s-r)=s^2.\)

Define

\(\displaystyle A=\sum_{v\notin\{a,b\}}C_{av}x_v,\qquad B=\sum_{v\notin\{a,b\}}C_{bv}x_v.\)

For a constant \(C_0\) containing the terms involving neither coordinate, the resulting objective is

\(\displaystyle F(x(r))=C_0+s^2+2rA+2(s-r)B.\)

This is affine in \(r\). Consequently, one endpoint has objective no greater than the original point. Since the original point is a global minimizer, that endpoint is also a global minimizer. It has smaller support, a contradiction.

Thus the chosen minimizer is supported on a clique.

Computing the minimum

If that clique support has size \(r\), all its off-diagonal costs vanish. Hence, by Cauchy–Schwarz,

\(\displaystyle F(x)=\sum_{v\in\operatorname{supp}(x)}x_v^2\geq\frac{\left(\sum_vx_v\right)^2}{r}=\frac1r\geq\frac1{\omega(G)}.\)

Conversely, the uniform distribution on a largest clique has objective \(1/\omega(G)\). This proves the claimed identity.

The constructed allocation instance therefore satisfies

\(\displaystyle \min_x\Phi(x)=\frac{k}{2\omega(G)}.\)

It follows that

\(\displaystyle \exists x:\Phi(x)\leq K\quad\Longleftrightarrow\quad\frac{k}{2\omega(G)}\leq\frac12\quad\Longleftrightarrow\quad\omega(G)\geq k.\)

This is a polynomial-time reduction proving hardness with \(\tau=1\). It uses precisely the same-type interactions permitted in the question.

2. Hardness with two domain values and no same-type interactions

First we establish why fractions do not improve the optimum when \(w_{tt}=0\) for every type.

Pure-allocation lemma

A pure allocation chooses one value \(d_t\in D_t\) for each type and assigns that value to its entire mass.

Given any fractional allocation \(x\), independently choose a random value \(Y_t\) for each type with

\(\displaystyle \Pr(Y_t=d)=x_{td}.\)

For distinct types, independence gives

\(\displaystyle \mathbb E[c_{tu}(Y_t,Y_u)]=\sum_{d\in D_t,e\in D_u}x_{td}x_{ue}c_{tu}(d,e).\)

Because all same-type terms vanish, the expected cost of this random pure allocation equals \(\Phi(x)\). At least one outcome has cost at most its expectation. Conversely, every pure allocation is feasible. Therefore

\(\displaystyle \min_{\text{fractional }x}\Phi(x)=\min_{\text{pure }x}\Phi(x).\)

Reduction from MAX-CUT

The decision problem asking whether a graph has a cut containing at least \(B\) edges is \(\mathrm{NP}\)-complete; this precise version is also stated in the proof of Corollary 2 of [Del Pia, Dey and Molinaro](https://arxiv.org/pdf/1407.4798).

Given \(G=(V,E)\), pad it with isolated vertices until its number \(N\) of vertices is a power of two. This adds fewer than \(|V|\) vertices.

Create one supported type per padded vertex, with

\(\displaystyle \tau=N,\qquad D_t=\{0,1\},\qquad \mu_t=\frac1N.\)

For every original edge \(\{t,u\}\), set \(w_{tu}=N^2\); set all other weights, including \(w_{tt}\), to zero. For distinct types, set \(c_{tu}(d,e)=1\) if \(d=e\), and zero otherwise. Set all same-type tables to zero and choose

\(\displaystyle K=|E|-B.\)

Symmetry and the factor \(1/2\) in the objective yield

\(\displaystyle \Phi(x)=\sum_{\{t,u\}\in E}\left(x_{t0}x_{u0}+x_{t1}x_{u1}\right).\)

For a pure allocation this counts exactly the uncut edges. By the pure-allocation lemma,

\(\displaystyle \min_x\Phi(x)=|E|-\operatorname{MaxCut}(G).\)

Thus the allocation instance is a yes-instance exactly when \(G\) has a cut of size at least \(B\).

Every supported mass is positive and dyadic. The construction lists \(O(N^2)\) constant-size tables and weights having \(O(\log N)\) bits, so its output length and construction time are polynomial in the source input length. This proves hardness with \(m=2\) and no same-type interactions.

3. Exact algorithm and polynomial-size certificates

Let

\(\displaystyle n=\sum_{t\in T}|D_t|\leq m\tau.\)

Index coordinates by pairs \((t,d)\), and define the rational symmetric matrix

\(\displaystyle Q_{(t,d),(u,e)}=\mu_t\mu_uw_{tu}c_{tu}(d,e).\)

Then \(\Phi(x)=\tfrac12x^\top Qx\). The feasible region is a nonempty compact product of simplices, so a global minimizer exists.

We now prove that an optimum can be recovered by enumerating supports and solving rational linear feasibility problems.

Stationarity on a specified support

Choose nonempty subsets \(S_t\subseteq D_t\), and let \(Q_S\) be the principal submatrix on their coordinates. Choose a reference value \(r_t\in S_t\) for each type.

Define \(R_S\) by the following linear constraints:

\(\displaystyle z_{td}\geq0,\qquad \sum_{d\in S_t}z_{td}=1\quad(t\in T),\)

\(\displaystyle (Q_Sz)_{td}=(Q_Sz)_{t r_t}\quad(t\in T,\ d\in S_t\setminus\{r_t\}).\)

Every point of \(R_S\), extended by zero outside the selected subsets, is a feasible allocation.

Let \(x^*\) be a global minimizer, and choose its actual supports

\(\displaystyle S_t=\{d\in D_t:x^*_{td}>0\}.\)

For any \(d,r_t\in S_t\), sufficiently small transfers of mass in either direction between those two coordinates remain feasible. The derivative of the objective in that direction must therefore vanish. Since its gradient on the selected coordinates is \(Q_Sx^*\), these derivatives give exactly the displayed stationarity equations. Consequently, \(x^*\in R_S\).

The quadratic objective is constant on \(R_S\)

Take \(z,y\in R_S\) and put \(\delta=y-z\). For each type,

\(\displaystyle \sum_{d\in S_t}\delta_{td}=0.\)

The stationarity equations make \(Q_Sz\) and \(Q_Sy\) constant within each type’s coordinates. Therefore

\(\displaystyle \delta^\top Q_Sz=\delta^\top Q_Sy=0.\)

Using symmetry,

\(\displaystyle \frac12y^\top Q_Sy-\frac12z^\top Q_Sz=\frac12(y-z)^\top Q_S(y+z)=0.\)

Thus any point of a nonempty \(R_S\) gives its unique objective value. In particular, any point of the set associated with an optimal support is itself globally optimal.

Bit complexity and membership in \(\mathrm{NP}\)

Each \(R_S\) is a bounded rational polyhedron: nonnegativity and the normalization equations bound every coordinate between zero and one. If nonempty, it has a vertex.

Its linear description has size polynomial in \(L\). To justify polynomial-size vertex coordinates, select a full-rank collection of active constraints determining a vertex. Such a collection exists: otherwise a nonzero direction preserving the active constraints would permit small feasible perturbations in both directions, contradicting extremality.

Clear denominators in those equations and apply Cramer’s rule. The integer coefficients have polynomial bit length; determinant bounds then give polynomial bit length for every vertex coordinate.

Applying this to an optimal support proves that every instance has a rational global minimizer of encoding length polynomial in \(L\). A certificate for a yes-instance consists of its rational coordinates. Nonnegativity, normalization, and \(\Phi(x)\leq K\) can all be checked by exact rational arithmetic in polynomial time. Hence the problem belongs to \(\mathrm{NP}\).

This also verifies the hypotheses of the general quadratic-feasibility result: the objective and threshold are rational, and the feasible region is a rational polyhedron. The continuous result appears as Theorem 3 in [Del Pia, Dey and Molinaro](https://arxiv.org/pdf/1407.4798).

Running time

Enumerate every choice of nonempty \(S_t\subseteq D_t\). For each choice, use polynomial-time rational linear programming to test whether \(R_S\) is nonempty and obtain a rational feasible point when it is. Evaluate its objective and compare with \(K\).

Every evaluated point is feasible, and the enumeration includes an optimal support. Thus this algorithm decides the problem exactly.

The number of choices is

\(\displaystyle \prod_{t\in T}(2^{|D_t|}-1)\leq(2^m-1)^\tau.\)

The total running time is therefore

\(\displaystyle O\!\left((2^m-1)^\tau\operatorname{poly}(L)\right)\subseteq O\!\left(2^{m\tau}\operatorname{poly}(L)\right).\)

When all same-type weights vanish, the pure-allocation lemma instead permits enumeration in

\(\displaystyle O\!\left(m^\tau\operatorname{poly}(L)\right).\)

4. Consequences and relation to the cited DCOP guarantee

For \(m=1\), the allocation is uniquely determined and the decision takes polynomial time in \(L\). For fixed \(m\) and \(\tau\), the support-enumeration algorithm is polynomial in \(L\). Fixing only \(\tau\) does not suffice: hardness already holds for \(\tau=1\). Fixing only \(m\) does not suffice either: hardness holds for \(m=2\).

The stated termination and optimality guarantee for BnB-ADOPT concerns exact discrete optimization; it does not supply a polynomial running-time bound. [Yeoh, Felner and Koenig](https://tzin.bgu.ac.il/~felner/2010/DFBnB.pdf). The reductions above directly establish hardness for the continuous allocation model, and the certificate argument establishes membership in \(\mathrm{NP}\).

Together they prove \(\mathrm{NP}\)-completeness. A polynomial-time algorithm for the general problem exists if and only if \(\mathrm{P}=\mathrm{NP}\).
