The anchor (named result in the paper)

Theorem 5.2 — class: hardness

The continuous mirror question, as graded

Given indivisible goods \(G=[m]\), \(k\) groups, rational additive types \(t=(i,v)\), and a rational mass distribution \(\mu\) over those types, together with \(r\), distinguish whether there is a partition \((A_1,\ldots,A_k)\) such that every type with \(\mu_t>0\) has exact consensus \(1/k\)-division, or whether no partition is \(\mathrm{PROP}_r\) for every such type.

Packaged proof task (what the prover saw — nothing else)

Fix any constant \(k\ge 2\). Let \(G=[m]\), with \(m\ge 1\), be indivisible goods. A type \(t=(i,v_t)\) belongs to group \(i\in[k]\) and has a nonnegative rational additive valuation \(v_t\in\mathbb{Q}_{\ge 0}^{m}\); write \(v_t(S)\) for its value of a bundle.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the support size, not the number of possible types. Require \(\sum_t\mu_t=1\) and \(\sum_{t:i(t)=i}\mu_t=1/k\) for every group. Let \(L\) be the total input bit length.
An allocation \((A_1,\ldots,A_k)\) is an ordered partition of all goods; empty bundles are allowed. It is an exact consensus \(1/k\)-division if \(v_t(A_j)=v_t(G)/k\) for every supported type \(t\) and every \(j\in[k]\).
For an input integer \(r\ge 0\), it is \(\mathrm{PROP}_r\) if every supported type \(t=(i,v_t)\) admits a set \(B_t\subseteq G\setminus A_i\), with \(|B_t|\le r\), such that \(v_t(A_i)\ge v_t(G)/k-v_t(B_t)\). These conditions apply separately to every supported type.
Promise that either YES: an exact consensus division exists; or NO: no allocation is \(\mathrm{PROP}_r\) for all supported types.

For each fixed \(k\ge 2\), is distinguishing these promised cases solvable in time \(\operatorname{poly}(m,\tau,L)\), or is it NP-hard, with \(r\) part of the input?

For finite societies with \(n'\) agents in each group, this distinction is NP-hard at relaxation \(\lfloor\varepsilon_k\sqrt{n'}\rfloor\) for some constant \(\varepsilon_k>0\); a deterministic polynomial-time algorithm achieves relaxation \(O(\sqrt{n})\) for \(n\) total agents. [Manurangsi–Suksompong](https://arxiv.org/html/2105.01609v2)
No result specifically addressing the stated distribution formulation was identified in the literature search.

  • Restricted valuations to nonnegative rational coordinates, allowing zero values, as intended for goods.

  • Normalized total mass to one and translated equally sized groups into group masses of 1/k.
  • Specified r as a nonnegative integer encoded in binary; retained it as an independent input rather than introducing a population count absent from the distribution model.

Result

For every fixed \(k\ge 2\), the promised distinction is \(\mathrm{NP}\)-hard. More strongly, there is a positive rational constant \(c_k\) such that hardness holds even under the restriction \(r=\lfloor c_k\sqrt{\tau}\rfloor\).

Thus the result concerns a relaxation depending on the support size, beyond the special case \(r=0\).

Finite-society hardness used

Fix \(k\ge 2\). By [Manurangsi–Suksompong, Theorem 5.2](https://arxiv.org/html/2105.01609v2#S5), there is a constant \(\varepsilon_k>0\) for which the following distinction is \(\mathrm{NP}\)-hard. The input explicitly lists \(n'\) agents in each of \(k\) groups, with additive valuations:

  • YES: an exact consensus \(1/k\)-division exists.
  • NO: no allocation satisfies \(\mathrm{PROP}_{\lfloor\varepsilon_k\sqrt{n'}\rfloor}\) for every agent.

Their definition of proportionality up to goods is exactly the definition in the question.

The theorem applies to rational inputs. Indeed, its construction starts with matrix entries in \(\{0,\tfrac12,1\}\), applies a Boolean matrix product and division by a fixed positive integer, and uses the resulting entries as valuations. Hence its hard instances have nonnegative rational valuations with polynomial encoding length.

Support aggregation preserves both predicates

Consider such a finite instance. For each group \(i\), let \(V_i\) be the set of distinct valuation vectors occurring in that group. For \(v\in V_i\), define its multiplicity by

\[ \]
\(d_{i,v}:=\bigl|\{a:\ a\text{ belongs to group }i\text{ and has valuation }v\}\bigr|\).

Create one supported type \(t=(i,v)\) with mass

\[ \]
\(\mu_{i,v}:=\dfrac{d_{i,v}}{kn'}\).

Here rational numerators and denominators are encoded in binary. Every listed mass is positive. Since each group contains exactly \(n'\) agents,

\[ \]
\(\displaystyle\sum_{v\in V_i}\mu_{i,v}=\frac{n'}{kn'}=\frac1k,\qquad \sum_{i=1}^{k}\sum_{v\in V_i}\mu_{i,v}=1.\)

Thus the constructed society satisfies every mass constraint, and its support size obeys \(\tau=\sum_i|V_i|\le kn'\).

We now verify predicate preservation for every allocation.

Exact consensus. Its equalities depend only on the valuation vector. Replacing multiple copies of a vector by one supported type therefore preserves every equality. Consequently, an allocation is an exact consensus division for the finite instance if and only if it is one for the constructed society.

Proportionality. Fix a nonnegative integer \(s\). All agents with the same pair \((i,v)\) have precisely the same requirement:

\[ \]
\(\displaystyle\exists B\subseteq G\setminus A_i,\quad |B|\le s,\quad v(A_i)\ge \frac{v(G)}k-v(B).\)

If this requirement holds for the type, its witnessing set works for each corresponding agent. Conversely, a witness for any corresponding agent works for the type. Therefore, an allocation satisfies \(\mathrm{PROP}_s\) for every finite agent if and only if it satisfies \(\mathrm{PROP}_s\) for every supported type.

Choosing an integer relaxation from the support size

Choose a positive integer \(q_k\), depending only on fixed \(k\), sufficiently large that \(\sqrt{k}/q_k\le\varepsilon_k\). Set \(c_k:=1/q_k\) and output

\[ \]
\(\displaystyle r:=\left\lfloor\frac{\sqrt{\tau}}{q_k}\right\rfloor=\lfloor c_k\sqrt{\tau}\rfloor.\)

This integer is computed exactly as the largest nonnegative integer \(h\) satisfying \(q_k^2h^2\le\tau\); no approximation of a square root is needed.

Because \(\tau\le kn'\),

\[ \]
\(\displaystyle r\le\frac{\sqrt{\tau}}{q_k}\le\frac{\sqrt{kn'}}{q_k}\le\varepsilon_k\sqrt{n'}.\)

Since \(r\) is integral, it follows that \(r\le\lfloor\varepsilon_k\sqrt{n'}\rfloor\).

We verify the two promised cases:

  • Finite YES implies distribution YES. Predicate preservation supplies an exact consensus division.
  • Finite NO implies distribution NO. Suppose the constructed society admitted an allocation satisfying \(\mathrm{PROP}_r\) for every type. Predicate preservation would make it satisfy \(\mathrm{PROP}_r\) for every finite agent. Every witnessing set would also have cardinality at most \(\lfloor\varepsilon_k\sqrt{n'}\rfloor\), contradicting the finite NO condition.

Hence every promised source instance maps to the corresponding promised target case.

Encoding and conclusion

The source instance explicitly lists all \(kn'\) valuation vectors. Grouping equal vectors can be done in polynomial time by exact rational comparison. Every mass numerator and denominator has bit length \(O(\log(kn'))\); valuations are copied without enlargement; and \(\tau\le kn'\). The output relaxation also has polynomial encoding length. Thus the reduction runs in polynomial time and produces a polynomial-size instance.

A distinguishing algorithm running in \(\operatorname{poly}(m,\tau,L)\) would therefore distinguish the finite hard instances in polynomial time. This proves \(\mathrm{NP}\)-hardness for every fixed \(k\ge2\), including the restriction \(r=\lfloor c_k\sqrt{\tau}\rfloor\).
