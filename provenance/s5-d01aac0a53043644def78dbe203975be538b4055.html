The continuous mirror question, as graded

Given a finite policy set \(R\), comparison set \(C\), finite type set \(T\), calibrated type utilities \(u_t\), known response map \(r_t(q)\in\{-1,0,1\}^K\), and rational polytope \(\mathcal M^0\subseteq\Delta(T)\), choose \(q\in C^K\) and a recommendation for each observed response-mass profile \(p\) to maximize \(\min_{p\in P(q)}\max_{x\in R}\min_{\mu\in\mathcal M(q,p)}\sum_{t\in T}\mu_t u_t^\top x\), where \(P(q)\) is the set of profiles compatible with \(q\) and \(\mathcal M(q,p)=\{\mu\in\mathcal M^0:\sum_{t:r_t(q)=r}\mu_t=p_r\ \forall r\}\).

Packaged proof task (what the prover saw — nothing else)

Let \(Q=\{y_1,\ldots,y_I\}\subseteq\mathbb Q^d\), with \(I\ge2\), be the explicitly listed query items, and let \(R\subseteq\mathbb Q^d\) be a nonempty explicitly listed recommendation set; these sets may differ. Put \(m=|Q\cup R|\) and \(C=\{(i,j):1\le i<j\le I\}\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; \(\tau\) is the support size, not the number of possible types. Here the masses are unknown: the input lists their common support \(T\), with \(|T|=\tau\), and a nonempty rational polytope \(\mathcal M^0\subseteq\{\mu\in\mathbb R_{>0}^{T}:\sum_t\mu_t=1\}\), given by explicit rational linear inequalities. Optimization ranges over real masses in this polytope.
Each type has a calibrated utility vector \(u_t\in\mathbb Q^d\), on a common interpersonal scale, and utility \(u_t^\top x\); attributes and utilities may have either sign. An explicit table gives \(a_{t,c}\in\{-1,0,1\}\) for every type and comparison: the first item is strictly preferred, the items are indifferent, or the second item is strictly preferred, respectively. These responses are fixed type data and may encode inconsistencies with utility.
Given a positive integer \(K\) in unary, precommit to \(q=(q_1,\ldots,q_K)\in C^K\), allowing repetitions, and write \(r_t(q)=(a_{t,q_1},\ldots,a_{t,q_K})\). Observe the joint response-mass profile, rather than separate marginal response frequencies: for \(D(q)=\{r_t(q):t\in T\}\), define \((A_q\mu)_r=\sum_{t:r_t(q)=r}\mu_t\), \(P(q)=A_q\mathcal M^0\), and \(\mathcal M(q,p)=\{\mu\in\mathcal M^0:A_q\mu=p\}\).
After observing \(p\), recommend one deterministic policy from \(R\), with any maximizing policy permitted in a tie. Define \(V=\max_{q\in C^K}\min_{p\in P(q)}\max_{x\in R}\min_{\mu\in\mathcal M(q,p)}\sum_{t\in T}\mu_tu_t^\top x\). Let \(L\) be the total binary encoding length of the rational data, inequalities, response table, and threshold.

Is deciding whether \(V\ge b\), for an input rational threshold \(b\), solvable in polynomial time or NP-hard? State running times in \(m,\tau,d,K,L\).

For a single decision-maker with polyhedral utility uncertainty and a discrete recommendation set, evaluating the worst-case utility of a fixed query sequence is NP-hard even with two recommendations. Result. The decision problem is \(\mathrm{NP}\)-complete, even with \(d=1\), exactly two recommendations, binary responses, and threshold \(b=0\). Evaluating a fixed query sequence is polynomial-time solvable.

The hardness therefore comes from selecting the queries. The fixed-query hardness in [Theorem 1(b) of the cited paper](https://optimization-online.org/wp-content/uploads/2020/02/Robust_Active_Preference_Elicitation_OptimizationOnline.pdf) concerns a different uncertainty model.

1. A polynomial-size linear program for a fixed sequence.

Write \(J=|R|\), and define \(g_x\in\mathbb Q^\tau\) by \((g_x)_t=u_t^\top x\). Fix a sequence \(q\), abbreviate \(A=A_q\), and denote its value by

\(v(q)=\min_{p\in A\mathcal M^0}\max_{x\in R}\min_{\mu\in\mathcal M^0:\,A\mu=p}g_x^\top\mu.\)

Choose any \(x_*\in R\). Introduce one mass vector \(\nu^x\) for each recommendation \(x\in R\). Consider the linear program with objective \(\min z\) and constraints

  • \(\nu^x\in\mathcal M^0\) for every \(x\in R\);
  • \(A\nu^x=A\nu^{x_*}\) for every \(x\in R\setminus\{x_*\}\);
  • \(g_x^\top\nu^x\le z\) for every \(x\in R\).

Its optimum is exactly \(v(q)\).

To prove this, first fix \(p\in A\mathcal M^0\). The fiber \(\{\mu\in\mathcal M^0:A\mu=p\}\) is nonempty and compact: \(\mathcal M^0\) is a closed polytope contained in the bounded simplex. Therefore every recommendation’s minimum is attained. Because the vectors \(\nu^x\) can be chosen independently within this common fiber,

\(\min_{\nu^x\in\mathcal M^0,\ A\nu^x=p\ \forall x}\max_{x\in R}g_x^\top\nu^x=\max_{x\in R}\min_{\mu\in\mathcal M^0:\,A\mu=p}g_x^\top\mu.\)

Indeed, any choices on the left give an objective at least the right-hand side, while choosing a minimizer separately for each \(x\) gives equality. Allowing the common profile \(p\) to vary gives exactly the stated linear program.

The feasible set of mass-vector tuples is a nonempty closed subset of the compact product \((\mathcal M^0)^J\). Hence minimizing the continuous function \(\max_x g_x^\top\nu^x\) attains its optimum. This also proves that the outer minimum defining \(v(q)\) is attained.

There are at most \(\tau\) realized response profiles, regardless of \(3^K\). If the input representation of \(\mathcal M^0\) has \(h\) inequalities, the program has \(J\tau+1\) variables, \(Jh+J\) inequalities, and at most \((J-1)\tau\) equalities. Its rational encoding length is polynomial in the input length. Polynomial-time rational linear programming therefore computes \(v(q)\) exactly in

\(\operatorname{poly}(m,\tau,d,K,L)\)

bit operations, including constructing the partition and the utility coefficients.

A sequence \(q\) is a certificate of length \(O(K\log |C|)\). Since \(K\) is unary, guessing \(q\) and checking \(v(q)\ge b\) proves membership in \(\mathrm{NP}\).

2. Reduction from Set Cover.

Take an instance of Set Cover with universe \(U=\{1,\ldots,n\}\), sets \(S_1,\ldots,S_s\), and budget \(k\), where \(n,s\ge1\) and \(1\le k\le s\). These restrictions preserve the standard \(\mathrm{NP}\)-completeness of Set Cover.

Construct the following instance:

  • \(d=1\), \(Q=\{2,3,\ldots,s+2\}\), and \(R=\{-1,1\}\);
  • \(T=\{0,1,\ldots,n\}\), so \(\tau=n+1\);
  • utilities \(u_0=-n\) and \(u_i=1\) for \(i\in U\);
  • query budget \(K=k\) and threshold \(b=0\).

Let \(y_1=2\). For each set \(S_j\), designate the comparison \(c_j=(1,j+1)\). Define its responses by

\(a_{0,c_j}=0,\qquad a_{i,c_j}=\begin{cases}1,&i\in S_j,\\0,&i\notin S_j.\end{cases}\)

Every undesignated comparison has response zero for every type. These responses are permitted because the task explicitly allows inconsistencies between responses and utility.

Put \(\varepsilon=1/(2(n+1))\), and define

\(\mathcal M^0=\{\mu\in\mathbb R^{n+1}:\sum_{i=0}^{n}\mu_i=1,\ \mu_i\ge\varepsilon\text{ for all }i\}.\)

This is a rational polytope wholly contained in the strictly positive simplex. It is nonempty because it contains the uniform vector \(\bar\mu_i=1/(n+1)\).

The construction has polynomial size. In particular, its explicit response table has \(O((n+1)s^2)\) entries, and writing \(K=k\) in unary costs at most \(s\) symbols.

For a sequence \(q\), define the covered elements by

\(H(q)=\bigcup_{j:\,c_j\text{ occurs in }q}S_j.\)

We prove the following gap:

\(H(q)=U\ \Longrightarrow\ v(q)=0,\qquad H(q)\ne U\ \Longrightarrow\ v(q)\le-\tfrac12.\)

3. Verification of the reduction.

Suppose first that \(H(q)=U\). Type zero has the all-zero response vector, and every element type has a nonzero response vector. Thus type zero forms a singleton response cell.

For any observed profile \(p\), let \(p_0\) be the mass of that cell. Every mass vector in its fiber has \(\mu_0=p_0\), so its welfare for recommendation \(1\) is

\(\sum_{i=0}^{n}\mu_i u_i=-np_0+(1-p_0)=1-(n+1)p_0.\)

Recommendation \(-1\) gives the negative of this quantity. Consequently the optimal guaranteed utility at this profile is

\(\max\{1-(n+1)p_0,\,-1+(n+1)p_0\}=|1-(n+1)p_0|\ge0.\)

The uniform vector produces an attainable profile with \(p_0=1/(n+1)\), where this value is zero. Therefore \(v(q)=0\).

Now suppose that some element \(e\) is uncovered. Then types zero and \(e\) both have the all-zero response vector, hence identical columns in \(A_q\).

Let \(e_i\) denote the coordinate vector for type \(i\), and define

\(\mu^+=\bar\mu+\varepsilon(e_e-e_0),\qquad \mu^-=\bar\mu-\varepsilon(e_e-e_0).\)

Both vectors belong to \(\mathcal M^0\): their coordinates are \(\varepsilon\), \(3\varepsilon\), or \(2\varepsilon\), and their coordinates sum to one. Their observed profiles coincide with the uniform profile:

\(A_q\mu^+=A_q\mu^-=A_q\bar\mu.\)

The uniform welfare for recommendation \(1\) is zero. Transferring mass \(\varepsilon\) from type zero to type \(e\) changes it by

\(\varepsilon(u_e-u_0)=\varepsilon(n+1)=\tfrac12.\)

Thus recommendation \(1\) has welfare \(-\tfrac12\) at \(\mu^-\), while recommendation \(-1\) has welfare \(-\tfrac12\) at \(\mu^+\). At their common observed profile, both recommendations therefore have worst-case utility at most \(-\tfrac12\). It follows that \(v(q)\le-\tfrac12\).

Finally, a cover using at most \(k\) sets yields a length-\(K\) sequence by querying those sets and repeating a selected comparison as necessary. Conversely, a length-\(K\) sequence reaching threshold zero must contain designated comparisons whose sets cover \(U\); it selects at most \(k\) such sets. Therefore

\(V\ge0\quad\Longleftrightarrow\quad U\text{ has a set cover using at most }k\text{ sets}.\)

This proves \(\mathrm{NP}\)-hardness and, together with membership, \(\mathrm{NP}\)-completeness.

4. Running times and tractable parameter regimes.

Let \(N=|C|=\binom I2\le\binom m2\).

Enumerating all sequences and solving the fixed-sequence linear program gives an exact deterministic running time of

\(N^K\operatorname{poly}(m,\tau,d,K,L)\subseteq m^{2K}\operatorname{poly}(m,\tau,d,K,L).\)

In particular, the problem is polynomial-time solvable for every fixed \(K\).

There is also an exact algorithm with running time

\(2^{O(\tau\log(\tau+1))}\operatorname{poly}(m,\tau,d,K,L).\)

Here is its justification. A sequence determines only a partition of \(T\) into equal-response cells. Appending a comparison refines that partition by splitting each cell according to its three possible responses.

Refinement cannot decrease the value. Indeed, any finer profile determines a coarser profile by summing cell masses. Its fiber is contained in the corresponding coarser fiber, so every recommendation’s worst-case utility can only increase. Taking the maximum over recommendations and then the minimum over finer profiles proves the claim.

Perform breadth-first search on partitions, starting from the single-cell partition. Each comparison gives a refinement transition. There are at most \(B_\tau\) states, where \(B_\tau\) is the Bell number and \(B_\tau\le\tau^\tau\). Breadth-first search finds the minimum number of comparisons realizing each partition. Evaluate the linear program for every partition at distance at most \(K\).

This gives the length-\(K\) optimum: a nonempty shorter sequence can be padded with repetitions without changing its partition. The empty sequence can be extended to length \(K\), and refinement ensures that its inclusion cannot increase the computed optimum beyond what length-\(K\) sequences attain. Thus at most \(B_\tau\) linear programs and \(B_\tau N\) refinement transitions suffice.

Finally, if \(K\ge\tau-1\), the problem is polynomial-time solvable. Process all comparisons, retaining a comparison only when it strictly refines the current partition. Each retained comparison increases the number of cells, so at most \(\tau-1\) are retained. A discarded comparison remains redundant under subsequent refinements; consequently the retained comparisons realize the partition induced by all comparisons. That partition dominates every other attainable partition, so evaluating it gives \(V\). Pad with repetitions to length \(K\). If none were retained, every comparison is constant across types, and any sequence already realizes this partition.
