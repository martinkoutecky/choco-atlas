Theorem 3 — class: hardness

The continuous mirror question, as graded

Given a finite type set \(T\), positive rational masses \(\mu_t\) summing to \(1\), rational internal opinions \(s_t\in[-1,1]\), a rational signed interaction kernel \(K_{tu}\), and a rational intervention share \(\beta\in[0,1]\), choose shielded masses \(x_t\) with \(0\le x_t\le\mu_t\) and \(\sum_t x_t=\beta\). For each type, let the expressed opinion of its unshielded mass satisfy \(y_t=[s_t+\sum_u K_{tu}(x_us_u+(\mu_u-x_u)y_u)]/[1+\sum_u\mu_u|K_{tu}|]\). Find \(x\) maximizing the population’s average expressed opinion \(\sum_t[x_ts_t+(\mu_t-x_t)y_t]\), with running time measured in the type count and input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) counts supported types, not all possible types.
Each type has a rational internal opinion \(s_t\in[-1,1]\). A directed signed interaction kernel has rational entries \(K_{tu}\in[-1,1]\), with no symmetry requirement; diagonal entries describe interactions within a type.
Given a rational intervention share \(\beta\in[0,1]\), choose real shielded masses \(x_t\in[0,\mu_t]\) satisfying \(\sum_t x_t=\beta\). Shielded individuals express \(s_t\) and remain influential on others.
For each feasible \(x\), define \(y\in[-1,1]^T\) as the unique solution of \(y_t=\frac{s_t+\sum_{u\in T}K_{tu}[x_us_u+(\mu_u-x_u)y_u]}{1+\sum_{u\in T}\mu_u|K_{tu}|}\). When \(x_t=\mu_t\), \(y_t\) is only an auxiliary variable.
The population average is \(F(x)=\sum_{t\in T}[x_ts_t+(\mu_t-x_t)y_t]\). The exact threshold problem asks, given a binary rational \(q\), whether some feasible \(x\) satisfies \(F(x)\ge q\).
Is this continuous shielding threshold problem in \(\mathrm{P}\), with running time polynomial in \(\tau\) and total input bit length \(L\), or is it \(\mathrm{NP}\)-hard? There is no separate \(m\) parameter in this model.
For finite directed signed networks, maximizing the equilibrium opinion sum by shielding exactly a prescribed number of individuals at their internal opinions is NP-hard ([source](https://www.ijcai.org/proceedings/2020/0174.pdf)).
No complexity classification for exactly this distribution-based mass-splitting problem was located in the literature search.

Modeling choices made when packaging the task

  • Restricted kernel entries to [-1,1], carrying over the discrete model's interaction-weight domain.
  • Allowed real shielded masses, since interventions split a continuous population rather than select indivisible agents.
  • Allowed diagonal kernel entries to represent interactions between individuals of the same type; a type is not a single individual.
  • Defined equilibrium variables for fully shielded types as auxiliary variables, so the displayed system remains defined while their unshielded contribution is zero.
  • Used an exact rational-threshold decision formulation to make the P-versus-NP-hard target precise without requiring a representation of potentially irrational optimizers.
  • Used support size and total binary input length as the size parameters; this model has no independent m parameter.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The continuous shielding threshold problem is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions. This holds even when every internal opinion is \(1\), every kernel entry is nonpositive, and all input numbers are dyadic rationals.

Consequently, an algorithm polynomial in \(\tau\) and \(L\) would imply \(\mathrm{P}=\mathrm{NP}\). The proof below directly handles arbitrary real mass splits; the [finite-network hardness result](https://www.ijcai.org/proceedings/2020/0174.pdf) provides background.

1. A quadratic characterization of clique number

Let \(A\) be the adjacency matrix of a nonempty simple undirected graph, and let \(\omega\) be its clique number. Define \(M_r=1-1/r\) for positive integers \(r\).

We will use the identity

\(\displaystyle \max_{\substack{p_i\ge 0\\ \sum_i p_i=1}}p^{\mathsf T}Ap=M_\omega.\)

Here is a proof. Suppose two nonadjacent vertices \(u,v\) both have positive weights. Holding their combined weight and all other weights fixed, the objective is affine in the weight assigned to \(u\): there are no diagonal terms and \(A_{uv}=0\). Moving their entire combined weight to one endpoint therefore does not decrease the objective and reduces its support.

Repeating this operation produces a vector supported on a clique of size \(r\le\omega\). On that support,

\(\displaystyle p^{\mathsf T}Ap=1-\sum_i p_i^2\le 1-\frac1r\le M_\omega,\)

where the first inequality follows from Cauchy–Schwarz. Uniform weights on a maximum clique attain \(M_\omega\), proving the identity.

By homogeneity, for any nonnegative vector \(w\) with total weight \(S\),

\(\displaystyle w^{\mathsf T}Aw\le S^2M_\omega.\)

This includes \(S=0\).

2. Construction of the society

We reduce from CLIQUE, restricted to instances with at least two vertices and target size \(k\) satisfying \(2\le k\le |V|\). This restriction remains \(\mathrm{NP}\)-complete because the excluded cases are immediately decidable.

Pad the graph with isolated vertices until its number \(n\) of vertices is a power of two. This increases its size by less than a factor of two and preserves its clique number. Write \(A\) for the padded graph’s adjacency matrix and \(\deg(i)\) for its degrees.

Construct \(n+1\) supported types, indexed by \(0,1,\ldots,n\). Set

\(\displaystyle W=\frac1{2n},\qquad \varepsilon=\frac1{4n},\qquad \mu_0=\frac12,\qquad \mu_i=W\quad(1\le i\le n).\)

These masses are positive and sum to one. Set every internal opinion to \(s_i=1\), and set the intervention share to

\(\displaystyle \beta=1-W.\)

For each graph vertex define

\(\displaystyle h_i=\frac{\varepsilon\bigl(n-1-\deg(i)\bigr)}n.\)

The kernel is

\(\displaystyle K_{00}=-1,\qquad K_{0j}=0\quad(1\le j\le n),\)

\(\displaystyle K_{i0}=-h_i,\qquad K_{ij}=-\varepsilon A_{ij}\quad(1\le i,j\le n).\)

Since \(0\le h_i\le\varepsilon\le1\), every kernel entry belongs to \([-1,1]\).

For every vertex type \(i\), its absolute interaction total is the same:

\(\displaystyle \sum_{u=0}^n\mu_u|K_{iu}|=\frac{h_i}{2}+\frac{\varepsilon\deg(i)}{2n}=\frac{\varepsilon(n-1)}{2n}=:D.\)

Define

\(\displaystyle d=1+D,\qquad c=\frac{2D}{d},\qquad a=\frac{\varepsilon}{d}.\)

The common value \(D\) is the purpose of the padding interactions with type \(0\).

3. Exact equilibrium identities

Write the unshielded masses as \(w_i=\mu_i-x_i\). Feasibility is equivalent to

\(\displaystyle 0\le w_i\le\mu_i,\qquad \sum_{i=0}^n w_i=W.\)

Write \(r_i=1-y_i\). Since every internal opinion is \(1\), the aggregate expressed mass of type \(i\) is

\(\displaystyle x_i+w_i y_i=\mu_i-w_i r_i,\)

and therefore

\(\displaystyle F=1-\sum_{i=0}^n w_i r_i.\)

For completeness, the equilibrium indeed lies in the prescribed cube. For any feasible shielding vector, the equilibrium update maps \([-1,1]^T\) into itself: each aggregate expressed mass has absolute value at most its type mass. If \(D_t=\sum_u\mu_u|K_{tu}|\), its Lipschitz constant in the supremum norm is at most

\(\displaystyle \max_t\frac{\sum_u w_u|K_{tu}|}{1+D_t}\le\max_t\frac{D_t}{1+D_t}\le\frac12.\)

The last inequality uses \(D_t\le\sum_u\mu_u=1\). Thus the contraction mapping theorem gives a unique equilibrium in the cube. In particular, \(r_i\ge0\).

Substituting \(\mu_u-w_u r_u\) into the equilibrium equations gives

\(\displaystyle (1+D_t)r_t=2D_t+\sum_u K_{tu}w_u r_u,\)

because all kernel entries are nonpositive.

For type \(0\), whose absolute interaction total is \(1/2\), this yields

\(\displaystyle r_0=\frac1{3/2+w_0}.\)

Consequently \(r_0\ge1/2\), since \(w_0\le\mu_0=1/2\).

For vertex types, the exact identities are

\(\displaystyle r_i=c-a\sum_{j=1}^n A_{ij}w_jr_j-\frac{h_i}{d}w_0r_0.\)

All subtracted terms are nonnegative, so

\(\displaystyle 0\le r_i\le c\qquad(1\le i\le n).\)

4. Bounds valid for arbitrary real mass splits

Define

\(\displaystyle B=1-cW,\qquad \lambda=acW^2>0,\qquad Q(w)=\sum_{i,j=1}^n A_{ij}w_iw_j.\)

We prove an upper bound for every feasible split and a matching lower bound up to a controlled error.

Upper bound

Let \(S=\sum_{i=1}^n w_i=W-w_0\). The exact equilibrium identities give

\(\displaystyle F=B+a\sum_{i,j=1}^n A_{ij}w_iw_jr_j+w_0\left(c-r_0+\frac{r_0}{d}\sum_{i=1}^n h_iw_i\right).\)

Using \(r_j\le c\) and \(h_i\le\varepsilon\), we obtain

\(\displaystyle F\le B+acQ(w)+w_0\bigl[c-r_0(1-aW)\bigr].\)

To verify the sign of the last term, set

\(\displaystyle H=8n^2+n-1.\)

Direct substitution gives

\(\displaystyle c=\frac{2(n-1)}H,\qquad a=\frac{2n}H,\qquad aW=\frac1H.\)

Also, \(D<\varepsilon/2\), so \(c<\varepsilon\le1/8\), while \(aW<1/(8n^2)\le1/32\). Hence

\(\displaystyle c-r_0(1-aW)\le\frac18-\frac12\left(1-\frac1{32}\right)<0.\)

The quadratic clique identity now implies

\(\displaystyle F\le B+acQ(w)\le B+acS^2M_\omega\le B+\lambda M_\omega.\)

This bound covers every feasible real vector, including those leaving type \(0\) partially unshielded.

Lower bound from a clique

Choose a maximum clique and assign unshielded mass \(W/\omega\) to each of its vertices, zero to all other vertex types, and \(w_0=0\). This is feasible because \(W/\omega\le W=\mu_i\). It satisfies

\(\displaystyle Q(w)=W^2M_\omega.\)

When \(w_0=0\), the equilibrium identities and \(r_j\le c\) give

\(\displaystyle r_i\ge c-ac\sum_j A_{ij}w_j\ge c(1-aW).\)

Consequently, for this explicit feasible split,

\(\displaystyle F=B+a\sum_{i,j}A_{ij}w_iw_jr_j\ge B+\lambda(1-aW)M_\omega\ge B+\lambda(M_\omega-aW).\)

The final inequality uses \(0\le M_\omega\le1\).

Thus we have proved:

  • Every feasible split satisfies \(F\le B+\lambda M_\omega\).
  • An explicit feasible split satisfies \(F\ge B+\lambda(M_\omega-aW)\).

5. A separating threshold

For the CLIQUE target \(k\), define

\(\displaystyle \Delta=M_k-M_{k-1}=\frac1{k(k-1)},\)

and the rational midpoint

\(\displaystyle q_* = B+\frac{\lambda}{2}(M_k+M_{k-1}).\)

Since \(k\le n\),

\(\displaystyle \Delta\ge\frac1{n^2},\qquad aW=\frac1H<\frac1{8n^2}\le\frac{\Delta}{8}.\)

If \(\omega\ge k\), the clique witness constructed above satisfies

\(\displaystyle F\ge B+\lambda(M_k-aW)=q_*+\lambda\left(\frac{\Delta}{2}-aW\right)>q_*.\)

If \(\omega\le k-1\), every feasible split satisfies

\(\displaystyle F\le B+\lambda M_{k-1}=q_*-\frac{\lambda\Delta}{2}.\)

We can make the input threshold dyadic while preserving this separation. Set

\(\displaystyle R=1024n^6,\qquad q=\frac{\lfloor Rq_*\rfloor}{R}.\)

Because \(n\) is a power of two, \(R\) is a power of two. Also,

\(\displaystyle \lambda=\frac{n-1}{nH^2}\ge\frac1{162n^4},\)

using \(n-1\ge n/2\) and \(H\le9n^2\). Therefore

\(\displaystyle \frac{\lambda\Delta}{2}\ge\frac1{324n^6}>\frac1R.\)

Rounding gives \(q_*-1/R<q\le q_*\). It follows that:

  • If \(\omega\ge k\), the explicit clique witness has \(F>q_*\ge q\).
  • If \(\omega\le k-1\), every feasible split has \(F\le q_*-\lambda\Delta/2<q\).

Thus the graph contains a clique of size at least \(k\) if and only if the constructed society admits a feasible shielding vector satisfying \(F\ge q\).

6. Polynomial encoding size

The constructed society has exactly \(\tau=n+1\) supported types. Since \(n\) is a power of two, all masses, kernel entries, internal opinions, the intervention share, and the rounded threshold are dyadic rationals.

Every entry has bit length \(O(\log n)\). The rational arithmetic used to compute \(q_*\) and its rounded threshold also involves only \(O(\log n)\)-bit integers. The complete society therefore has encoding length \(O(n^2\log n)\) and is constructible in polynomial time.

This completes the reduction and proves \(\mathrm{NP}\)-hardness for the exact continuous shielding threshold problem with the stated parameters \(\tau\) and \(L\).
