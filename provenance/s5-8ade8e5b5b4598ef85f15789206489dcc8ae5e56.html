The continuous mirror question, as graded

Given a finite set of complete workload types \(T\), rational masses \(\mu_t\geq 0\) with \(\sum_{t\in T}\mu_t=1\), normalized demands \(d_{tr}>0\), server classes \(q\), and rational per-capita capacities \(b_{qr}\) for each resource \(r\), find an optimal common global dominant share \(z\) and per-user class allocations \(x_{tq}\geq 0\). Maximize \(z\) subject to \(\sum_q x_{tq}=z\) for every type \(t\), and \(\sum_t \mu_t x_{tq}d_{tr}\leq b_{qr}\) for every class \(q\) and resource \(r\). Each type-\(t\) user receives \(x_{tq}d_{tr}\) of resource \(r\) from class \(q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq1\) workload types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) resources and \(k\geq1\) server classes. Each type has binary-rational normalized demands \(0<d_{tr}\leq1\), with \(\max_r d_{tr}=1\). Capacities \(b_{qr}\geq0\) are binary rationals, expressed in units with \(\sum_{q=1}^k b_{qr}=1\) for every resource.
Users have unlimited divisible workloads and equal entitlements. Classes aggregate interchangeable servers; there are no placement restrictions. A type receives the same per-user allocation throughout its mass.
Choose real \(z\geq0\) and \(x_{tq}\geq0\). A type-\(t\) user receives \(x_{tq}d_{tr}\) of resource \(r\) from class \(q\), and its global dominant share is \(\sum_q x_{tq}\).
Maximize \(z\) subject to \(\sum_q x_{tq}=z\) for every \(t\), and \(\sum_{t\in T}\mu_t x_{tq}d_{tr}\leq b_{qr}\) for every \(q,r\). Any optimal allocation may be returned. Let \(L\) be the total binary input length.

Can an exact optimum and allocation be computed in time polynomial in \(m,\tau,k,L\), or is deciding whether the optimum is at least an input binary-rational threshold \(h\geq0\) NP-hard?

For a finite list of users with positive demands and divisible workloads, optimal equal-global-dominant-share DRFH allocations are Pareto optimal. [Wang, Li, and Liang](https://arxiv.org/pdf/1308.0083)

Result

An exact optimum and an optimal allocation can be computed in time \(\operatorname{poly}(m,\tau,k,L)\). The threshold decision problem therefore belongs to \(\mathrm{P}\), and could be NP-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).

The support formulation is an explicitly described rational linear program. Small masses do not require expanding the society into individual users.

1. An equivalent linear program

For every listed type \(t\) and class \(q\), define the aggregate allocation variable \(y_{tq}=\mu_t x_{tq}\). Since every \(\mu_t\) is positive, this substitution is invertible, with \(x_{tq}=y_{tq}/\mu_t\).

The original problem is consequently equivalent to maximizing \(z\) subject to

\( \displaystyle \sum_{q=1}^{k}y_{tq}-\mu_t z=0 \qquad(t\in T), \)

\( \displaystyle \sum_{t\in T}d_{tr}y_{tq}\leq b_{qr} \qquad(q=1,\ldots,k,\ r=1,\ldots,m), \)

and \(z\geq0,\ y_{tq}\geq0\).

Indeed, multiplying each original type equality by \(\mu_t\) gives the first family, and substituting \(y_{tq}=\mu_t x_{tq}\) gives the capacity constraints. Conversely, division by \(\mu_t>0\) recovers every original constraint. The objective value is unchanged.

This program has \(N=1+\tau k\) variables, \(\tau\) equalities, and \(km\) capacity inequalities, together with nonnegativity constraints.

2. Feasibility and attainment of the optimum

Setting every variable to zero gives a feasible point.

To prove boundedness, sum all capacity inequalities over classes and resources. Every feasible point satisfies

\( \displaystyle \sum_{r=1}^{m}\sum_{q=1}^{k}\sum_{t\in T}d_{tr}y_{tq}\leq\sum_{r=1}^{m}\sum_{q=1}^{k}b_{qr}=m. \)

Reordering the finite sums and using the type equalities gives

\( \displaystyle z\sum_{t\in T}\mu_t\sum_{r=1}^{m}d_{tr}\leq m. \)

For each type, the normalization \(\max_r d_{tr}=1\) implies \(\sum_r d_{tr}\geq1\). Therefore

\( \displaystyle \sum_{t\in T}\mu_t\sum_{r=1}^{m}d_{tr}\geq\sum_{t\in T}\mu_t=1, \)

so \(0\leq z\leq m\). Nonnegativity and the type equalities also imply

\( \displaystyle 0\leq y_{tq}\leq\sum_{q'=1}^{k}y_{tq'}=\mu_t z\leq m. \)

Thus the feasible region is nonempty, closed, and bounded in finite-dimensional Euclidean space. It is compact, so the continuous objective \(z\) attains a finite maximum. This argument includes instances with zero capacities and optimum zero.

3. Polynomial encoding size and exact computation

Every coefficient in the transformed program is an input rational, its negative, or one of \(0,1,-1\). There are no products of input rationals in its constraint matrix.

Replacing each equality by two inequalities yields \(M=2\tau+km+N\) inequalities. Even a dense encoding has size

\( \displaystyle S=O\bigl((M+1)(N+1)(L+1)\bigr), \)

which is polynomial in \(m,\tau,k,L\). Constructing this encoding takes polynomial time.

We use the standard rational linear programming theorem: an explicitly encoded rational linear program can be solved in deterministic time polynomial in its binary encoding length; when its feasible region is nonempty and its optimum is finite, an exact rational optimal solution can be returned. Equalities and feasible regions of lower dimension are allowed. Polynomial-time feasibility and its reduction to optimization through primal-dual optimality are described in [MIT’s notes on the ellipsoid method](https://ocw.mit.edu/courses/6-251j-introduction-to-mathematical-programming-fall-2009/e13f5e6650f7be1e21101a2e7bd0d5b8_MIT6_251JF09_lec18.pdf).

All hypotheses hold here: the program is explicit and rational, its encoding size is polynomial, and Section 2 proves feasibility and a finite attained optimum. Applying the theorem returns \((z^\star,y^\star)\) exactly.

For completeness, exact output has polynomial encoding length. A linear objective on a nonempty compact polytope has an optimal vertex. At a vertex, one can select \(N\) linearly independent active constraints: otherwise a nonzero direction annihilating all active constraints would permit sufficiently small feasible perturbations in both directions, contradicting extremality. After clearing denominators, these constraints form an invertible integer system \(Av=a\) whose entries have \(O(S)\) bits. Cramer’s rule expresses every coordinate as a ratio of determinants. Hadamard’s inequality bounds those determinants by \(N^{N/2}2^{O(NS)}\), so their binary lengths are polynomial in \(N,S\).

Finally, return

\( \displaystyle x^\star_{tq}=\frac{y^\star_{tq}}{\mu_t}. \)

Exact rational division takes polynomial time and increases encoding length by at most a polynomial amount. Section 1 proves that these values constitute an optimal allocation for the original problem.

4. The threshold decision problem

Given a binary-rational threshold \(h\geq0\), add the inequality \(z\geq h\) to the transformed program.

If this augmented system is feasible, then \(z^\star\geq h\). Conversely, if \(z^\star\geq h\), the attained optimal solution is feasible for the augmented system. Exact rational LP feasibility therefore decides the threshold question in time polynomial in the society’s input length and the encoding length of \(h\).

The stated Pareto-optimality result is not needed for this computational conclusion.
