The continuous mirror question, as graded

Given a finite bundle set \(X=\prod_{j=1}^{m}\{0,\ldots,b_j\}\), a rational distribution \(\mu\) over valuation types \(t\), and per-capita supplies \(q_j\), can an algorithm find an exactly welfare-maximizing allocation using polynomially many demand-and-value queries? Each query gives a type \(t\) a rational price vector \(p\ge 0\) and returns \(x_t(p)\in\arg\max_{x\in X}\{v_t(x)-p\cdot x\}\) and \(v_t(x_t(p))\). The allocation variables \(y_{t,x}\ge 0\) must satisfy \(\sum_x y_{t,x}=\mu_t\) and \(\sum_{t,x}y_{t,x}x_j\le q_j\) for each resource \(j\); welfare is \(\sum_{t,x}y_{t,x}v_t(x)\). Bound the query count and running time in \(m\), the support size, and the binary input length, apart from oracle evaluation.

Packaged proof task (what the prover saw — nothing else)

Let \(m\ge1\), \(b_j\in\mathbb Z_{>0}\), and \(X=\prod_{j=1}^m\{0,\ldots,b_j\}\), with capacities encoded in binary and supplies \(q_j\in\mathbb Q_{\ge0}\).
A society is given by its support: a list of \(\tau\ge1\) valuation types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Each type has an unknown coordinatewise nondecreasing valuation \(v_t:X\to\mathbb Q_{\ge0}\) with \(v_t(0)=0\). A supplied bound \(B\) limits the binary encoding length of every valuation value; \(L\) is the explicit input length, including this bound, without a valuation table.
The only valuation access is a truthful oracle: for a chosen type \(t\) and rational \(p\in\mathbb Q_{\ge0}^m\), it returns \(x_t(p)\in\arg\max_{x\in X}\{v_t(x)-p\cdot x\}\) and \(v_t(x_t(p))\); ties may be resolved arbitrarily.
An allocation consists of masses \(y_{t,x}\ge0\) satisfying \(\sum_x y_{t,x}=\mu_t\) and \(\sum_{t,x}y_{t,x}x_j\le q_j\). Its welfare is \(\sum_{t,x}y_{t,x}v_t(x)\); allocations are represented by their nonzero entries.

Can an exactly welfare-maximizing allocation always be found using polynomially many oracle queries and polynomial running time in \(m,\tau,L,B\), excluding oracle evaluation, or is such a guarantee impossible?

For finite bidders receiving integral bundles, demand queries can fail to achieve welfare above \(\tfrac12+\epsilon\) of optimum, for every \(\epsilon>0\), even with arbitrarily many queries and values reported for demanded bundles.
For single-copy items with unit bidder and item bounds, exact fractional welfare optimization through demand oracles is known ([Feige–Vondrák](https://theory.stanford.edu/~jvondrak/data/submod-improve-ToC.pdf)); this does not explicitly cover binary-encoded multiset capacities and rational type masses.

Modeling choices made when packaging the task

  • Restored the valuation assumptions: nonnegative, coordinatewise nondecreasing, and zero at the empty bundle.
  • Normalized positive type masses to sum to one, consistent with a distribution and per-capita supplies.
  • Specified positive integer bundle capacities encoded in binary and nonnegative rational supplies.
  • Restricted valuations to rational values and introduced a supplied encoding-length bound B so exact oracle computation has a defined bit-complexity parameter.
  • Allowed arbitrary demand tie-breaking, as the demand definition permits any maximizing bundle.
  • Specified allocation representation by nonzero entries to avoid requiring an exponentially long dense output.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

An exact polynomial-time guarantee is possible. There is an algorithm using polynomially many demand queries and polynomial running time in \(m,\tau,L,B\), excluding oracle evaluation. It can return an optimal allocation with at most \(m+\tau\) nonzero entries.

The proof requires both separation of the welfare LP’s dual and recovery of an allocation from that separation oracle.

1. The welfare LP and its dual. Let \(W^\star\) denote the optimal welfare. The allocation problem is the finite linear program

\( \displaystyle \max_{y\ge 0}\ \sum_{t=1}^{\tau}\sum_{x\in X}v_t(x)y_{t,x}, \)

subject to

\( \displaystyle \sum_{x\in X}y_{t,x}=\mu_t\quad(t=1,\ldots,\tau), \qquad \sum_{t,x}x_jy_{t,x}\le q_j\quad(j=1,\ldots,m). \)

It is feasible: assign every type its entire mass at the zero bundle. Its feasible region is compact, since it has finitely many variables and \(0\le y_{t,x}\le\mu_t\). Consequently, its optimum exists.

Introduce resource prices \(p_j\ge0\) and unrestricted variables \(u_t\) for the type equalities. The dual is

\( \displaystyle \min_{p,u}\ \sum_{j=1}^{m}q_jp_j+\sum_{t=1}^{\tau}\mu_tu_t \)

subject to

\( \displaystyle p_j\ge0, \qquad u_t+p\cdot x\ge v_t(x)\quad(t=1,\ldots,\tau,\ x\in X). \)

The constraint for \(x=0\) is \(u_t\ge0\), because \(v_t(0)=0\). Thus every dual feasible point has \(p,u\ge0\). Let \(K\subseteq\mathbb R^{m+\tau}\) be this dual feasible region. Finite-dimensional LP strong duality gives

\( \displaystyle W^\star=\min_{(p,u)\in K}\bigl(q\cdot p+\mu\cdot u\bigr). \)

2. Demand queries provide exact separation. Given a rational candidate \((p,u)\), first check nonnegativity. If some \(p_j<0\), return the violated constraint \(p_j\ge0\). If some \(u_t<0\), return the zero-bundle constraint \(u_t\ge0\).

Otherwise, query each type at the nonnegative price vector \(p\). Write its answer as \(x_t\), with reported value \(v_t(x_t)\). Truthfulness implies

\( \displaystyle v_t(x_t)-p\cdot x_t = \max_{x\in X}\bigl(v_t(x)-p\cdot x\bigr). \)

If \(u_t+p\cdot x_t<v_t(x_t)\), return that violated dual constraint. If this never occurs, then for every type and every bundle,

\( \displaystyle v_t(x)-p\cdot x \le v_t(x_t)-p\cdot x_t \le u_t. \)

Hence the candidate belongs to \(K\). This is an exact strong separation oracle using at most \(\tau\) demand queries per call.

Arbitrary tie-breaking causes no difficulty: every maximizing bundle has the same utility, so every truthful answer supports the preceding comparison.

3. The exact oracle-LP theorem used for recovery. We use the following form of the rational ellipsoid theorem.

Suppose a rational polyhedron \(K\subseteq\mathbb R^d\) has a known bound \(\phi\) on the encoding length of each inequality in some description. Suppose its strong separation oracle returns normals of encoding length at most \(\phi\). For a rational objective whose minimum exists, an oracle-polynomial-time algorithm finds an optimal dual certificate supported on at most \(d\) oracle normals. The corresponding right-hand sides are their tight supporting bounds over \(K\). This is Grötschel–Lovász–Schrijver, Lemma 6.5.15, with signs reversed for minimization. [*Geometric Algorithms and Combinatorial Optimization*, second edition](https://link.springer.com/book/10.1007/978-3-642-78240-4).

Explicitly, if those supporting inequalities are \(a_i\cdot z\ge\beta_i\), the algorithm finds nonnegative rational multipliers \(\lambda_i\) satisfying

\( \displaystyle \sum_i\lambda_i a_i=c, \qquad \sum_i\lambda_i\beta_i=\min_{z\in K}c\cdot z, \)

where \(c\) is the objective vector. The positively weighted normals are linearly independent, giving the bound \(d\).

For our application, we must verify that the tight supporting bounds are the actual valuation values reported by the oracle.

Set \(V=2^B\), an upper bound on every valuation value under the usual binary encoding of rational numerators and denominators.

Every inequality returned by our separator is tight somewhere on \(K\):

  • For \(p_j\ge0\), use \(p=0\) and \(u_t=V\) for every type.
  • For \(u_t\ge0\), use \(p_j=V+1\) for every coordinate and \(u=0\). Indeed, any nonzero integral bundle satisfies \(p\cdot x\ge V+1>v_t(x)\), while the zero bundle gives equality.
  • For a demanded-bundle inequality \(u_t+p\cdot x_t\ge v_t(x_t)\), let \(p^0\) be the price vector at which that bundle was returned, and define

\( \displaystyle u_s^0=\max_{x\in X}\bigl(v_s(x)-p^0\cdot x\bigr) \)
for every type \(s\). Then \((p^0,u^0)\in K\), and demand optimality gives equality in the returned inequality.

Thus the theorem’s tight bounds coincide exactly with the known right-hand sides. This verifies the recovery step without assuming that arbitrary cuts collected during an optimization run preserve the optimum.

4. The certificate is an optimal allocation. Apply the theorem with

\( \displaystyle d=m+\tau,\qquad z=(p,u),\qquad c=(q,\mu). \)

For a valuation inequality indexed by \((t,x)\), its normal is \((x,e_t)\) and its right-hand side is \(v_t(x)\). Interpret its certificate multiplier as \(y_{t,x}\). Interpret a multiplier on \(u_t\ge0\) as mass \(y_{t,0}\), combining duplicate entries if necessary.

A resource inequality \(p_j\ge0\) has normal \((e_j,0)\) and right-hand side zero. Denote its multiplier by \(s_j\).

The certificate identity \(\sum_i\lambda_i a_i=c\) now says precisely

\( \displaystyle \sum_x y_{t,x}=\mu_t, \qquad \sum_{t,x}x_jy_{t,x}+s_j=q_j. \)

All multipliers are nonnegative, so these equations give a feasible allocation. Its welfare is

\( \displaystyle \sum_{t,x}y_{t,x}v_t(x) = \sum_i\lambda_i\beta_i = \min_{z\in K}c\cdot z = W^\star. \)

It is therefore exactly optimal. Since the certificate has at most \(d\) positive multipliers in total, the allocation has at most \(m+\tau\) nonzero entries.

5. Encoding length and running time. Every hypothesis needed for oracle-polynomial time holds with polynomial bounds.

First, a bundle requires only

\( \displaystyle O\!\left(\sum_{j=1}^{m}\log(b_j+1)\right) \)

bits. Every dual inequality has integer coefficients consisting of bundle coordinates and unit-vector entries, together with a valuation value of encoding length at most \(B\). Hence the description-length bound \(\phi\) is polynomial in \(m,\tau,L,B\), independently of the number of bundles.

Second, the objective vector \((q,\mu)\) is explicitly encoded in the input. The dual is feasible, for example at \((p,u)=(0,V\mathbf1)\), and its objective is bounded below by zero. Its minimum exists by the strong-duality argument above. Zero supplies are therefore included.

For completeness, the output masses also admit a direct polynomial bit bound. Put \(C=\max_j b_j\), and let \(D\) be the product of the denominators of all explicitly given supplies and masses. Then \(\log D\le L\), up to encoding conventions. A basic certificate uses \(k\le d\) linearly independent integral normals with entries bounded by \(C\). Selecting \(k\) independent coordinate equations gives a nonsingular integer matrix \(M\). Cramer’s rule shows that each multiplier’s denominator divides \(D|\det M|\), while

\( \displaystyle 1\le|\det M|\le k!C^k\le d!C^d. \)

The same determinant estimates bound numerator lengths polynomially in \(L,d,\log C\). Thus the sparse allocation has polynomial encoding length.

The oracle-LP theorem makes polynomially many separation calls, with rational query points of polynomial encoding length. Each call uses at most \(\tau\) demand queries and polynomial exact arithmetic. This establishes both requested polynomial bounds.

6. Relation to the stated integral obstruction. The allocation variables here are divisible masses. The obstruction for finite bidders receiving integral allocations concerns a different feasible set and does not prevent exact optimization of this fractional LP. The demand-oracle solution of the single-copy configuration LP noted by [Feige–Vondrák](https://theory.stanford.edu/~jvondrak/data/submod-improve-ToC.pdf) follows the same dual-separation principle; the encoding and certificate arguments above establish its extension to the capacities and masses in this question.
