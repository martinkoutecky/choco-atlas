The continuous mirror question, as graded

Given a fixed-width canonized DAG-network \(D\) with rational arc costs and a rational mass distribution \(\mu\) over its occupied-node types \(T\), compute an exact description of the stable cost-rate polytope \(\mathcal C_\mu(D)=\{q\in\mathbb R_{\ge 0}^{T}:\sum_{p\in T}\mu_pq_p=c_D(T),\ \sum_{p\in S}\mu_pq_p\le c_D(S)\ \forall S\subseteq T\}\), where \(c_D(S)\) is the cheapest-trunk cost for connecting the types in \(S\) to the root.

Packaged proof task (what the prover saw — nothing else)

Let \(D=(V,A,r,\delta)\) be an explicitly given simple DAG with \(m=|V|\), root \(r\), a directed path from every other node to \(r\), and nonnegative binary rational arc costs \(\delta\).
A society is given by its support: a nonempty list \(T\subseteq V\) of the \(\tau\) occupied-node types, each with positive binary rational mass \(\mu_p\), with \(\sum_{p\in T}\mu_p=1\). Here \(\tau=|T|\) is the support size, not the number of possible types; \(L\) is the total input bit length.
Canonical form means that every node with multiple outgoing arcs has a zero-cost outgoing arc, and every node with exactly one outgoing arc belongs to \(T\) and its outgoing arc has positive cost.
Let \(H\) contain all minimum-cost outgoing arcs at every nonroot node. The width \(k\) is the maximum size of a set of nodes pairwise incomparable under reachability in \(H\); \(k\) is fixed.
A trunk is a union of directed paths ending at \(r\). For \(S\subseteq T\), let \(c_D(S)\) be the minimum total arc cost of a trunk containing every node in \(S\), with \(c_D(\varnothing)=0\). All nodes are available for use, regardless of occupancy; tied minimum trunks have the same cost.
Define \(\mathcal C_\mu(D)=\{q\in\mathbb R_{\ge0}^{T}:\sum_{p\in T}\mu_pq_p=c_D(T),\ \sum_{p\in S}\mu_pq_p\le c_D(S)\text{ for every }S\subseteq T\}\). An exact description means a finite system of rational linear equalities and inequalities in the coordinates \(q\), defining precisely this polytope; redundant constraints are allowed.
Is computing an exact description of \(\mathcal C_\mu(D)\) polynomial-time solvable in \(m,\tau,L\) for every fixed \(k\), or is it NP-hard for some fixed \(k\)?
For finite players on fixed-width canonical networks, the core admits a polynomial-time description and the nucleolus is polynomial-time computable. [Sziklai, Fleiner and Solymosi](https://real.mtak.hu/39797/1/DAG_MP_rev2.pdf).

Result and interpretation

For the intended class of canonical networks, computing an exact description is polynomial-time solvable for every fixed \(k\).

The proof reduces the stated polytope to a finite-player core with exactly \(m\) players. It does not expand rational masses into populations.

1. Canonical form determines the grand-coalition cost

Extend the trunk-cost definition to every \(U\subseteq V\): let \(\widehat c(U)\) be the minimum cost of a trunk containing \(U\), with \(\widehat c(\varnothing)=0\). Thus \(\widehat c(S)=c_D(S)\) whenever \(S\subseteq T\).

This function is monotone: if \(U\subseteq W\), every trunk containing \(W\) also contains \(U\), so \(\widehat c(U)\leq\widehat c(W)\).

Let \(P\) be the set of nodes with exactly one outgoing arc. For \(v\in P\), denote that arc by \(a_v\), and put

\[ B=\sum_{v\in P}\delta(a_v). \]

By canonical form, \(P\subseteq T\). Every trunk containing \(T\) must therefore contain every \(a_v\): a path from \(v\) to \(r\) has no other first arc. Nonnegative costs give \(c_D(T)\geq B\).

Conversely, \(H\) contains an outgoing arc at every nonroot node. Following such arcs must reach \(r\), because the graph is finite and acyclic. Hence \(H\) is a trunk containing all of \(V\).

At a node with multiple outgoing arcs, all minimum-cost outgoing arcs have cost zero. At a node in \(P\), \(H\) contains its unique outgoing arc. Consequently, the total cost of \(H\) is exactly \(B\). Monotonicity now yields

\[ B\leq c_D(T)\leq\widehat c(V)\leq B. \]

Thus \(c_D(T)=\widehat c(V)=B\).

2. An equivalent finite-player core

Place one finite player at each node of \(V\), including unoccupied nodes. The player at \(v\) resides at \(v\), and the coalition-cost function is \(\widehat c\). Write its ordinary cost-game core as

\[ K=\left\{x\in\mathbb R^V: \sum_{v\in V}x_v=B,\quad \sum_{v\in U}x_v\leq\widehat c(U) \text{ for every }U\subseteq V \right\}. \]

Define a linear map \(F:\mathbb R^T\longrightarrow\mathbb R^V\) by

\[ F(q)_v= \begin{cases} \mu_vq_v,&v\in T,\\ 0,&v\notin T. \end{cases} \]

We claim that

\[ q\in\mathcal C_\mu(D) \quad\Longleftrightarrow\quad q\in\mathbb R_{\geq0}^T\text{ and }F(q)\in K. \]

Forward implication. Let \(q\in\mathcal C_\mu(D)\). The efficiency equation and Section 1 give \(\sum_{v\in V}F(q)_v=B\). For any \(U\subseteq V\), put \(S=U\cap T\). Then

\[ \sum_{v\in U}F(q)_v =\sum_{p\in S}\mu_pq_p \leq c_D(S) =\widehat c(S) \leq\widehat c(U). \]

Therefore \(F(q)\in K\).

Reverse implication. Suppose \(q\geq0\) and \(F(q)\in K\). Its efficiency equation gives \(\sum_{p\in T}\mu_pq_p=B=c_D(T)\). Applying its coalition inequality to each \(S\subseteq T\) gives

\[ \sum_{p\in S}\mu_pq_p \leq\widehat c(S)=c_D(S). \]

These are precisely the defining conditions of \(\mathcal C_\mu(D)\).

3. Applying the finite-player theorem

Use the finite-player core-description result supplied in the question: a canonical DAG network of fixed width admits a polynomial-time explicit linear description of its core. In the paper, the reachability order defining width uses the minimum-cost outgoing arcs; therefore its width agrees with the width of \(H\) here. See [Sziklai–Fleiner–Solymosi, Section 5 and Theorem 6](https://real.mtak.hu/39797/1/DAG_MP_rev2.pdf).

All hypotheses hold for the finite game constructed above:

  • The underlying simple DAG, root, and costs are unchanged.
  • Every node with multiple outgoing arcs has a zero-cost outgoing arc.
  • Every node with one outgoing arc has positive outgoing cost and now has a resident.
  • The minimum-arc graph remains \(H\), with width \(k\).
  • There are exactly \(m\) finite players.

The paper’s construction uses polynomially many coalition inequalities or trunk-cost bounds. Their coefficient vectors are coalition incidence vectors, and their right-hand sides are sums of input arc costs. This also gives the binary rational version: a common denominator can be taken as the product of the input denominators, whose bit length is at most their total input bit length. Every trunk-cost sum therefore has polynomial bit length.

Consequently, for fixed \(k\), the finite description can be computed with polynomial output size and polynomial bit complexity.

4. Producing the required description

Compute a description of \(K\). In every row, substitute

\[ x_v=\mu_vq_v\quad(v\in T), \qquad x_v=0\quad(v\notin T), \]

and append \(q_p\geq0\) for every \(p\in T\).

For example, a finite-core inequality \(\sum_{v\in V}a_vx_v\leq b\) becomes

\[ \sum_{p\in T}a_p\mu_pq_p\leq b. \]

By Section 2, the resulting system defines exactly \(\mathcal C_\mu(D)\). It contains only the requested coordinates \(q\); no auxiliary variables or projection are needed.

The substitution requires polynomially many rational multiplications. Multiplying a finite-description coefficient by an input mass increases its bit length by at most the bit length of that mass, up to a constant. Thus the complete procedure runs in polynomial time in \(m,\tau,L\) for every fixed \(k\).

The normalization of the masses creates no additional computational difficulty: their role is a positive diagonal change of coordinates on the occupied nodes.
