The continuous mirror question, as graded

Given a finite type set \(T\) with masses \(\mu_t\ge0\) and \(\sum_{t\in T}\mu_t=1\), finite item species \(J\), per-capita supplies \(0\le q_j\le1\), and additive values \(v_{tj}\ge0\), choose masses \(y_{t,S}\ge0\) of type-\(t\) agents receiving integral bundles \(S\subseteq J\), satisfying \(\sum_S y_{t,S}=\mu_t\) and \(\sum_{t,S:j\in S}y_{t,S}=q_j\), to maximize \(\exp\!\left(\sum_{t,S}y_{t,S}\log\!\left(\sum_{j\in S}v_{tj}\right)\right)\), with \(\log 0=-\infty\), or compute an \(\alpha\)-approximation.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. There are \(m\ge1\) item species \(J\), binary-rational supplies \(q_j\in[0,1]\) with \(\sum_jq_j\ge1\), and binary-rational additive values \(v_{tj}\ge0\). Let \(L\) be the total input bit length.
Each agent receives an integral bundle \(S\subseteq J\), containing at most one copy of each species. An allocation specifies masses \(y_{t,S}\ge0\) satisfying \(\sum_{S\subseteq J}y_{t,S}=\mu_t\) and \(\sum_{t,S:j\in S}y_{t,S}=q_j\).
Its welfare is \(W(y)=\exp\bigl(\sum_{t,S:y_{t,S}>0}y_{t,S}\log(\sum_{j\in S}v_{tj})\bigr)\), with \(\log0=-\infty\) and \(\exp(-\infty)=0\). Write \(W^*=\max_yW(y)\); an \(\alpha\)-approximation returns a feasible allocation with \(W(y)\ge W^*/\alpha\), including when \(W^*=0\).

Can this problem be approximated within some constant \(1\le\alpha<\sqrt{8/7}\) in time polynomial in \(m,\tau,L\), or is a \((\sqrt{8/7}-\delta)\)-approximation NP-hard for every fixed \(0<\delta<\sqrt{8/7}-1\)?

For finite agents and indivisible items with additive values, a \((\sqrt{8/7}-\delta)\)-approximation is impossible unless \(\mathrm{P}=\mathrm{NP}\), for every fixed \(0<\delta<\sqrt{8/7}-1\) ([Garg–Hoefer–Mehlhorn](https://arxiv.org/abs/1707.04428v3)).
A related logarithmic configuration LP, with each agent's bundle probabilities summing to \(1\) and each item's total allocation at most \(1\), can be solved to additive error \(\log(1+\varepsilon)\) in polynomial time in its input size and \(1/\varepsilon\) ([Feng–Li](https://drops.dagstuhl.de/doi/10.4230/LIPIcs.ICALP.2024.63)); this result is stated for different supply and agent-mass constraints.

Modeling choices made when packaging the task

  • The graded question did not specify encodings for supplies or values; both are nonnegative binary rationals, and L is the total input bit length.
  • The discrete definition assumes at least as many items as agents; its per-capita counterpart is sum_j q_j >= 1, rather than a comparison between m and the support size.
  • Zero-mass types are omitted from the support, and zero allocation coordinates contribute nothing to the logarithmic objective; positive mass receiving zero utility makes welfare zero.
  • The unspecified approximation convention is multiplicative maximization: welfare at least the optimum divided by alpha.
  • The anchor's approximation threshold is used as the target, with delta restricted so that the approximation factor exceeds one.

Result

The problem admits a deterministic \((1+\varepsilon)\)-approximation scheme, running in time polynomial in \(m,\tau,L,1/\varepsilon\) and the encoding length of \(\varepsilon\), for every rational \(0<\varepsilon\le1\).

In particular, choosing \(\varepsilon=1/20\) gives the constant approximation factor \(\alpha=21/20<\sqrt{8/7}\), because \(7\cdot21^2=3087<3200=8\cdot20^2\).

The proof below constructs a polynomial-size rational linear program. Its constraints preserve the masses and supplies exactly; only its objective is approximated.

1. Positive welfare and the zero-welfare case

Write \(u_t(S)=\sum_{j\in S}v_{tj}\). Call an allocation positive if every pair \((t,S)\) with \(y_{t,S}>0\) satisfies \(u_t(S)>0\).

An allocation has positive welfare exactly when it is positive. Consequently, if no positive allocation exists, then \(W^*=0\).

A feasible allocation always exists and can be represented with polynomially many nonzero entries. To see this, list the distinct elements of \(\{0,1\}\cup\{q_j:j\in J\}\) in increasing order as \(0=b_0<b_1<\cdots<b_r=1\). For each interval, define \(S_\ell=\{j:q_j\ge b_\ell\}\), and assign mass \(\mu_t(b_\ell-b_{\ell-1})\) of type \(t\) to \(S_\ell\).

The type masses sum correctly. Species \(j\) belongs precisely to the intervals below \(q_j\), so its total allocated mass is \(q_j\sum_t\mu_t=q_j\). This allocation has at most \(\tau(m+1)\) nonzero entries.

Thus, once we can determine whether a positive allocation exists, the zero-welfare case is completely handled.

If positive allocations exist, their feasible set is a nonempty compact polytope: take the original allocation constraints and set every zero-utility coordinate to zero. On this polytope,

\(H(y)=\sum_{t,S:u_t(S)>0}y_{t,S}\log u_t(S)\)

is a finite linear function. Therefore it attains a maximum \(H^*\), and \(W^*=\exp(H^*)\).

2. A polynomial-size representation of rounded bundle utilities

Fix a rational \(0<\varepsilon\le1\), and set

\(\eta=\varepsilon/(4m)\), \(\quad r=1+\eta\), \(\quad\theta=\varepsilon/8\).

If some type values every species at zero, its positive mass forces \(W^*=0\), so return the feasible allocation from Section 1. Henceforth every type has at least one positive value.

For each type \(t\), define

\(a_t=\min\{v_{tj}:v_{tj}>0\}\), \(\quad B_t=\sum_{j=1}^m v_{tj}\).

Use the geometric utility grid

\(\mathcal G_t=\{a_t r^k:0\le k\le K_t\}\),

where \(K_t\) is the largest integer satisfying \(a_t r^{K_t}\le B_t\). For \(a_t\le x\le B_t\), let \(R_t(x)\) be the largest grid element at most \(x\). Also set \(R_t(0)=0\). By construction,

\(x/r\le R_t(x)\le x\).

Indeed, the next grid element after \(R_t(x)\) exceeds \(x\); this also holds at the last grid element because \(a_t r^{K_t+1}>B_t\).

Process species in the fixed order \(1,\ldots,m\). For a bundle \(S\), start with \(z_0=0\) and update as follows:

  • If \(k\notin S\), set \(z_k=z_{k-1}\).
  • If \(k\in S\), set \(z_k=R_t(z_{k-1}+v_{tk})\).

The updates are well-defined. Whenever their argument is positive, it is at least \(a_t\). The following induction also shows that their argument never exceeds \(B_t\).

Rounding lemma. With \(U_k=\sum_{j\in S,\ j\le k}v_{tj}\), every prefix satisfies

\(r^{-k}U_k\le z_k\le U_k\).

Proof. The statement holds at \(k=0\). If species \(k\) is skipped, the previous lower bound implies \(z_k\ge r^{-k}U_k\), and the upper bound is unchanged.

If species \(k\) is taken, write \(v=v_{tk}\). The previous upper bound gives \(z_{k-1}+v\le U_{k-1}+v=U_k\le B_t\). When this sum is zero, the claim is immediate. Otherwise, the rounding inequality gives

\(z_k\ge(z_{k-1}+v)/r\ge r^{-k}U_{k-1}+v/r\ge r^{-k}(U_{k-1}+v)\),

where the last inequality uses \(k\ge1\), \(r>1\), and \(v\ge0\). Also \(z_k\le z_{k-1}+v\le U_k\). This completes the induction.

Let \(z_t(S)=z_m\). For every positive-utility bundle, the lemma yields

\(\log u_t(S)-m\log r\le\log z_t(S)\le\log u_t(S)\).

It also shows that \(z_t(S)>0\) exactly when \(u_t(S)>0\).

3. A flow linear program with exact allocation constraints

For each type \(t\), construct a layered directed multigraph.

Its source is state \(0\) at layer \(0\). At layer \(k\), a node records the rounded utility after processing the first \(k\) species. From each reachable node at layer \(k-1\), add two arcs:

  • A skip arc, leaving the utility state unchanged.
  • A take arc, updating the state by \(R_t(z+v_{tk})\), labelled with species \(k\).

Keep the arcs distinct even if they have the same endpoints. The rounding lemma guarantees that all reachable updates are well-defined.

At layer \(m\), connect each positive state to a sink. Do not connect state \(0\) to the sink.

A source-to-sink path selects a subset of species, with each species considered exactly once. It therefore represents an integral bundle with positive utility. Conversely, every positive-utility bundle defines such a path.

Introduce nonnegative arc flows \(f_{t,e}\), with the following constraints:

  • The source sends flow \(\mu_t\), the sink receives flow \(\mu_t\), and every other node satisfies flow conservation.
  • For each species \(j\), the total flow on take arcs labelled \(j\), summed over all type graphs, equals \(q_j\).

These are rational linear constraints.

Exact correspondence. These constraints are feasible if and only if a positive allocation exists.

To prove the forward direction, decompose each type’s flow into source-to-sink paths. The graphs are acyclic, so this is done by repeatedly choosing a path of positive-flow arcs and subtracting their minimum flow. Each subtraction eliminates at least one positive-flow arc. Thus the number of resulting paths is at most the number of arcs.

Assign each path’s mass to its associated bundle. The source-flow constraints give the required type masses, and the take-arc constraints give the required species supplies. Every path terminates at a positive utility state.

For the reverse direction, route each mass \(y_{t,S}\) of a positive allocation along the path associated with \(S\). This satisfies every flow and supply constraint.

Accordingly, infeasibility of this LP proves \(W^*=0\). Otherwise, its flows produce exactly feasible positive allocations.

4. Optimizing the rounded objective

Let \(h_{t,g}(f)\) denote the terminal flow from positive state \(g\). Define

\(Q(f)=\sum_{t,g}h_{t,g}(f)\log g\).

For any allocation \(y\) obtained by decomposing \(f\), the rounding lemma and the identity \(\sum_{t,S}y_{t,S}=1\) give

\(H(y)-m\log r\le Q(f)\le H(y)\).

To obtain a rational LP, compute rational coefficients \(c_{t,g}\) satisfying

\(|c_{t,g}-\log g|\le\theta\),

and maximize the rational objective

\(C(f)=\sum_{t,g}h_{t,g}(f)c_{t,g}\)

subject to the exact flow constraints. Terminal flow sums to \(\sum_t\mu_t=1\), so every feasible flow satisfies

\(|C(f)-Q(f)|\le\theta\).

Let \(\widehat f\) maximize \(C\), and decompose it to obtain \(\widehat y\). Let \(y^*\) maximize the original finite logarithmic objective, and route it to a flow \(f^*\). Then

\(H(\widehat y)\ge Q(\widehat f)\ge C(\widehat f)-\theta\ge C(f^*)-\theta\ge Q(f^*)-2\theta\ge H^*-m\log r-2\theta\).

Every inequality has a specified justification: respectively, the rounding bound, coefficient accuracy, optimality of \(\widehat f\), coefficient accuracy again, and the rounding bound applied to \(y^*\).

Since \(\log(1+\eta)\le\eta\),

\(m\log r+2\theta\le m\eta+2\theta=\varepsilon/2\).

Furthermore, for \(0<\varepsilon\le1\),

\(\log(1+\varepsilon)=\int_0^\varepsilon(1+x)^{-1}\,dx\ge\varepsilon/2\).

Consequently,

\(H(\widehat y)\ge H^*-\log(1+\varepsilon)\),

and exponentiating gives

\(W(\widehat y)\ge W^*/(1+\varepsilon)\).

If the flow constraints are infeasible, the allocation from Section 1 instead satisfies the approximation requirement because \(W^*=0\).

5. Polynomial running time and output length

It remains to check the binary encoding and running time.

Number of states. Every positive input value lies between \(2^{-L}\) and \(2^L\). Hence \(B_t/a_t\le m2^{2L}\). Since \(0<\eta\le1\), the integral formula for the logarithm gives \(\log(1+\eta)\ge\eta/2\). Therefore

\(K_t+1\le1+2\log(B_t/a_t)/\eta=O\bigl(m(L+\log m)/\varepsilon\bigr)\).

Each type graph has at most \(1+m(K_t+2)\) nodes and \(O(m(K_t+2))\) arcs. Thus the total graph size is polynomial in the asserted parameters.

Rational grid computation. Each grid value is \(a_t r^k\). Its numerator and denominator have bit lengths bounded by the bit length of \(a_t\) plus \(k\) times the bit length of \(r\). These lengths are polynomial. Grid generation, comparisons, and transition construction therefore use polynomially many operations on rationals of polynomial bit length.

Logarithmic coefficients. The required rational approximations can also be computed in polynomial time. For completeness, normalize a positive rational grid value as \(g=2^h x\), with \(1\le x<2\). Then

\(\log g=h\log2+\log x\).

For \(w=(x-1)/(x+1)\), one has \(0\le w<1/3\) and

\(\log x=2\sum_{\ell=0}^{N-1}w^{2\ell+1}/(2\ell+1)+E_N\),

with

\(0\le E_N\le2w^{2N+1}/((2N+1)(1-w^2))\le(9/4)3^{-(2N+1)}\).

The same expansion computes \(\log2\), using \(w=1/3\). Choosing \(N\) so that \((|h|+1)(9/4)3^{-(2N+1)}\le\theta\) gives the required accuracy. The input bit length bounds \(|h|\), and the resulting rational arithmetic has polynomial bit complexity.

Linear programming. We use the standard polynomial-time theorem for explicitly given rational LPs: feasibility can be decided, and a bounded feasible objective can be optimized exactly, with a rational solution of polynomial encoding length. Its hypotheses hold here. All coefficients are rational and explicitly listed, and the LP size is polynomial. Its feasible region is bounded because, in each acyclic type graph, every arc flow is at most the total source flow \(\mu_t\).

Allocation recovery. Flow decomposition produces at most one bundle per eliminated arc, hence polynomially many bundles. The masses have polynomial bit length: all decomposition operations are additions, subtractions, and comparisons of the polynomially many initial rational flows. A common denominator given by the product of their denominators has polynomial bit length and suffices throughout.

Thus the algorithm returns an explicit, polynomial-size, exactly feasible allocation in polynomial time.

6. Relation to the finite-agent results

The finite-agent hardness result concerns assigning one bundle to each agent. Here, a type’s mass may be split among several integral bundles. The proof exploits precisely that permitted splitting: decomposed path flows are already valid allocations for this problem.

[Feng–Li’s configuration LP](https://drops.dagstuhl.de/storage/00lipics/lipics-vol297-icalp2024/LIPIcs.ICALP.2024.63/LIPIcs.ICALP.2024.63.pdf), Section 2.1 and Appendix A, similarly optimizes a logarithmic objective over bundle distributions before rounding for finite agents. The construction above handles the present mass and supply equalities directly, so no reduction to their different constraints is required.

Therefore the constant-factor algorithm requested in the question exists, and the stronger approximation scheme is proved.
