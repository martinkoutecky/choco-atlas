The continuous mirror question, as graded

Given organizations \(N\), a finite support of types with rational masses \(\mu_t\), a type-level compatibility relation, and cycle cap \(\Delta\), with each type recording its owner and whether it is an original patient-donor pair or an available platform altruist, choose added altruist masses \(x_d \ge 0\) and nonnegative masses \(y_C\) on compatible cycles \(C\) of length at most \(\Delta\). Respect each type’s original-plus-added capacity, count each organization’s utility as the mass of its original nonaltruistic pairs covered, and minimize \(\sum_d x_d\), subject to no coalition being able to use only its original types for a feasible deviation that strictly raises every member’s utility.

Packaged proof task (what the prover saw — nothing else)

Let \(N=\{1,\ldots,n\}\), with \(n\geq1\). A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\); masses need not sum to one. Here \(\tau\) is the support size, not the number of possible types.
Each type records a compatibility label and either an organization owning original patient–donor pairs or platform ownership of altruists. Write \(O\) and \(A\) for these two classes. There are \(m\) compatibility labels; compatibility is specified by a directed Boolean relation on labels.
Pair labels are incompatible with themselves. Altruists have dummy patients compatible with every donor, so every label has an arc to each altruist label; altruist-to-patient compatibility is input data. The platform is not a coalition member.
The input includes a binary-encoded integer \(\Delta\geq2\). An admissible cycle is a closed compatible sequence of \(2\) through \(\Delta\) type occurrences; repeated types are allowed and consume capacity with multiplicity. Let \(a_{tC}\) count occurrences of \(t\) in \(C\).
Choose real masses \(x_d\geq0\) for \(d\in A\) and \(y_C\geq0\), satisfying \(\sum_C a_{tC}y_C\leq\mu_t\) for \(t\in O\) and \(\sum_C a_{dC}y_C\leq\mu_d+x_d\) for \(d\in A\). Existing platform masses are available without charge; additional masses have unit cost and no upper bound.
Organization \(i\)'s utility is \(u_i(y)=\sum_{t\in O:\operatorname{owner}(t)=i}\sum_C a_{tC}y_C\). A nonempty coalition \(S\subseteq N\) blocks if another feasible mass exchange, using only original types owned by \(S\) with capacities \(\mu_t\), gives \(u_i(z)>u_i(y)\) for every \(i\in S\).
Minimize \(\sum_{d\in A}x_d\) subject to absence of blocking coalitions. Let \(L\) be the total binary input length, including a nonnegative rational budget \(B\); state running times in \(m,\tau,n,\Delta,L\).

Is deciding whether such an unblocked exchange exists with \(\sum_{d\in A}x_d\leq B\) in \(\mathrm{P}\), or is it NP-hard?

For discrete exchanges with \(n\) organizations and \(k\) original compatibility types, at most \((\Delta-1)n(k+1)\) freely chosen additional altruists suffice for a weak-core exchange, and a Pareto-optimal such exchange exists ([source](https://arxiv.org/html/2602.10725v1)).
No complexity classification for this precise continuous optimization problem was located in the literature search.

Modeling choices made when packaging the task

  • Masses are unnormalized endowment quantities, following the discrete endowment model.
  • Original organizational endowments contain patient–donor pairs only, retaining the domain specified in the graded question.
  • Compatibility labels are distinguished from support types refined by ownership and altruist status; m counts labels and tau counts positive-mass support entries.
  • Original-plus-added capacity for a platform altruist means existing capacity mu_d plus purchased capacity x_d; existing capacity is free and additions of listed donor types have no upper bound.
  • Altruists receive universally compatible dummy patients, and the cycle cap counts altruist occurrences as well as pair occurrences.
  • Cycles may repeat a support type, with each occurrence consuming its corresponding capacity.
  • Coalitional deviations are divisible mass exchanges and exclude all platform resources, including existing platform altruists.
  • The cycle cap is at least two and binary encoded; the optimization question is expressed through a nonnegative binary-rational budget.

Result

The decision problem is in \(\mathrm{P}\). In fact, every valid instance admits an unblocked exchange of cost \(\,0\).

The essential reason is divisibility: weighted sums of coalition exchanges remain feasible. This makes the associated nontransferable-utility game balanced, so Scarf’s theorem guarantees a weak-core exchange.

1. The game using only original types

We first exclude all altruists, including existing platform altruists.

Let \(\mathcal C_O\) be the family of admissible cycles containing only original types. This family is finite: cycle lengths are bounded by the finite integer \(\Delta\), and each occurrence belongs to the finite support. Repeated occurrences are retained with their stated multiplicities.

For a nonempty coalition \(S\subseteq N\), write
\(\displaystyle O(S)=\{t\in O:\operatorname{owner}(t)\in S\}\).
Define \(P(S)\) to consist of vectors \(z\in\mathbb R_{\geq0}^{\mathcal C_O}\) satisfying:

  • \(z_C=0\) whenever \(C\) contains a type outside \(O(S)\);
  • \(\displaystyle \sum_{C\in\mathcal C_O}a_{tC}z_C\leq\mu_t\) for every \(t\in O\).

Thus \(P(S)\) is exactly the feasible exchange set available to coalition \(S\).

These sets are nonempty, since the zero exchange is feasible. They are also compact. Indeed, put
\(\displaystyle R=\sum_{t\in O}\mu_t\).
For every \(z\in P(S)\),
\(\displaystyle 2\sum_{C\in\mathcal C_O}z_C \leq\sum_{C\in\mathcal C_O}|C|z_C =\sum_{t\in O}\sum_{C\in\mathcal C_O}a_{tC}z_C \leq R\).
Consequently every coordinate is bounded, and the defining linear constraints make \(P(S)\) closed. If there are no original-only cycles, the exchange set consists of the zero vector.

Define the coalition’s comprehensive utility set by
\(\displaystyle V(S)=\{v\in\mathbb R^n:\text{there exists }z\in P(S)\text{ with }v_i\leq u_i(z)\text{ for every }i\in S\}\).
Coordinates outside \(S\) are unrestricted.

Each \(V(S)\) has the following properties:

  • Nonempty: the zero vector belongs to it.
  • Comprehensive: decreasing any coalition member’s coordinate preserves membership.
  • Closed: if \(v^{(r)}\in V(S)\) converges to \(v\), compactness of \(P(S)\) supplies a convergent subsequence of witnessing exchanges. Its limit witnesses \(v\in V(S)\), by continuity of utilities.
  • Bounded above on coalition coordinates: letting

\(\displaystyle M_i=\sum_{\substack{t\in O\\\operatorname{owner}(t)=i}}\mu_t\),
every \(v\in V(S)\) satisfies \(v_i\leq M_i\) for \(i\in S\).

These statements also cover organizations owning no original types.

2. Balancedness

A family \(\mathcal F\) of nonempty coalitions is balanced if there are weights \(\lambda_S\geq0\) such that
\(\displaystyle \sum_{\substack{S\in\mathcal F\\i\in S}}\lambda_S=1\)
for every organization \(i\).

We prove that
\(\displaystyle \bigcap_{S\in\mathcal F}V(S)\subseteq V(N)\)
for every balanced family.

Take \(v\) in this intersection. For each \(S\in\mathcal F\), choose \(z^S\in P(S)\) satisfying \(u_i(z^S)\geq v_i\) for every \(i\in S\). Define
\(\displaystyle \bar z_C=\sum_{S\in\mathcal F}\lambda_S z_C^S\).

Fix an original type \(t\), and let \(i=\operatorname{owner}(t)\). Coalitions excluding \(i\) use no occurrences of \(t\). Therefore
\(\displaystyle \sum_C a_{tC}\bar z_C =\sum_{\substack{S\in\mathcal F\\i\in S}}\lambda_S\sum_C a_{tC}z_C^S \leq\mu_t\sum_{\substack{S\in\mathcal F\\i\in S}}\lambda_S =\mu_t. \)
Hence \(\bar z\in P(N)\).

Likewise, coalitions excluding \(i\) give organization \(i\) zero utility. Linearity gives
\(\displaystyle u_i(\bar z) =\sum_{\substack{S\in\mathcal F\\i\in S}}\lambda_Su_i(z^S) \geq v_i\sum_{\substack{S\in\mathcal F\\i\in S}}\lambda_S =v_i. \)
Thus \(v\in V(N)\), proving balancedness.

3. Core existence and an actual exchange

We use the following standard form of Scarf’s core-existence theorem: a finite nontransferable-utility game with nonempty, closed, comprehensive coalition utility sets, bounded above on coalition members’ coordinates, has a nonempty weak core if it is balanced. Here the weak core consists of vectors \(v^\star\in V(N)\) for which no nonempty coalition \(S\) has a vector \(w\in V(S)\) satisfying \(w_i>v_i^\star\) for every \(i\in S\). See [Scarf, *The Core of an N Person Game*](https://cowles.yale.edu/sites/default/files/2022-08/d0182-r.pdf).

All hypotheses were verified above. Therefore such a \(v^\star\) exists.

Because \(v^\star\in V(N)\), some exchange \(y^\star\in P(N)\) satisfies \(u_i(y^\star)\geq v_i^\star\) for every organization \(i\). This actual exchange is unblocked: if \(S\) had an exchange \(z\in P(S)\) strictly improving every member’s utility over \(y^\star\), then
\(\displaystyle u_i(z)>u_i(y^\star)\geq v_i^\star\)
for every \(i\in S\), contradicting the weak-core property.

Now extend \(y^\star\) to the full model by assigning zero mass to every cycle containing an altruist and setting \(x_d=0\) for every \(d\in A\). All original capacities remain satisfied; all altruist capacities are unused. Blocking coalitions have exactly the original-only exchange opportunities already considered.

The resulting full-model exchange is therefore feasible and unblocked, with total additional-altruist cost \(\,0\). Since costs are nonnegative, the minimum is exactly \(\,0\).

Divisibility is essential to the balancedness proof: the weighted exchange \(\bar z\) is feasible with real masses, whereas weighted sums need not be permissible discrete exchanges.

4. Decision algorithm and running time

For the stipulated inputs, the budget satisfies \(B\geq0\), so the answer is always YES.

The decision algorithm takes \(O(L)\) time if it reads the entire supplied input, or \(O(1)\) time on the promise of a valid instance. It requires no cycle or coalition enumeration and has no additional dependence on \(m,\tau,n,\Delta\). This running-time statement concerns deciding existence; the existence proof above does not require computing a core exchange.
