The continuous mirror question, as graded

Given a finite set of slot types \(D\) and a finite support of complete patient types \(t=(r,e)\), where \(r\) is a strict ranking over \(D\), \(e\in D\) is the initially endowed slot type, and the rational masses \(\mu_t\) sum to one, let \(q_d=\sum_{t:e(t)=d}\mu_t\). Find a feasible mass assignment \(x_{t,d}\geq 0\) with \(\sum_d x_{t,d}=\mu_t\) and \(\sum_t x_{t,d}=q_d\) that admits no blocking coalition: no selected submass can reallocate only its initially endowed slots so every member weakly improves and positive mass strictly improves. Determine whether the resulting aggregate assignment is unique.

Packaged proof task (what the prover saw — nothing else)

Let \(D\) be a nonempty set of \(m\) slot types, each with positive supply. A society is given by its support: the list of \(\tau\) types \(t=(r_t,e_t)\) with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types. Each \(r_t\) is a complete strict ranking of \(D\), and each patient initially owns one slot of type \(e_t\in D\). Let \(L\) be the total input bit length and \(q_d=\sum_{t:e_t=d}\mu_t\).
An aggregate assignment is a real matrix \(x\geq0\) satisfying \(\sum_d x_{t,d}=\mu_t\) and \(\sum_t x_{t,d}=q_d\). Its entries represent masses of patients receiving individual slots.
A blocking coalition is specified by real masses \(z_{t,a,b}\geq0\), selecting patients of type \(t\) currently receiving \(a\) and assigning them \(b\), with \(\sum_b z_{t,a,b}\leq x_{t,a}\) and \(\sum_{t,a}z_{t,a,d}=\sum_{t:e_t=d}\sum_{a,b}z_{t,a,b}\) for every \(d\).
Require \(z_{t,a,b}=0\) unless \(b\succeq_{r_t}a\), and \(\sum_{t,a,b:b\succ_{r_t}a}z_{t,a,b}>0\). Thus the coalition uses exactly its initial endowments, everyone weakly improves, and positive mass strictly improves. A core assignment admits no such coalition; uniqueness means equality of the entire aggregate matrix.

Is computing a core assignment, or determining that none exists, polynomial-time solvable in \(m,\tau,L\), or NP-hard? Is deciding whether exactly one core aggregate assignment exists in P or NP-hard?

For finite patients with distinct endowed slots and complete strict preferences, TOAM produces the unique core allocation. [Singh, Mukhopadhyay and Das](https://arxiv.org/pdf/1606.08590).
For finite agents with fractional endowments and stochastic-dominance comparisons of assignments, the strong core can be empty; this uses a different blocking definition. [Athanasiou](https://arxiv.org/html/2508.11151v1). No result settling the precise mass-coalition complexity questions above was identified.

Modeling choices made when packaging the task

  • Made the initial allocation a fixed endowment input; uniqueness is conditional on that endowment rather than on a fresh random initialization.
  • Interpreted assignment entries as masses of patients receiving individual slots, and allowed coalitions to select arbitrary real submasses separately from each current assignment cell.
  • Formalized weak improvement pointwise through reassignment masses, with positive total mass strictly improving, rather than comparing lotteries or average utilities.
  • Interpreted aggregate uniqueness as uniqueness of the full type-by-slot matrix, since column totals are already fixed by feasibility.
  • Restricted the nonempty slot set to positive-supply types; zero-supply types can be deleted from every ranking.
  • Included reporting nonexistence in the computation task and interpreted the uniqueness decision as asking whether the core contains exactly one aggregate assignment.

Result

Both problems are polynomial-time solvable in \(m,\tau,L\). More precisely:

  • One can compute a core assignment or correctly report that the core is empty.
  • The core is always either empty or a singleton. Thus deciding whether exactly one core aggregate assignment exists is equivalent to deciding whether the core is nonempty.
  • In every core assignment, each supported patient type receives a single slot type: every row has exactly one positive entry.

The proof below uses the stated real-mass blocking definition directly.

1. Blocking coalitions and directed cycles

Fix a feasible assignment \(x\). Define a directed multigraph \(G_x\) on \(D\). For every triple \((t,a,b)\) satisfying \(x_{t,a}>0\) and \(b\succeq_{r_t}a\), include an arc from \(e_t\) to \(b\), labelled by that triple. Mark the arc strict when \(b\succ_{r_t}a\). Loops and parallel arcs are allowed.

Lemma 1. An assignment \(x\) admits a blocking coalition if and only if \(G_x\) contains a directed cycle with a strict arc.

Proof. Suppose first that such a cycle exists. For each pair \((t,a)\) used by its labelled arcs, let \(c_{t,a}\) be the number of occurrences of that pair. Choose

\(\displaystyle 0<\varepsilon\leq\min_{(t,a):c_{t,a}>0}\frac{x_{t,a}}{c_{t,a}}.\)

Assign mass \(\varepsilon\) to each labelled arc of the cycle, adding contributions if a label repeats, and set all other coalition variables to zero. The choice of \(\varepsilon\) ensures \(\sum_bz_{t,a,b}\leq x_{t,a}\).

An arc leaves the type of slot initially owned by its participants and enters the type they receive. Consequently, the cycle’s equal incoming and outgoing masses at every vertex are exactly the coalition’s endowment-balance equations. Every selected patient weakly improves, and the strict arc supplies positive strictly improving mass. This is a blocking coalition.

Conversely, a blocking coalition defines a nonnegative circulation on \(G_x\), putting weight \(z_{t,a,b}\) on the corresponding labelled arc. Its strict-improvement condition gives a strict arc of positive weight.

Every positive-weight arc of a finite circulation belongs to a directed cycle of positive-weight arcs. To verify this, consider an arc from \(u\) to \(v\). A loop already forms a cycle. Otherwise, let \(W\) be the vertices reachable from \(v\) along positive-weight arcs. If \(u\notin W\), no positive-weight arc leaves \(W\), while the arc from \(u\) to \(v\) enters \(W\). This contradicts flow conservation summed over \(W\). Thus a positive-weight path returns from \(v\) to \(u\). Applying this to the strict arc proves the claim. \(\square\)

This lemma applies even when \(x\) or the coalition masses are irrational.

2. The top-choice reduction

We will use reduced markets obtained by retaining a nonempty subset \(R\subseteq D\), precisely the patient types whose endowments lie in \(R\), and their original masses. Preferences are restricted to \(R\).

Their total mass need not equal one. The assignment and blocking equations still make sense without normalization, and all arguments below apply unchanged.

For each retained type \(t\), let \(h_R(t)\) be its uniquely most-preferred slot type in \(R\). Define the top-choice graph \(H_R\) on \(R\), with one labelled arc

\(\displaystyle e_t\longrightarrow h_R(t)\)

for every retained type \(t\).

Choose a sink strongly connected component \(S\) of \(H_R\): a strongly connected component with no arc leaving it. Such a component exists because the condensation graph of every finite directed graph is acyclic.

Write \(T_S=\{t:e_t\in S\}\). Since \(S\) is a sink, \(h_R(t)\in S\) for every \(t\in T_S\).

Lemma 2 — Forced assignments. In every core assignment of the reduced market, each type \(t\in T_S\) receives only \(h_R(t)\).

Proof. Let \(x\) be a core assignment of the reduced market. Suppose \(t\in T_S\) and \(x_{t,a}>0\) for some \(a\neq h_R(t)\).

Because rankings are strict,

\(\displaystyle h_R(t)\succ_{r_t}a.\)

Thus \(G_x\) contains a strict arc from \(e_t\) to \(h_R(t)\).

Every arc of \(H_R\) also has a corresponding arc in \(G_x\): its labelled type has positive mass, hence some positive assignment entry, and its top choice weakly improves upon any assigned slot type.

Strong connectivity of \(S\) provides a path in \(H_R\) from \(h_R(t)\) back to \(e_t\). Together with the strict arc, this gives a directed cycle in \(G_x\) containing a strict arc. If \(h_R(t)=e_t\), the strict arc itself is a loop. Either case contradicts Lemma 1.

Therefore \(x_{t,h_R(t)}=\mu_t\), and every other entry in that row is zero. \(\square\)

Define the forced demand for each \(d\in S\) by

\(\displaystyle F_d=\sum_{\substack{t\in T_S\\h_R(t)=d}}\mu_t.\)

Lemma 3 — Exact reduction.

  • If \(F_d\neq q_d\) for some \(d\in S\), the reduced market has no core assignment.
  • If \(F_d=q_d\) for every \(d\in S\), its core assignments are exactly the unions of the forced assignments on \(T_S\) and core assignments of the market on \(R\setminus S\).

Proof of necessity. Lemma 2 forces every type in \(T_S\) to receive its top choice in \(S\). Their total consumption in \(S\) equals

\(\displaystyle \sum_{t\in T_S}\mu_t=\sum_{d\in S}q_d.\)

This exhausts the entire supply in \(S\). Nonnegativity therefore implies that no type outside \(T_S\) receives any slot in \(S\). The individual column equations then require \(F_d=q_d\) for every \(d\in S\).

The assignment restricted to the remaining types and slots is feasible. It must also be core: any blocking coalition there would extend, by zero coalition variables for the removed types, to a blocking coalition of the original reduced market.

Proof of sufficiency. Suppose the equalities hold. Combine the forced assignment on \(T_S\) with a core assignment on \(R\setminus S\). The resulting assignment is feasible.

Assume a coalition blocks it. Every selected patient whose type lies in \(T_S\) currently receives its top choice in \(R\). Strict rankings imply that its only weakly improving reassignment is to that same slot type, which lies in \(S\). Such patients cannot strictly improve.

Let \(M_S\) be the selected mass of patients whose endowments lie in \(S\). They bring exactly \(M_S\) slots from \(S\), and their reassignment consumes exactly \(M_S\) slots in \(S\). Summing the coalition-balance equations over \(S\) shows that no selected patient with endowment outside \(S\) can receive a slot in \(S\).

Hence the coalition restricted to the remaining patients satisfies all capacity, preference, and endowment-balance conditions in the remaining market. All strictly improving mass lies among these remaining patients, so the restriction blocks their core assignment—a contradiction.

This proves sufficiency. The same argument covers an empty remaining market, whose empty assignment admits no block. \(\square\)

3. Algorithm and uniqueness

Start with \(R=D\) and an empty output matrix. Repeat:

  • Compute \(h_R(t)\) for every type with \(e_t\in R\).
  • Construct \(H_R\) and choose a sink strongly connected component \(S\).
  • Compute \(F_d\) for every \(d\in S\).
  • If any equality \(F_d=q_d\) fails, report that the core is empty.
  • Otherwise, assign \(x_{t,h_R(t)}=\mu_t\) for every \(t\in T_S\), with zero in every other entry of those rows, and replace \(R\) by \(R\setminus S\).

When \(R\) becomes empty, return the matrix.

Every successful iteration removes at least one slot type, so there are at most \(m\) iterations.

Correctness. Lemma 3 shows at each iteration that failure certifies emptiness, while success reduces the problem exactly to the remaining market. Induction on the number of remaining slot types proves that a completed run returns a core assignment.

Uniqueness. Fix any choices of sink components made by the algorithm. Lemma 2 forces every core assignment to agree with the output on the rows removed at the first iteration. Lemma 3 forces its remaining rows to constitute a core assignment of the remaining market. Repeating this argument forces agreement on every row.

Thus a successful run produces the only core aggregate assignment. A failed run certifies that none exists. In particular, the algorithm’s success and output do not depend on its choices among sink components.

The argument proves uniqueness among all feasible real matrices, not merely among rational assignments.

4. Polynomial bit complexity

Each top-choice graph has at most \(m\) vertices and at most \(\tau\) arcs. Its strongly connected components can be computed in time \(O(m+\tau)\).

Scanning the input rankings computes all current top choices using at most \(O(m\tau)\) operations per iteration. Across at most \(m\) iterations, the combinatorial work is therefore polynomial; a straightforward implementation uses \(O(m^2\tau)\) such operations.

For exact mass comparisons, write each input mass as \(\mu_t=a_t/b_t\), with positive integers encoded in binary. Set

\(\displaystyle B=\prod_t b_t,\qquad w_t=a_t(B/b_t),\qquad Q_d=\sum_{t:e_t=d}w_t.\)

The bit length of \(B\) is \(O(L)\). Since the original masses sum to one, \(\sum_t w_t=B\); consequently every weight and every demand or supply sum has \(O(L)\) bits.

The feasibility tests become exact integer comparisons:

\(\displaystyle \sum_{\substack{t\in T_S\\h_R(t)=d}}w_t=Q_d.\)

Constructing these integers and performing all comparisons requires polynomial bit time. The output entries are input masses or zero, so the output also has polynomial length.

This establishes polynomial-time core computation and emptiness detection in \(m,\tau,L\). Because nonemptiness implies uniqueness, the “exactly one” decision problem is in \(\mathrm{P}\).

5. The core can be empty

Let \(D=\{A,B\}\), with two supported types:

  • Type \(t_1\) owns \(A\), has mass \(3/4\), and ranks \(B\succ A\).
  • Type \(t_2\) owns \(B\), has mass \(1/4\), and ranks \(A\succ B\).

The top-choice graph has arcs \(A\longrightarrow B\) and \(B\longrightarrow A\). Its only sink component is all of \(D\).

Lemma 2 would require every patient to receive its top choice. This demands mass \(3/4\) of \(B\), although its supply is \(1/4\). Thus the core is empty.

If instead both masses are \(1/2\), the same checks succeed, and exchanging the endowments is the unique core aggregate assignment.

6. Relation to finite-market results

Strict preferences over slot types permit indifference between individual copies of the same type. Therefore existence results requiring strict preferences over distinct individual slots do not imply existence here.

The reduction is related to the absorbing-set method for finite houseswapping with indifferences developed by [Quint and Wako](https://pubsonline.informs.org/doi/10.1287/moor.1040.0106). Multiple copies with shared indifferences are also studied by [Sandholtz and Tai](https://arxiv.org/abs/2306.09529). The proof above establishes the precise real-mass model directly, using only the support and binary-encoded masses, without expanding them into a potentially exponentially large finite population.

The prover’s argument resolves both questions. Core computation and emptiness detection are polynomial-time solvable, and deciding whether exactly one core aggregate assignment exists is in \(\mathrm{P}\). No major or minor mathematical gaps were found.

  • Scope and definitions

The proof uses the specified blocking definition: coalitions select mass from individual assignment entries, conserve their initial endowments, weakly improve every selected patient, and strictly improve positive mass. It does not substitute stochastic-dominance comparisons or require every participant to strictly improve.

Reduced markets retain precisely the types endowed in the remaining slot set, with their original masses. Consequently, the supply of each retained slot type remains \(q_d\). The observation that normalization is unnecessary is correct: none of the feasibility or blocking arguments requires total mass to equal one.

  • Lemma 1: blocking coalitions and strict directed cycles

The forward construction from a cycle is valid. Every participating pair \((t,a)\) has \(x_{t,a}>0\), so the minimum defining \(\varepsilon\) is positive. Accounting for repeated occurrences through \(c_{t,a}\) ensures that the total selected mass from each assignment entry does not exceed that entry.

The graph’s orientation matches the coalition equations: outgoing mass at \(d\) counts selected patients initially endowed with \(d\), while incoming mass counts reassignment to \(d\). Equal incoming and outgoing cycle mass therefore gives exactly the required endowment balance. A strict arc contributes positive strictly improving mass.

Conversely, every positive coalition variable corresponds to an arc of \(G_x\): its capacity constraint implies \(x_{t,a}>0\), and its preference constraint supplies the permitted destination. The coalition balance equations make these arc weights a circulation.

The reachability argument establishing that a positive-weight arc belongs to a positive-weight cycle is correct. If its tail were outside the set reachable from its head, that set would have positive incoming flow and no positive outgoing flow, contradicting conservation. Loops are explicitly covered.

Thus the equivalence holds for real, including irrational, assignment and coalition masses.

  • Lemma 2: forced assignments

Every retained type has positive mass and therefore some positive assignment entry. Its top choice weakly improves upon every slot it could receive in the reduced market. Hence every top-choice arc has a corresponding arc in \(G_x\), as claimed.

If a type receives positive mass of anything other than its unique top choice, the associated top-choice arc is strict. Strong connectivity supplies the return path needed to put that arc on a directed cycle. The coincident-endpoint case is correctly handled as a strict loop.

Lemma 1 then excludes the supposed assignment entry. The row-sum equation forces the entire mass \(\mu_t\) onto \(h_R(t)\).

The sink hypothesis also ensures that all these forced destinations lie in \(S\), which is essential for the subsequent reduction.

  • Lemma 3: necessity and exact reduction

The supply-exhaustion argument is valid. The types endowed in \(S\) have total mass equal to the total supply in \(S\), and Lemma 2 makes them consume all that mass within \(S\). Feasibility and nonnegativity therefore leave no consumption in \(S\) by types endowed outside it. The individual column equations consequently force \(F_d=q_d\) for every \(d\in S\).

Removing those rows and columns leaves a feasible assignment. A blocking coalition in the remaining market extends by zeros to the larger reduced market, so restriction preserves the core property.

For sufficiency, each removed type receives its unique top choice in \(R\). Its only weakly improving destination is that same slot type. Thus selected patients endowed in \(S\) consume exactly their selected total mass within \(S\), and none strictly improves.

Summing the coalition balance equations over \(S\) leaves zero mass available there for participants endowed outside \(S\). Nonnegativity rules out their receiving slots in \(S\). Restricting the coalition therefore preserves all remaining capacity, preference, and balance constraints, together with all strictly improving mass.

This contradicts the assumed core property of the remaining assignment. The empty remaining market is explicitly and correctly covered.

  • Algorithm, existence, and uniqueness

A sink strongly connected component exists in every nonempty finite directed graph, by the acyclic condensation graph. Its use here requires no additional preference or mass hypothesis.

Every successful iteration removes a nonempty set of slot types, so termination occurs within \(m\) iterations. Lemma 3 justifies both outcomes: a failed comparison certifies emptiness, while successful reduction preserves an exact correspondence between core assignments.

Uniqueness follows from the stated repeated forcing argument. For any fixed sequence of component choices, every core assignment must agree on each removed row. Completion covers every supported type, so agreement is equality of the entire aggregate matrix.

This establishes uniqueness among all feasible real matrices. It also justifies independence from component choices: every completed run returns the same unique assignment, and a failed run correctly reports emptiness.

The claim that every core row has exactly one positive entry follows because each positive-mass type is eventually removed and forced to one destination.

  • Polynomial bit complexity

The graph-size and iteration bounds are correct. Ranking scans require at most \(O(m\tau)\) operations per iteration. Positive supply implies that every slot type occurs as some supported type’s endowment, so \(m\leq\tau\); graph processing is therefore covered by the stated overall polynomial bound.

The common-denominator construction is valid without requiring reduced fractions. Each denominator divides \(B\), making every \(w_t\) an integer.

The product \(B\) has bit length bounded by the sum of the input denominator bit lengths, hence \(O(L)\). Normalization gives \(\sum_t w_t=B\), so every nonnegative weight, demand sum, and supply sum is at most \(B\), with \(O(L)\) bits.

Exact integer arithmetic and equality comparisons therefore take polynomial bit time. Output entries are input masses or zero, and the explicit matrix has polynomial size. No expansion into individual patients is needed.

In the unequal-mass example, the unique sink component is all of \(D\), and forced demand for \(B\) is \(3/4\), exceeding its supply \(1/4\). The emptiness conclusion follows correctly. With equal masses, both forced-demand equalities hold, so the exchange is the unique core aggregate assignment.

The distinction between strict rankings of slot types and strict rankings of individual copies is valid. The literature citations are contextual rather than premises of the proof. Their general descriptions are consistent with the cited publications: [Quint and Wako](https://pubsonline.informs.org/doi/10.1287/moor.1040.0106) study houseswapping with indifferences and strict-core computation; [Sandholtz and Tai](https://arxiv.org/abs/2306.09529) study shared indifferences, including multiple copies.
