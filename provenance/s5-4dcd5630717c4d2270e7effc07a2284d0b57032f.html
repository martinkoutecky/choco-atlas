The continuous mirror question, as graded

Given a finite type set \(T\) with binary-rational masses \(\mu_t\) summing to \(1\), listed integral bundle sets \(\mathcal{B}_t\), values \(v_t(S)\), resource uses \(a_j(S)\), and per-capita supplies \(\rho_j\), compute an allocation maximizing \(\sum_{t,S}x_{t,S}v_t(S)\), subject to \(\sum_{S\in\mathcal{B}_t}x_{t,S}=\mu_t\), \(\sum_{t,S}x_{t,S}a_j(S)\le\rho_j\), and \(x_{t,S}\ge0\).

Conclusion

Exact welfare maximization is solvable in polynomial time in \(m,\tau,K,L\). The stated problem is an explicitly represented rational linear program. This conclusion applies to computing an exact optimal allocation, not merely approximating its welfare.

1. Exact linear-program formulation

Let \(I=\{(t,S):t\in T,\ S\in\mathcal B_t\}\), so \(|I|=K\). Introduce one real variable \(x_{t,S}\) for every pair in \(I\). Consider:

\(\displaystyle \max \sum_{t\in T}\sum_{S\in\mathcal B_t}v_t(S)x_{t,S}\)

subject to

\(\displaystyle \sum_{S\in\mathcal B_t}x_{t,S}=\mu_t \qquad(t\in T),\)

\(\displaystyle \sum_{t\in T}\sum_{S\in\mathcal B_t}a_j(S)x_{t,S}\le\rho_j \qquad(j=1,\ldots,m),\)

\(\displaystyle x_{t,S}\ge0 \qquad((t,S)\in I).\)

These constraints are exactly the allocation feasibility conditions, and the objective is exactly welfare. Consequently, feasible allocations and feasible solutions of this linear program coincide, with identical objective values.

The integrality of each listed bundle imposes no integrality constraint on \(x_{t,S}\): these variables represent masses, which the premises explicitly permit to be split.

2. Feasibility and attainment

For each type, select its empty bundle and assign its entire mass to that bundle. This satisfies the type equations and uses zero resources. Since every supply is nonnegative, the resulting allocation is feasible.

Furthermore, nonnegativity and the type equations imply

\(\displaystyle 0\le x_{t,S}\le\mu_t\le1.\)

The feasible region is therefore bounded. It is closed because it is defined by finitely many linear equalities and non-strict inequalities. Thus it is a nonempty compact polytope, and its continuous linear objective attains a finite maximum.

3. Polynomial encoding and exact computation

The program has \(K\) variables, \(\tau\) type equations, and \(m\) resource inequalities, together with nonnegativity constraints. Replacing each equation by two inequalities gives \(2\tau+m+K\) inequalities.

All numerical coefficients are rational and explicitly supplied, except for added coefficients from \(\{-1,0,1\}\). A dense representation contains at most \(O((m+\tau+K)K)\) entries. Each supplied coefficient has encoding length at most \(L\), so the resulting linear program has total encoding length polynomial in \(m,\tau,K,L\). Constructing it requires only copying the supplied tables and inserting the type-incidence coefficients.

We use the following standard theorem:

Exact rational linear programming theorem. A linear program with explicitly represented rational coefficients can be solved in a number of bit operations polynomial in its total binary encoding length. When its feasible region is nonempty and its optimum is finite, the algorithm returns an exact rational optimal solution. Exact polynomial-time algorithms, including the distinction between approximate and exact solutions, are discussed in Section 1.3 of [Gleixner and Steffy, *Linear Programming using Limited-Precision Oracles*](https://arxiv.org/pdf/1912.12820).

Every hypothesis has been checked: the coefficients are rational, the representation has polynomial length, feasibility holds, and the optimum is finite. Applying this theorem therefore computes an exact welfare-maximizing allocation in polynomial time in the requested parameters.

For completeness, exact output has polynomial length as well. Let \(H\) be the total encoding length of the constructed program. A linear objective on a nonempty compact polytope has an optimal vertex. At a vertex, the active constraint normals span \(\mathbb R^K\): otherwise a nonzero direction orthogonal to all of them would allow sufficiently small feasible perturbations in both directions, contradicting extremality.

Select \(K\) independent active constraints, yielding a nonsingular rational system \(Bx=b\). Let \(D\) be the product of the denominators in this system. Its bit length is \(O(H)\). Clearing denominators produces an integer system whose entries have absolute value at most \(2^{O(H)}\). By the determinant expansion, every determinant used in Cramer’s rule has absolute value at most

\(\displaystyle K!\,2^{O(KH)}.\)

Thus the numerator and denominator of each vertex coordinate have bit length \(O(KH+K\log K)\). An exact optimal allocation consequently admits a polynomial-length rational encoding.
