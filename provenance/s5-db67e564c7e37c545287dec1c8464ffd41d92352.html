Theorem 1 — class: other

The continuous mirror question, as graded

Given a depot, τ sponsor types at shared hubs with rational masses μ_t summing to 1, a rational directed cost matrix K satisfying the triangle inequalities, and a minimum-cost route σ through the depot and all types, find rational allocation rates a_t such that ∑_t μ_t a_t = c_{K,σ}(T) and ∑_t z_t a_t ≤ c_{K,σ}(supp(z)) for every coalition mass vector z with 0 ≤ z_t ≤ μ_t. Here c_{K,σ}(supp(z)) is the cost of shortcutting σ through the types with positive coalition mass.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\geq 1\) sponsor types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; all sponsors of a type share its hub.
Let \(T=\{1,\ldots,\tau\}\), with depot \(0\), and write \(m=\tau+1\) for the number of labelled locations. The input includes a directed matrix \(K\in\mathbb{Q}^{m\times m}\) satisfying \(K_{ii}=0\) and \(K_{ij}+K_{jk}\geq K_{ik}\) for all locations; entries need not be nonnegative or symmetric.
A cyclic tour \(\sigma\) visiting every labelled location exactly once is supplied, promised to have minimum total cost among such tours. Any minimizing tour is allowed.
For \(S\subseteq T\), define \(c_{K,\sigma}(S)\) as the sum of directed costs on the tour obtained by deleting types outside \(S\) from \(\sigma\), preserving the order and retaining the depot; set \(c_{K,\sigma}(\varnothing)=0\).
The allocation problem asks for signed rational rates \(a_t\) satisfying \(\sum_{t\in T}\mu_ta_t=c_{K,\sigma}(T)\) and \(\sum_{t\in T}z_ta_t\leq c_{K,\sigma}(\operatorname{supp}(z))\) for every real vector \(z\) with \(0\leq z_t\leq\mu_t\), where \(\operatorname{supp}(z)=\{t:z_t>0\}\), or a determination that no such rates exist. Let \(L\) be the total binary input length.

Is this allocation problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard, under the promise that the supplied tour is optimal?

For finite sponsors, an optimal fixed tour with zero diagonal and triangle inequalities has a nonempty core ([Potters–Curiel–Tijs, 1992](https://doi.org/10.1007/BF01585702)); [Derks–Kuipers, 1997](https://doi.org/10.1007/BF01295848) give an \(O(n^2)\) algorithm computing a core element of a routing game whenever its core is nonempty.
No result settling this exact mass-coalition formulation was located in the search.

Modeling choices made when packaging the task

  • Made the zero diagonal explicit, as required by the discrete definition.
  • Allowed signed rational costs and allocation rates, matching the discrete definition's real-valued domains rather than imposing nonnegativity.
  • Used one labelled hub per support type and defined m as the number of these labels plus the depot; no additional locations are part of the input.
  • Specified that the supplied optimal route is a cyclic tour visiting each labelled location exactly once, and treated optimality as an input promise.
  • Quantified coalition masses over real vectors and explicitly defined their support and the empty coalition's cost.
  • Included determining infeasibility because the continuous question does not supply a promise that suitable rates exist.

Result

The allocation problem is polynomial-time solvable. An explicit algorithm uses \(O(\tau^2)\) exact rational arithmetic operations, with polynomial bit complexity.

The algorithm works for any supplied fixed tour satisfying the matrix assumptions, so it applies under the optimal-tour promise without checking optimality.

1. Reduction to a finite core problem

Relabel the types in their order along the supplied tour, carrying along their masses. Write the tour as \(\sigma=(0,1,\ldots,\tau,0)\), and abbreviate \(c_{K,\sigma}(S)\) to \(c(S)\). Set \(C=c(T)\).

First, shortcut costs are monotone:

\[ \text{For }A\subseteq B\subseteq T,\qquad c(A)\leq c(B). \]

Indeed, deleting a visited type replaces two consecutive edges \(u\to v\to w\) by \(u\to w\). The triangle inequality gives \(K_{uw}\leq K_{uv}+K_{vw}\), so deletion cannot increase cost. This also covers deletion of the last type, since \(K_{00}=0\). Repeated deletion proves monotonicity, even when matrix entries are signed.

Define \(x_t=\mu_ta_t\), and write \(x(S)=\sum_{t\in S}x_t\). Consider the finite core constraints

\[ x(T)=C,\qquad x(S)\leq c(S)\quad\text{for every }S\subseteq T. \]

These are equivalent to the allocation constraints in the question.

Necessity. For each \(S\), choose \(z_t=\mu_t\) when \(t\in S\), and \(z_t=0\) otherwise. The allocation constraints give \(x(S)\leq c(S)\), together with \(x(T)=C\).

Sufficiency. Every vector satisfying the finite core constraints is nonnegative. For each \(t\),

\[ x_t=C-x(T\setminus\{t\}) \geq C-c(T\setminus\{t\}) \geq 0, \]

where the last inequality follows from monotonicity.

Consequently, define \(a_t=x_t/\mu_t\geq0\). For any allowed real vector \(z\), with \(S=\operatorname{supp}(z)\),

\[ \sum_{t\in T}z_ta_t =\sum_{t\in S}\frac{z_t}{\mu_t}x_t \leq\sum_{t\in S}x_t \leq c(S). \]

Efficiency follows from \(x(T)=C\). Thus the real coalition vectors impose no additional constraints beyond the finite core constraints.

2. Only consecutive deletion blocks need to be checked

Put \(v_0=0\), \(v_i=i\) for \(1\leq i\leq\tau\), and \(v_{\tau+1}=0\). For \(1\leq i\leq j\leq\tau\), define the saving from deleting the consecutive block \(I_{ij}=\{i,\ldots,j\}\) by

\[ D_{ij} =\sum_{r=i-1}^{j}K_{v_rv_{r+1}} -K_{v_{i-1}v_{j+1}}. \]

Repeated application of the triangle inequality shows that a direct edge costs no more than the corresponding directed path. Hence \(D_{ij}\geq0\). Also,

\[ c(T\setminus I_{ij})=C-D_{ij}, \qquad D_{1\tau}=C. \]

I claim that the finite core is exactly the set of vectors satisfying

\[ x(T)=C,\qquad \sum_{t=i}^{j}x_t\geq D_{ij} \quad(1\leq i\leq j\leq\tau). \]

Necessity. Apply the core inequality to \(T\setminus I_{ij}\):

\[ C-x(I_{ij})=x(T\setminus I_{ij}) \leq C-D_{ij}. \]

Rearranging gives \(x(I_{ij})\geq D_{ij}\).

Sufficiency. Fix \(S\subseteq T\). Decompose \(T\setminus S\) into its maximal consecutive blocks \(I_{i_1j_1},\ldots,I_{i_qj_q}\). Distinct maximal blocks have at least one retained type between them, so their deleted tour segments have disjoint edge sets. Shortcutting each segment therefore gives the exact identity

\[ C-c(S)=\sum_{\ell=1}^{q}D_{i_\ell j_\ell}. \]

The block inequalities imply

\[ x(T\setminus S) =\sum_{\ell=1}^{q}x(I_{i_\ell j_\ell}) \geq C-c(S). \]

Using efficiency yields \(x(S)\leq c(S)\), as required. When \(S=T\), the sums are empty and the same conclusion holds.

Thus only \(O(\tau^2)\) inequalities are needed. The singleton inequalities also give \(x_t\geq D_{tt}\geq0\).

3. An explicit dynamic program

Introduce prefix sums \(y_0=0\) and \(y_j=\sum_{t=1}^{j}x_t\). The block constraints become

\[ y_j\geq y_{i-1}+D_{ij} \quad(1\leq i\leq j\leq\tau), \qquad y_\tau=C. \]

Compute \(d_0=0\) and, successively,

\[ d_j=\max_{1\leq i\leq j}\bigl(d_{i-1}+D_{ij}\bigr) \quad(1\leq j\leq\tau). \]

Every feasible prefix vector satisfies \(y_j\geq d_j\). To prove this, use induction on \(j\): the block inequalities and the induction hypothesis give

\[ y_j\geq \max_{1\leq i\leq j}(y_{i-1}+D_{ij}) \geq \max_{1\leq i\leq j}(d_{i-1}+D_{ij}) =d_j. \]

In particular, feasibility requires \(C\geq d_\tau\). Conversely, the term \(i=1\) in the recurrence gives \(d_\tau\geq D_{1\tau}=C\). Therefore,

\[ \text{An allocation exists if and only if }d_\tau=C. \]

If \(d_\tau>C\), report that no allocation exists.

If \(d_\tau=C\), output

\[ x_j=d_j-d_{j-1}, \qquad a_j=\frac{x_j}{\mu_j}. \]

These values satisfy every block inequality because

\[ \sum_{t=i}^{j}x_t=d_j-d_{i-1}\geq D_{ij}. \]

They satisfy efficiency by telescoping, and are nonnegative because \(d_j\geq d_{j-1}+D_{jj}\geq d_{j-1}\). Sections 1 and 2 then prove that the output rates satisfy every allocation constraint.

There is also a short infeasibility certificate. Store a maximizing index at each recurrence step. Backtracking from \(\tau\) produces a partition of \(T\) into consecutive blocks whose savings sum to \(d_\tau\). If \(d_\tau>C\), summing the required block inequalities contradicts \(x(T)=C\).

4. Polynomial bit complexity

All block savings can be computed using tour-edge prefix sums. Define

\[ P_0=0,\qquad P_k=\sum_{r=0}^{k-1}K_{v_rv_{r+1}} \quad(1\leq k\leq\tau+1). \]

Then \(C=P_{\tau+1}\) and

\[ D_{ij}=P_{j+1}-P_{i-1}-K_{v_{i-1}v_{j+1}}. \]

Computing the savings and the dynamic program takes \(O(\tau^2)\) arithmetic operations.

For exact bit complexity, let \(Q\) be the product of the positive denominators of the matrix entries. Its binary length is \(O(L)\), and every \(QK_{uv}\) is an integer of polynomial binary length. Run the computations after scaling all costs by \(Q\).

Each scaled saving is a sum of at most \(\tau+2\) scaled matrix entries. Each dynamic-program value is a sum of at most \(\tau\) such savings, as follows by recursively expanding its maximizing choices. Thus all intermediate integers have binary length polynomial in \(L+\log\tau\).

Finally, dividing \(x_t\) by the positive input rational \(\mu_t\) produces a rational rate of polynomial binary length. The entire algorithm consequently runs in time polynomial in \(m,\tau,L\).
