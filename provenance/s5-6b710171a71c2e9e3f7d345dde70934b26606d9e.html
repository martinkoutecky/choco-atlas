The continuous mirror question, as graded

Given a fixed finite asset set \(A\) and rational masses \(\mu_t\) over complete rational utility tables \(u_t:2^A\to\mathbb{Q}_{\ge 0}\), let integer populations \(N_t\) satisfy \(\sum_t N_t=N\) and \(N_t/N\to\mu_t\). For each type, compute \(Q_t^+=\max_{\pi\in\Pi(A)}\sum_{S\in\pi}u_t(S)\) and \(Q_t^-=\min_{\pi\in\Pi(A)}\sum_{S\in\pi}u_t(S)\), where \(\Pi(A)\) contains all partitions into nonempty blocks. Output partitions attaining both extrema, the limiting aggregate guarantee \(\lim_{N\to\infty}\sum_tN_t\Gamma_N^{DC}(u_t)=\sum_t\mu_tQ_t^-\), and the D&C1 scaled safe-bid density \(Q_t^+-Q_t^-\) for each type.

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a set of \(m\ge2\) indivisible goods. A society is given by its support: a list of \(\tau\) types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
Each type supplies its complete binary rational utility table \(u_t:2^A\to\mathbb Q_{\ge0}\), with \(u_t(\varnothing)=0\) and \(u_t(S)\le u_t(T)\) whenever \(S\subseteq T\). Let \(L\) be the total input bit length, including all table entries and masses.
Let \(\Pi(A)\) contain all partitions of \(A\) into nonempty blocks, and define \(Q_t^+=\max_{\pi\in\Pi(A)}\sum_{S\in\pi}u_t(S)\) and \(Q_t^-=\min_{\pi\in\Pi(A)}\sum_{S\in\pi}u_t(S)\).
For \(N\ge2\), let \(E_{N,t}^+\) and \(E_{N,t}^-\) be the corresponding extrema over partitions into exactly \(N\) possibly empty shares. Define the Divide & Choose guarantee \(\Gamma_N^{DC}(u_t)=[E_{N,t}^++(N-1)E_{N,t}^-]/N^2\) and the D&C1 safe bid \(\beta_{N,t}=(E_{N,t}^+-E_{N,t}^-)/N\).
Hold \(A\) and the utility tables fixed as \(N\to\infty\). For any nonnegative integer populations satisfying \(\sum_tN_t=N\) and \(N_t/N\to\mu_t\), the requested outputs are both extrema and an attaining partition for each type, the limiting aggregate guarantee \(\lim_{N\to\infty}\sum_tN_t\Gamma_N^{DC}(u_t)=\sum_t\mu_tQ_t^-\), and each scaled safe-bid density \(\lim_{N\to\infty}N\beta_{N,t}=Q_t^+-Q_t^-\). Any attaining partition is acceptable when tied.

Is this exact computation solvable in time polynomial in \(m\), \(\tau\), and \(L\), or is it NP-hard?

For finite societies, the displayed guarantee and safe-bid formulas characterize Divide & Choose guarantees and D&C1 safe bidding; safe division uses a partition attaining the maximum. [Bogomolnaia–Moulin](https://arxiv.org/html/2202.08117v2).
No result settling this exact distributional computation with complete rational utility tables was located.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The exact computation is polynomial-time solvable with complete rational utility tables. A dynamic program computes both extrema and attaining partitions using \(O(\tau 3^m)\) transitions. This is polynomial in the explicit input length \(L\), and all arithmetic has polynomial bit complexity.

1. Computing the partition extrema

Fix a type \(t\), and order the goods. For every nonempty subset \(X\subseteq A\), let \(\Pi(X)\) denote its partitions into nonempty blocks, and define

\(F_t^+(X)=\max_{\pi\in\Pi(X)}\sum_{S\in\pi}u_t(S)\),

\(F_t^-(X)=\min_{\pi\in\Pi(X)}\sum_{S\in\pi}u_t(S)\).

Set \(F_t^+(\varnothing)=F_t^-(\varnothing)=0\), corresponding to the empty partition.

For nonempty \(X\), let \(a(X)\) be its least good. The recurrences are

\(F_t^+(X)=\max_{\substack{S\subseteq X\\a(X)\in S}}\bigl(u_t(S)+F_t^+(X\setminus S)\bigr)\),

\(F_t^-(X)=\min_{\substack{S\subseteq X\\a(X)\in S}}\bigl(u_t(S)+F_t^-(X\setminus S)\bigr)\).

To prove them, every partition of \(X\) has exactly one block \(S\) containing \(a(X)\). Removing that block leaves a partition of \(X\setminus S\). Conversely, any such block \(S\), together with any partition of \(X\setminus S\), forms a partition of \(X\). For fixed \(S\), maximizing or minimizing the remaining contribution therefore gives precisely \(F_t^+(X\setminus S)\) or \(F_t^-(X\setminus S)\). Taking the respective extremum over \(S\) proves both recurrences.

Every candidate block is nonempty, so \(X\setminus S\) is smaller than \(X\). Thus the recurrences can be evaluated in increasing subset cardinality, starting from the empty set. Their correctness follows inductively, and

\(Q_t^+=F_t^+(A),\qquad Q_t^-=F_t^-(A)\).

For each state and each extremum, store a block attaining the recurrence. Starting at \(A\), output the stored block and continue with its complement in the current state. Each step removes at least one good, so reconstruction terminates after at most \(m\) steps. The recurrence identities show that the resulting partition attains the computed extremum. Ties may be broken arbitrarily.

This argument applies to all supplied utility tables; monotonicity is not needed for the algorithm.

2. Polynomial running time and exact arithmetic

For a subset \(X\) of cardinality \(k\), exactly \(2^{k-1}\) candidate blocks contain \(a(X)\). Consequently, the number of candidates examined per type is

\(\displaystyle \sum_{k=1}^{m}\binom{m}{k}2^{k-1}=\frac{3^m-1}{2}\).

Computing both extrema therefore uses \(O(\tau 3^m)\) arithmetic operations and comparisons, with additional polynomial overhead for subset manipulation.

Because every type supplies all \(2^m\) table entries, the explicit input satisfies \(L\ge \tau 2^m\), up to an immaterial encoding constant. Hence

\(\tau 3^m\le \tau 4^m\le (\tau 2^m)^2=O(L^2)\).

It remains to account for rational arithmetic. Write each utility entry as \(u_t(S)=p_{t,S}/q_{t,S}\), with integer \(p_{t,S}\ge0\) and \(q_{t,S}\ge1\). Let \(L_t\) be the bit length of type \(t\)'s table, and set

\(\displaystyle D_t=\prod_{S\subseteq A}q_{t,S},\qquad w_t(S)=p_{t,S}\frac{D_t}{q_{t,S}}\).

The product \(D_t\) has \(O(L_t)\) bits, as does every integer \(w_t(S)\). Run the dynamic program with these integer weights. Every candidate value is the weight of a partition with at most \(m\) blocks, so it has \(O(L_t+\log m)\) bits. Integer addition, comparison, multiplication, and exact division on these lengths take polynomial time. Dividing the final integer extrema by \(D_t\) recovers \(Q_t^+\) and \(Q_t^-\) exactly.

Each reconstructed partition has at most \(m\) blocks and can be encoded with polynomially many bits. Finally, the rational quantities

\(\displaystyle G=\sum_{t=1}^{\tau}\mu_tQ_t^-,\qquad \Delta_t=Q_t^+-Q_t^-\)

can also be computed in polynomial time. Indeed, a common denominator for \(G\) is the product of all \(D_t\) and all mass denominators; its bit length is \(O(L)\). The numerators likewise have polynomial bit length, since they involve only products and sums of polynomially many input-length integers.

Thus the complete output is computable in time polynomial in \(m,\tau,L\).

3. Stabilization and the requested limits

For every \(N\ge m\), the attainable partition sums over exactly \(N\) possibly empty shares coincide with those over \(\Pi(A)\).

To verify this, delete the empty shares from any \(N\)-share partition. The remaining shares form a partition into nonempty blocks, with the same sum because \(u_t(\varnothing)=0\). Conversely, every partition into nonempty blocks has at most \(m\) blocks, so for \(N\ge m\) it can be padded with empty shares to obtain exactly \(N\) shares without changing its sum.

Therefore, for every \(N\ge m\),

\(E_{N,t}^+=Q_t^+,\qquad E_{N,t}^-=Q_t^-\).

The reconstructed partitions attain these extrema after padding with empty shares.

Since \(\Delta_t=Q_t^+-Q_t^-\), the given guarantee formula becomes

\(\displaystyle \Gamma_N^{DC}(u_t)=\frac{Q_t^-}{N}+\frac{\Delta_t}{N^2}\).

Put \(p_{N,t}=N_t/N\). Then

\(\displaystyle \sum_tN_t\Gamma_N^{DC}(u_t)=\sum_tp_{N,t}Q_t^-+\frac1N\sum_tp_{N,t}\Delta_t\).

The first sum converges to \(\sum_t\mu_tQ_t^-\), because the support is finite and \(p_{N,t}\to\mu_t\) for every type. Since \(p_{N,t}\ge0\), \(\sum_tp_{N,t}=1\), and \(\Delta_t\ge0\), the second term satisfies

\(\displaystyle 0\le\frac1N\sum_tp_{N,t}\Delta_t\le\frac{\max_t\Delta_t}{N}\to0\).

This proves

\(\displaystyle \lim_{N\to\infty}\sum_tN_t\Gamma_N^{DC}(u_t)=\sum_t\mu_tQ_t^-\).

Similarly, for every \(N\ge m\),

\(\displaystyle N\beta_{N,t}=E_{N,t}^+-E_{N,t}^-=\Delta_t\),

which proves

\(\displaystyle \lim_{N\to\infty}N\beta_{N,t}=Q_t^+-Q_t^-\).

4. Scope of the conclusion

The decisive hypothesis is the complete-table representation. An algorithm exponential in the number of goods can be polynomial in this input length. The discussion of exponential dependence on the number of goods in [Bogomolnaia–Moulin, “Computational complexity”](https://arxiv.org/html/2202.08117v2#S8.SS1) is compatible with the bound proved here.
