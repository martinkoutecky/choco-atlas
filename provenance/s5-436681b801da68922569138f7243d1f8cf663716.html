The continuous mirror question, as graded

Given two alternatives \(a,b\), rational mass \(p\) of type \(a\succ b\), and mass \(1-p\) of type \(b\succ a\), consider a nonatomic population whose members’ utilities are drawn independently from a common distribution \(\mathcal D\) on \([0,1]\). For positive mean utility, let \(v_H=\mathbb E[\max(U_1,U_2)]\) and \(v_L=\mathbb E[\min(U_1,U_2)]\), for independent \(U_1,U_2\sim\mathcal D\), and define \(W_a=pv_H+(1-p)v_L\) and \(W_b=(1-p)v_H+pv_L\). Which alternative maximizes \(W_j/\max\{W_a,W_b\}\)?

Packaged proof task (what the prover saw — nothing else)

The alternatives are \(a,b\), with \(m=2\). A society is given by its support: the list of the \(\tau\) ranking types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Masses sum to \(1\); write \(p\in[0,1]\) for the mass ranking \(a\succ b\), with the remaining mass ranking \(b\succ a\).
For any common probability distribution \(\mathcal D\) on \([0,1]\) with positive mean, draw two independent utilities and assign the larger to the first-ranked alternative and the smaller to the second-ranked alternative. Equal utilities are allowed despite strict reported rankings.
Define \(v_H=\mathbb E[\max(U_1,U_2)]\), \(v_L=\mathbb E[\min(U_1,U_2)]\), \(W_a=pv_H+(1-p)v_L\), and \(W_b=(1-p)v_H+pv_L\), where \(U_1,U_2\sim\mathcal D\) independently. These expected utility integrals define nonatomic welfare.
The computational task is to select one alternative maximizing \(W_j/\max\{W_a,W_b\}\). Either maximizer is permitted in a tie. Only the society is supplied; the selection must be valid for every admissible \(\mathcal D\).
Is this distribution-independent selection problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and the binary input length \(L\).
For finite societies with two alternatives, majority is a polynomial-time, distribution-independent rule maximizing both expected welfare and the expected welfare ratio to the realized optimum.
That discrete result concerns an expectation of a random ratio; the continuous objective specified here is a ratio of integrated expected utilities.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is in \(\mathrm P\). Select \(a\) when \(p>1/2\), select \(b\) when \(p<1/2\), and select either alternative when \(p=1/2\). This rule maximizes the specified ratio for every admissible distribution.

Proof of distribution independence

Let \(\mu=\mathbb E[U_1]>0\). Since the utilities lie in \([0,1]\), all the expectations below are finite. The pointwise identities
\(\max(U_1,U_2)+\min(U_1,U_2)=U_1+U_2\) and
\(\max(U_1,U_2)-\min(U_1,U_2)=|U_1-U_2|\)
give
\(v_H+v_L=2\mu\) and
\(v_H-v_L=\mathbb E[|U_1-U_2|]\geq 0\).

Consequently,
\(W_a+W_b=v_H+v_L=2\mu\).
Thus the denominator in the objective is positive:
\(\max\{W_a,W_b\}\geq\mu>0\).
Because both alternatives have the same positive denominator, maximizing the ratio is equivalent to maximizing their integrated expected welfare.

Subtracting the two welfare expressions yields
\(W_a-W_b=(2p-1)(v_H-v_L)=(2p-1)\mathbb E[|U_1-U_2|]\).

There are three cases:

  • If \(p>1/2\), both factors are nonnegative, so \(W_a\geq W_b\).
  • If \(p<1/2\), the first factor is negative and the second is nonnegative, so \(W_b\geq W_a\).
  • If \(p=1/2\), the difference is zero, so both alternatives maximize welfare.

In every case, the selected alternative attains ratio \(1\), the largest possible value. Equal utility draws do not affect the argument. In particular, a distribution concentrated at a positive constant makes both alternatives tie for every society.

Which selections are valid for every distribution?

For completeness, a strict majority also determines the only selection valid for every admissible distribution.

Take \(\mathcal D\) assigning probability \(1/2\) to each of \(0\) and \(1\). Its mean is positive, and independence gives \(v_H=3/4\) and \(v_L=1/4\). Hence
\(W_a-W_b=(2p-1)/2\).

For this admissible distribution, the majority alternative is strictly better whenever \(p\neq1/2\). Therefore choosing the minority alternative cannot satisfy the universal requirement. When \(p=1/2\), either alternative is valid for every distribution.

Algorithm and running time

There are exactly two possible strict ranking types when \(m=2\), so the support size satisfies \(1\leq\tau\leq2\).

Scan the support to find the mass of the type ranking \(a\succ b\); if that type is absent, set \(p=0\). If its mass is encoded as \(p=N/D\), with \(D>0\), compare the binary integers \(2N\) and \(D\). Their ordering determines whether \(p\) is above, below, or equal to \(1/2\). Doubling and comparing these integers take \(O(L)\) bit operations.

Reading the ranking lists takes \(O(m\tau)\) operations. Thus a bound displaying all requested parameters is \(O(m\tau+L)\); because \(m=2\) and \(\tau\leq2\), the total running time is \(O(L)\) bit operations under the standard explicit binary encoding. No utility distribution needs to be supplied or integrated.

The proof directly addresses the ratio of integrated expected utilities. It does not invoke the finite-society theorem about the expectation of a random ratio.
