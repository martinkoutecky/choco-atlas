The continuous mirror question, as graded

Given \(m\) indivisible projects with costs \(c_x\), budget \(1\), unit-sum utility types \(u_t\), and rational masses \(\mu_t\), partition each type mass into \(m\) candidate-query strata, apply independent thresholds \(T\sim U[0,1]\), observe the exact positive-report mass \(a_x=\sum_t\mu_tu_t(x)\) for each project, and output a feasible set \(S\) maximizing \(\sum_{x\in S}a_x\); determine its welfare guarantee and computational complexity.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) utility types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) indivisible projects, binary-rational costs \(0\leq c_x\leq1\), and budget \(1\). Each type has binary-rational utilities \(u_t(x)\geq0\), with \(\sum_xu_t(x)=1\) and pairwise distinct utilities within each type. Let \(L\) be the total input bit length.
Split each type equally among the \(m\) project-query strata. In each stratum, thresholds have exactly the uniform distribution on \([0,1]\); a truthful report is positive precisely when \(u_t(x)\geq T\). The exact positive mass for project \(x\) is \(a_x/m\), and the observed score is its rescaling \(a_x=\sum_t\mu_tu_t(x)\).
The exact rule returns a set \(S\subseteq C\) maximizing \(\sum_{x\in S}a_x\) subject to \(\sum_{x\in S}c_x\leq1\), with lexicographic tie-breaking using project labels.
Define \(W(S)=\sum_t\mu_t\sum_{x\in S}u_t(x)\), \(\mathrm{OPT}=\max_{S:\sum_{x\in S}c_x\leq1}W(S)\), and distortion as \(\sup\mathrm{OPT}/\mathbb E[W(S)]\), taking the ratio as infinite when the denominator is zero.

What is the sharp worst-case distortion of this exact rule?
For rational \(0<\varepsilon<1\), can a mechanism using only the observed scores and costs guarantee \(\mathbb E[W(S)]\geq(1-\varepsilon)\mathrm{OPT}\) in time polynomial in \(m,\tau,L,1/\varepsilon\), or is attaining this approximation NP-hard?

For a finite population of \(n\) voters, independent binary threshold queries with a uniformly balanced random project assignment yield \(W(S)\geq(1-\delta)\mathrm{OPT}\) with probability at least \(1-1/n\), where \(\delta=m^{5/2}\sqrt{72\log(4mn)/n}\), assuming exact maximization of the reported scores. Result. The sharp worst-case distortion is \(1\). Moreover, a deterministic mechanism using only the observed scores and costs achieves \(W(S)\geq(1-\varepsilon)\mathrm{OPT}\) by a fully polynomial-time approximation scheme.

1. The scores determine welfare exactly

Nonnegativity and normalization imply \(u_t(x)\in[0,1]\). Thus a uniform threshold satisfies
\(\Pr[T\leq u_t(x)]=u_t(x)\), including at the endpoints.

Type \(t\) has mass \(\mu_t/m\) in the stratum querying project \(x\). Consequently, that stratum’s positive mass is
\(\sum_{t=1}^{\tau}(\mu_t/m)u_t(x)=a_x/m\).

For every project set \(S\), interchanging the finite sums gives
\[ W(S)=\sum_{t=1}^{\tau}\mu_t\sum_{x\in S}u_t(x) =\sum_{x\in S}\sum_{t=1}^{\tau}\mu_tu_t(x) =\sum_{x\in S}a_x. \]
Therefore, the observed scores specify the welfare of every set exactly. Pairwise distinct utilities within each type are compatible with this identity and impose no additional requirement on the algorithm.

2. Sharp distortion of the exact rule

Let \(S_{\mathrm{ex}}\) be the exact rule’s output. Its objective equals welfare, and its feasibility constraint is the one defining \(\mathrm{OPT}\). Hence
\(W(S_{\mathrm{ex}})=\mathrm{OPT}\).
Lexicographic tie-breaking only chooses between sets with identical optimal welfare.

The denominator in the distortion ratio is positive. Indeed,
\(\sum_{x\in C}a_x=\sum_t\mu_t\sum_xu_t(x)=1\).
Writing \(M=\max_x a_x\), we therefore have \(M\geq1/m>0\). Since every individual project costs at most \(1\), every singleton is feasible, so \(\mathrm{OPT}\geq M\).

Thus every admissible instance has
\(\mathrm{OPT}/\mathbb E[W(S_{\mathrm{ex}})]=1\).
Taking the supremum proves that the sharp worst-case distortion is \(1\).

3. A mechanism using only scores and costs

Fix rational \(0<\varepsilon<1\), and label the projects \(1,\ldots,m\). Define
\(K=\varepsilon M/m\) and \(q_i=\lfloor a_i/K\rfloor\).
These are well-defined because \(M>0\). Each \(q_i\) is a nonnegative integer, and
\(q_i\leq m/\varepsilon\).
Consequently, \(Q=\sum_{i=1}^{m}q_i\leq m^2/\varepsilon\).

The mechanism chooses a feasible set maximizing the rounded objective
\(q(S)=\sum_{i\in S}q_i\).
It computes this set by the following dynamic program.

For \(i\in\{0,\ldots,m\}\) and \(q\in\{0,\ldots,Q\}\), let \(D_i(q)\) be the minimum cost of a subset of \(\{1,\ldots,i\}\) whose rounded objective is exactly \(q\). Use \(+\infty\) when no such subset exists. Initialize \(D_0(0)=0\) and \(D_0(q)=+\infty\) for \(q>0\). The recurrence is
\(D_i(q)=\min\{D_{i-1}(q),\,c_i+D_{i-1}(q-q_i)\}\),
where a negative index has value \(+\infty\).

To justify the recurrence, any subset either excludes project \(i\), giving the first term, or includes it, leaving a subset with rounded objective \(q-q_i\), giving the second term. Conversely, either finite term is realized by a subset with the required objective. This establishes the meaning of every state by induction.

Choose the largest \(q\) with \(D_m(q)\leq1\), and reconstruct its realizing subset \(S\). This maximizes the rounded objective among feasible sets. The recurrence remains valid for zero costs and zero rounded scores because both alternatives reference the previous layer.

4. Approximation guarantee

Let \(S^\star\) be a welfare-optimal feasible set. The floor definition gives, for every project,
\(Kq_i\leq a_i\) and \(Kq_i\geq a_i-K\).
Since the mechanism maximizes the rounded objective,
\(q(S)\geq q(S^\star)\).

Combining these facts yields
\(W(S)\geq Kq(S)\geq Kq(S^\star)\geq W(S^\star)-|S^\star|K\).

Now \(|S^\star|\leq m\), \(mK=\varepsilon M\), and \(M\leq\mathrm{OPT}\). Therefore,
\(W(S)\geq\mathrm{OPT}-\varepsilon M\geq(1-\varepsilon)\mathrm{OPT}\).

The mechanism is deterministic, so the same guarantee holds for \(\mathbb E[W(S)]\).

5. Bit complexity and the supplied results

The dynamic program has at most \((m+1)(Q+1)\) states and uses \(O(m^3/\varepsilon)\) arithmetic operations.

Exact rational arithmetic also has polynomial bit complexity. For example, the product of the input denominators of all masses and utilities is a common denominator for every score and has bit length \(O(L)\). Since \(0\leq a_x\leq1\), the corresponding score numerators also have bit length \(O(L)\). Similarly, a common denominator for the costs has bit length \(O(L)\); any subset-cost numerator has bit length \(O(L+\log m)\). Thus all dynamic-programming additions and comparisons have polynomial bit cost. Computing the scores from the supplied support, if necessary, uses \(m\tau\) products and sums and never enumerates possible utility types.

Including the supplied accuracy parameter’s encoding in total input length, the running time is polynomial in \(m,\tau,L,1/\varepsilon\). This proves the requested FPTAS directly under the stated restrictions.

The cited finite-population theorem controls sampling error, whereas the stipulated exact strata here give the welfare coefficients without sampling error.
