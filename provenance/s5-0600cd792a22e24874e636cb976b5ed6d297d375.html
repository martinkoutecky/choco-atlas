The continuous mirror question, as graded

Given a finite support of types \(t=(x_t,p_t,\rho_t)\), with rational masses \(\mu_t>0\) summing to \(1\), \(x_t\in[0,1]\), \(\rho_t\geq 0\), and \(p_t\in\{0,1\}\), find a type-symmetric pure default policy \(d:\mathcal T\to\mathcal T\cup\{\bot\}\). The policy must be a Nash equilibrium: no individual can increase their expected utility by changing their initial delegate type or choosing \(\bot\), with all other individuals following their type's policy. A type-\(t\) nonvoter receives \(\rho_t-|x_t-x_q|\) if their route reaches a certain voter of type \(q\), and \(0\) if it reaches no caster; a certain voter receives \(\rho_t\).

Packaged proof task (what the prover saw — nothing else)

A society is an atomless population given by its nonempty support \(\mathcal T\): the list of \(\tau\) types \(t=(x_t,p_t,\rho_t)\) with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). The support size \(\tau\) counts listed types, not possible types. Positions \(x_t\in[0,1]\) and tolerances \(\rho_t\geq0\) are binary rationals, and \(p_t\in\{0,1\}\). Let \(L\) be the total input bit length; there is no separate \(m\) parameter.
Assume general position on the support: for distinct \(t,s\), \(x_t\neq x_s\) and \(|x_t-x_s|\neq\rho_t\). Types with \(p_t=1\) always cast; types with \(p_t=0\) never cast. Either group may be empty.
A type-symmetric pure default policy is \(d:\mathcal T\to\mathcal T\cup\{\bot\}\), where \(\bot\) means declining delegation. Any support type, including one's own, is an available delegate. A route starts at the individual's type, stops at the first casting type, and otherwise follows \(d\); reaching \(\bot\) or repeating a noncasting type means no caster is reached.
A casting individual of type \(t\) receives \(\rho_t\); a noncasting individual receives \(\rho_t-|x_t-x_q|\) when represented by casting type \(q\), and \(0\) when no caster is reached. Negative utilities are retained.
An individual deviation changes only that individual's initial choice to some \(a\in\mathcal T\cup\{\bot\}\); thereafter the route follows the unchanged policy, including upon reaching the original type. A Nash equilibrium permits no strictly profitable individual deviation; utility ties require no tie-breaking.
The computational problem is to find such an equilibrium policy, or determine that none exists.

Can this problem be solved in polynomial time in \(\tau\) and \(L\), or is it NP-hard?

For finite societies with deterministic participation, a pure Nash equilibrium always exists and is computable in polynomial time. [Brill et al.](https://arxiv.org/html/2607.12610v1)

  • The encoding of positions and tolerances was unspecified; both are binary rationals, and L includes all input data.
  • The omitted general-position assumption is imposed between distinct support types: distinct positions and no distance exactly equal to the source type's tolerance.
  • The meaning of delegation to a type is fixed by deterministic type-level routing; delegation to one's own type is allowed, and a noncasting type cycle loses representation.
  • Individual deviations are atomless: only the initial choice changes, while subsequent routing uses the unchanged policy even at the deviator's original type.
  • Declining delegation gives no representation to a noncaster; casting overrides every default choice. Utilities are not truncated at zero, and only strict improvements violate equilibrium.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The problem is polynomial-time solvable, and every valid input admits an equilibrium. This holds also when both casting and noncasting types are present.

The essential observation is that every casting type is directly available to every individual. Thus delegation chains cannot provide a better outcome than choosing a nearest casting type, or declining delegation when all casting outcomes have negative utility.

1. A policy-independent bound on individual utility.

Let \(C=\{q\in\mathcal T:p_q=1\}\) be the set of casting types and \(N=\mathcal T\setminus C\) the set of noncasting types.

For each \(t\in N\), define
\(B_t=\max\bigl(\{0\}\cup\{\rho_t-|x_t-x_q|:q\in C\}\bigr)\).
This definition gives \(B_t=0\) when \(C\) is empty.

Fix any policy \(d\) and any individual of noncasting type \(t\). Under either the prescribed choice or an individual deviation, the route has exactly two possible kinds of outcome:

  • It reaches a casting type \(q\in C\), giving utility \(\rho_t-|x_t-x_q|\).
  • It reaches no casting type, giving utility \(0\).

Consequently, every such utility is at most \(B_t\). This argument includes routes that return to the original type and then follow its unchanged policy: their eventual outcome still belongs to one of these two categories.

Moreover, an individual can attain \(B_t\), independently of \(d\). If \(B_t=0\), choosing \(\bot\) attains it. If \(B_t>0\), choose a casting type \(q\) attaining the maximum. The route stops immediately at \(q\), so the utility is \(B_t\).

It follows that a policy is an equilibrium if and only if every noncasting type \(t\) receives utility \(B_t\):

  • If its current utility is smaller, one of the choices just described is a strictly profitable deviation.
  • If its current utility equals \(B_t\), the bound proves that no deviation is strictly profitable.

Casting individuals always receive \(\rho_t\), regardless of their initial delegation choice, so they impose no additional equilibrium conditions.

2. Construction of an equilibrium.

Construct \(d\) as follows.

  • For every \(t\in C\), set \(d(t)=\bot\).
  • If \(C=\varnothing\), set \(d(t)=\bot\) for every \(t\in N\).
  • Otherwise, for each \(t\in N\), choose any

\(q_t\in\operatorname*{arg\,min}_{q\in C}|x_t-x_q|\)
and put \(\delta_t=|x_t-x_{q_t}|\).
Set \(d(t)=q_t\) if \(\delta_t<\rho_t\), and set \(d(t)=\bot\) otherwise.

Ties between nearest casting types can be resolved by their input order.

To verify the construction, consider any \(t\in N\).

If \(C=\varnothing\), its utility is \(0=B_t\).

If \(C\neq\varnothing\), the minimality of \(\delta_t\) gives
\(B_t=\max\{0,\rho_t-\delta_t\}\).
When \(\delta_t<\rho_t\), the constructed route reaches \(q_t\) immediately and gives utility \(\rho_t-\delta_t=B_t\). When \(\delta_t\geq\rho_t\), declining delegation gives utility \(0=B_t\).

Thus every noncasting type attains its policy-independent maximum. By the characterization above, \(d\) is a Nash equilibrium. The construction assigns one choice to each support type, so it is type-symmetric.

General position excludes \(\delta_t=\rho_t\), because \(t\) and \(q_t\) are distinct. Even if that equality were allowed, choosing \(\bot\) would remain valid because only strictly profitable deviations matter.

3. Bit complexity and scope.

Scanning all casting types for each noncasting type uses at most \(\tau^2\) distance evaluations and comparisons.

These operations can be performed exactly on binary rationals. For example, if \(x_t=a/b\) and \(x_q=c/e\), then
\(|x_t-x_q|=|ae-bc|/(be)\).
Comparing two distances, or comparing a distance with a tolerance, requires only a constant number of integer additions and multiplications by cross multiplication. All intermediate integers have bit length \(O(L)\). With schoolbook arithmetic, the algorithm therefore uses \(O(\tau^2L^2)\) bit operations, a polynomial bound.

The masses \(\mu_t\) do not enter the construction: individual utility depends only on the eventual caster or its absence. Both empty-group cases are covered, and no instance requires reporting nonexistence.

This construction parallels the nearest acceptable caster construction in [Brill et al., Theorem 1(i)](https://arxiv.org/html/2607.12610v1). The argument above independently verifies it for the specified atomless deviation rule.
