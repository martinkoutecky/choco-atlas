The continuous mirror question, as graded

Given finite types \(S\) with positive rational masses \(\mu_s\) summing to \(1\), integer prior cumulative allocations \(a_s\), integer current demands \(d_s\), and common per-user fair share \(f\), compute integer allocations \(x_s\) to every member of type \(s\), subject to \(0\le x_s\le d_s\) and \(\sum_{s\in S}\mu_s x_s\le f\), that maximize \(\min_{s\in S}(a_s+x_s)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(S\) of \(\tau\) types with positive binary rational masses \(\mu_s\), where \(\sum_{s\in S}\mu_s=1\). Here \(\tau=|S|\) is the support size, not the number of possible types.
There is one resource, so \(m=1\). Each type has prior cumulative allocation \(a_s\in\mathbb Z_{\ge0}\) and current demand \(d_s\in\mathbb Z_{\ge0}\); the common fair share is \(f\in\mathbb Z_{>0}\). All integers are binary encoded, and \(L\) is the total input bit length.
Choose a common allocation \(x_s\in\mathbb Z_{\ge0}\) for every member of type \(s\), with \(x_s\le d_s\) and \(\sum_{s\in S}\mu_s x_s\le f\), maximizing \(\min_{s\in S}(a_s+x_s)\). Types cannot be split between different allocations. There is no guaranteed instantaneous share or credit constraint; any maximizer is acceptable.

Is computing an optimal allocation polynomial-time in \(m,\tau,L\), or is deciding whether a feasible allocation satisfies \(\min_{s\in S}(a_s+x_s)\ge k\), for a binary encoded \(k\in\mathbb Z_{\ge0}\), NP-hard?

Discrete case: with finitely many users, equal fair shares, zero guaranteed instantaneous share, and sufficient credits, Karma maximizes the minimum cumulative allocation after the current quantum, given fixed past allocations and current demands.

Result

Computing an optimal allocation is polynomial-time solvable for \(m=1\). The threshold decision problem is in \(\mathrm{P}\).

The key is that a prescribed minimum cumulative allocation imposes a unique componentwise smallest allocation. Checking its demand and budget constraints completely determines feasibility, even when each type must receive a common integer allocation.

1. Exact characterization of threshold feasibility

Fix an integer threshold \(k\in\mathbb Z_{\ge 0}\). For each type \(s\in S\), define
\(r_s(k)=\max\{0,k-a_s\}\).

This is a nonnegative integer.

Lemma. A feasible allocation satisfying \(\min_{s\in S}(a_s+x_s)\ge k\) exists if and only if both of the following hold:

  • \(r_s(k)\le d_s\) for every \(s\in S\).
  • \(\sum_{s\in S}\mu_s r_s(k)\le f\).

Proof. Suppose such an allocation \(x\) exists. For every type, the threshold condition implies \(x_s\ge k-a_s\). Together with \(x_s\ge 0\), this gives \(x_s\ge r_s(k)\). Therefore,
\(r_s(k)\le x_s\le d_s\).

Since every mass is positive, componentwise comparison also gives
\(\sum_{s\in S}\mu_s r_s(k)\le \sum_{s\in S}\mu_s x_s\le f\).
Both conditions are necessary.

Conversely, if both conditions hold, choose \(x_s=r_s(k)\) for every type. These allocations are integers, satisfy the demand caps and budget constraint, and obey
\(a_s+r_s(k)\ge k\).
They consequently form a feasible allocation attaining the threshold. This proves sufficiency. \(\square\)

In particular, this construction assigns one integer allocation to each entire type; it never splits a type.

2. Threshold feasibility can be checked in polynomial time

Write each input mass as \(\mu_s=p_s/q_s\), with positive binary-encoded integers \(p_s,q_s\). Reduction to lowest terms is unnecessary. Define
\(D=\prod_{s\in S}q_s\)
and
\(w_s=p_s(D/q_s)\).

Every \(w_s\) is an integer, and \(\mu_s=w_s/D\). Thus the budget test in the lemma is exactly the integer comparison
\(\sum_{s\in S}w_s r_s(k)\le fD\).

There is no rounding or numerical approximation.

Although \(D\) can have a large numerical value, its binary length is polynomial in the input length: indeed,
\(\log_2 D=\sum_{s\in S}\log_2 q_s\),
and the denominator encodings contribute to \(L\). Hence \(D\) has \(O(L)\) bits.

The normalization of the masses gives
\(\sum_{s\in S}w_s=D\).
Consequently, \(0<w_s\le D\). Also, because \(a_s\ge 0\),
\(0\le r_s(k)\le k\), so
\(\sum_{s\in S}w_s r_s(k)\le Dk\).

It follows that all integers used in this feasibility check have bit lengths polynomial in \(L\) and the encoded length of \(k\). Computing them and comparing them uses polynomially many bit operations with ordinary exact integer arithmetic. Therefore the threshold decision problem belongs to \(\mathrm{P}\).

3. Finding an optimal threshold

Define
\(b=\min_{s\in S}a_s\)
and
\(U=\min_{s\in S}(a_s+d_s)\).

The allocation \(x_s=0\) is feasible and has minimum cumulative allocation \(b\). Thus an optimal objective value is at least \(b\).

For every feasible allocation and every type,
\(a_s+x_s\le a_s+d_s\).
Taking minima yields
\(\min_{s\in S}(a_s+x_s)\le U\).
Therefore the optimal objective value lies in the integer interval \([b,U]\).

Threshold feasibility is monotone: if \(k'\le k\), then
\(r_s(k')\le r_s(k)\)
for every type. Hence feasibility of \(k\) implies feasibility of \(k'\), by the lemma.

We can therefore find the greatest feasible threshold using binary search:

  • Initialize \(\ell=b\) and \(h=U\).
  • While \(\ell<h\), set \(t=\lfloor(\ell+h+1)/2\rfloor\).
  • If \(t\) passes the feasibility test, set \(\ell=t\); otherwise set \(h=t-1\).
  • Return \(K=\ell\).

For completeness, let \(K^\star\) be the optimal objective value. Initially,
\(\ell\le K^\star\le h\).
If \(t\) is feasible, then \(K^\star\ge t\), so updating the lower endpoint preserves this invariant. If \(t\) is infeasible, monotonicity implies that every threshold at least \(t\) is infeasible; hence \(K^\star\le t-1\), and updating the upper endpoint also preserves the invariant. Each iteration reduces the interval, so termination gives \(K=K^\star\).

The integers \(b\) and \(U\) have \(O(L)\) bits. Thus binary search takes \(O(L)\) feasibility checks. For example, schoolbook integer arithmetic gives a sufficient overall bound of \(O(\tau L^3)\) bit operations for the optimization algorithm.

4. Recovering an optimal allocation

Output
\(x_s^\star=\max\{0,K-a_s\}\)
for every \(s\in S\).

Because \(K\) is feasible, the lemma proves that this allocation satisfies all demand and budget constraints and attains minimum cumulative allocation at least \(K\). Its minimum cannot exceed \(K\), since \(K=K^\star\) is the optimal objective value. Hence it is an optimal allocation.

This settles the rational-mass problem directly. The discrete Karma guarantee is not needed for the proof. The threshold problem could be NP-hard under polynomial-time many-one reductions only if \(\mathrm{P}=\mathrm{NP}\).
