Theorem 2 — class: hardness

The continuous mirror question, as graded

Given programs \(P\), a finite set of agent types \(\mathcal T\), rational masses \(\mu_t\ge 0\) summing to \(1\), type rankings of acceptable programs, program rankings of types in priority tiers, and nonnegative per-unit program costs \(c(p)\), choose \(x_{tp}\ge 0\) on mutually acceptable pairs with \(\sum_p x_{tp}=\mu_t\) for every type. Require that there are no types \(t,u\) and programs \(p,q\) with \(x_{tq}>0\), \(x_{up}>0\), \(p\succ_t q\), and \(t\) in a strictly higher priority tier than \(u\) at \(p\). Minimize \(\sum_p c(p)\sum_t x_{tp}\) (or decide whether this value can be at most a given rational budget \(B\)); measure complexity in \(|P|\), support size \(\tau=|\mathcal T|\), and input bit length \(L\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(\mathcal T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(P\) be the programs and \(m=|P|\).
Mutual acceptability is specified by \(E\subseteq\mathcal T\times P\); every type has a nonempty acceptable set and a strict ranking \(\succ_t\) of it. Each program partitions its acceptable types into ordered priority tiers; types within a tier are tied, with no tie-breaking. Write \(t\succ_p u\) for strictly higher priority.
Programs have no quotas and have finite costs \(c(p)\in\mathbb Q_{\geq0}\). The budget \(B\in\mathbb Q_{\geq0}\) is part of the input; \(L\) is the total input bit length.
An allocation consists of real masses \(x_{tp}\geq0\) on \(E\), zero elsewhere, satisfying \(\sum_p x_{tp}=\mu_t\) for every type; a type's mass may be split.
It is envy-free if there are no \(t,u\in\mathcal T\) and \(p,q\in P\) with \((t,p)\in E\), \(x_{tq}>0\), \(x_{up}>0\), \(p\succ_t q\), and \(t\succ_p u\). A closed program creates no envy condition.
The decision problem asks whether such an allocation exists with \(\sum_{p\in P}c(p)\sum_{t\in\mathcal T}x_{tp}\leq B\).

Is this continuous decision problem in \(\mathsf P\), with running time polynomial in \(m,\tau,L\), or is it \(\mathsf{NP}\)-hard?

For indivisible agents with strict preferences, minimum total cost is strongly \(\mathsf{NP}\)-hard even with exactly \(f\geq2\) acceptable programs per agent, two costs, and both sides' lists obtained by restricting fixed global orders. [Source](https://arxiv.org/html/2101.04425v4).
No result settling the exact mass-allocation problem above was located in the literature search.

Modeling choices made when packaging the task

  • Type rankings are strict, as in the discrete definition; program priority tiers remain as specified in the continuous question, with ties creating no justified envy and no tie-breaking.
  • Costs are finite nonnegative binary rationals, extending the discrete nonnegative integer domain to give the continuous input a finite encoding; the budget is a nonnegative binary rational.
  • Every supported type has a nonempty mutually acceptable set, reflecting the intended requirement that every agent can be assigned.
  • Zero-mass types are omitted from the support; masses retain the specified normalization to one.
  • Mutual acceptability of the envied program is explicitly required, and programs have no capacity constraints, as in the discrete model.

Result

The decision problem is \(\mathsf{NP}\)-complete. Splitting mass does not improve the minimum achievable cost: every envy-free allocation can be replaced by an envy-free allocation assigning each type entirely to one program, at no greater cost.

Hardness holds even with equal dyadic masses, exactly two acceptable programs per type, costs in \(\{0,1\}\), strict program priorities, and preferences and priorities obtained by restricting fixed global orders.

1. Eliminating splitting

For an allocation \(x\), define its positive support by
\(S(x)=\{(t,p)\in E:x_{tp}>0\}\).

Lemma. If \(x\) is envy-free and \(y\) is another allocation satisfying \(S(y)\subseteq S(x)\), then \(y\) is envy-free.

Proof. Suppose that \(y\) has an envy witness \(t,u,p,q\). Thus \(y_{tq}>0\), \(y_{up}>0\), \((t,p)\in E\), \(p\succ_t q\), and \(t\succ_p u\). Support inclusion implies \(x_{tq}>0\) and \(x_{up}>0\). All acceptability and ranking conditions are unchanged, so the same tuple witnesses envy in \(x\), a contradiction. \(\square\)

Now let \(x\) be any envy-free allocation. For each type \(t\), choose a program \(s(t)\) minimizing \(c(p)\) among programs with \(x_{tp}>0\). This set is nonempty because \(\sum_p x_{tp}=\mu_t>0\).

Define \(y_{t,s(t)}=\mu_t\), with all other entries zero. This is an allocation, and its support is contained in that of \(x\); consequently it is envy-free by the lemma. Moreover, for every type \(t\),

\(\displaystyle \mu_t c(s(t))=\sum_{p:x_{tp}>0}x_{tp}c(s(t))\leq\sum_p x_{tp}c(p).\)

Summing over types proves that the cost of \(y\) is at most the cost of \(x\).

Thus budget feasibility is equivalent to the existence of an envy-free function \(s:\mathcal T\to P\), with \((t,s(t))\in E\), satisfying
\(\sum_t\mu_t c(s(t))\leq B\).
This argument allows arbitrary priority ties and real allocation entries.

2. Polynomial reduction from the indivisible problem

We use the following known decision hardness result: deciding whether all indivisible agents can be assigned envy-freely with total cost at most an integer threshold \(K\) is \(\mathsf{NP}\)-hard, even with exactly two acceptable programs per agent, costs in \(\{0,1\}\), and both sides’ lists obtained by restricting fixed global orders. The explicit threshold reduction appears in Section 5.1 of [Limaye and Nasre, *Envy-free matchings with cost-controlled quotas*](https://arxiv.org/html/2101.04425v4#S5.SS1), taking their parameter \(f=2\).

Let such a source instance have \(n\geq1\) agents. Let \(D\) be the smallest power of two satisfying \(D\geq n\). We construct a society as follows.

Each original agent becomes one type of mass \(1/D\), retaining its acceptable programs and preferences. Every original program retains its cost and strict priority order, represented by singleton priority tiers.

If \(D>n\), add \(D-n\) dummy types and two new programs \(z_0,z_1\). Each dummy type has mass \(1/D\), accepts exactly these two programs, and prefers \(z_0\) to \(z_1\). Set \(c(z_0)=0\) and \(c(z_1)=1\). Both programs rank the dummy types in the same strict order. Original types do not accept these programs, and dummy types do not accept original programs.

Finally, set \(B=K/D\).

There are exactly \(D\) types, so their masses sum to one. All masses and the budget are dyadic rationals. Since \(D\leq2n\), the construction has polynomial size and bit length.

The stated restrictions are preserved. In particular, extend the original global program order by placing \(z_0\) before \(z_1\) at its end, and extend the global agent order by appending the dummy types in their priority order.

Forward direction. Suppose the source instance has a complete envy-free assignment of cost at most \(K\). Assign each corresponding type its entire mass at the same program, and assign every dummy type entirely to \(z_0\).

The original types remain envy-free because positive-support assignments and all relevant rankings are unchanged. Dummy types receive their first choice, and there are no acceptable pairs connecting the original and dummy parts. Hence the full allocation is envy-free. Its cost is at most \(K/D=B\).

Reverse direction. Suppose the constructed society has an envy-free allocation of cost at most \(B\). By Section 1, replace it by an envy-free allocation assigning every type entirely to one program, without increasing cost. Write its assignment function as \(s\). Since every mass equals \(1/D\),

\(\displaystyle \frac1D\sum_{t\in\mathcal T}c(s(t))\leq\frac KD.\)

Therefore \(\sum_{t\in\mathcal T}c(s(t))\leq K\). Costs are nonnegative, so the sum over original types alone is at most \(K\).

Restricting \(s\) to original types gives a complete source assignment. Any envy witness in that assignment would also be an envy witness in the constructed society. Thus the source assignment is envy-free and has cost at most \(K\).

Both directions establish a polynomial many-one reduction, proving \(\mathsf{NP}\)-hardness.

3. Membership in \(\mathsf{NP}\)

A certificate specifies one acceptable program \(s(t)\) for each type. Its length is polynomial in \(\tau\) and \(\log m\).

The verifier checks acceptability and the exact rational inequality
\(\sum_t\mu_t c(s(t))\leq B\).
Products and sums of the input rationals have polynomial bit length and can be compared using exact integer arithmetic.

For envy-freeness, the verifier examines every ordered pair of types \(t,u\). Put \(p=s(u)\). It rejects precisely when \((t,p)\in E\), \(p\succ_t s(t)\), and \(t\succ_p u\). These are exactly the possible envy witnesses for the certified allocation. With rank tables, this requires polynomial time.

Section 1 proves that every yes-instance has such a certificate, even if its initial witness uses irrational or split masses. Hence the continuous decision problem belongs to \(\mathsf{NP}\).

Together with Section 2, this proves \(\mathsf{NP}\)-completeness. A running time polynomial in \(m,\tau,L\) would therefore imply \(\mathsf P=\mathsf{NP}\).
