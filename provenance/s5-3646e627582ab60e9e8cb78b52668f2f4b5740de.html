The continuous mirror question, as graded

Given a finite set of preference types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), and indivisible public object classes \(J\) with rational per-capita supplies \(q_j\), compute an assignment \(x_{tj}\ge 0\), including the null object \(o^*\), with \(\sum_{j\in J\cup\{o^*\}}x_{tj}=\mu_t\) and \(\sum_{t\in T}x_{tj}\le q_j\), such that no feasible reassignment weakly improves every agent and strictly improves a positive mass.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) preference types \(T\) with positive masses \(\mu_t\) encoded as binary rationals, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\ge1\) publicly available object classes \(J\), each with positive binary-rational per-capita supply \(q_j\), and an unlimited null object \(o^*\). Each type has a strict ranking \(\succ_t\) of \(A=J\cup\{o^*\}\); the null object may occur anywhere. Copies within a class are interchangeable, and each individual receives one object or the null object.
An assignment records masses receiving actual objects: \(x_{tj}\ge0\), \(\sum_{j\in A}x_{tj}=\mu_t\), and \(\sum_t x_{tj}\le q_j\) for \(j\in J\). Let \(L\) be the total input bit length.
A Pareto improvement is a nonnegative real array \(z_{tab}\), recording mass of type \(t\) moved from \(a\) to \(b\), with \(\sum_b z_{tab}=x_{ta}\), \(z_{tab}=0\) unless \(b=a\) or \(b\succ_t a\), and \(\sum_{t,a}z_{taj}\le q_j\) for \(j\in J\), such that \(\sum_{t,a,b:\,b\succ_t a}z_{tab}>0\). An assignment is Pareto efficient if no such improvement exists.

Can a rational Pareto-efficient assignment always be computed in time polynomial in \(m,\tau,L\), or is this search problem NP-hard?

For discrete public ownership, YRMH-IGYT produces Pareto-efficient allocations, and its outcomes coincide with the strong, exclusion, refined exclusion, rectified, and effective cores. [Discrete characterization](https://arxiv.org/html/2511.21155v3).
No complexity classification for the exact mass-assignment problem defined here was located in the literature search.

Modeling choices made when packaging the task

  • Specified strict rankings over object classes and the null object, allowing unacceptable objects as in the discrete model; copies within a class are interchangeable.
  • Required a nonempty set of object classes and positive supplies, reflecting the discrete model's nonempty object set; imposed no normalization on total supply.
  • Interpreted assignment entries as masses receiving actual indivisible objects and formalized individual weak improvement through within-type transport of those masses.
  • Requested rational output assignments while permitting real-valued reassignment masses in the efficiency definition.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

A rational Pareto-efficient assignment can always be computed in time polynomial in \(m,\tau,L\). A greedy algorithm suffices, including when the null object occurs anywhere in a ranking. The proof applies to arbitrary real improvement arrays as defined in the question.

Algorithm

Fix any order \(t_1,\ldots,t_\tau\) of the listed support types. Initialize residual supplies \(R_j=q_j\) for each \(j\in J\), and initialize every assignment entry to zero.

For each type \(t_i\):

  • Set its remaining mass to \(r=\mu_{t_i}\).
  • Scan its ranking from best to worst.
  • Upon encountering an actual class \(j\), assign \(x_{t_i j}=\min\{r,R_j\}\), then subtract this amount from both \(r\) and \(R_j\).
  • Upon encountering \(o^*\), assign \(x_{t_i o^*}=r\) and stop processing this type. Also stop whenever \(r=0\).

All updates preserve nonnegativity. Every type receives its entire mass because the null object is available without limit. Each actual class receives at most its supply because assignments are deducted from its residual supply. Thus the output is feasible.

Prefix-maximality lemma

Let \(R_j^i\) denote the residual supply of class \(j\) just before processing \(t_i\). A *ranking prefix* is a set consisting of the first several alternatives in that type’s ranking. For an array \(v\), write \(v_t(P)=\sum_{a\in P}v_{ta}\).

Lemma. For every ranking prefix \(P\) of \(t_i\), the algorithm satisfies

\[ x_{t_i}(P)= \begin{cases} \min\left\{\mu_{t_i},\sum_{j\in P}R_j^i\right\},&o^*\notin P,\\ \mu_{t_i},&o^*\in P. \end{cases} \]

Moreover, every nonnegative row \(v_{t_i}\) satisfying \(\sum_{a\in A}v_{t_i a}=\mu_{t_i}\) and \(v_{t_i j}\le R_j^i\) for each actual class satisfies \(v_{t_i}(P)\le x_{t_i}(P)\).

Proof. Before encountering the null object, let \(S_k\) be the total mass assigned after scanning the first \(k\) alternatives, and let the \(k\)-th alternative be \(a_k\in J\). Since this class has not previously been visited during this type’s turn,

\[ S_k=S_{k-1}+\min\{\mu_{t_i}-S_{k-1},R_{a_k}^i\} =\min\{\mu_{t_i},S_{k-1}+R_{a_k}^i\}. \]

Starting with \(S_0=0\), induction gives the first formula. At the null object, all remaining mass is assigned, giving the second formula.

For any competing row \(v_{t_i}\), a prefix excluding the null object satisfies both \(v_{t_i}(P)\le\mu_{t_i}\) and \(v_{t_i}(P)\le\sum_{j\in P}R_j^i\). A prefix including the null object satisfies \(v_{t_i}(P)\le\mu_{t_i}\). These bounds prove the claim. \(\square\)

Pareto-efficiency proof

Suppose, for contradiction, that the output admits a Pareto improvement \(z\). Define its resulting assignment by

\[ y_{tb}=\sum_{a\in A}z_{tab}. \]

The defining constraints on \(z\) imply that \(y\) is feasible: its rows sum to the prescribed masses, and its actual-object columns respect the supplies.

Choose the smallest index \(i\) for which some strictly improving move has positive mass, meaning \(z_{t_iab}>0\) with \(b\succ_{t_i}a\). Such an index exists because the total strictly improving mass is positive.

For every earlier type \(t_h\), no strictly improving move has positive mass. Since every permitted move is either diagonal or strictly improving, all its moves are diagonal. Consequently \(y_{t_hj}=x_{t_hj}\) for \(h<i\).

Feasibility of \(y\), together with nonnegativity of later types’ allocations, therefore gives, for every actual class \(j\),

\[ y_{t_i j}\le q_j-\sum_{h<i}y_{t_hj} =q_j-\sum_{h<i}x_{t_hj} =R_j^i. \]

The prefix-maximality lemma applies to \(y_{t_i}\). Hence every ranking prefix \(P\) of \(t_i\) satisfies

\[ y_{t_i}(P)\le x_{t_i}(P). \]

On the other hand, a permitted move cannot leave a ranking prefix: every alternative inside the prefix is preferred to every alternative outside it. Using the source-mass constraints on \(z\), we obtain

\[ y_{t_i}(P)-x_{t_i}(P) =\sum_{a\notin P,\ b\in P}z_{t_iab}\ge0. \]

Now take a positive strictly improving move \(z_{t_iab}\), and choose \(P\) to be the prefix ending at \(b\). Because \(b\succ_{t_i}a\), this prefix contains \(b\) and excludes \(a\). Thus

\[ y_{t_i}(P)-x_{t_i}(P)\ge z_{t_iab}>0, \]

contradicting prefix maximality. Therefore no Pareto improvement exists. \(\square\)

Exact arithmetic and complexity

Write each input mass and supply as a ratio of binary integers with positive denominator. Let \(D\) be the product of all these denominators. Its binary length is at most the sum of their binary lengths, hence is \(O(L)\).

Scale every mass and supply by \(D\). All quantities are then integers, and the algorithm uses only comparisons, minima, and subtractions. Every intermediate integer has \(O(L)\) bits: residual supplies never increase, and remaining masses and assigned masses are at most \(D\).

There are at most \(\tau(m+1)\) ranking visits. Constructing the scaled inputs, performing these integer operations, and writing the output all take polynomial time in \(m,\tau,L\). Dividing each assigned integer by \(D\) yields an exact rational assignment, with \(O(L)\) bits per entry.

The algorithm processes the listed support directly; it never expands rational masses into individual agents or enumerates absent preference types.
